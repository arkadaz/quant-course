Building and Testing a Risk Model · 5 หัวข้อ

บทนี้สร้าง risk model ขึ้นมาเองจากข้อมูลดิบ จนได้ตัวเลขความเสี่ยงที่โปรแกรมจัดพอร์ตใช้ได้ทุกเช้า งานมีห้าชิ้น: หา factor return ของแต่ละวัน วัด covariance ของ factor ให้ไม่สูงเกินจริง ทำให้ตัวเลขตามทันเมื่อตลาดปั่นป่วน สร้าง covariance ของส่วนเฉพาะตัวที่รู้จักคู่หุ้นพิเศษ และคัดข้อมูลผิดออกโดยไม่ทิ้งข่าวจริง

คำถามหลักของบท

กองทุนหุ้นแห่งหนึ่งมีโปรแกรมชื่อ optimizer ทำหน้าที่เลือกทุกเช้าว่าจะถือหุ้นตัวไหนเท่าไร โปรแกรมนี้ต้องรู้ว่าพอร์ตแต่ละแบบเสี่ยงแค่ไหน ตัวเลขความเสี่ยงนี้มาจาก risk model คือแบบจำลองที่บอกว่าหุ้นแต่ละตัวแกว่งแรงแค่ไหน และหุ้นแต่ละคู่ขยับไปด้วยกันแค่ไหน บทนี้คือการสร้าง risk model นั้นขึ้นมาเองจากข้อมูลดิบ

ทีม risk model ดูแลหุ้น 600 ตัว (เรียกชุดหุ้นที่ดูแลทั้งหมดว่าจักรวาล) และต้องส่งรายงานความเสี่ยงให้โต๊ะเทรดก่อนตลาดเปิดทุกเช้า ทีมมีข้อมูลอยู่สองอย่าง

  • คุณสมบัติของแต่ละบริษัท เช่นอยู่กลุ่มธุรกิจ (industry) ไหน ราคาวิ่งแรงแค่ไหนในปีที่ผ่านมา (momentum) และบริษัทใหญ่แค่ไหน (มูลค่าตลาด คือราคาหุ้นคูณจำนวนหุ้นทั้งหมด)
  • ผลตอบแทนรายวันของหุ้นแต่ละตัว คือราคาเปลี่ยนไปกี่เปอร์เซ็นต์ในวันนั้น

ทีมใช้ factor model แบบจำลองนี้มองผลตอบแทนของหุ้นว่ามีสองส่วน ส่วนแรกมาจากแรงร่วมไม่กี่ตัวที่กระทบหุ้นหลายตัวพร้อมกัน เรียกแรงเหล่านี้ว่า factor เช่น market (แรงของทั้งตลาด) กลุ่มธุรกิจ และ momentum ขนาดของแรงร่วมแต่ละตัวในวันหนึ่ง วัดเป็นเปอร์เซ็นต์ เรียกว่า factor return ส่วนที่สองเป็นเรื่องของหุ้นตัวนั้นเอง เช่นบริษัทประกาศกำไร เรียกว่าส่วนเฉพาะตัว (idiosyncratic)

เช้านี้มีห้าคำถามรออยู่ ตัวเลขในคำถามเป็นผลที่หัวข้อในบทจะคำนวณให้ดูทีละขั้น

  1. factor return ของเมื่อวานคือเท่าไร ไลบรารี regression คืนค่า market −0.0324% มาโดยไม่เตือน แต่สมการที่มันแก้มีคำตอบที่ดีเท่ากันนับไม่ถ้วน ตัวเลขนี้จึงยังเชื่อไม่ได้
  2. ความผันผวนของ momentum ที่วัดได้คือ 0.3693% ต่อวัน ตัวเลขนี้เชื่อได้ไหม
  3. เมื่อตลาดเข้าช่วงปั่นป่วนแรง (บทนี้เรียกว่าพายุ) ตัวเลขความเสี่ยงจะตามทันภายในกี่วัน
  4. คู่หุ้นคู่ไหนที่แบบจำลองแนวทแยงรายงานความเสี่ยงผิดไปเกือบเท่าตัว (แบบจำลองแนวทแยงคือแบบที่ถือว่าส่วนเฉพาะตัวของหุ้นสองตัวไม่เกี่ยวกันเลย)
  5. ข้อมูลเช้านี้บอกว่าหุ้นตัวหนึ่งขึ้น 340% ในวันเดียว ค่านี้ควรแก้ ตัดทิ้ง หรือเก็บไว้

ทั้งบทใช้ตัวอย่างชุดเดียวต่อกันไป คือหุ้นแปดตัว (ข้อมูลสมมติ) แบ่งเป็นกลุ่ม tech สามตัว ธนาคาร (banks) สองตัว และพลังงาน (energy) สามตัว เอาหุ้นแปดตัวนี้มาซ้ำ 75 ชุด ได้จักรวาล $8\times75=600$ ตัว ส่วนหัวข้อที่ต้องใช้ factor จำนวนมาก ใช้แบบจำลอง 40 factor

ความคิดที่ร้อยทั้งบทคือ factor return ทุกตัวเป็นผลตอบแทนของพอร์ตหุ้นพอร์ตหนึ่งที่ซื้อได้จริง เรียกพอร์ตนี้ว่า factor-mimicking portfolio (พอร์ตเลียนแบบ factor) ความคิดนี้อธิบายได้สามเรื่อง

  • ทำไมการเลือกเงื่อนไขของ regression จึงเปลี่ยนความหมายของ market: แต่ละเงื่อนไขให้พอร์ตคนละพอร์ต
  • ทำไม covariance ที่วัดได้จึงสูงเกินจริงเสมอ: พอร์ตนั้นพกการแกว่งเฉพาะตัวของหุ้นที่ถืออยู่มาด้วย
  • ทำไมการตัดข่าวจริงทิ้งจึงผิด: ตัวเลขที่ได้กลายเป็นผลตอบแทนของพอร์ตบนราคาที่ไม่เคยเกิด

อีกความคิดหนึ่งที่ใช้ซ้ำทั้งบทคือ ก่อนจะเชื่อหรือทิ้งข้อมูลก้อนไหน ให้นับก่อนว่ามันมีหลักฐานจริงกี่ชิ้น

ก่อนเริ่ม: บท factor model ใช้ factor return และ covariance ราวกับว่ามีให้อยู่แล้ว บทนี้คือที่มาของตัวเลขเหล่านั้น จึงควรคุ้นกับสองเรื่องจากบทนั้น

  • สมการ factor model $\mathbf r=\mathbf B\mathbf f+\boldsymbol\epsilon$ โดย $\mathbf r$ คือผลตอบแทนของหุ้นทุกตัว $\mathbf B$ คือ matrix ของ loading (ตัวคูณที่บอกว่าหุ้นแต่ละตัวรับแรงของ factor แต่ละตัวมากแค่ไหน) $\mathbf f$ คือ factor return และ $\boldsymbol\epsilon$ คือส่วนเฉพาะตัว
  • การแยก PnL เป็นส่วนของ factor กับส่วนเฉพาะตัว (PnL คือกำไรขาดทุนของพอร์ต)

เครื่องมือที่ใช้ระหว่างทาง กดที่ชื่อเพื่อทบทวนได้

  • OLS regression: หาตัวคูณที่ทำให้สมการเข้ากับข้อมูลมากที่สุด ผ่านสมการ normal equations
  • rank ของ matrix: จำนวนคอลัมน์ที่เป็นอิสระกันจริง
  • ตัวคูณ Lagrange: วิธีหาคำตอบที่ดีที่สุดเมื่อมีเงื่อนไขบังคับ
  • covariance matrix: ตารางที่บอกว่าแต่ละตัวแกว่งแค่ไหน และแต่ละคู่ขยับไปด้วยกันแค่ไหน
  • eigenvalue และ positive definite: ใช้ตรวจว่า covariance matrix ยังใช้งานได้ คือไม่มีพอร์ตไหนที่ variance ออกมาติดลบหรือเป็นศูนย์
  • AR(1): ค่าวันนี้เท่ากับสัดส่วนหนึ่งของค่าเมื่อวาน บวกเสียงรบกวน
  • EWMA กับ Kalman filter: ค่าเฉลี่ยที่ให้น้ำหนักวันใหม่มากกว่าวันเก่า ความเร็วในการลืมอดีตวัดด้วย half-life คือจำนวนวันที่น้ำหนักของข้อมูลหดเหลือครึ่งหนึ่ง

เส้นทางที่ 1 — จากผลตอบแทนดิบถึง covariance ของ factor

เส้นทางนี้ตอบสองคำถามแรก คือ factor return ของแต่ละวันมาจากไหน และ covariance ของ factor ที่วัดได้เชื่อได้แค่ไหน

ทุกคืนทีมแก้ regression หนึ่งครั้ง ข้อมูลคือหุ้นทุกตัวในวันนั้น จึงเรียกว่า cross-sectional regression (regression ข้ามหุ้น) หุ้นแต่ละตัวได้น้ำหนัก $1/\sigma_i^2$ โดย $\sigma_i$ คือความผันผวนเฉพาะตัวของหุ้นตัวที่ $i$ เหตุผลคือหุ้นที่แกว่งน้อยมีเสียงรบกวนน้อย จึงบอกเรื่อง factor ได้ชัดกว่า

ปัญหาแรกอยู่ที่ loading หุ้นทุกตัวมี loading ของ market เป็น 1 และอยู่ใน industry เดียวพอดี คอลัมน์ market จึงเท่ากับผลบวกของคอลัมน์ industry ทั้งสาม matrix ของ loading จึงขาด rank ไปหนึ่ง ข้อมูลบอกได้แค่ผลรวม market + industry ของแต่ละกลุ่ม แต่แยกสองส่วนนี้ออกจากกันไม่ได้ ทีมจึงต้องเลือกเงื่อนไขเองอย่างรู้ตัว เงื่อนไขที่บทนี้ใช้คือ factor return ของ industry ทั้งสาม เมื่อเฉลี่ยแบบถ่วงด้วยมูลค่าตลาด ต้องได้ศูนย์ ผลที่ได้คือ factor return วันละหนึ่งชุด

คำตอบของ regression เขียนได้เป็น $\hat{\mathbf f}=\mathbf H\mathbf r$ แต่ละแถวของ matrix $\mathbf H$ คือน้ำหนักหุ้นของพอร์ตเลียนแบบ factor หนึ่งตัว factor return จึงเป็นผลตอบแทนของพอร์ตนั้นพอดี

ปัญหาที่สองอยู่ตอนทำ covariance หนึ่งปีมี 252 วันทำการ และผลตอบแทนหนึ่งค่าใช้ราคาสองวันติดกัน จึงได้ factor return $252-1=251$ ชุดต่อปี การเอา 251 ชุดนี้มาคิด covariance ตรง ๆ ผิดสี่ทาง หัวข้อ ประมาณ factor covariance matrix แก้ทีละทาง

  • ตัวเลขแต่ละวันเป็นผลตอบแทนของพอร์ตเลียนแบบ factor ซึ่งพกเสียงของหุ้นที่ถืออยู่มาด้วย variance ที่วัดได้จึงสูงเกินจริงเสมอ เรียกส่วนเกินนี้ว่า $\mathbf G$ และต้องหักออก
  • เมื่อจำนวน factor มากเมื่อเทียบกับจำนวนวัน eigenvalue ของ matrix ที่วัดได้กระจายห่างกันเกินจริง ต้องดึงเข้าหากัน เรียกว่า shrinkage
  • ความผันผวนกับ correlation ต้องการข้อมูลยาวไม่เท่ากัน จึงใช้ half-life คนละค่า
  • ผลตอบแทนของวันติดกันเกี่ยวกันเล็กน้อย การแปลงความผันผวนรายวันเป็นรายปีจึงต้องเติมพจน์ lag ของ Newey–West
  1. 27.1Cross-Sectional Regression and Rank-Deficient Loadingsสมการของวันนี้มีคำตอบที่ดีเท่ากันนับไม่ถ้วน ไลบรารีแอบเลือกให้หนึ่งคำตอบ (market −0.0324%) โดยไม่เตือน ทุกคำตอบให้ momentum 0.4741% เท่ากัน แต่ถ้าแก้ด้วยการลบคอลัมน์ energy ทิ้ง “market” จะกลายเป็นพอร์ตที่ลงเงินเกือบทั้งหมดในหุ้นพลังงาน หน้านี้คำนวณทุกตัวเลขให้ดู
  2. 27.2Estimating the Factor Covariance Matrixความผันผวนของ momentum ที่วัดได้คือ 0.3693% ต่อวัน แต่ค่าจริงคือ 0.35% เพราะ variance ที่วัดได้สูงเกินจริง 11.35% เสมอ และเมื่อมี 40 factor แต่มีข้อมูลแค่ 126 วัน (ครึ่งปี) พอร์ตที่แบบจำลองบอกว่าปลอดภัยที่สุดกลับเสี่ยงจริง 2.29 เท่าของที่เห็น หน้านี้คำนวณทุกตัวเลขให้ดู

จุดตรวจ: การแยก market ออกจาก industry ทำได้หลายทาง ทำไมทุกทางให้ momentum เท่ากัน แต่ให้ market ไม่เท่ากัน และทำไมส่วนเกิน $G$ ของ momentum จึงไม่ขึ้นกับว่าเลือกทางไหน

เฉลย

เรียง factor return เป็นห้าช่อง: market, tech, banks, energy, momentum ทุกทางแก้ต่างกันแค่การบวก $s\mathbf v$ เข้าไป โดย $\mathbf v=(1,-1,-1,-1,0)$ และ $s$ คือตัวเลขที่แต่ละทางเลือก การบวกนี้ไม่เปลี่ยนคำทำนายของหุ้นตัวไหนเลย เพราะหุ้นทุกตัวได้ market เพิ่ม $s$ และ industry ของมันลด $s$ พอดี แต่ละแถวของ $\mathbf B\mathbf v$ จึงเป็น $1\times1+1\times(-1)=0$

\[\begin{aligned}\mathbf B(\hat{\mathbf f}+s\mathbf v)&=\mathbf B\hat{\mathbf f}+s\,\mathbf B\mathbf v\\&=\mathbf B\hat{\mathbf f}.\end{aligned}\]

ช่อง momentum ของ $\mathbf v$ เป็น 0 momentum จึงไม่ขยับ ส่วนช่อง market เป็น 1 market จึงขยับตาม $s$ ที่แต่ละทางเลือก

แถว momentum ของ $\mathbf H$ (น้ำหนักหุ้นในพอร์ตเลียนแบบ momentum) ก็เหมือนกันทุกทางด้วยเหตุผลเดียวกัน ส่วนเกินของ momentum คิดจากแถวนี้แถวเดียว หุ้นตัวที่ $i$ มีน้ำหนัก $h_i$ และความผันผวนเฉพาะตัว $\sigma_i$ จึงใส่เสียงลงในพอร์ตเป็น variance $h_i^2\sigma_i^2$ รวมทุกตัวในจักรวาลแปดตัวได้

\[G_{\rm mom}=\sum_i h_i^2\sigma_i^2=1.0430\ (\%^2)\]

ตัวเลขนี้จึงเท่ากันทุกทาง หน้า ประมาณ factor covariance matrix คิดผลรวมนี้ให้ดูทีละหุ้น

เส้นทางที่ 2 — ความเร็ว: ตามพายุให้ทัน

เส้นทางนี้ตอบคำถามที่สาม: เมื่อตลาดปั่นป่วนขึ้นทันที ตัวเลขความเสี่ยงตามทันเร็วแค่ไหน

แบบจำลองจากเส้นทางแรกอัปเดตความผันผวนของ factor แต่ละตัวด้วย EWMA ที่ half-life 63 วัน (ราวหนึ่งไตรมาส) เรียกส่วนนี้ว่าชั้นล่าง ชั้นล่างนิ่ง แต่ตามการกระโดดของตลาดช้า ถ้าลด half-life ของ factor แต่ละตัวให้สั้นลง ตัวเลขจะเร็วขึ้น แต่จะแกว่งไปมา เพราะ factor แต่ละตัวมีข้อมูลใหม่แค่วันละหนึ่งชิ้น

ทางออกคือดู factor ทั้ง 40 ตัวพร้อมกันในวันเดียว ก่อนอื่นต้องทำให้ทุกตัวเทียบกันได้: หาร factor return ของแต่ละตัวด้วยความผันผวนของมัน และถอด correlation ระหว่างกันออก แล้ววัดขนาดรวมของทั้ง 40 ตัว ตัวเลขนี้บอกว่าวันนั้นปั่นป่วนแค่ไหน ความผันผวนที่ประมาณจากข้อมูล $k$ ชิ้นคลาดราว $1/\sqrt{2k}$ ของค่าจริง (variance คลาด $\sqrt{2/k}$ และความผันผวนเป็นรากที่สองของ variance จึงคลาดครึ่งหนึ่งของนั้น) ข้อมูล 40 ชิ้นในวันเดียวจึงคลาดแค่ $1/\sqrt{2\times40}=1/\sqrt{80}=11.2\%$

ระบบเอาตัวเลขรายวันนี้ไปเฉลี่ยแบบ EWMA ที่ half-life 15 วัน ได้ตัวคูณ $M$ หนึ่งตัวที่คูณความผันผวนของทุก factor พร้อมกัน เช่น $M=1.8$ แปลว่าทุก factor แกว่งแรงกว่าที่ชั้นล่างคิด 1.8 เท่า ตัวคูณนี้คือ Kalman filter อีกชั้นหนึ่งที่วางบนชั้นล่างเดิม มันทั้งเร็วกว่าและคลาดน้อยกว่าชั้นล่าง เพราะในหนึ่งวันมันเห็นข้อมูลมากกว่าชั้นล่าง 40 เท่า

  1. 27.3Short-Term Volatility Updatingถ้าความผันผวนจริงของทุก factor กระโดดเป็น 2.5 เท่าและอยู่อย่างนั้น EWMA ที่ half-life 63 วันพาตัวเลขที่รายงานมาถึงครึ่งทาง (1.75 เท่า) ในวันที่ 46 ไม่ใช่วันที่ 63 ตัวคูณที่ดู 40 factor พร้อมกันพาไปถึงในวันที่ 10 ส่วนขาลง 80 วันหลังพายุจบ ชั้นล่างอย่างเดียวยังบังคับพอร์ตให้เล็กกว่าที่ควร 37.9% หน้านี้คำนวณทุกตัวเลขให้ดู

จุดตรวจ: ในพายุ 2.5 เท่าข้างบน ทำไมความผันผวนที่รายงานมาถึงครึ่งทางในวันที่ 46 ก่อน half-life 63 วัน และทำไมตัวคูณที่ half-life 15 วัน ซึ่งลืมอดีตเร็วกว่า จึงคลาดน้อยกว่า EWMA ของ factor แต่ละตัวที่ half-life 63 วัน

เฉลย

half-life บอกว่าเมื่อไร variance มาถึงครึ่งทาง ไม่ใช่ความผันผวน variance เริ่มที่ $1^2=1$ และไปจบที่ $2.5^2=6.25$ แต่ความผันผวนถึงครึ่งทาง $(1+2.5)/2=1.75$ เมื่อ variance เป็นแค่ $1.75^2=3.0625$ ซึ่งยังไม่ถึงครึ่งทางของ variance

\[\tfrac{1+6.25}{2}=3.625\gt3.0625.\]

ความผันผวนจึงถึงครึ่งทางก่อน เพราะรากที่สองโค้งขึ้นเร็วตอนต้น

ส่วนความคลาด ให้นับว่าค่าเฉลี่ยแต่ละแบบเห็นข้อมูลกี่ชิ้น half-life $h$ วันแปลว่าน้ำหนักหดเหลือครึ่งใน $h$ วัน คือ $\lambda^h=0.5$ จึงได้ $\lambda=0.5^{1/h}$ EWMA ที่ลืมด้วยอัตรา $\lambda$ ต่อวันมีข้อมูลเทียบเท่า $N_{\rm eff}=(1+\lambda)/(1-\lambda)$ ชิ้น (effective sample size)

\[\begin{aligned}\lambda_{15}&=0.5^{1/15}=0.95484,\\N_{15}&=\tfrac{1.95484}{0.04516}=43.29,\\\lambda_{63}&=0.5^{1/63}=0.98906,\\N_{63}&=\tfrac{1.98906}{0.01094}=181.8.\end{aligned}\]

ตัวคูณเห็น 40 factor ทุกวัน ข้อมูลจึงคูณ 40 ส่วนชั้นล่างเห็น factor ละ 181.8 ชิ้น ใช้ความคลาด $1/\sqrt{2k}$ จากข้างบนกับทั้งสองแบบ

\[\begin{aligned}40\times43.2886&=1{,}731.5,\\\tfrac{1}{\sqrt{2\times1{,}731.5}}&=1.70\%,\\\tfrac{1}{\sqrt{2\times181.8}}&=5.24\%.\end{aligned}\]

ตัวคูณคลาด 1.70% ขณะที่ชั้นล่างคลาด 5.24% ความแม่นของตัวคูณจึงมาจากการรวม 40 factor ไม่ได้มาจาก half-life

เส้นทางที่ 3 — ส่วนเฉพาะตัวและข้อมูลสกปรก

เส้นทางนี้ตอบสองคำถามสุดท้าย คือคู่หุ้นไหนที่แบบจำลองรายงานความเสี่ยงผิด และค่าประหลาดในข้อมูลควรทำอย่างไร

ส่วนเฉพาะตัวของหุ้นก็ต้องมี covariance matrix ของมันเอง ในพอร์ตที่ถือหุ้นกระจายดี ส่วนนี้คือก้อนความเสี่ยงที่ใหญ่กว่าฝั่ง factor แบบจำลองถือว่า matrix นี้เป็นแนวทแยง คือมีแค่ variance ของหุ้นแต่ละตัว และ covariance ของหุ้นสองตัวใด ๆ เป็นศูนย์ ข้อนี้ถูกกับเกือบทุกคู่ แต่ผิดแรงกับคู่ไม่กี่คู่ เช่นหุ้นสองชั้นของบริษัทเดียวกัน (บริษัทออกหุ้นสองแบบที่ซื้อขายแยกกัน) หรือหุ้นไม่กี่ตัวในธีมแคบ ๆ อย่างเหมืองทอง สิ่งที่หุ้นสองสามตัวมีร่วมกันกระทบหุ้นน้อยตัวเกินกว่าจะเป็น factor มันจึงตกไปอยู่ในส่วนเฉพาะตัว

งานคือหาคู่เหล่านี้ด้วยเกณฑ์ correlation ที่สูงพอจนเสียงรบกวนล้วน ๆ ข้ามไม่ได้ แล้วตรวจ eigenvalue ว่า matrix ที่ได้ยังใช้ได้

สุดท้ายคือข้อมูลที่ป้อนเข้าทุกขั้น ค่าประหลาดมาจากสองแหล่ง แหล่งแรกคือข้อมูลผิด เช่นผู้ให้ข้อมูลลืมปรับการรวมหุ้น ต้องแก้ที่ต้นทาง แหล่งที่สองคือข่าวจริง เช่นกำไรต่ำกว่าคาด ต้องเก็บไว้ตามจริง เพราะพอร์ตที่ถือหุ้นนั้นเจ็บจริง winsorization คือการดึงค่าที่เกินเกณฑ์กลับมาที่เกณฑ์ มันจึงเป็นได้แค่ตาข่ายชั้นสุดท้าย

  1. 27.4The Idiosyncratic Covariance Matrix and Off-Diagonal Clusteringหุ้นสองชั้นของบริษัทเดียวกัน โต๊ะหนึ่งซื้อ (long) ทั้งคู่ข้างละ \$1 ล้าน อีกโต๊ะซื้อตัวหนึ่งและขายชอร์ต (short) อีกตัวเพื่อเก็บส่วนต่างราคา แบบจำลองแนวทแยงบอกว่าสองพอร์ตเสี่ยงเท่ากันที่ \$25,640 ต่อวัน (SD ของกำไรขาดทุนรายวัน) แต่ความจริงคือ \$33,594 และ \$13,647 และถ้าตั้งเกณฑ์ correlation ต่ำที่ 0.20 จะมีคู่ปลอมจากเสียงรบกวนหลุดเข้ามาเฉลี่ย 275.3 คู่ หน้านี้คำนวณทุกตัวเลขให้ดู
  2. 27.5Winsorization: Which Outliers to Keepราคาผิดตัวเดียวจาก 600 ตัว (ผู้ให้ข้อมูลไม่ปรับการรวมหุ้น จึงรายงานว่าหุ้นขึ้น 340%) ดัน momentum ของวันนั้นคลาด 104.64 bp (1 bp คือ 0.01%) winsorize ที่คะแนนความประหลาด 10 ลดความคลาดเหลือ 7.86 bp แต่ยังผิดทิศ และทำให้ข่าวจริงอีกเรื่องหายไป 29.5% ทางที่ถูกคือปรับการรวมหุ้นที่ต้นทาง หน้านี้คำนวณทุกตัวเลขให้ดู

จุดตรวจ: แบบจำลองแนวทแยงรายงานความเสี่ยงเท่ากันทั้งพอร์ตที่ long หุ้นสองชั้นทั้งคู่ และพอร์ตที่ long ตัวหนึ่ง short อีกตัว ทำไมจึงเป็นแบบนั้น และทำไมการ winsorize ข่าวจริงจึงทำให้ factor return ไม่ใช่ผลตอบแทนของพอร์ตไหนเลย

เฉลย

ให้พอร์ตมีหุ้นสองตัว ใส่เงินในสัดส่วน $w_1$ กับ $w_2$ (ค่าติดลบคือ short) หุ้นมีความผันผวน $\sigma_1$ กับ $\sigma_2$ และ correlation $\rho$ variance ของพอร์ตคือ

\[\begin{aligned}\sigma_P^2&=w_1^2\sigma_1^2+w_2^2\sigma_2^2\\&\quad+2w_1w_2\rho\sigma_1\sigma_2.\end{aligned}\]

ทิศของพอร์ตไปโผล่ในพจน์สุดท้ายพจน์เดียว พอร์ตที่ long ทั้งคู่มี $w_1w_2\gt0$ พจน์นี้จึงบวก ส่วนพอร์ต long กับ short มี $w_1w_2\lt0$ พจน์นี้จึงลบ แบบจำลองแนวทแยงตั้ง $\rho=0$ พจน์นี้จึงหายไปทั้งก้อน สองพอร์ตเหลือตัวเลขเดียวกัน

ส่วนเรื่องที่สอง factor return คือ $\hat{\mathbf f}=\mathbf H\mathbf r$ คือผลตอบแทนของพอร์ตที่ถือหุ้นตามน้ำหนักในแถวของ $\mathbf H$ ในตัวอย่างของหน้า winsorization หุ้นธนาคารตัวหนึ่งลงจริง 18% เพราะกำไรต่ำกว่าคาด ระบบดึงค่านี้ขึ้นมาเป็น −12.62% ตัวเลข momentum ที่รายงานจึงเป็นผลตอบแทนบนราคาที่ไม่เคยเกิด เทียบกับพอร์ต momentum ที่ถือหุ้นนั้นจริง (0.47415% คือ momentum ถ้าวันนั้นหุ้นตัวนี้ปกติ ส่วน 0.05425% กับ 0.03826% คือผลของ −18% กับ −12.62% ต่อ momentum หน้านั้นคำนวณให้ดู)

\[\begin{aligned}f_{\rm port}&=0.47415-0.05425\\&=0.41990\%,\\f_{\rm rep}&=0.47415-0.03826\\&=0.43589\%.\end{aligned}\]

พอร์ตจริงได้ 0.41990% แต่รายงานบอก 0.43589% ไม่มีพอร์ตไหนในโลกได้ตัวเลขที่รายงาน

โจทย์เชื่อมทั้งบท — จักรวาลที่ใหญ่ขึ้นเท่าตัว

ทีมกำลังคิดจะขยายจักรวาลจาก 600 เป็น 1,200 ตัว และอยากรู้ว่าตัวเลขต่าง ๆ ในบทจะเปลี่ยนไปอย่างไร โจทย์ห้าข้อนี้ใช้ทุกชิ้นของบท

โจทย์ให้อะไรมาบ้าง (ตัวเลขทั้งหมดสมมติ)

  • แบบจำลองหุ้นแปดตัวชุดเดิมของบท ใช้เงื่อนไขว่า industry ถ่วงด้วยมูลค่าตลาดรวมเป็นศูนย์ และใช้ความผันผวนเฉพาะตัวชุดเดิม
  • จักรวาลคือหุ้นแปดตัวซ้ำ 75 ชุด (600 ตัว) เหมือนในบท ยกเว้นข้อ 1 และ 2 ที่ซ้ำ 150 ชุด ได้ $8\times150=1{,}200$ ตัว
  • ความผันผวนจริงต่อวัน: momentum $\sigma_{\rm mom}=0.35\%$ และ market $\sigma_{\rm mkt}=1.0\%$
  • ส่วนเกินของจักรวาลแปดตัว คือ variance ของเสียงที่พอร์ตเลียนแบบ factor พกมา หน่วย %²: $G_{\rm mom}=1.0430$ และ $G_{\rm mkt}=0.5274$
  • ชั้นล่าง (EWMA ของ factor แต่ละตัว) ใช้ half-life 63 วัน และตัวคูณใช้ half-life 15 วัน

1. ในจักรวาล 1,200 ตัว variance ของ momentum ที่วัดได้สูงเกินจริงกี่เปอร์เซ็นต์ และความผันผวนที่วัดได้คือเท่าไร?

ดูเฉลยข้อ 1

เมื่อหุ้นแต่ละแบบมี 150 ตัว แต่ละตัวถือน้ำหนักแค่ $h_i/150$ จึงใส่เสียง $(h_i/150)^2\sigma_i^2$ และมีหุ้นแบบนี้ 150 ตัว ผลรวมจึงเท่ากับ $h_i^2\sigma_i^2/150$ ส่วนเกินทั้งก้อนหารด้วย 150

\[\begin{aligned}G&=\tfrac{1.0430}{150}=0.006953,\\\tfrac{\hat\sigma^2}{\sigma^2}&=1+\tfrac{0.006953}{0.35^2}\\&=1+\tfrac{0.006953}{0.1225}=1.0568,\\\hat\sigma&=\sqrt{0.1225+0.006953}\\&=0.3598\%.\end{aligned}\]

variance สูงเกินจริง 5.68% ซึ่งเป็นครึ่งหนึ่งของ 11.35% ในจักรวาล 600 ตัว เพราะหุ้นมากขึ้นสองเท่า $G$ จึงเหลือครึ่ง ความผันผวนที่วัดได้คือ 0.3598% แทนค่าจริง 0.35%

2. ในจักรวาลเดียวกัน market ที่ผันผวนจริง 1.0% ต่อวันจะวัดได้เท่าไร?

ดูเฉลยข้อ 2

ทำแบบเดียวกับข้อ 1 ส่วนเกินของ market ก็หารด้วย 150 แล้วบวกเข้ากับ variance จริง $1.0^2$

\[\begin{aligned}G&=\tfrac{0.5274}{150}=0.003516,\\\hat\sigma&=\sqrt{1.0^2+0.003516}\\&=1.0018\%.\end{aligned}\]

สูงไปแค่ 0.18% เพราะ variance จริงของ market คือ $1.0^2=1$ ใหญ่กว่าของ momentum ($0.1225$) ราว $1/0.1225=8.2$ เท่า ส่วนเกิน 0.003516 จึงเป็นแค่เศษเล็ก ๆ ของ variance ของ market factor ใหญ่แทบไม่เป็นไร factor เล็กเจ็บหนัก เหมือนในบท

3. พายุทำให้ความผันผวนจริงของทุก factor เป็นสองเท่าและอยู่อย่างนั้น ถ้าใช้ชั้นล่างอย่างเดียว ตัวเลขที่รายงานถึงครึ่งทาง (1.5 เท่า) ในวันที่เท่าไร และถ้าใช้สองชั้นถึงในวันที่เท่าไร?

ดูเฉลยข้อ 3

ชั้นล่างเฉลี่ย variance แบบ EWMA เริ่มจาก variance 1 แล้ววิ่งเข้าหา variance ใหม่ $2^2=4$ ระยะทางทั้งหมดคือ $4-1=3$ ทุกวันระยะที่ยังเหลือหดลงเป็น $\lambda$ เท่า หลัง $k$ วันจึงเหลือ $3\lambda^k$ ความผันผวนถึงครึ่งทาง $(1+2)/2=1.5$ เมื่อ variance เป็น $1.5^2=2.25$

\[\begin{aligned}v_k&=4-3\lambda^k,\\4-3\lambda^k&=2.25,\\\lambda^k&=\tfrac{4-2.25}{3}=0.5833.\end{aligned}\]

half-life 63 วันแปลว่า $\lambda^{63}=0.5$ จึงเขียน $\lambda^k=0.5^{k/63}$ แล้วแก้หา $k$

\[\begin{aligned}k&=63\log_2\tfrac{1}{0.5833}\\&=63\times0.7776=48.99.\end{aligned}\]

ชั้นล่างอย่างเดียวถึงครึ่งทางในวันที่ 49

สองชั้นไม่มีสูตรปิด ต้องเดินทีละวัน ให้ $\lambda=0.98906$ (half-life 63 วัน) และ $\lambda_0=0.95484$ (half-life 15 วัน) ตามที่หาไว้ในจุดตรวจข้างบน ทุกวันชั้นล่างอัปเดต variance $v$ ส่วนตัวคูณ $M$ อัปเดตด้วยขนาดที่เห็นในวันนั้น ซึ่งเมื่อไม่มีเสียงรบกวนคือความผันผวนจริงหารด้วยความผันผวนของชั้นล่าง $2/\sqrt{v}$ ตัวเลขที่รายงานคือ $R_d=\sqrt{v_d}\,M_d$

\[\begin{aligned}v_d&=\lambda v_{d-1}+(1-\lambda)\times4,\\M_d&=\lambda_0M_{d-1}\\&\quad+(1-\lambda_0)\tfrac{2}{\sqrt{v_{d-1}}}.\end{aligned}\]

วันแรกคิดด้วยมือ เริ่มจาก $v_0=1$ และ $M_0=1$

\[\begin{aligned}v_1&=0.98906+0.01094\times4\\&=1.03282,\\M_1&=0.95484+0.04516\times2\\&=1.04516,\\R_1&=\sqrt{1.03282}\times1.04516\\&=1.0622.\end{aligned}\]

เดินต่อแบบเดียวกัน (Node หรือสเปรดชีตก็ได้) ได้ $R_9=1.4712$ และ $R_{10}=1.5123$ สองชั้นจึงถึง 1.5 ในวันที่ 10 จากนั้นเลยเป้าไปสูงสุด 2.16 เท่าในวันที่ 63 ก่อนค่อย ๆ ลงมาหา 2 เพราะตัวคูณยังจำวันต้นพายุที่ชั้นล่างยังต่ำอยู่

4. บริษัทหนึ่งมีหุ้นสองชั้น A กับ B ความผันผวนเฉพาะตัว 2.0% ต่อวันทั้งคู่ และ correlation ของส่วนเฉพาะตัว 0.75 โต๊ะหนึ่ง long A \$2 ล้าน และ short B \$2 ล้าน เพื่อเก็บส่วนต่างราคา แบบจำลองแนวทแยงรายงานความเสี่ยงต่อวันเท่าไร และความจริงคือเท่าไร?

ดูเฉลยข้อ 4

ใช้สูตร variance ของพอร์ตสองหุ้นจากจุดตรวจข้างบน คิดเป็นเปอร์เซ็นต์ของเงินข้างละ \$2 ล้าน โดย $w_1=1$, $w_2=-1$ และ $\sigma_1=\sigma_2=2.0\%$ แบบจำลองแนวทแยงใช้ $\rho=0$ ส่วนความจริงใช้ $\rho=0.75$

\[\begin{aligned}\sigma_{\rm diag}&=2.0\%\times\sqrt{1+1}\\&=2.8284\%,\\\sigma_{\rm true}&=2.0\%\times\sqrt{2-2(0.75)}\\&=1.4142\%.\end{aligned}\]

คูณกับเงิน \$2 ล้านเพื่อเป็นดอลลาร์ต่อวัน

\[\begin{aligned}0.028284\times\$2{,}000{,}000&=\$56{,}569,\\0.014142\times\$2{,}000{,}000&=\$28{,}284.\end{aligned}\]

แบบจำลองรายงานสูงไป $56{,}569/28{,}284=2.00$ เท่าพอดี ใต้เพดานความเสี่ยงเดิม โต๊ะจึงทำการเทรดนี้ได้แค่ครึ่งขนาดที่ทำได้จริง

5. เช้านี้ผู้ให้ข้อมูลรายงานผลตอบแทนของหุ้นธนาคารตัวที่ 4 ชุดหนึ่งผิดเป็น −60% ทั้งที่จริงหุ้นได้ −0.60% ตามปกติ ของที่รู้เกี่ยวกับหุ้นตัวนี้

  • momentum loading −1.4
  • น้ำหนักในพอร์ตเลียนแบบ momentum ของจักรวาลแปดตัว $h=-0.22295$ (จากแถว momentum ของ $\mathbf H$)
  • ความผันผวนเฉพาะตัว $\sigma=2.6\%$ ต่อวัน
  • คะแนนความประหลาด $d=\lvert\ln(1+r)\rvert/s$ โดย $r$ คือผลตอบแทน และ $s=0.6745\sigma$ คือขนาดของ log return ในวันปกติที่อยู่ตรงกลาง (median) หน้า winsorization อธิบายที่มาของ 0.6745

ค่าผิดนี้ดัน momentum ของวันนั้นไปเท่าไร คะแนนความประหลาดเท่าไร และถ้า winsorize ที่คะแนน 10 ความผิดเหลือเท่าไร?

ดูเฉลยข้อ 5

ในจักรวาล 600 ตัว หุ้นแบบนี้มี 75 ตัว น้ำหนักจึงแบ่งเป็น 75 ส่วน ค่าผิดเปลี่ยนผลตอบแทนไป $\Delta r$ และ momentum ขยับไป $h_{600}\,\Delta r$ (เขียนผลตอบแทนเป็นทศนิยม −60% คือ −0.60 และ 1 bp คือ 0.0001)

\[\begin{aligned}h_{600}&=\tfrac{-0.22295}{75}=-0.002973,\\\Delta r&=-0.60-(-0.006)=-0.594,\\h_{600}\Delta r&=(-0.002973)(-0.594)\\&=+0.001766=+17.66\text{ bp}.\end{aligned}\]

ต่อมาคิดคะแนนความประหลาด

\[\begin{aligned}s&=0.6745\times2.6\%=1.7537\%,\\d&=\tfrac{\lvert\ln(1-0.60)\rvert}{0.017537}\\&=\tfrac{0.9163}{0.017537}=52.25.\end{aligned}\]

คะแนน 52.25 เกินเกณฑ์ 10 มาก ระบบจึงดึงค่าลงมาที่เพดาน คือ log return เท่ากับ $-10s$ แล้วคิดความผิดใหม่

\[\begin{aligned}r_{\rm cap}&=e^{-10(0.017537)}-1\\&=-16.09\%,\\\Delta r&=-0.1609-(-0.006)\\&=-0.1549,\\h_{600}\Delta r&=(-0.002973)(-0.1549)\\&=+4.60\text{ bp}.\end{aligned}\]

ความผิดลดจาก 17.66 bp เหลือ 4.60 bp คือลดไป $1-4.60/17.66=73.9\%$ ส่วนที่เหลือต้องแก้ที่ต้นทาง ด้วยการแก้ค่ากลับเป็น −0.60%

สิ่งที่ควรพกออกจากบทนี้

  • factor return ทุกตัวคือผลตอบแทนของพอร์ตที่ซื้อได้จริง เขียนเป็น $\hat{\mathbf f}=\mathbf H\mathbf r$ เมื่อ loading ขาด rank ทีมต้องเลือกเงื่อนไขเอง การเลือกนี้เปลี่ยนความหมายของ market แต่ไม่เปลี่ยน momentum ไม่เปลี่ยนคำทำนาย และไม่เปลี่ยนความเสี่ยง
  • variance ที่วัดจาก factor return สูงเกินจริงเท่ากับ $\mathbf G$ เสมอ เพราะพอร์ตเลียนแบบ factor พกเสียงของหุ้นที่ถืออยู่มาด้วย factor ที่ผันผวนน้อยเจ็บหนักที่สุด และเมื่อจำนวน factor มากเมื่อเทียบกับจำนวนวัน eigenvalue จะกระจายห่างเกินจริง จึงต้องใช้ shrinkage
  • ความผันผวนกับ correlation ต้องการข้อมูลยาวไม่เท่ากัน จึงใช้ half-life คนละค่า ตัวคูณที่ดูทุก factor ในวันเดียวพร้อมกันทำให้ตามพายุทันโดยตัวเลขไม่แกว่ง เพราะมันเห็นข้อมูลวันละ 40 ชิ้น
  • ส่วนเฉพาะตัวไม่เกี่ยวกันเกือบทุกคู่ คู่ที่เกี่ยวกันจริงหาได้ด้วยเกณฑ์ correlation ที่เสียงรบกวนข้ามไม่ได้ และหลังตัด correlation เล็ก ๆ ทิ้ง ต้องตรวจ eigenvalue ทุกครั้งว่า matrix ยังใช้ได้
  • ราคาผิดต้องแก้ที่ต้นทาง ข่าวจริงห้ามแตะ winsorization เป็นแค่ตาข่ายชั้นสุดท้าย และทุกครั้งที่มันทำงานต้องบันทึกไว้ให้คนอ่าน

บทนี้เป็นบทสุดท้ายของหนังสือ ถ้าอยากย้อนดูว่าแต่ละชิ้นในบทนี้มาจากไหน ตั้งแต่ความน่าจะเป็นในส่วนแรกจนถึง factor model ในส่วนสุดท้าย กลับไปที่สารบัญได้
