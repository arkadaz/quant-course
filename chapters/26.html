Linear Models of Returns · 6 หัวข้อ

ทั้งบทใช้สมการเดียว $\mathbf r=\boldsymbol\alpha+\mathbf B\mathbf f+\boldsymbol\epsilon$ สมการนี้บอกว่าผลตอบแทนของหุ้นแต่ละตัวมีสามส่วน ส่วนที่คาดว่าจะได้เกินปกติ ($\boldsymbol\alpha$) ส่วนที่แรงร่วมไม่กี่ตัวลากหุ้นไปพร้อมกัน ($\mathbf B\mathbf f$) และส่วนที่มาจากข่าวของหุ้นตัวนั้นเอง ($\boldsymbol\epsilon$) โต๊ะเทรดหุ้น (ทีมที่ซื้อขายหุ้นด้วยเงินของกองทุน) ใช้สมการนี้ตอบสามคำถาม พอร์ตกำลังเดิมพันกับอะไรอยู่จริง ถ้าต้องลดความเสี่ยงควรลดตรงไหน และกำไรขาดทุนที่เกิดขึ้นมาจากไหน

คำถามหลักของบท

ผู้จัดการกองทุนคนหนึ่งเลือกหุ้นเอง เขาซื้อหุ้นที่คิดว่าราคาจะขึ้น และ short หุ้นที่คิดว่าราคาจะลง (short คือยืมหุ้นมาขายก่อน แล้วซื้อคืนทีหลัง จึงได้กำไรเมื่อราคาลง) พอร์ตที่มีทั้งสองฝั่งแบบนี้เรียกว่าพอร์ต long–short ตัวอย่างหลักของบทคือพอร์ตหุ้นสี่ตัวของเขา (ตัวเลขสมมติ) ตัวเลขติดลบคือฝั่ง short

  • หุ้น A ซื้อ \$3 ล้าน
  • หุ้น B short \$2 ล้าน เขียนเป็น −\$2 ล้าน
  • หุ้น C ซื้อ \$4 ล้าน
  • หุ้น D short \$5 ล้าน เขียนเป็น −\$5 ล้าน

ฝั่งซื้อรวม $3+4=\$7$ ล้าน ฝั่ง short รวม $2+5=\$7$ ล้าน เท่ากันพอดี ผู้จัดการจึงเชื่อว่าพอร์ตไม่ขึ้นลงตามตลาด วันนี้หุ้นทั้งตลาดขึ้น 0.80% แต่พอร์ตขาดทุน \$13,000 (หน้าสมการ factor modelคำนวณตัวเลขนี้ให้ดูทีละขั้น) ผู้จัดการจึงโทษว่าตัวเองเลือกหุ้นพลาด

เหตุการณ์เดียวนี้ทำให้โต๊ะต้องตอบคำถามหลายข้อ

  • ขาดทุนวันนี้มาจากการเลือกหุ้น หรือจากเดิมพันที่ไม่ได้ตั้งใจ
  • พอร์ตนี้เสี่ยงวันละกี่ดอลลาร์
  • นักวิจัยเสนอสัญญาณ (กฎที่ทายว่าหุ้นตัวไหนจะดีกว่าปกติ) มาตัวหนึ่ง สัญญาณนั้นมีส่วนไหนเป็นฝีมือจริง
  • รายงานสองฉบับที่มาจาก model เดียวกัน ทำไมจึงโทษ factor คนละตัว
  • ถ้าต้องลดความเสี่ยง ควรลดกลุ่มไหน
  • ถ้านักวิจัยคิดคะแนนใหม่ให้หุ้นทุกตัว จะเพิ่มคะแนนนั้นเข้า model อย่างไรโดยไม่ทำให้ตัวเลขเก่าผิด
  • สิ้นปี กำไรมาจากฝีมือหรือจากโชค

บทนี้ตอบทุกข้อด้วยเครื่องมือเดียวกันคือ factor model ซึ่งมองว่าหุ้นทุกตัวขยับตามแรงร่วมไม่กี่ตัว บวกกับข่าวของตัวเอง แรงร่วมแต่ละตัวเรียกว่า factor เช่นตลาดทั้งตลาด กลุ่มอุตสาหกรรม หรือ momentum (แรงที่ทำให้หุ้นที่ราคาวิ่งแรงมาทั้งปียังวิ่งต่อ)

เส้นเรื่องที่ร้อยทั้งบทคือ “เงินสองฝั่งที่เท่ากัน ไม่ได้แปลว่าไม่มีเดิมพัน” หน้าสมการ factor model จะคำนวณให้ดูว่า พอร์ตนี้ไม่ได้เดิมพันกับตลาดเลยก็จริง แต่แอบเดิมพันกับ momentum เป็นเงิน \$13.8 ล้าน ตัวเลขนี้เรียกว่า exposure ต่อ momentum เทียบกับเงินทั้งพอร์ต $7+7=\$14$ ล้าน ได้ $13.8/14=98.6\%$ เงินเกือบทั้งพอร์ตจึงเป็นเดิมพันเดียว

วันนี้ momentum ลง 0.50% หุ้นกลุ่ม tech ให้คืนมา \$3,000 และการเลือกหุ้นทำเงินได้ \$53,000 (หน้าเดียวกันคำนวณสองตัวเลขนี้) บัญชีของวันนี้จึงเป็นแบบนี้

\[\begin{aligned}\text{momentum}&=13{,}800{,}000\times(-0.0050)\\&=-\$69{,}000,\\\text{factor}&=-69{,}000+3{,}000=-\$66{,}000,\\\text{total}&=-66{,}000+53{,}000=-\$13{,}000.\end{aligned}\]

การเลือกหุ้นไม่ได้พลาด เดิมพัน momentum ที่ไม่ได้ตั้งใจต่างหากที่ทำให้ขาดทุน ทุกหน้าในบทจึงทำสองอย่าง อย่างแรก แยกผลตอบแทน ความเสี่ยง และกำไรขาดทุนตามต้นเหตุจริง อย่างที่สอง ถามว่าผลของการแยกนั้นขึ้นกับวิธีที่เราเลือกแค่ไหน

ก่อนเริ่ม: บทนี้ใช้ของจากหน้าเหล่านี้ ถ้ายังไม่คุ้น ควรกลับไปอ่านก่อน

  • ผลคูณจุด มุม และ Cauchy–Schwarz กับnorm เพราะทั้งบทมองพอร์ตและผลตอบแทนเป็น vector แล้ววัดความยาวและมุมระหว่างกัน
  • การคูณ matrix และrange กับ rank ซึ่งบอกว่าส่วนที่ factor อธิบายได้ถูกขังอยู่ในกี่มิติ
  • eigenvalue และ Cholesky ใช้แปลง factor ให้ไม่สัมพันธ์กัน
  • ความเสี่ยงของพอร์ต $\mathbf w^{\mathsf T}\boldsymbol\Sigma\mathbf w$ คือ variance ของกำไรขาดทุน เมื่อ $\mathbf w$ คือเงินที่ถือในหุ้นแต่ละตัว และ $\boldsymbol\Sigma$ คือ covariance matrix ของผลตอบแทน หน้าเดียวกันมีกฎว่า covariance เปลี่ยนอย่างไรเมื่อคูณตัวสุ่มด้วย matrix
  • OLS regression ซึ่งในภาพเรขาคณิตคือการฉายเงา (projection) ใช้ทุกหน้า
  • multi-factor model ที่ให้สูตร covariance ของผลตอบแทน $\mathbf B\boldsymbol\Omega_f\mathbf B^{\mathsf T}+\mathbf D$ มาแล้ว ($\boldsymbol\Omega_f$ คือ covariance ของ factor และ $\mathbf D$ คือ variance เฉพาะตัวของหุ้นแต่ละตัว วางบนแนวทแยง)
  • gradient ใช้หาว่าความเสี่ยงเพิ่มเร็วแค่ไหนเมื่อขยายกลุ่มหนึ่ง
  • ความคลาดของ Sharpe Ratio ใช้แยกฝีมือออกจากโชค (Sharpe Ratio คือผลตอบแทนเฉลี่ยต่อปี หารด้วยความผันผวนต่อปี ยิ่งสูงยิ่งคุ้ม)

เส้นทางที่ 1 — สมการ และสิ่งที่มันแยก

สองหน้าแรกสร้างเครื่องมือหลักของบท หน้าแรกเขียนผลตอบแทนของหุ้นเป็นสามส่วน คือส่วนคงที่ ส่วนที่ factor ลากไป และส่วนเฉพาะตัว ตัวที่ผูกหุ้นกับ factor คือตาราง loading $\mathbf B$ ซึ่งมีแถวละหุ้น คอลัมน์ละ factor ช่องแถว $i$ คอลัมน์ $j$ บอกว่าหุ้น $i$ ขยับตาม factor $j$ แรงแค่ไหน ส่วน $\mathbf f$ คือ factor return คือ % ที่ factor แต่ละตัวขยับในวันนั้น

หน้าแรกอ่านสมการเดียวกันสามแบบ แบบแรกมองทีละหุ้น เป็นภาพเส้นเชื่อมจาก factor ลงไปหาหุ้น แบบที่สองมองทีละ factor เป็นผลรวมของคอลัมน์ของ $\mathbf B$ แบบที่สามมองทั้งพอร์ต คือเอาเงินที่ถือ $\mathbf w$ คูณเข้าไป แล้วพอร์ตจะมีหุ้นกี่พันตัวก็ย่อเหลือ exposure $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$ ซึ่งมีแค่ factor ละหนึ่งตัวเลข exposure ต่อ factor หนึ่งตัวคือขนาดเดิมพันกับ factor นั้น นับเป็นดอลลาร์ แบบที่สามนี้แยกกำไรขาดทุนและความเสี่ยงของพอร์ตออกเป็นก้อนของ factor กับก้อนเฉพาะตัว

หน้าที่สองดู alpha ($\boldsymbol\alpha$ คือผลตอบแทนที่สัญญาณคาดว่าหุ้นแต่ละตัวจะได้เกินกว่าที่ factor ให้) แล้วแยกมันด้วยการฉายเงา (projection) ลงบนคอลัมน์ของ $\mathbf B$ ส่วนที่เป็นผลรวมของคอลัมน์ได้ เรียกว่าอยู่ใน range ของ $\mathbf B$ ส่วนนี้เป็นแค่เดิมพัน factor ที่ใครก็ซื้อได้ในราคาถูก ส่วนที่ตั้งฉากกับทุกคอลัมน์คือเดิมพันเล็ก ๆ หลายร้อยครั้งที่การแกว่งหักล้างกันเอง ส่วนนี้คือฝีมือที่มีค่าจริง ตัวเลขที่ยกมาในรายการข้างล่าง แต่ละหน้าคำนวณให้ดูทีละขั้น

  1. 26.1The Factor Model Equation and Three Ways to Read Itพอร์ตที่เงินสองฝั่งเท่ากันขาดทุน \$13,000 เพราะ factor ทำให้เสีย \$66,000 ทั้งที่การเลือกหุ้นทำเงินได้ \$53,000 ส่วนความเสี่ยงรายวันมีสองก้อน คือจาก factor \$48,063 และเฉพาะตัว \$159,223 สองก้อนนี้ไม่ได้บวกกันตรง ๆ เป็น $48{,}063+159{,}223=\$207{,}286$ แต่ต่อกันเป็นสามเหลี่ยมมุมฉาก ได้ $\sqrt{48{,}063^2+159{,}223^2}=\$166{,}319$
  2. 26.2Alpha Spanned and Alpha Orthogonalสัญญาณที่ทายหุ้น 500 ตัว ตัวละ 2% ต่อปี โดยหุ้นแต่ละตัวมีความผันผวนเฉพาะตัวไม่เกิน 35% ได้ Sharpe Ratio อย่างน้อย $\sqrt{500}\times0.02/0.35=1.278$ ส่วนเดิมพัน momentum ที่คาดว่าได้ 3% ต่อปี และมีความผันผวน 8% ต่อปี ได้แค่ $3/8=0.375$ และถือทั้งสองอย่างให้ดีที่สุดก็ได้แค่ $\sqrt{1.278^2+0.375^2}=1.332$

จุดตรวจ: ลองตอบสองข้อนี้ก่อนไปต่อ

  • NMV (net market value) คือเงินฝั่งซื้อลบเงินฝั่ง short ทำไม exposure ต่อ market ของพอร์ตจึงเท่ากับ NMV พอดี
  • $\boldsymbol\alpha_\perp$ คือส่วนของ alpha ที่ตั้งฉากกับทุกคอลัมน์ของ $\mathbf B$ ถ้าสร้างพอร์ตที่ชี้ไปทางเดียวกับ $\boldsymbol\alpha_\perp$ และยาวหนึ่งหน่วย ทำไมผลตอบแทนคาดหวังของพอร์ตนี้จึงเท่ากับความยาวของ $\boldsymbol\alpha_\perp$ ไม่ใช่ค่าเฉลี่ยของตัวเลขใน $\boldsymbol\alpha_\perp$
เฉลย

ข้อแรก: ตลาดลากหุ้นทุกตัวเท่ากัน คอลัมน์ market ของ $\mathbf B$ จึงเป็น 1 ทุกแถว exposure ต่อ market คือเงินที่ถือคูณ 1 แล้วรวมทุกหุ้น

\[b_{\rm mkt}=\sum_iw_i\times1=\sum_iw_i\]

ฝั่งซื้อเป็นบวก ฝั่ง short เป็นลบ ผลรวมจึงเป็นเงินฝั่งซื้อลบฝั่ง short ซึ่งก็คือ NMV พอร์ตของบทได้ $3-2+4-5=0$ จึงไม่มี exposure ต่อ market เลย

ข้อสอง: พอร์ตคือ $\mathbf w=\boldsymbol\alpha_\perp/\lVert\boldsymbol\alpha_\perp\rVert$ การหาร vector ด้วยความยาวของมันเองทำให้ยาวหนึ่งหน่วย alpha ทั้งก้อนคือส่วน spanned $\mathbf B\boldsymbol\lambda$ บวก $\boldsymbol\alpha_\perp$ ส่วน spanned หายไปเพราะ $\mathbf w$ ตั้งฉากกับทุกคอลัมน์ของ $\mathbf B$

\[\begin{aligned}\mathbf w^{\mathsf T}\boldsymbol\alpha&=\mathbf w^{\mathsf T}\mathbf B\boldsymbol\lambda+\mathbf w^{\mathsf T}\boldsymbol\alpha_\perp\\&=0+\frac{\lVert\boldsymbol\alpha_\perp\rVert^2}{\lVert\boldsymbol\alpha_\perp\rVert}\\&=\lVert\boldsymbol\alpha_\perp\rVert.\end{aligned}\]

ความยาวมาจากผลรวมกำลังสองของทุกช่อง หุ้นยิ่งมาก ผลรวมยิ่งโต ถ้า $\boldsymbol\alpha_\perp$ มี $n$ ช่อง และทุกช่องมีขนาดอย่างน้อย $\mu$ ความยาวจะไม่น้อยกว่า $\sqrt{n\mu^2}=\sqrt n\,\mu$ จึงโตอย่างน้อยตาม $\sqrt n$ ส่วนค่าเฉลี่ยไม่โตตามจำนวนหุ้น

เส้นทางที่ 2 — model เดียวกันหลายหน้าตา และการแบ่งความเสี่ยง

สองหน้าถัดไปถามว่า ตัวเลขที่ model รายงานขึ้นกับวิธีที่เราเขียน model แค่ไหน หน้าแรกแสดงว่า model เดียวกันเขียนได้หลายแบบ ให้ $\mathbf C$ เป็น matrix ขนาดเท่าจำนวน factor ตัวไหนก็ได้ที่มี inverse เพราะ $\mathbf C^{-1}\mathbf C=\mathbf I$ เราแทรกมันเข้าไปกลาง $\mathbf B\mathbf f$ ได้โดยไม่เปลี่ยนค่า

\[\mathbf B\mathbf f=(\mathbf B\mathbf C^{-1})(\mathbf C\mathbf f).\]

ฝั่งขวาอ่านได้เป็น loading ชุดใหม่ $\mathbf B\mathbf C^{-1}$ คูณ factor return ชุดใหม่ $\mathbf C\mathbf f$ ผลตอบแทนหุ้น กำไรขาดทุนรวม และความเสี่ยงรวมจึงไม่ขยับ แต่คำตอบว่า factor ไหนทำเงินเท่าไรขยับตามแบบที่เลือก เหมือนลูกศรเส้นเดียวกันที่วัดพิกัดด้วยแกนคนละชุด การเปลี่ยนแบบนี้เรียกว่า rotation หน้าเดียวกันยังดูอีกสองท่า คือ projection (ตัด factor บางตัวออก แล้วให้ factor ที่เหลือรับส่วนของมันไปเท่าที่รับได้) และ push-out (เพิ่มคะแนนใหม่เข้า model โดยเก็บเฉพาะส่วนที่ factor เดิมยังไม่มี)

หน้าที่สองเลือกแบบหนึ่งแล้วยึดไว้ จากนั้นแบ่งความเสี่ยงของพอร์ตเป็นกลุ่ม แล้ววัดสามอย่าง

  • ส่วนแบ่งของ variance: กลุ่มนี้กินความเสี่ยงไปกี่ % ตัวเลขนี้กลายเป็น beta ของกลุ่มเทียบกับพอร์ต
  • MCR (marginal contribution to risk): ถ้ากลุ่มนี้แกว่งเพิ่ม \$1 ความเสี่ยงรวมของพอร์ตเพิ่มกี่ดอลลาร์ ตัวเลขนี้กลายเป็น correlation ของกลุ่มกับพอร์ต
  • Sharpe sensitivity: ถ้าขยายกลุ่มนี้อีกนิด Sharpe Ratio ทั้งพอร์ตขึ้นหรือลงเท่าไร ตัวเลขนี้บอกว่าควรขยายหรือหดกลุ่มนั้น

ตัวเลขที่ยกมาในรายการข้างล่าง แต่ละหน้าคำนวณให้ดูทีละขั้น

  1. 26.3Rotations, Projections, and Push-Outsรายงานฉบับหนึ่งบอกว่า market ทำให้เสีย \$5,528 ทั้งที่ exposure ต่อ market เป็นศูนย์ อีกฉบับบอกว่า momentum ทำให้เสีย \$69,000 ทั้งสองฉบับถูก เพราะฉบับแรกวัด factor หลังหักส่วนที่ขยับตามตลาดออก แล้วย้ายส่วนนั้นไปไว้ที่ market และคะแนนใหม่ที่นักวิจัยเสนอมา มีของใหม่จริงแค่ 12.5% ที่เหลือซ้ำกับ factor เดิม
  2. 26.4Decomposing Risk: Percentage of Variance, MCR, and Sharpe Sensitivityส่วนเฉพาะตัวแพงที่สุด เพราะถ้ามันแกว่งเพิ่ม \$1 ความเสี่ยงรวมขึ้น \$0.7507 แต่มันทำเงินมากที่สุดจึงควรขยาย กลุ่มที่ควรหดก่อนคือ market เพราะที่จุดวันนี้ ทุก \$100,000 ของความผันผวนรายวันที่ลดจาก market ทำให้ Sharpe Ratio ขึ้นราว 0.486 ถ้า hedge market ออกหมด (ซื้อขายของที่หักล้างส่วน market จนเหลือศูนย์) Sharpe Ratio ขึ้นจาก 1.5515 เป็น 1.7216 ไม่ใช่ $1.5515+0.486\approx2.04$ ที่ได้จากการยืดอัตรานี้เป็นเส้นตรง

จุดตรวจ: ลองตอบสองข้อนี้ก่อนไปต่อ

  • การดึงค่าเฉลี่ยออกจากคอลัมน์ loading คือลบค่าเฉลี่ยของคอลัมน์ออกจากทุกช่อง ให้คอลัมน์เฉลี่ยเป็นศูนย์ เมื่อไรที่การทำแบบนี้ยังเป็น rotation คือยังเป็น model ตัวเดิม
  • MCR บอกว่ากลุ่มไหนแพง ทำไมกลุ่มที่ MCR สูงที่สุด อาจเป็นกลุ่มที่ควรขยาย
เฉลย

ข้อแรก: ให้ $\mathbf e$ คือ vector ที่เป็น 1 ทุกตัว การลบค่าเฉลี่ย $c$ ออกจากคอลัมน์หนึ่ง คือการลบ $c\,\mathbf e$ ออกจากคอลัมน์นั้น ส่วนที่ลบออกต้องมีคอลัมน์อื่นรับไว้ model จึงจะยังเป็นตัวเดิม เงื่อนไขคือ $\mathbf e$ ต้องเขียนเป็นผลรวมถ่วงของคอลัมน์ loading ได้ เช่น model มีคอลัมน์ market ที่เป็น 1 ทุกแถวอยู่แล้ว หรือมีชุดคอลัมน์ industry ที่รวมกันได้ 1 ทุกแถว (หุ้นทุกตัวอยู่ในอุตสาหกรรมเดียวพอดี)

ข้อสอง: MCR บอกแค่ว่าแพง ไม่ได้บอกว่าได้อะไรกลับมา ให้ $\text{SR}_i$ คือ Sharpe Ratio ของกลุ่ม $i$ ให้ $\text{SR}_{\rm tot}$ คือของทั้งพอร์ต และ $m_i$ คือ MCR ของกลุ่ม $i$ กลุ่มควรขยายเมื่อ

\[\frac{\text{SR}_i}{\text{SR}_{\rm tot}}\gt m_i.\]

ในหน้าการแบ่งความเสี่ยง ส่วนเฉพาะตัวมี MCR สูงที่สุดที่ 0.7507 แต่ Sharpe Ratio ของมันเทียบกับพอร์ตคือ $1.6/1.5515=1.031$ ซึ่งสูงกว่า การขยายมันจึงยังคุ้ม

เส้นทางที่ 3 — ประมาณเป็นขั้น และบัญชีว่าเงินมาจากไหน

สองหน้าสุดท้ายพาไปใกล้งานจริง ในงานจริงไม่มีใครบอก factor return ให้ ต้องประมาณจากผลตอบแทนของหุ้นด้วย regression และมักทำเป็นขั้น คือใส่ factor ชุดหนึ่งก่อน แล้วค่อยเพิ่มคอลัมน์ใหม่ทีหลัง หน้าแรกพิสูจน์ทฤษฎีบท Frisch–Waugh–Lovell (FWL) ซึ่งบอกวิธีเพิ่มทีหลังที่ถูก หักส่วนที่ model เดิมอธิบายได้ออกจากทั้งผลตอบแทนและคอลัมน์ใหม่ก่อน แล้วจึง regress ส่วนที่เหลือของสองอย่างนี้บนกัน วิธีนี้ได้คำตอบเดียวกับใส่ทุกคอลัมน์ทีเดียวทุกหลัก

หน้าเดียวกันใช้สูตรนี้ในแบบถ่วงน้ำหนักด้วย แบบนี้เรียกว่า WLS (weighted least squares) คือ regression ที่ให้หุ้นที่แกว่งเฉพาะตัวน้อยมีน้ำหนักมากกว่า WLS ให้ของมาอีกสองอย่าง อย่างแรกคือ matrix $\mathbf H$ ซึ่งแต่ละแถวเป็นพอร์ตที่ขยับตาม factor หนึ่งตัวพอดี เรียกว่า factor-mimicking portfolio อย่างที่สองคือ matrix $\mathbf G$ ซึ่งบอกว่า factor return ที่ประมาณได้คลาดจากค่าจริงได้แค่ไหน

หน้าที่สองประกอบทุกชิ้นเป็นรายงานว่ากำไรมาจากไหน คือจากการเทรดระหว่างวัน (trading) จาก factor หรือจากการเลือกหุ้น และถามว่าตัวเลขแต่ละบรรทัดมีโชคปนอยู่แค่ไหน ตัวเลขที่ยกมาในรายการข้างล่าง แต่ละหน้าคำนวณให้ดูทีละขั้น

  1. 26.5The Frisch–Waugh–Lovell Theoremนักวิจัยอยากรู้ factor return ของคะแนนใหม่ ทางลัดที่ regress ส่วนที่ model เดิมอธิบายไม่ได้บนคะแนนดิบ ได้ 0.5707% แทนค่าที่ถูก 0.7496% เพราะทางลัดหดค่าเข้าหาศูนย์ด้วยตัวคูณ 0.7613 เสมอ: $0.7496\times0.7613=0.5707$ และถ้าประมาณ factor return จากหุ้นแค่สี่ตัว ความคลาดมาตรฐาน (SE) ของค่าประมาณ momentum คือ $\sqrt{1.3144}=1.15\%$ ต่อวัน (1.3144 คือ variance ของความคลาด ซึ่งหน้านั้นคำนวณ) มากกว่าความผันผวนของ momentum เองที่ 0.35%
  2. 26.6Performance Attribution: Factor PnL and Idiosyncratic PnLต้นทุนการเทรดวันละ \$3,000 ลด Sharpe Ratio ไป $3{,}000\sqrt{251}/159{,}844=0.297$ ตามค่าที่ตั้งไว้ในโจทย์ (251 คือจำนวนวันทำการในหนึ่งปี และ \$159,844 คือความผันผวนรายวันของพอร์ตในหน้านั้น) ส่วนในปีที่เกิดขึ้นจริงลดไป 0.287 กลุ่ม style ที่ทำเงินได้ \$0.77 ล้านในหนึ่งปี วัด Sharpe Ratio ได้ 0.74 ± 1.00 ซึ่งแยกจากศูนย์ไม่ออก และถ้าขยาย style เป็นสองเท่า Sharpe Ratio ของพอร์ตกลับลดจาก 1.5515 เป็น 1.5087

จุดตรวจ: ลองตอบสองข้อนี้ก่อนไปต่อ

  • ทางลัดเอา residual ของ model เดิม (ส่วนที่ model เดิมอธิบายไม่ได้) ไป regress บนคะแนนดิบ ทำไมค่าที่ได้จึงหดเข้าหาศูนย์เสมอ ไม่ว่าค่าจริงจะเป็นบวกหรือลบ
  • factor return ที่ประมาณได้คลาดจากค่าจริงเสมอ ทำไมความคลาดนี้จึงไม่เปลี่ยนกำไรรวมในรายงาน แต่เปลี่ยนการแบ่งระหว่างบรรทัด factor กับบรรทัดเฉพาะตัว

ข้อแรก: ให้ $\mathbf x_2$ คือคะแนนดิบ ให้ $\tilde{\mathbf x}_2$ คือคะแนนหลังหักส่วนที่ซ้ำกับ factor เดิมออก และ $\mathbf e$ คือ residual ของ model เดิม ค่าที่ถูกตาม FWL คือ $\hat\beta_2=\tilde{\mathbf x}_2^{\mathsf T}\mathbf e/\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2$ ส่วนทางลัดใช้ $\mathbf x_2$ แทนทั้งตัวตั้งและตัวหาร ตัวตั้งของสองแบบเท่ากัน เพราะ $\mathbf e$ ตั้งฉากกับส่วนที่ซ้ำ แต่ตัวหารไม่เท่า $\mathbf x_2$ คือ $\tilde{\mathbf x}_2$ บวกส่วนที่ซ้ำ ซึ่งตั้งฉากกัน ตาม Pythagoras จึงได้ $\mathbf x_2^{\mathsf T}\mathbf x_2\ge\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2$ ทางลัดจึงได้

\[\hat\beta_{\rm short}=\frac{\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2}{\mathbf x_2^{\mathsf T}\mathbf x_2}\,\hat\beta_2.\]

ตัวคูณข้างหน้าเป็นบวกและไม่เกิน 1 ค่าจึงหดเข้าหาศูนย์โดยเครื่องหมายไม่เปลี่ยน ในหน้า Frisch–Waugh–Lovell ตัวคูณนี้คือ 0.7613

ข้อสอง: WLS ประมาณ factor return ด้วย $\hat{\mathbf f}=\mathbf H\mathbf r$ และ $\mathbf H\mathbf B=\mathbf I$ แทน $\mathbf r=\mathbf B\mathbf f+\boldsymbol\epsilon$ จะได้ $\hat{\mathbf f}=\mathbf f+\mathbf H\boldsymbol\epsilon$ บรรทัด factor ในรายงานคือ $\mathbf b^{\mathsf T}\hat{\mathbf f}$ จึงเกินค่าจริงไป $\mathbf b^{\mathsf T}\mathbf H\boldsymbol\epsilon$ บรรทัดเฉพาะตัวคิดจากกำไรรวมลบบรรทัด factor จึงขาดไป $\mathbf b^{\mathsf T}\mathbf H\boldsymbol\epsilon$ เท่ากันพอดี ผลรวมจึงไม่ขยับ

1. พอร์ตใหม่เดิมพันกับแต่ละ factor เท่าไร (exposure $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$) และกำไรขาดทุนวันนี้แยกเป็นส่วนของ factor กับส่วนเฉพาะตัวเท่าไร (ใช้การอ่านสมการทั้งพอร์ต)?

ดูเฉลยข้อ 1

exposure ต่อ factor หนึ่งตัว คือเงินที่ถือในแต่ละหุ้นคูณ loading ของหุ้นนั้นต่อ factor นั้น แล้วรวมทุกหุ้น

\[\begin{aligned}b_{\rm mkt}&=2-1+1-2=0,\\b_{\rm mom}&=2(1.2)-1(-0.4)\\&\quad+1(0.6)-2(-1.4)\\&=2.4+0.4+0.6+2.8=6.2,\\b_{\rm tech}&=2(1)-1(1)=1.\end{aligned}\]

พอร์ตใหม่ยังไม่มีเดิมพันตลาด แต่ยังเดิมพัน momentum \$6.2 ล้าน เพราะฝั่ง short (B, D) มี loading momentum ติดลบ ลบคูณลบจึงเป็นบวก กำไรขาดทุนแยกเป็นสองก้อน ก้อน factor คือ exposure คูณ factor return ก้อนเฉพาะตัวคือเงินที่ถือคูณส่วนเฉพาะตัวของแต่ละหุ้น

\[\begin{aligned}\mathbf b^{\mathsf T}\mathbf f&=0(0.80)+6.2(-0.50)\\&\quad+1(0.30)\\&=-3.10+0.30=-2.80,\\\mathbf w^{\mathsf T}\boldsymbol\epsilon&=2(0.40)-1(-0.25)\\&\quad+1(0.15)-2(-0.60)\\&=0.80+0.25+0.15+1.20\\&=2.40.\end{aligned}\]

คูณหน่วย \$10,000 ได้ก้อน factor −\$28,000 และก้อนเฉพาะตัว +\$24,000 รวม $-2.80+2.40=-0.40$ คือขาดทุน \$4,000 ตรวจได้อีกทาง หน้าสมการ factor model คำนวณผลตอบแทนรวมของหุ้นวันนี้ไว้แล้วเป็น (0.90, 1.05, 0.65, 0.90)% เอาเงินที่ถือคูณตรง ๆ ได้ $2(0.90)-1(1.05)+1(0.65)-2(0.90)=-0.40$ เท่ากัน เพราะสองทางคือผลบวกชุดเดียวกันที่จัดกลุ่มต่างกัน

2. ความเสี่ยงรายวันของพอร์ตใหม่ (SD ของกำไรขาดทุนรายวัน) มาจาก factor เท่าไร มาจากส่วนเฉพาะตัวเท่าไร และรวมเป็นเท่าไร?

ดูเฉลยข้อ 2

เริ่มจากตัวเลขของ factor ก่อน variance ของ factor แต่ละตัวคือความผันผวนยกกำลังสอง ส่วน covariance ของสอง factor คือ correlation คูณความผันผวนของทั้งสองตัว ช่องของ market ไม่ต้องใช้ เพราะ $b_{\rm mkt}=0$

\[\begin{aligned}\sigma_{\rm mom}^2&=0.35^2=0.1225,\\\sigma_{\rm tech}^2&=0.55^2=0.3025,\\\operatorname{cov}_{\rm mom,tech}&=-0.10(0.35)(0.55)\\&=-0.01925.\end{aligned}\]

variance จาก factor คือ $\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b$ ($\boldsymbol\Omega_f$ คือ covariance matrix ของ factor) เมื่อเหลือสอง factor มันก็คือสูตร variance ของผลบวกสองก้อน variance เฉพาะตัวคือ $\sum_iw_i^2\sigma_i^2$ ไม่มีพจน์ไขว้ เพราะข่าวของหุ้นต่างตัวไม่สัมพันธ์กัน

\[\begin{aligned}v_f^2&=6.2^2(0.1225)+1^2(0.3025)\\&\quad+2(6.2)(1)(-0.01925)\\&=4.7089+0.3025-0.2387\\&=4.7727,\\v_\epsilon^2&=2^2(1.80^2)+1^2(2.20^2)\\&\quad+1^2(1.50^2)+2^2(2.60^2)\\&=12.96+4.84+2.25+27.04\\&=47.09.\end{aligned}\]

ถอดรากได้ $v_f=\sqrt{4.7727}=2.1847$ คือ \$21,847 ต่อวัน และ $v_\epsilon=\sqrt{47.09}=6.8622$ คือ \$68,622 ต่อวัน สองก้อนนี้ไม่สัมพันธ์กัน เพราะ factor ไม่ขยับตามข่าวเฉพาะตัว จึงบวกกันที่ variance ไม่ใช่ที่ SD

\[\begin{aligned}v_{\rm tot}&=\sqrt{4.7727+47.09}\\&=\sqrt{51.8627}=7.2016.\end{aligned}\]

ความเสี่ยงรวมคือ \$72,016 ต่อวัน ไม่ใช่ผลบวกตรง ๆ $21{,}847+68{,}622=\$90{,}469$

3. ทีมวิจัยมีสัญญาณที่ทาย alpha ของหุ้นสี่ตัว (ผลตอบแทนที่แต่ละตัวจะได้เกินกว่าที่ factor ให้) เป็น $\boldsymbol\alpha=(1.0,\ 0.0,\ 0.5,\ -0.5)\%$ ต่อปี ส่วนที่เป็นฝีมือจริงคือ $\boldsymbol\alpha_\perp$ ซึ่งตั้งฉากกับทุกคอลัมน์ของ $\mathbf B$ ส่วนนี้มีค่าเท่าไร และคิดเป็นกี่ % ของความยาวกำลังสองของ $\boldsymbol\alpha$ (ใช้การแยก alpha)? คำใบ้: หุ้นสี่ตัวกับ factor สามตัว เหลือทิศที่ตั้งฉากกับทุกคอลัมน์ได้ทิศเดียว คือ $\mathbf u=(1,\ -1,\ -0.8,\ 0.8)$

ดูเฉลยข้อ 3

ตรวจก่อนว่า $\mathbf u$ ตั้งฉากกับทุกคอลัมน์ของ $\mathbf B$ จริง คือผลคูณจุดกับแต่ละคอลัมน์เป็นศูนย์

\[\begin{aligned}\text{market}&:\ 1-1-0.8+0.8=0,\\\text{momentum}&:\ 1.2+0.4-0.48-1.12=0,\\\text{tech}&:\ 1-1=0.\end{aligned}\]

$\boldsymbol\alpha_\perp$ คือเงาของ $\boldsymbol\alpha$ บนทิศ $\mathbf u$ หาได้จากผลคูณจุด หารด้วยความยาวกำลังสองของ $\mathbf u$ แล้วคูณ $\mathbf u$

\[\begin{aligned}\lVert\mathbf u\rVert^2&=1+1+0.64+0.64=3.28,\\\boldsymbol\alpha^{\mathsf T}\mathbf u&=1.0-0-0.4-0.4=0.2,\\\boldsymbol\alpha_\perp&=\frac{0.2}{3.28}\,\mathbf u=0.0610\,\mathbf u\\&=(0.0610,\ -0.0610,\\&\qquad-0.0488,\ 0.0488).\end{aligned}\]

สองส่วนของ alpha ตั้งฉากกัน ความยาวกำลังสองจึงบวกกันได้ตาม Pythagoras เราจึงเทียบกันด้วยความยาวกำลังสอง

\[\begin{aligned}\lVert\boldsymbol\alpha_\perp\rVert^2&=\frac{0.2^2}{3.28}=0.012195,\\\lVert\boldsymbol\alpha\rVert^2&=1.0^2+0^2+0.5^2+0.5^2\\&=1.5,\\\frac{0.012195}{1.5}&=0.0081=0.81\%.\end{aligned}\]

ฝีมือจริงมีแค่ 0.81% อีก $100-0.81=99.19\%$ เป็นส่วน spanned คือเดิมพัน factor ที่ใครก็ซื้อได้ ส่วน spanned เขียนเป็น $\mathbf B\boldsymbol\lambda$ ได้ โดย $\boldsymbol\lambda$ คือขนาดเดิมพันต่อ factor แต่ละตัว หาได้จาก $\boldsymbol\alpha-\boldsymbol\alpha_\perp=(0.9390,\ 0.0610,\ 0.5488,\ -0.5488)$ เริ่มจากแถวของ C กับ D ก่อน เพราะสองแถวนี้ไม่มี tech

\[\begin{aligned}\lambda_1+0.6\lambda_2&=0.5488,\\\lambda_1-1.4\lambda_2&=-0.5488,\\2\lambda_2&=1.0976,\\\lambda_2&=0.5488,\\\lambda_1&=0.5488-0.6(0.5488)\\&=0.2195.\end{aligned}\]

แถวที่สามลบแถวที่สี่ได้ $2\lambda_2$ จึงหา $\lambda_2$ ได้ก่อน ส่วน $\lambda_1$ ออกมาเท่ากับ $0.4\lambda_2$ พอดี แถวของ B คือ $\lambda_1-0.4\lambda_2+\lambda_3=0.0610$ สองตัวแรกจึงหักล้างกัน เหลือ $\lambda_3=0.0610$ ได้ $\boldsymbol\lambda=(0.2195,\ 0.5488,\ 0.0610)$ alpha ก้อนใหญ่ของสัญญาณนี้จึงเป็นแค่การเดิมพันว่า momentum จะขึ้น

4. ผู้ให้บริการ risk model ส่งรายงานแบบ Cholesky มาด้วย (rotation) รายงานนี้วัด momentum และ tech หลังหักส่วนที่ขยับตามตลาดออกก่อน แล้วย้ายส่วนที่หักไปไว้ในบรรทัด market รายงานนี้จะแบ่ง factor PnL ของวันนี้เป็นสามบรรทัดอย่างไร?

ดูเฉลยข้อ 4

ขั้นแรกหาว่า factor แต่ละตัวขยับตามตลาดแค่ไหน ตัววัดคือ beta ต่อตลาด เท่ากับ correlation คูณความผันผวนของ factor หารด้วยความผันผวนของตลาด

\[\begin{aligned}\beta_{\rm mom}&=\frac{-0.20\times0.35}{1.00}=-0.07,\\\beta_{\rm tech}&=\frac{0.50\times0.55}{1.00}=0.275.\end{aligned}\]

บรรทัด market รับเดิมพันตลาดที่แฝงอยู่ในทุก exposure รวมกันเป็น $\tilde b_{\rm mkt}=b_{\rm mkt}+\beta_{\rm mom}b_{\rm mom}+\beta_{\rm tech}b_{\rm tech}$ แล้วคูณ market return อีกสองบรรทัดใช้ factor return หลังหักส่วนที่ตามตลาด เช่น momentum ใช้ $f_{\rm mom}-\beta_{\rm mom}f_{\rm mkt}$ แล้วคูณ exposure ของมัน

\[\begin{aligned}\tilde b_{\rm mkt}&=0+(-0.07)(6.2)+0.275(1)\\&=-0.434+0.275=-0.159,\\\text{market}&=-0.159(0.80)=-0.1272,\\\text{momentum}&=6.2(-0.50+0.07(0.80))\\&=6.2(-0.444)=-2.7528,\\\text{tech}&=1(0.30-0.275(0.80))\\&=1(0.08)=0.08.\end{aligned}\]

สามบรรทัดคือ −\$1,272, −\$27,528 และ +\$800 รวม $-0.1272-2.7528+0.08=-2.80$ หรือ −\$28,000 เท่ากับข้อ 1 เพราะยอดรวมไม่ขึ้นกับแกนที่ใช้วัด ให้สังเกตว่าบรรทัด market ไม่เป็นศูนย์ ทั้งที่ exposure ต่อ market เป็นศูนย์ เพราะเดิมพัน momentum พาเดิมพันตลาดติดมาด้วย บรรทัด tech เขียนง่ายแบบนี้ได้ เพราะหลังหักตลาดแล้ว momentum กับ tech ไม่สัมพันธ์กันเลยพอดี: covariance ของสองตัว ลบส่วนที่มาจากการตามตลาดร่วมกัน $\beta_{\rm mom}\beta_{\rm tech}\sigma_{\rm mkt}^2$ เหลือ $-0.01925-(-0.07)(0.275)(1.00^2)=0$ (ถ้าไม่เป็นศูนย์ บรรทัด tech ต้องหักส่วนที่ขยับตาม momentum ออกด้วย)

5. risk manager (คนที่ดูแลความเสี่ยงของทั้งโต๊ะ) อยากรู้ว่าความเสี่ยงของพอร์ตใหม่มาจากกลุ่มไหน จึงแบ่งเป็นสามกลุ่ม คือ momentum, tech และเฉพาะตัว (market ไม่ต้องนับ เพราะ exposure เป็นศูนย์) แต่ละกลุ่มมีส่วนแบ่ง variance และ MCR เท่าไร (การแบ่งความเสี่ยง)?

ดูเฉลยข้อ 5

variance รวม 51.8627 จากข้อ 2 คือผลรวมของทุกช่องในตาราง covariance ระหว่างกลุ่ม ส่วนของกลุ่มหนึ่งคือผลรวมแถวของมัน เรียกว่า $c_i$ คือช่องของตัวเองบวกช่องไขว้กับกลุ่มอื่น ช่องไขว้ระหว่าง momentum กับ tech คือ

\[\begin{aligned}b_{\rm mom}b_{\rm tech}\operatorname{cov}_{\rm mom,tech}&=6.2(1)(-0.01925)\\&=-0.11935.\end{aligned}\]

ส่วนเฉพาะตัวไม่สัมพันธ์กับ factor จึงไม่มีช่องไขว้ ผลรวมแถวและส่วนแบ่งของแต่ละกลุ่มจึงเป็น

\[\begin{aligned}c_{\rm mom}&=4.7089-0.11935=4.58955,\\c_{\rm tech}&=0.3025-0.11935=0.18315,\\c_{\rm idio}&=47.09,\\4.58955/51.8627&=8.85\%,\\0.18315/51.8627&=0.35\%,\\47.09/51.8627&=90.80\%.\end{aligned}\]

MCR ของกลุ่ม $i$ คือ $m_i=c_i/(v_iv_{\rm tot})$ เมื่อ $v_i$ คือความผันผวนของกลุ่มเอง: $v_{\rm mom}=6.2\times0.35=2.17$, $v_{\rm tech}=1\times0.55=0.55$ และ $v_{\rm idio}=6.8622$ จากข้อ 2

\[\begin{aligned}m_{\rm mom}&=\frac{4.58955}{2.17(7.2016)}=0.2937,\\m_{\rm tech}&=\frac{0.18315}{0.55(7.2016)}=0.0462,\\m_{\rm idio}&=\frac{47.09}{6.8622(7.2016)}=0.9529.\end{aligned}\]

MCR ก็คือ correlation ของกลุ่มกับพอร์ต ส่วนเฉพาะตัวได้ 0.9529 แปลว่าพอร์ตแทบขยับตามส่วนเฉพาะตัวล้วน ๆ ถ้าส่วนนี้แกว่งเพิ่ม \$1 ความเสี่ยงรวมขึ้นราว \$0.95 ส่วน tech ได้แค่ 0.0462 เพราะช่องไขว้ที่ติดลบหักล้างช่องของตัวเองไปเกือบหมด

6. ในงานจริงไม่มีใครบอก factor return ให้ ต้องประมาณจากผลตอบแทนของหุ้น สมมติประมาณด้วย WLS จากหุ้นสี่ตัวนี้เท่านั้น ค่าที่ได้คือ $\hat{\mathbf f}=(0.7237,\ -0.1120,\ 0.2990)\%$ เทียบกับค่าจริง $(0.80,\ -0.50,\ 0.30)\%$ ความคลาดของค่าประมาณมี covariance matrix $\mathbf G$ ช่องที่ต้องใช้คือ $G_{22}=1.3144$ (variance ของความคลาดของ momentum), $G_{33}=3.9045$ (ของ tech) และ $G_{23}=-0.6018$ (covariance ระหว่างสองตัว) ตัวเลขเหล่านี้ได้จากสูตร WLS ในหน้าFrisch–Waugh–Lovell รายงานที่ใช้ $\hat{\mathbf f}$ จะแบ่งกำไรขาดทุนวันนี้อย่างไร และความคลาดของการแบ่งมี SD เท่าไร (ใช้performance attribution)?

ดูเฉลยข้อ 6

ให้ $\hat F$ คือบรรทัด factor ในรายงาน คิดด้วย $\hat{\mathbf f}$ แทน $\mathbf f$ และ $\hat E$ คือบรรทัดเฉพาะตัว คิดจากกำไรขาดทุนรวม −0.40 (ซึ่งวัดได้ตรง) ลบ $\hat F$ ช่อง market ไม่ต้องใช้ เพราะ $b_{\rm mkt}=0$

\[\begin{aligned}\hat F&=6.2(-0.1120)+1(0.2990)\\&=-0.6944+0.2990=-0.3954,\\\hat E&=-0.40-(-0.3954)=-0.0046.\end{aligned}\]

รายงานจึงบอกว่า factor −\$3,954 และเฉพาะตัว −\$46 ขณะที่ค่าจริงจากข้อ 1 คือ −\$28,000 และ +\$24,000 ผลรวม −\$4,000 ยังถูก เพราะความคลาดที่บวกเข้าบรรทัด factor ถูกลบออกจากบรรทัดเฉพาะตัวเท่ากันพอดี แต่การแบ่งผิดไปไกลมาก

ขนาดของความคลาดนี้รู้ได้ล่วงหน้า ความคลาดของบรรทัด factor คือ $\mathbf b^{\mathsf T}(\hat{\mathbf f}-\mathbf f)$ จึงมี variance $\mathbf b^{\mathsf T}\mathbf G\mathbf b$ ตามกฎ covariance เมื่อคูณตัวสุ่มด้วย vector

\[\begin{aligned}\mathbf b^{\mathsf T}\mathbf G\mathbf b&=6.2^2(1.3144)+1^2(3.9045)\\&\quad+2(6.2)(1)(-0.6018)\\&=50.5255+3.9045-7.4623\\&=46.9677,\\\sqrt{46.9677}&=6.8533.\end{aligned}\]

SD ของความคลาดคือราว \$68,533 ต่อวัน ใหญ่กว่าเงินในทั้งสองบรรทัด รายงานที่ประมาณ factor return จากหุ้นสี่ตัวจึงแทบไม่บอกอะไร ทางแก้คือประมาณจากหุ้นจำนวนมาก ซึ่งทำให้ $\mathbf G$ เล็กลง

ก่อนไปสร้าง model จากข้อมูลจริง

  • สมการ $\mathbf r=\boldsymbol\alpha+\mathbf B\mathbf f+\boldsymbol\epsilon$ ย่อพอร์ตที่มีหุ้นกี่ตัวก็ได้ ให้เหลือ exposure $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$ ซึ่งมีแค่ factor ละหนึ่งตัวเลข กำไรขาดทุนจึงแยกเป็นก้อน factor บวกก้อนเฉพาะตัว $\mathbf b^{\mathsf T}\mathbf f+\mathbf w^{\mathsf T}\boldsymbol\epsilon$ ส่วนความเสี่ยงแยกกันที่ variance $\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b+\mathbf w^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf w$ เพราะสองก้อนไม่สัมพันธ์กัน SD ของสองก้อนจึงต่อกันเป็นสามเหลี่ยมมุมฉาก ไม่ได้บวกกันตรง ๆ
  • alpha ส่วนที่อยู่ใน range ของ $\mathbf B$ เป็นแค่เดิมพัน factor ที่ซื้อได้ถูก ส่วนที่ตั้งฉาก $\boldsymbol\alpha_\perp$ คือฝีมือจริง มันให้ Sharpe Ratio ที่โตตาม $\sqrt n$ เมื่อจำนวนหุ้น $n$ เพิ่ม ตราบใดที่ alpha ต่อหุ้นยังไม่หดลง
  • rotation ไม่เปลี่ยนยอดรวมใด ๆ แต่เปลี่ยนการแบ่งราย factor ได้ทั้งหมด จึงต้องเลือกแบบของ model ให้ตายตัวก่อนรายงานหรือแบ่งความเสี่ยง
  • เมื่อแบ่งความเสี่ยงเป็นกลุ่ม ส่วนแบ่ง variance ของกลุ่มคือ beta ของกลุ่มเทียบกับพอร์ต MCR คือ correlation ของกลุ่มกับพอร์ต และกลุ่ม $i$ ควรขยายเมื่อ $\text{SR}_i/\text{SR}_{\rm tot}\gt m_i$ เท่านั้น ($m_i$ คือ MCR) ตัวเลขเหล่านี้เป็นความชันที่จุดวันนี้ จึงใช้ได้กับการขยับเล็ก ๆ เท่านั้น
  • FWL ทำให้เพิ่มคอลัมน์ใหม่เข้า model ทีละขั้นได้โดยไม่เสียความแม่น ส่วนความคลาดของ factor return ที่ประมาณได้มี covariance $\mathbf G=(\mathbf B^{\mathsf T}\boldsymbol\Omega_\epsilon^{-1}\mathbf B)^{-1}$ ความคลาดนี้ย้ายเงินไปมาระหว่างบรรทัด factor กับบรรทัดเฉพาะตัว โดยไม่เปลี่ยนผลรวม จึงต้องรายงาน $\sqrt{\mathbf b^{\mathsf T}\mathbf G\mathbf b}$ คู่กับการแบ่งทุกครั้ง

ทั้งบทนี้สมมติว่ามี loading, factor return และ covariance ให้ใช้อยู่แล้ว บทถัดไปสร้างของเหล่านี้จากข้อมูลจริง เริ่มจากคะแนนของแต่ละบริษัท (ซึ่งใช้เป็น loading) กับผลตอบแทนดิบของหุ้น แล้วหา factor return ของทุกวันด้วยregression ข้ามหุ้น คือในแต่ละวัน regress ผลตอบแทนของหุ้นทุกตัวบนคะแนนของมัน แบบ WLS ที่ Frisch–Waugh–Lovell ปูทางไว้ จากนั้นสร้าง covariance ของ factor และของส่วนเฉพาะตัวที่ใช้กับพอร์ตจริงได้
