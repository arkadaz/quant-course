Linear Models of Returns · 6 หัวข้อ

จากสมการเดียว $\mathbf r=\boldsymbol\alpha+\mathbf B\mathbf f+\boldsymbol\epsilon$ ไปสู่สามคำถามของโต๊ะหุ้น: พอร์ตถือเดิมพันอะไรอยู่จริง ความเสี่ยงควรลดตรงไหน และกำไรขาดทุนที่เกิดขึ้นมาจากไหน ระหว่างทางแยก alpha เป็นส่วนที่ซื้อได้ถูกกับส่วนที่มีค่าจริง ดูว่า model เดียวกันเขียนได้หลายแบบ และพิสูจน์ว่าการประมาณเป็นขั้นได้คำตอบเดียวกับทำทีเดียว

คำถามหลักของบท

พอร์ต long–short หุ้นสี่ตัว ถือ A \$3 ล้าน B −\$2 ล้าน C \$4 ล้าน D −\$5 ล้าน เงินสองฝั่งเท่ากันพอดี วันนี้ขาดทุน \$13,000 โต๊ะต้องตอบหกข้อ: ขาดทุนนี้มาจากการเลือกหุ้นหรือจากเดิมพันที่ไม่ได้ตั้งใจ พอร์ตเสี่ยงวันละเท่าไร สัญญาณที่นักวิจัยเสนอมีส่วนไหนเป็นฝีมือจริง ทำไมรายงานสองฉบับจาก model เดียวกันจึงโทษ factor ต่างกัน ถ้าต้องลดความเสี่ยงควรลดกลุ่มไหน และคุณสมบัติใหม่ควรเพิ่มเข้า model อย่างไรโดยไม่ทำลายตัวเลขเก่า บทนี้ตอบทั้งหกข้อด้วย factor model ตัวเดียวกันตลอดบท

เส้นเรื่องที่ร้อยทั้งบทคือ “เงินที่เท่ากันไม่ได้แปลว่าเดิมพันที่เป็นกลาง”: พอร์ตในตัวอย่างไม่มี exposure ต่อตลาด แต่ 98.6% ของขนาดพอร์ตเป็นเดิมพัน momentum ทุกหัวข้อจึงแยกผลตอบแทน ความเสี่ยง และกำไรขาดทุนตามแหล่งที่มันมาจริง แล้วถามว่าการแยกนั้นขึ้นกับการเลือกของเราแค่ไหน

ก่อนเริ่ม: ควรคุ้นกับผลคูณจุดและ norm จาก 6.4–6.5 การคูณ matrix, range และ rank จาก 7.3 และ 7.5 eigenvalue จาก 7.6 ความเสี่ยงของพอร์ต $\mathbf w^{\mathsf T}\boldsymbol\Sigma\mathbf w$ จาก 8.2 และ risk contribution จาก 8.8 Cholesky จาก 8.9 marginal risk จาก 12.2 OLS จาก 15.1 model หลายปัจจัยและ covariance $B\Sigma_fB^{\mathsf T}+D$ จาก 15.3 และความคลาดของ Sharpe Ratio จาก 3.5

เส้นทางที่ 1 — สมการ และสิ่งที่มันแยก

เขียนผลตอบแทนเป็นส่วนคงที่ แรงร่วม และส่วนเฉพาะตัว แล้วอ่านสมการสามทาง ทางที่สามย่อพอร์ตให้เหลือ exposure $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$ แยกกำไรขาดทุนและความเสี่ยงเป็นสองก้อน จากนั้นแยก alpha ด้วย projection ส่วนที่อยู่ใน range ของ $\mathbf B$ คือเดิมพัน factor ที่ซื้อได้ถูก ส่วนที่ตั้งฉากคือเดิมพันหลายร้อยครั้งที่ความเสี่ยงหักล้างกัน

  1. 26.1The Factor Model Equation and Three Ways to Read Itพอร์ตที่เงินสองฝั่งเท่ากันเสีย \$13,000 เพราะ factor −\$66,000 ทั้งที่เลือกหุ้นได้ +\$53,000 และความเสี่ยง \$48,063 กับ \$159,223 รวมกันได้ \$166,319 ไม่ใช่ \$207,286
  2. 26.2Alpha Spanned and Alpha Orthogonalสัญญาณที่ทายหุ้นละ 2% บนหุ้น 500 ตัวได้ Sharpe Ratio อย่างน้อย 1.278 เดิมพัน momentum ได้ 0.375 และรวมกันอย่างดีที่สุดได้แค่ 1.332

จุดตรวจ: ทำไม exposure ต่อ market ของพอร์ตจึงเท่ากับ NMV พอดี และทำไมพอร์ตที่ชี้ไปทาง $\boldsymbol\alpha_\perp$ จึงได้ผลตอบแทนคาดหวังเท่ากับความยาวของ $\boldsymbol\alpha_\perp$ ไม่ใช่ค่าเฉลี่ยของมัน

เส้นทางที่ 2 — model เดียวกันหลายหน้าตา และการแบ่งความเสี่ยง

แทรก $\mathbf C^{-1}\mathbf C$ เข้าไปใน $\mathbf B\mathbf f$ แล้วผลตอบแทนหุ้น กำไรขาดทุนรวม และความเสี่ยงรวมไม่ขยับ แต่คำตอบว่า factor ไหนทำเงินขยับตามแบบที่เลือก เมื่อตรึงแบบแล้ว แบ่งความเสี่ยงเป็นกลุ่มได้สามตัววัด ส่วนแบ่ง variance ซึ่งคือ beta, MCR ซึ่งคือ correlation และ Sharpe sensitivity ซึ่งบอกทิศที่ควรขยายหรือหด

เส้นทางที่ 3 — ประมาณเป็นขั้น และบัญชีว่าเงินมาจากไหน

Frisch–Waugh–Lovell บอกว่าหักส่วนที่ model เดิมอธิบายได้ออกจากทั้งผลตอบแทนและคอลัมน์ใหม่ แล้ว regress ส่วนที่เหลือบนกัน ได้คำตอบเดียวกับทำทีเดียวทุกหลัก สูตรเดียวกันในแบบถ่วงน้ำหนักให้ factor-mimicking portfolio $\mathbf H$ และความคลาด $\mathbf G$ ของ factor return จากนั้นประกอบทุกชิ้นเป็นรายงานว่ากำไรมาจาก trading, factor หรือการเลือกหุ้น และตัวเลขแต่ละบรรทัดมีโชคปนแค่ไหน

ก่อนเดินต่อบท 27

  • $\mathbf r=\boldsymbol\alpha+\mathbf B\mathbf f+\boldsymbol\epsilon$ ย่อพอร์ตให้เหลือ exposure $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$ กำไรขาดทุนแยกเป็น $\mathbf b^{\mathsf T}\mathbf f+\mathbf w^{\mathsf T}\boldsymbol\epsilon$ และ variance แยกเป็น $\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b+\mathbf w^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf w$ ที่บวกกันแบบกำลังสอง
  • alpha ส่วนที่อยู่ใน range ของ $\mathbf B$ คือเดิมพัน factor ส่วนที่ตั้งฉากให้ Sharpe Ratio ที่โตตาม $\sqrt n$ ได้จนกว่า alpha ต่อหุ้นจะหด
  • rotation ไม่เปลี่ยนยอดรวมใด ๆ แต่เปลี่ยนการแบ่งราย factor ทั้งหมด จึงต้องตรึงแบบของ model ก่อนรายงานหรือแบ่งความเสี่ยง
  • ส่วนแบ่ง variance คือ beta MCR คือ correlation และกลุ่มควรขยายเมื่อ $\text{SR}_i/\text{SR}_{\rm tot}\gt m_i$ เท่านั้น ความชันใช้ได้เฉพาะแถวจุดปัจจุบัน
  • FWL ทำให้เพิ่มคอลัมน์เป็นขั้นได้โดยไม่เสียความแม่น และความคลาดของ factor return คือ $\mathbf G=(\mathbf B^{\mathsf T}\boldsymbol\Omega_\epsilon^{-1}\mathbf B)^{-1}$ ซึ่งย้ายเงินระหว่างบรรทัด factor กับเฉพาะตัวโดยไม่เปลี่ยนผลรวม

บทที่ 27 เลิกสมมติว่ามี factor return ให้ใช้ เริ่มจากคุณสมบัติบริษัทกับผลตอบแทนดิบ หา factor return ทุกวันด้วย WLS ข้ามหุ้นตาม 26.5 แล้วสร้าง covariance ของ factor และของส่วนเฉพาะตัวที่ใช้กับพอร์ตจริงได้
