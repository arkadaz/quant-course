25.2 The Stylized Facts of Stock Returns

ผลตอบแทนหุ้นทุกตลาดมีสี่นิสัยเหมือนกัน: ทายทิศของพรุ่งนี้ไม่ได้ วันสุดโต่งเกิดบ่อยกว่าที่ Normal บอก วันแรงมักตามด้วยวันแรง และพอรวมหลายวัน รูปร่างก็เข้าใกล้ Normal

กองทุนแห่งหนึ่งถือหุ้นตามดัชนีหุ้น (ตัวเลขที่สรุปราคาของหุ้นหลายร้อยตัวรวมกัน เช่น S&P 500) ทีมความเสี่ยงของกองทุนต้องตัดสินใจเรื่อง “กันทุน” คือแยกเงินสดก้อนหนึ่งไว้ ห้ามเอาไปลงทุน เพื่อให้วันที่ขาดทุนหนักยังจ่ายเงินที่ต้องจ่ายได้ ถ้าวันร่วงแรงแทบไม่เคยเกิด เงินก้อนนี้ก็นอนเฉย ๆ เสียโอกาส แต่ถ้ามันเกิดบ่อย การไม่กันทุนอาจทำให้กองทุนล้ม

ของที่รู้ (ตัวเลขสมมติ):

  • ผลตอบแทนรายวัน คือการเปลี่ยนแปลงของดัชนีในหนึ่งวัน คิดเป็นสัดส่วนของค่าเมื่อวาน เช่น ร่วง 5% หรือขึ้น 1%
  • ความผันผวนรายวัน $\sigma=1.2\%$ คือ SD (standard deviation) ของผลตอบแทนรายวัน พูดง่าย ๆ คือวันปกติดัชนีขยับขึ้นหรือลงราว 1.2%
  • วันที่ทีมกังวลคือวันที่ดัชนีร่วง 5% ในวันเดียว
  • ปีหนึ่งมี 252 วันทำการ คือวันที่ตลาดเปิด

นักวิเคราะห์คนหนึ่งสมมติว่าผลตอบแทนรายวันกระจายตัวเป็นรูประฆัง Normal (ค่าใกล้ศูนย์เกิดบ่อย ค่าที่ไกลออกไปเกิดน้อยลงเร็วมาก ดูNormal distribution และ QQ plot) เขาวัดว่าวัน −5% อยู่ไกลจากศูนย์กี่เท่าของ SD ได้ $x=5\%/1.2\%=4.17$ เท่า แล้วตอบว่า “ไม่ต้องกันทุน ระฆัง Normal บอกว่าวันที่ไกลถึง 4.17 SD เกิดครั้งเดียวในราว 250 ปี”

ในตลาดจริง วันแบบนี้เกิดบ่อยแค่ไหน และควรกันทุนไหม?

ลองตอบก่อนเปิดเฉลย

ควรกันทุน ตัวเลขของนักวิเคราะห์คิดถูกตามระฆัง Normal (ได้ครั้งเดียวใน 256.8 ปี) แต่ระฆัง Normal ผิดตรง “หาง” คือส่วนของวันที่อยู่ไกลจากศูนย์มาก ๆ ข้อมูลหุ้นจริงมีหางหนากว่ามาก แปลว่าวันสุดโต่งเกิดบ่อยกว่าที่ Normal บอก

หางของหุ้นจริงลดลงแบบ power law คือโอกาสที่วันหนึ่งจะไกลเกิน $x$ เท่าของ SD หดตาม $x^{-\zeta}$ ซึ่งช้ากว่าหางของ Normal มาก หน้านี้ลองสองค่า $\zeta=4$ กับ $\zeta=3$ ค่าที่วัดได้จาก SPY, IBM และ AAPL อยู่ระหว่างสองค่านี้ ถ้าตั้งหางแบบนี้ให้โอกาสเท่ากับ Normal ที่ระยะ 3 SD (ระยะที่ยังมีข้อมูลจริงพอให้เห็น) วัน −5% จะเกิดบ่อยขึ้นมาก:

  • $\zeta=4$: ครั้งเดียวใน 10.94 ปี บ่อยกว่า Normal $256.8/10.94=23.5$ เท่า
  • $\zeta=3$: ครั้งเดียวใน 7.88 ปี
  • ตลาดจำลองที่หน้านี้สร้าง ยาว 400,000 วัน มีวันที่ร่วงเกิน 4.17 SD อยู่ 484 วัน ขณะที่ Normal คาดไว้แค่ 6.2 วัน

ตัวเลขทุกตัวในเฉลยนี้ หน้านี้จะคำนวณให้ดูทีละขั้น

ภาพรวมก่อนลงสูตร

แบบจำลองราคาหุ้นพื้นฐานที่สุดคือ geometric Brownian motion มันสมมติว่าผลตอบแทนแต่ละวันเป็นระฆัง Normal ที่มีความผันผวนเท่าเดิมทุกวัน และไม่เกี่ยวกับวันก่อน ๆ เลย ถ้าเป็นอย่างนั้นจริง ทุกวันจะหน้าตาเหมือนกันหมด ไม่มีช่วงสงบ ไม่มีช่วงปั่นป่วน และวันที่ขยับไกลเกิน 4 เท่าของ SD แทบไม่เคยเกิด

ข้อมูลจริงไม่เป็นอย่างนั้น และมันเบี้ยวไปในแบบเดียวกันทุกตลาดทุกยุค นักวิจัยจึงเรียกนิสัยที่เจอซ้ำเหล่านี้ว่า stylized facts มีสี่ข้อ:

  1. ทิศไม่มีความจำ วันนี้ขึ้นหรือลง แทบไม่บอกว่าพรุ่งนี้จะขึ้นหรือลง
  2. หางหนา วันที่ขยับไกลจากศูนย์มาก ๆ เกิดบ่อยกว่าที่ระฆัง Normal บอก
  3. ขนาดมีความจำ วันที่ขยับแรง (ไม่ว่าขึ้นหรือลง) มักตามด้วยวันที่ขยับแรง วันแรงจึงเกาะกลุ่มกัน
  4. รวมแล้วเข้าใกล้ Normal ผลตอบแทนที่รวมหลายวัน เช่นรายเดือน มีรูปร่างใกล้ระฆัง Normal กว่ารายวัน

ทำไมต้องรู้ เพราะแบบจำลองที่ทีมความเสี่ยงใช้คุมเงินต้องทำซ้ำสี่ข้อนี้ได้ก่อน ถ้าทำไม่ได้ มันจะประเมินวันร้ายต่ำไปแบบนักวิเคราะห์ในโจทย์เปิดหน้า หน้านี้จะวัดแต่ละข้อเป็นตัวเลข ตามลำดับนี้:

  • หาโอกาสของวันสุดโต่งภายใต้ Normal ด้วยสูตรง่ายที่คิดในหัวได้ และรู้ว่าสูตรผิดไม่เกินเท่าไร
  • เทียบกับหางแบบ power law ที่ข้อมูลจริงมี
  • ดูว่าหางหนาทำให้ “โมเมนต์” ตัวไหนหายไป (โมเมนต์ลำดับ $k$ คือค่าเฉลี่ยของ $|X|^k$ เช่นลำดับสองใช้คิด variance) และทำไมโมเมนต์ลำดับสี่ตัดสินว่าเราประมาณความผันผวนได้แม่นแค่ไหน
  • สร้างตลาดจำลองที่มีครบสี่นิสัย แล้ววัดมันทั้งด้วยสูตรและด้วยการจำลอง 400,000 วัน

รูปด้านล่างคือ 500 วันจากตลาดจำลองนั้น นิสัยสามข้อแรกเห็นได้ในรูปเดียว

ศัพท์ที่ใช้ในหัวข้อนี้
Stylized facts
นิสัยทางสถิติของผลตอบแทนที่เจอซ้ำในทุกตลาดหุ้นและทุกยุค แบบจำลองผลตอบแทนต้องทำซ้ำนิสัยเหล่านี้ได้ก่อน จึงจะเอาไปคุมความเสี่ยงได้
หาง (tail)
ส่วนของการแจกแจงที่อยู่ไกลจากศูนย์มาก ๆ คือวันที่ขึ้นหรือลงแรงผิดปกติ “หางหนา” แปลว่าวันแบบนี้เกิดบ่อยกว่าที่ระฆัง Normal บอก
Power law และ tail index
หางแบบ power law คือหางที่โอกาสไกลเกิน $x$ เขียนได้เป็น $P(|X|\gt x)=Cx^{-\zeta}$ โดย $C$ เป็นค่าคงที่ เลข $\zeta$ เรียกว่า tail index ยิ่ง $\zeta$ เล็ก โอกาสยิ่งหดช้าเมื่อ $x$ โต หางจึงยิ่งหนา ตำราหลายเล่มเขียน tail index ว่า $\alpha$ แต่หน้านี้ใช้ $\alpha$ กับ GARCH แล้ว
โมเมนต์ (moment)
โมเมนต์ลำดับ $k$ คือค่าเฉลี่ยของ $|X|^k$ ลำดับสองใช้คิด variance ลำดับสี่ใช้คิด kurtosis ถ้าหางหนามาก ค่าเฉลี่ยนี้อาจโตไม่หยุด เราเรียกว่าโมเมนต์ “ไม่มีค่าจำกัด”
Kurtosis
ตัวเลขตัวเดียวที่สรุปว่าหางหนาแค่ไหน เมื่อค่าเฉลี่ยเป็นศูนย์ มันคือ $\mathbb E[r^4]/(\mathbb E[r^2])^2$ ระฆัง Normal มีค่า 3 เสมอ ค่าที่สูงกว่า 3 แปลว่าวันสุดโต่งเกิดบ่อยกว่า Normal
ACF (autocorrelation function)
correlation ระหว่างข้อมูลชุดหนึ่งกับตัวมันเองที่เลื่อนไป $k$ วัน ($k$ เรียกว่า lag) ใช้ดูว่าวันนี้บอกอะไรเกี่ยวกับอีก $k$ วันข้างหน้าได้บ้าง ดูACF
Volatility clustering
วันที่ขยับแรงเกาะกลุ่มกัน และช่วงสงบก็ลากยาว เห็นได้จาก ACF ของขนาด $|r_t|$ หรือ $r_t^2$ ที่เป็นบวกและจางลงช้า ๆ ผลคือเราทายความผันผวนของพรุ่งนี้ได้ แม้จะทายทิศไม่ได้
GARCH(1,1)
แบบจำลองที่ให้ variance ของพรุ่งนี้ขึ้นกับขนาดการขยับของวันนี้และ variance ของวันนี้ จึงสร้างวันแรงที่เกาะกลุ่มกันได้ ดูGARCH(1,1)
Student-t
การแจกแจงรูประฆังที่หางหนากว่า Normal มีตัวเลข $\nu$ (degrees of freedom) คุมความหนาของหาง ยิ่ง $\nu$ เล็ก หางยิ่งหนา
Aggregational Gaussianity
ผลตอบแทนที่รวมหลายวันมีรูปร่างเข้าใกล้ Normal มากขึ้น kurtosis รายเดือนจึงต่ำกว่ารายวัน ทุกครั้งที่รายงานความหนาของหางจึงต้องบอกด้วยว่าวัดรายวันหรือรายเดือน
Unconditional และ conditional
unconditional คือรูปร่างเมื่อเทข้อมูลทุกวันรวมกัน โดยไม่สนว่าวันนั้นอยู่ในช่วงสงบหรือปั่นป่วน conditional คือรูปร่างของพรุ่งนี้เมื่อรู้ข้อมูลถึงวันนี้แล้ว แบบแรกหางหนากว่าแบบหลัง
Leverage effect
วันที่ราคาลงดันความผันผวนขึ้นแรงกว่าวันที่ราคาขึ้นขนาดเท่ากัน เคยนับเป็นนิสัยข้อที่ห้า แต่ในข้อมูลช่วงหลังมันอ่อนลง หน้านี้จึงไม่นับรวม
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$r_t,\ \sigma$ผลตอบแทนของวันที่ $t$ และความผันผวนรายวัน (SD ของ $r_t$)ทศนิยมต่อวัน เช่น 0.012 คือ 1.2%
$x$ขนาดของวันที่สนใจ นับเป็นจำนวนเท่าของ $\sigma$ไม่มีหน่วย
$\varphi(x),\ \bar F(x)$density ของ Normal มาตรฐาน (ค่าเฉลี่ย 0, SD 1) และโอกาสที่ค่าจะเกิน $x$ไม่มีหน่วย
$\zeta,\ C$tail index และค่าคงที่ของหาง power lawไม่มีหน่วย
$\omega,\ \alpha,\ \beta,\ p$parameter ของ GARCH(1,1) และ $p=\alpha+\beta$ คือสัดส่วนของ variance ที่ส่งต่อไปวันถัดไป$\omega$ เป็น (ทศนิยมต่อวัน)², ที่เหลือไม่มีหน่วย
$z_t,\ \nu,\ \kappa_z$ก้อนสุ่มของวันที่ $t$ (ค่าเฉลี่ย 0, variance 1), degrees of freedom ของ Student-t และ $\kappa_z=\mathbb E[z^4]$ไม่มีหน่วย
$V,\ K,\ \rho_k$variance ระยะยาว, kurtosis รายวัน, ACF ของ $r_t^2$ ที่ lag $k$$V$ เป็น (ทศนิยมต่อวัน)², ที่เหลือไม่มีหน่วย
$m,\ K_m$จำนวนวันที่รวมเป็นหนึ่งงวด และ kurtosis ของผลรวมนั้นวันทำการ, ไม่มีหน่วย

ขั้นที่ 1 — บีบหางของ Normal ด้วยสองขอบ

โจทย์เปิดหน้าถามว่า ภายใต้ระฆัง Normal วันที่ไกลเกิน $x=4.17$ เท่าของ SD เกิดบ่อยแค่ไหน คำตอบคือพื้นที่ใต้ระฆังที่อยู่ทางขวาของ $x$ เราเรียกพื้นที่นี้ว่า $\bar F(x)$

ปัญหาคือ density ของ Normal มาตรฐาน (ความสูงของรูประฆังที่จุด $t$ เมื่อค่าเฉลี่ย 0 และ SD 1) คือ $\varphi(t)=e^{-t^2/2}/\sqrt{2\pi}$ ซึ่งอินทิเกรตออกมาเป็นสูตรปิดไม่ได้ ถ้าไม่อยากเปิดตารางหรือเขียนโปรแกรม เราต้องการสูตรง่ายที่คิดในหัวได้ และต้องรู้ด้วยว่าสูตรนั้นผิดไม่เกินเท่าไร วิธีคือหาขอบบนกับขอบล่างมาบีบค่าจริงไว้ตรงกลาง

เครื่องมือมีสองชิ้น ชิ้นแรกคืออนุพันธ์ของ density: ใช้ chain rule กับ $e^{-t^2/2}$ ได้ $\varphi'(t)=-t\varphi(t)$ แปลว่า $t\varphi(t)$ อินทิเกรตได้ทันทีเป็น $-\varphi(t)$ ชิ้นที่สองคือการอินทิเกรตทีละส่วน (integration by parts)

\[ \begin{aligned} \bar F(x)&=\int_x^{\infty}\frac1t\,t\varphi(t)\,dt\\ &=\frac{\varphi(x)}{x}-\int_x^{\infty}\frac{\varphi(t)}{t^{2}}\,dt,\\ 0&\le\int_x^{\infty}\frac{\varphi(t)}{t^{2}}\,dt\le\frac{\varphi(x)}{x^{3}},\\ \bar F(x)&\le\varphi(x)/x,\\ \bar F(x)&\ge\varphi(x)/x-\varphi(x)/x^{3}. \end{aligned} \]

กลเม็ดอยู่ที่การเขียน $\varphi(t)$ เป็น $\frac1t\cdot t\varphi(t)$ ซึ่งดูเหมือนทำให้ยุ่งขึ้น แต่มันทำให้ $t\varphi(t)$ เป็นส่วนที่อินทิเกรตได้ทันที ($-\varphi(t)$) ส่วน $1/t$ เป็นส่วนที่หาอนุพันธ์ อินทิเกรตทีละส่วนแล้วได้ $\varphi(x)/x$ ลบด้วยอินทิเกรตก้อนที่เหลือ ก้อนนั้นเป็นบวกเสมอเพราะ $\varphi$ กับ $t^2$ เป็นบวก เมื่อลบก้อนที่เป็นบวกออก $\bar F(x)$ จึงไม่เกิน $\varphi(x)/x$ นี่คือขอบบน

ขอบล่างได้จากการใช้กลเม็ดเดิมอีกรอบกับก้อนที่เหลือ คราวนี้เขียน $\varphi(t)/t^2$ เป็น $\frac{1}{t^3}\cdot t\varphi(t)$ ได้ว่าก้อนนั้นไม่เกิน $\varphi(x)/x^3$ เอาไปลบจาก $\varphi(x)/x$ จึงได้ค่าที่ไม่เกิน $\bar F(x)$

สองขอบต่างกันแค่ตัวคูณ $1-1/x^2$ ยิ่งไกลในหาง ยิ่งต่างกันน้อย ที่ $x=4$ ต่างกัน $1/4^2=0.0625$ หรือราว 6% ขอบบน $\varphi(x)/x$ จึงใช้แทนค่าจริงได้ และมันบอกนิสัยของหาง Normal ทันที: $\varphi(x)$ มี $e^{-x^2/2}$ อยู่ข้างใน ระยะ $x$ เพิ่มขึ้นนิดเดียว โอกาสก็ลดลงหลายเท่า

ขั้นที่ 2 — วัน −5% ที่ความผันผวน 1.2%: ครั้งเดียวใน 257 ปี

ตอนนี้มีสูตรแล้ว เอาตัวเลขของโจทย์เปิดหน้ามาใส่ เพื่อดูว่านักวิเคราะห์ได้ “ราว 250 ปี” มาอย่างไร

โจทย์ให้อะไรมาบ้าง:

  • ความผันผวนรายวัน $\sigma=1.2\%=0.012$
  • ค่าเฉลี่ยของผลตอบแทนรายวันถือเป็นศูนย์ เพราะมันเล็กมากเมื่อเทียบกับการขยับวันละ 1.2%
  • วันที่สนใจคือร่วง 5% ระยะของมันนับเป็นจำนวนเท่าของ SD คือ $x=0.05/0.012$
  • ระฆัง Normal สมมาตร โอกาสที่จะต่ำกว่า $-x$ จึงเท่ากับโอกาสที่จะสูงกว่า $x$ คือ $\bar F(x)$
  • ปีหนึ่งมี 252 วันทำการ มาจาก 365 วัน ลบเสาร์อาทิตย์ 104 วัน และลบวันหยุดตลาดราว 9 วัน: $365-104-9=252$
\[ \begin{aligned} x&=0.05/0.012=4.1667,\\ \varphi(x)&=e^{-x^2/2}/\sqrt{2\pi}\\ &=e^{-8.6806}/2.5066\\ &=6.7763\times10^{-5},\\ \varphi(x)/x&=1.6263\times10^{-5},\\ \tfrac{\varphi(x)}{x}\big(1-\tfrac{1}{x^2}\big)&=1.5326\times10^{-5},\\ \bar F(x)&=1.5454\times10^{-5},\\ 1/\bar F(x)&=64{,}707\ \text{days},\\ 64{,}707/252&=256.8\ \text{years}. \end{aligned} \]

สองขอบบีบค่าจริงไว้ระหว่าง $1.5326\times10^{-5}$ กับ $1.6263\times10^{-5}$ ค่าจริง $\bar F(x)=1.5454\times10^{-5}$ ได้จากการอินทิเกรต density เชิงตัวเลขในโค้ดท้ายหน้า และอยู่ในช่วงนั้นพอดี โอกาสต่อวันเท่านี้แปลว่าเฉลี่ยต้องรอ $1/\bar F(x)$ วันจึงจะเจอหนึ่งครั้ง หารด้วย 252 ก็ได้เป็นปี

คำตอบ: ถ้าผลตอบแทนเป็น Normal จริง วัน −5% เกิดครั้งเดียวในราว 64,707 วันทำการ หรือ 256.8 ปี นักวิเคราะห์คิดเลขถูก ส่วนที่ผิดคือสมมติฐานว่าหางเป็นแบบ Normal ซึ่งขั้นถัดไปจะดู

ตรวจเองใน 10 วินาที: ใช้ขอบบนอย่างเดียวก็พอ

\[ \begin{aligned} \varphi(4.17)&\approx e^{-8.68}/2.507\approx6.8\times10^{-5},\\ \varphi(4.17)/4.17&\approx1.6\times10^{-5}. \end{aligned} \]

ขั้นที่ 3 — หางแบบ power law: ครั้งเดียวใน 11 ปี

ขั้นที่แล้วได้ 256.8 ปี โดยสมมติว่าหางเป็นแบบ Normal ขั้นนี้เปลี่ยนแค่สมมติฐานเรื่องหาง แล้วดูว่าคำตอบเปลี่ยนไปแค่ไหน

หางของข้อมูลผลตอบแทนจริงหดช้ากว่า Normal มาก รูปที่ใช้อธิบายหางจริงกันมากคือ power law: โอกาสที่วันหนึ่งจะไกลเกิน $x$ เท่าของ SD เท่ากับ $\bar F(x)=Cx^{-\zeta}$ โดย $C$ เป็นค่าคงที่ และ $\zeta$ คือ tail index รูปนี้เป็นสมมติฐานของแบบจำลองหาง ไม่ใช่สิ่งที่พิสูจน์ได้

แล้ว $\zeta$ ของหุ้นจริงเป็นเท่าไร หนังสือ The Elements of Quantitative Investing ของ Paleologo วัดหางซ้าย (ฝั่งวันที่ราคาลง) ของผลตอบแทนรายวันหุ้นสหรัฐฯ ปี 2001 ถึง 2017 ได้เลขชี้กำลังราว 3.4 ถึง 4.8 เช่น SPY 4.1, IBM 4.3, AAPL 4.8

แต่ตัวเลขในตารางนั้นเป็นเลขชี้กำลัง $a$ ของ density คือ $f(x)\propto x^{-a}$ (density แปรผันตาม $x^{-a}$) ไม่ใช่ของ $\bar F(x)$ ต้องแปลงก่อน เพราะ $\bar F(x)$ คือพื้นที่ใต้ density จาก $x$ ไปถึงอนันต์ และการอินทิเกรตทำให้เลขชี้กำลังลดลงหนึ่ง:

\[ \begin{aligned} \int_x^{\infty}t^{-a}\,dt&=\frac{x^{-(a-1)}}{a-1},\\ \zeta&=a-1,\\ \text{SPY}:\ \zeta&=4.1-1=3.1. \end{aligned} \]

ช่วง $a$ ราว 3.4 ถึง 4.8 จึงกลายเป็น $\zeta$ ราว 2.4 ถึง 3.8 หน้านี้ลองสองค่าคือ $\zeta=3$ (ใกล้ SPY) และ $\zeta=4$ (หางบางกว่าหุ้นทุกตัวในตาราง จึงเป็นกรณีที่ใจดีกับ Normal ที่สุด)

จะเทียบให้ยุติธรรม ต้องให้สองแบบเห็นตรงกันที่จุดหนึ่งก่อน เราบังคับให้หาง power law ให้โอกาสเท่า Normal ที่ระยะ 3 SD ทำไมเลือก 3 SD เพราะที่ระยะนี้ Normal ให้โอกาสต่อวัน $\bar F(3)=1.3499\times10^{-3}$ (ได้จากโค้ดท้ายหน้าแบบเดียวกับขั้นที่ 2) วันแบบนี้จึงเกิดราว $1/(1.3499\times10^{-3}\times252)=2.9$ ปีต่อครั้ง ข้อมูลหลายปีมีวันแบบนี้ให้เห็นพอ ทั้งสองแบบจึงต้องตรงกับข้อมูลที่ระยะนี้ แล้วค่อยดูว่าที่ 4.1667 SD สองแบบให้คำตอบต่างกันแค่ไหน

\[ \begin{aligned} \bar F(x)&=C\,x^{-\zeta},\\ \frac{\bar F(4.1667)}{\bar F(3)}&=\Big(\frac{3}{4.1667}\Big)^{\zeta}\\ &=0.72^{\zeta},\\ \bar F(3)&=1.3499\times10^{-3},\\ \zeta=4:\ \bar F(4.1667)&=1.3499\times10^{-3}\times0.72^{4}\\ &=3.6277\times10^{-4},\\ \frac{1}{3.6277\times10^{-4}\times252}&=10.94\ \text{years},\\ \zeta=3:\ \bar F(4.1667)&=1.3499\times10^{-3}\times0.72^{3}\\ &=5.0385\times10^{-4},\\ \frac{1}{5.0385\times10^{-4}\times252}&=7.88\ \text{years}. \end{aligned} \]

หัวใจของการบังคับให้ตรงกันคือการหารสองค่าของ $\bar F$ ค่าคงที่ $C$ อยู่ทั้งบนและล่างจึงตัดกันหมด เหลือแค่อัตราส่วนของระยะ $3/4.1667=0.72$ พอดี เราจึงไม่ต้องรู้ $C$ เลย ขยับออกไปจาก 3 SD แค่ 1.17 SD คำตอบก็ต่างจาก Normal ($1.5454\times10^{-5}$ จากขั้นที่แล้ว) มาก: $\dfrac{3.6277\times10^{-4}}{1.5454\times10^{-5}}=23.5$ เท่าที่ $\zeta=4$ และ $\dfrac{5.0385\times10^{-4}}{1.5454\times10^{-5}}=32.6$ เท่าที่ $\zeta=3$

ทำไมต่างกันมากขนาดนี้ เพราะสองแบบหดคนละวิธี power law ที่ $\zeta=4$ ถ้าระยะเพิ่มเป็นสองเท่า โอกาสเหลือ $2^{-4}=1/16$ ไม่ว่าจะเริ่มที่ระยะไหน แต่ Normal จาก 3 SD ไป 6 SD โอกาสเหลือแค่ $\dfrac{\bar F(6)}{\bar F(3)}=\dfrac{9.87\times10^{-10}}{1.3499\times10^{-3}}=7.3\times10^{-7}$ เท่า

มองกลับด้านก็เห็นแบบเดียวกัน ถามว่า “วันแย่ที่เกิดด้วยโอกาส $\delta$ อยู่ไกลแค่ไหน” (ระยะนี้เรียกว่า quantile) ของ Normal แก้ $e^{-x^2/2}\approx\delta$ ได้ $x\approx\sqrt{2\ln(1/\delta)}$ ซึ่งโตช้ามากเมื่อ $\delta$ เล็กลง ของ power law แก้ $Cx^{-\zeta}=\delta$ ได้ $x=(C/\delta)^{1/\zeta}$ ซึ่งโตตาม $\delta^{-1/\zeta}$ เร็วกว่ามาก

ขั้นที่ 4 — โมเมนต์ไหนมีค่าจำกัด

หางหนาทำให้วันแย่เกิดบ่อยขึ้น แต่มีผลที่ลึกกว่านั้น ทีมความเสี่ยงใช้ค่าเฉลี่ยหลายแบบทุกวัน เช่น variance คือค่าเฉลี่ยของ $r^2$ และ kurtosis ใช้ค่าเฉลี่ยของ $r^4$ ถ้าหางหนามาก ค่าเฉลี่ยเหล่านี้บางตัวอาจโตไม่หยุด ยิ่งเก็บข้อมูลนาน ยิ่งได้ค่าใหญ่ขึ้น คำถามของขั้นนี้คือ โมเมนต์ลำดับไหน (ค่าเฉลี่ยของ $|X|^k$ ตัวไหน) ยังมีค่าจำกัด

ระฆัง Normal มีโมเมนต์ครบทุกลำดับ เพราะ $e^{-x^2/2}$ หดเร็วกว่ากำลังใด ๆ ของ $x$ ส่วน power law ต้องคิดดู เริ่มจากหา density ของหาง: โอกาสสะสม $F(x)=1-\bar F(x)$ มี density เป็นอนุพันธ์ของมัน แล้วอินทิเกรต $x^kf(x)$ เฉพาะส่วนหาง ตั้งแต่ $x=1$ ถึงขอบบน $L$ เพื่อดูว่าเมื่อ $L$ ไกลออกไปเรื่อย ๆ ผลรวมหยุดที่ค่าหนึ่งหรือไม่

\[ \begin{aligned} f(x)&=\frac{d}{dx}\big(1-Cx^{-\zeta}\big)\\ &=\zeta C\,x^{-\zeta-1},\\ I_k(L)&=\int_1^{L}x^{k}f(x)\,dx\\ &=\zeta C\,\frac{L^{k-\zeta}-1}{k-\zeta},\\ k\lt\zeta:\ I_k(\infty)&=\frac{\zeta C}{\zeta-k},\\ k=4,\ \zeta=3:\ I_4(L)&=3C(L-1). \end{aligned} \]

ทุกอย่างขึ้นกับเครื่องหมายของเลขชี้กำลัง $k-\zeta$ ถ้า $k\lt\zeta$ เลขชี้กำลังติดลบ $L^{k-\zeta}$ จึงหดเข้าหาศูนย์เมื่อ $L$ ไกล ผลรวมหยุดที่ $\zeta C/(\zeta-k)$ โมเมนต์จึงมีค่าจำกัด ถ้า $k$ ไม่น้อยกว่า $\zeta$ ผลรวมโตไม่หยุด (กรณี $k=\zeta$ พอดี อินทิเกรตได้ $\zeta C\ln L$ ซึ่งก็โตไม่หยุดเช่นกัน)

แถวสุดท้ายคือกรณีที่น่ากลัวที่สุดในทางปฏิบัติ: $\zeta=3$ กับโมเมนต์ที่สี่ $I_4(L)$ โตเป็นเส้นตรงตาม $L$ และ $L$ ในข้อมูลจริงก็คือวันที่แย่ที่สุดที่เคยเห็น ยิ่งเก็บข้อมูลนาน ยิ่งเจอวันที่แย่กว่าเดิม ค่าเฉลี่ยของ $r^4$ ที่วัดได้จึงไม่เคยนิ่ง

ขั้นที่ 3 วัดได้ว่าหุ้นจริงมี $\zeta$ ราว 2.4 ถึง 3.8 ทุกค่ามากกว่า 2 ค่าเฉลี่ย ($k=1$) และ variance ($k=2$) จึงมีค่าจำกัดแน่ แต่โมเมนต์ที่สี่ ($k=4$) อยู่ตรงขอบหรือเลยขอบไปแล้ว ขั้นถัดไปแสดงว่าทำไมขอบนี้ตัดสินว่าเราประมาณความผันผวนได้แม่นแค่ไหน

ขั้นที่ 5 — ทำไมโมเมนต์ที่สี่ตัดสินว่าความผันผวนประมาณได้แม่นแค่ไหน

ทีมความเสี่ยงไม่รู้ความผันผวนจริง ต้องประมาณจากข้อมูลย้อนหลัง วิธีพื้นฐานคือเอาผลตอบแทนรายวันมายกกำลังสองแล้วหาค่าเฉลี่ย คำถามคือ ข้อมูลหนึ่งปี ($n=252$ วัน) ให้ค่าที่แม่นแค่ไหน

เครื่องมือคือ Central Limit Theorem: ค่าเฉลี่ยของ $n$ ค่าที่อิสระกันจะคลาดเคลื่อนราว SD ของหนึ่งค่า หารด้วย $\sqrt n$ ความคลาดเคลื่อนนี้เรียกว่า SE (standard error) แต่มีเงื่อนไข: SD ของหนึ่งค่าต้องมีค่าจำกัด ในที่นี้ “หนึ่งค่า” คือ $r^2$ และ SD ของ $r^2$ ต้องใช้ค่าเฉลี่ยของ $r^4$ คือโมเมนต์ที่สี่ ขั้นนี้สมมติให้ค่าเฉลี่ยของ $r$ เป็นศูนย์ และแต่ละวันอิสระกัน

\[ \begin{aligned} \hat\sigma^2&=\frac1n\sum_{t=1}^{n}r_t^2,\\ \operatorname{Var}(r^2)&=\mathbb E[r^4]-(\mathbb E[r^2])^2\\ &=K\sigma^4-\sigma^4=(K-1)\,\sigma^4,\\ \operatorname{SE}(\hat\sigma^2)&=\sqrt{\operatorname{Var}(r^2)/n},\\ \frac{\operatorname{SE}(\hat\sigma^2)}{\sigma^2}&=\sqrt{\frac{K-1}{n}},\\ K=3:\ \sqrt{2/252}&=8.91\%,\\ K=6.34:\ \sqrt{5.34/252}&=14.56\%,\\ \frac{\operatorname{SE}(\hat\sigma)}{\sigma}&\approx\frac12\cdot\frac{\operatorname{SE}(\hat\sigma^2)}{\sigma^2},\\ K=6.34:\ \tfrac12\times14.56\%&=7.28\%. \end{aligned} \]

ตัวที่ทำให้ทุกอย่างเชื่อมกันคือนิยามของ kurtosis: $K=\mathbb E[r^4]/\sigma^4$ จึงเขียน $\mathbb E[r^4]$ เป็น $K\sigma^4$ ได้ ความแม่นของ variance จึงขึ้นกับ $K$ ตรง ๆ ถ้าผลตอบแทนเป็น Normal ($K=3$) ข้อมูลหนึ่งปีบอก variance ได้แม่นราว ±8.91% แต่ถ้า $K=6.34$ (ค่าของตลาดจำลองที่ขั้นถัดไปจะสร้าง) ความคลาดเคลื่อนกว้างขึ้นเป็น ±14.56%

ทำไมความผันผวนคลาดเคลื่อนแค่ครึ่งเดียว เพราะ $\hat\sigma=\sqrt{\hat\sigma^2}$ ถ้า $\hat\sigma^2$ คลาดไป $e$ (สัดส่วน) จะได้ $\sqrt{1+e}\approx1+e/2$ ความคลาดของ $\hat\sigma$ จึงราวครึ่งหนึ่ง คือ ±7.28% ส่วนถ้าโมเมนต์ที่สี่ไม่มีค่าจำกัดเลย ($K$ เป็นอนันต์) สูตรนี้ใช้ไม่ได้ และความคลาดเคลื่อนไม่หดตาม $\sqrt n$ อีกต่อไป

kurtosis เองยิ่งวัดยากกว่า เพราะ kurtosis คือค่าเฉลี่ยของ $r^4$ ความคลาดเคลื่อนของมันจึงต้องใช้ค่าเฉลี่ยของ $(r^4)^2=r^8$ คือโมเมนต์ที่แปด รูปด้านล่างแสดงว่าในข้อมูลจริงมันแกว่งแค่ไหน

ขั้นที่ 6 — ตลาดจำลองที่มีครบทุกนิสัย: GARCH กับ Student-t

ข้อมูลจริงมีปัญหาตรงที่เราไม่รู้คำตอบที่ถูก เช่นไม่รู้ kurtosis จริงของ SPY จะตรวจว่าวิธีวัดแต่ละนิสัยใช้ได้ไหม เราต้องมีตลาดที่รู้คำตอบล่วงหน้า วิธีคือสร้างตลาดจำลองเองจากสูตร คิดคำตอบที่ถูกด้วยมือ แล้วค่อยวัดจากข้อมูลที่จำลองออกมา

ตลาดจำลองนี้ใช้ GARCH(1,1) ผลตอบแทนของวันที่ $t$ คือความผันผวนของวันนั้นคูณก้อนสุ่ม $r_t=\sigma_tz_t$ และ variance ของวันถัดไปขึ้นกับสิ่งที่เพิ่งเกิด:

\[ \begin{aligned} \sigma_{t+1}^2&=\omega+\alpha\,r_t^2+\beta\,\sigma_t^2. \end{aligned} \]

อ่านสูตรนี้ได้ว่า variance ของพรุ่งนี้ คือพื้นขั้นต่ำ $\omega$ บวกส่วนหนึ่งของข่าววันนี้ (การขยับยกกำลังสอง $r_t^2$) บวกส่วนหนึ่งของ variance วันนี้ วันนี้ขยับแรง พรุ่งนี้ variance ก็สูงขึ้น นี่คือที่มาของวันแรงที่เกาะกลุ่มกัน ค่าที่ใช้ (สมมติให้ใกล้ค่าที่วัดได้จากดัชนีหุ้นจริง):

  • $\omega=3.1\times10^{-6}$ คือพื้นขั้นต่ำของ variance
  • $\alpha=0.07$ คือน้ำหนักของข่าววันนี้
  • $\beta=0.90$ คือน้ำหนักของ variance วันนี้
  • $p=\alpha+\beta=0.97$ คือสัดส่วนของ variance ที่ส่งต่อไปวันถัดไป ยิ่งใกล้ 1 ความจำยิ่งยาว
  • ก้อนสุ่ม $z_t$ มาจาก Student-t ที่ $\nu=8$ ปรับขนาดให้ variance เป็น 1 หางของมันหนากว่า Normal: $\kappa_z=\mathbb E[z^4]=\dfrac{3(\nu-2)}{\nu-4}=\dfrac{3\times6}{4}=4.5$ เทียบกับ 3 ของ Normal (สูตร $\kappa_z$ ได้จากการอินทิเกรต density ของ Student-t หน้านี้ใช้ผลเลย)

ทีนี้คิดคำตอบที่ถูกด้วยมือ สองตัวที่ต้องรู้คือ variance ระยะยาว $V=\mathbb E[r_t^2]$ และ kurtosis รายวัน $K$ เอาค่าเฉลี่ยของสองข้างของสูตร GARCH ($\mathbb E[r_t^2]=\mathbb E[\sigma_t^2]=V$ ทุกวัน) ได้ $V=\omega+\alpha V+\beta V$ จึงแก้ได้ $V=\omega/(1-p)$ ส่วน $K$ ต้องใช้ค่าเฉลี่ยของ $\sigma^4$ จึงยกกำลังสองสูตร GARCH แล้วหาค่าเฉลี่ยอีกรอบ

\[ \begin{aligned} V&=\frac{\omega}{1-p}=\frac{3.1\times10^{-6}}{0.03}\\ &=1.0333\times10^{-4},\\ \sqrt V&=1.0165\%\ \text{per day},\\ \sqrt{252V}&=16.14\%\ \text{per year},\\ \sigma_{t+1}^2&=\omega+\sigma_t^2(\alpha z_t^2+\beta),\\ \mathbb E[\sigma_{t+1}^4]&=\omega^2+2\omega pV\\ &\quad+c_4\,\mathbb E[\sigma_t^4],\\ c_4&=\mathbb E[(\alpha z^2+\beta)^2]\\ &=\kappa_z\alpha^2+2\alpha\beta+\beta^2\\ &=0.02205+0.126+0.81\\ &=0.95805,\\ \mathbb E[\sigma^4]&=\frac{V^2(1-p^2)}{1-c_4},\\ K&=\frac{\kappa_z\,\mathbb E[\sigma^4]}{V^2}=\frac{\kappa_z(1-p^2)}{1-c_4}\\ &=\frac{4.5\times0.0591}{0.04195}=6.340. \end{aligned} \]

จังหวะที่ต้องระวังคือการยกกำลังสอง เขียนสูตร GARCH ใหม่เป็น $\sigma_{t+1}^2=\omega+\sigma_t^2(\alpha z_t^2+\beta)$ (เพราะ $r_t^2=\sigma_t^2z_t^2$) แล้วยกกำลังสอง ก้อน $z_t$ เป็นของใหม่ ไม่เกี่ยวกับ $\sigma_t$ ค่าเฉลี่ยของผลคูณจึงแยกเป็นผลคูณของค่าเฉลี่ยได้ ตัวคูณ $c_4$ คือค่าเฉลี่ยของ $(\alpha z^2+\beta)^2$ ซึ่งกางออกได้ $\kappa_z\alpha^2+2\alpha\beta+\beta^2$ เพราะ $\mathbb E[z^2]=1$ และ $\mathbb E[z^4]=\kappa_z$

ตลาดนิ่งในระยะยาว ค่าเฉลี่ยของ $\sigma^4$ วันพรุ่งนี้จึงเท่ากับของวันนี้ แก้สมการได้ $\mathbb E[\sigma^4]=(\omega^2+2\omega pV)/(1-c_4)$ แทน $\omega=V(1-p)$ ตัวบนจัดรูปได้ $V^2(1-p)(1+p)=V^2(1-p^2)$ ส่วน $r^4=\sigma^4z^4$ จึงได้ $\mathbb E[r^4]=\kappa_z\mathbb E[\sigma^4]$ หารด้วย $V^2$ ก็ได้ $K$ ทั้งหมดนี้ใช้ได้ต่อเมื่อ $c_4\lt1$ ถ้า $c_4\ge1$ ค่าเฉลี่ยของ $\sigma^4$ โตไม่หยุด และโมเมนต์ที่สี่ไม่มีค่าจำกัด ที่นี่ $c_4=0.958$ จึงผ่าน

แยกได้ว่าหางหนามาจากไหน ถ้าก้อนสุ่มเป็น Normal ($\kappa_z=3$) จะได้ $c_4=3\times0.0049+0.126+0.81=0.9507$ และ $K=3\times0.0591/0.0493=3.596$ ความเกาะกลุ่มอย่างเดียวดัน kurtosis จาก 3 ขึ้นไป 3.6 ส่วนหางของ Student-t ดันต่อไปถึง 6.34

ตลาดนี้จึงมีหางหนาสองชั้น ชั้นแรกอยู่ในวันเดียว: $z_t$ หางหนากว่า Normal (นี่คือหาง conditional) ชั้นที่สองเกิดเมื่อเทหลายวันรวมกัน: วันสงบกับวันปั่นป่วนผสมกัน (นี่คือหาง unconditional) หางรวมจึงหนากว่าหางของวันเดียวเสมอ รูปด้านล่างแยกชั้นที่สองออกมาให้เห็นชัด

ขั้นที่ 7 — ข้อ 1 และข้อ 3: ทิศไม่มีความจำ แต่ขนาดมี

ตอนนี้มีตลาดที่รู้คำตอบแล้ว เริ่มตรวจนิสัยข้อ 1 กับข้อ 3 ทั้งสองข้อวัดด้วยเครื่องมือเดียวกัน คือ ACF ที่ lag $k$ ซึ่งเป็น correlation ระหว่างค่าของวันนี้กับค่าของ $k$ วันก่อน

  • ข้อ 1 (ทิศไม่มีความจำ) แปลว่า ACF ของผลตอบแทน $r_t$ เป็นศูนย์ทุก lag
  • ข้อ 3 (ขนาดมีความจำ) แปลว่า ACF ของขนาด $|r_t|$ หรือ $r_t^2$ เป็นบวก และจางลงช้า ๆ เมื่อ lag ยาวขึ้น

ข้อ 1 พิสูจน์ได้ในบรรทัดเดียว เพราะผลตอบแทนแต่ละวันมีค่าเฉลี่ยศูนย์ correlation จึงเป็นศูนย์ต่อเมื่อค่าเฉลี่ยของผลคูณ $r_tr_{t-k}$ เป็นศูนย์

\[ \begin{aligned} \mathbb E[r_tr_{t-k}]&=\mathbb E[\sigma_tr_{t-k}]\,\mathbb E[z_t]\\ &=0. \end{aligned} \]

ข้อ 3 ต้องใช้ผลจากหน้า GARCH(1,1): ข่าวกำลังสอง $r_t^2$ ของ GARCH(1,1) เดินแบบ ARMA(1,1) ซึ่งแปลว่าค่าของวันนี้คือส่วนหนึ่งของค่าเมื่อวาน บวกข่าวใหม่ ส่วนที่ส่งต่อแต่ละวันคือ $p=\alpha+\beta=0.97$ ACF จึงหดลงด้วยตัวคูณ 0.97 ทุกครั้งที่ lag ยาวขึ้นหนึ่งวัน ส่วนค่าเริ่มต้น $\rho_1$ ได้จากการคิด covariance ของ ARMA(1,1) นั้น หน้านี้ใช้ผลเลย

\[ \begin{aligned} \rho_1&=\frac{\alpha(1-\alpha\beta-\beta^2)}{1-2\alpha\beta-\beta^2}\\ &=\frac{0.07\times0.127}{0.064}\\ &=0.1389,\\ \rho_k&=0.97^{\,k-1}\rho_1,\\ \rho_5&=0.97^{4}\times0.1389=0.1230,\\ \rho_{20}&=0.97^{19}\times0.1389=0.0779,\\ \rho_{60}&=0.97^{59}\times0.1389=0.0230. \end{aligned} \]

ข้อ 1 แยกค่าเฉลี่ยออกเป็นสองก้อนได้ เพราะ $\sigma_t$ กับ $r_{t-k}$ รู้ค่าแล้วตั้งแต่เมื่อวาน ส่วน $z_t$ เป็นของใหม่ที่ไม่เกี่ยวกับอดีต และมีค่าเฉลี่ยศูนย์ ผลคูณจึงเป็นศูนย์ ไม่ว่า $z_t$ จะมาจาก Normal หรือ Student-t

ข้อ 3 ตัวเลขในสูตรมาจาก $1-\alpha\beta-\beta^2=1-0.063-0.81=0.127$ และ $1-2\alpha\beta-\beta^2=1-0.126-0.81=0.064$ สังเกตว่าสูตร $\rho_k$ ไม่มี $\kappa_z$ อยู่เลย หางของก้อนสุ่มจึงไม่เปลี่ยน ACF ของ $r_t^2$ ขอแค่โมเมนต์ที่สี่มีค่าจำกัด ที่ 60 วัน ACF ยังเหลือ 0.023 แปลว่าวันแรงวันนี้ยังบอกอะไรได้อีกราวสามเดือนทำการ

เทียบกับการจำลอง 400,000 วันในโค้ดท้ายหน้า ที่ lag 1, 5, 20, 60:

  • ACF ของ $r_t$ ได้ −0.0026, −0.0018, −0.0021, −0.0021 ทุกตัวอยู่ในแถบเสียงรบกวน $\pm2/\sqrt n=\pm2/\sqrt{400{,}000}=\pm0.0032$ (ถ้า ACF จริงเป็นศูนย์ ค่าที่วัดได้จะอยู่ในแถบนี้ราว 95 ครั้งจาก 100)
  • ACF ของ $r_t^2$ ได้ 0.1492, 0.1201, 0.0726, 0.0149 ใกล้สูตร
  • ACF ของ $|r_t|$ ได้ 0.1340, 0.1193, 0.0733, 0.0182

ผลตอบแทนชุดเดียวกันจึงมี ACF เป็นศูนย์ แต่ไม่ได้อิสระกัน เพราะขนาดของวันนี้ยังบอกขนาดของวันหน้าได้

ขั้นที่ 8 — ข้อ 2 และข้อ 4: ทำไม kurtosis ลดลงเมื่อรวมหลายวัน

เหลือข้อ 2 กับข้อ 4 คำถามคือ ถ้ารวมผลตอบแทนหลายวันเป็นหนึ่งงวด เช่นรวม 21 วันทำการเป็นหนึ่งเดือน หางของผลรวมยังหนาเท่าเดิมไหม เรื่องนี้สำคัญ เพราะกองทุนบางแห่งรายงานความเสี่ยงรายวัน บางแห่งรายงานรายเดือน ถ้าความหนาของหางเปลี่ยนตามความถี่ ตัวเลขของสองที่ก็เทียบกันตรง ๆ ไม่ได้

ให้ผลรวมของ $m$ วันเป็น $S=r_1+\cdots+r_m$ ความหนาของหางรายงวดวัดด้วย kurtosis ของ $S$ คือ $K_m=\mathbb E[S^4]/(\mathbb E[S^2])^2$ ตัวล่างง่าย: ผลตอบแทนแต่ละวันไม่มี correlation กัน (ข้อ 1) variance ของผลรวมจึงเป็นผลรวมของ variance ได้ $mV$ ตัวบนต้องกาง $(r_1+\cdots+r_m)^4$ ออก

พจน์ที่กางออกมามีหลายแบบ แต่พจน์ที่มีวันใดวันหนึ่งขึ้นกำลังคี่ เช่น $r_1r_2^3$ หรือ $r_1^2r_2r_3$ มีค่าเฉลี่ยศูนย์ทั้งหมด เหตุผลคือใน GARCH ความผันผวน $\sigma_t$ ขึ้นกับอดีตผ่าน $r^2$ เท่านั้น ถ้ากลับเครื่องหมายของ $z$ วันใดวันหนึ่ง $\sigma$ ทุกวันไม่เปลี่ยน มีแค่ $r$ ของวันนั้นที่กลับเครื่องหมาย พจน์ที่มีวันนั้นขึ้นกำลังคี่ก็กลับเครื่องหมายตาม แต่ $z$ สมมาตร (ขึ้นหรือลงด้วยโอกาสเท่ากัน) สองทางนี้จึงเกิดบ่อยเท่ากัน ค่าเฉลี่ยของพจน์นั้นต้องเป็นศูนย์

จึงเหลือแค่พจน์ที่ทุกวันขึ้นกำลังคู่ มีสองแบบ: $r_i^4$ และ $r_i^2r_j^2$ ($i\lt j$) แบบหลังมี 6 พจน์ต่อคู่ เพราะการเลือกว่าสองตัวไหนในสี่ตัวคูณเป็น $r_i$ ทำได้ $\binom42=6$ วิธี

\[ \begin{aligned} \mathbb E[S^2]&=mV,\\ \mathbb E[S^4]&=\sum_{i}\mathbb E[r_i^4]\\ &\quad+6\sum_{i\lt j}\mathbb E[r_i^2r_j^2],\\ \mathbb E[r_i^4]&=KV^2,\\ \mathbb E[r_i^2r_j^2]&=V^2\\ &\quad+(K-1)V^2\rho_{j-i},\\ \mathbb E[S^4]&=mKV^2+3m(m-1)V^2\\ &\quad+6(K-1)V^2\sum_{k=1}^{m-1}(m-k)\rho_k,\\ K_m&=\frac{\mathbb E[S^4]}{m^2V^2}\\ &=3+\frac{K-3}{m}\\ &\quad+\frac{6(K-1)}{m^2}\sum_{k=1}^{m-1}(m-k)\rho_k. \end{aligned} \]

จังหวะสำคัญคือค่าเฉลี่ยของ $r_i^2r_j^2$ ค่าเฉลี่ยของผลคูณเท่ากับผลคูณของค่าเฉลี่ย ($V\times V$) บวก covariance ระหว่าง $r_i^2$ กับ $r_j^2$ covariance นี้คือ correlation $\rho_{j-i}$ คูณ variance ของ $r^2$ ซึ่งขั้นที่ 5 คิดไว้แล้วว่าเท่ากับ $(K-1)V^2$ ถ้าวันอิสระกัน covariance เป็นศูนย์ แต่ใน GARCH มันเป็นบวก

จากนั้นนับ: คู่ $i\lt j$ มีทั้งหมด $m(m-1)/2$ คู่ คูณ 6 ได้ $3m(m-1)$ และคู่ที่ห่างกัน $k$ วันมีอยู่ $m-k$ คู่ หารทั้งหมดด้วย $(mV)^2$ แล้วจัดรูป $K/m+3(m-1)/m=3+(K-3)/m$ ก็ได้แถวสุดท้าย

อ่านความหมาย: ถ้าวันอิสระกัน ($\rho_k=0$) ส่วนที่เกิน 3 หดเป็น $(K-3)/m$ ทันที รวม 21 วันก็เหลือ $1/21$ แต่ความเกาะกลุ่มเติมพจน์บวกเข้าไป หางรายเดือนจึงยังหนาอยู่นานกว่าที่วันอิสระจะให้มาก

ใส่ค่าของตลาดจำลอง ($K=6.34$, $\rho_k=0.1389\times0.97^{k-1}$) ลงในสูตร ได้คอลัมน์ “สูตร $K_m$” คอลัมน์ “ถ้าวันอิสระ” คือ $3+(K-3)/m$ เช่น $m=21$: $3+3.34/21=3.159$ อีกสองคอลัมน์วัดจากข้อมูลจำลองสองชุด

ขั้นที่ 9 — วัดจากตลาดจำลอง 400,000 วัน

กลับมาที่คำถามของทีมความเสี่ยง ถ้าตลาดมีครบสี่นิสัยแบบตลาดจำลองของเรา วันที่ร่วงไกลแบบวัน −5% ในโจทย์เปิดหน้าเกิดบ่อยแค่ไหน และ kurtosis ที่วัดจากข้อมูลเชื่อได้แค่ไหน

โจทย์ให้อะไรมาบ้าง:

  • โค้ดท้ายหน้าจำลองตลาด GARCH กับ Student-t ของขั้นที่ 6 ยาว 400,000 วัน คิดเป็น $400{,}000/252=1{,}587$ ปีของวันทำการ
  • ตัวเลขสุ่มมาจาก mulberry32 ที่ตั้ง seed เป็น 25 (seed คือเลขเริ่มต้นของตัวสุ่ม ใช้ seed เดิมก็ได้ตัวเลขชุดเดิมทุกครั้ง ผลจึงทำซ้ำได้) และวันแรกเริ่มที่ variance ระยะยาว $V$
  • วันที่นับคือวันที่ร่วงเกิน 4.1667 เท่าของ SD ที่วัดจากข้อมูลจำลอง (ระยะเดียวกับวัน −5% ในโจทย์) แล้วเทียบกับจำนวนที่ Normal คาดไว้
  • แบ่งข้อมูลเป็นสี่ช่วง ช่วงละ 100,000 วัน แล้ววัด kurtosis ของแต่ละช่วง
\[ \begin{aligned} \text{SD}&=1.0183\%\ \text{per day},\\ 4.1667\times1.0183\%&=4.24\%,\\ \text{Normal}&=400{,}000\times\bar F(4.1667)\\ &=400{,}000\times1.5454\times10^{-5}\\ &=6.18\ \text{days},\\ \text{sim}&=484\ \text{days},\\ 484/6.18&=78.3. \end{aligned} \]

SD ที่วัดจากข้อมูลจำลองได้ 1.0183% ต่อวัน ใกล้กับค่าจากสูตร $\sqrt V=1.0165\%$ ของขั้นที่ 6 ตลาดจำลองนี้แกว่งวันละราว 1.02% ไม่ใช่ 1.2% แบบในโจทย์ ระยะ 4.1667 SD ของมันจึงเท่ากับร่วง 4.24% ไม่ใช่ 5% แต่สิ่งที่เราเทียบคือระยะนับเป็นจำนวน SD ซึ่งเท่ากับโจทย์พอดี

จำนวนวันที่ Normal คาดไว้ คือจำนวนวันทั้งหมดคูณโอกาสต่อวัน $\bar F(4.1667)$ จากขั้นที่ 2 ส่วน 484 วันได้จากการนับในข้อมูลจำลองตรง ๆ

คำตอบ: ตลาดนี้มีวันที่ร่วงเกิน 4.17 SD อยู่ 484 วัน มากกว่าที่ Normal คาดไว้ 78 เท่า วันที่แย่ที่สุดร่วง 15.1 SD หรือ $15.1\times1.0183\%=15.4\%$ ในวันเดียว ซึ่งภายใต้ Normal แทบเป็นไปไม่ได้

kurtosis ของสี่ช่วงคือ 6.968, 7.169, 6.070 และ 5.729 ทั้งที่ทุกช่วงมาจากแบบจำลองเดียวกัน และแต่ละช่วงยาวถึง $100{,}000/252=397$ ปี ค่าสูงสุดกับต่ำสุดยังต่างกัน $7.169-5.729=1.44$

GARCH ยังมีจุดอ่อนสามข้อ ข้อแรก ถ้าปรับ parameter ให้ kurtosis ตรงกับดัชนีจริง ACF ของ $r^2$ ที่แบบจำลองทำนายมักสูงเกินที่วัดได้ และความจำยาวเกินจริง ข้อสอง ผลรวมหลายวันของ GARCH ไม่ได้กลายเป็น Normal จริง ๆ มันแค่เข้าใกล้ช้า ๆ ตามตารางในขั้นที่ 8 ข้อสาม ข้อมูลจริงมักมี Taylor effect คือ ACF ของ $|r|$ สูงกว่า ACF ของ $r^2$ แต่ตลาดจำลองนี้กลับกัน: ที่ lag 1 ได้ 0.134 เทียบกับ 0.149

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

ใช้ Normal ตั้งทุนรับวันแย่ ระฆัง Normal ประเมินความถี่ของวันสุดโต่งต่ำไปหลายสิบเท่า ทุนที่กันไว้ตาม Normal จึงไม่พอในวันที่ต้องใช้มันจริง

\[ \begin{aligned} \text{Normal}:\ \frac{1}{1.5454\times10^{-5}\times252}&=256.8\ \text{years},\\ \zeta=4:\ \frac{1}{3.6277\times10^{-4}\times252}&=10.94\ \text{years}. \end{aligned} \]

อ่าน ACF ที่เป็นศูนย์ว่าแต่ละวันอิสระกัน หรือว่าทายอะไรไม่ได้เลย ACF ศูนย์บอกแค่ว่าทายทิศแบบเส้นตรงจากอดีตของตัวเองไม่ได้ ในตลาดจำลอง ACF ของ $r_t$ อยู่ในแถบ $\pm2/\sqrt{400{,}000}=\pm0.0032$ แต่ ACF ของ $r_t^2$ ที่ lag 1 คือ $\rho_1=0.139$ วันแรงจึงตามมาด้วยวันแรง นอกจากนั้น ผลตอบแทนอาจทายได้จากตัวแปรอื่น หรือจากอดีตในแบบที่ไม่เป็นเส้นตรง

เทียบ kurtosis ที่วัดคนละความถี่ ตลาดเดียวกันให้ kurtosis คนละค่าเมื่อวัดรายวันกับรายเดือน กองทุนที่รายงาน kurtosis รายเดือนต่ำกว่าอีกกองที่รายงานรายวัน จึงไม่ได้แปลว่าเสี่ยงเรื่องหางน้อยกว่า ตัวอย่างจากสูตรของขั้นที่ 8: รายวัน $K_1=6.34$ แต่รายเดือน $K_{21}=4.92$

เชื่อ kurtosis ถึงทศนิยมสองตำแหน่ง kurtosis ที่วัดจากข้อมูลแกว่งมาก แบบจำลองเดียวกันให้ตั้งแต่ 5.73 ถึง 7.17 ในช่วงละ 100,000 วัน ต่างกัน $7.17-5.73=1.44$ ข้อมูลจริง 17 ปีของ SPY ก็บอกได้แค่ว่าอยู่ราว 6.5 ถึง 16.0

อ่านปีที่เงียบว่าหางบาง ถ้า $\zeta$ ราว 3 ขั้นที่ 4 แสดงว่าโมเมนต์ที่สี่ของข้อมูลโตตามวันที่แย่ที่สุดที่เคยเห็น $I_4(L)=3C(L-1)$ ปีที่ยังไม่มีวันแย่จึงให้ kurtosis ต่ำ ตัวเลขนั้นบอกแค่ว่าวันแย่ยังไม่มา ไม่ได้บอกว่ามันจะไม่มา

ใช้ทำอะไรบนโต๊ะจริง

นิสัยแต่ละข้อเปลี่ยนวิธีทำงานของทีมความเสี่ยงคนละแบบ:

  • ข้อ 3 (ขนาดมีความจำ) ความผันผวนของพรุ่งนี้ทายได้จากความผันผวนช่วงนี้ ระบบความเสี่ยงจึงพยากรณ์ความผันผวนรายวันด้วย GARCH หรือ EWMA (ค่าเฉลี่ยของ $r^2$ ที่ให้น้ำหนักวันล่าสุดมากกว่า) แทนการใช้ค่าคงที่ค่าเดียว
  • ข้อ 2 (หางหนา) VaR คือระดับขาดทุนที่วันส่วนใหญ่ไม่แย่เกิน เช่นไม่เกินใน 99 วันจาก 100 วัน VaR ที่คิดจาก Normal จึงต่ำไป ทีมจึงต้องดู Expected Shortfall (ขาดทุนเฉลี่ยในวันที่แย่เกิน VaR) และทำ stress test (ลองใส่วันร้ายที่เคยเกิดจริงเข้าไปในพอร์ต) ดูVaR และ expected shortfall
  • ข้อ 4 (รวมแล้วเข้าใกล้ Normal) ทุกครั้งที่รายงานความหนาของหาง ต้องบอกด้วยว่าวัดรายวันหรือรายเดือน

เรื่องโมเมนต์ที่สี่บอกว่า การวัดความเสี่ยงด้วย variance จะแม่นขึ้นเมื่อมีข้อมูลมากขึ้น ตราบใดที่โมเมนต์ที่สี่ยังมีค่าจำกัด แต่ kurtosis ไม่มีหลักประกันนี้ นี่คือเหตุผลเชิงเทคนิคที่แบบจำลองความเสี่ยงแบบ factor model สร้างบน variance และ covariance ไม่ใช่บน kurtosis และเป็นเหตุผลที่ต้องจัดการค่าสุดโต่ง (outlier) ด้วย winsorization ก่อนประมาณ คือตัดค่าที่ไกลเกินเกณฑ์ให้เหลือเท่าเกณฑ์ เพื่อไม่ให้วันสุดโต่งไม่กี่วันลากผลทั้งหมด

3. ตลาดหนึ่ง (ตัวเลขสมมติ) มี kurtosis รายวัน $K=6$ ACF ของ $r^2$ เป็น 0.2 ที่ lag 1 และเป็นศูนย์ที่ lag อื่น ผู้จัดการกองทุนเสนอว่า ถ้ารายงานผลตอบแทนเป็นรายสองวันแทนรายวัน หางจะดูบางลง kurtosis ของผลรวมสองวันเป็นเท่าไร และเทียบกับกรณีที่วันอิสระกันได้เท่าไร?

เฉลย

ใช้สูตร $K_m$ ของขั้นที่ 8 ที่ $m=2$ ผลรวม $\sum_{k=1}^{m-1}$ มีแค่ $k=1$ คือคู่ที่ห่างกันหนึ่งวัน ซึ่งมี $m-k=1$ คู่

\[ \begin{aligned} K_2&=3+\frac{6-3}{2}+\frac{6(6-1)}{2^2}\times1\times0.2\\ &=3+1.5+1.5=6.0,\\ \text{independent}:\ K_2&=3+\frac{6-3}{2}=4.5. \end{aligned} \]

ถ้าวันอิสระกัน หางจะบางลงจาก 6 เหลือ 4.5 ตามที่ผู้จัดการคิด แต่ความเกาะกลุ่มเติมกลับมา 1.5 พอดี หางของผลรวมสองวันจึงหนาเท่าหางวันเดียว ข้อเสนอนี้ไม่ได้ทำให้หางบางลงเลย

function garchT({omega, alpha, beta, nu}) {
  const p = alpha + beta, kz = nu === Infinity ? 3 : 3 * (nu - 2) / (nu - 4), c4 = kz * alpha * alpha + 2 * alpha * beta + beta * beta;
  if (!(p < 1 && c4 < 1)) throw new RangeError('needs alpha + beta < 1 and a finite fourth moment');
  const V = omega / (1 - p), K = kz * (1 - p * p) / (1 - c4);
  const rho1 = alpha * (1 - alpha * beta - beta * beta) / (1 - 2 * alpha * beta - beta * beta);
  const rho = k => rho1 * p ** (k - 1);
  const aggregated = m => {
    let s = 0;
    for (let k = 1; k < m; k++) s += (m - k) * rho(k);
    return 3 + (K - 3) / m + 6 * (K - 1) * s / (m * m);
  };
  return {p, kz, c4, V, K, rho, aggregated};
}

    const v = rnd(), R = sqrt(-2 * log(u));
    spare = R * sin(2 * PI * v);
    return R * cos(2 * PI * v);
  };
}
function simulate(n, seed, {omega, alpha, beta, nu}) {
  const z = normals(mulberry32(seed)), r = new Float64Array(n), scale = sqrt((nu - 2) / nu);
  let h = omega / (1 - alpha - beta), prev = 0;
  for (let t = 0; t < n; t++) {
    if (t) h = omega + alpha * prev * prev + beta * h;
    let w = 0;
    for (let k = 0; k < nu; k++) { const g = z(); w += g * g; }
    prev = r[t] = sqrt(h) * z() / sqrt(w / nu) * scale;
  }
  return r;
}
function acf(x, k) {
  const n = x.length;
  let m = 0, c0 = 0, ck = 0;
  for (let i = 0; i < n; i++) m += x[i];
  m /= n;
  for (let i = 0; i < n; i++) c0 += (x[i] - m) ** 2;
  for (let i = k; i < n; i++) ck += (x[i] - m) * (x[i - k] - m);
  return ck / c0;
}
function kurtosis(x) {
  const n = x.length;
  let m = 0, s2 = 0, s4 = 0;
  for (let i = 0; i < n; i++) m += x[i];
  m /= n;
  for (let i = 0; i < n; i++) { const d = (x[i] - m) ** 2; s2 += d; s4 += d * d; }
  return s4 / n / (s2 / n) ** 2;
}
function sums(x, m) {
  const out = new Float64Array(floor(x.length / m));
  for (let i = 0; i < out.length; i++) for (let j = 0; j < m; j++) out[i] += x[i * m + j];
  return out;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • หางของ Normal บีบได้ด้วยสองขอบ $\varphi(x)/x\,(1-1/x^2)\le\bar F(x)\le\varphi(x)/x$ ซึ่งได้จากการอินทิเกรตทีละส่วนสองครั้ง วัน −5% ที่ความผันผวนรายวัน 1.2% อยู่ที่ $0.05/0.012=4.17$ SD และ Normal ให้ครั้งเดียวใน 256.8 ปี
  • หาง power law ที่ $\zeta=4$ ซึ่งให้โอกาสเท่า Normal ที่ 3 SD ให้วันเดียวกันครั้งเดียวใน 10.94 ปี บ่อยกว่า Normal 23.5 เท่า หางซ้ายของหุ้นสหรัฐฯ ที่วัดได้มี $\zeta$ ราว 2.4 ถึง 3.8 คือหนากว่ากรณี $\zeta=4$ นี้อีก
  • โมเมนต์ลำดับ $k$ มีค่าจำกัดเฉพาะเมื่อ $k\lt\zeta$ ที่ $\zeta$ ราว 2.4 ถึง 3.8 variance มีค่าแน่ แต่โมเมนต์ที่สี่อยู่ตรงขอบหรือเลยขอบไปแล้ว
  • ความคลาดเคลื่อนของ variance ที่ประมาณได้คือ $\sqrt{(K-1)/n}$ ของค่าจริง ข้อมูลหนึ่งปีให้ ±8.91% ถ้าเป็น Normal และ ±14.56% ที่ $K=6.34$ ส่วน kurtosis เองวัดได้หยาบมาก ข้อมูล 17 ปีของ SPY บอกได้แค่ว่าอยู่ราว 6.5 ถึง 16.0
  • แม้ทุกวันจะเป็น Normal ล้วน ๆ การผสมวันสงบกับวันปั่นป่วนก็ให้หางหนาได้ ครึ่งหนึ่ง SD 0.6 อีกครึ่ง SD 1.28 ให้วันเกิน 4 SD บ่อยกว่า Normal 14 เท่า
  • ACF ของผลตอบแทนเป็นศูนย์ แต่ ACF ของ $r^2$ ในตลาดจำลองเริ่มที่ 0.139 และหดด้วยตัวคูณ 0.97 ต่อวัน ACF ศูนย์จึงไม่ได้แปลว่าแต่ละวันอิสระกัน
  • kurtosis ของผลรวม $m$ วันคือ $K_m=3+(K-3)/m+6(K-1)\sum_k(m-k)\rho_k/m^2$ ในตลาดจำลองมันลดจาก 6.34 รายวันเหลือ 4.92 ราย 21 วัน ช้ากว่า 3.16 ของกรณีวันอิสระมาก เพราะความเกาะกลุ่มเติมหางกลับเข้าไป
