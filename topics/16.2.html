16.2 Autoregressive Processes (AR)

AR(1) ให้ค่าเดือนนี้เก็บส่วนหนึ่งของค่าเดือนก่อนไว้แล้วบวกข่าวใหม่ ผลคือค่าที่ถูกดึงกลับหาค่าเฉลี่ยระยะยาวด้วยความเร็วที่บอกเป็น half-life ได้ และคำทำนายที่ความคลาดมีเพดาน

สเปรดหุ้นกู้สมมติตัวหนึ่งเข้ากับแบบจำลองรายเดือน $X_t=1.8+0.88X_{t-1}+\epsilon_t$ สมมติข่าวใหม่แต่ละเดือนเป็น Normal อิสระกัน ค่าเฉลี่ยศูนย์และ SD 9 bp วันนี้สเปรดอยู่ที่ 45 bp นักวิเคราะห์คนหนึ่งบอกว่า “ค่าคงที่คือ 1.8 bp สเปรดตอนนี้กว้างกว่าปกติ 25 เท่า” อีกคนบอกว่า “0.88 แปลว่าหายเดือนละ 12% อีก $1/0.12=8.3$ เดือนก็กลับบ้านหมด” ค่าเฉลี่ยระยะยาว เวลาที่ต้องรอ และคำทำนาย 3 เดือนข้างหน้าคือเท่าไร?

ลองตอบก่อนเปิดเฉลย

ค่าเฉลี่ยระยะยาวคือ 15 bp ไม่ใช่ 1.8 bp สเปรดจึงห่างบ้าน 30 bp ไม่ใช่ 43 bp ระยะห่างของเส้นค่าคาดหดเหลือครึ่งใน 5.42 เดือน และหดไป 90% ใน 18.0 เดือน ไม่ใช่เวลาที่สเปรดจริงต้องกลับถึง 15 bp เพราะข่าวใหม่ยังผลักให้ค่าจริงขึ้นลง คำทำนาย 3 เดือนคือ 35.44 bp แต่ช่วง 95% กว้างตั้งแต่ 8.3 ถึง 62.6 bp

ภาพรวมก่อนลงสูตร

หน้า stationarity และ ACF วัดความจำของอนุกรม หน้านี้สร้างแบบจำลองของความจำแบบที่ง่ายที่สุด: ค่าเดือนนี้เท่ากับส่วนหนึ่งของค่าเดือนก่อน บวกของที่เติมคงที่ บวกข่าวใหม่ที่ไม่มีใครรู้ล่วงหน้า ชื่อว่า autoregressive process อันดับหนึ่ง หรือ AR(1) มันเหมาะกับของที่มีแรงดึงกลับ เช่นสเปรดเครดิต ส่วนต่างของคู่หุ้นในpairs trading อัตราดอกเบี้ยระยะสั้น และระดับความผันผวน

รูปด้านล่างคือทั้งเรื่องในภาพเดียว: เส้นประคือสิ่งที่แบบจำลองคาด มันโค้งกลับหา 15 bp เร็วตอนไกลบ้านและช้าลงเมื่อใกล้ เส้นทึบคือหนึ่งเส้นทางที่ข่าวใหม่เขย่าออกจากเส้นประทุกเดือน และแถบคือช่วงที่เส้นทางจริงน่าจะอยู่ 95% ซึ่งกว้างขึ้นในช่วงแรกแล้วหยุดกว้างที่เพดาน

เราจะเดินสมการด้วยมือก่อน แล้วหาทีละอย่าง: ค่าเฉลี่ยระยะยาว ความกว้างระยะยาว คำทำนายกับ half-life ความกว้างของความคลาด และการตัดสินใจถือหุ้นกู้ จากนั้นกางสมการย้อนหลังเพื่อดูว่าข่าวเก่าจางอย่างไรและทำไมต้อง $|\phi|\lt1$ หา ACF ของมัน และสุดท้ายถามว่า $\phi$ ที่ประมาณจากข้อมูล 10 ปีคลาดได้แค่ไหน ตัวเลขสเปรดทั้งหมดเป็นค่าสมมติที่เลือกให้คำนวณง่าย

ศัพท์ที่ใช้ในหัวข้อนี้
AR(1)
แบบจำลองที่ค่าปัจจุบันขึ้นกับค่าก่อนหน้าหนึ่งงวดบวกข่าวใหม่ ตัวเลข 1 คือจำนวนงวดที่จำ AR($p$) จำ $p$ งวด ใช้แทนของที่มีแรงดึงกลับหาระดับหนึ่ง
Mean reversion
การที่ค่าซึ่งเบี่ยงจากค่าเฉลี่ยระยะยาวถูกดึงกลับทีละส่วน ใช้กำหนดว่าจะถือสถานะนานแค่ไหนและตั้งจุดตัดขาดทุนที่ใด
Innovation (shock)
ข่าวใหม่ของงวดนั้นที่คาดจากอดีตไม่ได้ ค่าเฉลี่ยศูนย์ และไม่เกี่ยวกับค่าก่อนหน้า มันคือสิ่งที่ผลักอนุกรมออกจากเส้นทางที่คาดไว้
Half-life
เวลาที่ระยะห่างจากค่าเฉลี่ยที่คาดไว้หดเหลือครึ่ง แปลง $\phi$ ที่ไม่มีหน่วยเวลาให้เป็นจำนวนเดือนหรือวันที่คนบนโต๊ะเข้าใจ
Impulse response
ผลของข่าวหนึ่งก้อนที่ยังค้างอยู่ในอนุกรมหลังผ่านไป $j$ งวด ใน AR(1) คือ $\phi^j$ ต่อข่าวหนึ่งหน่วย ใช้ดูว่าข่าวเก่าจางเร็วแค่ไหน
Random walk
กรณี $\phi=1$ ข่าวเก่าไม่เคยจาง ไม่มีค่าเฉลี่ยระยะยาวให้กลับ และความไม่แน่นอนโตไม่หยุด ใช้เป็นเส้นฐานเทียบกับ AR(1)
Yule–Walker
สมการที่เชื่อม ACF กับ parameter ของ AR ใน AR(1) คือ $\rho_k=\phi\rho_{k-1}$ ใช้ประมาณ $\phi$ จาก ACF ที่วัดได้
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$X_t$สเปรดของเดือนที่ $t$bp
$c$ของที่เติมคงที่ทุกเดือนbp ต่อเดือน
$\phi$สัดส่วนของค่าเดือนก่อนที่ยังค้างอยู่ไม่มีหน่วย
$\epsilon_t,\ \sigma$ข่าวใหม่ของเดือนที่ $t$ และ SD ของมันbp
$\mu,\ V$ค่าเฉลี่ยระยะยาว และ variance ระยะยาวbp และ bp²
$Y_t$ระยะห่างจากค่าเฉลี่ย $X_t-\mu$bp

ขั้นที่ 1 — เดินสมการด้วยมือ หกเดือนที่ไม่มีข่าว

ก่อนมีสูตรใด ป้อนตัวเลขของโจทย์เข้าสมการทีละเดือน โดยปิดข่าวใหม่ไว้ก่อน จะได้เห็นว่าสเปรดถูกดึงไปหาเลขไหน และดึงเร็วแค่ไหน

\[ \begin{aligned} X_0&=45,\\ X_h&=1.8+0.88\,X_{h-1},\\ X_1&=1.8+0.88(45)\\ &=41.400,\\ X_2&=1.8+0.88(41.4)\\ &=38.232,\\ X_3&=1.8+0.88X_2\approx35.444,\\ X_4&=1.8+0.88X_3\approx32.991,\\ X_5&=1.8+0.88X_4\approx30.832,\\ X_6&=1.8+0.88X_5\approx28.932,\\ X_h-15&=26.4,\ 23.23,\ 20.44,\\ &\quad\ 17.99,\ 15.83,\ 13.93. \end{aligned} \]

คำนวณแต่ละเดือนด้วยค่าก่อนปัดเศษ เดือนแรกเส้นค่าคาดลด 3.6 bp แต่เดือนที่หกลดแค่ 1.9 bp ยิ่งเข้าใกล้บ้าน แรงดึงยิ่งอ่อน เพราะแรงดึงเป็นสัดส่วนกับระยะห่าง นี่คือเหตุที่คำตอบ “8.3 เดือนกลับบ้านหมด” ผิด มันถือว่าลดเท่ากันทุกเดือน

สองแถวล่างคือระยะห่างจาก 15 ซึ่งเหลือ 88% ของเดือนก่อนทุกเดือนพอดี ทำไมต้อง 15? เพราะถ้าเริ่มที่ 15 จะได้ $1.8+0.88(15)=1.8+13.2=15$ อยู่กับที่ ของที่เติม 1.8 กับแรงหด 12% หักล้างกันพอดีที่จุดนี้

ขั้นที่ 2 — เขียนเป็นแบบจำลอง และเงื่อนไขที่กันไม่ให้มันระเบิด

การเดินมือปิดข่าวไว้ ของจริงมีข่าวใหม่ทุกเดือน ใส่มันกลับเข้าไปเป็นก้อนที่สาม บรรทัดแรกคือนิยามของ AR(1) บรรทัดที่สองคือสิ่งที่เราสมมติเกี่ยวกับข่าว บรรทัดที่สามคือเงื่อนไขที่การกางสมการย้อนหลังด้านล่างจะแสดงที่มา

\[ \begin{aligned} X_t&=c+\phi X_{t-1}+\epsilon_t,\\ \mathbb E[\epsilon_t]&=0,\quad\operatorname{Var}(\epsilon_t)=\sigma^2,\\ |\phi|&\lt1,\\ c&=1.8,\quad\phi=0.88,\quad\sigma=9. \end{aligned} \]

$c$ คือของที่เติมทุกเดือน $\phi X_{t-1}$ คือความจำที่ลากค่าเดือนก่อนมา 88% และ $\epsilon_t$ คือข่าวใหม่ขนาดราว 9 bp ข่าวของเดือนนี้ไม่เกี่ยวกับค่าเดือนก่อนและไม่เกี่ยวกับข่าวเดือนอื่น

$|\phi|\lt1$ คือเส้นแบ่ง ที่ $\phi=1$ ข่าวเก่าไม่เคยจาง กลายเป็น random walk ที่ $\phi=1.05$ ระยะห่างโต 5% ทุกเดือนจนระเบิด ส่วน $\phi$ ติดลบทำให้ค่าสลับขึ้นลงทุกงวด

ขั้นที่ 3 — ค่าเฉลี่ยระยะยาว: ทำไม 1.8 กลายเป็น 15

ถ้าแบบจำลองเป็น stationary ค่าเฉลี่ยต้องไม่เปลี่ยนตามเวลา เงื่อนไขนี้แก้หาค่าเฉลี่ยได้ทันทีโดยไม่ต้องรู้เส้นทางสักเส้น หาค่าเฉลี่ยทั้งสองข้างของแบบจำลอง แล้วตั้งให้ค่าเฉลี่ยสองเดือนเท่ากัน

\[ \begin{aligned} \mathbb E[X_t]&=c+\phi\,\mathbb E[X_{t-1}]+0,\\ \mathbb E[X_t]&=\mathbb E[X_{t-1}]=\mu,\\ \mu&=c+\phi\mu,\\ \mu(1-\phi)&=c,\\ \mu&=\frac{c}{1-\phi}=\frac{1.8}{0.12}=15\ \text{bp}. \end{aligned} \]

บรรทัดแรกมีของไม่รู้ค่าสองตัว คือค่าเฉลี่ยของเดือนนี้กับเดือนก่อน บรรทัดที่สองคือจุดที่ทำให้แก้ได้: stationarity บังคับให้สองตัวเท่ากัน จึงยุบเหลือตัวเดียว ถ้าไม่ stationary ก็ไม่มีค่าเดียวให้แก้ตั้งแต่ต้น

อีกมุมหนึ่ง: ของที่เติมเดือนนี้คือ 1.8 ของเดือนก่อนยังค้าง 88% คือ 1.584 ของสองเดือนก่อนค้าง 1.394 ทบกันไปเรื่อย ๆ รวมเป็น $1.8\times1/0.12=1.8\times8.333=15$ การกางสมการด้านล่างจะพิสูจน์ตัวคูณ 8.333 นี้ $c$ จึงไม่ใช่ระดับเฉลี่ย ยิ่ง $\phi$ ใกล้ 1 ตัวคูณยิ่งใหญ่

ขั้นที่ 4 — รูประยะห่าง และความกว้างระยะยาว

ลบค่าเฉลี่ยออกทั้งสองข้าง แบบจำลองจะอยู่ในรูประยะห่างที่สะอาดที่สุด แล้วใช้ตรรกะเดียวกับค่าเฉลี่ยกับความกว้าง: ถ้า stationary variance ต้องเท่ากันทุกเดือน ขั้นนี้ตอบว่าสเปรดวันนี้ห่างจากปกติกี่ SD

\[ \begin{aligned} X_t-\mu&=c+\phi X_{t-1}+\epsilon_t-\mu\\ &=(\mu-\phi\mu)+\phi X_{t-1}+\epsilon_t-\mu\\ &=\phi(X_{t-1}-\mu)+\epsilon_t,\\ \operatorname{Var}(X_t)&=\phi^2\operatorname{Var}(X_{t-1})+\sigma^2,\\ V&=\phi^2V+\sigma^2,\\ V&=\frac{\sigma^2}{1-\phi^2}=\frac{81}{1-0.7744}\\ &=\frac{81}{0.2256}=359.0\ \text{bp}^2,\\ \sqrt V&=18.95\ \text{bp},\\ z&=(45-15)/18.95=1.58. \end{aligned} \]

บรรทัดที่สองแทน $c=\mu-\phi\mu$ จากค่าเฉลี่ยระยะยาวที่เพิ่งได้ แล้ว $c$ หายไป บรรทัดที่สี่คือจุดที่ต้องระวัง: variance ของผลรวมเท่ากับผลบวกของ variance ได้เพราะข่าวเดือนนี้ไม่เกี่ยวกับค่าเดือนก่อน และตัวคูณ $\phi$ ออกมาเป็น $\phi^2$ เพราะถ้าเดือนก่อนห่าง 10 bp เดือนนี้ห่าง 8.8 bp ความกว้างหด 0.88 เท่า variance จึงหด 0.7744 เท่า

ข่าวรายเดือนแค่ 9 bp แต่ความกว้างระยะยาว 18.95 bp เพราะข่าวเก่ายังค้างอยู่ ความจำขยายค่าเฉลี่ย 8.33 เท่า แต่ขยาย SD แค่ $1/\sqrt{0.2256}=2.1$ เท่า สเปรดวันนี้อยู่เหนือค่าเฉลี่ย 1.58 SD กว้างผิดปกติแต่ยังไม่สุดโต่ง

ข้อบกพร่องที่ต้องพูดตรง ๆ: ช่วงค่าเฉลี่ย ±2 SD คือ $15\pm37.9$ หรือ −22.9 ถึง 52.9 bp ถ้าต้องการสเปรดที่เป็นบวกเสมอ ขอบล่างนี้ไม่เหมาะ ทางเลือกหนึ่งคือฟิต AR บน log ของสเปรดแล้วแปลงกลับด้วย exponential ค่าหลังแปลงกลับเป็นบวกเสมอ แต่ exponential ของค่าคาด log ไม่ใช่ค่าคาดของสเปรดโดยตรง

ขั้นที่ 5 — คำทำนายหลายเดือน และ half-life

ในรูประยะห่าง การทำนายเดือนหน้าเหลือแค่ตัวคูณ เพราะข่าวของเดือนหน้ายังไม่เกิดและค่าเฉลี่ยของมันเป็นศูนย์ ทำซ้ำ $h$ ครั้งก็ได้คำทำนาย $h$ เดือน ตั้ง $Y_t:=X_t-\mu$ ซึ่งวันนี้คือ 30 bp

\[ \begin{aligned} \mathbb E_t[Y_{t+1}]&=\phi Y_t,\\ \mathbb E_t[Y_{t+h}]&=\phi^hY_t,\\ \hat X_{t+h|t}&=\mu+\phi^h(X_t-\mu),\\ h=1:&\quad15+0.8800(30)=41.40,\\ h=3:&\quad15+0.6815(30)=35.44,\\ h=6:&\quad15+0.4644(30)=28.93,\\ h=12:&\quad15+0.2157(30)=21.47. \end{aligned} \]

ตัวเลขตรงกับการเดินมือทุกตัว สูตรปิดดีกว่าการเดินซ้ำตรงที่คำนวณ $\phi^h$ ครั้งเดียว ไม่สะสมเศษจากการปัดทุกก้าว เมื่อ $h$ โตขึ้น $\phi^h$ หดเข้าหาศูนย์ คำทำนายจึงลู่เข้า 15 bp ไม่ใช่ศูนย์ บรรทัดที่สองใช้tower property (ค่าคาดของค่าคาดที่ละเอียดกว่าคือค่าคาดเดิม) ซ้ำ $h$ ครั้ง

คำถามที่โต๊ะอยากรู้คือ “อีกนานแค่ไหน” ถามว่ากี่เดือนระยะห่างที่คาดไว้จึงเหลือครึ่ง แล้วใส่ log ทั้งสองข้างเพื่อดึงเลขชี้กำลังลงมา

\[ \begin{aligned} \phi^{h_{1/2}}&=\tfrac12,\\ h_{1/2}\ln\phi&=\ln0.5,\\ h_{1/2}&=\frac{\ln0.5}{\ln0.88}\\ &\approx\frac{-0.69315}{-0.12783}\\ &\approx5.42,\\ 0.88^5&\approx0.5277,\\ 0.88^6&\approx0.4644,\\ h_{0.9}&=\frac{\ln0.1}{\ln0.88}=18.0. \end{aligned} \]

0.88⁵ ยังเหลือเกินครึ่ง 0.88⁶ เลยครึ่งแล้ว คำตอบจึงอยู่ระหว่าง 5 กับ 6 ค่อนไปทาง 5 ตรงกับระยะห่าง 15.83 และ 13.93 bp ของการเดินมือ แถวสุดท้ายคือเวลาที่ระยะห่างหายไป 90% ซึ่งนานกว่า 8.3 เดือนของคำตอบผิดในโจทย์เปิดเกินสองเท่า

ทำไมรายงาน half-life แทน $\phi$? 0.88 รายเดือนกับ 0.88 รายวันคือคนละโลก แต่ half-life พูดเป็นเวลาเสมอ AR(1) คือแบบจำลองแรงดึงกลับในเวลาต่อเนื่อง (Ornstein–Uhlenbeck หรือ Vasicek $dX=\kappa(\mu-X)\,dt+s\,dW$) ที่สุ่มดูเดือนละครั้ง ซึ่งให้ $\phi=e^{-\kappa\Delta}$ ที่ $\Delta=1/12$ ปี จึงได้ $\kappa=-12\ln0.88=1.534$ ต่อปี นี่คือเหตุที่การปรับ Vasicek เข้ากับข้อมูลเริ่มจาก regression แบบ AR(1)

ขั้นที่ 6 — คำทำนายคลาดได้กว้างแค่ไหน

คำทำนายอย่างเดียวไม่พอ ต้องรู้ว่ามันพลาดได้กว้างแค่ไหน กางรูประยะห่าง $h$ ก้าว ส่วนที่ไม่ได้อยู่ในคำทำนายคือข่าวทุกก้อนที่ยังไม่เกิด แต่ละก้อนถูกส่งต่อผ่านความจำคนละจำนวนชั้น

\[ \begin{aligned} Y_{t+h}&=\phi^hY_t+\sum_{j=0}^{h-1}\phi^j\epsilon_{t+h-j},\\ \operatorname{Var}_t(Y_{t+h})&=\sigma^2\sum_{j=0}^{h-1}\phi^{2j}\\ &=\sigma^2\,\frac{1-\phi^{2h}}{1-\phi^2},\\ \mathrm{SD}(1)&=9.00,\\ \mathrm{SD}(2)&=9\sqrt{1+0.7744}=11.99,\\ \mathrm{SD}(3)&=9\sqrt{2.3741}=13.87,\\ \mathrm{SD}(12)&\approx18.50,\\ \mathrm{SD}(\infty)&\approx18.95,\\ 95\%:&\quad35.44\pm1.96(13.87)\\ &\approx35.44\pm27.18\\ &\to8.3\ \text{to}\ 62.6,\\ \phi=1:&\quad9\sqrt3,\ 9\sqrt6,\ 9\sqrt{12}\\ &=15.6,\ 22.0,\ 31.2. \end{aligned} \]

ข่าวแต่ละก้อนไม่เกี่ยวกัน variance จึงบวกกันได้ ตัวคูณเข้าไปใน variance เป็น $\phi^{2j}$ แล้วรวมเป็นอนุกรมเรขาคณิต ความคลาดโตเร็วช่วงแรกแล้วช้าลง และชนเพดาน 18.95 bp ซึ่งคือความกว้างระยะยาวที่หาไว้แล้ว เพราะข่าวเก่าถูกลืมไป 12% ทุกเดือน

random walk ไม่ลืมอะไรเลย ความคลาดจึงโตไม่หยุด ถึง 31.2 bp ที่ 12 เดือน ช่วง 95% ที่ 3 เดือนของ AR(1) กว้าง ±27.18 bp เกือบสามเท่าของการลดที่คาดไว้

ขั้นที่ 7 — ถือหุ้นกู้รอสเปรดแคบลงคุ้มไหม

โจทย์ให้อะไรมาบ้าง: ซื้อหุ้นกู้ที่ duration 4 ปีวันนี้ที่สเปรด 45 bp แล้วถือ 3 เดือน duration 4 แปลว่าราคาขึ้นราว 4 bp ของราคาต่อสเปรดที่แคบลง 1 bp (duration) ใช้คำทำนาย 35.44 bp และ SD ความคลาด 13.87 bp ที่เพิ่งได้ ยังไม่รวมดอกเบี้ยที่ได้ระหว่างถือและต้นทุนซื้อขาย สมมติข่าวเป็น Normal

\[ \begin{aligned} 45-35.44&=9.56\ \text{bp},\\ 4\times9.56&=38.2\ \text{bp}=0.38\%,\\ 62.62-45&=17.62\ \text{bp},\\ 4\times17.62&=70.5\ \text{bp}=0.70\%,\\ 9.56/13.87&=0.69,\\ \Phi(0.69)&=0.755. \end{aligned} \]

คำตอบ: กำไรที่คาดไว้คือ 0.38% ของราคา แต่ในฉากแย่ที่ขอบบนของช่วง 95% สเปรดกว้างขึ้น 17.6 bp ขาดทุน 0.70% การลดที่คาดไว้เท่ากับ 0.69 SD ของความคลาด โอกาสที่สเปรดอีก 3 เดือนจะต่ำกว่า 45 bp คือราว 75.5% จาก CDF ของNormal นี่คือโอกาสภายใต้แบบจำลอง ไม่ใช่หลักฐานว่ามีกำไรในตลาดจริง ต้องตรวจค่าประมาณ ต้นทุน และผลนอกชุดข้อมูลที่ฟิต ซึ่งความคลาดของ $\phi$ ด้านล่างจะทำให้ระวังมากขึ้น

ตรวจเองใน 10 วินาที: $15+0.6815\times30=15+20.44=35.44$ และ $1.96\times13.87=27.19$ ส่วนต่างหลักสุดท้ายกับ 27.18 มาจากการปัด 13.867 เป็น 13.87

ขั้นที่ 8 — กางสมการย้อนหลัง: ข่าวเก่าจางอย่างไร และที่มาของ |φ| < 1

ค่าเฉลี่ยระยะยาวหาได้ด้วยการสมมติ stationarity โดยยังไม่เคยถามว่ามัน stationary จริงไหม ขั้นนี้ตอบ: แทนสมการของเดือนก่อนเข้าไปแทน $X_{t-1}$ ซ้ำ ๆ แล้วดูว่าเหลืออะไร

\[ \begin{aligned} X_t&=c+\phi X_{t-1}+\epsilon_t\\ &=c+\phi c+\phi^2X_{t-2}\\ &\quad+\phi\epsilon_{t-1}+\epsilon_t\\ &=c\sum_{j=0}^{k-1}\phi^j+\phi^kX_{t-k}\\ &\quad+\sum_{j=0}^{k-1}\phi^j\epsilon_{t-j},\\ \sum_{j=0}^{k-1}0.88^j&=\frac{1-0.88^k}{0.12},\\ k=1,2,5:&\quad1,\ 1.88,\ 3.936,\\ k=10,20,50:&\quad6.012,\ 7.687,\ 8.319,\\ |\phi|&\lt1:\\ X_t&=\frac{c}{1-\phi}+\sum_{j=0}^{\infty}\phi^j\epsilon_{t-j}. \end{aligned} \]

หลังแทน $k$ ครั้ง ค่าวันนี้แยกเป็นสามก้อน: ของที่เติมสะสม, ค่าในอดีตไกลที่หดด้วย $\phi^k$ และข่าวทุกก้อนที่เคยเกิดถ่วงด้วยความจำ ถ้า $|\phi|\lt1$ ก้อนกลางหายไปเมื่อ $k$ โต ผลรวมของตัวคูณเข้าใกล้ $1/0.12=8.333$ ช้า ๆ และคูณ 1.8 ได้ 15 bp ตรงกับค่าเฉลี่ยระยะยาวจากอีกทาง

น้ำหนัก $\phi^j$ ของข่าวเก่าคือ impulse response: ข่าว +10 bp เมื่อ $j$ เดือนก่อนยังค้างอยู่ $10(0.88^j)$ bp วันนี้ ตามรูปด้านล่าง ถ้า $\phi=1$ ข่าวทุกก้อนมีน้ำหนัก 1 เท่ากันตลอดไป variance ของผลรวม $k$ ก้อนคือ $k\sigma^2$ โตไม่หยุด ถ้า $|\phi|\gt1$ ตัวคูณ $\phi^k$ ระเบิด ตัวหาร $1-\phi$ ที่เป็นศูนย์ตอน $\phi=1$ จึงไม่ใช่ข้อบกพร่องของสูตร มันบอกว่าไม่มีค่าเฉลี่ยระยะยาวที่ดึงเส้นทางกลับไปหา

บรรทัดสุดท้ายบอกอีกเรื่องที่สำคัญ: AR(1) คือผลรวมของข่าวทั้งหมดในอดีตที่น้ำหนักจางลงแบบเรขาคณิต หน้า MA, ARMA และ ARIMA จะเริ่มจากอีกฝั่ง คือเขียนค่าวันนี้เป็นผลรวมของข่าวไม่กี่ก้อนโดยตรง

ขั้นที่ 9 — ACF ของ AR(1) และสมการ Yule–Walker

หน้า ACF วัดความจำจากข้อมูล ถ้าข้อมูลมาจาก AR(1) จริง ACF ต้องมีรูปร่างแบบไหน? คูณรูประยะห่างด้วยระยะห่างของ $k$ เดือนก่อนแล้วหาค่าเฉลี่ย

\[ \begin{aligned} Y_tY_{t-k}&=\phi\,Y_{t-1}Y_{t-k}+\epsilon_tY_{t-k},\\ \mathbb E[\epsilon_tY_{t-k}]&=0\quad(k\ge1),\\ \gamma_k&=\phi\,\gamma_{k-1},\\ \rho_k&=\phi\,\rho_{k-1}=\phi^k,\\ \rho_1,\rho_2,\rho_3&=0.88,\ 0.7744,\ 0.6815,\\ \rho_5,\rho_6&=0.5277,\ 0.4644. \end{aligned} \]

ข่าวของเดือนนี้ไม่เกี่ยวกับอดีตจึงหายไปในบรรทัดที่สอง เหลือความสัมพันธ์ระหว่าง autocovariance ของสอง lag ติดกัน หารด้วย $\gamma_0$ แล้วไล่จาก $\rho_0=1$ ได้ ACF ที่สลายแบบเรขาคณิตด้วยอัตรา $\phi$ ตัวเดียว ข้ามครึ่งระหว่าง lag 5 กับ 6 ตรงกับ half-life ACF ของ AR(1) กับคำทำนายใช้ตัวคูณ $\phi$ ตัวเดียวกัน

อ่านกลับทางได้: วัด $\hat\rho_1$ จากข้อมูลได้ 0.88 ก็ได้ $\hat\phi=0.88$ นี่คือ Yule–Walker และเป็นเหตุผลว่าทำไม AR(1) อธิบาย ACF ของขนาดการขยับในหน้า ACF ไม่ได้: ACF นั้นลดเร็วช่วงแรกแล้วลากหางยาว ซึ่งอัตราตัวเดียวสร้างไม่ได้

ถ้าสเปรดจำสองเดือน ใช้ AR(2): $X_t=c+\phi_1X_{t-1}+\phi_2X_{t-2}+\epsilon_t$ ค่าเฉลี่ยได้ด้วยวิธีเดียวกันคือ $c/(1-\phi_1-\phi_2)$ และคูณแบบเดียวกันได้ Yule–Walker สองสมการ

\[ \begin{aligned} \rho_k&=\phi_1\rho_{k-1}+\phi_2\rho_{k-2},\\ \rho_1&=\frac{\phi_1}{1-\phi_2},\\ \phi_1=0.5,\ \phi_2=0.3:&\quad\rho_1=0.714,\\ \rho_2&=0.5(0.714)+0.3=0.657,\\ \rho_3&=0.5(0.657)+0.3(0.714)\\ &=0.543. \end{aligned} \]

บรรทัด $\rho_1$ ได้จากใส่ $k=1$ ในบรรทัดแรกพร้อม $\rho_{-1}=\rho_1$ (ACF สมมาตร) แล้วย้ายข้าง ACF ของ AR(2) ไม่ได้ลดด้วยอัตราเดียวอีกต่อไป และถ้า $\phi_2$ ติดลบมากพอจะแกว่งเป็นคลื่น ซึ่งคือสิ่งที่ Yule ใช้อธิบายรอบจุดดับบนดวงอาทิตย์ เงื่อนไข stationary ของ AR(2) คือ $\phi_1+\phi_2\lt1$, $\phi_2-\phi_1\lt1$ และ $|\phi_2|\lt1$ ตัวอย่างนี้ผ่านทั้งสามข้อ

ขั้นที่ 10 — φ ที่ประมาณจากข้อมูล 10 ปีคลาดได้แค่ไหน

ทุกตัวเลขข้างบนถือว่ารู้ $\phi=0.88$ พอดี ของจริงต้องประมาณจากข้อมูล สมมติมีข้อมูลรายเดือน 10 ปี $n=120$ เดือน $\hat\phi$ คือความชันของ OLS regression ของ $X_t$ บน $X_{t-1}$ ใช้ variance ของความชัน (variance ของ residual หารด้วยผลรวมกำลังสองของตัวแปรต้นที่หักค่าเฉลี่ยแล้ว) แล้วแทนความกว้างระยะยาว $V$

\[ \begin{aligned} \operatorname{Var}(\hat\phi)&\approx\frac{\sigma^2}{\sum(X_{t-1}-\bar X)^2}\\ &\approx\frac{\sigma^2}{nV}\\ &=\frac{\sigma^2(1-\phi^2)}{n\sigma^2}\\ &=\frac{1-\phi^2}{n},\\ \mathrm{SE}&\approx\sqrt{0.2256/120}\\ &\approx0.0434,\\ &0.88\pm1.96(0.0434)\\ &\quad\to0.795\ \text{to}\ 0.965,\\ h_{\rm low}&=\frac{\ln0.5}{\ln0.795}\approx3.0,\\ h_{\rm high}&=\frac{\ln0.5}{\ln0.965}\\ &\approx19.4. \end{aligned} \]

$\sigma^2$ บนล่างตัดกัน SE ตามสูตรประมาณนี้จึงขึ้นกับ $\phi$ กับ $n$ ไม่ขึ้นกับขนาด $\sigma$ ช่วง 95% ของ $\phi$ ดูแคบ แต่แปลเป็น half-life ได้ตั้งแต่ 3.0 ถึง 19.4 เดือน เพราะใกล้ 1 การขยับ $\phi$ นิดเดียวเปลี่ยน half-life มาก

สูตรนี้เป็นค่าประมาณสำหรับข้อมูลยาว โค้ดท้ายหน้าจึงลองจริง: สร้างประวัติสเปรด 120 เดือนจากแบบจำลองที่ $\phi=0.88$ จำนวน 2,000 ชุด แล้วฟิต $\hat\phi$ ทุกชุด ได้ค่าเฉลี่ย 0.850 ไม่ใช่ 0.88 SD 0.052 และ 90% ของชุดอยู่ระหว่าง 0.752 ถึง 0.922 half-life ที่ประมาณได้จึงอยู่ระหว่าง 2.4 ถึง 8.6 เดือน

การที่ $\hat\phi$ ต่ำกว่าจริงโดยเฉลี่ยราว 0.03 เป็นผลที่รู้กันของข้อมูลสั้นที่ต้องประมาณค่าเฉลี่ยเอง สูตรประมาณคือ $-(1+3\phi)/n=-3.64/120=-0.030$ ตรงกับการจำลอง ข้อมูล 10 ปีจึงมักบอกว่าแรงดึงกลับเร็วกว่าความจริง

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

อ่าน $c$ เป็นค่าเฉลี่ย: 1.8 กับ 15 bp ต่างกัน 8.33 เท่า และถ้าคงค่า $c$ ไว้ ค่าเฉลี่ยไวต่อ $\phi$ มาก: $\phi=0.90$ ให้ $1.8/0.10=18$ bp ส่วน $\phi=0.95$ ให้ $1.8/0.05=36$ bp ซึ่งทำให้สเปรด 45 bp แทบไม่ผิดปกติเลย รายงาน $\mu$ กับ half-life ไม่ใช่ $c$ กับ $\phi$

คิดว่าลดเท่ากันทุกเดือน: “หายเดือนละ 12% จึงหมดใน 8.3 เดือน” ผิด หลัง 8.3 เดือนระยะห่างที่คาดยังเหลือ $0.88^{8.3}=34.6\%$ หรือราว 10.4 bp เพราะ 12% คิดจากระยะห่างที่เหลือ ไม่ใช่จากระยะห่างเริ่มต้น

เชื่อ $\hat\phi$ ตัวเดียว: ช่วงกลาง 90% ของ half-life ในการจำลองข้อมูล 10 ปีอยู่ที่ 2.4 ถึง 8.6 เดือนจากแบบจำลองเดียวกัน กลยุทธ์ที่ตั้งจุดออกตาม half-life ต้องทนต่อช่วงนี้ได้ และควรรู้ว่า $\hat\phi$ จากข้อมูลสั้นมักต่ำกว่าจริง

ถือว่า parameter คงที่ตลอดไป: ปี 2008 สเปรดหุ้นกู้กว้างขึ้นหลายร้อย bp แล้วค้างอยู่นาน การเปลี่ยนระบอบและค่าเฉลี่ยระยะยาวที่เลื่อนไม่ใช่ข่าวครั้งเดียวที่จะจางตาม $\phi$ เดิม การเดิมพันว่าจะกลับหาค่าเฉลี่ยเก่าคือความเสี่ยงใหญ่ที่สุดของกลยุทธ์กลุ่มนี้ ตรวจค่าประมาณแบบเลื่อนช่วงก่อนใช้

ใช้ทำอะไรบนโต๊ะจริง

ในตัวอย่าง AR(1) นี้ ค่าเฉลี่ยระยะยาวคือ 15 bp ระยะห่างของเส้นค่าคาดหดครึ่งใน 5.4 เดือน และช่วงประมาณสอง SD ระยะยาวกว้างราว ±37 bp ใช้เป็นข้อมูลตั้งสมมติฐานและประเมินความเสี่ยง ไม่ใช่คำรับรองราคาหรือกำหนดวันออกจากสถานะ เมื่อผ่านสามเท่าของ half-life ระยะห่างของค่าคาดเหลือ $0.5^3=12.5\%$ แต่ค่าจริงอาจยังห่างมากได้ การตั้ง time stop จึงเป็นนโยบายควบคุมความเสี่ยง

ความคิดเดียวกันใช้กับสัญญาณ alpha: ถ้าผลตอบแทนที่คาดของหุ้นตัวหนึ่งเป็น AR(1) ที่ $\phi$ ต่อวัน ค่าคาดของมันอีก $s$ วันคือ $\phi^s$ เท่าของวันนี้ สัญญาณที่มี half-life สองวันต้องซื้อขายเร็ว ส่วนสัญญาณที่มี half-life สามเดือนซื้อขายช้าได้และประหยัดต้นทุน นี่คือภาษาที่ใช้คุยเรื่องalpha decay และ AR(1) ยังเป็นชิ้นส่วนของแบบจำลองอัตราดอกเบี้ยแบบ Vasicek ของ log ความผันผวน และของ ARMA ในหน้าถัดไป

โจทย์ตรวจความเข้าใจ

1. ส่วนต่างราคาของคู่หุ้นเข้ากับ AR(1) รายวันที่ $\phi=0.95$ half-life กี่วัน และ $\kappa$ ต่อปีของแบบจำลองเวลาต่อเนื่องที่ตรงกันเป็นเท่าไร (ใช้ 252 วันทำการต่อปี)?

เฉลย

$\ln0.5/\ln0.95=-0.69315/-0.05129\approx13.51$ วันทำการ ตรวจ: $0.95^{13}=0.513$ ยังเกินครึ่ง $0.95^{14}=0.488$ เลยครึ่ง ส่วน $\phi=e^{-\kappa/252}$ ให้ $\kappa=-252\ln0.95=12.93$ ต่อปี ตรวจกลับ: half-life ในเวลาต่อเนื่องคือ $\ln2/\kappa=0.0536$ ปี คูณ 252 ได้ 13.51 วันเท่าเดิม

2. AR(1) ที่ $c=2$, $\phi=0.6$, $\sigma=4$ วันนี้ค่าอยู่ที่ 15 จงหาค่าเฉลี่ยระยะยาว SD ระยะยาว คำทำนายสองงวด และ SD ของความคลาดสองงวด

เฉลย

$\mu=2/0.4=5$ และ $\sqrt V=4/\sqrt{1-0.36}=4/0.8=5$ คำทำนายคือ $5+0.6^2(15-5)=5+3.6=8.6$ SD ความคลาดคือ $4\sqrt{1+0.36}\approx4.665$ ใกล้ความกว้างระยะยาว 5 แล้ว เพราะ $\phi=0.6$ ลืมเร็ว

3. AR(1) ที่ $\phi=-0.5$ มี ACF ที่ lag 1, 2, 3 เท่าไร และเส้นทางหน้าตาแบบไหน?

เฉลย

$\rho_k=(-0.5)^k$ คือ −0.5, 0.25, −0.125 เครื่องหมายสลับทุก lag ตามแท่งส้มในรูป ACF เส้นทางซิกแซ็ก ถ้างวดนี้สูงกว่าค่าเฉลี่ย งวดหน้าคาดว่าต่ำกว่า half-life ใช้ $|\phi|$ ได้ $\ln0.5/\ln0.5=1$ งวด รูปแบบสลับแบบนี้คล้ายการเด้งของราคาระหว่าง bid กับ ask แต่หน้า MA, ARMA และ ARIMA จะแสดงว่าการเด้งเป็นความจำของข่าว ไม่ใช่ของค่า เพราะ ACF ของมันตัดเป็นศูนย์หลัง lag 1

เปิดดูโค้ด

รันใน Node.js ได้โดยไม่ติดตั้งแพ็กเกจ โค้ดปฏิเสธ $|\phi|\ge1$ ซึ่งไม่มีค่าเฉลี่ยระยะยาว ปฏิเสธระยะพยากรณ์ที่ไม่ใช่จำนวนเต็ม เดินสมการจริงเทียบกับสูตรปิด และสร้างประวัติสเปรด 2,000 ชุดด้วยเครื่องสุ่มแบบมี seed เพื่อฟิต $\hat\phi$ แล้วพิมพ์ทุกตัวเลขของหน้านี้เป็น JSON บรรทัดเดียว

function checkModel({c, phi, sigma}) {
  if (![c, phi, sigma].every(Number.isFinite)) throw new TypeError('c, phi and sigma must be finite numbers');
  if (!(Math.abs(phi) < 1)) throw new RangeError('Need |phi| < 1 for a stationary AR(1)');
  if (!(sigma > 0)) throw new RangeError('Need sigma > 0');
}
// Long-run mean and spread from "the same at every date": mu = c + phi mu, V = phi^2 V + sigma^2.
function longRun(model) {
  checkModel(model);
  const {c, phi, sigma} = model, variance = sigma * sigma / (1 - phi * phi);
  return {mean: c / (1 - phi), variance, sd: Math.sqrt(variance)};
}
function checkHorizon(h) {
  if (!Number.isInteger(h) || h < 0) throw new RangeError('Horizon must be a whole number of periods >= 0');
}
// Expected gap shrinks by phi each period; forecast error adds phi^(2j) sigma^2 for each unseen shock.
function forecast(model, x0, h) {
  checkHorizon(h);
  if (!Number.isFinite(x0)) throw new TypeError('Starting value must be finite');
  const {mean} = longRun(model), {phi, sigma} = model;
  return {mean: mean + phi ** h * (x0 - mean), sd: sigma * Math.sqrt((1 - phi ** (2 * h)) / (1 - phi * phi))};
}
function halfLife(phi) {
  if (!Number.isFinite(phi) || !(Math.abs(phi) < 1)) throw new RangeError('Need |phi| < 1 for a half-life');
  return Math.log(0.5) / Math.log(Math.abs(phi));
}
function walkWithoutNews(model, x0, periods) {
  checkModel(model); checkHorizon(periods);
  const path = [];
  let x = x0;
  for (let h = 1; h <= periods; h++) { x = model.c + model.phi * x; path.push(x); }
  return path;
}
// AR(2) autocorrelations from the Yule-Walker recursion rho_k = phi1 rho_(k-1) + phi2 rho_(k-2).
function ar2Acf(phi1, phi2, lags) {
  if (!(phi1 + phi2 < 1 && phi2 - phi1 < 1 && Math.abs(phi2) < 1)) throw new RangeError('AR(2) is not stationary');
  const rho = [1, phi1 / (1 - phi2)];
  for (let k = 2; k <= lags; k++) rho.push(phi1 * rho[k - 1] + phi2 * rho[k - 2]);
  return rho.slice(1);
}
// Least-squares fit of X_t = c + phi X_(t-1) + e_t.
function fitAR1(x) {
  if (!Array.isArray(x) || x.length < 3 || ![...x].every(Number.isFinite)) throw new TypeError('Need at least three finite values');
  const y = x.slice(1), z = x.slice(0, -1), m = y.length;
  const my = y.reduce((s, v) => s + v, 0) / m, mz = z.reduce((s, v) => s + v, 0) / m;
  let szy = 0, szz = 0;
  for (let i = 0; i < m; i++) { szy += (z[i] - mz) * (y[i] - my); szz += (z[i] - mz) ** 2; }
  if (!(szz > 0)) throw new RangeError('Lagged values are constant: phi cannot be fitted');
  const phi = szy / szz;
  return {c: my - phi * mz, phi};
}
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const radius = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = radius * Math.sin(angle);
    return radius * Math.cos(angle);
  };
}
// One simulated path from today's spread, as drawn in the overview picture.
function simulatePath(model, x0, months, seed) {
  checkModel(model); checkHorizon(months);
  const z = normals(seed), x = [x0];
  for (let t = 1; t <= months; t++) x.push(model.c + model.phi * x[t - 1] + model.sigma * z());
  return x;
}
// Many ten-year histories from the true model: how far does the fitted phi land from 0.88?
function fitSpread(model, months, paths, seed) {
  if (!Number.isInteger(months) || months < 10 || !Number.isInteger(paths) || paths < 10) throw new RangeError('Need at least 10 months and 10 paths');
  const {mean, sd} = longRun(model), z = normals(seed), fits = [];
  for (let p = 0; p < paths; p++) {
    const x = [mean + sd * z()];
    for (let t = 1; t <= months; t++) x.push(model.c + model.phi * x[t - 1] + model.sigma * z());
    fits.push(fitAR1(x).phi);
  }
  fits.sort((a, b) => a - b);
  const avg = fits.reduce((s, v) => s + v, 0) / paths;
  const spread = Math.sqrt(fits.reduce((s, v) => s + (v - avg) ** 2, 0) / (paths - 1));
  return {mean: avg, sd: spread, p05: fits[Math.floor(0.05 * paths)], p95: fits[Math.floor(0.95 * paths)], min: fits[0]};
}
// Standard Normal CDF: 0.5 plus the density integrated from 0 to z by Simpson's rule.
function normalCdf(z) {
  if (!Number.isFinite(z)) throw new TypeError('z must be finite');
  const steps = 2000, w = z / steps, f = t => Math.exp(-t * t / 2) / Math.sqrt(2 * Math.PI);
  let s = f(0) + f(z);
  for (let i = 1; i < steps; i++) s += (i % 2 ? 4 : 2) * f(i * w);
  return 0.5 + s * w / 3;
}
const spread = {c: 1.8, phi: 0.88, sigma: 9}, today = 45;
const run = longRun(spread), seSmall = Math.sqrt((1 - 0.88 ** 2) / 120);
const band = [0.88 - 1.96 * seSmall, 0.88 + 1.96 * seSmall];
const threeMonths = forecast(spread, today, 3), simulated = fitSpread(spread, 120, 2000, 2016);
const onePath = simulatePath(spread, today, 24, 69);

สิ่งที่ควรตอบได้หลังอ่าน

  • AR(1) คือของที่เติมคงที่ บวกความจำ $\phi$ บวกข่าวใหม่ และมีค่าเฉลี่ยระยะยาวเมื่อ $|\phi|\lt1$
  • ค่าเฉลี่ยคือ $c/(1-\phi)=15$ bp ไม่ใช่ $c$ ความกว้างคือ $\sigma/\sqrt{1-\phi^2}=18.95$ bp ซึ่งกว้างกว่าข่าวรายเดือน
  • ระยะห่างของค่าคาดหดด้วย $\phi^h$ มี half-life $\ln0.5/\ln\phi=5.42$ เดือน และข่าวเก่าแต่ละก้อนจางด้วย $\phi^j$ แบบเดียวกัน
  • ความคลาดของคำทำนายโตแล้วชนเพดาน ต่างจาก random walk ที่โตไม่หยุด ช่วง 95% ที่ 3 เดือนคือ 8.3 ถึง 62.6 bp
  • ACF ของ AR(1) คือ $\phi^k$ ไม่เคยตัดเป็นศูนย์ และ $\hat\phi$ จากข้อมูล 10 ปีคลาดมาก: ช่วงกลาง 90% ของ half-life ที่ประมาณได้คือ 2.4 ถึง 8.6 เดือน และเฉลี่ยต่ำกว่าจริง

หน้าถัดไป MA, ARMA และ ARIMA ถามคำถามกลับด้าน: ถ้าค่าวันนี้ไม่ได้จำค่าเมื่อวาน แต่จำข่าวของเมื่อวาน ACF จะหน้าตาอย่างไร และการเด้งของราคาระหว่าง bid กับ ask ซ่อนต้นทุนการซื้อขายไว้ใน ACF ได้อย่างไร
