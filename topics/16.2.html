16.2 Autoregressive Processes (AR)

AR(1) คือแบบจำลองที่ค่าเดือนนี้เก็บส่วนหนึ่งของค่าเดือนก่อนไว้ แล้วบวกข่าวใหม่ ค่าจึงถูกดึงกลับหาระดับปกติทีละส่วน ความเร็วของการดึงกลับบอกเป็น half-life ได้ และความคลาดของคำทำนายโตไม่เกินเพดาน

บริษัทที่อยากกู้เงินจะออกหุ้นกู้ (bond) ขายให้นักลงทุน แล้วจ่ายดอกเบี้ยให้ทุกปี บริษัทอาจล้มและไม่คืนเงิน แต่รัฐบาลแทบไม่มีโอกาสนั้น หุ้นกู้บริษัทจึงต้องให้ดอกเบี้ยสูงกว่าพันธบัตรรัฐบาลอายุเท่ากัน ส่วนที่สูงกว่านี้เรียกว่าสเปรด (credit spread) หน่วยของมันคือ bp (basis point) โดย 1 bp เท่ากับ 0.01% ต่อปี

สเปรดขึ้นลงทุกวัน ตอนตลาดกลัว สเปรดกว้างขึ้น พอตลาดหายกลัว มันค่อย ๆ แคบกลับ คนที่ซื้อหุ้นกู้ตอนสเปรดกว้างจึงอยากรู้สองเรื่อง คือสเปรดจะกลับไปที่ระดับไหน และใช้เวลานานเท่าไร

ทีมวิจัยเขียนแบบจำลองรายเดือนของสเปรดหุ้นกู้ตัวหนึ่งไว้แบบนี้ (ตัวเลขทั้งหมดในหน้านี้เป็นค่าสมมติ ตั้งให้คิดตามด้วยมือได้)

\[X_t=1.8+0.88\,X_{t-1}+\epsilon_t\]
  • $X_t$ คือสเปรดของเดือนที่ $t$ หน่วย bp
  • $0.88\,X_{t-1}$ คือ 88% ของสเปรดเดือนก่อน ที่ยังค้างมาถึงเดือนนี้
  • 1.8 bp คือของที่เติมเข้ามาเท่าเดิมทุกเดือน
  • $\epsilon_t$ คือ “ข่าวใหม่” ของเดือนนั้น ซึ่งไม่มีใครรู้ล่วงหน้า สมมติว่ามีการแจกแจงแบบ Normal (รูประฆัง) ค่าเฉลี่ยศูนย์ และ SD (standard deviation) 9 bp แปลว่าข่าวแต่ละเดือนผลักสเปรดขึ้นหรือลงราว 9 bp ข่าวแต่ละเดือนไม่เกี่ยวกัน
  • สเปรดวันนี้ $X_0=45$ bp

นักวิเคราะห์สองคนอ่านแบบจำลองนี้ไม่ตรงกัน คนแรกเห็นเลข 1.8 แล้วคิดว่ามันคือระดับปกติของสเปรด เขาจึงสรุปว่าวันนี้สเปรดกว้างกว่าปกติ $45/1.8=25$ เท่า

คนที่สองเห็นเลข 0.88 แล้วคิดว่าส่วนเกินหายไปเดือนละ $1-0.88=0.12$ หรือ 12% ของส่วนเกินตอนเริ่ม เท่ากันทุกเดือน เขาจึงสรุปว่าอีก $1/0.12=8.3$ เดือน สเปรดจะกลับสู่ระดับปกติหมด

ระดับปกติจริงคือเท่าไร ต้องรอนานแค่ไหน และอีก 3 เดือนสเปรดน่าจะอยู่ที่เท่าไร?

ลองตอบก่อนเปิดเฉลย

ทั้งสองคนผิด หน้านี้จะคำนวณทุกตัวเลขในเฉลยนี้ให้ดูทีละขั้น

ระดับปกติ (เรียกว่าค่าเฉลี่ยระยะยาว) คือ $1.8/(1-0.88)=1.8/0.12=15$ bp ไม่ใช่ 1.8 bp สเปรดวันนี้จึงสูงกว่าปกติ $45-15=30$ bp ไม่ใช่ $45-1.8=43.2$ bp

ส่วนเกิน 30 bp ไม่ได้หายเดือนละเท่ากัน มันหายเดือนละ 12% ของส่วนที่ยังเหลือ จึงหายช้าลงเรื่อย ๆ ส่วนเกินที่คาดไว้เหลือครึ่งใน 5.42 เดือน และหายไป 90% ใน 18.0 เดือน ตัวเลขนี้เป็นแค่เส้นที่คาดไว้โดยเฉลี่ย สเปรดจริงยังโดนข่าวใหม่ผลักขึ้นลงทุกเดือน

คำทำนาย 3 เดือนข้างหน้าคือ 35.44 bp แต่ช่วงที่ครอบสเปรดจริงได้ 95 ครั้งจาก 100 กว้างตั้งแต่ 8.3 ถึง 62.6 bp

ภาพรวมก่อนลงสูตร

สเปรดรายเดือนเป็นอนุกรมเวลา คือตัวเลขชุดหนึ่งที่เรียงตามเวลา หน้า stationarity และ ACF วัดว่าอนุกรมแบบนี้ “จำ” อดีตได้แค่ไหน โดยดู correlation ระหว่างค่าเดือนนี้กับค่าเมื่อ $k$ เดือนก่อน หน้านี้ไปอีกขั้น คือสร้างแบบจำลองของความจำแบบที่ง่ายที่สุด

กติกามีข้อเดียว ค่าเดือนนี้เท่ากับส่วนหนึ่งของค่าเดือนก่อน บวกของที่เติมคงที่ บวกข่าวใหม่ แบบจำลองนี้ชื่อ autoregressive process อันดับหนึ่ง หรือ AR(1) คำว่า autoregressive แปลว่าทำนายตัวเองจากค่าในอดีตของตัวเอง ส่วน “อันดับหนึ่ง” แปลว่าจำย้อนไปแค่งวดเดียว

เขียนเป็นสูตรทั่วไปได้ $X_t=c+\phi X_{t-1}+\epsilon_t$ ในโจทย์ของเรา ของที่เติมคงที่ $c=1.8$ bp สัดส่วนที่จำ $\phi=0.88$ ($\phi$ คืออักษรกรีก phi) และ SD ของข่าว $\sigma=9$ bp

AR(1) เหมาะกับของที่มีแรงดึงกลับหาระดับปกติ เช่น สเปรดหุ้นกู้ อัตราดอกเบี้ยระยะสั้น ระดับความผันผวนของตลาด และส่วนต่างราคาของหุ้นสองตัวที่มักเดินคู่กัน ซึ่งคนเทรดเดิมพันว่าส่วนต่างจะกลับ (วิธีนี้เรียกว่าpairs trading)

รูปด้านล่างเล่าทั้งเรื่องในภาพเดียว เส้นประน้ำเงินคือเส้นที่แบบจำลองคาดไว้โดยเฉลี่ย มันโค้งลงจาก 45 หา 15 bp ลงเร็วตอนที่ยังห่างมาก และช้าลงเมื่อใกล้ 15 เส้นส้มคือเส้นทางที่อาจเกิดจริงหนึ่งเส้น ข่าวใหม่ผลักมันออกจากเส้นประทุกเดือน แถบฟ้าคือช่วงที่สเปรดจริงน่าจะอยู่ข้างใน 95 ครั้งจาก 100 แถบนี้กว้างขึ้นในช่วงแรก แล้วหยุดกว้างที่ระดับหนึ่ง

เราจะเริ่มจากเดินสมการด้วยมือ แล้วหาทีละเรื่อง ได้แก่ ระดับปกติ สเปรดแกว่งรอบระดับปกติกว้างแค่ไหน คำทำนายกับ half-life คำทำนายพลาดได้แค่ไหน และควรถือหุ้นกู้รอไหม จากนั้นกางสมการย้อนหลังเพื่อดูว่าข่าวเก่าจางอย่างไร และทำไมต้องมีเงื่อนไข $|\phi|\lt1$ แล้วหา ACF ของ AR(1) ปิดท้ายด้วยคำถามว่า $\phi$ ที่ประมาณจากข้อมูลจริง 10 ปีคลาดได้แค่ไหน

ศัพท์ที่ใช้ในหัวข้อนี้
สเปรดหุ้นกู้ (credit spread)
ดอกเบี้ยที่หุ้นกู้บริษัทให้สูงกว่าพันธบัตรรัฐบาลอายุเท่ากัน เป็นค่าชดเชยที่บริษัทอาจไม่คืนเงิน ตลาดยิ่งกลัว สเปรดยิ่งกว้าง
bp (basis point)
หนึ่งในร้อยของหนึ่งเปอร์เซ็นต์ คือ 1 bp เท่ากับ 0.01% สเปรด 45 bp จึงเท่ากับ 0.45% ต่อปี
AR(1)
แบบจำลองที่ค่างวดนี้เท่ากับส่วนหนึ่งของค่างวดก่อน บวกของที่เติมคงที่ บวกข่าวใหม่ เลข 1 คือจำนวนงวดที่จำ ส่วน AR($p$) จำย้อนไป $p$ งวด
Mean reversion
การที่ค่าซึ่งห่างจากค่าเฉลี่ยระยะยาวถูกดึงกลับทีละส่วน คนเทรดใช้มันตัดสินว่าจะถือนานแค่ไหน และจะยอมขาดทุนถึงจุดไหนก่อนขายทิ้ง
Innovation (shock)
ข่าวใหม่ของงวดนั้น ซึ่งเดาจากอดีตไม่ได้ ค่าเฉลี่ยเป็นศูนย์ และไม่เกี่ยวกับค่าก่อนหน้า มันคือแรงที่ผลักอนุกรมออกจากเส้นที่คาดไว้
Stationary
อนุกรมที่ค่าเฉลี่ยและความผันผวนไม่เปลี่ยนตามเวลา วัดช่วงไหนก็ได้สถิติชุดเดียวกัน
Half-life
เวลาที่ระยะห่างจากค่าเฉลี่ยที่คาดไว้หดเหลือครึ่ง มันแปลง $\phi$ ซึ่งไม่มีหน่วยเวลา ให้เป็นจำนวนเดือนหรือวันที่คนบนโต๊ะเข้าใจ
Impulse response
ข่าวหนึ่งก้อนยังค้างอยู่ในอนุกรมเท่าไร หลังผ่านไป $j$ งวด ใน AR(1) คือ $\phi^j$ ต่อข่าวหนึ่งหน่วย ใช้ดูว่าข่าวเก่าจางเร็วแค่ไหน
Random walk
กรณี $\phi=1$ ข่าวเก่าไม่เคยจาง ไม่มีค่าเฉลี่ยระยะยาวให้กลับ และความไม่แน่นอนโตไม่หยุด ใช้เป็นเส้นฐานเทียบกับ AR(1)
ACF (autocorrelation function)
correlation ระหว่างค่างวดนี้กับค่าเมื่อ $k$ งวดก่อน เขียนว่า $\rho_k$ ระยะ $k$ งวดนี้เรียกว่า lag $k$
Yule–Walker
สมการที่เชื่อม ACF กับ parameter ของ AR ใน AR(1) คือ $\rho_k=\phi\rho_{k-1}$ ใช้ประมาณ $\phi$ จาก ACF ที่วัดได้

ขั้นที่ 1 — เดินสมการด้วยมือ หกเดือนที่ไม่มีข่าว

ก่อนจะใช้สูตรใด ลองป้อนตัวเลขของโจทย์เข้าสมการทีละเดือนด้วยมือ ข่าวใหม่มีค่าเฉลี่ยเป็นศูนย์ เราจึงตั้ง $\epsilon_t=0$ ไว้ก่อน และให้ $h$ นับเดือนจากวันนี้ ($X_0$ คือวันนี้) เส้นที่ได้คือเส้นที่คาดไว้โดยเฉลี่ย เรียกสั้น ๆ ว่าเส้นค่าคาด แล้วดูสองเรื่อง คือสเปรดถูกดึงไปหาเลขไหน และดึงเร็วแค่ไหน

\[ \begin{aligned} X_0&=45,\\ X_h&=1.8+0.88\,X_{h-1},\\ X_1&=1.8+0.88(45)\\ &=41.400,\\ X_2&=1.8+0.88(41.4)\\ &=38.232,\\ X_3&=1.8+0.88X_2\approx35.444,\\ X_4&=1.8+0.88X_3\approx32.991,\\ X_5&=1.8+0.88X_4\approx30.832,\\ X_6&=1.8+0.88X_5\approx28.932,\\ X_h-15&=26.4,\ 23.23,\ 20.44,\\ &\quad\ 17.99,\ 15.83,\ 13.93. \end{aligned} \]

แต่ละเดือนคำนวณจากค่าก่อนปัดเศษ ลองดูว่าสเปรดลดลงเดือนละเท่าไร

\[\begin{aligned}X_0-X_1&=45-41.4=3.6,\\X_5-X_6&=30.832-28.932=1.9.\end{aligned}\]

เดือนแรกลด 3.6 bp แต่เดือนที่หกลดแค่ 1.9 bp ยิ่งเข้าใกล้ระดับปกติ แรงดึงยิ่งอ่อน เพราะแรงดึงเป็นสัดส่วนกับระยะห่าง คำตอบ “อีก 8.3 เดือนกลับหมด” ผิดตรงนี้ มันถือว่าสเปรดลดเท่ากันทุกเดือน

สองแถวล่างคือระยะห่างจาก 15 bp ของแต่ละเดือน ระยะห่างนี้เหลือ 88% ของเดือนก่อนพอดีทุกเดือน เช่น $26.4\times0.88=23.23$ แล้วทำไมต้องเป็น 15? ลองเริ่มที่ 15 จะได้ $1.8+0.88(15)=1.8+13.2=15$ สเปรดอยู่กับที่ เพราะที่ 15 bp ของที่เติม 1.8 bp เท่ากับส่วนที่หดไปพอดี คือ $0.12\times15=1.8$ bp ทั้งสองจึงหักล้างกัน

ขั้นที่ 2 — เขียนเป็นแบบจำลอง และเงื่อนไขที่กันไม่ให้มันระเบิด

การเดินด้วยมือปิดข่าวไว้ แต่ของจริงมีข่าวใหม่ทุกเดือน ขั้นนี้ใส่ข่าวกลับเข้าไป แล้วเขียนแบบจำลองด้วยสัญลักษณ์ทั่วไป ซึ่งใช้ได้กับทุกอนุกรม ไม่ใช่แค่สเปรดตัวนี้ สูตรมีสามส่วน คือตัวแบบจำลอง สิ่งที่เราสมมติเกี่ยวกับข่าว และเงื่อนไขที่กันไม่ให้แบบจำลองระเบิด ที่มาของเงื่อนไขนี้จะเห็นในขั้นกางสมการย้อนหลังด้านล่าง

\[ \begin{aligned} X_t&=c+\phi X_{t-1}+\epsilon_t,\\ \mathbb E[\epsilon_t]&=0,\quad\operatorname{Var}(\epsilon_t)=\sigma^2,\\ |\phi|&\lt1,\\ c&=1.8,\quad\phi=0.88,\quad\sigma=9. \end{aligned} \]

$c$ คือของที่เติมคงที่ทุกเดือน $\phi X_{t-1}$ คือความจำ มันลากค่าเดือนก่อนมา $\phi=88\%$ ส่วน $\epsilon_t$ คือข่าวใหม่ ค่าเฉลี่ยศูนย์ และ variance $\sigma^2$ (variance คือ SD ยกกำลังสอง ที่นี่ $\sigma^2=9^2=81$ bp²) เราสมมติด้วยว่าข่าวเดือนนี้ไม่เกี่ยวกับค่าเดือนก่อน และไม่เกี่ยวกับข่าวเดือนอื่น

เงื่อนไข $|\phi|\lt1$ คือเส้นแบ่งระหว่างของที่กลับสู่ระดับปกติกับของที่ไม่กลับ ลองดูสามกรณี ถ้า $\phi=1$ ข่าวเก่าไม่เคยจาง อนุกรมกลายเป็น random walk ที่ไม่มีระดับปกติให้กลับ ถ้า $\phi=1.05$ ระยะห่างโต 5% ทุกเดือน หลัง 24 เดือนโตเป็น $1.05^{24}=3.2$ เท่าของตอนเริ่ม และโตต่อไม่หยุด ถ้า $\phi$ ติดลบ เช่น −0.5 ระยะห่างถูกคูณด้วยเลขลบทุกเดือน เครื่องหมายจึงสลับ เดือนนี้สูงกว่าปกติ เดือนหน้าคาดว่าต่ำกว่าปกติ

ขั้นที่ 3 — ค่าเฉลี่ยระยะยาว: ทำไม 1.8 กลายเป็น 15

การเดินด้วยมือชี้ว่าระดับปกติคือ 15 bp ขั้นนี้หาตัวเลขนั้นจากสูตรตรง ๆ เครื่องมือคือ stationarity ถ้าอนุกรม stationary ค่าเฉลี่ยของมันต้องเท่ากันทุกเดือน เงื่อนไขนี้พอให้แก้หาค่าเฉลี่ยได้ โดยไม่ต้องจำลองเส้นทางสักเส้น วิธีคือหาค่าเฉลี่ย (เขียนว่า $\mathbb E$) ของทั้งสองข้างของแบบจำลอง แล้วตั้งให้ค่าเฉลี่ยของเดือนนี้เท่ากับของเดือนก่อน

\[ \begin{aligned} \mathbb E[X_t]&=c+\phi\,\mathbb E[X_{t-1}]+0,\\ \mathbb E[X_t]&=\mathbb E[X_{t-1}]=\mu,\\ \mu&=c+\phi\mu,\\ \mu(1-\phi)&=c,\\ \mu&=\frac{c}{1-\phi}=\frac{1.8}{0.12}=15\ \text{bp}. \end{aligned} \]

หลังหาค่าเฉลี่ยทั้งสองข้าง ข่าวหายไปเพราะค่าเฉลี่ยของมันเป็นศูนย์ แต่สมการยังมีของที่ไม่รู้สองตัว คือค่าเฉลี่ยของเดือนนี้กับของเดือนก่อน สมการเดียวแก้หาสองตัวไม่ได้ ตรงนี้ stationarity ช่วย มันบอกว่าสองตัวนี้เท่ากัน เรียกค่าเดียวนั้นว่า $\mu$ ของที่ไม่รู้จึงเหลือตัวเดียว แล้วแก้ได้ด้วยการย้ายข้าง ถ้าอนุกรมไม่ stationary ก็ไม่มีค่าเฉลี่ยค่าเดียวให้แก้ตั้งแต่ต้น

ทำไม 1.8 จึงโตเป็น 15? ลองไล่ของที่เติมย้อนหลัง ของที่เติมเดือนนี้คือ 1.8 ของที่เติมเมื่อเดือนก่อนยังค้าง 88% ของที่เติมเมื่อสองเดือนก่อนค้าง $0.88^2$ และทบกันไปเรื่อย ๆ

\[\begin{aligned}\mu&=1.8+1.8(0.88)+1.8(0.88^2)+\dots\\&=1.8+1.584+1.394+\dots\\&=1.8\times\frac{1}{1-0.88}\\&=1.8\times8.333=15.\end{aligned}\]

ผลบวก $1+0.88+0.88^2+\dots$ เป็นอนุกรมเรขาคณิต ซึ่งรวมได้ $1/(1-0.88)$ ขั้นกางสมการย้อนหลังด้านล่างจะให้ดูว่าผลรวมนี้เข้าใกล้ 8.333 จริง ข้อสรุปคือ $c$ ไม่ใช่ระดับปกติ มันคือของที่เติมต่อเดือน ระดับปกติคือ $c$ คูณตัวคูณ $1/(1-\phi)$ และยิ่ง $\phi$ ใกล้ 1 ตัวคูณนี้ยิ่งใหญ่

ขั้นที่ 4 — รูประยะห่าง และความกว้างระยะยาว

รู้ระดับปกติแล้ว คำถามต่อไปคือสเปรดแกว่งรอบระดับนี้กว้างแค่ไหน เราต้องรู้เรื่องนี้ก่อนจะตัดสินว่า 45 bp “กว้างผิดปกติ” จริงไหม ขั้นแรกลบ $\mu$ ออกจากทั้งสองข้าง แบบจำลองจะเหลือแค่ระยะห่างจากระดับปกติ ซึ่งเขียนง่ายกว่า จากนั้นใช้ตรรกะเดียวกับขั้นค่าเฉลี่ย คือถ้า stationary variance ก็ต้องเท่ากันทุกเดือนด้วย ให้ $V$ คือ variance ระยะยาวนั้น สุดท้ายเทียบระยะห่างวันนี้กับ SD ระยะยาว $\sqrt V$ ได้ค่า $z$ ซึ่งบอกว่าวันนี้ห่างจากปกติกี่ SD

\[ \begin{aligned} X_t-\mu&=c+\phi X_{t-1}+\epsilon_t-\mu\\ &=(\mu-\phi\mu)+\phi X_{t-1}+\epsilon_t-\mu\\ &=\phi(X_{t-1}-\mu)+\epsilon_t,\\ \operatorname{Var}(X_t)&=\phi^2\operatorname{Var}(X_{t-1})+\sigma^2,\\ V&=\phi^2V+\sigma^2,\\ V&=\frac{\sigma^2}{1-\phi^2}=\frac{81}{1-0.7744}\\ &=\frac{81}{0.2256}=359.0\ \text{bp}^2,\\ \sqrt V&=18.95\ \text{bp},\\ z&=(45-15)/18.95=1.58. \end{aligned} \]

การลบ $\mu$ ทำให้ $c$ หายไป เพราะขั้นค่าเฉลี่ยให้ $\mu=c+\phi\mu$ ซึ่งแปลว่า $c=\mu-\phi\mu$ แทนลงไปแล้วเหลือแค่ $\phi$ คูณระยะห่างเดือนก่อน บวกข่าว

จุดที่ต้องระวังคือตอนหา variance มีสองเรื่อง เรื่องแรก variance ของผลบวกเท่ากับผลบวกของ variance ได้ก็เพราะข่าวเดือนนี้ไม่เกี่ยวกับค่าเดือนก่อน ถ้าเกี่ยวกันจะมี covariance โผล่มาเพิ่ม เรื่องที่สอง ตัวคูณ $\phi$ ออกมาเป็น $\phi^2$ เพราะ variance วัดเป็นหน่วยกำลังสอง ถ้าเดือนก่อนห่าง 10 bp เดือนนี้ (ก่อนนับข่าว) ห่าง $0.88\times10=8.8$ bp ความกว้างหด 0.88 เท่า variance จึงหด $0.88^2=0.7744$ เท่า

ข่าวรายเดือนผลักแค่ราว 9 bp แต่ SD ระยะยาวคือ 18.95 bp ทำไมกว้างกว่า? เพราะข่าวเก่ายังค้างอยู่ ทบกับข่าวใหม่ ความจำขยายค่าเฉลี่ย $1/0.12=8.33$ เท่า แต่ขยาย SD แค่ $1/\sqrt{0.2256}=2.1$ เท่า สเปรดวันนี้อยู่เหนือระดับปกติ 1.58 SD จึงกว้างผิดปกติ แต่ยังไม่ถึงขั้นสุดโต่ง

จุดอ่อนที่ต้องพูดตรง ๆ คือช่วงระดับปกติ ±2 SD ซึ่งเท่ากับ $15\pm2(18.95)=15\pm37.9$ หรือ −22.9 ถึง 52.9 bp แต่สเปรดจริงแทบไม่เคยติดลบ ขอบล่างนี้จึงใช้ไม่ได้ ทางแก้หนึ่งคือฟิต AR(1) กับ log ของสเปรด แล้วแปลงกลับด้วย exponential ค่าที่แปลงกลับเป็นบวกเสมอ แต่ต้องระวังหนึ่งเรื่อง exponential ของค่าคาดของ log ไม่เท่ากับค่าคาดของสเปรด

ขั้นที่ 5 — คำทำนายหลายเดือน และ half-life

ตอนนี้ตอบคำถามที่สามของโจทย์ได้แล้ว คืออีก $h$ เดือนสเปรดน่าจะอยู่ที่เท่าไร ตั้งชื่อระยะห่างจากระดับปกติว่า $Y_t=X_t-\mu$ วันนี้ $Y_t=45-15=30$ bp ในรูประยะห่าง แบบจำลองคือ $Y_{t+1}=\phi Y_t+\epsilon_{t+1}$ ข่าวของเดือนหน้ายังไม่เกิด และค่าเฉลี่ยของมันเป็นศูนย์ คำทำนายเดือนหน้าจึงเหลือแค่ $\phi$ คูณระยะห่างวันนี้ ทำซ้ำ $h$ ครั้งก็ได้คำทำนาย $h$ เดือน ในสูตร $\mathbb E_t$ คือค่าคาดเมื่อรู้ข้อมูลถึงเดือน $t$ และ $\hat X_{t+h|t}$ คือคำทำนายสเปรดอีก $h$ เดือน

\[ \begin{aligned} \mathbb E_t[Y_{t+1}]&=\phi Y_t,\\ \mathbb E_t[Y_{t+h}]&=\phi^hY_t,\\ \hat X_{t+h|t}&=\mu+\phi^h(X_t-\mu),\\ h=1:&\quad15+0.8800(30)=41.40,\\ h=3:&\quad15+0.6815(30)=35.44,\\ h=6:&\quad15+0.4644(30)=28.93,\\ h=12:&\quad15+0.2157(30)=21.47. \end{aligned} \]

ตัวเลขตรงกับการเดินด้วยมือทุกตัว แต่สูตรนี้ดีกว่าตรงที่คำนวณ $\phi^h$ ครั้งเดียวจบ ไม่ต้องเดินทีละเดือน และไม่สะสมเศษจากการปัดทุกก้าว เมื่อ $h$ โตขึ้น $\phi^h$ หดเข้าหาศูนย์ คำทำนายจึงเข้าใกล้ 15 bp ไม่ใช่ศูนย์

ก้าวที่ต้องมีเหตุผลคือจาก 1 เดือนไปเป็น $h$ เดือน เราทำนายเดือนที่สองจากคำทำนายเดือนแรก ซึ่งทำได้เพราะtower property กฎนี้บอกว่า ค่าคาดวันนี้ของ “ค่าคาดที่เราจะมีในเดือนหน้า” เท่ากับค่าคาดวันนี้ตรง ๆ ใช้กฎนี้ซ้ำ $h$ ครั้ง ตัวคูณ $\phi$ จึงทบกันเป็น $\phi^h$

คนบนโต๊ะอยากรู้ว่า “อีกนานแค่ไหน” จึงถามแบบนี้ ต้องผ่านไปกี่เดือน ระยะห่างที่คาดไว้จึงเหลือครึ่ง จำนวนเดือนนั้นเรียกว่า half-life เขียนว่า $h_{1/2}$ ระยะห่างที่คาดไว้คือ $\phi^h$ เท่าของวันนี้ จึงตั้ง $\phi^{h_{1/2}}=\tfrac12$ แล้วใส่ log ทั้งสองข้าง เพื่อดึงเลขชี้กำลังลงมาเป็นตัวคูณ วิธีเดียวกันใช้หาเวลาที่ระยะห่างหายไป 90% (เหลือ 10%) ซึ่งเขียนว่า $h_{0.9}$

\[ \begin{aligned} \phi^{h_{1/2}}&=\tfrac12,\\ h_{1/2}\ln\phi&=\ln0.5,\\ h_{1/2}&=\frac{\ln0.5}{\ln0.88}\\ &\approx\frac{-0.69315}{-0.12783}\\ &\approx5.42,\\ 0.88^5&\approx0.5277,\\ 0.88^6&\approx0.4644,\\ h_{0.9}&=\frac{\ln0.1}{\ln0.88}=18.0. \end{aligned} \]

ตรวจด้วยกำลังที่เป็นจำนวนเต็ม $0.88^5=0.5277$ ยังเกินครึ่ง แต่ $0.88^6=0.4644$ ต่ำกว่าครึ่งแล้ว คำตอบ 5.42 จึงอยู่ระหว่าง 5 กับ 6 ค่อนไปทาง 5 ตรงกับการเดินด้วยมือ ที่ระยะห่างเดือนที่ 5 คือ 15.83 bp (ยังเกินครึ่งของ 30) และเดือนที่ 6 คือ 13.93 bp (ต่ำกว่าครึ่งแล้ว) ส่วนเวลาที่ระยะห่างหายไป 90% คือ 18.0 เดือน นานกว่า 8.3 เดือนของนักวิเคราะห์คนที่สองเกินสองเท่า

ทำไมรายงาน half-life แทน $\phi$? เพราะ $\phi$ ไม่มีหน่วยเวลา $\phi=0.88$ ของข้อมูลรายเดือนกับ $\phi=0.88$ ของข้อมูลรายวันคือแรงดึงคนละขนาดกันเลย แต่ half-life พูดเป็นเวลาเสมอ

มีอีกเหตุผลหนึ่ง AR(1) คือแบบจำลองแรงดึงกลับในเวลาต่อเนื่องที่เราสุ่มดูเดือนละครั้ง แบบจำลองนั้นชื่อ Ornstein–Uhlenbeck หรือ Vasicek เขียนว่า $dX=\kappa(\mu-X)\,dt+s\,dW$ โดย $\kappa$ คือความเร็วดึงกลับต่อปี และ $s\,dW$ คือแรงสุ่ม ถ้าดูทุก $\Delta$ ปี ระยะห่างจะหดเป็น $\phi=e^{-\kappa\Delta}$ เท่า ข้อมูลรายเดือนมี $\Delta=1/12$ ปี จึงได้ $\kappa=-12\ln0.88=12\times0.12783=1.534$ ต่อปี นี่คือเหตุที่การปรับ Vasicek เข้ากับข้อมูลเริ่มจาก regression แบบ AR(1)

ขั้นที่ 6 — คำทำนายคลาดได้กว้างแค่ไหน

คำทำนาย 35.44 bp เป็นแค่ค่าเฉลี่ย สเปรดจริงจะพลาดจากมันไปเท่าไร? ส่วนที่คำทำนายมองไม่เห็นคือข่าวทุกก้อนที่ยังไม่เกิด ระหว่างวันนี้ถึงเดือน $t+h$ วิธีหาคือกางรูประยะห่างออก $h$ ก้าว ข่าวที่มาถึงเร็วถูกคูณด้วย $\phi$ หลายรอบกว่า เพราะมันต้องผ่านความจำหลายเดือนกว่าจะถึงปลายทาง ในสูตร $\operatorname{Var}_t$ คือ variance เมื่อรู้ข้อมูลถึงเดือน $t$ และ $\mathrm{SD}(h)$ คือ SD ของความคลาดเมื่อทำนายไป $h$ เดือน ช่วง 95% คือคำทำนาย $\pm1.96\,\mathrm{SD}(h)$ เพราะใน Normal ค่าอยู่ห่างค่าเฉลี่ยไม่เกิน 1.96 SD ด้วยโอกาส 95%

\[ \begin{aligned} Y_{t+h}&=\phi^hY_t+\sum_{j=0}^{h-1}\phi^j\epsilon_{t+h-j},\\ \operatorname{Var}_t(Y_{t+h})&=\sigma^2\sum_{j=0}^{h-1}\phi^{2j}\\ &=\sigma^2\,\frac{1-\phi^{2h}}{1-\phi^2},\\ \mathrm{SD}(1)&=9.00,\\ \mathrm{SD}(2)&=9\sqrt{1+0.7744}=11.99,\\ \mathrm{SD}(3)&=9\sqrt{2.3741}=13.87,\\ \mathrm{SD}(12)&\approx18.50,\\ \mathrm{SD}(\infty)&\approx18.95,\\ 95\%:&\quad35.44\pm1.96(13.87)\\ &\approx35.44\pm27.18\\ &\to8.3\ \text{to}\ 62.6,\\ \phi=1:&\quad9\sqrt3,\ 9\sqrt6,\ 9\sqrt{12}\\ &=15.6,\ 22.0,\ 31.2. \end{aligned} \]

ส่วนที่ไม่รู้คือผลรวมของข่าว $h$ ก้อน ข่าวแต่ละก้อนไม่เกี่ยวกัน variance ของผลรวมจึงเท่ากับผลรวมของ variance ข่าวที่ถูกคูณด้วย $\phi^j$ มี variance $\phi^{2j}\sigma^2$ ด้วยเหตุผลเดียวกับขั้นความกว้างระยะยาว ผลรวม $1+\phi^2+\phi^4+\dots$ เป็นอนุกรมเรขาคณิต จึงยุบเป็นเศษส่วนได้

ดูตัวเลข ความคลาดโตเร็วช่วงแรก จาก 9 เป็น 11.99 และ 13.87 bp แล้วโตช้าลง และชนเพดาน 18.95 bp ซึ่งคือ SD ระยะยาวจากขั้นก่อน มันหยุดโตเพราะข่าวเก่าถูกลืมไป 12% ทุกเดือน ข่าวใหม่ที่เข้ามาจึงไปแทนที่ข่าวเก่าที่จางหาย ไม่ได้ทับถมไปเรื่อย ๆ

random walk ($\phi=1$) ไม่ลืมอะไรเลย SD ของความคลาดคือ $9\sqrt h$ ซึ่งโตไม่หยุด ถึง 31.2 bp ที่ 12 เดือน ส่วนช่วง 95% ที่ 3 เดือนของ AR(1) กว้าง ±27.18 bp ขณะที่การลดที่คาดไว้มีแค่ $45-35.44=9.56$ bp ช่วงนี้จึงกว้างเกือบสามเท่าของการลด ($27.18/9.56=2.8$)

ขั้นที่ 7 — ถือหุ้นกู้รอสเปรดแคบลงคุ้มไหม

สมมติคุณซื้อหุ้นกู้ตัวนี้วันนี้ ตอนสเปรด 45 bp แล้วถือไว้ 3 เดือน ถ้าสเปรดแคบลง ราคาหุ้นกู้จะขึ้น เพราะตลาดยอมรับดอกเบี้ยต่ำลง หุ้นกู้ที่จ่ายดอกเบี้ยเท่าเดิมจึงมีค่ามากขึ้น ถ้าสเปรดกว้างขึ้น ราคาจะลง คำถามคือ ถือรอแบบนี้คุ้มไหม

  • duration $D=4$ ปี คือตัวเลขที่บอกว่าราคาหุ้นกู้ไวต่อสเปรดแค่ไหน สเปรดแคบลง 1 bp ราคาขึ้นราว $D\times1=4$ bp ของราคา (รายละเอียดอยู่ในหน้า duration)
  • คำทำนายสเปรดอีก 3 เดือน 35.44 bp และ SD ความคลาด $\mathrm{SD}(3)=13.87$ bp จากสองขั้นก่อน
  • ยังไม่รวมดอกเบี้ยที่ได้ระหว่างถือ และต้นทุนซื้อขาย
  • ข่าวเป็น Normal ตามที่สมมติไว้

เราคำนวณสามเรื่อง คือกำไรที่คาดไว้ ขาดทุนในฉากแย่ (สเปรดไปอยู่ขอบบนของช่วง 95% คือ 62.62 bp) และโอกาสที่สเปรดจะแคบลงจริง กติกาที่ใช้คือ ราคาเปลี่ยนไปราว $D$ คูณจำนวน bp ที่สเปรดเปลี่ยน

\[ \begin{aligned} 45-35.44&=9.56\ \text{bp},\\ 4\times9.56&=38.2\ \text{bp}=0.38\%,\\ 62.62-45&=17.62\ \text{bp},\\ 4\times17.62&=70.5\ \text{bp}=0.70\%,\\ 9.56/13.87&=0.69,\\ \Phi(0.69)&=0.755. \end{aligned} \]

คำตอบ: ถ้าสเปรดเป็นไปตามคำทำนาย มันแคบลง 9.56 bp และราคาขึ้นราว 0.38% แต่ในฉากแย่ที่ขอบบนของช่วง 95% สเปรดกว้างขึ้น 17.62 bp และขาดทุนราว 0.70% ขาดทุนในฉากแย่จึงเกือบสองเท่าของกำไรที่คาดไว้

โอกาสได้กำไรคิดอย่างนี้ สเปรดอีก 3 เดือนจะต่ำกว่า 45 bp ก็ต่อเมื่อความคลาดไม่ดันมันขึ้นเกิน 9.56 bp เหนือคำทำนาย ระยะนี้คือ $9.56/13.87=0.69$ SD จาก CDF ของ Normal (โอกาสที่ค่าแบบ Normal ค่าเฉลี่ย 0 SD 1 ต่ำกว่า 0.69) ได้ $\Phi(0.69)=0.755$ หรือราว 75.5%

ตัวเลขนี้เป็นโอกาสภายใต้แบบจำลอง ไม่ใช่หลักฐานว่าตลาดจริงให้กำไร ก่อนใช้ต้องตรวจว่าประมาณ $\phi$ ได้แม่นแค่ไหน รวมต้นทุนซื้อขาย และทดสอบกับข้อมูลที่ไม่ได้ใช้ฟิต ขั้นความคลาดของ $\phi$ ด้านล่างจะทำให้ต้องระวังมากขึ้นอีก

ตรวจเองใน 10 วินาที: $15+0.6815\times30=15+20.44=35.44$ และ $1.96\times13.87=27.19$ ต่างจาก 27.18 ในหลักสุดท้าย เพราะขั้นก่อนใช้ SD ก่อนปัด คือ 13.867

ขั้นที่ 8 — กางสมการย้อนหลัง: ข่าวเก่าจางอย่างไร และที่มาของ |φ| < 1

ในขั้นค่าเฉลี่ย เราสมมติว่าอนุกรม stationary แล้วหาค่าเฉลี่ยออกมา แต่ยังไม่เคยถามว่ามัน stationary จริงไหม และเมื่อไร ขั้นนี้ตอบคำถามนั้น วิธีคือเอาสมการของเดือนก่อนมาใส่แทน $X_{t-1}$ แล้วทำซ้ำอีกหลายรอบ รวม $k$ รอบ จากนั้นดูว่าเหลืออะไร

\[ \begin{aligned} X_t&=c+\phi X_{t-1}+\epsilon_t\\ &=c+\phi c+\phi^2X_{t-2}\\ &\quad+\phi\epsilon_{t-1}+\epsilon_t\\ &=c\sum_{j=0}^{k-1}\phi^j+\phi^kX_{t-k}\\ &\quad+\sum_{j=0}^{k-1}\phi^j\epsilon_{t-j},\\ \sum_{j=0}^{k-1}0.88^j&=\frac{1-0.88^k}{0.12},\\ k=1,2,5:&\quad1,\ 1.88,\ 3.936,\\ k=10,20,50:&\quad6.012,\ 7.687,\ 8.319,\\ |\phi|&\lt1:\\ X_t&=\frac{c}{1-\phi}+\sum_{j=0}^{\infty}\phi^j\epsilon_{t-j}. \end{aligned} \]

หลังแทน $k$ รอบ ค่าวันนี้แยกเป็นสามก้อน ก้อนแรกคือของที่เติมสะสมมา $k$ เดือน ก้อนกลางคือค่าเมื่อ $k$ เดือนก่อน ซึ่งหดด้วย $\phi^k$ ก้อนสุดท้ายคือข่าวทุกก้อนที่เคยเกิด แต่ละก้อนถ่วงด้วยความจำ $\phi^j$

ถ้า $|\phi|\lt1$ ก้อนกลางหายไปเมื่อ $k$ โต เพราะ $\phi^k$ เข้าใกล้ศูนย์ ค่าวันนี้จึงไม่ขึ้นกับจุดเริ่มต้นอีกต่อไป ผลรวมของตัวคูณในก้อนแรกเข้าใกล้ $1/0.12=8.333$ ช้า ๆ (ที่ $k=50$ ได้ 8.319) และ $1.8\times8.333=15$ bp ตรงกับค่าเฉลี่ยระยะยาวที่ได้จากอีกทาง

น้ำหนัก $\phi^j$ ของข่าวเก่าเรียกว่า impulse response ตัวอย่างเช่น ข่าว +10 bp เมื่อ $j$ เดือนก่อนยังค้างอยู่ $10(0.88^j)$ bp วันนี้ ตามรูปด้านล่าง ถ้า $\phi=1$ ข่าวทุกก้อนมีน้ำหนัก 1 ตลอดไป variance ของผลรวม $k$ ก้อนจึงเป็น $k\sigma^2$ ซึ่งโตไม่หยุด ถ้า $|\phi|\gt1$ ตัวคูณ $\phi^k$ ระเบิด ดังนั้นตัวหาร $1-\phi$ ที่เป็นศูนย์ตอน $\phi=1$ ไม่ใช่ข้อบกพร่องของสูตร มันกำลังบอกว่าไม่มีระดับปกติให้เส้นทางกลับไปหา

แถวสุดท้ายบอกอีกเรื่องที่สำคัญ AR(1) คือผลรวมของข่าวทั้งหมดในอดีต โดยน้ำหนักจางลงแบบเรขาคณิต หน้า MA, ARMA และ ARIMA จะเริ่มจากอีกฝั่ง คือเขียนค่าวันนี้เป็นผลรวมของข่าวไม่กี่ก้อนโดยตรง

ขั้นที่ 9 — ACF ของ AR(1) และสมการ Yule–Walker

หน้า ACF วัดความจำจากข้อมูล โดยดู correlation ระหว่างค่าเดือนนี้กับค่าเมื่อ $k$ เดือนก่อน (เรียกว่า lag $k$) ถ้าข้อมูลมาจาก AR(1) จริง ACF ที่วัดได้ควรหน้าตาแบบไหน? วิธีหาคือคูณรูประยะห่างทั้งสองข้างด้วยระยะห่างเมื่อ $k$ เดือนก่อน $Y_{t-k}$ แล้วหาค่าเฉลี่ย ค่าเฉลี่ยของผลคูณนี้เรียกว่า autocovariance $\gamma_k$ เมื่อหารด้วย variance $\gamma_0$ จะได้ ACF คือ $\rho_k=\gamma_k/\gamma_0$

\[ \begin{aligned} Y_tY_{t-k}&=\phi\,Y_{t-1}Y_{t-k}+\epsilon_tY_{t-k},\\ \mathbb E[\epsilon_tY_{t-k}]&=0\quad(k\ge1),\\ \gamma_k&=\phi\,\gamma_{k-1},\\ \rho_k&=\phi\,\rho_{k-1}=\phi^k,\\ \rho_1,\rho_2,\rho_3&=0.88,\ 0.7744,\ 0.6815,\\ \rho_5,\rho_6&=0.5277,\ 0.4644. \end{aligned} \]

ข่าวของเดือนนี้ไม่เกี่ยวกับอดีต ค่าเฉลี่ยของ $\epsilon_tY_{t-k}$ จึงเป็นศูนย์และหายไป ที่เหลือบอกว่า autocovariance ของสอง lag ที่ติดกันต่างกัน $\phi$ เท่า หารด้วย $\gamma_0$ แล้วไล่จาก $\rho_0=1$ ได้ $\rho_k=\phi^k$ ACF จึงลดแบบเรขาคณิตด้วยอัตรา $\phi$ ตัวเดียว ตัวเลขเหมือนตัวคูณของคำทำนายเป๊ะ เพราะใช้ $\phi$ ตัวเดียวกัน ACF ข้ามครึ่งระหว่าง lag 5 กับ 6 ตรงกับ half-life 5.42 เดือน

อ่านกลับทางก็ได้ ถ้าวัด $\hat\rho_1$ จากข้อมูลได้ 0.88 ก็ประมาณได้ว่า $\hat\phi=0.88$ วิธีนี้ชื่อ Yule–Walker มันยังอธิบายด้วยว่าทำไม AR(1) ใช้กับ ACF ของขนาดการขยับของราคาในหน้า ACF ไม่ได้ ACF นั้นลดเร็วช่วงแรกแล้วลากหางยาว ซึ่งอัตราลดตัวเดียวสร้างรูปแบบนั้นไม่ได้

ถ้าสเปรดจำย้อนไปสองเดือน ใช้ AR(2) ซึ่งเขียนว่า $X_t=c+\phi_1X_{t-1}+\phi_2X_{t-2}+\epsilon_t$ ค่าเฉลี่ยหาด้วยวิธีเดียวกันได้ $\mu=c/(1-\phi_1-\phi_2)$ และคูณด้วย $Y_{t-k}$ แบบเดียวกันได้สมการ Yule–Walker ของ AR(2) ตัวอย่างข้างล่างใช้ค่าสมมติ $\phi_1=0.5$ และ $\phi_2=0.3$

\[ \begin{aligned} \rho_k&=\phi_1\rho_{k-1}+\phi_2\rho_{k-2},\\ \rho_1&=\frac{\phi_1}{1-\phi_2},\\ \phi_1=0.5,\ \phi_2=0.3:&\quad\rho_1=0.714,\\ \rho_2&=0.5(0.714)+0.3=0.657,\\ \rho_3&=0.5(0.657)+0.3(0.714)\\ &=0.543. \end{aligned} \]

$\rho_1$ หาอย่างนี้ ใส่ $k=1$ ลงในแถวแรก ได้ $\rho_1=\phi_1\rho_0+\phi_2\rho_{-1}$ ACF สมมาตร คือ $\rho_{-1}=\rho_1$ และ $\rho_0=1$ จึงได้ $\rho_1=\phi_1+\phi_2\rho_1$ ย้ายข้างแล้วได้ $\rho_1=\phi_1/(1-\phi_2)=0.5/0.7=0.714$

ACF ของ AR(2) ไม่ได้ลดด้วยอัตราเดียวอีกต่อไป และถ้า $\phi_2$ ติดลบมากพอ ACF จะแกว่งเป็นคลื่น Yule ใช้ลักษณะนี้อธิบายรอบของจุดดับบนดวงอาทิตย์ เงื่อนไข stationary ของ AR(2) มีสามข้อ คือ $\phi_1+\phi_2\lt1$, $\phi_2-\phi_1\lt1$ และ $|\phi_2|\lt1$ ตัวอย่างนี้ผ่านทั้งสามข้อ เพราะ $0.5+0.3=0.8$, $0.3-0.5=-0.2$ และ $|0.3|=0.3$ ล้วนน้อยกว่า 1

ขั้นที่ 10 — φ ที่ประมาณจากข้อมูล 10 ปีคลาดได้แค่ไหน

ทุกตัวเลขข้างบนถือว่ารู้ $\phi=0.88$ พอดี แต่ในงานจริงไม่มีใครบอก $\phi$ มาให้ ต้องประมาณจากข้อมูลย้อนหลัง สมมติมีข้อมูลรายเดือน 10 ปี คือ $n=12\times10=120$ เดือน ค่าประมาณ $\hat\phi$ คือความชันของเส้น OLS regression เมื่อใช้ $X_t$ เป็นตัวแปรตาม และ $X_{t-1}$ เป็นตัวแปรต้น

คำถามคือ $\hat\phi$ คลาดจาก 0.88 ได้แค่ไหน ขนาดความคลาดนี้วัดด้วย SE (standard error) คือ SD ของค่าประมาณ ถ้าเก็บข้อมูลใหม่หลายชุดแล้วประมาณซ้ำ เราใช้สูตร variance ของความชันจาก OLS คือ variance ของ residual หารด้วยผลรวมกำลังสองของตัวแปรต้นที่หักค่าเฉลี่ยแล้ว ผลรวมกำลังสองนั้นมีราว $n$ พจน์ แต่ละพจน์เฉลี่ยเท่ากับ variance ระยะยาว $V$ จึงแทนด้วย $nV$ ได้

\[ \begin{aligned} \operatorname{Var}(\hat\phi)&\approx\frac{\sigma^2}{\sum(X_{t-1}-\bar X)^2}\\ &\approx\frac{\sigma^2}{nV}\\ &=\frac{\sigma^2(1-\phi^2)}{n\sigma^2}\\ &=\frac{1-\phi^2}{n},\\ \mathrm{SE}&\approx\sqrt{0.2256/120}\\ &\approx0.0434,\\ &0.88\pm1.96(0.0434)\\ &\quad\to0.795\ \text{to}\ 0.965,\\ h_{\rm low}&=\frac{\ln0.5}{\ln0.795}\approx3.0,\\ h_{\rm high}&=\frac{\ln0.5}{\ln0.965}\\ &\approx19.4. \end{aligned} \]

$\sigma^2$ บนเศษกับบนส่วนตัดกันหมด SE ตามสูตรนี้จึงขึ้นกับ $\phi$ กับ $n$ เท่านั้น ไม่ขึ้นกับขนาดของข่าว ช่วง 95% ของ $\phi$ คือ 0.795 ถึง 0.965 ดูแคบ แต่เมื่อแปลงเป็น half-life กลับกว้างตั้งแต่ 3.0 ถึง 19.4 เดือน ทำไม? เพราะ half-life คือ $\ln0.5/\ln\phi$ และตัวหาร $\ln\phi$ เข้าใกล้ศูนย์เมื่อ $\phi$ ใกล้ 1 การขยับ $\phi$ นิดเดียวแถว 1 จึงเปลี่ยน half-life มาก

สูตรนี้เป็นค่าประมาณที่ใช้ได้ดีเมื่อข้อมูลยาว แล้ว 120 เดือนยาวพอไหม? โค้ดท้ายหน้าทดลองจริง โดยสร้างประวัติสเปรด 120 เดือนจากแบบจำลองที่ $\phi=0.88$ จำนวน 2,000 ชุด ฟิต $\hat\phi$ ทุกชุด แล้วดูว่าค่าที่ได้กระจายอย่างไร ผลคือ

  • ค่าเฉลี่ยของ $\hat\phi$ คือ 0.850 ไม่ใช่ 0.88
  • SD ของ $\hat\phi$ คือ 0.052 กว้างกว่า SE จากสูตรซึ่งได้ 0.0434
  • 90% ของชุดอยู่ระหว่าง 0.752 ถึง 0.922 แปลงเป็น half-life ได้ 2.4 ถึง 8.6 เดือน (คิดจากค่าก่อนปัด $\ln0.5/\ln0.7525=2.4$ และ $\ln0.5/\ln0.9222=8.6$)

ทำไม $\hat\phi$ จึงต่ำกว่าจริงโดยเฉลี่ย? เหตุหลักคือข้อมูลสั้นต้องใช้ค่าเฉลี่ยที่คำนวณจากข้อมูลชุดเดียวกันนั้นเอง ค่าเฉลี่ยนี้อยู่ใกล้เส้นทางที่เกิดจริงเกินไป เส้นทางจึงดูเหมือนข้ามค่าเฉลี่ยบ่อยและกลับเร็วกว่าความจริง สูตรประมาณขนาดของความเอียงนี้ (เรียกว่า bias) คือ

\[\begin{aligned}\text{bias}&\approx-\frac{1+3\phi}{n}\\&=-\frac{1+3(0.88)}{120}\\&=-\frac{3.64}{120}=-0.030,\end{aligned}\]

ตรงกับการจำลอง ซึ่งได้ $0.850-0.88=-0.030$ ข้อมูล 10 ปีจึงมักบอกว่าแรงดึงกลับเร็วกว่าความจริง และ half-life สั้นกว่าความจริง

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

อ่าน $c$ เป็นค่าเฉลี่ย: $c$ คือของที่เติมต่อเดือน ไม่ใช่ระดับปกติ ค่าที่ผิดคือ $c=1.8$ bp ค่าที่ถูกคือ $\mu=c/(1-\phi)=1.8/0.12=15$ bp ต่างกัน 8.33 เท่า ที่อันตรายกว่าคือ ถ้า $c$ คงเดิม ค่าเฉลี่ยไวต่อ $\phi$ มาก $\phi=0.90$ ให้ $\mu=1.8/0.10=18$ bp ส่วน $\phi=0.95$ ให้ $\mu=1.8/0.05=36$ bp ซึ่งทำให้สเปรด 45 bp แทบไม่ผิดปกติเลย จึงควรรายงาน $\mu$ กับ half-life แทน $c$ กับ $\phi$

คิดว่าลดเท่ากันทุกเดือน: 12% คิดจากระยะห่างที่ยังเหลือ ไม่ใช่จากระยะห่างตอนเริ่ม คำตอบที่ผิดคือ “หมดใน $1/0.12=8.3$ เดือน” ค่าที่ถูกคือ หลัง 8.3 เดือน ระยะห่างที่คาดไว้ยังเหลือ $0.88^{8.3}=0.346$ หรือ 34.6% ของ 30 bp คือ $0.346\times30=10.4$ bp

เชื่อ $\hat\phi$ ตัวเดียว: $\hat\phi$ จากข้อมูล 10 ปีคลาดได้มาก ถ้าเชื่อ $\hat\phi=0.88$ จะได้ half-life 5.42 เดือนค่าเดียว แต่การจำลองจากแบบจำลองเดียวกันให้ช่วงกลาง 90% ของ half-life ตั้งแต่ 2.4 ถึง 8.6 เดือน กลยุทธ์ที่ตั้งจุดขายตาม half-life ต้องทนช่วงนี้ได้ และต้องจำว่า $\hat\phi$ จากข้อมูลสั้นมักต่ำกว่าจริงราว 0.03

ถือว่า parameter คงที่ตลอดไป: ระดับปกติเองก็เลื่อนได้ ปี 2008 สเปรดหุ้นกู้กว้างขึ้นหลายร้อย bp แล้วค้างอยู่นาน นี่ไม่ใช่ข่าวครั้งเดียวที่จะจางตาม $\phi$ เดิม แต่เป็นการเปลี่ยนระบอบของตลาด (regime change) ซึ่ง $\mu$ และ $\phi$ เปลี่ยนไปทั้งชุด การเดิมพันว่าสเปรดจะกลับหาค่าเฉลี่ยเก่าจึงเป็นความเสี่ยงใหญ่ที่สุดของกลยุทธ์แบบนี้ ก่อนใช้ ให้ประมาณ $\mu$ กับ $\phi$ ซ้ำบนช่วงข้อมูลที่เลื่อนไปเรื่อย ๆ แล้วดูว่าค่าที่ได้นิ่งไหม

ใช้ทำอะไรบนโต๊ะจริง

สรุปตัวอย่างนี้ในภาษาของโต๊ะ ระดับปกติของสเปรดคือ 15 bp ระยะห่างที่คาดไว้หดครึ่งทุก 5.42 เดือน และในระยะยาวสเปรดอยู่ในช่วง $15\pm1.96\times18.95=15\pm37.1$ bp ราว 95% ของเวลา ตัวเลขเหล่านี้ใช้ตั้งสมมติฐานและประเมินความเสี่ยง ไม่ใช่คำรับประกันราคา และไม่ได้บอกวันขายที่แน่นอน

ตัวอย่างเช่น เมื่อผ่านไปสามเท่าของ half-life ระยะห่างที่คาดไว้เหลือ $0.5^3=12.5\%$ แต่สเปรดจริงอาจยังห่างมาก การตั้ง time stop (กติกาว่าถ้าถือครบเวลาที่กำหนดแล้วสเปรดยังไม่กลับ ให้ขายทิ้ง) จึงเป็นนโยบายคุมความเสี่ยงที่โต๊ะเลือกเอง ไม่ใช่สิ่งที่แบบจำลองรับรอง

ความคิดเดียวกันใช้กับสัญญาณ alpha ด้วย สัญญาณ alpha คือตัวเลขที่บอกว่าหุ้นตัวหนึ่งน่าจะให้ผลตอบแทนเกินตลาดเท่าไร ถ้าสัญญาณนี้เป็น AR(1) รายวันที่มีค่า $\phi$ ค่าคาดของมันอีก $s$ วันคือ $\phi^s$ เท่าของวันนี้ สัญญาณที่มี half-life สองวันต้องซื้อขายเร็วก่อนสัญญาณจาง ส่วนสัญญาณที่มี half-life สามเดือนซื้อขายช้าได้และประหยัดต้นทุน นี่คือภาษาที่ใช้คุยเรื่องalpha decay นอกจากนี้ AR(1) ยังเป็นชิ้นส่วนของแบบจำลองอัตราดอกเบี้ย Vasicek ของแบบจำลอง log ความผันผวน และของ ARMA ในหน้าถัดไป

โจทย์ตรวจความเข้าใจ

1. คนเทรดคู่หุ้นสองตัวที่มักเดินคู่กัน เขาติดตามส่วนต่างราคาของทั้งสองทุกวัน และพบว่าส่วนต่างนี้เข้ากับ AR(1) รายวันที่ $\phi=0.95$ เขาอยากรู้ว่าส่วนต่างที่ห่างจากปกติจะหดครึ่งในกี่วัน ปีหนึ่งมีวันทำการ (วันที่ตลาดเปิด) 252 วัน จงหา half-life เป็นวันทำการ และความเร็วดึงกลับ $\kappa$ ต่อปีของแบบจำลองเวลาต่อเนื่องที่ตรงกัน

เฉลย

half-life ใช้สูตรเดียวกับขั้นคำทำนาย แล้วตรวจด้วยกำลังที่เป็นจำนวนเต็ม

\[\begin{aligned}h_{1/2}&=\frac{\ln0.5}{\ln0.95}=\frac{-0.69315}{-0.05129}\\&\approx13.51,\\0.95^{13}&=0.513,\quad0.95^{14}=0.488.\end{aligned}\]

ได้ 13.51 วันทำการ เพราะ $0.95^{13}$ ยังเกินครึ่ง แต่ $0.95^{14}$ ต่ำกว่าครึ่งแล้ว ส่วน $\kappa$ ได้จาก $\phi=e^{-\kappa\Delta}$ โดยหนึ่งวันทำการคือ $\Delta=1/252$ ปี

\[\begin{aligned}\kappa&=-252\ln0.95\\&=252\times0.05129=12.93,\\\frac{\ln2}{\kappa}&=\frac{0.69315}{12.93}=0.0536,\\0.0536\times252&=13.51.\end{aligned}\]

$\kappa=12.93$ ต่อปี สองแถวล่างตรวจกลับ half-life ในเวลาต่อเนื่องคือ $\ln2/\kappa=0.0536$ ปี คิดเป็นวันทำการได้ 13.51 วันเท่าเดิม

2. อนุกรมหนึ่งเข้ากับ AR(1) ที่มีของที่เติมคงที่ $c=2$ สัดส่วนที่จำ $\phi=0.6$ และ SD ของข่าว $\sigma=4$ วันนี้ค่าอยู่ที่ 15 ซึ่งดูสูงผิดปกติ จงหาค่าเฉลี่ยระยะยาว SD ระยะยาว คำทำนายอีกสองงวด และ SD ของความคลาดของคำทำนายสองงวดนั้น

เฉลย
\[\begin{aligned}\mu&=\frac{2}{1-0.6}=\frac{2}{0.4}=5,\\\sqrt V&=\frac{4}{\sqrt{1-0.36}}=\frac{4}{0.8}=5,\\\hat X_{t+2|t}&=5+0.6^2(15-5)\\&=5+3.6=8.6,\\\mathrm{SD}(2)&=4\sqrt{1+0.36}\approx4.665.\end{aligned}\]

SD ของความคลาดสองงวด 4.665 ใกล้ SD ระยะยาว 5 แล้ว เพราะ $\phi=0.6$ ลืมข่าวเร็ว ข่าวเก่าจึงจางไปเกือบหมดภายในไม่กี่งวด

3. อนุกรมหนึ่งมีนิสัยว่างวดที่สูงมักตามด้วยงวดที่ต่ำ มันเข้ากับ AR(1) ที่ $\phi=-0.5$ จงหา ACF ที่ lag 1, 2, 3 และบอกว่าเส้นทางหน้าตาแบบไหน

เฉลย

ใช้ $\rho_k=\phi^k=(-0.5)^k$ ได้ $\rho_1=-0.5$, $\rho_2=0.25$ และ $\rho_3=-0.125$ เครื่องหมายสลับทุก lag ตามแท่งส้มในรูป ACF เส้นทางจึงซิกแซ็ก ถ้างวดนี้สูงกว่าค่าเฉลี่ย งวดหน้าคาดว่าต่ำกว่า half-life ใช้ $|\phi|$ ได้ $\ln0.5/\ln0.5=1$ งวด

รูปแบบสลับแบบนี้คล้ายการเด้งของราคาซื้อขายระหว่าง bid (ราคาที่มีคนรอซื้อ) กับ ask (ราคาที่มีคนรอขาย) แต่หน้า MA, ARMA และ ARIMA จะแสดงว่าการเด้งนั้นเป็นความจำของข่าว ไม่ใช่ความจำของค่า เพราะ ACF ของมันเป็นศูนย์ทันทีหลัง lag 1

function checkModel({c, phi, sigma}) {
  if (![c, phi, sigma].every(Number.isFinite)) throw new TypeError('c, phi and sigma must be finite numbers');
  if (!(Math.abs(phi) < 1)) throw new RangeError('Need |phi| < 1 for a stationary AR(1)');
  if (!(sigma > 0)) throw new RangeError('Need sigma > 0');
}
// Long-run mean and spread from "the same at every date": mu = c + phi mu, V = phi^2 V + sigma^2.
function longRun(model) {
  checkModel(model);
  const {c, phi, sigma} = model, variance = sigma * sigma / (1 - phi * phi);
  return {mean: c / (1 - phi), variance, sd: Math.sqrt(variance)};
}
function checkHorizon(h) {
  if (!Number.isInteger(h) || h < 0) throw new RangeError('Horizon must be a whole number of periods >= 0');
}
// Expected gap shrinks by phi each period; forecast error adds phi^(2j) sigma^2 for each unseen shock.
function forecast(model, x0, h) {
  checkHorizon(h);
  if (!Number.isFinite(x0)) throw new TypeError('Starting value must be finite');
  const {mean} = longRun(model), {phi, sigma} = model;
  return {mean: mean + phi ** h * (x0 - mean), sd: sigma * Math.sqrt((1 - phi ** (2 * h)) / (1 - phi * phi))};
}
function halfLife(phi) {
  if (!Number.isFinite(phi) || !(Math.abs(phi) < 1)) throw new RangeError('Need |phi| < 1 for a half-life');
  return Math.log(0.5) / Math.log(Math.abs(phi));
}
function walkWithoutNews(model, x0, periods) {
  checkModel(model); checkHorizon(periods);
  const path = [];
  let x = x0;
  for (let h = 1; h <= periods; h++) { x = model.c + model.phi * x; path.push(x); }
  return path;
}
// AR(2) autocorrelations from the Yule-Walker recursion rho_k = phi1 rho_(k-1) + phi2 rho_(k-2).
function ar2Acf(phi1, phi2, lags) {
  if (!(phi1 + phi2 < 1 && phi2 - phi1 < 1 && Math.abs(phi2) < 1)) throw new RangeError('AR(2) is not stationary');
  const rho = [1, phi1 / (1 - phi2)];
  for (let k = 2; k <= lags; k++) rho.push(phi1 * rho[k - 1] + phi2 * rho[k - 2]);
  return rho.slice(1);
}
// Least-squares fit of X_t = c + phi X_(t-1) + e_t.
function fitAR1(x) {
  if (!Array.isArray(x) || x.length < 3 || ![...x].every(Number.isFinite)) throw new TypeError('Need at least three finite values');
  const y = x.slice(1), z = x.slice(0, -1), m = y.length;
  const my = y.reduce((s, v) => s + v, 0) / m, mz = z.reduce((s, v) => s + v, 0) / m;
  let szy = 0, szz = 0;
  for (let i = 0; i < m; i++) { szy += (z[i] - mz) * (y[i] - my); szz += (z[i] - mz) ** 2; }
  if (!(szz > 0)) throw new RangeError('Lagged values are constant: phi cannot be fitted');
  const phi = szy / szz;
  return {c: my - phi * mz, phi};
}
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const radius = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = radius * Math.sin(angle);
    return radius * Math.cos(angle);
  };
}
// One simulated path from today's spread, as drawn in the overview picture.
function simulatePath(model, x0, months, seed) {
  checkModel(model); checkHorizon(months);
  const z = normals(seed), x = [x0];
  for (let t = 1; t <= months; t++) x.push(model.c + model.phi * x[t - 1] + model.sigma * z());
  return x;
}
// Many ten-year histories from the true model: how far does the fitted phi land from 0.88?
function fitSpread(model, months, paths, seed) {
  if (!Number.isInteger(months) || months < 10 || !Number.isInteger(paths) || paths < 10) throw new RangeError('Need at least 10 months and 10 paths');
  const {mean, sd} = longRun(model), z = normals(seed), fits = [];
  for (let p = 0; p < paths; p++) {
    const x = [mean + sd * z()];
    for (let t = 1; t <= months; t++) x.push(model.c + model.phi * x[t - 1] + model.sigma * z());
    fits.push(fitAR1(x).phi);
  }
  fits.sort((a, b) => a - b);
  const avg = fits.reduce((s, v) => s + v, 0) / paths;
  const spread = Math.sqrt(fits.reduce((s, v) => s + (v - avg) ** 2, 0) / (paths - 1));
  return {mean: avg, sd: spread, p05: fits[Math.floor(0.05 * paths)], p95: fits[Math.floor(0.95 * paths)], min: fits[0]};
}
// Standard Normal CDF: 0.5 plus the density integrated from 0 to z by Simpson's rule.
function normalCdf(z) {
  if (!Number.isFinite(z)) throw new TypeError('z must be finite');
  const steps = 2000, w = z / steps, f = t => Math.exp(-t * t / 2) / Math.sqrt(2 * Math.PI);
  let s = f(0) + f(z);
  for (let i = 1; i < steps; i++) s += (i % 2 ? 4 : 2) * f(i * w);
  return 0.5 + s * w / 3;
}

const run = longRun(spread), seSmall = Math.sqrt((1 - 0.88 ** 2) / 120);
const band = [0.88 - 1.96 * seSmall, 0.88 + 1.96 * seSmall];

สิ่งที่ควรตอบได้หลังอ่าน

  • AR(1) คือ ค่างวดนี้เท่ากับของที่เติมคงที่ $c$ บวกส่วนที่จำจากงวดก่อน $\phi X_{t-1}$ บวกข่าวใหม่ $\epsilon_t$ มันมีระดับปกติให้กลับเมื่อ $|\phi|\lt1$
  • ระดับปกติคือ $\mu=c/(1-\phi)=1.8/0.12=15$ bp ไม่ใช่ $c$ SD ระยะยาวคือ $\sigma/\sqrt{1-\phi^2}=9/\sqrt{0.2256}=18.95$ bp กว้างกว่าข่าวรายเดือน 9 bp เพราะข่าวเก่ายังค้างอยู่
  • ระยะห่างที่คาดไว้หดด้วย $\phi^h$ half-life คือ $\ln0.5/\ln0.88=5.42$ เดือน และข่าวเก่าแต่ละก้อนจางด้วย $\phi^j$ แบบเดียวกัน
  • ความคลาดของคำทำนายโตแล้วชนเพดาน 18.95 bp ต่างจาก random walk ที่โตไม่หยุด ช่วง 95% ที่ 3 เดือนคือ 8.3 ถึง 62.6 bp
  • ACF ของ AR(1) คือ $\phi^k$ ซึ่งจางแต่ไม่เคยเป็นศูนย์พอดี และ $\hat\phi$ จากข้อมูล 10 ปีคลาดได้มาก ช่วงกลาง 90% ของ half-life ที่ประมาณได้คือ 2.4 ถึง 8.6 เดือน และ $\hat\phi$ โดยเฉลี่ยต่ำกว่าจริง

หน้าถัดไป MA, ARMA และ ARIMA ถามคำถามกลับด้าน ถ้าค่าวันนี้ไม่ได้จำค่าเมื่อวาน แต่จำข่าวของเมื่อวาน ACF จะหน้าตาอย่างไร และการเด้งของราคาระหว่าง bid กับ ask ซ่อนต้นทุนการซื้อขายไว้ใน ACF ได้อย่างไร
