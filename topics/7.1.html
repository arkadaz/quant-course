7.1 What a Matrix Is

matrix คือตารางตัวเลขที่ทุกแถวและทุกคอลัมน์มีชื่อกับหน่วย และเมื่อคูณกับ vector มันคือเครื่องที่แปลง input หลายช่องเป็น output หลายช่องในคราวเดียว

พอร์ตสมมติ long AAPL \$2 ล้าน short MSFT \$1 ล้าน และ long JPM \$0.5 ล้าน รวมเป็น net position \$1.5 ล้าน เช้านี้ตลาดขึ้น 1% หัวหน้า desk ถามว่ากำไรส่วนที่มาจากตลาดควรเป็น \$15,000 ตาม net position หรือเป็นตัวเลขอื่น

ลองตอบก่อนเปิดเฉลย

ตอบไม่ได้จาก net position อย่างเดียว ต้องรู้ว่าหุ้นแต่ละตัวไวต่อตลาดแค่ไหน ถ้าความไว (loading) สมมติคือ 1.2, 0.9 และ 1.5 ความไวรวมของพอร์ตคือ $2(1.2)-1(0.9)+0.5(1.5)=2.25$ ล้าน ตลาดขึ้น 1% จึงให้ \$22,500 ไม่ใช่ \$15,000 ตัวเลข \$15,000 เท่ากับสมมติเงียบ ๆ ว่าทุกหุ้นมี loading เท่ากับ 1 ซึ่งไม่จริงในตัวอย่างนี้

ภาพรวมก่อนลงสูตร

คำตอบของ hook มาจากตารางเล็ก ๆ หนึ่งตาราง: แถวคือหุ้นสามตัว คอลัมน์คือ factor สองตัว (Market กับ Quality) ช่องแถวหุ้นคอลัมน์ factor ตอบคำถามเดียวว่า “ถ้า factor นี้ขยับหนึ่งหน่วย หุ้นนี้ขยับเท่าไร” ตารางแบบนี้คือ matrix ตัวเลขข้างในไม่มีความหมายเลยถ้าไม่รู้ชื่อแถว ชื่อคอลัมน์ และหน่วย

matrix ไม่ได้มีไว้เก็บตัวเลขเฉย ๆ มันเป็นเครื่องแปลง ส่ง factor shock สองตัวเข้าไป ได้ผลตอบแทนของหุ้นสามตัวออกมา หรือพลิกทิศ ส่งเงินที่ถือในหุ้นสามตัวเข้าไป ได้ความไวรวมต่อ factor สองตัวออกมา ซึ่งก็คือคำถามของ hook รูปด้านล่างวาดตารางนี้เป็นสายไฟ: ทุกเส้นคือหนึ่งช่องของตาราง

หน้านี้สร้างเครื่องมือทีละชิ้น: การเรียกขนาดและช่อง กติกาคูณ matrix กับ vector แบบทีละแถว การอ่านแบบทีละคอลัมน์ การพลิกทิศเพื่อหา exposure ตาราง payoff ที่แถวเป็นสถานะของโลก เหตุผลว่าทำไมฟังก์ชันเชิงเส้นทุกตัวคือ matrix และปิดด้วยการใช้แถวของตารางเป็นสมการ hedge

ศัพท์ที่ใช้ในหัวข้อนี้
Matrix และขนาด $m\times n$
ตารางตัวเลข $m$ แถว $n$ คอลัมน์ บอกแถวก่อนเสมอ ใช้เก็บความสัมพันธ์ระหว่างของสองกลุ่ม เช่นหุ้นกับ factor หรือสถานะของโลกกับสินทรัพย์
Entry $a_{ij}$
ตัวเลขในแถว $i$ คอลัมน์ $j$ ใช้ชี้ช่องที่ต้องการแบบไม่กำกวม
Row vector และ column vector
matrix ขนาด $1\times n$ และ $n\times1$ vector จึงเป็น matrix ชนิดหนึ่ง ใช้แทน input หรือ output ของเครื่องแปลง

Payoff matrix
ตารางที่แถวเป็นสถานะของโลกในอนาคต คอลัมน์เป็นสินทรัพย์ และช่องคือเงินที่สินทรัพย์หนึ่งหน่วยจ่ายในสถานะนั้น ใช้ตั้งโจทย์ hedge
Identity matrix $I_n$
matrix จัตุรัสที่มี 1 บนแนวทแยงและ 0 ที่อื่น คูณแล้วคืน input เดิม ใช้เป็นจุดอ้างอิงแบบเดียวกับเลข 1 ในการคูณตัวเลข
Linear function
ฟังก์ชันที่ผลของผลรวมเท่ากับผลรวมของผล และขยาย input กี่เท่า output ก็ขยายเท่านั้น ทุกฟังก์ชันแบบนี้เขียนเป็น matrix ได้
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย

$S$payoff matrix แถวเป็นสถานะ คอลัมน์เป็นสินทรัพย์ดอลลาร์ต่อหน่วยสินทรัพย์
$\boldsymbol\theta$, $\mathbf p$จำนวนหน่วยที่ถือ และราคาวันนี้ต่อหน่วยหน่วย, ดอลลาร์

ขั้นที่ 1 — ขนาด ชื่อเรียก และการชี้ช่อง

ก่อนทำอะไรกับตาราง ต้องเรียกชื่อมันให้ถูก matrix ที่มีสองแถวสามคอลัมน์เรียกว่าขนาด $2\times3$ แถวมาก่อนคอลัมน์เสมอ

\[\begin{aligned} M&=\begin{bmatrix}2&3&7\\1&6&5\end{bmatrix},\\ m&=2,\quad n=3,\quad m_{23}=5,\\ I_3&=\begin{bmatrix}1&0&0\\0&1&0\\0&0&1\end{bmatrix}. \end{aligned}\]

$m_{23}$ อ่านว่าช่องแถวที่ 2 คอลัมน์ที่ 3 คือเลข 5 ถ้าสลับดัชนีเป็น $m_{32}$ จะชี้ไปช่องที่ไม่มีอยู่ เพราะตารางมีแค่สองแถว ใน JavaScript ดัชนีเริ่มที่ 0 ช่องเดียวกันจึงเป็น M[1][2] ไม่ใช่ M[2][3] ความผิดแบบนี้ไม่มี error เตือนถ้าตารางใหญ่พอ โปรแกรมจะหยิบเลขผิดช่องมาใช้อย่างเงียบ ๆ

row vector และ column vector ก็คือ matrix ขนาด $1\times n$ และ $n\times1$ ส่วน $I_3$ คือ identity ขนาด $3\times3$ ที่คูณแล้วคืนของเดิม เหมือนเลข 1 ในการคูณตัวเลข

ขั้นที่ 2 — ตาราง loading ที่มีชื่อและหน่วยครบ

ตัวเลขชุดเดียวกับสายไฟในรูปภาพรวม เขียนเป็นตาราง แถวเรียง AAPL, MSFT, JPM คอลัมน์เรียง Market, Quality (ตัวเลขสมมติ ไม่ใช่ค่าที่ประมาณจากตลาดจริง)

\[\begin{aligned} A&=\begin{bmatrix}1.2&0.4\\0.9&0.2\\1.5&0.7\end{bmatrix},\\ a_{31}&=1.5,\qquad a_{12}=0.4. \end{aligned}\]

$A$ มีขนาด $3\times2$ ช่อง $a_{31}=1.5$ แปลว่า Market ขยับ 1% ผลตอบแทนส่วนที่มาจาก Market ของ JPM ขยับ 1.5% ช่อง $a_{12}=0.4$ คือความไวของ AAPL ต่อ Quality ตารางเดียวอ่านได้สองแนว แถว AAPL คือ “โปรไฟล์” ของหุ้นหนึ่งตัวต่อทุก factor ส่วนคอลัมน์ Market คือ “รอยเท้า” ของ factor หนึ่งตัวบนทุกหุ้น

หน่วยต้องตกลงก่อนใช้ ในหน้านี้ทั้ง factor return และผลตอบแทนหุ้นวัดเป็นเศษส่วนในงวดเดียวกัน loading จึงไม่มีหน่วย ถ้าวันหนึ่งระบบเปลี่ยนให้ factor วัดเป็นเปอร์เซ็นต์ (1 แทน 0.01) ตัวเลขทุกช่องต้องหารด้วย 100 ตาม และเทียบ 1.2 กับ 0.4 ตรง ๆ ว่า Market “เสี่ยงกว่าสามเท่า” ไม่ได้ เพราะ factor สองตัวผันผวนไม่เท่ากัน

ขั้นที่ 3 — คูณ matrix กับ vector: หนึ่งแถวให้หนึ่งคำตอบ

คำถามแรกที่ตารางตอบ: ถ้าวันนี้ Market ขึ้น 1% และ Quality ลง 2% แบบจำลองบอกว่าหุ้นแต่ละตัวควรขยับเท่าไร ใส่ shock เป็น column vector $\mathbf f=(0.01,-0.02)^{\mathsf T}$ แล้วให้แต่ละแถวจับคู่กับ $\mathbf f$ ทีละช่อง

\[\begin{aligned} \widehat r_{\mathrm{AAPL}}&=1.2(0.01)+0.4(-0.02)\\ &=0.004,\\ \widehat r_{\mathrm{MSFT}}&=0.9(0.01)+0.2(-0.02)\\ &=0.005,\\ \widehat r_{\mathrm{JPM}}&=1.5(0.01)+0.7(-0.02)\\ &=0.001. \end{aligned}\]

สามบรรทัดนี้เขียนรวมเป็นคำสั่งเดียวได้ กติกาทั่วไปคือช่องที่ $i$ ของคำตอบมาจากแถวที่ $i$ ของ matrix

\[\begin{aligned} \widehat{\mathbf r}&=A\mathbf f,\\ \widehat r_i&=\sum_{j=1}^{2}a_{ij}f_j,\\ (3\times2)(2\times1)&\longrightarrow 3\times1. \end{aligned}\]

แต่ละหุ้นได้ผลตอบแทนจากสองแรงที่ดึงคนละทาง Market ดันขึ้น Quality ดึงลง JPM โดนดึงลงแรงที่สุดเพราะไวต่อ Quality มากที่สุด จึงเหลือแค่ 0.1% ในรูปด้านล่าง

บรรทัดสุดท้ายคือกฎตรวจขนาด ตัวเลขด้านในสองตัว (2 กับ 2) ต้องเท่ากัน เพราะแต่ละแถวมีสองช่องที่ต้องจับคู่กับ shock สองตัว ตัวเลขด้านนอก (3 กับ 1) บอกขนาดของคำตอบ matrix ขนาด $m\times n$ จึงรับ input $n$ ช่องและให้ output $m$ ช่อง

ขั้นที่ 4 — อ่านอีกแนว: ผลคูณคือผลรวมของคอลัมน์

กติกาทีละแถวตอบทีละหุ้น แต่ถ้าจัดกลุ่มตาม factor แทน จะเห็นอีกภาพหนึ่งของผลคูณเดียวกัน

\[\begin{aligned} A\mathbf f&=0.01\begin{bmatrix}1.2\\0.9\\1.5\end{bmatrix} -0.02\begin{bmatrix}0.4\\0.2\\0.7\end{bmatrix}\\ &=\begin{bmatrix}0.012-0.008\\0.009-0.004\\0.015-0.014\end{bmatrix} =\begin{bmatrix}0.004\\0.005\\0.001\end{bmatrix}. \end{aligned}\]

ผลคูณ matrix กับ vector คือ linear combination ของคอลัมน์ โดยใช้ตัวเลขใน vector เป็นน้ำหนัก ตัวเลขชุดเดียวกับขั้นก่อน แค่บวกคนละลำดับ ไม่ต้องจำกติกาใหม่

มุมนี้ให้ข้อสรุปที่มุมทีละแถวมองไม่เห็น: ไม่ว่า shock จะเป็นเท่าไร ผลตอบแทนที่แบบจำลองสร้างได้ต้องเป็นส่วนผสมของสองคอลัมน์นี้เท่านั้น ลองถามว่ามี shock ไหนทำให้ AAPL ขึ้น 1% แต่ MSFT กับ JPM นิ่งสนิท แถว MSFT บังคับ $0.9a+0.2b=0$ คือ $b=-4.5a$ แทนในแถว JPM ได้ $1.5a-3.15a=-1.65a=0$ จึงต้องมี $a=0$ และ $b=0$ ซึ่งทำให้ AAPL ขยับไม่ได้เลย แบบจำลองสอง factor สร้างผลตอบแทนชุดนั้นไม่ได้ เรื่องว่าตารางหนึ่ง “ไปถึง” output ไหนได้บ้างคือ rank และ range

ขั้นที่ 5 — พลิกทิศคำถาม: จากเงินที่ถือ ไปสู่ exposure ของพอร์ต

ตอนนี้กลับมาที่คำถามของ hook ให้ $\mathbf w=(2,-1,0.5)^{\mathsf T}$ เป็นเงินที่ถือในหน่วยล้านดอลลาร์ เรียง AAPL, MSFT, JPM ตามแถวของ $A$ exposure ต่อ Market คือเงินแต่ละก้อนคูณ loading ในคอลัมน์ Market แล้วบวกกัน

\[\begin{aligned} e_M&=2(1.2)+(-1)(0.9)+0.5(1.5)\\ &=2.40-0.90+0.75=2.25,\\ e_Q&=2(0.4)+(-1)(0.2)+0.5(0.7)\\ &=0.80-0.20+0.35=0.95,\\ \mathbf e&=A^{\mathsf T}\mathbf w,\quad(2\times3)(3\times1)\longrightarrow2\times1. \end{aligned}\]

เที่ยวนี้เดินสายไฟย้อนจากหุ้นไป factor คอลัมน์ของ $A$ ต้องกลายเป็นแถว การพลิกแบบนี้คือ transpose ซึ่งเขียนว่า $A^{\mathsf T}$ หน่วยของ $e_M$ คือล้านดอลลาร์ต่อหนึ่งหน่วย Market return Market ขึ้น 0.01 จึงให้ $2.25(0.01)=0.0225$ ล้าน หรือ \$22,500 ตามคำตอบของ hook

ขา short ของ MSFT ลบออก 0.90 แต่ JPM ที่ถือแค่ \$0.5 ล้านเพิ่มกลับ 0.75 เพราะ loading สูง เงินที่ถือกับความไวจึงเป็นคนละเรื่อง net position \$1.5 ล้านนับเงิน exposure \$2.25 ล้านนับความไว

ขั้นที่ 6 — กำไรขาดทุนจากแบบจำลอง นับได้สองทาง

โจทย์ให้อะไรมาบ้าง: shock เดิม $\mathbf f=(0.01,-0.02)^{\mathsf T}$ ผลตอบแทนแบบจำลอง $A\mathbf f=(0.004,0.005,0.001)^{\mathsf T}$ จากขั้นที่หาไว้ และ exposure $\mathbf e=(2.25,0.95)^{\mathsf T}$ จากขั้นก่อน ถามว่ากำไรขาดทุนส่วนที่แบบจำลองอธิบายได้เป็นเท่าไร

\[\begin{aligned} \mathbf w^{\mathsf T}(A\mathbf f)&=2(0.004)-1(0.005)\\ &\quad+0.5(0.001)=0.0035,\\ \mathbf e^{\mathsf T}\mathbf f&=2.25(0.01)+0.95(-0.02)\\ &=0.0225-0.0190=0.0035. \end{aligned}\]

คำตอบ: 0.0035 ล้าน หรือ \$3,500 ทั้งสองทาง ทางแรกนับทีละหุ้น ทางที่สองนับทีละ factor เงินก้อนเดียวกันจึงต้องเท่ากัน Market ให้ \$22,500 แต่ Quality ที่ลง 2% กิน \$19,000 กลับไป

ผลตอบแทนจริงคือ $\mathbf r=A\mathbf f+\boldsymbol\varepsilon$ เสมอ ส่วน $\boldsymbol\varepsilon$ คือผลตอบแทนเฉพาะตัวของหุ้นที่ factor อธิบายไม่ได้ \$3,500 จึงเป็นแค่ส่วนที่ factor อธิบาย ยังไม่ใช่กำไรจริงของวัน

ตรวจเองใน 10 วินาที: $2.25-1.9=0.35$ แล้วคูณ 0.01 ได้ 0.0035

ขั้นที่ 7 — payoff matrix: แถวเป็นสถานะของโลก คอลัมน์เป็นสินทรัพย์

matrix อีกแบบที่จะใช้ทั้งบทมาจากโจทย์ hedge ตลาดมีสินทรัพย์ $d$ ตัว และโลกในวันพรุ่งนี้มีได้ $m$ สถานะ ช่อง $S_{ij}$ คือเงินที่สินทรัพย์ $j$ หนึ่งหน่วยจ่ายในสถานะ $i$ คอลัมน์ที่ $j$ จึงเป็น payoff ของสินทรัพย์ตัวนั้นในทุกสถานะ

โจทย์ให้อะไรมาบ้าง: สามสถานะ (ขึ้น กลาง ลง) หุ้นจ่าย 120, 100, 70 ดอลลาร์ bond จ่าย 105 ทุกสถานะ ราคาวันนี้หน่วยละ \$100 ทั้งคู่ (ตัวเลขสมมติ) ถือหุ้น 2 หน่วยและ short bond 1 หน่วย

\[\begin{aligned} S&=\begin{bmatrix}120&105\\100&105\\70&105\end{bmatrix},\quad \boldsymbol\theta=\begin{bmatrix}2\\-1\end{bmatrix},\\ \mathbf y=S\boldsymbol\theta&=2\begin{bmatrix}120\\100\\70\end{bmatrix} -\begin{bmatrix}105\\105\\105\end{bmatrix} =\begin{bmatrix}135\\95\\35\end{bmatrix},\\ \mathbf p^{\mathsf T}\boldsymbol\theta&=100(2)+100(-1)=100. \end{aligned}\]

คำตอบ: พอร์ตจ่าย \$135, \$95 และ \$35 ในสามสถานะ และใช้เงินวันนี้ \$100 กำไรจึงเป็น \$35, −\$5 และ −\$65 ตามลำดับ $\mathbf y$ คือ payoff ณ วันพรุ่งนี้ ไม่ใช่กำไร และยังไม่ใช่ค่าเฉลี่ย เพราะยังไม่มีใครบอกโอกาสของแต่ละสถานะ การมีสามแถวไม่ได้แปลว่าแต่ละแถวมีโอกาสหนึ่งในสาม

หน่วยของ $\boldsymbol\theta$ คือจำนวนหน่วยสินทรัพย์ ต่างจาก $\mathbf w$ ในขั้นก่อนที่เป็นเงินล้านดอลลาร์ ตารางสองแบบนี้คูณกับ vector คนละชนิด สลับกันเมื่อไรได้ตัวเลขที่ดูสมเหตุสมผลแต่ผิดทั้งหมด

ขั้นที่ 8 — ทำไมฟังก์ชันเชิงเส้นทุกตัวคือ matrix

ทุกเครื่องแปลงในหน้านี้มีสมบัติร่วมกัน: ถือของสองเท่า ผลก็สองเท่า และผลของพอร์ตรวมเท่ากับผลรวมของพอร์ตย่อย สมบัตินี้มีชื่อว่า linear และมันเป็นเหตุผลที่ตารางเดียวพอจะเก็บเครื่องแปลงทั้งเครื่อง

\[\begin{aligned} f(\alpha\mathbf x+\beta\mathbf y)&=\alpha f(\mathbf x)+\beta f(\mathbf y),\\ \mathbf x&=x_1\mathbf e_1+\cdots+x_n\mathbf e_n,\\ f(\mathbf x)&=x_1f(\mathbf e_1)+\cdots+x_nf(\mathbf e_n)\\ &=A\mathbf x,\quad A=\big[f(\mathbf e_1)\ \cdots\ f(\mathbf e_n)\big]. \end{aligned}\]

บรรทัดแรกคือนิยาม บรรทัดสองเขียน input ใดก็ได้ด้วย basis มาตรฐาน $\mathbf e_j$ (vector ที่มี 1 ในช่อง $j$ และ 0 ที่อื่น) บรรทัดสามใช้นิยามดึงตัวเลข $x_j$ ออกมา เหลือแค่ต้องรู้ว่า $f$ ส่ง $\mathbf e_j$ แต่ละตัวไปที่ไหน เอาคำตอบเหล่านั้นมาเรียงเป็นคอลัมน์ ก็ได้ matrix ของ $f$ ทั้งเครื่อง ทิศกลับก็จริง: $A\mathbf x$ เป็น linear เสมอเพราะคูณกระจายผ่านผลบวกได้ สรุปคือ linear กับ “คูณด้วย matrix” เป็นเรื่องเดียวกัน

ตัวอย่าง $f(\mathbf x)=(2x_1+3x_2+4x_3,\ x_1+2x_3)$ ส่ง $\mathbf e_1$ ไป $(2,1)$, $\mathbf e_2$ ไป $(3,0)$ และ $\mathbf e_3$ ไป $(4,2)$ matrix ของมันคือสามคอลัมน์นี้เรียงกัน ขนาด $2\times3$ ข้อควรระวังคือ payoff ของ call option เป็น linear ในจำนวนสัญญาที่ถือ แต่ไม่ linear ในราคาหุ้น เพราะ $\max(S-100,0)$ หักมุมที่ strike ต้องถามเสมอว่า linear ในตัวแปรไหน

ขั้นที่ 9 — แถวของตารางกลายเป็นสมการ hedge

desk อยากปิด exposure ทั้งสอง factor โดยยังถือ JPM \$0.5 ล้านไว้ และยอมปรับเฉพาะ AAPL ($w_1$) กับ MSFT ($w_2$) แต่ละคอลัมน์ของ $A$ ให้สมการหนึ่งเส้น

โจทย์ให้อะไรมาบ้าง: $w_3=0.5$ คงที่ ต้องการ $e_M=0$ และ $e_Q=0$

\[\begin{aligned} 1.2w_1+0.9w_2&=-0.75,\\ 0.4w_1+0.2w_2&=-0.35,\\ \text{(row 1)}-3\times\text{(row 2)}:\ \ 0.3w_2&=0.30,\\ w_2&=1,\quad w_1=-1.375. \end{aligned}\]

คำตอบ: พอร์ตเป้าหมายคือ $(-1.375,\ 1,\ 0.5)$ ล้านดอลลาร์ ต้องขาย AAPL $-1.375-2=-3.375$ ล้าน และซื้อ MSFT $1-(-1)=2$ ล้าน รายการซื้อขายคือเป้าหมายลบของเดิม ไม่ใช่ตัวเป้าหมายเอง ตัวเลข $-0.75$ และ $-0.35$ ทางขวาคือส่วนที่ JPM 0.5 ล้านใส่เข้ามาแล้ว ($0.5\times1.5$ และ $0.5\times0.7$)

ถ้าปิดแค่ Market โดยตั้ง AAPL เป็นศูนย์ จะได้ $w_2=-0.75/0.9=-5/6$ ล้าน แต่ Quality ยังค้าง $0.2(-5/6)+0.7(0.5)\approx0.183$ ล้าน ส่วนถ้าปิดแค่ Quality แบบเดียวกันได้ $w_2=-1.75$ และ Market ค้าง $-0.825$ ล้าน รูปด้านล่างแสดงว่าทำไม: แต่ละเงื่อนไขคือเส้นหนึ่งเส้น ปิดได้ทั้งคู่เฉพาะจุดที่สองเส้นตัดกัน

ตรวจเองใน 10 วินาที: $1.2(-1.375)+0.9(1)+0.75=-1.65+0.9+0.75=0$

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

เรียงชื่อไม่ตรงกัน: แถวของ $A$ เรียง AAPL, MSFT, JPM แต่ระบบส่งเงินมาเรียง JPM, AAPL, MSFT เป็น $(0.5,2,-1)$ จะได้ $e_M=0.5(1.2)+2(0.9)-1(1.5)=0.9$ แทน 2.25 ขนาดถูก คูณผ่าน ไม่มี error แต่ exposure ผิดไปเกินครึ่ง

เปอร์เซ็นต์กับเศษส่วน: ใส่ shock เป็น $(1,-2)$ แทน $(0.01,-0.02)$ ได้ $\mathbf e^{\mathsf T}\mathbf f=0.35$ ล้าน หรือ \$350,000 ใหญ่เกินจริง 100 เท่า

payoff ไม่ใช่กำไร: payoff \$135, \$95, \$35 ยังต้องหักต้นทุน \$100 และยังไม่มีโอกาสของแต่ละสถานะ จะเฉลี่ยสามตัวเลขเป็น \$88.33 ไม่ได้

net position แทน exposure: ใช้ net \$1.5 ล้านคูณ 1% ได้ \$15,000 พลาดไป \$7,500 จาก \$22,500 เพราะสมมติว่าทุก loading เท่ากับ 1

ปิด factor แล้วเรียกว่าไร้ความเสี่ยง: พอร์ต $(-1.375,1,0.5)$ ยังมีส่วน $\mathbf w^{\mathsf T}\boldsymbol\varepsilon$ ที่ factor ไม่อธิบาย และ loading ที่ประมาณมาก็เปลี่ยนได้ทุกวัน

ใช้ทำอะไรบนโต๊ะจริง

ระบบความเสี่ยงของกองทุนเก็บตาราง loading ขนาดหลายพันหุ้นคูณหลายสิบ factor ทุกวัน คำสั่งเดียว $A^{\mathsf T}\mathbf w$ ให้ exposure ของพอร์ตทั้งพอร์ต และคำสั่ง $A\mathbf f$ ใช้ทำ stress test ด้วย shock สมมติ โครงสร้างนี้คือ สมการ factor model ส่วน payoff matrix คือจุดตั้งต้นของ โจทย์ hedge ที่เขียนเป็น linear program ซึ่งหาพอร์ตที่ถูกที่สุดที่ payoff ไม่ต่ำกว่าภาระในทุกสถานะ

โจทย์ตรวจความเข้าใจ

1. ใช้ $A$ และพอร์ตเดิม ถ้า Market ขึ้น 2% และ Quality ขึ้น 1% แบบจำลองให้กำไรเท่าไร คิดทั้งสองทาง

เฉลย

ทีละหุ้น: $A\mathbf f=(1.2(0.02)+0.4(0.01),\ 0.9(0.02)+0.2(0.01),\ 1.5(0.02)+0.7(0.01))=(0.028,0.020,0.037)$ แล้ว $2(0.028)-0.020+0.5(0.037)=0.056-0.020+0.0185=0.0545$ ล้าน ทีละ factor: $2.25(0.02)+0.95(0.01)=0.045+0.0095=0.0545$ ล้าน เท่ากันคือ \$54,500

2. ใช้ payoff matrix $S$ เดิม ถือหุ้น 1 หน่วยและ bond 0.5 หน่วย หา payoff สามสถานะ ต้นทุนวันนี้ และกำไร

เฉลย

$S\boldsymbol\theta=1(120,100,70)+0.5(105,105,105)=(172.5,\ 152.5,\ 122.5)$ ดอลลาร์ ต้นทุน $100(1)+100(0.5)=150$ กำไรจึงเป็น $(22.5,\ 2.5,\ -27.5)$ ดอลลาร์ ยังบอกกำไรเฉลี่ยไม่ได้จนกว่าจะรู้โอกาสของสามสถานะ

3. ระบบมีตาราง loading 500 หุ้นคูณ 10 factor $A\mathbf f$ และ $A^{\mathsf T}\mathbf w$ ต้องการ input กี่ช่องและให้ output กี่ช่อง แต่ละช่องหมายถึงอะไร

เฉลย

$A$ ขนาด $500\times10$ ดังนั้น $A\mathbf f$ รับ shock 10 ช่องและให้ผลตอบแทนแบบจำลอง 500 ช่อง หนึ่งช่องต่อหุ้น ส่วน $A^{\mathsf T}$ ขนาด $10\times500$ รับเงินที่ถือ 500 ช่องและให้ exposure 10 ช่อง หนึ่งช่องต่อ factor ถ้าส่ง vector 10 ช่องเข้า $A^{\mathsf T}$ ขนาดจะไม่ตรงและคูณไม่ได้

คำนวณซ้ำด้วย JavaScript

โค้ดตรวจขนาดตารางก่อนคูณ แล้วคำนวณผลตอบแทนแบบจำลอง exposure กำไรขาดทุนสองทาง payoff และพอร์ต hedge ของหน้านี้

เปิดดูโค้ด 
function shape(A) {
  const n = A[0].length;
  if (A.some(row => row.length !== n)) throw new Error('rows of unequal length');
  return [A.length, n];
}
function matvec(A, x) {
  const [, n] = shape(A);
  if (x.length !== n) throw new Error('inner sizes do not match');
  return A.map(row => row.reduce((s, a, j) => s + a * x[j], 0));
}
const transpose = A => A[0].map((_, j) => A.map(row => row[j]));
const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);

const A = [[1.2, 0.4], [0.9, 0.2], [1.5, 0.7]];   // rows AAPL MSFT JPM
const f = [0.01, -0.02], w = [2, -1, 0.5];        // shock, $ million
const r = matvec(A, f);                           // 0.004 0.005 0.001
const e = matvec(transpose(A), w);                // 2.25 0.95
const S = [[120, 105], [100, 105], [70, 105]], theta = [2, -1];
const y = matvec(S, theta), cost = dot([100, 100], theta);
const hedge = [-1.375, 1, 0.5];
console.log({ r, e,
  pnlByStock: dot(w, r), pnlByFactor: dot(e, f),  // 0.0035 both
  marketOnly: e[0] * 0.01,                        // 0.0225
  payoff: y, cost, profit: y.map(v => v - cost),  // 135 95 35 / 100
  hedgeExposure: matvec(transpose(A), hedge),     // ~0 ~0
  wrongOrder: matvec(transpose(A), [0.5, 2, -1])[0] });

สิ่งที่ควรตอบได้หลังอ่าน

  • บอกขนาด $m\times n$ ชี้ช่อง $a_{ij}$ และบอกได้ว่าทุกแถว ทุกคอลัมน์ แทนอะไรในหน่วยไหน
  • คูณ matrix กับ vector ได้ทั้งแบบทีละแถว (หนึ่งแถวหนึ่งคำตอบ) และแบบผลรวมของคอลัมน์ถ่วงด้วย input
  • แยก $A\mathbf f$ (shock ไปผลตอบแทนหุ้น) ออกจาก $A^{\mathsf T}\mathbf w$ (เงินที่ถือไป exposure) และได้ \$22,500 ไม่ใช่ \$15,000 ในโจทย์เปิด
  • อ่าน payoff matrix ว่าแถวคือสถานะ คอลัมน์คือสินทรัพย์ และ $S\boldsymbol\theta$ เป็น payoff ไม่ใช่กำไรหรือค่าเฉลี่ย
  • อธิบายได้ว่าทำไมฟังก์ชัน linear ทุกตัวคือการคูณด้วย matrix ที่คอลัมน์คือภาพของ $\mathbf e_j$

หน้านี้พลิกตารางไปมาหลายครั้งโดยใช้สัญลักษณ์ $A^{\mathsf T}$ หน้าถัดไป Transpose ดูการพลิกนี้ให้ละเอียด ว่าตัวเลขย้ายไปช่องไหน ทำไมการพลิกต่างจากการจัดรูปตารางใหม่ และทำไม covariance matrix พลิกแล้วได้ตัวเดิม
