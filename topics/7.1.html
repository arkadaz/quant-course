7.1 What a Matrix Is

ตารางหนึ่งชุดแปลงข้อมูลอะไรเป็นอะไร? เริ่มจากชื่อแถว คอลัมน์ และหน่วย

ถือ AAPL 2 ล้าน, short MSFT 1 ล้าน และถือ JPM 0.5 ล้าน USD ถ้าตลาดขึ้น 1% ส่วนของกำไรที่มาจากตลาดควรเป็น 15,000 USD ตาม net position 1.5 ล้าน หรือ 22,500 USD?

ต้องรู้อะไรเพิ่มก่อนตอบ?

ต้องรู้ความไวของแต่ละหุ้นต่อตลาด ในโมเดลสมมติของบทนี้ loadings คือ 1.2, 0.9, 1.5 จึงได้ market exposure $2(1.2)-1(0.9)+0.5(1.5)=2.25$ ล้าน และ market contribution 22,500 USD แต่ไม่ใช่กำไรรวมที่รับประกัน เพราะ factor อื่น ผลตอบแทนเฉพาะหุ้นและต้นทุนอาจไม่เป็นศูนย์

Matrix ช่วยเก็บ loading หลายหุ้นต่อหลาย factor แล้วรวมผลอย่างเป็นระบบ สิ่งสำคัญไม่ใช่แค่ใส่ตัวเลขในกรอบ แต่ต้องบอกให้ได้ว่า input คืออะไร output คืออะไร และแต่ละช่องมีหน่วยอะไร

1. Matrix เป็นตารางมีลำดับ ไม่ใช่รายการตัวเลขที่สลับได้

Matrix ขนาด $m\times n$ มี $m$ แถวและ $n$ คอลัมน์ เขียนสมาชิกช่องแถว $i$ คอลัมน์ $j$ ว่า $a_{ij}$ ตัวอย่างนี้มีสองแถวสามคอลัมน์:

\[ M=\begin{bmatrix}2&3&7\\1&6&5\end{bmatrix}, \qquad m=2,\quad n=3,\quad m_{23}=5. \]

ดัชนีในคณิตศาสตร์เริ่มที่ 1 แต่ array ใน JavaScript เริ่มที่ 0 ช่องนี้จึงเป็น M[1][2] ไม่ใช่ M[2][3] โดยทั่วไป column vector เป็น matrix ขนาด $n\times1$ และ row vector เป็น matrix ขนาด $1\times n$ ทั้งสองแบบเป็น matrix

เมื่อใช้ matrix คูณ column vector กติกาคือแต่ละแถวสร้าง output หนึ่งช่องจากการจับคู่กับ input ทุกช่อง ดังนั้น matrix $m\times n$ รับ input $n$ ช่องและให้ output $m$ ช่อง:

\[ \begin{aligned} \mathbf y&=A\mathbf x,\qquad A\in\mathbb R^{m\times n},\quad\mathbf x\in\mathbb R^n,\\ y_i&=\sum_{j=1}^{n}a_{ij}x_j. \end{aligned} \]

เช่นเครื่องคำนวณที่กำหนด $y_1=0.5x_1$ และ $y_2=0.25x_1+0.5x_2$ เขียนกติกาสองบรรทัดด้วย matrix เดียวได้ เมื่อ input เป็น $(2,3)$:

\[ \begin{aligned} T&=\begin{bmatrix}0.5&0\\0.25&0.5\end{bmatrix},\\ T\begin{bmatrix}2\\3\end{bmatrix} &=\begin{bmatrix}0.5(2)+0(3)\\0.25(2)+0.5(3)\end{bmatrix} =\begin{bmatrix}1\\2\end{bmatrix}. \end{aligned} \]

นี่คือตารางของกติกาเชิงเส้น: เพิ่ม input ทุกช่องสองเท่า output ก็เพิ่มสองเท่า และ output ของผลรวมเท่ากับผลรวม output เพราะแจกแจงผลคูณในแต่ละแถวได้ แต่การนำตารางมาอธิบายระบบจริงยังต้องตรวจว่าระบบนั้นเป็นเชิงเส้นในช่วงที่ใช้หรือไม่

2. ตั้งชื่อแถว คอลัมน์ และหน่วยให้ครบ

กลับมาที่หุ้นสหรัฐสามตัว ใช้ loadings สมมติ ไม่ใช่ค่าประมาณล่าสุดของบริษัทจริง ทุกแถวแทนหุ้นหนึ่งตัว ทุกคอลัมน์แทน factor หนึ่งตัว:

\[ A=\begin{bmatrix}1.2&0.4\\0.9&0.2\\1.5&0.7\end{bmatrix}, \qquad A\text{ has shape }3\times2. \]

ในตัวอย่างนี้ market factor คือ return ของตลาด และ quality factor คือผลต่าง return ของพอร์ตคุณภาพสูงกับพอร์ตอ้างอิง โดยกำหนดสเกลคงที่ไว้ ทั้งสองวัดเป็นเศษส่วน เช่น 1% ใช้ 0.01 ในงวดเดียวกับ return หุ้น จึงเขียน loading เป็นสัมประสิทธิ์ไร้หน่วยได้

ถ้าเปลี่ยนหน่วยหรือ normalization ของ factor ต้องเปลี่ยน loading ชดเชยด้วย อย่านำ 1.2 กับ 0.4 มาเทียบว่า factor แรกเสี่ยงกว่าสามเท่าโดยไม่รู้ขนาดความผันผวนและ covariance ของ factors

Matrix เดียวกันอ่านได้สองมุม: แถว AAPL บอกว่าหุ้นนี้ตอบสนองต่อสอง factors อย่างไร ส่วนคอลัมน์ market บอกว่าหุ้นทั้งสามตอบสนองต่อ market อย่างไร การสลับชื่อหุ้นโดยไม่สลับตัวเลขตามเป็นความผิดที่ shape ไม่ตรวจให้

3. จากตำแหน่งหุ้นสู่ factor exposure

ให้ $\mathbf w=(2,-1,0.5)^{\mathsf T}$ เป็น มูลค่าสถานะในล้าน USD ตามลำดับ AAPL/MSFT/JPM ไม่ใช่น้ำหนักที่ต้องรวมเป็นหนึ่ง การรวม market exposure คือคูณสถานะแต่ละตัวด้วย loading ในคอลัมน์ market:

\[ \begin{aligned} e_M&=2(1.2)+(-1)(0.9)+0.5(1.5)\\ &=2.40-0.90+0.75=2.25,\\ e_Q&=2(0.4)+(-1)(0.2)+0.5(0.7)\\ &=0.80-0.20+0.35=0.95. \end{aligned} \]

เมื่อกลับคอลัมน์ของ $A$ มาเป็นแถวโดย transpose จะเขียนการรวมสองครั้งนี้เป็นคำสั่งเดียวได้:

\[ \begin{aligned} A^{\mathsf T}&=\begin{bmatrix}1.2&0.9&1.5\\0.4&0.2&0.7\end{bmatrix},\\ \mathbf e&=A^{\mathsf T}\mathbf w =\begin{bmatrix}2.25\\0.95\end{bmatrix},\\ (2\times3)(3\times1)&\longrightarrow2\times1. \end{aligned} \]

Exposure นี้มีหน่วยล้าน USD ต่อหนึ่งหน่วยของ factor return ตามสเกลที่กำหนด หาก market ขยับ 0.01 และพิจารณาเฉพาะส่วนจาก market จะได้ $2.25(0.01)=0.0225$ ล้าน หรือ 22,500 USD

4. ตารางเดิมใช้จำลองผลจาก factor shock ได้อีกทาง

ให้ factor shock เป็น $\mathbf f=(0.01,-0.02)^{\mathsf T}$ หมายถึง market +1% และ quality −2% สมมติคิดเฉพาะผลตอบแทนส่วนที่โมเดลเชิงเส้นอธิบายได้ จะได้ modeled returns $\widehat{\mathbf r}=A\mathbf f$:

\[ \begin{aligned} \widehat r_{\mathrm{AAPL}}&=1.2(0.01)+0.4(-0.02)=0.004,\\ \widehat r_{\mathrm{MSFT}}&=0.9(0.01)+0.2(-0.02)=0.005,\\ \widehat r_{\mathrm{JPM}}&=1.5(0.01)+0.7(-0.02)=0.001,\\ (3\times2)(2\times1)&\longrightarrow3\times1. \end{aligned} \]

คำนวณ P&L จากหุ้นทั้งสาม หรือจาก factor exposure สองตัว ต้องได้คำตอบเดียวกัน:

\[ \begin{aligned} \mathbf w^{\mathsf T}\widehat{\mathbf r} &=2(0.004)-1(0.005)+0.5(0.001)\\ &=0.0035\ \text{million USD},\\ \mathbf e^{\mathsf T}\mathbf f &=2.25(0.01)+0.95(-0.02)\\ &=0.0035\ \text{million USD}=3{,}500\ \text{USD}. \end{aligned} \]

ถ้า return จริงคือ $\mathbf r=A\mathbf f+\boldsymbol\varepsilon$ ยังมีส่วน $\mathbf w^{\mathsf T}\boldsymbol\varepsilon$ ที่โมเดลไม่ได้อธิบาย รวมทั้งต้นทุนและกระแสเงินสดอื่น จึงอย่ารายงาน 3,500 USD เป็นกำไรจริงโดยไม่ตรวจส่วนที่เหลือ

คำถามการคำนวณoutput
factor shock ทำให้หุ้นขยับตามโมเดลเท่าไร?$A\mathbf f$return สามหุ้น

สองทางนี้ใช้คนละ input และ output ไม่ใช่การแปลงไปแล้วใช้ transpose ย้อนคืนเหมือน inverse โดยทั่วไป $A^{\mathsf T}A\mathbf f$ ไม่เท่ากับ $\mathbf f$ เราจะเจาะเรื่อง transpose ในหัวข้อถัดไป

5. อีก matrix หนึ่ง: แถวเป็นสถานะ คอลัมน์เป็นสินทรัพย์

สมมติหุ้นกับ bond มี payoff สิ้นงวดต่อหนึ่งหน่วยตามสามสถานะดังตารางใน matrix $S$ โดย bond จ่าย 105 USD ทุกสถานะ และถือหุ้นสองหน่วยพร้อม short bond หนึ่งหน่วย:

\[ \begin{aligned} S&=\begin{bmatrix}120&105\\100&105\\70&105\end{bmatrix},\qquad \boldsymbol\theta=\begin{bmatrix}2\\-1\end{bmatrix},\\ \mathbf y=S\boldsymbol\theta &=\begin{bmatrix}240-105\\200-105\\140-105\end{bmatrix} =\begin{bmatrix}135\\95\\35\end{bmatrix}\ \text{USD}. \end{aligned} \]

ในคอลัมน์แรกหน่วยคือ USD ต่อหุ้น ส่วนคอลัมน์ที่สองคือ USD ต่อหน่วย bond แต่ละช่องของ $\boldsymbol\theta$ จึงเป็นจำนวนหน่วยของสินทรัพย์นั้น ไม่ใช่เปอร์เซ็นต์เงินลงทุนหรือจำนวนล้าน USD แบบ $\mathbf w$ ในตัวอย่างก่อน

ผลลัพธ์เป็น terminal payoff ในแต่ละสถานะ ไม่ใช่ profit, return หรือ expected payoff หากต้องการ profit ต้องมีต้นทุนเริ่มต้นและกระแสเงินสดที่เกี่ยวข้อง หากต้องการ expectation ต้องมีความน่าจะเป็นของสถานะตามแบบจำลองที่ใช้

ตัวอย่างเพิ่มเติม: ถ้าสมมติหุ้นและ bond ราคาเริ่มต้นอย่างละ 100 USD ต้นทุนสุทธิคือ $2(100)-100=100$ USD ก่อนค่าใช้จ่าย กำไรจึงเป็น $(35,-5,-65)$ USD และ simple returns เป็น $(35\%,-5\%,-65\%)$ ภายใต้สมมติฐานไม่มี cash flow อื่นระหว่างงวด

6. Identity และ zero matrix เป็นกติกาสองกรณีที่ควรจำ

Identity $I_n$ มีหนึ่งบนแนวทแยงและศูนย์ที่อื่น แต่ละแถวจึงเลือก input เดิมหนึ่งช่อง โดยไม่เปลี่ยนค่า ส่วน zero matrix ให้ output ศูนย์ทุกช่อง:

\[ \begin{aligned} I_3&=\begin{bmatrix}1&0&0\\0&1&0\\0&0&1\end{bmatrix},\\ I_3\begin{bmatrix}2\\-1\\0.5\end{bmatrix} &=\begin{bmatrix}2\\-1\\0.5\end{bmatrix},\\ 0_{2\times3}\begin{bmatrix}2\\-1\\0.5\end{bmatrix} &=\begin{bmatrix}0\\0\end{bmatrix}. \end{aligned} \]

สำหรับ $A$ ขนาด $3\times2$ จะมี $I_3A=A$ และ $AI_2=A$ ต้องเลือกขนาด identity ให้ตรง ไม่ใช่ใส่ $I_3$ ทั้งสองด้านโดยไม่ดู shape ส่วน output ศูนย์จาก zero matrix ไม่ได้พิสูจน์ว่า input เป็นศูนย์ ตารางนี้ทิ้งข้อมูลทั้งหมดไปตั้งแต่แรก

Matrix จัตุรัสมีจำนวนแถวเท่าคอลัมน์ แต่ยังไม่รับประกันว่ากลับด้านได้หรือปลอดภัยเชิงตัวเลข เราจะใช้ rank, range และ invertibility ในหัวข้อ 7.5 อธิบายเงื่อนไขเหล่านั้น

7. แถวของ exposure matrix กลายเป็นข้อจำกัดพอร์ต

ถ้าต้องการ market exposure ศูนย์ในโมเดลเดิม จะมีข้อจำกัดหนึ่งสมการ:

\[ 1.2w_1+0.9w_2+1.5w_3=0. \]

สมการเดียวกับตัวไม่ทราบค่าสามตัวนี้ให้ระนาบของคำตอบ ก่อนเพิ่มข้อจำกัดอื่น สมมติเลือก เป้าหมาย AAPL เป็นศูนย์และคง JPM 0.5 ล้าน USD เราจึงหาสถานะ MSFT ได้ดังนี้:

\[ \begin{aligned} 0.9w_2+1.5(0.5)&=0,\\ w_2&=-\frac{0.75}{0.9}=-\frac56\ \text{million USD},\\ e_Q&=0.2(-5/6)+0.7(0.5)\approx0.183333\ \text{million USD}. \end{aligned} \]

Market exposure เป็นศูนย์ แต่ quality ยังไม่เป็นศูนย์ และการตั้ง AAPL เป้าหมายศูนย์หมายถึงปิดสถานะเดิม 2 ล้าน ไม่ใช่ปล่อย AAPL ไว้เหมือนเดิม รายการซื้อขายต้องคำนวณจาก $\Delta\mathbf w=\mathbf w_{\text{target}}-\mathbf w_{\text{current}}$

หากเปลี่ยนเป้าหมายเป็น quality-neutral โดยยังให้ AAPL ศูนย์และ JPM 0.5 จะได้ $0.2w_2+0.7(0.5)=0$ หรือ $w_2=-1.75$ ล้าน ซึ่งใหญ่กว่าขา MSFT แบบ market-neutral 2.1 เท่า และเหลือ market exposure −0.825 ล้าน USD

ถ้าอยาก neutral ทั้งสอง factor ล่ะ?

ต้องแก้สองสมการพร้อมกัน หากยังคง JPM 0.5 แต่ยอมให้ AAPL และ MSFT เปลี่ยนได้:

\[ \begin{aligned} 1.2w_1+0.9w_2&=-0.75,\\ 0.4w_1+0.2w_2&=-0.35,\\ 0.3w_2&=0.30\ \Longrightarrow\ w_2=1,\\ w_1&=(-0.35-0.2)/0.4=-1.375. \end{aligned} \]

จึงได้ $\mathbf w=(-1.375,1,0.5)$ ล้าน USD ตรวจทั้งสอง exposure ได้ศูนย์ (ยอมให้ความคลาดเคลื่อนจิ๋วจาก floating point เมื่อใช้คอมพิวเตอร์) แต่ยังมีความเสี่ยงเฉพาะหุ้น ต้นทุน และข้อจำกัด short ไม่ได้กลายเป็นพอร์ตไร้ความเสี่ยง

การแก้ขาเดียวทำได้ในตัวอย่างเพราะ loading ของขาที่ปรับไม่เป็นศูนย์และอนุญาตสถานะตามคำตอบ หาก loading เป็นศูนย์ มี position limit หรือห้าม short อาจไม่มีพอร์ตที่ทำเป้าหมายนี้ได้

ข้อ 3: รู้ payoff สามสถานะเป็น 135, 95, 35 USD แล้ว ทำไมจึงยังหา expected payoff ไม่ได้?

ดูเฉลย

ยังไม่รู้ความน่าจะเป็นของแต่ละสถานะ การเป็นสามแถวไม่ได้ทำให้ทุกแถวมีโอกาสหนึ่งในสามโดยอัตโนมัติ และ payoff ที่คาดหมายก็ยังไม่ใช่กำไรหากยังไม่หักต้นทุน

function shape(A) {
  if (!Array.isArray(A) || !A.length || !Array.isArray(A[0]) || !A[0].length) {
    throw new TypeError('Need a nonempty rectangular matrix');
  }
  const n = A[0].length;
  // Spread exposes empty array slots as undefined so validation cannot skip them.
  if ([...A].some(row => !Array.isArray(row) || row.length !== n || ![...row].every(Number.isFinite))) {
    throw new TypeError('Need a finite rectangular matrix');
  }
  return [A.length, n];
}
function matvec(A, v) {
  const [, n] = shape(A);
  if (!Array.isArray(v) || ![...v].every(Number.isFinite)) throw new TypeError('Need a finite vector');
  if (v.length !== n) throw new RangeError('Matrix/vector dimensions do not match');
  return A.map(row => row.reduce((sum, x, j) => sum + x * v[j], 0));
}
function transpose(A) {
  const [, n] = shape(A);
  return Array.from({length: n}, (_, j) => A.map(row => row[j]));
}
const dot = (a, b) => a.reduce((sum, x, i) => sum + x * b[i], 0);
const assets = ['AAPL', 'MSFT', 'JPM'];
const positionsByName = {JPM: .5, AAPL: 2, MSFT: -1};
const w = assets.map(name => positionsByName[name]);

Sylvester ใช้ชื่อ matrix ในปี 1850 และ Cayley พัฒนาพีชคณิตของ matrices ในปี 1858 ภาษานี้ทำให้ระบบสมการหลายบรรทัดกลายเป็นการแปลงที่ประกอบกันและวิเคราะห์ได้ แต่ความกระชับของสัญกรณ์ไม่ทดแทนการระบุความหมายของตัวเลข

สี่ความผิดที่ shape ถูกก็ยังพลาดได้

  • แถวเป็น AAPL/MSFT/JPM แต่ input เรียง JPM/AAPL/MSFT
  • เอาจำนวนหุ้นไปใช้กับสูตรที่ต้องการ dollar position หรือใช้ return 1 แทน 0.01
  • ตีความ terminal payoff เป็น profit หรือสมมติให้แต่ละแถวมีโอกาสเท่ากันโดยไม่ได้รับข้อมูลนั้น
  • เรียก factor-neutral ว่า risk-free ทั้งที่โมเดลมี residual, loadings เปลี่ยนได้และการซื้อขายมีข้อจำกัด

ก่อนคูณ matrix ให้ตอบสามคำถาม

  • แต่ละแถวและคอลัมน์แทนอะไร และใช้หน่วยใด?
  • input/output ที่ต้องการมีกี่ช่อง และ shape ของคำสั่งให้ผลชนิดนั้นหรือไม่?
  • ผลลัพธ์เป็น sensitivity, return, payoff หรือ P&L ภายใต้สมมติฐานใด?
