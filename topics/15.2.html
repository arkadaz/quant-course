15.2 Capital Asset Pricing Model (CAPM) — Beta, Alpha, and Required Return

หักผลจากตลาดออกก่อนเรียกส่วนที่เหลือว่าฝีมือ

หุ้นหนึ่งชนะตลาดในเดือนดี; ชัยชนะนี้เป็น skill หรือแค่ผลจาก beta ที่สูงกว่าตลาด? เฉลย: ต้องหักส่วนที่ beta อธิบายได้ก่อน แล้วจึงเรียกส่วนที่เหลือว่า alpha. CAPM ช่วยไม่ให้เราเรียกเงาตัวเองว่าเพื่อนใหม่.

การนำไปใช้และสิ่งที่ CAPM ไม่ได้สัญญา

บนโต๊ะ risk ใช้ rolling beta เพื่อทำ exposure report และกำหนด hedge band; ฝ่าย performance ใช้ alpha หลังหัก cash และ market exposure ด้วยข้อมูล timestamp เดียวกัน สมมติฐานสำคัญคือ investor ถือ mean–variance efficient portfolios, เข้าถึง rate เดียวกัน, ไม่มี friction และ beta คงที่ในช่วงประมาณ ซึ่งของจริงละเมิดได้ทุกข้อ

คำตอบและวิธีเช็ก

คำตอบ ตรวจเอง และแปลว่าอะไร

คำตอบกำหนด horizon หนึ่งเดือน, cash proxy 0.30%, expected SPY return 1.10% และ beta ของ NVDA 1.40 จึงได้ market premium 0.80 percentage points และ CAPM hurdle 1.42%. หาก NVDA เกิดจริง 2.00% ส่วนเกินเหนือ hurdle คือ 0.58 percentage points หรือ 5,800 USD บน notional 1 ล้าน USD ก่อนต้นทุน แต่ observation เดียวไม่ใช่ alpha ระยะยาว สำหรับ market-neutral target ให้ short SPY notional 1.40 ล้าน USD; หาก beta จริงอยู่ที่ 1.10 หรือ 1.70 จะเหลือ under-hedge หรือ over-hedge 300,000 USD

ตรวจเองใน 10 วินาที1.10% ลบ 0.30% = 0.80%; 0.30% บวก 1.40 คูณ 0.80% = 1.42%.

›โค้ดตรวจ hurdle, attribution และ hedge bandเปิดโค้ด
rf=.003
market=.011
beta=1.40
value=1_000_000
required=rf+beta*(market-rf)
realized=.020
above=realized-required
hedge=beta*value
assert abs(required-.0142)<1e-12
assert abs(above*value-5800)<1e-9
assert hedge==1_400_000
assert (1.10*value,1.70*value)==(1_100_000,1_700_000)
โค้ดใช้ decimal return ต่อเดือนและ USD ตาม symbol table จึงตรวจได้ทั้งผลตอบแทน 1.42%, attribution 5,800 USD และ hedge band โดยไม่สลับหน่วย

ก่อนไปต่อ — แบบจำลองหลายตัวขับเคลื่อน

ถ้า CAPM เรียก size, value หรือ momentum exposure ว่า alpha ทั้งหมด attribution จะปน skill กับ compensated risk หัวข้อถัดไปขยาย design matrix ให้มีตัวขับเคลื่อนหลายชุด และแสดงว่าการเลือกชุดอธิบายเปลี่ยนทั้ง alpha และ covariance ที่ใช้จัดพอร์ต

ระวังตรงนี้

กับดัก: alpha เป็นกำไรที่ยืนยันแล้ว

alpha ขึ้นกับ benchmark, sample, frequency และ estimation error ทั้งหมด beta เปลี่ยนได้ตาม regime และ CAPM อาจพลาด factors สำคัญ รายงาน alpha พร้อม confidence interval, transaction costs และ out-of-sample protocol เสมอ

สรุปที่ใช้ได้จริง

  • CAPM ใช้ beta ตั้ง required return ภายใต้ assumptions ที่ระบุ
  • alpha คือผลต่างจาก benchmark ไม่ใช่หลักฐาน skill ใน observation เดียว
  • ตัวอย่าง beta hedge ใช้ 1.40 ล้าน USD ต่อหุ้น 1 ล้าน USD เพื่อสอน notional ไม่ใช่แนะนำ order
  • horizon ของ , market premium และ return ต้องตรงกัน
