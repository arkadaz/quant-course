15.2 Capital Asset Pricing Model (CAPM) — Beta, Alpha, and Required Return

ผลตอบแทนที่ได้จากการเกาะตลาดซื้อได้ในราคาถูก ต้องหักส่วนนั้นออกก่อน ส่วนที่เหลือจึงมีสิทธิ์ถูกเรียกว่าฝีมือ

ปีที่ดัชนี S&P 500 ขึ้น 10% และเงินฝากระยะสั้นให้ 2% ผู้จัดการ A ทำได้ 6% ผู้จัดการ B ทำได้ 12% พอร์ตของ A มี beta 0.5 ของ B มี beta 1.5 กรรมการเสนอให้โบนัสฝีมือกับ B เพราะทำได้สองเท่าของ A ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก ใครก็ได้ที่ยืมเงินที่ 2% มาซื้อกองทุนดัชนี 1.5 เท่าของทุน จะได้ $1.5(10\%)-0.5(2\%)=14\%$ โดยไม่ต้องเลือกหุ้นเลย B จึงทำได้ต่ำกว่าของที่ลอกได้ฟรี 2 จุด ส่วน A ได้ 6% เท่ากับของที่ลอกได้ด้วย beta 0.5 พอดี alpha ของ A คือ 0 และของ B คือ −2% ถ้าจะให้โบนัสใคร ต้องเป็น A ก่อน B

ภาพรวมก่อนลงสูตร

ผลตอบแทนส่วนหนึ่งของทุกพอร์ตมาจากการเกาะตลาด ซึ่งใครก็ซื้อได้ด้วยกองทุนดัชนีกับเงินสด ส่วนที่ซื้อแบบนั้นไม่ได้คือสิ่งเดียวที่ควรได้ค่าธรรมเนียมฝีมือ CAPM ให้ไม้บรรทัดสำหรับแยกสองส่วนนี้ คือเส้นตรง Security Market Line (SML) ระหว่าง beta กับผลตอบแทนที่ควรได้

ในรูปด้านล่าง เส้นน้ำเงินคือ SML ของปีในโจทย์ เริ่มที่เงินสด 2% (beta 0) และผ่านตลาด 10% (beta 1) ทุกจุดบนเส้นลอกได้ด้วยการผสมดัชนีกับเงินสด A อยู่บนเส้นพอดี ส่วน B อยู่ใต้เส้น ระยะแนวตั้งระหว่างจุดจริงกับเส้นคือ alpha

หน้านี้จะวัด beta และ alpha ด้วย OLS แยกให้เห็นว่าบรรทัดไหนเป็นพีชคณิต บรรทัดไหนเป็นข้อสมมติของ CAPM พิสูจน์ว่าทำไมตัววัดความเสี่ยงต้องเป็น beta ไม่ใช่ SD ถามว่า alpha ที่เห็นเป็นโชคหรือฝีมือ และจบที่การตั้งราคาโครงการลงทุนหนึ่งชิ้น ซึ่งเป็นจุดที่คนใช้เส้นผิดบ่อยที่สุด

ขั้นที่ 1 — ลองด้วยมือ: ของที่ลอกได้ฟรีของแต่ละคน

โจทย์ให้อะไรมาบ้าง: $R_m=10\%$, $R_f=2\%$, A มี beta 0.5 ทำได้ 6% และ B มี beta 1.5 ทำได้ 12% คำถามที่ยุติธรรมไม่ใช่ “ใครได้มากกว่า” แต่เป็น “ถ้าไม่มีฝีมือเลย แค่ถือกองทุนดัชนีกับเงินสดให้ได้ beta เท่ากัน จะได้เท่าไร” เพราะสิ่งนั้นใครก็ทำได้ในราคาถูก

\[ \begin{aligned} R_{\text{copy},B}&=1.5R_m-0.5R_f\\ &=R_f+1.5(R_m-R_f)\\ &=2+1.5(8)=14\%,\\ R_{\text{copy},A}&=0.5R_m+0.5R_f\\ &=2+0.5(8)=6\%,\\ \alpha_B&=12-14=-2\%,\\ \alpha_A&=6-6=0\%. \end{aligned} \]

คำตอบ: B ลอกได้ด้วยการลงดัชนี 150% ของทุนและยืมเงินสด 50% ได้ 14% จึงทำได้ต่ำกว่าของฟรี 2 จุด A ลอกได้ด้วยการลงดัชนีครึ่งหนึ่งและถือเงินสดครึ่งหนึ่ง ได้ 6% เท่ากับที่ทำได้จริง เกณฑ์ที่ใช้เทียบ (hurdle) จึงไม่เท่ากัน ขึ้นกับว่าแต่ละคนเกาะตลาดแค่ไหน

ตรวจเองใน 10 วินาที: บรรทัดที่สองเขียนได้ทุก beta เป็น $R_f+\beta(R_m-R_f)$ ใส่ $\beta=1$ ได้ 10% คือตลาดเอง ใส่ $\beta=0$ ได้ 2% คือเงินสด ทั้งสองจุดต้องอยู่บนเส้นเสมอ ตรงกับจุดน้ำเงินสองจุดในรูป SML

ขั้นที่ 2 — นิยาม: regression ของ excess return บน excess return ของตลาด

โจทย์มือใช้ beta ที่มีคนบอกมา ของจริงต้องวัดจากข้อมูล เครื่องมือคือ เส้น OLS โดยให้ $x$ เป็น excess return ของตลาดและ $y$ เป็นของหุ้น สมการนี้เป็นนิยามของสิ่งที่เราวัด ยังไม่ใช่ทฤษฎี

\[ \begin{aligned} R_i-R_f&=\alpha_i+\beta_i(R_m-R_f)+\varepsilon_i,\\ \beta_i&:=\frac{\operatorname{Cov}(R_i,R_m)}{\operatorname{Var}(R_m)}=\frac{\sigma_{im}}{\sigma_m^2},\\ \alpha_i&:=(\mu_i-R_f)-\beta_i(\mu_m-R_f). \end{aligned} \]

beta แบบนี้คือ slope covariance หารด้วย variance ของ OLS ในรูปค่าของ model ไม่ใช่ค่าจากตัวอย่าง alpha แบบนี้ทำให้เส้นผ่านจุดค่าเฉลี่ย เหมือนที่อนุพันธ์ทิศ intercept บังคับใน OLS ผลที่ได้ฟรีคือ $\varepsilon_i$ มีค่าเฉลี่ยศูนย์และไม่มี covariance กับตลาด เพราะสองข้อนี้คือเงื่อนไขอนุพันธ์เป็นศูนย์สองข้อเดิม ไม่ใช่ข้อสมมติเพิ่ม

ทุกพจน์ต้องเป็นช่วงเวลาเดียวกัน ถ้า $R_i$ เป็นรายเดือน $R_f$ ก็ต้องเป็นดอกเบี้ยรายเดือน beta ไม่มีหน่วย ส่วน alpha มีหน่วย % ต่อช่วงเหมือนผลตอบแทน

ขั้นที่ 3 — ค่าคาดหวัง และข้อสมมติเดียวของ CAPM

ต่อไปหาค่าคาดหวังของทั้งสองข้าง ทุกบรรทัดจนถึงบรรทัดที่สามเป็นพีชคณิตที่จริงเสมอ บรรทัดที่สี่คือสิ่งเดียวที่ CAPM เพิ่มเข้ามา และเป็นสิ่งที่งานวิจัยหลายสิบปีต่อมาโจมตี

\[ \begin{aligned} \mathbb E[R_i-R_f]&=\alpha_i+\beta_i\,\mathbb E[R_m-R_f]+\mathbb E[\varepsilon_i],\\ \mathbb E[\varepsilon_i]&=0,\\ \mu_i-R_f&=\alpha_i+\beta_i(\mu_m-R_f),\\ \alpha_i&=0,\\ \mu_i&=R_f+\beta_i(\mu_m-R_f). \end{aligned} \]

บรรทัดที่สี่บอกว่าในดุลยภาพ ไม่มีสินทรัพย์ไหนให้ผลตอบแทนคาดหวังเกินหรือขาดจากที่ beta กำหนด เส้นในบรรทัดสุดท้ายคือ SML ผลตอบแทนที่ควรได้ขึ้นกับ beta ตัวเดียว ไม่ขึ้นกับ SD ของหุ้นเลย หุ้นที่ผันผวนมากแต่ไม่เกี่ยวกับตลาดควรได้แค่ดอกเบี้ยเงินสด

ข้ออ้างนี้แรงมาก มันยืนบนสามข้อ: ทุกคนเห็นข้อมูลชุดเดียวกัน ทุกคนเลือกพอร์ตด้วย mean–variance (หรือผลตอบแทนเป็น Normal) และตลาดอยู่ในดุลยภาพ ขั้นถัดไปจะแสดงว่าสามข้อนี้นำไปสู่ beta ได้อย่างไร และ model หลายปัจจัย จะแสดงว่าข้อมูลจริงไม่ค่อยเชื่อฟังมัน

ขั้นที่ 4 — ทำไมตัววัดความเสี่ยงต้องเป็น beta ไม่ใช่ SD

ก่อนอื่นต้องรู้ว่าพอร์ตตลาดพิเศษอย่างไร สมมติหุ้นสามตัวมีมูลค่าตลาด \$600, \$300 และ \$100 พันล้าน ทุกคนใช้ Markowitz กับตัวเลขชุดเดียวกัน จึงถือส่วนเสี่ยงเป็นพอร์ต Sharpe สูงสุดชุดเดียวกัน ต่างกันแค่แบ่งเงินสดเท่าไร นักลงทุน A มี \$1 ล้าน ลงส่วนเสี่ยง 70% นักลงทุน B มี \$3 ล้าน ลง 40% ส่วนเสี่ยงรวมคือ $0.7+1.2=1.9$ ล้าน ถ้าพอร์ต Sharpe ให้หุ้นแรก 60% ทั้งคู่ถือหุ้นแรกรวม $0.6(1.9)=1.14$ ล้าน เท่ากับ 60% ของเงินในหุ้นทั้งหมด ซึ่งคือน้ำหนักตามมูลค่าตลาด $600/1{,}000$ พอดี เมื่อรวมทุกคนแล้วต้องได้ตลาดทั้งตลาด พอร์ต Sharpe สูงสุดจึงต้องเป็นพอร์ตตลาด และเส้นที่ลากจากเงินสดผ่านตลาด (CML) คือเส้น Sharpe สูงสุด

ตอนนี้ผสมหุ้น $i$ น้ำหนัก $w$ เข้ากับตลาด ที่ $w=0$ คือพอร์ตตลาดพอดี เส้นโค้งของพอร์ตผสมผ่านจุดตลาด แต่ห้ามทะลุเหนือ CML เส้นโค้งเรียบที่แตะเส้นตรงโดยไม่ทะลุต้องสัมผัสกันพอดี slope ที่ $w=0$ จึงต้องเท่ากัน

\[ \begin{aligned} \mu(w)&:=w\mu_i+(1-w)\mu_m,\\ \sigma^2(w)&:=w^2\sigma_i^2+(1-w)^2\sigma_m^2\\ &\quad+2w(1-w)\sigma_{im},\\ \mu'(0)&=\mu_i-\mu_m,\\ \frac{d\sigma^2}{dw}(0)&=-2\sigma_m^2+2\sigma_{im},\\ \sigma'(0)&=\frac{\sigma_{im}-\sigma_m^2}{\sigma_m},\\ \frac{\mu'(0)}{\sigma'(0)}&=\frac{\mu_m-R_f}{\sigma_m},\\ \mu_i-\mu_m&=(\mu_m-R_f)\Big(\frac{\sigma_{im}}{\sigma_m^2}-1\Big),\\ \mu_i-R_f&=\frac{\sigma_{im}}{\sigma_m^2}(\mu_m-R_f). \end{aligned} \]

บรรทัดที่ห้าใช้กฎลูกโซ่: $\sigma=\sqrt{\sigma^2}$ จึงได้ $\sigma'=(\sigma^2)'/(2\sigma)$ และที่ $w=0$ มี $\sigma=\sigma_m$ บรรทัดที่หกคือเงื่อนไขสัมผัส: slope ของเส้นโค้งในระนาบ SD–ผลตอบแทน เท่ากับ slope ของ CML

คูณไขว้แล้วย้าย $\mu_m$ ไปรวมกับ $-R_f$ พจน์ $-1$ ในวงเล็บหักล้างพอดี เหลือ $\sigma_{im}/\sigma_m^2$ ซึ่งคือ beta ตามนิยาม ความเสี่ยงที่ถูกตั้งราคาจึงเป็น covariance กับตลาด ไม่ใช่ SD ของหุ้นเอง ถ้าหุ้นตัวไหนให้ผลตอบแทนคาดหวังสูงกว่านี้ เส้นโค้งของมันจะทะลุเหนือ CML ทุกคนจะแห่ซื้อจนราคาขึ้นและผลตอบแทนคาดหวังลงกลับมาที่เส้น

ขั้นที่ 5 — หุ้นหนึ่งตัว หนึ่งเดือน: hurdle เกินเท่าไร และ hedge เท่าไร

โจทย์ให้อะไรมาบ้าง: ถือ NVDA \$1,000,000 beta 1.40 (ค่าที่ตั้งเพื่อสาธิต) เดือนนี้เงินสดให้ 0.30% ผลตอบแทนคาดหวังของตลาด 1.10% และ NVDA ทำได้จริง 2.00%

\[ \begin{aligned} \mu_m-R_f&=1.10-0.30=0.80\%,\\ \text{hurdle}&=0.30+1.40(0.80)\\ &=0.30+1.12=1.42\%,\\ 2.00-1.42&=0.58\%,\\ 0.0058\times1{,}000{,}000&=5{,}800\ \text{USD},\\ N_h&=1.40\times1{,}000{,}000\\ &=1{,}400{,}000\ \text{USD}. \end{aligned} \]

คำตอบ: hurdle คือ 1.42% ต่อเดือน เดือนนี้ทำได้เกิน 0.58% หรือ \$5,800 และถ้าอยากตัดความเสี่ยงตลาดออก ต้อง short ดัชนีราว \$1.4 ล้าน แต่ 0.58% ยังไม่ใช่ alpha มันคือผลเดือนเดียวลบค่าคาดหวัง ซึ่งรวมทั้งตลาดเดือนนั้นที่อาจต่างจาก 1.10% และโชคของหุ้นตัวนี้ การประมาณ alpha ต้องใช้ผลตอบแทนจริงของตลาดหลายช่วง พร้อม SE

ตรวจเองใน 10 วินาที: $1.4\times0.8=1.12$ บวก 0.30 ได้ 1.42 และ $2.00-1.42=0.58$ สามก้อน 0.30 + 1.12 + 0.58 รวมกลับได้ 2.00 พอดี

ขั้นที่ 6 — hedge ตัดได้แค่ก้อนตลาด: แยก variance เป็นสองก้อน

short ดัชนี \$1.4 ล้านแล้วเหลือความเสี่ยงเท่าไร? ต้องแยก variance ของหุ้นเป็นส่วนที่มาจากตลาดกับส่วนที่เป็นของหุ้นเอง สมมติ SD รายเดือนของตลาด 4% และของ $\varepsilon$ 5% ใช้ variance ของผลบวก

\[ \begin{aligned} \operatorname{Var}(R_i)&=\beta^2\sigma_m^2+\sigma_\varepsilon^2\\ &\quad+2\beta\operatorname{Cov}(R_m,\varepsilon),\\ \operatorname{Cov}(R_m,\varepsilon)&=0,\\ \operatorname{Var}(R_i)&=1.4^2(4^2)+5^2\\ &=31.36+25=56.36,\\ \sigma_i&=\sqrt{56.36}\approx7.51\%,\\ 31.36/56.36&\approx55.6\%. \end{aligned} \]

พจน์ไขว้หายเพราะนิยามของ regression ทำให้ $\varepsilon$ ไม่มี covariance กับตลาด ความเสี่ยงของหุ้นตัวนี้ 55.6% มาจากตลาด อีก 44.4% เป็นของตัวเอง hedge ด้วยดัชนีลบได้เฉพาะก้อนแรก หลัง hedge SD จึงลดจาก 7.51% เหลือ 5% ไม่ใช่ศูนย์

ทำไมตลาดไม่จ่ายค่าตอบแทนให้ก้อนที่สอง? ถือ $N$ ตัวที่ beta 1.4 เท่ากัน และ $\varepsilon$ อิสระกันที่ SD 5% น้ำหนักเท่ากัน ก้อนเฉพาะตัวของพอร์ตเหลือ $5\%/\sqrt N$ ที่ 100 ตัวเหลือ 0.5% ใครก็กระจายทิ้งได้ฟรี แต่ก้อนตลาด $1.4\times4\%=5.6\%$ ไม่ลดเลย ดังรูปด้านล่าง ก้อนตลาดจึงเป็นก้อนเดียวที่ต้องจ่ายราคา

ขั้นที่ 7 — alpha จากห้าเดือนของ AAPL: โชคหรือฝีมือ

โจทย์ให้อะไรมาบ้าง: ห้าเดือนสมมติจากหน้า OLS SPY $(2.0, -1.5, 0.5, 3.0, -1.0)$ และ AAPL $(3.4, -2.8, 0.2, 5.1, -1.4)$ % ต่อเดือน ได้ $\hat\beta=1.707483$, $\bar x=0.60$, $\bar y=0.90$, $S_{xx}=14.70$, $s_e=0.409136$ ให้ $R_f=0$ ก่อน variance ของ $\hat\alpha=\bar y-\hat\beta\bar x$ หาได้จากสองก้อนที่ไม่มี covariance กัน เพราะ $\operatorname{Cov}(\bar y,\hat\beta)=\sigma^2\sum(x_t-\bar x)/(nS_{xx})=0$

\[ \begin{aligned} \hat\alpha&=0.90-1.707483(0.60)\\ &\approx-0.124490,\\ \operatorname{Var}(\hat\alpha)&=\operatorname{Var}(\bar y)+\bar x^2\operatorname{Var}(\hat\beta)\\ &=\sigma^2\Big(\frac1n+\frac{\bar x^2}{S_{xx}}\Big),\\ \operatorname{SE}(\hat\alpha)&=0.409136\sqrt{0.2+\frac{0.36}{14.70}}\\ &\approx0.193850,\\ t&=\frac{-0.124490}{0.193850}\approx-0.64,\\ \hat\alpha&\pm3.182(0.193850)\\ &\approx[-0.741,\ 0.492],\\ R_f=0.15:\quad\hat\alpha&=0.75-1.707483(0.45)\\ &\approx-0.018367. \end{aligned} \]

คำตอบ: AAPL อยู่ใต้ SML เดือนละ 0.1245% หรือราว 1.49% ต่อปี แต่ $t=-0.64$ ห่างจากศูนย์ไม่ถึงหนึ่ง SE และช่วง 95% ครอบศูนย์สบาย ๆ จึงสรุปไม่ได้เลยว่าต่ำกว่าเส้นจริง ถ้าดอกเบี้ยเงินสดเป็น 0.15% ต่อเดือน alpha เหลือ −0.0184% ($t\approx-0.10$) เพราะ alpha ขยับไป $(\hat\beta-1)R_f=0.7075(0.15)=0.1061$ ใส่ดอกเบี้ยให้ถูกก่อนตัดสินใคร

ส่วน beta แยกความเสี่ยงได้ $\hat\beta^2S_{xx}/S_{yy}=98.84\%$ เป็นของตลาด ซึ่งคือ $R^2$ ของเส้นเดิม ถือ AAPL \$10 ล้าน ต้อง short ดัชนี \$17,074,830 SD รายเดือนของพอร์ตลดจาก 3.292% เหลือ 0.354% หรือลดลง 89.2% แต่ช่วง 95% ของ beta [1.3679, 2.0471] แปลเป็นขนาด short \$13.68 ถึง \$20.47 ล้าน

ตรวจเองใน 10 วินาที: $\sqrt{0.2+0.0245}=\sqrt{0.2245}\approx0.4738$ คูณ 0.4091 ได้ราว 0.1939 และ $-0.1245/0.1939\approx-0.64$

ขั้นที่ 8 — เลือกผู้ชนะจากหลายคน แล้วโอกาสที่เป็นแค่โชคพุ่งขึ้น

ผู้จัดการคนหนึ่งชนะตลาด (หลังปรับความเสี่ยงแล้ว) 9 ใน 10 ปี ถ้าไม่มีฝีมือเลย แต่ละปีชนะด้วยโอกาสครึ่งหนึ่งและปีต่าง ๆ อิสระกัน จำนวนปีที่ชนะจึงเป็น binomial ที่ $n=10$, $p=1/2$ คำถามที่สำคัญกว่าคือ คนนี้ถูกเลือกมาจากกี่คน

\[ \begin{aligned} P(X\ge9)&=\frac{\binom{10}{9}+\binom{10}{10}}{2^{10}}\\ &=\frac{11}{1024}\approx1.07\%,\\ P_M&:=1-\Big(1-\frac{11}{1024}\Big)^M,\\ P_{20}&\approx1-0.8057=19.43\%,\\ P_{100}&\approx1-0.3396=66.04\%. \end{aligned} \]

$P_M$ คือโอกาสที่ในผู้จัดการไร้ฝีมือ $M$ คน มีอย่างน้อยหนึ่งคนชนะ 9 ปีขึ้นไป คิดจากส่วนกลับ: โอกาสที่ไม่มีใครทำได้เลยคือ $(1-11/1024)^M$ เมื่อผลของแต่ละคนอิสระกัน

ถ้าเลือกคนนี้ไว้ก่อนดูผล 1.07% ก็ดูเหมือนฝีมือ แต่ถ้าเลือกเพราะผลดีที่สุดจาก 100 คน โอกาสที่เป็นแค่โชคคือ 66% และคาดว่าจะเจอคนแบบนี้ $100\times11/1024\approx1.07$ คนโดยไม่มีฝีมือใครเลย ต้องถามก่อนเสมอว่ามีกี่คนที่ไม่ได้ถูกเอามาให้ดู (multiple testing)

อีกรูปแบบของกับดักเดียวกันคือ survivorship bias ลองคิดว่าผู้จัดการทุกคนไม่มีฝีมือ และทุกสิ้นปีคนที่แพ้ตลาดถูกไล่ออก หลังผ่านไปหนึ่งปี ทุกคนที่ยังอยู่มีสถิติชนะ 100% ทั้งที่ไม่มีใครมีฝีมือ ฐานข้อมูลกองทุนที่เก็บเฉพาะกองที่ยังเปิดอยู่จึงสวยกว่าความจริงเสมอ

ขั้นที่ 9 — โครงการเดียวใช้ CML ไม่ได้: ต้องใช้ beta

ท่อส่งน้ำมันขายอยู่ที่ \$875 คาดว่าจะจ่าย \$1,000 ในหนึ่งปี ผลตอบแทนมี SD 40% และเงินที่จ่ายมี covariance กับตลาด 38.4 (หน่วย USD คูณผลตอบแทน) ตลาดรายปีมี $\mu_m=17\%$, $\sigma_m=12\%$ และ $R_f=5\%$ มีคนเสนอให้ใช้ CML เป็นเกณฑ์ เพราะมันใช้ SD ซึ่งหาง่าย

\[ \begin{aligned} \mathbb E[R]&=1000/875-1\approx14.29\%,\\ r_{\rm CML}&=R_f+\frac{\mu_m-R_f}{\sigma_m}\,\sigma\\ &=0.05+1.00(0.40)=45\%,\\ \beta&=\frac{38.4/875}{0.12^2}\approx3.048,\\ r_{\rm SML}&=0.05+3.048(0.12)\\ &\approx41.57\%. \end{aligned} \]

ทั้งสองเกณฑ์ปฏิเสธ 14.29% แต่ตัวเลขต่างกัน และเหตุผลต่างกันมาก CML ใช้ได้เฉพาะพอร์ตที่ผสมเงินสดกับตลาด ซึ่งความเสี่ยงทั้งหมดเป็นความเสี่ยงตลาด โครงการเดี่ยวมีความเสี่ยงเฉพาะตัวที่รูปการกระจายเพิ่งแสดงว่าไม่ได้ค่าตอบแทน

เขียน beta ใหม่เป็น $\rho\sigma/\sigma_m$ จะเห็นว่า SML ต่างจาก CML แค่ตัวคูณ $\rho$ ที่นี่ $\rho\approx0.914$ ถ้าโครงการไม่เกี่ยวกับตลาดเลย ($\rho=0$) CML ยังเรียก 45% แต่ SML เรียกแค่ 5% คนที่ใช้ CML จะปฏิเสธโครงการดีทุกโครงการที่ผันผวนแต่ไม่เกี่ยวกับตลาด

ขั้นที่ 10 — ราคายุติธรรมตาม CAPM: หักค่าความเสี่ยงก่อน แล้วคิดลดด้วยดอกเบี้ยเงินสด

แทนที่จะเทียบผลตอบแทนกับ hurdle เราถามกลับได้ว่าท่อส่งน้ำมันควรมีราคาเท่าไร สมการ SML ที่ใช้กับผลตอบแทน $X/P-1$ มีตัวไม่รู้ $P$ ซ่อนอยู่ทั้งสองข้าง ให้ $\lambda:=(\mu_m-R_f)/\sigma_m^2$

\[ \begin{aligned} \lambda&=\frac{0.12}{0.0144}\approx8.333,\\ \frac{\mathbb E[X]}{P}-1&=R_f+\lambda\operatorname{Cov}(X/P,R_m),\\ \mathbb E[X]-P&=PR_f+\lambda\operatorname{Cov}(X,R_m),\\ P&=\frac{\mathbb E[X]-\lambda\operatorname{Cov}(X,R_m)}{1+R_f}\\ &=\frac{1000-8.333(38.4)}{1.05}\\ &=\frac{1000-320}{1.05}\approx647.62. \end{aligned} \]

จังหวะสำคัญคือบรรทัดที่สามที่คูณทั้งสมการด้วย $P$ ทำได้เพราะ $P$ เป็นราคาที่รู้แล้ววันนี้ จึงดึงออกจาก covariance ได้: $P\operatorname{Cov}(X/P,R_m)=\operatorname{Cov}(X,R_m)$ แล้ว $P$ เหลืออยู่ข้างเดียว

อ่านบรรทัดสุดท้าย: หักค่าความเสี่ยง \$320 ออกจาก \$1,000 ที่คาดไว้ก่อน ได้ \$680 ที่เทียบเท่าเงินแน่นอน แล้วคิดลดด้วย 5% ได้ \$647.62 ราคาตลาด \$875 จึงแพงไป \$227.38 ซึ่งเป็นอีกทางพูดว่า 14.29% ต่ำกว่า hurdle ของ SML

ตรวจเองใน 10 วินาที: ที่ราคา \$647.62 ผลตอบแทนคาดหวังคือ $1000/647.62-1\approx54.41\%$ และ beta ใหม่คือ $38.4/(647.62\times0.0144)\approx4.118$ SML ให้ $5\%+4.118(12\%)\approx54.41\%$ ตรงกัน ราคาและ hurdle เป็นคำตอบเดียวกันมองสองด้าน

ความผิดที่ทำให้ตัดสินฝีมือผิดคน

ดอกเบี้ยคนละช่วงเวลา: ใส่ดอกเบี้ยรายปี 3.6% ลงในสูตรรายเดือนของ NVDA จะได้ hurdle $3.6+1.4(1.10-3.6)=0.10\%$ แทน 1.42% ผลตอบแทน 2.00% ดูเกิน hurdle ถึง 1.9 จุด ทั้งที่ของจริงเกินแค่ 0.58 จุด ตรวจทุกครั้งว่า $R_i$, $R_m$ และ $R_f$ เป็นช่วงเวลาเดียวกัน

ผลเดือนเดียวเรียกว่า alpha: 0.58% ของ NVDA เป็นผลต่างของเดือนเดียว ถ้าตลาดเดือนนั้นให้ 3% แทน 1.10% ส่วนเกินส่วนใหญ่ก็มาจากตลาด ไม่ใช่หุ้น การวัด alpha ต้องใช้ regression บนผลตอบแทนจริงของตลาดหลายช่วงพร้อม SE และห้าเดือนของ AAPL แสดงแล้วว่า SE ใหญ่กว่า alpha

ใช้ CML กับสินทรัพย์เดี่ยว: โครงการที่ไม่เกี่ยวกับตลาดถูกเรียก hurdle 45% แทน 5% โครงการดีจะถูกปฏิเสธ และโครงการที่เกาะตลาดมากกลับดูผ่านง่ายเกินจริง

เทียบ Sharpe ของหุ้นเดี่ยวกับ slope ของ CML: กฎ “ซื้อหุ้นที่ Sharpe สูงกว่า slope ของ CML” แทบไม่เคยให้สัญญาณซื้อ หุ้นที่ให้ 12% SD 30% มี Sharpe $(12-5)/30\approx0.23$ ต่ำกว่า CML 1.00 มาก แต่ไม่ได้แปลว่าหุ้นแพง หุ้นเดี่ยวแบกความเสี่ยงเฉพาะตัวที่กระจายทิ้งได้ Sharpe ของมันจึงต่ำกว่า CML เกือบเสมอ เกณฑ์ Sharpe ใช้กับพอร์ตทั้งก้อน ส่วนหุ้นเดี่ยวให้ดู alpha เทียบกับ SML และกฎ “ซื้อเมื่อ alpha บวก” ก็ใช้ได้เมื่อ alpha หนีจากศูนย์ได้หลาย SE เท่านั้น

ใช้ทำอะไรบนโต๊ะจริง

ฝ่ายวัดผลใช้ alpha หลังหักเงินสดและ beta ตัดสินว่าผู้จัดการสร้างมูลค่าจริงหรือแค่รับความเสี่ยงตลาดมากกว่าคนอื่น โต๊ะความเสี่ยงใช้ beta ที่คำนวณจากหน้าต่างข้อมูลที่เลื่อนไปเรื่อย ๆ รายงาน exposure และตั้งขนาด hedge ด้วยสัญญาซื้อขายล่วงหน้าหรือ ETF ดัชนีที่สภาพคล่องสูง ฝ่ายการเงินองค์กรใช้ SML ตั้งผลตอบแทนขั้นต่ำของโครงการ และทุกงานต้องใช้ข้อมูลช่วงเวลาและดัชนีอ้างอิงเดียวกันทั้งระบบ

ข้อควรรู้จากข้อมูลจริง: SML ที่วัดได้แบนกว่าทฤษฎี หุ้น beta ต่ำได้ผลตอบแทนเกิน hurdle และหุ้น beta สูงได้ต่ำกว่า hurdle อย่างสม่ำเสมอ (งานวิจัยเรียกว่า betting against beta) หุ้นเล็กและหุ้นราคาถูกเทียบมูลค่าทางบัญชีก็ให้ผลต่างจากที่ beta บอก alpha ที่วัดด้วยตลาดตัวเดียวจึงมักปนกับ exposure ที่ไม่ได้ใส่ ซึ่งคือเหตุผลของ model หลายปัจจัย

hurdle $=2+1.2(8)=11.6\%$ alpha $=11-11.6=-0.6\%$ C ชนะตลาด 1 จุดแต่ยังแพ้ของที่ลอกได้ด้วย beta 1.2 อยู่ 0.6 จุด ในรูป SML จุดของ C อยู่ใต้เส้นที่ beta 1.2

function finite(...values) {
  if (!values.every(Number.isFinite)) throw new TypeError('All inputs must be finite numbers');
}
// Required return on the security market line: cash plus beta times the market premium.
function hurdle(rf, marketMean, beta) {
  finite(rf, marketMean, beta);
  return rf + beta * (marketMean - rf);
}
// Variance split when the residual is uncorrelated with the market.
function splitRisk(beta, marketSD, residualSD) {
  finite(beta, marketSD, residualSD);
  if (marketSD < 0 || residualSD < 0) throw new RangeError('Standard deviations cannot be negative');
  const market = beta * beta * marketSD * marketSD, total = market + residualSD * residualSD;
  return {total, sd: Math.sqrt(total), marketShare: total === 0 ? null : market / total};
}
// SD of an equal-weight portfolio of N stocks with the same beta and independent residuals.
function diversifiedSD(beta, marketSD, residualSD, N) {
  finite(beta, marketSD, residualSD, N);
  if (!Number.isInteger(N) || N < 1) throw new RangeError('N must be a positive whole number');
  return Math.sqrt((beta * marketSD) ** 2 + residualSD ** 2 / N);
}
// OLS of excess stock returns on excess market returns, with the standard errors of both coefficients.
function capmRegression(market, stock, rf) {
  if (!Array.isArray(market) || !Array.isArray(stock) || market.length !== stock.length) {
    throw new TypeError('Market and stock returns must be arrays of the same length');
  }
  finite(rf, ...market, ...stock);
  const n = market.length;
  if (n < 3) throw new RangeError('Need at least three periods to estimate alpha, beta and their error');
  const x = market.map(v => v - rf), y = stock.map(v => v - rf);
  const xbar = x.reduce((s, v) => s + v, 0) / n, ybar = y.reduce((s, v) => s + v, 0) / n;
  let Sxy = 0, Sxx = 0, Syy = 0;
  for (let t = 0; t < n; t++) { Sxy += (x[t] - xbar) * (y[t] - ybar); Sxx += (x[t] - xbar) ** 2; Syy += (y[t] - ybar) ** 2; }
  if (Sxx === 0) throw new RangeError('Market return never changes, so beta is undefined');
  const beta = Sxy / Sxx, alpha = ybar - beta * xbar, sse = Syy - beta * Sxy, s2 = sse / (n - 2);
  const seAlpha = Math.sqrt(s2 * (1 / n + xbar * xbar / Sxx)), seBeta = Math.sqrt(s2 / Sxx);
  return {beta, alpha, seAlpha, tAlpha: alpha / seAlpha, seBeta, sse, Syy, r2: 1 - sse / Syy,
    sdStock: Math.sqrt(Syy / (n - 1)), sdHedged: Math.sqrt(sse / (n - 1))};
}
// P(at least k wins in n fair coin flips), and the chance that the best of M such managers clears it.
function luckyBest(n, k, M) {
  if (![n, k, M].every(Number.isInteger) || n < 1 || k < 0 || k > n || M < 1) {
    throw new RangeError('Need whole numbers with 0 <= k <= n and at least one manager');
  }
  let ways = 0, choose = 1;
  for (let j = 0; j <= n; j++) {
    if (j >= k) ways += choose;
    choose = choose * (n - j) / (j + 1);
  }
  const one = ways / 2 ** n;
  return {one, best: 1 - (1 - one) ** M, expectedLucky: M * one};
}
// A one-period asset paying X: CAPM value = E[X]/(1+rf) minus a discount for covariance with the market.
function capmPrice(expectedPayoff, covWithMarket, rf, marketMean, marketSD) {
  finite(expectedPayoff, covWithMarket, rf, marketMean, marketSD);
  if (!(marketSD > 0)) throw new RangeError('Market SD must be positive');
  const presentValue = expectedPayoff / (1 + rf);
  const discount = covWithMarket * (marketMean - rf) / ((1 + rf) * marketSD ** 2);
  return {presentValue, discount, price: presentValue - discount};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • hurdle ของสินทรัพย์คือ $R_f+\beta(\mu_m-R_f)$ ซึ่งคือผลตอบแทนที่ลอกได้ด้วยดัชนีกับเงินสด B ที่ทำได้ 12% จึงแพ้ของฟรี 14% และ alpha คือระยะแนวตั้งจาก SML
  • regression นิยาม beta และ alpha ข้อสมมติเดียวของ CAPM คือ alpha เท่ากับศูนย์ และมันพิสูจน์ได้จากการที่พอร์ตผสมต้องแตะ CML ที่พอร์ตตลาด
  • hedge ด้วยดัชนีตัดได้เฉพาะก้อน $\beta^2\sigma_m^2$ ก้อน $\sigma_\varepsilon^2$ ยังอยู่ และกระจายหายได้เมื่อถือหลายตัว ตลาดจึงจ่ายค่าตอบแทนให้ beta ไม่ใช่ SD
  • alpha −0.1245% ต่อเดือนของห้าเดือนมี $t=-0.64$ ยังเป็น noise และผู้ชนะที่ถูกเลือกจาก 100 คนมีโอกาส 66% เป็นแค่โชค
  • สินทรัพย์เดี่ยวต้องตั้งราคาด้วย beta ท่อส่งน้ำมันมีราคายุติธรรม \$647.62 ไม่ใช่ \$875
