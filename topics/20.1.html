20.1 Zero Rates, Forward Rates, and Bootstrapping

ราคาพันธบัตรในตลาดซ่อนราคาของเงิน \$1 ในแต่ละวันข้างหน้าไว้ เราแกะมันออกมาทีละอายุจากสั้นไปยาว แล้วเขียนตัวเลขชุดเดียวกันใหม่เป็น zero rate และ forward rate

เช้าวันหนึ่งโต๊ะตราสารหนี้เห็นราคาสี่ตัว (ตัวเลขสมมติ ต่อหน้าตั๋ว \$100): zero-coupon bond 6 เดือนราคา \$97.55, zero-coupon bond 1 ปีราคา \$95.05, note 18 เดือนคูปอง 4.80% ต่อปีจ่ายทุกครึ่งปีราคา \$100 และ note 2 ปีคูปอง 5.00% ราคา \$100 บริษัทต้องจ่าย \$10,000,000 ในอีก 18 เดือนและอยากกันเงินไว้วันนี้ให้พอดี เพื่อนร่วมโต๊ะบอกว่า note 18 เดือนขายที่ราคาหน้าตั๋ว แปลว่าตลาดให้ 4.80% คิดลดด้วย 4.80% ทบครึ่งปีสามงวดได้ \$9,313,225.75 ถูกไหม?

ลองตอบก่อนเปิดเฉลย

เกือบ แต่ไม่ถูก ต้องกันเงิน \$9,314,218.75 วิธีของเพื่อนขาดไป \$993.00 เพราะ 4.80% เป็นอัตราเฉลี่ยของเงินสามก้อนที่มาคนละวัน ไม่ใช่ราคาของเงินก้อนเดียวในเดือนที่ 18 ราคาที่ถูกได้จากการหักคูปองสองงวดแรกออกจาก note ด้วยราคาของ zero สองตัว เหลือราคาของ \$1 ในเดือนที่ 18 เท่ากับ 0.931421875

ภาพรวมก่อนลงสูตร

ทุกการคิดราคาในตลาดดอกเบี้ยใช้ของชิ้นเดียว คือราคาวันนี้ของเงิน \$1 ที่จะได้ในวันหนึ่งข้างหน้า เรียกว่า discount factor ตอนเรียน time value of money เราใช้มันย้ายเงินข้ามเวลา และตอนคิด ราคาพันธบัตรและ duration เราคูณเงินแต่ละก้อนด้วยมัน ปัญหาคือตลาดไม่ได้ประกาศ discount factor ตลาดประกาศราคาพันธบัตรที่จ่ายเงินหลายก้อนปนกัน

ทางออกคือแกะทีละตัว ตราสารสั้นสุดมีเงินก้อนเดียว อ่าน discount factor ได้ทันที ตราสารถัดไปมีเงินหลายก้อน แต่ทุกก้อนยกเว้นก้อนสุดท้ายรู้ราคาแล้วจากตัวก่อนหน้า สมการจึงเหลือตัวไม่รู้ตัวเดียว รูปด้านล่างวาดเงินสดของสี่ตราสารในโจทย์เปิดหน้า แต่ละแถวเพิ่มก้อนใหม่สีส้มแค่ก้อนเดียว วิธีไล่แกะแบบนี้เรียกว่า bootstrapping

ได้ discount factor แล้ว เราจะเขียนมันใหม่สองแบบ แบบแรกคือ zero rate อัตราเฉลี่ยจากวันนี้ถึงวันนั้น แบบที่สองคือ forward rate อัตราของช่วงหนึ่งในอนาคตที่ล็อกได้ตั้งแต่วันนี้ ปิดท้ายด้วยเหตุผลที่ yield ของพันธบัตรซึ่งตลาดชอบ quote เอาไปคิดลดเงินก้อนเดียวไม่ได้

Zero-coupon bond และ discount factor
zero-coupon bond จ่ายเงินก้อนเดียวตอนครบกำหนด ไม่มีคูปองระหว่างทาง ราคาของมันต่อหน้าตั๋ว \$1 จึงเป็น discount factor ของวันนั้นพอดี ใช้ย้ายเงินอนาคตมาเป็นเงินวันนี้
Bootstrapping
การแกะ discount factor ทีละอายุจากตราสารสั้นไปยาว ตราสารใหม่แต่ละตัวมีเงินแค่ก้อนเดียวที่ยังไม่รู้ราคา ก้อนอื่นใช้ค่าที่แกะไว้แล้ว มีไว้เพราะตลาดขายตราสารที่มีคูปอง ไม่ได้ขาย discount factor ตรง ๆ
Zero rate (spot rate)
อัตราต่อปีที่ให้ discount factor ของอายุหนึ่งพอดีภายใต้วิธีทบต้นที่ประกาศไว้ เป็นอีกวิธีเขียน discount factor ให้คนคุยกันรู้เรื่อง ไม่ใช่ข้อมูลใหม่
Forward rate
อัตราที่ตกลงวันนี้สำหรับช่วงเวลาที่เริ่มในอนาคต ถูกบังคับด้วยการห้ามเงินฟรีจาก discount factor สองตัว ไม่ใช่คำทำนายว่าอัตราจริงจะเป็นเท่าไร
Forward Rate Agreement (FRA)
สัญญานอกตลาด (over-the-counter) ที่ล็อกอัตราดอกเบี้ยแบบ simple ของช่วงอนาคต ใช้ล็อกต้นทุนกู้หรือผลตอบแทนเงินฝากล่วงหน้า และสร้างเองได้ด้วย zero สองตัว
Par yield และ yield to maturity
par yield คือคูปองที่ทำให้พันธบัตรใหม่ราคาเท่าหน้าตั๋ว yield to maturity คืออัตราเดียวที่คิดลดเงินทุกก้อนของพันธบัตรแล้วได้ราคาตลาด ทั้งสองเป็นค่าเฉลี่ยของหลายอายุ ใช้ quote ได้แต่ใช้คิดลดเงินก้อนเดียวไม่ได้

สัญลักษณ์ความหมายหน่วย

ขั้นที่ 1 — สองจุดแรกอ่านได้ทันทีจาก zero-coupon bond

เริ่มจากของที่ง่ายที่สุด zero-coupon bond มีเงินก้อนเดียว ราคาของมันหารด้วยหน้าตั๋วจึงเป็นราคาของเงิน \$1 ในวันครบกำหนด ซึ่งคือนิยามของ discount factor ไม่มีอะไรต้องแกะ

\[ \begin{aligned} D(0,0.5)&=\frac{97.55}{100}\\ &=0.9755,\\ D(0,1)&=\frac{95.05}{100}\\ &=0.9505. \end{aligned} \]

เงิน \$1 ที่จะได้ในอีก 6 เดือน วันนี้ซื้อได้ด้วย 97.55 เซนต์ และ \$1 ในอีกหนึ่งปีซื้อได้ด้วย 95.05 เซนต์ หารด้วย 100 เพราะราคา quote ต่อหน้าตั๋ว \$100

ตำราดอกเบี้ยส่วนใหญ่เขียนราคานี้ว่า $P(t,T)$ คือราคาที่เวลา $t$ ของเงิน \$1 ตอน $T$ เรียกตัวมันเองว่า zero-coupon bond หรือ T-bond และ $P(t,t)=1$ เสมอ เพราะเงิน \$1 ที่ได้ตอนนี้ก็มีค่า \$1 วันนี้คือ $t=0$ จึงได้ $P(0,T)=D(0,T)$ หน้านี้ใช้ $D$ และใช้ $P(t,T)$ เมื่อต้องพูดถึงราคาในวันอนาคต ยิ่งอัตราสูง เส้นของ $P(0,T)$ ยิ่งตกเร็วตาม $T$

ขั้นที่ 2 — ทำไมราคาทั้งใบต้องเท่าผลบวกของชิ้นย่อย

bootstrapping ทั้งหมดยืนบนประโยคเดียว: ราคาของตราสารที่จ่ายเงินหลายก้อนต้องเท่าผลบวกของราคาแต่ละก้อน (linear pricing) ก่อนใช้ ต้องรู้ว่าทำไมมันจริงและจริงเมื่อไร ลองสมมติว่ามีคนขายเงิน \$100 ที่ 6 เดือนรวมกับ \$100 ที่ 1 ปีเป็นก้อนเดียวในราคา \$191.00

\[ \begin{aligned} p_{\rm A}+p_{\rm B}&=97.55+95.05\\ &=192.60,\\ 192.60-191.00&=1.60,\\ PV_{6\%}&=\frac{50}{1.06}+\frac{50}{1.06^2}\\ &\quad+\frac{1{,}050}{1.06^3}\\ &=973.27,\\ PV_{4\%}&=1{,}027.75. \end{aligned} \]

ซื้อก้อนรวมที่ \$191.00 แล้วขายแยกเป็น zero สองตัวได้ \$192.60 เก็บ \$1.60 วันนี้ ส่วนเงินในอนาคตหักกันพอดี (ได้จากก้อนรวม จ่ายให้คนที่ซื้อ zero ไป) ถ้าก้อนรวมขายแพงกว่า \$192.60 ก็ทำกลับทาง ราคาจึงถูกบีบให้เท่ากันพอดี ข้อแม้มีสองข้อ: ชิ้นย่อยต้องซื้อขายได้คล่อง และกู้กับฝากได้ที่อัตราเดียวกัน พันธบัตรรัฐบาลสหรัฐฯ แยกขายทีละก้อนได้จริงในชื่อ STRIPS ข้อแรกจึงใกล้ความจริง

ถ้าข้อสองไม่จริง ราคาจะเหลือเป็นช่วง ไม่ใช่จุด สองแถวล่างคือสัญญาที่จ่าย \$50, \$50 และ \$1,050 ในปีที่ 1 ถึง 3 เมื่อกู้ได้ที่ 6% แต่ฝากได้แค่ 4% ถ้าสัญญาขายต่ำกว่า \$973.27 ซื้อมันแล้วกู้เงินเท่ามูลค่าที่ 6% ของแต่ละก้อน เงินที่สัญญาจ่ายใช้คืนหนี้ได้พอดี ได้ส่วนต่างฟรีวันนี้ ถ้าขายแพงกว่า \$1,027.75 ขายสัญญาแล้วฝากเงินที่ 4% ให้งอกเป็นเงินที่ต้องจ่าย ระหว่างสองค่านี้ไม่มีใครเก็บเงินฟรีได้ ถ้ากู้และฝากได้ 5% เท่ากัน ช่วงหดเหลือ \$1,000.00 จุดเดียว เป็นเหตุผลเดียวกับที่ใช้ตอน cash-and-carry ของสัญญา forward

ขั้นที่ 3 — note 18 เดือน: หักคูปองที่รู้ราคาแล้วออก

note 18 เดือนจ่ายสามก้อน: คูปองครึ่งปี 2.40 ต่อหน้าตั๋ว \$100 ที่เดือน 6 และ 12 และ 102.40 (คูปองรวมเงินต้น) ที่เดือน 18 ราคาทั้งใบเท่าผลบวกของชิ้นย่อยตามเหตุผลที่เพิ่งเห็น สองชิ้นแรกรู้ราคาจาก zero สองตัว สมการจึงเหลือตัวไม่รู้ตัวเดียว

\[ \begin{aligned} \frac{4.80}{2}&=2.40,\\ 100&=2.4\,D(0,0.5)\\ &\quad+2.4\,D(0,1)\\ &\quad+102.4\,D(0,1.5),\\ 2.4(1.9260)&=4.6224,\\ D(0,1.5)&=\frac{100-4.6224}{102.4}\\ &=\frac{95.3776}{102.4}\\ &=0.931421875. \end{aligned} \]

คูปองสองก้อนแรกมีราคารวม \$4.6224 วันนี้ ราคา note ที่เหลือ \$95.3776 จึงเป็นราคาของเงิน \$102.40 ในเดือนที่ 18 หารออกได้ราคาของ \$1 คือ 0.931421875 (หารลงตัวพอดีเพราะ 1,024 เท่ากับ $2^{10}$)

จุดที่ต้องจับให้ได้คือก้อนสุดท้ายเป็น 102.40 ไม่ใช่ 2.40 หรือ 100 และการหักแบบนี้ใช้ได้เพราะคูปองสองก้อนแรกของ note เหมือน zero สองตัวทุกอย่าง ต่างกันแค่ขนาด: คูปอง 2.40 ในเดือนที่ 6 มีค่าเท่า zero 6 เดือน 0.024 ใบ

ขั้นที่ 4 — คำตอบของโจทย์เปิดหน้า: เงิน \$10 ล้านในเดือนที่ 18

โจทย์ให้อะไรมาบ้าง: ต้องจ่าย \$10,000,000 ในเดือนที่ 18 และราคาของ \$1 ในวันนั้นคือ $D(0,1.5)=0.931421875$ ที่เพิ่งแกะได้ เพื่อนคิดลดด้วย 4.80% ทบครึ่งปีสามงวด คือหารด้วย $1.024^3$

\[ \begin{aligned} PV&=10^7(0.931421875)\\ &=9{,}314{,}218.75,\\ PV_{4.80}&=\frac{10^7}{1.024^3}\\ &=\frac{10^7}{1.073741824}\\ &=9{,}313{,}225.75,\\ PV-PV_{4.80}&=993.00. \end{aligned} \]

คำตอบ: ต้องกันเงิน \$9,314,218.75 วิธีของเพื่อนขาด \$993.00 เพราะ $1/0.931421875=1.073627$ ไม่ใช่ 1.073742 อัตราทบครึ่งปีที่ถูกของเงินก้อนนี้คือ 4.7927% ต่ำกว่า 4.80% ราว 0.7 bp ถ้า zero rate 18 เดือนขยับ 1 bp มูลค่านี้เปลี่ยนราว $1.5(9{,}314{,}218.75)(0.0001)=\$1{,}397.13$ ความคลาดของเพื่อนจึงเท่ากับการอ่านอัตราผิดไปเกือบ 1 bp

ตรวจเองใน 10 วินาที: \$10 ล้าน คูณ 0.93 ได้ราว \$9.3 ล้าน ตรงหลักแรก และคำตอบของเพื่อนต้องต่ำกว่าคำตอบที่ถูก เพราะคิดลดด้วยอัตราที่สูงกว่า

ขั้นที่ 5 — note 2 ปี แล้วคิดราคากลับเพื่อตรวจ

note 2 ปีคูปอง 5.00% จ่าย 2.50 สามครั้ง แล้ว 102.50 ตอนสิ้นปีที่ 2 ถึงตอนนี้เรารู้ discount factor ของสามวันแรกแล้ว สมการจึงเหลือตัวไม่รู้ตัวเดียวอีกครั้ง ให้ $S_3$ คือผลบวกของ discount factor สามตัวแรก จากนั้นเอาเงินทุกก้อนคูณ discount factor ของวันจ่ายแล้วบวกกัน ต้องได้ราคาตลาดกลับมา

\[ \begin{aligned} S_3&=0.9755+0.9505\\ &\quad+0.931421875\\ &=2.857421875,\\ D(0,2)&=\frac{100-2.5\,S_3}{102.5}\\ &=\frac{92.8564453}{102.5}\\ &=0.9059165,\\ P_{1.5}&=2.3412+2.2812\\ &\quad+95.3776=100.0000,\\ P_{2}&=7.1435547\\ &\quad+92.8564453=100.0000. \end{aligned} \]

เขียนสี่ตราสารเป็นระบบสมการ แถวคือตราสาร คอลัมน์คือวันจ่าย จะได้ matrix สามเหลี่ยมล่างแบบรูปลูกศรด้านบน การแก้จากบนลงล่างคือ forward substitution ไม่ต้องกลับ matrix ทั้งก้อน ถ้าเริ่มจาก note 2 ปี สมการเดียวมีตัวไม่รู้สี่ตัว แก้ไม่ได้

สองแถวล่างคือการตรวจ: note 18 เดือนคือ $2.4(0.9755)+2.4(0.9505)+102.4(0.931421875)$ และ note 2 ปีคือ $2.5(2.857421875)+102.5(0.9059165)$ ทั้งคู่กลับมาที่ \$100 พอดี curve ที่คิดราคาตราสารที่ใช้สร้างมันกลับไม่ได้คือ curve ที่ผิด ไม่ว่าจะดูเรียบแค่ไหน งานจริงทำการตรวจนี้ทุกเช้าเป็น unit test

ขั้นที่ 6 — แปลง discount factor เป็น zero rate และเรื่องวิธีทบต้น

คนในตลาดคุยกันด้วยอัตรา ไม่ใช่ discount factor จึงต้องแปลง แต่ “อัตรา” มีหลายภาษา เงิน $A$ ฝาก $T$ ปีที่อัตรา $r$ แบบ simple ได้ $A(1+rT)$ ทบ $n$ ครั้งต่อปีได้ $A(1+r/n)^{nT}$ และเมื่อ $n$ โตไม่จำกัดได้ $Ae^{rT}$ (ทบต่อเนื่อง) หน้านี้เลือกทบต่อเนื่องเป็นภาษาหลัก เพราะเลขชี้กำลังบวกกันได้ ซึ่งจะทำให้ forward rate ออกมาง่ายมาก

\[ \begin{aligned} D(0,T)&=e^{-z(T)\,T},\\ z(T)&=-\frac{\ln D(0,T)}{T},\\ z(1.5)&=\frac{0.0710430}{1.5}\\ &=4.7362\%,\\ 2\big[D^{-1/3}-1\big]&=4.7927\%,\\ D^{-1/1.5}-1&=4.8501\%,\\ \frac{1/D-1}{1.5}&=4.9085\%. \end{aligned} \]

ใส่ log ทั้งสองข้างเพื่อดึงเลขชี้กำลังลงมา แล้วหารด้วย $T$ เครื่องหมายลบทำให้อัตราเป็นบวก เพราะ $D\lt 1$ ทำให้ $\ln D\lt 0$ ทั้งสี่อายุได้ zero rate แบบต่อเนื่อง 4.9610%, 5.0767%, 4.7362% และ 4.9404% ต่อปี (เช่น $\ln 0.9755=-0.0248051$ หารด้วย 0.5)

สามแถวล่างคือ discount factor ตัวเดียวกัน 0.931421875 เขียนเป็นภาษาอื่น: ทบครึ่งปี 4.7927% ทบปีละครั้ง 4.8501% และ simple 4.9085% ซึ่งเป็นภาษาที่ LIBOR และ SOFR term rate ใช้ ($L=(1/P-1)/(T-t)$ โดยนับวันแบบ actual/360) ตัวเลขอัตราเปลี่ยนตามภาษา แต่ราคาไม่เปลี่ยน อัตราที่ไม่บอกวิธีทบต้นจึงเป็นตัวเลขที่ยังใช้ไม่ได้

ขั้นที่ 7 — forward rate มาจากการห้ามเงินฟรี: กู้ \$1,000 สองปี

ก่อนใช้กับเส้นของเรา ดูตัวอย่างที่เลขกลม วันนี้กู้ \$1,000 สองปีได้ที่ 10% ต่อปีทบปีละครั้ง ส่วนกู้หนึ่งปีได้ที่ 8% ทำไมกู้ยาวแพงกว่า? เพราะคนให้กู้ไม่อยากให้เงินถูกล็อกนาน ทางเลือกที่สองคือกู้หนึ่งปีที่ 8% แล้วเซ็นสัญญาวันนี้เลยว่าปีหน้าจะกู้ต่ออีกปีที่อัตรา $X$ ทั้งสองทางรู้ผลตั้งแต่วันนี้ ไม่มีอะไรสุ่ม จึงต้องจบที่เงินเท่ากัน

\[ \begin{aligned} V_A&=1{,}000(1.10)^2\\ &=1{,}210,\\ V_B&=1{,}000(1.08)(1+X)\\ &=1{,}080(1+X),\\ 1+X&=\frac{1{,}210}{1{,}080}\\ &=1.1203704,\\ X&=12.0370\%. \end{aligned} \]

ถ้าธนาคารยอมให้ปีที่สองกู้ที่ 8% เท่าปีแรก ทาง B จบที่ \$1,166.40 คนฉลาดจะกู้ทางนี้แล้วปล่อยกู้สองปีที่ 10% ได้คืน \$1,210 เก็บ \$43.60 ฟรีโดยไม่ใช้เงินตัวเอง การแข่งกันทำแบบนี้ดัน $X$ ขึ้นจนสองทางเท่ากัน

$X$ สูงกว่า 10% เพราะปีแรกจ่ายแค่ 8% ปีที่สองจึงต้องชดเชย ตรวจ: $1.08(1.1203704)=1.21=1.10^2$ ตัวเลขนี้ตกลงวันนี้สำหรับเงินที่จะกู้ในปีหน้า จึงเรียกว่า forward แต่มันไม่ใช่คำทำนาย ปีหน้าอัตราหนึ่งปีจริงจะออกมาเท่าไรก็ได้ ทฤษฎี expectations บอกว่า forward ใกล้ค่าคาดหมายของอัตราในอนาคต ทฤษฎี liquidity preference บอกว่า forward สูงกว่านั้นเพราะมีค่าชดเชยการล็อกเงิน และ market segmentation บอกว่าแต่ละอายุมีคนซื้อคนขายของตัวเอง

ขั้นที่ 8 — forward ของเส้นเรา และ zero rate คือค่าเฉลี่ยของ forward

ทำแบบเดียวกันแต่ทบต่อเนื่อง ทางแรกฝาก \$1 ยาวถึง $T_2$ ทางที่สองฝากถึง $T_1$ แล้วต่อด้วยอัตรา $f$ ที่ล็อกวันนี้ ตั้งให้เท่ากันแล้วใส่ log ผลคูณกลายเป็นผลบวก นี่คือเหตุที่เลือกทบต่อเนื่องเป็นภาษาหลัก ใช้กับช่วง 1 ถึง 1.5 ปีก่อน แล้วต่อทุกช่วงเข้าด้วยกัน

\[ \begin{aligned} e^{z_2T_2}&=e^{z_1T_1}\,e^{f\,(T_2-T_1)},\\ f&=\frac{z_2T_2-z_1T_1}{T_2-T_1}\\ &=\frac{\ln[D(0,T_1)/D(0,T_2)]}{T_2-T_1},\\ \frac{D(0,1)}{D(0,1.5)}&=1.0204828,\\ f(1,1.5)&=\frac{0.0202758}{0.5}\\ &=4.0552\%,\\ z(2)&=\tfrac14\,(f_1+f_2+f_3+f_4)\\ &=4.9404\%. \end{aligned} \]

$zT$ คือผลตอบแทนสะสมจากวันนี้ ถึง 1 ปีได้ 5.0767% ถึง 1.5 ปีได้ $1.5(4.7362\%)=7.1043\%$ ครึ่งปีที่เพิ่มมาได้แค่ 2.0276% หรือ 4.0552% ต่อปี forward จึงต่ำกว่า zero rate ทั้งสองตัว ถ้าเอาอัตรามาลบกันตรง ๆ จะได้ $4.7362\%-5.0767\%=-0.34\%$ ซึ่งไม่มีความหมาย ต้องลบผลตอบแทนสะสม ไม่ใช่ลบอัตรา

ทำแบบนี้ครบสี่ช่วงครึ่งปีได้ forward 4.9610%, 5.1924%, 4.0552% และ 5.5530% ผลตอบแทนสะสมของสองปีต้องเท่าผลบวกของทุกช่วง หารด้วยสองปีได้ว่า zero rate คือค่าเฉลี่ยของ forward: $(4.9610+5.1924+4.0552+5.5530)/4=4.9404\%$ ตรงกับที่แปลงจาก $D(0,2)$ พอดี ถ้าใช้ทบปีละครั้ง ความจริงเดียวกันเขียนเป็นผลคูณ $(1+s_t)^t=(1+f_{0,1})(1+f_{1,2})\cdots(1+f_{t-1,t})$ ค่าเฉลี่ยเรียบกว่าของที่ถูกเฉลี่ยเสมอ เส้น zero จึงเรียบกว่าเส้น forward

ขั้นที่ 9 — ช่วงสั้นลงจนเป็นศูนย์: forward ชั่วขณะและ short rate

ถ้าซอยช่วงให้สั้นลงเรื่อย ๆ ขั้นสีส้มในรูปด้านบนจะกลายเป็นเส้นโค้งต่อเนื่อง ผลบวกของผลตอบแทนสะสมทีละช่วงกลายเป็นอินทิกรัล และ forward กลายเป็นความชันของ $-\ln D$ เราต้องการรูปนี้เพราะแบบจำลองดอกเบี้ยทุกตัวในบทที่เหลือพูดถึงจุดซ้ายสุดของเส้นนี้

\[ \begin{aligned} \ln D(0,T)&=-\int_0^T f(u)\,du,\\ f(T)&=-\frac{d}{dT}\ln D(0,T),\\ r&=f(0),\\ P(t,T)&=e^{-\int_t^T f(t,u)\,du}. \end{aligned} \]

แถวแรกคือ “zero rate เป็นค่าเฉลี่ยของ forward” ในรูปต่อเนื่อง: $z(T)T$ เท่ากับพื้นที่ใต้เส้น forward จาก 0 ถึง $T$ แถวที่สองได้จากการหาอนุพันธ์ทั้งสองข้างตาม $T$ เรียกว่า instantaneous forward rate และเส้น $T\mapsto f(T)$ ทั้งเส้นเรียกว่า forward curve

จุดซ้ายสุด $f(0)$ คืออัตราสำหรับการกู้ช่วงสั้นไม่จำกัด เรียกว่า short rate $r$ ที่เวลา $t$ ใด ๆ ก็เขียนได้ว่า $f(t,T)=-\partial\ln P(t,T)/\partial T$ และ $r(t)=f(t,t)$ แบบจำลอง Vasicek และ CIR และ lattice ของ Ho–Lee และ BDT เลือกให้ $r$ เดินแบบสุ่ม แล้วคำนวณราคาของ zero ทุกตัวจากมัน

ขั้นที่ 10 — ล็อก forward ด้วย zero สองตัว: FRA

โจทย์ให้อะไรมาบ้าง: บริษัทจะได้เงิน \$1,000,000 ในอีก 1 ปี และอยากฝากต่ออีกครึ่งปีโดยรู้อัตราตั้งแต่วันนี้ zero 1 ปีราคา 0.9505 และ zero 1.5 ปีราคา 0.931421875 ต่อหน้าตั๋ว \$1

\[ \begin{aligned} V_0&=950{,}500-950{,}500\\ &=0,\\ N&=\frac{950{,}500}{0.931421875}\\ &=1{,}020{,}482.80,\\ 1+0.5F&=\frac{1{,}020{,}482.80}{1{,}000{,}000},\\ F(1,1.5)&=4.0966\%. \end{aligned} \]

คำตอบ: วันนี้ขาย zero 1 ปีหน้าตั๋ว \$1,000,000 ได้ \$950,500 แล้วเอาเงินทั้งหมดซื้อ zero 1.5 ปีได้หน้าตั๋ว $N=\$1{,}020{,}482.80$ เงินลงทุนวันนี้เป็นศูนย์ ปีที่ 1 ใช้เงิน \$1,000,000 ที่ได้มาจ่ายหน้าตั๋วของ zero ที่ขายไป ปีที่ 1.5 ได้ \$1,020,482.80 เท่ากับฝากครึ่งปีที่ 4.0966% ต่อปีแบบ simple ซึ่งคือ forward 4.0552% แบบต่อเนื่องเขียนเป็นอีกภาษา

สูตรทั่วไป: ที่เวลา $t$ ขาย zero อายุ $S$ หนึ่งใบ ซื้อ zero อายุ $T$ จำนวน $P(t,S)/P(t,T)$ ใบ ได้ $1+(T-S)F=P(t,S)/P(t,T)$ FRA คือสัญญาที่ล็อกอัตรานี้ตรง ๆ ถ้าใครเสนอ FRA ที่อัตราอื่น พอร์ต zero สองตัวนี้เก็บส่วนต่างได้ ถ้าให้ $S$ เป็นวันนี้ จะได้ simple spot rate ที่ใช้ผูก LIBOR กับราคา zero: $L(0,0.5)=2(1/0.9755-1)=5.0231\%$

ตรวจเองใน 10 วินาที: $0.9505/0.931421875$ ต้องได้ราว 1.0205 และ $e^{0.5(0.040552)}$ ต้องได้ตัวเลขเดียวกัน เพราะเป็นดีลเดียวกันที่เขียนสองภาษา

ขั้นที่ 11 — par yield และ yield to maturity: ตัวเลขที่ quote ได้แต่ใช้คิดลดไม่ได้

ตลาดชอบ quote พันธบัตรด้วยอัตราเดียว แบบแรกคือ par yield: คูปองที่ทำให้พันธบัตรใหม่ราคาเท่าหน้าตั๋ว ต่อหน้าตั๋ว \$1 คูปองครึ่งปี $c/2$ ทุกงวดบวกเงินต้นคืนต้องมีค่า \$1 พอดี ย้ายข้างแล้วได้ par yield จาก discount factor

\[ \begin{aligned} 1&=\tfrac{c}{2}\sum_{k} D(0,t_k)+D(0,T),\\ c_{\rm par}(T)&=\frac{2\,[1-D(0,T)]}{\sum_k D(0,t_k)},\\ c_{\rm par}(1)&=\frac{2(0.0495)}{1.9260}\\ &=5.1402\%,\\ c_{\rm par}(1.5)&=\frac{0.13715625}{2.857421875}\\ &=4.8000\%. \end{aligned} \]

par yield 18 เดือนออกมา 4.80% พอดีเท่าคูปองของ note ที่ขายที่ราคาหน้าตั๋ว เป็นการตรวจอีกชั้นหนึ่ง ส่วน 6 เดือน 1 ปี และ 2 ปีได้ 5.0231%, 5.1402% และ 5.0000% สูตรหน้าตาเดียวกันนี้จะกลับมาเป็นสูตร swap rate ในหน้าถัดไป

พันธบัตรที่ไม่ได้ขายที่ราคาหน้าตั๋วใช้ yield to maturity $\lambda$: อัตราเดียวที่ทำให้ $P=\sum_{k=1}^{2T}c/(1+\lambda/2)^k+F/(1+\lambda/2)^{2T}$ เช่น หน้าตั๋ว \$1,000 คูปอง 5% จ่ายครึ่งปีละ \$25 อายุ 3 ปีราคา \$980 แก้หา $\lambda$ ด้วย bisection ได้ 5.7352% สูงกว่าคูปองเพราะราคาต่ำกว่าหน้าตั๋ว yield สรุปหน้าตั๋ว คูปอง อายุ และคุณภาพเครดิตไว้ในตัวเลขเดียว (เครดิตแย่ ราคาต่ำ yield สูง) จึงสะดวกไว้เทียบพันธบัตร

แต่ทั้งสองตัวเป็นค่าเฉลี่ยของหลายอายุที่ถ่วงด้วยเงินของพันธบัตรตัวนั้น เอาไปคิดลดเงินก้อนเดียวแล้วจะพลาดแบบโจทย์เปิดหน้า

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

คิดลดด้วย yield ของตราสาร: ใช้ 4.80% กับเงิน \$10 ล้านในเดือนที่ 18 ขาด \$993.00 และใช้ 5.00% ของ note 2 ปีกับเงินสองก้อน (\$5 ล้านที่ปีที่ 1 และปีที่ 2 ในโจทย์ตรวจความเข้าใจท้ายหน้า) ได้มูลค่าเกินไป \$6,742.51

ใช้อัตราผิดภาษา: เอา zero rate ต่อเนื่อง 4.7362% ไปใส่สูตรทบครึ่งปี $10^7/(1+0.047362/2)^3$ ได้ \$9,321,935.38 เกินไป \$7,716.63 อัตราทุกตัวต้องมาพร้อมวิธีทบต้นของมัน

หา forward จากผลต่างของอัตรา: $z(1.5)-z(1)=-0.34\%$ ใช้ไม่ได้ ของจริงคือ 4.0552% ต้องลบผลตอบแทนสะสม $zT$ แล้วหารด้วยความยาวช่วง

ลืมเงินต้นในงวดสุดท้าย: หารด้วย 100 แทน 102.4 ได้ $D(0,1.5)=0.953776$ มากกว่า $D(0,1)=0.9505$ คือเงินที่รอนานกว่ามีค่ามากกว่า ซึ่งเป็นไปไม่ได้เมื่ออัตราเป็นบวก และคิดราคากลับได้ 102.29 แทน 100 การคิดราคากลับจับได้ทันที

เชื่อ forward ที่ได้จากราคาไม่แม่น: ถ้าราคา note 18 เดือนผิดไป 5 เซนต์ (100.05 แทน 100) $z(1.5)$ ขยับแค่ −3.5 bp แต่ forward ช่วง 1–1.5 ปีลง 10.5 bp และช่วง 1.5–2 ปีขึ้น 10.7 bp เพราะ forward หารด้วยช่วงสั้นครึ่งปี ความคลาดเล็กที่จุดเดียวจึงกลายเป็นฟันเลื่อย ฟันเลื่อยในเส้น forward จึงมักบอกว่าราคามีสัญญาณรบกวน ไม่ใช่ตลาดคาดว่าอัตราจะขึ้นลงแบบนั้น

ใช้ทำอะไรบนโต๊ะจริง

ทุกเช้าโต๊ะตราสารหนี้สร้าง curve ใหม่จากตราสารที่ซื้อขายคล่อง ได้แก่ตั๋วเงินคลังระยะสั้น futures ของอัตราดอกเบี้ย และ swap แล้วใช้ discount factor ตั้งราคาเงินทุกก้อนในพอร์ต ตรวจว่าทุกตราสารคิดราคากลับได้ แล้วขยับ quote ทีละตัว 1 bp เพื่อดูว่าพอร์ตไวต่ออายุไหน (bucketed DV01 ต่อยอดจาก DV01 และ duration)

งานจริงต่างจากหน้านี้สามเรื่อง ตราสารไม่ได้ครบกำหนดตรงวันจ่ายของกันและกัน จึงต้องเลือกกฎ interpolation ระหว่างจุด ซึ่งเป็นการตัดสินใจของเรา ไม่ใช่ข้อมูลตลาด (นิยมลากเส้นตรงบน $\ln D$ ซึ่งให้ forward คงที่ในแต่ละช่วงแบบขั้นสีส้มในรูปด้านบน และรับประกันว่า $D$ เป็นบวก) ราคา quote เป็น clean price ต้องบวกดอกเบี้ยค้างรับเป็นเงินที่จ่ายจริงก่อนแกะ และหลังปี 2008 ตลาดใช้หลายเส้น: เส้นหนึ่งสำหรับคิดลดตามหลักประกันของสัญญา อีกเส้นสำหรับทายอัตราลอยตัว USD LIBOR หยุดประกาศหลังเดือนมิถุนายน 2023 ตลาดดอลลาร์ย้ายไปใช้ SOFR ซึ่งมาจากธุรกรรม repo จริงที่มีพันธบัตรรัฐบาลค้ำ สูตร simple rate ของ FRA ยังเหมือนเดิม

$D(0,1.5)/D(0,2)=0.931421875/0.9059165=1.0281542$ แบบต่อเนื่อง $\ln(1.0281542)/0.5=0.0277651/0.5=5.5530\%$ แบบ simple $(1.0281542-1)/0.5=5.6308\%$ สูงกว่าช่วงก่อนหน้า 150 bp ตามขั้นสีส้มขวาสุดในรูป zero กับ forward

2. บริษัทต้องจ่าย \$5,000,000 ในอีก 1 ปี และอีก \$5,000,000 ในอีก 2 ปี ต้องกันเงินวันนี้เท่าไร และถ้าคิดลดทั้งสองก้อนด้วย 5.00% ทบครึ่งปี (yield ของ note 2 ปี) จะได้เท่าไร?

เฉลย

บน curve: $5{,}000{,}000(0.9505)+5{,}000{,}000(0.9059165)=4{,}752{,}500+4{,}529{,}582.70=\$9{,}282{,}082.70$ ที่ 5.00%: $5{,}000{,}000/1.025^2+5{,}000{,}000/1.025^4=4{,}759{,}071.98+4{,}529{,}753.22=\$9{,}288{,}825.20$ เกินไป \$6,742.51 เกือบทั้งหมดมาจากก้อนปีที่ 1 เพราะอัตราทบครึ่งปีของ 1 ปีคือ 5.1417% สูงกว่า 5%

3. ต่อจากตัวอย่างกู้ \$1,000: ถ้ากู้ 3 ปีได้ที่ 11% ต่อปีทบปีละครั้ง forward ของปีที่ 3 เป็นเท่าไร?

เฉลย

สองทางต้องจบเท่ากัน: $1.11^3=1.10^2(1+X_3)$ ได้ $1+X_3=1.367631/1.21=1.1302736$ คือ $X_3=13.0274\%$ ตรวจด้วยการต่อสามปี: $1.08(1.1203704)(1.1302736)=1.367631$ ตรงกับ $1.11^3$ ซึ่งคือสูตรผลคูณ $(1+s_3)^3=(1+f_{0,1})(1+f_{1,2})(1+f_{2,3})$

const {log, pow} = Math;

// Bootstrap discount factors from instruments on a half-year grid, shortest first.
// Each instrument: {price, coupon (annual, paid twice a year), years}. A zero has coupon 0.
function bootstrap(list) {
  const D = [];
  list.forEach((q, i) => {
    if (q.years !== 0.5 * (i + 1)) throw new RangeError('need one maturity every half year, shortest first');
    const c = 100 * q.coupon / 2;                     // coupon per half year per 100 face
    const known = D.reduce((s, d) => s + c * d, 0);    // coupons already priced by earlier rows
    const d = (q.price - known) / (100 + c);
    if (!(d > 0)) throw new RangeError('prices imply a non-positive discount factor');
    D.push(d);
  });
  return D;
}
// Price the same instruments back from the curve (the unit test of a curve).
const reprice = (list, D) => list.map((q, i) => {
  const c = 100 * q.coupon / 2;
  return D.slice(0, i + 1).reduce((s, d, k) => s + (k === i ? 100 + c : c) * d, 0);
});
const zero = (d, T) => -log(d) / T;
const forward = (d1, d2, T1, T2) => log(d1 / d2) / (T2 - T1);
const simpleForward = (d1, d2, T1, T2) => (d1 / d2 - 1) / (T2 - T1);
const parYield = (D, n) => 2 * (1 - D[n - 1]) / D.slice(0, n).reduce((s, d) => s + d, 0);
// Yield to maturity of a semiannual bond by bisection (price falls as y rises).
function ytm(price, couponPerHalf, face, halves) {
  const p = y => {
    let s = face / pow(1 + y / 2, halves);
    for (let k = 1; k <= halves; k++) s += couponPerHalf / pow(1 + y / 2, k);
    return s;
  };
  let lo = 0, hi = 1;
  for (let k = 0; k < 200; k++) { const m = (lo + hi) / 2; if (p(m) > price) lo = m; else hi = m; }
  return (lo + hi) / 2;
}
const pv = (flows, r) => flows.reduce((s, c, k) => s + c / pow(1 + r, k + 1), 0);

สิ่งที่ควรตอบได้หลังอ่าน

  • discount factor คือราคาของ \$1 ในวันข้างหน้า แกะจากราคาตราสารทีละอายุจากสั้นไปยาวได้เพราะแต่ละตราสารเพิ่มก้อนที่ไม่รู้แค่ก้อนเดียว: $D(0,1.5)=0.931421875$ และ $D(0,2)=0.9059165$
  • ราคาทั้งใบเท่าผลบวกชิ้นย่อยเพราะห้ามเงินฟรี และเมื่อกู้แพงกว่าฝาก ราคาเหลือเป็นช่วง (\$973.27 ถึง \$1,027.75 ในตัวอย่าง)
  • zero rate คือ discount factor ในอีกภาษา (4.7362% ต่อเนื่อง, 4.7927% ทบครึ่งปี, 4.9085% simple) และการคิดลดด้วย yield ของ note ทำให้เงิน \$10 ล้านขาดไป \$993.00
  • forward คือผลต่างของผลตอบแทนสะสมหารด้วยความยาวช่วง ถูกบังคับด้วยการห้ามเงินฟรี (12.0370% ในตัวอย่างกู้ และ 4.0552% บนเส้นเรา) และล็อกได้ด้วย zero สองตัว (FRA 4.0966% แบบ simple)
  • zero rate คือค่าเฉลี่ยของ forward forward จึงแกว่งแรงกว่าและไวต่อราคาที่คลาดมากกว่า และจุดซ้ายสุดของ forward curve คือ short rate ที่แบบจำลองดอกเบี้ยใช้

หน้าถัดไป swap rate และ swap curve ใช้ discount factor ชุดนี้กับสัญญาที่แลกดอกเบี้ยคงที่กับดอกเบี้ยลอยตัว หา swap rate ที่ทำให้สัญญามีค่าศูนย์วันแรก แล้วเดินกลับทางคือแกะ curve จาก swap rate ที่ตลาด quote
