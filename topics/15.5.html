15.5 Spurious Regression and Overfitting

ผลที่สวยในข้อมูลที่ใช้สร้าง model อาจเป็นของปลอมจากสามทาง คือระดับราคาที่เดินสุ่ม ตัวแปรที่มากเกินข้อมูล และการเลือกผู้ชนะจากหลายแบบ และทั้งสามทางจับได้ด้วยข้อมูลที่ model ไม่เคยเห็น

นักวิเคราะห์คนหนึ่งอยากรู้ว่าราคาหุ้น B ช่วยอธิบายราคาหุ้น A ได้ไหม เขาจึงทำ regression คือลากเส้นตรงที่เข้ากับข้อมูลที่สุด ตามวิธีในOLS regression โดยให้ log ราคาของ A เป็นตัวที่ต้องอธิบาย และ log ราคาของ B เป็นตัวอธิบาย (ใช้ log เพราะการเปลี่ยนของ log ราคาคือผลตอบแทนเป็น % โดยประมาณ)

เขาใช้ข้อมูลย้อนหลัง 750 วันซื้อขาย ตลาดหุ้นสหรัฐฯ เปิดราว 252 วันต่อปี 750 วันจึงเป็นราว $750/252\approx3$ ปี ในช่วงนั้นตลาดเป็นขาขึ้น และหุ้นทั้งสองตัวขึ้นด้วยกัน ผลที่เขาได้มีสองตัว

  • $R^2=0.70$ คือเส้นตรงนี้อธิบายการขึ้นลงของ log ราคา A ได้ 70% ถ้า $R^2=0$ เส้นไม่ช่วยอะไรเลย ถ้า $R^2=1$ ทุกจุดอยู่บนเส้นพอดี
  • $t=41$ คือ slope ของเส้นหารด้วย SE ของ slope (SE คือขนาดความคลาดที่คาดได้ของค่าประมาณ) ถ้าสองหุ้นไม่เกี่ยวกันจริง $|t|$ จะเกิน 1.96 โดยบังเอิญแค่ราว 5 ครั้งจาก 100 ครั้ง คนจึงถือว่า $|t|\gt1.96$ คือหลักฐานว่ามีความสัมพันธ์

$t=41$ ไกลจาก 1.96 มาก เขาจึงสรุปว่า B อธิบาย A ได้ 70% แต่สมมติว่าภายหลังรู้ว่าราคาสองเส้นนี้ถูกสุ่มแยกกัน ไม่มีอะไรเชื่อมกันเลย ผลสวยแบบนี้เกิดจากเส้นที่ไม่เกี่ยวกันได้บ่อยแค่ไหน และในผลชุดเดียวกันมีตัวเลขไหนเตือนได้ก่อน?

ลองตอบก่อนเปิดเฉลย

เกิดบ่อยมาก ขั้นการทดลองของหน้านี้สุ่มราคาสองเส้นที่ไม่เกี่ยวกัน 2,000 คู่ เส้นละ 750 วัน ทุกเส้นถูกลากขึ้นวันละ 0.08% เหมือนตลาดขาขึ้น แล้วทำ regression แบบเดียวกับนักวิเคราะห์ ผลที่ได้คือ

  • 49.6% ของคู่ได้ $R^2$ เกิน 0.70
  • 98.5% ของคู่ได้ $|t|\gt1.96$ ทั้งที่ควรเป็นแค่ราว 5%

ผล $R^2=0.70$ กับ $t=41$ จึงเป็นแค่ผลธรรมดาของเส้นสุ่ม ไม่ใช่หลักฐานอะไร

ตัวเตือนอยู่ในผลชุดเดียวกันนั้นเอง คือค่า Durbin–Watson (DW) ของ residual ซึ่งคือส่วนที่เส้นตรงอธิบายไม่ได้ในแต่ละวัน DW ใกล้ 2 แปลว่า residual แต่ละวันไม่เกี่ยวกัน แต่ในการทดลองนี้ DW ได้ราว 0.02 แปลว่า residual วันนี้แทบเท่ากับเมื่อวาน และ DW ที่ต่ำกว่า $R^2$ มากแบบนี้คือสัญญาณอันตราย

ทางแก้ก็ง่าย ให้ทำ regression ของการเปลี่ยนรายวัน (ราคาวันนี้ลบเมื่อวาน) แทนระดับราคา แล้ว $R^2$ จะเหลือราว 0.0007 และสัดส่วนที่ $|t|\gt1.96$ เหลือ 5% ตามที่ควร

ภาพรวมก่อนลงสูตร

หน้าก่อน ๆ ของบทนี้สร้างเครื่องมือ ได้แก่ OLS regression, beta และ alpha ของ CAPM, multi-factor model และ pairs trading หน้านี้ดูว่าเครื่องมือชุดเดียวกันหลอกเราได้อย่างไร

ก่อนอื่นต้องแยกข้อมูลเป็นสองชุด ข้อมูลที่ใช้สร้างหรือเลือก model เรียกว่า in-sample ข้อมูลที่ model ไม่เคยเห็นเรียกว่า out-of-sample หน้านี้พูดถึงความผิดสามแบบ ทั้งสามแบบมีอาการเดียวกัน คือผลใน in-sample สวย แต่พังใน out-of-sample

  1. Spurious regression (regression ลวง) เกิดเมื่อทำ regression บนระดับราคาที่เดินสุ่ม OLS จะรายงาน SE เล็กเกินจริงมาก ในตัวอย่างของหน้านี้เล็กไปราว 14 เท่า (ขั้น Durbin–Watson จะคำนวณให้ดู) ค่า $t$ จึงใหญ่เกินจริงเท่ากัน
  2. Overfitting เกิดเมื่อใส่ตัวแปรหรือ parameter มากเกินกว่าที่ข้อมูลรองรับ model จึงจับ noise เข้าไปด้วย (noise คือการแกว่งสุ่มที่ไม่มีความหมายและไม่เกิดซ้ำ) $R^2$ ที่ได้มาฟรีใน in-sample จะกลายเป็น $R^2$ ที่เสียใน out-of-sample
  3. การเลือกผู้ชนะ เกิดเมื่อลองกลยุทธ์หลายแบบแล้วเก็บแบบที่ผลดีที่สุดไว้ optimizer ที่เลือกน้ำหนักพอร์ตจากค่าประมาณที่คลาดก็ทำแบบเดียวกันโดยไม่รู้ตัว

รูปด้านล่างสรุปความผิดแบบที่สาม ซึ่งเจอบ่อยที่สุดในการวิจัยกลยุทธ์ แกนตั้งคือ Sharpe ratio คือผลตอบแทนที่ได้เกินเงินฝาก หารด้วยความผันผวน ยิ่งสูงยิ่งดี (ดูการทดสอบ Sharpe ratio) ยิ่งลองหลายแบบ ผู้ชนะยิ่งดูดีในข้อมูลที่ใช้เลือก แต่ในข้อมูลใหม่มันกลับไปเป็นศูนย์

ทั้งสามแบบแก้ด้วยหลักเดียวกัน คือตัดสินใจด้วยข้อมูลที่มีอยู่ ณ วันนั้นเท่านั้น แล้ววัดผลกับข้อมูลที่ไม่เคยใช้ตัดสินใจ หน้านี้จะไล่ทีละแบบ วัดขนาดของมันเป็นตัวเลข แล้วจบที่วิธีทำ backtest ที่ซื่อสัตย์ (backtest คือการลองกลยุทธ์กับข้อมูลย้อนหลัง ว่าถ้าเคยใช้จริงจะได้ผลเท่าไร)

ศัพท์ที่ใช้ในหัวข้อนี้
In-sample และ out-of-sample
in-sample คือข้อมูลที่ใช้สร้างหรือเลือก model ส่วน out-of-sample คือข้อมูลที่ model ไม่เคยเห็น ผลที่ใช้ตัดสินว่ากลยุทธ์ใช้ได้ต้องมาจากชุดหลังเท่านั้น
Random walk และ drift
random walk คือเส้นที่แต่ละวันขยับจากเมื่อวานด้วยตัวเลขสุ่มที่ไม่เกี่ยวกับอดีต ส่วน drift คือการเลื่อนขึ้น (หรือลง) คงที่ทุกวันที่บวกเพิ่มเข้าไป
$R^2$, SE และ $t$
$R^2$ คือสัดส่วนของการขึ้นลงที่เส้น regression อธิบายได้ SE คือขนาดความคลาดที่คาดได้ของค่าประมาณ $t$ คือค่าประมาณหารด้วย SE ของมัน ถ้าความจริงเป็นศูนย์ $|t|$ จะเกิน 1.96 แค่ราว 5% ของครั้ง
Residual
ส่วนที่เส้น regression อธิบายไม่ได้ในแต่ละวัน คือค่าจริงลบค่าบนเส้น
Noise
การแกว่งสุ่มที่ไม่มีความหมายและไม่เกิดซ้ำ model ที่จับ noise ได้ดีในข้อมูลย้อนหลังจะพลาดในข้อมูลใหม่
Spurious regression
regression ลวง คือ regression ระหว่างระดับของสองอนุกรมที่เดินสุ่มโดยไม่เกี่ยวกัน แต่ได้ $R^2$ สูงและ $t$ ใหญ่ เพราะ SE ที่ OLS คำนวณสมมติว่าแต่ละวันอิสระกัน ซึ่งไม่จริง ใช้เป็นคำเตือนก่อนทำ regression บนระดับราคาใด ๆ
Overfitting
การปรับ model ให้เข้ากับข้อมูลย้อนหลังมากจนจับ noise ของข้อมูลชุดนั้นไปด้วย ผลในข้อมูลใหม่จึงแย่กว่าที่เห็น และอาจแย่กว่าไม่มี model เลย
Effective sample size
ข้อมูลที่วันติดกันเกี่ยวข้องกันให้ความรู้น้อยกว่าจำนวนวันที่มี effective sample size คือจำนวนข้อมูลอิสระที่ให้ความแม่นเท่ากัน ใช้แก้ SE เมื่อข้อมูลแต่ละวันไม่อิสระกัน
Durbin–Watson (DW)
ตัวเลขวัดว่า residual ของวันติดกันต่างกันแค่ไหน ใกล้ 2 คือปกติ ใกล้ 0 คือ residual แทบไม่ขยับจากเมื่อวาน ใช้จับ regression ลวงบนระดับราคา
Sharpe ratio
ผลตอบแทนที่ได้เกินเงินฝาก หารด้วยความผันผวน ใช้วัดว่ากลยุทธ์ได้ผลตอบแทนคุ้มกับการแกว่งแค่ไหน
Data leakage
การที่ข้อมูลซึ่งยังไม่มี ณ วันตัดสินใจรั่วเข้ามาใน backtest เช่นรายชื่อหุ้นที่รอดถึงวันนี้ หรืองบการเงินที่ถูกแก้ย้อนหลัง ผลจึงดูดีโดยไม่มี error ใดเตือน
Walk-forward และ holdout
walk-forward คือ fit ด้วยข้อมูลถึงวันหนึ่ง แล้วทดสอบกับช่วงถัดไป แล้วเลื่อนไปเรื่อย ๆ holdout คือข้อมูลช่วงท้ายที่ล็อกไว้ และเปิดดูครั้งเดียวหลังตรึง model แล้ว
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$A_t,\ B_t$log ราคาของสองหุ้น วัดจากวันเริ่มหน่วย log ราคา
$\varepsilon_t,\ \sigma$shock รายวันของ random walk และความผันผวนของมันหน่วย log ราคา
$e_t,\ \rho_e$residual ของ regression และ autocorrelation ที่ lag หนึ่งของมันหน่วย log ราคา และไม่มีหน่วย
$n,\ n_{\rm eff}$จำนวนวัน และจำนวนข้อมูลอิสระเทียบเท่าวัน
$k$จำนวนตัวแปรอธิบายใน modelนับ
$R^2_{\rm in},\ R^2_{\rm out}$$R^2$ ในข้อมูลที่ใช้ fit และในข้อมูลใหม่ไม่มีหน่วย
$M,\ T$จำนวนแบบที่ลองก่อนเลือกผู้ชนะ และความยาว backtestนับ และปี
$\widehat{\mathrm{SR}}_m$Sharpe ratio รายปีที่วัดได้จาก backtest ของแบบที่ $m$ไม่มีหน่วย (คิดรายปี)
$Z_m$ค่าทดสอบของแบบที่ $m$ ภายใต้สมมติฐานว่าไม่มีฝีมือจำนวน SE

$\hat\mu,\ \Sigma,\ w$ผลตอบแทนเฉลี่ยที่ประมาณได้ covariance matrix และน้ำหนักพอร์ตต่อปี และสัดส่วน

ขั้นที่ 1 — ทำไม random walk ดูเหมือนมีแนวโน้ม

ทำไมสองเส้นที่ไม่เกี่ยวกันถึงได้ $R^2$ สูงได้? ก่อนตอบ ต้องเห็นก่อนว่าเส้นที่เดินสุ่มหน้าตาเป็นอย่างไร random walk คือเส้นที่แต่ละวันขยับจากเมื่อวานด้วยตัวเลขสุ่มที่ไม่เกี่ยวกับอดีต ตัวเลขสุ่มของวัน $t$ เรียกว่า shock เขียนเป็น $\varepsilon_t$

ให้ log ราคา $A_t$ เป็น random walk โดย

  • shock แต่ละวันอิสระกัน มีค่าเฉลี่ยศูนย์
  • ความผันผวนของ shock คือ $\sigma=1\%$ ต่อวัน (ตัวเลขสมมติ) แปลว่าวันปกติ log ราคาขยับขึ้นหรือลงราว 1%
  • เส้นเดินไป 750 วัน

คำถามคือ หลัง 750 วัน เส้นมักอยู่ห่างจุดเริ่มแค่ไหน

\[ \begin{aligned} A_t&=A_{t-1}+\varepsilon_t,\\ \operatorname{Var}(\varepsilon_t)&=\sigma^2,\\ A_t-A_0&=\sum_{s=1}^{t}\varepsilon_s,\\ \operatorname{Var}(A_t-A_0)&=t\sigma^2,\\ \operatorname{SD}(A_{750}-A_0)&=1\%\times\sqrt{750}\\ &\approx27.4\%. \end{aligned} \]

ตำแหน่งของเส้นหลัง $t$ วันคือผลรวมของ shock ทุกวันที่ผ่านมา เพราะ shock แต่ละวันอิสระกัน covariance ระหว่างวันจึงเป็นศูนย์ variance ของผลรวมจึงเท่ากับผลบวกของ variance ทีละวัน คือ $t\sigma^2$ ที่โตเป็นเส้นตรงตามจำนวนวัน และ SD โตตามรากของจำนวนวัน นี่คือสมบัติเดียวกับที่ทำให้ variance ของBrownian motion โตตามเวลา

ผลคือ ก้าวแต่ละวันเล็กแค่ราว 1% แต่หลังสามปี ระยะห่างจากจุดเริ่มตามปกติ (SD) โตเป็นราว 27% และไม่มีแรงไหนดึงเส้นกลับมา เส้นจึงมักค้างอยู่ฝั่งเดียวของจุดเริ่มนาน ๆ ดูเหมือนมีแนวโน้มขึ้นหรือลงทั้งที่ไม่มี

ทีนี้เพิ่ม drift คือการเลื่อนขึ้นคงที่ทุกวัน ให้วันละ 0.08% เหมือนตลาดขาขึ้น (เท่ากับปีละราว $252\times0.08\%\approx20\%$) สองเส้นจะถูกลากขึ้นเท่ากัน $750\times0.08\%=60\%$ ในสามปี OLS วัดว่าระดับของสองเส้นเรียงกันแค่ไหน มันจึงเจอ “ความสัมพันธ์” ที่แรงในคู่ที่บังเอิญไปทางเดียวกัน ทั้งที่ตัวเชื่อมจริงมีแค่ “เวลาเดินไปข้างหน้า”

ขั้นที่ 2 — การทดลอง: regression ระดับของเส้นที่ไม่เกี่ยวกัน 2,000 คู่

โจทย์ให้อะไรมาบ้าง: ทำแบบเดียวกับนักวิเคราะห์ตอนต้นหน้า แต่ทำซ้ำหลายพันครั้ง เพื่อนับว่าผลสวย ๆ เกิดจากเส้นที่ไม่เกี่ยวกันบ่อยแค่ไหน

  • แต่ละครั้งสุ่ม log ราคาสองเส้น $A_t$ และ $B_t$ ที่อิสระกันสนิท เส้นละ 750 วัน shock รายวันมีความผันผวน 1%
  • สองเส้นไม่เกี่ยวกัน slope ที่แท้จริงจึงเป็นศูนย์ คำตอบที่ถูกคือ “ไม่มีความสัมพันธ์”
  • ทำสองชุด ชุดละ 2,000 คู่ ชุดแรกไม่มี drift ชุดที่สองให้ทั้งสองเส้น drift ขึ้นวันละ 0.08% เหมือนตลาดขาขึ้นในขั้นก่อน
  • แต่ละคู่ทำ regression สองแบบ แบบระดับคือ $A_t$ บน $B_t$ และแบบการเปลี่ยนรายวันคือ $\Delta A_t=A_t-A_{t-1}$ บน $\Delta B_t=B_t-B_{t-1}$

พอเปลี่ยนไปทำ regression ของการเปลี่ยนรายวัน ทุกอย่างกลับมาตามที่ควร สัดส่วนที่ $|t|\gt1.96$ เหลือ 5.0% ถึง 5.9% และ median $R^2$ เหลือ 0.0007 ข้อมูลชุดเดียวกัน แต่ถามคนละคำถาม จึงได้คำตอบต่างกันคนละโลก

ตรวจเองใน 10 วินาที: การนับจาก 2,000 คู่ก็คลาดได้เอง ถ้าโอกาสจริงคือ $p=5\%$ สัดส่วนที่นับได้จาก $N=2{,}000$ คู่จะคลาดรอบ 5% ด้วย SD ของสัดส่วน

\[ \begin{aligned} \sqrt{\frac{p(1-p)}{N}}&=\sqrt{\frac{0.05\times0.95}{2000}}\\ &\approx0.49\%. \end{aligned} \]

5.0% และ 5.9% ของการเปลี่ยนรายวันห่างจาก 5% ไม่ถึงสองเท่าของความคลาดนี้ จึงเป็นความคลาดธรรมดา ส่วน 90.8% ห่างจาก 5% ไป $(90.8-5)/0.49\approx175$ เท่าของความคลาด จึงไม่ใช่โชคแน่นอน

ขั้นที่ 3 — ข้อมูลที่ติดกันนับเป็นข้อมูลอิสระได้กี่ตัว

ทำไม SE ของ regression ระดับถึงเล็กเกินจริง? SE ในOLS regression สมมติว่า error แต่ละวันอิสระกัน ข้อมูล 750 วันจึงถูกนับเป็นหลักฐาน 750 ชิ้น แต่ถ้าวันนี้คล้ายเมื่อวานมาก วันนี้ก็แทบไม่ได้บอกอะไรใหม่ ข้อมูล $n$ วันจึงให้ความรู้น้อยกว่า $n$ ชิ้น ขั้นนี้วัดว่าน้อยกว่าเท่าไร โดยดูว่า variance ของค่าเฉลี่ยเปลี่ยนไปแค่ไหน

ให้ข้อมูล $X_1,\dots,X_n$ แต่ละวันมี variance $\sigma^2$ และให้ correlation ระหว่างสองวันที่ห่างกัน $k$ วันเป็น $\rho^k$ แปลว่าวันติดกันมี correlation $\rho$ ห่างสองวันเหลือ $\rho^2$ และจางลงเรื่อย ๆ รูปแบบนี้เรียกว่า AR(1) (รายละเอียดของautocorrelation อยู่ในบทถัดไป) ตัวอย่างตัวเลขใช้ $n=750$ วัน และ $\rho=0.1$

\[ \begin{aligned} \operatorname{Var}(\bar X)&=\frac{1}{n^2}\sum_i\sum_j\operatorname{Cov}(X_i,X_j)\\ &=\frac{\sigma^2}{n^2}\sum_i\sum_j\rho^{|i-j|},\\ \sum_i\sum_j\rho^{|i-j|}&\approx n\Big(1+2\sum_{k\ge1}\rho^k\Big)\\ &=n\,\frac{1+\rho}{1-\rho},\\ n_{\rm eff}&:=n\,\frac{1-\rho}{1+\rho},\\ 750\times\frac{0.9}{1.1}&\approx613.6. \end{aligned} \]

ถ้าข้อมูลอิสระกัน variance ของค่าเฉลี่ยคือ $\sigma^2/n$ ที่คุ้นกัน เมื่อข้อมูลเกี่ยวกัน ต้องบวก covariance ของทุกคู่วันเข้าไปด้วย ลองนึกถึงตารางขนาด $n\times n$ ที่ช่อง $(i,j)$ คือ $\rho^{|i-j|}$ แต่ละแถวมีเลข 1 บนเส้นทแยงหนึ่งตัว และมี $\rho^k$ สองตัว คือวันที่อยู่ก่อนและหลังวัน $i$ ไป $k$ วัน เมื่อ $n$ ใหญ่ แถวที่อยู่ใกล้ขอบตารางมีจำนวนน้อยจนละได้ ผลรวมทั้งตารางจึงราว $n$ เท่าของผลรวมหนึ่งแถว

ผลรวมหนึ่งแถวคืออนุกรมเรขาคณิต $\rho+\rho^2+\dots=\rho/(1-\rho)$ คูณสองแล้วบวก 1 ได้ $(1+\rho)/(1-\rho)$ ดังนั้น $\operatorname{Var}(\bar X)\approx\sigma^2/n_{\rm eff}$ หน้าตาเหมือนสูตรของข้อมูลอิสระ แต่จำนวนข้อมูลลดจาก $n$ เป็น $n_{\rm eff}$ ตัว

autocorrelation แค่ 0.1 ก็ทำให้ 750 วันเหลือข้อมูลอิสระ 613.6 ตัว หายไป $750-613.6\approx136$ ตัว SE ที่คำนวณราวกับมีข้อมูลอิสระ 750 ตัวจึงเล็กเกินจริง ถ้า $\rho$ ใกล้ 1 ตัวคูณ $(1+\rho)/(1-\rho)$ พุ่งขึ้นไม่จำกัด ซึ่งคือสิ่งที่เกิดกับ residual ของ regression ระดับในขั้นถัดไป

ขั้นที่ 4 — Durbin–Watson จับ regression ลวง และการเปลี่ยนรายวันแก้มัน

ใน regression ของระดับ residual $e_t$ (ค่าจริงลบค่าบนเส้นในวัน $t$) เองก็เกือบเป็น random walk เส้นตรงพลาดไปทางเดียวกันติดกันหลายร้อยวัน ขั้นก่อนบอกว่าข้อมูลที่ติดกันแบบนี้ทำให้ SE เล็กเกินจริง แต่เราไม่รู้ $\rho$ ของ residual จึงต้องวัดจากข้อมูล

เครื่องวัดที่ใช้กันคือ Durbin–Watson (DW) ซึ่งเทียบว่า residual วันนี้ต่างจากเมื่อวานแค่ไหน เทียบกับขนาดของ residual เอง ขั้นนี้มีสามงาน คือนิยาม DW แปลง DW เป็น autocorrelation ที่ lag หนึ่ง $\rho_e$ (correlation ระหว่าง residual วันนี้กับเมื่อวาน) แล้วใช้ $\rho_e$ ประเมินว่า SE เล็กเกินไปกี่เท่า ตัวเลขใช้ median DW 0.021 และ median $|t|$ 12.1 ของชุดไม่มี drift จากตารางการทดลอง

\[ \begin{aligned} \mathrm{DW}&:=\frac{\sum_t(e_t-e_{t-1})^2}{\sum_te_t^2}\\ &\approx\frac{2\sum_te_t^2-2\sum_te_te_{t-1}}{\sum_te_t^2}\\ &\approx2(1-\rho_e),\\ \rho_e&\approx1-0.021/2\approx0.99,\\ \sqrt{\frac{1+0.99}{1-0.99}}&=\sqrt{199}\approx14.1,\\ 12.1/14.1&\approx0.86. \end{aligned} \]

ทำไม DW ถึงบอก $\rho_e$ ได้? กระจายตัวเศษ $(e_t-e_{t-1})^2=e_t^2+e_{t-1}^2-2e_te_{t-1}$ ผลรวมของสองพจน์แรกแทบเท่ากับ $2\sum e_t^2$ ส่วนผลรวมของพจน์ที่สามคือ $2\rho_e\sum e_t^2$ ตามนิยามของ autocorrelation ที่ lag หนึ่ง หารด้วย $\sum e_t^2$ แล้วเหลือ $2(1-\rho_e)$ DW จึงใกล้ 2 เมื่อ residual แต่ละวันไม่เกี่ยวกัน และใกล้ 0 เมื่อ residual แทบไม่ขยับ DW 0.021 จึงแปลกลับได้เป็น $\rho_e\approx0.99$

ขั้นต่อมาใช้ผลจากขั้นนับข้อมูลอิสระ SE แปรผันตาม $1/\sqrt{n}$ เมื่อจำนวนข้อมูลจริงลดจาก $n$ เหลือ $n_{\rm eff}$ SE จริงจึงใหญ่กว่าที่ OLS พิมพ์ $\sqrt{n/n_{\rm eff}}=\sqrt{(1+\rho_e)/(1-\rho_e)}$ เท่า ที่ $\rho_e=0.99$ คือราว 14 เท่า $t$ คือ slope หารด้วย SE ค่า $t$ จึงต้องหารด้วย 14 ตามไปด้วย median $|t|$ 12.1 จึงเหลือราว 0.86 ซึ่งต่ำกว่า 1.96 แปลว่าไม่มีหลักฐานว่าสองเส้นสัมพันธ์กันเลย

Granger กับ Newbold นักเศรษฐมิติสองคนที่ชี้ปัญหานี้ในปี 1974 ให้กฎหัวแม่มือไว้ว่า ถ้า $R^2$ สูงกว่า DW ให้สงสัยทันทีว่าเป็น regression ลวง

ทางแก้คือทำ regression ของการเปลี่ยนรายวัน ซึ่งเป็น shock อิสระตามที่ OLS ต้องการ ตารางการทดลองแสดงว่าได้ DW 2.00 และสัดส่วนที่ $|t|\gt1.96$ กลับมาราว 5% การทำ regression บนระดับมีความหมายกรณีเดียว คือเมื่อสองระดับ cointegrate (มีแรงดึงให้ส่วนต่างกลับมาที่เดิม) แบบในpairs trading และ cointegration กรณีนั้น residual ถูกดึงกลับ DW ไม่ใกล้ศูนย์ และต้องตัดสินด้วยเกณฑ์ของ Engle–Granger ที่หน้านั้นสอน ไม่ใช่เกณฑ์ $t$ ธรรมดา

ขั้นที่ 5 — ตัวแปรขยะ: $R^2$ ที่ได้ฟรีในข้อมูลที่ใช้ fit คือ $R^2$ ที่เสียในข้อมูลใหม่

ความผิดแบบที่สอง overfitting เกิดได้แม้ข้อมูลแต่ละวันอิสระกันดี ลองนึกถึงนักวิจัยที่อยากทำนายผลตอบแทน $y$ ของวันพรุ่งนี้ เขาหาตัวแปรมาใส่ model ได้ 50 ตัว แต่ความจริงไม่มีตัวไหนเกี่ยวกับ $y$ เลย ขั้นนี้วัดว่าตัวแปรไร้ประโยชน์เหล่านี้ (ขอเรียกว่าตัวแปรขยะ) หลอกเราได้แค่ไหน ของที่ตั้งไว้มีดังนี้

  • $y$ เป็น noise ล้วน มีความผันผวน $\sigma$ และไม่เกี่ยวกับอะไรเลย
  • ตัวแปรขยะ $x_1,\dots,x_k$ เป็นเลขสุ่มล้วน ปรับให้แต่ละตัวมี variance 1 และ model มี intercept ด้วย
  • ข้อมูล $n=750$ วัน และตัวแปรขยะ $k=50$ ตัว

ถามสองคำถาม ข้อแรก $R^2$ ในข้อมูลที่ใช้ fit ได้เท่าไร ข้อสอง ถ้านำค่าประมาณ $\hat\beta$ ชุดเดิมไปใช้กับข้อมูลใหม่ขนาดเท่ากัน $R^2$ จะเป็นเท่าไร

ข้อแรกตอบด้วยเรขาคณิตของOLS regression หลังหักค่าเฉลี่ยออก ค่า $y$ ทั้ง $n$ วันเรียงกันเป็น vector $\tilde{\mathbf y}$ ที่อยู่ในพื้นที่ $n-1$ มิติ (หายไปหนึ่งมิติเพราะหักค่าเฉลี่ย) ค่าบนเส้น regression คือเงา $P\tilde{\mathbf y}$ ของมันบนพื้นที่ $k$ มิติที่ตัวแปรขยะกาง โดย $P$ คือ matrix ที่ฉายลงพื้นที่นั้น ข้อสองต้องดูว่า $\hat\beta$ คลาดแค่ไหน แล้วความคลาดนั้นไปเพิ่ม error ของวันใหม่เท่าไร

\[ \begin{aligned} R^2_{\rm in}&=\frac{\|P\tilde{\mathbf y}\|^2}{\|\tilde{\mathbf y}\|^2},\\ \mathbb E\Big[\frac{\tilde y_j^2}{\|\tilde{\mathbf y}\|^2}\Big]&=\frac{1}{n-1},\\ \mathbb E[R^2_{\rm in}]&=\frac{k}{n-1}=\frac{50}{749}\approx6.7\%,\\ \hat\beta_j&\approx\frac1n\sum_tx_{tj}y_t,\\ \operatorname{Var}(\hat\beta_j)&\approx\frac{\sigma^2}{n},\\ e_{\rm new}&:=y-\sum_j\hat\beta_jx_j,\\ \operatorname{Var}(e_{\rm new})&\approx\sigma^2\Big(1+\frac kn\Big),\\ R^2_{\rm out}&\approx1-\Big(1+\frac kn\Big)\\ &=-\frac kn\approx-6.7\%. \end{aligned} \]

ข้อแรกคือ $R^2_{\rm in}$ ซึ่งเท่ากับสัดส่วนของความยาวกำลังสองของ $\tilde{\mathbf y}$ ที่เงาเก็บไว้ได้ ลองหมุนแกนให้พื้นที่ $k$ มิติของตัวแปรขยะเป็น $k$ แกนแรก การหมุนทำได้เพราะความยาวไม่เปลี่ยนเมื่อหมุน ถ้า $y$ เป็น Normal อิสระ ทิศของ $\tilde{\mathbf y}$ สุ่มเท่ากันทุกทาง ไม่มีแกนไหนพิเศษ แต่ละแกนจึงถือความยาวกำลังสองเฉลี่ย $1/(n-1)$ ของทั้งหมด เงาบน $k$ แกนจึงเก็บไว้ $k/(n-1)$ ตัวแปรขยะ 50 ตัวบนข้อมูล 750 วันจึงให้ $R^2$ ฟรีราว 6.7% ทั้งที่ไม่มีตัวไหนเกี่ยวกับ $y$ เลย

ข้อสองเริ่มจากความคลาดของ $\hat\beta_j$ เพราะ $x_j$ มี variance 1 ค่าประมาณ $\hat\beta_j$ จึงแทบเท่ากับ covariance ตัวอย่างของ $x_j$ กับ $y$ คือค่าเฉลี่ยของ $n$ พจน์ $x_{tj}y_t$ (มองข้ามผลเล็ก ๆ ของ intercept) แต่ละพจน์มี variance $1\times\sigma^2=\sigma^2$ เพราะ $x_{tj}$ กับ $y_t$ อิสระกัน และมีค่าเฉลี่ยศูนย์ทั้งคู่ ค่าเฉลี่ยของ $n$ พจน์จึงคลาดรอบศูนย์ด้วย variance $\sigma^2/n$ ทั้งที่ค่าจริงเป็นศูนย์

ตอนใช้กับวันใหม่ $\hat\beta$ มาจากข้อมูลย้อนหลัง จึงอิสระกับ $x$ และ noise ของวันใหม่ variance ของ error $e_{\rm new}$ จึงบวกกันได้ตรง ๆ คือ $\sigma^2$ จาก noise บวก $\sigma^2/n$ จาก $\hat\beta_jx_j$ แต่ละตัว รวม $k$ ตัว error จึงใหญ่กว่า variance ของ $y$ เอง แปลว่า model ทำนายแย่กว่าการตอบค่าเฉลี่ยเฉย ๆ $R^2$ ในข้อมูลใหม่จึงติดลบ

รวมสองข้อ ช่องว่างระหว่างข้อมูลที่ใช้ fit กับข้อมูลใหม่คือราว $2k/n=100/750\approx13.3\%$ ค่าประมาณอันดับแรกนี้มองข้ามสองเรื่อง คือ intercept ก็ถูก fit ด้วย และ $X^\top X$ ของข้อมูลจริงก็แกว่งไปจากค่าทฤษฎี การจำลอง 300 ครั้งในโค้ดท้ายหน้าได้ $+6.8\%$ ในข้อมูลที่ใช้ fit และ $-7.8\%$ ในข้อมูลใหม่ แย่กว่าค่าประมาณเล็กน้อย

เครื่องมือมาตรฐานที่หักส่วนที่ได้ฟรีออกคือ adjusted $R^2$ เขียนเป็น $\bar R^2$ มันขยายส่วนที่อธิบายไม่ได้ $1-R^2$ ด้วยตัวคูณที่โตตามจำนวนตัวแปร model 50 ตัวบน 750 วันที่รายงาน $R^2=10\%$ จะเหลือ

\[ \begin{aligned} \bar R^2&=1-(1-R^2)\frac{n-1}{n-k-1}\\ &=1-0.90\times\frac{749}{699}\\ &\approx3.6\%. \end{aligned} \]

ขั้นที่ 6 — ข้อมูล 750 วันรองรับตัวแปรได้กี่ตัว

โจทย์ให้อะไรมาบ้าง: ขั้นตัวแปรขยะบอกว่าตัวแปรยิ่งมาก ยิ่งหลอกตา คำถามที่ตามมาคือ ข้อมูล 750 วันใส่ตัวแปรได้กี่ตัวก่อนจะอันตราย

  • กฎหัวแม่มือที่คนใช้กันคือ อยากได้ข้อมูลอิสระราว 30 ตัวต่อ parameter หนึ่งตัว (เป็นกฎจากประสบการณ์ ไม่ใช่ทฤษฎีบท)
  • มีข้อมูล $n=750$ วัน
  • ผลตอบแทนอาจมี autocorrelation ที่ lag หนึ่ง (correlation ระหว่างวันนี้กับเมื่อวาน) เป็น $\rho=0$, 0.1, 0.3 หรือ 0.6

ทุกกรณีคำนวณจำนวนข้อมูลอิสระ $n_{\rm eff}=n(1-\rho)/(1+\rho)$ จากขั้นนับข้อมูลอิสระก่อน แล้วหารด้วย 30 และปัดลง (ลูกศรชี้ไปที่จำนวนตัวแปรที่รองรับได้)

\[ \begin{aligned} \rho=0:&\quad750/30=25,\\ \rho=0.1:&\quad750\times\tfrac{0.9}{1.1}\approx613.6,\\ &\quad613.6/30\approx20.5\to20,\\ \rho=0.3:&\quad750\times\tfrac{0.7}{1.3}\approx403.8,\\ &\quad403.8/30\approx13.5\to13,\\ \rho=0.6:&\quad750\times\tfrac{0.4}{1.6}=187.5,\\ &\quad187.5/30=6.25\to6. \end{aligned} \]

คำตอบ: ถ้า 750 วันอิสระกันจริง จะรองรับตัวแปรได้ราว 25 ตัว แต่ autocorrelation 0.1 ทำให้เหลือ 20 ตัว 0.3 เหลือ 13 ตัว และ 0.6 เหลือแค่ 6 ตัว

แล้วเก็บข้อมูลให้ยาวขึ้นได้ไหม? ได้ แต่ไม่ฟรี เพราะข้อมูลที่ยาวขึ้นมักคร่อมหลายสภาวะตลาด และความสัมพันธ์ในแต่ละสภาวะไม่เหมือนกัน ตลาดเปลี่ยนเร็วกว่าที่ประวัติจะสะสมให้ทัน

ตรวจเองใน 10 วินาที: $0.9/1.1\approx0.818$ และ $0.818\times750\approx614$ แล้ว $614/30\approx20.5$ ปัดลงเป็น 20 ตัวแปร

ขั้นที่ 7 — ผู้ชนะจาก 400 แบบ: Sharpe ในข้อมูลที่ใช้เลือกกับในข้อมูลใหม่

ความผิดแบบที่สามเกิดได้แม้แต่ละแบบที่ลองมีตัวแปรแค่ตัวเดียว ลองนึกถึงทีมวิจัยที่หากลยุทธ์ซื้อขาย สัญญาณ (signal) คือตัวเลขที่บอกว่าควรซื้อหรือขาย เช่นผลตอบแทนย้อนหลังของหุ้น ทีมลองหลายแบบแล้วเก็บแบบที่ Sharpe ดีที่สุด

  • สัญญาณ 20 ชนิด แต่ละชนิดลองช่วงเวลามองย้อน 5 แบบ และเกณฑ์เข้าซื้อ 4 แบบ รวม $M=20\times5\times4=400$ แบบ
  • แต่ละแบบวัด Sharpe รายปีจาก backtest ยาว $T=5$ ปี
  • สมมติว่าไม่มีแบบไหนมีฝีมือจริง Sharpe จริงของทุกแบบเป็นศูนย์

Sharpe ที่วัดได้จากข้อมูลจำกัดย่อมคลาด หน้าการทดสอบ Sharpe ratio แสดงว่า backtest ยาว $T$ ปีให้ Sharpe ที่คลาดด้วย SE ราว $1/\sqrt T$ ที่ $T=5$ คือ $1/\sqrt5\approx0.45$ เราจึงเขียน Sharpe ที่วัดได้ของแบบที่ $m$ เป็น $\widehat{\mathrm{SR}}_m=Z_m/\sqrt T$ โดย $Z_m$ คือค่าสุ่ม Normal มาตรฐาน (ค่าเฉลี่ย 0, SD 1) ที่อิสระกันทุกแบบ

คำถามคือ ผู้ชนะ (แบบที่ $Z_m$ สูงสุด) ดูดีแค่ไหนในข้อมูลที่ใช้เลือก และจะเหลือเท่าไรในข้อมูลใหม่ สูตรด้านล่างหาค่าเฉลี่ยของค่าสูงสุดจาก $M$ ตัวก่อน แล้วแปลงเป็น Sharpe ด้วยการหารด้วย $\sqrt5$ สองแถวสุดท้ายคือเกณฑ์ Bonferroni ซึ่งอธิบายหลังสูตร

\[ \begin{aligned} P\Big(\max_mZ_m\le z\Big)&=\Phi(z)^M,\\ \mathbb E\Big[\max_mZ_m\Big]&=\int z\,M\varphi(z)\Phi(z)^{M-1}\,dz,\\ M=20:\ 1.87,&\quad M=400:\ 2.97,\\ \mathbb E\big[\widehat{\mathrm{SR}}_{\rm in}\big]&\approx2.97/\sqrt5\approx1.33,\\ \mathbb E\big[\widehat{\mathrm{SR}}_{\rm out}\big]&=0,\\ z_{\rm Bonf}&=\Phi^{-1}(1-0.05/400)\approx3.66,\\ \widehat{\mathrm{SR}}_{\rm Bonf}&=3.66/\sqrt5\approx1.64. \end{aligned} \]

ค่าสูงสุดจะไม่เกิน $z$ ก็ต่อเมื่อทุกตัวไม่เกิน $z$ และเพราะทุกตัวอิสระกัน โอกาสจึงเป็นผลคูณของโอกาสทีละตัว ได้ $\Phi(z)^M$ หาอนุพันธ์ตาม $z$ ได้ density ของผู้ชนะ $M\varphi(z)\Phi(z)^{M-1}$ แล้วหาค่าเฉลี่ยด้วย integral เชิงตัวเลขในโค้ดท้ายหน้า (หน้าปัญหาการทดสอบหลายครั้ง ไล่การหาสูตรนี้ละเอียด) ค่าเฉลี่ยของผู้ชนะจาก 20 แบบคือ 1.87 และจาก 400 แบบคือ 2.97 หารด้วย $\sqrt5$ แล้ว ผู้ชนะจาก 400 แบบที่เป็น noise ล้วนจึงคาดว่าโชว์ Sharpe ราว 1.33 ในข้อมูลที่ใช้เลือก ซึ่งคือจุดแดงขวาในรูปภาพรวม

หัวใจของหน้านี้คือ Sharpe ของผู้ชนะในข้อมูลใหม่มีค่าเฉลี่ยเป็นศูนย์ เพราะข้อมูลใหม่คือ noise ชุดใหม่ที่ไม่รู้ว่าใครเคยชนะ ค่าเฉลี่ยของผู้ชนะจึงเท่ากับของแบบใดก็ได้หนึ่งแบบ คือศูนย์ ถ้วยรางวัลไม่ติดตัวไปข้างหน้า การเลือกไม่ได้สร้างฝีมือ มันแค่ย้าย noise ที่โชคดีที่สุดมาวางไว้หน้าสุด

แล้วผู้ชนะต้องดีแค่ไหนจึงจะเชื่อได้? ถ้าลองแบบเดียว เกณฑ์ปกติคือค่าทดสอบเกิน 1.645 ซึ่งหลุดโดยบังเอิญแค่ 5% คิดเป็น Sharpe ห้าปี $1.645/\sqrt5\approx0.74$ แต่ถ้าลอง 400 แบบ โอกาสที่สักแบบหลุดเกณฑ์โดยบังเอิญสูงกว่ามาก วิธี Bonferroni แก้ด้วยการแบ่งโอกาส 5% ให้ทั้ง 400 แบบ แต่ละแบบจึงได้แค่ $0.05/400=0.000125$ เกณฑ์ใหม่หาได้จากการเปิดตาราง Normal ย้อนกลับ ($\Phi^{-1}$ คือค่า $z$ ที่โอกาสไม่เกิน $z$ เท่ากับตัวเลขที่ให้) ได้ค่าทดสอบต้องเกิน 3.66 คือ Sharpe ห้าปีต้องถึง 1.64 ไม่ใช่ 0.74

ในชีวิตจริง แบบที่ลองมักคล้ายกัน มองย้อน 20 วันกับ 21 วันให้ผลแทบเหมือนกัน จำนวนแบบที่อิสระจริงจึงน้อยกว่า 400 และผู้ชนะปลอมดูดีน้อยกว่านี้ แต่จะรู้ว่าน้อยลงเท่าไร ต้องใช้ correlation จริงของผลตอบแทนทุกแบบที่ลอง ไม่ใช่การเดา และทั้งหมดนี้ใช้ได้ก็ต่อเมื่อทีมจดไว้ว่าลองไปกี่แบบ

ขั้นที่ 8 — optimizer ก็เป็นเครื่องเลือกผู้ชนะ

โจทย์ให้อะไรมาบ้าง: optimizer คือโปรแกรมที่รับค่าประมาณผลตอบแทนและความเสี่ยงของสินทรัพย์ แล้วคำนวณน้ำหนักพอร์ตที่ “ดีที่สุด” ให้ ขั้นนี้แสดงว่ามันก็เลือกผู้ชนะจาก noise ได้เหมือนทีมวิจัยในขั้นก่อน ตัวอย่างนี้เป็นตัวเลขสมมติ

  • สินทรัพย์สองตัวเหมือนกันทุกอย่าง ผลตอบแทนเฉลี่ยจริงตัวละ 6% ต่อปี
  • ความผันผวนตัวละ $\sigma=20\%$ ต่อปี และสองตัวไม่สัมพันธ์กัน covariance matrix $\Sigma$ จึงมี $\sigma^2$ บนเส้นทแยงและศูนย์นอกเส้นทแยง
  • แต่ค่าประมาณจากข้อมูลย้อนหลังคลาดไปคนละทาง ตัวแรกประมาณได้ $\hat\mu_1=8\%$ ตัวที่สองได้ $\hat\mu_2=4\%$ ความคลาดคือ +2% กับ −2% เฉลี่ยเป็นศูนย์ ค่าประมาณจึงไม่เอียงโดยรวม
  • เพื่อให้ตัวเลขง่าย สมมติดอกเบี้ยเงินฝากเป็นศูนย์ Sharpe จึงเป็นผลตอบแทนของพอร์ตหารด้วยความผันผวนของพอร์ต

optimizer ใช้พอร์ต Sharpe สูงสุดของMarkowitz ซึ่งให้น้ำหนักเป็นสัดส่วนกับ $\Sigma^{-1}\hat\mu$ แล้วปรับให้น้ำหนักรวมเป็นหนึ่ง เราจะเทียบสามตัวเลข คือ Sharpe ที่ optimizer คิดว่าจะได้ ($\widehat{\mathrm{SR}}_{\rm in}$) Sharpe ที่พอร์ตเดียวกันได้จริง ($\mathrm{SR}_{\rm real}$) และ Sharpe ของการแบ่งเงินครึ่งต่อครึ่งโดยไม่ใช้ค่าประมาณเลย ($\mathrm{SR}_{\rm half}$) ความผันผวนของพอร์ต $\sigma_p$ ใช้สูตรของสองสินทรัพย์ที่ไม่สัมพันธ์กัน $\sigma_p=\sigma\sqrt{w_1^2+w_2^2}$

\[ \begin{aligned} w&\propto\Sigma^{-1}\hat\mu=\tfrac{1}{\sigma^2}(8\%,\ 4\%),\\ w&=(2/3,\ 1/3),\\ \sigma_p&=20\%\sqrt{(2/3)^2+(1/3)^2}\\ &\approx14.91\%,\\ \widehat{\mathrm{SR}}_{\rm in}&=\frac{\tfrac23(8\%)+\tfrac13(4\%)}{14.91\%}\approx0.447,\\ \mathrm{SR}_{\rm real}&=\frac{6\%}{14.91\%}\approx0.402,\\ \mathrm{SR}_{\rm half}&=\frac{6\%}{20\%/\sqrt2}\approx0.424. \end{aligned} \]

คำตอบ: $\Sigma$ เป็น diagonal และสองตัวมีความผันผวนเท่ากัน $\Sigma^{-1}\hat\mu$ จึงเป็นแค่ $\hat\mu$ หารด้วย $\sigma^2$ น้ำหนักจึงเป็นสัดส่วน 8 ต่อ 4 คือ 2/3 กับ 1/3

optimizer เชื่อว่าจะได้ Sharpe 0.447 แต่ของจริงได้ 0.402 ซึ่งแย่กว่าการแบ่งครึ่งเฉย ๆ ที่ได้ 0.424 ทำไม? เพราะมันทุ่มน้ำหนักให้ตัวที่ค่าประมาณสูงเกินจริงพอดี และการทุ่มน้ำหนักไปตัวเดียวทำให้กระจายความเสี่ยงได้น้อยลง ($\sigma_p$ 14.91% สูงกว่า $20\%/\sqrt2\approx14.14\%$ ของการแบ่งครึ่ง) ทั้งที่ผลตอบแทนจริงเท่าเดิม

นี่คือการเลือกผู้ชนะในรูปที่เนียนที่สุด optimizer หาทิศที่ noise ในค่าประมาณเข้าข้างมากที่สุด แล้วเดิมพันหนักที่นั่น คนในวงการจึงเรียก mean-variance optimization ว่า “error-maximizing” คือเครื่องขยายความคลาด ถ้ายอมให้ short (ขายสินทรัพย์ที่ยืมมา คือน้ำหนักติดลบ) ได้มาก ช่องว่างยิ่งกว้าง ทางแก้คือดึงค่าประมาณเข้าหาค่าเฉลี่ยก่อนใส่ optimizer (shrinkage แบบLedoit–Wolf หรือมุมมองแบบBlack–Litterman) และใส่ข้อจำกัดน้ำหนัก

ตรวจเองใน 10 วินาที:

\[ \begin{aligned} w_1^2+w_2^2&=\tfrac49+\tfrac19=\tfrac59,\\ \sigma_p&=20\%\times\sqrt{5/9}\\ &\approx20\%\times0.745\approx14.9\%,\\ w^\top\hat\mu&=\tfrac{16}{3}\%+\tfrac43\%=\tfrac{20}{3}\%\\ &\approx6.67\%. \end{aligned} \]

optimizer เห็นผลตอบแทน 6.67% แต่ของจริงคือ 6% เพราะทั้งสองตัวได้ 6% จริง จะถือสัดส่วนเท่าไรก็ได้ 6%

ขั้นที่ 9 — นิยามการทดสอบที่ซื่อสัตย์: เดินไปข้างหน้าเท่านั้น

ทั้งสามความผิดมีทางป้องกันร่วมกันข้อเดียว คือการตัดสินใจทุกอย่างต้องใช้ข้อมูลที่มีถึงวันนั้นเท่านั้น แล้วไปวัดผลกับช่วงถัดไปที่ยังไม่เคยเห็น เหมือนตอนเทรดจริงที่เราไม่รู้อนาคต สิ่งที่ตามมาเป็นนิยามของขั้นตอนที่เราเลือกใช้ ไม่ใช่ทฤษฎีที่ต้องพิสูจน์

แบ่งข้อมูลตามเวลาเป็นช่วงต่อกัน $D_1,D_2,\dots$ ให้ $\operatorname{fit}$ คือทุกอย่างที่ทำเพื่อสร้าง model จากข้อมูล และ $\operatorname{score}$ คือการวัดผลของ model บนข้อมูลช่วงหนึ่ง เช่น Sharpe แล้วทำซ้ำสองบรรทัดนี้

\[ \begin{aligned} \hat\theta_k&=\operatorname{fit}(D_1,\dots,D_k),\\ s_{k+1}&=\operatorname{score}(\hat\theta_k,\ D_{k+1}). \end{aligned} \]

$\hat\theta_k$ คือทุกอย่างที่ตัดสินใจจากข้อมูลช่วง 1 ถึง $k$ ได้แก่ ตัวแปรที่ใช้ ค่า parameter เกณฑ์เข้าออก และรายชื่อหุ้น ส่วน $s_{k+1}$ คือผลในช่วงถัดไปที่ model ยังไม่เคยเห็น เลื่อน $k$ ไปทีละช่วง แล้วต่อผลทุกช่วงเข้าด้วยกันเป็น backtest เส้นเดียว ขั้นตอนนี้เรียกว่า walk-forward

ทำไมผลแบบนี้จึงเชื่อได้? เพราะการเลือกเกิดก่อนเห็นผลเสมอ ผลที่ได้จึงไม่มีอคติจากการเลือกผู้ชนะแบบในขั้นผู้ชนะจาก 400 แบบ ราคาที่ต้องจ่ายคือ model ช่วงแรก ๆ ได้ข้อมูลฝึกน้อยกว่าการ fit ด้วยข้อมูลทั้งหมด

หน้าต่างข้อมูลฝึกมีสองแบบ แบบเลื่อน (rolling) ใช้ความยาวคงที่ ค่าประมาณแต่ละช่วงจึงเทียบกันได้ แบบขยาย (expanding) ใช้ข้อมูลทั้งหมดตั้งแต่ต้นจนถึงวันนั้น

ต้องเว้นช่องว่าง (embargo) ระหว่างข้อมูลฝึกกับช่วงทดสอบ อย่างน้อยเท่าระยะที่สัญญาณมองย้อนหรือถือสถานะ ตัวอย่างเช่นสัญญาณ momentum 12 เดือน (ซื้อหุ้นที่ขึ้นมามากในปีที่ผ่านมา) ใช้ผลตอบแทนย้อนหลังราว 252 วัน ถ้าช่วงฝึกต่อกับช่วงทดสอบติดกัน label (ค่าที่ model ถูกสอนให้ทาย) ของวันท้าย ๆ ในช่วงฝึกจะคาบเกี่ยวกับผลตอบแทนในช่วงทดสอบ model จึงได้เห็นข้อสอบบางส่วนก่อนสอบ

สุดท้ายเก็บ holdout ช่วงท้ายไว้ ล็อก model ทั้งหมดก่อน แล้วเปิดดูครั้งเดียว ถ้าผลไม่ดีแล้วกลับไปปรับ holdout นั้นก็หมดสภาพ เพราะมันกลายเป็นข้อมูลที่ใช้เลือกไปแล้ว

วินัยเดียวกันใช้กับตัวข้อมูลด้วย คือใช้แต่ตัวเลขที่มีอยู่จริงณ วันนั้น ตัวอย่างการรั่วที่แม้นักวิจัยมีประสบการณ์ยังพลาด

  • ใช้รายชื่อหุ้นเฉพาะตัวที่รอดมาถึงวันนี้ ทิ้งหุ้นที่ล้มไปแล้ว
  • ลงวันที่งบการเงินเป็นวันสิ้นไตรมาส ทั้งที่บริษัทประกาศงบหลังจากนั้นหลายสัปดาห์
  • ใช้ตัวเลขที่ถูกแก้ย้อนหลัง แทนตัวเลขที่ประกาศครั้งแรก
  • ใช้ราคาที่ปรับ split แล้วเป็นตัวแปร (split คือการแตกหุ้นหนึ่งหุ้นเป็นหลายหุ้น ราคาปรับที่ต่ำมากในอดีตบอกล่วงหน้าว่าหุ้นนี้จะ split อีกหลายครั้ง ซึ่งแปลว่าราคาจะขึ้นมาก)
  • นับวันผิดหนึ่งวัน จนผลตอบแทนของวันถัดไปหลุดเข้าไปในสัญญาณ
  • normalize ข้อมูลทั้งชุดก่อนแบ่ง ค่าเฉลี่ยและ SD ที่ใช้จึงมีข้อมูลอนาคตปน (ดูตัวอย่างอัตราแลกเปลี่ยนในปัญหาการทดสอบหลายครั้ง)

ความผิดที่ทำให้ backtest สวยกว่าความจริง

เชื่อ $t$ ของ regression ระดับ: ความผิดคือใช้ $t$ ที่ OLS พิมพ์ออกมาตรง ๆ ทั้งที่ residual ติดกันจนแทบไม่ขยับ ในการทดลอง median $|t|$ ที่ OLS พิมพ์คือ 12.1 ซึ่งดูมีนัยสำคัญมาก แต่เมื่อแก้ SE ด้วยตัวคูณจาก DW แล้ว $t$ ที่ควรเป็นคือ $12.1/14.1\approx0.86$ ไม่มีนัยสำคัญเลย ตารางการทดลองยังแสดงว่า $|t|\gt10$ เกิด 58% ของครั้งแม้สองเส้นไม่เกี่ยวกัน ให้ดู DW ทุกครั้ง ถ้าต่ำกว่า 1 หรือต่ำกว่า $R^2$ อย่าเชื่อ $t$

ไม่นับว่าลองมากี่แบบ: ความผิดคือเทียบผู้ชนะกับเกณฑ์ของการลองแบบเดียว เกณฑ์ผิดคือ Sharpe ห้าปี $1.645/\sqrt5\approx0.74$ เกณฑ์ที่ถูกหลังลอง 400 แบบคือ $3.66/\sqrt5\approx1.64$ และผู้ชนะต้องเทียบกับ Sharpe $2.97/\sqrt5\approx1.33$ ที่ noise ล้วนก็ทำได้ ไม่ใช่เทียบกับศูนย์ ทีมที่ไม่จดจำนวนแบบที่ลองจะไม่มีทางรู้ว่าต้องหักเท่าไร

สุ่มแบ่ง fold สำหรับข้อมูลที่เรียงตามเวลา: ความผิดคือใช้ cross-validation แบบสุ่ม (แบ่งข้อมูลเป็นหลายส่วน หรือ fold แล้วผลัดกันใช้ส่วนหนึ่งทดสอบ) กับข้อมูลที่เรียงตามเวลา การสุ่มทำให้วันจากอนาคตไปอยู่ในชุดฝึก และสัญญาณที่มองย้อน 252 วันของวันในชุดฝึกจะมีผลตอบแทนของชุดทดสอบปนอยู่ ผลจึงดีเกินจริงโดยไม่มี error ขึ้นเลย ต้องแบ่งตามเวลา และเว้นช่องว่างอย่างน้อยเท่าระยะที่สัญญาณมองย้อน

เปิด holdout หลายรอบ: ความผิดคือเปิด holdout ดูแล้วกลับไปแก้ model ซ้ำ ทุกครั้งที่ทำแบบนี้ คือการทดสอบอีกหนึ่งครั้งบนข้อมูลชุดเดิม ถ้าคิดว่าเปิดครั้งเดียว โอกาสผ่านปลอมคือ 5% แต่ถ้าเปิด 20 รอบที่เกณฑ์ 5% (และถือว่าแต่ละรอบอิสระกัน) โอกาสที่จะผ่านปลอมอย่างน้อยหนึ่งรอบคือ $1-0.95^{20}\approx64\%$

เชื่อ optimizer ที่ป้อนด้วยค่าประมาณดิบ: ความผิดคือเชื่อ Sharpe ที่ optimizer รายงาน ในตัวอย่างสองสินทรัพย์ optimizer รายงาน $6.67\%/14.91\%\approx0.447$ แต่ของจริงคือ $6\%/14.91\%\approx0.402$ และยังแย่กว่าการแบ่งครึ่ง $6\%/14.14\%\approx0.424$

ใช้ทำอะไรบนโต๊ะจริง

ทีมวิจัยกลยุทธ์ใช้ขั้นตอนของหน้านี้เป็นด่านตรวจก่อนใส่เงินจริง ด่านมีห้าข้อ

  1. ก่อนทำ regression บนระดับราคา ให้ทดสอบ unit root ก่อน (การทดสอบว่าอนุกรมเดินแบบ random walk หรือไม่) ถ้าใช่ ให้ใช้การเปลี่ยนรายวันแทน หรือทดสอบ cointegration
  2. ก่อนเพิ่มตัวแปร ให้นับจำนวนข้อมูลอิสระ $n_{\rm eff}$ ก่อนว่ารองรับไหวไหม
  3. จดจำนวนแบบที่ลองไว้ในสมุดวิจัยทุกครั้ง แล้วปรับเกณฑ์ด้วย Bonferroni หรือวิธีที่ใกล้เคียง
  4. ทดสอบแบบ walk-forward ด้วยข้อมูลที่มี ณ วันนั้น และใช้แบบจำลองต้นทุนการซื้อขายเดียวกับที่จะเจอจริง
  5. เปิด holdout ครั้งเดียว

ถ้ามีเหตุผลเชิงกลไกว่าทำไมสัญญาณควรทำงาน ให้เขียนไว้ก่อน backtest เพราะมันลดจำนวนแบบที่ต้องลอง และทำให้อ่านผลได้ว่าสอดคล้องกับเหตุผลนั้นไหม ฝ่ายบริหารความเสี่ยงก็ใช้คำถามชุดเดียวกันตรวจกลยุทธ์ที่คนอื่นส่งมา และผลที่ดูดีเกินจริงแทบเป็นสัญญาณเตือนเสมอ

โจทย์ตรวจความเข้าใจ

1. นักวิเคราะห์ทำ regression ของ log ราคาหุ้นตัวหนึ่งบน log ราคาของอีกตัว ใช้ระดับราคา ไม่ใช่การเปลี่ยนรายวัน ได้ผลสามตัว คือ $R^2=0.9$, $t=8$ และ DW 0.8 ค่า $t=8$ ดูมีนัยสำคัญมาก ควรเชื่อมันแค่ไหน

เฉลย

แปลง DW เป็น $\rho_e$ แล้วหาว่า SE เล็กเกินไปกี่เท่า ด้วยสูตรจากขั้น Durbin–Watson

\[ \begin{aligned} \rho_e&\approx1-\mathrm{DW}/2=1-0.8/2=0.6,\\ \sqrt{\frac{1+\rho_e}{1-\rho_e}}&=\sqrt{\frac{1.6}{0.4}}=\sqrt4=2,\\ t_{\rm adj}&\approx8/2=4. \end{aligned} \]

SE จริงใหญ่กว่าที่พิมพ์ราว 2 เท่า $t$ ที่ควรเป็นจึงราว 4 ซึ่งยังเกิน 1.96 จึงยังไม่ต้องทิ้งผลนี้ทั้งหมด แต่ $R^2$ 0.9 สูงกว่า DW 0.8 ตามกฎของ Granger กับ Newbold ต้องสงสัยว่าเป็น regression ลวง ก่อนสรุปต้องทดสอบ unit root และลองทำ regression ของการเปลี่ยนรายวันดู

2. ทีมหนึ่งสร้าง model ทำนายผลตอบแทนรายวันด้วยตัวแปร $k=20$ ตัว บนข้อมูล $n=250$ วัน (ราวหนึ่งปีซื้อขาย) และรายงาน $R^2=12\%$ adjusted $R^2$ เป็นเท่าไร และถ้าตัวแปรทั้ง 20 ตัวเป็นตัวแปรขยะล้วน คาดว่า $R^2$ ในข้อมูลที่ใช้ fit และในข้อมูลใหม่เป็นเท่าไร

เฉลย

adjusted $R^2$ ใช้สูตรจากขั้นตัวแปรขยะ

\[ \begin{aligned} \bar R^2&=1-(1-R^2)\frac{n-1}{n-k-1}\\ &=1-0.88\times\frac{249}{229}\\ &=1-0.9569\approx4.3\%. \end{aligned} \]

ถ้าเป็นตัวแปรขยะล้วน ข้อมูลที่ใช้ fit ให้ $R^2$ ฟรีเฉลี่ย $k/(n-1)=20/249\approx8.0\%$ และข้อมูลใหม่ให้ราว $-k/n=-20/250=-8.0\%$ (ค่าประมาณอันดับแรก ของจริงแย่กว่าเล็กน้อย) $R^2$ 12% ที่รายงานจึงมีส่วนที่อาจอธิบายได้จริงเพียงราว $12-8=4$ จุด ใกล้กับ adjusted $R^2$ และต้องรอดในข้อมูลใหม่ก่อน จึงจะเชื่อได้แม้แต่ 4 จุดนั้น

3. กลับไปที่สินทรัพย์สองตัวในขั้น optimizer (ผลตอบแทนจริงตัวละ 6% ความผันผวนตัวละ 20% ไม่สัมพันธ์กัน) สมมติว่าใช้ข้อมูลย้อนหลังยาวขึ้น ค่าประมาณจึงคลาดน้อยลง เหลือ $\hat\mu_1=7\%$ กับ $\hat\mu_2=5\%$ น้ำหนัก Sharpe ที่ optimizer เห็น และ Sharpe จริงเป็นเท่าไร

เฉลย

น้ำหนักเป็นสัดส่วนกับ 7 ต่อ 5 เหมือนเดิมเพราะ $\Sigma$ เป็น diagonal ที่ความผันผวนเท่ากัน

\[ \begin{aligned} w&=\big(\tfrac{7}{12},\ \tfrac{5}{12}\big)\approx(0.583,\ 0.417),\\ \sigma_p&=20\%\times\sqrt{\tfrac{49+25}{144}}\\ &=20\%\times0.717\approx14.34\%,\\ w^\top\hat\mu&=\tfrac{49+25}{12}\%\approx6.17\%,\\ \widehat{\mathrm{SR}}_{\rm in}&=6.17/14.34\approx0.430,\\ \mathrm{SR}_{\rm real}&=6/14.34\approx0.418. \end{aligned} \]

Sharpe จริง 0.418 ยังต่ำกว่าการแบ่งครึ่ง 0.424 แต่ช่องว่างแคบลงมาก ยิ่งค่าประมาณแม่น ราคาที่ต้องจ่ายให้การ optimize ยิ่งถูก

const {sqrt, log, sin, cos, exp, imul, PI, abs} = Math;
// Seeded standard normals (mulberry32 + Box-Muller) so every reader gets the same experiment.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = imul(a ^ (a >>> 15), a | 1);
    t ^= t + imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = sqrt(-2 * log(u())), q = 2 * PI * u();
    spare = r * sin(q);
    return r * cos(q);
  };
}
// OLS of y on x: slope, R^2, the usual t (assumes independent errors) and Durbin-Watson of the residuals.
function regress(x, y) {
  if (!Array.isArray(x) || !Array.isArray(y) || x.length !== y.length || x.length < 3) {
    throw new RangeError('Need two series of the same length, at least 3 points');
  }
  const n = x.length;
  let mx = 0, my = 0;
  for (let i = 0; i < n; i++) { mx += x[i]; my += y[i]; }
  mx /= n; my /= n;
  let sxx = 0, sxy = 0, syy = 0;
  for (let i = 0; i < n; i++) { const dx = x[i] - mx, dy = y[i] - my; sxx += dx * dx; sxy += dx * dy; syy += dy * dy; }
  if (sxx === 0) throw new RangeError('x never changes');
  const b = sxy / sxx, sse = syy - b * sxy;
  let dw = 0, prev = null;
  for (let i = 0; i < n; i++) {
    const e = (y[i] - my) - b * (x[i] - mx);
    if (prev !== null) dw += (e - prev) ** 2;
    prev = e;
  }
  return {b, r2: 1 - sse / syy, t: b / sqrt(sse / (n - 2) / sxx), dw: dw / sse};
}
// Two independent random walks, many times: regress the levels, then the daily changes.
function spurious(runs, days, drift, seed) {
  if (!Number.isInteger(runs) || runs < 100 || !Number.isInteger(days) || days < 10 || !Number.isFinite(drift)) {
    throw new RangeError('Use at least 100 runs of at least 10 days and a finite drift');
  }
  const z = normals(seed), levels = [], changes = [];
  for (let k = 0; k < runs; k++) {
    const A = [0], B = [0]; // log prices measured from the start
    for (let t = 1; t < days; t++) { A.push(A[t - 1] + drift + 0.01 * z()); B.push(B[t - 1] + drift + 0.01 * z()); }
    levels.push(regress(B, A));
    changes.push(regress(B.slice(1).map((v, i) => v - B[i]), A.slice(1).map((v, i) => v - A[i])));
  }
  const median = (list, key) => list.map(o => abs(o[key])).sort((p, q) => p - q)[Math.floor(runs / 2)];
  const share = (list, test) => list.filter(test).length / runs;
  return {levels: {medianR2: median(levels, 'r2'), r2Above70: share(levels, o => o.r2 > 0.7), medianT: median(levels, 't'),
    t196: share(levels, o => abs(o.t) > 1.96), t10: share(levels, o => abs(o.t) > 10), medianDW: median(levels, 'dw')},
    changes: {medianR2: median(changes, 'r2'), t196: share(changes, o => abs(o.t) > 1.96), medianDW: median(changes, 'dw')},
    pictured: {levels: levels[38], changes: changes[38]}}; // run 38 is the pair drawn on the page
}
function effectiveN(n, rho) {
  if (!(n > 0) || !(abs(rho) < 1)) throw new RangeError('Need n > 0 and |rho| < 1');
  return n * (1 - rho) / (1 + rho);
}
// OLS with an intercept: solve the normal equations by Gauss-Jordan, return the coefficients.
function ols(X, y) {
  const m = X[0].length;
  const A = Array.from({length: m}, (_, i) => Array.from({length: m + 1}, (_, j) =>
    j < m ? X.reduce((s, row) => s + row[i] * row[j], 0) : X.reduce((s, row, t) => s + row[i] * y[t], 0)));
  for (let c = 0; c < m; c++) {
    for (let i = 0; i < m; i++) {
      if (i === c) continue;
      const f = A[i][c] / A[c][c];
      for (let j = c; j <= m; j++) A[i][j] -= f * A[c][j];
    }
  }
  return A.map((row, i) => row[m] / row[i]);
}
// k pure-noise regressors: average R^2 on the data used to fit, and on a fresh sample of the same size.
function noiseR2(n, k, runs, seed) {
  if (![n, k, runs].every(Number.isInteger) || k < 1 || n < k + 2 || runs < 1) throw new RangeError('Need whole numbers with n >= k + 2');
  const z = normals(seed), r2 = (X, y, b) => {
    const ybar = y.reduce((s, v) => s + v, 0) / y.length;
    let sse = 0, sst = 0;
    X.forEach((row, t) => { const fit = row.reduce((s, v, j) => s + v * b[j], 0); sse += (y[t] - fit) ** 2; sst += (y[t] - ybar) ** 2; });
    return 1 - sse / sst;
  };
  let inside = 0, outside = 0;
  for (let r = 0; r < runs; r++) {
    const draw = () => Array.from({length: n}, () => [1, ...Array.from({length: k}, z)]);
    const X = draw(), y = Array.from({length: n}, z), Xnew = draw(), ynew = Array.from({length: n}, z);
    const b = ols(X, y);
    inside += r2(X, y, b); outside += r2(Xnew, ynew, b);
  }
  return {inSample: inside / runs, outOfSample: outside / runs, theoryIn: k / (n - 1), firstOrderOut: -k / n};
}
const adjustedR2 = (r2, n, k) => 1 - (1 - r2) * (n - 1) / (n - k - 1);
const phiN = x => exp(-x * x / 2) / sqrt(2 * PI);
function simpson(f, lo, hi, n) {
  const w = (hi - lo) / n;
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * f(lo + i * w);
  return s * w / 3;
}
const Phi = x => (x < -10 ? 0 : x > 10 ? 1 : 0.5 + Math.sign(x) * simpson(phiN, 0, abs(x), 2000));
// E[max of M independent N(0,1)] = integral of z * M phi(z) Phi(z)^(M-1).
function expectedMax(M) {
  if (!Number.isInteger(M) || M < 1) throw new RangeError('M must be a positive whole number');
  return simpson(z => z * M * phiN(z) * Phi(z) ** (M - 1), -8, 8, 2000);
}
function upperQuantile(p) {
  if (!(p > 0 && p < 0.5)) throw new RangeError('Tail probability must lie in (0, 0.5)');
  let lo = 0, hi = 10;
  for (let i = 0; i < 80; i++) { const mid = (lo + hi) / 2; if (1 - Phi(mid) > p) lo = mid; else hi = mid; }
  return (lo + hi) / 2;
}
// Two identical, uncorrelated assets (true mean 6%, volatility 20%): the optimizer sees estimates m1, m2.
function optimizerPick(m1, m2, trueMean = 0.06, vol = 0.20) {
  if (![m1, m2, trueMean, vol].every(Number.isFinite) || !(m1 > 0 && m2 > 0 && vol > 0)) throw new RangeError('Need positive estimates and volatility');
  const w1 = m1 / (m1 + m2), w2 = m2 / (m1 + m2), sd = vol * sqrt(w1 * w1 + w2 * w2);
  return {w1, w2, sd, seenSharpe: (w1 * m1 + w2 * m2) / sd, realSharpe: trueMean / sd, equalSharpe: trueMean / (vol / sqrt(2))};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • regression บนระดับของสองเส้นที่เดินสุ่มแยกกันให้ $|t|\gt1.96$ ถึง 90.8% ของครั้ง แทนที่จะเป็น 5% และเมื่อ drift ขึ้นทั้งคู่ ครึ่งหนึ่งให้ $R^2$ เกิน 0.70 DW ราว 0.02 คือสัญญาณเตือน และ regression ของการเปลี่ยนรายวันคือทางแก้
  • ข้อมูล $n$ วันที่มี autocorrelation $\rho$ นับเป็นข้อมูลอิสระได้ $n(1-\rho)/(1+\rho)$ ตัว 750 วันที่ $\rho=0.1$ เหลือราว 614 ตัว
  • ตัวแปรขยะ $k$ ตัวให้ $R^2$ ฟรีราว $k/(n-1)$ ในข้อมูลที่ใช้ fit และเสียราว $k/n$ ในข้อมูลใหม่ 50 ตัวบน 750 วันคือ +6.7% กับราว −7%
  • ผู้ชนะจาก 400 แบบที่เป็น noise ล้วนโชว์ Sharpe ห้าปีราว 1.33 แต่ในข้อมูลใหม่คาดว่าเป็นศูนย์ เกณฑ์ Bonferroni ที่ต้องผ่านคือ 1.64 และ optimizer ที่ใช้ค่าประมาณดิบก็เป็นเครื่องเลือกผู้ชนะแบบเดียวกัน
  • backtest ที่ซื่อสัตย์คือ walk-forward ด้วยข้อมูลที่มี ณ วันนั้น มีช่องว่างกันข้อมูลฝึกคาบเกี่ยวกับช่วงทดสอบ และมี holdout ที่เปิดดูครั้งเดียว
