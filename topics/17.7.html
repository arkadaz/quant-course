17.7 VaR Backtesting: Kupiec and Christoffersen

VaR คือตัวเลขที่ธนาคารประกาศทุกเช้าว่า “วันนี้ขาดทุนไม่น่าเกินเท่านี้” หน้านี้ตรวจคำสัญญานั้นย้อนหลัง โดยนับวันที่ขาดทุนเกินตัวเลข แล้วถามสองข้อ: วันแบบนี้มีมากเกินไปไหม (Kupiec) และมาติดกันเกินไปไหม (Christoffersen)

ทุกเช้า ธนาคารต้องประกาศตัวเลขชื่อ VaR (Value at Risk) ของพอร์ตตัวเอง VaR 99% หนึ่งวันคือคำสัญญาว่า “วันนี้ขาดทุนจะเกินตัวเลขนี้ได้แค่ 1 วันใน 100 วัน” ผู้กำกับดูแลธนาคารตรวจคำสัญญานี้ย้อนหลัง โดยนับวันที่ขาดทุนจริงเกิน VaR ที่ประกาศไว้ หน้านี้เรียกวันแบบนั้นว่าวันพลาด

ผู้ตรวจคนหนึ่งได้แบบจำลอง VaR สองตัวมาตรวจ (แบบจำลองในที่นี้คือวิธีคำนวณ VaR ของแต่ละวัน) ตัวเลขของโจทย์นี้เป็นตัวเลขสมมติ:

  • ช่วงที่ตรวจ $T=250$ วันทำการ (วันที่ตลาดเปิด) ราวหนึ่งปี
  • VaR 99% สัญญาว่าโอกาสพลาดคือ $p=1\%$ ต่อวัน จำนวนวันพลาดที่คาดไว้จึงเป็น $Tp=250\times0.01=2.5$ วัน
  • แบบจำลองแรกพลาด 5 วัน กระจายห่าง ๆ ทั้งปี
  • แบบจำลองที่สองก็พลาด 5 วัน แต่เป็น 5 วันติดกัน

ผู้ตรวจบอกว่า “จำนวนเท่ากัน คุณภาพก็เท่ากัน” ถูกไหม? และพลาด 5 วันในเมื่อคาดไว้ 2.5 วัน มากพอจะบอกว่าแบบจำลองผิดหรือยัง?

ลองตอบก่อนเปิดเฉลย

ตัวเลขทุกตัวในเฉลยนี้ หน้านี้จะคำนวณให้ดูทีละขั้น

ข้อแรก 5 วันยังไม่มากพอ การทดสอบของ Kupiec ดูว่าจำนวนวันพลาดห่างจากคำสัญญาเกินความบังเอิญไหม มันให้ค่าสถิติ 1.957 ซึ่งต่ำกว่าจุดตัด 3.841 จึงยังไม่ถือว่าผิด p-value ประมาณ 0.16 แปลว่า ถ้าแบบจำลองถูก ผลที่ห่างจากที่คาดอย่างน้อยเท่านี้เกิดได้ราว 16 ครั้งใน 100 ครั้ง ผลนี้เหมือนกันทั้งสองแบบ เพราะ Kupiec ดูแค่จำนวน

ข้อสอง ผู้ตรวจพูดผิด การทดสอบของ Christoffersen ดูว่าวันพลาดมาติดกันเป็นก้อนไหม มันให้ 0.204 กับแบบแรก แต่ให้ 31.02 กับแบบที่สอง เพราะแบบที่สองพลาดซ้ำ 4 ครั้งจาก 5 วันที่ตามหลังวันพลาด เมื่อรวมสองการทดสอบเป็นตัวเลขเดียวได้ 32.97 ซึ่งให้ p-value ประมาณ $6.9\times10^{-8}$ แบบที่สองจึงถูกปฏิเสธ ส่วนแบบแรกไม่ถูกปฏิเสธ

ภาพรวมก่อนลงสูตร

VaR 99% หนึ่งวันคือ quantile ที่ 99% ของขาดทุน คือตัวเลขที่ขาดทุนของวันจะต่ำกว่ามัน 99 วันใน 100 วัน พูดอีกแบบคือคำสัญญาว่า “ขาดทุนจะเกินตัวเลขนี้แค่ 1% ของวัน” คำสัญญาแบบนี้ตรวจได้เมื่อเวลาผ่านไป วิธีตรวจมีสองขั้น: ประกาศ VaR ไว้ก่อนวันเริ่ม แล้วนับวันที่ขาดทุนจริงเกินมัน วันแบบนั้นภาษาอังกฤษเรียกว่า exception หน้านี้เรียกว่าวันพลาด

ถ้าแบบจำลองถูก วันพลาดต้องมีสองลักษณะ ข้อแรก มาประมาณ 1% ของวัน ข้อสอง มาแบบสุ่ม ไม่เกาะกันเป็นก้อน

นอกจากโจทย์ในกล่องข้างบน หน้านี้ยังใช้ข้อมูลตัวอย่างชุดเล็กอีกชุดให้ลองมือ คือพอร์ตที่ถือสามสินทรัพย์ในสัดส่วนเท่ากัน เราดูผลตอบแทนรายเดือนของพอร์ตย้อนหลัง 60 เดือน (5 ปี) แล้วเทียบแต่ละเดือนกับ VaR 95% รายเดือน VaR 95% สัญญาว่าจะพลาดแค่ 5 เดือนใน 100 เดือน จึงคาดว่าจะพลาด $60\times0.05=3$ เดือน แต่รูปด้านล่างเห็นจริง 5 เดือน (แท่งแดง)

หน้านี้จะถามสองคำถามกับลำดับเลข 0 กับ 1 ของแต่ละวัน (1 คือพลาด 0 คือไม่พลาด) คำถามแรกเรื่องจำนวน: ใช้ Binomial ดูว่าจำนวนวันพลาดแกว่งตามความบังเอิญได้แค่ไหน แล้วสร้างสถิติของ Kupiec และกติกาไฟสามสีของ Basel คำถามที่สองเรื่องจังหวะ: นับว่าเมื่อวานพลาดแล้ววันนี้พลาดอีกบ่อยแค่ไหน ได้สถิติของ Christoffersen ท้ายหน้าจะตอบคำถามที่สำคัญที่สุด คือการทดสอบเหล่านี้จับแบบจำลองที่แย่ได้บ่อยแค่ไหน

ศัพท์ที่ใช้ในหัวข้อนี้
Backtesting
การตรวจย้อนหลัง: เอา VaR ที่ประกาศไว้ก่อนแต่ละวัน มาเทียบกับขาดทุนที่เกิดจริงในวันนั้น เพื่อดูว่าแบบจำลองความเสี่ยงยังเชื่อได้ไหม ผู้กำกับดูแลบังคับให้ธนาคารทำ
Exception (breach) หรือวันพลาด
วันที่ขาดทุนจริงมากกว่า VaR ที่ประกาศไว้ ถ้าโอกาสพลาดคือวันละ 1% ใน 250 วันจะพลาดเฉลี่ย $250\times0.01=2.5$ วัน ตัวเลขนี้เป็นค่าเฉลี่ย ไม่ใช่จำนวนที่ต้องเกิดทุกปี
Likelihood
โอกาสที่จะได้ข้อมูลชุดที่เห็นจริง ถ้าเชื่อคำอธิบายหนึ่ง เช่น “โอกาสพลาดคือวันละ 1%” คำอธิบายที่ทำให้ข้อมูลชุดนี้ดูน่าเกิดกว่า คือคำอธิบายที่เข้ากับข้อมูลได้ดีกว่า
Likelihood ratio (LR)
ตัวเลขที่เทียบ likelihood ของสองคำอธิบาย คือคำอธิบายที่ตรึงค่าไว้ตามคำสัญญา กับคำอธิบายที่ให้ข้อมูลเลือกค่าเอง LR ยิ่งใหญ่ ยิ่งแปลว่าคำสัญญาเข้ากับข้อมูลได้แย่
p-value
ถ้าแบบจำลองถูก นี่คือโอกาสที่จะเห็นผลที่สุดโต่งอย่างน้อยเท่ากับที่เห็นจริง ถ้าต่ำกว่า 5% ถือว่าบังเอิญได้ยาก จึงปฏิเสธแบบจำลอง (ดูการทดสอบสมมติฐาน)
Kupiec (proportion of failures)
การทดสอบว่าสัดส่วนวันพลาดตรงกับที่แบบจำลองสัญญาไหม ดูแค่จำนวน ไม่ดูลำดับวัน
Christoffersen (independence)
การทดสอบว่าโอกาสพลาดวันนี้ขึ้นกับเมื่อวานไหม คือเทียบโอกาสพลาดหลังวันที่ไม่พลาด กับหลังวันที่พลาด ใช้จับแบบจำลองที่ปรับตามความผันผวนของตลาดไม่ทัน แต่ไม่ได้บอกสาเหตุ
Basel Committee (คณะกรรมการ Basel)
กลุ่มผู้กำกับดูแลธนาคารของประเทศหลัก ๆ ที่ออกกติกากลางให้ธนาคารทั่วโลกใช้ ตั้งชื่อตามเมือง Basel ในสวิตเซอร์แลนด์ที่ประชุมกัน
เงินกองทุน (capital)
เงินส่วนของเจ้าของที่ธนาคารต้องมีไว้รองรับขาดทุน ยิ่งกติกาสั่งให้มีมาก ธนาคารยิ่งเอาเงินไปทำธุรกิจได้น้อยลง
Traffic light (ไฟสามสีของ Basel)
กติกาที่แบ่งจำนวนวันพลาดใน 250 วันเป็นสามโซน เขียว เหลือง แดง โซนยิ่งแย่ ธนาคารยิ่งต้องมีเงินกองทุนมากขึ้น
Power
โอกาสที่การทดสอบจะปฏิเสธ เมื่อแบบจำลองผิดจริง ใช้ตอบว่าคำว่า “ผ่าน” มีน้ำหนักแค่ไหน
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$L_t,\ v_t$ขาดทุนจริงของวันที่ $t$ (เสียเป็นบวก) และ VaR ที่ประกาศไว้ก่อนวันนั้นดอลลาร์ หรือ %
$I_t$1 ถ้า $L_t\gt v_t$ (วันพลาด) ไม่อย่างนั้น 00 หรือ 1
$T,\ x$จำนวนวันที่ตรวจ และจำนวนวันพลาดวัน
$p,\ \hat p$โอกาสพลาดที่แบบจำลองสัญญา (0.01 สำหรับ VaR 99%) และสัดส่วนพลาดที่เห็นจริง $x/T$สัดส่วน
$L(p)$likelihood: โอกาสที่จะได้ข้อมูลชุดนี้ ถ้าโอกาสพลาดคือ $p$โอกาส
$n_{ij}$จำนวนคู่ที่เมื่อวานเป็น $i$ และวันนี้เป็น $j$ (0 ไม่พลาด, 1 พลาด)คู่
$\hat\pi_0,\ \hat\pi_1,\ \hat\pi$สัดส่วนพลาดหลังวันไม่พลาด หลังวันพลาด และของทุกวันรวมกันสัดส่วน
$\ell_1,\ \ell_0$log-likelihood ($\ln$ ของ likelihood) ของคำอธิบายที่มีสองโอกาส และที่มีโอกาสเดียวไม่มีหน่วย
$\mathrm{LR}_{\mathrm{uc}},\ \mathrm{LR}_{\mathrm{ind}},\ \mathrm{LR}_{\mathrm{cc}}$สถิติของจำนวน ของการเกาะกลุ่ม และผลรวมของสองตัวไม่มีหน่วย
$q$โอกาสพลาดจริงต่อวัน เมื่อแบบจำลองอาจผิด (ใช้ตอนวัด power)สัดส่วน

ขั้นที่ 1 — จากขาดทุนเป็นเลข 0 กับ 1

ก่อนจะทดสอบอะไรได้ ต้องมีของสองอย่างในทุกงวด อย่างแรกคือ VaR ที่ประกาศไว้ล่วงหน้า อย่างที่สองคือผลจริงว่างวดนั้นพลาดหรือไม่พลาด ขั้นนี้ทำทั้งสองอย่างกับข้อมูล 60 เดือนในรูปแรก ของที่แบบจำลองให้มามีดังนี้:

  • ผลตอบแทนเฉลี่ยต่อปีของสามสินทรัพย์ คือ 6%, 2% และ 4%
  • covariance matrix รายปี $V$ ขนาด 3×3 ซึ่งบอกว่าแต่ละคู่สินทรัพย์ขึ้นลงไปด้วยกันแค่ไหน ถ้าบวกทุกช่องของ $V$ จะได้ 0.018
  • น้ำหนักในพอร์ต $w=(\tfrac13,\ \tfrac13,\ \tfrac13)$ คือถือสามตัวเท่ากัน
  • สมมติว่าผลตอบแทนรายเดือนเป็น Normal

VaR 95% คือขาดทุนที่จะถูกเกินแค่ 5% ของเดือน ถ้าผลตอบแทนเป็น Normal จุดนั้นอยู่ห่างจากค่าเฉลี่ยไปทางขาดทุน 1.645 เท่าของ SD เพราะ Normal มาตรฐานมีพื้นที่เลย 1.645 ออกไปพอดี 5% ขาดทุนเฉลี่ยคือลบของผลตอบแทนเฉลี่ย VaR จึงเป็น $v=-\mu+1.645\,\sigma$ เมื่อ $\mu$ คือผลตอบแทนเฉลี่ยรายเดือน และ $\sigma$ คือความผันผวนรายเดือนของพอร์ต

\[ \begin{aligned} \mu&=\tfrac13(6+2+4)\div12\\ &=4\div12\approx0.333\%,\\ \sigma^2&=w^{\mathsf T}Vw\div12\\ &=\tfrac19(0.018)\div12\\ &=0.002\div12=0.0001667,\\ \sigma&=\sqrt{0.0001667}\approx1.291\%,\\ v&=-\mu+1.645\,\sigma\\ &\approx-0.333+1.645(1.291)\\ &\approx-0.333+2.124=1.790\%,\\ I_t&=1\ \text{if}\ L_t\gt v,\ \text{else}\ 0,\\ x&=\textstyle\sum_{t=1}^{60}I_t=5,\\ Tp&=60(0.05)=3. \end{aligned} \]

ทำไม $w^{\mathsf T}Vw$ กลายเป็น $\tfrac19$ ของผลรวมทุกช่อง? ความเสี่ยงของพอร์ตคือ $w^{\mathsf T}Vw=\sum_i\sum_j w_iw_jV_{ij}$ (ดูความเสี่ยงของพอร์ต) เมื่อน้ำหนักทุกตัวเป็น $\tfrac13$ ทุกพจน์มีตัวคูณ $w_iw_j=\tfrac19$ เท่ากันหมด จึงดึงออกมานอกผลรวมได้ ทำไมหารด้วย 12? เพราะ variance ของผลตอบแทนโตตามเวลาเป็นเส้นตรง ปีหนึ่งมี 12 เดือน variance ต่อเดือนจึงเป็น $\tfrac1{12}$ ของต่อปี ค่าเฉลี่ยก็หารด้วย 12 ด้วยเหตุผลเดียวกัน

VaR 1.790% นี้ต้องล็อกไว้ก่อนเดือนนั้นเริ่ม ห้ามแก้หลังเห็นผล จากนั้นแต่ละเดือนแปลงเป็นเลขตัวเดียว $I_t$ ซึ่งเป็น 1 ถ้าขาดทุน $L_t$ ของเดือนนั้นเกิน $v$ ใน 60 เดือนนี้มีเลข 1 ห้าตัว คือเดือน 36, 42, 43, 53 และ 58 ส่วนที่คาดไว้คือ $Tp=3$ ตัว คำถามต่อไปคือ 5 กับ 3 ห่างกันเกินความบังเอิญหรือยัง

ขั้นที่ 2 — ถ้าแบบจำลองถูก จำนวนวันพลาดเป็น Binomial

จะรู้ว่า 5 กับ 3 (หรือ 5 กับ 2.5) ห่างกันมากไหม ต้องรู้ก่อนว่า ถ้าแบบจำลองถูก จำนวนวันพลาดแกว่งได้แค่ไหนตามธรรมชาติ ถ้าแบบจำลองถูกและแต่ละวันไม่ขึ้นต่อกัน แต่ละวันก็เหมือนโยนเหรียญที่ออก “พลาด” ด้วยโอกาส $p$ จำนวนวันพลาด $x$ ใน $T$ วันจึงเป็น Binomial

เคสหลักของหน้านี้มาจากกติกาจริง ในปี 1996 คณะกรรมการ Basel ให้ธนาคารตรวจ VaR 99% หนึ่งวัน ย้อนหลัง 250 วันทำการ ซึ่งคือราวหนึ่งปี เพราะตลาดหุ้นสหรัฐเปิดราว 252 วันต่อปี คือ $365-104-9=252$ (ปีหนึ่งมีเสาร์อาทิตย์ 104 วัน และวันหยุดราชการที่ตลาดปิดราว 9 วัน) ขั้นนี้แทน $T=250$ และ $p=0.01$ ลงในสูตรของ Binomial

\[ \begin{aligned} P(x=k)&=\binom{T}{k}p^k(1-p)^{T-k},\\ \mathbb E[x]&=Tp=250(0.01)=2.5,\\ P(x=0)&=0.99^{250}\approx0.0811,\\ P(x=1)&=250(0.01)(0.99)^{249}\\ &\approx0.2047,\\ P(x\le4)&\approx0.0811+0.2047+0.2574\\ &\quad+0.2149+0.1341\\ &=0.8922,\\ P(x\ge5)&=1-0.8922=0.1078,\\ T=60,\ p=0.05&:\ P(x\ge5)=1-0.8197\\ &\approx0.180. \end{aligned} \]

$P(x=2)$, $P(x=3)$ และ $P(x=4)$ คิดแบบเดียวกับ $P(x=1)$ แค่เปลี่ยน $k$ ส่วน $P(x\ge5)$ หาจาก $1-P(x\le4)$ เพราะง่ายกว่าบวกทุกจำนวนตั้งแต่ 5 ถึง 250 ข้อมูล 60 เดือนก็คิดแบบเดียวกัน ด้วย $T=60$ และ $p=0.05$

ข้อที่ต้องจำคือ 2.5 เป็นค่าเฉลี่ย ไม่ใช่จำนวนที่ต้องเกิด แบบจำลองที่ถูกเป๊ะยังมีปีที่ไม่พลาดเลยได้ 8.1% และมีปีที่พลาดตั้งแต่ 5 วันได้ 10.78% ดังนั้นพลาด 5 วัน แม้จะเป็นสองเท่าของที่คาด ก็เกิดได้ราวหนึ่งปีในสิบปี ทั้งที่แบบจำลองไม่ผิดอะไรเลย ข้อมูล 60 เดือนยิ่งหลวมกว่า ถ้าแบบจำลองถูก โอกาสเห็นตั้งแต่ 5 เดือนคือ 18% หรือราวหนึ่งในห้า

ขั้นที่ 3 — สถิติของ Kupiec: likelihood ของสองคำอธิบาย

ตัวเลข 10.78% ตอบได้แค่ว่า “พลาดมากเกินไปไหม” แต่แบบจำลองผิดได้สองทาง ถ้า VaR ต่ำไป ก็จะพลาดบ่อย ถ้า VaR สูงไป (ระวังเกิน) ก็จะแทบไม่พลาดเลย Kupiec จึงสร้างตัวเลขเดียวที่วัดว่าข้อมูลห่างจากคำสัญญาแค่ไหน ไม่ว่าจะห่างทางไหน

เครื่องมือที่ใช้คือ likelihood $L(p)$ คือโอกาสที่จะได้ข้อมูลชุดที่เห็น ถ้าโอกาสพลาดคือ $p$ แล้วเทียบสองคำอธิบาย คำอธิบายแรกเชื่อคำสัญญา ใช้ $p$ ตามที่แบบจำลองบอก คำอธิบายที่สองให้ข้อมูลเลือกโอกาสพลาดเอง โดยเลือกค่าที่ทำให้ likelihood สูงสุด ค่านั้นหาได้ด้วยการตั้งอนุพันธ์ของ $\ln L$ เป็นศูนย์ ผลคือ $\hat p=x/T$ สัดส่วนวันพลาดที่เห็นจริงนั่นเอง

\[ \begin{aligned} L(p)&=\tbinom{T}{x}p^x(1-p)^{T-x},\\ \frac{d\ln L}{dp}&=\frac{x}{p}-\frac{T-x}{1-p}=0,\\ \hat p&=\frac{x}{T},\\ \frac{L(p)}{L(\hat p)}&=\Big(\frac{p}{\hat p}\Big)^x\Big(\frac{1-p}{1-\hat p}\Big)^{T-x},\\ \mathrm{LR}_{\mathrm{uc}}&=-2\ln\frac{L(p)}{L(\hat p)}\\ &=2\Big[x\ln\frac{\hat p}{p}\\ &\qquad+(T-x)\ln\frac{1-\hat p}{1-p}\Big]. \end{aligned} \]

อ่านอัตราส่วน $L(p)/L(\hat p)$ เป็นคำถามว่า “ถ้าเชื่อคำสัญญา ข้อมูลชุดนี้ดูน่าเกิดน้อยลงเหลือกี่เท่า” ตัว $\binom{T}{x}$ เหมือนกันทั้งบนและล่าง จึงตัดกันหายไป ส่วน $\hat p$ คือค่าที่ทำให้ likelihood สูงสุด ดังนั้น $L(\hat p)$ ไม่มีวันน้อยกว่า $L(p)$ อัตราส่วนจึงไม่เกิน 1 และ $\ln$ ของมันไม่เป็นบวก พอคูณด้วย $-2$ LR จึงไม่ติดลบ ถ้า $\hat p=p$ พอดี LR เป็นศูนย์ ยิ่ง $\hat p$ ห่างจาก $p$ ไม่ว่าทางมากหรือทางน้อย LR ยิ่งโต ตัวห้อย uc ย่อจาก unconditional coverage คือดูว่าครอบคลุมตามสัญญาไหม โดยไม่สนลำดับวัน

ทำไมต้องคูณ $-2$ ไม่ใช่ $-1$? ใกล้จุดสูงสุด กราฟของ $\ln L$ โค้งเป็นพาราโบลา (Taylor อันดับสอง) ให้ SE คือ standard error ของ $\hat p$ คือขนาดที่ $\hat p$ แกว่งตามความบังเอิญของข้อมูล จะได้

\[ \begin{aligned} \ln L(p)&\approx\ln L(\hat p)-\tfrac12\Big(\frac{\hat p-p}{\mathrm{SE}}\Big)^2,\\ \mathrm{LR}_{\mathrm{uc}}&\approx\Big(\frac{\hat p-p}{\mathrm{SE}}\Big)^2=Z^2. \end{aligned} \]

ถ้าคำสัญญาถูกและข้อมูลมากพอ $Z$ คือ Normal มาตรฐาน ตัวคูณ 2 มีไว้หักล้าง $\tfrac12$ ให้เหลือ $Z^2$ พอดี distribution ของ $Z^2$ มีชื่อว่า chi-square หนึ่ง degree of freedom ผลนี้เรียกว่าทฤษฎีบทของ Wilks (หนึ่ง degree of freedom เพราะคำอธิบายแรกตรึงค่าไว้หนึ่งตัวคือ $p$) จุดตัดมาจาก Normal ตรง ๆ: $Z$ หลุดนอก ±1.96 ได้ 5% ของเวลา $Z^2$ จึงเกิน $1.96^2=3.841$ ได้ 5% ของเวลา ถ้า LR เกิน 3.841 จึงปฏิเสธคำสัญญาที่ระดับ 5% ทั้งหมดนี้เป็นการประมาณ ขั้นถัดไปจะเห็นว่าเมื่อวันพลาดที่คาดไว้มีแค่ 2.5 วัน การประมาณนี้คลาดพอสมควร

ขั้นที่ 4 — ห้าวันใน 250 วัน และช่วงจำนวนที่การทดสอบยอมรับ

ตอนนี้แทนตัวเลขของโจทย์ในกล่องแรก: $T=250$, $x=5$ และ $p=0.01$ สัดส่วนที่เห็นจริงคือ $\hat p=5/250=0.02$ อัตราส่วนสองตัวในสูตรจึงเป็น $\hat p/p=0.02/0.01=2$ และ $(1-\hat p)/(1-p)=0.98/0.99$

จากนั้นหา p-value สองแบบ แบบแรกประมาณด้วย chi-square เพราะ LR มีรูปร่างใกล้ $Z^2$ โอกาสที่ LR เกินค่าที่เห็นจึงเท่ากับโอกาสที่ $|Z|$ เกิน $\sqrt{\mathrm{LR}}$ แบบที่สองนับตรงจาก Binomial: หาว่าจำนวนวันพลาดไหนบ้างให้ LR อย่างน้อยเท่าที่เห็น แล้วบวกโอกาสของจำนวนเหล่านั้น

\[ \begin{aligned} \mathrm{LR}_{\mathrm{uc}}&=2\Big[5\ln2+245\ln\frac{0.98}{0.99}\Big]\\ &\approx2\big[3.465736-2.487331\big]\\ &\approx1.957,\\ p_{\chi^2}&=P\big(|Z|\ge\sqrt{1.957}\big)\\ &=P(|Z|\ge1.399)\approx0.162,\\ p_{\text{exact}}&=P(x=0)+P(x\ge5)\\ &\approx0.0811+0.1078=0.189. \end{aligned} \]

ในวงเล็บมีสองก้อน ก้อนแรก $5\ln2$ เป็นบวก เพราะวันพลาดมีมากกว่าที่สัญญาสองเท่า ก้อนที่สองเป็นลบ เพราะวันที่ไม่พลาดมีน้อยกว่าที่ควรนิดหน่อย สองก้อนหักกันเหลือ $3.465736-2.487331=0.978405$ คูณ 2 ได้ 1.957 ซึ่งต่ำกว่า 3.841 จึงไม่ปฏิเสธ

p-value แบบนับตรงต้องรู้ก่อนว่าจำนวนไหน “สุดโต่งอย่างน้อยเท่า 5 วัน” ตารางข้างล่างแทนจำนวนวันพลาดแต่ละค่าลงในสูตรเดียวกัน จำนวนที่ให้ LR ไม่ต่ำกว่า 1.957 มีสองกลุ่ม คือพลาดตั้งแต่ 5 วัน และไม่พลาดเลย (LR 5.03) ที่ 0 วันติดเข้ามาด้วยเพราะ LR ลงโทษทั้งพลาดมากเกินไปและพลาดน้อยเกินไป p-value แบบนับตรงจึงเป็น 0.189 ไม่ใช่ 0.108

ขั้นที่ 5 — ไฟสามสีในกรอบ Basel ปี 1996

ผู้กำกับดูแลไม่ได้ใช้ LR ตรง ๆ เพราะต้องการกติกาที่ง่ายและตรวจได้ทันที คณะกรรมการ Basel จึงใช้ Binomial ของขั้นที่ 2 แบบสะสม คือบวก $P(x=k)$ ไล่ขึ้นไปทีละจำนวน แล้วแบ่งจำนวนวันพลาดใน 250 วันเป็นสามโซน

แต่ละโซนกำหนดตัวคูณ $k$ ของเงินกองทุน ตามกติกาปี 1996 เงินกองทุนที่ธนาคารต้องมีไว้รองรับความเสี่ยงด้านตลาด คิดเป็นราว $k$ เท่าของ VaR เฉลี่ยช่วง 60 วันทำการล่าสุด โดย $k$ ขั้นต่ำคือ 3 โซนยิ่งแย่ $k$ ยิ่งสูง

\[ \begin{aligned} P(x\le4)&\approx89.22\%,\\ P(x\le5)&\approx95.88\%,\\ P(x\le9)&\approx99.975\%,\\ P(x\le10)&\approx99.99\%,\\ 0\text{–}4&:\ \text{green},\ 3.00,\\ 5\text{–}9&:\ \text{yellow},\ 3.40\text{–}3.85,\\ 10+&:\ \text{red},\ 4.00. \end{aligned} \]

ขอบของโซนมาจากโอกาสสะสม โซนเขียวคือจำนวนที่โอกาสสะสมยังต่ำกว่า 95% ที่ 4 วันได้ 89.22% ยังต่ำกว่า แต่ที่ 5 วันได้ $89.22+6.66=95.88\%$ เกินแล้ว โซนเหลืองจึงเริ่มที่ 5 วัน โซนแดงเริ่มที่จำนวนแรกที่โอกาสสะสมแตะ 99.99% คือ 10 วัน ในโซนเหลือง ตัวคูณขึ้นทีละขั้น: 5 วัน 3.40, 6 วัน 3.50, 7 วัน 3.65, 8 วัน 3.75 และ 9 วัน 3.85

ทั้งสองแบบจำลองในโจทย์พลาด 5 วัน จึงตกโซนเหลืองที่ $k=3.40$ เงินกองทุนส่วนนี้จึงเพิ่มเป็น $3.40/3=1.133$ เท่า หรือเพิ่มราว 13% ทั้งที่ Kupiec ยังไม่ปฏิเสธ

ถ้าแบบจำลองถูก โอกาสตกเหลืองหรือแดงคือ $P(x\ge5)=10.78\%$ ซึ่งตั้งใจให้สูงพอสมควร กติกายอมลงโทษแบบจำลองที่ดีบ้าง เพื่อไม่ให้แบบจำลองที่แย่หลุดรอดง่าย ไฟเหลืองครั้งเดียวจึงยังไม่ใช่หลักฐานว่าแบบจำลองผิด ส่วนไฟแดงเกิดกับแบบจำลองที่ถูกได้แค่ $P(x\ge10)=1-0.99975=0.00025$ คือ 0.025% หรือราว 1 ปีใน 4,000 ปี

ขั้นที่ 6 — นับการเปลี่ยนสถานะ: เมื่อวานพลาด วันนี้พลาดอีกไหม

Kupiec ให้คะแนนสองแบบจำลองในโจทย์เท่ากัน เพราะมันดูแค่จำนวน แต่แบบจำลองที่ดีต้องพลาดแบบสุ่มด้วย ทำไมวันพลาดถึงมาเป็นก้อนได้? เพราะความผันผวนของตลาดจริงมาเป็นช่วง ๆ ช่วงสงบก็สงบยาว ช่วงป่วนก็ป่วนหลายวันติดกัน (ARCH/GARCH อธิบายเรื่องนี้) ถ้าแบบจำลองใช้ความผันผวนคงที่ พอตลาดเข้าช่วงป่วน VaR ก็ต่ำเกินไปหลายวันติดกัน วันพลาดจึงมาเป็นก้อน

วิธีจับคือดูวันเป็นคู่ เมื่อวานกับวันนี้ แต่ละวันมีสองสถานะ คือ 0 (ไม่พลาด) หรือ 1 (พลาด) ให้ $n_{ij}$ คือจำนวนคู่ที่เมื่อวานเป็น $i$ และวันนี้เป็น $j$ เช่น $n_{01}$ คือจำนวนครั้งที่เมื่อวานไม่พลาดแต่วันนี้พลาด วันแรกไม่มีเมื่อวาน จึงกำหนดให้วันก่อนวันแรกเป็น “ไม่พลาด” แล้วจะได้คู่ครบ 250 คู่ จากนั้นคิดสามสัดส่วน คือโอกาสพลาดหลังวันที่ไม่พลาด $\hat\pi_0$ โอกาสพลาดหลังวันที่พลาด $\hat\pi_1$ และโอกาสพลาดของทุกวันรวมกัน $\hat\pi$

\[ \begin{aligned} \hat\pi_0&=\frac{n_{01}}{n_{00}+n_{01}},\\ \hat\pi_1&=\frac{n_{11}}{n_{10}+n_{11}},\\ \hat\pi&=\frac{n_{01}+n_{11}}{T}=\frac{5}{250}=0.02,\\ \text{clustered}&:\ n=(244,\ 1,\ 1,\ 4),\\ &\quad\ \hat\pi_0=\tfrac{1}{245}\approx0.0041,\\ &\quad\ \hat\pi_1=\tfrac45=0.8,\\ \text{separated}&:\ n=(240,\ 5,\ 5,\ 0),\\ &\quad\ \hat\pi_0=\tfrac{5}{245}\approx0.0204,\\ &\quad\ \hat\pi_1=\tfrac05=0. \end{aligned} \]

$n$ เขียนเรียงเป็น $(n_{00},\ n_{01},\ n_{10},\ n_{11})$ ตัวห้อยตัวแรกคือเมื่อวาน ตัวที่สองคือวันนี้ ลองนับชุดที่พลาดติดกัน (clustered) ซึ่งพลาดวันที่ 101 ถึง 105 คู่วันที่ 100 กับ 101 คือการเข้าสู่วันพลาด ได้ $n_{01}=1$ คู่ 101–102 ไปจนถึง 104–105 คือพลาดต่อ ได้ $n_{11}=4$ คู่วันที่ 105 กับ 106 คือการออก ได้ $n_{10}=1$ ที่เหลือเป็นไม่พลาดต่อไม่พลาด ได้ $n_{00}=250-1-4-1=244$

ชุดที่กระจาย (separated) พลาดห้าวันห่างกัน แต่ละวันพลาดมีการเข้าหนึ่งครั้งและการออกหนึ่งครั้ง จึงได้ $n_{01}=n_{10}=5$ และ $n_{11}=0$ ที่เหลือ $n_{00}=250-10=240$

ถ้าวันพลาดไม่ขึ้นกับเมื่อวาน $\hat\pi_0$ กับ $\hat\pi_1$ ควรใกล้กัน และใกล้ $\hat\pi=0.02$ ชุดที่ติดกันห่างกันมาก หลังวันปกติพลาดแค่ 0.41% แต่หลังวันพลาดกลับพลาดซ้ำ 80% ชุดที่กระจายไม่เคยพลาดสองวันติด ($\hat\pi_1=0$) ก็ห่างจาก 0.02 เหมือนกัน แต่มีข้อมูลหลังวันพลาดแค่ 5 คู่ ถ้าโอกาสจริงคือ 2% การไม่พลาดเลยใน 5 คู่ก็เกิดได้ง่าย เพราะ $0.98^5\approx0.90$ ขั้นถัดไปจะวัดความต่างนี้ให้เป็นตัวเลข

ขั้นที่ 7 — สถิติของ Christoffersen

ตอนนี้ใช้ตรรกะเดียวกับ Kupiec คือเทียบ likelihood ของสองคำอธิบาย คำอธิบายแรกบอกว่าโอกาสพลาดขึ้นกับเมื่อวาน จึงมีสองค่า $\hat\pi_0$ และ $\hat\pi_1$ คำอธิบายที่สองบอกว่าเมื่อวานไม่มีผล ใช้โอกาสเดียว $\hat\pi$ กับทุกวัน แล้วดูว่าคำอธิบายแรกเข้ากับข้อมูลดีกว่ามากไหม

ทำงานกับ log-likelihood ($\ell=\ln L$) จะง่ายกว่า เพราะผลคูณของโอกาสกลายเป็นผลบวก แต่ละคู่ใส่ $\ln$ ของโอกาสที่มันเกิดหนึ่งครั้ง เช่น คู่ 0→1 เกิดด้วยโอกาส $\hat\pi_0$ คู่ 0→0 เกิดด้วยโอกาส $1-\hat\pi_0$ คู่แบบเดียวกันมี $n_{ij}$ คู่ จึงคูณ $\ln$ ด้วย $n_{ij}$

\[ \begin{aligned} \ell_1&=\textstyle\sum_{i=0}^{1}\big[n_{i0}\ln(1-\hat\pi_i)\\ &\qquad+n_{i1}\ln\hat\pi_i\big],\\ \ell_0&=(n_{00}+n_{10})\ln(1-\hat\pi)\\ &\quad+(n_{01}+n_{11})\ln\hat\pi,\\ \mathrm{LR}_{\mathrm{ind}}&=2(\ell_1-\ell_0),\\ \mathrm{LR}_{\mathrm{cc}}&=\mathrm{LR}_{\mathrm{uc}}+\mathrm{LR}_{\mathrm{ind}}. \end{aligned} \]

$\ell_1$ ใช้โอกาสคนละค่าสำหรับคู่ที่เริ่มจาก 0 ($i=0$) กับคู่ที่เริ่มจาก 1 ($i=1$) ส่วน $\ell_0$ ใช้ $\hat\pi$ ค่าเดียว จึงรวมคู่ที่จบด้วย 0 เข้าด้วยกัน และคู่ที่จบด้วย 1 เข้าด้วยกัน $\mathrm{LR}_{\mathrm{ind}}$ (ind ย่อจาก independence) เทียบกับ chi-square หนึ่ง degree of freedom ด้วยเหตุผลเดียวกับ Kupiec คือคำอธิบายแรกมีค่าที่ปรับได้สองตัว คำอธิบายที่สองมีตัวเดียว ต่างกันหนึ่งตัว จุดตัดที่ระดับ 5% จึงเป็น 3.841 เหมือนเดิม

$\mathrm{LR}_{\mathrm{cc}}$ (conditional coverage) รวมสองคำถามไว้ในตัวเลขเดียว คือจำนวนถูกไหม และลำดับสุ่มไหม มันเทียบกับ chi-square สอง degree of freedom ซึ่งมีหางเป็น $P(\chi^2_2\gt c)=e^{-c/2}$ พอดี (ดูช่วงความเชื่อมั่น) จุดตัดที่ระดับ 5% จึงหาได้ตรง ๆ จาก $e^{-c/2}=0.05$ ได้ $c=-2\ln0.05=5.991$

ถ้ามีช่องที่เป็นศูนย์ เช่น $n_{11}=0$ ของชุดที่กระจาย จะเจอพจน์ $0\ln0$ ให้ถือว่าเท่ากับ 0 เพราะ $y\ln y$ เข้าใกล้ 0 เมื่อ $y$ เข้าใกล้ 0

ขั้นที่ 8 — แทนตัวเลขของสองชุด

กลับมาที่คำถามในกล่องแรก: ผู้ตรวจที่บอกว่า “จำนวนเท่ากัน คุณภาพก็เท่ากัน” พูดถูกไหม ขั้นนี้แทนตัวเลขของสองชุดลงในสูตรของขั้นที่แล้ว

โจทย์ให้อะไรมาบ้าง:

  • ตารางนับคู่ของชุดที่ติดกัน $n=(244,\ 1,\ 1,\ 4)$ และของชุดที่กระจาย $n=(240,\ 5,\ 5,\ 0)$ จากขั้นที่ 6
  • $\mathrm{LR}_{\mathrm{uc}}=1.957$ จากขั้นที่ 4 ซึ่งเท่ากันทั้งสองชุด เพราะจำนวนวันพลาดเท่ากัน

ในชุดที่ติดกัน $1-\hat\pi_0=\tfrac{244}{245}$ และ $1-\hat\pi_1=\tfrac15$ ส่วนชุดที่กระจาย พจน์หลังวันพลาดหายไปหมด เพราะ $5\ln(1-0)=0$ และ $0\ln0=0$ ค่า $\ell_0$ ใช้แค่จำนวนรวม คือ 245 คู่ที่จบด้วย 0 และ 5 คู่ที่จบด้วย 1 จึงเท่ากันทั้งสองชุด

\[ \begin{aligned} \ell_1^{\text{clu}}&=244\ln\tfrac{244}{245}+\ln\tfrac{1}{245}\\ &\quad+\ln\tfrac15+4\ln\tfrac45\\ &\approx-0.99796-5.50126\\ &\quad-1.60944-0.89257\\ &\approx-9.00123,\\ \ell_0&=245\ln0.98+5\ln0.02\\ &\approx-4.94966-19.56012\\ &\approx-24.50978,\\ \mathrm{LR}_{\mathrm{ind}}^{\text{clu}}&=2(\ell_1^{\text{clu}}-\ell_0)\\ &\approx2(-9.00123+24.50978)\\ &\approx2(15.50855)=31.017,\\ \mathrm{LR}_{\mathrm{cc}}^{\text{clu}}&\approx1.957+31.017=32.974,\\ \ell_1^{\text{sep}}&=240\ln\tfrac{240}{245}+5\ln\tfrac{5}{245}\\ &\approx-4.94863-19.45910\\ &\approx-24.40773,\\ \mathrm{LR}_{\mathrm{ind}}^{\text{sep}}&=2(\ell_1^{\text{sep}}-\ell_0)\\ &\approx2(0.10205)=0.204,\\ \mathrm{LR}_{\mathrm{cc}}^{\text{sep}}&\approx1.957+0.204=2.161. \end{aligned} \]

คำตอบ: ชุดที่ติดกันได้ $\mathrm{LR}_{\mathrm{ind}}=31.02$ สูงกว่าจุดตัด 3.841 มาก และได้ $\mathrm{LR}_{\mathrm{cc}}=32.97$ สูงกว่าจุดตัด 5.991 มาก จึงปฏิเสธ ชุดที่กระจายได้ 0.204 และ 2.161 ต่ำกว่าจุดตัดทั้งสอง จึงไม่ปฏิเสธ p-value ของ $\mathrm{LR}_{\mathrm{cc}}$ คิดจากหางของ chi-square สอง degree of freedom $P(\chi^2_2\gt c)=e^{-c/2}$ โดยแทน $c$ ด้วยค่าที่เห็น:

\[ \begin{aligned} p_{\text{clu}}&=e^{-32.974/2}=e^{-16.49}\\ &\approx6.9\times10^{-8},\\ p_{\text{sep}}&=e^{-2.161/2}=e^{-1.08}\\ &\approx0.34. \end{aligned} \]

จำนวนวันพลาดเท่ากัน แต่ลำดับของวันให้หลักฐานต่างกันสุดขั้ว ผู้ตรวจจึงพูดผิด

ข้อมูล 60 เดือนในรูปแรกมีเดือนพลาดติดกันหนึ่งคู่ คือเดือน 42 กับ 43 นับคู่ได้ดังนี้ เข้าสู่เดือนพลาด 4 ครั้ง (เดือน 36, 42, 53 และ 58) ได้ $n_{01}=4$ พลาดต่อ 1 ครั้ง (42 ไป 43) ได้ $n_{11}=1$ ออก 4 ครั้ง ได้ $n_{10}=4$ ที่เหลือ $n_{00}=60-4-1-4=51$ ดังนั้น $\hat\pi_0=4/55\approx7.3\%$ และ $\hat\pi_1=1/5=20\%$ แทนลงสูตรเดียวกัน:

\[ \begin{aligned} \ell_1&=51\ln\tfrac{51}{55}+4\ln\tfrac{4}{55}\\ &\quad+4\ln\tfrac45+\ln\tfrac15\\ &\approx-3.8509-10.4842\\ &\quad-0.8926-1.6094\\ &\approx-16.8371,\\ \ell_0&=55\ln\tfrac{55}{60}+5\ln\tfrac{5}{60}\\ &\approx-4.7856-12.4245\\ &\approx-17.2102,\\ \mathrm{LR}_{\mathrm{ind}}&\approx2(0.3731)=0.746. \end{aligned} \]

0.746 ต่ำกว่า 3.841 จึงไม่ปฏิเสธ หลังเดือนพลาดมีข้อมูลแค่ 5 คู่ การพลาดซ้ำหนึ่งครั้งยังอธิบายด้วยความบังเอิญได้

อีกเรื่องที่ต้องระวัง: บางช่องของตารางมีจำนวนน้อยมาก (ชุดที่ติดกันมีคู่หลังวันพลาดแค่ 5 คู่) p-value จาก chi-square จึงต้องใช้อย่างระวัง แต่ 31 ห่างจาก 3.841 มากจนข้อสรุปไม่เปลี่ยน

เรื่องจริงของวันพลาดที่เกาะกลุ่ม: ในเดือนสิงหาคม 2007 David Viniar ผู้บริหารฝ่ายการเงิน (CFO) ของ Goldman Sachs บอก Financial Times ว่ากองทุนเชิงปริมาณของบริษัทเจอการขยับขนาด 25 เท่าของ standard deviation หลายวันติดกัน ถ้าผลตอบแทนเป็น Normal จริง โอกาสของวันเดียวแบบนั้นคือ $P(Z\ge25)\approx3\times10^{-138}$ การเห็นหลายวันติดจึงไม่ใช่โชคร้าย แต่บอกว่าความผันผวนที่แบบจำลองใช้ต่ำกว่าความผันผวนจริงของช่วงนั้นมาก ซึ่งคือการพลาดแบบเกาะกลุ่มที่ Christoffersen ออกแบบมาจับ

ตรวจเองใน 10 วินาที: $244+1+1+4=250$ และ $240+5+5+0=250$ คู่ครบทั้งสองชุด

ขั้นที่ 9 — การทดสอบจับแบบจำลองที่แย่ได้บ่อยแค่ไหน

คำว่า “ไม่ปฏิเสธ” ฟังเหมือนสอบผ่าน แต่ควรถามกลับว่า ถ้าแบบจำลองผิดจริง การทดสอบจะจับได้บ่อยแค่ไหน ตัวเลขนี้เรียกว่า power

ลองสมมติว่าโอกาสพลาดจริงต่อวันคือ $q=2\%$ แต่แบบจำลองอ้างว่า 1% แปลว่าแบบจำลองมองว่าวันร้ายเกิดน้อยกว่าความจริงครึ่งหนึ่ง วิธีคิดมีสามขั้น:

  • ใช้ช่วงยอมรับจากขั้นที่ 4: Kupiec ปฏิเสธเมื่อพลาด 0 วัน หรือตั้งแต่ 7 วัน
  • คิดโอกาสที่ $x$ จะตกในช่วงนี้ ด้วย Binomial ที่ $T=250$ แต่ใช้โอกาสพลาดจริง $q$ แทน $p$ เช่น $P(x=0)=(1-q)^{250}$
  • ทำซ้ำกับไฟแดง ($x\ge10$) และไฟเหลืองหรือแดง ($x\ge5$)

ค่า $q=1\%$ คือกรณีที่แบบจำลองถูก ใช้ดูว่าการทดสอบปฏิเสธแบบจำลองที่ดีบ่อยแค่ไหน ค่าอื่นของ $q$ บอก power

\[ \begin{aligned} P_{\text{rej}}(q)&=P(x=0)+P(x\ge7),\\ q=0.01&:\ 0.0811+0.0137=9.48\%,\\ q=0.02&:\ 0.0064+0.2363=24.27\%,\\ q=0.03&:\ 0.0005+0.6250=62.55\%,\\ q=0.02,\ x\ge10&:\ 3.04\%,\\ q=0.02,\ x\ge5&:\ 56.13\%. \end{aligned} \]

เริ่มจากกรณีที่แบบจำลองถูก ($q=1\%$) การทดสอบที่ตั้งใจให้ปฏิเสธผิดแค่ 5% กลับปฏิเสธแบบจำลองที่ดี 9.48% ของปี เหตุผลมีสองข้อ ข้อแรก จำนวนวันเป็นเลขเต็ม ขอบของช่วงยอมรับจึงขยับได้ทีละหนึ่งวัน ตัดให้ได้ 5% พอดีไม่ได้ ข้อสอง chi-square ประมาณได้ไม่ดีเมื่อวันพลาดที่คาดไว้มีแค่ 2.5 วัน

ส่วนที่น่ากลัวคือกรณี $q=2\%$ แบบจำลองที่พลาดจริงบ่อยเป็นสองเท่าของที่อ้าง ถูก Kupiec จับได้แค่ 24% ของปี อีก $100-24.27=75.73\%$ ผ่าน ไฟแดงจับได้แค่ 3% ไฟเหลืองหรือแดงจับได้ 56% ทำไมจับยาก? เพราะแบบจำลองที่ผิดนี้คาดว่าจะพลาดแค่ $250\times0.02=5$ วัน ส่วนแบบจำลองที่ถูกคาด 2.5 วัน และทั้งสองแกว่งได้หลายวันตามความบังเอิญ สองกองนี้จึงซ้อนกันมาก

ข้อมูลปีเดียวมีวันพลาดที่คาดไว้น้อยเกินจะแยกแบบจำลองที่ดีออกจากแบบที่แย่ได้ชัด “ไม่ปฏิเสธ” จึงแปลว่า “ยังไม่มีหลักฐานพอว่าแย่” ไม่ได้แปลว่าดี

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

แก้ VaR หลังเห็นขาดทุน: ถ้าคำนวณ VaR ของวันหนึ่งใหม่ โดยรวมข้อมูลของวันนั้นเข้าไปด้วย ตัวเลขนั้นไม่ใช่การพยากรณ์ล่วงหน้าแล้ว และมักทำให้ผลการตรวจดูดีกว่าตอนใช้งานจริง VaR ต้องล็อกไว้ก่อนเห็นผลเสมอ

รายงาน p-value ผิดตัว: คนมักรายงานโอกาสหางด้านเดียว $P(x\ge5)=0.108$ เป็น p-value ของ Kupiec ซึ่งผิด เพราะ LR ลงโทษทั้งสองทาง ตัวที่ถูกคือ $P(|Z|\ge1.399)\approx0.162$ ถ้าประมาณด้วย chi-square หรือ $P(x=0)+P(x\ge5)\approx0.0811+0.1078=0.189$ ถ้านับตรงจาก Binomial

สรุปว่าแบบจำลองระวังเกินจากปีที่ไม่พลาดเลย: ถ้าดูแค่ chi-square จะเห็น $\mathrm{LR}_{\mathrm{uc}}(0)=5.03$ เกินจุดตัด 3.841 จึงอยากปฏิเสธ แต่ถ้านับตรง จำนวนที่สุดโต่งอย่างน้อยเท่า 0 วันคือ 0 วัน และตั้งแต่ 7 วัน (LR 5.50) ไม่รวม 6 วัน (LR 3.56) p-value จึงเป็น $P(x=0)+P(x\ge7)\approx0.0811+0.0137=0.0948$ ซึ่งเกิน 0.05 จึงไม่ปฏิเสธ แบบจำลองที่ถูกเป๊ะก็ไม่พลาดเลยได้ 8.1% ของปี

หาร $\hat\pi_1$ ด้วยศูนย์: ถ้าไม่มีวันพลาดเลย ก็ไม่มีวันที่ตามหลังวันพลาด $n_{10}+n_{11}=0$ และประมาณ $\hat\pi_1$ ไม่ได้ อย่าหารศูนย์แล้วรายงาน p-value สวย ๆ ออกมา โค้ดข้างล่างโยน error แทน

ดูแค่ 0 กับ 1: การนับไม่เห็นว่าวันพลาดเสียลึกแค่ไหน พอร์ตที่ขาดทุนบ่อยครั้งละนิด แต่นาน ๆ ทีเสียหนักมาก (เรียกว่า tail stuffing) ผ่านการนับได้สบาย จึงต้องดูขนาดของขาดทุนในหางด้วย Expected Shortfall (ขาดทุนเฉลี่ยในวันที่แย่กว่า VaR) และดูผลตอบแทนทั้งชุด หลังลบค่าเฉลี่ยแล้วหารด้วยความผันผวนที่แบบจำลองบอก ถ้าแบบจำลองถูก ตัวเลขนี้มีค่าเฉลี่ย 0 และ variance 1 ค่าเฉลี่ยของกำลังสองของมันจึงควรใกล้ 1 แต่ข้อมูล 60 เดือนในรูปแรก ซึ่งใช้ $\mu=0.333\%$ และ $\sigma=1.291\%$ จากขั้นที่ 1 ให้

\[ \begin{aligned} \frac{1}{60}\sum_{t=1}^{60}\Big(\frac{r_t-\mu}{\sigma}\Big)^2&\approx0.81,\\ \sqrt{0.81}&=0.9. \end{aligned} \]

เมื่อ $r_t$ คือผลตอบแทนของเดือน $t$ ผลนี้แปลว่าความผันผวนจริงเป็นแค่ราว 0.9 เท่าของที่แบบจำลองบอก ทั้งที่จำนวนเดือนพลาดมากกว่าที่คาด การนับวันพลาดอย่างเดียวจึงเล่าเรื่องไม่ครบ

ลืมว่ามีหลายโต๊ะ: ธนาคารที่ตรวจ 20 โต๊ะเทรด ซึ่งแบบจำลองถูกทุกโต๊ะ และผลของแต่ละโต๊ะไม่ขึ้นต่อกัน แต่ละโต๊ะอยู่โซนเขียวด้วยโอกาส $P(x\le4)=0.8922$ โอกาสที่อย่างน้อยหนึ่งโต๊ะจะตกเหลืองคือ $1-0.8922^{20}\approx89.8\%$ โต๊ะเดียวที่ตกเหลืองในยี่สิบโต๊ะจึงไม่ใช่หลักฐานพิเศษ เป็นเรื่องเดียวกับการทดสอบหลายครั้ง

ใช้ทำอะไรบนโต๊ะจริง

ในงานจริง ธนาคารเก็บ VaR ที่ประกาศไว้ทุกวัน คู่กับ P&L (กำไรขาดทุนของวัน) สองแบบ แบบแรกคือ P&L สมมติ: ถ้าถือพอร์ตเมื่อเช้าไว้ทั้งวันโดยไม่เทรดเลย จะได้หรือเสียเท่าไร แบบที่สองคือ P&L จริง ซึ่งรวมการเทรดระหว่างวันและค่าธรรมเนียม

VaR คิดจากพอร์ตเมื่อเช้า การเทียบกับ P&L สมมติจึงทดสอบตัวแบบจำลองตรง ๆ ถ้า P&L สองแบบให้ผลการตรวจต่างกันมาก ให้ตรวจผลของการเทรดระหว่างวันและการตีราคาก่อน แล้วค่อยโทษแบบจำลอง

ไฟสามสีใช้กำหนดเงินกองทุนตามกติกาของผู้กำกับดูแล ส่วนการทดสอบการเกาะกลุ่มใช้กันภายในธนาคาร เพื่อถามว่าการพยากรณ์ความผันผวนตามตลาดทันไหม กติการุ่นใหม่ของ Basel ที่เรียกว่า FRTB คิดเงินกองทุนจาก Expected Shortfall แทน VaR แต่ยังนับวันพลาดของ VaR เพื่อตรวจแต่ละโต๊ะเทรด เพราะการนับเข้าใจง่ายและตรวจได้เร็ว

โจทย์ตรวจความเข้าใจ

1. ธนาคารตรวจ VaR 99% หนึ่งวันของโต๊ะหนึ่ง ย้อนหลังสองปี คือ $T=500$ วันทำการ เจอวันพลาด $x=9$ วัน ส่วนที่คาดไว้คือ $Tp=500\times0.01=5$ วัน Kupiec ปฏิเสธไหม?

เฉลย

สัดส่วนที่เห็นคือ $\hat p=9/500=0.018$ แทนลงสูตรของ Kupiec:

\[ \begin{aligned} \mathrm{LR}&=2\Big[9\ln\frac{0.018}{0.01}\\ &\qquad+491\ln\frac{0.982}{0.99}\Big]\\ &\approx2\big[5.2901-3.9838\big]\\ &\approx2.613. \end{aligned} \]

2.613 ต่ำกว่า 3.841 จึงไม่ปฏิเสธ ทั้งที่เห็นวันพลาดเกือบสองเท่าของที่คาด เพราะแม้มีข้อมูลสองปี วันพลาดที่คาดไว้ก็มีแค่ 5 วัน ความบังเอิญยังกลบสัญญาณได้

2. อีกโต๊ะหนึ่งรายงาน VaR 95% ซึ่งสัญญาว่าจะพลาด 5% ของวัน ตรวจย้อนหลัง $T=250$ วัน เจอวันพลาด $x=20$ วัน ส่วนที่คาดไว้คือ $Tp=250\times0.05=12.5$ วัน Kupiec ปฏิเสธไหม?

เฉลย

สัดส่วนที่เห็นคือ $\hat p=20/250=0.08$ แทนลงสูตร:

\[ \begin{aligned} \mathrm{LR}&=2\Big[20\ln\frac{0.08}{0.05}\\ &\qquad+230\ln\frac{0.92}{0.95}\Big]\\ &\approx2\big[9.4001-7.3803\big]\\ &\approx4.040. \end{aligned} \]

4.040 เกิน 3.841 เล็กน้อย จึงปฏิเสธที่ระดับ 5% VaR ระดับต่ำกว่าคาดวันพลาดไว้มากกว่า (12.5 วัน เทียบกับ 2.5 วันของ VaR 99%) การทดสอบจึงมีข้อมูลให้ใช้มากกว่า นี่คือเหตุผลที่บางกติกาตรวจ VaR 97.5% ด้วย

3. แบบจำลองหนึ่งพลาดวันที่ 10, 11, 100, 200, 201 และ 202 ใน 250 วัน ให้นับตารางคู่ (เมื่อวาน, วันนี้) แล้วหา $\mathrm{LR}_{\mathrm{ind}}$ วันพลาดเกาะกลุ่มเกินความบังเอิญไหม?

เฉลย

นับคู่ก่อน เข้าสู่วันพลาดสามครั้ง (วันที่ 10, 100 และ 200) ได้ $n_{01}=3$ พลาดต่อสามครั้ง (10 ไป 11, 200 ไป 201, 201 ไป 202) ได้ $n_{11}=3$ ออกสามครั้ง (11 ไป 12, 100 ไป 101, 202 ไป 203) ได้ $n_{10}=3$ ที่เหลือ $n_{00}=250-3-3-3=241$

สัดส่วนสามตัวคือ $\hat\pi_0=3/244\approx1.23\%$, $\hat\pi_1=3/6=50\%$ และ $\hat\pi=6/250=0.024$ แทนลงสูตรของ Christoffersen:

\[ \begin{aligned} \ell_1&=241\ln\tfrac{241}{244}+3\ln\tfrac{3}{244}\\ &\quad+3\ln\tfrac12+3\ln\tfrac12\\ &\approx-2.9815-13.1957\\ &\quad-2.0794-2.0794\\ &\approx-20.336,\\ \ell_0&=244\ln0.976+6\ln0.024\\ &\approx-5.9274-22.3782\\ &\approx-28.306,\\ \mathrm{LR}_{\mathrm{ind}}&=2(-20.336+28.306)\\ &\approx15.94. \end{aligned} \]

15.94 เกิน 3.841 มาก จึงปฏิเสธว่าวันพลาดเป็นอิสระต่อกัน หลังวันพลาด แบบจำลองนี้พลาดซ้ำถึงครึ่งหนึ่ง ขณะที่หลังวันปกติพลาดแค่ราว 1%

const xlogy = (x, y) => (x === 0 ? 0 : x * Math.log(y));        // 0 ln 0 = 0 by the limit
// Complementary error function: series for small x, continued fraction for large x.
function erfc(x) {
  const t = Math.abs(x); let e;
  if (t < 2.5) { let s = 0, term = t; for (let k = 0; k < 300; k++) { const add = term / (2 * k + 1); s += add; if (Math.abs(add) < 1e-18 * Math.abs(s)) break; term *= -t * t / (k + 1); } e = 1 - 2 / Math.sqrt(Math.PI) * s; }
  else { let f = t; for (let k = 150; k >= 1; k--) f = t + (k / 2) / f; e = Math.exp(-t * t) / Math.sqrt(Math.PI) / f; }
  return x >= 0 ? e : 2 - e;
}
const chi2sf1 = x => erfc(Math.sqrt(x / 2));     // P(chi2 with 1 df >= x) = P(|Z| >= sqrt x)
const chi2sf2 = x => Math.exp(-x / 2);           // chi2 with 2 df has tail e^(-x/2)
function binomial(T, p) {
  const pmf = [(1 - p) ** T];
  for (let k = 1; k <= T; k++) pmf.push(pmf[k - 1] * (T - k + 1) / k * p / (1 - p));
  return pmf;
}
function kupiec(x, T, p) {
  const ph = x / T;
  return 2 * (xlogy(x, ph) + xlogy(T - x, 1 - ph) - xlogy(x, p) - xlogy(T - x, 1 - p));
}
// Transition counts n00, n01, n10, n11 of breach days (1..T); the day before day 1 counts as "no breach".
function transitions(T, days) {
  const s = new Array(T + 1).fill(0); days.forEach(d => (s[d] = 1));
  const n = [0, 0, 0, 0];
  for (let t = 1; t <= T; t++) n[2 * s[t - 1] + s[t]]++;
  return n;
}
function christoffersen([n00, n01, n10, n11]) {
  if (n10 + n11 === 0) throw new RangeError('no day after a breach: pi1 cannot be estimated');
  const p0 = n01 / (n00 + n01), p1 = n11 / (n10 + n11), p = (n01 + n11) / (n00 + n01 + n10 + n11);
  const l1 = xlogy(n00, 1 - p0) + xlogy(n01, p0) + xlogy(n10, 1 - p1) + xlogy(n11, p1);
  const l0 = xlogy(n00 + n10, 1 - p) + xlogy(n01 + n11, p);
  return 2 * (l1 - l0);
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ถ้าแบบจำลองถูกและแต่ละวันไม่ขึ้นต่อกัน จำนวนวันพลาดของ VaR 99% ใน 250 วันเป็น Binomial คาดไว้ $250\times0.01=2.5$ วัน แต่ไม่พลาดเลยได้ 8.1% ของปี และพลาดตั้งแต่ 5 วันได้ 10.78% ของปี
  • Kupiec เทียบ likelihood ของโอกาสที่สัญญา $p$ กับสัดส่วนที่เห็นจริง $\hat p$ ห้าวันใน 250 วันให้ LR 1.957 ต่ำกว่าจุดตัด 3.841 (p-value 0.162 จาก chi-square หรือ 0.189 แบบนับตรง) การทดสอบที่ระดับ 5% ยอมรับเมื่อพลาด 1 ถึง 6 วัน
  • ไฟสามสีของ Basel มาจาก Binomial แบบสะสม: 0–4 วันเขียว 5–9 วันเหลือง ตั้งแต่ 10 วันแดง ห้าวันทำให้ตัวคูณเงินกองทุนขึ้นจาก 3 เป็น 3.40
  • Christoffersen นับคู่ (เมื่อวาน, วันนี้) เพื่อดูว่าวันพลาดมาเป็นก้อนไหม ห้าวันติดกันให้ 31.02 ห้าวันที่กระจายให้ 0.204 จำนวนเท่ากัน แต่หลักฐานต่างกันสุดขั้ว
  • การทดสอบด้วยข้อมูลปีเดียวมี power ต่ำ แบบจำลองที่พลาดจริง 2% แต่อ้าง 1% ถูกจับได้แค่ 24% ของปี “ไม่ปฏิเสธ” จึงไม่ได้แปลว่าแบบจำลองดี

เมื่อ VaR สอบตก ต้นเหตุมักอยู่ที่ตัวเลขที่ป้อนเข้า โดยเฉพาะ covariance matrix ที่ประมาณจากข้อมูลน้อยเกินไป หน้าถัดไป Ledoit–Wolf shrinkage ดูว่า covariance ที่คิดจากข้อมูลมีเสียงรบกวนแค่ไหน inverse ของมันขยายเสียงนั้นไปเป็นน้ำหนักพอร์ตอย่างไร และการผสมมันกับ matrix ที่เรียบง่ายช่วยได้เท่าไร
