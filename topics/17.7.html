17.7 VaR Backtesting: Kupiec and Christoffersen

VaR คือคำสัญญาว่าขาดทุนจะเกินเส้นเพียงสัดส่วนที่กำหนดของวัน การทดสอบย้อนหลังนับวันที่ขาดทุนเกินเส้นแล้วถามสองข้อ: มากเกินไปไหม (Kupiec) และมาติดกันเกินไปไหม (Christoffersen)

สองแบบจำลอง VaR 99% หนึ่งวัน ถูกตรวจย้อนหลัง 250 วันทำการ ทั้งคู่มีวันที่ขาดทุนเกิน VaR 5 วันเท่ากัน แบบแรกพลาดกระจายทั้งปี แบบที่สองพลาดห้าวันติดกัน ผู้ตรวจคนหนึ่งบอกว่า “จำนวนเท่ากัน คุณภาพก็เท่ากัน” ถูกไหม? และห้าวันในเมื่อคาดไว้ 2.5 วัน มากพอจะเรียกว่าแบบจำลองผิดหรือยัง?

ลองตอบก่อนเปิดเฉลย

ห้าวันยังไม่มากพอ: การทดสอบของ Kupiec ให้สถิติ 1.957 ต่ำกว่าจุดตัด 3.841 (p-value ประมาณ 0.16) ทั้งสองแบบ แต่จำนวนเท่ากันไม่ได้แปลว่าเท่ากัน การทดสอบของ Christoffersen ให้ 0.204 กับชุดที่กระจาย และ 31.02 กับชุดที่ติดกัน ชุดหลังพลาดซ้ำใน 4 จาก 5 วันที่ตามหลังวันพลาด สถิติรวม 32.97 ให้ p-value ประมาณ $6.9\times10^{-8}$ แบบที่สองจึงถูกปฏิเสธ ส่วนแบบแรกไม่ถูกปฏิเสธ

ภาพรวมก่อนลงสูตร

VaR 99% หนึ่งวันคือ quantile ที่ 99% ของขาดทุน พูดอีกแบบคือคำสัญญาว่า “ขาดทุนจะเกินตัวเลขนี้เพียง 1% ของวัน” คำสัญญาแบบนี้ตรวจได้เมื่อเวลาผ่านไป: ประกาศ VaR ไว้ก่อนวันเริ่ม แล้วนับวันที่ขาดทุนจริงเกินมัน เรียกวันนั้นว่า exception ถ้าแบบจำลองถูก exception ต้องมาประมาณ 1% ของวัน และต้องมาแบบสุ่ม ไม่เกาะกันเป็นก้อน

รูปด้านล่างคือการตรวจแบบนี้กับข้อมูลตัวอย่าง: ผลตอบแทนรายเดือน 60 เดือนของพอร์ตที่ถือสามสินทรัพย์เท่ากัน เทียบกับ VaR 95% รายเดือนที่คิดจากพารามิเตอร์ของแบบจำลอง แท่งแดงคือเดือนที่ขาดทุนเกินเส้น มี 5 เดือน ขณะที่แบบจำลองคาดไว้ 3 เดือน

หน้านี้จะถามสองคำถามกับเลข 0 กับ 1 ของแต่ละวัน คำถามแรกเรื่องจำนวน: ใช้ Binomial บอกว่าจำนวนแกว่งได้แค่ไหน แล้วสร้างสถิติของ Kupiec และกติกาไฟสามสีของ Basel คำถามที่สองเรื่องจังหวะ: นับว่าเมื่อวานพลาดแล้ววันนี้พลาดอีกบ่อยแค่ไหน ได้สถิติของ Christoffersen แล้วจบที่คำถามที่สำคัญที่สุด คือการทดสอบจับแบบจำลองที่แย่ได้บ่อยแค่ไหน

ศัพท์ที่ใช้ในหัวข้อนี้
Backtesting
การเทียบ VaR ที่ประกาศไว้ก่อนแต่ละวันกับขาดทุนที่เกิดจริง ใช้ตรวจว่าแบบจำลองความเสี่ยงยังใช้ได้ ผู้กำกับดูแลบังคับให้ธนาคารทำ
Exception (breach)
วันที่ขาดทุนจริงมากกว่า VaR ที่ประกาศ ถ้าโอกาสพลาดวันละ 1% จำนวนเฉลี่ยใน 250 วันคือ 2.5 วัน ไม่ใช่จำนวนที่ต้องเกิดทุกปี
Likelihood ratio (LR)
สองเท่าของผลต่าง log-likelihood ระหว่างคำอธิบายที่ยืดหยุ่นกว่ากับคำอธิบายที่ตรึงค่าไว้ ใช้ถามว่าความยืดหยุ่นที่เพิ่มอธิบายข้อมูลดีขึ้นเกินความบังเอิญไหม
Kupiec (proportion of failures)
การทดสอบว่าสัดส่วนวันพลาดตรงกับที่แบบจำลองสัญญาหรือไม่ ดูแค่จำนวน ไม่ดูลำดับ
Christoffersen (independence)
การทดสอบว่าโอกาสพลาดวันนี้ต่างกันหรือไม่ระหว่างกรณีที่เมื่อวานพลาดกับไม่พลาด ใช้จับแบบจำลองที่ปรับตามความผันผวนไม่ทัน แต่ไม่ได้บอกสาเหตุ
Traffic light (ไฟสามสีของ Basel)
กติกาที่แบ่งจำนวนวันพลาดใน 250 วันเป็นเขียว เหลือง แดง แล้วเพิ่มตัวคูณเงินกองทุนตามโซน
Power
โอกาสที่การทดสอบปฏิเสธเมื่อแบบจำลองผิดจริง ใช้ตอบว่า “ผ่าน” มีความหมายแค่ไหน
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$L_t,\ v_t$ขาดทุนจริงของวันที่ $t$ (เสียเป็นบวก) และ VaR ที่ประกาศไว้ก่อนวันนั้นดอลลาร์ หรือ %
$I_t$1 ถ้า $L_t\gt v_t$ ไม่อย่างนั้น 00 หรือ 1
$T,\ x$จำนวนวันที่ตรวจ และจำนวนวันพลาดวัน
$p,\ \hat p$สัดส่วนพลาดที่แบบจำลองสัญญา (0.01 สำหรับ VaR 99%) และสัดส่วนที่เห็น $x/T$สัดส่วน
$n_{ij}$จำนวนคู่ (เมื่อวานสถานะ $i$, วันนี้สถานะ $j$)คู่
$\hat\pi_0,\ \hat\pi_1,\ \hat\pi$สัดส่วนพลาดหลังวันไม่พลาด หลังวันพลาด และรวมสัดส่วน
$\mathrm{LR}_{\mathrm{uc}},\ \mathrm{LR}_{\mathrm{ind}},\ \mathrm{LR}_{\mathrm{cc}}$สถิติของจำนวน ของการเกาะกลุ่ม และผลรวมของสองตัวไม่มีหน่วย

ขั้นที่ 1 — จากขาดทุนเป็นเลข 0 กับ 1

ก่อนทดสอบอะไร ต้องมี VaR ที่ประกาศไว้ล่วงหน้าทุกงวด แล้วแปลงขาดทุนแต่ละงวดเป็นพลาดหรือไม่พลาด ลองกับข้อมูลในรูปแรก: แบบจำลองบอกว่าสามสินทรัพย์มีผลตอบแทนเฉลี่ย 6%, 2% และ 4% ต่อปี และ covariance รายปี $V$ ที่ผลรวมทุกช่องเท่ากับ 0.018 พอร์ตถือเท่ากัน ถ้าผลตอบแทนเป็น Normal VaR คือค่าเฉลี่ยของขาดทุนบวก 1.645 เท่าของความผันผวน

\[ \begin{aligned} \mu&=\frac{6+2+4}{3}\cdot\frac{1}{12}\approx0.333\%,\\ \sigma^2&=\frac{1}{9}\cdot\frac{0.018}{12}=0.0001667,\\ \sigma&\approx1.291\%,\\ v&=-\mu+1.645\,\sigma\\ &\approx-0.333+2.124=1.790\%,\\ I_t&=1\ \text{if}\ L_t\gt v,\ \text{else}\ 0,\\ x&=\textstyle\sum_{t=1}^{60}I_t=5,\\ Tp&=60(0.05)=3. \end{aligned} \]

variance ของพอร์ตที่ถือ $\tfrac13$ เท่ากันคือ $\tfrac19$ ของผลรวมทุกช่องของ $V$ (ความเสี่ยงของพอร์ต $w^{\mathsf T}Vw$) ได้ 0.002 ต่อปี หารด้วย 12 เป็นรายเดือนเพราะ variance โตตามเวลา ส่วนค่าเฉลี่ยของขาดทุนคือลบของค่าเฉลี่ยผลตอบแทน VaR จึงเริ่มจาก $-\mu$

VaR ต้องล็อกก่อนเดือนนั้นเริ่ม ห้ามแก้หลังเห็นผล ตัวเลข 0/1 ของ 60 เดือนนี้มีเลข 1 ห้าตัวในเดือน 36, 42, 43, 53 และ 58 เทียบกับที่คาด 3 ตัว คำถามต่อไปคือ 5 กับ 3 ห่างกันเกินความบังเอิญหรือยัง

ขั้นที่ 2 — ถ้าแบบจำลองถูก จำนวนวันพลาดเป็น Binomial

ถ้าแบบจำลองถูกและแต่ละวันอิสระกัน แต่ละวันคือเหรียญที่ออกหัว (พลาด) ด้วยโอกาส $p$ จำนวนวันพลาดใน $T$ วันจึงเป็น Binomial เคสหลักของหน้านี้คือกรอบ backtesting ของ Basel ปี 1996 ที่ตรวจ VaR 99% หนึ่งวันย้อนหลัง 250 วันทำการ (ราวหนึ่งปี เพราะปีหนึ่งมีราว 252 วันทำการ)

\[ \begin{aligned} P(x=k)&=\binom{T}{k}p^k(1-p)^{T-k},\\ T=250,\ p=0.01&:\ \mathbb E[x]=2.5,\\ P(x=0)&=0.99^{250}\approx0.0811,\\ P(x\le4)&\approx0.0811+0.2047+0.2574\\ &\quad+0.2149+0.1341\\ &=0.8922,\\ P(x\ge5)&\approx0.1078,\\ T=60,\ p=0.05&:\ P(x\ge5)\approx0.180. \end{aligned} \]

2.5 เป็นค่าเฉลี่ย ไม่ใช่จำนวนที่ต้องเกิด แบบจำลองที่ถูกเป๊ะยังมีโอกาส 8.1% ที่จะไม่พลาดเลยทั้งปี และ 10.78% ที่จะพลาดตั้งแต่ 5 วัน ห้าวันจึงเป็นสองเท่าของค่าคาด แต่เป็นเรื่องที่เกิดได้ราวหนึ่งปีในสิบปีแม้แบบจำลองถูก ข้อมูล 60 เดือนในรูปแรกยิ่งหลวม: เห็นตั้งแต่ 5 เดือนได้ 18% ของเวลา

ขั้นที่ 3 — สถิติของ Kupiec: likelihood ของสองคำอธิบาย

ต้องมีตัวเลขเดียวที่บอกว่าข้อมูลห่างจากคำสัญญาแค่ไหน คำอธิบายแรกบอกว่าโอกาสพลาดคือ $p$ ตามที่แบบจำลองสัญญา คำอธิบายที่สองปล่อยให้ข้อมูลเลือกโอกาสเอง ซึ่งค่าที่ทำให้ข้อมูลน่าจะเกิดที่สุดคือ $\hat p=x/T$ แล้วถามว่าคำอธิบายแรกแย่กว่าแค่ไหน ตัว $\binom{T}{x}$ เหมือนกันทั้งสองคำอธิบายจึงตัดกัน

\[ \begin{aligned} \frac{L(p)}{L(\hat p)}&=\Big(\frac{p}{\hat p}\Big)^x\Big(\frac{1-p}{1-\hat p}\Big)^{T-x},\\ \mathrm{LR}_{\mathrm{uc}}&=-2\ln\frac{L(p)}{L(\hat p)}\\ &=2\Big[x\ln\frac{\hat p}{p}\\ &\qquad+(T-x)\ln\frac{1-\hat p}{1-p}\Big]. \end{aligned} \]

$L(\hat p)$ ไม่มีวันน้อยกว่า $L(p)$ เพราะ $\hat p$ คือค่าที่ทำให้ likelihood สูงสุด อัตราส่วนจึงไม่เกิน 1 และ LR ไม่ติดลบ ถ้า $\hat p=p$ พอดี LR เป็นศูนย์ ยิ่ง $\hat p$ ห่างจาก $p$ ไม่ว่าทางมากหรือทางน้อย LR ยิ่งโต ตัวห้อย uc ย่อจาก unconditional coverage คือดูความครอบคลุมโดยไม่สนลำดับ

ทำไมคูณ $-2$? เพราะทฤษฎีบทของ Wilks บอกว่าเมื่อข้อมูลมากและคำอธิบายที่ตรึงค่าถูก $-2\ln$ ของอัตราส่วนนี้มี distribution ใกล้ chi-square หนึ่ง degree of freedom (ตรึงค่าไว้หนึ่งตัว) จุดตัดที่ระดับ 5% คือ 3.841 ซึ่งเท่ากับ $1.96^2$ นี่คือการประมาณ ขั้นถัดไปจะเห็นว่าที่จำนวนพลาดน้อยขนาดนี้มันคลาดพอสมควร

ขั้นที่ 4 — ห้าวันใน 250 วัน และช่วงจำนวนที่การทดสอบยอมรับ

แทน $T=250$, $x=5$, $p=0.01$ ลงในสูตร แล้วหา p-value สองแบบ: แบบประมาณด้วย chi-square (เท่ากับโอกาสที่ Normal มาตรฐานห่างศูนย์อย่างน้อย $\sqrt{\mathrm{LR}}$) และแบบนับตรงจาก Binomial ว่าจำนวนไหนบ้างให้ LR อย่างน้อยเท่านี้

\[ \begin{aligned} \mathrm{LR}_{\mathrm{uc}}&=2\Big[5\ln2+245\ln\frac{0.98}{0.99}\Big]\\ &\approx2\big[3.465736-2.487331\big]\\ &\approx1.957,\\ p_{\chi^2}&=P\big(|Z|\ge\sqrt{1.957}=1.399\big)\\ &\approx0.162,\\ \mathrm{LR}(0)&\approx5.03,\quad\mathrm{LR}(6)\approx3.56,\\ \mathrm{LR}(7)&\approx5.50,\\ p_{\text{exact}}&=P(x=0)+P(x\ge5)\\ &\approx0.0811+0.1078=0.189. \end{aligned} \]

ก้อนแรกในวงเล็บเป็นบวกเพราะพลาดบ่อยกว่าที่สัญญาสองเท่า ก้อนที่สองเป็นลบเพราะวันที่ไม่พลาดน้อยกว่าที่ควร สองก้อนหักกันเหลือ 1.957 ต่ำกว่า 3.841 จึงไม่ปฏิเสธ

LR สนใจทั้งพลาดมากและพลาดน้อยเกินไป ผลลัพธ์ที่ “สุดโต่งอย่างน้อยเท่า 5 วัน” จึงมีสองกลุ่ม: พลาดตั้งแต่ 5 วัน และไม่พลาดเลย (LR 5.03) p-value แบบนับตรงจึงเป็น 0.189 ส่วน 0.108 คือโอกาสหางด้านเดียว ซึ่งตอบอีกคำถามหนึ่ง เมื่อไล่ LR ทุกจำนวน จะได้ว่าการทดสอบที่ 5% ยอมรับเมื่อพลาด 1 ถึง 6 วัน และปฏิเสธเมื่อพลาด 0 วัน หรือตั้งแต่ 7 วัน ข้อมูล 60 เดือนในรูปแรกได้ $\mathrm{LR}=1.179$ (p-value ประมาณ 0.28) ก็ไม่ปฏิเสธเช่นกัน

ขั้นที่ 5 — ไฟสามสีในกรอบ Basel ปี 1996

ผู้กำกับดูแลไม่ได้ใช้ LR ตรง ๆ แต่ใช้ Binomial สะสมของขั้นที่ 2 แบ่งจำนวนวันพลาดใน 250 วันเป็นสามโซน แล้วเพิ่มตัวคูณของเงินกองทุนส่วนที่คิดจาก VaR (ตัวคูณขั้นต่ำ 3)

\[ \begin{aligned} P(x\le4)&\approx89.22\%,\\ P(x\le5)&\approx95.88\%,\\ P(x\le9)&\approx99.97\%,\\ P(x\le10)&\approx99.99\%,\\ 0\text{–}4&:\ \text{green},\ 3.00,\\ 5\text{–}9&:\ \text{yellow},\ 3.40\text{–}3.85,\\ 10+&:\ \text{red},\ 4.00. \end{aligned} \]

โซนเขียวจบตรงที่โอกาสสะสมยังไม่ถึง 95% โซนแดงเริ่มตรงที่โอกาสสะสมแตะ 99.99% ในโซนเหลือง ตัวคูณขึ้นทีละขั้น: 5 วัน 3.40, 6 วัน 3.50, 7 วัน 3.65, 8 วัน 3.75 และ 9 วัน 3.85 ทั้งสองแบบจำลองในโจทย์อยู่โซนเหลืองที่ 3.40

ภายใต้แบบจำลองที่ถูก โอกาสตกเหลืองหรือแดงคือ 10.78% ซึ่งตั้งใจให้สูงพอสมควร: กติกายอมลงโทษแบบจำลองที่ดีบ้าง เพื่อไม่ให้แบบจำลองที่แย่หลุดง่าย ไฟเหลืองครั้งเดียวจึงยังไม่ใช่หลักฐานว่าแบบจำลองผิด ส่วนไฟแดงเกิดกับแบบจำลองที่ถูกได้แค่ราว 0.03% ของปี

ขั้นที่ 6 — นับการเปลี่ยนสถานะ: เมื่อวานพลาด วันนี้พลาดอีกไหม

จำนวนเท่ากันไม่ได้แปลว่าเหมือนกัน ถ้าแบบจำลองตามความผันผวนไม่ทัน เช่นใช้ความผันผวนคงที่ทั้งที่ตลาดเข้าช่วงป่วน (ARCH/GARCH อธิบายว่าความผันผวนเกาะกลุ่ม) วันพลาดจะมาเป็นก้อน วิธีจับคือนับคู่ของเมื่อวานกับวันนี้ กำหนดให้สถานะก่อนวันแรกเป็น “ไม่พลาด” จะได้ 250 คู่ครบ แล้วนิยามสามสัดส่วน

\[ \begin{aligned} \hat\pi_0&=\frac{n_{01}}{n_{00}+n_{01}},\\ \hat\pi_1&=\frac{n_{11}}{n_{10}+n_{11}},\\ \hat\pi&=\frac{n_{01}+n_{11}}{T},\\ \text{clustered}&:\ n=(244,\ 1,\ 1,\ 4),\\ &\quad\ \hat\pi_0=\tfrac{1}{245},\ \hat\pi_1=\tfrac45,\\ \text{separated}&:\ n=(240,\ 5,\ 5,\ 0),\\ &\quad\ \hat\pi_0=\tfrac{5}{245},\ \hat\pi_1=0. \end{aligned} \]

$n$ เรียงเป็น $n_{00},\ n_{01},\ n_{10},\ n_{11}$ ตัวห้อยตัวแรกคือเมื่อวาน ตัวที่สองคือวันนี้ ชุดติดกันพลาดวันที่ 101 ถึง 105: เข้าสู่วันพลาดครั้งเดียว (วันที่ 100 ไป 101) พลาดต่อสี่ครั้ง แล้วออกครั้งเดียว (วันที่ 105 ไป 106) ถ้าวันพลาดไม่ขึ้นกับเมื่อวาน $\hat\pi_0$ กับ $\hat\pi_1$ ควรใกล้กันและใกล้ $\hat\pi=0.02$

ชุดติดกัน หลังวันไม่พลาดพลาดแค่ 0.41% แต่หลังวันพลาดพลาดซ้ำ 80% ชุดกระจายไม่เคยพลาดสองวันติด ($\hat\pi_1=0$) ซึ่งก็ห่างจาก 0.02 แต่มีข้อมูลหลังวันพลาดแค่ 5 คู่ ความต่างนี้อธิบายด้วยความบังเอิญได้ ขั้นถัดไปจะวัดให้เป็นตัวเลข

ขั้นที่ 7 — สถิติของ Christoffersen

ใช้ตรรกะเดียวกับ Kupiec: เทียบ likelihood ของคำอธิบายที่ให้โอกาสพลาดขึ้นกับเมื่อวาน (สองค่า $\hat\pi_0,\ \hat\pi_1$) กับคำอธิบายที่มีโอกาสเดียว $\hat\pi$ แต่ละคู่ที่ออกผล $j$ หลังสถานะ $i$ ใส่ $\ln$ ของโอกาสนั้นหนึ่งครั้ง จึงได้ผลรวมที่มีจำนวนคู่เป็นตัวคูณ

\[ \begin{aligned} \ell_1&=\textstyle\sum_{i=0}^{1}\big[n_{i0}\ln(1-\hat\pi_i)\\ &\qquad+n_{i1}\ln\hat\pi_i\big],\\ \ell_0&=(n_{00}+n_{10})\ln(1-\hat\pi)\\ &\quad+(n_{01}+n_{11})\ln\hat\pi,\\ \mathrm{LR}_{\mathrm{ind}}&=2(\ell_1-\ell_0),\\ \mathrm{LR}_{\mathrm{cc}}&=\mathrm{LR}_{\mathrm{uc}}+\mathrm{LR}_{\mathrm{ind}}. \end{aligned} \]

คำอธิบายที่มีสองค่ามีตัวที่ปรับได้มากกว่าหนึ่งตัว $\mathrm{LR}_{\mathrm{ind}}$ จึงเทียบกับ chi-square หนึ่ง degree of freedom ส่วน $\mathrm{LR}_{\mathrm{cc}}$ (conditional coverage) รวมคำถามเรื่องจำนวนกับเรื่องลำดับไว้ด้วยกัน เทียบกับ chi-square สอง degree of freedom ซึ่งมีหางเป็น $e^{-x/2}$ พอดี จุดตัด 5% ของมันคือ 5.991 เมื่อมีช่องที่เป็นศูนย์ ใช้ $0\ln0=0$ ตาม limit

ขั้นที่ 8 — แทนตัวเลขของสองชุด

โจทย์ให้อะไรมาบ้าง: ตารางการเปลี่ยนสถานะของสองชุด และ $\mathrm{LR}_{\mathrm{uc}}=1.95681$ ซึ่งเท่ากันทั้งสองชุดเพราะจำนวนเท่ากัน

\[ \begin{aligned} \ell_1^{\text{clu}}&=244\ln\tfrac{244}{245}+\ln\tfrac{1}{245}\\ &\quad+\ln\tfrac15+4\ln\tfrac45\\ &\approx-0.99796-5.50126\\ &\quad-1.60944-0.89257\\ &\approx-9.00123,\\ \ell_0&=245\ln0.98+5\ln0.02\\ &\approx-24.50978,\\ \mathrm{LR}_{\mathrm{ind}}^{\text{clu}}&\approx2(15.50855)=31.017,\\ \mathrm{LR}_{\mathrm{cc}}^{\text{clu}}&\approx1.957+31.017=32.974,\\ \ell_1^{\text{sep}}&=240\ln\tfrac{240}{245}+5\ln\tfrac{5}{245}\\ &\approx-24.40773,\\ \mathrm{LR}_{\mathrm{ind}}^{\text{sep}}&\approx2(0.10205)=0.204,\\ \mathrm{LR}_{\mathrm{cc}}^{\text{sep}}&\approx1.957+0.204=2.161. \end{aligned} \]

คำตอบ: ชุดติดกันได้ $\mathrm{LR}_{\mathrm{ind}}=31.02$ สูงกว่าจุดตัด 3.841 มาก และ $\mathrm{LR}_{\mathrm{cc}}=32.97$ ให้ p-value ประมาณ $e^{-16.49}\approx6.9\times10^{-8}$ จึงปฏิเสธ ส่วนชุดกระจายได้ 0.204 และ 2.161 ต่ำกว่าจุดตัดร่วม 5.991 (p-value ประมาณ 0.34) จึงไม่ปฏิเสธ จำนวนวันพลาดเท่ากัน แต่ลำดับวันให้หลักฐานต่างกันสุดขั้ว ข้อมูล 60 เดือนในรูปแรกมีเดือน 42 กับ 43 ติดกันหนึ่งคู่ ได้ $n=(51,\ 4,\ 4,\ 1)$ และ $\mathrm{LR}_{\mathrm{ind}}\approx0.75$ ไม่ปฏิเสธ

เซลล์ที่มีจำนวนน้อยทำให้ p-value จาก chi-square ต้องใช้อย่างระวัง แต่ 31 ไกลจาก 3.841 มากจนข้อสรุปไม่เปลี่ยน ตัวอย่างจริงของการพลาดเกาะกลุ่มคือเดือนสิงหาคม 2007 ที่ผู้จัดการกองทุนเชิงปริมาณบางรายบอกว่าเจอการขยับ 25 เท่าของ standard deviation หลายวันติดกัน ภายใต้ Normal โอกาสของวันเดียวแบบนั้นมีราว $3\times10^{-138}$ การเห็นหลายวันติดจึงบอกว่าความผันผวนในแบบจำลองต่ำกว่าความผันผวนของช่วงนั้นมาก ไม่ใช่ว่าโลกโชคร้ายเป็นพิเศษ

ตรวจเองใน 10 วินาที: $244+1+1+4=250$ และ $240+5+5+0=250$ คู่ครบ และ $\ell_0$ เหมือนกันทั้งสองชุดเพราะใช้แค่จำนวนรวม

ขั้นที่ 9 — การทดสอบจับแบบจำลองที่แย่ได้บ่อยแค่ไหน

“ไม่ปฏิเสธ” ฟังเหมือนผ่าน ลองถามกลับ: ถ้าความจริงคือพลาด 2% ของวัน (แบบจำลองประเมินความถี่ของวันร้ายต่ำไปครึ่งหนึ่ง) การทดสอบจะปฏิเสธบ่อยแค่ไหนใน 250 วัน ใช้ช่วงยอมรับของขั้นที่ 4 คือปฏิเสธเมื่อพลาด 0 วัน หรือตั้งแต่ 7 วัน แล้วคิดโอกาสของช่วงนี้ภายใต้ Binomial ที่โอกาสพลาดจริง $q$

\[ \begin{aligned} \text{reject}&=P(x=0)+P(x\ge7),\\ q=0.01&:\ 9.48\%,\\ q=0.02&:\ 24.27\%,\\ q=0.03&:\ 62.55\%,\\ q=0.02,\ x\ge10&:\ 3.04\%,\\ q=0.02,\ x\ge5&:\ 56.13\%. \end{aligned} \]

บรรทัดที่สองคือขนาดจริงของการทดสอบ: แบบจำลองที่ถูกถูกปฏิเสธ 9.48% ไม่ใช่ 5% ที่ตั้งใจ เพราะจำนวนเป็นเลขเต็มและ chi-square ประมาณไม่ดีเมื่อคาดไว้แค่ 2.5 วัน

บรรทัดที่สามคือคำตอบที่น่ากลัว: แบบจำลองที่พลาดจริง 2% แต่รายงาน 1% ถูกจับได้แค่ 24% ของปี อีก 76% ผ่าน ไฟแดงจับได้แค่ 3% ไฟเหลืองหรือแดงจับได้ 56% ข้อมูลปีเดียวมีวันพลาดที่คาดไว้น้อยเกินจะแยกแบบจำลองที่ดีจากที่แย่ได้ชัด “ไม่ปฏิเสธ” จึงแปลว่า “ยังไม่มีหลักฐานพอว่าแย่” ไม่ได้แปลว่าดี

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

แก้ VaR หลังเห็นขาดทุน: ถ้าคำนวณ VaR ของวันนั้นใหม่โดยรวมข้อมูลของวันนั้นเข้าไปแล้ว ไม่ใช่การพยากรณ์ล่วงหน้า และมักทำให้ผลดูดีกว่าที่ใช้งานจริง VaR ต้องล็อกไว้ก่อนเห็นผล

เทียบ p-value คนละคำถาม: LR สองด้านให้ประมาณ 0.162 จาก chi-square และ 0.189 จากการนับ Binomial ตรง ส่วน 0.108 คือโอกาสหางด้านเดียว ไม่ใช่ค่าแม่นตรงของการทดสอบสองด้าน

สรุปจากศูนย์วันพลาด: $\mathrm{LR}_{\mathrm{uc}}(0)=5.03$ เกินจุดตัด แต่ p-value แบบนับตรงคือ $P(x=0)+P(x\ge7)\approx0.0948$ ไม่ปฏิเสธที่ 5% ปีที่ไม่พลาดเลยจึงไม่ได้พิสูจน์ว่าแบบจำลองระวังเกิน แบบจำลองที่ถูกเป๊ะก็ไม่พลาดเลยได้ 8.1% ของปี

หาร $\hat\pi_1$ เมื่อไม่มีวันหลังพลาด: ถ้าไม่มีวันพลาดเลย $n_{10}+n_{11}=0$ ประมาณ $\hat\pi_1$ ไม่ได้ อย่าหารศูนย์แล้วรายงาน p-value สวย ๆ โค้ดข้างล่างโยน error แทน

ดูแค่ 0 กับ 1: การนับไม่เห็นว่าวันพลาดเสียลึกแค่ไหน ตำแหน่งที่ขาดทุนบ่อยครั้งละนิดแต่นาน ๆ ทีเสียหนัก (ที่เรียกว่า tail stuffing) ผ่านการนับได้สบาย ต้องดูขนาดของขาดทุนในหางด้วย Expected Shortfall และดูผลตอบแทนที่หารด้วยความผันผวนที่พยากรณ์ไว้ทั้งชุด ข้อมูล 60 เดือนในรูปแรกให้ค่าเฉลี่ยของกำลังสองของตัวเลขนี้ 0.81 แปลว่าความผันผวนจริงต่ำกว่าที่แบบจำลองบอก แม้จำนวนวันพลาดจะมากกว่าที่คาด

ลืมว่ามีหลายโต๊ะ: ธนาคารที่ตรวจ 20 โต๊ะซึ่งแบบจำลองถูกทั้งหมด จะมีอย่างน้อยหนึ่งโต๊ะตกเหลืองด้วยโอกาส $1-0.8922^{20}\approx89.8\%$ โต๊ะที่ตกเหลืองคนเดียวในยี่สิบโต๊ะจึงไม่ใช่หลักฐานพิเศษ เรื่องเดียวกับการทดสอบหลายครั้ง

ใช้ทำอะไรบนโต๊ะจริง

ธนาคารเก็บ VaR ที่ประกาศไว้ทุกวันคู่กับ P&L สองแบบ: P&L สมมติที่ถือพอร์ตเมื่อเช้าไว้ทั้งวัน และ P&L จริงที่รวมการเทรดระหว่างวันและค่าธรรมเนียม VaR คิดจากพอร์ตเมื่อเช้า การเทียบกับ P&L สมมติจึงทดสอบแบบจำลองตรง ๆ ถ้าสองแบบให้ผลต่างกันมาก ให้ตรวจผลของการเทรดระหว่างวันและการตีราคาก่อนโทษแบบจำลอง ไฟสามสีกำหนดเงินกองทุนในกรอบกำกับดูแล ส่วนการทดสอบการเกาะกลุ่มใช้ภายในเพื่อถามว่าการพยากรณ์ความผันผวนตามตลาดทันไหม กรอบที่ใหม่กว่าคิดเงินกองทุนจาก Expected Shortfall แต่ยังใช้การนับวันพลาดของ VaR ตรวจแต่ละโต๊ะ เพราะการนับเข้าใจง่ายและตรวจได้เร็ว

const xlogy = (x, y) => (x === 0 ? 0 : x * Math.log(y));        // 0 ln 0 = 0 by the limit
// Complementary error function: series for small x, continued fraction for large x.
function erfc(x) {
  const t = Math.abs(x); let e;
  if (t < 2.5) { let s = 0, term = t; for (let k = 0; k < 300; k++) { const add = term / (2 * k + 1); s += add; if (Math.abs(add) < 1e-18 * Math.abs(s)) break; term *= -t * t / (k + 1); } e = 1 - 2 / Math.sqrt(Math.PI) * s; }
  else { let f = t; for (let k = 150; k >= 1; k--) f = t + (k / 2) / f; e = Math.exp(-t * t) / Math.sqrt(Math.PI) / f; }
  return x >= 0 ? e : 2 - e;
}
const chi2sf1 = x => erfc(Math.sqrt(x / 2));     // P(chi2 with 1 df >= x) = P(|Z| >= sqrt x)
const chi2sf2 = x => Math.exp(-x / 2);           // chi2 with 2 df has tail e^(-x/2)
function binomial(T, p) {
  const pmf = [(1 - p) ** T];
  for (let k = 1; k <= T; k++) pmf.push(pmf[k - 1] * (T - k + 1) / k * p / (1 - p));
  return pmf;
}
function kupiec(x, T, p) {
  const ph = x / T;
  return 2 * (xlogy(x, ph) + xlogy(T - x, 1 - ph) - xlogy(x, p) - xlogy(T - x, 1 - p));
}
// Transition counts n00, n01, n10, n11 of breach days (1..T); the day before day 1 counts as "no breach".
function transitions(T, days) {
  const s = new Array(T + 1).fill(0); days.forEach(d => (s[d] = 1));
  const n = [0, 0, 0, 0];
  for (let t = 1; t <= T; t++) n[2 * s[t - 1] + s[t]]++;
  return n;
}
function christoffersen([n00, n01, n10, n11]) {
  if (n10 + n11 === 0) throw new RangeError('no day after a breach: pi1 cannot be estimated');
  const p0 = n01 / (n00 + n01), p1 = n11 / (n10 + n11), p = (n01 + n11) / (n00 + n01 + n10 + n11);
  const l1 = xlogy(n00, 1 - p0) + xlogy(n01, p0) + xlogy(n10, 1 - p1) + xlogy(n11, p1);
  const l0 = xlogy(n00 + n10, 1 - p) + xlogy(n01 + n11, p);
  return 2 * (l1 - l0);
}

const T = 250, p = 0.01, cut = 3.841458820694124, pmf = binomial(T, p);
const uc = kupiec(5, T, p);
const accept = pmf.map((_, x) => kupiec(x, T, p) <= cut);            // true for x = 1..6
const reject = q => binomial(T, q).reduce((a, v, x) => a + (accept[x] ? 0 : v), 0);
const tail = (q, k) => binomial(T, q).reduce((a, v, x) => a + (x >= k ? v : 0), 0);

สิ่งที่ควรตอบได้หลังอ่าน

  • ถ้าแบบจำลองถูกและวันอิสระกัน จำนวนวันพลาดของ VaR 99% ใน 250 วันเป็น Binomial: คาด 2.5 วัน ไม่พลาดเลยได้ 8.1% และพลาดตั้งแต่ 5 วันได้ 10.78%
  • Kupiec เทียบ likelihood ของ $p$ กับ $\hat p$: ห้าวันให้ LR 1.957 (p-value 0.162 จาก chi-square หรือ 0.189 แบบนับตรง) และการทดสอบที่ 5% ยอมรับเมื่อพลาด 1 ถึง 6 วัน
  • ไฟสามสีของ Basel มาจาก Binomial สะสม: 0–4 เขียว 5–9 เหลือง ตั้งแต่ 10 แดง ห้าวันได้ตัวคูณ 3.40 แทน 3
  • Christoffersen นับการเปลี่ยนสถานะ: ห้าวันติดกันให้ 31.02 ห้าวันกระจายให้ 0.204 จำนวนเท่ากัน หลักฐานต่างกันสุดขั้ว
  • การทดสอบปีเดียวมีพลังต่ำ: แบบจำลองที่พลาดจริง 2% ถูกจับได้แค่ 24% ของปี ไม่ปฏิเสธจึงไม่ได้แปลว่าดี

ปัญหาของ VaR มักเริ่มที่ตัวเลขที่ป้อนเข้า โดยเฉพาะ covariance ที่ประมาณจากข้อมูลไม่พอ หน้าถัดไป Ledoit–Wolf shrinkage ดูว่า covariance จากข้อมูลมีเสียงรบกวนแค่ไหน inverse ของมันขยายเสียงนั้นเป็นน้ำหนักพอร์ตอย่างไร และการผสมกับ matrix ที่เรียบง่ายช่วยได้เท่าไร
