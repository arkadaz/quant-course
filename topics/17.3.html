17.3 Markowitz Portfolio Theory

ความเสี่ยงของพอร์ตมาจาก covariance ของทุกคู่ ไม่ใช่ค่าเฉลี่ยของความเสี่ยงรายตัว Markowitz จึงหาส่วนผสมที่ให้ผลตอบแทนคาดหวังสูงสุดต่อความผันผวนแต่ละระดับได้ด้วยพีชคณิต matrix

มีเงิน \$10 ล้าน แบ่งระหว่างหุ้น (คาดหวัง 9% ต่อปี ความผันผวน 20%) กับพันธบัตร (3.5% และ 6%) correlation 0.15 เงินสดได้ 2% คนแรกบอกว่าอยากเสี่ยงน้อยที่สุดก็ถือพันธบัตรล้วน เสี่ยง 6% คนที่สองบอกว่าหุ้นมี Sharpe ratio 0.35 (ส่วนเกินเงินสด 7% หารด้วยความผันผวน 20%) ดีกว่าพันธบัตรที่ 0.25 (1.5% หารด้วย 6%) อยากได้ Sharpe สูงสุดก็ถือหุ้นล้วน ใครถูก

ลองตอบก่อนเปิดเฉลย

ผิดทั้งคู่ ใส่หุ้น 4.5% (\$450,000) ความผันผวนลดเหลือ 5.93% ต่ำกว่าพันธบัตรล้วน ทั้งที่หุ้นแกว่งกว่าสามเท่า และพอร์ตหุ้น 32.19% (\$3,218,884) พันธบัตร 67.81% ได้ Sharpe 0.4030 สูงกว่าหุ้นล้วน 15.1% เพราะสองตัวนี้ขึ้นลงไม่พร้อมกัน

ภาพรวมก่อนลงสูตร

Markowitz เสนอในปี 1952 ว่าให้วัดพอร์ตด้วยสองตัวเลข คือผลตอบแทนคาดหวังแทน “ผลตอบแทน” และความผันผวนแทน “ความเสี่ยง” ผลตอบแทนคาดหวังของพอร์ตเป็นค่าเฉลี่ยถ่วงน้ำหนักธรรมดา แต่ความผันผวนไม่ใช่ เพราะ variance ของพอร์ตมีพจน์ไขว้ของ covariance ทุกคู่ (ดู ความเสี่ยงของพอร์ตจาก covariance matrix) สองสินทรัพย์ที่ขึ้นลงไม่พร้อมกันจึงหักล้างกันได้

ถ้าลองทุกส่วนผสม แล้ววาดแต่ละพอร์ตเป็นจุดบนระนาบความผันผวนกับผลตอบแทนคาดหวัง ขอบซ้ายบนของกลุ่มจุดคือ efficient frontier พอร์ตใดอยู่ใต้ขอบนี้ก็แพ้พอร์ตบนขอบที่ความผันผวนเท่ากัน เมื่อมีเงินสด ทางเลือกที่ดีที่สุดคือเส้นตรงจากเงินสดที่แตะขอบพอดี จุดที่แตะคือพอร์ต tangency ซึ่ง Sharpe ratio สูงสุด

หน้านี้ประกอบ covariance แล้วลองด้วยมือกับสองสินทรัพย์ ดูว่าการกระจายมีพื้นตรงไหน เขียนเป็น matrix ให้ใช้ได้ทุกขนาด หาพอร์ต tangency ของ \$10 ล้าน แล้วถามคำถามที่สำคัญที่สุด คือคำตอบไวต่อค่าเฉลี่ยที่ประมาณมาแค่ไหน ก่อนจบที่ข้อมูลจริงแปดกลุ่มสินทรัพย์ ซึ่งให้คำตอบที่ถูกทางคณิตแต่เทรดไม่ได้

ศัพท์ที่ใช้ในหัวข้อนี้
Mean-variance
กรอบเลือกพอร์ตที่ดูแค่สองตัวเลข คือผลตอบแทนคาดหวังกับ variance ของพอร์ต ใช้เพราะทั้งสองคิดได้จาก $\mu$ และ $\Sigma$ ด้วยพีชคณิต matrix ล้วน และพอดีกับผลตอบแทนที่เป็น Normal
Minimum-variance portfolio
พอร์ตที่น้ำหนักรวมเป็นหนึ่งและ variance ต่ำที่สุด ใช้แค่ $\Sigma$ ไม่ต้องรู้ค่าเฉลี่ยเลย จึงเป็นพอร์ตที่ประมาณได้นิ่งที่สุด
Efficient frontier
ชุดพอร์ตที่ให้ผลตอบแทนคาดหวังสูงสุดที่แต่ละระดับความผันผวน พอร์ตที่อยู่ใต้เส้นแพ้พอร์ตบนเส้นเสมอ
Tangency portfolio
ส่วนผสมของสินทรัพย์เสี่ยงที่ Sharpe ratio สูงสุด เป็นจุดที่เส้นจากเงินสดแตะ frontier พอดี เส้นนั้นเรียกว่า capital market line
One-fund theorem
เมื่อทุกคนใช้ค่าเฉลี่ยและ covariance ชุดเดียวกัน ไม่มีข้อจำกัดน้ำหนัก และกู้หรือฝากได้ที่อัตราเดียวกัน ผู้ลงทุนต่างความกลัวความเสี่ยงจะถือส่วนผสมเสี่ยงเดียวกัน แล้วปรับแค่สัดส่วนกับเงินสด
Sharpe ratio
ผลตอบแทนส่วนเกินเงินสดหารด้วยความผันผวน ใช้เทียบความคุ้มของความเสี่ยงหนึ่งหน่วย

ขั้นที่ 1 — ประกอบ covariance แล้วลองพอร์ตครึ่งต่อครึ่ง

โจทย์ให้ความผันผวนรายตัวกับ correlation มา แต่สูตรทุกสูตรต่อจากนี้ใช้ covariance matrix จึงต้องประกอบก่อน แล้วลองพอร์ตที่ง่ายที่สุด 50/50 กับ correlation สามค่า เพื่อดูว่า variance ของพอร์ตมาจากไหน

\[ \begin{aligned} \sigma_{EB}&=\rho\,\sigma_E\sigma_B\\ &=0.15(0.20)(0.06)=0.0018,\\ \Sigma&=\begin{bmatrix}0.04&0.0018\\0.0018&0.0036\end{bmatrix},\\ \sigma_p^2&=w_E^2\sigma_E^2+w_B^2\sigma_B^2\\ &\quad+2w_Ew_B\,\rho\,\sigma_E\sigma_B,\\ w_E=w_B=\tfrac12&:\ \sigma_p^2=0.0109+0.0060\rho,\\ \rho=0.15&:\ \sqrt{0.0118}=10.86\%,\\ \rho=1&:\ \sqrt{0.0169}=13.00\%,\\ \rho=-1&:\ \sqrt{0.0049}=7.00\%. \end{aligned} \]

ช่องนอกแนวทแยงคือ correlation คูณความผันผวนทั้งสอง ไม่ใช่ correlation เฉย ๆ ส่วน $\sigma_p^2$ คือ $w^{\mathsf T}\Sigma w$ ที่กางออก พจน์ไขว้ $2w_Ew_B\rho\sigma_E\sigma_B$ เป็นตัวเดียวที่ correlation มีส่วน ที่ 50/50 สองก้อนแรกคือ $0.25(0.04)=0.0100$ กับ $0.25(0.0036)=0.0009$ และพจน์ไขว้คือ $0.006\rho$

ถ้า $\rho=1$ พอร์ตเสี่ยง 13% เท่าค่าเฉลี่ยของความผันผวนรายตัวพอดี ทุกค่า $\rho$ ที่ต่ำกว่า 1 ได้ต่ำกว่านั้น กรณี $\rho=0.15$ ของโจทย์ได้ 10.86% ลดลง 2.14 จุดโดยไม่ได้เปลี่ยนสินทรัพย์ตัวไหนเลย นี่คือของฟรีของการกระจาย

ขั้นที่ 2 — สินทรัพย์หลายตัว: การกระจายมีพื้น

ของฟรีนี้ได้มากแค่ไหน ลองกรณีสมมาตร มีสินทรัพย์ $d$ ตัว ทุกตัวความผันผวน $\sigma$ ทุกคู่ correlation $\rho$ ถือเท่ากันตัวละ $1/d$ แล้วนับพจน์ใน $w^{\mathsf T}\Sigma w$ ว่ามีแนวทแยงกี่ตัว นอกแนวทแยงกี่ตัว

\[ \begin{aligned} \sigma_p^2&=\sum_i\sum_j\frac1d\cdot\frac1d\,\sigma_{ij},\\ &=d\cdot\frac{\sigma^2}{d^2}+d(d-1)\cdot\frac{\rho\sigma^2}{d^2}\\ &=\sigma^2\Big(\rho+\frac{1-\rho}{d}\Big),\\ \rho=0,\ d=10&:\ \frac{20\%}{\sqrt{10}}=6.32\%,\\ \rho=0.3,\ d=10&:\ 20\%\sqrt{0.37}=12.17\%,\\ d\to\infty&:\ \sigma\sqrt\rho=20\%\sqrt{0.3}\\ &=10.95\%. \end{aligned} \]

matrix ขนาด $d\times d$ มีแนวทแยง $d$ ช่อง แต่ละช่องคูณน้ำหนัก $1/d$ สองครั้ง จึงรวมได้ $\sigma^2/d$ ซึ่งหายไปเมื่อ $d$ โต ส่วนนอกแนวทแยงมี $d(d-1)$ ช่อง เกือบ $d^2$ ช่อง จึงไม่หายไป เหลือ $\rho\sigma^2$ เป็นพื้น

ถ้าทุกตัวอิสระกัน ($\rho=0$) ความผันผวนลดตาม $1/\sqrt d$ ไปจนเกือบศูนย์ แต่หุ้นจริงมี correlation กันราว 0.3 เพราะทุกตัวขยับตามตลาดร่วมกัน ถือกี่ร้อยตัวก็ลงไม่ต่ำกว่า 10.95% ส่วนที่กระจายทิ้งได้คือความเสี่ยงเฉพาะตัว ส่วนที่เหลือคือความเสี่ยงของตลาด ซึ่ง CAPM บอกว่าเป็นส่วนเดียวที่ตลาดจ่ายผลตอบแทนให้

ขั้นที่ 3 — พอร์ตเสี่ยงต่ำสุดด้วยมือ

กลับมาที่หุ้นกับพันธบัตร ถ้าน้ำหนักรวมต้องเป็นหนึ่ง $w_B=1-w_E$ variance เป็นพาราโบลาของตัวแปรเดียว หาจุดต่ำสุดด้วย derivative ได้เลย กางวงเล็บทุกก้อนก่อน จะเห็นว่าแต่ละสัมประสิทธิ์มาจากไหน

\[ \begin{aligned} \sigma_p^2&=0.04w_E^2+0.0036(1-w_E)^2\\ &\quad+2(0.0018)w_E(1-w_E)\\ &=0.04w_E^2-0.0036w_E+0.0036,\\ \frac{d\sigma_p^2}{dw_E}&=0.08w_E-0.0036=0,\\ w_E&=\frac{0.0036}{0.08}=0.045,\\ \sigma_p^2&=0.000081-0.000162+0.0036\\ &=0.003519,\\ \sigma_p&\approx5.93\%. \end{aligned} \]

ก้อน $w_E^2$ รวมได้ $0.04+0.0036-0.0036=0.04$ ก้อน $w_E$ รวมได้ $-0.0072+0.0036=-0.0036$ สัมประสิทธิ์หน้า $w_E^2$ เป็นบวก จุดที่ความชันศูนย์จึงเป็นจุดต่ำสุด หุ้น 4.5% พันธบัตร 95.5% ผลตอบแทนคาดหวัง $0.045(9\%)+0.955(3.5\%)=3.75\%$

ความผันผวน 5.93% ต่ำกว่าพันธบัตรล้วน 6% ทั้งที่ใส่หุ้นที่แกว่ง 20% เข้าไป ความชันที่ $w_E=0$ คือ $-0.0036$ ติดลบ แปลว่าหุ้นก้อนแรกลด variance เพราะวันที่พันธบัตรลง หุ้นไม่ได้ลงตามเสมอ

ขั้นที่ 4 — correlation สูงไม่ได้แปลว่ากระจายไม่ได้

ทำการหาจุดต่ำสุดซ้ำด้วยสัญลักษณ์ เพื่อดูว่าน้ำหนักของพอร์ตเสี่ยงต่ำสุดขึ้นกับ $\rho$ อย่างไร แล้วลองสามค่า สัญชาตญาณบอกว่า correlation ยิ่งสูง การกระจายยิ่งช่วยน้อย ขั้นนี้แสดงว่าจริงแค่ครึ่งเดียว

\[ \begin{aligned} \tfrac12\frac{d\sigma_p^2}{dw_E}&=\sigma_E^2w_E-\sigma_B^2(1-w_E)\\ &\quad+\rho\sigma_E\sigma_B(1-2w_E)=0,\\ w_E&=\frac{\sigma_B^2-\rho\sigma_E\sigma_B}{\sigma_E^2+\sigma_B^2-2\rho\sigma_E\sigma_B},\\ \rho=-0.5&:\ \frac{0.0036+0.0060}{0.0556}\approx17.27\%,\\ \rho=0.3&:\ \frac{0.0036-0.0036}{0.0364}=0,\\ \rho=0.8&:\ \frac{0.0036-0.0096}{0.0244}\approx-24.59\%. \end{aligned} \]

แทนน้ำหนักกลับเข้าไปใน $\sigma_p^2$ ได้ความผันผวนต่ำสุด 4.41% ที่ $\rho=-0.5$ และ 6.00% ที่ $\rho=0.3$ ซึ่งคือพันธบัตรล้วน เพราะที่ $\rho=\sigma_B/\sigma_E=0.3$ หุ้นก้อนแรกไม่ช่วยและไม่ทำร้าย

ที่ $\rho=0.8$ คำตอบคือ short หุ้น 24.59% แล้วถือพันธบัตร 124.59% ความผันผวนลงไปเหลือ 4.61% ต่ำกว่าที่ $\rho=0.15$ เสียอีก เมื่อสองตัวขึ้นลงพร้อมกันมาก หุ้นกลายเป็นเครื่องมือ hedge ของพันธบัตร ความเสี่ยงต่ำสุดจึงสูงที่สุดตรงกลาง ($\rho=0.3$) ไม่ใช่ที่ correlation สูง แต่ถ้าห้าม short (ต้องแก้ด้วย KKT conditions) คำตอบที่ $\rho=0.8$ คือพันธบัตรล้วน 6%

ขั้นที่ 5 — เขียนเป็น matrix: พอร์ตเสี่ยงต่ำสุดกับพอร์ต tangency

เมื่อมีหลายสินทรัพย์ ต้องเขียนเป็น matrix เพื่อใช้วิธีเดียวกันได้ทุกขนาด โจทย์ mean-variance ตั้งได้สามแบบที่ให้ชุดคำตอบเดียวกัน คือ variance ต่ำสุดโดยผลตอบแทนถึงเป้า ผลตอบแทนสูงสุดโดยความผันผวนไม่เกินงบ และผลตอบแทนหักค่าปรับความเสี่ยง ขั้นนี้ใช้แบบแรกหาพอร์ตเสี่ยงต่ำสุด และแบบที่สามเมื่อมีเงินสด ตัวอย่างนี้ $\Sigma$ เป็นบวกแน่นอน จึงกลับได้ด้วยสูตร 2×2

\[ \begin{aligned} \det\Sigma&=0.04(0.0036)-0.0018^2\\ &=0.00014076,\\ \Sigma^{-1}&=\begin{bmatrix}25.5754&-12.7877\\-12.7877&284.1716\end{bmatrix},\\ \Sigma w&=\lambda\mathbf1,\quad \mathbf1^{\mathsf T}w=1,\\ w_{\text{mv}}&=\frac{\Sigma^{-1}\mathbf1}{A},\quad A=\mathbf1^{\mathsf T}\Sigma^{-1}\mathbf1,\\ A&\approx284.1716,\\ w_{\text{mv}}&\approx\frac{(12.7877,\ 271.3839)}{284.1716}\\ &\approx(0.045,\ 0.955),\\ U(w)&=r_f+w^{\mathsf T}(\mu-r_f\mathbf1)-\tfrac\gamma2w^{\mathsf T}\Sigma w,\\ \nabla U&=(\mu-r_f\mathbf1)-\gamma\Sigma w=0,\\ w^*&=\frac1\gamma\,\Sigma^{-1}(\mu-r_f\mathbf1),\\ w_{\text{tan}}&=\frac{\Sigma^{-1}(\mu-r_f\mathbf1)}{\mathbf1^{\mathsf T}\Sigma^{-1}(\mu-r_f\mathbf1)}. \end{aligned} \]

$\Sigma^{-1}$ ได้จากสลับช่องแนวทแยง กลับเครื่องหมายช่องนอกแนวทแยง แล้วหารด้วย $\det\Sigma$ บรรทัด $\Sigma w=\lambda\mathbf1$ มาจาก Lagrange multipliers ของ variance กับข้อบังคับเดียว ความชันของ variance ต้องชี้ทิศเดียวกับความชันของข้อบังคับ แก้ได้ $w=\lambda\Sigma^{-1}\mathbf1$ แล้วใช้ $\mathbf1^{\mathsf T}w=1$ หา $\lambda=1/A$ variance ที่จุดนั้นคือ $1/A=0.003519$ ตรงกับการหาด้วยมือข้างบน ถ้าเพิ่มข้อบังคับผลตอบแทนถึงเป้า $\mu^{\mathsf T}w=m$ ก็ได้ระบบสมการเชิงเส้น $d+2$ ตัวแปร (น้ำหนัก $d$ ตัวกับตัวคูณสองตัว) แก้ได้ทีเดียว ผลคือ frontier $\sigma^2=(Am^2-2Bm+C)/D$ ของ Markowitz portfolio selection

เมื่อมีเงินสด น้ำหนักเงินสดคือ $1-\mathbf1^{\mathsf T}w$ และไม่มีความเสี่ยง จึงหายไปจาก variance ตั้ง gradient ของ $U$ เป็นศูนย์ได้ $w^*$ ซึ่งมี $\gamma$ อยู่ข้างหน้าเท่านั้น หาร $w^*$ ด้วยผลรวมของมันเอง $1/\gamma$ อยู่ทั้งเศษและส่วนจึงตัดกัน ส่วนผสมเสี่ยงจึงไม่ขึ้นกับว่าใครกลัวความเสี่ยงแค่ไหน นี่คือ one-fund theorem ทิศ $\Sigma^{-1}(\mu-r_f\mathbf1)$ คือทิศเดียวกับขนาด Kelly แบบหลายสินทรัพย์ Kelly คือกรณี $\gamma=1$ พอดี

อีกผลหนึ่งที่ตามมา คือน้ำหนักบน frontier เป็นเส้นตรงใน $m$ พอร์ตบนเส้นทุกพอร์ตจึงเป็นส่วนผสมของสองพอร์ตบนเส้นใดก็ได้ (two-fund theorem) กองทุนสองกองก็พอสร้างทุกพอร์ตที่มีประสิทธิภาพ

ขั้นที่ 6 — พอร์ต tangency ของ \$10 ล้าน และค่าของการกระจาย

โจทย์ให้อะไรมาบ้าง: $\Sigma^{-1}$ จากขั้นที่แล้ว และผลตอบแทนส่วนเกินเงินสด $9\%-2\%=7\%$ ของหุ้น กับ $3.5\%-2\%=1.5\%$ ของพันธบัตร แทนลงในสูตร tangency คือคูณ $\Sigma^{-1}$ แล้วหารด้วยผลรวม

\[ \begin{aligned} u_1&\approx25.5754(0.070)-12.7877(0.015)\\ &\approx1.5985,\\ u_2&\approx-12.7877(0.070)+284.1716(0.015)\\ &\approx3.3674,\\ w_{\text{tan}}&\approx\frac{(1.5985,\ 3.3674)}{4.9659}\\ &\approx(0.3219,\ 0.6781),\\ \mu_{\text{tan}}&\approx0.035+0.055(0.3219)\\ &\approx5.27\%,\\ \sigma^2_{\text{tan}}&\approx0.0041445+0.0016554\\ &\quad+0.0007858=0.0065857,\\ \sigma_{\text{tan}}&\approx8.12\%,\\ \mathrm{SR}&=\frac{0.052704-0.02}{0.081152}=0.4030,\\ \mathrm{SR}^2&=u^{\mathsf T}(\mu-r_f\mathbf1)\\ &=1.5985(0.07)+3.3674(0.015)\\ &=0.16240,\\ \frac{0.20}{0.081152}&\approx2.4645. \end{aligned} \]

คำตอบ: ทั้ง $u_1$ และ $u_2$ เป็นบวก จึงไม่ต้อง short หุ้นได้ 32.19% คือ \$3,218,884 พันธบัตร 67.81% คือ \$6,781,116 ผลตอบแทนคาดหวัง 5.27% ความผันผวน 8.12% Sharpe 0.4030 สูงกว่าหุ้นล้วน (0.35) 15.1% สามก้อนของ variance คือหุ้น พันธบัตร และพจน์ไขว้

บรรทัด $\mathrm{SR}^2$ เป็นทางตรวจที่ไม่ต้องหาน้ำหนัก ตัวหาร $\mathbf1^{\mathsf T}u$ ตัดกันระหว่างเศษและส่วนของ Sharpe และ $u^{\mathsf T}\Sigma u=u^{\mathsf T}(\mu-r_f\mathbf1)$ เพราะ $\Sigma u$ คือส่วนเกินพอดี รากที่สองของ 0.16240 คือ 0.4030 ตรงกัน

บรรทัดสุดท้ายคือถือพอร์ต tangency 2.46 เท่าด้วยเงินกู้ที่ 2% ให้ความผันผวนเท่าหุ้นล้วน 20% ได้ผลตอบแทนคาดหวัง $0.02+0.4030(0.20)=10.06\%$ แทน 9% โดยสมมติว่ากู้ได้ที่ดอกเบี้ยเดียวกับเงินฝาก พันธบัตรได้น้ำหนักมากทั้งที่ Sharpe ต่ำกว่าหุ้น เพราะมันแกว่งน้อย และ correlation ต่ำทำให้มันหักความผันผวนของหุ้นได้มากกว่าผลตอบแทนที่เสียไป

ตรวจเองใน 10 วินาที: $1.5985+3.3674=4.9659$ และ $1.5985/4.9659=0.3219$ ส่วน $(5.27-2)/8.12=0.403$

ขั้นที่ 7 — ค่าเฉลี่ยผิดนิดเดียว น้ำหนักขยับเท่าไร

ทุกอย่างข้างบนสมมติว่ารู้ $\mu$ และ $\Sigma$ จริง แต่ค่าเฉลี่ย 9% ของหุ้นเป็นค่าประมาณ ความผันผวน 20% กับข้อมูล 25 ปีให้ standard error ของค่าเฉลี่ยราว $20\%/\sqrt{25}=4\%$ ลองสองการทดลอง ครั้งแรกเปลี่ยนค่าเฉลี่ยหุ้นโดยตรึงทุกอย่างไว้ ครั้งที่สองให้สองสินทรัพย์ที่เหมือนกันทุกประการ ค่าเฉลี่ยจริง 6% ความผันผวน 20% correlation ศูนย์ แต่ค่าประมาณคลาดไปข้างละ 2% เป็น 8% กับ 4%

\[ \begin{aligned} w_E(m)&=\frac{u_1}{u_1+u_2},\quad u=\Sigma^{-1}\begin{bmatrix}m-0.02\\0.015\end{bmatrix},\\ m=8\%&:\ 27.75\%,\quad m=10\%:\ 36.40\%,\\ \frac{36.40-27.75}{10-8}&=4.325,\\ w_{\text{est}}&\propto\Sigma^{-1}\begin{bmatrix}0.06\\0.02\end{bmatrix}\propto\begin{bmatrix}0.75\\0.25\end{bmatrix},\\ \mathrm{SR}_{\text{est}}&=\frac{\sqrt{0.06^2+0.02^2}}{0.2}=0.3162,\\ \mathrm{SR}_{\text{true}}&=\frac{0.04}{0.2/\sqrt2}=0.2828,\\ \sigma(w_{\text{est}})&=0.2\sqrt{0.75^2+0.25^2}=15.81\%,\\ \mathrm{SR}_{\text{real}}&=\frac{0.04}{0.1581}=0.2530. \end{aligned} \]

การทดลองแรก ค่าเฉลี่ยของหุ้นคลาด 1 จุด น้ำหนักหุ้นขยับราว 4.3 จุด คือเงินราว \$430,000 จาก \$10 ล้าน ย้ายข้างเพราะความคลาดของตัวเลขตัวเดียว

การทดลองที่สองแสดงว่าทำไมมันแย่กว่าแค่ไหว คำตอบจริงคือ 50/50 แต่ optimizer เห็นตัวแรกดีกว่า จึงถือ 75/25 ซึ่งเป็นทิศที่ผิดพอดี ความคลาดเฉลี่ยของสองค่าเป็นศูนย์ ตัวประมาณ “ดีโดยเฉลี่ย” แต่ optimizer ไม่ได้ใช้ค่าเฉลี่ย มันเลือกตัวที่ดูดีที่สุด ซึ่งคือตัวที่ถูกประมาณสูงเกิน ผลคือสามตัวเลข Sharpe ที่เชื่อไว้ 0.3162 สูงกว่าที่ดีที่สุดที่เป็นไปได้ 0.2828 และที่ได้จริงจากพอร์ตที่เลือก 0.2530 ต่ำกว่าที่ดีที่สุด frontier ที่ประมาณจึงอยู่สูงเกินจริงเสมอ และ frontier ที่ได้จริงอยู่ต่ำกว่าเสมอ

ความคลาด 2% นี้เล็กกว่า standard error 4% ด้วยซ้ำ ในสองสินทรัพย์ยังพอรับได้ แต่ $\Sigma^{-1}$ ของสินทรัพย์หลายตัวที่คล้ายกันมีทิศที่ variance เล็กมาก ความคลาดในทิศนั้นถูกขยายจนน้ำหนักสุดโต่ง Richard Michaud จึงเรียก mean-variance optimizer ว่า “error maximizer”

ขั้นที่ 8 — สามสินทรัพย์ที่กลับ matrix ได้ด้วยมือ

ตัวอย่างสามสินทรัพย์ ค่าเฉลี่ย 6%, 2% และ 4% ต่อปี covariance เป็น 0.002 คูณ matrix เลขจำนวนเต็ม (ความผันผวน 8.94%, 4.47% และ 8.94%) และเงินสด 1% ดึงตัวคูณ 0.002 ออกก่อน matrix ที่เหลือกลับด้วยมือได้ แล้วใช้สูตรพอร์ตเสี่ยงต่ำสุดกับ tangency ตรง ๆ

\[ \begin{aligned} \Sigma&=0.002\,M,\quad M=\begin{bmatrix}4&-1&2\\-1&1&-1\\2&-1&4\end{bmatrix},\\ \det M&=4(4-1)+1(-4+2)+2(1-2)\\ &=8,\\ \Sigma^{-1}&=\frac{1}{0.002(8)}\begin{bmatrix}3&2&-1\\2&12&2\\-1&2&3\end{bmatrix},\\ \Sigma^{-1}\mathbf1&=62.5(4,\ 16,\ 4)\\ &=(250,\ 1{,}000,\ 250),\\ A&=1{,}500,\quad w_{\text{mv}}=\big(\tfrac16,\ \tfrac23,\ \tfrac16\big),\\ \sigma_{\text{mv}}&=\sqrt{1/1{,}500}=2.58\%,\\ u&=62.5(0.14,\ 0.28,\ 0.06)\\ &=(8.75,\ 17.5,\ 3.75),\\ w_{\text{tan}}&=\tfrac1{30}u\approx(0.2917,\ 0.5833,\ 0.1250),\\ \mathrm{SR}^2&=u^{\mathsf T}(\mu-0.01\mathbf1)\\ &=0.4375+0.175+0.1125=0.725,\\ \mathrm{SR}&\approx0.8515. \end{aligned} \]

matrix ตัวที่สามคือ adjugate ของ $M$ (คูณกลับกับ $M$ ได้ 8 เท่าของ identity) ตัวคูณหน้าจึงเป็น $1/0.016=62.5$ คิดด้วยมือได้ทั้งหมด ส่วนเกินเงินสดคือ $(0.05,\ 0.01,\ 0.03)$ คูณแถวของ adjugate ได้ $(0.14,\ 0.28,\ 0.06)$

พอร์ตเสี่ยงต่ำสุดถือตัวที่สองถึงสองในสาม เพราะมันแกว่งน้อยที่สุดและเคลื่อนสวนตัวอื่น (covariance ติดลบ) ได้ค่าเฉลี่ย $B/A=45/1{,}500=3\%$ พอร์ต tangency มีค่าเฉลี่ย 3.4167% ความผันผวน 2.8382% และ Sharpe 0.8515 สูงกว่าตัวที่ดีที่สุดรายตัว (ตัวแรก $0.05/0.0894=0.559$) ถึง 52%

ขั้นที่ 9 — เพดานความผันผวน 5%: มีเงินสดกับไม่มีเงินสด

ถามต่อว่าผลตอบแทนสูงสุดที่ความผันผวนไม่เกิน 5% คือเท่าไร ถ้ามีเงินสด คำตอบอยู่บนเส้นจากเงินสดผ่านพอร์ต tangency ถ้าไม่มี คำตอบอยู่บนแขนบนของ frontier ซึ่งต้องแก้ $\sigma^2=(Am^2-2Bm+C)/D$ หา $m$

\[ \begin{aligned} B&=250(0.06)+1{,}000(0.02)+250(0.04)\\ &=45,\\ C&=62.5(0.0236)=1.475,\\ D&=AC-B^2=187.5,\\ Am^2&=2Bm-(C-D\sigma^2),\\ m&=\frac{B+\sqrt{D(A\sigma^2-1)}}{A},\\ \sigma=5\%&:\ m=\frac{45+\sqrt{187.5(2.75)}}{1{,}500}\\ &\approx4.51\%,\\ w(4.51\%)&\approx(62.1\%,\ 36.4\%,\ 1.5\%),\\ m_{\text{cash}}&\approx0.01+0.05(0.8515)\\ &\approx5.26\%,\\ \frac{0.05}{0.028382}&\approx1.76. \end{aligned} \]

สูตรรากเลือกเครื่องหมายบวกเพราะต้องการแขนบน และใช้ $B^2-AC=-D$ ทำให้ในรากเหลือ $D(A\sigma^2-1)$ ซึ่งเป็นศูนย์พอดีที่ความผันผวนต่ำสุด $\sigma^2=1/A$

ไม่มีเงินสด ได้ผลตอบแทนคาดหวัง 4.51% ด้วยน้ำหนัก 62.1%, 36.4% และ 1.5% ถ้ากู้ได้ที่อัตราเงินสด จะถือพอร์ต tangency 1.76 เท่าแล้วกู้ 76% ได้ 5.26% สูงขึ้นประมาณ 0.74 จุดที่ความผันผวนเท่ากัน ทั้งหมดเป็นผลของแบบจำลอง

เพดานที่หลวมเกินไปก็คือไม่มีเพดาน ถ้าตั้งเพดานความผันผวนไว้ 85.94% โดยให้ short ได้ไม่จำกัด สูตรเดียวกันให้ผลตอบแทนคาดหวัง 33.37% ด้วยน้ำหนัก 928%, −541% และ −287%

ขั้นที่ 10 — ข้อมูลแปดกลุ่มสินทรัพย์: คำตอบที่ถูกทางคณิตแต่เทรดไม่ได้

ชุดข้อมูลจริงหนึ่งมีแปดกลุ่ม คือพันธบัตรสหรัฐฯ พันธบัตรต่างประเทศ หุ้นสหรัฐฯ สี่กลุ่ม (ใหญ่และเล็ก แบบโตและแบบคุณค่า) หุ้นประเทศพัฒนาแล้ว และหุ้นตลาดเกิดใหม่ ค่าเฉลี่ยที่ประมาณได้ (%) คือ 3.15, 1.75, −6.39, −2.86, −6.75, −0.54, −6.75 และ −5.26 เงินสด 1.5% แก้ $Vz=\hat\mu$ ด้วยคอมพิวเตอร์ (matrix 8×8) ได้ $\mathbf1^{\mathsf T}z=1{,}364.93$, $z_1=1{,}700.78$ และผลตอบแทนส่วนเกินของพอร์ต tangency 4.2267% ที่เหลือคิดจากสามตัวนี้

\[ \begin{aligned} \hat\mu&=\mu-1.5\,\mathbf1\\ &=(1.65,\ 0.25,\ -7.89,\ -4.36,\\ &\qquad-8.25,\ -2.04,\ -8.25,\ -6.76),\\ s^*_1&=\frac{z_1}{\mathbf1^{\mathsf T}z}\approx\frac{1{,}700.78}{1{,}364.93}\approx1.2461,\\ \sigma_s^2&=s^{*\mathsf T}Vs^*=\frac{s^{*\mathsf T}\hat\mu}{\mathbf1^{\mathsf T}z}\\ &\approx\frac{4.2267}{1{,}364.93}\approx0.0030967,\\ \sigma_s&\approx5.5647\%,\\ \mathrm{SR}&\approx\frac{4.2267}{5.5647}=0.7595,\\ \beta_1&=\frac{(Vs^*)_1}{\sigma_s^2}=\frac{\hat\mu_1}{\hat\mu_s}\\ &\approx\frac{1.65}{4.2267}\approx0.3904. \end{aligned} \]

$s^*$ ถือพันธบัตรสหรัฐฯ 124.61% และ short หุ้นประเทศพัฒนาแล้ว 33.56% ค่าเฉลี่ยของหุ้นเกือบทุกกลุ่มในช่วงข้อมูลนี้ติดลบ optimizer เชื่อตัวเลขนั้นตรง ๆ แล้ว short หุ้นเพื่อซื้อพันธบัตรเกินทุน ถ้าตั้งเพดานความผันผวน 100% และไม่มีเงินสด frontier ให้ผลตอบแทนคาดหวัง 67.36% ด้วยพันธบัตรสหรัฐฯ 568% และ short หุ้นประเทศพัฒนาแล้ว 865% ไม่มีใครเทรดพอร์ตแบบนี้

ค่าเฉลี่ยเป็นเปอร์เซ็นต์แต่ $V$ เป็นทศนิยม $z$ จึงดูใหญ่ การหารด้วย $\mathbf1^{\mathsf T}z$ ตัดหน่วยทิ้ง $s^*$ จึงถูก และเพราะ $Vz=\hat\mu$ variance ของพอร์ตจึงเป็นผลตอบแทนส่วนเกินหารด้วย $\mathbf1^{\mathsf T}z$ โดยไม่ต้องเห็น $V$ เลย

บรรทัด $\beta$ คือการตรวจที่น่าสนใจ เพราะ $Vs^*$ ชี้ทิศเดียวกับ $\hat\mu$ beta ของแต่ละกลุ่มเทียบพอร์ต tangency คูณผลตอบแทนส่วนเกินของพอร์ต ได้ผลตอบแทนส่วนเกินของกลุ่มนั้นพอดี ($0.3904\times4.2267=1.65$) ถ้าทุกคนถือ tangency เดียวกัน พอร์ตนั้นก็คือพอร์ตตลาด และนี่คือโครงของ CAPM ถ้าผู้ลงทุนมี $U=R_p-\tau\sigma_p^2$ กับ $\tau=1$ (หน่วยเปอร์เซ็นต์) คำตอบคือ $z/20{,}000$ ถือสินทรัพย์เสี่ยงรวม 6.82% เงินสด 93.18% หารน้ำหนักเสี่ยงด้วย 0.068246 ได้ $s^*$ เดิมทุกตัว one-fund theorem เป็นตัวเลขจริง

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

เฉลี่ยความผันผวนตามน้ำหนัก: พอร์ต 50/50 ไม่ได้เสี่ยง $(20\%+6\%)/2=13\%$ ถ้า $\rho=0.15$ มันเสี่ยง 10.86% ตัวเลข 13% ถูกเฉพาะเมื่อ $\rho=1$

ใส่ correlation แทน covariance ในตาราง: ถ้าใส่ 0.15 ในช่องนอกแนวทแยงแทน 0.0018 จะได้ determinant $0.04(0.0036)-0.15^2=-0.022356$ ติดลบ ตารางนี้ไม่ใช่ covariance ที่เป็นไปได้ และ optimizer จะหาพอร์ตที่ “variance ติดลบ” ให้

เชื่อค่าเฉลี่ย: ค่าเฉลี่ยหุ้นคลาด 1 จุด น้ำหนักขยับราว 4.3 จุดในสองสินทรัพย์ สองสินทรัพย์ที่เหมือนกันถูกถือ 75/25 เพราะความคลาด 2% และในแปดกลุ่มได้พอร์ต 568% กับ −865% optimizer เทน้ำหนักไปที่ตัวที่ค่าเฉลี่ยถูกประมาณสูงเกินที่สุดเสมอ

ตัดตัวที่ติดลบทิ้งแล้วปรับสัดส่วน: คำตอบที่ $\rho=0.8$ และที่เพดาน 85.94% ต้อง short ถ้าห้าม short ต้องแก้โจทย์ใหม่พร้อมข้อจำกัดด้วย KKT ไม่ใช่ตัดตัวที่ติดลบทิ้งแล้วปรับให้รวมเป็นหนึ่ง และมุมของข้อจำกัด “ห้าม short” ทำให้คำตอบกระโดดได้ไวขึ้นต่อค่าที่ป้อน

ใช้ทำอะไรบนโต๊ะจริง

ปัญหาหลักคือจำนวนตัวเลขที่ต้องประมาณ covariance ของ $d$ สินทรัพย์มี $d(d+1)/2$ ตัวที่ไม่ซ้ำกัน แปดกลุ่มมี 36 ตัวบวกค่าเฉลี่ยอีก 8 หุ้น 500 ตัวมี 125,250 ตัว ขณะที่ข้อมูลรายเดือนห้าปีมีแค่ 60 แถว ทุก desk จึงทำอย่างน้อยหนึ่งอย่างต่อไปนี้ ใส่เพดานน้ำหนักหรือเพดาน leverage ซึ่งช่วยจำกัดความเสียหายจากค่าคลาด ดึงค่าเฉลี่ยรายตัวเข้าหาค่าเฉลี่ยรวม และดึง covariance เข้าหารูปที่ง่ายกว่า (Ledoit–Wolf shrinkage) หรือเริ่มจากพอร์ตตลาดแล้วผสมมุมมองของตัวเองทีละน้อย (Black–Litterman)

พอร์ตเสี่ยงต่ำสุดไม่ต้องใช้ $\mu$ จึงประมาณได้นิ่งที่สุด และในทางปฏิบัติมักทำผลงานได้ดีกว่าที่ทฤษฎีคาด เพราะหลบความคลาดของค่าเฉลี่ยทั้งหมด ส่วนต้นทุนซื้อขายของการปรับพอร์ตตามค่าประมาณที่ขยับทุกเดือน ต้องใส่เข้าไปในโจทย์ด้วย (mean-variance with transaction costs)

โจทย์ตรวจความเข้าใจ

1. สองสินทรัพย์ความผันผวน 30% และ 10% correlation ศูนย์ พอร์ตเสี่ยงต่ำสุดถือตัวแรกเท่าไร และเสี่ยงเท่าไร

เฉลย

สูตรน้ำหนักเสี่ยงต่ำสุดกับ $\rho=0$: $w=0.01/(0.09+0.01)=10\%$ variance $=0.01(0.09)+0.81(0.01)=0.0009+0.0081=0.009$ ความผันผวน 9.49% ต่ำกว่าตัวที่นิ่งกว่า (10%) แม้ไม่มี correlation ติดลบเลย

2. โจทย์ \$10 ล้านเดิม แต่เงินสดได้ 3% พอร์ต tangency เปลี่ยนเป็นอย่างไร

เฉลย

ส่วนเกินเป็น (0.06, 0.005) $u_1=25.5754(0.06)-12.7877(0.005)=1.4706$ $u_2=-12.7877(0.06)+284.1716(0.005)=0.6536$ หารด้วย 2.1242 ได้หุ้น 69.23% พันธบัตร 30.77% $\mathrm{SR}^2=u^{\mathsf T}(\mu-r_f\mathbf1)=1.4706(0.06)+0.6536(0.005)=0.091504$ รากที่สองได้ 0.3025 เงินสดแพงขึ้น พันธบัตรได้เหนือเงินสดแค่ 0.5% จึงเสียน้ำหนักให้หุ้น

3. โครงการท่อส่งน้ำมันขายหุ้นละ \$875 คาดว่าจ่าย \$1,000 ในหนึ่งปี ความผันผวน 40% เงินสดได้ 5% พอร์ตตลาดคาดหวัง 17% ความผันผวน 12% ถ้าใช้เส้นจากเงินสดผ่านพอร์ตตลาดเป็นเกณฑ์ โครงการนี้น่าสนใจไหม

เฉลย

ผลตอบแทนคาดหวัง $1{,}000/875-1=14.29\%$ เส้นจากเงินสดมีความชัน $(17\%-5\%)/12\%=1$ ที่ความผันผวน 40% เส้นนี้ให้ $5\%+1(40\%)=45\%$ ถือส่วนผสมของตลาดกับเงินกู้ที่เสี่ยงเท่ากันได้มากกว่าสามเท่า โครงการนี้จึงไม่น่าสนใจเมื่อถือเดี่ยว ๆ (ถ้าจะถือเป็นส่วนเล็กของพอร์ตใหญ่ เกณฑ์ที่ถูกคือ beta ของ CAPM ไม่ใช่ความผันผวนรวม)

const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);
const times = (S, v) => S.map(r => dot(r, v));
// Solve S x = b by Gaussian elimination with partial pivoting (no explicit inverse)
function solve(S, b) {
  const n = S.length, M = S.map((r, i) => [...r, b[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (Math.abs(M[r][c]) > Math.abs(M[p][c])) p = r;
    [M[c], M[p]] = [M[p], M[c]];
    for (let r = c + 1; r < n; r++) { const f = M[r][c] / M[c][c]; for (let k = c; k <= n; k++) M[r][k] -= f * M[c][k]; }
  }
  const x = new Array(n).fill(0);
  for (let r = n - 1; r >= 0; r--) x[r] = (M[r][n] - dot(M[r].slice(r + 1, n), x.slice(r + 1))) / M[r][r];
  return x;
}
const stats = (S, mu, w) => ({w, mean: dot(w, mu), sd: Math.sqrt(dot(w, times(S, w)))});
function minVariance(S, mu) {                    // w = S^-1 1 / A, variance 1/A
  const y = solve(S, S.map(() => 1)), A = y.reduce((a, b) => a + b, 0);
  return {...stats(S, mu, y.map(v => v / A)), A};
}
function tangency(S, mu, rf) {                   // u = S^-1 (mu - rf), scaled to sum 1
  const u = solve(S, mu.map(m => m - rf)), total = u.reduce((a, b) => a + b, 0);
  const s = stats(S, mu, u.map(v => v / total));
  return {...s, u, sharpe: (s.mean - rf) / s.sd};
}
function frontier(S, mu) {                       // A, B, C, D and the top-arm return at a volatility
  const y1 = solve(S, S.map(() => 1)), ym = solve(S, mu);
  const A = y1.reduce((a, b) => a + b, 0), B = dot(mu, y1), C = dot(mu, ym), D = A * C - B * B;
  const weights = m => y1.map((v, i) => ((C - B * m) * v + (A * m - B) * ym[i]) / D);
  return {A, B, C, D, weights, returnAt: sd => (B + Math.sqrt(D * (A * sd * sd - 1))) / A};
}

// Three assets: covariance 0.002 times an integer matrix, cash 1%
const S3 = [[4, -1, 2], [-1, 1, -1], [2, -1, 4]].map(r => r.map(x => 0.002 * x)), mu3 = [0.06, 0.02, 0.04];
const f3 = frontier(S3, mu3), tan3 = tangency(S3, mu3, 0.01);

สิ่งที่ควรตอบได้หลังอ่าน

  • พอร์ต 50/50 เสี่ยง 10.86% ไม่ใช่ 13% เพราะพจน์ไขว้ของ covariance และพอร์ตถือเท่ากันหลายตัวมีพื้นที่ $\sigma\sqrt\rho$
  • พอร์ตเสี่ยงต่ำสุด (หุ้น 4.5%) เสี่ยง 5.93% ต่ำกว่าพันธบัตรล้วน และใช้แค่ $\Sigma$: $w=\Sigma^{-1}\mathbf1/A$ variance $1/A$
  • correlation สูงมากทำให้ตัวหนึ่ง hedge อีกตัวได้ ที่ 0.8 short หุ้น 24.59% เสี่ยงเหลือ 4.61%
  • พอร์ต tangency คือ $\Sigma^{-1}(\mu-r_f\mathbf1)$ ปรับให้รวมเป็นหนึ่ง หุ้น 32.19% Sharpe 0.4030 และ $\mathrm{SR}^2=u^{\mathsf T}(\mu-r_f\mathbf1)$
  • optimizer ขยายความคลาดของค่าเฉลี่ย สองสินทรัพย์เหมือนกันถูกถือ 75/25 Sharpe ที่เชื่อสูงเกินจริง ที่ได้จริงต่ำกว่าที่ดีที่สุด

ความไวต่อค่าคลาดมาจากทิศใน $\Sigma$ ที่ variance เล็กมาก หน้าถัดไป PCA ดู $\Sigma$ ผ่าน eigenvector ของมัน เมื่อสินทรัพย์หลายตัวขยับไปด้วยกันแน่น matrix หลายมิติอาจมีทิศสำคัญจริงแค่ไม่กี่ทิศ
