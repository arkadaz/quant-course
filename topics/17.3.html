17.3 Markowitz Portfolio Theory

ความเสี่ยงของพอร์ตไม่ใช่ค่าเฉลี่ยของความเสี่ยงรายตัว เพราะสินทรัพย์ไม่ได้ขึ้นลงพร้อมกันเสมอ Markowitz ใช้ข้อนี้หาส่วนผสมที่ได้ผลตอบแทนคาดหวังสูงสุดที่ความผันผวนแต่ละระดับ ด้วยพีชคณิต matrix

คุณดูแลเงิน \$10 ล้าน และต้องตัดสินใจว่าจะแบ่งไปซื้อหุ้นเท่าไร ซื้อพันธบัตรเท่าไร พันธบัตรคือตราสารหนี้ที่จ่ายดอกเบี้ยสม่ำเสมอ ราคาแกว่งน้อยกว่าหุ้น เงินส่วนที่ไม่ลงทุนก็ฝากเป็นเงินสดได้ ทุกคนอยากได้ผลตอบแทนมาก แต่ไม่อยากให้มูลค่าพอร์ตแกว่งแรง

ตัวเลขตัวอย่าง (สมมติ) คิดต่อปี:

  • หุ้นมีผลตอบแทนคาดหวัง $\mu_E=9\%$ คือผลตอบแทนเฉลี่ยที่คาดว่าจะได้ในหนึ่งปี
  • หุ้นมีความผันผวน $\sigma_E=20\%$ คือ SD (standard deviation) ของผลตอบแทนรายปี บอกว่าแต่ละปีผลตอบแทนแกว่งห่างจากค่าเฉลี่ยประมาณเท่าไร
  • พันธบัตรมีผลตอบแทนคาดหวัง $\mu_B=3.5\%$ และความผันผวน $\sigma_B=6\%$
  • correlation ของหุ้นกับพันธบัตร $\rho=0.15$ คือตัวเลขระหว่าง −1 ถึง 1 ที่บอกว่าสองตัวขึ้นลงพร้อมกันแค่ไหน ค่า 1 คือขึ้นลงพร้อมกันเป๊ะ ค่า 0 คือไม่เกี่ยวกันเลย ค่า 0.15 จึงแปลว่าเกี่ยวกันน้อย
  • เงินสดได้ดอกเบี้ย $r_f=2\%$ แน่นอน ไม่แกว่งเลย

คนแรกบอกว่า “อยากเสี่ยงน้อยที่สุด ก็ถือพันธบัตรล้วน ความผันผวนแค่ 6%”

คนที่สองดู Sharpe ratio คือผลตอบแทนคาดหวังที่ได้เกินดอกเบี้ยเงินสด หารด้วยความผันผวน ตัวเลขนี้บอกว่าแกว่งหนึ่งหน่วยแล้วได้ผลตอบแทนเพิ่มเท่าไร ยิ่งสูงยิ่งคุ้ม

\[\begin{aligned}\mathrm{SR}_E&=\frac{9\%-2\%}{20\%}=0.35,\\ \mathrm{SR}_B&=\frac{3.5\%-2\%}{6\%}=0.25.\end{aligned}\]

หุ้นได้ Sharpe สูงกว่า คนที่สองจึงบอกว่า “อยากได้ Sharpe สูงสุด ก็ถือหุ้นล้วน” ใครถูก

ลองตอบก่อนเปิดเฉลย

ผิดทั้งคู่ เพราะหุ้นกับพันธบัตรขึ้นลงไม่พร้อมกัน การผสมสองตัวจึงหักล้างการแกว่งได้บางส่วน หน้านี้จะคำนวณตัวเลขต่อไปนี้ให้ดูทีละขั้น

ใส่หุ้นแค่ 4.5% คือ $0.045\times\$10{,}000{,}000=\$450{,}000$ ความผันผวนของพอร์ตจะลดเหลือ 5.93% ต่ำกว่าพันธบัตรล้วน ทั้งที่หุ้นแกว่งมากกว่าพันธบัตร $20/6\approx3.3$ เท่า คนแรกจึงผิด

ถ้าใส่หุ้น 32.19% (\$3,218,884) กับพันธบัตร 67.81% จะได้ Sharpe 0.4030 สูงกว่าหุ้นล้วน เพราะ $0.4030/0.35\approx1.151$ คือสูงกว่า 15.1% คนที่สองจึงผิดด้วย

ภาพรวมก่อนลงสูตร

ทำไมการผสมถึงลดความเสี่ยงได้ ลองนึกถึงสองสินทรัพย์ที่บางปีตัวหนึ่งขึ้นขณะที่อีกตัวลง ถ้าถือทั้งสองตัว ส่วนที่ขึ้นจะชดเชยส่วนที่ลง มูลค่าพอร์ตรวมจึงแกว่งน้อยกว่าที่แต่ละตัวแกว่ง

Harry Markowitz เสนอในปี 1952 ให้วัดพอร์ตด้วยสองตัวเลข คือผลตอบแทนคาดหวัง (ได้มากแค่ไหน) กับความผันผวน (เสี่ยงแค่ไหน) ผลตอบแทนคาดหวังของพอร์ตคิดง่าย มันคือค่าเฉลี่ยถ่วงน้ำหนัก เช่น หุ้นครึ่งหนึ่งกับพันธบัตรครึ่งหนึ่งได้ $0.5\times9\%+0.5\times3.5\%=6.25\%$

แต่ความผันผวนของพอร์ตไม่ใช่ค่าเฉลี่ยถ่วงน้ำหนัก เพราะ variance ของพอร์ต (ความผันผวนยกกำลังสอง) มีพจน์ไขว้ของ covariance ทุกคู่ covariance คือตัวเลขที่บอกว่าสองสินทรัพย์แกว่งไปทางเดียวกันมากแค่ไหน (ดู ความเสี่ยงของพอร์ตจาก covariance matrix) ถ้าสองตัวขึ้นลงไม่พร้อมกัน พจน์ไขว้จะเล็ก และการแกว่งของสองตัวหักล้างกันได้

ถ้าลองทุกส่วนผสม แล้ววาดแต่ละพอร์ตเป็นจุด โดยแกนนอนคือความผันผวน แกนตั้งคือผลตอบแทนคาดหวัง จุดทั้งหมดจะเรียงกันเป็นรูปร่างหนึ่ง ขอบซ้ายบนของรูปนั้นเรียกว่า efficient frontier เพราะพอร์ตใดที่อยู่ใต้ขอบ จะมีพอร์ตบนขอบที่แกว่งเท่ากันแต่ได้ผลตอบแทนคาดหวังมากกว่าเสมอ

ทีนี้เอาเงินสดมาผสมด้วย สมมติมีพอร์ตเสี่ยงพอร์ตหนึ่งที่มีผลตอบแทนคาดหวัง $\mu_p$ และความผันผวน $\sigma_p$ ถ้าใส่เงินในพอร์ตนี้เป็นสัดส่วน $a$ ที่เหลือเป็นเงินสด ผลตอบแทนคาดหวังคือ $r_f+a(\mu_p-r_f)$ และความผันผวนคือ $a\sigma_p$ เพราะเงินสดไม่แกว่ง ทั้งสองตัวโตตาม $a$ แบบเส้นตรง ส่วนผสมทุกแบบจึงเรียงเป็นเส้นตรงที่เริ่มจากจุดเงินสด ความชันของเส้นคือ $(\mu_p-r_f)/\sigma_p$ ซึ่งก็คือ Sharpe ratio ของพอร์ตเสี่ยงนั้นพอดี

เส้นที่ดีที่สุดคือเส้นที่ชันที่สุดที่ยังแตะขอบได้ จุดที่เส้นนี้แตะขอบเรียกว่าพอร์ต tangency (tangency แปลว่าจุดสัมผัส) มันจึงเป็นพอร์ตเสี่ยงที่ Sharpe ratio สูงที่สุด

หน้านี้เดินตามลำดับนี้

  • ประกอบ covariance แล้วคิดพอร์ตครึ่งต่อครึ่งด้วยมือ
  • ดูว่าการกระจายไปหลายตัวลดความเสี่ยงได้ถึงแค่ไหน
  • หาพอร์ตเสี่ยงต่ำสุด และดูว่า correlation เปลี่ยนคำตอบอย่างไร
  • เขียนทุกอย่างเป็น matrix แล้วหาพอร์ต tangency ของเงิน \$10 ล้าน
  • ถามว่าคำตอบไวต่อค่าเฉลี่ยที่ประมาณมาแค่ไหน ซึ่งเป็นคำถามที่สำคัญที่สุด
  • ลองสามสินทรัพย์ด้วยมือ แล้วจบที่ข้อมูลจริงแปดกลุ่มสินทรัพย์ ซึ่งให้คำตอบที่ถูกทางคณิตแต่เอาไปซื้อขายจริงไม่ได้

ขั้นที่ 1 — ประกอบ covariance แล้วลองพอร์ตครึ่งต่อครึ่ง

โจทย์ให้ความผันผวนของแต่ละตัวกับ correlation มา แต่สูตร variance ของพอร์ตต้องใช้ covariance เราจึงต้องแปลงก่อน แล้วจัดเป็นตาราง $\Sigma$ (covariance matrix)

จากนั้นลองพอร์ตที่ง่ายที่สุด คือหุ้นครึ่งหนึ่งกับพันธบัตรครึ่งหนึ่ง ($w_E=w_B=\tfrac12$) แล้วเปลี่ยน correlation เป็นสามค่า เพื่อดูว่าความเสี่ยงของพอร์ตมาจากไหน ตัวช่วยที่ใช้ซ้ำคือ $\sigma_E\sigma_B=0.20\times0.06=0.012$

\[ \begin{aligned} \sigma_{EB}&=\rho\,\sigma_E\sigma_B\\ &=0.15\times0.012=0.0018,\\ \Sigma&=\begin{bmatrix}\sigma_E^2&\sigma_{EB}\\\sigma_{EB}&\sigma_B^2\end{bmatrix}\\ &=\begin{bmatrix}0.04&0.0018\\0.0018&0.0036\end{bmatrix},\\ \sigma_p^2&=w_E^2\sigma_E^2+w_B^2\sigma_B^2\\ &\quad+2w_Ew_B\,\rho\,\sigma_E\sigma_B\\ &=\tfrac14(0.04)+\tfrac14(0.0036)\\ &\quad+2\cdot\tfrac14\cdot0.012\,\rho\\ &=0.0109+0.006\rho,\\ \rho=0.15&:\ \sqrt{0.0109+0.0009}=10.86\%,\\ \rho=1&:\ \sqrt{0.0109+0.006}=13.00\%,\\ \rho=-1&:\ \sqrt{0.0109-0.006}=7.00\%. \end{aligned} \]

ทำไมช่องนอกแนวทแยงต้องเป็น $\rho\,\sigma_E\sigma_B$ ไม่ใช่ $\rho$ เฉย ๆ เพราะทุกช่องของ $\Sigma$ ต้องมีหน่วยเดียวกัน แนวทแยงคือ variance ($0.20^2=0.04$ และ $0.06^2=0.0036$) มีหน่วยเป็นผลตอบแทนยกกำลังสอง correlation ไม่มีหน่วย จึงต้องคูณด้วยความผันผวนสองตัวก่อนจะใส่ลงตารางได้

สูตร $\sigma_p^2$ คือ $w^{\mathsf T}\Sigma w$ ที่กางออก สองก้อนแรกคือการแกว่งของแต่ละตัว ก้อนที่สามคือพจน์ไขว้ และเป็นก้อนเดียวที่มี correlation อยู่ ถ้า $\rho$ เล็ก ก้อนนี้ก็เล็ก ความเสี่ยงรวมจึงลดลง

เมื่อ $\rho=1$ ความผันผวนออกมา 13% เท่ากับค่าเฉลี่ยของความผันผวนรายตัว $(20\%+6\%)/2=13\%$ พอดี เพราะสามก้อนรวมกันเป็นกำลังสองสมบูรณ์ $(w_E\sigma_E+w_B\sigma_B)^2$ แต่ถ้า $\rho$ ต่ำกว่า 1 ก็ได้ต่ำกว่า 13% เสมอ กรณีของโจทย์ $\rho=0.15$ ได้ 10.86% ลดลง $13.00-10.86=2.14$ จุด โดยไม่ได้เปลี่ยนสินทรัพย์ตัวไหนเลย การลดความเสี่ยงที่ได้มาฟรีจากการผสมนี้เรียกว่าการกระจายความเสี่ยง (diversification)

ขั้นที่ 2 — สินทรัพย์หลายตัว: การกระจายมีพื้น

ของฟรีนี้ได้มากแค่ไหน ถ้าเพิ่มจำนวนสินทรัพย์ไปเรื่อย ๆ ความเสี่ยงจะลดลงถึงศูนย์ไหม ลองกรณีที่คิดง่ายที่สุด

  • มีสินทรัพย์ $d$ ตัว ถือเท่ากันตัวละ $1/d$ ของเงิน
  • ทุกตัวมีความผันผวน $\sigma$ เท่ากัน ตัวอย่างใช้ $\sigma=20\%$ ช่องแนวทแยงของ $\Sigma$ จึงเป็น $\sigma^2$ ทุกช่อง
  • ทุกคู่มี correlation $\rho$ เท่ากัน ช่องนอกแนวทแยงจึงเป็น $\rho\sigma^2$ ทุกช่อง

variance ของพอร์ต $w^{\mathsf T}\Sigma w$ คือผลรวมของทุกช่อง $\sigma_{ij}$ (ช่องแถว $i$ หลัก $j$ ของ $\Sigma$) คูณน้ำหนักสองตัว เราจึงแค่นับว่าช่องบนแนวทแยงมีกี่ช่อง ช่องนอกแนวทแยงมีกี่ช่อง

\[ \begin{aligned} \sigma_p^2&=\sum_i\sum_j\frac1d\cdot\frac1d\,\sigma_{ij}\\ &=d\cdot\frac{\sigma^2}{d^2}+d(d-1)\cdot\frac{\rho\sigma^2}{d^2}\\ &=\frac{\sigma^2}{d}+\rho\sigma^2-\frac{\rho\sigma^2}{d}\\ &=\sigma^2\Big(\rho+\frac{1-\rho}{d}\Big),\\ \rho=0,\ d=10&:\ \sigma_p=\frac{20\%}{\sqrt{10}}=6.32\%,\\ \rho=0.3,\ d=10&:\ 0.3+\frac{0.7}{10}=0.37,\\ &\quad\ \sigma_p=20\%\sqrt{0.37}=12.17\%,\\ d\to\infty&:\ \sigma_p\to\sigma\sqrt\rho=20\%\sqrt{0.3}\\ &\quad\ =10.95\%. \end{aligned} \]

ทำไมก้อนหนึ่งหายแต่อีกก้อนไม่หาย matrix ขนาด $d\times d$ มีช่องแนวทแยงแค่ $d$ ช่อง แต่ละช่องคูณน้ำหนัก $1/d$ สองครั้ง รวมได้ $\sigma^2/d$ ซึ่งเข้าใกล้ศูนย์เมื่อ $d$ โต ส่วนช่องนอกแนวทแยงมี $d(d-1)$ ช่อง เกือบ $d^2$ ช่อง จำนวนช่องโตเร็วพอ ๆ กับที่น้ำหนักเล็กลง จึงเหลือ $\rho\sigma^2$ ค้างอยู่เป็นพื้น

ถ้าทุกตัวไม่เกี่ยวกันเลย ($\rho=0$) ความผันผวนลดตาม $1/\sqrt d$ ไปจนเกือบศูนย์ แต่หุ้นในตลาดเดียวกันมักมี correlation กันราว 0.3 (ใช้เป็นตัวเลขตัวอย่างที่นี่) เพราะทุกตัวขยับตามภาวะตลาดร่วมกัน ถือกี่ร้อยตัวก็ลงไม่ต่ำกว่า 10.95%

ส่วนที่กระจายทิ้งได้เรียกว่าความเสี่ยงเฉพาะตัว คือการแกว่งที่มาจากเรื่องของบริษัทนั้นเอง ส่วนพื้นที่เหลือเรียกว่าความเสี่ยงของตลาด คือการแกว่งที่ทุกตัวโดนพร้อมกัน CAPM บอกว่าตลาดจ่ายผลตอบแทนชดเชยให้เฉพาะส่วนหลังนี้ เพราะส่วนแรกใครก็กระจายทิ้งได้ฟรี

ขั้นที่ 3 — พอร์ตเสี่ยงต่ำสุดด้วยมือ

กลับมาที่หุ้นกับพันธบัตร คำถามของคนแรกคือ พอร์ตไหนเสี่ยงน้อยที่สุด ขั้นนี้ยังไม่มีเงินสด เงินทั้งหมดอยู่ในหุ้นกับพันธบัตร น้ำหนักรวมจึงเป็นหนึ่ง $w_B=1-w_E$

แทน $w_B$ ลงไป variance จะเหลือตัวแปรเดียวคือ $w_E$ และเป็นพาราโบลา จุดต่ำสุดของพาราโบลาคือจุดที่ derivative เป็นศูนย์ ก่อนหา derivative ให้กางวงเล็บทุกก้อน จะได้เห็นว่าสัมประสิทธิ์แต่ละตัวมาจากไหน

\[ \begin{aligned} \sigma_p^2&=0.04w_E^2+0.0036(1-w_E)^2\\ &\quad+2(0.0018)w_E(1-w_E)\\ &=0.04w_E^2\\ &\quad+(0.0036-0.0072w_E+0.0036w_E^2)\\ &\quad+(0.0036w_E-0.0036w_E^2)\\ &=0.04w_E^2-0.0036w_E+0.0036,\\ \frac{d\sigma_p^2}{dw_E}&=0.08w_E-0.0036=0,\\ w_E&=\frac{0.0036}{0.08}=0.045,\\ \sigma_p^2&=0.04(0.045)^2-0.0036(0.045)\\ &\quad+0.0036\\ &=0.000081-0.000162+0.0036\\ &=0.003519,\\ \sigma_p&=\sqrt{0.003519}\approx5.93\%. \end{aligned} \]

รวมก้อนที่มี $w_E^2$ ได้ $0.04+0.0036-0.0036=0.04$ รวมก้อนที่มี $w_E$ ได้ $-0.0072+0.0036=-0.0036$ สัมประสิทธิ์หน้า $w_E^2$ เป็นบวก พาราโบลาจึงหงาย จุดที่ความชันเป็นศูนย์จึงเป็นจุดต่ำสุด ไม่ใช่สูงสุด

คำตอบคือหุ้น 4.5% พันธบัตร $1-0.045=95.5\%$ ผลตอบแทนคาดหวังคือ $0.045\times9\%+0.955\times3.5\%=3.75\%$ ความผันผวน 5.93% ต่ำกว่าพันธบัตรล้วนที่ 6% ทั้งที่ใส่หุ้นที่แกว่ง 20% เข้าไป

เป็นไปได้อย่างไร ดูความชันที่ $w_E=0$ (พันธบัตรล้วน) ได้ $0.08\times0-0.0036=-0.0036$ ติดลบ แปลว่าใส่หุ้นก้อนแรกเข้าไปแล้ว variance ลดลง ความชันนี้มาจากสองแรงที่สู้กัน คือ $2(\sigma_{EB}-\sigma_B^2)=2(0.0018-0.0036)=-0.0036$ ย้ายเงินจากพันธบัตรมาเป็นหุ้นก้อนเล็ก ๆ ช่วยลดการแกว่งของพันธบัตรในอัตรา $\sigma_B^2=0.0036$ แต่เพิ่มการแกว่งร่วมกับหุ้นแค่ในอัตรา $\sigma_{EB}=0.0018$ ส่วนการแกว่งของหุ้นเองโตตาม $w_E^2$ ซึ่งยังเล็กมากตอนเริ่ม พูดง่าย ๆ คือหุ้นเกี่ยวกับพันธบัตรน้อย ปีที่พันธบัตรลง หุ้นมักไม่ได้ลงตาม

ขั้นที่ 4 — correlation สูงไม่ได้แปลว่ากระจายไม่ได้

ขั้นที่แล้วใช้ตัวเลขของโจทย์ ขั้นนี้ทำซ้ำด้วยสัญลักษณ์ เพื่อดูว่าพอร์ตเสี่ยงต่ำสุดเปลี่ยนไปอย่างไรเมื่อ $\rho$ เปลี่ยน สัญชาตญาณบอกว่า correlation ยิ่งสูง การกระจายยิ่งช่วยน้อย ขั้นนี้จะแสดงว่าจริงแค่ครึ่งเดียว

ตั้งครึ่งหนึ่งของ derivative เป็นศูนย์ (หารด้วย 2 ให้สูตรสั้นลง) แล้วแก้หา $w_E$ ตัวเลขที่ใช้ซ้ำคือ $\sigma_E^2+\sigma_B^2=0.04+0.0036=0.0436$ และ $\sigma_E\sigma_B=0.012$

\[ \begin{aligned} \tfrac12\frac{d\sigma_p^2}{dw_E}&=\sigma_E^2w_E-\sigma_B^2(1-w_E)\\ &\quad+\rho\sigma_E\sigma_B(1-2w_E)=0,\\ w_E&=\frac{\sigma_B^2-\rho\sigma_E\sigma_B}{\sigma_E^2+\sigma_B^2-2\rho\sigma_E\sigma_B}\\ &=\frac{0.0036-0.012\rho}{0.0436-0.024\rho},\\ \rho=-0.5&:\ \frac{0.0036+0.0060}{0.0556}\approx17.27\%,\\ \rho=0.3&:\ \frac{0.0036-0.0036}{0.0364}=0,\\ \rho=0.8&:\ \frac{0.0036-0.0096}{0.0244}\approx-24.59\%. \end{aligned} \]

น้ำหนักอย่างเดียวยังไม่พอ เราอยากรู้ด้วยว่าเสี่ยงต่ำสุดเท่าไร มีทางลัด derivative ข้างบนจัดรูปได้เป็น $(\Sigma w)_1-(\Sigma w)_2$ คือแถวที่หนึ่งลบแถวที่สองของ vector $\Sigma w$ ที่จุดต่ำสุดสองแถวนี้จึงเท่ากัน และเพราะ $\sigma_p^2=w_E(\Sigma w)_1+w_B(\Sigma w)_2$ กับ $w_E+w_B=1$ variance ที่จุดต่ำสุดจึงเท่ากับแถวที่สองพอดี

\[ \begin{aligned} \sigma_{\min}^2&=(\Sigma w)_2\\ &=\rho\sigma_E\sigma_B\,w_E+\sigma_B^2(1-w_E),\\ \rho=-0.5&:\ -0.006(0.1727)+0.0036(0.8273)\\ &\quad\approx0.001942,\ \ \sigma_{\min}=4.41\%,\\ \rho=0.3&:\ 0+0.0036(1)=0.0036,\\ &\quad\ \sigma_{\min}=6.00\%,\\ \rho=0.8&:\ 0.0096(-0.2459)+0.0036(1.2459)\\ &\quad\approx0.002125,\ \ \sigma_{\min}=4.61\%. \end{aligned} \]

ลองตรวจทางลัดกับกรณีของโจทย์ $\rho=0.15$ ได้ $0.0018(0.045)+0.0036(0.955)=0.000081+0.003438=0.003519$ ตรงกับขั้นที่ 3 ทางลัดนี้ใช้ได้เพราะที่จุดต่ำสุด ย้ายเงินเล็กน้อยจากตัวหนึ่งไปอีกตัวแล้ว variance ไม่เปลี่ยน แปลว่าทั้งสองตัวเพิ่ม variance ต่อเงินหนึ่งหน่วยเท่ากัน

ที่ $\rho=-0.5$ พอร์ตเสี่ยงต่ำสุดถือหุ้น 17.27% และเสี่ยงแค่ 4.41% เพราะสองตัวมักสวนทางกัน ที่ $\rho=0.3$ น้ำหนักหุ้นเป็นศูนย์พอดี คำตอบคือพันธบัตรล้วน 6% เพราะ $\rho=\sigma_B/\sigma_E=0.06/0.20=0.3$ ทำให้ $\sigma_{EB}=0.3\times0.012=0.0036=\sigma_B^2$ สองแรงที่สู้กันในขั้นที่ 3 จึงเท่ากันพอดี หุ้นก้อนแรกไม่ช่วยและไม่ทำร้าย

ที่ $\rho=0.8$ คำตอบคือ short หุ้น 24.59% แล้วเอาเงินที่ได้ไปซื้อพันธบัตรเพิ่ม จนถือพันธบัตร $1+0.2459=124.59\%$ ความผันผวนลงไปเหลือ 4.61% ต่ำกว่ากรณี $\rho=0.15$ (5.93%) เสียอีก ทำไม เมื่อสองตัวขึ้นลงพร้อมกันมาก หุ้นที่ short ไว้จะได้กำไรตอนที่พันธบัตรขาดทุน มันจึงกลายเป็นเครื่องมือ hedge (ป้องกันความเสี่ยง) ของพันธบัตร

ดังนั้นความเสี่ยงต่ำสุดไม่ได้สูงที่สุดตอน correlation สูง มันสูงที่สุดตรงกลางที่ $\rho=0.3$ แต่ทั้งหมดนี้อาศัยว่า short ได้ ถ้าห้าม short ต้องแก้โจทย์ที่มีข้อห้ามแบบอสมการด้วย KKT conditions และคำตอบที่ $\rho=0.8$ จะกลายเป็นพันธบัตรล้วน 6%

ขั้นที่ 5 — เขียนเป็น matrix: พอร์ตเสี่ยงต่ำสุดกับพอร์ต tangency

เมื่อมีสินทรัพย์หลายตัว การกางวงเล็บแบบขั้นที่ 3 จะยาวเกินไป เราจึงเขียนทุกอย่างเป็น matrix ซึ่งใช้วิธีเดียวกันได้ทุกขนาด ขั้นนี้ทำสองเรื่อง

  • ไม่มีเงินสด: หาพอร์ตเสี่ยงต่ำสุด คือให้ variance $w^{\mathsf T}\Sigma w$ ต่ำที่สุด โดยน้ำหนักรวมเป็นหนึ่ง $\mathbf1^{\mathsf T}w=1$
  • มีเงินสด: หาพอร์ตที่ให้คะแนนความพอใจ $U(w)$ สูงที่สุด คะแนนนี้คือผลตอบแทนคาดหวัง ลบด้วยค่าปรับที่โตตาม variance

ยังมีวิธีตั้งโจทย์อีกแบบ คือให้ผลตอบแทนสูงสุดโดยความผันผวนไม่เกินเพดาน ทุกแบบให้คำตอบชุดเดียวกัน คือพอร์ตบน frontier

ทุกเรื่องต้องใช้ $\Sigma^{-1}$ ก่อน ตัวอย่างนี้ $\Sigma$ เป็น positive definite คือทุกพอร์ตที่ไม่ใช่ศูนย์มี variance เป็นบวก จึงกลับได้ สูตรกลับ matrix 2×2 คือสลับสองช่องบนแนวทแยง กลับเครื่องหมายสองช่องนอกแนวทแยง แล้วหารด้วย determinant

\[ \begin{aligned} \det\Sigma&=0.04(0.0036)-0.0018^2\\ &=0.000144-0.00000324\\ &=0.00014076,\\ \Sigma^{-1}&=\frac1{\det\Sigma}\begin{bmatrix}0.0036&-0.0018\\-0.0018&0.04\end{bmatrix}\\ &=\begin{bmatrix}25.5754&-12.7877\\-12.7877&284.1716\end{bmatrix},\\ \Sigma w&=\lambda\mathbf1,\quad \mathbf1^{\mathsf T}w=1,\\ w_{\text{mv}}&=\frac{\Sigma^{-1}\mathbf1}{A},\quad A=\mathbf1^{\mathsf T}\Sigma^{-1}\mathbf1,\\ \Sigma^{-1}\mathbf1&=(25.5754-12.7877,\\ &\qquad-12.7877+284.1716)\\ &=(12.7877,\ 271.3839),\\ A&=12.7877+271.3839=284.1716,\\ w_{\text{mv}}&=\frac{(12.7877,\ 271.3839)}{284.1716}\\ &\approx(0.045,\ 0.955),\\ U(w)&=r_f+w^{\mathsf T}(\mu-r_f\mathbf1)-\tfrac\gamma2w^{\mathsf T}\Sigma w,\\ \nabla U&=(\mu-r_f\mathbf1)-\gamma\Sigma w=0,\\ w^*&=\frac1\gamma\,\Sigma^{-1}(\mu-r_f\mathbf1),\\ w_{\text{tan}}&=\frac{\Sigma^{-1}(\mu-r_f\mathbf1)}{\mathbf1^{\mathsf T}\Sigma^{-1}(\mu-r_f\mathbf1)}. \end{aligned} \]

บรรทัด $\Sigma w=\lambda\mathbf1$ มาจาก Lagrange multipliers ที่จุดต่ำสุดภายใต้ข้อบังคับ ความชันของ variance ซึ่งคือ $2\Sigma w$ ต้องชี้ทิศเดียวกับความชันของข้อบังคับ ซึ่งคือ $\mathbf1$ (เลข 2 รวมเข้าไปใน $\lambda$ ได้) นี่คือทางลัดในขั้นที่ 4 ในภาษา matrix ทุกแถวของ $\Sigma w$ ต้องเท่ากัน

แก้ได้ $w=\lambda\Sigma^{-1}\mathbf1$ แล้วใช้ $\mathbf1^{\mathsf T}w=1$ ได้ $\lambda A=1$ คือ $\lambda=1/A$ variance ที่จุดนั้นคือ $w^{\mathsf T}\Sigma w=\lambda\,\mathbf1^{\mathsf T}w=\lambda=1/284.1716=0.003519$ ตรงกับที่หาด้วยมือในขั้นที่ 3 ถ้าเพิ่มข้อบังคับข้อที่สอง ให้ผลตอบแทนถึงเป้า $\mu^{\mathsf T}w=m$ ก็ได้ระบบสมการเชิงเส้นที่มีตัวแปร $d+2$ ตัว (น้ำหนัก $d$ ตัวกับตัวคูณ Lagrange สองตัว) ผลคือสูตรของ frontier $\sigma^2=(Am^2-2Bm+C)/D$ ซึ่งหน้า Markowitz portfolio selection พิสูจน์ไว้ โดย $B=\mathbf1^{\mathsf T}\Sigma^{-1}\mu$, $C=\mu^{\mathsf T}\Sigma^{-1}\mu$ และ $D=AC-B^2$ ขั้นที่ 9 จะใช้สูตรนี้

เมื่อมีเงินสด น้ำหนักเงินสดคือส่วนที่เหลือ $1-\mathbf1^{\mathsf T}w$ เงินสดไม่แกว่ง จึงไม่โผล่ใน variance คะแนน $U$ คือดอกเบี้ยเงินสด บวกผลตอบแทนที่ได้เกินเงินสด ลบค่าปรับ $\tfrac\gamma2w^{\mathsf T}\Sigma w$ โดย $\gamma$ ใหญ่แปลว่ากลัวความเสี่ยงมาก ตั้ง gradient ของ $U$ เป็นศูนย์ได้ $w^*$ จุดสำคัญคือ $\gamma$ อยู่ข้างหน้าเป็นตัวคูณเท่านั้น

ดังนั้นถ้าหาร $w^*$ ด้วยผลรวมของมันเอง ตัวคูณ $1/\gamma$ ที่อยู่ทั้งเศษและส่วนจะตัดกัน ได้ $w_{\text{tan}}$ ที่รวมเป็นหนึ่ง แปลว่าส่วนผสมเสี่ยงไม่ขึ้นกับว่าใครกลัวความเสี่ยงแค่ไหน คนกลัวมากแค่ถือส่วนผสมนี้น้อยลงแล้วถือเงินสดมากขึ้น นี่คือ one-fund theorem ทิศ $\Sigma^{-1}(\mu-r_f\mathbf1)$ ยังเป็นทิศเดียวกับขนาดเดิมพันของ Kelly แบบหลายสินทรัพย์ โดย Kelly คือกรณี $\gamma=1$ พอดี

อีกผลหนึ่งที่ตามมา น้ำหนักบน frontier เป็นฟังก์ชันเส้นตรงของเป้า $m$ พอร์ตบนเส้นทุกพอร์ตจึงเป็นส่วนผสมของสองพอร์ตบนเส้นใดก็ได้ (two-fund theorem) แปลว่ามีกองทุนแค่สองกองก็สร้างทุกพอร์ตบน frontier ได้

ขั้นที่ 6 — พอร์ต tangency ของ \$10 ล้าน และค่าของการกระจาย

ตอนนี้ตอบคำถามของคนที่สองได้แล้ว พอร์ตเสี่ยงไหนให้ Sharpe สูงสุด สิ่งที่ใช้มีสองอย่าง

  • $\Sigma^{-1}$ จากขั้นที่ 5
  • ผลตอบแทนที่ได้เกินเงินสด $\mu-r_f\mathbf1$ ของหุ้นคือ $9\%-2\%=7\%$ ของพันธบัตรคือ $3.5\%-2\%=1.5\%$

ทำตามสูตร tangency สองจังหวะ คือคูณ $\Sigma^{-1}$ เข้ากับ vector ส่วนเกิน ได้ $u$ แล้วหาร $u$ ด้วยผลรวมของมัน ให้น้ำหนักรวมเป็นหนึ่ง จากนั้นคิดผลตอบแทนคาดหวัง ความผันผวน และ Sharpe ของพอร์ตที่ได้

\[ \begin{aligned} u_1&=25.5754(0.070)-12.7877(0.015)\\ &=1.79028-0.19182\approx1.5985,\\ u_2&=-12.7877(0.070)+284.1716(0.015)\\ &=-0.89514+4.26257\approx3.3674,\\ w_{\text{tan}}&=\frac{(1.5985,\ 3.3674)}{1.5985+3.3674}\\ &=\frac{(1.5985,\ 3.3674)}{4.9659}\approx(0.3219,\ 0.6781),\\ \mu_{\text{tan}}&=\mu_B+w_E(\mu_E-\mu_B)\\ &=0.035+0.055(0.3219)\approx5.27\%,\\ \sigma^2_{\text{tan}}&=w_E^2\sigma_E^2+w_B^2\sigma_B^2\\ &\quad+2w_Ew_B\sigma_{EB}\\ &=0.0041445+0.0016554\\ &\quad+0.0007858=0.0065857,\\ \sigma_{\text{tan}}&=\sqrt{0.0065857}\approx8.12\%,\\ \mathrm{SR}&=\frac{\mu_{\text{tan}}-r_f}{\sigma_{\text{tan}}}\\ &=\frac{0.052704-0.02}{0.081152}=0.4030,\\ \mathrm{SR}^2&=u^{\mathsf T}(\mu-r_f\mathbf1)\\ &=1.5985(0.07)+3.3674(0.015)\\ &=0.16240,\\ \frac{\sigma_E}{\sigma_{\text{tan}}}&=\frac{0.20}{0.081152}\approx2.4645. \end{aligned} \]

คำตอบ: $u_1$ กับ $u_2$ เป็นบวกทั้งคู่ จึงไม่ต้อง short เงิน \$10 ล้าน แบ่งได้ดังนี้

  • หุ้น $0.3218884\times\$10{,}000{,}000=\$3{,}218{,}884$
  • พันธบัตร $0.6781116\times\$10{,}000{,}000=\$6{,}781{,}116$

พอร์ตนี้มีผลตอบแทนคาดหวัง 5.27% ความผันผวน 8.12% และ Sharpe 0.4030 สูงกว่าหุ้นล้วน (0.35) อยู่ $0.4030/0.35-1\approx15.1\%$ ใน variance สามก้อน ก้อนแรกมาจากหุ้น ก้อนที่สองมาจากพันธบัตร ก้อนที่สามคือพจน์ไขว้

บรรทัด $\mathrm{SR}^2$ เป็นทางตรวจที่ไม่ต้องหาน้ำหนัก ทำไมใช้ได้ Sharpe ไม่เปลี่ยนเมื่อคูณน้ำหนักทุกตัวด้วยค่าคงที่เดียวกัน เพราะทั้งส่วนเกินและความผันผวนโตเท่ากัน เราจึงคิด Sharpe จาก $u$ ตรง ๆ ได้ และ $u$ ถูกสร้างมาให้ $\Sigma u=\mu-r_f\mathbf1$ variance ของ $u$ จึงเป็น $u^{\mathsf T}\Sigma u=u^{\mathsf T}(\mu-r_f\mathbf1)$ เท่ากับส่วนเกินของ $u$ พอดี Sharpe ยกกำลังสองคือส่วนเกินยกกำลังสองหารด้วย variance จึงเหลือ $u^{\mathsf T}(\mu-r_f\mathbf1)$ รากที่สอง $\sqrt{0.16240}=0.4030$ ตรงกับที่คิดตรง ๆ

บรรทัดสุดท้ายตอบว่า ถ้าอยากแกว่งเท่าหุ้นล้วน (20%) ต้องถือพอร์ต tangency กี่เท่าของเงินตัวเอง คำตอบคือ 2.46 เท่า คือใช้เงินตัวเอง 1 ส่วนกับเงินกู้อีก 1.46 ส่วนที่ดอกเบี้ย 2% ได้ผลตอบแทนคาดหวัง $0.02+0.4030\times0.20=10.06\%$ มากกว่าหุ้นล้วนที่ได้ 9% ตัวเลขนี้สมมติว่ากู้ได้ที่ดอกเบี้ยเดียวกับเงินฝาก

ทำไมพันธบัตรได้น้ำหนักมากทั้งที่ Sharpe ต่ำกว่าหุ้น เพราะมันแกว่งน้อยและเกี่ยวกับหุ้นน้อย มันจึงหักความผันผวนของหุ้นได้มาก ความผันผวนที่หายไปมีค่ามากกว่าผลตอบแทนที่เสียไป

ตรวจเองใน 10 วินาที: $1.5985+3.3674=4.9659$ และ $1.5985/4.9659=0.3219$ ส่วน $(5.27-2)/8.12=0.403$

ขั้นที่ 7 — ค่าเฉลี่ยผิดนิดเดียว น้ำหนักขยับเท่าไร

ทุกอย่างข้างบนสมมติว่าเรารู้ $\mu$ และ $\Sigma$ จริง แต่ในชีวิตจริงไม่มีใครรู้ ค่าเฉลี่ย 9% ของหุ้นเป็นแค่ค่าประมาณจากข้อมูลย้อนหลัง ค่าประมาณนี้คลาดได้แค่ไหน วัดด้วย standard error คือความผันผวนของค่าเฉลี่ยที่ประมาณได้ ถ้ามีข้อมูลรายปี $n$ ปี standard error คือ $\sigma/\sqrt n$

ข้อมูล 25 ปีให้ $20\%/\sqrt{25}=20\%/5=4\%$ แปลว่าค่าเฉลี่ยจริงอาจห่างจาก 9% ได้ราว 4 จุดโดยไม่มีอะไรผิดปกติ ขั้นนี้มีสองการทดลองเพื่อดูว่าความคลาดขนาดนี้ทำอะไรกับคำตอบ

  • การทดลองแรก: เปลี่ยนค่าเฉลี่ยหุ้นที่ป้อนเข้าไป เรียกว่า $m$ จาก 8% เป็น 10% โดยตรึงทุกอย่างอื่นไว้ แล้วดูว่าน้ำหนักหุ้นของพอร์ต tangency ขยับเท่าไร
  • การทดลองที่สอง: สมมติสองสินทรัพย์ที่เหมือนกันทุกประการ ค่าเฉลี่ยจริง 6% ความผันผวน 20% correlation ศูนย์ แต่ค่าที่ประมาณได้คลาดไปข้างละ 2% เป็น 8% กับ 4% เงินสดยังได้ 2%
\[ \begin{aligned} u&=\Sigma^{-1}\begin{bmatrix}m-0.02\\0.015\end{bmatrix},\quad w_E(m)=\frac{u_1}{u_1+u_2},\\ m=8\%&:\ u_1=25.5754(0.06)-0.19182=1.34270,\\ &\quad\ u_2=-12.7877(0.06)+4.26257=3.49531,\\ &\quad\ w_E=\frac{1.34270}{4.83801}=27.75\%,\\ m=10\%&:\ u_1=25.5754(0.08)-0.19182=1.85421,\\ &\quad\ u_2=-12.7877(0.08)+4.26257=3.23955,\\ &\quad\ w_E=\frac{1.85421}{5.09376}=36.40\%,\\ \frac{36.40-27.75}{10-8}&=4.325,\\ \Sigma&=0.04I,\quad \Sigma^{-1}=25I,\\ u_{\text{est}}&=25\begin{bmatrix}0.06\\0.02\end{bmatrix}=\begin{bmatrix}1.5\\0.5\end{bmatrix},\quad w_{\text{est}}=\begin{bmatrix}0.75\\0.25\end{bmatrix},\\ \mathrm{SR}_{\text{est}}&=\sqrt{1.5(0.06)+0.5(0.02)}\\ &=\sqrt{0.1}=0.3162,\\ \mathrm{SR}_{\text{true}}&=\frac{0.04}{0.2/\sqrt2}=\frac{0.04}{0.1414}=0.2828,\\ \sigma(w_{\text{est}})&=0.2\sqrt{0.75^2+0.25^2}=15.81\%,\\ \mathrm{SR}_{\text{real}}&=\frac{0.04}{0.1581}=0.2530. \end{aligned} \]

ในการทดลองแรก ตัวเลข 0.19182 กับ 4.26257 คือ $12.7877\times0.015$ กับ $284.1716\times0.015$ จากขั้นที่ 6 ซึ่งไม่เปลี่ยน เพราะส่วนเกินของพันธบัตรยังเป็น 1.5% เหมือนเดิม ผลคือค่าเฉลี่ยของหุ้นคลาด 1 จุด น้ำหนักหุ้นขยับราว 4.3 จุด กับเงิน \$10 ล้าน คือเงิน $0.043\times\$10{,}000{,}000\approx\$430{,}000$ ย้ายข้าง เพราะตัวเลขตัวเดียวคลาด และความคลาดที่เกิดได้จริง (standard error 4%) ใหญ่กว่า 1 จุดถึงสี่เท่า

การทดลองที่สองแสดงว่าทำไมมันแย่กว่าแค่ “น้ำหนักแกว่ง” ในตารางข้างบน $I$ คือ identity matrix ($\Sigma=0.04I$ เพราะ variance ของแต่ละตัวคือ $0.2^2=0.04$ และ covariance เป็นศูนย์) คำตอบที่ถูกคือถือครึ่งต่อครึ่ง เพราะสองตัวเหมือนกันทุกอย่าง แต่ optimizer (โปรแกรมที่หาน้ำหนักที่ดีที่สุดจากตัวเลขที่ป้อน) เห็นตัวแรกดีกว่า จึงถือ 75/25

ความคลาดของสองค่าเฉลี่ยรวมกันเป็นศูนย์ (+2% กับ −2%) ตัวประมาณจึง “ถูกโดยเฉลี่ย” แต่ optimizer ไม่ได้ใช้ค่าเฉลี่ยของความคลาด มันเทน้ำหนักไปที่ตัวที่ดูดีที่สุด ซึ่งก็คือตัวที่ถูกประมาณสูงเกินจริง

ผลคือ Sharpe สามตัวที่ไม่เท่ากัน ตัวแรกคือ Sharpe ที่เชื่อ 0.3162 คิดด้วยทางลัด $\mathrm{SR}^2=u^{\mathsf T}(\mu-r_f\mathbf1)$ ของขั้นที่ 6 ตัวที่สองคือ Sharpe ที่ดีที่สุดที่เป็นไปได้จริง 0.2828 จากการถือครึ่งต่อครึ่ง ตัวที่สามคือ Sharpe ที่ได้จริงจากพอร์ต 75/25 เท่ากับ 0.2530 พอร์ต 75/25 ได้ส่วนเกินจริง $0.75(4\%)+0.25(4\%)=4\%$ แต่แกว่งมากกว่า Sharpe ที่ได้จริงต่ำกว่าที่ดีที่สุดเสมอ ส่วน Sharpe ที่เชื่อมักสูงเกินจริง เพราะ optimizer เลือกตัวที่ถูกประมาณสูงเกิน

ความคลาด 2% ในตัวอย่างนี้เล็กกว่า standard error 4% ด้วยซ้ำ และสองสินทรัพย์ยังพอรับได้ แต่ถ้ามีสินทรัพย์หลายตัวที่คล้ายกัน จะมีพอร์ตแบบ “ซื้อตัวหนึ่ง แล้ว short อีกตัวที่คล้ายกัน” ซึ่งแทบไม่แกว่งเลย นี่คือทิศใน $\Sigma$ ที่ variance เล็กมาก $\Sigma^{-1}$ หารด้วย variance ที่เล็กนั้น ความคลาดเล็ก ๆ ของค่าเฉลี่ยในทิศนั้นจึงถูกขยายจนน้ำหนักสุดโต่ง Richard Michaud จึงเรียก mean-variance optimizer ว่า “error maximizer” คือเครื่องขยายความคลาด

ขั้นที่ 8 — สามสินทรัพย์ที่กลับ matrix ได้ด้วยมือ

สองสินทรัพย์ยังไม่ได้แสดงพลังของ matrix เต็มที่ ขั้นนี้ลองสามสินทรัพย์ ตัวเลขเป็นตัวอย่างสมมติที่เลือกมาให้กลับ matrix ด้วยมือได้

  • ผลตอบแทนคาดหวัง $\mu=(6\%,\ 2\%,\ 4\%)$ ต่อปี
  • covariance $\Sigma=0.002M$ โดย $M$ เป็น matrix เลขจำนวนเต็มข้างล่าง ความผันผวนคือรากที่สองของช่องแนวทแยง $\sqrt{0.002\times4}=8.94\%$, $\sqrt{0.002\times1}=4.47\%$ และ $\sqrt{0.002\times4}=8.94\%$
  • เงินสดได้ $r_f=1\%$ ส่วนเกินจึงเป็น $\mu-0.01\mathbf1=(0.05,\ 0.01,\ 0.03)$

แผนคือดึงตัวคูณ 0.002 ออกก่อน กลับ $M$ ด้วยมือ แล้วใช้สูตรพอร์ตเสี่ยงต่ำสุดกับสูตร tangency ของขั้นที่ 5 ตรง ๆ

\[ \begin{aligned} \Sigma&=0.002\,M,\quad M=\begin{bmatrix}4&-1&2\\-1&1&-1\\2&-1&4\end{bmatrix},\\ \det M&=4(4-1)+1(-4+2)+2(1-2)\\ &=12-2-2=8,\\ \Sigma^{-1}&=\frac{1}{0.002(8)}\begin{bmatrix}3&2&-1\\2&12&2\\-1&2&3\end{bmatrix},\\ \Sigma^{-1}\mathbf1&=62.5(4,\ 16,\ 4)\\ &=(250,\ 1{,}000,\ 250),\\ A&=250+1{,}000+250=1{,}500,\\ w_{\text{mv}}&=\frac{(250,\ 1{,}000,\ 250)}{1{,}500}=\big(\tfrac16,\ \tfrac23,\ \tfrac16\big),\\ \sigma_{\text{mv}}&=\sqrt{1/1{,}500}=2.58\%,\\ u&=62.5(0.14,\ 0.28,\ 0.06)\\ &=(8.75,\ 17.5,\ 3.75),\\ \mathbf1^{\mathsf T}u&=8.75+17.5+3.75=30,\\ w_{\text{tan}}&=\tfrac1{30}u\approx(0.2917,\ 0.5833,\ 0.1250),\\ \mathrm{SR}^2&=u^{\mathsf T}(\mu-0.01\mathbf1)\\ &=8.75(0.05)+17.5(0.01)+3.75(0.03)\\ &=0.4375+0.175+0.1125=0.725,\\ \mathrm{SR}&=\sqrt{0.725}\approx0.8515,\\ \mu_{\text{tan}}&=0.2917(6\%)+0.5833(2\%)\\ &\quad+0.125(4\%)=3.4167\%,\\ \sigma_{\text{tan}}&=\frac{\mu_{\text{tan}}-r_f}{\mathrm{SR}}\\ &=\frac{2.4167\%}{0.8515}=2.8382\%. \end{aligned} \]

ทำไม matrix ตัวที่สามถึงเป็นคำตอบ มันคือ adjugate ของ $M$ คือ matrix ของ cofactor ที่สลับแถวกับหลัก ซึ่งคูณกับ $M$ แล้วได้ $\det M$ เท่าของ identity ลองตรวจหนึ่งช่อง แถวแรกของ $M$ คูณหลักแรกของ adjugate ได้ $4(3)+(-1)(2)+2(-1)=8$ ดังนั้น $\Sigma^{-1}$ คือ adjugate หารด้วย $0.002\times8=0.016$ ตัวคูณหน้าจึงเป็น $1/0.016=62.5$

$\Sigma^{-1}\mathbf1$ คือ 62.5 คูณผลรวมของแต่ละแถวของ adjugate ได้ $3+2-1=4$, $2+12+2=16$ และ $-1+2+3=4$ ส่วน $u$ คือ 62.5 คูณ adjugate กับส่วนเกิน เช่นแถวแรก $3(0.05)+2(0.01)-1(0.03)=0.14$ ความผันผวนของพอร์ต tangency ใช้ความหมายของ Sharpe ย้อนกลับ เพราะ Sharpe คือส่วนเกินหารด้วยความผันผวน

พอร์ตเสี่ยงต่ำสุดถือตัวที่สองถึงสองในสาม เพราะมันแกว่งน้อยที่สุด และมี covariance ติดลบกับอีกสองตัว (ช่อง −1 ใน $M$) คือมักเคลื่อนสวนทางกัน ผลตอบแทนคาดหวังของพอร์ตนี้คือ $\tfrac16(6\%)+\tfrac23(2\%)+\tfrac16(4\%)=3\%$

พอร์ต tangency ได้ Sharpe 0.8515 ส่วนตัวที่ดีที่สุดเมื่อถือเดี่ยว ๆ คือตัวแรก ได้ $(6\%-1\%)/8.94\%=0.559$ การผสมจึงเพิ่ม Sharpe ได้ $0.8515/0.559\approx1.52$ เท่า คือสูงขึ้น 52%

ขั้นที่ 9 — เพดานความผันผวน 5%: มีเงินสดกับไม่มีเงินสด

ทีนี้ใส่ข้อบังคับแบบที่โต๊ะลงทุนใช้จริง สมมติว่ากองทุนมีกฎว่าความผันผวนของพอร์ตห้ามเกิน 5% ต่อปี ภายใต้กฎนี้ ผลตอบแทนคาดหวังสูงสุดคือเท่าไร คำตอบขึ้นกับว่าใช้เงินสดได้ไหม

  • ถ้าฝากหรือกู้เงินสดได้ที่ 1% คำตอบอยู่บนเส้นตรงจากเงินสดผ่านพอร์ต tangency
  • ถ้าไม่มีเงินสด คำตอบอยู่บนแขนบนของ frontier ต้องแก้สูตร frontier $\sigma^2=(Am^2-2Bm+C)/D$ หาเป้า $m$ ที่ทำให้ $\sigma=5\%$

สูตร frontier ต้องใช้ตัวเลขช่วย $B$, $C$ และ $D$ จึงหาสามตัวนี้ก่อน แล้วแก้สมการกำลังสองหา $m$ จากนั้นหาน้ำหนักด้วยสูตรน้ำหนักบน frontier ซึ่งหน้า Markowitz portfolio selection พิสูจน์ไว้

\[ \begin{aligned} B&=\mathbf1^{\mathsf T}\Sigma^{-1}\mu\\ &=250(0.06)+1{,}000(0.02)+250(0.04)\\ &=15+20+10=45,\\ \Sigma^{-1}\mu&=62.5(0.18,\ 0.44,\ 0.10)\\ &=(11.25,\ 27.5,\ 6.25),\\ C&=\mu^{\mathsf T}\Sigma^{-1}\mu\\ &=0.06(11.25)+0.02(27.5)+0.04(6.25)\\ &=0.675+0.55+0.25=1.475,\\ D&=AC-B^2=2{,}212.5-2{,}025=187.5,\\ 0&=Am^2-2Bm+(C-D\sigma^2),\\ B^2-A(C-D\sigma^2)&=D(A\sigma^2-1),\\ m&=\frac{B+\sqrt{D(A\sigma^2-1)}}{A},\\ \sigma=5\%&:\ A\sigma^2-1=1{,}500(0.0025)-1=2.75,\\ m&=\frac{45+\sqrt{187.5(2.75)}}{1{,}500}\\ &=\frac{45+22.707}{1{,}500}\approx4.51\%,\\ w(m)&=\frac{(C-Bm)\Sigma^{-1}\mathbf1+(Am-B)\Sigma^{-1}\mu}{D},\\ C-Bm&=1.475-45(0.045138)=-0.55622,\\ Am-B&=22.707,\\ w_1&=\frac{-0.55622(250)+22.707(11.25)}{187.5}\approx62.1\%,\\ w_2&=\frac{-0.55622(1{,}000)+22.707(27.5)}{187.5}\approx36.4\%,\\ w_3&=\frac{-0.55622(250)+22.707(6.25)}{187.5}\approx1.5\%,\\ m_{\text{cash}}&=r_f+\sigma\,\mathrm{SR}\\ &=0.01+0.05(0.8515)\approx5.26\%,\\ \frac{\sigma}{\sigma_{\text{tan}}}&=\frac{0.05}{0.028382}\approx1.76. \end{aligned} \]

สูตรของ $m$ คือสูตรรากของสมการกำลังสองธรรมดา จังหวะที่ต้องดูคือตัวใต้ราก $B^2-A(C-D\sigma^2)=B^2-AC+AD\sigma^2$ และเพราะ $B^2-AC=-D$ ตามนิยามของ $D$ ตัวใต้รากจึงเหลือ $D(A\sigma^2-1)$ ซึ่งเป็นศูนย์พอดีที่ $\sigma^2=1/A$ คือที่พอร์ตเสี่ยงต่ำสุด เราเลือกเครื่องหมายบวกเพราะต้องการแขนบน ซึ่งได้ผลตอบแทนมากกว่าที่ความผันผวนเท่ากัน ตัวเลข $\Sigma^{-1}\mu$ คิดแบบเดียวกับ $u$ ในขั้นที่ 8 คือ 62.5 คูณ adjugate กับ $\mu$ เช่นแถวแรก $3(0.06)+2(0.02)-1(0.04)=0.18$

ไม่มีเงินสด ได้ผลตอบแทนคาดหวัง 4.51% ด้วยน้ำหนัก 62.1%, 36.4% และ 1.5% ถ้ากู้ได้ที่ดอกเบี้ยเงินสด 1% จะถือพอร์ต tangency 1.76 เท่าของเงินตัวเอง คือกู้เพิ่มอีก 76% ของทุน ได้ 5.26% สูงกว่า $5.257\%-4.514\%\approx0.74$ จุดที่ความผันผวนเท่ากัน ทั้งหมดนี้เป็นตัวเลขของแบบจำลอง ซึ่งเชื่อค่าเฉลี่ยที่ป้อนเข้าไปเต็มที่

ถ้าเพดานหลวมเกินไป ก็เท่ากับไม่มีเพดาน ลองตั้งเพดานไว้ที่ 85.94% และให้ short ได้ไม่จำกัด สูตรเดียวกันให้ $m=(45+\sqrt{187.5(1{,}500\times0.8594^2-1)})/1{,}500=(45+455.56)/1{,}500\approx33.37\%$ ด้วยน้ำหนัก 928%, −541% และ −287% คือ short ตัวที่สองกับตัวที่สาม แล้วเอาเงินไปซื้อตัวแรกเกือบสิบเท่าของทุน ไม่มีใครถือพอร์ตแบบนี้จริง

ตัวอย่างสุดท้ายใช้ข้อมูลจริงชุดหนึ่ง แต่ละกลุ่มคือดัชนีที่รวมสินทรัพย์ประเภทเดียวกันไว้ ค่าเฉลี่ยคือผลตอบแทนเฉลี่ยต่อปีที่ประมาณจากข้อมูลย้อนหลังช่วงหนึ่ง หุ้นแบบโต (growth) คือหุ้นของบริษัทที่โตเร็วและราคาแพงเมื่อเทียบกับกำไร หุ้นแบบคุณค่า (value) คือหุ้นที่ราคาถูกเมื่อเทียบกับกำไรหรือทรัพย์สิน เงินสดได้ 1.5% หลักขวาสุดจึงเป็นค่าเฉลี่ยลบ 1.5 เช่น $3.15-1.5=1.65$

covariance matrix ของแปดกลุ่มเรียกว่า $V$ ตามไฟล์ข้อมูล มันทำหน้าที่เดียวกับ $\Sigma$ ข้างบน matrix ขนาด 8×8 กลับด้วยมือไม่ไหว จึงให้คอมพิวเตอร์แก้สมการ $Vz=\hat\mu$ หา $z$ ซึ่งก็คือ $u$ ของขั้นที่ 6 คอมพิวเตอร์ให้ตัวเลขสามตัวที่ใช้ต่อ

  • ผลรวม $\mathbf1^{\mathsf T}z=1{,}364.93$
  • ช่องแรก $z_1=1{,}700.78$
  • ส่วนเกินของพอร์ต tangency $\hat\mu_s=s^{*\mathsf T}\hat\mu=4.2267\%$ โดย $s^*=z/\mathbf1^{\mathsf T}z$ คือน้ำหนักของพอร์ต tangency

ที่เหลือคิดด้วยมือจากสามตัวนี้ได้

\[ \begin{aligned} s^*_1&=\frac{z_1}{\mathbf1^{\mathsf T}z}\approx\frac{1{,}700.78}{1{,}364.93}\approx1.2461,\\ \sigma_s^2&=s^{*\mathsf T}Vs^*=\frac{s^{*\mathsf T}\hat\mu}{\mathbf1^{\mathsf T}z}\\ &\approx\frac{4.2267}{1{,}364.93}\approx0.0030967,\\ \sigma_s&=\sqrt{0.0030967}\approx5.5647\%,\\ \mathrm{SR}&=\frac{\hat\mu_s}{\sigma_s}\approx\frac{4.2267}{5.5647}=0.7595,\\ \beta_1&=\frac{(Vs^*)_1}{\sigma_s^2}=\frac{\hat\mu_1}{\hat\mu_s}\\ &\approx\frac{1.65}{4.2267}\approx0.3904. \end{aligned} \]

ผลคือ $s^*$ ถือพันธบัตรสหรัฐฯ $s^*_1=124.61\%$ คือมากกว่าเงินทุนทั้งหมด และ short หุ้นประเทศพัฒนาแล้ว 33.56% (น้ำหนักของกลุ่มที่ 7 คือ $z_7/\mathbf1^{\mathsf T}z$ จากคอมพิวเตอร์) ทำไม เพราะในช่วงข้อมูลนี้ ค่าเฉลี่ยของหุ้นเกือบทุกกลุ่มติดลบ optimizer เชื่อตัวเลขนั้นตรง ๆ จึง short หุ้นเพื่อเอาเงินไปซื้อพันธบัตรเกินทุน

ถ้าไม่มีเงินสดและตั้งเพดานความผันผวน 100% สูตร frontier แบบขั้นที่ 9 (คิดด้วยคอมพิวเตอร์) ให้ผลตอบแทนคาดหวัง 67.36% ด้วยพันธบัตรสหรัฐฯ 568% และ short หุ้นประเทศพัฒนาแล้ว 865% ไม่มีใครเทรดพอร์ตแบบนี้ ผลตอบแทน 67% ต่อปีมาจากการเชื่อค่าเฉลี่ยติดลบของหุ้นแบบเต็มที่

ทำไม $z$ ถึงเป็นตัวเลขใหญ่ เพราะค่าเฉลี่ยใช้หน่วยเปอร์เซ็นต์ (1.65 แทน 0.0165) แต่ $V$ ใช้ทศนิยม $z$ จึงใหญ่กว่าปกติ 100 เท่า การหารด้วย $\mathbf1^{\mathsf T}z$ ตัดตัวคูณนี้ทิ้ง $s^*$ จึงถูกต้อง และเพราะ $Vz=\hat\mu$ variance ของพอร์ตจึงเท่ากับส่วนเกินหารด้วย $\mathbf1^{\mathsf T}z$ โดยไม่ต้องเห็น $V$ เลย เปอร์เซ็นต์ในเศษกับตัวคูณ 100 ในส่วนตัดกัน variance จึงออกมาเป็นทศนิยมตามปกติ

บรรทัด $\beta$ คือการตรวจที่มีความหมาย beta ของกลุ่มที่ $i$ เทียบพอร์ต $s^*$ คือ covariance ของกลุ่มนั้นกับพอร์ต $(Vs^*)_i$ หารด้วย variance ของพอร์ต มันบอกว่ากลุ่มนั้นขยับตามพอร์ตกี่เท่า เพราะ $Vs^*=\hat\mu/\mathbf1^{\mathsf T}z$ และ $\sigma_s^2=\hat\mu_s/\mathbf1^{\mathsf T}z$ ตัว $\mathbf1^{\mathsf T}z$ จึงตัดกัน เหลือ beta เท่ากับ $\hat\mu_i/\hat\mu_s$ พลิกกลับได้ว่า beta คูณส่วนเกินของพอร์ต ได้ส่วนเกินของกลุ่มนั้นพอดี $0.3904\times4.2267=1.65$

ถ้าทุกคนถือพอร์ต tangency เดียวกัน พอร์ตนั้นก็คือพอร์ตตลาด และสมการ “ส่วนเกินของกลุ่ม = beta × ส่วนเกินของตลาด” ก็คือโครงของ CAPM

สุดท้าย ตรวจ one-fund theorem ด้วยตัวเลขจริง สมมติผู้ลงทุนให้คะแนน $U=R_p-\tau\sigma_p^2$ โดย $\tau=1$ และวัดทั้งสองตัวเป็นหน่วยเปอร์เซ็นต์ variance หน่วยเปอร์เซ็นต์ยกกำลังสองคือ $10{,}000V$ ตั้ง gradient เป็นศูนย์ได้ $\hat\mu=2\tau(10{,}000V)w$ คือ $w=z/20{,}000$ น้ำหนักเสี่ยงรวมกันได้ $1{,}364.93/20{,}000=0.068246$ คือถือสินทรัพย์เสี่ยง 6.82% และเงินสด 93.18% เมื่อหารน้ำหนักเสี่ยงด้วย 0.068246 ก็ได้ $s^*$ เดิมทุกตัว ส่วนผสมเสี่ยงไม่เปลี่ยน เปลี่ยนแค่สัดส่วนกับเงินสด

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

เฉลี่ยความผันผวนตามน้ำหนัก: คนมักคิดว่าพอร์ตครึ่งต่อครึ่งเสี่ยงเท่าค่าเฉลี่ยของสองตัว ค่าที่ผิดคือ $(20\%+6\%)/2=13\%$ ค่าที่ถูกเมื่อ $\rho=0.15$ คือ $\sqrt{0.0109+0.006\times0.15}=\sqrt{0.0118}=10.86\%$ ตัวเลข 13% ถูกเฉพาะเมื่อ $\rho=1$

ใส่ correlation แทน covariance ในตาราง: ถ้าใส่ 0.15 ลงช่องนอกแนวทแยงแทน 0.0018 จะได้ determinant $0.04(0.0036)-0.15^2=0.000144-0.0225=-0.022356$ ติดลบ ค่าที่ถูกคือ $0.04(0.0036)-0.0018^2=0.00014076$ เป็นบวก covariance matrix 2×2 จริงมี determinant $\sigma_E^2\sigma_B^2(1-\rho^2)$ ซึ่งติดลบไม่ได้ ตารางที่ผิดจึงไม่ใช่ covariance ที่เป็นไปได้ และ optimizer จะหาพอร์ตที่ “variance ติดลบ” ให้ ซึ่งไม่มีความหมาย

เชื่อค่าเฉลี่ยที่ประมาณมา: ค่าเฉลี่ยหุ้นคลาด 1 จุด น้ำหนักหุ้นขยับ $(36.40-27.75)/(10-8)\approx4.3$ จุด สองสินทรัพย์ที่เหมือนกันถูกถือ 75/25 แทน 50/50 เพราะความคลาดแค่ 2% และในแปดกลุ่มได้พอร์ตที่ถือพันธบัตร 568% กับ short หุ้น 865% optimizer เทน้ำหนักไปที่ตัวที่ค่าเฉลี่ยถูกประมาณสูงเกินเสมอ

ตัดน้ำหนักติดลบทิ้งแล้วปรับให้รวมเป็นหนึ่ง: เมื่อห้าม short คนมักเอาคำตอบแบบ short ได้ ตัดตัวที่ติดลบเป็นศูนย์ แล้วหารให้รวมเป็นหนึ่ง วิธีนี้ไม่ได้คำตอบที่ดีที่สุด ดูสามสินทรัพย์ของขั้นที่ 8 ที่เพดานความผันผวน 8% สูตรของขั้นที่ 9 ให้ $m=(45+\sqrt{187.5(1{,}500\times0.0064-1)})/1{,}500=(45+40.16)/1{,}500=5.68\%$ ด้วยน้ำหนักแบบ short ได้ $(96.98\%,\ 13.13\%,\ -10.10\%)$ ตัดตัวที่สามทิ้งแล้วหารด้วย $0.9698+0.1313=1.1011$ ได้ $(88.08\%,\ 11.92\%,\ 0)$

เมื่อถือแค่ตัวที่หนึ่งเป็นสัดส่วน $w$ กับตัวที่สองเป็น $1-w$ จาก $M$ ของขั้นที่ 8 ได้ variance $0.002\,(4w^2+(1-w)^2-2w(1-w))=0.002\,(7w^2-4w+1)$ และผลตอบแทนคาดหวัง $2\%+4\%\,w$ ใช้สองสูตรนี้เทียบคำตอบที่ผิดกับที่ถูก ให้ $w_{\text{clip}}$ คือน้ำหนักตัวที่หนึ่งจากวิธีตัดทิ้ง และ $w_{\text{KKT}}$ คือน้ำหนักจากการแก้แบบห้าม short ที่ถูกต้อง (แก้ด้วย KKT conditions หรือคอมพิวเตอร์ ได้ว่าตัวที่สามเป็นศูนย์ และต้องใช้เพดาน 8% ให้เต็ม)

\[ \begin{aligned} w_{\text{clip}}&=0.8808,\\ \sigma^2&=0.002\,(7(0.8808)^2-4(0.8808)+1)\\ &=0.002(2.9074)=0.005815,\\ \sigma&=\sqrt{0.005815}=7.63\%,\\ \mu_p&=2\%+4\%(0.8808)=5.52\%,\\ 0.002\,(7w^2-4w+1)&=0.08^2=0.0064,\\ 7w^2-4w-2.2&=0,\\ w_{\text{KKT}}&=\frac{4+\sqrt{16+61.6}}{14}=0.9149,\\ \mu_p&=2\%+4\%(0.9149)=5.66\%. \end{aligned} \]

วิธีตัดทิ้งได้ 5.52% ที่ความผันผวนแค่ 7.63% คือใช้งบความเสี่ยงไม่เต็ม คำตอบที่ถูกได้ 5.66% ข้อห้าม short ยังทำให้คำตอบกระโดดได้ เมื่อค่าที่ป้อนเปลี่ยนนิดเดียวจนมีสินทรัพย์ตัวใหม่เข้าหรือออกจากพอร์ต

ใช้ทำอะไรบนโต๊ะจริง

ปัญหาหลักบนโต๊ะจริงคือจำนวนตัวเลขที่ต้องประมาณ covariance matrix ของ $d$ สินทรัพย์มีตัวเลขที่ไม่ซ้ำกัน $d(d+1)/2$ ตัว คือแนวทแยง $d$ ตัว บวกครึ่งหนึ่งของช่องนอกแนวทแยง เพราะ matrix สมมาตร

  • แปดกลุ่มสินทรัพย์มี $8\times9/2=36$ ตัว บวกค่าเฉลี่ยอีก 8 ตัว
  • หุ้น 500 ตัวมี $500\times501/2=125{,}250$ ตัว
  • ข้อมูลรายเดือนห้าปีมีแค่ $5\times12=60$ แถว

ตัวเลขที่ต้องประมาณจึงมากกว่าข้อมูลที่มีหลายเท่า ทุกโต๊ะจึงทำอย่างน้อยหนึ่งอย่างต่อไปนี้

  • ใส่เพดานน้ำหนักของแต่ละตัว หรือเพดาน leverage (สัดส่วนเงินกู้ต่อทุน) เพื่อจำกัดความเสียหายจากค่าที่คลาด
  • ดึงค่าเฉลี่ยของแต่ละตัวเข้าหาค่าเฉลี่ยรวม และดึง covariance เข้าหารูปที่ง่ายกว่า (Ledoit–Wolf shrinkage)
  • เริ่มจากพอร์ตตลาด แล้วผสมมุมมองของตัวเองเข้าไปทีละน้อย (Black–Litterman)

พอร์ตเสี่ยงต่ำสุดไม่ต้องใช้ $\mu$ จึงประมาณได้นิ่งที่สุด ในทางปฏิบัติมันมักทำผลงานได้ดีกว่าที่ทฤษฎีคาด เพราะหลบความคลาดของค่าเฉลี่ยไปได้ทั้งหมด อีกเรื่องที่ต้องใส่ในโจทย์คือต้นทุนซื้อขาย ค่าประมาณขยับทุกเดือน ถ้าปรับพอร์ตตามทุกครั้งก็เสียค่าซื้อขายทุกครั้ง (mean-variance with transaction costs)

โจทย์ตรวจความเข้าใจ

1. ทีมของคุณถือสินทรัพย์สองตัว ไม่มีเงินสด ตัวแรกแกว่งแรง ความผันผวน $\sigma_1=30\%$ ต่อปี ตัวที่สองนิ่งกว่า ความผันผวน $\sigma_2=10\%$ ต่อปี และทั้งสองไม่เกี่ยวกันเลย ($\rho=0$) พอร์ตเสี่ยงต่ำสุดควรถือตัวแรกกี่เปอร์เซ็นต์ และเสี่ยงเท่าไร

เฉลย

ใช้สูตรน้ำหนักของขั้นที่ 4 เมื่อ $\rho=0$ พจน์ที่มี $\rho$ หายไปหมด เหลือแค่ variance ของสองตัว $\sigma_1^2=0.09$ และ $\sigma_2^2=0.01$

\[\begin{aligned}w&=\frac{\sigma_2^2}{\sigma_1^2+\sigma_2^2}=\frac{0.01}{0.09+0.01}=10\%,\\ \sigma_p^2&=w^2\sigma_1^2+(1-w)^2\sigma_2^2\\ &=0.01(0.09)+0.81(0.01)\\ &=0.0009+0.0081=0.009,\\ \sigma_p&=\sqrt{0.009}=9.49\%.\end{aligned}\]

ถือตัวแรก 10% แล้วเสี่ยง 9.49% ต่ำกว่าตัวที่นิ่งกว่าเมื่อถือเดี่ยว ๆ (10%) ทั้งที่ไม่มี correlation ติดลบเลย

2. กลับมาที่เงิน \$10 ล้านของหน้านี้ หุ้นกับพันธบัตรเหมือนเดิมทุกอย่าง แต่ดอกเบี้ยขึ้น เงินสดได้ $r_f=3\%$ แทน 2% พอร์ต tangency เปลี่ยนเป็นอย่างไร

เฉลย

ส่วนเกินเงินสดใหม่คือ $9\%-3\%=6\%$ ของหุ้น และ $3.5\%-3\%=0.5\%$ ของพันธบัตร แล้วทำตามขั้นที่ 6 ทุกจังหวะ

\[\begin{aligned}u_1&=25.5754(0.06)-12.7877(0.005)\\ &=1.5345-0.0639=1.4706,\\ u_2&=-12.7877(0.06)+284.1716(0.005)\\ &=-0.7673+1.4209=0.6536,\\ \mathbf1^{\mathsf T}u&=1.4706+0.6536=2.1242,\\ w_{\text{tan}}&=\frac{(1.4706,\ 0.6536)}{2.1242}=(69.23\%,\ 30.77\%),\\ \mathrm{SR}^2&=1.4706(0.06)+0.6536(0.005)\\ &=0.091504,\quad \mathrm{SR}=0.3025.\end{aligned}\]

หุ้นได้น้ำหนักเพิ่มจาก 32.19% เป็น 69.23% เพราะเงินสดแพงขึ้น พันธบัตรได้เหนือเงินสดแค่ 0.5% จึงเสียน้ำหนักให้หุ้น Sharpe สูงสุดก็ลดลงจาก 0.4030 เหลือ 0.3025

3. บริษัทหนึ่งขายหุ้นของโครงการท่อส่งน้ำมัน ราคาวันนี้หุ้นละ \$875 และคาดว่าจะจ่ายคืนเฉลี่ย \$1,000 ในหนึ่งปี ผลตอบแทนของโครงการมีความผันผวน 40% ต่อปี ในตลาดเดียวกัน เงินสดได้ 5% ส่วนพอร์ตตลาด (ส่วนผสมของสินทรัพย์เสี่ยงทั้งตลาด) มีผลตอบแทนคาดหวัง 17% และความผันผวน 12% ถ้าใช้เส้นตรงจากเงินสดผ่านพอร์ตตลาดเป็นเกณฑ์ โครงการนี้น่าลงทุนไหม

เฉลย

หาผลตอบแทนคาดหวังของโครงการ แล้วเทียบกับสิ่งที่เส้นจากเงินสดให้ที่ความผันผวนเท่ากัน

\[\begin{aligned}\mu_{\text{proj}}&=\frac{1{,}000}{875}-1=14.29\%,\\ \mathrm{SR}_{\text{mkt}}&=\frac{17\%-5\%}{12\%}=1,\\ 5\%+1\times40\%&=45\%.\end{aligned}\]

ถ้าอยากแกว่ง 40% เท่าโครงการ ก็ถือพอร์ตตลาด $40/12\approx3.33$ เท่าของทุนด้วยเงินกู้ ได้ผลตอบแทนคาดหวัง 45% มากกว่าโครงการราว $45/14.29\approx3.1$ เท่า โครงการนี้จึงไม่น่าสนใจถ้าจะถือเดี่ยว ๆ แต่ถ้าจะถือเป็นส่วนเล็กของพอร์ตใหญ่ เกณฑ์ที่ถูกคือ beta ของ CAPM ไม่ใช่ความผันผวนรวม เพราะความเสี่ยงเฉพาะตัวของโครงการกระจายทิ้งได้

const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);
const times = (S, v) => S.map(r => dot(r, v));
// Solve S x = b by Gaussian elimination with partial pivoting (no explicit inverse)
function solve(S, b) {
  const n = S.length, M = S.map((r, i) => [...r, b[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (Math.abs(M[r][c]) > Math.abs(M[p][c])) p = r;
    [M[c], M[p]] = [M[p], M[c]];
    for (let r = c + 1; r < n; r++) { const f = M[r][c] / M[c][c]; for (let k = c; k <= n; k++) M[r][k] -= f * M[c][k]; }
  }
  const x = new Array(n).fill(0);
  for (let r = n - 1; r >= 0; r--) x[r] = (M[r][n] - dot(M[r].slice(r + 1, n), x.slice(r + 1))) / M[r][r];
  return x;
}
const stats = (S, mu, w) => ({w, mean: dot(w, mu), sd: Math.sqrt(dot(w, times(S, w)))});
function minVariance(S, mu) {                    // w = S^-1 1 / A, variance 1/A
  const y = solve(S, S.map(() => 1)), A = y.reduce((a, b) => a + b, 0);
  return {...stats(S, mu, y.map(v => v / A)), A};
}
function tangency(S, mu, rf) {                   // u = S^-1 (mu - rf), scaled to sum 1
  const u = solve(S, mu.map(m => m - rf)), total = u.reduce((a, b) => a + b, 0);
  const s = stats(S, mu, u.map(v => v / total));
  return {...s, u, sharpe: (s.mean - rf) / s.sd};
}
function frontier(S, mu) {                       // A, B, C, D and the top-arm return at a volatility
  const y1 = solve(S, S.map(() => 1)), ym = solve(S, mu);
  const A = y1.reduce((a, b) => a + b, 0), B = dot(mu, y1), C = dot(mu, ym), D = A * C - B * B;
  const weights = m => y1.map((v, i) => ((C - B * m) * v + (A * m - B) * ym[i]) / D);
  return {A, B, C, D, weights, returnAt: sd => (B + Math.sqrt(D * (A * sd * sd - 1))) / A};
}

  • พอร์ตเสี่ยงต่ำสุด (หุ้น 4.5%) เสี่ยง 5.93% ต่ำกว่าพันธบัตรล้วน และใช้แค่ $\Sigma$ ด้วยสูตร $w=\Sigma^{-1}\mathbf1/A$ ซึ่งมี variance $1/A$
  • correlation สูงมากทำให้ตัวหนึ่ง hedge อีกตัวได้ ที่ $\rho=0.8$ การ short หุ้น 24.59% ทำให้เสี่ยงเหลือ 4.61%
