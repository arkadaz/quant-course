14.1 The Replicating Portfolio and the Black–Scholes Partial Differential Equation (PDE)

ราคาของ option คือเงินที่ต้องใช้สร้างมันขึ้นมาเองด้วยหุ้นกับเงินกู้ ไม่ใช่การเดาว่าหุ้นจะขึ้นหรือลง

คุณทำงานที่โต๊ะเทรด option ของธนาคาร (ทีมที่ซื้อขายสัญญาประเภทนี้) วันนี้ลูกค้ามาซื้อ European call จากคุณ European call คือสัญญาที่ให้ผู้ซื้อมีสิทธิ์ (แต่ไม่บังคับ) ซื้อหุ้นจากคุณในราคาที่ตกลงกันไว้ล่วงหน้า ราคานี้เรียกว่า strike และใช้สิทธิ์ได้เฉพาะวันหมดอายุ

ถ้าวันหมดอายุหุ้นแพงกว่า strike ลูกค้าจะใช้สิทธิ์ และคุณต้องจ่ายส่วนต่างนั้น ถ้าหุ้นไม่แพงกว่า ลูกค้าปล่อยสิทธิ์ทิ้ง คุณไม่ต้องจ่ายอะไร เงินที่สัญญาจ่ายในวันหมดอายุเรียกว่า payoff ส่วนเงินค่าสิทธิ์ที่ลูกค้าจ่ายให้คุณตั้งแต่วันนี้เรียกว่า premium

ของที่รู้ (ตัวเลขสมมติ):

  • คุณขาย 100 สัญญา สัญญาละ 100 หุ้น รวม $100\times100=10{,}000$ หุ้น หน้านี้จะเรียกว่า call 10,000 ใบ ใบละหนึ่งหุ้น
  • ราคาหุ้นวันนี้ $S_0=\$100$
  • strike $K=\$105$ วันนี้หุ้นจึงยังต่ำกว่า strike อยู่ \$5
  • อายุสัญญา 3 เดือน คิดเป็นปีได้ $T=3/12=0.25$ ปี
  • ดอกเบี้ย $r=4\%$ ต่อปี คืออัตราที่โต๊ะกู้หรือฝากเงินได้
  • ความผันผวน $\sigma=20\%$ ต่อปี คือขนาดการแกว่งตามปกติของผลตอบแทนหุ้นในหนึ่งปี วัดเป็น SD (standard deviation ดูvariance และ SD)
  • premium ที่รับมา \$2.3909 ต่อหุ้น รวม $2.3909\times10{,}000=\$23{,}909$ (หน้านี้จะคำนวณตัวเลข \$2.3909 นี้ให้ดูเองในขั้นที่ 7)

ความเสี่ยงของคุณคือ ถ้าหุ้นขึ้นแรง คุณต้องจ่ายมาก เทรดเดอร์ฝึกหัดเสนอสองทาง

  • ทาง ก: ซื้อหุ้นมาถือครบ 10,000 หุ้น ถ้าลูกค้าใช้สิทธิ์ก็มีหุ้นส่งให้
  • ทาง ข: ไม่ซื้อเลย เพราะวันนี้หุ้นยังต่ำกว่า strike ลูกค้าน่าจะไม่ใช้สิทธิ์

ถ้าพรุ่งนี้หุ้นขยับ \$1 แต่ละทางขาดทุนได้เท่าไร และคุณควรถือหุ้นกี่หุ้น

ลองตอบก่อนเปิดเฉลย

ผิดทั้งสองทาง ก่อนอื่นต้องรู้ว่าเมื่อหุ้นขยับ \$1 ราคา call ขยับเท่าไร ตัวเลขนี้เรียกว่า delta ขั้นที่ 5 จะแสดงว่ามันคือความชันของราคา call เทียบราคาหุ้น และขั้นที่ 7 จะคำนวณได้ราว \$0.3677 ต่อหุ้น คุณขาย call ไว้บนหุ้น 10,000 หุ้น ราคา call ที่ขยับจึงกระทบคุณ $0.3677\times10{,}000=\$3{,}677$ ต่อการขยับ \$1

ทาง ก ถ้าหุ้นลง \$1 หุ้นที่ถือเสีย $10{,}000\times\$1=\$10{,}000$ ส่วน call ที่ขายไว้ถูกลง คุณจึงได้คืน \$3,677 สุทธิขาดทุน $10{,}000-3{,}677=\$6{,}323$

ทาง ข ถ้าหุ้นขึ้น \$1 call ที่ขายไว้แพงขึ้น คุณขาดทุน \$3,677 และไม่มีหุ้นมาชดเชยเลย

จำนวนที่ทำให้การขยับเล็ก ๆ หักล้างกันพอดี คือถือหุ้นเท่ากับ delta คูณ 10,000 ใช้ delta ละเอียดหกตำแหน่ง 0.367719 จะได้จำนวนหุ้น เงินซื้อหุ้น และเงินที่ต้องกู้

\[\begin{aligned}\text{shares}&=0.367719\times10{,}000\\&\approx3{,}677,\\\text{cost}&=3{,}677.19\times\$100\\&=\$367{,}719,\\\text{loan}&=367{,}719-23{,}909\\&=\$343{,}810.\end{aligned}\]

เงินซื้อหุ้นส่วนหนึ่งมาจาก premium \$23,909 ที่รับมา ส่วนที่ยังขาดต้องกู้ หน้านี้จะสร้างตัวเลขเหล่านี้ขึ้นมาเองทีละขั้น และแสดงว่ามันไม่ขึ้นกับว่าใครเชื่อว่าหุ้นจะขึ้นหรือลง

ภาพรวมก่อนลงสูตร

ถ้าต้องตั้งราคา call วิธีแรกที่นึกออกคือเดาอนาคต เดาว่าวันหมดอายุหุ้นจะอยู่ที่ราคาไหนด้วยโอกาสเท่าไร คำนวณ payoff เฉลี่ยตามโอกาสนั้น แล้วคิดลดกลับเป็นเงินวันนี้ (หักผลของดอกเบี้ยออก)

แต่โอกาสนั้นเป็นของใคร คนที่มองว่าหุ้นจะขึ้นได้ราคาแพง คนที่มองว่าหุ้นจะลงได้ราคาถูก ต่อให้ทุกคนตกลงโอกาสกันได้ แต่ละคนก็ยังกลัวความเสี่ยงไม่เท่ากันอีก วิธีนี้จึงไม่ได้ราคาเดียว

หน้านี้ใช้คำถามใหม่ ถ้าไม่ซื้อ call แต่สร้างของที่จ่ายเงินเหมือน call ขึ้นมาเอง ด้วยหุ้นจำนวนหนึ่งกับเงินสด ต้องใช้เงินเท่าไร (เงินสดเป็นบวกคือฝาก ติดลบคือกู้) พอร์ตแบบนี้เรียกว่า replicating portfolio หรือพอร์ตเลียนแบบ

ถ้าพอร์ตเลียนแบบจ่ายเงินเท่ากับ call ในทุกกรณี ราคา call วันนี้ต้องเท่ากับต้นทุนของพอร์ต เพราะถ้าไม่เท่า คนจะซื้อตัวที่ถูก ขายตัวที่แพง แล้วเก็บส่วนต่างได้ฟรีโดยไม่เสี่ยงเลย การได้เงินฟรีแบบนี้เรียกว่า arbitrage และตลาดไม่ปล่อยให้มันอยู่นาน

รูปด้านล่างคือทั้งหน้าในภาพเดียว แกนนอนคือราคาหุ้น แกนตั้งคือมูลค่า ราคา call ก่อนหมดอายุเป็นเส้นโค้ง แต่มูลค่าพอร์ตเป็นเส้นตรงเสมอ เพราะพอร์ตที่ถือหุ้น $\Delta$ หุ้นกับเงินสด $B$ ดอลลาร์มีค่า $V=\Delta S+B$ เมื่อ $S$ คือราคาหุ้น เส้นตรงจึงแตะเส้นโค้งได้ทีละจุด เราเลือกเส้นตรงที่แตะเส้นโค้งตรงราคาวันนี้ แล้วเปลี่ยนเป็นเส้นใหม่ทุกครั้งที่หุ้นขยับ

หน้านี้เดินตามลำดับนี้

  • ขั้นที่ 1–2: ทำด้วยมือในโลกที่หุ้นพรุ่งนี้มีได้แค่สองราคา แล้วต่อเป็นต้นไม้หลายงวด
  • ขั้นที่ 3–6: ทำเรื่องเดียวกันในเวลาต่อเนื่อง จนได้สมการ Black–Scholes PDE (PDE คือสมการที่ผูกอนุพันธ์ของราคา call เทียบราคาหุ้นและเทียบเวลาไว้ด้วยกัน)
  • ขั้นที่ 7: แก้ PDE ด้วยตัวเลขบนกริด ได้ราคา \$2.3909 ในโจทย์เปิดเรื่อง
  • ขั้นที่ 8–9: ตั้ง hedge ให้ 10,000 call แล้วอ่าน PDE เป็นบัญชีรายวันของโต๊ะ (hedge คือการถือของอีกอย่างไว้ให้กำไรขาดทุนหักล้างกัน)
  • ขั้นที่ 10: จำลองการ hedge ที่ปรับได้เป็นครั้ง ๆ เหมือนของจริง เพื่อดูว่ายังเหลือความเสี่ยงเท่าไร
ศัพท์ที่ใช้ในหัวข้อนี้
Option
สัญญาที่ให้ “สิทธิ์” กับผู้ซื้อ ไม่ใช่ “หน้าที่” ผู้ซื้อจะใช้สิทธิ์เฉพาะตอนที่ได้ประโยชน์ และจ่ายค่าสิทธิ์ให้ผู้ขายตั้งแต่วันแรก
European call
สิทธิ์ซื้อหุ้นที่ราคา strike $K$ ใช้ได้เฉพาะวันหมดอายุ $T$ ถ้าวันนั้นราคาหุ้น $S_T$ สูงกว่า $K$ ผู้ถือใช้สิทธิ์และได้ $S_T-K$ ถ้าไม่สูงกว่าก็ปล่อยทิ้งและได้ศูนย์ รวมเขียนได้ว่า $\max(S_T-K,0)$ ส่วน put คือสิทธิ์ขาย ได้ $\max(K-S_T,0)$ ถ้าใช้สิทธิ์ได้ทุกวันก่อนหมดอายุ เรียกว่า American option
Strike
ราคาที่ตกลงไว้ล่วงหน้าว่าผู้ถือ option ซื้อ (หรือขาย) หุ้นได้ในราคานี้
Payoff
เงินที่ option จ่ายในวันหมดอายุ ขึ้นกับราคาหุ้นวันนั้นอย่างเดียว
Premium
เงินค่าสิทธิ์ที่ผู้ซื้อ option จ่ายให้ผู้ขายวันนี้ ก็คือราคาของ option นั่นเอง
Hedge
การถือของอีกอย่างไว้คู่กัน เพื่อให้กำไรขาดทุนของสองอย่างหักล้างกัน ในหน้านี้ผู้ขาย call ถือหุ้นไว้ เพราะเมื่อหุ้นขึ้น call ที่ขายไว้ทำให้ขาดทุน แต่หุ้นที่ถือทำให้ได้กำไร
Replicating portfolio (พอร์ตเลียนแบบ)
พอร์ตหุ้นกับเงินสดที่มีมูลค่าเท่ากับ option ทุกกรณี มันเปลี่ยนคำถาม “option ควรราคาเท่าไร” ซึ่งต้องเดาอนาคต ให้เป็น “สร้างมันเองต้องใช้เงินเท่าไร” ซึ่งตอบได้จากราคาที่เห็นวันนี้
Self-financing
กติกาว่าหลังตั้งพอร์ตแล้ว ห้ามเติมหรือถอนเงิน จะซื้อหุ้นเพิ่มต้องใช้เงินสดในพอร์ตเอง มูลค่าพอร์ตก่อนซื้อขายจึงเท่ากับหลังซื้อขายเสมอ ถ้าไม่มีกติกานี้ พอร์ตไหนก็ “เลียนแบบ” อะไรก็ได้ ด้วยการแอบเติมเงิน
Delta ($\Delta$)
จำนวนหุ้นที่ต้องถือต่อ option หนึ่งใบ เพื่อให้การขยับของพอร์ตกับของ option หักล้างกันพอดี หน้านี้จะได้ว่ามันเท่ากับความชันของราคา call เทียบราคาหุ้น การถือหุ้นตามจำนวนนี้แล้วปรับไปเรื่อย ๆ เรียกว่า delta hedge
Arbitrage
รายการที่ได้เงินฟรีโดยไม่มีทางขาดทุน มีสองแบบ แบบแรกได้เงินทันทีวันนี้ และอนาคตไม่ติดลบ แบบที่สองไม่ต้องใช้เงินวันนี้ อนาคตไม่ติดลบ และมีโอกาสเป็นบวก หน้านี้ใช้มันพิสูจน์ราคา ถ้าราคาไม่ตรงกับต้นทุนการสร้างซ้ำ จะมีรายการแบบนี้เกิดขึ้น ราคาจึงต้องตรง
Drift ($\mu$) และความผันผวน ($\sigma$)
drift คืออัตราที่ราคาหุ้นคาดว่าจะโตเฉลี่ยต่อปี ความผันผวนคือขนาดการแกว่งตามปกติของผลตอบแทนรอบค่าเฉลี่ยนั้น วัดเป็น SD ต่อปี
โอกาสแบบ risk-neutral
ชุดโอกาสสมมติที่ทำให้หุ้นโตเฉลี่ยเท่าดอกเบี้ยพอดี มันไม่ใช่โอกาสจริง แต่ถ้าใช้มันเฉลี่ย payoff แล้วคิดลดด้วยดอกเบี้ย จะได้ราคาเท่ากับต้นทุนพอร์ตเลียนแบบ ขั้นที่ 1 แสดงว่ามันมาจากไหน
PDE และเงื่อนไขปลายทาง
PDE (partial differential equation) คือสมการที่ผูกอนุพันธ์ย่อยหลายตัวไว้ด้วยกัน ในหน้านี้คืออัตราเปลี่ยนตามเวลา ความชัน และความโค้งของราคา option สมการอย่างเดียวมีคำตอบได้มากมาย ต้องบอกเพิ่มว่าวันหมดอายุราคาเท่ากับ payoff (เงื่อนไขปลายทาง) จึงได้ราคาเดียว
P&L
profit and loss คือกำไรขาดทุนของโต๊ะในช่วงเวลาหนึ่ง

  • ABC ขึ้นด้วยโอกาส 99% แต่ XYZ ขึ้นด้วยโอกาสแค่ 1%
  • call strike $K=\$105$ หมดอายุพรุ่งนี้
  • ดอกเบี้ยข้ามคืนถือเป็นศูนย์ เงิน \$1 วันนี้ยังเป็น \$1 พรุ่งนี้ ตัวคูณเงินฝากจึงเป็น $R=1$

คำถามคือ call บน ABC กับ call บน XYZ ควรราคาต่างกันเท่าไร คนส่วนใหญ่จะตอบว่า call บน ABC ต้องแพงกว่ามาก เพราะ ABC เกือบแน่นอนว่าจะขึ้น

เราจะไม่เดา แต่จะสร้าง call ขึ้นมาเอง ด้วยหุ้น $\Delta$ หุ้นกับเงินสด $B$ ดอลลาร์ (ติดลบคือกู้) ถ้าราคาหุ้นพรุ่งนี้คือ $S_1$ พอร์ตจะมีค่า $\Delta S_1+B$ ส่วน call จ่าย $\max(S_1-105,0)$ ซึ่งเป็น $\max(110-105,0)=5$ ในขาขึ้น และ $\max(90-105,0)=0$ ในขาลง เราต้องการให้พอร์ตจ่ายเท่ากับ call ทั้งสองขา จึงได้สองสมการ

\[ \begin{aligned} 110\Delta+B&=5,\\ 90\Delta+B&=0. \end{aligned} \]

มีตัวไม่รู้สองตัวกับสองสมการ เอาสมการบนลบสมการล่าง $B$ จะหายไป เหลือ $\Delta$ ตัวเดียว แล้วแทนกลับหา $B$ สุดท้ายคิดว่าพอร์ตนี้ต้องใช้เงินวันนี้เท่าไร

\[ \begin{aligned} (110-90)\Delta&=5-0,\\ \Delta&=\frac{5}{20}=0.25,\\ B&=0-90\times0.25=-22.5,\\ V_0&=\Delta S_0+B\\ &=0.25\times100-22.5=2.5. \end{aligned} \]

จำนวนหุ้นคือ “ส่วนต่างของ payoff หารด้วยส่วนต่างของราคาหุ้น” เพราะเมื่อหุ้นเปลี่ยนจาก \$90 เป็น \$110 (ต่างกัน \$20) call จ่ายเพิ่มจาก \$0 เป็น \$5 พอร์ตจึงต้องถือหุ้นจำนวนที่ทำให้มูลค่าเพิ่ม \$5 เมื่อหุ้นขึ้น \$20 คือ $5/20=0.25$ หุ้น ส่วนเงินสดมีหน้าที่ยกหรือกดทั้งเส้นให้ตรงกับ payoff เงินสดที่ติดลบแปลว่าพอร์ตกู้เงินมาซื้อหุ้น

คำตอบ: ถือหุ้น 0.25 หุ้นและกู้ \$22.5 พอร์ตนี้ใช้เงินวันนี้ \$2.5 และพรุ่งนี้จ่ายตรงกับ call ทุกขา ราคา call จึงเป็น \$2.5 ทั้งบน ABC และบน XYZ

ถ้าเฉลี่ย payoff ด้วยโอกาสจริง จะได้ตัวเลขที่ผิดมาก

\[ \begin{aligned} \text{ABC}&:\ 0.99\times5+0.01\times0=\$4.95,\\ \text{XYZ}&:\ 0.01\times5+0.99\times0=\$0.05. \end{aligned} \]

ทำไม \$4.95 ใช้ไม่ได้ ถ้ามีคนยอมซื้อ call บน ABC ที่ \$4.95 เราขายให้ แล้วใช้ \$2.5 สร้างพอร์ตเลียนแบบ เหลือเงินในมือ $4.95-2.5=\$2.45$ ทันที พรุ่งนี้พอร์ตจ่ายภาระของ call ได้พอดีไม่ว่าหุ้นไปทางไหน เงิน \$2.45 จึงเป็นเงินฟรี

ตรวจเองใน 10 วินาที: แทนกลับ $110\times0.25-22.5=5$ และ $90\times0.25-22.5=0$ ถูกทั้งสองขา โอกาส 99% หรือ 1% ไม่อยู่ในสมการเลย

ถามกลับบ้าง ถ้าอยากได้ \$2.5 จากการเฉลี่ย payoff ต้องใช้โอกาสขาขึ้นเท่าไร คำตอบคือโอกาส $q$ ที่ทำให้ราคาหุ้นเฉลี่ยพรุ่งนี้เท่ากับราคาวันนี้ (เพราะดอกเบี้ยเป็นศูนย์ เงินจึงไม่โต)

\[ \begin{aligned} 100&=110q+90(1-q),\\ q&=\frac{100-90}{110-90}=0.5,\\ C_0&=0.5\times5+0.5\times0=2.5. \end{aligned} \]

ตัวเลข $q=0.5$ คือ “โอกาสแบบ risk-neutral” มันไม่ใช่โอกาสจริงของหุ้นตัวไหน แต่เป็นโอกาสสมมติที่ทำให้หุ้นโตเฉลี่ยเท่าดอกเบี้ย และให้ราคาที่ตรงกับต้นทุนพอร์ตเลียนแบบพอดี

ขั้นที่ 2 — หลายงวด: ไล่ถอยหลังบนต้นไม้แล้วปรับพอร์ตทุกโหนด

โลกสองราคาเป็นแค่ของเล่น หุ้นจริงขยับหลายครั้งก่อนหมดอายุ ขั้นนี้จึงให้หุ้นขยับหลายงวดติดกัน แต่ละงวดขึ้นหรือลงได้สองทาง ภาพที่ได้เป็นต้นไม้ (เรียกว่า binomial tree) แต่ละจุดบนต้นไม้เรียกว่าโหนด

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ)

  • ราคาหุ้นวันนี้ $S_0=\$100$
  • ทุกงวด หุ้นขึ้นเป็น $u=1.07$ เท่า หรือลงเป็น $d=1/1.07\approx0.9345794$ เท่า ขึ้นหนึ่งครั้งแล้วลงหนึ่งครั้งจึงกลับมาที่ราคาเดิม
  • เงินฝากโตงวดละ 1% ตัวคูณเงินฝากจึงเป็น $R=1.01$
  • call strike $K=\$100$ หมดอายุหลังสามงวด

หลังสามงวด หุ้นจบได้สี่ราคา คือ $100\times1.07^3=122.504$ (ขึ้นสามครั้ง), $100\times1.07=107$ (ขึ้นสองลงหนึ่ง), $100/1.07=93.46$ (ขึ้นหนึ่งลงสอง) และ $100/1.07^3=81.63$ (ลงสามครั้ง) call จึงจ่าย $122.504-100=22.504$, $107-100=7$, 0 และ 0 ตามลำดับ เราต้องการราคา call วันนี้ และพอร์ตเลียนแบบที่ทุกโหนด

ต้นไม้สามงวดคือต้นไม้หนึ่งงวดหลายต้นต่อกัน ที่ปลายต้นไม้เรารู้ payoff แล้ว เราจึงเริ่มจากปลาย แล้วถอยหลังทีละชั้น ที่แต่ละโหนดแก้ปัญหาหนึ่งงวดแบบขั้นที่ 1 แต่ต้องเขียนในรูปทั่วไปก่อน เพราะตอนนี้เงินสดมีดอกเบี้ย

ที่โหนดที่หุ้นราคา $S$ งวดถัดไปหุ้นเป็น $uS$ หรือ $dS$ ให้ $C_{\rm up}$ กับ $C_{\rm down}$ คือราคา call ที่สองโหนดลูกนั้น (หาไว้แล้วจากชั้นถัดไป) พอร์ตถือหุ้น $\Delta$ หุ้นกับเงินสด $B$ ซึ่งงวดถัดไปโตเป็น $RB$ พอร์ตต้องจ่ายเท่ากับ call ทั้งสองลูก

\[ \begin{aligned} \Delta uS+RB&=C_{\rm up},\\ \Delta dS+RB&=C_{\rm down},\\ \Delta&=\frac{C_{\rm up}-C_{\rm down}}{uS-dS}. \end{aligned} \]

สูตร $\Delta$ ได้จากการเอาสองสมการลบกันแบบขั้นที่ 1 ต่อไปเราอยากได้ราคาโหนด $C=\Delta S+B$ ในรูปที่ใช้แค่ราคาของสองลูก สมการล่างให้ $B=(C_{\rm down}-\Delta dS)/R$ แทนลงไป

\[ \begin{aligned} C&=\Delta S+\frac{C_{\rm down}-\Delta dS}{R}\\ &=\frac{\Delta S\,(R-d)+C_{\rm down}}{R}\\ &=\frac{q\,(C_{\rm up}-C_{\rm down})+C_{\rm down}}{R}\\ &=\frac{qC_{\rm up}+(1-q)C_{\rm down}}{R},\\ q&=\frac{R-d}{u-d}. \end{aligned} \]

ขั้นที่ต้องดูคือการเปลี่ยน $\Delta S\,(R-d)$ เป็น $q\,(C_{\rm up}-C_{\rm down})$ สูตร $\Delta$ บอกว่า $\Delta S=(C_{\rm up}-C_{\rm down})/(u-d)$ เพราะ $S$ ตัดกันได้ คูณด้วย $R-d$ จึงได้ $q\,(C_{\rm up}-C_{\rm down})$ ผลคือราคาโหนดเท่ากับค่าเฉลี่ยของสองลูก ถ่วงด้วย $q$ กับ $1-q$ แล้วหารด้วย $R$ เพื่อคิดลดกลับมาหนึ่งงวด $q$ ตัวนี้คือโอกาสแบบ risk-neutral ตัวเดียวกับขั้นที่ 1 ลองแทนโลกสองราคา $u=1.1$, $d=0.9$, $R=1$ จะได้ $q=(1-0.9)/(1.1-0.9)=0.5$ ตรงกัน

$q$ อยู่ระหว่าง 0 กับ 1 ก็ต่อเมื่อ $d\lt R\lt u$ ถ้า $R\gt u$ เงินฝากโตเร็วกว่าหุ้นแม้ในขาขึ้น ทุกคนจะ short หุ้น (ยืมหุ้นมาขายก่อน แล้วซื้อคืนทีหลัง) แล้วเอาเงินไปฝาก ถ้า $R\lt d$ หุ้นโตเร็วกว่าเงินฝากแม้ในขาลง ทุกคนจะกู้เงินมาซื้อหุ้น ทั้งสองกรณีได้เงินฟรี

ตอนนี้แทนตัวเลข เริ่มจาก $q$ แล้วไล่ราคาโหนดถอยหลังจากงวด 2 ไปงวด 1 และงวด 0 เขียน $C_2(114.49)$ แปลว่าราคา call ที่งวด 2 ตอนหุ้นราคา \$114.49 ($100\times1.07^2$) และใช้ทศนิยมสามตำแหน่ง ส่วนโหนดล่างสุดของงวด 2 (หุ้น \$87.34) มีค่าศูนย์ เพราะลูกทั้งสองจ่ายศูนย์

\[ \begin{aligned} q&=\frac{1.01-0.9345794}{1.07-0.9345794}\\ &=\frac{0.0754206}{0.1354206}=0.556936,\\ 1-q&=0.443064,\\ C_2(114.49)&=\big(0.556936\times22.504\\ &\quad+0.443064\times7\big)/1.01\\ &=15.480,\\ C_2(100)&=\big(0.556936\times7\\ &\quad+0.443064\times0\big)/1.01\\ &=3.860,\\ C_1(107)&=\big(0.556936\times15.480\\ &\quad+0.443064\times3.860\big)/1.01\\ &=10.229,\\ C_1(93.46)&=\big(0.556936\times3.860\\ &\quad+0.443064\times0\big)/1.01\\ &=2.128,\\ C_0&=\big(0.556936\times10.229\\ &\quad+0.443064\times2.128\big)/1.01\\ &=6.574. \end{aligned} \]

จำนวนหุ้นกับเงินสดวันนี้มาจากสองลูกของโหนดแรก คือ \$107 กับ \$93.46

\[ \begin{aligned} \Delta_0&=\frac{10.229-2.128}{107-93.458}\\ &=\frac{8.101}{13.542}=0.5982,\\ B_0&=C_0-\Delta_0S_0\\ &=6.574-0.5982\times100\approx-53.25. \end{aligned} \]

คำตอบ: call ราคา \$6.57 วันนี้พอร์ตถือหุ้น 0.5982 หุ้นและกู้ \$53.25 หลังจากนั้นทุกงวดต้องปรับจำนวนหุ้นตามโหนดที่ไปถึง ตารางด้านล่างเดินตามเส้นสีเขียวในรูปต้นไม้ คือ ขึ้น ลง ขึ้น ช่อง “มูลค่าพอร์ตก่อนปรับ” คือหุ้นเดิมคูณราคาใหม่ บวกเงินสดเดิมที่โตด้วยดอกเบี้ย $\Delta_{\rm old}S_{\rm new}+RB_{\rm old}$

ขั้นที่ 3 — โลกต่อเนื่อง: ส่งการขยับของหุ้นผ่านราคา call

ต้นไม้ยังเป็นโลกปลอม เพราะหุ้นจริงขยับต่อเนื่อง ถ้าซอยงวดให้สั้นลงเรื่อย ๆ ต้นไม้จะเหมือนหุ้นจริงขึ้นเรื่อย ๆ ให้งวดยาว $h$ ปี ตัวคูณขาขึ้น $u=e^{\sigma\sqrt{h}}$ และขาลง $d=1/u$ เช่นงวดละหนึ่งวันปฏิทิน $h=1/365$ กับ $\sigma=0.20$ จะได้ $u=e^{0.20\times0.052342}=e^{0.010468}=1.010523$ หุ้นจึงขึ้นหรือลงราว 1% ต่อวัน เมื่อ $h$ เล็กลงจนเข้าใกล้ศูนย์ ต้นไม้จะกลายเป็น geometric Brownian motion (GBM)

GBM บอกว่าในช่วงเวลาสั้น ๆ $dt$ ราคาหุ้นขยับ $dS$ เป็นสองส่วน ส่วนแรก $\mu S\,dt$ รู้ล่วงหน้า มาจาก drift $\mu$ ส่วนที่สอง $\sigma S\,dW$ เป็นส่วนสุ่ม $dW$ คือก้อนสุ่มของ Brownian motion ในช่วง $dt$ มีค่าเฉลี่ยศูนย์และ SD เท่ากับ $\sqrt{dt}$ หุ้นทั้งตัวถูกขับด้วย $dW$ ก้อนเดียวนี้

เราจะทำเรื่องเดิม คือจับคู่พอร์ตกับ call แต่ในเวลาต่อเนื่อง ขั้นแรกต้องรู้ว่าเมื่อหุ้นขยับ $dS$ ราคา call ขยับ $dC$ เท่าไร ราคา call เป็นฟังก์ชันของราคาหุ้นกับเวลา $C(S,t)$ ให้ $C_t$ คืออัตราเปลี่ยนของราคา call ตามเวลา $C_S$ คือความชันเทียบราคาหุ้น และ $C_{SS}$ คือความโค้ง calculus ปกติใช้ Taylor อันดับหนึ่ง $dC\approx C_t\,dt+C_S\,dS$ แต่หุ้นแกว่งแรงจนกำลังสองของการขยับ $(dS)^2$ มีขนาดพอ ๆ กับ $dt$ ทิ้งไม่ได้ จึงต้องเก็บพจน์อันดับสองไว้ด้วย กฎนี้ชื่อ Itô's lemma

\[ \begin{aligned} dS&=\mu S\,dt+\sigma S\,dW,\\ (dW)^2&=dt,\quad dt\,dW=0,\\ (dS)^2&=\sigma^2S^2\,dt,\\ dC&=C_t\,dt+C_S\,dS+\tfrac12C_{SS}(dS)^2\\ &=\big(C_t+\mu SC_S+\tfrac12\sigma^2S^2C_{SS}\big)dt\\ &\quad+\sigma SC_S\,dW. \end{aligned} \]

ขั้นที่ต้องเข้าใจคือกฎ $(dW)^2=dt$ SD ของ $dW$ คือ $\sqrt{dt}$ กำลังสองของมันจึงมีขนาด $dt$ เท่ากับพจน์ drift และไม่เล็กพอจะทิ้ง ส่วน $(dt)^2$ กับ $dt\,dW$ (ขนาด $dt^{3/2}$) เล็กกว่า $dt$ มากเมื่อก้าวสั้นลง จึงทิ้งได้ ผลรวมกำลังสองของการขยับเล็ก ๆ ทั้งหมดเท่ากับเวลาที่ผ่านไปพอดี เรื่องนี้เรียกว่า quadratic variation เมื่อยกกำลังสอง $dS$ จะได้สามพจน์ พจน์ที่มี $(dt)^2$ และ $dt\,dW$ ทิ้งได้ เหลือแค่ $\sigma^2S^2(dW)^2=\sigma^2S^2\,dt$

ลองดูด้วยตัวเลข ในหนึ่งวันปฏิทิน การขยับปกติ (หนึ่ง SD) ของหุ้น \$100 คือ $\sigma S\sqrt{h}=0.20\times100\times\sqrt{1/365}=20\times0.052342=\$1.0468$ ยกกำลังสองได้ $1.0468^2=1.0959$ ซึ่งเท่ากับ $\sigma^2S^2h=0.04\times10{,}000/365=1.0959$ ทิศของการขยับสุ่ม แต่ขนาดของกำลังสองรู้ล่วงหน้า

ผลสุดท้ายแยกการขยับของ call เป็นสองก้อน ก้อนคูณ $dt$ รู้ล่วงหน้า ก้อนคูณ $dW$ สุ่ม พจน์ความโค้ง $\tfrac12\sigma^2S^2C_{SS}$ ไม่มีใน calculus ปกติ และมันจะกลายเป็นหัวใจของ PDE

ขั้นที่ 4 — บัญชีของพอร์ตที่ห้ามเติมเงิน

ขั้นที่แล้วได้การขยับของ call แล้ว ก่อนจะจับคู่ ต้องรู้การขยับของพอร์ตด้วย กติกาคือ self-financing ห้ามเติมหรือถอนเงิน ต้นไม้สามงวดให้คำตอบแบบเป็นงวดไว้แล้ว ระหว่างงวด จำนวนหุ้นคงที่ มูลค่าพอร์ตเปลี่ยนเพราะหุ้นขยับกับดอกเบี้ยเท่านั้น และตอนปรับ ขาหุ้นเพิ่มเท่าไร เงินสดก็ลดเท่านั้น

เขียนเป็นสูตร ให้ก้าวที่ $i$ ยาว $h$ ปี พอร์ตมีค่า $V_i$ ถือหุ้น $\Delta_i$ หุ้นที่ราคา $S_i$ เงินสดที่เหลือคือ $B_i=V_i-\Delta_iS_i$ และเงินสด \$1 โตเป็น $e^{rh}$ ในหนึ่งก้าว เพราะ $r$ คือดอกเบี้ยแบบต่อเนื่องต่อปี

\[ \begin{aligned} V&=\Delta S+B,\\ V_{i+1}&=V_i+\Delta_i(S_{i+1}-S_i)\\ &\quad+(V_i-\Delta_iS_i)(e^{rh}-1),\\ dV&=\Delta\,dS+rB\,dt. \end{aligned} \]

สูตรกลางคือบัญชีจริงหนึ่งก้าว มูลค่าใหม่เท่ากับมูลค่าเดิม บวกกำไรจากหุ้นที่ถือ บวกดอกเบี้ยของเงินสด $B_i$ ไม่มีพจน์ไหนให้เติมหรือถอนเงิน เมื่อ $h$ สั้นลง $e^{rh}-1\approx rh$ (เพราะ $e^x\approx1+x$ เมื่อ $x$ เล็ก เช่น $e^{0.04/365}-1=0.00010960$ เทียบกับ $0.04/365=0.00010959$) และเขียน $h$ เป็น $dt$ จึงได้สูตรสุดท้าย

จุดที่คนพลาดบ่อยคือเขียน $d(\Delta S)=\Delta\,dS+S\,d\Delta$ แล้วนับ $S\,d\Delta$ เป็นกำไรขาดทุน แต่ $S\,d\Delta$ คือเงินที่จ่ายซื้อหุ้นเพิ่ม เงินสดจึงลดลงเท่ากันพอดี เหมือนในต้นไม้ที่ซื้อหุ้นเพิ่ม 0.2037 หุ้นด้วยเงิน \$21.80 แล้วมูลค่ารวมไม่ขยับเลย

ขั้นที่ 5 — เลือกจำนวนหุ้นให้ส่วนสุ่มหักล้างกัน

ตอนนี้มีของสองอย่างที่ถูกขับด้วย $dW$ ก้อนเดียวกัน คือ call (ขั้นที่ 3) กับพอร์ต (ขั้นที่ 4) ถ้าตัวคูณหน้า $dW$ ของสองอย่างเท่ากัน ผลต่างของมันจะไม่เหลือความสุ่มเลย นี่คือรูปต่อเนื่องของ “เอาสมการขาขึ้นลบสมการขาลง” ในโลกสองราคา เริ่มจากแทน $dS$ ของ GBM ลงในบัญชีพอร์ต แล้วจับตัวคูณหน้า $dW$ ให้เท่ากัน

\[ \begin{aligned} dV&=\Delta(\mu S\,dt+\sigma S\,dW)+rB\,dt\\ &=(\Delta\mu S+rB)\,dt+\Delta\sigma S\,dW,\\ \Delta\sigma S&=\sigma SC_S\ \Rightarrow\ \Delta=C_S,\\ V&=C\ \Rightarrow\ B=C-SC_S. \end{aligned} \]

หัวใจอยู่ที่การจับตัวคูณหน้า $dW$ ให้เท่ากัน ฝั่งซ้ายคือตัวคูณหน้า $dW$ ของพอร์ต ฝั่งขวาคือของ call จากขั้นที่ 3 หารทั้งสองข้างด้วย $\sigma S$ ได้ (เพราะเป็นบวก ไม่ใช่ศูนย์) จึงได้ว่าจำนวนหุ้นเท่ากับความชันของราคา call เทียบราคาหุ้น จำนวนหุ้นจึงไม่ได้ตั้งขึ้นลอย ๆ มันคือคำตอบของสมการที่บังคับให้ความสุ่มสองฝั่งเท่ากัน ในโลกสองราคาเราได้ $\Delta=(C_{\rm up}-C_{\rm down})/(S_{\rm up}-S_{\rm down})$ ซึ่งคือความชันแบบผลต่าง พอก้าวสั้นลง ผลต่างก็กลายเป็นอนุพันธ์

เงื่อนไข $V=C$ บอกเงินสดที่ต้องมี เพื่อให้พอร์ตเริ่มที่มูลค่าเท่ากับ call คือ $\Delta S+B=C$ สำหรับ call เงินสด $B$ ติดลบเสมอ รูปเส้นโค้งของ call กับเส้นตรงของพอร์ตเลียนแบบด้านบนบอกเหตุผล เส้นตรงของพอร์ต $V=\Delta S+B$ มีความชัน $\Delta$ และตัดแกนตั้ง (ที่ $S=0$) ที่ $B$ เส้นโค้งของ call โค้งหงายและเริ่มที่ศูนย์ เส้นสัมผัสจึงต้องตัดแกนตั้งต่ำกว่าศูนย์ แปลว่าพอร์ตต้องกู้เงินมาซื้อหุ้น ตรงกับเงินกู้ \$22.5 ในโลกสองราคา และ \$53.25 ในต้นไม้ ส่วนโจทย์เปิดเรื่อง ขั้นที่ 8 จะคำนวณได้เงินกู้ \$34.38 ต่อ call

ขั้นที่ 6 — เทียบส่วนที่รู้ล่วงหน้า แล้ว μ ก็หายไป

หลังเลือก $\Delta=C_S$ และ $B=C-SC_S$ ผลต่าง $C-V$ เริ่มที่ศูนย์ และไม่มีส่วนสุ่มเหลือเลย ของที่รู้ผลล่วงหน้าแน่นอนต้องโตในอัตราดอกเบี้ย ไม่อย่างนั้นคนจะกู้เงินมาถือมัน (หรือขายมันแล้วเอาเงินไปฝาก) และได้กำไรฟรี ของที่มีค่าศูนย์ โตในอัตราดอกเบี้ยก็ยังเป็นศูนย์ ผลต่าง $C-V$ จึงต้องไม่ขยับเลย แปลว่าก้อนคูณ $dt$ ของ call (จากขั้นที่ 3) ต้องเท่ากับก้อนคูณ $dt$ ของพอร์ต (จากขั้นที่ 5)

\[ \begin{aligned} &C_t+\mu SC_S+\tfrac12\sigma^2S^2C_{SS}\\ &\qquad=\Delta\mu S+rB\\ &\qquad=\mu SC_S+r(C-SC_S),\\ &C_t+rSC_S+\tfrac12\sigma^2S^2C_{SS}\\ &\qquad-rC=0. \end{aligned} \]

ฝั่งซ้ายมาจากการขยับของ call ด้วย Itô ฝั่งขวามาจากบัญชีพอร์ต หลังแทน $\Delta=C_S$ กับ $B=C-SC_S$ จุดสำคัญคือพจน์ $\mu SC_S$ อยู่ทั้งสองฝั่งพอดี จึงตัดกันทิ้ง จากนั้นย้าย $rC-rSC_S$ ที่เหลือทางขวามาไว้ฝั่งซ้าย อัตราโตที่คาดของหุ้นหายไปจากสมการ สมการที่เหลือคือ Black–Scholes PDE

ทำไม $\mu$ หาย เพราะหุ้นที่ถือไว้ hedge พาทั้งส่วนสุ่มและ drift ของหุ้นมาด้วยกัน หักส่วนสุ่มจนหมด ก็หัก drift ไปพร้อมกัน นี่คือเหตุผลเดียวกับที่โอกาส 99% หรือ 1% ของ ABC และ XYZ ไม่มีผลในโลกสองราคา สิ่งที่ไม่หายคือ $\sigma$ เพราะมันมาจากกำลังสองของการขยับ ซึ่งเป็นบวกเสมอไม่ว่าหุ้นไปทางไหน หุ้นที่ถือให้กำไรขาดทุนเป็นเส้นตรงตามการขยับ จึงหักส่วนที่เป็นกำลังสองทิ้งไม่ได้ ราคา option จึงเป็นราคาของความผันผวน ไม่ใช่ราคาของทิศทาง

PDE นี้ใช้ได้กับทุกสัญญาที่มูลค่าขึ้นกับราคาหุ้นตัวนี้และเวลา เพราะตอน derive เราไม่ได้ใช้ payoff เลย put ก็ต้องผ่าน PDE เดียวกัน ต่างกันแค่เงื่อนไขปลายทาง แม้แต่ตัวหุ้นเองก็ผ่าน ลองแทน $V=S$ จะได้ $V_t=0$, $V_S=1$, $V_{SS}=0$ ใส่ใน PDE ได้ $0+rS\times1+0-rS=0$

ขั้นที่ 7 — ปิดโจทย์ด้วย payoff แล้วแก้ PDE บนกริดโดยไม่ใช้สูตร

PDE อย่างเดียวยังไม่ใช่ราคา call เพราะมันมีคำตอบได้มากมาย (ขั้นที่แล้วเพิ่งเห็นว่าตัวหุ้นเองก็เป็นคำตอบ) ต้องบอกเพิ่มว่าเรากำลังตั้งราคาสัญญาอะไร สำหรับ call ของโจทย์เปิดเรื่อง มีเงื่อนไขสามข้อ

  • วันหมดอายุ ราคาเท่ากับ payoff คือ $C(S,T)=\max(S-K,0)$ เขียนสั้น ๆ ว่า $(S-K)^+$
  • ถ้าหุ้นราคาศูนย์ call มีค่าศูนย์ $C(0,t)=0$ เพราะหุ้นใน GBM ที่ตกถึงศูนย์จะอยู่ที่ศูนย์ตลอดไป
  • ถ้าหุ้นแพงมาก call เกือบแน่นอนว่าจะถูกใช้สิทธิ์ จึงมีค่าใกล้ $S-Ke^{-r(T-t)}$ คือราคาหุ้นลบ strike ที่คิดลดเป็นเงินวันนี้

เราจะแก้ด้วยตัวเลข โดยไม่ใช้สูตรสำเร็จ วางกริดราคาห่างกันช่องละ $\delta$ ดอลลาร์ ตั้งแต่ \$0 ถึง \$300 ให้ $C_i$ คือราคา call ที่จุดกริด $S_i=i\delta$ แล้วแทนความชันและความโค้งด้วยผลต่างของค่าบนกริด PDE บอกว่า $C_t=-\big(\tfrac12\sigma^2S^2C_{SS}+rSC_S-rC\big)$ ถ้าย้อนเวลากลับไป $h$ ปี ราคาจึงเปลี่ยนไป $-hC_t$ เราเริ่มจาก payoff ในวันหมดอายุ แล้วเดินถอยหลังทีละ $h$ ปี เหมือนไล่ถอยหลังบนต้นไม้ วิธีนี้ชื่อ explicit finite difference

\[ \begin{aligned} &C_i^{\rm new}=C_i+h\Big[\\ &\quad\tfrac12\sigma^2S_i^2\,\frac{C_{i+1}-2C_i+C_{i-1}}{\delta^2}\\ &\quad+rS_i\,\frac{C_{i+1}-C_{i-1}}{2\delta}-rC_i\Big]. \end{aligned} \]

$C_i^{\rm new}$ คือราคาที่จุดเดิม แต่ย้อนเวลาไปอีก $h$ ปี ในวงเล็บคือสามพจน์ของ PDE ก้อนแรกคือความโค้งแบบผลต่าง (ค่าซ้ายบวกค่าขวา ลบสองเท่าของค่ากลาง) ก้อนที่สองคือความชันแบบผลต่างกลาง (ค่าขวาลบค่าซ้าย หารด้วยระยะ $2\delta$) ทุกค่าทางขวาเป็นค่าที่รู้แล้วจากก้าวก่อน จึงคำนวณค่าใหม่ได้ทันที คำว่า explicit หมายถึงข้อนี้

โจทย์ให้อะไรมาบ้าง: $\sigma=0.20$, $r=0.04$, $K=\$105$ อายุ 0.25 ปี กริดห่าง $\delta=\$1$ และแบ่งอายุเป็น 2,000 ก้าว ก้าวละ $h=0.25/2000=0.000125$ ปี

ลองคิดก้าวแรกที่ $S=105$ ด้วยมือ ค่าก่อนหน้าคือ payoff ซึ่งที่ \$104, \$105 และ \$106 เป็น $C_{104}=0$, $C_{105}=0$ และ $C_{106}=106-105=1$

\[ \begin{aligned} \frac{C_{106}-2C_{105}+C_{104}}{\delta^2}&=\frac{1-0+0}{1}=1,\\ \frac{C_{106}-C_{104}}{2\delta}&=\frac{1-0}{2}=0.5,\\ \tfrac12\sigma^2S^2&=0.02\times105^2=220.5,\\ rS&=0.04\times105=4.2,\\ C_{105}^{\rm new}&=0+0.000125\\ &\quad\times(220.5\times1+4.2\times0.5-0)\\ &=0.000125\times222.6\approx0.0278. \end{aligned} \]

ก้าวแรกนี้บอกเรื่องสำคัญ ในวงเล็บ 222.6 มาจากพจน์ความโค้งถึง 220.5 คิดเป็น $220.5/222.6\approx99\%$ payoff มีความโค้งแค่ตรง strike ที่เส้นหักมุม (ที่อื่นเป็นเส้นตรง ความโค้งเป็นศูนย์) ค่าเวลาของ option จึงเกิดจากหักมุมตรง strike นี้เอง

ทำไมต้องคุมก้าวเวลา: สูตรอัปเดตคือการผสมราคาสามจุดเดิม $C_{i-1}$, $C_i$, $C_{i+1}$ ด้วยน้ำหนัก รวบพจน์ที่มี $C_i$ จะได้น้ำหนักของตัวกลางเป็น $1-h\sigma^2S_i^2/\delta^2-hr$ ถ้า $h$ ใหญ่เกินจนน้ำหนักนี้ติดลบ ความคลาดเล็ก ๆ จะถูกขยายทุกก้าวจนตัวเลขระเบิด จุดที่อันตรายที่สุดคือบนสุดของกริด $S_{\max}=\$300$

\[ \begin{aligned} \frac{h\sigma^2S_{\max}^2}{\delta^2}&=\frac{0.000125\times0.04\times300^2}{1^2}\\ &=0.45. \end{aligned} \]

น้ำหนักตัวกลางจึงยังเป็นบวก ราว $1-0.45=0.55$ โค้ดในหน้านี้ไม่ยอมให้ค่านี้เกิน 0.5 เพื่อเผื่อระยะปลอดภัยไว้ (น้ำหนักจะติดลบจริงเมื่อค่านี้เกินราว 1) ทุกครั้งที่ $\delta$ ลดครึ่ง ตัวหาร $\delta^2$ เล็กลงสี่เท่า จึงต้องลด $h$ ลงสี่เท่าด้วย จำนวนก้าวจึงเพิ่มจาก 2,000 เป็น 8,000 และ 32,000 เช่นแถวที่สอง $\frac{0.25}{8000}\times0.04\times\frac{300^2}{0.5^2}=0.45$ เท่าเดิม

ขั้นที่ 8 — hedge ของ 10,000 call และบัญชีหนึ่งวันถัดมา

กลับมาที่โจทย์เปิดเรื่อง คุณขาย call ไว้บนหุ้น 10,000 หุ้น ตอนนี้รู้ราคาและ delta แล้ว ขั้นนี้ตั้งพอร์ตเลียนแบบจริง แล้วลงบัญชีวันถัดไปดูว่าพอร์ตตาม call ทันไหม คิดต่อ call หนึ่งใบ (หุ้นหนึ่งหุ้นในสัญญา) ก่อน แล้วค่อยคูณ 10,000

โจทย์ให้อะไรมาบ้าง

  • ราคา call วันนี้ $C=\$2.390877$ ต่อหุ้น (จากกริดในขั้นที่ 7 ซึ่งตรงกับสูตร Black–Scholes)
  • จำนวนหุ้นต่อ call $\Delta=C_S=0.367719$ คือความชันของราคา call ที่ $S=\$100$ (ขั้นที่ 5 บอกว่าต้องถือเท่านี้)
  • หนึ่งวันปฏิทินต่อมา $h=1/365$ ปี หุ้นขึ้นจาก \$100 เป็น \$101 (สมมติ)
  • delta ใหม่ของ call ที่หุ้น \$101 และอายุเหลือ $0.25-1/365$ ปี คือ 0.404635 และราคา call ใหม่คือ \$2.751877 (สองค่านี้คำนวณด้วยสูตร Black–Scholes ในหน้าถัดไป)

วันนี้ เงินสดที่ต้องมีมาจาก $B=C-S\Delta$ ในขั้นที่ 5 แล้วคูณ 10,000 ได้ตำแหน่งจริงของโต๊ะ

\[ \begin{aligned} S\Delta&=100\times0.367719=36.7719,\\ B&=2.3909-36.7719\\ &=-34.3810,\\ \text{stock}&=36.7719\times10{,}000\\ &=\$367{,}719,\\ \text{loan}&=34.3810\times10{,}000\\ &=\$343{,}810. \end{aligned} \]

วันถัดมา ก่อนปรับพอร์ต ขาหุ้นมีค่าตามราคาใหม่ และหนี้โตด้วยดอกเบี้ยหนึ่งวัน $e^{rh}=e^{0.04/365}=1.0001096$

\[ \begin{aligned} \Delta S_1&=0.367719\times101\approx37.1396,\\ Be^{rh}&=-34.3810\times1.0001096\\ &\approx-34.3848,\\ V_1&=37.1396-34.3848\approx2.7548. \end{aligned} \]

ค่าเต็มความละเอียดของ $V_1$ คือ \$2.754828 จากนั้นปรับจำนวนหุ้นให้เท่า delta ใหม่ ซื้อหุ้นเพิ่มด้วยเงินสดในพอร์ต

\[ \begin{aligned} \text{buy}&=0.404635-0.367719\\ &=0.036916,\\ \text{cost}&=0.036916\times101\approx3.7285,\\ B_{\rm new}&=-34.3848-3.7285\\ &=-38.1133,\\ \text{stock}_{\rm new}&=0.404635\times101\approx40.8681,\\ V_1&=40.8681-38.1133=2.7548. \end{aligned} \]

คำตอบ: วันนี้ถือหุ้น 3,677 หุ้น มูลค่า \$367,719 ใช้ premium \$23,909 และกู้ \$343,810 ตรงกับเฉลยของโจทย์เปิดเรื่อง วันถัดมาพอร์ตมีค่า \$2.754828 ต่อ call การซื้อหุ้นเพิ่มไม่ทำให้มูลค่ารวมเปลี่ยน ส่วน call มีค่า \$2.751877 พอร์ตจึงนำ call อยู่

\[ \begin{aligned} \text{lead}&=2.754828-2.751877\\ &=0.002951,\\ \text{lead}\times10{,}000&=\$29.51. \end{aligned} \]

ส่วนต่างเล็ก ๆ นี้เกิดเพราะหุ้นขยับ \$1 ซึ่งน้อยกว่าการขยับปกติหนึ่งวัน \$1.0468 (จากขั้นที่ 3) เล็กน้อย ขั้นที่ 9 จะแสดงว่าทำไมการขยับที่น้อยกว่าปกติจึงเป็นผลดีกับผู้ขาย

ตรวจเองใน 10 วินาที: $367{,}719-343{,}810=23{,}909$ คือ premium พอดี และหลังปรับ $40.8681-38.1133=2.7548$ เท่ากับก่อนปรับ การซื้อหุ้นเพิ่ม \$3.73 จึงไม่ใช่ขาดทุน มันคือการย้ายเงินจากขาเงินสดไปขาหุ้น

ขั้นที่ 9 — อ่าน PDE เป็นงบรายวันของโต๊ะ

ผู้ขาย call ที่ hedge แล้วอยากรู้ว่าแต่ละวันกำไรขาดทุนมาจากไหน PDE ตอบคำถามนี้ได้ เพราะมันมีสี่พจน์ และแต่ละพจน์คือเงินก้อนหนึ่งในบัญชีของโต๊ะ ขั้นนี้ใส่ตัวเลขจริงของโจทย์เปิดเรื่องลงไป

โจทย์ให้อะไรมาบ้าง (ทุกค่าที่ $S=\$100$ วันนี้ คำนวณจากสูตร Black–Scholes ชื่อ theta และ gamma มาจากthe Greeks)

  • $\Theta=C_t=-8.911341$ ดอลลาร์ต่อปี คือราคา call ลดลงเร็วแค่ไหนเมื่อเวลาผ่านไป ถ้าหุ้นไม่ขยับเลย
  • $\Delta=C_S=0.367719$ คือความชัน (จำนวนหุ้นที่ถือ)
  • $\Gamma=C_{SS}=0.0376805$ ต่อดอลลาร์ คือความโค้ง หรือ delta เปลี่ยนไปเท่าไรเมื่อหุ้นขยับ \$1
  • $C=2.390877$, เงินสด $B=-34.380989$ (ค่าเต็มของ −34.3810 ในขั้นที่ 8), $r=0.04$, $\sigma=0.20$

แทนลงในสี่พจน์ของ PDE หน่วยเป็นดอลลาร์ต่อปีต่อ call หนึ่งใบ ($\tfrac12\sigma^2=0.02$ และ $S^2=10{,}000$)

\[ \begin{aligned} \Theta&=-8.911341,\\ rS\Delta&=0.04\times100\times0.367719\\ &=1.470875,\\ \tfrac12\sigma^2S^2\Gamma&=0.02\times10{,}000\times0.0376805\\ &=7.536101,\\ \text{sum}&=-8.911341+1.470875+7.536101\\ &=0.095635,\\ rC&=0.04\times2.390877=0.095635. \end{aligned} \]

สามพจน์แรกรวมกันได้เท่ากับ $rC$ พอดี PDE จึงปิดบัญชีได้จริงกับตัวเลขนี้ (ค่าที่พิมพ์คำนวณจากค่าเต็มความละเอียด ถ้าคูณจากค่าที่ปัดแล้วอาจต่างในหลักสุดท้าย) แต่โต๊ะคิดบัญชีเป็นรายวัน จึงคูณด้วย $h=1/365$ เพราะอายุ option นับเป็นวันปฏิทิน ใช้ $(\sigma S)^2=20^2=400$

\[ \begin{aligned} \Theta h&=-8.911341/365=-0.024415,\\ \tfrac12\Gamma(\sigma S)^2h&=0.5\times0.0376805\times400/365\\ &=0.020647,\\ rBh&=0.04\times(-34.380989)/365\\ &=-0.003768. \end{aligned} \]

คำตอบ: แปลเป็นภาษาโต๊ะสำหรับผู้ขาย 10,000 call ที่ hedge แล้ว (คูณแต่ละบรรทัดด้วย 10,000)

  • ได้ค่าเวลาวันละ $0.024415\times10{,}000=\$244.15$ เพราะ call ที่ขายไว้ถูกลงทุกวันที่ผ่านไป
  • จ่ายดอกเบี้ยเงินกู้วันละ $0.003768\times10{,}000=\$37.68$
  • เสียให้ความโค้ง $\tfrac12\Gamma x^2$ ต่อ call ทุกครั้งที่หุ้นขยับ $x$ ดอลลาร์ ไม่ว่าขึ้นหรือลง (เพราะยกกำลังสอง) พจน์นี้มาจาก $\tfrac12C_{SS}(dS)^2$ ใน Itô

ถ้าหุ้นขยับเท่าการขยับปกติหนึ่งวัน \$1.0468 ซึ่งยกกำลังสองได้ 1.0959 (ขั้นที่ 3) จะเสีย $0.5\times0.0376805\times1.0959\times10{,}000\approx\$206.47$ เท่ากับ $244.15-37.68=206.47$ พอดี ขยับน้อยกว่านั้น ผู้ขายได้ ขยับมากกว่านั้น ผู้ขายเสีย นี่คือเหตุที่พอร์ตในขั้นที่ 8 นำ call อยู่เล็กน้อย เมื่อหุ้นขยับแค่ \$1

ตรวจเองใน 10 วินาที: $-0.024415+0.020647=-0.003768$ ตรงกับบรรทัดดอกเบี้ย ระวังเรื่องนาฬิกา ในแบบจำลองทุกวันปฏิทินมีการขยับเท่ากัน แต่หุ้นจริงขยับเฉพาะวันทำการ ซึ่งมีราว 252 วันต่อปีในตลาดสหรัฐ ($365-104-9=252$ คือ 365 วัน ลบเสาร์อาทิตย์ 104 วัน และวันหยุดราว 9 วัน) ถ้านับความผันผวนแบบ 252 วัน การขยับปกติในหนึ่งวันทำการคือ $\sigma S/\sqrt{252}=20/15.87\approx\$1.26$ ทั้งสองฝั่งของบัญชีต้องใช้นาฬิกาเดียวกัน

ขั้นที่ 10 — hedge เป็นครั้ง ๆ: drift ต่างกันสุดขั้ว ต้นทุนเท่ากัน

PDE สมมติว่าเราปรับจำนวนหุ้นได้ตลอดเวลา แต่โต๊ะจริงปรับได้เป็นครั้ง ๆ และทุกครั้งมีค่าซื้อขาย ระหว่างสองครั้งที่ปรับ พอร์ตจึงตาม call ไม่ทันพอดี ขั้นนี้ถามสองข้อ ข้อแรก ยังเหลือความเสี่ยงเท่าไร ข้อสอง ความเสี่ยงที่เหลือขึ้นกับว่าหุ้นมีแนวโน้มขึ้นหรือลงไหม ตอบด้วยการจำลอง

โจทย์ให้อะไรมาบ้าง

  • ขาย call หนึ่งใบของโจทย์เปิดเรื่องที่ \$2.390877 แล้ว hedge ด้วย $\Delta=C_S$
  • ปรับจำนวนหุ้นได้แค่ $n$ ครั้งตลอดอายุ 0.25 ปี ลองสามแบบ คือ $n=13$ (สัปดาห์ละครั้ง เพราะ $0.25\times52=13$ สัปดาห์), $n=63$ (วันทำการละครั้ง เพราะ $0.25\times252=63$ วันทำการ) และ $n=252$ (วันทำการละ $252/63=4$ ครั้ง)
  • จำลองราคาหุ้น 10,000 เส้นทางด้วย GBM ใช้เครื่องสุ่ม mulberry32 กับ seed 2024 และวิธี Box–Muller แบบเดียวกับที่ใช้ตอนจำลอง multivariate normal (seed ตายตัวทำให้ผู้อ่านทุกคนได้เลขสุ่มชุดเดียวกัน)
  • ลองสองโลกที่ต่างกันสุดขั้ว หุ้นโต $\mu=+12\%$ ต่อปี กับหุ้นดิ่ง $\mu=-10\%$ ต่อปี โดยใช้เลขสุ่มชุดเดียวกัน
  • สิ่งที่วัดคือความคลาดปลายทาง เท่ากับมูลค่าพอร์ตวันหมดอายุลบ payoff ที่ต้องจ่าย ถ้า hedge สมบูรณ์ ค่านี้ต้องเป็นศูนย์ทุกเส้นทาง

คำตอบข้อสอง (drift): ทั้งสองโลกให้ค่าเฉลี่ยใกล้ศูนย์ ค่าเฉลี่ยจาก 10,000 เส้นทางก็แกว่งได้ ขนาดการแกว่งของมันเรียกว่า standard error เท่ากับ SD หารด้วย $\sqrt{10{,}000}=100$ ค่าเฉลี่ยที่ห่างศูนย์มากที่สุดในตารางคือแถวแรก

\[ \begin{aligned} \text{SE}&=0.9488/100=0.009488,\\ \frac{0.0234}{0.009488}&\approx2.5. \end{aligned} \]

ทุกแถวจึงห่างศูนย์ไม่เกินราว 2.5 เท่าของ standard error ซึ่งเป็นระยะที่การสุ่มอธิบายได้ ทั้งที่หุ้นโลกหนึ่งโตเฉลี่ย 12% ต่อปี และอีกโลกดิ่ง 10% ต่อปี เงิน \$2.3909 พอสร้าง payoff ได้ในทั้งสองโลก นี่คือตัวเลขยืนยันว่า $\mu$ ไม่อยู่ในราคา

คำตอบข้อแรก (ความเสี่ยงที่เหลือ): SD ลดราวครึ่งหนึ่งทุกครั้งที่ปรับถี่ขึ้นสี่เท่า เช่น $0.4436/0.2228\approx1.99$ ทำไมเป็นแบบนี้ ในแต่ละก้าว พอร์ตคลาดจาก call เป็นก้อนสุ่มเล็ก ๆ ที่มีขนาดตามความยาวก้าว $T/n$ ก้อนพวกนี้มี $n$ ก้อนและไม่เกี่ยวกัน SD ของผลรวมจึงโตตาม $\sqrt{n}$ (variance บวกกันได้)

\[ \begin{aligned} \text{SD}&\propto\sqrt{n}\times\frac{1}{n}=\frac{1}{\sqrt{n}},\\ \frac{\text{SD}_{63}}{\text{SD}_{252}}&=\sqrt{\frac{252}{63}}=\sqrt4=2. \end{aligned} \]

ตรวจเองใน 10 วินาที: ผู้ขาย 10,000 call ที่ปรับ hedge วันละครั้ง ยังมี SD ของผลปลายทาง $0.4436\times10{,}000=\$4{,}436$ คิดเป็น $4{,}436/23{,}909\approx18.6\%$ ของ premium การ hedge ต่อเนื่องเป็นอุดมคติ ของจริงยังเหลือความเสี่ยง ซึ่งลดได้ด้วยการปรับถี่ขึ้น แต่ทุกครั้งที่ปรับต้องเสียค่าซื้อขาย

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

เฉลี่ย payoff ด้วยโอกาสจริง: ราคาที่ได้จะผิด และคนอื่นจะได้เงินฟรีจากเรา ในโลกสองราคา call บน ABC ที่เฉลี่ยด้วยโอกาสจริงได้ $0.99\times5=\$4.95$ แต่ต้นทุนสร้างจริงคือ $0.25\times100-22.5=\$2.5$ ใครตั้งราคา \$4.95 จะถูกคนอื่นขายให้ แล้วคนนั้นเก็บส่วนต่าง $4.95-2.5=\$2.45$ ต่อใบ โอกาสที่ใช้ตั้งราคาได้คือ $q=(R-d)/(u-d)$ ซึ่งมาจาก $u$, $d$, $R$ เท่านั้น ในโลกนี้ $q=0.5$ และ $0.5\times5=\$2.5$

นับการซื้อหุ้นเป็นกำไรขาดทุน: ระบบจะรายงานขาดทุนที่ไม่มีอยู่จริง ในบัญชีวันถัดมาของขั้นที่ 8 การซื้อหุ้นเพิ่มใช้เงิน $0.036916\times101\approx\$3.7285$ ต่อ call ถ้าระบบนับเงินนี้ ($S\,d\Delta$) เป็น P&L โดยไม่ลงเงินสดฝั่งตรงข้าม จะเห็นขาดทุนปลอม $3.7285\times10{,}000\approx\$37{,}285$ ในวันเดียว ทั้งที่มูลค่าพอร์ตยังเป็น \$2.754828 ต่อ call เท่าเดิม วิธีกันคือบันทึกจำนวนหุ้นกับบัญชีเงินสดคู่กันทุกครั้ง

ใช้โอกาสใช้สิทธิ์เป็นจำนวนหุ้น: จะถือหุ้นน้อยเกินไป สูตร Black–Scholes ให้โอกาสแบบ risk-neutral ที่ call นี้จะจบเหนือ strike เป็น 33.07% ถ้าเอาตัวเลขนี้เป็นจำนวนหุ้น จะถือ $0.3307\times10{,}000=3{,}307$ หุ้น แทนที่จะเป็น 3,677 หุ้น ขาดไป $3{,}677-3{,}307=370$ หุ้น ทุกการขยับ \$1 จึงมีเงิน $370\times\$1=\$370$ ที่ไม่ได้ hedge โดยไม่รู้ตัว จำนวนหุ้นมาจากความชัน ไม่ใช่จากโอกาส

ใช้ σ ผิด: พอร์ตจะขาดเงินเป็นระบบ ไม่ใช่แค่สุ่ม ราคาและจำนวนหุ้นทุกตัวคำนวณจาก $\sigma$ ที่ใส่เข้าไป สมมติใส่ 20% แต่หุ้นจริงแกว่งแบบ 25% การขยับปกติหนึ่งวันจะเป็น $0.25\times100\times\sqrt{1/365}=\$1.3086$ แทนที่จะเป็น \$1.0468 ความโค้งจึงกินเงินมากกว่าที่ค่าเวลาจ่าย เทียบความโค้งที่เสียจริงต่อวันกับ 0.020647 ที่ราคาคิดไว้ (ขั้นที่ 9) โดยใช้ gamma ตัวเดิม เพราะราคาและ hedge ยังคิดด้วย 20%

\[ \begin{aligned} \tfrac12\Gamma\,(0.25\times100)^2h&=0.5\times0.0376805\times\frac{25^2}{365}\\ &=0.032261,\\ 0.032261-0.020647&=0.011614. \end{aligned} \]

ผู้ขาย 10,000 call จึงเสียเพิ่มราว $0.011614\times10{,}000\approx\$116$ ต่อวัน ทุกวัน (ตราบที่ gamma ยังใกล้ค่าวันนี้) การเลียนแบบจึงทำได้แค่ประมาณ เพราะไม่มีใครรู้ $\sigma$ จริงล่วงหน้า

ปนนาฬิกา: บัญชีรายวันจะไม่ปิด ถ้าคิด theta ต่อวันโดยหารด้วย 365 แต่คิดการขยับรายวันโดยหารด้วย $\sqrt{252}$ ในบัญชีเดียวกัน จะได้จุดคุ้มทุน $20/\sqrt{252}=\$1.26$ ขณะที่ค่าเวลาคิดไว้สำหรับการขยับ $20/\sqrt{365}=\$1.05$ ต้องเลือกนาฬิกาเดียว แล้วบอกไว้ในรายงาน

ใช้ทำอะไรบนโต๊ะจริง

ผู้ค้า option ไม่ได้ขาย call เพราะเดาว่าหุ้นจะลง เขาขายที่ราคาเท่ากับต้นทุนการ hedge บวกส่วนเผื่อเล็กน้อย แล้วถือพอร์ตเลียนแบบไว้ กำไรขาดทุนรายวันจึงแตกเป็นสามก้อน ตามบัญชีรายวันของ PDE ในขั้นที่ 9 คือ ค่าเวลา ดอกเบี้ย และความโค้งคูณกำลังสองของการขยับจริง

ถ้าหุ้นขยับจริงน้อยกว่าที่ $\sigma$ ในราคาบอก ผู้ขายได้เงิน ถ้าขยับมากกว่า ผู้ขายเสีย ทุกโต๊ะจึงคุยกันเรื่อง “ความผันผวนที่เกิดขึ้นจริง เทียบกับความผันผวนที่ใส่ไว้ในราคา” มากกว่าเรื่องทิศทางของหุ้น (ดูP&L ของการ delta hedge)

ในทางปฏิบัติ option ที่ซื้อขายกันมาก ราคาถูกกำหนดด้วยแรงซื้อแรงขายในตลาด ไม่ใช่ด้วยการเลียนแบบ แต่แบบจำลองนี้ยังจำเป็นสำหรับสองงาน งานแรกคือตั้งราคาสัญญาแปลก ๆ ที่ไม่มีตลาดให้เทียบ ให้สอดคล้องกับ option ที่มีราคาตลาด งานที่สองคือบริหารความเสี่ยงของพอร์ตด้วย Greeks (ชุดความไวของราคา option เช่น delta, gamma, theta) การ hedge แบบนี้ยังลดความเสี่ยงได้มาก แม้ $\sigma$ ที่ใช้จะไม่ตรงเป๊ะ และแม้หุ้นจริงจะกระโดดได้ ซึ่ง GBM ไม่ยอมให้เกิด

โจทย์ตรวจความเข้าใจ

1. กลับไปที่โลกสองราคาของขั้นที่ 1 หุ้น \$100 พรุ่งนี้เป็น \$110 หรือ \$90 และ call strike \$105 แต่คราวนี้เงินมีดอกเบี้ย สมมติช่วงเวลาถึงวันหมดอายุยาว 0.25 ปี และดอกเบี้ย 4% ต่อปีแบบต่อเนื่อง เงินสด \$1 จึงโตเป็น $R=e^{0.04\times0.25}=e^{0.01}=1.010050$ ราคา call เป็นเท่าไร และทำไมแพงขึ้น

เฉลย

payoff ของ call ไม่เปลี่ยน (\$5 หรือ \$0) ตอนนี้เงินสด $B$ โตเป็น $RB$ จึงต้องแก้สมการใหม่

\[\begin{aligned}110\Delta+RB&=5,\\90\Delta+RB&=0,\\\Delta&=\frac{5-0}{110-90}=0.25,\\RB&=-90\times0.25=-22.5,\\B&=-22.5/1.010050=-22.2761,\\C_0&=0.25\times100-22.2761\\&=\$2.7239.\end{aligned}\]

จำนวนหุ้นเท่าเดิม และหนี้ที่ต้องคืนในวันหมดอายุก็ยังเป็น \$22.5 แต่หนี้ก้อนนี้รวมดอกเบี้ยแล้ว วันนี้จึงกู้ได้แค่ \$22.2761 ราคาแพงกว่ากรณีดอกเบี้ยศูนย์ $2.7239-2.5=\$0.2239$ เพราะพอร์ตเลียนแบบ call ต้องกู้เงิน ดอกเบี้ยสูงขึ้นทำให้กู้ได้น้อยลงสำหรับหนี้ก้อนเดิม ต้องใส่เงินตัวเองมากขึ้น

ตรวจด้วย $q$ โดย $u=110/100=1.1$ และ $d=90/100=0.9$

\[\begin{aligned}q&=\frac{1.010050-0.9}{1.1-0.9}=0.550251,\\C_0&=\frac{0.550251\times5}{1.010050}=2.7239.\end{aligned}\]

2. ในโลกสองราคาของขั้นที่ 1 (ดอกเบี้ยศูนย์) คราวนี้ลูกค้าอยากซื้อ put strike \$105 คือสิทธิ์ขายหุ้นที่ \$105 หาพอร์ตเลียนแบบ put แล้วตรวจว่า $C-P=S_0-K$ เมื่อ $C$ คือราคา call \$2.5 และ $P$ คือราคา put

เฉลย

put จ่าย $\max(105-110,0)=0$ เมื่อหุ้น \$110 และ $\max(105-90,0)=15$ เมื่อหุ้น \$90 แก้สมการสองขาแบบเดิม

\[\begin{aligned}110\Delta+B&=0,\\90\Delta+B&=15,\\\Delta&=\frac{0-15}{110-90}=-0.75,\\B&=15-90\times(-0.75)=82.5,\\P&=-0.75\times100+82.5=\$7.5.\end{aligned}\]

$\Delta$ ติดลบแปลว่า short หุ้น 0.75 หุ้น (ยืมหุ้นมาขาย) และเอาเงินไปฝาก \$82.5 ตรวจ $C-P=2.5-7.5=-5$ และ $S_0-K=100-105=-5$ เท่ากัน ความสัมพันธ์นี้คือ put–call parity ซึ่งจริงโดยไม่ต้องพึ่งแบบจำลองใดเลย

3. สมมติมีสัญญาแปลก ๆ ที่จ่าย $S_T^2$ ดอลลาร์ในวันหมดอายุ (ราคาหุ้นยกกำลังสอง) PDE ใช้ได้กับทุกสัญญาบนหุ้นตัวนี้ จึงใช้ตั้งราคาสัญญานี้ได้ด้วย ลองแทน $V=S^2e^{(r+\sigma^2)(T-t)}$ ลงใน PDE เพื่อตรวจว่าเป็นคำตอบ แล้วหามูลค่าวันนี้ที่ $S=100$, $T-t=0.25$, $r=4\%$, $\sigma=20\%$ พร้อมจำนวนหุ้นที่ต้องถือ

เฉลย

หาอนุพันธ์ทั้งสามก่อน (ตัวคูณ $e^{(r+\sigma^2)(T-t)}$ ไม่ขึ้นกับ $S$ และอนุพันธ์ตาม $t$ ของมันได้ $-(r+\sigma^2)$ คูณตัวมันเอง) แล้วแทนลงใน PDE

\[\begin{aligned}V_t&=-(r+\sigma^2)V,\\V_S&=2V/S,\quad V_{SS}=2V/S^2,\\0&=-(r+\sigma^2)V+rS\cdot\frac{2V}{S}\\&\quad+\tfrac12\sigma^2S^2\cdot\frac{2V}{S^2}-rV\\&=(-r-\sigma^2+2r+\sigma^2-r)V.\end{aligned}\]

วงเล็บรวมเป็นศูนย์พอดี จึงผ่าน PDE และวันหมดอายุ $T-t=0$ ตัวคูณเป็น $e^0=1$ จึงได้ $S_T^2$ ตรงกับ payoff ต่อไปแทนตัวเลข ($r+\sigma^2=0.04+0.04=0.08$)

\[\begin{aligned}V&=100^2e^{0.08\times0.25}\\&=10{,}000e^{0.02}=10{,}202.01,\\\Delta&=V_S=\frac{2\times10{,}202.01}{100}\\&=204.04.\end{aligned}\]

ต้องถือหุ้น 204.04 หุ้นต่อสัญญาหนึ่งใบ ตัวคูณ $e^{\sigma^2(T-t)}$ ที่ทำให้มูลค่าเกิน $S^2e^{r(T-t)}$ มาจากความโค้งของ $S^2$ ล้วน ๆ เพราะมันมาจากพจน์ $\tfrac12\sigma^2S^2V_{SS}$

// Replicating a European call: one-period toy, three-period tree, the PDE, a grid solve, discrete hedging.
const { abs, exp, log, sqrt, max, sin, cos, imul, round, PI } = Math;
const phi = x => exp(-0.5 * x * x) / sqrt(2 * PI);
function Phi(x) { // normal CDF: series near the centre, continued fraction in the tails
  const a = abs(x);
  if (a <= 3) { let t = a, s = a; for (let n = 1; n < 200 && t > 1e-17 * s; n++) { t *= a * a / (2 * n + 1); s += t; }
    return x >= 0 ? 0.5 + phi(a) * s : 0.5 - phi(a) * s; }
  let f = a; for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - phi(a) / f : phi(a) / f;
}
function call(S, K, T, r, sigma) { // Black-Scholes price and the three derivatives the PDE uses
  if (!(S > 0 && K > 0 && T > 0 && sigma > 0)) throw new RangeError('S, K, T, sigma must be positive');
  const sT = sigma * sqrt(T), d1 = (log(S / K) + (r + 0.5 * sigma * sigma) * T) / sT, d2 = d1 - sT;
  const price = S * Phi(d1) - K * exp(-r * T) * Phi(d2);
  return { price, delta: Phi(d1), gamma: phi(d1) / (S * sT),
    theta: -S * phi(d1) * sigma / (2 * sqrt(T)) - r * K * exp(-r * T) * Phi(d2), cash: price - S * Phi(d1) };
}
function oneStep(S0, up, down, K, growth) { // two prices tomorrow: solve for shares and cash
  const pu = max(up - K, 0), pd = max(down - K, 0), delta = (pu - pd) / (up - down);
  return { delta, cash: (pd - delta * down) / growth, price: delta * S0 + (pd - delta * down) / growth };
}
function tree(S0, u, d, R, K, n) { // backward induction; returns value, shares and cash at every node
  const q = (R - d) / (u - d), V = [];
  if (!(q > 0 && q < 1)) throw new RangeError('Need d < R < u, otherwise there is free money');
  for (let t = n; t >= 0; t--) V[t] = Array.from({ length: t + 1 }, (_, j) => t === n
    ? max(S0 * u ** j * d ** (n - j) - K, 0) : (q * V[t + 1][j + 1] + (1 - q) * V[t + 1][j]) / R);
  const nodes = [];
  for (let t = 0; t < n; t++) for (let j = 0; j <= t; j++) {
    const S = S0 * u ** j * d ** (t - j), delta = (V[t + 1][j + 1] - V[t + 1][j]) / (S * (u - d));
    nodes.push({ t, S: +S.toFixed(2), C: +V[t][j].toFixed(4), delta: +delta.toFixed(4), cash: +(V[t][j] - delta * S).toFixed(4) });
  }
  return { q, price: V[0][0], nodes };
}
const S = 100, K = 105, T = 0.25, r = 0.04, sigma = 0.2, h = 1 / 365;
const now = call(S, K, T, r, sigma);
function dayLater(S1) { // old hedge carried one day, then rebalanced
  const next = call(S1, K, T - h, r, sigma), before = now.delta * S1 + now.cash * exp(r * h), buy = next.delta - now.delta;
  return { newDelta: next.delta, buy, cost: buy * S1, portfolio: before, callValue: next.price, lead: before - next.price };
}
function gridPrice(dS, steps, Smax = 300) { // explicit finite differences, marching back from the payoff
  const n = round(Smax / dS), dt = T / steps;
  if (dt * sigma * sigma * Smax * Smax / (dS * dS) > 0.5) throw new RangeError('Time step too large for this grid');
  let C = Array.from({ length: n + 1 }, (_, i) => max(i * dS - K, 0));
  for (let k = 1; k <= steps; k++) {
    const N = C.slice();
    for (let i = 1; i < n; i++) { const Si = i * dS;
      N[i] = C[i] + dt * (0.5 * sigma * sigma * Si * Si * (C[i + 1] - 2 * C[i] + C[i - 1]) / (dS * dS)
        + r * Si * (C[i + 1] - C[i - 1]) / (2 * dS) - r * C[i]); }
    N[0] = 0; N[n] = Smax - K * exp(-r * k * dt); C = N;
  }
  const i = round(S / dS);
  return { dS, steps, price: C[i], delta: (C[i + 1] - C[i - 1]) / (2 * dS) };
}
function normals(seed) { // mulberry32 + Box-Muller, so every reader gets the same paths
  let a = seed >>> 0, spare = null;
  const u = () => { a = (a + 0x6D2B79F5) >>> 0; let t = imul(a ^ (a >>> 15), a | 1);
    t ^= t + imul(t ^ (t >>> 7), t | 61); return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296; };
  return () => { if (spare !== null) { const z = spare; spare = null; return z; }
    const rad = sqrt(-2 * log(u())), ang = 2 * PI * u(); spare = rad * sin(ang); return rad * cos(ang); };
}
function hedgeError(mu, n, paths, seed) { // sell one call at the model price, rebalance n times
  const z = normals(seed), dt = T / n;
  const deltaAt = (x, tau) => Phi((log(x / K) + (r + 0.5 * sigma * sigma) * tau) / (sigma * sqrt(tau)));
  let sum = 0, sum2 = 0;
  for (let p = 0; p < paths; p++) {
    let St = S, d = now.delta, cash = now.price - d * St;
    for (let k = 1; k <= n; k++) {
      St *= exp((mu - 0.5 * sigma * sigma) * dt + sigma * sqrt(dt) * z());
      cash *= exp(r * dt);
      if (k < n) { const nd = deltaAt(St, T - k * dt); cash -= (nd - d) * St; d = nd; }
    }
    const e = d * St + cash - max(St - K, 0); sum += e; sum2 += e * e;
  }
  const mean = sum / paths;
  return { mu, n, mean, sd: sqrt((sum2 - paths * mean * mean) / (paths - 1)) };
}
const hedging = [];
for (const mu of [0.12, -0.10]) for (const n of [13, 63, 252]) hedging.push(hedgeError(mu, n, 10000, 2024));

สิ่งที่ควรตอบได้หลังอ่าน

  • ราคา option คือต้นทุนของพอร์ตหุ้นกับเงินสดที่จ่ายเงินเท่ากับ option ทุกกรณี ไม่ใช่การเดาว่าหุ้นจะไปทางไหน ในโลกสองราคาได้ \$2.5 ไม่ว่าหุ้นจะขึ้นด้วยโอกาส 99% หรือ 1%
  • ต้นไม้หลายงวดคือต้นไม้หนึ่งงวดหลายต้นต่อกัน ไล่ถอยหลังด้วย $C=\big(qC_{\rm up}+(1-q)C_{\rm down}\big)/R$ เมื่อ $q=(R-d)/(u-d)$ ได้ call \$6.57 และพอร์ตที่ปรับทุกโหนดโดยไม่ต้องเติมเงิน จนจ่าย payoff ได้พอดี
  • บัญชี self-financing ให้ $dV=\Delta\,dS+rB\,dt$ การซื้อหุ้นเพิ่มคือการย้ายเงินจากขาเงินสดไปขาหุ้น ไม่ใช่กำไรขาดทุน
  • จับตัวคูณหน้า $dW$ ให้เท่ากันได้ $\Delta=C_S$ จับก้อนคูณ $dt$ ให้เท่ากันได้ Black–Scholes PDE $C_t+rSC_S+\tfrac12\sigma^2S^2C_{SS}-rC=0$ และ $\mu$ หายไป เพราะหุ้นที่ hedge พา drift ออกไปพร้อมกับส่วนสุ่ม
  • ขาย call บน 10,000 หุ้นที่ \$2.3909 ต้องถือ 3,677 หุ้น และกู้ \$343,810 บัญชีรายวันคือได้ค่าเวลา \$244.15 จ่ายดอกเบี้ย \$37.68 และเสียให้ความโค้ง \$206.47 ถ้าหุ้นขยับเท่าการขยับปกติ \$1.0468
  • hedge เป็นครั้ง ๆ เหลือความคลาดที่ SD ลดครึ่งหนึ่งเมื่อปรับถี่ขึ้นสี่เท่า และไม่ขึ้นกับ drift ของหุ้น

หน้าถัดไป สูตร Black–Scholes จะแก้ PDE นี้ออกมาเป็นสูตรปิด โดยเฉลี่ย payoff ด้วยโอกาสแบบ risk-neutral (ที่ให้หุ้นโตในอัตรา $r$ แทน $\mu$) แล้วได้ \$2.3909 ตัวเดียวกับกริด
