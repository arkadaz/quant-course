14.1 The Law of Large Numbers

นับการทดลองที่เป็นอิสระจริง ก่อนเชื่อว่าค่าเฉลี่ยจะนิ่ง

desk หนึ่งเทรดวันละ 10,000 ไม้ กำไรเฉลี่ยหลังหักต้นทุนแค่ครึ่งเซ็นต์ต่อไม้ แต่ละไม้เหวี่ยงราว \$2 วันหนึ่งมีโอกาสขาดทุนเท่าไร และต้องเทรดกี่วันถึงจะเห็นว่าค่าเฉลี่ยพ้นศูนย์ที่สองเท่าของความเหวี่ยง?

เฉลย: ขาดทุน 40.1% ของวัน และต้องเทรด 64 วัน (640,000 ไม้) ถ้าไม้สัมพันธ์กันแค่ 0.001 หมื่นไม้ต่อวันจะมีค่าเท่ากับไม้อิสระเพียง 909 ไม้ และตัวเลข 64 วันจะยาวขึ้นอีกมาก

Law of Large Numbers บอกว่าค่าเฉลี่ยเข้าใกล้ค่าจริงเมื่อข้อมูลมากพอ หัวข้อนี้คำนวณว่ามากพอคือเท่าไร และเงื่อนไขอะไรที่ทำให้มันไม่จริง

ศัพท์ที่ใช้ในหัวข้อนี้
Law of Large Numbers (LLN)
ผลที่ว่าค่าเฉลี่ยจากการทดลองจำนวนมากเข้าใกล้ expected value เมื่อการทดลองไม่เกี่ยวกันและค่าเฉลี่ยจริงมีค่าจำกัด ใช้ประเมินว่าการทำซ้ำลดความไม่แน่นอนได้แค่ไหน
independent and identically distributed (iid)
ผลแต่ละครั้งไม่บอกข่าวของครั้งอื่น และมาจากรูปแบบความน่าจะเป็นเดียวกัน ใช้เป็นเงื่อนไขที่ทำให้ข้อมูลเพิ่มแต่ละชิ้นเป็นข่าวใหม่จริง
expected value
ค่ากลางที่ถ่วงด้วยโอกาส เป็นตัวเลขตายตัวที่มองไม่เห็น ใช้เป็นเป้าที่ค่าเฉลี่ยจากข้อมูลเข้าใกล้
variance
ค่าเฉลี่ยของกำลังสองของระยะห่างจากค่ากลาง ใช้เพราะบวกกันได้ตรง ๆ เมื่อข้อมูลไม่เกี่ยวกัน
standard deviation
รากที่สองของ variance มีหน่วยเดียวกับข้อมูล ใช้บอกว่าข้อมูลแต่ละชิ้นเหวี่ยงแค่ไหน
standard error (SE)
standard deviation ของค่าเฉลี่ยจากข้อมูล n ชิ้น ใช้บอกว่าค่าเฉลี่ยที่วัดได้คลาดจากค่าจริงได้ราวเท่าไร
Sharpe ratio (SR)
ผลตอบแทนส่วนเกินเฉลี่ยหารความเหวี่ยงในช่วงเวลาเดียวกัน ใช้เทียบคุณภาพของกลยุทธ์ข้ามขนาดกัน
Markov's inequality
ขอบเขตที่ว่าโอกาสที่ตัวเลขไม่ติดลบจะเกิน a ไม่เกินค่าเฉลี่ยหาร a ใช้เป็นฐานของ Chebyshev
Chebyshev's inequality
ขอบเขตที่ว่าโอกาสหลุดห่างจากค่ากลางเกิน ε ไม่เกิน variance หาร ε² ใช้ได้กับทุกรูปแบบข้อมูล จึงใช้วางแผนจำนวนข้อมูลแบบปลอดภัย
correlation
ตัวเลขระหว่าง −1 ถึง 1 ที่บอกว่าสองรายการขยับไปด้วยกันแค่ไหน ใช้วัดว่าข้อมูลซ้ำข่าวกันมากเท่าไร
effective sample size
จำนวนข้อมูลอิสระที่เทียบเท่าหลังหักส่วนที่ซ้ำข่าวกัน ใช้แทนจำนวนแถวดิบเวลาคำนวณความแม่น
normal approximation
การประมาณผลรวมของข้อมูลจำนวนมากด้วยรูประฆัง (หัวข้อ 14.2) ใช้แปลงค่าเฉลี่ยกับความเหวี่ยงเป็นโอกาส
Cauchy distribution
รูปแบบหางอ้วนมากจนไม่มีค่าเฉลี่ย (หัวข้อ 1.11) ใช้เป็นตัวอย่างที่ค่าเฉลี่ยจากข้อมูลไม่นิ่งเลย
regime
ช่วงที่ตลาดมีพฤติกรรมต่างไปอย่างชัดเจน เช่นช่วงประกาศนโยบายหรือช่วงวิกฤต ใช้แยกข้อมูลที่มาจากโลกคนละแบบ

ที่มาที่ไป: ทฤษฎีบทแรกของวิชาความน่าจะเป็น

Jacob Bernoulli เริ่มงานราวปี 1689 และเขียนเสร็จใน Ars Conjectandi ที่ตีพิมพ์หลังเขาเสียชีวิตในปี 1713 เขาพิสูจน์สิ่งที่ทุกคนเชื่ออยู่แล้ว คือโยนเหรียญมากพอ สัดส่วนหัวจะเข้าใกล้ครึ่งหนึ่ง เหตุผลที่ทุ่มเวลายี่สิบปีคือเขาต้องการรู้ว่ามันเข้าใกล้เร็วแค่ไหน

ราวปี 1867 Chebyshev ให้เครื่องมือที่ทำให้พิสูจน์สั้นลงเหลือไม่กี่บรรทัด คำถามเรื่องความเร็วนี่เองที่โต๊ะเทรดต้องการ เพราะรู้ว่าค่าเฉลี่ยนิ่งในที่สุดไม่มีประโยชน์ ถ้าไม่รู้ว่าต้องใช้กี่ปี และคำตอบมักยาวกว่าอายุของกลยุทธ์ส่วนใหญ่

ขั้นที่ 1 — เหรียญด้วยมือ: สัดส่วนหัวเหวี่ยงน้อยลงช้า ๆ

โยนเหรียญเที่ยงตรง n ครั้ง แต่ละครั้งได้ 1 ถ้าหัว 0 ถ้าก้อย ค่าเฉลี่ยคือสัดส่วนหัว แต่ละครั้งเหวี่ยงรอบ 0.5 ด้วยความเหวี่ยง 0.5

\[ \begin{aligned} \sigma&=\sqrt{0.5(1-0.5)}=0.5\\ \operatorname{SE}&=\frac{0.5}{\sqrt n}\\ &n=4:\ 0.25\qquad n=100:\ 0.05\\ &n=10{,}000:\ 0.005\\ &\operatorname{SE}\le0.01\\ &\Rightarrow\ \sqrt n\ge\frac{0.5}{0.01}=50\ \Rightarrow\ n\ge2{,}500 \end{aligned} \]

สี่ครั้งสัดส่วนหัวเหวี่ยงได้ถึง ±0.25 จึงออก 3 ใน 4 หรือ 1 ใน 4 ได้ง่าย ร้อยครั้งเหลือ ±0.05 จะให้ความเหวี่ยงเหลือ 0.01 ต้องโยน 2,500 ครั้ง ตัวเลขรากที่สองนี้คือคำตอบเรื่องความเร็วของ Bernoulli ขั้นต่อไปแสดงว่ามาจากไหน

ขั้นที่ 2 — นิยามของสองปริมาณ: ค่าเฉลี่ยต่อไม้ กับผลรวม

สองก้อนนี้เป็นนิยาม ต้องเขียนให้ชัดก่อน เพราะกฎในหัวข้อนี้พูดถึงตัวแรกเท่านั้น ตัวแรกมีหน่วยเงินต่อไม้ ตัวที่สองมีหน่วยเงิน

\[ \bar X_n=\frac{1}{n}\sum_{i=1}^{n}X_i,\qquad S_n=\sum_{i=1}^{n}X_i=n\,\bar X_n \]

ค่าเฉลี่ยต่อไม้นิ่งขึ้นเมื่อเทรดมาก แต่ผลรวมเป็นดอลลาร์เหวี่ยงกว้างขึ้น การสลับสองหน่วยนี้คือความผิดที่ทำให้คนสรุปว่าเทรดเยอะแล้วความเสี่ยงหายไปเอง

ขั้นที่ 3 — ความเหวี่ยงของค่าเฉลี่ย: หดตามรากของจำนวนข้อมูล

ถามคำถามเดียว ถ้าเอาข้อมูลหลายชิ้นมาเฉลี่ย ค่าเฉลี่ยนั้นเหวี่ยงแค่ไหน ใส่ variance ลงบนนิยามของขั้นที่ 2

\[ \begin{aligned}\operatorname{Var}(\bar X_n)&=\operatorname{Var}\!\Big(\frac1n\sum_{i=1}^{n}X_i\Big)=\frac{1}{n^{2}}\operatorname{Var}\!\Big(\sum_{i=1}^{n}X_i\Big)\\ &=\frac{1}{n^{2}}\sum_{i=1}^{n}\operatorname{Var}(X_i)\qquad(\text{independent})\\ &=\frac{1}{n^{2}}\cdot n\sigma^{2}=\frac{\sigma^{2}}{n}\\ \operatorname{SE}(\bar X_n)&=\frac{\sigma}{\sqrt n}\end{aligned} \]

ตัวหารถูกยกกำลังสองตอนดึงออกจาก variance ข้อสมมติเดียวอยู่บรรทัดสอง แต่ละไม้ไม่ส่งข่าวถึงกัน พจน์ไขว้จึงเป็นศูนย์ variance ของผลรวมโตตาม n ไปหักกับ n² เหลือ n ตัวเดียวข้างล่าง

ค่าเฉลี่ยของค่าเฉลี่ยยังเท่ากับ μ การเฉลี่ยไม่ลด bias เลย สิ่งที่ลดคือความเหวี่ยงเท่านั้น

ทำไมหดตาม n ไม่ใช่ n²

มีสองแรงสู้กัน ตัวหารยกกำลังสองดันให้เล็กลงเร็ว แต่ความเหวี่ยงของผลรวมโตตามจำนวนก้อนที่บวก สองแรงหักกันไปหนึ่งชั้น เหลือการหดตาม n ถ้าข้อมูลซ้ำกันหมด ความเหวี่ยงของผลรวมจะโตเป็น n² แล้วค่าเฉลี่ยจะไม่หดเลย เก็บข่าวเดิมเพิ่มจึงไม่ช่วยอะไร

ขั้นที่ 4 — ตัวเลขของ desk: ต้องใช้กี่ไม้ กี่วัน

ใช้ความเหวี่ยง \$2 และกำไรเฉลี่ย \$0.005 ต่อไม้ของคำถามเปิด แล้วนับว่าความเหวี่ยงของค่าเฉลี่ยลดลงแค่ไหน

\[ \begin{aligned} &\operatorname{SE}(\bar X_n)=\frac{2}{\sqrt n}:\\ &\quad n=100\to0.2,\qquad n=10{,}000\to0.02\\ &\operatorname{SE}=\mu\\ &\Rightarrow\ n=\Big(\frac{2}{0.005}\Big)^2=160{,}000\ \text{trades}\\ &=16\ \text{days}\\ &\operatorname{SE}=\frac{\mu}{2}\\ &\Rightarrow\ n=\Big(\frac{2\times2}{0.005}\Big)^2=640{,}000\ \text{trades}\\ &=64\ \text{days} \end{aligned} \]

ที่หมื่นไม้ต่อวัน ความเหวี่ยงของค่าเฉลี่ยยังใหญ่กว่า edge สี่เท่า วันเดียวตัดสินอะไรไม่ได้ ให้ค่าเฉลี่ยห่างศูนย์สองเท่าของความเหวี่ยงต้องใช้ 64 วัน นี่คือคำตอบของคำถามเปิด ทุกครั้งที่อยากให้ความเหวี่ยงลดครึ่งหนึ่ง ต้องเก็บข้อมูลเพิ่มสี่เท่า

ขั้นที่ 5 — หนึ่งวัน: กำไรโตตาม n แต่ความเหวี่ยงโตตามรากของ n

ดูผลรวมของหนึ่งวันแทนค่าเฉลี่ย ค่าเฉลี่ยของผลรวมบวกกันตรง ๆ ส่วนความเหวี่ยงบวกแบบ variance แล้วใช้รูประฆังของหัวข้อ 14.2 หาโอกาสขาดทุน

\[ \begin{aligned}\mathbb E[S_n]&=n\mu=10{,}000(0.005)=50\ \text{USD}\\ \operatorname{SD}(S_n)&=\sigma\sqrt n=2(100)=200\ \text{USD}\\ \mathrm{SR}_{\rm day}&=\frac{n\mu}{\sigma\sqrt n}=\frac{\mu}{\sigma}\sqrt n=\frac{50}{200}=0.25\\ P(S_n\lt0)&\approx\Phi(-0.25)=0.4013=40.13\%\end{aligned} \]

รากตัดกับจำนวนไม้ เหลือรากเดียว การทำซ้ำจึงช่วย แต่ช่วยช้า กำไรคาดหวัง \$50 ต่อวันแต่ความเหวี่ยง \$200 วันขาดทุนสี่ในสิบวันเป็นเรื่องปกติ และไม่ได้ลบล้าง edge

ขั้นที่ 6 — หนึ่งปี 252 วันเทรด: หน่วยของเวลาต้องตรงกัน

หนึ่งปีเทรดมี 252 วัน (ที่มาอยู่ในหัวข้อ 1.1) ถ้าวันเป็นอิสระต่อกัน ใช้เหตุผลเดียวกันข้าม 252 วัน

\[ \begin{aligned} \mathbb E[\text{year}]&=252(50)=12{,}600\ \text{USD}\\ &\operatorname{SD}(\text{year})=200\sqrt{252}\\ &=3{,}174.90\ \text{USD}\\ \mathrm{SR}_{\rm year}&=\frac{12{,}600}{3{,}174.90}=3.969=0.25\sqrt{252}\\ &P(\text{losing year})\approx\Phi(-3.969)=0.004\% \end{aligned} \]

วันขาดทุน 40% แต่ปีขาดทุนแทบไม่เกิด ถ้าวันเป็นอิสระจริง ทุกตัวเลขต้องบอกหน่วยเวลา ห้ามเอา \$50 ต่อวันไปเทียบกับความเหวี่ยงต่อปีโดยไม่แปลงหน่วย

ขั้นที่ 7 — Markov's inequality: ขอบเขตจากค่าเฉลี่ยอย่างเดียว

Andrey Markov (ราวปี 1884) สร้างขอบเขตที่ง่ายที่สุดระหว่างค่าเฉลี่ยกับโอกาส ขอแค่ตัวเลขไม่ติดลบ ไม่ต้องรู้รูปแบบใดเลย

\[ \begin{aligned} &Y\ge0,\ a\gt0:\\ \mathbb E[Y]&=\int_0^{\infty}y\,f(y)\,dy\ \ge\ \int_a^{\infty}y\,f(y)\,dy\\ &\ge a\int_a^{\infty}f(y)\,dy=a\,P(Y\ge a)\\ P(Y\ge a)&\le\frac{\mathbb E[Y]}{a} \end{aligned} \]

ตัดส่วนที่ต่ำกว่า a ทิ้ง ค่าลดลงเท่านั้นเพราะส่วนที่ตัดไม่ติดลบ ในช่วงที่เหลือ y ไม่น้อยกว่า a จึงแทน y ด้วย a ได้ integral ที่เหลือคือโอกาสที่ Y ไม่น้อยกว่า a พอดี เช่นเงินเดือนเฉลี่ย \$3,000 คนที่ได้เกิน \$30,000 มีไม่เกิน 10%

ขั้นที่ 8 — Chebyshev's inequality: แทนระยะห่างกำลังสองลงใน Markov

ต้องการโอกาสที่ค่าเฉลี่ยหลุดห่างจาก μ เกิน ε ระยะห่างกำลังสองไม่ติดลบแน่นอน จึงผ่านเงื่อนไขเดียวที่ Markov ขอ

\[ \begin{aligned} Y&=\big(\bar X_n-\mu\big)^{2},\qquad a=\varepsilon^{2}\\ &P\big(|\bar X_n-\mu|\ge\varepsilon\big)\\ &=P\big((\bar X_n-\mu)^{2}\ge\varepsilon^{2}\big)\\ &\le\frac{\mathbb E\big[(\bar X_n-\mu)^{2}\big]}{\varepsilon^{2}}=\frac{\operatorname{Var}(\bar X_n)}{\varepsilon^{2}}=\frac{\sigma^{2}}{n\varepsilon^{2}}\\ &n\to\infty\ \Rightarrow\ \frac{\sigma^{2}}{n\varepsilon^{2}}\to0 \end{aligned} \]

ตัวเศษกลายเป็นนิยามของ variance พอดี ผลของขั้นที่ 3 จึงเสียบเข้าได้ โอกาสหลุดกรอบถูกกดด้วย n ที่อยู่ข้างล่าง เก็บข้อมูลมากพอ โอกาสพลาดจะเล็กเท่าไรก็ได้ นี่คือใจความของ LLN และไม่มีตรงไหนต้องรู้ว่าข้อมูลเป็นรูปแบบใด

ขั้นที่ 9 — Chebyshev กับตัวเลขของ desk: หลวมแต่ปลอดภัย

ที่ 640,000 ไม้ ถามโอกาสที่ค่าเฉลี่ยคลาดจาก edge เกิน \$0.005 เทียบขอบเขตของ Chebyshev กับคำตอบจากรูประฆัง แล้วกลับทิศเป็นสูตรวางแผนจำนวนข้อมูล

\[ \begin{aligned}\text{Chebyshev}&:\ \frac{\sigma^2}{n\varepsilon^2}=\frac{4}{640{,}000(0.005)^2}=\frac{4}{16}=25\%\\ \text{bell}&:\ 2\,\Phi\Big(-\frac{0.005}{0.0025}\Big)=2\,\Phi(-2)=4.55\%\\ \text{planning}&:\ \frac{\sigma^2}{n\varepsilon^2}\le\delta\ \Rightarrow\ n\ge\frac{\sigma^2}{\delta\,\varepsilon^2}\end{aligned} \]

Chebyshev บอกไม่เกิน 25% ของจริงสำหรับระฆังคือ 4.55% ขอบเขตหลวมมากเพราะมันต้องใช้ได้กับทุกรูปแบบ รวมถึงกำไรที่หางอ้วน ใช้วางแผนเมื่อไม่มั่นใจเรื่องรูปร่าง เช่นอยากให้โอกาสคลาดไม่เกิน 5% ต้องใช้ 4 หาร 0.05 × 0.000025 = 3.2 ล้านไม้

ขั้นที่ 10 — เมื่อข้อมูลสัมพันธ์กัน: นับทุกคู่

ถ้าไม้ตอบสนองข่าวเดียวกัน ข้อสมมติของขั้นที่ 3 พัง กาง variance ของผลรวมเป็นตาราง covariance ทุกคู่ สมมติทุกคู่มี correlation ρ เท่ากัน

\[ \begin{aligned} &\operatorname{Var}\Big(\sum_{i=1}^{n}X_i\Big)\\ &=\sum_i\sum_j\operatorname{Cov}(X_i,X_j)\\ &=\sum_i\operatorname{Var}(X_i)+\sum_{i\ne j}\operatorname{Cov}(X_i,X_j)\\ &=n\sigma^2+n(n-1)\rho\sigma^2\\ &=n\sigma^2\big[1+(n-1)\rho\big]\\ \operatorname{Var}(\bar X_n)&=\frac{\sigma^2}{n}\big[1+(n-1)\rho\big] \end{aligned} \]

ตาราง n × n มีเส้นทแยง n ช่อง คือ variance ของตัวเอง และนอกเส้นทแยง n(n − 1) ช่อง ช่องละ ρσ² ถ้า ρ เป็นศูนย์ สูตรกลับเป็นขั้นที่ 3 พอดี ถ้า ρ เป็นบวกแม้นิดเดียว ตัวคูณในวงเล็บใหญ่ได้มากเมื่อ n ใหญ่ เพราะจำนวนคู่โตเร็วกว่าจำนวนไม้

ขั้นที่ 11 — correlation หนึ่งในพัน กินข้อมูลไปเก้าในสิบ

เทียบสูตรของขั้นที่ 10 กับ σ²/n ได้จำนวนไม้อิสระที่เทียบเท่า แทนหมื่นไม้ต่อวันกับ ρ = 0.001

\[ \begin{aligned} n_{\rm eff}&=\frac{n}{1+(n-1)\rho}\\ &n=10{,}000,\ \rho=0.001:\\ &\quad1+9{,}999(0.001)=10.999\\ &\quad n_{\rm eff}=\frac{10{,}000}{10.999}=909\\ &n\to\infty:\quad n_{\rm eff}\to\frac{1}{\rho}=1{,}000 \end{aligned} \]

หนึ่งในพันคูณเกือบหมื่นคู่ได้เกือบสิบ หมื่นไม้จึงมีค่าเท่ากับไม้อิสระ 909 ไม้ confidence interval ที่คำนวณด้วยจำนวนดิบแคบกว่าความจริงราวสามเท่า และไม่ว่าเพิ่มไม้เท่าไร ก็ได้ไม่เกินพันไม้อิสระ นี่คือเพดานที่การเทรดถี่ขึ้นทะลุไม่ได้

ขั้นที่ 12 — เมื่อไม่มีค่าเฉลี่ยให้เข้าหา: Cauchy

LLN ต้องการให้ค่าเฉลี่ยจริงมีค่าจำกัด ข้อมูลแบบ Cauchy ของหัวข้อ 1.11 ไม่มีค่าเฉลี่ย ดูว่าค่าเฉลี่ยจาก n ตัวเป็นอย่างไร

\[ \begin{aligned} \mathbb E|X|&=\int_{-\infty}^{\infty}\frac{|x|}{\pi(1+x^2)}\,dx=\infty\\ &X_i\sim\text{Cauchy}\\ &\Rightarrow\ \bar X_n\sim\text{Cauchy}\quad\text{for every }n\\ &P(|\bar X_n|\gt10)=P(|X_1|\gt10)\\ &=1-\frac{2}{\pi}\arctan(10)=6.3\%\\ &\quad\text{for every }n \end{aligned} \]

ค่าเฉลี่ยของหนึ่งล้านตัวเหวี่ยงเท่ากับตัวเดียว เพราะค่าสุดขั้วแต่ละตัวใหญ่พอจะลากค่าเฉลี่ยทั้งก้อน กำไรของกลยุทธ์ขายหางความเสี่ยงไม่ได้เป็น Cauchy พอดี แต่หางอ้วนพอให้ค่าเฉลี่ยตัวอย่างสวยหลายปีก่อนเหตุการณ์เดียวกินกำไรคืน

คำตอบ ตรวจเอง และแปลว่าอะไร

โจทย์ให้อะไรมาบ้าง: 10,000 ไม้ต่อวัน กำไรเฉลี่ย \$0.005 ต่อไม้ ความเหวี่ยง \$2 ต่อไม้ 252 วันเทรดต่อปี

คำตอบ: ต่อวัน กำไรคาดหวัง \$50 ความเหวี่ยง \$200 Sharpe 0.25 โอกาสขาดทุน 40.13% ต่อปี \$12,600 ความเหวี่ยง \$3,174.90 Sharpe 3.969 ให้ค่าเฉลี่ยพ้นศูนย์สองเท่าของความเหวี่ยงต้อง 64 วัน ถ้าไม้สัมพันธ์กัน 0.001 หมื่นไม้เท่ากับ 909 ไม้อิสระ

ตรวจเองใน 10 วินาที: 50/200 = 0.25 และ 0.25 × √252 = 0.25 × 15.87 = 3.97 และ 10,000/10.999 ≈ 909

แปลว่าอะไร: ก่อน annualize ต้องล็อกนิยามกำไร หน่วย ช่วงเวลา ต้นทุน และตรวจว่าวันเป็นอิสระจริง ถ้า edge อยู่รอดเฉพาะหลัง annualize แบบอุดมคติ ให้ถือเป็นสมมติฐาน ไม่ใช่งบความเสี่ยง

กับดัก: LLN ไม่ได้บอกว่าข้อมูลที่มีเป็นตัวแทนของอนาคต

LLN ต้องการค่าเฉลี่ยที่มีจริงและข้อมูลที่ไม่ซ้ำข่าวกัน มันไม่ได้ทำให้หางอ้วน การจับคู่คำสั่งที่เกี่ยวกัน หรือกติกาตลาดที่เปลี่ยนไป กลายเป็นข้อมูลอิสระ ในงานจริงให้คุมการกระจุกตัวต่อผู้ออกหลักทรัพย์ ข่าว และช่วงตลาด วัด autocorrelation ของกำไร และ stress ผลเมื่อจำนวนไม้ลดลงหรือความเหวี่ยงเพิ่มขึ้น

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
independenceแต่ละครั้งไม่เกี่ยวกันผลตอบแทนเกี่ยวพันกันข้ามเวลาจำนวนข้อมูลที่ใช้ได้จริงน้อยกว่าจำนวนที่นับได้
การมีค่าเฉลี่ยมีค่าเฉลี่ยที่แน่นอนอยู่รูปแบบหางอ้วนบางแบบไม่มีค่าเฉลี่ยเลยค่าเฉลี่ยที่คำนวณจะไม่นิ่งไม่ว่าจะเก็บข้อมูลนานแค่ไหน
ความคงที่ค่าเฉลี่ยที่แท้จริงไม่เปลี่ยนมันเปลี่ยนตามภาวะตลาดและการแข่งขันการเก็บข้อมูลนานขึ้นอาจไม่ช่วย เพราะข้อมูลเก่ามาจากโลกคนละใบ

แถวล่างเป็นความขัดแย้งหลักของงานนี้ ต้องการข้อมูลเยอะเพื่อความมั่นใจ แต่ข้อมูลเก่าใช้ไม่ได้

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

ใช้ตอบว่าต้องเก็บข้อมูลกี่ไม้หรือกี่ปีถึงจะสรุปได้ว่ากลยุทธ์มี edge จริง ใช้กำหนดว่าการจำลองต้องรันกี่รอบ และใช้เตือนนักลงทุนว่าค่าเฉลี่ยระยะสั้นแทบไม่บอกอะไร

หัวข้อ 14.2 ถามคำถามที่ใช้งานได้กว่า: ณ จำนวนข้อมูลที่มีอยู่ ค่าเฉลี่ยมีรูปร่างการกระจายแบบไหน และโอกาสเห็นผลระดับนี้เป็นเท่าไร

โค้ดตรวจ Law of Large Numbers, Chebyshev และกรณีที่ล้มเหลว 
import numpy as np
from math import sqrt, atan, pi
from statistics import NormalDist
Phi = NormalDist().cdf
for n, want in ((4, 0.25), (100, 0.05), (10_000, 0.005)):
    assert abs(0.5 / sqrt(n) - want) < 1e-12
assert (0.5 / 0.01) ** 2 == 2500
mu, sig = 0.005, 2.0
assert abs(sig / sqrt(100) - 0.2) < 1e-12 and abs((sig / mu) ** 2 - 160_000) < 1e-6 and abs((2 * sig / mu) ** 2 - 640_000) < 1e-6
n = 10_000
assert abs(n * mu - 50) < 1e-9 and sig * sqrt(n) == 200 and abs(Phi(-0.25) - 0.4013) < 5e-5
assert 252 * 50 == 12_600 and abs(200 * sqrt(252) - 3174.90) < 5e-3                # a 252-day year
assert abs(0.25 * sqrt(252) - 3.969) < 5e-4 and Phi(-3.969) < 5e-5
assert abs(sig ** 2 / (640_000 * 0.005 ** 2) - 0.25) < 1e-12 and abs(2 * Phi(-2) - 0.0455) < 5e-5
assert abs(10_000 / (1 + 9_999 * 0.001) - 909) < 0.5
assert abs(1 - 2 / pi * atan(10) - 0.063) < 5e-4
rng = np.random.default_rng(22)
X = rng.standard_cauchy((8000, 1000))
assert abs(np.mean(np.abs(X.mean(1)) > 10) - 0.063) < 0.015      # averaging does not tame Cauchy
days = rng.normal(mu, sig, (200, 10_000)).sum(1)
assert abs(days.mean() - 50) < 50 and abs(days.std() - 200) < 25

โค้ดยืนยันว่าความเหวี่ยงของค่าเฉลี่ยหดตามรากของ n desk ต้องใช้ 160,000 ไม้ถึงจะเห็น edge หนึ่งวันยังขาดทุนได้ 40% แต่หนึ่งปี Sharpe 3.97 Chebyshev ให้ขอบ 25% เทียบกับระฆัง 4.55% correlation หนึ่งในพันเหลือข้อมูลจริง 909 ไม้ และค่าเฉลี่ยของ Cauchy ไม่เคยนิ่ง

สรุปที่ใช้ได้จริง

  • ความเหวี่ยงของค่าเฉลี่ยคือ σ/√n อยากลดครึ่งหนึ่งต้องเก็บข้อมูลเพิ่มสี่เท่า
  • edge \$0.005 ต่อไม้ที่หมื่นไม้ต่อวัน: ขาดทุน 40% ของวัน ต้อง 64 วันถึงจะพ้นศูนย์สองเท่าของความเหวี่ยง
  • Chebyshev ให้ขอบเขตที่ใช้ได้กับทุกรูปแบบ หลวมแต่ปลอดภัย: 25% เทียบกับ 4.55% ของระฆัง
  • correlation 0.001 ทำให้หมื่นไม้เหลือ 909 ไม้อิสระ และเพดานคือ 1/ρ
  • ถ้าไม่มีค่าเฉลี่ยจริงแบบ Cauchy ค่าเฉลี่ยจากข้อมูลไม่นิ่งเลย
