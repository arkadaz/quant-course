22.1 Mortgage Mathematics and Pass-Throughs

ค่างวดบ้านเท่ากันทุกเดือน แต่ข้างในคือดอกเบี้ยที่หดลงกับเงินต้นที่โตแบบทบต้น และ pass-through ก็แค่ส่งเงินชุดนี้ของบ้านหลายพันหลังต่อให้ผู้ลงทุนหลังหักค่าบริการ

ธนาคารปล่อยกู้ซื้อบ้าน \$100,000 ดอกเบี้ย 8.125% ต่อปี ผ่อนเท่ากันทุกเดือน 30 ปี (360 งวด) ค่างวดเดือนละ \$742.50 ผ่านไปสองปี ธนาคารจะขายสินเชื่อก้อนนี้เข้ากองสินเชื่อ (pool) ที่จะออกเป็นตราสาร จึงต้องบอกผู้ซื้อว่าหนี้เหลือเท่าไร เจ้าหน้าที่คนหนึ่งตอบว่า “ผ่อนไปแล้ว 24 จาก 360 งวด หนี้ก็ลดไป 24/360 เหลือราว \$93,333” ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ผิดไปเกือบ \$5,000 หนี้ยังเหลือ \$98,301.53 ผู้กู้จ่ายไปแล้ว 24 งวด รวม \$17,819.93 แต่ตัดเงินต้นได้แค่ \$1,698.47 หรือ 1.7% ของยอดกู้ อีก \$16,121.47 เป็นดอกเบี้ย เพราะดอกเบี้ยของแต่ละเดือนคิดจากหนี้ที่ยังค้าง และสองปีแรกหนี้ยังค้างเกือบเต็มก้อน การเดา 24/360 คือการคิดว่าเงินต้นตัดเท่ากันทุกเดือน ซึ่งหน้านี้จะแสดงว่าไม่จริง

ภาพรวมก่อนลงสูตร

สินเชื่อบ้านแบบค่างวดคงที่ (level-payment mortgage) มีกติกาเดียว: ทุกเดือนหนี้งอกดอกเบี้ยตามอัตราของสัญญา แล้วค่างวดก็หักออก ค่างวดถูกเลือกให้หนี้เป็นศูนย์พอดีหลังงวดสุดท้าย เพราะดอกเบี้ยคิดจากหนี้ที่เหลือ เดือนแรก ๆ ค่างวดเกือบทั้งก้อนจึงเป็นดอกเบี้ย และเงินต้นที่ตัดค่อย ๆ โตขึ้นจนเป็นเกือบทั้งก้อนในปีท้าย ๆ

ธนาคารไม่ค่อยถือสินเชื่อไว้เองจนครบ 30 ปี มันรวมสินเชื่อหลายพันก้อนเป็น pool แล้วขายสิทธิ์ในเงินของ pool ให้ผู้ลงทุน แบบที่ง่ายที่สุดเรียก pass-through คือส่งดอกเบี้ยและเงินต้นทุกดอลลาร์ที่เก็บได้ต่อให้ผู้ถือตามสัดส่วน หลังหักค่าบริการของคนที่เก็บเงิน ตลาดนี้ใหญ่มาก ไตรมาสที่ 3 ปี 2012 ตราสารหนี้ที่ผูกกับสินเชื่อบ้านในสหรัฐฯ มี \$8.2 ล้านล้าน หรือ 23.3% ของตลาดตราสารหนี้ทั้งหมด \$35.3 ล้านล้าน

หน้านี้จะลองเงินกู้สามงวดด้วยมือ แล้วขยายเป็นสูตรค่างวด แยกงวดเป็นดอกเบี้ยกับเงินต้น หาหนี้ของเดือนใดก็ได้ในบรรทัดเดียว ถามว่าสินเชื่อมีค่าเท่าไรเมื่ออัตราตลาดเปลี่ยน แล้วรวมสินเชื่อ \$400 ล้านเป็น pass-through ตลอดหน้านี้ยังสมมติว่าไม่มีใครคืนหนี้ก่อนกำหนดและไม่มีใครผิดนัด สองเรื่องนั้นคือการคืนก่อนกำหนดกับมาตรฐาน PSA และสิ่งที่พังในปี 2007–2008

ศัพท์ที่ใช้ในหัวข้อนี้
Level-payment mortgage
สินเชื่อบ้านที่จ่ายเท่ากันทุกเดือนจนหนี้หมดพอดีในงวดสุดท้าย (fully amortizing) ใช้เป็นแบบพื้นฐานเพราะเงินทุกงวดรู้ล่วงหน้าถ้าไม่มีใครคืนก่อน แบบอื่นที่มีในตลาดคือ adjustable-rate mortgage (ARM) ที่อัตราปรับตามตลาด และ balloon ที่ผ่อนน้อยแล้วคืนก้อนใหญ่ตอนจบ
Principal และ interest
Principal คือเงินต้นที่ยังค้าง interest คือดอกเบี้ยของเดือนนั้นซึ่งคิดจากเงินต้นที่ค้างตอนต้นเดือน ค่างวดแต่ละงวดจ่ายดอกเบี้ยก่อน ส่วนที่เหลือไปตัดเงินต้น
Amortization schedule
ตารางที่แยกทุกงวดเป็นดอกเบี้ย เงินต้น และหนี้ปลายเดือน ใช้ตรวจว่าเงินที่รับกับยอดหนี้สอดคล้องกันทุกเดือน และเป็นวัตถุดิบของการตัด pool เป็นชิ้นที่ได้แต่ดอกเบี้ยหรือแต่เงินต้น
Mortgage-backed security (MBS) และ pass-through
MBS คือตราสารที่มีกองสินเชื่อบ้านเป็นหลักประกัน เป็น asset-backed security ชนิดหนึ่ง และการสร้างมันเรียก securitization pass-through คือแบบที่ง่ายที่สุด ส่งดอกเบี้ยและเงินต้นที่เก็บได้ให้ผู้ถือทุกคนตามสัดส่วน หลังหักค่าบริการ
Servicing fee และ pass-through rate
ค่าตอบแทนของผู้เก็บเงินจากผู้กู้ (servicer) คิดเป็นอัตราต่อปีบนหนี้ที่ค้าง อัตราที่ผู้ลงทุนได้จึงต่ำกว่าอัตราของผู้กู้เสมอ
WAC และ WAM
Weighted-average coupon และ weighted-average maturity คืออัตราดอกเบี้ยและจำนวนเดือนที่เหลือของสินเชื่อทุกก้อนใน pool เฉลี่ยโดยใช้หนี้ค้างเป็นน้ำหนัก ใช้สรุป pool ด้วยตัวเลขสองตัว
Agency MBS
MBS ที่ออกโดย Ginnie Mae, Fannie Mae หรือ Freddie Mac ซึ่งรับประกันว่าผู้ลงทุนได้เงินต้นคืนแม้ผู้กู้ผิดนัด ผู้ถือจึงเหลือความเสี่ยงเรื่องอัตราดอกเบี้ยและจังหวะการคืนเงิน MBS ที่ธนาคารพาณิชย์ออกเอง (non-agency) ไม่มีการรับประกันนี้
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$B_0,\ B_t$ยอดกู้ตั้งต้น และหนี้ค้างหลังจ่ายงวดที่ $t$ดอลลาร์
$c,\ r=c/12$อัตราดอกเบี้ยของสินเชื่อต่อปี และต่อเดือนสัดส่วนต่อปี, ต่อเดือน
$N,\ t$จำนวนงวดทั้งหมด และงวดที่กำลังดูเดือน
$A$ค่างวดคงที่ดอลลาร์ต่อเดือน
$I_t,\ P_t$ดอกเบี้ย และเงินต้นที่ตัดในงวดที่ $t$ดอลลาร์ต่อเดือน
$y$อัตราตลาดต่อปีที่ใช้คิดลด (ทบรายเดือน)สัดส่วนต่อปี
$s,\ c-s$ค่าบริการต่อปี และอัตราที่ผู้ลงทุนได้ (pass-through rate)สัดส่วนต่อปี
$C_t$เงินที่ pass-through ส่งให้ผู้ลงทุนในเดือน $t$ดอลลาร์ต่อเดือน

ขั้นที่ 1 — ลองด้วยมือ: เงินกู้ \$1,000 ผ่อนสามเดือน

ก่อนแตะ 360 งวด ลองเงินกู้ที่เล็กพอจะคิดบนกระดาษ กติกามีข้อเดียว: ทุกเดือนหนี้โตด้วยดอกเบี้ยก่อน แล้วค่างวดจึงหักออก และหนี้ต้องเป็นศูนย์พอดีหลังงวดสุดท้าย

โจทย์ให้อะไรมาบ้าง: $B_0=\$1{,}000$ ดอกเบี้ย 1% ต่อเดือน ($r=0.01$) ผ่อน 3 งวดเท่ากัน หาค่างวด $A$

\[ \begin{aligned} B_1&=1{,}000(1.01)-A,\\ B_2&=B_1(1.01)-A,\\ B_3&=B_2(1.01)-A,\\ B_3&=1{,}000(1.01)^3\\ &\quad-A(1.01^2+1.01+1)\\ &=1{,}030.301-3.0301A,\\ B_3=0&:\ A=\frac{1{,}030.301}{3.0301}\\ &\qquad\ \ =340.0221. \end{aligned} \]
เดือนดอกเบี้ย (1% ของหนี้ต้นเดือน)เงินต้นที่ตัดหนี้ปลายเดือน
110.00330.02669.98
26.70333.32336.66
33.37336.660.00

คำตอบ: ค่างวด \$340.02 เดือนแรกดอกเบี้ยกิน \$10.00 เพราะหนี้ยังค้างเต็ม \$1,000 เดือนสุดท้ายเหลือแค่ \$3.37 เงินต้นที่ตัดจึงโตขึ้นทุกเดือนทั้งที่ค่างวดเท่าเดิม นี่คือรูปพื้นที่สองสีด้านบนในขนาดย่อส่วน

ตรวจเองใน 10 วินาที: เงินต้นสามก้อน $330.02+333.32+336.66=1{,}000.00$ คือยอดกู้พอดี และดอกเบี้ยรวม $10.00+6.70+3.37=20.07$ เท่ากับ $3(340.0221)-1{,}000$

ขั้นที่ 2 — สูตรค่างวดของ $N$ งวด

เงินกู้สามงวดคลี่หนี้ออกทีละเดือนแล้วตั้งให้งวดสุดท้ายเป็นศูนย์ ขั้นนี้ทำแบบเดียวกันกับ $N$ งวด ผลรวมที่ออกมาเป็นอนุกรมเรขาคณิตตัวเดียวกับ annuity ในมูลค่าเงินตามเวลา

\[ \begin{aligned} B_t&=B_{t-1}(1+r)-A,\\ B_t&=B_0(1+r)^t\\ &\quad-A\sum_{j=0}^{t-1}(1+r)^j,\\ \sum_{j=0}^{t-1}(1+r)^j&=\frac{(1+r)^t-1}{r},\\ B_N=0&:\ A=\frac{B_0\,r}{1-(1+r)^{-N}}. \end{aligned} \]

บรรทัดแรกคือกติกาของสัญญา ใช้ซ้ำ $t$ ครั้งจะได้บรรทัดที่สอง ค่างวดที่จ่ายเดือนแรกถูกทบดอกเบี้ยไปอีก $t-1$ เดือน ส่วนงวดล่าสุดยังไม่ถูกทบเลย ตัวคูณเหล่านี้รวมกันเป็นอนุกรมเรขาคณิต บรรทัดสุดท้ายตั้ง $B_N=0$ ย้าย $A$ ไปอีกข้าง แล้วหารทั้งเศษและส่วนด้วย $(1+r)^N$ จึงได้ค่างวด

อัตรา 8.125% เป็นอัตราต่อปีที่ธรรมเนียมสินเชื่อบ้านสหรัฐฯ แบ่งเป็นรายเดือนด้วยการหารด้วย 12 ตรง ๆ จึงใช้ $r=0.08125/12$ ไม่ใช่ $1.08125^{1/12}-1$ ถ้าทบ 12 เดือนจริง ผู้กู้จ่าย $(1.006770833)^{12}-1=8.43\%$ ต่อปี ตัวเลข 8.125% จึงเป็นอัตราที่ประกาศ ไม่ใช่อัตราที่ทบแล้ว

ขั้นที่ 3 — สินเชื่อ \$100,000: ค่างวด งวดแรก และงวดที่สอง

โจทย์ให้อะไรมาบ้าง: $B_0=\$100{,}000$, $c=8.125\%$ ต่อปี, $N=360$ ดอกเบี้ยของแต่ละงวดคิดจากหนี้ต้นงวด $I_t=rB_{t-1}$ ส่วนที่เหลือของค่างวด $P_t=A-I_t$ ไปตัดเงินต้น

\[ \begin{aligned} r&=0.08125/12\\ &=0.006770833,\\ (1+r)^{360}&=11.350765,\\ A&=\frac{100{,}000(0.006770833)}{1-1/11.350765}\\ &=742.4972,\\ I_1&=0.006770833(100{,}000)\\ &=677.0833,\\ P_1&=742.4972-677.0833\\ &=65.4138,\\ B_1&=99{,}934.5862,\\ I_2&=rB_1=676.6404,\\ P_2&=65.8568,\\ B_2&=99{,}868.7294. \end{aligned} \]

คำตอบ: ค่างวด \$742.50 (ปัดจาก 742.4972) เดือนแรกเป็นดอกเบี้ย \$677.08 หรือ 91.19% ของค่างวด ตัดเงินต้นได้ \$65.41 หนี้ปลายเดือนแรกเหลือ \$99,934.59 เดือนที่สองดอกเบี้ยลดลงเล็กน้อยเพราะหนี้ลดลง \$65.41 เงินต้นที่ตัดจึงเพิ่มเป็น \$65.86

ตรวจเองใน 10 วินาที: $65.8568/65.4138=1.00677$ ซึ่งคือ $1+r$ พอดี ไม่ใช่เรื่องบังเอิญ ขั้นถัดไปบอกว่าทำไม

ขั้นที่ 4 — ทำไมเงินต้นโตเดือนละ $(1+r)$ เท่า

เงินต้นงวดที่สองเท่ากับงวดแรกคูณ $1+r$ ขั้นนี้แสดงว่าเป็นแบบนี้ทุกงวด เหตุผลสั้น ๆ คือทุกดอลลาร์ที่ตัดเงินต้นไปเดือนก่อน ทำให้ดอกเบี้ยเดือนนี้ลดลง $r$ ดอลลาร์ และเงินที่ประหยัดได้นั้นก็ไปตัดเงินต้นเพิ่ม

\[ \begin{aligned} P_t&=A-rB_{t-1}\\ &=A-r(B_{t-2}-P_{t-1})\\ &=(A-rB_{t-2})+rP_{t-1}\\ &=(1+r)P_{t-1},\\ P_t&=P_1(1+r)^{t-1},\\ P_{360}&=A-rB_{359}=\frac{A}{1+r}\\ &=737.5037,\\ P_1&=\frac{P_{360}}{(1+r)^{359}}=\frac{A}{(1+r)^{360}}\\ &=65.4138. \end{aligned} \]

บรรทัดที่สองแทน $B_{t-1}=B_{t-2}-P_{t-1}$ จากกติกาของสัญญา บรรทัดที่สามเห็นว่าวงเล็บแรกคือ $P_{t-1}$ เอง เงินต้นจึงโตแบบทบต้นด้วยอัตราเดียวกับดอกเบี้ย เดือนที่ 24 จึงตัดเงินต้น $65.4138(1+r)^{23}=76.40$ เท่านั้น

งวดสุดท้ายต้องล้างหนี้ที่เหลือ $B_{359}$ พร้อมดอกเบี้ยของมัน จึงได้ $B_{359}(1+r)=A$ เงินต้นงวดสุดท้ายคือ \$737.50 และดอกเบี้ยเหลือแค่ \$4.99 ย้อนกลับมาจะได้ว่าเงินต้นงวดแรกคือค่างวดที่คิดลดไป 360 เดือน $742.4972/11.350765=65.4138$ สัญญายิ่งยาว เงินต้นก้อนแรกยิ่งเล็ก นี่คือเหตุที่พื้นที่เขียวในรูปภาพรวมเริ่มบางมาก

ขั้นที่ 5 — หนี้ของเดือนใดก็ได้ และคำตอบของโจทย์

ถ้าอยากรู้หนี้หลังสองปี ไม่ต้องไล่ตาราง 24 แถว แทนสูตรค่างวดลงในสูตรหนี้ของการคลี่ทีละเดือน ค่างวดจะหายไปจากสูตร เหลือแค่สัดส่วนของตัวทบต้น

\[ \begin{aligned} g_t&=(1+r)^t,\\ B_t&=B_0\,g_t-A\,\frac{g_t-1}{r}\\ &=B_0\,\frac{g_N-g_t}{g_N-1}\\ &=A\,\frac{1-(1+r)^{-(N-t)}}{r},\\ g_{24}&=1.175804,\\ B_{24}&=\frac{100{,}000(10.174960)}{10.350765}\\ &=98{,}301.53,\\ 24A&=17{,}819.9323,\\ B_0-B_{24}&=1{,}698.4658,\\ \sum_{t=1}^{24}I_t&=24A-(B_0-B_{24})\\ &=16{,}121.4665. \end{aligned} \]

เขียน $g_t$ แทน $(1+r)^t$ ให้สั้นลง บรรทัดที่สามได้จากแทน $A$ แล้วรวมเศษส่วน ตัวเลขของสองปีคือ $g_{360}-g_{24}=11.3507646-1.1758042=10.1749604$ หารด้วย $g_{360}-1=10.350765$

บรรทัดที่สี่คือความหมายที่ใช้บ่อยที่สุดในบทนี้: หนี้ที่ค้างเท่ากับมูลค่าวันนี้ของค่างวดที่เหลือ $N-t$ งวด คิดลดด้วยอัตราของสินเชื่อเอง ผู้กู้ที่อยากปิดหนี้ก่อนกำหนดจึงจ่ายเท่านี้พอดี ใน 24 งวดผู้กู้จ่ายไป \$17,819.93 ตัดเงินต้นได้ \$1,698.47 ที่เหลือ \$16,121.47 หรือ 90.5% ของเงินที่จ่ายเป็นดอกเบี้ย

ขั้นที่ 6 — สินเชื่อนี้มีค่าเท่าไรเมื่ออัตราตลาดเปลี่ยน

สำหรับคนที่ซื้อสินเชื่อไป มันคือเงิน \$742.50 ต่อเดือนอีก 360 เดือน มูลค่าวันนี้ได้จากการคิดลดด้วยอัตราตลาด $y$ แบบเดียวกับพันธบัตรในyield curve, duration และ convexity ขั้นนี้ถามว่ามูลค่านั้นขยับเท่าไร และทำไมผู้กู้ไม่ยอมให้มันขึ้นไปได้เต็มที่

\[ \begin{aligned} V(y)&=\sum_{k=1}^{360}\frac{A}{(1+y/12)^k}\\ &=A\,\frac{1-(1+y/12)^{-360}}{y/12},\\ V(8.125\%)&=742.4972(134.6806)\\ &=100{,}000.00,\\ V(6\%)&=742.4972(166.7916)\\ &=123{,}842.30,\\ V(10\%)&=742.4972(113.9508)\\ &=84{,}608.16. \end{aligned} \]

เมื่อ $y=c$ ตัวคูณ 134.6806 คือส่วนกลับของ $r/(1-(1+r)^{-N})$ ในสูตรค่างวดพอดี มูลค่าจึงเท่ากับยอดกู้ ถ้าอัตราตลาดลงเป็น 6% เงินชุดเดิมมีค่าขึ้น 23.8% ถ้าขึ้นเป็น 10% ค่าลง 15.4% ทิศเดียวกับพันธบัตรทุกตัว ในทางปฏิบัติคนที่ซื้อสินเชื่อคิดลดด้วยอัตราที่ต่ำกว่า $c$ ไม่ได้ เพราะส่วนต่างต้องจ่ายค่าบริการ ค่าความเสี่ยงผิดนัด ค่าความไม่แน่นอนเรื่องการคืนก่อน และกำไรของผู้ปล่อยกู้

แต่ผู้กู้บ้านในสหรัฐฯ มีสิทธิปิดหนี้เมื่อไรก็ได้ด้วยยอดหนี้ค้าง (\$100,000 ในวันแรก) ถ้าอัตราลงเป็น 6% เขาจะกู้ก้อนใหม่ที่ถูกกว่ามาปิดก้อนเดิม เจ้าของสินเชื่อจึงได้ \$100,000 คืน ไม่ใช่ของที่มีค่า \$123,842.30 สิทธินี้คือการคืนก่อนกำหนด (prepayment) และมันทำให้ผู้ถือสินเชื่อเหมือนขาย option ให้ผู้กู้ไปแล้วตั้งแต่วันแรก

ขั้นที่ 7 — รวมสินเชื่อ \$400 ล้านเป็น pass-through

ถ้าธนาคารรวมสินเชื่อแบบเดียวกันหลายพันก้อนเป็น pool \$400 ล้าน แล้วออกตราสารที่ส่งเงินทุกดอลลาร์ที่เก็บได้ต่อให้ผู้ถือตามสัดส่วน ผู้ถือจะได้อะไรในแต่ละเดือน ขั้นนี้เขียนกติกาของ pass-through: servicer หักค่าบริการจากดอกเบี้ย ส่วนเงินต้นส่งต่อครบ ตัวอย่างใช้ pool ที่ทุกก้อนเหมือนกัน (8.125%, 360 งวด) จึงคิดเหมือนสินเชื่อก้อนเดียวที่ใหญ่ขึ้น 4,000 เท่า และค่าบริการ $s=0.625\%$ ต่อปี

\[ \begin{aligned} C_t&=\frac{c-s}{12}B_{t-1}+P_t,\\ 4{,}000A&=2{,}969{,}988.72,\\ \tfrac{c}{12}B_0&=2{,}708{,}333.33,\\ \tfrac{s}{12}B_0&=208{,}333.33,\\ \tfrac{c-s}{12}B_0&=2{,}500{,}000.00,\\ P_1&=261{,}655.39,\\ C_1&=2{,}761{,}655.39. \end{aligned} \]

บรรทัดแรกคือนิยาม ผู้ลงทุนได้ดอกเบี้ยที่อัตรา $c-s=7.50\%$ บนหนี้ต้นเดือน บวกเงินต้นทุกดอลลาร์ที่ผู้กู้คืน เดือนแรกเก็บจากผู้กู้ได้ \$2,969,988.72 เป็นดอกเบี้ย \$2,708,333.33 และเงินต้น \$261,655.39 ค่าบริการ \$208,333.33 ไปที่ servicer ที่เหลือ \$2,761,655.39 ส่งให้ผู้ลงทุน

ผู้ถือ 1% ของตราสาร (หน้าตั๋ว \$4 ล้าน) ได้ 1% ของทุกก้อน คือ \$27,616.55 ในเดือนแรก ค่าบริการคิดจากหนี้ค้างซึ่งลดลงทุกเดือน เงินรวมที่ผู้ลงทุนได้จึงขยับขึ้นช้า ๆ เป็น \$2,771,498.50 ในเดือนที่ 60 ทั้งที่ผู้กู้จ่ายเท่าเดิม

ขั้นที่ 8 — WAC และ WAM: สรุป pool ด้วยสองตัวเลข

pool จริงมีสินเชื่ออัตราและอายุต่างกัน เอกสารของตราสารจึงสรุปด้วยค่าเฉลี่ยที่ใช้หนี้ค้างเป็นน้ำหนัก ขั้นนี้นิยามสองค่านี้ ลองกับ pool สามก้อน แล้วถามว่าใช้สองตัวเลขนี้แทน pool ได้แค่ไหน

\[ \begin{aligned} w_j&=\frac{B_j}{\sum_i B_i},\\ \mathrm{WAC}&=\sum_j w_jc_j,\\ \mathrm{WAM}&=\sum_j w_jm_j,\\ w&=(0.5,\ 0.375,\ 0.125),\\ \mathrm{WAC}&=0.5(7.5\%)+0.375(8\%)\\ &\quad+0.125(9.5\%)=7.9375\%,\\ \mathrm{WAM}&=0.5(300)+0.375(330)\\ &\quad+0.125(355)=318.125. \end{aligned} \]

pool สมมติมีสามก้อน: \$200,000 อัตรา 7.5% เหลือ 300 เดือน, \$150,000 อัตรา 8% เหลือ 330 เดือน และ \$50,000 อัตรา 9.5% เหลือ 355 เดือน หนี้รวม \$400,000 น้ำหนักจึงเป็น 0.5, 0.375 และ 0.125 อัตราของ pass-through ที่ออกจาก pool นี้ต้องต่ำกว่า WAC อย่างเคร่งครัด เพราะส่วนต่างคือค่าบริการ

ค่างวดจริงของสามก้อนรวมกันคือ $1{,}477.98+1{,}125.64+421.48=\$3{,}025.10$ แต่ถ้าสร้างสินเชื่อก้อนเดียว \$400,000 ที่อัตรา WAC และ 318.125 เดือน จะได้ \$3,016.17 ขาดไป \$8.93 ต่อเดือน เพราะค่างวดไม่ได้เป็นเส้นตรงในอัตราและอายุ WAC กับ WAM จึงเป็นบทสรุป ไม่ใช่ตัวแทนที่แม่นของ pool

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

คิดว่าเงินต้นตัดเท่ากันทุกเดือน: หนี้หลัง 24 งวดไม่ใช่ $100{,}000(1-24/360)=\$93{,}333$ แต่เป็น \$98,301.53 ต่างกันเกือบ \$5,000 ต่อสินเชื่อก้อนเดียว และที่ 15 ปีต่างกันถึง \$27,112

คิดดอกเบี้ยจากยอดกู้เดิมทุกเดือน: แบบนี้ได้ดอกเบี้ย \$677.08 ทุกเดือน รวม 30 ปี \$243,750 ทั้งที่สัญญาคิดจากหนี้ค้างและรวมแค่ \$167,298.98

ใช้ค่างวดที่ปัดแล้วคิดต่อ: $742.50-677.08=65.42$ ไม่ใช่ 65.41 ที่ถูก และถ้าผ่อน \$742.50 ครบ 360 งวด หนี้ปลายสัญญาจะติดลบ \$4.31 เงินที่ผ่อนเกินเดือนละ 0.28 เซนต์ทบกัน 30 ปี ตารางของ servicer จึงต้องใช้ค่างวดเต็มแล้วปรับงวดสุดท้าย

ลืมหารค่าบริการด้วย 12: $400{,}000{,}000(0.00625)=\$2.5$ ล้าน เท่ากับดอกเบี้ยสุทธิทั้งเดือนของผู้ลงทุนพอดี ค่าที่ถูกคือ \$208,333.33

ทบอัตรารายปีเป็นรายเดือน: ถ้าใช้ $1.08125^{1/12}-1=0.6531\%$ แทน $0.6771\%$ ค่างวดจะออกมา \$722.45 ต่ำไป \$20.05 ต่อเดือน และตารางทั้งชุดไม่ตรงกับสัญญา

ใช้ทำอะไรบนโต๊ะจริง

ทุกเดือน servicer ต้องกระทบยอดให้ได้ว่า เงินที่เก็บจากผู้กู้เท่ากับเงินที่ส่งผู้ลงทุนบวกค่าบริการ (\$2,761,655.39 + \$208,333.33 = \$2,969,988.72) และหนี้ปลายเดือนเท่ากับหนี้ต้นเดือนลบเงินต้นที่คืน ผู้ลงทุนติดตาม pool ด้วยสัดส่วนหนี้ที่ยังค้าง (pool factor) เช่น $B_{24}/B_0=0.9830$ ถ้าไม่มีใครคืนก่อนกำหนด ตัวเลขที่รายงานจริงต่ำกว่านี้เสมอ และส่วนที่ต่างคือสิ่งที่มาตรฐาน PSAใช้วัดความเร็ว

ตลาดนี้เกิดหลังวิกฤตทศวรรษ 1930 เมื่อสินเชื่อแบบจ่ายแต่ดอกเบี้ยแล้วคืนก้อนใหญ่ตอนจบ (balloon) ทำให้คนเสียบ้านจำนวนมากเมื่อธนาคารไม่ต่อสัญญา สินเชื่อผ่อนเท่ากันจนหมดหนี้จึงกลายเป็นแบบมาตรฐาน และ pass-through ตัวแรกออกในปี 1970

โจทย์ตรวจความเข้าใจ

1. กู้ \$300,000 ดอกเบี้ย 6% ต่อปี ผ่อน 30 ปี ค่างวดเท่าไร และงวดแรกตัดเงินต้นเท่าไร?

เฉลย

$r=0.005$ และ $1.005^{360}=6.022575$ ค่างวด $300{,}000(0.005)/(1-1/6.022575)=\$1{,}798.65$ ดอกเบี้ยงวดแรก $0.005(300{,}000)=\$1{,}500$ ตัดเงินต้น \$298.65 หรือ 16.6% ของค่างวด ตรวจด้วยความจริงที่ว่าเงินต้นงวดแรกคือค่างวดคิดลดไป 360 เดือน: $1{,}798.65/6.022575=298.65$

2. สินเชื่อข้อ 1 ผ่อนไป 5 ปี หนี้เหลือเท่าไร และจ่ายดอกเบี้ยไปเท่าไร?

เฉลย

$1.005^{60}=1.348850$ หนี้ $300{,}000(6.022575-1.348850)/(6.022575-1)=\$279{,}163.07$ จ่ายไป $60(1{,}798.6516)=\$107{,}919.09$ ตัดเงินต้น \$20,836.93 ดอกเบี้ยจึงเป็น \$87,082.16 หรือ 80.7% ของเงินที่จ่าย

3. pass-through \$100 ล้าน WAC 6.5% ค่าบริการ 0.5% ต่อปี เดือนแรกผู้ลงทุนได้ดอกเบี้ยเท่าไร และ servicer ได้เท่าไร?

เฉลย

อัตราที่ผู้ลงทุนได้ $6.5\%-0.5\%=6.0\%$ ดอกเบี้ย $100{,}000{,}000(0.06/12)=\$500{,}000$ ค่าบริการ $100{,}000{,}000(0.005/12)=\$41{,}666.67$ รวมกันเป็นดอกเบี้ยที่ผู้กู้จ่าย \$541,666.67 ถ้าลืมหารด้วย 12 ค่าบริการจะเป็น \$500,000 เท่ากับดอกเบี้ยทั้งหมดของผู้ลงทุน

function num(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(`${name} must be a finite number`);
  return x;
}
function positive(name, x) {
  if (!(num(name, x) > 0)) throw new RangeError(`${name} must be positive`);
  return x;
}
function months(name, n) {
  if (!Number.isInteger(n) || n < 1) throw new RangeError(`${name} must be a whole number of months, at least 1`);
  return n;
}

// Level payment that takes B0 to zero after N months at annual rate c (monthly rate c/12).
// N may be fractional here (a pool's WAM); the month-by-month schedule needs whole months.
function levelPayment(B0, c, N) {
  positive('B0', B0); positive('c', c); positive('N', N);
  const r = c / 12;
  return B0 * r / (1 - (1 + r) ** -N);
}

// Month-by-month schedule: interest on the opening balance, the rest of the payment is principal.
function schedule(B0, c, N) {
  months('N', N);
  const A = levelPayment(B0, c, N), r = c / 12, rows = [];
  let B = B0, paidI = 0;
  for (let t = 1; t <= N; t++) {
    const I = r * B, P = A - I;
    B -= P; paidI += I;
    rows.push({t, I, P, B, paidI});
  }
  return {A, rows};
}

// Balance after t payments in closed form.
function balanceAfter(B0, c, N, t) {
  months('N', N); levelPayment(B0, c, N);
  if (!Number.isInteger(t) || t < 0 || t > N) throw new RangeError('t must be a whole month from 0 to N');
  const g = (1 + c / 12) ** N;
  return B0 * (g - (1 + c / 12) ** t) / (g - 1);
}

// Value today of n remaining payments A at market rate y (annual, compounded monthly).
function loanValue(A, y, n) {
  positive('A', A); positive('y', y); months('n', n);
  const m = y / 12;
  return A * (1 - (1 + m) ** -n) / m;
}

// One month of a pass-through: the servicing fee s comes out of interest on the opening balance.
function passThroughMonth(B, c, s, A) {
  positive('B', B); positive('c', c); positive('A', A);
  if (!(num('s', s) >= 0 && s < c)) throw new RangeError('servicing fee must be at least 0 and below the mortgage rate');
  const gross = c / 12 * B, fee = s / 12 * B, principal = A - gross;
  return {collected: A, gross, fee, net: gross - fee, principal, investor: gross - fee + principal};
}

// Balance-weighted coupon and remaining term of a pool: loans = [[balance, rate, months], ...].
function wacWam(loans) {
  if (!Array.isArray(loans) || loans.length === 0) throw new RangeError('loans must be a non-empty array');
  let total = 0, wc = 0, wm = 0;
  for (const [B, c, m] of loans) { positive('balance', B); positive('rate', c); months('months', m); total += B; wc += B * c; wm += B * m; }
  return {total, wac: wc / total, wam: wm / total};
}

const loan = schedule(100000, 0.08125, 360);
const A = loan.A, row = t => loan.rows[t - 1];
const half = loan.rows.find(x => 100000 - x.B >= 50000).t;
const cross = loan.rows.find(x => x.P > x.I).t;
const poolA = levelPayment(400e6, 0.08125, 360);
const pool = passThroughMonth(400e6, 0.08125, 0.00625, poolA);
const loans = [[200000, 0.075, 300], [150000, 0.08, 330], [50000, 0.095, 355]];
const w = wacWam(loans);

สิ่งที่ควรตอบได้หลังอ่าน

  • ค่างวดคือค่าที่ทำให้หนี้เป็นศูนย์พอดีหลังงวดสุดท้าย: \$100,000 ที่ 8.125% 360 งวด ได้ \$742.50 ต่อเดือน
  • ดอกเบี้ยคิดจากหนี้ค้าง เงินต้นที่ตัดจึงโตเดือนละ $(1+r)$ เท่า เริ่มจาก \$65.41 ซึ่งคือค่างวดที่คิดลดไป 360 เดือน และแซงดอกเบี้ยได้ในเดือนที่ 259
  • หนี้ค้างเท่ากับมูลค่าวันนี้ของค่างวดที่เหลือ หลังสองปีจึงเหลือ \$98,301.53 ไม่ใช่ \$93,333
  • สินเชื่อมีค่าขึ้นลงตามอัตราตลาด (\$123,842.30 ที่ 6%) แต่ผู้กู้ปิดหนี้ได้ที่ยอดค้าง ของที่ผู้ถือได้จริงจึงมีเพดานด้านบน
  • pass-through ส่งดอกเบี้ยที่อัตรา $c-s$ บวกเงินต้นทั้งหมดให้ผู้ถือตามสัดส่วน และ WAC กับ WAM สรุป pool ได้ แต่แทน pool ไม่ได้พอดี

หน้าถัดไป การคืนก่อนกำหนดและมาตรฐาน PSA ปล่อยให้ผู้กู้คืนหนี้ก่อนเวลา แล้ววัดว่าเงินต้นกลับมาเร็วแค่ไหน ทำไม pool “30 ปี” จึงอายุจริงแค่ราว 12 ปี และทำไมผู้ถือ MBS ได้ราคาที่ขึ้นยากแต่ลงง่าย
