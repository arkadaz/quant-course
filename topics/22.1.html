22.1 Mortgage Mathematics and Pass-Throughs

คนกู้ซื้อบ้านจ่ายค่างวดเท่ากันทุกเดือน แต่ข้างในค่างวด ส่วนที่เป็นดอกเบี้ยหดลงทุกเดือน ส่วนที่ลดหนี้โตขึ้นแบบทบต้น ส่วน pass-through คือการรวมสินเชื่อบ้านหลายพันก้อน แล้วส่งเงินที่เก็บได้ต่อให้ผู้ลงทุนหลังหักค่าบริการ

คนส่วนใหญ่ซื้อบ้านด้วยเงินกู้จากธนาคาร เงินกู้ซื้อบ้านเรียกว่า mortgage แบบที่พบบ่อยที่สุดในสหรัฐฯ คือผ่อนเท่ากันทุกเดือนนาน 30 ปี เงินที่ผู้กู้จ่ายแต่ละเดือนเรียกว่า “ค่างวด” ค่างวดหนึ่งงวดจ่ายสองอย่าง อย่างแรกคือดอกเบี้ยของเดือนนั้น อย่างที่สองคือส่วนที่เหลือ ซึ่งไปลดหนี้ที่ยังค้าง หนี้ที่ยังค้างนี้เรียกว่าเงินต้น (principal)

ธนาคารมักไม่ถือเงินกู้ไว้เองจนครบ 30 ปี มันขายเงินกู้ต่อให้คนอื่น ซึ่งจะเอาไปรวมกับเงินกู้อีกหลายพันก้อน ตอนขาย ผู้ซื้อต้องรู้ว่าผู้กู้ยังติดหนี้อยู่เท่าไร เพราะนั่นคือเงินต้นที่ผู้ซื้อจะได้คืนในอนาคต

ของที่รู้ (ตัวเลขตัวอย่าง):

  • ยอดกู้ตอนเริ่ม $B_0=\$100{,}000$
  • ดอกเบี้ยตามสัญญา $c=8.125\%$ ต่อปี
  • ผ่อนเดือนละงวด นาน 30 ปี จึงมี $N=30\times12=360$ งวด
  • ค่างวด $A=\$742.50$ ต่อเดือน (หน้านี้จะคำนวณตัวเลขนี้ให้ดูทีละขั้น)

ผู้กู้ผ่อนมาแล้วสองปี คือ 24 งวด เขียนหนี้ที่ค้างหลังงวดที่ 24 ว่า $B_{24}$ เจ้าหน้าที่คนหนึ่งให้เหตุผลว่า ผ่อนไปแล้ว 24 จาก 360 งวด หนี้ก็น่าจะลดไปในสัดส่วนเดียวกัน:

\[\begin{aligned}B_{24}&\approx100{,}000\times\Big(1-\frac{24}{360}\Big)\\&=100{,}000\times\frac{336}{360}\\&=\$93{,}333.33.\end{aligned}\]

ลองตอบก่อนเปิดเฉลย

ผิด หนี้จริงยังเหลือ $B_{24}=\$98{,}301.53$ (หน้านี้จะคำนวณให้ดูทีละขั้น) ห่างจากที่เดา $98{,}301.53-93{,}333.33=\$4{,}968.20$ เกือบ \$5,000

ลองดูว่าเงินที่ผู้กู้จ่ายไปใน 24 งวดไปอยู่ที่ไหน ผู้กู้จ่ายไปทั้งหมด $24A$ แต่หนี้ลดลงแค่ $B_0-B_{24}$ ส่วนที่เหลือจึงเป็นดอกเบี้ย (ใช้ค่างวดก่อนปัดเศษ $A=742.4972$):

\[\begin{aligned}24A&=24\times742.4972\\&=\$17{,}819.93,\\B_0-B_{24}&=100{,}000-98{,}301.53\\&=\$1{,}698.47,\\24A-(B_0-B_{24})&=17{,}819.93-1{,}698.47\\&=\$16{,}121.47.\end{aligned}\]

หนี้ลดไปแค่ $1{,}698.47/100{,}000=1.7\%$ ของยอดกู้ เพราะดอกเบี้ยของแต่ละเดือนคิดจากหนี้ที่ยังค้าง สองปีแรกหนี้ยังค้างเกือบเต็มก้อน ค่างวดเกือบทั้งก้อนจึงเป็นดอกเบี้ย การเดาแบบ 24/360 แอบสมมติว่าเงินต้นลดเท่ากันทุกเดือน หน้านี้จะแสดงว่าไม่จริง

ภาพรวมก่อนลงสูตร

หน้านี้ดูสินเชื่อบ้านแบบค่างวดคงที่ (level-payment mortgage) คือสัญญาที่ผู้กู้จ่ายเท่ากันทุกเดือน และหนี้หมดพอดีหลังงวดสุดท้าย กติกาของสัญญามีข้อเดียว ทุกเดือนหนี้ที่ค้างงอกดอกเบี้ยตามอัตราของสัญญา แล้วค่างวดก็หักออก ค่างวดถูกเลือกมาให้หนี้เหลือศูนย์พอดีหลังงวดสุดท้าย

กติกานี้มีผลที่คนมักมองข้าม ดอกเบี้ยของแต่ละเดือนคิดจากหนี้ที่ยังค้าง ช่วงแรกหนี้ยังค้างเกือบเต็ม ค่างวดเกือบทั้งก้อนจึงเป็นดอกเบี้ย เงินที่ไปลดหนี้มีนิดเดียว พอหนี้ค่อย ๆ ลด ดอกเบี้ยก็ลดตาม ส่วนที่ไปลดหนี้จึงโตขึ้น จนในปีท้าย ๆ ค่างวดเกือบทั้งก้อนเป็นเงินต้น

ทำไมคนนอกธนาคารต้องสนใจ เพราะสินเชื่อหลายพันก้อนถูกรวมเป็นกองเดียว เรียกว่า pool แล้วสิทธิ์รับเงินจาก pool ถูกขายให้ผู้ลงทุน ตราสารแบบนี้เรียกว่า MBS (mortgage-backed security) แบบที่ง่ายที่สุดคือ pass-through ซึ่งส่งดอกเบี้ยและเงินต้นทุกดอลลาร์ที่เก็บจากผู้กู้ได้ต่อให้ผู้ลงทุนตามสัดส่วนที่ถือ หลังหักค่าบริการของคนที่ทำหน้าที่เก็บเงิน

ตลาดนี้ใหญ่มาก SIFMA (สมาคมอุตสาหกรรมหลักทรัพย์ของสหรัฐฯ) รายงานว่า ณ ไตรมาสที่ 3 ปี 2012 ตราสารหนี้ทั้งหมดในสหรัฐฯ มีมูลค่า \$35.3 ล้านล้าน ในจำนวนนี้เป็นตราสารที่ผูกกับสินเชื่อบ้าน \$8.2 ล้านล้าน คิดเป็น $8.2/35.3\approx23\%$ (SIFMA รายงาน 23.3% ซึ่งคิดจากยอดก่อนปัดเศษ) ราวหนึ่งในสี่ของตลาดตราสารหนี้ทั้งหมด

หน้านี้เดินทีละขั้น:

  • ลองเงินกู้สามงวดด้วยมือ แล้วขยายเป็นสูตรค่างวดของ $N$ งวด
  • แยกค่างวดแต่ละงวดเป็นดอกเบี้ยกับเงินต้น และดูว่าทำไมเงินต้นโตแบบทบต้น
  • หาหนี้ของเดือนใดก็ได้ด้วยสูตรบรรทัดเดียว แล้วตอบโจทย์ข้างบน
  • ถามว่าสินเชื่อมีค่าเท่าไรเมื่อดอกเบี้ยในตลาดเปลี่ยน
  • รวมสินเชื่อ \$400 ล้านเป็น pass-through แล้วสรุป pool ด้วยตัวเลขสองตัว

ตลอดหน้านี้ สมมติว่าไม่มีผู้กู้คนไหนคืนหนี้ก่อนกำหนด และไม่มีใครผิดนัด สองเรื่องนั้นอยู่ในหน้าการคืนก่อนกำหนดกับมาตรฐาน PSA และหน้าสิ่งที่พังในปี 2007–2008

ศัพท์ที่ใช้ในหัวข้อนี้
Level-payment mortgage
สินเชื่อบ้านที่จ่ายเท่ากันทุกเดือน และหนี้หมดพอดีในงวดสุดท้าย (คำนี้เรียกว่า fully amortizing) หน้านี้ใช้แบบนี้เป็นแบบพื้นฐาน เพราะถ้าไม่มีใครคืนหนี้ก่อนกำหนด เงินทุกงวดรู้ล่วงหน้าหมด ในตลาดยังมีแบบอื่น เช่น adjustable-rate mortgage (ARM) ที่อัตราดอกเบี้ยปรับตามตลาด และ balloon ที่ผ่อนน้อย ๆ แล้วคืนก้อนใหญ่ตอนจบ
Principal และ interest
Principal คือเงินต้น หมายถึงหนี้ที่ยังค้าง interest คือดอกเบี้ยของเดือนนั้น คิดจากเงินต้นที่ค้างตอนต้นเดือน ค่างวดแต่ละงวดจ่ายดอกเบี้ยก่อน ส่วนที่เหลือจึงไปลดเงินต้น
Amortization schedule
ตารางที่แยกทุกงวดเป็นดอกเบี้ย เงินต้นที่ลด และหนี้ปลายเดือน ใช้ตรวจว่าเงินที่รับมากับยอดหนี้ตรงกันทุกเดือน ตารางนี้ยังเป็นวัตถุดิบตอนหั่น pool เป็นชิ้นที่ได้แต่ดอกเบี้ย หรือได้แต่เงินต้น
Pool, mortgage-backed security (MBS) และ pass-through
Pool คือกองสินเชื่อบ้านหลายพันก้อนที่รวมไว้ด้วยกัน MBS คือตราสารที่ผู้ถือได้เงินจาก pool นั้น MBS เป็น asset-backed security ชนิดหนึ่ง (ตราสารที่มีทรัพย์สินก้อนหนึ่งหนุนหลัง) และการสร้างตราสารแบบนี้เรียกว่า securitization pass-through คือ MBS แบบที่ง่ายที่สุด มันส่งดอกเบี้ยและเงินต้นที่เก็บได้ให้ผู้ถือทุกคนตามสัดส่วน หลังหักค่าบริการ
Servicer, servicing fee และ pass-through rate
Servicer คือบริษัทที่เก็บค่างวดจากผู้กู้ทุกเดือนแล้วส่งต่อให้ผู้ลงทุน ค่าตอบแทนของมันเรียกว่า servicing fee คิดเป็นอัตราต่อปีบนหนี้ที่ยังค้าง อัตราดอกเบี้ยที่ผู้ลงทุนได้ (pass-through rate) คืออัตราของผู้กู้ลบค่าบริการ จึงต่ำกว่าอัตราของผู้กู้เสมอ
WAC และ WAM
Weighted-average coupon คืออัตราดอกเบี้ยเฉลี่ยของสินเชื่อทุกก้อนใน pool weighted-average maturity คือจำนวนเดือนที่เหลือเฉลี่ย ทั้งสองค่าใช้หนี้ค้างของแต่ละก้อนเป็นน้ำหนัก ใช้สรุป pool ด้วยตัวเลขสองตัว
Agency MBS
MBS ที่ออกโดย Ginnie Mae, Fannie Mae หรือ Freddie Mac หน่วยงานเหล่านี้รับประกันว่าผู้ลงทุนจะได้เงินต้นคืนแม้ผู้กู้ผิดนัด ผู้ถือจึงเหลือความเสี่ยงแค่สองเรื่อง คืออัตราดอกเบี้ยในตลาด และจังหวะที่ผู้กู้คืนเงิน MBS ที่ธนาคารพาณิชย์ออกเอง (non-agency) ไม่มีการรับประกันนี้

ขั้นที่ 1 — ลองด้วยมือ: เงินกู้ \$1,000 ผ่อนสามเดือน

360 งวดยาวเกินจะคิดบนกระดาษ จึงเริ่มจากเงินกู้เล็ก ๆ ที่มีแค่สามงวดก่อน เพื่อดูว่าค่างวดหามาอย่างไร กติกามีข้อเดียว ทุกเดือนหนี้งอกดอกเบี้ยก่อน แล้วค่างวดจึงหักออก และหลังงวดสุดท้ายหนี้ต้องเหลือศูนย์พอดี

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ):

  • ยอดกู้ $B_0=\$1{,}000$
  • ดอกเบี้ยต่อเดือน $r=1\%=0.01$
  • ผ่อน 3 งวด งวดละเท่ากัน ค่างวด $A$ คือสิ่งที่ต้องหา

เขียนหนี้ปลายเดือนทีละเดือน หนี้ปลายเดือนคือหนี้ต้นเดือนคูณ $1.01$ (งอกดอกเบี้ย 1%) แล้วลบค่างวด จากนั้นแทนเดือนก่อนลงในเดือนถัดไป จนหนี้เดือนที่ 3 เขียนด้วย $A$ ตัวเดียว:

\[ \begin{aligned} B_1&=1{,}000(1.01)-A,\\ B_2&=B_1(1.01)-A,\\ B_3&=B_2(1.01)-A\\ &=1{,}000(1.01)^3\\ &\quad-A(1.01^2+1.01+1)\\ &=1{,}030.301-3.0301A. \end{aligned} \]

ทำไม $A$ ถึงคูณด้วย $1.01^2+1.01+1$ เพราะค่างวดเดือนแรกที่หักออกไปแล้ว ถ้าไม่ได้หัก มันจะงอกดอกเบี้ยต่ออีกสองเดือน ค่างวดเดือนที่สองจะงอกอีกหนึ่งเดือน ส่วนค่างวดเดือนที่สามไม่ทันงอก ทีนี้ตั้งให้หนี้หลังงวดที่ 3 เป็นศูนย์ แล้วแก้หา $A$:

\[ \begin{aligned} 1{,}030.301-3.0301A&=0,\\ A&=\frac{1{,}030.301}{3.0301}\\ &=340.0221. \end{aligned} \]

ตารางด้านล่างเดินทีละเดือนด้วยค่างวดนี้ ดอกเบี้ยของเดือน $t$ คือ $I_t=0.01B_{t-1}$ (1% ของหนี้ต้นเดือน) ส่วนที่เหลือของค่างวด $P_t=A-I_t$ ไปลดหนี้ และหนี้ปลายเดือนคือ $B_t=B_{t-1}-P_t$ คิดด้วย $A=340.0221$ เต็ม ๆ แล้วปัดเป็นเซนต์ตอนแสดง

ขั้นที่ 2 — สูตรค่างวดของ $N$ งวด

สามงวดคิดมือได้ แต่สินเชื่อจริงมี 360 งวด ขั้นนี้ทำแบบเดียวกับเงินกู้สามงวด แต่ใช้ตัวอักษรแทนตัวเลข เพื่อให้ได้สูตรที่ใช้กับจำนวนงวดเท่าไรก็ได้ ตัวอักษรที่ใช้มีสี่ตัว $r$ คือดอกเบี้ยต่อเดือน $A$ คือค่างวด $B_t$ คือหนี้ที่ค้างหลังจ่ายงวดที่ $t$ และ $N$ คือจำนวนงวดทั้งหมด

\[ \begin{aligned} B_t&=B_{t-1}(1+r)-A,\\ B_t&=B_0(1+r)^t\\ &\quad-A\sum_{j=0}^{t-1}(1+r)^j,\\ \sum_{j=0}^{t-1}(1+r)^j&=\frac{(1+r)^t-1}{r},\\ B_N=0&:\ B_0(1+r)^N\\ &\qquad=A\,\frac{(1+r)^N-1}{r},\\ A&=\frac{B_0\,r\,(1+r)^N}{(1+r)^N-1}\\ &=\frac{B_0\,r}{1-(1+r)^{-N}}. \end{aligned} \]

กติกาของสัญญาคือ หนี้เดือนนี้เท่ากับหนี้เดือนก่อนที่งอกดอกเบี้ยแล้ว ลบด้วยค่างวด ถ้าคลี่กติกานี้ย้อนไปถึงวันกู้ ยอดกู้ $B_0$ ถูกทบดอกเบี้ยครบ $t$ เดือน แต่ค่างวดแต่ละงวดถูกทบไม่เท่ากัน ค่างวดงวดแรกถูกทบอีก $t-1$ เดือน ค่างวดงวดล่าสุดยังไม่ถูกทบเลย ตัวคูณ $1,(1+r),\dots,(1+r)^{t-1}$ จึงเรียงกันเป็นอนุกรมเรขาคณิต ซึ่งบวกได้ด้วยสูตรเดียวกับ annuity ในหน้ามูลค่าเงินตามเวลา

เหลือแค่ตั้งเงื่อนไขของสัญญา หนี้หลังงวดสุดท้ายต้องเป็นศูนย์ $B_N=0$ สมการที่ได้บอกว่า ยอดกู้ที่ทบดอกเบี้ยครบ $N$ เดือน เท่ากับค่างวดทุกงวดที่ทบดอกเบี้ยไปถึงวันเดียวกัน แก้หา $A$ แล้วหารทั้งเศษและส่วนด้วย $(1+r)^N$ ก็ได้รูปสุดท้าย ลองแทน $B_0=1{,}000$, $r=0.01$, $N=3$ จะได้ $A=10/(1-1.01^{-3})=10/0.029410=340.02$ ตรงกับที่คิดมือ

ทำไม $r=c/12$ ธรรมเนียมสินเชื่อบ้านสหรัฐฯ ประกาศอัตราต่อปี แล้วแบ่งเป็นรายเดือนด้วยการหารด้วย 12 ตรง ๆ ไม่ได้ถอดรากที่ 12 สินเชื่อในโจทย์จึงใช้ $r=0.08125/12$ ไม่ใช่ $1.08125^{1/12}-1$ ผลคือถ้าทบดอกเบี้ยครบ 12 เดือนจริง ผู้กู้จ่ายต่อปีมากกว่าตัวเลขที่ประกาศ:

\[\begin{aligned}\Big(1+\frac{0.08125}{12}\Big)^{12}-1&=1.006770833^{12}-1\\&=8.43\%.\end{aligned}\]

ตัวเลข 8.125% จึงเป็นอัตราที่ประกาศ ไม่ใช่อัตราที่ทบแล้ว

ขั้นที่ 3 — สินเชื่อ \$100,000: ค่างวด งวดแรก และงวดที่สอง

ตอนนี้กลับมาที่สินเชื่อในโจทย์ ขั้นนี้ใช้สูตรค่างวดหาว่าทำไมค่างวดเป็น \$742.50 แล้วแยกสองงวดแรกเป็นดอกเบี้ยกับเงินต้น เพื่อดูว่าเงินแต่ละดอลลาร์ของผู้กู้ไปไหน

โจทย์ให้อะไรมาบ้าง:

  • ยอดกู้ $B_0=\$100{,}000$
  • ดอกเบี้ยต่อปี $c=8.125\%$ จึงได้ดอกเบี้ยต่อเดือน $r=c/12$
  • จำนวนงวด $N=360$

กติกาแยกค่างวดมีสามข้อ ดอกเบี้ยงวดที่ $t$ คิดจากหนี้ต้นงวด $I_t=rB_{t-1}$ ส่วนที่เหลือของค่างวด $P_t=A-I_t$ ไปลดหนี้ และหนี้ปลายงวดคือ $B_t=B_{t-1}-P_t$ เริ่มจากค่างวดก่อน:

\[ \begin{aligned} r&=0.08125/12\\ &=0.006770833,\\ (1+r)^{360}&=11.350765,\\ A&=\frac{100{,}000\times0.006770833}{1-1/11.350765}\\ &=\frac{677.0833}{0.911900}\\ &=742.4972. \end{aligned} \]

ต่อด้วยสองงวดแรก ใช้ค่างวดเต็ม 742.4972 ไม่ใช่ค่าที่ปัดแล้ว:

\[ \begin{aligned} I_1&=rB_0\\ &=0.006770833\times100{,}000\\ &=677.0833,\\ P_1&=A-I_1\\ &=742.4972-677.0833\\ &=65.4138,\\ B_1&=B_0-P_1\\ &=100{,}000-65.4138\\ &=99{,}934.5862,\\ I_2&=rB_1\\ &=0.006770833\times99{,}934.5862\\ &=676.6404,\\ P_2&=A-I_2\\ &=742.4972-676.6404\\ &=65.8568,\\ B_2&=B_1-P_2\\ &=99{,}934.5862-65.8568\\ &=99{,}868.7294. \end{aligned} \]

คำตอบ: ค่างวดคือ \$742.50 (ปัดจาก 742.4972) เดือนแรกเป็นดอกเบี้ย \$677.08 คิดเป็น $677.0833/742.4972=91.19\%$ ของค่างวด จึงลดหนี้ได้แค่ \$65.41 และหนี้ปลายเดือนแรกเหลือ \$99,934.59 เดือนที่สองหนี้ต้นเดือนน้อยลง \$65.41 ดอกเบี้ยจึงลดลงเล็กน้อย ส่วนที่ไปลดหนี้จึงเพิ่มเป็น \$65.86

ตรวจเองใน 10 วินาที: $P_2/P_1=65.8568/65.4138=1.00677$ ซึ่งคือ $1+r$ พอดี นี่ไม่ใช่เรื่องบังเอิญ ขั้นถัดไปบอกว่าทำไม

ขั้นที่ 4 — ทำไมเงินต้นโตเดือนละ $(1+r)$ เท่า

ขั้นที่แล้วพบว่าเงินต้นงวดที่สองเท่ากับงวดแรกคูณ $1+r$ ขั้นนี้แสดงว่าเป็นแบบนี้ทุกงวด เหตุผลสั้น ๆ คือ เงินต้นทุก \$1 ที่ลดไปเดือนก่อน ทำให้ดอกเบี้ยเดือนนี้ลดลง $r$ ดอลลาร์ ค่างวดยังเท่าเดิม เงินที่ประหยัดได้นั้นจึงไปลดหนี้เพิ่ม รู้แบบนี้แล้ว เราจะหาเงินต้นของงวดไหนก็ได้โดยไม่ต้องเดินตาราง

\[ \begin{aligned} P_t&=A-rB_{t-1}\\ &=A-r(B_{t-2}-P_{t-1})\\ &=(A-rB_{t-2})+rP_{t-1}\\ &=(1+r)P_{t-1},\\ P_t&=P_1(1+r)^{t-1},\\ P_{360}&=A-rB_{359}=\frac{A}{1+r}\\ &=737.5037,\\ P_1&=\frac{P_{360}}{(1+r)^{359}}=\frac{A}{(1+r)^{360}}\\ &=65.4138. \end{aligned} \]

จังหวะที่ต้องคิดคือการแทน $B_{t-1}=B_{t-2}-P_{t-1}$ ซึ่งมาจากกติกาเอง หนี้ลดลงเท่ากับเงินต้นที่ลด พอแทนแล้ว ก้อน $A-rB_{t-2}$ ก็คือนิยามของเงินต้นเดือนก่อน $P_{t-1}$ จึงได้ $P_t=(1+r)P_{t-1}$ เงินต้นที่ลดในแต่ละเดือนโตแบบทบต้น ด้วยอัตราเดียวกับดอกเบี้ย แต่มันเริ่มจากฐานที่เล็กมาก เดือนที่ 24 จึงลดหนี้ได้แค่ $P_{24}=65.4138\times1.006771^{23}=65.4138\times1.167897=\$76.40$

เงินต้นงวดแรกหาได้จากงวดสุดท้าย งวดสุดท้ายต้องล้างหนี้ที่เหลือ $B_{359}$ พร้อมดอกเบี้ยของมันพอดี จึงได้ $A=B_{359}(1+r)$ และเงินต้นงวดสุดท้ายคือหนี้ที่เหลือทั้งก้อน $P_{360}=B_{359}=A/(1+r)=742.4972/1.006771=\$737.50$ ดอกเบี้ยงวดสุดท้ายจึงเหลือ $I_{360}=A-P_{360}=742.4972-737.5037=\$4.99$ เดินย้อนจากงวดสุดท้ายลงมา 359 เดือน ได้ $P_1=742.4972/11.350765=\$65.41$ แปลว่าเงินต้นงวดแรกคือค่างวดที่คิดลดไป 360 เดือน สัญญายิ่งยาว เงินต้นงวดแรกยิ่งเล็ก นี่คือเหตุที่สีเขียวในรูปแรกเริ่มบางมาก

แล้วเงินต้นแซงดอกเบี้ยเดือนไหน ทั้งสองส่วนรวมกันเป็น $A$ เสมอ เงินต้นจึงแซงเมื่อ $P_t\gt A/2$ รวมสองผลข้างบน $P_t=P_1(1+r)^{t-1}$ กับ $P_1=A/(1+r)^{360}$ ได้ $P_t=A(1+r)^{t-1}/(1+r)^{360}$ แทนลงในเงื่อนไข แล้ว $A$ ตัดกันหายไป:

\[\begin{aligned}(1+r)^{t-1}&\gt\frac{(1+r)^{360}}{2}=\frac{11.350765}{2}\\&=5.6754,\\t-1&\gt\frac{\ln5.6754}{\ln1.006771}\\&=\frac{1.7361}{0.006748}=257.3.\end{aligned}\]

งวดเป็นจำนวนเต็ม งวดแรกที่ผ่านเงื่อนไขจึงเป็นงวดที่ $t=259$ หรือปีที่ $259/12=21.6$ ก่อนหน้านั้น 258 เดือน คิดเป็น $258/360=72\%$ ของเวลาผ่อนทั้งหมด ผู้กู้จ่ายดอกเบี้ยมากกว่าเงินต้นทุกเดือน

ขั้นที่ 5 — หนี้ของเดือนใดก็ได้ และคำตอบของโจทย์

โจทย์ข้างบนถามหนี้หลังสองปี ถ้าเดินตารางทีละเดือนต้องทำ 24 แถว ขั้นนี้หาสูตรที่ให้หนี้ของเดือนไหนก็ได้ในบรรทัดเดียว วิธีคือเอาสูตรหนี้จากการคลี่ทีละเดือนในขั้นสูตรค่างวด แล้วแทนค่างวด $A$ ลงไป สูตรจะเหลือแค่ตัวทบต้น ตัวทบต้นเขียนย่อว่า $g_t=(1+r)^t$ คือมูลค่าของเงิน \$1 ที่ทบดอกเบี้ยไป $t$ เดือน

\[ \begin{aligned} B_t&=B_0\,g_t-A\,\frac{g_t-1}{r}\\ &=B_0\,\frac{g_N-g_t}{g_N-1}\\ &=A\,\frac{1-(1+r)^{-(N-t)}}{r},\\ g_{24}&=1.006771^{24}=1.175804,\\ B_{24}&=100{,}000\times\frac{g_{360}-g_{24}}{g_{360}-1}\\ &=100{,}000\times\frac{11.350765-1.175804}{11.350765-1}\\ &=100{,}000\times\frac{10.174961}{10.350765}\\ &=\$98{,}301.53,\\ \sum_{t=1}^{24}I_t&=24A-(B_0-B_{24})\\ &=17{,}819.93-1{,}698.47\\ &=\$16{,}121.47. \end{aligned} \]

จังหวะที่ต้องคิดคือการแทน $A$ ค่างวดจากขั้นสูตรค่างวดเขียนด้วย $g$ ได้ว่า $A=B_0\,r\,g_N/(g_N-1)$ แทนลงในแถวบนสุด แล้วรวมเศษส่วน ค่าของ $r$ ตัดกันหายไป:

\[\begin{aligned}B_t&=B_0\,g_t-\frac{B_0\,g_N(g_t-1)}{g_N-1}\\&=B_0\,\frac{g_t g_N-g_t-g_N g_t+g_N}{g_N-1}\\&=B_0\,\frac{g_N-g_t}{g_N-1}.\end{aligned}\]

รูปที่สามได้จากการแทนยอดกู้ในรูปของค่างวด $B_0=A(g_N-1)/(r\,g_N)$ ลงในรูปที่สอง จะได้ $A(g_N-g_t)/(r\,g_N)=A\big(1-(1+r)^{-(N-t)}\big)/r$ รูปนี้คือความหมายที่ใช้บ่อยที่สุดในบทนี้ หนี้ที่ค้างอยู่เท่ากับมูลค่าวันนี้ของค่างวดที่ยังเหลือ $N-t$ งวด โดยคิดลดด้วยอัตราของสินเชื่อเอง (คิดลด คือแปลงเงินในอนาคตเป็นค่าวันนี้) ผู้กู้ที่อยากปิดหนี้ก่อนกำหนดจึงต้องจ่ายเท่านี้พอดี

ตอบโจทย์ได้แล้ว หลัง 24 งวด หนี้เหลือ \$98,301.53 ผู้กู้จ่ายไป \$17,819.93 แต่หนี้ลดลงแค่ \$1,698.47 ส่วนที่เหลือเป็นดอกเบี้ย คิดเป็น $16{,}121.47/17{,}819.93=90.5\%$ ของเงินที่จ่าย

สูตรเดียวกันตอบคำถามของรูปถัดไปได้ด้วย คำถามแรก ครึ่งทางของเวลา (15 ปี หรือ 180 เดือน) หนี้ยังเหลือเท่าไร:

\[\begin{aligned}g_{180}&=1.006771^{180}=3.369090,\\B_{180}&=100{,}000\times\frac{11.350765-3.369090}{10.350765}\\&=\$77{,}111.94.\end{aligned}\]

หนี้ยังเหลือ $77{,}111.94/100{,}000=77\%$ ของยอดกู้ คำถามที่สอง หนี้ลดเหลือครึ่งเดียวตอนไหน เงื่อนไขคือ $B_t\le B_0/2$ หรือ $(g_N-g_t)/(g_N-1)\le1/2$ คูณ $2(g_N-1)$ ทั้งสองข้างแล้วจัดรูป จะได้เงื่อนไขของ $g_t$:

\[\begin{aligned}g_t&\ge\frac{g_N+1}{2}=\frac{12.350765}{2}\\&=6.1754,\\t&\ge\frac{\ln6.1754}{\ln1.006771}\\&=\frac{1.8206}{0.006748}=269.8.\end{aligned}\]

เงินต้นจึงคืนครบครึ่งในเดือนที่ 270 หรือปีที่ $270/12=22.5$ คำถามที่สาม หนี้จริงห่างจากเส้นตรงที่เดามากที่สุดตอนไหน ช่องว่างคือ $D(t)=B_t-B_0(1-t/N)$ มองเป็นฟังก์ชันต่อเนื่องของ $t$ แล้วตั้งอนุพันธ์เป็นศูนย์ (อนุพันธ์ของ $g_t=e^{t\ln(1+r)}$ คือ $g_t\ln(1+r)$):

\[\begin{aligned}D'(t)&=-\frac{B_0\,g_t\ln(1+r)}{g_N-1}\\&\quad+\frac{B_0}{N}=0,\\g_t&=\frac{g_N-1}{N\ln(1+r)}\\&=\frac{10.350765}{360\times0.006748}=4.2608,\\t&=\frac{\ln4.2608}{0.006748}=214.8,\\D(215)&=B_{215}-100{,}000\times\frac{145}{360}\\&=68{,}440.74-40{,}277.78\\&=\$28{,}162.96.\end{aligned}\]

ช่องว่างกว้างที่สุดราว \$28,163 ในเดือนที่ 215 ($B_{215}$ คิดด้วยสูตรเดียวกัน โดย $g_{215}=4.266625$)

ขั้นที่ 6 — สินเชื่อนี้มีค่าเท่าไรเมื่ออัตราตลาดเปลี่ยน

ลองมองจากฝั่งคนที่ซื้อสินเชื่อนี้ไปในวันแรก สิ่งที่เขาได้คือเงิน \$742.50 ทุกเดือนอีก 360 เดือน ถ้าวันพรุ่งนี้ดอกเบี้ยในตลาดเปลี่ยน เงินชุดเดิมนี้ควรมีค่าเท่าไร ขั้นนี้ตอบคำถามนั้น แล้วดูว่าทำไมผู้กู้ไม่ยอมให้มูลค่าขึ้นไปได้เต็มที่

เครื่องมือคือการคิดลด แบบเดียวกับพันธบัตรในหน้าyield curve, duration และ convexity ให้ $y$ คืออัตราตลาดต่อปี หมายถึงผลตอบแทนที่ผู้ลงทุนหาได้จากของแบบเดียวกันในตลาดวันนี้ ทบรายเดือน เงิน $A$ ที่จะได้ในอีก $k$ เดือนมีค่าวันนี้ $A/(1+y/12)^k$ มูลค่าวันนี้ของสินเชื่อ $V(y)$ คือผลรวมของทุกงวด และผลรวมนี้ยุบเป็นสูตร annuity ตัวเดิม:

\[ \begin{aligned} V(y)&=\sum_{k=1}^{360}\frac{A}{(1+y/12)^k}\\ &=A\,\frac{1-(1+y/12)^{-360}}{y/12},\\ V(8.125\%)&=A\,\frac{1-(1+r)^{-360}}{r}\\ &=742.49718\times134.68065\\ &=\$100{,}000.00,\\ V(6\%)&=A\,\frac{1-1.005^{-360}}{0.005}\\ &=742.49718\times166.79161\\ &=\$123{,}842.30,\\ V(10\%)&=A\,\frac{1-1.0083333^{-360}}{0.0083333}\\ &=742.49718\times113.95082\\ &=\$84{,}608.16. \end{aligned} \]

เมื่ออัตราตลาดเท่ากับอัตราของสินเชื่อ ($y=c$) มูลค่าเท่ากับยอดกู้พอดี เพราะตัวคูณ 134.68065 คือส่วนกลับของ $r/(1-(1+r)^{-N})$ ในสูตรค่างวด ค่างวดถูกเลือกมาให้เป็นแบบนั้นตั้งแต่แรก ถ้าอัตราตลาดเปลี่ยน มูลค่าจะขยับ:

\[\begin{aligned}\frac{V(6\%)}{B_0}-1&=\frac{123{,}842.30}{100{,}000}-1\\&=+23.8\%,\\\frac{V(10\%)}{B_0}-1&=\frac{84{,}608.16}{100{,}000}-1\\&=-15.4\%.\end{aligned}\]

อัตราตลาดลง มูลค่าขึ้น อัตราตลาดขึ้น มูลค่าลง ทิศเดียวกับพันธบัตรทุกตัว เพราะเงินชุดเดิมถูกหารด้วยตัวที่เล็กลงหรือใหญ่ขึ้น

ในโลกจริง อัตราไร้ความเสี่ยง (อัตราที่ได้จากพันธบัตรรัฐบาล) มักต่ำกว่า $c$ เพราะอัตราที่คิดกับผู้กู้ต้องเผื่อค่าบริการ ความเสี่ยงที่ผู้กู้ผิดนัด ความไม่แน่นอนว่าผู้กู้จะคืนก่อนเมื่อไร และกำไรของผู้ปล่อยกู้ ถ้าคิดลดด้วยอัตราไร้ความเสี่ยงตรง ๆ จะได้มูลค่าสูงกว่ายอดกู้ แต่ส่วนเกินนั้นไม่ใช่กำไรฟรี มันคือเงินที่ต้องจ่ายให้สิ่งเหล่านี้

มีอีกเรื่องที่ทำให้มูลค่าขึ้นไปไม่ถึง \$123,842.30 ผู้กู้บ้านในสหรัฐฯ มีสิทธิปิดหนี้เมื่อไรก็ได้ โดยจ่ายแค่ยอดหนี้ที่ค้าง (\$100,000 ในวันแรก) ถ้าอัตราตลาดลงเป็น 6% ผู้กู้จะไปกู้ก้อนใหม่ที่ดอกเบี้ยถูกกว่า แล้วเอามาปิดก้อนเดิม เจ้าของสินเชื่อจึงได้เงินคืนแค่ \$100,000 ไม่ใช่ของที่มีค่า \$123,842.30 สิทธินี้คือการคืนก่อนกำหนด (prepayment) มันทำให้ผู้ถือสินเชื่อเหมือนขาย option ให้ผู้กู้ไปแล้วตั้งแต่วันแรก (option คือสิทธิที่ผู้ถือเลือกใช้หรือไม่ใช้ก็ได้ ผู้กู้จะใช้เฉพาะตอนที่ได้ประโยชน์)

ขั้นที่ 7 — รวมสินเชื่อ \$400 ล้านเป็น pass-through

ตอนนี้ขยับจากสินเชื่อก้อนเดียวไปเป็น pool ธนาคารรวมสินเชื่อหลายพันก้อนเป็นกองเดียว แล้วออกตราสาร pass-through ที่ส่งเงินทุกดอลลาร์ที่เก็บได้ต่อให้ผู้ถือตามสัดส่วน ระหว่างทางมี servicer คือบริษัทที่เก็บค่างวดจากผู้กู้ทุกเดือน servicer หักค่าบริการของตัวเองออกจากดอกเบี้ย ส่วนเงินต้นส่งต่อครบทุกดอลลาร์ ขั้นนี้ถามว่าผู้ถือจะได้เงินเท่าไรในแต่ละเดือน

ของที่รู้ (ตัวเลขตัวอย่าง):

  • หนี้รวมของ pool $B_0=\$400$ ล้าน
  • ทุกก้อนเหมือนสินเชื่อในโจทย์ (\$100,000, 8.125%, 360 งวด) จึงมี $400{,}000{,}000/100{,}000=4{,}000$ ก้อน และคิดได้เหมือนสินเชื่อก้อนเดียวที่ใหญ่ขึ้น 4,000 เท่า
  • ค่าบริการ $s=0.625\%$ ต่อปีของหนี้ที่ค้าง ผู้ลงทุนจึงได้ดอกเบี้ยที่อัตรา $c-s=8.125\%-0.625\%=7.50\%$ ต่อปี

เงินที่ผู้ลงทุนได้ในเดือน $t$ เขียนว่า $C_t$ มันคือดอกเบี้ยที่อัตรา $c-s$ บนหนี้ต้นเดือน บวกเงินต้นทุกดอลลาร์ที่ผู้กู้คืน ลองคิดเดือนแรก:

\[ \begin{aligned} C_t&=\frac{c-s}{12}B_{t-1}+P_t,\\ 4{,}000A&=4{,}000\times742.49718\\ &=2{,}969{,}988.72,\\ \tfrac{c}{12}B_0&=\tfrac{0.08125}{12}\times400{,}000{,}000\\ &=2{,}708{,}333.33,\\ \tfrac{s}{12}B_0&=\tfrac{0.00625}{12}\times400{,}000{,}000\\ &=208{,}333.33,\\ \tfrac{c-s}{12}B_0&=2{,}708{,}333.33-208{,}333.33\\ &=2{,}500{,}000.00,\\ P_1&=4{,}000A-\tfrac{c}{12}B_0\\ &=2{,}969{,}988.72-2{,}708{,}333.33\\ &=261{,}655.39,\\ C_1&=2{,}500{,}000.00+261{,}655.39\\ &=2{,}761{,}655.39. \end{aligned} \]

อ่านเป็นเรื่องเงินไหล เดือนแรกผู้กู้ทั้ง pool จ่ายมา \$2,969,988.72 ในนั้นเป็นดอกเบี้ย \$2,708,333.33 และเงินต้น \$261,655.39 servicer ตัดค่าบริการ \$208,333.33 ออกจากส่วนดอกเบี้ย ที่เหลือ \$2,761,655.39 ส่งให้ผู้ลงทุน ผู้ที่ถือ 1% ของตราสาร (หน้าตั๋ว \$4 ล้าน) ได้ 1% ของทุกก้อน คือ $0.01\times2{,}761{,}655.39=\$27{,}616.55$ ในเดือนแรก

มีมุมที่ง่ายกว่านั้น ผู้ลงทุนได้ทุกอย่างที่ผู้กู้จ่าย ยกเว้นค่าบริการ จึงเขียนได้ว่า $C_t=4{,}000A-\tfrac{s}{12}B_{t-1}$ ค่างวดรวมเท่าเดิมทุกเดือน แต่ค่าบริการคิดจากหนี้ที่ค้าง ซึ่งลดลงทุกเดือน เงินที่ผู้ลงทุนได้จึงขยับขึ้นช้า ๆ ลองเดือนที่ 60 หนี้ต้นเดือนหาได้จากสูตรหนี้ของเดือนใดก็ได้ โดย $g_{59}=(1+r)^{59}=1.48904182$ (เงินก้อนใหญ่ขนาดนี้ต้องใช้ทศนิยมหลายหลัก ไม่อย่างนั้นปลายทางคลาดไปหลายดอลลาร์):

\[\begin{aligned}B_{59}&=400{,}000{,}000\\&\quad\times\frac{11.35076460-1.48904182}{10.35076460}\\&=381{,}101{,}229,\\\tfrac{s}{12}B_{59}&=\tfrac{0.00625}{12}\times381{,}101{,}229\\&=198{,}490.22,\\C_{60}&=4{,}000A-\tfrac{s}{12}B_{59}\\&=2{,}969{,}988.72-198{,}490.22\\&=\$2{,}771{,}498.50.\end{aligned}\]

ผู้กู้จ่ายเท่าเดิม แต่ผู้ลงทุนได้มากขึ้น $2{,}771{,}498.50-2{,}761{,}655.39=\$9{,}843.11$ ต่อเดือน เพราะค่าบริการหดลงตามหนี้

ขั้นที่ 8 — WAC และ WAM: สรุป pool ด้วยสองตัวเลข

pool ในขั้นที่แล้วมีสินเชื่อเหมือนกันทุกก้อน pool จริงไม่เป็นแบบนั้น แต่ละก้อนกู้มาคนละปี อัตราดอกเบี้ยจึงต่างกัน และเหลือเวลาผ่อนไม่เท่ากัน ผู้ซื้อตราสารอยากได้ตัวเลขสั้น ๆ ที่สรุป pool ทั้งกอง เอกสารของตราสารจึงรายงานค่าเฉลี่ยสองตัว WAC (weighted-average coupon) คืออัตราดอกเบี้ยเฉลี่ย และ WAM (weighted-average maturity) คือจำนวนเดือนที่เหลือเฉลี่ย ขั้นนี้ลองคิดสองค่านี้กับ pool เล็ก ๆ แล้วถามว่าใช้สองตัวเลขนี้แทน pool ได้แม่นแค่ไหน

โจทย์ให้อะไรมาบ้าง (pool สมมติสามก้อน): ก้อนที่ $j$ มีหนี้ค้าง $B_j$ อัตราดอกเบี้ยต่อปี $c_j$ และเหลือ $m_j$ เดือน

ก้อน $j$หนี้ค้าง $B_j$อัตรา $c_j$เดือนที่เหลือ $m_j$
1\$200,0007.5%300
2\$150,0008%330
3\$50,0009.5%355

ค่าเฉลี่ยทั้งสองใช้หนี้ค้างเป็นน้ำหนัก $w_j$ ก้อนที่หนี้เหลือมากจึงมีผลต่อค่าเฉลี่ยมาก เพราะเงินส่วนใหญ่ที่ผู้ลงทุนจะได้มาจากก้อนนั้น หนี้รวมคือ $200{,}000+150{,}000+50{,}000=\$400{,}000$

\[ \begin{aligned} w_j&=\frac{B_j}{\sum_i B_i},\\ w&=\Big(\tfrac{200}{400},\ \tfrac{150}{400},\ \tfrac{50}{400}\Big)\\ &=(0.5,\ 0.375,\ 0.125),\\ \mathrm{WAC}&=\sum_j w_jc_j\\ &=0.5(7.5\%)+0.375(8\%)\\ &\quad+0.125(9.5\%)=7.9375\%,\\ \mathrm{WAM}&=\sum_j w_jm_j\\ &=0.5(300)+0.375(330)\\ &\quad+0.125(355)=318.125. \end{aligned} \]

pool นี้มีอัตราเฉลี่ย 7.9375% และเหลือเวลาเฉลี่ย 318.125 เดือน อัตราของ pass-through ที่ออกจาก pool นี้ต้องต่ำกว่า WAC เสมอ เพราะส่วนต่างคือค่าบริการของ servicer

ทีนี้ทดสอบว่าสองตัวเลขนี้แทน pool ได้ไหม ถ้าแทนได้ ค่างวดของสินเชื่อก้อนเดียว \$400,000 ที่อัตรา WAC และอายุ WAM ต้องเท่ากับค่างวดจริงของสามก้อนรวมกัน ค่างวดของแต่ละก้อนใช้สูตรค่างวดตัวเดิม $A_j=B_j(c_j/12)/\big(1-(1+c_j/12)^{-m_j}\big)$:

\[\begin{aligned}A_1&=\frac{1{,}250}{1-1.00625^{-300}}\\&=\frac{1{,}250}{0.845748}=1{,}477.98,\\A_2&=\frac{1{,}000}{1-1.006667^{-330}}\\&=\frac{1{,}000}{0.888385}=1{,}125.64,\\A_3&=\frac{395.83}{1-1.007917^{-355}}\\&=\frac{395.83}{0.939150}=421.48,\\A_1+A_2+A_3&=\$3{,}025.10,\\A_{\mathrm{WAC}}&=\frac{2{,}645.83}{1-1.006615^{-318.125}}\\&=\frac{2{,}645.83}{0.877217}=\$3{,}016.17.\end{aligned}\]

เศษของแต่ละก้อนคือดอกเบี้ยเดือนแรก $B_jc_j/12$ เช่น $200{,}000\times0.075/12=1{,}250$ และของก้อนเดียวที่ใช้ WAC คือ $400{,}000\times0.079375/12=2{,}645.83$ สินเชื่อก้อนเดียวที่สรุปจาก WAC กับ WAM จ่ายน้อยกว่าของจริง $3{,}025.10-3{,}016.17=\$8.93$ ต่อเดือน เหตุผลคือค่างวดเป็นฟังก์ชันโค้งของอัตราและอายุ ไม่ใช่เส้นตรง และค่าเฉลี่ยของฟังก์ชันโค้งไม่เท่ากับฟังก์ชันของค่าเฉลี่ย WAC กับ WAM จึงเป็นบทสรุปที่ดี แต่ไม่ใช่ตัวแทนที่แม่นของ pool

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

คิดว่าเงินต้นลดเท่ากันทุกเดือน เดาแบบนี้ได้หนี้ที่ต่ำเกินจริงเสมอ เพราะช่วงแรกค่างวดเกือบทั้งก้อนเป็นดอกเบี้ย

\[\begin{aligned}\text{wrong: }B_{24}&=100{,}000\times(1-24/360)\\&=\$93{,}333.33,\\\text{right: }B_{24}&=100{,}000\times\frac{g_{360}-g_{24}}{g_{360}-1}\\&=\$98{,}301.53,\\\text{wrong: }B_{180}&=100{,}000\times(1-180/360)\\&=\$50{,}000,\\\text{right: }B_{180}&=\$77{,}111.94.\end{aligned}\]

ที่สองปีคลาดไปเกือบ \$5,000 ต่อสินเชื่อก้อนเดียว ที่ 15 ปีคลาดไปถึง $77{,}111.94-50{,}000=\$27{,}111.94$

คิดดอกเบี้ยจากยอดกู้เดิมทุกเดือน ลืมว่าดอกเบี้ยคิดจากหนี้ที่ยังค้าง ไม่ใช่ยอดกู้ตอนเริ่ม

\[\begin{aligned}\text{wrong: }360\times rB_0&=360\times677.0833\\&=\$243{,}750,\\\text{right: }360A-B_0&=360\times742.49718\\&\quad-100{,}000\\&=\$167{,}298.98.\end{aligned}\]

ใช้ค่างวดที่ปัดแล้วคิดต่อ ค่าที่ปัดแล้วทำให้ตัวเลขทุกงวดคลาด และหนี้ไม่จบที่ศูนย์ เงินต้นงวดแรกจะออกมา $742.50-677.08=65.42$ แต่ค่าที่ถูกคือ $742.4972-677.0833=65.41$ ถ้าผ่อน \$742.50 ครบ 360 งวด ผู้กู้จ่ายเกินเดือนละ $742.50-742.49718=\$0.00282$ (0.28 เซนต์) เงินเกินนี้ทบดอกเบี้ยไปจนจบสัญญา หนี้ปลายสัญญาจึงติดลบ ใช้สูตรหนี้จากการคลี่ทีละเดือน กับข้อเท็จจริงว่าค่างวดเต็ม $A$ ทำให้ $B_0g_{360}=A(g_{360}-1)/r$ พอดี:

\[\begin{aligned}B_{360}&=B_0g_{360}-742.50\,\frac{g_{360}-1}{r}\\&=-(742.50-A)\,\frac{g_{360}-1}{r}\\&=-0.00282\times1{,}528.73\\&=-\$4.31.\end{aligned}\]

ตารางของ servicer จึงต้องใช้ค่างวดเต็มทุกหลัก แล้วปรับเศษในงวดสุดท้าย

ลืมหารค่าบริการด้วย 12 อัตรา $s$ เป็นอัตราต่อปี แต่เงินไหลเป็นรายเดือน

\[\begin{aligned}\text{wrong: }sB_0&=0.00625\times400{,}000{,}000\\&=\$2{,}500{,}000,\\\text{right: }\tfrac{s}{12}B_0&=\tfrac{0.00625}{12}\times400{,}000{,}000\\&=\$208{,}333.33.\end{aligned}\]

ค่าที่ผิดเท่ากับดอกเบี้ยสุทธิทั้งเดือนของผู้ลงทุนพอดี servicer จะกินดอกเบี้ยของผู้ลงทุนไปหมด

ทบอัตรารายปีเป็นรายเดือน ธรรมเนียมสินเชื่อบ้านสหรัฐฯ หารด้วย 12 ตรง ๆ ไม่ได้ถอดรากที่ 12 ถ้าถอดราก อัตราต่อเดือนจะต่ำไป และค่างวดต่ำไปด้วย:

\[\begin{aligned}\text{wrong: }r'&=1.08125^{1/12}-1=0.6531\%,\\A'&=\frac{100{,}000\times0.006531}{1-1.006531^{-360}}\\&=\$722.45,\\\text{right: }r&=0.08125/12=0.6771\%,\\A&=\$742.50.\end{aligned}\]

ค่างวดต่ำไป $742.50-722.45=\$20.05$ ต่อเดือน และตารางทั้งชุดไม่ตรงกับสัญญา

ใช้ทำอะไรบนโต๊ะจริง

servicer ใช้สูตรในหน้านี้ทุกเดือน งานแรกคือกระทบยอด หมายถึงตรวจว่าเงินเข้ากับเงินออกตรงกัน เงินที่เก็บจากผู้กู้ต้องเท่ากับเงินที่ส่งผู้ลงทุนบวกค่าบริการ เช่นเดือนแรกของ pool \$400 ล้าน $2{,}761{,}655.39+208{,}333.33=2{,}969{,}988.72$ และหนี้ปลายเดือนต้องเท่ากับหนี้ต้นเดือนลบเงินต้นที่คืน $B_t=B_{t-1}-P_t$

ฝั่งผู้ลงทุนติดตาม pool ด้วยตัวเลขชื่อ pool factor คือหนี้ที่ยังค้างหารด้วยหนี้ตอนเริ่ม ถ้าไม่มีใครคืนก่อนกำหนด สินเชื่อในโจทย์หลังสองปีจะมี pool factor $B_{24}/B_0=98{,}301.53/100{,}000=0.9830$ ตัวเลขที่ pool จริงรายงานต่ำกว่านี้เสมอ เพราะมีผู้กู้บางคนคืนก่อน ส่วนที่ต่างนี้คือสิ่งที่มาตรฐาน PSAใช้วัดว่าผู้กู้คืนเร็วแค่ไหน

ที่มาของสินเชื่อแบบนี้ ก่อนทศวรรษ 1930 สินเชื่อบ้านในสหรัฐฯ มักเป็นแบบ balloon คือจ่ายแต่ดอกเบี้ยหลายปี แล้วคืนเงินต้นก้อนใหญ่ตอนจบ พอเกิดวิกฤตเศรษฐกิจทศวรรษ 1930 ธนาคารไม่ยอมต่อสัญญา คนจำนวนมากหาเงินก้อนใหญ่มาคืนไม่ได้จึงเสียบ้าน หลังจากนั้น สินเชื่อที่ผ่อนเท่ากันจนหมดหนี้จึงกลายเป็นแบบมาตรฐาน ส่วน pass-through ตัวแรกออกในปี 1970

เฉลย

ดอกเบี้ยต่อเดือน $r=0.06/12=0.005$ ใช้สูตรค่างวด แล้วแยกงวดแรกเป็นดอกเบี้ยกับเงินต้น:

\[\begin{aligned}(1+r)^{360}&=1.005^{360}=6.022575,\\A&=\frac{300{,}000\times0.005}{1-1/6.022575}\\&=\frac{1{,}500}{0.833958}=\$1{,}798.65,\\I_1&=0.005\times300{,}000=\$1{,}500,\\P_1&=1{,}798.65-1{,}500=\$298.65.\end{aligned}\]

งวดแรกลดหนี้ได้แค่ $298.65/1{,}798.65=16.6\%$ ของค่างวด ตรวจได้อีกทาง เงินต้นงวดแรกคือค่างวดที่คิดลดไป 360 เดือน $P_1=A/(1+r)^{360}=1{,}798.65/6.022575=298.65$ ตรงกัน

2. ครอบครัวในข้อ 1 ผ่อนมาแล้ว 5 ปี (60 งวด) และอยากรู้ว่ายังติดหนี้อยู่เท่าไร กับจ่ายดอกเบี้ยไปแล้วเท่าไร?

เฉลย

ใช้สูตรหนี้ของเดือนใดก็ได้ $B_t=B_0(g_N-g_t)/(g_N-1)$ แล้วแยกเงินที่จ่ายไปเป็นส่วนที่ลดหนี้กับดอกเบี้ย:

\[\begin{aligned}g_{60}&=1.005^{60}=1.348850,\\B_{60}&=300{,}000\times\frac{6.022575-1.348850}{6.022575-1}\\&=\$279{,}163.07,\\60A&=60\times1{,}798.6516\\&=\$107{,}919.09,\\B_0-B_{60}&=300{,}000-279{,}163.07\\&=\$20{,}836.93,\\60A-(B_0-B_{60})&=107{,}919.09-20{,}836.93\\&=\$87{,}082.16.\end{aligned}\]

ยังติดหนี้ \$279,163.07 และจ่ายดอกเบี้ยไปแล้ว \$87,082.16 คิดเป็น $87{,}082.16/107{,}919.09=80.7\%$ ของเงินที่จ่ายทั้งหมด

3. pool สินเชื่อบ้านหนี้รวม $B_0=\$100$ ล้าน มีอัตราดอกเบี้ยเฉลี่ย (WAC) $c=6.5\%$ ต่อปี servicer คิดค่าบริการ $s=0.5\%$ ต่อปีของหนี้ที่ค้าง ในเดือนแรก ผู้ถือ pass-through ได้ดอกเบี้ยเท่าไร และ servicer ได้เท่าไร?

เฉลย

ผู้ลงทุนได้ดอกเบี้ยที่อัตรา $c-s=6.5\%-0.5\%=6.0\%$ ต่อปี ทั้งสองอัตราต้องหารด้วย 12 เพราะเงินไหลรายเดือน:

\[\begin{aligned}\tfrac{c-s}{12}B_0&=\tfrac{0.06}{12}\times100{,}000{,}000\\&=\$500{,}000,\\\tfrac{s}{12}B_0&=\tfrac{0.005}{12}\times100{,}000{,}000\\&=\$41{,}666.67.\end{aligned}\]

ตรวจ: สองส่วนรวมกัน $500{,}000+41{,}666.67=\$541{,}666.67$ ต้องเท่ากับดอกเบี้ยที่ผู้กู้จ่าย $\tfrac{0.065}{12}\times100{,}000{,}000=\$541{,}666.67$ ตรงกัน ถ้าลืมหารด้วย 12 ค่าบริการจะเป็น $0.005\times100{,}000{,}000=\$500{,}000$ เท่ากับดอกเบี้ยทั้งหมดของผู้ลงทุน

function num(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(`${name} must be a finite number`);
  return x;
}
function positive(name, x) {
  if (!(num(name, x) > 0)) throw new RangeError(`${name} must be positive`);
  return x;
}
function months(name, n) {
  if (!Number.isInteger(n) || n < 1) throw new RangeError(`${name} must be a whole number of months, at least 1`);
  return n;
}

// Level payment that takes B0 to zero after N months at annual rate c (monthly rate c/12).
// N may be fractional here (a pool's WAM); the month-by-month schedule needs whole months.
function levelPayment(B0, c, N) {
  positive('B0', B0); positive('c', c); positive('N', N);
  const r = c / 12;
  return B0 * r / (1 - (1 + r) ** -N);
}

// Month-by-month schedule: interest on the opening balance, the rest of the payment is principal.
function schedule(B0, c, N) {
  months('N', N);
  const A = levelPayment(B0, c, N), r = c / 12, rows = [];
  let B = B0, paidI = 0;
  for (let t = 1; t <= N; t++) {
    const I = r * B, P = A - I;
    B -= P; paidI += I;
    rows.push({t, I, P, B, paidI});
  }
  return {A, rows};
}

// Balance after t payments in closed form.
function balanceAfter(B0, c, N, t) {
  months('N', N); levelPayment(B0, c, N);
  if (!Number.isInteger(t) || t < 0 || t > N) throw new RangeError('t must be a whole month from 0 to N');
  const g = (1 + c / 12) ** N;
  return B0 * (g - (1 + c / 12) ** t) / (g - 1);
}

// Value today of n remaining payments A at market rate y (annual, compounded monthly).
function loanValue(A, y, n) {
  positive('A', A); positive('y', y); months('n', n);
  const m = y / 12;
  return A * (1 - (1 + m) ** -n) / m;
}

// One month of a pass-through: the servicing fee s comes out of interest on the opening balance.
function passThroughMonth(B, c, s, A) {
  positive('B', B); positive('c', c); positive('A', A);
  if (!(num('s', s) >= 0 && s < c)) throw new RangeError('servicing fee must be at least 0 and below the mortgage rate');
  const gross = c / 12 * B, fee = s / 12 * B, principal = A - gross;
  return {collected: A, gross, fee, net: gross - fee, principal, investor: gross - fee + principal};
}

// Balance-weighted coupon and remaining term of a pool: loans = [[balance, rate, months], ...].
function wacWam(loans) {
  if (!Array.isArray(loans) || loans.length === 0) throw new RangeError('loans must be a non-empty array');
  let total = 0, wc = 0, wm = 0;
  for (const [B, c, m] of loans) { positive('balance', B); positive('rate', c); months('months', m); total += B; wc += B * c; wm += B * m; }
  return {total, wac: wc / total, wam: wm / total};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ค่างวดคือค่าที่ทำให้หนี้เหลือศูนย์พอดีหลังงวดสุดท้าย $A=B_0r/\big(1-(1+r)^{-N}\big)$ สินเชื่อ \$100,000 ที่ 8.125% 360 งวด จึงผ่อนเดือนละ \$742.50
  • ดอกเบี้ยคิดจากหนี้ที่ค้าง เงินต้นที่ลดในแต่ละเดือนจึงโตเดือนละ $(1+r)$ เท่า มันเริ่มจากแค่ \$65.41 (ค่างวดที่คิดลดไป 360 เดือน) และแซงดอกเบี้ยได้ในเดือนที่ 259
  • หนี้ที่ค้างเท่ากับมูลค่าวันนี้ของค่างวดที่เหลือ หลังสองปีหนี้จึงเหลือ \$98,301.53 ไม่ใช่ \$93,333 ที่ได้จากการเดาว่าหนี้ลดเท่ากันทุกเดือน
  • มูลค่าของสินเชื่อขึ้นลงตามอัตราตลาด เช่น \$123,842.30 เมื่ออัตราตลาดเป็น 6% แต่ผู้กู้ปิดหนี้ได้ทุกเมื่อด้วยยอดค้าง ของที่ผู้ถือได้จริงจึงมีเพดานด้านบน
  • pass-through ส่งดอกเบี้ยที่อัตรา $c-s$ บวกเงินต้นทุกดอลลาร์ให้ผู้ถือตามสัดส่วน ส่วน WAC กับ WAM สรุป pool ได้ดี แต่ใช้แทน pool ได้ไม่พอดี
