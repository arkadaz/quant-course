5.3 Conditional Distributions

เมื่อรู้ค่าของตัวแปรหนึ่งแล้ว ให้เลือกเฉพาะส่วนของ joint distribution ที่ตรงกับสิ่งที่รู้ แล้วหารด้วยมวลของส่วนนั้นให้รวมได้ 1 อีกครั้ง

ตารางโอกาสร่วม (สมมติ) ของผลตอบแทน AAPL กับทิศทาง MSFT บอกว่าในวันทั่วไป AAPL ลง 2% ด้วยโอกาส 0.20 และให้ผลตอบแทนเฉลี่ย +0.2% ต่อวัน หัวหน้า desk ถามคำถามแบบ stress test: “ในวันที่ MSFT ลง AAPL ลง 2% บ่อยแค่ไหน และผลตอบแทนเฉลี่ยของ AAPL ในวันแบบนั้นเป็นเท่าไร” ข้อมูลที่มีคือช่อง “AAPL −2% และ MSFT ลง” มีโอกาส 0.15 ช่อง “AAPL 0% และ MSFT ลง” 0.20 ช่อง “AAPL +2% และ MSFT ลง” 0.05

ลองตอบก่อนเปิดเฉลย

สามช่องนี้รวมกันได้ 0.40 คือโอกาสที่ MSFT ลง เมื่อรู้ว่าวันนี้ MSFT ลง โลกของเราเหลือแค่ 40% ของวันนี้ จึงต้องหารด้วย 0.40: AAPL ลง 2% ด้วยโอกาส $0.15/0.40=0.375$ สูงขึ้นเกือบสองเท่าจาก 0.20 ผลตอบแทนเฉลี่ยคือ $(-2)(0.375)+0(0.5)+2(0.125)=-0.5\%$ แทนที่จะเป็น +0.2% คำตอบ 0.15 ผิด เพราะนั่นคือสัดส่วนของทุกวัน ไม่ใช่ของวันที่ MSFT ลง

ภาพรวมก่อนลงสูตร

marginal distribution ตอบคำถามเรื่องตัวเดียวโดยรวมทุกกรณีของอีกตัว conditional distribution ทำตรงข้าม: เมื่อรู้แล้วว่าอีกตัวเป็นค่าใด ให้ทิ้งกรณีอื่นทั้งหมด เหลือเฉพาะส่วนที่ตรงกับสิ่งที่รู้ แล้วหารด้วยมวลของส่วนนั้นเพื่อให้โอกาสรวมเป็น 1 อีกครั้ง สองท่านี้คือ “เลือก” กับ “ปรับสเกล”

รูปด้านล่างแสดงทั้งสองท่าในภาพเดียว แท่งเทาคือ marginal ของ AAPL แท่งส้มอ่อนคือคอลัมน์ MSFT ลงตามที่อยู่ในตาราง (รวมได้แค่ 0.40) แท่งส้มเข้มคือคอลัมน์เดียวกันหลังหารด้วย 0.40 รูปร่างของส้มอ่อนกับส้มเข้มเหมือนกันทุกประการ ต่างกันแค่สเกล และมันเอียงไปทางซ้ายกว่าแท่งเทา นั่นคือข้อมูลที่การรู้ว่า MSFT ลงให้เรา

หน้านี้จะทำท่านี้กับตาราง สลับทิศของเงื่อนไขด้วย Bayes แก้ปัญหาตัวแปรต่อเนื่องที่โอกาสของจุดเดียวเป็นศูนย์ แล้วดูว่าค่าเฉลี่ยตามเงื่อนไขเป็นฟังก์ชันของข้อมูล เฉลี่ยกลับแล้วได้ค่าเฉลี่ยเดิม และในแบบจำลอง Gaussian ให้ทั้งค่าคาดหมายและความกว้างใหม่ ซึ่งเป็นรากของ hedge ratio

ศัพท์ที่ใช้ในหัวข้อนี้
Conditional distribution
การแจกแจงของตัวแปรหนึ่งเมื่อรู้ค่าของอีกตัวแล้ว ได้จากการเลือกส่วนของ joint ที่ตรงกับสิ่งที่รู้แล้วหารด้วยมวลของส่วนนั้น ใช้ตอบคำถามแบบ “ถ้า ... แล้ว ...” เช่น stress test
Conditional density $f_{X\mid Y}(x\mid y)$
density ของ $X$ เมื่อรู้ $Y=y$ เท่ากับ $f_{X,Y}(x,y)/f_Y(y)$ ใช้ได้เมื่อ $f_Y(y)\gt0$ เป็นรอยตัดของ joint density ที่ถูกปรับสเกลให้พื้นที่เป็น 1
Conditional expectation $E[X\mid Y=y]$
ค่าเฉลี่ยของ $X$ ภายใต้ conditional distribution เป็นตัวเลขเมื่อรู้ $y$ และเป็นฟังก์ชันของ $Y$ ก่อนรู้ ใช้เป็นค่าพยากรณ์ที่ดีที่สุดในความหมาย mean squared error
Regression function
ชื่อเรียก $m(y)=E[X\mid Y=y]$ เมื่อมองเป็นฟังก์ชันของ $y$ ไม่จำเป็นต้องเป็นเส้นตรง ในแบบจำลอง Gaussian มันเป็นเส้นตรงและความชันคือ hedge ratio
Conditional variance
ความผันผวนที่เหลืออยู่หลังรู้ข้อมูล $\operatorname{Var}(X\mid Y=y)$ ใช้วัดว่าข้อมูลช่วยลดความไม่แน่นอนได้แค่ไหน

ขั้นที่ 2 — สลับทิศของเงื่อนไขด้วย Bayes

คำถาม “ในวันที่ MSFT ลง AAPL ลง 2% บ่อยแค่ไหน” กับ “ในวันที่ AAPL ลง 2% MSFT ลงบ่อยแค่ไหน” ฟังคล้ายกัน แต่ตัวหารต่างกัน และมักสลับกันโดยไม่ตั้งใจ

\[\begin{aligned} P(\text{down}\mid X=-2)&=\frac{0.15}{0.20}=0.75,\\ f_{Y\mid X}(y\mid x)&=\frac{f_{X\mid Y}(x\mid y)\,f_Y(y)}{f_X(x)},\\ P(\text{down}\mid X=-2)&=\frac{0.375\times0.40}{0.20}=0.75. \end{aligned}\]

บรรทัดแรกเลือกแถว $X=-2$ แทนคอลัมน์ จึงหารด้วยมวลของแถว 0.20 ได้ 0.75 ซึ่งต่างจาก 0.375 มาก บรรทัดที่สองคือ Bayes' theorem ในรูปของการแจกแจง: เขียนโอกาสร่วมเป็น “conditional คูณ marginal” ได้สองแบบ แล้วจับเท่ากัน บรรทัดสุดท้ายแทนตัวเลขของคอลัมน์ MSFT ลงที่หาไว้แล้ว เพื่อยืนยันว่าได้ 0.75 เหมือนกัน

ความต่างนี้มีผลจริง: 0.75 บอกว่าวัน AAPL ลง 2% เกือบทุกวันเป็นวันที่ MSFT ลงด้วย ส่วน 0.375 บอกว่าวัน MSFT ลงส่วนใหญ่ AAPL ไม่ได้ลง 2% ทั้งสองค่าจริงพร้อมกัน เพราะวัน MSFT ลง (0.40) มีมากกว่าวัน AAPL ลง 2% (0.20) สองเท่า

ขั้นที่ 3 — ตัวแปรต่อเนื่อง: หารด้วยศูนย์ไม่ได้ จึงใช้แถบแคบ

ถ้า MSFT เป็นผลตอบแทนต่อเนื่อง โอกาสที่มันเท่ากับ −3% พอดีคือศูนย์ สูตร “เลือกแล้วหาร” ของตารางจะกลายเป็น $0/0$ วิธีแก้คือเริ่มจากแถบแคบ $y\le Y\le y+h$ ซึ่งมีโอกาสเป็นบวก แล้วค่อยบีบแถบให้แคบลง

\[\begin{aligned} &P(X\le x\mid y\le Y\le y+h)\\ &=\frac{\int_{-\infty}^{x}\int_y^{y+h}f_{X,Y}(u,v)\,dv\,du} {\int_y^{y+h}f_Y(v)\,dv}\\ &\approx\frac{h\int_{-\infty}^{x}f_{X,Y}(u,y)\,du}{h\,f_Y(y)},\\ f_{X\mid Y}(x\mid y)&=\frac{f_{X,Y}(x,y)}{f_Y(y)},\qquad f_Y(y)\gt0. \end{aligned}\]

บรรทัดแรกเป็นโอกาสตามเงื่อนไขธรรมดาแบบเดียวกับตาราง เพราะเงื่อนไขเป็นแถบที่มีโอกาสเป็นบวก บรรทัดที่สองใช้ว่าในแถบแคบมาก density แทบคงที่ตาม $v$ อินทิกรัลตาม $v$ ทั้งเศษและส่วนจึงประมาณความกว้าง $h$ คูณค่าที่ $v=y$ ตรงนี้คือท่าสำคัญ: $h$ ตัดกันเอง เหลืออัตราส่วนของ density ที่ไม่เป็น $0/0$ อีกต่อไป

บรรทัดสุดท้ายอ่านว่า “ตัดรอยของ joint density ที่ $Y=y$ แล้วหารด้วยพื้นที่ใต้รอยนั้น” พื้นที่ใต้รอยคือ $f_Y(y)$ ตามที่เห็นใน marginal distribution หน่วยก็ลงตัว: ต่อจุดเปอร์เซ็นต์กำลังสอง หารด้วยต่อจุดเปอร์เซ็นต์ เหลือต่อจุดเปอร์เซ็นต์ ซึ่งเป็นหน่วยของ density ตัวแปรเดียว

ตัวอย่างในรูปด้านล่าง (แบบจำลอง Gaussian สมมติ ส่วนเบี่ยงเบนมาตรฐาน 2.5 และ 3 จุดเปอร์เซ็นต์ correlation 0.6): ที่ MSFT = −3% พื้นที่ใต้รอยตัดคือ $f_Y(-3)=0.0807$ ต่อจุดเปอร์เซ็นต์ รอยตัดดิบจึงเตี้ยมาก การหารด้วย 0.0807 ยืดมันขึ้น 12.4 เท่า

ขั้นที่ 4 — สามเหลี่ยม: เมื่อรู้ $Y$ แล้ว $X$ เหลือ uniform

แบบจำลอง Gaussian หาอัตราส่วนด้วยมือยาก ขั้นนี้ใช้สามเหลี่ยมจาก marginal distribution ที่หาได้ครบทุกบรรทัด

โจทย์ให้อะไรมาบ้าง: $f_{X,Y}(x,y)=2$ บน $0\le y\le x\le1$ และศูนย์ที่อื่น ตัวแปรไร้หน่วย marginal ของ $Y$ คือ $f_Y(y)=2(1-y)$ ต้องการการแจกแจงของ $X$ เมื่อรู้ $Y=y$ โดย $0\le y\lt1$

\[\begin{aligned} f_{X\mid Y}(x\mid y)&=\frac{2}{2(1-y)}=\frac{1}{1-y},\quad y\le x\le1,\\ \int_y^1\frac{1}{1-y}\,dx&=1,\\ f_{X\mid Y}(x\mid 0.3)&=\tfrac{1}{0.7}=\tfrac{10}{7}\approx1.43,\\ P(X\le0.6\mid Y=0.3)&=\frac{0.6-0.3}{0.7}=\tfrac37\approx0.43. \end{aligned}\]

คำตอบ: เมื่อรู้ $Y=y$ ค่า $X$ กระจายสม่ำเสมอระหว่าง $y$ กับ 1 รอยตัดแนวนอนของสามเหลี่ยมมีความสูงคงที่ 2 และยาว $1-y$ หารด้วยพื้นที่ $2(1-y)$ จึงได้ความสูง $1/(1-y)$ ตลอดช่วง นอกช่วงนี้ conditional density เป็นศูนย์ เพราะ $X$ ต่ำกว่า $Y$ ไม่ได้

ตรวจเองใน 10 วินาที: ที่ $y=1$ ตัวหาร $2(1-y)$ เป็นศูนย์ สูตรนี้จึงไม่ให้คำตอบ ซึ่งสมเหตุสมผล: ในสามเหลี่ยมนี้ $Y=1$ เกิดได้เฉพาะเมื่อ $X=1$ ด้วย แต่มวลที่จุดนั้นเป็นศูนย์ อย่าให้โปรแกรมหารด้วยศูนย์แล้วคืนค่าที่ดูเหมือนใช้ได้

ขั้นที่ 5 — ค่าเฉลี่ยตามเงื่อนไขเป็นฟังก์ชันของข้อมูล

เมื่อได้ conditional distribution แล้ว ทุกสิ่งที่ทำกับการแจกแจงหนึ่งตัวแปรทำได้ทันที ที่ใช้บ่อยที่สุดคือค่าเฉลี่ยและ variance ซึ่งตอนนี้ขึ้นกับค่าที่รู้

\[\begin{aligned} m(y)&=E[X\mid Y=y]=\int x\,f_{X\mid Y}(x\mid y)\,dx,\\ m(y)&=\frac{1}{1-y}\int_y^1x\,dx=\frac{1+y}{2},\\ v(y)&=\operatorname{Var}(X\mid Y=y)=\frac{(1-y)^2}{12},\\ m(0.3)&=0.65,\qquad v(0.3)=\tfrac{0.49}{12}\approx0.0408. \end{aligned}\]

บรรทัดแรกคือนิยาม: ค่าเฉลี่ยธรรมดา แต่ใช้ conditional density เป็นน้ำหนัก บรรทัดที่สองแทน density ของสามเหลี่ยม อินทิกรัลได้ $(1-y^2)/2$ และ $1-y^2=(1-y)(1+y)$ ตัวหาร $1-y$ จึงตัดกันเหลือ $(1+y)/2$ ซึ่งคือจุดกึ่งกลางของช่วง $y$ ถึง 1 ตามที่คาดจาก uniform บรรทัดที่สามคือ variance ของ uniform บนช่วงยาว $1-y$ ซึ่งเท่ากับความยาวกำลังสองหารด้วย 12

จุดที่ต้องหยุดคิด: เมื่อรู้ $y$ แล้ว $m(y)$ เป็นตัวเลข แต่ก่อนรู้ $Y$ เรายังไม่รู้ว่าจะได้ $m$ ของค่าไหน $m(Y)=E[X\mid Y]$ จึงเป็นตัวแปรสุ่มที่ขึ้นกับ $Y$ ฟังก์ชัน $m$ นี้เรียกว่า regression function ในตัวอย่างนี้มันเป็นเส้นตรง แต่โดยทั่วไปไม่จำเป็น

ขั้นที่ 6 — เฉลี่ยกลับแล้วต้องได้ค่าเฉลี่ยเดิม

ถ้าเอาค่าเฉลี่ยในแต่ละกรณีมาถ่วงด้วยความถี่ของกรณีนั้น ต้องได้ค่าเฉลี่ยรวม นี่คือ tower property และเป็นการตรวจว่า conditional distribution ที่หามาถูกต้อง

\[\begin{aligned} E[m(Y)]&=\int m(y)\,f_Y(y)\,dy=E[X],\\ E\!\left[\tfrac{1+Y}{2}\right]&=\frac{1+\tfrac13}{2}=\tfrac23,\\ E[X]&=0.60\left(\tfrac{0.4}{0.6}\right)+0.40(-0.5)\\ &=0.4-0.2=0.2. \end{aligned}\]

บรรทัดแรกได้จากการแทน $f_{X\mid Y}f_Y=f_{X,Y}$ แล้วอินทิเกรตทั้งสองแกน (บทพิสูจน์เต็มอยู่ใน tower property) บรรทัดที่สองใช้ $E[Y]=1/3$ จาก marginal distribution ได้ $2/3$ ตรงกับ $E[X]$ ที่หาจาก marginal $2x$ โดยตรง บรรทัดสุดท้ายทำแบบเดียวกันกับตาราง: ค่าเฉลี่ย AAPL ในวัน MSFT ขึ้นคือ $(-2)(0.05)+2(0.25)$ หารด้วย 0.60 ได้ $0.4/0.6=0.667$ ถ่วงกับ −0.5 ของวัน MSFT ลง ได้ 0.2 ตรงกับค่าเฉลี่ยรวม

กับดักคือเฉลี่ย $m(y)$ โดยให้น้ำหนักทุกกรณีเท่ากัน ในตาราง $(0.667-0.5)/2=0.083$ ไม่ใช่ 0.2 เพราะวัน MSFT ขึ้นมีมากกว่าวัน MSFT ลง น้ำหนักต้องเป็นการแจกแจงของตัวแปรที่ใช้เป็นเงื่อนไข

ขั้นที่ 7 — ความผันผวนแยกเป็นส่วนภายในกับส่วนระหว่าง

ข้อมูลช่วยลดความไม่แน่นอนได้แค่ไหน ใช้ law of total variance แยกความผันผวนรวมของ $X$ เป็นสองส่วน

\[\begin{aligned} \operatorname{Var}(X)&=E[v(Y)]+\operatorname{Var}(m(Y)),\\ E[v(Y)]&=\int_0^1\frac{(1-y)^2}{12}\,2(1-y)\,dy=\tfrac{1}{24},\\ \operatorname{Var}(m(Y))&=\tfrac14\operatorname{Var}(Y)=\tfrac14\cdot\tfrac{1}{18}=\tfrac{1}{72},\\ \tfrac{1}{24}+\tfrac{1}{72}&=\tfrac{4}{72}=\tfrac{1}{18}. \end{aligned}\]

ส่วนแรกคือความผันผวนที่ยังเหลือหลังรู้ $Y$ เฉลี่ยข้ามทุกค่า $Y$ ส่วนที่สองคือความผันผวนของค่าเฉลี่ยตามเงื่อนไขเอง เพราะ $m(Y)=(1+Y)/2$ เป็นเส้นตรงที่มีความชัน $\tfrac12$ variance ของมันจึงเป็น $\tfrac14$ ของ $\operatorname{Var}(Y)$ ผลรวม $1/18$ ตรงกับ $\operatorname{Var}(X)=E[X^2]-(E[X])^2=\tfrac12-\tfrac49=\tfrac{1}{18}$

ข้อความนี้สัญญาแค่ว่าโดยเฉลี่ยการรู้ $Y$ ลดความผันผวน (จาก $1/18\approx0.0556$ เหลือ $1/24\approx0.0417$) ไม่ได้สัญญาว่าทุกค่า $y$ จะลด ที่ $y=0.1$ ได้ $v(0.1)=0.81/12=0.0675$ ซึ่งมากกว่า variance รวม เพราะช่วงของ $X$ ยาวถึง 0.9 แต่ uniform บนช่วงนั้นกระจายกว่าการแจกแจง $2x$ ที่กองอยู่ทางขวา

ขั้นที่ 8 — Gaussian: ค่าเฉลี่ยเลื่อนเป็นเส้นตรง ความกว้างหดคงที่

กลับมาที่หุ้นสองตัว ในแบบจำลอง Gaussian เราหา conditional distribution ได้เป็นสูตรปิด และมันให้คำตอบของคำถาม desk ว่า “ถ้า MSFT ลง 3% AAPL ควรลงเท่าไร”

\[\begin{aligned} Y&=\mu_Y+\sigma_Y U,\\ X&=\mu_X+\sigma_X\big(\rho U+\sqrt{1-\rho^2}\,V\big),\\ m(y)&=\mu_X+\rho\frac{\sigma_X}{\sigma_Y}(y-\mu_Y),\\ s^2&=\sigma_X^2(1-\rho^2),\\ m(-3)&=0.6\cdot\tfrac{2.5}{3}\cdot(-3)=-1.5,\\ s&=2.5\sqrt{1-0.36}=2. \end{aligned}\]

สองบรรทัดแรกสร้างคู่ Gaussian จาก $U,V$ ที่เป็น normal มาตรฐานอิสระกัน ตรวจได้ว่า $X$ มีส่วนเบี่ยงเบน $\sigma_X\sqrt{\rho^2+1-\rho^2}=\sigma_X$ และ covariance กับ $Y$ คือ $\rho\sigma_X\sigma_Y$ ตามต้องการ คู่ Gaussian ถูกกำหนดด้วยค่าเฉลี่ยกับ covariance จึงใช้การสร้างนี้แทนแบบจำลองได้

ท่าสำคัญ: รู้ $Y=y$ คือรู้ $U=(y-\mu_Y)/\sigma_Y$ แต่ $V$ ยังสุ่มเหมือนเดิม เพราะไม่เกี่ยวกับ $U$ แทน $U$ ลงในบรรทัดที่สองได้ส่วนคงที่ซึ่งคือ $m(y)$ กับส่วนสุ่ม $\sigma_X\sqrt{1-\rho^2}V$ ซึ่งมี variance $s^2$ ผลคือ $X$ เมื่อรู้ $Y=y$ เป็น normal ค่าเฉลี่ย $m(y)$ ส่วนเบี่ยงเบน $s$

ตัวเลข: ถ้า MSFT ลง 3% ค่าเฉลี่ยของ AAPL คือ −1.5% และส่วนเบี่ยงเบนลดจาก 2.5 เหลือ 2 จุดเปอร์เซ็นต์ โอกาสที่ AAPL ลงเกิน 2% เพิ่มจาก $\Phi(-2/2.5)=0.212$ เป็น $\Phi\big((-2+1.5)/2\big)=\Phi(-0.25)=0.401$ ความชัน $\rho\sigma_X/\sigma_Y=0.5$ คือจำนวนจุดที่ AAPL คาดว่าจะขยับต่อ MSFT หนึ่งจุด ซึ่งคือ hedge ratio ใน MVN conditional distribution ส่วน $s$ ที่ไม่ขึ้นกับ $y$ เป็นคุณสมบัติเฉพาะของ Gaussian ไม่ใช่ของทุกแบบจำลอง ในตัวอย่างสามเหลี่ยม $v(y)=(1-y)^2/12$ ที่เปลี่ยนตาม $y$

เมื่อแบ่งเวกเตอร์เป็นกลุ่มที่รู้ $\mathbf X_1$ กับกลุ่มที่สนใจ $\mathbf X_2$ หลักเดิมยังใช้ได้ทุกมิติ: $f_{\mathbf X_2\mid\mathbf X_1}=f_{\mathbf X}/f_{\mathbf X_1}$ เมื่อตัวหารเป็นบวก ส่วนสูตรปิดของกรณี Gaussian หลายมิติอยู่ในหน้าเดียวกันนั้น

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

สลับทิศของเงื่อนไข: ใช้ $P(\text{down}\mid X=-2)=0.75$ แทน $P(X=-2\mid\text{down})=0.375$ ทำให้ประเมินโอกาส AAPL ลงแรงในวันที่ MSFT ลงสูงไปสองเท่า ตรวจทุกครั้งว่าตัวหารคือมวลของสิ่งที่รู้แล้ว

ลืมหาร: ใช้ 0.15 ตรง ๆ แทน 0.375 คือการใช้สัดส่วนของทุกวันกับคำถามที่จำกัดเฉพาะวัน MSFT ลง ต่ำไป 2.5 เท่า ตรวจได้ทันทีเพราะคอลัมน์ที่ไม่หารรวมได้ 0.40 ไม่ใช่ 1

เฉลี่ยกลับด้วยน้ำหนักเท่ากัน: $(0.667+(-0.5))/2=0.083$ แทนค่าเฉลี่ยจริง 0.2 น้ำหนักต้องเป็น 0.60 กับ 0.40

เชื่อว่าการรู้ข้อมูลลดความเสี่ยงทุกกรณี: สามเหลี่ยมที่ $y=0.1$ ให้ variance 0.0675 สูงกว่าค่ารวม 0.0556 กฎแยก variance รับรองแค่ค่าเฉลี่ยข้ามทุกกรณี

ใช้ข้อมูลที่ยังไม่มีตอนตัดสินใจ: “ถ้า MSFT ปิดลบ 3% วันนี้” เป็นเงื่อนไขของ stress scenario ไม่ใช่สัญญาณที่รู้ล่วงหน้า backtest ที่ใช้ผลตอบแทนปิดตลาดของวันเดียวกันเป็นตัวพยากรณ์จะดูดีเกินจริง

ใช้ทำอะไรบนโต๊ะจริง

stress test เกือบทุกแบบคือ conditional distribution: “ถ้าดัชนีลง 10% พอร์ตจะขาดทุนเฉลี่ยเท่าไร และกระจายแค่ไหน” hedge ratio คือความชันของ $m(y)$ ในแบบจำลอง Gaussian ซึ่งเป็นตัวเดียวกับ beta ใน CAPM เมื่อ $Y$ คือตลาด ส่วนการพยากรณ์ด้วยสัญญาณใด ๆ ก็คือการหา $E[\text{ผลตอบแทนวันพรุ่งนี้}\mid\text{ข้อมูลวันนี้}]$ ซึ่งต้องระวังว่าข้อมูลที่ใช้เป็นเงื่อนไขมีอยู่จริง ณ เวลาที่ตัดสินใจ ในเครดิต การคำนวณโอกาสผิดนัดพร้อมกันเริ่มจากการตรึงภาวะเศรษฐกิจไว้ก่อน ซึ่งเป็นหัวใจของ Gaussian copula

โจทย์ตรวจความเข้าใจ

1. จากตาราง จงหาการแจกแจงของ AAPL ในวันที่ MSFT ขึ้น และ $E[X\mid\text{up}]$

เฉลย

หารคอลัมน์ขึ้นด้วย 0.60: $0.05/0.60=0.083$, $0.30/0.60=0.5$, $0.25/0.60=0.417$ รวมได้ 1 ค่าเฉลี่ย $(-2)(0.083)+2(0.417)=0.667$ จุดเปอร์เซ็นต์ (เท่ากับ $0.4/0.6$) ตรวจด้วยการเฉลี่ยกลับ: $0.60(0.667)+0.40(-0.5)=0.2$ ตรงกับค่าเฉลี่ยรวม

2. ในสามเหลี่ยม เมื่อรู้ $Y=0.6$ จงหา $P(X\gt0.8\mid Y=0.6)$ ค่าเฉลี่ย และส่วนเบี่ยงเบนมาตรฐานตามเงื่อนไข

เฉลย

$X$ เป็น uniform บนช่วง 0.6 ถึง 1 ซึ่งยาว 0.4 โอกาส $(1-0.8)/0.4=0.5$ ค่าเฉลี่ย $(1+0.6)/2=0.8$ variance $0.4^2/12=0.01333$ ส่วนเบี่ยงเบน $0.115$

3. แบบจำลอง Gaussian ของหุ้นสองตัว ถ้า MSFT ขึ้น 3% จงหาค่าเฉลี่ยตามเงื่อนไขของ AAPL และโอกาสที่ AAPL ยังติดลบ

เฉลย

$m(3)=0.5\times3=1.5\%$ ส่วนเบี่ยงเบน 2 เท่าเดิม โอกาสติดลบ $\Phi\big((0-1.5)/2\big)=\Phi(-0.75)=0.227$ ในวันทั่วไปโอกาสนี้คือ $\Phi(0)=0.5$ การรู้ว่า MSFT ขึ้นแรงลดโอกาสนี้ลงเกินครึ่ง แต่ยังไม่ใช่ศูนย์

// 1) table: rows X = -2, 0, 2 ; columns MSFT up, down
const joint = [[.05, .15], [.30, .20], [.25, .05]], xs = [-2, 0, 2];
const colSum = j => joint.reduce((s, r) => s + r[j], 0);
const given = j => joint.map(r => r[j] / colSum(j));          // select, then rescale
const mean = p => p.reduce((s, q, i) => s + q * xs[i], 0);
const down = given(1), up = given(0);
console.log({ down, meanDown: mean(down), meanUp: mean(up),
  tower: colSum(0) * mean(up) + colSum(1) * mean(down),   // 0.2
  reverse: joint[0][1] / (joint[0][0] + joint[0][1]) });  // P(down | X=-2) = 0.75

// 2) triangle: X | Y=y is uniform on [y, 1]
const integrate = (g, a, b, n = 20000) => {
  let s = 0; const h = (b - a) / n;
  for (let i = 0; i < n; i++) s += g(a + (i + .5) * h) * h;
  return s;
};
const m = y => (1 + y) / 2, v = y => (1 - y) ** 2 / 12, fY = y => 2 * (1 - y);
console.log({ m03: m(.3), v03: v(.3), p: (.6 - .3) / .7,
  EmY: integrate(y => m(y) * fY(y), 0, 1),                // 2/3
  within: integrate(y => v(y) * fY(y), 0, 1),             // 1/24
  between: integrate(y => (m(y) - 2 / 3) ** 2 * fY(y), 0, 1), // 1/72
  v01: v(.1) });                                           // 0.0675 > 1/18

// 3) Gaussian model: sx = 2.5, sy = 3, rho = 0.6
function Phi(x) {
  const a = Math.abs(x); let t = a, s = a;
  for (let k = 1; k < 200; k++) { t *= a * a / (2 * k + 1); s += t; }
  const half = Math.exp(-a * a / 2) / Math.sqrt(2 * Math.PI) * s;
  return x < 0 ? .5 - half : .5 + half;
}
const sx = 2.5, sy = 3, r = .6;
const slope = r * sx / sy, s = sx * Math.sqrt(1 - r * r);
const fYm3 = Math.exp(-0.5) / Math.sqrt(2 * Math.PI) / sy;  // area under the raw slice
console.log({ slope, s, mGivenMinus3: slope * -3, fYm3, stretch: 1 / fYm3,

สิ่งที่ควรตอบได้หลังอ่าน

  • conditional distribution คือเลือกส่วนที่ตรงกับสิ่งที่รู้แล้วหารด้วยมวลของส่วนนั้น: วัน MSFT ลง ทำให้ AAPL −2% มีโอกาส $0.15/0.40=0.375$
  • ตัวหารต้องเป็นมวลของสิ่งที่ใช้เป็นเงื่อนไข สลับทิศแล้วได้ 0.75 ซึ่งตอบอีกคำถาม และ Bayes เชื่อมสองทิศเข้าหากัน
  • สำหรับตัวแปรต่อเนื่อง $f_{X\mid Y}=f_{X,Y}/f_Y$ คือรอยตัดของ joint ที่ถูกยืดให้พื้นที่เป็น 1 ใช้ได้เมื่อ $f_Y(y)\gt0$
  • $E[X\mid Y]$ เป็นฟังก์ชันของ $Y$ เฉลี่ยกลับด้วยการแจกแจงของ $Y$ แล้วได้ $E[X]$ และ variance รวมแยกเป็นส่วนภายในกับส่วนระหว่าง โดยไม่ได้สัญญาว่าทุกกรณีจะผันผวนน้อยลง
  • ในแบบจำลอง Gaussian: MSFT −3% ให้ AAPL ค่าเฉลี่ย −1.5% ส่วนเบี่ยงเบน 2 ความชัน 0.5 คือ hedge ratio

ถ้าการรู้ $Y$ ไม่เปลี่ยน conditional distribution ของ $X$ เลยสักค่า ตารางทั้งตารางจะเป็นผลคูณของ marginal หน้าถัดไป independence นิยามสถานการณ์นี้อย่างแม่นยำ และแสดงว่าต้องตรวจอะไรให้ครบก่อนจะคูณโอกาสได้
