5.3 Conditional Distributions

เมื่อรู้ข้อมูลเพิ่ม ต้องเปลี่ยนทั้งกลุ่มอ้างอิงและมาตราส่วนความน่าจะเป็น

จาก “วันทั่วไป” เป็น “วันที่ MSFT ลง”

ในหัวข้อก่อน เรารวมทุกสถานะของ MSFT เพื่อดู AAPL เพียงตัวเดียว คราวนี้คำถามเปลี่ยนเป็น “ในวันที่ MSFT ลง AAPL มีโอกาสลง 2% เท่าไร?” เราจะไม่รวมทั้งตาราง แต่เลือกเฉพาะคอลัมน์ที่ตรงเงื่อนไข แล้วปรับผลรวมของคอลัมน์นั้นให้เป็นหนึ่ง

Conditional distribution คือการแจกแจงภายใต้ข้อมูลที่ระบุ ไม่ใช่เพียงค่าเฉลี่ยใหม่ และไม่ได้บอกเหตุและผลด้วยตัวมันเอง ในตัวอย่างผลตอบแทนรายวันร่วม การรู้ผลตอบแทนของ MSFT ทั้งวันเป็นเงื่อนไขเชิงสถานการณ์ ไม่ใช่สัญญาณที่รู้ล่วงหน้าได้กลางวัน

1. ตัดคอลัมน์ แล้วหารด้วยโอกาสของเงื่อนไข

คอลัมน์ลงมีมวลเพียง 0.40 ค่า 0.15 ในช่องแรกหมายถึง “AAPL ลง 2% และ MSFT ลง” จากทุกวัน แต่เมื่อกลุ่มอ้างอิงเหลือเฉพาะวัน MSFT ลง เราต้องหารด้วย 0.40:

\[ \begin{aligned} P(X=-2\mid Y=\mathrm{down})&=0.15/0.40=0.375,\\ P(X=0\mid Y=\mathrm{down})&=0.20/0.40=0.500,\\ P(X=2\mid Y=\mathrm{down})&=0.05/0.40=0.125. \end{aligned} \]

ผลรวมใหม่เป็นหนึ่ง จากนั้นคำนวณค่าเฉลี่ยด้วยน้ำหนักใหม่:

\[ \begin{aligned} E[X\mid Y=\mathrm{down}]&=(-2)(0.375)+2(0.125)=-0.5,\\ E[X]&=(-2)(0.20)+2(0.30)=0.2. \end{aligned} \]

ทั้งสองค่ามีหน่วยจุดเปอร์เซ็นต์ต่อวัน ค่าเฉลี่ยตามเงื่อนไขเป็น −0.5% เทียบกับค่าเฉลี่ยทุกวัน 0.2% ไม่ได้แปลว่า AAPL จะให้ผลตอบแทน −0.5% ทุกครั้ง และอย่าสลับเป็น $P(Y=\mathrm{down}\mid X=-2)=0.15/0.20=0.75$ ซึ่งตอบอีกคำถามหนึ่ง

2. กรณีต่อเนื่อง: ทำไมไม่หารด้วย $P(Y=y)$?

ถ้า $Y$ ต่อเนื่อง โอกาส $P(Y=y)$ เป็นศูนย์ เราจึงเริ่มจากช่วงแคบ $y\le Y\le y+h$ ที่มีโอกาสเป็นบวก แล้วค่อยลดความกว้างช่วง ไม่ใช้สูตรเหตุการณ์แบบตรง ๆ จนกลายเป็น $0/0$

\[ \begin{aligned} &P(X\le x\mid y\le Y\le y+h)\\ &=\frac{\displaystyle\int_{-\infty}^{x}\int_y^{y+h} f_{X,Y}(u,v)\,dv\,du} {\displaystyle\int_y^{y+h}f_Y(v)\,dv}. \end{aligned} \]

หารทั้งเศษและส่วนด้วย $h$ แล้วให้ $h\to0$ ที่จุดซึ่ง density มีพฤติกรรมเหมาะสมและ $f_Y(y)\gt0$ ค่าเฉลี่ยบนช่วงจะเข้าใกล้ density ที่ $y$:

\[ \begin{aligned} F_{X\mid Y}(x\mid y)&=\int_{-\infty}^{x} \frac{f_{X,Y}(u,y)}{f_Y(y)}\,du,\\ f_{X\mid Y}(x\mid y)&=\frac{f_{X,Y}(x,y)}{f_Y(y)},\\ \int_{-\infty}^{\infty}f_{X\mid Y}(x\mid y)\,dx &=\frac{\int f_{X,Y}(x,y)\,dx}{f_Y(y)}=1. \end{aligned} \]

นี่คือการเลือก รอยตัด ของ joint PDF แล้ว normalize ด้วยพื้นที่ใต้รอยตัด หน่วยของ joint PDF หารหน่วยของ $f_Y$ แล้วเหลือส่วนกลับของหน่วย $X$ ถูกต้องตาม density ของตัวแปรเดียว

สูตรอัตราส่วนกำหนด conditional density ได้เกือบทุกค่าของเงื่อนไขที่เกี่ยวข้องกับการแจกแจง หาก $f_Y(y)=0$ สูตรนี้ใช้ไม่ได้ อย่าให้โปรแกรมแทนผลหารด้วยศูนย์เป็นการแจกแจงที่มีความหมายเอง

3. ค่าเฉลี่ยใหม่เป็นฟังก์ชันของข้อมูล

\[ \begin{aligned} m(y)&=E[X\mid Y=y] =\int_{-\infty}^{\infty}x f_{X\mid Y}(x\mid y)\,dx,\\ v(y)&=\operatorname{Var}(X\mid Y=y)\\ &=\int_{-\infty}^{\infty}(x-m(y))^2 f_{X\mid Y}(x\mid y)\,dx. \end{aligned} \]

เมื่อทราบ $y$ แล้ว $m(y)$ เป็นตัวเลข แต่ก่อนทราบค่า $m(Y)=E[X\mid Y]$ เป็นตัวแปรสุ่มที่เปลี่ยนตามข้อมูล ฟังก์ชันนี้เรียกว่า regression function และไม่จำเป็นต้องเป็นเส้นตรง หากต้องการค่าคาดหมาย ต้องมี $E[|X|]\lt\infty$ และหากต้องการใช้สูตร variance ต่อไป ต้องมี $E[X^2]\lt\infty$

4. ตัวอย่างสามเหลี่ยม: คำนวณได้ทั้ง distribution และ mean

ให้ $f_{X,Y}(x,y)=2$ บน $0\le y\le x\le1$ และศูนย์ที่อื่น ตัวแปรไม่มีหน่วย จาก 5.2 เรามี $f_Y(y)=2(1-y)$ สำหรับ $0\le y\le1$ เมื่อ $0\le y\lt1$:

\[ \begin{aligned} f_{X\mid Y}(x\mid y)&=\frac{1}{1-y},&&y\le x\le1,\\ \int_y^1\frac{1}{1-y}\,dx&=1,\\ X\mid Y=y&\sim\mathrm{Uniform}(y,1). \end{aligned} \]

ส่วน conditional density เป็นศูนย์นอกช่วงนั้น การสะสมและการหาค่าเฉลี่ยให้

\[ F_{X\mid Y}(x\mid y)= \begin{cases} 0,&x\lt y,\\ (x-y)/(1-y),&y\le x\le1,\\ 1,&x\gt1, \end{cases} \]
\[ \begin{aligned} m(y)&=\frac{1}{1-y}\int_y^1x\,dx =\frac{1-y^2}{2(1-y)}=\frac{1+y}{2},\\ E[X^2\mid Y=y]&=\frac{1}{1-y}\int_y^1x^2\,dx =\frac{1+y+y^2}{3},\\ v(y)&=\frac{1+y+y^2}{3}-\left(\frac{1+y}{2}\right)^2\\ &=\frac{(1-y)^2}{12}. \end{aligned} \]

เช่น เมื่อ $y=0.3$ เราเหลือ uniform บน $[0.3,1]$ มี density $10/7$ ค่าเฉลี่ย 0.65 และ variance $0.49/12\approx0.0408333$ โอกาส $X\le0.6$ เท่ากับ $0.3/0.7=3/7$ ที่ $y=1$ ตัวหารเป็นศูนย์ สูตรนี้จึงไม่กำหนดคำตอบ แม้อาจนิยามลิมิตให้เป็นมวลจุดที่ 1 ได้ แต่นั่นเป็นการเลือกต่อเติม ไม่ใช่ผลจากการหาร density

5. เฉลี่ยกลับต้องได้ของเดิม: Tower property

ถ้าเอาค่าเฉลี่ยของแต่ละกลุ่มมาถ่วงด้วยความถี่ของกลุ่ม เราต้องได้ค่าเฉลี่ยรวม เห็นได้โดยแทน $m(y)$ แล้วคืน joint density:

\[ \begin{aligned} E[m(Y)]&=\int\left[\int x f_{X\mid Y}(x\mid y)\,dx\right]f_Y(y)\,dy\\ &=\iint x f_{X,Y}(x,y)\,dx\,dy=E[X]. \end{aligned} \]

ในสามเหลี่ยม $E[Y]=1/3$ จึงได้ $E[(1+Y)/2]=(1+1/3)/2=2/3$ ตรงกับการอินทิเกรต $x f_X(x)=2x^2$ โดยตรง ห้ามเฉลี่ยค่า $m(y)$ แบบให้น้ำหนักทุก $y$ เท่ากัน เพราะ $Y$ ไม่ได้ uniform

6. แยกความผันผวน “ภายในกลุ่ม” และ “ระหว่างกลุ่ม”

เขียน $X-E[X]=(X-m(Y))+(m(Y)-E[X])$ เมื่อยกกำลังสองแล้วเฉลี่ย พจน์คูณข้ามเป็นศูนย์ เพราะ $E[X-m(Y)\mid Y]=0$ จึงได้กฎความแปรปรวนรวม:

\[ \operatorname{Var}(X) =E[\operatorname{Var}(X\mid Y)] +\operatorname{Var}(E[X\mid Y]). \]

สำหรับสามเหลี่ยม $E[X^2]=1/2$ และ $\operatorname{Var}(Y)=1/18$ ดังนั้น

\[ \begin{aligned} \operatorname{Var}(X)&=\frac12-\left(\frac23\right)^2=\frac1{18},\\ \operatorname{Var}(m(Y))&=\frac14\operatorname{Var}(Y)=\frac1{72},\\ E[v(Y)]&=\int_0^1\frac{(1-y)^2}{12}\,2(1-y)\,dy=\frac1{24},\\ \frac1{72}+\frac1{24}&=\frac1{18}. \end{aligned} \]

ข้อสรุปคือ variance ตามเงื่อนไขลดลงโดยเฉลี่ย ไม่ใช่ทุกค่า $y$ ตัวอย่างเช่น $y=0.1$ ให้ $v(0.1)=0.81/12=0.0675$ มากกว่า variance รวม $1/18\approx0.05556$ ได้โดยไม่ขัดกับกฎนี้

7. กรณี Gaussian: เห็นทั้งตำแหน่งและความกว้างที่เปลี่ยน

รูปทั้งสี่ใช้แบบจำลอง jointly Gaussian สมมติ ค่าเฉลี่ยทั้งคู่ศูนย์ ส่วนเบี่ยงเบนมาตรฐาน AAPL 2.5 และ MSFT 3 จุดเปอร์เซ็นต์ กับ $\rho=0.6$ ภายใต้เงื่อนไข Gaussian และ $|\rho|\lt1$:

\[ \begin{aligned} X\mid Y=y&\sim N(m(y),s^2),\\ m(y)&=\mu_X+\rho\frac{\sigma_X}{\sigma_Y}(y-\mu_Y),\\ s^2&=\sigma_X^2(1-\rho^2). \end{aligned} \]
ที่มาของสูตร: แยกส่วนที่รู้แล้วออกจากส่วนที่ยังสุ่ม

ให้ $U,V$ เป็น standard Normal ที่เป็นอิสระกัน และให้ $\sigma_X,\sigma_Y\gt0$ เราสร้าง jointly Gaussian ที่มี mean, SD และ correlation ตามต้องการได้ดังนี้:

\[ \begin{aligned} Y&=\mu_Y+\sigma_Y U,\\ X&=\mu_X+\sigma_X\bigl(\rho U+\sqrt{1-\rho^2}\,V\bigr),\\ \operatorname{Var}(X)&=\sigma_X^2\bigl(\rho^2+1-\rho^2\bigr)=\sigma_X^2,\\ \operatorname{Cov}(X,Y)&=\rho\sigma_X\sigma_Y. \end{aligned} \]

joint Gaussian ถูกกำหนดด้วย mean และ covariance จึงใช้การสร้างนี้แทนโมเดลข้างต้นได้ เมื่อรู้ $Y=y$ เรารู้ $U=(y-\mu_Y)/\sigma_Y$ แต่ $V$ ยังเป็น standard Normal ตัวเดิม เพราะเป็นอิสระจาก $U$:

\[ \begin{aligned} X\mid Y=y &=\mu_X+\rho\frac{\sigma_X}{\sigma_Y}(y-\mu_Y)\\ &\quad+\sigma_X\sqrt{1-\rho^2}\,V. \end{aligned} \]

สองพจน์แรกเป็นค่าคงที่เมื่อรู้ $y$ จึงเป็น conditional mean ส่วนพจน์สุดท้ายมี mean ศูนย์และ variance $\sigma_X^2(1-\rho^2)$ นี่คือที่มาของทั้งสองสูตร ไม่ใช่กฎสำหรับข้อมูลที่เพียงแค่มี correlation เท่ากัน

เมื่อ $y=-3$ ได้ $m=-1.5$ จุดเปอร์เซ็นต์ และ $s=2$ จุดเปอร์เซ็นต์ เทียบกับ marginal ที่ mean 0 และ SD 2.5 จุดเปอร์เซ็นต์ สูตร variance ที่ไม่ขึ้นกับ $y$ เป็นคุณสมบัติเฉพาะของ Gaussian นี้ ไม่ใช่ของทุก conditional distribution

รูป 5.3a แสดง density ที่ normalize แล้ว มีจุดกึ่งกลาง −1.5% และพื้นที่เกือบหนึ่งในช่วงที่วาด ไม่ใช่รอยตัดดิบของ joint PDF

รูป 5.3b เทียบ marginal กับ conditional: เส้นตามเงื่อนไขเลื่อนไปซ้ายและแคบลงตามพารามิเตอร์ที่คำนวณข้างต้น

รูป 5.3c แสดง $m(y)=0.5y$ จุดที่ $y=-3,0,3$ ให้ mean −1.5, 0, 1.5 ตามลำดับ ความสัมพันธ์นี้เป็นการคาดหมายตามเงื่อนไข ไม่ใช่ผลตอบแทนจริงทุกครั้งหรือข้อสรุปเชิงเหตุผล

รูป 5.3d เป็นกราฟแท่งของ พื้นที่ใต้ density ในกรณี MSFT −3%, 0%, +3% ทุกแท่งใกล้หนึ่ง เป็นการตรวจ normalization ไม่ใช่แผนภูมิโอกาสของสามค่าผลตอบแทน MSFT

8. Bayes และเงื่อนไขที่เป็นกลุ่มตัวแปร

แบ่งเวกเตอร์เป็นข้อมูล $\mathbf A$ กับสิ่งที่สนใจ $\mathbf B$ หลักเลือกและ normalize ยังเหมือนเดิม เมื่อ $f_{\mathbf A}(\mathbf a)\gt0$:

\[ \begin{aligned} f_{\mathbf B\mid\mathbf A}(\mathbf b\mid\mathbf a) &=\frac{f_{\mathbf A,\mathbf B}(\mathbf a,\mathbf b)}{f_{\mathbf A}(\mathbf a)}\\ &=\frac{f_{\mathbf A\mid\mathbf B}(\mathbf a\mid\mathbf b) f_{\mathbf B}(\mathbf b)}{f_{\mathbf A}(\mathbf a)},\\ F_{\mathbf B\mid\mathbf A}(\mathbf b\mid\mathbf a) &=\int_{\mathbf u\le\mathbf b} f_{\mathbf B\mid\mathbf A}(\mathbf u\mid\mathbf a)\,d\mathbf u. \end{aligned} \]

อสมการของเวกเตอร์หมายถึงทุกพิกัดผ่านเกณฑ์พร้อมกัน สูตร Bayes สลับทิศของเงื่อนไขด้วยน้ำหนัก marginal ไม่ใช่สลับชื่อในวงเล็บเฉย ๆ แนวคิดการปรับความเชื่อจากข้อมูลของ Bayes และ Laplace จึงเชื่อมต่อกับการ normalize density ได้โดยตรง

JavaScript: ตรวจ conditional, tower และ total variance

const down = [.15,.20,.05].map(p => p/.40);
const values = [-2,0,2];
const downMean = down.reduce((s,p,i) => s+p*values[i],0);
function integrate(f,a,b,n=10000) {
  const h=(b-a)/n; let s=0;
  for(let i=0;i<n;i++) s+=f(a+(i+.5)*h)*h;
  return s;
}
function conditional(x,y) {
  if(y<0 || y>=1) throw new RangeError('Need 0 <= y < 1');
  return x<y || x>1 ? 0 : 1/(1-y);
}
const y=.3, m=(1+y)/2;
const mean = integrate(x => x*conditional(x,y),y,1);
const variance = integrate(x => (x-m)**2*conditional(x,y),y,1);
const tower = integrate(t => ((1+t)/2)*2*(1-t),0,1);
const within = integrate(t => ((1-t)**2/12)*2*(1-t),0,1);
const between = integrate(t => (((1+t)/2)-2/3)**2*2*(1-t),0,1);
let rejectsBoundary=false;
try { conditional(1,1); } catch(e) { rejectsBoundary=e instanceof RangeError; }
console.log({down,downMean,mean,variance,
  area:integrate(x => conditional(x,y),y,1),
  probability:integrate(x => conditional(x,y),y,.6),
  tower,within,between,total:within+between,
  gaussianMean:.6*2.5/3*(-3),
  gaussianSD:2.5*Math.sqrt(1-.6**2),
  largerConditionalVariance:(1-.1)**2/12,rejectsBoundary});

ผลสำคัญ: mean 0.65, variance ประมาณ 0.0408333, tower ประมาณ 0.666667 และผลรวม within กับ between ประมาณ 0.0555556 โค้ดตั้งใจปฏิเสธขอบ $y=1$ แทนการให้ค่าที่ดูใช้ได้แต่ผิดความหมาย

ฝึกเปลี่ยนกลุ่มอ้างอิง

  1. จากตาราง หา $E[X\mid Y=\mathrm{up}]$ และใช้ตรวจค่าเฉลี่ยรวม
    เฉลย

    $( -2(0.05)+2(0.25))/0.60=2/3$ จุดเปอร์เซ็นต์ แล้ว $0.60(2/3)+0.40(-0.5)=0.2$ ตรงกับ marginal mean

  2. ในสามเหลี่ยม เมื่อ $Y=0.6$ โอกาส $X\gt0.8$ และค่าเฉลี่ยเป็นเท่าไร?
    เฉลย

    ช่วงใหม่คือ $[0.6,1]$ โอกาส $(1-0.8)/(1-0.6)=0.5$ และ mean $(1+0.6)/2=0.8$

  3. การ conditioning ทำให้ variance ลดลงทุกกรณีหรือไม่?
    เฉลย

    ไม่ กฎรวมรับรองเพียง $E[v(Y)]\le\operatorname{Var}(X)$ เมื่อ variance มีค่าจำกัด ตัวอย่าง $y=0.1$ ข้างต้นมี variance มากกว่าค่ารวม

ข้อจำกัดในการนำไปใช้

หากเงื่อนไขอยู่ในหางที่ $f_Y(y)$ เล็กมาก การประมาณ joint หรือ marginal ผิดเพียงเล็กน้อยอาจทำให้อัตราส่วนไม่นิ่ง ควรตรวจข้อมูลในบริเวณนั้นและทดสอบความไวของแบบจำลอง การสร้าง forecast ต้องกำหนดเวลาของ $X,Y$ ให้ชัดและใช้เฉพาะข้อมูลที่ทราบ ณ เวลาพยากรณ์ ไม่ใช่ผลตอบแทนอนาคตที่ยังไม่เกิด

สิ่งที่ควรจำ
