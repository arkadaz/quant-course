13.3 The Itô Integral

Itô integral คือกำไรสะสมเมื่อเราตั้งจำนวนหุ้นที่ถือก่อนราคาขยับ ถ้าโค้ดเผลอใช้จำนวนหุ้นที่รู้ผลแล้ว จะได้กำไรปลอมเท่ากับผลรวมกำลังสองของการขยับ และกำไรปลอมนี้เฉลี่ยเท่ากับเวลาที่ผ่านไป

ก่อนเอากลยุทธ์เทรดไปใช้เงินจริง ทีม quant (ทีมที่สร้างกลยุทธ์ด้วยคณิตศาสตร์และโค้ด) จะลองกลยุทธ์กับราคาชุดหนึ่งก่อน การลองนี้เรียกว่า backtest คือให้โค้ดเทรดตามกฎของกลยุทธ์ไปทีละวัน แล้วนับกำไรขาดทุน ปัญหาคือ ถ้าโค้ด backtest มีบั๊ก กลยุทธ์ที่ไม่มีดีอะไรเลยก็ดูเก่งได้

ทีมจึงตรวจโค้ดกับตลาดปลอมที่สร้างขึ้นเอง ตลาดนี้ไม่มี edge แน่นอน คือไม่มีความได้เปรียบซ่อนอยู่ ไม่มีกฎการเทรดใดทำกำไรเฉลี่ยได้ ตลาดปลอมตั้งไว้แบบนี้

  • ราคาเริ่มต้น $S_0=\$520$ ตั้งให้ใกล้ราคาของ SPY (กองทุนที่ซื้อขายเหมือนหุ้น และวิ่งตามดัชนี S&P 500)
  • ความผันผวนต่อปี $\sigma=18\%$ คิดเป็นดอลลาร์ได้ $\sigma S_0=0.18\times520=\$93.6$ แปลว่าการขยับของราคาในหนึ่งปีมี SD (standard deviation) \$93.6
  • ราคาเดินสุ่มแบบ Brownian motion โดยไม่มี drift คือไม่มีแนวโน้มขึ้นหรือลง เขียนได้ $S_t=520+93.6\,W_t$ โดย $W_t$ คือ Brownian motion มาตรฐาน: เริ่มที่ 0 และหลังผ่านไป $t$ ปี มีค่าสุ่มแบบ Normal ที่ค่าเฉลี่ย 0 และ SD $\sqrt t$

กลยุทธ์ที่ทดสอบเป็นแบบ momentum คือไล่ตามทิศของราคา ราคาอยู่เหนือ \$520 กี่ดอลลาร์ ก็ถือ 100 หุ้นต่อทุกดอลลาร์นั้น เขียนเป็นสูตรได้ $H=100\,(S-520)$ หุ้น เช่น ราคา \$523 ถือ $100\times3=300$ หุ้น ถ้าราคาต่ำกว่า \$520 ตัวเลขจะติดลบ แปลว่า short คือยืมหุ้นมาขาย ซึ่งได้กำไรเมื่อราคาลง

ทีมปรับจำนวนหุ้นวันละครั้ง รันหนึ่งปี และสุ่มเส้นทางราคา (ราคาหนึ่งเส้นตลอดปี) ทั้งหมด 20,000 เส้น โค้ดรายงานว่ากำไรเฉลี่ยราว \$874,000 ต่อปี และไม่มีเส้นทางไหนขาดทุนเลย กลยุทธ์นี้ดีจริงไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ดี ตลาดนี้ไม่มี edge กลยุทธ์ที่ทำได้จริงจึงต้องได้กำไรเฉลี่ย \$0 บั๊กอยู่ที่โค้ดตั้งจำนวนหุ้นด้วยราคาปิดของวันเดียวกับวันที่คิดกำไร เท่ากับรู้ผลของวันนั้นก่อนตัดสินใจ

หน้านี้จะพิสูจน์ทีละขั้นว่ากำไรปลอมเท่ากับ 100 คูณผลรวมของ $(\Delta S)^2$ ทั้งปี โดย $\Delta S$ คือการขยับของราคาในหนึ่งวัน ผลรวมนี้เฉลี่ยเท่ากับ $(\sigma S_0)^2$ ต่อปี กำไรปลอมจึงเฉลี่ย $100\times93.6^2=\$876{,}096$ ต่อปี ตัวเลข \$874,000 ที่โค้ดรายงานคือค่านี้บวกความคลาดจากการสุ่ม และเพราะกำไรปลอมเป็นผลรวมของกำลังสอง มันจึงเป็นบวกทุกเส้นทาง ส่วนโค้ดที่ถูกต้องให้กำไรเฉลี่ย \$0 และขาดทุนใน 68% ของเส้นทาง

ภาพรวมก่อนลงสูตร

กำไรของกลยุทธ์ใดก็ตามคิดแบบเดียวกัน แบ่งเวลาเป็นท่อนสั้น ๆ เช่น วันละท่อน ในแต่ละท่อน กำไรเท่ากับจำนวนหุ้นที่ถือคูณการขยับของราคาในท่อนนั้น แล้วบวกทุกท่อน จำนวนที่ถือนี้เรียกว่าสถานะ (position) ถ้าเขียนสถานะเป็น $H$ และการขยับของราคาเป็น $\Delta S$ กำไรรวมคือ $\sum H\,\Delta S$

คำถามเดียวของหน้านี้คือ ค่า $H$ ที่เอามาคูณ อ่านตอนไหนของท่อน ใน calculus ปกติ จะอ่านที่ต้นท่อน ปลายท่อน หรือกลางท่อน ก็ได้คำตอบเดียวกันเมื่อซอยท่อนให้สั้นลงเรื่อย ๆ ทำไม? ส่วนต่างระหว่างอ่านปลายท่อนกับอ่านต้นท่อน คือผลรวมของ “การขยับของ $H$ คูณการขยับของ $S$” ทุกท่อน หรือ $\sum_i(H_i-H_{i-1})\,\Delta S_i$ ถ้าเส้นเรียบ ท่อนยาว $\Delta t$ ขยับราว $\Delta t$ ผลคูณจึงราว $(\Delta t)^2$ รวม $T/\Delta t$ ท่อนได้ราว $T\,\Delta t$ ซึ่งหายไปเมื่อซอยถี่

เส้นทาง Brownian ไม่เรียบ มันขยับราว $\sqrt{\Delta t}$ ต่อท่อน ถ้า $H$ ขยับตามราคาด้วย ผลคูณจึงราว $\sqrt{\Delta t}\times\sqrt{\Delta t}=\Delta t$ และรวมทุกท่อนได้ราว $T$ ซึ่งไม่หายไปไหน (เรื่องนี้ชื่อ quadratic variation: ผลรวมกำลังสองของการขยับเท่ากับเวลาที่ผ่านไป) จุดที่อ่าน $H$ จึงเปลี่ยนคำตอบไปเท่ากับเวลาพอดี

Itô integral เลือกอ่านที่ต้นท่อน เพราะเป็นทางเดียวที่ตรงกับการเทรดจริง: ต้องตั้งสถานะก่อน ราคาค่อยขยับ รูปด้านล่างคิดกำไรบนเส้นทางสี่ก้าวเส้นเดียวกันสองแบบ แบบอ่านต้นท่อน (เขียว) ได้กำไรรวม 0 แบบอ่านปลายท่อน (แดง) ได้ 1.0 ทั้งที่เป็นตลาดเดียวกัน ขั้นที่ 1 และขั้นที่ 2 จะคำนวณสองตัวเลขนี้ทีละไตรมาส

จากนั้นหน้านี้จะวัดส่วนต่างแบบทั่วไป แล้วใช้มันนิยาม Itô integral ซึ่งให้ความหมายกับพจน์ $\int b\,dW$ ในทุก SDE (สมการที่บอกว่าสิ่งที่สุ่มขยับอย่างไรในเวลาสั้น ๆ) ที่ Itô's lemma ใช้ แล้วพิสูจน์สองสมบัติที่ใช้ตลอดบท ข้อแรก กำไรเฉลี่ยเป็นศูนย์ ข้อสอง variance ของกำไรหาได้จากสูตรชื่อ Itô isometry สุดท้ายจะตอบโจทย์ backtest เป็นดอลลาร์ และจบที่กำไรขาดทุนของการ hedge

ขั้นที่ 1 — สี่ก้าวด้วยมือ: ตั้งสถานะก่อน ราคาค่อยขยับ

เริ่มจากกรณีเล็กที่สุดที่คิดด้วยมือได้ เพื่อดูว่า “ตั้งสถานะก่อน ราคาค่อยขยับ” หน้าตาเป็นอย่างไรเมื่อเป็นตัวเลข

โจทย์ให้อะไรมาบ้าง:

  • หนึ่งปีแบ่งเป็นสี่ไตรมาส ท่อนละ $\Delta t=0.25$ ปี
  • ราคาของเล่นคือ $W$ เอง เดินแบบโยนเหรียญ แต่ละไตรมาสขึ้นหรือลง $\sqrt{\Delta t}=\sqrt{0.25}=0.5$ ขนาดนี้เลือกให้เหมือน Brownian motion คือการขยับในท่อนยาว $\Delta t$ มีค่าเฉลี่ย 0 และ variance $0.5^2=0.25=\Delta t$
  • เส้นทางที่ออก (สมมติ) คือ ขึ้น ลง ขึ้น ขึ้น จึงได้ $W$ เป็น 0, 0.5, 0, 0.5, 1.0 (เส้นทางในรูปด้านบน)
  • กลยุทธ์ถือ $H=W$ หน่วย: ที่ต้นไตรมาสดูว่า $W$ อยู่ที่เท่าไร แล้วถือเท่านั้นหน่วยตลอดไตรมาส กำไรของไตรมาสที่ $i$ คือสถานะคูณการขยับ $H_{i-1}\,\Delta W_i$
\[ \begin{aligned} H_{i-1}=W_{i-1}&:\ 0,\ 0.5,\ 0,\ 0.5,\\ \Delta W_i&:\ +0.5,\ -0.5,\ +0.5,\ +0.5,\\ I_4&=0(0.5)+0.5(-0.5)\\ &\quad+0(0.5)+0.5(0.5)=0. \end{aligned} \]

คำตอบ: กำไรสะสม $I_4=0$ ไตรมาสที่สองถือ 0.5 หน่วยแล้วราคาลง จึงเสีย $0.5\times(-0.5)=-0.25$ ไตรมาสที่สี่ถือ 0.5 หน่วยแล้วราคาขึ้น จึงได้ $0.5\times0.5=+0.25$ ทุกสถานะรู้ค่าแล้วก่อนการขยับที่มันคูณ นี่คือสิ่งที่ทำได้จริงในตลาด

ตรวจเองใน 10 วินาที: ไตรมาสแรกและไตรมาสที่สามเริ่มที่ $W=0$ จึงถือ 0 หน่วย ได้กำไร 0 ไม่ว่าราคาจะไปทางไหน เหลือสองไตรมาสที่หักกันพอดี $-0.25+0.25=0$

ขั้นที่ 2 — เลื่อนดัชนีหนึ่งช่อง: กำไรปลอมโผล่มา

ทีนี้ทำบั๊กแบบเดียวกับในโจทย์ backtest ให้เห็นกับตา ใช้เส้นทางเดิม แต่อ่านสถานะที่ปลายไตรมาสแทนต้นไตรมาส

โจทย์ให้อะไรมาบ้าง: เส้นทางเดิม $W$ เป็น 0, 0.5, 0, 0.5, 1.0 แต่โค้ดคูณการขยับของไตรมาสที่ $i$ ด้วย $W_i$ ซึ่งเป็นค่าที่ปลายไตรมาสเดียวกัน ค่านี้รู้ได้ก็ต่อเมื่อไตรมาสนั้นจบแล้ว

ในตารางข้อมูลรายวัน บั๊กนี้หน้าตาแบบนี้ แถว $i$ เก็บสองอย่าง คือสัญญาณที่คิดจากราคาปิดวันที่ $i$ และผลตอบแทนของวันที่ $i$ (จากราคาปิดเมื่อวานถึงราคาปิดวันนี้) โค้ดที่ถูกต้องเอาสัญญาณแถว $i$ ไปคูณผลตอบแทนแถว $i+1$ แต่โค้ดที่มีบั๊กคูณกับแถว $i$ เลย

\[ \begin{aligned} H_i=W_i&:\ 0.5,\ 0,\ 0.5,\ 1.0,\\ R_4&=0.5(0.5)+0(-0.5)\\ &\quad+0.5(0.5)+1.0(0.5)=1.0. \end{aligned} \]

คำตอบ: $R_4=1.0$ จากเส้นทางเดียวกันและตลาดเดียวกัน ไตรมาสที่สอง แบบนี้ถือ 0 หน่วยพอดีตอนราคาลง จึงเสีย $0\times(-0.5)=0$ ไตรมาสที่สี่ถือ 1.0 หน่วยตอนราคาขึ้น จึงได้ $1.0\times0.5=0.5$ ทุกการตัดสินใจรู้ผลก่อนแล้ว

ตรวจเองใน 10 วินาที: ส่วนต่าง $R_4-I_4=1.0-0=1.0$ เท่ากับผลรวมกำลังสองของสี่ก้าว $4\times0.5^2=1.0$ พอดี ขั้นถัดไปแสดงว่าไม่ใช่เรื่องบังเอิญ

ขั้นที่ 3 — ส่วนต่างคือผลรวมกำลังสองพอดี ทุกเส้นทาง

ส่วนต่าง 1.0 เป็นเรื่องบังเอิญของเส้นทางนี้ หรือเกิดกับทุกเส้นทาง? เพื่อตอบ ให้ลบสองผลรวมกันแบบทั่วไป (ยังถือ $H=W$ เหมือนเดิม) แล้วเขียนทั้งสองผลรวมด้วยของสองอย่างที่อ่านได้จากเส้นทาง คือจุดจบ $W_T$ และผลรวมกำลังสองของการขยับ $Q_n=\sum_i(\Delta W_i)^2$ เครื่องมือมีอย่างเดียว คือกระจายกำลังสองของ $W_i=W_{i-1}+\Delta W_i$

\[ \begin{aligned} R_n-I_n&=\textstyle\sum_i(W_i-W_{i-1})\,\Delta W_i\\ &=\textstyle\sum_i(\Delta W_i)^2=Q_n,\\ W_i^2-W_{i-1}^2&=2W_{i-1}\Delta W_i+(\Delta W_i)^2,\\ W_T^2&=2I_n+Q_n,\\ I_n&=\tfrac12\big(W_T^2-Q_n\big),\\ R_n=I_n+Q_n&=\tfrac12\big(W_T^2+Q_n\big)\gt0,\\ I_4&=\tfrac12(1-1)=0,\\ R_4&=\tfrac12(1+1)=1. \end{aligned} \]

ส่วนต่างหาได้ง่าย เพราะระดับที่ปลายท่อนลบระดับที่ต้นท่อนก็คือการขยับของท่อนนั้นเอง ส่วนต่างทั้งหมดจึงเป็นผลรวมกำลังสอง $Q_n$

จุดที่ต้องคิดคือการกระจายกำลังสอง เมื่อบวกทุกท่อน ฝั่งซ้าย $W_i^2-W_{i-1}^2$ หักกันเป็นทอด ๆ เหลือ $W_T^2-W_0^2=W_T^2$ (เพราะ $W_0=0$) ส่วนฝั่งขวาคือ $2I_n+Q_n$ พอดี ย้ายข้างก็ได้ $I_n$ และ $R_n$ บนเส้นทางสี่ก้าว $W_T=1$ และ $Q_4=4\times0.5^2=1$ จึงได้ 0 กับ 1 ตรงกับที่คิดด้วยมือ

$Q_n$ ไม่หายเมื่อซอยถี่ เพราะแต่ละ $(\Delta W_i)^2$ เฉลี่ย $\Delta t$ รวม $n$ ท่อนจึงเฉลี่ย $n\,\Delta t=T$ ทุกความละเอียด ใน calculus ปกติสองแบบให้คำตอบเดียวกัน แต่บนเส้นทาง Brownian ต่างกันราว $T$

สัญญาณเตือนที่ดีที่สุดอยู่ที่ $R_n$ มันเป็นครึ่งหนึ่งของผลบวกกำลังสองสองก้อน จึงเป็นบวกทุกเส้นทาง ดังนั้น backtest ที่ไม่เคยขาดทุนในตลาดสุ่มคือ backtest ที่รู้อนาคต

ขั้นที่ 4 — นิยาม: Itô integral อ่านตัวคูณที่ต้นท่อนเสมอ

ใน calculus ปกติ จะเลือกจุดไหนในท่อนมาคูณก็ได้ขีดจำกัดเดียวกัน แต่ส่วนต่าง $Q_n$ ที่เพิ่งหาได้บอกว่าที่นี่เลือกตามใจไม่ได้ ต้องประกาศให้ชัดเป็นนิยาม Itô เลือกต้นท่อน เพราะเป็นทางเดียวที่ตรงกับการเทรดจริง นิยามนี้ยังให้ความหมายกับ SDE ที่ใช้มาตั้งแต่หน้าก่อน ๆ ด้วย

\[ \begin{aligned} \int_0^TH_t\,dW_t&:=\lim_{n\to\infty}\textstyle\sum_{i=1}^nH_{t_{i-1}}\,\Delta W_i,\\ X_T&=X_0+\int_0^Ta\,dt+\int_0^Tb\,dW_t. \end{aligned} \]

นิยามบอกว่า Itô integral คือผลรวม “สถานะต้นท่อน คูณการขยับ” เมื่อซอยท่อนให้สั้นลงเรื่อย ๆ เงื่อนไขเดียวคือ $H_{t_{i-1}}$ ต้องคำนวณได้จากข้อมูลถึงเวลา $t_{i-1}$ เท่านั้น ตำราเรียกว่า adapted สี่ก้าวด้วยมือในขั้นที่ 1 ก็คือผลรวมนี้ที่ $n=4$

สูตรที่สองคือความหมายเต็มของ SDE ที่เขียนย่อว่า $dX=a\,dt+b\,dW$ โดย $X$ คือสิ่งที่สุ่ม เช่น ราคา $a$ คือ drift หรืออัตราการขยับส่วนที่ไม่สุ่ม และ $b$ คือขนาดของส่วนที่สุ่ม พจน์ $\int a\,dt$ เป็น integral ปกติตามเวลา ส่วนพจน์ $\int b\,dW$ เป็น Itô integral ตามนิยามข้างบน

ทำไมไม่อ่านกลางท่อน? ถ้าใช้ค่าเฉลี่ยของสถานะต้นท่อนกับปลายท่อน เส้นทางสี่ก้าวได้ $\tfrac12(I_4+R_4)=\tfrac12(0+1.0)=0.5$ เท่ากับ $\tfrac12W_T^2$ ตามสูตร $\int x\,dx=\tfrac12x^2$ ของ calculus ปกติพอดี integral แบบนี้ชื่อ Stratonovich integral แต่ค่าเฉลี่ยของมันคือ $\tfrac12(\mathbb E[I_n]+\mathbb E[R_n])=\tfrac12(0+T)=\tfrac12T$ ไม่ใช่ศูนย์ (ขั้นถัดไปพิสูจน์ค่าเฉลี่ยสองตัวนี้) เพราะมันต้องรู้การขยับครึ่งท่อนข้างหน้า ฟิสิกส์ใช้มันได้ แต่ไม่ใช่กำไรที่นักเทรดทำได้

คำว่าขีดจำกัดของผลรวมสุ่มในที่นี้ หมายถึงระยะห่างกำลังสองเฉลี่ยระหว่างผลรวมกับ integral เข้าหาศูนย์ ไม่ได้แปลว่าทุกเส้นทางลู่เข้าแบบตัวเลขธรรมดา รายละเอียดนี้ไม่เปลี่ยนการคำนวณใดในบทนี้

ขั้นที่ 5 — ทำไมค่าเฉลี่ยเป็นศูนย์: ถือก่อน ขยับทีหลัง

ในตลาดที่ไม่มี edge กลยุทธ์ที่ทำได้จริงทุกตัวควรได้กำไรเฉลี่ยศูนย์ ขั้นนี้พิสูจน์ว่าเป็นอย่างนั้นจริง และพิสูจน์ว่าแบบอ่านปลายท่อนเฉลี่ย $T$ วิธีคือดูทีละท่อน แล้วใช้ tower property: ค่าเฉลี่ยของ “ค่าเฉลี่ยเมื่อรู้ข้อมูลบางส่วน” เท่ากับค่าเฉลี่ยเดิม เราจึงหาค่าเฉลี่ยโดยยืนมองจากต้นท่อนก่อนได้

ยืนที่ต้นท่อน ($\mathbb E_{i-1}$ คือค่าเฉลี่ยเมื่อรู้ข้อมูลถึงตรงนั้น) สถานะ $H_{i-1}$ รู้ค่าแล้ว จึงดึงออกนอกค่าเฉลี่ยได้เหมือนค่าคงที่ ส่วน $\Delta W_i$ ยังไม่เกิด และเฉลี่ยศูนย์ไม่ว่าอดีตเป็นอย่างไร เทคนิคนี้เหมือนที่ใช้หา ค่าเฉลี่ยของ $W_{t+s}W_s$

\[ \begin{aligned} \mathbb E[H_{i-1}\Delta W_i]&=\mathbb E\big[\mathbb E_{i-1}[H_{i-1}\Delta W_i]\big]\\ &=\mathbb E\big[H_{i-1}\,\mathbb E_{i-1}[\Delta W_i]\big]=0,\\ \mathbb E[I_n]&=0,\\ \mathbb E[W_i\Delta W_i]&=\mathbb E\big[(W_{i-1}+\Delta W_i)\Delta W_i\big]\\ &=0+\Delta t,\\ \mathbb E[R_n]&=n\,\Delta t=T. \end{aligned} \]

หัวใจคือลำดับเวลา สถานะต้นท่อนรู้ค่าก่อนการขยับ และการขยับที่ยังไม่เกิดเฉลี่ยศูนย์ ผลคูณจึงเฉลี่ยศูนย์ทุกท่อน รวม $n$ ท่อนก็ยังเป็นศูนย์ เหตุผลนี้ไม่ได้ใช้สูตรของ $H$ เลย จึงใช้ได้กับทุก $H$ ที่ adapted ไม่ว่าจะซับซ้อนแค่ไหน

ถ้าอ่านที่ปลายท่อน สถานะ $W_i=W_{i-1}+\Delta W_i$ มีการขยับของท่อนนั้นปนอยู่ ผลคูณจึงมีก้อน $(\Delta W_i)^2$ ซึ่งเฉลี่ย $\Delta t$ เพราะนั่นคือ variance ของการขยับหนึ่งท่อน รวม $n$ ท่อนได้ $n\,\Delta t=T$ ตรงกับส่วนต่าง $Q_n$ ในขั้นที่ 3

ผลนี้บอกว่า Itô integral เป็น martingale แปลว่าบนตลาดที่ไม่มี edge ไม่มีกฎการเทรดที่ทำได้จริงกฎใดทำกำไรเฉลี่ยได้ เป็นเหตุผลเดียวกับที่ ระบบเดิมพันแบบ martingale เพิ่มเงินเดิมพันอย่างไรก็เอาชนะเกมที่ยุติธรรมไม่ได้

ขั้นที่ 6 — ความเสี่ยงของกำไรสะสม: พิสูจน์ Itô isometry

ค่าเฉลี่ยศูนย์ยังไม่บอกว่ากำไรกระจายกว้างแค่ไหน ทีมเทรดต้องรู้ด้วยว่าปีหนึ่งกำไรแกว่งได้เท่าไร ตัววัดคือ variance และเมื่อค่าเฉลี่ยเป็นศูนย์ variance ก็คือ $\mathbb E[I_n^2]$

วิธีคือกระจายกำลังสองของผลรวม เหมือน $(a+b)^2=a^2+b^2+2ab$ จะได้พจน์ของท่อนเดียวกัน (ยกกำลังสอง) กับพจน์ไขว้ของคนละท่อน แล้วใช้เหตุผล “ถือก่อน ขยับทีหลัง” กับทีละพจน์

\[ \begin{aligned} I_n^2&=\textstyle\sum_iH_{i-1}^2(\Delta W_i)^2\\ &\quad+2\textstyle\sum_{i\lt j}H_{i-1}H_{j-1}\Delta W_i\,\Delta W_j,\\ \mathbb E[H_{i-1}H_{j-1}\Delta W_i\Delta W_j]&=\mathbb E\big[H_{i-1}H_{j-1}\Delta W_i\,\mathbb E_{j-1}[\Delta W_j]\big]\\ &=0,\\ \mathbb E[H_{i-1}^2(\Delta W_i)^2]&=\mathbb E[H_{i-1}^2]\,\Delta t,\\ \mathbb E[I_n^2]&=\textstyle\sum_i\mathbb E[H_{i-1}^2]\,\Delta t\\ &\to\int_0^T\mathbb E[H_t^2]\,dt. \end{aligned} \]

พจน์ไขว้คือคู่ของท่อน $i$ กับท่อน $j$ ที่ $i$ มาก่อน $j$ ยืนที่ต้นท่อน $j$ ทุกตัวในผลคูณรู้ค่าแล้ว ยกเว้น $\Delta W_j$ ซึ่งเฉลี่ยศูนย์ พจน์ไขว้จึงหายทุกคู่ นี่คือเหตุผล “ถือก่อน ขยับทีหลัง” ทำงานอีกรอบ

พจน์ของท่อนเดียวเหลือกำลังสองของสถานะคูณ $(\Delta W_i)^2$ การขยับที่ยังไม่เกิดเป็นอิสระจาก $H_{i-1}$ ที่ตั้งไว้แล้ว ค่าเฉลี่ยจึงแยกคูณกันได้เป็น $\mathbb E[H_{i-1}^2]\times\Delta t$ รวมทุกท่อนเป็นผลรวมแบบ Riemann ซึ่งเข้าหา integral ตามเวลาเมื่อซอยถี่

ผลนี้คือเครื่องมือหาความเสี่ยงของกลยุทธ์ก่อนรันจำลอง รู้แค่ว่าสถานะยกกำลังสองเฉลี่ยเท่าไรในแต่ละช่วงเวลา ก็ได้ variance ของกำไรทั้งปี เป็นพื้นที่ใต้กราฟของ $\mathbb E[H_t^2]$ ตามรูปด้านล่าง

ขั้นที่ 7 — H = W: คำตอบปิด ความเสี่ยงสองทาง และรูปร่างที่ไม่สมมาตร

ตอนนี้กลับมาที่กลยุทธ์ของโจทย์ $H=W$ บนหนึ่งปี ($T=1$) ขั้นนี้หาสามอย่าง คือสูตรปิดของกำไร ความเสี่ยงของกำไร (คิดสองทางให้ตรวจกันเอง) และรูปร่างของการกระจาย

สูตรปิดมาจากขั้นที่ 3 ตรง ๆ: $I_n=\tfrac12(W_T^2-Q_n)$ และ $Q_n\to T$ ผลเดียวกันได้จาก Itô's lemma ด้วย $f(x)=x^2$ ซึ่งให้ $d(W^2)=dt+2W\,dW$ integrate สองข้างจาก 0 ถึง $T$ ได้ $W_T^2=T+2\int_0^TW\,dW$ ส่วนความเสี่ยง ทางแรกใช้ isometry กับ $\mathbb E[W_t^2]=t$ ทางที่สองคิดตรงจากสูตรปิด โดยเขียน $W_1=Z$ ซึ่งเป็น Normal มาตรฐาน

\[ \begin{aligned} \int_0^TW_t\,dW_t&=\tfrac12\big(W_T^2-T\big),\\ \operatorname{Var}&=\int_0^Tt\,dt=\tfrac12T^2=0.5,\\ \operatorname{Var}\big(\tfrac12(Z^2-1)\big)&=\tfrac14\operatorname{Var}(Z^2)\\ &=\tfrac14\big(\mathbb E[Z^4]-1\big)=\tfrac14(3-1)=0.5,\\ \operatorname{SD}&=\sqrt{0.5}=0.7071,\\ \operatorname{Var}_{252}&=\textstyle\sum_{i=1}^{252}(i-1)\Delta t\cdot\Delta t\\ &=\dfrac{251\times252}{2\times252^2}=\dfrac{251}{504}\\ &=0.49802,\\ \operatorname{SD}_{252}&=\sqrt{0.49802}=0.7057,\\ P(I\lt0)&=P(Z^2\lt1)\\ &=P(|Z|\lt1)=0.6827,\\ \operatorname{Med}(I)&=\tfrac12(0.454936-1)\\ &=-0.272532. \end{aligned} \]

สองทางให้ variance 0.5 ตรงกัน ทางที่สองใช้ $\operatorname{Var}(Z^2)=\mathbb E[Z^4]-(\mathbb E[Z^2])^2=3-1$ โดย $\mathbb E[Z^4]=3$ มาจาก สมบัติของเส้นทาง Brownian

ถ้าปรับสถานะวันละครั้ง ตารางเวลามี 252 ท่อน (จำนวนวันทำการของตลาดหุ้นสหรัฐในหนึ่งปี) และท่อนที่ $i$ มี $\mathbb E[W_{t_{i-1}}^2]=(i-1)\Delta t$ ผลรวมจึงเป็น $\Delta t^2(0+1+\dots+251)$ ได้ 0.49802 ต่ำกว่า 0.5 นิดหนึ่ง เพราะแต่ละวันถือสถานะเก่าจากต้นวัน และวันแรกเริ่มที่ $W=0$ จึงถือ 0 หน่วย

รูปร่างของกำไรไม่สมมาตร ค่าเฉลี่ยเป็นศูนย์ แต่ $I=\tfrac12(W_T^2-T)$ ต่ำสุดได้แค่ $-\tfrac12T$ (เมื่อ $W_T=0$) ขณะที่ด้านบนไม่มีเพดาน ผลคือขาดทุนเล็ก ๆ บ่อย และกำไรก้อนใหญ่นาน ๆ ครั้ง กำไรติดลบเมื่อ $Z^2\lt1$ คือ $|Z|\lt1$ ซึ่งตาราง Normal บอกว่าเกิด 68.27% ของเส้นทาง

median (ค่าตรงกลางเมื่อเรียงทุกเส้นทางจากน้อยไปมาก) จึงติดลบ หาได้จาก median ของ $Z^2$: จุดที่ $P(|Z|\lt z)=0.5$ คือ $z=0.674490$ median ของ $Z^2$ จึงเป็น $0.674490^2=0.454936$ แทนลงใน $\tfrac12(Z^2-1)$ ได้ median ของกำไร −0.2725 หน่วยกำไร

ขั้นที่ 8 — คำตอบของโจทย์ backtest เป็นดอลลาร์

ตอนนี้แปลงทุกอย่างกลับเป็นดอลลาร์ เพื่อตอบโจทย์ backtest ตรง ๆ

โจทย์ให้อะไรมาบ้าง:

  • ราคาในตลาดทดสอบเดินแบบ Brownian motion แบบบวก คือขยับเป็นดอลลาร์ ไม่ใช่เป็นเปอร์เซ็นต์ และไม่มี drift: $S_t=520+0.18\times520\,W_t=520+93.6\,W_t$
  • การขยับของราคาในหนึ่งวันจึงเป็น $\Delta S=93.6\,\Delta W$
  • จำนวนหุ้นที่ถือ $H=100\,(S-520)=100\times93.6\,W=9{,}360\,W$ หุ้น
  • กำไรของแต่ละวันคือจำนวนหุ้นที่ถือคูณ $\Delta S$

ทั้งจำนวนหุ้นและการขยับเป็น $W$ คูณค่าคงที่ กำไรทั้งปีจึงเป็นผลรวมแบบต้นท่อน (หรือปลายท่อน) ของ $W$ คูณค่าคงที่ตัวเดียว ค่าคงที่นั้นคือขนาดของ 1 หน่วยกำไรเป็นดอลลาร์

\[ \begin{aligned} \text{P\&L}&=\textstyle\sum_i100(93.6\,W_{i-1})(93.6\,\Delta W_i)\\ &=100\times93.6^2\times I_n=876{,}096\,I_n,\\ \mathbb E[\text{P\&L}]&=0,\\ \operatorname{SD}&=876{,}096\times\sqrt{251/504}\\ &=618{,}263,\\ \operatorname{Med}&=876{,}096\times(-0.272532)\\ &=-238{,}764,\\ \mathbb E[876{,}096\,R_n]&=876{,}096\,T. \end{aligned} \]

คำตอบ: โค้ดที่ถูกต้องให้กำไรเฉลี่ย \$0 และ SD \$618,263 ต่อปี ถ้าปรับสถานะต่อเนื่องแทนวันละครั้ง SD จะเป็น $876{,}096\times0.7071=\$619{,}493$ median ของกำไรคือ −\$238,764 และขาดทุนใน 68.3% ของเส้นทาง

ขาดทุนมากที่สุดเท่าไร? เพราะ $I_n=\tfrac12(W_T^2-Q_n)\ge-\tfrac12Q_n$ และ $Q_n$ อยู่ราว 1 ขาดทุนสูงสุดจึงราว $\tfrac12\times876{,}096=\$438{,}048$

โค้ดที่เลื่อนดัชนีได้ $876{,}096\,R_n$ ซึ่งเฉลี่ย $876{,}096\times1=\$876{,}096$ ต่อปี ตัวเลข \$874,000 ที่โค้ดรายงานคือค่านี้บวกความคลาดจากการสุ่ม (ขั้นถัดไปตรวจให้ดู) และกำไรปลอมเป็นบวกทุกเส้นทาง เพราะ $R_n=\tfrac12(W_T^2+Q_n)$

ตรวจเองใน 10 วินาที: $\sigma S_0=0.18\times520=93.6$ และ $100\times93.6^2=100\times8{,}760.96=876{,}096$

ตัวเลขทั้งหมดที่ผ่านมาได้จากสูตร ขั้นนี้ตรวจสูตรด้วยการสุ่มจริง แบบเดียวกับที่ทีมรัน backtest ในโจทย์

โจทย์ให้อะไรมาบ้าง: โค้ดท้ายหน้าสร้าง 20,000 เส้นทาง แต่ละเส้นยาวหนึ่งปี แบ่ง 252 ท่อน ท่อนละหนึ่งวันทำการ ใช้ seed 133 (ตัวเลขตั้งต้นของเครื่องสุ่ม ทำให้รันซ้ำได้ผลเดิม) แล้วคิดทั้ง $I_{252}$ และ $R_{252}$ บนเส้นทางเดียวกัน ตัวเลขในตารางเป็นหน่วยกำไร คูณ \$876,096 ได้ดอลลาร์

ค่าเฉลี่ยจากการสุ่มคลาดจากทฤษฎีได้เสมอ ขนาดความคลาดปกติวัดด้วย SE (standard error) ของค่าเฉลี่ย ซึ่งเท่ากับ SD หารด้วยรากของจำนวนเส้นทาง

\[ \begin{aligned} \text{SE}_I&=\sqrt{0.49802/20{,}000}=0.00499,\\ \operatorname{Var}(Q_{252})&=252\times2\,\Delta t^2=2/252,\\ \text{SE}_R&=\sqrt{(0.49802+2/252)/20{,}000}\\ &=0.00503. \end{aligned} \]

ขั้นที่ 10 — ตัวคูณที่เป็นเวลาล้วน: ส่วนต่างหายไป

ส่วนต่าง $Q_n$ มาจากไหนกันแน่? ส่วนต่างทั่วไปคือ $R_n-I_n=\sum_i(H_i-H_{i-1})\,\Delta W_i$ มันจึงขึ้นกับว่าสถานะขยับในท่อนเดียวกันมากแค่ไหน และขยับไปทางเดียวกับ $W$ หรือเปล่า วิธีทดสอบคือลองสถานะที่ขยับตามเวลาอย่างเดียว $H_t=t$ คือถือเพิ่มขึ้นทีละน้อยตามปฏิทินโดยไม่สนราคา บนเส้นทางสี่ก้าวเดิม แล้วหาความเสี่ยงด้วย isometry

\[ \begin{aligned} I_4&=0(0.5)+0.25(-0.5)\\ &\quad+0.5(0.5)+0.75(0.5)=0.5,\\ R_4&=0.25(0.5)+0.5(-0.5)\\ &\quad+0.75(0.5)+1(0.5)=0.75,\\ R_n-I_n&=\textstyle\sum_i\Delta t\,\Delta W_i=\Delta t\,W_T\to0,\\ \operatorname{Var}\Big(\int_0^1t\,dW_t\Big)&=\int_0^1t^2\,dt=\tfrac13,\\ \operatorname{Var}_n&=\textstyle\sum_{k=0}^{n-1}(k\,\Delta t)^2\,\Delta t,\\ n=4&:\ \tfrac{0+1+4+9}{4^3}=0.21875,\\ n=8&:\ \tfrac{140}{8^3}=0.2734,\\ n=64&:\ \tfrac{85{,}344}{64^3}=0.3256. \end{aligned} \]

บนเส้นทางสี่ก้าว สองแบบต่างกัน $0.75-0.5=0.25$ เท่ากับ $\Delta t\,W_T=0.25\times1$ พอดี เหตุผลคือสถานะ $t$ เพิ่มขึ้นท่อนละ $\Delta t$ เท่ากันทุกท่อน จึงดึง $\Delta t$ ออกนอกผลรวมได้ เหลือผลรวมของการขยับ ซึ่งคือ $W_T$

ส่วนต่าง $\Delta t\,W_T$ มี SD เท่ากับ $\Delta t\sqrt T=\Delta t$ บนตารางรายวันเหลือ $1/252=0.00397$ และหายไปเมื่อซอยถี่ ต่างจาก $H=W$ ที่ส่วนต่างเข้าหา $T$ ข้อสรุปคือ Itô correction ไม่ได้มาจากการที่สถานะเปลี่ยนค่า แต่มาจากการที่สถานะขยับไปพร้อมกับ $W$ ในท่อนเดียวกัน คือมีส่วน $dW$ ของตัวเอง

ผลรวม $\operatorname{Var}_n$ คือ variance ของกลยุทธ์ที่ปรับสถานะแค่ $n$ ครั้งต่อปี ระหว่างนั้นถือสถานะเก่าซึ่งเล็กกว่า $t$ ความเสี่ยงจึงต่ำกว่าแบบปรับต่อเนื่อง ถ้าใช้ตารางหยาบประมาณความเสี่ยงของกลยุทธ์ที่ปรับต่อเนื่อง จะได้ต่ำเกินไป เช่น 4 ท่อนได้ $0.21875\div\tfrac13=0.656$ คือราว 66% ของค่าจริง

ขั้นที่ 11 — งานจริง: P&L ของการ hedge คือ Itô integral

ขั้นสุดท้ายแสดงว่า Itô integral ไม่ได้มีแค่ใน backtest มันคือกำไรขาดทุนของงาน hedge ที่โต๊ะเทรด option ทำทุกวัน

ฉากเป็นแบบนี้ โต๊ะเทรดขาย option ให้ลูกค้า (option คือสัญญาที่ให้สิทธิ์ซื้อหรือขายหุ้นในราคาที่ตกลงไว้ล่วงหน้า) เมื่อราคาหุ้นขยับ มูลค่าของ option ที่ขายไปก็ขยับตาม โต๊ะจึงถือหุ้นไว้จำนวนหนึ่ง ให้กำไรขาดทุนของหุ้นหักล้างกับของ option การถือแบบนี้เรียกว่า hedge จำนวนหุ้นต่อ option หนึ่งสัญญาเรียกว่า delta เขียนว่า $\Delta$ และโต๊ะต้องตั้งจำนวนนี้ตอนเช้า ก่อนราคาวันนั้นขยับ

โจทย์ให้อะไรมาบ้าง: (ตัวเลขสมมติ ไม่คิดดอกเบี้ย)

  • สี่วัน โต๊ะตั้ง $\Delta=0.50,\ 0.60,\ 0.40,\ 0.55$ หุ้นต่อ option ตามลำดับ
  • ราคาหุ้นในสี่วันนั้นขยับ $\Delta S=+\$1.0,\ -\$2.0,\ +\$1.5,\ +\$0.5$ ตามลำดับ
  • กำไรของหุ้นที่ถือในวันที่ $i$ คือ delta ที่ตั้งตอนเช้าคูณการขยับของวันนั้น $\Delta_{i-1}\,\Delta S_i$ (ระวังสัญลักษณ์: $\Delta$ ตัวเดียวคือ delta ส่วน $\Delta S$ คือการขยับของราคา)
\[ \begin{aligned} \text{hedge P\&L}&=\textstyle\sum_i\Delta_{i-1}\,\Delta S_i\approx\int_0^T\Delta_t\,dS_t,\\ &=0.50(1.0)+0.60(-2.0)\\ &\quad+0.40(1.5)+0.55(0.5)\\ &=0.5-1.2+0.6+0.275=0.175. \end{aligned} \]

คำตอบ: หุ้นที่ถือทำกำไร \$0.175 ต่อ option ในสี่วัน ผลรวมนี้คือ Itô integral ที่ซอยรายวัน เพราะ $\Delta$ ตั้งจากข้อมูลตอนเช้าก่อนราคาขยับ แบบจำลอง Black–Scholes สมมติว่าเทรดได้ต่อเนื่องโดยไม่มีต้นทุน แล้วเลือก $\Delta$ ให้กำไรก้อนนี้หักล้างการขยับของมูลค่า option พอดี ส่วนหน้า P&L ของการ delta hedge จะวัดว่าการปรับวันละครั้งแทนการปรับต่อเนื่องทิ้งความคลาดไว้เท่าไร

ตรวจเองใน 10 วินาที: วันที่สองถือมากที่สุด 0.60 หุ้น และราคาลงแรงที่สุด จึงเป็นวันที่เสียมากที่สุด $0.60\times(-2.0)=-\$1.20$ ถ้าโค้ดใช้ $\Delta$ ตอนเย็นแทน ผลจะมีข้อมูลของวันนั้นปนเข้ามา แบบเดียวกับการเลื่อนดัชนี

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

เลื่อนดัชนีผิดหนึ่งช่อง: โค้ดเอาสัญญาณของวันไปคูณผลตอบแทนของวันเดียวกัน แทนที่จะเป็นวันถัดไป ในโจทย์ backtest ตัวเลขผิดคือกำไรเฉลี่ย $100\times93.6^2\times1=\$876{,}096$ ต่อปี ตัวเลขถูกคือ \$0 สูตรของกำไรปลอมคือ 100 คูณ $(\sigma S_0)^2$ คูณเวลา ไม่มีจำนวนครั้งที่ปรับสถานะอยู่ในสูตร มันจึงไม่หดเมื่อปรับห่างขึ้น (โจทย์ข้อ 1) สัญญาณที่จับได้ทันทีคือไม่มีเส้นทางไหนขาดทุน วิธีแก้คือเลื่อนสัญญาณลงหนึ่งแถวก่อนคูณผลตอบแทน แล้วรันซ้ำบนตลาดทดสอบ

คิดว่าค่าเฉลี่ยศูนย์แปลว่าสมมาตร: ถ้ารายงานแค่ค่าเฉลี่ย \$0 กับ SD \$618,263 ผู้อ่านจะนึกภาพระฆังที่ median เป็น \$0 และขาดทุนครึ่งหนึ่งของเวลา ตัวเลขจริงคือ median $876{,}096\times(-0.272532)=-\$238{,}764$ และขาดทุนใน 68.3% ของเส้นทาง เพราะขาดทุนถูกจำกัดไว้ที่ราว \$438,048 แต่กำไรไม่มีเพดาน

ใช้ calculus ปกติกับ $\int W\,dW$: สูตร $\int x\,dx=\tfrac12x^2$ ให้ $\tfrac12W_T^2$ ซึ่งเฉลี่ย $\tfrac12T$ แปลเป็นกำไรเฉลี่ย $\tfrac12\times876{,}096=\$438{,}048$ ต่อปีจากตลาดที่ไม่มี edge ตัวเลขถูกคือ $\tfrac12(W_T^2-T)$ ซึ่งเฉลี่ย \$0 พจน์ $-\tfrac12T$ ที่หายไปคือ Itô correction

ใช้ทำอะไรบนโต๊ะจริง

กำไรขาดทุน (P&L) ของทุกกลยุทธ์ที่ปรับสถานะตามสัญญาณ คือ Itô integral บนตารางเวลาของมัน การตรวจ backtest ขั้นแรกจึงเป็นการรันบนตลาดสุ่มที่ไม่มี edge แล้วดูสองอย่าง ค่าเฉลี่ยต้องห่างจากศูนย์ไม่กี่ SE และต้องมีเส้นทางที่ขาดทุน

ระวังเรื่องเวลาของข้อมูลด้วย ราคาปิดรู้ได้หลังตลาดปิดเท่านั้น การใช้ราคาปิดของวันหนึ่งไปตั้งสถานะที่กินกำไรจากราคาปิดเดียวกัน คือการเลื่อนดัชนีแบบเดียวกับในหน้านี้

ผลรวมในหน้านี้ยังไม่หักต้นทุน ทุกครั้งที่ปรับสถานะต้องเสีย spread (ส่วนต่างระหว่างราคาซื้อกับราคาขาย) และค่าธรรมเนียม คำสั่งใหญ่ยังดันราคาไปทางที่เสียเปรียบด้วย ในโจทย์นี้ เมื่อราคาอยู่เหนือ \$520 ไปหนึ่ง SD รายปี (\$93.6) กลยุทธ์ถือ $100\times93.6=9{,}360$ หุ้น ต้นทุนจากการดันราคาแบบนี้มีแบบจำลองชื่อ Almgren–Chriss กลยุทธ์ที่ปรับบ่อยจึงได้ผลต่ำกว่าผลรวมแบบไม่มีต้นทุน

isometry ใช้ประเมินความเสี่ยงของกลยุทธ์ก่อนรันจริง และใช้วัดกำไรขาดทุนของการ hedge ส่วนสมบัติค่าเฉลี่ยศูนย์เป็นแกนของ Girsanov และ risk-neutral measure ซึ่งเปลี่ยนโอกาสของเหตุการณ์ เพื่อให้ราคาที่ลดค่าด้วยดอกเบี้ยแล้วเป็น martingale

\[ \begin{aligned} \mathbb E[Q_{52}]&=52\times\tfrac1{52}=1,\\ \operatorname{Var}(Q_{52})&=52\times2\times\tfrac1{52^2}=\tfrac2{52},\\ \operatorname{SD}(Q_{52})&=\sqrt{2/52}=0.19612,\\ 876{,}096\,\operatorname{SD}(Q_{52})&=876{,}096\times0.19612\\ &=\$171{,}817. \end{aligned} \]

กำไรปลอมยังเฉลี่ย $876{,}096\times1=\$876{,}096$ เท่าเดิม และ SD ของมันคือ \$171,817 ปรับห่างขึ้นทำให้กำไรปลอมแกว่งมากขึ้น แต่ไม่ได้ทำให้มันเล็กลง

2. อีกกลยุทธ์หนึ่งถือ $H_t=W_t^2$ หน่วย คือถือเพิ่มเร็วขึ้นเมื่อราคาวิ่งไกลจากจุดเริ่ม (กลยุทธ์สมมติ) บนหนึ่งปี กำไร $\int_0^1W_t^2\,dW_t$ เฉลี่ยเท่าไร และ SD เท่าไร?

เฉลย

$W_t^2$ รู้ค่าได้ที่เวลา $t$ จึง adapted ค่าเฉลี่ยจึงเป็นศูนย์ เพราะถือก่อน ขยับทีหลัง ส่วน variance ใช้ isometry ซึ่งต้องรู้ $\mathbb E[H_t^2]=\mathbb E[W_t^4]$ โดยเขียน $W_t=\sqrt t\,Z$

\[ \begin{aligned} \mathbb E[W_t^4]&=t^2\,\mathbb E[Z^4]=3t^2,\\ \operatorname{Var}&=\int_0^13t^2\,dt=1,\\ \operatorname{SD}&=\sqrt1=1. \end{aligned} \]

SD เท่ากับ 1 หน่วยกำไร (เส้นส้มในรูปพื้นที่ใต้กราฟ) มากกว่ากรณี $H=W$ ที่ได้ 0.7071 เพราะสถานะโตเร็วกว่าเมื่อราคาวิ่งไกล

3. ในตลาดทดสอบเดิม กลยุทธ์ที่ง่ายที่สุดคือซื้อ 1,000 หุ้นแล้วถือคงที่ทั้งปี ไม่ปรับเลย กำไรทั้งปีมี SD เท่าไร และบั๊กเลื่อนดัชนีเปลี่ยนผลไหม?

เฉลย

แต่ละวันได้ $1{,}000\,\Delta S=1{,}000\times93.6\,\Delta W$ สถานะในหน่วยของ $W$ จึงคงที่ที่ $1{,}000\times93.6=93{,}600$

\[ \begin{aligned} \text{P\&L}&=93{,}600\,W_1,\\ \operatorname{Var}&=\int_0^193{,}600^2\,dt=93{,}600^2,\\ \operatorname{SD}&=\$93{,}600. \end{aligned} \]

บั๊กไม่เปลี่ยนอะไร เพราะสถานะที่ต้นท่อนกับปลายท่อนเท่ากัน ส่วนต่าง $\sum_i(H_i-H_{i-1})\,\Delta W_i$ จึงเป็นศูนย์ (สถานะไม่มีส่วน $dW$ ของตัวเอง) บั๊กเลื่อนดัชนีอันตรายเฉพาะกับสถานะที่ขยับตามราคา ซึ่งคือกลยุทธ์เกือบทุกตัว

// Left-point (Ito), right-point and midpoint sums of H dW along one path of levels W and a weight H.
function pathSums(H, W) {
  if (!Array.isArray(W) || W.length < 2 || H.length !== W.length) throw new TypeError('Need one weight per level and at least two levels');
  let left = 0, right = 0, mid = 0, Q = 0;
  for (let i = 1; i < W.length; i++) {
    const d = W[i] - W[i - 1];
    left += H[i - 1] * d; right += H[i] * d; mid += 0.5 * (H[i - 1] + H[i]) * d; Q += d * d;
  }
  return {left, right, mid, Q};
}
// Ito isometry on a grid: Var(sum H_(i-1) dW_i) = sum E[H_(i-1)^2] dt when H is known at the left end.
function isometry(meanSquare, T, n) {
  const dt = T / n;
  let v = 0;
  for (let i = 0; i < n; i++) v += meanSquare(i * dt) * dt;
  return v;
}
// mulberry32 + Box-Muller: seeded standard Normals, the same generator as the quadratic-variation page.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Backtest H = W on a no-edge market: the honest left-point P&L I and the one-row-shifted right-point P&L R.
function backtest(paths, steps, T, seed) {
  if (!Number.isInteger(paths) || paths < 2 || paths % 2 || !Number.isInteger(steps) || steps < 1) throw new RangeError('Need an even whole number of paths and whole steps');
  const z = normals(seed), sq = Math.sqrt(T / steps), I = new Float64Array(paths);
  let sI = 0, sI2 = 0, sR = 0, rightPositive = 0, leftNegative = 0, worstGap = 0, minR = Infinity;
  for (let p = 0; p < paths; p++) {
    let w = 0, left = 0, right = 0, Q = 0;
    for (let k = 0; k < steps; k++) {
      const d = sq * z();
      left += w * d; w += d; right += w * d; Q += d * d;
    }
    I[p] = left; sI += left; sI2 += left * left; sR += right;
    worstGap = Math.max(worstGap, Math.abs(right - left - Q)); minR = Math.min(minR, right);
    if (right > 0) rightPositive++;
    if (left < 0) leftNegative++;
  }
  I.sort();
  const meanI = sI / paths;
  return {meanI, sdI: Math.sqrt((sI2 - paths * meanI * meanI) / (paths - 1)), medianI: (I[paths / 2 - 1] + I[paths / 2]) / 2,
    meanR: sR / paths, worstGap, minR, rightPositive: rightPositive / paths, leftNegative: leftNegative / paths};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • Itô integral $\int H\,dW$ คือขีดจำกัดของ $\sum H_{i-1}\Delta W_i$ ที่อ่านสถานะที่ต้นท่อน ตรงกับการเทรดจริงที่ตั้งสถานะก่อนราคาขยับ และเป็นความหมายของพจน์ $\int b\,dW$ ใน SDE
  • ถ้าอ่านที่ปลายท่อนแทน จะได้กำไรเกินมา $Q_n$ พอดี กำไรปลอมนี้เฉลี่ย $T$ และทำให้ผลเป็นบวกทุกเส้นทาง ในโจทย์ backtest คือ $100\times93.6^2=\$876{,}096$ ต่อปี
  • ค่าเฉลี่ยเป็นศูนย์เพราะถือก่อน ขยับทีหลัง และ variance คือ $\int\mathbb E[H_t^2]\,dt$ (isometry) ซึ่งเป็นพื้นที่ใต้กราฟของ $\mathbb E[H_t^2]$
  • $\int_0^TW\,dW=\tfrac12(W_T^2-T)$: เมื่อ $T=1$ เฉลี่ยศูนย์ SD $\sqrt{0.5}=0.7071$ แต่ขาดทุนใน 68.27% ของเส้นทาง เพราะขาดทุนมีพื้นอยู่ที่ $-\tfrac12T$ ส่วนกำไรไม่มีเพดาน
  • ส่วนต่างระหว่างต้นท่อนกับปลายท่อนเกิดเฉพาะเมื่อสถานะขยับไปพร้อมกับ $W$ (มีส่วน $dW$ ของตัวเอง) สถานะที่ขยับตามเวลาล้วน หรือคงที่ ไม่มีส่วนต่าง

หน้าถัดไป การแก้ SDE: GBM, Vasicek และ CIR ใช้ Itô integral กับ Itô's lemma แก้ SDE จริงสามตัว คือ GBM ซึ่งเป็นแบบจำลองของราคาหุ้น และ Vasicek กับ CIR ซึ่งเป็นแบบจำลองของอัตราดอกเบี้ย
