13.3 The Itô Integral

Itô integral คือกำไรสะสมของการถือสถานะที่ตั้งก่อนราคาขยับ และถ้าเผลออ่านสถานะที่ปลายท่อน จะได้กำไรปลอมเท่ากับผลรวมกำลังสองของการขยับ ซึ่งเฉลี่ยเท่ากับเวลาที่ผ่านไป

ทีม quant ทดสอบโค้ด backtest กับตลาดปลอมที่รู้แน่ว่าไม่มี edge: ราคา SPY เริ่มที่ \$520 และขยับแบบ Brownian motion ไม่มี drift ด้วยความผันผวน \$93.60 ต่อ $\sqrt{\text{yr}}$ (18% ของ \$520) กลยุทธ์ momentum ถือ 100 หุ้นต่อทุก \$1 ที่ราคาอยู่เหนือ \$520 (ต่ำกว่าก็ short) ปรับทุกวัน รันหนึ่งปี 20,000 เส้นทาง โค้ดรายงานว่ากำไรเฉลี่ย \$876,096 ต่อปี และไม่มีเส้นทางไหนขาดทุนเลย กลยุทธ์นี้ดีจริงไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ ตลาดนี้ไม่มี edge กลยุทธ์ที่ทำได้จริงต้องได้เฉลี่ย \$0 โค้ดตั้งสถานะด้วยราคาปิดของวันเดียวกับที่คิดกำไร คือรู้ผลก่อนถือ กำไรปลอมเท่ากับ 100 คูณผลรวมของ $(\Delta S)^2$ ซึ่งเฉลี่ย $100\times93.6^2=\$876{,}096$ พอดี และเพราะเป็นผลรวมกำลังสองจึงบวกทุกเส้นทาง ส่วนกลยุทธ์ที่ถูกต้องเฉลี่ย \$0 แต่ขาดทุนใน 68% ของเส้นทาง

ภาพรวมก่อนลงสูตร

กำไรของกลยุทธ์ใดก็ตามคือผลรวมของ “สถานะที่ถือ คูณการขยับของราคา” ทุกท่อนเวลา คำถามเดียวของหน้านี้คือ สถานะนั้นอ่านค่าตอนไหน ใน calculus ปกติจะอ่านที่ต้นท่อน ปลายท่อน หรือกลางท่อน ก็ได้คำตอบเดียวกันเมื่อซอยละเอียด แต่บนเส้นทาง Brownian ผลรวมกำลังสองของการขยับไม่หาย (quadratic variation เท่ากับเวลาที่ผ่านไป) จุดที่อ่านจึงเปลี่ยนคำตอบไปเท่ากับเวลาพอดี

Itô integral เลือกต้นท่อน เพราะเป็นทางเดียวที่ตรงกับการเทรดจริง: ตั้งสถานะก่อน ราคาค่อยขยับ รูปด้านล่างลงบัญชีเส้นทางสี่ก้าวเส้นเดียวกันสองแบบ แบบต้นท่อน (เขียว) ได้กำไรรวม 0 แบบปลายท่อน (แดง) ได้ 1.0 ทั้งที่ตลาดเป็นตลาดเดียวกัน

หน้านี้จะวัดส่วนต่างนั้นแบบทั่วไป นิยาม Itô integral ให้ความหมายกับ $\int b\,dW$ ใน SDE ทุกตัวของ Itô's lemma พิสูจน์สองสมบัติที่ใช้ตลอดบท คือค่าเฉลี่ยเป็นศูนย์ และความเสี่ยงหาได้จาก Itô isometry แล้วตอบโจทย์ backtest เป็นดอลลาร์ และจบที่ P&L ของการ hedge

ขั้นที่ 1 — สี่ก้าวด้วยมือ: ตั้งสถานะก่อน ราคาค่อยขยับ

โจทย์ให้อะไรมาบ้าง: หนึ่งปีซอยสี่ไตรมาส $\Delta t=0.25$ ใช้เส้นทางแบบโยนเหรียญที่แต่ละก้าวขึ้นหรือลง $\sqrt{0.25}=0.5$ ได้ $W$ เป็น 0, 0.5, 0, 0.5, 1.0 (เส้นทางในรูปด้านบน) กลยุทธ์ถือ $H=W$ หน่วย ตั้งที่ต้นแต่ละไตรมาส แล้วรับกำไรเท่ากับสถานะคูณการขยับของไตรมาสนั้น

\[ \begin{aligned} H_{i-1}=W_{i-1}&:\ 0,\ 0.5,\ 0,\ 0.5,\\ \Delta W_i&:\ +0.5,\ -0.5,\ +0.5,\ +0.5,\\ I_4&=0(0.5)+0.5(-0.5)\\ &\quad+0(0.5)+0.5(0.5)=0. \end{aligned} \]

คำตอบ: กำไรสะสม 0 ไตรมาสที่สองถือ 0.5 หน่วยแล้วราคาลงจึงเสีย 0.25 ไตรมาสที่สี่ถือ 0.5 แล้วราคาขึ้นจึงได้ 0.25 ตัวคูณทุกตัวรู้ค่าแล้วก่อนการขยับที่มันคูณ นี่คือสิ่งที่ทำได้จริงในตลาด

ตรวจเองใน 10 วินาที: ไตรมาสแรกและไตรมาสที่สามเริ่มที่ $W=0$ จึงถือศูนย์หน่วย ได้กำไรศูนย์ไม่ว่าราคาจะไปทางไหน เหลือแค่สองไตรมาสที่หักกันพอดี

ขั้นที่ 2 — เลื่อนดัชนีหนึ่งช่อง: กำไรปลอมโผล่มา

โจทย์ให้อะไรมาบ้าง: เส้นทางเดิม แต่โค้ดเผลอใช้สถานะ $W_i$ ที่ปลายไตรมาสคูณการขยับของไตรมาสเดียวกัน ในตารางข้อมูลคือการคูณสัญญาณแถว $i$ กับผลตอบแทนแถว $i$ แทนที่จะคูณกับแถว $i+1$

\[ \begin{aligned} H_i=W_i&:\ 0.5,\ 0,\ 0.5,\ 1.0,\\ R_4&=0.5(0.5)+0(-0.5)\\ &\quad+0.5(0.5)+1.0(0.5)=1.0. \end{aligned} \]

คำตอบ: ได้ 1.0 จากเส้นทางและตลาดเดียวกัน ไตรมาสที่สองแบบนี้ถือ 0 หน่วยพอดีตอนราคาลง ส่วนไตรมาสที่สี่ถือ 1.0 หน่วยตอนราคาขึ้น ทุกการตัดสินใจรู้ผลก่อนแล้ว

ตรวจเองใน 10 วินาที: $1.0-0=1.0$ เท่ากับ $4(0.5)^2$ คือผลรวมกำลังสองของสี่ก้าว ขั้นถัดไปแสดงว่าไม่ใช่เรื่องบังเอิญ

ขั้นที่ 3 — ส่วนต่างคือผลรวมกำลังสองพอดี ทุกเส้นทาง

ลบสองผลรวมกันแบบทั่วไปเพื่อดูว่าส่วนต่างขึ้นกับอะไร แล้วใช้ identity ที่เป็นจริงทุกเส้นทาง $W_T^2=\sum2W_{i-1}\Delta W_i+Q_n=2I_n+Q_n$ (ยกกำลังสองของ “ต้นท่อนบวกการขยับ” แล้วบวกทุกท่อน) เขียนทั้งสองผลรวมด้วย $W_T$ กับ $Q_n$

\[ \begin{aligned} R_n-I_n&=\textstyle\sum_i(W_i-W_{i-1})\,\Delta W_i\\ &=\textstyle\sum_i(\Delta W_i)^2=Q_n,\\ I_n&=\tfrac12\big(W_T^2-Q_n\big),\\ R_n&=\tfrac12\big(W_T^2+Q_n\big)\gt0,\\ I_4&=\tfrac12(1-1)=0,\\ R_4&=\tfrac12(1+1)=1. \end{aligned} \]

ระดับปลายท่อนลบระดับต้นท่อนคือการขยับของท่อนนั้นเอง ส่วนต่างจึงเป็นผลรวมกำลังสอง ซึ่งเฉลี่ย $T$ ทุกความละเอียดและไม่หายเมื่อซอยถี่ ใน calculus ปกติสองแบบนี้ให้คำตอบเดียวกัน กับเส้นทาง Brownian ต่างกัน $T$

บรรทัดที่สี่เป็นสัญญาณเตือนที่ดีที่สุด: ผลรวมแบบปลายท่อนเป็นบวกทุกเส้นทาง backtest ที่ไม่เคยขาดทุนในตลาดสุ่มคือ backtest ที่รู้อนาคต

ขั้นที่ 4 — นิยาม: Itô integral อ่านตัวคูณที่ต้นท่อนเสมอ

calculus ปกติเลือกจุดไหนในท่อนมาคูณก็ได้ขีดจำกัดเดียวกัน ส่วนต่าง $Q_n$ ที่เพิ่งได้บอกว่าที่นี่เลือกไม่ได้ จึงต้องประกาศเป็นนิยาม และเลือกต้นท่อนเพราะเป็นทางเดียวที่ตรงกับการเทรดจริง

\[ \begin{aligned} \int_0^TH_t\,dW_t&:=\lim_{n\to\infty}\textstyle\sum_{i=1}^nH_{t_{i-1}}\,\Delta W_i,\\ X_T&=X_0+\int_0^Ta\,dt+\int_0^Tb\,dW_t. \end{aligned} \]

บรรทัดแรกคือนิยาม เงื่อนไขคือ $H_{t_{i-1}}$ ต้องคำนวณได้จากข้อมูลถึง $t_{i-1}$ ตำราเรียกว่า adapted สี่ก้าวด้วยมือคือผลรวมนี้ที่ $n=4$ บรรทัดที่สองคือความหมายเต็มของ SDE: $dX=a\,dt+b\,dW$ เป็นตัวย่อของบรรทัดนี้ โดยพจน์แรกเป็น integral ปกติตามเวลา และพจน์ที่สองเป็น Itô integral

ทำไมไม่อ่านกลางท่อน? ใช้ค่าเฉลี่ยของต้นและปลายท่อน เส้นทางสี่ก้าวได้ $\tfrac12(0+1.0)=0.5=\tfrac12W_T^2$ ตรงกับ calculus ปกติพอดี นี่คือ Stratonovich integral แต่ค่าเฉลี่ยของมันคือ $\tfrac12T$ ไม่ใช่ศูนย์ เพราะต้องรู้การขยับครึ่งท่อนข้างหน้า ฟิสิกส์ใช้มันได้ แต่ไม่ใช่กำไรที่นักเทรดทำได้

ขีดจำกัดของผลรวมสุ่มหมายถึงระยะห่างกำลังสองเฉลี่ยเข้าหาศูนย์ ไม่ใช่ทุกเส้นทางลู่เข้าแบบตัวเลขธรรมดา รายละเอียดนี้ไม่เปลี่ยนการคำนวณใดในบทนี้

ขั้นที่ 5 — ทำไมค่าเฉลี่ยเป็นศูนย์: ถือก่อน ขยับทีหลัง

ดูทีละท่อน ใช้ tower property (ค่าเฉลี่ยของค่าเฉลี่ยแบบมีเงื่อนไขคือค่าเฉลี่ยเดิม) ให้มองจากต้นท่อนก่อน ที่ต้นท่อน $H_{i-1}$ รู้ค่าแล้วจึงดึงออกนอกค่าเฉลี่ยได้ ส่วน $\Delta W_i$ เฉลี่ยศูนย์ไม่ว่าอดีตเป็นอย่างไร เป็นเทคนิคเดียวกับที่ใช้หา ค่าเฉลี่ยของ $W_{t+s}W_s$

\[ \begin{aligned} \mathbb E[H_{i-1}\Delta W_i]&=\mathbb E\big[\mathbb E_{i-1}[H_{i-1}\Delta W_i]\big]\\ &=\mathbb E\big[H_{i-1}\,\mathbb E_{i-1}[\Delta W_i]\big]=0,\\ \mathbb E[I_n]&=0,\\ \mathbb E[W_i\Delta W_i]&=\mathbb E\big[(W_{i-1}+\Delta W_i)\Delta W_i\big]\\ &=0+\Delta t,\\ \mathbb E[R_n]&=n\,\Delta t=T. \end{aligned} \]

ถ้าอ่านที่ปลายท่อน ตัวคูณมีการขยับของท่อนนั้นปนอยู่ ผลคูณจึงมี $(\Delta W_i)^2$ ซึ่งเฉลี่ย $\Delta t$ รวม $n$ ท่อนได้ $T$ ตรงกับส่วนต่าง $Q_n$

ผลของบรรทัดแรกใช้ได้กับทุก $H$ ที่ adapted ไม่ว่าสูตรจะซับซ้อนแค่ไหน Itô integral จึงเป็น martingale: บนตลาดที่ไม่มี edge ไม่มีกฎการเทรดที่ทำได้จริงกฎใดทำกำไรเฉลี่ยได้ เป็นเหตุผลเดียวกับที่ ระบบเดิมพันแบบ martingale เพิ่มเงินเดิมพันอย่างไรก็เอาชนะเกมที่ยุติธรรมไม่ได้

ขั้นที่ 6 — ความเสี่ยงของกำไรสะสม: พิสูจน์ Itô isometry

ค่าเฉลี่ยศูนย์ยังไม่บอกว่ากำไรกระจายกว้างแค่ไหน กระจายกำลังสองของผลรวมเป็นพจน์ของท่อนเดียวกับพจน์ไขว้ แล้วใช้เหตุผล “ถือก่อน ขยับทีหลัง” กับทีละพจน์

\[ \begin{aligned} I_n^2&=\textstyle\sum_iH_{i-1}^2(\Delta W_i)^2\\ &\quad+2\textstyle\sum_{i\lt j}H_{i-1}H_{j-1}\Delta W_i\,\Delta W_j,\\ \mathbb E[H_{i-1}H_{j-1}\Delta W_i\Delta W_j]&=\mathbb E\big[H_{i-1}H_{j-1}\Delta W_i\,\mathbb E_{j-1}[\Delta W_j]\big]\\ &=0,\\ \mathbb E[H_{i-1}^2(\Delta W_i)^2]&=\mathbb E[H_{i-1}^2]\,\Delta t,\\ \mathbb E[I_n^2]&=\textstyle\sum_i\mathbb E[H_{i-1}^2]\,\Delta t\\ &\to\int_0^T\mathbb E[H_t^2]\,dt. \end{aligned} \]

พจน์ไขว้ของคู่ที่ $i$ มาก่อน $j$: มองจากต้นท่อน $j$ ทุกอย่างรู้แล้วยกเว้น $\Delta W_j$ ซึ่งเฉลี่ยศูนย์ พจน์ไขว้จึงหายทุกคู่ พจน์ของท่อนเดียวเหลือกำลังสองของสถานะคูณความยาวท่อน (ใช้ว่า $(\Delta W_i)^2$ อิสระจาก $H_{i-1}$ และเฉลี่ย $\Delta t$) รวมกันได้ integral ตามเวลา

ผลนี้คือเครื่องมือหาความเสี่ยงของกลยุทธ์ก่อนรันจำลอง: รู้แค่ว่าสถานะเฉลี่ยกำลังสองเท่าไรในแต่ละช่วง ก็ได้ variance ของกำไรทั้งปี เป็นพื้นที่ใต้กราฟ ตามรูปด้านล่าง

ขั้นที่ 7 — H = W: คำตอบปิด ความเสี่ยงสองทาง และรูปร่างที่ไม่สมมาตร

ผลรวมต้นท่อน $I_n=\tfrac12(W_T^2-Q_n)$ และ $Q_n\to T$ จึงได้คำตอบปิด เป็นผลเดียวกับที่ Itô's lemma ให้เมื่อใช้ $f=x^2$ กับ $W$: $d(W^2)=dt+2W\,dW$ แล้วหาความเสี่ยงด้วย isometry โดยใช้ $\mathbb E[W_t^2]=t$ เทียบกับทางตรง

\[ \begin{aligned} \int_0^TW_t\,dW_t&=\tfrac12\big(W_T^2-T\big),\\ \operatorname{Var}&=\int_0^Tt\,dt=\tfrac12T^2=0.5,\\ \operatorname{Var}\big(\tfrac12(W_1^2-1)\big)&=\tfrac14\big(\mathbb E[Z^4]-1\big)=\tfrac14(2)=0.5,\\ \operatorname{SD}&=\sqrt{0.5}=0.7071,\\ n=252&:\ \textstyle\sum_i(i-1)\Delta t\cdot\Delta t=\frac{251}{504},\\ \operatorname{SD}&=0.7057,\\ P(I\lt0)&=P(|Z|\lt1)=0.6827,\\ \operatorname{Med}(I)&=\tfrac12(0.454936-1)\\ &=-0.272532. \end{aligned} \]

สองทางได้ variance 0.5 ตรงกัน ($\mathbb E[Z^4]=3$ จาก สมบัติของเส้นทาง Brownian) บนตารางรายวันผลรวมหยุดที่ $251/504=0.49802$ เพราะท่อนแรกถือศูนย์หน่วย ค่าเฉลี่ยเป็นศูนย์ แต่ $I=\tfrac12(W_T^2-T)$ ต่ำสุดได้แค่ $-\tfrac12T$ ขณะที่ด้านบนไม่มีเพดาน

ผลคือขาดทุนเล็ก ๆ บ่อย (68.27% ของเส้นทาง เมื่อ $|Z|\lt1$) และกำไรก้อนใหญ่นาน ๆ ครั้ง median อยู่ที่ −0.2725 โดย 0.454936 คือ median ของ $Z^2$ (จุดที่ $P(|Z|\lt z)=0.5$ คือ $z=0.6745$ และ $0.6745^2=0.4549$)

ขั้นที่ 8 — คำตอบของโจทย์ backtest เป็นดอลลาร์

โจทย์ให้อะไรมาบ้าง: ตลาดทดสอบคือ Brownian motion แบบบวก ที่ไม่มี drift $S_t=520(1+0.18W_t)=520+93.6W_t$ สถานะ $H=100(S-520)=9{,}360\,W$ หุ้น กำไรของแต่ละวันคือสถานะคูณ $\Delta S=93.6\,\Delta W$ ทุกอย่างจึงเป็นผลรวมต้นท่อนกับปลายท่อนคูณค่าคงที่ตัวเดียว

\[ \begin{aligned} \text{P\&L}&=\textstyle\sum_i100(93.6\,W_{i-1})(93.6\,\Delta W_i)\\ &=100\times93.6^2\times I_n=876{,}096\,I_n,\\ \mathbb E[\text{P\&L}]&=0,\\ \operatorname{SD}&=876{,}096\times\sqrt{251/504}\\ &=618{,}263,\\ \operatorname{Med}&=876{,}096\times(-0.272532)\\ &=-238{,}764,\\ \mathbb E[876{,}096\,R_n]&=876{,}096\,T. \end{aligned} \]

คำตอบ: โค้ดที่ถูกต้องให้กำไรเฉลี่ย \$0 SD \$618,263 ต่อปี (\$619,493 ถ้าปรับต่อเนื่อง) median −\$238,764 และขาดทุนใน 68.3% ของเส้นทาง ขาดทุนมากที่สุดราว $\tfrac12Q_n$ หน่วย คือราว \$438,048 โค้ดที่เลื่อนดัชนีให้ \$876,096 พอดีตามที่รายงาน (บรรทัดสุดท้าย) และบวกทุกเส้นทางเพราะ $R_n=\tfrac12(W_T^2+Q_n)$

ตรวจเองใน 10 วินาที: $93.6^2=8{,}760.96$ คูณ 100 หุ้นต่อดอลลาร์ได้ 876,096 และ 93.6 คือ 18% ของ 520

ขั้นที่ 9 — ตรวจด้วยการสุ่ม: 20,000 เส้นทาง ท่อนละหนึ่งวันทำการ

โจทย์ให้อะไรมาบ้าง: โค้ดท้ายหน้าสร้าง 20,000 เส้นทางหนึ่งปี 252 ท่อน ด้วย seed 133 คิดทั้ง $I_{252}$ และ $R_{252}$ บนเส้นทางเดียวกัน ตัวเลขเป็นหน่วยความเสี่ยง คูณ \$876,096 ได้ดอลลาร์ SE ของค่าเฉลี่ย $I$ คือ $\sqrt{0.49802/20{,}000}=0.00499$ ของ $R$ ใช้ variance $0.49802+2/252$ เพราะ $R=I+Q$ และสองก้อนนี้ covariance เป็นศูนย์

ขั้นที่ 10 — ตัวคูณที่เป็นเวลาล้วน: ส่วนต่างหายไป

ส่วนต่าง $Q_n$ มาจากไหนกันแน่ ตัวคูณสุ่ม หรือตัวคูณที่ขยับไปพร้อมกับ $W$? ลองตัวคูณที่ขยับตามเวลาอย่างเดียว $H_t=t$ บนเส้นทางสี่ก้าวเดิม แล้วหาความเสี่ยงด้วย isometry

\[ \begin{aligned} I_4&=0(0.5)+0.25(-0.5)\\ &\quad+0.5(0.5)+0.75(0.5)=0.5,\\ R_4&=0.25(0.5)+0.5(-0.5)\\ &\quad+0.75(0.5)+1(0.5)=0.75,\\ R_n-I_n&=\textstyle\sum_i\Delta t\,\Delta W_i=\Delta t\,W_T\to0,\\ \operatorname{Var}\Big(\int_0^1t\,dW_t\Big)&=\int_0^1t^2\,dt=\tfrac13,\\ n=4,\ 8,\ 64&:\ 0.21875,\ 0.2734,\ 0.3256. \end{aligned} \]

ตัวคูณขยับท่อนละ $\Delta t$ เท่ากันทุกท่อน จึงดึงออกได้ เหลือผลรวมของการขยับซึ่งคือ $W_T$ ส่วนต่าง $\Delta t\,W_T$ มี SD $\Delta t$ รายวันเหลือ $1/252=0.00397$ แล้วหายไป Itô correction จึงไม่ได้มาจากความสุ่มของตัวคูณ แต่มาจากตัวคูณที่มีส่วน $dW$ ของตัวเอง

แถวสุดท้ายคือ $\sum t_{i-1}^2\Delta t$ ของกลยุทธ์ที่ปรับสถานะแค่ $n$ ครั้ง ซึ่งถือสถานะเก่าที่เล็กกว่า $t$ ตลอดท่อน ความเสี่ยงของมันจึงต่ำกว่าจริง ถ้าใช้ตารางหยาบประมาณความเสี่ยงของกลยุทธ์ที่ปรับต่อเนื่อง จะต่ำไป เช่น 4 ท่อนได้ 66% ของ $\tfrac13$

ขั้นที่ 11 — งานจริง: P&L ของการ hedge คือ Itô integral

โจทย์ให้อะไรมาบ้าง: โต๊ะที่ขาย option แล้วถือหุ้น $\Delta$ หุ้นต่อ option เพื่อหักล้าง ต้องตั้งจำนวนหุ้นตอนเช้าก่อนราคาวันนั้นขยับ สี่วันตั้ง $\Delta=0.50, 0.60, 0.40, 0.55$ และราคาขยับ $+\$1.0, -\$2.0, +\$1.5, +\$0.5$ (ตัวเลขสมมติ ไม่คิดดอกเบี้ย)

\[ \begin{aligned} \text{hedge P\&L}&=\textstyle\sum_i\Delta_{i-1}\,\Delta S_i\approx\int_0^T\Delta_t\,dS_t,\\ &=0.50(1.0)+0.60(-2.0)\\ &\quad+0.40(1.5)+0.55(0.5)\\ &=0.5-1.2+0.6+0.275=0.175. \end{aligned} \]

คำตอบ: หุ้นที่ถือทำกำไร \$0.175 ต่อ option ในสี่วัน นี่คือ Itô integral ที่ซอยรายวัน เพราะ $\Delta$ ตั้งจากข้อมูลตอนเช้า แบบจำลอง Black–Scholes สมมติว่าเทรดได้ต่อเนื่องโดยไม่มีต้นทุน แล้วเลือก $\Delta$ ให้กำไรก้อนนี้หักล้างการขยับของมูลค่า option พอดี ส่วน P&L ของการ delta hedge จะวัดว่าการปรับวันละครั้งแทนต่อเนื่องเหลือความคลาดเท่าไร

ตรวจเองใน 10 วินาที: วันที่สองถือมากที่สุด 0.60 หุ้นแล้วราคาลงแรงที่สุด จึงเป็นวันที่เสียมากที่สุด −\$1.20 ถ้าโค้ดใช้ $\Delta$ ตอนเย็นแทน ผลจะมีข้อมูลของวันนั้นปนเข้ามาแบบการเลื่อนดัชนี

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

เลื่อนดัชนีผิดหนึ่งช่อง: กลยุทธ์ในโจทย์ backtest แสดงกำไร \$876,096 ต่อปีจากตลาดที่ไม่มี edge ขนาดของกำไรปลอมคือสถานะคูณความแปรปรวนต่อปี จึงไม่หดเมื่อปรับห่างขึ้น (โจทย์ข้อ 1) สัญญาณที่จับได้ทันทีคือไม่มีเส้นทางไหนขาดทุน วิธีแก้คือเลื่อนสัญญาณลงหนึ่งแถวก่อนคูณผลตอบแทน แล้วรันซ้ำบนตลาดทดสอบ

คิดว่าค่าเฉลี่ยศูนย์แปลว่าสมมาตร: กลยุทธ์ที่ถูกต้องเฉลี่ย \$0 แต่ median −\$238,764 และขาดทุนใน 68.3% ของปี ถ้ารายงานแค่ค่าเฉลี่ยกับ SD ผู้อ่านจะนึกภาพระฆังซึ่งผิดรูป

ใช้ calculus ปกติกับ $\int W\,dW$: ได้ $\tfrac12W_T^2$ ซึ่งมีค่าเฉลี่ย $\tfrac12T$ แปลเป็นกำไรเฉลี่ย \$438,048 ต่อปีจากตลาดที่ไม่มี edge พจน์ $-\tfrac12T$ ที่หายไปคือ Itô correction

ใช้ทำอะไรบนโต๊ะจริง

ทุก P&L ของกลยุทธ์ที่ปรับสถานะตามสัญญาณคือ Itô integral บนตารางเวลาของมัน การตรวจ backtest ขั้นแรกจึงเป็นการรันบนตลาดสุ่มที่ไม่มี edge: ค่าเฉลี่ยต้องอยู่ในระยะ SE ของศูนย์ และต้องมีเส้นทางที่ขาดทุน ระวังเรื่องข้อมูลด้วย ราคาปิดมาหลังตลาดปิด การใช้ราคาปิดตั้งสถานะที่ราคาปิดเดียวกันคือการเลื่อนดัชนีแบบเดียวกับในหน้านี้

ผลรวมในหน้านี้ยังไม่หักต้นทุน ทุกครั้งที่ปรับสถานะเสีย spread และค่าธรรมเนียม และคำสั่งใหญ่อย่าง 9,360 หุ้นต่อ 1 SD ของราคาดันราคาเอง (Almgren–Chriss) กลยุทธ์ที่ปรับบ่อยจึงได้ผลต่ำกว่าผลรวมแบบไม่มีต้นทุน

isometry ใช้ประเมินความเสี่ยงก่อนรันจริง และใช้วัด P&L ของการ hedge ส่วนสมบัติค่าเฉลี่ยศูนย์เป็นแกนของ Girsanov และ risk-neutral measure ที่เปลี่ยนโอกาสเพื่อให้ราคาที่ลดค่าด้วยดอกเบี้ยเป็น martingale

เฉลย

กำไรปลอมคือ \$876,096 คูณ $Q_{52}$ และ $\mathbb E[Q_n]=T$ ทุก $n$ จึงยังเฉลี่ย \$876,096 เท่าเดิม SD ของ $Q_{52}$ คือ $\sqrt{2/52}=0.19612$ ได้ SD ของกำไรปลอม $876{,}096\times\sqrt{2/52}=\$171{,}817$ ปรับห่างขึ้นทำให้กำไรปลอมแกว่งมากขึ้น แต่ไม่ได้ทำให้มันเล็กลง

2. กลยุทธ์ถือ $H_t=W_t^2$ หน่วย หากำไรเฉลี่ยและ SD ของ $\int_0^1W_t^2\,dW_t$

เฉลย

$W_t^2$ รู้ค่าที่เวลา $t$ จึง adapted ค่าเฉลี่ยเป็นศูนย์เพราะถือก่อน ขยับทีหลัง isometry ต้องใช้ $\mathbb E[W_t^4]=3t^2$ ได้ variance $\int_0^13t^2\,dt=1$ (เส้นส้มในรูปพื้นที่) SD จึงเท่ากับ 1 หน่วยความเสี่ยง มากกว่ากรณี $H=W$ ที่ได้ 0.7071 เพราะสถานะโตเร็วกว่าเมื่อราคาวิ่งไกล

3. ในตลาดทดสอบ ถือ 1,000 หุ้นคงที่ทั้งปี กำไรมี SD เท่าไร และบั๊กเลื่อนดัชนีเปลี่ยนผลไหม?

รันใน Node.js ได้โดยไม่ต้องติดตั้งอะไร โค้ดคิดผลรวมต้นท่อน ปลายท่อน และกลางท่อนของเส้นทางสี่ก้าว คิด isometry บนตารางต่าง ๆ แล้วสุ่ม 20,000 เส้นทางด้วยเครื่องสุ่มที่มี seed เพื่อเทียบ backtest ที่ถูกกับที่เลื่อนดัชนี

// Left-point (Ito), right-point and midpoint sums of H dW along one path of levels W and a weight H.
function pathSums(H, W) {
  if (!Array.isArray(W) || W.length < 2 || H.length !== W.length) throw new TypeError('Need one weight per level and at least two levels');
  let left = 0, right = 0, mid = 0, Q = 0;
  for (let i = 1; i < W.length; i++) {
    const d = W[i] - W[i - 1];
    left += H[i - 1] * d; right += H[i] * d; mid += 0.5 * (H[i - 1] + H[i]) * d; Q += d * d;
  }
  return {left, right, mid, Q};
}
// Ito isometry on a grid: Var(sum H_(i-1) dW_i) = sum E[H_(i-1)^2] dt when H is known at the left end.
function isometry(meanSquare, T, n) {
  const dt = T / n;
  let v = 0;
  for (let i = 0; i < n; i++) v += meanSquare(i * dt) * dt;
  return v;
}
// mulberry32 + Box-Muller: seeded standard Normals, the same generator as the quadratic-variation page.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Backtest H = W on a no-edge market: the honest left-point P&L I and the one-row-shifted right-point P&L R.
function backtest(paths, steps, T, seed) {
  if (!Number.isInteger(paths) || paths < 2 || paths % 2 || !Number.isInteger(steps) || steps < 1) throw new RangeError('Need an even whole number of paths and whole steps');
  const z = normals(seed), sq = Math.sqrt(T / steps), I = new Float64Array(paths);
  let sI = 0, sI2 = 0, sR = 0, rightPositive = 0, leftNegative = 0, worstGap = 0, minR = Infinity;
  for (let p = 0; p < paths; p++) {
    let w = 0, left = 0, right = 0, Q = 0;
    for (let k = 0; k < steps; k++) {
      const d = sq * z();
      left += w * d; w += d; right += w * d; Q += d * d;
    }
    I[p] = left; sI += left; sI2 += left * left; sR += right;
    worstGap = Math.max(worstGap, Math.abs(right - left - Q)); minR = Math.min(minR, right);
    if (right > 0) rightPositive++;
    if (left < 0) leftNegative++;
  }
  I.sort();
  const meanI = sI / paths;
  return {meanI, sdI: Math.sqrt((sI2 - paths * meanI * meanI) / (paths - 1)), medianI: (I[paths / 2 - 1] + I[paths / 2]) / 2,
    meanR: sR / paths, worstGap, minR, rightPositive: rightPositive / paths, leftNegative: leftNegative / paths};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • Itô integral $\int H\,dW$ คือขีดจำกัดของ $\sum H_{i-1}\Delta W_i$ ที่อ่านสถานะที่ต้นท่อน และเป็นความหมายของ $\int b\,dW$ ใน SDE
  • อ่านที่ปลายท่อนแทนได้ส่วนต่าง $Q_n$ พอดี: กำไรปลอมเฉลี่ย $T$ และบวกทุกเส้นทาง ในโจทย์ backtest คือ \$876,096 ต่อปี
  • ค่าเฉลี่ยเป็นศูนย์เพราะถือก่อน ขยับทีหลัง และ variance คือ $\int\mathbb E[H_t^2]\,dt$ (isometry) ซึ่งเป็นพื้นที่ใต้กราฟ
  • $\int_0^TW\,dW=\tfrac12(W_T^2-T)$: เฉลี่ยศูนย์ SD 0.7071 แต่ขาดทุนใน 68.27% ของเส้นทาง
  • ส่วนต่างระหว่างต้นกับปลายท่อนเกิดเมื่อตัวคูณขยับไปพร้อมกับ $W$ เท่านั้น ตัวคูณที่เป็นเวลาล้วนไม่มีส่วนต่าง
