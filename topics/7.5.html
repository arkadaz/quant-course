7.5 Rank, Range, and Invertibility

range คือทุก output ที่ matrix ไปถึงได้ rank นับว่ามันไปได้กี่ทิศอิสระ และ matrix จัตุรัสกลับด้านได้ก็ต่อเมื่อไม่มีทิศไหนถูกบี้หายไป

ลูกค้ารายหนึ่งต้องจ่ายหนี้ \$10 ในปีหน้า ไม่ว่าเศรษฐกิจจะดีหรือแย่ เขาจึงขอให้ธนาคารจัดชุดสัญญาที่ให้เงิน \$10 พอดีในทุกกรณี ชุดสัญญาที่ถือรวมกันแบบนี้เรียกว่าพอร์ต

เพื่อให้เห็นภาพง่าย ๆ เราใช้ตลาดจำลองที่ปีหน้าเกิดได้แค่สองแบบ เรียกว่าสองสถานะ คือ “ตลาดขึ้น” กับ “ตลาดลง” สัญญาแต่ละตัวจ่ายเงินตอนปีหน้า เงินที่จ่ายเรียกว่า payoff และขึ้นกับว่าเกิดสถานะไหน เราเขียน payoff เป็นคู่ตัวเลข (เงินที่ได้เมื่อตลาดขึ้น, เงินที่ได้เมื่อตลาดลง)

ในตลาดมีสัญญาให้เลือกสามตัว payoff ทุกตัวเลขข้างล่างเป็นดอลลาร์ต่อสัญญาหนึ่งหน่วย

  • สัญญาแรกจ่าย $(1,2)$ คือได้ \$1 ถ้าตลาดขึ้น และได้ \$2 ถ้าตลาดลง
  • สัญญาที่สองจ่าย $(2,4)$
  • สัญญาที่สามจ่าย $(3,6)$
  • ถือได้ทั้ง long และ short ถือ long คือซื้อมาถือ จำนวนหน่วยเป็นบวก ถือ short คือขายสัญญาที่ไม่มีอยู่ จำนวนหน่วยติดลบ และเราต้องจ่าย payoff ของสัญญานั้นแทน
  • เป้าหมายคือพอร์ตที่จ่าย $(10,10)$

มีสัญญาให้เลือกถึงสามตัว ผสมให้ได้ $(10,10)$ ได้ไหม

ลองตอบก่อนเปิดเฉลย

ทำไม่ได้ สัญญาที่สองคือสัญญาแรกคูณ 2 และสัญญาที่สามคือสัญญาแรกคูณ 3 ถ้าถือสามสัญญาจำนวน $\theta_1$, $\theta_2$, $\theta_3$ หน่วย payoff ของพอร์ตคือ

\[\begin{aligned}&\theta_1(1,2)+\theta_2(2,4)+\theta_3(3,6)\\&=(\lambda,\ 2\lambda),\quad\lambda=\theta_1+2\theta_2+3\theta_3\end{aligned}\]

เงินตอนตลาดลงจึงเป็นสองเท่าของเงินตอนตลาดขึ้นเสมอ แต่ $(10,10)$ ต้องการเงินสองกรณีเท่ากัน

ถ้าเพิ่มสัญญาใหม่ที่จ่าย $(3,1)$ จะทำได้ ถือสัญญาแรก 4 หน่วยกับสัญญาใหม่ 2 หน่วย ได้ $4(1,2)+2(3,1)=(4+6,\ 8+2)=(10,10)$

ดังนั้นจำนวนสัญญาที่มีขายไม่ใช่ตัวตัดสิน สิ่งที่ตัดสินคือจำนวนทิศที่ไม่ซ้ำกัน สามสัญญาเดิมชี้ทิศเดียวกันหมด จำนวนทิศนี้เรียกว่า rank

ภาพรวมก่อนลงสูตร

โจทย์ใน hook คือระบบสมการเชิงเส้น $A\mathbf x=\mathbf b$ แบบที่วิศวกรคุ้นเคย

  • $A$ คือ matrix ที่แต่ละคอลัมน์เป็น payoff ของสัญญาหนึ่งตัว และแต่ละแถวเป็นสถานะหนึ่ง
  • $\mathbf x$ คือจำนวนหน่วยที่ถือของแต่ละสัญญา เรียกว่า holdings
  • $A\mathbf x$ คือ payoff ของทั้งพอร์ต และ $\mathbf b$ คือ payoff ที่ลูกค้าต้องการ

งาน hedge (จัดพอร์ตเพื่อหักล้างความเสี่ยงที่มีอยู่) และงานจัดพอร์ตอีกหลายแบบเขียนได้ในรูปนี้ ก่อนแก้สมการ เราต้องถามสามคำถามแยกกัน

  • มีคำตอบไหม คือ $\mathbf b$ อยู่ในชุดของ output ที่ $A$ สร้างได้หรือเปล่า ชุดนี้เรียกว่า range
  • มีคำตอบเดียวไหม คือมีการเปลี่ยน $\mathbf x$ แบบที่ $A$ ส่งไปเป็นศูนย์หรือเปล่า ถ้ามี เราเปลี่ยน holdings ได้โดยที่ payoff ไม่เปลี่ยน การเปลี่ยนแบบนี้ทั้งหมดเรียกว่า null space
  • คำตอบนิ่งไหม คือถ้า $\mathbf b$ ขยับนิดเดียว $\mathbf x$ จะกระโดดไปไกลแค่ไหน

รูปด้านล่างตอบคำถามแรกของ hook ด้วยภาพ payoff ของสามสัญญาวางตัวบนเส้นตรงเส้นเดียว ผสมกันอย่างไรก็ได้แค่จุดบนเส้นนั้น เป้าหมาย $(10,10)$ อยู่นอกเส้น แต่ถ้าเพิ่มสัญญาที่ชี้ทิศใหม่ ทุกจุดในระนาบก็ไปถึงได้

หน้านี้เดินตามลำดับนี้

  • ใช้ rank นับทิศที่สัญญาให้ได้จริง
  • ใช้ null space อธิบายว่าทำไมคำตอบมีได้หลายชุด
  • ดูว่าทำไม matrix จัตุรัสกลับด้านได้ (หา inverse ได้) เฉพาะเมื่อ rank เต็ม และทำไมกลับด้านได้แล้วคำตอบก็ยังอาจไม่นิ่ง
  • ปิดด้วยเรื่องที่ใช้จริงบ่อยที่สุด คือ inverse ของ covariance matrix ในสูตรจัดพอร์ต (covariance matrix คือตารางที่บอกว่าผลตอบแทนของหุ้นแต่ละคู่ขยับไปด้วยกันแค่ไหน) เราจะเห็นว่าทำไม covariance ที่ประมาณจากข้อมูลหุ้น 500 ตัวหนึ่งปีกลับด้านไม่ได้ และวิธี shrink ช่วยได้อย่างไร
ศัพท์ที่ใช้ในหัวข้อนี้
Payoff
เงินที่สัญญาหรือพอร์ตจ่ายตอนจบ ในหน้านี้เขียนเป็นคู่ตัวเลข (เงินเมื่อตลาดขึ้น, เงินเมื่อตลาดลง)
Long และ short
long คือซื้อมาถือ จำนวนหน่วยเป็นบวก short คือขายสิ่งที่ไม่มีอยู่ จำนวนหน่วยติดลบ คนที่ short ต้องจ่าย payoff นั้นเอง
Holdings
จำนวนหน่วยที่ถือของแต่ละสัญญาหรือแต่ละหุ้น เขียนเป็นเวกเตอร์ $\mathbf x$ หรือ $\boldsymbol\theta$
Range (column space)
output ทั้งหมด $A\mathbf x$ ที่สร้างได้ คือทุกผลรวมแบบ “คอลัมน์คูณตัวเลขแล้วบวกกัน” (linear combination) ใช้ตอบว่าเป้าหมายมีคำตอบหรือไม่
Rank
จำนวนคอลัมน์ที่เป็น linearly independent คือไม่มีคอลัมน์ไหนสร้างได้จากคอลัมน์อื่น หรือพูดอีกแบบคือมิติของ range rank เท่ากับจำนวนแถวที่อิสระเสมอ และไม่เกินจำนวนแถวหรือจำนวนคอลัมน์ ใช้นับทิศที่ตลาดหรือข้อมูลให้ได้จริง
Null space
input $\mathbf x$ ทั้งหมดที่ทำให้ $A\mathbf x=\mathbf 0$ ในภาษาพอร์ตคือการเปลี่ยน holdings ที่ไม่เปลี่ยน payoff ใช้อธิบายว่าทำไมคำตอบมีได้หลายชุด
Invertible และ singular
matrix จัตุรัสที่มี $A^{-1}$ ซึ่ง $A^{-1}A=AA^{-1}=I$ เรียกว่า invertible ($I$ คือ identity matrix ที่มี 1 บนแนวทแยงและ 0 ที่อื่น คูณเวกเตอร์ไหนก็ได้เวกเตอร์เดิม) เกิดขึ้นเมื่อ rank เต็มพอดี ถ้าไม่มี $A^{-1}$ เรียกว่า singular
Determinant
ตัวเลขที่บอกว่า matrix จัตุรัสขยายพื้นที่ (หรือปริมาตร) กี่เท่า เป็นศูนย์เมื่อมีทิศถูกบี้หาย
Condition number
ตัวคูณที่บอกว่า error สัมพัทธ์ใน $\mathbf b$ (ขนาด error เทียบกับขนาดของ $\mathbf b$ เอง) อาจขยายเป็น error สัมพัทธ์ใน $\mathbf x$ ได้กี่เท่า ใช้วัดว่าคำตอบนิ่งแค่ไหน
Covariance matrix
ตารางของหุ้น $N$ ตัว ช่องแนวทแยงคือ variance ของหุ้นแต่ละตัว ช่องอื่นคือ covariance ของหุ้นแต่ละคู่ ซึ่งบอกว่าคู่นั้นขยับไปด้วยกันแค่ไหน ดู the mean vector and the covariance matrix
Shrink
การผสม covariance ที่ประมาณจากข้อมูลเข้ากับ matrix ที่เรียบง่ายและกลับด้านได้แน่ ๆ เพื่อให้ผลรวมกลับด้านได้และนิ่งขึ้น

ขั้นที่ 1 — range: ทุก payoff ที่สร้างได้

คำถามแรกคือ “มีคำตอบไหม” จะตอบได้ เราต้องรู้ก่อนว่าสามสัญญานี้ผสมแล้วได้ payoff แบบไหนบ้าง

วางสามสัญญาเป็นคอลัมน์ของ matrix $S$ แถวบนคือสถานะตลาดขึ้น แถวล่างคือสถานะตลาดลง ให้ $\boldsymbol\theta=(\theta_1,\theta_2,\theta_3)$ คือจำนวนหน่วยที่ถือของแต่ละสัญญา payoff ของพอร์ตคือ $S\boldsymbol\theta$ เราลองดูว่า $S\boldsymbol\theta$ หน้าตาเป็นอย่างไรเมื่อ $\boldsymbol\theta$ เป็นอะไรก็ได้

\[\begin{aligned} S&=\begin{bmatrix}1&2&3\\2&4&6\end{bmatrix},\\ S\boldsymbol\theta&=\begin{bmatrix}\theta_1+2\theta_2+3\theta_3\\2(\theta_1+2\theta_2+3\theta_3)\end{bmatrix} =\lambda\begin{bmatrix}1\\2\end{bmatrix},\\ \lambda&=\theta_1+2\theta_2+3\theta_3. \end{aligned}\]

ไม่ว่าจะถือแต่ละสัญญากี่หน่วย payoff ที่ได้คือ $(1,2)$ คูณตัวเลขตัวเดียว $\lambda$ เสมอ เพราะแถวล่างของ $S$ เป็นสองเท่าของแถวบนพอดี ชุดของ payoff ที่สร้างได้ (range) จึงเป็นแค่เส้นตรงผ่านจุด $(0,0)$ ไม่ใช่ทั้งระนาบ เส้นตรงมีหนึ่งมิติ rank คือมิติของ range จึงเท่ากับ 1

เป้าหมาย $(10,10)$ อยู่บนเส้นนี้ไหม ลองเทียบทีละแถว

\[\begin{aligned}\text{up: }\lambda&=10,\\\text{down: }2\lambda&=10\ \Rightarrow\ \lambda=5.\end{aligned}\]

สองแถวต้องการ $\lambda$ คนละค่า จึงไม่มี $\boldsymbol\theta$ ไหนทำได้

อีกวิธีนับ rank คือลบแถว ถ้าแถวไหนสร้างได้จากแถวอื่น แถวนั้นจะกลายเป็นศูนย์

\[\text{row}_2-2\,\text{row}_1=(2,4,6)-2(1,2,3)=(0,0,0)\]

เหลือแถวที่ไม่เป็นศูนย์แถวเดียว rank จึงเป็น 1 ตรงกับที่นับจากคอลัมน์ ข้อนี้จริงเสมอ คือจำนวนแถวที่อิสระเท่ากับจำนวนคอลัมน์ที่อิสระ ดังนั้น matrix ที่มี $m$ แถวและ $n$ คอลัมน์มี rank ไม่เกิน $\min(m,n)$ ตลาดที่มีสองสถานะจึงมี rank ไม่เกิน 2 เพราะมีแค่สองแถว ต่อให้มีสัญญาขายเป็นร้อยตัวก็ตาม

ทำให้ได้พอดีไม่ได้ ไม่ได้แปลว่าช่วยลูกค้าไม่ได้เลย ถ้าถือสัญญาแรก 10 หน่วย จะได้ $10(1,2)=(10,20)$ ซึ่งอยู่บนเส้น เงินนี้พอจ่ายหนี้ \$10 ทั้งสองสถานะ การจัดพอร์ตให้ได้เงิน “อย่างน้อย” เท่าภาระทุกกรณีแบบนี้เรียกว่า superhedge ซึ่งตั้งเป็นโจทย์ไว้ใน linear functions and linear constraints ข้อเสียคือมีเงินเกินมา \$10 ในสถานะตลาดลง และเราต้องจ่ายเงินซื้อส่วนเกินนี้ด้วย

ขั้นที่ 2 — null space: เปลี่ยน holdings แล้ว payoff ไม่เปลี่ยน

คำถามที่สองคือ “มีคำตอบเดียวไหม” ลองเป้าหมายที่ทำได้ เช่น $(5,10)$ ซึ่งเท่ากับ $5(1,2)$ จึงอยู่บนเส้น คราวนี้ปัญหากลับกัน คือทำได้หลายแบบเกินไป เราอยากรู้ว่าคำตอบทั้งหมดหน้าตาเป็นอย่างไร

เริ่มจากหาการเปลี่ยน holdings ที่ $S$ ส่งไปเป็นศูนย์ คือเปลี่ยนแล้ว payoff ไม่ขยับเลย เพราะสัญญาที่สองคือสองเท่าของสัญญาแรก การขายสัญญาแรก 2 หน่วยแล้วซื้อสัญญาที่สอง 1 หน่วยจึงหักล้างกันพอดี ทำนองเดียวกันกับสัญญาที่สาม

\[\begin{aligned} S\begin{bmatrix}-2\\1\\0\end{bmatrix}&=\mathbf 0,\quad S\begin{bmatrix}-3\\0\\1\end{bmatrix}=\mathbf 0,\\ S\boldsymbol\theta=\begin{bmatrix}5\\10\end{bmatrix} &\ \text{exactly when}\ \ \boldsymbol\theta=\begin{bmatrix}5-2s-3t\\s\\t\end{bmatrix},\\ \dim\text{range}+\dim\text{null}&=1+2=3=n. \end{aligned}\]

สองเวกเตอร์แรกคือ “การเปลี่ยนที่ไม่เปลี่ยนอะไร” เช่น $-2(1,2)+1(2,4)=(0,0)$ เอาตัวแรกคูณ $s$ บวกตัวที่สองคูณ $t$ ก็ยังได้ payoff ศูนย์ การเปลี่ยนทั้งหมดแบบนี้คือ null space ของ $S$

บรรทัดที่สองบอกวิธีเขียนคำตอบทั้งหมด เริ่มจากคำตอบง่าย ๆ หนึ่งชุด คือ $(5,0,0)$ ซึ่งถือแค่สัญญาแรก 5 หน่วย แล้วบวกเวกเตอร์ตัวแรก $s$ เท่า และเวกเตอร์ตัวที่สอง $t$ เท่า โดย $s$ กับ $t$ เป็นตัวเลขอะไรก็ได้ เช่น $s=2,\ t=0$ ได้ $(1,2,0)$ และ $s=0,\ t=1$ ได้ $(2,0,1)$ ตรวจได้ว่า $1(1,2)+2(2,4)=(5,10)$ และ $2(1,2)+1(3,6)=(5,10)$

เหตุผลที่ใช้ได้เสมอคือ ถ้า $S\boldsymbol\theta_0=\mathbf b$ และ $S\mathbf z=\mathbf 0$ แล้ว $S(\boldsymbol\theta_0+\mathbf z)=\mathbf b+\mathbf 0=\mathbf b$ กลับกัน ถ้ามีสองคำตอบ ผลต่างของมันถูก $S$ ส่งไปที่ $\mathbf b-\mathbf b=\mathbf 0$ จึงอยู่ใน null space เสมอ คำตอบจึงมีชุดเดียวก็ต่อเมื่อ null space มีแค่ $\mathbf 0$

บรรทัดสุดท้ายเรียกว่า rank–nullity input มี $n$ ทิศ (ในที่นี้คือสามสัญญา) แต่ละทิศไปจบที่หนึ่งในสองที่ คือทำให้ output ขยับ (นับรวมเป็น rank) หรือหายไปใน null space ดังนั้น matrix ที่มี $n$ คอลัมน์และ rank $r$ มี null space $n-r$ มิติ สำหรับ $S$ คือ $3-1=2$ มิติ รูปด้านล่างแสดงเรื่องเดียวกันกับ matrix $2\times2$ ที่บี้ทั้งระนาบลงเหลือเส้นเดียว

ขั้นที่ 3 — matrix จัตุรัสกลับด้านได้เมื่อไร

ตอนนี้ดูกรณีที่จำนวนสัญญาเท่ากับจำนวนสถานะ คือ matrix จัตุรัส $n\times n$ ถ้า rank เป็น $n$ ก็ไม่มีทิศไหนถูกบี้ null space มีแค่ $\mathbf 0$ ทุกเป้าหมายจึงมีคำตอบและมีคำตอบเดียว แปลว่ามี “เครื่องย้อน” จาก payoff กลับไปหา holdings เครื่องนี้คือ inverse $A^{-1}$ ซึ่งทำให้ $A^{-1}A=AA^{-1}=I$ โดย $I$ คือ identity matrix (1 บนแนวทแยง 0 ที่อื่น)

กรณี $2\times2$ หาสูตรได้ตรง ๆ เราเดา matrix $B$ ที่สลับสองตัวบนแนวทแยง และเปลี่ยนเครื่องหมายสองตัวที่เหลือ แล้วคูณดูว่าได้อะไร

\[\begin{aligned} A&=\begin{bmatrix}a&b\\c&d\end{bmatrix},\quad B=\begin{bmatrix}d&-b\\-c&a\end{bmatrix},\\ AB&=\begin{bmatrix}ad-bc&-ab+ba\\cd-dc&-cb+da\end{bmatrix}\\ &=\begin{bmatrix}ad-bc&0\\0&ad-bc\end{bmatrix}=(ad-bc)\,I,\\ \det A&=ad-bc,\quad A^{-1}=\frac{1}{ad-bc}B. \end{aligned}\]

เดาถูกเกือบพอดี $AB$ ได้ $ad-bc$ บนแนวทแยงและศูนย์ที่อื่น (คูณ $BA$ ก็ได้ผลเดียวกัน) เหลือแค่หารด้วย $ad-bc$ ก็ได้ $I$ แต่การหารทำได้เมื่อ $ad-bc\ne0$ เท่านั้น ตัวเลข $ad-bc$ นี้คือ determinant ของ $A$

determinant มีความหมายเป็นภาพ $|\det A|$ คือพื้นที่ของสี่เหลี่ยมด้านขนานที่ $A$ ส่งจัตุรัสขนาด $1\times1$ ไปเป็น ถ้า $\det A$ ติดลบ แปลว่ารูปถูกพลิกด้านด้วย determinant เป็นศูนย์แปลว่ารูปถูกบี้แบนเป็นเส้น เช่น matrix $\begin{bmatrix}1&3\\2&6\end{bmatrix}$ ในรูปก่อนมี $\det=1(6)-3(2)=0$

ส่วน matrix ของสัญญาแรกกับสัญญาใหม่ $C=\begin{bmatrix}1&3\\2&1\end{bmatrix}$ มี $\det C=1(1)-3(2)=-5$ ไม่เป็นศูนย์ จึงกลับด้านได้ และส่งจัตุรัส $1\times1$ ไปเป็นสี่เหลี่ยมด้านขนานพื้นที่ $|-5|=5$ ดังรูปถัดไป

ขั้นที่ 4 — แก้โจทย์ของ hook ด้วย inverse

กลับไปที่ลูกค้าใน hook สมมติว่าธนาคารหาสัญญาใหม่ที่จ่าย $(3,1)$ มาได้ ตอนนี้ตลาดมีสองสัญญาที่ชี้คนละทิศ เราจะใช้สูตร inverse จากขั้นก่อนหาว่าต้องถือแต่ละตัวกี่หน่วย

โจทย์ให้อะไรมาบ้าง:

  • สัญญาแรกจ่าย $(1,2)$ และสัญญาใหม่จ่าย $(3,1)$ วางเป็นคอลัมน์ของ $C=\begin{bmatrix}1&3\\2&1\end{bmatrix}$
  • เป้าหมาย $\mathbf b=(10,10)$
  • ต้องหา holdings $\boldsymbol\theta=(\theta_1,\theta_2)$ ที่ทำให้ $C\boldsymbol\theta=\mathbf b$ จึงได้ $\boldsymbol\theta=C^{-1}\mathbf b$

ใช้สูตรจากขั้นก่อน สลับสองตัวบนแนวทแยง (1 กับ 1) เปลี่ยนเครื่องหมายสองตัวที่เหลือ (3 กับ 2) แล้วหารด้วย $\det C=-5$

\[\begin{aligned} C^{-1}&=\frac{1}{-5}\begin{bmatrix}1&-3\\-2&1\end{bmatrix} =\begin{bmatrix}-0.2&0.6\\0.4&-0.2\end{bmatrix},\\ C^{-1}\begin{bmatrix}10\\10\end{bmatrix}&=\begin{bmatrix}-0.2(10)+0.6(10)\\0.4(10)-0.2(10)\end{bmatrix}\\ &=\begin{bmatrix}-2+6\\4-2\end{bmatrix}=\begin{bmatrix}4\\2\end{bmatrix}. \end{aligned}\]

คำตอบ: ถือสัญญาแรก 4 หน่วยและสัญญาใหม่ 2 หน่วย ในตลาดสองสัญญานี้มีคำตอบนี้คำตอบเดียว เพราะ $C$ กลับด้านได้

อีกมุมหนึ่ง $(4,2)$ คือ “พิกัด” ของจุด $(10,10)$ เมื่อเราใช้สองสัญญาเป็นแกนแทนแกนนอนกับแกนตั้งปกติ สองทิศที่ใช้เป็นแกนแบบนี้เรียกว่า basis รูปด้านล่างวาดตารางพิกัดใหม่นี้

ข้อควรระวัง คำตอบเดียวเกิดขึ้นเพราะตลาดมีแค่สองสัญญา ถ้าตลาดยังมีสามสัญญาเดิมอยู่ด้วย จะมีสี่สัญญา $(1,2)$, $(2,4)$, $(3,6)$, $(3,1)$ matrix เป็น $2\times4$ มี rank 2 และ null space มี $4-2=2$ มิติ จึงมีหลายพอร์ตที่จ่าย $(10,10)$ เช่น $(4,0,0,2)$, $(2,1,0,2)$ และ $(1,0,1,2)$ ลองตรวจตัวที่สอง $2(1,2)+1(2,4)+2(3,1)=(2+2+6,\ 4+4+2)=(10,10)$

ตรวจเองใน 10 วินาที: $4(1,2)+2(3,1)$ ให้แถวบน $4+6=10$ และแถวล่าง $8+2=10$

ขั้นที่ 5 — rank เต็มตามแถว แต่ห้าม short ทำให้ไปไม่ถึง

ตลาดสองสัญญาในขั้นก่อนมี rank 2 เท่ากับจำนวนสถานะ เรียกว่า rank เต็มตามแถว แปลว่าในทางพีชคณิตไปถึงได้ทุกจุดในระนาบ แต่ในงานจริงมักมีกฎเพิ่ม เช่น กองทุนหลายแห่งถูกห้าม short ขั้นนี้ดูว่ากฎแบบนี้ทำให้คำตอบที่พีชคณิตให้มาใช้ไม่ได้อย่างไร

โจทย์ให้อะไรมาบ้าง:

  • สองสัญญาเดิม $(1,2)$ และ $(3,1)$ จึงใช้ $C$ และ $C^{-1}$ จากขั้นก่อนได้
  • ลูกค้าคราวนี้เป็นกองทุน ต้องการ payoff $(6,0)$ คือได้ \$6 เมื่อตลาดขึ้น และไม่ได้อะไรเมื่อตลาดลง
  • กองทุนห้าม short จำนวนหน่วยที่ถือทุกตัวต้องไม่ติดลบ
\[\begin{aligned} \boldsymbol\theta&=C^{-1}\begin{bmatrix}6\\0\end{bmatrix}\\ &=\begin{bmatrix}-0.2(6)+0.6(0)\\0.4(6)-0.2(0)\end{bmatrix}=\begin{bmatrix}-1.2\\2.4\end{bmatrix},\\ C\boldsymbol\theta&=-1.2\begin{bmatrix}1\\2\end{bmatrix}+2.4\begin{bmatrix}3\\1\end{bmatrix}=\begin{bmatrix}6\\0\end{bmatrix}. \end{aligned}\]

คำตอบ: พีชคณิตบอกว่าทำได้ เพราะ rank 2 ไปถึงทุกจุดในระนาบ แต่คำตอบที่มีอยู่คำตอบเดียวต้องถือสัญญาแรก $-1.2$ หน่วย คือ short 1.2 หน่วย กองทุนที่ห้าม short จึงทำไม่ได้

ถ้าจำนวนหน่วยห้ามติดลบ จุดที่ไปถึงได้ไม่ใช่ทั้งระนาบ แต่เป็นแค่ “กรวย” ระหว่างสองทิศในรูปด้านล่าง $(10,10)$ อยู่ในกรวย เพราะคำตอบ $(4,2)$ เป็นบวกทั้งคู่ ส่วน $(6,0)$ อยู่นอกกรวย rank บอกได้แค่ว่ามีคำตอบเมื่อไม่มีกฎอื่น การจัดการกฎแบบนี้เป็นเรื่องของ linear functions and linear constraints

ตารางด้านล่างสรุปว่า rank บอกอะไรได้บ้าง $A$ มี $m$ แถว (สถานะ) และ $n$ คอลัมน์ (สัญญา) “rank เต็มตามคอลัมน์” คือ rank $=n$ ทุกคอลัมน์อิสระ ส่วน “rank เต็มตามแถว” คือ rank $=m$ ไปถึงทุกจุด

ขนาดและ rank ของ $A$ ($m\times n$)มีคำตอบไหมคำตอบเดียวไหม
rank $=n$ (เต็มตามคอลัมน์)เฉพาะ $\mathbf b$ ใน rangeใช่ ถ้ามี
rank $=m$ (เต็มตามแถว)ทุก $\mathbf b$ไม่ ถ้า $n\gt m$
$m=n$ และ rank $=n$ทุก $\mathbf b$ใช่ มี $A^{-1}$
rank น้อยกว่าทั้ง $m$ และ $n$เฉพาะ $\mathbf b$ ใน rangeไม่

ขั้นที่ 6 — กลับด้านได้ แต่คำตอบไม่นิ่ง

มาถึงคำถามที่สามของหน้านี้ “คำตอบนิ่งไหม” ตัวเลขในงานจริงมาจากการวัดหรือการประมาณ จึงคลาดเคลื่อนเล็กน้อยเสมอ ถ้าสองคอลัมน์เกือบชี้ทิศเดียวกัน matrix ยังกลับด้านได้ แต่ตัวเลขขยับนิดเดียว คำตอบจะกระโดดไปไกล ลองดูด้วยตัวเลข

โจทย์ให้อะไรมาบ้าง:

  • matrix $A_\varepsilon=\begin{bmatrix}1&1\\1&1+\varepsilon\end{bmatrix}$ คอลัมน์ที่สองต่างจากคอลัมน์แรกแค่ $\varepsilon$ ในแถวล่าง เราตั้ง $\varepsilon=0.001$
  • เป้าหมาย $\mathbf b=(2,\ 2+\varepsilon)$ คำตอบคือ $\mathbf x=(1,1)$ เพราะ $1+1=2$ และ $1+(1+\varepsilon)=2+\varepsilon$
  • ต่อมาเป้าหมายแถวล่างคลาดไป $\eta=0.01$ (สมมติ) เช่นจากการปัดเศษหรือการวัด

แก้ระบบใหม่ด้วยการเอาแถวล่างลบแถวบน ซึ่งตัด $x_1$ ทิ้ง

\[\begin{aligned} x_1+x_2&=2,\\ x_1+(1+\varepsilon)x_2&=2+\varepsilon+\eta,\\ \text{(row 2)}-\text{(row 1)}:\ \ \varepsilon x_2&=\varepsilon+\eta,\\ x_2&=\frac{\varepsilon+\eta}{\varepsilon}=1+\frac{0.01}{0.001}=11,\\ x_1&=2-x_2=2-11=-9. \end{aligned}\]

คำตอบ: เป้าหมายขยับแค่ 0.01 แต่คำตอบกระโดดจาก $(1,1)$ ไปเป็น $(-9,11)$ คือ $x_1$ ขยับ $-9-1=-10$ และ $x_2$ ขยับ $11-1=10$ เทียบกับที่เป้าหมายขยับ ได้ $10/0.01=1{,}000$ เท่า

ต้นเหตุไม่ใช่การไม่มี inverse เพราะ $\det A_\varepsilon=1(1+\varepsilon)-1(1)=\varepsilon=0.001\ne0$ ต้นเหตุคือสองคอลัมน์แทบแยกกันไม่ออก ในภาพ สองสมการคือสองเส้นตรงที่เกือบขนานกัน เลื่อนเส้นหนึ่งนิดเดียว จุดตัดก็วิ่งไปไกล

ตัวเลขที่วัดความไวนี้คือ condition number $\kappa$ เราเทียบ error แบบสัมพัทธ์ คือขนาดของ error หารด้วยขนาดของตัวมันเอง ขนาดของเวกเตอร์ในที่นี้ใช้ค่าสัมบูรณ์ที่ใหญ่ที่สุดในบรรดาสมาชิกของมัน และขนาดของ matrix ใช้ผลรวมค่าสัมบูรณ์ของแถวที่มากที่สุด ทั้งสองแบบเขียนว่า $\|\cdot\|_\infty$ (ดู norms) condition number คือ $\kappa_\infty(A)=\|A\|_\infty\|A^{-1}\|_\infty$ ซึ่งเป็นเพดานของอัตราขยาย error สัมพัทธ์ ส่วน $A_\varepsilon^{-1}$ ได้จากสูตร $2\times2$ ในขั้นที่สาม โดย determinant เท่ากับ $\varepsilon$

\[\begin{aligned} A_\varepsilon^{-1}&=\frac1\varepsilon\begin{bmatrix}1+\varepsilon&-1\\-1&1\end{bmatrix},\\ \|A_\varepsilon\|_\infty&=\max(2,\ 2+\varepsilon)=2+\varepsilon,\\ \|A_\varepsilon^{-1}\|_\infty&=\frac{\max(2+\varepsilon,\ 2)}{\varepsilon}=\frac{2+\varepsilon}{\varepsilon},\\ \kappa_\infty&=\frac{(2+\varepsilon)^2}{\varepsilon}=\frac{2.001^2}{0.001}\approx4004. \end{aligned}\]

error สัมพัทธ์ในข้อมูลจึงขยายในคำตอบได้ถึงราว 4,000 เท่า ตัวอย่างของเราขยายจริงราวครึ่งหนึ่งของเพดานนี้

\[\begin{aligned} \text{data: }&\frac{0.01}{2.001}\approx0.005,\\ \text{answer: }&\frac{10}{1}=10,\\ \text{ratio: }&\frac{10}{0.01/2.001}=2{,}001\le4004. \end{aligned}\]

อย่าใช้ determinant ที่เล็กเป็นสัญญาณเตือนอย่างเดียว เช่น $10^{-6}I_2$ คือ identity $2\times2$ คูณ $10^{-6}$ มี determinant $10^{-6}\times10^{-6}=10^{-12}$ แต่ condition number เท่ากับ $10^{-6}\times10^{6}=1$ เพราะมันแค่ย่อทุกทิศเท่ากัน ไม่ได้บี้ทิศไหนเป็นพิเศษ ในงานจริงจึงตรวจ rank ด้วยวิธีแยก matrix มาตรฐานในไลบรารีตัวเลข เช่น QR หรือ SVD และตั้ง tolerance ให้ชัด คือเกณฑ์ว่าตัวเลขเล็กกว่าเท่าไรให้นับเป็นศูนย์

ขั้นที่ 7 — inverse ของ covariance ในสูตรจัดพอร์ต

ทีนี้ไปดูงานที่ใช้ inverse บ่อยที่สุดงานหนึ่งในการเงิน คือการจัดพอร์ตหุ้น นักลงทุนคนหนึ่งมีเงินก้อนหนึ่ง เขาแบ่งเงินไปซื้อหุ้นสองตัว ส่วนที่เหลือฝากไว้ในสินทรัพย์ปลอดความเสี่ยง ซึ่งคือที่เก็บเงินที่ได้ดอกเบี้ยแน่นอน เช่นพันธบัตรรัฐบาลระยะสั้น เขาอยากได้ผลตอบแทนสูง แต่ไม่อยากให้พอร์ตแกว่งแรง วิธีชั่งสองเรื่องนี้แบบที่นิยมที่สุดเรียกว่า mean–variance

ของที่ใช้ในโจทย์

  • $\mathbf w=(w_1,w_2)$ คือน้ำหนัก หรือสัดส่วนของเงินทั้งหมดที่ลงในหุ้นแต่ละตัว เงินที่เหลือ $1-w_1-w_2$ อยู่ในสินทรัพย์ปลอดความเสี่ยง
  • $\boldsymbol\mu$ คือผลตอบแทนคาดหวังต่อปีของหุ้นแต่ละตัว นับเฉพาะส่วนที่ได้เกินดอกเบี้ยของสินทรัพย์ปลอดความเสี่ยง
  • $\Sigma$ คือ covariance matrix ของผลตอบแทนหุ้น และ $\mathbf w^{\mathsf T}\Sigma\mathbf w$ คือ variance ของผลตอบแทนพอร์ต ซึ่งวัดว่าพอร์ตแกว่งแค่ไหน
  • $\tau\gt0$ คือความกลัวความเสี่ยงของนักลงทุน ยิ่ง $\tau$ ใหญ่ variance ยิ่งถูกหักคะแนนมาก

คะแนนของพอร์ตคือ $U(\mathbf w)=\boldsymbol\mu^{\mathsf T}\mathbf w-\tau\,\mathbf w^{\mathsf T}\Sigma\mathbf w$ คือผลตอบแทนคาดหวังลบด้วยโทษของการแกว่ง เราหาน้ำหนักที่ทำให้ $U$ สูงสุด ด้วยการตั้ง gradient เป็นศูนย์ (ดู the gradient and first-order conditions) gradient ของ $\boldsymbol\mu^{\mathsf T}\mathbf w$ คือ $\boldsymbol\mu$ และ gradient ของ $\mathbf w^{\mathsf T}\Sigma\mathbf w$ คือ $2\Sigma\mathbf w$ เพราะ $\Sigma$ สมมาตร เหมือนอนุพันธ์ของ $\sigma^2w^2$ คือ $2\sigma^2w$ ตัวเลขของหุ้นสองตัวข้างล่างเป็นตัวเลขสมมติ

\[\begin{aligned} \boldsymbol\mu-2\tau\Sigma\mathbf w&=\mathbf 0 \ \Longrightarrow\ \mathbf w^*=\frac{1}{2\tau}\Sigma^{-1}\boldsymbol\mu,\\ \Sigma&=\begin{bmatrix}0.04&0.02\\0.02&0.05\end{bmatrix},\quad \boldsymbol\mu=\begin{bmatrix}0.08\\0.04\end{bmatrix},\\ \det\Sigma&=0.04(0.05)-0.02^2=0.0016,\\ \Sigma^{-1}&=\frac{1}{0.0016}\begin{bmatrix}0.05&-0.02\\-0.02&0.04\end{bmatrix}\\ &=\begin{bmatrix}31.25&-12.5\\-12.5&25\end{bmatrix},\\ \Sigma^{-1}\boldsymbol\mu&=\begin{bmatrix}31.25(0.08)-12.5(0.04)\\-12.5(0.08)+25(0.04)\end{bmatrix}\\ &=\begin{bmatrix}2.5-0.5\\-1+1\end{bmatrix}=\begin{bmatrix}2\\0\end{bmatrix},\\ \tau=2:\ \mathbf w^*&=\frac{1}{2(2)}\begin{bmatrix}2\\0\end{bmatrix}=\begin{bmatrix}0.5\\0\end{bmatrix}. \end{aligned}\]

ตัวเลขใน $\Sigma$ อ่านได้แบบนี้ ช่องแนวทแยง 0.04 กับ 0.05 คือ variance ของหุ้นแต่ละตัว คิดเป็นความผันผวน $\sqrt{0.04}=20\%$ และ $\sqrt{0.05}\approx22\%$ ต่อปี ช่อง 0.02 คือ covariance ซึ่งเป็นบวก แปลว่าสองหุ้นมักขึ้นลงไปด้วยกัน ส่วน $\boldsymbol\mu$ บอกว่าหุ้นแรกคาดว่าได้เกินดอกเบี้ย 8% ต่อปี และหุ้นที่สอง 4%

สูตร $\mathbf w^*$ ต้องใช้ $\Sigma^{-1}$ ซึ่งมีอยู่เพราะ $\det\Sigma=0.0016\ne0$ ระบบจึงมีคำตอบเดียว คำตอบบอกให้ลงเงิน 50% ในหุ้นแรก ไม่ซื้อหุ้นที่สองเลย และเก็บอีก $1-0.5-0=50\%$ ไว้ในสินทรัพย์ปลอดความเสี่ยง

น่าแปลกที่หุ้นที่สองคาดว่าได้เกินดอกเบี้ยตั้ง 4% แต่ได้น้ำหนักศูนย์ ลองเอา covariance หารด้วย variance ของหุ้นแรก ได้ $0.02/0.04=0.5$ ตัวเลขนี้บอกว่าเมื่อหุ้นแรกขยับ 1% หุ้นที่สองมักขยับตามราว 0.5% การขยับตามนี้ควรได้ผลตอบแทน $0.5\times8\%=4\%$ ซึ่งเท่ากับที่หุ้นที่สองให้พอดี ถือหุ้นที่สองจึงไม่ได้อะไรที่หุ้นแรกให้ไม่ได้ ได้แค่การแกว่งเพิ่ม

จุดที่ gradient เป็นศูนย์เป็นค่าสูงสุดจริงไหม ลองเขียนพอร์ตอื่นเป็น $\mathbf w^*+\mathbf z$ แล้วกระจาย

\[\begin{aligned} U(\mathbf w^*+\mathbf z)&=U(\mathbf w^*)+\mathbf z^{\mathsf T}(\boldsymbol\mu-2\tau\Sigma\mathbf w^*)\\ &\quad-\tau\,\mathbf z^{\mathsf T}\Sigma\mathbf z\\ &=U(\mathbf w^*)-\tau\,\mathbf z^{\mathsf T}\Sigma\mathbf z. \end{aligned}\]

พจน์ไขว้ทั้งสองตัวรวมกันได้ $2\tau\,\mathbf z^{\mathsf T}\Sigma\mathbf w^*$ เพราะ $\Sigma$ สมมาตร และวงเล็บตรงกลางเป็นศูนย์เพราะ $\mathbf w^*$ ทำให้ gradient เป็นศูนย์ ที่เหลือ $\mathbf z^{\mathsf T}\Sigma\mathbf z$ คือ variance ของพอร์ต $\mathbf z$ ซึ่งไม่มีวันติดลบ พอร์ตอื่นจึงได้ $U$ ไม่เกิน $U(\mathbf w^*)$

ถ้า $\Sigma$ singular จะเกิดอะไร สมมติสองหุ้นแกว่งเหมือนกันทุกอย่าง $\Sigma=\begin{bmatrix}0.04&0.04\\0.04&0.04\end{bmatrix}$ ($\det=0.04^2-0.04^2=0$) แต่ $\boldsymbol\mu$ ยังเป็น $(0.08,\ 0.04)$ พอร์ต $\mathbf z=(1,-1)$ คือซื้อหุ้นแรกและ short หุ้นที่สองเท่ากัน มี $\Sigma\mathbf z=\mathbf 0$ จึงมี variance ศูนย์ แต่ได้ผลตอบแทนคาดหวัง $\boldsymbol\mu^{\mathsf T}\mathbf z=0.08-0.04=0.04$ เติม $t\mathbf z$ เข้าไปในพอร์ตใด ๆ แล้ว $U$ เพิ่มขึ้น $0.04t$ โดยไม่มีโทษเลย

\[U(\mathbf w+t\mathbf z)=U(\mathbf w)+0.04\,t\]

$U$ จึงโตได้ไม่สิ้นสุด โปรแกรมหาค่าที่ดีที่สุด (optimizer) จะเพิ่ม $t$ ไปเรื่อย ๆ คือกู้เงินมาซื้อขายเกินทุนที่มี (leverage) ไม่หยุด

สูตร mean–variance อีกแบบที่กำหนดผลตอบแทนเป้าหมายไว้ก่อนก็ต้องกลับด้าน matrix ที่ใหญ่กว่า matrix นั้นมี $\Sigma$ อยู่ข้างใน และมีแถว $\boldsymbol\mu^{\mathsf T}$ (ผลตอบแทนต้องได้ตามเป้า) กับแถว $\mathbf 1^{\mathsf T}$ (น้ำหนักรวมกันเป็น 1) ต่อท้าย ถ้าหุ้นทุกตัวมีผลตอบแทนคาดหวังเท่ากันเป็น $c$ แถว $\boldsymbol\mu^{\mathsf T}$ ก็เท่ากับ $c$ คูณแถว $\mathbf 1^{\mathsf T}$ สองแถวขนานกัน matrix จึง singular และตั้งเป้าหมายผลตอบแทนที่ไม่ใช่ $c$ ไม่ได้ รายละเอียดอยู่ที่ Markowitz portfolio selection

ขั้นที่ 8 — sample covariance ของหุ้น 500 ตัวจากข้อมูลหนึ่งปีกลับด้านไม่ได้

ในขั้นก่อน $\Sigma$ เป็นตัวเลขที่เรารู้ แต่ในงานจริงไม่มีใครรู้ $\Sigma$ ทีมลงทุนต้องประมาณมันจากผลตอบแทนในอดีต ตัวที่ประมาณได้เรียกว่า sample covariance ลองนึกถึงทีมที่ดูแลหุ้นใหญ่ 500 ตัว เช่นหุ้นในดัชนี S&P 500 ของสหรัฐ และใช้ข้อมูลรายวันย้อนหลังหนึ่งปี ขั้นนี้จะนับ rank ของ sample covariance ที่ได้ และพบว่ามันกลับด้านไม่ได้

ของที่ใช้

  • $T$ คือจำนวนวันในข้อมูล และ $N$ คือจำนวนหุ้น
  • $R$ คือ matrix ขนาด $T\times N$ แถวละหนึ่งวัน คอลัมน์ละหนึ่งหุ้น แต่ละช่องคือผลตอบแทนของวันนั้นลบด้วยค่าเฉลี่ยของหุ้นตัวนั้น
  • sample covariance คือ $\widehat\Sigma=R^{\mathsf T}R/(T-1)$ ตามกฎของ matrix multiplication หมวก $\widehat{\ }$ แปลว่าค่าที่ประมาณจากข้อมูล การหารด้วย $T-1$ แทน $T$ เป็นสูตรมาตรฐานของ sample variance ที่อธิบายใน estimators, bias, and standard error
  • $\mathbf v$ คือน้ำหนักของพอร์ตใด ๆ บนหุ้น $N$ ตัว
\[\begin{aligned} \mathbf v^{\mathsf T}\widehat\Sigma\mathbf v&=\frac{\mathbf v^{\mathsf T}R^{\mathsf T}R\mathbf v}{T-1}=\frac{\|R\mathbf v\|^2}{T-1},\\ \operatorname{rank}\widehat\Sigma&=\operatorname{rank}R\le\min(T-1,\ N),\\ T=250,\ N=500:\ \operatorname{rank}&\le\min(249,\ 500)=249,\\ \dim\text{null}&\ge500-249=251. \end{aligned}\]

บรรทัดแรกมีความหมายตรง ๆ $R\mathbf v$ คือผลตอบแทนรายวันของพอร์ต $\mathbf v$ (หลังหักค่าเฉลี่ย) ดังนั้น $\mathbf v^{\mathsf T}\widehat\Sigma\mathbf v$ ก็คือ variance ของพอร์ตนั้นในข้อมูล ถ้า $\widehat\Sigma\mathbf v=\mathbf 0$ ด้านซ้ายเป็นศูนย์ จึงต้องมี $\|R\mathbf v\|=0$ คือ $R\mathbf v=\mathbf 0$ กลับกัน ถ้า $R\mathbf v=\mathbf 0$ ก็ได้ $\widehat\Sigma\mathbf v=R^{\mathsf T}\mathbf 0/(T-1)=\mathbf 0$ สอง matrix จึงมี null space เดียวกัน ทั้งคู่มี $N$ คอลัมน์ ตาม rank–nullity ในขั้นที่สอง rank จึงเท่ากันด้วย

ทำไม rank ไม่เกิน $T-1$ แทนที่จะเป็น $T$ เพราะแต่ละคอลัมน์ถูกหักค่าเฉลี่ยแล้ว ผลรวมของทุกคอลัมน์จึงเป็นศูนย์ แปลว่าผลรวมของทั้ง $T$ แถวเป็นเวกเตอร์ศูนย์ แถวสุดท้ายจึงเท่ากับลบของผลรวมแถวอื่น แถวที่อิสระจึงมีได้มากสุด $T-1$ แถว

ตัวเลข 250 มาจากจำนวนวันที่ตลาดหุ้นสหรัฐเปิด ปีหนึ่งมี 365 วัน หักเสาร์อาทิตย์ราว 104 วัน และวันหยุดตลาดราว 9 วัน เหลือราว 252 วัน เราปัดเป็น 250 ให้คิดง่าย ผลคือ sample covariance ของหุ้น 500 ตัวมี null space อย่างน้อย 251 มิติ แต่ละทิศในนั้นคือพอร์ตที่ variance ในข้อมูลเป็นศูนย์ ดูเหมือน “ไม่มีความเสี่ยงเลย” ทั้งที่ในโลกจริงไม่มีพอร์ตหุ้นแบบนั้น

นับจำนวนตัวเลขก็เห็นปัญหา covariance matrix สมมาตร ตัวเลขที่ต้องประมาณจึงมีเท่ากับช่องบนแนวทแยงบวกช่องเหนือแนวทแยง เทียบกับจำนวนตัวเลขในข้อมูล

\[\begin{aligned} \text{unknowns: }&\frac{N(N+1)}{2}=\frac{500\times501}{2}=125{,}250,\\ \text{data: }&T\times N=250\times500=125{,}000. \end{aligned}\]

ตัวที่ต้องประมาณมีมากกว่าข้อมูลที่มี optimizer ที่เห็นทิศ “ความเสี่ยงศูนย์” จะทุ่มน้ำหนักเข้าไปในทิศนั้น ซึ่งเท่ากับเลือกทิศที่ error ของการประมาณใหญ่ที่สุดพอดี

ขั้นที่ 9 — ย่อส่วนให้เห็น: พอร์ตผีที่ความเสี่ยงเป็นศูนย์ และการ shrink

matrix $500\times500$ ใหญ่เกินกว่าจะดูด้วยตา ขั้นนี้ย่อเรื่องเดียวกันให้เหลือหุ้นสองตัวกับข้อมูลสามวัน ข้อมูลสามวันให้ rank ได้ถึง $\min(3-1,\ 2)=2$ ซึ่งยังเต็มได้ เราจึงเลือกข้อมูลที่หุ้นสองตัวขยับเป็นสัดส่วนกันพอดี ให้ rank ตกเหลือ 1 เหมือนสิ่งที่เกิดกับหุ้น 500 ตัว จะได้เห็นพอร์ต “ความเสี่ยงศูนย์” ที่ไม่มีอยู่จริง เราเรียกมันว่าพอร์ตผี แล้วดูว่าการ shrink แก้ได้อย่างไร

โจทย์ให้อะไรมาบ้าง: (ตัวเลขสมมติ หน่วยเป็นเปอร์เซ็นต์ต่อวัน)

  • ผลตอบแทนของ (หุ้นแรก, หุ้นที่สอง) สามวันคือ $\mathbf r_1=(2,1)$, $\mathbf r_2=(0,0)$ และ $\mathbf r_3=(-2,-1)$
  • ค่าเฉลี่ยของแต่ละหุ้นเป็นศูนย์อยู่แล้ว เพราะ $(2+0-2)/3=0$ และ $(1+0-1)/3=0$ จึงไม่ต้องหักค่าเฉลี่ย
  • วันที่สี่ ซึ่งไม่อยู่ในข้อมูลที่ใช้ประมาณ เกิดขึ้นจริงเป็น $\mathbf r_4=(1,\ 0.8)$

sample covariance $H$ คือผลรวมของ $\mathbf r_t\mathbf r_t^{\mathsf T}$ ทุกวัน หารด้วย $T-1=2$ วันที่สองเป็นศูนย์ทั้งหมดจึงไม่ช่วยอะไร

\[\begin{aligned} \mathbf r_1\mathbf r_1^{\mathsf T}&=\begin{bmatrix}2\\1\end{bmatrix}\begin{bmatrix}2&1\end{bmatrix}=\begin{bmatrix}4&2\\2&1\end{bmatrix}=\mathbf r_3\mathbf r_3^{\mathsf T},\\ H&=\tfrac12\big(\mathbf r_1\mathbf r_1^{\mathsf T}+\mathbf r_2\mathbf r_2^{\mathsf T}+\mathbf r_3\mathbf r_3^{\mathsf T}\big)\\ &=\tfrac12\cdot2\begin{bmatrix}4&2\\2&1\end{bmatrix}=\begin{bmatrix}4&2\\2&1\end{bmatrix},\\ \det H&=4(1)-2(2)=0,\\ \mathbf w=(1,-2):\ H\mathbf w&=(4-4,\ 2-2)=\mathbf 0,\\ \mathbf w^{\mathsf T}\mathbf r_4&=1(1)-2(0.8)=-0.6. \end{aligned}\]

คำตอบ: $\mathbf w=(1,-2)$ คือพอร์ตที่ซื้อหุ้นแรก 1 หน่วยและ short หุ้นที่สอง 2 หน่วย มันอยู่ใน null space ของ $H$ จึงมี sample variance ศูนย์ เหตุผลคือทุกวันในข้อมูล หุ้นแรกขยับเป็นสองเท่าของหุ้นที่สองพอดี ผลตอบแทนของพอร์ตนี้ในสามวันคือ $2-2(1)=0$, $0$ และ $-2-2(-1)=0$ แต่พอถึงวันที่สี่ พอร์ตนี้ขาดทุน 0.6% ทันที “ความเสี่ยงศูนย์” จึงเป็นสมบัติของข้อมูลชุดเล็ก ไม่ใช่ของโลกจริง

วิธีแก้มาตรฐานคือ shrink คือผสม sample covariance เข้ากับ matrix เป้าหมายที่ไม่มีทิศศูนย์ เป้าหมายที่ง่ายที่สุดคือ identity คูณ variance เฉลี่ยของหุ้นสองตัว ซึ่งได้จากช่องแนวทแยงของ $H$ คือ $\bar s^2=(4+1)/2=2.5$ ให้น้ำหนักกับ $H$ เป็น $\lambda=0.8$ และกับเป้าหมายเป็น $1-\lambda=0.2$ (เลือกเอง)

\[\begin{aligned} V_{\text{sh}}&=\lambda H+(1-\lambda)\bar s^2I\\ &=\begin{bmatrix}3.2&1.6\\1.6&0.8\end{bmatrix}+\begin{bmatrix}0.5&0\\0&0.5\end{bmatrix} =\begin{bmatrix}3.7&1.6\\1.6&1.3\end{bmatrix},\\ \det V_{\text{sh}}&=3.7(1.3)-1.6^2=4.81-2.56=2.25,\\ \mathbf w^{\mathsf T}V_{\text{sh}}\mathbf w&=3.7(1)^2+2(1.6)(1)(-2)+1.3(-2)^2\\ &=3.7-6.4+5.2=2.5. \end{aligned}\]

matrix ใหม่มี determinant 2.25 ไม่เป็นศูนย์ จึงกลับด้านได้ พอร์ตผีมี variance $2.5\ (\%)^2$ คิดเป็นความผันผวน $\sqrt{2.5}\approx1.58\%$ ต่อวัน ไม่ใช่ศูนย์อีกต่อไป

ตัวเลขนี้เข้ากับวันที่สี่ได้ดีกว่าเดิม ถ้าเชื่อ $H$ พอร์ตนี้ไม่ควรขยับเลยสักนิด การขาดทุน 0.6% จึงเป็นไปไม่ได้ ถ้าเชื่อ $V_{\text{sh}}$ การขาดทุน 0.6% คือแค่ $0.6/1.58\approx0.38$ เท่าของ SD ซึ่งเป็นวันธรรมดา

สัดส่วน 0.8 ในที่นี้เลือกด้วยมือ วิธี covariance shrinkage (Ledoit–Wolf) เลือกสัดส่วนนี้จากข้อมูลให้

อีกทางหนึ่งคือ factor model แบบจำลองนี้บอกว่าผลตอบแทนของหุ้นแต่ละตัวมาจากปัจจัยร่วมไม่กี่ตัว เช่นการขึ้นลงของทั้งตลาด บวกกับส่วนที่แกว่งเฉพาะตัว covariance ที่ได้มีรูป $B\Omega B^{\mathsf T}+D$

  • $B$ บอกว่าหุ้นแต่ละตัวขยับตามปัจจัยแต่ละตัวแค่ไหน
  • $\Omega$ คือ covariance ของปัจจัย
  • $D$ เป็น matrix แนวทแยง ช่องที่ $i$ คือ variance เฉพาะตัว $d_i$ ของหุ้นตัวที่ $i$ ซึ่งเป็นบวกทุกช่อง

variance ของพอร์ต $\mathbf v$ ใด ๆ จึงมีสองส่วน ส่วนแรก $\mathbf v^{\mathsf T}B\Omega B^{\mathsf T}\mathbf v$ คือ variance ที่มาจากปัจจัย ซึ่งไม่ติดลบ ส่วนที่สอง $\mathbf v^{\mathsf T}D\mathbf v=\sum_i d_i v_i^2$ เป็นบวกเสมอเมื่อ $\mathbf v\ne\mathbf 0$ เพราะทุก $d_i\gt0$ ผลรวมจึงเป็นบวกทุกทิศ ไม่มีทิศศูนย์เหลือ

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

นับจำนวนสัญญาแทนนับทิศ: คิดว่ามีสามสัญญาก็น่าจะสร้าง payoff สองสถานะได้ทุกแบบ แต่ $(2,4)=2(1,2)$ และ $(3,6)=3(1,2)$ สามสัญญาจึงมี rank แค่ 1 ไปถึงได้แค่เส้นเดียว และเป้าหมาย $(10,10)$ ไม่มีคำตอบ

ถือว่ากลับด้านได้แล้วคำตอบเชื่อได้: $\det A_\varepsilon=0.001\ne0$ จึงกลับด้านได้ แต่ $\kappa_\infty\approx4004$ เป้าหมายขยับ 0.01 คำตอบกระโดดจาก $(1,1)$ ไป $(-9,11)$

ใช้ determinant ที่เล็กเป็นเกณฑ์ว่า singular: $10^{-6}I_2$ มี determinant $10^{-12}$ แต่ไม่มีปัญหาเลย เพราะ condition number เท่ากับ 1 แค่เปลี่ยนหน่วยข้อมูลก็ทำ determinant เล็กลงได้มาก ถ้าเปลี่ยนผลตอบแทนจากเปอร์เซ็นต์เป็นเศษส่วน ทุกผลตอบแทนถูกหารด้วย 100 ทุกช่องของ covariance ถูกหารด้วย $100^2=10^4$ และ determinant ของ covariance $2\times2$ ซึ่งเป็นผลคูณของสองช่อง ถูกหารด้วย $(10^4)^2=10^8$ ทั้งที่ข้อมูลเหมือนเดิมทุกอย่าง

ลืมกฎอื่นของพอร์ต: rank เต็มบอกว่า $(6,0)$ ทำได้ แต่คำตอบ $C^{-1}(6,0)=(-1.2,\ 2.4)$ ต้อง short สัญญาแรก 1.2 หน่วย ถ้าห้าม short ก็ไปไม่ถึง

เชื่อพอร์ตความเสี่ยงศูนย์จาก sample covariance: หุ้น 500 ตัวกับข้อมูล 250 วันให้ rank ไม่เกิน 249 จึงมีทิศความเสี่ยงศูนย์อย่างน้อย $500-249=251$ ทิศ ในตัวอย่างย่อส่วน พอร์ตผี $(1,-2)$ มี variance ศูนย์ในข้อมูล แต่ขาดทุน 0.6% ในวันถัดไป

โจทย์ตรวจความเข้าใจ

1. ธนาคารในขั้นที่สี่ยังเก็บสามสัญญาเดิมไว้ ตลาดจึงมีสี่สัญญา $(1,2)$, $(2,4)$, $(3,6)$, $(3,1)$ และไม่มีข้อห้าม short holdings เขียนเป็นจำนวนหน่วยของสี่สัญญาตามลำดับนี้ ถ้าถือ $(2,1,0,2)$ แทน $(4,0,0,2)$ payoff เปลี่ยนไหม และตลาดนี้สร้างได้ทุก payoff ในสองสถานะหรือไม่

เฉลย

payoff ไม่เปลี่ยน ผลต่างของสองพอร์ตและ payoff ของผลต่างคือ

\[\begin{aligned}\mathbf z&=(2,1,0,2)-(4,0,0,2)=(-2,1,0,0),\\\text{payoff of }\mathbf z&=-2(1,2)+1(2,4)=(0,0).\end{aligned}\]

$\mathbf z$ จึงอยู่ใน null space และทั้งสองพอร์ตจ่าย $(10,10)$ เท่ากัน ตลาดนี้มี rank 2 เท่ากับจำนวนสถานะ (rank เต็มตามแถว) จึงสร้างได้ทุก payoff แต่ null space มี $4-2=2$ มิติ holdings ที่ให้ payoff เดียวกันจึงมีได้หลายชุด

2. นักวิเคราะห์อยากประมาณ covariance ของหุ้น 20 ตัว แต่มีข้อมูลผลตอบแทนแค่ 20 วัน หลังหักค่าเฉลี่ยแล้ว sample covariance กลับด้านได้ไหม และต้องมีข้อมูลอย่างน้อยกี่วัน

เฉลย

กลับด้านไม่ได้ เพราะ

\[\operatorname{rank}\widehat\Sigma\le\min(T-1,\ N)=\min(20-1,\ 20)=19\lt20.\]

rank เต็มต้องการ $T-1\ge N=20$ คือ $T\ge21$ วัน แต่ 21 วันเป็นแค่เงื่อนไขขั้นต่ำ ถ้าหุ้นบางตัวขยับเป็นสัดส่วนกันพอดีในข้อมูล rank ก็ยังลดลงได้ และถึง rank จะเต็ม covariance ที่ได้ก็ยังไม่นิ่ง (condition number สูง) เพราะข้อมูลเกือบไม่พอ

3. นักลงทุนในขั้นที่เจ็ดใช้ $\Sigma$ และ $\boldsymbol\mu$ ชุดเดิม แต่กลัวความเสี่ยงน้อยลง คือ $\tau=0.5$ แทน 2 น้ำหนักในหุ้นสองตัว เงินในสินทรัพย์ปลอดความเสี่ยง และความผันผวนของพอร์ตเป็นเท่าไร

เฉลย

ใช้ $\Sigma^{-1}\boldsymbol\mu=(2,0)$ ที่คำนวณไว้แล้ว

\[\begin{aligned} \mathbf w^*&=\frac{1}{2(0.5)}\begin{bmatrix}2\\0\end{bmatrix}=\begin{bmatrix}2\\0\end{bmatrix},\\ 1-w_1-w_2&=1-2-0=-1,\\ \sqrt{\mathbf w^{*\mathsf T}\Sigma\mathbf w^*}&=\sqrt{2^2(0.04)}=2(0.2)=0.4. \end{aligned}\]

นักลงทุนลงเงินในหุ้นแรก 200% ของเงินทุน เงินในสินทรัพย์ปลอดความเสี่ยงเป็น $-1$ คือกู้มาเพิ่มอีก 100% ของเงินทุน ความผันผวนของพอร์ตเป็น 40% ต่อปี หุ้นที่สองยังได้น้ำหนักศูนย์ เพราะ $\Sigma^{-1}\boldsymbol\mu$ ไม่ขึ้นกับ $\tau$ ค่า $\tau$ แค่กำหนดว่าส่วนที่ลงในหุ้นใหญ่แค่ไหน ไม่ได้เปลี่ยนสัดส่วนระหว่างหุ้นสองตัว

function rank(A, tol = 1e-10) {
  const R = A.map(r => r.slice()), m = R.length, n = R[0].length;
  let r = 0;
  for (let c = 0; c < n && r < m; c++) {
    let p = r;
    for (let i = r + 1; i < m; i++) if (Math.abs(R[i][c]) > Math.abs(R[p][c])) p = i;
    if (Math.abs(R[p][c]) <= tol) continue;
    [R[r], R[p]] = [R[p], R[r]];
    for (let i = r + 1; i < m; i++) {
      const f = R[i][c] / R[r][c];
      for (let j = c; j < n; j++) R[i][j] -= f * R[r][j];
    }
    r++;
  }
  return r;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • range คือทุก output ที่ matrix สร้างได้ rank คือจำนวนทิศที่ไม่ซ้ำกัน สามสัญญาที่ชี้ทิศเดียวกันมี rank 1 จึงสร้าง $(10,10)$ ไม่ได้ ต่อให้มีสัญญากี่ตัวก็ตาม
  • null space คือการเปลี่ยน holdings ที่ไม่เปลี่ยน payoff คำตอบมีชุดเดียวเมื่อ null space มีแค่ $\mathbf 0$ และ rank บวกมิติของ null space เท่ากับจำนวนคอลัมน์เสมอ
  • matrix จัตุรัสกลับด้านได้เมื่อ rank เต็ม ซึ่งตรงกับ determinant ไม่เป็นศูนย์ และ $|\det|$ คือตัวขยายพื้นที่
  • กลับด้านได้ไม่ได้แปลว่าคำตอบนิ่ง $A_\varepsilon$ มี condition number ราว 4004 เป้าหมายขยับแค่ 0.01 คำตอบก็กระโดดจาก $(1,1)$ ไป $(-9,11)$
  • rank เต็มบอกว่ามีคำตอบเมื่อไม่มีกฎอื่น ถ้าห้าม short จุดที่ไปถึงได้เหลือแค่กรวย
  • sample covariance มี rank ไม่เกิน $\min(T-1,\ N)$ หุ้น 500 ตัวกับข้อมูล 250 วันจึงมีพอร์ต “ความเสี่ยงศูนย์” ปลอม ๆ อย่างน้อย 251 ทิศ การ shrink หรือ factor model แก้ปัญหานี้ได้
