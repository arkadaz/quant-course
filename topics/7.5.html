7.5 Rank, Range, and Invertibility

range คือทุก output ที่ matrix ไปถึงได้ rank นับว่ามันไปได้กี่ทิศอิสระ และ matrix จัตุรัสกลับด้านได้ก็ต่อเมื่อไม่มีทิศไหนถูกบี้หายไป

ตลาดจำลองมีสองสถานะ (ขึ้น ลง) และสัญญาสามตัวที่จ่าย $(1,2)$, $(2,4)$ และ $(3,6)$ ดอลลาร์ต่อหน่วย ซื้อขายได้ทั้ง long และ short ลูกค้าต้องการพอร์ตที่จ่าย \$10 พอดีในทั้งสองสถานะ มีสัญญาให้เลือกถึงสามตัว ทำได้ไหม

ลองตอบก่อนเปิดเฉลย

ทำไม่ได้ ไม่ว่าจะถือกี่หน่วย payoff สถานะลงจะเป็นสองเท่าของสถานะขึ้นเสมอ เพราะสัญญาทั้งสามคือสัญญาแรกคูณ 1, 2, 3 สามสัญญาจึงให้ทิศเดียว ถ้าเพิ่มสัญญาใหม่ที่จ่าย $(3,1)$ จะทำได้: ถือสัญญาแรก 4 หน่วยกับสัญญาใหม่ 2 หน่วย ได้ $4(1,2)+2(3,1)=(10,10)$ จำนวนสัญญาที่มีขายไม่ใช่ตัวตัดสิน จำนวนทิศอิสระต่างหาก ซึ่งเรียกว่า rank

ภาพรวมก่อนลงสูตร

เมื่อเขียนโจทย์ hedge หรือโจทย์จัดพอร์ตเป็น $A\mathbf x=\mathbf b$ มีสามคำถามที่ต้องแยกกันถาม ข้อแรกมีคำตอบไหม: $\mathbf b$ อยู่ในชุดของ output ที่ $A$ สร้างได้หรือไม่ ชุดนี้เรียกว่า range ข้อสองมีคำตอบเดียวไหม: มีทิศของ $\mathbf x$ ที่ $A$ ส่งไปศูนย์หรือไม่ ทิศพวกนี้เรียกว่า null space ข้อสามคำตอบนิ่งไหม: ถ้า $\mathbf b$ ขยับนิดเดียว $\mathbf x$ กระโดดแค่ไหน

รูปด้านล่างตอบข้อแรกของ hook ด้วยภาพ สามคอลัมน์วางตัวบนเส้นเดียวกัน ผสมกันอย่างไรก็ได้แค่จุดบนเส้นนั้น เป้าหมาย $(10,10)$ อยู่นอกเส้น เพิ่มคอลัมน์ที่ชี้ทิศใหม่เมื่อไร ทั้งระนาบก็ไปถึงได้

หน้านี้ให้ rank นับทิศ ให้ null space อธิบายว่าทำไมคำตอบมีได้หลายชุด ดูว่าทำไม matrix จัตุรัสกลับด้านได้เฉพาะเมื่อ rank เต็ม แล้วพาไปเรื่องที่ใช้จริงที่สุด: inverse ของ covariance ในสูตรจัดพอร์ต ทำไม sample covariance ของหุ้น 500 ตัวจากข้อมูลหนึ่งปีกลับด้านไม่ได้ และการ shrink ช่วยได้อย่างไร

ศัพท์ที่ใช้ในหัวข้อนี้
Range (column space)
output ทั้งหมด $A\mathbf x$ ที่สร้างได้ คือทุก linear combination ของคอลัมน์ ใช้ตอบว่าเป้าหมายมีคำตอบหรือไม่
Rank
จำนวนคอลัมน์ที่เป็น linearly independent หรือมิติของ range เท่ากับจำนวนแถวอิสระเสมอ และไม่เกินจำนวนแถวหรือคอลัมน์ ใช้นับทิศที่ตลาดหรือข้อมูลให้จริง
Null space
input ทั้งหมดที่ $A\mathbf x=\mathbf 0$ คือการเปลี่ยน holdings ที่ไม่เปลี่ยน output ใช้อธิบายว่าทำไมคำตอบมีหลายชุด
Invertible และ singular
matrix จัตุรัสที่มี $A^{-1}$ ซึ่ง $A^{-1}A=AA^{-1}=I$ เรียก invertible เกิดขึ้นเมื่อ rank เต็มพอดี ถ้าไม่มีเรียก singular
Determinant
ตัวเลขที่บอกว่า matrix จัตุรัสขยายพื้นที่ (หรือปริมาตร) กี่เท่า เป็นศูนย์เมื่อมีทิศถูกบี้หาย
Condition number
ตัวคูณที่บอกว่า error สัมพัทธ์ใน $\mathbf b$ อาจขยายเป็น error ใน $\mathbf x$ ได้กี่เท่า ใช้วัดความนิ่งของคำตอบ

ขั้นที่ 1 — range: ทุก payoff ที่สร้างได้

วางสามสัญญาเป็นคอลัมน์ แถวคือสถานะ แล้วดูว่า $S\boldsymbol\theta$ หน้าตาเป็นอย่างไรเมื่อ $\boldsymbol\theta$ เป็นอะไรก็ได้

\[\begin{aligned} S&=\begin{bmatrix}1&2&3\\2&4&6\end{bmatrix},\\ S\boldsymbol\theta&=\begin{bmatrix}\theta_1+2\theta_2+3\theta_3\\2(\theta_1+2\theta_2+3\theta_3)\end{bmatrix} =\lambda\begin{bmatrix}1\\2\end{bmatrix},\\ \lambda&=\theta_1+2\theta_2+3\theta_3. \end{aligned}\]

ทุก output คือ $(1,2)$ คูณตัวเลขหนึ่งตัว range จึงเป็นเส้นตรงผ่านจุดกำเนิด ไม่ใช่ทั้งระนาบ rank คือมิติของ range เท่ากับ 1 เป้าหมาย $(10,10)$ ต้องการ $\lambda=10$ และ $2\lambda=10$ พร้อมกัน ซึ่งขัดกัน จึงไม่มีคำตอบ

นับ rank ด้วยการลบแถวก็ได้: แถวสองลบสองเท่าของแถวแรกเหลือ $(0,0,0)$ เหลือแถวอิสระหนึ่งแถว ข้อเท็จจริงที่ใช้ได้เสมอคือจำนวนแถวอิสระเท่ากับจำนวนคอลัมน์อิสระ และไม่เกิน $\min(m,n)$ ตาราง $2\times3$ จึงมี rank ไม่เกิน 2 ไม่ว่ามีกี่สัญญา

ทำไม่ได้แบบพอดี ไม่ได้แปลว่าทำไม่ได้เลย พอร์ตที่จ่าย $(10,20)$ (อยู่บนเส้น) ครอบคลุมภาระ $(10,10)$ ได้แบบ superhedge ตามที่ตั้งโจทย์ใน linear constraints แต่มีส่วนเกินในสถานะลงที่ต้องจ่ายเงินซื้อ

ขั้นที่ 2 — null space: เปลี่ยน holdings แล้ว payoff ไม่เปลี่ยน

เป้าหมาย $(5,10)$ อยู่บนเส้น จึงทำได้ แต่ทำได้หลายแบบ ทุกแบบต่างกันด้วยการเปลี่ยนที่ $S$ ส่งไปศูนย์

\[\begin{aligned} S\begin{bmatrix}-2\\1\\0\end{bmatrix}&=\mathbf 0,\quad S\begin{bmatrix}-3\\0\\1\end{bmatrix}=\mathbf 0,\\ S\boldsymbol\theta=\begin{bmatrix}5\\10\end{bmatrix} &\ \text{exactly when}\ \ \boldsymbol\theta=\begin{bmatrix}5-2s-3t\\s\\t\end{bmatrix},\\ \dim\text{range}+\dim\text{null}&=1+2=3=n. \end{aligned}\]

การขายสัญญาแรก 2 หน่วยแล้วซื้อสัญญาที่สอง 1 หน่วยไม่เปลี่ยน payoff เลย เพราะสัญญาที่สองคือสัญญาแรกสองเท่า $(5,0,0)$, $(1,2,0)$ และ $(2,0,1)$ จ่าย $(5,10)$ เท่ากันหมด ถ้ามีคำตอบหนึ่งชุด $\boldsymbol\theta_0$ แล้ว $\boldsymbol\theta_0+\mathbf z$ ก็เป็นคำตอบเมื่อ $S\mathbf z=\mathbf 0$ และสองคำตอบใดก็ต่างกันด้วย $\mathbf z$ แบบนี้เสมอ

บรรทัดสุดท้ายคือ rank–nullity: input มี $n$ ทิศ ทุกทิศไปจบที่หนึ่งในสองที่ คือส่งผลต่อ output (นับเป็น rank) หรือหายไปใน null space ตาราง $m\times n$ ที่ rank $r$ มี null space มิติ $n-r$ รูปด้านล่างแสดงกับตาราง $2\times2$ ที่บี้ระนาบทั้งระนาบลงเป็นเส้น

ขั้นที่ 3 — matrix จัตุรัสกลับด้านได้เมื่อไร

matrix $n\times n$ ที่ rank เป็น $n$ ไม่มีทิศไหนถูกบี้ ทุก output มีคำตอบเดียว จึงมีเครื่องย้อน $A^{-1}$ ที่ $A^{-1}A=AA^{-1}=I$ กรณี $2\times2$ หาสูตรได้ตรง ๆ ด้วยการเดา matrix ที่สลับและเปลี่ยนเครื่องหมาย แล้วคูณดู

\[\begin{aligned} A&=\begin{bmatrix}a&b\\c&d\end{bmatrix},\quad B=\begin{bmatrix}d&-b\\-c&a\end{bmatrix},\\ AB&=BA=\begin{bmatrix}ad-bc&0\\0&ad-bc\end{bmatrix},\\ \det A&=ad-bc,\quad A^{-1}=\frac{1}{ad-bc}B. \end{aligned}\]

ผลคูณ $AB$ ได้ $ad-bc$ บนแนวทแยงและศูนย์ที่อื่น หารด้วย $ad-bc$ ก็ได้ identity ทำได้เมื่อ $ad-bc\ne0$ เท่านั้น ตัวเลขนี้คือ determinant และมีความหมายเป็นภาพ: $|\det A|$ คือพื้นที่ของสี่เหลี่ยมด้านขนานที่ $A$ ส่งจัตุรัสหนึ่งหน่วยไปถึง (เครื่องหมายลบแปลว่ารูปถูกพลิกด้านด้วย) determinant ศูนย์คือรูปถูกบี้แบนเป็นเส้น เหมือนตาราง $\begin{bmatrix}1&3\\2&6\end{bmatrix}$ ในรูปก่อน ที่ $1(6)-3(2)=0$

ตาราง $C=\begin{bmatrix}1&3\\2&1\end{bmatrix}$ ของสัญญาแรกกับสัญญาใหม่มี $\det C=1-6=-5$ จึงกลับด้านได้ และส่งจัตุรัสหนึ่งหน่วยไปเป็นสี่เหลี่ยมด้านขนานพื้นที่ 5 ดังรูปถัดไป

ขั้นที่ 4 — แก้โจทย์ของ hook ด้วย inverse

โจทย์ให้อะไรมาบ้าง: สัญญาแรก $(1,2)$ และสัญญาใหม่ $(3,1)$ เป้าหมาย $(10,10)$

\[\begin{aligned} C^{-1}&=\frac{1}{-5}\begin{bmatrix}1&-3\\-2&1\end{bmatrix} =\begin{bmatrix}-0.2&0.6\\0.4&-0.2\end{bmatrix},\\ C^{-1}\begin{bmatrix}10\\10\end{bmatrix}&=\begin{bmatrix}-2+6\\4-2\end{bmatrix}=\begin{bmatrix}4\\2\end{bmatrix}. \end{aligned}\]

คำตอบ: สัญญาแรก 4 หน่วย สัญญาใหม่ 2 หน่วย และเป็นคำตอบเดียวในตลาดสองสัญญานี้ $(4,2)$ คือ “พิกัด” ของ $(10,10)$ เมื่อใช้สองคอลัมน์เป็น basis แทนแกนนอนแกนตั้ง รูปด้านล่างวาดตารางพิกัดใหม่นี้

ข้อควรระวัง: คำตอบเดียวเฉพาะเมื่อมีแค่สองสัญญา ถ้าตลาดยังเก็บสามสัญญาเดิมไว้ครบ ตารางเป็น $2\times4$ rank 2 และ null space มีมิติ $4-2=2$ จึงมีหลายพอร์ตที่จ่าย $(10,10)$ เช่น $(4,0,0,2)$, $(2,1,0,2)$ และ $(1,0,1,2)$

ตรวจเองใน 10 วินาที: $4+6=10$ และ $8+2=10$

ขั้นที่ 5 — rank เต็มตามแถว แต่ห้าม short ทำให้ไปไม่ถึง

โจทย์ให้อะไรมาบ้าง: สองสัญญา $(1,2)$ และ $(3,1)$ เหมือนเดิม ลูกค้าต้องการ payoff $(6,0)$ คือจ่ายเฉพาะสถานะขึ้น และกองทุนห้าม short

\[\begin{aligned} C^{-1}\begin{bmatrix}6\\0\end{bmatrix}&=\begin{bmatrix}-0.2(6)\\0.4(6)\end{bmatrix}=\begin{bmatrix}-1.2\\2.4\end{bmatrix}. \end{aligned}\]

คำตอบ: พีชคณิตบอกว่าทำได้ (rank 2 ไปถึงทุกจุดในระนาบ) แต่คำตอบเดียวที่มีต้อง short สัญญาแรก 1.2 หน่วย ห้าม short จึงทำไม่ได้ ถ้าจำนวนหน่วยห้ามติดลบ สิ่งที่ไปถึงได้ไม่ใช่ทั้งระนาบ แต่เป็นแค่ “กรวย” ระหว่างสองทิศในรูปด้านล่าง $(10,10)$ อยู่ในกรวย $(6,0)$ อยู่นอก rank บอกได้แค่ว่ามีคำตอบในโลกที่ไม่มีข้อบังคับ ส่วนข้อบังคับเป็นงานของ linear constraints

ขนาดและ rank ของ $A$ ($m\times n$)มีคำตอบไหมคำตอบเดียวไหม
rank $=n$ (เต็มตามคอลัมน์)เฉพาะ $\mathbf b$ ใน rangeใช่ ถ้ามี
rank $=m$ (เต็มตามแถว)ทุก $\mathbf b$ไม่ ถ้า $n\gt m$
$m=n$ และ rank $=n$ทุก $\mathbf b$ใช่ มี $A^{-1}$
rank น้อยกว่าทั้ง $m$ และ $n$เฉพาะ $\mathbf b$ ใน rangeไม่

ขั้นที่ 6 — กลับด้านได้ แต่คำตอบไม่นิ่ง

คำถามข้อที่สามของหน้านี้ สองคอลัมน์ที่เกือบชี้ทิศเดียวกันยังกลับด้านได้ แต่ข้อมูลขยับนิดเดียวคำตอบกระโดดไกล

โจทย์ให้อะไรมาบ้าง: $A_\varepsilon=\begin{bmatrix}1&1\\1&1+\varepsilon\end{bmatrix}$ กับ $\varepsilon=0.001$ เป้าหมาย $\mathbf b=(2,\ 2+\varepsilon)$ ซึ่งมีคำตอบ $(1,1)$ แล้วเป้าหมายแถวสองขยับเพิ่ม $\eta=0.01$

\[\begin{aligned} x_1+x_2&=2,\\ x_1+(1+\varepsilon)x_2&=2+\varepsilon+\eta,\\ \text{(row 2)}-\text{(row 1)}:\ \ \varepsilon x_2&=\varepsilon+\eta,\\ x_2&=1+\eta/\varepsilon=11,\quad x_1=-9. \end{aligned}\]

คำตอบ: เป้าหมายขยับ 0.01 คำตอบกระโดดจาก $(1,1)$ เป็น $(-9,11)$ ขยายพันเท่า ($\eta/\varepsilon=10$) ไม่ใช่เพราะไม่มี inverse ($\det A_\varepsilon=0.001\ne0$) แต่เพราะสองคอลัมน์แทบแยกกันไม่ออก ภาพคือสองเส้นที่เกือบขนาน เลื่อนเส้นหนึ่งนิดเดียว จุดตัดวิ่งไปไกล

ตัววัดความไวนี้คือ condition number ใน matrix norm แบบผลรวมแถวมากสุด $\kappa_\infty(A)=\|A\|_\infty\|A^{-1}\|_\infty$ ได้ $(2+\varepsilon)^2/\varepsilon\approx4004$ error สัมพัทธ์ในข้อมูลจึงขยายได้ถึงราวสี่พันเท่าในคำตอบ ส่วน determinant ขนาดเล็กอย่างเดียวไม่ใช่สัญญาณเตือน: $10^{-6}I_2$ มี determinant $10^{-12}$ แต่ condition number เป็น 1 เพราะแค่ย่อทุกทิศเท่ากัน ในงานจริงใช้ QR หรือ SVD ตรวจ rank เชิงตัวเลขพร้อม tolerance ที่ระบุชัด

ขั้นที่ 7 — inverse ของ covariance ในสูตรจัดพอร์ต

โจทย์ mean–variance ที่มีสินทรัพย์ปลอดความเสี่ยงเลือกน้ำหนักสินทรัพย์เสี่ยง $\mathbf w$ เพื่อให้ $U(\mathbf w)=\boldsymbol\mu^{\mathsf T}\mathbf w-\tau\,\mathbf w^{\mathsf T}\Sigma\mathbf w$ สูงสุด โดย $\boldsymbol\mu$ คือผลตอบแทนส่วนเกินคาดหวังรายปี $\tau\gt0$ คือความกลัวความเสี่ยง และเงินที่เหลือ $1-\mathbf 1^{\mathsf T}\mathbf w$ อยู่ในสินทรัพย์ปลอดความเสี่ยง ตั้งอนุพันธ์เป็นศูนย์แล้วแก้ระบบ

\[\begin{aligned} \boldsymbol\mu-2\tau\Sigma\mathbf w&=\mathbf 0 \ \Longrightarrow\ \mathbf w^*=\frac{1}{2\tau}\Sigma^{-1}\boldsymbol\mu,\\ \Sigma&=\begin{bmatrix}0.04&0.02\\0.02&0.05\end{bmatrix},\quad \boldsymbol\mu=\begin{bmatrix}0.08\\0.04\end{bmatrix},\\ \Sigma^{-1}&=\frac{1}{0.0016}\begin{bmatrix}0.05&-0.02\\-0.02&0.04\end{bmatrix} =\begin{bmatrix}31.25&-12.5\\-12.5&25\end{bmatrix},\\ \Sigma^{-1}\boldsymbol\mu&=\begin{bmatrix}2.5-0.5\\-1+1\end{bmatrix}=\begin{bmatrix}2\\0\end{bmatrix},\quad \tau=2:\ \mathbf w^*=\begin{bmatrix}0.5\\0\end{bmatrix}. \end{aligned}\]

ระบบ $2\tau\Sigma\mathbf w=\boldsymbol\mu$ มีคำตอบเดียวเพราะ $\det\Sigma=0.04(0.05)-0.02^2=0.0016\ne0$ คำตอบคือลงเงิน 50% ในสินทรัพย์แรก ไม่ซื้อสินทรัพย์ที่สองเลย และอีก 50% อยู่ในสินทรัพย์ปลอดความเสี่ยง น่าแปลกที่สินทรัพย์ที่สองมีผลตอบแทนส่วนเกิน 4% แต่ได้ศูนย์ เหตุผลคือ 4% นั้นเท่ากับที่มัน “ควรได้” จากการขยับไปกับสินทรัพย์แรกพอดี ($0.04/0.08=0.02/0.04$) ถือมันไม่ได้อะไรเพิ่ม นอกจากความเสี่ยง

ตรวจว่าเป็นค่าสูงสุดจริง: เขียนพอร์ตอื่นเป็น $\mathbf w^*+\mathbf z$ แล้วกระจาย ใช้ $2\tau\Sigma\mathbf w^*=\boldsymbol\mu$ ตัดพจน์ไขว้ ได้ $U(\mathbf w^*+\mathbf z)=U(\mathbf w^*)-\tau\,\mathbf z^{\mathsf T}\Sigma\mathbf z$ ซึ่งไม่เกิน $U(\mathbf w^*)$ เพราะ $\mathbf z^{\mathsf T}\Sigma\mathbf z$ คือ variance ของพอร์ต $\mathbf z$ ที่ไม่ติดลบ

ถ้า $\Sigma$ singular เช่น $\begin{bmatrix}0.04&0.04\\0.04&0.04\end{bmatrix}$ พอร์ต $\mathbf z=(1,-1)$ มี variance ศูนย์ แต่ได้ผลตอบแทนคาดหวัง $\boldsymbol\mu^{\mathsf T}\mathbf z=0.04$ เพิ่ม $t\mathbf z$ ไปเรื่อย ๆ $U$ โตได้ไม่สิ้นสุด optimizer จะขยาย leverage ไม่หยุด สูตร mean–variance แบบมีเป้าหมายผลตอบแทนก็ต้องกลับด้าน matrix ใหญ่กว่าที่มี $\Sigma$ อยู่ข้างใน พร้อมแถว $\boldsymbol\mu^{\mathsf T}$ และ $\mathbf 1^{\mathsf T}$ ต่อท้าย ถ้าสินทรัพย์ทุกตัวมีผลตอบแทนคาดหวังเท่ากัน สองแถวนั้นขนานกัน matrix ก็ singular และตั้งเป้าหมายผลตอบแทนอื่นไม่ได้ รายละเอียดอยู่ที่ Markowitz portfolio selection

ขั้นที่ 8 — sample covariance ของหุ้น 500 ตัวจากข้อมูลหนึ่งปีกลับด้านไม่ได้

ให้ $R$ เป็นผลตอบแทน $T$ วัน (แถว) ของ $N$ หุ้น (คอลัมน์) ที่หักค่าเฉลี่ยของแต่ละคอลัมน์แล้ว sample covariance คือ $\widehat\Sigma=R^{\mathsf T}R/(T-1)$ ตาม matrix multiplication นับ rank ของมัน

\[\begin{aligned} \mathbf v^{\mathsf T}\widehat\Sigma\mathbf v&=\frac{\|R\mathbf v\|^2}{T-1},\\ \operatorname{rank}\widehat\Sigma&=\operatorname{rank}R\le\min(T-1,\ N),\\ T=250,\ N=500:\ \operatorname{rank}&\le249,\quad\text{null}\ge251. \end{aligned}\]

บรรทัดแรกบอกว่า $\widehat\Sigma\mathbf v=\mathbf 0$ เกิดขึ้นพร้อมกับ $R\mathbf v=\mathbf 0$ พอดี (ถ้า $\widehat\Sigma\mathbf v=0$ ด้านซ้ายเป็นศูนย์ จึงต้อง $R\mathbf v=0$) สอง matrix จึงมี null space เดียวกันและ rank เท่ากัน ทำไม $T-1$ ไม่ใช่ $T$: ทุกคอลัมน์ที่หักค่าเฉลี่ยแล้วรวมกันได้ศูนย์ แถวทั้ง $T$ จึงมีแถวที่ไม่อิสระอยู่หนึ่งแถวเสมอ

ข้อมูลรายวันหนึ่งปีราว 250 วันทำการ (หลังหักวันหยุดสุดสัปดาห์และวันหยุดตลาด) กับหุ้น 500 ตัว ให้ covariance ที่มีพอร์ตอย่างน้อย 251 ทิศที่ “ความเสี่ยงเป็นศูนย์” ตามข้อมูล ทั้งที่ในโลกจริงไม่มีพอร์ตหุ้นแบบนั้น นับจำนวนก็เห็นปัญหา: covariance มีตัวเลขอิสระ $N(N+1)/2=125{,}250$ ตัว แต่ข้อมูลมีแค่ $250\times500=125{,}000$ ตัว optimizer ที่เห็นทิศความเสี่ยงศูนย์จะทุ่มน้ำหนักเข้าไปที่ทิศนั้น ซึ่งคือการขยาย error ของการประมาณให้ใหญ่ที่สุด

ขั้นที่ 9 — ย่อส่วนให้เห็น: พอร์ตผีที่ความเสี่ยงเป็นศูนย์ และการ shrink

โจทย์ให้อะไรมาบ้าง: สองหุ้น สามวัน ผลตอบแทนเป็นเปอร์เซ็นต์ $(2,1)$, $(0,0)$, $(-2,-1)$ ค่าเฉลี่ยเป็นศูนย์อยู่แล้ว วันที่สี่เกิดขึ้นจริงเป็น $(1,\ 0.8)$

\[\begin{aligned} H&=\frac{(2,1)^{\mathsf T}(2,1)+(-2,-1)^{\mathsf T}(-2,-1)}{2} =\begin{bmatrix}4&2\\2&1\end{bmatrix},\\ \det H&=4-4=0,\quad \mathbf w=(1,-2):\ H\mathbf w=\mathbf 0,\\ \mathbf w^{\mathsf T}\mathbf r_4&=1(1)-2(0.8)=-0.6. \end{aligned}\]

คำตอบ: พอร์ต long หุ้นแรก 1 short หุ้นที่สอง 2 มี sample variance ศูนย์ เพราะทุกวันในข้อมูลหุ้นแรกขยับสองเท่าของหุ้นที่สองพอดี แต่วันที่สี่ทำให้มันขาดทุน 0.6% ทันที “ความเสี่ยงศูนย์” เป็นของข้อมูลชุดเล็ก ไม่ใช่ของโลก

วิธีแก้มาตรฐานคือ shrink: ผสม sample covariance กับเป้าหมายที่ไม่มีทิศศูนย์ เช่น identity คูณ variance เฉลี่ย $\bar s^2=(4+1)/2=2.5$ ด้วยสัดส่วน $\lambda=0.8$

\[\begin{aligned} V_{\text{sh}}&=\lambda H+(1-\lambda)\bar s^2I =\begin{bmatrix}3.7&1.6\\1.6&1.3\end{bmatrix},\\ \det V_{\text{sh}}&=4.81-2.56=2.25,\\ \mathbf w^{\mathsf T}V_{\text{sh}}\mathbf w&=3.7-6.4+5.2=2.5. \end{aligned}\]

ตารางใหม่กลับด้านได้ และพอร์ตผีมี variance 2.5 %² หรือความผันผวน $\sqrt{2.5}\approx1.58\%$ ต่อวัน ไม่ใช่ศูนย์อีกต่อไป ใกล้กับ 0.6% ที่เกิดจริงมากกว่าศูนย์ สัดส่วน 0.8 ในที่นี้เลือกด้วยมือ วิธี Ledoit–Wolf เลือกสัดส่วนจากข้อมูล ทางเลือกอื่นคือ factor model $B\Omega B^{\mathsf T}+D$ ที่ $D$ มี variance เฉพาะตัวเป็นบวกทุกช่อง เพราะ $\mathbf v^{\mathsf T}D\mathbf v\gt0$ ทุก $\mathbf v\ne\mathbf 0$ จึงไม่มีทิศศูนย์เหลือ

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

นับสินค้าแทนนับทิศ: สามสัญญาที่จ่าย $(1,2)$, $(2,4)$, $(3,6)$ มี rank 1 ไปถึงได้แค่เส้นเดียว เป้าหมาย $(10,10)$ ไม่มีคำตอบ

ใช้ inverse สำเร็จเป็นหลักฐานว่าคำตอบดี: $A_\varepsilon$ กลับด้านได้ แต่เป้าหมายขยับ 0.01 คำตอบกระโดดจาก $(1,1)$ ไป $(-9,11)$

ใช้ determinant เล็กเป็นเกณฑ์ singular: $10^{-6}I_2$ มี determinant $10^{-12}$ แต่ไม่มีปัญหาใด ๆ (condition number 1) เปลี่ยนหน่วยข้อมูลจากเปอร์เซ็นต์เป็นเศษส่วนก็ทำ determinant ของ covariance $2\times2$ เล็กลง $10^8$ เท่าได้แล้ว

ลืมข้อบังคับ: rank เต็มให้ $(6,0)$ ได้ในพีชคณิต แต่ต้อง short 1.2 หน่วย ถ้าห้าม short ไปไม่ถึง

เชื่อพอร์ตความเสี่ยงศูนย์จาก sample covariance: หุ้น 500 ตัวกับข้อมูล 250 วันให้ทิศความเสี่ยงศูนย์อย่างน้อย 251 ทิศ พอร์ตผี $(1,-2)$ ในตัวอย่างย่อส่วนขาดทุน 0.6% ในวันถัดไป

โจทย์ตรวจความเข้าใจ

1. ในตลาดสี่สัญญา $(1,2)$, $(2,4)$, $(3,6)$, $(3,1)$ ถ้าถือ $(2,1,0,2)$ แทน $(4,0,0,2)$ payoff เปลี่ยนไหม ตลาดนี้สร้างทุก payoff ในสองสถานะได้หรือไม่ (ไม่มีข้อห้าม short)

เฉลย

ไม่เปลี่ยน ผลต่าง $(-2,1,0,0)$ ให้ payoff $-2(1,2)+(2,4)=(0,0)$ จึงอยู่ใน null space ทั้งสองพอร์ตจ่าย $(10,10)$ ตลาดมี rank 2 เท่ากับจำนวนสถานะ (เต็มตามแถว) จึงสร้างทุก payoff ได้ แต่ null space มีมิติ $4-2=2$ holdings จึงไม่เป็นเอกลักษณ์

2. มีหุ้น 20 ตัวและข้อมูล 20 วัน หลังหักค่าเฉลี่ยแล้ว sample covariance กลับด้านได้ไหม ต้องมีข้อมูลอย่างน้อยกี่วัน

เฉลย

ไม่ได้ rank ไม่เกิน $\min(20-1,20)=19$ น้อยกว่า 20 ต้องมีอย่างน้อย $T-1\ge20$ คือ 21 วันจึงจะมีโอกาส rank เต็ม และแม้ครบ 21 วันก็ยังเป็นแค่เงื่อนไขจำเป็น ถ้าหุ้นบางตัวขยับเป็นสัดส่วนกันพอดีในข้อมูล rank ก็ยังลด และ covariance ที่ได้จะไม่นิ่ง (condition number สูง) เพราะข้อมูลเกือบไม่พอ

3. ใช้ $\Sigma$ และ $\boldsymbol\mu$ ในขั้น inverse ของ covariance ถ้าความกลัวความเสี่ยงลดเป็น $\tau=0.5$ น้ำหนักสินทรัพย์เสี่ยงและเงินในสินทรัพย์ปลอดความเสี่ยงเป็นเท่าไร

เฉลย

$\mathbf w^*=\frac{1}{2(0.5)}\Sigma^{-1}\boldsymbol\mu=(2,0)$ ลงสินทรัพย์แรก 200% ของเงินทุน เงินในสินทรัพย์ปลอดความเสี่ยงเป็น $1-2=-1$ คือกู้มาอีก 100% ความผันผวนพอร์ต $2\sqrt{0.04}=40\%$ ต่อปี สินทรัพย์ที่สองยังได้ศูนย์ เพราะ $\Sigma^{-1}\boldsymbol\mu$ ไม่ขึ้นกับ $\tau$ ทิศของพอร์ตเสี่ยงคงเดิม $\tau$ แค่กำหนดขนาด

คำนวณซ้ำด้วย JavaScript

โค้ดนับ rank ด้วยการลบแถว (มี tolerance ที่ระบุชัด) แก้ระบบ $2\times2$ ด้วย inverse และสร้างตัวอย่างพอร์ตผีกับการ shrink

เปิดดูโค้ด 
function rank(A, tol = 1e-10) {
  const R = A.map(r => r.slice()), m = R.length, n = R[0].length;
  let r = 0;
  for (let c = 0; c < n && r < m; c++) {
    let p = r;
    for (let i = r + 1; i < m; i++) if (Math.abs(R[i][c]) > Math.abs(R[p][c])) p = i;
    if (Math.abs(R[p][c]) <= tol) continue;
    [R[r], R[p]] = [R[p], R[r]];
    for (let i = r + 1; i < m; i++) {
      const f = R[i][c] / R[r][c];
      for (let j = c; j < n; j++) R[i][j] -= f * R[r][j];
    }
    r++;
  }
  return r;
}
const inv2 = ([[a, b], [c, d]]) => { const D = a * d - b * c;
  if (D === 0) throw new Error('singular'); return [[d / D, -b / D], [-c / D, a / D]]; };
const mv = (A, x) => A.map(r => r.reduce((s, v, j) => s + v * x[j], 0));
const quad = (A, x) => x.reduce((s, v, i) => s + v * mv(A, x)[i], 0);

console.log(rank([[1, 2, 3], [2, 4, 6]]), rank([[1, 2, 3, 3], [2, 4, 6, 1]])); // 1 2
const C = [[1, 3], [2, 1]];
console.log(mv(inv2(C), [10, 10]), mv(inv2(C), [6, 0]));  // [4,2]  [-1.2,2.4]

const e = 0.001, Ae = [[1, 1], [1, 1 + e]];
console.log(mv(inv2(Ae), [2, 2 + e]), mv(inv2(Ae), [2, 2 + e + 0.01])); // [1,1] [-9,11]

const S = [[0.04, 0.02], [0.02, 0.05]], mu = [0.08, 0.04], tau = 2;
console.log(mv(inv2(S), mu).map(v => v / (2 * tau)));    // [0.5, 0]

const H = [[4, 2], [2, 1]], ghost = [1, -2];               // percent^2
console.log(rank(H), mv(H, ghost), ghost[0] * 1 + ghost[1] * 0.8); // 1 [0,0] -0.6
const lam = 0.8, avg = (H[0][0] + H[1][1]) / 2;
const Vsh = H.map((r, i) => r.map((v, j) => lam * v + (i === j ? (1 - lam) * avg : 0)));
console.log(Vsh, quad(Vsh, ghost), Math.sqrt(quad(Vsh, ghost)));  // 2.5, 1.58

สิ่งที่ควรตอบได้หลังอ่าน

  • range คือทุก output ที่ไปถึงได้ rank คือจำนวนทิศอิสระ สามสัญญาที่ชี้ทิศเดียวมี rank 1 และสร้าง $(10,10)$ ไม่ได้
  • null space คือการเปลี่ยน holdings ที่ไม่เปลี่ยน payoff และ rank บวก nullity เท่ากับจำนวน input
  • matrix จัตุรัสกลับด้านได้เมื่อ rank เต็ม คือ determinant ไม่เป็นศูนย์ และ $|\det|$ คือตัวขยายพื้นที่
  • กลับด้านได้ไม่ได้แปลว่าคำตอบนิ่ง: condition number 4004 ทำให้เป้าหมายขยับ 0.01 แล้วคำตอบกระโดดไป $(-9,11)$
  • sample covariance มี rank ไม่เกิน $\min(T-1,N)$ หุ้น 500 ตัวกับ 250 วันจึงมีพอร์ตความเสี่ยงศูนย์ปลอม ๆ และ shrink หรือ factor model ใช้แก้
