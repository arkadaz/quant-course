7.5 Rank, Range, and Invertibility

มีคำตอบไหม มีคำตอบเดียวไหม และคำตอบไวต่อข้อมูลแค่ไหน เป็นคนละคำถาม

ตลาดจำลองมีสองสถานะ สัญญาสามตัวจ่าย $(1,2)$, $(2,4)$ และ $(3,6)$ USD ต่อหน่วย ถ้าต้องจ่าย 10 USD ในแต่ละสถานะ จะประกอบพอร์ตให้จ่ายพอดีได้หรือไม่?

ดูคำตอบ และสิ่งที่เปลี่ยนเมื่อเพิ่มสัญญา

ไม่ได้ เพราะไม่ว่าถืออย่างไร สถานะสองได้เงินสองเท่าของสถานะแรกเสมอ หากเพิ่มสัญญาที่จ่าย $(3,1)$ จะทำได้ เช่นถือสัญญาแรก 4 หน่วยและสัญญาใหม่ 2 หน่วย แต่ถ้ายังเก็บสามสัญญาเดิมไว้ จำนวนหน่วยที่ให้ payoff นี้ไม่ได้มีชุดเดียว

เราจะใช้ rank นับทิศ output ที่สร้างได้ ใช้ range ตรวจเป้าหมาย และใช้ null space อธิบายความไม่เป็นเอกลักษณ์ ก่อนแยกปัญหาเหล่านี้ออกจากความไม่เสถียรทางตัวเลข

1. Range คือ payoff ที่สร้างได้ ไม่ใช่จำนวนสินค้าที่มีขาย

เขียนตารางให้แถวเป็นสถานะและคอลัมน์เป็นสัญญา จำนวนหน่วยที่ถือคือ $\theta$ อนุญาตให้เป็นจำนวนจริงรวมถึง short ในการตรวจ linear span นี้ ทุกตัวเลขเป็นตัวอย่างสมมติ:

\[ \begin{aligned} S&=\begin{bmatrix}1&2&3\\2&4&6\end{bmatrix},\\ S\theta&=\begin{bmatrix}\theta_1+2\theta_2+3\theta_3\\2(\theta_1+2\theta_2+3\theta_3)\end{bmatrix}\\ &=\lambda\begin{bmatrix}1\\2\end{bmatrix},\qquad \lambda=\theta_1+2\theta_2+3\theta_3. \end{aligned} \]

Range หรือ column space คือเซตของ $S\theta$ ทั้งหมด จึงเป็นเส้นผ่าน $(1,2)$ ไม่ใช่ทั้งระนาบ สัญญาที่สองและสามเพียงเพิ่มขนาดของทิศเดิม Rank คือมิติของ range ในที่นี้เท่ากับ 1

ตรวจด้วยการกำจัดแถวก็ได้: ใช้แถวสองลบสองเท่าของแถวแรก เหลือ $\begin{bmatrix}1&2&3\\0&0&0\end{bmatrix}$ มี pivot หนึ่งตำแหน่ง การแปลงแถวแบบที่ย้อนกลับได้ไม่เปลี่ยน rank และจำนวนแถวอิสระเท่ากับจำนวนคอลัมน์อิสระ

ต้องการ exact hedge ของ $X=(10,10)$ จะบังคับทั้ง $\lambda=10$ และ $2\lambda=10$ ซึ่งขัดกัน แต่ $X'=(10,20)$ อยู่ใน range และทำได้หลายวิธี:

\[ \begin{aligned} \theta&=(10,0,0),\quad(0,5,0),\quad(4,0,2),\\ \lambda&=10\quad\text{in each case},\\ S\theta&=(10,20)^{\mathsf T}. \end{aligned} \]

“ทำ exact hedge ไม่ได้” ไม่ได้แปลว่า superhedge ไม่ได้ พอร์ตที่จ่าย $(10,20)$ ครอบคลุมภาระ $(10,10)$ แบบ $S\theta\ge X$ ได้ภายใต้สองสถานะนี้ แต่มีส่วนเกินและต้องตรวจต้นทุน/ข้อจำกัดเพิ่มเติมตาม 7.4

2. Null space บอกว่าเปลี่ยน holdings อย่างไรแล้ว output ไม่เปลี่ยน

Null space ของ $A$ คือเซตของ input $z$ ที่ $Az=0$ ถ้า $Ax_0=b$ แล้ว ทุก $x_0+z$ ที่ $z$ อยู่ใน null space ให้คำตอบเดิม เพราะ $A(x_0+z)=b+0$ ในทางกลับกัน ผลต่างของสองคำตอบก็ต้องถูกส่งไปศูนย์

\[ \begin{aligned} S\begin{bmatrix}-2\\1\\0\end{bmatrix}&=0,\qquad S\begin{bmatrix}-3\\0\\1\end{bmatrix}=0,\\ S\theta=(10,20)^{\mathsf T} &\ \Longleftrightarrow\ \theta=\begin{bmatrix}10-2s-3t\\s\\t\end{bmatrix},\quad s,t\in\mathbb R. \end{aligned} \]

มีตัวแปรอิสระสองตัว เพราะจากสาม input directions มีหนึ่งทิศที่ส่งผลต่อ output สำหรับ $A$ ขนาด $m\times n$ ที่มี rank $r$ ความสัมพันธ์นี้คือ rank–nullity:

\[ \dim\operatorname{Range}(A)=r,\qquad \dim\operatorname{Null}(A)=n-r. \]

Range อยู่ใน output space $\mathbb R^m$ ส่วน null space อยู่ใน input space $\mathbb R^n$ จึงไม่ควรวาดแล้วสรุปว่าทั้งคู่ตั้งฉากกันเสมอ เช่น $A=\begin{bmatrix}1&3\\2&6\end{bmatrix}$ มี range ตาม $(1,2)$ และ null ตาม $(-3,1)$ ซึ่ง dot product เท่ากับ −1 ไม่ใช่ศูนย์

นึกถึงกฎของเล่นที่ย่อข้อมูลสองช่องเป็นค่าเฉลี่ย $g(r,b)=(r+b)/2$ Input $(1,0)$ กับ $(0,1)$ ให้ 0.5 เท่ากัน เมื่อเก็บแต่ค่าเฉลี่ยก็ย้อนรู้คู่เดิมไม่ได้ อย่างไรก็ตาม หากเพิ่มข้อจำกัดบน input บางครั้งอาจเหลือคำตอบเดียวได้ ต้องตรวจระบบรวม ไม่ใช่ดู null space ของ matrix ตัวเดียวแล้วหยุด

3. กลับด้านได้ ต้องถามถึง shape ด้วย

เงื่อนไขของ $A$สิ่งที่สรุปได้ โดยยังไม่ใส่ข้อจำกัดอื่น
$m\times n$, rank $=n$Full column rank: มีอย่างมากหนึ่งคำตอบสำหรับแต่ละ $b$ แต่บาง $b$ อาจอยู่นอก range
$m\times n$, rank $=m$Full row rank: ทุก $b\in\mathbb R^m$ มีคำตอบ แต่เมื่อ $n\gt m$ จะไม่เป็นเอกลักษณ์
$n\times n$, rank $=n$ทุก $b$ มีคำตอบเดียว และมี two-sided inverse

เช่น $T=(1,2)^{\mathsf T}$ เป็น matrix $2\times1$ ที่มี full column rank เป้าหมาย $(10,20)$ มีคำตอบ 10 เพียงค่าเดียว แต่ $(10,10)$ ไม่มีคำตอบ จึงพูดไม่ได้ว่า “full column rank แล้วแก้ได้ทุกเป้าหมาย”

สำหรับ matrix จัตุรัส หากมี $z\ne0$ ที่ $Az=0$ จะมี input สองตัว $x$ กับ $x+z$ ให้ output เดิม จึงไม่มี inverse ที่ย้อนกลับได้อย่างเอกลักษณ์ ในทางกลับกัน rank เต็มทำให้คอลัมน์เป็น basis ของ output space และทุกเป้าหมายมีพิกัดเดียว

สูตร inverse ขนาด 2×2 มาจากไหน?
\[ \begin{aligned} A&=\begin{bmatrix}a&b\\c&d\end{bmatrix},\qquad B=\begin{bmatrix}d&-b\\-c&a\end{bmatrix},\\ AB=BA&=\begin{bmatrix}ad-bc&0\\0&ad-bc\end{bmatrix},\\ \det A&:=ad-bc,\\ A^{-1}&=\frac{B}{ad-bc},\qquad ad-bc\ne0. \end{aligned} \]

การหารด้วย determinant ทำให้ทั้งสองผลคูณเป็น identity เมื่อ determinant เป็นศูนย์ matrix 2×2 จะมีคอลัมน์ไม่อิสระและไม่มี inverse ไม่ใช่เพียงปัญหาที่โปรแกรมไม่ยอมให้หารด้วยศูนย์

ตัวอย่าง $\Sigma=\begin{bmatrix}1&1\\1&2\end{bmatrix}$ มี determinant 1 จึงมี inverse $\begin{bmatrix}2&-1\\-1&1\end{bmatrix}$ และ $x^{\mathsf T}\Sigma^{-1}x=2x_1^2-2x_1x_2+x_2^2=x_1^2+(x_1-x_2)^2$

ถ้า $\Sigma$ เป็น covariance และ $x$ เป็นความเบี่ยงเบนจากค่าเฉลี่ยในหน่วยเดียวกับข้อมูล จำนวนนี้เป็น standardized squared distance ที่ปรากฏใน multivariate Normal ไม่ใช่ variance ของพอร์ตน้ำหนัก $x$ เครื่องหมายลบใน inverse ก็ไม่ได้แปลว่า covariance เดิมติดลบ

กลับไปตลาดจำลอง เพิ่ม payoff $(3,1)$ แล้วเลือกสัญญาแรกกับสัญญาใหม่เป็น basis:

\[ \begin{aligned} C&=\begin{bmatrix}1&3\\2&1\end{bmatrix},\qquad \det C=1-6=-5,\\ C^{-1}&=\begin{bmatrix}-0.2&0.6\\0.4&-0.2\end{bmatrix},\\ C^{-1}\begin{bmatrix}10\\10\end{bmatrix} &=\begin{bmatrix}-2+6\\4-2\end{bmatrix}=\begin{bmatrix}4\\2\end{bmatrix}. \end{aligned} \]

พิกัด $(4,2)$ เป็นเอกลักษณ์ ใน basis สองสัญญานี้ แต่ตลาดที่เก็บครบสี่สัญญามี matrix $2\times4$ และ nullity 2 จึงยังมีหลาย holdings เช่น $(4,0,0,2)$, $(2,1,0,2)$ และ $(1,0,1,2)$ ล้วนจ่าย $(10,10)$

Full row rank จึงหมายถึง spanning ทุก payoff ในโมเดลสองสถานะที่อนุญาต unrestricted positions ไม่ได้รับรอง no-arbitrage หรือผ่านข้อห้าม short หากห้าม short เป้าหมาย $(1,0)$ ก็ทำไม่ได้ด้วยคอลัมน์บวกเหล่านี้ แม้ $C^{-1}(1,0)^{\mathsf T}=(-0.2,0.4)^{\mathsf T}$ จะเป็นคำตอบทางสมการ

4. Invertible ยังไม่พอ: เปลี่ยนข้อมูลนิดเดียว คำตอบอาจเปลี่ยนมาก

ให้ $A_\varepsilon=\begin{bmatrix}1&1\\1&1+\varepsilon\end{bmatrix}$ และ $b=(2,2+\varepsilon)^{\mathsf T}$ เมื่อ $\varepsilon\ne0$ มี determinant $\varepsilon$ และคำตอบ $(1,1)$

ถ้าเปลี่ยนเฉพาะ input เป้าหมายแถวสองเพิ่ม $\eta$ ใช้สมการแถวสองลบแถวแรกได้:

\[ \begin{aligned} x_1+x_2&=2,\\ x_1+(1+\varepsilon)x_2&=2+\varepsilon+\eta,\\ \varepsilon x_2&=\varepsilon+\eta,\\ x_2&=1+\eta/\varepsilon,\qquad x_1=1-\eta/\varepsilon. \end{aligned} \]

ที่ $\varepsilon=0.001$ การเปลี่ยนแถวสองเพียง 0.01 ทำให้คำตอบเปลี่ยนจาก $(1,1)$ เป็นประมาณ $(-9,11)$ ปัญหานี้ไม่ใช่เพราะไม่มี inverse แต่เพราะคอลัมน์เกือบเป็นทิศเดียวกัน

ทำไมขนาด determinant เพียงอย่างเดียวจึงเตือนเรื่องนี้ไม่ได้?

$10^{-6}I_2$ มี determinant เล็กถึง $10^{-12}$ แต่การคูณหรือหารทุกทิศด้วยสเกลเดียวกันไม่ได้ขยาย relative error อย่างไม่สมดุล ตรงข้ามกับ $A_\varepsilon$ ที่แทบแยกสองทิศไม่ออก

ตัววัดหนึ่งคือ condition number $\kappa_\infty(A)=\|A\|_\infty\|A^{-1}\|_\infty$ โดย matrix norm นี้คือผลรวม absolute values ของแถวที่มากที่สุด จากสูตร inverse ข้างบน สำหรับ $\varepsilon\gt0$ ได้:

\[ \begin{aligned} \|A_\varepsilon\|_\infty&=2+\varepsilon,\\ \|A_\varepsilon^{-1}\|_\infty&=(2+\varepsilon)/\varepsilon,\\ \kappa_\infty(A_\varepsilon)&=(2+\varepsilon)^2/\varepsilon\\ &=4004.001\quad(\varepsilon=0.001). \end{aligned} \]

ส่วน scaled identity ข้างต้นมี condition number 1 การตรวจ numerical rank ก็ต้องระบุ tolerance และ scaling ไม่ใช่ใช้ determinant cutoff เดียวกับทุกหน่วยข้อมูล ในงานจริงใช้วิธีที่เหมาะสม เช่น QR/SVD และตรวจ residual/ความไวต่อ perturbations

5. เหตุใด inverse จึงไปปรากฏในสูตรจัดพอร์ต?

ตั้งตัวอย่างใหม่ที่งวดหนึ่งปี ให้ $\mu=(0.08,0.04)^{\mathsf T}$ เป็น expected excess returns และ $\Sigma=\begin{bmatrix}0.04&0.02\\0.02&0.05\end{bmatrix}$ เป็น covariance ในหน่วย return เศษส่วนยกกำลังสอง กำหนดเป้าหมายแบบไม่มีข้อจำกัดน้ำหนัก $U(w)=\mu^{\mathsf T}w-\frac\gamma2w^{\mathsf T}\Sigma w$ โดย $\gamma\gt0$

$\Sigma$ เป็น positive definite เมื่อ $z^{\mathsf T}\Sigma z\gt0$ สำหรับทุก $z\ne0$ ซึ่งจะเรียนละเอียดใน 7.6 ตารางในตัวอย่างนี้ตรวจได้จาก:

\[ \begin{aligned} z^{\mathsf T}\Sigma z&=0.04(z_1+0.5z_2)^2+0.04z_2^2\\ &\gt0\quad\text{if }z\ne0. \end{aligned} \]

เลือก $w_*=(1/\gamma)\Sigma^{-1}\mu$ จะมี $\mu=\gamma\Sigma w_*$ เมื่อนำไปกระจายกำลังสองจึงได้:

\[ \begin{aligned} U(w_*+z)&=U(w_*)-\frac\gamma2z^{\mathsf T}\Sigma z\\ &\le U(w_*),\\ \Sigma^{-1}&=\frac1{0.04(0.05)-0.02^2} \begin{bmatrix}0.05&-0.02\\-0.02&0.04\end{bmatrix}\\ &=\begin{bmatrix}31.25&-12.5\\-12.5&25\end{bmatrix},\\ \gamma=1:\quad w_{*,1}&=31.25(0.08)-12.5(0.04)\\ &=2,\\ w_{*,2}&=-12.5(0.08)+25(0.04)=0. \end{aligned} \]

คำตอบนี้คือ risky exposure 200% ของ NAV ในตัวแรก ไม่ใช่สูตรจัดเงินแบบห้ามกู้โดยอัตโนมัติ หากให้เงินสดคงเหลือเท่ากับ $1-\sum w_i$ จะเป็น −100% ภายใต้สมมติฐาน financing ที่สอดคล้องกับ excess returns พอร์ตมี variance 0.16 และ SD 40% ต่อปี ถ้าบังคับ fully invested หรือกำหนด gross limit ต้องแก้ปัญหาที่มี constraints ใหม่

ส่วน $\Sigma_{\rm sing}=\begin{bmatrix}0.04&0.04\\0.04&0.04\end{bmatrix}$ ส่ง $z=(1,-1)$ ไปศูนย์ ถ้า $\mu=(0.08,0.04)$ จะมี $\mu^{\mathsf T}z=0.04$ การเพิ่ม $tz$ จึงเพิ่ม objective โดยไม่เพิ่ม model variance และทำให้ปัญหาไร้ขอบเขตหากไม่มี constraint ขวาง

แต่ถ้า expected return ในทุก null direction เป็นศูนย์ objective อาจเพียงแบนและมีหลายคำตอบ ไม่จำเป็นต้องไร้ขอบเขต ส่วนข้อจำกัดเพิ่มเติมอาจทำให้คำตอบเป็นเอกลักษณ์ได้ จึงไม่ควรสรุปว่า covariance singular แล้ว optimizer ทุกแบบจะขยาย leverage จนอนันต์เสมอ

6. Sample covariance: ข้อมูลกี่วันให้ทิศอิสระได้มากที่สุดเท่าไร?

ให้ $R$ มี $T$ แถววันที่ตรงกันและ $N$ คอลัมน์ assets หลังหักค่าเฉลี่ยของแต่ละคอลัมน์แล้ว จาก 7.3 sample covariance คือ $\widehat\Sigma=R^{\mathsf T}R/(T-1)$ สำหรับ $T\ge2$

\[ \begin{aligned} v^{\mathsf T}\widehat\Sigma v&=\frac{\|Rv\|_2^2}{T-1},\\ Rv=0&\ \Longleftrightarrow\ \widehat\Sigma v=0,\\ \operatorname{rank}(\widehat\Sigma)&=\operatorname{rank}(R)\le\min(T-1,N),\\ T=250,\ N=500:\quad \operatorname{rank}(\widehat\Sigma)&\le249,\\ \dim\operatorname{Null}(\widehat\Sigma)&\ge500-249=251. \end{aligned} \]

เหตุผลของ $T-1$ ไม่ใช่แค่ตัวหาร: centered columns ทุกคอลัมน์มีผลรวมศูนย์ จึงอยู่ใน subspace ของ $\mathbb R^T$ ที่มีมิติ $T-1$ ส่วน $R$ กับ covariance มี null space เดียวกันตามบรรทัดแรก จึงมี rank เท่ากัน

Covariance 500×500 มีช่องอิสระตามสมมาตร $500(501)/2=125{,}250$ ช่อง เทียบกับข้อมูล $250(500)=125{,}000$ ตัว การนับนี้บอกขนาดภาระการประมาณ แต่หลักฐานว่าตาราง singular คือ rank bound ด้านบน ไม่ใช่แค่เปรียบเทียบจำนวนตัวเลข

ย่อส่วนเป็นสามวันสมมติ $r=(0.02,0.01)$, $(0,0)$ และ $-r$ ทั้งสองคอลัมน์มี mean ศูนย์อยู่แล้ว จึงได้:

\[ \begin{aligned} H=\widehat\Sigma&=\frac{rr^{\mathsf T}+0+(-r)(-r)^{\mathsf T}}{3-1}\\ &=rr^{\mathsf T}=\begin{bmatrix}0.0004&0.0002\\0.0002&0.0001\end{bmatrix},\\ \det H&=4\times10^{-8}-4\times10^{-8}=0,\\ w&=(1,-2)^{\mathsf T},\\ Hw&=(0,0)^{\mathsf T},\qquad w^{\mathsf T}Hw=0. \end{aligned} \]

แม้ตัวเลข $rr^{\mathsf T}$ จะคำนวณได้จากหนึ่ง observation แต่ไม่ใช่ centered sample covariance ที่ประมาณจากวันเดียว เพราะตัวหาร $T-1$ จะเป็นศูนย์ ตัวอย่างสามวันข้างบนทำให้ความหมายทางสถิติครบ และแสดงอีกอย่างว่า $T\gt N$ ก็ยัง singular ได้หากข้อมูลซ้ำทิศ

Model variance ศูนย์ไม่ได้รับรองผลในอนาคต วันใหม่ที่ returns เป็น $(0.01,0.008)$ ให้พอร์ต $w=(1,-2)$ มี return $0.01-2(0.008)=-0.006$ หรือ −0.6% และ zero variance ของข้อมูลที่ center แล้วก็ไม่ได้หมายความว่า mean return ต้องศูนย์เสมอไป

7. Shrinkage ช่วยให้กลับด้านได้ โดยเพิ่มสมมติฐาน ไม่ใช่เพิ่มข้อมูล

เลือก covariance target $F=\operatorname{diag}(H)$ และผสม $\Sigma_\delta=(1-\delta)H+\delta F$ ในตัวอย่างนี้กำหนด $\delta=0.20$ ด้วยมือเพื่อให้คิดตามได้ ไม่ใช่ผลที่อ้างว่าคำนวณจากวิธีเลือก shrinkage intensity แบบ Ledoit–Wolf

\[ \begin{aligned} F&=\begin{bmatrix}0.0004&0\\0&0.0001\end{bmatrix},\\ \Sigma_{0.2}&=\begin{bmatrix}0.0004&0.00016\\0.00016&0.0001\end{bmatrix},\\ \det\Sigma_{0.2}&=4\times10^{-8}-(0.00016)^2=1.44\times10^{-8},\\ \Sigma_{0.2}^{-1}&\approx\begin{bmatrix}6944.4444&-11111.1111\\-11111.1111&27777.7778\end{bmatrix}. \end{aligned} \]

สำหรับ $w=(1,-2)$ ความเสี่ยงที่เคยเป็นศูนย์กลายเป็น $w^{\mathsf T}\Sigma_{0.2}w=0.00016$ หรือ SD ประมาณ 1.2649% ต่อวันตามโมเดลสมมตินี้ การคงแนวทแยงเดิมเป็นทางเลือกของ target ไม่ใช่หลักฐานว่า individual variances ถูกต้องแล้ว

เงื่อนไขที่รับประกัน positive definiteness คือ $H$ เป็น positive semidefinite, $F$ เป็น positive definite และ $0\lt\delta\le1$ เพราะสำหรับทุก $v\ne0$:

\[ \begin{aligned} v^{\mathsf T}\Sigma_\delta v&=(1-\delta)v^{\mathsf T}Hv\\ &\quad+\delta v^{\mathsf T}Fv\gt0. \end{aligned} \]

ถ้า diagonal target มีช่อง variance เป็นศูนย์ เงื่อนไขนี้อาจไม่ครบ และการผสมก็อาจยัง singular อยู่ เป้าหมายที่มี covariance นอกแนวทแยงเป็นศูนย์ก็ไม่ได้บอกว่า assets เป็นอิสระกันเสมอไป

Inverse ใหญ่ขึ้น 18 เท่า ไม่ได้แปลว่า normalized weights ใหญ่ขึ้น 18 เท่า

สำหรับ positive definite $\Sigma$ และโจทย์ minimum variance ที่อนุญาต short แต่กำหนด $\mathbf1^{\mathsf T}w=1$ ให้ $v=\Sigma^{-1}\mathbf1$ และ $w_*=v/(\mathbf1^{\mathsf T}v)$ จะมี $\Sigma w_* =\mathbf1/(\mathbf1^{\mathsf T}v)$

พอร์ตที่ผ่าน budget อีกตัวเขียนเป็น $w_*+z$ โดย $\mathbf1^{\mathsf T}z=0$ ดังนั้น:

\[ \begin{aligned} (w_*+z)^{\mathsf T}\Sigma(w_*+z) &=w_*^{\mathsf T}\Sigma w_*+z^{\mathsf T}\Sigma z\\ &\ge w_*^{\mathsf T}\Sigma w_*. \end{aligned} \]

Cross term หายเพราะ $z^{\mathsf T}\Sigma w_*=0$ จึงพิสูจน์สูตร normalized weights ได้ ไม่ใช่แค่จำว่าต้องใช้ inverse

8. ทางเลือกอื่นต้องแก้โจทย์ข้อมูลด้วย ไม่ใช่แค่ทำให้ไม่มี error

Diagonal loading: เติม $\lambda I$ โดย $\lambda\gt0$ ให้ $v^{\mathsf T}(H+\lambda I)v=v^{\mathsf T}Hv+\lambda\|v\|_2^2\gt0$ ในตัวอย่างเลือก $\lambda=2\times10^{-5}$ จะมี determinant $1.04\times10^{-8}$ และ variance ของ $(1,-2)$ เป็น 0.0001 การเลือก $\lambda$ ขึ้นกับหน่วย covariance และความเหมาะสมของโมเดล

Factor covariance: ใช้ $B\Omega B^{\mathsf T}+D$ โดย $\Omega$ เป็น PSD และ $D$ เป็น diagonal ที่มีค่าบวกทุกช่อง จะมี $v^{\mathsf T}B\Omega B^{\mathsf T}v\ge0$ และ $v^{\mathsf T}Dv\gt0$ จึงเป็น PD ส่วน idiosyncratic variance นี้สำคัญ: เก็บเพียง $K$ factors โดยตัด $D$ ทิ้งยังมี rank ไม่เกิน $K$

สำหรับ $N=500$, $K=4$ ต้องเก็บ loadings $500(4)=2000$ ค่า, factor covariance $4(5)/2=10$ ค่า และ diagonal residual อีก 500 ค่า รวม 2,510 เทียบกับ 125,250 ประมาณ 50 เท่าน้อยกว่า นี่คือจำนวนตัวเลขตาม parameterization นี้ ไม่ได้แปลว่าทุก parameter ระบุได้อย่างเอกลักษณ์หรือว่าความเสี่ยงจริงมีเพียงสี่ทิศ

PCA และข้อมูลเพิ่มเติม: หากสาม components อธิบาย variance ได้ 97% ในชุดข้อมูลหนึ่ง ยังเหลือ 3% ไม่ใช่ศูนย์ จึงไม่ใช่ข้อพิสูจน์ว่า exact rank เท่ากับ 3 การตัดเหลือสามทิศเปลี่ยนโมเดล ส่วนการมีหลายปีข้อมูลก็อาจผสม regimes ที่ไม่เหมือนกัน

สำหรับ centered sample covariance ต้องมีอย่างน้อย $T\ge N+1$ จึงจะเป็น full rank ได้ แต่ยังต้องไม่มี dependence ที่ทำให้ rank ลด เงื่อนไขเช่น $T\ge2N$ ไม่ใช่หลักประกันว่าประมาณ covariance ได้แม่น ต้องดูความเสถียรและทดสอบ out of sample เพิ่ม

function shape(A) {
  if (!Array.isArray(A) || !A.length || !Array.isArray(A[0]) || !A[0].length) throw new TypeError('Need a rectangular matrix');
  const n = A[0].length;
  if ([...A].some(row => !Array.isArray(row) || row.length !== n || ![...row].every(Number.isFinite))) throw new TypeError('Need a finite rectangular matrix');
  return [A.length, n];
}
function dot(a, b) {
  if (!Array.isArray(a) || !Array.isArray(b) || !a.length || a.length !== b.length || ![...a, ...b].every(Number.isFinite)) throw new TypeError('Need matching finite vectors');
  const result = a.reduce((s, x, i) => s + x * b[i], 0);
  if (!Number.isFinite(result)) throw new RangeError('Arithmetic overflow');
  return result;
}
function matvec(A, x) { shape(A); return A.map(row => dot(row, x)); }
function transpose(A) { const [, n] = shape(A); return Array.from({length: n}, (_, j) => A.map(row => row[j])); }
function multiply(A, B) { shape(A); const Bt = transpose(B); return A.map(row => Bt.map(col => dot(row, col))); }
function numericalRank(A, tolerance = 1e-10) {
  const [m, n] = shape(A);
  if (!Number.isFinite(tolerance) || tolerance < 0 || tolerance >= 1) throw new RangeError('Invalid rank tolerance');
  const scale = A.flat().reduce((s, x) => Math.max(s, Math.abs(x)), 0);
  if (scale === 0) return 0;
  const R = A.map(row => row.map(x => x / scale));
  let rank = 0;
  for (let col = 0; col < n && rank < m; col++) {
    let pivot = rank;
    for (let i = rank + 1; i < m; i++) if (Math.abs(R[i][col]) > Math.abs(R[pivot][col])) pivot = i;
    if (Math.abs(R[pivot][col]) <= tolerance) continue;
    [R[rank], R[pivot]] = [R[pivot], R[rank]];
    for (let i = rank + 1; i < m; i++) {
      const factor = R[i][col] / R[rank][col];
      R[i][col] = 0;
      for (let j = col + 1; j < n; j++) R[i][j] -= factor * R[rank][j];
    }
    rank++;
  }
  return rank;
}
function solve2(A, rhs) {
  const [m, n] = shape(A);
  if (m !== 2 || n !== 2) throw new RangeError('Need a 2 by 2 matrix');
  dot(rhs, [0, 0]);
  const scale = A.flat().reduce((s, x) => Math.max(s, Math.abs(x)), 0);
  if (scale === 0) throw new RangeError('Singular system in working precision');
  let [[a, b], [c, d]] = A.map(row => row.map(x => x / scale));
  let [r, s] = rhs.map(x => x / scale);
  if (Math.abs(c) > Math.abs(a)) { [a, b, c, d] = [c, d, a, b]; [r, s] = [s, r]; }
  if (a === 0) throw new RangeError('Singular system in working precision');
  const factor = c / a, pivot = d - factor * b;
  if (pivot === 0) throw new RangeError('Singular system in working precision');
  const y = (s - factor * r) / pivot, x = (r - b * y) / a;
  if (![x, y].every(Number.isFinite)) throw new RangeError('Arithmetic overflow');
  return [x, y];
}
function inverse2(A) { const c1 = solve2(A, [1, 0]), c2 = solve2(A, [0, 1]); return [[c1[0], c2[0]], [c1[1], c2[1]]]; }
function det2(A) { const [m, n] = shape(A); if (m !== 2 || n !== 2) throw new RangeError('Need a 2 by 2 matrix'); return A[0][0] * A[1][1] - A[0][1] * A[1][0]; }
const normInfinity = A => { shape(A); return Math.max(...A.map(row => row.reduce((s, x) => s + Math.abs(x), 0))); };
const quadratic = (A, x) => dot(x, matvec(A, x));
function sampleCovariance(rows) {
  const [T, n] = shape(rows);
  if (T < 2) throw new RangeError('Need at least two observations');
  // Shift before averaging so constant columns stay exactly zero.
  const offsets = rows.map(row => row.map((x, j) => x - rows[0][j]));
  const means = Array.from({length: n}, (_, j) => offsets.reduce((s, row) => s + row[j] / T, 0));
  const R = offsets.map(row => row.map((x, j) => x - means[j]));
  return multiply(transpose(R), R).map(row => row.map(x => x / (T - 1)));
}

  if (!Number.isFinite(delta) || delta < 0 || delta > 1) throw new RangeError('Invalid shrinkage intensity');
  return H.map((row, i) => row.map((x, j) => i === j ? x : (1 - delta) * x));
}

  return {matrix: A, determinant: det2(A), inverse, ghostVariance: quadratic(A, ghost),

}

Existence: เป้าหมายอยู่ใน range หรือเป็นเพียงคำตอบใกล้เคียงแบบ least squares? Uniqueness: มี null directions เหลือหลังใส่ constraints หรือไม่? Stability: เปลี่ยนข้อมูลเล็กน้อยแล้ว holdings เปลี่ยนมากเพียงใด?

สิ่งที่ควรตรวจ ก่อนสั่ง inverse

  • ระบุ shape และ input/output space: full row rank กับ full column rank ตอบคนละคำถาม
  • Exact hedge ต้องอยู่ใน range; null space อธิบายหลาย holdings แต่ constraints อาจตัดบางคำตอบออก
  • Invertible ไม่เท่ากับ well-conditioned และ small determinant ไม่ใช่เกณฑ์สากล
  • Centered sample covariance มี rank ไม่เกิน $\min(T-1,N)$; ข้อมูลมากพอด้านจำนวนยังอาจซ้ำทิศ
  • Regularization ช่วยกำหนดโมเดลใหม่ให้คำนวณได้ แต่ต้องตรวจ assumptions, constraints และผลนอก sample ต่อ
