20.4 Caps, Floors, and Swaptions on the Lattice

caplet และ floorlet คือ option บนอัตราของงวดเดียวที่กำหนดวันหนึ่งแต่จ่ายอีกวันหนึ่ง swaption คือสิทธิ์เข้า swap ทั้งสัญญาครั้งเดียว ทั้งหมดตั้งราคาได้บนต้นไม้ของ short rate ถ้าวางนาฬิกาของเงินให้ถูก

บริษัทแห่งหนึ่งกู้เงินแบบดอกเบี้ยลอยตัว แปลว่าดอกเบี้ยไม่ได้ตายตัว ทุกต้นงวดธนาคารจะตั้งอัตราของงวดนั้นใหม่ตามอัตราตลาดตอนนั้น บริษัทกลัวว่าอัตราจะพุ่งจนจ่ายดอกเบี้ยไม่ไหว จึงอยากซื้อประกันที่เรียกว่า caplet ถ้าอัตราของงวดสูงกว่าเพดานที่ตกลงไว้ caplet จะจ่ายส่วนที่เกินให้บริษัท เพดานนี้เรียกว่า strike

ของที่รู้ (ตัวเลขสมมติ):

  • เงินต้น $N=\$10{,}000{,}000$
  • งวดที่ประกันคือครึ่งปีจากปีที่ 1 ถึงปีที่ 1.5 ยาว $\delta=0.5$ ปี อัตราของงวดถูกตั้งที่ปีที่ 1 แต่ดอกเบี้ยจ่ายจริงตอนปลายงวด คือปีที่ 1.5
  • strike $K=5.25\%$ ต่อปี
  • อัตราที่ปีที่ 1 ยังไม่มีใครรู้ แต่หน้า ต้นไม้ของ short rate สร้างแผนภาพที่แตกกิ่งทุกครึ่งปีเป็นอัตราที่อาจเกิดขึ้น (short rate คืออัตราดอกเบี้ยของช่วงสั้น ๆ ช่วงถัดไป) แผนภาพนี้เรียกว่าต้นไม้ และบอกว่าที่ปีที่ 1 อัตราเป็นได้สามค่า คือ 7%, 5% หรือ 3% ต่อปี
  • state price ของจุด 7% คือ $Q_{7\%}=0.2366213$ หมายถึงราคาวันนี้ของเงิน \$1 ที่จะได้ ที่ปีที่ 1 เฉพาะในกรณีที่อัตราไปถึง 7% (ตัวเลขนี้มาจากหน้าต้นไม้เดียวกัน)

ถ้าอัตราขึ้นไปเป็น 7% caplet จ่ายดอกเบี้ยส่วนที่เกินเพดาน คิดเป็นเงินได้

\[\begin{aligned}\Pi&=N\delta\,(0.07-K)\\&=10^7\times0.5\times(0.07-0.0525)\\&=\$87{,}500.\end{aligned}\]

เพื่อนในทีมเอาเงินก้อนนี้คูณ state price ตรง ๆ ได้ราคา caplet เป็น $87{,}500\times0.2366213=\$20{,}704.36$ ราคานี้ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก state price แปลงเงินที่ได้ ที่ปีที่ 1 เป็นเงินวันนี้ แต่ caplet จ่ายที่ปีที่ 1.5 ช้ากว่านั้นครึ่งปี เงินที่มาช้ามีค่าน้อยกว่า จึงต้องคิดลดครึ่งปีนั้นก่อน ต้นไม้นี้คิดดอกเบี้ยแบบทบต่อเนื่อง เงิน \$1 ที่มาช้าไป $\delta$ ปีจึงมีค่า $e^{-r\delta}$ และอัตรา $r$ ที่ใช้คือ 7% ของกรณีนั้นเอง

\[\begin{aligned}V_1&=87{,}500\,e^{-0.07\times0.5}\\&=87{,}500\times0.9656054\\&=\$84{,}490.47,\\V_0&=84{,}490.47\times0.2366213\\&=\$19{,}992.24.\end{aligned}\]

$V_1$ คือค่าของเงินก้อนนี้ ณ ปีที่ 1 และ $V_0$ คือค่าของมันวันนี้ เพื่อนตั้งราคาสูงไป $20{,}704.36-19{,}992.24=\$712.12$ เพราะนับว่าเงินมาถึงเร็วกว่าจริงหกเดือน

ภาพรวมก่อนลงสูตร

บริษัทที่กู้ลอยตัวกลัวว่าอัตราจะขึ้นแรงจนจ่ายดอกเบี้ยไม่ไหว ทางหนึ่งคือทำ swap ซึ่งเปลี่ยนดอกเบี้ยลอยตัวเป็นดอกเบี้ยคงที่ แต่ถ้าวันหลังอัตราลง บริษัทก็ยังต้องจ่ายอัตราคงที่สูง ๆ อยู่ดี อีกทางคือซื้อ cap ซึ่งเป็นประกันทีละงวด งวดไหนอัตราเกินเพดาน cap จ่ายส่วนเกินให้ งวดไหนอัตราต่ำ บริษัทก็จ่ายดอกเบี้ยต่ำตามตลาด ประกันของงวดเดียวเรียกว่า caplet และ cap คือ caplet หลายงวดรวมกัน

สัญญาอีกสองแบบในหน้านี้เป็นญาติกัน floor เป็นด้านกลับของ cap คือจ่ายเมื่ออัตราต่ำกว่าพื้น คนที่ซื้อคือคนที่ ได้รับ ดอกเบี้ยลอยตัว เช่น ผู้ให้กู้ ส่วน swaption คือสิทธิ์ที่จะเข้าทำ swap ทั้งสัญญาในวันหนึ่งข้างหน้า ถ้าวันนั้นไม่คุ้มก็ไม่ต้องเข้า

ทั้งสามแบบจ่ายเงินเฉพาะบางกรณี ราคาจึงขึ้นกับว่าอัตราในอนาคตออกมาเป็นค่าไหนได้บ้าง และแต่ละกรณีมีราคาวันนี้เท่าไร ข้อมูลนี้ได้มาแล้วจาก ต้นไม้ของ short rate และ state price รูปด้านล่างแสดงว่า caplet และ floorlet จ่ายเท่าไรเมื่ออัตราของงวดเป็นค่าต่าง ๆ และมีจุดสามจุดของต้นไม้ที่โจทย์เปิดหน้าใช้

ส่วนที่ยากของหน้านี้ไม่ใช่สูตร แต่คือ “นาฬิกา” สัญญาเดียวมีได้ถึงสามวัน วันที่อัตราของงวดถูกตั้ง (reset) วันที่เงินจ่ายจริง (payment) และวันที่ต้องตัดสินใจว่าจะใช้สิทธิ์ไหม (exercise) ถ้าคิดลดผิดวัน ราคาจะผิดแบบเงียบ ๆ เหมือนในโจทย์เปิดหน้า

ลำดับของหน้า:

  • ตั้งราคา caplet และ floorlet บนต้นไม้สามชั้นของโจทย์เปิดหน้า
  • ตรวจคำตอบด้วย cap–floor parity ซึ่งใช้แค่ราคาพันธบัตรวันนี้ ไม่ต้องเชื่อต้นไม้
  • ตั้งราคา swaption บนต้นไม้เดียวกัน
  • ย้ายไปต้นไม้ที่ใหญ่ขึ้น (เริ่ม 6% ห้างวด) เพื่อตั้งราคา caplet, swap, swaption และ swap ที่เริ่มในอนาคต
  • ปิดด้วยต้นไม้ BDT สองต้นที่ตรงกับราคาตลาดของพันธบัตรเท่ากัน แต่ให้ราคา swaption ต่างกันเกือบครึ่ง

หมายเหตุเรื่องเศษ: ตัวเลขกลางทางในหน้านี้ปัดไว้ 4–7 หลัก แต่ผลลัพธ์คำนวณจากค่าเต็ม (โค้ดท้ายหน้า) ถ้ากดเครื่องคิดเลขตามตัวเลขที่ปัดแล้ว อาจคลาดไปไม่กี่สตางค์

ศัพท์ที่ใช้ในหัวข้อนี้
Caplet และ cap
caplet คือประกันดอกเบี้ยของงวดเดียว ถ้าอัตราของงวดสูงกว่า strike (เพดานที่ตกลงไว้) caplet จ่ายส่วนที่เกิน คูณเงินต้น คูณความยาวงวด ถ้าไม่เกินก็ไม่จ่าย มันจึงเป็น option (สิทธิ์ที่ใช้เมื่อคุ้ม ไม่ใช่ภาระ) แบบ call บนอัตราดอกเบี้ย cap คือ caplet หลายงวดที่ใช้ strike เดียวกัน ผู้กู้ลอยตัวซื้อเพื่อกันไม่ให้ดอกเบี้ยเกินเพดาน
Floorlet และ floor
ด้านกลับของ caplet จ่ายเมื่ออัตราต่ำกว่า strike เป็น option แบบ put บนอัตรา คนที่ได้รับดอกเบี้ยลอยตัว เช่น ผู้ให้กู้ ซื้อไว้กันไม่ให้รายรับต่ำเกินไป floor คือ floorlet หลายงวดรวมกัน
Reset date และ payment date
reset date คือวันที่อัตราของงวดถูกตั้ง payment date คือวันที่เงินของงวดนั้นจ่ายจริง ปกติคือปลายงวด (เรียกว่า settled in arrears) ทุกครั้งที่คิดลด ต้องแยกสองวันนี้ออกจากกัน
Payer และ receiver swaption
สิทธิ์ที่จะเข้าทำ swap ในวันหนึ่งข้างหน้า โดยใช้อัตราคงที่ $K$ ที่ตกลงไว้วันนี้ payer swaption คือสิทธิ์เป็นฝั่ง จ่าย อัตราคงที่ จะคุ้มเมื่อ swap rate ของตลาดตอนนั้นสูงกว่า $K$ บริษัทที่จะกู้ในอนาคตใช้มันล็อกต้นทุน receiver swaption คือสิทธิ์เป็นฝั่ง รับ อัตราคงที่ คุ้มเมื่อ swap rate ต่ำกว่า $K$
FRA (forward rate agreement)
สัญญาล็อกอัตราของงวดเดียว จ่าย $N\delta(L-K)$ ทุกกรณี ฝั่งที่รับเงินก้อนนี้ได้เงินเมื่ออัตราสูงกว่า $K$ และเสียเงินเมื่ออัตราต่ำกว่า $K$ ไม่มีสิทธิ์เลือก
Cap–floor parity
ซื้อ caplet และขาย floorlet ที่ strike เดียวกัน เงินที่ได้สุทธิเท่ากับ FRA พอดีทุกกรณี ราคาของผลต่างนี้จึงหาได้จากราคาพันธบัตรวันนี้อย่างเดียว ไม่ต้องรู้ว่าอัตราแกว่งแรงแค่ไหน ใช้ตรวจว่าโค้ดตั้งราคาไม่มีบั๊ก
Forward-start swap
swap ที่ตกลงกันวันนี้ แต่งวดแรกเริ่มในอนาคต ตั้งราคาได้โดยคิดลดเงินแต่ละก้อนกลับไปที่จุดที่อัตราของมันถูกตั้ง คูณ state price ของจุดนั้น แล้วบวกกัน

ขั้นที่ 1 — caplet และ floorlet: จ่ายเท่าไร และจ่ายเมื่อไร

ก่อนจะตั้งราคาอะไร ต้องรู้ให้ชัดก่อนว่าสัญญาจ่ายเงินเท่าไร และจ่ายวันไหน ให้ $L$ เป็นอัตราของงวด (ต่อปี) อัตรานี้ถูกตั้งที่วัน reset $T$ แต่เงินจ่ายที่ปลายงวด $T+\delta$ ดอกเบี้ยของงวดคือเงินต้นคูณอัตราต่อปีคูณความยาวงวด caplet จึงจ่ายส่วนที่เกิน strike คิดแบบเดียวกัน

\[ \begin{aligned} \Pi^{\rm cap}&=N\delta\,(L-K)^+,\\ \Pi^{\rm floor}&=N\delta\,(K-L)^+,\\ x^+&=\max(x,\ 0). \end{aligned} \]

เครื่องหมาย $^+$ คือหัวใจของสูตร ถ้าอัตราต่ำกว่า strike ค่า $L-K$ ติดลบ แต่ผู้ถือ caplet ไม่ต้องจ่ายเงินคืน เพราะ caplet เป็นสิทธิ์ ไม่ใช่ภาระ เงินที่ได้จึงเป็นศูนย์ ไม่ติดลบ floorlet กลับทางกัน ได้เงินเมื่ออัตราต่ำกว่า strike ดังนั้น caplet คือ call บนอัตรา และ floorlet คือ put บนอัตรา

ตัวอย่างของหน้านี้ใช้ $N=\$10{,}000{,}000$, $\delta=0.5$ ปี และ $K=5.25\%$ อัตราถูกตั้งที่ปีที่ 1 และเงินจ่ายที่ปีที่ 1.5 เพื่อให้เห็นกลไกง่ายที่สุด สัญญาฝึกนี้ใช้ short rate ของจุดในต้นไม้เป็นอัตราของงวดตรง ๆ คือ $L_j=r_j$ สัญญาที่ซื้อขายจริงใช้อัตราอีกแบบ คืออัตรา simple (อัตราแบบดอกเบี้ยไม่ทบ) ขั้นที่ 4 จะแปลงให้ดูว่าราคาเปลี่ยนไปเท่าไร

ใส่อัตราสามค่าของต้นไม้ที่ปีที่ 1 (7%, 5% และ 3%) ลงในสูตร โดย $N\delta=10^7\times0.5=5\times10^6$:

\[ \begin{aligned} \Pi^{\rm cap}_{7\%}&=5\times10^6\times(0.07-0.0525)\\ &=\$87{,}500,\\ \Pi^{\rm floor}_{5\%}&=5\times10^6\times(0.0525-0.05)\\ &=\$12{,}500,\\ \Pi^{\rm floor}_{3\%}&=5\times10^6\times(0.0525-0.03)\\ &=\$112{,}500. \end{aligned} \]

ที่จุด 5% และ 3% อัตราไม่ถึง strike caplet จึงจ่ายศูนย์ ที่จุด 7% อัตราสูงกว่า strike floorlet จึงจ่ายศูนย์ ตัวเลขทั้งสามคือจุดกลมในรูปด้านบน

ขั้นที่ 2 — ราคา caplet: คิดลดสองช่วง ช่วงหนึ่งอยู่ใน state price อีกช่วงต้องใส่เอง

ตอนนี้รู้แล้วว่า caplet จ่ายเท่าไร ต่อไปต้องแปลงเงินนั้นเป็นเงินวันนี้ เครื่องมือที่มีคือ state price $Q_j$ แต่ $Q_j$ แปลงได้เฉพาะเงินที่ได้ ที่วัน reset (ปีที่ 1) ส่วน caplet จ่ายที่ปีที่ 1.5 จึงต้องถอยเงินสองช่วง ช่วงแรกถอยจากปีที่ 1.5 มาปีที่ 1 ด้วยตัวคูณ $e^{-r_j\delta}$ ช่วงที่สองถอยจากปีที่ 1 มาวันนี้ด้วย $Q_j$ แล้วบวกทุกจุด

\[ \begin{aligned} V_1(j)&=e^{-r_j\delta}\,\Pi_j,\\ V_0&=\sum_jQ_j\,V_1(j). \end{aligned} \]

$V_1(j)$ คือค่าของเงินก้อนนั้น ณ วัน reset ในกรณีที่อัตราอยู่ที่จุด $j$ ช่วงแรกใช้อัตรา $r_j$ ของจุดนั้นเอง ไม่ใช่อัตราของวันนี้ ทำไมใช้ได้? เพราะที่วัน reset อัตราของงวดถัดไปรู้แล้วว่าเป็น $r_j$ เงินที่ปลายงวดจึงเป็นเงินที่แน่นอน คิดลดครึ่งปีด้วย $r_j$ ได้ตรง ๆ ในโลกที่อัตราขึ้นเป็น 7% เงินครึ่งปีหลังก็ต้องคิดลดด้วย 7%

caplet จ่ายเงินแค่ที่จุด 7% ผลบวกจึงเหลือพจน์เดียว:

\[ \begin{aligned} V_1(7\%)&=87{,}500\,e^{-0.07\times0.5}\\ &=87{,}500\times0.9656054\\ &=\$84{,}490.47,\\ V_0&=0.2366213\times84{,}490.47\\ &=\$19{,}992.24. \end{aligned} \]

ถ้าลืมช่วงแรกจะได้ \$20,704.36 แบบเพื่อนในโจทย์เปิดหน้า ความผิดนี้ทำให้ราคาสูงไป ทุกครั้ง ไม่ใช่สูงบ้างต่ำบ้าง เพราะ $e^{-r\delta}$ น้อยกว่า 1 เสมอ และมองไม่เห็นจนกว่าจะเทียบกับราคาตลาด

ต้นไม้บางแบบคิดดอกเบี้ยทบทีละงวดแทนทบต่อเนื่อง ตัวคูณของช่วงแรกจึงเป็น $1/(1+r)$ แทน $e^{-r\delta}$ caplet ที่อัตราถูกตั้งที่งวด $\tau-1$ และจ่าย $(r_{\tau-1}-K)^+$ ที่งวด $\tau$ จึงมีค่า $(r_{\tau-1}-K)^+/(1+r_{\tau-1})$ ที่งวด $\tau-1$ ขั้นที่ 6 จะใช้รูปนี้

ขั้นที่ 3 — floorlet ที่ strike เดียวกัน

คราวนี้มองจากอีกฝั่ง ผู้ให้กู้ที่ได้รับดอกเบี้ยลอยตัวกลัวว่าอัตราจะลงจนรายรับต่ำเกินไป จึงซื้อ floorlet ของงวดเดียวกัน ที่ strike เดียวกัน

โจทย์ให้อะไรมาบ้าง:

  • งวดเดียวกับ caplet: $N=\$10{,}000{,}000$, $\delta=0.5$, $K=5.25\%$ อัตราตั้งที่ปีที่ 1 และจ่ายที่ปีที่ 1.5
  • floorlet จ่าย $N\delta(K-L)^+$ จากขั้นที่ 1 ได้ \$0, \$12,500 และ \$112,500 ที่จุด 7%, 5% และ 3%
  • state price ของจุด 5% และ 3% จากหน้าต้นไม้ คือ $Q_{5\%}=0.4756207$ และ $Q_{3\%}=0.2389994$

ใช้สองช่วงเหมือนขั้นที่ 2 ทุกจุดที่จ่ายเงิน ถอยครึ่งปีด้วยอัตราของจุดนั้นก่อน แล้วคูณ state price:

\[ \begin{aligned} V_1(5\%)&=12{,}500\,e^{-0.05\times0.5}\\ &=12{,}500\times0.9753099\\ &=\$12{,}191.37,\\ V_1(3\%)&=112{,}500\,e^{-0.03\times0.5}\\ &=112{,}500\times0.9851119\\ &=\$110{,}825.09,\\ V_0&=0.4756207\times12{,}191.37\\ &\quad+0.2389994\times110{,}825.09\\ &=5{,}798.47+26{,}487.13\\ &=\$32{,}285.60. \end{aligned} \]

คำตอบ: floorlet ราคา \$32,285.60 จุด 3% จ่ายมากเป็น $112{,}500/12{,}500=9$ เท่าของจุด 5% มูลค่าส่วนใหญ่จึงมาจากจุด 3% คือ $26{,}487.13/32{,}285.60=82\%$ floorlet แพงกว่า caplet (\$19,992.24) ทั้งที่ใช้ strike เดียวกัน เพราะ strike 5.25% อยู่สูงกว่าจุดกลางของต้นไม้ (5%) floorlet จึงได้เงินในสองกรณีจากสาม ส่วน caplet ได้แค่กรณีเดียว

ตรวจเองใน 10 วินาที: ปัดตัวเลขให้กลม ๆ: state price ราว 0.24 และตัวคูณครึ่งปีราว 0.985 ดังนั้นส่วนของจุด 3% ควรเป็นราว $112{,}500\times0.24\times0.985\approx\$26{,}600$ ใกล้กับ \$26,487.13 ที่คำนวณได้

ขั้นที่ 4 — cap–floor parity และสัญญาที่จ่ายอัตรา simple

ราคา caplet และ floorlet มาจากต้นไม้ ถ้าต้นไม้หรือโค้ดผิด จะรู้ได้อย่างไร? มีการตรวจที่ไม่ต้องเชื่อต้นไม้เลย ลองซื้อ caplet หนึ่งตัวและขาย floorlet หนึ่งตัวที่ strike เดียวกัน แล้วดูเงินที่ได้สุทธิทีละกรณี

  • ถ้า $L\gt K$: caplet จ่ายให้เรา $N\delta(L-K)$ ส่วน floorlet ไม่จ่าย สุทธิได้ $N\delta(L-K)$
  • ถ้า $L\lt K$: caplet ไม่จ่าย แต่เราต้องจ่าย $N\delta(K-L)$ ให้คนที่ซื้อ floorlet จากเรา สุทธิได้ $-N\delta(K-L)=N\delta(L-K)$ ซึ่งติดลบ

ทั้งสองกรณีได้สูตรเดียวกัน คือเส้นตรงเส้นเดียว (ในรูปแรก เส้นส้มลบเส้นเขียวได้เส้นตรง) เงินแบบนี้คือ FRA สัญญาที่ล็อกอัตราของงวดเดียวโดยไม่มีสิทธิ์เลือก

\[ \begin{aligned} \Pi^{\rm cap}-\Pi^{\rm floor}&=N\delta\,(L-K),\\ C-F&=19{,}992.24-32{,}285.60\\ &=-\$12{,}293.36. \end{aligned} \]

$C$ และ $F$ คือราคาวันนี้ของ caplet และ floorlet จากขั้นที่ 2 และ 3 ผลต่างของสัญญาฝึกคือ −\$12,293.36 แต่ตัวเลขนี้ยังตรวจจากข้างนอกต้นไม้ไม่ได้ เพราะสัญญาฝึกจ่ายตาม short rate $r_j$ ซึ่งเป็นตัวเลขภายในต้นไม้ ไม่ใช่อัตราที่ตลาดใช้ทำสัญญา

สัญญาจริงในตลาดใช้อัตรา simple ของงวด คืออัตรา $L_j$ ที่ทำให้เงิน $P_j$ ที่วัน reset งอกเป็น \$1 พอดีตอนปลายงวด ด้วยดอกเบี้ยแบบไม่ทบ: $P_j(1+\delta L_j)=1$ ย้ายข้างได้สูตรด้านล่าง ในต้นไม้นี้ $P_j=e^{-r_j\delta}$ จึงได้ $1/P_j=e^{r_j\delta}$

\[ \begin{aligned} L_j&=\frac{1/P_j-1}{\delta}=\frac{e^{r_j\delta}-1}{\delta},\\ L_{7\%}&=\frac{e^{0.035}-1}{0.5}=\frac{0.0356197}{0.5}\\ &=7.1239\%. \end{aligned} \]

ทำแบบเดียวกันกับจุด 5% และ 3% ได้ $(e^{0.025}-1)/0.5=5.0630\%$ และ $(e^{0.015}-1)/0.5=3.0226\%$ อัตรา simple สูงกว่า short rate เล็กน้อย เพราะดอกเบี้ยไม่ทบต้องใช้อัตราสูงกว่าเพื่อให้ได้เงินเท่ากัน

เดินต้นไม้แบบขั้นที่ 2–3 ด้วย $L_j$ แทน $r_j$ ที่จุด 7% caplet จ่าย $5\times10^6\times(0.0712394-0.0525)=\$93{,}697$ คูณตัวคูณสองช่วง $0.9656054\times0.2366213=0.2284828$ ได้ราว \$21,408 floorlet ทำเหมือนกันที่จุด 5% และ 3% ได้ราว \$30,558 ค่าเต็มคือ caplet \$21,408.17 และ floorlet \$30,557.62 ผลต่างคือ $21{,}408.17-30{,}557.62=-\$9{,}149.45$

ทีนี้ตรวจผลต่างนี้จากราคาพันธบัตรล้วน ๆ ต้องการแค่สองตัวเลข $D(0,1)$ คือราคาวันนี้ของ \$1 ที่ได้แน่นอนที่ปีที่ 1 และ $D(0,1.5)$ คือราคาวันนี้ของ \$1 ที่ได้แน่นอนที่ปีที่ 1.5

\[ \begin{aligned} C_L-F_L&=N\big[D(0,1)-D(0,1.5)\big]\\ &\quad-N\delta K\,D(0,1.5)\\ &=10^7(0.951241315-0.927801471)\\ &\quad-262{,}500\times0.927801471\\ &=234{,}398.44-243{,}547.89\\ &=-\$9{,}149.45. \end{aligned} \]

ทำไมใช้แค่ราคาพันธบัตรได้? ดูทีละขา ขาลอยตัวจ่าย $N\delta L_j$ ที่ปลายงวด ค่าของมันที่วัน reset คือ $N\delta L_jP_j$ และจากนิยาม $P_j(1+\delta L_j)=1$ จะได้ $\delta L_jP_j=1-P_j$ ค่านี้จึงเท่ากับ $N(1-P_j)$ พอดี ไม่ว่าอัตราจะเป็นเท่าไร คูณ state price แล้วบวกทุกจุด ผลบวก $\sum_jQ_j$ คือ $D(0,1)$ และ $\sum_jQ_jP_j$ คือ $D(0,1.5)$ ขาลอยตัวจึงมีค่า $N[D(0,1)-D(0,1.5)]$ ส่วนขาคงที่จ่าย $N\delta K=10^7\times0.5\times0.0525=\$262{,}500$ แน่นอนที่ปีที่ 1.5 จึงมีค่า $N\delta K\,D(0,1.5)$

ราคาพันธบัตรสองตัวนี้มาจาก หน้าต้นไม้ของ short rate ($D(0,1)=0.951241$ และ $D(0,1.5)=0.927801$) ที่นี่เขียนเก้าหลัก เพราะถูกคูณด้วย $10^7$ ผลที่ได้ −\$9,149.45 ตรงกับผลต่างจากการเดินต้นไม้ทุกหลัก และในสูตรไม่มีความผันผวนเลย ถ้าโค้ดให้ผลต่างอื่น แปลว่ามีบั๊กเรื่องเครื่องหมาย วันจ่าย หรือวิธีคิดอัตรา

ขั้นที่ 5 — payer swaption: ตัดสินใจครั้งเดียวกับ swap ทั้งสัญญา

ทีนี้เปลี่ยนสถานการณ์ บริษัทรู้ว่าปีหน้าจะต้องกู้เงินลอยตัว \$10 ล้านอีกหนึ่งปี และอยากล็อกอัตราคงที่ไว้ไม่เกิน 5.25% แต่ถ้าปีหน้าอัตราตลาดต่ำกว่านั้นก็ไม่อยากถูกผูกมัด สิ่งที่ตอบโจทย์คือ payer swaption: สิทธิ์ที่ปีที่ 1 ที่จะเข้าทำ swap อายุ 1 ปี เป็นฝั่ง จ่าย อัตราคงที่ $K=5.25\%$ และรับดอกเบี้ยลอยตัว จ่ายกันทุกครึ่งปี (สองงวด ที่ปีที่ 1.5 และปีที่ 2)

ที่วันใช้สิทธิ์ ต้องรู้ว่า swap นี้มีค่าเท่าไร swap rate $S$ คืออัตราคงที่ที่ทำให้ swap ใหม่มีค่าศูนย์พอดีตอนนั้น ถ้าเราได้จ่ายแค่ $K$ แทน $S$ เราประหยัด $S-K$ ต่อปีทุกงวด เงินที่ประหยัดต้องคิดลดทีละงวด ผลบวกของความยาวงวดคูณ discount factor ของแต่ละงวดเรียกว่า annuity $A$ ค่าของ swap จึงเป็น $NA(S-K)$ และเราใช้สิทธิ์เฉพาะเมื่อค่านี้เป็นบวก เพื่อให้คิดด้วยมือได้ สมมติว่าหลังวันใช้สิทธิ์ อัตราของทุกช่วงเวลาเท่ากับ $r_j$ ของจุดนั้น (curve แบน) discount factor ของสองงวดนับจากปีที่ 1 จึงเป็น $e^{-0.5r_j}$ และ $e^{-r_j}$

\[ \begin{aligned} \Pi^{\rm pay}_j&=NA_j\,(S_j-K)^+,\\ A_j&=0.5e^{-0.5r_j}+0.5e^{-r_j},\\ S_j&=\frac{1-e^{-r_j}}{A_j}. \end{aligned} \]

$S_j$ มาจากสูตร par swap rate ในหน้า swap: ขาลอยตัวของ swap มีค่า $1-D_n$ ต่อเงินต้น \$1 เพราะเงิน \$1 ที่ฝากรับดอกเบี้ยลอยตัวจนครบงวดสุดท้ายมีค่า \$1 วันนี้ ตัดเงินต้นที่ได้คืนตอนท้าย (มีค่า $D_n$) ออก ที่เหลือคือดอกเบี้ยลอยตัวทุกงวด ส่วนขาคงที่มีค่า $S\times A$ ตั้งสองขาให้เท่ากันได้ $S=(1-D_n)/A$ ที่นี่ $D_n=e^{-r_j}$ คือ discount factor ของงวดสุดท้าย

ใส่ตัวเลขของจุด 7%:

\[ \begin{aligned} A_{7\%}&=0.5e^{-0.035}+0.5e^{-0.07}\\ &=0.4828027+0.4661969\\ &=0.949000,\\ S_{7\%}&=\frac{1-e^{-0.07}}{0.949000}=\frac{0.0676062}{0.949000}\\ &=7.1239\%,\\ \Pi^{\rm pay}_{7\%}&=10^7\times0.949000\\ &\quad\times(0.0712394-0.0525)\\ &=\$177{,}837,\\ V_0&=0.2366213\times177{,}837\\ &=\$42{,}080.02. \end{aligned} \]

ที่จุด 5% และ 3% swap rate คือ 5.0630% และ 3.0226% ต่ำกว่า $K$ จึงไม่ใช้สิทธิ์และได้ศูนย์ ราคาทั้งหมดจึงมาจากจุด 7% จุดเดียว สังเกตว่า swap rate ทั้งสามตัวเท่ากับอัตรา simple $L_j$ ในขั้นที่ 4 พอดี ไม่ใช่เรื่องบังเอิญ ให้ $x=e^{-0.5r_j}$ จะได้ $S_j=\dfrac{1-x^2}{0.5x(1+x)}=\dfrac{1-x}{0.5x}=\dfrac{1/x-1}{0.5}=L_j$

ทำไมไม่ต้องคิดลดครึ่งปีเพิ่มเหมือน caplet? เพราะ $NA_j(S_j-K)$ เป็นค่า ที่วันใช้สิทธิ์ อยู่แล้ว annuity คิดลดเงินของทุกงวดกลับมาที่ปีที่ 1 ให้แล้ว จึงคูณ state price ได้ทันที

อีกด้านคือ receiver swaption: สิทธิ์เป็นฝั่ง รับ อัตราคงที่ 5.25% จ่ายเงิน $NA_j(K-S_j)^+$ จึงใช้สิทธิ์ที่จุด 5% และ 3%

\[ \begin{aligned} \Pi^{\rm rec}_{5\%}&=10^7\times0.9632697\\ &\quad\times(0.0525-0.0506302)\\ &=\$18{,}011,\\ \Pi^{\rm rec}_{3\%}&=10^7\times0.9777787\\ &\quad\times(0.0525-0.0302261)\\ &=\$217{,}789,\\ V_0^{\rm rec}&=0.4756207\times18{,}011\\ &\quad+0.2389994\times217{,}789\\ &=\$60{,}617.79. \end{aligned} \]

annuity ของจุด 5% และ 3% คำนวณแบบเดียวกับจุด 7% คือ $0.5e^{-0.025}+0.5e^{-0.05}=0.9632697$ และ $0.5e^{-0.015}+0.5e^{-0.03}=0.9777787$ payer ลบ receiver ได้ $42{,}080.02-60{,}617.79=-\$18{,}537.77$ เหตุผลเดียวกับ cap–floor parity: $(S-K)^+-(K-S)^+=S-K$ ผลต่างนี้จึงเท่ากับค่าวันนี้ของ swap จ่ายคงที่ 5.25% ที่เริ่มปีที่ 1 แบบไม่มีสิทธิ์เลือก ค่าติดลบเพราะในต้นไม้นี้ swap rate เฉลี่ยต่ำกว่า 5.25%

ขั้นที่ 6 — ต้นไม้ 6% ห้างวด: caplet strike 2% ที่จ่ายงวดที่ 6

ต้นไม้สามชั้นเล็กเกินไปสำหรับสัญญาหลายงวด จึงย้ายไปต้นไม้ที่ใหญ่ขึ้น ต้นไม้นี้คือต้นไม้ฝึกมาตรฐานใน หน้าต้นไม้ของ short rate ซึ่งต่างจากต้นไม้สามชั้นสองเรื่อง

  • อัตราเป็นอัตราต่องวด และคิดดอกเบี้ยทบทีละงวด ตัวคูณคิดลดหนึ่งงวดจึงเป็น $1/(1+r)$ ไม่ใช่ $e^{-r\delta}$
  • short rate เริ่ม 6% แต่ละงวดคูณ 1.25 (ขึ้น) หรือ 0.9 (ลง) ครึ่งต่อครึ่ง ที่งวด $i$ ถ้าขึ้นมาแล้ว $j$ ครั้ง อัตราคือ $r_{i,j}=0.06\times1.25^j\times0.9^{\,i-j}$

สัญญาแรกบนต้นไม้นี้คือ caplet strike 2% ที่จ่าย $(r_5-0.02)^+$ ต่อเงินต้น \$1 ที่งวดที่ 6 อัตรา $r_5$ รู้ตั้งแต่งวดที่ 5 เงินก้อนนี้จึงเป็นเงินแน่นอนตั้งแต่งวดที่ 5 เหมือนในขั้นที่ 2 วิธีคือคิดลดเงินก้อนนั้นหนึ่งงวดด้วยอัตราของจุดนั้น แล้วบันทึกไว้ที่จุดของงวดที่ 5 จากนั้นเดินย้อนทีละงวด แต่ละจุดคือค่าเฉลี่ยของสองจุดลูก หารด้วย $1+r$ ของตัวเอง

\[ \begin{aligned} V_{5,j}&=\frac{(r_{5,j}-0.02)^+}{1+r_{5,j}},\\ V_{i,j}&=\frac{\tfrac12\big(V_{i+1,j}+V_{i+1,j+1}\big)}{1+r_{i,j}}. \end{aligned} \]

การเดินย้อนเริ่มจากเงินที่บันทึกไว้ที่งวด 5 ไม่ใช่งวด 6 เพราะเงินของงวด 6 รู้ค่าแน่นอนตั้งแต่งวด 5 แล้ว ข้อดีคือไม่ต้องสร้างชั้นที่ 6 ของต้นไม้เลย จากนั้นใช้กฎเดียวกับการตั้งราคาพันธบัตรในหน้าต้นไม้ คือเฉลี่ยลูกสองจุด ($V_{i+1,j}$ คือลูกที่ลง และ $V_{i+1,j+1}$ คือลูกที่ขึ้น) แล้วคิดลดหนึ่งงวดด้วยอัตราของจุดพ่อแม่

ลองสองจุดล่างสุดของงวดที่ 5 แล้วถอยหนึ่งงวด อัตราของจุดเหล่านี้คือ $0.06\times0.9^5=3.54294\%$, $0.06\times1.25\times0.9^4=4.92075\%$ และที่งวด 4 จุดล่างสุด $0.06\times0.9^4=3.9366\%$

\[ \begin{aligned} V_{5,0}&=\frac{0.0354294-0.02}{1.0354294}=0.01490,\\ V_{5,1}&=\frac{0.0492075-0.02}{1.0492075}=0.02784,\\ V_{4,0}&=\frac{\tfrac12(0.01490+0.02784)}{1.039366}\\ &=0.02056. \end{aligned} \]

ทำแบบนี้ทุกจุดจนถึงวันนี้ ได้ $V_0=0.0420$ ต่อเงินต้น \$1 หรือราว $0.0420\times10^6=\$42{,}000$ ต่อเงินต้น \$1 ล้าน รูปด้านล่างแสดงตัวเลขทุกจุด แม้แต่จุดล่างสุดของงวดที่ 5 อัตราก็ยังเป็น 3.54% สูงกว่า strike 2% caplet นี้จึงจ่ายเงินทุกกรณี จุดบนสุดของงวดที่ 5 มีอัตรา $0.06\times1.25^5=18.31\%$ ได้ $(0.1831-0.02)/1.1831=0.1379$ ต่อ \$1

ขั้นที่ 7 — swap บนต้นไม้เดียวกัน และ cap ลบ floor เท่ากับ swap

สัญญาถัดไปคือ swap หกงวดบนต้นไม้เดียวกัน เรายืนฝั่งจ่ายดอกเบี้ยคงที่ 5% และรับดอกเบี้ยลอยตัว ต่อเงินต้น \$1 เงินสุทธิของงวด $i+1$ คือ $r_{i,j}-0.05$ ซึ่งรู้ตั้งแต่งวด $i$ จึงบันทึกไว้ที่จุดของงวด $i$ หลังคิดลดหนึ่งงวด เหมือน caplet ในขั้นที่ 6 แต่ต่างจาก caplet สองเรื่อง เรื่องแรก ไม่มี $^+$ เพราะ swap เป็นภาระ งวดที่ติดลบก็ต้องจ่าย เรื่องที่สอง swap มีเงินทุกงวด ไม่ใช่งวดเดียว ค่าที่จุดหนึ่งจึงต้องรวมค่าของงวดที่เหลือข้างหน้าด้วย ซึ่งก็คือค่าเฉลี่ยของสองจุดลูก $\bar V_{i+1}=\tfrac12(V_{i+1,j}+V_{i+1,j+1})$

\[ \begin{aligned} V_{i,j}&=\frac{r_{i,j}-0.05+\bar V_{i+1}}{1+r_{i,j}},\\ V_{5,5}&=\frac{0.1831-0.05}{1.1831}=0.1125,\\ \bar V_3&=\tfrac12(0.17927+0.10206)\\ &=0.14067,\\ V_{2,2}&=\frac{0.04375+0.14067}{1.09375}=0.1686,\\ V_0&=0.0990. \end{aligned} \]

เดินย้อนจากงวดสุดท้าย ที่งวด 5 ไม่มีงวดถัดไปแล้ว $\bar V$ จึงเป็นศูนย์ จุดบนสุดมีอัตรา 18.31% ได้ 0.1125 ที่งวด 2 จุดบนสุดมีอัตรา $0.06\times1.25^2=9.375\%$ เงินของงวดถัดไปคือ $0.09375-0.05=0.04375$ และลูกสองจุดของมันที่งวด 3 มีค่า 0.17927 และ 0.10206 (ได้จากการเดินย้อนแบบเดียวกัน) เฉลี่ยกันได้ $\bar V_3$ เดินจนถึงวันนี้ได้ $V_0=0.0990$ ต่อ \$1 เป็นบวก เพราะต้นไม้นี้อยู่สูงกว่า 5% เกือบทุกจุด ฝั่งรับลอยตัวจึงได้เปรียบ มีบางจุดที่ติดลบ เช่น จุดล่างสุดของงวดที่ 3 มีค่า −0.0085 เพราะอัตราตรงนั้นคือ 4.37% ต่ำกว่า 5% และอัตราข้างหน้าก็ยังต่ำอยู่

ทีนี้เทียบกับ cap และ floor ที่ strike 5% บนหกงวดเดียวกัน แต่ละงวด caplet ลบ floorlet ได้ $(r-0.05)^+-(0.05-r)^+=r-0.05$ ซึ่งคือเงินของ swap งวดนั้นพอดี บวกทุกงวดแล้ว cap ลบ floor ต้องเท่ากับ swap ราคา cap และ floor หาได้ด้วยวิธีของขั้นที่ 6 ทีละงวด (หก caplet และหก floorlet) แล้วบวกกัน โค้ดท้ายหน้าคำนวณให้ได้ cap $C=0.100902$ และ floor $F=0.001898$

\[ \begin{aligned} C-F&=0.100902-0.001898\\ &=0.099004=V_0. \end{aligned} \]

ตรงกับค่า swap ทุกหลัก นี่คือ cap–floor parity ที่ต่อกันทุกงวด ผลตามมาข้อหนึ่ง ถ้าเลือก strike ให้เท่ากับ swap rate ของตลาด swap จะมีค่าศูนย์ cap กับ floor จึงต้องราคาเท่ากัน

parity นี้ยังตอบคำถามว่าทำไมผู้กู้ไม่ทำ swap ไปเลย swap ล็อกทั้งขาขึ้นและขาลง อัตราลงเมื่อไร ผู้กู้ก็ยังจ่าย 5% ส่วน cap กันแค่ขาขึ้น และปล่อยให้ผู้กู้ได้ประโยชน์เมื่ออัตราลง ส่วนต่าง $C-V_0=0.100902-0.099004=0.001898$ คือราคาของประโยชน์ขาลงนั้น ซึ่งก็คือราคา floor พอดี

ขั้นที่ 8 — swaption ที่งวดที่ 3 และทำไมไม่แพงกว่า cap

บนต้นไม้เดียวกัน ลองตั้งราคา swaption ที่ใช้สิทธิ์ได้ที่งวดที่ 3 แล้วเทียบกับ cap ของงวดเดียวกัน คำถามคือ สิทธิ์เลือกครั้งเดียวทั้งสัญญา กับสิทธิ์เลือกทีละงวด อันไหนแพงกว่า

โจทย์ให้อะไรมาบ้าง:

  • ที่งวดที่ 3 ผู้ถือมีสิทธิ์เข้า swap ของขั้นที่ 7 ในส่วนที่เหลือ คือเงินงวดที่ 4 ถึง 6 เป็นฝั่งจ่ายคงที่ 5%
  • ตอนเข้า swap ไม่ต้องจ่ายอะไร (strike ของ option นี้คือศูนย์ อย่าสับสนกับอัตราคงที่ 5% ของ swap) ผู้ถือจึงใช้สิทธิ์เมื่อ swap มีค่าเป็นบวก
  • ค่าของ swap ที่งวดที่ 3 จากขั้นที่ 7 คือ −0.0085, 0.0400, 0.1021 และ 0.1793 ต่อ \$1 (จากจุดอัตราต่ำไปสูง)
  • ก่อนวันใช้สิทธิ์ ผู้ถือยังไม่ได้เงินรายงวดของ swap การเดินย้อนจึงใช้กฎของขั้นที่ 6 คือเฉลี่ยลูกแล้วหาร ไม่บวกเงินรายงวด
\[ \begin{aligned} W_{3,j}&=\max(0,\ V_{3,j})\\ &=0,\ 0.0400,\ 0.1021,\ 0.1793,\\ W_{2,2}&=\frac{\tfrac12(0.1793+0.1021)}{1.09375}\\ &=0.1286,\\ W_0&=0.0620. \end{aligned} \]

$W_{i,j}$ คือค่าของ swaption ที่จุด $(i,j)$ ที่จุดล่างสุดของงวด 3 swap ติดลบ จึงไม่ใช้สิทธิ์และได้ศูนย์ อีกสามจุดใช้สิทธิ์ แล้วเดินย้อนถึงวันนี้ได้ 0.0620 ต่อ \$1

cap ที่ strike 5% บนงวดเดียวกัน (caplet สามตัวที่จ่ายงวดที่ 4, 5 และ 6) หาด้วยวิธีของขั้นที่ 6 ได้ $C_{4..6}=0.0627$ แพงกว่า swaption เพราะอสมการด้านล่าง ให้ $X_i$ คือค่าที่วันใช้สิทธิ์ของเงินงวดที่ $i$ ของ swap

\[ \Big(\sum_iX_i\Big)^+\le\sum_iX_i^+. \]

คำตอบ: swaption ราคา 0.0620 ต่อ \$1 cap ราคา 0.0627 แพงกว่า $10^6\times(0.06266748-0.06197181)=\$695.67$ ต่อเงินต้น \$1 ล้าน เหตุผลอยู่ในอสมการ ที่วันใช้สิทธิ์ swaption ได้ $(\sum_iX_i)^+$ คือต้องรับทุกงวดพร้อมกัน ทั้งงวดดีและงวดแย่ caplet แต่ละตัวมีค่าอย่างน้อย $X_i^+$ เพราะเลือกได้ทีละงวด ทิ้งงวดแย่ได้ ผลบวกของส่วนบวกจึงไม่น้อยกว่าส่วนบวกของผลบวก ส่วนต่างในตัวอย่างนี้เล็ก เพราะในจุดส่วนใหญ่ เงินทุกงวดของ swap เป็นบวกอยู่แล้ว สิทธิ์เลือกทีละงวดจึงแทบไม่ได้ใช้

ตรวจเองใน 10 วินาที: swaption ต่างจาก swap ที่เริ่มงวด 4 แบบไม่มีสิทธิ์เลือกแค่ที่จุดล่างสุดของงวด 3 จุดเดียว จุดนั้นมาได้ทางเดียว (ลงสามครั้ง) state price ของมันคือ $(\tfrac12)^3/(1.06\times1.054\times1.0486)=0.1067$ swaption จึงแพงกว่า swap แบบไม่มีสิทธิ์อยู่ $0.1067\times0.0085=0.0009$ swap แบบนั้นจึงมีค่า $0.0620-0.0009=0.0611$ ลำดับ $0.0611\le0.0620\le0.0627$ ต้องเป็นแบบนี้เสมอ swaption ไม่ถูกกว่า swap ที่ไม่มีสิทธิ์เลือก เพราะ $\max(0,V)\ge V$ และไม่แพงกว่า cap เพราะอสมการด้านบน

ขั้นที่ 9 — swap ที่เริ่มในอนาคต: คูณ state price ได้เลย

สองบริษัทตกลงกันวันนี้ว่าจะทำ swap ที่เริ่มในอนาคต (forward-start swap) บนต้นไม้ 6% เดิม เงินต้น \$1,000,000 เรายืนฝั่งรับดอกเบี้ยคงที่ 7% และจ่ายดอกเบี้ยลอยตัว swap เริ่มที่งวด 1 และจบที่งวด 3 จึงมีเงินสองก้อน ที่งวด 2 และงวด 3 ซึ่งใช้อัตราลอยตัวที่ตั้งไว้ที่งวด 1 และงวด 2 ตามลำดับ

วิธีเดินย้อนทั้งต้นไม้ใช้ได้ แต่มีทางลัด เงินแต่ละก้อนรู้ค่าก่อนจ่ายหนึ่งงวด จึงคิดลดหนึ่งงวดด้วยอัตราของจุดนั้น ได้ค่าที่จุดนั้น แล้วคูณ state price $E_{i,j}$ ของจุดนั้น (ราคาวันนี้ของ \$1 ที่ได้เฉพาะเมื่อไปถึงจุด $(i,j)$) แล้วบวกกันทุกจุด

\[ \begin{aligned} c_{i,j}&=\frac{0.07-r_{i,j}}{1+r_{i,j}}\,E_{i,j},\\ V_0&=10^6\sum_{i,j}c_{i,j}. \end{aligned} \]

$c_{i,j}$ คือส่วนที่จุด $(i,j)$ เพิ่มให้ราคาวันนี้ ต่อเงินต้น \$1 state price บนต้นไม้นี้หาด้วย forward equations จาก หน้าต้นไม้ของ short rate โดยใช้ตัวคูณ $1/(1+r)$ แทน $e^{-r\Delta t}$ แต่ละจุดส่ง state price ของตัวเองครึ่งหนึ่งไปให้ลูกแต่ละจุด หลังคิดลดด้วยอัตราของตัวเอง

\[ \begin{aligned} E_{1,0}&=E_{1,1}=\frac{1/2}{1.06}=0.4716981,\\ E_{2,0}&=\frac{0.4716981}{2\times1.054}=0.2237657,\\ E_{2,2}&=\frac{0.4716981}{2\times1.075}=0.2193945,\\ E_{2,1}&=0.2237657+0.2193945\\ &=0.4431602. \end{aligned} \]

จุดกลางของงวด 2 มาได้สองทาง คือจากจุด 5.40% ด้วยการขึ้น และจากจุด 7.50% ด้วยการลง จึงรับมาจากพ่อแม่ทั้งสอง ทีนี้ใส่ตัวเลขทั้งห้าจุดลงในสูตรของ $c_{i,j}$:

จุดที่อัตราลอยตัวสูงกว่า 7% ให้ค่าติดลบ เพราะเราต้องจ่ายลอยตัวมากกว่าที่รับคงที่ ผลรวมยังเป็นบวก swap นี้จึงมีค่า \$5,807 ต่อเรา (ค่าเต็มจากโค้ดคือ \$5,807.06) ทางลัดนี้ไม่ต้องเดินย้อนเลย เพราะ state price แต่ละจุดหาไว้ครั้งเดียวแล้วใช้กับสัญญาไหนก็ได้

ขั้นที่ 10 — swaption บน BDT สองต้นที่ fit curve เท่ากัน

ขั้นสุดท้ายถามคำถามที่สำคัญที่สุดของหน้า ถ้าต้นไม้สองต้นตรงกับราคาพันธบัตรในตลาดทุกตัวเท่ากัน มันจะให้ราคา option เท่ากันไหม? ใช้ต้นไม้ BDT จาก หน้าต้นไม้ของ short rate ต้นไม้นี้วางอัตราที่ปี $i$ ไว้เป็น $r_{i,j}=a_ie^{bj}$ ตัว $a_i$ กำหนดระดับของอัตราในปีนั้น ตัว $b$ กำหนดว่าอัตราในปีเดียวกันกระจายห่างกันแค่ไหน ซึ่งก็คือความผันผวนของอัตรา

ของที่รู้:

  • เส้น spot (ผลตอบแทนต่อปีของพันธบัตรที่ไม่มีคูปอง อายุ 1 ถึง 10 ปี ทบปีละครั้ง ตัวเลขสมมติ) คือ 7.30, 7.62, 8.10, 8.45, 9.20, 9.64, 10.12, 10.45, 10.75 และ 11.22%
  • ต้นไม้สองต้น ต้นหนึ่งใช้ $b=0.005$ อีกต้นใช้ $b=0.01$ แต่ละต้นเลือก $a_i$ ทีละปี (calibrate) จนราคาพันธบัตรทั้งสิบตัวตรงกับเส้น spot พอดี
  • สัญญา: สิทธิ์ที่ปีที่ 2 ที่จะเข้า swap อายุ 8 ปี เป็นฝั่งจ่ายคงที่ 11.65% รับลอยตัว เงินต้น \$1 ล้าน เงินปีที่ 3 ถึง 10 ใช้อัตราลอยตัวของปีก่อนหน้า

วิธีตั้งราคาเหมือนขั้นที่ 7 และ 8 ทุกอย่าง เดินย้อนหาค่า swap จากปีที่ 10 ถึงปีที่ 2 ตัดด้วย $\max(0,\cdot)$ ที่ปีที่ 2 แล้วเดินย้อนต่อถึงวันนี้โดยไม่บวกเงินรายงวด โค้ดท้ายหน้าทำทั้งหมดนี้ได้ผลดังนี้

\[ \begin{aligned} b=0.005&:\ W_0=\$1{,}339.08,\\ b=0.01&:\ W_0=\$1{,}961.44,\\ \frac{1{,}961.44}{1{,}339.08}&=1.4648. \end{aligned} \]

ต้นไม้ทั้งสองให้ราคาพันธบัตรทั้งสิบตัวตรงตลาดเท่ากัน แต่ swaption ต่างกัน $1{,}961.44-1{,}339.08=\$622.36$ คือแพงขึ้น 46.5% ทำไม? ราคาพันธบัตรขึ้นกับระดับเฉลี่ยของอัตรา ซึ่ง $a_i$ ปรับให้ตรงได้เสมอไม่ว่า $b$ จะเป็นเท่าไร แต่ option ขึ้นกับว่าอัตรากระจายกว้างแค่ไหน ยิ่งกระจายกว้าง กรณีที่ได้เงินก้อนใหญ่ก็ยิ่งมาก ราคาพันธบัตรจึงบอกอะไรเรื่อง $b$ ไม่ได้เลย

บทเรียนคือ ตราสารที่ใช้ calibrate ต้องหน้าตาใกล้กับของที่จะตั้งราคา จะตั้งราคา swaption ต้อง calibrate $b$ กับราคา cap, floor หรือ swaption ที่ตลาดซื้อขายอยู่ และทุกครั้งที่เปลี่ยน $b$ ต้องหา $a_i$ ใหม่ด้วย

งานจริงเลือกพารามิเตอร์ $\theta$ (เช่น $b$) ด้วยการทำให้ค่า $J(\theta)$ ด้านล่างต่ำที่สุด $P_i^{\rm mdl}$ คือราคาที่แบบจำลองให้กับตราสารตัวที่ $i$ $P_i^{\rm mkt}$ คือราคาตลาดของมัน $w_i$ คือน้ำหนักตามความเชื่อถือในราคาตลาดตัวนั้น และ $\lambda$ คือค่าปรับเมื่อ $\theta$ ขยับห่างจากค่า $\theta_{\rm prev}$ ที่ calibrate ครั้งก่อน เพื่อไม่ให้พารามิเตอร์กระโดดไปมาทุกวัน

\[ \begin{aligned} J(\theta)&=\sum_iw_i\big(P_i^{\rm mdl}-P_i^{\rm mkt}\big)^2\\ &\quad+\lambda(\theta-\theta_{\rm prev})^2. \end{aligned} \]

ตัวอย่างของเล่น: มีตราสารสองตัว ราคาตลาด 1.10 และ 1.20 ให้ราคาแบบจำลองเท่ากับ $\theta$ ตรง ๆ น้ำหนัก $w_i=1$ และค่าครั้งก่อน $\theta_{\rm prev}=1.00$ ดังนั้น $J(\theta)=(\theta-1.10)^2+(\theta-1.20)^2+\lambda(\theta-1.00)^2$ ตั้งอนุพันธ์เป็นศูนย์ได้ $\theta=(1.10+1.20+\lambda\times1.00)/(2+\lambda)$ ถ้าไม่มีค่าปรับ ($\lambda=0$) ได้ $\theta=2.30/2=1.15$ คือกึ่งกลางของราคาตลาด ถ้า $\lambda=1$ ได้ $\theta=3.30/3=1.10$ ถูกดึงกลับไปทางค่าเดิม ปัญหาจริงยากกว่านี้มาก มันไม่ convex (กราฟของ $J$ ไม่ได้เป็นชามใบเดียว) มี จุดต่ำสุดเฉพาะที่ หลายจุด และต้องทำใหม่หลายครั้งต่อวัน

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

นับว่า caplet จ่ายที่วัน reset: เงินจ่ายจริงที่ปลายงวด แต่ถ้าลืมคิดลดครึ่งปีนั้น จะได้ $0.2366213\times87{,}500=\$20{,}704.36$ ที่ถูกคือ $0.2366213\times87{,}500\,e^{-0.035}=\$19{,}992.24$ สูงไป \$712.12 และสูงไปทุกครั้ง

ใช้อัตราของต้นไม้แทนอัตราที่สัญญาเขียนไว้: สัญญาจริงจ่ายตามอัตรา simple ซึ่งที่จุด 7% คือ $(e^{0.035}-1)/0.5=7.1239\%$ ไม่ใช่ 7% caplet ของสัญญาจริงจึงราคา \$21,408.17 ไม่ใช่ \$19,992.24 ต่างกัน $21{,}408.17-19{,}992.24=\$1{,}415.93$

ลืม annuity ของ swaption: ส่วนต่างของอัตรา $S-K$ ได้ทุกงวดตลอดอายุ swap จึงต้องคูณ annuity ที่คิดลดทุกงวดไว้แล้ว ถ้าใช้ $N(S-K)^+$ จะได้ $0.2366213\times10^7\times0.0187394=\$44{,}341.45$ ที่ถูกคือ $0.2366213\times10^7\times0.949000\times0.0187394=\$42{,}080.02$

บวกเงินรายงวดของ swap ก่อนวันใช้สิทธิ์: ผู้ถือ swaption ยังไม่ได้เงินของ swap ก่อนงวดที่ 3 ถ้าเดินย้อนจากงวดที่ 3 แล้วบวกเงินรายงวดเข้าไปด้วย จะได้ 0.0999 แทน 0.0620 สูงไป $10^6\times(0.0999076-0.0619718)=\$37{,}936$ ต่อเงินต้น \$1 ล้าน

calibrate กับราคาพันธบัตรอย่างเดียว: ต้นไม้ $b=0.005$ และ $b=0.01$ ตรงกับราคาพันธบัตรเท่ากัน แต่ swaption ต่างกัน $1{,}961.44-1{,}339.08=\$622.36$ ต่อเงินต้น \$1 ล้าน หรือ 46.5% ถ้าเลือก $b$ มั่ว ๆ ราคา option ก็ผิดได้เกือบครึ่ง

ใช้ทำอะไรบนโต๊ะจริง

ธนาคารขาย cap ให้บริษัทที่กู้ลอยตัว และขาย floor ให้คนที่มีรายรับลอยตัว เช่น ผู้ให้กู้ swaption เหมาะกับบริษัทที่รู้ว่าจะกู้เงินหรือออกหุ้นกู้ในอนาคต ความเสี่ยงของบริษัทแบบนี้คือวันนั้นต้องทำ swap ทั้งสัญญาที่อัตราตลาดตอนนั้น swaption ตรงกับความเสี่ยงนี้พอดี และถูกกว่า cap เพราะไม่ต้องจ่ายเพิ่มสำหรับสิทธิ์เลือกทีละงวด (ขั้นที่ 8) พันธบัตรหรือเงินกู้ที่ผู้กู้ไถ่ถอนก่อนกำหนดได้ ก็มีสิทธิ์แบบ swaption ซ่อนอยู่ข้างใน

ในตลาดจริง คนไม่ได้บอกราคา cap และ swaption เป็นดอลลาร์ แต่บอกเป็นความผันผวนที่ใส่ในสูตร Black (ญาติของ สูตร Black–Scholes ที่ใช้กับราคา forward) ทีละ caplet หรือทีละ swaption ต้นไม้มีข้อดีกว่าสองข้อ ข้อแรก ใช้ได้กับสิทธิ์ที่ใช้ได้หลายวัน ข้อสอง ให้ราคาทุกสัญญาจากแบบจำลองเดียว ซึ่งตรงกับราคาพันธบัตรอยู่แล้ว

งานประจำของโต๊ะมีดังนี้ เก็บวัน reset วันจ่าย และวันใช้สิทธิ์แยกกันในระบบ ตรวจ parity ตรวจว่าไม่มีราคาติดลบ ตรวจว่าราคาไม่เปลี่ยนเมื่อซอยงวดของต้นไม้ให้ถี่ขึ้น แล้วรายงานว่าราคาไวต่อ curve ต่อความผันผวน และต่อ strike แค่ไหน แยกกัน

ข้อจำกัดที่ต้องจำ ต้นไม้ในหน้านี้มีตัวขับเคลื่อนตัวเดียว (one-factor) คือ short rate อัตราของทุกอายุจึงขยับไปด้วยกันเสมอ แต่ ข้อมูลจริงของ swap แต่ละอายุ บอกว่าอัตราต่างอายุไม่ได้ขยับตามกันสมบูรณ์ swaption อายุยาวจึงอาจถูกตั้งราคาผิด แม้ caplet จะตรงกับตลาดแล้วก็ตาม

โจทย์ตรวจความเข้าใจ

1. บริษัทในโจทย์เปิดหน้าอยากได้ประกันที่เข้มกว่าเดิม คือเพดานต่ำลงเป็น strike $K=4.5\%$ งวดเดิม (ตั้งอัตราที่ปีที่ 1 จ่ายที่ปีที่ 1.5) เงินต้นเดิม \$10 ล้าน และเป็นสัญญาฝึกที่จ่ายตาม $r_j$ ของต้นไม้สามชั้น caplet นี้ราคาเท่าไร?

เฉลย

ตอนนี้ caplet จ่ายสองจุด เพราะทั้ง 7% และ 5% สูงกว่า 4.5% ส่วนจุด 3% ไม่จ่าย แต่ละจุดถอยครึ่งปีด้วย $P_j=e^{-r_j\delta}$ ของตัวเอง แล้วคูณ state price รวมสองตัวคูณไว้ก่อนได้ $Q_{7\%}P_{7\%}=0.2366213\times0.9656054=0.2284828$ และ $Q_{5\%}P_{5\%}=0.4756207\times0.9753099=0.4638776$

\[ \begin{aligned} \Pi_{7\%}&=5\times10^6\times(0.07-0.045)\\ &=\$125{,}000,\\ \Pi_{5\%}&=5\times10^6\times(0.05-0.045)\\ &=\$25{,}000,\\ V_0&=0.2284828\times125{,}000\\ &\quad+0.4638776\times25{,}000\\ &=28{,}560.35+11{,}596.94\\ &=\$40{,}157.29. \end{aligned} \]

แพงกว่า caplet ที่ strike 5.25% (\$19,992.24) ราวสองเท่า เพราะเพดานต่ำลงทำให้ได้เงินมากขึ้นที่จุด 7% และได้เงินเพิ่มที่จุด 5% ด้วย

2. สัญญาจริงที่จ่ายตามอัตรา simple ของงวดเดียวกัน ที่ strike 5.25% มีคนบอกราคา caplet มาว่า \$21,408.17 ถ้าไม่อยากเดินต้นไม้ floorlet ที่ strike เดียวกันต้องราคาเท่าไร?

เฉลย

ใช้ cap–floor parity จากขั้นที่ 4 ซึ่งใช้แค่ราคาพันธบัตรวันนี้ $D(0,1)=0.951241315$ และ $D(0,1.5)=0.927801471$ ผลต่าง $C_L-F_L$ คือ −\$9,149.45 ย้ายข้างได้

\[ \begin{aligned} F_L&=C_L-(C_L-F_L)\\ &=21{,}408.17-(-9{,}149.45)\\ &=\$30{,}557.62. \end{aligned} \]

ตรงกับการเดินต้นไม้ทุกหลัก โดยไม่ต้องรู้เลยว่าอัตราแกว่งแรงแค่ไหน

3. บนต้นไม้ 6% มีคนบอกสองตัวเลข: cap ที่ strike 5% บนหกงวดราคา 0.100902 ต่อเงินต้น \$1 และ swap หกงวดที่จ่ายคงที่ 5% รับลอยตัวมีค่า 0.099004 ต่อ \$1 floor ที่ strike 5% บนหกงวดเดียวกันราคาเท่าไร?

เฉลย

parity ทุกงวด: cap − floor = swap ย้ายข้างได้

\[ \begin{aligned} F&=C-V_{\rm swap}\\ &=0.100902-0.099004\\ &=0.001898. \end{aligned} \]

ต่อเงินต้น \$1 ล้านคือ $0.001898\times10^6=\$1{,}898$ ตรงกับการเดินต้นไม้ทีละ floorlet floor ถูกมาก เพราะในต้นไม้นี้อัตราต่ำกว่า 5% แค่ที่จุดล่าง ๆ ไม่กี่จุด และจุดเหล่านั้นมี state price น้อย

const {exp, max} = Math;

// One-period rate option on the three-layer tree: rate fixed at the reset layer, paid delta later, discounted with the node rate.
function rateOption(Q, r, {N, delta, K, kind, simple = false}) {
  const P = r.map(x => exp(-x * delta));                         // value at reset of $1 paid at period end
  const L = simple ? P.map(p => (1 / p - 1) / delta) : r;          // rate written in the contract
  const pay = L.map(l => N * delta * (kind === 'cap' ? max(l - K, 0) : kind === 'floor' ? max(K - l, 0) : l - K));
  const parts = pay.map((x, j) => Q[j] * P[j] * x);
  return {L, pay, parts, value: parts.reduce((s, x) => s + x, 0)};
}
// Swaption on a two-payment half-yearly swap starting at the exercise layer, curve flat at the node rate after exercise.
function swaption(Q, r, {N, K, payer = true}) {
  const A = r.map(x => 0.5 * exp(-0.5 * x) + 0.5 * exp(-x));
  const S = r.map((x, j) => (1 - exp(-x)) / A[j]);
  const pay = S.map((s, j) => N * A[j] * max(payer ? s - K : K - s, 0));
  return {A, S, pay, value: pay.reduce((s, x, j) => s + x * Q[j], 0)};
}
// Per-period lattice, q = 1/2, j counts up moves.
const tree = (r0, u, d, n) => Array.from({length: n}, (_, i) => Array.from({length: i + 1}, (_, j) => r0 * u ** j * d ** (i - j)));
const step = (R, i, V, cash = () => 0) => R[i].map((x, j) => (cash(x) + 0.5 * (V[j] + V[j + 1])) / (1 + x));
// Value today of a payment f(r_i) made at i + 1 and fixed at layer i (recorded at layer i, then rolled back).
function inArrears(R, i, f) {
  let V = R[i].map(x => f(x) / (1 + x));
  for (let k = i - 1; k >= 0; k--) V = step(R, k, V);
  return V[0];
}
function swapLayers(R, K) {
  const last = R.length - 1, out = [];
  let V = R[last].map(x => (x - K) / (1 + x)); out[last] = V;
  for (let i = last - 1; i >= 0; i--) { V = step(R, i, V, x => x - K); out[i] = V; }
  return out;
}
function statePrices(R, n) {
  const E = [[1]];
  for (let k = 0; k < n; k++) {
    const next = Array(k + 2).fill(0);
    E[k].forEach((e, j) => { const v = e / (2 * (1 + R[k][j])); next[j] += v; next[j + 1] += v; });
    E.push(next);
  }
  return E;
}
// BDT (per-period, b fixed) calibrated to a spot curve, then a payer swaption: exercise at `expiry`, payments expiry + 1 .. n.
function bdtSwaption(spot, b, K, expiry) {
  let E = [1]; const R = [];
  spot.forEach((s, i) => {
    const target = (1 + s) ** -(i + 1);
    let lo = 0, hi = 1;
    for (let k = 0; k < 200; k++) {
      const m = (lo + hi) / 2;
      if (E.reduce((sum, e, j) => sum + e / (1 + m * exp(b * j)), 0) > target) lo = m; else hi = m;
    }
    R.push(E.map((_, j) => (lo + hi) / 2 * exp(b * j)));
    const next = Array(i + 2).fill(0);
    E.forEach((e, j) => { const v = e / (2 * (1 + R[i][j])); next[j] += v; next[j + 1] += v; });
    E = next;
  });
  let V = R[R.length - 1].map(x => (x - K) / (1 + x));
  for (let i = R.length - 2; i >= expiry; i--) V = step(R, i, V, x => x - K);
  let W = V.map(v => max(v, 0));
  for (let i = expiry - 1; i >= 0; i--) W = step(R, i, W);
  return W[0];
}

  • floorlet ที่ strike เดียวกันราคา \$32,285.60 caplet ลบ floorlet ได้เงินเท่ากับ FRA ซึ่งตั้งราคาได้จากราคาพันธบัตรวันนี้อย่างเดียว สำหรับสัญญาที่จ่ายอัตรา simple ผลต่างคือ −\$9,149.45 ใช้ตรวจโค้ดได้โดยไม่ต้องเชื่อต้นไม้
  • payer swaption จ่าย $NA(S-K)^+$ ที่วันใช้สิทธิ์ โดย annuity $A$ คิดลดเงินทุกงวดของ swap ไว้แล้ว บนต้นไม้สามชั้นได้ \$42,080.02 และ swaption ไม่มีทางแพงกว่า cap ของงวดเดียวกัน เพราะ cap เลือกได้ทีละงวด (บนต้นไม้ 6%: 0.0620 เทียบ 0.0627)
  • บนต้นไม้ 6% caplet strike 2% ราคา 0.0420 ต่อ \$1 swap จ่ายคงที่ 5% มีค่า 0.0990 เท่ากับ cap ลบ floor และ swap ที่เริ่มในอนาคตตั้งราคาได้ด้วย state price อย่างเดียว ได้ \$5,807
  • ต้นไม้สองต้นที่ตรงกับราคาพันธบัตรเท่ากัน ให้ swaption \$1,339 กับ \$1,962 ความผันผวนของต้นไม้จึงต้อง calibrate กับราคา option ในตลาด โดยทำให้ผลรวมกำลังสองของความคลาดที่ถ่วงน้ำหนักต่ำที่สุด บวกค่าปรับเมื่อพารามิเตอร์ขยับจากเมื่อวาน

หน้าถัดไป การ calibrate Vasicek และ CIR เปลี่ยนจากต้นไม้เป็นแบบจำลองที่เวลาไหลต่อเนื่อง แล้วปรับพารามิเตอร์ให้ตรงกับอัตราตลาดจริงของสองวัน เพื่อดูว่าพารามิเตอร์สี่ตัวทำให้ curve ตรงได้แค่ไหน และส่วนที่ยังไม่ตรงบอกอะไรเรา
