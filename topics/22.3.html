22.3 CMO Tranche Waterfalls

CMO เขียนกติกาว่าเงินต้นแต่ละดอลลาร์ของ pool ไปถึงผู้ถือชั้นไหนก่อน จึงสร้างของอายุสั้นและอายุยาวจาก pool เดียวได้ แต่ความไม่แน่นอนเรื่องเวลาไม่ได้หายไป มันแค่ย้ายที่

ธนาคารปล่อยสินเชื่อบ้านให้คนหลายพันคน แล้วรวมสินเชื่อเหล่านี้เป็นก้อนเดียว เรียกว่า pool ตราสารที่ส่งเงินผ่อนทุกดอลลาร์ของ pool ต่อให้ผู้ลงทุนตามสัดส่วนเรียกว่า pass-through ปัญหาคือผู้กู้คืนหนี้ก่อนกำหนดได้ทุกเมื่อ ผู้ถือ pass-through จึงไม่รู้ว่าเงินต้นจะกลับมาเมื่อไร

ผู้จัดตั้ง (ธนาคารที่ออกแบบและขายตราสาร) จึงแบ่ง pass-through ก้อนหนึ่งเป็นสี่ชั้น ชั้นแรกได้เงินต้นคืนก่อน ชั้นสุดท้ายได้คืนหลังสุด ของที่รู้:

  • pass-through ขนาด \$400 ล้าน เป็นก้อนเดียวกับในหน้าการคืนก่อนกำหนด
  • ขนาดของสี่ชั้นที่ผู้จัดตั้งเลือก: A \$194.5 ล้าน, B \$36 ล้าน, C \$96.5 ล้าน และ D \$73 ล้าน รวมกันได้ $194.5+36+96.5+73=400$ พอดี
  • ความเร็วที่ผู้กู้คืนก่อนกำหนดวัดเป็นหน่วย PSA โดย 100 PSA คือความเร็วมาตรฐานที่ตลาดตกลงกัน และ 200 PSA คือเร็วเป็นสองเท่า
  • อายุของแต่ละชั้นวัดด้วย average life คือเวลาเฉลี่ยที่เงินต้นแต่ละดอลลาร์ของชั้นนั้นกลับมาถึงผู้ถือ

ผู้จัดตั้งขายชั้น A ให้กองทุนตลาดเงิน (กองทุนที่ถือได้แต่ของอายุสั้น) ว่าเป็นของอายุราว 5 ปี และขายชั้น D ให้บริษัทประกันชีวิต (ซึ่งต้องจ่ายเงินให้ลูกค้าในอีกหลายสิบปี จึงอยากได้ของอายุยาว) ว่าเป็นของอายุราว 25 ปี ทั้งสองตัวเลขคิดที่ 100 PSA แล้วเขาก็บอกว่า “แบ่งชั้นแล้ว ทุกคนได้อายุที่ต้องการ ความเสี่ยงเรื่องเวลาจัดการเรียบร้อย”

ถ้าอัตราดอกเบี้ยตลาดลด ผู้กู้จะรีไฟแนนซ์ (กู้ใหม่ที่ดอกเบี้ยถูกกว่ามาปิดหนี้เก่า) ความเร็วจึงขึ้นเป็น 200 PSA ตอนนั้นอายุของชั้น A และชั้น D เหลือเท่าไร?

ลองตอบก่อนเปิดเฉลย

หน้านี้จะคำนวณตัวเลขทุกตัวในเฉลยนี้ให้ดูทีละขั้น ที่ 100 PSA ชั้น A มี average life 4.92 ปี และชั้น D มี 24.60 ปี ตรงกับที่ขาย แต่ที่ 200 PSA ชั้น A เหลือ 3.06 ปี และชั้น D เหลือ 18.12 ปี

\[\begin{aligned}\Delta\mathrm{AL}_A&=3.06-4.92=-1.86,\\\Delta\mathrm{AL}_D&=18.12-24.60=-6.48.\end{aligned}\]

บริษัทประกันเสียอายุไป 6.48 ปี ส่วนกองทุนตลาดเงินเสียไป 1.86 ปี คิดเป็น $6.48/1.86=3.5$ เท่า ความเสี่ยงเรื่องเวลาไม่ได้หายไป และถ้าเอาอายุของสี่ชั้นมาเฉลี่ย โดยถ่วงด้วยขนาดของชั้น จะได้อายุของ pool ทั้งก้อนทุกความเร็ว คือ 11.67 ปีที่ 100 PSA และ 7.69 ปีที่ 200 PSA การแบ่งชั้นจึงย้ายความไม่แน่นอนไปมาระหว่างผู้ถือได้ แต่ทำให้มันหายไปไม่ได้

ภาพรวมก่อนลงสูตร

pass-through ส่งเงินต้นให้ผู้ถือทุกคนตามสัดส่วน เดือนไหน pool ได้เงินต้นคืน 1% ของหนี้ ผู้ถือทุกคนก็ได้เงินต้นคืน 1% ของเงินที่ลงไป ทุกคนจึงได้อายุเดียวกัน แต่ผู้ลงทุนแต่ละกลุ่มต้องการต่างกัน กองทุนตลาดเงินอยากได้ของสั้น บริษัทประกันอยากได้ของยาว และไม่มีใครชอบที่ไม่รู้ว่าเงินต้นจะกลับมาเมื่อไร ความไม่รู้นี้เรียกว่า prepayment risk

collateralized mortgage obligation (CMO) แปลตรง ๆ ว่าหนี้ที่มีสินเชื่อบ้านเป็นหลักประกัน CMO แก้ปัญหาข้างบนโดยไม่แตะเงินของ pool เลย มันเปลี่ยนแค่กติกาว่าเงินต้นของแต่ละเดือนไปถึงใครก่อน ตลาดเรียกแต่ละชั้นว่า tranche และเรียกชุดกติกาแจกเงินว่า waterfall

กติกาที่ง่ายที่สุดคือแบบเรียงคิว (sequential) มีสองข้อ:

  • ดอกเบี้ย: ทุกชั้นที่ยังมีหนี้ได้ดอกเบี้ยทุกเดือน ตามหนี้ที่ตัวเองยังค้าง
  • เงินต้น: เงินต้นทั้งเดือนไปชั้น A ก่อน จนหนี้ของ A หมด แล้วจึงไปชั้น B ต่อด้วย C และ D

ให้นึกถึงถังน้ำสี่ใบวางเป็นขั้นบันได น้ำเติมถังแรกจนเต็ม แล้วล้นลงถังถัดไป ชั้นหน้าจึงได้เงินต้นคืนเร็ว ชั้นท้ายได้คืนช้า จากกติกานี้ ตลาดสร้างแบบอื่นต่อได้อีกสามแบบ:

  • ชั้น Z ซึ่งทบดอกเบี้ยเข้าหนี้ของตัวเองแทนการรับเงินสด
  • ชั้น PAC ซึ่งได้เงินต้นตามตารางที่ประกาศไว้ล่วงหน้า
  • floater กับ inverse floater คือการตัดชั้นดอกเบี้ยคงที่เป็นสองชิ้น ชิ้นหนึ่งได้ดอกเบี้ยที่ขึ้นตามตลาด อีกชิ้นได้ดอกเบี้ยที่ลดลงเมื่อตลาดขึ้น

หน้านี้เดินไปตามลำดับนี้: แจกเงินของ pool ผ่านสี่ชั้นทีละเดือน หา average life ของแต่ละชั้น พิสูจน์ว่าค่าเฉลี่ยถ่วงของทุกชั้นต้องเท่ากับของ pool เสมอ ดูว่าแต่ละชั้นขยับเท่าไรเมื่อความเร็วเปลี่ยน แล้วสร้าง Z, PAC, floater และ inverse floater ทีละแบบ ตัวเลขทั้งหมดมาจาก pool ใน workbook ของคอร์ส และคำนวณซ้ำได้ด้วยโค้ดท้ายหน้า

ศัพท์ที่ใช้ในหัวข้อนี้
Pool และ pass-through
pool คือสินเชื่อบ้านจำนวนมากที่รวมเป็นก้อนเดียว pass-through คือตราสารที่ส่งเงินผ่อนทั้งหมดของ pool (ทั้งเงินต้นและดอกเบี้ย) ต่อให้ผู้ถือตามสัดส่วน รายละเอียดอยู่ในหน้าการคืนก่อนกำหนด
PSA
หน่วยวัดความเร็วที่ผู้กู้คืนหนี้ก่อนกำหนด 100 PSA คือเส้นมาตรฐานของตลาด 200 PSA คือเร็วเป็นสองเท่าของเส้นนั้น และ 50 PSA คือช้าเป็นครึ่งหนึ่ง
Average life
เวลาเฉลี่ยที่เงินต้นแต่ละดอลลาร์กลับมาถึงผู้ถือ โดยถ่วงด้วยจำนวนเงินต้นที่ได้ในแต่ละเดือน มีหน่วยเป็นปี
Collateralized mortgage obligation (CMO)
ตราสารหลายชั้นที่มี pool สินเชื่อบ้านหรือ pass-through เป็นหลักประกัน แต่ละชั้นได้เงินตามกติกาของตัวเอง จึงสร้างของหลายอายุและหลายความเสี่ยงจากเงินชุดเดียวได้
Tranche
ชั้นหนึ่งของ CMO แต่ละชั้นมียอดหนี้ อัตราดอกเบี้ย และลำดับการได้เงินต้นของตัวเอง คำนี้มาจากภาษาฝรั่งเศส แปลว่าชิ้น
Waterfall
ชุดกติกาที่บอกว่าเงินที่ pool เก็บได้ในแต่ละเดือนไหลไปชั้นไหนก่อนหลัง กติกาเขียนไว้ในเอกสารที่ออกมาพร้อม CMO แต่ละรุ่น ละเอียดจนตัดสินได้ทุกดอลลาร์โดยไม่ต้องตีความ
Principal window
ช่วงเดือนที่ชั้นหนึ่งได้เงินต้น ตั้งแต่ดอลลาร์แรกจนหนี้ของชั้นหมด ใช้บอกผู้ซื้อว่าเงินต้นจะกลับมาในช่วงไหน
Accrual (Z) tranche
ชั้นที่ไม่ได้ดอกเบี้ยเป็นเงินสด จนกว่าชั้นหน้าจะได้เงินต้นคืนครบ ระหว่างนั้นดอกเบี้ยของมันถูกบวกเข้าหนี้ของชั้น และเงินสดก้อนนั้นถูกส่งไปจ่ายเงินต้นของชั้นหน้าแทน
PAC และ support
PAC (planned amortization class) คือชั้นที่ได้เงินต้นตามตารางที่ประกาศไว้ ตราบใดที่ความเร็วอยู่ในช่วงที่ออกแบบ (PSA band) ชั้น support (หรือ companion) รับเงินต้นส่วนเกินเมื่อเงินมาเร็ว และรอเมื่อเงินมาช้า จึงรับความไม่แน่นอนแทน PAC
Floater และ inverse floater
สองชิ้นที่ตัดจากชั้นดอกเบี้ยคงที่ชั้นเดียว floater ได้ดอกเบี้ยเท่ากับอัตราอ้างอิงของตลาดบวกส่วนเพิ่มคงที่ inverse floater ได้ดอกเบี้ยที่ลดลงเมื่ออัตราอ้างอิงขึ้น ดอกเบี้ยของสองชิ้นรวมกันเท่ากับดอกเบี้ยคงที่เดิมพอดี
Agency
หน่วยงานที่รัฐบาลสหรัฐตั้งหรือหนุนหลัง เช่น Ginnie Mae, Fannie Mae และ Freddie Mac ซึ่งค้ำประกันเงินต้นของ pool ถ้าผู้กู้ผิดนัด ผู้ถือก็ยังได้เงินต้นคืนครบ

$c_k,\ I^k_t$อัตราดอกเบี้ยของชั้น $k$ และดอกเบี้ยที่ชั้นนั้นได้ในเดือน $t$สัดส่วนต่อปี, ล้านดอลลาร์

ขั้นที่ 1 — เงินเดือนแรก และเดือนที่ล้นไป B

ก่อนเขียนกติกาเป็นสูตร ลองแจกเงินด้วยมือสองเดือน เดือนแรกง่ายที่สุด เพราะเงินต้นทั้งหมดไปชั้น A เดือนที่ 117 น่าสนใจกว่า เพราะ A หมดหนี้ในเดือนนั้น แล้วเงินส่วนที่เหลือล้นไป B

โจทย์ให้อะไรมาบ้าง: ตัวเลขทั้งหมดเป็นล้านดอลลาร์ ปัดสี่ตำแหน่ง

  • หนี้ตั้งต้นของแต่ละชั้น: A 194.5, B 36, C 96.5 และ D 73
  • ทุกชั้นได้ดอกเบี้ย 7.50% ต่อปี เท่ากับอัตราที่ pass-through จ่ายให้ผู้ถือ (pass-through rate) ผู้กู้จ่าย 8.125% ส่วนต่างเป็นค่าธรรมเนียมของผู้เก็บเงินผ่อนและผู้ค้ำประกัน
  • เงินต้นที่ pool เก็บได้ในเดือนแรกที่ 100 PSA: $Q_1=0.5350$ ค่านี้คือเงินผ่อนตามตาราง บวกเงินที่ผู้กู้คืนก่อนกำหนด ซึ่งหน้าการคืนก่อนกำหนดคำนวณไว้แล้ว
  • เดือนที่ 117: pool เก็บเงินต้นได้ $Q_{117}=1.4016$ และ A เหลือหนี้ต้นเดือนแค่ 0.8668 สองค่านี้มาจากการแจกเงินครบทุกเดือนในขั้นที่ 2

ให้ $X^k_t$ คือเงินต้นที่ชั้น $k$ ได้ในเดือน $t$ และ $B^k_t$ คือหนี้ที่ชั้น $k$ ยังค้างหลังเดือน $t$ ชั้นหนึ่งรับเงินต้นได้ไม่เกินหนี้ที่ตัวเองค้าง และไม่เกินเงินที่ยังเหลือในเดือนนั้น จึงรับค่าที่น้อยกว่าของสองอย่างนี้ ($\min$) แจกสองเดือนได้ดังนี้

\[ \begin{aligned} X^A_1&=\min(0.5350,\ 194.5)\\ &=0.5350,\\ B^A_1&=194.5-0.5350=193.9650,\\ X^A_{117}&=\min(1.4016,\ 0.8668)\\ &=0.8668,\\ X^B_{117}&=1.4016-0.8668=0.5348,\\ B^B_{117}&=36-0.5348=35.4652. \end{aligned} \]

ทำแบบเดียวกันทุกเดือนแล้วเขียนเป็นสูตรทั่วไปได้ ชั้นถัดไปได้เฉพาะเงินที่ชั้นก่อนหน้ารับไม่หมด และชั้น D ซึ่งอยู่ท้ายคิวได้เงินที่เหลือทั้งหมด

\[ \begin{aligned} X^A_t&=\min(Q_t,\ B^A_{t-1}),\\ X^B_t&=\min(Q_t-X^A_t,\ B^B_{t-1}),\\ X^C_t&=\min(Q_t-X^A_t-X^B_t,\\ &\qquad\ \ B^C_{t-1}),\\ X^D_t&=Q_t-X^A_t-X^B_t-X^C_t,\\ I^k_t&=\tfrac{0.075}{12}B^k_{t-1}. \end{aligned} \]

$I^k_t$ คือดอกเบี้ยที่ชั้น $k$ ได้ในเดือน $t$ คิดจากหนี้ต้นเดือน $B^k_{t-1}$ ไม่ใช่หนี้หลังจ่ายเงินต้น อัตราต่อเดือนคืออัตราต่อปีหารด้วย 12: $0.075/12=0.00625$

คำตอบ: เดือนแรก เงินต้น \$0.5350 ล้านไปชั้น A ทั้งหมด หนี้ของ A ลดเหลือ \$193.9650 ล้าน ชั้นอื่นไม่ได้เงินต้น แต่ทุกชั้นได้ดอกเบี้ยตามหนี้ตั้งต้นของตัวเอง (ล้านดอลลาร์):

\[ \begin{aligned} I^A_1&=0.00625\times194.5=1.2156,\\ I^B_1&=0.00625\times36=0.2250,\\ I^C_1&=0.00625\times96.5=0.6031,\\ I^D_1&=0.00625\times73=0.4563. \end{aligned} \]

ตรวจเองใน 10 วินาที: ดอกเบี้ยสี่ชั้นรวมกันต้องเท่ากับดอกเบี้ยที่ pass-through จ่ายในเดือนแรก เพราะเงินทั้งหมดมาจากก้อนเดียวกัน

\[ \begin{aligned} \textstyle\sum_k I^k_1&=1.2156+0.2250\\ &\quad+0.6031+0.4563\\ &=2.5000,\\ 0.00625\times400&=2.5000. \end{aligned} \]

สองค่าเท่ากันพอดี เงินต้นที่แจกรวมกันก็เท่ากับ $Q_1$ ไม่มีดอลลาร์ไหนเกิดใหม่หรือหายไป ในตัวอย่างนี้ทุกชั้นได้อัตรา 7.50% เท่ากัน CMO จริงตั้งอัตราของแต่ละชั้นต่างกันได้ แต่ค่าเฉลี่ยของอัตรา ถ่วงด้วยหนี้ของแต่ละชั้น ต้องไม่เกิน 7.50% ไม่อย่างนั้นดอกเบี้ยของ pool ไม่พอจ่าย

ขั้นที่ 2 — เดินครบ 357 เดือน: ใครได้เงินต้นช่วงไหน

สองเดือนข้างบนคือกติกาเดียวกันที่ใช้ซ้ำได้ทุกเดือน ขั้นนี้จึงใช้กติกาเรียงคิวกับทุกเดือนของ pool ซึ่งมีทั้งหมด 357 เดือน เพราะสินเชื่อ 30 ปีมี $30\times12=360$ งวด และปล่อยมาแล้ว 3 เดือน: $360-3=357$ เงินต้นรายเดือน $Q_t$ ทั้ง 357 ค่ามาจากการเดินเงินของ pool ที่ 100 PSA

ทุกเดือน หนี้ของแต่ละชั้นลดลงเท่ากับเงินต้นที่ชั้นนั้นได้ สิ่งที่อยากรู้คือแต่ละชั้นได้เงินต้นช่วงเดือนไหน ช่วงนี้เรียกว่า principal window

\[ \begin{aligned} B^k_t&=B^k_{t-1}-X^k_t,\\ \text{A}&:\ 1\le t\le117,\\ \text{B}&:\ 117\le t\le145,\\ \text{C}&:\ 145\le t\le242,\\ \text{D}&:\ 242\le t\le357. \end{aligned} \]

ช่วงเดือนของสี่ชั้นต่อกันเป็นคิว เพราะชั้นถัดไปเริ่มได้เงินต้นในเดือนเดียวกับที่ชั้นก่อนหน้าหมดหนี้ ชั้น A ได้เงินต้นทุกเดือนตั้งแต่เดือนแรก และหมดหนี้ในเดือนที่ 117 คือปีที่ $117/12=9.75$ ในเดือนนั้น เงินต้นส่วนที่เกินหนี้ที่เหลือของ A ไหลไป B ทันที เดือนที่ 117 จึงมีสองชั้นได้เงินต้นพร้อมกัน

B เป็นชั้นที่เล็กที่สุด (\$36 ล้าน) จึงหมดเร็ว ใช้เวลาแค่ $145-117+1=29$ เดือน ชั้น D ต้องรอถึงเดือนที่ 242 คือปีที่ $242/12=20.17$ กว่าจะได้เงินต้นดอลลาร์แรก แต่ระหว่างรอ D ได้ดอกเบี้ยทุกเดือน

ขั้นที่ 3 — average life ของแต่ละชั้น

principal window บอกแค่ช่วงเดือน ผู้ซื้อยังต้องการตัวเลขเดียวที่บอกว่าเงินต้นของชั้นนี้กลับมาโดยเฉลี่ยตอนไหน ตัวเลขนั้นคือ average life วิธีคิดเหมือนกับ average life ของ pool ในหน้าการคืนก่อนกำหนด เงินต้นที่ได้ในเดือน $t$ กลับมาตอนปีที่ $t/12$ เอาเวลานี้มาเฉลี่ย โดยให้น้ำหนักตามเงินต้น $X^k_t$ ที่ชั้นนั้นได้ในเดือนนั้น

ตัวหารคือหนี้ตั้งต้นของชั้น $B^k_0$ เพราะเงินต้นทุกดอลลาร์ของชั้นต้องกลับมาครบ น้ำหนักทั้งหมดจึงรวมกันได้ $\sum_t X^k_t=B^k_0$ พอดี

\[ \begin{aligned} \mathrm{AL}_k&=\frac{1}{B^k_0}\sum_t\frac{t}{12}X^k_t,\\ \mathrm{AL}_A&=4.92,\quad \mathrm{AL}_B=10.88,\\ \mathrm{AL}_C&=15.80,\quad \mathrm{AL}_D=24.60,\\ \mathrm{AL}_{\rm pool}&=11.67. \end{aligned} \]

pool เดียวกันให้ของสี่อายุ ตั้งแต่ 4.92 ถึง 24.60 ปี ตัวเลขทั้งห้าคำนวณด้วยโค้ดท้ายหน้า และตรงกับ workbook ทุกหลักที่แสดง $\mathrm{AL}_{\rm pool}=11.67$ คือ average life ของ pool ทั้งก้อน ซึ่งหน้าการคืนก่อนกำหนดคำนวณไว้แล้ว

ตรวจด้วยตาได้ว่าตัวเลขสมเหตุสมผล ชั้น A ได้เงินต้นในเดือน 1 ถึง 117 อายุเฉลี่ยของมันจึงต้องไม่เกิน 9.75 ปี ชั้น D ได้เงินต้นในเดือน 242 ถึง 357 อายุจึงต้องอยู่ระหว่าง $242/12=20.17$ กับ $357/12=29.75$ ปี ทั้ง 4.92 และ 24.60 อยู่ในช่วงของตัวเอง ชั้น A สั้นเพราะได้เงินต้นทุกเดือนตั้งแต่แรก ชั้น D ยาวเพราะต้องรอให้สามชั้นหน้าได้คืนครบก่อน

ขั้นที่ 4 — ทำไมค่าเฉลี่ยของทุกชั้นต้องเท่ากับของ pool

ผู้จัดตั้งอาจพูดว่าการแบ่งชั้น “ทำให้เงินกลับเร็วขึ้น” ขั้นนี้แสดงว่าเป็นไปไม่ได้ ถ้าเอาอายุของแต่ละชั้นมาเฉลี่ย โดยถ่วงด้วยขนาดของชั้น จะได้อายุของ pool เสมอ ไม่ว่ากติกาการแบ่งจะเป็นแบบไหน ในสูตร $B_0=400$ คือหนี้ตั้งต้นของ pool ทั้งก้อน $\sum_k$ คือบวกทุกชั้น และ $\sum_t$ คือบวกทุกเดือน

\[ \begin{aligned} \sum_k B^k_0\,\mathrm{AL}_k&=\sum_k\sum_t\frac{t}{12}X^k_t\\ &=\sum_t\frac{t}{12}\sum_k X^k_t\\ &=\sum_t\frac{t}{12}Q_t\\ &=B_0\,\mathrm{AL}_{\rm pool},\\ \sum_k\frac{B^k_0}{B_0}\mathrm{AL}_k&=\mathrm{AL}_{\rm pool}. \end{aligned} \]

แนวคิดคือ average life เป็นเวลาเฉลี่ยของเงินต้นทุกดอลลาร์ การแบ่งชั้นแค่เขียนชื่อชั้นลงบนแต่ละดอลลาร์ ไม่ได้เปลี่ยนว่าดอลลาร์นั้นมาถึงเดือนไหน ในสูตร เมื่อคูณนิยามของ $\mathrm{AL}_k$ ด้วย $B^k_0$ ตัวหารก็หายไป เหลือผลรวมของเวลาคูณเงินต้น

ขั้นที่สำคัญคือการสลับลำดับการบวก จากบวกทีละชั้นเป็นบวกทีละเดือน สลับได้เพราะเป็นผลรวมของพจน์จำนวนจำกัด ($4\times357$ พจน์) บวกลำดับไหนก็ได้ผลเท่ากัน หลังสลับ แต่ละเดือนเหลือ $\sum_k X^k_t$ ซึ่งคือเงินต้นของเดือนนั้นที่แจกไปทุกชั้นรวมกัน waterfall แจกเงินต้นของเดือนหนึ่งได้ $Q_t$ พอดี ไม่มากไม่น้อย ผลรวมจึงกลายเป็นนิยามของ average life ของ pool คูณ $B_0$ หารทั้งสองข้างด้วย $B_0$ จะได้ว่าค่าเฉลี่ยของ $\mathrm{AL}_k$ ที่ถ่วงด้วยสัดส่วนขนาด $B^k_0/B_0$ เท่ากับ $\mathrm{AL}_{\rm pool}$

เงื่อนไขเดียวที่ใช้คือ “แจกเงินต้นของทุกเดือนให้ครบ $Q_t$” ข้อสรุปนี้จึงเป็นจริงกับ waterfall ทุกแบบที่แจกเงินต้นแบบนี้ รวมทั้ง PAC ที่จะเห็นต่อไป (ชั้น Z เป็นข้อยกเว้น เพราะมันเอาดอกเบี้ยมาแจกเป็นเงินต้นด้วย) ตรวจด้วยตัวเลขของขั้นที่แล้ว ใช้สามตำแหน่งเพื่อไม่ให้การปัดเศษบังผล:

\[ \begin{aligned} 194.5\times4.918&=956.55,\\ 36\times10.877&=391.57,\\ 96.5\times15.798&=1{,}524.51,\\ 73\times24.599&=1{,}795.73,\\ \textstyle\sum_k B^k_0\,\mathrm{AL}_k&=4{,}668.36,\\ 4{,}668.36/400&=11.671. \end{aligned} \]

ได้ 11.671 ปี ตรงกับ pool การแบ่งชั้นจึงเป็นการแลกอายุระหว่างผู้ถือ ชั้น A ได้อายุสั้นเพราะชั้น D รับอายุยาวแทน

ขั้นที่ 5 — เมื่อความเร็วเปลี่ยน ทุกชั้นขยับ

ขั้นนี้ตอบคำถามตอนต้นหน้า ทุกอย่างข้างบนคิดที่ 100 PSA แต่ความเร็วจริงขึ้นกับอัตราดอกเบี้ยตลาด ซึ่งไม่มีใครรู้ล่วงหน้า วิธีดูผลคือสร้างเงินต้นรายเดือนของ pool ชุดใหม่ที่ความเร็วอื่น แล้วแจกผ่านกติกาเรียงคิวเดิม

โจทย์ให้อะไรมาบ้าง:

  • pool และกติกาเรียงคิวเดิม
  • ความเร็ว 50, 100, 200 และ 300 PSA คือช้าเป็นครึ่งหนึ่ง เท่ามาตรฐาน เร็วสองเท่า และเร็วสามเท่า
  • average life ของ pool ทั้งก้อนที่สี่ความเร็วนี้คือ 15.13, 11.67, 7.69 และ 5.64 ปี ตามที่หน้าการคืนก่อนกำหนดคำนวณไว้

ขั้นที่ 6 — ชั้น Z: เอาดอกเบี้ยของชั้นท้ายมาเร่งชั้นหน้า

สมมติว่ากองทุนตลาดเงินอยากได้ชั้น A ที่สั้นกว่านี้อีก เงินต้นของ pool มีเท่าเดิม จึงต้องหาเงินสดจากที่อื่นมาจ่ายเงินต้นให้ A เร็วขึ้น แหล่งที่หาได้คือดอกเบี้ยของชั้น D ผู้จัดตั้งจึงเปลี่ยนชั้น D เป็นชั้นทบดอกเบี้ย (accrual หรือ Z)

กติกาคือ ตราบใดที่ A, B, C ยังมีหนี้ D ไม่ได้ดอกเบี้ยเป็นเงินสด ดอกเบี้ยของ D ถูกบวกเข้าหนี้ของ D แทน เหมือนสินเชื่อที่ยังไม่จ่ายดอกเบี้ยแล้วดอกเบี้ยไปพอกเป็นหนี้ เงินสดก้อนนั้นถูกส่งไปจ่ายเงินต้นของชั้นหน้าตามคิว ในสูตร $I^Z_t$ คือดอกเบี้ยที่ D ควรได้ $B^Z_t$ คือหนี้ของ D และ $Q'_t$ คือเงินทั้งหมดที่ waterfall แจกเป็นเงินต้นให้ A, B, C

\[ \begin{aligned} I^Z_t&=\tfrac{0.075}{12}B^Z_{t-1},\\ B^Z_t&=B^Z_{t-1}+I^Z_t,\\ Q'_t&=Q_t+I^Z_t,\\ I^Z_1&=\tfrac{0.075}{12}(73)=0.4563,\\ Q'_1&=0.5350+0.4563\\ &=0.9913. \end{aligned} \]

D ไม่ได้เสียดอกเบี้ย ดอกเบี้ยยังเป็นของ D แต่ถูกเก็บไว้เป็นหนี้ที่โตขึ้น ส่วนเงินสดของ pool ไม่ได้เพิ่มขึ้นเลย แค่ถูกเรียกชื่อใหม่ จาก “ดอกเบี้ยของ D” เป็น “เงินต้นของ A” เดือนแรก A จึงได้เงินต้น $0.9913$ ล้าน แทน $0.5350$ ล้าน คิดเป็น $0.9913/0.5350=1.85$ เท่า เกือบสองเท่า

แจกเงินแบบนี้ครบทุกเดือนที่ 100 PSA ด้วยโค้ดท้ายหน้า ได้ผลดังนี้

  • A หมดหนี้ในเดือนที่ 84 แทนเดือนที่ 117 และ average life หดจาก 4.92 เป็น 3.76 ปี
  • B หดจาก 10.88 เป็น 7.64 ปี และ C หดจาก 15.80 เป็น 9.99 ปี
  • Z ไม่ได้เงินสดเลยจนถึงเดือนที่ 140 หนี้ของมันเริ่มที่ \$73 ล้าน แต่ดอกเบี้ยพอกเข้าไปทุกเดือน สุดท้ายจึงได้เงินต้นคืนรวม \$174.64 ล้าน มากกว่าหนี้ตั้งต้น $174.64-73=101.64$ ล้าน

ผู้ถือ Z จึงได้ของที่หน้าตาเหมือนพันธบัตรไม่มีคูปองระยะยาว (zero-coupon bond คือพันธบัตรที่ไม่จ่ายอะไรเลยระหว่างทาง แล้วจ่ายก้อนเดียวตอนท้าย) ของแบบนี้ราคาไวต่ออัตราดอกเบี้ยมาก เพราะเงินทั้งหมดมาไกลในอนาคต การคิดลดจึงกินราคามากเมื่ออัตราขึ้น

ขั้นที่ 7 — PAC: สร้างตารางที่ pool จ่ายได้ทั้งสองขอบของช่วงความเร็ว

ตารางความเร็วในขั้นที่ 5 แสดงว่าชั้นเรียงคิวทุกชั้นยังขยับเมื่อความเร็วเปลี่ยน ถ้าผู้ซื้ออยากได้เงินต้นตามตารางที่รู้ล่วงหน้าจริง ๆ ต้องมีอีกชั้นหนึ่งรับความไม่แน่นอนแทน กติกา PAC ทำแบบนี้

  • เลือกช่วงความเร็วที่ออกแบบไว้ ในตัวอย่างนี้คือ 100 ถึง 250 PSA (ผู้จัดตั้งเลือกเอง)
  • ตั้งตารางเงินต้นของ PAC เดือนละ $S_t$ ให้เป็นเงินต้นที่ pool จ่ายได้แน่ ไม่ว่าความเร็วจะอยู่ที่ขอบล่างหรือขอบบนของช่วง จึงใช้ค่าที่น้อยกว่าระหว่าง $Q^{100}_t$ (เงินต้นของ pool ที่ 100 PSA) กับ $Q^{250}_t$ (ที่ 250 PSA)
  • ขนาดของ PAC คือผลรวมของตารางทุกเดือน เงินที่เหลือของ pool เป็นชั้น support
\[ \begin{aligned} S_t&=\min\big(Q^{100}_t,\ Q^{250}_t\big),\\ \textstyle\sum_t S_t&=279.74,\\ 400-279.74&=120.26,\\ X^{PAC}_t&=\min(Q_t,\ S_t,\ B^{PAC}_{t-1}),\\ X^{SUP}_t&=\min(Q_t-X^{PAC}_t,\\ &\qquad\ \ B^{SUP}_{t-1}). \end{aligned} \]

ทำไมสองเส้นสลับกันเป็นตัวน้อย? ช่วง 109 เดือนแรก pool ที่ 100 PSA จ่ายเงินต้นน้อยกว่า เพราะผู้กู้คืนก่อนกำหนดช้ากว่า ตั้งแต่เดือนที่ 110 pool ที่ 250 PSA กลับจ่ายน้อยกว่า เพราะมันหดเร็วจนเหลือหนี้ให้คืนน้อย ตารางจึงเป็นขอบล่างของทั้งสองเส้น ผลรวมของตารางทุกเดือน (คำนวณด้วยโค้ดท้ายหน้า) คือขนาดของ PAC \$279.74 ล้าน ที่เหลือ \$120.26 ล้านเป็น support

$X^{PAC}_t$ และ $X^{SUP}_t$ คือเงินต้นที่ PAC และ support ได้ในเดือน $t$ กติกาแจกเงินคือ PAC ได้ไม่เกินตารางของเดือนนั้น ส่วนเกินไป support และเมื่อ support หมดหนี้แล้ว เงินต้นทั้งหมดไป PAC ส่วนที่ PAC ได้ขาดจากตารางในเดือนก่อน กติกานี้ไม่ตามเก็บให้ทีหลัง หน้านี้และรูปข้างล่างใช้กติกานี้

ขั้นที่ 8 — PAC นิ่งในช่วง support แกว่งแทน

ตารางสร้างเสร็จแล้ว ขั้นนี้ทดสอบว่ามันทำงานตามที่สัญญาไหม คือถ้าความเร็วจริงเปลี่ยนไป อายุของ PAC ยังนิ่งหรือเปล่า และใครรับการเปลี่ยนแปลงแทน

โจทย์ให้อะไรมาบ้าง:

  • PAC \$279.74 ล้าน และ support \$120.26 ล้าน ตามตารางที่เพิ่งสร้าง
  • ความเร็วจริงที่ทดสอบ: ตั้งแต่ 50 ถึง 400 PSA ทั้งในและนอกช่วง 100 ถึง 250 PSA

แจกเงินที่แต่ละความเร็วตามกติกา PAC แล้วหา average life ของทั้งสองชั้นด้วยโค้ดท้ายหน้า ได้ผลดังนี้ (ตัวเลขในวงเล็บคือความเร็วเป็น PSA)

\[ \begin{aligned} \mathrm{AL}_{PAC}(100)&=7.91,\\ \mathrm{AL}_{PAC}(250)&=7.91,\\ \mathrm{AL}_{SUP}(100)&=20.43,\\ \mathrm{AL}_{SUP}(250)&=3.28,\\ \mathrm{AL}_{PAC}(50)&=13.26,\\ \mathrm{AL}_{PAC}(400)&=5.59. \end{aligned} \]

คำตอบ: ทุกความเร็วตั้งแต่ 100 ถึง 250 PSA PAC ได้เงินต้นตามตารางทุกเดือนพอดี เงินต้นที่ได้แต่ละเดือนจึงเหมือนกันทุกความเร็ว average life จึงเป็น 7.91 ปีทุกจุด ส่วน support แกว่งจาก 20.43 ปีลงไปถึง 3.28 ปี เพราะรับส่วนเกินทั้งหมดเมื่อเงินมาเร็ว

นอกช่วง PAC ก็ขยับ ที่ 50 PSA เงินต้นมาไม่พอจ่ายตาราง PAC จึงยืดเป็น 13.26 ปี ที่ 400 PSA support ได้คืนหมดเร็ว หลังจากนั้นเงินต้นทั้งหมดไป PAC จึงหดเหลือ 5.59 ปี

ตรวจเองใน 10 วินาที: ที่ 100 PSA ค่าเฉลี่ยถ่วงด้วยขนาดของสองชั้นต้องเท่ากับอายุของ pool ตามเหตุผลเรื่องค่าเฉลี่ยถ่วง (ใช้สามตำแหน่ง)

\[ \begin{aligned} 279.74\times7.907&=2{,}211.90,\\ 120.26\times20.427&=2{,}456.55,\\ 2{,}211.90+2{,}456.55&=4{,}668.45,\\ 4{,}668.45/400&=11.67. \end{aligned} \]

ได้ 11.67 ปี เท่ากับ pool ความนิ่งของ PAC จึงจ่ายด้วยความไม่นิ่งของ support

ขั้นที่ 9 — แยกดอกเบี้ยคงที่เป็น floater กับ inverse floater

ขั้นก่อน ๆ แบ่งเงินต้น ขั้นนี้แบ่งดอกเบี้ย ผู้ลงทุนบางกลุ่ม เช่นธนาคารที่ต้นทุนเงินฝากขึ้นลงตามตลาด อยากได้ดอกเบี้ยที่ลอยตัวตามตลาด แต่ pool จ่ายดอกเบี้ยคงที่ ผู้จัดตั้งจึงตัดชั้นดอกเบี้ยคงที่ชั้นหนึ่งเป็นสองชิ้น ชิ้นหนึ่งได้ดอกเบี้ยขึ้นตามตลาด (floater) อีกชิ้นได้ดอกเบี้ยลงเมื่อตลาดขึ้น (inverse floater)

โจทย์ให้อะไรมาบ้าง:

  • ชั้นที่ตัดคือชั้น C: หนี้ $B=\$96.5$ ล้าน ดอกเบี้ยคงที่ $c=7.50\%$ ต่อปี
  • floater เอา 75% ของชั้น: $B_f=0.75\times96.5=72.375$ ล้าน
  • inverse floater เอาอีก 25%: $B_i=0.25\times96.5=24.125$ ล้าน
  • $L$ คืออัตราอ้างอิงของตลาด (อัตราดอกเบี้ยระยะสั้นที่ประกาศใหม่ทุกงวด) floater ได้ $L$ บวกส่วนเพิ่มคงที่ $m=0.5\%$

สัดส่วน 75/25 และส่วนเพิ่ม $m$ เป็นตัวเลขตัวอย่าง (สมมติ) ซึ่งในตลาดจริงผู้จัดตั้งเลือกเองให้ตรงกับผู้ซื้อ

ข้อจำกัดมีข้อเดียว ดอกเบี้ยที่จ่ายให้สองชิ้นรวมกันต้องเท่ากับดอกเบี้ยที่ชั้น C ได้ ทุกเดือน และทุกระดับของ $L$ เพราะเงินมีแค่นั้น ให้ $c_f$ และ $c_i$ คืออัตราดอกเบี้ยของ floater และ inverse floater แล้วแก้หา $c_i$

\[ \begin{aligned} B_fc_f+B_ic_i&=Bc,\\ c_f&=L+m,\\ c_i&=\frac{Bc-B_fm}{B_i}-\frac{B_f}{B_i}L\\ &=K-gL,\\ g&=\frac{72.375}{24.125}=3,\\ Bc&=96.5\times0.075=7.2375,\\ B_fm&=72.375\times0.005=0.3619,\\ K&=\frac{7.2375-0.3619}{24.125}\\ &=\frac{6.8756}{24.125}=28.5\%. \end{aligned} \]

แนวคิดคือ inverse floater ได้ดอกเบี้ยส่วนที่เหลือหลังจ่าย floater แล้ว เมื่อ $L$ ขึ้น floater เอาไปมากขึ้น inverse floater จึงเหลือน้อยลง ผลคือเส้นตรง $c_i=K-gL$ ที่ลดลงตาม $L$ ความชัน $g=B_f/B_i$ คือขนาดของ floater หารด้วยขนาดของ inverse floater ที่นี่ $g=3$ เพราะ floater ใหญ่กว่าสามเท่า เมื่อ $L$ ขึ้น 1% floater เอาเงินเพิ่มไป $B_f\times1\%=3B_i\times1\%$ inverse floater จึงเสียดอกเบี้ย 3% ของหนี้ตัวเอง ส่วน $K$ คืออัตราของ inverse floater ตอนที่ $L=0$

ลองที่ $L=5\%$ (จุดในรูปข้างล่าง) แล้วตรวจว่าดอกเบี้ยรวมยังเท่าเดิม

\[ \begin{aligned} c_f&=5\%+0.5\%=5.5\%,\\ c_i&=28.5\%-3\times5\%=13.5\%,\\ 0.75\times5.5\%&+0.25\times13.5\%\\ &=4.125\%+3.375\%=7.5\%. \end{aligned} \]

เป็นเงินในเดือนแรก floater ได้ $72.375\times0.055/12=0.3317$ ล้าน และ inverse floater ได้ $24.125\times0.135/12=0.2714$ ล้าน รวมกัน $0.3317+0.2714=0.6031$ ล้าน เท่ากับดอกเบี้ยของชั้น C ในขั้นที่ 1 พอดี

ดอกเบี้ยติดลบไม่ได้ $c_i$ จึงหยุดที่ศูนย์เมื่อ $L$ ขึ้นถึง $K/g=28.5\%/3=9.5\%$ ส่วน floater ต้องมีเพดาน เพราะดอกเบี้ยทั้งหมดของชั้น C หารด้วยขนาดของ floater ได้แค่ $7.5\%/0.75=10\%$ เมื่อ $L=9.5\%$ floater ได้ $9.5\%+0.5\%=10\%$ ชนเพดานพอดี ผู้ถือ inverse floater จึงรับความไวต่ออัตราดอกเบี้ยเป็นสามเท่า (ดอกเบี้ยลด 3 จุดทุกครั้งที่ $L$ ขึ้น 1 จุด) และยังไวต่อความเร็วการคืนก่อนกำหนดเหมือนชั้น C เดิม

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

แบ่งเงินต้นตามสัดส่วน: คนที่คุ้นกับ pass-through มักแบ่งเงินต้นให้ทุกชั้นตามขนาด แต่ CMO เรียงคิว ไม่ได้แบ่งตามสัดส่วน ตารางเงินของทุกชั้นจึงผิดตั้งแต่เดือนแรก

\[ \begin{aligned} \text{wrong: }X^A_1&=0.535\times\tfrac{194.5}{400}=0.260,\\ \text{right: }X^A_1&=\min(0.535,\ 194.5)=0.535. \end{aligned} \]

คิดดอกเบี้ยจากหนี้หลังจ่ายเงินต้น: ดอกเบี้ยของเดือนหนึ่งคิดจากหนี้ต้นเดือน ถ้าใช้หนี้ปลายเดือน ดอกเบี้ยของ A จะต่ำไป และผลรวมสี่ชั้นจะไม่เท่ากับดอกเบี้ยของ pool

\[ \begin{aligned} \text{wrong: }I^A_1&=193.965\times0.00625=1.2123,\\ \text{right: }I^A_1&=194.5\times0.00625=1.2156. \end{aligned} \]

ถ้าใช้ค่าผิด ผลรวมสี่ชั้นเป็น $1.2123+0.2250+0.6031+0.4563=2.4967$ ไม่ใช่ 2.5000

เชื่อว่าการแบ่งชั้นลดความเสี่ยงรวม: ค่าเฉลี่ยถ่วงของอายุเท่ากับของ pool เสมอ ความเสี่ยงที่ชั้นหนึ่งไม่ได้รับจึงต้องไปอยู่ที่ชั้นอื่น เมื่อความเร็วขึ้นจาก 100 เป็น 200 PSA อายุของ pool หดไป $11.67-7.69=3.98$ ปี และค่าเฉลี่ยถ่วงของสี่ชั้นก็หดไป 3.98 ปีเท่ากัน ไม่มีส่วนไหนหายไป

เชื่อ PAC นอกช่วงที่ออกแบบ: ตารางของ PAC รับประกันแค่ในช่วง 100 ถึง 250 PSA ที่ 50 PSA PAC ยืดจาก 7.91 เป็น 13.26 ปี คือยาวขึ้น $13.26-7.91=5.35$ ปี และช่วงที่ปลอดภัยจริงจะแคบลงเรื่อย ๆ หลังวันออก เมื่อ support ถูกจ่ายคืนไปก่อน

คิดว่าชั้นท้ายปลอดภัยที่สุดเพราะอยู่ท้ายคิว: ในเรื่องเวลา D กลับเลื่อนเป็นจำนวนปีมากที่สุด เมื่อความเร็วขึ้นจาก 100 เป็น 200 PSA D หด $24.60-18.12=6.48$ ปี ส่วน A หดแค่ $4.92-3.06=1.86$ ปี ส่วนเรื่องการผิดนัด pool นี้มี agency ค้ำประกัน จึงไม่มีชั้นไหนขาดทุนเงินต้น ลำดับเงินต้นของ CMO จึงไม่ใช่ลำดับการรับขาดทุน การไหลของขาดทุนลงชั้นต่าง ๆ เป็นกติกาอีกแบบ ซึ่งอยู่ในหน้าCDO และ Gaussian copula

ใช้ทำอะไรบนโต๊ะจริง

ทีมเทรดที่ตั้งราคา CMO ทำแบบเดียวกับหน้านี้ แต่ละเอียดกว่า ขั้นแรก สร้างเงินต้นรายเดือนของ pool ที่หลายความเร็ว หรือตามหลายเส้นทางของอัตราดอกเบี้ย ขั้นที่สอง แจกเงินผ่าน waterfall ตามเอกสารของ CMO รุ่นนั้นทีละข้อ ขั้นที่สาม คิดมูลค่าปัจจุบันของเงินที่แต่ละชั้นได้แยกกัน

รายงานที่ขาดไม่ได้คือ average life และ principal window ของทุกชั้นที่หลายความเร็ว เหมือนตารางความเร็วข้างบน สำหรับ PAC ต้องรายงานด้วยว่าวันนี้ช่วงความเร็วที่ยังรักษาตารางได้เหลือเท่าไร เพราะช่วงนี้แคบลงตามเวลา ไม่ใช่ช่วงที่ประกาศในวันออก ความไม่แน่นอนทั้งหมดของ pool ไปกองที่ชั้น support คนที่ซื้อ support จึงได้ผลตอบแทนสูงกว่าเป็นค่าตอบแทน และมักเป็นคนที่เชื่อว่าตัวเองคาดความเร็วได้ดีกว่าตลาด

CMO ตัวแรกออกโดย Freddie Mac ในปี 1983 ใช้กติกาเรียงคิวแบบเดียวกับที่หน้านี้เริ่ม ชั้น Z, PAC และ floater กับ inverse floater ตามมาทีหลัง เพื่อสร้างของให้ตรงกับผู้ซื้อแต่ละกลุ่มมากขึ้น

โจทย์ตรวจความเข้าใจ

1. CMO เรียงคิวสี่ชั้นของหน้านี้ ที่ 100 PSA หลังเดือนแรก ชั้น A เหลือหนี้ \$193.9650 ล้าน (จากขั้นที่ 1) เดือนที่ 2 pool เก็บเงินต้นได้ $Q_2=\$0.6034$ ล้าน (ค่าจากโค้ดท้ายหน้า) หลังเดือนที่ 2 ชั้น A เหลือหนี้เท่าไร ชั้น B ได้เงินต้นเท่าไร และ A ได้ดอกเบี้ยเท่าไร?

เฉลย

หนี้ของ A ต้นเดือนมากกว่าเงินต้นที่เข้ามา เงินต้นทั้งหมดจึงไป A และไม่เหลือให้ B ดอกเบี้ยคิดจากหนี้ต้นเดือน (ล้านดอลลาร์)

\[ \begin{aligned} X^A_2&=\min(0.6034,\ 193.9650)\\ &=0.6034,\\ B^A_2&=193.9650-0.6034=193.3616,\\ X^B_2&=0.6034-0.6034=0,\\ I^A_2&=193.9650\times0.00625=1.2123. \end{aligned} \]

2. ผู้ซื้อคนหนึ่งสงสัยว่าข้อพิสูจน์เรื่องค่าเฉลี่ยถ่วงยังจริงไหมเมื่อความเร็วช้าลง ใช้แถว 50 PSA ของตารางความเร็ว ตรวจว่าค่าเฉลี่ยของอายุสี่ชั้น ถ่วงด้วยขนาด เท่ากับอายุของ pool 15.13 ปี

เฉลย
\[ \begin{aligned} 194.5\times7.49&=1{,}456.81,\\ 36\times15.99&=575.64,\\ 96.5\times21.03&=2{,}029.40,\\ 73\times27.25&=1{,}989.25,\\ \textstyle\sum_k B^k_0\,\mathrm{AL}_k&=6{,}051.10,\\ 6{,}051.10/400&=15.13. \end{aligned} \]

ได้ 15.13 ปี เท่ากับช่องของ pool ตัวเลขในตารางปัดสองตำแหน่ง ผลจึงอาจคลาดที่หลักสุดท้ายได้

3. inverse floater ที่ตัดจากชั้น C ในขั้นที่ 9 มีอัตรา $c_i=28.5\%-3L$ และ floater มีอัตรา $L+0.5\%$ โดยมีเพดาน 10% ถ้าอัตราอ้างอิงของตลาดขึ้นเป็น $L=8\%$ และ $L=10\%$ แต่ละชิ้นได้ดอกเบี้ยเท่าไร?

เฉลย

ที่ $L=8\%$ ทั้งสองชิ้นยังไม่ชนพื้นหรือเพดาน

\[ \begin{aligned} c_i&=28.5\%-3\times8\%=4.5\%,\\ c_f&=8\%+0.5\%=8.5\%,\\ 0.75\times8.5\%&+0.25\times4.5\%\\ &=6.375\%+1.125\%=7.5\%. \end{aligned} \]

ที่ $L=10\%$ สูตรให้ $c_i=28.5\%-3\times10\%=-1.5\%$ แต่ดอกเบี้ยติดลบไม่ได้ $c_i$ จึงเป็นศูนย์ floater อยากได้ $10\%+0.5\%=10.5\%$ แต่เงินดอกเบี้ยของชั้น C พอจ่ายแค่ $7.5\%/0.75=10\%$ floater จึงได้ 10% ซึ่งคือเพดาน

const {min, max} = Math;
function num(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(`${name} must be a finite number`);
  return x;
}

// Monthly principal Q_t of the course pool ($400M, 8.125%, 3 months seasoned) at k times PSA.
function poolPrincipal(k, B = 400, wac = 0.08125, season = 3, N = 360) {
  if (!(num('k', k) > 0 && k * 0.06 < 1)) throw new RangeError('k must be positive and keep CPR below 100%');
  const r = wac / 12, Q = [];
  for (let t = 1; t <= N - season && B > 1e-12; t++) {
    const A = B * r / (1 - (1 + r) ** -(N - season - t + 1)), P = A - B * r;
    const smm = 1 - (1 - k * min(0.002 * (t + season), 0.06)) ** (1 / 12), PP = (B - P) * smm;
    Q.push(P + PP); B -= P + PP;
  }
  return Q;
}
// Sequential waterfall: each month's principal fills tranche 1, then 2, ...
function sequential(Q, sizes) {
  if (!Array.isArray(sizes) || sizes.some(s => !(num('size', s) > 0))) throw new RangeError('tranche sizes must be positive numbers');
  const bal = sizes.slice(), pay = sizes.map(() => []);
  for (const q0 of Q) {
    let q = q0;
    for (let i = 0; i < bal.length; i++) { const x = min(q, bal[i]); pay[i].push(x); bal[i] -= x; q -= x; }
  }
  return pay;
}
// Last tranche is a Z: while the others are outstanding its interest accrues and pays their principal.
function withZ(Q, sizes, c = 0.075) {
  const bal = sizes.slice(), pay = sizes.map(() => []), z = bal.length - 1;
  for (const q0 of Q) {
    const accr = bal[z] * c / 12, active = bal.slice(0, z).some(b => b > 1e-9);
    let q = q0 + (active ? accr : 0);
    if (active) bal[z] += accr;
    for (let i = 0; i < bal.length; i++) { const x = min(q, bal[i]); pay[i].push(x); bal[i] -= x; q -= x; }
  }
  return pay;
}
function averageLife(pay) {
  let tw = 0, w = 0;
  pay.forEach((x, i) => { tw += (i + 1) * x; w += x; });
  if (!(w > 0)) throw new RangeError('no principal paid');
  return tw / (12 * w);
}
const windowOf = p => [p.findIndex(x => x > 1e-12) + 1, p.length - [...p].reverse().findIndex(x => x > 1e-12)];
// PAC takes min(Q, schedule, balance) while support lives; support takes the rest; no catch-up of shortfalls.
function pacSplit(Q, S) {
  let bp = S.reduce((a, b) => a + b, 0), bs = 400 - bp;
  if (!(bs >= 0)) throw new RangeError('PAC schedule exceeds the pool');
  const pp = [], ps = [];
  Q.forEach((q0, t) => {
    let q = q0;
    let a = bs > 1e-12 ? min(q, S[t] || 0, bp) : min(q, bp);
    bp -= a; q -= a;
    const s = min(q, bs); bs -= s; q -= s;
    if (q > 1e-12) { const x = min(q, bp); a += x; bp -= x; }
    pp.push(a); ps.push(s);
  });
  return {pac: averageLife(pp), support: averageLife(ps)};
}
// Floater L + m and inverse floater K - gL cut from a fixed coupon c; inverse coupon floored at zero.
function floaterSplit(B, c, share, m, L) {
  if (!(num('share', share) > 0 && share < 1)) throw new RangeError('floater share must be strictly between 0 and 1');
  const Bf = share * B, Bi = B - Bf, g = Bf / Bi, K = (B * c - Bf * num('m', m)) / Bi;
  const ci = max(0, K - g * num('L', L)), cf = min(L + m, (B * c - Bi * ci) / Bf);
  return {g, K, cap: K / g, cf, ci};
}

  • กติกาเรียงคิวส่งเงินต้นทั้งเดือนให้ชั้นหน้าสุดที่ยังมีหนี้ ส่วนดอกเบี้ยจ่ายให้ทุกชั้นตามหนี้ต้นเดือนของตัวเอง
  • ที่ 100 PSA pool อายุ 11.67 ปีกลายเป็นสี่ชั้นอายุ 4.92, 10.88, 15.80 และ 24.60 ปี ค่าเฉลี่ยของอายุสี่ชั้นที่ถ่วงด้วยขนาดเท่ากับอายุของ pool เสมอ เพราะเงินต้นที่แจกในแต่ละเดือนรวมกันได้ $Q_t$ พอดี
  • เมื่อความเร็วเปลี่ยน ทุกชั้นขยับ จาก 100 เป็น 200 PSA ชั้น A สั้นลง 1.86 ปี แต่ชั้น D สั้นลง 6.48 ปี
  • ชั้น Z เก็บดอกเบี้ยของตัวเองเป็นหนี้ แล้วเอาเงินสดก้อนนั้นไปเร่งชั้นหน้า (A จาก 4.92 เหลือ 3.76 ปี) ส่วน PAC ได้ 7.91 ปีทุกความเร็วในช่วง 100 ถึง 250 PSA เพราะ support รับความไม่แน่นอนแทน
  • floater กับ inverse floater แบ่งดอกเบี้ยคงที่ก้อนเดียวกัน inverse floater ได้อัตราตามเส้นตรง $c_i=K-gL$ (ในตัวอย่างคือ $28.5\%-3L$) และสองชิ้นต้องมีพื้นศูนย์กับเพดาน
