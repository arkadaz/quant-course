13.4 Solving Stochastic Differential Equations — Geometric Brownian Motion, Vasicek, and Cox–Ingersoll–Ross

สาม SDE ที่ต่างกันแค่ตัวคูณหน้า $dW$ ให้โลกคนละแบบ: ราคาหุ้นกระจายกว้างขึ้นไม่หยุด ดอกเบี้ยของ Vasicek ถูกดึงกลับจนความผันผวนชนเพดาน และ CIR ไม่ยอมให้ดอกเบี้ยติดลบ

ดอกเบี้ยระยะสั้นสมมติวันนี้ 1.50% ระบบความเสี่ยงของธนาคารจำลองมันด้วย Brownian motion ธรรมดา $r_t=0.015+0.012W_t$ (ขยับ 1.2 จุดต่อ $\sqrt{\text{yr}}$ ไม่มีแรงดึงกลับ) ได้ว่าหนึ่งปีข้างหน้าเฉลี่ย 1.50% SD 1.20 จุด โอกาสติดลบ 10.6% และ SD ของ 25 ปีข้างหน้า 6.00 จุด ถ้าดอกเบี้ยถูกดึงกลับหาระดับ 3.00% ด้วยความเร็ว 0.8 ต่อปีตามแบบจำลอง Vasicek ตัวเลขเหล่านี้ควรเป็นเท่าไร?

ลองตอบก่อนเปิดเฉลย

หนึ่งปีข้างหน้าเฉลี่ย 2.33% SD 0.85 จุด โอกาสติดลบ 0.30% ไม่ใช่ 10.6% ต่างกันราว 35 เท่า และไม่ว่ามองไกลแค่ไหน SD ไม่เกิน 0.95 จุด ที่ 25 ปีจึงเป็น 0.95 ไม่ใช่ 6.00 แรงดึงกลับทำสองอย่าง: ยกค่าเฉลี่ยออกห่างจากศูนย์ และทำให้ shock เก่าจางหายแทนที่จะสะสม

ภาพรวมก่อนลงสูตร

“แก้ SDE” แปลว่าเขียนค่าของตัวแปรในอนาคตเป็นสูตรของค่าวันนี้กับ shock ทั้งหมดระหว่างทาง แล้วอ่านการกระจายของมันออกมา เครื่องมือมีสองชิ้นจากหน้าก่อน ๆ: Itô's lemma ใช้เปลี่ยนตัวแปรให้สมการแก้ง่ายขึ้น และ Itô integral ให้ค่าเฉลี่ยศูนย์กับ isometry สำหรับหา variance ของก้อนสุ่ม

หน้านี้ใช้ของสองชิ้นนั้นกับสาม SDE ที่ใช้จริงบนโต๊ะ GBM ของราคาหุ้นไม่มีอะไรดึงกลับ shock ทุกตัวอยู่ในราคาตลอดไป ส่วน Vasicek และ CIR ของอัตราดอกเบี้ยมีแรงดึงกลับหาระดับระยะยาว รูปด้านล่างคือความต่างนั้น: เส้นทางสีเทาที่ไม่มีแรงดึงกลับเดินหนีไปทั้งขึ้นและลงจนติดลบ ส่วนเส้นทางสีน้ำเงินของ Vasicek ถูกดึงเข้าหา 3% แล้ววนอยู่แถวนั้น

ลำดับคือ เทียบสามสมการ หาค่าเฉลี่ยของ Vasicek แก้สมการเต็มด้วย integrating factor หา variance ตอบโจทย์ อ่านครึ่งชีวิตและเพดานของความผันผวน ใช้คำตอบตั้งราคาพันธบัตร แล้วไปที่ CIR ว่าทำไมศูนย์เป็นพื้น และเมื่อไรเส้นทางแตะพื้นนั้น

ศัพท์ที่ใช้ในหัวข้อนี้
Short rate
อัตราดอกเบี้ยทบต้นต่อเนื่องสำหรับกู้ยืมช่วงสั้นมากในแบบจำลอง ใช้เป็นตัวแปรเดียวที่ขับการคิดลดเงินและราคาพันธบัตร: พันธบัตรคือค่าเฉลี่ยของ $e^{-\int r\,dt}$
Mean reversion
แรงที่ดึงตัวแปรกลับหาระดับระยะยาว $\theta$ ยิ่งห่างยิ่งดึงแรง ความเร็ว $\kappa$ บอกว่า shock เก่าจางเร็วแค่ไหน ใช้กับสิ่งที่วนรอบระดับหนึ่ง เช่นดอกเบี้ย และส่วนต่างราคาของคู่หุ้น
Vasicek model (Ornstein–Uhlenbeck)
SDE ที่มีแรงดึงกลับและส่วนสุ่มขนาดคงที่ มีคำตอบเป็น Normal จึงคำนวณทุกอย่างได้ด้วยสูตร รวมทั้งราคาพันธบัตร แต่ยอมให้ดอกเบี้ยติดลบ
Cox–Ingersoll–Ross (CIR) model
SDE ที่มีแรงดึงกลับเหมือนกัน แต่ส่วนสุ่มแปรตาม $\sqrt r$ จึงอ่อนลงเองเมื่อใกล้ศูนย์ ใช้กับตัวแปรที่ห้ามติดลบ เช่นดอกเบี้ย หรือ variance ในแบบจำลอง Heston แลกกับการที่คำตอบไม่เป็น Normal
Integrating factor
ตัวคูณ $e^{\kappa t}$ ที่ทำให้สองพจน์ของสมการรวมเป็นอนุพันธ์ของผลคูณก้อนเดียว ใช้แก้สมการเชิงเส้นอันดับหนึ่ง แบบเดียวกับที่แก้สมการดอกเบี้ยทบต้นต่อเนื่อง
Half-life
เวลาที่ระยะห่างเฉลี่ยจาก $\theta$ หดเหลือครึ่งหนึ่ง คือ $\ln2/\kappa$ ใช้แปลง $\kappa$ ให้เป็นภาษาที่คุยกับคนได้
Feller condition
เงื่อนไข $2\kappa\theta\ge\sigma^2$ ของ CIR ถ้าเป็นจริง เส้นทางไม่แตะศูนย์เลย ถ้าไม่จริง แตะแล้วเด้งกลับ

สัญลักษณ์ความหมายหน่วย
$r_t,\ r_0$short rate ที่เวลา $t$ และวันนี้ทศนิยมต่อปี
$\theta,\ \kappa$ระดับระยะยาว และความเร็วของแรงดึงกลับทศนิยมต่อปี, ต่อปี

ขั้นที่ 1 — สามสมการ ต่างกันที่ตัวคูณหน้า dW

วางสาม SDE ไว้ข้างกันในรูป $dX=a\,dt+b\,dW$ ส่วน $a$ ของหุ้นโตตามราคา ส่วน $a$ ของดอกเบี้ยชี้กลับหา $\theta$ ความต่างที่ตัดสินรูปของเส้นทางอยู่ที่ $b$

\[ \begin{aligned} \text{GBM}&:\ dS=\mu S\,dt+\sigma S\,dW,\\ \text{Vasicek}&:\ dr=\kappa(\theta-r)\,dt+\sigma_V\,dW,\\ \text{CIR}&:\ dr=\kappa(\theta-r)\,dt+\sigma_C\sqrt r\,dW. \end{aligned} \]

GBM ให้ส่วนสุ่มเป็นสัดส่วนกับราคา ราคาจึงไม่ติดลบ Vasicek ให้ส่วนสุ่มเท่ากันทุกระดับ แม้ดอกเบี้ยอยู่ใกล้ศูนย์ก็ยังถูกเขย่าแรงเท่าเดิม CIR ให้ส่วนสุ่มหดลงตามรากของระดับ ตัวคูณตัวเดียวนี้กำหนดว่าเส้นทางติดลบได้หรือไม่ และกำหนดว่าคำตอบเป็น Normal (Vasicek) หรือไม่ (CIR)

ขั้นที่ 2 — แรงดึงกลับเป็นตัวเลข และค่าเฉลี่ยที่ได้โดยไม่ต้องแก้ SDE

ก่อนแก้สมการ ลองอ่าน drift ของ Vasicek ที่สามระดับด้วย $\kappa=0.8$ และ $\theta=3\%$ จากนั้นเอาค่าเฉลี่ยทั้งสองข้างของ SDE: พจน์ $\sigma_V\,dW$ เฉลี่ยศูนย์ (Itô integral ถือก่อน ขยับทีหลัง) เหลือ ODE ธรรมดาของค่าเฉลี่ย $m_t$ แล้วให้ $d_t:=m_t-\theta$ เป็นระยะห่างจากเป้า

\[ \begin{aligned} r=1.5\%,\ 3\%,\ 4.5\%&:\ \kappa(\theta-r)=+0.012,\ 0,\ -0.012,\\ m_t'&=\kappa(\theta-m_t),\\ d_t'&=-\kappa\,d_t,\quad d_t=d_0e^{-\kappa t},\\ m_t&=\theta+(r_0-\theta)e^{-\kappa t},\\ m_1&=0.03-0.015\,e^{-0.8}\\ &=0.03-0.015(0.449329)=0.023260. \end{aligned} \]

ต่ำกว่าเป้า 1.5 จุด ถูกดันขึ้นด้วยอัตรา 1.2 จุดต่อปี สูงกว่าเป้าเท่ากันถูกดึงลงเท่ากัน แรงแปรตามระยะห่างเหมือนสปริง พอเข้าใกล้เป้าแรงก็อ่อนลง ระยะห่างจึงหดแบบ exponential ในหนึ่งปีระยะห่าง −1.5 จุดเหลือ 44.9% คือ −0.674 จุด ค่าเฉลี่ยจึงขึ้นมาที่ 2.326%

ค่าเฉลี่ยได้มาโดยไม่ต้องรู้อะไรเรื่องการกระจายเลย แต่คำถามเรื่องโอกาสติดลบต้องรู้ทั้งรูป ขั้นถัดไปจึงแก้ SDE เต็ม

ขั้นที่ 3 — integrating factor ที่ตรวจด้วย Itô's lemma

แก้ตรง ๆ ไม่ได้เพราะ $r$ อยู่ทั้งสองข้าง ย้ายพจน์ $-\kappa r\,dt$ ไปทางซ้ายได้ $dr+\kappa r\,dt$ ซึ่งคล้ายอนุพันธ์ของผลคูณ เป็นท่าเดียวกับสมการดอกเบี้ยทบต้นต่อเนื่อง $B'=rB$ ที่ได้ $B_t=B_0e^{rt}$ (time value of money) ตัวคูณที่ทำให้มันเป็นผลคูณพอดีคือ $e^{\kappa t}$ ใช้ Itô กับ $f(t,r)=e^{\kappa t}r$ เพื่อดูว่ามีพจน์พิเศษไหม

\[ \begin{aligned} f_t&=\kappa e^{\kappa t}r,\quad f_r=e^{\kappa t},\quad f_{rr}=0,\\ d\big(e^{\kappa t}r_t\big)&=\kappa e^{\kappa t}r_t\,dt+e^{\kappa t}\,dr_t+0\\ &=e^{\kappa t}\big(dr_t+\kappa r_t\,dt\big)\\ &=e^{\kappa t}\big(\kappa\theta\,dt+\sigma_V\,dW_t\big). \end{aligned} \]

$f$ เป็นเส้นตรงใน $r$ ความโค้งจึงเป็นศูนย์และ Itô correction หายไป ครั้งนี้ calculus ปกติให้คำตอบถูกพอดี บรรทัดสุดท้ายแทน $dr+\kappa r\,dt$ ด้วย $\kappa\theta\,dt+\sigma_V\,dW$ จาก SDE ตอนนี้ฝั่งขวาไม่มี $r$ เหลือ บวกทุกท่อนได้ตรง ๆ

ขั้นที่ 4 — บวกตลอดช่วง แล้วหารกลับ

บวกสองข้างจาก 0 ถึง $t$ ส่วนของ $dt$ เป็น integral ธรรมดา $\int_0^t\kappa\theta e^{\kappa s}\,ds=\theta(e^{\kappa t}-1)$ ส่วนของ $dW$ เป็น Itô integral ที่ตัวคูณ $e^{\kappa s}$ รู้ล่วงหน้า แล้วหารด้วย $e^{\kappa t}$

\[ \begin{aligned} e^{\kappa t}r_t-r_0&=\theta\big(e^{\kappa t}-1\big)+\sigma_V\int_0^te^{\kappa s}\,dW_s,\\ r_t&=\theta+(r_0-\theta)e^{-\kappa t}\\ &\quad+\sigma_V\int_0^te^{-\kappa(t-s)}\,dW_s. \end{aligned} \]

สองพจน์แรกคือค่าเฉลี่ย $m_t$ ที่ได้จาก ODE ตรงกันพอดี พจน์สุดท้ายคือ shock ทุกตัวที่เกิดระหว่างทาง แต่ละตัวคูณด้วย $e^{-\kappa(t-s)}$ ซึ่งเล็กลงตามอายุของ shock ที่ $\kappa=0.8$ shock เมื่อหนึ่งปีก่อนเหลือน้ำหนัก 0.449 และเมื่อห้าปีก่อนเหลือ 0.018 ดอกเบี้ยลืมอดีต ต่างจากราคาหุ้นที่ shock ทุกตัวอยู่ใน $W_t$ ด้วยน้ำหนัก 1 ตลอดไป

สังเกตเครื่องหมาย: $r_0$ คูณ $e^{-\kappa t}$ ไม่ใช่ $e^{+\kappa t}$ ถ้าเขียนผิดเป็นบวก ค่าเฉลี่ยจะระเบิดแทนที่จะเข้าหา $\theta$ (ดูความผิดท้ายหน้า)

ขั้นที่ 5 — รูปร่าง Normal และ variance จาก isometry

พจน์สุ่มคือผลรวมของ $e^{-\kappa(t-s)}\Delta W$ ที่ตัวคูณเป็นตัวเลขรู้ล่วงหน้า แต่ละก้อนเป็น Normal และอิสระกัน ผลรวมของ Normal ที่อิสระกันเป็น Normal จึงได้ Normal ค่าเฉลี่ยศูนย์ ส่วน variance ใช้ Itô isometry (variance เท่ากับ integral ของกำลังสองของตัวคูณตามเวลา) โดยเปลี่ยนตัวแปรเป็นอายุ $u=t-s$

\[ \begin{aligned} v_t&=\sigma_V^2\int_0^te^{-2\kappa(t-s)}\,ds=\sigma_V^2\int_0^te^{-2\kappa u}\,du\\ &=\frac{\sigma_V^2}{2\kappa}\big(1-e^{-2\kappa t}\big),\\ r_t&\sim\mathcal N(m_t,\ v_t). \end{aligned} \]

ตัวหารเป็น $2\kappa$ ไม่ใช่ $\kappa$ เพราะ isometry ยกตัวคูณกำลังสองก่อนรวม $e^{-\kappa u}$ จึงกลายเป็น $e^{-2\kappa u}$ เมื่อ $t$ โต $e^{-2\kappa t}$ หายไป variance เข้าหาค่าคงที่ $\sigma_V^2/(2\kappa)$ นี่คือเพดานของความไม่แน่นอน

ขั้นที่ 6 — คำตอบของโจทย์เปิดเรื่อง: หนึ่งปีข้างหน้า

โจทย์ให้อะไรมาบ้าง: $r_0=1.50\%$, $\theta=3.00\%$, $\kappa=0.8$ ต่อปี และ $\sigma_V=1.2\%$ ต่อ $\sqrt{\text{yr}}$ ใช้ค่าเฉลี่ย $m_t$ กับ variance $v_t$ ที่เพิ่งได้ แล้ววัดว่าศูนย์ห่างจากค่าเฉลี่ยกี่ SD ใช้ CDF $\Phi$ ของ Normal มาตรฐาน

\[ \begin{aligned} m_1&=0.023260,\\ v_1&=\frac{0.000144}{1.6}\big(1-e^{-1.6}\big)\\ &=0.00009(0.798103)=0.0000718,\\ \sqrt{v_1}&=0.008475,\\ P(r_1\lt0)&=\Phi(-0.023260/0.008475)\\ &=\Phi(-2.7445)=0.00303,\\ \Phi(-0.015/0.012)&=\Phi(-1.25)=0.1056. \end{aligned} \]

คำตอบ: ดอกเบี้ยปีหน้าเฉลี่ย 2.326% SD 0.8475 จุด โอกาสติดลบ 0.30% หรือราว 3 ใน 1,000 เส้นทาง แบบจำลองที่ไม่มีแรงดึงกลับ (บรรทัดสุดท้าย) ให้ 10.6% มากกว่า 35 เท่า เพราะค่าเฉลี่ยค้างอยู่ที่ 1.5% และ SD ใหญ่กว่า ที่ห้าปี Vasicek ให้ค่าเฉลี่ย 2.9725% SD 0.9485 จุด โอกาสติดลบลดเหลือ 0.086%

ตรวจเองใน 10 วินาที: $2.326/0.8475\approx2.74$ SD และหางซ้ายเกิน 2.7 SD ของระฆังคือราว 0.3% ส่วน SD ต่ำกว่า 1.2 จุดเพราะ shock ช่วงต้นปีจางไปแล้วบางส่วนตอนสิ้นปี

ขั้นที่ 7 — half-life และเพดานของความผันผวน เทียบกับ GBM

$\kappa=0.8$ ไม่ได้บอกอะไรกับคนฟังมากนัก แปลงเป็นเวลาที่ระยะห่างหายไปครึ่งหนึ่ง แล้วเทียบ SD ของ Vasicek กับของแบบจำลองไม่มีแรงดึงกลับ $\sigma_V\sqrt t$ ที่ 1, 5 และ 25 ปี และกับ GBM ของ SPY (ความผันผวน 18%) ซึ่ง Itô's lemma ให้ $\ln S_t=\ln S_0+(\mu-\tfrac12\sigma^2)t+\sigma W_t$

\[ \begin{aligned} e^{-\kappa t_{1/2}}&=0.5,\quad t_{1/2}=\frac{\ln2}{\kappa}=\frac{0.693147}{0.8}=0.8664,\\ \sqrt{\sigma_V^2/(2\kappa)}&=0.012/\sqrt{1.6}=0.009487,\\ t=1,\ 5,\ 25&:\ 0.8475\%,\ 0.9485\%,\ 0.9487\%,\\ \sigma_V\sqrt t&:\ 1.20\%,\ 2.68\%,\ 6.00\%,\\ \operatorname{SD}(\ln S_t)&=\sigma\sqrt t:\ 0.18,\ 0.40,\ 0.90. \end{aligned} \]

ระยะห่างจากเป้าหายครึ่งหนึ่งใน 0.8664 ปี หรือราว 10.4 เดือน SD ปีแรกถึง 89.3% ของเพดานแล้ว และที่ห้าปีถึง 99.98% ส่วนแบบจำลองไม่มีแรงดึงกลับกว้างขึ้นตามรากของเวลาไม่หยุด ที่ 25 ปีกว้างกว่าเพดาน 6.3 เท่า เพดานคือจุดที่แรงดึงกลับหักล้างการสะสมของ shock พอดี shock ใหม่เข้ามาเท่าไร ของเก่าก็จางออกไปเท่านั้น

GBM อยู่ฝั่งเดียวกับแบบจำลองไม่มีแรงดึงกลับ บนแกน log SD โตเป็น 0.90 ที่ 25 ปี คือช่วงหนึ่ง SD ตั้งแต่ราว 0.41 ถึง 2.46 เท่าของ median ราคาหุ้นไม่มีระดับให้กลับไปหา ถ้ามี ใครก็ซื้อตอนต่ำกว่าระดับแล้วขายตอนสูงกว่าได้กำไรแทบแน่นอน ดอกเบี้ยมีระดับเพราะนโยบายการเงินกำหนดทิศ

ขั้นที่ 8 — ใช้คำตอบตั้งราคาพันธบัตร

โจทย์ให้อะไรมาบ้าง: บนโต๊ะดอกเบี้ย สิ่งที่สำคัญที่สุดไม่ใช่ตัว short rate แต่คือราคาพันธบัตรศูนย์คูปอง $P(0,T)$ ที่จ่าย \$1 ในอีก $T$ ปี ซึ่งเท่ากับค่าเฉลี่ยของ $e^{-\int_0^Tr_t\,dt}$ (คิดลดด้วยดอกเบี้ยสั้นที่เกิดจริงทุกช่วง) ค่าเฉลี่ยนี้ต้องคิดใต้ risk-neutral measure ในขั้นนี้สมมติว่าพารามิเตอร์ของโจทย์คือพารามิเตอร์สำหรับตั้งราคาแล้ว ใช้ $T=1$ ปี

ก้อนสุ่มของ $\int_0^Tr_t\,dt$ คือ shock $dW_s$ แต่ละตัวคูณด้วยน้ำหนักรวมที่มันมีต่อดอกเบี้ยทุกวันหลังจากนั้น $\int_s^Te^{-\kappa(t-s)}dt=B(s,T)$ ผลรวมของ Normal ที่น้ำหนักรู้ล่วงหน้าเป็น Normal และค่าเฉลี่ยของ $e^{-Y}$ เมื่อ $Y$ เป็น Normal ค่าเฉลี่ย $M$ variance $V$ คือ $e^{-M+V/2}$ (ค่าเฉลี่ยของ lognormal)

\[ \begin{aligned} B(s,T)&=\frac{1-e^{-\kappa(T-s)}}{\kappa},\\ M&=\int_0^Tm_t\,dt\\ &=\theta T+(r_0-\theta)\frac{1-e^{-\kappa T}}{\kappa}\\ &=0.03-0.015(0.688339)\\ &=0.019675,\\ V&=\sigma_V^2\int_0^TB(s,T)^2\,ds\\ &=\frac{\sigma_V^2}{\kappa^2}\Big[T-\frac{2(1-e^{-\kappa T})}{\kappa}\\ &\qquad+\frac{1-e^{-2\kappa T}}{2\kappa}\Big]\\ &=0.000225\,(1-1.376678+0.498815)\\ &=0.000225(0.122137)\\ &=0.00002748,\\ P(0,1)&=e^{-0.019675+0.00001374}\\ &=e^{-0.019661}=0.980531. \end{aligned} \]

คำตอบ: พันธบัตรหนึ่งปีราคา \$0.980531 ต่อ \$1 คิดเป็น yield ทบต้นต่อเนื่อง $-\ln P=1.9661\%$ ต่ำกว่าดอกเบี้ยเฉลี่ยของปี 1.9675% อยู่ $V/2=0.0014$ จุด ส่วนนั้นคือ convexity ของ $e^{-x}$ ที่โค้งหงาย ทำทุก $T$ ได้เส้น yield ในรูปด้านล่าง: 1.97% ที่หนึ่งปี 2.62% ที่ห้าปี 2.80% ที่สิบปี และเข้าหา $\theta-\sigma_V^2/(2\kappa^2)=2.989\%$ เมื่อ $T$ ยาวมาก

ตรวจเองใน 10 วินาที: สูตรปิดของ Vasicek เขียนเป็น $P=e^{A-Br_0}$ โดย $B=B(0,T)=0.688339$ และ $A=(\theta-\tfrac{\sigma_V^2}{2\kappa^2})(B-T)-\tfrac{\sigma_V^2}{4\kappa}B^2=-0.009336$ ได้ $e^{-0.009336-0.010325}=e^{-0.019661}$ ตรงกันทุกหลัก หน้า Feynman–Kac ได้สูตรเดียวกันอีกทางจากสมการอนุพันธ์ย่อย

$B$ ยังบอกความเสี่ยงของพันธบัตรด้วย: $P$ เป็นฟังก์ชันของ $r$ ที่มี $\partial P/\partial r=-BP$ Itô's lemma ให้ส่วนสุ่มของ $dP$ เป็น $-\sigma_VBP\,dW$ ความผันผวนของราคาพันธบัตรจึงเป็น $\sigma_VB$: พันธบัตรหนึ่งปี $0.012(0.688)=0.83\%$ ต่อปี และพันธบัตรสิบปี 1.50% (ไม่เกิน $\sigma_V/\kappa=1.5\%$ ไม่ว่าอายุยาวแค่ไหน)

ขั้นที่ 9 — CIR: ทำไมศูนย์เป็นพื้น และค่าเฉลี่ยกับ SD ที่หาได้จาก Itô

ใช้ $\kappa$ และ $\theta$ ชุดเดิม กับ $\sigma_C=0.10$ ดูสองส่วนของ CIR เมื่อ $r$ ลงไปใกล้ศูนย์ แล้วหาค่าเฉลี่ยกับ variance: drift เป็นเส้นตรงเหมือน Vasicek จึงได้ $m_t$ ชุดเดิม ส่วนโมเมนต์ที่สอง $M_t:=\mathbb E[r_t^2]$ ใช้ Itô กับ $f=r^2$ ($f_r=2r$, $f_{rr}=2$, $b^2=\sigma_C^2r$) แล้วเอาค่าเฉลี่ย

\[ \begin{aligned} r\to0&:\ \kappa(\theta-r)\to0.024,\quad \sigma_C\sqrt r\to0,\\ r=0.0001&:\ \sigma_C\sqrt r=0.10(0.01)=0.001,\\ d(r^2)&=\big(2\kappa\theta r-2\kappa r^2+\sigma_C^2r\big)\,dt\\ &\quad+2\sigma_Cr^{3/2}\,dW,\\ M_t'&=(2\kappa\theta+\sigma_C^2)\,m_t-2\kappa M_t,\\ t=1&:\ m_1=2.326\%,\ \operatorname{SD}=1.016\%,\\ t\to\infty&:\ \operatorname{SD}=\sqrt{\theta\sigma_C^2/(2\kappa)}=1.369\%. \end{aligned} \]

ใกล้ศูนย์ แรงดันขึ้นเหลือ $\kappa\theta=0.024$ ต่อปีเต็ม ๆ ส่วนแรงเขย่าหายไป ที่ดอกเบี้ย 0.01% แรงเขย่าของ CIR เหลือ 0.001 เล็กกว่า 0.012 ของ Vasicek 12 เท่า แรงดันจึงชนะและผลักกลับขึ้น คำตอบต่อเนื่องของ CIR จึงไม่ติดลบ ราคาที่ต้องจ่ายคือคำตอบไม่เป็น Normal อีกต่อไป (เป็น noncentral chi-square ที่ปรับสเกล) ไม่มีสูตรเส้นทางแบบ Vasicek แต่ค่าเฉลี่ย variance และราคาพันธบัตรยังมีสูตรปิด

ODE ของ $M_t$ เป็นเส้นตรงอันดับหนึ่ง แก้ด้วย integrating factor แบบเดียวกับ Vasicek ได้ variance $\tfrac{r_0\sigma_C^2}{\kappa}(e^{-\kappa t}-e^{-2\kappa t})+\tfrac{\theta\sigma_C^2}{2\kappa}(1-e^{-\kappa t})^2$ คือ SD 1.016% ที่หนึ่งปี ค่า $\sigma_C=0.10$ เขย่าที่ระดับ 3% ด้วย $0.10\sqrt{0.03}=0.0173$ แรงกว่า 0.012 ของ Vasicek SD จึงใหญ่กว่า แม้ค่าเฉลี่ยเท่ากัน

ขั้นที่ 10 — ไม่ติดลบ ยังไม่แปลว่าไม่แตะศูนย์: Feller condition

ใกล้ศูนย์มีการแข่งกันระหว่างแรงดัน $\kappa\theta$ กับแรงเขย่า ใช้ Itô กับ $\ln r$ ($f_r=1/r$, $f_{rr}=-1/r^2$) เพื่อดูว่าใครชนะเมื่อ $r$ เล็กมาก แล้วลองสองค่าของ $\sigma_C$

\[ \begin{aligned} d\ln r&=\Big(\frac{\kappa\theta-\tfrac12\sigma_C^2}{r}-\kappa\Big)dt\\ &\quad+\frac{\sigma_C}{\sqrt r}\,dW,\\ \text{ratio}&:=\frac{2\kappa\theta}{\sigma_C^2},\\ 2\kappa\theta&=2(0.8)(0.03)=0.048,\\ \sigma_C=0.10&:\ \kappa\theta-\tfrac12\sigma_C^2=0.019,\\ &\quad\ \text{ratio}=0.048/0.01=4.8,\\ \sigma_C=0.25&:\ \kappa\theta-\tfrac12\sigma_C^2=-0.00725,\\ &\quad\ \text{ratio}=0.048/0.0625=0.768. \end{aligned} \]

บรรทัดแรกคือหัวใจ: เมื่อ $r$ เล็กมาก drift ของ $\ln r$ ถูกครองโดย $(\kappa\theta-\tfrac12\sigma_C^2)/r$ ถ้าตัวเศษเป็นบวก drift พุ่งขึ้นไม่สิ้นสุดเมื่อเข้าใกล้ศูนย์ $\ln r$ จึงลงไปถึงลบอนันต์ไม่ได้ เส้นทางไม่แตะศูนย์ ถ้าตัวเศษติดลบ drift ช่วยดึงลงอีก เส้นทางแตะศูนย์ได้แล้วเด้งกลับ ตัวเศษเป็นบวกเมื่อ $2\kappa\theta\gt\sigma_C^2$ ซึ่งคือ Feller condition (กรณีเท่ากันพอดียังไม่แตะ ผลนี้พิสูจน์ละเอียดในตำรา SDE)

ค่าแรกผ่านเงื่อนไขสบาย ๆ ค่าที่สองไม่ผ่าน โค้ดท้ายหน้าเดิน CIR วันละก้าวห้าปี ก้าวละ $\Delta r=\kappa(\theta-r^+)\Delta t+\sigma_C\sqrt{r^+\Delta t}\,Z$ โดย $r^+=\max(r,0)$ และตัดค่าติดลบเป็นศูนย์ (full truncation) 2,000 เส้นทางต่อค่า: อัตราส่วน 4.8 ไม่มีเส้นไหนแตะศูนย์ อัตราส่วน 0.768 แตะ 73.5% ของเส้นทาง

ขั้นที่ 11 — ตรวจสูตรของ Vasicek ด้วยการเดิน SDE ทีละวัน

โจทย์ให้อะไรมาบ้าง: โค้ดท้ายหน้าเดิน $\Delta r=\kappa(\theta-r)\Delta t+\sigma_V\sqrt{\Delta t}\,Z$ วันละก้าว 252 ก้าว 20,000 เส้นทาง ด้วย seed 134 โดยไม่ใช้สูตรค่าเฉลี่ยหรือ variance เลย แล้วเทียบกับสูตร

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

ใช้ Brownian motion ธรรมดากับดอกเบี้ย: โอกาสติดลบในหนึ่งปีกลายเป็น 10.6% แทน 0.30% และ SD ของ 25 ปีเป็น 6.00 จุดแทน 0.95 จุด ราคาพันธบัตรยาวและ option บนดอกเบี้ยที่คิดจากช่วงกว้างขนาดนั้นผิดไปมาก

เขียนเครื่องหมายของ $e^{-\kappa t}$ ผิด: คำตอบของ Vasicek คือ $e^{-\kappa t}r_0+\theta(1-e^{-\kappa t})$ ถ้าพิมพ์เป็น $e^{+\kappa t}r_0$ ค่าเฉลี่ยห้าปีจะเป็น $0.015e^{4}+0.03(0.9817)=84.8\%$ แทน 2.97% ตรวจง่าย ๆ: ที่ $t=0$ ต้องได้ $r_0$ และเมื่อ $t$ โตต้องเข้าหา $\theta$

ใช้ $\kappa$ ต่อปีกับเวลาเป็นเดือน: ใส่ $t=12$ แทน $t=1$ ได้ $e^{-9.6}$ ค่าเฉลี่ยหนึ่งปีกลายเป็น 2.9999% คือแทบถึงเป้าแล้ว แทนที่จะเป็น 2.326% ต้องเขียนหน่วยของ $\kappa$ กำกับไว้ทุกครั้ง

ลืมเลข 2 ในตัวหารของ variance: ใช้ $\sigma_V^2/\kappa$ ได้เพดาน SD 1.342% แทน 0.9487% กว้างเกิน $\sqrt2=1.414$ เท่า ตัวเลข 2 มาจากการยกตัวคูณกำลังสองใน isometry

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะดอกเบี้ยใช้ Vasicek และ CIR จำลองดอกเบี้ยในอนาคตเพื่อวัดความเสี่ยงของพอร์ตพันธบัตร และตั้งราคาพันธบัตรด้วยสูตรปิด $P=e^{A-Br}$ ซึ่งมีทั้งสองแบบจำลอง สำหรับ CIR สูตรของ $B$ คือ $2/(\kappa+\gamma\coth(\gamma T/2))$ เมื่อ $\gamma=\sqrt{\kappa^2+2\sigma_C^2}$ แต่ derivative ส่วนใหญ่บน CIR ไม่มีสูตรปิด ต้องใช้ Monte Carlo หรือแก้สมการอนุพันธ์ย่อยด้วย finite difference

ค่าพารามิเตอร์ได้จากการ calibrate Vasicek และ CIR กับอัตรา LIBOR และ swap ของวันนั้น โดยหา $\kappa$, $\theta$, $\sigma$ และ $r_0$ ที่ทำให้ผลรวมกำลังสองของความคลาดแบบสัดส่วนระหว่างอัตราของแบบจำลองกับของตลาดต่ำที่สุด มีพารามิเตอร์แค่สี่ตัว จึงจับเส้นอัตราดอกเบี้ยทั้งเส้นได้ไม่พอดีทุกจุด ถ้าต้องการให้ตรงทุกจุด โต๊ะใช้ lattice อย่าง Ho–Lee และ BDT แทน และแบบจำลองตัวแปรเดียวขยับทุกช่วงอายุไปด้วยกัน จับการบิดของเส้นไม่ได้

ดอกเบี้ยติดลบเกิดขึ้นจริง: ECB ตั้ง deposit rate ต่ำสุด −0.50% ในปี 2019 และธนาคารกลางญี่ปุ่นใช้ −0.1% ตั้งแต่ปี 2016 ถึง 2024 ในตลาดแบบนั้น Vasicek ที่ยอมให้ติดลบเป็นข้อดี คำถามที่ถูกคือในตลาดที่ดูแลอยู่ ดอกเบี้ยลงต่ำกว่าศูนย์ได้แค่ไหน แล้วเลือกแบบจำลองตามนั้น สมการเดียวกันนี้ยังใช้กับ variance ใน Heston (CIR) และกับส่วนต่างราคาของ คู่หุ้นที่ cointegrate กัน (Vasicek) เวลาอธิบายแบบจำลองให้คนอื่นฟัง ใช้ half-life แทน $\kappa$

3. ใช้ CIR ที่ $\kappa=0.8$, $\theta=3\%$, $\sigma_C=0.10$, $r_0=1.5\%$ หาราคาพันธบัตรหนึ่งปีจากสูตรปิด $P=e^{A-Br_0}$ โดย $\gamma=\sqrt{\kappa^2+2\sigma_C^2}$, $B=2/(\kappa+\gamma\coth(\gamma/2))$ และ $A=\tfrac{2\kappa\theta}{\sigma_C^2}\ln\!\big(e^{\kappa/2}/(\cosh(\gamma/2)+\tfrac{\kappa}{\gamma}\sinh(\gamma/2))\big)$ แล้วเทียบกับ Vasicek

$\gamma=\sqrt{0.64+0.02}=0.812404$ ได้ $B=0.687567$ และ $\tfrac{2\kappa\theta}{\sigma_C^2}=4.8$ ทำให้ $A=-0.009344$ ราคาคือ $e^{-0.009344-0.687567(0.015)}=e^{-0.019658}=0.980534$ yield 1.9658% เทียบกับ Vasicek 0.980531 และ 1.9661% ต่างกันไม่ถึง 0.1 basis point เพราะค่าเฉลี่ยของดอกเบี้ยเท่ากันพอดี ส่วนต่างเล็ก ๆ มาจาก CIR ที่ผันผวนกว่าที่ระดับนี้ จึงได้ convexity มากกว่านิดหนึ่ง สำหรับพันธบัตรสั้น สองแบบจำลองให้ราคาแทบเท่ากัน ความต่างจริงอยู่ที่หางล่างของดอกเบี้ยและ option

// Standard Normal CDF: Simpson's rule on the bell curve from 0 to |x|.
function Phi(x) {
  if (!Number.isFinite(x) || Math.abs(x) > 8) throw new RangeError('Phi needs a finite score between -8 and 8');
  const n = 4000, h = Math.abs(x) / n, phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(x) * s * h / 3;
}
// Vasicek dr = kappa (theta - r) dt + sigma dW: the solution is Normal with this mean and variance.
function vasicek(r0, theta, kappa, sigma, t) {
  const mean = theta + (r0 - theta) * Math.exp(-kappa * t);
  const sd = Math.sqrt(sigma * sigma / (2 * kappa) * (1 - Math.exp(-2 * kappa * t)));
  return {mean, sd, negative: t > 0 ? Phi(-mean / sd) : Number(r0 < 0)};
}
// Zero-coupon bond two ways: e^(-M + V/2) from the Normal integral of r, and the closed form e^(A - B r0).
function vasicekBond(r0, theta, kappa, sigma, T) {
  const B = (1 - Math.exp(-kappa * T)) / kappa;
  const M = theta * T + (r0 - theta) * B;
  const V = sigma * sigma / (kappa * kappa) * (T - 2 * B + (1 - Math.exp(-2 * kappa * T)) / (2 * kappa));
  const A = (theta - sigma * sigma / (2 * kappa * kappa)) * (B - T) - sigma * sigma * B * B / (4 * kappa);
  return {B, M, V, viaMoments: Math.exp(-M + V / 2), closedForm: Math.exp(A - B * r0), yield: (M - V / 2) / T, bondVol: sigma * B};
}
// CIR dr = kappa (theta - r) dt + sigma sqrt(r) dW: same mean; variance from Ito on r^2; closed-form bond.
function cir(r0, theta, kappa, sigma, T) {
  const e1 = Math.exp(-kappa * T), e2 = Math.exp(-2 * kappa * T);
  const variance = r0 * sigma * sigma / kappa * (e1 - e2) + theta * sigma * sigma / (2 * kappa) * (1 - e1) ** 2;
  const g = Math.sqrt(kappa * kappa + 2 * sigma * sigma);
  const B = 2 / (kappa + g / Math.tanh(g * T / 2));
  const A = 2 * kappa * theta / (sigma * sigma) * Math.log(Math.exp(kappa * T / 2) / (Math.cosh(g * T / 2) + kappa / g * Math.sinh(g * T / 2)));
  return {mean: theta + (r0 - theta) * e1, sd: Math.sqrt(variance), feller: 2 * kappa * theta / (sigma * sigma),
    bond: Math.exp(A - B * r0), B, A};
}
// mulberry32 + Box-Muller: seeded standard Normals, the same generator as the quadratic-variation page.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Step dr = kappa (theta - r) dt + sigma r^power dW daily; power 0 is Vasicek, 0.5 is CIR (full truncation at 0).
function simulateRate(paths, years, r0, theta, kappa, sigma, power, seed) {
  const z = normals(seed), steps = 252 * years, dt = 1 / 252, sq = Math.sqrt(dt);
  let sum = 0, sumSq = 0, negative = 0, touched = 0;
  for (let p = 0; p < paths; p++) {
    let r = r0, hit = false;
    for (let k = 0; k < steps; k++) {
      const x = power ? Math.max(r, 0) : r;
      r += kappa * (theta - x) * dt + sigma * (power ? Math.sqrt(x) : 1) * sq * z();
      if (power && r <= 0) { r = 0; hit = true; }
    }
    sum += r; sumSq += r * r;
    if (r < 0) negative++;
    if (hit) touched++;
  }
  const mean = sum / paths;
  return {mean, sd: Math.sqrt((sumSq - paths * mean * mean) / (paths - 1)), negative: negative / paths, touched: touched / paths};
}

const v1 = vasicek(r0, theta, kappa, sigma, 1), cap = sigma / Math.sqrt(2 * kappa);
const sim = simulateRate(N, 1, r0, theta, kappa, sigma, 0, 134);

สิ่งที่ควรตอบได้หลังอ่าน

  • GBM, Vasicek และ CIR ต่างกันที่ตัวคูณหน้า $dW$: โตตามระดับ คงที่ หรือโตตามรากของระดับ และตัวคูณนี้ตัดสินว่าติดลบได้ไหม และคำตอบเป็น Normal ไหม
  • Vasicek แก้ด้วย $e^{\kappa t}$ ซึ่ง Itô correction เป็นศูนย์: $r_t\sim\mathcal N\big(\theta+(r_0-\theta)e^{-\kappa t},\ \tfrac{\sigma_V^2}{2\kappa}(1-e^{-2\kappa t})\big)$ และ shock อายุ $a$ ปีเหลือน้ำหนัก $e^{-\kappa a}$
  • เริ่ม 1.50% เป้า 3.00%: ปีหน้าเฉลี่ย 2.326% SD 0.8475 จุด โอกาสติดลบ 0.30% ไม่ใช่ 10.6% ของแบบจำลองไม่มีแรงดึงกลับ half-life 0.8664 ปี และ SD ไม่เกิน 0.9487 จุด
  • คำตอบที่เป็น Normal ให้ราคาพันธบัตร $e^{-M+V/2}$: พันธบัตรหนึ่งปี \$0.980531 yield 1.966% และเส้น yield ขึ้นเข้าหา 2.99%
  • CIR ไม่ติดลบ ค่าเฉลี่ยเท่ากับ Vasicek และไม่แตะศูนย์เมื่อ $2\kappa\theta\ge\sigma_C^2$ (อัตราส่วน 4.8: 0% แตะ, 0.768: 73.5% แตะ)

หน้าถัดไป Itô หลายมิติและ product rule ใช้ Itô กับฟังก์ชันของสอง process พร้อมกัน เช่นมูลค่าพอร์ตสองสินทรัพย์ หรือราคาหุ้นคูณอัตราแลกเปลี่ยน แล้วดูว่า correlation เข้ามาในพจน์พิเศษอย่างไร
