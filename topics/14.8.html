14.8 Variance Swaps and Log-Contract Replication

variance swap คือสัญญาที่จ่ายเงินตามขนาดการแกว่งของราคาที่เกิดขึ้นจริง ราคายุติธรรมของมันหาได้จากราคา option ทุก strike ถ่วงด้วย $1/K^2$ โดยไม่ต้องเชื่อแบบจำลองใด ตราบที่ราคาไม่กระโดด

กองทุนแห่งหนึ่งอยากได้เงินเมื่อตลาดหุ้นแกว่งแรง ไม่ว่าจะแกว่งขึ้นหรือลง โต๊ะเทรดของธนาคารจึงขายสัญญาชื่อ variance swap ให้ สัญญานี้วัดว่าดัชนี SPX (ดัชนี S&P 500 ของหุ้นใหญ่ 500 ตัวในสหรัฐฯ) แกว่งแรงแค่ไหนตลอดอายุสัญญา ถ้าแกว่งแรงกว่าระดับที่ตกลงไว้ โต๊ะจ่ายส่วนต่างให้กองทุน ถ้าแกว่งเบากว่า กองทุนจ่ายให้โต๊ะ

ข้อตกลงของสัญญา (ตัวเลขสมมติ):

  • อายุ 30 วันปฏิทิน ในนั้นมีวันที่ตลาดเปิด (วันทำการ) 21 วัน สัญญาจึงวัดผลตอบแทนรายวัน 21 ตัว ผลตอบแทนที่ใช้คือ log return: log ของราคาปิดวันนี้หารด้วยราคาปิดเมื่อวาน ซึ่งใกล้กับเปอร์เซ็นต์ที่ราคาขึ้นลงมาก
  • ตัววัดการแกว่งคือ realized variance: เอาผลตอบแทนรายวันยกกำลังสอง บวกกัน แล้วปรับเป็นต่อปี ขั้นแรกของหน้านี้จะคิดให้ดูทีละขั้น
  • ระดับที่ตกลงไว้ (strike) คือ variance $K_{\rm var}=0.040203$ ต่อปี ถอดรากได้ความผันผวน $\sqrt{0.040203}=20.05\%$ ต่อปี โต๊ะคิดตัวเลขนี้จากราคา option 81 strike ในตลาด หน้านี้จะคิดให้ดูในขั้นกริด 81 strike
  • ขนาดสัญญา (notional) $N_v=\$1{,}000{,}000$ ต่อ variance 1.00 พอถึงวันหมดอายุ โต๊ะจ่ายกองทุน $N_v({\rm RV}-K_{\rm var})$ โดย ${\rm RV}$ คือ realized variance ของทั้งสัญญา ถ้าค่านี้ติดลบ กองทุนเป็นฝ่ายจ่าย

ผ่านไป 10 วันทำการ ผลตอบแทนรายวันของดัชนีคือ +1.2%, −1.0%, +0.7%, −2.2%, +1.8%, −1.5%, +0.4%, −0.9%, +2.1%, −0.6% realized variance ของ 10 วันนี้คือ 0.04788 ต่อปี หรือความผันผวน 21.88% (ขั้นแรกจะคำนวณให้ดู) ซึ่งสูงกว่า strike เทรดเดอร์จึงเอาค่านี้ไปแทนในสูตรจ่ายเงิน

\[10^6\times(0.04788-0.040203)=\$7{,}677\]

แล้วรายงานว่า “เราเสีย \$7,677 แล้ว” ตัวเลขนี้ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ยังไม่ถูก \$7,677 คิดเหมือนสัญญาจบแล้วที่วันที่ 10 แต่สัญญาวัด 21 วัน 10 วันที่ผ่านไปจึงมีน้ำหนักแค่ $10/21$ ของทั้งสัญญา อีก 11 วันยังไม่เกิด ค่าที่ตลาดคาดไว้สำหรับ 11 วันนั้นคือระดับ strike เอง จึงแทน 11 วันที่เหลือด้วย 0.040203 แล้วคิดเงินที่โต๊ะต้องจ่าย $\Pi_T$ ใหม่

\[\begin{aligned}{\rm RV}&=\tfrac{10}{21}(0.04788)+\tfrac{11}{21}(0.040203)\\&=0.022800+0.021059\\&=0.043859,\\\Pi_T&=10^6(0.043859-0.040203)\\&=\$3{,}656.\end{aligned}\]

โต๊ะจึงคาดว่าจะเสียราว \$3,656 ไม่ใช่ \$7,677 จะเสียถึง \$7,677 ก็ต่อเมื่อ 11 วันที่เหลือแกว่งแรง 21.88% เท่ากับ 10 วันแรก อีกเรื่องที่น่าสังเกต: ผลตอบแทนทั้งสิบวันรวมกันได้ศูนย์พอดี ดัชนีกลับมาที่เดิม แต่ variance ไม่เป็นศูนย์

ภาพรวมก่อนลงสูตร

คนที่อยากได้เงินจากการแกว่งของราคา เดิมต้องเทรดผ่าน option หน้าโครงสร้างสำหรับเทรดความผันผวนแสดงว่า ถ้าซื้อ option แล้ว hedge delta (ซื้อขายหุ้นทุกวันเพื่อหักล้างผลของราคาที่ขยับ) กำไรของแต่ละวันคือ

\[\delta\Pi\approx\tfrac12\Gamma S^2\big(R^2-\sigma^2\delta t\big)\]

ในสูตรนี้ $R$ คือผลตอบแทนของวันนั้น $\sigma^2\delta t$ คือ variance ที่จ่ายไว้แล้วในราคา option และ $\Gamma$ (gamma) คือความโค้งของราคา option เทียบกับราคาหุ้น ตัวคูณข้างหน้า $\tfrac12\Gamma S^2$ เรียกว่า dollar gamma มันบอกว่าการแกว่งหนึ่งวันแปลงเป็นเงินได้เท่าไร ปัญหาคือ gamma สูงเฉพาะตอนหุ้นอยู่ใกล้ strike ถ้าหุ้นวิ่งหนีไปไกล การแกว่งวันนั้นแทบไม่ให้เงิน กำไรจึงขึ้นกับว่าหุ้นแกว่งตอนอยู่ตรงไหน ไม่ได้ขึ้นกับการแกว่งอย่างเดียว

variance swap แก้ปัญหานี้ตรง ๆ เพราะมันจ่ายตาม variance ที่เกิดจริง ไม่สนว่าดัชนีอยู่ตรงไหน คำถามของหน้านี้คือ strike ที่ยุติธรรมควรเป็นเท่าไร และผู้ขายจะ hedge อย่างไร แบบจำลอง Hestonตอบคำถามแบบนี้ได้ แต่ต้องเชื่อสมการของแบบจำลองก่อน หน้านี้ไม่สมมติแบบจำลองความผันผวนใดเลย ใช้แค่ราคา option ที่ตลาดมีวันนี้

กุญแจคือสัญญาสมมติชื่อ log contract ซึ่งวันหมดอายุจ่าย $-\log(S_T/F)$ ในที่นี้ $S_T$ คือราคาดัชนีวันหมดอายุ และ $F$ คือ forward: ราคาที่ตกลงกันวันนี้สำหรับซื้อขายดัชนีในวันหมดอายุ log contract มี dollar gamma เท่ากันทุกระดับราคา มันจึงได้เงินตาม $R^2$ ไม่ว่าดัชนีจะไปอยู่ไหน log contract ไม่มีขายในตลาด แต่สร้างได้จาก option สองกลุ่ม:

  • put นอกเงิน คือ put ที่ strike ต่ำกว่า forward ใช้ทุก strike
  • call นอกเงิน คือ call ที่ strike สูงกว่า forward ใช้ทุก strike

option ที่ strike $K$ ถือจำนวนเป็นสัดส่วนกับ $1/K^2$ รูปด้านล่างแสดงภาพนี้: เส้นโค้งคือส่วนที่ log contract ต้องจ่าย เส้นหักคือผลรวมของ option 17 ตัว สองเส้นทับกันเกือบสนิท

ลำดับของหน้านี้:

  1. คิด realized variance ด้วยมือ แล้วเขียนข้อตกลงของสัญญาเป็นสูตร
  2. ใช้ Itô's lemma แยก variance ออกจาก log ของราคา แล้วแสดงว่า log contract สร้างได้จาก option ทุก strike
  3. ดูว่าทำไม dollar gamma ของมันคงที่ แล้วตรวจสูตรกับกรณีที่รู้คำตอบ
  4. ใช้สูตรกับกริด 81 strike และอธิบายว่าทำไมได้ 20.05% ไม่ใช่ 20%
  5. ชำระเงิน คิดมูลค่ากลางสัญญา (mark-to-market) และสร้างความผันผวน 30 วันแบบ VIX
  6. จบที่จุดที่วิธีนี้พัง: วันที่ราคากระโดด

ตลาดในหน้านี้เป็นตัวอย่างสมมติ:

  • forward ของ SPX $F=5{,}000$ จุด
  • ดอกเบี้ย $r=4\%$ ต่อปี
  • อายุ $T=30/365=0.0821918$ ปี เวลาของ option นับวันปฏิทิน 365 วันต่อปี ต่างจาก realized variance ที่นับ 252 วันทำการต่อปี
  • ราคา option ทุกตัวคิดจากสูตร Black–76 (สูตร Black–Scholes ที่เขียนด้วย forward) ที่ความผันผวน 20% เท่ากันทุก strike เราเรียกตลาดแบบนี้ว่า “ความผันผวนแบน”
  • strike มีตั้งแต่ 3,000 ถึง 7,000 จุด ห่างกันทุก 50 จุด รวม $\frac{7{,}000-3{,}000}{50}+1=81$ strike
ศัพท์ที่ใช้ในหัวข้อนี้
Variance swap
สัญญาที่วันหมดอายุจ่ายเงิน $N_v({\rm RV}-K_{\rm var})$ คือขนาดสัญญา คูณ (variance ที่เกิดจริง ลบ strike) ผู้ซื้อได้เงินเมื่อตลาดแกว่งแรงกว่า strike ผู้ขายได้เงินเมื่อตลาดแกว่งเบากว่า ใช้ซื้อขายความผันผวนตรง ๆ โดยไม่ต้อง hedge delta เอง และไม่ขึ้นกับว่าดัชนีจบที่ราคาไหน
Realized variance
ขนาดการแกว่งที่เกิดขึ้นจริง วิธีคิดคือยก log return รายวันกำลังสอง บวกกัน แล้วคูณ $252/n$ เพื่อปรับเป็นต่อปี ($n$ คือจำนวนวันที่วัด 252 คือจำนวนวันที่ตลาดหุ้นสหรัฐฯ เปิดในหนึ่งปีโดยประมาณ) ยกกำลังสองเพื่อให้วันขึ้นกับวันลงนับตามขนาดเท่ากัน ไม่หักล้างกัน ตัวเลขนี้คือตัวที่ใช้ชำระเงิน
Variance notional, vega notional และ variance point
variance notional $N_v$ คือเงินที่ได้เสียต่อ variance 1.00 ต่อปี vega notional คือเงินที่ได้เสียโดยประมาณ เมื่อความผันผวนที่เกิดจริงต่างจาก strike 1 จุด (1 จุดคือ 1% หรือ 0.01) ตลาดพูดขนาดสัญญาด้วย vega notional เพราะคนคิดเป็นความผันผวนง่ายกว่า แต่เงินที่ชำระจริงคิดจาก variance ตลาดมักนับ variance เป็น variance point: ความผันผวน 20 จุดยกกำลังสองได้ $20^2=400$ variance point และ 1 variance point คือ $0.01^2=0.0001$
Forward และ option นอกเงิน (OTM)
forward $F$ คือราคาที่ตกลงกันวันนี้สำหรับซื้อขายดัชนีในวันหมดอายุ option นอกเงิน (out of the money) คือ option ที่ถ้าจบที่ราคา forward จะไม่จ่ายอะไร ได้แก่ put ที่ strike ต่ำกว่า $F$ และ call ที่ strike สูงกว่า $F$
Dollar gamma
ตัวคูณ $\tfrac12\Gamma S^2$ ในกำไรรายวันของ option ที่ hedge delta แล้ว มันบอกว่าการแกว่ง $R^2$ ของวันหนึ่งแปลงเป็นเงินได้เท่าไร ถ้าตัวนี้เปลี่ยนตามราคา กำไรก็ขึ้นกับว่าราคาแกว่งตอนอยู่ตรงไหน
Log contract
สัญญาสมมติที่วันหมดอายุจ่าย $-\log(S_T/F)$ ไม่มีขายจริง แต่ค่าคาดหมายของมันคูณ $2/T$ คือ variance ที่ตลาดคาดไว้พอดี และสร้างได้จาก option ทุก strike
Static replication และ option strip
static replication คือการสร้างเงินจ่ายที่ต้องการ โดยซื้อ option หลาย strike ในวันแรกแล้วถือไว้เฉย ๆ จนหมดอายุ ไม่ต้องซื้อขายเพิ่ม strip คือชุด option วันหมดอายุเดียวกันที่เรียงทุก strike ในหน้านี้ถ่วงน้ำหนักด้วย $1/K^2$ ใน hedge ของ variance swap ส่วนที่ยังต้องปรับทุกวันมีแค่ขาหุ้น
VIX และ constant maturity
VIX คือดัชนีความผันผวนของ S&P 500 ที่ตลาด Cboe ประกาศ Cboe คิด fair variance ด้วยผลรวมแบบเดียวกับในหน้านี้ แล้วรายงานรากที่สองคูณ 100 constant maturity แปลว่าอายุคงที่ 30 วันเสมอ เพราะวันหมดอายุในตลาดไม่ได้ห่าง 30 วันพอดีทุกวัน Cboe จึงเอาสองวันหมดอายุที่คร่อม 30 วันมาเชื่อมกันบน total variance
Replication error จาก jump
ในวันที่ราคากระโดด (ขยับก้อนใหญ่ทันที ไม่ไหลต่อเนื่อง) เงินที่พอร์ต hedge ให้จะไม่เท่ากับเงินที่สัญญาจ่าย ส่วนต่างนี้คือ replication error สูตรในหน้านี้สมมติราคาเดินต่อเนื่อง จึงเหลือส่วนต่างนี้ทุกครั้งที่ราคากระโดด

ขั้นที่ 1 — ลองด้วยมือ: variance ของ 10 วัน

ก่อนตั้งราคาสัญญา ต้องรู้ก่อนว่าสัญญาวัดอะไร ขั้นนี้คิด realized variance ของ 10 วันแรกในโจทย์เปิดเรื่องด้วยมือ

โจทย์ให้อะไรมาบ้าง: log return 10 วัน คือ +1.2%, −1.0%, +0.7%, −2.2%, +1.8%, −1.5%, +0.4%, −0.9%, +2.1%, −0.6% สูตรของ realized variance ต่อปีคือ

\[{\rm RV}_{10}=\frac{252}{10}\sum_{i=1}^{10}r_i^2\]

หารด้วย 10 เพื่อได้ค่าเฉลี่ยต่อวัน แล้วคูณ 252 (จำนวนวันทำการในหนึ่งปี) เพื่อปรับเป็นต่อปี ตัวเลขเป็นเปอร์เซ็นต์ จึงต้องแปลงก่อน เช่น $1.2\%=0.012$ และ $0.012^2=1.44\times10^{-4}$ ทุกวันจึงได้ตัวคูณ $10^{-4}$ ร่วมกัน ยกกำลังสองทีละวันก่อน แล้วค่อยบวก

\[ \begin{aligned} \sum_{1}^{5}r_i^2&=10^{-4}(1.44+1.00+0.49\\ &\quad+4.84+3.24)=10^{-4}(11.01),\\ \sum_{6}^{10}r_i^2&=10^{-4}(2.25+0.16+0.81\\ &\quad+4.41+0.36)=10^{-4}(7.99),\\ \sum_{1}^{10}r_i^2&=0.001900,\quad \sum_{1}^{10}r_i=0,\\ {\rm RV}_{10}&=\frac{252}{10}(0.001900)=0.047880,\\ \sqrt{0.047880}&=21.88\%. \end{aligned} \]

คำตอบ: variance ต่อปีของ 10 วันนี้คือ 0.04788 ถอดรากได้ความผันผวน 21.88% ผลตอบแทนทั้งสิบวันรวมกันได้ศูนย์พอดี ดัชนีจึงจบที่เดิม แต่ variance ไม่เป็นศูนย์ เพราะเรายกกำลังสองก่อนบวก วันขึ้นกับวันลงจึงไม่หักล้างกัน สังเกตด้วยว่าสูตรไม่ลบค่าเฉลี่ยออกก่อนยกกำลังสอง ต่างจาก SD ในวิชาสถิติ สัญญาจริงเขียนไว้แบบนี้ เพราะค่าเฉลี่ยรายวันเล็กมากเมื่อเทียบกับขนาดการแกว่ง

ตรวจเองใน 10 วินาที: วัน −2.2% ให้ก้อนใหญ่ที่สุด $(-0.022)^2=4.84\times10^{-4}$ ถ้าวันนั้นเป็น +2.2% ก็ได้ $(+0.022)^2=4.84\times10^{-4}$ เท่าเดิม สัญญานี้สนใจขนาดการขยับ ไม่สนใจทิศ (รูปข้างล่าง)

ขั้นที่ 2 — สัญญาจ่ายอะไร และ variance ของช่วงต่อกันบวกกันได้

ตอนนี้รู้แล้วว่าสัญญาวัดอะไร ขั้นนี้เขียนข้อตกลงของสัญญาเป็นสูตร แล้วแยก variance ของทั้งสัญญาเป็นส่วนที่เกิดแล้วกับส่วนที่ยังไม่เกิด การแยกนี้คือสิ่งที่เทรดเดอร์ในโจทย์เปิดเรื่องลืม

สัญญาต้องระบุว่าวัดกี่วัน 30 วันปฏิทินมีวันทำการราว $30\times252/365=20.7$ วัน สัญญานี้จึงตกลงวัด $n=21$ ผลตอบแทน (สมมติ) สัญลักษณ์ที่ใช้:

  • $\Pi_T$ คือเงินที่ผู้ซื้อ variance ได้ในวันหมดอายุ (ติดลบแปลว่าผู้ซื้อจ่าย)
  • ${\rm RV}_{10}$ คือ variance ต่อปีของ 10 วันแรก และ ${\rm RV}_{11}$ คือ variance ต่อปีของ 11 วันที่เหลือ
  • $N_{\rm vega}$ คือ vega notional เงินโดยประมาณต่อความผันผวน 1 จุด
\[ \begin{aligned} \Pi_T&=N_v\big({\rm RV}-K_{\rm var}\big),\\ {\rm RV}&=\frac{252}{21}\sum_{i=1}^{21}r_i^2=12\sum_{i=1}^{21}r_i^2,\\ {\rm RV}&=\frac{10}{21}{\rm RV}_{10}+\frac{11}{21}{\rm RV}_{11},\\ N_{\rm vega}&\approx N_v\cdot2K_{\rm vol}\cdot0.01. \end{aligned} \]

ใจความของสูตรนี้คือ variance ของทั้งสัญญาเป็นค่าเฉลี่ยถ่วงด้วยเวลาของ variance แต่ละช่วง 10 วันแรกได้น้ำหนัก $10/21$ และ 11 วันหลังได้ $11/21$ ทำไมทำได้? เพราะ variance คือผลรวมของก้อนรายวัน แยกผลรวม 21 ตัวเป็น 10 ตัวแรกกับ 11 ตัวหลังได้เสมอ แล้วคูณและหารด้วย 10 ให้ก้อนแรกกลายเป็น variance ต่อปีของช่วงตัวเอง: $\frac{252}{21}\sum_1^{10}r_i^2=\frac{10}{21}\cdot\frac{252}{10}\sum_1^{10}r_i^2=\frac{10}{21}{\rm RV}_{10}$ เป็นเหตุผลเดียวกับที่ variance ของ Brownian motion โตตามเวลา (สามสมบัติของ Brownian motion) ส่วนความผันผวนซึ่งเป็นรากที่สองแยกแบบนี้ไม่ได้ เพราะ $\sqrt{a+b}\ne\sqrt a+\sqrt b$

บรรทัดสุดท้ายแปลงขนาดสัญญาเป็นภาษาที่ตลาดพูด อนุพันธ์ของ $\sigma^2$ ตาม $\sigma$ คือ $2\sigma$ ถ้าความผันผวนที่เกิดจริงขยับจาก $K_{\rm vol}$ ไป 1 จุด (0.01) variance จึงขยับราว $2K_{\rm vol}\times0.01$ ที่ strike 20.05% ได้ $N_{\rm vega}\approx10^6\times2\times0.2005\times0.01=\$4{,}010$ ต่อจุด คำว่า “ราว” สำคัญ ตัวอย่าง mark-to-market ด้านล่างจะแสดงว่าค่านี้ใช้ได้แค่ใกล้ strike

ขั้นที่ 3 — Itô แยก variance ออกจาก log ของราคา

รู้แล้วว่าสัญญาจ่ายอะไร คำถามต่อไปคือราคายุติธรรม วิธีปกติคือหาพอร์ตของที่ซื้อขายได้ซึ่งจ่ายเงินเท่ากับสัญญาทุกกรณี ถ้ามีพอร์ตแบบนั้น ราคาของสัญญาก็ต้องเท่าราคาของพอร์ต

ถ้าวัดถี่ขึ้นเรื่อย ๆ ผลรวม $\sum r_i^2$ จะเข้าหา $\int_0^T\sigma_t^2dt$ คือ variance รวมตลอดอายุ โดย $\sigma_t$ คือความผันผวน ณ ขณะนั้น ขั้นนี้ใช้ Itô's lemma (กฎลูกโซ่ของแคลคูลัสสำหรับตัวแปรสุ่ม) กับ $\log S$ เพื่อเขียน $\sigma_t^2dt$ เป็นของที่ซื้อขายได้ เรายอมให้ $\sigma_t$ เปลี่ยนตามเวลาและสุ่มได้ เช่นในแบบจำลอง Heston สมมติข้อเดียวคือราคาเดินต่อเนื่อง ไม่กระโดด ในสมการแรก $r-q$ คือดอกเบี้ยลบอัตราเงินปันผล และ $dW_t$ คือการขยับสุ่มของ Brownian motion ในช่วงเวลาสั้น ๆ $dt$

\[ \begin{aligned} \frac{dS_t}{S_t}&=(r-q)\,dt+\sigma_t\,dW_t,\\ d\log S_t&=\frac{dS_t}{S_t}-\frac12\cdot\frac{(dS_t)^2}{S_t^2},\\ (dS_t)^2&=\sigma_t^2S_t^2\,dt,\\ \sigma_t^2\,dt&=2\,\frac{dS_t}{S_t}-2\,d\log S_t. \end{aligned} \]

ใจความคือ log ของราคาโตช้ากว่าผลตอบแทนธรรมดา $dS/S$ อยู่ครึ่งหนึ่งของ variance เสมอ ส่วนที่หายไปนี้คือ variance พอดี เราจึงวัด variance ได้จากผลต่างของสองสิ่งที่ซื้อขายได้

ขั้นที่ต้องระวังคือการใช้ Itô กับ $f(S)=\log S$ ซึ่ง $f'=1/S$ และ $f''=-1/S^2$ แคลคูลัสธรรมดาจะมีแค่พจน์ $f'\,dS$ แต่ราคาสุ่มแกว่งแรงจน $(dS)^2$ ไม่เล็กพอจะทิ้ง เพราะ $(dW)^2=dt$ พจน์ $\tfrac12f''(dS)^2$ จึงต้องอยู่ และติดลบเพราะ $\log$ โค้งลง พอแทน $(dS)^2=\sigma_t^2S^2dt$ แล้วย้ายข้าง ก็ได้แถวสุดท้าย

ไม่ได้สมมติว่า $\sigma$ คงที่เลย และทั้งสองก้อนทางขวาเป็นของที่ซื้อขายได้ ก้อนแรก $2\,dS/S$ คือถือหุ้นมูลค่าคงที่ 2 ดอลลาร์ แล้วปรับจำนวนหุ้นทุกวันให้มูลค่าคงที่ ก้อนที่สองคือสัญญาที่จ่ายตาม $\log S_T$

ขั้นที่ 4 — variance ที่คาดไว้คือราคาของ log contract

ขั้นก่อนได้ variance ของช่วงสั้น ๆ หนึ่งช่วง ขั้นนี้รวมทุกช่วงตลอดอายุ แล้วหาค่าคาดหมายภายใต้ risk-neutral measure $\mathbb Q$ นี่คือโลกสมมติที่ใช้ตั้งราคา ในโลกนี้ทุกสินทรัพย์โตเฉลี่ยเท่าดอกเบี้ย และราคาวันนี้เท่ากับค่าคาดหมายของเงินในอนาคตที่คิดลดด้วยดอกเบี้ย มีสองข้อเท็จจริงที่ใช้:

  • ขาหุ้นเหลือแค่ drift $(r-q)T$ เพราะค่าคาดหมายของส่วนสุ่ม $\int\sigma_t\,dW_t$ เป็นศูนย์ (Itô integral)
  • forward คือ $F=S_0e^{(r-q)T}$ จึงได้ $\log(F/S_0)=(r-q)T$ log ของราคาจึงแยกเป็นส่วนที่เทียบกับ forward บวกส่วนที่รู้แน่นอน
\[ \begin{aligned} \int_0^T\sigma_t^2dt&=2\int_0^T\frac{dS_t}{S_t}-2\log\frac{S_T}{S_0},\\ \mathbb E^{\mathbb Q}\Big[\int_0^T\frac{dS_t}{S_t}\Big]&=(r-q)T,\\ \log\frac{S_T}{S_0}&=\log\frac{S_T}{F}+(r-q)T,\\ \mathbb E^{\mathbb Q}\Big[\int_0^T\sigma_t^2dt\Big]&=-2\,\mathbb E^{\mathbb Q}\Big[\log\frac{S_T}{F}\Big]. \end{aligned} \]

ใจความคือคำถามที่ตอบไม่ได้ “อนาคตจะผันผวนแค่ไหน” ถูกแทนด้วยคำถามที่ตลาดตอบได้ “สัญญาที่จ่าย $-2\log(S_T/F)$ ราคาเท่าไร”

แถวสุดท้ายได้จากการหาค่าคาดหมายของแถวแรก แล้วแทนสองแถวกลางลงไป: $2(r-q)T-2\,\mathbb E^{\mathbb Q}[\log(S_T/F)]-2(r-q)T$ พจน์ $2(r-q)T$ หักกันพอดี เหลือแค่ log contract

fair strike คือ strike ที่ทำให้สัญญามีมูลค่าศูนย์ในวันทำสัญญา ซึ่งต้องเป็น $K_{\rm var}=\frac1T\mathbb E^{\mathbb Q}[\int_0^T\sigma_t^2dt]$ ตัวเลขนี้เป็นค่าในโลก $\mathbb Q$ ที่ใช้ตั้งราคา ไม่ใช่คำพยากรณ์ว่าตลาดจะแกว่งจริงเท่าไร

ขั้นที่ 5 — payoff โค้งใดก็ประกอบได้จาก option ทุก strike (Carr–Madan)

log contract ไม่มีขายในตลาด ถ้าจะใช้มัน hedge ต้องสร้างมันเองจากของที่มีขาย คือ option ขั้นนี้แสดงว่าเงินจ่าย (payoff) $g(S_T)$ แบบใดก็ได้ที่หาอนุพันธ์ได้สองครั้ง เขียนได้เป็นสามส่วน:

  • เส้นตรงที่สัมผัสกราฟของ $g$ ที่ $F$ ซึ่งสร้างได้ด้วยเงินสดกับ forward
  • put ทุก strike ที่ต่ำกว่า $F$
  • call ทุก strike ที่สูงกว่า $F$

option ที่ strike $K$ ถือจำนวน $g''(K)$ หน่วย เครื่องมือมีแค่ทฤษฎีบทมูลฐานของแคลคูลัสกับ integration by parts ทำทีละฝั่ง เริ่มจากกรณี $S_T\ge F$

\[ \begin{aligned} g(S_T)-g(F)&=\int_F^{S_T}g'(K)\,dK\\ &=\big[-(S_T-K)g'(K)\big]_F^{S_T}\\ &\quad+\int_F^{S_T}(S_T-K)g''(K)\,dK\\ &=g'(F)(S_T-F)\\ &\quad+\int_F^\infty g''(K)(S_T-K)^+dK,\\ S_T\lt F:\ g(S_T)-g(F)&=g'(F)(S_T-F)\\ &\quad+\int_0^F g''(K)(K-S_T)^+dK,\\ g(S_T)&=g(F)+g'(F)(S_T-F)\\ &\quad+\int_0^F g''(K)(K-S_T)^+dK\\ &\quad+\int_F^\infty g''(K)(S_T-K)^+dK. \end{aligned} \]

ใจความคือ option ที่ strike $K$ เป็นเหมือนก้อนอิฐที่ใส่ความโค้งให้ payoff ตรงจุด $K$ จุดเดียว กราฟ payoff ของ call แบนอยู่แล้วหักขึ้นที่ $K$ ถ้าอยากได้เส้นโค้ง $g$ ก็เอา option มาเรียงทุก strike โดยที่ strike $K$ ถือจำนวนเท่ากับความโค้ง $g''(K)$ ของเส้น ณ จุดนั้น

ขั้นที่ต้องระวังคือ integration by parts ในแถวที่สอง เราต้องการฟังก์ชันของ $K$ ที่อนุพันธ์ตาม $K$ เท่ากับ 1 และเลือก $-(S_T-K)$ เพราะมันเป็นศูนย์ที่ขอบบน $K=S_T$ ที่ขอบล่าง $K=F$ จึงเหลือ $g'(F)(S_T-F)$ ซึ่งคือเส้นสัมผัส อินทิกรัลที่เหลือมี $(S_T-K)$ ซึ่งคือ payoff ของ call เมื่อ $K$ ต่ำกว่า $S_T$ และ payoff ของ call เป็นศูนย์เมื่อ $K$ สูงกว่า $S_T$ จึงขยายขอบบนไปถึง $\infty$ ได้ ถ้าเขียนด้วย $(\cdot)^+$ ซึ่งแปลว่า “ค่าบวก หรือศูนย์ถ้าติดลบ”

ฝั่ง $S_T\lt F$ ทำแบบเดียวกันโดยใช้ $K-S_T$ จึงได้ put แทน call แถวสุดท้ายรวมสองกรณีเข้าด้วยกัน ใช้ได้ทุก $S_T$ เพราะในแต่ละกรณีอินทิกรัลของอีกฝั่งเป็นศูนย์ เหตุผลนี้เหมือนกับที่ราคา butterfly บอก density ในผืนความผันผวน

ขั้นที่ 6 — ใส่ log contract แล้วได้สูตร fair strike

ตอนนี้มีสูตรสร้าง payoff ใดก็ได้จาก option แล้ว ขั้นนี้ใส่ log contract ลงไป $g(S)=-\log(S/F)$ มีค่าที่ต้องใช้ดังนี้:

  • $g(F)=-\log1=0$
  • $g'(S)=-1/S$ จึงได้ $g'(F)=-1/F$
  • $g''(K)=1/K^2$ นี่คือจำนวน option ที่ strike $K$

จากนั้นหาค่าคาดหมายใต้ $\mathbb Q$ ส่วนเส้นตรงหายไป เพราะ forward คือราคาคาดหมายของดัชนีในโลก $\mathbb Q$ หรือ $\mathbb E^{\mathbb Q}[S_T]=F$ ส่วน option ใช้ความจริงที่ว่าราคาวันนี้คือค่าคาดหมายของ payoff คิดลดด้วย $e^{-rT}$ ค่าคาดหมายของ payoff จึงเท่ากับราคาวันนี้คูณ $e^{rT}$ ในสูตร $P(K)$ และ $C(K)$ คือราคา put และ call ที่ strike $K$ วันนี้

\[ \begin{aligned} -\log\frac{S_T}{F}&=-\frac{S_T-F}{F}+\int_0^F\frac{(K-S_T)^+}{K^2}dK\\ &\quad+\int_F^\infty\frac{(S_T-K)^+}{K^2}dK,\\ K_{\rm var}&=\frac2T\,\mathbb E^{\mathbb Q}\Big[-\log\frac{S_T}{F}\Big]\\ &=\frac{2e^{rT}}{T}\Big[\int_0^F\frac{P(K)}{K^2}dK\\ &\qquad+\int_F^\infty\frac{C(K)}{K^2}dK\Big]. \end{aligned} \]

ใจความคือ fair strike ของ variance swap คือผลรวมของราคา option นอกเงินทุก strike ถ่วงด้วย $1/K^2$ แล้วคูณ $2e^{rT}/T$ น้ำหนัก $1/K^2$ ไม่ใช่ธรรมเนียมที่ใครตั้งขึ้น มันคือความโค้งของ $-\log$ พอดี put strike ต่ำจึงได้น้ำหนักต่อราคามากกว่า call strike สูง (รูปน้ำหนักข้างล่าง)

สูตรใช้แค่ราคา option นอกเงินของวันหมดอายุเดียว ไม่มี $\sigma$ ของแบบจำลองใดอยู่ในนั้น จึงใช้ได้กับ smile (ความผันผวนที่ต่างกันตาม strike) แบบไหนก็ได้ ตราบที่ราคาเดินต่อเนื่องและมี option ครบทุก strike

ตลาดหุ้นจริงมักมี skew คือ put strike ต่ำมีราคาแพงกว่าที่ความผันผวนแบนจะให้ put ที่แพงอยู่แล้วเหล่านี้ยังได้น้ำหนัก $1/K^2$ มากอีก fair variance จึงสูงกว่า variance ที่อ่านจาก option ATM (strike เท่ากับ forward) ตัวอย่างจากแบบจำลอง Heston: fair variance 1 ปีคือ $\mathbb E[\bar v_1]=0.061617$ ถอดรากได้ $\sqrt{0.061617}=24.82\%$ ขณะที่ implied volatility ของ ATM คือ 24.15% และฝั่ง put ให้ 63% ของผลรวม เทียบกับ 50.8% ในตลาดแบนของหน้านี้ (ขั้นตรวจสูตรด้านล่างคิดตัวเลขนี้)

ขั้นที่ 7 — ทำไม strip นี้ได้ variance ไม่ว่าหุ้นจะไปไหน: dollar gamma คงที่

ขั้นก่อน ๆ พิสูจน์ด้วยพีชคณิตว่าสูตรถูก ขั้นนี้ดูอีกมุมว่าทำไมมันได้ผลในทางปฏิบัติ จำสูตรกำไรรายวันในภาพรวมได้ไหม: option ที่ hedge delta แล้วได้วันละ $\tfrac12\Gamma S^2(R^2-\sigma^2\delta t)$ ถ้า dollar gamma $\tfrac12\Gamma S^2$ เปลี่ยนตามราคา กำไรก็ขึ้นกับว่าหุ้นแกว่งตอนอยู่ตรงไหน log contract มีความโค้งแบบที่ทำให้ตัวนี้คงที่

hedge ของ variance swap ถือ log contract $2/T$ หน่วย เพราะ $K_{\rm var}=\frac2T\mathbb E^{\mathbb Q}[-\log(S_T/F)]$ เรียก payoff ของการถือนี้ว่า $L(S)$ แล้วหาอนุพันธ์สองครั้ง ($L''$ ก็คือ gamma ของมัน)

\[ \begin{aligned} L(S)&=\frac2T\Big(-\log\frac{S}{F}\Big),\\ L''(S)&=\frac2T\cdot\frac1{S^2},\\ \tfrac12S^2L''(S)&=\frac1T=\frac{365}{30}=12.17,\\ \delta\Pi&\approx\frac1T\Big[R^2-\sigma^2\delta t\Big]. \end{aligned} \]

ใจความคือ $S^2$ ในสูตร dollar gamma หักกับ $1/S^2$ ของความโค้งพอดี dollar gamma จึงเป็น $1/T$ ทุกระดับราคา ที่อายุ 30 วันได้ $1/T=365/30=12.17$ ไม่ว่าดัชนีจะอยู่ที่ไหน

แถวสุดท้ายเอา dollar gamma คงที่นี้ใส่ในสูตรกำไรรายวัน แต่ละวันได้ $R^2$ ที่เกิดจริง ลบ $\sigma^2\delta t$ ที่จ่ายไว้ตอนซื้อ ทั้งคู่คูณ $1/T$ เท่ากันทุกวัน รวมทั้งอายุจึงได้ realized variance ลบ strike ซึ่งตรงกับ payoff ของ variance swap

นี่คือความต่างจาก option ตัวเดียว ในตัวอย่างขาย call ที่ความผันผวน 30% บนเส้นทาง 50 ช่วงของหน้าโครงสร้างสำหรับเทรดความผันผวน การกระโดดครั้งเดียวตอนหุ้นอยู่ใกล้ strike กินกำไรไปเกือบสามในสิบ เพราะ gamma ตรงนั้นสูง ถ้าใช้ strip $1/K^2$ วันนั้นจะนับเท่ากับวันอื่นที่ขยับขนาดเท่ากัน

ขั้นที่ 8 — ตรวจสูตรกับกรณีที่รู้คำตอบ

ก่อนใช้สูตรกับกริดจริง ควรลองกับกรณีที่รู้คำตอบอยู่แล้ว ถ้าสูตรคืนคำตอบนั้นไม่ได้ ก็แปลว่ามีอะไรผิด

โจทย์ให้อะไรมาบ้าง: ตลาดสมมติมีความผันผวนแบน 20% ทุก strike ราคาเดินแบบ Black–Scholes ด้วยความผันผวนคงที่ variance ต่อปีจึงต้องเป็น $0.2^2=0.04$ พอดี ให้

  • $I_P=\int_0^F P(K)/K^2\,dK$ คือส่วนของ put
  • $I_C=\int_F^\infty C(K)/K^2\,dK$ คือส่วนของ call
  • $Q(K)$ คือราคา option นอกเงินที่ strike $K$ (put เมื่อ $K\lt F$ และ call เมื่อ $K\gt F$)

คิดอินทิกรัลด้วยกฎ Simpson บนตัวแปรใหม่ $y=\log(K/F)$ จาก −1.5 ถึง 1.5 คือ strike ตั้งแต่ $5{,}000e^{-1.5}=1{,}116$ ถึง $5{,}000e^{1.5}=22{,}408$ จุด ใช้ $y$ เพราะ strike กระจายตัวแบบทวีคูณ และแยกอินทิกรัลที่ $y=0$ เพราะ $Q$ มีมุมหักตรงนั้น (เปลี่ยนจาก put เป็น call) ตัวคูณหน้าอินทิกรัลคือ $2e^{rT}/T$ โดย $rT=0.04\times\frac{30}{365}=0.0032877$ และ $e^{0.0032877}=1.0032931$

\[ \begin{aligned} \frac{2e^{rT}}{T}&=\frac{2(1.0032931)}{0.0821918}=24.413465,\\ K_{\rm var}^{\rm cont}&=24.413465\,(I_P+I_C)=0.0400000,\\ \frac{I_P}{I_P+I_C}&=0.5076,\\ K_{\rm var}^{[3000,\,7000]}&=0.04-3.8\times10^{-12}. \end{aligned} \]

คำตอบ: สูตรคืน 0.04 ทุกหลักที่คำนวณ ค่าของอินทิกรัลคิดด้วยโค้ดท้ายหน้า ฝั่ง put ให้ 50.8% ของผลรวม ฝั่ง call ให้ $100\%-50.8\%=49.2\%$ แถวสุดท้ายคิดซ้ำโดยใช้ strike แค่ 3,000 ถึง 7,000 (ช่วงของกริดในขั้นถัดไป) การตัดปีกนี้เสียไปแค่ $3.8\times10^{-12}$ เพราะที่อายุ 30 วัน option ที่ strike ไกลขนาดนั้นแทบไม่มีราคา

ตรวจเองใน 10 วินาที: ใน 30 วัน log ของราคามี SD ราว $\sigma\sqrt T=0.2\sqrt{0.0822}=0.057$ strike 3,000 อยู่ที่ $\log(3{,}000/5{,}000)=\log0.6=-0.51$ ห่างจาก forward ราว $0.51/0.057=9$ SD ราคา put ที่นั่นจึงเป็นศูนย์ในทางปฏิบัติ

ขั้นที่ 9 — กริดจริง 81 strike

ตลาดจริงไม่มี option ทุก strike ต่อเนื่อง มีแค่ strike ห่างกันทุก 50 จุด ขั้นนี้จึงแทนอินทิกรัลด้วยผลรวม แบบเดียวกับที่ Cboe ใช้คำนวณ VIX และได้ strike 0.040203 ของโจทย์เปิดเรื่อง

โจทย์ให้อะไรมาบ้าง: option 81 strike จาก 3,000 ถึง 7,000 จุด กติกาของผลรวมคือ

  • ใช้ราคา put เมื่อ strike ต่ำกว่า $F$ และราคา call เมื่อ strike สูงกว่า $F$
  • ที่ strike $K_0=F=5{,}000$ ใช้ค่าเฉลี่ยของ call กับ put
  • แต่ละ strike คูณความกว้าง $\Delta K=50$ เหมือนพื้นที่ของแท่งหนึ่งแท่ง
  • สูตรของ Cboe มีพจน์ปรับ $-\frac1T(F/K_0-1)^2$ ไว้สำหรับวันที่ไม่มี strike ตรงกับ forward พอดี ที่นี่ $K_0=F$ พจน์นี้จึงเป็นศูนย์

ขั้นที่ 10 — ทำไมกริดให้ 20.05% ไม่ใช่ 20%: มุมหักที่ forward

กริดให้ 20.05% แต่ตลาดถูกสร้างที่ 20% ถ้าเอาตัวเลขนี้ไปเทียบกับความผันผวนที่เกิดจริงโดยไม่รู้ว่า 0.05 จุดนี้มาจากไหน ก็จะสรุปผิด ขั้นนี้หาขนาดของมันด้วยสูตร

ผลรวมบนกริดคือกฎสี่เหลี่ยมคางหมู (trapezoid) ใช้กับฟังก์ชัน $f(K)=Q(K)/K^2$ เมื่อ strike ห่างกัน $h$ จุด กฎนี้มีผลมาตรฐานจากวิชาการอินทิเกรตเชิงตัวเลข (รับมาใช้): บนช่วง $[a,b]$ ที่ $f$ เรียบ ความคลาดเคลื่อน (ผลรวมลบอินทิกรัล) คือราว $\frac{h^2}{12}[f'(b)-f'(a)]$ เรียกความคลาดเคลื่อนนี้ว่า $E_h$

$f$ เรียบทั้งสองฝั่งของ $F$ แต่มีมุมหักที่ $F$ เพราะเปลี่ยนจาก put เป็น call จึงต้องใช้สูตรนี้แยกสองช่วง: $[3{,}000,F]$ กับ $[F,7{,}000]$ ที่ปลาย 3,000 และ 7,000 ราคา option เกือบศูนย์ $f'$ ตรงนั้นจึงเกือบศูนย์ด้วย ที่เหลือคือความชันสองข้างของมุมหัก $f'(F^-)$ (เข้าหา $F$ จากซ้าย) กับ $f'(F^+)$ (จากขวา) ส่วนที่ทำให้กริดคลาดจึงมาจากมุมหักอย่างเดียว

\[ \begin{aligned} E_h&\approx\frac{h^2}{12}\big[f'(F^-)-f'(F^+)\big],\\ f'(F^-)-f'(F^+)&=\frac{P_K(F)-C_K(F)}{F^2}=\frac{D}{F^2},\\ \Delta K_{\rm var}&\approx\frac{2e^{rT}}{T}\cdot\frac{h^2}{12}\cdot\frac{D}{F^2}=\frac{h^2}{6TF^2},\\ h=50:\ \Delta K_{\rm var}&=\frac{2{,}500}{6(0.0821918)(5{,}000)^2}\\ &=0.00020278. \end{aligned} \]

ใจความคือ ทั้งสองข้างของ forward กราฟของ $f$ โค้งหงาย แท่งคางหมูที่ลากเส้นตรงระหว่างจุดจึงอยู่เหนือกราฟเล็กน้อย และบวกเกินทุกช่อง ผลรวมของส่วนเกินทั้งหมดถูกกำหนดด้วยว่าความชันหักลงที่ forward มากแค่ไหน

ขั้นที่ต้องระวังคือแถวที่สอง อนุพันธ์ของ $f=Q/K^2$ คือ $Q_K/K^2-2Q/K^3$ โดย $Q_K$ คืออนุพันธ์ของราคาตาม strike ที่ $K=F$ ราคา put เท่ากับราคา call พจน์ $-2Q/K^3$ จึงเท่ากันทั้งสองฝั่งและหักกันหมด เหลือแค่ $P_K$ กับ $C_K$ อนุพันธ์สองตัวนี้หาได้จากการหาอนุพันธ์ของ payoff ตาม $K$ แล้วหาค่าคาดหมายที่คิดลด: $P_K=D\,\mathbb Q(S_T\lt K)$ และ $C_K=-D\,\mathbb Q(S_T\gt K)$ ลบกันได้ $D$ เพราะสองโอกาสรวมกันเป็นหนึ่ง ผลนี้ไม่ขึ้นกับแบบจำลอง เพราะ put–call parity $C-P=D(F-K)$ ให้ $C_K-P_K=-D$ ทุกตลาด แถวที่สามใช้ $e^{rT}D=1$

สูตรทำนาย 0.00020278 ส่วนต่างจริงจากขั้นก่อนคือ $0.04020277-0.04=0.00020277$ ตรงกันเกือบทุกหลัก ความคลาดเคลื่อนเป็นสัดส่วนกับ $h^2$ ทุกครั้งที่ระยะห่างลดครึ่ง ส่วนเกินลดสี่เท่า ระยะ 200, 100, 50 และ 25 จุดให้ส่วนเกิน 0.00324, 0.00081, 0.00020 และ 0.00005 เช่นที่ $h=200$ ได้ $\sqrt{0.04+0.00324}=20.79\%$ บนกริดจริงจึงควรลบ $h^2/(6TF^2)$ ออก หรือบอกให้ชัดว่ามันรวมอยู่

ขั้นที่ 11 — ชำระเงิน และ mark-to-market กลางสัญญา

ตอนนี้มีเครื่องมือครบที่จะตอบโจทย์เปิดเรื่องแล้ว ระหว่างอายุสัญญา โต๊ะต้องตีมูลค่าสัญญาทุกวัน (mark-to-market) ส่วนที่เกิดแล้วใช้ตามจริง ส่วนที่ยังไม่เกิดใช้ค่าที่ตลาดคาด

โจทย์ให้อะไรมาบ้าง:

  • strike $K_{\rm var}=0.040203$ จากกริด 81 strike ถอดรากได้ $K_{\rm vol}=0.200506$
  • notional $N_v=\$1{,}000{,}000$ ต่อ variance 1.00
  • ผ่านไป 10 จาก 21 วัน ด้วย ${\rm RV}_{10}=0.04788$ (ความผันผวน 21.88%)
  • สมมติว่า 11 วันที่เหลือแกว่งเท่าระดับ strike ซึ่งคือค่าที่ตลาดคาดไว้เมื่อทำสัญญา

แถวของ ${\rm RV}$ และ $\Pi_T$ ใช้การแยก variance ตามน้ำหนักเวลาจากขั้นที่สอง แถวถัดมาคิดตัวเลขของเทรดเดอร์ในโจทย์เปิดเรื่อง สามแถวล่างเทียบกับการประมาณด้วย vega notional ส่วนต่างของความผันผวนที่ใช้คือ $\sqrt{0.04788}-0.200506=0.218815-0.200506=0.018309$ หรือ 1.8309 จุด

\[ \begin{aligned} {\rm RV}&=\tfrac{10}{21}(0.047880)+\tfrac{11}{21}(0.040203)\\ &=0.022800+0.021059=0.043859,\\ \Pi_T&=10^6(0.043859-0.040203)=3{,}656,\\ 10^6(0.047880-0.040203)&=7{,}677.23,\\ N_{\rm vega}&=10^6(2)(0.200506)(0.01)=4{,}010,\\ N_{\rm vega}(1.8309)&=7{,}342,\\ 10^6(0.018309)^2&=335. \end{aligned} \]

คำตอบ: ผู้ซื้อ variance คาดว่าจะได้ \$3,656 ณ วันหมดอายุ โต๊ะที่ขายจึงคาดว่าเสียราว \$3,656 ไม่ใช่ \$7,677.23 ตัวเลข \$7,677.23 เป็นของกรณีที่ทั้ง 21 วันแกว่ง 21.88%

สองแถวล่างแยก \$7,677.23 เป็นสองก้อน ก้อนแรกคือการประมาณเส้นตรงด้วย vega notional $4{,}010\times1.8309=\$7{,}342$ ก้อนที่สองคือส่วนโค้ง \$335 ทำไมต้องมีก้อนที่สอง? เพราะ payoff เป็นเส้นตรงใน variance แต่โค้งในความผันผวน เขียนเป็นพีชคณิตได้ว่า $\sigma^2-K_{\rm vol}^2=2K_{\rm vol}(\sigma-K_{\rm vol})+(\sigma-K_{\rm vol})^2$ คูณทั้งสองข้างด้วย $N_v$ แล้ว ก้อนแรกคือ vega notional คูณจำนวนจุดที่ห่าง strike ก้อนหลังคือส่วนโค้ง $N_v(\sigma-K_{\rm vol})^2$ ซึ่งการประมาณเส้นตรงทิ้งไป (รูปข้างล่าง)

ตรวจเองใน 10 วินาที: $\tfrac{10}{21}\times7{,}677.23=3{,}656$ เพราะส่วนที่ยังไม่เกิดคาดไว้ที่ strike พอดี จึงไม่ให้กำไรหรือขาดทุน เหลือแค่ $10/21$ ของส่วนที่เกิดแล้ว

ขั้นที่ 12 — 30 วันคงที่แบบ VIX: เชื่อมบน total variance

VIX ต้องบอกความผันผวนของ 30 วันข้างหน้าทุกวัน แต่วันหมดอายุของ option ในตลาดไม่ได้ห่างจากวันนี้ 30 วันพอดี สมมติว่าวันนี้มีวันหมดอายุที่ใกล้ที่สุดสองวัน:

  • อายุ 23 วัน fair strike จากผลรวมแบบกริดคิดเป็นความผันผวน $\sigma_{23}=22\%$ (สมมติ)
  • อายุ 37 วัน คิดเป็นความผันผวน $\sigma_{37}=19\%$ (สมมติ)

ต้องเชื่อมสองค่านี้ให้ได้ 30 วัน ขั้นที่สองแสดงว่า variance ของช่วงต่อกันบวกกันได้ตามเวลา ตัวที่โตเป็นเส้นตรงตามเวลาจึงเป็น total variance $w=\sigma^2T$ คือ variance สะสมตั้งแต่วันนี้ถึงวันหมดอายุ ไม่ใช่ความผันผวน เราจึงเชื่อมเส้นตรงบน $w$ แล้วค่อยแปลงกลับเป็นความผันผวน แบบเดียวกับการเชื่อมอายุบนผืนความผันผวน

\[ \begin{aligned} w_{23}&=0.22^2\,(23/365)=0.00304986,\\ w_{37}&=0.19^2\,(37/365)=0.00365945,\\ w_{30}&=w_{23}+\tfrac{30-23}{37-23}\,(w_{37}-w_{23})\\ &=0.00304986+0.5(0.00060959)\\ &=0.00335466,\\ \sigma_{30}&=\sqrt{0.00335466/(30/365)}\\ &=\sqrt{0.040815}=20.2027\%. \end{aligned} \]

30 วันอยู่กึ่งกลางระหว่าง 23 กับ 37 พอดี น้ำหนักจึงเป็น $\frac{30-23}{37-23}=\frac{7}{14}=0.5$ ถ้าเฉลี่ยความผันผวนตรง ๆ จะได้ $\frac{22+19}{2}=20.5\%$ สูงเกินไป $20.5-20.20=0.30$ จุด

ทำไมการเฉลี่ยตรง ๆ ให้ค่าสูงเกิน? เอา $w_{30}=0.5\,w_{23}+0.5\,w_{37}$ หารด้วย $30/365$ เพื่อให้เห็นน้ำหนักบน variance ของแต่ละอายุ: $\sigma_{30}^2=\frac{0.5(23)}{30}(0.22^2)+\frac{0.5(37)}{30}(0.19^2)=\frac{23}{60}(0.0484)+\frac{37}{60}(0.0361)=0.018553+0.022262=0.040815$ อายุสั้นที่ความผันผวนสูงได้น้ำหนักแค่ $23/60$ เพราะมันครอบคลุมเวลาน้อยกว่า การเฉลี่ยตรง ๆ ให้มันครึ่งหนึ่งเต็ม ๆ จึงสูงเกิน

VIX คือ $100\sigma_{30}$ โดย Cboe คิด $K_{\rm var}$ ของแต่ละวันหมดอายุด้วยผลรวมแบบกริดในขั้นก่อน แล้วเชื่อมแบบนี้ VIX จึงเป็นดัชนีอ้างอิง ไม่ใช่ราคาของ variance swap ที่ซื้อขายได้ทันที

ขั้นที่ 13 — ราคากระโดด: ส่วนที่ hedge จ่ายไม่ครบ

ทุกอย่างก่อนหน้านี้ตั้งอยู่บนสมมติข้อเดียว: ราคาเดินต่อเนื่อง ไม่มีวันที่ราคาโดดก้อนใหญ่ทันที เพราะการแยก variance ออกจาก log ในขั้น Itô ต้องการเส้นทางต่อเนื่อง แต่ตลาดจริงมีวันแบบนั้น เช่นวันที่มีข่าวร้ายใหญ่ ขั้นนี้ดูว่าวันแบบนั้น hedge ขาดไปเท่าไร

สมมติวันหนึ่ง log return เป็น $x$ ทันทีในก้อนเดียว

  • สัญญาเพิ่ม $x^2$ ให้ผลรวม $\sum r_i^2$
  • พอร์ต hedge (ขาหุ้นสองหน่วยบวก log contract สองหน่วย ตามแถวสุดท้ายของขั้น Itô) ได้ $2(\Delta S/S)-2\Delta\log S$ เมื่อ log return เป็น $x$ ราคาขยับ $\Delta S/S=e^x-1$ และ $\Delta\log S=x$

สองค่านี้ไม่เท่ากัน แปลงส่วนต่างเป็นเงินด้วยตัวคูณ $A/n=252/21=12$ (เพราะ ${\rm RV}=12\sum r_i^2$) และ $N_v=10^6$

\[ \begin{aligned} 2(e^x-1)-2x&=2(e^x-1-x)\\ &\approx x^2+\tfrac13x^3,\\ x=-0.10:\ 2(e^{-0.1}-0.9)&=0.0096748,\\ 0.0096748-0.01&=-0.0003252,\\ 10^6(12)(-0.0003252)&=-3{,}902,\\ x=+0.10:\ 2(e^{0.1}-1.1)&=0.0103418,\\ 0.0103418-0.01&=+0.0003418,\\ 10^6(12)(0.0003418)&=+4{,}102. \end{aligned} \]

ใจความคือในวันกระโดด hedge ให้ไม่ตรงกับ $x^2$ ส่วนต่างราว $x^3/3$ มีเครื่องหมายตาม $x$ วันร่วงแรง hedge ให้ขาด วันพุ่งแรง hedge ให้เกิน

แถวที่สองมาจากการกระจาย $e^x=1+x+\tfrac12x^2+\tfrac16x^3+\cdots$ แทนลงไปได้ $2(e^x-1-x)=x^2+\tfrac13x^3+\cdots$ พจน์ $x^2$ ตรงกับสัญญา ส่วนที่เหลือคือ $\tfrac13x^3$ ที่ $x$ เล็กมาก พจน์นี้เล็กจนไม่มีผล แต่ที่ $x=\pm0.10$ มันเริ่มเห็นเป็นเงิน

โต๊ะที่ขาย variance swap แล้ว hedge ครบด้วย strip และหุ้น จึงยังเสีย \$3,902 ในวันที่ log return เป็น −10% ซึ่งคือดัชนีลง $1-e^{-0.1}=9.5\%$ ในทางกลับกัน โต๊ะได้ \$4,102 ในวันที่ log return เป็น +10% วันร่วงแรงเกิดบ่อยกว่าวันพุ่งแรงในตลาดหุ้น ผู้ขาย variance จึงเรียกค่าชดเชย นี่เป็นเหตุหนึ่งที่ fair variance ในตลาดจริงมักสูงกว่า variance ที่เกิดขึ้นตามมา

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

ใช้ variance ที่เกิดแล้วแทนทั้งสัญญา: เทรดเดอร์คิดเหมือนสัญญาจบแล้ว ทั้งที่เพิ่งผ่านไป 10 จาก 21 วัน ตัวเลขผิดคือ $10^6(0.04788-0.040203)=\$7{,}677.23$ ตัวเลขถูกใช้น้ำหนักเวลา และคาดส่วนที่เหลือไว้ที่ strike: $10^6(0.043859-0.040203)=\$3{,}656$

ประมาณด้วยความผันผวนแทน variance: คนมักเอาส่วนต่างของความผันผวนคูณ vega notional ซึ่งลืมส่วนโค้ง ตัวเลขผิดคือ $4{,}010\times(21.8815-20.0506)=4{,}010\times1.8309=\$7{,}342$ ตัวเลขถูกคือ \$7,677.23 ขาดไป $10^6(0.018309)^2=\$335$ ยิ่งความผันผวนห่าง strike ส่วนนี้ยิ่งโต ที่ความผันผวน 40% การประมาณเส้นตรงให้ $4{,}010\times(40-20.05)=\$80{,}000$ แต่เงินจริงคือ \$119,797 ขาดไป $10^6(0.40-0.200506)^2=\$39{,}798$

ลืมยกกำลังสองของ variance point: คนมักคิดว่า 1 variance point คือ 0.01 แต่ที่ถูกคือ $0.01^2=0.0001$ ถ้าคิด notional ต่อ variance point ผิดเป็นต่อ 0.01 เงินทุกบรรทัดจะผิดไป $0.01/0.0001=100$ เท่า

เฉลี่ยความผันผวนข้ามอายุ: คนมักเชื่อมความผันผวนตรง ๆ ตัวเลขผิดคือ $(22\%+19\%)/2=20.5\%$ ตัวเลขถูกต้องเชื่อมบน total variance แล้วได้ 20.2027%

เชื่อผลรวมบนกริดว่าเป็นคำตอบ: ผลรวมบนกริดสูงกว่าค่าจริงด้วยสาเหตุทางตัวเลขล้วน ๆ กริด 50 จุดให้ 20.05% แทน 20% และกริด 200 จุดให้ถึง 20.79% ก่อนเอาไปเทียบกับ realized ต้องหักส่วนเกิน $\frac{h^2}{6TF^2}$ ออก ซึ่งที่ $h=50$ คือ 0.000203

ตัดปีกในตลาดที่มี skew: ในตัวอย่างนี้ตัดปีกเสียแค่ $3.8\times10^{-12}$ เพราะความผันผวนแบนและอายุสั้น แต่ในตลาดจริง put ที่ strike ไกลมีราคา และได้น้ำหนัก $1/K^2$ มาก การตัดทิ้งทำให้ fair strike ต่ำกว่าจริง และต่ำเกินที่สุดในวันที่ตลาดกลัวที่สุด

ใช้ทำอะไรบนโต๊ะจริง

เมื่อลูกค้าขอราคา โต๊ะคิด strike จาก strip ของ option ในวันนั้น แล้ว hedge ด้วย option ชุดเดียวกันบวกขาหุ้นที่ปรับทุกวัน เงินที่โต๊ะเหลือจริงคือส่วนต่างระหว่าง realized variance กับ strike แต่ต้องหักสองอย่าง อย่างแรกคือต้นทุนส่วนต่างราคาเสนอซื้อเสนอขาย (bid–ask) ของ option หลายสิบใบ อย่างที่สองคือความเสี่ยงจากวันกระโดด

ระหว่างอายุสัญญา โต๊ะ mark-to-market ด้วยน้ำหนักเวลาแบบในตัวอย่างชำระเงิน ส่วนที่เกิดแล้วใช้ตามจริง ส่วนที่เหลือใช้ fair strike ใหม่ของอายุที่เหลือ ซึ่งคิดจาก option วันนั้น สัญญาจริงชำระด้วยราคาปิดรายวันตามเอกสารสัญญา วันหยุดหรือวันที่ไม่มีราคาต้องตัดสินตามที่สัญญาเขียนไว้

ใครใช้บ้าง ผู้จัดการกองทุนซื้อ variance เพื่อป้องกันวันที่ตลาดผันผวนแรง และขาย variance เพื่อเก็บส่วนต่าง เพราะ fair variance มักสูงกว่า realized กลยุทธ์ dispersion ใช้ variance swap ของดัชนีคู่กับของหุ้นรายตัว เพื่อเดิมพันว่าหุ้นรายตัวจะแกว่งไปคนละทิศมากกว่าที่ราคา option บอก และ VIX เป็นตัวเลขอ้างอิงที่ทั้งตลาดดูร่วมกัน

ประวัติย่อ: Neuberger (1994) เสนอ log contract, Carr และ Madan (1998) ให้สูตรสร้าง payoff โค้งจาก option ทุก strike, Demeterfi, Derman, Kamal และ Zou (1999) เขียนการตั้งราคาและ hedge variance swap ด้วย strip $1/K^2$ และในปี 2003 Cboe เปลี่ยนวิธีคำนวณ VIX มาใช้ผลรวมแบบกริดบน option ของ S&P 500

โจทย์ตรวจความเข้าใจ

1. ลูกค้าอยากซื้อ variance swap และบอกขนาดเป็นภาษาตลาด:

  • vega notional \$50,000 คือได้เสียราว \$50,000 ต่อความผันผวน 1 จุด
  • strike ความผันผวน 20 จุด (20%)

โต๊ะต้องแปลงเป็น notional ต่อ variance point (ต่อ 0.0001) เพื่อใช้ชำระเงินจริง notional นี้เท่าไร? ถ้าความผันผวนที่เกิดจริงคือ 25 จุด ผู้ซื้อได้เท่าไร และการประมาณด้วย vega notional ให้เท่าไร?

เฉลย

ในหน่วยจุด variance คือ $\sigma^2$ ซึ่งมีอนุพันธ์ $2\sigma$ ที่ strike 20 จุด ความผันผวนขยับ 1 จุดจึงทำให้ variance ขยับราว $2\times20=40$ variance point notional ต่อ variance point ($N_{\rm pt}$) จึงเป็น vega notional หารด้วย 40 แล้วใช้มันคิดเงินจริง $\Pi$ และเทียบกับการประมาณเส้นตรง $\Pi_{\rm lin}$

\[\begin{aligned}N_{\rm pt}&=\frac{50{,}000}{2\times20}=\$1{,}250,\\\Pi&=1{,}250\,(25^2-20^2)\\&=1{,}250\times225=\$281{,}250,\\\Pi_{\rm lin}&=50{,}000\times(25-20)\\&=\$250{,}000,\\\Pi-\Pi_{\rm lin}&=1{,}250\times(25-20)^2\\&=\$31{,}250.\end{aligned}\]

ผู้ซื้อได้ \$281,250 การประมาณเส้นตรงให้แค่ \$250,000 ส่วนต่าง \$31,250 คือส่วนโค้ง ซึ่งเป็นสูตรเดียวกับ \$335 ในตัวอย่างชำระเงิน

2. กลับมาที่สัญญาเดิมของหน้านี้ แต่สมมติว่าตลาดเงียบกว่าเดิม ผ่านไป 15 จาก 21 วัน ด้วยความผันผวนที่เกิดแล้ว 18% ถ้า 6 วันที่เหลือคาดไว้ที่ strike 0.040203 ผู้ซื้อ variance คาดว่าได้หรือเสียเท่าไร?

เฉลย

variance ของ 15 วันที่ผ่านไปคือ $0.18^2=0.0324$ ใช้น้ำหนักเวลาแบบขั้นที่สอง แล้วคิดเงินด้วย $N_v=10^6$

\[\begin{aligned}{\rm RV}&=\tfrac{15}{21}(0.0324)+\tfrac{6}{21}(0.040203)\\&=0.023143+0.011487\\&=0.034629,\\\Pi_T&=10^6(0.034629-0.040203)\\&=-\$5{,}573.\end{aligned}\]

ผู้ซื้อคาดว่าเสีย \$5,573 เพราะ 15 วันที่ผ่านไปแกว่งเบากว่า strike

3. วันนี้ต้องคำนวณความผันผวน 30 วันแบบ VIX แต่ตลาดมีวันหมดอายุแค่สองวัน (สมมติ):

  • อายุ 16 วัน ความผันผวน 25%
  • อายุ 44 วัน ความผันผวน 21%

ความผันผวน 30 วันคงที่คือเท่าไร และถ้าเชื่อมความผันผวนตรง ๆ จะได้เท่าไร?

เฉลย

คิด total variance ของแต่ละอายุ หาน้ำหนักของ 30 วัน เชื่อมบน $w$ แล้วแปลงกลับเป็นความผันผวน

\[\begin{aligned}w_{16}&=0.25^2\,(16/365)=0.00273973,\\w_{44}&=0.21^2\,(44/365)=0.00531616,\\\tfrac{30-16}{44-16}&=\tfrac{14}{28}=0.5,\\w_{30}&=0.5\,(w_{16}+w_{44})=0.00402795,\\\sigma_{30}^2&=0.00402795/(30/365)\\&=0.049007,\\\sigma_{30}&=\sqrt{0.049007}=22.14\%.\end{aligned}\]

การเฉลี่ยตรง ๆ ได้ $(25\%+21\%)/2=23\%$ สูงไป $23-22.14=0.86$ จุด ด้วยเหตุผลเดียวกับขั้น VIX: อายุสั้นที่ความผันผวนสูงครอบคลุมเวลาน้อยกว่า

// Variance swap: realized variance, the log-contract strip on an 81-strike grid, the grid's corner bias,
// settlement and mark-to-market, 30-day interpolation on total variance, and the jump error of the hedge.
// Local names for the Math functions.
const { abs, exp, log, sqrt, PI } = Math;
const npdf = x => exp(-0.5 * x * x) / sqrt(2 * PI);
// Normal CDF: Taylor series near the centre, continued fraction in the tails.
function ncdf(x) {
  const a = abs(x);
  if (a <= 3) { let t = a, s = a; for (let n = 1; n < 200 && t > 1e-17 * s; n++) { t *= a * a / (2 * n + 1); s += t; } return x >= 0 ? 0.5 + npdf(a) * s : 0.5 - npdf(a) * s; }
  let f = a;
  for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - npdf(a) / f : npdf(a) / f;
}
// Annualized realized variance of log returns, no mean subtracted.
function realizedVariance(returns, A = 252) {
  if (!Array.isArray(returns) || returns.length === 0) throw new RangeError('Need at least one return');
  if (!returns.every(Number.isFinite)) throw new TypeError('Returns must be finite numbers');
  return A / returns.length * returns.reduce((s, x) => s + x * x, 0);
}

  const v = sigma * sqrt(T), d1 = (log(F / K) + v * v / 2) / v, d2 = d1 - v, call = D * (F * ncdf(d1) - K * ncdf(d2));
  return type === 'call' ? call : call - D * (F - K); // put by put-call parity
}
// Out-of-the-money quote: put below the forward, call above, the average at the forward.
const otm = K => K < F ? black76(K, 'put') : K > F ? black76(K, 'call') : (black76(K, 'call') + black76(K, 'put')) / 2;
const factor = 2 * exp(r * T) / T;
// The strike grid sum with Delta K = h (the correction term is zero because K0 = F).
function gridStrike(h, lo = 3000, hi = 7000) {
  if (!(h > 0 && lo > 0 && hi > lo)) throw new RangeError('Need spacing h > 0 and 0 < lo < hi');
  let sum = 0, count = 0;
  for (let K = lo; K <= hi + 1e-9; K += h) { sum += h * otm(K) / (K * K); count++; }
  return {count, sum, kvar: factor * sum};
}
// The continuous strip by Simpson in y = log(K / F), split at the corner y = 0.
function simpson(f, a, b, n) {
  const h = (b - a) / n;
  let s = f(a) + f(b);
  for (let i = 1; i < n; i++) s += (i % 2 ? 4 : 2) * f(a + i * h);
  return s * h / 3;
}
function continuousStrike(yLow, yHigh) {
  const putSide = simpson(y => black76(F * exp(y), 'put') * exp(-y) / F, yLow, 0, 20000);
  const callSide = simpson(y => black76(F * exp(y), 'call') * exp(-y) / F, 0, yHigh, 20000);
  return {kvar: factor * (putSide + callSide), putShare: putSide / (putSide + callSide)};
}

// Interpolate total variance w = sigma^2 T between two expiries.
function interpolateVol(t, t1, s1, t2, s2) {
  if (!(t1 < t && t < t2)) throw new RangeError('Target maturity must lie between the two expiries');
  const w1 = s1 * s1 * t1, w2 = s2 * s2 * t2, w = w1 + (t - t1) / (t2 - t1) * (w2 - w1);
  return {w1, w2, w, vol: sqrt(w / t)};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • realized variance ยกกำลังสองก่อนบวก วันขึ้นกับวันลงจึงไม่หักล้างกัน 10 วันที่ผลตอบแทนรวมเป็นศูนย์ยังมี variance 0.04788 (ความผันผวน 21.88%) และ variance ของช่วงต่อกันบวกกันได้ตามน้ำหนักเวลา ส่วนความผันผวนบวกแบบนี้ไม่ได้
  • Itô ให้ $\sigma^2dt=2\,dS/S-2\,d\log S$ fair variance จึงเป็นราคาของ log contract $-2\log(S_T/F)$ ซึ่งสร้างได้จาก put และ call นอกเงินทุก strike ถ่วงด้วย $1/K^2$ โดยไม่ต้องเชื่อแบบจำลองใด
  • strip $1/K^2$ มี dollar gamma คงที่ $1/T$ (12.17 ที่อายุ 30 วัน) จึงได้เงินตาม $R^2$ ไม่ว่าดัชนีจะไปไหน ต่างจาก straddle ที่ dollar gamma เหลือแค่ 0.18 เท่าเมื่อดัชนีหนีไป 10%
  • กริด 81 strike ให้ 0.040203 (20.05%) ส่วนเกิน 0.000203 จากคำตอบจริง 0.04 คือ $h^2/(6TF^2)$ ซึ่งมาจากมุมหักที่ forward
  • mark-to-market ใช้น้ำหนักเวลา หลัง 10 จาก 21 วันที่ 21.88% ผู้ขายคาดว่าเสียราว \$3,656 ไม่ใช่ \$7,677
  • ความผันผวน 30 วันคงที่ต้องเชื่อมบน total variance (ได้ 20.2027% ไม่ใช่ 20.5%) และวันที่ราคากระโดดทำให้ hedge คลาดราว $x^3/3$ เช่นเสีย \$3,902 ในวันที่ log return เป็น −10%
