15.4 Pairs Trading and Cointegration

เทรดส่วนต่างของ log ราคาสองหุ้นได้ก็ต่อเมื่อมีหลักฐานว่าส่วนต่างถูกดึงกลับ และต้องรู้ว่ามันกลับช้าแค่ไหน หลักฐานอ่อนแค่ไหน และต้นทุนกินกำไรไปเท่าไร

หุ้นสองตัวที่ทำธุรกิจเดียวกัน เรียกว่าหุ้น A กับหุ้น B มักขึ้นลงไปด้วยกัน แต่บางช่วงตัวหนึ่งวิ่งนำไปก่อน ช่องว่างระหว่างสองราคาจึงถ่างออก เทรดเดอร์คนหนึ่งเดิมพันว่าช่องว่างนี้จะหุบกลับ เขาซื้อตัวที่ถูกไป และ short ตัวที่แพงไป (short คือยืมหุ้นมาขายก่อน แล้วซื้อคืนทีหลัง จึงได้กำไรเมื่อราคาลง) แล้วรอให้ช่องว่างหุบ

ช่องว่างนี้วัดด้วยตัวเลขตัวเดียวชื่อ spread คือ $s=\ln P_A-h\ln P_B$ โดย $P_A$ กับ $P_B$ คือราคาหุ้น และ $h$ เรียกว่า hedge ratio มันบอกว่าเมื่อ B ขยับ 1% A มักขยับราว $h$% ขั้นที่ 1 จะอธิบายว่าทำไมต้องใช้ log

ของที่รู้มีดังนี้ (ประมาณจากข้อมูลในอดีต ตัวเลขสมมติ)

  • ราคาวันนี้ $P_A=\$42$ และ $P_B=\$28$
  • hedge ratio $h=1.15$
  • ปกติ spread แกว่งรอบค่าเฉลี่ย $\mu=-0.025$ ขนาดการแกว่งวัดด้วย SD (standard deviation) ได้ $\sigma_s=0.032$
  • spread มีแรงดึงกลับ: แต่ละวัน ระยะห่างจากค่าเฉลี่ยหดเหลือโดยเฉลี่ย $\phi=e^{-0.05}=0.9512$ เท่าของเมื่อวาน ตัวเลข 0.05 จึงเรียกว่าความเร็วดึงกลับต่อวัน

วันนี้ spread อยู่ห่างค่าเฉลี่ยกี่ SD? ตัวเลขนี้เรียกว่า z-score หรือสั้น ๆ ว่า $z$

\[\begin{aligned}s&=\ln42-1.15\ln28\approx-0.0944,\\z&=\frac{s-\mu}{\sigma_s}=\frac{-0.0944+0.025}{0.032}\\&\approx-2.17.\end{aligned}\]

spread ต่ำกว่าปกติเกิน 2 SD กติกาของเทรดเดอร์บอกให้เข้า “long spread” คือซื้อ A และ short B ไม้นี้ (ไม้ คือคำที่เทรดเดอร์ใช้เรียกการเทรดหนึ่งครั้ง ตั้งแต่เปิดจนปิด) จะได้กำไรเมื่อ spread ขึ้นกลับหาค่าเฉลี่ย เขาจะปิดไม้เมื่อ $z$ ขึ้นมาถึงเส้นออก −0.5

เขายังตั้ง time stop ไว้ 14 วันซื้อขาย คือถ้าถือครบ 14 วันแล้วยังไม่ถึงเส้นออก ให้ปิดไม้ทิ้ง เหตุผลของเขาคือ half-life ของ spread นี้ (จำนวนวันที่ระยะห่างจากค่าเฉลี่ยหดเหลือครึ่ง) เท่ากับ $t_{1/2}=\ln2/0.05=0.693/0.05\approx13.9$ วัน (ขั้นที่ 3 จะอธิบายว่าสูตรนี้มาจากไหน) เขาจึงคิดว่า “ภายในสองสัปดาห์มันต้องกลับแล้ว”

ตั้ง time stop แบบนี้ถูกไหม?

ลองตอบก่อนเปิดเฉลย

เหตุผลนี้ไม่ถูก half-life คือเวลาที่ระยะห่างโดยเฉลี่ยหดเหลือครึ่ง ไม่ใช่เวลาที่ไม้จะถึงเส้นออก ลองดูค่าเฉลี่ยของ $z$ ที่วันที่ 14 โดยเริ่มจาก $z_0=-2.17$ ในวันเข้าไม้ แต่ละวันระยะห่างหดเหลือ $e^{-0.05}$ เท่า 14 วันจึงหดเหลือ $e^{-0.05\times14}$ เท่า

\[\begin{aligned}\mathbb E[z_{14}]&=z_0\,e^{-0.05\times14}\\&=-2.17\times0.497\approx-1.08.\end{aligned}\]

แม้แต่ค่าเฉลี่ยก็ยังห่างจากเส้นออก −0.5 อยู่มาก อีกทั้งแต่ละไม้เจอการกระชากแบบสุ่มไม่เหมือนกัน เวลาที่ไม้ถึงเส้นออกจึงเป็นตัวแปรสุ่ม ขั้นที่ 3 จำลอง spread ตาม model เดียวกัน 20,000 เส้นทาง เริ่มจาก $z_0=-2.17$ แล้วนับว่าแต่ละเส้นแตะเส้นออกครั้งแรกวันไหน ผลคือ

  • มีแค่ราว 36% ที่แตะเส้นออกภายใน 14 วัน
  • ครึ่งหนึ่งใช้นานกว่า 19 วัน (19 วันคือ median)
  • 10% ใช้นานกว่า 45 วัน

stop 14 วันจึงตัดไม้ราว $100\%-36\%=64\%$ หรือราวสองในสามทิ้งก่อนถึงเส้นออก ทั้งที่ model ยังถูกอยู่ ถ้าจะใช้ time stop ต้องตั้งจากการกระจายของเวลาออกจริง และจากต้นทุนการถือไม้ ไม่ใช่จาก half-life

ภาพรวมก่อนลงสูตร

หุ้นสองตัวที่ทำธุรกิจเดียวกัน เช่นธนาคารสองแห่ง มักขึ้นลงไปด้วยกัน เพราะเจอข่าวเศรษฐกิจชุดเดียวกัน แต่บางวันตัวหนึ่งวิ่งนำไปก่อน ถ้ามีแรงที่ดึงสองราคากลับมาอยู่ในสัดส่วนเดิมเสมอ ช่องว่างที่ถ่างออกก็เป็นโอกาสทำเงิน วิธีคือซื้อตัวที่ถูกไป short ตัวที่แพงไป แล้วรอให้ช่องว่างหุบ วิธีนี้เรียกว่า pairs trading

ทำไมต้องถือสองขาพร้อมกัน? เพราะถ้าทั้งตลาดขึ้น ขาที่ซื้อได้กำไร แต่ขาที่ short เสียเงินพอ ๆ กัน สองขาจึงหักกันเอง ถ้าทั้งตลาดลงก็หักกันแบบเดียวกัน สิ่งที่เหลือให้เดิมพันจึงมีแค่เรื่องเดียว คือช่องว่างจะหุบหรือไม่

รูปด้านล่างเป็นข้อมูลจำลองที่สร้างให้สองหุ้นผูกกันจริง แผงบนคือราคาหุ้น A และ B ที่ลอยขึ้นลงไปด้วยกัน แผงล่างคือ spread ในหน่วย SD คือ $z$ ที่แกว่งรอบศูนย์ เส้นแดงประคือเส้นเข้าไม้ที่ ±2 และเส้นเขียวประคือเส้นออกที่ ±0.5

มีเรื่องหนึ่งที่ต้องระวังตั้งแต่ต้น ถ้าลากเส้นตรงด้วย regression ให้ราคาหุ้นตัวหนึ่งอธิบายราคาอีกตัวหนึ่ง ผลมักดูดีมากแม้สองหุ้นไม่เกี่ยวกันเลย เพราะราคาแต่ละตัวลอยไปเรื่อย ๆ แบบไม่มีระดับปกติ ปัญหานี้เรียกว่า spurious regression ข้อยกเว้นมีกรณีเดียว คือส่วนต่างของสองราคาถูกดึงกลับหาระดับปกติจริง กรณีนี้เรียกว่า cointegration และเป็นสิ่งที่ pairs trading เดิมพันอยู่

หน้านี้ทำงานตามลำดับนี้

  • นิยาม spread และวัดว่าวันนี้มันห่างค่าเฉลี่ยแค่ไหน
  • ใช้ model AR(1) วัดว่ามันกลับช้าแค่ไหน แล้วเชื่อมกับ OU process เพื่อดูว่า SD ของ spread มาจากไหน
  • ทดสอบ cointegration ด้วยวิธี Engle–Granger และวัดว่าข้อมูลหนึ่งปีพอจะจับคู่ที่ผูกกันจริงได้บ่อยแค่ไหน
  • แปลงเป็นเงิน: จำนวนหุ้นแต่ละขา กำไรเป้าหมาย จำนวนครั้งที่ spread ข้ามเส้นต่อปี จุดตัดขาดทุน และต้นทุนที่กินกำไร
ศัพท์ที่ใช้ในหัวข้อนี้
Pairs trading
ซื้อหุ้นตัวหนึ่งและ short อีกตัวหนึ่ง ในสัดส่วนที่ทำให้การขึ้นลงร่วมกันของสองตัวหักกันหมด สิ่งที่เหลือคือเดิมพันว่าส่วนต่างจะกลับหาค่าเฉลี่ย
Short
ยืมหุ้นมาขายก่อน แล้วซื้อคืนมาคืนผู้ให้ยืมทีหลัง ได้กำไรเมื่อราคาลง ระหว่างที่ยืมต้องจ่ายค่ายืมหุ้นเป็น % ต่อปี ส่วน long คือการซื้อหุ้นไว้ตามปกติ ได้กำไรเมื่อราคาขึ้น
Spread
$\ln P_A-h\ln P_B$ คือตัวเลขตัวเดียวที่ใช้ตัดสินว่าจะเข้าไม้ ออกไม้ หรือตัดขาดทุน long spread คือซื้อ A และ short B (ได้กำไรเมื่อ spread ขึ้น) ส่วน short spread คือกลับกัน
Hedge ratio
ตัวเลข $h$ ที่บอกว่าเมื่อ B ขยับ 1% A มักขยับราว $h$% ใช้กำหนดว่าขา B ต้องใหญ่กว่าขา A กี่เท่า
z-score
ระยะห่างของ spread จากค่าเฉลี่ย นับเป็นจำนวน SD เช่น $z=-2$ คือต่ำกว่าค่าเฉลี่ยสอง SD
Stationary
ข้อมูลที่มีระดับปกติให้อ้างอิง: ค่าเฉลี่ยและ variance ไม่เปลี่ยนตามเวลา และความสัมพันธ์ระหว่างสองวันขึ้นกับว่าห่างกันกี่วันเท่านั้น ไม่ขึ้นกับว่าเริ่มวัดวันไหน มันบอกว่ามีระดับปกติ แต่ไม่ได้รับรองว่าทุกเส้นทางจะกลับถึงระดับนั้นภายในเวลาที่กำหนด
Unit root
กรณี $\phi=1$ ของ AR(1) แรงดึงกลับเป็นศูนย์ ส่วนต่างจึงเดินสุ่มไปเรื่อย ๆ (random walk) ไม่มีระดับปกติ การทดสอบตั้งกรณีนี้เป็นสมมติฐานแล้วพยายามหาหลักฐานมาปฏิเสธ
Cointegration
log ราคาแต่ละตัวเดินสุ่มแบบไม่มีระดับปกติ (มี unit root) แต่เมื่อนำสองตัวมาผสมกันเป็น $\ln P_A-h\ln P_B$ ผลที่ได้กลับ stationary มันเป็นหลักฐานว่าการดูส่วนต่างรอบระดับปกติมีความหมาย แต่ไม่ใช่หลักประกันกำไร
Engle–Granger test
วิธีทดสอบ cointegration สองขั้น ขั้นแรกใช้ regression ให้ log ราคา B อธิบาย log ราคา A เพื่อหา $h$ ขั้นที่สองดูส่วนที่เส้นตรงอธิบายไม่ได้ (residual) ว่ามีแรงดึงกลับไหม ด้วยการทดสอบ Dickey–Fuller ถ้าเพิ่มค่าการเปลี่ยนของวันก่อน ๆ (lag) เข้าไปด้วย เรียกว่า Augmented Dickey–Fuller (ADF)
Half-life
จำนวนวันที่ระยะห่างจากค่าเฉลี่ยโดยเฉลี่ยหดเหลือครึ่ง ใช้บอกว่าแรงดึงกลับแรงแค่ไหน แต่ไม่ใช่เวลาที่ไม้จะถึงเส้นออก
Time stop
กฎปิดไม้เมื่อถือครบจำนวนวันที่กำหนดแล้วยังไม่ถึงเส้นออก ส่วนจุดตัดขาดทุนตามราคา (stop) คือกฎปิดไม้เมื่อ $z$ วิ่งผิดทางถึงระดับที่กำหนด
Basis point (bp)
หนึ่งในร้อยของ 1% คือ 0.01% ดังนั้น 5 bp เท่ากับ 0.05% หรือ 0.0005

ขั้นที่ 1 — นิยาม spread จาก log ราคา

ก่อนเทรดส่วนต่าง ต้องตกลงกันก่อนว่า “ส่วนต่าง” คืออะไร ทางที่ง่ายที่สุดคือเอาราคามาลบกันตรง ๆ $P_A-P_B=42-28=\$14$ แต่วิธีนี้มีปัญหา ถ้าปีหน้าทั้งสองหุ้นราคาขึ้นเป็นสองเท่า ส่วนต่างจะกลายเป็น $84-56=\$28$ ทั้งที่ความสัมพันธ์ของสองหุ้นไม่ได้เปลี่ยนเลย เกณฑ์เข้าไม้ที่ตั้งไว้ปีนี้จึงใช้ปีหน้าไม่ได้

ทางแก้คือสมมติว่าราคาสองตัวผูกกันแบบสัดส่วน คือเมื่อ B ขึ้น 1% A ขึ้นราว $h$% เสมอ ความสัมพันธ์ที่ให้สมบัตินี้คือ $P_A=c\,P_B^{\,h}$ โดย $c$ เป็นค่าคงที่ แล้วดูว่าอะไรคงที่เมื่อราคาเปลี่ยน

\[ \begin{aligned} P_A&=c\,P_B^{\,h},\\ \ln P_A&=\ln c+h\ln P_B,\\ \ln P_A-h\ln P_B&=\ln c,\\ s_t&:=\ln P_{A,t}-h\ln P_{B,t}. \end{aligned} \]

ข้อสมมติทั้งหมดอยู่ในสมการแรก ที่เหลือเป็นแค่การใส่ log ซึ่งเปลี่ยนผลคูณเป็นผลบวก และดึงเลขชี้กำลัง $h$ ลงมาเป็นตัวคูณ ผลคือ $\ln P_A-h\ln P_B$ เท่ากับค่าคงที่ $\ln c$ ไม่ว่าราคาจะโตไปเท่าไร ตัวอย่างเช่น ถ้า B ขึ้นเป็นสองเท่า $\ln P_B$ เพิ่ม $\ln2$ และ A ขึ้น $2^{h}$ เท่า $\ln P_A$ จึงเพิ่ม $h\ln2$ สองส่วนนี้หักกันพอดี ส่วนต่างจึงไม่ขยับ

ความสัมพันธ์จริงไม่เป๊ะขนาดนั้น $s_t$ จึงแกว่งไปมารอบค่าเฉลี่ย $\mu$ สิ่งที่เดิมพันคือ เมื่อมันแกว่งออกไปไกล มันจะแกว่งกลับ

ส่วน $h$ ไม่ได้เดาเอา มันคือความชันของเส้นตรงที่ลากด้วย OLS ให้ $\ln P_B$ อธิบาย $\ln P_A$ จากข้อมูลในอดีต $h$ จึงเป็นค่าประมาณที่มีความคลาดเคลื่อนติดมาเสมอ

ขั้นที่ 2 — วันนี้ spread อยู่ห่างค่าเฉลี่ยกี่ SD

เทรดเดอร์ดูราคาปิดทุกเย็น แล้วถามว่าวันนี้ spread ห่างจากปกติพอจะเข้าไม้หรือยัง

โจทย์ให้อะไรมาบ้าง:

  • ราคาปิดสามวันล่าสุดของ A และ B อยู่ในสองคอลัมน์แรกของตาราง (ตัวเลขสมมติ)
  • $h=1.15$, $\mu=-0.025$ และ $\sigma_s=0.032$ ประมาณจากข้อมูลช่วงก่อนหน้า (เรียกว่าช่วงฝึก) ซึ่งจบก่อนสามวันนี้ แล้วตรึงค่าไว้ ไม่ได้คำนวณจากสามวันนี้ เพราะถ้าใช้ข้อมูลวันนี้คำนวณค่าเฉลี่ย ก็เท่ากับแอบดูคำตอบ
  • ตอนนี้ยังไม่มีไม้ที่เปิดอยู่
  • กติกาตั้งไว้ก่อนดูข้อมูล: เข้าไม้เมื่อ $z$ ข้ามออกนอกช่วง −2 ถึง +2 และออกเมื่อ $z$ กลับเข้ามาในช่วง −0.5 ถึง +0.5

คอลัมน์ $s$ และ $z$ คำนวณแบบเดียวกันทุกแถว เช่นแถวแรกคือ $s=\ln41-1.15\ln26=3.713572-3.746811=-0.033239$ ข้างล่างจะทำแถวของวันนี้ให้ดูเต็ม ๆ

เริ่มจากแทนราคาวันนี้ลงในนิยามของ spread แล้วแปลงเป็นจำนวน SD นอกจากนั้นยังแปลงเส้นเข้าและเส้นออกจากหน่วย $z$ กลับเป็นระดับ spread ด้วย เพราะ $z=(s-\mu)/\sigma_s$ ย้ายข้างได้ $s=\mu+z\,\sigma_s$

\[ \begin{aligned} s&=\ln42-1.15\ln28\\ &\approx3.737670-1.15(3.332205)\\ &\approx3.737670-3.832035\\ &\approx-0.094366,\\ z&=\frac{s-\mu}{\sigma_s}\\ &=\frac{-0.094366+0.025}{0.032}\\ &=\frac{-0.069366}{0.032}\approx-2.168,\\ s_{\rm entry}&=\mu-2\sigma_s\\ &=-0.025-2(0.032)=-0.089,\\ s_{\rm exit}&=\mu-0.5\sigma_s\\ &=-0.025-0.5(0.032)=-0.041. \end{aligned} \]

คำตอบ: spread วันนี้อยู่ที่ −0.0944 ต่ำกว่าเส้นเข้า −0.089 หรือนับเป็น SD ได้ $z\approx-2.17$ จึงเข้าไม้

น่าแปลกที่ราคาหุ้นทั้งคู่ขึ้นทุกวัน แต่ spread กลับลง เหตุผลคือ B ขึ้นเร็วกว่าที่สัดส่วน 1.15 จะอธิบายได้ ดูจากเมื่อสองวันก่อนถึงวันนี้

\[ \begin{aligned} \Delta\ln P_A&=\ln\tfrac{42}{41}\approx0.0241,\\ \Delta\ln P_B&=\ln\tfrac{28}{26}\approx0.0741,\\ \Delta s&=0.0241-1.15(0.0741)\\ &\approx-0.0611. \end{aligned} \]

log ราคา A เพิ่มแค่ 0.0241 แต่ log ราคา B เพิ่ม 0.0741 พอคูณ 1.15 ได้ $1.15\times0.0741\approx0.0852$ มากกว่าส่วนของ A spread จึงลง 0.0611 ตรงกับในตาราง $-0.094366-(-0.033239)=-0.061127$

ตอนนี้ spread ต่ำเกินไป และเราอยากได้กำไรเมื่อมันขึ้น $s=\ln P_A-h\ln P_B$ จะขึ้นเมื่อ A ขึ้น หรือเมื่อ B ลง จึงต้องซื้อ A (ได้กำไรเมื่อ A ขึ้น) และ short B (ได้กำไรเมื่อ B ลง) ระวัง ถ้าใครนิยาม spread กลับด้านเป็น $\ln P_B$ เทียบ $\ln P_A$ เครื่องหมายจะกลับหมด อย่าท่องว่าต้องซื้อตัวไหน ให้ดูนิยามทุกครั้ง

ตรวจเองใน 10 วินาที: $-0.0944+0.025=-0.0694$ และ $0.0694/0.032\approx2.17$ ระยะ 0.0694 หน่วย log ราคานี้คือระยะที่ spread ต้องเดินกลับถึงค่าเฉลี่ย ขั้นที่ 7 จะแปลงมันเป็นกำไรเป้าหมายเป็นเงิน

ขั้นที่ 3 — กลับช้าแค่ไหน: half-life ไม่ใช่เวลาถึงเส้นออก

รู้แล้วว่าวันนี้ spread ห่างจากปกติ แต่ยังไม่รู้ว่ามันจะกลับเร็วแค่ไหน เรื่องนี้สำคัญ เพราะระหว่างรอ เงินถูกผูกไว้ในไม้ และค่ายืมหุ้น B ที่ short อยู่ก็คิดทุกวัน

ให้ $d_t=s_t-\mu$ คือระยะห่างจากค่าเฉลี่ยในวันที่ $t$ model ที่ง่ายที่สุดที่มีแรงดึงกลับคือ AR(1) มันบอกว่าระยะห่างวันนี้เท่ากับ $\phi$ เท่าของเมื่อวาน บวกการกระชากแบบสุ่มของวันนี้ $\eta_t$ (เรียกว่า shock) ซึ่งมีค่าเฉลี่ยศูนย์และไม่ขึ้นกับอดีต ในหน้านี้ $\phi=e^{-0.05}\approx0.9512$ แปลว่าแต่ละวัน ระยะห่างหดลงโดยเฉลี่ยราว $1-0.9512\approx4.9\%$

เราต้องการสองตัวเลข ตัวแรกคือ half-life $t_{1/2}$ ตัวที่สองคือ $t_m$ จำนวนวันที่เส้นค่าเฉลี่ยของ $z$ เดินจาก $z_0$ ถึงเส้นออก −0.5 ตัวเลขนี้ยังไม่ใช่เวลาออกจริงของไม้ใดไม้หนึ่ง ซึ่งเป็นตัวแปรสุ่ม

\[ \begin{aligned} d_t&=\phi\,d_{t-1}+\eta_t,\quad\mathbb E[\eta_t]=0,\\ \mathbb E[d_t\mid d_0]&=\phi^t d_0,\\ \phi^{t_{1/2}}&=\tfrac12,\\ t_{1/2}&=\frac{\ln0.5}{\ln\phi}=\frac{-0.6931}{-0.05}\\ &\approx13.86,\\ |z_0|\,e^{-0.05\,t_m}&=0.5,\\ t_m&=\frac{\ln(|z_0|/0.5)}{0.05}\\ &=\frac{\ln(2.1677/0.5)}{0.05}\\ &=\frac{1.4668}{0.05}\approx29.34. \end{aligned} \]

หัวใจของขั้นนี้คือ เมื่อหาค่าเฉลี่ย shock จะหายไปเพราะค่าเฉลี่ยของมันเป็นศูนย์ เหลือแต่การคูณ $\phi$ ซ้ำทุกวัน $\mathbb E[d_1]=\phi d_0$, $\mathbb E[d_2]=\phi^2d_0$ ไปเรื่อย ๆ $z$ ก็หดแบบเดียวกัน เพราะ $z_t=d_t/\sigma_s$ เป็นแค่ $d_t$ หารด้วยค่าคงที่ และ $\phi^t=e^{-0.05t}$

คำถาม “กี่วันจึงเหลือครึ่ง” คือการแก้ $\phi^{t}=\tfrac12$ หา $t$ ซึ่ง $t$ อยู่ที่เลขชี้กำลัง ทริกคือใส่ log ทั้งสองข้างเพื่อดึง $t$ ลงมา ทั้งเศษและส่วนติดลบ ผลจึงเป็นบวก $t_m$ ได้มาด้วยทริกเดียวกัน คือหาว่าวันไหนที่ $|z_0|e^{-0.05t}$ ลดลงเหลือ 0.5

บนเส้นค่าเฉลี่ย $z$ ต้องหดจาก 2.17 เหลือ 0.5 คือเหลือ $0.5/2.1677\approx23\%$ ซึ่งน้อยกว่าครึ่งมาก จึงใช้ราว 29.3 วัน ไม่ใช่ 13.9 วัน ที่วันที่ 14 ค่าเฉลี่ยของ $z$ เพิ่งมาถึง $z_0e^{-0.05\times14}\approx-1.08$

แต่ไม้จริงไม่ได้เดินบนเส้นค่าเฉลี่ย แต่ละไม้เจอ shock ของตัวเอง และเราปิดไม้ทันทีที่ $z$ แตะเส้นออกครั้งแรก shock ที่บังเอิญดีจึงพาบางไม้ไปถึงเร็วกว่า 29.3 วันมาก ส่วน shock ที่ไม่ดีลากบางไม้ให้ช้ากว่ามาก

เพื่อดูภาพเต็ม โค้ดท้ายหน้าจำลอง $z$ 20,000 เส้นทาง เริ่มจาก $z_0=-2.17$ เดินวันละก้าวตาม $z_t=\phi z_{t-1}+\sqrt{1-\phi^2}\,\varepsilon_t$ โดย $\varepsilon_t$ สุ่มจาก Normal มาตรฐาน (ตัวคูณ $\sqrt{1-\phi^2}$ ทำให้ SD ของ $z$ คงที่ที่ 1 ขั้นที่ 4 จะอธิบายว่าทำไม) แล้วนับวันที่แต่ละเส้นแตะ −0.5 ครั้งแรก ผลคือ

  • median 19 วัน และค่าเฉลี่ย 23 วัน
  • 25% ของไม้ออกภายใน 12 วัน และ 75% ออกภายใน 30 วัน
  • 10% ใช้นานกว่า 45 วัน
  • ราว 36% แตะเส้นออกภายใน 14 วัน

$t_m$ จึงไม่ใช่เวลาออกที่คาดหวัง และ half-life ยิ่งไม่ใช่

ขั้นที่ 4 — เชื่อมกับ OU process: SD ของ spread มาจากไหน

จนถึงตอนนี้เราใช้ตัวเลขสองตัวราวกับไม่เกี่ยวกัน คือความเร็วดึงกลับ 0.05 ต่อวัน กับ SD ของ spread 0.032 แต่จริง ๆ สองตัวนี้ผูกกัน ลองนึกถึงลูกตุ้มติดสปริงที่โดนเขย่าตลอดเวลา สปริงยิ่งแข็ง ลูกตุ้มยิ่งออกไปได้ไม่ไกล แรงเขย่ายิ่งแรง ลูกตุ้มยิ่งออกไปไกล ขั้นนี้หาว่า SD ของ spread มาจากสองแรงนี้อย่างไร

เครื่องมือคือ OU process ซึ่งเป็น AR(1) ในเวลาต่อเนื่อง และเป็นสมการเดียวกับ model อัตราดอกเบี้ย Vasicek มันเขียนว่า $ds_t=\kappa(\mu-s_t)\,dt+\sigma\,dW_t$ ส่วนแรกคือแรงดึงเข้าหา $\mu$ ซึ่งแรงตามระยะห่าง ด้วยความเร็ว $\kappa=0.05$ ต่อวัน ส่วนที่สองคือการเขย่าแบบสุ่ม $W_t$ คือ Brownian motion (การเดินสุ่มในเวลาต่อเนื่อง) และ $\sigma$ คือขนาดการเขย่า นับเป็น SD ต่อวัน ขั้นนี้สมมติ $\sigma=0.01$ หรือ 1% ต่อวัน เพื่อดูว่าได้ SD ใกล้ 0.032 ไหม

เงื่อนไขที่ใช้คือ เมื่อ spread แกว่งมานานจนเข้าที่ (stationary) variance ของวันนี้ต้องเท่ากับของเมื่อวาน เรียกค่านี้ว่า $\operatorname{Var}(d)$

\[ \begin{aligned} \phi&=e^{-\kappa\Delta t}=e^{-0.05}\approx0.9512,\\ \operatorname{Var}(d)&=\phi^2\operatorname{Var}(d)+\sigma_\eta^2,\\ \operatorname{Var}(d)&=\frac{\sigma_\eta^2}{1-\phi^2},\\ \sigma_\eta^2&=\sigma^2\int_0^1e^{-2\kappa v}\,dv\\ &=\frac{\sigma^2(1-e^{-2\kappa})}{2\kappa},\\ \operatorname{Var}(d)&=\frac{\sigma^2(1-e^{-2\kappa})}{2\kappa(1-e^{-2\kappa})}\\ &=\frac{\sigma^2}{2\kappa}=\frac{0.01^2}{2(0.05)}\\ &=\frac{0.0001}{0.1}=0.001,\\ \sigma_s&=\sqrt{0.001}\approx0.0316. \end{aligned} \]

สมการแรกแปลงความเร็วต่อเนื่อง $\kappa$ เป็นตัวคูณรายวัน $\phi$ โดย $\Delta t=1$ วัน จากนั้นหา variance ของทั้งสองข้างของ $d_t=\phi d_{t-1}+\eta_t$ เพราะ $\eta_t$ ไม่ขึ้นกับ $d_{t-1}$ variance ของผลบวกจึงเป็นผลบวกของ variance ไม่มีพจน์ไขว้ แล้วแก้สมการหา $\operatorname{Var}(d)$

ขั้นที่ยากคือ $\sigma_\eta^2$ ซึ่งเป็น variance ของ shock ที่สะสมในหนึ่งวัน แรงเขย่าที่เข้ามา $v$ วันก่อนสิ้นวัน ถูกแรงดึงกลับกดให้เหลือ $e^{-\kappa v}$ เท่าเมื่อถึงสิ้นวัน variance ของมันจึงเหลือ $e^{-2\kappa v}$ เท่า รวมทุกช่วงเล็ก ๆ ตลอดวันก็คือ integral นี้ (หน้า Vasicek หาแบบเต็ม) พอแทนกลับลงไป $1-\phi^2$ กับ $1-e^{-2\kappa}$ เป็นตัวเดียวกัน เพราะ $\phi^2=e^{-2\kappa}$ จึงตัดกันหมด เหลือ $\sigma^2/(2\kappa)$ ซึ่งตรงกับภาพสปริง: เขย่าแรงขึ้น ($\sigma$ โต) spread กว้างขึ้น ดึงแรงขึ้น ($\kappa$ โต) spread แคบลง

ผลคือ ถ้าการเขย่ามี SD 1% ต่อวัน SD ระยะยาวของ spread คือ 0.0316 ใกล้กับ 0.032 ที่ใช้ทั้งหน้า ถ้าคิดกลับด้าน SD 0.032 กับ $\phi=0.9512$ แปลว่า shock รายวันมี SD

\[\begin{aligned}\sigma_\eta&=\sigma_s\sqrt{1-\phi^2}\\&=0.032\sqrt{1-0.9048}\approx0.00987.\end{aligned}\]

ข้อควรระวังคือ 0.032 เป็น SD ของระดับ spread ไม่ใช่ SD ของการเปลี่ยนรายวัน สองตัวนี้ต่างกันมาก การเปลี่ยนรายวันคือ $\Delta d_t=d_t-d_{t-1}=(\phi-1)d_{t-1}+\eta_t$ ดังนั้น

\[\begin{aligned}\operatorname{Var}(\Delta d)&=(1-\phi)^2\sigma_s^2+(1-\phi^2)\sigma_s^2\\&=2(1-\phi)\,\sigma_s^2,\\\operatorname{SD}(\Delta d)&=0.032\sqrt{2(0.0488)}\\&\approx0.032(0.312)\approx0.0100.\end{aligned}\]

ใครเอา SD ของการเปลี่ยนรายวัน 0.0100 มาตั้งแถบ ±2 จะได้แถบกว้างแค่ ±0.020 แทนที่จะเป็น $\pm2(0.032)=\pm0.064$ แคบเกินไป $0.032/0.0100\approx3.2$ เท่า

ขั้นที่ 5 — ทดสอบ cointegration: Engle–Granger และเกณฑ์ −3.37

ทุกอย่างข้างบนสมมติว่า spread ถูกดึงกลับจริง ถ้าไม่จริง คือ $\phi=1$ spread จะเดินสุ่มไปเรื่อย ๆ (random walk) ไม่มีระดับปกติ ค่าเฉลี่ยในอดีตจึงไม่มีความหมาย และกลยุทธ์พัง ก่อนเอาเงินจริงไปเสี่ยง จึงต้องหาหลักฐานจากข้อมูลว่าแรงดึงกลับมีอยู่จริง

วิธี Engle–Granger ทำสองขั้น ขั้นแรกใช้ regression แบบ OLS ลากเส้นตรงให้ $\ln P_B$ อธิบาย $\ln P_A$ เพื่อหา $c$ กับ $h$ ส่วนที่เส้นตรงอธิบายไม่ได้คือ residual $e_t$ ซึ่งก็คือ spread ที่หักค่าเฉลี่ยแล้ว ขั้นที่สองถามว่า $e_t$ มีแรงดึงกลับหรือไม่ (คือ stationary หรือไม่) โดยให้ $\xi_t$ เป็น shock ของ $e_t$ แบบเดียวกับ $\eta_t$

\[ \begin{aligned} \ln P_{A,t}&=c+h\ln P_{B,t}+e_t,\\ e_t&=\phi\,e_{t-1}+\xi_t,\\ \Delta e_t&=\gamma\,e_{t-1}+\xi_t,\quad\gamma:=\phi-1,\\ t_\gamma&=\frac{\hat\gamma}{\operatorname{SE}(\hat\gamma)},\\ t_\gamma&\lt-3.37. \end{aligned} \]

ทริกอยู่ที่สมการที่สาม ลบ $e_{t-1}$ ออกทั้งสองข้างของ $e_t=\phi e_{t-1}+\xi_t$ ได้ $e_t-e_{t-1}=(\phi-1)e_{t-1}+\xi_t$ ซึ่งเป็น regression ธรรมดาของการเปลี่ยนรายวัน $\Delta e_t$ บนระดับเมื่อวาน $e_{t-1}$ คำถาม “มีแรงดึงกลับไหม” จึงกลายเป็นคำถาม “ความชัน $\gamma$ ติดลบจริงไหม”

  • ถ้า $\gamma=0$ คือ $\phi=1$ (unit root) วันนี้ไม่ได้ถูกดึงกลับเลย
  • ถ้า $\gamma\lt0$ ยิ่งเมื่อวานห่างมาก วันนี้ยิ่งถูกดึงกลับมาก

$t_\gamma$ คือค่าประมาณ $\hat\gamma$ หารด้วย standard error ของมัน คือบอกว่า $\hat\gamma$ ต่ำกว่าศูนย์กี่เท่าของความคลาดเคลื่อน ถ้า $t_\gamma$ ต่ำกว่า −3.37 เราปฏิเสธ unit root และสรุปว่ามีหลักฐานของแรงดึงกลับ ส่วน ADF คือการเพิ่ม $\Delta e$ ของวันก่อน ๆ (lag) เข้าไปใน regression ด้วย เพื่อรับความสัมพันธ์ข้ามวันที่ AR(1) อธิบายไม่หมด โค้ดท้ายหน้าใช้แบบไม่มี lag

ทำไมไม่ใช้เกณฑ์ −1.645 ของ t-test ธรรมดา? มีสองเหตุผล เหตุผลแรก ถ้าไม่มีแรงดึงกลับจริง สถิติ $t_\gamma$ ไม่ได้มี distribution แบบ Student t แต่เบ้ไปทางลบ ค่าติดลบมาก ๆ จึงเกิดบ่อยกว่าที่ตาราง t บอก เหตุผลที่สอง OLS เลือก $h$ ให้ residual แกว่งน้อยที่สุดอยู่แล้ว residual จึงดูนิ่งกว่าความจริง เกณฑ์จึงต้องเข้มกว่าเดิม −3.37 คือเกณฑ์ที่ระดับ 5% จากตารางค่าวิกฤตของการทดสอบนี้ ระดับ 5% หมายความว่า ถ้าสองหุ้นไม่ผูกกันจริง การทดสอบจะบอกผิดว่าผูกกันแค่ 5 ครั้งใน 100 ครั้ง ขั้นที่ 6 ตรวจซ้ำด้วยการจำลองคู่ที่ spread เป็น random walk 2,000 คู่ คู่ละ 250 วัน ได้ $t_\gamma\lt-3.37$ เพียง 4.9% ตรงกับ 5% ที่ตั้งใจ

แล้วทำไมไม่เลือกคู่จาก correlation ของผลตอบแทนรายวัน? เพราะ correlation วัดว่าสองหุ้นขยับไปทางเดียวกันในแต่ละวันแค่ไหน ส่วน cointegration วัดว่าระดับของส่วนต่างถูกดึงกลับหรือไม่ สองเรื่องนี้ต่างกัน คู่ในรูปภาพรวมผูกกันจริง แต่ correlation ของผลตอบแทนรายวันมีแค่ราว 0.81 คิดจากสูตรที่ใช้สร้างข้อมูล คือ $\Delta\ln P_A=1.15\,\Delta\ln P_B+\Delta d$ โดย B ขยับวันละ SD 0.012 และ $\operatorname{Var}(\Delta d)=2(1-\phi)\sigma_s^2$ จากขั้นที่ 4

\[\begin{aligned}\operatorname{Var}(\Delta\ln P_B)&=0.012^2=0.000144,\\\operatorname{Var}(\Delta d)&=2(0.0488)(0.032^2)\\&\approx0.0000999,\\\operatorname{Var}(\Delta\ln P_A)&=1.15^2(0.000144)+0.0000999\\&\approx0.000290,\\\rho&=\frac{1.15(0.000144)}{\sqrt{0.000290}\sqrt{0.000144}}\\&=\frac{0.0001656}{0.01704\times0.012}\approx0.81.\end{aligned}\]

ในทางกลับกัน รูปด้านล่างมีสองคู่ที่การขยับรายวันต่างกันแค่ค่าคงที่ แต่คู่หนึ่งหนีไปไม่กลับ

ขั้นที่ 6 — ข้อมูลหนึ่งปีจับคู่จริงได้บ่อยแค่ไหน

สมมติเรามีข้อมูลราคาย้อนหลังหนึ่งปี และคู่หุ้นนี้ผูกกันจริงตามตัวเลขทั้งหน้า การทดสอบ Engle–Granger จะบอกว่า “ผูกกัน” บ่อยแค่ไหน สัดส่วนครั้งที่การทดสอบจับคู่ที่ผูกกันจริงได้ เรียกว่า power ของการทดสอบ

โจทย์ให้อะไรมาบ้าง: โค้ดท้ายหน้าสร้างคู่จำลองดังนี้ (ใช้ seed ตายตัว รันซ้ำได้ผลเดิม)

  • log ราคา B เป็น random walk ที่แต่ละวันขยับแบบสุ่มด้วย SD 2%
  • log ราคา A เท่ากับ $-0.025+1.15\ln P_B+d_t$ โดย $d_t$ เป็น AR(1) ที่ $\phi=0.9512$ และ SD ระยะยาว 0.032 คู่นี้จึงผูกกันจริง
  • เพื่อเทียบ สร้างอีกชุดที่ $\phi=1$ คือ spread เป็น random walk สองหุ้นไม่ผูกกันจริง
  • ปีหนึ่งมีวันซื้อขายราว 250 วัน (ตลาดหุ้นสหรัฐฯ เปิดราว 252 วันต่อปี) ข้อมูล 500 และ 1,000 วันจึงคือราวสองและสี่ปี

แต่ละคู่ทดสอบด้วย Engle–Granger แล้วนับว่ากี่คู่ได้ $t_\gamma\lt-3.37$

คำตอบ: คู่ที่สร้างให้ดึงกลับด้วย half-life 13.9 วัน ถูกตรวจพบจากข้อมูลหนึ่งปีเพียง 30.7% ของครั้ง อีก $100\%-30.7\%=69.3\%$ การทดสอบบอกว่า “ปฏิเสธ unit root ไม่ได้” ทั้งที่คู่นี้ผูกกันจริง

บทเรียนมีสองข้อ ข้อแรก การไม่ผ่านการทดสอบไม่ได้แปลว่าไม่มี cointegration อาจแค่ข้อมูลสั้นเกินไป ข้อสอง การผ่านก็เป็นแค่หลักฐานจากข้อมูลในอดีต ไม่ได้รับประกันว่าอนาคตจะผูกกันต่อ

ตรวจเองใน 10 วินาที: สัดส่วนที่นับจาก 2,000 ครั้ง คลาดเคลื่อนจากการสุ่มได้ราว $\sqrt{0.05(0.95)/2000}\approx0.5\%$ ค่า 4.9% จึงเข้ากับ 5% ส่วน 30.7% กับ 83.6% ห่างกันมากเกินกว่าความคลาดเคลื่อนนี้มาก ข้อมูลที่ยาวขึ้นช่วยได้จริง

ขั้นที่ 7 — ขนาดสองขา กำไรเป้าหมาย และทำไมขาต้องไม่เท่ากัน

ตอนนี้ต้องตัดสินใจว่าจะลงเงินแต่ละขาเท่าไร เป้าหมายคือให้กำไรขาดทุนขึ้นกับ spread อย่างเดียว ไม่ขึ้นกับว่าตลาดทั้งตลาดขึ้นหรือลง สมมติลงขา A (ซื้อ) มูลค่า $V_A=\$1$ ล้าน คำถามคือขา B (short) มูลค่า $V_B$ ต้องเป็นเท่าไร

เครื่องมือที่ใช้คือ เมื่อราคาขยับไม่มาก กำไรของขาหนึ่งประมาณได้ด้วยมูลค่าของขา คูณการเปลี่ยนของ log ราคา เพราะการเปลี่ยนของ log ราคาใกล้เคียงกับ % ที่ราคาเปลี่ยน (log return ใกล้เคียงผลตอบแทนธรรมดา) ขา short ได้กำไรเมื่อราคาลง จึงมีเครื่องหมายลบ

\[ \begin{aligned} \Pi&\approx V_A\Delta\ln P_A-V_B\Delta\ln P_B,\\ V_B&=hV_A\ \Rightarrow\\ \Pi&\approx V_A(\Delta\ln P_A-h\Delta\ln P_B)\\ &=V_A\,\Delta s,\\ V_B&=1.15(1{,}000{,}000)=1{,}150{,}000,\\ \Delta s&=\mu-s_0\\ &\approx-0.025-(-0.094366)\\ &\approx0.069366,\\ \Pi&\approx1{,}000{,}000(0.069366)\approx69{,}366,\\ n_A&=1{,}000{,}000/42\approx23{,}810,\\ n_B&=1{,}150{,}000/28\approx41{,}071. \end{aligned} \]

ทริกคือเลือก $V_B=hV_A$ แล้ววงเล็บ $\Delta\ln P_A-h\Delta\ln P_B$ จะกลายเป็น $\Delta s$ พอดีตามนิยาม กำไรจึงขึ้นกับ spread ตัวเดียว ถ้าทั้งตลาดขึ้นจน A ขยับตาม B ในสัดส่วน $h$ พอดี spread ไม่ขยับ กำไรก็เป็นศูนย์ ขา B จึงใหญ่กว่าขา A อยู่ $1{,}150{,}000-1{,}000{,}000=\$150{,}000$ โดยตั้งใจ ถ้าลงเงินสองขาเท่ากัน จะไม่ได้ hedge แบบเดียวกัน (ส่วนความผิดพลาดท้ายหน้าแสดงว่าเสียหายแค่ไหน)

$\Delta s=\mu-s_0$ คือระยะที่ spread ต้องเดินจากวันนี้ $s_0$ กลับถึงค่าเฉลี่ย ถ้าปิดไม้ที่เส้นออก $s=-0.041$ แทนที่จะรอถึงค่าเฉลี่ย ระยะจะสั้นลงเป็น $\Delta s=-0.041-(-0.094366)=0.053366$ กำไรจึงเหลือ $1{,}000{,}000\times0.053366\approx\$53{,}366$ ทั้งสองตัวเลขเป็นค่าประมาณก่อนหักต้นทุน ไม่ใช่กำไรที่รับประกัน ถ้า $h$ เปลี่ยน หรือความสัมพันธ์ของสองหุ้นขาด ไม้นี้ก็ขาดทุนได้

ลองกับราคาจริงเพื่อดูว่าค่าประมาณแม่นแค่ไหน ถ้า spread กลับถึงค่าเฉลี่ยเพราะ A ขยับขาเดียว $\ln P_A$ ต้องเพิ่ม 0.069366 ถ้า B ขยับขาเดียว $\ln P_B$ ต้องลด $0.069366/1.15$

\[\begin{aligned}P_A&=42e^{0.069366}\approx45.02,\\n_A(P_A-42)&\approx23{,}810(3.01677)\\&\approx\$71{,}829,\\P_B&=28e^{-0.069366/1.15}\approx26.36,\\n_B(28-P_B)&\approx41{,}071(1.63897)\\&\approx\$67{,}314.\end{aligned}\]

ค่าประมาณเส้นตรง \$69,366 อยู่ระหว่างสองค่านี้ ที่ไม่ตรงเป๊ะเพราะ % ที่ราคาเปลี่ยนจริงกับการเปลี่ยนของ log ราคาต่างกันเล็กน้อย เมื่อเทียบกับเงินที่เปิดไม้ทั้งสองขารวมกัน (เรียกว่า gross) $1{,}000{,}000+1{,}150{,}000=\$2.15$ ล้าน กำไรเป้าหมายคิดเป็น $69{,}366/2{,}150{,}000\approx3.23\%$

ขั้นที่ 8 — วันนอกแถบ การข้ามเส้น และจำนวนไม้ เป็นคนละเรื่อง

ก่อนลงทุนในกลยุทธ์นี้ ผู้จัดการอยากรู้ว่าปีหนึ่งจะได้เข้าไม้กี่ครั้ง เพราะกำไรทั้งปีคือกำไรต่อไม้คูณจำนวนไม้

วิธีคิดที่ผิดแต่พบบ่อยเป็นแบบนี้ ถ้า $z$ เป็น Normal มาตรฐาน (ค่าเฉลี่ย 0 และ SD 1) สัดส่วนวันที่ $|z|\gt2$ คือ 4.55% ปีหนึ่งมี 252 วันซื้อขาย จึงคูณได้ราว 11.5 วันต่อปี แล้วเรียกมันว่า 11 สัญญาณต่อปี

ปัญหาคือ $z$ ของวันติดกันไม่ได้อิสระต่อกัน correlation ระหว่าง $z_{t-1}$ กับ $z_t$ คือ $\phi=0.951$ (เพราะ $z_t=\phi z_{t-1}+$ shock ที่ไม่ขึ้นกับ $z_{t-1}$) ถ้าวันนี้อยู่นอกเส้น พรุ่งนี้ก็มักยังอยู่นอกเส้น วันที่เลยเส้นจึงมาเป็นกลุ่ม ดังที่เห็นในรูปภาพรวมที่ $z$ อยู่ใต้ −2 ติดกันหลายวัน แต่ละกลุ่มให้เข้าไม้ได้แค่ครั้งเดียว

สิ่งที่ควรนับจึงเป็นการข้ามเส้น การข้ามเส้นล่างหนึ่งครั้งคือ เมื่อวาน $z$ ยังอยู่เหนือ −2 แต่วันนี้ลงไปต่ำกว่า −2 ส่วนการข้ามเส้นบนเป็นแบบสมมาตรกัน ให้ $\Phi$ คือพื้นที่ใต้ระฆัง Normal มาตรฐานทางซ้ายของจุดหนึ่ง และ $\varphi$ (phi ตัวหยัก ไม่ใช่ $\phi$ ของ AR(1)) คือ density ของ Normal มาตรฐาน

\[ \begin{aligned} &P(|z|\gt2)=2\Phi(-2)\approx4.55\%,\\ &252(0.0455)\approx11.5,\\ &p_\times:=P(z_{t-1}\gt-2,\ z_t\lt-2),\\ &a(u)=\frac{-2-\phi u}{\sqrt{1-\phi^2}},\\ &p_\times=\int_{-2}^{\infty}\varphi(u)\,\Phi(a(u))\,du\\ &\qquad\approx0.00664,\\ &2(252)(0.00664)\approx3.35. \end{aligned} \]

สองบรรทัดแรกคือวิธีคิดแบบผิดที่นับวัน บรรทัดที่เหลือนับการข้ามเส้น ทริกคือแยกเป็นสองขั้น ขั้นแรก สมมติว่ารู้ค่าเมื่อวาน $z_{t-1}=u$ แล้ว จาก conditional distribution ของ MVN ค่าวันนี้เป็น Normal ที่มีค่าเฉลี่ย $\phi u$ และ SD $\sqrt{1-\phi^2}$ โอกาสที่วันนี้จะต่ำกว่า −2 จึงเป็น $\Phi(a(u))$ โดย $a(u)$ คือระยะจาก $\phi u$ ลงไปถึง −2 นับเป็นจำนวน SD ขั้นที่สอง เฉลี่ยโอกาสนี้ทุกค่า $u$ ที่เมื่อวานยังอยู่เหนือ −2 โดยถ่วงด้วย density $\varphi(u)$ ซึ่งก็คือ integral ข้างบน

integral นี้ไม่มีสูตรปิด โค้ดท้ายหน้าจึงคำนวณด้วยวิธี Simpson (แบ่งช่วงเป็นชิ้นเล็ก ๆ แล้วรวมพื้นที่) ได้ $p_\times\approx0.00664$ ต่อวันต่อฝั่ง คูณ 2 เพราะมีทั้งฝั่งบนและฝั่งล่าง และคูณ 252 วันต่อปี

ผลคือการข้ามเส้นรวมสองฝั่งมีราว 3.35 ครั้งต่อปี ไม่ใช่ 11.5 อัตราส่วน $11.5/3.35\approx3.4$ คือจำนวนวันเฉลี่ยที่ $z$ อยู่นอกเส้นต่อการข้ามหนึ่งครั้ง

แม้แต่ 3.35 ก็ยังไม่ใช่จำนวนไม้ที่เปิดได้จริง เพราะบางครั้ง $z$ ข้ามเส้นอีกรอบระหว่างที่ยังถือไม้เดิมอยู่ จำนวนไม้จริงต้องจำลองพร้อมกฎเข้า ออก และ stop ถ้าสมมติให้ทุกการข้ามทำกำไรได้เต็มทางถึงค่าเฉลี่ย คือ 3.23% ของ gross จะได้ $3.35\times3.23\%\approx10.8\%$ ต่อปี แต่ตัวเลขนี้เป็นเพดานในฝัน ไม่ใช่ประมาณการ เพราะยังไม่รวมไม้ที่ซ้อนกัน ไม้ที่ขาดทุน และต้นทุน

ขั้นที่ 9 — ตั้งจุดตัดขาดทุนก่อนเข้า ไม่ใช่หลังขาดทุน

ฉากที่กลยุทธ์นี้ตายคือ spread กว้างขึ้นเรื่อย ๆ แทนที่จะแคบลง เพราะความสัมพันธ์ของสองหุ้นขาดไปแล้ว เช่นมีข่าวว่าบริษัทหนึ่งจะถูกซื้อกิจการ หรือบริษัทหนึ่งเปลี่ยนไปทำธุรกิจอื่น ขา short อันตรายเป็นพิเศษ เพราะราคาหุ้นขึ้นได้ไม่จำกัด ขาดทุนจึงไม่มีเพดาน

ทางป้องกันคือตั้งกฎปิดไม้ไว้ก่อนส่งคำสั่ง ทั้งจุดตัดขาดทุนตามราคา (stop) และตามเวลา (time stop) ตอนที่ใจยังเย็น ในตัวอย่างนี้ตั้ง stop ไว้ที่ $z_{\rm stop}=-4$ (ตัวเลขสมมติ) แล้วหาว่าถ้าโดน stop จะเสียเท่าไร เพราะ $s=\mu+z\sigma_s$ การเปลี่ยนของ spread จึงเท่ากับการเปลี่ยนของ $z$ คูณ $\sigma_s$ และกำไรเป็น $V_A\Delta s$ จากขั้นที่ 7

\[ \begin{aligned} \Delta s&=(z_{\rm stop}-z_0)\,\sigma_s\\ &=(-4+2.16767)(0.032)\\ &\approx-0.058634,\\ \Pi_{\rm stop}&\approx V_A\Delta s\approx-\$58{,}634,\\ \frac{58{,}634}{69{,}366}&\approx84.5\%,\\ \mathbb E[z_{40}\mid z_0]&=z_0e^{-0.05(40)}\\ &\approx-0.29. \end{aligned} \]

ถ้า $z$ วิ่งผิดทางจาก −2.17 ลงไปถึง −4 ไม้นี้ขาดทุนราว \$58,634 คิดเป็น 84.5% ของกำไรเป้าหมายถ้ากลับถึงค่าเฉลี่ย และมากกว่ากำไรที่เส้นออก \$53,366 เสียอีก

ทำไมเลือก −4? เพราะถ้า spread ยังผูกกันดีและเป็น Normal จริง วันที่ $|z|\gt4$ เกิดน้อยมาก โอกาสคือ $2\Phi(-4)\approx2(0.0000317)\approx6\times10^{-5}$ หรือราว 6 วันในแสนวัน เหตุการณ์หายากขนาดนี้เป็นสัญญาณให้ตรวจว่าความสัมพันธ์ขาดหรือยัง แต่ยังไม่ใช่หลักฐานว่าขาดแล้ว

บรรทัดสุดท้ายเตือนเรื่องกับดักของ time stop ที่วันที่ 40 เส้นค่าเฉลี่ยของ $z$ ขึ้นมาถึง −0.29 แล้ว ซึ่งเลยเส้นออก −0.5 ไป บางคนจึงคิดว่า “ไม้ที่ยังไม่ออกถึงวันที่ 40 แปลว่า model ผิดแน่” ความคิดนี้ผิด เส้นค่าเฉลี่ยนี้เฉลี่ยรวมทุกเส้นทาง แต่ไม้ที่ยังค้างอยู่ถึงวันที่ 40 คือกลุ่มที่บังเอิญเจอ shock ไม่ดีมาตลอด ซึ่งถูกคัดมาแล้ว ผลจำลองในขั้นที่ 3 บอกว่าราว 10% ของไม้ใช้นานกว่า 45 วัน แม้ model ถูกทุกประการ

ดังนั้นระดับ stop ราคา stop เวลา และขนาดเงินต่อคู่ (เช่น 2% ของ NAV คือ 2% ของเงินทุนทั้งหมดของกองทุน) เป็นนโยบายคุมความเสี่ยงที่ต้องเลือกโดยดูต้นทุนและข้อมูลประกอบ ไม่มีสูตร half-life ตัวไหนบอกได้ว่าค่าไหนดีที่สุด

ขั้นที่ 10 — ต้นทุนที่กินกำไร: ค่าซื้อขาย ค่ายืมหุ้น และหุ้นที่ยืมไม่ได้

กำไรเป้าหมายทุกตัวข้างบนยังไม่หักต้นทุน ขั้นนี้หักต้นทุนสองก้อนที่ไม้นี้ต้องจ่ายจริง ก้อนแรกคือค่าซื้อขายทุกครั้งที่ส่งคำสั่ง ก้อนที่สองคือค่ายืมหุ้น B ที่ short อยู่ ซึ่งคิดทุกวันที่ถือไม้

โจทย์ให้อะไรมาบ้าง:

  • ไม้เดิม: ซื้อ A \$1 ล้าน short B \$1.15 ล้าน gross จึงเป็น \$2.15 ล้าน
  • ค่าซื้อขาย 5 bp (คือ 0.05% หรือ 0.0005) ของมูลค่าที่ซื้อขายในแต่ละครั้ง (ตัวเลขสมมติ) รวมส่วนต่างระหว่างราคาเสนอซื้อกับเสนอขาย และราคาที่ขยับหนีเพราะคำสั่งของเราเอง (ผลกระทบราคา)
  • ไม้หนึ่งต้องซื้อขายสี่ครั้ง คือเปิดสองขาและปิดสองขา มูลค่าที่ซื้อขายรวมจึงเป็น $2\times2.15=\$4.3$ ล้าน
  • ถือนานเท่า median ของเวลาออกจากขั้นที่ 3 คือ 19 วันซื้อขาย
  • ค่ายืมหุ้น B คิดเป็น % ต่อปีตามวันปฏิทิน หุ้นทั่วไปราว 0.5% ต่อปี แต่หุ้นที่คนแย่งกันยืมอาจถึง 20% ต่อปี (ตัวเลขสมมติ)

ค่ายืมคิดตามวันปฏิทิน ซึ่งนับเสาร์อาทิตย์และวันหยุดด้วย จึงต้องแปลงวันซื้อขายเป็นวันปฏิทินก่อน ตลาดหุ้นสหรัฐฯ มีราว 252 วันซื้อขายใน 365 วันปฏิทิน

\[ \begin{aligned} T&=19\times\frac{365}{252}\approx27.5,\\ \text{trade}&=4.3\text{M}\times0.0005=2{,}150,\\ \text{borrow}_{0.5\%}&=1.15\text{M}\times0.005\times\frac{27.5}{365}\\ &\approx434,\\ \text{borrow}_{20\%}&=1.15\text{M}\times0.20\times\frac{27.5}{365}\\ &\approx17{,}341,\\ \frac{2{,}150+434}{53{,}366}&\approx4.8\%,\\ \frac{2{,}150+17{,}341}{53{,}366}&\approx36.5\%. \end{aligned} \]

คำตอบ: ถ้า B ยืมง่าย ต้นทุนรวมคือ $2{,}150+434=\$2{,}584$ หรือราว 5% ของกำไรเป้าหมายที่เส้นออก (\$53,366) แต่ถ้า B ยืมยาก ต้นทุนรวมพุ่งเป็น $2{,}150+17{,}341=\$19{,}491$ หรือ 36.5% ของเป้า ทั้งที่สัญญาณเหมือนเดิมทุกอย่าง

ค่าซื้อขายยังโตเร็วกว่าขนาดไม้ด้วย เพราะคำสั่งยิ่งใหญ่เมื่อเทียบกับปริมาณที่หุ้นตัวนั้นซื้อขายกันต่อวัน ราคายิ่งขยับหนีมาก (Almgren–Chriss)

กรณีสุดขั้วคือส่วนต่างที่ “ต้องหุบแน่ ๆ” แต่เทรดไม่ได้ ในปี 2000 บริษัท 3Com แยกบริษัทลูกชื่อ Palm ออกมาขายในตลาดหุ้น แต่ขายหุ้นออกไปแค่ 5% อีก 95% 3Com ยังถือไว้เอง หลังเข้าตลาด มูลค่าตลาดของ Palm (ราคาหุ้นคูณจำนวนหุ้นทั้งหมด) อยู่ที่ราว \$54 พันล้าน ส่วนมูลค่าตลาดของ 3Com ทั้งบริษัทอยู่ที่ราว \$28 พันล้าน ลองคิดว่าตลาดตีราคาธุรกิจอื่นของ 3Com ที่ไม่ใช่ Palm ไว้เท่าไร

\[\begin{aligned}0.95\times54&=51.3,\\28-51.3&=-23.3.\end{aligned}\]

ธุรกิจที่เหลือถูกตีราคาไว้ติดลบ \$23.3 พันล้าน ซึ่งเป็นไปไม่ได้ เพราะเจ้าของหุ้นไม่ต้องรับผิดเกินเงินที่ลงไป ทางทำเงินที่ดูเหมือนแน่นอนคือ short Palm แล้วซื้อ 3Com แต่หุ้น Palm ที่หมุนเวียนในตลาดมีน้อยมาก ค่ายืมจึงสูงจนแทบยืมไม่ได้ ช่องว่างจึงค้างอยู่หลายเดือน สัญญาณถูก แต่ต้นทุนและข้อจำกัดในการ short ทำให้เก็บกำไรไม่ได้

ตรวจเองใน 10 วินาที: $1.15\text{M}\times20\%=\$230{,}000$ ต่อปี หารด้วย 365 ได้ราว \$630 ต่อวัน คูณ 27.5 วันได้ราว \$17,300

ความผิดที่ทำให้กลยุทธ์ดูดีกว่าความจริง

ใช้ half-life แทนเวลาออกจริง: half-life บอกแค่ว่าเส้นค่าเฉลี่ยหดเร็วแค่ไหน ไม่ได้บอกว่าไม้จะถึงเส้นออกวันไหน ถ้าถือไม้ไว้ถึงวันที่ 14 โดยไม่มีกฎออกหรือ stop ระหว่างทาง ค่าเฉลี่ยของ $z$ ที่วันนั้นคือ −1.08 กำไรที่คาดหวังจึงมีแค่

\[\begin{aligned}\Pi_{14}&\approx V_A\sigma_s\big(\mathbb E[z_{14}]-z_0\big)\\&=32{,}000(-1.0764+2.1677)\\&\approx\$34{,}900,\end{aligned}\]

ราวครึ่งเดียวของเป้า \$69,366 และยังไม่หักต้นทุน ผลจำลองในขั้นที่ 3 บอกว่ามีแค่ราว 36% ที่ถึงเส้นออกภายในวันที่ 14 time stop ที่ตั้งจาก half-life จึงตัดไม้ส่วนใหญ่ทิ้งก่อนเวลา

ลงเงินสองขาเท่ากัน: ถ้าซื้อ A \$1 ล้าน และ short B แค่ \$1 ล้าน แทน \$1.15 ล้าน พอร์ตจะแอบเดิมพันทิศทางของ B ไว้โดยไม่ตั้งใจ แยกกำไรได้ดังนี้

\[\begin{aligned}\Pi&\approx V_A\Delta\ln P_A-V_A\Delta\ln P_B\\&=V_A(\Delta\ln P_A-1.15\Delta\ln P_B)\\&\quad+0.15V_A\Delta\ln P_B\\&=V_A\Delta s+0.15V_A\Delta\ln P_B.\end{aligned}\]

พจน์แรกคือเดิมพันเรื่อง spread ที่ตั้งใจ พจน์ที่สองคือเดิมพันว่า B จะขึ้น ถ้า B ขึ้น 10% โดย spread ไม่ขยับ $\Delta\ln P_B=\ln1.1\approx0.0953$ พอร์ตได้ $1{,}000{,}000(0.15)(0.0953)\approx\$14{,}300$ จากเดิมพันที่ไม่ได้ตั้งใจ ถ้า B ลง 10% พจน์นี้จะทำให้เสียพอ ๆ กันแทน

นับวันหรือการข้ามเส้นเป็นจำนวนไม้: 11.5 ที่ได้จาก $252\times4.55\%$ คือจำนวนวันที่ $z$ อยู่นอกเส้นต่อปี และ 3.35 คือจำนวนครั้งที่ $z$ ข้ามเส้นต่อปี ทั้งสองตัวไม่ใช่จำนวนไม้ที่เปิดได้จริง จำนวนไม้ต้องนับจากการจำลองย้อนหลัง (backtest) ที่ใส่ไม้ที่ถืออยู่ กฎออก stop และต้นทุนครบแล้ว

ใช้ค่าเฉลี่ยและ SD จากข้อมูลทั้งชุด: ถ้าคำนวณ $\mu$, $\sigma_s$ หรือ $h$ จากข้อมูลทั้งหมด รวมช่วงที่ใช้ทดสอบด้วย backtest จะแอบรู้ล่วงหน้าว่าระดับปกติในอนาคตอยู่ตรงไหน กลยุทธ์จึงดูดีในการทดสอบแล้วพังตอนใช้จริง ค่าทุกตัวต้องมาจากข้อมูลที่มีอยู่จริง ณ วันที่ตัดสินใจเท่านั้น

ลองหลายคู่แล้วเลือกคู่ที่ผ่าน: ถ้าทดสอบคู่ที่ไม่ผูกกันเลย 100 คู่ที่ระดับ 5% คาดว่าจะมีคู่ผ่านโดยบังเอิญ $100\times0.05=5$ คู่ และโอกาสที่จะมีอย่างน้อยหนึ่งคู่ผ่านคือ $1-0.95^{100}\approx99.4\%$ แทบแน่นอนว่าจะเจอคู่ปลอม คู่ที่ผ่านจึงต้องมีเหตุผลทางธุรกิจรองรับ และต้องผ่านอีกครั้งในข้อมูลช่วงใหม่ที่ไม่เคยใช้เลือก (multiple testing)

ใช้ทำอะไรบนโต๊ะจริง

ทีมที่ทำเงินจากความสัมพันธ์ทางสถิติระหว่างหุ้นแบบนี้เรียกว่าโต๊ะ statistical arbitrage พวกเขาใช้ขั้นตอนในหน้านี้กับคู่ที่มีเหตุผลทางธุรกิจว่าควรผูกกัน เช่น

  • สองบริษัทในธุรกิจเดียวกัน
  • หุ้นสองประเภทของบริษัทเดียวกัน เช่นหุ้นที่มีสิทธิออกเสียงต่างกัน แต่ได้ส่วนแบ่งกำไรเหมือนกัน
  • ETF (กองทุนที่ซื้อขายในตลาดเหมือนหุ้น) กับตะกร้าหุ้นที่กองทุนถืออยู่ข้างใน

ลำดับงานคือ ประมาณ $h$ จากข้อมูลช่วงหนึ่ง ทดสอบ residual แล้วตรึงค่าเฉลี่ย SD เส้นเข้า เส้นออก stop ราคา และ stop เวลาไว้ จากนั้นจึงเทรดในช่วงถัดไปที่ไม่ได้ใช้ประมาณค่าเหล่านี้ และทบทวนทุกค่าเป็นระยะ

ทีมของ Nunzio Tartaglia ที่ Morgan Stanley ทำแบบนี้ด้วยคอมพิวเตอร์ตั้งแต่กลางทศวรรษ 1980 ส่วนเครื่องมือทดสอบ cointegration มาทีหลัง คือบทความของ Engle และ Granger ในปี 1987 งานจริงทุกวันนี้ยังขยายจากคู่หุ้น ไปเป็นหุ้นหนึ่งตัวเทียบกับตะกร้าหุ้นที่สร้างจาก factor model แล้วเทรดส่วนที่หุ้นตัวนั้นขยับเองโดยไม่เกี่ยวกับตะกร้า

โจทย์ตรวจความเข้าใจ

1. สมมติว่าวันนี้ราคาปิดออกมาต่างจากตัวอย่าง A ปิดที่ \$44 และ B ยังปิดที่ \$28 ใช้ $h$, $\mu$ และ $\sigma_s$ ชุดเดิม เทรดเดอร์ควรเข้าไม้ไหม

เฉลย

คำนวณ spread แล้วแปลงเป็น $z$ แบบเดียวกับขั้นที่ 2

\[\begin{aligned}s&=\ln44-1.15\ln28\\&=3.784190-3.832035\\&\approx-0.047846,\\z&=\frac{-0.047846+0.025}{0.032}\approx-0.71.\end{aligned}\]

$z$ ยังอยู่ในช่วง −2 ถึง +2 จึงไม่เข้าไม้ ราคา A ที่สูงขึ้นทำให้ spread ขยับขึ้นมาใกล้ค่าเฉลี่ย

2. สมมติทีมวิจัยประมาณ $\phi$ จากข้อมูลชุดใหม่ได้ 0.98 ต่อวัน แทน 0.9512 (ความเร็วดึงกลับจึงเป็น $\kappa=-\ln0.98\approx0.0202$ ต่อวัน) half-life และจำนวนวันที่เส้นค่าเฉลี่ยของ $z$ เดินจาก $z_0=-2.168$ ถึงเส้นออก −0.5 จะเป็นเท่าไร

เฉลย

ใช้สูตรเดียวกับขั้นที่ 3 แต่เปลี่ยน 0.05 เป็น $-\ln0.98$

\[\begin{aligned}t_{1/2}&=\frac{\ln0.5}{\ln0.98}\approx34.3,\\t_m&=\frac{\ln(2.1677/0.5)}{-\ln0.98}\\&\approx\frac{1.4668}{0.0202}\approx72.6.\end{aligned}\]

half-life 34.3 วัน และ $t_m$ 72.6 วัน ช้ากว่าเดิมราว $72.6/29.3\approx2.5$ เท่า ทั้งที่ $\phi$ ต่างกันแค่ $0.98-0.9512\approx0.029$ ค่ายืมหุ้นที่คิดตามจำนวนวันจึงโตตามราว 2.5 เท่าด้วย และเวลาออกจริงยังกระจายกว้างกว่า $t_m$ อีก

3. สมมติกองทุนอยากทำไม้นี้ให้ใหญ่ขึ้น โดยลงขา A \$3 ล้าน แทน \$1 ล้าน ต้องซื้อ A กี่หุ้น และ short B กี่หุ้น ถ้า spread กลับถึงค่าเฉลี่ยเต็มทาง กำไรแบบเส้นตรงเป็นเท่าไร และถ้า $z$ วิ่งผิดทางไปโดน stop ที่ −4 ขาดทุนเท่าไร

เฉลย

ใช้สูตรของขั้นที่ 7 และขั้นที่ 9 โดยเปลี่ยน $V_A$ เป็น \$3 ล้าน

\[\begin{aligned}V_B&=1.15\times3{,}000{,}000=3{,}450{,}000,\\n_A&=3{,}000{,}000/42\approx71{,}429,\\n_B&=3{,}450{,}000/28\approx123{,}214,\\\Pi&=3{,}000{,}000(0.069366)\\&\approx\$208{,}100,\\\Pi_{\rm stop}&=3\times(-58{,}634)\\&\approx-\$175{,}900.\end{aligned}\]

ทุกตัวเป็นสามเท่าของเดิมพอดี เพราะทุกสูตรเป็นเส้นตรงใน $V_A$ ข้อยกเว้นคือค่าซื้อขาย ซึ่งโตเร็วกว่าเส้นตรงเมื่อไม้ใหญ่ขึ้น เพราะคำสั่งที่ใหญ่ขึ้นดันราคาหนีมากขึ้น

function positive(...values) {
  if (!values.every(v => Number.isFinite(v) && v > 0)) throw new RangeError('Prices, sizes and speeds must be positive numbers');
}
// Spread of log prices, and how many standard deviations it sits from its long-run mean.
function spreadZ(priceA, priceB, h, mean, sd) {
  positive(priceA, priceB, h, sd);
  if (!Number.isFinite(mean)) throw new TypeError('Mean must be a finite number');
  const s = Math.log(priceA) - h * Math.log(priceB);
  return {s, z: (s - mean) / sd};
}
// AR(1) with coefficient phi = exp(-kappa): expected deviation shrinks by phi each day.
function reversion(kappa) {
  positive(kappa);
  const phi = Math.exp(-kappa);
  return {phi, halfLife: Math.log(0.5) / Math.log(phi), daysTo: (z0, z1) => Math.log(Math.abs(z0 / z1)) / kappa};
}
function legs(valueA, h, priceA, priceB) {
  positive(valueA, h, priceA, priceB);
  const valueB = h * valueA;
  return {valueB, sharesA: Math.round(valueA / priceA), sharesB: Math.round(valueB / priceB), gross: valueA + valueB, net: valueA - valueB};
}
const {exp, sqrt, log, sin, cos, imul, PI} = Math; // local names: hot loops below avoid global lookups
const phiN = x => exp(-x * x / 2) / sqrt(2 * PI);
function simpson(f, lo, hi, n = 4000) {
  const w = (hi - lo) / n;
  let sum = 0;
  for (let i = 0; i <= n; i++) sum += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * f(lo + i * w);
  return sum * w / 3;
}
const Phi = x => Math.abs(x) > 10 ? (x > 0 ? 1 : 0) : 0.5 + Math.sign(x) * simpson(phiN, 0, Math.abs(x), 400);
// Days beyond +-z and raw threshold crossings, not executable trade entries.
// Lower crossing: yesterday > -z, today < -z; the upper side is symmetric.
function signalCount(z, rho, days) {
  if (!(z > 0) || !(Math.abs(rho) < 1) || !(days > 0)) throw new RangeError('Need z > 0, |rho| < 1 and a positive day count');
  const tail = 2 * Phi(-z);
  const crossOneSide = simpson(z1 => phiN(z1) * Phi((-z - rho * z1) / sqrt(1 - rho * rho)), -z, 10, 4000);
  return {tail, daysBeyond: days * tail, entries: 2 * days * crossOneSide, daysPerEpisode: tail / (2 * crossOneSide)};
}
// Seeded standard normals (mulberry32 + Box-Muller).
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = imul(a ^ (a >>> 15), a | 1);
    t ^= t + imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const q = spare; spare = null; return q; }
    const r = sqrt(-2 * log(u())), q = 2 * PI * u();
    spare = r * sin(q);
    return r * cos(q);
  };
}
// First day the AR(1) z-score climbs from z0 back to the exit line, over many simulated paths.
function firstHit(z0, exitZ, phi, runs, seed) {
  if (!(z0 < exitZ) || !(phi > 0 && phi < 1) || !Number.isInteger(runs) || runs < 100) {
    throw new RangeError('Need z0 below the exit line, 0 < phi < 1 and at least 100 runs');
  }
  const g = normals(seed), sz = sqrt(1 - phi * phi), hits = [];
  let by14 = 0;
  for (let k = 0; k < runs; k++) {
    let z = z0, t = 0;
    while (z < exitZ && t < 2000) { z = phi * z + sz * g(); t++; }
    hits.push(t);
    if (t <= 14) by14++;
  }
  hits.sort((p, q) => p - q);
  const q = f => hits[Math.floor(f * runs)];
  return {median: q(0.5), mean: hits.reduce((s, v) => s + v, 0) / runs, p25: q(0.25), p75: q(0.75), p90: q(0.9), shareBy14: by14 / runs};
}
// Engle-Granger: OLS of log A on log B, then a Dickey-Fuller regression of the residual's change on its lagged level.
function engleGranger(logA, logB) {
  if (!Array.isArray(logA) || !Array.isArray(logB) || logA.length !== logB.length || logA.length < 20) {
    throw new RangeError('Need two log-price series of the same length, at least 20 days');
  }
  if (![...logA, ...logB].every(Number.isFinite)) throw new TypeError('Log prices must be finite');
  const n = logA.length, ma = logA.reduce((s, v) => s + v, 0) / n, mb = logB.reduce((s, v) => s + v, 0) / n;
  let sxy = 0, sxx = 0;
  for (let t = 0; t < n; t++) { sxy += (logB[t] - mb) * (logA[t] - ma); sxx += (logB[t] - mb) ** 2; }
  const h = sxy / sxx, c = ma - h * mb, e = logA.map((v, t) => v - c - h * logB[t]);
  let num = 0, den = 0;
  for (let t = 1; t < n; t++) { num += e[t - 1] * (e[t] - e[t - 1]); den += e[t - 1] ** 2; }
  const gamma = num / den;
  let ss = 0;
  for (let t = 1; t < n; t++) ss += (e[t] - e[t - 1] - gamma * e[t - 1]) ** 2;
  return {h, gamma, t: gamma / Math.sqrt(ss / (n - 2) / den)};
}
// Share of simulated pairs whose Engle-Granger t falls below the critical value.
function egPower(runs, days, phi, seed, critical = -3.37) {
  if (!Number.isInteger(runs) || runs < 100 || !Number.isInteger(days) || days < 20) throw new RangeError('Use at least 100 runs of at least 20 days');
  if (!(phi > 0 && phi <= 1)) throw new RangeError('phi must lie in (0, 1]');
  const z = normals(seed), sd = 0.032, step = phi < 1 ? sd * Math.sqrt(1 - phi * phi) : 0.00987;
  let reject = 0;
  for (let k = 0; k < runs; k++) {
    let lb = Math.log(28), x = phi < 1 ? sd * z() : 0;
    const la = [], lbs = [];
    for (let t = 0; t < days; t++) {
      lb += 0.02 * z(); x = phi * x + step * z();
      lbs.push(lb); la.push(-0.025 + 1.15 * lb + x);
    }
    if (engleGranger(la, lbs).t < critical) reject++;
  }
  return reject / runs;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • spread คือ $\ln P_A-h\ln P_B$ ใช้ log เพื่อให้ส่วนต่างไม่โตตามระดับราคา ในตัวอย่าง spread วันนี้คือ −0.0944 หรือ $z=-2.17$ จึงซื้อ A และ short B ในสัดส่วนเงิน 1 ต่อ 1.15
  • half-life 13.9 วันคือเวลาที่ระยะห่างโดยเฉลี่ยหดเหลือครึ่ง เส้นค่าเฉลี่ยของ $z$ ถึงเส้นออก −0.5 ในราว 29.3 วัน แต่เวลาออกจริงของแต่ละไม้กระจายกว้าง ผลจำลองให้ median 19 วัน และ 10% เกิน 45 วัน
  • SD ของ spread มาจากสองแรง คือขนาดการเขย่าและความเร็วดึงกลับ $\sigma_s^2=\sigma^2/(2\kappa)$ และเป็น SD ของระดับ ไม่ใช่ของการเปลี่ยนรายวัน
  • ตั้งขา B ให้เป็น $h$ เท่าของขา A กำไรจึงเป็น $V_A\Delta s$ ขึ้นกับ spread อย่างเดียว กับไม้ \$1 ล้าน ปิดที่เส้นออกได้ราว \$53,366 ถึงค่าเฉลี่ยได้ราว \$69,366 และโดน stop ที่ −4 เสียราว \$58,634 ทั้งหมดก่อนต้นทุน
  • Engle–Granger ที่เกณฑ์ −3.37 จับคู่ที่ผูกกันจริงจากข้อมูลหนึ่งปีได้แค่ราว 31% ในการจำลองนี้ ขณะที่คู่ปลอมผ่านได้ 5% ลองร้อยคู่จึงแทบแน่นอน (99.4%) ว่าจะเจอคู่ปลอม

  • ถ้าหุ้นที่ short ยืมยาก ต้นทุนรวมกินกำไรที่เส้นออกได้ถึงราว 36.5% หรือเกินหนึ่งในสาม และส่วนต่างที่ถูกต้องอาจเทรดไม่ได้เลยถ้ายืมหุ้นมา short ไม่ได้
