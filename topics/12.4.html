12.4 Lagrange Multipliers — Equality Constraints

เมื่อถูกบังคับให้อยู่บนเส้น จุดที่ดีที่สุดคือจุดที่เส้นระดับของเป้าหมายแตะเส้นนั้นพอดี และตัวคูณ Lagrange ที่ได้มาด้วยบอกว่าข้อบังคับมีราคาเท่าไรต่อหนึ่งหน่วย

บริษัทเทรดแห่งหนึ่งแบ่งคนเป็นเดสก์ (desk คือทีมเทรดย่อยที่ดูแลกลยุทธ์ของตัวเอง) ทุกปีหัวหน้าฝ่ายเทรดต้องแบ่ง “ทุนความเสี่ยง” ให้แต่ละเดสก์ ทุนความเสี่ยงคือวงเงินที่บริษัทยอมให้เดสก์เอาไปลงทุน และยอมให้เสี่ยงขาดทุนได้ ปีนี้มีงบ \$12 ล้าน มีสองเดสก์ และต้องแบ่งให้หมดทุกดอลลาร์

ทีมวิจัยมีแบบจำลอง (สมมติ) ที่บอกกำไรคาดหวังต่อปีของแต่ละเดสก์ กำไรคาดหวังคือกำไรเฉลี่ยที่คาดว่าจะได้ นับทุนเป็นล้านดอลลาร์

  • เดสก์ 1 ได้ทุน $x_1$ ล้าน ทำกำไร $2\ln(1+x_1)$ ล้านดอลลาร์ต่อปี
  • เดสก์ 2 ได้ทุน $x_2$ ล้าน ทำกำไร $4\ln(1+x_2)$ ล้านดอลลาร์ต่อปี
  • งบต้องใช้ครบพอดี $x_1+x_2=12$

เลขหน้า $\ln$ คือฝีมือ เดสก์ 2 มีเลข 4 เดสก์ 1 มีเลข 2 เดสก์ 2 จึงเก่งกว่าสองเท่า แบบจำลองใช้ $\ln$ เพราะเงินยิ่งมาก เงินล้านถัดไปยิ่งทำกำไรได้น้อยลง (เทรดก้อนใหญ่ ต้นทุนการซื้อขายสูงขึ้น และโอกาสดี ๆ ในตลาดมีจำกัด) ส่วนเลข $1+$ ทำให้เดสก์ที่ได้ทุน 0 ได้กำไร $2\ln1=0$ พอดี

ในที่ประชุมมีคนพูดสองข้อ

  1. “เดสก์ 2 เก่งกว่าสองเท่า ก็ให้เงินสองเท่า แบ่ง 4 : 8” คือ $x_1=4$ และ $x_2=8$
  2. “หาให้ได้ว่าเงินก้อนเล็ก ๆ ก้อนสุดท้ายทำกำไรได้กี่เปอร์เซ็นต์ต่อปี เรียกอัตรานี้ว่า $r$ ถ้าปีหน้าได้งบเพิ่มอีก \$1 ล้าน กำไรจะเพิ่ม $r\times\$1$ ล้าน พอดี”

สองข้อนี้ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ผิดทั้งสองข้อ แต่ผิดไม่มาก หน้านี้จะคำนวณตัวเลขเหล่านี้ให้ดูทีละขั้น

  • แบ่ง 4 : 8 ได้กำไร $2\ln5+4\ln9=12.0078$ ล้านต่อปี
  • แบ่งที่ดีที่สุดคือ $x_1=11/3\approx3.667$ และ $x_2=25/3\approx8.333$ ได้กำไร \$12.0153 ล้านต่อปี มากกว่าแบบ 4 : 8 อยู่ $12.015259-12.007774=0.007485$ ล้าน คือ \$7,485 ต่อปี
  • เดสก์ที่เก่งกว่าสองเท่าควรได้เงิน $\dfrac{25/3}{11/3}=\dfrac{25}{11}\approx2.27$ เท่า ไม่ใช่ 2 เท่า
  • อัตรากำไรของเงินก้อนสุดท้ายคือตัวคูณ Lagrange $\nu=3/7\approx0.4286$ คือ 42.86% ต่อปี ข้อสองจึงทำนายว่างบเพิ่ม \$1 ล้าน ได้กำไรเพิ่ม $\tfrac37\times\$1{,}000{,}000=\$428{,}571$ แต่ได้จริงแค่ \$413,957 เพราะอัตรานี้ลดลงเรื่อย ๆ ระหว่างที่เติมเงิน

ภาพรวมก่อนลงสูตร

ถ้าไม่มีงบจำกัด ทั้งสองเดสก์อยากได้เงินไม่จำกัด เพราะ $\ln(1+x)$ ยังขึ้นต่อไปเรื่อย ๆ แต่งบ \$12 ล้าน บังคับว่า $x_1+x_2=12$ ถ้าวาดทุกการแบ่ง $(x_1, x_2)$ เป็นจุดบนระนาบ การแบ่งที่ใช้งบครบพอดีคือเส้นตรงเส้นเดียว คำถามจึงไม่ใช่ “จุดไหนบนระนาบกำไรสูงสุด” แต่เป็น “บนเส้นตรงเส้นนี้ จุดไหนกำไรสูงสุด” ข้อบังคับที่ต้องเท่ากับค่าหนึ่งพอดีแบบนี้ เรียกว่า equality constraint

รูปด้านล่างตอบด้วยตา เส้นโค้งสีน้ำเงินคือเส้นระดับกำไร (level curve) ทุกจุดบนเส้นเดียวกันได้กำไรเท่ากัน เหมือนเส้นชั้นความสูงบนแผนที่ภูเขา ยิ่งไปทางขวาบน กำไรยิ่งสูง ลองเดินไปตามเส้นงบ แล้วดูว่าแตะเส้นระดับได้สูงสุดแค่ไหน จุดที่ดีที่สุดคือจุดที่เส้นระดับแค่แตะเส้นงบ โดยไม่ตัดข้าม

ตรงจุดแตะนั้นมีลูกศรสองอัน ลูกศรแรกคือ gradient ของกำไร คือลูกศรที่ชี้ไปทางที่กำไรเพิ่มเร็วที่สุด ลูกศรที่สองคือ gradient ของงบ ซึ่งตั้งฉากกับเส้นงบ สองลูกศรชี้ทางเดียวกัน ต่างกันแค่ความยาว อัตราส่วนความยาวนี้เรียกว่าตัวคูณ Lagrange (Lagrange multiplier) เขียนด้วยอักษรกรีก $\nu$ (อ่านว่า นิว) หน้านี้จะพิสูจน์ว่า $\nu$ คือกำไรที่เพิ่มขึ้นต่องบที่เพิ่ม 1 ล้าน หรือ “ราคา” ของเงินล้านถัดไป

หน้านี้เดินตามลำดับนี้

  1. พิสูจน์ว่าทำไมสองลูกศรต้องขนานกันที่จุดดีที่สุด
  2. สร้าง Lagrangian คือ function ตัวเดียวที่รวมเป้าหมายกับข้อบังคับไว้ด้วยกัน แล้วใช้แก้โจทย์แบ่งทุน
  3. พิสูจน์ว่า $\nu$ คือราคาเงา (shadow price) คือมูลค่าของงบหน่วยถัดไป แล้วทดสอบด้วยงบ \$13 ล้าน
  4. ตรวจความโค้งว่าจุดที่ได้เป็นยอดสูงสุดจริง
  5. ใช้วิธีเดียวกันกับพอร์ตหุ้นกับพันธบัตร สองแบบ: พอร์ตที่แกว่งน้อยที่สุด ซึ่งกลายเป็นระบบสมการเชิงเส้นชุดเดียว และพอร์ต mean-variance ซึ่งตัวคูณบอกว่าควรกู้เงินมาลงทุนเพิ่มหรือไม่
  6. ปิดด้วยกรณีที่วิธีนี้พัง

ขั้นที่ 1 — ทำไม gradient ของเป้าหมายต้องขนานกับ gradient ของข้อบังคับ

รูปบอกเราด้วยตาแล้ว แต่เราต้องการวิธีตรวจด้วยสูตร ว่าจุดหนึ่งบนเส้นงบดีที่สุดแล้วหรือยัง ขั้นนี้เขียนแบบทั่วไป เพื่อใช้ได้กับทุกโจทย์

  • $f(x)$ คือเป้าหมายที่อยากให้สูงที่สุด ในโจทย์แบ่งทุน $f$ คือกำไรรวม $F$
  • $g(x)=b$ คือข้อบังคับ ในโจทย์แบ่งทุนคือ $x_1+x_2=12$
  • $x$ คือจุดปัจจุบัน $d$ คือทิศที่จะก้าว และ $\epsilon$ คือระยะก้าวที่เล็กมาก

เครื่องมือคือการประมาณด้วยเส้นตรงจากหน้า gradient และเงื่อนไขอันดับหนึ่ง: ก้าวเล็ก ๆ ไปทาง $d$ ทำให้ค่าของ function เปลี่ยนประมาณ gradient คูณทิศ เราใช้มันสองครั้ง ครั้งแรกกับ $g$ เพื่อหาว่าทิศไหนเดินแล้วไม่หลุดเส้น ครั้งที่สองกับ $f$ เพื่อดูว่าเดินทิศนั้นแล้วเป้าหมายเปลี่ยนอย่างไร

\[ \begin{aligned} g(x+\epsilon d)&\approx g(x)+\epsilon\,\nabla g^{\mathsf T}d,\\ g(x+\epsilon d)=b:&\quad\nabla g^{\mathsf T}d=0,\\ f(x\pm\epsilon d)&\approx f(x)\pm\epsilon\,\nabla f^{\mathsf T}d,\\ x^\star:&\quad\nabla f^{\mathsf T}d=0,\\ \nabla f(x^\star)&=\nu\,\nabla g(x^\star). \end{aligned} \]

แนวคิดคือ ถ้าลูกศร $\nabla f$ ยังมีส่วนที่ชี้ไปตามเส้นข้อบังคับ เราก็เดินตามส่วนนั้นได้ เป้าหมายจะสูงขึ้นโดยไม่หลุดเส้น จุดนั้นจึงยังไม่ดีที่สุด

ทิศที่เดินแล้วไม่หลุดเส้นคือทิศที่ทำให้ $g$ ไม่เปลี่ยน คือ $\nabla g^{\mathsf T}d=0$ หรือทิศที่ตั้งฉากกับ $\nabla g$ ถ้าในทิศนั้น $\nabla f^{\mathsf T}d$ ไม่เป็นศูนย์ ก้าวไปทาง $+d$ กับทาง $-d$ ให้ $f$ เปลี่ยนคนละเครื่องหมาย ทางใดทางหนึ่งจึงทำให้ $f$ สูงขึ้นแน่ ที่จุดดีที่สุด $x^\star$ จึงต้องมี $\nabla f^{\mathsf T}d=0$ แปลว่า $\nabla f$ ตั้งฉากกับเส้นเหมือนกับ $\nabla g$

ในสองมิติ ทิศที่ตั้งฉากกับเส้นตรงมีแนวเดียว $\nabla f$ กับ $\nabla g$ จึงอยู่บนแนวเดียวกัน ต่างกันแค่ตัวคูณ $\nu$ (ต้องมี $\nabla g\ne0$ ไม่อย่างนั้นไม่มีแนวให้เทียบ) นี่คือภาพ “เส้นระดับแตะเส้นงบ” ในรูปแรก เพราะ gradient ตั้งฉากกับเส้นระดับเสมอ

ในโจทย์แบ่งทุน $\nabla g=(1, 1)$ และทิศที่เดินได้คือ $d=(1, -1)$ คือย้ายเงินจากเดสก์ 2 ไปเดสก์ 1 เงื่อนไข $\nabla F^{\mathsf T}d=0$ จึงกลายเป็น $\dfrac{\partial F}{\partial x_1}-\dfrac{\partial F}{\partial x_2}=0$ แปลว่ากำไรส่วนเพิ่มของสองเดสก์ต้องเท่ากัน เหตุผลตรงไปตรงมา ถ้าไม่เท่ากัน ย้ายเงินจากเดสก์ที่ทำได้น้อยไปเดสก์ที่ทำได้มาก กำไรรวมก็ขึ้น กฎนี้คือกฎเดียวกับ “marginal variance เท่ากันทุกตัว” ของพอร์ตที่ลงเงินครบในหน้า gradient และเงื่อนไขอันดับหนึ่ง

ขั้นที่ 2 — Lagrangian: เอาข้อบังคับใส่เข้าไปในเป้าหมาย

ตอนนี้มีสองเงื่อนไขที่ต้องถือไว้พร้อมกัน คือลูกศรต้องขนานกัน และจุดต้องอยู่บนเส้นงบ Lagrange รวมสองเงื่อนไขไว้ใน function ใหม่ตัวเดียว เรียกว่า Lagrangian เขียนว่า $\mathcal L$ ข้อดีคือหลังจากนั้นใช้กฎเดิมที่รู้แล้วได้เลย คือตั้ง derivative ทุกตัวเป็นศูนย์ $\mathcal L$ มีตัวแปรสามตัว คือ $x_1$, $x_2$ และ $\nu$ ซึ่งเป็นตัวที่ยังไม่รู้ค่าอีกตัวหนึ่ง แถวแรกด้านล่างเป็นนิยาม แถวที่เหลือคือ derivative ที่ตั้งเป็นศูนย์

\[ \begin{aligned} \mathcal L(x,\nu)&=F(x)-\nu\,(x_1+x_2-b),\\ \frac{\partial\mathcal L}{\partial x_i}&=\frac{\partial F}{\partial x_i}-\nu=0,\\ \frac{\partial\mathcal L}{\partial\nu}&=-(x_1+x_2-b)=0. \end{aligned} \]

derivative เทียบ $x_1$ และ $x_2$ บอกว่า $\partial F/\partial x_i=\nu$ ทั้งสองเดสก์ นี่คือเงื่อนไขขนานกัน $\nabla F=\nu\nabla g$ นั่นเอง เพราะ $\nabla g=(1, 1)$ ส่วน derivative เทียบ $\nu$ เป็นของแถม มันคืนข้อบังคับเดิมกลับมา รวมได้สามสมการ สำหรับสามตัวที่ไม่รู้ ($x_1$, $x_2$, $\nu$) พอดี

ทำไมเติมพจน์นี้แล้วโจทย์ไม่เปลี่ยน? เพราะบนเส้นงบ $x_1+x_2-b=0$ พจน์ที่เติมจึงเป็นศูนย์ และ $\mathcal L$ เท่ากับ $F$ ทุกจุดบนเส้น

จะเขียนลบหรือบวกพจน์นี้ก็ได้ ถ้าเขียนบวก ค่า $\nu$ ที่ได้จะกลับเครื่องหมาย แต่ $x$ ที่ได้เหมือนเดิม หน้านี้เลือกลบ เพื่อให้ $\nu$ เป็นบวกเมื่อทุนเพิ่มแล้วกำไรเพิ่ม ซึ่งตรงกับความหมายของราคา อ่าน $\mathcal L$ ได้อีกแบบว่า “คิดค่าปรับ $\nu$ ต่อทุกหน่วยที่ใช้เกินงบ แล้วปล่อยให้เลือก $x$ ได้อิสระ” แนวคิดนี้เป็นตัวเดียวกับ Lagrangian relaxation ของ linear program

ขั้นที่ 3 — แก้ระบบด้วยตัวอักษร: ทุกอย่างเขียนเป็น ν ได้

ระบบมีสามสมการ แต่ถ้าพยายามแก้หา $x_1$ ตรง ๆ จะติด เพราะทุกสมการมี $\nu$ ที่ยังไม่รู้ค่า เคล็ดคือทำสองจังหวะ จังหวะแรก เขียนทุนของแต่ละเดสก์เป็น function ของ $\nu$ จังหวะที่สอง แทนทุนทั้งสองลงในข้อบังคับงบ ซึ่งจะเหลือตัวไม่รู้แค่ $\nu$ ตัวเดียว ขั้นนี้ยังไม่ใส่ตัวเลขงบ ใช้ $b$ ไว้ก่อน เพื่อให้สูตรใช้ได้กับทุกงบ

\[ \begin{aligned} \frac{2}{1+x_1}&=\nu,\qquad x_1=\frac{2}{\nu}-1,\\ \frac{4}{1+x_2}&=\nu,\qquad x_2=\frac{4}{\nu}-1,\\ x_1+x_2&=\frac{6}{\nu}-2=b,\\ \nu&=\frac{6}{b+2}. \end{aligned} \]

derivative ของ $2\ln(1+x_1)$ คือ $\dfrac{2}{1+x_1}$ ตาม chain rule ตัวนี้คือกำไรส่วนเพิ่มของเดสก์ 1 สมการบอกว่ามันต้องเท่ากับ $\nu$ ย้ายข้างแล้วได้ $x_1$ ในรูปของ $\nu$ เดสก์ 2 ทำแบบเดียวกัน พอบวกทุนสองเดสก์ ได้สมการที่มี $\nu$ ตัวเดียว จึงแก้ได้

เอาสูตรของสองเดสก์มาหารกันจะเห็นสิ่งที่น่าสนใจ $\dfrac{1+x_2}{1+x_1}=\dfrac{4/\nu}{2/\nu}=2$ เสมอ ไม่ว่างบเท่าไร แปลว่าฝีมือเป็นตัวล็อกสัดส่วนของ “ทุนบวกหนึ่ง” ส่วนงบกำหนดแค่ขนาด

สูตร $\nu=\dfrac{6}{b+2}$ บอกว่า $\nu$ ลดลงเมื่องบ $b$ โตขึ้น ยิ่งมีเงินมาก เงินก้อนถัดไปยิ่งทำกำไรได้น้อย นี่คือ diminishing returns ที่ฝังอยู่ใน $\ln$

ขั้นที่ 4 — งบ \$12 ล้าน: แบ่ง 3.667 กับ 8.333

โจทย์ให้อะไรมาบ้าง: งบ $b=12$ ล้าน แทนลงในสูตร $\nu=6/(b+2)$ ที่เพิ่งได้ แล้วแทน $\nu$ ลงในสูตรทุนของแต่ละเดสก์ สุดท้ายเอาทุนไปคำนวณกำไร ตัวเลขใน $\ln$ คือ $1+x_1=2/\nu=14/3$ และ $1+x_2=4/\nu=28/3$

\[ \begin{aligned} \nu&=\frac{6}{14}=\frac37\approx0.428571,\\ x_1&=\frac{14}{3}-1=\frac{11}{3}\approx3.667,\\ x_2&=\frac{28}{3}-1=\frac{25}{3}\approx8.333,\\ F^\star&=2\ln\frac{14}{3}+4\ln\frac{28}{3}\\ &=2(1.540445)+4(2.233592)\\ &=12.015259. \end{aligned} \]

ทำไมเดสก์ 2 ได้เงิน 2.27 เท่า ไม่ใช่ 2 เท่า? สิ่งที่เป็นสองเท่าพอดีคือ “ทุนบวกหนึ่ง” คือ $1+x_2=2(1+x_1)$ ย้ายข้างได้ $x_2=2x_1+1$ หารด้วย $x_1$ ทั้งสองข้าง

\[ \begin{aligned} \frac{x_2}{x_1}&=2+\frac{1}{x_1}\\ &=2+\frac{3}{11}=\frac{25}{11}\approx2.27. \end{aligned} \]

ส่วนเกิน $1/x_1$ มาจากเลข 1 ใน $\ln(1+x)$ ถ้างบโตขึ้น $x_1$ โตตาม ส่วนเกินนี้ก็เล็กลง และสัดส่วนเข้าใกล้ 2 เท่า

ขั้นที่ 5 — ν คือราคาของเงินก้อนถัดไป แล้วทดสอบด้วยงบ \$13 ล้าน

ถึงตรงนี้ $\nu$ ดูเหมือนแค่ตัวช่วยแก้สมการ แต่มันมีความหมายในตัวเอง ถ้าบริษัทเพิ่มงบ $b$ ขึ้นนิดหนึ่ง คำตอบ $x^\star(b)$ ขยับตาม กำไรที่ดีที่สุด $F^\star(b)=F\big(x^\star(b)\big)$ ก็ขยับตาม เราอยากรู้ว่ากำไรที่ดีที่สุดขึ้นเร็วแค่ไหนต่องบที่เพิ่ม คือ $dF^\star/db$ หาได้ด้วย chain rule แล้วแทนเงื่อนไขขนานกัน $\nabla F=\nu\nabla g$ ที่จุดคำตอบ

\[ \begin{aligned} \frac{dF^\star}{db}&=\nabla F(x^\star)^{\mathsf T}\,\frac{dx^\star}{db}\\ &=\nu\,\nabla g^{\mathsf T}\,\frac{dx^\star}{db}\\ &=\nu\,\frac{d}{db}\big(x_1^\star+x_2^\star\big)\\ &=\nu\,\frac{d}{db}\,b=\nu. \end{aligned} \]

ผลคือ $dF^\star/db=\nu$ พอดี ตัวคูณจึงไม่ใช่แค่ตัวช่วยคำนวณ มันคืออัตราที่กำไรที่ดีที่สุดเพิ่มขึ้นต่องบที่เพิ่ม ผลนี้มีชื่อว่า envelope theorem

จังหวะที่ต้องดูคือช่วงท้าย คำตอบอยู่บนเส้นงบทุกค่าของ $b$ คือ $x_1^\star(b)+x_2^\star(b)=b$ เสมอ derivative ของสองข้างเทียบ $b$ จึงเป็น 1 พอดี และเหลือแค่ $\nu$

หน่วยของ $\nu$ คือล้านดอลลาร์ต่อปี ต่อทุน 1 ล้าน ล้านหารด้วยล้านตัดกัน จึงเหลือเป็นอัตราต่อปี $\nu=3/7=0.4286$ คือ 42.86% ต่อปี ตัวเลขนี้เป็นของเงินก้อนเล็ก ๆ ก้อนถัดไปเท่านั้น อย่าสับสนกับผลตอบแทนเฉลี่ยของเงินทั้งก้อน ซึ่งคือ $12.0153/12=1.0013$ หรือ 100.13% ต่อปี

มาทดสอบด้วยตัวเลข ถ้างบเพิ่มจาก \$12 ล้าน เป็น \$13 ล้าน $\nu$ ทำนายว่ากำไรเพิ่ม $\nu\times1=0.428571$ ล้าน คือ \$428,571 ต่อปี ของจริงต้องแก้โจทย์ใหม่ เราหาสูตรของกำไรที่ดีที่สุดสำหรับงบ $b$ ใด ๆ ไว้ก่อน โดยแทน $1+x_1=2/\nu=(b+2)/3$ และ $1+x_2=4/\nu=2(b+2)/3$ ลงใน $F$ แล้วกระจาย $\ln$ ของผลคูณและผลหาร

\[ \begin{aligned} F^\star(b)&=2\ln\tfrac{b+2}{3}+4\ln\tfrac{2(b+2)}{3}\\ &=6\ln(b+2)-6\ln3+4\ln2,\\ F^\star(13)-F^\star(12)&=6\ln15-6\ln14\\ &=6\ln\tfrac{15}{14}=0.413957. \end{aligned} \]

derivative ของสูตรนี้คือ $\dfrac{6}{b+2}$ ซึ่งเท่ากับ $\nu$ ทุกค่าของ $b$ ตรงกับที่พิสูจน์ แต่กำไรที่เพิ่มจริงคือ \$413,957 ต่อปี การทำนายด้วย $\nu$ สูงไป $\dfrac{0.428571-0.413957}{0.413957}=3.53\%$ สาเหตุคือ $\nu$ เองลดลงระหว่างที่เติมเงิน จาก $6/14=0.4286$ ที่งบ 12 เหลือ $6/15=0.4$ ที่งบ 13

ถ้าเติมพจน์ความโค้งของ Taylor อันดับสองเข้าไป การทำนายจะดีขึ้นมาก ความโค้งของ $F^\star$ คืออัตราที่ความชัน $\nu$ เปลี่ยน คือ $\dfrac{d\nu}{db}=-\dfrac{6}{(b+2)^2}$ ซึ่งที่ $b=12$ เท่ากับ $-\dfrac{6}{196}$ งบเพิ่ม $\Delta b=1$ ล้าน

\[ \begin{aligned} F^\star(13)-F^\star(12)&\approx\nu\,\Delta b\\ &\quad+\tfrac12\,\frac{d\nu}{db}\,(\Delta b)^2\\ &=0.428571-\tfrac12\cdot\tfrac{6}{196}\\ &=0.428571-0.015306\\ &=0.413265. \end{aligned} \]

ขั้นที่ 6 — ตรวจอันดับสอง: ทำไมเป็นยอดสูงสุดของทั้งเส้น

เงื่อนไขขนานกันบอกแค่ว่าความชันตามเส้นงบเป็นศูนย์ จุดแบบนี้เป็นแค่ “ผู้สมัคร” เพราะจุดที่ความชันเป็นศูนย์อาจเป็นยอดเนิน ก้นหุบ หรือจุดอานม้าก็ได้ ต้องดูความโค้งด้วย Hessian matrix $H$ คือ matrix ของ derivative อันดับสอง ตามหน้า Hessian และเงื่อนไขอันดับสอง แต่บนข้อบังคับ เราเดินได้แค่ตามเส้นงบ ทิศที่ต้องตรวจจึงมีแค่ $d=(1, -1)$ ความโค้งตามทิศ $d$ คือ $d^{\mathsf T}Hd$ ถ้าค่านี้ติดลบ จุดนี้เป็นยอดเนินเมื่อเดินตามเส้นงบ

\[ \begin{aligned} H&=\begin{bmatrix}-\frac{2}{(1+x_1)^2}&0\\0&-\frac{4}{(1+x_2)^2}\end{bmatrix},\\ H_{11}(x^\star)&=-\frac{2}{(14/3)^2}\approx-0.0918,\\ H_{22}(x^\star)&=-\frac{4}{(28/3)^2}\approx-0.0459,\\ d^{\mathsf T}Hd&=H_{11}+H_{22}\\ &\approx-0.1378\lt0. \end{aligned} \]

ค่าติดลบแปลว่า ย้ายเงินออกจากจุดคำตอบไปทางไหนก็ตามบนเส้นงบ กำไรลดลง จุดนี้จึงเป็นยอด ที่ $d^{\mathsf T}Hd$ เหลือแค่ $H_{11}+H_{22}$ เพราะช่องนอกทแยงเป็นศูนย์ (กำไรของเดสก์หนึ่งไม่ขึ้นกับทุนของอีกเดสก์) และสมาชิกของ $d$ คือ $1$ กับ $-1$ ซึ่งยกกำลังสองแล้วเป็น 1 ทั้งคู่

เราพูดได้มากกว่า “ยอดใกล้ตัว” ด้วย ทแยงของ $H$ ติดลบทุกจุดที่ทุนมากกว่า $-1$ ซึ่งคือทุกจุดที่ $\ln(1+x)$ คำนวณได้ กำไรรวมจึงโค้งคว่ำทุกทิศทุกที่ (concave) และเส้นงบเป็นเส้นตรง หน้า global กับ local minimum พิสูจน์ว่า function ที่เป็นชามหงาย (convex) บนเขตที่เป็นเส้นตรง ก้นหลุมใกล้ตัวคือก้นต่ำสุดของทั้งเขต กลับหัวเรื่องนี้ก็ได้ว่ายอดใกล้ตัวของ function โค้งคว่ำคือยอดสูงสุดของทั้งเส้น

ถ้าเป้าหมายไม่ได้โค้งคว่ำทุกทิศ ให้ตรวจเฉพาะทิศ $d$ ที่เดินได้ คือ $\nabla g^{\mathsf T}d=0$ ทิศที่หลุดเส้นงบไม่ต้องนับ เพราะเราเดินไปทางนั้นไม่ได้อยู่แล้ว

ขั้นที่ 7 — วิธีเดียวกันกับพอร์ต: ความเสี่ยงต่ำสุด และระบบสมการเชิงเส้นชุดเดียว

วิธีเดียวกันใช้กับพอร์ตได้ทันที กองทุนหนึ่งลงเงินในสองอย่าง คือหุ้นกับพันธบัตร และต้องลงเงินครบ 100% เป้าหมายคือให้ผลตอบแทนของพอร์ตแกว่งน้อยที่สุด ตัววัดการแกว่งคือ variance ของผลตอบแทน (ความผันผวนยกกำลังสอง) โจทย์นี้หาค่าต่ำสุด ไม่ใช่สูงสุด แต่เงื่อนไข “ลูกศรขนานกัน” เหมือนเดิม

โจทย์ให้อะไรมาบ้าง:

  • น้ำหนักหุ้น $x_1$ และน้ำหนักพันธบัตร $x_2$ คือสัดส่วนของเงินที่ลงในแต่ละอย่าง ข้อบังคับคือ $x_1+x_2=1$
  • ความผันผวนต่อปีของหุ้น $\sigma_1=20\%$ และของพันธบัตร $\sigma_2=10\%$
  • correlation ระหว่างหุ้นกับพันธบัตร $\rho=0.30$ คือตัวเลขจาก $-1$ ถึง $1$ ที่บอกว่าสองอย่างขึ้นลงไปด้วยกันแค่ไหน

สามตัวเลขนี้ใส่ลงใน covariance matrix $V$ ช่องทแยงคือ $\sigma_1^2=0.2^2=0.04$ และ $\sigma_2^2=0.1^2=0.01$ ช่องนอกทแยงคือ $\rho\sigma_1\sigma_2=0.3\times0.2\times0.1=0.006$ variance ของพอร์ตคือ $q(x)=x^{\mathsf T}Vx$ และ gradient ของมันคือ $2Vx$ ใช้ $\lambda$ เป็นตัวคูณของงบน้ำหนัก ตั้ง Lagrangian แล้วตั้ง derivative เทียบ $x_1$, $x_2$ และ $\lambda$ เป็นศูนย์ ได้ระบบสมการเชิงเส้นสามสมการ

\[ \begin{aligned} \mathcal L&=x^{\mathsf T}Vx-\lambda\,(x_1+x_2-1),\\ 0.08x_1+0.012x_2-\lambda&=0,\\ 0.012x_1+0.02x_2-\lambda&=0,\\ x_1+x_2&=1,\\ 0.068x_1-0.008x_2&=0,\\ x_2&=8.5x_1,\\ x_1&=\tfrac{1}{9.5}=\tfrac{2}{19}\approx0.105263,\\ x_2&=\tfrac{17}{19}\approx0.894737,\\ \lambda&=0.08(\tfrac{2}{19})+0.012(\tfrac{17}{19})\\ &\approx0.019158. \end{aligned} \]

คำตอบ: หุ้น 10.53% พันธบัตร 89.47% ตรงกับที่หน้า global กับ local minimum ได้จากการแทน $x_2=1-x_1$ และที่หน้า gradient และเงื่อนไขอันดับหนึ่ง ได้จากการตั้ง marginal variance เท่ากัน

วิธีแก้มีจังหวะเดียวที่ต้องคิด สองสมการแรกเขียนรวมกันได้ $2Vx=\lambda\mathbf1$ ($\mathbf1$ คือ vector ที่มีเลข 1 ทุกช่อง) แปลว่า marginal variance ของทุกสินทรัพย์ (variance ที่เพิ่มขึ้นเมื่อเพิ่มน้ำหนักตัวนั้นนิดหนึ่ง) ต้องเท่ากับ $\lambda$ ตัวเดียวกัน เอาสมการแรกลบสมการที่สอง $\lambda$ ก็หายไป เหลือ $0.068x_1=0.008x_2$ หรือ $x_2=8.5x_1$ แทนลง $x_1+x_2=1$ ได้ $9.5x_1=1$

$\lambda$ แปลว่าอะไร? ที่คำตอบ $Vx=\tfrac{\lambda}{2}\mathbf1$ variance ต่ำสุดจึงเป็น

\[ \begin{aligned} q^\star&=x^{\mathsf T}Vx=\tfrac{\lambda}{2}(x_1+x_2)\\ &=\tfrac{\lambda}{2}=0.0095789. \end{aligned} \]

ถ้าลงเงิน $b$ เท่าของทุนแทน 1 เท่า โดยใช้ส่วนผสมเดิม น้ำหนักทุกตัวคูณ $b$ variance จึงคูณ $b^2$ ได้ $q^\star(b)=0.0095789\,b^2$ อัตราเปลี่ยนที่ $b=1$ คือ $\dfrac{dq^\star}{db}=2(0.0095789)=0.019158=\lambda$ ตัวคูณจึงเป็นราคาเงาเหมือนเดิม คือ variance ที่เพิ่มขึ้นต่องบที่เพิ่ม

ตรวจเองใน 10 วินาที: สามสมการเขียนเป็น matrix ได้

\[ \begin{bmatrix}0.08&0.012&-1\\0.012&0.02&-1\\1&1&0\end{bmatrix} \begin{bmatrix}x_1\\x_2\\\lambda\end{bmatrix} =\begin{bmatrix}0\\0\\1\end{bmatrix} \]

รูปนี้ใช้ได้กับสินทรัพย์ $n$ ตัว คือ matrix ขนาด $(n+1)\times(n+1)$ มุมบนซ้ายคือ $2V$ หลักสุดท้ายเป็น $-1$ แถวสุดท้ายเป็น 1 ทุกช่อง (ยกเว้นช่องมุมที่เป็น 0) และฝั่งขวาคือ $(0, \dots, 0, 1)$ ถ้าเพิ่มข้อบังคับผลตอบแทนเป้าหมาย ก็แค่เพิ่มอีกหนึ่งแถว หนึ่งหลัก และตัวคูณอีกหนึ่งตัว และเพราะ variance เป็น convex ส่วนข้อบังคับเป็นเส้นตรง คำตอบของระบบนี้คือคำตอบที่ดีที่สุดจริง ไม่ใช่แค่ผู้สมัคร

ขั้นที่ 8 — mean-variance ที่ลงเงินครบ: ตัวคูณบอกว่าควรกู้มาลงทุนเพิ่มไหม

พอร์ตความเสี่ยงต่ำสุดสนใจแค่การแกว่ง แต่กองทุนส่วนใหญ่อยากได้ผลตอบแทนด้วย วิธีที่นิยมคือ mean-variance: ให้คะแนนพอร์ตด้วย “ผลตอบแทนคาดหวัง ลบค่าปรับความเสี่ยง” แล้วหาพอร์ตที่ได้คะแนนสูงสุด ในขั้นนี้ยังต้องลงเงินครบ 100% และยังไม่มีเงินสดให้ถือหรือกู้

โจทย์ให้อะไรมาบ้าง:

  • ผลตอบแทนคาดหวังต่อปีของหุ้น 12% และของพันธบัตร 6% เขียนเป็น vector $\mu=(0.12,\ 0.06)$
  • covariance matrix $V$ ชุดเดิมจากตัวอย่างที่แล้ว
  • คะแนนของพอร์ตคือ $\mu^{\mathsf T}x-\gamma\,x^{\mathsf T}Vx$ โดย $\gamma=2$ (สมมติ) คือระดับความกลัวความเสี่ยง (risk aversion) ยิ่ง $\gamma$ สูง กองทุนยิ่งยอมเสียผลตอบแทนเพื่อลดการแกว่ง
  • ข้อบังคับ $\mathbf1^{\mathsf T}x=x_1+x_2=1$ และตัวคูณของข้อบังคับนี้เขียนว่า $v$

สูตรคำตอบต้องใช้ inverse ของ $V$ จึงคำนวณตัวเลขที่ต้องใช้ไว้ก่อน inverse ของ matrix 2×2 ทำตามหน้า rank และ invertibility: สลับสองช่องทแยง เปลี่ยนเครื่องหมายช่องนอกทแยง แล้วหารด้วย determinant

\[ \begin{aligned} \det V&=0.04(0.01)-0.006^2=0.000364,\\ V^{-1}&=\tfrac{1}{0.000364}\begin{bmatrix}0.01&-0.006\\-0.006&0.04\end{bmatrix},\\ 0.01(0.12)-0.006(0.06)&=0.00084,\\ -0.006(0.12)+0.04(0.06)&=0.00168,\\ V^{-1}\mu&=\tfrac{1}{0.000364}(0.00084,\ 0.00168)\\ &\approx(2.3077,\ 4.6154),\\ \mathbf1^{\mathsf T}V^{-1}\mathbf1&=\frac{0.01-0.006-0.006+0.04}{0.000364}\\ &=\frac{0.038}{0.000364}\approx104.3956. \end{aligned} \]

จากนั้นใช้เคล็ดเดียวกับโจทย์แบ่งทุน ตั้ง derivative ของ Lagrangian เป็นศูนย์ เขียน $x$ เป็น function ของ $v$ แล้วแทนลงในข้อบังคับ $\mathbf1^{\mathsf T}x=1$ เพื่อหา $v$

\[ \begin{aligned} \mathcal L&=\mu^{\mathsf T}x-\gamma\,x^{\mathsf T}Vx-v\,(\mathbf1^{\mathsf T}x-1),\\ \mu-2\gamma Vx-v\mathbf1&=0,\\ x&=\tfrac{1}{2\gamma}V^{-1}(\mu-v\mathbf1),\\ \mathbf1^{\mathsf T}x&=\tfrac{1}{2\gamma}\big(\mathbf1^{\mathsf T}V^{-1}\mu\\ &\qquad-v\,\mathbf1^{\mathsf T}V^{-1}\mathbf1\big)=1,\\ v&=\frac{\mathbf1^{\mathsf T}V^{-1}\mu-2\gamma}{\mathbf1^{\mathsf T}V^{-1}\mathbf1},\\ \mathbf1^{\mathsf T}V^{-1}\mu&=2.3077+4.6154=6.9231,\\ v&=\frac{6.9231-4}{104.3956}=0.028,\\ \mu-v\mathbf1&=(0.092,\ 0.032),\\ x&=\tfrac14V^{-1}(0.092,\ 0.032)=(0.5,\ 0.5). \end{aligned} \]

เลข 4 ในการหา $v$ คือ $2\gamma=2\times2$ และ $\tfrac14$ ในแถวสุดท้ายคือ $\tfrac{1}{2\gamma}$

คำตอบ: พอร์ต 50/50 และตัวคูณของงบ $v=0.028$

อ่าน $v$ ด้วยความหมายราคาเงา ถ้ากองทุนลงเงินเกิน 100% ของทุนได้ คะแนน mean-variance จะเพิ่มประมาณ 0.028 หรือ 2.8% ต่อเงินที่เพิ่มหนึ่งเท่าของทุน (สำหรับก้อนแรก ๆ) การลงเงินเกิน 100% ทำได้ด้วยการกู้เงินสดมาลงทุนเพิ่ม ถ้ากู้ได้ที่ดอกเบี้ย 2% ต่อปี เงินกู้ก้อนแรกจึงได้สุทธิ $0.028-0.02=0.008$ คือ 0.8% ต่อหน่วย การกู้จึงคุ้ม นี่อธิบายว่าทำไมหน้า Hessian และเงื่อนไขอันดับสอง ซึ่งให้กู้เงินสดได้ที่ 2% ได้คำตอบที่กู้เงิน 20.88% ของทุน (โจทย์ข้อ 3 ท้ายหน้าหาตัวเลขนี้จากตัวคูณ)

ตรวจเองใน 10 วินาที: คูณ $V^{-1}$ เข้ากับ $\mu-v\mathbf1=(0.092,\ 0.032)$ ทีละแถว

\[ \begin{aligned} 0.01(0.092)-0.006(0.032)&=0.000728,\\ -0.006(0.092)+0.04(0.032)&=0.000728,\\ V^{-1}(\mu-v\mathbf1)&=\tfrac{1}{0.000364}(0.000728,\ 0.000728)\\ &=(2,\ 2),\\ x&=\tfrac14(2,\ 2)=(0.5,\ 0.5). \end{aligned} \]

น้ำหนักรวม $0.5+0.5=1$ ลงเงินครบพอดี

ขั้นที่ 9 — ทำให้มันพัง: งบ \$0.5 ล้าน ให้ทุนติดลบ

วิธีที่ดีควรรู้ว่าตัวเองพังตรงไหน กลับไปที่โจทย์แบ่งทุน สูตร $\nu=6/(b+2)$ ดูเหมือนใช้ได้กับทุกงบ ลองงบเล็ก ๆ คือ $b=0.5$ ล้าน หรือ \$500,000 แทนลงสูตรเดิมทีละตัว แล้วเทียบกับทางเลือกที่ทำได้จริง คือให้เงินทั้งหมดกับเดสก์ 2

\[ \begin{aligned} \nu&=\frac{6}{2.5}=2.4,\\ x_1&=\frac{2}{2.4}-1\approx-0.1667,\\ x_2&=\frac{4}{2.4}-1\approx0.6667,\\ F(x)&=2\ln\tfrac56+4\ln\tfrac53\approx1.678659,\\ F(0,\ 0.5)&=4\ln1.5\approx1.621860,\\ \frac{2}{1+0}&=2\lt\frac{4}{1.5}\approx2.667. \end{aligned} \]

Lagrange สั่งให้เดสก์ 1 ได้ทุน $-0.1667$ ล้าน คือต้องคืนเงิน \$166,667 ที่มันไม่มี คำตอบนั้นให้กำไร 1.678659 ซึ่งสูงกว่า แต่ทำไม่ได้จริง สาเหตุคือวิธีนี้รู้จักแค่ข้อบังคับแบบสมการ มันไม่รู้ว่าทุนห้ามติดลบ เพราะเราไม่ได้บอกมัน

คำตอบจริงคือให้เดสก์ 2 ทั้ง \$0.5 ล้าน ได้กำไร 1.621860 ที่จุดนั้นกำไรส่วนเพิ่มไม่เท่ากัน เงินก้อนถัดไปของเดสก์ 1 ทำได้ 2 แต่ของเดสก์ 2 ทำได้ 2.667 เราอยากย้ายเงินออกจากเดสก์ 1 ต่อ แต่เดสก์ 1 ไม่มีเงินเหลือให้ย้ายแล้ว

จุดเปลี่ยนอยู่ที่งบเท่าไร? สูตรทุนของเดสก์ 1 คือ $x_1=\dfrac{2}{\nu}-1=\dfrac{b+2}{3}-1=\dfrac{b-1}{3}$ ซึ่งเป็นศูนย์เมื่อ $b=1$ ถ้างบต่ำกว่า \$1 ล้าน กฎ “กำไรส่วนเพิ่มเท่ากัน” ใช้ไม่ได้ ต้องเพิ่มเงื่อนไขเรื่องเครื่องหมาย ซึ่งคือ KKT conditions

กับดัก: เอาราคาเงาไปคูณก้อนใหญ่ อ่านหน่วยผิด และลืมข้อบังคับที่ไม่ได้เขียน

กับดักที่ 1: คูณราคาเงาเข้ากับเงินก้อนใหญ่ $\nu$ เป็นความชันที่จุดเดียว สมมติเดสก์ขอเพิ่มทีเดียว \$5 ล้าน แล้วเขียนในเอกสารว่ากำไรจะเพิ่ม $5\nu$

\[ \begin{aligned} 5\nu&=5\times\tfrac37=2.142857,\\ F^\star(17)-F^\star(12)&=6\ln\tfrac{19}{14}=1.832290,\\ \frac{2.142857-1.832290}{1.832290}&=16.9\%. \end{aligned} \]

ตัวเลขในเอกสารคือ \$2.1429 ล้าน แต่ของจริงคือ \$1.8323 ล้าน สูงเกินไป 16.9% เงินห้าล้านนี้ทำกำไรเฉลี่ยแค่ $1.832290/5=0.366458$ คือ \$366,458 ต่อล้าน การคูณราคาเงาเข้ากับก้อนใหญ่คือวิธีสร้างตัวเลขเกินจริงที่พบบ่อยที่สุดในเอกสารขอวงเงิน

กับดักที่ 2: อ่านหน่วยผิด $\nu=0.4286$ มีหน่วยเป็นล้านดอลลาร์ต่อปี ต่อทุน 1 ล้าน ทุนเพิ่ม \$1 ล้าน จึงได้กำไรเพิ่มประมาณ $\tfrac37\times\$1{,}000{,}000=\$428{,}571$ ต่อปี ถ้าอ่านว่า “ได้เพิ่ม \$0.43” จะต่ำไปล้านเท่า อีกจุดที่ติดบ่อยเป็นเรื่องพีชคณิต คือได้ $x_1=2/\nu-1$ แล้วหยุด เพราะยังมี $\nu$ ที่ไม่รู้ค่า ทางออกคือสมการจาก derivative เทียบ $\nu$ ซึ่งคือข้อบังคับงบที่กลับมา

กับดักที่ 3: ลืมข้อบังคับที่ไม่ได้เขียน ต้องตรวจเสมอว่าคำตอบไม่ละเมิดข้อบังคับที่ไม่ได้ใส่ เช่นทุนติดลบที่งบ \$0.5 ล้าน ในโจทย์พอร์ต ข้อบังคับที่มักลืมคือห้าม short (short คือขายของที่ยืมมา ทำให้น้ำหนักติดลบ) ลองเปลี่ยน correlation ของหุ้นกับพันธบัตรเป็น 0.8 ช่องนอกทแยงของ $V$ จะเป็น $0.8\times0.2\times0.1=0.016$ แล้วตั้ง marginal variance สองตัวให้เท่ากันเหมือนเดิม

\[ \begin{aligned} 0.08x_1+0.032x_2&=0.032x_1+0.02x_2,\\ 0.048x_1&=-0.012x_2,\\ x_2&=-4x_1,\\ x_1+x_2=-3x_1&=1,\quad x_1=-\tfrac13. \end{aligned} \]

พอร์ตความเสี่ยงต่ำสุดจาก Lagrange คือ short หุ้น 1/3 ของทุน แล้วถือพันธบัตร 4/3 ของทุน กองทุนที่ห้าม short ทำแบบนี้ไม่ได้

ใช้ทำอะไรบนโต๊ะจริง

บริษัทจริงแบ่งทุนความเสี่ยงด้วยโครงเดียวกันนี้ ผลลัพธ์ที่มีค่าที่สุดไม่ใช่ตัวเลขทุนของแต่ละเดสก์ แต่คืออัตรา $\nu$ ในโจทย์นี้ $\nu=42.86\%$ ต่อปี อัตรานี้ใช้ได้สองแบบ

  • เป็นเกณฑ์ที่ทุกเดสก์ต้องทำได้เกิน เดสก์ไหนกำไรส่วนเพิ่มต่ำกว่า 42.86% ต่อปี ควรถูกดึงเงินไปให้เดสก์ที่ยังทำได้สูงกว่า
  • เป็นเพดานดอกเบี้ยที่ยอมจ่ายเพื่อได้ทุนเพิ่ม ถ้าเงินก้อนถัดไปมีต้นทุนต่ำกว่า $\nu$ ก็คุ้มที่จะหามาเพิ่ม

ตัวเลข 3.667 : 8.333 มาจากแบบจำลองสมมติ ควรอ่านเป็นทิศทาง ไม่ใช่คำสั่งโอนเงิน เพราะในงานจริง capacity ของกลยุทธ์ (เงินมากที่สุดที่กลยุทธ์รับได้ก่อนกำไรเริ่มหาย) ประมาณได้แค่หยาบ ๆ (strategy capacity)

ในโจทย์พอร์ต ตัวคูณของงบน้ำหนักบอกว่าการลงเงินเพิ่มเปลี่ยนเป้าหมายเท่าไร ถ้าเพิ่มข้อบังคับอื่น เช่นต้องได้ผลตอบแทนตามเป้าในหน้า Markowitz portfolio selection ตัวคูณของข้อบังคับนั้นบอกว่าการขอผลตอบแทนเพิ่ม 1 จุด ต้องแลกด้วยความเสี่ยงเพิ่มเท่าไร ตัวคูณทุกตัวคือแนวคิดเดียวกับตัวแปร dual ในหน้า LP duality: ราคาของการผ่อนข้อบังคับหนึ่งหน่วย

1. บริษัทเปิดเดสก์ที่ 3 แบบจำลองสมมติบอกว่าถ้าเดสก์นี้ได้ทุน $x_3$ ล้าน จะทำกำไร $3\ln(1+x_3)$ ล้านดอลลาร์ต่อปี ฝีมือจึงอยู่ระหว่างเดสก์ 1 (เลข 2) กับเดสก์ 2 (เลข 4) งบรวมยังเป็น \$12 ล้าน ควรแบ่งให้สามเดสก์อย่างไร และราคาเงาเปลี่ยนไปเท่าไร?

เขียนฝีมือของเดสก์ $i$ ว่า $s_i$ คือ $s_1=2$, $s_2=4$, $s_3=3$ เงื่อนไขเดิมยังใช้ได้ คือกำไรส่วนเพิ่มของทุกเดสก์เท่ากับ $\nu$ เขียนทุนเป็น function ของ $\nu$ แล้วแทนลงในงบ

\[ \begin{aligned} \frac{s_i}{1+x_i}&=\nu,\quad x_i=\frac{s_i}{\nu}-1,\\ x_1+x_2+x_3&=\frac{2+4+3}{\nu}-3=12,\\ \nu&=\frac{9}{15}=0.6,\\ x_1&=\frac{2}{0.6}-1\approx2.333,\\ x_2&=\frac{4}{0.6}-1\approx5.667,\\ x_3&=\frac{3}{0.6}-1=4. \end{aligned} \]

ทุนรวม $2.333+5.667+4=12$ ใช้ครบ ตัวเลขใน $\ln$ คือ $1+x_i=s_i/\nu$ ได้ $10/3$, $20/3$ และ $5$ กำไรรวมคือ $2\ln\tfrac{10}{3}+4\ln\tfrac{20}{3}+3\ln5\approx14.8247$ ล้านต่อปี ราคาเงาขึ้นจาก 0.4286 เป็น 0.6 เพราะมีที่ลงเงินดี ๆ มากขึ้น เงินแต่ละล้านจึงมีค่ามากขึ้น

2. กลับไปที่สองเดสก์เดิม ตอนนี้งบ \$12 ล้าน สมมติว่าบริษัทกู้ทุนเพิ่มได้ไม่จำกัด แต่ต้องจ่ายดอกเบี้ย 30% ต่อปีของเงินที่กู้ ควรกู้เท่าไร และกำไรหลังหักดอกเบี้ยเพิ่มขึ้นเท่าไร?

เฉลย

กู้ต่อไปตราบที่เงินล้านถัดไปทำกำไรได้มากกว่าดอกเบี้ย คือจนราคาเงาลดลงมาเท่าดอกเบี้ยพอดี ราคาเงาที่งบ $b$ คือ $\nu=6/(b+2)$ จากสูตรที่แก้ไว้ด้วยตัวอักษร ส่วนกำไรที่ดีที่สุดใช้สูตร $F^\star(b)$ ที่หาไว้ตอนทดสอบงบ \$13 ล้าน

\[ \begin{aligned} \frac{6}{b+2}&=0.30,\quad b=\frac{6}{0.30}-2=18,\\ F^\star(18)-F^\star(12)&=6\ln\tfrac{20}{14}\approx2.140050,\\ 0.30\times(18-12)&=1.8,\\ 2.140050-1.8&=0.340050. \end{aligned} \]

งบใหม่คือ \$18 ล้าน คือกู้ \$6 ล้าน กำไรเพิ่ม 2.140050 ล้าน หักดอกเบี้ย 1.8 ล้าน เหลือกำไรสุทธิเพิ่ม \$340,050 ต่อปี ถ้ากู้เกิน \$6 ล้าน เงินล้านถัดไปทำกำไรต่ำกว่า 30% จึงไม่คุ้มดอกเบี้ย

3. กลับไปที่พอร์ต mean-variance สมมติว่ากองทุนกู้เงินสดได้ที่ดอกเบี้ย 2% ต่อปี แล้วเอาเงินกู้ไปลงในหุ้นกับพันธบัตรเพิ่ม ให้เงินที่ลงในหุ้นกับพันธบัตรรวมเป็น $b$ เท่าของทุน แทนที่จะเป็น 1 เท่า ตัวคูณของงบจะเป็น $v(b)=\dfrac{6.9231-4b}{104.3956}$ ควรลงทุนรวมกี่เปอร์เซ็นต์ของทุน?

เฉลย

สูตร $v(b)$ มาจากการเปลี่ยนข้อบังคับเป็น $\mathbf1^{\mathsf T}x=b$ แทน 1 ทำให้ $2\gamma$ ในตัวเศษกลายเป็น $2\gamma b=4b$ กู้ต่อไปจนราคาเงาของงบลดลงมาเท่าดอกเบี้ย

\[ \begin{aligned} \frac{6.9231-4b}{104.3956}&=0.02,\\ 4b&=6.9231-0.02(104.3956)\\ &=6.9231-2.0879=4.8352,\\ b&=4.8352/4\approx1.2088. \end{aligned} \]

ลงในหุ้นกับพันธบัตรรวม 120.88% ของทุน โดยกู้ $120.88\%-100\%=20.88\%$ ตรงทุกหลักกับคำตอบที่ได้จากการตั้ง gradient เป็นศูนย์ในหน้า Hessian และเงื่อนไขอันดับสอง สองวิธีคือโจทย์เดียวกันที่มองคนละมุม

เปิดดูโค้ด 
// Desks with expected profit s_i ln(1 + x_i), x_i in USD million.
const profit = (skills, x) => skills.reduce((s, k, i) => s + k * Math.log(1 + x[i]), 0);
// Lagrange: s_i / (1 + x_i) = nu for every desk and sum x_i = b.
function allocate(skills, b) {
  const total = skills.reduce((s, k) => s + k, 0), nu = total / (b + skills.length);
  const x = skills.map(k => k / nu - 1);
  return {nu, x, feasible: x.every(v => v >= 0), value: profit(skills, x)};
}
// Two assets: solve [2V, -1; 1', 0] [x; lambda] = [0; 0; 1] by elimination.
function minVariance(V) {
  const a = 2 * V[0][0] - 2 * V[1][0], c = 2 * V[0][1] - 2 * V[1][1]; // row1 - row2: a x1 + c x2 = 0
  const x1 = -c / (a - c), x = [x1, 1 - x1];
  return {x, lambda: 2 * (V[0][0] * x[0] + V[0][1] * x[1])};
}
// Mean-variance with budget b: x = V^-1 (mu - v 1) / (2 gamma).
function meanVarianceBudget(mu, V, gamma, b) {
  const det = V[0][0] * V[1][1] - V[0][1] ** 2;
  const Vi = [[V[1][1] / det, -V[0][1] / det], [-V[0][1] / det, V[0][0] / det]];
  const Vimu = [Vi[0][0] * mu[0] + Vi[0][1] * mu[1], Vi[1][0] * mu[0] + Vi[1][1] * mu[1]];
  const s1 = Vi[0][0] + 2 * Vi[0][1] + Vi[1][1], v = (Vimu[0] + Vimu[1] - 2 * gamma * b) / s1;
  const x = [0, 1].map(i => (Vimu[i] - v * (Vi[i][0] + Vi[i][1])) / (2 * gamma));
  return {v, x, borrowAt2pct: (Vimu[0] + Vimu[1] - 0.02 * s1) / (2 * gamma)};
}
const skills = [2, 4], best = allocate(skills, 12);
const Fstar = b => allocate(skills, b).value;
const V = [[0.04, 0.006], [0.006, 0.01]];
console.log({

  table: [12.01, 12.1, 12.5, 13, 14].map(b => [b, (Fstar(b) - best.value) / (b - 12)]),
  plusFive: {actual: Fstar(17) - best.value, byNu: 5 * best.nu},
  hessianAlongBudget: -skills[0] / (1 + best.x[0]) ** 2 - skills[1] / (1 + best.x[1]) ** 2,
  minVariance: minVariance(V), meanVariance: meanVarianceBudget([0.12, 0.06], V, 2, 1),
  tooSmall: allocate(skills, 0.5), cornerValue: profit(skills, [0, 0.5]),

สิ่งที่ควรตอบได้หลังอ่าน

  • ที่จุดดีที่สุดบนข้อบังคับ เส้นระดับของเป้าหมายแตะเส้นข้อบังคับพอดี จึงได้ $\nabla f=\nu\nabla g$ ในภาษาของโต๊ะเทรด แปลว่ากำไรส่วนเพิ่ม (หรือ marginal variance ในโจทย์พอร์ต) ต้องเท่ากันทุกที่ที่ลงเงิน
  • Lagrangian $\mathcal L=F-\nu(g-b)$ ให้ทุกเงื่อนไขในคราวเดียว รวมถึงข้อบังคับเดิมที่ได้จาก derivative เทียบ $\nu$ งบ \$12 ล้าน แบ่ง 3.667 : 8.333 ได้กำไร \$12.0153 ล้านต่อปี
  • $\nu=dF^\star/db=3/7$ คือราคาเงา หรือ 42.86% ต่อปี แต่เป็นความชันที่จุดเดียว งบเพิ่ม \$1 ล้าน ได้จริง \$413,957 ไม่ใช่ \$428,571 และงบเพิ่ม \$5 ล้าน ทำนายเกิน 16.9%
  • พอร์ตความเสี่ยงต่ำสุดคือระบบสมการเชิงเส้นชุดเดียว ได้หุ้น 2/19 และ $\lambda=0.019158$ ส่วน mean-variance ที่ลงเงินครบได้ 50/50 กับราคาเงาของงบ 2.8% ซึ่งสูงกว่าดอกเบี้ยเงินกู้ 2% จึงคุ้มที่จะกู้มาลงทุนเพิ่ม
  • วิธีนี้รู้จักแค่ข้อบังคับแบบสมการ จึงพังเมื่อข้อบังคับแบบอสมการเริ่มมีผล เช่นงบ \$0.5 ล้าน ทำให้ทุนของเดสก์ 1 ติดลบ
