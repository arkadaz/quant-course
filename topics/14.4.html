14.4 Put–Call Parity and the Volatility Smile

ราคา call ลบราคา put ที่ strike เดียวกันถูกล็อกไว้ด้วยเหตุผลง่าย ๆ โดยไม่ต้องใช้แบบจำลอง แต่ความผันผวนที่ทำให้สูตร Black–Scholes ตรงกับราคาตลาดกลับไม่เท่ากันในแต่ละ strike

เทรดเดอร์คนหนึ่งกำลังดูราคา option บนจอ option คือสัญญาที่ให้ “สิทธิ์” ซื้อหรือขายของชิ้นหนึ่ง ในราคาที่ตกลงไว้ล่วงหน้า ณ วันที่กำหนด ราคาที่ตกลงไว้เรียกว่า strike และวันที่กำหนดเรียกว่าวันหมดอายุ ของในที่นี้คือ SPX ซึ่งเป็นดัชนี S&P 500 ของหุ้นใหญ่ 500 ตัวในสหรัฐฯ วัดเป็น “จุด” option มีสองชนิด

  • call คือสิทธิ์ซื้อดัชนีที่ราคา strike ถ้าวันหมดอายุดัชนีจบสูงกว่า strike ผู้ถือได้ส่วนต่างเป็นเงิน ถ้าจบต่ำกว่า ผู้ถือไม่ได้อะไร
  • put คือสิทธิ์ขายดัชนีที่ราคา strike ถ้าดัชนีจบต่ำกว่า strike ผู้ถือได้ส่วนต่าง ถ้าจบสูงกว่า ผู้ถือไม่ได้อะไร put จึงทำหน้าที่เหมือนประกันขาลง

option บนจอเป็นแบบยุโรป แปลว่าใช้สิทธิ์ได้เฉพาะวันหมดอายุเท่านั้น ของที่รู้มีดังนี้ (ตัวเลขสมมติ แต่ใกล้ของจริง)

  • ดัชนีวันนี้ $S_0=5{,}000$ จุด
  • strike ของทั้ง call และ put คือ $K=5{,}000$ จุด เท่ากับดัชนีวันนี้พอดี
  • อายุสัญญา $T=0.5$ ปี (6 เดือน)
  • ราคา call $C=300$ จุด และราคา put $P=235$ จุด ทั้งคู่เป็นราคากลาง คือค่ากลางระหว่างราคาที่มีคนเสนอซื้อ กับราคาที่มีคนเสนอขาย
  • ดอกเบี้ย $r=4\%$ ต่อปี
  • หุ้นในดัชนีจ่ายปันผล คิดเป็น $q=1.5\%$ ของดัชนีต่อปี
  • option หนึ่งใบมีค่า $m=\$100$ ต่อจุด (ตัวคูณนี้เป็นของจริงของ SPX)

เพื่อนร่วมโต๊ะบอกว่า “strike เท่ากับดัชนีวันนี้ call กับ put ก็ต้องราคาเท่ากัน” แต่บนจอ call แพงกว่า put อยู่ $C-P=300-235=65$ จุด คิดเป็นเงิน $m(C-P)=100\times65=\$6{,}500$ ต่อคู่ (call หนึ่งใบกับ put หนึ่งใบ) เพื่อนจึงสรุปว่าส่วนต่างนี้คือเงินฟรี ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก หน้านี้จะพิสูจน์ว่า call ลบ put ต้องเท่ากับมูลค่าวันนี้ของ “ได้ดัชนีหนึ่งหน่วย และจ่าย strike” ในวันหมดอายุ ซึ่งไม่ใช่ศูนย์ ใช้ $qT=0.015\times0.5=0.0075$ และ $rT=0.04\times0.5=0.02$ ได้

\[ \begin{aligned} C-P&=S_0e^{-qT}-Ke^{-rT}\\ &=5{,}000e^{-0.0075}-5{,}000e^{-0.02}\\ &=4{,}962.64-4{,}900.99\\ &=61.65. \end{aligned} \]

ส่วนที่เกินจริงจึงมีแค่ $65-61.65=3.35$ จุด หรือ $100\times3.35=\$335$ ต่อคู่ และยังไม่ได้หักต้นทุนการซื้อขายของสี่รายการที่ต้องทำพร้อมกัน ยิ่งกว่านั้น ถ้าดอกเบี้ยที่ตลาดใช้จริงสูงกว่า 4% แค่ 0.137% ต่อปี (เรียกว่า 13.7 bp โดย 1 bp คือ 0.01%) ส่วนเกินนี้ก็หายหมด หน้านี้จะคำนวณตัวเลขเหล่านี้ให้ดูทีละขั้น ข้อสรุปคือ เกือบแน่นอนว่าไม่ใช่เงินฟรี

ภาพรวมก่อนลงสูตร

หน้านี้มีสองครึ่งที่ต่อกัน

ครึ่งแรกคือ put–call parity ความคิดหลักอยู่ในรูปด้านล่าง เราเทียบพอร์ตสองชุด (พอร์ตคือของหลายอย่างที่ถือรวมกัน)

  • พอร์ตแรก: call หนึ่งใบ กับเงินฝากที่จะโตเป็น 5,000 พอดีในวันหมดอายุ
  • พอร์ตสอง: put หนึ่งใบ กับดัชนีหนึ่งหน่วย

ในวันหมดอายุ สองพอร์ตนี้จ่ายเงินเท่ากันทุกกรณี ไม่ว่าดัชนีจะจบที่ไหน ราคาวันนี้จึงต้องเท่ากัน ถ้าไม่เท่า คนจะซื้อพอร์ตที่ถูก ขายพอร์ตที่แพง แล้วเก็บส่วนต่างได้โดยไม่เสี่ยงเลย (เรียกว่า arbitrage) เหตุผลนี้ไม่ได้ใช้แบบจำลองราคาหรือความผันผวนเลย เราจะใช้มันตรวจราคาบนจอ สร้างรายการซื้อขายที่ล็อกส่วนต่างไว้ แล้วดูว่าต้นทุนจริงกินส่วนต่างหมดอย่างไร

ครึ่งหลังคือ volatility smile สูตร Black–Scholes รับความผันผวนเข้าไป แล้วให้ราคา option ออกมา ครึ่งหลังเดินย้อนสูตร: ใส่ราคาตลาดเข้าไป แล้วแก้หาความผันผวนที่ทำให้สูตรได้ราคานั้นพอดี ค่าที่ได้เรียกว่า implied volatility parity บังคับให้ call กับ put ที่ strike เดียวกันได้ implied volatility ค่าเดียวกัน แต่ไม่บังคับอะไรข้าม strike เมื่อวาด implied volatility ของทุก strike จะได้เส้นโค้ง เรียกว่า smile สุดท้ายเราจะดูว่าทำไมเส้นนี้ของดัชนีหุ้นจึงเอียงขึ้นทางซ้าย และอ่านโอกาสที่ตลาดคิดไว้ออกจากราคาชุดนั้นโดยตรง

ศัพท์ที่ใช้ในหัวข้อนี้
Call และ put
call คือสิทธิ์ซื้อ put คือสิทธิ์ขาย ของชิ้นหนึ่ง (ในหน้านี้คือดัชนี) ที่ราคา strike ในวันหมดอายุ ผู้ถือ call ได้ $(S_T-K)^+=\max(S_T-K,0)$ ผู้ถือ put ได้ $(K-S_T)^+=\max(K-S_T,0)$ คนที่ขาย option ได้เงินค่า option วันนี้ และต้องจ่ายจำนวนนี้ในวันหมดอายุ
Strike และวันหมดอายุ
strike $K$ คือราคาที่ตกลงไว้ล่วงหน้าในสัญญา วันหมดอายุคือวันที่สัญญาจบและจ่ายเงิน อายุที่เหลือเขียนเป็น $T$ ปี
Option ยุโรป และ option อเมริกัน
option ยุโรปใช้สิทธิ์ได้เฉพาะวันหมดอายุ option อเมริกันใช้สิทธิ์ได้ทุกวันจนถึงวันหมดอายุ option บน SPX เป็นแบบยุโรป ส่วน option ของหุ้นรายตัวในสหรัฐฯ ส่วนใหญ่เป็นแบบอเมริกัน
Bid, ask และราคากลาง
bid คือราคาที่มีคนพร้อมซื้อจากเรา ask คือราคาที่มีคนพร้อมขายให้เรา ask สูงกว่า bid เสมอ ราคากลางคือค่าเฉลี่ยของทั้งสอง ใช้ดูราคาได้ แต่ซื้อขายจริงที่ราคานั้นไม่ได้
Dividend yield
ปันผลที่หุ้นในดัชนีจ่าย คิดเป็นสัดส่วนของดัชนีต่อปี เขียนเป็น $q$ ดัชนีมีหุ้นหลายร้อยตัวที่จ่ายปันผลกระจายทั้งปี จึงสมมติได้ว่าปันผลไหลออกมาต่อเนื่อง ผู้ถือดัชนีได้ปันผลนี้ แต่ผู้ถือ option ไม่ได้
Forward และ prepaid forward
forward คือสัญญาที่ตกลงราคา $F$ วันนี้ เพื่อซื้อดัชนีในวันหมดอายุ โดยจ่ายเงินวันนั้น prepaid forward คือจ่ายเงินวันนี้เลย เพื่อรับดัชนีหนึ่งหน่วยในวันหมดอายุ ราคาของมันคือ $S_0e^{-qT}$ ซึ่งถูกกว่าดัชนีวันนี้ เพราะซื้อน้อยกว่าหนึ่งหน่วย แล้วเอาปันผลซื้อเพิ่มจนครบหนึ่งหน่วยพอดี
Put–call parity
สมการที่ผูกราคา call, put, ดัชนี และเงินฝาก ที่ strike และวันหมดอายุเดียวกัน มันจริงเพราะสองฝั่งจ่ายเงินเท่ากันทุกกรณีในวันหมดอายุ จึงใช้ตรวจราคาได้โดยไม่ต้องเชื่อแบบจำลองใดเลย
Arbitrage
รายการซื้อขายที่ได้เงินแน่นอนโดยไม่เสี่ยงเลย เช่นซื้อของชิ้นหนึ่ง แล้วขายของอีกชิ้นที่จ่ายเงินเหมือนกันทุกกรณีแต่ราคาแพงกว่า ในตลาดที่ทำงานดี ช่องแบบนี้ถูกปิดเร็วมาก
Conversion และ reversal
conversion คือขาย call ซื้อ put ซื้อดัชนี (แบบ prepaid forward) และกู้เงิน พร้อมกันทั้งสี่ขา ใช้เมื่อ call ลบ put แพงเกินที่ parity บอก reversal คือทำทุกขากลับทิศ ใช้เมื่อ call ลบ put ถูกเกิน ทุกขาต้องทำพร้อมกัน จึงมีชื่อเรียกทั้งชุด
Basis point (bp)
หน่วยเล็กของดอกเบี้ย 1 bp เท่ากับ 0.01% หรือ 0.0001 เช่นดอกเบี้ยขึ้นจาก 4% เป็น 4.137% คือขึ้น 13.7 bp
Implied volatility
ค่าความผันผวนที่ใส่ในสูตร Black–Scholes แล้วได้ราคาตลาดพอดี มันแปลงราคาของทุก strike และทุกอายุให้อยู่บนสเกลเดียวกัน จึงเทียบกันได้ มันคือราคาที่เขียนในหน่วยความผันผวน ไม่ใช่การพยากรณ์ว่าดัชนีจะแกว่งเท่าไร
Vega
ราคา option เปลี่ยนเท่าไรเมื่อความผันผวนเพิ่มขึ้นนิดหนึ่ง เขียนเป็น $\nu$ ราคา call และ put ขึ้นตามความผันผวนเสมอ vega จึงเป็นบวกเสมอ
Smile และ skew
รูปของ implied volatility เมื่อวาดเทียบ strike ที่วันหมดอายุเดียวกัน ถ้า Black–Scholes ถูกทุกข้อ เส้นนี้ต้องแบนและไม่ขยับไปตามวัน smile หมายถึงปลายสองข้างสูงกว่าตรงกลาง skew หมายถึงเส้นเอียง ดัชนีหุ้นเอียงชัด: put ที่ strike ต่ำมี implied volatility สูงกว่า จึงแพงกว่า
Leverage effect
หุ้นของบริษัทที่มีหนี้จะแกว่งแรงขึ้นเมื่อราคาหุ้นตก เพราะหนี้ก้อนเดิมกลายเป็นสัดส่วนที่ใหญ่ขึ้นของบริษัท ผู้ถือหุ้นจึงรับแรงขยับของทั้งบริษัทไว้มากขึ้น
Put spread, butterfly และ digital
put spread คือซื้อ put strike หนึ่ง และขาย put อีก strike หนึ่ง ราคาของมันบอกโอกาสที่ดัชนีจบต่ำกว่าช่วงนั้น butterfly คือ call สาม strike ที่ห่างเท่ากัน ซื้อตัวนอกอย่างละใบ ขายตัวกลางสองใบ ราคาของมันบอก density (ความหนาแน่นของโอกาส) ที่ strike กลาง digital คือสัญญาที่จ่ายเงินก้อนคงที่ เช่น \$1 ถ้าดัชนีจบเหนือ strike ทั้งสามแบบใช้อ่านสิ่งที่ตลาดคิดไว้ โดยไม่ต้องใช้แบบจำลอง

ขั้นที่ 1 — ลองด้วยมือ: call ลบ put จ่ายเท่าไรในวันหมดอายุ

ก่อนจะคุยเรื่องราคาวันนี้ ดูก่อนว่าถ้าถือ call และขาย put คู่กัน วันหมดอายุจะได้เงินเท่าไร เพราะ “call ลบ put” คือสิ่งที่เพื่อนในโจทย์เปิดเรื่องกำลังตั้งราคาอยู่

โจทย์ให้อะไรมาบ้าง: ถือ call strike $K=5{,}000$ หนึ่งใบ และขาย put strike 5,000 หนึ่งใบ อายุเดียวกัน call จ่ายเรา $(S_T-K)^+$ ส่วนการขาย put แปลว่าเราได้เงินค่า put วันนี้ แต่ต้องจ่าย $(K-S_T)^+$ ให้ผู้ซื้อในวันหมดอายุ เครื่องหมาย $x^+$ แปลว่า $\max(x,0)$ คือเอาค่า $x$ ถ้ามันเป็นบวก และเอา 0 ถ้ามันติดลบ ลองสองกรณี: ดัชนีจบที่ 5,600 (สูงกว่า strike 600 จุด) และจบที่ 4,400 (ต่ำกว่า strike 600 จุด)

\[ \begin{aligned} S_T=5{,}600:&\ \ (S_T-K)^+-(K-S_T)^+\\ &=600-0=600=S_T-K,\\ S_T=4{,}400:&\ \ (S_T-K)^+-(K-S_T)^+\\ &=0-600=-600=S_T-K. \end{aligned} \]

คำตอบ: ทั้งสองกรณีได้ $S_T-K$ พอดี และเป็นแบบนี้ทุกปลายทาง เพราะมีแค่สองกรณี ถ้าดัชนีจบเหนือ strike, call จ่ายส่วนต่าง $S_T-K$ ให้เรา ส่วน put ไม่มีค่า ถ้าดัชนีจบต่ำกว่า strike, call ไม่มีค่า ส่วน put ที่เราขายไว้ทำให้เราต้องจ่าย $K-S_T$ ซึ่งก็คือได้ $S_T-K$ ที่ติดลบ ดังนั้นถือ call และขาย put ก็คือ “ได้ดัชนี และจ่าย strike” ในวันหมดอายุ ไม่ว่าดัชนีจะจบที่ไหน

ตรวจเองใน 10 วินาที: เราไม่ได้ใช้เลยว่าดัชนีเดินแบบไหน หรือแกว่งแรงแค่ไหน ข้อสรุปนี้จึงจริงแม้ Black–Scholes จะผิด ลองจุดกลางอีกจุด: ที่ $S_T=5{,}000$ ทั้งสองใบไม่มีค่า และ $S_T-K=5{,}000-5{,}000=0$ ก็ตรงกัน

ขั้นที่ 2 — จาก payoff ที่เท่ากัน สู่ราคาวันนี้ที่เท่ากัน

ขั้นที่แล้วได้ว่า call ลบ put จ่าย $S_T-K$ ในวันหมดอายุ ถ้าเราสร้าง $S_T-K$ ด้วยของอย่างอื่นที่ซื้อขายได้ ราคาวันนี้ของของชุดนั้นต้องเท่ากับ $C-P$ เพราะถ้าไม่เท่า เราจะซื้อตัวที่ถูก ขายตัวที่แพง แล้วเก็บส่วนต่างได้โดยไม่เสี่ยง งานของขั้นนี้จึงเป็นการหาราคาวันนี้ของสองชิ้น คือ “ได้ดัชนีหนึ่งหน่วย” และ “จ่าย $K$” ในวันหมดอายุ ตั้งชื่อดังนี้

  • $A$ คือเงินที่ต้องจ่ายวันนี้ เพื่อให้มีดัชนีหนึ่งหน่วยในวันหมดอายุ (prepaid forward)
  • $B$ คือเงินที่ฝากวันนี้ แล้วโตเป็น $K$ พอดีในวันหมดอายุ
  • $F$ คือราคา forward: ราคาที่ตกลงวันนี้ เพื่อซื้อดัชนีในวันหมดอายุ โดยจ่ายเงินวันนั้น

ในสมการ ลูกศร $\to$ อ่านว่า “จ่ายเป็น … ในวันหมดอายุ” และ $:=$ อ่านว่า “นิยามว่า”

\[ \begin{aligned} A&:=S_0e^{-qT}\ \to\ S_T,\\ B&:=Ke^{-rT}\ \to\ K,\\ C-P&=A-B\\ &=S_0e^{-qT}-Ke^{-rT},\\ F&:=S_0e^{(r-q)T},\\ C-P&=e^{-rT}(F-K). \end{aligned} \]

ความคิดหลักคือ “ถือ $A$ และกู้ $B$” จ่าย $S_T-K$ เหมือน call ลบ put ทุกกรณี สองอย่างนี้จึงต้องราคาเท่ากัน: $C-P=A-B$ ย้ายข้างได้ $C+B=P+A$ ซึ่งก็คือรูปสองพอร์ตด้านบน ส่วนที่ต้องคิดจริง ๆ คือราคาของ $A$ และ $B$

$B$ ง่าย: เงิน $Ke^{-rT}$ ที่ฝากด้วยดอกเบี้ยต่อเนื่อง $r$ นาน $T$ ปี โตเป็น $Ke^{-rT}\times e^{rT}=K$ พอดี $A$ ต้องคิดอีกนิด เพราะดัชนีจ่ายปันผล ถ้าซื้อดัชนีหนึ่งหน่วยวันนี้ในราคา $S_0$ เราจะได้ทั้งดัชนีหนึ่งหน่วยและปันผลระหว่างทาง ซึ่งเกินกว่าที่ต้องการ วิธีที่ถูกกว่าคือซื้อแค่ $e^{-qT}$ หน่วย แล้วเอาปันผลที่ไหลเข้ามาซื้อดัชนีเพิ่ม จำนวนหน่วยจึงโตในอัตรา $q$ ต่อปี และกลายเป็น $e^{-qT}\times e^{qT}=1$ หน่วยพอดีในวันหมดอายุ (ดู ต้นทุนการถือ) ต้นทุนวันนี้จึงเป็น $S_0e^{-qT}$

รูปสุดท้าย $C-P=e^{-rT}(F-K)$ ได้จากการเขียน $A=S_0e^{-qT}=e^{-rT}\times S_0e^{(r-q)T}=e^{-rT}F$ รูปนี้คือรูปที่โต๊ะเทรดใช้จริง มันบอกว่า call ลบ put คือระยะที่ forward อยู่เหนือ strike คิดเป็นเงินวันนี้ call กับ put จึงราคาเท่ากันเมื่อ $K=F$ ไม่ใช่เมื่อ $K=S_0$ อย่างที่เพื่อนในโจทย์เปิดเรื่องคิด

ขั้นที่ 3 — ตรวจราคาบนจอ SPX

ตอนนี้มีสูตรแล้ว ใส่ตัวเลขของจอ SPX ในโจทย์เปิดเรื่องลงไป เพื่อดูว่าราคาบนจอผิดไปจาก parity เท่าไร

โจทย์ให้อะไรมาบ้าง: ตัวเลขชุดเดิมจากโจทย์เปิดเรื่อง

  • ดัชนี $S_0=5{,}000$ จุด, strike $K=5{,}000$ จุด, อายุ $T=0.5$ ปี
  • ดอกเบี้ย $r=0.04$ และ dividend yield $q=0.015$ ต่อปี
  • ราคากลางของ call $C=300$ จุด และของ put $P=235$ จุด
  • ตัวคูณ $m=\$100$ ต่อจุด

ส่วนที่ราคาตลาดผิดไปจาก parity เรียกว่า $\varepsilon$ คือ $C-P$ บนจอ ลบด้วย $A-B$ ที่ parity บังคับ ส่วนเลขชี้กำลังของ $F$ คือ $(r-q)T=(0.04-0.015)\times0.5=0.0125$

\[ \begin{aligned} A&=S_0e^{-qT}=5{,}000e^{-0.015\times0.5}\\ &=5{,}000e^{-0.0075}=4{,}962.6403,\\ B&=Ke^{-rT}=5{,}000e^{-0.04\times0.5}\\ &=5{,}000e^{-0.02}=4{,}900.9934,\\ A-B&=61.6469,\\ F&=S_0e^{(r-q)T}=5{,}000e^{0.0125}\\ &=5{,}062.8923,\\ C-P&=300-235=65,\\ \varepsilon&=(C-P)-(A-B)\\ &=65-61.6469=3.3531,\\ m\varepsilon&=100\times3.3531=\$335.31. \end{aligned} \]

คำตอบ: บนจอ call ลบ put แพงกว่าที่ parity บังคับ 3.3531 จุด หรือ \$335.31 ต่อคู่ ไม่ใช่ 65 จุดอย่างที่เพื่อนคิด ส่วนใหญ่ของ 65 จุด คือ 61.65 จุด เป็นส่วนที่ต้องมีอยู่แล้ว เพราะดอกเบี้ย (4%) สูงกว่าปันผล (1.5%) forward จึงอยู่ที่ 5,062.89 สูงกว่า strike 5,000 และจากรูป $C-P=e^{-rT}(F-K)$ call จึงต้องแพงกว่า put

ตรวจเองใน 10 วินาที: ดอกเบี้ยลบปันผลคือ $4\%-1.5\%=2.5\%$ ต่อปี ครึ่งปีทำให้ forward สูงกว่าดัชนีราว $5{,}000\times0.025\times0.5=62.5$ จุด ใกล้กับ 61.65 ส่วนต่างเล็ก ๆ มาจากการทบต้นและการคิดลดด้วย $e^{-rT}$ ถ้าลืมปันผล จะได้ $A-B=5{,}000-4{,}900.99=99.01$ จุด แล้วสรุปว่า call ลบ put ถูกไป $99.01-65=34.01$ จุด ซึ่งผิดทิศเลย

ขั้นที่ 4 — รายการที่ล็อกส่วนต่าง และต้นทุนจริงที่กินมัน

ราคาบนจอให้ $C-P$ แพงเกินไป 3.3531 จุด ขั้นนี้ดูว่าจะเก็บส่วนต่างนี้ได้อย่างไร แล้วเก็บได้จริงเท่าไรเมื่อนับต้นทุน

โจทย์ให้อะไรมาบ้าง: หลักคือขายของที่แพง ซื้อของที่ถูก ของที่แพงคือ call ลบ put เราจึงขาย call และซื้อ put ของที่ถูกคือ $A-B$ เราจึงซื้อ prepaid forward (จ่าย $A$) และกู้เงิน $B$ ทั้งสี่ขารวมกันเรียกว่า conversion เงินสดวันนี้ของชุดนี้ และเงินที่จ่ายในวันหมดอายุ เป็นดังนี้

\[ \begin{aligned} \text{cash}_0&=C-P-A+B\\ &=300-235-4{,}962.6403+4{,}900.9934\\ &=+3.3531,\\ \text{payoff}_T&=-(S_T-K)^++(K-S_T)^+\\ &\quad+S_T-K=0. \end{aligned} \]

ตัวเลขข้างบนยังใช้ราคากลาง แต่ในการซื้อขายจริง เราขาย call ได้ที่ bid และซื้อ put ได้ที่ ask สมมติว่า call bid คือ 299 และ put ask คือ 236 คือห่างราคากลางข้างละ 1 จุด อีกเรื่องคือดอกเบี้ย 4% เป็นแค่ค่าที่เราใส่เอง ถ้าดอกเบี้ยเงินกู้แพงกว่านั้น เงินที่กู้ได้วันนี้จะน้อยลง เราจึงถามต่อว่าดอกเบี้ยต้องเป็น $r'$ เท่าไร ส่วนต่างจึงหายหมด คือเงินกู้ $B'$ ต้องทำให้ $A-B'=65$ พอดี แล้วแก้ $B'=Ke^{-r'T}$ หา $r'$

\[ \begin{aligned} (299-236)-61.6469&=1.3531,\\ B'&=A-65=4{,}962.6403-65\\ &=4{,}897.6403,\\ r'&=-\frac1T\ln\frac{B'}{K}=-2\ln\frac{4{,}897.6403}{5{,}000}\\ &=4.1369\%,\\ r'-r&=4.1369\%-4\%=0.1369\%. \end{aligned} \]

คำตอบ: conversion ได้เงินสดวันนี้ +3.3531 จุด และในวันหมดอายุจ่ายศูนย์ทุก $S_T$ เหตุผลคือ ขาย call และซื้อ put ให้ $-(S_T-K)$ (กลับทิศของขั้นที่ 1) ขา prepaid forward ให้ดัชนี $S_T$ และขาเงินกู้ต้องคืน $K$ รวมกันได้ $-(S_T-K)+S_T-K=0$ เงินที่ได้วันแรกจึงถูกล็อกไว้ โดยไม่มีความเสี่ยงเรื่องดัชนี

แต่เมื่อซื้อขายที่ bid และ ask จริง ส่วนต่างเหลือแค่ 1.3531 จุด และยังไม่รวมต้นทุนการซื้อขายขาดัชนี ที่สำคัญกว่าคือ ส่วนต่างทั้งก้อน 3.3531 จุดหายหมด ถ้าดอกเบี้ยเงินกู้แพงกว่า 4% แค่ 0.1369% หรือ 13.7 bp ถ้าเรากู้ได้ที่ 4.25% เงินที่กู้ได้วันนี้คือ $5{,}000e^{-0.0425\times0.5}=4{,}894.87$ และเงินสดวันนี้กลายเป็น $65-4{,}962.64+4{,}894.87=-2.77$ จุด คือขาดทุน โต๊ะเทรดจึงอ่านตัวเลขนี้กลับด้าน: ราคา option บอกว่าตลาดใช้ดอกเบี้ย 4.1369% ในการตั้งราคา ไม่ใช่มีเงินฟรีวางอยู่

ตรวจเองใน 10 วินาที: ดอกเบี้ยที่เพิ่มอีก 13.7 bp บนเงินกู้ราว 4,900 จุด นานครึ่งปี คิดเป็น $4{,}900\times0.00137\times0.5=3.36$ จุด ใกล้กับส่วนต่าง 3.35 จุด

ขั้นที่ 5 — สิ่งที่ parity บอกอีก: ขอบเขตของราคา และ option อเมริกัน

parity ยังบอกอะไรได้อีกสองเรื่อง โดยไม่ต้องใช้แบบจำลองเช่นเดิม เรื่องแรกคือขอบเขตราคาของ call และ put แต่ละตัว เรื่องที่สองคือ option อเมริกัน (ใช้สิทธิ์ได้ทุกวันก่อนหมดอายุ) ควรใช้สิทธิ์ก่อนกำหนดเมื่อไร

ขอบเขตมาจากข้อเท็จจริงง่าย ๆ สองข้อ ข้อแรก option มีค่าไม่ติดลบ เพราะผู้ถือเลือกไม่ใช้สิทธิ์ได้เสมอ เมื่อ $P\ge0$ parity $C=A-B+P$ จึงบังคับให้ $C\ge A-B$ ข้อสอง call จ่าย $(S_T-K)^+$ ซึ่งไม่เกิน $S_T$ ราคาของมันจึงไม่เกินราคาของ “ได้ $S_T$” ซึ่งคือ $A$ ทำนองเดียวกัน put จ่ายไม่เกิน $K$ ราคาจึงไม่เกิน $B$

\[ \begin{aligned} C&=A-B+P\ \ge\ \max(A-B,0),\\ P&=B-A+C\ \ge\ \max(B-A,0),\\ C&\le A,\qquad P\le B. \end{aligned} \]

ตัวอย่างจอ SPX: $A-B=61.65$ และ $A=4{,}962.64$ call strike 5,000 จึงต้องราคาอยู่ระหว่าง 61.65 ถึง 4,962.64 จุด ราคา 300 จุดอยู่ในช่วงนี้ ขอบเขตกว้างมาก แต่มันจะสำคัญในขั้นที่ 7 เพราะเป็นช่วงที่หา implied volatility ได้

ทีนี้ดู call อเมริกันบนหุ้นที่ไม่จ่ายปันผล คือ $q=0$ และ $A=S_0$ ถ้าใช้สิทธิ์ทันที ผู้ถือได้ $S_0-K$ คำถามคือคุ้มกว่าถือต่อไหม อีกสมการหนึ่งคือ parity เมื่อหุ้นจ่ายปันผลเป็นก้อน ๆ แทนการไหลต่อเนื่อง โดย $D$ คือมูลค่าวันนี้ของปันผลทุกก้อนที่จ่ายก่อนวันหมดอายุ

\[ \begin{aligned} q=0:\ C_{\rm Am}&\ge C\ge S_0-Ke^{-rT}\gt S_0-K,\\ P+S_0-D&=C+Ke^{-rT}. \end{aligned} \]

ผลที่น่าแปลกใจคือ บนหุ้นที่ไม่จ่ายปันผล call อเมริกันมีค่ามากกว่าการใช้สิทธิ์ทันทีเสมอ เหตุผลอยู่ที่ $Ke^{-rT}\lt K$: ถ้ารอ เราจ่าย strike ช้าลง และได้ดอกเบี้ยของเงินก้อนนั้นระหว่างรอ ส่วน call ที่ยังถือไว้ก็ยังกันขาลงให้อยู่ (ถ้าหุ้นตกต่ำกว่า strike เราแค่ไม่ใช้สิทธิ์) การใช้สิทธิ์ก่อนจึงเท่ากับทิ้งเงิน ไม่มีวันคุ้ม ถ้าอยากได้เงินสด ขาย call ไปเลยยังได้มากกว่า ผลคือ call อเมริกันกับ call ยุโรปบนหุ้นแบบนี้ราคาเท่ากัน

put ไม่เป็นแบบนั้น ขอบล่างของ put ยุโรปคือ $Ke^{-rT}-S_0$ ซึ่งต่ำกว่าเงินที่ได้จากการใช้สิทธิ์ทันที $K-S_0$ ขอบเขตจึงไม่ห้ามการใช้สิทธิ์ก่อน เมื่อหุ้นอยู่ต่ำกว่า strike มาก การรับเงิน strike เร็วขึ้นเพื่อเอาไปกินดอกเบี้ยคุ้มกว่าการรอ ราคา put อเมริกันจึงไม่มีสูตรสำเร็จ ต้องหาด้วย ต้นไม้ binomial

สำหรับปันผลเป็นก้อน: ผู้ถือหุ้นได้ปันผลก่อนวันหมดอายุ แต่ผู้ถือ option ไม่ได้ จึงต้องหักมูลค่าวันนี้ของปันผล $D$ ออกจากฝั่งหุ้น ถ้าปันผลไหลต่อเนื่องในอัตรา $q$ จะได้ $S_0-D=S_0e^{-qT}$ และกลับมาเป็นรูปเดิม (ดู ปันผลในสูตรราคา)

ขั้นที่ 6 — parity ไม่สนความผันผวน

ขั้นที่ 2 พิสูจน์ parity โดยไม่ใช้แบบจำลองเลย ขั้นนี้ตรวจจากอีกทาง: สูตร Black–Scholes มีความผันผวน $\sigma$ อยู่ข้างใน แต่ถ้า parity ถูก ผลต่าง call ลบ put จากสูตรนี้ต้องไม่ขึ้นกับ $\sigma$ เลย สูตรแบบมีปันผลอยู่ในสองแถวแรกด้านล่าง $\Phi(x)$ คือพื้นที่ใต้ระฆัง Normal มาตรฐานทางซ้ายของ $x$ และ $\sigma$ อยู่ในตัวเลข $d_1$ กับ $d_2$ เท่านั้น เครื่องมือที่ใช้มีข้อเดียว: ระฆังสมมาตร พื้นที่ทางซ้ายของ $-x$ จึงเท่ากับพื้นที่ทางขวาของ $x$ และได้ $\Phi(x)+\Phi(-x)=1$ เสมอ

สามแถวท้ายลองตัวเลขจริง ราคา call และ put แต่ละตัวคำนวณจากสูตรเดียวกัน ที่ $S_0=K=5{,}000$, $T=0.5$, $r=4\%$, $q=1.5\%$ เปลี่ยนแค่ความผันผวน (โค้ดท้ายหน้าคำนวณซ้ำได้)

\[ \begin{aligned} C&=S_0e^{-qT}\Phi(d_1)-Ke^{-rT}\Phi(d_2),\\ P&=Ke^{-rT}\Phi(-d_2)-S_0e^{-qT}\Phi(-d_1),\\ C-P&=S_0e^{-qT}\big[\Phi(d_1)+\Phi(-d_1)\big]\\ &\quad-Ke^{-rT}\big[\Phi(d_2)+\Phi(-d_2)\big]\\ &=S_0e^{-qT}-Ke^{-rT},\\ \sigma=10\%:\ C-P&=172.0852-110.4383=61.6469,\\ \sigma=20\%:\ C-P&=309.9232-248.2763=61.6469,\\ \sigma=40\%:\ C-P&=586.0079-524.3610=61.6469. \end{aligned} \]

เมื่อลบ put ออกจาก call ทั้ง $d_1$ และ $d_2$ ไปอยู่ในวงเล็บรูป $\Phi(x)+\Phi(-x)$ ซึ่งเท่ากับ 1 เสมอ ความผันผวนจึงหายไปทั้งหมด เหลือ $A-B$ เหมือนที่ขั้นที่ 2 ได้ ตัวเลขสามแถวยืนยันเรื่องนี้: เมื่อความผันผวนขึ้นจาก 10% เป็น 40% call แพงขึ้น $586.01/172.09=3.4$ เท่า แต่ผลต่างคงที่ที่ 61.6469 จุด ซึ่งคือ $A-B$ จากขั้นที่ 3 พอดี

ความหมายคือ parity บอกได้แค่ว่า call กับ put ห่างกันเท่าไร บอกไม่ได้ว่าแต่ละตัวควรราคาเท่าไร ระดับราคาขึ้นกับความผันผวน ซึ่งเป็นตัวเลขเดียวที่ผู้ซื้อกับผู้ขายต้องต่อรองกัน

ขั้นที่ 7 — เดินย้อนสูตร: implied volatility และทำไม call กับ put ต้องได้ค่าเดียว

ถึงตรงนี้เราใช้สูตรในทิศปกติ: ใส่ความผันผวน ได้ราคา แต่บนจอ ราคามีอยู่แล้ว สิ่งที่ไม่รู้คือความผันผวน เราจึงเดินย้อน: หา $\sigma$ ที่ทำให้ราคาจากสูตร $C_{\rm BS}(\sigma)$ เท่ากับราคาตลาด $C_{\rm market}$ ค่าที่ได้เรียกว่า implied volatility

สมการนี้มีคำตอบเดียวเสมอ ถ้าราคาตลาดอยู่ในขอบเขตจากขั้นที่ 5 คือระหว่าง $\max(A-B,0)$ กับ $A$ เหตุผลคือราคา call ขึ้นตาม $\sigma$ เสมอ อัตราที่มันขึ้นคือ vega เขียนเป็น $\nu$ และ $\nu$ เป็นบวกเสมอ (ดู the Greeks) ราคาจึงไล่จากขอบล่างไปขอบบนโดยไม่ย้อนกลับ ผ่านทุกค่าในช่วงนั้นครั้งเดียว

วิธีแก้ที่เร็วคือ Newton: เริ่มจากค่าเดา ใช้ $\nu$ เป็นความชันของกราฟราคา แล้วเดินตามเส้นสัมผัสไปหาจุดที่ราคาเท่ากับราคาตลาด เริ่มที่ $\sigma_0=20\%$ ที่ค่านี้สูตรให้ call 309.9232 จุด และ $\nu=1{,}382.33$ จุดต่อความผันผวน 1 หน่วย แปลว่าถ้าความผันผวนขึ้น 1 จุดเปอร์เซ็นต์ ราคาขึ้นราว $1{,}382.33\times0.01=13.8$ จุด

\[ \begin{aligned} \sigma_{n+1}&=\sigma_n-\frac{C_{\rm BS}(\sigma_n)-C_{\rm market}}{\nu(\sigma_n)},\\ \sigma_1&=0.20-\frac{309.9232-300}{1{,}382.33}\\ &=0.20-\frac{9.9232}{1{,}382.33}\\ &=0.20-0.007179=0.192821. \end{aligned} \]

ทำแบบเดียวกันกับราคา put 235 จุด แล้วเทียบสองค่า ต่อจากนั้นคูณช่องว่างระหว่างสองค่าด้วย vega ที่ $\sigma_c$ (ซึ่งคือ 1,382.16 ต่างจาก 1,382.33 ที่ 20% เล็กน้อย) เพื่อแปลงช่องว่างกลับเป็นจุด

\[ \begin{aligned} C=300:\ \ \sigma_c&=19.2821\%,\\ P=235:\ \ \sigma_p&=19.0395\%,\\ \sigma_c-\sigma_p&=0.002426,\\ \varepsilon&\approx\nu\,(\sigma_c-\sigma_p)\\ &=1{,}382.16\times0.002426=3.353. \end{aligned} \]

Newton เร็วมากที่นี่ ก้าวเดียวจาก 20% ได้ 19.2821% ซึ่งใส่กลับในสูตรได้ call 300.0006 จุด พลาดแค่ 0.0006 จุด เหตุผลคือที่ strike ใกล้ forward ราคา option เกือบเป็นเส้นตรงในความผันผวน เส้นสัมผัสจึงแทบทับกราฟจริง ก้าวที่สองได้ 19.282099% ตรงทุกหลัก

ส่วนที่น่าคิดคือ put ที่ strike และอายุเดียวกันได้ 19.0395% ต่ำกว่า call $19.2821\%-19.0395\%=0.2426$ จุดเปอร์เซ็นต์ ถ้าราคาบนจอเป็นไปตาม parity สองค่านี้ต้องเท่ากัน เหตุผลมีสามข้อต่อกัน ข้อแรก ถ้า parity จริง ราคาตลาดจะเป็น $C=P+A-B$ ข้อสอง สูตร Black–Scholes เองก็เป็นไปตาม parity ทุก $\sigma$ (ขั้นที่ 6) จึงได้ $C_{\rm BS}(\sigma_p)=P+A-B=C$ แปลว่า $\sigma_p$ ก็ให้ราคา call ตรงตลาดด้วย ข้อสาม ราคา call ขึ้นตาม $\sigma$ อย่างเดียวโดยไม่มีช่วงแบน สองค่าที่ให้ราคา call เดียวกันจึงต้องเป็นค่าเดียวกัน

ดังนั้นช่องว่าง 0.2426 จุดเปอร์เซ็นต์ คือส่วนต่าง parity ที่เขียนในหน่วยความผันผวน คูณด้วย vega ก็ได้ 3.353 จุด ตรงกับ $\varepsilon$ จากขั้นที่ 3 ถ้าใส่ดอกเบี้ย 4.1369% ที่ตลาดใช้ (จากขั้นที่ 4) แทน 4% ทั้ง call และ put จะได้ 19.1582% เท่ากัน โต๊ะเทรดจึงใช้กฎ “call กับ put ที่ strike เดียวกันต้องมี implied volatility เท่ากัน” ตรวจว่าใส่ดอกเบี้ยกับปันผลถูกหรือไม่

ขั้นที่ 8 — วาดทุก strike: ความผันผวนไม่เท่ากัน

ขั้นที่แล้วดูแค่ strike เดียว ขั้นนี้ดูทุก strike พร้อมกัน ถ้า Black–Scholes ถูก ดัชนีมีความผันผวนจริงค่าเดียว ทุก strike จึงควรได้ implied volatility เท่ากัน มาดูว่าตลาดเป็นแบบนั้นไหม

โจทย์ให้อะไรมาบ้าง: ใช้ดัชนีสมมติที่อยู่ที่ $S_0=1{,}000$ จุด เพื่อให้ตัวเลขกลม option อายุ 3 เดือน ($T=0.25$ ปี) ดอกเบี้ย $r=2\%$ ต่อปี ไม่มีปันผล implied volatility ของห้า strike เป็นรูปร่างที่พบบ่อยในตลาดดัชนี (ตัวเลขสมมติ ไม่ใช่ราคาของวันใดวันหนึ่ง)

put strike 800 จ่ายเงินเมื่อดัชนีจบต่ำกว่า 800 คือเมื่อดัชนีร่วงเกิน $(800-1{,}000)/1{,}000=-20\%$ ใน 3 เดือน มันจึงเป็นประกันกันตลาดพัง คำถามคือ ราคาของมันในตลาด (ใช้ 28.5%) แพงกว่าราคาที่จะได้ถ้าทุก strike ใช้ความผันผวนเดียว 19.8% ของ strike 1,000 กี่เท่า ราคา put ทั้งสองค่าด้านล่างคำนวณจากสูตร Black–Scholes ที่ $S_0=1{,}000$, $K=800$, $T=0.25$, $r=2\%$ เปลี่ยนแค่ความผันผวน

\[ \begin{aligned} P_{800}(28.5\%)&=2.9424,\\ P_{800}(19.8\%)&=0.3189,\\ \frac{2.9424}{0.3189}&=9.2,\\ 28.5\%-18.2\%&=10.3\ \text{points}. \end{aligned} \]

คำตอบ: ในตลาด put strike 800 ราคา 2.9424 จุด แพงกว่าราคาแบบความผันผวนเดียว 9.2 เท่า และ implied volatility ที่ปลายซ้าย (strike 800) สูงกว่าจุดต่ำสุดที่ strike 1,100 ถึง 10.3 จุดเปอร์เซ็นต์ ถ้า Black–Scholes ถูกทุกข้อ ห้าจุดนี้ต้องอยู่บนเส้นแบนเส้นเดียว และต้องไม่ขยับไปตามวัน การที่มันไม่แบนคือหลักฐานว่าตลาดไม่เชื่อสมมติฐานของ Black–Scholes ที่ว่า log ของดัชนีในวันหมดอายุกระจายแบบ Normal ซึ่งหางบาง (เหตุการณ์สุดขั้วเกิดยาก) ตลาดคิดว่าดัชนีร่วงแรงได้บ่อยกว่านั้น คนในวงการยังใช้สูตรนี้อยู่ แต่ใส่ความผันผวนคนละค่าในแต่ละ strike จึงมีคำพูดว่า “ใส่ตัวเลขผิดลงในสูตรผิด เพื่อให้ได้ราคาที่ถูก”

ตรวจเองใน 10 วินาที: รูปนี้ไม่ขัดกับ parity เพราะ parity ผูกเฉพาะ call กับ put ที่ strike เดียวกัน call strike 800 จึงต้องใช้ 28.5% เหมือน put strike 800 ส่วนข้าม strike ไม่มีอะไรบังคับให้เท่ากัน ข้อยกเว้นคือ option ของหุ้นรายตัวที่เป็นแบบอเมริกัน: call กับ put ของมันมักให้ smile คนละเส้น เพราะ parity ของ option อเมริกันเป็นช่วง ไม่ใช่สมการ

ขั้นที่ 9 — ทำไมดัชนีหุ้นเอียงไปทางซ้าย

ทำไม smile ของดัชนีหุ้นถึงเอียงขึ้นทางซ้าย ประวัติให้เบาะแส ก่อนเดือนตุลาคม 1987 smile ของดัชนีหุ้นสหรัฐฯ แทบแบน แล้ววันที่ 19 ตุลาคม 1987 (เรียกกันว่า Black Monday) ดัชนีร่วงราว 20% ในวันเดียว หลังจากนั้น put ที่ strike ต่ำก็แพงขึ้นอย่างถาวร คำอธิบายมีสองกลุ่ม

  • ความกลัว: ราคาหุ้นกระโดดลงแรงและบ่อยกว่ากระโดดขึ้น เมื่อตลาดร่วง ความผันผวนก็พุ่งตาม และนักลงทุนจำนวนมากซื้อ put เป็นประกันพอร์ต คนอยากได้ put ที่ strike ต่ำมาก ราคาจึงสูง
  • leverage effect: หุ้นของบริษัทที่มีหนี้จะแกว่งแรงขึ้นเมื่อราคาหุ้นตก กลุ่มนี้เขียนเป็นสมการได้ จึงขอแสดงให้ดู

ให้ $V$ คือมูลค่าทั้งบริษัท $E$ คือมูลค่าหุ้นทั้งหมด และ $D$ คือหนี้ (ในขั้นนี้ $D$ คือหนี้ ไม่ใช่ปันผลแบบในขั้นที่ 5) บริษัทเป็นของผู้ถือหุ้นกับเจ้าหนี้รวมกัน จึงได้ $V=D+E$ เครื่องหมาย $\delta$ หมายถึงการเปลี่ยนแปลงเล็ก ๆ เช่น $\delta V/V$ คือผลตอบแทนของทั้งบริษัท ส่วน $\sigma_V$ และ $\sigma_E$ คือความผันผวนของบริษัทและของหุ้น

\[ \begin{aligned} V&=D+E,\\ \frac{\delta V}{V}&=\frac EV\cdot\frac{\delta E}{E}+\frac DV\cdot\frac{\delta D}{D},\\ \delta D\approx0:\ \ \sigma_V&\approx\frac EV\,\sigma_E,\\ \sigma_E&\approx\frac VE\,\sigma_V=\Big(1+\frac DE\Big)\sigma_V,\\ V=150,\ D=50:\ \sigma_E&=\tfrac{150}{100}\times15\%=22.5\%,\\ V=120,\ D=50:\ \sigma_E&=\tfrac{120}{70}\times15\%=25.7\%. \end{aligned} \]

ความคิดหลักคือ หนี้ทำงานเหมือนคานงัด เมื่อบริษัทขยับ ผู้ถือหุ้นรับแรงขยับเกือบทั้งหมด เพราะเจ้าหนี้ได้เงินเท่าเดิม ผลตอบแทนของทั้งบริษัทจึงเป็นค่าเฉลี่ยถ่วงน้ำหนักของผลตอบแทนหุ้นกับผลตอบแทนหนี้ โดยน้ำหนักคือสัดส่วน $E/V$ และ $D/V$ ขั้นที่สำคัญคือการสมมติว่าหนี้แทบไม่เสี่ยง ($\delta D\approx0$) ซึ่งสมเหตุสมผลสำหรับบริษัทที่ยังไม่ใกล้ล้ม พจน์ของหนี้จึงหายไป ความผันผวนของบริษัทเหลือ $E/V$ เท่าของความผันผวนหุ้น กลับด้านได้ว่าหุ้นแกว่งแรงกว่าบริษัท $V/E=1+D/E$ เท่า

ตัวเลขสมมติแสดงผล: บริษัทผันผวน 15% ต่อปีคงที่ และหนี้ 50 คงที่ เมื่อมูลค่าบริษัทลดจาก 150 เป็น 120 คือ $(120-150)/150=-20\%$ หุ้นลดจาก $150-50=100$ เป็น $120-50=70$ คือ $(70-100)/100=-30\%$ และความผันผวนของหุ้นขึ้นจาก 22.5% เป็น 25.7% เอง ทั้งที่ธุรกิจไม่เปลี่ยนเลย หุ้นยิ่งตก ยิ่งผันผวน ตรงกับที่ smile เอียงซ้ายบอก ความคิดนี้มาจากการมองหุ้นเป็น call บนมูลค่าบริษัท ที่มี strike เท่ากับหนี้ เพราะเจ้าหนี้ได้เงินก่อน ผู้ถือหุ้นได้ส่วนที่เหลือ $(V-D)^+$

ขั้นที่ 10 — ราคาข้าม strike บอกโอกาสที่ตลาดคิดไว้

smile ไม่ได้เป็นแค่รูปที่บอกว่า “put ที่ strike ต่ำแพง” ราคาที่เรียงตาม strike บอกได้ตรง ๆ ว่าตลาดให้โอกาสดัชนีจบที่แต่ละระดับเท่าไร โอกาสในที่นี้คือโอกาสแบบ risk-neutral เขียนเป็น $\mathbb Q$ คือชุดโอกาสที่ตลาดใช้ตั้งราคา: ราคา option ทุกตัวเท่ากับค่าเฉลี่ยของเงินที่มันจ่าย ถ่วงด้วยโอกาสชุดนี้ แล้วคิดลดมาวันนี้ด้วย $e^{-rT}$ (ดู Girsanov และ risk-neutral measure) มันรวมความกลัวของคนไว้ด้วย จึงไม่ใช่โอกาสจริงเสียทีเดียว ส่วน $f^{\mathbb Q}(s)$ คือ density ของ $S_T$ ภายใต้โอกาสชุดนี้

วิธีคือเขียนราคา call เป็น integral ของเงินที่มันจ่าย $(s-K)$ คูณ density แล้วถามว่า ถ้าเลื่อน strike ขึ้นนิดหนึ่ง ราคาเปลี่ยนเท่าไร $K$ อยู่สองที่ คือที่ขอบล่างของ integral และในตัวที่ถูก integrate จึงต้องใช้กฎของ Leibniz ซึ่งบอกว่า อนุพันธ์ของ integral แบบนี้เท่ากับพจน์จากขอบ บวก integral ของอนุพันธ์ของตัวข้างใน

\[ \begin{aligned} C(K)&=e^{-rT}\int_K^{\infty}(s-K)f^{\mathbb Q}(s)\,ds,\\ \frac{\partial C}{\partial K}&=-e^{-rT}(K-K)f^{\mathbb Q}(K)\\ &\quad-e^{-rT}\int_K^{\infty}f^{\mathbb Q}(s)\,ds\\ &=-e^{-rT}\,\mathbb Q(S_T\gt K),\\ \frac{\partial P}{\partial K}&=\frac{\partial C}{\partial K}+e^{-rT}\\ &=e^{-rT}\,\mathbb Q(S_T\lt K),\\ \frac{\partial^2C}{\partial K^2}&=e^{-rT}f^{\mathbb Q}(K),\\ f^{\mathbb Q}(K)&\approx e^{rT}\,\frac{C(K-h)-2C(K)+C(K+h)}{h^2}. \end{aligned} \]

ความคิดหลัก: เลื่อน strike ขึ้น 1 จุด call จะจ่ายน้อยลง 1 จุดในทุกปลายทางที่ดัชนีจบเหนือ strike ราคา call จึงลดลงเท่ากับโอกาสที่ดัชนีจบเหนือ strike คิดลดมาวันนี้ ในสมการ พจน์จากขอบหายไป เพราะตัวที่ถูก integrate $(s-K)$ เป็นศูนย์ที่ขอบ $s=K$ พอดี ส่วนที่เหลือคืออนุพันธ์ของ $s-K$ เทียบ $K$ ซึ่งเท่ากับ $-1$ และ integral ของ density เหนือ $K$ ก็คือโอกาสจบเหนือ $K$

สูตรของ put ได้จากการหาอนุพันธ์ของ parity $C-P=A-Ke^{-rT}$ เทียบ $K$ ได้ $\partial C/\partial K-\partial P/\partial K=-e^{-rT}$ แล้วใช้ $1-\mathbb Q(S_T\gt K)=\mathbb Q(S_T\lt K)$ หาอนุพันธ์ของ call อีกครั้งได้ density

ในตลาดจริง strike ห่างกันเป็นช่วง อนุพันธ์จึงกลายเป็นผลต่าง และผลต่างเหล่านี้ซื้อขายได้จริง ผลต่างของราคา put สอง strike คือ put spread ผลต่างอันดับสองในแถวสุดท้ายคือ butterfly: ซื้อ call strike $K-h$ และ $K+h$ อย่างละใบ ขาย call strike $K$ สองใบ หารด้วย $h^2$ แล้วคูณ $e^{rT}$ ก็ได้ density จากราคาที่ซื้อขายได้ โดยไม่ต้องสมมติแบบจำลองใดเลย

ผลข้างเคียงคือ smile จะเป็นรูปอะไรก็ได้ไม่ได้ เพราะโอกาสและ density ห้ามติดลบ smile จึงชันเกินไปไม่ได้ (put spread จะติดลบ) และโค้งผิดรูปไม่ได้ (butterfly จะติดลบ) ข้อควรระวัง: ราคา option ยุโรปของทุก strike บอกได้แค่การกระจายตัวของดัชนีในวันหมดอายุวันเดียว ไม่ได้บอกว่าดัชนีเดินทางอย่างไรระหว่างทาง สัญญาที่ขึ้นกับเส้นทาง เช่น barrier option (สัญญาที่เริ่มหรือเลิกมีผลเมื่อดัชนีแตะระดับหนึ่งระหว่างทาง) จึงตั้งราคาจาก smile อย่างเดียวไม่ได้

ขั้นที่ 11 — อ่านโอกาสดัชนีร่วง และตั้งราคา digital ให้ถูก

ขั้นที่แล้วให้สูตร ขั้นนี้ใช้มันกับ smile ของดัชนี 1,000 จุดในขั้นที่ 8 เพื่อตอบคำถามที่คนดูแลความเสี่ยงอยากรู้: ตลาดให้โอกาสเท่าไรที่ดัชนีจะร่วงลงต่ำกว่า 800 ใน 3 เดือน แล้วใช้ผลเดียวกันตั้งราคา digital

โจทย์ให้อะไรมาบ้าง:

  • ราคา put ในตลาด (สูตร Black–Scholes ที่ความผันผวนของแต่ละ strike): $P_{800}=2.9424$ จุด (ใช้ 28.5%) และ $P_{900}=9.8942$ จุด (ใช้ 23.1%)
  • ราคา put ถ้าใช้ความผันผวนเดียว 19.8% ทุก strike: 0.3189 จุด และ 6.2383 จุด
  • ตัวคูณย้อนการคิดลด $e^{rT}=e^{0.02\times0.25}=e^{0.005}=1.005$
  • พาราโบลาที่ fit กับ smile ในรูปของขั้นที่ 8: $\sigma(K)=0.197143-0.241x+0.992857x^2$ โดย $x=K/1{,}000-1$ ที่ strike 800 จึงได้ $x=-0.2$

คำถามแรกคือโอกาสเฉลี่ยบนช่วง 800 ถึง 900 จากสูตร $\partial P/\partial K=e^{-rT}\mathbb Q(S_T\lt K)$ ถ้า integrate จาก 800 ถึง 900 จะได้ว่า put spread $P_{900}-P_{800}$ เท่ากับ $e^{-rT}$ คูณพื้นที่ใต้กราฟโอกาสบนช่วงนั้น หารด้วยความกว้าง 100 จุด แล้วคูณ $e^{rT}$ จึงได้ค่าเฉลี่ยของ $\mathbb Q(S_T\lt k)$ บนช่วง $800\le k\le900$

\[ \begin{aligned} \text{market:}\ \ e^{0.005}\,\frac{9.8942-2.9424}{100}&=0.0699,\\ \text{flat:}\ \ e^{0.005}\,\frac{6.2383-0.3189}{100}&=0.0595. \end{aligned} \]

คำถามที่สองคือโอกาสที่ strike 800 พอดี ซึ่งต้องใช้กฎลูกโซ่ เพราะราคา put ในตลาดขึ้นกับ strike สองทาง ทางตรงคือผ่านสูตร โดยถือความผันผวนคงที่ ทางนี้ให้ $\partial P_{\rm BS}/\partial K=e^{-rT}\Phi(-d_2)$ ซึ่งคือสูตรของขั้นที่ 10 ในโลกที่ความผันผวนเป็นค่าเดียว ทางอ้อมคือผ่านความผันผวน $\sigma(K)$ ที่เปลี่ยนตาม strike ทางนี้ให้ vega คูณความชันของ smile $\nu\,\partial\sigma/\partial K$ รวมสองทาง แล้วคูณ $e^{rT}$ ก็ได้โอกาส ก่อนอื่นต้องรู้ $d_2$ และ $\nu$ ที่ strike 800 ความผันผวน 28.5% จากสูตร Black–Scholes ซึ่ง $d_1=\big[\ln(S_0/K)+(r+\tfrac12\sigma^2)T\big]/(\sigma\sqrt T)$ และ $d_2=d_1-\sigma\sqrt T$

\[ \begin{aligned} \ln\frac{1{,}000}{800}&=0.22314,\\ \big(r+\tfrac12\sigma^2\big)T&=(0.02+0.0406)\times0.25\\ &=0.01515,\\ \sigma\sqrt T&=0.285\times0.5=0.1425,\\ d_1&=\frac{0.22314+0.01515}{0.1425}=1.6723,\\ d_2&=d_1-0.1425=1.5298,\\ \nu_{800}&=S_0\,\phi(d_1)\sqrt T\\ &=1{,}000\times0.09855\times0.5=49.28. \end{aligned} \]

ต่อมาคือความชันของ smile ที่ 800 ซึ่งได้จากการหาอนุพันธ์ของพาราโบลา (หาร 1,000 เพราะ $x=K/1{,}000-1$) แล้วรวมทุกอย่างเข้าด้วยกัน

\[ \begin{aligned} \mathbb Q(S_T\lt K)&=\Phi(-d_2)+e^{rT}\nu\,\frac{\partial\sigma}{\partial K},\\ \frac{\partial\sigma}{\partial K}\Big|_{800}&=\frac{-0.241+2(0.992857)(-0.2)}{1{,}000}\\ &=-0.000638,\\ \Phi(-d_2)&=\Phi(-1.5298)=0.0630,\\ \mathbb Q(S_T\lt800)&=0.0630+1.005(49.28)(-0.000638)\\ &=0.0630-0.0316=0.0314. \end{aligned} \]

คำตอบ: ราคาตลาดให้โอกาสที่ดัชนีจบต่ำกว่าระดับในช่วง 800 ถึง 900 เฉลี่ย 6.99% เทียบกับ 5.95% ในโลกความผันผวนเดียว ที่ strike 800 พอดี ตลาดให้ราว 3.1% ส่วนโลกความผันผวนเดียวไม่มีทางอ้อม จึงได้แค่ $\Phi(-d_2)$ ที่ 19.8% คือ $\Phi(-2.2550)=0.0121$ หรือ 1.21% หางซ้ายของตลาดจึงหนากว่า $3.14/1.21=2.6$ เท่า

ตัวเลขนี้ไวต่อความชันที่ใช้มาก ความชัน −0.000638 ต่อจุดคือความชันของเส้น smile ที่ 800 พอดี ถ้าใช้ความชันของเส้นตรงที่ลากจาก 800 ไป 900 แทน คือ $(0.231-0.285)/100=-0.00054$ ต่อจุด จะได้ $0.0630+1.005(49.28)(-0.00054)=0.0363$ หรือ 3.6% แต่ตัวเลข 6.30% ที่ได้จากการใส่ 28.5% ลงใน $\Phi(-d_2)$ ตรง ๆ ผิดแน่นอน เพราะมันคือโอกาสในโลกที่ความผันผวนเป็น 28.5% ทุก strike ซึ่งตลาดไม่ได้คิดแบบนั้น

กฎลูกโซ่เดียวกันใช้ตั้งราคา digital call ซึ่งจ่าย \$1 เมื่อดัชนีจบเหนือ strike ราคาของมันคือมูลค่าวันนี้ของโอกาสจบเหนือ strike คือ $e^{-rT}\mathbb Q(S_T\gt K)=-\partial C/\partial K$ จากขั้นที่ 10 แยกทางตรงกับทางอ้อมเหมือนเดิม ได้ $e^{-rT}\Phi(d_2)-\nu\,\partial\sigma/\partial K$ ตัวอย่าง (ตัวเลขสมมติ)

  • ดัชนี $S_0=100$ และ strike $K=100$
  • อายุ $T=1$ ปี ดอกเบี้ยและปันผลเป็นศูนย์ ($r=q=0$)
  • ความผันผวนที่ strike นี้ $\sigma=25\%$
  • skew: เมื่อ strike สูงขึ้น 10% (คือ 10 จุด) ความผันผวนลด 2.5 จุดเปอร์เซ็นต์ จึงได้ $\partial\sigma/\partial K=-0.025/10=-0.0025$ ต่อจุด
\[ \begin{aligned} d_1&=\frac{\ln 1+\tfrac12(0.25)^2}{0.25}=0.125,\\ d_2&=d_1-0.25=-0.125,\\ \Phi(d_2)&=\Phi(-0.125)=0.4503,\\ \nu&=S_0\,\phi(d_1)\sqrt T=100\,\phi(0.125)=39.58,\\ \text{digital}&=0.4503-39.58\times(-0.0025)\\ &=0.4503+0.0990=0.549. \end{aligned} \]

ราคาคือ 0.549 หรือราว 55% ของเงินที่จ่าย ถ้าไม่นับ skew จะได้แค่ 0.4503 หรือราว 45% ถูกไป $0.549-0.450=0.099$ หรือราว 10 จุดเปอร์เซ็นต์

ตรวจเองใน 10 วินาที: โอกาสจบต่ำกว่าระดับหนึ่งต้องเพิ่มขึ้นเมื่อระดับสูงขึ้น ค่าที่ 800 พอดี (3.1%) จึงต้องไม่เกินค่าเฉลี่ยบนช่วง 800 ถึง 900 (6.99%) และต้องสูงกว่า 1.21% ของโลกความผันผวนเดียว เพราะ smile เอียงซ้าย ผ่านทั้งสองข้อ ส่วน digital: skew ที่ติดลบทำให้ call ถูกลงเร็วกว่าโลกความผันผวนเดียวเมื่อ strike สูงขึ้น ราคา digital คือความชันนี้ติดเครื่องหมายลบ จึงต้องสูงกว่า

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

ลืมปันผลหรือลืมคิดลด: ความผิดนี้ทำให้ทิศการเทรดกลับด้านได้ ถ้าไม่คิดลดเลย ใช้ $S_0-K=5{,}000-5{,}000=0$ จะเห็นเงินฟรี $65-0=65$ จุด ถ้าคิดลดแต่ลืมปันผล ใช้ $S_0-Ke^{-rT}=5{,}000-4{,}900.99=99.01$ จะเห็น call ลบ put ถูกไป $99.01-65=34.01$ จุด แล้วทำ reversal (ซื้อ call ขาย put) ทั้งสองแบบผิด ค่าที่ถูกคือ $S_0e^{-qT}-Ke^{-rT}=61.65$ จุด call ลบ put แพงไป $65-61.65=3.35$ จุด และทิศที่ถูกคือ conversion

ใช้ parity แบบสมการกับ option อเมริกัน: option ของหุ้นรายตัวในสหรัฐฯ ส่วนใหญ่ใช้สิทธิ์ก่อนได้ สำหรับหุ้นที่ไม่จ่ายปันผล parity กลายเป็นช่วง $S_0-K\le C-P\le S_0-Ke^{-rT}$ ตัวอย่าง หุ้นราคา \$1,000 strike \$1,000 ดอกเบี้ย 2% ต่อปี อายุครึ่งปี ช่วงนี้คือ $0\le C-P\le1{,}000-1{,}000e^{-0.01}=9.95$ ถ้าตลาดให้ $C-P=5$ สูตรแบบยุโรปจะบอกว่าถูกไป $9.95-5=4.95$ จุด แต่สำหรับ option อเมริกัน ค่า 5 อยู่ในช่วงพอดี ไม่มีเงินฟรี

อ่าน $\Phi(-d_2)$ ที่ความผันผวนของ strike นั้นว่าเป็นโอกาสของตลาด: ที่ strike 800 สูตรนี้ให้ $\Phi(-1.5298)=6.30\%$ แต่โอกาสที่ถูกคือ $0.0630-0.0316=0.0314$ หรือราว 3.1% เพราะต้องบวกพจน์ $e^{rT}\nu\,\partial\sigma/\partial K=-0.0316$ ที่มาจากความเอียงของ smile digital ที่ตั้งราคาแบบเดียวกันก็ผิดไปราว 10 จุดเปอร์เซ็นต์ (45% แทน 55%) โอกาสของตลาดต้องอ่านจาก put spread หรือจากอนุพันธ์ของราคาตลาดเทียบ strike ทั้งก้อน

จับคู่ call กับ put ที่ไม่ใช่สัญญาเดียวกัน: call กับ put ต้องมี strike วันหมดอายุ และวิธีชำระเงินตรงกันเป๊ะ เช่น SPX มีทั้งสัญญาที่ชำระเงินด้วยราคาเปิดตอนเช้า และสัญญาที่ชำระเงินด้วยราคาปิดตอนเย็นของวันเดียวกัน ถ้าจับ call ชนิดหนึ่งกับ put อีกชนิด ส่วนต่างที่ได้ไม่มีความหมาย

ใช้ทำอะไรบนโต๊ะจริง

ทุกเช้า โต๊ะเทรด option (ทีมที่ซื้อขาย option ให้ธนาคาร) ตรวจ parity กับทุกคู่ call–put ก่อนทำอย่างอื่น ส่วนต่างที่ใหญ่ผิดปกติแทบทุกครั้งมาจากราคาเก่าที่ค้างอยู่บนจอ ปันผลที่ใส่ผิด หรือดอกเบี้ยที่ไม่ตรงกับที่ตลาดใช้ ไม่ใช่เงินฟรี โต๊ะยังใช้ parity ในทางกลับกันด้วย คือดึง forward และ dividend yield ที่ตลาดใช้จริงออกมาจากราคา option (แบบโจทย์ข้อ 3 ท้ายหน้า) เพราะแม่นกว่าการประมาณปันผลเอง

ราคาทุกตัวบนจอถูกแปลงเป็น implied volatility แล้ววาดเป็น smile ของแต่ละวันหมดอายุ โต๊ะ equity (หุ้น) และ FX (อัตราแลกเปลี่ยน) ทุกแห่งทำแบบนี้ และคำนวณ Greeks ด้วยสูตร Black–Scholes ที่ความผันผวนของแต่ละ strike ทั้งที่รู้ว่าแบบจำลองผิด เพราะมันเป็นภาษากลางที่ทุกคนในตลาดใช้คุยกัน

ต้องจำไว้ว่า implied volatility ไม่ใช่ความผันผวนที่ตลาดคาดไว้ตรง ๆ มันรวมค่าประกันที่คนยอมจ่ายเพื่อป้องกันขาลงไว้ด้วย ความผันผวนที่เกิดขึ้นจริงของดัชนีจึงมักต่ำกว่า implied และส่วนต่างนี้คือรายได้ของคนขาย option (ดู variance swap) ถ้าวาง smile ของทุกอายุเข้าด้วยกันจะได้ volatility surface ส่วนแบบจำลองที่สร้าง skew ขึ้นเองได้ คือแบบจำลองที่ความผันผวนเปลี่ยนไปเองตามเวลา และขยับสวนทางกับดัชนี (correlation ติดลบ) เช่น Heston

โจทย์ตรวจความเข้าใจ

1. ดัชนีตัวหนึ่งไม่จ่ายปันผล อยู่ที่ $S_0=1{,}000$ จุด บนจอมี option ยุโรป strike $K=1{,}000$ อายุ $T=0.5$ ปี ราคา call 45 จุด และ put 32 จุด ดอกเบี้ย $r=2\%$ ต่อปี ตัวคูณ \$100 ต่อจุด ราคาคู่นี้ผิดจาก parity เท่าไร ควรทำรายการอะไรเพื่อเก็บส่วนต่าง และ implied volatility ของ call กับ put ต่างกันเท่าไร

เฉลย

ไม่มีปันผล ดัชนีหนึ่งหน่วยวันนี้จึงจ่ายดัชนีหนึ่งหน่วยในวันหมดอายุพอดี ได้ $A=S_0=1{,}000$ ที่เหลือคิดแบบขั้นที่ 3

\[ \begin{aligned} B&=1{,}000e^{-0.02\times0.5}=1{,}000e^{-0.01}\\ &=990.0498,\\ A-B&=1{,}000-990.0498=9.9502,\\ C-P&=45-32=13,\\ \varepsilon&=13-9.9502=3.0498,\\ m\varepsilon&=100\times3.0498=\$304.98. \end{aligned} \]

call ลบ put แพงไป 3.0498 จุด จึงทำ conversion: ขาย call ได้ +45 ซื้อ put จ่าย −32 ซื้อดัชนีจ่าย −1,000 และกู้เงินได้ +990.0498 รวม $45-32-1{,}000+990.0498=+3.0498$ จุดวันนี้ หรือ \$304.98 ต่อชุด ส่วน implied volatility แก้ด้วย Newton แบบขั้นที่ 7 ได้ call 14.195% และ put 13.101% ห่างกัน $14.195\%-13.101\%=1.094$ หรือราว 1.09 จุดเปอร์เซ็นต์ นี่คืออาการเดียวกันในหน่วยความผันผวน ตรวจได้ด้วย vega ที่ 14.195% ซึ่ง $S_0=K$ ทำให้ $\ln(S_0/K)=0$ และ $d_1=(0.02+\tfrac12\times0.14195^2)\times0.5/(0.14195\sqrt{0.5})=0.1498$ จึงได้ $\nu=1{,}000\,\phi(0.1498)\sqrt{0.5}=278.95$ คูณช่องว่างได้ $278.95\times0.01094=3.05$ จุด เท่ากับ $\varepsilon$

2. หุ้นตัวหนึ่งไม่จ่ายปันผล ราคาตกหนักจนเหลือ $S_0=\$20$ นักลงทุนถือ put strike $K=\$36$ อายุเหลือ $T=0.25$ ปี (3 เดือน) ดอกเบี้ย $r=2\%$ ต่อปี ความผันผวน $\sigma=24\%$ ต่อปี ถ้าเป็น put ยุโรป ราคาเท่าไร และถ้าเป็น put อเมริกัน การใช้สิทธิ์ทันทีซึ่งได้ $K-S_0=36-20=\$16$ ดีกว่าถือต่อไหม

เฉลย

ใช้สูตร Black–Scholes ของ put โดย $\sigma\sqrt T=0.24\times0.5=0.12$ และ $\tfrac12\sigma^2=\tfrac12\times0.24^2=0.0288$

\[ \begin{aligned} d_1&=\frac{\ln(20/36)+(0.02+0.0288)\times0.25}{0.12}\\ &=\frac{-0.5878+0.0122}{0.12}=-4.797,\\ d_2&=d_1-0.12=-4.917,\\ Ke^{-rT}&=36e^{-0.005}=35.8204,\\ P&=Ke^{-rT}\Phi(-d_2)-S_0\Phi(-d_1)\\ &\approx35.8204-20=\$15.8204. \end{aligned} \]

หุ้นอยู่ต่ำกว่า strike มาก $d_1$ และ $d_2$ ติดลบลึกเกือบ 5 จึงได้ $\Phi(-d_1)$ และ $\Phi(-d_2)$ เกือบเป็น 1 (ต่างจาก 1 ไม่ถึงหนึ่งในล้าน) put จึงเกือบเท่ากับขอบล่างจาก parity $Ke^{-rT}-S_0$ พอดี ราคานี้ต่ำกว่าการใช้สิทธิ์ทันที $16-15.8204=\$0.18$ เพราะ put ยุโรปต้องรอสามเดือนกว่าจะได้เงิน strike และเงิน \$36 ที่ได้ช้าไปสามเดือนมีค่าแค่ \$35.82 วันนี้ ถ้าเป็น put อเมริกัน การใช้สิทธิ์ทันทีจึงดีกว่า: ได้ \$16 วันนี้ แล้วเอาไปฝากกินดอกเบี้ย นี่คือเหตุผลที่ put อเมริกันที่อยู่ต่ำกว่า strike มากถูกใช้สิทธิ์ก่อนกำหนด

3. กลับไปที่จอ SPX ในโจทย์เปิดเรื่อง สมมติว่าเรามั่นใจว่าดอกเบี้ย 4% ถูกต้อง แต่ไม่แน่ใจตัวเลขปันผล ปันผล $q$ ต้องเป็นเท่าไร parity จึงตรงกับราคากลาง call 300 และ put 235 พอดี

เฉลย

ให้ parity ตรงพอดี คือ $C-P=A-B$ แก้หา $A$ ก่อน แล้วใช้ $A=S_0e^{-qT}$ แก้หา $q$ โดย $B=4{,}900.9934$ จากขั้นที่ 3

\[ \begin{aligned} A&=(C-P)+B=65+4{,}900.9934\\ &=4{,}965.9934,\\ e^{-0.5q}&=\frac{4{,}965.9934}{5{,}000}=0.9931987,\\ q&=-2\ln0.9931987=1.3649\%. \end{aligned} \]

ค่านี้ต่ำกว่า 1.5% ที่เราใส่ไว้ $1.5\%-1.3649\%=0.135\%$ ต่อปี แปลว่าตลาดตั้งราคาเหมือนปันผลน้อยกว่าที่เราคิด ตัวเลขนี้เรียกว่า implied dividend โต๊ะเทรดดึงมันออกมาจากราคา option แบบนี้ทุกวัน

// Put-call parity with dividends, the conversion trade, implied volatility, the leverage effect and reading the smile.
const { abs, exp, log, sqrt, max, PI } = Math;
const phi = x => exp(-0.5 * x * x) / sqrt(2 * PI);
function Phi(x) { // normal CDF: series near the centre, continued fraction in the tails
  const a = abs(x);
  if (a <= 3) { let t = a, s = a; for (let n = 1; n < 200 && t > 1e-17 * s; n++) { t *= a * a / (2 * n + 1); s += t; }
    return x >= 0 ? 0.5 + phi(a) * s : 0.5 - phi(a) * s; }
  let f = a; for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - phi(a) / f : phi(a) / f;
}
function bs(S, K, T, r, sigma, q = 0) {
  if (!(S > 0 && K > 0 && T > 0 && sigma > 0 && sigma <= 5)) throw new RangeError('Need positive S, K, T and 0 < sigma <= 5');
  const sT = sigma * sqrt(T), A = S * exp(-q * T), B = K * exp(-r * T);
  const d1 = (log(A / B) + 0.5 * sigma * sigma * T) / sT, d2 = d1 - sT;
  return { d1, d2, call: A * Phi(d1) - B * Phi(d2), put: B * Phi(-d2) - A * Phi(-d1), vega: A * phi(d1) * sqrt(T) };
}
function parity(S, K, T, r, q, call, put) { // prepaid forward A pays S_T, bond B pays K
  const A = S * exp(-q * T), B = K * exp(-r * T);
  return { A, B, F: S * exp((r - q) * T), fair: A - B, market: call - put, residual: call - put - (A - B),
    impliedRate: -log((A - (call - put)) / K) / T, impliedDividend: -log((call - put + B) / S) / T };
}
function impliedVol(price, S, K, T, r, q = 0, kind = 'call') { // Newton on vega inside a bisection bracket
  const A = S * exp(-q * T), B = K * exp(-r * T);
  const low = kind === 'call' ? max(A - B, 0) : max(B - A, 0), high = kind === 'call' ? A : B;
  if (!(price > low && price < high)) throw new RangeError(`No volatility gives this price: it must lie strictly between ${low} and ${high}`);
  let lo = 1e-6, hi = 5, sigma = 0.2;
  for (let i = 0; i < 100; i++) {
    const b = bs(S, K, T, r, sigma, q), diff = (kind === 'call' ? b.call : b.put) - price;
    if (abs(diff) < 1e-12 * price) return sigma;
    if (diff > 0) hi = sigma; else lo = sigma;
    const next = sigma - diff / b.vega;
    sigma = next > lo && next < hi ? next : 0.5 * (lo + hi);
  }
  return sigma;
}
const S = 5000, K = 5000, T = 0.5, r = 0.04, q = 0.015;
const spx = parity(S, K, T, r, q, 300, 235);
const ivCall = impliedVol(300, S, K, T, r, q, 'call'), ivPut = impliedVol(235, S, K, T, r, q, 'put');

const sig = k => { const x = k / 1000 - 1; return 0.197143 - 0.241 * x + 0.992857 * x * x; };
const putAt = k => bs(1000, k, 0.25, 0.02, sig(k)).put, callAt = k => bs(1000, k, 0.25, 0.02, sig(k)).call;

สิ่งที่ควรตอบได้หลังอ่าน

  • พอร์ต “call บวกเงินฝาก” กับพอร์ต “put บวกดัชนี” จ่าย $\max(S_T,K)$ เท่ากันทุกกรณี จึงต้องราคาเท่ากัน ได้ $C-P=S_0e^{-qT}-Ke^{-rT}=e^{-rT}(F-K)$ โดยไม่ต้องใช้แบบจำลองหรือความผันผวน
  • จอ SPX: parity ต้องการ $C-P=61.65$ จุด ตลาดให้ 65 ส่วนเกินจริงคือ 3.35 จุด (\$335 ต่อคู่) ไม่ใช่ 65 และหายหมดถ้าดอกเบี้ยเงินกู้แพงกว่า 4% แค่ 13.7 bp
  • parity ให้ขอบเขตราคาของ option แต่ละตัว และบอกว่า call อเมริกันบนหุ้นที่ไม่จ่ายปันผลไม่ควรใช้สิทธิ์ก่อนกำหนด แต่ put อเมริกันอาจควร
  • implied volatility คือความผันผวนที่ทำให้สูตรตรงกับราคาตลาด หาได้ด้วย Newton โดยใช้ vega เป็นความชัน parity บังคับให้ call กับ put ที่ strike เดียวกันได้ค่าเดียวกัน แต่ข้าม strike ไม่มีอะไรบังคับ: put strike 800 แพงกว่าราคาแบบความผันผวนเดียว 9.2 เท่า
  • skew ของดัชนีมาจากความกลัวขาลง และจาก leverage effect $\sigma_E\approx(1+D/E)\sigma_V$ ราคาข้าม strike อ่านเป็นโอกาสได้ด้วย $\partial P/\partial K=e^{-rT}\mathbb Q(S_T\lt K)$ และ $\partial^2C/\partial K^2=e^{-rT}f^{\mathbb Q}(K)$ ไม่ใช่ด้วย $\Phi(-d_2)$ ที่ความผันผวนของ strike นั้น

หน้านี้ดู smile ที่อายุเดียว หน้าถัดไป volatility surface และ term structure จะวางทุกอายุเข้าด้วยกัน และหากฎที่ทำให้แต่ละอายุไม่ขัดกันเอง
