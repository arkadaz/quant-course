4.2 Transpose

พลิกแถวเป็นคอลัมน์เพื่อเปลี่ยนมุมมอง

ตารางที่นั่งมีแถวเป็นชื่อนักเรียนและคอลัมน์เป็นวิชา ถ้าอยากถามว่า “วิชานี้มีใครบ้าง” ต้องหมุนมุมมองอย่างไรโดยไม่เปลี่ยนชื่อหรือคะแนน?

เฉลย: ค่าทุกตัวยังเดิม แต่ช่องแถว 2 คอลัมน์ 3 ย้ายไปแถว 3 คอลัมน์ 2

transpose คือการสลับแถวกับคอลัมน์ของ matrix ใช้เปลี่ยนบทบาท input กับ output หรือจัด vector ให้วางด้านที่คูณได้

transpose ไม่ได้สับไพ่ มันแค่หันสมุด 90 องศา งานจริงใช้มันเขียน quadratic form และตรวจทิศทางของข้อมูลใน regression หรือ optimization

คำตอบและวิธีเช็ก

คำตอบ — transpose สลับแกน แต่ค่าเดิมอยู่ครบ

คำตอบtranspose ของตาราง 3×2 ต้องมี shape 2×3 โดย market row เป็น [1.2, 0.9, 1.5] และ quality row เป็น [0.4, 0.2, 0.7] ค่า loading ทั้งหกตัวไม่เปลี่ยน มีเพียงตำแหน่งที่สลับ

ตรวจเองใน 10 วินาทีดูช่อง market–SPY หลัง transpose ต้องได้ 1.5 เท่ากับช่อง SPY–market เดิม แล้ว transpose ซ้ำอีกครั้งต้องกลับเป็นตาราง 3×2 เดิมทุกช่อง

ใช้ตัดสินใจ: ส่ง matrix เข้า factor-first API ได้เมื่อ shape เป็น 2×3 และ labels เดินไปพร้อมแกน ถ้าตัวเลขตรงแต่ label ไม่ตรง ให้ reject ก่อนคำนวณ exposure

ระวังตรงนี้

กับดัก: reshape ไม่ใช่ transpose

reshape เพียงจัดค่าตามลำดับข้อมูลที่ถูก flatten และไม่ได้สลับ index ตามนิยาม transpose ต่อให้ shape ที่ได้ดูพอดี label ก็อาจจับกับ value ผิด การ transpose ต้องอ้างอิง และควรตรวจว่า transpose ซ้ำสองครั้งคืน matrix เดิม

สรุปที่ใช้ได้จริง

  • transpose สลับ index ตาม โดยไม่เปลี่ยน element
  • shape กลายเป็น
  • ใช้ transpose เพื่อหันข้อมูลให้ dot product และ matrix multiplication ถูกทิศ
  • reshape แบบไม่รักษา labels เป็นความเสี่ยงเชิงระบบ
