4.2 Transpose

พลิกแถวเป็นคอลัมน์เพื่อเปลี่ยนมุมมอง

ตาราง payoff มี 2 แถวคือสองสภาวะตลาด และ 3 คอลัมน์คือสามสินทรัพย์: แถวแรก 2, 3, 7 แถวสอง 1, 6, 5 ระบบ risk ต้องการตารางแบบแถวเป็นสินทรัพย์ เลข 7 ต้องย้ายไปอยู่ช่องไหน และมีเลขตัวไหนเปลี่ยนค่าไหม?

เฉลย: เลข 7 ย้ายจากแถว 1 คอลัมน์ 3 ไปแถว 3 คอลัมน์ 1 ตารางใหม่มี 3 แถว 2 คอลัมน์ คือ (2, 1), (3, 6), (7, 5) ไม่มีเลขตัวไหนเปลี่ยนค่า มีแต่ที่อยู่เปลี่ยน

transpose คือการสลับแถวกับคอลัมน์ของ matrix ใช้จัด vector ให้วางด้านที่คูณได้ งานจริงใช้มันเขียนความเสี่ยงพอร์ตเป็น quadratic form และตรวจทิศทางของข้อมูลใน regression หรือ optimization

ที่มาที่ไป: การพลิกที่ทำให้สูตรความเสี่ยงเขียนได้

การสลับแถวกับคอลัมน์ฟังดูเหมือนเรื่องเล็กที่สุดในบทนี้ แต่ถ้าไม่มีมัน สูตรความเสี่ยงของพอร์ตเขียนไม่ได้เลย

เหตุผลอยู่ที่กติกาการคูณ ซึ่งบังคับเรื่องรูปร่างอย่างเคร่งครัด น้ำหนักพอร์ตที่เขียนเป็นคอลัมน์ จะคูณกับตารางความเสี่ยงแล้วได้คอลัมน์ออกมา ซึ่งยังไม่ใช่ตัวเลขตัวเดียวที่เราต้องการ

การพลิกน้ำหนักให้เป็นแถวก่อนแล้วคูณอีกครั้ง คือขั้นตอนที่ยุบทุกอย่างเหลือตัวเลขตัวเดียว ซึ่งเป็นเหตุผลที่น้ำหนักปรากฏสองครั้งในสูตร โดยครั้งหนึ่งพลิกแล้ว

นอกจากนั้นมันยังให้เครื่องตรวจฟรี เพราะตารางความเสี่ยงต้องเท่ากับตัวพลิกของตัวเองเสมอ

ความเป็นมา: กำเนิด transpose จากการสลับดัชนีสู่ quadratic form

Arthur Cayley เป็นผู้นิยาม transpose อย่างเป็นทางการในบทความปี 1858 เรื่องทฤษฎี matrix ก่อนหน้านั้น นักคณิตศาสตร์รุ่นก่อนหน้าอย่าง Joseph-Louis Lagrange และ Carl Friedrich Gauss ต้องศึกษา quadratic form โดยเขียนเครื่องหมายผลรวมสองชั้นยาวเหยียด และต้องคอยสลับดัชนี $i, j$ ด้วยมือทุกครั้งที่ต้องการวิเคราะห์สมมาตร

Cayley มองเห็นว่าการสลับแถวเป็นคอลัมน์คือการแปลงเชิงพีชคณิตที่เป็นเอกเทศ การใส่สัญลักษณ์ transpose ทำให้เกิดกฎความสัมพันธ์สำคัญอย่าง $(AB)^{\mathsf T} = B^{\mathsf T}A^{\mathsf T}$ ซึ่งช่วยให้การคำนวณในระบบหลายมิติง่ายขึ้นอย่างมหาศาล

ในโลกการเงินเชิงปริมาณ Harry Markowitz ในปี 1952 ได้นำ transpose มาใช้นิยาม portfolio variance ในรูป $w^{\mathsf T}\Sigma w$ หากไม่มี transpose เราจะไม่สามารถเชื่อม vector น้ำหนักพอร์ตเข้ากับ covariance matrix เพื่อยุบตัวเลขความเสี่ยงออกมาเป็น scalar ค่าเดียวได้เลย

Worked Example — โจทย์และสิ่งที่ให้มา

โจทย์ให้อะไรมาบ้าง: ตาราง $A$ มี rows เป็น AAPL, MSFT, SPY และ columns เป็น market กับ quality factor การ transpose ไม่ได้เปลี่ยน factor loading ใด ๆ มันเพียงสลับมุมมองเพื่อให้ factor เป็น rows และ asset เป็น columns

ขั้นที่ 1 — พลิกตารางจริงด้วยมือ แล้วพลิกกลับ

ก่อนกฎ ลองกับตารางจากหัวข้อ 4.1 ตรง ๆ หันสมุด 90 องศาแล้วเขียนใหม่ แล้วหันกลับ

\[ A=\begin{bmatrix}1.2&0.4\\ 0.9&0.2\\ 1.5&0.7\end{bmatrix}\quad\Longrightarrow\quad A^{\mathsf T}=\begin{bmatrix}1.2&0.9&1.5\\ 0.4&0.2&0.7\end{bmatrix}\quad\Longrightarrow\quad(A^{\mathsf T})^{\mathsf T}=\begin{bmatrix}1.2&0.4\\ 0.9&0.2\\ 1.5&0.7\end{bmatrix}=A \]

แถวของ $A$ (AAPL, MSFT, SPY) กลายเป็นคอลัมน์ของ $A^{\mathsf T}$ และคอลัมน์ (market, quality) กลายเป็นแถว ตัวเลขทั้งหกไม่มีตัวไหนเปลี่ยนค่า เช่น 1.5 ที่เคยอยู่แถว 3 คอลัมน์ 1 ย้ายไปแถว 1 คอลัมน์ 3

พลิกซ้ำได้ของเดิม นี่คือการตรวจที่เร็วที่สุด และเป็นเหตุผลที่ reshape (จัดเรียงตัวเลขใหม่ตามลำดับหน่วยความจำ) ไม่ใช่ transpose

ขั้นที่ 2 — นิยาม element

transpose คือการสลับที่ของทุกช่องตามกฎเดียว เขียนเป็นสูตรได้บรรทัดเดียว

\[ (A^{\mathsf T})_{ij}=A_{ji} \]

element ที่ row $i$, column $j$ ใน transpose เท่ากับ element ที่ row $j$, column $i$ ใน matrix เดิม จึงเป็นการสลับตำแหน่ง ไม่ใช่การเปลี่ยนค่า

ขั้นที่ 3 — ทำไม transpose ต้องสลับจำนวนแถวกับคอลัมน์

นิยามในบรรทัดก่อนบอกว่า transpose คือการสลับ index สองตัวของแต่ละช่อง ส่วนรูปร่างของผลลัพธ์ไม่ต้องจำแยก เพราะมันตามมาเองจากการนับ index

ช่องหนึ่งของ $A$ ถูกระบุด้วยเลขสองตัว ตัวแรกนับแถว ตัวที่สองนับคอลัมน์ พอสลับกัน ตัวที่นับแถวก็กลายเป็นตัวที่นับคอลัมน์

\[ \begin{aligned} A&=\begin{bmatrix}1.2&0.4\\ 0.9&0.2\\ 1.5&0.7\end{bmatrix}\\ &\quad(3\times2:\ m=3,\ n=2)\\[4pt] (A^{\mathsf T})_{ij}&=a_{ji}\\ &\quad\text{(the two indices trade places)}\\[4pt] &\text{rows of }A^{\mathsf T}:\ i=1,\dots,n=2\\ &\text{columns: }j=1,\dots,m=3\\[4pt] &\Longrightarrow\quad A^{\mathsf T}=\begin{bmatrix}1.2&0.9&1.5\\ 0.4&0.2&0.7\end{bmatrix}\\ &\quad(2\times3) \end{aligned} \]

$A$ มี $3$ rows และ $2$ columns ช่อง $(i,j)$ ของ $A^{\mathsf T}$ คือ $a_{ji}$ แปลว่า index แรกของ $A^{\mathsf T}$ วิ่งตาม index ที่สองของ $A$ ซึ่งมีอยู่ $2$ ค่า

ส่วน index ที่สองของ $A^{\mathsf T}$ วิ่งตาม index แรกของ $A$ ผลลัพธ์จึงมี $2$ rows และ $3$ columns

ดูจากตัวเลขจริงจะเห็นว่าแถวแรกของ $A$ คือ $1.2$ กับ $0.4$ กลายเป็นคอลัมน์แรกของ $A^{\mathsf T}$ ไม่มีตัวเลขใดถูกคำนวณใหม่ทั้งหมด แค่ย้ายที่อยู่ นี่คือเหตุผลที่ transpose ไม่เปลี่ยนข้อมูล มีแต่เปลี่ยนมุมมองว่าจะอ่านเป็นแถวหรือคอลัมน์

ขั้นที่ 4 — shape เปลี่ยนอย่างไร

ขั้นที่ 3 ตรวจกับตารางขนาด 3 คูณ 2 จริง ขั้นนี้เขียนกรณีทั่วไปด้วยตัวอักษร เพื่อให้เห็นว่าผลไม่ได้ขึ้นกับตัวเลขของตัวอย่าง

\[ \begin{aligned}A:\ m\times n\ &\Rightarrow\ a_{ij}\ \text{exists for }i\le m,\ j\le n\\[4pt] (A^{\mathsf T})_{ij}&=a_{ji}\ \Rightarrow\ i\le n,\ j\le m\\[4pt] \Longrightarrow\quad A^{\mathsf T}&:\ n\times m\end{aligned} \]

แถวแรกบอกว่า index ของ $A$ มีอยู่เท่าไร: ตัวแรกวิ่งถึง $m$ ตัวที่สองวิ่งถึง $n$ นี่คือความหมายของคำว่ารูปร่าง ไม่ใช่ข้อมูลเพิ่ม

แถวที่สองสลับ index ทั้งสอง แล้วถามว่าตอนนี้แต่ละตัววิ่งได้ถึงเท่าไร คำตอบคือตัวแรกได้ถึง $n$ และตัวที่สองได้ถึง $m$ เพราะมันสลับบทบาทกัน

บรรทัดสุดท้ายจึงเป็นเพียงการอ่านจำนวนที่นับได้กลับออกมาเป็นรูปร่าง ไม่มีขั้นตอนใดที่ต้องเชื่อ ต้องเชื่อแค่ว่าการสลับ index สองตัวสลับกันจริง

ขั้นที่ 5 — transpose กลับที่เดิม

ทำสองครั้งได้ของเดิม ซึ่งเป็นการตรวจที่เร็วที่สุดว่าเข้าใจถูก และเหตุผลสั้นมาก คือสลับที่สองครั้งย่อมกลับมาที่เดิม ไม่ต้องรู้อะไรเกี่ยวกับค่าในตารางเลย

\[ \begin{aligned}\big(A^{\mathsf T}\big)_{ij}&=A_{ji}\\ \Big(\big(A^{\mathsf T}\big)^{\mathsf T}\Big)_{ij}&=\big(A^{\mathsf T}\big)_{ji}\\ &=A_{ij}\\ \Longrightarrow\;\big(A^{\mathsf T}\big)^{\mathsf T}&=A\end{aligned} \]

นิยามของ transpose บอกว่าช่องแถว $i$ คอลัมน์ $j$ ของตัวใหม่ คือช่องแถว $j$ คอลัมน์ $i$ ของตัวเดิม ทำสองครั้งก็คือสลับดัชนีสองครั้ง ซึ่งย่อมกลับมาที่เดิม

บรรทัดสองใช้นิยามนั้นกับตัวที่ transpose ไปแล้ว ส่วนบรรทัดสามอ่านค่ากลับด้วยนิยามเดิมอีกที ดัชนีกลับมาตรงกับของเดิมทุกช่อง ตารางสองอันจึงเป็นอันเดียวกัน สังเกตว่าตลอดการพิสูจน์ เราไม่ต้องรู้อะไรเกี่ยวกับค่าในตารางเลยแม้แต่ช่องเดียว

ขั้นที่ 6 — dot product เป็นกรณีพิเศษ

การคูณกันแบบที่ใช้บ่อยที่สุดในหนังสือเล่มนี้ แท้จริงเป็นกรณีเฉพาะของ transpose คูณ vector และการที่สลับลำดับได้เป็นเรื่องเฉพาะของกรณีนี้ ไม่ใช่กฎทั่วไปของการคูณตาราง ซึ่งเป็นจุดที่ขั้นถัดไปจะย้ำ

\[ \begin{aligned}u^{\mathsf T}v&=\sum_{i=1}^{n}u_iv_i\\ v^{\mathsf T}u&=\sum_{i=1}^{n}v_iu_i\\ u_iv_i&=v_iu_i\\ \Longrightarrow\;u^{\mathsf T}v&=v^{\mathsf T}u=\sum_{i=1}^{n}u_iv_i\end{aligned} \]

การคูณแบบนี้ใช้บ่อยที่สุดในเล่ม และมันเป็นแค่กรณีเฉพาะของการคูณตาราง: transpose เปลี่ยน vector แนวตั้งให้เป็นแนวนอน จึงคูณกันได้ และผลออกมาเป็นเลขตัวเดียว ไม่ใช่ตาราง

เหตุผลที่สลับลำดับได้มีข้อเดียว อยู่บรรทัดสาม คือการคูณเลขสองตัวสลับที่กันได้ ทีละคู่ ทุกคู่ สองผลรวมจึงบวกของชิ้นเดียวกัน ค่าย่อมเท่ากัน ข้อควรระวังคือนี่เป็นเรื่องเฉพาะของกรณีนี้ ไม่ใช่กฎทั่วไปของการคูณตาราง ซึ่งเป็นจุดที่ขั้นถัดไปจะย้ำ

ขั้นที่ 7 — ทรานสโพสของผลคูณ: ทำไมลำดับต้องสลับ

ข้อนี้เป็นกฎที่ใช้บ่อยที่สุดในบทหลัง ๆ และเป็นข้อที่คนจำผิดบ่อยที่สุดด้วย เพราะเผลอคิดว่าทรานสโพสกระจายเข้าไปเฉย ๆ โดยไม่สลับลำดับ

\[ \begin{aligned}\big((AB)^{\mathsf T}\big)_{ij}&=(AB)_{ji}\\ &=\sum_k A_{jk}B_{ki}\\ &=\sum_k\big(B^{\mathsf T}\big)_{ik}\big(A^{\mathsf T}\big)_{kj}\\ &=\big(B^{\mathsf T}A^{\mathsf T}\big)_{ij}\\[4pt] \Longrightarrow\;(AB)^{\mathsf T}&=B^{\mathsf T}A^{\mathsf T}\end{aligned} \]

เดาคำตอบจากรูปร่างก่อนก็ได้ ถ้า $A$ เป็น $m\times n$ และ $B$ เป็น $n\times p$ ผลคูณเป็น $m\times p$ ทรานสโพสจึงเป็น $p\times m$ ซึ่งต่อกันได้ทางเดียวคือ $B^{\mathsf T}$ คูณ $A^{\mathsf T}$ สลับทางอื่นรูปร่างไม่รับกันเลย

การพิสูจน์จริงคือไล่ทีละช่อง ช่อง $ij$ ของทรานสโพสคือช่อง $ji$ ของตัวเดิม ซึ่งตามนิยามการคูณในหัวข้อ 4.3 คือแถวที่ $j$ ของ $A$ จับคู่กับหลักที่ $i$ ของ $B$

จังหวะที่ทุกอย่างลงตัวคือบรรทัดสาม แถวของ $A$ ก็คือหลักของ $A^{\mathsf T}$ และหลักของ $B$ ก็คือแถวของ $B^{\mathsf T}$ พอเรียกชื่อใหม่ ผลรวมเดิมกลายเป็นการคูณสองตัวที่สลับที่กันพอดี โดยไม่ได้ขยับตัวเลขสักตัว

กฎนี้ถูกใช้ตรง ๆ ในหัวข้อ 7.5 ตอนยุบความเสี่ยงพอร์ตให้เหลือ $a^{\mathsf T}\Sigma a$ และในหัวข้อ 7.6 ตอนตรวจว่า Cholesky ให้ covariance ตรงตามที่สั่งไว้จริง

ขั้นที่ 8 — ตรวจกฎสลับลำดับด้วยตาราง payoff จากโจทย์เปิดเรื่อง

ตาราง payoff S จากโจทย์เปิดเรื่องมี 2 สภาวะ × 3 สินทรัพย์ ถือสินทรัพย์ 2, 6, 4 หน่วย คูณแถวกับคอลัมน์แบบหัวข้อ 3.1 ได้เงินของแต่ละสภาวะ แล้วลองกฎของขั้นที่ 7 ด้วยตัวเลขจริง

\[ \begin{aligned} S&=\begin{bmatrix}2&3&7\\1&6&5\end{bmatrix},\qquad \theta=\begin{bmatrix}2\\6\\4\end{bmatrix}\\ S^{\mathsf T}&=\begin{bmatrix}2&1\\3&6\\7&5\end{bmatrix},\qquad \theta^{\mathsf T}=\begin{bmatrix}2&6&4\end{bmatrix}\\[4pt] S\theta&=\begin{bmatrix}2(2)+3(6)+7(4)\\1(2)+6(6)+5(4)\end{bmatrix}=\begin{bmatrix}50\\58\end{bmatrix}\\[4pt] (\theta^{\mathsf T}S^{\mathsf T})_1&=2(2)+6(3)+4(7)=50\\ (\theta^{\mathsf T}S^{\mathsf T})_2&=2(1)+6(6)+4(5)=58\\ \theta^{\mathsf T}S^{\mathsf T}&=\begin{bmatrix}50&58\end{bmatrix}=(S\theta)^{\mathsf T}\\[4pt] S^{\mathsf T}\theta^{\mathsf T}&:\ (3\times2)(1\times3),\quad 2\ne1 \end{aligned} \]

Sθ คือเงินที่พอร์ตได้ในสองสภาวะ 50 กับ 58 หัวข้อ 4.3 จะไล่ทีละช่อง ตรงนี้ใช้แค่ตรวจกฎ: พลิกผลลัพธ์ต้องเท่ากับ θᵀ คูณ Sᵀ ซึ่งสลับลำดับแล้ว และได้ 50 กับ 58 เท่าเดิมจริง

บรรทัดล่างคือสิ่งที่เกิดถ้าพลิกแต่ไม่สลับลำดับ ตาราง 3 × 2 คูณแถว 1 × 3 มิติตรงกลางเป็น 2 กับ 1 คูณไม่ได้เลย กฎสลับลำดับจึงไม่ใช่ท่าจำ แต่เป็นทางเดียวที่มิติลงตัว ในโค้ดจริง numpy มักเก็บผลตอบแทนเป็นวัน × หุ้น แต่สูตรในตำราเขียนหุ้น × วัน ลืม .T ครั้งเดียว ตัวเลขความเสี่ยงเพี้ยนทั้งรายงาน

ขั้นที่ 9 — การสร้าง quadratic form และ portfolio variance

นี่คือการประยุกต์ใช้ transpose ที่สำคัญที่สุดในทฤษฎีพอร์ต โดย $\Sigma$ คือ covariance matrix ขนาด $d\times d$ และ $w$ คือ vector สัดส่วนลงทุนขนาด $d\times 1$

เงื่อนไขบังคับคือมิติทางพีชคณิตต้องประสานกัน: $w^{\mathsf T}$ ขนาด $1\times d$ คูณกับ $\Sigma$ ขนาด $d\times d$ แล้วคูณกับ $w$ ขนาด $d\times 1$ จึงจะได้ขนาด $1\times 1$ หากไม่ transpose ตัวหน้า การคูณระหว่าง $d\times 1$ กับ $d\times d$ จะผิดกฎมิติและทำงานไม่ได้ทันที

\[ \begin{aligned}\sigma_p^2 &= \sum_{i=1}^d \sum_{j=1}^d w_i \Sigma_{ij} w_j \\ &= \begin{bmatrix} w_1 & \dots & w_d \end{bmatrix} \begin{bmatrix} \sum_{j} \Sigma_{1j} w_j \\ \vdots \\ \sum_{j} \Sigma_{dj} w_j \end{bmatrix} = w^{\mathsf T}(\Sigma w) = w^{\mathsf T}\Sigma w \\[6pt] \Sigma w &= \begin{bmatrix} 0.1 & -0.0559 \\ -0.0559 & 0.5 \end{bmatrix} \begin{bmatrix} 0.6 \\ 0.4 \end{bmatrix} = \begin{bmatrix} 0.06 - 0.02236 \\ -0.03354 + 0.20 \end{bmatrix} = \begin{bmatrix} 0.03764 \\ 0.16646 \end{bmatrix} \\ \sigma_p^2 &= \begin{bmatrix} 0.6 & 0.4 \end{bmatrix} \begin{bmatrix} 0.03764 \\ 0.16646 \end{bmatrix} = 0.6(0.03764) + 0.4(0.16646) = 0.089168\end{aligned} \]

สูตรนี้เริ่มต้นจากนิยามพื้นฐานของ variance ที่เป็นผลรวมสองชั้นของ covariance ถ่วงน้ำหนักด้วยสัดส่วนการลงทุน การจะเขียนให้อยู่ในรูป matrix จำเป็นต้องแยก vector น้ำหนักออกมาทางซ้ายและขวา

vector $w$ ทางขวามือถูกคูณเข้ากับ $\Sigma$ ได้ผลลัพธ์เป็น vector ขนาด $d\times 1$ ซึ่งบอกความเสี่ยงส่วนเพิ่มของแต่ละสินทรัพย์ จากนั้นการคูณด้วย $w^{\mathsf T}$ จากทางซ้ายจะยุบผลลัพธ์ทั้งหมดให้กลายเป็น scalar ตัวเดียว

เมื่อแทนตัวเลขจริงจากตลาดสองสินทรัพย์ เราจะเห็นผลลัพธ์ที่เป็นตัวเลขชัดเจน ความเสี่ยงรวมของพอร์ตคือ 0.089168 ซึ่งต่ำกว่าการถือครองสินทรัพย์เดี่ยวเพราะมีผลกระจายความเสี่ยงจาก covariance ที่ติดลบ

สังเกตว่า Σ ในบรรทัดนี้สมมาตร ช่องแถว 1 คอลัมน์ 2 กับช่องแถว 2 คอลัมน์ 1 เป็น −0.0559 เท่ากัน พลิกแล้วได้ตัวเดิม Σᵀ = Σ เพราะ covariance ของ A กับ B เท่ากับของ B กับ A เสมอ นี่คือเครื่องตรวจฟรีที่พูดถึงตอนต้นหัวข้อ

ขั้นที่ 10 — ตรวจด้วยเลขของตัวเอง: transpose สองครั้ง และ quadratic form

สองข้อที่ทั้งเล่มใช้ต่อจากนี้ ตรวจได้ด้วยเลขชุดเดียว ข้อแรก transpose สองครั้งแล้วกลับมาที่เดิม ข้อที่สอง quadratic form ให้ผลเป็นเลขตัวเดียว ไม่ใช่ matrix

\[ \begin{aligned}B&=\begin{bmatrix}2&1\\ 0&3\end{bmatrix},\qquad B^{\mathsf T}=\begin{bmatrix}2&0\\ 1&3\end{bmatrix}\\[4pt] (B^{\mathsf T})^{\mathsf T}&=\begin{bmatrix}2&1\\ 0&3\end{bmatrix}=B\\[6pt] x&=\begin{bmatrix}1\\ 2\end{bmatrix}\\[4pt] Bx&=\begin{bmatrix}2(1)+1(2)\\ 0(1)+3(2)\end{bmatrix}=\begin{bmatrix}4\\ 6\end{bmatrix}\\[4pt] x^{\mathsf T}Bx&=\begin{bmatrix}1&2\end{bmatrix}\begin{bmatrix}4\\ 6\end{bmatrix}=1(4)+2(6)=16\end{aligned} \]

สลับ index สองครั้งก็เท่ากับไม่ได้สลับ จึงได้ $B$ กลับคืนมา ข้อนี้ทำให้เขียน $V=W^{\mathsf T}W$ แล้วไม่ต้องกังวลว่ารูปแบบจะเพี้ยน

ทางฝั่ง quadratic form: คูณจากขวาก่อนได้ $Bx=(4,6)$ แล้วคูณจากซ้ายด้วย $x^{\mathsf T}$ เหลือ $4+12=16$ ซึ่งเป็น matrix ขนาด $1\times1$ คือเลขตัวเดียว

ความกว้าง $1$ นี้มาจากการที่เราบังคับให้ index ทั้งสองฝั่งถูกบวกจนหมด จึงเป็นเหตุผลว่าทำไม portfolio variance ซึ่งเป็นความเสี่ยงก้อนเดียวจึงเขียนเป็น $w^{\mathsf T}Vw$ ได้

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

การพลิกแถวเป็นคอลัมน์ฟังดูเล็กน้อย แต่เป็นสิ่งที่ทำให้สูตรความเสี่ยงเขียนได้

ใช้ทำให้การคูณเป็นไปได้ เพราะกติกาการคูณบังคับเรื่องรูปร่าง การพลิกจึงเป็นขั้นที่ขาดไม่ได้

ใช้เขียนความเสี่ยงของพอร์ตในรูปที่สั้นที่สุด ซึ่งมีน้ำหนักปรากฏสองครั้ง ครั้งหนึ่งพลิกแล้ว

ใช้ตรวจว่า covariance ที่คำนวณมาถูกต้อง เพราะตารางนั้นต้องเท่ากับตัวพลิกของตัวเองเสมอ

คำตอบ — transpose สลับแกน แต่ค่าเดิมอยู่ครบ

คำตอบ: transpose ของตาราง 3×2 ต้องมี shape 2×3 โดย market row เป็น [1.2, 0.9, 1.5] และ quality row เป็น [0.4, 0.2, 0.7] ค่า loading ทั้งหกตัวไม่เปลี่ยน มีเพียงตำแหน่งที่สลับ

ตรวจเองใน 10 วินาที: ดูช่อง market–SPY หลัง transpose ต้องได้ 1.5 เท่ากับช่อง SPY–market เดิม แล้ว transpose ซ้ำอีกครั้งต้องกลับเป็นตาราง 3×2 เดิมทุกช่อง

ใช้ตัดสินใจ: ส่ง matrix เข้า factor-first API ได้เมื่อ shape เป็น 2×3 และ labels เดินไปพร้อมแกน ถ้าตัวเลขตรงแต่ label ไม่ตรง ให้ reject ก่อนคำนวณ exposure

ตัวอย่างที่สอง — คำตอบและวิธีเช็ก

คำตอบ: transpose สองครั้งได้ $B$ กลับคืนมา และ quadratic form ของตัวอย่างนี้เท่ากับ $16$ ซึ่งเป็นเลขตัวเดียว ไม่ใช่ตาราง

ตรวจเองใน 10 วินาที: ผลลัพธ์ของ quadratic form ต้องมีรูปร่าง $1\times1$ เสมอ ถ้าได้เป็น matrix แปลว่าลำดับการคูณผิดด้าน

ใช้ตัดสินใจ: เวลาเห็นสูตรความเสี่ยงในรูป quadratic form ให้อ่านว่ามันคือเลขตัวเดียว จึงเอาไปเทียบกับ budget ความเสี่ยงหรือใส่เป็นข้อจำกัดได้ทันที

กับดัก: reshape ไม่ใช่ transpose

reshape เพียงจัดค่าตามลำดับข้อมูลที่ถูก flatten และไม่ได้สลับ index ตามนิยาม transpose ต่อให้ shape ที่ได้ดูพอดี label ก็อาจจับกับ value ผิด การ transpose ต้องอ้างอิง $(A^{\mathsf T})_{ij}=A_{ji}$ และควรตรวจว่า transpose ซ้ำสองครั้งคืน matrix เดิม

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
ลำดับการคูณการพลิกไม่เปลี่ยนความหมายการพลิกเปลี่ยนลำดับการคูณผลคูณสองแบบให้ผลต่างกันคนละเรื่อง อันหนึ่งเป็นตัวเลข อีกอันเป็นตาราง
ในโค้ดมิติชัดเจนไลบรารีบางตัวยุบมิติที่มีขนาดหนึ่งทิ้งเงียบ ๆคำนวณผ่านแต่ผลผิด และไม่มีข้อความเตือน
ความสมมาตรตารางความเสี่ยงสมมาตรเสมอตารางที่ประมาณมาอาจไม่สมมาตรเป๊ะเพราะการปัดเลขต้องบังคับให้สมมาตรก่อนใช้ ไม่งั้นวิธีคำนวณบางอย่างจะพัง

แถวกลางคือข้อผิดพลาดที่พบบ่อยที่สุดเวลาเขียนโค้ดคำนวณความเสี่ยงครั้งแรก

สรุปที่ใช้ได้จริง

  • พลิกผลคูณต้องสลับลำดับ: (Sθ)ᵀ = θᵀSᵀ = [50 58] ส่วน Sᵀθᵀ แบบไม่สลับคูณไม่ได้เพราะมิติไม่ตรง และ covariance matrix พลิกแล้วได้ตัวเดิมเสมอ
  • transpose สลับ index ตาม $(A^{\mathsf T})_{ij}=A_{ji}$ โดยไม่เปลี่ยน element
  • shape $m\times n$ กลายเป็น $n\times m$
  • ใช้ transpose เพื่อหันข้อมูลให้ dot product และ matrix multiplication ถูกทิศ
  • reshape แบบไม่รักษา labels เป็นความเสี่ยงเชิงระบบ
  • รูปร่างของ transpose ไม่ต้องจำ: index สองตัวสลับที่ จำนวนแถวจึงกลายเป็นจำนวนคอลัมน์ตาม definition
  • quadratic form ให้ผลเป็นเลขตัวเดียว เพราะ index ทั้งสองฝั่งถูก sum จนหมด
