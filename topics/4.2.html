4.2 Building Martingales from a Random Walk

แยกสิ่งที่คาดได้ออกจากผลสะสม แล้ววัดส่วนที่เหลือด้วยขนาดความผันผวน

โต๊ะเทรดตั้งสมมติฐานล่วงหน้าว่ากำไรเฉลี่ยสุทธิต่อไม้คือ \$320 หลัง 400 ไม้ทำได้ \$165,000 จึงเกินเส้นฐาน \$37,000 ตัวเลขนี้บอกว่าฝีมือดีขึ้นแล้วหรือยัง?

เปิดคำตอบตั้งต้น

ยังสรุปไม่ได้ ต้องรู้ขนาดความผันผวนและที่มาของเส้นฐานด้วย ถ้าส่วนเบี่ยงเบนมาตรฐานต่อไม้คือ \$2,500 ภายใต้เงื่อนไขที่ทำให้ variance บวกกันได้ ส่วนเกินนี้มีขนาดเพียง 0.74 เท่าของส่วนเบี่ยงเบนมาตรฐานสะสม ไม่ใช่ผลที่หายากมาก

เราจะแยกสามขั้นซึ่งใช้สมมติฐานต่างกัน: สร้าง martingale, คำนวณ variance และประมาณความน่าจะเป็นด้วย normal distribution อย่าใช้คำว่า martingale เป็นใบอนุญาตข้ามสองขั้นหลัง

1. ลองหักส่วนที่คาดได้ในเกมเล็ก ๆ

แต่ละไม้ได้ 3 ดอลลาร์หรือเสีย 1 ดอลลาร์ด้วยโอกาสครึ่งหนึ่งอย่างเป็นอิสระ ให้ $X_i$ เป็นกำไรไม้ที่ $i$ และ $S_n$ เป็นกำไรรวมหลัง $n$ ไม้ เริ่มจาก $S_0=0$ ข้อมูล $\mathcal F_n$ รวมผลทุกไม้ที่จบแล้ว

\[ \begin{aligned} \mu&=\tfrac12(3)+\tfrac12(-1)=1\ \text{USD per trade}\\ S_1=3:\quad S_2&=6\ \text{or}\ 2\\ \mathbb E_1[S_2]&=\tfrac12(6)+\tfrac12(2)=4=S_1+1 \end{aligned} \]

กำไรดิบจึงมี drift ขึ้น ไม่ใช่ martingale แต่ถ้าตัดกำไรที่คาดไว้ไม้ละ 1 ดอลลาร์ออก จะเหลือกำไรส่วนเกิน $M_n=S_n-n$

\[ \begin{aligned} M_1&=3-1=2\\ M_2&=6-2=4\ \text{or}\ 2-2=0\\ \mathbb E_1[M_2]&=\tfrac12(4)+\tfrac12(0)=2=M_1 \end{aligned} \]

การหักเส้นฐานไม่ได้ทำให้การเล่นเสี่ยงน้อยลง มันเพียงเปลี่ยนสิ่งที่เราวัด จากกำไรทั้งหมดเป็นกำไรที่เกินส่วนซึ่งแบบจำลองคาดไว้แล้ว

2. สมมติฐานขั้นต่ำสำหรับการหัก drift

ให้ $X_i$ วัดเป็นดอลลาร์ เป็น $\mathcal F_i$-measurable และมี $\mathbb E|X_i|\lt\infty$ สมมติว่าค่าเฉลี่ยเมื่อรู้ข้อมูลก่อนเทรดไม้ที่ $i$ เป็นค่าคงที่ $\mu$ ไม่ใช่แค่ค่าเฉลี่ยเมื่อยังไม่เห็นข้อมูลเลย

\[ \begin{aligned} S_n&=\sum_{i=1}^nX_i,\qquad S_0=0\\ \mathbb E[X_i\mid\mathcal F_{i-1}]&=\mu\\ Y_i&=X_i-\mu\\ M_n&=S_n-n\mu=\sum_{i=1}^nY_i \end{aligned} \]

$Y_i$ เรียกว่า martingale difference เพราะ $\mathbb E_{i-1}[Y_i]=0$ ไม่จำเป็นต้องเป็นอิสระทุกไม้ ความผันผวนอาจเปลี่ยนตามอดีตได้ ตราบใดที่ conditional mean ยังคงตรงตามสมมติฐาน การมีเพียง $\mathbb E[X_i]=\mu$ โดยไม่ใส่เงื่อนไขยังไม่พอ

3. พิสูจน์ครบทั้งนิยามและหลายก้าว

$M_n$ คำนวณจากข้อมูลถึงเวลา $n$ จึง adapted และมีค่าเฉลี่ยสัมบูรณ์จำกัด เพราะเป็นผลรวมจำกัดของตัวแปร integrable สำหรับ $j\gt n$ ใช้ tower property เพื่อย้อนข้อมูลจาก $j-1$ กลับมาที่ $n$

\[ \begin{aligned} \mathbb E_n[X_j]&=\mathbb E_n[\mathbb E_{j-1}[X_j]]=\mu\\ \mathbb E_n[S_{n+m}]&=S_n+\sum_{j=n+1}^{n+m}\mathbb E_n[X_j]\\ &=S_n+m\mu\\ \mathbb E_n[M_{n+m}]&=S_n+m\mu-(n+m)\mu\\ &=S_n-n\mu=M_n \end{aligned} \]

$m$ ในสูตรเป็นจำนวนก้าวล่วงหน้าคงที่ ถ้า $\mu\gt0$ กระบวนการ $S_n$ เป็น submartingale; ถ้า $\mu\lt0$ เป็น supermartingale; ถ้า $\mu=0$ เป็น martingale อยู่แล้ว ส่วน $M_n$ เป็น martingale ทั้งสามกรณี

หากค่าเฉลี่ยที่ทำนายก่อนแต่ละไม้ไม่คงที่ ให้ $\mu_i=\mathbb E[X_i\mid\mathcal F_{i-1}]$ เราต้องหัก $\sum_{i=1}^n\mu_i$ ไม่ใช่ยืนยันใช้ $n\mu$ ต่อไป ค่า $\mu_i$ ต้องคำนวณได้ก่อนเห็นผลไม้ที่ $i$ และมี integrability ที่เหมาะสม

4. กลับไปที่โต๊ะเทรด: ทำนายจากข้อมูลวันนี้

สมมติ $\mu=320$ ดอลลาร์ต่อไม้เป็นค่าที่กำหนดก่อนเริ่มประเมิน และยังใช้ได้ในอนาคต ณ ไม้ที่ 400 เรารู้ว่า $S_{400}=165{,}000$ ดอลลาร์

\[ \begin{aligned} 400\mu&=128{,}000\ \text{USD}\\ M_{400}&=165{,}000-128{,}000=37{,}000\ \text{USD}\\ \mathbb E_{400}[S_{800}]&=165{,}000+400(320)\\ &=293{,}000\ \text{USD}\\ \mathbb E_{400}[S_{800}]&=\mathbb E_{400}[M_{800}]+800\mu\\ &=37{,}000+256{,}000=293{,}000\ \text{USD} \end{aligned} \]

สองวิธีต้องได้คำตอบเดียวกัน การตอบ 256,000 ดอลลาร์คือกลับไปใช้ค่าเฉลี่ยจากวันเริ่มต้นและทิ้งส่วนเกินที่เกิดขึ้นแล้ว ส่วนการคาดว่าส่วนเกินต้องเพิ่มเป็นสองเท่าก็แอบสมมติว่าค่าเฉลี่ยต่อไม้เปลี่ยน ซึ่งยังไม่ได้พิสูจน์

5. เพิ่มสมมติฐานอันดับสองเพื่อวัดความเสี่ยง

จากนี้สมมติ $\mathbb E[Y_i^2]\lt\infty$ เพิ่มเติม และให้ $\mathbb E[Y_i^2]=\sigma^2$ เท่ากันทุกไม้ หน่วยของ variance คือดอลลาร์ยกกำลังสอง แม้ $Y_i$ ไม่เป็นอิสระ แต่ martingale differences คนละเวลามี covariance ศูนย์: เมื่อ $i\lt j$, $Y_i$ รู้ค่าแล้วภายใต้ $\mathcal F_{j-1}$

\[ \begin{aligned} \mathbb E[Y_iY_j]&=\mathbb E[\mathbb E_{j-1}[Y_iY_j]]\\ &=\mathbb E[Y_i\mathbb E_{j-1}[Y_j]]=0\\ \operatorname{Var}(M_n)&=\mathbb E\left[\left(\sum_{i=1}^nY_i\right)^2\right]\\ &=\sum_{i=1}^n\mathbb E[Y_i^2]+2\sum_{i\lt j}\mathbb E[Y_iY_j]\\ &=n\sigma^2\\ \operatorname{SD}(M_n)&=\sigma\sqrt n \end{aligned} \]

ถ้า variance ของแต่ละไม้ต่างกัน สูตรทั่วไปคือผลรวม $\sum_i\mathbb E[Y_i^2]$ ไม่ใช่บังคับใช้ $n\sigma^2$ และสูตรนี้เป็น variance ก่อนเริ่มเกม การพยากรณ์ variance อนาคตเมื่อเห็นประวัติบางส่วนแล้วต้องใช้ conditional second moments ที่เหมาะกับประวัตินั้น

เช็กด้วยการแจกแจงสองไม้

ในเกม $+3/-1$ เมื่อหัก $\mu=1$ แล้ว $Y_i$ เป็น $+2/-2$ ดอลลาร์ จึงมี $\sigma^2=4$ ดอลลาร์ยกกำลังสอง ผลรวมสองไม้เป็น $4,0,0,-4$ โดยแต่ละลำดับมีโอกาส $1/4$

\[ \begin{aligned} \mathbb E[M_2]&=\tfrac14(4+0+0-4)=0\\ \operatorname{Var}(M_2)&=\tfrac14(16+0+0+16)=8\\ &=2\sigma^2 \end{aligned} \]

Variance โตสองเท่า แต่ SD โตเพียง $\sqrt2$ เท่า นี่คือเหตุผลที่ต้องแยกหน่วยและไม่บวก SD ตรง ๆ

6. จากจำนวนดอลลาร์เป็น z-score

ใช้ $\sigma=2{,}500$ ดอลลาร์ต่อไม้ ภายใต้สมมติฐานข้างต้น จะได้

\[ \begin{aligned} \operatorname{Var}(M_{400})&=400(2{,}500)^2\\ &=2.5\times10^9\ \text{USD}^2\\ \operatorname{SD}(M_{400})&=2{,}500\sqrt{400}=50{,}000\ \text{USD}\\ z&=\frac{37{,}000}{50{,}000}=0.74 \end{aligned} \]

ค่า 0.74 เป็นสัดส่วนไร้หน่วย วัดว่าส่วนเกินไกลจากค่าเฉลี่ยศูนย์เพียงใดเมื่อเทียบกับ SD แต่ยังไม่ใช่ความน่าจะเป็น จนกว่าเราจะระบุการแจกแจงหรือมีทฤษฎีประมาณที่ใช้ได้

7. ใช้ normal approximation อย่างมีเงื่อนไข

หาก increments เป็น i.i.d. มี variance จำกัด เราอาจใช้ central limit theorem ประมาณผลรวมเมื่อจำนวนไม้มากพอ ถ้า increments เป็น normal สูตรนี้ตรงตามการแจกแจงเลย สำหรับ martingale differences ที่ไม่เป็นอิสระ ต้องตรวจเงื่อนไข martingale CLT เพิ่ม เช่นการควบคุมก้าวใหญ่และพฤติกรรมของ conditional variance; คำว่า martingale อย่างเดียวไม่รับรองรูประฆัง

\[ \begin{aligned} \frac{M_{400}}{\sigma\sqrt{400}}&\approx N(0,1)\\ P(M_{400}\ge37{,}000)&\approx1-\Phi(0.74)\\ &\approx0.22965 \end{aligned} \]

ภายใต้เส้นฐานและ normal approximation นี้ มีโอกาสประมาณ 23% ที่จะเห็นส่วนเกินอย่างน้อยเท่าที่ได้ นี่เป็นโอกาสของข้อมูลภายใต้สมมติฐาน ไม่ใช่โอกาส 23% ที่เทรดเดอร์ไม่มีฝีมือ ถ้าทดสอบสองด้านโดยสนใจทั้งเกินและต่ำกว่าเส้นฐาน จะได้ประมาณ $2(0.22965)=0.45930$

8. จำนวนไม้ที่ข้ามเกณฑ์ ไม่ใช่จำนวนไม้ที่รับประกันข้อสรุป

ส่วนเกินที่สังเกตได้ต่อไม้คือ $37{,}000/400=92.5$ ดอลลาร์ สมมติใช้ค่านี้เป็นขนาดผลที่คาดว่าจะคงอยู่ และยังมี $\sigma=2{,}500$ เช่นเดิม หากต้องการให้ ส่วนเกินตามเส้นคาดหมาย แตะ 1.96 SD จะต้องมีจำนวนไม้เท่าไร?

\[ \begin{aligned} 92.5n&\ge1.96(2{,}500)\sqrt n\\ \sqrt n&\ge\frac{4{,}900}{92.5}\approx52.973\\ n&\ge2{,}806.1359\\ n_{\min}&=2{,}807 \end{aligned} \]

นี่เป็นเพียงการคำนวณระดับสัญญาณเทียบ noise ไม่ใช่การวางแผน sample size ที่กำหนด power แล้ว และไม่รับประกันว่าข้อมูลจริงจะผ่านเกณฑ์ ถ้าผลจริงเป็น 92.5 ดอลลาร์ต่อไม้ ก็แปลว่าเส้นฐาน $\mu=320$ ไม่ใช่ conditional mean จริงอีกต่อไป: ส่วนที่หักเส้นฐานเดิมจะมี drift 92.5 ดอลลาร์ต่อไม้

ห้ามเฝ้าดูผลทุกไม้แล้วหยุดทันทีเมื่อ $z\ge1.96$ พร้อมอ้างระดับนัยสำคัญเดิม การเลือกเวลาจากข้อมูลเปลี่ยนโจทย์ เช่นเดียวกับการลองหลายกลยุทธ์แล้วรายงานเฉพาะผู้ชนะ

กับดักของการสร้างเส้นฐานจากผลที่กำลังตัดสิน

ถ้าตั้ง $\widehat\mu=S_n/n$ จากข้อมูลทั้งชุด แล้วคำนวณ $S_n-n\widehat\mu$ จะได้ศูนย์โดยนิยาม ไม่ได้พิสูจน์ว่าตลาดเป็นเกมยุติธรรม และถ้าเอา $\widehat\mu$ จากปลายชุดไปหักทุกจุดก่อนหน้า ก็ใช้ข้อมูลอนาคตย้อนอดีต ทำให้ละเมิดการตีความ adapted ของ residual process

ควรกำหนดเส้นฐานจากช่วงฝึกหรือแบบจำลองก่อนการประเมิน นับต้นทุนจริง และแยกความไม่แน่นอนของค่าประมาณออกจากความผันผวนของกำไร สมมติฐาน conditional mean คงที่อาจเสียเมื่อ regime เปลี่ยน ส่วนหางหนาและ volatility clustering อาจทำให้การประมาณ normal ใช้ได้ไม่ดี แม้การหัก conditional mean ที่ถูกต้องยังสร้าง martingale ได้

ตรวจหน่วยแล้วต้องตรวจค่าที่เกิดขึ้นได้ด้วย

กลับไปเกม +3 หรือ −1 ดอลลาร์อย่างละครึ่ง ถ้าเล่น 100 ไม้และชนะ $k$ ไม้ กำไรคือ $S_{100}=3k-(100-k)=4k-100$ ดังนั้นกำไร 130 ดอลลาร์เกิดไม่ได้ เพราะจะต้องชนะ 57.5 ไม้ ใช้ตัวอย่างที่เป็นไปได้คือ 132 ดอลลาร์จากการชนะ 58 ไม้แทน

\[ \begin{aligned} M_{100}&=132-100=32\\ \operatorname{SD}(M_{100})&=2\sqrt{100}=20\\ z&=32/20=1.6 \end{aligned} \]

การประมาณปกติแบบไม่ปรับความต่อเนื่องให้หางขวาราว 5.48% แต่การนับทวินามตรง ๆ สำหรับการชนะตั้งแต่ 58 ไม้ขึ้นไปให้ราว 6.66% ความต่างนี้เตือนว่าคะแนนมาตรฐานเพียงอย่างเดียวไม่กำหนดความน่าจะเป็น และค่าที่เป็นไปไม่ได้ไม่ควรถูกนำมาเป็นผลสังเกตในโจทย์

ตรวจความเข้าใจ — ฝึกแยกสามชั้นของสมมติฐาน

  1. เกม $+3/-1$ เล่น 100 ไม้ ได้กำไร 132 ดอลลาร์ หาเส้นฐาน ส่วนเกิน SD และ z-score
  2. รู้เพียง $\mathbb E_{i-1}[X_i]=320$ และ integrability สรุปได้หรือไม่ว่า $M_n$ เป็น martingale, variance เท่ากับ $n(2{,}500)^2$, และผลรวมเป็น normal?
  3. โต๊ะเทรดเดิมควรคาดส่วนเกิน $M_{800}$ เท่าไรเมื่อรู้ $M_{400}=37{,}000$?
เฉลยและเหตุผล
  1. เส้นฐาน 100 ดอลลาร์ ส่วนเกิน 32 ดอลลาร์ SD $=2\sqrt{100}=20$ ดอลลาร์ และ $z=1.6$ การแปลงเป็น tail probability ต้องใช้การแจกแจง exact หรือประมาณเพิ่ม
  2. ถ้า adapted ด้วย สรุป martingale ได้ แต่ยังไม่มีสมมติฐาน second moment สำหรับ variance และไม่มีสมมติฐานการแจกแจงหรือ CLT สำหรับ normal
  3. 37,000 ดอลลาร์ ไม่ใช่ศูนย์และไม่ใช่ 74,000 เพราะ conditional mean ของกำไรส่วนเกินแต่ละไม้ในอนาคตเป็นศูนย์ตามแบบจำลองเดิม
JavaScript — ตรวจ variance และพื้นที่หางโดยไม่ใช้ไลบรารี
const near = (a, b, eps = 1e-8) => {
  if (Math.abs(a - b) > eps) throw new Error(`${a} != ${b}`);
};
// Simpson integration from 0 to z; this example uses z >= 0.
function normalCDF(z) {
  const n = 10000, h = z / n;
  const density = x => Math.exp(-x * x / 2) / Math.sqrt(2 * Math.PI);
  let sum = density(0) + density(z);
  for (let i = 1; i < n; i++) sum += (i % 2 ? 4 : 2) * density(i * h);
  return 0.5 + sum * h / 3;
}
const mu = 320, sigma = 2500, n = 400, total = 165000;
const excess = total - n * mu;
near(excess, 37000);
near(total + 400 * mu, 293000);
near(sigma * Math.sqrt(n), 50000);
let secondMoment = 0;
for (const a of [-2, 2]) for (const b of [-2, 2]) secondMoment += (a + b) ** 2 / 4;
near(secondMoment, 8);
const z = excess / (sigma * Math.sqrt(n));
near(z, 0.74);
near(1 - normalCDF(z), 0.22965, 0.00001);
const minimum = Math.ceil((1.96 * sigma / (excess / n)) ** 2);
near(minimum, 2807);
near(n * sigma ** 2, 2.5e9);
near(total / n, 412.5);
near(4 * 58 - 100, 132);
near((132 - 100) / (2 * Math.sqrt(100)), 1.6);
let probability = 2 ** -100;
let tail = 0;
for (let wins = 0; wins <= 100; wins++) {
  if (wins >= 58) tail += probability;
  probability *= (100 - wins) / (wins + 1);
}
near(tail, 0.0666053096036069, 1e-12);
near(1 - normalCDF(1.6), 0.0547993, 1e-6);

สรุปก่อนเดินต่อ

  • หัก conditional mean ที่รู้ก่อนแต่ละไม้จึงได้ martingale difference; การหักค่าเฉลี่ยรวมที่คำนวณภายหลังไม่ใช่สิ่งเดียวกัน
  • Martingale ไม่จำเป็นต้องมี increments อิสระ แต่การคำนวณ variance ต้องมี second moments และการใช้ normal approximation ต้องมีเงื่อนไขเพิ่ม
  • ส่วนเกินวันนี้ยังอยู่ในคำทายของวันหน้า ไม่ถูกล้างให้กลับศูนย์
  • ตัวอย่าง 400 ไม้เกินเส้นฐาน 37,000 ดอลลาร์ แต่มีขนาดเพียง 0.74 SD ยังไม่ใช่หลักฐานหนักแน่นของค่าเฉลี่ยที่เพิ่มขึ้น
  • หัวข้อ 4.3 จะทดสอบว่าการปรับขนาดเดิมพันและเลือกเวลาหยุดสามารถสร้างค่าเฉลี่ยบวกจากเกมยุติธรรมได้หรือไม่
