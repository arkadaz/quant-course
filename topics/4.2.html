4.2 Building Martingales from a Random Walk

หักกำไรที่คาดไว้แล้วออกจากกำไรสะสม ส่วนที่เหลือเป็น martingale ซึ่งวัดได้ว่าใหญ่แค่ไหนเมื่อเทียบกับความผันผวน

desk หนึ่งตั้งเส้นฐานไว้ล่วงหน้าว่ากำไรสุทธิเฉลี่ยไม้ละ \$320 และ SD ไม้ละ \$2,500 (ตัวเลขสมมติ) หลัง 400 ไม้ทำกำไรรวมได้ \$165,000 สูงกว่าเส้นฐาน \$37,000 หัวหน้าถามสองข้อ: ตัวเลขนี้เป็นหลักฐานว่าเทรดเดอร์เก่งขึ้นหรือยัง และถ้าแบบจำลองเดิมยังใช้ได้ ควรคาดกำไรรวมหลัง 800 ไม้ไว้เท่าไร

ลองตอบก่อนเปิดเฉลย

ยังไม่ใช่หลักฐาน ส่วนเกินสะสมมี SD $2{,}500\sqrt{400}=\$50{,}000$ ส่วนเกิน \$37,000 จึงมีขนาดแค่ 0.74 SD และถ้าเทรดเดอร์ไม่ได้เก่งขึ้นเลย ก็ยังมีโอกาสราว 23% ที่จะเห็นส่วนเกินขนาดนี้หรือมากกว่า ส่วนคำพยากรณ์หลัง 800 ไม้คือ \$293,000 = \$165,000 ที่มีแล้ว บวก 400 ไม้ข้างหน้าไม้ละ \$320 ส่วนเกิน \$37,000 ยังอยู่ ไม่หายกลับเป็นศูนย์และไม่โตเป็นสองเท่า

ภาพรวมก่อนลงสูตร

กำไรสะสมแบบนี้คือ random walk: ผลรวมของกำไรรายไม้ที่สุ่ม แต่ละไม้เฉลี่ย $\mu$ ดอลลาร์ ตัวมันเองไม่ใช่ martingale เพราะคาดได้ว่าจะโตไม้ละ $\mu$ ถ้าหักส่วนที่คาดได้ $n\mu$ ออก ส่วนที่เหลือ $M_n=S_n-n\mu$ คือกำไรส่วนเกิน ซึ่งเป็น martingale ตามนิยามใน filtration และ martingale (ค่าเฉลี่ยของก้าวถัดไปเมื่อรู้ข้อมูลวันนี้เท่ากับค่าวันนี้)

ทำไมต้องหัก เพราะคำถามที่มีความหมายไม่ใช่ “กำไรเท่าไร” แต่คือ “กำไรเกินที่คาดไว้เท่าไร และเกินมากพอจะไม่ใช่ความบังเอิญหรือยัง” คำถามที่สองต้องรู้ว่าส่วนเกินแกว่งได้กว้างแค่ไหน จุดสำคัญของหน้านี้คือเส้นฐานโตตาม $n$ แต่ความกว้างของการแกว่งโตตาม $\sqrt n$ เท่านั้น

รูปด้านล่างคือภาพรวม: เส้นฐานส้ม แถบน้ำเงินคือช่วงที่ส่วนเกินแกว่งได้ตามปกติ และจุดเขียวคือผลจริง หน้านี้จะพิสูจน์ว่าการหักเส้นฐานให้ martingale ใช้มันพยากรณ์ หา variance แปลงเป็น z-score แล้วถามว่าต้องเทรดกี่ไม้ถึงจะแยกฝีมือออกจากโชคได้

ศัพท์ที่ใช้ในหัวข้อนี้
Random walk
ผลรวมสะสมของก้าวสุ่ม $S_n=X_1+\cdots+X_n$ ใช้เป็นแบบจำลองของกำไรสะสม ราคา log หรือยอดเงินในเกม
Drift $\mu$
ค่าเฉลี่ยของหนึ่งก้าวเมื่อรู้อดีต คือส่วนที่คาดได้ล่วงหน้า ใช้ตั้งเส้นฐาน $n\mu$
Martingale difference
ก้าวที่เฉลี่ยศูนย์เมื่อรู้อดีต $\mathbb E_{i-1}[Y_i]=0$ ผลรวมของมันเป็น martingale ไม่จำเป็นต้องเป็นอิสระกัน
Doob decomposition
การแยกกระบวนการเป็นส่วนที่คาดได้ล่วงหน้า (ผลรวมของ drift) บวก martingale ใช้แยก “กำไรที่ควรได้อยู่แล้ว” ออกจาก “กำไรที่เป็นข่าวใหม่”
z-score
ส่วนเกินหารด้วย SD ของมัน เป็นตัวเลขไร้หน่วย ใช้เทียบว่าส่วนเกินไกลจากศูนย์กี่เท่าของการแกว่งปกติ
Normal approximation
ประมาณการแจกแจงของผลรวมจำนวนมากด้วย normal ตาม central limit theorem ใช้แปลง z-score เป็นโอกาส แต่ต้องมีเงื่อนไขของมันรองรับ
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$X_i$กำไรสุทธิของไม้ที่ $i$ดอลลาร์
$S_n$กำไรสะสมหลัง $n$ ไม้ เริ่ม $S_0=0$ดอลลาร์
$\mu$กำไรเฉลี่ยต่อไม้ตามเส้นฐานดอลลาร์ต่อไม้
$Y_i=X_i-\mu$กำไรส่วนเกินของไม้ที่ $i$ดอลลาร์
$M_n=S_n-n\mu$กำไรส่วนเกินสะสมดอลลาร์
$\sigma$SD ของกำไรต่อไม้ดอลลาร์
$z$ส่วนเกินหารด้วย SD ของส่วนเกินไม่มีหน่วย

ขั้นที่ 1 — ลองหักเส้นฐานในเกมเล็ก ๆ

ก่อนพิสูจน์ทั่วไป ดูเกมที่นับได้ด้วยมือว่าการหักเส้นฐานเปลี่ยนอะไร

โจทย์ให้อะไรมาบ้าง: แต่ละไม้ได้ \$3 หรือเสีย \$1 อย่างละครึ่ง แต่ละไม้ไม่เกี่ยวกัน เริ่ม $S_0=0$ ข้อมูล $\mathcal F_n$ คือผลทุกไม้ที่จบแล้ว

\[ \begin{aligned} \mu&=\tfrac12(3)+\tfrac12(-1)=1\\ \mathbb E_1[S_2]&=\tfrac12(6)+\tfrac12(2)=4\\ &=S_1+1\quad(S_1=3)\\ M_n&=S_n-n\\ \mathbb E_1[M_2]&=\tfrac12(4)+\tfrac12(0)=2=M_1 \end{aligned} \]

คำตอบ: กำไรดิบคาดว่าจะโตไม้ละ \$1 เสมอ จึงไม่ใช่ martingale (เป็น submartingale) แต่กำไรส่วนเกิน $M_n=S_n-n$ ไม่มี drift แล้ว เมื่อยืนที่ $M_1=2$ ค่าเฉลี่ยของไม้ถัดไปคือ 2 พอดี

ตรวจเองใน 10 วินาที: หลังหัก \$1 ทุกไม้ แต่ละไม้เหลือ $+2$ หรือ $-2$ อย่างละครึ่ง ซึ่งเฉลี่ยศูนย์ ผลรวมของก้าวที่เฉลี่ยศูนย์จึงไม่มี drift การหักเส้นฐานไม่ได้ทำให้เสี่ยงน้อยลง แค่เปลี่ยนสิ่งที่วัด จากกำไรทั้งหมดเป็นกำไรที่เกินความคาดหมาย

ขั้นที่ 2 — พิสูจน์ทั่วไป: ทำไม $S_n-n\mu$ เป็น martingale

เกมเล็กแสดงให้เห็นแล้ว ขั้นนี้แสดงว่าใช้ได้กับ random walk ทุกตัว ให้ $X_1,X_2,\ldots$ เป็น IID มีค่าเฉลี่ย $\mu$ และ $\mathbb E|X_i|$ จำกัด ตั้ง $S_n=\sum_{i=1}^nX_i$ และ $M_n=S_n-n\mu$ เราตรวจเงื่อนไข martingale แบบล่วงหน้า $m$ ไม้ตรง ๆ

\[ \begin{aligned} \mathbb E_n[M_{n+m}]&=\mathbb E_n\Big[\sum_{i=1}^{n+m}X_i\Big]-(n+m)\mu\\ &=\sum_{i=1}^{n}X_i+\mathbb E_n\Big[\sum_{i=n+1}^{n+m}X_i\Big]\\ &\qquad-(n+m)\mu\\ &=S_n+m\mu-(n+m)\mu\\ &=S_n-n\mu=M_n \end{aligned} \]

บรรทัดแรกดึง $(n+m)\mu$ ออกเพราะเป็นค่าคงที่ บรรทัดที่สองคือท่าหลัก: แบ่งผลรวมเป็นอดีตกับอนาคต อดีต $X_1,\ldots,X_n$ รู้แล้ว ณ เวลา $n$ จึงออกมาเป็นตัวเลข ส่วนอนาคต $m$ ไม้ยังสุ่ม บรรทัดที่สามใช้ว่าแต่ละไม้ในอนาคตไม่ขึ้นกับอดีต ค่าเฉลี่ยของมันเมื่อรู้อดีตจึงเป็น $\mu$ ตามเดิม รวม $m$ ไม้ได้ $m\mu$ ที่เหลือหักกันพอดี

ผลข้างเคียง: $S_n$ เองมี $\mathbb E_n[S_{n+1}]=S_n+\mu$ จึงเป็น submartingale ถ้า $\mu\gt0$ เป็น supermartingale ถ้า $\mu\lt0$ และเป็น martingale ถ้า $\mu=0$ ส่วน $M_n$ เป็น martingale ทั้งสามกรณี

สมมติฐาน IID แรงเกินจำเป็น สิ่งที่ใช้จริงมีแค่ $\mathbb E_{i-1}[X_i]=\mu$ คือค่าเฉลี่ยเมื่อรู้อดีตเป็น $\mu$ ความผันผวนเปลี่ยนตามอดีตได้ แต่ละไม้พึ่งพากันได้ ถ้าค่าเฉลี่ยก่อนแต่ละไม้ไม่คงที่ ให้ $\mu_i=\mathbb E_{i-1}[X_i]$ ซึ่งต้องคำนวณได้ก่อนเห็นผลไม้นั้น แล้วหัก $\sum_{i=1}^n\mu_i$ แทน $n\mu$ การเขียน $S_n=\sum\mu_i+M_n$ แบบนี้ชื่อ Doob decomposition: ส่วนที่คาดได้ล่วงหน้า บวกส่วนที่เป็นข่าวใหม่ล้วน ๆ

ขั้นที่ 3 — กลับไปที่ desk: พยากรณ์จากข้อมูลวันนี้

martingale ให้คำพยากรณ์ทันที: ส่วนเกินในอนาคตเฉลี่ยเท่าส่วนเกินวันนี้

โจทย์ให้อะไรมาบ้าง: $\mu=320$ ดอลลาร์ต่อไม้ ตั้งไว้ก่อนเริ่มประเมินและยังใช้ได้ต่อ ณ ไม้ที่ 400 รู้ $S_{400}=165{,}000$ ดอลลาร์

\[ \begin{aligned} M_{400}&=165{,}000-400(320)\\ &=165{,}000-128{,}000=37{,}000\\ \mathbb E_{400}[S_{800}]&=S_{400}+400(320)\\ &=165{,}000+128{,}000=293{,}000\\ \mathbb E_{400}[S_{800}]&=\mathbb E_{400}[M_{800}]+800(320)\\ &=37{,}000+256{,}000=293{,}000 \end{aligned} \]

คำตอบ: คาดกำไรรวม \$293,000 หลัง 800 ไม้ วิธีแรกบวกกำไรที่คาดของ 400 ไม้ข้างหน้าเข้ากับยอดที่มีแล้ว วิธีที่สองใช้ $\mathbb E_{400}[M_{800}]=M_{400}$ แล้วบวกเส้นฐานของ 800 ไม้ ทั้งสองต้องได้ค่าเดียวกัน

ตรวจเองใน 10 วินาที: ตอบ \$256,000 คือใช้ค่าเฉลี่ยจากวันเริ่มต้นและทิ้งส่วนเกินที่เกิดขึ้นแล้ว ตอบ \$330,000 ($2\times165{,}000$) คือแอบสมมติว่าส่วนเกินจะเกิดซ้ำ ซึ่งเท่ากับบอกว่าค่าเฉลี่ยต่อไม้ไม่ใช่ 320 แล้ว

ขั้นที่ 4 — ถ้าการโตเป็นแบบคูณ ให้หารแทนลบ

ราคาหุ้นโตเป็นเปอร์เซ็นต์ ไม่ได้โตเป็นดอลลาร์คงที่ ถ้าแต่ละงวดราคาคูณด้วยตัวคูณสุ่ม $G_i$ ที่มีค่าเฉลี่ย $g$ เมื่อรู้อดีต การหัก $n\mu$ ใช้ไม่ได้ ต้องหารด้วย $g^n$ แทน ตัวอย่าง: ราคาเริ่ม 100 คูณ 1.1 ด้วยโอกาส 0.6 หรือ 0.9 ด้วยโอกาส 0.4

\[ \begin{aligned} g&=0.6(1.1)+0.4(0.9)=1.02\\ \mathbb E_n[S_{n+1}]&=S_n\,\mathbb E_n[G_{n+1}]=1.02\,S_n\\ \mathbb E_n\Big[\frac{S_{n+1}}{1.02^{n+1}}\Big]&=\frac{1.02\,S_n}{1.02^{n+1}}\\ &=\frac{S_n}{1.02^{n}} \end{aligned} \]

บรรทัดที่สองดึง $S_n$ ออกเพราะรู้แล้ว เหลือค่าเฉลี่ยของตัวคูณ ราคาจึงคาดว่าจะโต 2% ต่องวด บรรทัดที่สามหารทั้งสองข้างด้วย $1.02^{n+1}$ ซึ่งเป็นค่าคงที่ ได้ว่า $S_n/1.02^n$ เป็น martingale แนวคิดเหมือนกับการลบเส้นฐาน แค่เปลี่ยนจาก “บวกเพิ่มคงที่” เป็น “คูณเพิ่มคงที่”

นี่คือท่าเดียวกับการคิดลดในการตั้งราคา: ใต้ความน่าจะเป็นสำหรับตั้งราคา ตัวคูณเฉลี่ยของหุ้นเท่ากับตัวคูณดอกเบี้ย $R$ พอดี ราคาที่หารด้วย $R^n$ จึงเป็น martingale ตามที่เห็นใน filtration และ martingale และในเวลาต่อเนื่อง ราคา GBM ที่มี drift μ มี $\mathbb E_t[S_{t+s}]=e^{\mu s}S_t$ จึงได้ $e^{-\mu t}S_t$ เป็น martingale ด้วยเหตุผลเดียวกัน

ขั้นที่ 5 — Variance ของส่วนเกิน: บวกกันได้เพราะไม่มีพจน์ไขว้

คำพยากรณ์ \$293,000 ยังไม่บอกว่าผลจริงจะแกว่งไปได้แค่ไหน และการตัดสินว่าส่วนเกิน \$37,000 “ใหญ่” ต้องรู้ความกว้างนี้ เพิ่มสมมติฐานว่าแต่ละไม้มี $\mathbb E[Y_i^2]=\sigma^2$ จำกัดและเท่ากัน

\[ \begin{aligned} \mathbb E[Y_iY_j]&=\mathbb E\big[Y_i\,\mathbb E_{j-1}[Y_j]\big]\\ &=\mathbb E[Y_i\cdot0]=0\\ \operatorname{Var}(M_n)&=\sum_{i=1}^n\mathbb E[Y_i^2]\\ &\qquad+2\sum_{i\lt j}\mathbb E[Y_iY_j]\\ &=n\sigma^2\\ \operatorname{SD}(M_n)&=\sigma\sqrt n \end{aligned} \]

บรรทัดแรกคือจุดที่ martingale ช่วย: เมื่อ $i\lt j$ ไม้ที่ $i$ จบไปแล้ว ณ เวลา $j-1$ จึงดึง $Y_i$ ออกนอกค่าเฉลี่ยแบบมีเงื่อนไขได้ ที่เหลือ $\mathbb E_{j-1}[Y_j]$ เป็นศูนย์ตามนิยามของ martingale difference พจน์ไขว้ทุกคู่จึงหายไป แม้แต่ละไม้ไม่ได้อิสระกันก็ตาม

บรรทัดถัดมาเป็นการกระจายกำลังสองของผลรวมตาม variance ของผลรวม เมื่อพจน์ไขว้หายหมด variance จึงบวกกันตรง ๆ ได้ $n\sigma^2$ หน่วยเป็นดอลลาร์ยกกำลังสอง ถอดรากได้ SD โตตาม $\sqrt n$ ไม่ใช่ $n$ นี่คือเหตุผลที่แถบในรูปภาพรวมบานช้ากว่าเส้นฐาน

ผลเดียวกันเขียนเป็น martingale อีกตัวได้: $\mathbb E_n[M_{n+1}^2]=M_n^2+2M_n\mathbb E_n[Y_{n+1}]+\mathbb E_n[Y_{n+1}^2]=M_n^2+\sigma^2$ เมื่อ variance ของแต่ละไม้เมื่อรู้อดีตคงที่เป็น $\sigma^2$ ดังนั้น $M_n^2-n\sigma^2$ ก็เป็น martingale ในเวลาต่อเนื่องคู่ของมันคือ $W_t^2-t$ ซึ่งเป็นแก่นของ quadratic variation

ขั้นที่ 6 — แปลงดอลลาร์เป็น z-score

ตอนนี้วัดส่วนเกินของ desk ด้วยไม้บรรทัดที่ถูกต้องได้แล้ว ใช้ $\sigma=2{,}500$ ดอลลาร์ต่อไม้

\[ \begin{aligned} \operatorname{Var}(M_{400})&=400(2{,}500)^2\\ &=2.5\times10^9\\ \operatorname{SD}(M_{400})&=2{,}500\sqrt{400}\\ &=50{,}000\\ z&=\frac{37{,}000}{50{,}000}=0.74 \end{aligned} \]

variance มีหน่วยดอลลาร์ยกกำลังสอง ($2.5\times10^9$) ถอดรากกลับเป็น 50,000 ดอลลาร์ก่อนเทียบกับส่วนเกิน z = 0.74 บอกว่าส่วนเกินอยู่ห่างจากศูนย์ไม่ถึงหนึ่ง SD ของการแกว่งตามปกติ

z ยังไม่ใช่โอกาส การแปลงเป็นโอกาสต้องรู้หรือประมาณรูปร่างการแจกแจง ซึ่งเป็นสมมติฐานชั้นที่สาม martingale ให้แค่ “ไม่มี drift” สมมติฐาน second moment ให้ “ความกว้าง” ส่วน “รูประฆัง” ต้องมาจากที่อื่น

ขั้นที่ 7 — ใช้ normal approximation อย่างรู้เงื่อนไข

ถ้ากำไรแต่ละไม้เป็น IID และมี variance จำกัด central limit theorem บอกว่าผลรวม 400 ไม้ใกล้ normal ถ้าแต่ละไม้พึ่งพากัน (เป็นแค่ martingale difference) ต้องใช้ martingale CLT ซึ่งต้องการเงื่อนไขเพิ่ม เช่นไม่มีไม้ใดใหญ่ครอบงำผลรวม และ variance เมื่อรู้อดีตรวมกันแล้วนิ่ง

\[ \begin{aligned} \frac{M_{400}}{2{,}500\sqrt{400}}&\approx N(0,1)\\ P(M_{400}\ge37{,}000)&\approx1-\Phi(0.74)\\ &\approx0.2296 \end{aligned} \]

ถ้าเส้นฐาน \$320 ถูกต้องและเทรดเดอร์ไม่มีอะไรดีขึ้นเลย ก็ยังมีโอกาสราว 23% ที่จะเห็นส่วนเกินอย่างน้อย \$37,000 ถ้าสนใจทั้งสองทาง (เกินหรือขาดเส้นฐานมากพอกัน) โอกาสเป็น $2(0.2296)\approx46\%$ นี่คือ p-value ใน hypothesis testing

ประโยคที่ถูกคือ “ถ้าไม่มีฝีมือเพิ่ม โอกาสเห็นผลแบบนี้คือ 23%” ไม่ใช่ “โอกาส 23% ที่เทรดเดอร์ไม่มีฝีมือ” สองประโยคนี้ต่างกันแบบเดียวกับที่ Bayes' theorem แยก $P(A\mid B)$ ออกจาก $P(B\mid A)$

ขั้นที่ 8 — ต้องเทรดกี่ไม้ถึงจะแยกฝีมือออกจากโชค

สมมติว่าส่วนเกินที่เห็น $37{,}000/400=92.50$ ดอลลาร์ต่อไม้เป็นของจริงและจะคงอยู่ ถามว่าเมื่อไรส่วนเกินที่คาด (โตตาม $n$) จะแซงเกณฑ์ 1.96 SD (โตตาม $\sqrt n$)

โจทย์ให้อะไรมาบ้าง: ส่วนเกินต่อไม้ 92.50 ดอลลาร์ $\sigma=2{,}500$ ดอลลาร์ เกณฑ์สองด้าน 5% ใช้ 1.96

\[ \begin{aligned} 92.5\,n&\ge1.96(2{,}500)\sqrt n\\ \sqrt n&\ge\frac{4{,}900}{92.5}\approx52.97\\ n&\ge2{,}806.1\\ n_{\min}&=2{,}807 \end{aligned} \]

คำตอบ: ประมาณ 2,807 ไม้ หรือราวเจ็ดเท่าของข้อมูลที่มี หารสองข้างด้วย $\sqrt n$ ได้บรรทัดที่สอง แล้วยกกำลังสองได้บรรทัดที่สาม ปัดขึ้นเพราะจำนวนไม้เป็นจำนวนเต็ม

ตัวเลขนี้เป็นแค่จุดที่สัญญาณที่คาดไว้แตะเส้น noise ไม่ใช่การวางแผนขนาดตัวอย่างที่กำหนด power ไว้ และไม่รับประกันว่าข้อมูลจริงจะผ่าน (ถ้าส่วนเกินจริงเป็น 92.50 พอดี โอกาสผ่านเกณฑ์ที่ 2,807 ไม้มีแค่ราวครึ่งเดียว) และถ้าส่วนเกินจริงคือ 92.50 ก็แปลว่าเส้นฐาน \$320 ไม่ใช่ค่าเฉลี่ยจริงแล้ว ส่วนที่หักเส้นฐานเดิมจะมี drift 92.50 ต่อไม้

ตรวจเองใน 10 วินาที: ที่ 2,807 ไม้ ส่วนเกินที่คาดคือ $92.5\times2{,}807\approx259{,}650$ และเกณฑ์คือ $4{,}900\sqrt{2{,}807}\approx259{,}610$ เกือบเท่ากันพอดี

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

สร้างเส้นฐานจากข้อมูลชุดที่กำลังตัดสิน: ถ้าตั้ง $\widehat\mu=S_{400}/400=412.50$ แล้วคำนวณ $S_{400}-400\widehat\mu$ จะได้ศูนย์ทุกครั้งโดยนิยาม ไม่ได้พิสูจน์อะไร และการเอาค่าเฉลี่ยของทั้งชุดไปหักทุกจุดก่อนหน้าคือการใช้ข้อมูลอนาคตย้อนอดีต ส่วนเกินที่ได้จึงไม่ adapted เส้นฐานต้องมาจากช่วงก่อนหน้าหรือแบบจำลองที่ตั้งไว้ก่อน

บวก SD แทนบวก variance: ถ้าคิดว่า SD ของ 400 ไม้คือ $400\times2{,}500=1{,}000{,}000$ จะได้ $z=0.037$ แล้วสรุปว่าไม่มีอะไรเลย ซึ่งประเมิน noise สูงไป 20 เท่า ถ้าลืมคูณ $\sqrt{400}$ เลยแล้วใช้ 2,500 จะได้ $z=14.8$ แล้วสรุปว่าเก่งมาก ทั้งสองทางผิด คำตอบที่ถูกคือ 50,000

เฝ้าดูทุกไม้แล้วหยุดเมื่อผ่าน: ถ้าคำนวณ z ใหม่ทุกไม้แล้วประกาศความสำเร็จทันทีที่ $z\ge1.96$ โอกาสที่ desk ไม่มีฝีมือจะ “ผ่าน” สักครั้งระหว่างทางสูงกว่า 2.5% มาก เพราะการเลือกเวลาหยุดจากข้อมูลเปลี่ยนโจทย์ เรื่องเดียวกับการลองหลายกลยุทธ์แล้วรายงานเฉพาะตัวที่ดีที่สุดใน multiple testing ส่วนการเลือกเวลาหยุดในเกมยุติธรรมเป็นหัวข้อของ ระบบเดิมพัน martingale

ใช้ normal กับค่าที่เกิดได้ไม่กี่ค่า: เกม $+3/-1$ เล่น 100 ไม้ ชนะ 58 ไม้ได้กำไร $3(58)-42=132$ ส่วนเกิน $132-100=32$ SD $2\sqrt{100}=20$ ได้ $z=1.6$ normal ให้หางขวาราว 5.48% แต่นับ binomial ตรง ๆ (ชนะตั้งแต่ 58 ไม้) ได้ราว 6.66% ต่างกันกว่าหนึ่งในห้า เพราะผลรวมขึ้นทีละ 4 ดอลลาร์ ไม่ต่อเนื่อง

ใช้ทำอะไรบนโต๊ะจริง

การหักส่วนที่คาดได้ออกก่อนตัดสินคือหัวใจของการประเมินผลงาน: ผลตอบแทนเกินดัชนี กำไรเกิน carry ที่คาดไว้ หรือผลตอบแทนที่เหลือหลังหักส่วนที่อธิบายด้วย factor (factor PnL และ idiosyncratic PnL) ทุกตัวคือ $M_n$ ในหน้านี้ และคำถามต่อไปเหมือนกันทุกครั้ง: ส่วนเกินนี้ห่างจากศูนย์กี่ SD และ SD นั้นโตตาม $\sqrt n$ ทำให้ desk ส่วนใหญ่ต้องมีข้อมูลหลายปีก่อนจะแยกฝีมือออกจากโชคได้

โจทย์ตรวจความเข้าใจ

1. เกม $+3/-1$ เล่น 100 ไม้ได้กำไร 132 ดอลลาร์ จงหาเส้นฐาน ส่วนเกิน SD ของส่วนเกิน และ z-score

เฉลย

$\mu=1$ เส้นฐาน $100\times1=100$ ส่วนเกิน $132-100=32$ แต่ละไม้หลังหักเส้นฐานเป็น $\pm2$ จึง $\sigma=2$ และ SD ของส่วนเกิน $2\sqrt{100}=20$ ได้ $z=32/20=1.6$ การแปลง z เป็นโอกาสต้องใช้ binomial ตรง ๆ (ราว 6.66%) หรือยอมรับความคลาดเคลื่อนของ normal (ราว 5.48%)

2. รู้เพียงว่า $\mathbb E_{i-1}[X_i]=320$ และกำไรแต่ละไม้มีขนาดเฉลี่ยจำกัด สรุปได้หรือไม่ว่า (ก) $M_n$ เป็น martingale (ข) variance ของ $M_n$ คือ $n(2{,}500)^2$ (ค) $M_n$ ใกล้ normal

เฉลย

(ก) ได้ เพราะเงื่อนไข martingale ต้องการแค่ค่าเฉลี่ยเมื่อรู้อดีตกับ integrability (ข) ไม่ได้ ยังไม่มีสมมติฐานว่า $\mathbb E[Y_i^2]=2{,}500^2$ ทุกไม้ (ค) ไม่ได้ ต้องมี CLT ที่เงื่อนไขครบ สามข้อนี้คือสามชั้นของสมมติฐานที่แยกกัน

3. desk เดิมรู้ $M_{400}=37{,}000$ ควรคาด $M_{800}$ เท่าไร และ SD ของ $M_{800}-M_{400}$ เมื่อมองจากวันนี้เท่าไร

เฉลย

คาด $\mathbb E_{400}[M_{800}]=M_{400}=37{,}000$ ไม่ใช่ศูนย์และไม่ใช่ 74,000 ส่วนที่ยังสุ่มคือ 400 ไม้ข้างหน้า ซึ่งมี SD $2{,}500\sqrt{400}=50{,}000$ ดอลลาร์ ช่วงราว ±1.96 SD รอบ 37,000 จึงกว้างตั้งแต่ประมาณ −61,000 ถึง 135,000

คำนวณซ้ำด้วย JavaScript

โค้ดคำนวณส่วนเกิน คำพยากรณ์ z-score พื้นที่หาง และจำนวนไม้ที่ต้องใช้ แล้วนับ binomial ตรง ๆ ของเกม $+3/-1$

เปิดดูโค้ด 
// standard normal CDF by Simpson integration (z >= 0)
function Phi(z) {
  const n = 10000, h = z / n;
  const f = x => Math.exp(-x * x / 2) / Math.sqrt(2 * Math.PI);
  let s = f(0) + f(z);
  for (let i = 1; i < n; i++) s += (i % 2 ? 4 : 2) * f(i * h);
  return 0.5 + s * h / 3;
}
const mu = 320, sigma = 2500, n = 400, total = 165000;
const excess = total - n * mu;                     // 37000
const forecast800 = total + 400 * mu;              // 293000
const sd = sigma * Math.sqrt(n);                   // 50000
const z = excess / sd;                             // 0.74
const tail = 1 - Phi(z);                           // 0.2296
const nMin = Math.ceil((1.96 * sigma / (excess / n)) ** 2); // 2807
// +2/-2 game after removing the baseline: variance after two trades
let v2 = 0;
for (const a of [-2, 2]) for (const b of [-2, 2]) v2 += (a + b) ** 2 / 4; // 8
// +3/-1 game, 100 trades: exact P(wins >= 58)
let pr = 2 ** -100, exact = 0;
for (let w = 0; w <= 100; w++) {
  if (w >= 58) exact += pr;
  pr *= (100 - w) / (w + 1);
}
console.log({excess, forecast800, sd, z, tail, nMin, v2,
  exact, normal: 1 - Phi(1.6)});              // exact 0.0666, normal 0.0548

สิ่งที่ควรตอบได้หลังอ่าน

  • Random walk ที่มี drift ไม่ใช่ martingale แต่ $S_n-n\mu$ เป็น โดยต้องใช้แค่ $\mathbb E_{i-1}[X_i]=\mu$ ถ้า drift เปลี่ยนตามเวลาให้หัก $\sum\mu_i$ ถ้าโตแบบคูณให้หารด้วย $g^n$
  • ส่วนเกินวันนี้คือคำพยากรณ์ของส่วนเกินในอนาคต desk ที่เกิน \$37,000 ที่ 400 ไม้ควรคาด \$293,000 ที่ 800 ไม้
  • พจน์ไขว้ของ martingale difference เป็นศูนย์ variance จึงโตตาม $n$ และ SD โตตาม $\sqrt n$ ส่วน $M_n^2-n\sigma^2$ ก็เป็น martingale
  • \$37,000 เท่ากับ 0.74 SD และมีโอกาสราว 23% ภายใต้เส้นฐาน ต้องใช้ราว 2,807 ไม้ถ้าสัญญาณจริงคือ \$92.50 ต่อไม้
  • Martingale ให้ “ไม่มี drift” เท่านั้น ความกว้างต้องใช้ second moment และรูปร่างต้องใช้ CLT หรือการนับตรง ๆ

หน้าถัดไป ระบบเดิมพัน martingale ถามคำถามที่นักพนันถามมาหลายร้อยปี: ถ้าเกมยุติธรรม แต่เราเลือกขนาดเดิมพันและเวลาหยุดเองจากผลที่เห็น จะสร้างกำไรเฉลี่ยที่เป็นบวกได้หรือไม่
