4.2 Transpose

พลิกแถวเป็นคอลัมน์เพื่อเปลี่ยนมุมมอง

ตารางที่นั่งมีแถวเป็นชื่อนักเรียนและคอลัมน์เป็นวิชา ถ้าอยากถามว่า “วิชานี้มีใครบ้าง” ต้องหมุนมุมมองอย่างไรโดยไม่เปลี่ยนชื่อหรือคะแนน?

เฉลย: ค่าทุกตัวยังเดิม แต่ช่องแถว 2 คอลัมน์ 3 ย้ายไปแถว 3 คอลัมน์ 2

transpose คือการสลับแถวกับคอลัมน์ของ matrix ใช้เปลี่ยนบทบาท input กับ output หรือจัด vector ให้วางด้านที่คูณได้

transpose ไม่ได้สับไพ่ มันแค่หันสมุด 90 องศา งานจริงใช้มันเขียน quadratic form และตรวจทิศทางของข้อมูลใน regression หรือ optimization

ที่มาที่ไป: การพลิกที่ทำให้สูตรความเสี่ยงเขียนได้

การสลับแถวกับคอลัมน์ฟังดูเหมือนเรื่องเล็กที่สุดในบทนี้ แต่ถ้าไม่มีมัน สูตรความเสี่ยงของพอร์ตเขียนไม่ได้เลย

เหตุผลอยู่ที่กติกาการคูณ ซึ่งบังคับเรื่องรูปร่างอย่างเคร่งครัด น้ำหนักพอร์ตที่เขียนเป็นคอลัมน์ จะคูณกับตารางความเสี่ยงแล้วได้คอลัมน์ออกมา ซึ่งยังไม่ใช่ตัวเลขตัวเดียวที่เราต้องการ

การพลิกน้ำหนักให้เป็นแถวก่อนแล้วคูณอีกครั้ง คือขั้นตอนที่ยุบทุกอย่างเหลือตัวเลขตัวเดียว ซึ่งเป็นเหตุผลที่น้ำหนักปรากฏสองครั้งในสูตร โดยครั้งหนึ่งพลิกแล้ว

นอกจากนั้นมันยังให้เครื่องตรวจฟรี เพราะตารางความเสี่ยงต้องเท่ากับตัวพลิกของตัวเองเสมอ

ความเป็นมา: กำเนิด transpose จากการสลับดัชนีสู่ quadratic form

Arthur Cayley เป็นผู้นิยาม transpose อย่างเป็นทางการในบทความปี 1858 เรื่องทฤษฎี matrix ก่อนหน้านั้น นักคณิตศาสตร์รุ่นก่อนหน้าอย่าง Joseph-Louis Lagrange และ Carl Friedrich Gauss ต้องศึกษา quadratic form โดยเขียนเครื่องหมายผลรวมสองชั้นยาวเหยียด และต้องคอยสลับดัชนี ด้วยมือทุกครั้งที่ต้องการวิเคราะห์สมมาตร

Cayley มองเห็นว่าการสลับแถวเป็นคอลัมน์คือการแปลงเชิงพีชคณิตที่เป็นเอกเทศ การใส่สัญลักษณ์ transpose ทำให้เกิดกฎความสัมพันธ์สำคัญอย่าง ซึ่งช่วยให้การคำนวณในระบบหลายมิติง่ายขึ้นอย่างมหาศาล

ในโลกการเงินเชิงปริมาณ Harry Markowitz ในปี 1952 ได้นำ transpose มาใช้นิยาม portfolio variance ในรูป หากไม่มี transpose เราจะไม่สามารถเชื่อม vector น้ำหนักพอร์ตเข้ากับ covariance matrix เพื่อยุบตัวเลขความเสี่ยงออกมาเป็นscalarค่าเดียวได้เลย

การสร้าง quadratic form และ portfolio variance

นี่คือการประยุกต์ใช้ transpose ที่สำคัญที่สุดในทฤษฎีพอร์ต โดย คือ covariance matrix ขนาด และ คือ vector สัดส่วนลงทุนขนาด

เงื่อนไขบังคับคือมิติทางพีชคณิตต้องประสานกัน: ขนาด คูณกับ ขนาด แล้วคูณกับ ขนาด จึงจะได้ขนาด หากไม่ transpose ตัวหน้า การคูณระหว่าง กับ จะผิดกฎมิติและทำงานไม่ได้ทันที

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

การพลิกแถวเป็นคอลัมน์ฟังดูเล็กน้อย แต่เป็นสิ่งที่ทำให้สูตรความเสี่ยงเขียนได้

ใช้ทำให้การคูณเป็นไปได้ เพราะกติกาการคูณบังคับเรื่องรูปร่าง การพลิกจึงเป็นขั้นที่ขาดไม่ได้

ใช้เขียนความเสี่ยงของพอร์ตในรูปที่สั้นที่สุด ซึ่งมีน้ำหนักปรากฏสองครั้ง ครั้งหนึ่งพลิกแล้ว

ใช้ตรวจว่า covariance ที่คำนวณมาถูกต้อง เพราะตารางนั้นต้องเท่ากับตัวพลิกของตัวเองเสมอ

คำตอบและวิธีเช็ก

คำตอบ — transpose สลับแกน แต่ค่าเดิมอยู่ครบ

คำตอบtranspose ของตาราง 3×2 ต้องมี shape 2×3 โดย market row เป็น [1.2, 0.9, 1.5] และ quality row เป็น [0.4, 0.2, 0.7] ค่า loading ทั้งหกตัวไม่เปลี่ยน มีเพียงตำแหน่งที่สลับ

ตรวจเองใน 10 วินาทีดูช่อง market–SPY หลัง transpose ต้องได้ 1.5 เท่ากับช่อง SPY–market เดิม แล้ว transpose ซ้ำอีกครั้งต้องกลับเป็นตาราง 3×2 เดิมทุกช่อง

ใช้ตัดสินใจ: ส่ง matrix เข้า factor-first API ได้เมื่อ shape เป็น 2×3 และ labels เดินไปพร้อมแกน ถ้าตัวเลขตรงแต่ label ไม่ตรง ให้ reject ก่อนคำนวณ exposure

ระวังตรงนี้

กับดัก: reshape ไม่ใช่ transpose

reshape เพียงจัดค่าตามลำดับข้อมูลที่ถูก flatten และไม่ได้สลับ index ตามนิยาม transpose ต่อให้ shape ที่ได้ดูพอดี label ก็อาจจับกับ value ผิด การ transpose ต้องอ้างอิง และควรตรวจว่า transpose ซ้ำสองครั้งคืน matrix เดิม

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
ลำดับการคูณการพลิกไม่เปลี่ยนความหมายการพลิกเปลี่ยนลำดับการคูณผลคูณสองแบบให้ผลต่างกันคนละเรื่อง อันหนึ่งเป็นตัวเลข อีกอันเป็นตาราง
ในโค้ดมิติชัดเจนไลบรารีบางตัวยุบมิติที่มีขนาดหนึ่งทิ้งเงียบ ๆคำนวณผ่านแต่ผลผิด และไม่มีข้อความเตือน
ความสมมาตรตารางความเสี่ยงสมมาตรเสมอตารางที่ประมาณมาอาจไม่สมมาตรเป๊ะเพราะการปัดเลขต้องบังคับให้สมมาตรก่อนใช้ ไม่งั้นวิธีคำนวณบางอย่างจะพัง
แถวกลางคือข้อผิดพลาดที่พบบ่อยที่สุดเวลาเขียนโค้ดคำนวณความเสี่ยงครั้งแรก
