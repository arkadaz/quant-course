14.7 Stochastic Volatility and the Heston Model

แบบจำลอง Heston ให้ variance ของหุ้นเดินสุ่มและถูกดึงกลับหาระดับระยะยาว ราคา option จึงขึ้นกับการกระจายของ variance ตลอดอายุและการที่มันเดินสวนทางกับหุ้น ไม่ใช่ค่าเฉลี่ยตัวเดียว

หุ้นราคา \$100 ความผันผวนตอนนี้ 30% ต่อปี แต่โต๊ะเชื่อว่ามันจะถูกดึงกลับหา 20% ด้วยความเร็ว 2 ต่อปี ดอกเบี้ย 3% ปันผล 1% ต้องตั้งราคา call ATM strike 100 อายุ 1 ปี เด็กฝึกงานเอาค่ากลางของ 30% กับ 20% คือ 25% ใส่สูตร Black–Scholes ได้ \$10.76 ราคานี้ใช้ได้ไหม ถ้าไม่ได้ ควรเป็นเท่าไร?

ลองตอบก่อนเปิดเฉลย

แพงไป \$0.33 ต่อหุ้น (3.1%) สิ่งที่ถูกดึงกลับเป็นเส้นโค้ง exponential คือ variance ไม่ใช่ความผันผวน ถ้าใช้ค่าคาดหมายของ variance เฉลี่ยตลอดปี 0.0616 เป็นตัวแทน จะได้ความผันผวน 24.82% และราคา Black–Scholes \$10.69 แต่ตัวแทนนี้ยังไม่ใช่ราคาจากแบบจำลองเต็ม ความผันผวนเองก็สุ่ม และมักขึ้นตอนหุ้นลง แบบจำลอง Heston จึงให้ \$10.43 เท่ากับ implied volatility 24.15% ส่วนต่าง \$0.26 จากราคาที่ความผันผวนเฉลี่ยมาจากความสุ่มของ variance \$0.18 และจากการเดินสวนทางกับหุ้น \$0.08

ภาพรวมก่อนลงสูตร

หน้าของ volatility smile และ ผืนความผันผวน แสดงว่าตลาดไม่ได้ใช้ความผันผวนตัวเดียว put strike ต่ำแพงกว่า (skew) และแต่ละอายุมีระดับของตัวเอง (term structure) สูตร Black–Scholes ถือ $\sigma$ คงที่ จึงสร้างทั้งสองอย่างไม่ได้ ข้อมูลจริงยังบอกอีกเรื่อง: วันที่แกว่งแรงมักมาเป็นกลุ่ม (volatility clustering) และตลาดที่ร่วงมักแกว่งแรงขึ้น หน้านี้ให้ variance ของหุ้นเป็นตัวแปรสุ่มที่มีสมการของตัวเอง ตามแบบจำลองของ Heston (1993) แล้วดูว่า term structure และ skew เกิดขึ้นเองได้อย่างไร

รูปด้านล่างคือแบบจำลองที่ทำงาน: ความผันผวนเริ่มที่ 30% ถูกดึงลงหา 20% แต่ระหว่างทางเดินสุ่ม บางเส้นพุ่งขึ้นไปเกิน 40% บางเส้นลงต่ำกว่า 10% ช่องล่างคือผลตอบแทนรายวันของเส้นสีน้ำเงิน ช่วงที่ความผันผวนสูง แท่งยาวมาเป็นกลุ่ม

ลำดับคือ เดินแรงดึงกลับด้วยมือ เขียนแบบจำลองสองสมการ หาค่าคาดหมายของ variance ตรวจเงื่อนไข Feller และวิธีจำลอง สร้างสมการตั้งราคาแล้วยุบเป็นสอง ODE ด้วย characteristic function (ภาคขยายที่อ่านทีหลังได้) แปลงกลับเป็นราคา ตรวจด้วย Monte Carlo อธิบายว่าทำไมราคาต่ำกว่า Black–Scholes ที่ความผันผวนเฉลี่ย ดู smile ที่แบบจำลองสร้าง และจบที่การปรับค่าให้ตรงตลาด ทั้งหน้าใช้ชุดตัวเลขเดียว (สมมติ ไม่ได้ปรับจากตลาดจริง): $S_0=K=100$, $T=1$ ปี, $r=3\%$, $q=1\%$, $v_0=0.09$, $\theta=0.04$, $\kappa=2$, $\xi=0.3$ และ $\rho=-0.7$

ขั้นที่ 1 — ลองด้วยมือ: variance ถูกดึงกลับทีละไตรมาส

โจทย์ให้อะไรมาบ้าง: variance วันนี้ $v_0=0.09$ (ความผันผวน 30%) ระดับระยะยาว $\theta=0.04$ (20%) ความเร็ว $\kappa=2$ ต่อปี ปิดความสุ่มไว้ก่อน กฎคือทุกช่วงเวลา $h$ variance ขยับเข้าหา $\theta$ เป็นสัดส่วน $\kappa h$ ของระยะห่าง ใช้ $h=0.25$ ปี จึง $\kappa h=0.5$

\[ \begin{aligned} v_{t+h}&=v_t+\kappa(\theta-v_t)h,\\ v_{0.25}&=0.09+2(0.04-0.09)(0.25)\\ &=0.065,\\ v_{0.5}&=0.065+2(-0.025)(0.25)\\ &=0.0525,\\ v_{0.75}&=0.0525-0.00625=0.04625,\\ v_{1}&=0.04625-0.003125\\ &=0.043125,\\ \bar v_{\rm q}&=\tfrac14\big(0.09+0.065\\ &\quad+0.0525+0.04625\big)\\ &\approx0.063438. \end{aligned} \]

คำตอบ: ระยะห่างจาก 0.04 หดครึ่งหนึ่งทุกไตรมาส 0.05, 0.025, 0.0125, 0.00625, 0.003125 ปลายปี variance เหลือ 0.043125 แต่ค่าเฉลี่ยของค่าต้นไตรมาสทั้งสี่ $\bar v_{\rm q}$ คือ 0.0634 สูงกว่าปลายปีมาก เพราะครึ่งปีแรก variance ยังสูง ขั้นค่าคาดหมายด้านล่างจะหาค่าเฉลี่ยนี้แบบแม่นยำ

ตรวจเองใน 10 วินาที: ก้าวไตรมาสหยาบไป หดครึ่งสี่ครั้งเหลือ $0.5^4=0.0625$ ของระยะเดิม ถ้าซอยเป็น 12, 52 และ 252 ก้าว ค่าปลายปีคือ 0.045608, 0.046505 และ 0.046713 ลู่เข้าหา 0.046767 ซึ่งใช้ $e^{-2}=0.1353$ (รูปข้างล่าง)

ขั้นที่ 2 — แบบจำลอง Heston: สองสมการและแรงสุ่มที่เกาะกัน

ตัวอย่างมือตัดความสุ่มทิ้ง ตอนนี้ใส่กลับ บรรทัดแรกคือ geometric Brownian motion ภายใต้ risk-neutral measure (drift $r-q$) ต่างแค่ความผันผวนคือ $\sqrt{v_t}$ ที่เปลี่ยนตามเวลา บรรทัดที่สองคือแรงดึงกลับบวกแรงสุ่มขนาด $\xi\sqrt{v_t}$ รูปรากที่สองแบบเดียวกับ Cox–Ingersoll–Ross สองบรรทัดนี้เป็นนิยามของแบบจำลอง ส่วนสามบรรทัดล่างสร้างแรงสุ่มที่มี correlation $\rho$ จากแรงอิสระสองตัวแบบ Cholesky แล้วตรวจขนาด

\[ \begin{aligned} \frac{dS_t}{S_t}&=(r-q)\,dt+\sqrt{v_t}\,dW_t^S,\\ dv_t&=\kappa(\theta-v_t)\,dt\\ &\quad+\xi\sqrt{v_t}\,dW_t^v,\\ dW_t^v&=\rho\,dW_t^S+\sqrt{1-\rho^2}\,dW_t^\perp,\\ (dW_t^v)^2&=\rho^2dt+(1-\rho^2)\,dt=dt,\\ dW_t^S\,dW_t^v&=\rho\,(dW_t^S)^2+0=\rho\,dt. \end{aligned} \]

ทำไมต้องเป็นรากที่สอง: เมื่อ $v$ เข้าใกล้ศูนย์ แรงสุ่ม $\xi\sqrt v$ เล็กลงเอง ขณะที่แรงดึง $\kappa\theta$ ยังดันขึ้น variance จึงไม่ถูกผลักลงไปติดลบ และรูปนี้เองที่ทำให้สมการตั้งราคายุบเป็น ODE ได้ หน่วยของ $\xi$ คือต่อปี เพราะ $\xi\sqrt v\,dW$ ต้องมีหน่วยเดียวกับ $dv$

สองบรรทัดล่างใช้กฎคูณของ Itô หลายตัวแปร: $(dW)^2=dt$ และ $dW^S dW^\perp=0$ เพราะอิสระกัน น้ำหนัก $\sqrt{1-\rho^2}$ เป็นตัวเดียวที่ทำให้ขนาดยังเป็น $dt$ พร้อมกับให้ correlation เท่ากับ $\rho$ ค่า $\kappa$, $\theta$, $\xi$, $\rho$ ทั้งหมดเป็นค่าภายใต้ risk-neutral measure ที่ใช้ตั้งราคา

ขั้นที่ 3 — ค่าคาดหมายของ variance: ที่ปลายทางและเฉลี่ยตลอดอายุ

ตัวอย่างมือเดินแรงดึงกลับแบบหยาบ ขั้นนี้หาคำตอบแม่นยำ เอาค่าคาดหมายทั้งสองข้างของสมการ variance พจน์สุ่มหายไปเพราะค่าคาดหมายของ Itô integral เป็นศูนย์ เหลือ ODE ธรรมดาแบบเดียวกับค่าเฉลี่ยของ Vasicek แล้วเฉลี่ยตลอดอายุเพื่อสร้างตัวแทนสำหรับเทียบราคา

\[ \begin{aligned} m(t)&=\mathbb E^{\mathbb Q}[v_t],\\ m'&=\kappa(\theta-m),\\ y&=m-\theta:\quad y'=-\kappa y,\\ m(t)&=\theta+(v_0-\theta)e^{-\kappa t},\\ \mathbb E^{\mathbb Q}[\bar v_T]&=\frac1T\int_0^T m(t)\,dt\\ &=\theta+(v_0-\theta)\,\frac{1-e^{-\kappa T}}{\kappa T},\\ m(1)&=0.04+0.05(0.135335)\\ &=0.046767,\\ \mathbb E^{\mathbb Q}[\bar v_1]&=0.04+0.05(0.432332)\\ &=0.061617,\\ \sqrt{0.061617}&=24.82\%. \end{aligned} \]

$y'=-\kappa y$ คือสมการที่คำตอบเป็น exponential: ระยะห่างจาก $\theta$ หดด้วยอัตรา $\kappa$ และหายไปครึ่งหนึ่งทุก $\ln2/\kappa=0.3466$ ปี (ราว 4.2 เดือน) สูตรค่าเฉลี่ยสะสมสลับค่าคาดหมายกับอินทิกรัลได้เพราะทั้งคู่เป็นการบวกเชิงเส้น แล้วใช้ $\int_0^Te^{-\kappa t}dt=(1-e^{-\kappa T})/\kappa$

ตัวประกอบ $(1-e^{-\kappa T})/(\kappa T)$ อยู่ระหว่าง 0 กับ 1: เข้าใกล้ 1 เมื่ออายุสั้น option สั้นจึงเห็น $v_0$ และเข้าใกล้ 0 เมื่ออายุยาว option ยาวจึงเห็น $\theta$ ที่ 1 ปี variance ปลายทาง 0.0468 แต่ค่าเฉลี่ย 0.0616 ความผันผวน 25% ของเด็กฝึกงานจึงไม่ใช่ทั้งสองค่า

ขั้นที่ 4 — term structure ที่แบบจำลองสร้างเอง

โจทย์ให้อะไรมาบ้าง: สูตรค่าเฉลี่ยสะสมที่เพิ่งได้กับชุดตัวเลขเดิม หารากของ variance เฉลี่ยที่คาด $\sqrt{\mathbb E[\bar v_T]}$ ซึ่งเป็นตัวแทนความผันผวน ไม่ใช่ implied volatility ที่อายุ 3 เดือน 1 ปี และ 5 ปี โดยใช้ $(1-e^{-0.5})/0.5=0.786939$ และ $(1-e^{-10})/10=0.099995$

\[ \begin{aligned} &T=0.25:\\ &\quad\mathbb E[\bar v]=0.04+0.05(0.786939)\\ &\qquad\approx0.079347,\quad 28.17\%,\\ &T=1:\\ &\quad\mathbb E[\bar v]\approx0.061617,\quad 24.82\%,\\ &T=5:\\ &\quad\mathbb E[\bar v]=0.04+0.05(0.099995)\\ &\qquad\approx0.045000,\quad 21.21\%. \end{aligned} \]

คำตอบ: ตัวแทนความผันผวนลดจาก 28.17% ที่ 3 เดือน เป็น 24.82% ที่ 1 ปี และ 21.21% ที่ 5 ปี คือ term structure ขาลงแบบที่ตลาดมีหลังช่วงผันผวนสูง โดยไม่ต้องใส่ความผันผวนแยกทีละอายุ $v_0$ คุมปลายสั้น $\theta$ คุมปลายยาว $\kappa$ คุมว่าเปลี่ยนจากตัวหนึ่งไปอีกตัวเร็วแค่ไหน implied volatility ATM จริงของแบบจำลองต่ำกว่าตัวเลขนี้เล็กน้อย ขั้น Jensen ด้านล่างอธิบายว่าทำไม

ตรวจเองใน 10 วินาที: ในสูตร $\kappa$ กับ $T$ มาคู่กันเป็น $\kappa T$ เสมอ $\kappa=0.5$ ที่ 4 ปีจึงให้ 24.82% เท่ากับ $\kappa=2$ ที่ 1 ปี เส้น $\kappa=0.5$ ในรูปความเร็วของแรงดึงกลับคือเส้น $\kappa=2$ ที่ยืดแกนเวลาออกสี่เท่า

ขั้นที่ 5 — เงื่อนไข Feller และการจำลองทีละวัน

ก่อนจำลองต้องรู้สองเรื่อง: variance ในสมการจริงแตะศูนย์ได้ไหม และเมื่อเดินเป็นก้าวจะกันค่าติดลบอย่างไร เรื่องแรกใช้ผลของ Feller (1951) ที่รับมาใช้โดยไม่พิสูจน์ในที่นี้: ถ้า $2\kappa\theta\ge\xi^2$ แรงดันขึ้นชนะแรงสุ่มใกล้ศูนย์ และ variance ไม่แตะศูนย์ เรื่องที่สองเรานิยามวิธีเดินแบบ full truncation ตามการจำลอง SDE แบบ Euler ส่วนสมการของ $x=\log S$ มาจาก Itô's lemma บน log ซึ่งให้ drift $r-q-\tfrac12v$

\[ \begin{aligned} 2\kappa\theta&=2(2)(0.04)=0.16,\\ \xi^2&=0.09\le0.16,\quad\xi_{\max}=0.40,\\ v^+&=\max(v_j,0),\\ x_{j+1}&=x_j+(r-q-\tfrac12v^+)h\\ &\quad+\sqrt{v^+h}\,Z_1,\\ v_{j+1}&=v_j+\kappa(\theta-v^+)h\\ &\quad+\xi\sqrt{v^+h}\,\big(\rho Z_1\\ &\qquad+\sqrt{1-\rho^2}\,Z_2\big). \end{aligned} \]

ชุดนี้ผ่าน Feller สบาย ๆ ($\xi$ ขึ้นได้ถึง $\sqrt{0.16}=0.40$) แต่ $\xi=0.6$ ไม่ผ่าน ($0.16\lt0.36$) ไม่ผ่านไม่ได้แปลว่าแบบจำลองใช้ไม่ได้ แปลว่า variance แตะศูนย์ได้แล้วเด้งกลับ ซึ่งทำให้การจำลองยากขึ้น

ในการจำลองของขั้น Monte Carlo ($h=1/252$, 50,000 เส้นทาง) ค่าดิบ $v_{j+1}$ ติดลบ 0.0045% ของก้าวทั้งที่ชุดนี้ผ่าน Feller เพราะก้าวที่มีขนาดจำกัดกระโดดข้ามศูนย์ได้ ที่ $\xi=0.6$ เป็น 3.75% ของก้าว $\max(v,0)$ ทำให้ถอดรากได้เสมอ และค่าดิบยังถูกเก็บเป็นสถานะของก้าวถัดไป

จุดที่พลาดง่ายที่สุด: $Z_1$ ตัวเดียวกันต้องอยู่ในทั้งสองบรรทัด ถ้าสุ่มตัวใหม่ให้หุ้น correlation จะหายไปเงียบ ๆ รูปเส้นทางในภาพรวมสร้างด้วยสูตรนี้ทุกก้าว

ภาคขยาย ขั้นที่ 6–8 — จาก PDE ถึง characteristic function (อ่านทีหลังได้)

ขั้นที่ 6 — สมการตั้งราคาเมื่อ variance เป็นตัวแปรที่สอง

ในพอร์ตทำซ้ำและ PDE ของ Black–Scholes ราคา option เป็นฟังก์ชันของ $S$ และ $t$ ตอนนี้ variance เปลี่ยนได้ ราคาจึงเป็น $C(t,S,v)$ ภายใต้ risk-neutral measure ราคาของสิ่งที่ซื้อขายได้ต้องโตเฉลี่ยในอัตรา $r$ จึงหา drift ของ $dC$ ด้วย Itô สองตัวแปร แล้วตั้งให้เท่ากับ $rC$

\[ \begin{aligned} dC&=C_t\,dt+C_S\,dS+C_v\,dv\\ &\quad+\tfrac12C_{SS}(dS)^2+C_{Sv}\,dS\,dv\\ &\quad+\tfrac12C_{vv}(dv)^2,\\ (dS)^2&=vS^2dt,\quad (dv)^2=\xi^2v\,dt,\\ dS\,dv&=\rho\xi vS\,dt,\\ rC&=C_t+(r-q)SC_S\\ &\quad+\kappa(\theta-v)C_v\\ &\quad+\tfrac12vS^2C_{SS}+\rho\xi vSC_{Sv}\\ &\quad+\tfrac12\xi^2vC_{vv}. \end{aligned} \]

บรรทัดที่สี่และห้ามาจากแรงสุ่มที่เกาะกันในขั้นแบบจำลอง: ส่วนสุ่มของ $dS$ คือ $S\sqrt v\,dW^S$ ยกกำลังสองได้ $S^2v\,dt$ ส่วนสุ่มของ $dv$ ยกกำลังสองได้ $\xi^2v\,dt$ และผลคูณได้ $S\sqrt v\,\xi\sqrt v\,\rho\,dt$ พจน์ที่เหลือมี $dW$ ซึ่งค่าคาดหมายเป็นศูนย์ บรรทัดสุดท้ายคือ PDE ของ Heston

เทียบกับ PDE ของ Black–Scholes มีสามพจน์ใหม่: drift ของ $v$ ความโค้งตาม $v$ และพจน์ไขว้ $\rho\xi vSC_{Sv}$ ซึ่งเป็นที่เดียวที่ $\rho$ เข้ามา ถ้า $\xi=0$ และ $v_0=\theta$ สมการกลับเป็นของ Black–Scholes

มีแหล่งสุ่มสองตัวแต่หุ้นตัวเดียว hedge ด้วยหุ้นอย่างเดียวจึงไม่พอ ต้องใช้ option อีกตัว และราคาของความเสี่ยงความผันผวนถูกรวมอยู่ใน $\kappa$, $\theta$ ของ risk-neutral measure แล้ว

ขั้นที่ 7 — characteristic function ยุบ PDE เหลือสอง ODE

PDE สองมิติแก้ด้วยกริดเชิงตัวเลขได้ แต่ต้องคำนวณหลายจุด Heston ใช้อีกทาง: หา characteristic function ของ $x_T=\log S_T$ แทนราคา โดย condition ที่สถานะปัจจุบัน $x_t=x$, $v_t=v$ มันเป็นค่าคาดหมายภายใต้ risk-neutral measure เหมือนราคา จึงทำตาม PDE เดียวกัน (ไม่มีการคิดลด และเขียนด้วย $x$) แล้วเดารูป exponential ที่เป็นเส้นตรงใน $x$ และ $v$ ถ้าเดาถูก สมการต้องยุบลงได้

\[ \begin{aligned} &f=\mathbb E^{\mathbb Q}\big[e^{iux_T}\big],\quad\tau=T-t,\\ &f_\tau=(r-q-\tfrac12v)f_x\\ &\quad+\kappa(\theta-v)f_v+\tfrac12vf_{xx}\\ &\quad+\rho\xi vf_{xv}+\tfrac12\xi^2vf_{vv},\\ &f=e^{iux+A(\tau)+B(\tau)v},\\ &\frac{f_\tau}{f}=A'+B'v,\quad\frac{f_x}{f}=iu,\\ &\frac{f_{xx}}{f}=-u^2,\quad\frac{f_v}{f}=B,\\ &\frac{f_{vv}}{f}=B^2,\quad\frac{f_{xv}}{f}=iuB,\\ &A'+B'v=iu(r-q)+\kappa\theta B\\ &\quad+v\Big[-\tfrac12(u^2+iu)\\ &\qquad+(\rho\xi iu-\kappa)B\\ &\qquad+\tfrac12\xi^2B^2\Big],\\ &A'=iu(r-q)+\kappa\theta B,\\ &B'=-\tfrac12(u^2+iu)\\ &\quad+(\rho\xi iu-\kappa)B+\tfrac12\xi^2B^2,\\ &A(0)=B(0)=0. \end{aligned} \]

ทำไม $f$ ทำตาม PDE เดียวกัน: $f$ เป็นค่าคาดหมายของฟังก์ชันของ $x_T$ เหมือนราคาที่ยังไม่คิดลด จึงไม่มีพจน์ $-rC$ และเพราะ $\tau=T-t$ นับถอยหลัง $f_t=-f_\tau$ drift ของ $x$ คือ $r-q-\tfrac12v$ ตามขั้นจำลอง และ $(dx)^2=v\,dt$, $dx\,dv=\rho\xi v\,dt$

แทนรูปที่เดาลงไป อนุพันธ์ทุกตัวหารด้วย $f$ เหลือแค่ $iu$, $-u^2$, $B$, $B^2$, $iuB$ ทั้งสองข้างเป็นเส้นตรงใน $v$ และต้องเท่ากันทุกค่าของ $v$ สัมประสิทธิ์หน้า $v^0$ และ $v^1$ จึงต้องเท่ากันทีละคู่

ผลคือสอง ODE ตัวของ $B$ (Riccati เพราะมี $B^2$) แก้ได้เองก่อน แล้ว $A$ ได้จากการอินทิเกรต $\kappa\theta B$ เงื่อนไข $A(0)=B(0)=0$ มาจาก $f=e^{iux}$ ในวันหมดอายุ

ตรวจทันที: $u=-i$ ให้ $u^2+iu=-1+1=0$ สมการของ $B$ จึงได้ $B=0$ ตลอด และ $A=(r-q)T$ นั่นคือ $f=Se^{(r-q)T}=\mathbb E^{\mathbb Q}[S_T]$ ตรงกับ forward

ขั้นที่ 8 — คำตอบของสอง ODE และการตรวจด้วยเครื่อง

สมการของ $B$ เป็น Riccati ที่มีคำตอบปิด (Heston 1993) ขั้นนี้รับคำตอบมาใช้ในรูปที่คำนวณได้เสถียร ($g$ สร้างจาก $b-d$ และใช้ $e^{-dT}$) แล้วไม่เชื่อเปล่า ๆ แต่ตรวจกับการเดินสอง ODE ด้วย RK4 ที่ $u=1$

\[ \begin{aligned} &b=\kappa-\rho\xi iu,\\ &d=\sqrt{b^2+\xi^2(u^2+iu)},\\ &g=\frac{b-d}{b+d},\\ &B=\frac{b-d}{\xi^2}\cdot\frac{1-e^{-dT}}{1-ge^{-dT}},\\ &A=iu(r-q)T\\ &\quad+\frac{\kappa\theta}{\xi^2}\Big[(b-d)T\\ &\qquad-2\log\frac{1-ge^{-dT}}{1-g}\Big],\\ &u=1:\\ &B\approx-0.230617-0.198513i,\\ &A\approx-0.011892+0.009274i. \end{aligned} \]

RK4 2,000 ก้าวจาก $\tau=0$ ถึง 1 ที่ $u=1$ ให้ $A$ และ $B$ ต่างจากสูตรปิดไม่ถึง $10^{-15}$ อีกการตรวจหนึ่ง: ที่ $u=-i$ สูตรให้ $\varphi(-i)=102.0201=100e^{0.02}$ เท่ากับ forward

รูปเดียวกันนี้มักเขียนด้วย $\cosh$ กับ $\sinh$: ตัวส่วน $\big(\cosh\tfrac{dT}2+\tfrac bd\sinh\tfrac{dT}2\big)^{2\kappa\theta/\xi^2}$ และพจน์ของ $v_0$ คือ $-(u^2+iu)v_0/(d\coth\tfrac{dT}2+b)$ ทั้งสองรูปให้ตัวเลขเดียวกันทุกหลักที่ $u=0.5$, 1 และ 3

ทำไมต้องรูป $e^{-dT}$: รูปในบทความของ Heston เองใช้ $e^{+dT}$ และ log ของจำนวนเชิงซ้อนในรูปนั้นข้ามกิ่งได้เมื่ออายุยาว ราคาจะกระโดดโดยไม่มีอะไรเตือน รูปที่ใช้ที่นี่อาศัยแนวทางของ Albrecher และคณะ (2007) เพื่อลดปัญหากิ่งของ log

ขั้นที่ 9 — จาก characteristic function เป็นราคา call

call คือขาหุ้นลบขา strike เหมือนสูตร Black–Scholes: $C=e^{-rT}\mathbb E^{\mathbb Q}[S_T\mathbf 1_{S_T\gt K}]-Ke^{-rT}\mathbb Q(S_T\gt K)$ ต้องหาสองตัวนี้จาก $\varphi$ สูตรกลับบรรทัดแรก (Gil-Pelaez) รับมาใช้จากทฤษฎี Fourier ที่หน้า Fourier และ FFT pricing สร้างเต็ม ส่วน $\varphi_1$ ของขาหุ้นได้จากการถ่วงทุกผลลัพธ์ด้วย $S_T$

\[ \begin{aligned} &\mathbb Q(x_T\gt k)=\frac12\\ &\quad+\frac1\pi\int_0^\infty\operatorname{Re}\frac{e^{-iuk}\varphi(u)}{iu}\,du,\\ &\varphi_1(u)=\frac{\mathbb E^{\mathbb Q}[S_Te^{iux_T}]}{\mathbb E^{\mathbb Q}[S_T]}=\frac{\varphi(u-i)}{\varphi(-i)},\\ &P_2\approx0.535922,\quad P_1\approx0.630706,\\ &C=S_0e^{-qT}P_1-Ke^{-rT}P_2\\ &\quad\approx62.4431-52.0083\\ &\quad\approx10.4348. \end{aligned} \]

$P_2=\mathbb Q(S_T\gt K)$ ใช้สูตรกลับกับ $\varphi$ ที่ $k=\log K$ ส่วน $P_1$ ใช้สูตรเดียวกันกับ $\varphi_1$: $e^{i(u-i)x}=e^{iux}e^{x}=e^{iux}S_T$ การแทน $u-i$ จึงเท่ากับถ่วงทุกผลลัพธ์ด้วย $S_T$ และหารด้วย $\varphi(-i)=\mathbb E[S_T]=F$ ให้น้ำหนักรวมเป็นหนึ่ง ขาหุ้นจึงเป็น $e^{-rT}FP_1=S_0e^{-qT}P_1=99.0050\times0.630706$ ขา strike คือ $97.0446\times0.535922$ $P_1$ กับ $P_2$ เล่นบทเดียวกับ $\Phi(d_1)$ และ $\Phi(d_2)$ และไม่ใช่โอกาสกำไรในโลกจริง

ตรวจสูตรกลับกับกรณีที่รู้คำตอบ: ใส่ characteristic function ของ lognormal ที่ความผันผวน 24.82% ได้ 0.482635 เท่ากับ $\Phi(d_2)$ ของ Black–Scholes ทุกหลักที่พิมพ์ อินทิกรัลคิดด้วย Simpson 3,000 ช่วงบน 0 ถึง 150 ขนาดของ $\varphi$ ที่ $u=40$ เหลือ $2.4\times10^{-6}$ ราคา \$10.4348 เท่ากับ implied volatility 24.15%

ตรวจกับชุดตัวเลขอีกชุดที่รู้คำตอบ: $\kappa=2$, $\theta=0.05$, $\xi=0.3$, $\rho=-0.7$, $v_0=0.04$, $S_0=100$, $K=80$, $T=1$, $r=5\%$ ไม่มีปันผล ได้ 25.2428 ตรงกับที่วิธี FFT ให้ทุกหลัก (เทียบกับ Black–Scholes ที่ 30% คือ 25.6146) ถ้าต้องการราคาหลาย strike พร้อมกัน วิธี FFT ของ Carr–Madan คูณราคา call ด้วย $e^{\alpha k}$ ให้อินทิเกรตได้ แล้วคำนวณ $N$ strike ในเวลาราว $N\log N$ แต่ต้องเลือก $\alpha$ และกริดให้ดี: $\alpha=0.01$ ให้ราคาเพี้ยนเป็นหลักร้อย ส่วน $\alpha$ ตั้งแต่ 0.5 ถึง 10 บนกริด $2^{10}$ จุดให้ 25.2428 เท่ากันทุกตัว

ขั้นที่ 10 — ตรวจด้วย Monte Carlo โดยมีหุ้นเป็นตัวช่วย

โจทย์ให้อะไรมาบ้าง: จำลองตามขั้นจำลองวันละก้าว ($h=1/252$) 50,000 เส้นทาง seed 14 ให้ $Y=e^{-rT}(S_T-100)^+$ และ $X=e^{-rT}S_T$ ค่าเฉลี่ยจริงของ $X$ รู้แน่นอนว่าเป็น $S_0e^{-qT}=99.0050$ ถ้าเส้นทางที่สุ่มได้ให้ $\bar X$ พลาดไป $\bar Y$ ก็พลาดไปทางเดียวกัน จึงหักส่วนที่พลาดออกด้วยความชัน $\beta$ (control variate)

\[ \begin{aligned} \bar Y&=10.5968\pm0.0645,\\ \bar X&=99.2366,\quad S_0e^{-qT}=99.0050,\\ \beta&=\frac{\operatorname{Cov}(Y,X)}{\operatorname{Var}(X)}=0.5357,\\ \hat C&=\bar Y-\beta\big(\bar X-99.0050\big)\\ &=10.5968-0.5357(0.2316)\\ &=10.4727\pm0.0313. \end{aligned} \]

คำตอบ: ค่าเฉลี่ยตรง ๆ 10.5968 ห่างจาก 10.4348 ถึง 2.5 เท่าของ SE เพราะเส้นทางชุดนี้บังเอิญให้หุ้นขึ้นมากไป (99.2366 แทน 99.0050) พอหักด้วย $\beta$ ได้ 10.4727 ± 0.0313 ห่างจากราคาสูตรกลับเพียง 1.2 SE และ SE ลดลงครึ่งหนึ่ง สองวิธีจึงสอดคล้องกัน แต่ SE วัดเฉพาะความคลาดจากการสุ่ม ยังต้องลดก้าวเวลาเพื่อตรวจ bias ของการจำลองด้วย

ตรวจเองใน 10 วินาที: $(10.4727-10.4348)/0.0313=1.21$ ส่วน $\beta=0.54$ ต้องอยู่ระหว่าง 0 กับ 1 เพราะ payoff ของ call ขึ้นตามหุ้นไม่เร็วกว่าหนึ่งต่อหนึ่ง และไม่เคยลงเมื่อหุ้นขึ้น

ขั้นที่ 11 — ทำไมราคาต่ำกว่า Black–Scholes ที่ความผันผวนเฉลี่ย

โจทย์ให้อะไรมาบ้าง: ราคา Heston 10.4348 ต่ำกว่า Black–Scholes ที่ 24.82% คือ 10.6938 อยู่ \$0.26 เริ่มจากกรณี $\rho=0$ ซึ่งคิดด้วยเหตุผลได้ ให้ $C_{\rm BS}(w)$ คือราคา Black–Scholes ที่ variance $w$ ต่อปี แล้วลองตัวอย่างสองเส้นทาง: variance เฉลี่ย 0.031617 หรือ 0.091617 ด้วยโอกาสเท่ากัน (ค่าเฉลี่ย 0.061617 เท่าเดิม)

\[ \begin{aligned} \rho=0:\ C&=\mathbb E^{\mathbb Q}\big[C_{\rm BS}(\bar v_T)\big],\\ &C_{\rm BS}(0.031617)\approx7.9683,\\ &C_{\rm BS}(0.091617)\approx12.7975,\\ &\tfrac12(7.9683+12.7975)\\ &\qquad\approx10.3829,\\ &C_{\rm BS}(0.061617)\approx10.6938,\\ &10.69382-10.51385\\ &\qquad=0.17997,\\ &10.51385-10.43478\\ &\qquad=0.07907. \end{aligned} \]

คำตอบ: บรรทัดแรกจริงเพราะเมื่อ $\rho=0$ แรงสุ่มของหุ้นไม่เกี่ยวกับเส้นทางของ variance ถ้ารู้เส้นทาง $v$ ทั้งเส้น $\log S_T$ คือผลรวมของก้อนปกติอิสระที่รู้ขนาด จึงเป็นปกติที่มี variance $\bar v_TT$ ราคาเมื่อรู้เส้นทางคือ Black–Scholes ที่ $\bar v_T$ แล้วราคาจริงคือค่าเฉลี่ยของราคาเหล่านั้น (Hull และ White 1987)

ตัวอย่างสองเส้นทางให้ 10.3829 ต่ำกว่า 10.6938 เพราะราคา ATM แทบเป็นเส้นตรงใน $\sigma=\sqrt{w}$ ซึ่งเป็นฟังก์ชันเว้าของ $w$ ค่าเฉลี่ยของฟังก์ชันเว้าต่ำกว่าฟังก์ชันของค่าเฉลี่ย (Jensen) ใน Heston จริง $\rho=0$ ให้ 10.5139 (implied 24.36%) ต่ำลง \$0.18 และค่าเฉลี่ยของ $C_{\rm BS}(\bar v_T)$ บนเส้นทาง variance ของ Monte Carlo ให้ 10.5003 ± 0.0082 อีก \$0.08 มาจาก $\rho=-0.7$: เส้นทางที่หุ้นขึ้นมักมาพร้อม variance ที่ลด ปลายขาขึ้นของ call จึงบางลง

ตรวจเองใน 10 วินาที: $0.17997+0.07907=0.25904$ เท่ากับ $10.69382-10.43478$ และ $\sqrt{0.031617}=17.78\%$, $\sqrt{0.091617}=30.27\%$ ค่ากลางของสองความผันผวนคือ 24.02% ต่ำกว่า 24.82% ซึ่งเป็นผล Jensen ตัวเดียวกัน

ขั้นที่ 13 — ปรับค่าให้ตรงตลาด: calibration และปุ่มที่แยกกันไม่ออก

Heston มีห้าตัวเลข แต่ผืนในตลาดมีราคาหลายสิบถึงหลายร้อยจุด การปรับค่า (calibration) คือหา $\Theta=(\kappa,\theta,\xi,\rho,v_0)$ ที่ทำให้ราคาจากแบบจำลอง $\hat V_i(\Theta)$ ใกล้ราคาตลาด $V_i$ ที่สุด implied volatility คือกรณีพิเศษที่ราคาหนึ่งตัวต่อปุ่มหนึ่งตัว ส่วน Heston มีราคามากกว่าปุ่ม จึงไม่มีชุดที่ตรงทุกจุด ต้องเลือกว่า “ใกล้” วัดอย่างไร

โจทย์ให้อะไรมาบ้าง: สูตรวัดความคลาดสามแบบที่ใช้กันและ RMSE ด้านล่าง น้ำหนัก $w_i$ มักให้ตามความแคบของ bid–ask (จุดที่ซื้อขายคล่องได้น้ำหนักมาก) สูตรตรงให้ option ราคาแพงครองผล สูตรสัดส่วนและสูตร log ให้ทุกจุดมีเสียงใกล้กัน และผลการปรับค่า Heston กับผืน call ของหุ้น Apple จริงชุดหนึ่ง ($\Theta$ เรียงเป็น $\kappa,\theta,\xi,\rho,v_0$ RMSE เป็นดอลลาร์)

ทางเลือกของ optimizer มีสามแบบ (รายละเอียดใน optimizer หลายตัวแปรสำหรับ calibration): กริดค้นทุกจุดได้จุดต่ำสุดของกริดแน่นอน แต่ห้าปุ่มปุ่มละ 11 ค่าคือ $11^5=161{,}051$ ชุด แต่ละชุดต้องตั้งราคาทั้งผืน Nelder–Mead ไม่ใช้อนุพันธ์ BFGS ใช้อนุพันธ์แบบ quasi-Newton จึงเร็วเมื่อผิวเรียบและโค้งหงาย แต่ติดจุดอานม้าได้และไม่รับประกันจุดต่ำสุดทั่วทั้งผิว จุดเริ่มต้นจึงสำคัญ

ตรวจเองใน 10 วินาที: ปัญหาเดียวกันเห็นได้ในชุดตัวเลขของหน้านี้: $\kappa=1$ กับ $v_0=0.0742$ ให้ variance เฉลี่ย 1 ปีเท่ากับชุดหลักพอดี (24.82%) implied volatility ATM 1 ปีต่างกันแค่ 0.32 จุด (24.15% กับ 23.83%) แต่ที่ 3 เดือนต่างกัน 1.70 จุด (27.86% กับ 26.16%) ถ้าปรับกับอายุเดียว ค่า $\kappa$ ที่ได้แทบไม่มีความหมาย ต้องใช้หลายอายุพร้อมกัน

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

เฉลี่ยความผันผวน หรือใช้ variance ปลายทาง: ค่ากลาง 25% ให้ \$10.7624 แพงไป \$0.33 ส่วน variance ปลายปี 0.0468 (21.63%) ให้ \$9.4567 ถูกไป \$0.98 ค่าที่ควรใช้เป็นตัวแทนคือค่าคาดหมายของ variance เฉลี่ยตลอดอายุ แต่ราคาที่ถูกต้องคำนวณการแจกแจงร่วมเต็ม ไม่ใช่แทนด้วยค่าเฉลี่ยแล้วหักค่าปรับตายตัว

สุ่ม $Z$ ใหม่ให้หุ้น: correlation หายไป แบบจำลองกลายเป็น $\rho=0$: call ATM เป็น 10.5139 และ put 80 ถูกตั้งที่ความผันผวน 24.81% แทน 26.93% skew หายทั้งเส้นโดยโค้ดไม่ฟ้องอะไร

ลืมปันผลใน characteristic function: พจน์ $iu(r-q)T$ ใน $A$ คือที่เดียวที่ปันผลเข้ามา ชุดตรวจที่ strike 80 ให้ 25.2428 เมื่อไม่มีปันผล แต่ถ้าหุ้นจ่าย 1% ราคาที่ถูกคือ 24.3325 ใส่ $q$ ในสูตร Black–Scholes ที่ใช้เทียบแต่ลืมใส่ใน $\varphi$ จะได้ราคาเพี้ยน \$0.91 และ implied volatility เพี้ยนตามทั้งเส้น

รากที่สองเชิงซ้อนแบบตำรา: ถ้าคิดส่วนจินตภาพเป็น $\sqrt{(|a|-\operatorname{Re}a)/2}$ ใกล้ $u=0$ ผลต่างในรากเหลือแต่เศษปัด ราคาออกมา 10.3901, 10.4124 และ 10.4236 ที่ 1,500, 3,000 และ 6,000 ช่วง แทน 10.4348 สัญญาณเตือนคือราคาเปลี่ยนตามจำนวนช่วง ทั้งที่รูปที่ถูก (ส่วนจินตภาพ $=\operatorname{Im}a/(2\operatorname{Re}\sqrt a)$) นิ่งตั้งแต่ 1,500 ช่วง

ไม่เทียบ simulation กับสิ่งที่รู้คำตอบ: ค่าเฉลี่ยตรง ๆ ของ seed 14 คือ 10.5968 ห่าง 2.5 SE ถ้าไม่ดูว่าค่าเฉลี่ยของ $e^{-rT}S_T$ คือ 99.2366 ไม่ใช่ 99.0050 จะไม่รู้ว่าเส้นทางชุดนี้เอียงขึ้น

เชื่อค่าปุ่มที่ calibrate ได้: สามวิธีบนผืนเดียวกันให้ $\rho$ ตั้งแต่ −0.22 ถึง −0.74 ถ้าเอา $\rho$ ไปใช้ตั้งราคาสัญญาที่ขึ้นกับเส้นทาง เช่น knock-in ราคาจะต่างกันมากทั้งที่ราคา vanilla เท่ากันหมด ต้องดูความนิ่งของค่าข้ามวัน และเทียบกับแบบจำลองอื่นก่อนเชื่อ

ใช้ทำอะไรบนโต๊ะจริง

ทุกเช้าโต๊ะปรับห้าตัวเลขให้ตรงกับผืนความผันผวน ตามสูตรห้าขั้น: เลือกข้อมูล (ทุกราคา หรือเฉพาะ call และ put นอกเงิน) เลือกแบบจำลอง เลือกสูตรวัดความคลาด เลือกจุดเริ่ม และเลือก optimizer วัดความคลาดเป็นจุดของ implied volatility หรือเป็นราคาหารด้วย vega ให้อยู่ในช่วง bid–ask ตั้งขอบเขต $\kappa,\theta,\xi,v_0\gt0$ และ $-1\lt\rho\lt1$ ลองจุดเริ่มหลายชุด แล้วเก็บค่าที่ได้ทุกวันเพื่อดูว่านิ่งไหม (สูตรเต็มอยู่ในขั้นตอน calibration ระดับ production)

แบบจำลองที่ปรับแล้วใช้ตั้งราคาสิ่งที่ผืนวันนี้บอกไม่ได้: สัญญาที่ขึ้นกับเส้นทาง สัญญาที่เริ่มในอนาคต และสัญญาที่จ่ายตามความผันผวนเอง ใช้แยก vega ตามอายุผ่าน $v_0$ และ $\theta$ มีแหล่งสุ่มสองตัวแต่หุ้นตัวเดียว ส่วนที่มาจาก variance จึงต้อง hedge ด้วย option อีกตัว หรือ variance swap ในหน้าถัดไป

ห้าตัวเลข fit อายุกลางถึงยาวได้ดี แต่ skew ของอายุสั้นมากในตลาดชันกว่าที่ราคาซึ่งเดินต่อเนื่องสร้างได้ เพราะในเวลาสั้นมาก ราคาเดินไปไม่ไกลถ้าไม่กระโดด โต๊ะจึงเพิ่มการกระโดด หรือใช้ local volatility ของ Dupire เมื่อต้องการให้ตรงผืนวันนี้ทุกจุด ตลาดอัตราดอกเบี้ยนิยม SABR ซึ่งเป็นแบบจำลองความผันผวนสุ่มที่มีสูตรประมาณ implied volatility ตรง ๆ จึง fit smile ของแต่ละอายุได้เร็ว

// Fourier inversion for P1 and P2, implied vols and the smile, and a full-truncation Monte Carlo check.

// Complex numbers as {re, im}.
const cx = (re, im = 0) => ({re, im});
const add = (a, b) => cx(a.re + b.re, a.im + b.im), sub = (a, b) => cx(a.re - b.re, a.im - b.im);
const mul = (a, b) => cx(a.re * b.re - a.im * b.im, a.re * b.im + a.im * b.re), scale = (k, a) => cx(k * a.re, k * a.im);
const div = (a, b) => { const d = b.re * b.re + b.im * b.im; return cx((a.re * b.re + a.im * b.im) / d, (a.im * b.re - a.re * b.im) / d); };
const cexp = a => { const m = exp(a.re); return cx(m * cos(a.im), m * sin(a.im)); };
const clog = a => cx(log(hypot(a.re, a.im)), atan2(a.im, a.re));
// Square root with Re >= 0. The imaginary part is Im(a) / (2 Re): the textbook form
// sqrt((|a| - Re a) / 2) cancels to noise when Im(a) is tiny, i.e. near u = 0 (see the pitfalls).
function csqrt(a) {
  const r = hypot(a.re, a.im);
  if (a.re >= 0) { const re = sqrt((r + a.re) / 2); return cx(re, re === 0 ? 0 : a.im / (2 * re)); }
  const im = (a.im < 0 ? -1 : 1) * sqrt((r - a.re) / 2);
  return cx(a.im / (2 * im), im);
}

function pullSteps(p, n) {

const expectedVariance = (p, t) => p.theta + (p.v0 - p.theta) * exp(-p.kappa * t);
const averageVariance = (p, T) => p.theta + (p.v0 - p.theta) * (1 - exp(-p.kappa * T)) / (p.kappa * T);
// E[exp(i u log S_T)] in the stable form (g built from b - d, and exp(-dT)).
function hestonCF(u, p) {
  const iu = mul(cx(0, 1), u), b = sub(cx(p.kappa), scale(p.rho * p.xi, iu));
  const d = csqrt(add(mul(b, b), scale(p.xi * p.xi, add(iu, mul(u, u)))));
  const g = div(sub(b, d), add(b, d)), e = cexp(scale(-p.T, d));
  const B = mul(scale(1 / (p.xi * p.xi), sub(b, d)), div(sub(cx(1), e), sub(cx(1), mul(g, e))));
  const A = add(scale((p.r - p.q) * p.T, iu), scale(p.kappa * p.theta / (p.xi * p.xi),
    sub(scale(p.T, sub(b, d)), scale(2, clog(div(sub(cx(1), mul(g, e)), sub(cx(1), g)))))));
  return {A, B, value: cexp(add(add(A, scale(p.v0, B)), scale(log(p.S), iu)))};
}
// Check: march the two Riccati ODEs with RK4 and compare with the closed form.
function riccatiRK4(u, p, steps) {
  const iu = mul(cx(0, 1), u);
  const dB = B => add(add(scale(-0.5, add(mul(u, u), iu)), mul(sub(scale(p.rho * p.xi, iu), cx(p.kappa)), B)), scale(0.5 * p.xi * p.xi, mul(B, B)));
  const dA = B => add(scale(p.r - p.q, iu), scale(p.kappa * p.theta, B));
  let A = cx(0), B = cx(0);
  const h = p.T / steps, rk = (a, b, c, d) => scale(h / 6, add(add(a, scale(2, b)), add(scale(2, c), d)));
  for (let i = 0; i < steps; i++) {
    const B2 = add(B, scale(h / 2, dB(B))), B3 = add(B, scale(h / 2, dB(B2))), B4 = add(B, scale(h, dB(B3)));
    A = add(A, rk(dA(B), dA(B2), dA(B3), dA(B4)));
    B = add(B, rk(dB(B), dB(B2), dB(B3), dB(B4)));
  }
  return {A, B};
}
// Fourier inversion: P(x_T > k) = 1/2 + (1/pi) * integral of Re[exp(-iuk) f(u) / (iu)] du by Simpson on [0, U].
// The integrand has a finite limit at u = 0, so its value there is taken just beside zero.
function tailProbability(f, k, U = 150, n = 3000) {
  if (!(Number.isInteger(n) && n >= 2 && n % 2 === 0)) throw new RangeError('Simpson needs an even number of intervals');
  const g = u => div(mul(cexp(cx(0, -u * k)), f(u)), cx(0, u)).re;
  const h = U / n;
  let s = g(1e-9) + g(U);
  for (let i = 1; i < n; i++) s += (i % 2 ? 4 : 2) * g(i * h);
  return 0.5 + s * h / 3 / PI;
}
function hestonCall(p, K) {
  checkParams(p);
  if (!(Number.isFinite(K) && K > 0)) throw new RangeError('Strike must be a positive number');
  const forward = hestonCF(cx(0, -1), p).value.re; // phi(-i) = E[S_T] = S e^{(r-q)T}
  const P2 = tailProbability(u => hestonCF(cx(u), p).value, log(K));
  const P1 = tailProbability(u => scale(1 / forward, hestonCF(cx(u, -1), p).value), log(K));
  return {P1, P2, call: p.S * exp(-p.q * p.T) * P1 - K * exp(-p.r * p.T) * P2};
}
// Black-Scholes with a dividend yield and the implied vol by bisection.
const npdf = x => exp(-0.5 * x * x) / sqrt(2 * PI);
function ncdf(x) {
  const a = abs(x);
  if (a <= 3) { let t = a, s = a; for (let n = 1; n < 200 && t > 1e-17 * s; n++) { t *= a * a / (2 * n + 1); s += t; } return x >= 0 ? 0.5 + npdf(a) * s : 0.5 - npdf(a) * s; }
  let f = a;
  for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - npdf(a) / f : npdf(a) / f;
}
function bsCall(S, K, T, r, q, sigma) {
  if (!(sigma > 0)) throw new RangeError('Volatility must be positive');
  const v = sigma * sqrt(T), d1 = (log(S / K) + (r - q + sigma * sigma / 2) * T) / v;
  return {call: S * exp(-q * T) * ncdf(d1) - K * exp(-r * T) * ncdf(d1 - v), d1, d2: d1 - v};
}
function impliedVol(price, S, K, T, r, q) {
  const low = max(S * exp(-q * T) - K * exp(-r * T), 0), high = S * exp(-q * T);
  if (!(price > low && price < high)) throw new RangeError('Price is outside the no-arbitrage range for a call');
  let lo = 1e-4, hi = 4;
  for (let i = 0; i < 100; i++) { const m = (lo + hi) / 2; if (bsCall(S, K, T, r, q, m).call > price) hi = m; else lo = m; }
  return (lo + hi) / 2;
}
// Seeded normals: mulberry32 uniforms and Box-Muller.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => { a = (a + 0x6D2B79F5) >>> 0; let t = imul(a ^ (a >>> 15), 1 | a); t = (t + imul(t ^ (t >>> 7), 61 | t)) ^ t; return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296; };
  return () => { if (spare !== null) { const z = spare; spare = null; return z; }
    const m = sqrt(-2 * log(u())), w = 2 * PI * u(); spare = m * sin(w); return m * cos(w); };
}
// Full-truncation Euler. The price step reuses z1, the same draw that drives the variance.
function monteCarlo(p, K, paths, steps, seed) {
  checkParams(p);
  if (!(Number.isInteger(paths) && paths >= 2 && Number.isInteger(steps) && steps >= 1)) throw new RangeError('paths >= 2 and steps >= 1 must be integers');
  const z = normals(seed), h = p.T / steps, c = sqrt(1 - p.rho * p.rho), disc = exp(-p.r * p.T);
  const pay = [], stock = [], mix = [];
  let negative = 0;
  for (let i = 0; i < paths; i++) {
    let x = log(p.S), v = p.v0, area = 0;
    for (let j = 0; j < steps; j++) {
      const z1 = z(), z2 = z(), vp = max(v, 0);
      x += (p.r - p.q - 0.5 * vp) * h + sqrt(vp * h) * z1;
      v += p.kappa * (p.theta - vp) * h + p.xi * sqrt(vp * h) * (p.rho * z1 + c * z2);
      area += vp * h;
      if (v < 0) negative++;
    }
    pay.push(disc * max(exp(x) - K, 0));
    stock.push(disc * exp(x));
    // The Black-Scholes price at this path's own average variance (the rho = 0 reading).
    mix.push(bsCall(p.S, K, p.T, p.r, p.q, sqrt(max(area, 1e-12) / p.T)).call);
  }
  const mean = a => a.reduce((s, x) => s + x, 0) / a.length;
  const cov = (a, b) => { const ma = mean(a), mb = mean(b); let s = 0; for (let i = 0; i < a.length; i++) s += (a[i] - ma) * (b[i] - mb); return s / (a.length - 1); };
  // Control variate: the average of disc * S_T must be S e^{-qT}; correct the call by beta times the miss.
  const beta = cov(pay, stock) / cov(stock, stock), target = p.S * exp(-p.q * p.T);
  const adjusted = pay.map((y, i) => y - beta * (stock[i] - target));
  return {plain: mean(pay), plainSe: sqrt(cov(pay, pay) / paths), stockMean: mean(stock), target, beta,
    price: mean(adjusted), se: sqrt(cov(adjusted, adjusted) / paths),
    mixing: mean(mix), mixingSe: sqrt(cov(mix, mix) / paths), negativeShare: negative / (paths * steps)};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ค่าคาดหมายของ variance ถูกดึงกลับด้วย $e^{-\kappa t}$ ค่าเฉลี่ยตลอดอายุที่คาดคือ $\theta+(v_0-\theta)(1-e^{-\kappa T})/(\kappa T)$: 0.0616 ที่ 1 ปี รากคือ 24.82% ใช้เทียบได้ แต่ยังไม่ใช่ราคา Heston
  • $v_0$ คุมอายุสั้น $\theta$ คุมอายุยาว $\kappa$ คุมความเร็ว: 28.17%, 24.82% และ 21.21% ที่ 3 เดือน 1 ปี และ 5 ปี และ variance ที่สุ่มทำให้วันแกว่งแรงมาเป็นกลุ่ม
  • Itô สองตัวแปรให้ PDE ที่มีพจน์ไขว้ $\rho\xi vSC_{Sv}$ และรูป $e^{iux+A+Bv}$ ยุบมันเป็นสอง ODE ราคา call ATM คือ \$10.4348 (implied 24.15%) และ Monte Carlo ที่มีหุ้นเป็นตัวช่วยให้ 10.4727 ± 0.0313
  • ราคาต่ำกว่า Black–Scholes ที่ความผันผวนเฉลี่ย \$0.26: \$0.18 จากความสุ่มของ variance (Jensen) และ \$0.08 จาก $\rho=-0.7$ และ $\rho$ ทำให้ smile เอียง (28.48% ถึง 20.86% จาก strike 70 ถึง 130) $\xi$ ทำให้โค้ง
  • calibration หาห้าปุ่มให้ราคาใกล้ตลาดที่สุด แต่ $\kappa$, $\xi$ และ $\rho$ แลกกันได้: สามวิธีบนผืนเดียวกันให้ $\rho$ ตั้งแต่ −0.22 ถึง −0.74 ขณะที่ $\theta$ และ $v_0$ นิ่ง
