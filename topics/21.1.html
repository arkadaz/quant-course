21.1 Finite-Difference Pricing

ตัดราคาหุ้นกับเวลาเป็นตาราง เขียนมูลค่าวันหมดอายุลงขอบขวา แล้วเดินถอยหลังทีละก้าว โดยทุกช่องคำนวณจากสามช่องข้างหน้าและเลือกค่าที่มากกว่าระหว่างใช้สิทธิ์เลยกับถือต่อ

ลูกค้าของธนาคารถือหุ้นอยู่และกลัวว่าราคาจะร่วง จึงขอซื้อ put จากโต๊ะเทรดของธนาคาร put คือสิทธิ์ที่จะขายหุ้นในราคาที่ตกลงไว้ล่วงหน้า ราคาที่ตกลงไว้นี้เรียกว่า strike ถ้าหุ้นร่วงต่ำกว่า strike ลูกค้าก็ยังขายได้ที่ strike put ตัวนี้เป็นแบบ American แปลว่าลูกค้าใช้สิทธิ์วันไหนก็ได้จนถึงวันหมดอายุ ส่วนแบบ European ใช้สิทธิ์ได้เฉพาะวันหมดอายุวันเดียว

ของที่รู้ (ตัวเลขสมมติ):

  • ราคาหุ้นวันนี้ $S_0=\$50$
  • strike $K=\$52$
  • อายุสัญญา $T=0.5$ ปี (6 เดือน)
  • ดอกเบี้ย $r=5\%$ ต่อปี (คิดแบบทบต้นต่อเนื่อง) และหุ้นไม่จ่ายปันผล
  • ความผันผวน $\sigma=30\%$ ต่อปี คือขนาดการแกว่งของผลตอบแทนหุ้นในหนึ่งปี วัดเป็น SD (standard deviation)
  • ขนาดของดีล 100 สัญญา สัญญาละ 100 หุ้น รวม $100\times100=10{,}000$ หุ้น

เด็กฝึกงานเปิด สูตร Black–Scholes ของ put แทนตัวเลขข้างบน ได้ราคา \$4.6213 ต่อหุ้น (โค้ดท้ายหน้าคำนวณซ้ำให้) แล้วเสนอราคานั้นให้ลูกค้า

เพื่อนอีกคนแย้งว่า ถ้าลูกค้าใช้สิทธิ์วันนี้ เขาขายหุ้นได้ที่ \$52 ทั้งที่ตลาดให้แค่ \$50 จึงได้กำไรทันที $K-S_0=52-50=\$2$ ต่อหุ้น เพื่อนจึงคิดว่าลูกค้าควรใช้สิทธิ์ทันที

ราคา \$4.6213 ใช้ได้ไหม และลูกค้าควรใช้สิทธิ์วันนี้หรือเปล่า?

ลองตอบก่อนเปิดเฉลย

ผิดทั้งสองข้อ สูตร Black–Scholes ตั้งราคา put แบบ European ที่ใช้สิทธิ์ได้เฉพาะวันหมดอายุ แต่ put ของลูกค้าใช้สิทธิ์ก่อนได้ และสิทธิ์นี้มีมูลค่า หน้านี้จะคำนวณทีละขั้นจนได้ราคา American put ที่ถูกคือราว \$4.7830 ต่อหุ้น ดังนั้นการขายที่ \$4.6213 ทำให้โต๊ะขาดทุน ขาดไปหุ้นละ \$0.1617 และทั้งดีลขาดไป \$1,617

\[\begin{aligned}4.7830-4.6213&=\$0.1617,\\0.1617\times10{,}000&=\$1{,}617.\end{aligned}\]

ส่วนลูกค้าที่ใช้สิทธิ์วันนี้ได้เงิน \$2 แต่ต้องทิ้งสิทธิ์ที่มีค่า \$4.7830 จึงเสียเปล่า $4.7830-2=\$2.7830$ ต่อหุ้น เมื่อเหลืออายุครึ่งปี การใช้สิทธิ์ทันทีจะคุ้มก็ต่อเมื่อหุ้นลงไปต่ำกว่าราว \$38.5 ตัวเลขนี้หน้านี้ก็จะหาให้บนตารางเช่นกัน

ภาพรวมก่อนลงสูตร

ทำไมสูตรของเด็กฝึกงานจึงใช้ไม่ได้? ราคา option ทุกตัวในโลกของ Black–Scholes ต้องทำตามสมการเดียวกัน คือ PDE ของ Black–Scholes คำว่า PDE ย่อมาจาก partial differential equation ในที่นี้คือสมการที่ผูกการเปลี่ยนของราคา option ตามราคาหุ้นกับการเปลี่ยนตามเวลาเข้าด้วยกัน สำหรับ European put สมการนี้มีสูตรปิด คือสูตรที่แทนตัวเลขแล้วได้คำตอบทันที แต่ American put ไม่มีสูตรปิด เพราะเจ้าของต้องตัดสินใจทุกวันว่าจะใช้สิทธิ์หรือถือต่อ

การตัดสินใจนั้นทำได้ง่ายถ้ารู้ว่าถือต่ออีกหนึ่งก้าวมีค่าเท่าไร แค่เทียบสองตัวเลข แล้วเลือกตัวที่มากกว่า ปัญหาคือมูลค่าของก้าวถัดไปก็ขึ้นกับก้าวที่ถัดไปอีก วันเดียวที่รู้มูลค่าแน่นอนคือวันหมดอายุ เพราะวันนั้นไม่มีอนาคตเหลือ เราจึงเริ่มที่วันหมดอายุแล้วเดินถอยหลังกลับมาหาวันนี้ทีละก้าว แบบเดียวกับ ต้นไม้ binomial ที่ไล่จากปลายกิ่งกลับมาที่ราก

ที่ที่เราใช้คำนวณเรียกว่ากริด กริดคือตารางแบบ spreadsheet คอลัมน์คือเวลา แถวคือราคาหุ้น แต่ละช่องเก็บมูลค่า put หนึ่งตัวเลข สูตรของทุกช่องอ่านค่าจากสามช่องในคอลัมน์ทางขวา ซึ่งเป็นเวลาที่อยู่ถัดไปและคำนวณไว้แล้ว ใครเคยสร้าง lattice ของอัตราดอกเบี้ย (ตารางรูปต้นไม้ของอัตราดอกเบี้ย) ใน Excel จะคุ้นกับโครงนี้

รูปด้านล่างคือกริดของหน้านี้ทั้งผืน ขอบขวาคือวันหมดอายุ ซึ่งเรารู้มูลค่าแน่นอน ขอบบนกับขอบล่างก็รู้ค่าเช่นกัน พื้นที่แดงคือบริเวณที่กริดตัดสินว่าควรใช้สิทธิ์ทันที

หน้านี้สร้างกริดทีละชิ้นตามลำดับนี้:

  • เขียนความชันและความโค้งของราคา put ด้วยผลต่างของช่องข้างเคียง แล้วได้น้ำหนักสามตัวต่อช่อง
  • เดินก้าวแรกด้วยมือ
  • ดูว่าทำไมวิธีที่ง่ายที่สุดจึงให้ตัวเลขระเบิด แล้วเปลี่ยนไปใช้วิธีที่ไม่ระเบิด
  • อ่านราคา American put เส้นที่ควรใช้สิทธิ์ และ Greeks (ตัวเลขที่บอกว่าราคา put เปลี่ยนแค่ไหนเมื่อหุ้นขยับ) จากตารางเดียวกัน
ศัพท์ที่ใช้ในหัวข้อนี้
Put, strike
put คือสิทธิ์ที่จะขายหุ้นในราคาที่ตกลงไว้ ราคานั้นเรียกว่า strike ($K$) ถ้าหุ้นราคา $S$ ต่ำกว่า strike ผู้ถือใช้สิทธิ์แล้วได้ $K-S$ ต่อหุ้น
American, European
American put ใช้สิทธิ์วันไหนก็ได้จนถึงวันหมดอายุ European put ใช้ได้เฉพาะวันหมดอายุ สิทธิ์ที่ยืดหยุ่นกว่าจึงมีราคาสูงกว่าหรือเท่ากัน
Payoff
เงินที่ผู้ถือได้ ณ วันหมดอายุ ของ put คือ $(K-S)^+=\max(K-S,\,0)$ ใช้เป็นคอลัมน์แรกที่รู้แน่นอนของกริด
PDE
partial differential equation สมการที่มีอนุพันธ์ตามหลายตัวแปร ในหน้านี้คือสมการที่ผูกการเปลี่ยนของราคา put ตามราคาหุ้นกับตามเวลาเข้าด้วยกัน
Delta, gamma
delta คือความชันของราคา put เทียบราคาหุ้น บอกว่าหุ้นขึ้น \$1 แล้ว put เปลี่ยนกี่ดอลลาร์ gamma คือความโค้ง บอกว่า delta เปลี่ยนเร็วแค่ไหน โต๊ะใช้ delta ตัดสินว่าต้องถือหุ้นกี่หุ้นเพื่อหักล้างความเสี่ยง (hedge)
Finite difference
การประมาณความชันหรือความโค้งของฟังก์ชันจากค่าที่จุดข้างเคียงบนตาราง ใช้เปลี่ยน PDE ที่มีอนุพันธ์ให้เป็นการบวกลบคูณหารที่คอมพิวเตอร์ทำได้ จำเป็นเพราะสัญญาส่วนใหญ่ไม่มีสูตรปิด
กริด (grid)
ตารางที่แถวคือราคาหุ้นห่างกันเท่า ๆ กัน และคอลัมน์คือเวลาห่างกันเท่า ๆ กัน แต่ละช่องเก็บมูลค่าสัญญาหนึ่งตัวเลข เดินจบครั้งเดียวได้มูลค่าที่ทุกราคาหุ้นพร้อมกัน
Explicit scheme
กฎที่คำนวณแต่ละช่องของคอลัมน์ใหม่จากสามช่องของคอลัมน์ที่รู้แล้วโดยตรง ง่ายที่สุดและไม่ต้องแก้ระบบสมการ แต่ถ้าก้าวเวลายาวเกินไปเมื่อเทียบกับระยะห่างของแถวราคา ความคลาดเคลื่อนจะโตจนตัวเลขระเบิด
Implicit scheme
กฎที่เขียนแต่ละช่องด้วยช่องข้างเคียงในคอลัมน์ที่ยังไม่รู้ จึงต้องแก้ระบบสมการทั้งคอลัมน์ทุกก้าว ข้อดีคือก้าวยาวแค่ไหนก็ไม่ระเบิด ข้อเสียคือความคลาดเคลื่อนตามเวลาหดช้ากว่า Crank–Nicolson
Crank–Nicolson
กฎที่เฉลี่ย explicit กับ implicit ครึ่งต่อครึ่ง ข้อดีคือความคลาดเคลื่อนตามเวลาหดเร็ว ก้าวสั้นลงครึ่งหนึ่ง ความคลาดเคลื่อนเล็กลงสี่เท่า ข้อเสียคือถ้าก้าวแรกยาว รอยหยักที่มุมของ payoff จะแกว่งค้างอยู่
Stability (ความเสถียร)
สมบัติที่ความคลาดเคลื่อนเล็ก ๆ ไม่โตขึ้นเมื่อเดินหลายก้าว ใช้เลือกขนาดก้าวเวลาของ explicit สำคัญเพราะกริดที่ไม่เสถียรให้ตัวเลขผิดโดยโปรแกรมไม่ฟ้องอะไรเลย
Early exercise boundary
เส้นของราคาหุ้นที่ถ้าหุ้นต่ำกว่าเส้นนี้ การใช้สิทธิ์ทันทีดีกว่าถือต่อ เส้นนี้ขยับตามเวลาที่เหลือ ใช้บอกลูกค้าและโต๊ะว่าเมื่อไรควรใช้สิทธิ์ ใต้เส้นนี้ put มีค่า $K-S$ พอดี delta จึงเป็น −1
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$S,\ K$ราคาหุ้น และ strikeดอลลาร์ต่อหุ้น
$T,\ \tau$อายุสัญญา และเวลาที่เหลือก่อนหมดอายุปี
$r,\ q,\ \sigma$ดอกเบี้ยต่อเนื่อง อัตราปันผลต่อเนื่อง และความผันผวนต่อปี, ต่อปี, ต่อรากที่สองของปี
$V(S,t)$มูลค่า put ที่ราคาหุ้น $S$ และเวลา $t$ดอลลาร์ต่อหุ้น
$\Delta S,\ M$ระยะห่างของแถวราคา และเลขของแถวบนสุด ($S_{\max}=M\Delta S$)ดอลลาร์, ไม่มีหน่วย
$\Delta t,\ N$ขนาดก้าวเวลา และจำนวนก้าว ($T=N\Delta t$)ปี, ไม่มีหน่วย
$V_i^n$มูลค่าที่ช่อง $S_i=i\Delta S$ และเวลา $t_n=n\Delta t$ดอลลาร์ต่อหุ้น
$a_i,\ b_i,\ c_i$น้ำหนักของช่องล่าง กลาง และบน ในหนึ่งก้าวแบบ explicitไม่มีหน่วย
$\lambda_i$$\tfrac12\sigma^2i^2\Delta t$ ส่วนของน้ำหนักที่มาจากความโค้ง ในหนึ่งก้าวที่แถว $i$ไม่มีหน่วย
$\omega$สัดส่วนของอนุพันธ์ที่อ่านจากคอลัมน์ใหม่ (0 explicit, ½ Crank–Nicolson, 1 implicit)ไม่มีหน่วย

ขั้นที่ 1 — วางกริด แล้วเริ่มจากคอลัมน์ที่รู้คำตอบแน่นอน

ก่อนคำนวณอะไร เราต้องมีที่วางตัวเลข และต้องมีจุดเริ่มที่รู้คำตอบแน่นอน จุดนั้นคือวันหมดอายุ วันนั้นผู้ถือ put ได้ $K-S$ ถ้าหุ้นต่ำกว่า strike (ขายหุ้นราคา $S$ ได้ในราคา $K$) และได้ศูนย์ถ้าหุ้นไม่ต่ำกว่า strike (ไม่มีใครอยากขายต่ำกว่าราคาตลาด) ก่อนวันหมดอายุ มูลค่ายังขึ้นกับอนาคต จึงยังไม่รู้

เราจึงทำสามอย่าง แบ่งราคาหุ้นเป็นแถวห่างกันแถวละ $\Delta S$ แบ่งเวลาเป็นก้าวละ $\Delta t$ แล้วเติมคอลัมน์วันหมดอายุก่อน สุดท้ายกำหนดค่าที่ขอบล่างและขอบบนของตาราง เพราะแถวบนสุดกับแถวล่างสุดไม่มีช่องข้างเคียงครบสามช่อง ในสูตรข้างล่าง $i$ คือเลขแถว $n$ คือเลขก้าวเวลา $M$ คือเลขของแถวบนสุด และ $N$ คือจำนวนก้าวทั้งหมด

\[ \begin{aligned} S_i&=i\,\Delta S,\quad i=0,\dots,M,\\ t_n&=n\,\Delta t,\quad \Delta t=T/N,\\ V_i^N&=(K-S_i)^+,\\ V_0^n&=K,\qquad V_M^n=0,\\ \Delta S=5&:\ M=20,\ S_M=100,\\ V^N&=17,\ 12,\ 7,\ 2,\ 0,\\ S&=35,\ 40,\ 45,\ 50,\ 55. \end{aligned} \]

บรรทัดที่ยากคือขอบล่าง $V_0^n=K$ ทำไมที่หุ้นราคาศูนย์ put จึงมีค่า $K$ ทุกเวลา? เหตุผลมาจากแบบจำลองของหุ้น คือ GBM ซึ่งบอกว่าในช่วงเวลาสั้น ๆ $dt$ หุ้นขยับ $dS=\mu S\,dt+\sigma S\,dW$ ทั้งสองพจน์มี $S$ คูณอยู่ ถ้าหุ้นแตะศูนย์ การขยับจึงเป็นศูนย์ทั้งคู่ และหุ้นอยู่ที่ศูนย์ตลอดไป ผู้ถือ American put จึงใช้สิทธิ์ทันทีแล้วได้ $K$ เต็ม ไม่มีเหตุให้รอ (ถ้าเป็น European put ต้องรอถึงวันหมดอายุ จึงมีค่าเท่ากับ $K$ ที่คิดลดกลับมาวันนี้ คือ $Ke^{-r\tau}$ โดย $\tau$ คือเวลาที่เหลือ)

ขอบบนคือราคาหุ้นที่สูงจน put แทบไม่มีค่า เราตั้งให้เป็นศูนย์ไปเลย การตั้งแบบนี้เป็นการประมาณ ขั้นที่ 10 จะลองย้ายขอบนี้ไปมาเพื่อยืนยันว่ามันอยู่ไกลพอ

กริดแรกหยาบโดยตั้งใจ เพื่อให้คิดตามด้วยมือได้ แถวละ $\Delta S=\$5$ จาก \$0 ถึง \$100 จึงมีแถวบนสุดที่ $M=100/5=20$ และก้าวละ $\Delta t=0.02$ ปี จึงมี $N=0.5/0.02=25$ ก้าวในครึ่งปี สองบรรทัดล่างคือ payoff ที่ห้าราคาซึ่งก้าวแรกด้วยมือจะใช้ เช่น $(52-35)^+=17$, $(52-50)^+=2$ และ $(52-55)^+=0$ เพราะ $-3$ ติดลบจึงกลายเป็นศูนย์

ขั้นที่ 2 — ความชันและความโค้งจากสามจุดข้างเคียง

PDE ของ Black–Scholes มีอนุพันธ์สองตัวตามราคาหุ้น ตัวแรกคือความชัน $V_S=\partial V/\partial S$ บอกว่าหุ้นขึ้น \$1 แล้ว put เปลี่ยนเท่าไร (นี่คือ delta) ตัวที่สองคือความโค้ง $V_{SS}=\partial^2V/\partial S^2$ บอกว่าความชันเปลี่ยนเร็วแค่ไหน (นี่คือ gamma) แต่บนกริดเราไม่มีฟังก์ชันทั้งเส้น มีแค่ค่าที่แถวห่างกันแถวละ $h=\Delta S$ เราจึงต้องเขียนอนุพันธ์ด้วยค่าที่แถวข้างเคียง

เครื่องมือคือการกระจาย Taylor ของ $V$ ไปทางขวาหนึ่งแถว ($S+h$) และทางซ้ายหนึ่งแถว ($S-h$) แล้วเอาสองสมการมาลบกันเพื่อหาความชัน หรือบวกกันเพื่อหาความโค้ง

\[ \begin{aligned} V_\pm&=V(S\pm h),\\ V_\pm&=V\pm hV_S+\tfrac12h^2V_{SS}\\ &\quad\pm\tfrac16h^3V_{SSS}+\cdots,\\ V_S&\approx\frac{V_+-V_-}{2h},\\ V_{SS}&\approx\frac{V_+-2V+V_-}{h^2},\\ h=5:\ V_S&\approx\frac{2.6439-7.5232}{10}\\ &=-0.48793,\\ V_{SS}&\approx\frac{2.6439-9.2426+7.5232}{25}\\ &=0.036976. \end{aligned} \]

ความคิดหลักคือ ค่าทางขวากับค่าทางซ้ายต่างกันที่เครื่องหมายของพจน์เลขคี่เท่านั้น ($\pm hV_S$ และ $\pm\tfrac16h^3V_{SSS}$) ถ้าลบสองสมการกัน พจน์ $V$ กับ $\tfrac12h^2V_{SS}$ ซึ่งมีเครื่องหมายเหมือนกันจะหักกันหายไป เหลือ $V_+-V_-=2hV_S$ บวกเศษขนาด $h^3$ หารทั้งสองข้างด้วย $2h$ ก็ได้ความชันที่พลาดไปราว $\tfrac16h^2V_{SSS}$

ถ้าบวกกันแทน พจน์เลขคี่จะหักกันหมด เหลือ $V_++V_-=2V+h^2V_{SS}$ บวกเศษขนาด $h^4$ ย้าย $2V$ ไปอีกข้างแล้วหารด้วย $h^2$ ก็ได้ความโค้งที่พลาดไปราว $\tfrac1{12}h^2$ คูณอนุพันธ์อันดับสี่ ทั้งสองสูตรจึงพลาดเป็นสัดส่วนกับ $h^2$ แปลว่าถ้าแถวห่างกันน้อยลง 5 เท่า ความคลาดเคลื่อนควรเล็กลงราว $5^2=25$ เท่า

มาลองกับตัวเลขจริง เราใช้ put ของหน้านี้ในแบบ European เพราะมีสูตรปิดให้เทียบ สูตร Black–Scholes ให้ราคาที่หุ้น \$55, \$50 และ \$45 เป็น 2.6439, 4.6213 และ 7.5232 ตามลำดับ (โค้ดท้ายหน้าคำนวณ) ในสูตรข้างบน ตัวหาร $2h=10$ และ $h^2=25$ ส่วน $9.2426=2\times4.6213$ ค่าจริงจากสูตรของ Greeks คือ delta −0.484434 และ gamma 0.0375840 ถ้าลด $h$ จาก 5 เหลือ 1 ผลต่างให้ delta −0.484582 และ gamma 0.0375594 ให้ $e_\Delta(h)$ กับ $e_\Gamma(h)$ เป็นความคลาดเคลื่อนของ delta กับ gamma เมื่อแถวห่างกัน $h$ คือค่าจากผลต่างลบค่าจริง

\[ \begin{aligned} e_\Delta(5)&=-0.487933+0.484434\\ &=-0.003499,\\ e_\Delta(1)&=-0.484582+0.484434\\ &=-0.000148,\\ e_\Gamma(5)&=0.0369755-0.0375840\\ &=-0.0006085,\\ e_\Gamma(1)&=0.0375594-0.0375840\\ &=-0.0000246,\\ \frac{e_\Delta(5)}{e_\Delta(1)}&=\frac{0.003499}{0.000148}=23.6,\\ \frac{e_\Gamma(5)}{e_\Gamma(1)}&=\frac{0.0006085}{0.0000246}=24.7. \end{aligned} \]

แถวห่างน้อยลง 5 เท่า ความคลาดเคลื่อนเล็กลง 23.6 และ 24.7 เท่า ใกล้ 25 ตามที่ Taylor บอก

ขั้นที่ 3 — ใส่ผลต่างลงใน PDE แล้วได้น้ำหนักสามตัว

ตอนนี้เรามีสูตรของความชันและความโค้งแล้ว ขั้นนี้แทนมันลงใน PDE เพื่อให้ได้สูตรของหนึ่งช่อง PDE ที่อยู่ต้นสูตรข้างล่างผูกสี่พจน์เข้าด้วยกัน $V_t$ คือมูลค่า put เปลี่ยนเร็วแค่ไหนตามเวลา ตามด้วยพจน์ความโค้ง พจน์ความชัน และ $rV$ ซึ่งเป็นดอกเบี้ยของเงินก้อนเท่ามูลค่า put เราใส่อัตราปันผลต่อปี $q$ ไว้ด้วยแบบเดียวกับ ปันผลในสูตรราคา หน้านี้ใช้ $q=0$ แต่โจทย์ข้อ 3 ท้ายหน้าจะใช้

อนุพันธ์ตามเวลาเขียนเป็นผลต่างของสองคอลัมน์ที่ติดกัน คือคอลัมน์ $n$ ที่กำลังหา กับคอลัมน์ $n+1$ ซึ่งอยู่ถัดไปหนึ่งก้าวและรู้แล้ว ส่วนความชันกับความโค้ง เราเลือกอ่านจากคอลัมน์ $n+1$ ทั้งหมด ผลคือฝั่งขวาของสูตรมีแต่ค่าที่รู้แล้ว และค่าที่ยังไม่รู้ $V_i^n$ อยู่ฝั่งซ้ายตัวเดียว การเลือกแบบนี้เรียกว่า explicit สุดท้ายแทน $S_i=i\Delta S$ แล้ว $\Delta S$ จะตัดกันหมด

\[ \begin{aligned} 0&=V_t+\tfrac12\sigma^2S^2V_{SS}\\ &\quad+(r-q)SV_S-rV,\\ V_t&\approx\frac{V_i^{n+1}-V_i^n}{\Delta t},\\ \frac{S_i^2}{\Delta S^2}&=i^2,\qquad \frac{S_i}{2\Delta S}=\frac i2,\\ V_i^n&=a_iV_{i-1}^{n+1}+b_iV_i^{n+1}\\ &\quad+c_iV_{i+1}^{n+1},\\ a_i&=\tfrac12\Delta t\big(\sigma^2i^2-(r-q)i\big),\\ b_i&=1-\Delta t\big(\sigma^2i^2+r\big),\\ c_i&=\tfrac12\Delta t\big(\sigma^2i^2+(r-q)i\big),\\ a_i+b_i+c_i&=1-r\Delta t. \end{aligned} \]

ผลลัพธ์บอกว่า ช่องใหม่แต่ละช่องคือผลรวมถ่วงน้ำหนักของสามช่องที่รู้แล้ว คือช่องล่าง ($i-1$) ช่องกลาง ($i$) และช่องบน ($i+1$) น้ำหนักได้มาจากการรวบพจน์ตามสามช่องนี้ พจน์ความโค้งให้ตัวคูณ $(1,-2,1)$ คูณ $\tfrac12\sigma^2i^2\Delta t$ พจน์ความชันให้ตัวคูณ $(-1,0,1)$ คูณ $\tfrac12(r-q)i\Delta t$ และพจน์ $-rV$ หัก $r\Delta t$ ออกจากช่องกลาง ช่องกลางยังมีเลข 1 อีกตัว ซึ่งมาจากการย้าย $V_i^{n+1}$ ในผลต่างตามเวลามาไว้ฝั่งเดียวกัน

ทำไมน้ำหนักชุดนี้จึงสมเหตุสมผล? ลองมอง $a_i$, $b_i$, $c_i$ เป็นโอกาสที่หุ้นลงหนึ่งแถว อยู่ที่เดิม หรือขึ้นหนึ่งแถวในหนึ่งก้าว แล้วคำนวณสองอย่าง

\[ \begin{aligned} (c_i-a_i)\Delta S&=(r-q)\,i\,\Delta t\,\Delta S\\ &=(r-q)S_i\Delta t,\\ (a_i+c_i)\Delta S^2&=\sigma^2i^2\Delta t\,\Delta S^2\\ &=\sigma^2S_i^2\Delta t. \end{aligned} \]

$(c_i-a_i)\Delta S$ คือค่าเฉลี่ยของการขยับในหนึ่งก้าว และ $(a_i+c_i)\Delta S^2$ คือค่าเฉลี่ยของกำลังสองของการขยับ ทั้งสองตรงกับหุ้นภายใต้ risk-neutral measure ซึ่งเป็นโลกสมมติที่ใช้ตั้งราคา ในโลกนั้นหุ้นโตเฉลี่ย $(r-q)S\,\Delta t$ ต่อก้าว และแกว่งด้วย variance $\sigma^2S^2\Delta t$ กริด explicit จึงเป็นต้นไม้สามกิ่งนั่นเอง ส่วนต้นไม้ binomial ก็คือกริด explicit แบบหนึ่งที่เลือกน้ำหนักกลางเป็นศูนย์

ผลรวม $a_i+b_i+c_i=1-r\Delta t$ คือการคิดลดดอกเบี้ยหนึ่งก้าว รวมกันแล้วสูตรนี้บอกว่า มูลค่าวันนี้คือค่าเฉลี่ยของมูลค่าในก้าวถัดไป แล้วคิดลดกลับมาหนึ่งก้าว นี่คือ Feynman–Kac ในรูปตาราง

ขั้นที่ 4 — ก้าวแรกด้วยมือ: ที่หุ้น \$45 การใช้สิทธิ์ชนะแล้ว

สูตรน้ำหนักพร้อมแล้ว ขั้นนี้ลองใช้มันจริงหนึ่งก้าว เพื่อดูว่าการตัดสินใจ “ใช้สิทธิ์หรือถือต่อ” เกิดขึ้นในตารางอย่างไร เรายืนอยู่ที่ 0.02 ปีก่อนวันหมดอายุ และถามว่า ถ้าหุ้นอยู่ที่ \$50 หรือ \$45 ตอนนั้น ผู้ถือ put ควรใช้สิทธิ์เลยหรือรออีกหนึ่งก้าว

โจทย์ให้อะไรมาบ้าง:

  • กริดหยาบจากขั้นที่ 1: $\Delta S=\$5$, $\Delta t=0.02$ ปี, ไม่มีปันผล ($q=0$)
  • ค่าของหุ้นและดอกเบี้ยจากโจทย์เปิดเรื่อง: $\sigma^2=0.3^2=0.09$, $r=0.05$ ดังนั้น $\tfrac12\Delta t=0.01$
  • คอลัมน์วันหมดอายุ (payoff) ที่หุ้น \$40, \$45, \$50, \$55 คือ 12, 7, 2, 0
  • หุ้น \$50 อยู่แถว $i=50/5=10$ และหุ้น \$45 อยู่แถว $i=45/5=9$

มูลค่าถือต่อ (hold) คือผลรวมถ่วงน้ำหนักของสามช่องในวันหมดอายุ ตามสูตรของขั้นที่ 3 ที่หุ้น \$50 ช่องล่างคือ \$45 (payoff 7) ช่องกลางคือ \$50 (payoff 2) ช่องบนคือ \$55 (payoff 0)

\[ \begin{aligned} \sigma^2i^2&=0.09\times10^2=9,\\ ri&=0.05\times10=0.5,\\ a&=0.01(9-0.5)=0.085,\\ b&=1-0.02(9+0.05)=0.819,\\ c&=0.01(9+0.5)=0.095,\\ \text{hold}&=0.085(7)+0.819(2)\\ &\quad+0.095(0)\\ &=0.595+1.638+0\\ &=2.233. \end{aligned} \]

ที่หุ้น \$45 ทำแบบเดียวกัน ช่องล่างคือ \$40 (payoff 12) ช่องกลางคือ \$45 (payoff 7) ช่องบนคือ \$50 (payoff 2)

\[ \begin{aligned} \sigma^2i^2&=0.09\times9^2=7.29,\\ ri&=0.05\times9=0.45,\\ a&=0.01(7.29-0.45)=0.0684,\\ b&=1-0.02(7.29+0.05)=0.8532,\\ c&=0.01(7.29+0.45)=0.0774,\\ \text{hold}&=0.0684(12)+0.8532(7)\\ &\quad+0.0774(2)\\ &=0.8208+5.9724+0.1548\\ &=6.948. \end{aligned} \]

คำตอบ: ที่หุ้น \$50 ถ้าใช้สิทธิ์ได้ $52-50=\$2$ แต่ถือต่อมีค่า 2.233 ซึ่งมากกว่า ผู้ถือจึงควรรอ และช่องนี้เก็บค่า $\max(2.233,\,2)=2.233$ ที่หุ้น \$45 ถ้าใช้สิทธิ์ได้ $52-45=\$7$ แต่ถือต่อมีค่าแค่ 6.948 ซึ่งน้อยกว่า ผู้ถือจึงควรใช้สิทธิ์ทันที และช่องนี้เก็บค่า $\max(6.948,\,7)=7$ การใช้สิทธิ์ก่อนกำหนดจึงโผล่ออกมาเองจากการเทียบสองตัวเลขนี้ ไม่ต้องมีสูตรพิเศษ

ทำไมที่ \$45 การถือต่อแพ้ไป $7-6.948=0.052$ พอดี? ที่ราคานี้ทั้งสามช่องข้างเคียง (\$40, \$45, \$50) อยู่ต่ำกว่า strike ทั้งหมด payoff ของทั้งสามช่องจึงอยู่บนเส้นตรงเดียวกัน คือ $K-S$ แทนเส้นตรงนี้ลงในน้ำหนัก แล้วใช้ผลรวม $a+b+c=1-r\Delta t$ กับ $(c-a)\Delta S=rS\Delta t$ จากขั้นที่ 3

\[ \begin{aligned} \text{hold}&=a(K-S+\Delta S)+b(K-S)\\ &\quad+c(K-S-\Delta S)\\ &=(1-r\Delta t)(K-S)-(c-a)\Delta S\\ &=(K-S)-rK\Delta t,\\ rK\Delta t&=0.05\times52\times0.02=0.052. \end{aligned} \]

ความหมายคือ การรออีกหนึ่งก้าวทำให้ได้เงิน $K$ ช้าลงหนึ่งก้าว จึงเสียดอกเบี้ยของเงิน \$52 ไป 0.052 และไม่ได้อะไรคืนมาเลย เพราะในก้าวเดียวหุ้นขยับได้แค่ไป \$40 หรือ \$50 ซึ่งยังต่ำกว่า strike ทั้งคู่ ส่วนที่หุ้น \$50 ช่องบน (\$55) อยู่เหนือ strike ตรงนั้น payoff หักมุมเป็นศูนย์แทนที่จะติดลบ (put ไม่บังคับให้ขาดทุน) มุมนี้ทำหน้าที่เหมือนประกัน และค่าประกันนี้มากกว่าดอกเบี้ยที่เสีย การรอจึงคุ้ม

ตรวจเองใน 10 วินาที: $0.085+0.819+0.095=0.999$ ตรงกับ $1-r\Delta t=1-0.05\times0.02=0.999$ และ $7-0.052=6.948$ ตรงกับมูลค่าถือต่อที่ \$45 ถ้าทำแบบเดียวกันทุกช่องทุกก้าวจนครบ 25 ก้าว (โค้ดท้ายหน้าทำให้) กริดหยาบนี้ให้ American put ที่ \$50 เท่ากับ 4.7753 และ European put เท่ากับ 4.6335 ซึ่งใกล้ค่าจากสูตร 4.6213 แล้ว กริดที่ละเอียดกว่าในขั้นที่ 9 จะเก็บส่วนต่างที่เหลือ

ขั้นที่ 5 — ทำไม explicit ระเบิด: ติดตามรอยหยักหนึ่งอัน

กริดหยาบเดินได้สวย แต่ถ้าอยากได้ราคาแม่นขึ้น เราต้องลดระยะห่างของแถวราคา และตรงนี้ explicit จะมีปัญหา น้ำหนักสามตัวรวมกันได้เกือบ 1 จึงดูเหมือนค่าเฉลี่ย แต่น้ำหนักกลาง $b_i=1-\Delta t(\sigma^2i^2+r)$ ลดลงเมื่อ $i$ โต ถ้ามันติดลบ สูตรก็ไม่ใช่ค่าเฉลี่ยอีกต่อไป และความคลาดเคลื่อนเล็ก ๆ อาจถูกขยายทุกก้าว

วิธีตรวจคือใส่ความคลาดเคลื่อนรูปที่แย่ที่สุดเข้าไปในคอลัมน์หนึ่ง แล้วดูว่าหนึ่งก้าวทำอะไรกับมัน รูปที่แย่ที่สุดคือรอยหยัก ขึ้นลงสลับกันทุกแถว สูง $\varepsilon$ บ้าง ต่ำ $-\varepsilon$ บ้าง ($\varepsilon$ คือขนาดของความคลาดเคลื่อน) เราเรียกการคลาดเคลื่อนที่แถว $i$ ว่า $e_i$

\[ \begin{aligned} e_i&=\varepsilon(-1)^i,\\ e_{i+1}-2e_i+e_{i-1}&=-4\varepsilon(-1)^i,\\ \lambda_i&=\tfrac12\sigma^2i^2\Delta t,\\ e_i^{\rm new}&\approx(1-4\lambda_i)\,e_i,\\ |1-4\lambda_M|\le1&:\ \lambda_M\le\tfrac12,\\ \sigma^2M^2\Delta t&\le1,\\ b_M\ge0&:\ \Delta t\le\frac{1}{\sigma^2M^2+r}. \end{aligned} \]

ทำไมหนึ่งก้าวจึงคูณรอยหยักด้วย $1-4\lambda_i$? ในน้ำหนักทั้งสามตัว ส่วนที่มาจากความโค้งคือ $\lambda_i=\tfrac12\sigma^2i^2\Delta t$ ใน $a_i$ และ $c_i$ กับ $-2\lambda_i$ ใน $b_i$ ส่วนนี้คูณรอยหยักแล้วได้ $\lambda_i(e_{i+1}-2e_i+e_{i-1})=-4\lambda_ie_i$ เพราะช่องบนและช่องล่างมีเครื่องหมายตรงข้ามกับช่องกลาง ส่วนที่มาจากความชันคูณ $e_{i+1}-e_{i-1}$ ซึ่งเป็นศูนย์ เพราะช่องบนกับช่องล่างของรอยหยักสูงเท่ากัน เราทิ้งพจน์ $r\Delta t$ ไว้ก่อนเพราะเล็กมาก จึงเหลือ $e_i+(-4\lambda_ie_i)=(1-4\lambda_i)e_i$

ถ้าตัวคูณนี้ต่ำกว่า −1 รอยหยักจะกลับด้านและสูงขึ้นทุกก้าว นี่คือการระเบิด ความคลาดเคลื่อนรูปที่เรียบกว่ารอยหยักจะถูกคูณด้วยตัวเลขระหว่าง 1 กับ $1-4\lambda_i$ รอยหยักจึงเป็นกรณีที่แย่ที่สุดและเป็นตัวตัดสิน

$\lambda_i$ โตตาม $i^2$ แถวบนสุด ($i=M$) จึงคุมทั้งกริด เงื่อนไข $|1-4\lambda_M|\le1$ ให้ $\lambda_M\le\tfrac12$ หรือ $\sigma^2M^2\Delta t\le1$ ถ้านับ $r$ ด้วย เงื่อนไขเดียวกันคือน้ำหนักกลาง $b_M$ ต้องไม่ติดลบ ลองกับกริดหยาบ ($\Delta S=5$, $M=20$)

\[ \begin{aligned} \sigma^2M^2+r&=0.09\times400+0.05=36.05,\\ \Delta t&\le1/36.05=0.02774,\\ \lambda_{20}&=\tfrac12\times0.09\times400\times0.02=0.36,\\ 1-4\lambda_{20}&=1-1.44=-0.44. \end{aligned} \]

ก้าว 0.02 ปีของก้าวแรกด้วยมือจึงผ่าน เพราะ $0.02\le0.02774$ รอยหยักถูกคูณ −0.44 ทุกก้าว จึงเล็กลงเรื่อย ๆ

แต่ความละเอียดมีราคา ถ้าแถวห่าง $\Delta S=1$ แถวบนสุดคือ $M=100/1=100$ และถ้า $\Delta S=0.5$ จะได้ $M=100/0.5=200$ จำนวนก้าวในครึ่งปีคือ $N=T/\Delta t$ เงื่อนไข $\Delta t\le1/(\sigma^2M^2+r)$ จึงแปลว่า $N\ge T(\sigma^2M^2+r)$

\[ \begin{aligned} M=100&:\ 0.09\times100^2+0.05=900.05,\\ N&\ge0.5\times900.05=450.025,\\ M=200&:\ 0.09\times200^2+0.05=3{,}600.05,\\ N&\ge0.5\times3{,}600.05=1{,}800.025. \end{aligned} \]

จำนวนก้าวต้องเป็นจำนวนเต็มที่ไม่น้อยกว่านี้ จึงต้องใช้อย่างน้อย 451 ก้าวและ 1,801 ก้าวในครึ่งปีตามลำดับ สรุปคือ แถวห่างน้อยลงครึ่งหนึ่ง จำนวนก้าวต้องเพิ่มสี่เท่า และจำนวนแถวเพิ่มสองเท่า งานทั้งหมดจึงเพิ่ม $4\times2=8$ เท่า

ขั้นที่ 7 — implicit และ Crank–Nicolson: อ่านเพื่อนบ้านจากคอลัมน์ที่ยังไม่รู้

ต้นเหตุของการระเบิดคือ explicit อ่านความชันและความโค้งจากคอลัมน์ที่รู้แล้ว แล้วกระโดดไปไกลเกินไปในก้าวเดียว ทางแก้คืออ่านความชันและความโค้งจากคอลัมน์ใหม่ที่กำลังหาแทน อ่านทั้งหมดเรียกว่า implicit อ่านครึ่งหนึ่งเรียกว่า Crank–Nicolson (ในสูตรย่อว่า CN) ข้อเสียคือค่าที่ยังไม่รู้จะไปโผล่ในสูตรของกันและกัน เราจึงต้องแก้สมการทั้งคอลัมน์พร้อมกัน

เพื่อเขียนสามแบบในสมการเดียว ให้ $LV$ คือทุกพจน์ของ PDE ที่ไม่ใช่ $V_t$ คือ $\tfrac12\sigma^2S^2V_{SS}+(r-q)SV_S-rV$ เขียนด้วยสามช่องแบบเดียวกับขั้นที่ 3 และให้ $\omega$ เป็นสัดส่วนที่อ่านจากคอลัมน์ใหม่ ($\omega=0$ คือ explicit)

\[ \begin{aligned} V^n-\omega\Delta t\,LV^n&=V^{n+1}\\ &\quad+(1-\omega)\Delta t\,LV^{n+1},\\ \omega=1,\ i=10&:\ -0.085\,V_9^n\\ &\quad+1.181\,V_{10}^n\\ &\quad-0.095\,V_{11}^n\\ &\quad=V_{10}^{n+1},\\ \text{implicit}&:\ e^{\rm new}=\frac{e}{1+4\lambda},\\ \text{CN}&:\ e^{\rm new}=\frac{1-2\lambda}{1+2\lambda}\,e. \end{aligned} \]

สมการหลักแยกของสองคอลัมน์ไว้คนละฝั่ง ฝั่งซ้ายคือคอลัมน์ใหม่ $V^n$ ที่ยังไม่รู้ ฝั่งขวาคือคอลัมน์ $V^{n+1}$ ที่รู้แล้ว ถ้า $\omega=0$ ฝั่งซ้ายเหลือ $V^n$ ตัวเดียว ก็กลับไปเป็น explicit ถ้า $\omega=1$ คือ implicit และ $\omega=\tfrac12$ คือ Crank–Nicolson

ในแบบ implicit แต่ละแถวใช้น้ำหนักชุดเดิมของขั้นที่ 3 แต่กลายเป็น $-a_i$, $2-b_i$ และ $-c_i$ คูณค่าที่ยังไม่รู้ ที่ $i=10$ จึงได้ $-0.085$, $2-0.819=1.181$ และ $-0.095$ ฝั่งซ้ายมีค่าที่ยังไม่รู้สามตัว ($V_9^n$, $V_{10}^n$, $V_{11}^n$) ซึ่งแต่ละตัวก็ไปโผล่ในสมการของแถวข้างเคียงด้วย

ทั้งคอลัมน์จึงเป็นระบบสมการเชิงเส้น ซึ่ง matrix มีค่าแค่สามเส้นทแยง เรียกว่า tridiagonal ระบบแบบนี้แก้ได้เร็วด้วย Thomas algorithm คือกำจัดตัวแปรลงไปทีละแถวจากบนลงล่าง แล้วแทนค่ากลับขึ้นมา งานจึงโตตามจำนวนแถวเท่านั้น ไม่ต้องหา inverse ของ matrix

ลองใส่รอยหยักแบบขั้นที่ 5 อีกครั้ง implicit อ่านความโค้งจากคอลัมน์ใหม่ จึงได้ $e^{\rm new}-\lambda(-4e^{\rm new})=e$ หรือ $e^{\rm new}(1+4\lambda)=e$ แปลว่ารอยหยักถูกหารด้วย $1+4\lambda$ ซึ่งมากกว่า 1 เสมอ Crank–Nicolson แบ่งครึ่ง จึงได้ $e^{\rm new}(1+2\lambda)=e(1-2\lambda)$ ตัวคูณ $(1-2\lambda)/(1+2\lambda)$ อยู่ระหว่าง −1 กับ 1 เสมอ ทั้งสองแบบจึงไม่ระเบิด ไม่ว่าก้าวยาวแค่ไหน ลองที่ $\lambda=1.125$ ซึ่งทำให้ explicit คูณ −3.5 ในขั้นที่ 6

\[ \begin{aligned} \text{implicit}&:\ \frac{1}{1+4.5}=0.182,\\ \text{CN}&:\ \frac{1-2.25}{1+2.25}=\frac{-1.25}{3.25}=-0.385. \end{aligned} \]

แต่ไม่ระเบิดไม่ได้แปลว่าแม่น ทั้ง explicit และ implicit พลาดเพราะก้าวเวลาเป็นสัดส่วนกับ $\Delta t$ คือก้าวสั้นลงครึ่งหนึ่ง ความคลาดเคลื่อนลดลงครึ่งหนึ่ง ส่วน Crank–Nicolson เฉลี่ยสองคอลัมน์ ความคลาดเคลื่อนส่วนแรกจึงหักกันหาย เหลือความคลาดเคลื่อนเป็นสัดส่วนกับ $\Delta t^2$ คือก้าวสั้นลงครึ่งหนึ่ง ความคลาดเคลื่อนลดลงสี่เท่า

ตารางข้างล่างวัดเรื่องนี้ด้วย European put ตัวเดิมที่หุ้น \$50 บนกริดห่างแถวละ \$0.5 ขอบบน \$200 “พลาด” คือค่าที่ได้ลบค่าอ้างอิง 4.620218 ซึ่งเป็นคำตอบของกริดเดียวกันเมื่อเดินแบบ Crank–Nicolson 5,000 ก้าว (โค้ดท้ายหน้าคำนวณ) การใช้กริดเดียวกันเป็นค่าอ้างอิงตัดความคลาดเคลื่อนจากแถวราคาออก จึงเหลือแต่ส่วนที่มาจากก้าวเวลา

ขั้นที่ 9 — American put บนกริด implicit: เลือกค่าที่มากกว่าทุกก้าว

ตอนนี้มีเครื่องมือครบแล้ว ขั้นนี้กลับมาตอบโจทย์เปิดเรื่อง คือราคาของ American put ที่ลูกค้าขอซื้อ เราใช้ implicit เพราะไม่ระเบิด และใส่การตัดสินใจใช้สิทธิ์แบบเดียวกับก้าวแรกด้วยมือ

โจทย์ให้อะไรมาบ้าง:

  • ทุกก้าวแก้ระบบ implicit ก่อน แล้วแทนแต่ละช่องด้วย $\max(V_i^n,\ K-S_i)$ คือเลือกค่าที่มากกว่าระหว่างถือต่อกับใช้สิทธิ์ทันที
  • ขอบล่างเป็น $K$ แบบ American ตามขั้นที่ 1
  • ทำซ้ำบนกริดสี่ระดับ แต่ละระดับลดระยะห่างของแถวลงครึ่งหนึ่ง และเพิ่มจำนวนก้าวสี่เท่า ($\Delta t$ ลดตาม $\Delta S^2$ ความคลาดเคลื่อนจากราคาและจากเวลาจึงหดไปพร้อมกัน)
  • อ่านมูลค่าที่หุ้น \$50 และขอบใช้สิทธิ์ คือราคาหุ้นสูงสุดที่การใช้สิทธิ์ทันทีดีกว่าถือต่อ เมื่อเหลือเวลาครึ่งปี (โค้ดท้ายหน้าคำนวณทุกตัวเลขในตาราง)

ถ้าทุกระดับลดความคลาดเคลื่อนลงสี่เท่า การซอยครั้งถัดไปจะเพิ่มมูลค่าอีก $d_2/4$ ครั้งต่อไปอีก $d_2/16$ และต่อไปเรื่อย ๆ ผลรวมทั้งหมดที่ยังขาดคือ $d_2\left(\tfrac14+\tfrac1{16}+\cdots\right)=d_2\times\dfrac{1/4}{1-1/4}=\dfrac{d_2}{3}$ นี่คือที่มาของ $V\approx4.782763+d_2/3=4.7830$ ในสูตรข้างบน

ตรวจกับวิธีที่ไม่เกี่ยวกันเลย ต้นไม้ CRR (ต้นไม้ binomial แบบมาตรฐาน) 2,000 ช่วงให้ 4.7831 สองวิธีตรงกันถึงทศนิยมสามตำแหน่ง ส่วนต่างจากราคา European คือ $4.7830-4.6213=\$0.1617$ ต่อหุ้น หรือ $0.1617\times10{,}000=\$1{,}617$ สำหรับ 10,000 หุ้นของโจทย์เปิดเรื่อง นี่คือมูลค่าของสิทธิ์ที่จะใช้ก่อนวันหมดอายุ ขอบใช้สิทธิ์นิ่งอยู่ที่ \$38.5 ตั้งแต่ระดับที่สอง

ตรวจเองใน 10 วินาที: การ “แก้ระบบก่อนแล้วค่อยเลือกค่าที่มากกว่า” เป็นการประมาณ เพราะตอนแก้ระบบ implicit สมการยังไม่รู้ว่าช่องข้างเคียงบางช่องจะถูกใช้สิทธิ์ ความคลาดเคลื่อนส่วนนี้หดตาม $\Delta t$ และรวมอยู่ในตารางแล้ว ระบบจริงที่ต้องการความแม่นยิ่งกว่านี้จะแก้สมการกับเงื่อนไข “ไม่ต่ำกว่า $K-S$” ไปพร้อมกันในครั้งเดียว เช่นวิธี projected SOR หรือ penalty method

ขั้นที่ 10 — Greeks จากตารางเดียวกัน และการตรวจขอบบน

นอกจากราคา โต๊ะยังต้องรู้ delta เพื่อ hedge และต้องแน่ใจว่าขอบบนที่ตั้งเป็นศูนย์ในขั้นที่ 1 ไม่ได้ทำให้ราคาเพี้ยน ขั้นนี้ตอบทั้งสองเรื่องจากกริดที่มีอยู่แล้ว

โจทย์ให้อะไรมาบ้าง:

  • กริด implicit ห่างแถวละ $h=\Delta S=0.5$ ขอบบน \$200 400 ก้าว ของขั้นที่ 9 ซึ่งเก็บมูลค่าทุกราคาหุ้นไว้แล้ว (โค้ดท้ายหน้าคำนวณตัวเลขทั้งหมดในขั้นนี้)
  • หา delta และ gamma ที่ \$50 ด้วยสูตรสามแถวของขั้นที่ 2 ซึ่งใช้ค่าที่ \$49.5, \$50 และ \$50.5
  • ลองย้ายขอบบนจาก \$200 ลงมาที่ \$100, \$70 และ \$60 แล้วดูว่ามูลค่าที่ \$50 เปลี่ยนไหม (มูลค่าที่ขอบ \$200 คือ 4.778905)
\[ \begin{aligned} \Delta&=\frac{V(50.5)-V(49.5)}{2(0.5)}\\ &=V(50.5)-V(49.5)=-0.5093,\\ \Gamma&=\frac{V(50.5)-2V(50)+V(49.5)}{0.5^2}\\ &=0.04121,\\ \Delta_{\rm EU},\ \Gamma_{\rm EU}&=-0.4844,\ 0.03758,\\ S_{\max}=100&:\ 4.778905,\\ S_{\max}=70&:\ 4.774692,\\ S_{\max}=60&:\ 4.507274. \end{aligned} \]

คำตอบ: กริดให้มูลค่าทุกราคาหุ้นมาพร้อมกัน Greeks จึงได้มาฟรีจากช่องข้างเคียง ($\Delta_{\rm EU}$ กับ $\Gamma_{\rm EU}$ คือค่าของ European put จากสูตร ไว้เทียบ) American put มี delta ติดลบมากกว่า European คือ −0.5093 เทียบกับ −0.4844 เพราะมันอยู่ใกล้เขตใช้สิทธิ์ ซึ่งใต้ \$38.5 delta เป็น −1 เต็ม

ตัวเลขนี้มีผลจริงกับโต๊ะ โต๊ะที่ขาย put บน 10,000 หุ้นต้อง short หุ้น (ขายหุ้นที่ยืมมา) เพื่อ hedge จำนวน $0.5093\times10{,}000=5{,}093$ หุ้น ไม่ใช่ $0.4844\times10{,}000=4{,}844$ หุ้นตามสูตร European

เรื่องขอบบน ขอบที่ \$100 ให้ค่าเท่ากับขอบที่ \$200 ถึงทศนิยมตำแหน่งที่ 9 จึงไกลพอ ขอบที่ \$70 พลาด $4.778905-4.774692=0.0042$ และขอบที่ \$60 พลาด $4.778905-4.507274=0.2716$

ตรวจเองใน 10 วินาที: กฎหยาบที่ใช้กันคือ ให้ขอบบนอยู่สูงกว่าราคาที่หุ้นจะไปถึงได้ถ้าขึ้นแรงถึง 3 SD ตลอดอายุสัญญา คือ $S_0e^{3\sigma\sqrt T}=50e^{3(0.3)\sqrt{0.5}}=50e^{0.6364}=94.5$ ขอบ \$100 ผ่านกฎนี้ และการทดลองข้างบนก็ยืนยันว่าพอ ส่วน \$70 กับ \$60 ไม่ผ่าน กฎหยาบใช้เป็นจุดเริ่มได้ แต่ต้องยืนยันด้วยการขยับขอบจริงทุกครั้ง

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

ใช้สูตร European กับสัญญา American สูตรปิดของ Black–Scholes ไม่นับมูลค่าของการใช้สิทธิ์ก่อน จึงให้ราคา American put ต่ำเกินไป ผิด: \$4.6213 ถูก: \$4.7830 ขาดไป $4.7830-4.6213=\$0.1617$ ต่อหุ้น หรือ $0.1617\times10{,}000=\$1{,}617$ สำหรับ 10,000 หุ้น และ hedge ด้วยหุ้นน้อยไป $5{,}093-4{,}844=249$ หุ้น ส่วนต่างนี้ยิ่งโตเมื่อดอกเบี้ยสูง หรือเมื่อหุ้นอยู่ต่ำกว่า strike มาก

ตั้งก้าวเวลาของ explicit ด้วยความรู้สึก ก้าวที่ยาวเกินกฎทำให้ตัวเลขผิดโดยไม่มีอะไรเตือน ผิด: 320 ก้าวบนกริดห่างแถวละ \$1 ให้ 4.3671 ซึ่งดูเป็นราคาปกติ ถูก: 4.6169 ต่างกัน $4.6169-4.3671=0.2498$ วิธีป้องกันคือคำนวณ $N\ge T(\sigma^2M^2+r)=0.5\times900.05=450.025$ หรือ 451 ก้าวก่อนเดินทุกครั้ง หรือเปลี่ยนไปใช้ implicit

รายงาน gamma จาก Crank–Nicolson ที่เริ่มด้วยก้าวยาว มุมของ payoff ที่ strike ทำให้ gamma แกว่ง ผิด: gamma ที่ strike เป็น 1.4676 และติดลบรอบข้าง ถูก: ราว 0.0353 สูงเกิน $1.4676/0.0353\approx42$ เท่า ถ้า hedge ตามตัวเลขนี้ โต๊ะจะซื้อขายหุ้นกลับไปกลับมาโดยไม่มีเหตุผล วิธีป้องกันคือเดินสองก้าวแรกแบบ implicit เสมอ

ขอบบนใกล้เกินไป กริดบังคับให้ put ที่ขอบบนมีค่าศูนย์ ถ้าขอบอยู่ใกล้ ก็เท่ากับทิ้งโอกาสที่หุ้นจะลงกลับมาใต้ strike ผิด: ขอบ $S_{\max}=\$60$ ให้ 4.5073 ถูก: 4.7789 ต่ำไป $4.7789-4.5073=0.2716$ วิธีตรวจคือย้ายขอบออกไปไกลขึ้น แล้วดูว่าราคาไม่ขยับ

ใช้ทำอะไรบนโต๊ะจริง

option บนหุ้นรายตัวที่ซื้อขายในตลาดสหรัฐเกือบทั้งหมดเป็นแบบ American โต๊ะเทรด (ทีมที่ขาย option ให้ลูกค้าและ hedge ความเสี่ยงที่เกิดขึ้น) จึงต้องมีเครื่องตั้งราคาที่คิดเรื่องใช้สิทธิ์ก่อนได้ทุกวัน กริด implicit หรือ Crank–Nicolson ที่เริ่มด้วย implicit สองก้าว ให้ราคา delta gamma และเส้นใช้สิทธิ์จากการคำนวณครั้งเดียว โต๊ะใช้เส้นนี้บอกลูกค้าว่าควรใช้สิทธิ์เมื่อไร และใช้เตือนตัวเองว่า put ที่ขายไปอาจถูกใช้สิทธิ์ถ้าหุ้นลงต่ำกว่าเส้นนั้น

ต้นไม้ binomial ก็ตั้งราคา American ได้ และได้ตัวเลขเดียวกัน (4.7831) เพราะมันคือกริด explicit แบบหนึ่ง แต่กริดมีข้อดีกว่าสามข้อ ข้อแรก กริดให้มูลค่าที่ทุกราคาหุ้นในคราวเดียว ข้อสอง กริดวางแถวให้ตรงกับระดับราคาของ barrier option ได้พอดี (barrier option คือ option ที่ดับหรือเกิดเมื่อหุ้นแตะระดับที่ตกลงไว้) ข้อสาม ถ้าเดินแบบ implicit ก็ไม่ต้องกลัวกฎของรอยหยัก แบบจำลองที่มีตัวแปรสุ่มสองตัว เช่น Heston ซึ่งให้ความผันผวนเองก็สุ่มได้ ก็แก้บนกริดสองมิติได้ แต่ถ้ามีตัวแปรเกินสามตัว จำนวนช่องจะโตเร็วมากจนต้องเปลี่ยนไปใช้ Monte Carlo คือสุ่มเส้นทางราคาหุ้นจำนวนมากแล้วเฉลี่ย

ทั้งหน้านี้ถือว่าความผันผวนคงที่ 30% แต่ราคา option ในตลาดจริงบอกความผันผวนที่ต่างกันไปตาม strike และอายุ ก่อนใช้กริดกับตลาดจริง จึงต้องเลือก parameter ของแบบจำลองให้ราคาจากกริดตรงกับราคาตลาดก่อน งานนี้เรียกว่า calibration และเป็นเรื่องของหน้าถัดไป

โจทย์ตรวจความเข้าใจ

1. ใช้กริดหยาบของขั้นที่ 4 เดิม ($\Delta S=\$5$, $\Delta t=0.02$ ปี, $\sigma=30\%$, $r=5\%$) หนึ่งก้าวก่อนหมดอายุ หุ้นอยู่ที่ \$40 ซึ่งเป็นแถว $i=40/5=8$ ช่องข้างเคียงในวันหมดอายุคือหุ้น \$35, \$40, \$45 ซึ่งมี payoff 17, 12, 7 จงหาน้ำหนักสามตัว มูลค่าถือต่อ และบอกว่าผู้ถือ put ควรใช้สิทธิ์ไหม

เฉลย

ใช้สูตรน้ำหนักของขั้นที่ 3 โดย $\tfrac12\Delta t=0.01$

\[ \begin{aligned} \sigma^2i^2&=0.09\times8^2=5.76,\\ ri&=0.05\times8=0.4,\\ a&=0.01(5.76-0.4)=0.0536,\\ b&=1-0.02(5.76+0.05)=0.8838,\\ c&=0.01(5.76+0.4)=0.0616,\\ \text{hold}&=0.0536(17)+0.8838(12)\\ &\quad+0.0616(7)\\ &=0.9112+10.6056+0.4312\\ &=11.948. \end{aligned} \]

ถ้าใช้สิทธิ์ทันทีได้ $52-40=\$12$ ซึ่งมากกว่า 11.948 จึงควรใช้สิทธิ์ ตรวจด้วยทางลัดของขั้นที่ 4 ได้ เพราะช่องข้างเคียงทั้งสาม (\$35, \$40, \$45) อยู่ต่ำกว่า strike ทั้งหมด มูลค่าถือต่อจึงเท่ากับ $12-rK\Delta t=12-0.05\times52\times0.02=11.948$ ตรงกัน

2. เพื่อนในทีมอยากได้ราคาแม่นกว่ากริดหยาบ จึงจะใช้ explicit บนกริดที่ห่างแถวละ \$2 ขอบบน \$100 เขาต้องใช้อย่างน้อยกี่ก้าวในครึ่งปีจึงไม่ระเบิด และถ้าลดระยะห่างเหลือแถวละ \$1 ต้องใช้กี่ก้าว?

เฉลย

แถวบนสุดคือ $M=100/2=50$ ใช้กฎของขั้นที่ 5

\[ \begin{aligned} \Delta t&\le\frac{1}{0.09\times50^2+0.05}=\frac{1}{225.05}\\ &=0.0044435,\\ N&\ge\frac{0.5}{0.0044435}=112.5. \end{aligned} \]

จำนวนก้าวต้องเป็นจำนวนเต็ม จึงต้องใช้อย่างน้อย 113 ก้าว ถ้าห่างแถวละ \$1 จะได้ $M=100$ และต้องใช้ 451 ก้าวตามขั้นที่ 5 มากขึ้น $451/113=4.0$ เท่า เพราะก้าวเวลาต้องสั้นลงตาม $1/M^2$ และ $M$ เพิ่มเป็นสองเท่า

3. คราวนี้เป็น American call คือสิทธิ์ที่จะซื้อหุ้นในราคา strike ใช้สิทธิ์วันไหนก็ได้ ถ้าใช้สิทธิ์ทันทีได้ $S-K$ ต่อหุ้น ให้ strike $K=\$52$ หุ้นอยู่ที่ $S=\$60$ ก้าวละ $\Delta t=0.02$ ปี ดอกเบี้ย $r=5\%$ สมมติว่าช่องข้างเคียงทั้งสามอยู่เหนือ strike มูลค่าที่นั่นจึงเป็นเส้นตรง $S-K$ การถือต่อหนึ่งก้าวชนะหรือแพ้การใช้สิทธิ์ทันทีเท่าไร ถ้าหุ้นไม่จ่ายปันผล และถ้าหุ้นจ่ายปันผล $q=8\%$ ต่อปี?

เฉลย

แทนเส้นตรง $S-K$ ลงในน้ำหนักสามตัว แบบเดียวกับทางลัดของ put ในขั้นที่ 4 แต่คราวนี้ใช้ $(c-a)\Delta S=(r-q)S\Delta t$ ที่มีปันผล

\[ \begin{aligned} \text{hold}&=(a+b+c)(S-K)+(c-a)\Delta S\\ &=(1-r\Delta t)(S-K)+(r-q)S\Delta t\\ &=(S-K)+rK\Delta t-qS\Delta t,\\ q=0&:\ 0.05\times52\times0.02=0.052,\\ q=0.08&:\ 0.052-0.08\times60\times0.02\\ &\quad=0.052-0.096=-0.044. \end{aligned} \]

ถ้าไม่มีปันผล ถือต่อชนะ 0.052 จึงไม่ใช้สิทธิ์ ถ้ามีปันผล 8% ถือต่อแพ้ 0.044 จึงควรใช้สิทธิ์ เพื่อเป็นเจ้าของหุ้นและรับปันผล เหตุผลคือ ผู้ถือ call ต้องจ่าย strike ตอนใช้สิทธิ์ การรอจ่ายทีหลังจึงได้ดอกเบี้ยของ strike ($rK\Delta t$) แต่ระหว่างรอก็ไม่ได้ปันผลของหุ้น ($qS\Delta t$) ถ้าหุ้นไม่จ่ายปันผล การรอจึงชนะเสมอ และ call ไม่เคยถูกใช้สิทธิ์ก่อน ส่วน put กลับด้าน ผู้ถือ put ได้รับ strike ตอนใช้สิทธิ์ การรอจึงเสียดอกเบี้ย และบางครั้งการใช้สิทธิ์ก่อนก็คุ้ม

// American put on a grid: weights from the PDE, one step by hand, the stability rule,
// implicit and Crank-Nicolson steps, early exercise, grid Greeks and the checks before trusting a price.
const { abs, exp, log, sqrt, max, ceil, round, PI } = Math;
const S0 = 50, K = 52, r = 0.05, q = 0, sigma = 0.3, T = 0.5;
function checkGrid(dS, Smax, steps) {
  if (![dS, Smax, steps].every(Number.isFinite)) throw new TypeError('Grid settings must be finite numbers');
  if (dS <= 0 || Smax <= S0) throw new RangeError('Price step must be positive and the top of the grid above the stock price');
  if (!Number.isInteger(steps) || steps < 1) throw new RangeError('Number of time steps must be a positive whole number');
  if (abs(Smax / dS - round(Smax / dS)) > 1e-9 || abs(S0 / dS - round(S0 / dS)) > 1e-9) throw new RangeError('Grid nodes must fall on the stock price and on the top of the grid');
}
// Normal CDF: Taylor series near the centre, continued fraction in the tails.
const phi = x => exp(-0.5 * x * x) / sqrt(2 * PI);
function Phi(x) {
  const a = abs(x);
  if (a <= 3) {
    let term = a, sum = a;
    for (let n = 1; n < 200 && term > 1e-17 * sum; n++) { term *= a * a / (2 * n + 1); sum += term; }
    return x >= 0 ? 0.5 + phi(a) * sum : 0.5 - phi(a) * sum;
  }
  let f = a;
  for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - phi(a) / f : phi(a) / f;
}
// European put by the Black-Scholes formula: the benchmark the grid must reproduce.
function bsPut(S) {
  if (!(S > 0)) throw new RangeError('Stock price must be positive');
  const v = sigma * sqrt(T), d1 = (log(S / K) + (r - q + 0.5 * sigma * sigma) * T) / v, d2 = d1 - v;
  return {put: K * exp(-r * T) * Phi(-d2) - S * exp(-q * T) * Phi(-d1), delta: -exp(-q * T) * Phi(-d1), gamma: exp(-q * T) * phi(d1) / (S * v)};
}
const payoff = S => max(K - S, 0);
// Per-year PDE coefficients at node i (S = i dS): L V_i = al V_{i-1} + be V_i + ga V_{i+1}.
const coef = i => ({al: 0.5 * (sigma * sigma * i * i - (r - q) * i), be: -(sigma * sigma * i * i + r), ga: 0.5 * (sigma * sigma * i * i + (r - q) * i)});
function weights(i, dt) { const c = coef(i); return {a: dt * c.al, b: 1 + dt * c.be, c: dt * c.ga}; }
// One explicit step back from expiry at chosen nodes, then the early-exercise choice.
function handStep(dS, dt, nodes) {
  return nodes.map(i => {
    const w = weights(i, dt), S = i * dS, hold = w.a * payoff(S - dS) + w.b * payoff(S) + w.c * payoff(S + dS);
    return {S, a: w.a, b: w.b, c: w.c, hold, exercise: payoff(S), value: max(hold, payoff(S))};
  });
}
// Explicit scheme. European: bottom edge K e^{-r tau}; American: bottom edge K and max() every step.
function explicitPut(dS, Smax, steps, american) {
  checkGrid(dS, Smax, steps);
  const M = round(Smax / dS), dt = T / steps;
  let V = Array.from({length: M + 1}, (_, i) => payoff(i * dS));
  for (let n = 1; n <= steps; n++) {
    const W = V.slice();
    for (let i = 1; i < M; i++) {
      const w = weights(i, dt);
      W[i] = w.a * V[i - 1] + w.b * V[i] + w.c * V[i + 1];
      if (american) W[i] = max(W[i], K - i * dS);
    }
    W[0] = american ? K : K * exp(-r * n * dt); W[M] = 0;
    V = W;
  }
  return V[round(S0 / dS)];
}
// The fewest steps that keep every centre weight b_i >= 0, i.e. dt (sigma^2 M^2 + r) <= 1.
function stabilityLimit(dS, Smax) {
  const M = round(Smax / dS), dtMax = 1 / (sigma * sigma * M * M + r);
  return {M, dtMax, minSteps: ceil(T / dtMax)};
}
// What one step does to a zigzag of size 1 at the node of price S, lambda = sigma^2 i^2 dt / 2.
function zigzagAt(S, dS, steps) {
  const i = S / dS, lam = 0.5 * sigma * sigma * i * i * T / steps;
  return {lambda: lam, explicit: 1 - 4 * lam, implicit: 1 / (1 + 4 * lam), crankNicolson: (1 - 2 * lam) / (1 + 2 * lam)};
}
// Thomas algorithm: a tridiagonal system in work proportional to its size.
function thomas(lo, di, up, rhs) {
  const n = di.length, c = new Array(n), d = new Array(n), x = new Array(n);
  c[0] = up[0] / di[0]; d[0] = rhs[0] / di[0];
  for (let i = 1; i < n; i++) { const m = di[i] - lo[i] * c[i - 1]; c[i] = up[i] / m; d[i] = (rhs[i] - lo[i] * d[i - 1]) / m; }
  x[n - 1] = d[n - 1];
  for (let i = n - 2; i >= 0; i--) x[i] = d[i] - c[i] * x[i + 1];
  return x;
}
// omega = 1 implicit, omega = 0.5 Crank-Nicolson; the first `implicitStart` steps are fully implicit (Rannacher).
// American: solve, then take the max with the exercise value at every node.
function thetaPut(dS, Smax, steps, omega, american, implicitStart = 0) {
  checkGrid(dS, Smax, steps);
  if (!(omega >= 0 && omega <= 1)) throw new RangeError('Omega must lie between 0 and 1');
  const M = round(Smax / dS), dt = T / steps, C = Array.from({length: M + 1}, (_, i) => coef(i));
  let V = Array.from({length: M + 1}, (_, i) => payoff(i * dS)), boundary = K;
  for (let n = 1; n <= steps; n++) {
    const w = n <= implicitStart ? 1 : omega;
    const lo = new Array(M + 1).fill(0), di = new Array(M + 1).fill(1), up = new Array(M + 1).fill(0), rhs = V.slice();
    for (let i = 1; i < M; i++) {
      lo[i] = -w * dt * C[i].al; di[i] = 1 - w * dt * C[i].be; up[i] = -w * dt * C[i].ga;
      rhs[i] = V[i] + (1 - w) * dt * (C[i].al * V[i - 1] + C[i].be * V[i] + C[i].ga * V[i + 1]);
    }
    rhs[0] = american ? K : K * exp(-r * n * dt); rhs[M] = 0;
    V = thomas(lo, di, up, rhs);
    if (american) {
      boundary = NaN;
      for (let i = 0; i <= M; i++) { V[i] = max(V[i], K - i * dS); if (V[i] - (K - i * dS) < 1e-9) boundary = i * dS; }
    }
  }
  const j = round(S0 / dS);
  return {value: V[j], delta: (V[j + 1] - V[j - 1]) / (2 * dS), gamma: (V[j + 1] - 2 * V[j] + V[j - 1]) / (dS * dS), boundary, V};
}
// Cross-check with a Cox-Ross-Rubinstein tree, early exercise at every node.
function treePut(steps) {
  const dt = T / steps, u = exp(sigma * sqrt(dt)), d = 1 / u, disc = exp(-r * dt), p = (exp((r - q) * dt) - d) / (u - d);
  const V = Array.from({length: steps + 1}, (_, j) => payoff(S0 * u ** (steps - 2 * j)));
  for (let n = steps - 1; n >= 0; n--) for (let j = 0; j <= n; j++) V[j] = max(disc * (p * V[j] + (1 - p) * V[j + 1]), K - S0 * u ** (n - 2 * j));
  return V[0];
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ความชันและความโค้งเขียนได้ด้วยค่าที่สามแถวข้างเคียง โดยพลาดเป็นสัดส่วนกับ $\Delta S^2$ ใส่ลงใน PDE แล้วได้น้ำหนัก $a_i$, $b_i$, $c_i$ ที่รวมกันได้ $1-r\Delta t$ น้ำหนักชุดนี้ให้ค่าเฉลี่ยและ variance ของการขยับของหุ้นในโลก risk-neutral พอดี กริด explicit จึงเป็นต้นไม้สามกิ่ง
  • American put เลือกค่าที่มากกว่าระหว่าง $K-S$ กับมูลค่าถือต่อ ทุกช่องทุกก้าว ที่หุ้น \$45 หนึ่งก้าวก่อนหมดอายุ ถือต่อแพ้การใช้สิทธิ์เท่ากับดอกเบี้ยของ strike พอดี คือ $rK\Delta t=0.052$
  • explicit ต้องมี $\Delta t\le1/(\sigma^2M^2+r)$ เพราะทุกก้าวคูณรอยหยักด้วย $1-4\lambda$ ถ้าละเมิดกฎ ผลมีได้ตั้งแต่ราคาผิดแบบเงียบ ๆ (4.3671 แทน 4.6169) ไปจนถึง −2.7 พันล้าน
  • implicit กับ Crank–Nicolson ไม่ระเบิด implicit พลาดเป็นสัดส่วนกับ $\Delta t$ ส่วน Crank–Nicolson พลาดเป็นสัดส่วนกับ $\Delta t^2$ แต่ต้องเริ่มด้วย implicit สองก้าว ไม่อย่างนั้น gamma ที่ strike จะแกว่ง
  • put ของโจทย์เปิดเรื่องมีค่า \$4.7830 ต่อหุ้น (Richardson จากกริดสี่ระดับ ต้นไม้ CRR ให้ 4.7831) มากกว่า European $4.7830-4.6213=\$0.1617$ ควรใช้สิทธิ์ทันทีเมื่อหุ้นต่ำกว่าราว \$38.5 และ delta คือ −0.5093
