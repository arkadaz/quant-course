13.6 Girsanov and the Risk-Neutral Measure

การเปลี่ยน measure คือการคูณน้ำหนักใหม่ให้เส้นทางเดิมทุกเส้น จน drift ของหุ้นกลายเป็นดอกเบี้ยโดยความผันผวนไม่เปลี่ยน ราคาของสัญญาจึงเป็นค่าเฉลี่ยใต้น้ำหนักชุดนั้นคิดลดกลับ และไม่ขึ้นกับว่าใครเชื่อว่าหุ้นจะโตเท่าไร

หุ้นสมมติราคา \$100 มี drift 12% ความผันผวน 28% ต่อปี ดอกเบี้ยปลอดความเสี่ยง 2% ลูกค้าขอราคาสัญญา digital ที่จ่าย \$1 ถ้าปีหน้าหุ้นปิดเหนือ \$110 นักวิเคราะห์คิดโอกาสจากแบบจำลองได้ 47.93% คิดลดหนึ่งปีได้ $e^{-0.02}(0.4793)=\$0.4698$ ควรเสนอราคานี้ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ควร ราคาที่ไม่เปิดช่องให้ใครได้เงินฟรีคือ \$0.3345 ซึ่งใช้โอกาส 34.13% ของโลกที่หุ้นโตเท่าดอกเบี้ย ไม่ใช่ 47.93% ของโลกจริง ส่วนต่าง \$0.1353 ต่อสัญญาคือเงินที่คนอื่นเก็บได้โดยขายสัญญาให้เราแล้ว hedge ด้วยหุ้น และคนที่เชื่อว่าหุ้นโตแค่ 5% ก็ได้ราคา \$0.3345 เท่ากัน

ภาพรวมก่อนลงสูตร

คำตอบแรกที่ทุกคนคิดคือ “ราคาคือค่าเฉลี่ยของเงินที่จ่าย คิดลดกลับ” คำถามคือค่าเฉลี่ยใต้โอกาสชุดไหน ต้นไม้หนึ่งงวดตอบได้โดยไม่ต้องเดา: สร้างพอร์ตหุ้นกับเงินสดที่จ่ายเท่ากับสัญญาทุกกรณี ต้นทุนของพอร์ตนั้นคือราคา และตอนคำนวณ โอกาสจริงที่หุ้นจะขึ้นไม่ถูกใช้เลย สิ่งที่โผล่ออกมาแทนคือโอกาสชุดใหม่ที่ทำให้หุ้นโตเท่าเงินฝาก เรียกว่า risk-neutral measure $Q$

ในเวลาต่อเนื่อง ทฤษฎีบทของ Girsanov บอกว่าโลก $Q$ ไม่ต้องสร้างเส้นทางใหม่ ใช้เส้นทางเดิมของโลกจริง $P$ ทุกเส้น แค่คูณน้ำหนักให้แต่ละเส้น เส้นที่จบสูงได้น้ำหนักน้อยลง เส้นที่จบต่ำได้น้ำหนักมากขึ้น ผลคือการกระจายของราคาเลื่อนไปทางซ้ายทั้งก้อนโดยความกว้างเท่าเดิม รูปด้านล่างคือคำตอบของโจทย์เปิดเรื่องในภาพเดียว

หน้านี้เริ่มจากต้นไม้หนึ่งงวดด้วยมือ อ่านโอกาสชุดใหม่เป็นน้ำหนักของเส้นทาง ขยายไปเวลาต่อเนื่องจนได้น้ำหนัก $e^{-\lambda W_T-\frac12\lambda^2T}$ ใช้กฎผลคูณของ Itôหาค่า $\lambda$ ตัวเดียวที่ใช้ได้ ได้สูตรตั้งราคา ตอบโจทย์ digital แสดงว่า drift ของหุ้นหายไปจากราคา แล้วตรวจด้วยการสุ่มสองทาง

ศัพท์ที่ใช้ในหัวข้อนี้
Physical measure $P$
ชุดโอกาสที่พยายามบอกความถี่ของเหตุการณ์จริง ใช้ทำคำทาย stress test และวัดความเสี่ยงเช่น VaR
Risk-neutral measure $Q$
ชุดโอกาสที่ทำให้ราคาที่คิดลดของทุกสิ่งที่ซื้อขายได้เป็น martingale (ค่าเฉลี่ยของอนาคตเท่ากับค่าวันนี้) ใช้ตั้งราคา ไม่ใช่คำทายโลกจริง
Replicating portfolio
พอร์ตหุ้นกับเงินสดที่จ่ายเท่ากับสัญญาทุกกรณี ต้นทุนของมันคือราคาของสัญญา เพราะถ้าไม่เท่าจะมีคนซื้อถูกขายแพงเก็บส่วนต่างฟรี
Radon–Nikodym derivative $dQ/dP$
ตัวคูณน้ำหนักของแต่ละเส้นทาง คือน้ำหนักใหม่หารด้วยน้ำหนักเก่า ใช้แปลงค่าเฉลี่ยใต้ $P$ เป็นค่าเฉลี่ยใต้ $Q$: $\mathbb E^Q[X]=\mathbb E^P[Z\,X]$
Market price of risk $\lambda$
$(\mu-r)/\sigma$ ผลตอบแทนส่วนเกินต่อความผันผวนหนึ่งหน่วย คือ Sharpe ratio ของหุ้น บอกว่าต้องเอียงน้ำหนักมากแค่ไหน
Girsanov theorem
ผลที่ว่าใต้น้ำหนัก $e^{-\lambda W_T-\frac12\lambda^2T}$ process $W_t+\lambda t$ เป็น Brownian motion ใช้ย้าย drift โดยไม่แตะความผันผวน
Digital option
สัญญาที่จ่ายเงินก้อนคงที่ถ้าราคาปลายทางเกินระดับที่กำหนด ราคาของมันคือโอกาสใต้ $Q$ คิดลด จึงเป็นตัวอย่างที่เห็น $Q$ ชัดที่สุด
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$P,\ Q$ชุดโอกาสของโลกจริง และของการตั้งราคา—
$p,\ q$โอกาสขาขึ้นในต้นไม้หนึ่งงวด ใต้ $P$ และใต้ $Q$ไม่มีหน่วย
$R$เงิน \$1 ที่ฝากไว้หนึ่งงวดโตเป็น $R$ ดอลลาร์ไม่มีหน่วย
$S_t,\ \mu,\ \sigma$ราคาหุ้น, drift ใต้ $P$, ความผันผวนดอลลาร์ต่อหุ้น, ต่อปี, ต่อ $\sqrt{\text{yr}}$

ขั้นที่ 1 — ต้นไม้หนึ่งงวด: ราคามาจากการเลียนแบบ ไม่ได้มาจากโอกาสจริง

โจทย์ให้อะไรมาบ้าง: หุ้นวันนี้ \$100 งวดหน้าเป็น \$107 หรือ \$93.46 เงินฝากโต 1% ต่องวด ($R=1.01$) call ที่ strike \$102 จ่าย \$5 ถ้าหุ้นขึ้นและ \$0 ถ้าหุ้นลง หาพอร์ตที่ถือหุ้น $x$ หุ้นและเงินสด $y$ ดอลลาร์ ให้จ่ายเท่ากับ call ทั้งสองกรณี แล้วเทียบกับค่าเฉลี่ยใต้โอกาส $q=(R-d)/(u-d)$ โดย $u=1.07$ และ $d=0.9346$

\[ \begin{aligned} 107x+1.01y&=5,\\ 93.46x+1.01y&=0,\\ x&=5/13.54=0.3693,\\ y&=-93.46(0.3693)/1.01\\ &=-34.1708,\\ C_0&=100x+y=2.757,\\ q&=\frac{1.01-0.9346}{1.07-0.9346}=0.5569,\\ \tfrac1R\big[q(5)+(1-q)(0)\big]&=2.757. \end{aligned} \]

คำตอบ: call ราคา \$2.76 เพราะเป็นต้นทุนของพอร์ต 0.3693 หุ้นที่กู้เงินมา \$34.17 ซึ่งจ่ายเท่ากับ call ทุกกรณี ถ้า call ขายแพงกว่านี้ ใครก็ขาย call แล้วซื้อพอร์ตเก็บส่วนต่างฟรี ถูกกว่าก็ทำกลับข้าง สังเกตว่าตลอดการคำนวณไม่มีโอกาสจริง $p$ ที่หุ้นจะขึ้นเลย หุ้นสองตัวที่ราคาวันนี้และปลายทางเหมือนกันทุกอย่าง แต่ตัวหนึ่งขึ้นด้วยโอกาส 99% อีกตัวขึ้นด้วยโอกาส 1% จึงมี call ราคาเดียวกัน บรรทัดสุดท้ายบอกว่าราคาเดียวกันนี้เขียนเป็นค่าเฉลี่ยคิดลดใต้โอกาส $q$ ได้

ตรวจเองใน 10 วินาที: กรณีขึ้น $0.3693(107)-34.1708(1.01)=39.51-34.51=5.00$ กรณีลง $0.3693(93.46)-34.51=0.00$

ขั้นที่ 2 — q คือน้ำหนักใหม่ของเส้นทางเดิม

$q$ ที่โผล่ออกมาเป็นโอกาสได้จริงไหม และมันเกี่ยวกับ $p$ อย่างไร สมมติว่าโลกจริงให้หุ้นขึ้นด้วยโอกาส $p=0.70$ (สมมติ) แล้วเขียน $q$ เป็นตัวคูณของน้ำหนักเดิมทีละกิ่ง ตัวคูณนี้ชื่อ $Z=dQ/dP$

\[ \begin{aligned} Z(\text{up})&=q/p=0.5569/0.70\\ &=0.7955,\\ Z(\text{down})&=(1-q)/(1-p)\\ &=0.4431/0.30=1.4771,\\ \mathbb E^P[Z]&=0.70(0.7955)+0.30(1.4771)\\ &=1,\\ \mathbb E^Q[S_1]&=\mathbb E^P[Z\,S_1]\\ &=0.5569(107)+0.4431(93.46)\\ &=101.00=R\,S_0,\\ \mathbb E^P[S_1]&=0.70(107)+0.30(93.46)\\ &=102.94. \end{aligned} \]

$q$ อยู่ระหว่าง 0 กับ 1 พอดีเมื่อ $d\lt R\lt u$ คือ $0.9346\lt1.01\lt1.07$ ถ้าเงินฝากโตเร็วกว่าหุ้นแม้ในกรณีดีที่สุด ($R\ge u$) ทุกคนจะ short หุ้นไปฝากเงินได้กำไรแน่นอน ถ้าหุ้นแย่ที่สุดยังชนะเงินฝาก ($R\le d$) ทุกคนจะกู้เงินซื้อหุ้น ไม่มีเงินฟรีจึงเป็นเงื่อนไขเดียวกับการมี $q$ ที่เป็นโอกาสได้ ข้อสรุปนี้เรียกว่า first fundamental theorem of asset pricing

ตัวคูณ $Z$ ลดน้ำหนักกิ่งขึ้นลงเหลือ 0.7955 เท่า และเพิ่มกิ่งลงเป็น 1.4771 เท่า โดยค่าเฉลี่ยของตัวคูณใต้ $P$ เท่ากับ 1 พอดี $Q$ จึงเป็นชุดโอกาสที่ถูกต้อง ใต้ $Q$ หุ้นโต 1% เท่าเงินฝาก ใต้ $P$ หุ้นโต 2.94% ส่วนเกิน 1.94% คือค่าตอบแทนของการรับความเสี่ยง ถ้าโลกจริงมี $p=0.99$ ตัวคูณของกิ่งลงจะเป็น 44.31 แต่ $q$ และราคา call ไม่เปลี่ยนเลย

ขั้นที่ 3 — น้ำหนักแบบต่อเนื่อง: exponential ของปลายทาง

ในต้นไม้หลายงวด น้ำหนักของทั้งเส้นทางคือผลคูณของตัวคูณทีละงวด ซึ่งขึ้นกับว่าเส้นทางขึ้นกี่ครั้งเท่านั้น จำนวนครั้งที่ขึ้นเป็นเส้นตรงของตำแหน่งปลายทาง log ของน้ำหนักจึงเป็นเส้นตรงของ $W_T$ เมื่อซอยงวดจนต่อเนื่อง น้ำหนักจึงอยู่ในรูป $e^{-\lambda W_T-c}$ ค่าคงที่ $c$ ต้องทำให้น้ำหนักเฉลี่ยเป็น 1 ใช้ moment generating function ของ Normal: $\mathbb E[e^{uW_T}]=e^{u^2T/2}$ ใช้หุ้นของโจทย์เปิดเรื่อง ค่า $\lambda=(0.12-0.02)/0.28$ จะหาที่มาด้านล่าง

\[ \begin{aligned} Z_T&=e^{-\lambda W_T-c},\\ \mathbb E^P[e^{-\lambda W_T}]&=e^{\lambda^2T/2},\\ c&=\tfrac12\lambda^2T,\\ \lambda&=0.10/0.28=0.357143,\\ \tfrac12\lambda^2&=0.063776,\\ W_1=+1&:\ e^{-0.420919}=0.6564,\\ W_1=0&:\ e^{-0.063776}=0.9382,\\ W_1=-1&:\ e^{0.293367}=1.3409,\\ dZ_t&=-\lambda Z_t\,dW_t. \end{aligned} \]

เส้นทางที่จบที่ $W_1=+1$ ถูกลดน้ำหนักราว 34% เส้นที่จบที่ $-1$ ถูกเพิ่มราว 34% โลก $Q$ ให้น้ำหนักกับเส้นทางที่เลวร้ายมากกว่าโลกจริง นี่คือการตีราคาของความเสี่ยงเข้าไปในโอกาส

บรรทัดสุดท้ายได้จาก Itô's lemma กับ $e^{-\lambda W_t-\frac12\lambda^2t}$: ความโค้งให้ $+\tfrac12\lambda^2$ หักกับ $-\tfrac12\lambda^2$ ที่ใส่ไว้พอดี $dZ$ จึงเหลือแต่ส่วนสุ่ม เป็น Itô integral ที่ค่าเฉลี่ยคงที่ มองจากเวลาไหน ค่าเฉลี่ยของน้ำหนักปลายทางก็เท่ากับน้ำหนักตอนนั้น ($\mathbb E_s^P[Z_T]=Z_s$) น้ำหนักจึงสอดคล้องกันทุกเวลา ถ้าลืมค่าคงที่ $c$ น้ำหนักรวมกันได้ $e^{0.063776}=1.0659$ ทุกราคาที่คิดด้วยน้ำหนักนั้นจะสูงเกิน 6.6%

ขั้นที่ 4 — ใต้ Q ระฆังของ W เลื่อนไป แต่ความกว้างเท่าเดิม

density ของ $W_T$ ใต้ $Q$ คือ density ใต้ $P$ คูณน้ำหนัก ทั้งสองเป็น exponential จึงรวมเลขชี้กำลังได้ แล้วเติมกำลังสองแบบเดียวกับที่ใช้หาราคาคาดหวังของ GBM

\[ \begin{aligned} &-\frac{w^2}{2T}-\lambda w-\frac{\lambda^2T}{2}\\ &\quad=-\frac{(w+\lambda T)^2}{2T},\\ &W_T\ \text{under}\ Q\sim\mathcal N(-\lambda T,\ T),\\ &W^Q_t:=W_t+\lambda t,\\ &W_T^Q\sim\mathcal N(0,\ T)\ \text{under}\ Q. \end{aligned} \]

คูณน้ำหนักแล้วได้ระฆังความกว้างเดิมที่จุดกลางเลื่อนไป $-\lambda T=-0.357$ การเปลี่ยนน้ำหนักแบบนี้ย้ายแค่จุดกลาง ไม่แตะความกว้าง บวก $\lambda t$ กลับเข้าไปก็ได้ Brownian motion ที่เริ่มจากศูนย์อีกครั้ง บรรทัดนี้ดูแค่ปลายทาง ทฤษฎีบทของ Girsanov (ยกมาใช้ พิสูจน์ด้วยการทำแบบเดียวกันกับทุกช่วงเวลาย่อย) บอกว่าทั้งเส้นทาง $W_t^Q$ เป็น Brownian motion ใต้ $Q$: การขยับแต่ละช่วงยังอิสระกันและยังมี variance เท่ากับความยาวช่วง

ขั้นที่ 5 — หา λ ด้วยกฎผลคูณ: ราคาหุ้นที่คิดลดต้องไม่มี drift ใต้ Q

ในต้นไม้ $q$ ถูกกำหนดด้วยเงื่อนไขเดียวคือหุ้นต้องโตเท่าเงินฝากใต้ $Q$ ในเวลาต่อเนื่องก็เหมือนกัน: ราคาที่คิดลด $\tilde S_t:=e^{-rt}S_t$ ต้องมีค่าเฉลี่ยคงที่ใต้ $Q$ ค่าเฉลี่ยใต้ $Q$ คือค่าเฉลี่ยใต้ $P$ ของ $Z\tilde S$ จึงต้องให้ $Z\tilde S$ ไม่มี drift ใต้ $P$ ใช้กฎผลคูณกับ $Z$ และ $\tilde S$ โดย $d\tilde S=\tilde S\big((\mu-r)\,dt+\sigma\,dW\big)$

\[ \begin{aligned} d(Z\tilde S)&=Z\,d\tilde S+\tilde S\,dZ+dZ\,d\tilde S,\\ dZ\,d\tilde S&=(-\lambda Z\,dW)(\sigma\tilde S\,dW)\\ &=-\lambda\sigma Z\tilde S\,dt,\\ \text{drift}&=Z\tilde S\,(\mu-r-\lambda\sigma)=0,\\ \lambda&=\frac{\mu-r}{\sigma}=\frac{0.12-0.02}{0.28}\\ &=0.357143,\\ \frac{dS}{S}&=r\,dt+\sigma\,dW^Q. \end{aligned} \]

พจน์ $\tilde S\,dZ$ ไม่มี drift เพราะ $dZ$ มีแต่ส่วนสุ่ม drift ทั้งหมดจึงมาจาก $Z\,d\tilde S$ ซึ่งให้ $\mu-r$ และพจน์ไขว้ซึ่งให้ $-\lambda\sigma$ มีค่า $\lambda$ ค่าเดียวที่หักกันพอดี ไม่ใช่ทางเลือกตามความเห็น บรรทัดสุดท้ายได้จากการแทน $dW=dW^Q-\lambda\,dt$ ลงใน SDE ของหุ้น: drift เป็น $\mu-\sigma\lambda=r$ ใต้ $Q$ หุ้นโตเท่าดอกเบี้ย และความผันผวนยังเป็น 28%

ถ้าหุ้นจ่ายเงินปันผลต่อเนื่องในอัตรา $c$ ต่อปี คนถือได้ทั้งราคาที่ขึ้นและเงินปันผล ผลรวมสองก้อนนี้ต่างหากที่ต้องโตเท่าเงินฝาก ใต้ $Q$ ราคาจึงมี drift $r-c$ (ดูเงินปันผลในสูตรราคา) ต้นไม้ก็ใช้หลักเดียวกัน: $q=(R-c-d)/(u-d)$ เมื่อหุ้นจ่ายปันผล $c$ เท่าของราคาต่องวด

ขั้นที่ 6 — สูตรตั้งราคา: ค่าเฉลี่ยใต้ Q แล้วคิดลด

ต้นไม้หนึ่งงวดพิสูจน์ด้วยพอร์ตเลียนแบบว่าราคาคือค่าเฉลี่ยใต้ $q$ คิดลด ในเวลาต่อเนื่อง หลักเดียวกันคือราคาที่คิดลดของทุกสิ่งที่ซื้อขายได้เป็น martingale ใต้ $Q$ (ยกมาใช้ พอร์ตเลียนแบบของ Black–Scholes สร้างพอร์ตที่ทำให้มันเป็นจริง) อ่านสมบัตินี้ที่เวลา 0 กับสัญญาที่จ่าย $H_T$ แล้วตรวจกับหุ้นเองและกับสัญญา forward

\[ \begin{aligned} V_0&=e^{-rT}\,\mathbb E^Q[H_T],\\ \mathbb E^Q[S_1]&=100\,e^{0.02}=102.02,\\ e^{-0.02}(102.02)&=100.00,\\ 0&=e^{-rT}\,\mathbb E^Q[S_T-G_0],\\ G_0&=\mathbb E^Q[S_T]=102.02,\\ \mathbb E^P[S_1]&=100\,e^{0.12}=112.75. \end{aligned} \]

ตัวคิดลดดึงออกนอกค่าเฉลี่ยได้เพราะดอกเบี้ยคงที่ ตรวจกับหุ้น: ค่าเฉลี่ยใต้ $Q$ โต 2% เป็น \$102.02 เท่ากับฝากเงินเฉย ๆ คิดลดกลับได้ \$100 พอดี สัญญา forward ที่ตกลงซื้อหุ้นปีหน้าในราคา $G_0$ ไม่มีต้นทุนวันนี้ ค่าเฉลี่ยคิดลดของมันจึงเป็นศูนย์ ได้ราคา forward \$102.02 คือค่าเฉลี่ยใต้ $Q$ ไม่ใช่ใต้ $P$ ส่วนค่าเฉลี่ยใต้ $P$ \$112.75 เป็นคำทายที่ดีกว่า แต่คิดลดแล้วได้ \$110.52 ซึ่งไม่ใช่ราคาของอะไรเลย

ขั้นที่ 7 — คำตอบของโจทย์เปิดเรื่อง: digital ที่ \$110 ในสองโลก

โจทย์ให้อะไรมาบ้าง: สัญญาจ่าย \$1 ถ้า $S_1\gt110$ จุดกลางของ $\ln(S_1/S_0)$ คือ drift ลบ $\tfrac12\sigma^2=0.0392$ (ผลของ Itô's lemma กับ log ราคา) ใต้ $P$ ได้ $0.12-0.0392=0.0808$ ใต้ $Q$ ได้ $0.02-0.0392=-0.0192$ ความผันผวน 0.28 เท่ากันทั้งสองโลก ใช้ $\Phi$ ของ Normal distribution

\[ \begin{aligned} \ln(110/100)&=0.0953102,\\ P(S_1\gt110)&=1-\Phi\Big(\frac{0.0953102-0.0808}{0.28}\Big)\\ &=1-\Phi(0.0518)=0.4793,\\ Q(S_1\gt110)&=1-\Phi\Big(\frac{0.0953102+0.0192}{0.28}\Big)\\ &=1-\Phi(0.4090)=0.3413,\\ V_0&=e^{-0.02}(0.3413)=0.3345. \end{aligned} \]

คำตอบ: ราคาคือ \$0.3345 ไม่ใช่ \$0.4698 สองโอกาสต่างกัน 13.81 จุด ทั้งที่เกณฑ์และความผันผวนเหมือนกัน ต่างกันแค่จุดกลาง ในรูปภาพรวมคือพื้นที่ส้มเทียบพื้นที่น้ำเงินทางขวาของเส้นประ ตัวเลข 34.13% คือ $\Phi(d_2)$ ในสูตร Black–Scholes มันไม่เคยเป็นโอกาสที่หุ้นจะปิดเหนือ \$110 ในโลกจริง

ตรวจเองใน 10 วินาที: $0.4793-0.3413=0.1380$ และ $e^{-0.02}\approx0.9802$ คูณ 0.3413 ได้ 0.3345

ขั้นที่ 8 — drift ของหุ้นหายไปจากราคา

นักวิเคราะห์อีกคนเชื่อว่าหุ้นตัวนี้โตแค่ 5% ต่อปี ลองคิดทั้งสองโลกด้วยความเชื่อนี้ และดูว่าถ้าเลือก $\lambda$ ผิด drift ใต้น้ำหนักใหม่จะเป็นอย่างไร

\[ \begin{aligned} \mu=0.05&:\ \lambda=0.03/0.28=0.1071,\\ P(S_1\gt110)&=0.3814,\\ Q(S_1\gt110)&=0.3413,\\ V_0&=0.3345,\\ \lambda=0&:\ \mu-\sigma\lambda=0.12\gt r,\\ \lambda=0.5&:\ 0.12-0.28(0.5)\\ &\qquad=-0.02\lt r. \end{aligned} \]

สองคนเห็นต่างเรื่องโลกจริง (47.93% กับ 38.14%) แต่ได้ $Q$ และราคาเดียวกัน เพราะใต้ $Q$ drift ของหุ้นถูกแทนด้วย $r$ เสมอ ไม่ว่า $\mu$ เดิมเป็นเท่าไร ความเห็นเรื่อง $\mu$ เปลี่ยนแค่ $\lambda$ ซึ่งเป็นตัวกลางที่หักล้างตัวเองออกไป เหมือนในต้นไม้ที่ $p$ เปลี่ยนแค่ตัวคูณ $Z$ แต่ไม่เปลี่ยน $q$

ถ้าเลือก $\lambda$ ผิด หุ้นในโลกตั้งราคาจะโตเร็วหรือช้ากว่าเงินฝาก ที่ $\lambda=0$ หุ้นโต 12% ขณะกู้ได้ที่ 2% ราคาที่คิดจากโลกนั้นเปิดช่องให้กู้เงินซื้อหุ้นแล้วได้ส่วนเกินฟรี

ขั้นที่ 9 — ตรวจด้วยการสุ่มสองทาง

โจทย์ให้อะไรมาบ้าง: โค้ดท้ายหน้าสุ่ม $W_1$ ใต้ $P$ 200,000 ครั้งด้วย seed 136 ทางที่หนึ่งคูณแต่ละครั้งด้วยน้ำหนัก $Z_1$ แล้วเฉลี่ย ทางที่สองสุ่มราคาใหม่ด้วย drift $r$ ตรง ๆ แล้วนับ ถ้าการเปลี่ยนน้ำหนักถูก สองทางต้องให้ตัวเลขเดียวกัน

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

ตั้งราคาด้วยโอกาสใต้ $P$: digital ถูกเสนอที่ \$0.4698 แทน \$0.3345 แพงเกิน 40% ถ้าโต๊ะเสนอซื้อที่ราคานั้น คนอื่นจะขายให้แล้ว hedge ด้วยหุ้น ได้ \$0.1353 ต่อสัญญาโดยไม่รับความเสี่ยงของหุ้น

วัดความเสี่ยงใต้ $Q$: ราคาหุ้นที่ quantile 5% ของปีหน้าใต้ $P$ คือ $100e^{0.0808-1.645(0.28)}=\$68.40$ ใต้ $Q$ ได้ \$61.89 VaR 95% ของหุ้นหนึ่งหุ้นจึงถูกรายงานเป็น \$38.11 แทน \$31.60 เกินจริง 21% เพราะโลก $Q$ ถูกตั้งให้หุ้นโตแค่ 2%

อ่าน $Q$ เป็นคำทาย: median ของราคาปีหน้าใต้ $Q$ คือ $100e^{0.02-0.0392}=\$98.10$ ต่ำกว่าวันนี้ ขณะที่ใต้ $P$ คือ \$108.42 ถ้าอ่านเป็นคำทาย นี่คือการบอกว่าหุ้นที่ drift 12% น่าจะลง ซึ่งไม่มีใครเชื่อ $Q$ ไม่ได้ทำหน้าที่ทาย ระยะ \$10.32 ระหว่างสอง median คือระยะที่ความเสี่ยงถูกตีราคาเข้าไปในน้ำหนัก

ลืม $-\tfrac12\lambda^2T$ ในน้ำหนัก: น้ำหนักรวมกันได้ 1.0659 ไม่ใช่ 1 ราคา digital ที่คิดจากน้ำหนักนี้กลายเป็น \$0.3566 สูงเกิน 6.6% และทุกราคาในระบบเพี้ยนขึ้นเท่ากัน

ใช้ทำอะไรบนโต๊ะจริง

ทุกระบบตั้งราคา derivative ใช้ $Q$: สุ่มเส้นทางด้วย drift $r$ (หรือถ่วงน้ำหนักเส้นทางเดิม) เฉลี่ยเงินที่จ่าย แล้วคิดลด ระบบความเสี่ยงอย่าง VaR และ expected shortfall ใช้ $P$ ทีมที่ใช้ระบบเดียวทำทั้งสองงานต้องแยกให้ชัดว่า drift ที่ใส่คือตัวไหน

$Q$ ไม่ใช่แค่ทฤษฎี ตลาดบอกมันให้เห็นได้ ราคา call ที่ strike ติดกันสามตัวประกอบเป็น butterfly ที่จ่ายเงินเฉพาะเมื่อราคาปลายทางอยู่ใกล้ $K$ ราคาของ butterfly จึงเท่ากับ density ใต้ $Q$ ที่ $K$ คิดลด เมื่อช่อง strike แคบลงได้ $f^Q_T(K)=e^{rT}\,\partial^2C/\partial K^2$ ทำนองเดียวกัน digital คือ call สองตัวที่ strike ห่างกันนิดเดียว ราคาของมันคือ $-\partial C/\partial K$ ตัวอย่างที่ใช้กันบ่อย: ดอกเบี้ยศูนย์ หุ้น \$100 หนึ่งปี ความผันผวน at-the-money 25% และ skew ที่ความผันผวนลด 2.5 จุดเมื่อ strike ขึ้น 10% digital ที่ \$100 ราคา $\Phi(-0.125)+39.58(0.0025)=0.450+0.099\approx0.55$ ของ notional ถ้าใช้สูตร Black–Scholes ที่ไม่สน skew จะได้แค่ 0.45 ต่ำไปราว 10 จุด

ในหน้านี้มีแหล่งความเสี่ยงแหล่งเดียวและ hedge ด้วยหุ้นได้ $Q$ จึงมีชุดเดียว เมื่อความผันผวนเองก็สุ่มอย่างใน แบบจำลอง Heston จะมี $Q$ ได้หลายชุด ตลาด option เป็นคนเลือกชุดที่ใช้ หน้าถัดไป Feynman–Kac เปลี่ยนสูตร $V_0=e^{-rT}\mathbb E^Q[H_T]$ ให้เป็นสมการเชิงอนุพันธ์ย่อยที่แก้บนตารางได้

รันใน Node.js ได้โดยไม่ต้องติดตั้งอะไร โค้ดคิดพอร์ตเลียนแบบของต้นไม้หนึ่งงวด ตัวคูณน้ำหนัก $\lambda$ โอกาสใต้ $P$ และ $Q$ และราคา digital แล้วสุ่มสองทางด้วยเครื่องสุ่มที่มี seed: ถ่วงน้ำหนักเส้นทางของโลกจริง กับสุ่มใหม่ด้วย drift $r$ แล้วพิมพ์ JSON บรรทัดเดียว

// Standard Normal CDF: Simpson's rule on the bell curve from 0 to |x|.
function Phi(x) {
  if (!Number.isFinite(x) || Math.abs(x) > 8) throw new RangeError('Phi needs a finite score between -8 and 8');
  const n = 4000, h = Math.abs(x) / n, phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(x) * s * h / 3;
}
// One-period tree: replicate a payoff with x shares and y dollars of cash, then compare with q.
function replicate(S0, Su, Sd, R, payUp, payDown) {
  if (!(Sd > 0 && Su > Sd && R > 0)) throw new RangeError('Need 0 < Sd < Su and R > 0');
  const x = (payUp - payDown) / (Su - Sd), y = (payDown - x * Sd) / R, q = (R * S0 - Sd) / (Su - Sd);
  if (!(q > 0 && q < 1)) throw new RangeError('No-arbitrage needs Sd < R S0 < Su');
  return {x, y, cost: x * S0 + y, q, viaQ: (q * payUp + (1 - q) * payDown) / R};
}
function checkMarket(m) {
  const {S0, mu, sigma, r, T} = m;
  if (![S0, mu, sigma, r, T].every(Number.isFinite)) throw new TypeError('Market inputs must be finite numbers');
  if (S0 <= 0 || sigma <= 0 || T <= 0) throw new RangeError('Need S0 > 0, sigma > 0 and T > 0');
}
// Market price of risk: the only lambda that removes the drift of Z e^(-rt) S under P (product rule).
function lambdaOf(m) { checkMarket(m); return (m.mu - m.r) / m.sigma; }
// Path weight dQ/dP given the terminal Brownian value w.
const weight = (m, w) => Math.exp(-lambdaOf(m) * w - 0.5 * lambdaOf(m) ** 2 * m.T);
// Chance that S_T ends above K when the stock drifts at g per year.
function above(m, K, g) {
  checkMarket(m);
  if (!(K > 0) || !Number.isFinite(g)) throw new RangeError('Need K > 0 and a finite drift');
  return 1 - Phi((Math.log(K / m.S0) - (g - 0.5 * m.sigma ** 2) * m.T) / (m.sigma * Math.sqrt(m.T)));
}
function digital(m, K) {
  const pP = above(m, K, m.mu), pQ = above(m, K, m.r), disc = Math.exp(-m.r * m.T);
  return {pP, pQ, price: disc * pQ, wrongPrice: disc * pP};
}
// mulberry32 + Box-Muller: seeded standard Normals, the same generator on every page of this chapter.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Draw W_T under P; (a) reweight those paths by dQ/dP, (b) draw fresh paths with drift r; compare.
function reweight(m, K, draws, seed) {
  checkMarket(m);
  if (!Number.isInteger(draws) || draws < 2) throw new RangeError('Need a whole number of draws >= 2');
  const z = normals(seed), lam = lambdaOf(m), sq = Math.sqrt(m.T), s2 = m.sigma * m.sigma;
  const acc = {w: 0, ww: 0, wS: 0, wS2: 0, wD: 0, wD2: 0, D: 0, qD: 0};
  for (let i = 0; i < draws; i++) {
    const W = sq * z(), Z = Math.exp(-lam * W - 0.5 * lam * lam * m.T);
    const S = m.S0 * Math.exp((m.mu - 0.5 * s2) * m.T + m.sigma * W), d = S > K ? 1 : 0;
    const SQ = m.S0 * Math.exp((m.r - 0.5 * s2) * m.T + m.sigma * sq * z());
    acc.w += Z; acc.ww += Z * Z; acc.wS += Z * S; acc.wS2 += (Z * S) ** 2; acc.wD += Z * d; acc.wD2 += (Z * d) ** 2;
    acc.D += d; acc.qD += SQ > K ? 1 : 0;
  }
  const mean = k => acc[k] / draws, se = (k, k2) => Math.sqrt((acc[k2] / draws - mean(k) ** 2) / (draws - 1));
  return {meanWeight: mean('w'), seWeight: se('w', 'ww'), weightedS: mean('wS'), seS: se('wS', 'wS2'),
    weightedDigital: mean('wD'), seDigital: se('wD', 'wD2'), plainDigital: mean('D'), directQ: mean('qD')};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ในต้นไม้หนึ่งงวด ราคาคือต้นทุนของพอร์ตเลียนแบบ (\$2.76) ซึ่งเท่ากับค่าเฉลี่ยใต้ $q=(R-d)/(u-d)$ คิดลด และไม่ใช้โอกาสจริง $p$ เลย
  • การเปลี่ยน measure คือการคูณน้ำหนัก $Z_T=e^{-\lambda W_T-\frac12\lambda^2T}$ ให้เส้นทางเดิม: ความผันผวนเดิม จุดกลางเลื่อน $-\lambda T$ และ $dZ=-\lambda Z\,dW$ จึงเฉลี่ย 1 ทุกเวลา
  • กฎผลคูณบังคับ $\lambda=(\mu-r)/\sigma$ ค่าเดียว แล้วใต้ $Q$ หุ้นโตเท่าดอกเบี้ย: $dS/S=r\,dt+\sigma\,dW^Q$ (ลบเงินปันผลถ้ามี)
  • ราคา $=e^{-rT}\mathbb E^Q[H_T]$: digital \$1 ที่ \$110 ราคา \$0.3345 (โอกาสใต้ $Q$ 34.13%) ไม่ใช่ \$0.4698 (โอกาสใต้ $P$ 47.93%) และไม่ขึ้นกับ drift ที่เชื่อ
  • ใช้ $P$ ทำคำทายและวัดความเสี่ยง ใช้ $Q$ ตั้งราคา และตลาด option บอก density ใต้ $Q$ ให้อ่านได้จาก butterfly

หน้าถัดไป Feynman–Kac เขียน $e^{-rT}\mathbb E^Q[H_T]$ เป็นฟังก์ชันของเวลาและราคา แล้วใช้ Itô แสดงว่ามันต้องแก้สมการเชิงอนุพันธ์ย่อยที่เดินย้อนจากวันครบกำหนด
