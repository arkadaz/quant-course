17.4 Principal Component Analysis (PCA)

ลดมิติการเคลื่อนไหวของ UST curve แล้วแปลงกลับเป็นความเสี่ยง USD

เส้นสามจุดขยับพร้อมกันหรือบิดคนละทิศ; ต้องดูความเสี่ยงทีละจุดทั้งหมดหรือไม่?

เฉลย: ไม่จำเป็น—การขยับร่วมส่วนใหญ่สรุปได้ด้วยแกนไม่กี่แกน. Principal Component Analysis (PCA) หาแกนเหล่านั้นก่อน เพื่อให้เห็นขบวนทั้งก้อนแทนการนับคนเดินทีละราย.

Principal Component Analysis (PCA)
การหมุนแกนข้อมูลไปยังทิศทางที่อธิบาย variance มากที่สุดตามลำดับ ใช้ลดมิติและแยกทิศทางความเสี่ยง
yield curve
ชุดอัตราผลตอบแทนของตราสารที่อายุต่างกัน ณ เวลาเดียวกัน ใช้ติดตามต้นทุนเงินและรูปการเคลื่อนไหวของอัตรา
basis point
หน่วยอัตราเท่ากับหนึ่งในร้อยของหนึ่งเปอร์เซ็นต์ ใช้บอกการเปลี่ยนอัตราที่เล็กกว่าหนึ่งเปอร์เซ็นต์อย่างชัดเจน
covariance
matrix ที่เก็บการเคลื่อนไหวร่วมของข้อมูลหลังหักค่าเฉลี่ย ใช้หาทิศทางการแกว่งที่ไม่ซ้ำกัน
eigenvector
คืออะไร: ทิศทางพิเศษที่เมื่อข้อมูลถูกแปลงแล้ว ทิศไม่เปลี่ยน เปลี่ยนแต่ความยาว ใช้ทำอะไร: เป็นแกนใหม่ที่เราจะฉายข้อมูลลงไป ทำไมต้องเป็นทิศพวกนี้: เพราะมันคือทิศที่ข้อมูลกระจายมากที่สุดพอดี การเลือกแกนตามทิศนี้จึงเก็บข้อมูลไว้ได้มากที่สุดต่อหนึ่งแกนที่ใช้
loading
คืออะไร: ตัวเลขในแกนนั้น ที่บอกว่าสินทรัพย์แต่ละตัวมีน้ำหนักเท่าไรในแกน ใช้ทำอะไร: ใช้ตีความว่าแกนที่ได้หมายถึงอะไรในโลกจริง ทำไมต้องดูตัวเลขพวกนี้: เพราะแกนที่คำนวณได้เป็นแค่ตัวเลขจนกว่าจะอ่านมันออก แกนที่ทุกตัวมีน้ำหนักเท่ากันคือการขึ้นลงพร้อมกันทั้งตลาด ซึ่งอ่านได้จากตัวเลขพวกนี้เท่านั้น
eigenvalue
ขนาดที่ matrix ยืดทิศทางนั้น ใช้วัด variance ที่แกนใหม่นั้นรับไว้
Dollar Value of One Basis Point (DV01)

ที่มาที่ไป: ลดร้อยมิติให้เหลือสาม โดยแทบไม่เสียอะไร

Karl Pearson วางแนวคิดนี้ไว้ในปี 1901 และ Harold Hotelling พัฒนาเป็นรูปแบบที่ใช้กันในปี 1933

ปัญหาที่มันแก้คือ เมื่อมีตัวแปรจำนวนมากที่ขยับพร้อมกัน การดูทีละตัวเห็นแต่เรื่องเดียวกันซ้ำ ๆ และการดูทั้งหมดพร้อมกันก็เกินกำลังมนุษย์

การใช้งานที่ชัดเจนที่สุดในการเงินคือกับเส้นอัตราดอกเบี้ย ซึ่งมีอายุให้ติดตามเป็นสิบจุด แต่การเคลื่อนไหวเกือบทั้งหมดสรุปได้ด้วยสามทิศ คือทั้งเส้นขยับขึ้นลง เส้นชันขึ้นหรือแบนลง และเส้นโค้ง

สามคำนั้นกลายเป็นภาษาที่โต๊ะพันธบัตรใช้คุยกันจริงทุกวัน ซึ่งเป็นตัวอย่างที่ดีของเครื่องมือคณิตศาสตร์ ที่กลายเป็นคำศัพท์ในที่ทำงาน

ระวังตรงนี้

แกนเล็กอาจเป็นตำแหน่งที่เราถือใหญ่

PCA ย่อรายงานได้ แต่ไม่ได้ย่อขาดทุนตามจำนวนบรรทัดที่หายไป การทำบน correlation จะให้น้ำหนักแต่ละตัวแปรหลังปรับมาตราส่วน จึงต้องแปลงกลับด้วย standard deviation ก่อนคำนวณ USD; การทำบน covariance ใช้ขนาดการแกว่งจริงในหน่วยที่เลือก ตรวจแกนใหม่เมื่อข้อมูลเปลี่ยน และอย่าเรียกความเป็นกลางเชิงเส้นว่าไม่เสี่ยงทุกสถานการณ์

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
การตีความทิศที่ได้มีความหมายทางเศรษฐกิจมันเป็นผลจากคณิตศาสตร์ล้วน ๆการตั้งชื่อให้ทิศแล้วเชื่อชื่อนั้น นำไปสู่ข้อสรุปที่ผิด
ความนิ่งทิศที่ได้นิ่งทิศที่มีขนาดใกล้กันสลับที่กันเองเมื่อข้อมูลเปลี่ยนนิดเดียวรายงานความเสี่ยงเปลี่ยนโดยที่พอร์ตไม่ได้เปลี่ยน
ทิศที่ทิ้งไปทิศเล็ก ๆ ไม่สำคัญพอร์ตที่ hedge มาดีแล้วเหลือความเสี่ยงอยู่ในทิศเล็กพอดีการทิ้งทิศเล็กทำให้มองไม่เห็นความเสี่ยงที่เหลืออยู่จริง
แถวล่างเป็นกับดักที่ร้ายแรง เพราะเกิดกับพอร์ตที่ดูเหมือนบริหารความเสี่ยงมาดีที่สุด
›คำนวณซ้ำได้เปิดโค้ด
import numpy as np
Q=np.column_stack([np.ones(3)/np.sqrt(3),np.array([-1,0,1])/np.sqrt(2),np.array([1,-2,1])/np.sqrt(6)])
S=Q@np.diag([81,9,1])@Q.T
assert np.allclose(S,np.array([[95,80,68],[80,83,80],[68,80,95]])/3)
assert np.allclose(np.linalg.eigvalsh(S),[1,9,81])
assert abs(np.array([-14000,5000,9000])@Q[:,0])<1e-10
