17.4 Principal Component Analysis (PCA)

PCA หมุนแกนของข้อมูลหลายตัวแปรไปยังทิศที่แกว่งมากที่สุดทีละทิศ ทิศเหล่านั้นคือ eigenvector ของ covariance และ variance ในแต่ละทิศคือ eigenvalue

อัตราผลตอบแทนพันธบัตรรัฐบาลหลายอายุขยับไปด้วยกันแน่นมาก ลองดูสามอายุ 2, 7 และ 20 ปี การขยับรายวันของอายุติดกันมี correlation ราว 0.90 ปลายกับปลาย 0.75 ทิศเดียวที่ “ทุกอายุขึ้นหรือลงพร้อมกัน” อธิบาย variance ได้กี่เปอร์เซ็นต์ และถ้าถือพันธบัตร 10 ปี \$100 ล้าน อยากตัดความไวต่อทิศนั้น คนหนึ่งบอกให้ short พันธบัตร 2 ปี \$100 ล้านเท่ากัน ถูกไหม

ลองตอบก่อนเปิดเฉลย

ทิศแรกของสามอายุอธิบายได้ 90.06% ของ variance (ตัวแปรที่ปรับมาตรฐานแล้ว) และในตัวอย่างแปดอายุสามทิศแรกรวมกันได้ 96.5% ส่วน \$100 ล้านผิดไปมาก พันธบัตร 2 ปีไวต่อดอกเบี้ยน้อยกว่า 10 ปีราว 4.36 เท่า ต้อง short ราว \$453.1 ล้าน ถ้าสองอายุมีความผันผวนรายวันเท่ากัน และ \$528.6 ล้าน ถ้าอายุ 10 ปีแกว่ง 7 bp ต่ออายุ 2 ปี 6 bp

ภาพรวมก่อนลงสูตร

เมื่อมีตัวแปรหลายตัวที่ขยับไปด้วยกัน เช่นอัตราพันธบัตรแปดอายุ หรือหุ้นห้าร้อยตัว ข้อมูลไม่ได้กระจายทุกทิศเท่ากัน มันกองเป็นรูปรีที่ยาวมากในบางทิศและแบนในทิศอื่น PCA หาทิศที่ยาวที่สุดก่อน แล้วหาทิศที่ยาวที่สุดในบรรดาทิศที่ตั้งฉากกับทิศแรก ไปเรื่อย ๆ จนครบ ทิศเหล่านี้คือ eigenvector ของ covariance matrix และความยาวของรูปรีในแต่ละทิศ (variance) คือ eigenvalue (นิยามอยู่ใน eigenvalue และ positive definiteness)

ประโยชน์มีสามข้อ ข้อแรก ลดมิติ แปดอายุอาจเหลือสามทิศที่อธิบายเกือบทั้งหมด ข้อสอง ทิศใหม่มี covariance ระหว่างกันเป็นศูนย์ จึงรายงานความเสี่ยงแยกทิศได้โดยไม่ปนกัน ข้อสาม มันบอกว่าทิศไหนแบนมาก ซึ่งเป็นทิศที่ inverse ของ covariance ขยายความคลาด และเป็นต้นเหตุที่ Markowitz optimizer ให้น้ำหนักสุดโต่ง

หน้านี้หาทิศของสามอายุด้วยมือ อ่านรูปทรง level, slope และ curvature พิสูจน์ว่าทำไมต้องเป็น eigenvector ดูผลของแปดอายุและเลือกว่าจะเก็บกี่ทิศ แล้วใช้ทิศแรกสร้าง hedge และจบที่บทเรียนสำคัญ ทิศที่ variance เล็กไม่ได้แปลว่าความเสี่ยงของพอร์ตในทิศนั้นเล็ก

ขั้นที่ 1 — ลองด้วยมือ: เดาทิศที่ปลายสองข้างสวนกัน

เพื่อคิดด้วยมือ เลือกตัวแทนสามอายุ 2, 7 และ 20 ปี ของการขยับรายวัน (ไม่ใช่ระดับ เพราะระดับดอกเบี้ยเดินไปเรื่อย ๆ ไม่วนรอบค่าเดิม) และใช้ correlation คือมองการขยับที่หักค่าเฉลี่ยแล้วหารด้วยความผันผวนของแต่ละอายุ ตัวแปรที่ปรับแล้วมี variance 1 ทุกตัว covariance ของมันจึงเท่ากับ $R$ สังเกตว่าอ่าน $R$ จากมุมล่างขวาย้อนขึ้นไปได้ matrix เดิม ทิศพิเศษจึงน่าจะพลิกแล้วได้ตัวเองหรือได้ลบของตัวเอง ลองแบบหลังก่อน

\[ \begin{aligned} R&=\begin{bmatrix}1&0.90&0.75\\0.90&1&0.90\\0.75&0.90&1\end{bmatrix},\\ v&=(1,\ 0,\ -1),\\ Rv&=(1-0.75,\ 0.90-0.90,\ 0.75-1)\\ &=(0.25,\ 0,\ -0.25)=0.25\,v,\\ \lambda_2&=1-0.75=0.25,\\ q_2&=\tfrac{1}{\sqrt2}(1,\ 0,\ -1)\\ &=(0.7071,\ 0,\ -0.7071). \end{aligned} \]

คูณ $R$ กับ $v$ แล้วได้ $v$ เดิมคูณ 0.25 นี่คือนิยามของ eigenvector ตรงตัว เครื่องหมายบวก ศูนย์ ลบ คือทิศที่อายุสั้นขึ้นขณะที่อายุยาวลง นั่นคือความชัน (slope) ของเส้นอัตรา

$\lambda_2$ เท่ากับ 1 ลบ correlation ของปลายสองข้างพอดี ยิ่งปลายเกาะกันแน่น ความเสี่ยงเรื่องความชันยิ่งเล็ก หาร $v$ ด้วยความยาว $\sqrt2$ เพื่อให้ยาวหนึ่งหน่วย

ขั้นที่ 2 — อีกสองตัวจากสมการกำลังสอง

ทิศอีกแบบคือปลายเท่ากัน $(x,y,x)$ ใส่เข้าไปแล้วแถวแรกกับแถวสามให้สมการเดียวกัน ปัญหาสามตัวแปรจึงยุบเหลือสอง

\[ \begin{aligned} R(x,y,x)&=(1.75x+0.90y,\ 1.80x+y,\\ &\qquad 1.75x+0.90y),\\ 1.75x+0.90y&=\lambda x,\\ 1.80x+y&=\lambda y,\\ (1.75-\lambda)(1-\lambda)&=0.90(1.80)=1.62,\\ \lambda^2-2.75\lambda+0.13&=0,\\ \lambda&=\frac{2.75\pm\sqrt{7.0425}}{2}=\frac{2.75\pm2.65377}{2},\\ \lambda_1&=2.70189,\quad \lambda_3=0.04811,\\ \lambda_1+\lambda_2+\lambda_3&=3=\operatorname{trace}R. \end{aligned} \]

สองสมการกลางเป็นระบบ 2×2 ที่มีคำตอบไม่ใช่ศูนย์ได้เมื่อ determinant ของมันเป็นศูนย์ จึงได้สมการกำลังสอง $7.0425=2.75^2-4(0.13)$ ระบบนี้ไม่สมมาตร (0.90 กับ 1.80) เพราะพับปลายสองข้างเข้าหากัน ตัวกลางเห็นปลายทั้งสองข้าง ส่วนปลายแต่ละข้างเห็นตัวกลางครั้งเดียว

บรรทัดสุดท้ายคือตัวตรวจ ผลบวกของ eigenvalue เท่ากับผลบวกแนวทแยงของ matrix เสมอ และแนวทแยงของ correlation เป็น 1 ทุกช่อง จึงได้ 3 พอดี รากของ 7.0425 คิดมือได้ $2.65^2=7.0225$ ขาด 0.02 หารด้วย $2(2.65)$ ได้เพิ่ม 0.00377

ขั้นที่ 3 — loading แล้วอ่านเครื่องหมาย

มี $\lambda$ แล้ว หา $y$ จากสมการแรกของระบบ 2×2 คือ $y=(\lambda-1.75)x/0.90$ ตั้ง $x=1$ แล้วหารด้วยความยาวให้ยาวหนึ่งหน่วย

\[ \begin{aligned} \lambda_1&:\ y=\frac{0.95189}{0.90}=1.05765,\\ |v|&=\sqrt{2+1.05765^2}=1.76596,\\ q_1&=(0.5663,\ 0.5989,\ 0.5663),\\ \lambda_3&:\ y=\frac{-1.70189}{0.90}=-1.89098,\\ |v|&=\sqrt{2+1.89098^2}=2.36132,\\ q_3&=(0.4235,\ -0.8008,\ 0.4235),\\ q_1^{\mathsf T}q_3&=2(0.5663)(0.4235)\\ &\quad-0.5989(0.8008)\approx0. \end{aligned} \]

$q_1$ เป็นบวกทุกช่องขนาดใกล้กัน คือทั้งเส้นขึ้นลงพร้อมกัน เรียก level ส่วน $q_3$ ปลายบวกกลางลบ คือท้องเส้นนูนหรือยุบ เรียก curvature ผลคูณ $q_1^{\mathsf T}q_3$ เป็นศูนย์ (ตัวเลขที่ปัดสี่ตำแหน่งให้ 0.47966 ลบ 0.47960) เพราะ eigenvector ของ matrix สมมาตรที่ eigenvalue ต่างกันตั้งฉากกันเสมอ

วิธีอ่านเร็ว เดินจากอายุสั้นไปยาวแล้วนับว่าเครื่องหมายสลับกี่ครั้ง ไม่สลับคือ level สลับครั้งเดียวคือ slope สลับสองครั้งคือ curvature ถ้าโปรแกรมให้เครื่องหมายกลับทั้งชุด ก็เป็นทิศเดียวกันมองกลับด้าน เพราะลบของ eigenvector ก็เป็น eigenvector

ขั้นที่ 4 — ทำไมทิศที่แกว่งมากที่สุดต้องเป็น eigenvector

ถามให้ตรง ถ้ารวมตัวแปรที่ปรับมาตรฐานแล้วด้วยน้ำหนัก $q$ ที่ยาวหนึ่งหน่วย variance คือ $q^{\mathsf T}Rq$ (หลักเดียวกับ ความเสี่ยงของพอร์ต) ทิศไหนทำให้ค่านี้มากที่สุด ต้องบังคับความยาว ไม่อย่างนั้นยืด $q$ ออกก็ได้ค่ามากขึ้นไม่สิ้นสุด จึงใช้ Lagrange multipliers มองอีกแบบได้ว่านี่คือการหา “พอร์ต” ที่แกว่งมากที่สุด โดยผลรวมกำลังสองของน้ำหนักเป็นหนึ่ง

\[ \begin{aligned} \mathcal L&=q^{\mathsf T}Rq-\lambda\big(q^{\mathsf T}q-1\big),\\ \frac{\partial\mathcal L}{\partial q}&=2Rq-2\lambda q=0,\\ Rq&=\lambda q,\\ q^{\mathsf T}Rq&=\lambda\,q^{\mathsf T}q=\lambda,\\ z&=Q^{\mathsf T}x,\\ \operatorname{Cov}(z)&=Q^{\mathsf T}RQ=\Lambda,\\ x&=Qz=\textstyle\sum_k q_k z_k,\\ \Delta y_i&=m_i+\sigma_i\textstyle\sum_k q_{ik}z_k. \end{aligned} \]

ความชันศูนย์ของ Lagrangian คือนิยามของ eigenvector ตรงตัว และ variance ในทิศนั้นเท่ากับ $\lambda$ ของมันพอดี ทิศที่แกว่งมากที่สุดจึงเป็น eigenvector ที่ $\lambda$ ใหญ่ที่สุด ทิศถัดไปคือทิศที่แกว่งมากที่สุดในบรรดาทิศที่ตั้งฉากกับทิศแรก ซึ่งก็คือ eigenvector ตัวถัดไป

$z$ คือคะแนนของแต่ละวันบนแกนใหม่ covariance ของมันเป็นแนวทแยง คะแนนต่างแกนจึงมี covariance เป็นศูนย์ แต่ไม่ได้แปลว่าเป็นอิสระกัน (ดู covariance ศูนย์ไม่ใช่ความอิสระ) เพราะ $Q$ ตั้งฉากและยาวหนึ่ง $Q^{\mathsf T}=Q^{-1}$ การกลับจากคะแนนเป็นข้อมูลเดิมจึงแค่คูณ $Q$ แล้วคูณ $\sigma_i$ บวกค่าเฉลี่ยกลับตามบรรทัดสุดท้าย

ถ้าทำ PCA บน covariance $\Sigma$ ในหน่วย bp แบบรูปกลุ่มจุดข้างบน ให้ใช้ eigenvector ของ $\Sigma$ แทน และไม่ต้องหาร $\sigma_i$ คะแนนจะมีหน่วย bp และ eigenvalue มีหน่วย bp กำลังสอง ส่วน loading ยังไร้หน่วย ผลสองแบบไม่เท่ากัน correlation ให้ทุกตัวแปรมีเสียงเท่ากัน ส่วน covariance ให้ตัวที่แกว่งมากมีเสียงดังกว่า

ขั้นที่ 5 — สัดส่วนที่อธิบาย การประมาณที่ดีที่สุด และทิศที่ inverse ขยาย

สัดส่วนที่ทิศหนึ่งอธิบายคือ eigenvalue ของมันหารด้วยผลบวกทั้งหมด ซึ่งเมื่อใช้ correlation คือจำนวนตัวแปร แล้วดูอีกด้านที่ Markowitz ทิ้งไว้ $R^{-1}=Q\Lambda^{-1}Q^{\mathsf T}$ มี eigenvector ชุดเดิม แต่ eigenvalue กลับหัว

\[ \begin{aligned} \frac{2.70189}{3}&=90.06\%,\quad \frac{0.25}{3}=8.33\%,\\ \frac{0.04811}{3}&=1.60\%,\\ R&\approx\lambda_1q_1q_1^{\mathsf T}+\lambda_2q_2q_2^{\mathsf T},\\ \frac{1}{\lambda_k}&=0.370,\ 4.00,\ 20.78,\\ \frac{\lambda_1}{\lambda_3}&=\frac{2.70189}{0.04811}=56.2. \end{aligned} \]

ทิศแรกอธิบาย 90% ของ variance รวมของตัวแปรที่ปรับมาตรฐาน ไม่ได้แปลว่าอธิบายการขยับของทุกวันได้ 90% ถ้า correlation ทุกคู่เป็น 1 ทิศแรกจะได้ 100% และอีกสองทิศเป็นศูนย์

บรรทัดที่สามคือความหมายของการ “เก็บสองทิศ” ทุก matrix สมมาตรเขียนได้เป็นผลบวก $\sum_k\lambda_kq_kq_k^{\mathsf T}$ การตัดพจน์ที่ $\lambda$ เล็กทิ้งให้ matrix ที่มีอันดับ (rank) สองซึ่งใกล้ของจริงที่สุด (ผลของ Eckart และ Young) และถ้าฉายข้อมูลทุกวันลงบนสองทิศแรกแล้วสร้างกลับ ผลรวมกำลังสองของส่วนที่หายไปต่อวันโดยเฉลี่ยเท่ากับ eigenvalue ที่ทิ้ง คือ 0.048 จาก 3

$R^{-1}$ ขยายทิศ curvature ราว 56 เท่าของทิศ level ความคลาดที่ตกในทิศ variance ต่ำจึงถูกขยายมากเมื่อใช้ inverse ซึ่งเป็นสิ่งที่ optimizer ทำ ตัวเลข 56.2 คือ condition number ของ $R$ หน้า Ledoit–Wolf shrinkage จะดึงค่านี้ลง

ขั้นที่ 6 — แปดอายุด้วยคอมพิวเตอร์ และเลือกว่าจะเก็บกี่ทิศ

ขยายเป็นแปดอายุ 1, 2, 3, 5, 7, 10, 15 และ 20 ปี โดยใช้ correlation สมมติที่ลดลงตามระยะห่างของ log อายุ (คู่ที่อายุห่างกันเป็นสัดส่วนเท่ากันมี correlation เท่ากัน) อายุ 1 กับ 2 ปีได้ 0.901 อายุ 15 กับ 20 ปีได้ 0.958 ปลายกับปลายได้ 0.638 matrix 8×8 แก้ด้วยมือไม่ไหว จึงใช้โค้ดท้ายหน้า (หมุนแบบ Jacobi) ผลบวก eigenvalue ต้องเป็น 8

\[ \begin{aligned} R_{ij}&=e^{-0.15\,|\ln T_i-\ln T_j|},\\ \lambda&=6.849,\ 0.662,\ 0.211,\ 0.110,\\ &\qquad 0.063,\ 0.043,\ 0.034,\ 0.029,\\ \frac{\lambda}{8}&=85.6\%,\ 8.3\%,\ 2.6\%,\ 1.4\%,\dots,\\ 85.6+8.3+2.6&=96.5\%,\\ \tfrac{1}{\sqrt8}&=0.354,\quad q_1\approx0.324\ \text{to}\ 0.367,\\ q_2&=(0.53,\ 0.43,\ 0.29,\ 0.04,\\ &\qquad -0.12,\ -0.28,\ -0.40,\ -0.44). \end{aligned} \]

ถ้าทั้งแปดอายุขยับเท่ากันเป๊ะ loading ของทิศแรกจะเป็น $1/\sqrt8=0.354$ ทุกช่อง ค่าที่ได้เกาะรอบนั้น ทิศแรกจึงคือทั้งเส้นขยับพร้อมกัน ทิศที่สองสลับเครื่องหมายครั้งเดียวระหว่าง 5 กับ 7 ปี จึงเป็น slope ทิศที่สามสลับสองครั้ง เป็น curvature รูปทรงเหมือนตัวอย่างสามอายุ แม้ตัวเลขไม่เท่ากันเพราะ matrix ต่างกัน ในข้อมูลพันธบัตรจริง Litterman และ Scheinkman (1991) พบรูปทรงสามแบบนี้เหมือนกัน และสามทิศแรกรวมกันอธิบายได้ราว 95% ขึ้นไป

เก็บกี่ทิศ วิธีที่เก่าและนิยมที่สุดคือ scree plot ในรูปข้างล่าง มองหาจุดที่แท่งหักจากก้อนใหญ่ลงเป็นเศษเล็ก ๆ ที่ลดลงช้า ๆ ในที่นี้คือหลังทิศที่สามหรือสี่ อีกเกณฑ์หนึ่งมาจากทฤษฎี random matrix (Marchenko–Pastur ซึ่งยกมาใช้โดยไม่พิสูจน์) ถ้ามีตัวแปร $n$ ตัวที่ไม่สัมพันธ์กันเลย และข้อมูล $T$ วัน eigenvalue ของ correlation ที่ประมาณได้จะไม่เท่ากับ 1 ทุกตัว แต่กระจายขึ้นไปได้ถึง $(1+\sqrt{n/T})^2$ หุ้น 500 ตัวกับข้อมูล 250 วัน ($n/T=2$) ขอบนี้คือ 5.83 ทิศใดที่ eigenvalue ไม่เกินระดับนี้แยกจากเสียงสุ่มไม่ออก และ eigenvector ของมันแทบไม่มีข้อมูล ส่วนทิศใหญ่ที่แยกออกมาได้ก็ถูกประมาณสูงเกินจริงราว $n/T$ เช่นกัน

ถ้าต้องพลาด ให้พลาดทางเก็บทิศมากเกินไปดีกว่า เก็บน้อยเกินแปลว่าพอร์ตที่สร้างจากแบบจำลองมองไม่เห็นความเสี่ยงบางทิศ แล้ว optimizer จะเทน้ำหนักเข้าไปในทิศนั้นเพราะคิดว่ามันไม่เสี่ยง สำหรับหุ้น ทิศแรกเกือบเสมอคือตลาดทั้งตลาด (loading บวกทุกตัว) ทิศถัดไปมักเป็นกลุ่มอุตสาหกรรมหรือสไตล์ ซึ่งเชื่อมกับ multi-factor models

ขั้นที่ 7 — สร้างพอร์ตที่ไม่สนใจระดับดอกเบี้ย

โจทย์ให้อะไรมาบ้าง: ถือพันธบัตร 10 ปี \$100 ล้าน ต้องการให้ความไวต่อทิศแรกเป็นศูนย์ โดยยอมเหลือความเสี่ยง slope และ curvature DV01 ของพันธบัตร \$100 ล้าน คือ \$85,000 สำหรับ 10 ปี (modified duration สมมติ 8.5 ปี คูณ \$100 ล้าน คูณ 0.0001) และ \$19,500 สำหรับ 2 ปี (duration 1.95) loading ของทิศแรกจากแปดอายุคือ 0.3632 ที่ 10 ปี และ 0.3494 ที่ 2 ปี จุดที่ต้องระวัง PCA ทำบน correlation คือบนการขยับที่หารด้วยความผันผวนแล้ว การขยับหนึ่งหน่วยของทิศแรกจึงขยับอายุ $i$ เป็น $\sigma_iq_{1i}$ bp

\[ \begin{aligned} \Delta y_i&=\sigma_i\,q_{1i}\,z_1,\\ N&=\frac{85{,}000\,\sigma_{10}(0.3632)}{19{,}500\,\sigma_{2}(0.3494)},\\ \sigma_2=\sigma_{10}&:\ N=\frac{30{,}870}{6{,}813.5}=4.5307,\\ \frac{\sigma_{10}}{\sigma_2}=\frac76&:\ N=4.5307\Big(\frac76\Big)=5.2858. \end{aligned} \]

คำตอบ: ความไวของแต่ละขาต่อคะแนนของทิศแรกคือ DV01 คูณการขยับในหน่วย bp ต้อง short พันธบัตร 2 ปี $N$ หน่วยของ \$100 ล้าน ถ้าสองอายุมีความผันผวนรายวันเท่ากัน ได้ \$453.1 ล้าน ถ้าอายุ 10 ปีแกว่ง 7 bp และอายุ 2 ปีแกว่ง 6 bp (ตัวเลขสมมติ) ต้อง short \$528.6 ล้าน ต่างกัน 17% จากความต่างของความผันผวนแค่ 1 bp ก่อนใช้ loading ของ correlation กับเงินจริง ต้องคูณความผันผวนกลับเข้าไปเสมอ

ทำไมต้อง short ถึงราว 4.5 เท่า พันธบัตร 2 ปีมี DV01 เล็กกว่า $85{,}000/19{,}500=4.36$ เท่า และ loading ต่างกันอีก $0.3632/0.3494=1.039$ เท่า สิ่งที่เหลือหลัง hedge คือความไวต่อทิศอื่น ซึ่ง loading ของ slope คือ $+0.43$ ที่ 2 ปี และ $-0.28$ ที่ 10 ปี พอร์ตนี้จึงเป็นเดิมพันความชัน ถ้าเส้นชันขึ้น (อายุยาวขึ้นมากกว่าอายุสั้น) พอร์ตนี้ขาดทุน ถ้าแบนลงได้กำไร

ตรวจเองใน 10 วินาที: $4.5307\times19{,}500\times0.3494=30{,}869$ เท่ากับ $85{,}000\times0.3632=30{,}872$ ภายในการปัดเศษ สองขาหักล้างกันพอดี

ขั้นที่ 8 — ตัวอย่างที่สอง: ประกอบ matrix จากแกนที่รู้คำตอบ

ย้อนทาง เลือกสามทิศและขนาดเอง แล้วประกอบเป็น covariance ของการขยับรายวันของพันธบัตร 2, 5 และ 10 ปี หน่วย bp กำลังสอง (ตัวเลขสมมติ) เพื่อดูว่า PCA แกะกลับได้ของเดิม และใช้ตัวอย่างนี้ต่อในขั้นถัดไป ตัวอย่างนี้ใช้ covariance คะแนนจึงมีหน่วย bp

\[ \begin{aligned} q_1&=\tfrac{1}{\sqrt3}(1,1,1),\quad q_2=\tfrac{1}{\sqrt2}(-1,0,1),\\ q_3&=\tfrac{1}{\sqrt6}(1,-2,1),\quad \Lambda=\operatorname{diag}(81,\ 9,\ 1),\\ \Sigma&=Q\Lambda Q^{\mathsf T}=\frac13\begin{bmatrix}95&80&68\\80&83&80\\68&80&95\end{bmatrix},\\ (\Sigma q_1)_1&=\frac{95+80+68}{3\sqrt3}=\frac{81}{\sqrt3}=81\,(q_1)_1,\\ \frac{81}{91}&=89.01\%,\quad \frac{9}{91}=9.89\%,\quad \frac{1}{91}=1.10\%. \end{aligned} \]

ช่อง $(1,1)$ ของ $\Sigma$ คือ $81(\tfrac13)+9(\tfrac12)+1(\tfrac16)=\tfrac{95}{3}$ ช่องอื่นคิดแบบเดียวกัน คูณแถวแรกของ $\Sigma$ กับ $q_1$ ได้ 81 คูณช่องแรกของ $q_1$ พอดี matrix แค่ยืดทิศนี้ 81 เท่าโดยไม่หมุน

ผลบวกแนวทแยง $(95+83+95)/3=91$ เท่ากับผลบวก eigenvalue ที่เลือก ความผันผวนรายวันของคะแนนสามทิศคือ $\sqrt{81}=9$, $\sqrt9=3$ และ 1 bp

ขั้นที่ 9 — variance เล็กไม่ได้แปลว่ากำไรขาดทุนเล็ก

พอร์ตมี DV01 ที่ 2, 5 และ 10 ปีเท่ากับ \$2,000, \$5,000 และ \$9,000 ต่อ bp มูลค่าเปลี่ยน $-d^{\mathsf T}\Delta y$ แยกการขยับเป็นสามทิศ $\Delta y=\sum_kq_kz_k$ แล้วดูความไวต่อแต่ละทิศ ก่อนและหลังเพิ่มสถานะที่ 2 ปีเพื่อตัด level ให้ $s_V$ เป็นความผันผวนรายวันของกำไรขาดทุน

\[ \begin{aligned} \Delta V&=-\textstyle\sum_k(d^{\mathsf T}q_k)\,z_k,\\ d^{\mathsf T}q_1&=\tfrac{16{,}000}{\sqrt3}=9{,}238,\\ d^{\mathsf T}q_2&=\tfrac{7{,}000}{\sqrt2}=4{,}950,\\ d^{\mathsf T}q_3&=\tfrac{1{,}000}{\sqrt6}=408,\\ s_V^2&=81\Big(\frac{16{,}000}{\sqrt3}\Big)^2+9\Big(\frac{7{,}000}{\sqrt2}\Big)^2\\ &\quad+\Big(\frac{1{,}000}{\sqrt6}\Big)^2,\\ s_V&\approx84{,}455,\\ d'&=(-14{,}000,\ 5{,}000,\ 9{,}000),\\ d'^{\mathsf T}q_1&=0,\quad d'^{\mathsf T}q_2=\tfrac{23{,}000}{\sqrt2}=16{,}263,\\ d'^{\mathsf T}q_3&=\tfrac{-15{,}000}{\sqrt6}=-6{,}124,\\ (s'_V)^2&=9\Big(\frac{23{,}000}{\sqrt2}\Big)^2+\Big(\frac{15{,}000}{\sqrt6}\Big)^2,\\ s'_V&\approx49{,}173. \end{aligned} \]

บรรทัด $s_V^2$ ใช้ว่าคะแนนของสามทิศมี covariance เป็นศูนย์และ variance $81,\ 9,\ 1$ variance ของ $\Delta V$ จึงเป็นผลบวกของความไวกำลังสองคูณ $\lambda$ ไม่มีพจน์ไขว้ ก่อน hedge variance 97% มาจาก level ($81\times9{,}238^2$ หารด้วย $84{,}455^2$)

เพิ่ม DV01 −16,000 ที่ 2 ปี (short พันธบัตร 2 ปี) ความไวต่อ level เป็นศูนย์ แต่ความไวต่อ slope โตจาก 4,950 เป็น 16,263 และต่อ curvature จาก 408 เป็น −6,124 ความเสี่ยงรวมลดแค่ 42% เหลือ \$49,173 ต่อวัน และเกือบทั้งหมดอยู่ในทิศ slope ที่มี eigenvalue แค่ 9 จาก 91

ความเสี่ยงของพอร์ตในแต่ละทิศคือ variance ของทิศคูณความไวกำลังสอง ไม่ใช่ variance อย่างเดียว และ hedge ที่ตัด level ทิ้งหมดก็ไม่ใช่ hedge ที่เสี่ยงน้อยที่สุด ถ้าเลือก DV01 ที่ 2 ปีให้ variance ของพอร์ตต่ำสุดโดยตรง จะได้ $-(\Sigma d)_1/\Sigma_{11}=-12{,}653$ ความเสี่ยงเหลือ \$45,422 เพราะมันยอมเหลือ level นิดหนึ่งเพื่อไม่ให้ slope โตมาก

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

อ่าน loading เป็นสัดส่วนเงิน: คนที่อ่าน $q_1=(0.566,\ 0.599,\ 0.566)$ แล้วซื้อพันธบัตรสามอายุด้วยเงินสัดส่วนนั้น จะไม่ได้พอร์ตของทิศแรกเลย เพราะ DV01 ต่อเงินของอายุสั้นกับยาวต่างกันหลายเท่า ต้องแปลงผ่าน DV01 แบบการสร้าง hedge ข้างบน

ลืมคูณความผันผวนกลับ: คะแนนจาก PCA ของ correlation อ้างอิงตัวแปรที่หารด้วยความผันผวนแล้ว ถ้า 10 ปีแกว่ง 7 bp ต่อ 6 bp ของ 2 ปี hedge ที่ถูกคือ \$528.6 ล้าน ไม่ใช่ \$453.1 ล้าน

ทิ้งทิศเล็กหลัง hedge: รายงานที่แสดงแค่ level บอกว่าพอร์ตที่ตัด level แล้วไม่มีความเสี่ยง ทั้งที่ยังเสี่ยง \$49,173 ต่อวัน

เชื่อ eigenvector ของทิศที่ eigenvalue ใกล้กัน: ถ้าสองทิศมี eigenvalue เท่ากัน ทิศใดก็ได้ในระนาบของมันเป็น eigenvector ทั้งนั้น เมื่อใกล้กัน ข้อมูลเพิ่มไม่กี่วันก็หมุนสองทิศนั้นไปได้มาก รายงานความเสี่ยงรายทิศจึงกระโดดทั้งที่พอร์ตไม่ได้เปลี่ยน

ใช้ loading เก่าในวันที่โลกเปลี่ยน: ช่วงที่อัตราสั้นถูกตรึงใกล้ศูนย์แต่อัตรายาวยังแกว่ง correlation เปลี่ยนกะทันหัน loading ทั้งชุดล้าสมัยพร้อมกัน ต้องคำนวณใหม่บนหน้าต่างข้อมูลที่เลื่อนไปเรื่อย ๆ แล้วดูว่าทิศยังนิ่งไหม

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะพันธบัตรรายงานความเสี่ยงเป็นความไวต่อสามทิศแทนแปดอายุ ตั้งเพดานของแต่ละทิศ และสร้างเดิมพันเฉพาะทิศ เช่นเดิมพันความชันแบบตัดทิศแรก หรือเดิมพันท้องเส้นด้วยสามขาที่ตัด level และ slope ทิ้ง ฝ่ายความเสี่ยงใช้ทิศเดียวกันสร้าง stress test เช่นขยับ level สามเท่าของความผันผวน ฝั่งหุ้น แบบจำลองปัจจัยเชิงสถิติใช้ PCA หาทั้ง loading และผลตอบแทนของปัจจัยจากข้อมูลผลตอบแทนอย่างเดียว เหมาะกับตลาดที่ไม่มีข้อมูลพื้นฐานของบริษัท หรือข้อมูลความถี่สูงระดับนาที และจำนวนทิศที่เก็บไว้ยังใช้ลดมิติก่อนสร้างสถานการณ์สุ่มด้วย Monte Carlo

// Eigenvalues and unit eigenvectors of a symmetric matrix by Jacobi rotations, largest first
function eigenSym(S) {
  const n = S.length, A = S.map(r => [...r]), V = S.map((r, i) => r.map((_, j) => (i === j ? 1 : 0)));
  for (let sweep = 0; sweep < 100; sweep++) {
    let off = 0;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) off += A[p][q] ** 2;
    if (off < 1e-30) break;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) {
      if (Math.abs(A[p][q]) < 1e-300) continue;
      const theta = (A[q][q] - A[p][p]) / (2 * A[p][q]);
      const t = Math.sign(theta || 1) / (Math.abs(theta) + Math.sqrt(theta * theta + 1));
      const c = 1 / Math.sqrt(t * t + 1), s = t * c;
      for (let k = 0; k < n; k++) { const a = A[k][p], b = A[k][q]; A[k][p] = c * a - s * b; A[k][q] = s * a + c * b; }
      for (let k = 0; k < n; k++) { const a = A[p][k], b = A[q][k]; A[p][k] = c * a - s * b; A[q][k] = s * a + c * b; }
      for (let k = 0; k < n; k++) { const a = V[k][p], b = V[k][q]; V[k][p] = c * a - s * b; V[k][q] = s * a + c * b; }
    }
  }
  const order = [...Array(n).keys()].sort((a, b) => A[b][b] - A[a][a]);
  return order.map(k => {
    const v = V.map(r => r[k]), sign = v[0] < 0 ? -1 : 1;   // eigenvectors are defined up to sign
    return {value: A[k][k], vector: v.map(x => sign * x)};
  });
}
const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);

const pc3 = eigenSym([[1, 0.90, 0.75], [0.90, 1, 0.90], [0.75, 0.90, 1]]);
console.log('3 maturities', pc3.map(p => [p.value.toFixed(5), p.vector.map(x => x.toFixed(4))]));

// Example two: covariance built from known directions and sizes (bp^2)
const s3 = Math.sqrt(3), s2 = Math.sqrt(2), s6 = Math.sqrt(6);
const Q = [[1 / s3, -1 / s2, 1 / s6], [1 / s3, 0, -2 / s6], [1 / s3, 1 / s2, 1 / s6]], lam = [81, 9, 1];
const Sigma = Q.map((_, i) => Q.map((__, j) => lam.reduce((a, l, k) => a + Q[i][k] * l * Q[j][k], 0)));
const risk = d => { const e = lam.map((_, k) => dot(d, Q.map(r => r[k]))); return {e, sd: Math.sqrt(e.reduce((a, x, k) => a + lam[k] * x * x, 0))}; };
console.log('3 x Sigma', Sigma.map(r => r.map(x => (3 * x).toFixed(2))));

สิ่งที่ควรตอบได้หลังอ่าน

  • ทิศที่พอร์ตยาวหนึ่งหน่วยแกว่งมากที่สุดคือ eigenvector และ variance ในทิศนั้นคือ eigenvalue (Lagrangian ให้ $Rq=\lambda q$)
  • สามอายุด้วยมือได้ 90.06, 8.33 และ 1.60% แปดอายุได้ 85.6, 8.3 และ 2.6% รูปทรง level, slope และ curvature อ่านจากจำนวนครั้งที่เครื่องหมายสลับ
  • เก็บกี่ทิศดูจาก scree plot และขอบของเสียงสุ่ม $(1+\sqrt{n/T})^2$ ถ้าลังเลให้เก็บมากไว้ก่อน
  • inverse ขยายทิศที่ eigenvalue เล็ก 56 เท่าในสามอายุ นี่คือเหตุที่ optimizer ไวต่อทิศที่ข้อมูลบอกน้อย
  • hedge ทิศแรกต้องผ่าน DV01 และความผันผวน และหลังตัด level ความเสี่ยงอาจกองใน slope: \$84,455 เหลือ \$49,173
