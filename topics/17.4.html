17.4 Principal Component Analysis (PCA)

PCA หมุนแกนของข้อมูลหลายตัวแปรไปยังทิศที่แกว่งมากที่สุดทีละทิศ ทิศเหล่านั้นคือ eigenvector ของ covariance และ variance ในแต่ละทิศคือ eigenvalue

รัฐบาลกู้เงินด้วยการออกพันธบัตร (bond) หลายอายุ เช่น 2 ปี 7 ปี และ 20 ปี ตลาดตั้งดอกเบี้ยให้พันธบัตรแต่ละอายุแยกกัน ดอกเบี้ยนี้เรียกว่า yield ทุกวัน yield ของแต่ละอายุขยับขึ้นหรือลงเล็กน้อย หน่วยที่ใช้วัดคือ bp (basis point คือ 0.01% เช่น yield จาก 4.20% เป็น 4.25% คือขึ้น 5 bp)

โต๊ะเทรดพันธบัตรจึงต้องเฝ้าตัวเลขหลายตัวพร้อมกัน แต่ตัวเลขเหล่านี้ไม่ได้ขยับอิสระจากกัน วันที่ yield อายุหนึ่งขึ้น อายุอื่นก็มักขึ้นด้วย ถ้ามันขยับไปด้วยกันแน่นขนาดนั้น ก็น่าจะสรุปทั้งชุดได้ด้วยตัวเลขน้อยตัวกว่าเดิม

ของที่รู้ (ตัวเลขสมมติ แต่ขนาดใกล้ข้อมูลจริง):

  • ดูสามอายุ คือ 2, 7 และ 20 ปี
  • correlation ของการขยับรายวันระหว่างอายุที่อยู่ติดกัน (2 กับ 7 ปี และ 7 กับ 20 ปี) เท่ากับ 0.90 correlation คือตัวเลขจาก −1 ถึง 1 ที่บอกว่าสองตัวขยับไปทางเดียวกันแน่นแค่ไหน ค่า 1 คือไปด้วยกันเป๊ะ
  • correlation ระหว่างปลายกับปลาย (2 กับ 20 ปี) เท่ากับ 0.75

คำถามที่ 1: ถ้าสรุปแต่ละวันด้วยตัวเลขตัวเดียว คือ “วันนี้ทั้งสามอายุขึ้นหรือลงพร้อมกันเท่าไร” ตัวเลขนี้เก็บความแกว่ง (variance) ของทั้งชุดไว้ได้กี่เปอร์เซ็นต์

คำถามที่ 2: เทรดเดอร์คนหนึ่งถือพันธบัตร 10 ปี มูลค่า \$100 ล้าน เมื่อ yield ขึ้น ราคาพันธบัตรตก เขาจึงกลัววันที่ yield ทั้งเส้นขึ้นพร้อมกัน เขาอยากหักล้างความเสี่ยงนี้ (เรียกว่า hedge) ด้วยการ short พันธบัตร 2 ปี (short คือยืมพันธบัตรมาขายก่อน แล้วซื้อคืนทีหลัง จึงได้กำไรเมื่อราคาตก) เพื่อนบอกให้ short \$100 ล้านเท่ากัน ขนาดนี้ถูกไหม

ลองตอบก่อนเปิดเฉลย

คำถามที่ 1: ทิศ “ทุกอายุขยับพร้อมกัน” เก็บ variance ได้ 90.06% ขั้นที่ 2 และ 5 จะคำนวณตัวเลขนี้ให้ดูทีละขั้น ถ้าเพิ่มเป็นแปดอายุ ขั้นที่ 6 จะแสดงว่าสามทิศแรกรวมกันเก็บได้ 96.5%

คำถามที่ 2: \$100 ล้านน้อยไปมาก เพราะพันธบัตร 2 ปีไวต่อ yield น้อยกว่าพันธบัตร 10 ปีหลายเท่า ความไวนี้วัดด้วย DV01 คือเงินที่มูลค่าพันธบัตรเปลี่ยนเมื่อ yield ขยับ 1 bp ขั้นที่ 7 ให้ DV01 ต่อ \$100 ล้านเป็น \$85,000 สำหรับ 10 ปี และ \$19,500 สำหรับ 2 ปี (สมมติ) แล้วคำนวณจำนวนเท่า $N$ ของ \$100 ล้านที่ต้อง short:

\[\begin{aligned}\frac{85{,}000}{19{,}500}&=4.36,\\N&=4.36\times\frac{0.3632}{0.3494}=4.53.\end{aligned}\]

0.3632 กับ 0.3494 คือน้ำหนักของอายุ 10 ปีและ 2 ปีในทิศ “ขยับพร้อมกัน” ที่ขั้นที่ 6 หาได้ ค่าละเอียดที่ขั้นที่ 7 คำนวณคือ $N=4.5307$ จึงต้อง short $4.5307\times\$100$ ล้าน $=\$453.1$ ล้าน ถ้าสองอายุแกว่งรายวันเท่ากัน ถ้าอายุ 10 ปีแกว่งวันละ 7 bp แต่อายุ 2 ปีแกว่งวันละ 6 bp ต้องคูณเพิ่มอีก $7/6$ ได้ $4.5307\times7/6=5.2858$ หรือ \$528.6 ล้าน

ภาพรวมก่อนลงสูตร

นึกภาพว่าจดการขยับของ yield ทุกวัน วันละหนึ่งจุด ถ้ามีสองอายุ แต่ละวันคือจุดหนึ่งบนกระดาษ แกนนอนคือการขยับของอายุสั้น แกนตั้งคือการขยับของอายุยาว (รูปข้างล่าง) เพราะสองอายุมักขยับไปทางเดียวกัน จุดจึงไม่กระจายเป็นวงกลม แต่กองเป็นรูปรีที่ยาวไปทางหนึ่งและแบนอีกทางหนึ่ง ถ้ามีแปดอายุ แต่ละวันก็เป็นจุดใน 8 มิติ วาดไม่ได้ แต่ก็ยังกองเป็นรูปรีแบบเดียวกัน

PCA (Principal Component Analysis) หาแกนใหม่ให้รูปรีนี้ แกนแรกคือทิศที่รูปรียาวที่สุด หรือทิศที่ข้อมูลแกว่งมากที่สุด แกนที่สองคือทิศที่ยาวที่สุดในบรรดาทิศที่ตั้งฉากกับแกนแรก แล้วทำต่อไปจนครบทุกมิติ หน้านี้จะพิสูจน์ว่าแกนเหล่านี้คือ eigenvector ของ covariance matrix และ variance ตามแต่ละแกนคือ eigenvalue ของมัน (eigenvector คือ vector ที่ matrix คูณแล้วได้ทิศเดิม แค่ยืดหรือหด ส่วนตัวยืดคือ eigenvalue ดูนิยามเต็มใน eigenvalue และ positive definiteness)

ทำไมต้องหาแกนใหม่ มีเหตุผลสามข้อ

  • ลดจำนวนตัวเลขที่ต้องดู แปดอายุอาจสรุปได้ด้วยสามแกนที่เก็บความแกว่งไว้เกือบทั้งหมด
  • แกนใหม่ไม่มี covariance ระหว่างกัน โต๊ะจึงรายงานความเสี่ยงแยกทีละแกนได้โดยไม่ปนกัน
  • มันชี้ทิศที่รูปรีแบนมาก ทิศเหล่านี้คือที่มาของปัญหาใน Markowitz optimizer (โปรแกรมที่เลือกน้ำหนักของพอร์ตจาก covariance) เพราะสูตรของ optimizer ใช้ inverse ของ covariance ซึ่งขยายความคลาดในทิศแบนให้ใหญ่มาก น้ำหนักที่ได้จึงสุดโต่ง

ลำดับของหน้านี้: หาแกนของสามอายุด้วยมือ อ่านรูปทรงของแต่ละแกน (เรียกว่า level, slope และ curvature) พิสูจน์ว่าทำไมต้องเป็น eigenvector ดูผลของแปดอายุแล้วเลือกว่าจะเก็บกี่แกน จากนั้นใช้แกนแรกสร้าง hedge และจบที่บทเรียนสำคัญ: แกนที่ variance เล็ก ไม่ได้แปลว่าพอร์ตเสี่ยงน้อยในแกนนั้น

คำว่า “ทิศ” กับ “แกน” ในหน้านี้หมายถึงสิ่งเดียวกัน คือ vector ยาวหนึ่งหน่วยที่บอกว่าแต่ละอายุขยับมากน้อยแค่ไหนเมื่อเดินไปตามแกนนั้น

ศัพท์ที่ใช้ในหัวข้อนี้
Principal Component Analysis (PCA)
การหาแกนใหม่ให้ข้อมูลหลายตัวแปร แกนแรกชี้ทิศที่ข้อมูลแกว่งมากที่สุด แกนถัดไปชี้ทิศที่แกว่งมากที่สุดในบรรดาทิศที่ตั้งฉากกับแกนก่อนหน้า ใช้ลดจำนวนตัวแปร และแยกความเสี่ยงออกเป็นส่วนที่ไม่ปนกัน
พันธบัตร (bond) และ yield
พันธบัตรคือสัญญากู้เงินที่ผู้กู้ (ในหน้านี้คือรัฐบาล) จ่ายดอกเบี้ยและคืนเงินต้นเมื่อครบอายุ yield คือดอกเบี้ยต่อปีที่ตลาดเรียกจากพันธบัตรอายุนั้นในวันนี้ yield ขึ้นแปลว่าราคาพันธบัตรตก
Yield curve (เส้น yield)
yield ของพันธบัตรทุกอายุในวันเดียวกัน วาดเป็นเส้นโดยให้แกนนอนเป็นอายุ ใช้ดูว่าการกู้ยืมระยะสั้นกับระยะยาวมีดอกเบี้ยต่างกันแค่ไหน
Basis point (bp)
หนึ่งในร้อยของหนึ่งเปอร์เซ็นต์ คือ 0.01% เป็นหน่วยที่ใช้วัดการขยับของดอกเบี้ย เช่น 4.20% เป็น 4.25% คือขึ้น 5 bp
Correlation
ตัวเลขจาก −1 ถึง 1 ที่บอกว่าสองตัวแปรขยับไปทางเดียวกันแน่นแค่ไหน คือ covariance หารด้วยผลคูณของความผันผวนทั้งสองตัว (ดู ค่าเฉลี่ยและ covariance matrix)
Loading
ตัวเลขแต่ละช่องของ eigenvector ยาวหนึ่งหน่วย ไม่มีหน่วย บอกว่าเมื่อเดินตามแกนนั้นหนึ่งหน่วย แต่ละตัวแปรขยับเท่าไร มันไม่ใช่สัดส่วนเงินลงทุน
คะแนน (score)
ตำแหน่งของข้อมูลวันหนึ่งบนแกนใหม่ หาได้จากผลคูณภายใน (dot product) ของการขยับวันนั้นกับ eigenvector ใช้แทนตัวแปรเดิมทั้งชุดด้วยตัวเลขไม่กี่ตัว
Level, slope, curvature
ชื่อของสามแกนแรกของเส้น yield level คือทั้งเส้นขึ้นหรือลงพร้อมกัน slope คือปลายสั้นกับปลายยาวขยับสวนกัน เส้นจึงชันขึ้นหรือแบนลง curvature คือตรงกลางขยับสวนกับสองปลาย ท้องเส้นจึงนูนหรือยุบ
Scree plot
กราฟแท่งของ eigenvalue เรียงจากมากไปน้อย ใช้ตัดสินว่าจะเก็บกี่แกน โดยดูว่าแท่งหักลงเป็นเศษเล็ก ๆ ตรงไหน
DV01
เงินที่มูลค่าพันธบัตรเปลี่ยนเมื่อ yield ขยับ 1 bp หน่วยคือดอลลาร์ต่อ bp ใช้แปลงการขยับของ yield เป็นกำไรขาดทุน (ที่มาของมันอยู่ใน duration)
Short และ hedge
short คือยืมของมาขายก่อนแล้วซื้อคืนทีหลัง จึงได้กำไรเมื่อราคาตก hedge คือการถือสถานะอีกขาหนึ่งไว้หักล้างกำไรขาดทุนของขาแรก

$Q,\ \Lambda$matrix ที่มี $q_k$ เป็นคอลัมน์ และ matrix แนวทแยงของ $\lambda_k$ตาม matrix

ขั้นที่ 1 — ลองด้วยมือ: เดาทิศที่ปลายสองข้างสวนกัน

เริ่มจากตัวอย่างที่เล็กพอจะคิดด้วยมือ คือสามอายุ 2, 7 และ 20 ปีจากโจทย์ต้นหน้า ข้อมูลที่ใช้คือการขยับรายวันของ yield ไม่ใช่ตัว yield เอง เพราะระดับ yield เดินไปเรื่อย ๆ ไม่วนกลับมาที่ค่าเดิม ค่าเฉลี่ยของมันจึงไม่นิ่ง ส่วนการขยับรายวันแกว่งรอบค่าคงที่

ก่อนเริ่ม ปรับแต่ละอายุให้เป็นมาตรฐาน คือลบค่าเฉลี่ย $m_i$ แล้วหารด้วยความผันผวนรายวัน $\sigma_i$ ของอายุนั้น ได้ $x_i=(\Delta y_i-m_i)/\sigma_i$ ตัวแปร $x_i$ ไม่มีหน่วยและมี variance 1 ทุกตัว covariance ของ $x$ จึงเท่ากับ correlation matrix $R$ ของการขยับพอดี

สิ่งที่ตามหาคือ eigenvector ของ $R$ คือ vector $v$ ที่ $Rv=\lambda v$ (ขั้นที่ 4 จะพิสูจน์ว่าทำไมต้องเป็นมัน) ทางลัดของการเดาอยู่ที่รูปของ $R$ ถ้าสลับอายุ 2 ปีกับ 20 ปี (แถวแรกกับแถวสาม และคอลัมน์แรกกับคอลัมน์สาม) $R$ ยังเหมือนเดิม เพราะ correlation ของ 2 กับ 7 ปี เท่ากับของ 7 กับ 20 ปี คือ 0.90 ทั้งคู่ ดังนั้นถ้ากลับหัวท้ายของ eigenvector ก็ต้องได้ eigenvector อีก ทิศที่ง่ายที่สุดจึงมีสองแบบ แบบแรกกลับหัวท้ายแล้วได้ตัวเดิม $(x,y,x)$ แบบที่สองกลับแล้วได้ลบของตัวเอง ซึ่งช่องกลางต้องเป็นศูนย์ คือ $(1,0,-1)$ ลองแบบที่สองก่อน เพราะไม่มีตัวแปรให้หา

\[ \begin{aligned} R&=\begin{bmatrix}1&0.90&0.75\\0.90&1&0.90\\0.75&0.90&1\end{bmatrix},\\ v&=(1,\ 0,\ -1),\\ Rv&=(1-0.75,\ 0.90-0.90,\ 0.75-1)\\ &=(0.25,\ 0,\ -0.25)=0.25\,v,\\ \lambda_2&=1-0.75=0.25,\\ |v|&=\sqrt{1^2+0^2+1^2}=\sqrt2,\\ q_2&=\tfrac{1}{\sqrt2}(1,\ 0,\ -1)\\ &=(0.7071,\ 0,\ -0.7071). \end{aligned} \]

$R$ คูณ $v$ แล้วได้ $v$ ตัวเดิมคูณ 0.25 ทิศไม่เปลี่ยน แค่หดลง นี่คือนิยามของ eigenvector พอดี และ 0.25 คือ eigenvalue ของมัน ตั้งชื่อว่า $\lambda_2$ เพราะขั้นถัดไปจะพบว่ามันใหญ่เป็นอันดับสอง เครื่องหมาย บวก ศูนย์ ลบ หมายถึงวันที่อายุสั้นขึ้นแต่อายุยาวลง หรือกลับกัน เส้น yield จึงเปลี่ยนความชัน ทิศนี้เลยชื่อ slope

ทำไม $\lambda_2$ ออกมาเป็น $1-0.75$ เพราะทิศนี้วัดว่าปลายสองข้างขยับต่างกันแค่ไหน ถ้าปลายทั้งสองเกาะกันแน่น (correlation ใกล้ 1) ก็แทบไม่ต่างกัน ความแกว่งในทิศ slope จึงเล็ก สุดท้ายหาร $v$ ด้วยความยาว $\sqrt2$ เพื่อให้ได้ vector ยาวหนึ่งหน่วย $q_2$ ตัวเลขในแต่ละช่องของ $q_2$ เรียกว่า loading

ขั้นที่ 2 — อีกสองตัวจากสมการกำลังสอง

matrix สมมาตรขนาด 3×3 มี eigenvector ที่ตั้งฉากกันสามตัว เราได้มาแล้วหนึ่งตัว อีกสองตัวต้องตั้งฉากกับ $(1,0,-1)$ คือช่องแรกลบช่องสามต้องเป็นศูนย์ จึงเป็นแบบปลายสองข้างเท่ากัน $(x,y,x)$ ใส่ $(x,y,x)$ เข้าไปใน $R$ แล้วแถวแรกกับแถวสามให้สมการเดียวกัน ปัญหาสามตัวแปรจึงเหลือสองตัวแปร คือ $x$ กับ $y$

\[ \begin{aligned} R(x,y,x)&=(1.75x+0.90y,\ 1.80x+y,\\ &\qquad 1.75x+0.90y),\\ 1.75x+0.90y&=\lambda x,\\ 1.80x+y&=\lambda y,\\ (1.75-\lambda)(1-\lambda)&=0.90(1.80)=1.62,\\ \lambda^2-2.75\lambda+1.75&=1.62,\\ \lambda^2-2.75\lambda+0.13&=0,\\ \lambda&=\frac{2.75\pm\sqrt{7.0425}}{2}=\frac{2.75\pm2.65377}{2},\\ \lambda_1&=2.70189,\quad \lambda_3=0.04811,\\ \lambda_1+\lambda_2+\lambda_3&=3=\operatorname{trace}R. \end{aligned} \]

ช่องแรกของ $R(x,y,x)$ มาจาก $1\cdot x+0.90y+0.75x=1.75x+0.90y$ ช่องกลางมาจาก $0.90x+y+0.90x=1.80x+y$ สองสมการ $1.75x+0.90y=\lambda x$ กับ $1.80x+y=\lambda y$ เขียนใหม่ได้เป็น $(1.75-\lambda)x+0.90y=0$ และ $1.80x+(1-\lambda)y=0$ ระบบนี้มีคำตอบเสมอคือ $x=y=0$ แต่นั่นไม่ใช่ทิศ เราต้องการคำตอบที่ไม่ใช่ศูนย์ ซึ่งมีได้เมื่อ determinant ของระบบเป็นศูนย์ คือ $(1.75-\lambda)(1-\lambda)-0.90(1.80)=0$ กระจายออกมาก็ได้สมการกำลังสองในบรรทัดถัดมา

ทำไมสัมประสิทธิ์ไม่สมมาตร (0.90 กับ 1.80) เพราะเราพับปลายสองข้างให้เป็นตัวแปร $x$ ตัวเดียว ตัวกลางเห็นปลายทั้งสองข้าง จึงได้ 0.90 สองครั้ง ส่วนปลายแต่ละข้างเห็นตัวกลางแค่ครั้งเดียว

รากของสมการต้องการ $\sqrt{2.75^2-4(0.13)}=\sqrt{7.5625-0.52}=\sqrt{7.0425}$ ซึ่งคิดมือได้ดังนี้ $2.65^2=7.0225$ ยังขาดอีก $7.0425-7.0225=0.02$ เมื่อเพิ่ม $2.65$ ขึ้นนิดหนึ่ง กำลังสองโตขึ้นราว $2(2.65)$ เท่าของส่วนที่เพิ่ม จึงต้องเพิ่ม $0.02/5.3=0.00377$ ได้ $2.65377$

บรรทัดสุดท้ายคือตัวตรวจคำตอบ ผลบวกของ eigenvalue เท่ากับผลบวกแนวทแยงของ matrix (trace) เสมอ แนวทแยงของ correlation matrix เป็น 1 ทุกช่อง ผลบวกจึงต้องเป็น 3 พอดี ซึ่งก็เป็นอย่างนั้น ตอนนี้ได้ eigenvalue ครบสามตัว เรียงจากใหญ่ไปเล็กคือ $\lambda_1=2.70189$, $\lambda_2=0.25$ และ $\lambda_3=0.04811$

ขั้นที่ 3 — loading แล้วอ่านเครื่องหมาย

ตอนนี้รู้ขนาดของแต่ละทิศ (eigenvalue) แล้ว แต่ยังไม่รู้ว่าทิศหน้าตาเป็นอย่างไร ต้องหา $x$ กับ $y$ ของแต่ละ $\lambda$ จากสมการแรกของระบบ $1.75x+0.90y=\lambda x$ ได้ $y=(\lambda-1.75)x/0.90$ ความยาวของ vector ไม่สำคัญ จึงตั้ง $x=1$ ไปก่อน แล้วค่อยหารด้วยความยาวให้ยาวหนึ่งหน่วย

\[ \begin{aligned} \lambda_1&:\ y=\frac{2.70189-1.75}{0.90}=\frac{0.95189}{0.90}\\ &\qquad=1.05765,\\ |v|&=\sqrt{1^2+1.05765^2+1^2}=1.76596,\\ q_1&=\frac{(1,\ 1.05765,\ 1)}{1.76596}\\ &=(0.5663,\ 0.5989,\ 0.5663),\\ \lambda_3&:\ y=\frac{0.04811-1.75}{0.90}=\frac{-1.70189}{0.90}\\ &\qquad=-1.89098,\\ |v|&=\sqrt{1^2+1.89098^2+1^2}=2.36132,\\ q_3&=\frac{(1,\ -1.89098,\ 1)}{2.36132}\\ &=(0.4235,\ -0.8008,\ 0.4235),\\ q_1^{\mathsf T}q_3&=2(0.5663)(0.4235)\\ &\quad-0.5989(0.8008)\approx0. \end{aligned} \]

$q_1$ เป็นบวกทุกช่อง และขนาดใกล้กัน แปลว่าเมื่อเดินตามทิศนี้ ทุกอายุขยับไปทางเดียวกันเกือบเท่ากัน ทั้งเส้นขึ้นหรือลงพร้อมกัน จึงเรียกทิศนี้ว่า level ส่วน $q_3$ บวกที่สองปลายแต่ลบตรงกลาง แปลว่าตรงกลางขยับสวนกับปลาย ท้องเส้นจึงนูนหรือยุบ เรียกว่า curvature

บรรทัดสุดท้ายตรวจว่า $q_1$ ตั้งฉากกับ $q_3$ ผลคูณภายในออกมาเป็น $0.47966-0.47960$ ซึ่งเป็นศูนย์ภายในการปัดเศษ ไม่ใช่เรื่องบังเอิญ eigenvector ของ matrix สมมาตรที่ eigenvalue ต่างกัน ตั้งฉากกันเสมอ

วิธีอ่านรูปทรงให้เร็ว: เดินจากอายุสั้นไปอายุยาว แล้วนับว่าเครื่องหมายของ loading สลับกี่ครั้ง ไม่สลับเลยคือ level สลับครั้งเดียวคือ slope สลับสองครั้งคือ curvature ถ้าโปรแกรมให้เครื่องหมายกลับทั้งชุด เช่นได้ $-q_1$ ก็ยังเป็นทิศเดิมที่มองจากอีกด้าน เพราะ $R(-q)=\lambda(-q)$ ลบของ eigenvector จึงเป็น eigenvector ด้วย

ขั้นที่ 4 — ทำไมทิศที่แกว่งมากที่สุดต้องเป็น eigenvector

สามขั้นที่ผ่านมาหา eigenvector ได้ครบ แต่ยังไม่ได้ตอบว่าทำไมทิศที่ข้อมูลแกว่งมากที่สุดต้องเป็น eigenvector ขั้นนี้พิสูจน์ให้ดู

ให้ $q$ เป็นทิศหนึ่งที่ยาวหนึ่งหน่วย ตำแหน่งของข้อมูลวันหนึ่งบนทิศนี้คือผลคูณภายใน $q^{\mathsf T}x=q_1x_1+q_2x_2+q_3x_3$ ซึ่งก็คือการรวมตัวแปรด้วยน้ำหนัก $q$ เหมือนพอร์ตที่ถือแต่ละตัวแปรเป็นน้ำหนัก $q_i$ variance ของมันจึงเป็น $q^{\mathsf T}Rq$ ตามหลักเดียวกับ ความเสี่ยงของพอร์ต คำถามคือ $q$ แบบไหนทำให้ $q^{\mathsf T}Rq$ มากที่สุด

ต้องบังคับให้ $q^{\mathsf T}q=1$ ด้วย เพราะถ้าไม่บังคับ แค่ยืด $q$ ให้ยาวขึ้น ค่า $q^{\mathsf T}Rq$ ก็โตขึ้นไม่มีที่สิ้นสุด การหาค่ามากสุดภายใต้เงื่อนไขแบบนี้ใช้ Lagrange multipliers

\[ \begin{aligned} \mathcal L&=q^{\mathsf T}Rq-\lambda\big(q^{\mathsf T}q-1\big),\\ \frac{\partial\mathcal L}{\partial q}&=2Rq-2\lambda q=0,\\ Rq&=\lambda q,\\ q^{\mathsf T}Rq&=\lambda\,q^{\mathsf T}q=\lambda,\\ z&=Q^{\mathsf T}x,\\ \operatorname{Cov}(z)&=Q^{\mathsf T}RQ=\Lambda,\\ x&=Qz=\textstyle\sum_k q_k z_k,\\ \Delta y_i&=m_i+\sigma_i\textstyle\sum_k q_{ik}z_k. \end{aligned} \]

$\mathcal L$ คือ variance ลบด้วยตัวคูณ $\lambda$ คูณเงื่อนไขความยาว ที่จุดสูงสุด อนุพันธ์ของ $\mathcal L$ เทียบกับ $q$ ต้องเป็นศูนย์ อนุพันธ์ของ $q^{\mathsf T}Rq$ คือ $2Rq$ (เพราะ $R$ สมมาตร) และของ $q^{\mathsf T}q$ คือ $2q$ จึงได้ $Rq=\lambda q$ ซึ่งคือนิยามของ eigenvector พอดี ทิศที่เป็นจุดสูงสุดจึงต้องเป็น eigenvector

eigenvector ตัวไหน คูณ $Rq=\lambda q$ ด้วย $q^{\mathsf T}$ ทางซ้าย ได้ variance $q^{\mathsf T}Rq=\lambda$ เพราะ $q^{\mathsf T}q=1$ variance ในทิศของ eigenvector จึงเท่ากับ eigenvalue ของมัน ทิศที่แกว่งมากที่สุดคือ eigenvector ที่ $\lambda$ ใหญ่ที่สุด ทิศถัดไปคือทิศที่แกว่งมากที่สุดในบรรดาทิศที่ตั้งฉากกับทิศแรก ซึ่งก็คือ eigenvector ตัวถัดไป

ครึ่งล่างของสูตรพูดถึงคะแนน $z$ คือตำแหน่งของแต่ละวันบนแกนใหม่ทุกแกนพร้อมกัน ($Q$ คือ matrix ที่มี $q_k$ เป็นคอลัมน์) covariance ของ $z$ คือ $Q^{\mathsf T}RQ$ ซึ่งเป็น matrix แนวทแยง $\Lambda$ ที่มี $\lambda_k$ บนแนวทแยง คะแนนต่างแกนจึงมี covariance เป็นศูนย์ แต่ไม่ได้แปลว่าเป็นอิสระกัน (ดู covariance ศูนย์ไม่ใช่ความอิสระ)

การกลับจากคะแนนเป็นข้อมูลเดิมทำได้ง่าย เพราะคอลัมน์ของ $Q$ ยาวหนึ่งหน่วยและตั้งฉากกัน ทำให้ $Q^{\mathsf T}=Q^{-1}$ จึงได้ $x=Qz$ แล้วคูณ $\sigma_i$ และบวกค่าเฉลี่ย $m_i$ กลับ ได้การขยับในหน่วย bp ตามบรรทัดสุดท้าย

ทำ PCA บน covariance $\Sigma$ ในหน่วย bp ก็ได้ แบบรูปกลุ่มจุดข้างบน วิธีนี้ใช้ eigenvector ของ $\Sigma$ และไม่ต้องหารด้วย $\sigma_i$ คะแนนจะมีหน่วย bp eigenvalue มีหน่วย bp กำลังสอง ส่วน loading ยังไม่มีหน่วยเหมือนเดิม สองวิธีให้ผลไม่เท่ากัน เพราะ correlation ให้ทุกตัวแปรมีเสียงเท่ากัน ส่วน covariance ให้ตัวที่แกว่งมากมีเสียงดังกว่า

ขั้นที่ 5 — สัดส่วนที่อธิบาย การประมาณที่ดีที่สุด และทิศที่ inverse ขยาย

ตอนนี้ตอบคำถามแรกของโจทย์ต้นหน้าได้แล้ว variance รวมของทั้งชุดคือผลบวกของ eigenvalue ทุกตัว ซึ่งเท่ากับ trace สำหรับ correlation matrix ตัวเลขนี้คือจำนวนตัวแปร (ที่นี่คือ 3) สัดส่วนที่ทิศหนึ่งเก็บไว้จึงเป็น eigenvalue ของมันหารด้วย 3

อีกเรื่องที่ต้องดูคือ inverse เพราะ Markowitz optimizer ใช้ $R^{-1}$ (หรือ $\Sigma^{-1}$) ในการหาน้ำหนักพอร์ต เมื่อ $R=Q\Lambda Q^{\mathsf T}$ และ $Q^{-1}=Q^{\mathsf T}$ จะได้ $R^{-1}=Q\Lambda^{-1}Q^{\mathsf T}$ คือ eigenvector ชุดเดิม แต่ eigenvalue กลับเป็น $1/\lambda_k$

\[ \begin{aligned} \frac{2.70189}{3}&=90.06\%,\quad \frac{0.25}{3}=8.33\%,\\ \frac{0.04811}{3}&=1.60\%,\\ R&\approx\lambda_1q_1q_1^{\mathsf T}+\lambda_2q_2q_2^{\mathsf T},\\ \frac{1}{\lambda_k}&=0.370,\ 4.00,\ 20.78,\\ \frac{\lambda_1}{\lambda_3}&=\frac{2.70189}{0.04811}=56.2. \end{aligned} \]

ทิศ level เก็บ variance ไว้ 90% นี่คือ 90% ของ variance รวมของตัวแปรที่ปรับมาตรฐานแล้ว ไม่ได้แปลว่าทายการขยับของทุกวันได้ถูก 90% ลองนึกกรณีสุดขั้ว ถ้า correlation ทุกคู่เป็น 1 ทุกอายุขยับเหมือนกันเป๊ะ ทิศแรกจะเก็บได้ 100% และอีกสองทิศเป็นศูนย์

บรรทัด $R\approx\lambda_1q_1q_1^{\mathsf T}+\lambda_2q_2q_2^{\mathsf T}$ คือความหมายของการ “เก็บสองทิศ” matrix สมมาตรทุกตัวเขียนได้เป็นผลบวก $\sum_k\lambda_kq_kq_k^{\mathsf T}$ ถ้าตัดพจน์ที่ $\lambda$ เล็กทิ้ง จะได้ matrix ที่มีอันดับ (rank) สองซึ่งใกล้ของจริงที่สุด ผลนี้ชื่อทฤษฎีบทของ Eckart และ Young (ยกมาใช้โดยไม่พิสูจน์) ในภาษาข้อมูล ถ้าเก็บแค่คะแนนสองทิศแรกของทุกวันแล้วสร้างการขยับกลับ ส่วนที่หายไปมีผลรวมกำลังสองเฉลี่ยต่อวันเท่ากับ eigenvalue ที่ทิ้ง คือ $\lambda_3=0.048$ จาก variance รวม 3

ด้าน inverse: $1/\lambda$ ของทิศ curvature ใหญ่กว่าของทิศ level ถึง $\lambda_1/\lambda_3=56.2$ เท่า สมมติว่า covariance ที่ประมาณจากข้อมูลมีความคลาดเล็ก ๆ ปนอยู่ ถ้าความคลาดตกในทิศที่ variance ต่ำ inverse จะขยายมันมาก optimizer ซึ่งใช้ inverse จึงตอบสนองต่อทิศเหล่านี้แรงเกินจริง อัตราส่วน eigenvalue ใหญ่สุดต่อเล็กสุดนี้เรียกว่า condition number ของ $R$ หน้า Ledoit–Wolf shrinkage จะแสดงวิธีดึงค่านี้ลง

ขั้นที่ 6 — แปดอายุด้วยคอมพิวเตอร์ และเลือกว่าจะเก็บกี่ทิศ

โต๊ะจริงดูมากกว่าสามอายุ ขั้นนี้ขยายเป็นแปดอายุ คือ 1, 2, 3, 5, 7, 10, 15 และ 20 ปี แล้วดูว่ารูปทรงสามแบบยังอยู่ไหม และต้องเก็บกี่ทิศ

correlation ที่ใช้มาจากสูตรสมมติ ให้ correlation ของอายุ $T_i$ กับ $T_j$ ลดลงตามระยะห่างของ $\ln T$ เหตุผลคือ 1 ปีกับ 2 ปีต่างกันมาก (อายุเป็นสองเท่า) แต่ 15 ปีกับ 20 ปีแทบเหมือนกัน คู่ที่อายุห่างกันเป็นสัดส่วนเท่ากันจึงควรมี correlation เท่ากัน ตัวอย่างสามคู่:

\[ \begin{aligned} R_{1,2}&=e^{-0.15\ln2}=2^{-0.15}=0.901,\\ R_{15,20}&=(20/15)^{-0.15}=0.958,\\ R_{1,20}&=20^{-0.15}=0.638. \end{aligned} \]

matrix 8×8 แก้ด้วยมือไม่ไหว จึงให้โค้ดท้ายหน้าคำนวณ (ใช้การหมุนแบบ Jacobi) ตัวตรวจยังเหมือนเดิม ผลบวกของ eigenvalue ต้องเท่ากับ trace คือ 8

\[ \begin{aligned} R_{ij}&=e^{-0.15\,|\ln T_i-\ln T_j|},\\ \lambda&=6.849,\ 0.662,\ 0.211,\ 0.110,\\ &\qquad 0.063,\ 0.043,\ 0.034,\ 0.029,\\ \frac{\lambda}{8}&=85.6\%,\ 8.3\%,\ 2.6\%,\ 1.4\%,\dots,\\ 85.6+8.3+2.6&=96.5\%,\\ \tfrac{1}{\sqrt8}&=0.354,\quad q_1\approx0.324\ \text{to}\ 0.367,\\ q_2&=(0.53,\ 0.42,\ 0.28,\ 0.04,\\ &\qquad -0.12,\ -0.28,\ -0.40,\ -0.44). \end{aligned} \]

ดูทิศแรกก่อน ถ้าทั้งแปดอายุขยับเท่ากันเป๊ะ loading ของทิศแรกจะเป็น $1/\sqrt8=0.354$ ทุกช่อง (vector ที่ทุกช่องเท่ากันและยาวหนึ่งหน่วย) ค่าที่ได้จริงอยู่ระหว่าง 0.324 ถึง 0.367 เกาะรอบ 0.354 ทิศแรกจึงคือทั้งเส้นขยับพร้อมกัน เป็น level เหมือนตัวอย่างสามอายุ ทิศที่สองเปลี่ยนเครื่องหมายครั้งเดียว ระหว่าง 5 ปี (+0.04) กับ 7 ปี (−0.12) จึงเป็น slope ทิศที่สามเปลี่ยนเครื่องหมายสองครั้ง จึงเป็น curvature ตัวเลขไม่เท่ากับตัวอย่างสามอายุ เพราะ matrix ต่างกัน แต่รูปทรงเหมือนกัน ข้อมูลพันธบัตรจริงก็ให้ภาพเดียวกัน Litterman และ Scheinkman (1991) พบรูปทรงสามแบบนี้ในพันธบัตรรัฐบาลสหรัฐ และสามทิศแรกรวมกันอธิบาย variance ได้ราว 95% ขึ้นไป

ต่อไปคือคำถามว่าจะเก็บกี่ทิศ วิธีที่เก่าและนิยมที่สุดคือ scree plot ในรูปข้างล่าง ให้มองหาจุดที่แท่งหักจากก้อนใหญ่ลงเป็นเศษเล็ก ๆ ที่ลดลงช้า ๆ ในตัวอย่างนี้คือหลังทิศที่สามหรือสี่

อีกเกณฑ์หนึ่งตอบคำถามว่า eigenvalue ขนาดไหนเกิดได้จากความบังเอิญล้วน ๆ สมมติว่ามีตัวแปร $n$ ตัวที่ไม่สัมพันธ์กันเลย correlation matrix ที่แท้จริงคือ identity matrix (1 บนแนวทแยง 0 ที่อื่น) ซึ่ง eigenvalue ทุกตัวเป็น 1 แต่ถ้าประมาณ correlation จากข้อมูลแค่ $T$ วัน eigenvalue ที่ได้จะกระจายออกจาก 1 และตัวที่ใหญ่สุดขึ้นไปได้ถึงราว $(1+\sqrt{n/T})^2$ ผลนี้มาจากทฤษฎี random matrix ชื่อ Marchenko–Pastur (ยกมาใช้โดยไม่พิสูจน์) ตัวอย่างเช่นหุ้น 500 ตัวกับข้อมูล 250 วัน:

\[\begin{aligned}n/T&=500/250=2,\\(1+\sqrt2)^2&=2.414^2=5.83.\end{aligned}\]

ทิศใดที่ eigenvalue ไม่เกิน 5.83 จึงแยกจากเสียงสุ่มไม่ออก และ eigenvector ของมันแทบไม่มีข้อมูลจริง ส่วนทิศใหญ่ที่ยื่นพ้นขอบนี้ ค่าที่ประมาณได้ก็สูงกว่าค่าจริงราว $n/T$ เช่นกัน

ถ้าต้องพลาด ให้พลาดทางเก็บทิศมากเกินไปดีกว่า เพราะถ้าเก็บน้อยเกิน แบบจำลองจะมองไม่เห็นความเสี่ยงในทิศที่ทิ้งไป optimizer ก็จะเทน้ำหนักเข้าไปในทิศนั้นเพราะคิดว่ามันไม่เสี่ยง สำหรับหุ้น ทิศแรกเกือบทุกครั้งคือตลาดทั้งตลาด (loading บวกทุกตัว) ทิศถัดไปมักเป็นกลุ่มอุตสาหกรรม หรือสไตล์ของหุ้น เช่นหุ้นเล็กสวนกับหุ้นใหญ่ ซึ่งเชื่อมกับ multi-factor models

ขั้นที่ 7 — สร้างพอร์ตที่ไม่สนใจระดับดอกเบี้ย

กลับมาที่คำถามที่ 2 ของโจทย์ต้นหน้า เทรดเดอร์ถือพันธบัตร 10 ปี และกลัววันที่ทั้งเส้นขึ้นพร้อมกัน คือการขยับในทิศ level เขาจึงจะ short พันธบัตร 2 ปี ให้กำไรขาดทุนจากทิศ level ของสองขาหักล้างกันพอดี ส่วนความเสี่ยงจาก slope และ curvature เขายอมเก็บไว้

โจทย์ให้อะไรมาบ้าง:

  • ขา long: พันธบัตร 10 ปี มูลค่า \$100 ล้าน
  • DV01 ของพันธบัตร 10 ปี \$100 ล้าน คิดจาก modified duration (ราวว่ามูลค่าเปลี่ยนกี่ % เมื่อ yield ขยับ 1% ดู duration) ซึ่งสมมติว่าเป็น 8.5: $8.5\times\$100{,}000{,}000\times0.0001=\$85{,}000$ ต่อ bp (0.0001 คือ 1 bp)
  • DV01 ของพันธบัตร 2 ปี \$100 ล้าน ใช้ duration สมมติ 1.95: $1.95\times\$100{,}000{,}000\times0.0001=\$19{,}500$ ต่อ bp
  • loading ของทิศแรกจากแปดอายุในขั้นที่ 6: 0.3632 ที่ 10 ปี และ 0.3494 ที่ 2 ปี

จุดที่ต้องระวัง PCA นี้ทำบน correlation คือบนการขยับที่หารด้วยความผันผวน $\sigma_i$ แล้ว คะแนนของทิศแรกขยับหนึ่งหน่วย อายุ $i$ จึงขยับ $\sigma_iq_{1i}$ bp ไม่ใช่ $q_{1i}$ bp เมื่อรู้ว่าแต่ละอายุขยับกี่ bp ก็คูณ DV01 ได้กำไรขาดทุน ขา long เสียเงินเมื่อ yield ขึ้น จึงมีเครื่องหมายลบ ขา short $N$ เท่าของ \$100 ล้าน ได้เงินเมื่อ yield ขึ้น จึงมีเครื่องหมายบวก ตั้งผลรวมให้เป็นศูนย์แล้วแก้หา $N$

\[ \begin{aligned} \Delta y_i&=\sigma_i\,q_{1i}\,z_1,\\ 0&=-85{,}000\,\sigma_{10}(0.3632)\,z_1\\ &\quad+N\,19{,}500\,\sigma_2(0.3494)\,z_1,\\ N&=\frac{85{,}000\,\sigma_{10}(0.3632)}{19{,}500\,\sigma_{2}(0.3494)},\\ \sigma_2=\sigma_{10}&:\ N=\frac{30{,}870}{6{,}813.5}=4.5307,\\ \frac{\sigma_{10}}{\sigma_2}=\frac76&:\ N=4.5307\Big(\frac76\Big)=5.2858. \end{aligned} \]

ตัวเลข 30,870 กับ 6,813.5 คำนวณจาก loading ที่ยังไม่ปัด (0.363179 และ 0.349412) ถ้าใช้ค่าที่ปัดแล้วจะได้ 30,872 กับ 6,813.3 ซึ่งให้ $N$ เท่าเดิมเมื่อปัดสามตำแหน่ง

ทำไมต้อง short มากถึงราว 4.5 เท่า เหตุผลหลักคือ DV01 พันธบัตร 2 ปีไวต่อ yield น้อยกว่า 10 ปีถึง $85{,}000/19{,}500=4.36$ เท่า และ loading ยังต่างกันอีก $0.3632/0.3494=1.039$ เท่า ผลคูณ $4.36\times1.039=4.53$ คือ $N$ ที่ได้

คำตอบ: ถ้าสองอายุมีความผันผวนรายวันเท่ากัน ต้อง short พันธบัตร 2 ปี $4.5307\times\$100$ ล้าน $=\$453.1$ ล้าน ถ้าอายุ 10 ปีแกว่งวันละ 7 bp และอายุ 2 ปีแกว่งวันละ 6 bp (ตัวเลขสมมติ) ต้อง short $5.2858\times\$100$ ล้าน $=\$528.6$ ล้าน ความผันผวนต่างกันแค่ 1 bp แต่ hedge ต่างกัน $7/6-1\approx17\%$ ดังนั้น ก่อนเอา loading ของ correlation ไปใช้กับเงินจริง ต้องคูณความผันผวนกลับเข้าไปเสมอ

หลัง hedge พอร์ตยังเหลือความไวต่อทิศอื่น ดูทิศ slope ซึ่ง loading คือ $+0.42$ ที่ 2 ปี และ $-0.28$ ที่ 10 ปี วันที่คะแนน slope เป็นบวก yield 2 ปีขึ้น ราคาพันธบัตร 2 ปีตก ขา short ได้กำไร ส่วน yield 10 ปีลง ราคาพันธบัตร 10 ปีขึ้น ขา long ก็ได้กำไร สองขาได้พร้อมกัน ไม่หักล้างกัน วันแบบนี้คือวันที่เส้น yield แบนลง (อายุสั้นขึ้น อายุยาวลง) พอร์ตนี้จึงเป็นเดิมพันความชัน เส้นแบนลงได้กำไร เส้นชันขึ้นขาดทุน

ตรวจเองใน 10 วินาที: ขา short ขยับ $4.5307\times19{,}500\times0.3494=30{,}869$ ขา long ขยับ $85{,}000\times0.3632=30{,}872$ ต่อหน่วยของ $\sigma z_1$ สองตัวเท่ากันภายในการปัดเศษ สองขาจึงหักล้างกันพอดี

ขั้นที่ 8 — ตัวอย่างที่สอง: ประกอบ matrix จากแกนที่รู้คำตอบ

ตัวอย่างแรกเริ่มจาก matrix แล้วหาทิศ ตัวอย่างนี้ทำกลับทาง คือเลือกทิศและขนาดเองก่อน แล้วประกอบเป็น covariance matrix เราจึงรู้คำตอบล่วงหน้า และตรวจได้ว่า PCA แกะกลับได้ของเดิม ขั้นถัดไปจะใช้ matrix นี้คิดความเสี่ยงของพอร์ตเป็นดอลลาร์

ของที่เลือก (สมมติทั้งหมด):

  • สามอายุ คือ 2, 5 และ 10 ปี ข้อมูลคือการขยับรายวันในหน่วย bp และใช้ covariance โดยตรง ไม่ปรับมาตรฐาน คะแนนจึงมีหน่วย bp
  • ทิศ level $q_1$ ทุกช่องเท่ากัน ทิศ slope $q_2$ สองปลายสวนกัน ทิศ curvature $q_3$ ตรงกลางสวนกับสองปลาย
  • variance ของคะแนนสามทิศคือ 81, 9 และ 1 bp กำลังสอง ความผันผวนรายวันจึงเป็น $\sqrt{81}=9$, $\sqrt9=3$ และ $\sqrt1=1$ bp
\[ \begin{aligned} q_1&=\tfrac{1}{\sqrt3}(1,1,1),\quad q_2=\tfrac{1}{\sqrt2}(-1,0,1),\\ q_3&=\tfrac{1}{\sqrt6}(1,-2,1),\quad \Lambda=\operatorname{diag}(81,\ 9,\ 1),\\ \Sigma&=Q\Lambda Q^{\mathsf T}=\frac13\begin{bmatrix}95&80&68\\80&83&80\\68&80&95\end{bmatrix},\\ (\Sigma q_1)_1&=\frac{95+80+68}{3\sqrt3}=\frac{81}{\sqrt3}=81\,(q_1)_1,\\ \frac{81}{91}&=89.01\%,\quad \frac{9}{91}=9.89\%,\quad \frac{1}{91}=1.10\%. \end{aligned} \]

แต่ละช่องของ $\Sigma=Q\Lambda Q^{\mathsf T}$ คือ $\Sigma_{ij}=\sum_k\lambda_k(q_k)_i(q_k)_j$ ช่อง $(1,1)$ จึงเป็น $81\big(\tfrac{1}{\sqrt3}\big)^2+9\big(\tfrac{-1}{\sqrt2}\big)^2+1\big(\tfrac{1}{\sqrt6}\big)^2=27+4.5+\tfrac16=\tfrac{95}{3}$ ช่องอื่นคิดแบบเดียวกัน

บรรทัด $(\Sigma q_1)_1$ คือการตรวจคำตอบ คูณแถวแรกของ $\Sigma$ กับ $q_1$ ได้ 81 คูณช่องแรกของ $q_1$ พอดี แปลว่า $\Sigma$ แค่ยืดทิศ $q_1$ ออก 81 เท่าโดยไม่หมุน $q_1$ จึงเป็น eigenvector ที่มี eigenvalue 81 ตามที่เลือกไว้ PCA แกะกลับได้ของเดิมจริง

variance รวมคือผลบวกแนวทแยง $(95+83+95)/3=91$ ซึ่งเท่ากับ $81+9+1$ ผลบวกของ eigenvalue ที่เลือก สัดส่วนของแต่ละทิศจึงหารด้วย 91 ทิศ level เก็บไว้ 89%

ขั้นที่ 9 — variance เล็กไม่ได้แปลว่ากำไรขาดทุนเล็ก

ทิศ slope มี variance แค่ 9 จาก 91 และทิศ curvature แค่ 1 จาก 91 ใครเห็นตัวเลขนี้อาจคิดว่าตัด level ทิ้งแล้วก็แทบไม่เหลือความเสี่ยง ขั้นนี้ใช้พอร์ตจริงตัวหนึ่งตรวจความคิดนั้น

ของที่รู้ (สมมติ): พอร์ตพันธบัตรมี DV01 ที่อายุ 2, 5 และ 10 ปี เท่ากับ \$2,000, \$5,000 และ \$9,000 ต่อ bp เขียนเป็น vector $d=(2{,}000,\ 5{,}000,\ 9{,}000)$ ถ้า yield แต่ละอายุขยับ $\Delta y_i$ bp มูลค่าพอร์ตเปลี่ยน $\Delta V=-d^{\mathsf T}\Delta y$ (ลบเพราะ yield ขึ้นแล้วราคาพันธบัตรตก) ขั้นที่ 4 ให้ $\Delta y=\sum_kq_kz_k$ เมื่อใช้ covariance (ไม่มี $\sigma_i$ และสมมติค่าเฉลี่ยเป็นศูนย์) แทนลงไปแล้ว กำไรขาดทุนแยกเป็นสามทิศ ตัวคูณหน้า $z_k$ คือความไวของพอร์ตต่อทิศนั้น หน่วยดอลลาร์ต่อ bp ของคะแนน ให้ $s_V$ เป็นความผันผวนรายวันของกำไรขาดทุน

\[ \begin{aligned} \Delta V&=-\textstyle\sum_k(d^{\mathsf T}q_k)\,z_k,\\ d^{\mathsf T}q_1&=\tfrac{2{,}000+5{,}000+9{,}000}{\sqrt3}\\ &=\tfrac{16{,}000}{\sqrt3}=9{,}238,\\ d^{\mathsf T}q_2&=\tfrac{-2{,}000+9{,}000}{\sqrt2}\\ &=\tfrac{7{,}000}{\sqrt2}=4{,}950,\\ d^{\mathsf T}q_3&=\tfrac{2{,}000-10{,}000+9{,}000}{\sqrt6}\\ &=\tfrac{1{,}000}{\sqrt6}=408,\\ s_V^2&=81\tfrac{16{,}000^2}{3}+9\tfrac{7{,}000^2}{2}+1\tfrac{1{,}000^2}{6}\\ &=(6{,}912+220.5+0.17)\times10^6,\\ s_V&=\sqrt{7{,}132.7\times10^6}\approx84{,}455. \end{aligned} \]

ทำไม $s_V^2$ เป็นแค่ผลบวกสามพจน์ เพราะคะแนนของสามทิศมี covariance เป็นศูนย์ต่อกัน (ขั้นที่ 4) และมี variance $\lambda_k=81,\ 9,\ 1$ variance ของผลบวกจึงเป็นความไวกำลังสองคูณ $\lambda_k$ รวมกัน ไม่มีพจน์ไขว้ ก่อน hedge ความเสี่ยงเกือบทั้งหมดมาจาก level คือ $6{,}912/7{,}132.7\approx97\%$ ของ variance

ต่อไปตัดทิศ level ทิ้งด้วยการ short พันธบัตร 2 ปี ซึ่งเพิ่ม DV01 ติดลบที่อายุ 2 ปี เพราะ $q_1$ มีทุกช่องเท่ากัน $d^{\mathsf T}q_1$ จะเป็นศูนย์เมื่อผลรวมของ DV01 เป็นศูนย์ จึงต้องเพิ่ม $-16{,}000$ ที่ 2 ปี ได้พอร์ตใหม่ $d'$

\[ \begin{aligned} d'&=(2{,}000-16{,}000,\ 5{,}000,\ 9{,}000)\\ &=(-14{,}000,\ 5{,}000,\ 9{,}000),\\ d'^{\mathsf T}q_1&=\tfrac{-14{,}000+5{,}000+9{,}000}{\sqrt3}=0,\\ d'^{\mathsf T}q_2&=\tfrac{-(-14{,}000)+9{,}000}{\sqrt2}\\ &=\tfrac{23{,}000}{\sqrt2}=16{,}263,\\ d'^{\mathsf T}q_3&=\tfrac{-14{,}000-10{,}000+9{,}000}{\sqrt6}\\ &=\tfrac{-15{,}000}{\sqrt6}=-6{,}124,\\ (s'_V)^2&=9\tfrac{23{,}000^2}{2}+1\tfrac{15{,}000^2}{6}\\ &=(2{,}380.5+37.5)\times10^6,\\ s'_V&=\sqrt{2{,}418\times10^6}\approx49{,}173. \end{aligned} \]

ความไวต่อ level เป็นศูนย์ตามที่ต้องการ แต่การ short พันธบัตร 2 ปีก็ไปเปลี่ยนความไวต่อทิศอื่นด้วย ความไวต่อ slope โตจาก 4,950 เป็น 16,263 และความไวต่อ curvature เปลี่ยนจาก 408 เป็น −6,124 ความเสี่ยงรวมจึงลดลงแค่ $1-49{,}173/84{,}455\approx42\%$ เหลือ \$49,173 ต่อวัน และเกือบทั้งหมดอยู่ในทิศ slope ที่มี eigenvalue แค่ 9 จาก 91

บทเรียนคือ ความเสี่ยงของพอร์ตในแต่ละทิศคือ variance ของทิศนั้นคูณความไวกำลังสอง ไม่ใช่ variance อย่างเดียว ทิศที่ variance เล็กก็สร้างความเสี่ยงใหญ่ได้ ถ้าพอร์ตไวต่อมันมาก

อีกเรื่องหนึ่ง hedge ที่ตัด level ทิ้งหมดก็ไม่ใช่ hedge ที่เสี่ยงน้อยที่สุด ถ้าเลือกจำนวน $h$ ที่เพิ่มเข้าไปที่ 2 ปีให้ variance ของพอร์ตต่ำสุดโดยตรง ให้หาอนุพันธ์ของ variance $(d+he_1)^{\mathsf T}\Sigma(d+he_1)$ เทียบกับ $h$ แล้วตั้งเป็นศูนย์ ($e_1=(1,0,0)$ คือช่องของอายุ 2 ปี):

\[ \begin{aligned} 2(\Sigma d)_1+2h\,\Sigma_{11}&=0,\\ (\Sigma d)_1&=\tfrac{95(2{,}000)+80(5{,}000)+68(9{,}000)}{3}\\ &=\tfrac{1{,}202{,}000}{3},\\ h&=-\frac{(\Sigma d)_1}{\Sigma_{11}}=-\frac{1{,}202{,}000/3}{95/3}\\ &=-12{,}653,\\ s_V^{*2}&=s_V^2-\frac{(\Sigma d)_1^2}{\Sigma_{11}}\\ &=(7{,}132.7-5{,}069.5)\times10^6,\\ s_V^{*}&=\sqrt{2{,}063.2\times10^6}\approx45{,}422. \end{aligned} \]

$(\Sigma d)_1$ คือแถวแรกของ $\Sigma$ คูณกับ $d$ และ $\Sigma_{11}=95/3$ คือ variance ของอายุ 2 ปี แถว $s_V^{*2}$ ได้จากการแทน $h$ กลับเข้าไปใน variance $s_V^2+2h(\Sigma d)_1+h^2\Sigma_{11}$ hedge แบบนี้ short น้อยกว่า (12,653 แทน 16,000) และเหลือความเสี่ยง \$45,422 ต่อวัน ซึ่งต่ำกว่า \$49,173 เพราะมันยอมเหลือ level ไว้นิดหนึ่ง เพื่อไม่ให้ความไวต่อ slope โตมากเกินไป

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

อ่าน loading เป็นสัดส่วนเงิน: loading บอกว่าแต่ละอายุขยับมากน้อยแค่ไหนเมื่อเดินตามทิศนั้น ไม่ได้บอกว่าต้องลงเงินเท่าไร ตัวอย่างเช่น loading ของทิศแรกที่ 2 ปีกับ 10 ปีเกือบเท่ากัน (0.3494 กับ 0.3632) คนที่อ่านผิดจะถือสองอายุด้วยเงินเท่ากัน คือ long 10 ปี \$100 ล้าน และ short 2 ปี \$100 ล้าน ($N=1$) แต่ DV01 ของเงินก้อนเดียวกันต่างกัน $85{,}000/19{,}500=4.36$ เท่า ขา 10 ปีจึงแกว่งเป็นเงินมากกว่าขา 2 ปีหลายเท่า ทางที่ถูกคือแปลงผ่าน DV01 แบบขั้นที่ 7 ได้ $N=4.5307$ หรือ short \$453.1 ล้าน

ลืมคูณความผันผวนกลับ: คะแนนจาก PCA ของ correlation วัดในหน่วยของตัวแปรที่หารด้วยความผันผวนแล้ว ถ้าอายุ 10 ปีแกว่งวันละ 7 bp แต่อายุ 2 ปีแกว่ง 6 bp คำตอบผิดคือ $N=4.5307$ หรือ \$453.1 ล้าน คำตอบถูกคือ $N=4.5307\times7/6=5.2858$ หรือ \$528.6 ล้าน

ทิ้งทิศเล็กหลัง hedge: รายงานที่แสดงแค่ทิศ level จะบอกว่าพอร์ตที่ตัด level แล้วเสี่ยง $s'_V=0$ แต่ความเสี่ยงจริงคือ $s'_V=\sqrt{9(16{,}263)^2+1(6{,}124)^2}\approx\$49{,}173$ ต่อวัน

เชื่อ eigenvector ของทิศที่ eigenvalue ใกล้กัน: ถ้าสองทิศมี eigenvalue เท่ากันพอดี ทิศใดก็ได้ในระนาบของสองทิศนั้นเป็น eigenvector ทั้งหมด เมื่อ eigenvalue แค่ใกล้กัน ข้อมูลเพิ่มไม่กี่วันก็หมุนสองทิศไปได้มาก เช่นทิศที่ 6 กับ 7 ของแปดอายุ (0.043 กับ 0.034) รายงานความเสี่ยงรายทิศจึงกระโดดไปมา ทั้งที่พอร์ตไม่ได้เปลี่ยนเลย

ใช้ loading เก่าในวันที่ตลาดเปลี่ยนนิสัย: เช่นช่วงที่ธนาคารกลางตรึง yield อายุสั้นไว้ใกล้ศูนย์ แต่ yield อายุยาวยังแกว่ง correlation เปลี่ยนกะทันหัน loading ทั้งชุดจึงล้าสมัยพร้อมกัน ทางแก้คือคำนวณใหม่บนช่วงข้อมูลล่าสุดที่เลื่อนไปเรื่อย ๆ แล้วดูว่าทิศยังนิ่งไหม

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะพันธบัตรรายงานความเสี่ยงเป็นความไวต่อสามทิศ แทนที่จะเป็นความไวต่อแปดอายุ เพราะสามตัวเลขอ่านง่ายกว่าและไม่ปนกัน แต่ละทิศมีเพดานของตัวเอง เทรดเดอร์ยังใช้ทิศเหล่านี้สร้างเดิมพันเฉพาะเรื่อง เช่นเดิมพันความชันด้วยสองขาที่ตัด level ทิ้งแบบขั้นที่ 7 หรือเดิมพันท้องเส้นด้วยสามขาที่ตัดทั้ง level และ slope ทิ้ง

ฝ่ายบริหารความเสี่ยงใช้ทิศเดียวกันทำ stress test คือถามว่าพอร์ตเสียเท่าไรในวันที่แย่ผิดปกติ เช่นวันที่คะแนน level ขยับสามเท่าของความผันผวนรายวัน

ฝั่งหุ้นก็ใช้ PCA เช่นกัน แบบจำลองปัจจัยเชิงสถิติหาทั้ง loading และผลตอบแทนของแต่ละปัจจัยจากข้อมูลผลตอบแทนอย่างเดียว ไม่ต้องใช้ข้อมูลงบการเงินของบริษัท จึงเหมาะกับตลาดที่ไม่มีข้อมูลแบบนั้น หรือกับข้อมูลรายนาที สุดท้าย การเก็บแค่ไม่กี่ทิศยังช่วยลดจำนวนตัวแปรก่อนสร้างสถานการณ์สุ่มด้วย Monte Carlo

โจทย์ตรวจความเข้าใจ

1. โต๊ะดูแค่สองอายุ คือ 2 ปีกับ 10 ปี การขยับรายวันของสองอายุนี้มี correlation 0.8 ถ้าทำ PCA บน correlation matrix $R=\begin{bmatrix}1&0.8\\0.8&1\end{bmatrix}$ จะได้ eigenvalue เท่าไร ทิศแรกเก็บ variance ไว้กี่ % และ eigenvector หน้าตาเป็นอย่างไร

เฉลย

$R$ สมมาตรเมื่อสลับสองอายุ จึงลองทิศ $(1,1)$ และ $(1,-1)$ แบบเดียวกับขั้นที่ 1:

\[\begin{aligned}R(1,1)&=(1+0.8,\ 0.8+1)=1.8\,(1,1),\\R(1,-1)&=(1-0.8,\ 0.8-1)=0.2\,(1,-1).\end{aligned}\]

จึงได้ $\lambda_1=1.8$ และ $\lambda_2=0.2$ ผลบวก $1.8+0.2=2$ เท่ากับ trace ถูกต้อง ทิศแรกเก็บ variance ไว้ $1.8/2=90\%$ eigenvector ยาวหนึ่งหน่วยคือ $\tfrac{1}{\sqrt2}(1,1)$ (level) และ $\tfrac1{\sqrt2}(1,-1)$ (slope)

เทียบกับรูปกลุ่มจุดซึ่งใช้ covariance (ความผันผวน 6 และ 7 bp) ทิศแรกได้ 90.3% และเอียง 50 องศา ไม่ใช่ 45 องศา เพราะ covariance ให้อายุ 10 ปีที่แกว่งมากกว่ามีเสียงดังกว่า ลูกศรจึงเอนไปทางแกนตั้ง

2. ใน hedge ของขั้นที่ 7 (ความผันผวนสองอายุเท่ากัน) สมมติว่าประมาณ loading ของทิศแรกที่ 2 ปีจากข้อมูลอีกชุด ได้ 0.33 แทน 0.3494 ส่วนตัวเลขอื่นเหมือนเดิม ต้อง short พันธบัตร 2 ปีเท่าไร และต่างจากเดิมเท่าไร

เฉลย

เศษ $85{,}000\times0.363179=30{,}870$ ไม่เปลี่ยน (ใช้ loading ที่ไม่ปัดเหมือนขั้นที่ 7) เปลี่ยนแค่ส่วน:

\[\begin{aligned}N&=\frac{30{,}870}{19{,}500\times0.33}=\frac{30{,}870}{6{,}435}\\&=4.7972.\end{aligned}\]

ต้อง short $4.7972\times\$100$ ล้าน $=\$479.7$ ล้าน มากกว่าเดิม $479.7-453.1=\$26.6$ ล้าน loading ต่างกันแค่ราว 0.02 แต่ hedge เปลี่ยนเกือบ 6% ความแม่นของ loading จึงสำคัญพอ ๆ กับ DV01

3. ใช้ covariance ของตัวอย่างที่สอง (อายุ 2, 5 และ 10 ปี) เทรดเดอร์อีกคนถือพอร์ตที่มี DV01 $d=(3{,}000,\ -6{,}000,\ 3{,}000)$ ดอลลาร์ต่อ bp คือถือสองปลายและ short ตรงกลาง พอร์ตนี้ไวต่อแต่ละทิศเท่าไร และความผันผวนรายวันของกำไรขาดทุนเป็นเท่าไร

เฉลย
\[\begin{aligned}d^{\mathsf T}q_1&=\tfrac{3{,}000-6{,}000+3{,}000}{\sqrt3}=0,\\d^{\mathsf T}q_2&=\tfrac{-3{,}000+3{,}000}{\sqrt2}=0,\\d^{\mathsf T}q_3&=\tfrac{3{,}000+12{,}000+3{,}000}{\sqrt6}\\&=\tfrac{18{,}000}{\sqrt6}=7{,}348,\\s_V&=\sqrt{1\times7{,}348^2}=\$7{,}348.\end{aligned}\]

// Eigenvalues and unit eigenvectors of a symmetric matrix by Jacobi rotations, largest first
function eigenSym(S) {
  const n = S.length, A = S.map(r => [...r]), V = S.map((r, i) => r.map((_, j) => (i === j ? 1 : 0)));
  for (let sweep = 0; sweep < 100; sweep++) {
    let off = 0;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) off += A[p][q] ** 2;
    if (off < 1e-30) break;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) {
      if (Math.abs(A[p][q]) < 1e-300) continue;
      const theta = (A[q][q] - A[p][p]) / (2 * A[p][q]);
      const t = Math.sign(theta || 1) / (Math.abs(theta) + Math.sqrt(theta * theta + 1));
      const c = 1 / Math.sqrt(t * t + 1), s = t * c;
      for (let k = 0; k < n; k++) { const a = A[k][p], b = A[k][q]; A[k][p] = c * a - s * b; A[k][q] = s * a + c * b; }
      for (let k = 0; k < n; k++) { const a = A[p][k], b = A[q][k]; A[p][k] = c * a - s * b; A[q][k] = s * a + c * b; }
      for (let k = 0; k < n; k++) { const a = V[k][p], b = V[k][q]; V[k][p] = c * a - s * b; V[k][q] = s * a + c * b; }
    }
  }
  const order = [...Array(n).keys()].sort((a, b) => A[b][b] - A[a][a]);
  return order.map(k => {
    const v = V.map(r => r[k]), sign = v[0] < 0 ? -1 : 1;   // eigenvectors are defined up to sign
    return {value: A[k][k], vector: v.map(x => sign * x)};
  });
}
const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);

สิ่งที่ควรตอบได้หลังอ่าน

  • ทิศยาวหนึ่งหน่วยที่ข้อมูลแกว่งมากที่สุดคือ eigenvector ของ covariance (หรือ correlation) และ variance ในทิศนั้นคือ eigenvalue ของมัน เหตุผลคือ Lagrangian ของปัญหา “variance มากสุดเมื่อความยาวเป็นหนึ่ง” ให้ $Rq=\lambda q$ พอดี
  • สัดส่วนที่ทิศหนึ่งเก็บไว้คือ eigenvalue หารด้วยผลบวกของ eigenvalue ทั้งหมด สามอายุที่คิดด้วยมือได้ 90.06, 8.33 และ 1.60% แปดอายุได้ 85.6, 8.3 และ 2.6%
  • สามทิศแรกของเส้น yield มีชื่อ level, slope และ curvature อ่านได้จากจำนวนครั้งที่เครื่องหมายของ loading สลับ คือ 0, 1 และ 2 ครั้ง
  • เก็บกี่ทิศให้ดูจาก scree plot และขอบของเสียงสุ่ม $(1+\sqrt{n/T})^2$ ถ้าลังเลให้เก็บมากไว้ก่อน
  • inverse กลับ eigenvalue เป็น $1/\lambda$ ในสามอายุ ทิศ curvature จึงถูกขยายมากกว่าทิศ level 56 เท่า นี่คือเหตุที่ optimizer ไวต่อทิศที่ข้อมูลบอกได้น้อย
  • loading ไม่ใช่สัดส่วนเงิน hedge ทิศแรกต้องแปลงผ่าน DV01 และคูณความผันผวนกลับ (\$453.1 ล้าน หรือ \$528.6 ล้าน ไม่ใช่ \$100 ล้าน)
  • variance ของทิศเล็กไม่ได้แปลว่าความเสี่ยงเล็ก หลังตัด level ความเสี่ยงของพอร์ตตัวอย่างลดจาก \$84,455 เหลือ \$49,173 ต่อวันเท่านั้น และไปกองอยู่ในทิศ slope

หน้าถัดไป Monte Carlo และ bootstrap ใช้ covariance และทิศเหล่านี้สร้างสถานการณ์สุ่มจำนวนมาก แล้วถามสองเรื่อง คำตอบที่ได้จากการสุ่มแม่นแค่ไหน และถ้ามีข้อมูลอยู่ชุดเดียว จะรู้ได้อย่างไรว่าตัวเลขที่ประมาณจากมันคลาดได้มากแค่ไหน
