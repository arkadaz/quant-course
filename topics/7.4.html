7.4 Linear Functions and Linear Constraints

แยกกติกาคำนวณออกจากข้อบังคับ แล้วตรวจว่ามีคำตอบก่อนถามว่าคำตอบไหนดีที่สุด

โต๊ะเทรดมีวงเงินภายใน 10 ล้าน USD และคิดการใช้วงเงินของแผนสองขาด้วย $f(x)=x_1+2x_2$ แผน $(4,2)$ ใช้ไป 8 จึงดูเหมือนขยายได้ $10/8=1.25$ เท่า

แต่ถ้าต้องกันวงเงินคงที่อีก 1 ล้าน USD ไว้สำหรับงานอื่น ไม่ว่าแผนนี้จะใหญ่เท่าไร ยังขยายได้ 1.25 เท่าหรือไม่?

ดูคำตอบ

ไม่ได้ การใช้วงเงินรวมเป็น $1+f(x)$ ที่สเกล 1.25 จะใช้ $1+8(1.25)=11$ ล้าน USD ขยายได้จริงเพียง $(10-1)/8=1.125$ เท่า เพราะส่วนคงที่ไม่ได้ขยายตามแผน ความต่างระหว่าง linear กับ affine จึงเปลี่ยนคำตอบที่ใช้ตัดสินใจได้

ในตัวอย่างนี้ $x_1,x_2$ เป็นขนาดขา hedge ที่ไม่ติดลบ วัดเป็นล้าน USD ทิศซื้อหรือขายของแต่ละขาถูกกำหนดไว้แล้ว สัมประสิทธิ์ 1 และ 2 เป็นกติกาวงเงินสมมติ ไม่ใช่สูตร variance หรือหลักฐานว่า hedge จะลดความเสี่ยงจริง

1. Linear ไม่ได้หมายถึงเพียง “กราฟเป็นเส้นตรง”

นิยามกติกาคำนวณบน $\mathbb R^n$ ก่อน แล้วค่อยจำกัดแผนที่อนุญาต เช่น $x_i\ge0$ แยกต่างหาก ฟังก์ชัน $f$ เป็น linear เมื่อการรวม input และการคูณด้วยสเกลส่งผ่านได้ สำหรับทุก $u,v$ และทุกสเกลจริง $\alpha,\beta$:

\[ f(\alpha u+\beta v)=\alpha f(u)+\beta f(v). \]

สำหรับ $f(x)=a^{\mathsf T}x$ ใช้การกระจายผลคูณพิสูจน์ได้โดยตรง:

\[ \begin{aligned} f(\alpha u+\beta v) &=\sum_i a_i(\alpha u_i+\beta v_i)\\ &=\alpha\sum_i a_iu_i+\beta\sum_i a_iv_i\\ &=\alpha f(u)+\beta f(v). \end{aligned} \]

จึงมีทั้ง $f(u+v)=f(u)+f(v)$ และ $f(su)=sf(u)$ โดยเฉพาะ $f(0)=0$ ส่วน $g(x)=c+a^{\mathsf T}x$ เรียกว่า affine: มีส่วน linear บวกค่าคงที่ เมื่อ $c\ne0$ จะไม่เป็น linear เพราะ $g(0)=c\ne0$

ในโจทย์เปิด $g(sx)=1+s f(x)$ แต่ $s g(x)=s+s f(x)$ ต่างกันเมื่อ $s\ne1$ อย่างไรก็ตาม affine ยังรักษาการผสมแบบน้ำหนักรวมหนึ่งไว้ จึงใช้แค่ midpoint test แยก linear ออกจาก affine ไม่ได้

ตรวจด้วยตัวเลขเดิม และดูว่าตัวอย่างที่ผ่านหนึ่งคู่ยังไม่ใช่ข้อพิสูจน์

ให้ $u=(4,2)$ และ $v=(8,3)$ จะมี $f(u)=8$, $f(v)=14$ และจุดกึ่งกลาง $(6,2.5)$ ให้ $f=11=(8+14)/2$ แต่ $q(x)=x_1^2$ ให้ $q((u+v)/2)=36$ ขณะที่ $(q(u)+q(v))/2=(16+64)/2=40$ จึงไม่เป็น linear

ตัวอย่างที่ไม่เท่ากันเพียงคู่เดียวหักล้างความเป็น linear ได้ แต่คู่ที่เท่ากันเพียงคู่เดียวยืนยันไม่ได้ ต้องมีเหตุผลที่ใช้ได้กับทุก input เช่นการกระจายผลคูณด้านบน และจุด $v$ ในการทดสอบนี้ไม่ได้ผ่านวงเงิน 10 ด้วย

2. หนึ่งแถวคือหนึ่งกติกา หลายแถวคือหลาย output

Matrix–vector multiplication จาก 7.3 เป็น linear map เพราะแต่ละแถวเป็น weighted sum ตัวอย่างที่มี input สามช่อง:

\[ \begin{aligned} M&=\begin{bmatrix}2&3&4\\1&0&2\end{bmatrix},\qquad z=\begin{bmatrix}1\\1\\1\end{bmatrix},\\ Mz&=\begin{bmatrix}2+3+4\\1+0+2\end{bmatrix} =\begin{bmatrix}9\\3\end{bmatrix}. \end{aligned} \]

ในทางกลับกัน ถ้า $L$ เป็น linear map เราเขียน $x=\sum_jx_je_j$ ด้วย basis มาตรฐานได้ จึงมี $L(x)=\sum_jx_jL(e_j)$ วาง $L(e_j)$ เป็นคอลัมน์ที่ $j$ ของ matrix ก็ได้ $L(x)=Mx$ แต่ทุกช่องยังต้องมีชื่อและหน่วยที่ชัดเจน ไม่ใช่รวมตัวเลขเพียงเพราะขนาดพอดีกัน

ฟังก์ชัน ให้ค่าที่คำนวณออกมา ส่วน constraint บอกว่าค่านั้นยอมรับได้หรือไม่ เช่น $a^{\mathsf T}x\le b$ กำหนดเพดาน และ $a^{\mathsf T}x=b$ กำหนดเป้าหมายที่ต้องตรง ทั้งสองเรียกว่า linear constraints แม้ค่าด้านขวาจะไม่เป็นศูนย์

รวมข้อจำกัดได้เป็น $Gx\le h$ และ $Ex=d$ โดยอสมการต้องผ่านทุกแถว ต่อไปใช้กรณีที่ยังไม่กันวงเงินคงที่ 1 ล้าน USD: แผนสองขาต้องผ่านสามข้อ:

\[ \begin{aligned} x_1+2x_2&\le10,\qquad x_1\ge0,\quad x_2\ge0,\\ G&=\begin{bmatrix}1&2\\-1&0\\0&-1\end{bmatrix},\qquad h=\begin{bmatrix}10\\0\\0\end{bmatrix},\\ Gx&\le h. \end{aligned} \]

แถวสองคือ $-x_1\le0$ และแถวสามคือ $-x_2\le0$ เครื่องหมายลบมีหน้าที่เปลี่ยนทุกข้อให้อยู่ในรูปเดียวกัน หากลืมสองแถวนี้ จะยอมให้ขนาดขาติดลบมาหักวงเงิน ซึ่งเป็นคนละโมเดลกับที่ตั้งไว้

3. ตรวจ slack ก่อนส่งแผนไปหา optimum

สำหรับแถว $a^{\mathsf T}x\le b$ นิยาม slack เป็น $b-a^{\mathsf T}x$ ค่าบวกคือยังเหลือวงเงิน ศูนย์คือชนข้อจำกัด และค่าลบคือเกินเพดาน:

\[ \begin{aligned} x=(4,2):\quad f(x)&=4+2(2)=8,\quad 10-f(x)=2,\\ x=(8,3):\quad f(x)&=8+2(3)=14,\quad 10-f(x)=-4. \end{aligned} \]

Slack ของกฎทั้งสามสำหรับ $(4,2)$ เป็น $(2,4,2)^{\mathsf T}$ จึงผ่านทุกข้อ แต่ $(8,3)$ ให้ $(-4,8,3)^{\mathsf T}$ แม้สองขาจะไม่ติดลบก็ยังไม่ผ่านวงเงิน การรวม slacks ทุกแถวเป็นยอดเดียวแล้วดูว่าบวกหรือไม่จะซ่อนข้อที่ละเมิดไว้

ถ้าขยายแผนเดิมตามแนว $sx$ โดย $s\ge0$ การใช้วงเงินที่ไม่มีส่วนคงที่เป็น $f(sx)=sf(x)$ จึงหาเพดานตามแนวนั้นได้:

\[ \begin{aligned} x&=(4,2),\qquad sx=(4s,2s),\\ f(sx)&=4s+2(2s)=8s,\\ 8s\le10&\ \Longrightarrow\ 0\le s\le1.25,\\ s=1.25&\ \Longrightarrow\ sx=(5,2.5). \end{aligned} \]

ขีดจำกัด 1.25 นี้มาจากกฎชุดที่เขียนไว้เท่านั้น หากเพิ่มเพดาน $x_1\le4.5$ จะต้องมี $4s\le4.5$ ด้วย จึงขยายได้เพียง $\min(1.25,1.125)=1.125$ เท่า แม้ยังเหลือวงเงินรวมก็ตาม

4. เวกเตอร์ normal บอกทิศ แต่ slack ไม่ใช่ระยะโดยตรง

สำหรับ $a\ne0$ สมการ $a^{\mathsf T}x=b$ เป็นเส้นในสองมิติ หรือ hyperplane ในมิติที่สูงกว่า ถ้าเคลื่อนตาม $d$ โดยยังอยู่บนเส้นเดิม ต้องมี $a^{\mathsf T}d=0$ ดังนั้น $a$ ตั้งฉากกับเส้น ไม่ได้ขนานไปตามเส้น

\[ \begin{aligned} a&=(1,2),\qquad d=(2,-1),\\ a^{\mathsf T}d&=1(2)+2(-1)=0,\\ f(x+td)&=f(x)+t\,a^{\mathsf T}d=f(x),\\ f(x+ta)&=f(x)+t\,a^{\mathsf T}a=f(x)+5t. \end{aligned} \]

Slack 2 ของจุด $(4,2)$ มีหน่วยเป็นวงเงินล้าน USD ถ้าถามถึงระยะ Euclidean ในพิกัด $(x_1,x_2)$ ต้องหารด้วยความยาว normal อีกขั้น จาก 6.5 การเคลื่อนที่สั้นที่สุดไปยังเส้นเป็นการเคลื่อนตาม normal:

\[ \begin{aligned} x_*&=x+ta,\qquad a^{\mathsf T}x_*=b,\\ t&=\frac{b-a^{\mathsf T}x}{a^{\mathsf T}a}=\frac25,\\ x_*&=(4,2)+\frac25(1,2)=(4.4,2.8),\\ \|x_*-x\|_2&=\frac{|b-a^{\mathsf T}x|}{\|a\|_2} =\frac2{\sqrt5}\approx0.894427. \end{aligned} \]

นี่คือระยะถึงเส้นวงเงินใน metric ที่เลือก ไม่ใช่ต้นทุนซื้อขาย และไม่ใช่ระยะถึงทุกขอบของ feasible region โดยทั่วไป ส่วนการขยายแผนตามแนวเดิมไป $(5,2.5)$ เป็นอีกคำถามหนึ่ง ไม่ใช่การหาจุดที่ใกล้ที่สุด

ถ้า $a=0$ จะไม่มี normal direction ที่ใช้ได้: กฎ $0\le b$ ยอมรับทุกจุดเมื่อ $b\ge0$ และไม่ยอมรับจุดใดเมื่อ $b\lt0$ การเขียนหนึ่งแถวจึงไม่ได้สร้างเส้นแบ่งที่แท้จริงเสมอไป

5. Hedge ภาระจ่าย: ต้องผ่านแต่ละสถานะ ไม่ใช่แค่ยอดเฉลี่ย

เปลี่ยนหน่วยสำหรับตัวอย่างนี้: ทุก payoff และภาระจ่ายวัดเป็น USD ณ วันเดียวกัน ไม่ใช่ล้าน USD ให้ $S$ มีแถวเป็นสามสถานะที่โมเดลกำหนด และคอลัมน์เป็น payoff ต่อหนึ่งหน่วยหุ้นกับพันธบัตร

\[ S=\begin{bmatrix}120&105\\100&105\\70&105\end{bmatrix},\qquad X=\begin{bmatrix}110\\100\\80\end{bmatrix}. \]

ถ้าถือจำนวนหน่วย $\theta=(0.5,0.5)^{\mathsf T}$ เงื่อนไขการครอบคลุมภาระจ่ายคือ $S\theta\ge X$ ทุกแถว หรือเขียนให้อยู่ในรูปมาตรฐานเดียวกันเป็น $-S\theta\le-X$:

\[ \begin{aligned} S\theta &=\begin{bmatrix}120(0.5)+105(0.5)\\100(0.5)+105(0.5)\\70(0.5)+105(0.5)\end{bmatrix} =\begin{bmatrix}112.5\\102.5\\87.5\end{bmatrix},\\ S\theta-X&=\begin{bmatrix}2.5\\2.5\\7.5\end{bmatrix}\ge0. \end{aligned} \]

นี่เป็น superhedge สำหรับสามสถานะที่ระบุ ไม่ใช่ exact replication เพราะ payoff ยังมีส่วนเกิน และ $\theta$ เป็นจำนวนหน่วย ไม่ใช่น้ำหนักเงินโดยนิยาม ส่วนเกินเป็นเงิน ณ วันจ่ายในสถานะนั้น ไม่ใช่เงินสดสำรองที่มีอยู่ตั้งแต่วันนี้

การผ่านเงื่อนไขนี้ไม่ยืนยันว่าครบทุกสถานะในโลกจริง หากเพิ่มสถานะที่ payoff หุ้นเหลือ 40 และพันธบัตรยังจ่าย 105 ขณะที่ต้องจ่าย 80 พอร์ตเดิมได้เงิน $40(0.5)+105(0.5)=72.5$ จึงขาด 7.5 USD

ผ่านกฎแล้ว เหตุใดยังต้องมี objective?

สมมติราคาวันนี้เป็น 100 USD ต่อหน่วยทั้งสองสินทรัพย์ ต้นทุนพอร์ตเดิมคือ $100(0.5)+100(0.5)=100$ USD แต่ถือ $\theta=(0.5,10/21)$ จะได้เงิน $(110,100,85)$ ในสามสถานะเดิม จึงยังผ่าน และมีต้นทุน $100(0.5+10/21)\approx97.619$ USD เท่านั้น

เพียงพบแผนที่ถูกกว่าก็แสดงแล้วว่า “ผ่านกฎ” กับ “ต้นทุนต่ำที่สุด” เป็นคนละคำถาม ถ้าต้องการหาแผนต้นทุนต่ำสุด ต้องระบุ objective $p^{\mathsf T}\theta$ พร้อมข้อจำกัดทั้งหมด เช่นห้าม short, จำนวน lot และวงเงิน ไม่ใช่ตรวจ $S\theta\ge X$ แล้วจบ

6. ทำไมผสมแผนที่ผ่านกฎแล้วจึงยังผ่าน?

ถ้า $u,v$ ผ่าน $Gx\le h$ ทั้งคู่ และ $0\le t\le1$ จะได้:

\[ \begin{aligned} G(tu+(1-t)v)&=tGu+(1-t)Gv\\ &\le th+(1-t)h=h. \end{aligned} \]

Equalities $Ex=d$ ก็ยังตรง เพราะ $tEu+(1-t)Ev=td+(1-t)d=d$ นี่คือเหตุผลที่ feasible set ของ linear equalities/inequalities เป็น convex: ส่วนผสมบนเส้นระหว่างสองจุดที่ผ่านยังผ่าน

เช่น $(4,2)$ ใช้วงเงิน 8 และ $(2,4)$ ใช้ 10 จุดกึ่งกลาง $(3,3)$ ใช้ 9 จึงยังผ่าน แต่เหตุผลนี้ใช้ไม่ได้ถ้าหนึ่งในสองจุดไม่ผ่านกฎตั้งแต่ต้น

ข้อจำกัดสิ่งที่เหลือ
$x_1,x_2\ge0$, $x_1+2x_2\le10$สามเหลี่ยมที่ไม่ว่างและมีขอบเขต
$x_1\ge2$ และ $x_1\le1$เซตว่าง ไม่มีแผนที่ผ่าน
$x_1\ge0$ เพียงข้อเดียวครึ่งระนาบที่ขยายได้ไม่สิ้นสุด
$x_1=0$, $0\le x_2\le5$ส่วนของเส้น ไม่ใช่พื้นที่สองมิติ

ดังนั้น intersection ของ half-spaces ไม่จำเป็นต้องเป็นรูปหลายเหลี่ยมที่มีพื้นที่และมีขอบเขตเสมอไป หากกฎขัดแย้งกันต้องรายงาน infeasible ไม่ใช่ให้โปรแกรมผ่อนข้อที่สำคัญเองโดยไม่ได้รับอนุญาต

7. เมื่อไรจึงตรวจแค่จุดมุมได้?

สำหรับสามเหลี่ยมของเรา มีจุดมุม $v_0=(0,0)$, $v_1=(10,0)$ และ $v_2=(0,5)$ ทุกจุด $x$ ที่ผ่านกฎเขียนเป็นส่วนผสมของจุดมุมได้ โดยเลือก:

\[ \begin{aligned} \lambda_1&=x_1/10,\qquad\lambda_2=x_2/5,\\ \lambda_0&=1-x_1/10-x_2/5\ge0,\\ \lambda_0+\lambda_1+\lambda_2&=1,\qquad x=\sum_{k=0}^{2}\lambda_kv_k,\\ c^{\mathsf T}x&=\sum_{k=0}^{2}\lambda_kc^{\mathsf T}v_k\\ &\le\left(\max_k c^{\mathsf T}v_k\right)\sum_{k=0}^{2}\lambda_k\\ &=\max_k c^{\mathsf T}v_k. \end{aligned} \]

จึงไม่มีจุดข้างในให้ linear objective สูงกว่ามุมที่ดีที่สุดได้ เป็นข้อพิสูจน์จากโครงสร้างของบริเวณนี้ ไม่ใช่คำสรุปว่า “convex ทุกแบบตรวจแค่มุมได้” เช่นบริเวณไม่จำกัดอาจไม่มีค่าสูงสุดเลย

จุดมุม$f=x_1+2x_2$$q=3x_1+2x_2$
(0,0)00
(10,0)1030
(0,5)1010

ถ้า maximize $f$ มุมสองมุมผูกกัน และทุกจุดบนเส้น $x_1+2x_2=10$ ภายในสามเหลี่ยมก็ได้ 10 เหมือนกัน จึงไม่ใช่ว่าคำตอบที่ดีที่สุดต้องเป็นจุดมุมเท่านั้น ต้องมีเป้าหมายรองหากต้องการเลือกแผนเดียว

แต่ถ้า maximize คะแนนสมมติ $q=3x_1+2x_2$ จะได้ 30 ที่ $(10,0)$ เพียงจุดเดียว ตรวจได้อีกทางโดยไม่ใช้ solver:

\[ \begin{aligned} q(x)&=3(x_1+2x_2)-4x_2\\ &\le30-4x_2\le30. \end{aligned} \]

จะเท่ากับ 30 ต้องมีทั้ง $x_2=0$ และใช้วงเงินเต็ม 10 เท่านั้น คะแนนนี้เป็น objective ที่โจทย์กำหนด ไม่ใช่การรับรองผลกำไรจากตลาด และการชนวงเงินตามแนวเดิมที่ $(5,2.5)$ ให้คะแนนเพียง 20 จึงยังไม่ optimal

ใน LP หลายมิติ หลักการเลือก optimal vertex ต้องใช้ภายใต้เงื่อนไขที่เหมาะสม ไม่ใช่ไล่ทุกมุมโดยไม่ตรวจความเป็นไปได้หรือความไม่มีขอบเขต โค้ดด้านล่างตรวจเฉพาะสามเหลี่ยมที่พิสูจน์แล้ว ไม่ได้แทน general-purpose LP solver

8. อย่าเรียกกฎทุกอย่างว่า linear เพียงเพื่อให้ใช้ solver เดิมได้

ข้อจำกัดด้าน variance, market impact และจำนวน lot อาจไม่ใช่ linear constraints ในตัวแปรเดิม ต้องแยกกรณีที่แปลงรูปได้ตรงตัว ออกจากกรณีที่ต้องเปลี่ยน solver หรือยอมใช้ approximation พร้อมระบุขอบเขต

ตัวอย่างแปลงได้ตรงตัว: เพดาน gross exposure

สำหรับ signed weights เงื่อนไข $\sum_i|w_i|\le L$ เขียนใหม่ด้วยตัวแปรช่วย $t_i$ เป็น $t_i\ge w_i$, $t_i\ge-w_i$ และ $\sum_i t_i\le L$ ทุกข้อเป็น linear

สองข้อแรกบังคับ $t_i\ge|w_i|$ จึงทำให้เพดาน gross จริงไม่เกิน $L$ และถ้า weights ผ่านกฎเดิม ก็เลือก $t_i=|w_i|$ ได้เสมอ นี่จึงเป็น reformulation ที่เทียบเท่ากันสำหรับเพดานนี้ ไม่ใช่การแทน absolute value ด้วย net sum

การบังคับซื้อขายเป็นจำนวนเต็มต่างออกไป: สองแผนที่เป็นจำนวนเต็มอาจมีจุดกึ่งกลางไม่เป็นจำนวนเต็ม จึงนำข้อพิสูจน์ convexity ของปัญหาแบบแบ่งเศษได้มาใช้ตรง ๆ ไม่ได้ ส่วน quadratic constraints บางชนิดยัง convex เช่นเพดาน variance ที่ covariance เป็น positive semidefinite แต่ไม่ได้กลายเป็น linear เพียงเพราะ convex

สุดท้ายผลตรวจผ่านหมายถึงผ่านกฎที่เขียนไว้พร้อมสมมติฐานเท่านั้น ต้องตรวจหน่วย วันที่ scenario coverage และการปัดจำนวนซื้อขายด้วย การผ่อนกฎเพื่อให้พบคำตอบเป็นการเปลี่ยนโจทย์ ต้องตัดสินใจอย่างเปิดเผย

function finiteVector(v, n) {
  if (!Array.isArray(v) || !v.length || (n !== undefined && v.length !== n) || ![...v].every(Number.isFinite)) {
    throw new TypeError('Need a nonempty finite vector of matching length');
  }
  return v;
}
function dot(a, b) {
  finiteVector(a); finiteVector(b, a.length);
  const value = a.reduce((sum, x, i) => sum + x * b[i], 0);
  if (!Number.isFinite(value)) throw new RangeError('Dot product overflow');
  return value;
}
function matvec(M, v) {
  if (!Array.isArray(M) || !M.length) throw new TypeError('Need matrix rows');
  return [...M].map(row => dot(row, v));
}
function evaluate(G, h, x) {
  const lhs = matvec(G, x);
  finiteVector(h, lhs.length);
  const slack = h.map((limit, i) => limit - lhs[i]);
  if (!slack.every(Number.isFinite)) throw new RangeError('Slack calculation overflow');
  return {lhs, slack, feasible: slack.every(s => s >= 0),
    nearBoundary: slack.some(s => Math.abs(s) < 1e-10)};
}
function budget(x) { finiteVector(x, 2); return dot([1, 2], x); }
function scaleLimit(x, available = 10) {
  finiteVector(x, 2);
  if (x.some(v => v < 0) || !Number.isFinite(available) || available < 0) {
    throw new RangeError('Need nonnegative sizes and available budget');
  }
  const used = budget(x);
  if (used === 0) return Infinity; // Scaling the zero plan leaves it unchanged.
  const scale = available / used;
  if (!Number.isFinite(scale)) throw new RangeError('Scale calculation overflow');
  return scale;
}
const G = [[1, 2], [-1, 0], [0, -1]], h = [10, 0, 0];
function barycentric(x) {
  if (!evaluate(G, h, x).feasible) throw new RangeError('Point is not feasible for the triangle');
  return [1 - x[0] / 10 - x[1] / 5, x[0] / 10, x[1] / 5];
}
const p = [4, 2], q = [8, 3], middle = p.map((x, i) => (x + q[i]) / 2);
const affine = x => 1 + budget(x), square = x => x[0] ** 2;
const a = [1, 2], tangent = [2, -1], projection = p.map((x, i) => x + 2 * a[i] / dot(a, a));
const S = [[120, 105], [100, 105], [70, 105]], X = [110, 100, 80];
const theta = [.5, .5], cheaper = [.5, 10 / 21], prices = [100, 100];
const cover = t => evaluate(S.map(row => row.map(x => -x)), X.map(x => -x), t);
const vertices = [[0, 0], [10, 0], [0, 5]], score = x => dot([3, 2], x);
const ray = p.map(x => x * scaleLimit(p)), reserved = p.map(x => x * scaleLimit(p, 9));
