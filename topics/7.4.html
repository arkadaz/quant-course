7.4 Linear Functions and Linear Constraints

ฟังก์ชัน linear คือคูณแต่ละตัวด้วยน้ำหนักแล้วบวกกัน linear constraint คือกฎที่บอกว่าผลบวกนี้ห้ามเกินตัวเลขหนึ่ง กฎแต่ละข้อขีดเส้นแบ่งระนาบเป็นฝั่งที่ยอมรับกับฝั่งที่ไม่ยอมรับ แผนที่ผ่านทุกข้อจึงรวมกันเป็นรูปหลายเหลี่ยมที่วาดดูได้

โต๊ะเทรด (ทีมที่ซื้อขายในตลาด) กำลังวางแผน hedge คือซื้อสินทรัพย์เก็บไว้ เพื่อชดเชยในกรณีที่ตลาดขยับไปทางที่ทำให้พอร์ตหลักขาดทุน แผนนี้มีสองส่วน เรียกแต่ละส่วนว่า “ขา” ฝ่ายความเสี่ยง (ทีมที่คุมไม่ให้โต๊ะเสี่ยงเกินไป) กำหนด “วงเงิน” ให้โต๊ะไว้ก้อนหนึ่ง โต๊ะใช้เกินนี้ไม่ได้ และฝ่ายความเสี่ยงมีสูตรคิดว่าแผนแต่ละแบบกินวงเงินไปเท่าไร

ของที่รู้:

  • ขนาดขาที่หนึ่ง $x_1$ และขาที่สอง $x_2$ หน่วยเป็นล้านดอลลาร์ ห้ามติดลบ เขียนแผนรวมเป็นคู่ $x=(x_1,x_2)$
  • สูตรคิดวงเงินที่ใช้ $f(x)=x_1+2x_2$ ขาที่สองนับหนักเป็นสองเท่า (ตัวเลขสมมติ เช่นเพราะขานี้เสี่ยงกว่า)
  • เพดานวงเงิน \$10 ล้าน
  • แผนตอนนี้คือ $x=(4,2)$ ใช้วงเงิน $f(4,2)=4+2\times2=8$ คือ \$8 ล้าน

โต๊ะอยากขยายทั้งสองขาด้วยตัวคูณ $s$ ตัวเดียวกัน แผนใหม่คือ $(4s,\ 2s)$ ซึ่งใช้วงเงิน $4s+2(2s)=8s$ จึงดูเหมือนขยายได้จนถึง $8s=10$ คือ $s=10/8=1.25$ เท่า

แต่ฝ่ายความเสี่ยงเพิ่มกฎอีกข้อ: ต้องกันวงเงิน \$1 ล้านไว้ให้งานอื่นเสมอ ไม่ว่าแผนจะใหญ่หรือเล็ก

ถามว่า ยังขยายได้ 1.25 เท่าเหมือนเดิมไหม

ลองตอบก่อนเปิดเฉลย

ไม่ได้ วงเงินที่ใช้ตอนนี้มีสองส่วน ส่วนแรกคือ \$1 ล้านที่กันไว้ ซึ่งไม่ขยายตามแผน ส่วนที่สองคือ $x_1+2x_2$ ซึ่งขยายตามแผน ให้ $g$ คือวงเงินที่ใช้ตามกฎใหม่ แผนที่ขยาย 1.25 เท่าคือ $1.25\times(4,2)=(5,\ 2.5)$

\[\begin{aligned} g(x)&=1+x_1+2x_2,\\ g(5,\,2.5)&=1+5+2\times2.5=11\gt10,\\ 1+8s&=10\ \Rightarrow\ s=\tfrac{10-1}{8}=1.125. \end{aligned}\]

ขยาย 1.25 เท่าจะใช้วงเงิน \$11 ล้าน เกินเพดาน ขยายได้จริงแค่ 1.125 เท่า เพราะ \$1 ล้านที่กันไว้ไม่ขยายตามแผน กฎเดิม $x_1+2x_2$ เรียกว่า linear ส่วนกฎใหม่เรียกว่า affine คือ linear บวกค่าคงที่ และ affine ขยายตามสัดส่วนแบบนี้ไม่ได้

ภาพรวมก่อนลงสูตร

โจทย์แบบใน hook มีของสองชิ้นที่ต้องแยกให้ออก

ชิ้นแรกคือสูตรคิดตัวเลข เช่นวงเงินที่แผนใช้ หรือต้นทุนของแผน สูตรแบบนี้ส่วนใหญ่ทำแค่สองอย่าง คือคูณแต่ละขาด้วยน้ำหนัก แล้วบวกกัน สูตรที่ทำแค่นี้เรียกว่าฟังก์ชัน linear เขียนสั้น ๆ ได้เป็น $a^{\mathsf T}x=a_1x_1+a_2x_2$ โดย $a$ คือ vector ของน้ำหนัก (เรียกว่า vector สัมประสิทธิ์) และ $x$ คือแผน สูตรวงเงินใน hook มี $a=(1,2)$

ชิ้นที่สองคือกฎ เช่นวงเงินห้ามเกิน 10 ขนาดขาห้ามติดลบ หรือเงินที่พอร์ตจ่ายออกมาต้องไม่น้อยกว่าเงินที่เราต้องจ่ายคนอื่น กฎแต่ละข้อเอาฟังก์ชัน linear หนึ่งตัวมาเทียบกับตัวเลขหนึ่งตัว เช่น $x_1+2x_2\le10$ กฎแบบนี้เรียกว่า linear constraint

linear constraint วาดเป็นภาพได้ง่าย สมการ $a^{\mathsf T}x=b$ คือเส้นตรงในระนาบ (ถ้ามีสามขา จะเป็นระนาบในสามมิติ) อสมการ $a^{\mathsf T}x\le b$ คือฝั่งหนึ่งของเส้นนั้น เรียกว่าครึ่งระนาบ แผนที่ผ่านทุกกฎคือส่วนที่ทุกครึ่งระนาบทับกัน ในโจทย์ของ hook ส่วนนั้นเป็นสามเหลี่ยม ดังรูปด้านล่าง

หน้านี้ไล่ทีละเรื่อง เริ่มจากแยก linear ออกจาก affine แล้วดูว่าทิศของ $a$ บอกอะไร จากนั้นตรวจแผนกับกฎทีละข้อด้วยตัวเลขที่เรียกว่า slack แล้วตั้งโจทย์ hedge ที่เงินที่ได้ต้องไม่ต่ำกว่าเงินที่ต้องจ่าย ต่อด้วยเหตุผลว่าทำไมเอาสองแผนที่ผ่านมาผสมกันแล้วยังผ่าน และปิดท้ายด้วยเหตุผลว่าทำไมแผนที่ดีที่สุดมักอยู่ที่มุมของรูปหลายเหลี่ยม เรื่องสุดท้ายนี้คือหัวใจของ linear programming คือการหาค่ามากสุดหรือน้อยสุดของฟังก์ชัน linear ภายใต้ linear constraint หลายข้อ

ศัพท์ที่ใช้ในหัวข้อนี้
Linear function
$f(x)=a^{\mathsf T}x=a_1x_1+\dots+a_nx_n$ คือคูณแต่ละช่องด้วยน้ำหนักแล้วบวกกัน มันมีสมบัติสองข้อ ใส่ผลรวมของสองแผน จะได้ผลรวมของสองคำตอบ และขยายแผน $s$ เท่า คำตอบก็ขยาย $s$ เท่า ผลที่ตามมาคือ $f(0)=0$ เสมอ ใช้เป็นสูตรคิดวงเงิน ต้นทุน หรือ exposure (เงินที่พอร์ตจะได้หรือเสียเมื่อตลาดขยับ)
Affine function
$g(x)=c+a^{\mathsf T}x$ คือ linear บวกค่าคงที่ $c$ ขยายแผนแล้ว $c$ ไม่ขยายตาม ใช้แทนค่าธรรมเนียมคงที่ หรือวงเงินที่กันไว้แบบใน hook
Linear constraint
กฎที่เอาฟังก์ชัน linear หนึ่งตัวมาเทียบกับตัวเลข เช่น $x_1+2x_2\le10$ หรือ $x_1\ge0$
Hyperplane และ half-space
hyperplane คือจุดทั้งหมดที่ $a^{\mathsf T}x=b$ เป็นเส้นตรงในสองมิติ และเป็นระนาบในสามมิติ half-space คือจุดทั้งหมดที่ $a^{\mathsf T}x\le b$ คือฝั่งหนึ่งของ hyperplane นั้น ใช้วาดกฎหนึ่งข้อเป็นภาพ
Feasible region
ชุดของแผนทั้งหมดที่ผ่านทุก constraint พร้อมกัน ใช้ตอบก่อนว่ามีแผนที่ทำได้จริงไหม แล้วค่อยถามว่าแผนไหนดีที่สุด
Slack
ที่ว่างที่เหลือของกฎแต่ละข้อ คือ $b-a^{\mathsf T}x$ ถ้าเป็นบวกแปลว่ายังเหลือ ถ้าเป็นศูนย์แปลว่าชนขอบพอดี ถ้าเป็นลบแปลว่าผิดกฎ ใช้ตรวจแผนทีละข้อ
Normal vector
vector สัมประสิทธิ์ $a$ ของเส้น $a^{\mathsf T}x=b$ มันตั้งฉากกับเส้น และชี้ไปทางที่ค่า $a^{\mathsf T}x$ เพิ่มเร็วที่สุด
Hedge, payoff และภาระ
hedge คือการถือสินทรัพย์ไว้เพื่อชดเชยการขาดทุน หรือเพื่อให้มีเงินพอจ่ายภาระ ภาระคือเงินที่เราสัญญาว่าจะจ่ายคนอื่น payoff คือเงินที่สินทรัพย์หรือพอร์ตจ่ายออกมาในอนาคต ซึ่งขึ้นกับว่าตลาดออกมาแบบไหน
Convex
ชุดของจุดที่ลากเส้นตรงระหว่างสองจุดใดในชุด แล้วทั้งเส้นยังอยู่ในชุด feasible region ของ linear constraint เป็นแบบนี้เสมอ
Linear program
โจทย์หาค่าต่ำสุดหรือสูงสุดของฟังก์ชัน linear ภายใต้ linear constraint หลายข้อ ใช้หา hedge ที่ถูกที่สุด

ขั้นที่ 1 — linear กับ affine: ขยายแผนแล้วเกิดอะไรขึ้น

คำตอบของ hook ขึ้นกับคำถามเดียว: ถ้าขยายแผน $s$ เท่า วงเงินที่ใช้ขยาย $s$ เท่าตามไปด้วยไหม ฟังก์ชันที่ขยายตามแผนได้ทั้งตัวเรียกว่า linear นิยามของมันคือ การบวกแผนกับการคูณแผนด้วยตัวเลข จะทำก่อนหรือหลังใส่ $f$ ก็ได้ผลเท่ากัน ให้ $u$ และ $v$ คือสองแผนใด ๆ และ $\alpha$, $\beta$ คือตัวเลขใด ๆ

\[\begin{aligned} f(\alpha u+\beta v)&=\alpha f(u)+\beta f(v),\\ a^{\mathsf T}(\alpha u+\beta v)&=\sum_ia_i(\alpha u_i+\beta v_i)\\ &=\alpha\,a^{\mathsf T}u+\beta\,a^{\mathsf T}v,\\ g(x)&=1+a^{\mathsf T}x,\\ g(sx)&=1+s\,a^{\mathsf T}x\ne s\,g(x). \end{aligned}\]

สูตรแบบถ่วงน้ำหนักแล้วบวก $f(x)=a^{\mathsf T}x$ ผ่านนิยามนี้เสมอ เหตุผลคือการคูณกระจายเข้าไปในวงเล็บได้ทีละช่อง $a_i(\alpha u_i+\beta v_i)=\alpha a_iu_i+\beta a_iv_i$ พอบวกทุกช่องก็ได้ผลเดียวกัน ผลข้างเคียงที่ใช้บ่อยคือ ใส่ $\alpha=\beta=0$ จะได้ $f(0)=0$ แปลว่าแผนว่างใช้วงเงินศูนย์ และทุกฟังก์ชัน linear ต้องผ่านจุดกำเนิด

กฎใหม่ของ hook ซึ่งเขียนเป็น $g$ ผ่านนิยามนี้ไม่ได้ เมื่อขยายแผน $s$ เท่า ส่วน $a^{\mathsf T}x$ ขยาย $s$ เท่าตาม แต่เลข 1 ที่กันไว้ไม่ขยาย จึงได้ $g(sx)\ne s\,g(x)$ ใส่ตัวเลขของ hook แผน $(4,2)$ มี $a^{\mathsf T}x=8$ ถ้าเป็น linear ขยายได้ถึง $s=10/8=1.25$ ถ้าเป็น affine ขยายได้ถึง $s=(10-1)/8=1.125$ รูปด้านล่างแสดงว่าสองกฎนี้ชนเพดานคนละจุด

ข้อควรระวัง: ทดสอบด้วยจุดกึ่งกลางแยก linear ออกจาก affine ไม่ได้ เพราะ affine ก็ให้ค่าที่จุดกึ่งกลางเท่ากับค่าเฉลี่ยของสองปลาย

\[\begin{aligned} g\big(\tfrac{u+v}2\big)&=1+\tfrac{a^{\mathsf T}u+a^{\mathsf T}v}2\\ &=\tfrac{(1+a^{\mathsf T}u)+(1+a^{\mathsf T}v)}2\\ &=\tfrac{g(u)+g(v)}2. \end{aligned}\]

วิธีที่แยกได้จริงคือขยายแผนแล้วดูว่าคำตอบขยายตามสัดส่วนไหม หรือดูง่าย ๆ ว่า $g(0)=0$ หรือเปล่า ในที่นี้ $g(0)=1$ จึงไม่ใช่ linear

ขั้นที่ 2 — ฟังก์ชัน linear หนึ่งตัวคือหนึ่งแถว หลายตัวคือ matrix

ขั้นก่อนมีสูตรวงเงินแค่สูตรเดียว แต่งานจริงมักต้องคิดหลายตัวเลขจากแผนเดียวกัน เช่นวงเงินที่ใช้กับต้นทุน ขั้นนี้ดูวิธีเขียนให้เป็นระเบียบ ฟังก์ชัน linear ที่ให้ตัวเลขเดียว เขียนเป็นแถวของน้ำหนักหนึ่งแถวคูณกับ input ได้ ถ้าต้องการหลายตัวเลข ก็ซ้อนหลายแถวเป็น matrix ตามที่พิสูจน์ไว้ใน What a Matrix Is (คอลัมน์ที่ $j$ ของ matrix คือผลของการใส่ $\mathbf e_j$ ซึ่งคือ vector ที่ช่อง $j$ เป็น 1 และช่องอื่นเป็น 0) ตัวอย่างข้างล่างใช้น้ำหนัก 2, 3, 4 ที่ตั้งขึ้นเพื่อให้เห็นรูปเท่านั้น

\[\begin{aligned} f(x)&=\begin{bmatrix}2&3&4\end{bmatrix}x=2x_1+3x_2+4x_3,\\ F(x)&=\begin{bmatrix}2&3&4\\1&0&2\end{bmatrix}x =\begin{bmatrix}2x_1+3x_2+4x_3\\x_1+2x_3\end{bmatrix}. \end{aligned}\]

$f$ รับสามช่องแล้วให้ตัวเลขเดียว ส่วน $F$ รับสามช่องแล้วให้สองตัวเลข ลองใส่ $x=(1,1,1)$ จะได้ $f=2+3+4=9$ และ $F=(2+3+4,\ 1+0+2)=(9,3)$ แถวแรกของ $F$ คือ $f$ ตัวเดิม matrix จึงเป็นแค่หลายสูตรที่วางซ้อนกัน

ทุกสูตรบนโต๊ะเทรดที่ “คูณน้ำหนักแล้วบวก” อยู่ในรูปนี้ สูตรวงเงิน $x_1+2x_2$ ของ hook คือแถว $(1,2)$ ความไวของพอร์ตต่อตลาดทั้งตลาด (exposure ต่อ Market) คือแถวของ loading ซึ่ง loading ของหุ้นแต่ละตัวบอกว่ามันขยับตามตลาดแรงแค่ไหน ต้นทุนของพอร์ตคือ $\mathbf p^{\mathsf T}\boldsymbol\theta$ โดย $\mathbf p$ คือราคาต่อหน่วยของสินทรัพย์แต่ละตัว และ $\boldsymbol\theta$ คือจำนวนหน่วยที่ถือ

สูตรที่ไม่อยู่ในรูปนี้ก็มี ให้ $w_i$ คือเงินที่ลงในสินทรัพย์ตัวที่ $i$ สูตรแรกคือ variance ของพอร์ต (ตัวเลขที่วัดว่าผลตอบแทนแกว่งแรงแค่ไหน) ซึ่งมี $w_i$ คูณกันเองเป็นกำลังสอง สูตรที่สองคือค่าธรรมเนียมคงที่ ซึ่งทำให้สูตรเป็น affine สูตรที่สามคือค่าสัมบูรณ์ $|w_i|$ ซึ่งหักมุมที่ศูนย์ ขั้นที่ 9 จะแสดงวิธีเขียนกฎที่มี $|w_i|$ ให้เป็น linear

ขั้นที่ 3 — เส้นระดับ และ vector สัมประสิทธิ์ที่ตั้งฉากกับมัน

ก่อนดูอสมการ ดูสมการก่อน จุดทุกจุดที่ใช้วงเงินเท่ากันพอดี คือ $a^{\mathsf T}x=b$ สำหรับ $b$ หนึ่งค่า เรียงตัวเป็นเส้นตรง เรียกว่าเส้นระดับ เปลี่ยน $b$ ก็ได้เส้นขนานอีกเส้น ขั้นนี้ถามสองข้อ เดินทิศไหนแล้ววงเงินไม่เปลี่ยน และเดินทิศไหนแล้ววงเงินเพิ่มเร็วที่สุด ใช้ $a=(1,2)$ ของ hook ให้ $d$ คือทิศที่เลือกให้ $a^{\mathsf T}d=0$ และให้ $t$ คือระยะที่เดินไปตามทิศนั้น

\[\begin{aligned} a&=(1,2),\quad d=(2,-1),\\ a^{\mathsf T}d&=1(2)+2(-1)=0,\\ f(x+td)&=f(x)+t\,a^{\mathsf T}d=f(x),\\ f(x+ta)&=f(x)+t\,a^{\mathsf T}a=f(x)+5t. \end{aligned}\]

เดินตาม $d$ แล้ววงเงินไม่เปลี่ยน เพราะ $a^{\mathsf T}d=0$ แปลว่า $d$ ตั้งฉากกับ $a$ (inner product เป็นศูนย์คือตั้งฉาก ตาม inner product) $d$ จึงวิ่งไปตามเส้นระดับ ส่วนเดินตาม $a$ เอง วงเงินเพิ่ม $a^{\mathsf T}a=1^2+2^2=5$ ต่อหนึ่งหน่วยของ $t$ สรุปได้ว่า vector สัมประสิทธิ์ $a$ ตั้งฉากกับเส้น $a^{\mathsf T}x=b$ เสมอ และชี้ไปฝั่งที่ค่าเพิ่ม เรียก $a$ ว่า normal vector ของเส้น

ทำไมทิศของ $a$ ทำให้ค่าเพิ่มเร็วที่สุด ลองเดินในทิศ $u$ ใด ๆ ที่ยาวเท่ากัน ค่าที่เพิ่มต่อหนึ่งหน่วยของ $t$ คือ $a^{\mathsf T}u=\|a\|\|u\|\cos\varphi$ โดย $\varphi$ คือมุมระหว่าง $a$ กับ $u$ ความยาวสองตัวคงที่ เหลือแค่ $\cos\varphi$ ที่เปลี่ยน และมันมากที่สุดเมื่อ $\varphi=0$ คือเมื่อ $u$ ชี้ไปทางเดียวกับ $a$

ผลที่ใช้บ่อยตามมา: ทางที่สั้นที่สุดจากจุด $x$ ไปถึงเส้นคือเดินตาม normal ให้จุดปลายทางคือ $x_*=x+ta$ แล้วหา $t$ ที่ทำให้ $x_*$ อยู่บนเส้นพอดี ลองกับแผน $(4,2)$ และเส้นเพดาน $b=10$ ให้ $\ell$ คือระยะที่เดิน

\[\begin{aligned} a^{\mathsf T}(x+ta)&=b\ \Rightarrow\ t=\frac{b-a^{\mathsf T}x}{a^{\mathsf T}a},\\ t&=\frac{10-8}{5}=0.4,\\ x_*&=(4,2)+0.4\,(1,2)=(4.4,\ 2.8),\\ \ell&=t\,\|a\|=0.4\sqrt5=\frac{2}{\sqrt5}\approx0.894. \end{aligned}\]

ระยะ $\ell$ วัดในหน่วยของขนาดขา คือล้านดอลลาร์ สังเกตว่า slack ของแผนนี้ (วงเงินที่เหลือ $10-8=2$) กับระยะ 0.894 เป็นคนละตัวเลข slack วัดเป็นหน่วยวงเงิน ระยะวัดเป็นหน่วยขนาดขา จะแปลง slack เป็นระยะต้องหารด้วยความยาว $\|a\|=\sqrt5$ ก่อน คือ $2/\sqrt5\approx0.894$

ขั้นที่ 4 — อสมการคือครึ่งระนาบ วางซ้อนกันเป็น $Gx\le h$

ตอนนี้กลับมาที่อสมการ กฎทั้งสามข้อของ hook จะเขียนให้อยู่ในรูปเดียวกันทั้งหมด คือ “แถว linear ไม่เกินตัวเลข” แล้วซ้อนกันเป็น matrix ตัวเดียว เพื่อให้โปรแกรมตรวจทุกข้อได้ในครั้งเดียว ให้ $G$ คือ matrix ที่แต่ละแถวเป็นน้ำหนักของกฎหนึ่งข้อ และ $h$ คือ vector ของเพดานของแต่ละข้อ กฎ “ห้ามติดลบ” เขียนด้วย $\ge$ จึงต้องพลิกให้เป็น $\le$ ก่อน โดยคูณทั้งสองข้างด้วย −1

\[\begin{aligned} x_1+2x_2&\le10,\quad x_1\ge0,\quad x_2\ge0,\\ G&=\begin{bmatrix}1&2\\-1&0\\0&-1\end{bmatrix},\quad h=\begin{bmatrix}10\\0\\0\end{bmatrix},\\ Gx&\le h\quad\text{(every row)}. \end{aligned}\]

แถวที่สองของ $G$ อ่านได้ว่า $-x_1\le0$ ซึ่งคือ $x_1\ge0$ ทุกประการ เพราะคูณทั้งสองข้างด้วย −1 แล้วอสมการกลับทิศ แถวที่สามก็เช่นกัน เครื่องหมาย $Gx\le h$ ระหว่างสอง vector หมายความว่าต้องจริงทุกแถว ไม่ใช่จริงแบบรวม ๆ

ทำไมสองแถวล่างสำคัญ ถ้าลืมใส่ โปรแกรมจะยอมให้ขาหนึ่งติดลบมาหักวงเงินของอีกขา เช่นแผน $(-10,10)$ ใช้วงเงิน $-10+2\times10=10$ พอดี จึง “ผ่าน” กฎวงเงิน ทั้งที่ขาแรกติดลบ ซึ่งไม่ใช่แผนที่ตั้งใจ ในภาพ แต่ละแถวคือครึ่งระนาบหนึ่งอัน และ feasible region ในรูปสามเหลี่ยมตอนต้นหน้าคือส่วนที่ทุกครึ่งระนาบทับกัน

กฎที่เป็นสมการก็ใส่ได้ โดยซ้อนไว้อีกชุดเป็น $Ex=r$ เช่นกฎ “ลงเงินครบ” $\mathbf 1^{\mathsf T}w=1$ ซึ่งแปลว่าน้ำหนัก $w_i$ ของสินทรัพย์ทุกตัวรวมกันได้ 100% ($\mathbf 1$ คือ vector ที่ทุกช่องเป็น 1) โจทย์ที่ถามว่า “หาค่าต่ำสุดหรือสูงสุดของ $c^{\mathsf T}x$ ภายใต้ $Ex=r$ และ $Gx\le h$” เรียกว่า linear program โดย $c$ คือน้ำหนักของเป้าหมาย รูปแบบมาตรฐานของโจทย์นี้อยู่ใน standard form ของ LP

ขั้นที่ 5 — ตรวจแผนด้วย slack ทีละแถว

เมื่อมีกฎหลายข้อ คำถามแรกของทุกแผนคือ ผ่านกฎข้อไหน และผิดข้อไหน ตัวเลขที่ใช้ตอบคือ slack ของแต่ละแถว $h-Gx$ คือเพดานลบด้วยส่วนที่ใช้ไป ถ้าเป็นบวกแปลว่ายังเหลือ ถ้าเป็นศูนย์แปลว่าชนขอบพอดี ถ้าเป็นลบแปลว่าผิดกฎ

โจทย์ให้อะไรมาบ้าง: กฎสามข้อในรูป $Gx\le h$ จากขั้นก่อน และสามแผนที่จะตรวจ $(4,2)$, $(8,3)$, $(-1,0)$

\[\begin{aligned} h-Gx&=\begin{bmatrix}10-x_1-2x_2\\x_1\\x_2\end{bmatrix},\\ (4,2)&\to(10-8,\ 4,\ 2)=(2,4,2),\\ (8,3)&\to(10-14,\ 8,\ 3)=(-4,8,3),\\ (-1,0)&\to(10+1,\ -1,\ 0)=(11,-1,0). \end{aligned}\]

แถวแรกของ slack คือวงเงินที่เหลือ ส่วนแถวที่สองและสามคือ $0-(-x_1)=x_1$ และ $0-(-x_2)=x_2$ ซึ่งก็คือขนาดของแต่ละขานั่นเอง

คำตอบ: $(4,2)$ ผ่านทุกแถว $(8,3)$ เกินวงเงินไป 4 ทั้งที่สองขาไม่ติดลบ $(-1,0)$ เหลือวงเงินถึง 11 แต่ผิดกฎห้ามติดลบในแถวที่สอง ถ้าเอา slack ทุกแถวของ $(-1,0)$ มารวมเป็นตัวเดียว จะได้ $11+(-1)+0=10$ ดูเหมือนผ่านสบาย ๆ จึงต้องดูเครื่องหมายทีละแถวเสมอ ส่วน slack ศูนย์ในแถวที่สามของ $(-1,0)$ บอกว่าจุดนี้อยู่บนเส้น $x_2=0$ พอดี

slack ยังบอกได้ว่าขยายแผนได้อีกเท่าไร ขยาย $(4,2)$ ด้วยตัวคูณ $s$ ไปจนชนเพดานวงเงิน คือ $8s=10$ ได้ $s=1.25$ และแผน $(5,\ 2.5)$ ถ้ามีกฎเพิ่มอีกข้อ $x_1\le4.5$ (ตัวเลขสมมติ) แถวใหม่นี้กลายเป็น $4s\le4.5$ คือ $s\le4.5/4=1.125$ จึงชนก่อน ตัวคูณที่ขยายได้จริงคือค่าที่น้อยที่สุดของทุกแถว $\min(1.25,\ 1.125)=1.125$ ไม่ใช่ดูแค่กฎวงเงินข้อเดียว

ตรวจเองใน 10 วินาที: แผน $(8,3)$ ใช้วงเงิน $8+2\times3=14\gt10$ จึงเกินไป $14-10=4$

ขั้นที่ 6 — โจทย์ hedge: payoff ต้องไม่ต่ำกว่าภาระในทุกสถานะ

ขั้นนี้คือกฎแบบที่ใช้จริงในการ hedge สมมติว่าเรามีภาระ คือเงินที่สัญญาไว้ว่าจะจ่ายให้คนอื่นพรุ่งนี้ และจำนวนเงินนั้นขึ้นกับว่าตลาดพรุ่งนี้ออกมาเป็นแบบไหน วันนี้เราจะซื้อสินทรัพย์เก็บไว้ เพื่อให้เงินที่มันจ่ายออกมาพรุ่งนี้ (payoff) พอจ่ายภาระในทุกกรณี ตัวเลขทั้งหมดเป็นตัวเลขสมมติ หน่วยดอลลาร์

โจทย์ให้อะไรมาบ้าง:

  • สินทรัพย์มีสองตัว คือหุ้นหนึ่งตัวกับ bond หนึ่งตัว (bond คือตราสารหนี้ที่จ่ายเงินคงที่ตามสัญญา) ราคาวันนี้หน่วยละ \$100 ทั้งคู่
  • พรุ่งนี้ตลาดออกมาได้สามแบบ เรียกว่าสามสถานะ คือขึ้น กลาง และลง
  • payoff ต่อหน่วยเขียนเป็นตาราง $S$ แถวคือสถานะ คอลัมน์คือหุ้นกับ bond สถานะขึ้นได้ $(120,105)$ สถานะกลางได้ $(100,105)$ สถานะลงได้ $(70,105)$ bond จ่าย \$105 ทุกสถานะ เพราะเป็นเงินตามสัญญา
  • ภาระในสามสถานะคือ $X=(110,100,80)$
  • พอร์ตที่จะลองคือ $\boldsymbol\theta=(\theta_1,\theta_2)=(0.5,0.5)$ คือถือหุ้นครึ่งหน่วย และ bond ครึ่งหน่วย

กฎคือ payoff ของพอร์ตต้องไม่ต่ำกว่าภาระในทุกสถานะ เขียนได้เป็น $S\boldsymbol\theta\ge X$ ทีละแถว

\[\begin{aligned} S\boldsymbol\theta&=\begin{bmatrix}120(0.5)+105(0.5)\\100(0.5)+105(0.5)\\70(0.5)+105(0.5)\end{bmatrix} =\begin{bmatrix}112.5\\102.5\\87.5\end{bmatrix},\\ S\boldsymbol\theta-X&=(2.5,\ 2.5,\ 7.5)\ \ge0,\\ -S\boldsymbol\theta&\le-X\quad\text{(same rows, }Gx\le h\text{ form)}. \end{aligned}\]

แถวสุดท้ายคูณทั้งสองข้างด้วย −1 เพื่อให้กฎนี้อยู่ในรูป $Gx\le h$ แบบขั้นที่ 4 โดย $G=-S$ และ $h=-X$ โปรแกรมเดียวกันจึงตรวจกฎ hedge ได้ด้วย

คำตอบ: ผ่านทุกสถานะ เพราะส่วนเกิน $S\boldsymbol\theta-X$ ไม่ติดลบทุกแถว ต้นทุนของพอร์ตคือราคาคูณจำนวนหน่วย $100(0.5)+100(0.5)=\$100$ พอร์ตที่จ่ายได้ไม่ต่ำกว่าภาระทุกสถานะเรียกว่า superhedge คือไม่ต้องจ่ายเท่าภาระพอดี ขอแค่ไม่ขาด ส่วนเกิน \$2.5, \$2.5 และ \$7.5 คือเงินที่เหลือพรุ่งนี้ในแต่ละสถานะ

แต่ผ่านกฎไม่ได้แปลว่าถูกที่สุด รูปด้านล่างวาดกฎสามข้อเป็นสามเส้นในระนาบ $(\theta_1,\theta_2)$ ฝั่งที่ผ่านคืออยู่เหนือทุกเส้น เส้นประคือพอร์ตที่ต้นทุนเท่ากัน ถ้าเลื่อนเส้นต้นทุนลงเรื่อย ๆ จุดสุดท้ายที่ยังแตะบริเวณที่ผ่านคือมุมที่สถานะขึ้นกับสถานะกลางชนขอบพอดี แปลว่าพอร์ตจ่ายเท่าภาระพอดีในสองสถานะนี้ หามุมนี้ได้จากสองสมการ เอาสมการบนลบสมการล่างก่อน

\[\begin{aligned} 120\theta_1+105\theta_2&=110,\\ 100\theta_1+105\theta_2&=100,\\ 20\theta_1&=10\ \Rightarrow\ \theta_1=0.5,\\ \theta_2&=\tfrac{110-120(0.5)}{105}=\tfrac{50}{105}\approx0.476,\\ 100(\theta_1+\theta_2)&=100(0.5+0.476)\approx97.62. \end{aligned}\]

พอร์ตนี้จ่าย \$110 และ \$100 ในสถานะขึ้นและกลาง พอดีกับภาระ ส่วนสถานะลงจ่าย $70(0.5)+105(0.476)=35+50=85$ ยังเหลือ $85-80=5$ ต้นทุนคือ \$97.62 ถูกกว่าพอร์ตแรก $100-97.62=\$2.38$ วิธีหาพอร์ตนี้อย่างเป็นระบบอยู่ใน โจทย์ hedge แบบ linear program

ข้อจำกัดสำคัญ: กฎนี้ป้องกันได้เฉพาะสถานะที่เขียนไว้ ถ้ามีสถานะที่สี่ที่หุ้นเหลือ \$40 และภาระยังเป็น \$80 พอร์ต $(0.5,0.5)$ จะจ่าย $40(0.5)+105(0.5)=72.5$ ขาดไป $80-72.5=\$7.5$ ทันที

ขั้นที่ 7 — ผสมแผนที่ผ่าน ก็ยังผ่าน

ขั้นนี้ถามว่า ถ้ามีสองแผนที่ผ่านกฎทั้งคู่ แผนที่อยู่ระหว่างกลางผ่านด้วยไหม ให้ $u$ และ $v$ คือสองแผนที่ผ่าน $Gx\le h$ และให้ $t$ คือตัวเลขระหว่าง 0 ถึง 1 แผนผสม $tu+(1-t)v$ คือเอา $u$ มาสัดส่วน $t$ และเอา $v$ มาสัดส่วน $1-t$ เมื่อ $t$ วิ่งจาก 0 ไป 1 แผนผสมก็วิ่งไปตามเส้นตรงจาก $v$ ไปหา $u$ เครื่องมือที่ใช้คือความเป็น linear ของ $G$

\[\begin{aligned} G\big(tu+(1-t)v\big)&=t\,Gu+(1-t)\,Gv\\ &\le t\,h+(1-t)\,h=h. \end{aligned}\]

เหตุผลมีสองจังหวะ จังหวะแรก $G$ เป็น linear จึงกระจายเข้าไปในวงเล็บได้ จังหวะที่สองเป็นจุดที่ต้องระวัง เรารู้ว่า $Gu\le h$ และ $Gv\le h$ แล้วคูณสองอสมการนี้ด้วย $t$ และ $1-t$ ซึ่งไม่ติดลบทั้งคู่ การคูณด้วยตัวเลขไม่ติดลบไม่กลับทิศอสมการ จึงยังได้ $\le$ แล้วบวกกันได้ $t\,h+(1-t)\,h=h$ ถ้า $t$ อยู่นอกช่วง 0 ถึง 1 ตัวคูณตัวหนึ่งจะติดลบ และข้อสรุปนี้พัง กฎที่เป็นสมการ $Ex=r$ ก็รอดแบบเดียวกัน

ชุดของแผนที่มีสมบัตินี้เรียกว่า convex คือลากเส้นตรงระหว่างสองจุดใดในชุด แล้วทั้งเส้นยังอยู่ในชุด ตัวอย่างเช่น $(4,2)$ ใช้วงเงิน 8 และ $(2,4)$ ใช้วงเงิน $2+2\times4=10$ จุดกึ่งกลาง $(3,3)$ ใช้วงเงิน $3+2\times3=9$ ซึ่งเท่ากับค่าเฉลี่ย $(8+10)/2=9$ จึงยังผ่าน

convex ไม่ได้แปลว่าต้องเป็นสามเหลี่ยมสวย ๆ รูปด้านล่างแสดงสี่หน้าตาที่ linear constraint สร้างได้ ทุกแบบ convex แต่บางแบบไม่มีขอบเขต และบางแบบว่างเปล่า ถ้ากฎขัดกันจนไม่มีแผนไหนผ่านเลย ต้องรายงานว่า infeasible (ทำไม่ได้) ไม่ใช่ปล่อยให้โปรแกรมผ่อนกฎข้อสำคัญเองเงียบ ๆ

ขั้นที่ 8 — ทำไมค่าดีที่สุดของเป้าหมาย linear อยู่ที่มุม

สมมติโต๊ะให้คะแนนแต่ละแผนด้วยเป้าหมาย linear $q(x)=3x_1+2x_2$ (ตัวเลขสมมติ เช่นกำไรที่คาดว่าจะได้) และอยากได้แผนที่คะแนนสูงสุดในสามเหลี่ยม คำถามคือ ต้องตรวจทุกจุดในสามเหลี่ยมไหม คำตอบคือไม่ต้อง ตรวจแค่สามมุมก็พอ เหตุผลคือทุกจุดในสามเหลี่ยมเขียนเป็นส่วนผสมของสามมุม $v_0=(0,0)$, $v_1=(10,0)$, $v_2=(0,5)$ ได้ โดยน้ำหนัก $\lambda_0$, $\lambda_1$, $\lambda_2$ ไม่ติดลบ และรวมกันได้ 1

\[\begin{aligned} \lambda_1&=x_1/10,\quad\lambda_2=x_2/5,\\ \lambda_0&=1-x_1/10-x_2/5\ \ge0,\\ \textstyle\sum_k\lambda_kv_k&=(10\lambda_1,\ 5\lambda_2)=(x_1,x_2),\\ q(x)&=\lambda_0q(v_0)+\lambda_1q(v_1)+\lambda_2q(v_2)\\ &\le\max_k q(v_k)=\max(0,\,30,\,10)=30. \end{aligned}\]

น้ำหนักของมุมหาได้ตรง ๆ เพราะ $v_1$ มีแค่ช่องแรก และ $v_2$ มีแค่ช่องที่สอง ส่วน $v_0$ เป็นศูนย์ จึงรับน้ำหนักที่เหลือให้รวมเป็น 1 น้ำหนัก $\lambda_0$ ไม่ติดลบเพราะจุดผ่านกฎวงเงิน หาร $x_1+2x_2\le10$ ด้วย 10 จะได้ $x_1/10+x_2/5\le1$

จังหวะสำคัญคือความเป็น linear คะแนนของส่วนผสมเท่ากับส่วนผสมของคะแนน และค่าเฉลี่ยถ่วงน้ำหนักไม่มีทางเกินค่าที่มากที่สุดที่เอามาเฉลี่ย ดังนั้นไม่มีจุดข้างในจุดไหนชนะมุมที่ดีที่สุดได้ คะแนนของสามมุมคือ $q(v_0)=0$, $q(v_1)=3\times10=30$ และ $q(v_2)=2\times5=10$ คะแนนสูงสุด 30 จึงอยู่ที่มุม $(10,0)$

ตรวจอีกทางโดยไม่ใช้มุม เขียนคะแนนให้มีสูตรวงเงินอยู่ข้างใน แล้วใช้ $x_1+2x_2\le10$ กับ $x_2\ge0$

\[\begin{aligned} q&=3(x_1+2x_2)-4x_2\\ &\le3\times10-4x_2\le30. \end{aligned}\]

คะแนนเท่ากับ 30 ได้เมื่อ $x_2=0$ และใช้วงเงินเต็ม 10 เท่านั้น ซึ่งคือจุด $(10,0)$

ถ้าเป้าหมายขนานกับขอบ เช่นเป้าหมายคือวงเงินเอง $f=x_1+2x_2$ มุม $(10,0)$ กับ $(0,5)$ ได้ 10 เท่ากัน เพราะ $10+2\times0=10$ และ $0+2\times5=10$ ทุกจุดบนขอบระหว่างสองมุมนั้นก็ได้ 10 คำตอบที่ดีที่สุดจึงมีได้หลายแผน ถ้าต้องเลือกแผนเดียว ต้องมีเป้าหมายรองไว้ตัดสิน และวิธี “ดูแค่มุม” ใช้ได้เมื่อ feasible region มีขอบเขตและไม่ว่างเท่านั้น ครึ่งระนาบในรูปสี่หน้าตาอาจไม่มีคำตอบเลย

ขั้นที่ 9 — กฎที่ดูไม่ linear แต่เขียนให้ linear ได้ และกฎที่ทำไม่ได้

กฎบางข้อดูไม่ linear แต่เขียนให้เป็น linear ได้ ตัวอย่างคือเพดาน gross exposure ให้ $w_i$ คือเงินที่ลงในสินทรัพย์ตัวที่ $i$ ถ้าเป็นบวกคือ long (ซื้อถือไว้) ถ้าเป็นลบคือ short (ยืมมาขาย ได้กำไรเมื่อราคาลง) gross exposure คือขนาดรวมของทุกตัวโดยไม่สนเครื่องหมาย $\sum_i|w_i|$ และฝ่ายความเสี่ยงตั้งเพดานไว้ที่ $L$ ค่าสัมบูรณ์ $|w_i|$ หักมุมที่ศูนย์ จึงไม่ใช่ linear แต่ถ้าเพิ่มตัวแปรช่วย $t_i$ หนึ่งตัวต่อสินทรัพย์ ก็เขียนกฎใหม่เป็นแถว linear ล้วน ๆ ได้

\[\begin{aligned} t_i&\ge w_i,\quad t_i\ge-w_i,\\ \sum_it_i&\le L. \end{aligned}\]

สองอสมการแรกบังคับว่า $t_i$ ต้องไม่น้อยกว่าทั้ง $w_i$ และ $-w_i$ ตัวที่มากกว่าในสองตัวนี้คือ $|w_i|$ พอดี จึงได้ $t_i\ge|w_i|$ แล้วตามมาด้วย $\sum|w_i|\le\sum t_i\le L$ ทิศกลับก็จริง น้ำหนักชุดใดผ่านกฎเดิม ก็เลือก $t_i=|w_i|$ ให้ผ่านกฎใหม่ได้เสมอ สองแบบจึงยอมรับน้ำหนักชุดเดียวกันพอดี

ห้ามแทน $\sum|w_i|$ ด้วยผลรวมแบบมีเครื่องหมาย $\sum w_i$ (เรียกว่า net) เพราะ long \$5 ล้านกับ short \$5 ล้านจะได้ $5+(-5)=0$ ทั้งที่ขนาดรวมของสองตำแหน่งคือ $|5|+|-5|=\$10$ ล้าน

กฎที่เขียนให้ linear ไม่ได้มีสองแบบที่เจอบ่อย แบบแรกคือจำนวนหุ้นต้องเป็นจำนวนเต็มเท่าของ lot (หน่วยซื้อขายขั้นต่ำ เช่นทีละ 100 หุ้น) จุดกึ่งกลางของสองแผนที่เป็นจำนวนเต็มไม่จำเป็นต้องเป็นจำนวนเต็ม เช่น 1 lot กับ 2 lot มีจุดกึ่งกลาง $(1+2)/2=1.5$ lot ซึ่งซื้อไม่ได้ สมบัติ convex จึงพัง แบบที่สองคือเพดาน variance $\mathbf w^{\mathsf T}\Sigma\mathbf w\le\sigma^2_{\max}$ โดย $\Sigma$ คือ covariance matrix ของผลตอบแทน และ $\sigma_{\max}$ คือความผันผวนสูงสุดที่ยอมได้ กฎนี้ยัง convex เมื่อ $\Sigma$ เป็น positive semidefinite แต่มีน้ำหนักคูณกันเป็นกำลังสอง จึงต้องใช้ solver (โปรแกรมหาคำตอบ) อีกประเภท เช่นใน Markowitz portfolio selection

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ขยายกฎ affine เหมือนเป็น linear: ลืมว่ามีส่วนคงที่ที่ไม่ขยายตามแผน ผิดคือ $s=10/8=1.25$ ซึ่งใช้วงเงินจริง $1+8\times1.25=11$ เกินเพดาน \$1 ล้าน ถูกคือ $s=(10-1)/8=1.125$

ลืมแถวห้ามติดลบ: ใส่แค่กฎวงเงิน แผน $(-10,10)$ ใช้วงเงิน $-10+2\times10=10$ พอดีจึงผ่าน ทั้งที่ขาแรกติดลบ \$10 ล้าน ใส่แถว $-x_1\le0$ ด้วย แล้ว slack ของแถวนี้คือ $x_1=-10\lt0$ จึงจับได้

เอา slack มารวมกัน: แผน $(-1,0)$ มี slack รวม $11+(-1)+0=10$ ดูเหมือนผ่านสบาย ๆ แต่ slack แถวที่สองคือ $-1\lt0$ แปลว่าผิดกฎห้ามติดลบ

อ่าน slack เป็นระยะ: slack ของแผน $(4,2)$ คือวงเงินที่เหลือ \$2 ล้าน ไม่ใช่ระยะถึงเส้นเพดาน ระยะจริงคือ $2/\|a\|=2/\sqrt5\approx0.894$ ในหน่วยขนาดขา

ผ่านกฎแล้วเรียกว่าดีที่สุด: hedge $(0.5,0.5)$ ผ่านทุกสถานะ แต่ต้นทุน \$100 แพงกว่ามุม $(0.5,\ 0.476)$ ที่ต้นทุน \$97.62 อยู่ $100-97.62=\$2.38$ ทำนองเดียวกัน การขยายแผนจนชนวงเงินได้คะแนน 20 ขณะที่มุมที่ดีที่สุดได้ 30

ป้องกันเฉพาะสถานะที่เขียนไว้: superhedge $(0.5,0.5)$ ที่ตรวจแค่สามสถานะ จะจ่าย $40(0.5)+105(0.5)=72.5$ ในสถานะที่สี่ที่หุ้นเหลือ \$40 ขาดภาระ \$80 ไป $80-72.5=\$7.5$

โจทย์ตรวจความเข้าใจ

1. ฝ่ายความเสี่ยงกันวงเงิน \$1 ล้านไว้เหมือนใน hook และโต๊ะขยายแผน $(4,2)$ ด้วยตัวคูณ $s$ จนวงเงินเต็มพอดี ได้แผนอะไร ถ้าให้คะแนนแผนด้วย $q=3x_1+2x_2$ แบบขั้นที่ 8 แผนนี้ได้กี่คะแนน และมีแผนอื่นที่ใช้วงเงินเท่ากันแต่คะแนนสูงกว่าไหม

เฉลย

หาตัวคูณก่อน แล้วคิดแผน วงเงิน และคะแนน

\[\begin{aligned} 1+8s&=10\ \Rightarrow\ s=1.125,\\ x&=1.125\,(4,2)=(4.5,\ 2.25),\\ g(x)&=1+4.5+2\times2.25=10,\\ q(x)&=3(4.5)+2(2.25)=13.5+4.5=18. \end{aligned}\]

มีแผนที่ดีกว่า เมื่อกันไว้ 1 แผนจริงเหลือวงเงิน $10-1=9$ สามเหลี่ยมใหม่จึงเป็น $x_1+2x_2\le9$ มีมุมที่ $(9,0)$ และ $(0,\ 4.5)$ แผน $(9,0)$ ใช้วงเงิน $1+9=10$ เท่ากัน แต่ได้คะแนน $3\times9=27$ เพราะเป็นมุมที่ดีที่สุดของสามเหลี่ยมใหม่ ส่วนมุม $(0,\ 4.5)$ ได้แค่ $2\times4.5=9$

2. เพิ่มสถานะที่สี่ในโจทย์ hedge ของขั้นที่ 6 ในสถานะนี้หุ้นจ่าย \$40, bond จ่าย \$105 และภาระคือ \$80 มุม $(0.5,\ 0.476)$ ยังผ่านไหม ถ้าไม่ผ่าน มุมที่ถูกที่สุดใหม่เกิดจากกฎของสถานะคู่ไหน และต้นทุนเท่าไร

เฉลย

มุมเดิมจ่ายในสถานะใหม่ $40(0.5)+105(0.476)=20+50=70\lt80$ จึงไม่ผ่าน ขาดไป $80-70=10$ ลองมุมที่สถานะขึ้นกับสถานะใหม่ชนขอบพอดี เอาสมการบนลบสมการล่าง

\[\begin{aligned} 120\theta_1+105\theta_2&=110,\\ 40\theta_1+105\theta_2&=80,\\ 80\theta_1&=30\ \Rightarrow\ \theta_1=0.375,\\ \theta_2&=\tfrac{80-40(0.375)}{105}=\tfrac{65}{105}\approx0.619. \end{aligned}\]

ตรวจอีกสองสถานะ สถานะกลางจ่าย $100(0.375)+105(0.619)=37.5+65=102.5\ge100$ สถานะลงจ่าย $70(0.375)+105(0.619)=26.25+65=91.25\ge80$ ผ่านทั้งหมด ต้นทุนคือ $100(0.375+0.619)\approx\$99.40$ แพงขึ้นประมาณ \$1.79 (คิดจากค่าที่ไม่ปัด $99.405-97.619=1.786$) ส่วนนี้คือราคาของการป้องกันสถานะที่เพิ่มเข้ามา โค้ดท้ายหน้าไล่ทุกมุมแล้วยืนยันว่ามุมนี้ถูกที่สุด

3. เปลี่ยนเป้าหมายเป็น $2x_1+4x_2$ บนสามเหลี่ยมเดิม ค่าสูงสุดอยู่ที่จุดเดียวหรือไม่ อธิบายด้วยทิศของ normal

เฉลย

ไม่ใช่จุดเดียว เป้าหมายใหม่คือ $2x_1+4x_2=2(x_1+2x_2)$ ทิศที่ค่าเพิ่มคือ $(2,4)=2\,(1,2)$ ซึ่งขนานกับ normal $(1,2)$ ของขอบวงเงิน เส้นระดับของเป้าหมายจึงขนานกับขอบเอียง ทุกจุดบนขอบนั้นมี $x_1+2x_2=10$ จึงได้ $2\times10=20$ เท่ากัน ตั้งแต่ $(10,0)$ ไปจนถึง $(0,5)$

const slack = (G, h, x) => G.map((row, i) => h[i] - dot(row, x));

const G = [[1, 2], [-1, 0], [0, -1]], h = [10, 0, 0];
for (const x of [[4, 2], [8, 3], [-1, 0]]) {
  const s = slack(G, h, x);
  console.log(x, s, s.every(v => v >= 0) ? 'feasible' : 'violates');
}

// hedge: each row is (stock payoff, bond payoff, obligation)
function cheapest(rows) {
  let best = null;
  for (let i = 0; i < rows.length; i++) for (let j = i + 1; j < rows.length; j++) {
    const [p, q, r] = rows[i], [u, v, s] = rows[j], det = p * v - q * u;
    if (Math.abs(det) < 1e-12) continue;
    const th = [(r * v - q * s) / det, (p * s - r * u) / det];
    const ok = rows.every(([x, y, z]) => x * th[0] + y * th[1] >= z - 1e-9);
    const cost = 100 * (th[0] + th[1]);
    if (ok && (!best || cost < best.cost)) best = { th, cost };
  }
  return best;
}
const states = [[120, 105, 110], [100, 105, 100], [70, 105, 80]];
console.log(cheapest(states));                      // (0.5, 0.476), 97.62
console.log(cheapest([...states, [40, 105, 80]])); // (0.375, 0.619), 99.40

สิ่งที่ควรตอบได้หลังอ่าน

  • แยก linear ($f(0)=0$ และขยายตามแผนทั้งตัว) ออกจาก affine (มีส่วนคงที่ที่ไม่ขยาย) และอธิบายได้ว่าทำไมโจทย์เปิดขยายได้ $(10-1)/8=1.125$ เท่า ไม่ใช่ $10/8=1.25$ เท่า
  • มอง $a^{\mathsf T}x=b$ เป็นเส้นที่ $a$ ตั้งฉาก มอง $a^{\mathsf T}x\le b$ เป็นครึ่งระนาบ แล้วซ้อนกฎหลายข้อเป็น $Gx\le h$
  • ตรวจแผนด้วย slack ทีละแถว และแยก slack (หน่วยวงเงิน) ออกจากระยะถึงเส้น (slack หารด้วย $\|a\|$)
  • เขียนโจทย์ hedge เป็น $S\boldsymbol\theta\ge X$ และเห็นว่า “ผ่านกฎ” กับ “ถูกที่สุด” เป็นคนละคำถาม (\$100 กับ \$97.62)
  • อธิบายได้ว่าทำไม feasible region เป็น convex และทำไมค่าดีที่สุดของเป้าหมาย linear บนบริเวณที่มีขอบเขตอยู่ที่มุม

โจทย์ hedge ในหน้านี้ถามแค่ว่า “ผ่านไหม” หน้าถัดไป Rank, Range, and Invertibility ถามคำถามที่เข้มกว่า คือสร้าง payoff ที่ต้องการได้พอดีไหม ถ้าได้ มีวิธีเดียวหรือหลายวิธี และถ้าตัวเลขในโจทย์ขยับนิดเดียว คำตอบกระโดดไปแค่ไหน
