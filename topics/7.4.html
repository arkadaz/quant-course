7.4 Linear Functions and Linear Constraints

ฟังก์ชัน linear คือการถ่วงน้ำหนักแล้วบวก ส่วน linear constraint ใช้ฟังก์ชันแบบนี้ขีดเส้นแบ่งระนาบเป็นฝั่งที่ยอมรับได้กับฝั่งที่ไม่ได้ แผนที่ผ่านทุกข้อจึงเป็นรูปหลายเหลี่ยมที่มองเห็นได้

desk มีวงเงินภายใน \$10 ล้าน แผน hedge สองขามีขนาด $x_1$ และ $x_2$ (ล้านดอลลาร์ ไม่ติดลบ) และกติกาคิดวงเงินที่ใช้คือ $x_1+2x_2$ แผน $(4,2)$ ใช้ไป 8 จึงดูเหมือนขยายได้อีก $10/8=1.25$ เท่า แต่ฝ่ายความเสี่ยงบอกว่าต้องกันวงเงินคงที่ \$1 ล้านไว้ให้งานอื่นเสมอ ไม่ว่าแผนจะใหญ่แค่ไหน ยังขยายได้ 1.25 เท่าไหม

ลองตอบก่อนเปิดเฉลย

ไม่ได้ วงเงินที่ใช้กลายเป็น $1+(x_1+2x_2)$ ขยาย 1.25 เท่าจะใช้ $1+8(1.25)=11$ เกินวงเงิน ขยายได้จริง $(10-1)/8=1.125$ เท่า เพราะส่วนคงที่ \$1 ล้านไม่ได้ขยายตามแผน กติกาเดิม $x_1+2x_2$ เป็น linear ส่วนกติกาใหม่เป็น affine คือ linear บวกค่าคงที่ และ affine ไม่ยอมให้ขยายแบบเป็นสัดส่วน

ภาพรวมก่อนลงสูตร

โจทย์บน desk ส่วนใหญ่มีสองชิ้นที่ต้องแยกให้ออก ชิ้นแรกคือกติกาคำนวณ เช่นวงเงินที่ใช้ exposure หรือต้นทุน ซึ่งมักเป็นการถ่วงน้ำหนักแล้วบวก คือฟังก์ชัน linear ชิ้นที่สองคือข้อบังคับ เช่นวงเงินห้ามเกิน 10 ขนาดขาห้ามติดลบ หรือ payoff ต้องไม่ต่ำกว่าภาระในทุกสถานะ แต่ละข้อบังคับเอาฟังก์ชัน linear หนึ่งตัวมาเทียบกับตัวเลข เรียกว่า linear constraint

ภาพของ linear constraint เรียบง่ายมาก สมการ $a^{\mathsf T}x=b$ คือเส้นตรงในระนาบ (หรือระนาบในสามมิติ) อสมการ $a^{\mathsf T}x\le b$ คือ “ครึ่งหนึ่ง” ของระนาบที่อยู่ฝั่งหนึ่งของเส้นนั้น แผนที่ผ่านทุกข้อคือส่วนที่ทุกครึ่งระนาบทับกัน ในโจทย์ของ hook มันคือสามเหลี่ยมในรูปด้านล่าง

หน้านี้แยก linear ออกจาก affine ดูว่าทิศของ vector สัมประสิทธิ์บอกอะไร ตรวจแผนด้วย slack ทีละข้อ ตั้งโจทย์ hedge ที่ payoff ต้องไม่ต่ำกว่าภาระ ดูว่าทำไมผสมแผนที่ผ่านแล้วยังผ่าน และทำไมค่าที่ดีที่สุดของเป้าหมาย linear มักอยู่ที่มุม ซึ่งคือหัวใจของ linear programming

ศัพท์ที่ใช้ในหัวข้อนี้
Linear function
$f(x)=a^{\mathsf T}x$ ผลของผลรวมเท่ากับผลรวมของผล และ $f(0)=0$ ใช้เป็นกติกาคำนวณวงเงิน exposure หรือต้นทุน
Affine function
$g(x)=c+a^{\mathsf T}x$ คือ linear บวกค่าคงที่ ขยายแผนแล้วส่วนคงที่ไม่ขยายตาม ใช้แทนค่าธรรมเนียมคงที่หรือวงเงินที่กันไว้
Hyperplane และ half-space
จุดทั้งหมดที่ $a^{\mathsf T}x=b$ (เส้นในสองมิติ ระนาบในสามมิติ) และจุดทั้งหมดที่ $a^{\mathsf T}x\le b$ (ฝั่งหนึ่งของเส้นนั้น) ใช้แทน constraint หนึ่งข้อเป็นภาพ
Feasible region
แผนทั้งหมดที่ผ่านทุก constraint พร้อมกัน ใช้ตอบว่ามีแผนที่เป็นไปได้หรือไม่ ก่อนถามว่าแผนไหนดีที่สุด
Slack
$b-a^{\mathsf T}x$ ของแต่ละข้อ บวกคือยังเหลือ ศูนย์คือชนขอบ ลบคือละเมิด ใช้ตรวจแผนทีละข้อ
Normal vector
vector สัมประสิทธิ์ $a$ ซึ่งตั้งฉากกับเส้น $a^{\mathsf T}x=b$ ชี้ทิศที่ค่า $a^{\mathsf T}x$ เพิ่มเร็วที่สุด
Linear program
โจทย์หาค่าต่ำสุดหรือสูงสุดของฟังก์ชัน linear ภายใต้ linear constraints ใช้หา hedge ที่ถูกที่สุด

ขั้นที่ 1 — linear กับ affine: ขยายแผนแล้วเกิดอะไรขึ้น

คำตอบของ hook ขึ้นกับว่ากติกาคำนวณ “ขยายตามแผน” ได้ทั้งตัวหรือไม่ นิยามของ linear คือการรวม input และการคูณด้วยตัวเลขส่งผ่านฟังก์ชันได้ สำหรับทุก $u,v$ และทุกตัวเลข $\alpha,\beta$

\[\begin{aligned} f(\alpha u+\beta v)&=\alpha f(u)+\beta f(v),\\ a^{\mathsf T}(\alpha u+\beta v)&=\sum_ia_i(\alpha u_i+\beta v_i)\\ &=\alpha\,a^{\mathsf T}u+\beta\,a^{\mathsf T}v,\\ g(x)=1+a^{\mathsf T}x:\quad g(sx)&=1+s\,a^{\mathsf T}x\ne s\,g(x). \end{aligned}\]

บรรทัดสองและสามพิสูจน์ว่า $f(x)=a^{\mathsf T}x$ ผ่านนิยามเสมอ เพราะคูณกระจายผ่านผลบวกได้ทีละช่อง ใส่ $\alpha=\beta=0$ จะได้ $f(0)=0$ ทุกฟังก์ชัน linear ต้องผ่านจุดกำเนิด บรรทัดสุดท้ายคือกติกาที่กันวงเงิน: ขยายแผน $s$ เท่า ส่วน $a^{\mathsf T}x$ ขยาย แต่เลข 1 ไม่ขยาย

ในตัวเลขของ hook แผน $(4,2)$ ใช้ $f=8$ ถ้าเป็น linear ขยายได้ถึง $8s=10$ คือ $s=1.25$ ถ้าเป็น affine ต้อง $1+8s=10$ คือ $s=1.125$ รูปด้านล่างแสดงสองเส้นนี้ชนเพดานคนละจุด ข้อควรระวัง: การทดสอบด้วยจุดกึ่งกลางแยก linear จาก affine ไม่ได้ เพราะ affine ก็ผ่าน $g(\tfrac{u+v}2)=\tfrac{g(u)+g(v)}2$ ต้องทดสอบด้วยการขยาย หรือดูว่า $g(0)=0$ หรือไม่

ขั้นที่ 2 — ฟังก์ชัน linear หนึ่งตัวคือหนึ่งแถว หลายตัวคือ matrix

ทุกฟังก์ชัน linear ที่ให้ตัวเลขเดียวเขียนเป็นแถวหนึ่งแถวคูณ input ได้ และหลาย output ก็คือหลายแถวซ้อนกันเป็น matrix ตามที่พิสูจน์ใน What a Matrix Is (คอลัมน์ของ matrix คือภาพของ $\mathbf e_j$)

\[\begin{aligned} f(x)&=\begin{bmatrix}2&3&4\end{bmatrix}x=2x_1+3x_2+4x_3,\\ F(x)&=\begin{bmatrix}2&3&4\\1&0&2\end{bmatrix}x =\begin{bmatrix}2x_1+3x_2+4x_3\\x_1+2x_3\end{bmatrix}. \end{aligned}\]

$f$ ส่งสามช่องไปหนึ่งช่อง $F$ ส่งสามช่องไปสองช่อง ใส่ $x=(1,1,1)$ ได้ $f=9$ และ $F=(9,3)$ ทุกกติกาคำนวณบน desk ที่ “ถ่วงน้ำหนักแล้วบวก” อยู่ในรูปนี้: วงเงิน $x_1+2x_2$ คือแถว $(1,2)$ exposure ต่อ Market คือแถวของ loading ต้นทุนพอร์ตคือแถวของราคา $\mathbf p^{\mathsf T}\boldsymbol\theta$ ที่ไม่อยู่ในรูปนี้ได้แก่ variance (กำลังสองของน้ำหนัก) ค่าธรรมเนียมคงที่ (affine) และ $|w_i|$ (หักมุมที่ศูนย์)

ขั้นที่ 3 — เส้นระดับ และ vector สัมประสิทธิ์ที่ตั้งฉากกับมัน

ก่อนดูอสมการ ดูสมการก่อน ทุกจุดที่ใช้วงเงินเท่ากันพอดี $a^{\mathsf T}x=b$ เรียงตัวเป็นเส้นตรง เปลี่ยน $b$ ได้เส้นขนานชุดหนึ่ง ถามว่าเดินทิศไหนแล้ววงเงินไม่เปลี่ยน และทิศไหนเพิ่มเร็วที่สุด

\[\begin{aligned} a&=(1,2),\quad d=(2,-1),\quad a^{\mathsf T}d=0,\\ f(x+td)&=f(x)+t\,a^{\mathsf T}d=f(x),\\ f(x+ta)&=f(x)+t\,a^{\mathsf T}a=f(x)+5t. \end{aligned}\]

เดินตาม $d$ ที่ตั้งฉากกับ $a$ ค่าไม่เปลี่ยน $d$ จึงวิ่งไปตามเส้นระดับ ส่วนเดินตาม $a$ เอง ค่าเพิ่ม $\|a\|^2=5$ ต่อหนึ่งหน่วย $t$ ดังนั้น vector สัมประสิทธิ์ $a$ ตั้งฉากกับเส้น $a^{\mathsf T}x=b$ เสมอ และชี้ไปทางที่ค่าเพิ่ม เรียกว่า normal vector (ใช้ inner product เป็นศูนย์คือตั้งฉาก)

ผลข้างเคียงที่ใช้บ่อย: ระยะสั้นที่สุดจากจุด $x$ ไปถึงเส้นคือเดินตาม normal ตั้ง $x_*=x+ta$ แล้วบังคับ $a^{\mathsf T}x_*=b$ ได้ $t=(b-a^{\mathsf T}x)/(a^{\mathsf T}a)$ แผน $(4,2)$ มี $b-a^{\mathsf T}x=10-8=2$ จึงได้ $t=0.4$ จุดใกล้สุดคือ $(4.4,\,2.8)$ และระยะคือ $2/\sqrt5\approx0.894$ ล้านดอลลาร์ในพิกัดของขนาดขา สังเกตว่า slack 2 กับระยะ 0.894 เป็นคนละตัวเลข slack วัดเป็นหน่วยวงเงิน ระยะวัดเป็นหน่วยขนาดขา ต้องหารด้วย $\|a\|$ ก่อน

ขั้นที่ 4 — อสมการคือครึ่งระนาบ วางซ้อนกันเป็น $Gx\le h$

constraint ทุกข้อของ hook เขียนให้อยู่ในรูปเดียวกัน “แถว linear ไม่เกินตัวเลข” แล้วซ้อนเป็น matrix เดียว ข้อ “ไม่ติดลบ” ต้องพลิกเครื่องหมายให้เป็นรูปไม่เกินก่อน

\[\begin{aligned} x_1+2x_2&\le10,\quad x_1\ge0,\quad x_2\ge0,\\ G&=\begin{bmatrix}1&2\\-1&0\\0&-1\end{bmatrix},\quad h=\begin{bmatrix}10\\0\\0\end{bmatrix},\\ Gx&\le h\quad\text{(every row)}. \end{aligned}\]

แถวสองคือ $-x_1\le0$ ซึ่งเหมือน $x_1\ge0$ ทุกประการ คูณด้วย −1 กลับทิศอสมการ อสมการระหว่าง vector หมายถึงต้องจริงทุกแถว ไม่ใช่โดยรวม ถ้าลืมสองแถวล่าง โปรแกรมจะยอมให้ขาติดลบมาหักวงเงิน เช่น $(-10,10)$ ใช้วงเงิน $-10+20=10$ พอดีและ “ผ่าน” ทั้งที่ไม่ใช่แผนที่ตั้งใจ ภาพของแต่ละแถวคือครึ่งระนาบ และ feasible region ในรูปภาพรวมคือส่วนที่ทุกครึ่งระนาบทับกัน

สมการก็เขียนเป็น constraint ได้ ซ้อนไว้อีกชุด $Ex=d$ เช่น “ลงเงินครบ” $\mathbf 1^{\mathsf T}w=1$ รูปแบบรวม “หาค่าต่ำสุดหรือสูงสุดของ $c^{\mathsf T}x$ ภายใต้ $Ex=d$ และ $Gx\le h$” คือ linear program ที่ใช้ทั้ง standard form ของ LP

ขั้นที่ 5 — ตรวจแผนด้วย slack ทีละแถว

โจทย์ให้อะไรมาบ้าง: $G,h$ จากขั้นก่อน และสามแผน $(4,2)$, $(8,3)$, $(-1,0)$ slack ของแต่ละแถวคือ $h-Gx$

\[\begin{aligned} x=(4,2):\ h-Gx&=(10-8,\ 4,\ 2)=(2,4,2),\\ x=(8,3):\ h-Gx&=(10-14,\ 8,\ 3)=(-4,8,3),\\ x=(-1,0):\ h-Gx&=(10+1,\ -1,\ 0)=(11,-1,0). \end{aligned}\]

คำตอบ: $(4,2)$ ผ่านทุกแถว $(8,3)$ เกินวงเงิน 4 แม้สองขาไม่ติดลบ $(-1,0)$ เหลือวงเงินถึง 11 แต่ละเมิดข้อห้ามติดลบ ถ้ารวม slack ทุกแถวเป็นตัวเดียว $(-1,0)$ จะได้ $11-1+0=10$ ดูเหมือนผ่านสบาย ๆ ต้องดูเครื่องหมายทีละแถวเสมอ slack ศูนย์ในแถวสามของ $(-1,0)$ บอกว่ามันนั่งอยู่บนเส้น $x_2=0$ พอดี

ขยาย $(4,2)$ ตามแนวเดิมไปจนชนเพดาน คือ $8s=10$ ได้ $(5,2.5)$ ถ้ามีเพดานเพิ่ม $x_1\le4.5$ แถวใหม่ $4s\le4.5$ จะชนก่อนที่ $s=1.125$ ขยายได้เท่ากับค่าน้อยสุดของทุกแถว ไม่ใช่ดูแค่วงเงินรวม

ตรวจเองใน 10 วินาที: $8+2(3)=14\gt10$ จึงเกิน 4

ขั้นที่ 6 — โจทย์ hedge: payoff ต้องไม่ต่ำกว่าภาระในทุกสถานะ

นี่คือ constraint แบบที่ใช้จริงในการ hedge ตลาดมีสินทรัพย์สองตัว โลกพรุ่งนี้มีสามสถานะ ตาราง $S$ ให้ payoff ต่อหน่วย (แถวคือสถานะ คอลัมน์คือหุ้นกับ bond) และ $X$ คือเงินที่เราต้องจ่ายในแต่ละสถานะ ตัวเลขสมมติ หน่วยดอลลาร์

โจทย์ให้อะไรมาบ้าง: $S$ แถว $(120,105)$, $(100,105)$, $(70,105)$ ภาระ $X=(110,100,80)$ ราคาวันนี้หน่วยละ \$100 ทั้งสองตัว ลองถือ $\boldsymbol\theta=(0.5,0.5)$

\[\begin{aligned} S\boldsymbol\theta&=\begin{bmatrix}120(0.5)+105(0.5)\\100(0.5)+105(0.5)\\70(0.5)+105(0.5)\end{bmatrix} =\begin{bmatrix}112.5\\102.5\\87.5\end{bmatrix},\\ S\boldsymbol\theta-X&=(2.5,\ 2.5,\ 7.5)\ \ge0,\\ -S\boldsymbol\theta&\le-X\quad\text{(same rows, }Gx\le h\text{ form)}. \end{aligned}\]

คำตอบ: ผ่านทุกสถานะ ต้นทุน $100(0.5)+100(0.5)=\$100$ พอร์ตแบบนี้เรียก superhedge: จ่ายได้ไม่ต่ำกว่าภาระทุกสถานะ ไม่ใช่จ่ายเท่าพอดี ส่วนเกิน 2.5, 2.5, 7.5 เป็นเงินในอนาคตของแต่ละสถานะ

แต่ผ่านไม่ได้แปลว่าถูกที่สุด รูปด้านล่างวาดสาม constraint เป็นสามเส้นในระนาบ $(\theta_1,\theta_2)$ ฝั่งที่ผ่านคือเหนือทุกเส้น เส้นประคือต้นทุนเท่ากัน เลื่อนเส้นต้นทุนลงจนแตะ feasible region ครั้งสุดท้ายที่มุมซึ่งสถานะขึ้นและสถานะกลางชนพอดี ได้ $\boldsymbol\theta=(0.5,\ 10/21)\approx(0.5,\ 0.476)$ จ่าย $(110,\ 100,\ 85)$ ต้นทุน $100(0.5+0.476)\approx\$97.62$ ถูกกว่าเดิม \$2.38 การหาพอร์ตนี้อย่างเป็นระบบคือ โจทย์ hedge แบบ linear program

ข้อจำกัดสำคัญ: ผ่านเฉพาะสถานะที่เขียนไว้ ถ้ามีสถานะที่สี่ที่หุ้นเหลือ 40 และภาระยังเป็น 80 พอร์ต $(0.5,0.5)$ จ่าย $40(0.5)+105(0.5)=72.5$ ขาด 7.5 ทันที

ขั้นที่ 7 — ผสมแผนที่ผ่าน ก็ยังผ่าน

ถ้า $u$ และ $v$ ผ่าน $Gx\le h$ ทั้งคู่ แผนผสม $tu+(1-t)v$ โดย $0\le t\le1$ คือทุกจุดบนเส้นตรงระหว่างสองแผน ใช้ความเป็น linear ของ $G$

\[\begin{aligned} G\big(tu+(1-t)v\big)&=t\,Gu+(1-t)\,Gv\\ &\le t\,h+(1-t)\,h=h. \end{aligned}\]

บรรทัดแรกใช้ linear บรรทัดสองใช้ว่าทั้ง $Gu\le h$ และ $Gv\le h$ แล้วคูณด้วยตัวเลขไม่ติดลบ $t$ และ $1-t$ ซึ่งไม่กลับทิศอสมการ สมการ $Ex=d$ ก็รอดแบบเดียวกัน ชุดที่มีคุณสมบัตินี้เรียกว่า convex: ลากเส้นระหว่างสองจุดใดในชุด ทั้งเส้นอยู่ในชุด เช่น $(4,2)$ ใช้วงเงิน 8 และ $(2,4)$ ใช้ 10 จุดกึ่งกลาง $(3,3)$ ใช้ 9 ยังผ่าน

convex ไม่ได้แปลว่าต้องเป็นสามเหลี่ยมสวย ๆ รูปด้านล่างแสดงสี่หน้าตาที่ linear constraints สร้างได้ ทั้งหมด convex แต่บางแบบไม่มีขอบเขต บางแบบว่างเปล่า ถ้ากฎขัดกันจนว่าง ต้องรายงานว่า infeasible ไม่ใช่ให้โปรแกรมผ่อนกฎข้อที่สำคัญเองเงียบ ๆ

ขั้นที่ 8 — ทำไมค่าดีที่สุดของเป้าหมาย linear อยู่ที่มุม

สมมติ desk ให้คะแนนแผนด้วยเป้าหมาย linear $q(x)=3x_1+2x_2$ (สมมติ) แล้วอยากได้คะแนนสูงสุดในสามเหลี่ยม ทุกจุดในสามเหลี่ยมเขียนเป็นส่วนผสมของสามมุม $v_0=(0,0)$, $v_1=(10,0)$, $v_2=(0,5)$ ได้ โดยน้ำหนักไม่ติดลบและรวมเป็นหนึ่ง

\[\begin{aligned} \lambda_1&=x_1/10,\quad\lambda_2=x_2/5,\\ \lambda_0&=1-x_1/10-x_2/5\ \ge0,\\ q(x)&=\lambda_0q(v_0)+\lambda_1q(v_1)+\lambda_2q(v_2)\\ &\le\max_k q(v_k)=\max(0,\,30,\,10)=30. \end{aligned}\]

$\lambda_0\ge0$ เพราะจุดผ่านกฎวงเงิน $x_1+2x_2\le10$ (หารด้วย 10 ได้ $x_1/10+x_2/5\le1$) บรรทัดสามใช้ linear: คะแนนของส่วนผสมคือส่วนผสมของคะแนน และค่าเฉลี่ยถ่วงน้ำหนักไม่มีทางเกินค่าที่มากที่สุด จึงไม่มีจุดข้างในชนะมุมที่ดีที่สุด คะแนนสูงสุด 30 อยู่ที่ $(10,0)$ ตรวจอีกทาง: $q=3(x_1+2x_2)-4x_2\le30-4x_2\le30$ เท่ากับ 30 ได้เมื่อ $x_2=0$ และใช้วงเงินเต็มเท่านั้น

ถ้าเป้าหมายขนานกับขอบ เช่นวงเงินเอง $f=x_1+2x_2$ มุม $(10,0)$ กับ $(0,5)$ ได้ 10 เท่ากัน และทุกจุดบนขอบระหว่างนั้นก็ได้ 10 คำตอบที่ดีที่สุดจึงมีได้หลายตัว ต้องมีเป้าหมายรองถ้าต้องเลือกแผนเดียว แนวคิด “ดูแค่มุม” ใช้ได้เมื่อบริเวณมีขอบเขตและไม่ว่าง ครึ่งระนาบในรูปก่อนอาจไม่มีคำตอบเลย

ขั้นที่ 9 — กฎที่ดูไม่ linear แต่เขียนให้ linear ได้ และกฎที่ทำไม่ได้

เพดาน gross exposure $\sum_i|w_i|\le L$ มีค่าสัมบูรณ์ซึ่งหักมุมที่ศูนย์ แต่เพิ่มตัวแปรช่วย $t_i$ หนึ่งตัวต่อสินทรัพย์ แล้วเขียนใหม่เป็นแถว linear ล้วน ๆ ได้

\[\begin{aligned} t_i&\ge w_i,\quad t_i\ge-w_i,\\ \sum_it_i&\le L. \end{aligned}\]

สองแถวแรกบังคับ $t_i\ge|w_i|$ จึงได้ $\sum|w_i|\le\sum t_i\le L$ ทิศกลับก็จริง: น้ำหนักใดผ่านกฎเดิม ก็เลือก $t_i=|w_i|$ ให้ผ่านกฎใหม่ได้เสมอ สองชุดจึงยอมรับน้ำหนักชุดเดียวกันพอดี ห้ามแทน $|w_i|$ ด้วย net $\sum w_i$ เพราะ long \$5 ล้าน short \$5 ล้านจะได้ศูนย์

กฎที่เขียนให้ linear ไม่ได้: จำนวนหุ้นต้องเป็นจำนวนเต็มเท่าของ lot (จุดกึ่งกลางของสองแผนจำนวนเต็มไม่จำเป็นต้องเป็นจำนวนเต็ม convexity พัง) และเพดาน variance $\mathbf w^{\mathsf T}\Sigma\mathbf w\le\sigma^2_{\max}$ ซึ่งยัง convex เมื่อ covariance positive semidefinite แต่เป็นกำลังสอง ต้องใช้ solver ประเภทอื่น เช่นใน Markowitz portfolio selection

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ขยายกติกา affine เหมือน linear: กันวงเงิน \$1 ล้านไว้แต่ยังขยาย 1.25 เท่า ใช้วงเงิน 11 เกินเพดาน \$1 ล้าน

ลืมแถวไม่ติดลบ: แผน $(-10,10)$ ใช้วงเงิน $-10+20=10$ พอดี ผ่านกฎวงเงินแถวเดียว แต่ขาแรกติดลบ \$10 ล้าน

รวม slack: $(-1,0)$ มี slack รวม 10 แต่ละเมิดแถวที่สอง

อ่าน slack เป็นระยะ: slack 2 ล้านดอลลาร์ของวงเงิน คือระยะ 0.894 ในพิกัดของขนาดขา ต้องหาร $\|a\|=\sqrt5$

ผ่านกฎแล้วเรียกว่าดีที่สุด: hedge $(0.5,0.5)$ ผ่านทุกสถานะแต่แพงกว่ามุม $(0.5,0.476)$ \$2.38 และขยายแผนจนชนวงเงินได้คะแนน 20 ขณะที่มุมที่ดีที่สุดได้ 30

ผ่านเฉพาะสถานะที่เขียน: superhedge ที่ตรวจสามสถานะขาด \$7.5 ทันทีในสถานะที่สี่ที่ไม่ได้ใส่ไว้

โจทย์ตรวจความเข้าใจ

1. กันวงเงินคงที่ \$1 ล้าน แล้วขยายแผน $(4,2)$ จนเต็ม ได้แผนอะไร คะแนน $q=3x_1+2x_2$ เท่าไร และมีแผนอื่นที่ใช้วงเงินเท่ากันแต่คะแนนสูงกว่าไหม

เฉลย

$1+8s=10$ ได้ $s=1.125$ แผนคือ $(4.5,\ 2.25)$ ใช้วงเงิน $4.5+4.5=9$ บวก 1 เป็น 10 คะแนน $13.5+4.5=18$ แผน $(9,0)$ ใช้วงเงิน $9+1=10$ เท่ากันแต่ได้คะแนน 27 เพราะเป็นมุมของสามเหลี่ยมใหม่ $x_1+2x_2\le9$

2. เพิ่มสถานะที่สี่ในโจทย์ hedge: หุ้นจ่าย 40, bond จ่าย 105 และภาระ 80 มุม $(0.5,0.476)$ ยังผ่านไหม ถ้าไม่ผ่าน มุมที่ถูกที่สุดใหม่คือ constraint คู่ไหน และต้นทุนเท่าไร

เฉลย

$40(0.5)+105(0.476)=20+50=70\lt80$ ไม่ผ่าน ขาด 10 ลองมุมที่สถานะขึ้นกับสถานะใหม่ชนพอดี: $120\theta_1+105\theta_2=110$ และ $40\theta_1+105\theta_2=80$ ลบกันได้ $80\theta_1=30$ คือ $\theta_1=0.375$ แล้ว $\theta_2=(80-15)/105\approx0.619$ ตรวจสถานะกลาง $37.5+65=102.5\ge100$ และสถานะลง $26.25+65=91.25\ge80$ ผ่านทั้งหมด ต้นทุน $100(0.375+0.619)\approx\$99.40$ แพงขึ้น \$1.79 จากการ hedge สถานะที่เพิ่มมา

3. เปลี่ยนเป้าหมายเป็น $2x_1+4x_2$ บนสามเหลี่ยมเดิม ค่าสูงสุดอยู่ที่จุดเดียวหรือไม่ อธิบายด้วยทิศของ normal

เฉลย

ไม่ เป้าหมายใหม่คือ $2(x_1+2x_2)$ ทิศที่ค่าเพิ่มคือ $(2,4)$ ขนานกับ normal $(1,2)$ ของขอบวงเงิน เส้นระดับของเป้าหมายจึงขนานกับขอบเอียง และทุกจุดบนขอบนั้นได้ 20 เท่ากัน ตั้งแต่ $(10,0)$ ถึง $(0,5)$

โค้ดตรวจ slack ทีละแถว หาตัวคูณขยายแผนแบบ linear และ affine และไล่มุมของโจทย์ hedge เพื่อหาพอร์ตที่ถูกที่สุด (ไล่มุมได้เพราะโจทย์เล็กและมีขอบเขต ไม่ใช่ solver ทั่วไป)

เปิดดูโค้ด 
const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);
const slack = (G, h, x) => G.map((row, i) => h[i] - dot(row, x));

const G = [[1, 2], [-1, 0], [0, -1]], h = [10, 0, 0];
for (const x of [[4, 2], [8, 3], [-1, 0]]) {
  const s = slack(G, h, x);
  console.log(x, s, s.every(v => v >= 0) ? 'feasible' : 'violates');
}
console.log(10 / 8, (10 - 1) / 8);                 // 1.25 linear, 1.125 affine
const a = [1, 2], t = (10 - dot(a, [4, 2])) / dot(a, a);
console.log([4 + t, 2 + 2 * t], 2 / Math.sqrt(5)); // (4.4, 2.8), 0.894

// hedge: each row is (stock payoff, bond payoff, obligation)
function cheapest(rows) {
  let best = null;
  for (let i = 0; i < rows.length; i++) for (let j = i + 1; j < rows.length; j++) {
    const [p, q, r] = rows[i], [u, v, s] = rows[j], det = p * v - q * u;
    if (Math.abs(det) < 1e-12) continue;
    const th = [(r * v - q * s) / det, (p * s - r * u) / det];
    const ok = rows.every(([x, y, z]) => x * th[0] + y * th[1] >= z - 1e-9);
    const cost = 100 * (th[0] + th[1]);
    if (ok && (!best || cost < best.cost)) best = { th, cost };
  }
  return best;
}
const states = [[120, 105, 110], [100, 105, 100], [70, 105, 80]];
console.log(cheapest(states));                      // (0.5, 0.476), 97.62
console.log(cheapest([...states, [40, 105, 80]])); // (0.375, 0.619), 99.40
const corners = [[0, 0], [10, 0], [0, 5]];
console.log(corners.map(c => dot([3, 2], c)));    // 0 30 10

สิ่งที่ควรตอบได้หลังอ่าน

  • แยก linear ($f(0)=0$ ขยายตามแผน) ออกจาก affine (มีส่วนคงที่) และได้ 1.125 ไม่ใช่ 1.25 ในโจทย์เปิด
  • มอง $a^{\mathsf T}x=b$ เป็นเส้นที่ $a$ ตั้งฉาก และ $a^{\mathsf T}x\le b$ เป็นครึ่งระนาบ แล้วซ้อนหลายข้อเป็น $Gx\le h$
  • ตรวจแผนด้วย slack ทีละแถว และแยก slack (หน่วยวงเงิน) ออกจากระยะ (หาร $\|a\|$)
  • เขียนโจทย์ hedge เป็น $S\boldsymbol\theta\ge X$ และเห็นว่าผ่านกฎกับถูกที่สุดเป็นคนละคำถาม (\$100 กับ \$97.62)
  • อธิบายว่าทำไม feasible region เป็น convex และทำไมค่าดีที่สุดของเป้าหมาย linear บนบริเวณที่มีขอบเขตอยู่ที่มุม

ขั้นการ hedge ในหน้านี้ถามว่า “ผ่านไหม” หน้าถัดไป Rank, Range, and Invertibility ถามคำถามที่เข้มกว่า: สร้าง payoff ที่ต้องการได้พอดีไหม มีวิธีเดียวหรือหลายวิธี และถ้าข้อมูลขยับนิดเดียว คำตอบกระโดดแค่ไหน
