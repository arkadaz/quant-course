8.7 The MVN Conditional Distribution and the Hedge Ratio

อัปเดตเมื่อมีข้อมูล กับเลือก hedge ก่อนเกิดผลตอบแทน: ใช้ slope เดียวกัน แต่เป็นคนละงาน

ถือ QQQ มูลค่า \$10 ล้าน ในโมเดลสมมติที่ QQQ มี daily SD 3%, SPX มี SD 2% และ correlation 0.40 ถ้าจะลด variance ด้วย hedge ที่อ้างอิง SPX ควร short notional \$4 ล้าน ตาม correlation หรือ \$6 ล้าน? ขนาดนี้รับประกันไม่ขาดทุนหรือไม่?

ลองตอบก่อนเปิดเฉลย

Unconstrained minimum-variance hedge คือ \$6 ล้าน เพราะ $\beta=\rho\sigma_Y/\sigma_X=0.40(3/2)=0.60$ ไม่ใช่ 0.40 ความเสี่ยงยังเหลือ SD ประมาณ 2.7495% ของมูลค่า QQQ เดิม ไม่มีการรับประกันกำไร และต้องวาง hedge ก่อน return ของช่วงนั้นเกิดขึ้น

เริ่มจากระบุว่า X คือข้อมูลของช่วงไหน

ในตัวอย่างหลัก X คือ SPX return และ Y คือ QQQ return ของช่วงหนึ่งวันเดียวกัน การถามว่า Y เป็นอย่างไรเมื่อรู้ X เป็นโจทย์ข้อมูลร่วม ไม่ใช่การใช้ X วันนี้ทำนาย Y พรุ่งนี้โดยอัตโนมัติ หากจะถามข้ามวัน ต้องสร้างและตรวจโมเดลของคู่ข้ามวันนั้นแยกต่างหาก

SPX เป็นดัชนี ไม่ใช่หลักทรัพย์ที่สั่ง short ได้โดยตรง คำว่า hedge อ้างอิง SPX ในตัวอย่างหมายถึงเครื่องมือซื้อขายได้ที่สมมติให้ return ตรงกับ X โดยยังละ basis risk, ค่าธรรมเนียม, ดอกเบี้ย และข้อจำกัดการซื้อขายออกก่อน

ศัพท์ที่จะใช้
Conditional mean
Mean ของ Y หลังให้ข้อมูล X=x ไม่ใช่ผลลัพธ์จริงที่ Y ต้องเท่ากับค่านี้
Innovation
ส่วนที่ X ต่างจาก mean ของมัน คือ $x-\mu_X$ ใช้อัปเดต mean ของ Y; แม้ innovation เป็นศูนย์ การรู้ X ก็ยังให้ข้อมูลเกี่ยวกับความไม่แน่นอน
Residual
ส่วนของ Y ที่เหลือหลังหักการคาดการณ์จาก X; การไม่ correlated กับ X ไม่รับประกัน independence หากไม่ได้มี joint Gaussianity
Hedge ratio
Coefficient b ใน $Y-bX$ เมื่อทั้งคู่เป็น returns หน่วยเดียวกันและช่วงเดียวกัน b จึงแปลงเป็น notional hedge ต่อ notional ของ target ได้ภายใต้สมมติฐานที่ระบุ
Schur complement
Matrix $\Sigma_{YY}-\Sigma_{YX}\Sigma_{XX}^{-1}\Sigma_{XY}$ ซึ่งเป็น covariance ของ Gaussian residual ใน derivation นี้
กำหนดทิศของ regression ก่อนใช้ตัวเลข
สัญลักษณ์ความหมาย
$X,Y$X คือ observed/predictor หรือ hedge return; Y คือ target ที่ต้องการอธิบายหรือ hedge
$\Sigma_{XX},\Sigma_{YY}$Covariance ภายใน X และ Y; กรณี scalar คือ $\sigma_X^2,\sigma_Y^2$
$\Sigma_{YX}$Cross-covariance:แถวของ Y, คอลัมน์ของ X
$B,\beta$B คือ coefficient matrix; beta คือกรณี scalar
$V$มูลค่า target book เริ่มต้นใน USD; ผลตอบแทน hedge ในบทคิดต่อ V ไม่ใช่ต่อ gross exposure หรือ margin ที่วางจริง

ขั้นที่ 1 — สร้าง residual ที่ไม่ correlated กับข้อมูล

ให้คู่ vector $(X,Y)$ เป็น joint Gaussian ที่มี means $\mu_X,\mu_Y$ และ covariance blocks ตามชื่อข้างบน สมมติ $\Sigma_{XX}$ invertible กำหนด B ให้ $B\Sigma_{XX}=\Sigma_{YX}$ แล้วหักส่วนที่อธิบายจาก X ออกจาก Y

\[ \begin{aligned} B&:=\Sigma_{YX}\Sigma_{XX}^{-1},\\ \varepsilon&:=Y-\mu_Y-B(X-\mu_X),\\ \mathbb E[\varepsilon]&=0,\\ \operatorname{Cov}(\varepsilon,X) &=\Sigma_{YX}-B\Sigma_{XX}\\ &=0. \end{aligned} \]

คู่ $(\varepsilon,X)$ ยังเป็น joint Gaussian เพราะสร้างด้วย affine transformation ดังนั้น covariance block ศูนย์จึงให้ independence ตาม 8.3 เมื่อรู้ X จึงไม่เปลี่ยน distribution ของ residual นี้

ในคอมพิวเตอร์ควรแก้ linear system เพื่อหา B แทนการสร้าง inverse แล้วคูณ โดยเฉพาะเมื่อ predictors หลายตัวเกือบซ้ำกัน เขียน inverse ในสูตรเพื่อระบุความสัมพันธ์ทางคณิตศาสตร์ ไม่ใช่สั่งให้คำนวณด้วยวิธีนั้นเสมอ

ขั้นที่ 2 — Conditional covariance คือ covariance ของ residual

ขยาย covariance ของผลต่าง แล้วใช้ $B\Sigma_{XX}=\Sigma_{YX}$ เพื่อลดรูป พจน์ที่เหลือเป็น PSD เพราะเป็น covariance ของตัวแปรสุ่มจริง

\[ \begin{aligned} \Omega&:=\operatorname{Cov}(\varepsilon)\\ &=\Sigma_{YY}-B\Sigma_{XY}\\ &\quad-\Sigma_{YX}B^{\mathsf T}+B\Sigma_{XX}B^{\mathsf T}\\ &=\Sigma_{YY}-B\Sigma_{XY},\\ m(x)&:=\mu_Y+B(x-\mu_X),\\ Y\mid X=x&\sim\mathcal N(m(x),\Omega). \end{aligned} \]

Conditional law จึงเป็น Gaussian ที่มี mean ตาม x และ covariance เท่ากับ Omega โดยใน fixed Gaussian model นี้ ค่า covariance ไม่ขึ้นกับ x ที่สังเกตได้ ไม่ใช่กฎว่า uncertainty ของข้อมูลจริงต้องคงที่ทุกสถานการณ์

Full covariance อาจเป็น PSD แต่ singular ได้: ถ้า Omega เป็นศูนย์บางทิศ Y ในทิศนั้นถูกกำหนดแน่นอนเมื่อรู้ X แล้ว แต่ถ้า $\Sigma_{XX}$ singular ต้องจัดการข้อมูลซ้ำและตรวจ support ก่อน เช่น predictors $(Z,Z)$ ต้องมีค่าที่สังเกตสอดคล้องกัน ไม่ควรใช้ pseudoinverse กลบ observation ที่โมเดลเกิดไม่ได้

ขั้นที่ 3 — ย่อเป็น scalar แล้วตรวจ denominator

เมื่อ X, Y เป็น scalar และ $\sigma_X\gt0$ เราเขียน covariance เป็น $\rho\sigma_X\sigma_Y$ แล้วเห็นทั้ง slope และส่วน variance ที่เหลือชัดเจน

\[ \begin{aligned} \beta&=\frac{\operatorname{Cov}(Y,X)}{\sigma_X^2}\\ &=\rho\frac{\sigma_Y}{\sigma_X},\\ m(x)&:=\mathbb E[Y\mid X=x]\\ &=\mu_Y+\beta(x-\mu_X),\\ v_{\rm res}&:=\operatorname{Var}(Y\mid X=x)\\ &=\sigma_Y^2-\frac{(\rho\sigma_X\sigma_Y)^2}{\sigma_X^2}\\ &=\sigma_Y^2(1-\rho^2),\\ \sigma_{\rm res}&=\sigma_Y\sqrt{1-\rho^2}. \end{aligned} \]

Denominator เป็น variance ของ predictor/hedge X ไม่ใช่ variance ของ target Y Correlation บอกทิศและความแรงเชิงเส้นใน standardized units แต่ต้องคูณอัตราส่วน SD เพื่อกลับมาเป็น slope ในหน่วย Y ต่อ X

กลับทิศ regression แล้ว slope ไม่ใช่ reciprocal:ใน primary model นี้ $\beta_{Y\mid X}=0.60$ แต่ $\beta_{X\mid Y}=0.40(2/3)\approx0.266667$ ผลคูณเท่ากับ $\rho^2=0.16$ ไม่ใช่ 1 การมี residual ทำให้ไม่สามารถกลับสมการเหมือนเป็นความสัมพันธ์เชิงเส้นแบบแน่นอนได้

ขั้นที่ 4 — SPX ลง 3% บอกอะไรเกี่ยวกับ QQQ ของช่วงเดียวกัน

โจทย์ให้อะไรมาบ้าง: daily model มี $\mu_X=0.0004,\mu_Y=0.0003$, SDs 0.02 และ 0.03, correlation 0.40 และให้ข้อมูล $x=-0.03$ ตัวเลขทั้งหมดในสูตรนี้เป็น decimal returns

\[ \begin{aligned} \beta&=0.40(0.03/0.02)=0.60,\\ x-\mu_X&=-0.03-0.0004=-0.0304,\\ m(x)&=0.0003+0.60(-0.0304)\\ &=-0.01794=-1.794\%,\\ v_{\rm res}&=0.03^2(1-0.40^2)=0.000756,\\ \sigma_{\rm res}&=\sqrt{0.000756}\approx2.7495\%. \end{aligned} \]

คำตอบ: mean QQQ เปลี่ยนจาก +0.03% เป็น −1.794% ส่วน SD จาก 3% เหลือประมาณ 2.7495% ยังมี uncertainty มาก ไม่ใช่คำทำนายว่า QQQ ต้องปิดตรง mean

ตรวจเองใน 10 วินาที: variance ลด 16% แต่ SD ลดเพียง $1-\sqrt{0.84}\approx8.35\%$ และต้องหัก mean ของ X ก่อนคูณ beta ไม่ใช่แทน innovation ด้วย x เฉย ๆ

Conditioning ที่ค่าแน่นอนของตัวแปรต่อเนื่องใช้นิยามผ่าน density/regular conditional law หรือขีดจำกัดของช่วงแคบ ไม่ใช่หารด้วย $P(X=x)$ ซึ่งเป็นศูนย์ ตัวอย่างนี้เป็นเรื่องข้อมูลของช่วงเดียวกัน ไม่ได้สร้างสิทธิให้เทรดย้อนเวลากลับไปก่อน SPX ลง

ขั้นที่ 5 — หา hedge ด้วย variance โดยไม่ต้องสมมติ Gaussian

คราวนี้เลือก b ก่อน returns เกิด ให้ target P&L หลัง hedge เท่ากับ $V(Y-bX)$ ก่อนต้นทุน โดยทั้ง X, Y เป็น returns ของช่วงเดียวกันและหน่วยเดียวกัน สมมติมี second moments finite กับ $\sigma_X^2\gt0$

\[ \begin{aligned} c&:=\operatorname{Cov}(Y,X),\\ v(b)&:=\operatorname{Var}(Y-bX)\\ &=\sigma_Y^2-2bc+b^2\sigma_X^2,\\ \beta&:=c/\sigma_X^2,\\ v(b)&=\sigma_X^2(b-\beta)^2\\ &\quad+\sigma_Y^2-\beta^2\sigma_X^2,\\ b^*&=\beta,\\ v(b^*)&=\sigma_Y^2(1-\rho^2). \end{aligned} \]

พจน์กำลังสองไม่ติดลบและต่ำสุดที่ b=beta จึงได้ unique unconstrained minimum นี่เป็นผลเรื่อง second moments ไม่ต้องใช้ joint Normal ส่วนการเรียก variance นี้ว่า conditional variance ของ Y ทุกค่า x ต้องมีเงื่อนไขเพิ่มแบบที่พิสูจน์ในขั้นที่ 1–2

สำหรับ QQQ \$10 ล้าน, ให้ b=0.60 จึง short SPX-linked instrument notional \$6 ล้าน ตามโมเดลอุดมคติ หากลอง b=0.30,0.60,0.90 จะได้ variances 0.000792,0.000756,0.000792 ตามลำดับ จึงเห็น minimum ไม่ใช่แค่จำสูตร beta

ถ้า covariance ติดลบ beta ก็ติดลบ: การลบ $bX$ กลายเป็นถือ X เพิ่ม ไม่ใช่ short หากข้อจำกัดบังคับ short เท่านั้นหรือจำกัด notional ต้องแก้ปัญหาที่มีข้อจำกัด ไม่ใช่เรียก beta เดิมว่า optimum ภายใต้ข้อจำกัดใหม่

ใช้ coefficient เดียวกัน ไม่ได้ทำให้สองงานเป็นงานเดียวกัน

งานรู้/ทำอะไรเมื่อไรผลที่อ่านได้
วาง hedgeเลือก b ก่อน X, Y ของช่วงนั้นเกิดเปลี่ยน payoff เป็น $Y-bX$ และลด ex-ante variance ภายใต้โมเดล
Conditionมีข้อมูล X=x แล้ว ถาม Y ของคู่ที่กำหนดไว้เปลี่ยนข้อมูลที่ใช้ประเมิน Y ไม่ได้สร้าง hedge ย้อนหลัง
Forecast ข้ามเวลากำหนดคู่ $X_t,Y_{t+1}$ และ fit ความสัมพันธ์นั้นใช้ past observation กับ future target ได้เมื่อโมเดลรองรับ ไม่ใช่เอา same-day covariance มาสวม

ถ้ารู้ X=x แล้ว การหักค่าคงที่ bx ไม่ลด $\operatorname{Var}(Y\mid X=x)$ เพิ่ม เพราะ X ไม่สุ่มอีกใน conditional question นั้น การลด ex-ante variance ของ hedge เกิดจากออกแบบ payoff ของสอง legs ก่อนผลตอบแทนเกิด ไม่ใช่จากหักเลขที่รู้แล้วภายหลัง

ขั้นที่ 6 — สมมติโมเดลข้ามวันให้ชัด แล้วดู VaR ที่อาจแย่ลง

โจทย์ให้อะไรมาบ้าง: กำหนด hypothetical lagged model โดย $X_t$ คือ S&P 500 return วันนี้ และ $Y_{t+1}$ คือ Russell 2000 return พรุ่งนี้ ใช้หน่วย percentage points:means 0 และ 0.03, SDs 1.20 และ 1.00, lagged correlation 0.70 ตัวเลขนี้เป็นสมมติฐานฝึกคำนวณ ไม่ใช่ผลวัด predictive correlation ของตลาด

หากค่าที่คุณมีเป็น correlation ของ returns วันเดียวกัน ตัวอย่างนี้ใช้ทำนายวันถัดไปไม่ได้ ต้องประมาณและทดสอบคู่ข้ามวันจริง รวมถึงแยก training period กับช่วงทดสอบ

\[ \begin{aligned} x&=-2\quad\text{percentage points},\\ \beta&=0.70(1/1.20)=7/12,\\ m(x)&=0.03+(7/12)(-2-0)\\ &=-1.136667,\\ v_{\rm res}&=1^2(1-0.70^2)=0.51,\\ \sigma_{\rm res}&=\sqrt{0.51}\approx0.714143,\\ P(Y\lt0)&=\Phi(-0.03)\approx48.8034\%,\\ p_*&:=P(Y\lt0\mid X=-2),\\ p_*&=\Phi\left(\frac{1.136667}{0.714143}\right)\\ &\approx94.4269\%. \end{aligned} \]

คำตอบ: conditional variance ลด 49%, SD ลดประมาณ 28.59% แต่ mean ติดลบมากขึ้นจนโอกาสขาดทุนในโมเดลสูงขึ้น ไม่ควรดูแค่ variance แล้วสรุปว่าทุก risk metric ดีขึ้น

ตรวจเองใน 10 วินาที: เปลี่ยนเกณฑ์เป็น return ต่ำกว่า −1% จะได้ probability เดิมประมาณ 15.15% และหลังข้อมูลประมาณ 57.59% แม้ส่วน SD ลดลงก็ตาม

กำหนด loss VaR 99% เป็น quantile 99% ของ loss ไม่ใช่ worst loss ใช้ $z_{0.99}\approx2.326347874$ จึงต้องแยก quantile ของ return ซึ่งอาจติดลบ ออกจาก VaR ใน USD

\[ \begin{aligned} q_{\rm pp}^{\rm prior}&=0.03-z_{0.99}(1)\\ &\approx-2.296347874,\\ q_{\rm pp}^{\rm cond}&=m(-2)-z_{0.99}\sqrt{0.51}\\ &\approx-2.798011351,\\ \operatorname{VaR}_{0.99}&=-V(q_{\rm pp}/100),\\ V&=100{,}000{,}000\ \mathrm{USD}. \end{aligned} \]

ที่นี่ $q_{\rm pp}$ คือค่าตัวเลขของ return quantile ในหน่วย percentage points จึงต้องหาร 100 ก่อนคูณ V เช่น −2.296347874 percentage points เท่ากับ decimal return −0.02296347874

ได้ loss VaR จากประมาณ \$2,296,348 เป็น \$2,798,011 เพิ่มราว \$501,663 หรือ 21.85% ตัวเลขเต็มใช้ quantile ที่ละเอียดกว่า 2.326 จึงอาจต่างเล็กน้อยจากคำตอบที่ปัดระหว่างทาง และยังเป็น risk measure ตามโมเดล ไม่ใช่ขอบเขตขาดทุนสูงสุด

ขั้นที่ 7 — แปลง beta เป็นเงิน โดยไม่สลับ predictor กับ target

โจทย์ให้อะไรมาบ้าง: อีกโมเดลหนึ่งของช่วงวันเดียวกัน: ถือ small-cap book Y มูลค่า \$100 ล้าน, hedge ด้วย Russell 2000 ETF X สมมติ $\mu_X=0.0003,\mu_Y=0.0005$, SDs 0.0120 และ 0.0155, correlation 0.82 ทั้งคู่เป็น decimal returns นี่ไม่ใช่ชุด parameters ข้ามวันเมื่อครู่

\[ \begin{aligned} c&:=\operatorname{Cov}(Y,X)\\ &=0.82(0.0120)(0.0155)=0.00015252,\\ \beta&=\frac{0.00015252}{0.0120^2}\\ &=1271/1200\approx1.059166667,\\ N_{\rm short}&=\beta V\\ &\approx105{,}916{,}666.67\ \mathrm{USD},\\ v_{\rm res}&=0.0155^2(1-0.82^2)\\ &=0.0000787059,\\ \sigma_{\rm res}&\approx0.8871635\%. \end{aligned} \]

คำตอบ: short notional ประมาณ \$105.917 ล้าน หากปัด beta เป็น 1.0592 ก่อนคูณ จะได้ \$105.920 ล้าน ซึ่งต่างราว \$3,333 ไม่ใช่ค่า exact เดียวกัน ที่ beta มากกว่าหนึ่งมาจากผลคูณ correlation กับ SD ratio ไม่ใช่เพียงรู้ว่า target มี SD สูงกว่า hedge

ตรวจเองใน 10 วินาที: ถ้าใช้ denominator ผิดเป็น $0.0155^2$ จะได้ประมาณ 0.634839 และ hedge น้อยกว่าที่โมเดลกำหนดราว 40.06% ส่วนการปัด covariance เป็น 0.00015 จะลด beta เหลือ 1.041667 ทำให้ short notional น้อยไป \$1.75 ล้าน

Variance ลด 67.24% แต่ SD ลด 42.7636% การรายงาน “ลดความเสี่ยง 67%” โดยไม่บอก metric จึงทำให้เข้าใจผิด และ notional short ที่มากกว่า NAV ยังต้องตรวจ margin, funding, availability และข้อจำกัดของ mandate ก่อนใช้จริง

หาก ETF return ของช่วงนั้นเป็น −3%, แบบจำลอง conditional ของ unhedged target ให้ mean กับช่วง prediction 95% ดังนี้ ไม่ใช่ช่วง confidence ของค่า mean

\[ \begin{aligned} m_*&:=m(-0.03)\\ &=0.0005+\beta(-0.03-0.0003)\\ &=-0.03159275=-3.159275\%,\\ P_*&:=\mathbb E[VY\mid X=-0.03]\\ &=-3{,}159{,}275\ \mathrm{USD},\\ z_{0.975}&\approx1.959963985,\\ I_{0.95}&:=m_*\pm z_{0.975}\sigma_{\rm res}\\ &\approx[-4.8981\%,\,-1.4205\%]. \end{aligned} \]

ภายใต้โมเดลที่ parameters ถูกต้องยังมี conditional probability 5% นอกช่วงนี้ และหากโมเดลผิด coverage จริงอาจต่างไปด้วย ส่วน book ที่ วาง hedge ไว้ก่อนแล้ว มี conditional mean หลัง hedge เท่ากับ $m(x)-\beta x=\mu_Y-\beta\mu_X$ ไม่ใช่ −3.159275% ของ unhedged target

ขั้นที่ 8 — เปรียบเทียบ VaR หลัง hedge ต้องใช้ mean หลัง hedgeด้วย

สำหรับ Gaussian same-period model ข้างบน payoff $H=Y-\beta X$ ยัง Gaussian ใช้ mean ใหม่กับ residual SD และคิด loss quantile ต่อ target NAV เดิม โดยยังละ funding/costs

\[ \begin{aligned} \mu_H&=\mu_Y-\beta\mu_X\\ &=0.0005-\beta(0.0003)\\ &=0.00018225,\\ L_{99}^{\rm prior}&:=V(z_{0.99}\sigma_Y-\mu_Y)\\ &\approx3{,}555{,}839\ \mathrm{USD},\\ L_{99}^{\rm hedge}&:=V(z_{0.99}\sigma_{\rm res}-\mu_H)\\ &\approx2{,}045{,}626\ \mathrm{USD},\\ \Delta L_{99}&\approx1{,}510{,}213\ \mathrm{USD}. \end{aligned} \]

นี่คือการลด modeled one-day loss VaR ไม่ใช่กำไร \$1.51 ล้าน ต่อวัน และไม่ได้บอกว่าจะถอนเงินทุนตามกฎกำกับได้เท่านี้ทันที การใช้ mean ของ unhedged target กับ SD ของ hedged payoff เป็นการผสมสองพอร์ต

Minimum-variance hedge ไม่จำเป็นต้องเป็น hedge ที่ลด VaR ได้มากที่สุดเมื่อ means, costs หรือ constraints สำคัญ เช่นหากจำกัด short notional ไม่เกิน \$100 ล้าน ต้องใช้ $b\le1$; ในตัวอย่างนี้ optimum ภายใต้ขอบเขตดังกล่าวอยู่ที่ b=1 ให้ SD 0.8900% แทน 0.8872%

คำรับรองทางพีชคณิตไปได้ไกลแค่ไหน

  • Outside Gaussian: ให้ X เป็น standard Normal และ $Y=X^2$ จะได้ covariance ศูนย์และ best linear hedge beta ศูนย์ แต่ $\mathbb E[Y\mid X=x]=x^2$ และ conditional variance เป็นศูนย์ ไม่ใช่ residual variance 2 ของ linear fit
  • Time alignment: same-period hedge, conditional inference และ lagged forecast ต้องมีวันที่/ช่วงถือครองถูกคู่ ความสัมพันธ์ร่วมไม่ได้ยืนยันเหตุและผลหรือให้ข้อมูลอนาคตฟรี
  • Estimated parameters: covariance ที่ประมาณมี error และเปลี่ยนได้ตาม regime เส้น Gaussian ที่สวยไม่ใช่หลักฐานว่าความเสี่ยงในวิกฤตเท่าเดิม ต้องตรวจ stress, out-of-sample และ basis risk
  • Trading constraints: frictionless continuous notional เป็นโจทย์อุดมคติ; fees, funding, lot sizes, availability และ bounds อาจเปลี่ยนคำตอบ

Regression และ conditional Gaussian formulas อธิบายว่าทำไม linear hedge ใช้ covariance เดียวกับ linear prediction ได้ แต่ไม่มีเหตุผลให้ตีความ statistical slope เป็นผลเชิงสาเหตุ หรือให้เรียก VaR ว่า maximum loss

คำนวณซ้ำด้วย JavaScript

รันใน Node.js ได้โดยไม่ใช้แพ็กเกจ ทุกชุด parameters เป็นตัวอย่างสมมติ โค้ดไม่อาจตรวจว่าคุณจับคู่ return dates ถูกหรือว่าโมเดลเป็น Gaussian จริง การใช้ variance-only hedge ไม่ต้อง Gaussian แต่ loss probabilities, prediction intervals และ Gaussian VaR ต้องมีสมมติฐาน distribution เพิ่ม

Loss VaR ในโค้ดเป็น signed loss quantile ไม่ตัดค่าติดลบเป็นศูนย์ ส่วน covariance/variance ต้องคำนวณได้ใน Number โดยไม่ overflow/underflow ตัวอย่างแยก zero residual variance ที่ถูกต้องเมื่อ $|\rho|=1$ ออกจากศูนย์ที่เกิดจากเครื่องปัดเศษ

function finite(x) {
  if (!Number.isFinite(x)) throw new RangeError('Arithmetic overflow or invalid input');
  return x;
}
function model(muX, muY, sx, sy, rho) {
  if (![muX, muY, sx, sy, rho].every(Number.isFinite) || sx <= 0 || sy <= 0 || Math.abs(rho) > 1) {
    throw new RangeError('Need finite means, positive SDs and correlation in [-1,1]');
  }
  const vx = finite(sx * sx), vy = finite(sy * sy);
  if (vx === 0 || vy === 0) throw new RangeError('Variance underflow');
  const covariance = finite((rho * Math.max(sx, sy)) * Math.min(sx, sy));
  const beta = finite((rho * sy) / sx);
  const residualSD = finite(sy * Math.sqrt((1 - rho) * (1 + rho)));
  const residualVariance = finite(residualSD * residualSD);
  if (residualVariance === 0 && Math.abs(rho) !== 1) throw new RangeError('Residual variance underflow');
  const intercept = finite(muY - beta * muX);
  return {muX, muY, sx, sy, rho, vx, vy, covariance, beta, residualVariance, residualSD, intercept};
}
function conditional(m, x) {
  finite(x);
  return {mean: finite(m.muY + m.beta * finite(x - m.muX)), variance: m.residualVariance, sd: m.residualSD};
}
function hedge(m, b) {
  finite(b);
  const extra = finite(m.sx * finite(b - m.beta));
  const variance = finite(m.residualVariance + extra * extra);
  return {b, mean: finite(m.muY - b * m.muX), variance, sd: Math.sqrt(variance),
    covarianceWithX: finite((m.beta - b) * m.vx)};
}
function Phi(x) {
  if (!Number.isFinite(x) || Math.abs(x) > 6) throw new RangeError('CDF demo requires finite scores within 6');
  const n = 12000, h = Math.abs(x) / n;
  const phi = z => Math.exp(-.5 * z * z) / Math.sqrt(2 * Math.PI);
  let total = 0, correction = 0;
  for (let i = 0; i <= n; i++) {
    const term = (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h) - correction;
    const next = total + term;
    correction = (next - total) - term; total = next;
  }
  return .5 + Math.sign(x) * total * h / 3;
}
function probabilityBelow(bound, mean, sd) {
  if (![bound, mean, sd].every(Number.isFinite) || sd < 0) throw new RangeError('Invalid Normal threshold inputs');
  if (sd === 0) return Number(mean < bound); // Strict event, including deterministic endpoints.
  return Phi(finite((bound - mean) / sd));
}
const z99 = 2.3263478740408408, z975 = 1.959963984540054;
function lossVaR99(V, mean, sd) {
  if (![V, mean, sd].every(Number.isFinite) || V < 0 || sd < 0) throw new RangeError('Invalid VaR inputs');
  return finite(V * finite(z99 * sd - mean));
}
function twoPredictors(meanX, meanY, S, c, varianceY, observed) {
  const vector2 = v => Array.isArray(v) && v.length === 2 && [...v].every(Number.isFinite);
  if (!vector2(meanX) || !vector2(c) || !vector2(observed) || !Number.isFinite(meanY) ||
      !Number.isFinite(varianceY) || varianceY < 0 || !Array.isArray(S) || S.length !== 2 ||
      ![...S].every(vector2)) throw new TypeError('Need finite two-predictor inputs');
  const a = S[0][0], d = S[1][1], off = S[0][1];
  if (off !== S[1][0] || a <= 0 || d <= 0) throw new RangeError('Predictor covariance must be symmetric PD');
  const l11 = Math.sqrt(a), l21 = finite(off / l11), remainder = finite(d - l21 * l21);
  if (remainder <= 0) throw new RangeError('Predictor covariance must be symmetric PD');
  const l22 = Math.sqrt(remainder);
  const y1 = finite(c[0] / l11), y2 = finite((c[1] - l21 * y1) / l22);
  const b2 = finite(y2 / l22), b1 = finite((y1 - l21 * b2) / l11);
  const variance = finite(varianceY - (y1 * y1 + y2 * y2));
  if (variance < 0) throw new RangeError('Negative Schur complement: inspect covariance or numerical precision');
  const mean = finite(meanY + b1 * finite(observed[0] - meanX[0]) + b2 * finite(observed[1] - meanX[1]));
  return {beta: [b1, b2], mean, variance, sd: Math.sqrt(variance)};
}
const primary = model(.0004, .0003, .02, .03, .4);
const primaryGiven = conditional(primary, -.03), primaryHedge = hedge(primary, primary.beta);
const lagged = model(0, .03, 1.2, 1, .7); // Percentage points; hypothetical X_t and Y_(t+1).
const laggedGiven = conditional(lagged, -2), V = 1e8;
const laggedPriorVaR = lossVaR99(V, lagged.muY / 100, lagged.sy / 100);
const laggedConditionalVaR = lossVaR99(V, laggedGiven.mean / 100, laggedGiven.sd / 100);
const book = model(.0003, .0005, .012, .0155, .82);
const bookGiven = conditional(book, -.03), bookHedge = hedge(book, book.beta);
const beforeVaR = lossVaR99(V, book.muY, book.sy), afterVaR = lossVaR99(V, bookHedge.mean, bookHedge.sd);

สิ่งที่ควรตอบได้หลังอ่าน

  • Conditional Gaussian mean อัปเดตด้วย innovation $x-\mu_X$ ส่วน conditional covariance เป็น Schur complement และไม่ขึ้นกับ x ใน fixed model นี้
  • การกลับทิศ regression เปลี่ยน denominator; correlation ไม่เท่ากับ hedge ratio และ reverse slope ไม่ใช่ reciprocal โดยทั่วไป
  • Minimum-variance linear hedge ใช้ finite second moments ก็พอ แต่ conditional Normal probabilities/intervals ต้องมี distribution assumptions เพิ่ม
  • วาง hedge ก่อน returns เกิด, condition หลังได้รับข้อมูล และ forecast คู่ข้ามเวลาเป็นคนละงาน ต้องไม่สลับวันที่เพื่อสร้างข้อมูลอนาคต
  • ลด variance ไม่เท่ากับลด SD ในสัดส่วนเดียวกัน และ adverse mean อาจทำให้ VaR แย่ลงแม้ distribution แคบลง
  • แปลง beta เป็น notional ด้วยหน่วยและฐานเงินที่ตรงกัน; VaR reduction ไม่ใช่ profit, funding หรือ maximum-loss guarantee
