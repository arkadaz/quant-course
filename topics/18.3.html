18.3 Binomial Tree Pricing

ราคา option คือต้นทุนของพอร์ตหุ้นกับเงินกู้ที่จ่ายเงินเท่า option ทุกกิ่งของต้นไม้ ไม่ใช่ค่าเฉลี่ยของ payoff ตามโอกาสที่ใครคิดว่าหุ้นจะขึ้น

option คือสัญญาที่ให้ “สิทธิ์” แต่ไม่บังคับ แบบที่หน้านี้ใช้มากที่สุดคือ call ซึ่งเป็นสิทธิ์ซื้อหุ้นในวันข้างหน้า ในราคาที่ตกลงไว้ตั้งแต่วันนี้ ราคาที่ตกลงไว้นี้เรียกว่า strike ถ้าวันนั้นหุ้นแพงกว่า strike เจ้าของ call ซื้อหุ้นในราคา strike แล้วขายต่อในตลาด ได้ส่วนต่างเป็นกำไร ถ้าหุ้นถูกกว่า strike เขาก็แค่ไม่ใช้สิทธิ์ ได้ \$0 เงินที่ได้ตอนจบนี้เรียกว่า payoff คำถามของหน้านี้คือ สิทธิ์แบบนี้ควรมีราคาวันนี้เท่าไร

ลองดูหุ้นสองตัว ABC กับ XYZ ซึ่งเหมือนกันทุกอย่าง ยกเว้นความเห็นของนักวิเคราะห์ (ตัวเลขสมมติ):

  • ราคาวันนี้ \$100 ทั้งคู่
  • อีกหนึ่งช่วงเวลา ราคาของทั้งคู่จะเป็น \$110 หรือ \$90 เท่านั้น
  • นักวิเคราะห์บอกว่า ABC มีโอกาสขึ้น 99% แต่ XYZ มีโอกาสขึ้นแค่ 1%
  • เงินฝากธนาคารโต 1% ต่อช่วง คือฝาก \$1 วันนี้ ได้คืน \$1.01 ตอนจบช่วง
  • call ของแต่ละตัวมี strike \$100 จึงจ่าย $110-100=\$10$ ถ้าหุ้นขึ้น และจ่าย \$0 ถ้าหุ้นลง

วิธีที่คนส่วนใหญ่คิดก่อนคือ หา payoff เฉลี่ยตามโอกาส แล้วหารด้วย 1.01 เพื่อแปลงเงินตอนจบช่วงกลับเป็นเงินวันนี้ (การหารแบบนี้เรียกว่า “คิดลด”):

\[ \begin{aligned} \text{ABC}&:\ \frac{0.99\times10+0.01\times0}{1.01}=\$9.80,\\ \text{XYZ}&:\ \frac{0.01\times10+0.99\times0}{1.01}=\$0.10. \end{aligned} \]

ตามวิธีนี้ call ของ ABC แพงกว่าของ XYZ เกือบร้อยเท่า ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก call ทั้งสองตัวต้องราคาเท่ากันที่ \$5.45 เพราะเราสร้างของที่จ่ายเงินเหมือน call ทุกกรณีได้เอง: ซื้อหุ้นครึ่งหุ้น แล้วกู้เงิน \$44.5545 (ขั้นที่ 4 จะหาตัวเลขสองตัวนี้ให้ดู) ดูว่าตอนจบช่วงได้อะไร:

  • หุ้นขึ้น: ครึ่งหุ้นมีค่า $0.5\times110=\$55$ คืนเงินกู้พร้อมดอกเบี้ย $44.5545\times1.01=\$45$ เหลือ $55-45=\$10$ เท่ากับ call
  • หุ้นลง: ครึ่งหุ้นมีค่า $0.5\times90=\$45$ คืนหนี้ \$45 เหลือ \$0 เท่ากับ call

พอร์ตนี้มีต้นทุนวันนี้ $0.5\times100-44.5545=\$5.4455$ ถ้ามีคนยอมซื้อ call ของ ABC ที่ \$9.80 เราขายให้เขา แล้วใช้ \$5.4455 สร้างพอร์ตนี้ ไม่ว่าหุ้นจะไปทางไหน พอร์ตจ่ายเงินที่เราติดค้างเขาได้พอดี เราจึงเก็บ $9.8020-5.4455\approx\$4.36$ ได้แน่นอน

โอกาส 99% ไม่อยู่ในการคำนวณนี้เลย เพราะความเชื่อเรื่องทิศทางของหุ้นสะท้อนอยู่ในราคาหุ้นวันนี้แล้ว

ภาพรวมก่อนลงสูตร

ราคาหุ้นจริงขยับได้ทุกค่าและทุกเวลา จึงตั้งราคา option ได้ยาก หน้านี้เริ่มจากโลกที่ง่ายที่สุดก่อน คือในแต่ละช่วงเวลา ราคาหุ้นทำได้แค่สองอย่าง ขึ้นเป็น $u$ เท่า หรือลงเป็น $d$ เท่า ถ้าวาดทุกเส้นทางที่เป็นไปได้ จะได้รูปกิ่งไม้ที่แตกเป็นสองทางทุกช่วง จึงเรียกว่า binomial tree (ต้นไม้สองทาง) จุดที่กิ่งแตกออกแต่ละจุดเรียกว่าโหนด

ความคิดหลักมีข้อเดียว ถ้าเราหาพอร์ตที่ทำจากหุ้นกับเงินฝาก (หรือเงินกู้) ซึ่งตอนจบช่วงมีค่าเท่า option ในทุกกิ่งได้ option ก็ต้องราคาเท่าต้นทุนของพอร์ตนั้น เหตุผลคือของสองอย่างที่จ่ายเงินเท่ากันทุกกรณีต้องราคาเท่ากัน ถ้าราคาไม่เท่า คนจะซื้ออันที่ถูก ขายอันที่แพง แล้วเก็บส่วนต่างไปโดยไม่เสี่ยงเลย การเก็บเงินฟรีแบบนี้เรียกว่า arbitrage ส่วนพอร์ตที่จ่ายเงินเลียนแบบ option เรียกว่าพอร์ตเลียนแบบ (replicating portfolio)

ในการคำนวณนี้ โอกาสจริงที่หุ้นจะขึ้นไม่ถูกใช้เลย แต่ราคาที่ได้กลับเขียนได้เหมือน “ค่าเฉลี่ยของ payoff แล้วคิดลด” โดยใช้น้ำหนักชุดหนึ่งชื่อ $q$ ซึ่งคำนวณจาก $u$, $d$ และดอกเบี้ยเท่านั้น

หน้านี้คือฉบับเวลาเป็นช่วง ๆ ของพอร์ตเลียนแบบและสมการ Black–Scholes ซึ่งปรับพอร์ตทุกขณะ ในต้นไม้ แต่ละช่วงแก้แค่สมการสองตัวแปร ทุกตัวเลขจึงตรวจได้ด้วยเครื่องคิดเลข ลำดับเรื่องเป็นแบบนี้:

  • ขั้นที่ 1–5: ต้นไม้หนึ่งช่วง หาพอร์ตเลียนแบบ หาเงื่อนไขที่ตลาดไม่มีเงินฟรี และหาที่มาของ $q$
  • ขั้นที่ 6–8: ต่อเป็นต้นไม้สามช่วง คิดย้อนจากปลายทางมาหาวันนี้ และตรวจว่าพอร์ตไม่ต้องเติมเงินระหว่างทาง
  • ขั้นที่ 9–10: option แบบอเมริกันซึ่งใช้สิทธิ์ก่อนวันหมดอายุได้ สูตรปิดอย่าง Black–Scholes ตั้งราคาแบบนี้ไม่ได้ แต่ต้นไม้ทำได้ แล้วดูผลของปันผล
  • ขั้นที่ 11–13: เลือก $u$ กับ $d$ จากความผันผวนของหุ้นจริง แล้วดูต้นไม้ให้คำตอบเข้าใกล้ Black–Scholes
ศัพท์ที่ใช้ในหัวข้อนี้
Call, put, strike และ payoff
call คือสิทธิ์ซื้อหุ้นในราคาที่ตกลงไว้ ส่วน put คือสิทธิ์ขายหุ้นในราคาที่ตกลงไว้ ราคาที่ตกลงไว้นี้เรียกว่า strike ($K$) payoff คือเงินที่สิทธิ์นั้นจ่ายตอนใช้สิทธิ์ ถ้าหุ้นราคา $S$ call จ่าย $\max(S-K,0)$ และ put จ่าย $\max(K-S,0)$
Binomial tree (ต้นไม้สองทาง)
แบบจำลองที่ในแต่ละช่วง ราคาหุ้นคูณ $u$ (ขึ้น) หรือคูณ $d$ (ลง) ได้แค่สองทาง เราใช้มันเพราะแก้ด้วยพีชคณิตได้ทีละโหนด และเมื่อซอยช่วงให้ถี่พอ ก็ให้คำตอบใกล้แบบจำลองเวลาต่อเนื่อง
Replicating portfolio (พอร์ตเลียนแบบ)
พอร์ตที่ถือหุ้น $x$ หุ้น กับเงินฝาก $y$ ดอลลาร์ ($y$ ติดลบแปลว่ากู้) โดยเลือก $x$ กับ $y$ ให้จ่ายเงินเท่า option ในทุกกิ่ง ของสองอย่างที่จ่ายเท่ากันทุกกรณีต้องราคาเท่ากัน ต้นทุนของพอร์ตนี้จึงเป็นราคาของ option
Short (ชอร์ตหุ้น)
ยืมหุ้นจากคนอื่นมาขายวันนี้ แล้วซื้อคืนไปคืนเขาทีหลัง ได้เงินวันนี้ แต่ต้องจ่ายตามราคาหุ้นในวันที่คืน ในสูตร การชอร์ตคือ $x$ ติดลบ
Arbitrage แบบ A และแบบ B
แบบ A คือได้เงินวันนี้ และไม่มีทางเสียเงินในอนาคต แบบ B คือไม่ต้องจ่ายอะไรวันนี้ ไม่มีทางเสีย และมีโอกาสได้เงิน ราคาที่ถูกต้องต้องไม่เปิดช่องให้ทั้งสองแบบ
Risk-neutral probability ($q$)
น้ำหนักที่ทำให้ราคา option เขียนเป็นค่าเฉลี่ยของ payoff แล้วคิดลดด้วยดอกเบี้ย มันคำนวณจาก $u$, $d$ และ $R$ เท่านั้น ไม่ใช่โอกาสจริงที่หุ้นจะขึ้น
European และ American option
แบบยุโรปใช้สิทธิ์ได้แค่วันหมดอายุวันเดียว แบบอเมริกันใช้สิทธิ์ได้ทุกวันจนถึงวันหมดอายุ ต้นไม้ตั้งราคาแบบอเมริกันได้ โดยเทียบ “ใช้สิทธิ์เลย” กับ “ถือต่อ” ที่ทุกโหนด
Self-financing และ backward induction
self-financing คือปรับพอร์ตได้ทุกโหนด โดยไม่ต้องเติมเงินเข้าหรือดึงเงินออก backward induction คือเริ่มคิดจากปลายต้นไม้ ซึ่งรู้ payoff แน่นอน แล้วย้อนกลับมาทีละช่วงจนถึงวันนี้
ปันผล (dividend)
เงินสดที่บริษัทจ่ายให้คนถือหุ้น คนถือ option ไม่ได้เงินนี้ เพราะยังไม่ได้ถือหุ้นจริง

ขั้นที่ 1 — หนึ่งช่วงด้วยมือ: พอร์ตหุ้นกับเงินกู้ที่จ่ายเท่า call

เริ่มจากต้นไม้หนึ่งช่วงที่ตัวเลขคิดในใจได้ ก่อนกลับไปไขปริศนา ABC กับ XYZ ในขั้นที่ 4 ของที่รู้ (ตัวเลขสมมติ):

  • หุ้นราคาวันนี้ $S_0=\$100$ อีกหนึ่งช่วงจะเป็น \$120 หรือ \$90
  • เงินฝาก \$1 โตเป็น \$1.05 ในหนึ่งช่วง (ดอกเบี้ย 5% ต่อช่วง) จึงมีตัวคูณ $R=1.05$ ถ้ากู้ก็ต้องคืนในอัตราเดียวกัน
  • call strike $K=\$100$ จึงจ่าย $120-100=\$20$ ถ้าหุ้นขึ้น และจ่าย \$0 ถ้าหุ้นลง

เราไม่ทายว่าหุ้นจะไปทางไหน แต่หาพอร์ตที่ถือหุ้น $x$ หุ้น กับเงินฝาก $y$ ดอลลาร์ ซึ่งตอนจบช่วงมีค่าเท่า call ทั้งสองกิ่ง ตอนจบช่วง หุ้น $x$ หุ้นมีค่า $120x$ หรือ $90x$ ส่วนเงินฝากโตเป็น $1.05y$ ทั้งสองกิ่ง จึงได้สองสมการ สองตัวแปร:

\[ \begin{aligned} \text{up}&:\ 120x+1.05y=20,\\ \text{down}&:\ 90x+1.05y=0,\\ \text{up}-\text{down}&:\ 30x=20,\\ x&=\tfrac{20}{30}=\tfrac23,\\ y&=\frac{0-90x}{1.05}=\frac{-60}{1.05}\\ &=-57.1429,\\ C_0&=100x+y\\ &=66.6667-57.1429\\ &=9.5238. \end{aligned} \]

เงินฝากโตเท่ากันทั้งสองกิ่ง พอเอาสมการล่างไปลบสมการบน $y$ จึงหายไป เหลือแค่ $x$ ส่วนต่างของหุ้นระหว่างสองกิ่ง ($30x$) ต้องเท่ากับส่วนต่างของ call (\$20) พอร์ตที่ได้คือซื้อหุ้นสองในสามหุ้น และ $y$ ติดลบแปลว่ากู้เงิน \$57.1429 ตอนจบช่วงต้องคืน $57.1429\times1.05=\$60$ ตรวจทั้งสองกิ่ง:

  • หุ้นขึ้น: หุ้นมีค่า $\tfrac23\times120=\$80$ คืนหนี้แล้วเหลือ $80-60=\$20$ เท่ากับ call
  • หุ้นลง: หุ้นมีค่า $\tfrac23\times90=\$60$ คืนหนี้แล้วเหลือ $60-60=\$0$ เท่ากับ call

ต้นทุนวันนี้คือค่าหุ้นที่ซื้อ ลบเงินที่กู้มา ได้ \$9.5238 ถ้า $x$ ติดลบ จะแปลว่าต้องชอร์ตหุ้น (ยืมหุ้นมาขาย) ซึ่งเกิดกับ put

ทำไมราคาต้องเป็น \$9.5238 พอดี สมมติผู้ค้า (dealer) รายหนึ่งยอมซื้อ call จากเราที่ \$12 เราขายให้ แล้วใช้ \$9.5238 สร้างพอร์ตเลียนแบบ ตอนจบช่วง พอร์ตจ่ายเงินที่เราติดค้างผู้ซื้อ call ได้พอดีทุกกิ่ง เราจึงเหลือ $12-9.5238=\$2.4762$ ตั้งแต่วันนี้ ถ้าอีกรายยอมขาย call ให้เราที่ \$8 เราซื้อ แล้วทำพอร์ตกลับทาง (ชอร์ตหุ้น $\tfrac23$ หุ้น และฝากเงิน \$57.1429) ได้ $9.5238-8=\$1.5238$ วันนี้ ทั้งสองกรณีคือ arbitrage แบบ A: ได้เงินวันนี้ และไม่มีทางเสียทีหลัง ราคาที่ไม่เปิดช่องนี้มีค่าเดียวคือ \$9.5238

ในตลาดจริง กำไรก้อนนี้เป็นแค่เพดาน เพราะยังต้องหักต้นทุนการซื้อขาย ค่ายืมหุ้น และเงินที่ต้องวางเป็นหลักประกัน

ขั้นที่ 2 — ต้นไม้ต้องมี $d\lt R\lt u$ ไม่อย่างนั้นทั้งตลาดมีเงินฟรี

ก่อนตั้งราคา option ต้องเช็กก่อนว่าตัวต้นไม้เองสมเหตุสมผลไหม คือหุ้นกับเงินฝากเปิดช่องให้เก็บเงินฟรีหรือเปล่า ถ้าเปิด ราคาอะไรที่คำนวณต่อจากนี้ก็ไม่มีความหมาย มีสองกรณีที่ผิดปกติ:

  • เงินฝากแพ้หุ้นแม้ในกิ่งที่แย่ที่สุด ($R\le d$): กู้เงิน $S_0$ ดอลลาร์มาซื้อหุ้นหนึ่งหุ้น
  • เงินฝากชนะหุ้นแม้ในกิ่งที่ดีที่สุด ($R\ge u$): ชอร์ตหุ้นหนึ่งหุ้น (ยืมมาขาย ได้เงิน $S_0$) แล้วเอาเงินไปฝาก

ทั้งสองทางไม่ใช้เงินตัวเองเลย ต่อไปนี้ $V_0$ คือต้นทุนวันนี้ ส่วน $V_1^u$ กับ $V_1^d$ คือเงินที่เหลือตอนจบช่วงในกิ่งขึ้นและกิ่งลง ดูว่าได้อะไร:

\[ \begin{aligned} R\le d&:\ V_0=S_0-S_0=0,\\ V_1^u&=(u-R)S_0\gt 0,\\ V_1^d&=(d-R)S_0\ge 0,\\ R\ge u&:\ V_0=S_0-S_0=0,\\ V_1^u&=(R-u)S_0\ge 0,\\ V_1^d&=(R-d)S_0\gt 0. \end{aligned} \]

ในกรณีแรก ตอนจบช่วงเราถือหุ้นที่มีค่า $uS_0$ หรือ $dS_0$ และต้องคืนหนี้ $RS_0$ ทั้งสองกิ่ง ผลต่างจึงเป็น $(u-R)S_0$ กับ $(d-R)S_0$ ซึ่งไม่ติดลบเพราะ $R\le d\lt u$ กรณีที่สองกลับทางกัน เงินฝากโตเป็น $RS_0$ แล้วต้องซื้อหุ้นคืนในราคา $uS_0$ หรือ $dS_0$

ทั้งสองกรณีเป็น arbitrage แบบ B: ไม่ต้องจ่ายอะไรวันนี้ ไม่มีกิ่งไหนขาดทุน และมีกิ่งที่ได้เงินแน่ ๆ ตลาดจึงไม่มีช่องนี้ก็ต่อเมื่อ $d\lt R\lt u$ แปลว่าเงินฝากต้องโตเร็วกว่าหุ้นในกิ่งแย่ แต่ช้ากว่าหุ้นในกิ่งดี ต้นไม้ในขั้นที่ 1 มี $u=120/100=1.2$ และ $d=90/100=0.9$ จึงผ่าน เพราะ $0.9\lt 1.05\lt 1.2$

ขั้นที่ 3 — จัดรูปราคาเลียนแบบ แล้วน้ำหนัก $q$ โผล่ออกมาเอง

ขั้นที่ 1 แก้ด้วยตัวเลขเฉพาะ ต่อไปเราจะเจอต้นไม้อีกหลายต้น จึงควรแก้ครั้งเดียวในรูปทั่วไป แล้วใช้ซ้ำได้ทุกต้น ให้กิ่งขึ้นหุ้นเป็น $uS_0$ และ option จ่าย $C_u$ ส่วนกิ่งลงหุ้นเป็น $dS_0$ และ option จ่าย $C_d$ เงินฝาก $y$ โตเป็น $Ry$ ทั้งสองกิ่ง ตั้งสองสมการเหมือนเดิม แก้หา $x$ กับ $y$ แล้วรวมเป็นต้นทุนวันนี้ $C_0=xS_0+y$ ขั้นนี้ไม่ใส่สมมติฐานเรื่องโอกาสเลย เป็นแค่การจัดพีชคณิต

\[ \begin{aligned} \text{up}&:\ uS_0x+Ry=C_u,\\ \text{down}&:\ dS_0x+Ry=C_d,\\ xS_0&=\frac{C_u-C_d}{u-d},\\ y&=\frac1R\Big[C_d-\frac{d\,(C_u-C_d)}{u-d}\Big],\\ C_0&=xS_0+y\\ &=\frac1R\Big[\frac{(R-d)(C_u-C_d)}{u-d}+C_d\Big]\\ &=\frac1R\Big[\frac{R-d}{u-d}C_u+\frac{u-R}{u-d}C_d\Big],\\ q&=\frac{R-d}{u-d},\quad 1-q=\frac{u-R}{u-d},\\ C_0&=\frac1R\big[qC_u+(1-q)C_d\big]. \end{aligned} \]

$x$ มาจากการลบสองสมการแบบขั้นที่ 1 ส่วน $y$ มาจากการแทน $x$ ลงในสมการกิ่งลง ท่าที่ต้องสังเกตคือตอนรวม $xS_0+y$ เราเขียน $xS_0$ เป็น $\frac{R}{R}xS_0$ เพื่อให้ทุกพจน์มี $\frac1R$ อยู่ข้างหน้าเหมือนกัน แล้วรวมพจน์ที่มี $C_d$ เข้าด้วยกัน ได้ $C_d-\frac{(R-d)C_d}{u-d}=\frac{u-R}{u-d}C_d$

ผลที่ได้คือ $C_u$ กับ $C_d$ ถูกคูณด้วยตัวเลขสองตัว ซึ่งบวกกันได้ $\frac{(R-d)+(u-R)}{u-d}=1$ พอดี และเป็นบวกทั้งคู่เมื่อ $d\lt R\lt u$ (เงื่อนไขจากขั้นที่ 2) ตัวเลขคู่นี้จึงทำตัวเหมือนโอกาส เราตั้งชื่อว่า $q$ และ $1-q$ ราคาจึงเขียนเหมือน “ค่าเฉลี่ยของ payoff แล้วคิดลด” แต่ลำดับความคิดกลับกัน เราได้ราคาจากการเลียนแบบก่อน แล้วค่อยพบว่ามันมีรูปค่าเฉลี่ย

ลองกับต้นไม้ในขั้นที่ 1 ($u=1.2$, $d=0.9$, $R=1.05$):

\[ \begin{aligned} q&=\frac{1.05-0.9}{1.2-0.9}=\frac{0.15}{0.30}=0.5,\\ C_0&=\frac{0.5\times20+0.5\times0}{1.05}=9.5238,\\ qu+(1-q)d&=0.5\times1.2+0.5\times0.9\\ &=1.05=R. \end{aligned} \]

ราคาตรงกับขั้นที่ 1 แถวสุดท้ายบอกเรื่องที่น่าสนใจ: ถ้าถ่วงด้วย $q$ หุ้นโตเฉลี่ยเท่าเงินฝากพอดี เหมือนโลกที่ไม่มีใครขอผลตอบแทนเพิ่มเพื่อแลกกับความเสี่ยง ชื่อ risk-neutral (เป็นกลางต่อความเสี่ยง) มาจากตรงนี้ ผลนี้ใช้ได้ทั่วไป: มีน้ำหนักแบบ $q$ ที่เป็นบวกทุกกิ่ง ก็ต่อเมื่อตลาดไม่มี arbitrage ผลนี้ชื่อ first fundamental theorem of asset pricing

put (สิทธิ์ขาย) strike \$100 บนต้นไม้เดียวกันจ่าย \$0 เมื่อหุ้นขึ้นเป็น 120 และจ่าย $100-90=\$10$ เมื่อหุ้นลงเป็น 90 ใช้ $q$ เดิมได้:

\[ \begin{aligned} P_0&=\frac{0.5\times0+0.5\times10}{1.05}=4.7619,\\ x&=\frac{0-10}{120-90}=-\tfrac13,\\ C_0-P_0&=9.5238-4.7619=4.7619,\\ S_0-\frac{K}{R}&=100-\frac{100}{1.05}=4.7619. \end{aligned} \]

$x$ ติดลบแปลว่าพอร์ตเลียนแบบ put ต้องชอร์ตหุ้น สองแถวล่างเท่ากัน ตรงกับput–call parity: call ลบ put เท่ากับราคาหุ้นลบ strike ที่คิดลดแล้ว

ขั้นที่ 4 — ปริศนา ABC กับ XYZ

กลับมาที่ปริศนาตอนต้นหน้า ตอนนี้เรามีเครื่องมือครบแล้ว ทั้งพอร์ตเลียนแบบและ $q$ จึงคิดได้สองทางและเทียบกันได้

โจทย์ให้อะไรมาบ้าง:

  • หุ้นทั้งสองตัวราคาวันนี้ $S_0=\$100$ อีกหนึ่งช่วงเป็น \$110 หรือ \$90 จึงมี $u=110/100=1.1$ และ $d=90/100=0.9$
  • call strike \$100 จ่าย \$10 (หุ้นขึ้น) หรือ \$0 (หุ้นลง)
  • เงินฝากโต $R=1.01$ ต่อช่วง
  • โอกาสขึ้นจริง $p=0.99$ สำหรับ ABC และ $p=0.01$ สำหรับ XYZ

สามแถวแรกคือพอร์ตเลียนแบบ สองแถวถัดมาคือสูตร $q$ จากขั้นที่ 3 สองแถวล่างสุดคือวิธีที่ผิด ซึ่งคิดลดด้วยโอกาสจริง $p$ แล้วเรียกผลว่า $V_p$:

\[ \begin{aligned} x&=\frac{10-0}{110-90}=0.5,\\ y&=-\frac{0.5(90)}{1.01}=-44.5545,\\ C_0&=100x+y=50-44.5545\\ &=5.4455,\\ q&=\frac{1.01-0.9}{1.1-0.9}=0.55,\\ C_0&=\frac{0.55(10)}{1.01}=5.4455,\\ V_p^{\rm ABC}&=\frac{0.99(10)}{1.01}=9.8020,\\ V_p^{\rm XYZ}&=\frac{0.01(10)}{1.01}=0.0990. \end{aligned} \]

คำตอบ: call ทั้งสองตัวราคา \$5.4455 เพราะพอร์ตเลียนแบบของทั้งสองตัวเหมือนกันทุกตัวเลข และไม่มี $p$ อยู่ในการคำนวณเลย ถ้ามีคนยอมซื้อ call ของ ABC ที่ \$9.8020 เราขายให้ แล้วสร้างพอร์ตเลียนแบบด้วย \$5.4455 เก็บส่วนต่าง $9.8020-5.4455\approx\$4.36$ ได้แน่นอน

ตรวจเองใน 10 วินาที: สูตร $q$ ใช้แค่ $R=1.01$, $u=1.1$ และ $d=0.9$ ไม่มี $p$ เลย ส่วนที่ดูแปลกเพราะโจทย์ตั้งผิดตั้งแต่ต้น ถ้าตลาดเชื่อจริงว่า ABC ขึ้นแน่ ราคาหุ้น ABC วันนี้คงไม่ใช่ \$100 เท่ากับ XYZ ความเชื่อเรื่องทิศทางจึงอยู่ในราคาหุ้นวันนี้แล้ว option ไม่ต้องนับซ้ำ ในเวลาต่อเนื่องก็เป็นแบบเดียวกัน drift $\mu$ (อัตราที่ราคาหุ้นโตเฉลี่ยต่อปี) ไม่อยู่ในสูตร Black–Scholes ด้วยเหตุผลเดียวกับที่ $p$ ไม่อยู่ในต้นไม้

ขั้นที่ 5 — ต้นไม้ 107 กับ 93.46: strike สามค่า

ต้นไม้ในขั้นต่อ ๆ ไปใช้หุ้นที่ขึ้น 7% หรือลงกลับในสัดส่วนเดียวกัน ขั้นนี้ฝึกกับต้นไม้นั้นหนึ่งช่วงก่อน และดูว่าเกิดอะไรขึ้นเมื่อ strike อยู่ตรงขอบหรือนอกช่วงราคาหุ้น

โจทย์ให้อะไรมาบ้าง:

  • หุ้นราคาวันนี้ \$100 ขึ้นด้วย $u=1.07$ เป็น \$107 หรือลงด้วย $d=1/1.07=0.934579\approx0.9346$ เป็น \$93.46
  • เงินฝากโต $R=1.01$ ต่อช่วง
  • call สามตัว strike \$102, \$107 และ \$92

payoff ของแต่ละตัวคือ $\max(S-K,0)$ ที่ปลายสองกิ่ง:

  • $K=102$: กิ่งขึ้น $107-102=\$5$ กิ่งลง \$0
  • $K=107$: กิ่งขึ้น $107-107=\$0$ กิ่งลง \$0
  • $K=92$: กิ่งขึ้น $107-92=\$15$ กิ่งลง $93.46-92=\$1.46$

ตั้งสมการพอร์ตเลียนแบบของ strike 102 แบบขั้นที่ 1 แล้วหา $q$ ไว้ตรวจ แถวท้าย ๆ เป็นของ strike 107 และ 92 ซึ่งคิดง่ายกว่ามาก:

\[ \begin{aligned} \text{up}&:\ 107x+1.01y=5,\\ \text{down}&:\ 93.46x+1.01y=0,\\ x&=\frac{5}{13.54}=0.369276,\\ y&=-\frac{93.46x}{1.01}=-34.1708,\\ C_0(102)&=100x+y\\ &=36.9276-34.1708=2.76,\\ q&=\frac{1.01-0.9346}{1.07-0.9346}\\ &=0.5569,\\ C_0(107)&=0,\\ x(92)&=\frac{15-1.46}{107-93.46}=1,\\ C_0(92)&=100-\frac{92}{1.01}=8.91. \end{aligned} \]

คำตอบ: \$2.76, \$0 และ \$8.91 strike 107 เท่ากับราคาหุ้นในกิ่งขึ้นพอดี call จึงจ่ายศูนย์ทั้งสองกิ่ง ราคาจึงเป็นศูนย์ strike 92 ต่ำกว่าราคาหุ้นทั้งสองกิ่ง call ถูกใช้สิทธิ์แน่นอน payoff จึงเท่ากับ $S-92$ ทุกกิ่ง พอร์ตเลียนแบบคือถือหุ้นหนึ่งหุ้นเต็ม ($x=1$) แล้วกู้เงิน $92/1.01$ ซึ่งตอนจบช่วงต้องคืนพอดี \$92 แบบนี้ไม่ต้องใช้ $q$ เลย

ตรวจเองใน 10 วินาที: ใช้ $q$ กับ strike 102 ได้ $\frac{0.5569\times5}{1.01}=2.76$ ตรงกับพอร์ตเลียนแบบ ถ้าใช้ $d=1/1.07$ แบบไม่ปัด เงินกู้จะเป็น \$34.1649 แทน \$34.1708 แต่ราคาปัดแล้วยังเป็น \$2.76

ขั้นที่ 6 — ต่อเป็นสามช่วง: ย้อนทีละโหนด หรือถ่วงปลายทางครั้งเดียว

option จริงมีอายุยาวกว่าหนึ่งช่วง และระหว่างทางหุ้นขึ้นลงได้หลายครั้ง เราจึงต่อต้นไม้หนึ่งช่วงหลายต้นเข้าด้วยกัน แต่ละโหนดคือต้นไม้หนึ่งช่วงหนึ่งต้น จึงใช้สูตร $q$ เดิมได้ทุกโหนด ปัญหาคือเรารู้ payoff แน่นอนแค่ที่ปลายทาง จึงต้องเริ่มคิดจากปลายทาง แล้วย้อนกลับมาทีละช่วงจนถึงวันนี้ (backward induction)

ของที่รู้:

  • หุ้นราคาวันนี้ $S_0=\$100$ แต่ละช่วงคูณ $u=1.07$ หรือ $d=1/1.07$
  • เงินฝากโต $R=1.01$ ต่อช่วง
  • call strike $K=\$100$ หมดอายุตอนจบช่วงที่ 3
  • น้ำหนัก $q=\dfrac{1.01-0.934579}{1.07-0.934579}=\dfrac{0.075421}{0.135421}=0.556936$

หลังสามช่วง หุ้นอยู่ได้สี่ราคา ตามจำนวนครั้งที่ขึ้น: $100\times1.07^3=122.5043$, $100\times1.07=107$, $100/1.07=93.4579$ และ $100/1.07^3=81.6298$ (ขึ้นแล้วลงหักล้างกัน เพราะ $ud=1$) call จ่าย $\max(S-100,0)$ จึงได้ $C_3$ ในแถวแรก ตัวห้อยบอกเส้นทาง เช่น $C_{ud}$ คือค่า call หลังขึ้นหนึ่งครั้ง ลงหนึ่งครั้ง:

\[ \begin{aligned} C_3&=22.5043,\ 7,\ 0,\ 0,\\ C_{uu}&=\frac{q(22.5043)+(1-q)7}{1.01}\\ &=15.4801,\\ C_{ud}&=\frac{q(7)+(1-q)0}{1.01}\\ &=3.8600,\\ C_{dd}&=0,\\ C_u&=\frac{q(15.4801)+(1-q)3.86}{1.01}\\ &=10.2293,\\ C_d&=\frac{q(3.86)+(1-q)0}{1.01}\\ &=2.1285,\\ C_0&=\frac{q(10.2293)+(1-q)2.1285}{1.01}\\ &=6.5744. \end{aligned} \]

มีอีกทางที่ไม่ต้องหาค่ากลางทางเลย คือถ่วง payoff ปลายทางทุกตัวในครั้งเดียว แล้วคิดลดครั้งเดียวด้วย $R^n$ ($n$ คือจำนวนช่วง):

\[ \begin{aligned} C_0&=\frac{1}{R^n}\sum_{j=0}^{n}\binom nj q^j(1-q)^{n-j}\\ &\qquad\times\max(S_0u^jd^{n-j}-K,0),\\ q^3&=0.172749,\\ 3q^2(1-q)&=0.412286,\\ C_0&=\frac{0.172749(22.5043)+0.412286(7)}{1.01^3}\\ &=\frac{3.8876+2.8860}{1.030301}\\ &=6.5744. \end{aligned} \]

ทำไมถ่วงครั้งเดียวได้ เพราะน้ำหนักของเส้นทางหนึ่งเส้นคือผลคูณของน้ำหนักตามกิ่งที่ผ่าน เส้นทางที่ขึ้น $j$ ครั้งจาก $n$ ครั้งมีน้ำหนัก $q^j(1-q)^{n-j}$ และมีเส้นทางแบบนี้ $\binom nj$ เส้น (เลือกว่าช่วงไหนเป็นช่วงขึ้น) ส่วนการหารด้วย 1.01 ทีละช่วงสามครั้ง ก็เท่ากับหารด้วย $1.01^3=1.030301$ ครั้งเดียว

ในต้นไม้นี้ ปลายบนสุดต้องขึ้นสามครั้ง มีเส้นทางเดียว น้ำหนัก $q^3$ ปลายที่สองขึ้นสองครั้งลงหนึ่งครั้ง มีสามเส้นทาง (ลง ตอนช่วงที่ 1, 2 หรือ 3) น้ำหนักรวม $3q^2(1-q)$ สองปลายล่างจ่ายศูนย์ จึงไม่ต้องคิด ทั้งสองวิธีได้ \$6.5744 ตรงกัน

ระวังการปัดเลข ปลายบนสุดคือ $100\times1.07^3=122.5043$ ไม่ใช่ 122.50 ถ้าใช้ payoff 22.50 จะได้ราคา 6.5737 แทน 6.5744 ต่างกันน้อย แต่พอทำให้สองวิธีไม่ตรงกันในหลักที่สี่

ขั้นที่ 7 — พอร์ตเลียนแบบทีละโหนด และตรวจว่าไม่ต้องเติมเงิน

ในต้นไม้สามช่วง พอร์ตเลียนแบบไม่ได้ซื้อครั้งเดียวแล้วจบ ทุกครั้งที่หุ้นขยับไปโหนดใหม่ ต้องปรับจำนวนหุ้นให้ตรงกับต้นไม้หนึ่งช่วงต้นถัดไป คำถามคือการปรับนี้ต้องใส่เงินเพิ่มหรือไม่ ถ้าต้องใส่ ราคา \$6.57 วันนี้ก็ยังไม่ใช่ต้นทุนทั้งหมด

ตัวแปรในขั้นนี้:

  • $x$ คือจำนวนหุ้น และ $y$ คือจำนวนหน่วยของบัญชีเงินฝาก หนึ่งหน่วยมีค่า $B_t=1.01^t$ ดอลลาร์ที่ช่วง $t$ เรานับเป็นหน่วยแทนดอลลาร์ เพราะจำนวนหน่วยไม่เปลี่ยนเองเมื่อดอกเบี้ยงอก
  • $x_1, y_1$ คือของที่ซื้อวันนี้ แล้วถือไปตลอดช่วงแรก วันนี้ $B_0=1$ หน่วยจึงเท่ากับดอลลาร์
  • $x_2, y_2$ คือของที่ปรับใหม่ที่โหนด “หุ้นขึ้นเป็น 107” ตอนจบช่วงแรก

จำนวนหุ้นใช้สูตร $xS_0=\frac{C_u-C_d}{u-d}$ ของขั้นที่ 3 ซึ่งอ่านได้อีกแบบว่า ผลต่างค่า call สองกิ่ง หารด้วยผลต่างราคาหุ้นสองกิ่ง ค่า call ทุกโหนดเอามาจากขั้นที่ 6:

\[ \begin{aligned} x_1&=\frac{10.2293-2.1285}{107-93.4579}\\ &=0.5982,\\ y_1&=6.5744-0.5982\times100\\ &=-53.2456,\\ x_2&=\frac{15.4801-3.8600}{114.49-100}\\ &=0.80194,\\ y_2&=\frac{10.2293-0.80194\times107}{1.01}\\ &=-74.8300,\\ V^{\rm old}&=0.5982\times107-53.2456\times1.01\\ &=10.23,\\ V^{\rm new}&=0.80194\times107-74.8300\times1.01\\ &=10.23,\\ V_{t+1}-V_t&=x_{t+1}(S_{t+1}-S_t)\\ &\quad+y_{t+1}(B_{t+1}-B_t). \end{aligned} \]

$V^{\rm old}$ คือค่าของพอร์ตเก่าตอนมาถึงโหนด 107 คือหุ้นเก่า 0.5982 หุ้นที่ตอนนี้ราคา \$107 บวกเงินฝาก $-53.2456$ หน่วย ซึ่งตอนนี้หน่วยละ $B_1=\$1.01$ ได้ \$10.23 เท่ากับค่า call ที่โหนดนั้นพอดี จากนั้นขายเงินฝาก (กู้เพิ่ม) ไปซื้อหุ้นจนมี 0.80194 หุ้น $V^{\rm new}$ คือค่าของพอร์ตใหม่ในวินาทีเดียวกัน ก็ยังเป็น \$10.23 แปลว่าไม่มีเงินไหลเข้าหรือออกตอนปรับพอร์ต นี่คือ self-financing และเป็นเหตุผลที่ \$6.57 วันนี้พอสำหรับทั้งต้นไม้

แถวสุดท้ายคือเงื่อนไขเดียวกันในรูปทั่วไป: ค่าพอร์ตเปลี่ยนได้จากสองทางเท่านั้น คือราคาหุ้นที่ถืออยู่ขยับ ($x_{t+1}(S_{t+1}-S_t)$) กับดอกเบี้ยของเงินฝากที่ถืออยู่ ($y_{t+1}(B_{t+1}-B_t)$) ไม่มีเงินเติมจากนอกพอร์ต

โหนดอื่นคำนวณแบบเดียวกัน (เขียนเป็น [หุ้น, หน่วยเงินฝาก]):

  • ช่วงที่ 1 โหนดล่าง (หุ้น 93.46): $[0.3050,\ -26.11]$
  • ช่วงที่ 2 โหนดบนสุด (หุ้น 114.49): $[1,\ -97.06]$
  • ช่วงที่ 2 โหนดกลาง (หุ้น 100): $[0.5169,\ -46.89]$
  • ช่วงที่ 2 โหนดล่างสุด (หุ้น 87.34): $[0,\ 0]$

ที่โหนดบนสุด หุ้นช่วงถัดไปเป็น 122.50 หรือ 107 ซึ่งเกิน strike ทั้งคู่ call จึงถูกใช้สิทธิ์แน่ พอร์ตเลียนแบบคือหุ้นหนึ่งหุ้นเต็ม กับเงินกู้ที่ตอนจบต้องคืน \$100 พอดี คิดเป็นหน่วยเงินฝากได้ $-\frac{100/1.01}{1.01^2}=-97.06$ ส่วนโหนดล่างสุด call ไม่มีทางมีค่า พอร์ตจึงว่างเปล่า

$x$ ในแต่ละโหนดคือ delta: จำนวนหุ้นที่ต้องถือต่อ option หนึ่งตัวเพื่อให้ค่าพอร์ตขยับตาม option หน้ากำไรขาดทุนของการ delta hedge จะตามเรื่องนี้ต่อ

ขั้นที่ 8 — ดอกเบี้ยสูงขึ้น call แพงขึ้น

ถ้าดอกเบี้ยเงินฝากสูงขึ้น ราคา call จะถูกลงหรือแพงขึ้น? คนส่วนใหญ่เดาว่าถูกลง เพราะต้องหารด้วยดอกเบี้ยที่สูงขึ้น ขั้นนี้ลองคำนวณดูจริง ๆ

โจทย์ให้อะไรมาบ้าง:

  • ต้นไม้สามช่วง หุ้นเริ่ม \$100 แต่ละช่วงคูณ $u=1.06$ หรือ $d=1/1.06$
  • call strike $K=\$95$ หมดอายุตอนจบช่วงที่ 3
  • ลองดอกเบี้ยสองค่า: $R=1.02$ และ $R=1.04$ ต่อช่วง

ปลายทางมีสี่ราคา: $100\times1.06^3=119.1016$, $100\times1.06=106$, $100/1.06=94.34$ และ $100/1.06^3=83.96$ call จ่าย $119.1016-95=24.1016$ กับ $106-95=11$ ส่วนสองปลายล่างต่ำกว่า 95 จึงจ่ายศูนย์ ใช้สูตรถ่วงครั้งเดียวของขั้นที่ 6:

\[ \begin{aligned} d&=\frac{1}{1.06}=0.943396,\\ u-d&=0.116604,\\ q(1.02)&=\frac{1.02-0.943396}{0.116604}\\ &=0.6570,\\ C_0(1.02)&=\frac{0.283539(24.1016)+0.444164(11)}{1.02^3}\\ &=\frac{6.8337+4.8858}{1.061208}=11.04,\\ q(1.04)&=\frac{1.04-0.943396}{0.116604}\\ &=0.8285,\\ C_0(1.04)&=\frac{0.568649(24.1016)+0.353184(11)}{1.04^3}\\ &=\frac{13.7054+3.8850}{1.124864}=15.64. \end{aligned} \]

ตัวเลข 0.283539 กับ 0.444164 คือ $q^3$ และ $3q^2(1-q)$ เมื่อ $q=0.656958$ ส่วน 0.568649 กับ 0.353184 คือค่าเดียวกันเมื่อ $q=0.828479$

คำตอบ: ดอกเบี้ยขึ้น ราคา call ขึ้นจาก \$11.04 เป็น \$15.64 แม้ตัวหารจะใหญ่ขึ้น เพราะ $q$ ขึ้นมาก น้ำหนักจึงเทไปทางปลายบนที่ call มีค่า เหตุผลทางเงินคือ คนถือ call ได้ประโยชน์จากหุ้นเหมือนคนถือหุ้น แต่ยังไม่ต้องจ่าย strike จนถึงวันหมดอายุ ระหว่างนั้นเงินที่ยังไม่ต้องจ่ายนี้เอาไปฝากได้ ดอกเบี้ยยิ่งสูง การได้จ่ายทีหลังยิ่งมีค่า

ตรวจเองใน 10 วินาที: ต้นไม้ราคาหุ้นเหมือนเดิมทั้งสองกรณี payoff ปลายทางจึงเท่าเดิม สิ่งเดียวที่เปลี่ยนคือ $R$ ซึ่งอยู่ทั้งในสูตร $q$ และในตัวหาร และผลผ่าน $q$ ชนะผลผ่านตัวหาร

ขั้นที่ 9 — option อเมริกัน: ทุกโหนดเลือกค่าที่มากกว่าระหว่างใช้เลยกับถือต่อ

ทุกขั้นที่ผ่านมาเป็น option แบบยุโรป ซึ่งใช้สิทธิ์ได้แค่วันหมดอายุ option ที่ซื้อขายจริงจำนวนมากเป็นแบบอเมริกัน ซึ่งใช้สิทธิ์เมื่อไรก็ได้จนถึงวันหมดอายุ คนถือจึงต้องตัดสินใจทุกโหนดว่าจะใช้สิทธิ์เลย หรือถือต่อ

เริ่มจากเกมที่เห็นภาพง่ายก่อน ทอยลูกเต๋าได้สูงสุดสามครั้ง หลังทอยแต่ละครั้ง จะหยุดแล้วรับเงินเท่าแต้มที่ออกก็ได้ หรือทิ้งแต้มนั้นแล้วทอยต่อก็ได้ ให้ $V_k$ คือค่าเฉลี่ยของเงินที่ได้ เมื่อยังเหลือสิทธิ์ทอย $k$ ครั้งและเล่นอย่างดีที่สุด กติกาการเล่นคือ หยุดเมื่อแต้มที่ออกมากกว่าค่าของการทอยต่อ คิดจากครั้งสุดท้ายย้อนกลับมา:

\[ \begin{aligned} V_1&=\tfrac16(1+2+\dots+6)=3.5,\\ V_2&=\tfrac16(4+5+6)\\ &\quad+\tfrac36(3.5)=4.25,\\ V_3&=\tfrac16(5+6)\\ &\quad+\tfrac46(4.25)=4.6667. \end{aligned} \]

put อเมริกันใช้ตรรกะเดียวกัน ใช้ต้นไม้สามช่วงของขั้นที่ 6 ($u=1.07$, $d=1/1.07$, $R=1.01$, $q=0.556936$) กับ put strike \$100 ซึ่งจ่าย $100-S$ ถ้าใช้สิทธิ์ตอนหุ้นราคา $S\lt100$ ที่ทุกโหนด เราเทียบสองค่า:

  • $E$ = ค่าถ้าใช้สิทธิ์เลย คือ $100-S$
  • $H$ = ค่าถ้าถือต่อ คือค่าเฉลี่ยถ่วง $q$ ของสองกิ่งถัดไป หารด้วย 1.01 แบบขั้นที่ 6

ค่าของ put อเมริกันที่โหนดนั้นคือค่าที่มากกว่าระหว่าง $E$ กับ $H$ เริ่มที่โหนดล่างสุดของช่วงที่ 2 ซึ่งหุ้นอยู่ที่ $100/1.07^2=87.3439$ สองกิ่งถัดไปคือหุ้น 93.4579 (put จ่าย $100-93.4579=6.5421$) และหุ้น 81.6298 (put จ่าย $100-81.6298=18.3702$):

\[ \begin{aligned} H_{dd}&=\big[q(6.5421)\\ &\quad+(1-q)(18.3702)\big]/1.01\\ &=11.67,\\ E_{dd}&=100-87.3439=12.66,\\ V_{dd}&=\max(E_{dd},H_{dd})=12.66,\\ H_d&=\big[q(2.8699)\\ &\quad+(1-q)(12.6561)\big]/1.01\\ &=7.13,\\ E_d&=100-93.4579=6.54,\\ P_0^{\rm Am}&=\big[q(1.2589)\\ &\quad+(1-q)(7.1345)\big]/1.01\\ &=3.82,\\ P_0^{\rm Eu}&=3.63. \end{aligned} \]

เกมลูกเต๋าก่อน เหลือทอยครั้งเดียว ต้องรับแต้มที่ออก ค่าเฉลี่ยจึงเป็น 3.5 เหลือสองครั้ง ถ้าครั้งแรกออก 4, 5 หรือ 6 ควรหยุด เพราะมากกว่า 3.5 ที่คาดว่าจะได้ถ้าทอยต่อ ถ้าออก 1, 2 หรือ 3 (สามในหกหน้า) ควรทอยต่อแล้วได้เฉลี่ย 3.5 จึงได้ $V_2=4.25$ เมื่อเหลือสามครั้ง เกณฑ์หยุดสูงขึ้นเป็น 4.25 จึงหยุดแค่เมื่อออก 5 หรือ 6 ยิ่งมีสิทธิ์ทอยมาก ค่าของเกมยิ่งสูง ถ้าทอยได้ 1,000 ครั้ง ค่าของเกมเข้าใกล้ 6 เพราะรอจน 6 ออกได้แทบแน่นอน

put ที่โหนดหุ้น 87.34 ถ้าถือต่อมีค่า \$11.67 แต่ใช้สิทธิ์ทันทีได้ \$12.66 จึงควรใช้ทันที เหตุผลคือ ใช้สิทธิ์เร็วได้รับเงิน \$100 เร็วขึ้น แล้วเอาไปฝากกินดอกเบี้ยได้ การรอมีข้อดีแค่ว่าหุ้นอาจลงต่อ แต่ที่โหนดนี้ ดอกเบี้ยที่ได้จากการรับเงินเร็วมีค่ามากกว่า ค่า 12.66 นี้ (แทน 11.67) ไหลย้อนไปที่โหนดหุ้น 93.46 ของช่วงที่ 1 ซึ่งถือต่อได้ \$7.13 มากกว่าใช้เลย \$6.54 จึงถือต่อ

ตัวเลข 2.8699 และ 1.2589 ในการคำนวณคือค่า put ที่โหนดหุ้น 100 ของช่วงที่ 2 และโหนดหุ้น 107 ของช่วงที่ 1 ซึ่งคิดด้วยวิธีเดียวกัน (สองโหนดนี้ถือต่อชนะ) ค่าทุกโหนดอยู่ในรูปด้านล่าง put ยุโรปคิดแบบเดียวกันแต่ไม่มีการเทียบใช้สิทธิ์เลย ได้ \$3.63 (ตรวจได้อีกทางด้วย put–call parity ในโจทย์ข้อ 2) put อเมริกันจึงแพงกว่า $3.82-3.63=\$0.19$

call บนหุ้นที่ไม่จ่ายปันผลไม่มีวันคุ้มที่จะใช้สิทธิ์ก่อน เหตุผลคือ พอร์ต “ถือหุ้นหนึ่งหุ้น และกู้เงิน $K/R^{n-t}$ ที่ตอนจบต้องคืน $K$” ไม่มีทางจ่ายดีกว่า call ค่าของการถือ call ต่อจึงไม่ต่ำกว่า $S_t-K/R^{n-t}$ ซึ่งมากกว่า $S_t-K$ ที่ได้ถ้าใช้สิทธิ์เลย เพราะ $R\gt1$

ขั้นที่ 10 — หุ้นที่จ่ายปันผล: $q$ เปลี่ยน และ call อเมริกันอาจถูกใช้สิทธิ์ก่อน

หลายบริษัทแบ่งกำไรเป็นเงินสดให้คนถือหุ้นเป็นระยะ เงินนี้เรียกว่าปันผล คนถือหุ้นได้ปันผล แต่คนถือ option ไม่ได้ เพราะยังไม่ได้ถือหุ้นจริง ปันผลจึงเปลี่ยนราคา option และอาจทำให้ call อเมริกันควรใช้สิทธิ์ก่อนกำหนด

สมมติหุ้นจ่ายปันผลทุกช่วง เป็นสัดส่วน $c$ ของราคาหุ้นตอนต้นช่วง ($c=0.01$ คือ 1%) ราคาในต้นไม้คือราคาหลังจ่ายปันผลแล้ว ตอนจบช่วง คนถือหุ้น $x$ หุ้นจึงได้ทั้งหุ้นที่มีค่า $uS_0x$ หรือ $dS_0x$ และเงินปันผล $cS_0x$ พอร์ตเลียนแบบต้องนับเงินปันผลนี้ด้วย ตั้งสมการเหมือนขั้นที่ 3 แล้วดูว่า $q$ กลายเป็นอะไร ตัวอย่างใช้ต้นไม้เดิม ($u=1.07$, $d=1/1.07$, $R=1.01$) กับปันผล $c=0.01$ ต่อช่วง:

\[ \begin{aligned} uS_0x+cS_0x+Ry&=C_u,\\ dS_0x+cS_0x+Ry&=C_d,\\ q_c&=\frac{R-d-c}{u-d},\\ q_c&=\frac{1.01-0.934579-0.01}{1.07-0.934579}\\ &=\frac{0.065421}{0.135421}=0.483092,\\ H_{uu}&=\frac{q_c(22.5043)+(1-q_c)7}{1.01}\\ &=14.3465,\\ E_{uu}&=114.49-100=14.49,\\ C_0^{\rm Eu}&=4.9214,\quad C_0^{\rm Am}=4.9542. \end{aligned} \]

ลบสองสมการแรก ปันผล $cS_0x$ หักล้างกันเหมือนเงินฝาก $x$ จึงเท่าเดิม แต่เงินที่ต้องกู้เปลี่ยน แก้ต่อแบบขั้นที่ 3 ได้สูตร $q_c$ ซึ่งมี $-c$ เพิ่มมาในตัวเศษ $q$ จึงลดจาก 0.5569 เป็น 0.4831 ทำไมต้องลด ตรวจได้ว่า

\[ \begin{aligned} q_cu+(1-q_c)d+c&=0.483092\times1.07\\ &\quad+0.516908\times0.934579\\ &\quad+0.01\\ &=1.01=R. \end{aligned} \]

แปลว่าใต้น้ำหนัก $q_c$ ผลตอบแทนรวมของหุ้น (ราคาที่ขยับบวกปันผล) ต้องโตเท่าเงินฝาก เมื่อปันผลกินส่วนหนึ่งไปแล้ว ราคาหุ้นอย่างเดียวจึงต้องโตช้ากว่า $q$ จึงเล็กลง เงื่อนไขไม่มีเงินฟรีของขั้นที่ 2 จึงกลายเป็น $d+c\lt R\lt u+c$ และ call ยุโรปถูกลงจาก \$6.57 เหลือ \$4.92

ที่โหนดบนสุดของช่วงที่ 2 (หุ้น 114.49) ถือ call ต่อมีค่า \$14.35 แต่ใช้สิทธิ์เลยได้ $114.49-100=\$14.49$ จึงควรใช้สิทธิ์เลย เหตุผลคือ ใช้สิทธิ์แล้วได้หุ้นมาถือทันรับปันผลงวดหน้า ประมาณ $0.01\times114.49=\$1.14$ ถ้าถือ call ต่อ จะไม่ได้เงินนี้ ค่าที่สูงขึ้นที่โหนดนี้ไหลย้อนกลับมาทีละช่วงแบบขั้นที่ 9 (ค่าทุกโหนดอยู่ในรูปด้านล่าง) จนถึงราก $C_0^{\rm Am}=\frac{q_c(8.6442)+(1-q_c)(1.6015)}{1.01}=4.9542$ ส่วน call ยุโรปซึ่งที่โหนดบนใช้ 14.3465 แทน 14.49 ได้ $\frac{q_c(8.5756)+(1-q_c)(1.6015)}{1.01}=4.9214$ call อเมริกันจึงแพงกว่ายุโรปเล็กน้อย ถ้าตั้ง $c=0$ ในต้นไม้เดียวกัน การถือต่อชนะทุกโหนด และ call อเมริกันเท่ากับยุโรปที่ \$6.57 พอดี ในต้นไม้นี้ ปันผลจึงเป็นเหตุผลเดียวที่ทำให้ call ถูกใช้สิทธิ์ก่อน กรณีปันผลที่จ่ายเป็นเงินก้อนในวันที่กำหนดจริง อยู่ในหน้าปันผลในสูตรราคา

ขั้นที่ 11 — $u$ กับ $d$ มาจากไหน: เลือกจากความผันผวน (CRR)

ตัวอย่างข้างบนเลือก $u$ และ $d$ ให้เลขสวย ถ้าจะใช้ต้นไม้กับหุ้นจริง สองตัวนี้ต้องมาจากสิ่งที่วัดได้ สิ่งที่วัดได้จากหุ้นจริงคือความผันผวน $\sigma$: SD ของ log ผลตอบแทนต่อปี (log ผลตอบแทนคือ $\ln$ ของราคาใหม่หารด้วยราคาเก่า) ซึ่งประมาณได้จากราคาในอดีต ถ้าต้นไม้จะเลียนแบบหุ้นตัวนั้น การแกว่งของราคาในต้นไม้ต้องมีขนาดเท่ากัน

Cox, Ross และ Rubinstein (CRR) จึงให้ log ของราคาขยับขึ้นหรือลง $\sigma\sqrt{\Delta t}$ ต่อช่วง เมื่อ $\Delta t$ คือความยาวหนึ่งช่วง หน่วยเป็นปี วิธีนี้ทำให้ความแปรปรวน (SD ยกกำลังสอง) ของ log ราคาต่อช่วงเป็น $\sigma^2\Delta t$ ตรงกับแบบจำลองราคาหุ้นในgeometric Brownian motion log ราคาขึ้น $\sigma\sqrt{\Delta t}$ แปลว่าราคาคูณ $e^{\sigma\sqrt{\Delta t}}$ ตัวคูณนี้จึงเป็น $u$ และขาลงคือ $d=e^{-\sigma\sqrt{\Delta t}}=1/u$

ดอกเบี้ยในขั้นนี้เป็นอัตราทบต้นต่อเนื่อง $r$ ต่อปี คือเงิน \$1 โตเป็น $e^{rt}$ ดอลลาร์ในเวลา $t$ ปี เงินฝากหนึ่งช่วงจึงโตเป็น $R=e^{r\Delta t}$ ของที่ใช้ในตัวอย่าง (ตัวเลขสมมติ):

  • ความผันผวน $\sigma=30\%=0.30$ ต่อปี
  • ช่วงละ $\Delta t=0.01$ ปี (ปีหนึ่งแบ่งเป็น 100 ช่วง)
  • ดอกเบี้ย $r=5\%=0.05$ ต่อปี ทบต้นต่อเนื่อง
\[ \begin{aligned} X&=\ln\tfrac{S_{t+\Delta t}}{S_t}=\pm\sigma\sqrt{\Delta t},\\ X^2&=\sigma^2\Delta t,\\ u&=e^{\sigma\sqrt{\Delta t}},\quad d=1/u,\\ R&=e^{r\Delta t},\\ u&=e^{0.30\sqrt{0.01}}=e^{0.03}\\ &=1.030455,\\ d&=e^{-0.03}=0.970446,\\ R&=e^{0.05(0.01)}=1.000500,\\ q&=\frac{1.000500-0.970446}{1.030455-0.970446}\\ &=0.500835. \end{aligned} \]

$X$ คือก้าวของ log ราคาในหนึ่งช่วง เป็น $+\sigma\sqrt{\Delta t}$ หรือ $-\sigma\sqrt{\Delta t}$ ทั้งสองกิ่งยกกำลังสองได้ $\sigma^2\Delta t$ เท่ากัน ค่าเฉลี่ยของ $X^2$ จึงเป็น $\sigma^2\Delta t$ ไม่ว่าน้ำหนักของสองกิ่งจะเป็นเท่าไร ความแปรปรวนคือค่าเฉลี่ยของ $X^2$ ลบด้วยกำลังสองของค่าเฉลี่ยของ $X$ และค่าเฉลี่ยของ $X$ เล็กมากเมื่อ $\Delta t$ สั้น (เล็กระดับ $\Delta t$ กำลังสองของมันจึงเล็กระดับ $\Delta t^2$) ความแปรปรวนจึงเป็น $\sigma^2\Delta t$ ตามที่ต้องการ

การเลือก $d=1/u$ ทำให้ $ud=1$ คือขึ้นแล้วลงก็กลับมาที่ราคาเดิม กิ่งจึงมาบรรจบกัน ที่ช่วง $t$ มีแค่ $t+1$ โหนด แทนที่จะเป็น $2^t$ เช่นที่ 30 ช่วง มี 31 โหนด แทน $2^{30}=1{,}073{,}741{,}824$ โหนด ถ้าหุ้นจ่ายปันผลต่อเนื่องในอัตรา $c$ ต่อปี ให้ใช้ $q=(e^{(r-c)\Delta t}-d)/(u-d)$ แทน ด้วยเหตุผลเดียวกับขั้นที่ 10

อ่านกลับทางก็ได้ ถ้ามีต้นไม้สองช่วง ช่วงละครึ่งปี ($\Delta t=0.5$) ที่ใช้ $u=1.2$ ต้นไม้นี้มีความผันผวนต่อปีเท่ากับ

\[ \begin{aligned} \sigma&=\frac{\ln u}{\sqrt{\Delta t}}=\frac{\ln1.2}{\sqrt{0.5}}\\ &=\frac{0.182322}{0.707107}=25.78\%. \end{aligned} \]

ขั้นที่ 12 — put อเมริกันบนต้นไม้ CRR สองช่วง

ขั้นนี้รวมทุกอย่างเข้าด้วยกัน: ต้นไม้ CRR จากขั้นที่ 11 กับ put อเมริกันจากขั้นที่ 9 ต้นไม้มีแค่สองช่วง จึงคิดด้วยมือได้ทุกโหนด

โจทย์ให้อะไรมาบ้าง:

  • หุ้นราคาวันนี้ \$100 put strike \$100 อายุ 1 ปี
  • ดอกเบี้ย $r=2\%$ ต่อปี ทบต้นต่อเนื่อง
  • สองช่วง ช่วงละ $\Delta t=0.5$ ปี กับ $u=1.2$ และ $d=1/1.2=0.833333$ (ความผันผวน 25.78% ต่อปี จากขั้นที่ 11)

ราคาหุ้นที่โหนดต่าง ๆ: กิ่งบนเป็น $100\times1.2=120$ แล้วเป็น 144 หรือ 100 ทุกราคาไม่ต่ำกว่า strike put ในกิ่งบนจึงมีค่าศูนย์ทั้งหมด กิ่งล่างเป็น $100/1.2=83.3333$ แล้วเป็น 100 (put จ่าย 0) หรือ $100/1.2^2=69.4444$ ที่โหนดหุ้น 83.33 ต้องเทียบใช้เลย ($E_d$) กับถือต่อ ($H_d$):

\[ \begin{aligned} R&=e^{0.02\times0.5}=e^{0.01}\\ &=1.010050,\\ q&=\frac{1.010050-0.833333}{1.2-0.833333}\\ &=0.481955,\\ S_{dd}&=100/1.2^2=69.4444,\\ P_{dd}&=100-69.4444=30.5556,\\ H_d&=\frac{(1-q)(30.5556)}{1.010050}\\ &=15.6717,\\ E_d&=100-83.3333=16.6667,\\ P_0^{\rm Am}&=\frac{(1-q)(16.6667)}{1.010050}\\ &=8.5482,\\ P_0^{\rm Eu}&=\frac{(1-q)(15.6717)}{1.010050}\\ &=8.0378. \end{aligned} \]

คำตอบ: ที่โหนดล่าง (หุ้น 83.33) ใช้สิทธิ์ทันทีได้ \$16.6667 มากกว่าถือต่อ \$15.6717 จึงใช้สิทธิ์ทันที put อเมริกันราคา \$8.5482 ส่วน put ยุโรปซึ่งต้องถือต่อ ราคา \$8.0378 ต่างกัน $8.5482-8.0378\approx\$0.51$ ถ้าเอาวิธีแบบยุโรปไปตั้งราคา put อเมริกัน ราคาจะต่ำไป $\frac{0.51}{8.55}\approx6\%$

ตรวจเองใน 10 วินาที: หารด้วย $R=1.010050$ เท่ากับคูณ $1/1.010050=0.990050$ และ $1-q=1-0.481955=0.518045$ จึงได้ $0.990050\times0.518045\times16.6667=8.5482$ กิ่งบนไม่ต้องคิด เพราะหุ้นไม่เคยต่ำกว่า 100 ในกิ่งนั้น

ขั้นที่ 13 — ซอยช่วงถี่ขึ้น ต้นไม้ลู่เข้า Black–Scholes

หุ้นจริงไม่ได้ขยับเป็นช่วงห่าง ๆ แต่ขยับตลอดเวลา ถ้าต้นไม้จะเชื่อถือได้ เมื่อซอยช่วงให้ถี่ขึ้นเรื่อย ๆ ราคาที่ได้ต้องเข้าใกล้คำตอบของสูตร Black–Scholes ซึ่งเป็นสูตรปิดของโลกเวลาต่อเนื่อง ขั้นนี้ทดสอบเรื่องนั้นด้วย call ยุโรป (ตัวเลขสมมติ):

  • หุ้นราคาวันนี้ \$100 strike \$100 อายุ $T=1$ ปี
  • ดอกเบี้ย $r=5\%$ ต่อปี ทบต้นต่อเนื่อง ความผันผวน $\sigma=30\%$ ต่อปี
  • ต้นไม้ CRR $n$ ช่วง แต่ละช่วงยาว $\Delta t=1/n$ ปี

ต้นไม้ $n=1$ คิดด้วยมือได้: $u=e^{0.30}=1.349859$, $d=e^{-0.30}=0.740818$, $R=e^{0.05}=1.051271$ จึงได้ $q=\frac{1.051271-0.740818}{1.349859-0.740818}=0.509741$ กิ่งขึ้น call จ่าย $134.9859-100=34.9859$ กิ่งลงจ่ายศูนย์ ราคาจึงเป็น $C_0=\frac{0.509741\times34.9859}{1.051271}=16.9640$ ค่าที่ $n$ อื่นคำนวณด้วยวิธีเดียวกับขั้นที่ 6 (โค้ดท้ายหน้าทำซ้ำได้) ส่วน $C_{\text{BS}}$ มาจากสูตร Black–Scholes ตัวเลขในวงเล็บคือราคาจากต้นไม้ลบด้วย $C_{\text{BS}}$:

\[ \begin{aligned} n=1&:\ 16.9640\quad(+2.7327),\\ n=10&:\ 13.9408\quad(-0.2905),\\ n=11&:\ 14.4831\quad(+0.2518),\\ n=100&:\ 14.2018\quad(-0.0294),\\ n=101&:\ 14.2585\quad(+0.0272),\\ n=2{,}000&:\ 14.2298\quad(-0.0015),\\ C_{\text{BS}}&=14.2313. \end{aligned} \]

ความคลาดเคลื่อนเล็กลงราวสิบเท่าทุกครั้งที่ $n$ โตสิบเท่า เช่น $n=10$ คลาด 0.29 ส่วน $n=100$ คลาด 0.029 และมันสลับข้าง: $n$ คู่ต่ำไป $n$ คี่สูงไป สาเหตุคือเมื่อ $n$ เป็นเลขคู่ จำนวนครั้งขึ้นกับลงเท่ากันได้ จึงมีโหนดปลายทางที่ราคา \$100 ตรงกับ strike พอดี ส่วน $n$ คี่ไม่มีโหนดนี้ ความสลับนี้เป็นลักษณะปกติของต้นไม้ ไม่ใช่สัญญาณว่าคำนวณผิด

ทำไมต้องเข้าใกล้ Black–Scholes ดูสูตรถ่วงครั้งเดียวของขั้นที่ 6 แต่เก็บเฉพาะปลายทางที่หุ้นอยู่เหนือ strike (ปลายอื่นจ่ายศูนย์) แล้วแยก $S_0u^jd^{n-j}-K$ ออกเป็นสองก้อน ก้อนที่สองคือ $K/R^n$ คูณโอกาสที่ปลายทางอยู่เหนือ strike ภายใต้น้ำหนัก $q$ ก้อนแรกคือ $S_0$ คูณโอกาสเดียวกัน แต่ภายใต้น้ำหนักอีกชุดคือ $qu/R$ (ซึ่งบวกกับ $(1-q)d/R$ ได้ 1 พอดี) รูปนี้เหมือน $S_0N(d_1)-Ke^{-rT}N(d_2)$ ของ Black–Scholes แล้ว เมื่อ $N(\cdot)$ คือโอกาสสะสมของ Normal มาตรฐาน

ชิ้นสุดท้ายคือ เมื่อ $n$ โต log ราคาปลายทางคือผลบวกของก้าว $\pm\sigma\sqrt{\Delta t}$ จำนวนมาก ตามcentral limit theorem ผลบวกของก้าวสุ่มจำนวนมากมีการกระจายเข้าใกล้ Normal โอกาสสองก้อนในต้นไม้จึงเข้าใกล้ $N(d_1)$ กับ $N(d_2)$

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ใช้โอกาสจริง $p$ แทน $q$: ราคาที่ได้ผิด และคนที่ขายตามราคานั้นเปิดช่องให้คนอื่นเก็บเงินฟรี ในปริศนา ABC ราคาผิดคือ $\frac{0.99\times10}{1.01}=\$9.80$ ราคาถูกคือ $\frac{0.55\times10}{1.01}=\$5.45$ ใครขาย call ที่ \$9.80 เท่ากับยกเงินราว $9.80-5.45\approx\$4.36$ ต่อสัญญาให้คนที่สร้างพอร์ตเลียนแบบ

คิดว่าต้องรู้ความชอบความเสี่ยงของคนซื้อ: ถ้าไม่มีพอร์ตเลียนแบบ ราคาจะขึ้นกับว่าแต่ละคนพอใจกับความเสี่ยงแค่ไหน ซึ่งไม่มีคำตอบเดียว ตัวอย่างดั้งเดิมคือปริศนา St Petersburg: โยนเหรียญจนออกหัว ถ้าออกหัวครั้งแรกที่การโยนครั้งที่ $n$ ได้ $2^n$ ดอลลาร์ ค่าเฉลี่ยของเงินรางวัลคือ

\[ \sum_{n=1}^{\infty}2^n\Big(\frac12\Big)^n=1+1+1+\dots=\infty \]

แต่ไม่มีใครยอมจ่ายแพงเพื่อเล่น Daniel Bernoulli เสนอว่าคนไม่ได้ตัดสินจากตัวเงิน แต่จากความพอใจ (utility) ซึ่งเขาให้เป็น $\log$ ของเงิน:

\[ \begin{aligned} \sum_{n=1}^{\infty}\Big(\tfrac12\Big)^n\log2^n&=\log2\sum_{n=1}^{\infty}\tfrac{n}{2^n}\\ &=2\log2,\\ e^{2\log2}&=\$4. \end{aligned} \]

แถวแรกใช้ $\log2^n=n\log2$ ส่วน $\sum n/2^n=2$ มาจากสูตรอนุกรม $\sum nx^n=\frac{x}{(1-x)^2}$ ที่ $x=\tfrac12$ ได้ $\frac{0.5}{0.25}=2$ ผลแปลว่าเงินแน่นอน \$4 ให้ความพอใจเท่ากับเกมนี้ แต่ถ้าคนอื่นใช้ utility แบบอื่น ก็ได้ราคาอื่น ต้นไม้หลบปัญหานี้ได้ทั้งหมด เมื่อสร้างพอร์ตเลียนแบบได้ ราคาถูกบังคับเหลือค่าเดียว โดยไม่ต้องรู้ทั้งโอกาสจริงและความชอบของใคร

ลืมคิดลด: ค่าเฉลี่ยถ่วง $q$ ของ payoff เป็นเงินตอนจบช่วง ยังไม่ใช่ราคาวันนี้ ในขั้นที่ 1 ค่าผิดคือ $0.5\times20=\$10$ ราคาถูกคือ $\frac{10}{1.05}=\$9.5238$ ต่างกัน 5% ต่อช่วง และความต่างนี้ทบกันทุกช่วงของต้นไม้

ตั้งราคา put อเมริกันด้วยต้นไม้แบบยุโรป: ลืมเทียบ “ใช้สิทธิ์เลย” ที่ทุกโหนด ในขั้นที่ 12 ค่าผิดคือ \$8.0378 ค่าถูกคือ \$8.5482 ต่ำไป $\frac{8.5482-8.0378}{8.5482}\approx6\%$

ลืมปันผลใน $q$: ใช้ $q=\frac{R-d}{u-d}$ กับหุ้นที่จ่ายปันผล แทน $q_c=\frac{R-d-c}{u-d}$ ในขั้นที่ 10 ค่าผิดคือ \$6.5744 (จาก $q=0.5569$) ค่าถูกคือ \$4.9214 (จาก $q_c=0.4831$) แพงไป $\frac{6.5744}{4.9214}-1\approx34\%$

เลือก $u$, $d$, $R$ ที่ไม่ผ่าน $d\lt R\lt u$: ต้นไม้แบบนี้มีเงินฟรีอยู่ในตัว และ “น้ำหนัก” ที่ได้ไม่ใช่น้ำหนักจริง เช่น $u=1.01$, $d=0.99$, $R=1.02$ ได้ $q=\frac{1.02-0.99}{1.01-0.99}=\frac{0.03}{0.02}=1.5$ ซึ่งเกิน 1 และ $1-q=-0.5$ ติดลบ ราคาที่ได้ไม่มีความหมาย โค้ดท้ายหน้าจึงปฏิเสธต้นไม้แบบนี้

ใช้ทำอะไรบนโต๊ะจริง

option บนหุ้นรายตัวที่ซื้อขายในสหรัฐฯ ส่วนใหญ่เป็นแบบอเมริกัน ซึ่ง Black–Scholes ตั้งราคาให้ไม่ได้ โต๊ะเทรด option จึงใช้ต้นไม้ (หรือกริด ซึ่งเป็นการแบ่งราคากับเวลาเป็นตารางแบบเดียวกัน) ตั้งราคา put ที่ใช้สิทธิ์ก่อนได้ และ call บนหุ้นที่จ่ายปันผล ต้นไม้ยังใช้ตรวจวิธีอื่นได้ด้วย เพราะเมื่อซอยถี่ ราคาจากต้นไม้ต้องเข้าใกล้สูตรปิด

ข้อจำกัดคือต้นไม้ในหน้านี้ใช้ความผันผวน $\sigma$ ตัวเดียว แต่ราคา option ในตลาดจริงบอกความผันผวนที่ต่างกันตาม strike และอายุ (เรียกว่า volatility surface) ต้นไม้ที่ใช้ $\sigma$ ตัวเดียวจึงตั้งราคาคลาดกับ option ที่ strike ห่างจากราคาหุ้นมาก ส่วน $x$ ในแต่ละโหนดคือจำนวนหุ้นที่ต้องถือเพื่อ hedge (ถือหุ้นไว้ให้กำไรขาดทุนหักล้างกับ option ที่ขายไป) หน้าถัดไปจะนับกำไรขาดทุนของการ hedge แบบนี้

โจทย์ตรวจความเข้าใจ

1. คุณถือหุ้นราคา \$50 และอยากซื้อ put (สิทธิ์ขายหุ้น) strike \$50 ไว้กันหุ้นตก อีกหนึ่งช่วงหุ้นจะเป็น \$60 หรือ \$45 เงินฝากโต $R=1.02$ ต่อช่วง put นี้ควรราคาเท่าไร ให้หาทั้งพอร์ตเลียนแบบ และหาด้วย $q$

เฉลย

put จ่าย $\max(50-S,0)$ จึงจ่าย \$0 เมื่อหุ้นเป็น 60 และจ่าย $50-45=\$5$ เมื่อหุ้นเป็น 45 ต้นไม้นี้มี $u=60/50=1.2$ และ $d=45/50=0.9$:

\[ \begin{aligned} x&=\frac{0-5}{60-45}=-\tfrac13,\\ y&=\frac{5-45x}{1.02}=\frac{5+15}{1.02}\\ &=19.6078,\\ P_0&=50x+y=-16.6667+19.6078\\ &=\$2.9412,\\ q&=\frac{1.02-0.9}{1.2-0.9}=0.4,\\ P_0&=\frac{0.4\times0+0.6\times5}{1.02}=\$2.9412. \end{aligned} \]

$x$ ติดลบคือชอร์ตหุ้นหนึ่งในสามหุ้น และ $y$ เป็นบวกคือฝากเงิน \$19.61 สองวิธีได้ราคาเท่ากัน

2. ขั้นที่ 6 ได้ราคา call ยุโรป strike \$100 บนต้นไม้สามช่วง ($S_0=\$100$, $u=1.07$, $R=1.01$) เป็น \$6.5744 ส่วนขั้นที่ 9 ได้ put ยุโรปบนต้นไม้เดียวกันเป็น \$3.63 จากการย้อนทีละโหนด ลองใช้ put–call parity หา put จาก call โดยไม่ต้องย้อนต้นไม้ แล้วเทียบกัน

เฉลย

put–call parity บอกว่า $C-P=S_0-K/R^3$ จึงได้

\[ \begin{aligned} P&=C-S_0+\frac{K}{R^3}\\ &=6.5744-100+\frac{100}{1.030301}\\ &=6.5744-100+97.0590\\ &=\$3.6334. \end{aligned} \]

ตรงกับการย้อนทีละโหนด เหตุผลคือ “ถือ call และขาย put” จ่าย $S-K$ ในทุกกิ่ง ซึ่งเลียนแบบได้ด้วยหุ้นหนึ่งหุ้นกับเงินกู้ $K/R^3$

3. สัญญา forward คือข้อตกลงที่ “ต้อง” ซื้อหุ้นในวันข้างหน้า ในราคาที่ตกลงวันนี้ ไม่ใช่แค่สิทธิ์ และไม่มีใครจ่ายเงินให้ใครในวันทำสัญญา บนต้นไม้สามช่วงเดียวกัน (หุ้นไม่จ่ายปันผล) สมมติตกลงซื้อหุ้นตอนจบช่วงที่ 3 ในราคา $G_0$ ราคา $G_0$ ต้องเป็นเท่าไร

เฉลย

ตอนจบ สัญญานี้จ่าย $S_3-G_0$ ในทุกกิ่ง ให้ $E^q[S_3]$ คือค่าเฉลี่ยของราคาหุ้นปลายทางเมื่อถ่วงด้วย $q$ สัญญาที่ไม่มีใครจ่ายวันนี้ต้องมีค่าวันนี้เป็นศูนย์:

\[ \begin{aligned} 0&=\frac{1}{R^3}\big(E^q[S_3]-G_0\big),\\ G_0&=E^q[S_3]=S_0R^3\\ &=100\times1.01^3=\$103.03. \end{aligned} \]

$E^q[S_3]=S_0R^3$ เพราะใต้น้ำหนัก $q$ หุ้นโตเฉลี่ยเท่าเงินฝากทุกช่วง ($qu+(1-q)d=R$ จากขั้นที่ 3) ตรวจด้วยพอร์ต: กู้ \$100 มาซื้อหุ้นวันนี้ ตอนจบช่วงที่ 3 ต้องคืน \$103.03 ดังนั้นการถือหุ้นผ่าน forward กับการกู้เงินมาซื้อหุ้น ต้นทุนเท่ากันพอดีเมื่อ $G_0=\$103.03$ เรื่องนี้ต่อยอดในหน้าcost of carry

const {exp, log, sqrt, max, abs} = Math;

function check(u, d, R, c = 0) {
  if (!(d + c < R && R < u + c)) throw new RangeError('no-arbitrage needs d + c < R < u + c');
}
// One period: x shares and y dollars in the bank reproduce payoffs vu (up) and vd (down).
function replicate(S0, u, d, R, vu, vd) {
  check(u, d, R);
  const x = (vu - vd) / (S0 * (u - d));
  const y = (vd - x * S0 * d) / R;
  return {x, y, price: x * S0 + y, q: (R - d) / (u - d)};
}
// n-period recombining tree; c = proportional dividend per period; american allows early exercise.
function tree({S0, K, u, d, R, n, kind = 'call', american = false, c = 0}) {
  check(u, d, R, c);
  const q = (R - d - c) / (u - d);
  const pay = s => kind === 'call' ? max(s - K, 0) : max(K - s, 0);
  const S = (t, k) => S0 * u ** k * d ** (t - k);
  let V = [...Array(n + 1)].map((_, k) => pay(S(n, k)));
  const nodes = [V], exercised = [];
  for (let t = n - 1; t >= 0; t--) {
    V = V.slice(0, t + 1).map((_, k) => {
      const hold = (q * V[k + 1] + (1 - q) * V[k]) / R;
      if (american && pay(S(t, k)) > hold) { exercised.push([t, k, S(t, k), hold]); return pay(S(t, k)); }
      return hold;
    });
    nodes.unshift(V);
  }
  return {price: V[0], q, nodes, exercised, S, R};
}
// Holdings chosen at node (t, k): x shares and y units of a bank account worth R^t.
function holdings(res, t, k) {
  const {nodes, S, R} = res;
  const x = (nodes[t + 1][k + 1] - nodes[t + 1][k]) / (S(t + 1, k + 1) - S(t + 1, k));
  return {x, y: (nodes[t][k] - x * S(t, k)) / R ** t};
}
// Standard normal CDF from its Taylor series around 0.
function normCdf(x) {
  if (x < -8) return 0;
  if (x > 8) return 1;
  let term = x, sum = x;
  for (let k = 1; k < 300 && abs(term) > 1e-17 * abs(sum); k++) { term *= x * x / (2 * k + 1); sum += term; }
  return 0.5 + sum * exp(-x * x / 2) / sqrt(2 * Math.PI);
}
function blackScholesCall(S, K, r, sigma, T) {
  const d1 = (log(S / K) + (r + sigma * sigma / 2) * T) / (sigma * sqrt(T));
  return S * normCdf(d1) - K * exp(-r * T) * normCdf(d1 - sigma * sqrt(T));
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ราคา option คือต้นทุนของพอร์ตหุ้นกับเงินกู้ที่จ่ายเงินเท่า option ทุกกิ่ง ในต้นไม้ 120/90 ของขั้นที่ 1 คือ \$9.5238 ราคาอื่นเปิดช่องให้เก็บเงินฟรี
  • ต้นไม้ไม่มีเงินฟรีก็ต่อเมื่อ $d\lt R\lt u$ น้ำหนัก $q=\frac{R-d}{u-d}$ โผล่ออกมาเองจากการจัดพีชคณิต และไม่ใช่โอกาสจริง call ของ ABC กับ XYZ จึงราคาเท่ากันที่ \$5.45 แม้โอกาสขึ้นจะเป็น 99% กับ 1%
  • ต้นไม้หลายช่วงคิดย้อนจากปลายทางทีละโหนด (call ในขั้นที่ 6 ได้ \$6.57) และพอร์ตเลียนแบบปรับได้ทุกโหนดโดยไม่ต้องเติมเงิน
  • option อเมริกันต้องเทียบ “ใช้สิทธิ์เลย” กับ “ถือต่อ” ที่ทุกโหนด put ในขั้นที่ 9 ควรใช้สิทธิ์ก่อนที่หุ้น 87.34 จึงราคา \$3.82 แทน \$3.63 ส่วน call ควรใช้สิทธิ์ก่อนได้ก็เฉพาะเมื่อหุ้นจ่ายปันผล
  • ต้นไม้ CRR เลือก $u=e^{\sigma\sqrt{\Delta t}}$ และ $d=1/u$ จากความผันผวน เมื่อซอยช่วงถี่ ราคาเข้าใกล้ Black–Scholes แบบฟันเลื่อย ที่ 2,000 ช่วงได้ \$14.2298 เทียบกับ \$14.2313
