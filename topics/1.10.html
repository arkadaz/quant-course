1.10 The Lognormal Distribution

ถ้า log ของราคาเป็น Normal ราคาจะเป็น Lognormal ซึ่งเป็นบวกเสมอ เบ้ไปทางขวา และมีค่าเฉลี่ยสูงกว่า median

ผู้จัดการกองทุนคนหนึ่งถือหุ้นเทคโนโลยีอยู่หนึ่งตัว เขาต้องตัดสินใจว่าจะถือต่ออีกหนึ่งปีหรือขายทิ้ง จึงขอให้ทีมวิจัยประเมินราคาปีหน้า ทีมวิจัยใช้แบบจำลองราคาหุ้น คือสูตรที่บอกว่าราคาปีหน้าออกมาเป็นค่าไหนได้บ้าง และแต่ละค่ามีโอกาสเท่าไร

ของที่รู้และของที่ทีมวิจัยส่งกลับมา:

  • ราคาวันนี้ $S_0=\$120$
  • ผลตอบแทนคือราคาเปลี่ยนไปกี่ % ในหนึ่งปี ผลตอบแทนแต่ละปีไม่เท่ากัน มันแกว่งขึ้นลงรอบค่าเฉลี่ยของมัน
  • SD (standard deviation) คือระยะที่ตัวเลขชุดหนึ่งมักแกว่งห่างจากค่าเฉลี่ยตามปกติ ความผันผวนคือ SD ของผลตอบแทนหนึ่งปี
  • หุ้นตัวนี้แกว่งแรง ทีมวิจัยตั้งความผันผวนต่อปีไว้ที่ $\sigma=55\%$ แปลว่าในปีปกติ ผลตอบแทนแกว่งห่างจากค่าเฉลี่ยได้ราว 55% หน้านี้วัดผลตอบแทนด้วยวิธีที่ต่างไปเล็กน้อย ภาพรวมด้านล่างจะอธิบาย
  • ตัวเลข 55% และตัวเลขตั้งต้นอื่นของแบบจำลองเป็นตัวเลขสมมติ ขั้นที่ 6 จะบอกครบทุกตัว
  • ทีมวิจัยส่งราคาคาดหวังปีหน้ามาด้วย ราคาคาดหวังคือค่าเฉลี่ย ถ้าปีหน้าเกิดซ้ำได้หลายพันแบบ แล้วเอาราคาปลายปีของทุกแบบมาเฉลี่ยกัน จะได้ตัวเลขนี้ ทีมวิจัยได้ $\mathbb E[S_1]=\$139.42$ โดย $S_1$ คือราคาเมื่อผ่านไป 1 ปี และ $\mathbb E$ ย่อมาจาก expected value
  • ราคาเฉลี่ยนี้เป็น $139.42/120=1.16$ เท่าของราคาวันนี้ คือสูงขึ้น $1.16-1=0.16=16\%$
  • โอกาสที่ราคาปีหน้าจะสูงกว่า \$120 ซึ่งก็คือโอกาสได้กำไร มีแค่ 49.9%

ตัวเลข \$139.42 และ 49.9% มาจากแบบจำลองเดียวกัน หน้านี้จะคำนวณทั้งสองตัวให้ดูทีละขั้น

ผู้จัดการถามว่า “ราคาเฉลี่ยขึ้น 16% แต่โอกาสขึ้นไม่ถึงครึ่ง ตัวเลขขัดกันเองหรือเปล่า”

ลองตอบก่อนเปิดเฉลย

ไม่ขัดกัน เพราะสองตัวเลขตอบคนละคำถาม ราคาลงได้อย่างมาก \$120 (จาก \$120 ถึงศูนย์) แต่ขึ้นได้ไม่จำกัด ปีที่ราคาพุ่งขึ้นสามสี่เท่าแม้เกิดไม่บ่อย ก็ดึงค่าเฉลี่ยขึ้นไปได้มาก ส่วนโอกาสกำไรนับแค่ว่าราคาผ่าน \$120 หรือไม่ ไม่สนว่าผ่านไปไกลเท่าไร

ตัวเลขอีกตัวที่ช่วยให้เห็นภาพคือ median ของราคาปีหน้า median คือราคาตรงกลางที่แบ่งผลลัพธ์เป็นสองครึ่ง ผลลัพธ์ครึ่งหนึ่งต่ำกว่า median และอีกครึ่งสูงกว่า

ในหุ้นตัวนี้ median คือ \$119.85 ซึ่งต่ำกว่า \$120 อยู่นิดเดียว โอกาสกำไรจึงต่ำกว่าครึ่งอยู่นิดเดียวเหมือนกัน แต่ค่าเฉลี่ยลอยขึ้นไปถึง \$139.42 ขั้นที่ 6 จะคำนวณตัวเลขทั้งสามให้ดู

ภาพรวมก่อนลงสูตร

ทำไมต้องมี distribution ใหม่สำหรับราคา เริ่มจากเรื่องที่ทุกคนเคยเจอ หุ้น \$100 ขึ้น 10% แล้วลง 10% ไม่ได้กลับมาที่ \$100 แต่ได้ $100\times1.10\times0.90=\$99$ เพราะผลตอบแทนแต่ละช่วงคูณต่อกัน ไม่ได้บวกกัน

การคูณจัดการยาก แต่ log เปลี่ยนการคูณเป็นการบวกได้ เราจึงวัดผลตอบแทนเป็น log return $R=\ln(S_T/S_0)$ โดย $S_0$ คือราคาต้นช่วง และ $S_T$ คือราคาปลายช่วง นี่คือวิธีวัดผลตอบแทนที่ต่างไปเล็กน้อยซึ่งโจทย์เปิดพูดถึง ตัวอย่างเดิมกลายเป็น

\[\begin{aligned}\ln1.10+\ln0.90&=0.0953-0.1054\\&=-0.0101=\ln0.99\end{aligned}\]

log return ทั้งปีจึงเป็นผลบวกของ log return รายวันราว 252 ก้อน (252 คือจำนวนวันที่ตลาดหุ้นสหรัฐเปิดซื้อขายในหนึ่งปี) ผลบวกของก้อนเล็ก ๆ จำนวนมากที่อิสระกันมักออกมาเป็นรูประฆังของ Normal distribution เราจึงสมมติว่า log return เป็น Normal และเรียก distribution ของราคาที่ตามมาว่า Lognormal

จาก log return กลับมาเป็นราคาต้องใช้ exponential เรายกกำลัง $e$ ทั้งสองข้างของ $R=\ln(S_T/S_0)$ แล้วคูณด้วย $S_0$

\[\begin{aligned}e^{R}&=S_T/S_0\\S_T&=S_0\,e^{R}\end{aligned}\]

ราคาปลายช่วงจึงเท่ากับราคาต้นช่วงคูณ $e$ ยกกำลัง log return ตัว exponential นี้บิดระฆังที่สมมาตรให้เบ้ไปทางขวา คือหางฝั่งราคาสูงยาวกว่าหางฝั่งราคาต่ำ

รูปข้างล่างแสดงเรื่องนี้ด้วยตัวเลขสมมติชุดหนึ่ง ซึ่งขั้นที่ 2 จะใช้ซ้ำ

  • ราคาต้นช่วง $S_0=\$100$
  • log return เฉลี่ย 0.1 (ตั้งไว้เป็นบวก ไม่ใช่ 0 เพื่อให้หุ้นมีแนวโน้มขึ้นเหมือนหุ้นทั่วไป)
  • log return ก้าวลงหรือก้าวขึ้นจากค่าเฉลี่ยข้างละ 0.2

จุดตั้งต้นของการก้าวคือจุดกลาง ที่ log return เฉลี่ย $R=0.1$ ราคาคือ $100e^{0.1}=\$110.52$ ก้าวลง 0.2 ไปที่ $R=-0.1$ และก้าวขึ้น 0.2 ไปที่ $R=0.3$

\[\begin{aligned}100\,e^{0.1-0.2}=100\,e^{-0.1}&=\$90.48\\100\,e^{0.1+0.2}=100\,e^{0.3}&=\$134.99\\110.52-90.48&=\$20.04\\134.99-110.52&=\$24.47\end{aligned}\]

ก้าวลงทำให้ราคาลด \$20.04 แต่ก้าวขึ้นขนาดเท่ากันทำให้ราคาเพิ่ม \$24.47 รูปข้างล่างวาดสามจุดนี้บนเส้นโค้ง

การยกกำลัง $e$ ให้ผลสามข้อ

  • ราคาไม่มีวันติดลบ เพราะ $e$ ยกกำลังอะไรก็ได้ค่าบวก
  • หางขวาที่ยาวดึงค่าเฉลี่ยของราคา (mean) ให้ลอยสูงกว่า median ซึ่งเป็นราคาตรงกลาง ที่ผลลัพธ์ครึ่งหนึ่งต่ำกว่าและอีกครึ่งสูงกว่า
  • ถ้าอยากให้ราคาเฉลี่ยโตตามอัตราที่ตั้งเป็นเป้า ต้องลด log return เฉลี่ยลงชดเชย ขนาดที่ลดคือครึ่งหนึ่งของ variance ของ log return (variance คือ SD ยกกำลังสอง) ขั้นที่ 5 จะหาที่มาของเทอม “ลบครึ่ง variance” นี้

หน้านี้เดินตามลำดับนี้ ขั้นที่ 1 ดูการทบต้น ขั้นที่ 2 ถึง 4 สร้าง Lognormal จาก Normal แล้วหา mean, median และ mode (ราคาที่เกิดบ่อยที่สุด) ขั้นที่ 5 หาที่มาของเทอมลบครึ่ง variance ขั้นที่ 6 ถึง 8 ใช้ทั้งหมดกับหุ้น \$120 ในโจทย์เปิด เพื่อหาโอกาสกำไร โอกาสที่ราคาข้ามเกณฑ์ ช่วงราคา และ SD ของราคาเป็นดอลลาร์

ขั้นที่ 1 — ราคาคูณกัน แต่ log return บวกกัน

ก่อนจะเลือก distribution ให้ราคา ต้องรู้ก่อนว่าผลตอบแทนหลายช่วงรวมกันอย่างไร ลองดูกองทุนหนึ่งที่มีผลงานสองปีดังนี้

  • มูลค่ากองทุนตอนเริ่ม ปลายปีแรก และปลายปีที่สอง เขียนเป็น $S_0$, $S_1$, $S_2$
  • ปีแรกได้ผลตอบแทน $r_1=+20\%$
  • ปีที่สองได้ผลตอบแทน $r_2=-10\%$

ผลตอบแทนแบบนี้เรียกว่า simple return ของปีที่ $t$ คือ $r_t=S_t/S_{t-1}-1$ บอกว่ามูลค่าเปลี่ยนไปกี่ % ถ้าบวก 1 เข้าไปจะได้ gross return $1+r_t=S_t/S_{t-1}$ ซึ่งบอกว่ามูลค่าคูณกี่เท่า เช่น +20% คือคูณ 1.20 และ −10% คือคูณ 0.90

ถ้าเฉลี่ยแบบบวกแล้วหาร (ค่าเฉลี่ยเลขคณิต) ได้ $\big(20\%+(-10\%)\big)/2=5\%$ ต่อปี คำถามคือ เงินโตจริงปีละเท่าไร

เราหาคำตอบสองทาง ทางแรกคูณ gross return ของสองปีเข้าด้วยกัน ทางที่สองบวก log return ของสองปี โดย log return ของปีที่ $t$ เขียนเป็น $R_t$ สุดท้ายหาอัตราโตทบต้นต่อปี $g$ ซึ่งคืออัตราคงที่ที่ถ้าโตสองปีติดกันจะได้ผลรวมเท่าของจริง

\[ \begin{aligned} \frac{S_2}{S_0}&=(1+r_1)(1+r_2)\\ &=1.20\times0.90=1.08\\ R_t&=\ln\frac{S_t}{S_{t-1}}=\ln(1+r_t)\\ \ln\frac{S_2}{S_0}&=R_1+R_2=\ln1.20+\ln0.90\\ &=0.1823+(-0.1054)=0.0770\\ (1+g)^2&=1.08=e^{0.0770}\\ g&=e^{0.0770/2}-1\approx3.92\% \end{aligned} \]

สองปีเงินโตรวม 8% คิดเป็นปีละ 3.92% แบบทบต้น ไม่ใช่ 5% ทำไม 5% เกินจริง เพราะการลง 10% เกิดบนฐานที่ใหญ่ขึ้นแล้ว เงิน \$100 ปีแรกโตเป็น \$120 ปีที่สองเสีย 10% ของ \$120 คือ $0.10\times120=\$12$ ไม่ใช่ \$10 จึงเหลือ \$108

log return บวกกันได้เพราะกฎของ log $\ln(ab)=\ln a+\ln b$ เท่านั้น ไม่ต้องสมมติอะไรเรื่องโอกาสเลย ข้อนี้ทำให้ราคาปลายทางเขียนได้ง่าย คือ $S_T=S_0\,e^{R_1+R_2+\cdots}$ ราคาวันนี้คูณ $e$ ยกกำลังผลรวมของ log return ทุกช่วง ส่วนต่างระหว่าง 5% กับ 3.92% จะกลับมาอีกครั้งในขั้นที่ 5 ในชื่อ volatility drag

ขั้นที่ 2 — นิยาม Lognormal และการแปลงจาก Z เป็นราคา

ขั้นที่ 1 บอกว่า log return ทั้งช่วง $R$ คือผลบวกของ log return รายวันจำนวนมาก ผลบวกของก้อนเล็ก ๆ จำนวนมากที่อิสระกันมีรูปเป็นระฆัง Normal (นี่คือ central limit theorem ใน Normal distribution) เราจึงสมมติว่า $R$ เป็น Normal ที่มีค่าเฉลี่ย $m$ และ SD $s$ เขียนย่อว่า $R\sim N(m,\ s^2)$ (ตัวที่สองในวงเล็บคือ variance)

Normal ทุกตัวสร้างได้จาก Normal มาตรฐาน $Z$ (ค่าเฉลี่ย 0 SD 1) โดยยืดด้วย $s$ แล้วเลื่อนด้วย $m$ จึงเขียน $R=m+sZ$ ได้ แทนลงใน $S_T=S_0e^{R}$ จากขั้นที่ 1 ก็ได้ราคาปลายทาง ราคาที่ได้จาก $e$ ยกกำลัง Normal แบบนี้คือนิยามของ Lognormal

เพื่อให้เห็นภาพ ลองใช้ตัวเลขสมมติชุดเดียวกับรูปภาพรวม

  • ราคาวันนี้ $S_0=\$100$
  • log return เฉลี่ย $m=0.10$
  • SD ของ log return $s=0.20$

แล้วดูราคาที่ $Z=-1,\ 0,\ +1$ คือที่ค่าเฉลี่ย และที่ห่างจากค่าเฉลี่ยข้างละหนึ่ง SD

\[ \begin{aligned} R&=\ln\frac{S_T}{S_0}\sim N(m,\ s^2)\\ S_T&=S_0\,e^{m+sZ},\qquad Z\sim N(0,1)\\ Z=-1&:\quad100\,e^{0.10-0.20}=90.48\\ Z=0&:\quad100\,e^{0.10}=110.52\\ Z=+1&:\quad100\,e^{0.10+0.20}=134.99 \end{aligned} \]

ข้อแรกที่ต้องจำคือ $m$ และ $s$ เป็นค่าเฉลี่ยและ SD ของ log return ทั้งช่วง ไม่ใช่ของราคา สามแถวล่างคือสามจุดในรูปภาพรวม $Z$ ห่างกันเท่ากันทีละ 1 แต่ราคาห่างกันไม่เท่ากัน ก้าวลงคือ $110.52-90.48=\$20.04$ ก้าวขึ้นคือ $134.99-110.52=\$24.47$

ข้อที่สอง $e$ ยกกำลังอะไรก็ตามได้ค่าบวกเสมอ ราคาใน Lognormal จึงไม่มีวันติดลบ ข้อนี้ตรงกับโลกจริง เพราะผู้ถือหุ้นรับผิดชอบหนี้ของบริษัทแค่เท่าเงินที่ลงไป (limited liability) ราคาหุ้นลงได้ต่ำสุดแค่ศูนย์

ขั้นที่ 3 — ค่าเฉลี่ยของ exponential ไม่ใช่ exponential ของค่าเฉลี่ย

โจทย์ให้อะไรมาบ้าง: ก่อนใช้ Normal เราลองแบบจำลองที่ง่ายที่สุดก่อน เพื่อดูว่าทำไม “ราคาเฉลี่ย” กับ “ราคาที่ได้จาก log return เฉลี่ย” ไม่เท่ากัน

  • ราคาวันนี้ \$100
  • ทอยเหรียญยุติธรรมหนึ่งครั้ง ออกหัวราคาคูณสองเป็น \$200 ออกก้อยราคาหารสองเป็น \$50
  • log return จึงเป็น $\ln2=+0.693$ หรือ $\ln\tfrac12=-0.693$ อย่างละครึ่ง

ถามว่าราคาเฉลี่ยเป็นเท่าไร คำตอบที่ใครก็อยากตอบคือ “log return เฉลี่ยเป็นศูนย์ ราคาเฉลี่ยก็คือ \$100” ลองคำนวณทั้งสองทางดู

\[ \begin{aligned} \mathbb E[R]&=\tfrac12\ln2+\tfrac12(-\ln2)=0\\ 100\,e^{\mathbb E[R]}&=100\,e^{0}=100\\ \mathbb E[S_T]&=\tfrac12(200)+\tfrac12(50)=125 \end{aligned} \]

คำตอบ: ราคาเฉลี่ยคือ \$125 ไม่ใช่ \$100 แม้ log return เฉลี่ยเป็นศูนย์ เพราะฝั่งขึ้นได้ $200-100=+\$100$ แต่ฝั่งลงเสียแค่ $50-100=-\$50$ ความไม่สมมาตรนี้ดันค่าเฉลี่ยขึ้น

ความไม่เท่ากันแบบนี้มีชื่อว่า Jensen's inequality เขียนเป็นสูตรได้ว่า $\mathbb E[e^R]\ge e^{\mathbb E[R]}$ เสมอ และสองข้างเท่ากันก็ต่อเมื่อ $R$ ไม่สุ่มเลย

ทำไมต้องเป็น “มากกว่าหรือเท่ากับ” ลองลากเส้นตรงเชื่อมสองจุดบนเส้นโค้ง $100e^{R}$ คือจุด $(-0.693,\ 50)$ กับจุด $(0.693,\ 200)$ เส้น exponential โค้งหงาย มันจึงอยู่ใต้เส้นตรงนี้ตลอดช่วงระหว่างสองจุด จุดกึ่งกลางของเส้นตรงคือค่าเฉลี่ยของสองกรณี $(50+200)/2=125$ ส่วนจุดบนเส้นโค้งตรงกลาง ที่ $R=0$ คือ $100e^{0}=100$ ซึ่งอยู่ต่ำกว่า ราคาเฉลี่ยจึงสูงกว่าราคาที่ได้จาก log return เฉลี่ย

ถ้าอยากให้ราคาเฉลี่ยเป็น \$100 พอดีล่ะ ทำไมต้องอยาก เพราะในงานจริงคนมักกำหนดราคาเฉลี่ยเป็นเป้าไว้ก่อน เช่น “ราคาเฉลี่ยปีหน้าต้องเท่ากับราคาวันนี้” หรือ “ราคาเฉลี่ยปีหน้าต้องโต 15%” แล้วปรับแบบจำลองให้ตรงเป้านั้น ขั้นที่ 5 จะทำแบบนี้กับหุ้นจริง ในเหรียญนี้ทำได้โดยเลื่อน log return ทั้งสองกรณีลงเท่ากันขนาด $c$ การเลื่อนลง $c$ ทำให้ราคาทุกกรณีคูณด้วย $e^{-c}$ เพราะ $100e^{R-c}=100e^{R}\times e^{-c}$ จากนั้นตั้งราคาเฉลี่ยให้เท่ากับ 100 แล้วแก้หา $c$

\[ \begin{aligned} \mathbb E[S_T]&=\tfrac12(200e^{-c})+\tfrac12(50e^{-c})\\ &=125e^{-c}=100\\ e^{c}&=125/100=1.25\\ c&=\ln1.25\approx0.223 \end{aligned} \]

การเลื่อนลงแบบนี้คือต้นแบบของเทอม “ลบครึ่ง variance” ในขั้นที่ 5

หมายเหตุเรื่อง median: เหรียญนี้มีผลลัพธ์แค่สองแบบ คือ \$50 กับ \$200 อย่างละครึ่ง ราคาใดก็ได้ระหว่าง \$50 ถึง \$200 จึงแบ่งผลลัพธ์ครึ่งต่อครึ่ง median ของเหรียญจึงไม่ได้มีค่าเดียว แต่เมื่อ log return เป็น Normal ในขั้นที่ 4 สูตร $S_0e^{\mathbb E[R]}$ จะให้ median ได้ค่าเดียว ในเหรียญนี้สูตรเดียวกันให้ $100e^{0}=\$100$ ซึ่งต่ำกว่า mean \$125 ช่องว่างระหว่าง median กับ mean จึงเห็นได้ตั้งแต่โจทย์ที่ง่ายที่สุด

ขั้นที่ 4 — mean, median และ mode ของ Lognormal

ตอนนี้ทำแบบเดียวกับเหรียญ แต่ log return เป็น Normal $R=m+sZ$ เราอยากได้สามค่าของราคา $S_T=S_0e^{m+sZ}$ คือ mean, median และ mode เครื่องมือมีสองชิ้น

  • ค่าเฉลี่ยของ $e^{aZ}$ สำหรับตัวเลข $a$ ใด ๆ คือ $\mathbb E[e^{aZ}]=e^{a^2/2}$ ค่านี้เรียกว่า moment generating function (MGF) ของ $Z$ ได้มาจากการเติมกำลังสองใน Normal distribution
  • density ของราคา $f_S(x)$ ได้จาก density ของ log return $f_R(r)$ ซึ่งเป็น density ของ Normal ให้ $x$ คือราคาที่สนใจ และ $r$ คือ log return ที่คู่กับราคานั้น เหตุผลคือ โอกาสที่ราคาตกในแถบแคบ ๆ หนึ่งแถบต้องเท่ากัน ไม่ว่าจะวัดบนแกนราคาหรือบนแกน log return ผลคือ density ของราคามีตัว $1/x$ เพิ่มเข้ามาข้างหน้า ดูที่มาในบล็อกข้างล่าง
\[ \begin{aligned} r&=\ln(x/S_0),\qquad \frac{dr}{dx}=\frac1x\\ f_S(x)\,dx&=f_R(r)\,dr\\ f_S(x)&=f_R(r)\,\frac{dr}{dx}=\frac{f_R(r)}{x}\\ f_R(r)&=\frac{1}{s\sqrt{2\pi}}\,e^{-(r-m)^2/(2s^2)} \end{aligned} \]

ที่มาสั้นมาก เราเขียนเงื่อนไข “โอกาสในแถบแคบเท่ากันทั้งสองแกน” เป็นสมการ แล้วหารด้วย $dx$ ส่วน $f_R$ คือ density ของ Normal ที่มีค่าเฉลี่ย $m$ และ SD $s$ จาก Normal distribution ซึ่งจะแทนลงไปในบล็อกถัดไป ตอนนี้พร้อมหาทั้งสามค่าแล้ว

\[ \begin{aligned} \mathbb E[S_T]&=S_0e^{m}\,\mathbb E[e^{sZ}]\\ &=S_0\,e^{m+s^2/2}\\ \operatorname{median}(S_T)&=S_0\,e^{m}\\ f_S(x)&=\frac{1}{xs\sqrt{2\pi}}\,e^{-(\ln(x/S_0)-m)^2/(2s^2)}\\ \ln f_S(x)&=-\ln x-\ln(s\sqrt{2\pi})\\ &\quad-\frac{(\ln(x/S_0)-m)^2}{2s^2}\\ \frac{d}{dx}\ln f_S(x)&=-\frac1x-\frac{\ln(x/S_0)-m}{s^2x}=0\\ \ln(x/S_0)&=m-s^2\\ \operatorname{mode}(S_T)&=S_0\,e^{m-s^2}\\ e^{m-s^2}&\lt e^{m}\lt e^{m+s^2/2} \end{aligned} \]

mean ได้ตัวคูณเพิ่ม $e^{s^2/2}$ ส่วน median ไม่ได้ ทำไม สำหรับ mean ตัว $S_0e^m$ เป็นค่าคงที่ จึงดึงออกนอกค่าเฉลี่ยได้ (linearity ใน expected value) ที่เหลือคือ MGF ที่ $a=s$ ซึ่งให้ $e^{s^2/2}$ ตัวคูณนี้คือ Jensen's inequality ในรูปตัวเลข เหมือนที่เหรียญได้ \$125 แทน \$100

สำหรับ median ครึ่งหนึ่งของ $Z$ ต่ำกว่า 0 และ exponential เป็น function เพิ่ม ลำดับจึงไม่เปลี่ยน ครึ่งหนึ่งของราคาจึงต่ำกว่าราคาที่ $Z=0$ ซึ่งคือ $S_0e^{m+s\cdot0}=S_0e^m$ median ผ่าน function เพิ่มได้ แต่ mean ผ่านไม่ได้ เพราะ exponential ยืดฝั่งบนมากกว่าฝั่งล่าง

สำหรับ mode เราหาจุดยอดของ density โดยตั้งอนุพันธ์ของ $\ln f_S$ ให้เป็นศูนย์ (ใช้ $\ln f_S$ เพราะจุดยอดเดียวกันแต่อนุพันธ์ง่ายกว่า) อนุพันธ์ของพจน์ยกกำลังสองได้จาก chain rule โดย $\frac{d}{dx}\ln(x/S_0)=1/x$ จากนั้นคูณทั้งสองข้างด้วย $-s^2x$ ได้ $s^2+\ln(x/S_0)-m=0$ จุดที่คนส่วนใหญ่สะดุดคือตัว $1/x$ ใน density ทำไมมันดึงยอดลง ดูรูปภาพรวมอีกครั้ง ก้าว log return ขนาดเท่ากันครอบช่วงดอลลาร์ที่กว้างขึ้นเมื่อราคาสูงขึ้น โอกาสก้อนเท่าเดิมจึงถูกเกลี่ยบนช่วงที่กว้างกว่า density ทางขวาจึงบางลง และยอดเลื่อนลงมาต่ำกว่า median ผลคือสามค่าเรียงกันเสมอ mode ต่ำสุด median อยู่กลาง mean สูงสุด

ขั้นที่ 5 — ตั้ง drift ให้ราคาเฉลี่ยตรงเป้า: เทอมลบครึ่ง variance

ขั้นที่ 4 เริ่มจาก $m$ แล้วได้ราคาเฉลี่ย แต่ในงานจริงทิศกลับกัน นักวิเคราะห์มักบอกเป้ามาก่อนว่าราคาเฉลี่ยโตปีละเท่าไร แล้วเราต้องเลือก $m$ ให้ได้ตามเป้านั้น

ให้ $T$ คือจำนวนปีที่มองไปข้างหน้า ค่าที่เราต้องเลือกคือ $m$ ซึ่งเป็น log return เฉลี่ยของทั้ง $T$ ปี ถ้าหารด้วย $T$ จะได้ $m/T$ คืออัตราต่อปีที่ log return เลื่อนไปโดยเฉลี่ย อัตราเลื่อนเฉลี่ยต่อปีแบบนี้เรียกว่า drift และต้องบอกเสมอว่าเป็น drift ของอะไร เพราะหน้านี้มี drift สองตัว $m/T$ คือ drift ของ log return ส่วน $\mu$ ข้างล่างคือ drift ของราคาเฉลี่ย

เป้าของนักวิเคราะห์มักเขียนเป็นอัตราทบต้นต่อเนื่อง $\mu$ เช่น $\mu=15\%$ ต่อปี ทบต้นต่อเนื่องแปลว่าทบดอกถี่จนแทบทุกขณะ ถ้าทบ $n$ ครั้งต่อปี เงินหลัง $T$ ปีคูณด้วย $(1+\mu/n)^{nT}$ เมื่อ $n$ โตมาก ตัวคูณนี้เข้าใกล้ $e^{\mu T}$ ดูได้จากตัวเลขหนึ่งปี

\[ \begin{aligned} n=12&:\ \big(1+0.15/12\big)^{12}=1.1608\\ n=365&:\ \big(1+0.15/365\big)^{365}=1.1618\\ n\to\infty&:\ e^{0.15}=1.1618 \end{aligned} \]

ราคาเฉลี่ยหลัง $T$ ปีจึงคูณด้วย $e^{\mu T}$ และ μ = 15% แปลว่าในหนึ่งปีราคาเฉลี่ยสูงขึ้น $1.1618-1=16.18\%$ ไม่ใช่ 15% พอดี เราใช้รูป $e^{\mu T}$ เพราะสูตรราคาเฉลี่ยของขั้นที่ 4 ก็อยู่ในรูป $e$ ยกกำลังอยู่แล้ว จึงเทียบเลขชี้กำลังกันได้ตรง ๆ

ก่อนหา $m$ ต้องรู้ $s$ ก่อน ให้ $\sigma$ คือความผันผวนต่อปี คือ SD ของ log return หนึ่งปี ถ้า log return แต่ละปีอิสระกันและมี variance ปีละ $\sigma^2$ เท่ากันทุกปี variance ของผลบวก $T$ ปีคือผลบวกของ variance (ดู variance) จึงได้ $s^2=\sigma^2T$ และ $s=\sigma\sqrt T$

ตอนนี้ตั้งราคาเฉลี่ยจากขั้นที่ 4 ให้เท่ากับเป้า $S_0e^{\mu T}$ แล้วแก้หา $m$

\[ \begin{aligned} S_0\,e^{m+s^2/2}&=S_0\,e^{\mu T}\\ m&=\mu T-\tfrac12 s^2=\big(\mu-\tfrac12\sigma^2\big)T\\ S_T&=S_0\exp\!\Big[\big(\mu-\tfrac12\sigma^2\big)T+\sigma\sqrt T\,Z\Big] \end{aligned} \]

ลองตรวจเลขคณิตด้วยตัวเลขสมมติ

  • ราคาวันนี้ $S_0=\$100$
  • ราคาเฉลี่ยโต $\mu=0.10$ ต่อปี
  • ความผันผวน $\sigma=0.20$ ต่อปี
  • มองไปข้างหน้า $T=1$ ปี

การตรวจนี้ไม่ได้พิสูจน์อะไรใหม่ เพราะ $m$ ถูกตั้งมาให้ได้ผลนี้อยู่แล้ว มันแค่ยืนยันว่าเลขคณิตไม่พลาด ถ้าไม่พลาด ราคาเฉลี่ยต้องออกมาเป็น $100e^{0.10}$

\[ \begin{aligned} s&=\sigma\sqrt T=0.20\times\sqrt1=0.20\\ m&=0.10-\tfrac12(0.20)^2=0.10-0.02=0.08\\ \mathbb E[S_T]&=100\,e^{m+s^2/2}=100\,e^{0.08+0.02}\\ &=100\,e^{0.10}=\$110.52 \end{aligned} \]

ทำไมต้องลบครึ่ง variance เพราะขั้นที่ 4 บอกว่าความผันผวนดันราคาเฉลี่ยขึ้นเป็น $e^{s^2/2}$ เท่าโดยอัตโนมัติ ถ้าอยากให้ราคาเฉลี่ยโตแค่ $e^{\mu T}$ ต้องเลื่อน log return ลงชดเชย $s^2/2$ เหมือนที่เหรียญต้องเลื่อนลง 0.223

สูตรแถวที่สามคือราคาปลายทางของ geometric Brownian motion ซึ่งเป็นแบบจำลองราคาหุ้นมาตรฐานที่ให้ราคาเดินแบบสุ่มต่อเนื่องตลอดเวลา ในแบบจำลองนี้ราคาเฉลี่ยโตในอัตรา $\mu$ ตามที่ตั้งไว้ แต่ median และอัตราโตของคนที่ถือหุ้นไว้นาน ๆ โตช้ากว่านั้น ดูได้จากสูตร median ของขั้นที่ 4 และจากเลขชี้กำลังของสูตรแถวที่สาม

\[ \begin{aligned} \operatorname{median}(S_T)&=S_0\,e^{m}=S_0\,e^{(\mu-\sigma^2/2)T}\\ \ln\frac{S_T}{S_0}&=\big(\mu-\tfrac12\sigma^2\big)T+\sigma\sqrt T\,Z\\ \frac1T\ln\frac{S_T}{S_0}&=\big(\mu-\tfrac12\sigma^2\big)+\frac{\sigma Z}{\sqrt T} \end{aligned} \]

เมื่อแทน $m$ ที่เพิ่งหาได้ลงในสูตร median จะเห็นว่า median โตปีละ $\mu-\sigma^2/2$ ไม่ใช่ $\mu$ ส่วนคนที่ถือหุ้น $T$ ปี ได้อัตราโตต่อปีแบบทบต้นต่อเนื่องเท่ากับ log return ทั้งช่วงหารด้วย $T$ อัตรานี้มีส่วนสุ่ม $\sigma Z/\sqrt T$ ซึ่งเล็กลงเมื่อ $T$ ยาวขึ้น เพราะ $\sqrt T$ อยู่ที่ตัวหาร คนที่ถือนาน ๆ จึงได้อัตราใกล้ $\mu-\sigma^2/2$ อัตรานี้ก็คือ drift ของ log return $m/T$ ที่เราเพิ่งเลือก ส่วนต่าง $\sigma^2/2$ ที่หายไปจาก $\mu$ เรียกว่า volatility drag (ความผันผวนกัดอัตราโตทบต้น)

ลองตรวจกับกองทุน +20% แล้ว −10% ในขั้นที่ 1 สูตร $\mu-\sigma^2/2$ สร้างมาสำหรับ log return ที่เป็น Normal แต่ใช้กับ simple return รายปีเป็นค่าประมาณได้ ใช้ค่าเฉลี่ยเลขคณิต $\bar r$ แทน $\mu$ และใช้ $v$ แทน $\sigma^2$ โดย $v$ คือ variance ของผลตอบแทนรายปีสองค่า (ปีแรกกับปีที่สอง) หา $v$ โดยเอาผลตอบแทนแต่ละปีลบค่าเฉลี่ย ยกกำลังสอง แล้วหารด้วย 2 เพราะมีสองปี ถ้าค่าประมาณใช้ได้ $\bar r-v/2$ ต้องออกมาใกล้อัตราโตทบต้น 3.92% ของขั้นที่ 1

\[ \begin{aligned} \bar r&=(0.20-0.10)/2=0.05\\ 0.20-\bar r&=+0.15\\ -0.10-\bar r&=-0.15\\ v&=(0.15^2+0.15^2)/2=0.0225\\ \bar r-v/2&=0.05-0.01125\\ &=0.03875\approx3.9\% \end{aligned} \]

ได้ 3.9% ใกล้กับ 3.92% ที่คำนวณได้จริงในขั้นที่ 1 แต่ไม่เท่ากันพอดี เพราะการใช้สูตรนี้กับ simple return รายปีเป็นแค่ค่าประมาณ

รูปด้านล่างแสดง volatility drag กับหุ้นในโจทย์เปิด ถ้าตรึงราคาเฉลี่ยไว้แล้วเพิ่มความผันผวน median จะลดลงเรื่อย ๆ

ขั้นที่ 6 — โจทย์หลัก: หุ้น \$120 ปีหน้า

ตอนนี้มีเครื่องมือครบแล้ว กลับมาที่หุ้นของผู้จัดการกองทุนในโจทย์เปิด ตัวเลขตั้งต้นของแบบจำลองทีมวิจัยมีดังนี้ (ทั้งหมดเป็นตัวเลขสมมติ)

  • ราคาวันนี้ $S_0=\$120$
  • ราคาเฉลี่ยโตปีละ $\mu=0.15$ แบบทบต้นต่อเนื่อง ตามขั้นที่ 5 แปลว่าราคาเฉลี่ยปีหน้าสูงกว่าวันนี้ $e^{0.15}-1=0.1618=16.18\%$ ตรงกับ “ราว 16%” ในโจทย์เปิด
  • ความผันผวนต่อปี $\sigma=0.55$ ระดับของหุ้นเทคโนโลยีที่โตเร็วและแกว่งแรง
  • มองไปข้างหน้า $T=1$ ปี

ลำดับงานคือ หา $s$ และ $m$ ด้วยสูตรของขั้นที่ 5 แล้วแทนในสูตร mean, median, mode ของขั้นที่ 4 สุดท้ายหาโอกาสกำไร

โอกาสกำไรหาได้โดยแปลงเป็นคำถามเรื่อง $Z$ ราคาปีหน้าสูงกว่า \$120 ก็ต่อเมื่อ $S_T/S_0\gt1$ ซึ่งก็คือ log return $m+sZ$ เป็นบวก เพราะ $\ln$ ของค่าที่มากกว่า 1 เป็นบวก

\[ \begin{aligned} s^2&=0.55^2\times1=0.3025,\quad s=0.55\\ m&=0.15-0.3025/2=-0.00125\\ \mathbb E[S_T]&=120\,e^{-0.00125+0.3025/2}\\ &=120\,e^{0.15}\approx\$139.42\\ \operatorname{median}&=120\,e^{-0.00125}\approx\$119.85\\ \operatorname{mode}&=120\,e^{-0.00125-0.3025}\approx\$88.57\\ P(S_T\gt120)&=P(m+sZ\gt0)=P\big(Z\gt-m/s\big)\\ z&=-m/s=0.00125/0.55=0.00227\\ P(S_T\gt120)&=P(Z\gt z)=1-\Phi(z)\\ &\approx1-(0.5+0.00227\times0.3989)\\ &=1-0.50091\approx49.91\% \end{aligned} \]

$m$ ติดลบเล็กน้อย เพราะ volatility drag $s^2/2=0.3025/2=0.15125$ มากกว่าอัตราโต 0.15 ไปนิดหนึ่ง median จึงต่ำกว่า \$120 นิดหนึ่ง และโอกาสกำไรก็ต่ำกว่าครึ่งนิดหนึ่งด้วย

โอกาสกำไรใช้ $1-\Phi$ เพราะ $\Phi$ ให้โอกาสฝั่งต่ำกว่า แต่เราถามฝั่งสูงกว่า ตัวที่ต้องระวังคือ $z=0.00227$ ซึ่งเล็กมาก ตาราง Normal ทั่วไปให้ $z$ แค่ทศนิยมสองตำแหน่ง $z$ จึงถูกปัดเป็น 0.00 และได้ $\Phi(0.00)=0.5000$ ซึ่งให้โอกาสกำไร 50% พอดี และลบความต่าง $50\%-49.91\%=0.09\%$ ที่เราอยากเห็นไปหมด

เราจึงใช้อีกทาง ใกล้ศูนย์ กราฟของ $\Phi$ เกือบเป็นเส้นตรง ความชันของเส้นนี้คือความสูงของระฆังที่ศูนย์ $\varphi(0)=1/\sqrt{2\pi}=0.3989$ เพราะอนุพันธ์ของ CDF คือ density จึงประมาณได้ว่า $\Phi(z)\approx0.5+z\,\varphi(0)$ ค่า 49.91% ที่ได้ตรงกับฟังก์ชัน Phi ในโค้ด JavaScript ท้ายหน้า ซึ่งคำนวณ $\Phi$ แบบละเอียด

ส่วนค่าเฉลี่ยเป็น $e^{s^2/2}=e^{0.15125}\approx1.163$ เท่าของ median ตรวจได้จาก $119.85\times1.163\approx139.4$

นี่คือคำตอบของผู้จัดการกองทุน ตัวเลขไม่ขัดกัน เพราะแต่ละตัวตอบคนละคำถาม ค่าเฉลี่ยถามว่า “ถ้าเฉลี่ยทุกกรณีได้เท่าไร” โอกาสกำไรถามว่า “กี่กรณีที่จบเหนือ \$120” ส่วน mode ที่ \$88.57 บอกว่าผลลัพธ์กระจุกแน่นที่สุดในบริเวณที่ต่ำกว่าราคาวันนี้มาก ผู้ถือหุ้นตัวเดียวควรรู้ภาพนี้ เพราะหุ้นที่แกว่งแรงมักจบปีที่ราคาแย่กว่าค่าเฉลี่ยมาก

ขั้นที่ 7 — โอกาสข้ามเกณฑ์ราคา และช่วงราคา 90%

ผู้จัดการกองทุนยังมีคำถามแบบอื่นอีกสองแบบ แบบแรกถามโอกาสที่ราคาปลายปีจะข้ามเกณฑ์ราคา $K$ เช่น “โอกาสที่ราคาจะต่ำกว่า \$100 เป็นเท่าไร” แบบที่สองถามกลับทิศ เช่น “ราคาระดับไหนที่มีโอกาสแค่ 5% ที่ราคาจริงจะต่ำกว่า” ราคาระดับนั้นเรียกว่า quantile $q_p$ โดย $p$ คือโอกาส ถ้ารู้ทั้ง $q_{0.05}$ และ $q_{0.95}$ ราคาจริงจะอยู่ระหว่างสองค่านี้ด้วยโอกาส $95\%-5\%=90\%$ นี่คือ “ช่วงราคา 90%” ในชื่อขั้นนี้

วิธีตอบแบบแรกคือแปลงคำถามเรื่องราคาเป็นคำถามเรื่อง $Z$ เพราะโอกาสของ $Z$ หาได้จาก $\Phi$ ทำได้โดยหารทั้งสองข้างด้วย $S_0$ ใส่ $\ln$ แล้วแก้หา $Z$

\[ \begin{aligned} S_T&\le K\\ \ln\frac{S_T}{S_0}=m+sZ&\le\ln\frac{K}{S_0}\\ Z&\le\frac{\ln(K/S_0)-m}{s} \end{aligned} \]

ทิศของอสมการไม่เปลี่ยนตลอดทาง เพราะ $S_0$ และ $s$ เป็นบวก การหารจึงไม่กลับทิศ และ $\ln$ เป็น function เพิ่ม ค่าที่ใหญ่กว่าจึงได้ $\ln$ ที่ใหญ่กว่า โอกาสที่ $S_T\le K$ จึงเท่ากับ $\Phi$ ของค่าทางขวา เขียนค่านี้สั้น ๆ ว่า $z_K$ นี่คือสองแถวแรกในสูตรข้างล่าง

แบบที่สองใช้สมการเดิมย้อนกลับ ตั้ง $\big(\ln(q_p/S_0)-m\big)/s=\Phi^{-1}(p)$ แล้วแก้หา $q_p$ ตัว $\Phi^{-1}(p)$ คือค่า $z$ ที่ Normal มาตรฐานมีพื้นที่ทางซ้ายเท่ากับ $p$ จากตาราง Normal (หรือคอมพิวเตอร์) $\Phi^{-1}(0.95)=1.6449$ และเพราะระฆังสมมาตร $\Phi^{-1}(0.05)=-1.6449$

\[ \begin{aligned} z_K&=\frac{\ln(K/S_0)-m}{s}\\ P(S_T\le K)&=\Phi(z_K)\\ z_{100}&=\frac{\ln(100/120)-(-0.00125)}{0.55}\\ &=\frac{-0.18232+0.00125}{0.55}=-0.3292\\ P(S_T\lt100)&=\Phi(-0.3292)\approx37.10\%\\ z_{160}&=\frac{\ln(160/120)-(-0.00125)}{0.55}\\ &=\frac{0.28768+0.00125}{0.55}=0.5253\\ P(S_T\gt160)&=1-\Phi(0.5253)\approx29.97\%\\ \ln(q_p/S_0)&=m+s\,\Phi^{-1}(p)\\ q_p&=S_0\,e^{m+s\,\Phi^{-1}(p)}\\ q_{0.05}&=120\,e^{-0.00125-0.55(1.6449)}\approx\$48.50\\ q_{0.95}&=120\,e^{-0.00125+0.55(1.6449)}\approx\$296.16 \end{aligned} \]

จุดที่ชวนพลาดคือเครื่องหมายของ $m$ เพราะ $m=-0.00125$ ติดลบ การลบ $m$ จึงกลายเป็นการบวก 0.00125 ผลคือโอกาสที่ราคาปีหน้าต่ำกว่า \$100 เท่ากับ 37.10% และโอกาสที่เกิน \$160 เท่ากับ 29.97% ข้อเกิน \$160 ต้องใช้ $1-\Phi$ เพราะ $\Phi$ ให้โอกาสฝั่งต่ำกว่า

ค่า $\Phi$ ที่ $z$ มีทศนิยมสี่ตำแหน่งแบบนี้ได้จากคอมพิวเตอร์ (ฟังก์ชัน Phi ในโค้ด JavaScript ท้ายหน้า) ถ้าเปิดตาราง Normal ที่ปัด $z$ เป็นทศนิยมสองตำแหน่ง เช่น $\Phi(-0.33)=0.3707$ จะได้ค่าใกล้กัน แต่ไม่ตรงทุกหลัก

ราคาปีหน้ามีโอกาส 90% ที่จะอยู่ระหว่าง \$48.50 ถึง \$296.16 ช่วงนี้ไม่สมมาตรรอบ \$120 เลย ฝั่งล่างห่าง $120-48.50=\$71.50$ ฝั่งบนห่าง $296.16-120=\$176.16$ แต่บนแกน log มันสมมาตรพอดี คือ $m$ บวกและลบ $0.55\times1.6449=0.9047$ เท่ากันสองข้าง

อีกคู่ที่ชวนพลาดคือ “ขึ้นเกิน 30%” (ราคาเกิน $120\times1.30=\$156$) กับ “ลงเกิน 30%” (ราคาต่ำกว่า $120\times0.70=\$84$) หลายคนเดาว่าโอกาสเท่ากัน แต่สูตรเดิมให้

\[ \begin{aligned} z_{156}&=\frac{\ln(156/120)-(-0.00125)}{0.55}\\ &=\frac{0.26236+0.00125}{0.55}=0.4793\\ P(S_T\gt156)&=1-\Phi(0.4793)\approx31.59\%\\ z_{84}&=\frac{\ln(84/120)-(-0.00125)}{0.55}\\ &=\frac{-0.35667+0.00125}{0.55}=-0.6462\\ P(S_T\lt84)&=\Phi(-0.6462)\approx25.91\% \end{aligned} \]

สองโอกาสไม่เท่ากัน เพราะบนแกน log การลง 30% ไกลกว่าการขึ้น 30% คือ $\ln0.70=-0.357$ แต่ $\ln1.30=0.262$ เท่านั้น ข้อควรระวังคือช่วงทั้งหมดนี้เป็นช่วงของราคา ณ วันสิ้นปี ไม่ได้บอกว่าระหว่างปีราคาจะอยู่ในช่วงนี้

ขั้นที่ 8 — SD ของราคา

ผู้จัดการความเสี่ยงของกองทุน (คนที่ดูว่ากองทุนอาจเสียเงินได้แค่ไหน) อยากรู้ว่าราคาปีหน้าแกว่งได้กี่ดอลลาร์ คำตอบคือ SD ของราคา $S_T$ เป็นดอลลาร์ ซึ่งไม่ใช่ $\sigma=55\%$ เพราะ σ เป็น SD ของ log return

ทางหาคือใช้สูตร $\operatorname{Var}(S_T)=\mathbb E[S_T^2]-\big(\mathbb E[S_T]\big)^2$ จาก variance ค่าเฉลี่ยของราคา $\mathbb E[S_T]$ มีแล้วจากขั้นที่ 4 ที่ยังขาดคือค่าเฉลี่ยของราคายกกำลังสอง $\mathbb E[S_T^2]$

ราคายกกำลังสองคือ $S_T^2=S_0^2e^{2m+2sZ}$ ซึ่งยังเป็น $e$ ยกกำลัง $Z$ จึงใช้ MGF ตัวเดิมได้ แค่ใส่ $a=2s$ ได้ $\mathbb E[e^{2sZ}]=e^{(2s)^2/2}=e^{2s^2}$ ตอนแทนตัวเลขจะต้องใช้ผลรวม $2m+s^2$ ซึ่งหาได้ง่ายถ้าแทน $m=\mu T-s^2/2$ จากขั้นที่ 5

\[ \begin{aligned} 2m+s^2&=2\big(\mu T-\tfrac12s^2\big)+s^2\\ &=2\mu T=2\times0.15\times1=0.30 \end{aligned} \]
\[ \begin{aligned} \mathbb E[S_T^2]&=S_0^2e^{2m}\,\mathbb E[e^{2sZ}]=S_0^2e^{2m+2s^2}\\ \operatorname{Var}(S_T)&=S_0^2e^{2m+2s^2}-S_0^2e^{2m+s^2}\\ &=S_0^2\,e^{2m+s^2}\big(e^{s^2}-1\big)\\ &=120^2e^{0.30}\big(e^{0.3025}-1\big)\\ &=14{,}400\times1.3499\times0.3532\approx6{,}866\\ \operatorname{SD}(S_T)&=\sqrt{6{,}866}\approx\$82.86 \end{aligned} \]

ตัวที่ถูกลบใน variance คือ $\big(\mathbb E[S_T]\big)^2=\big(S_0e^{m+s^2/2}\big)^2=S_0^2e^{2m+s^2}$ เมื่อดึงตัวร่วม $S_0^2e^{2m+s^2}$ ออกมา ก็ได้สูตร variance ของ Lognormal ที่ใช้กันทั่วไป

\$82.86 ยังเทียบกับ σ = 55% ตรง ๆ ไม่ได้ เพราะ σ บอกการแกว่งเป็นสัดส่วนของราคา ไม่ใช่เป็นดอลลาร์ จึงต้องหาร SD ของราคาด้วยราคาเฉลี่ย ให้เป็น “การแกว่งคิดเป็นสัดส่วนของราคา” เหมือนกัน ก่อนหาร ให้ถอดรากของ variance ทีละส่วน

\[ \begin{aligned} \operatorname{SD}(S_T)&=\sqrt{S_0^2e^{2m+s^2}}\,\sqrt{e^{s^2}-1}\\ &=S_0e^{m+s^2/2}\sqrt{e^{s^2}-1}\\ \frac{\operatorname{SD}(S_T)}{\mathbb E[S_T]}&=\frac{S_0e^{m+s^2/2}\sqrt{e^{s^2}-1}}{S_0e^{m+s^2/2}}\\ &=\sqrt{e^{s^2}-1}=\sqrt{0.3532}\approx59.4\% \end{aligned} \]

ตัว $S_0e^{m+s^2/2}$ ซึ่งก็คือราคาเฉลี่ย ตัดกันพอดีทั้งบนและล่าง สัดส่วนนี้จึงขึ้นกับ $s$ อย่างเดียว ตรวจด้วยตัวเลขได้ $82.86/139.42\approx0.594$ ตรงกัน

SD \$82.86 คิดเป็น 59.4% ของราคาเฉลี่ย สูงกว่า σ = 55% ของ log return เพราะ exponential ขยายหางขวาของราคาออกไป ถ้า σ เล็ก สองตัวนี้ใกล้กันมาก เพราะ $e^{x}-1\approx x$ เมื่อ $x$ เล็ก จึงได้ $\sqrt{e^{s^2}-1}\approx s$ เช่น $s=0.10$ ให้ $\sqrt{e^{0.01}-1}=0.1003$ แต่ที่ความผันผวนสูงแบบหุ้นตัวนี้ ต้องแยกสองตัวนี้ให้ออก

ความผิดพลาดที่ให้คำตอบผิดแบบเงียบ ๆ

เอาค่าเฉลี่ยของ log return ไปยกกำลัง $e$ แล้วเรียกว่าราคาเฉลี่ย: ความผิดข้อนี้คือเอา median ไปใช้แทน mean ในหุ้นของโจทย์เปิด ทางผิดให้ $120e^{m}=120e^{-0.00125}=\$119.85$ ซึ่งเป็น median ทางถูกคือ $120e^{m+s^2/2}=\$139.42$ ตัวเลขผิดต่ำไป $(139.42-119.85)/139.42\approx14\%$ ของราคาเฉลี่ย

ใช้ μ เป็นอัตราโตของ median: ความผิดข้อนี้กลับทิศกับข้อแรก คือเอา mean ไปใช้แทน median คนที่ลืม volatility drag จะคิดว่าราคาตรงกลางปีหน้าคือ $120e^{0.15}=\$139.42$ ซึ่งเป็น mean ค่าจริงของ median คือ $120e^{0.15-0.3025/2}=\$119.85$ จึงประเมินสูงไป $139.42-119.85=\$19.57$ ยิ่งความผันผวนสูง ยิ่งผิดมาก เพราะส่วนที่ลืมคือ $\sigma^2/2$

สับสน σ ของ log return กับ SD ของราคา: σ = 55% ไม่ได้แปลว่า SD ของราคาคือ $0.55\times120=\$66$ ค่าจริงจากขั้นที่ 8 คือ \$82.86

ใช้ Normal กับราคาตรง ๆ: ถ้าวาง Normal ที่มี mean \$139.42 และ SD \$82.86 ลงบนแกนราคาเลย โอกาสที่ราคาติดลบคือ $\Phi\big((0-139.42)/82.86\big)=\Phi(-1.683)\approx4.6\%$ แต่ราคาหุ้นติดลบไม่ได้ แบบจำลองนี้จึงผิดตั้งแต่ต้น Lognormal แก้เรื่องนี้ได้

แต่ Lognormal ก็มีข้อจำกัดของตัวเองสามข้อ

  • ราคาใน Lognormal เข้าใกล้ศูนย์ได้แต่ไม่เคยถึง จึงจำลองบริษัทล้มละลายไม่ได้
  • ราคาจริงกระโดดได้ในวันที่มีข่าวใหญ่ แต่ Lognormal สร้างจากการขยับเล็ก ๆ จำนวนมากที่อิสระกัน (ตามที่ภาพรวมก่อนลงสูตรเล่า) จึงไม่มีการกระโดดก้อนใหญ่อยู่ในตัว
  • ผลตอบแทนจริงมีหางหนากว่า Lognormal คือเหตุการณ์สุดโต่งเกิดบ่อยกว่าที่สูตรบอก

ข้อสามเห็นได้ชัดในตลาด option ซึ่งเป็นสัญญาที่ให้สิทธิซื้อหรือขายหุ้นในราคาที่ตกลงไว้ล่วงหน้า ราคาที่ตกลงไว้นี้เรียกว่า strike มีสูตรมาตรฐานที่ใช้ Lognormal คำนวณราคา option คือ สูตร Black–Scholes ในตลาดจริง option ที่มี strike ไกลจากราคาหุ้นวันนี้ซื้อขายกันแพงกว่าที่สูตรนี้คำนวณได้ เพราะคนในตลาดรู้ว่าราคาวิ่งไปไกลได้บ่อยกว่าที่ Lognormal บอก ภาพนี้มีชื่อเรียกว่า volatility smile

ใช้ distribution ปลายทางตอบคำถามเรื่องเส้นทาง: สูตรในหน้านี้บอกราคา ณ วันสิ้นปีเท่านั้น ถ้าผู้จัดการตั้ง stop-loss ไว้ที่ \$80 (คำสั่งขายอัตโนมัติเมื่อราคาแตะ \$80) สูตรนี้ตอบไม่ได้ว่าระหว่างปีราคาจะแตะ \$80 หรือไม่ ราคาอาจลงไปแตะแล้วกลับขึ้นมาจบปีสูงกว่า \$80 ก็ได้ คำถามแบบนี้ต้องใช้แบบจำลองเส้นทางอย่าง geometric Brownian motion

ใช้ทำอะไรในงานจริง

งานแรกคือตั้งราคา option ซึ่งเป็นสัญญาที่ให้สิทธิซื้อหรือขายหุ้นในราคาที่ตกลงไว้ล่วงหน้า สูตร Black–Scholes ที่ใช้ตั้งราคา option กันทั่วโลก สมมติว่าราคาหุ้น ณ วันหมดอายุของ option เป็น Lognormal แบบในหน้านี้

งานที่สองคือ Monte Carlo คือการสุ่มราคาปลายทางหลายหมื่นครั้งแล้วเฉลี่ยผล แบบที่ทำในรูปการจำลองของขั้นที่ 8 งานนี้มักเริ่มจาก SDE (stochastic differential equation) ซึ่งเป็นสมการที่บอกว่าราคาขยับทีละนิดแบบสุ่มอย่างไร สูตร $S_T=S_0e^{m+sZ}$ คือเครื่องสุ่มราคาที่ใช้ในหน้า การจำลอง SDE

งานตั้งราคา option มีข้อควรระวังสำคัญหนึ่งข้อ drift ของราคาเฉลี่ย $\mu$ ที่ใช้พยากรณ์ราคาในโลกจริง ไม่ใช่ตัวที่ใช้ตั้งราคา option ตอนตั้งราคา option ต้องเปลี่ยน $\mu$ เป็นอัตราดอกเบี้ยไร้ความเสี่ยง อัตรานี้คือดอกเบี้ยที่ได้จากการให้รัฐบาลกู้ระยะสั้น เหตุผลที่ต้องเปลี่ยนอยู่ในหน้า Girsanov และ risk-neutral measure ซึ่งอธิบายสองเรื่อง เรื่องแรกคือ risk-neutral measure เป็นการให้น้ำหนักโอกาสชุดใหม่ ที่ทำให้ราคาทุกสินทรัพย์โตเฉลี่ยเท่าดอกเบี้ยไร้ความเสี่ยง เรื่องที่สองคือ Girsanov เป็นทฤษฎีบทที่บอกว่าเปลี่ยน drift แบบนี้ได้อย่างไร โดยความผันผวนไม่เปลี่ยน

งานที่สามคือการอ่านรายงานผลกองทุน กองทุนมักรายงานค่าเฉลี่ยเลขคณิตของผลตอบแทนรายปี $\bar r$ ค่านี้สูงกว่าอัตราโตทบต้นต่อปี $g$ เว้นแต่ผลตอบแทนทุกปีเท่ากัน ขั้นที่ 5 ให้ค่าประมาณของส่วนต่างนี้ไว้ว่า $\bar r-g\approx v/2$ โดย $v$ คือ variance ของผลตอบแทนรายปี ลองกับกองทุนในขั้นที่ 1 ซึ่งรายงาน $\bar r=5\%$ แต่เงินโตจริง $g=3.92\%$ และขั้นที่ 5 หาไว้แล้วว่า $v=0.0225$

\[\begin{aligned}\bar r-g&=0.05-0.0392=0.0108\\v/2&=0.0225/2=0.01125\end{aligned}\]

สองค่าใกล้กัน ส่วนที่ค่าเฉลี่ยเลขคณิตเกินเงินที่โตจริงคือราวครึ่งหนึ่งของ variance กองทุนที่รายงานแต่ค่าเฉลี่ยเลขคณิตจึงดูดีเกินจริง และยิ่งผลตอบแทนแกว่งแรง ยิ่งดูดีเกินจริงมาก

โจทย์ตรวจความเข้าใจ

1. ผู้จัดการกองทุนในโจทย์เปิดถามต่อว่า ถ้าถือไปสองปีแทนหนึ่งปีจะเป็นอย่างไร ใช้หุ้นตัวเดิม

  • ราคาวันนี้ $S_0=\$120$
  • ราคาเฉลี่ยโต $\mu=0.15$ ต่อปี
  • ความผันผวน $\sigma=0.55$ ต่อปี
  • แต่มองไปข้างหน้า $T=2$ ปี

หา $m$, $s$, ราคาเฉลี่ย และ median ของราคาปลายปีที่สอง

เฉลย

ใช้สูตรของขั้นที่ 5 กับ $T=2$ แล้วแทนในสูตรของขั้นที่ 4

\[ \begin{aligned} m&=\big(0.15-0.3025/2\big)\times2=-0.0025\\ s&=0.55\sqrt2\approx0.7778\\ \mathbb E[S_T]&=120\,e^{0.15\times2}=120\,e^{0.30}\approx\$161.98\\ \operatorname{median}&=120\,e^{-0.0025}\approx\$119.70 \end{aligned} \]

ราคาเฉลี่ยโตต่อ แต่ median ทรงตัว เพราะ drift ของ log return ติดลบเล็กน้อย ช่องว่างระหว่างสองตัวกว้างขึ้นตามเวลา เพราะตัวคูณ $e^{s^2/2}=e^{\sigma^2T/2}$ โตตาม $T$ หนึ่งปีได้ $e^{0.3025\times1/2}=e^{0.15125}=1.163$ สองปีได้ $e^{0.3025\times2/2}=e^{0.3025}=1.353$

2. ทีมวิจัยอีกทีมเขียนรายงานว่า “ราคาเฉลี่ยปีหน้าสูงกว่าวันนี้ 15% พอดี” ซึ่งแปลว่า simple return ที่คาดหวังเป็น 15% ราคาเฉลี่ยปีหน้าจึงเป็น $120\times1.15=\$138$ ความผันผวนยังเป็น $\sigma=0.55$ ทีมนี้ใช้ μ เท่าไร และ median ของราคาปีหน้าเป็นเท่าไร

เฉลย

ราคาเฉลี่ยหนึ่งปีคือ $120e^{\mu}$ ตั้งให้เท่ากับ \$138 แล้วแก้หา μ จากนั้นหา $m$ และ median

\[ \begin{aligned} 120\,e^{\mu}&=138\\ e^{\mu}&=138/120=1.15\\ \mu&=\ln1.15\approx0.1398\\ m&=0.1398-0.3025/2\\ &=0.1398-0.1513=-0.0115\\ \operatorname{median}&=120\,e^{-0.0115}\approx\$118.63 \end{aligned} \]

ตรวจอีกทางได้ เพราะ median คือราคาเฉลี่ยหารด้วยตัวคูณ $e^{s^2/2}$ จึงได้ $138e^{-0.3025/2}\approx\$118.63$ ตรงกัน ข้อนี้ชี้ว่า μ = 15% ในโจทย์หลักไม่ได้แปลว่าราคาเฉลี่ยสูงกว่าวันนี้ 15% เพราะ μ เป็นอัตราทบต้นต่อเนื่อง simple return ที่คาดหวังคือ $e^{0.15}-1=16.18\%$

3. กองทุนอีกกองได้ผลตอบแทน +30% ในปีแรก และ −20% ในปีที่สอง ผู้ขายกองทุนโฆษณาว่า “เฉลี่ยปีละ 5%” หาค่าเฉลี่ยเลขคณิต ผลตอบแทนทบต้นต่อปี แล้วตรวจด้วยค่าประมาณ volatility drag

เฉลย

ให้ $\bar r$ คือค่าเฉลี่ยเลขคณิต และ $g$ คืออัตราโตทบต้นต่อปีแบบในขั้นที่ 1 ส่วน $v$ คือ variance ของผลตอบแทนรายปีสองค่า (ปีแรกกับปีที่สอง) หา $v$ โดยเอาผลตอบแทนแต่ละปีลบค่าเฉลี่ย ยกกำลังสอง แล้วหารด้วย 2 เพราะมีสองปี ค่าประมาณ volatility drag ใช้ $\bar r$ แทน $\mu$ และใช้ $v$ แทน $\sigma^2$ เหมือนในขั้นที่ 5 ทุกตัวเขียนเป็นทศนิยม

\[ \begin{aligned} \bar r&=\big(0.30+(-0.20)\big)/2=0.05\\ (1+g)^2&=1.30\times0.80=1.04\\ g&=\sqrt{1.04}-1\approx0.0198\\ 0.30-\bar r&=+0.25\\ -0.20-\bar r&=-0.25\\ v&=(0.25^2+0.25^2)/2=0.0625\\ \bar r-v/2&=0.05-0.03125\\ &=0.01875\approx1.9\% \end{aligned} \]

ค่าประมาณ 1.9% ใกล้ค่าจริง 1.98% ค่าเฉลี่ยเลขคณิต 5% เท่ากับกองทุน +20% แล้ว −10% ในขั้นที่ 1 แต่กองนี้ผันผวนกว่า เงินจึงโตได้แค่ราวครึ่งหนึ่ง คือ 1.98% เทียบกับ 3.92%

function Phi(z) {
  const n = 10000, h = Math.abs(z) / n;
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(z) * h * s / 3;
}

console.log(1.2 * 0.9, Math.sqrt(1.2 * 0.9) - 1);       // 1.08 0.0392

const S0 = 120, mu = 0.15, sigma = 0.55, T = 1;
const s2 = sigma ** 2 * T, s = Math.sqrt(s2), m = mu * T - s2 / 2;
const mean = S0 * Math.exp(m + s2 / 2), median = S0 * Math.exp(m), mode = S0 * Math.exp(m - s2);
console.log(m, mean, median, mode);                      // -0.00125 139.42 119.85 88.57
const below = K => Phi((Math.log(K / S0) - m) / s);
console.log(1 - below(120), below(100), 1 - below(160)); // 0.4991 0.3710 0.2997
console.log(1 - below(156), below(84));                  // 0.3159 0.2591
const z95 = 1.644854;
console.log(S0 * Math.exp(m - s * z95), S0 * Math.exp(m + s * z95)); // 48.50 296.16
const variance = S0 ** 2 * Math.exp(2 * m + s2) * Math.expm1(s2);
console.log(variance, Math.sqrt(variance), Math.sqrt(Math.expm1(s2))); // 6866 82.86 0.594

สิ่งที่ควรตอบได้หลังอ่าน

  • gross return คูณกัน log return บวกกัน กองทุนที่ได้ +20% แล้ว −10% โตรวม $1.20\times0.90=1.08$ เท่าในสองปี หรือปีละ 3.92% แบบทบต้น ไม่ใช่ 5%
  • ถ้า log return $\ln(S_T/S_0)$ เป็น Normal ที่มีค่าเฉลี่ย $m$ และ SD $s$ ราคาจะเป็น Lognormal ซึ่งเป็นบวกเสมอ มี median $S_0e^m$, mean $S_0e^{m+s^2/2}$ และ mode $S_0e^{m-s^2}$
  • ตัวคูณ $e^{s^2/2}$ ที่ทำให้ mean สูงกว่า median มาจาก MGF ของ Normal และคือ Jensen's inequality ในรูปตัวเลข
  • ถ้าอยากให้ราคาเฉลี่ยโตในอัตรา μ ต้องตั้ง $m=(\mu-\sigma^2/2)T$ ส่วนต่าง $\sigma^2/2$ คือ volatility drag ที่ความผันผวนกัดผลตอบแทนทบต้น
  • หุ้น \$120 ที่ μ = 15% และ σ = 55% มองไปหนึ่งปี มี mean \$139.42, median \$119.85, mode \$88.57, โอกาสกำไร 49.9%, ช่วงราคาที่มีโอกาส 90% คือ \$48.50 ถึง \$296.16 และ SD ของราคา \$82.86 ทั้งหมดคำนวณไว้ในขั้นที่ 6 ถึง 8
