1.10 The Lognormal Distribution

ราคาคูณกัน แต่ log return บวกกัน: แยกค่าเฉลี่ยของราคาออกจากราคาของผลลัพธ์กึ่งกลาง

ราคาวันนี้ \$120 แบบจำลองให้ราคาเฉลี่ยปีหน้า \$139.42 แต่โอกาสที่ปีหน้าราคาจะสูงกว่า \$120 กลับต่ำกว่า 50% เล็กน้อย ตัวเลขขัดกันหรือไม่?

เปิดคำตอบตั้งต้น

ไม่ขัดกัน ราคาเฉลี่ยอาจถูกดึงขึ้นด้วยราคาสูงในหางขวา ส่วนโอกาสกำไรนับว่าราคาผ่านเกณฑ์ \$120 หรือไม่ ไม่ได้ให้น้ำหนักตามขนาดกำไร เราจะสร้างตัวอย่างนี้ทีละส่วนและหาทั้ง mean, median และ mode

หัวใจของบทคือไม่สลับสามสิ่ง: simple return, log return และราคา ทั้งสามเชื่อมกันได้ แต่ค่าเฉลี่ยและหน่วยไม่ใช่สิ่งเดียวกัน

เริ่มจากการเปลี่ยนราคาจริงสองช่วง

เงิน \$100 ขึ้น 10% เป็น \$110 แล้วลง 10% เหลือ \$99 แม้ $10\%-10\%=0$ แต่ผลตอบแทนรวมเป็น −1% เพราะการขึ้นและลงใช้ฐานเงินต่างกัน ผลตอบแทนหลายช่วงจึงรวมด้วยการคูณ gross return ซึ่งเท่ากับหนึ่งบวก simple return

ขั้นที่ 1 — เปลี่ยนผลคูณราคาเป็นผลบวก log return

ให้ $r_t$ เป็น simple return ของช่วงที่ $t$ และ $R_t$ เป็น log return เมื่อราคาต้นและปลายช่วงเป็นบวก

\[ \begin{aligned} 1+r_t&=\frac{S_t}{S_{t-1}}\\ R_t&\equiv\ln\frac{S_t}{S_{t-1}}=\ln(1+r_t)\\ \frac{S_2}{S_0}&=(1+r_1)(1+r_2)\\ \ln\frac{S_2}{S_0}&=R_1+R_2\\[3pt] 1.10(0.90)&=0.99\\ \ln(1.10)+\ln(0.90)&=\ln(0.99)\approx-0.0100503\\ e^{-0.0100503}-1&\approx-0.01=-1\% \end{aligned} \]

Log return บวกข้ามเวลาได้เป็นเอกลักษณ์ทางพีชคณิต ไม่ต้องสมมติ independence หรือ Normal ส่วนการใช้ $R\approx r$ เป็นเพียงค่าประมาณเมื่อผลตอบแทนมีขนาดเล็ก และใช้ไม่ได้กับการขาดทุน 100% เพราะราคาศูนย์ไม่มี logarithm ที่เป็นจำนวนจริงจำกัด

เมื่อไรจึงเรียกว่า Lognormal

ตอนนี้เพิ่มสมมติฐานใหม่: log return รวมตลอดช่วงเป็น Normal ให้ $R=\ln(S_T/S_0)\sim N(m,s^2)$ โดย $m$ เป็นค่าเฉลี่ย log return และ $s$ เป็น standard deviation ของ log return ตลอดช่วงนั้น ไม่ใช่ค่าเฉลี่ยและ SD ของราคา

ถ้า $Z\sim N(0,1)$ เราสร้าง $R=m+sZ$ ได้ เมื่อ exponentiate กลับ ราคาปลายทาง $S_T=S_0e^R$ จึงมี Lognormal distribution เพราะ logarithm ของราคานั้นเป็น Normal

ขั้นที่ 2 — แปลง log return เป็นราคาโดยไม่เปลี่ยนความหมายของพารามิเตอร์

\[ \begin{aligned} R&=m+sZ\\ S_T&=S_0e^{m+sZ}\\ &=S_0e^m e^{sZ}\\[3pt] S_0=100,\ m=0.10,\ s=0.20&:\\ Z=-1&\quad\Longrightarrow\quad S_T=100e^{-0.10}\approx90.48\\ Z=0&\quad\Longrightarrow\quad S_T=100e^{0.10}\approx110.52\\ Z=1&\quad\Longrightarrow\quad S_T=100e^{0.30}\approx134.99 \end{aligned} \]

ค่าของ $Z$ ทั้งสามเป็นจุดสำหรับลองแทน ไม่ใช่สามผลลัพธ์ที่มีโอกาสเท่ากัน Normal เป็นแบบต่อเนื่องจึงให้โอกาสรายจุดเป็นศูนย์ ความสมมาตรของมันหมายถึงโอกาสในช่วงของ $Z$ ที่สมมาตรกัน ไม่ใช่ช่วงราคาที่มีความกว้างเป็นดอลลาร์เท่ากัน

ทำไม exponentiate ค่าเฉลี่ยแล้วจึงไม่เท่ากับราคาเฉลี่ย

พักจาก Normal แล้วใช้เหรียญยุติธรรมหนึ่งครั้ง: เริ่ม \$100 ถ้าหัวราคาคูณสอง ถ้าก้อยราคาหารสอง จึงมีราคา \$200 กับ \$50 อย่างละโอกาสครึ่งหนึ่ง Log return เป็น $+\ln2$ กับ $-\ln2$

ค่าเฉลี่ย log return เป็นศูนย์ จึงได้ $100e^{\mathbb E[R]}=100$ แต่ค่าเฉลี่ยราคาจริงในแบบจำลองเหรียญคือ $(200+50)/2=125$ การแปลงก่อนเฉลี่ยกับเฉลี่ยก่อนแปลงให้คนละคำตอบ

ถ้าต้องการให้ราคาเฉลี่ยของเหรียญนี้เท่ากับ \$100 ต้องคูณทั้งสองราคาด้วย $100/125=0.8$ ได้ \$160 กับ \$40 หรือเลื่อน log return ทุกกรณีลงด้วย $\ln(0.8)=-\ln(1.25)\approx-0.223144$

ค่านี้ไม่ใช่ $-(\ln2)^2/2\approx-0.240227$ สูตรลบครึ่ง variance ที่จะใช้ต่อไปมาจากสมมติฐาน Normal ไม่ใช่สูตรชดเชยที่ใช้ตรงได้กับ log return ทุกชนิด

หาค่าเฉลี่ยของ exponential ภายใต้ Normal

จากหัวข้อ 1.9 Standard Normal มี MGF เท่ากับ $\mathbb E[e^{aZ}]=e^{a^2/2}$ เราทบทวนเหตุผลด้วยการเติมกำลังสอง เพื่อให้เห็นว่าครึ่ง variance ปรากฏตรงไหน

ขั้นที่ 3 — พิสูจน์ตัวคูณที่เพิ่มเข้ามาในค่าเฉลี่ยราคา

\[ \begin{aligned} az-\frac{z^2}{2}&=-\frac{(z-a)^2}{2}+\frac{a^2}{2}\\ \mathbb E[e^{aZ}]&=e^{a^2/2}\int_{-\infty}^{\infty}\frac{e^{-(z-a)^2/2}}{\sqrt{2\pi}}\,dz\\ &=e^{a^2/2}\\[3pt] \mathbb E[S_T]&=S_0e^m\mathbb E[e^{sZ}]\\ &=\boxed{S_0e^{m+s^2/2}} \end{aligned} \]

Integral เป็นพื้นที่ของ Normal ที่เลื่อนไป จึงเท่ากับหนึ่ง ส่วน $S_0e^m$ ย้ายออกนอก expectation ได้เพราะเป็นค่าคงที่ตามกฎ linearity ในหัวข้อ 1.3 ถ้าแทน $a=s$ ตัวคูณจากการเฉลี่ยส่วนสุ่มคือ $e^{s^2/2}$ ไม่ใช่หนึ่ง

Jensen's inequality เป็นชื่อของความต่างที่เพิ่งเห็น

เมื่อ expectation ที่เกี่ยวข้องมีอยู่ ความนูนของ exponential ให้ $\mathbb E[e^R]\ge e^{\mathbb E[R]}$ และเป็นมากกว่าอย่างเคร่งครัดเมื่อ $R$ ไม่เป็นค่าคงที่ ดังนั้น “log return เฉลี่ยศูนย์” ไม่เท่ากับ “ราคาเฉลี่ยไม่เปลี่ยน”

ข้อความนี้ไม่ใช่กำไรฟรีจากความผันผวน หากกำหนดราคาเฉลี่ยปลายทางไว้แล้ว การเพิ่มความผันผวนต้องเปลี่ยนพารามิเตอร์อื่นให้เป้าหมายยังเท่าเดิม เราจะทำการปรับนั้นอย่างชัดเจนในขั้นถัดไป

ขั้นที่ 4 — กำหนดเป้าหมายราคาเฉลี่ย แล้วแก้ค่าเฉลี่ย log return

กำหนดเป้าหมาย $\mathbb E[S_T]=S_0e^{\mu T}$ โดย $T$ วัดเป็นปีและ $\mu$ เป็นอัตราเติบโตแบบ exponential ของราคาเฉลี่ย จากนั้นเทียบกับสูตรที่พิสูจน์แล้ว

\[ \begin{aligned} S_0e^{m+s^2/2}&=S_0e^{\mu T}\\ m+s^2/2&=\mu T\\ m&=\mu T-s^2/2\\[3pt] s^2&=\sigma^2T,\qquad s=\sigma\sqrt T\\ m&=(\mu-\sigma^2/2)T\\ S_T&=\boxed{S_0\exp\left[(\mu-\sigma^2/2)T+\sigma\sqrt T\,Z\right]} \end{aligned} \]

การใช้ $s^2=\sigma^2T$ เพิ่มสมมติฐานว่า log return สะสมมี variance ต่อหน่วยเวลาคงที่และบวกตามเวลาได้ เช่น Normal increments ที่เป็นอิสระในช่วงไม่ทับกัน ถ้ามี covariance หรือ volatility เปลี่ยน ต้องปรับการรวม variance

เทอม $-\sigma^2T/2$ ทำให้ค่าเฉลี่ยราคาตรงเป้าหมายที่กำหนด ไม่ใช่ค่าธรรมเนียมที่ถูกหักจากทุกเส้นทางเพราะตลาดเรียกเก็บ และไม่ได้บอกว่าหุ้นจริงต้องมีสมการนี้

ตรวจด้วยตัวเลขเล็กก่อนใช้โจทย์หลัก

เริ่ม \$100 ต้องการราคาเฉลี่ย $100e^{0.10}\approx\$110.52$ และกำหนด $s=0.20$ หากตั้ง $m=0.10$ จะได้ mean $100e^{0.10+0.02}\approx\$112.75$ ซึ่งสูงกว่าเป้าหมาย

ค่า $m$ ที่ตรงเป้าคือ $0.10-0.20^2/2=0.08$ จากนั้น mean กลับเป็น $100e^{0.08+0.02}=100e^{0.10}$ การตั้ง drift จึงต้องเริ่มจากระบุให้ชัดว่าตัวเลขที่ต้องการเป็นค่าเฉลี่ยของอะไร

ขั้นที่ 5 — หา mean และ median แล้วตอบคำถามเปิดครึ่งแรก

Median เป็นราคาแบ่งโอกาสซ้ายขวาอย่างละครึ่ง เพราะ $P(Z\le0)=1/2$ และ exponential เพิ่มตามค่า input จึงใช้ $Z=0$ หาระดับ median ได้ แต่ไม่ได้หมายความว่า $Z$ ต้องเกิดที่ศูนย์จริง

\[ \begin{aligned} s^2&=0.55^2(1)=0.3025\\ m&=0.15-0.3025/2=-0.00125\\ \operatorname{median}(S_T)&=S_0e^m\\ &=120e^{-0.00125}\approx\boxed{\$119.85}\\ \mathbb E[S_T]&=S_0e^{\mu T}\\ &=120e^{0.15}\approx\boxed{\$139.42}\\ \frac{\mathbb E[S_T]}{\operatorname{median}(S_T)}&=e^{s^2/2}\approx1.163288 \end{aligned} \]

Median อยู่ต่ำกว่าราคาเริ่มต้นเล็กน้อย แต่ mean สูงกว่า เพราะการเฉลี่ยราคาให้น้ำหนักตามขนาดราคาในหางขวาด้วย Mean ไม่ใช่ราคาที่มีโอกาสเกิดสูงสุด และไม่รับรองว่าผู้ถือหนึ่งคนจะได้ผลตอบแทนเท่าค่าเฉลี่ย

ขั้นที่ 6 — เปลี่ยนเกณฑ์ราคาให้เป็นเกณฑ์ของ Standard Normal

สำหรับเกณฑ์ราคา $K\gt0$ ใช้ logarithm ซึ่งเป็น function เพิ่ม จึงรักษาทิศทางอสมการ จากนั้นลบ $m$ และหาร $s\gt0$

\[ \begin{aligned} P(S_T\le K)&=P(S_0e^{m+sZ}\le K)\\ &=P(m+sZ\le\ln(K/S_0))\\ &=\Phi\left(\frac{\ln(K/S_0)-m}{s}\right)\\[3pt] P(S_T\gt S_0)&=1-\Phi(-m/s)\\ &=1-\Phi(0.00125/0.55)\\ &\approx\boxed{49.9093\%} \end{aligned} \]

นี่ตอบคำถามเปิดครบ: mean ประมาณ \$139.42 อยู่ร่วมกับโอกาสกำไรประมาณ 49.91% ได้ ถ้า $K\le0$ โอกาส $S_T\le K$ เป็นศูนย์ใน Lognormal จึงไม่ควรฝืนใส่ $K$ ลงใน logarithm

ใช้ $\Phi(z)$ สำหรับเหตุการณ์ต่ำกว่าเกณฑ์ และ $1-\Phi(z)$ สำหรับสูงกว่าเกณฑ์ ช่วง ±30% สมมาตรใน simple return แต่ $\ln(1.30)$ ไม่เท่ากับ $-\ln(0.70)$ จึงไม่สมมาตรใน log return

ขั้นที่ 7 — ย้อน probability เป็นช่วงราคาปลายทาง

ให้ $q_p$ เป็น quantile ที่ทำให้โอกาสราคาต่ำกว่าระดับนั้นเท่ากับ $p$ แก้สมการ CDF เดิมกลับเป็นราคา

\[ \begin{aligned} \Phi\left(\frac{\ln(q_p/S_0)-m}{s}\right)&=p\\ \ln(q_p/S_0)&=m+s\Phi^{-1}(p)\\ q_p&=S_0e^{m+s\Phi^{-1}(p)}\\[3pt] q_{0.05}&=120e^{-0.00125+0.55(-1.644854)}\\ &\approx\$48.50\\ q_{0.95}&=120e^{-0.00125+0.55(1.644854)}\\ &\approx\$296.16 \end{aligned} \]

ช่วงกลาง 90% ของราคาปลายปีจึงประมาณ \$48.50 ถึง \$296.16 ตามแบบจำลอง ไม่สมมาตรเป็นดอลลาร์รอบ mean หรือ median และไม่ใช่ช่วงที่ราคาตลอดทั้งปีต้องอยู่ภายใน

ขั้นที่ 8 — หา variance ของราคาจาก moment ลำดับสอง

ใช้ผล $\mathbb E[e^{aZ}]=e^{a^2/2}$ เดิม แต่แทน $a=2s$ เพื่อเฉลี่ยราคากำลังสอง จากนั้นลบกำลังสองของ mean

\[ \begin{aligned} \mathbb E[S_T^2]&=S_0^2e^{2m}\mathbb E[e^{2sZ}]\\ &=S_0^2e^{2m+2s^2}\\ (\mathbb E[S_T])^2&=S_0^2e^{2m+s^2}\\ \operatorname{Var}(S_T)&=S_0^2e^{2m+s^2}(e^{s^2}-1)\\ &=S_0^2e^{2\mu T}(e^{\sigma^2T}-1)\\ &=120^2e^{0.30}(e^{0.3025}-1)\\ &\approx6{,}866.22\text{ dollars}^2\\ \operatorname{SD}(S_T)&\approx\boxed{\$82.86} \end{aligned} \]

Variance มีหน่วยดอลลาร์² ส่วน SD กลับมาเป็นดอลลาร์ ค่า $s=0.55$ เป็น SD ของ log return ไม่ใช่ SD ของราคา และไม่ใช่ SD ของ simple return โดยตรง การแปลงกลับผ่าน exponential ทำให้ความสัมพันธ์ไม่เป็นเส้นตรง

ขั้นที่ 9 — เปรียบเทียบความผันผวนราคาเป็นสัดส่วนของ mean

Coefficient of variation หรือ CV คือ SD หารด้วย mean ซึ่งในโจทย์ราคานี้ mean เป็นบวก

\[ \begin{aligned} \operatorname{SD}(S_T)&=S_0e^{\mu T}\sqrt{e^{\sigma^2T}-1}\\ CV&\equiv\frac{\operatorname{SD}(S_T)}{\mathbb E[S_T]}\\ &=\sqrt{e^{\sigma^2T}-1}\\ &=\sqrt{e^{0.3025}-1}\approx59.4338\% \end{aligned} \]

59.43% วัดเทียบกับราคาเฉลี่ย ไม่ใช่ราคาเริ่มต้น ส่วนการหาร SD ของราคาด้วย $S_0$ จะให้ SD ของ simple return ในโจทย์นี้ จึงเป็นคนละสัดส่วน อย่าสลับ CV กับ annualized log volatility 55%

เหลือจุดสำคัญอีกหนึ่งจุด: mode อยู่ตรงไหน

Mode ของ distribution ต่อเนื่องหมายถึงตำแหน่งที่ PDF สูงสุด ไม่ใช่ราคาที่มี probability รายจุดสูงสุด เพราะทุกจุดมีโอกาสศูนย์เหมือนกัน เราจะหา PDF จากอนุพันธ์ของ CDF แล้วหาจุดสูงสุดของความหนาแน่นราคา

ขั้นที่ 10 — สร้าง density ของราคาและหาจุดยอด

สำหรับ $x\gt0$ ใช้ chain rule กับ $F_S(x)=\Phi([\ln(x/S_0)-m]/s)$ ส่วนขอบด้านที่ราคาไม่เป็นบวก density เป็นศูนย์

\[ \begin{aligned} f_S(x)&=\frac1{xs\sqrt{2\pi}}\exp\left[-\frac{(\ln(x/S_0)-m)^2}{2s^2}\right]\\ \ln f_S(x)&=-\ln x-\ln(s\sqrt{2\pi})\\ &\quad-\frac{(\ln(x/S_0)-m)^2}{2s^2}\\ \frac{d}{dx}\ln f_S(x)&=-\frac1x-\frac{\ln(x/S_0)-m}{s^2x}\\ 0&=-1-\frac{\ln(x/S_0)-m}{s^2}\\ x_{\text{mode}}&=S_0e^{m-s^2}\\ &=120e^{-0.00125-0.3025}\approx\boxed{\$88.57} \end{aligned} \]

อนุพันธ์เปลี่ยนจากบวกเป็นลบเมื่อผ่านจุดนี้ จึงเป็นจุดสูงสุด เมื่อ $s\gt0$ ได้ mode ต่ำกว่า median และ median ต่ำกว่า mean จุดสูงสุดของ density ราคาไม่ใช่แค่ exponentiate จุดสูงสุดของ density log return เพราะมีตัวปรับ $1/x$ เพิ่มเข้ามา

$m=(0.15-0.55^2/2)(2)=-0.0025$ และ $s=0.55\sqrt2\approx0.777817$ ค่าเฉลี่ยราคาคือ $120e^{0.30}\approx\$161.98$ ส่วน median คือ $120e^{-0.0025}\approx\$119.70$

Mean เพิ่มตามเป้าหมาย แต่ median ลดเล็กน้อยเพราะ drift ของ log return ในชุดพารามิเตอร์นี้เป็นลบ ต้องใช้สมมติฐานการสะสมตลอดสองปีด้วย ไม่ใช่นำพารามิเตอร์ระยะสั้นไปขยายโดยไม่ตรวจการเปลี่ยนสภาวะ

ลองทำเอง 2 — หากต้องการ expected simple return 15% จริง ๆ

คง $S_0=120,\sigma=0.55,T=1$ แต่เปลี่ยนเป้าหมายเป็นราคาเฉลี่ย $120(1.15)=138$ ต้องใช้ $\mu$ และ median เท่าไร?

เปิดคำตอบ

แก้ $e^\mu=1.15$ ได้ $\mu=\ln(1.15)\approx0.139762$ จากนั้น $m=\ln(1.15)-0.55^2/2$ จึงมี median $138e^{-0.15125}\approx\$118.63$

หากใช้ $\mu=0.15$ อย่างเดิมจะได้ mean \$139.42 ไม่ใช่ \$138 ความต่างมาจากการตีความพารามิเตอร์ ไม่ใช่ความผิดพลาดของเครื่องคิดเลข

ตรวจเองใน 10 วินาที: เมื่อตั้ง $\sigma=0$ ราคาปลายทางเป็นค่าคงที่ $S_0e^{\mu T}$ จึงมี mean, median และค่าที่เกิดจริงตรงกัน สูตร PDF สำหรับ $s\gt0$ ใช้กับกรณีนี้ตรง ๆ ไม่ได้ เพราะเป็น point mass

ราคาปลายทางไม่ใช่เส้นทาง และความเสี่ยงราคาไม่ใช่ความเสี่ยงทั้งหมด

การให้ $S_T$ มี Lognormal distribution ยังไม่กำหนดว่าระหว่างทางราคาเคลื่อนอย่างไร การถามว่าจะเคยต่ำกว่า stop-loss หรือแตะ barrier ก่อนเวลาหรือไม่ต้องมีแบบจำลองเส้นทางเพิ่ม แม้สูตรปลายทางนี้จะเข้ากับแบบจำลอง Geometric Brownian Motion ก็ยังต้องระบุสมมติฐานของ process นั้น

Lognormal ไม่มีมวลที่ราคาศูนย์ จึงไม่แทนการล้มละลายที่มีโอกาสบวกได้ครบ การถือหุ้นเต็มจำนวนโดยไม่กู้จำกัดการเสียเงินจากราคาที่เงินลงเริ่มต้น แต่การใช้ leverage, margin หรืออนุพันธ์ไม่ได้รับขอบเขตการขาดทุนเดียวกันโดยอัตโนมัติ

ค่า $\mu$ ที่อธิบายผลตอบแทนภายใต้มาตรวัดจริงไม่ใช่ drift สำหรับตั้งราคา option โดยอัตโนมัติ การตั้งราคาต้องใช้มาตรวัดที่เหมาะสมและเงื่อนไขเรื่องอัตราดอกเบี้ย เงินปันผล และการคิดลด ไม่ใช่เพียงใส่ expected return ของหุ้นลงในสูตร

ตรวจราคาเฉลี่ย variance และโอกาสด้วย JavaScript 
const S0 = 120, mu = 0.15, sigma = 0.55, T = 1;
const s2 = sigma ** 2 * T, s = Math.sqrt(s2), m = mu * T - s2 / 2;
const mean = S0 * Math.exp(mu * T);
const median = S0 * Math.exp(m);
const mode = S0 * Math.exp(m - s2);
const variance = S0 ** 2 * Math.exp(2 * mu * T) * Math.expm1(s2);
console.log([m, s, mean, median, mode, variance, Math.sqrt(variance)]);
function Phi(z) {
  const n = 10000, h = Math.abs(z) / n;
  let sum = 0;
  for (let i = 0; i <= n; i++) {
    const w = i === 0 || i === n ? 1 : i % 2 ? 4 : 2;
    sum += w * Math.exp(-0.5 * (i * h) ** 2) / Math.sqrt(2 * Math.PI);
  }
  return 0.5 + Math.sign(z) * h * sum / 3;
}
const below = K => K <= 0 ? 0 : Phi((Math.log(K / S0) - m) / s);
console.log([1 - below(S0), below(100), 1 - below(160)]);
console.log([1 - below(156), below(84)]);
console.log([S0 * Math.exp(m - 3 * s), S0 * Math.exp(m + 3 * s)]);
console.log([120 * Math.exp(0.30), 120 * Math.exp(-0.0025)]);
console.log(138 * Math.exp(-(0.55 ** 2) / 2));

สรุป — ตั้งคำถามให้ชัดว่ากำลังเฉลี่ยอะไร

  • Gross return คูณข้ามเวลา ส่วน log return บวกข้ามเวลาได้ แต่ความบวกได้นี้ไม่ได้พิสูจน์ว่า log return เป็น Normal
  • ถ้า $R\sim N(m,s^2)$ จะได้ $\mathbb E[S_T]=S_0e^{m+s^2/2}$ และ median เท่ากับ $S_0e^m$ ค่าเฉลี่ยของราคาไม่ใช่ exponentiate ค่าเฉลี่ย log return แล้วจบ
  • การกำหนดราคาเฉลี่ยเป้าหมาย $S_0e^{\mu T}$ ภายใต้ Normal log return ให้ $m=(\mu-\sigma^2/2)T$ เทอมครึ่ง variance ผูกกับสมมติฐานนี้
  • ในโจทย์หลัก mean ประมาณ \$139.42, median \$119.85, mode \$88.57 และโอกาสราคาสูงกว่าต้นช่วงประมาณ 49.91% ตัวเลขตอบคนละคำถามจึงไม่ขัดกัน
  • Lognormal เป็นแบบจำลองราคาปลายทางที่เป็นบวก ไม่ได้รับรองว่าเก็บความเสี่ยงผิดนัด เส้นทางราคา และหางตลาดจริงครบถ้วน
