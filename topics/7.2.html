7.2 Transpose

transpose พลิกตารางข้ามแนวทแยง ช่องแถว $i$ คอลัมน์ $j$ ย้ายไปแถว $j$ คอลัมน์ $i$ พร้อมชื่อของมัน ตารางเดิมจึงตอบคำถามในทิศกลับได้โดยไม่ต้องสร้างข้อมูลใหม่

ตาราง payoff มีสองแถว (สถานะขึ้น สถานะลง) และสามคอลัมน์ (สัญญาสามตัว) ช่องละกี่ดอลลาร์ต่อหนึ่งสัญญา พอร์ตถือสัญญา 2, 6 และ 4 หน่วย จึงได้ \$50 ในสถานะขึ้นและ \$58 ในสถานะลง วันหนึ่งโปรแกรมใหม่ต้องการคูณจากอีกด้าน จึงแปลงตารางเป็นสามแถวสองคอลัมน์ ขนาดถูก คูณผ่าน แต่ได้ \$70 กับ \$32 เงินรวมสองสถานะหายไป \$6 เกิดอะไรขึ้น

ลองตอบก่อนเปิดเฉลย

โปรแกรมใช้ reshape แทน transpose reshape อ่านตัวเลขทีละแถวแล้วเทใส่ช่องใหม่ตามลำดับ ตัวเลขครบ ขนาดถูก แต่ payoff ของสัญญาที่ 3 ในสถานะขึ้นไปนั่งคู่กับ payoff ของสัญญาที่ 1 ในสถานะลง โปรแกรมจึงคูณจำนวนสัญญากับ payoff ผิดตัว transpose ที่ถูกต้องให้ $(50,58)$ เท่าเดิม เงินไม่ได้หายจากพอร์ต มันหายจากการจับคู่ข้อมูล

ภาพรวมก่อนลงสูตร

ใน หน้าที่แล้ว ตาราง loading เดียวตอบได้สองคำถาม ส่ง factor shock เข้าทางคอลัมน์ได้ผลตอบแทนหุ้น หรือส่งเงินที่ถือเข้าทางแถวได้ exposure ของพอร์ต การเปลี่ยนทิศนี้ต้องพลิกตารางให้คอลัมน์กลายเป็นแถว เรียกว่า transpose และเขียน $A^{\mathsf T}$ กติกามีข้อเดียว: ช่องแถว $i$ คอลัมน์ $j$ ไปอยู่แถว $j$ คอลัมน์ $i$ ชื่อของแถวและคอลัมน์ย้ายตามตัวเลขไปด้วย

รูปด้านล่างใช้สีแทนชื่อสัญญา transpose ทำให้แต่ละแถวใหม่เป็นสัญญาเดียวกันทั้งแถว ส่วน reshape ที่โปรแกรมใน hook ใช้ ทำให้สัญญาปนกันในแถวเดียว ทั้งสองได้ตาราง $3\times2$ เหมือนกัน การตรวจแค่ขนาดจึงจับความผิดนี้ไม่ได้

หน้านี้สร้างกฎของ transpose จากการดูทีละช่อง แล้วใช้มันอธิบายสามเรื่องที่ใช้ทั้งเล่ม: dot product คือแถวคูณคอลัมน์ ทำไม transpose ของผลคูณต้องกลับลำดับ และทำไม covariance matrix พลิกแล้วได้ตัวเดิม ซึ่งนำไปสู่สูตรความเสี่ยงพอร์ต $\mathbf w^{\mathsf T}\Sigma\mathbf w$

ศัพท์ที่ใช้ในหัวข้อนี้
Transpose $A^{\mathsf T}$
ตารางที่ได้จากการสลับดัชนีแถวกับคอลัมน์ $(A^{\mathsf T})_{ji}=A_{ij}$ ใช้เปลี่ยนทิศของคำถามที่ตารางตอบ
Reshape
การเทตัวเลขชุดเดิมลงตารางขนาดใหม่ตามลำดับการอ่าน ไม่ได้รักษาคู่ชื่อกับค่า ใช้ได้เฉพาะเมื่อรู้ว่าลำดับการอ่านมีความหมายตรงกับที่ต้องการ
Symmetric matrix
matrix จัตุรัสที่ $A^{\mathsf T}=A$ คือ $a_{ij}=a_{ji}$ ทุกคู่ covariance matrix เป็นแบบนี้เสมอ ใช้ตรวจความถูกต้องของข้อมูลเบื้องต้น
Inner product และ outer product
$\mathbf u^{\mathsf T}\mathbf v$ ให้ตัวเลขเดียว ใช้วัดการจับคู่ของสอง vector ส่วน $\mathbf u\mathbf v^{\mathsf T}$ ให้ตารางผลคูณทุกคู่ ใช้สร้าง covariance จากข้อมูล
Quadratic form
นิพจน์ $\mathbf x^{\mathsf T}B\mathbf x$ ที่ให้ตัวเลขเดียว variance ของพอร์ตคือ quadratic form ของ covariance matrix แต่ quadratic form ทุกตัวไม่ได้เป็น variance

ขั้นที่ 1 — นิยามทีละช่อง: ชื่อย้ายตามตัวเลข

เริ่มจากตาราง payoff ใน hook แถวคือสถานะขึ้นและลง คอลัมน์คือสัญญาสามตัว พลิกมันแล้วดูว่าแต่ละช่องไปไหน

\[\begin{aligned} S&=\begin{bmatrix}2&3&7\\1&6&5\end{bmatrix},\quad S^{\mathsf T}=\begin{bmatrix}2&1\\3&6\\7&5\end{bmatrix},\\ (S^{\mathsf T})_{ji}&=S_{ij},\qquad (S^{\mathsf T})_{31}=S_{13}=7,\\ \boldsymbol\theta&=\begin{bmatrix}2\\6\\4\end{bmatrix},\quad \boldsymbol\theta^{\mathsf T}=\begin{bmatrix}2&6&4\end{bmatrix}. \end{aligned}\]

เลข 7 เดิมอยู่แถวสถานะขึ้น คอลัมน์สัญญา 3 หลังพลิกอยู่แถว 3 คอลัมน์ 1 ซึ่งตอนนี้ชื่อว่าแถวสัญญา 3 คอลัมน์สถานะขึ้น ความหมายยังเป็น “สัญญา 3 จ่าย \$7 ในสถานะขึ้น” เหมือนเดิมทุกประการ ตารางขนาด $m\times n$ กลายเป็น $n\times m$ และ column vector พลิกแล้วเป็น row vector

วิธีจำที่ไม่พลาด: นึกถึงการส่องกระจกข้ามแนวทแยงที่วิ่งจากมุมซ้ายบนลงขวาล่าง ช่องบนแนวทแยงอยู่ที่เดิม ช่องอื่นสลับฝั่ง มันไม่ใช่การหมุนกระดาษ 90 องศา เพราะการหมุนจะกลับลำดับของแกนหนึ่งด้วย

ขั้นที่ 2 — กฎพื้นฐาน และสิ่งที่ transpose ไม่ใช่

กฎของ transpose ทุกข้อพิสูจน์ได้ด้วยการดูช่องเดียว เพราะบวกและคูณด้วยตัวเลขทำทีละช่องอยู่แล้ว เมื่อ $A,B$ ขนาดเท่ากันและ $c$ เป็นตัวเลข

\[\begin{aligned} \big((A^{\mathsf T})^{\mathsf T}\big)_{ij}&=(A^{\mathsf T})_{ji}=A_{ij},\\ \big((A+B)^{\mathsf T}\big)_{ij}&=A_{ji}+B_{ji},\\ \big((cA)^{\mathsf T}\big)_{ij}&=cA_{ji}. \end{aligned}\]

จึงได้ $(A^{\mathsf T})^{\mathsf T}=A$ พลิกสองครั้งกลับที่เดิม $(A+B)^{\mathsf T}=A^{\mathsf T}+B^{\mathsf T}$ และ $(cA)^{\mathsf T}=cA^{\mathsf T}$ matrix ที่พลิกแล้วได้ตัวเดิม $A^{\mathsf T}=A$ เรียกว่า symmetric ต้องเป็นจัตุรัสและ $a_{ij}=a_{ji}$ ทุกคู่ ไม่ได้แปลว่าทุกช่องเท่ากัน

ข้อที่คนสับสนบ่อยที่สุด: transpose ไม่ใช่ inverse inverse คือเครื่องที่ย้อนผลของ matrix กลับ แต่ transpose เป็นแค่การพลิกดัชนี เช่น $D=\begin{bmatrix}2&0\\0&3\end{bmatrix}$ มี $D^{\mathsf T}=D$ แต่ $D^{\mathsf T}D=\begin{bmatrix}4&0\\0&9\end{bmatrix}$ ไม่ใช่ identity ส่วน inverse ที่แท้จริงคือ $\begin{bmatrix}1/2&0\\0&1/3\end{bmatrix}$ รูปด้านล่างแสดงความต่างนี้เป็นภาพ

ขั้นที่ 3 — วาง transpose คนละที่ ได้คำถามคนละแบบ

vector สองตัวที่เป็นคอลัมน์ คูณกันตรง ๆ ไม่ได้เพราะขนาดด้านในไม่ตรง ต้องพลิกตัวหนึ่ง และตำแหน่งที่พลิกเปลี่ยนคำตอบโดยสิ้นเชิง ให้ $\mathbf u=(1,-2,3)^{\mathsf T}$ และ $\mathbf v=(4,0.5,-1)^{\mathsf T}$

\[\begin{aligned} \mathbf u^{\mathsf T}\mathbf v&=1(4)+(-2)(0.5)+3(-1)=0,\\ (1\times3)(3\times1)&\longrightarrow1\times1,\\ \mathbf u\mathbf v^{\mathsf T}&=\begin{bmatrix}4&0.5&-1\\-8&-1&2\\12&1.5&-3\end{bmatrix},\\ (3\times1)(1\times3)&\longrightarrow3\times3. \end{aligned}\]

แบบแรกคือ inner product จับคู่ช่องที่ตรงกันแล้วรวมเป็นตัวเลขเดียว ได้ศูนย์ คือสอง vector ตั้งฉากกัน แบบที่สองคือ outer product เก็บผลคูณทุกคู่ $u_iv_j$ ไว้เป็นตาราง ไม่รวมอะไรเลย inner product เป็นศูนย์ไม่ได้ทำให้ outer product เป็นศูนย์

ความยาวกำลังสองของ vector ก็เป็น inner product กับตัวเอง เช่น $\|(1,-2)\|^2=\begin{bmatrix}1&-2\end{bmatrix}\begin{bmatrix}1\\-2\end{bmatrix}=1+4=5$ ส่วน outer product มีลักษณะเฉพาะ: ทุกแถวคือ $\mathbf v$ คูณตัวเลขหนึ่งตัว ดังรูปด้านล่าง ตารางนี้จึงมีทิศอิสระทิศเดียว คือมี rank เท่ากับ 1 ต่อให้มีเก้าช่องก็ตาม

ขั้นที่ 4 — คลี่ hook: ขนาดถูก แต่จับคู่ผิด

โจทย์ให้อะไรมาบ้าง: $S$ และ $\boldsymbol\theta=(2,6,4)^{\mathsf T}$ จากขั้นแรก หน่วยของ $S$ คือดอลลาร์ต่อสัญญา ต้องการ payoff ในรูป row vector โดยคูณจากด้านซ้าย

\[\begin{aligned} S\boldsymbol\theta&=\begin{bmatrix}2(2)+3(6)+7(4)\\1(2)+6(6)+5(4)\end{bmatrix} =\begin{bmatrix}50\\58\end{bmatrix},\\ \boldsymbol\theta^{\mathsf T}S^{\mathsf T} &=\begin{bmatrix}50&58\end{bmatrix},\\ \widetilde S&=\begin{bmatrix}2&3\\7&1\\6&5\end{bmatrix}\ \ \text{(reshape)},\\ \boldsymbol\theta^{\mathsf T}\widetilde S &=\begin{bmatrix}4+42+24&6+6+20\end{bmatrix}\\ &=\begin{bmatrix}70&32\end{bmatrix}. \end{aligned}\]

คำตอบ: transpose ให้ \$50 กับ \$58 เท่าเดิม แค่เปลี่ยนจากคอลัมน์เป็นแถว reshape ให้ \$70 กับ \$32 เพราะแถวที่สองของ $\widetilde S$ คือ $(7,1)$ ซึ่งเอา payoff สัญญา 3 สถานะขึ้นมาคู่กับ payoff สัญญา 1 สถานะลง แล้วคูณทั้งคู่ด้วย 6 ซึ่งเป็นจำนวนที่ถือของสัญญา 2 ทุกตัวเลขถูก แต่ไม่มีคู่ไหนเป็นของสัญญาเดียวกัน

บทเรียนเชิงปฏิบัติ: reshape กลับขนาดเดิมก็คืนตารางเดิมได้ การทดสอบแบบ “แปลงไปแล้วแปลงกลับ” จึงจับความผิดนี้ไม่ได้ ต้องทดสอบว่า $(S^{\mathsf T})_{ji}=S_{ij}$ ทุกช่อง และตรวจว่าชื่อแกนย้ายตามด้วย ตาราง pandas ที่ใช้ df.T พาชื่อแถวคอลัมน์ไปด้วยให้ ส่วน reshape ของ array ไม่รู้จักชื่ออะไรเลย

ขั้นที่ 5 — ทำไม transpose ของผลคูณต้องกลับลำดับ

ใน หน้าที่แล้ว กำไรขาดทุนจากแบบจำลองนับได้สองทาง ทีละหุ้นคือ $\mathbf w^{\mathsf T}(A\mathbf f)$ ทีละ factor คือ $\mathbf e^{\mathsf T}\mathbf f$ กับ $\mathbf e=A^{\mathsf T}\mathbf w$ สองทางเท่ากันเพราะกฎข้อนี้ ให้ $P$ ขนาด $m\times n$ และ $Q$ ขนาด $n\times p$

\[\begin{aligned} \big((PQ)^{\mathsf T}\big)_{ij}&=(PQ)_{ji}=\sum_{k=1}^{n}P_{jk}Q_{ki}\\ &=\sum_{k=1}^{n}(Q^{\mathsf T})_{ik}(P^{\mathsf T})_{kj}\\ &=(Q^{\mathsf T}P^{\mathsf T})_{ij},\\ (PQ)^{\mathsf T}&=Q^{\mathsf T}P^{\mathsf T}. \end{aligned}\]

บรรทัดแรกใช้นิยามของ transpose แล้วนิยามการคูณ บรรทัดที่สองคือจุดที่ต้องดูให้ดี: $P_{jk}Q_{ki}$ เป็นผลคูณของตัวเลขสองตัว จึงสลับลำดับได้ แล้วเขียนแต่ละตัวใหม่เป็นช่องของ transpose เราไม่ได้สมมติว่า matrix สลับลำดับการคูณได้ ซึ่งไม่จริงโดยทั่วไป เช็กขนาดก็ได้ผลเดียวกัน: $(PQ)^{\mathsf T}$ ขนาด $p\times m$ และ $Q^{\mathsf T}P^{\mathsf T}$ คือ $(p\times n)(n\times m)$ ขนาด $p\times m$ พอดี ส่วน $P^{\mathsf T}Q^{\mathsf T}$ มักคูณไม่ได้ด้วยซ้ำ

นึกถึงการใส่ถุงเท้าแล้วใส่รองเท้า การถอดต้องกลับลำดับ ใช้กับกำไรขาดทุน: $\mathbf w^{\mathsf T}A\mathbf f$ เป็นตัวเลขตัวเดียว ซึ่งพลิกแล้วได้ตัวเอง จึงเท่ากับ $(\mathbf w^{\mathsf T}A\mathbf f)^{\mathsf T}=\mathbf f^{\mathsf T}A^{\mathsf T}\mathbf w=\mathbf f^{\mathsf T}\mathbf e$ สามตัวกลับลำดับเป็น $R^{\mathsf T}Q^{\mathsf T}P^{\mathsf T}$ ตามกฎเดิมสองรอบ

ถ้าทั้งสองเป็นจัตุรัส ลำดับผิดยังคูณได้และได้ขนาดถูก จึงอันตรายกว่า ลองกับ $P=\begin{bmatrix}1&2\\0&1\end{bmatrix}$ และ $Q=\begin{bmatrix}1&0\\3&1\end{bmatrix}$

\[\begin{aligned} PQ&=\begin{bmatrix}7&2\\3&1\end{bmatrix},\quad (PQ)^{\mathsf T}=Q^{\mathsf T}P^{\mathsf T}=\begin{bmatrix}7&3\\2&1\end{bmatrix},\\ P^{\mathsf T}Q^{\mathsf T}&=\begin{bmatrix}1&0\\2&1\end{bmatrix}\begin{bmatrix}1&3\\0&1\end{bmatrix} =\begin{bmatrix}1&3\\2&7\end{bmatrix}. \end{aligned}\]

ขั้นที่ 6 — covariance matrix พลิกแล้วได้ตัวเดิม

ให้ $R_1,\dots,R_n$ เป็นผลตอบแทนของสินทรัพย์ $n$ ตัวในงวดเดียวกัน ค่าเฉลี่ย $\mu_i$ ช่อง $(i,j)$ ของ covariance matrix คือค่าเฉลี่ยของผลคูณส่วนเบี่ยงเบน

\[\begin{aligned} \Sigma_{ij}&=E\big[(R_i-\mu_i)(R_j-\mu_j)\big]\\ &=E\big[(R_j-\mu_j)(R_i-\mu_i)\big]=\Sigma_{ji},\\ \Sigma^{\mathsf T}&=\Sigma. \end{aligned}\]

ความสมมาตรมาจากเรื่องเดียว: ผลคูณของตัวเลขสองตัวสลับลำดับได้ ไม่ได้มาจากความอิสระ และไม่ได้แปลว่าสินทรัพย์เสี่ยงเท่ากัน ช่องนอกแนวทแยงเป็นบวก ลบ หรือศูนย์ก็ได้ แนวทแยงคือ variance ของแต่ละตัว รูปด้านล่างทดลองกับข้อมูลสี่วันสมมติ: สลับแกน $x$ กับ $y$ ทำให้กลุ่มจุดสะท้อนข้ามเส้นทแยง แต่ผลคูณ $x\cdot y$ ของทุกวันเท่าเดิม covariance จึงเท่าเดิม สิ่งที่เปลี่ยนคือ variance สองตัวบนแนวทแยงสลับที่กัน

ข้อใช้งาน: ตาราง covariance ที่ระบบส่งมาแล้วไม่สมมาตร บอกว่ามีอะไรผิด เช่นชื่อสินทรัพย์เรียงไม่ตรงกัน หรือสองช่องคำนวณจากช่วงวันต่างกัน ต้องหาสาเหตุก่อน การแก้ด้วย $(C+C^{\mathsf T})/2$ ใช้ได้เฉพาะเมื่อยืนยันแล้วว่าความต่างเป็นแค่เศษจากการปัด

ขั้นที่ 7 — variance ของพอร์ตคือ $\mathbf w^{\mathsf T}\Sigma\mathbf w$

ผลตอบแทนพอร์ตที่น้ำหนักคงที่คือ $R_p=\mathbf w^{\mathsf T}\mathbf R=\sum_iw_iR_i$ ส่วนเบี่ยงเบนจากค่าเฉลี่ยของพอร์ตจึงเป็นผลรวมถ่วงน้ำหนักของส่วนเบี่ยงเบนรายตัว ยกกำลังสองแล้วเฉลี่ย

\[\begin{aligned} \operatorname{Var}(R_p)&=E\Big[\Big(\sum_iw_i(R_i-\mu_i)\Big)^2\Big]\\ &=\sum_i\sum_jw_iw_j\,E\big[(R_i-\mu_i)(R_j-\mu_j)\big]\\ &=\sum_i\sum_jw_i\Sigma_{ij}w_j=\mathbf w^{\mathsf T}\Sigma\mathbf w. \end{aligned}\]

บรรทัดที่สองคือการกระจายกำลังสองของผลรวม ได้ผลคูณครบทุกคู่ $(i,j)$ แล้วดึงน้ำหนักซึ่งเป็นค่าคงที่ออกนอกค่าเฉลี่ย บรรทัดสุดท้ายเขียนผลรวมสองชั้นเป็นแถวคูณ matrix คูณคอลัมน์ $\mathbf w$ อยู่สองข้างเพราะกำลังสองให้น้ำหนักสองตัว ไม่ใช่เพราะอยากเติม transpose ให้ขนาดพอดี ผลออกมาขนาด $(1\times n)(n\times n)(n\times1)$ คือตัวเลขเดียว

ตัวอย่างสองสินทรัพย์: variance รายปี 0.1 และ 0.5 correlation −0.25 จึงมี covariance $-0.25\sqrt{0.1}\sqrt{0.5}\approx-0.0559$ น้ำหนัก $\mathbf w=(0.6,0.4)^{\mathsf T}$

\[\begin{aligned} \Sigma&=\begin{bmatrix}0.1&-0.0559\\-0.0559&0.5\end{bmatrix},\\ \Sigma\mathbf w&=\begin{bmatrix}0.06-0.02236\\-0.03354+0.20\end{bmatrix} =\begin{bmatrix}0.03764\\0.16646\end{bmatrix},\\ \sigma_p^2&=0.6(0.03764)+0.4(0.16646)\\ &=0.089168,\\ \sigma_p&=\sqrt{0.089168}\approx0.2986. \end{aligned}\]

ความผันผวนของพอร์ตคือ 29.86% ต่อปี ตรวจด้วยสูตรสองสินทรัพย์ก็ได้ $0.6^2(0.1)+2(0.6)(0.4)(-0.0559)+0.4^2(0.5)=0.036-0.026832+0.08=0.089168$ เลข 2 ข้างหน้าพจน์ไขว้มาจากสองช่องนอกแนวทแยงที่เท่ากันเพราะความสมมาตร ดังรูปด้านล่าง ถ้าลืมพจน์ไขว้จะได้ 0.116 ซึ่งคือพอร์ตในโลกที่ correlation เป็นศูนย์ ไม่ใช่พอร์ตนี้

แต่ละช่องของ $\Sigma\mathbf w$ มีความหมายของตัวเอง: $(\Sigma\mathbf w)_i=\sum_j\operatorname{Cov}(R_i,R_j)w_j=\operatorname{Cov}(R_i,R_p)$ คือ covariance ของสินทรัพย์ $i$ กับพอร์ตทั้งก้อน หารด้วย $\sigma_p^2$ ได้ 0.42 และ 1.87 สินทรัพย์ที่สองมีน้ำหนักแค่ 40% แต่ขยับไปกับพอร์ตแรงกว่าพอร์ตเกือบสองเท่า เรื่องการแบ่งความเสี่ยงแบบนี้ทำต่อใน matrix multiplication

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ใช้ reshape แทน transpose: ได้ขนาดถูกแต่จับคู่ผิด payoff เปลี่ยนจาก $(50,58)$ เป็น $(70,32)$ โดยไม่มี error ใด ๆ

ลืมกลับลำดับ: เขียน $(PQ)^{\mathsf T}$ เป็น $P^{\mathsf T}Q^{\mathsf T}$ กับ matrix จัตุรัสยังคูณได้ แต่ได้ $\begin{bmatrix}1&3\\2&7\end{bmatrix}$ แทน $\begin{bmatrix}7&3\\2&1\end{bmatrix}$

ใช้ transpose แทน inverse: $D=\operatorname{diag}(2,3)$ พลิกแล้วได้ตัวเดิม ถ้าใช้ $D^{\mathsf T}$ “ย้อน” การยืด จะยืดซ้ำเป็น 4 และ 9 แทนที่จะกลับเป็น 1

quadratic form ไม่ได้เป็น variance เสมอ: $B=\begin{bmatrix}2&1\\0&3\end{bmatrix}$ กับ $\mathbf x=(1,2)$ ให้ $\mathbf x^{\mathsf T}B\mathbf x=4+12=16$ ตัวเลขเดียวเหมือนกัน แต่ $B$ ไม่สมมาตร จึงไม่ใช่ covariance ของอะไรเลย และต่อให้สมมาตร ก็ยังใช้ไม่ได้เสมอ: $C=\begin{bmatrix}1&2\\2&1\end{bmatrix}$ กับ $\mathbf a=(1,-1)$ ให้ $\mathbf a^{\mathsf T}C\mathbf a=1-2-2+1=-2$ variance ติดลบเป็นไปไม่ได้ ตารางนี้จึงไม่ใช่ covariance ที่ใช้ได้ เงื่อนไขที่ขาดไปคือ positive semidefinite ซึ่งตรวจด้วย eigenvalues

symmetrize เพื่อปิดปัญหา: เฉลี่ย $(C+C^{\mathsf T})/2$ ทำให้ตารางสมมาตร แต่ถ้าความไม่สมมาตรมาจากชื่อเรียงผิด ค่าเฉลี่ยของสองช่องที่ผิดก็ยังผิด แค่ดูเรียบร้อยขึ้น

โจทย์ตรวจความเข้าใจ

1. ตาราง loading $A$ ใน What a Matrix Is มีแถว AAPL, MSFT, JPM และคอลัมน์ Market, Quality หลัง transpose ช่องแถว Market คอลัมน์ JPM มีค่าเท่าไร และเป็นความไวของอะไรต่ออะไร

เฉลย

1.5 คือช่อง $(A^{\mathsf T})_{13}=A_{31}$ ยังเป็นความไวของ JPM ต่อ Market เหมือนเดิม การพลิกตารางเปลี่ยนทิศที่เราอ่าน ไม่ได้กลับความหมายเป็น “ความไวของ Market ต่อ JPM”

2. ในตัวอย่าง variance พอร์ต ถ้าน้ำหนักเพิ่มเป็นสองเท่าทั้งคู่ คือ $(1.2,0.8)$ variance และความผันผวนเป็นเท่าไร

เฉลย

$(2\mathbf w)^{\mathsf T}\Sigma(2\mathbf w)=4\,\mathbf w^{\mathsf T}\Sigma\mathbf w=4(0.089168)=0.356672$ ความผันผวน $\sqrt{0.356672}\approx0.5972$ หรือ 59.72% คือสองเท่าของ 29.86% variance โตตามกำลังสองของขนาดพอร์ต ความผันผวนโตเป็นเส้นตรง

3. $A$ ขนาด $2\times3$, $B$ ขนาด $3\times4$ และ $\mathbf c$ ขนาด $4\times1$ เขียน $(AB\mathbf c)^{\mathsf T}$ ในรูปผลคูณของ transpose และตรวจขนาดทุกตัว

เฉลย

$(AB\mathbf c)^{\mathsf T}=\mathbf c^{\mathsf T}B^{\mathsf T}A^{\mathsf T}$ ขนาด $(1\times4)(4\times3)(3\times2)$ ได้ $1\times2$ ตรงกับ $AB\mathbf c$ ที่มีขนาด $2\times1$ ส่วนลำดับเดิม $A^{\mathsf T}B^{\mathsf T}\mathbf c^{\mathsf T}$ คือ $(3\times2)(4\times3)\cdots$ ซึ่งคูณไม่ได้ตั้งแต่คู่แรก

คำนวณซ้ำด้วย JavaScript

โค้ดเทียบ transpose กับ reshape ตรวจกฎกลับลำดับ และคำนวณ variance พอร์ตทั้งแบบ matrix และแบบสูตรสองสินทรัพย์

เปิดดูโค้ด 
const transpose = A => A[0].map((_, j) => A.map(row => row[j]));
function multiply(A, B) {
  if (A[0].length !== B.length) throw new Error('inner sizes do not match');
  const Bt = transpose(B);
  return A.map(row => Bt.map(col => row.reduce((s, x, k) => s + x * col[k], 0)));
}
const reshape = (A, m, n) => { const flat = A.flat();
  return Array.from({length: m}, (_, i) => flat.slice(i * n, i * n + n)); };

const S = [[2, 3, 7], [1, 6, 5]], thetaRow = [[2, 6, 4]];
console.log(multiply(thetaRow, transpose(S)));    // [[50, 58]]
console.log(multiply(thetaRow, reshape(S, 3, 2))); // [[70, 32]]  wrong pairing

const P = [[1, 2], [0, 1]], Q = [[1, 0], [3, 1]];
console.log(transpose(multiply(P, Q)));             // [[7,3],[2,1]]
console.log(multiply(transpose(Q), transpose(P)));  // same
console.log(multiply(transpose(P), transpose(Q)));  // [[1,3],[2,7]] wrong order

const Sigma = [[0.1, -0.0559], [-0.0559, 0.5]], w = [[0.6], [0.4]];
const Sw = multiply(Sigma, w);                      // 0.03764, 0.16646
const V = multiply(transpose(w), Sw)[0][0];         // 0.089168
console.log(Sw, V, Math.sqrt(V),
  0.36 * 0.1 + 2 * 0.24 * -0.0559 + 0.16 * 0.5,    // same V
  Sw.map(r => r[0] / V));                           // 0.42, 1.87

const days = [[3, 1], [-1, 1], [-1, 0], [-1, -2]];
const cov = d => d.reduce((s, [x, y]) => s + x * y, 0) / (d.length - 1);
console.log(cov(days), cov(days.map(([x, y]) => [y, x]))); // 4/3 both

สิ่งที่ควรตอบได้หลังอ่าน

  • $(A^{\mathsf T})_{ji}=A_{ij}$ ชื่อแถวคอลัมน์ย้ายตามตัวเลข และ reshape ไม่ใช่ transpose แม้ได้ขนาดเดียวกัน ($70,32$ แทน $50,58$)
  • transpose ไม่ใช่ inverse: การเฉือน $P$ ถูกย้อนด้วย $P^{-1}$ ไม่ใช่ $P^{\mathsf T}$
  • $\mathbf u^{\mathsf T}\mathbf v$ ให้ตัวเลขเดียว $\mathbf u\mathbf v^{\mathsf T}$ ให้ตารางที่ทุกแถวเป็นรูปแบบเดียวกัน
  • $(PQ)^{\mathsf T}=Q^{\mathsf T}P^{\mathsf T}$ เพราะผลคูณของตัวเลขสลับได้ และนี่คือเหตุผลที่กำไรขาดทุนนับทีละหุ้นหรือทีละ factor ได้เท่ากัน
  • covariance matrix สมมาตรเสมอ variance พอร์ตคือ $\mathbf w^{\mathsf T}\Sigma\mathbf w$ (0.089168 ในตัวอย่าง) และ $\Sigma\mathbf w$ คือ covariance ของแต่ละสินทรัพย์กับพอร์ต

ทั้งหน้านี้ใช้การคูณ matrix ไปหลายรอบโดยยังไม่ได้ถามว่ากติกา “แถวคูณคอลัมน์” มาจากไหน หน้าถัดไป Matrix Multiplication สร้างกติกานี้จากการต่อเครื่องแปลงสองเครื่อง แล้วใช้มันแบ่งความเสี่ยงของพอร์ตให้แต่ละสินทรัพย์
