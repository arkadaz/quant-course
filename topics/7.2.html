7.2 Transpose

transpose พลิกตารางข้ามแนวทแยง ตัวเลขที่อยู่แถว $i$ คอลัมน์ $j$ ย้ายไปอยู่แถว $j$ คอลัมน์ $i$ และพาชื่อของมันไปด้วย ตารางเดิมจึงตอบคำถามในทิศกลับได้ โดยไม่ต้องสร้างข้อมูลใหม่

โต๊ะเทรดแห่งหนึ่งถือสัญญาการเงินสามชนิด สัญญาแต่ละชนิดจ่ายเงินให้ผู้ถือตอนหมดอายุ แต่จ่ายเท่าไรขึ้นกับว่าตลาดขึ้นหรือลง เงินที่สัญญาจ่ายเรียกว่า payoff

ทีมเก็บ payoff ไว้ในตารางหนึ่ง แถวคือ “สถานะ” ของตลาด (ขึ้นหรือลง) คอลัมน์คือสัญญา แต่ละช่องบอกว่าสัญญาหนึ่งหน่วยจ่ายกี่ดอลลาร์ในสถานะนั้น (ตัวเลขทั้งหมดในหน้านี้สมมติ)

สัญญา 1สัญญา 2สัญญา 3
ตลาดขึ้น\$2\$3\$7
ตลาดลง\$1\$6\$5

พอร์ตถือสัญญา 1 จำนวน 2 หน่วย สัญญา 2 จำนวน 6 หน่วย และสัญญา 3 จำนวน 4 หน่วย เงินที่พอร์ตได้ในแต่ละสถานะคือจำนวนหน่วยคูณ payoff แล้วบวกกันทั้งแถว ให้ $V_{\text{up}}$ คือเงินที่ได้เมื่อตลาดขึ้น และ $V_{\text{down}}$ คือเงินที่ได้เมื่อตลาดลง

\[\begin{aligned} V_{\text{up}}&=2(2)+6(3)+4(7)=\$50,\\ V_{\text{down}}&=2(1)+6(6)+4(5)=\$58. \end{aligned}\]

วันหนึ่งทีมเปลี่ยนไปใช้โปรแกรมใหม่ โปรแกรมนี้ต้องการตารางที่หันอีกด้าน คือให้สัญญาเป็นแถว และให้สถานะเป็นคอลัมน์ ตารางจึงต้องเปลี่ยนจาก 2 แถว 3 คอลัมน์ เป็น 3 แถว 2 คอลัมน์ โปรแกรมแปลงตารางให้เอง ขนาดออกมาถูก คูณผ่านโดยไม่มี error แต่ได้ \$70 เมื่อตลาดขึ้น และ \$32 เมื่อตลาดลง

ถ้ารวมเงินสองสถานะ เดิมได้ $50+58=\$108$ ตอนนี้ได้ $70+32=\$102$ หายไป $108-102=\$6$ ทั้งที่พอร์ตไม่ได้ซื้อขายอะไรเลย เงินหายไปไหน

ลองตอบก่อนเปิดเฉลย

เงินไม่ได้หายจากพอร์ต มันหายตอนจับคู่ตัวเลข เพราะโปรแกรมใช้ reshape ไม่ใช่ transpose

  • reshape อ่านตัวเลขทีละแถวจากซ้ายไปขวา ได้ลำดับ 2, 3, 7, 1, 6, 5 แล้วเทลงตารางใหม่ทีละช่องตามลำดับนั้น ตารางใหม่จึงมีแถว (2, 3), (7, 1) และ (6, 5)
  • แถวที่สองควรเป็นของสัญญา 2 แต่เลข 7 คือ payoff ของสัญญา 3 ตอนตลาดขึ้น และเลข 1 คือ payoff ของสัญญา 1 ตอนตลาดลง โปรแกรมจึงเอา 6 หน่วยของสัญญา 2 ไปคูณกับ payoff ของสัญญาอื่น เงินตอนตลาดขึ้นจึงเป็น $2(2)+6(7)+4(6)=\$70$ แทนที่จะเป็น \$50
  • transpose พลิกตารางโดยให้แต่ละสัญญาพาตัวเลขของมันไปด้วย ตารางใหม่จึงมีแถว (2, 1), (3, 6) และ (7, 5) แถวละหนึ่งสัญญา คำตอบยังเป็น \$50 กับ \$58 เท่าเดิม

ภาพรวมก่อนลงสูตร

ปัญหาใน hook ไม่ได้เกิดแค่กับตาราง payoff ตารางไหนที่ต้องอ่านได้สองทิศก็เจอเรื่องนี้ได้ ตัวอย่างหนึ่งมาจาก What a Matrix Is ที่นั่นเราใช้ตาราง loading ตารางหนึ่ง แถวคือหุ้น คอลัมน์คือ factor (แรงที่ขยับหุ้นหลายตัวพร้อมกัน เช่น ตลาดทั้งตลาด) แต่ละช่องบอกว่าหุ้นตัวนั้นไวต่อ factor นั้นแค่ไหน ตารางเดียวนี้ตอบได้สองคำถาม

  • ใส่การขยับของ factor เข้าทางคอลัมน์ ได้ผลตอบแทนของหุ้นแต่ละตัว
  • ใส่เงินที่ถือในหุ้นแต่ละตัวเข้าทางแถว ได้ exposure ของพอร์ต คือความไวของพอร์ตทั้งก้อนต่อ factor แต่ละตัว

คำถามที่สองอ่านตารางในทิศกลับ จึงต้องพลิกตารางให้คอลัมน์กลายเป็นแถว การพลิกแบบนี้เรียกว่า transpose เขียนว่า $A^{\mathsf T}$ (อ่านว่า “A transpose”) กติกามีข้อเดียว: ตัวเลขที่อยู่แถว $i$ คอลัมน์ $j$ ย้ายไปอยู่แถว $j$ คอลัมน์ $i$ และชื่อของแถวกับคอลัมน์ย้ายตามตัวเลขไปด้วย

รูปด้านล่างใช้สีแทนชื่อสัญญาใน hook หลัง transpose แต่ละแถวของตารางใหม่เป็นสัญญาเดียวกันทั้งแถว ส่วน reshape ที่โปรแกรมใช้ ทำให้สัญญาปนกันในแถวเดียว ทั้งสองแบบได้ตาราง $3\times2$ (3 แถว 2 คอลัมน์) เหมือนกัน การตรวจแค่ขนาดจึงจับความผิดนี้ไม่ได้

หน้านี้เริ่มจากดูทีละช่องว่าตัวเลขแต่ละตัวไปอยู่ไหน แล้วใช้กติกานั้นอธิบายสามเรื่องที่ใช้ทั้งเล่ม

  • การคูณ vector สองตัว: วาง transpose ไว้คนละที่ ได้ผลคนละแบบ
  • ทำไม transpose ของผลคูณต้องกลับลำดับ
  • ทำไม covariance matrix (ตารางที่บอกว่าสินทรัพย์แต่ละคู่ขยับไปด้วยกันแค่ไหน) พลิกแล้วได้ตัวเดิม ข้อนี้พาไปสู่สูตรความเสี่ยงของพอร์ต $\mathbf w^{\mathsf T}\Sigma\mathbf w$
ศัพท์ที่ใช้ในหัวข้อนี้
Payoff
เงินที่สัญญาการเงินจ่ายให้ผู้ถือ ขึ้นกับว่าเกิดสถานะไหน ในหน้านี้มีสองสถานะ คือตลาดขึ้นกับตลาดลง
Transpose $A^{\mathsf T}$
ตารางที่ได้จากการพลิก $A$ ข้ามแนวทแยง ตัวเลขในแถว $i$ คอลัมน์ $j$ ไปอยู่แถว $j$ คอลัมน์ $i$ เขียนเป็นสูตรว่า $(A^{\mathsf T})_{ji}=A_{ij}$ ใช้เมื่ออยากอ่านตารางเดิมในทิศกลับ
Reshape
การอ่านตัวเลขชุดเดิมเรียงทีละแถว แล้วเทลงตารางขนาดใหม่ตามลำดับนั้น มันไม่สนว่าตัวเลขไหนเป็นของใคร จึงใช้ได้เฉพาะเมื่อลำดับการอ่านตรงกับความหมายที่ต้องการจริง ๆ
Symmetric matrix
matrix จัตุรัส (จำนวนแถวเท่าจำนวนคอลัมน์) ที่พลิกแล้วได้ตัวเดิม $A^{\mathsf T}=A$ คือ $a_{ij}=a_{ji}$ ทุกคู่ covariance matrix เป็นแบบนี้เสมอ ถ้าไม่สมมาตร แปลว่าข้อมูลมีอะไรผิด
Inner product และ outer product
$\mathbf u^{\mathsf T}\mathbf v$ จับช่องที่ตรงกันของสอง vector มาคูณแล้วบวกรวม ได้ตัวเลขตัวเดียว ส่วน $\mathbf u\mathbf v^{\mathsf T}$ เก็บผลคูณทุกคู่ $u_iv_j$ ไว้เป็นตาราง ไม่บวกอะไรเลย
Quadratic form
นิพจน์ $\mathbf x^{\mathsf T}B\mathbf x$ ซึ่งให้ตัวเลขตัวเดียว variance ของพอร์ตเขียนในรูปนี้ได้ โดย $B$ คือ covariance matrix แต่ quadratic form ไม่ได้เป็น variance เสมอไป

ขั้นที่ 1 — นิยามทีละช่อง: ชื่อย้ายตามตัวเลข

ก่อนจะใช้ transpose ในสูตร ต้องเห็นชัดก่อนว่าตัวเลขแต่ละตัวไปอยู่ไหน และพาความหมายอะไรไปด้วย เริ่มจากตาราง payoff ใน hook

  • $S$ คือตาราง payoff แถว 1 คือตลาดขึ้น แถว 2 คือตลาดลง คอลัมน์ 1 ถึง 3 คือสัญญา 1 ถึง 3 หน่วยเป็นดอลลาร์ต่อสัญญาหนึ่งหน่วย
  • $S_{ij}$ คือตัวเลขในแถว $i$ คอลัมน์ $j$ ของ $S$
  • $\boldsymbol\theta$ (อ่านว่า theta) คือจำนวนหน่วยที่พอร์ตถือ เรียงตามสัญญา 1 ถึง 3

พลิก $S$ แล้วดูว่าแต่ละช่องไปไหน

\[\begin{aligned} S&=\begin{bmatrix}2&3&7\\1&6&5\end{bmatrix},\quad S^{\mathsf T}=\begin{bmatrix}2&1\\3&6\\7&5\end{bmatrix},\\ (S^{\mathsf T})_{ji}&=S_{ij},\qquad (S^{\mathsf T})_{31}=S_{13}=7,\\ \boldsymbol\theta&=\begin{bmatrix}2\\6\\4\end{bmatrix},\quad \boldsymbol\theta^{\mathsf T}=\begin{bmatrix}2&6&4\end{bmatrix}. \end{aligned}\]

สูตร $(S^{\mathsf T})_{ji}=S_{ij}$ บอกว่า transpose ไม่ได้สร้างตัวเลขใหม่ มันแค่สลับว่าดัชนีตัวไหนเรียกแถว ตัวไหนเรียกคอลัมน์ ดูเลข 7 เป็นตัวอย่าง ใน $S$ มันอยู่แถว 1 (ตลาดขึ้น) คอลัมน์ 3 (สัญญา 3) ใน $S^{\mathsf T}$ มันย้ายไปอยู่แถว 3 คอลัมน์ 1 แต่ชื่อก็ย้ายตามมาด้วย แถว 3 ของ $S^{\mathsf T}$ ตอนนี้ชื่อว่าสัญญา 3 และคอลัมน์ 1 ชื่อว่าตลาดขึ้น ความหมายจึงยังเป็น “สัญญา 3 จ่าย \$7 เมื่อตลาดขึ้น” เหมือนเดิม

ผลที่ตามมามีสองข้อ ตารางขนาด $m\times n$ ($m$ แถว $n$ คอลัมน์) กลายเป็น $n\times m$ และ column vector อย่าง $\boldsymbol\theta$ (ตัวเลขเรียงแนวตั้ง) พลิกแล้วกลายเป็น row vector $\boldsymbol\theta^{\mathsf T}$ (ตัวเลขเรียงแนวนอน)

วิธีจำ: นึกถึงกระจกที่วางตามแนวทแยงจากมุมซ้ายบนลงมุมขวาล่าง ตัวเลขบนแนวทแยงอยู่ที่เดิม ตัวเลขอื่นสลับไปอีกฝั่งของกระจก transpose ไม่ใช่การหมุนกระดาษ 90 องศา เพราะการหมุนทำให้ลำดับกลับหัวด้วย เช่น หมุน $S$ ตามเข็มนาฬิกา แถวแรกจะเป็น $(1,2)$ แต่แถวแรกของ $S^{\mathsf T}$ คือ $(2,1)$

ขั้นที่ 2 — กฎพื้นฐาน และสิ่งที่ transpose ไม่ใช่

ก่อนใช้ transpose ในสูตรยาว ๆ ต้องรู้ว่ามันเข้ากับการบวกและการคูณด้วยตัวเลขอย่างไร กฎทุกข้อพิสูจน์ได้โดยดูช่องเดียว เพราะการบวก matrix และการคูณ matrix ด้วยตัวเลขทำทีละช่องอยู่แล้ว ให้ $A$ กับ $B$ เป็น matrix ขนาดเท่ากัน และ $c$ เป็นตัวเลขหนึ่งตัว

\[\begin{aligned} \big((A^{\mathsf T})^{\mathsf T}\big)_{ij}&=(A^{\mathsf T})_{ji}=A_{ij},\\ \big((A+B)^{\mathsf T}\big)_{ij}&=A_{ji}+B_{ji},\\ \big((cA)^{\mathsf T}\big)_{ij}&=cA_{ji}. \end{aligned}\]

ทั้งสามข้อใช้เหตุผลเดียว: ช่อง $(i,j)$ ของตารางที่พลิกแล้ว คือช่อง $(j,i)$ ของตารางก่อนพลิก ผลที่ได้คือ $(A^{\mathsf T})^{\mathsf T}=A$ พลิกสองครั้งกลับที่เดิม $(A+B)^{\mathsf T}=A^{\mathsf T}+B^{\mathsf T}$ บวกก่อนพลิกหรือพลิกก่อนบวกได้ผลเท่ากัน และ $(cA)^{\mathsf T}=cA^{\mathsf T}$ คูณตัวเลขก่อนหรือหลังพลิกก็ได้

matrix ที่พลิกแล้วได้ตัวเดิม คือ $A^{\mathsf T}=A$ เรียกว่า symmetric matrix มันต้องเป็นจัตุรัส เพราะถ้าไม่จัตุรัส พลิกแล้วขนาดจะเปลี่ยน และต้องมี $a_{ij}=a_{ji}$ ทุกคู่ แต่ไม่ได้แปลว่าทุกช่องเท่ากัน เช่น $\begin{bmatrix}1&5\\5&9\end{bmatrix}$ เป็น symmetric

ข้อที่คนสับสนบ่อยที่สุด: transpose ไม่ใช่ inverse inverse ของ $D$ เขียนว่า $D^{-1}$ คือ matrix ที่ย้อนผลของ $D$ กลับ คูณกันแล้วได้ identity $I$ (matrix ที่ไม่เปลี่ยนอะไร แนวทแยงเป็น 1 ช่องอื่นเป็น 0) ส่วน transpose แค่สลับดัชนี ลองกับ $D=\begin{bmatrix}2&0\\0&3\end{bmatrix}$ ซึ่งยืดแกนแรก 2 เท่า และยืดแกนที่สอง 3 เท่า

$D$ เป็น symmetric จึงมี $D^{\mathsf T}=D$ ถ้าใช้ $D^{\mathsf T}$ เพื่อย้อนการยืด จะได้ $D^{\mathsf T}D=\begin{bmatrix}2\cdot2&0\\0&3\cdot3\end{bmatrix}=\begin{bmatrix}4&0\\0&9\end{bmatrix}$ คือยืดซ้ำอีกรอบ ไม่ใช่ $I$ ตัวที่ย้อนได้จริงคือ $D^{-1}=\begin{bmatrix}1/2&0\\0&1/3\end{bmatrix}$ เพราะ $\tfrac12\cdot2=1$ และ $\tfrac13\cdot3=1$ รูปด้านล่างแสดงความต่างนี้เป็นภาพ

ขั้นที่ 3 — วาง transpose คนละที่ ได้คำถามคนละแบบ

ในงานพอร์ต เราต้องคูณ vector สองตัวกันบ่อยมาก เช่น น้ำหนักของพอร์ตกับผลตอบแทนของสินทรัพย์แต่ละตัว แต่การคูณ matrix มีเงื่อนไข: จำนวนคอลัมน์ของตัวซ้ายต้องเท่ากับจำนวนแถวของตัวขวา เพราะแต่ละแถวทางซ้ายต้องจับคู่กับคอลัมน์ทางขวาทีละช่อง เขียนสั้น ๆ ว่า $(m\times n)(n\times p)$ ได้ $m\times p$ โดยเลขด้านใน $n$ ต้องตรงกัน

vector คอลัมน์ขนาด $3\times1$ สองตัวจึงคูณกันตรง ๆ ไม่ได้ เพราะเลขด้านในคือ 1 กับ 3 ไม่ตรงกัน ต้องพลิกตัวหนึ่งก่อน และตำแหน่งที่พลิกเปลี่ยนคำตอบไปเลย ลองกับ vector สมมติสองตัว $\mathbf u=(1,-2,3)^{\mathsf T}$ และ $\mathbf v=(4,0.5,-1)^{\mathsf T}$

\[\begin{aligned} \mathbf u^{\mathsf T}\mathbf v&=1(4)+(-2)(0.5)+3(-1)=0,\\ (1\times3)(3\times1)&\longrightarrow1\times1,\\ \mathbf u\mathbf v^{\mathsf T}&=\begin{bmatrix}4&0.5&-1\\-8&-1&2\\12&1.5&-3\end{bmatrix},\\ (3\times1)(1\times3)&\longrightarrow3\times3. \end{aligned}\]

แบบแรก $\mathbf u^{\mathsf T}\mathbf v$ คือ inner product มันจับช่องที่ตรงกันมาคูณ แล้วบวกรวมเป็นตัวเลขตัวเดียว ที่นี่ได้ 0 ซึ่งแปลว่า $\mathbf u$ กับ $\mathbf v$ ตั้งฉากกัน แบบที่สอง $\mathbf u\mathbf v^{\mathsf T}$ คือ outer product มันเก็บผลคูณทุกคู่ $u_iv_j$ ไว้ในช่อง $(i,j)$ และไม่บวกอะไรเลย ดังนั้น inner product เป็น 0 ไม่ได้ทำให้ outer product เป็น 0 ทั้งตาราง

ความยาวกำลังสองของ vector ก็คือ inner product กับตัวเอง เช่น $\|(1,-2)\|^2=\begin{bmatrix}1&-2\end{bmatrix}\begin{bmatrix}1\\-2\end{bmatrix}=1+4=5$

outer product มีลักษณะพิเศษ: แถวที่ $i$ คือ $\mathbf v^{\mathsf T}$ คูณด้วยตัวเลขตัวเดียวคือ $u_i$ เช่น แถวที่สองคือ $-2\times(4,0.5,-1)=(-8,-1,2)$ ทุกแถวจึงชี้ทิศเดียวกัน ต่างกันแค่ขนาดกับเครื่องหมาย ดังรูปด้านล่าง ตารางนี้จึงมีทิศที่เป็นอิสระแค่ทิศเดียว เรียกว่ามี rank เท่ากับ 1 (rank คือจำนวนทิศที่เป็นอิสระในตาราง) ต่อให้มีเก้าช่องก็ตาม

ขั้นที่ 4 — คลี่ hook: ขนาดถูก แต่จับคู่ผิด

ตอนนี้มีเครื่องมือพอจะหาแล้วว่า \$6 ใน hook หายไปตรงไหน

โจทย์ให้อะไรมาบ้าง:

  • ตาราง payoff $S$ ขนาด $2\times3$ จากขั้นแรก หน่วยเป็นดอลลาร์ต่อสัญญาหนึ่งหน่วย
  • จำนวนหน่วยที่ถือ $\boldsymbol\theta=(2,6,4)^{\mathsf T}$
  • โปรแกรมใหม่เก็บจำนวนหน่วยเป็น row vector $\boldsymbol\theta^{\mathsf T}$ แล้วคูณตารางจากด้านซ้าย จึงต้องการตาราง $3\times2$ ที่แถวคือสัญญา

คำนวณสามแบบเทียบกัน แบบเดิม $S\boldsymbol\theta$ แบบที่ถูก $\boldsymbol\theta^{\mathsf T}S^{\mathsf T}$ และแบบที่โปรแกรมทำจริง คือ reshape ก่อนแล้วคูณ ให้ $\widetilde S$ คือตารางที่ได้จาก reshape

\[\begin{aligned} S\boldsymbol\theta&=\begin{bmatrix}2(2)+3(6)+7(4)\\1(2)+6(6)+5(4)\end{bmatrix} =\begin{bmatrix}50\\58\end{bmatrix},\\ \boldsymbol\theta^{\mathsf T}S^{\mathsf T} &=\begin{bmatrix}4+18+28&2+36+20\end{bmatrix}\\ &=\begin{bmatrix}50&58\end{bmatrix},\\ \widetilde S&=\begin{bmatrix}2&3\\7&1\\6&5\end{bmatrix}\ \ \text{(reshape)},\\ \boldsymbol\theta^{\mathsf T}\widetilde S &=\begin{bmatrix}4+42+24&6+6+20\end{bmatrix}\\ &=\begin{bmatrix}70&32\end{bmatrix}. \end{aligned}\]

คำตอบ: transpose ให้ \$50 กับ \$58 เท่าเดิม ตัวเลขชุดเดิมแค่เปลี่ยนจากคอลัมน์เป็นแถว ส่วน reshape ให้ \$70 กับ \$32 ต้นเหตุอยู่ที่แถวที่สองของ $\widetilde S$ คือ $(7,1)$ เลข 7 เป็น payoff ของสัญญา 3 ตอนตลาดขึ้น เลข 1 เป็น payoff ของสัญญา 1 ตอนตลาดลง แต่ทั้งคู่ถูกคูณด้วย 6 ซึ่งเป็นจำนวนหน่วยของสัญญา 2 ตัวเลขทุกตัวในตารางถูกต้อง แต่ไม่มีแถวไหนเป็นของสัญญาเดียวกันทั้งแถว

บทเรียนสำหรับคนเขียนโปรแกรม: การทดสอบแบบ “แปลงไปแล้วแปลงกลับ ต้องได้ตารางเดิม” จับความผิดนี้ไม่ได้ เพราะ reshape $\widetilde S$ กลับเป็น $2\times3$ ก็ได้ $S$ คืนมาพอดี การทดสอบที่ถูกคือตรวจว่า $(S^{\mathsf T})_{ji}=S_{ij}$ ทุกช่อง และตรวจว่าชื่อแถวกับชื่อคอลัมน์ย้ายตามไปด้วย ใน pandas (ไลบรารีตารางข้อมูลของ Python) คำสั่ง df.T พาชื่อแถวและชื่อคอลัมน์ไปให้ ส่วน reshape ของ array ไม่รู้จักชื่ออะไรเลย มันรู้แค่ลำดับของตัวเลข

ขั้นที่ 5 — ทำไม transpose ของผลคูณต้องกลับลำดับ

ใน What a Matrix Is กำไรขาดทุนของพอร์ตที่แบบจำลองทำนายนับได้สองทาง ของที่ใช้มีสามอย่าง

  • $\mathbf w$ คือเงินที่ถือในหุ้นแต่ละตัว
  • $A$ คือตาราง loading แถวคือหุ้น คอลัมน์คือ factor
  • $\mathbf f$ คือการขยับของ factor แต่ละตัววันนี้

ทางแรกนับทีละหุ้น: หาผลตอบแทนของหุ้นแต่ละตัว $A\mathbf f$ ก่อน แล้วจับคู่กับเงินที่ถือ ได้ $\mathbf w^{\mathsf T}(A\mathbf f)$ ทางที่สองนับทีละ factor: หา exposure $\mathbf e=A^{\mathsf T}\mathbf w$ ก่อน แล้วจับคู่กับการขยับของ factor ได้ $\mathbf e^{\mathsf T}\mathbf f$ สองทางนี้ต้องได้เงินก้อนเดียวกัน แต่ทำไมถึงเท่ากันเสมอ คำตอบอยู่ในกฎ transpose ของผลคูณ

ให้ $P$ ขนาด $m\times n$ และ $Q$ ขนาด $n\times p$ ตามนิยามการคูณ ช่อง $(j,i)$ ของ $PQ$ คือแถว $j$ ของ $P$ จับคู่กับคอลัมน์ $i$ ของ $Q$ คูณทีละช่องแล้วบวกรวม

\[\begin{aligned} \big((PQ)^{\mathsf T}\big)_{ij}&=(PQ)_{ji}=\sum_{k=1}^{n}P_{jk}Q_{ki}\\ &=\sum_{k=1}^{n}(Q^{\mathsf T})_{ik}(P^{\mathsf T})_{kj}\\ &=(Q^{\mathsf T}P^{\mathsf T})_{ij},\\ (PQ)^{\mathsf T}&=Q^{\mathsf T}P^{\mathsf T}. \end{aligned}\]

หัวใจของการพิสูจน์อยู่ที่ $P_{jk}Q_{ki}$ ซึ่งเป็นผลคูณของตัวเลขสองตัว ตัวเลขสลับลำดับการคูณได้ จึงเขียนเป็น $Q_{ki}P_{jk}$ แล้วเรียกชื่อใหม่ว่า $(Q^{\mathsf T})_{ik}(P^{\mathsf T})_{kj}$ ผลรวมนี้คือแถว $i$ ของ $Q^{\mathsf T}$ จับคู่กับคอลัมน์ $j$ ของ $P^{\mathsf T}$ พอดี เราไม่ได้สมมติว่า matrix สลับลำดับการคูณได้ ซึ่งโดยทั่วไปไม่จริง เราสลับแค่ตัวเลขข้างใน

ตรวจด้วยขนาดก็ได้ผลเดียวกัน $PQ$ ขนาด $m\times p$ พลิกแล้วเป็น $p\times m$ ส่วน $Q^{\mathsf T}P^{\mathsf T}$ คือ $(p\times n)(n\times m)$ ได้ $p\times m$ พอดี แต่ $P^{\mathsf T}Q^{\mathsf T}$ คือ $(n\times m)(p\times n)$ ซึ่งคูณไม่ได้ด้วยซ้ำ เว้นแต่ $m=p$

ภาพที่ช่วยจำ: เราใส่ถุงเท้าก่อนแล้วจึงใส่รองเท้า แต่ตอนถอดต้องถอดรองเท้าก่อน ลำดับกลับกัน ผลคูณสามตัวก็กลับทั้งหมด $(PQR)^{\mathsf T}=R^{\mathsf T}Q^{\mathsf T}P^{\mathsf T}$ โดยใช้กฎเดิมสองรอบ

กลับมาที่กำไรขาดทุน $\mathbf w^{\mathsf T}A\mathbf f$ เป็นตัวเลขตัวเดียว (ตาราง $1\times1$) และตัวเลขตัวเดียวพลิกแล้วได้ตัวเอง จึงเขียนได้ว่า $\mathbf w^{\mathsf T}A\mathbf f=(\mathbf w^{\mathsf T}A\mathbf f)^{\mathsf T}=\mathbf f^{\mathsf T}A^{\mathsf T}\mathbf w=\mathbf f^{\mathsf T}\mathbf e$ ซึ่งเท่ากับ $\mathbf e^{\mathsf T}\mathbf f$ เพราะ inner product สลับข้างได้ นับทีละหุ้นกับนับทีละ factor จึงได้เงินก้อนเดียวกันเสมอ

ถ้า $P$ กับ $Q$ เป็นจัตุรัสทั้งคู่ ลำดับที่ผิดยังคูณได้และได้ขนาดถูก ความผิดจึงเงียบกว่าและอันตรายกว่า ลองกับ matrix สมมติ $P=\begin{bmatrix}1&2\\0&1\end{bmatrix}$ และ $Q=\begin{bmatrix}1&0\\3&1\end{bmatrix}$

\[\begin{aligned} PQ&=\begin{bmatrix}1+6&0+2\\0+3&0+1\end{bmatrix}=\begin{bmatrix}7&2\\3&1\end{bmatrix},\\ (PQ)^{\mathsf T}&=Q^{\mathsf T}P^{\mathsf T}=\begin{bmatrix}7&3\\2&1\end{bmatrix},\\ P^{\mathsf T}Q^{\mathsf T}&=\begin{bmatrix}1&0\\2&1\end{bmatrix}\begin{bmatrix}1&3\\0&1\end{bmatrix}\\ &=\begin{bmatrix}1+0&3+0\\2+0&6+1\end{bmatrix}=\begin{bmatrix}1&3\\2&7\end{bmatrix}. \end{aligned}\]

ลำดับที่ถูกกับลำดับที่ผิดให้ตัวเลขชุดเดียวกันคือ 1, 2, 3, 7 แต่เลข 7 กับเลข 1 สลับช่องกัน ขนาดเท่ากัน ไม่มี error ต้องรู้กฎกลับลำดับจึงจะจับได้

ขั้นที่ 6 — covariance matrix พลิกแล้วได้ตัวเดิม

ต่อไปเป็นตารางที่สำคัญที่สุดในงานความเสี่ยง คือ covariance matrix covariance ของสินทรัพย์สองตัววัดว่ามันขยับไปด้วยกันแค่ไหน ถ้าวันที่ตัวหนึ่งได้ผลตอบแทนสูงกว่าปกติ อีกตัวมักสูงกว่าปกติด้วย covariance จะเป็นบวก ถ้ามักสวนทางกัน covariance จะเป็นลบ ตั้งชื่อของที่ใช้ก่อน

  • $R_1,\dots,R_n$ คือผลตอบแทนของสินทรัพย์ $n$ ตัวในงวดเดียวกัน
  • $\mu_i$ คือค่าเฉลี่ยของ $R_i$ และ $R_i-\mu_i$ คือส่วนเบี่ยงเบน หมายถึงผลตอบแทนห่างจากค่าเฉลี่ยเท่าไร
  • $E[\cdot]$ คือค่าเฉลี่ยตามแบบจำลอง (expected value)

ช่อง $(i,j)$ ของ covariance matrix $\Sigma$ คือค่าเฉลี่ยของผลคูณส่วนเบี่ยงเบนของสินทรัพย์ $i$ กับสินทรัพย์ $j$ ลองสลับ $i$ กับ $j$ แล้วดูว่าได้อะไร

\[\begin{aligned} \Sigma_{ij}&=E\big[(R_i-\mu_i)(R_j-\mu_j)\big]\\ &=E\big[(R_j-\mu_j)(R_i-\mu_i)\big]=\Sigma_{ji},\\ \Sigma^{\mathsf T}&=\Sigma. \end{aligned}\]

ความสมมาตรมาจากเหตุผลเดียว: ผลคูณของตัวเลขสองตัวสลับลำดับได้ $(R_i-\mu_i)(R_j-\mu_j)$ กับ $(R_j-\mu_j)(R_i-\mu_i)$ จึงเป็นตัวเลขเดียวกันทุกครั้ง ค่าเฉลี่ยของมันก็ต้องเท่ากัน ความสมมาตรไม่ได้มาจากการที่สินทรัพย์เป็นอิสระต่อกัน และไม่ได้แปลว่าสินทรัพย์เสี่ยงเท่ากัน ช่องนอกแนวทแยงเป็นบวก ลบ หรือศูนย์ก็ได้ ส่วนช่องบนแนวทแยง $\Sigma_{ii}=E\big[(R_i-\mu_i)^2\big]$ คือ variance ของสินทรัพย์แต่ละตัว

รูปด้านล่างทดลองกับข้อมูลสมมติสี่วัน การสลับแกน $x$ กับ $y$ ทำให้กลุ่มจุดสะท้อนข้ามเส้นทแยง แต่ผลคูณ $x\cdot y$ ของทุกวันเท่าเดิม covariance จึงเท่าเดิม สิ่งที่เปลี่ยนมีอย่างเดียว คือ variance สองตัวบนแนวทแยงสลับที่กัน

ข้อใช้งาน: ถ้าตาราง covariance ที่ระบบส่งมาไม่สมมาตร แปลว่ามีอะไรผิด เช่น ชื่อสินทรัพย์ของแถวกับของคอลัมน์เรียงไม่ตรงกัน หรือสองช่องคำนวณจากช่วงวันที่ต่างกัน ต้องหาสาเหตุก่อน การบังคับให้สมมาตรด้วย $(C+C^{\mathsf T})/2$ คือเฉลี่ยช่อง $(i,j)$ กับช่อง $(j,i)$ ใช้ได้เฉพาะเมื่อยืนยันแล้วว่าสองช่องต่างกันแค่เศษจากการปัดตัวเลข

ขั้นที่ 7 — variance ของพอร์ตคือ $\mathbf w^{\mathsf T}\Sigma\mathbf w$

ถึงตรงนี้มีของครบที่จะหาความเสี่ยงของพอร์ตแล้ว ให้ $w_i$ คือน้ำหนักของสินทรัพย์ $i$ คือสัดส่วนของเงินในพอร์ตที่ลงในสินทรัพย์นั้น และให้น้ำหนักคงที่ตลอดงวด ผลตอบแทนพอร์ตคือผลตอบแทนแต่ละตัวถ่วงด้วยน้ำหนัก $R_p=\sum_iw_iR_i=\mathbf w^{\mathsf T}\mathbf R$ ค่าเฉลี่ยของพอร์ตจึงเป็น $\sum_iw_i\mu_i$ และส่วนเบี่ยงเบนของพอร์ตคือ $\sum_iw_i(R_i-\mu_i)$

variance ของพอร์ตคือค่าเฉลี่ยของส่วนเบี่ยงเบนนี้ยกกำลังสอง เราอยากเขียนมันด้วย $\Sigma$ เพราะ $\Sigma$ คือสิ่งที่ประมาณได้จากข้อมูล

\[\begin{aligned} \operatorname{Var}(R_p)&=E\Big[\Big(\sum_iw_i(R_i-\mu_i)\Big)^2\Big]\\ &=\sum_i\sum_jw_iw_j\,E\big[(R_i-\mu_i)(R_j-\mu_j)\big]\\ &=\sum_i\sum_jw_i\Sigma_{ij}w_j=\mathbf w^{\mathsf T}\Sigma\mathbf w. \end{aligned}\]

ขั้นที่ต้องดูให้ดีคือการกระจายกำลังสองของผลรวม ผลรวมยกกำลังสองให้ผลคูณครบทุกคู่ $(i,j)$ เช่น $(a_1+a_2)^2=a_1a_1+a_1a_2+a_2a_1+a_2a_2$ น้ำหนักเป็นค่าคงที่ จึงดึงออกมานอกค่าเฉลี่ยได้ สิ่งที่เหลือข้างในค่าเฉลี่ยคือ $\Sigma_{ij}$ พอดี

ผลรวมสองชั้น $\sum_i\sum_jw_i\Sigma_{ij}w_j$ ก็คือแถว $\mathbf w^{\mathsf T}$ คูณ matrix $\Sigma$ คูณคอลัมน์ $\mathbf w$ ตัว $\mathbf w$ โผล่สองข้างเพราะกำลังสองให้น้ำหนักสองตัวในทุกพจน์ ไม่ใช่เพราะเติม transpose ให้ขนาดพอดี ขนาดคือ $(1\times n)(n\times n)(n\times1)$ จึงได้ตัวเลขตัวเดียว

ลองกับพอร์ตสมมติที่มีสินทรัพย์สองตัว ของที่รู้มีดังนี้

  • สินทรัพย์ 1 มี variance รายปี $\Sigma_{11}=0.1$ คิดเป็นความผันผวน $\sigma_1=\sqrt{0.1}\approx0.316$ หรือ 31.6% ต่อปี
  • สินทรัพย์ 2 มี variance รายปี $\Sigma_{22}=0.5$ คิดเป็นความผันผวน $\sigma_2=\sqrt{0.5}\approx0.707$ หรือ 70.7% ต่อปี
  • correlation ของทั้งสอง $\rho=-0.25$ (correlation คือ covariance ที่หารด้วยความผันผวนทั้งสองตัวแล้ว จึงอยู่ระหว่าง −1 ถึง 1 ค่าลบแปลว่ามักขยับสวนทางกัน ดู Inner Product, Angle, and Correlation)
  • น้ำหนัก $\mathbf w=(0.6,0.4)^{\mathsf T}$ คือลงเงิน 60% ในสินทรัพย์ 1 และ 40% ในสินทรัพย์ 2

correlation คือ covariance หารด้วยความผันผวนสองตัว ย้อนกลับจึงได้ covariance $\Sigma_{12}=\rho\,\sigma_1\sigma_2=-0.25\times0.316\times0.707\approx-0.0559$ ใส่ทุกอย่างลงใน $\Sigma$ แล้วคำนวณ $\Sigma\mathbf w$ ก่อน จากนั้นจับคู่กับ $\mathbf w$

\[\begin{aligned} \Sigma&=\begin{bmatrix}0.1&-0.0559\\-0.0559&0.5\end{bmatrix},\\ \Sigma\mathbf w&=\begin{bmatrix}0.06-0.02236\\-0.03354+0.20\end{bmatrix} =\begin{bmatrix}0.03764\\0.16646\end{bmatrix},\\ \sigma_p^2&=0.6(0.03764)+0.4(0.16646)\\ &=0.022584+0.066584\\ &=0.089168,\\ \sigma_p&=\sqrt{0.089168}\approx0.2986. \end{aligned}\]

ความผันผวนของพอร์ตคือ $\sigma_p\approx0.2986$ หรือ 29.86% ต่อปี ต่ำกว่าสินทรัพย์ 2 ที่ผันผวน 70.7% มาก เพราะสองสินทรัพย์มักขยับสวนทางกัน

ตรวจอีกทางด้วยสูตรสองสินทรัพย์ $\sigma_p^2=w_1^2\Sigma_{11}+2w_1w_2\Sigma_{12}+w_2^2\Sigma_{22}$ สูตรนี้ได้จากการเขียน $\sum_i\sum_j$ ออกมาครบสี่พจน์ แล้วรวมสองพจน์ไขว้ที่เท่ากันเป็นพจน์เดียว แทนค่าทีละพจน์ พจน์แรกได้ $0.6^2(0.1)=0.036$ พจน์ไขว้ได้ $2(0.6)(0.4)(-0.0559)=-0.026832$ พจน์สุดท้ายได้ $0.4^2(0.5)=0.08$ รวมกันได้ $0.036-0.026832+0.08=0.089168$ ตรงกับแบบ matrix

เลข 2 หน้าพจน์ไขว้มาจากสองช่องนอกแนวทแยง $\Sigma_{12}$ กับ $\Sigma_{21}$ ซึ่งเท่ากันเพราะ $\Sigma$ สมมาตร ดังรูปด้านล่าง ถ้าลืมพจน์ไขว้จะได้ $0.036+0.08=0.116$ คือความผันผวน $\sqrt{0.116}\approx34.1\%$ ตัวเลขนี้เป็นของพอร์ตในโลกที่ correlation เป็นศูนย์ ไม่ใช่พอร์ตนี้

แต่ละช่องของ $\Sigma\mathbf w$ ก็มีความหมายของตัวเอง ช่องที่ $i$ คือ covariance ของสินทรัพย์ $i$ กับพอร์ตทั้งก้อน เพราะ covariance กระจายเข้าไปในผลรวมได้ $\operatorname{Cov}(R_i,R_p)=\sum_jw_j\operatorname{Cov}(R_i,R_j)=(\Sigma\mathbf w)_i$ ถ้าหารด้วย variance ของพอร์ต จะได้ตัวเลขที่บอกว่าเมื่อพอร์ตขยับ 1% สินทรัพย์นั้นขยับไปทางเดียวกันโดยเฉลี่ยกี่ %

สินทรัพย์ 1 ได้ $0.03764/0.089168\approx0.42$ สินทรัพย์ 2 ได้ $0.16646/0.089168\approx1.87$ สินทรัพย์ 2 มีน้ำหนักแค่ 40% แต่ขยับตามพอร์ตแรงเกือบสองเท่าของพอร์ตเอง ความเสี่ยงของพอร์ตนี้จึงมาจากสินทรัพย์ 2 เป็นส่วนใหญ่ เรื่องการแบ่งความเสี่ยงของพอร์ตให้แต่ละสินทรัพย์ทำต่อใน matrix multiplication

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ใช้ reshape แทน transpose: ขนาดออกมาถูก แต่ตัวเลขจับคู่ผิดสัญญา ใน hook แบบผิดให้ $\boldsymbol\theta^{\mathsf T}\widetilde S=(70,32)$ แบบถูกให้ $\boldsymbol\theta^{\mathsf T}S^{\mathsf T}=(50,58)$ และโปรแกรมไม่แจ้ง error ใด ๆ

ลืมกลับลำดับ: เขียน $(PQ)^{\mathsf T}$ เป็น $P^{\mathsf T}Q^{\mathsf T}$ ถ้าเป็น matrix จัตุรัสก็ยังคูณได้ จึงไม่มีอะไรเตือน กับ $P,Q$ ในขั้นที่ 5 แบบผิดให้ $P^{\mathsf T}Q^{\mathsf T}=\begin{bmatrix}1&3\\2&7\end{bmatrix}$ แบบถูกให้ $Q^{\mathsf T}P^{\mathsf T}=\begin{bmatrix}7&3\\2&1\end{bmatrix}$

ใช้ transpose แทน inverse: $D=\begin{bmatrix}2&0\\0&3\end{bmatrix}$ พลิกแล้วได้ตัวเดิม ถ้าใช้ $D^{\mathsf T}$ เพื่อ “ย้อน” การยืด จะได้ $D^{\mathsf T}D=\begin{bmatrix}4&0\\0&9\end{bmatrix}$ คือยืดซ้ำ แบบถูกคือ $D^{-1}D=\begin{bmatrix}1&0\\0&1\end{bmatrix}$ ซึ่งกลับสู่ขนาดเดิม

คิดว่า quadratic form ทุกตัวเป็น variance: ตารางที่ไม่สมมาตรใช้เป็น covariance ไม่ได้ เช่น $B=\begin{bmatrix}2&1\\0&3\end{bmatrix}$ กับ $\mathbf x=(1,2)^{\mathsf T}$ ให้ $B\mathbf x=(2+2,\ 0+6)=(4,6)$ และ $\mathbf x^{\mathsf T}B\mathbf x=1(4)+2(6)=16$ ได้ตัวเลขตัวเดียวเหมือนกัน แต่ $B$ ไม่สมมาตร จึงไม่ใช่ covariance ของอะไรเลย

ต่อให้สมมาตรก็ยังไม่พอ เช่น $C=\begin{bmatrix}1&2\\2&1\end{bmatrix}$ กับพอร์ต $\mathbf a=(1,-1)^{\mathsf T}$ ได้ $C\mathbf a=(1-2,\ 2-1)=(-1,1)$ และ $\mathbf a^{\mathsf T}C\mathbf a=1(-1)+(-1)(1)=-2$ variance ติดลบเป็นไปไม่ได้ ตารางนี้จึงไม่ใช่ covariance ที่ใช้ได้ เงื่อนไขที่ขาดไปเรียกว่า positive semidefinite คือทุก vector $\mathbf x$ ต้องให้ $\mathbf x^{\mathsf T}C\mathbf x\ge0$ ซึ่งตรวจได้ด้วย eigenvalues

บังคับให้สมมาตรเพื่อปิดปัญหา: การเฉลี่ย $(C+C^{\mathsf T})/2$ ทำให้ตารางสมมาตร แต่ไม่ได้ทำให้ถูก สมมติ covariance จริงของสินทรัพย์ 1 กับ 2 คือ 0.02 แต่ระบบเรียงชื่อผิด ช่อง $(1,2)$ จึงได้ 0.02 ส่วนช่อง $(2,1)$ ได้ $-0.01$ ซึ่งเป็นของสินทรัพย์คู่อื่น เฉลี่ยแล้วได้ $(0.02+(-0.01))/2=0.005$ ตารางดูเรียบร้อย แต่ค่าที่ถูกคือ 0.02

โจทย์ตรวจความเข้าใจ

1. ทีมความเสี่ยงใช้ตาราง loading $A$ จาก What a Matrix Is แถวคือหุ้นสามตัว AAPL (Apple), MSFT (Microsoft) และ JPM (ธนาคาร JPMorgan) คอลัมน์คือ factor สองตัว Market กับ Quality ตัวเลขสมมติคือ

\[A=\begin{bmatrix}1.2&0.4\\0.9&0.2\\1.5&0.7\end{bmatrix}.\]

ทีมพลิกตารางเป็น $A^{\mathsf T}$ เพื่อหา exposure ของพอร์ต ช่องแถว Market คอลัมน์ JPM ของ $A^{\mathsf T}$ มีค่าเท่าไร และเป็นความไวของอะไรต่ออะไร

เฉลย

แถว Market คือแถว 1 ของ $A^{\mathsf T}$ และคอลัมน์ JPM คือคอลัมน์ 3 ช่องนี้จึงเป็น $(A^{\mathsf T})_{13}=A_{31}=1.5$ ความหมายยังเป็นความไวของ JPM ต่อ Market เหมือนเดิม คือ Market ขยับ 1% JPM ขยับ 1.5% การพลิกตารางเปลี่ยนแค่ทิศที่เราอ่าน ไม่ได้กลับความหมายเป็น “ความไวของ Market ต่อ JPM”

2. ผู้จัดการพอร์ตในขั้นที่ 7 กู้เงินมาลงเพิ่ม จนน้ำหนักของทั้งสองสินทรัพย์เป็นสองเท่าของเดิม คือ $2\mathbf w=(1.2,0.8)^{\mathsf T}$ (น้ำหนักรวมเกิน 1 เพราะใช้เงินกู้) $\Sigma$ เท่าเดิม variance และความผันผวนของพอร์ตใหม่เป็นเท่าไร

เฉลย

ตัวเลข 2 ดึงออกมาได้ทั้งสองข้าง เพราะ $(2\mathbf w)^{\mathsf T}=2\mathbf w^{\mathsf T}$

\[\begin{aligned} (2\mathbf w)^{\mathsf T}\Sigma(2\mathbf w)&=4\,\mathbf w^{\mathsf T}\Sigma\mathbf w\\ &=4(0.089168)=0.356672,\\ \sigma&=\sqrt{0.356672}\approx0.5972. \end{aligned}\]

ความผันผวนคือ 59.72% ต่อปี เท่ากับ $2\times29.86\%$ พอดี variance โตตามกำลังสองของขนาดพอร์ต (คูณ 4) แต่ความผันผวนโตเป็นเส้นตรง (คูณ 2)

3. โปรแกรมหนึ่งคำนวณ $AB\mathbf c$ โดย $A$ ขนาด $2\times3$, $B$ ขนาด $3\times4$ และ $\mathbf c$ ขนาด $4\times1$ แต่ส่วนถัดไปของโปรแกรมต้องการผลลัพธ์เป็น row vector เขียน $(AB\mathbf c)^{\mathsf T}$ เป็นผลคูณของ transpose แต่ละตัว และตรวจขนาดทุกตัว

เฉลย

กลับลำดับตามกฎของขั้นที่ 5 ได้ $(AB\mathbf c)^{\mathsf T}=\mathbf c^{\mathsf T}B^{\mathsf T}A^{\mathsf T}$ ขนาดคือ $(1\times4)(4\times3)(3\times2)$ เลขด้านในตรงกันทุกคู่ ได้ $1\times2$ ตรงกับ $AB\mathbf c$ ขนาด $2\times1$ ที่พลิกแล้ว ส่วนถ้าไม่กลับลำดับ $A^{\mathsf T}B^{\mathsf T}\mathbf c^{\mathsf T}$ คือ $(3\times2)(4\times3)\cdots$ เลขด้านในคือ 2 กับ 4 ไม่ตรงกัน จึงคูณไม่ได้ตั้งแต่คู่แรก

คำนวณซ้ำด้วย JavaScript

โค้ดด้านล่างคำนวณตัวเลขหลักของหน้านี้ซ้ำ: เทียบ transpose กับ reshape ในตาราง payoff ตรวจกฎกลับลำดับกับ $P$ และ $Q$ คำนวณ variance พอร์ตทั้งแบบ matrix และแบบสูตรสองสินทรัพย์ และตรวจว่าสลับแกนแล้ว covariance ของข้อมูลสี่วันเท่าเดิม

เปิดดูโค้ด 
const transpose = A => A[0].map((_, j) => A.map(row => row[j]));
function multiply(A, B) {
  if (A[0].length !== B.length) throw new Error('inner sizes do not match');
  const Bt = transpose(B);
  return A.map(row => Bt.map(col => row.reduce((s, x, k) => s + x * col[k], 0)));
}
const reshape = (A, m, n) => { const flat = A.flat();
  return Array.from({length: m}, (_, i) => flat.slice(i * n, i * n + n)); };

const S = [[2, 3, 7], [1, 6, 5]], thetaRow = [[2, 6, 4]];
console.log(multiply(thetaRow, transpose(S)));    // [[50, 58]]
console.log(multiply(thetaRow, reshape(S, 3, 2))); // [[70, 32]]  wrong pairing

const P = [[1, 2], [0, 1]], Q = [[1, 0], [3, 1]];
console.log(transpose(multiply(P, Q)));             // [[7,3],[2,1]]
console.log(multiply(transpose(Q), transpose(P)));  // same
console.log(multiply(transpose(P), transpose(Q)));  // [[1,3],[2,7]] wrong order

const Sigma = [[0.1, -0.0559], [-0.0559, 0.5]], w = [[0.6], [0.4]];
const Sw = multiply(Sigma, w);                      // 0.03764, 0.16646
const V = multiply(transpose(w), Sw)[0][0];         // 0.089168
console.log(Sw, V, Math.sqrt(V),
  0.36 * 0.1 + 2 * 0.24 * -0.0559 + 0.16 * 0.5,    // same V
  Sw.map(r => r[0] / V));                           // 0.42, 1.87

const days = [[3, 1], [-1, 1], [-1, 0], [-1, -2]];
const cov = d => d.reduce((s, [x, y]) => s + x * y, 0) / (d.length - 1);
console.log(cov(days), cov(days.map(([x, y]) => [y, x]))); // 4/3 both

สิ่งที่ควรตอบได้หลังอ่าน

  • transpose ย้ายตัวเลขแถว $i$ คอลัมน์ $j$ ไปแถว $j$ คอลัมน์ $i$ คือ $(A^{\mathsf T})_{ji}=A_{ij}$ และชื่อแถวกับชื่อคอลัมน์ย้ายตามตัวเลขไปด้วย reshape ไม่ใช่ transpose แม้ได้ขนาดเดียวกัน ใน hook มันให้ \$70 กับ \$32 แทน \$50 กับ \$58
  • transpose ไม่ใช่ inverse: การเฉือน $P$ ย้อนกลับได้ด้วย $P^{-1}$ ไม่ใช่ $P^{\mathsf T}$
  • $\mathbf u^{\mathsf T}\mathbf v$ ให้ตัวเลขตัวเดียว ส่วน $\mathbf u\mathbf v^{\mathsf T}$ ให้ตารางที่ทุกแถวเป็นรูปแบบเดียวกัน คือ $\mathbf v^{\mathsf T}$ คูณตัวเลขหนึ่งตัว
  • $(PQ)^{\mathsf T}=Q^{\mathsf T}P^{\mathsf T}$ เพราะตัวเลขข้างในสลับลำดับการคูณได้ กฎนี้คือเหตุผลที่กำไรขาดทุนนับทีละหุ้นหรือนับทีละ factor ได้เท่ากัน
  • covariance matrix สมมาตรเสมอ variance ของพอร์ตคือ $\mathbf w^{\mathsf T}\Sigma\mathbf w$ (ในตัวอย่างได้ 0.089168 คือความผันผวน 29.86% ต่อปี) และช่องที่ $i$ ของ $\Sigma\mathbf w$ คือ covariance ของสินทรัพย์ $i$ กับพอร์ต

หน้านี้ใช้การคูณ matrix ไปหลายรอบ แต่ยังไม่ได้ถามว่ากติกา “แถวคูณคอลัมน์” มาจากไหน หน้าถัดไป Matrix Multiplication สร้างกติกานี้จากการต่อเครื่องแปลงสองเครื่องเข้าด้วยกัน แล้วใช้มันแบ่งความเสี่ยงของพอร์ตให้สินทรัพย์แต่ละตัว
