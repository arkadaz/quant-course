19.4 Dividends in the Formulas

ปันผลคือเงินสดที่บริษัทแจกให้คนถือหุ้น คนที่ถือแค่สัญญาบนหุ้นไม่ได้เงินก้อนนี้ ทุกสูตรราคา forward และ option จึงต้องหักปันผลออก โดยหักเป็นมูลค่าวันนี้ และปันผลคือเหตุผลเดียวที่การใช้สิทธิ์ call แบบ American ก่อนหมดอายุอาจคุ้ม

บริษัทหนึ่งประกาศจ่ายปันผลหุ้นละ \$2 ปันผลคือเงินสดที่บริษัทแจกให้คนถือหุ้น คนที่ถือหุ้นอยู่ตอนตลาดปิดวันนี้จะได้เงินก้อนนี้ คนที่ซื้อตั้งแต่พรุ่งนี้เช้าไม่ได้ พรุ่งนี้จึงเรียกว่าวัน XD (ex-dividend date) และเช้าวันนั้นราคาหุ้นมักหล่นลงราวเท่าปันผล

คุณไม่ได้ถือหุ้น แต่ถือ call หนึ่งตัว call คือสิทธิ์ซื้อหุ้นหนึ่งหุ้นที่ราคาตกลงไว้ล่วงหน้า เรียกราคานั้นว่า strike call ตัวนี้เป็นแบบ American คือใช้สิทธิ์วันไหนก็ได้จนหมดอายุ ถ้าใช้สิทธิ์วันนี้ คุณจ่าย strike แล้วได้หุ้นทันที และได้ปันผลด้วย

ของที่รู้ (ตัวเลขสมมติ):

  • ราคาหุ้นวันนี้ $S=\$110$
  • ปันผล $D=\$2$ ต่อหุ้น
  • strike $K=\$100$
  • หลังวัน XD call เหลืออายุ $\tau=3$ เดือน หรือ $0.25$ ปี
  • ดอกเบี้ย $r=5\%$ ต่อปี
  • ความผันผวนของหุ้น $\sigma=20\%$ ต่อปี คือ SD (standard deviation) ของผลตอบแทนหุ้นในหนึ่งปี บอกว่าราคาแกว่งแรงแค่ไหน

เพื่อนบอกว่า “call อยู่ใน money แล้ว (ราคาหุ้นสูงกว่า strike) ใช้สิทธิ์วันนี้ได้ $110-100=\$10$ ทันที แถมได้หุ้นทันปันผล ถ้ารอ พรุ่งนี้หุ้นหล่นไป \$2” ควรใช้สิทธิ์ไหม? แล้วถ้าหุ้นอยู่ที่ \$120 ล่ะ?

ลองตอบก่อนเปิดเฉลย

ที่ \$110 ไม่ควร ใช้สิทธิ์ได้ $110-100=\$10$ แต่ถ้าถือ call ต่อ call มีค่า \$10.29 ค่านี้คือราคา call แบบยุโรป (ใช้สิทธิ์ได้วันหมดอายุวันเดียว) บนหุ้นหลังปันผล $110-2=\$108$ ซึ่งขั้นที่ 10 คำนวณให้ดู ที่ \$120 ควรใช้สิทธิ์ เพราะได้ $120-100=\$20$ แต่ถือต่อมีค่าแค่ \$19.40 จุดแบ่งอยู่ที่หุ้นราว \$111.91 และถ้าปันผลไม่เกิน $100(1-e^{-0.05\times0.25})=\$1.24$ ไม่มีราคาหุ้นไหนเลยที่ใช้สิทธิ์ก่อนแล้วคุ้ม

ภาพรวมก่อนลงสูตร

สูตรราคา forward และ option ที่ผ่านมาใช้เหตุผลเดียวกัน เราเทียบคนสองคนที่จบด้วยของชิ้นเดียวกัน คนแรกซื้อหุ้นจริงวันนี้ คนที่สองทำสัญญาว่าจะได้หุ้นทีหลัง ถ้าสองทางจบเหมือนกัน ต้นทุนวันนี้ต้องเท่ากัน ไม่อย่างนั้นจะมีคนทำเงินฟรีได้

ปันผลทำให้สองทางนี้จบไม่เหมือนกัน คนถือหุ้นได้เงินสดระหว่างทาง แต่คนถือ forward (สัญญาซื้อหุ้นในอนาคตที่ราคาตกลงไว้วันนี้) หรือคนถือ option (สิทธิ์ซื้อหรือขายหุ้นที่ไม่บังคับให้ใช้) ไม่ได้เงินก้อนนั้น เราจึงต้องหักปันผลออกจากฝั่งหุ้น และต้องหักเป็นมูลค่าวันนี้ เพราะปันผลจ่ายในอนาคต และเงินในอนาคตมีค่าวันนี้น้อยกว่าตัวเลขที่ประกาศ (เงินวันนี้ฝากได้ดอกเบี้ย) รูปแรกด้านล่างวาดความต่างนี้บนเส้นเวลา

หน้านี้ทำเรื่องเดียวกันซ้ำในทุกสูตร ตามลำดับนี้

  • ราคา forward แบบ cost of carry เมื่อปันผลเป็นก้อนเงิน และเมื่อปันผลเป็นอัตราต่อปี
  • ทำไมราคาหุ้นหล่นในวัน XD
  • อ่านปันผลที่ตลาดคาดย้อนจากราคา futures
  • ต้นไม้ binomial, สูตร Black–Scholes, put–call parity และบัญชี delta hedge
  • จบที่คำถามของโจทย์เปิดเรื่อง: เมื่อไรการใช้สิทธิ์ call ก่อนวัน XD จึงคุ้ม
ศัพท์ที่ใช้ในหัวข้อนี้
Dividend (ปันผล)
เงินสดที่บริษัทแจกให้คนถือหุ้น เช่น หุ้นละ \$2 ปีละไม่กี่ครั้ง คนที่ถือแค่สัญญาบนหุ้น (forward, futures, option) ไม่ได้เงินก้อนนี้
Ex-dividend date (XD)
วันแรกที่คนซื้อหุ้นไม่ได้ปันผลรอบนั้น เช้าวันนั้นราคาหุ้นจึงหล่นลงราวเท่าปันผล วันนี้กำหนดว่าใครได้ปันผล และเป็นวันที่คนถือ call ต้องตัดสินใจว่าจะใช้สิทธิ์ก่อนหรือไม่
Forward และ futures
forward คือสัญญาซื้อขายหุ้นในวันส่งมอบข้างหน้า ที่ราคา $F$ ซึ่งตกลงไว้วันนี้ futures คือ forward ที่ซื้อขายในตลาดกลาง เช่น ES ซึ่งเป็น futures บนดัชนี S&P 500
Call, put และ strike
call คือสิทธิ์ซื้อหุ้นที่ราคา strike $K$ put คือสิทธิ์ขายหุ้นที่ราคา strike คนถือมีสิทธิ์แต่ไม่ถูกบังคับให้ใช้ call อยู่ “ใน money” เมื่อราคาหุ้นสูงกว่า strike
Cash-and-carry
กู้เงินมาซื้อหุ้นถือไว้ แล้วขาย forward ไปพร้อมกัน ใช้หาว่าราคา forward ที่ยุติธรรมควรเป็นเท่าไร (ดูหน้า cost of carry)
Dividend yield
ปันผลที่เขียนเป็นอัตราต่อปีของราคาหุ้น $q$ เหมือนปันผลไหลออกมาต่อเนื่อง เหมาะกับดัชนีที่มีหุ้นหลายร้อยตัวทยอยจ่ายทั้งปี ส่วนหุ้นตัวเดียวที่จ่ายเป็นก้อน การใช้ปันผลเป็นเงินพร้อมวันจ่ายแม่นกว่า
Prepaid forward
จ่ายเงินวันนี้เพื่อรับหุ้นหนึ่งหุ้นในวันส่งมอบ ถ้าหุ้นจ่ายปันผลระหว่างทาง ต้นทุนคือ $S_0-D_0$ หรือ $S_0e^{-qT}$ ซึ่งถูกกว่าราคาหุ้น เพราะคนรับหุ้นทีหลังไม่ได้ปันผล ชิ้นนี้แทนที่ $S_0$ ในทุกสูตรของหน้านี้
Implied dividend
ปันผลที่อ่านย้อนจากราคา futures หรือ forward ในตลาด โต๊ะใช้ตัวนี้แทนการเดาปันผลเอง และใช้ตรวจว่าราคา futures ผิดปกติหรือไม่
American call และ call แบบยุโรป
American call ใช้สิทธิ์ได้ทุกวันจนหมดอายุ call แบบยุโรปใช้สิทธิ์ได้วันหมดอายุวันเดียว ถ้าหุ้นไม่จ่ายปันผล สิทธิ์ใช้ก่อนของ American call ไม่มีค่าอะไรเลย
Early exercise
การใช้สิทธิ์ option แบบ American ก่อนวันหมดอายุ ถ้าใช้สิทธิ์ call ก่อน เราต้องจ่าย strike เร็วขึ้นและเสียดอกเบี้ยของเงินก้อนนั้น จึงอาจคุ้มเฉพาะเมื่อปันผลที่ได้มากกว่าดอกเบี้ยที่เสีย
Delta
จำนวนหุ้นที่ต้องถือต่อ option หนึ่งตัว เพื่อให้กำไรขาดทุนของหุ้นหักล้างกับของ option เมื่อราคาหุ้นขยับนิดเดียว

ขั้นที่ 1 — ลองด้วยมือ: cash-and-carry ที่มีปันผลหนึ่งก้อน

ลูกค้าขอทำ forward กับโต๊ะ คือขอซื้อหุ้นหนึ่งหุ้นในอีกครึ่งปี ที่ราคา $F$ ซึ่งตกลงกันวันนี้ หุ้นตัวนี้จะจ่ายปันผลหนึ่งครั้งระหว่างทาง โต๊ะควรตั้ง $F$ เท่าไร วิธีหาคือดูว่าโต๊ะต้องใช้ต้นทุนเท่าไรจึงจะมีหุ้นไว้ส่งให้ลูกค้า

โจทย์ให้อะไรมาบ้าง: ตัวเลขสมมติต่อไปนี้

  • ราคาหุ้นวันนี้ $S_0=\$100$
  • ปันผล $D=\$1$ ต่อหุ้น จ่ายที่เวลา $t_D=0.25$ ปี (สามเดือนจากวันนี้)
  • วันส่งมอบหุ้นคือ $T=0.5$ ปี (หกเดือนจากวันนี้)
  • ดอกเบี้ย $r=5\%$ ต่อปีแบบทบต้นต่อเนื่อง แปลว่าเงิน \$1 ที่ฝากหรือกู้นาน $t$ ปี โตเป็น $e^{rt}$ ดอลลาร์

โต๊ะทำ cash-and-carry เป็นสามจังหวะ

  1. วันนี้ กู้ \$100 มาซื้อหุ้นหนึ่งหุ้น และตกลงขาย forward ให้ลูกค้าที่ราคา $F$
  2. ที่ 0.25 ปี ได้ปันผล \$1 แล้วเอาไปฝากทันที
  3. ที่ 0.5 ปี ส่งหุ้นให้ลูกค้าแล้วรับเงิน $F$ คืนหนี้ และถอนเงินฝากปันผล

ให้ $V_T$ คือเงินที่เหลือในมือหลังทำครบ วันนี้โต๊ะไม่ได้ใช้เงินตัวเองเลย ราคาที่ยุติธรรมจึงต้องทำให้ $V_T=0$ ถ้า $V_T$ เป็นบวก ใครก็ทำซ้ำเพื่อเก็บเงินฟรีได้ ถ้าติดลบ ทุกคนจะทำกลับด้าน

\[ \begin{aligned} V_T&=F-100e^{0.05\times0.5}\\ &\quad+1\times e^{0.05\times0.25}\\ &=F-102.5315+1.0126,\\ V_T=0:\quad F&=102.5315-1.0126\\ &=101.5189,\\ F_{\text{no div}}-F&=102.5315-101.5189\\ &=1.0126. \end{aligned} \]

$V_T$ รวมเงินสามก้อนในวันส่งมอบ ก้อนแรกคือ $F$ ที่ลูกค้าจ่าย ก้อนที่สองคือหนี้ \$100 ที่โตมาครึ่งปีเป็น \$102.5315 ซึ่งต้องคืน ก้อนที่สามคือปันผล \$1 ที่ฝากไว้สามเดือน (จาก 0.25 ถึง 0.5 ปี) จึงโตเป็น \$1.0126 ตั้งผลรวมเป็นศูนย์ ก็ได้ราคา forward ที่ไม่มีใครเก็บเงินฟรีได้ ส่วน $F_{\text{no div}}=102.5315$ คือราคา forward ถ้าหุ้นไม่จ่ายปันผล ซึ่งเท่ากับหนี้ก้อนเดียวกันนั้น

คำตอบที่ล่อใจคือ $102.5315-1=101.5315$ ซึ่งสูงไป $101.5315-101.5189=0.0126$ หรือ 1.26 เซนต์ต่อหุ้น ที่ผิดเพราะปันผลมาถึงก่อนวันส่งมอบสามเดือน คนถือหุ้นเอาปันผลไปฝากได้ดอกเบี้ยอีกนิด forward จึงต้องต่ำลงมากกว่า \$1 เล็กน้อย

คำตอบ: forward ที่ยุติธรรมคือ \$101.5189 ต่ำกว่ากรณีไม่มีปันผล \$1.0126

ตรวจเองใน 10 วินาที: ดอกเบี้ยแบบไม่ทบต้นของ \$1 นานสามเดือนที่ 5% ต่อปีคือ $1\times0.05\times0.25=0.0125$ ปันผลจึงโตเป็นราว 1.0125 ใกล้ 1.0126 ส่วนที่ต่างกันคือดอกเบี้ยทบต้น

ขั้นที่ 2 — ทำไมราคาหุ้นลดลงเท่าปันผลในวัน XD และหุ้นแยกเป็นชิ้นอะไรได้

ขั้นที่ 1 ใช้ข้อเท็จจริงหนึ่งโดยไม่ได้พูดถึง หุ้นที่โต๊ะส่งให้ลูกค้าคือหุ้นที่จ่ายปันผลออกไปแล้ว ราคาของหุ้นแบบนี้ต่ำกว่าหุ้นที่ยังมีปันผลติดอยู่ ขั้นนี้ตอบสองคำถาม ข้อแรก ทำไมราคาหุ้นหล่นในวัน XD และหล่นเท่าไร ข้อสอง หุ้นหนึ่งหุ้นวันนี้แยกเป็นของกี่ชิ้น คำตอบข้อสองให้สูตร forward ที่ใช้ได้กับปันผลกี่ก้อนก็ได้

ให้ $S_{\text{cum}}$ คือราคาหุ้นตอนตลาดปิดวันสุดท้ายที่ยังได้ปันผล (cum แปลว่า “พร้อม” ปันผล) และ $S_{\text{ex}}$ คือราคาตอนตลาดเปิดเช้าวัน XD ลองเทรดข้ามคืนนี้ คือซื้อหุ้นตอนตลาดปิดที่ $S_{\text{cum}}$ รับปันผล $D$ แล้วขายเช้าวัน XD ที่ $S_{\text{ex}}$ สองจังหวะห่างกันแค่ชั่วข้ามคืน ดอกเบี้ยข้ามคืนน้อยมากจึงไม่นับ

\[ \begin{aligned} -S_{\text{cum}}+D+S_{\text{ex}}&=0,\\ S_{\text{ex}}&=S_{\text{cum}}-D,\\ S_0&=D_0+e^{-rT}F,\\ F&=(S_0-D_0)e^{rT},\\ D_0&=De^{-rt_D}\\ &=1\times e^{-0.05\times0.25}=0.9876,\\ F&=(100-0.9876)e^{0.05\times0.5}\\ &=101.5189. \end{aligned} \]

เทรดข้ามคืนนี้จ่าย $S_{\text{cum}}$ แล้วได้คืน $D+S_{\text{ex}}$ ผลรวมต้องเป็นศูนย์ ถ้าเป็นบวก ทุกคนจะซื้อก่อน XD แล้วขายทิ้งเช้าวันรุ่งขึ้น เก็บเงินฟรีทุกครั้งที่มีปันผล ถ้าติดลบ ไม่มีใครอยากถือหุ้นข้ามคืนนั้น ทุกคนจะรอซื้อหลัง XD แรงซื้อขายทั้งสองทางดันให้ราคาหล่นเท่าปันผลพอดี ของจริงหล่นน้อยกว่านิดหน่อย เพราะปันผลต้องเสียภาษี และวันนั้นราคาก็ขยับตามข่าวอื่นด้วย

ส่วนที่เหลือของสูตรมองหุ้นหนึ่งหุ้นวันนี้เป็นของสองชิ้นรวมกัน ชิ้นแรกคือสิทธิ์รับปันผลทุกก้อนที่จ่ายก่อนวันส่งมอบ มีค่าวันนี้ $D_0$ ซึ่งได้จากการคิดลดปันผลกลับมาด้วย $e^{-rt_D}$ ชิ้นที่สองคือสิทธิ์รับหุ้นหลังปันผลในวันส่งมอบ เรียกว่า prepaid forward มีค่าวันนี้ $e^{-rT}F$ เพราะ $F$ จ่ายที่ $T$ จึงต้องคิดลดกลับมา แก้หา $F$ ได้ $F=(S_0-D_0)e^{rT}$ ใส่ตัวเลขของขั้นที่ 1 ได้ 101.5189 เท่ากับที่ทำด้วยมือ ถ้ามีปันผลหลายก้อน $D_0$ ก็คือผลรวมของมูลค่าวันนี้ของทุกก้อน

ในภาษาของต้นไม้ binomial ประโยคเดียวกันเขียนได้ว่า $S_0=\mathbb E^{\mathbb Q}_0\big[\sum_i D_i/R^i\big]+\mathbb E^{\mathbb Q}_0[S_n/R^n]$ โดย $\mathbb E^{\mathbb Q}_0$ คือค่าเฉลี่ยภายใต้โอกาสตั้งราคา $D_i$ คือปันผลงวดที่ $i$ $R$ คือตัวคูณเงินฝากต่องวด และ $n$ คืองวดวันส่งมอบ ความหมายคือปันผลแต่ละก้อนเป็นหลักทรัพย์ชิ้นหนึ่งที่ตั้งราคาด้วยวิธีเดิม ไม่ต้องมีทฤษฎีใหม่ และ $F=\mathbb E^{\mathbb Q}_0[S_n]$ ยังจริงเหมือนเดิม ปันผลเปลี่ยนแค่ตัวโอกาสตั้งราคา $\mathbb Q$ ซึ่งขั้นที่ 5 จะเห็นด้วยตัวเลข

ขั้นที่ 3 — ปันผลเป็นอัตรา: ซื้อหุ้นไม่ครบหนึ่งหุ้น แล้วให้ปันผลซื้อเพิ่ม

ดัชนีหุ้นอย่าง S&P 500 คือตะกร้าหุ้นหลายร้อยตัว หุ้นเหล่านั้นทยอยจ่ายปันผลเกือบทุกวันทั้งปี การลงบัญชีทีละก้อนแบบขั้นที่ 1 จึงทำไม่ไหว เราประมาณแทนว่าปันผลไหลออกมาต่อเนื่องในอัตรา $q$ ต่อปีของราคา เรียกว่า dividend yield เช่น $q=2\%$ แปลว่าในหนึ่งปีได้ปันผลรวมราว 2% ของราคาหุ้น

เป้าหมายเหมือนเดิม คือมีหุ้นครบหนึ่งหน่วยในวันส่งมอบ คราวนี้ใช้กลเล็ก ๆ คือเอาปันผลที่ได้ไปซื้อหุ้นเพิ่มทันที จำนวนหุ้นจึงงอกขึ้นเองในอัตรา $q$ ต่อปี เหมือนเงินฝากที่ได้ดอกเบี้ยทบต้น วันนี้จึงซื้อแค่ $e^{-qT}$ หน่วยก็พอ ให้ $n_T$ คือจำนวนหุ้นที่มีในวันส่งมอบ

\[ \begin{aligned} n_T&=e^{-qT}e^{qT}=1,\\ S_0e^{-qT}\times e^{rT}&=F,\\ F&=S_0e^{(r-q)T},\\ q=2\%:\quad F&=100e^{(0.05-0.02)\times0.5}\\ &=100e^{0.015}=101.5113. \end{aligned} \]

ทำไมเริ่มที่ $e^{-qT}$ หน่วย เพราะปันผลซื้อหุ้นเพิ่มจนจำนวนหุ้นโตเป็น $e^{qT}$ เท่าในเวลา $T$ ปี คูณกันได้หนึ่งหุ้นพอดี ต้นทุนวันนี้คือ $S_0e^{-qT}$ ซึ่งกู้มาทั้งหมด หนี้โตด้วยดอกเบี้ยเป็น $S_0e^{-qT}e^{rT}$ ในวันส่งมอบ ราคา forward ที่ยุติธรรมต้องเท่าหนี้ก้อนนี้พอดี อัตราสุทธิจึงเป็น $r-q$ ดอกเบี้ยดันราคา forward ขึ้น ปันผลดันลง

ลองเทียบกับขั้นที่ 1 ปันผล 2% ต่อปีของหุ้น \$100 นานครึ่งปีคือราว $100\times0.02\times0.5=\$1$ เท่ากับปันผลก้อนในขั้นที่ 1 ราคา forward จึงใกล้กันมาก คือ 101.5113 กับ 101.5189 ที่ต่างกันนิดเดียวเพราะเงินออกคนละจังหวะ ส่วนที่หักออกจากหุ้นวันนี้ของแบบอัตราคือ $100-100e^{-0.01}=0.9950$ ส่วนแบบก้อนหัก $D_0=0.9876$

ขั้นที่ 4 — อ่านปันผลย้อนจากราคา futures

ขั้นที่แล้วเริ่มจาก $q$ แล้วหาราคา forward แต่ในตลาดจริงมักเป็นทางกลับกัน ราคา futures มีให้เห็นบนจอทุกวินาที แต่ปันผลของหุ้นห้าร้อยตัวในอีกหกเดือนไม่มีใครรู้แน่ เราจึงอ่านปันผลที่ตลาดคาดย้อนจากราคา futures ตัวอย่างนี้ใช้ ES ซึ่งเป็น futures บนดัชนี S&P 500

โจทย์ให้อะไรมาบ้าง: ข้อมูลจากตลาดต่อไปนี้

  • ดัชนีวันนี้ $S_0=5{,}000$ จุด
  • ดอกเบี้ย $r=5\%$ ต่อปี
  • ES อายุ $T=0.5$ ปี (6 เดือน) เสนอราคา $F=5{,}088.27$ จุด
  • อีกราคาหนึ่งคือ $F=5{,}200$ จุด จากโจทย์เปิดเรื่องของหน้า cost of carry ซึ่งตอนนั้นสมมติว่าหุ้นไม่จ่ายปันผล

คำถามคือ แต่ละราคาบอกว่าตลาดคาดปันผลกี่เปอร์เซ็นต์ต่อปี วิธีคือแก้สูตร $F=S_0e^{(r-q)T}$ หา $q$ โดยใส่ $\ln$ ทั้งสองข้างเพื่อเอา $q$ ลงมาจากเลขชี้กำลัง

\[ \begin{aligned} \ln(F/S_0)&=(r-q)T,\\ q&=r-\frac{\ln(F/S_0)}{T},\\ F=5{,}088.27:\quad q&=0.05-\frac{\ln1.017654}{0.5}\\ &=0.05-0.0350=1.50\%,\\ F=5{,}200:\quad q&=0.05-\frac{\ln1.04}{0.5}\\ &=0.05-0.0784=-2.84\%. \end{aligned} \]

โต๊ะไม่ต้องเดาปันผลของหุ้นห้าร้อยตัวเอง ราคา futures บอกไว้แล้วว่าตลาดคาดปันผลเท่าไร ราคา 5,088.27 จุดตรงกับปันผล 1.50% ต่อปี ($5{,}088.27/5{,}000=1.017654$)

ราคา 5,200 จุดให้ปันผลติดลบ 2.84% ต่อปี ซึ่งเป็นไปไม่ได้ ปันผลติดลบแปลว่าคนถือหุ้นต้องจ่ายเงินให้บริษัท ไม่มีดัชนีไหนทำแบบนั้น ราคานี้จึงแพงเกินจริง แม้สมมติว่าไม่มีปันผลเลย ($q=0$) ราคายุติธรรมก็เป็นแค่ $5{,}000e^{0.05\times0.5}=5{,}126.58$ จุด ราคาบนจอสูงกว่านั้น $5{,}200-5{,}126.58=73.42$ จุด ตรงกับกำไรที่ cash-and-carry ล็อกได้ในหน้า cost of carry

คำตอบ: 5,088.27 จุดบอกปันผล 1.50% ต่อปี ส่วน 5,200 จุดบอกปันผล −2.84% ต่อปี ซึ่งเป็นสัญญาณว่าราคา futures ผิด

ตรวจเองใน 10 วินาที: ใส่ $q=1.5\%$ กลับเข้าสูตร ได้ $5{,}000e^{(0.05-0.015)\times0.5}=5{,}000e^{0.0175}=5{,}088.27$ เท่าราคาบนจอ

ขั้นที่ 5 — ต้นไม้หนึ่งงวดที่มีปันผล: ปันผลเปลี่ยนโอกาสตั้งราคา แต่ไม่เปลี่ยน delta

ก่อนเข้าสูตร Black–Scholes ลองดูผลของปันผลบนต้นไม้ binomial หนึ่งงวดก่อน เพราะบนต้นไม้เราเห็นทุกตัวเลข ต้นไม้ binomial คือ model ที่ให้ราคาหุ้นงวดหน้าเป็นได้แค่สองค่า คือขึ้นหรือลง (ดูหน้า binomial)

ของที่รู้ (ตัวเลขสมมติ):

  • หุ้นวันนี้ $S_0=\$100$ งวดหน้าเป็น $uS_0=110$ หรือ $dS_0=90$ โดย $u=1.10$ และ $d=0.90$ สองราคานี้คือราคาหลังจ่ายปันผลแล้ว
  • ปลายงวดหุ้นจ่ายปันผล $cS_0$ โดย $c=1\%$ จึงได้ $0.01\times100=\$1$ ทั้งขาขึ้นและขาลง
  • เงินฝาก \$1 โตเป็น $R=1.02$ ดอลลาร์ในหนึ่งงวด
  • call strike \$100 อ้างอิงราคาหลังปันผล จึงจ่าย $C_u=110-100=10$ ถ้าหุ้นขึ้น และ $C_d=0$ ถ้าหุ้นลง

call ควรราคาเท่าไรวันนี้ วิธีคือสร้างพอร์ตเลียนแบบ (replicating portfolio) ที่ให้เงินปลายงวดเท่ากับ call ทุกกรณี พอร์ตถือหุ้น $x$ หุ้น กับเงินสด $y$ ดอลลาร์ หุ้นในพอร์ตได้ปันผลด้วย ปลายงวดหุ้นแต่ละหุ้นจึงมีค่าเป็นราคาบวกปันผล คือ $(u+c)S_0$ หรือ $(d+c)S_0$

\[ \begin{aligned} C_u&=(u+c)S_0x+Ry,\\ C_d&=(d+c)S_0x+Ry,\\ x&=\frac{C_u-C_d}{(u-d)S_0}=\frac{10}{20}=0.5,\\ y&=\frac{C_d-(d+c)S_0x}{R}\\ &=\frac{0-0.91\times100\times0.5}{1.02}\\ &=\frac{-45.5}{1.02}=-44.6078,\\ C_0&=xS_0+y\\ &=50-44.6078=5.3922,\\ R&=p(u+c)+(1-p)(d+c),\\ p&=\frac{R-d-c}{u-d}=\frac{0.11}{0.20}=0.55,\\ C_0&=\frac{0.55\times10+0.45\times0}{1.02}\\ &=5.3922. \end{aligned} \]

เอาสมการขาขึ้นลบขาลง เงินสด $Ry$ หักล้างกัน ปันผล $cS_0x$ ก็หักล้างกันด้วย เพราะปันผลเท่ากันทั้งสองขา จำนวนหุ้น $x$ ซึ่งก็คือ delta (จำนวนหุ้นที่ต้องถือต่อ option หนึ่งตัว) จึงขึ้นกับราคาหลังปันผลเท่านั้น ได้ 0.5 เท่ากรณีไม่มีปันผล สิ่งที่เปลี่ยนคือเงินสด หุ้นที่ถือจ่ายปันผลมาช่วยใช้หนี้ พอร์ตจึงกู้ได้มากขึ้น ราคา call วันนี้คือต้นทุนของพอร์ต $C_0=5.3922$ ถ้าไม่มีปันผล $y=-0.90\times100\times0.5/1.02=-44.1176$ และ call เป็น $50-44.1176=5.8824$

สามแถวล่างได้ราคาเดียวกันอีกทาง โดยใช้โอกาสตั้งราคา $p$ (risk-neutral probability) คือโอกาสของขาขึ้นที่ทำให้ผลตอบแทนเฉลี่ยของหุ้นรวมปันผลเท่ากับเงินฝาก $R$ พอดี แล้ว call คือค่าเฉลี่ยของ payoff คิดลดด้วย $R$ ถ้าไม่มีปันผล $p=(1.02-0.90)/0.20=0.60$ และ call เป็น $0.60\times10/1.02=5.8824$ ปันผลลดโอกาสของขาขึ้นเหลือ 0.55 เพราะหุ้นได้ผลตอบแทนส่วนหนึ่งเป็นเงินสดแล้ว ราคาจึงไม่ต้องขึ้นแรงเท่าเดิม

$p$ ต้องอยู่ระหว่าง 0 กับ 1 เงื่อนไขที่ไม่มีใครทำเงินฟรีได้จึงกลายเป็น $d+c\lt R\lt u+c$ ต้นไม้หลายงวดที่จ่าย $c$ ทุกงวดมี $p$ เท่ากันทุกจุด เมื่อตั้งต้นไม้จากความผันผวนต่อปี ให้ $q$ คือ dividend yield ต่อปี และ $\Delta t$ คือความยาวหนึ่งงวดเป็นปี แล้วใช้ $p=\big(e^{(r-q)\Delta t}-d\big)/(u-d)$ แบบเดียวกับที่ตั้งราคา option บน futures

ขั้นที่ 6 — Black–Scholes ที่มีปันผล: เปลี่ยนแค่ forward

ต้นไม้บอกว่าปันผลเปลี่ยนแค่ว่าหุ้นต้องโตเท่าไรในโลกของโอกาสตั้งราคา $\mathbb Q$ ซึ่งคือโลกที่ผลตอบแทนรวมของหุ้นเท่าดอกเบี้ย $r$ พอหุ้นจ่ายปันผล $q$ ผลตอบแทนรวม $r$ แบ่งเป็นปันผล $q$ กับราคาที่โตอีก $r-q$ ราคาหุ้นใต้ $\mathbb Q$ จึงโตแค่ $r-q$ ขั้นนี้แสดงว่าใน สูตร Black–Scholes สิ่งเดียวที่เปลี่ยนคือราคา forward แล้วแปลงสูตรกลับเป็นรูปที่โต๊ะใช้กัน

ตัวอย่าง (ตัวเลขสมมติ):

  • ราคาหุ้น $S_0=\$100$ และ strike $K=\$100$
  • อายุ $T=0.5$ ปี
  • ดอกเบี้ย $r=5\%$ dividend yield $q=2\%$ และความผันผวน $\sigma=20\%$ ต่อปี

ตัวเลขที่ต้องใช้ในสูตร คือ $S_0e^{-qT}=100e^{-0.02\times0.5}=99.0050$ กับ $Ke^{-rT}=100e^{-0.05\times0.5}=97.5310$ กับ $\sigma\sqrt T=0.2\times\sqrt{0.5}=0.141421$ ในสูตร $Z$ คือค่าสุ่ม normal มาตรฐาน และ $\Phi$ คือ CDF ของมัน ค่า $\Phi$ ของแต่ละจุดคำนวณด้วยโค้ดท้ายหน้า

\[ \begin{aligned} S_T&=Fe^{-\frac12\sigma^2T+\sigma\sqrt T\,Z},\\ C&=e^{-rT}\big(F\,\Phi(d_1)-K\,\Phi(d_2)\big)\\ &=S_0e^{-qT}\Phi(d_1)-Ke^{-rT}\Phi(d_2),\\ d_{1}&=\frac{\ln(S_0/K)+(r-q+\frac12\sigma^2)T}{\sigma\sqrt T}\\ &=\frac{0+0.015+0.01}{0.141421}=0.176777,\\ d_2&=d_1-\sigma\sqrt T=0.035355,\\ C&=99.0050\times0.570158\\ &\quad-97.5310\times0.514102\\ &=56.4485-50.1409=6.3076,\\ \Delta&=e^{-qT}\Phi(d_1)\\ &=0.990050\times0.570158=0.5645. \end{aligned} \]

หุ้นใต้ $\mathbb Q$ แกว่งรอบราคา forward $F=S_0e^{(r-q)T}=101.5113$ ค่าเฉลี่ยของ $S_T$ เท่ากับ $F$ พอดี เพราะ $e^{-\frac12\sigma^2T}$ ชดเชยค่าเฉลี่ยของ $e^{\sigma\sqrt T Z}$ ที่สูงกว่าหนึ่ง จากนั้นการหาค่าเฉลี่ยของ payoff แล้วคิดลดทำทุกขั้นเหมือนกรณีไม่มีปันผล ต่างแค่ใส่ $F$ แทน $S_0e^{rT}$

จังหวะที่ต้องสังเกตคือ $e^{-rT}F=S_0e^{-qT}$ ซึ่งคือ prepaid forward ของหุ้น กฎจำง่ายจึงเป็น ทุกที่ที่สูตรเดิมมี $S_0$ ให้ใส่ $S_0e^{-qT}$ แทน ใน $d_1$ จึงเห็น $r-q$ แทน $r$ (ตัวเลข $0.015=(0.05-0.02)\times0.5$ และ $0.01=\frac12\times0.2^2\times0.5$) และ delta มี $e^{-qT}$ คูณอยู่หน้า delta คือจำนวนหุ้นที่ต้องถือเพื่อ hedge call หนึ่งตัว

ถ้าไม่มีปันผล ($q=0$) สูตรเดิมให้ call 6.8887 put 4.4197 และ delta 0.5977 ปันผล 2% ทำให้ call ถูกลง $6.8887-6.3076=0.5811$ เพราะคนถือ call ไม่ได้ปันผล แต่ราคาหุ้นที่ call อ้างอิงถูกปันผลดึงลง put กลับแพงขึ้นเป็น 4.8336 ด้วยเหตุผลเดียวกัน ขั้นถัดไปหาค่านี้ด้วย parity ส่วน delta ลดจาก 0.5977 เหลือ 0.5645 คนที่ hedge call ด้วยหุ้นจึงถือหุ้นน้อยลง

ขั้นที่ 7 — put–call parity ที่มีปันผล

ขั้นที่แล้วยังไม่ได้หาราคา put (สิทธิ์ขายหุ้นที่ strike) วิธีที่ไม่ต้องใช้สูตรใหม่คือ put–call parity ถ้าถือ call หนึ่งตัวและขาย put หนึ่งตัว strike เดียวกัน วันหมดอายุจะได้ $S_T-K$ เสมอ ถ้าหุ้นจบเหนือ strike call จ่าย $S_T-K$ ถ้าหุ้นจบใต้ strike put ที่ขายไปบังคับให้เราจ่าย $K-S_T$ ซึ่งก็คือ $S_T-K$ ที่ติดลบ

เงิน $S_T-K$ ก้อนนี้สร้างจากหุ้นกับเงินฝากได้ ฝั่ง $-K$ ที่จ่ายตอนหมดอายุมีค่าวันนี้ $Ke^{-rT}$ ฝั่ง $S_T$ ต้องใช้ prepaid forward ไม่ใช่หุ้นเต็มตัว เพราะคนถือ call กับ put ได้แค่หุ้นตอนจบ ไม่ได้ปันผลระหว่างทาง

\[ \begin{aligned} C-P&=S_0e^{-qT}-Ke^{-rT}\\ &=99.0050-97.5310\\ &=1.4740,\\ P&=6.3076-1.4740=4.8336,\\ C-P&=S_0-D_0-Ke^{-rT}\\ &=100-0.9876-97.5310\\ &=1.4814. \end{aligned} \]

สูตรแรกใช้กับปันผลเป็นอัตรา $q=2\%$ ของขั้นที่ 6 เอา $C=6.3076$ จาก Black–Scholes ลบ 1.4740 ได้ put 4.8336 สูตรหลังใช้กับปันผลเป็นก้อน (ปันผล \$1 ที่ 0.25 ปีจากขั้นที่ 1 ซึ่ง $D_0=0.9876$) ทั้งสองแบบ ฝั่งหุ้นคือเงินที่ต้องจ่ายวันนี้เพื่อได้หุ้นหนึ่งหุ้นในวันหมดอายุโดยไม่ได้ปันผล

ถ้าลืมปันผล จะได้ $C-P=100-97.5310=2.4690$ แล้วเห็นว่า call ราคาต่ำเกินไป $2.4690-1.4740=0.9950$ เกือบ \$1 ทั้งที่ราคาถูกต้องอยู่แล้ว

ขั้นที่ 8 — delta hedge: หุ้นที่ถือไว้ hedge ก็ได้ปันผล

ลองมองจากฝั่งโต๊ะที่ขาย call ของขั้นที่ 6 ให้ลูกค้า โต๊ะไม่อยากเสี่ยงกับราคาหุ้น จึง hedge คือซื้อหุ้นถือไว้ $\Delta=0.5645$ หุ้นต่อ call หนึ่งตัว ให้กำไรขาดทุนของหุ้นหักล้างกับของ call เงินซื้อหุ้นมาจากค่า call ที่ขายได้ ส่วนที่ขาดกู้มา พอร์ตนี้ไม่มีเงินเข้าออกจากข้างนอก (เรียกว่า self-financing) มูลค่าพอร์ตจึงโตได้สามทางเท่านั้น คือราคาหุ้นที่ถือ ปันผลของหุ้นที่ถือ และดอกเบี้ยของเงินสด คำถามคือ ถ้าลืมทางที่สอง บัญชีจะเพี้ยนแค่ไหน

ลองหนึ่งวันทำการ:

  • หนึ่งรอบยาว $\Delta t=1/252$ ปี เพราะตลาดหุ้นสหรัฐเปิดราว 252 วันต่อปี
  • เริ่มที่มูลค่าพอร์ต $V_0=6.3076$ คือเงินที่ได้จากการขาย call
  • ถือหุ้น $\Delta_0=0.5645$ หุ้น
  • หุ้นขึ้นจาก $S_0=100$ เป็น $S_1=101$
\[ \begin{aligned} V_{i+1}&=V_i+\Delta_i\big(S_{i+1}+S_iq\Delta t-S_i\big)\\ &\quad+(V_i-\Delta_iS_i)\big(e^{r\Delta t}-1\big),\\ \Delta_0(S_1-S_0)&=0.5645\times(101-100)\\ &=0.5645,\\ \Delta_0S_0q\Delta t&=0.5645\times100\times\tfrac{0.02}{252}\\ &=0.004480,\\ V_0-\Delta_0S_0&=6.3076-56.4485\\ &=-50.1409,\\ (V_0-\Delta_0S_0)(e^{r\Delta t}-1)&=-50.1409\times0.000198\\ &=-0.009950,\\ V_1&=6.3076+0.5645\\ &\quad+0.004480-0.009950\\ &=6.8667. \end{aligned} \]

สูตรบัญชีแยกเงินที่เพิ่มในหนึ่งรอบเป็นสามก้อน ก้อนแรกคือกำไรจากราคาหุ้น $\Delta_i(S_{i+1}-S_i)$ ก้อนที่สองคือปันผลที่หุ้น $\Delta_i$ หุ้นจ่ายในรอบนั้น $\Delta_iS_iq\Delta t$ คืออัตรา $q$ ต่อปีคูณเวลาหนึ่งรอบ ก้อนที่สามคือดอกเบี้ยของเงินสด $V_i-\Delta_iS_i$ ซึ่งติดลบ เพราะพอร์ตมีเงินแค่ 6.31 แต่ซื้อหุ้นไป 56.45 จึงต้องกู้ 50.14 และ $e^{r\Delta t}-1=e^{0.05/252}-1=0.000198$ คือดอกเบี้ยหนึ่งวันต่อเงินหนึ่งดอลลาร์

ปันผลวันละ 0.0045 ต่อ call หนึ่งตัวฟังดูน้อย แต่ตลอดครึ่งปีที่ delta อยู่แถว 0.56 รวมได้ราว $0.56\times100\times0.02\times0.5=0.56$ คิดเป็น $0.56/6.31\approx9\%$ ของราคา call

บัญชีถูกหรือไม่ ดูได้จากการเทียบกับราคา call ใหม่ ที่หุ้น 101 และอายุเหลือ $0.5-1/252$ ปี สูตรขั้นที่ 6 ให้ call 6.8583 (คำนวณในโค้ดท้ายหน้า) บัญชี hedge ได้ 6.8667 ต่างกัน $6.8667-6.8583=0.0084$ ส่วนต่างนี้เกิดเพราะปรับ hedge วันละครั้งแทนที่จะปรับต่อเนื่อง เป็นเรื่องของหน้า delta-hedging P&L ถ้าลืมก้อนปันผล บัญชีจะเหลือ $6.8667-0.0045=6.8622$ ต่ำกว่าความจริงทุกวัน และโต๊ะจะเห็นขาดทุนสะสมที่ไม่มีอยู่จริง

ขั้นที่ 9 — call แบบ American: ปันผลต้องชนะดอกเบี้ยของ strike ก่อน

ถึงเวลากลับไปที่คำถามของโจทย์เปิดเรื่อง เริ่มจากกรณีที่หุ้นไม่จ่ายปันผล ในกรณีนี้การใช้สิทธิ์ call ก่อนหมดอายุไม่มีวันคุ้ม เหตุผลมาจาก parity ซึ่งบอกว่า call เท่ากับหุ้น ลบ strike ที่คิดลด บวก put เนื่องจาก put ไม่มีทางติดลบ call ที่เหลืออายุ $\tau$ ปีจึงมีค่าอย่างน้อย $S-Ke^{-r\tau}$ ค่านี้มากกว่า $S-K$ ที่ได้จากการใช้สิทธิ์ เพราะ $Ke^{-r\tau}\lt K$ การขาย call ทิ้งจึงได้เงินมากกว่าการใช้สิทธิ์เสมอ call แบบ American บนหุ้นที่ไม่จ่ายปันผลจึงมีราคาเท่า call แบบยุโรป

ปันผลเปลี่ยนเรื่องนี้ ให้ยืนอยู่ตอนตลาดปิดวันก่อน XD ราคาหุ้นคือ $S$ และมีสองทางเลือก

  • ใช้สิทธิ์ตอนนี้ จ่าย $K$ ได้หุ้นที่ยังมีปันผลติดอยู่ มูลค่าคือ $V_{\text{now}}$
  • ถือ call ต่อ เช้าพรุ่งนี้หุ้นหล่นเหลือ $S-D$ แล้ว call เหลืออายุ $\tau$ ปีโดยไม่มีปันผลอีก มูลค่าคือ $V_{\text{hold}}$
\[ \begin{aligned} V_{\text{now}}&=S-K,\\ V_{\text{hold}}&\ge(S-D)-Ke^{-r\tau},\\ V_{\text{now}}-V_{\text{hold}}&\le D-K\big(1-e^{-r\tau}\big),\\ K\big(1-e^{-r\tau}\big)&=100\big(1-e^{-0.05\times0.25}\big)\\ &=100\times(1-0.987578)\\ &=1.2422. \end{aligned} \]

ขอบล่างของ $V_{\text{hold}}$ ใช้เหตุผลเดียวกับกรณีไม่มีปันผล แต่ใช้กับหุ้นหลังปันผล $S-D$ เอา $V_{\text{now}}$ ลบขอบล่างนี้ $S$ หักล้างกันหมด เหลือการเทียบที่ง่ายมาก ใช้สิทธิ์ก่อนแล้วได้ปันผล $D$ แต่ต้องจ่าย strike เร็วขึ้น $\tau$ ปี จึงเสียดอกเบี้ยของ strike ช่วงนั้น คือ $K(1-e^{-r\tau})$

ถ้าปันผลไม่เกิน \$1.2422 ด้านขวาไม่มีทางเป็นบวก การใช้สิทธิ์ก่อนจึงไม่มีวันคุ้ม ไม่ว่าหุ้นราคาเท่าไร ปันผล \$1 จึงไม่ต้องคิดเลย ปันผล \$2 ของโจทย์เปิดเรื่องผ่านเงื่อนไขนี้ แต่เงื่อนไขนี้บอกแค่ว่า “อาจคุ้ม” เพราะเราเทียบกับขอบล่างของการถือต่อ ไม่ใช่ค่าจริง ค่าจริงสูงกว่าขอบล่างเท่าค่าของ put ที่ซ่อนอยู่ put ตัวนี้คือประกันขาลง ถ้าถือ call ต่อแล้วหุ้นร่วงต่ำกว่า strike เราแค่ไม่ใช้สิทธิ์ แต่ถ้าใช้สิทธิ์ไปแล้ว เราถือหุ้นและรับขาดทุนเต็ม ๆ ขั้นถัดไปจึงต้องคำนวณค่าเต็มของการถือต่อ

ขั้นที่ 10 — คำตอบของโจทย์เปิดเรื่อง: ใช้สิทธิ์ที่ \$110 หรือ \$120

ตอนนี้ตอบโจทย์เปิดเรื่องได้ครบแล้ว เราต้องรู้ค่าเต็มของการถือ call ต่อข้ามวัน XD แล้วเทียบกับเงินที่ได้จากการใช้สิทธิ์ทันที

โจทย์ให้อะไรมาบ้าง: ตัวเลขเดียวกับโจทย์เปิดเรื่อง

  • ปันผล $D=\$2$ และ strike $K=\$100$
  • หลังวัน XD call เหลืออายุ $\tau=0.25$ ปี และไม่มีปันผลอีกจนหมดอายุ
  • ดอกเบี้ย $r=5\%$ และความผันผวน $\sigma=20\%$ ต่อปี

ทำไมค่าการถือต่อจึงคำนวณด้วย call แบบยุโรปได้ เพราะหลังวัน XD ไม่มีปันผลอีก ขั้นที่ 9 บอกว่าการใช้สิทธิ์ก่อนหมดอายุในช่วงนั้นไม่มีวันคุ้ม call แบบ American จึงมีค่าเท่า call แบบยุโรปบนหุ้นหลังปันผล $S-D$ ใช้ Black–Scholes ที่ $q=0$ ได้เลย ตัวเลขที่ใช้ซ้ำคือ $\sigma\sqrt\tau=0.2\times\sqrt{0.25}=0.1$ กับ $r\tau+\frac12\sigma^2\tau=0.0125+0.005=0.0175$ กับ $Ke^{-r\tau}=100e^{-0.0125}=98.7578$

\[ \begin{aligned} d_1(108)&=\frac{\ln1.08+0.0175}{0.1}=0.9446,\\ d_2(108)&=0.9446-0.1=0.8446,\\ V_{\text{hold}}&=108\times0.827571\\ &\quad-98.7578\times0.800836\\ &=10.2889\gt10,\\ d_1(118)&=\frac{\ln1.18+0.0175}{0.1}=1.8301,\\ d_2(118)&=1.8301-0.1=1.7301,\\ V_{\text{hold}}&=118\times0.966386\\ &\quad-98.7578\times0.958198\\ &=19.4040\lt20,\\ S^{*}(D=2)&=111.91. \end{aligned} \]

ที่ \$110 หุ้นหลังปันผลเป็น $110-2=108$ call ที่ถือต่อมีค่า 10.29 มากกว่า $110-100=10$ ที่ได้จากการใช้สิทธิ์ ค่า $\Phi$ ทั้งสี่ตัวในสูตรคำนวณด้วยโค้ดท้ายหน้า ลองแยกดูว่าทำไมแพ้ การใช้สิทธิ์ได้ปันผลหักดอกเบี้ยของ strike แล้วเหลือ $2-1.2422=0.76$ แต่ต้องทิ้งประกันขาลงที่มีค่า $10.29-(108-98.7578)=1.05$ ไป จึงขาดทุน $0.76-1.05=-0.29$

ที่ \$120 หุ้นหลังปันผลเป็น 118 call อยู่ลึกใน money (หุ้นสูงกว่า strike มาก) โอกาสที่หุ้นจะร่วงต่ำกว่า strike ในสามเดือนมีน้อย ประกันขาลงจึงเหลือค่าแค่ $19.40-(118-98.7578)=0.16$ ซึ่งน้อยกว่า 0.76 ที่ได้จากปันผล ถือต่อได้ 19.40 น้อยกว่า $120-100=20$ จึงควรใช้สิทธิ์ก่อนวัน XD

ราคาหุ้นที่สองทางมีค่าเท่ากันเรียกว่า early-exercise boundary $S^*$ หาได้ด้วยการแบ่งครึ่งช่วง (bisection) ในโค้ดท้ายหน้า คือลองราคากลางช่วง ถ้าการใช้สิทธิ์ยังแพ้การถือต่อ ให้ขยับขอบล่างขึ้นมา ถ้าชนะ ให้ขยับขอบบนลงมา ทำซ้ำจนช่วงแคบมาก ได้ $S^*=111.91$ สำหรับปันผล \$2 ปันผลยิ่งมาก จุดแบ่งยิ่งต่ำ คือ 117.21 ที่ \$1.50, 107.70 ที่ \$3 และ 105.53 ที่ \$4 ส่วนปันผลที่ไม่เกิน \$1.2422 ไม่มีจุดแบ่งเลย ตรงกับเงื่อนไขในขั้นที่ 9

คำตอบ: ที่ \$110 ถือต่อ (10.29 เทียบกับ 10) ที่ \$120 ใช้สิทธิ์ (20 เทียบกับ 19.40) เพื่อนพูดถูกแค่ครึ่งเดียว

ตรวจเองใน 10 วินาที: ตามขอบล่างของขั้นที่ 9 ถือต่อมีค่าอย่างน้อย $108-98.7578=9.24$ ค่า 10.29 ที่ได้สูงกว่านั้น $10.29-9.24=1.05$ ซึ่งคือค่าของ put ที่ซ่อนอยู่ในการถือต่อ

หักปันผลตามตัวเลขที่ประกาศ แทนมูลค่าวันนี้: ผิดตรงที่ลืมว่าปันผลที่ได้ก่อนวันส่งมอบเอาไปฝากต่อได้ ตัวอย่างขั้นที่ 1 ทางผิดได้ $102.5315-1=101.5315$ ทางถูกได้ $(100-0.9876)e^{0.05\times0.5}=101.5189$ ผิดไป $1\times(e^{0.0125}-1)=\$0.012578$ ต่อหุ้น ถ้า forward ครอบหุ้นล้านหุ้น ผิด $0.012578\times1{,}000{,}000=\$12{,}578$

ลืมปันผลในราคา option: ผิดตรงที่ใช้ $S_0$ แทน prepaid forward $S_0e^{-qT}$ ตัวอย่างขั้นที่ 6 ทางผิดได้ call 6.8887 ทางถูกได้ 6.3076 แพงเกิน $6.8887/6.3076-1=9.2\%$ ส่วน put ทางผิดได้ 4.4197 ทางถูกได้ 4.8336 ถูกไป $4.8336-4.4197=0.4139$

ใช้ parity แบบไม่มีปันผล: ผิดตรงที่ฝั่งหุ้นยังเป็นหุ้นเต็มตัว ทางผิดได้ $C-P=100-97.5310=2.4690$ ทางถูกได้ $99.0050-97.5310=1.4740$ แล้วเห็นราคาเพี้ยน $2.4690-1.4740=0.9950$ ที่ไม่มีอยู่จริง

ลืมปันผลในบัญชี delta hedge: ผิดตรงที่ไม่ลงก้อน $\Delta_iS_iq\Delta t$ บัญชีขาดวันละ $0.5645\times100\times0.02/252=0.0045$ ต่อ call หนึ่งตัว รวมราว $0.56\times100\times0.02\times0.5=0.56$ ในครึ่งปี ส่วน delta ที่คิดแบบไม่มีปันผลได้ 0.5977 แทน 0.5645 ทำให้ถือหุ้นเกินไป $0.5977-0.5645=0.0332$ หุ้นต่อ call หนึ่งตัว

ใช้สิทธิ์ call ใน money ทุกครั้งก่อนวัน XD: ผิดตรงที่ลืมว่าการถือต่อมีประกันขาลง ที่หุ้น \$110 ใช้สิทธิ์ได้ \$10 แต่ถือต่อมีค่า \$10.2889 เสีย $10.2889-10=\$0.2889$ ต่อหุ้น option หุ้นในตลาดสหรัฐหนึ่งสัญญาครอบหุ้น 100 หุ้น จึงเสีย $0.2889\times100=\$28.89$ ต่อสัญญา

คิดว่าปันผลยิ่งมาก ยิ่งต้องรอให้หุ้นสูงขึ้นก่อนใช้สิทธิ์: ความจริงกลับกัน ปันผลยิ่งมาก จุดแบ่งยิ่งต่ำ ที่ปันผล \$2 จุดแบ่งคือ \$111.91 แต่ที่ปันผล \$4 ลดเหลือ \$105.53 และปันผลที่ไม่เกิน $100(1-e^{-0.05\times0.25})=\$1.2422$ ไม่มีจุดแบ่งเลย

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะ index arbitrage คือโต๊ะที่หากำไรเมื่อราคา futures ห่างจากราคายุติธรรม โต๊ะนี้อ่านปันผลย้อนจากราคา futures ทุกวันแบบขั้นที่ 4 แล้วเทียบกับประมาณการปันผลของตัวเอง ถ้าสองตัวเลขต่างกันมาก แปลว่ามีโอกาสทำกำไร หรือมีอะไรผิดปกติที่ต้องตรวจ

ดัชนีใช้ $q$ ได้เพราะปันผลไหลเข้าเกือบทุกวัน แต่หุ้นตัวเดียวจ่ายปันผลปีละไม่กี่ครั้ง โต๊ะ option บนหุ้นรายตัวจึงเก็บตารางวัน XD ของหุ้นทุกตัว เพราะราคา option, delta และการตัดสินใจใช้สิทธิ์เปลี่ยนตรงวันนั้น ถ้ามีปันผลหลายก้อนก่อนหมดอายุ ต้องใช้ต้นไม้ binomial หรือวิธี finite-difference เพื่อตัดสินใจใหม่ทุกวัน XD

คนที่ขาย call แบบ American ต้องเตรียมรับการถูกใช้สิทธิ์ก่อนวัน XD เมื่อ call ลึกใน money และปันผลเกินดอกเบี้ยของ strike ถ้าคนถือไม่ใช้สิทธิ์ทั้งที่ควรใช้ ส่วนที่คนถือเสียไปก็กลายเป็นกำไรของคนขาย เช่นที่หุ้น \$120 ของโจทย์เปิดเรื่อง คนขายได้ $20-19.40=\$0.60$ ต่อหุ้น ฝั่ง put แบบ American กลับกัน ปันผลทำให้การใช้สิทธิ์ put ก่อนวัน XD น่าสนใจน้อยลง เพราะถ้ารอให้หุ้นหล่นเท่าปันผลก่อน แล้วค่อยใช้สิทธิ์ขายที่ strike จะได้ส่วนต่างมากกว่า

โจทย์ตรวจความเข้าใจ

1. ลูกค้าขอทำ forward ซื้อหุ้นหนึ่งหุ้นในอีก 1 ปี หุ้นราคาวันนี้ $S_0=\$100$ และจะจ่ายปันผลสองครั้ง ครั้งละ \$0.50 ที่ 0.25 ปีและ 0.75 ปี ดอกเบี้ย $r=5\%$ ต่อปีแบบทบต้นต่อเนื่อง ราคา forward ที่ยุติธรรมเป็นเท่าไร และต่ำกว่ากรณีไม่มีปันผลเท่าไร?

เฉลย

คิดลดปันผลทั้งสองก้อนกลับมาเป็นมูลค่าวันนี้ แล้วใช้สูตร $F=(S_0-D_0)e^{rT}$ จากขั้นที่ 2

\[ \begin{aligned} D_0&=0.5e^{-0.05\times0.25}+0.5e^{-0.05\times0.75}\\ &=0.493789+0.481597=0.975386,\\ F&=(100-0.975386)e^{0.05\times1}\\ &=104.1017,\\ F_{\text{no div}}&=100e^{0.05}=105.1271,\\ F_{\text{no div}}-F&=105.1271-104.1017\\ &=1.0254. \end{aligned} \]

ส่วนต่าง 1.0254 มากกว่าปันผลรวม $0.5+0.5=\$1$ เพราะคนถือหุ้นเอาปันผลแต่ละก้อนไปฝากต่อจนถึงวันส่งมอบ

2. ดัชนี S&P 500 อยู่ที่ 5,000 จุด ดอกเบี้ย $r=5\%$ ต่อปี ES อายุ 6 เดือนเสนอราคา 5,050 จุด ตลาดคาดปันผลกี่เปอร์เซ็นต์ต่อปี?

เฉลย

ใช้สูตรอ่านปันผลย้อนของขั้นที่ 4

\[ \begin{aligned} q&=r-\frac{\ln(F/S_0)}{T}\\ &=0.05-\frac{\ln(5{,}050/5{,}000)}{0.5}\\ &=0.05-\frac{0.0099503}{0.5}\\ &=0.05-0.0199=3.01\%. \end{aligned} \]

ได้ 3.01% ต่อปี สูงกว่า 1.50% ของราคา 5,088.27 ราคา futures ที่ต่ำลงแปลว่าตลาดคาดปันผลมากขึ้น เพราะปันผลดันราคา forward ลง

3. คุณถือ call แบบ American strike \$50 พรุ่งนี้เป็นวัน XD ของปันผล \$0.80 หลังวันนั้น call เหลืออายุ 6 เดือน ดอกเบี้ย $r=4\%$ ต่อปี ควรคิดเรื่องใช้สิทธิ์ก่อนวัน XD ไหม?

เฉลย

เทียบปันผลกับดอกเบี้ยของ strike ตามเงื่อนไขในขั้นที่ 9

\[ \begin{aligned} K\big(1-e^{-r\tau}\big)&=50\big(1-e^{-0.04\times0.5}\big)\\ &=50\times(1-0.980199)\\ &=0.9901. \end{aligned} \]

ปันผล \$0.80 ต่ำกว่าเกณฑ์ \$0.9901 การใช้สิทธิ์ก่อนจึงไม่มีวันคุ้ม ไม่ว่าหุ้นจะราคาเท่าไร ถือ call ต่อหรือขาย call ทิ้งได้เงินมากกว่าใช้สิทธิ์เสมอ

const {exp, log, sqrt, max} = Math;

// Standard normal CDF by the series 0.5 + phi(x)(x + x^3/3 + x^5/15 + ...).
function Phi(x) {
  let sum = x, prev = 0, term = x, k = 1;
  while (sum !== prev) { prev = sum; k += 2; term *= x * x / k; sum = prev + term; }
  return 0.5 + sum * exp(-0.5 * x * x - 0.91893853320467274178);
}

// Forward with cash dividends [[D, t], ...]: (S - D0) e^{rT}.
function forwardCash(S, r, T, dividends) {
  const D0 = dividends.reduce((s, [D, t]) => s + D * exp(-r * t), 0);
  return {D0, F: (S - D0) * exp(r * T)};
}

// European call and put with dividend yield q (forward F = S e^{(r - q)T}).
function euro(S, K, T, r, q, sigma) {
  const F = S * exp((r - q) * T), v = sigma * sqrt(T);
  const d1 = (log(F / K) + 0.5 * v * v) / v, d2 = d1 - v;
  const call = exp(-r * T) * (F * Phi(d1) - K * Phi(d2));
  return {F, d1, call, put: call - S * exp(-q * T) + K * exp(-r * T), delta: exp(-q * T) * Phi(d1)};
}

// American call just before an ex-date: exercise now, or hold a European call on S - D.
function holdValue(S, D, K, r, tau, sigma) { return euro(S - D, K, tau, r, 0, sigma).call; }
function boundary(D, K, r, tau, sigma) {
  const gain = S => (S - K) - holdValue(S, D, K, r, tau, sigma);
  let lo = K + D, hi = 10 * K;
  if (gain(hi) <= 0) return null;
  for (let k = 0; k < 200; k++) { const mid = (lo + hi) / 2; if (gain(mid) < 0) lo = mid; else hi = mid; }
  return (lo + hi) / 2;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • หักปันผลเป็นมูลค่าวันนี้ ด้วยสูตร $F=(S_0-D_0)e^{rT}$ ตัวอย่างหุ้น \$100 ปันผล \$1 ได้ $F=101.5189$ ต่ำกว่ากรณีไม่มีปันผล 1.0126 ไม่ใช่ 1.0000 เพราะปันผลเอาไปฝากต่อได้ และราคาหุ้นหล่นเท่าปันผลในวัน XD เพราะไม่อย่างนั้นจะมีคนเก็บเงินฟรีข้ามคืน
  • ปันผลเป็นอัตรา $q$ ให้ $F=S_0e^{(r-q)T}$ กลับสูตรได้ $q=r-\ln(F/S_0)/T$ ราคา futures จึงบอกปันผลที่ตลาดคาด คือ 1.50% ที่ 5,088.27 จุด และ −2.84% ที่ 5,200 จุด ซึ่งเป็นไปไม่ได้ ราคานั้นจึงผิด
  • ในต้นไม้ binomial ปันผลลดโอกาสตั้งราคาของขาขึ้นจาก 0.60 เหลือ 0.55 และลดราคา call จาก 5.8824 เหลือ 5.3922 แต่ไม่เปลี่ยน delta
  • ใน Black–Scholes ทุกที่ที่เคยมี $S_0$ ให้ใส่ $S_0e^{-qT}$ แทน ตัวอย่างได้ call 6.3076 put 4.8336 delta 0.5645 และ $C-P=1.4740$ ส่วนบัญชี delta hedge ต้องลงปันผลของหุ้นที่ถือด้วย
  • การใช้สิทธิ์ call ก่อนวัน XD จะคุ้มได้ก็ต่อเมื่อปันผลเกินดอกเบี้ยของ strike $K(1-e^{-r\tau})=\$1.2422$ และหุ้นต้องสูงกว่าจุดแบ่ง ซึ่งคือ \$111.91 เมื่อปันผล \$2

หน้าถัดไป zero rate, forward rate และ bootstrapping เปลี่ยนเรื่องจากหุ้นมาเป็นเงินกู้ ดอกเบี้ยที่หน้านี้ถือว่าเป็น 5% ทุกอายุ จะกลายเป็นเส้นที่ต่างกันตามอายุเงินกู้ และเหตุผลแบบ cash-and-carry จะถูกใช้หาอัตราดอกเบี้ยล่วงหน้า
