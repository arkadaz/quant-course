19.4 Dividends in the Formulas

ปันผลคือเงินที่คนถือหุ้นได้แต่คนถือสัญญาไม่ได้ ต้องหักออกที่มูลค่าวันนี้ทั้งใน forward และใน option และมันคือเหตุผลเดียวที่การใช้สิทธิ์ call แบบ American ก่อนกำหนดอาจคุ้ม

หุ้นราคา \$110 พรุ่งนี้ขึ้นเครื่องหมาย XD ของปันผล \$2 คุณถือ call แบบ American strike \$100 ซึ่งจะเหลืออายุ 3 เดือนหลังวันนั้น ดอกเบี้ย 5% ความผันผวน 20% ต่อปี เพื่อนบอกว่า “call อยู่ใน money แล้ว ใช้สิทธิ์วันนี้เลย จะได้หุ้นพร้อมปันผล ไม่อย่างนั้นพรุ่งนี้ราคาหุ้นหล่นไป \$2” ควรใช้สิทธิ์ไหม และถ้าหุ้นอยู่ที่ \$120 ล่ะ?

ลองตอบก่อนเปิดเฉลย

ที่ \$110 ไม่ควร ใช้สิทธิ์ได้ \$10 แต่ถือต่อ call มีค่า \$10.29 (call ยุโรปบนหุ้นหลังปันผล \$108) ที่ \$120 ควร ใช้สิทธิ์ได้ \$20 ถือต่อมีค่าแค่ \$19.40 จุดแบ่งอยู่ที่หุ้นราว \$111.91 และถ้าปันผลไม่เกิน $100(1-e^{-0.05(0.25)})=\$1.24$ ไม่มีราคาหุ้นไหนที่ใช้สิทธิ์ก่อนแล้วคุ้มเลย

ภาพรวมก่อนลงสูตร

ทุกสูตรที่ผ่านมาในบทนี้ทำงานได้เพราะเราจับคู่ “ถือหุ้นจริง” กับ “ถือสัญญาบนหุ้น” แล้วบอกว่าสองอย่างต้องราคาเท่ากัน ปันผลทำให้คู่นี้ไม่เท่ากันพอดี คนถือหุ้นได้เงินสดระหว่างทาง คนถือ forward หรือ option ไม่ได้ ส่วนต่างนั้นต้องหักออก และต้องหักที่มูลค่าวันนี้ ไม่ใช่ที่ตัวเลขบนประกาศ รูปด้านล่างคือความต่างนั้นบนเส้นเวลา

หน้านี้ทำเรื่องเดียวซ้ำในทุกสูตร: forward จาก cost of carry (แบบปันผลก้อนและแบบอัตรา) ราคาหุ้นที่หล่นในวัน XD ปันผลที่อ่านย้อนจากราคา futures ต้นไม้ binomial สูตร Black–Scholes put–call parity และบัญชี delta hedge แล้วจบที่คำถามของโจทย์เปิดเรื่อง ว่าเมื่อไรการใช้สิทธิ์ call ก่อนวัน XD จึงคุ้ม

ศัพท์ที่ใช้ในหัวข้อนี้
Ex-dividend date (XD)
วันแรกที่คนซื้อหุ้นไม่ได้ปันผลรอบนั้น ราคาหุ้นจึงลดลงราวเท่าปันผลในเช้าวันนั้น ใช้กำหนดว่าใครได้ปันผล และเป็นวันที่ต้องตัดสินใจเรื่องใช้สิทธิ์ call ก่อนกำหนด
Dividend yield
ปันผลเขียนเป็นอัตราต่อปีของราคาหุ้น $q$ เหมือนไหลออกมาต่อเนื่อง เหมาะกับดัชนีที่มีหุ้นหลายร้อยตัวจ่ายกระจายทั้งปี ส่วนหุ้นตัวเดียวที่จ่ายเป็นก้อนใช้ปันผลเป็นเงินพร้อมวันจ่ายแม่นกว่า
Prepaid forward
จ่ายเงินวันนี้เพื่อรับหุ้นหนึ่งหุ้นในวันส่งมอบ ถ้าหุ้นจ่ายปันผลระหว่างทาง ต้นทุนคือ $S_0-D_0$ หรือ $S_0e^{-qT}$ ถูกกว่าราคาหุ้น เพราะคนรับหุ้นทีหลังไม่ได้ปันผล เป็นชิ้นที่แทนหุ้นในทุกสูตรของหน้านี้
Implied dividend
ปันผลที่อ่านย้อนจากราคา futures หรือ forward ในตลาด โต๊ะใช้ตัวนี้แทนการเดาปันผลเอง และใช้ตรวจว่าราคา futures ผิดปกติหรือไม่
American call
call ที่ใช้สิทธิ์ได้ทุกวันจนหมดอายุ ต่างจาก call ยุโรปที่ใช้ได้วันสุดท้ายเท่านั้น ถ้าหุ้นไม่จ่ายปันผล สิทธิ์พิเศษนี้ไม่มีค่า
Early exercise
การใช้สิทธิ์ option แบบ American ก่อนวันหมดอายุ กับ call ทำแล้วเสียดอกเบี้ยของ strike ที่จ่ายเร็ว จึงมีโอกาสคุ้มเฉพาะเมื่อปันผลที่ได้มากกว่าดอกเบี้ยก้อนนั้น

ขั้นที่ 1 — ลองด้วยมือ: cash-and-carry ที่มีปันผลหนึ่งก้อน

โจทย์ให้อะไรมาบ้าง: หุ้น $S_0=\$100$ จ่ายปันผล $D=\$1$ ที่ $t_D=0.25$ ปี forward อายุ $T=0.5$ ปี ดอกเบี้ย 5% ต่อปีแบบต่อเนื่อง ทำ cash-and-carry: กู้ \$100 ซื้อหุ้น ขาย forward ที่ $F$ ปันผลที่ได้เอาไปฝากทันทีจนถึงวันส่งมอบ หา $F$ ที่ทำให้ผลสุดท้ายเป็นศูนย์

\[ \begin{aligned} V_T&=F-100e^{0.05(0.5)}\\ &\quad+1\cdot e^{0.05(0.25)}\\ &=F-102.5315\\ &\quad+1.0126,\\ F&=101.5189,\\ F_{\text{no div}}-F&=102.5315-101.5189\\ &=1.0126. \end{aligned} \]

ในวันส่งมอบ หุ้นถูกส่งตามสัญญาได้ $F$ ต้องคืนหนี้ \$100 ที่โตมาครึ่งปี และมีปันผล \$1 ที่ฝากไว้สามเดือนโตเป็น 1.0126 ศูนย์ของบรรทัดแรกคือราคาที่ไม่มีใครเก็บเงินฟรีได้

คำตอบที่ล่อใจคือเอา 102.5315 ลบ 1 ได้ 101.5315 ผิดไป 1.26 เซนต์ต่อหุ้น เพราะปันผลมาถึงก่อนวันส่งมอบสามเดือน คนถือหุ้นเอามันไปฝากต่อได้ forward จึงต้องต่ำลงมากกว่า \$1 เล็กน้อย

คำตอบ: forward ที่ยุติธรรมคือ \$101.5189 ต่ำกว่ากรณีไม่มีปันผล \$1.0126

ตรวจเองใน 10 วินาที: ดอกเบี้ยของ \$1 นานสามเดือนที่ 5% คือราว $1(0.05)(0.25)=0.0125$ จึงได้ราว 1.0125 ใกล้ 1.0126

ขั้นที่ 2 — ทำไมราคาหุ้นลดลงเท่าปันผลในวัน XD และหุ้นแยกเป็นชิ้นอะไรได้

บัญชีด้วยมือสมมติเงียบ ๆ ว่าหุ้นที่ส่งมอบคือหุ้นหลังปันผลออกไปแล้ว ขั้นนี้ดูว่าทำไมราคาหุ้นต้องลดลงเท่าปันผล และหุ้นหนึ่งหุ้นวันนี้แยกเป็นอะไรได้บ้าง ให้ $S_{\text{cum}}$ คือราคาก่อนวัน XD และ $S_{\text{ex}}$ คือราคาหลัง ห่างกันชั่วข้ามคืน จึงไม่นับดอกเบี้ย

\[ \begin{aligned} -S_{\text{cum}}+D+S_{\text{ex}}&=0,\\ S_{\text{ex}}&=S_{\text{cum}}-D,\\ S_0&=D_0+e^{-rT}F,\\ F&=(S_0-D_0)e^{rT},\\ D_0&=De^{-rt_D}=0.9876. \end{aligned} \]

บรรทัดแรกคือซื้อหุ้นก่อน XD ได้ปันผล แล้วขายหลัง XD ถ้าผลรวมเป็นบวก ใครก็ทำได้เงินฟรีทุกไตรมาส ถ้าติดลบ ทุกคนจะเลื่อนการซื้อไปหลัง XD ราคาจึงต้องลดลงเท่าปันผลพอดี ของจริงลดน้อยกว่าเล็กน้อยเพราะภาษีของปันผล และราคาขยับด้วยข่าวอื่นในวันเดียวกัน

บรรทัดที่สามมองหุ้นหนึ่งหุ้นเป็นพอร์ตสองชิ้น: สิทธิ์รับปันผลก่อนวันส่งมอบ มีค่า $D_0$ กับสิทธิ์รับหุ้นหลังปันผลในวันส่งมอบ ซึ่งคือ prepaid forward มีค่า $e^{-rT}F$ ในภาษาของต้นไม้ binomial นี่คือ $S_0=\mathbb E^{\mathbb Q}_0\big[\sum_i D_i/R^i\big]+\mathbb E^{\mathbb Q}_0[S_n/R^n]$: ปันผลแต่ละก้อนเป็นหลักทรัพย์ชิ้นหนึ่ง ไม่ต้องมีทฤษฎีใหม่ แก้หา $F$ ได้สูตรเดียวกับบัญชีด้วยมือ และ $F=\mathbb E^{\mathbb Q}_0[S_n]$ ยังเป็นจริง ปันผลเข้ามาทาง $\mathbb Q$ เท่านั้น

ขั้นที่ 3 — ปันผลเป็นอัตรา: ซื้อหุ้นไม่ครบหนึ่งหุ้น แล้วให้ปันผลซื้อเพิ่ม

ดัชนีมีหุ้นหลายร้อยตัว ปันผลไหลเข้ามาเกือบทุกวัน ลงบัญชีทีละก้อนไม่ไหว จึงเขียนเป็นอัตรา $q$ ต่อปี ต้องการมีหุ้นครบหนึ่งหน่วยในวันส่งมอบ แต่ปันผลเอาไปซื้อหุ้นเพิ่มได้เรื่อย ๆ จำนวนหุ้นจึงโตในอัตรา $q$ วันนี้ซื้อแค่ $e^{-qT}$ หน่วยก็พอ

\[ \begin{aligned} n_T&=e^{-qT}e^{qT}=1,\\ S_0e^{-qT}\cdot e^{rT}&=F,\\ F&=S_0e^{(r-q)T},\\ q=2\%:\quad F&=100e^{0.03(0.5)}\\ &=101.5113. \end{aligned} \]

บรรทัดแรกคือเหตุผลที่เลือก $e^{-qT}$: ปันผลซื้อหุ้นเพิ่มจนจำนวนโตเป็น $e^{qT}$ เท่า คูณกันได้หนึ่งพอดี บรรทัดที่สองคือกู้เงิน $S_0e^{-qT}$ มาซื้อหุ้นชุดนั้น แล้วหนี้โตเป็น $F$ ในวันส่งมอบ อัตราสุทธิจึงเป็น $r-q$ ดอกเบี้ยดันราคาล่วงหน้าขึ้น ปันผลดันลง

ปันผล 2% ต่อปีของหุ้น \$100 ครึ่งปีคือราว \$1 จึงได้ 101.5113 ใกล้ 101.5189 ของปันผลก้อน \$1 ต่างกันแค่ว่าเงินออกเมื่อไร

ขั้นที่ 4 — อ่านปันผลย้อนจากราคา futures

โจทย์ให้อะไรมาบ้าง: ดัชนี 5,000 จุด ดอกเบี้ย 5% ES อายุ 6 เดือนเสนอ 5,088.27 จุด ตลาดคาดปันผลเท่าไร แล้วราคา 5,200 จากโจทย์เปิดเรื่องของหน้า cost of carry บอกอะไร แก้สูตร $F=S_0e^{(r-q)T}$ หา $q$

\[ \begin{aligned} q&=r-\frac{\ln(F/S_0)}{T},\\ F&=5{,}088.27:\\ q&=0.05\\ &\quad-2\ln(1.017654)\\ &=1.50\%,\\ F=5{,}200:\quad q&=0.05\\ &\quad-2\ln(1.04)\\ &=-2.84\%. \end{aligned} \]

โต๊ะไม่ต้องเดาปันผลของหุ้นห้าร้อยตัวเอง ราคา futures บอกไว้แล้วว่าตลาดคิดว่าจะได้ปันผลเท่าไร ราคา 5,088.27 ตรงกับ 1.50% ต่อปี

ราคา 5,200 ให้ปันผลติดลบ 2.84% ต่อปี ซึ่งเป็นไปไม่ได้ ไม่มีดัชนีไหนเก็บเงินจากคนถือหุ้น ราคาแบบนี้แปลว่า futures แพงเกินจริง ตรงกับที่ cash-and-carry หาได้ว่าล็อกกำไรได้ 73.42 จุด

คำตอบ: 5,088.27 บอกปันผล 1.50% ต่อปี ส่วน 5,200 บอกปันผล −2.84% ต่อปี คือสัญญาณว่าราคา futures ผิด

ตรวจเองใน 10 วินาที: $5{,}000e^{(0.05-0.015)(0.5)}=5{,}000e^{0.0175}=5{,}088.27$ กลับมาที่ราคาเดิม

ขั้นที่ 5 — ต้นไม้หนึ่งงวดที่มีปันผล: ปันผลเปลี่ยนโอกาสตั้งราคา แต่ไม่เปลี่ยน delta

ก่อนเข้า Black–Scholes ดูผลของปันผลบนต้นไม้ ซึ่งเห็นทุกตัวเลข หุ้น \$100 งวดหน้าเป็น 110 หรือ 90 และจ่ายปันผล $cS_0$ โดย $c=1\%$ ตอนสิ้นงวด เงินฝากโต $R=1.02$ call strike 100 จ่าย $C_u=10$ หรือ $C_d=0$ ตามราคาหลังปันผล พอร์ตเลียนแบบถือหุ้น $x$ หุ้นซึ่งได้ปันผลด้วย และเงินสด $y$

\[ \begin{aligned} C_u&=(u+c)S_0x+Ry,\\ C_d&=(d+c)S_0x+Ry,\\ x&=\frac{C_u-C_d}{(u-d)S_0}=\frac{10}{20}=0.5,\\ y&=\frac{C_d-(d+c)S_0x}{R}=\frac{-45.5}{1.02}\\ &=-44.6078,\\ C_0&=xS_0+y\\ &=50-44.6078=5.3922,\\ p&=\frac{R-d-c}{u-d}=\frac{0.11}{0.20}=0.55,\\ C_0&=\frac{0.55(10)+0.45(0)}{1.02}=5.3922. \end{aligned} \]

ลบสองบรรทัดแรกกัน ปันผล $cS_0x$ หักล้างกันหมด delta $x$ จึงขึ้นกับราคาหลังปันผลเท่านั้น ได้ 0.5 เท่ากรณีไม่มีปันผล แต่เงินสดเปลี่ยน เพราะหุ้นที่ถือจ่ายปันผลมาช่วยใช้หนี้ พอร์ตจึงกู้ได้มากขึ้น ราคา call ออกมา 5.3922

บรรทัดล่างเป็นวิธีเดียวกันแบบโอกาสตั้งราคา ถ้าไม่มีปันผล $p=(1.02-0.90)/0.20=0.60$ call เป็น $0.60(10)/1.02=5.8824$ ปันผลลดโอกาสของขาขึ้นเหลือ 0.55 เพราะผลตอบแทนรวมของหุ้นต้องเท่าดอกเบี้ย ส่วนที่มาเป็นปันผลแล้วจึงไม่ต้องมาจากราคา เงื่อนไขไม่มีเงินฟรีกลายเป็น $d+c\lt R\lt u+c$ ต้นไม้หลายงวดที่จ่าย $c$ ทุกงวดมี $p$ เท่ากันทุกต้นย่อย และเมื่อตั้งต้นไม้จากความผันผวน ใช้ $p=\big(e^{(r-c)\Delta t}-d\big)/(u-d)$ แบบเดียวกับที่ตั้งราคา option บน futures

ขั้นที่ 6 — Black–Scholes ที่มีปันผล: เปลี่ยนแค่ forward

ใต้ $\mathbb Q$ หุ้นโตแค่ $r-q$ เพราะส่วน $q$ ออกมาเป็นปันผล ขั้นนี้เขียนให้เห็นว่าสิ่งเดียวที่เปลี่ยนใน สูตร Black–Scholes คือ forward ของปันผลเป็นอัตรา แล้วแปลงกลับเป็นรูปที่โต๊ะใช้กัน ตัวอย่าง: $S_0=K=100$, $T=0.5$, $r=5\%$, $q=2\%$, $\sigma=20\%$

\[ \begin{aligned} S_T&=Fe^{-\frac12\sigma^2T+\sigma\sqrt T\,Z},\\ C&=e^{-rT}\big(F\,\Phi(d_1)-K\,\Phi(d_2)\big)\\ &=S_0e^{-qT}\Phi(d_1)-Ke^{-rT}\Phi(d_2),\\ d_{1}&=\frac{\ln(S_0/K)+(r-q+\frac12\sigma^2)T}{\sigma\sqrt T}\\ &=\frac{0.015+0.01}{0.141421}=0.176777,\\ d_2&=d_1-\sigma\sqrt T=0.035355,\\ C&=99.0050(0.570158)\\ &\quad-97.5310(0.514102)=6.3076,\\ \Delta&=e^{-qT}\Phi(d_1)=0.5645. \end{aligned} \]

บรรทัดแรกคือหุ้นใต้ $\mathbb Q$ ที่เขียนรอบ $F=S_0e^{(r-q)T}=101.5113$ การคิดค่าเฉลี่ยคิดลดทำทุกขั้นเหมือนกรณีไม่มีปันผล ต่างแค่ใส่ $F$ แทน $S_0e^{rT}$ จังหวะที่ทำให้ได้รูปที่สองคือ $e^{-rT}F=S_0e^{-qT}$ ซึ่งคือ prepaid forward ของหุ้น: ทุกที่ที่สูตรเดิมมี $S_0$ ให้ใส่ $S_0e^{-qT}$ แทน รวมทั้งใน $d_1$ ที่ $r$ กลายเป็น $r-q$ และใน delta ที่มี $e^{-qT}$ คูณอยู่หน้า

ถ้าไม่มีปันผล call เป็น 6.8887 และ put เป็น 4.4197 ปันผล 2% ทำให้ call ถูกลง 0.5811 เพราะคนถือ call ไม่ได้ปันผล และ put แพงขึ้นเป็น 4.8336 เพราะปันผลดึงราคาหุ้นลง ค่า put มาจาก parity ในขั้นถัดไป delta ก็ลดจาก 0.5977 เหลือ 0.5645 คนที่ hedge call ด้วยหุ้นจึงถือหุ้นน้อยลง

ขั้นที่ 7 — put–call parity ที่มีปันผล

put–call parity มาจาก payoff อย่างเดียว: call ลบ put จ่าย $S_T-K$ ในวันหมดอายุ สร้างสิ่งเดียวกันจากหุ้นกับเงินฝาก ฝั่งหุ้นต้องใช้ prepaid forward เพราะคนถือ call กับ put ไม่ได้ปันผล

\[ \begin{aligned} C-P&=S_0e^{-qT}-Ke^{-rT}\\ &=99.0050-97.5310\\ &=1.4740,\\ 6.3076-4.8336&=1.4740,\\ C-P&=S_0-D_0-Ke^{-rT}\\ &=100-0.9876\\ &\quad-97.5310=1.4814. \end{aligned} \]

บรรทัดแรกสำหรับปันผลเป็นอัตรา บรรทัดที่สี่สำหรับปันผลเป็นก้อน (ปันผล \$1 ที่ 0.25 ปีของบัญชีด้วยมือ) ทั้งสองแบบฝั่งหุ้นคือเงินที่ต้องจ่ายวันนี้เพื่อได้หุ้นหนึ่งหุ้นในวันหมดอายุ ราคา call และ put จาก Black–Scholes ผ่าน parity พอดี

ถ้าลืมปันผล จะได้ $100-97.5310=2.4690$ แล้วคิดว่า call ถูกเกินไปเกือบหนึ่งดอลลาร์ทั้งที่ราคาถูกต้อง

ขั้นที่ 8 — delta hedge: หุ้นที่ถือไว้ hedge ก็ได้ปันผล

โต๊ะที่ขาย call ข้างบนแล้ว hedge ด้วยหุ้น $\Delta=0.5645$ หุ้น ต้องลงบัญชีพอร์ต hedge ทุกรอบ บัญชีที่ไม่มีเงินเข้าออกจากข้างนอก (self-financing) โตได้จากสามทาง: ราคาหุ้นที่ถือ ปันผลของหุ้นที่ถือ และดอกเบี้ยของเงินสดที่เหลือ ลองหนึ่งวัน ($\Delta t=1/252$ จาก 252 วันทำการต่อปี) เริ่มที่ $V_0=6.3076$ หุ้นขึ้นจาก 100 เป็น 101

\[ \begin{aligned} V_{i+1}&=V_i+\Delta_i\big(S_{i+1}+S_iq\Delta t-S_i\big)\\ &\quad+(V_i-\Delta_iS_i)\big(e^{r\Delta t}-1\big),\\ \Delta_0S_0q\Delta t&=0.5645(100)\tfrac{0.02}{252}\\ &=0.004480,\\ (V_0-\Delta_0S_0)(e^{r\Delta t}-1)&=-50.1409(0.000198)\\ &=-0.009950,\\ V_1&=6.3076+0.5645\\ &\quad+0.004480-0.009950\\ &=6.8667. \end{aligned} \]

พจน์แรกในวงเล็บคือกำไรจากราคาหุ้น พจน์ $S_iq\Delta t$ คือปันผลที่หุ้น $\Delta_i$ หุ้นจ่ายในรอบนั้น และพจน์สุดท้ายคือดอกเบี้ยของเงินสด ซึ่งติดลบเพราะพอร์ตกู้เงินมาซื้อหุ้น ($6.31-56.45=-50.14$) บัญชีได้ปันผลวันละ 0.0045 ต่อหุ้นของ option ฟังดูน้อย แต่ตลอดครึ่งปีที่ delta อยู่แถว 0.56 รวมได้ราว $0.56(100)(0.02)(0.5)=0.56$ ต่อหุ้น หรือ 9% ของราคา call

call ใหม่ที่หุ้น 101 เหลืออายุ $0.5-1/252$ ปีมีค่า 6.8583 บัญชี hedge ได้ 6.8667 ส่วนต่าง 0.0084 มาจากการปรับ hedge วันละครั้งแทนต่อเนื่อง ซึ่งเป็นเรื่องของ delta-hedging P&L ถ้าลืมพจน์ปันผล บัญชีจะเหลือ 6.8622 และโต๊ะจะเห็นขาดทุนที่ไม่มีอยู่จริงทุกวัน

ขั้นที่ 9 — call แบบ American: ปันผลต้องชนะดอกเบี้ยของ strike ก่อน

ถ้าหุ้นไม่จ่ายปันผล การใช้สิทธิ์ call ก่อนกำหนดไม่มีวันคุ้ม เพราะ call มีค่าอย่างน้อย $S-Ke^{-r\tau}$ ซึ่งมากกว่า $S-K$ ที่ได้จากการใช้สิทธิ์ call แบบ American บนหุ้นที่ไม่จ่ายปันผลจึงราคาเท่า call ยุโรป ปันผลเปลี่ยนเรื่องนี้ ณ ชั่วขณะก่อนวัน XD เทียบสองทาง: ใช้สิทธิ์ได้หุ้นที่ยังมีปันผลติดอยู่ หรือถือต่อแล้วหุ้นลดลง $D$ หลังจากนั้นเหลือเวลา $\tau$ ไม่มีปันผลอีก

\[ \begin{aligned} V_{\text{ex}}&=S-K,\\ V_{\text{hold}}&\ge(S-D)-Ke^{-r\tau},\\ V_{\text{ex}}-V_{\text{hold}}&\le D-K\big(1-e^{-r\tau}\big),\\ K\big(1-e^{-r\tau}\big)&=100\big(1-e^{-0.0125}\big)\\ &=1.2422. \end{aligned} \]

บรรทัดที่สองมาจาก parity บนหุ้นหลังปันผล: call เท่ากับหุ้นลบ strike ที่คิดลดบวก put และ put ไม่ติดลบ จึงได้ขอบล่าง ลบสองบรรทัดแรก $S$ หักล้างกันหมด เหลือการเทียบที่ง่ายมาก: ใช้สิทธิ์ได้ปันผล $D$ แต่ต้องจ่าย strike เร็วขึ้น เสียดอกเบี้ยของ strike ช่วงที่เหลือ

ถ้าปันผลไม่เกิน \$1.2422 ผลต่างไม่มีทางเป็นบวก ใช้สิทธิ์ก่อนไม่มีวันคุ้ม ไม่ว่าหุ้นราคาเท่าไร ปันผล \$1 จึงไม่ต้องคิดเลย ปันผล \$2 ผ่านเงื่อนไขนี้ แต่นี่เป็นเงื่อนไขจำเป็นเท่านั้น ยังต้องเทียบกับค่าเต็มของการถือต่อ ซึ่งมี put ซ่อนอยู่ข้างใน

ขั้นที่ 10 — คำตอบของโจทย์เปิดเรื่อง: ใช้สิทธิ์ที่ \$110 หรือ \$120

โจทย์ให้อะไรมาบ้าง: ปันผล $D=\$2$ strike 100 หลังวัน XD เหลือ $\tau=0.25$ ปี ดอกเบี้ย 5% ความผันผวน 20% ไม่มีปันผลอีก ค่าของการถือต่อจึงเท่ากับ call ยุโรปบนหุ้นหลังปันผล ($S-D$) ใช้ Black–Scholes ที่ $q=0$ ซึ่ง $\sigma\sqrt\tau=0.1$, $\frac12\sigma^2\tau=0.005$ และ $100e^{-0.0125}=98.7578$

\[ \begin{aligned} d_1(108)&=\frac{\ln1.08+0.0125+0.005}{0.1}\\ &=0.9446,\\ V_{\text{hold}}&=108(0.827571)\\ &\quad-98.7578(0.800836)\\ &=10.2889\gt10,\\ d_1(118)&=\frac{\ln1.18+0.0175}{0.1}\\ &=1.8301,\\ V_{\text{hold}}&=118(0.966386)\\ &\quad-98.7578(0.958198)\\ &=19.4040\lt20,\\ S^{*}(D=2)&=111.91. \end{aligned} \]

ที่ \$110 หุ้นหลังปันผลเป็น 108 call ที่ถือต่อมีค่า 10.29 มากกว่า 10 ที่ได้จากการใช้สิทธิ์ ปันผล \$2 ไม่พอชดเชยค่าเวลาที่เหลือ ที่ \$120 call ลึกใน money จนแทบไม่เหลือค่าเวลา ถือต่อได้ 19.40 น้อยกว่า 20 จึงควรใช้สิทธิ์ก่อนวัน XD

บรรทัดสุดท้ายหาด้วยการแบ่งครึ่งช่วงในโค้ด: ราคาที่สองทางเท่ากันคือ 111.91 ปันผลยิ่งมาก จุดแบ่งยิ่งต่ำ: 117.21 ที่ \$1.50, 107.70 ที่ \$3 และ 105.53 ที่ \$4 ส่วนปันผลไม่เกิน 1.2422 ไม่มีจุดแบ่งเลย ตรงกับเงื่อนไขในขั้นก่อน จุดแบ่งนี้เรียกว่า early-exercise boundary

คำตอบ: ที่ \$110 ถือต่อ (10.29 เทียบ 10) ที่ \$120 ใช้สิทธิ์ (20 เทียบ 19.40) เพื่อนพูดถูกแค่ครึ่งเดียว

ตรวจเองใน 10 วินาที: ถือต่อมีค่าอย่างน้อย $108-98.7578=9.24$ ตามขอบล่าง ค่า 10.29 ที่ได้สูงกว่านั้น 1.05 ซึ่งคือค่าของ put ในตัวที่ยังเหลือ

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

หักปันผลที่มูลค่าหน้าตั๋ว: 102.5315 ลบ 1 ได้ 101.5315 แทน 101.5189 ผิด 1.26 เซนต์ต่อหุ้น หรือราว \$12,578 ต่อหุ้นล้านหุ้น

ลืมปันผลในราคา option: call ของตัวอย่าง Black–Scholes จะเป็น 6.8887 แทน 6.3076 แพงเกิน 9.2% และ put ถูกไป 0.4139

ใช้ parity แบบไม่มีปันผล: ได้ 2.4690 แทน 1.4740 แล้วเห็นส่วนต่างเกือบ \$1 ที่ไม่มีอยู่จริง

ลืมปันผลในบัญชี delta hedge: บัญชีขาดวันละ 0.0045 ต่อหุ้น รวมราว 0.56 ต่อหุ้นในครึ่งปี และ delta ที่คิดแบบไม่มีปันผล (0.5977 แทน 0.5645) ทำให้ถือหุ้นเกินไป 0.033 หุ้นต่อ option

ใช้สิทธิ์ call ใน money ทุกครั้งก่อนวัน XD: ที่ \$110 เสีย 0.29 ต่อหุ้น หรือ \$28.89 ต่อสัญญา 100 หุ้น

คิดว่าปันผลมากขึ้นต้องรอราคาหุ้นสูงขึ้นก่อนใช้สิทธิ์: รูปจุดแบ่งแสดงตรงข้าม: ปันผลมากขึ้นทำให้จุดแบ่งต่ำลง และปันผลไม่เกิน \$1.2422 ไม่มีจุดแบ่งเลย

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะ index arbitrage อ่านปันผลย้อนจากราคา futures ทุกวัน และเทียบกับประมาณการปันผลของตัวเอง ถ้าต่างกันมากคือโอกาสหรือคำเตือน ดัชนีใช้ $q$ ได้เพราะปันผลไหลเข้าเกือบทุกวัน ส่วนหุ้นตัวเดียวจ่ายปีละไม่กี่ครั้ง โต๊ะ option บนหุ้นรายตัวจึงเก็บตารางวัน XD ไว้ทุกตัว เพราะราคา delta และการตัดสินใจใช้สิทธิ์เปลี่ยนตรงวันนั้น เมื่อปันผลมีหลายก้อนก่อนหมดอายุ ต้องใช้ต้นไม้หรือ finite-difference ตัดสินใจทุกวัน XD

คนที่ขาย call แบบ American ต้องเตรียมรับการถูกใช้สิทธิ์ก่อนวัน XD เมื่อ call ลึกใน money และปันผลเกินดอกเบี้ยของ strike ถ้าไม่ถูกใช้สิทธิ์ตามที่ควร ปันผลก้อนนั้นก็กลายเป็นกำไรของคนขาย ฝั่ง put แบบ American กลับกัน: ปันผลทำให้การใช้สิทธิ์ put ก่อนวัน XD น่าสนใจน้อยลง เพราะรอให้หุ้นลดลงเท่าปันผลก่อนแล้วค่อยใช้สิทธิ์ได้ราคาดีกว่า

1. หุ้น \$100 จ่ายปันผล \$0.50 สองครั้งที่ 0.25 และ 0.75 ปี forward อายุ 1 ปี ดอกเบี้ย 5% ราคา forward เป็นเท่าไร และต่ำกว่ากรณีไม่มีปันผลเท่าไร?

เฉลย

$D_0=0.5e^{-0.0125}+0.5e^{-0.0375}=0.493789+0.481597=0.975386$ ราคา $F=(100-0.975386)e^{0.05}=104.1017$ กรณีไม่มีปันผล $100e^{0.05}=105.1271$ ต่ำกว่า 1.0254 มากกว่าปันผลรวม \$1 เพราะปันผลแต่ละก้อนถูกฝากต่อจนถึงวันส่งมอบ

2. ดัชนี 5,000 ดอกเบี้ย 5% ES อายุ 6 เดือนเสนอ 5,050 ตลาดคาดปันผลเท่าไรต่อปี?

เฉลย

$q=0.05-2\ln(5{,}050/5{,}000)=0.05-2(0.0099503)=3.01\%$ ต่อปี สูงกว่า 1.50% ของราคา 5,088.27 ราคา futures ที่ต่ำลงแปลว่าตลาดคาดปันผลมากขึ้น

3. call แบบ American strike \$50 หลังวัน XD เหลืออายุ 6 เดือน ดอกเบี้ย 4% ปันผล \$0.80 ควรคิดเรื่องใช้สิทธิ์ก่อนวัน XD ไหม?

เฉลย

เกณฑ์คือ $50(1-e^{-0.04(0.5)})=50(1-0.980199)=0.9901$ ปันผล 0.80 ต่ำกว่าเกณฑ์ การใช้สิทธิ์ก่อนไม่มีวันคุ้มไม่ว่าหุ้นจะราคาเท่าไร ถือ call ต่อหรือขายทิ้งดีกว่าใช้สิทธิ์เสมอ

const {exp, log, sqrt, max} = Math;

// Standard normal CDF by the series 0.5 + phi(x)(x + x^3/3 + x^5/15 + ...).
function Phi(x) {
  let sum = x, prev = 0, term = x, k = 1;
  while (sum !== prev) { prev = sum; k += 2; term *= x * x / k; sum = prev + term; }
  return 0.5 + sum * exp(-0.5 * x * x - 0.91893853320467274178);
}

// Forward with cash dividends [[D, t], ...]: (S - D0) e^{rT}.
function forwardCash(S, r, T, dividends) {
  const D0 = dividends.reduce((s, [D, t]) => s + D * exp(-r * t), 0);
  return {D0, F: (S - D0) * exp(r * T)};
}

// European call and put with dividend yield q (forward F = S e^{(r - q)T}).
function euro(S, K, T, r, q, sigma) {
  const F = S * exp((r - q) * T), v = sigma * sqrt(T);
  const d1 = (log(F / K) + 0.5 * v * v) / v, d2 = d1 - v;
  const call = exp(-r * T) * (F * Phi(d1) - K * Phi(d2));
  return {F, d1, call, put: call - S * exp(-q * T) + K * exp(-r * T), delta: exp(-q * T) * Phi(d1)};
}

function holdValue(S, D, K, r, tau, sigma) { return euro(S - D, K, tau, r, 0, sigma).call; }
function boundary(D, K, r, tau, sigma) {
  const gain = S => (S - K) - holdValue(S, D, K, r, tau, sigma);
  let lo = K + D, hi = 10 * K;
  if (gain(hi) <= 0) return null;
  for (let k = 0; k < 200; k++) { const mid = (lo + hi) / 2; if (gain(mid) < 0) lo = mid; else hi = mid; }
  return (lo + hi) / 2;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • หักปันผลที่มูลค่าวันนี้: $F=(S_0-D_0)e^{rT}=101.5189$ ต่ำกว่ากรณีไม่มีปันผล 1.0126 ไม่ใช่ 1.0000 และราคาหุ้นหล่นเท่าปันผลในวัน XD
  • ปันผลเป็นอัตราให้ $F=S_0e^{(r-q)T}$ และราคา futures บอกปันผลที่ตลาดคาดได้ (1.50% ที่ 5,088.27 และ −2.84% ที่ 5,200 ซึ่งเป็นไปไม่ได้)
  • ในต้นไม้ ปันผลลดโอกาสตั้งราคาของขาขึ้น (0.60 เหลือ 0.55) และราคา call (5.8824 เหลือ 5.3922) แต่ไม่เปลี่ยน delta
  • ใน Black–Scholes ใส่ $S_0e^{-qT}$ แทน $S_0$: call 6.3076 put 4.8336 delta 0.5645 parity 1.4740 และบัญชี delta hedge ต้องรับปันผลของหุ้นที่ถือ
  • ใช้สิทธิ์ call ก่อนวัน XD ต้องมีปันผลเกินดอกเบี้ยของ strike (\$1.2422) และหุ้นต้องสูงกว่าจุดแบ่ง (\$111.91 ที่ปันผล \$2)
