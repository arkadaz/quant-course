8.9 Simulating the MVN with the Cholesky Decomposition

เครื่องสุ่มให้แค่ตัวเลข Normal ที่อิสระต่อกัน Cholesky หา matrix สามเหลี่ยมล่าง $L$ ที่ $LL^{\mathsf T}=\Sigma$ แล้ว $r=\mu+Lz$ จะได้ผลตอบแทนที่ขยับร่วมกันตาม covariance ที่ต้องการพอดี

ต้องจำลองผลตอบแทนรายปีของสองสินทรัพย์ ตัวแรก SD 20% ตัวที่สอง SD 30% และ correlation 0.6 แต่เครื่องสุ่มในคอมพิวเตอร์ให้ได้อย่างเดียวคือตัวเลข standard Normal ที่อิสระต่อกัน มีคนเสนอ $r_2=0.30(0.6z_1+0.4z_2)$ เพราะ “ยืม 60% จากตัวแรก ที่เหลือ 40% เป็นของตัวเอง” จะได้ correlation 0.6 ไหม

ลองตอบก่อนเปิดเฉลย

ไม่ได้ สูตรนั้นให้ SD ของตัวที่สอง $0.30\sqrt{0.6^2+0.4^2}\approx21.63\%$ แทน 30% และ correlation ราว 0.832 แทน 0.6 น้ำหนักของสองก้อนต้องยกกำลังสองแล้วรวมได้ 1 จึงต้องเป็น 0.6 กับ 0.8 สูตรที่ถูกคือ $r_1=0.20z_1$ และ $r_2=0.18z_1+0.24z_2$ ถ้าเครื่องสุ่มได้ $z=(1.4,\ -0.7)$ สองสินทรัพย์จะได้ +28.0% กับ +8.4%

ภาพรวมก่อนลงสูตร

หน้าที่แล้วเริ่มจาก MVN แล้วรวมเป็นตัวเลขตัวเดียว หน้านี้เดินกลับ เริ่มจากเมฆกลมของเลขสุ่มที่อิสระต่อกัน แล้วยืดและเอียงมันให้เป็นเมฆรีที่มี covariance ตามสั่ง เหตุที่ต้องทำคือหลายคำถามไม่มีสูตรปิด เช่น VaR ของพอร์ตที่มี option หรือราคาของ derivative ที่อ้างอิงหลายสินทรัพย์ ทางเดียวที่เหลือคือสุ่ม scenario จำนวนมากแล้วนับ

เครื่องมือคือการคูณ matrix ผลตอบแทนแต่ละตัวเป็นผลรวมถ่วงน้ำหนักของ shock อิสระ ตัวแรกใช้ shock แรกอย่างเดียว ตัวที่สองใช้ shock แรกบางส่วนและ shock ของตัวเองบางส่วน ไล่ไปเรื่อย ๆ matrix ของน้ำหนักจึงเป็นสามเหลี่ยมล่าง แก้ได้ทีละแถวจากบนลงล่าง เรียกว่า Cholesky factor รูปด้านล่างแสดงว่ามันทำอะไรกับเมฆจุด

หน้านี้จะแก้กรณีสองสินทรัพย์ด้วยมือ ตามเส้นทางแรกให้เห็นทีละก้าว พิสูจน์ว่าได้ทั้ง covariance และ Normal ครบ เขียนสูตรทั่วไป ขยายเป็นสามสินทรัพย์ เทียบกับวิธี factor เดียวของ Gaussian copula สุ่มจริงแล้วตัดสินว่าคลาดแค่ไหนจึงปกติ อ่าน VaR จากผลสุ่ม และสุดท้ายป้อนตารางที่เป็นไปไม่ได้ ดูว่า Cholesky ร้องเตือนตรงไหน

ขั้นที่ 1 — แก้กรณีสองสินทรัพย์ด้วยมือ

ให้ตัวแรกใช้ shock ตัวเดียว ส่วนตัวที่สองใช้ shock ร่วมกับตัวแรกบางส่วนและ shock ของตัวเองบางส่วน ยังไม่รู้ตัวคูณ $a, b, c$ แต่รู้ว่า $z_1, z_2$ อิสระกันและมี variance 1 จึงเขียน variance และ covariance ของสิ่งที่สร้างได้ทันทีด้วยสูตรของlinear combinations แล้วจับให้ตรงเป้า

\[ \begin{aligned} r_1&=az_1,\qquad r_2=bz_1+cz_2,\\ \operatorname{Var}(r_1)&=a^2=0.20^2=0.04,\\ \operatorname{Cov}(r_1,r_2)&=ab=0.6(0.20)(0.30)\\ &=0.036,\\ \operatorname{Var}(r_2)&=b^2+c^2=0.30^2=0.09,\\ a&=0.20,\\ b&=0.036/0.20=0.18,\\ c&=\sqrt{0.09-0.18^2}=\sqrt{0.0576}\\ &=0.24. \end{aligned} \]

สามเงื่อนไข สามตัวที่ไม่รู้ และแก้ได้ทีละบรรทัด เงื่อนไขแรกมีแค่ $a$ พอรู้ $a$ เงื่อนไขที่สองเหลือแค่ $b$ พอรู้ $b$ เงื่อนไขสุดท้ายเหลือแค่ $c$ ลำดับที่เรียบร้อยนี้เกิดได้เพราะจงใจให้ $r_1$ ไม่แตะ $z_2$ เลย ตัวคูณของตัวที่สองคือ $0.18=0.30(0.6)$ กับ $0.24=0.30(0.8)$ และ $0.6^2+0.8^2=1$ variance จึงกลับมาเป็น $0.30^2$ พอดี นี่คือจุดที่สูตร 0.6 กับ 0.4 ในโจทย์เปิดพลาด

เขียนเป็นสัญลักษณ์ได้ $b=\rho\sigma_2$ และ $c=\sigma_2\sqrt{1-\rho^2}$ ตัว $c$ คือ SD ของตัวที่สองที่เหลือหลังรู้ตัวแรกแล้ว ตัวเดียวกับความกว้างของรอยตัดในconditional distribution Cholesky กับ conditional distribution จึงเป็นเรื่องเดียวกันมองคนละมุม ตัวหนึ่งถามว่าเหลือความไม่แน่นอนเท่าไร อีกตัวถามว่าจะประกอบมันกลับอย่างไร

ขั้นที่ 2 — เส้นทางแรก: เลขสุ่มคู่เดียวให้อะไร

โจทย์ให้อะไรมาบ้าง: เครื่องสุ่มให้ $z_1=1.4$ และ $z_2=-0.7$ ซึ่งได้จากเลขสุ่มระหว่าง 0 ถึง 1 คือ 0.9192 กับ 0.2420 ผ่าน $\Phi^{-1}$ เพราะ $\Phi(1.4)\approx0.9192$ และ $\Phi(-0.7)\approx0.2420$ ถือสองสินทรัพย์อย่างละครึ่ง

\[ \begin{aligned} r_1&=0.20(1.4)=0.280,\\ r_2&=0.18(1.4)+0.24(-0.7)\\ &=0.252-0.168=0.084,\\ r_{50/50}&=0.5(0.280)+0.5(0.084)\\ &=0.182. \end{aligned} \]

คำตอบ: +28.0%, +8.4% และพอร์ตครึ่งต่อครึ่ง +18.2% สังเกตว่า $z_2$ ติดลบแต่ $r_2$ ยังบวก เพราะแรงดึงจาก shock ร่วม 0.252 ชนะ shock ของตัวเอง 0.168 นี่คือ correlation ทำงานให้เห็นในเส้นทางเดียว

ตรวจเองใน 10 วินาที: $0.18\times1.4=0.252$ และ $0.24\times0.7=0.168$ ต่างกัน 0.084 แต่เส้นทางเดียวพิสูจน์ correlation ไม่ได้ ต้องสุ่มหลายเส้นแล้ววัดกลับ ซึ่งทำในขั้นที่ 7

ขั้นที่ 3 — เขียนเป็น matrix แล้วพิสูจน์ว่าได้ทั้ง covariance และ Normal

สิ่งที่ทำในขั้นที่ 1 คือหา $L=\begin{bmatrix}0.20&0\\0.18&0.24\end{bmatrix}$ แล้วตั้ง $r=\mu+Lz$ คำถามคือทำไมวิธีนี้ให้ covariance ตรงเป้าเสมอ ไม่ใช่แค่ในตัวอย่างนี้ วิธีตอบคือคำนวณ covariance ของสิ่งที่สร้างตรง ๆ

\[ \begin{aligned} \Sigma&=LL^{\mathsf T},\qquad r=\mu+Lz,\\ \operatorname{Cov}(r)&=\mathbb E\big[(Lz)(Lz)^{\mathsf T}\big]\\ &=L\,\mathbb E\big[zz^{\mathsf T}\big]\,L^{\mathsf T}\\ &=L\,I\,L^{\mathsf T}=\Sigma. \end{aligned} \]

จังหวะสำคัญคือดึง $L$ ออกนอกค่าคาดหวัง ซึ่งทำได้เพราะ $L$ เป็นตัวเลขคงที่ที่คำนวณไว้ก่อนสุ่ม ตรงกลางเหลือ $\mathbb E[zz^{\mathsf T}]=I$ แนวทแยงเป็น 1 เพราะแต่ละ $z_k$ มี variance 1 นอกแนวทแยงเป็น 0 เพราะอิสระกัน สมมติฐานเรื่องเครื่องสุ่มถูกใช้ตรงนี้ที่เดียว ถ้าเลขสุ่มที่ออกติดกันมี correlation แฝง ผลจะผิดทั้งที่พีชคณิตถูกทุกบรรทัด

covariance ตรงยังไม่พอ หลายรูปทรงมี covariance เดียวกันได้ ถ้าจะอ่านหางซ้ายอย่าง VaR ต้องรู้ว่า $r$ เป็น MVN จริง ใช้ MGF โดยตั้ง $u:=L^{\mathsf T}s$ เพื่อให้ $s^{\mathsf T}Lz=u^{\mathsf T}z$ แล้วใช้ความอิสระของ $z_k$ แยกค่าคาดหวังเป็นผลคูณ

\[ \begin{aligned} M_r(s)&=e^{s^{\mathsf T}\mu}\,\mathbb E\big[e^{u^{\mathsf T}z}\big]\\ &=e^{s^{\mathsf T}\mu}\prod_{k=1}^{d}\mathbb E\big[e^{u_kz_k}\big]\\ &=e^{s^{\mathsf T}\mu}\prod_{k=1}^{d}e^{u_k^2/2}\\ &=\exp\big(s^{\mathsf T}\mu+\tfrac12u^{\mathsf T}u\big)\\ &=\exp\big(s^{\mathsf T}\mu+\tfrac12s^{\mathsf T}\Sigma s\big). \end{aligned} \]

บรรทัดที่สองคือจุดที่ใช้ความอิสระ ค่าคาดหวังของผลคูณแยกเป็นผลคูณของค่าคาดหวัง (consequences of independence) บรรทัดที่สามใช้ MGF ของ standard Normal $\mathbb E[e^{tz}]=e^{t^2/2}$ แล้วผลคูณของ exponential กลายเป็นผลบวกในเลขชี้กำลัง ได้ $u^{\mathsf T}u=s^{\mathsf T}LL^{\mathsf T}s$ บรรทัดสุดท้ายคือ MGF ของ $\mathcal N(\mu,\Sigma)$ พอดี $r$ จึงเป็น MVN จริง ไม่ใช่แค่มี covariance ตรง

ขั้นที่ 4 — สูตรทั่วไป: ถอดทีละช่อง และความหมายของสิ่งที่อยู่ในราก

กรณี $d$ สินทรัพย์ทำแบบขั้นที่ 1 ทุกอย่าง แค่เขียนด้วยสัญลักษณ์ ช่อง $(i,j)$ ของ $LL^{\mathsf T}$ คือ dot product ของแถว $i$ กับแถว $j$ ของ $L$ และเพราะช่องเหนือแนวทแยงเป็นศูนย์ ผลรวมจึงหยุดที่ $\min(i,j)$ ไล่หลักจากซ้ายไปขวา ในแต่ละหลักแก้ช่องทแยงก่อน แล้วค่อยแก้ช่องใต้ทแยง

\[ \begin{aligned} \Sigma_{ij}&=\sum_{k=1}^{\min(i,j)}\ell_{ik}\ell_{jk},\\ p_j&:=\Sigma_{jj}-\sum_{k=1}^{j-1}\ell_{jk}^2,\\ \ell_{jj}&=\sqrt{p_j},\\ \ell_{ij}&=\frac{\Sigma_{ij}-\sum_{k=1}^{j-1}\ell_{ik}\ell_{jk}}{\ell_{jj}}\quad(i\gt j). \end{aligned} \]

บรรทัดที่สองได้จากบรรทัดแรกเมื่อ $i=j$: $\Sigma_{jj}=\sum_{k\lt j}\ell_{jk}^2+\ell_{jj}^2$ ย้ายข้างแล้วตั้งชื่อสิ่งที่เหลือว่า pivot ความหมายของมันคือส่วนของ variance สินทรัพย์ที่ $j$ ที่ shock ของสินทรัพย์ก่อนหน้าอธิบายไม่ได้ ในขั้นที่ 1 pivot ตัวที่สองคือ $0.09-0.0324=0.0576=0.24^2$ บรรทัดสุดท้ายได้จากบรรทัดแรกเมื่อ $i\gt j$ โดยแยกพจน์ $k=j$ ออกมา คือเอา covariance เป้าหมาย หักส่วนที่ shock ก่อนหน้าสร้างไว้แล้ว แล้วหารด้วย $\ell_{jj}$ ที่เพิ่งได้

ทำไม pivot ของตาราง positive definite ถึงบวกเสมอ เพราะ $p_j$ คือ variance ของ “สินทรัพย์ $j$ ลบส่วนที่ทำนายได้จากสินทรัพย์ก่อนหน้า” ซึ่งเป็นพอร์ตหนึ่งที่น้ำหนักไม่เป็นศูนย์หมด ถ้าทุกพอร์ตแบบนั้นมี variance บวก รากก็ถอดได้ทุกขั้น และการบังคับให้แนวทแยงเป็นบวกทำให้ $L$ มีคำตอบเดียว

ขั้นที่ 5 — แบบจำลองรายวันของ desk: SPX, QQQ และกองทุนพันธบัตร

โจทย์ให้อะไรมาบ้าง: แบบจำลองรายวันเดียวกับconditional distribution: SPX SD 2% QQQ SD 3% covariance 0.00024 (correlation 0.4) เพิ่มกองทุนพันธบัตรระยะยาว SD 1% ต่อวัน covariance กับ SPX และกับ QQQ เท่ากันที่ −0.00006 (correlation −0.3 และ −0.2) mean ใส่ทีหลังได้โดยไม่กระทบ $L$

\[ \begin{aligned} \ell_{11}&=\sqrt{0.0004}=0.02,\\ \ell_{21}&=0.00024/0.02=0.012,\\ \ell_{22}&=\sqrt{0.0009-0.012^2}\\ &=\sqrt{0.000756}\approx0.0274955,\\ \ell_{31}&=-0.00006/0.02=-0.003,\\ \ell_{32}&=\frac{-0.00006-(-0.003)(0.012)}{0.0274955}\\ &=\frac{-0.000024}{0.0274955}\approx-0.000873,\\ p_3&=0.0001-0.003^2-0.000873^2\\ &\approx90.24\times10^{-6},\\ \ell_{33}&=\sqrt{p_3}\approx0.00950. \end{aligned} \]

คำตอบ: แถวของ QQQ คือ (1.2%, 2.75%, 0) และแถวของพันธบัตรคือ (−0.30%, −0.087%, 0.95%) ตัวเลข 0.0274955 คือ SD 2.7495% ที่เหลือหลังรู้ SPX ซึ่งเป็นตัวเลขเดียวกับ hedge ratio ของหน้าก่อน เพราะทั้งคู่คือรากของ pivot ตัวที่สอง

ตรวจเองใน 10 วินาที: แถวที่สามคือหัวใจของ Cholesky ก่อนแบ่ง covariance ระหว่างพันธบัตรกับ QQQ ให้ shock ตัวที่สอง ต้องหักส่วนที่เกิดแล้วผ่าน shock ตัวแรก $(-0.003)(0.012)=-0.000036$ ออก เพราะทั้งสองรับ $z_1$ มาแล้ว ถ้าไม่หัก covariance จะถูกนับซ้ำ ภาพรวมเหมือนแบบจำลองปัจจัย $z_1$ ทำหน้าที่เหมือนตลาด $z_2$ คือส่วนที่ QQQ ต่างจาก SPX และ $z_3$ คือความเสี่ยงเฉพาะของพันธบัตร ซึ่งยังเหลือ 0.95% จาก 1% เพราะหุ้นอธิบายพันธบัตรได้น้อย

ขั้นที่ 6 — ไม่ได้มีแค่ L: วิธี factor เดียวของ Gaussian copula

matrix $A$ ใดก็ตามที่ $AA^{\mathsf T}=\Sigma$ ใช้ได้หมด เพราะการพิสูจน์ในขั้นที่ 3 ไม่ได้ใช้ว่า $L$ เป็นสามเหลี่ยมเลย แบบจำลองสินเชื่อที่ใช้ตั้งราคาCDO สร้าง Normal ที่สัมพันธ์กันด้วยปัจจัยร่วมตัวเดียว $M$ บวกส่วนเฉพาะตัว $Z_i$ ซึ่งทั้งหมดอิสระกัน

\[ \begin{aligned} X_i&=a_iM+\sqrt{1-a_i^2}\,Z_i,\\ \operatorname{Var}(X_i)&=a_i^2+(1-a_i^2)=1,\\ \operatorname{Cov}(X_i,X_j)&=a_ia_j\quad(i\ne j). \end{aligned} \]

บรรทัดที่สามมาจากว่าส่วนเดียวที่ $X_i$ กับ $X_j$ แชร์กันคือ $M$ ส่วน $Z_i$ กับ $Z_j$ อิสระกัน สำหรับโจทย์เปิด เลือก $a_1=a_2=\sqrt{0.6}\approx0.7746$ แล้วตั้ง $r_1=0.20X_1$ และ $r_2=0.30X_2$ ก็ได้ correlation $0.7746^2=0.6$ เหมือนกัน แต่ใช้ shock สามตัวแทนสอง และทำได้เฉพาะตารางที่ correlation ทุกคู่เขียนเป็น $a_ia_j$ ได้ Cholesky ใช้ shock เท่าจำนวนสินทรัพย์พอดี และใช้ได้กับทุกตาราง positive definite

การเลือกสามเหลี่ยมล่างจึงไม่ได้ให้ distribution ที่ต่างไป ทุก $A$ ที่ $AA^{\mathsf T}=\Sigma$ ให้ MVN ตัวเดียวกัน ข้อดีของ $L$ คือแก้ได้ทีละแถวโดยไม่ต้องหา eigenvalue และคูณ $Lz$ ใช้แค่ครึ่งตาราง นับจากสูตรในขั้นที่ 4 ทั้งตารางใช้ราว $d^3/3$ flops พอร์ต 500 สินทรัพย์ใช้ราว 41.7 ล้าน flops ครั้งเดียว ส่วนแต่ละเส้นทางใช้ราว $d^2=250{,}000$ flops สุ่ม 200,000 เส้นทางใช้ $5\times10^{10}$ flops การแตก $\Sigma$ จึงแทบไม่มีราคาเมื่อเทียบกับการสุ่ม

ขั้นที่ 7 — สุ่มจริง 200,000 เส้นทาง แล้วตัดสินว่าคลาดแค่ไหนจึงปกติ

ขั้นที่ 3 พิสูจน์ค่าของแบบจำลอง แต่ตัวอย่างจำกัดย่อมคลาดเคลื่อน คำถามที่ถูกจึงไม่ใช่ “ตรงเป้าไหม” แต่คือ “คลาดเท่าไรจึงปกติ” เริ่มจาก SD ถ้า $r=\sigma z$ แล้ว $\hat\sigma^2$ คือค่าเฉลี่ยของ $\sigma^2z^2$ จำนวน $n$ ตัว ใช้ $\mathbb E[z^4]=3$ ที่ MGF ให้ แล้วแปลงจาก variance เป็น SD ด้วยอนุพันธ์ของราก

\[ \begin{aligned} \operatorname{Var}(z^2)&=\mathbb E[z^4]-1=2,\\ \operatorname{SE}(\hat\sigma^2)&\approx\sigma^2\sqrt{2/n},\\ \operatorname{SE}(\hat\sigma)&\approx\frac{\sigma^2\sqrt{2/n}}{2\sigma}=\frac{\sigma}{\sqrt{2n}},\\ \operatorname{SE}(\hat\rho)&\approx\frac{1-\rho^2}{\sqrt n}=\frac{0.64}{447.2}\approx0.00143. \end{aligned} \]

บรรทัดที่สามใช้ว่าถ้า $\hat\sigma^2$ ขยับเล็กน้อย $\hat\sigma$ ขยับประมาณ $1/(2\sigma)$ เท่า สำหรับ $n=200{,}000$ ได้ SE ของ SD เป็น $0.20/\sqrt{400{,}000}\approx0.00032$ และ $0.30/\sqrt{400{,}000}\approx0.00047$ บรรทัดสุดท้ายเป็นสูตรประมาณสำหรับตัวอย่างใหญ่จากข้อมูล Normal ที่ใช้กันทั่วไป หน้านี้ใช้เป็นไม้บรรทัด ไม่ได้พิสูจน์

ขั้นที่ 8 — อ่าน VaR และ ES จากผลสุ่มที่เรียงแล้ว

โจทย์ให้อะไรมาบ้าง: ใช้ 10,000 เส้นทางแรกของการสุ่มในขั้นที่ 7 คิดขาดทุนของพอร์ตครึ่งต่อครึ่งเป็น $\ell=-(0.5r_1+0.5r_2)$ ต่อมูลค่าพอร์ต เรียงจากน้อยไปมาก VaR 95% คือค่าที่ลำดับ $K=0.95\times10{,}000=9{,}500$ และ ES 95% คือค่าเฉลี่ยของ 500 ค่าที่ใหญ่กว่านั้น เทียบกับสูตรของlinear combinations ที่รู้ว่าพอร์ตเป็น Normal mean 0 SD $\sqrt{0.25(0.04)+0.25(0.09)+0.5(0.036)}=\sqrt{0.0505}\approx22.47\%$

ขั้นที่ 9 — ทำให้มันพัง: ตารางที่เป็นไปไม่ได้

Cholesky ไม่ได้แค่คำนวณ มันตรวจตารางไปด้วย ลองป้อนของผิดสองแบบ แบบแรกมีคนพิมพ์ correlation 1.1 ในโจทย์เปิด แบบที่สองร้ายกว่า ทุก correlation อยู่ระหว่าง −1 ถึง 1 แต่สามคู่คือ 0.9, 0.9 และ −0.9 เรียก correlation matrix นี้ว่า $C$ แล้วลองพอร์ต $v$ ที่ short ตัวแรกและถือสองตัวหลัง

\[ \begin{aligned} \ell_{21}&=\frac{1.1(0.20)(0.30)}{0.20}=0.33,\\ p_2&=0.09-0.33^2=-0.0189\lt0,\\ C&=\begin{bmatrix}1&0.9&0.9\\0.9&1&-0.9\\0.9&-0.9&1\end{bmatrix},\\ p_2^{C}&=1-0.9^2=0.19,\\ \ell_{32}&=\frac{-0.9-0.9(0.9)}{\sqrt{0.19}}\approx-3.923,\\ p_3^{C}&=1-0.81-3.923^2\approx-15.2\lt0,\\ v&=(-1,\ 1,\ 1)^{\mathsf T},\\ v^{\mathsf T}Cv&=3+2(-0.9-0.9-0.9)=-2.4. \end{aligned} \]

correlation 1.1 ทำให้ pivot ตัวที่สองติดลบ แปลว่าสินทรัพย์ที่สองต้องมี “ส่วนที่ตัวแรกอธิบายไม่ได้” ที่ variance ติดลบ ซึ่งไม่มีอยู่จริง กรณี $C$ ทุกช่องดูปกติแต่ขัดกันเอง ถ้าตัวที่ 1 ไปทางเดียวกับทั้งตัวที่ 2 และตัวที่ 3 เกือบเต็มที่ ตัวที่ 2 กับ 3 ก็ต้องไปทางเดียวกันด้วย จะสวนกันที่ −0.9 ไม่ได้ พอร์ต $v$ จึงได้ variance −2.4 ซึ่งเป็นไปไม่ได้ บรรทัดสุดท้ายนับเลข 1 สามตัวบนแนวทแยง บวกพจน์ไขว้สามคู่ที่แต่ละคู่ได้ −0.9 Cholesky ผ่านสองแถวแรกเพราะตาราง $2\times2$ มุมบนยังใช้ได้ แล้วหยุดที่แถวสามซึ่งเป็นจุดที่ความขัดแย้งปรากฏ

ขั้นที่ 10 — ซ่อม C แล้วดูว่าเสียอะไรไป

โจทย์ให้อะไรมาบ้าง: จาก $Cv=(0.8,-0.8,-0.8)^{\mathsf T}=-0.8v$ ตาราง $C$ มี eigenvalue −0.8 ในทิศ $v$ วิธีซ่อมแบบง่ายที่ใช้กันคือยก eigenvalue นั้นขึ้นเป็นศูนย์ โดยบวก $0.8$ ในทิศ $v/\|v\|$ แล้วหารให้แนวทแยงกลับเป็น 1

\[ \begin{aligned} F&=C+\tfrac{0.8}{3}\,vv^{\mathsf T},\\ F_{ii}&=1+\tfrac{0.8}{3}=\tfrac{3.8}{3},\\ |F_{ij}|&=0.9-\tfrac{0.8}{3}=\tfrac{1.9}{3},\\ \rho_{\rm fix}&=\frac{1.9/3}{3.8/3}=0.5,\\ (p_1,p_2,p_3)&=(1,\ 0.75,\ 0). \end{aligned} \]

คำตอบ: correlation ใหม่คือ 0.5, 0.5 และ −0.5 ซึ่งเปลี่ยนไปทุกคู่ ไม่ใช่แค่คู่ที่ผิด และ pivot ตัวที่สามเป็นศูนย์พอดี เพราะ $v^{\mathsf T}C_{\rm fix}v=3+2(-0.5-0.5-0.5)=0$ สินทรัพย์ที่สามจึงเท่ากับสินทรัพย์แรกลบสินทรัพย์ที่สองทุกเส้นทาง ในโค้ด pivot นี้ออกมาเป็นราว $-1\times10^{-16}$ เพราะการปัดเศษ ตารางที่อยู่บนขอบจึงตกไปฝั่งลบได้ งานจริงจึงยก eigenvalue ขึ้นเป็นค่าบวกเล็ก ๆ หรือหา correlation matrix ที่ใกล้ที่สุดอย่างเป็นระบบ และต้องรายงานเสมอว่าการซ่อมเปลี่ยนทุกคู่

ตรวจเองใน 10 วินาที: $F_{12}=0.9+\tfrac{0.8}{3}(-1)(1)=0.9-0.267=0.633$ หารด้วย $3.8/3=1.267$ ได้ 0.5

ความผิดที่อันตรายคือแบบที่รันผ่าน

  • คูณ $L$ แทน $L^{\mathsf T}$: หลายภาษาเก็บแต่ละเส้นทางเป็นแถว $z^{\mathsf T}$ สูตรจึงเป็น $r^{\mathsf T}=z^{\mathsf T}L^{\mathsf T}$ ถ้าเผลอคูณ $L$ จะได้ covariance $L^{\mathsf T}L$ ในโจทย์เปิดให้ SD 26.91% กับ 24% และ correlation 0.669 แทน 20%, 30% และ 0.6 ผิดทั้งสามตัวโดยไม่มี error
  • แตก correlation matrix แล้วลืมคูณ SD: ผลทุกตัวมี SD 1 คือ 100% ต่อช่วง
  • ลำดับไม่ตรงกัน: เรียงสินทรัพย์ใหม่แล้ว $L$ เปลี่ยน แม้ distribution ของผลจำลองเท่าเดิม ห้ามใช้ $L$ ของลำดับหนึ่งกับ mean หรือน้ำหนักของอีกลำดับ (ดูmean vector และ covariance matrix)
  • บวกเลขเข้าแนวทแยงจนผ่าน: เมื่อ library แจ้งว่าไม่ positive definite การบวก $\epsilon I$ เพิ่ม variance ทุกตัวและลด correlation ทุกคู่โดยไม่ตั้งใจ ต้องหาต้นเหตุก่อน เช่นประมาณ correlation แต่ละคู่จากช่วงวันที่ไม่ตรงกัน หรือมีสินทรัพย์มากกว่าจำนวนวันข้อมูล ซึ่งทำให้ sample covariance singular เสมอ ทางแก้ที่มีหลักการคือLedoit–Wolf shrinkage
  • หางบางเกินจริง: ผลจำลองจาก MVN มีหางของ Normal เท่านั้น ในวิกฤตหลายสินทรัพย์ดิ่งพร้อมกันบ่อยกว่าที่ Gaussian บอก และ correlation มักพุ่งขึ้นช่วงตลาดตก ต้อง stress $\Sigma$ แยก หรือใช้ distribution หางหนาแบบที่a zoo of distributions รวบรวมไว้

ใช้ทำอะไรบนโต๊ะจริง

บรรทัด $L=\operatorname{chol}(\Sigma)$ อยู่ใน VaR แบบMonte Carlo ของพอร์ตที่มี option ซึ่งต้องจำลองทุก underlying พร้อมกันแล้วคำนวณ payoff ที่ไม่เป็นเส้นตรงทีละเส้นทาง อยู่ในการตั้งราคา derivative ที่อ้างอิงหลายสินทรัพย์ เช่น basket option ที่ไม่มีสูตรปิด และอยู่ในการทดลองเรื่อง estimation error เช่นสุ่มข้อมูล 60 เดือนจากแบบจำลองที่รู้ค่าจริง ประมาณ mean กับ covariance จากข้อมูลนั้น แล้วดูว่าพอร์ตที่ optimize ด้วยค่าประมาณพลาดไปไกลแค่ไหน การทดลองแบบนี้คือเหตุที่ desk ไม่เชื่อ mean ที่ประมาณจากข้อมูลไม่กี่ปี

// Cholesky, seeded simulation, standard errors and Monte Carlo VaR / ES.
function checkSquare(S) {
  const n = S.length;
  for (const row of S) if (row.length !== n || !row.every(Number.isFinite)) throw new TypeError('Need a finite square matrix');
  for (let i = 0; i < n; i++) for (let j = 0; j < i; j++) if (S[i][j] !== S[j][i]) throw new RangeError('Matrix must be symmetric');
  return n;
}
function pivots(S) { // p_j = variance left after the earlier assets; reported even when negative
  const n = checkSquare(S), U = S.map(() => new Array(n).fill(0)), D = [];
  for (let j = 0; j < n; j++) {
    let p = S[j][j];
    for (let k = 0; k < j; k++) p -= U[j][k] * U[j][k] * D[k];
    D.push(p);
    for (let i = j + 1; i < n; i++) {
      let s = S[i][j];
      for (let k = 0; k < j; k++) s -= U[i][k] * U[j][k] * D[k];
      U[i][j] = p === 0 ? NaN : s / p;
    }
  }
  return D;
}
function cholesky(S) {
  const n = checkSquare(S), L = S.map(() => new Array(n).fill(0));
  for (let j = 0; j < n; j++) {
    let p = S[j][j];
    for (let k = 0; k < j; k++) p -= L[j][k] * L[j][k];
    if (!(p > 1e-12 * S[j][j])) throw new RangeError('Not positive definite: pivot ' + (j + 1) + ' = ' + p);
    L[j][j] = Math.sqrt(p);
    for (let i = j + 1; i < n; i++) {
      let s = S[i][j];
      for (let k = 0; k < j; k++) s -= L[i][k] * L[j][k];
      L[i][j] = s / L[j][j];
    }
  }
  return L;
}
const scenario = (mu, L, z) => mu.map((m, i) => L[i].reduce((s, x, k) => s + x * z[k], m));
function uniforms(seed) { // mulberry32: small seeded generator, values strictly inside (0, 1)
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
}
function normals(seed) { // Box-Muller: two uniforms give two independent N(0,1)
  const u = uniforms(seed); let spare = null;
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const radius = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = radius * Math.sin(angle);
    return radius * Math.cos(angle);
  };
}
function simulate(mu, L, n, seed) {
  const draw = normals(seed), paths = [];
  for (let p = 0; p < n; p++) paths.push(scenario(mu, L, mu.map(() => draw())));
  return paths;
}
function stats(paths) {
  const n = paths.length, d = paths[0].length;
  const mean = [...Array(d).keys()].map(i => paths.reduce((s, r) => s + r[i], 0) / n);
  const cov = (i, j) => paths.reduce((s, r) => s + (r[i] - mean[i]) * (r[j] - mean[j]), 0) / (n - 1);
  const sd = mean.map((_, i) => Math.sqrt(cov(i, i)));
  return {n, mean, sd, corr: cov(0, 1) / (sd[0] * sd[1])};
}
function tailRisk(losses, level) { // VaR = K-th smallest loss with K = level * N; ES = mean of the losses above it
  const sorted = [...losses].sort((a, b) => a - b), K = Math.round(level * sorted.length);
  const tail = sorted.slice(K);
  return {VaR: sorted[K - 1], ES: tail.reduce((s, x) => s + x, 0) / tail.length};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • Cholesky หา $L$ สามเหลี่ยมล่างที่ $LL^{\mathsf T}=\Sigma$ แล้ว $r=\mu+Lz$ ได้ covariance $\Sigma$ เพราะ $\mathbb E[zz^{\mathsf T}]=I$ และเป็น MVN เพราะ MGF ออกมาตรงกัน
  • สองสินทรัพย์: $r_2=\sigma_2(\rho z_1+\sqrt{1-\rho^2}\,z_2)$ น้ำหนักสองก้อนยกกำลังสองแล้วรวมได้ 1 ไม่ใช่รวมกันตรง ๆ ได้ 1
  • pivot $p_j$ คือ variance ส่วนที่สินทรัพย์ก่อนหน้าอธิบายไม่ได้ ตัวเดียวกับ conditional variance ถ้าติดลบแปลว่าตารางขัดกันเอง และการซ่อมเปลี่ยนทุกคู่
  • ทุก $A$ ที่ $AA^{\mathsf T}=\Sigma$ ให้ distribution เดียวกัน รวมถึงแบบ factor เดียวของ Gaussian copula แต่ $L$ ถูกและใช้ได้กับทุกตาราง positive definite
  • ผลสุ่มต้องเทียบกับ SE ไม่ใช่เทียบว่าตรงเป้าเป๊ะ และ VaR จากผลสุ่มคือค่าที่ลำดับ $pN$ ของขาดทุนที่เรียงแล้ว ซึ่งใช้ได้แม้พอร์ตไม่เป็นเส้นตรง

บทถัดไปใช้ shock อิสระแบบเดียวกันนี้ แต่เรียงต่อกันตามเวลาแทนการเรียงตามสินทรัพย์ แล้วสร้างเส้นทางราคาจากผลรวมของมัน ไปต่อที่ สามสมบัติของ Brownian motion
