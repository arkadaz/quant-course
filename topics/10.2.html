10.2 Expected Future Price — Why the Drift Is Exactly μ

ค่าเฉลี่ยของราคาโตที่ μ พอดี แต่เส้นทางกลาง ๆ โตที่ μ − σ²/2 และช่องว่างนี้กว้างขึ้นทุกปีที่ถือ

กองทุนแห่งหนึ่งลงโฆษณาว่า “มูลค่าโตเฉลี่ย 14% ต่อปี” คุณกำลังคิดจะลงเงินก้อนหนึ่งแล้วทิ้งไว้ 20 ปี จึงอยากรู้ว่าตอนถอนออก เงินก้อนนั้นน่าจะเป็นเท่าไร

ของที่รู้ (สมมติทั้งหมด):

  • เงินลงทุนวันนี้ $S_0=\$100$
  • อัตราโตเฉลี่ย $\mu=14\%$ ต่อปี ตัวเลขนี้คือ drift ของ GBM (model ราคาสุ่มที่หน้าก่อนสร้างไว้) หมายถึงอัตราที่ค่าเฉลี่ยของมูลค่าโตแบบทบต้นต่อเนื่อง
  • ความผันผวน $\sigma=32\%$ ต่อปี คือขนาดที่มูลค่าแกว่งขึ้นลงในหนึ่งปี วัดเป็น SD ของ log return ต่อปี (log return คือ $\ln$ ของมูลค่าปลายปีหารด้วยมูลค่าต้นปี)
  • ระยะเวลาที่ถือ $s=20$ ปี

เพื่อนสองคนช่วยคิด คนแรกทบต้นปีละครั้ง ได้ $100\times1.14^{20}\approx\$1{,}374$ คนที่สองทบต้นต่อเนื่อง ได้ $100e^{0.14\times20}=100e^{2.8}\approx\$1{,}644$

ทีนี้ลองนึกว่ามีคน 1,000 คนลงกองนี้พร้อมกัน แต่ละคนเจอโชคต่างกัน ครบ 20 ปีแล้วเรียงทุกคนตามเงินที่ได้ จากน้อยไปมาก คนที่ยืนตรงกลางแถวได้เท่าไร?

ลองตอบก่อนเปิดเฉลย

ไม่ใช่ทั้งสองตัว \$1,644 ของคนที่สองคือค่าเฉลี่ย: เอาเงินของทั้ง 1,000 คนมารวมกันแล้วหารด้วย 1,000 ตัวเลขนี้ถูกต้อง แต่คนตรงกลางแถว (เรียกว่า median) ได้น้อยกว่านั้นมาก เพราะอัตราโตของเขาถูกหักลงอีก $\sigma^2/2$:

\[ \begin{aligned} \nu&=\mu-\tfrac12\sigma^2\\ &=0.14-\tfrac12(0.32)^2=0.0888,\\ \operatorname{median}&=100e^{\nu\times20}\\ &=100e^{1.776}\approx\$590.62. \end{aligned} \]

หน้านี้จะพิสูจน์ว่าทำไมต้องหัก $\sigma^2/2$ และจะคำนวณให้ดูทีละขั้นว่า จาก 1,000 คน มีเพียงราว 237 คน (23.71%) ที่ได้ถึงค่าเฉลี่ย และราว 107 คน (10.73%) ยังขาดทุนหลัง 20 ปี ส่วน \$1,374 ของคนแรกไม่ตรงกับตัวเลขไหนใน model นี้เลย

ภาพรวมก่อนลงสูตร

ประโยค “หุ้นตัวนี้โต 12% ต่อปี” ฟังดูชัด แต่ในราคาที่สุ่มขึ้นลง มีตัวเลขอย่างน้อยสามตัวที่คนเรียกปนกัน ลองนึกว่ามีโลกคู่ขนานจำนวนมาก แต่ละโลกราคาหุ้นวิ่งไปคนละทาง แล้วถามสามคำถาม:

  • ค่าเฉลี่ยของราคาในอนาคต: เอาราคาปลายทางของทุกโลกมารวมกันแล้วหารด้วยจำนวนโลก
  • median ของราคาในอนาคต: เรียงราคาปลายทางจากน้อยไปมาก แล้วดูค่าตรงกลาง ครึ่งหนึ่งของโลกจบต่ำกว่าค่านี้ นี่คือสิ่งที่นักลงทุน “คนกลาง ๆ” ได้
  • ค่าเฉลี่ยของ log return ต่อปี: อัตราที่ $\ln S$ โตเฉลี่ยต่อปี ใน GBM ค่านี้คือ $\nu=\mu-\sigma^2/2$

สามตัวนี้ไม่เท่ากัน และความต่างไม่ใช่เศษทศนิยม ในกองทุนของคำถามเปิด ค่าเฉลี่ยหลัง 20 ปีเป็นเกือบสามเท่าของ median (ขั้นที่ 6 จะคำนวณให้ดู)

ต้นเหตุคือรูปร่างของ distribution ของราคาในอนาคต มันเบ้ขวา คือมีหางยาวไปทางราคาสูง เส้นทางส่วนน้อยที่ขึ้นแรงดึงค่าเฉลี่ยขึ้นไปไกล แต่เส้นทางส่วนใหญ่จบต่ำกว่าค่าเฉลี่ย

หน้านี้ทำสี่อย่างตามลำดับ:

  • พิสูจน์ว่าค่าเฉลี่ยของราคาโตที่อัตรา $\mu$ พอดี เครื่องมือคือ moment generating function (MGF) ของ Normal ซึ่งเป็นสูตรสำเร็จสำหรับค่าเฉลี่ยของ $e$ ยกกำลังตัวแปร Normal
  • หา median และอัตราส่วนระหว่างค่าเฉลี่ยกับ median
  • ดูด้วยตัวอย่างขึ้นแล้วลงว่าเงินของคนกลาง ๆ หายไปไหน
  • ใช้ผลทั้งหมดตอบคำถามที่มีเงินจริงอยู่ข้างหลัง: กองทุน 20 ปี การกู้เงินมาลงเพิ่ม (leverage) และ leveraged ETF (กองทุนที่ให้ผลตอบแทนรายวันเป็นสองเท่าของดัชนี หรือกลับทิศกับดัชนี)

Conditional expectation $\mathbb E_t$

Martingale
process ที่ค่าเฉลี่ยของอนาคต เมื่อรู้ข้อมูลถึงวันนี้ เท่ากับค่าของวันนี้พอดี เหมือนเกมที่ยุติธรรม: เล่นต่อไปนานเท่าไร โดยเฉลี่ยก็ไม่ได้ไม่เสีย
Volatility drag
ส่วนต่าง $\sigma^2/2$ ต่อปี ระหว่างอัตราโตของค่าเฉลี่ย ($\mu$) กับอัตราโตของ median ($\mu-\sigma^2/2$) ความผันผวนไม่ได้ลดค่าเฉลี่ย แต่กินการทบต้นของเส้นทางทั่วไป
Leverage $k$
ถือหุ้นมูลค่า $k$ เท่าของเงินทุนตัวเอง ส่วนที่เกินเงินทุนกู้มา และปรับทุกวันให้คงที่ $k$ เท่า เช่น $k=2$ คือมีเงิน \$100 กู้อีก \$100 แล้วซื้อหุ้น \$200 ทั้ง drift และความผันผวนของพอร์ตถูกขยาย
Leveraged ETF
ETF คือกองทุนที่ซื้อขายในตลาดหุ้นเหมือนหุ้นตัวหนึ่ง leveraged ETF ตั้งเป้าให้ผลตอบแทนรายวันเป็น $\lambda$ เท่าของดัชนี เช่น $\lambda=2$ (ดัชนีขึ้น 1% กองขึ้น 2%) หรือ $\lambda=-1$ (ดัชนีขึ้น 1% กองลง 1%) กองต้องปรับสถานะทุกวัน จึงเจอ volatility drag แม้ดัชนีวนกลับมาที่เดิม

ขั้นที่ 1 — ย้ายคำถามเรื่องราคาไปที่ log ratio

เป้าหมายของหน้านี้คือหาราคาเฉลี่ยในอนาคต แต่ราคาในอนาคตเป็น lognormal (ตัวแปรที่ log ของมันเป็น Normal) ถ้าหาค่าเฉลี่ยตรง ๆ ต้อง integrate กับ density ที่ยุ่ง ทางลัดคือสูตรเดินหน้าของ GBM: ราคาอนาคตเท่ากับราคาวันนี้คูณ $e^X$ และ $X$ เป็น Normal ซึ่งคำนวณง่ายกว่ามาก

ก่อนหาค่าเฉลี่ย เราต้องรู้ให้ชัดว่า $X$ ประกอบด้วยอะไร ส่วนไหนรู้แล้ว ณ เวลา $t$ และส่วนไหนยังสุ่มอยู่ ในสูตรข้างล่าง $\nu=\mu-\sigma^2/2$ คือ log drift และ $W_{t+s}-W_t$ คือการขยับของ Brownian motion ในช่วง $s$ ปีข้างหน้า

\[ \begin{aligned} S_{t+s}&=S_t\,e^{X},\\ X&:=\nu s+\sigma\big(W_{t+s}-W_t\big),\\ W_{t+s}-W_t&\sim\mathcal N(0,s),\\ m_X&=\nu s,\qquad v_X=\sigma^2s,\\ X&\sim\mathcal N\big(\nu s,\ \sigma^2s\big). \end{aligned} \]

$X$ มีสองชิ้น ชิ้นแรก $\nu s$ เป็นตัวเลขคงที่ ชิ้นที่สองคือการขยับของ $W$ ที่ยังไม่เกิด การขยับนี้เป็น Normal ค่าเฉลี่ย 0 และ variance $s$ พอคูณด้วย $\sigma$ variance ก็คูณด้วย $\sigma^2$ จึงได้ $\sigma^2s$ ส่วน $S_t$ เป็นตัวเลขที่เห็นบนจอแล้ว ไม่สุ่ม

ประเด็นสำคัญคือ การขยับของ $W$ ที่ยังไม่เกิดเป็นอิสระจากทุกอย่างที่เห็นจนถึงเวลา $t$ (สมบัติแรกใน สามสมบัติของ Brownian motion ส่วนความหมายของ “รู้ถึงเวลา $t$” อยู่ใน filtration ในเวลาต่อเนื่อง) ดังนั้นต่อให้รู้เส้นทางที่ผ่านมาทั้งหมด distribution ของ $X$ ก็ไม่เปลี่ยน ขั้นถัดไปต้องใช้ข้อนี้ เพื่อเปลี่ยนค่าเฉลี่ยแบบมีเงื่อนไข $\mathbb E_t[e^X]$ ให้เป็นค่าเฉลี่ยธรรมดา $\mathbb E[e^X]$

ขั้นที่ 2 — ค่าเฉลี่ยของราคาจาก MGF

ตอนนี้พร้อมหาราคาเฉลี่ยแล้ว สิ่งที่ต้องการคือ $\mathbb E_t[S_{t+s}]=\mathbb E_t[S_te^X]$ ราคาวันนี้ $S_t$ รู้แล้ว จึงเป็นค่าคงที่ ดึงออกนอกค่าเฉลี่ยได้ ส่วน $e^X$ ไม่ขึ้นกับอดีต (จากขั้นที่ 1) จึงเหลือค่าเฉลี่ยธรรมดา $\mathbb E[e^X]$

ค่านี้ตรงกับนิยามของ MGF $M_X(u)=\mathbb E[e^{uX}]$ ที่ $u=1$ พอดี สูตร MGF ของ Normal พิสูจน์ไว้แล้ว (ด้วยการจัดกำลังสองสมบูรณ์) ในหน้า moment generating function จึงหยิบมาใช้ได้เลย

\[ \begin{aligned} \mathbb E_t[S_{t+s}]&=\mathbb E_t\big[S_te^{X}\big]=S_t\,\mathbb E\big[e^{X}\big]\\ &=S_t\,M_X(1),\\ M_X(u)&=e^{m_Xu+\frac12v_Xu^2},\\ M_X(1)&=e^{\nu s+\frac12\sigma^2s}\\ &=e^{(\mu-\frac12\sigma^2)s+\frac12\sigma^2s}\\ &=e^{\mu s},\\ \mathbb E_t[S_{t+s}]&=S_t\,e^{\mu s},\\ \mathbb E_t\big[e^{-\mu(t+s)}S_{t+s}\big]&=e^{-\mu t}S_t. \end{aligned} \]

จุดที่ต้องหยุดดูคือ $\mathbb E[e^X]$ ไม่เท่ากับ $e^{\mathbb E[X]}=e^{\nu s}$ มันได้ตัวคูณเกินมาอีก $e^{\sigma^2s/2}$ ตัวคูณนี้มาจากความโค้งของ exponential ลองดูตัวเลข: ถ้า $X$ ขึ้น 1 ราคาคูณ $e^{1}\approx2.72$ คือได้เพิ่ม 1.72 เท่าของเดิม แต่ถ้า $X$ ลง 1 ราคาคูณ $e^{-1}\approx0.37$ คือเสียไปแค่ 0.63 เท่าของเดิม ขาขึ้นได้มากกว่าที่ขาลงขนาดเท่ากันเสีย ค่าเฉลี่ยจึงถูกดันขึ้น

ทำไมนิยามของ GBM ต้องใส่ $-\sigma^2/2$ ไว้ใน $\nu$? เพราะมันหักกับส่วนเกิน $+\sigma^2s/2$ ได้พอดี เหลือ $e^{\mu s}$ ค่าเฉลี่ยของราคาจึงโตที่อัตรา $\mu$ ทุกระยะเวลา ไม่ใช่แค่ในช่วงสั้นที่ประมาณด้วย Taylor นี่คือความหมายของชื่อหัวข้อ: $\mu$ คือ expected growth rate หรืออัตราโตของราคาเฉลี่ย

ถ้าเราหักการเติบโตเฉลี่ยออกจากราคา โดยคูณ $e^{-\mu(t+s)}$ เข้าทั้งสองข้างของ $\mathbb E_t[S_{t+s}]=S_te^{\mu s}$ ปริมาณที่เหลือ $e^{-\mu t}S_t$ มีค่าเฉลี่ยของอนาคตเท่ากับค่าของวันนี้พอดี มันจึงเป็น martingale แปลว่าในราคาที่โตเสมอ มีเกมที่ยุติธรรมซ่อนอยู่

ขั้นที่ 3 — median และอัตราส่วนค่าเฉลี่ยต่อ median

ค่าเฉลี่ยตอบคำถามแบบหนึ่ง: ถ้ามีนักลงทุนจำนวนมาก เอาเงินทุกคนมารวมกันแล้วหารด้วยจำนวนคน ได้เท่าไร แต่คนหนึ่งคนอยากรู้ว่าตัวเองน่าจะได้เท่าไร คำถามนี้ต้องตอบด้วย median

median หาง่ายกว่าค่าเฉลี่ย เพราะมีสองข้อช่วย ข้อแรก $X$ เป็น Normal จึงสมมาตรรอบค่าเฉลี่ย $\nu s$ ครึ่งหนึ่งต่ำกว่า ครึ่งหนึ่งสูงกว่า ข้อสอง ราคา $S_te^X$ เพิ่มขึ้นตาม $X$ เสมอ การแปลงกลับเป็นราคาจึงไม่สลับลำดับ เส้นทางที่ $X$ อยู่ตรงกลาง ราคาก็อยู่ตรงกลางด้วย

\[ \begin{aligned} P(X\le\nu s)&=\tfrac12,\\ P\big(S_{t+s}\le S_te^{\nu s}\big)&=P(X\le\nu s)=\tfrac12,\\ \operatorname{median}_t(S_{t+s})&=S_t\,e^{(\mu-\frac12\sigma^2)s},\\ \frac{\mathbb E_t[S_{t+s}]}{\operatorname{median}_t(S_{t+s})}&=e^{\frac12\sigma^2s}. \end{aligned} \]

median ได้จากการแทน $X$ ด้วยค่าตรงกลางของมัน $\nu s$ ส่วนอัตราส่วนค่าเฉลี่ยต่อ median ได้จากการหาร $S_te^{\mu s}$ ด้วย $S_te^{(\mu-\sigma^2/2)s}$ $\mu$ หักกันหมด เหลือแค่ $\sigma^2s$ แปลว่ายิ่งผันผวนและยิ่งถือนาน ค่าเฉลี่ยยิ่งห่างจาก median และเพราะ $s$ อยู่ในเลขชี้กำลัง ช่องว่างจึงโตแบบทวีคูณ ไม่ใช่เส้นตรง ในรูปกรวยด้านบน เส้นเขียวกับเส้นส้มแยกกันมากขึ้นทุกปีด้วยเหตุนี้

ทำไม median ไม่ถูกหางขวาลาก? เส้นทางที่ขึ้นไปสิบเท่าดึงค่าเฉลี่ยตามขนาดของมัน แต่ใน median มันนับเป็นแค่ “หนึ่งเส้นที่อยู่ข้างบน” เท่ากับเส้นที่ขึ้นเพียงนิดเดียว

ขั้นที่ 4 — ตรวจด้วยหุ้นสมมติหนึ่งตัวในห้าปี

สูตรพร้อมแล้ว ลองใช้กับตัวเลขก่อนไปถึงกองทุนในคำถามเปิด ลูกค้าคนหนึ่งถือหุ้นสมมติตัวหนึ่ง ที่ปรึกษาต้องทำสไลด์บอกว่าห้าปีข้างหน้าหุ้นนี้น่าจะมีราคาเท่าไร

โจทย์ให้อะไรมาบ้าง:

  • ราคาวันนี้ $S_0=\$100$
  • drift $\mu=12\%$ ต่อปี และความผันผวน $\sigma=30\%$ ต่อปี
  • ถือ $s=5$ ปี และสมมติว่าหุ้นไม่จ่ายเงินปันผล

นอกจากค่าเฉลี่ยกับ median ขอ SD ของราคาด้วย เพื่อดูว่าราคากระจายรอบค่าเฉลี่ยกว้างแค่ไหน SD หาได้จาก MGF ตัวเดิมที่จุด $u=2$ เพราะ $S_5^2=S_0^2e^{2X}$ ดังนั้น $\mathbb E[S_5^2]=S_0^2M_X(2)$ แล้วใช้ variance $=\mathbb E[S^2]-(\mathbb E[S])^2$

\[ \begin{aligned} \nu&=0.12-\tfrac12(0.30)^2\\ &=0.12-0.045=0.075,\\ m_X&=\nu s=0.075\times5=0.375,\\ v_X&=\sigma^2s=0.09\times5=0.45,\\ \mathbb E[S_5]&=100e^{\mu s}=100e^{0.60}\\ &\approx182.21,\\ \operatorname{median}(S_5)&=100e^{m_X}=100e^{0.375}\\ &\approx145.50,\\ \frac{182.21}{145.50}&=e^{v_X/2}=e^{0.225}\approx1.2523,\\ \mathbb E[S_5^2]&=100^2M_X(2)=100^2e^{2m_X+2v_X},\\ \big(\mathbb E[S_5]\big)^2&=100^2e^{2m_X+v_X},\\ \operatorname{Var}(S_5)&=100^2e^{2m_X+v_X}\big(e^{v_X}-1\big)\\ &=182.21^2\big(e^{0.45}-1\big),\\ \operatorname{SD}(S_5)&=182.21\sqrt{e^{0.45}-1}\\ &\approx137.36. \end{aligned} \]

สองแถวที่ยากคือ $M_X(2)$ กับ $(\mathbb E[S_5])^2$ แถวแรกแทน $u=2$ ลงในสูตร $e^{m_Xu+\frac12v_Xu^2}$ ได้ $e^{2m_X+2v_X}$ แถวที่สองยกกำลังสองของ $100e^{m_X+v_X/2}$ ได้ $100^2e^{2m_X+v_X}$ ลบกันแล้วดึง $100^2e^{2m_X+v_X}$ ออกเป็นตัวร่วม ตัวร่วมนี้ก็คือ $182.21^2$ นั่นเอง

คำตอบ: หลังห้าปี ราคาเฉลี่ยคือ \$182.21 median คือ \$145.50 และ SD ของราคาคือ \$137.36 SD เกือบเท่าค่าเฉลี่ย แปลว่าราคาห้าปีกระจายกว้างมาก

สมมติลูกค้าถือ 10,000 หุ้น (มูลค่าวันนี้ $10{,}000\times\$100=\$1$ ล้าน) ใช้ค่าก่อนปัดเศษ $e^{0.60}=1.822119$ และ $e^{0.375}=1.454991$:

\[ \begin{aligned} \mathbb E[V_5]&=10{,}000\times182.2119\\ &\approx\$1{,}822{,}119,\\ \operatorname{median}(V_5)&=10{,}000\times145.4991\\ &\approx\$1{,}454{,}991,\\ \mathbb E[V_5]-\operatorname{median}(V_5)&\approx\$367{,}127,\\ \frac{367{,}127}{1{,}454{,}991}&\approx25.23\%. \end{aligned} \]

ในที่นี้ $V_5$ คือมูลค่าพอร์ตของลูกค้าเมื่อครบห้าปี สไลด์ที่เรียก \$1.45 ล้านว่า “มูลค่าคาดหวัง” (expected value แปลว่าค่าเฉลี่ย) ใช้คำผิดความหมาย ส่วนสไลด์ที่บอกลูกค้าว่า \$1.82 ล้านคือผลที่ตัวเขาน่าจะได้ ก็ชวนเข้าใจผิด เพราะลูกค้าคนเดียวได้เส้นทางเดียว และครึ่งหนึ่งของเส้นทางจบต่ำกว่า \$1.45 ล้าน

ตรวจเองใน 10 วินาที: ใช้ Taylor สี่พจน์แรกกับ $e^{0.225}$:

\[ \begin{aligned} e^{0.225}&\approx1+0.225+\tfrac{0.225^2}{2}+\tfrac{0.225^3}{6}\\ &=1+0.225+0.0253+0.0019\\ &=1.2522,\\ 145.50\times1.2523&\approx182.21. \end{aligned} \]

ได้ใกล้ 1.2523 และคูณกลับได้ค่าเฉลี่ยพอดี สังเกตว่าอัตราส่วนนี้ไม่ต้องรู้ $\mu$ เลย ใช้แค่ $\sigma^2s/2=0.225$ ส่วน SD ตรวจได้อีกทางด้วยสูตร variance ของ lognormal $e^{2m+v}(e^v-1)$ โดย $m=\ln100+0.375$ และ $v=0.45$ ซึ่งเป็นการคำนวณเดียวกับข้างบน

ขั้นที่ 5 — ช่องว่างมาจากไหน: ขึ้นแล้วลงเท่ากัน เงินไม่กลับที่เดิม

สูตรบอกว่าค่าเฉลี่ยห่างจาก median เป็นตัวคูณ $e^{\sigma^2s/2}$ แต่ยังไม่บอกว่าเงินของคนกลาง ๆ หายไปไหน ลองดูตัวอย่างที่เล็กที่สุด: เงิน \$100 ผ่านสองงวด งวดแรกขึ้น $x$ งวดที่สองลง $x$ (เปอร์เซ็นต์เท่ากัน) ผลตอบแทนเฉลี่ยของสองงวดเป็นศูนย์ ถ้าเงินไม่หาย มันต้องกลับมาที่ \$100

\[ \begin{aligned} (1+x)(1-x)&=1-x^2,\\ x=10\%:&\quad100\to110\to99,\\ x=50\%:&\quad100\to150\to75,\\ \tfrac12\ln(1-x^2)&\approx-\tfrac12x^2,\\ \sigma=30\%:&\quad\tfrac12\sigma^2=\tfrac12(0.09)=4.5\%,\\ \sigma=32\%:&\quad\tfrac12\sigma^2=\tfrac12(0.1024)=5.12\%. \end{aligned} \]

เงินไม่กลับมาที่ \$100 เพราะขาลงคิดบนฐานที่ใหญ่กว่าขาขึ้น ขึ้น 50% จาก \$100 ได้มา \$50 แต่ลง 50% จาก \$150 เสียไป \$75 สองงวดจึงเหลือ $1-x^2$ ของเงินต้น เมื่อดูบน log จะหาย $\ln(1-x^2)\approx-x^2$ ต่อสองงวด (ใช้ $\ln(1-y)\approx-y$ เมื่อ $y$ เล็ก) หรือราว $x^2/2$ ต่องวด ถ้า $x$ คือขนาดการขยับต่องวด $x^2$ ก็คือ variance ต่องวด เงินที่หายต่องวดจึงเท่ากับครึ่งหนึ่งของ variance ต่องวด พอรวมทุกงวดในหนึ่งปี variance รวมเป็น $\sigma^2$ เงินที่หายต่อปีจึงเป็น $\sigma^2/2$ สองแถวล่างคือขนาดของมันสำหรับหุ้นตัวอย่างและกองทุนในคำถามเปิด

สิ่งนี้เรียกว่า volatility drag มันไม่ได้ลดค่าเฉลี่ยของราคา (MGF บอกแล้วว่าค่าเฉลี่ยโตที่ $\mu$ เสมอ) แต่ลดอัตราทบต้นของเส้นทางทั่วไป ค่าเฉลี่ยรอดได้เพราะเส้นทางส่วนน้อยที่ขึ้นติดกันหลายงวดชดเชยให้ ดูต้นไม้ด้านล่าง และเพราะ drag คือ $\sigma^2/2$ มันจึงโตตามกำลังสอง: ความผันผวนสองเท่า drag สี่เท่า เช่น $\sigma=30\%$ ได้ 4.5% แต่ $\sigma=60\%$ ได้ $\tfrac12(0.36)=18\%$

ขั้นที่ 6 — กองทุนในคำถามเปิด: 20 ปี ค่าเฉลี่ยกับ median ห่างกันกี่เท่า

กลับมาที่กองทุนในคำถามเปิด ตอนนี้มีเครื่องมือครบแล้วที่จะตอบว่าคนตรงกลางแถวได้เท่าไร และทำไมเพื่อนสองคนคิดได้ไม่ตรงกัน

โจทย์ให้อะไรมาบ้าง:

  • เงินลงทุน $S_0=\$100$
  • drift $\mu=0.14$ และความผันผวน $\sigma=0.32$ ต่อปี
  • ถือ $s=20$ ปี และไม่คิดค่าธรรมเนียม
\[ \begin{aligned} \sigma^2&=0.32^2=0.1024,\\ \tfrac12\sigma^2&=0.0512,\\ \nu&=0.14-0.0512=0.0888,\\ \mathbb E[S_{20}]&=100e^{0.14\times20}=100e^{2.8}\\ &\approx1{,}644.46,\\ \operatorname{median}(S_{20})&=100e^{0.0888\times20}=100e^{1.776}\\ &\approx590.62,\\ \frac{1{,}644.46}{590.62}&=e^{0.0512\times20}=e^{1.024}\\ &\approx2.784,\\ 100(1.14)^{20}&\approx1{,}374.35. \end{aligned} \]

คำตอบ: ค่าเฉลี่ยคือ \$1,644.46 แต่คนตรงกลางแถวได้ \$590.62 ค่าเฉลี่ยเป็น 2.78 เท่าของ median อัตราส่วนนี้คือ $e^{0.0512s}$ จึงโตตามเวลาที่ถือ:

ถือ $s$ ปี1102040
$0.0512s$0.05120.5121.0242.048
ค่าเฉลี่ยหารด้วย median $e^{0.0512s}$1.0531.6692.7847.752

แล้ว \$1,374.35 ของเพื่อนคนแรกมาจากไหน? เพื่อนคนแรกเอา 14% ไปทบต้นปีละครั้ง เหมือนกับว่าทุกปีได้ 14% เท่ากันไม่แกว่งเลย แต่ $\mu=14\%$ เป็นอัตราทบต้นต่อเนื่องของค่าเฉลี่ย ไม่ใช่อัตราทบต้นรายปี ตัวเลขนี้จึงไม่ใช่ทั้งค่าเฉลี่ยและ median ถ้าอยากได้อัตราทบต้นรายปี (simple return ต่อปี) ต้องแปลงก่อน:

\[ \begin{aligned} \text{mean}:&\quad e^{0.14}-1\approx15.03\%,\\ \text{median}:&\quad e^{0.0888}-1\approx9.29\%. \end{aligned} \]

ตรวจเองใน 10 วินาที: $\tfrac12(0.32)^2\times20=0.0512\times20=1.024$ และ $e^{1.024}=e\times e^{0.024}\approx2.718\times1.024\approx2.78$

ขั้นที่ 7 — กี่คนได้ถึงค่าเฉลี่ย และกี่คนยังขาดทุน

ค่าเฉลี่ยกับ median บอกแค่สองจุด แต่สิ่งที่นักลงทุนอยากรู้จริงคือโอกาส: “โอกาสที่ฉันจะได้ถึงค่าเฉลี่ยมีเท่าไร” และ “โอกาสที่ฉันจะขาดทุนมีเท่าไร” ถามบนราคาตรง ๆ ยาก เพราะราคาเป็น lognormal แต่ถามบนแกน log ง่าย เพราะ log ratio $X=\ln(S_{20}/100)$ เป็น Normal แล้วอ่านโอกาสจาก $\Phi$ ของ Normal distribution ($\Phi(z)$ คือโอกาสที่ตัวแปร Normal มาตรฐานมีค่าต่ำกว่า $z$)

ขั้นแรกแปลงเกณฑ์ราคาให้เป็นเกณฑ์บน $X$:

  • ได้ถึงค่าเฉลี่ย: $S_{20}\ge100e^{2.8}$ ก็คือ $X\ge2.8$
  • ขาดทุน: $S_{20}\lt100$ ก็คือ $X\lt\ln1=0$

จากนั้นหาค่าเฉลี่ยและ variance ของ $X$ แล้วแปลงเกณฑ์เป็นจำนวน SD ที่ห่างจากค่าเฉลี่ย (ลบค่าเฉลี่ยแล้วหารด้วย SD) เพื่ออ่าน $\Phi$:

\[ \begin{aligned} m_X&=\nu s=0.0888\times20=1.776,\\ v_X&=\sigma^2s=0.1024\times20=2.048,\\ \sqrt{v_X}&=\sqrt{2.048}\approx1.43108,\\ P(X\ge2.8)&=1-\Phi\!\left(\frac{2.8-1.776}{1.43108}\right)\\ &=1-\Phi(0.71554)\approx23.71\%,\\ P(X\lt0)&=\Phi\!\left(\frac{0-1.776}{1.43108}\right)\\ &=\Phi(-1.24102)\approx10.73\%. \end{aligned} \]

แปลเป็นคน: ถ้าคน 1,000 คนลงกองนี้พร้อมกัน ราว $1{,}000\times0.2371\approx237$ คนได้ถึงหรือเกินค่าเฉลี่ย และราว $1{,}000\times0.1073\approx107$ คนยังขาดทุนหลัง 20 ปี ทั้งที่ drift ของกองเป็นบวก 14% ต่อปี

ทำไมคนที่ได้ถึงค่าเฉลี่ยจึงน้อย? ดูระยะจาก median ถึงค่าเฉลี่ยบนแกน $X$ นับเป็นจำนวน SD: $\dfrac{(\mu-\nu)s}{\sigma\sqrt s}=\dfrac{\sigma^2s/2}{\sigma\sqrt s}=\dfrac{\sigma\sqrt s}{2}=\dfrac{0.32\sqrt{20}}{2}\approx0.716$ ซึ่งตรงกับ 0.71554 ข้างบน ระยะนี้โตตาม $\sqrt s$ ยิ่งถือนาน ค่าเฉลี่ยยิ่งไกลออกไปทางหางขวา สัดส่วนคนที่ไปถึงยิ่งหดเข้าหาศูนย์ ค่าเฉลี่ยจึงถูกค้ำไว้ด้วยคนส่วนน้อยที่โชคดีมาก

ขั้นที่ 8 — กู้มาลงเพิ่มกี่เท่า median จึงโตเร็วที่สุด

ความผันผวนกิน median ไปปีละ $\sigma^2/2$ คำถามที่ตามมาคือ ถ้ากู้เงินมาลงเพิ่ม median จะโตเร็วขึ้นไหม? ตั้งพอร์ตแบบนี้:

  • มีเงินทุนตัวเอง แล้วถือหุ้นมูลค่า $k$ เท่าของเงินทุน (leverage $k$) ส่วนที่เกินคือ $k-1$ เท่าของเงินทุน กู้มาที่ดอกเบี้ย $r$ ต่อปี (ถ้า $k\lt1$ ส่วนที่เหลือฝากได้ดอกเบี้ย $r$)
  • ปรับพอร์ตทุกวันให้ถือหุ้น $k$ เท่าเสมอ
  • ใช้หุ้นแบบเดียวกับกองทุนในคำถามเปิด: $\mu=0.14$ และ $\sigma=0.32$ ต่อปี

ในช่วงสั้น $\Delta t$ ให้ $R_p$ คือผลตอบแทนของพอร์ตคิดเป็นสัดส่วนของเงินทุน ส่วนหุ้นได้ $k\mu\Delta t$ โดยเฉลี่ย และต้องจ่ายดอกเบี้ย $(k-1)r\Delta t$ ความผันผวนก็ถูกขยาย $k$ เท่า พอร์ตนี้จึงเป็น GBM ตัวใหม่ที่มี drift $r+k(\mu-r)$ และความผันผวน $k\sigma$ เหตุผลเดียวกับที่ GBM หัก $\sigma^2/2$ ทำให้ median ของพอร์ตโตที่อัตรา $g(k)$ ซึ่งเท่ากับ drift ลบ $\tfrac12(k\sigma)^2$ เริ่มจากกรณีกู้ฟรี $r=0$ เพื่อดูโครงก่อน

\[ \begin{aligned} \mathbb E[R_p]&=k\mu\Delta t-(k-1)r\Delta t\\ &=\big(r+k(\mu-r)\big)\Delta t,\\ \operatorname{SD}(R_p)&=k\sigma\sqrt{\Delta t},\\ g(k)&=r+k(\mu-r)-\tfrac12k^2\sigma^2,\\ r=0:\quad g(k)&=0.14k-0.0512k^2,\\ g'(k)&=0.14-0.1024k=0,\\ k^*&=0.14/0.1024\approx1.367,\\ g(k^*)&=\frac{\mu^2}{2\sigma^2}=\frac{0.14^2}{2(0.1024)}\approx9.57\%,\\ g(k)=0:\quad k&=\frac{2\mu}{\sigma^2}=\frac{2(0.14)}{0.1024}\approx2.734,\\ g(1)&=0.14-0.0512=8.88\%,\\ g(2)&=0.28-0.2048=7.52\%,\\ g(3)&=0.42-0.4608=-4.08\%. \end{aligned} \]

ทำไมกราฟมียอด? ผลตอบแทนเฉลี่ยเพิ่มเป็นเส้นตรงตาม $k$ แต่ drag เพิ่มตาม $k^2$ เพราะความผันผวนของพอร์ต $k\sigma$ ถูกยกกำลังสอง ผลรวมจึงเป็นพาราโบลาคว่ำ ยอดหาได้โดยตั้งอนุพันธ์เป็นศูนย์ พอแทน $k^*=\mu/\sigma^2$ กลับเข้า $g$ จะได้ $\mu^2/\sigma^2-\mu^2/(2\sigma^2)=\mu^2/(2\sigma^2)$

ตัวเลขบอกว่าการกู้ช่วยได้นิดเดียว ถือ 1.37 เท่าให้ median โต 9.57% ต่อปี ดีกว่า 8.88% ของการไม่กู้ ($k=1$) เพียง 0.69 จุด กู้สองเท่าได้ 7.52% แย่กว่าไม่กู้ และถ้าเกิน 2.73 เท่า median หดทุกปี ทั้งที่ค่าเฉลี่ยของความมั่งคั่งยังโต $0.14k$ ต่อปี

ถ้ากู้มีต้นทุน ตั้ง $g'(k)=\mu-r-k\sigma^2=0$ ยอดจะย้ายไปที่ $k^*=(\mu-r)/\sigma^2$ ที่ดอกเบี้ย $r=4\%$ ได้ $k^*=0.10/0.1024\approx0.98$ น้อยกว่า 1 แปลว่าไม่ควรกู้เลย สูตรนี้คือ Kelly criterion แบบเวลาต่อเนื่อง (สูตรเลือกขนาดการลงทุนให้ความมั่งคั่งของเส้นทางทั่วไปโตเร็วที่สุด)

ขั้นที่ 9 — leveraged ETF: ดัชนีกลับที่เดิม แต่กองทุนไม่กลับ

volatility drag ไม่ได้อยู่แค่ในทฤษฎี มันเห็นได้ชัดใน leveraged ETF ซึ่งปรับสถานะทุกวันเหมือนพอร์ตในขั้นที่ 8 คนที่ซื้อกองแบบนี้มักคิดว่า “ถ้าดัชนีกลับมาที่เดิม กองก็ต้องกลับมาที่เดิม” ลองดูด้วยตัวเลขสองวัน ดัชนีในที่นี้คือตัวเลขที่สรุปราคาของหุ้นกลุ่มหนึ่ง เช่น S&P 500

โจทย์ให้อะไรมาบ้าง (สมมติ):

  • ดัชนีวันที่ 0 อยู่ที่ 100 วันที่ 1 ขึ้นเป็น 105 วันที่ 2 กลับมาที่ 100
  • กอง $\lambda=2$ ให้ผลตอบแทนรายวันสองเท่าของดัชนี กอง $\lambda=-1$ ให้ผลตอบแทนรายวันกลับทิศ
  • ทั้งสองกองเริ่มที่ $V_0=100$ ไม่คิดค่าธรรมเนียมและดอกเบี้ย

ให้ $r_i$ คือผลตอบแทนรายวันของดัชนีในวันที่ $i$ แต่ละวันกองคูณมูลค่าด้วย $1+\lambda r_i$ จึงคำนวณมูลค่าวันที่ 2 ได้ตรง ๆ:

\[ \begin{aligned} r_1&=105/100-1=5\%,\\ r_2&=100/105-1\approx-4.7619\%,\\ \lambda=2:\quad V_2&=100(1+2r_1)(1+2r_2)\\ &=100(1.10)(0.904762)\approx99.524,\\ \lambda=-1:\quad V_2&=100(1-r_1)(1-r_2)\\ &=100(0.95)(1.047619)\approx99.524. \end{aligned} \]

ทั้งสองกองเสียเงินเท่ากัน เพื่อดูว่าทำไม ให้ $y_i=\ln(1+r_i)$ คือ log return รายวันของดัชนี แล้วใช้ Taylor สองชั้น: $r_i=e^{y_i}-1\approx y_i+\tfrac12y_i^2$ และ $\ln(1+z)\approx z-\tfrac12z^2$ โดยแทน $z=\lambda r_i$ เก็บพจน์ถึง $y_i^2$ แล้วรวมทุกวัน เพราะ log ของการเปลี่ยนแปลงทั้งหมดคือผลรวมของ log รายวัน:

\[ \begin{aligned} \ln(1+\lambda r_i)&\approx\lambda\big(y_i+\tfrac12y_i^2\big)-\tfrac12\lambda^2y_i^2\\ &=\lambda y_i-\tfrac12(\lambda^2-\lambda)y_i^2,\\ y_1&=\ln1.05,\qquad y_2=-\ln1.05,\\ \textstyle\sum_i y_i&=0,\\ \textstyle\sum_i y_i^2&=2(\ln1.05)^2\approx0.0047610,\\ 2^2-2&=(-1)^2-(-1)=2,\\ \ln(V_2/V_0)&=\textstyle\sum_i\ln(1+\lambda r_i)\\ &\approx\lambda\textstyle\sum_i y_i-\tfrac12(\lambda^2-\lambda)\textstyle\sum_i y_i^2\\ &=0-\tfrac12(2)(0.0047610)\\ &=-0.476\%,\\ \ln(0.99524)&\approx-0.477\%. \end{aligned} \]

คำตอบ: ดัชนีกลับมาที่ 100 แต่กองทุนทั้งสองเหลือ 99.52 ขาดทุน 0.48% เท่ากัน สูตรประมาณให้ −0.476% ใกล้ค่าจริง −0.477% เหตุผลคือพจน์แรก $\lambda\sum y_i$ เป็นศูนย์ เพราะดัชนีกลับที่เดิม เหลือแต่พจน์ drag $-\tfrac12(\lambda^2-\lambda)\sum y_i^2$ ซึ่งติดลบเสมอเมื่อ $\lambda\gt1$ หรือ $\lambda\lt0$ และ $\lambda^2-\lambda$ เท่ากับ 2 ทั้งที่ $\lambda=2$ และ $\lambda=-1$ ทั้งกองขาขึ้นและกองขาลงจึงเสียเท่ากันเมื่อตลาดแกว่งไปมา

ตรวจเองใน 10 วินาที: ถ้าดัชนีมีความผันผวน $\sigma=20\%$ ต่อปี ผลรวมของ $y_i^2$ ตลอดหนึ่งปีจะราว $\sigma^2=0.04$ (variance ต่อปีคือผลรวมของ variance รายวัน) drag ของกองทั้งสองจึงราว $\tfrac12(2)(0.04)=4\%$ ต่อปี ในรูปต่อเนื่อง กอง $\lambda$ เท่าก็คือพอร์ต leverage $k=\lambda$ ที่กู้ฟรี median จึงโตที่ $\lambda\mu-\tfrac12\lambda^2\sigma^2$ ถ้าดัชนีมี $\mu=10\%$:

\[ \begin{aligned} \lambda=1:&\quad0.10-\tfrac12(0.04)=8\%,\\ \lambda=2:&\quad0.20-\tfrac12(4)(0.04)=12\%,\\ \lambda=3:&\quad0.30-\tfrac12(9)(0.04)=12\%. \end{aligned} \]

กอง 2 เท่าได้ 12% ไม่ใช่ $2\times8\%=16\%$ และกอง 3 เท่าก็ได้แค่ 12% เท่ากัน

ความผิดที่ทำให้ตัวเลขดูน่าเชื่อแต่ผิดความหมาย

เอา median มาเรียกว่า “ราคาคาดหวัง”: คนที่จำได้ว่า GBM “ต้องหัก $\sigma^2/2$” มักหักตอนหาค่าเฉลี่ยด้วย ซึ่งไม่ควรหัก ในหุ้นตัวอย่างห้าปี:

\[ \begin{aligned} \text{wrong}:&\quad S_0e^{\nu s}=100e^{0.375}\approx\$145.50,\\ \text{right}:&\quad S_0e^{\mu s}=100e^{0.60}\approx\$182.21,\\ \text{gap}:&\quad1-145.50/182.21\approx20.1\%. \end{aligned} \]

ความผิดนี้เกิดบ่อยเมื่อคนหนึ่งส่งพารามิเตอร์มาเป็น $\mu$ แล้วอีกคนแปลงเป็น $\nu$ ซ้ำอีกรอบ ตัวเลข \$145.50 ไม่ผิด แต่มันคือ median ไม่ใช่ค่าเฉลี่ย

ทบต้น $\mu$ แบบรายปี: $\mu$ เป็นอัตราทบต้นต่อเนื่องของค่าเฉลี่ย เอาไปทบต้นปีละครั้งตรง ๆ จะได้ตัวเลขที่ไม่ใช่ทั้งค่าเฉลี่ยและ median ในกองทุน 20 ปี:

\[ \begin{aligned} \text{wrong}:&\quad100(1.14)^{20}\approx\$1{,}374.35,\\ \text{right}:&\quad100e^{0.14\times20}\approx\$1{,}644.46,\\ \text{same}:&\quad100\big(e^{0.14}\big)^{20}=100(1.1503)^{20}. \end{aligned} \]

ถ้าจะทบต้นรายปีให้ได้ค่าเฉลี่ย ต้องใช้อัตรา $e^{0.14}-1\approx15.03\%$ ต่อปี ไม่ใช่ 14%

ใช้ $e^{\sigma^2s/2}$ กับข้อมูลที่หางหนา: “หางหนา” หมายถึงวันที่ราคาขยับแรงมาก ๆ เกิดบ่อยกว่าที่ Normal ทาย ตัวคูณ $e^{\sigma^2s/2}$ มาจาก MGF ของ Normal เท่านั้น ถ้า log return มีหางหนากว่า Normal ส่วนเกินจะต่างออกไป สิ่งเดียวที่รับประกันได้กับทุก distribution คือ $\mathbb E[e^X]\ge e^{\mathbb E[X]}$ (Jensen's inequality ซึ่งจริงเพราะ $e^x$ โค้งขึ้น) แปลว่าค่าเฉลี่ยยังอยู่เหนือ median แต่ห่างเท่าไรต้องคำนวณจาก distribution จริง

รายงานค่าเฉลี่ยจากการจำลองโดยไม่บอก SE: ถ้าไม่รู้ SE ก็บอกไม่ได้ว่าค่าที่ได้ห่างสูตรเพราะโชคหรือเพราะโค้ดผิด 5,000 เส้นทางในหุ้นตัวอย่างมี SE ราว \$1.94 สมมติโค้ดใส่ $\mu$ แทน $\nu$ ในเลขชี้กำลัง คือจำลอง $S_0e^{\mu s+\sigma\sqrt s\,Z}$ เมื่อ $Z$ เป็น Normal มาตรฐาน ค่าเฉลี่ยจะได้ส่วนเกิน $\sigma^2s/2$ ซ้อนเข้าไป:

\[ \begin{aligned} \text{wrong}:&\quad100e^{\mu s+\sigma^2s/2}=100e^{0.60+0.225}\\ &\quad=100e^{0.825}\approx\$228.2,\\ \text{right}:&\quad100e^{0.60}\approx\$182.21,\\ \text{gap}:&\quad(228.2-182.21)/1.94\approx24\ \text{SE}. \end{aligned} \]

ห่างราว 24 SE ไม่มีทางเป็นโชค จึงรู้ทันทีว่าโค้ดผิด

ใช้ทำอะไรบนโต๊ะจริง

เวลาส่งรายงานคาดการณ์ให้ลูกค้าหรือฝ่ายดูแลความเสี่ยง ควรแยกคอลัมน์ให้ชัด: ค่าเฉลี่ย median และ percentile (เช่น percentile ที่ 5 คือค่าที่ 5% ของเส้นทางจบต่ำกว่า) และบอกด้วยว่าเป็นตัวเลขก่อนหักภาษีและต้นทุน และรวมเงินปันผลหรือไม่ ค่าเฉลี่ยเหมาะกับการรวมผลของพอร์ตใหญ่หรือของลูกค้าจำนวนมาก ส่วน median เหมาะกับการบอกว่าลูกค้าหนึ่งคนควรคาดอะไร

ผล $\mathbb E[S_T]=S_0e^{\mu T}$ ยังกลับมาอีกครั้งตอนตั้งราคา derivative (สัญญาที่มูลค่าขึ้นกับราคาหุ้น เช่น option) การตั้งราคาแบบนี้คิดใน risk-neutral measure ซึ่งเป็นโลกสมมติที่ใช้คำนวณราคา ในโลกนั้น drift $\mu$ ถูกแทนด้วย $r-c$ โดย $r$ คือดอกเบี้ยต่อปี และ $c$ คือ dividend yield (เงินปันผลต่อปีคิดเป็นสัดส่วนของราคาหุ้น) ราคาเฉลี่ยจึงเป็น $S_0e^{(r-c)T}$ ซึ่งก็คือราคา forward ของหุ้น (ราคาที่ตกลงวันนี้ เพื่อซื้อขายกันในวันที่ $T$)

ตัวอย่าง: หุ้นราคา $S_0=\$100$ ดอกเบี้ย $r=4\%$ dividend yield $c=1.5\%$ สัญญาหนึ่งปี $T=1$ จะได้ราคา forward $100e^{(0.04-0.015)\times1}=100e^{0.025}\approx\$102.53$ (รายละเอียดอยู่ที่ เงินปันผลในสูตร) พจน์ $-\sigma^2/2$ ในเลขชี้กำลังคือสิ่งที่ทำให้สมการนี้เป็นจริงทุก $T$ และ สูตร Black–Scholes ก็สร้างอยู่บนมัน

// Standard Normal CDF: Taylor series near the centre, continued fraction in the tails.
function normCdf(x) {
  const ax = Math.abs(x), density = Math.exp(-ax * ax / 2) / Math.sqrt(2 * Math.PI);
  if (ax < 3) {
    let term = ax, sum = ax;
    for (let k = 1; term > 1e-17 * sum; k++) { term *= ax * ax / (2 * k + 1); sum += term; }
    return x < 0 ? 0.5 - density * sum : 0.5 + density * sum;
  }
  let f = 0;
  for (let k = 300; k >= 1; k--) f = k / (ax + f);
  const tail = density / (ax + f);
  return x < 0 ? tail : 1 - tail;
}
function normInv(p) {
  let lo = -40, hi = 40;
  for (let i = 0; i < 200; i++) { const mid = (lo + hi) / 2; if (normCdf(mid) < p) lo = mid; else hi = mid; }
  return (lo + hi) / 2;
}

const mgf = (m, v, u) => Math.exp(m * u + v * u * u / 2);
function gbmMoments(S0, mu, sigma, s) {
  if (!(S0 > 0 && sigma > 0 && s > 0)) throw new RangeError('Price, volatility and horizon must be positive');
  const nu = mu - sigma * sigma / 2, m = nu * s, v = sigma * sigma * s;
  const mean = S0 * mgf(m, v, 1), median = S0 * Math.exp(m);
  return {nu, mean, median, ratio: mean / median, sd: Math.sqrt(S0 * S0 * mgf(m, v, 2) - mean * mean)};
}

  const nu = mu - sigma * sigma / 2;
  return 1 - normCdf((Math.log(K / S0) - nu * s) / (sigma * Math.sqrt(s)));
}
// Log growth of a portfolio kept at k times capital in the stock, the rest borrowed or lent at r.
const leveredGrowth = (mu, sigma, r, k) => r + k * (mu - r) - k * k * sigma * sigma / 2;
const bestLeverage = (mu, sigma, r) => (mu - r) / (sigma * sigma);
// A daily-rebalanced fund returns lambda times each daily index return.
function leveragedFund(indexPrices, lambda) {
  let value = 100;
  for (let i = 1; i < indexPrices.length; i++) {
    const r = indexPrices[i] / indexPrices[i - 1] - 1;
    if (1 + lambda * r <= 0) throw new RangeError('Fund is wiped out on one day');
    value *= 1 + lambda * r;
  }
  return value;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ค่าเฉลี่ยของราคาโตที่ $\mu$ พอดี: $\mathbb E_t[S_{t+s}]=S_tM_X(1)=S_te^{\nu s+\sigma^2s/2}=S_te^{\mu s}$ เพราะส่วนเกิน $+\sigma^2s/2$ จาก MGF หักกับ $-\sigma^2/2$ ในนิยามของ GBM พอดี และราคาที่หักการเติบโตออกแล้ว $e^{-\mu t}S_t$ เป็น martingale
  • median คือ $S_te^{(\mu-\sigma^2/2)s}$ และค่าเฉลี่ยหารด้วย median คือ $e^{\sigma^2s/2}$ ซึ่งไม่ขึ้นกับ $\mu$ ยิ่งผันผวนและยิ่งถือนาน ช่องว่างยิ่งกว้าง
  • กองทุน $\mu=14\%$ ความผันผวน 32% เงิน \$100 หลัง 20 ปี: ค่าเฉลี่ย \$1,644.46 แต่ median \$590.62 มีเพียง 23.71% ของนักลงทุนที่ได้ถึงค่าเฉลี่ย และ 10.73% ยังขาดทุน
  • volatility drag ไม่ลดค่าเฉลี่ย แต่ลดอัตราทบต้นของเส้นทางทั่วไป และโตตาม $\sigma^2$ ตัวอย่างที่เล็กที่สุดคือต้นไม้ ±50% สองงวด ค่าเฉลี่ยยังเป็น \$100 แต่ median เหลือ \$75
  • leverage ที่ทำให้ median โตเร็วที่สุดคือ $k^*=(\mu-r)/\sigma^2$ กู้เกินนั้นทำให้ median โตช้าลง และ leveraged ETF เสีย drag แม้ดัชนีวนกลับมาที่เดิม

หน้าถัดไป สามสมบัติที่ GBM รับมาจาก Brownian motion จะใช้ log ratio ตัวเดียวกันนี้ตอบคำถามเรื่องโอกาส เช่น หุ้นราคา \$100 ตอนครบหนึ่งปีมีโอกาสปิดเหนือ \$130 หรือปิดใต้ \$70 เท่าไร หน้านั้นจะคำนวณให้ดูว่า ทำไมสองเป้าที่ห่างจากราคาวันนี้ \$30 เท่ากัน จึงมีโอกาสต่างกันเกือบห้าเท่า
