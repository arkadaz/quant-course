10.2 Standard Brownian Motion (SBM)

เริ่มจาก random walk มาตรฐาน แล้วอ่านค่าเฉลี่ยกับความผันผวน

พอร์ต SPY มูลค่า \$25,000,000 มีความผันผวนรายวัน 1.15% หากตลาดเปิด 252 วันต่อปี ความเสี่ยงรายปีและราคา option แบบ at-the-money (ATM) straddle อายุ 30 วันที่ราคาหุ้น \$520 ควรมีมูลค่าเท่าใด?

เฉลย: ความผันผวนรายปีคือ 18.26% (ความเสี่ยงพอร์ต \$4.57 ล้าน ไม่ใช่ \$72.45 ล้าน) และราคา straddle 30 วันคือ 4.18% ของราคาหุ้น หรือ \$21.72 ต่อหุ้น (\$2,172 ต่อสัญญา) เพราะความเสี่ยงโตตามรากของเวลา

ศัพท์ที่ใช้ในหัวข้อนี้
Standard Brownian Motion (SBM)
Brownian motion ที่เริ่มจาก 0 ไม่มี drift และมี variance เท่ากับเวลาที่ผ่านไป ใช้เป็นหน่วยมาตรฐานสำหรับสร้าง Brownian motion และจำลอง noise ใน model เวลาต่อเนื่อง
expected value
ค่าเฉลี่ยที่ถ่วงด้วยโอกาสของผลลัพธ์ทุกแบบ ใช้บอกค่าเฉลี่ยที่ model คาดเมื่อสุ่มเหตุการณ์เดิมจำนวนมาก
sample path
ผลลัพธ์หนึ่งเส้นจากการสุ่ม process ตลอดหลายเวลา ใช้ดู scenario ที่เป็นไปได้ แต่เส้นเดียวไม่ใช่ forecast ของตลาด
Monte Carlo simulation
วิธีสุ่ม sample paths จำนวนมากแล้วสรุป distribution ของผลลัพธ์ ใช้ประมาณ risk, probability และราคาเมื่อคำนวณตรง ๆ ยาก
log return
logarithm ของอัตราส่วนราคาปลายช่วงต่อราคาเริ่มช่วง ซึ่งบวกข้ามช่วงเวลาติดกันได้ ใช้เชื่อม Brownian increments กับผลตอบแทนสะสม
square-root-of-time rule
กฎที่แปลง standard deviation ระหว่าง horizons ด้วยรากของอัตราส่วนเวลา ใช้ annualize หรือ de-annualize volatility เมื่อ increments เป็นอิสระและมี variance คงที่
at-the-money (ATM)
สถานะที่ strike เท่ากับราคา spot ปัจจุบันของ underlying ใช้เป็นจุดอ้างอิงคำนวณ option โดยไม่มี intrinsic value
at-the-money straddle
position ที่ซื้อ call option และ put option strike เดียวกับ spot และ expiry เดียวกัน ใช้ซื้อความผันผวนทั้งขาขึ้นและขาลงโดยไม่เลือกทิศ
call option
สัญญาที่ให้สิทธิ์ซื้อ underlying ที่ strike ภายในหรือ ณ expiry ใช้รับ upside โดยจำกัดขาดทุนของผู้ซื้อไว้ที่ premium
put option
สัญญาที่ให้สิทธิ์ขาย underlying ที่ strike ภายในหรือ ณ expiry ใช้รับ downside หรือป้องกันราคาลดลง
strike
ราคาที่กำหนดสิทธิ์ซื้อหรือขายไว้ใน option ใช้แบ่งว่าที่ expiry option มี intrinsic payoff หรือไม่
spot
ราคาตลาดของ underlying ณ ปัจจุบัน ใช้เป็นฐานเทียบ strike และคำนวณ notional ของ position
expiry
เวลาสิ้นสุดสิทธิ์ของ option ใช้กำหนด horizon ที่ความผันผวนมีเวลาสะสม
premium
ราคาที่ผู้ซื้อ option จ่ายล่วงหน้าให้ผู้ขาย ใช้แลกกับ payoff ที่อาจเกิดในอนาคต
United States (US) equity option contract
หน่วยซื้อขาย option ในตลาดสหรัฐฯ ซึ่งหนึ่งสัญญาโดยทั่วไปอ้างอิง 100 shares ใช้แปลงราคาต่อ share เป็นเงินสดต่อสัญญา
notional
มูลค่าอ้างอิงที่ position ควบคุมก่อนหัก hedge หรือ leverage ใช้แปลง return volatility เป็น P&L risk หน่วย USD
realized volatility
ความผันผวนที่วัดได้จริงจากผลตอบแทนในอดีต ใช้เทียบว่าราคา option ในตลาดแพงหรือถูก
implied volatility
ความผันผวนที่ต้องใส่ในสูตรให้ได้ราคา option เท่าราคาตลาด ใช้อ่านว่าตลาดคาดความผันผวนในอนาคตเท่าไร

ที่มาที่ไป: ก้อนสุ่มมาตรฐาน ที่ทุกอย่างสร้างต่อจากมัน

แทนที่จะนิยามแบบจำลองใหม่ทุกครั้งที่เจอสินทรัพย์ใหม่ วิธีที่ประหยัดกว่าคือนิยามก้อนสุ่มมาตรฐานไว้ก้อนเดียว แล้วสร้างทุกอย่างต่อจากมันด้วยการเลื่อนและขยาย

แนวคิดเดียวกับที่เราทำกับระฆังคว่ำในบทที่หนึ่ง คือมีตัวมาตรฐานที่ค่าเฉลี่ยเป็นศูนย์และความผันผวนเป็นหนึ่ง แล้วตัวอื่นสร้างจากมัน

ผลพลอยได้ที่สำคัญคือกฎรากที่สอง ซึ่งโผล่ออกมาจากนิยามโดยตรง ไม่ใช่กฎที่ใครตั้งขึ้น

กฎนั้นคือสิ่งที่ทำให้แปลงความเสี่ยงรายวันเป็นรายปีได้ และเป็นการคำนวณที่ทำกันทุกวันในทุกทีม

ประวัติความเป็นมา: จากละอองเกสรของ Brown สู่สมการฟิสิกส์และการเงิน

ในปี 1827 นักพฤกษศาสตร์ชาวสก็อต Robert Brown ส่องกล้องจุลทรรศน์ดูละอองเกสรดอกไม้ Clarkia pulchella ที่ลอยในน้ำ แล้วพบว่าอนุภาคขนาดเล็กขยับสั่นไปมาอย่างไม่มีทิศทางแน่นอนตลอดเวลา ตอนแรกเขาคิดว่าละอองเกสรอาจมีชีวิต แต่เมื่อทดลองกับผงแก้วและเขม่าควันกลับพบการส่ายแบบเดียวกัน จึงสรุปว่าเป็นปรากฏการณ์ธรรมชาติของอนุภาคจิ๋ว

ต่อมาในปี 1900 นักคณิตศาสตร์ชาวฝรั่งเศส Louis Bachelier นำเสนอวิทยานิพนธ์ Théorie de la spéculation โดยเสนอเป็นคนแรกว่า ราคาพันธบัตรรัฐบาลในตลาดหุ้นปารีสมีพฤติกรรมสุ่มแบบเดียวกับละอองเกสรของ Brown การสร้างแบบจำลอง continuous-time ครั้งนั้นนำไปสู่สูตรคำนวณราคา option ก่อนที่วงการการเงินสมัยใหม่จะหยิบมาต่อยอดกว่าเจ็ดสิบปี

ในปี 1905 Albert Einstein ตีพิมพ์คำอธิบายฟิสิกส์ว่า การส่ายของอนุภาคเกิดจากโมเลกุลของน้ำนับพันล้านโมเลกุลวิ่งชนจากรอบทิศ เขาแสดงว่าระยะทางกำลังสองเฉลี่ยโตตามเวลาแบบเส้นตรง ไม่ใช่เวลาคูณเวลา ซึ่งผลงานนี้เปิดทางให้ Jean Perrin ทดลองยืนยันการมีอยู่จริงของอะตอมจนได้รับรางวัลโนเบล

ท้ายที่สุดในปี 1923 Norbert Wiener ได้สร้างรากฐานคณิตศาสตร์อันรัดกุม พิสูจน์ว่า stochastic process ที่มี sample path ต่อเนื่องบนเวลา continuous time นี้มีอยู่จริงในทางทฤษฎีความน่าจะเป็น นักคณิตศาสตร์จึงเรียกกระบวนการนี้ว่า Wiener process เพื่อเป็นเกียรติแก่เขา

ขั้นที่ 1 — นิยาม SBM ในหนึ่งบรรทัด

ก่อนจะสร้าง model ราคาอะไรก็ตาม ต้องมีก้อนสุ่มมาตรฐานไว้หนึ่งก้อนก่อน ขั้นนี้นิยามมันด้วยสามเงื่อนไขสั้น ๆ ที่เหลือทั้งบทสร้างต่อจากนี้

\[ \begin{aligned} W_0&=0\\ W_{t+s}-W_t&\sim\mathcal N(0,s)\\ W_{t+s}-W_t&\ \ \text{independent of}\ \ \mathcal F_t \end{aligned} \]

$W_0$ กำหนดจุดเริ่มที่ 0; ให้ $\mathcal F_t$ แทนข้อมูลจาก path ถึงเวลา $t$; increment ยาว $s$ มี mean 0 และ variance $s$; บรรทัดสามบอกว่า increment อนาคตไม่ขึ้นกับข้อมูลถึงเวลา $t$

ขั้นที่ 2 — Brownian motion ทุก scale สร้างจาก SBM

ของจริงไม่ได้เริ่มที่ศูนย์ ไม่ได้นิ่ง และไม่ได้แกว่งเท่ากันทุกตัว สี่บรรทัดนี้แสดงว่าการเติมสามอย่างนั้นเข้าไป ไม่ได้ทำให้ต้องสร้างทฤษฎีใหม่ เพราะทุกบรรทัดใช้แค่กฎค่าเฉลี่ยกับกฎ variance ที่มีอยู่แล้ว

\[ \begin{aligned}X_t&:=x+\mu t+\sigma W_t\\ \mathbb E[X_t]&=x+\mu t+\sigma\,\mathbb E[W_t]=x+\mu t\\ \operatorname{Var}(X_t)&=\operatorname{Var}(\sigma W_t)=\sigma^{2}\operatorname{Var}(W_t)=\sigma^{2}t\\ W_t\ \text{normal}\;&\Longrightarrow\;X_t\sim\mathcal N\big(x+\mu t,\ \sigma^{2}t\big)\end{aligned} \]

บรรทัดแรกไม่ใช่ผลลัพธ์ แต่เป็น นิยาม ของสิ่งที่เราสร้างขึ้นเอง: หยิบก้อนมาตรฐานมา แล้วเติมจุดเริ่มต้น ทิศทาง และขนาดความผันผวนเข้าไป คำถามคือของที่สร้างแบบนี้มีหน้าตาอย่างไร

หาค่าเฉลี่ยก่อน สองพจน์แรกไม่ได้สุ่มจึงผ่านออกมาตรง ๆ ส่วนก้อนมาตรฐานมีค่าเฉลี่ยเป็นศูนย์ ทิศทางจึงเป็นของที่เราใส่เข้าไปล้วน ๆ

ต่อด้วยความผันผวน การบวกเลขคงที่ไม่เปลี่ยนความผันผวน เพราะเลื่อนทั้งก้อนเท่ากันหมด ส่วนตัวคูณออกมาเป็นกำลังสองตามหัวข้อ 6.5 แล้วใช้ผลของหัวข้อ 10.1 ว่า variance เท่ากับเวลา

บรรทัดสุดท้ายคือประเด็นที่ทำให้ทั้งบทเดินต่อได้ การคูณและบวกด้วยเลขคงที่ไม่ทำให้ระฆังเลิกเป็นระฆัง มันแค่เลื่อนและยืด ทุกขนาดจึงสร้างจากก้อนมาตรฐานก้อนเดียวได้หมด

simulation ที่ถูกต้องไม่บวก Normal scale 1 ทุกก้าว

แบ่ง horizon เป็น grid แล้วสุ่ม increment ที่มี standard deviation สอดคล้องกับความยาวช่วง ถ้าลด $\Delta t$ ลง 100 เท่า แต่ไม่ลดขนาดก้าวลง 10 เท่า path จะระเบิดและไม่ใช่ SBM

ขั้นที่ 3 — สูตรสร้าง path บน grid

จะจำลองด้วยคอมพิวเตอร์ได้ ต้องแปลงนิยามที่เป็นเวลาต่อเนื่อง ให้กลายเป็นสูตรเดินทีละขั้นเสียก่อน

\[ \begin{aligned} \Delta W_i&=\sqrt{\Delta t}\,Z_i,\qquad Z_i\ \text{i.i.d.}\ \mathcal N(0,1)\\ W_{t_k}&=\sum_{i=1}^{k}\Delta W_i \end{aligned} \]

$Z_i$ คือ standard Normal draws ที่ independent and identically distributed; นำ $\sqrt{\Delta t}$ มาคูณเพื่อให้แต่ละ increment มี variance $\Delta t$ แล้ว cumulative sum ให้ค่าของ $W$ ที่ grid point $t_k$

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

ก้อนสุ่มมาตรฐานเป็นวัตถุดิบที่ใช้ประกอบแบบจำลองราคาทุกตัว

ใช้เขียนโค้ดจำลองราคา ซึ่งทุกระบบจำลองเริ่มจากการสร้างก้อนนี้ก่อนแล้วค่อยปรับขนาด

ใช้แปลงความผันผวนรายวันเป็นรายเดือนหรือรายปี ด้วยกฎรากที่สองที่ได้จากที่นี่

ใช้ประมาณราคาของกลยุทธ์ที่จ่ายตามขนาดการเคลื่อนไหว โดยไม่สนทิศ ซึ่งเป็นโครงสร้างที่ใช้เทรดความผันผวน

ขั้นที่ 4 — self-similarity ของ SBM

SBM มีสมบัติที่ใช้ตรวจงานได้ดีมาก คือย่อหรือขยายแกนเวลา แล้วปรับแกนตั้งด้วยราก หน้าตาของมันจะเหมือนเดิมทุกประการ

\[ \frac{W_{ct}}{\sqrt c}\overset{d}{=} W_t\qquad (c>0,\ t\ge 0) \]

$c$ คือ factor ขยายเวลา; หารแกนตั้งด้วย $\sqrt c$ แล้ว finite-dimensional distributions ของ process เท่ากันทุกช่วงเวลา เครื่องหมาย equality in distribution ไม่ได้บอกว่าเป็น sample path เส้นเดียวกัน

ขั้นที่ 5 — พิสูจน์ Brownian scaling จากสมบัติของ SBM

การพิสูจน์นี้ยืนยันว่าการย่อขยายแกนเวลาด้วยตัวคูณ $c$ แล้วปรับสเกลแกนตั้งด้วย $\sqrt c$ ไม่ทำให้สมบัติของ SBM เสียหายเลย ทั้งจุดเริ่มต้น expected value, variance และ independence ของ increment ยังสอดคล้องกับนิยามตั้งต้นครบทุกข้อ

\[ \begin{aligned} Y_t&:=\frac{W_{ct}}{\sqrt c},\qquad c>0\\[4pt] Y_0&=\frac{W_0}{\sqrt c}=\frac{0}{\sqrt c}=0\\[4pt] &Y_{t+s}-Y_t=\frac{W_{c(t+s)}-W_{ct}}{\sqrt c}\\[4pt] &\mathbb E[Y_{t+s}-Y_t]\\ &=\frac{\mathbb E[W_{c(t+s)}-W_{ct}]}{\sqrt c}=\frac{0}{\sqrt c}=0\\[4pt] &\operatorname{Var}(Y_{t+s}-Y_t)\\ &=\frac{\operatorname{Var}(W_{c(t+s)}-W_{ct})}{(\sqrt c)^2}\\ &=\frac{c(t+s)-ct}{c}=\frac{cs}{c}=s\\[4pt] &Y_{t+s}-Y_t\sim\mathcal N(0,s) \end{aligned} \]

กำหนด process ใหม่ $Y_t$ ด้วยการเร่งเวลาไป $c$ เท่าแล้วบีบความสูงลงด้วย $\sqrt c$; จุดเริ่มต้น $Y_0$ ยังคงเป็นศูนย์เพราะ $W_0$ เท่ากับศูนย์ตั้งแต่แรก

เมื่อดู increment จาก $t$ ไป $t+s$ ตัวเศษคือการก้าวของ $W$ ในช่วงเวลาที่ยาว $cs$ ค่าเฉลี่ยของก้อนนี้เป็นศูนย์เพราะไม่มี drift ตั้งแต่ต้น

เมื่อดึงตัวคูณคงที่ $\sqrt c$ ออกจาก variance มันจะถูกยกกำลังสองกลายเป็น $c$ ในตัวส่วน จึงตัดกับความยาวช่วงเวลา $cs$ พอดี เหลือ variance เท่ากับ $s$

เนื่องจากการคูณและรวมเชิงเส้นของ Normal ยังคงเป็น Normal ก้อน $Y$ จึงมี increment ที่มี distribution เดียวกัน และ independence ของแต่ละช่วงเวลายังคงเดิมทุกประการ ทำให้ $Y$ เป็น SBM เช่นกัน

derive square-root-of-time จาก log returns

ให้ daily log returns อิสระและมี standard deviation $\sigma_d$ ผลตอบแทน $n$ วันคือผลรวมของ daily increments ดังนั้นสิ่งที่บวกกันคือ variance ไม่ใช่ volatility

ขั้นที่ 6 — variance ของผลรวม $n$ วัน

คำถามที่โต๊ะถามบ่อยที่สุดคือความเสี่ยงรายวันแปลงเป็นรายเดือนรายปีอย่างไร สูตรข้างล่างตอบ และที่สำคัญกว่าคำตอบคือบรรทัดที่ตั้ง covariance เป็นศูนย์ ซึ่งเป็นจุดที่กฎนี้พัง ในวันที่ตลาดมีแนวโน้มต่อเนื่อง พจน์ไขว้ไม่เป็นศูนย์ และรากที่สองก็ประเมินความเสี่ยงต่ำไป

\[ \begin{aligned} &\operatorname{Var}\Big(\sum_{i=1}^{n}r_i\Big)\\ &=\sum_{i=1}^{n}\operatorname{Var}(r_i)+\sum_{i\ne j}\operatorname{Cov}(r_i,r_j)\\ &=\sum_{i=1}^{n}\operatorname{Var}(r_i)\\ &\quad(\operatorname{Cov}=0,\ \text{independent})\\ &=n\sigma_d^{2}\qquad(\operatorname{Var}(r_i)=\sigma_d^{2})\\ \operatorname{SD}&=\sigma_d\sqrt{n} \end{aligned} \]

กาง variance ของผลรวมให้ครบก่อน ตามรูปที่หัวข้อ 6.5 สร้างไว้ คือ variance ของแต่ละวัน บวกพจน์ไขว้ทุกคู่ พจน์ไขว้นั่นแหละคือหัวใจของขั้นนี้

บรรทัดที่สามถึงสี่ใช้ข้อสมมติว่าแต่ละวันไม่ส่งข่าวถึงกัน พจน์ไขว้ทุกตัวจึงเป็นศูนย์ กฎรากที่สองทั้งกฎแขวนอยู่กับบรรทัดนี้บรรทัดเดียว และนี่คือข้อที่ตลาดจริงละเมิดบ่อยที่สุด เพราะวันแย่มักมากันเป็นชุด

ที่เหลือง่าย ทุกวันแกว่งเท่ากัน จึงบวก $n$ ก้อนที่เท่ากัน แล้วถอดรากกลับมาเป็นหน่วยผลตอบแทน ได้รูปที่ใช้แปลงความเสี่ยงรายวันเป็นรายปีกันทุกวันนี้

ขั้นที่ 7 — แปลงกลับเป็น volatility

variance บวกกันได้ แต่ความผันผวนบวกกันไม่ได้ ขั้นนี้แสดงว่ารากที่สองที่ทุกคนท่องจำกันนั้นโผล่ออกมาจากตรงไหน

\[ \sigma_n=\sqrt{n\sigma_d^2}=\sigma_d\sqrt n \]

$\sigma_n$ คือ standard deviation ของผลตอบแทนสะสม $n$ วัน; square root เกิดจากนิยาม standard deviation ไม่ใช่สูตรจำลอย ๆ

ขั้นที่ 8 — แทน daily volatility 1.15%

ความผันผวนของ Brownian motion โตตามรากของเวลา ไม่ใช่ตามเวลา จึงต้องถอดรากจำนวนวันก่อนคูณ

\[ \begin{aligned} \sigma_{5}&=1.15\%\sqrt5=1.15\%(2.2361)=2.57\%\\ \sigma_{21}&=1.15\%\sqrt{21}=1.15\%(4.5826)=5.27\%\\ \sqrt{252}&=\sqrt{4\times63}=2(7.9373)=15.8745\\ \sigma_{252}&=1.15\%(15.8745)=18.26\%\\[4pt] \text{wrong}&:\ 1.15\%(252)=289.8\%\\ \text{ratio}&=289.8/18.26=15.87=\sqrt{252} \end{aligned} \]

หนึ่งปีมี 252 วัน แต่ความผันผวนโตขึ้นเพียง 15.87 เท่า ไม่ใช่ 252 เท่า

นี่คือเหตุผลที่ความเสี่ยงรายปีดูเล็กกว่าที่สัญชาตญาณคิด เมื่อเทียบกับความเสี่ยงรายวันคูณจำนวนวัน

√252 หาด้วยมือได้ แยก 252 = 4 × 63 แล้วลองยกกำลังสอง 7.93² = 62.885 กับ 7.94² = 63.044 จึงได้ √63 ≈ 7.9373 และ √252 ≈ 15.87 ≈ 16 ทางลัดในหัวคือ σ รายปี ≈ 16 × σ รายวัน เห็น 1% ต่อวันให้อ่านว่าราว 16% ต่อปี

สองบรรทัดล่างคือความผิดที่พบบ่อย คูณ 252 ตรง ๆ ได้ 289.8% ผิดไป 15.87 เท่าพอดี ซึ่งคือ √252 นั่นเอง วิธีจับผิดในสองวินาที: ถ้าเวลาเพิ่มสี่เท่า ความเสี่ยงต้องเพิ่มสองเท่า ไม่ใช่สี่เท่า

sanity check ด้วยราคา straddle 30 วัน

เพื่อผูก scale กับราคา option ให้ SPY spot และ strike เท่ากับ \$520, annual volatility 18.26%, expiry 30/365 ปี และสมมติ rate กับ dividend เป็น 0 สำหรับ approximation ระยะสั้น payoff ของ at-the-money straddle ใกล้เคียงขนาด absolute Normal move

ขั้นที่ 9 — scale ของการขยับตลอด 30 วัน

ใช้กฎรากที่สองกับ horizon ที่โจทย์ถามจริง คือหนึ่งเดือนข้างหน้า

\[ \begin{aligned} T&=30/365=0.082192\\ \sqrt T&=0.286691\\ \sigma\sqrt T&=0.182557(0.286691)\\ &=0.052337=5.234\%\\[4pt] &\text{21 trading days}:\\ &\quad 0.182557\sqrt{21/252}\\ &\quad=0.182557(0.288675)\\ &=0.052700=5.270\% \end{aligned} \]

30 วันคิดเป็น 0.082192 ปี ถอดรากได้ 0.286691 ความผันผวนหนึ่งเดือนจึงเป็นราว 28.7% ของความผันผวนทั้งปี

สี่บรรทัดล่างตรวจอีกทาง 30 วันปฏิทินราว 21 วันทำการ ได้ 5.27% ต่างจาก 5.23% แค่ 0.04 จุด ในบรรทัดเดียวกันห้ามปนสองแบบ แต่คนละบรรทัดได้: σ รายปีนับวันทำการเพราะราคาขยับตอนตลาดเปิด ส่วนอายุสัญญานับวันปฏิทินเพราะหมดอายุตามนาฬิกาจริง สำหรับ option อายุ 2–3 วันความต่างนี้จะใหญ่ขึ้นมาก

ขั้นที่ 10 — expected value ของ absolute standard Normal

straddle จ่ายตามขนาดการขยับ โดยไม่สนว่าขึ้นหรือลง เราจึงต้องการค่าเฉลี่ยของ *ขนาด* ไม่ใช่ค่าเฉลี่ยของค่าที่ยังติดเครื่องหมาย ซึ่งเป็นศูนย์

\[ \begin{aligned}\mathbb E[|Z|]&=2\int_0^\infty z\,\phi(z)\,dz\\[4pt] &=2\int_0^\infty z\,\frac{1}{\sqrt{2\pi}}e^{-z^2/2}\,dz\\[4pt] &=\sqrt{\frac{2}{\pi}}\int_0^\infty e^{-u}\,du\qquad (u=z^2/2,\ du=z\,dz)\\[4pt] &=\sqrt{\frac{2}{\pi}}\Big[-e^{-u}\Big]_0^\infty\\[4pt] &=\sqrt{\frac{2}{\pi}}\big(0-(-1)\big)=\sqrt{\frac{2}{\pi}}\approx0.797885\end{aligned} \]

$Z$ คือ standard Normal และ $\phi$ คือ density ของมัน; absolute value พับ left tail มารวมกับ right tail ทำให้ expected magnitude เป็น 0.797885 แทน 0

แทน $\phi(z)=e^{-z^2/2}/\sqrt{2\pi}$ จะได้ $2/\sqrt{2\pi}$ คูณ integral ของ $ze^{-z^2/2}$ ตั้งแต่ 0 ถึงอนันต์ เพราะ derivative ของ $-e^{-z^2/2}$ คือ $ze^{-z^2/2}$ integral จึงเป็น $0-(-1)=1$ เหลือ $2/\sqrt{2\pi}=\sqrt{2/\pi}$

ขั้นที่ 11 — ราคา straddle แบบ small-move approximation

รวมสามชิ้นที่หามาได้เข้าด้วยกัน คือราคาปัจจุบัน ความผันผวนของการขยับหนึ่งเดือน และค่าเฉลี่ยของขนาดการขยับ

\[ \begin{aligned} S_0\,\sigma\sqrt T\,\mathbb E|Z|&=\$520(0.052337)(0.797885)\\ &=\$21.72\ \text{per share}\\ &=\$2{,}172\ \text{per contract} \end{aligned} \]

$S_0$ คือ spot \$520, 5.234% คือ return scale และ 0.797885 คือ expected absolute Normal move; คูณ 100 shares ต่อ contract แปลง premium ต่อ share เป็นเงินสดต่อ US equity option contract

ขั้นที่ 12 — ตรวจกับสูตร Black–Scholes เต็ม

ทางลัด 0.798 × σ√T ต้องตรวจกับสูตรเต็มของบทที่ 13 ก่อนเชื่อ ที่ ATM และดอกเบี้ย 0 call กับ put ราคาเท่ากัน straddle จึงเท่ากับสอง call และสูตรยุบเหลือผลต่างของพื้นที่ใต้ระฆังที่สองตำแหน่ง

\[ \begin{aligned} &\text{straddle}\\ &=2S\big[\Phi(\sigma\sqrt T/2)-\Phi(-\sigma\sqrt T/2)\big]\\ &\sigma\sqrt T/2=0.052337/2=0.026169\\ &\Phi(0.026169)=0.510439\\ &\Phi(-0.026169)=0.489561\\ &2(0.510439-0.489561)\\ &=2(0.020877)\\ &=0.041754=4.175\%\\ &\text{shortcut}:\\ &\quad 0.797885(0.052337)\\ &\quad=0.041759=4.176\%\\[4pt] &\Phi(x)\approx0.5+\varphi(0)\,x\\ &\varphi(0)=\frac{1}{\sqrt{2\pi}}=0.398942 \end{aligned} \]

สูตรเต็มให้ 4.175% ทางลัดให้ 4.176% ต่างกัน 0.001 จุด บนหุ้น \$520 คือ 21.71 เทียบ \$21.72 ทางลัดจึงใช้ได้จริงที่ ATM

ทำไมแม่นขนาดนี้ ดูสองบรรทัดสุดท้าย ใกล้ศูนย์ระฆังแทบเป็นเส้นตรง ผลต่างของสองค่านี้จึงเป็น 2φ(0)(σ√T/2) = φ(0)σ√T คูณ 2S ได้ 2φ(0) = 0.798 พอดี นี่คือที่มาของกฎในหัวของโต๊ะว่า ATM call ≈ 0.4 × S × σ√T

ทางลัดจะเริ่มเพี้ยนเมื่อ σ√T ใหญ่ เช่น option อายุยาวมาก หรือหุ้นที่ผันผวนสุดขั้ว เพราะระฆังไม่เป็นเส้นตรงอีกต่อไป

คำตอบ — ความเสี่ยงพอร์ต SPY และราคา ATM straddle 30 วัน

โจทย์ให้อะไรมาบ้าง: พอร์ต SPY มูลค่า \$25,000,000 ผันผวนรายวัน 1.15% (252 วันทำการต่อปี) ราคาหุ้น \$520 และ option อายุ 30 วัน

คำถาม: ความผันผวนรายปี และราคา option แบบ ATM straddle อายุ 30 วัน มีมูลค่ากี่ดอลลาร์?

ของที่มี (ขั้นที่ 6 ถึง 12): $\sigma_d = 1.15\%$, พอร์ต \$25,000,000, spot \$520, อายุ 30 วัน ($T = 30/365$ ปี)

1 คำนวณความผันผวนรายปี: 1.15% คูณ 15.8745 ได้ 18.26% คิดเป็นความเสี่ยงพอร์ต \$4.57 ล้าน (ไม่ใช่คูณ 252 ตรง ๆ ซึ่งได้ 289.8% และผิดไป 15.87 เท่า)

2 คำนวณขนาดแกว่ง 30 วัน: 18.26% คูณ 0.28669 ได้ 5.234%

3 คำนวณราคา ATM straddle: คูณด้วย 0.7979 ได้ 4.18% ของราคาหุ้น คิดเป็น \$21.72 ต่อหุ้น (\$2,172 ต่อสัญญา)

คำตอบ: ความผันผวนรายปีคือ 18.26% และราคา ATM straddle 30 วันคือ \$21.72 ต่อหุ้น เทียบกับสูตร Black-Scholes (บทที่ 13) เต็มที่ได้ \$21.71

ตรวจเองใน 10 วินาที: เอา 16 คูณ 1.15% ได้ราว 18.4% และ straddle ประมาณ 0.8 คูณ 5.23% ได้ราว 4.18%

แปลว่าอะไร: ตัวเลขเดียวคือความผันผวนรายวัน 1.15% ตอบได้สามคำถามที่ต่างกันสิ้นเชิง เดือนนี้พอร์ตแกว่งได้แค่ไหน (5.27%) ปีนี้ควรตั้ง limit เท่าไร (18.26% หรือ \$4.57 ล้าน) และ option ตัวนี้แพงหรือถูก (4.18%) ถ้าตลาดขาย straddle ตัวนี้ที่ 6% แปลว่าตลาดคาดความผันผวนราว 6% ÷ 0.7979 ÷ 0.2867 = 26.2% ต่อปี สูงกว่า 18.26% ที่วัดจากอดีต นั่นคือ implied volatility คุยกับ realized volatility ซึ่งเป็นงานประจำวันของโต๊ะ option

โค้ดตรวจการแปลงความผันผวนและราคา straddle ด้วย Python 
import math
from scipy.stats import norm

spot = 520.0
notional = 25_000_000.0
sigma_daily = 0.0115

# 1. Horizon volatility
sigma_5 = sigma_daily * math.sqrt(5)
sigma_21 = sigma_daily * math.sqrt(21)
sigma_252 = sigma_daily * math.sqrt(252)
risk_year = notional * sigma_252

# 2. 30-day option scaling
T = 30.0 / 365.0
sigma_T = sigma_252 * math.sqrt(T)

# 3. Expected absolute standard Normal and straddle approximation
e_abs_z = math.sqrt(2.0 / math.pi)
straddle_pct = sigma_T * e_abs_z
straddle_price = spot * straddle_pct

# 4. Full Black-Scholes comparison at ATM, r = 0
d1 = sigma_T / 2.0
bs_straddle_pct = 2.0 * (norm.cdf(d1) - norm.cdf(-d1))

assert abs(sigma_5 - 0.0257) < 1e-3
assert abs(sigma_21 - 0.0527) < 1e-3
assert abs(sigma_252 - 0.1826) < 1e-3
assert abs(risk_year - 4_563_925) < 1000
assert abs(e_abs_z - 0.79788) < 1e-4
assert abs(straddle_pct - 0.0418) < 1e-3
assert abs(straddle_price - 21.72) < 0.05
assert abs(straddle_pct - bs_straddle_pct) < 1e-4
assert abs(sigma_daily * 252 - 2.898) < 1e-9 and abs(2.898 / sigma_252 - 15.87) < 0.01   # the wrong way
assert abs(sigma_252 * math.sqrt(21 / 252) - 0.0527) < 1e-4          # trading-day check
assert abs(0.06 / e_abs_z / math.sqrt(T) - 0.2623) < 1e-4             # implied vol of a 6% straddle
print(f"Annual vol: {sigma_252*100:.2f}%, Straddle: ${straddle_price:.2f}, BS: {bs_straddle_pct*100:.3f}%")

ตรวจการแปลงความผันผวนรายวันเป็นรายปี และราคา straddle เปรียบเทียบกับสูตร Black-Scholes (บทที่ 13)
