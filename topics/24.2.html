24.2 Bubbles, Crises, and Regulation

เงินกู้ทำให้ราคาที่ลงนิดเดียวกลายเป็นการขายบังคับครั้งใหญ่ และเมื่อทุกคนขายพร้อมกัน ความเสี่ยงไม่ได้มาจากโชคร้าย แต่มาจากโครงสร้าง

กองทุนถือสินเชื่อบ้านมัดรวม (mortgage pool) มูลค่า \$10 ล้าน ใช้เงินตัวเอง \$1 ล้าน กู้ \$9 ล้าน เจ้าหนี้กำหนดว่าเงินตัวเองต้องไม่ต่ำกว่า 5% ของมูลค่าสินทรัพย์ (maintenance margin) วันหนึ่งราคาลง 8% ผู้จัดการบอกว่า “ลงแค่ 8% เกณฑ์ตั้ง 5% ยังไม่ต้องทำอะไร” ถูกไหม และถ้าไม่มีเงินเติม ต้องขายเท่าไร?

ลองตอบก่อนเปิดเฉลย

ผิด สินทรัพย์เหลือ \$9.2 ล้าน หนี้ยังเป็น \$9 ล้าน เงินตัวเองเหลือ \$200,000 หรือ 2.17% ของสินทรัพย์ ต่ำกว่าเกณฑ์แล้ว ขาดหลักประกัน \$260,000 ถ้าไม่มีเงินเติมต้องขายสินทรัพย์ \$5.2 ล้าน หรือ 56.5% ของพอร์ต ขาดทุน 8% ของสินทรัพย์คือ 80% ของเงินตัวเอง และถ้าหลายกองทุนขายพร้อมกัน ราคาจะลงต่อ

ภาพรวมก่อนลงสูตร

หน้า market efficiency และ limits to arbitrage แสดงว่าดีลเดียวที่ใช้หลักประกันอาจถูกบังคับปิดก่อนความคิดจะถูก หน้านี้ขยายเรื่องนั้นเป็นทั้งระบบ ฟองสบู่คือช่วงที่ราคาสูงกว่าที่เงินสดในอนาคตอธิบายได้ ส่วนวิกฤตคือช่วงที่เงินกู้ซึ่งค้ำด้วยราคาเหล่านั้นถูกเรียกคืนพร้อมกัน ราคาจึงไม่ได้แค่กลับมาที่มูลค่าพื้นฐาน แต่ทะลุลงไปต่ำกว่า เพราะทุกคนต้องขายในวันเดียวกัน

เราจะเริ่มจากการวัดว่าส่วนไหนของราคาเป็นฟอง แล้วหาว่าเงินกู้คูณผลตอบแทนอย่างไร ราคาต้องลงแค่ไหนจึงโดนเรียกหลักประกัน คิดกองทุนในโจทย์ทีละขั้นจนถึงการขายบังคับ ดูว่าส่วนลดหลักประกัน (haircut) คุมอัตราทดของทั้งตลาดอย่างไร แยกสภาพคล่องสองแบบ เทียบขาดทุนเฉลี่ยกับขาดทุนในวิกฤต ถามว่าเหตุการณ์ “25 sigma” บอกอะไร แล้วดูว่ากฎหลังปี 2008 ตัดวงจรนี้ตรงไหน รูปด้านล่างคือเรื่องทั้งหมดในเส้นเดียว

ศัพท์ที่ใช้ในหัวข้อนี้
มูลค่าพื้นฐาน และฟองสบู่ (bubble)
มูลค่าพื้นฐานคือมูลค่าปัจจุบันของเงินสดที่สินทรัพย์จะจ่าย ฟองคือส่วนของราคาที่เกินมูลค่านั้น ใช้แยกราคาที่มีเงินสดรองรับออกจากราคาที่อยู่ได้เพราะคนเชื่อว่าจะขายต่อได้แพงกว่า
Leverage (อัตราทด)
มูลค่าสินทรัพย์หารด้วยเงินตัวเอง ใช้บอกว่ากำไรและขาดทุนของสินทรัพย์ถูกขยายกี่เท่าเมื่อถึงมือเจ้าของ
Margin และ margin call
margin คือสัดส่วนเงินตัวเองขั้นต่ำที่เจ้าหนี้กำหนด margin call คือการเรียกเงินเพิ่มเมื่อสัดส่วนต่ำกว่าเกณฑ์ ถ้าไม่มีเงินเติมต้องขายสินทรัพย์ไปคืนหนี้
Haircut
ส่วนลดที่ผู้ให้กู้หักจากมูลค่าหลักประกันก่อนให้กู้ เช่น haircut 25% แปลว่ากู้ได้ 75% ของมูลค่า ตัวเลขนี้กำหนดอัตราทดสูงสุด
Fire sale
การขายเร่งด่วนเพื่อหาเงินสด จนต้องยอมราคาต่ำกว่าปกติ เมื่อหลายรายขายพร้อมกัน ราคาที่ลงก็ทำให้รายอื่นโดนเรียกหลักประกันต่อ
Funding liquidity และ market liquidity
funding liquidity คือความสามารถหาเงินสดหรือกู้ต่อ market liquidity คือความสามารถขายของได้เร็วโดยราคาไม่ทรุด สองอย่างนี้หายพร้อมกันในวิกฤต
Stress test
การคิดขาดทุนภายใต้สถานการณ์เลวร้ายที่กำหนดไว้ล่วงหน้า ใช้ถามว่าจะรอดไหม ไม่ใช่ถามว่าโดยเฉลี่ยเสียเท่าไร

ขั้นที่ 1 — ฟองสบู่ในตัวเลข: ส่วนไหนของราคาไม่มีเงินสดรองรับ

จะพูดว่าราคา “สูงเกินไป” ได้ต้องมีของเทียบ ของเทียบคือมูลค่าปัจจุบันของเงินปันผลทั้งหมด ถ้าปันผลปีหน้า $D=\$4$ โตปีละ $g=4\%$ และผู้ถือต้องการผลตอบแทน $r=8\%$ มูลค่านี้คืออนุกรมเรขาคณิต (แบบเดียวกับมูลค่าเงินตามเวลา) แล้วดูว่าถ้าราคาในตลาดเป็น \$150 ส่วนเกินต้องทำตัวอย่างไรจึงมีคนยอมถือ

\[ \begin{aligned} F&=\sum_{t=1}^{\infty}\frac{D(1+g)^{t-1}}{(1+r)^t}=\frac{D}{r-g},\\ F&=\frac{4}{0.08-0.04}=100,\\ g=5\%&:\ F=\frac{4}{0.03}=133.33,\\ B_0&=150-100=50,\\ (1-\pi)(1+g_B)&=1+r,\\ g_B&=\frac{1.08}{0.90}-1=20\%. \end{aligned} \]

บรรทัดแรก: ปันผลปีที่ $t$ คือ $D(1+g)^{t-1}$ คิดลด $t$ ปี อัตราส่วนระหว่างพจน์ติดกันคือ $(1+g)/(1+r)$ ซึ่งน้อยกว่า 1 อนุกรมจึงรวมได้เป็น $D/(r-g)$ บรรทัดที่สามคือจุดอันตราย: ตัวหาร $r-g$ เล็ก ปรับความเชื่อเรื่องการเติบโตขึ้นแค่ 1% มูลค่าพุ่ง 33% เรื่องเล่าว่า “ครั้งนี้ไม่เหมือนเดิม” มักเป็นการขยับ $g$ แบบนี้

ส่วนเกิน $B_0=50$ ไม่มีเงินปันผลรองรับเลย คนจะยอมถือมันก็ต่อเมื่อมันให้ผลตอบแทน $r$ เหมือนกัน ถ้าฟองมีโอกาสแตก (เหลือศูนย์) ปีละ $\pi=10\%$ ฟองที่รอดต้องโตเร็วพอให้ค่าเฉลี่ยยังได้ 8% คือ 20% ต่อปี เร็วกว่ามูลค่าพื้นฐานห้าเท่า นี่คือรูปทรงของเส้นแดงในรูปด้านบน: ฟองต้องเร่งตัว ห้าปีผ่านไปฟองเป็น $50(1.2)^5=124$ แบบจำลองนี้เรียกว่า rational bubble (Blanchard และ Watson, 1982) และบอกว่าฟองไม่ต้องอาศัยความโง่ แค่ต้องมีคนเชื่อว่าจะขายต่อได้

ขั้นที่ 2 — เงินกู้คูณผลตอบแทนทั้งสองทิศ

ฟองโตได้นานเพราะคนซื้อด้วยเงินกู้ ก่อนดูกองทุนในโจทย์ ต้องรู้ว่าเงินกู้ทำอะไรกับผลตอบแทนของเจ้าของ สินทรัพย์ทั้งก้อนทำผลตอบแทน $R_A$ แต่เจ้าของต้องจ่ายดอกเบี้ย $r_L$ ให้ส่วนที่กู้ หารด้วยเงินตัวเองแล้วเขียนทุกอย่างด้วยอัตราทด

\[ \begin{aligned} R_E&=\frac{A\,R_A-L\,r_L}{E},\\ \frac{L}{E}&=\frac{A-E}{E}=\ell-1,\\ R_E&=\ell R_A-(\ell-1)r_L,\\ \ell=4,\ r_L=2\%&:\ R_E(+5\%)=0.20-0.06=14\%,\\ &\quad\ R_E(-5\%)=-0.20-0.06=-26\%. \end{aligned} \]

บรรทัดที่สองมาจาก $A=L+E$ ตรง ๆ บรรทัดที่สามจึงบอกว่าผลตอบแทนของเจ้าของคือผลตอบแทนสินทรัพย์คูณอัตราทด ลบต้นทุนเงินกู้ของส่วนที่กู้ ตัวคูณเดียวกันทำงานทั้งสองทิศ สินทรัพย์ +5% กลายเป็น +14% แต่ −5% กลายเป็น −26% และดอกเบี้ยทำให้ฝั่งขาดทุนหนักกว่าฝั่งกำไรเสมอ

ขั้นที่ 3 — ราคาต้องลงแค่ไหนจึงโดนเรียกหลักประกัน

สัญชาตญาณบอกว่าเริ่มที่เงินตัวเอง 10% เกณฑ์ 5% ราคาต้องลง 5% จึงถึงเกณฑ์ ขั้นนี้แสดงว่าผิด เพราะหนี้ไม่ลดตามราคา ขาดทุนทั้งหมดจึงตกที่เงินตัวเอง ให้ $\ell_0$ คืออัตราทดวันแรก

\[ \begin{aligned} \frac{E_t}{A_t}&=\frac{R_A+1/\ell_0}{1+R_A}\lt m,\\ R_A+\frac1{\ell_0}&\lt m+mR_A,\\ R_A&\lt-\frac{1/\ell_0-m}{1-m},\\ \ell_0=10,\ m=5\%&:\ R_A\lt-\frac{0.05}{0.95}=-5.26\%. \end{aligned} \]

บรรทัดแรกได้จาก $A_t=A_0(1+R_A)$ และ $E_t=A_t-L$ โดย $L=A_0(1-1/\ell_0)$ คงที่ เศษ (เงินตัวเอง) ลดเต็มจำนวนของขาดทุน ส่วนตัวหาร (สินทรัพย์) ลดแค่ตามสัดส่วน อัตราส่วนจึงรูดเร็วกว่าราคา คูณตัวหารขึ้นแล้วย้ายข้างได้เกณฑ์ ราคาลงแค่ 5.26% ก็ถึงเกณฑ์ ไม่ใช่ 5% และกองทุนในโจทย์ลงไป 8%

ขั้นที่ 4 — กองทุนในโจทย์: ขาดหลักประกันเท่าไร

โจทย์ให้อะไรมาบ้าง: $A_0=\$10$ ล้าน $L=\$9$ ล้าน ($\ell_0=10$) ราคาลง 8% และ $m=5\%$

\[ \begin{aligned} A&=10{,}000{,}000(1-0.08)=9{,}200{,}000,\\ E&=9{,}200{,}000-9{,}000{,}000=200{,}000,\\ mA-E&=0.05(9{,}200{,}000)-200{,}000\\ &=260{,}000. \end{aligned} \]

คำตอบ: เงินตัวเองเหลือ \$200,000 ต้องมี \$460,000 จึงขาด \$260,000 สินทรัพย์ลง 8% แต่เงินตัวเองหายไป 80%

ตรวจเองใน 10 วินาที: ขาดทุน $0.08\times10{,}000{,}000=800{,}000$ ตกที่เงินตัวเองทั้งหมด $1{,}000{,}000-800{,}000=200{,}000$ และ $200{,}000/9{,}200{,}000=2.17\%$ ต่ำกว่า 5%

ขั้นที่ 5 — ไม่มีเงินเติม: ต้องขายเท่าไร

ถ้ามีเงินสด \$260,000 ก็จบ ถ้าไม่มี ต้องขายสินทรัพย์ $x$ แล้วเอาเงินทั้งหมดไปคืนหนี้ คำถามที่ติดคือ ขาย \$260,000 พอไหม? ไม่พอ เพราะการขายไม่ได้เพิ่มเงินตัวเอง สินทรัพย์กับหนี้ลดเท่ากัน สิ่งที่เปลี่ยนคือตัวหาร ต้องขายจนเงินตัวเองกลับมาเป็น 5% ของสินทรัพย์ที่เหลือ

\[ \begin{aligned} A'&=A-x,\quad L'=L-x,\\ E'&=A'-L'=E,\\ \frac{E}{A-x}&=m,\\ x&=\frac{mA-E}{m}=\frac{260{,}000}{0.05}\\ &=5{,}200{,}000. \end{aligned} \]

เงินที่ขาดทุกดอลลาร์ต้องขายสินทรัพย์ $1/m=20$ ดอลลาร์ ขาดหลักประกัน \$260,000 จึงต้องขาย \$5.2 ล้าน หรือ 56.5% ของพอร์ตที่เหลือ ตรวจ: $200{,}000/4{,}000{,}000=5\%$ พอดี

ถ้ากองทุนหลายแห่งถือของคล้ายกันและขายพร้อมกัน ราคาจะลงต่อ ทำให้กองทุนที่ยังไม่โดนเรียกกลายเป็นโดนเรียก นี่คือ fire sale และเป็นเหตุที่เส้นแดงในรูปแรกทะลุลงต่ำกว่ามูลค่าพื้นฐาน

ขั้นที่ 6 — haircut คุมอัตราทดของทั้งตลาด

ในตลาดกู้ยืมโดยใช้หลักทรัพย์ค้ำ (repo) ผู้ให้กู้ไม่ได้บอกอัตราทดตรง ๆ แต่บอก haircut $h$ ซึ่งก็คุมอัตราทดสูงสุดอยู่ดี

\[ \begin{aligned} L&=A(1-h),\quad E=A-L=Ah,\\ \ell_{\max}&=\frac{A}{E}=\frac1h,\\ h=25\%&:\ \ell_{\max}=4,\\ h=40\%&:\ \ell_{\max}=2.5,\\ \frac{x}{A}&=1-\frac{2.5E}{4E}=37.5\%. \end{aligned} \]

เงินตัวเองคือส่วนที่กู้ไม่ได้พอดี มูลค่าสินทรัพย์ตัดกันหมด เหลืออัตราทดสูงสุดเท่ากับส่วนกลับของ haircut กองทุนที่ใช้อัตราทดเต็มที่ 4 เท่า ถ้าผู้ให้กู้ขึ้น haircut เป็น 40% ต้องลดสินทรัพย์เหลือ 2.5 เท่าของเงินตัวเอง คือขาย 37.5% ของพอร์ตทันที ทั้งที่ราคายังไม่ได้ลงเลย

ผู้ให้กู้มักขึ้น haircut ตอนตลาดแย่ซึ่งเป็นตอนที่ทุกคนต้องการเงินที่สุด Brunnermeier และ Pedersen (2009) ใช้กลไกนี้อธิบายว่าสภาพคล่องหายเป็นเกลียว (liquidity spiral)

ขั้นที่ 7 — สภาพคล่องสองแบบ หมดไม่พร้อมกัน

desk อาจมั่นใจว่าสินทรัพย์จะฟื้นใน 30 วัน แต่ถ้าผู้ให้กู้เรียกเงินวันนี้ ก็ต้องขายวันนี้ ความเสี่ยงจึงอยู่ที่เส้นทาง ไม่ใช่ราคาปลายทาง ใช้ตัวเลขสมมติสองเส้น: เงินสดสำรอง $f(t)=100-2.2t$ ลดจาก margin call และดัชนีสภาพคล่องตลาด $g(t)=100-t-0.05t^2$ ลดเร็วขึ้นเรื่อย ๆ โดยมีเกณฑ์ลงมือที่ 40

\[ \begin{aligned} f(t)=40&:\ t=\frac{60}{2.2}=27.3,\\ g(t)=40&:\ 0.05t^2+t-60=0,\\ &\quad t=26.1,\\ f(t)=g(t)&:\ 0.05t^2=1.2t,\quad t=24. \end{aligned} \]

ตลาดเริ่มขายยากกว่าเกณฑ์ในวันที่ 26.1 ก่อนเงินสดหมดในวันที่ 27.3 สองเส้นตัดกันวันที่ 24 ที่ระดับ 47.2 หลังจากนั้นสภาพคล่องตลาดแย่กว่าเงินสดสำรอง บทเรียนคือ ถ้ารอจนเงินสดใกล้หมดค่อยขาย จะได้ขายในวันที่ตลาดรับของได้แย่ที่สุด เกณฑ์ลงมือต้องดูทั้งสองเส้น

ขั้นที่ 8 — ขาดทุนเฉลี่ยไม่ใช่ขาดทุนในวิกฤต

ธนาคารตั้งสำรองด้วยขาดทุนเฉลี่ย (expected loss) ของสินเชื่อ ขาดทุนคือตัวบอกการผิดนัด $D_{\text{def}}$ (0 หรือ 1) คูณสัดส่วนที่เสีย คูณยอดที่เสี่ยง สูตรเฉลี่ยแยกเป็นผลคูณได้ก็ต่อเมื่อการผิดนัดกับความรุนแรงเป็นอิสระต่อกัน ซึ่งเป็นสมมติฐาน ไม่ใช่ข้อเท็จจริง

\[ \begin{aligned} \mathcal L&=D_{\text{def}}\cdot\mathrm{LGD}\cdot\mathrm{EAD},\\ \mathbb E[\mathcal L]&=\mathrm{PD}\cdot\mathbb E[\mathrm{LGD}]\cdot\mathrm{EAD}\\ &=0.02(0.40)(10{,}000{,}000)=80{,}000,\\ \mathcal L_{\text{crisis}}&=0.15(0.70)(10{,}000{,}000)\\ &=1{,}050{,}000. \end{aligned} \]

ในเวลาปกติ โอกาสผิดนัด 2% และเสีย 40% ของยอดเมื่อผิดนัด ขาดทุนเฉลี่ย \$80,000 ในวิกฤต ทั้งโอกาสผิดนัดและความรุนแรงขึ้นพร้อมกัน เพราะราคาบ้านที่ค้ำหนี้ก็ลงด้วย ขาดทุนเป็น \$1,050,000 หรือ 13.1 เท่า ความเป็นอิสระที่ใช้แยกผลคูณพังในวันที่สำคัญที่สุด เรื่องเดียวกับที่ทำให้CDO และ Gaussian copulaประเมินความเสี่ยงต่ำเกินในปี 2007

ตารางสถานการณ์ในรูปด้านล่างให้ภาพเดียวกัน: ขาดทุน 0.8, 3.5 และ 12.0 ล้าน ด้วยน้ำหนัก 0.70, 0.25 และ 0.05 เฉลี่ยได้ $0.56+0.875+0.60=2.035$ ล้าน แต่ถ้าวิกฤตเกิด ต้องมีทุนรับ 12.0 ล้าน การรายงานแค่ค่าเฉลี่ยจึงซ่อนคำถามว่าจะรอดไหม

ขั้นที่ 9 — “25 sigma หลายวันติด” บอกอะไร

เดือนสิงหาคม 2007 กองทุน quant ที่ใช้กลยุทธ์คล้ายกันขาดทุนพร้อมกันหลายวัน CFO ของ Goldman Sachs พูดว่าเห็นการเคลื่อนไหวระดับ 25 standard deviation หลายวันติดต่อกัน ถ้าผลตอบแทนเป็น Normal จริง โอกาสนั้นเท่าไร? ใช้ขอบเขตบนของหาง Normal แล้วคิดเป็นลอการิทึมเพื่อไม่ให้ตัวเลขเล็กเกินเครื่องคิดเลข

\[ \begin{aligned} P(Z\ge z)&\le\frac{e^{-z^2/2}}{\sqrt{2\pi}\,z},\\ \ln P(Z\ge25)&\le-0.9189-3.2189-312.5\\ &=-316.638,\\ \log_{10}P(Z\ge25)&\le\frac{-316.638}{2.302585}=-137.514,\\ P(Z\ge25)&\approx3.06\times10^{-138},\\ P_{t_3}(X\ge25)&=1.36\times10^{-5}. \end{aligned} \]

ขอบเขตบนได้จากการอินทิเกรตหางของ density ทีละส่วน และแน่นมากเมื่อ $z$ ใหญ่ ค่าจริงคือ $3.057\times10^{-138}$ ต่างจากขอบเขตแค่ 0.16% ถ้านับเวลาตั้งแต่เอกภพเกิดเป็นไมโครวินาทีจะได้ราว $4\times10^{23}$ ครั้ง เหตุการณ์ $10^{-138}$ จึงไม่ควรเกิดแม้ครั้งเดียว ถ้าแต่ละวันอิสระ สองวันติดคือราว $10^{-275}$

บรรทัดสุดท้ายใช้หางหนาแบบที่ราคาหุ้นจริงมี: t distribution ที่มี 3 degrees of freedom ปรับให้ variance เท่ากับ 1 วัน 25 SD เกิดราววันละ $1.36\times10^{-5}$ คือราวหนึ่งครั้งใน 293 ปีของวันทำการ (ปีละ 252 วัน) หายากแต่ไม่ใช่ปาฏิหาริย์

ข้อสรุปจึงไม่ใช่ “โชคร้ายสุดขีด” แต่คือ “แบบจำลองผิด” ทั้งเรื่องหางและเรื่องความเป็นอิสระ เมื่อทุกกองทุนขายของชุดเดียวกัน วันร้ายจึงต่อกัน

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

เทียบการลงของราคากับเกณฑ์ตรง ๆ: ราคาลง 5.26% ก็ถึงเกณฑ์ 5% แล้วที่อัตราทด 10 เท่า ลง 8% เงินตัวเองหาย 80%

ลืมว่าการขายไม่เพิ่มเงินตัวเอง: ขาด \$260,000 ไม่ได้แปลว่าขาย \$260,000 แล้วจบ ต้องขาย \$5.2 ล้าน

คูณ PD × LGD โดยถือว่าอิสระ: ในวิกฤตทั้งสองขึ้นพร้อมกัน ขาดทุนเฉลี่ย \$80,000 กลายเป็น \$1,050,000

เรียกเหตุการณ์ในแบบจำลองว่าเป็นไปไม่ได้: $10^{-138}$ ใต้ Normal กลายเป็นหนึ่งครั้งใน 293 ปีใต้หางหนา สิ่งที่ผิดคือแบบจำลอง

เชื่อสถิติแบบ “ตลาดหุ้นไม่เคยลงในช่วง 20 ปีใดเลย”: ช่วง 20 ปีที่ซ้อนกันในข้อมูลร้อยปีมีช่วงที่ไม่ซ้อนกันจริงแค่ราวห้าช่วง และตลาดที่ถูกยกมาพูดคือตลาดที่รอดมาให้เห็น (สหรัฐฯ) ไม่ใช่ตลาดที่หายไป ตัวเลขนี้จึงเป็นหลักฐานที่อ่อนกว่าที่ฟังดูมาก

ประเมินมูลค่าด้วยการขยับอัตราโตนิดเดียว: $g$ จาก 4% เป็น 5% ทำให้มูลค่าพื้นฐานจาก 100 เป็น 133 ราคาที่ “มีเหตุผลรองรับ” จึงยืดได้มากถ้าตัวหาร $r-g$ เล็ก

ใช้ทำอะไรบนโต๊ะจริง

ฝ่ายความเสี่ยงคำนวณจุดถูกเรียกหลักประกัน เงินที่ขาด สินทรัพย์ที่ต้องขาย และผลของการขึ้น haircut ทุกวันสำหรับทุกบัญชีที่ใช้เงินกู้ แล้วดูว่าของที่ต้องขายเหมือนกับที่คนอื่นถืออยู่แค่ไหน ถ้าเหมือนกันมาก ราคาที่ใช้คิดควรเป็นราคาขายบังคับ ไม่ใช่ราคาปิดของเมื่อวาน รู้ได้ไหมว่าตอนนี้เป็นฟองสบู่? สัญญาณที่เกิดซ้ำมีอยู่: เงินกู้โตเร็ว มาตรฐานการปล่อยกู้หย่อน และเรื่องเล่าว่า “ครั้งนี้ไม่เหมือนเดิม” แต่จังหวะแตกบอกไม่ได้ คนที่ short เร็วเกินไปอาจเจ๊งก่อนฟองแตก แบบเดียวกับดีลหุ้นสองชั้นที่ส่วนต่างถ่างก่อน จึงใช้เตรียมกันชน ไม่ใช่ใช้จับจังหวะ

โจทย์ตรวจความเข้าใจ

1. อัตราทด 5 เท่า maintenance margin 5% ราคาต้องลงเท่าไรจึงโดนเรียกหลักประกัน?

เฉลย

$R_A\lt-(0.20-0.05)/0.95=-15.79\%$ อัตราทดครึ่งหนึ่งของ 10 เท่า แต่ทนราคาลงได้ราวสามเท่า (15.79% เทียบ 5.26%) เพราะกันชน $1/\ell_0-m$ เพิ่มจาก 5% เป็น 15%

2. พอร์ต \$20 ล้าน เงินตัวเอง \$2 ล้าน ราคาลง 6% $m=5\%$ ขาดหลักประกันเท่าไร และถ้าไม่มีเงินเติมต้องขายเท่าไร?

เฉลย

สินทรัพย์ $18.8$ ล้าน เงินตัวเอง $18.8-18=0.8$ ล้าน ต้องมี $0.05(18.8)=0.94$ ล้าน ขาด \$140,000 ต้องขาย $140{,}000/0.05=\$2.8$ ล้าน ตรวจ $800{,}000/16{,}000{,}000=5\%$

3. หุ้นจ่ายปันผลปีหน้า \$4 ผู้ถือต้องการ 8% ต่อปี ถ้าฟองแตกได้ปีละ 20% ฟองต้องโตปีละเท่าไร และถ้าราคาวันนี้ \$150 ขณะที่ตลาดเชื่อว่าปันผลโต 5% ส่วนไหนเป็นฟอง?

เฉลย

ฟองต้องโต $1.08/0.80-1=35\%$ ต่อปี ยิ่งเสี่ยงแตก ยิ่งต้องเร่ง ที่ $g=5\%$ มูลค่าพื้นฐานคือ $4/0.03=133.33$ ฟองเหลือแค่ 16.67 ไม่ใช่ 50 ขนาดของฟองที่วัดได้ขึ้นกับว่าเชื่อ $g$ เท่าไร ซึ่งเป็นเหตุที่ฟองบอกได้ชัดก็ต่อเมื่อแตกแล้ว

function num(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(name + ' must be a finite number');
  return x;
}
function fraction(name, x) {
  if (!(num(name, x) > 0 && x < 1)) throw new RangeError(name + ' must be strictly between 0 and 1');
  return x;
}

// Fundamental value of a growing dividend stream, and the growth a bubble needs if it can burst each year.
function gordon(D, r, g) {
  if (!(num('r', r) > num('g', g))) throw new RangeError('need r > g');
  return num('D', D) / (r - g);
}
function bubbleGrowth(r, burst) {
  fraction('burst', burst);
  return (1 + num('r', r)) / (1 - burst) - 1;
}

// Return on equity at leverage l = A/E, asset return rA, borrowing rate rL.
function equityReturn(l, rA, rL) {
  if (!(num('l', l) >= 1)) throw new RangeError('leverage must be at least 1');
  return l * num('rA', rA) - (l - 1) * num('rL', rL);
}

// Asset return at which equity/assets falls to the maintenance margin m (debt fixed).
function marginTrigger(l, m) {
  fraction('m', m);
  if (!(1 / l > m)) throw new RangeError('starting equity share must exceed the margin');
  return -(1 / l - m) / (1 - m);
}

// After a fall, how much cash is missing, and how much must be sold (proceeds repay debt) if no cash comes in.
function marginCall({assets, debt, fall, m}) {
  fraction('m', m);
  const A = num('assets', assets) * (1 - num('fall', fall)), E = A - num('debt', debt);
  if (E <= 0) throw new RangeError('equity is wiped out: this is default, not a margin call');
  const shortfall = Math.max(m * A - E, 0);
  return {A, E, shortfall, sell: shortfall / m, soldShare: shortfall / m / A};
}

// log10 of the standard Normal upper tail, via the continued fraction of the Mills ratio (no underflow).
function normalTailLog10(z) {
  if (!(num('z', z) > 0)) throw new RangeError('z must be positive');
  let f = z;
  for (let k = 200; k >= 1; k--) f = z + k / f;
  return (Math.log(1 / f) - z * z / 2 - 0.5 * Math.log(2 * Math.PI)) / Math.LN10;
}

// Upper tail of a Student-t with 3 degrees of freedom rescaled to variance 1, at k standard deviations.
function t3Tail(k) {
  const x = num('k', k);                       // T / sqrt(3) has variance 1, so P(X > k) = P(T > k sqrt 3)
  return 0.5 - (Math.atan(x) + x / (1 + x * x)) / Math.PI;
}

const bound = -0.5 * Math.log10(2 * Math.PI) - Math.log10(25) - 312.5 / Math.LN10;
const exact = normalTailLog10(25);

สิ่งที่ควรตอบได้หลังอ่าน

  • ฟองคือส่วนของราคาที่เกินมูลค่าปัจจุบันของเงินปันผล และถ้ามันแตกได้ มันต้องโตเร็วกว่าผลตอบแทนที่ผู้ถือต้องการ (20% เทียบ 8% ในตัวอย่าง)
  • อัตราทดคูณผลตอบแทนทั้งสองทิศ: +5% เป็น +14% แต่ −5% เป็น −26% ที่ 4 เท่า และที่ 10 เท่า ราคาลงแค่ 5.26% ก็ถึงเกณฑ์ 5%
  • ขาดหลักประกัน \$260,000 โดยไม่มีเงินเติม ต้องขาย \$5.2 ล้าน เพราะทุกดอลลาร์ที่ขาดต้องขาย $1/m$ ดอลลาร์ และ haircut คุมอัตราทดสูงสุด $1/h$
  • ขาดทุนเฉลี่ยซ่อนวิกฤต (80,000 เทียบ 1,050,000) เพราะโอกาสผิดนัดกับความรุนแรงขึ้นพร้อมกัน
  • “25 sigma” คือหลักฐานว่าแบบจำลองผิด ไม่ใช่โชคร้าย: $3\times10^{-138}$ ใต้ Normal แต่หนึ่งครั้งใน 293 ปีใต้หางหนา
