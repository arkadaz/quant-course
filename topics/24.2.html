24.2 Bubbles, Crises, and Regulation

เงินกู้ทำให้ราคาที่ลงนิดเดียวกลายเป็นการขายบังคับครั้งใหญ่ และเมื่อทุกคนขายพร้อมกัน ความเสี่ยงไม่ได้มาจากโชคร้าย แต่มาจากการที่ทุกคนผูกกันด้วยเงินกู้

กองทุนแห่งหนึ่งซื้อสินเชื่อบ้านมัดรวม (mortgage pool) มาถือไว้ สินเชื่อบ้านมัดรวมคือหนี้บ้านหลายพันสัญญาที่มัดเป็นก้อนเดียวแล้วซื้อขายกันได้ คนถือก้อนนี้ได้เงินผ่อนบ้านทุกเดือน

กองทุนจ่ายค่าก้อนนี้ด้วยเงินกู้เกือบทั้งหมด ส่วนเจ้าหนี้ก็ป้องกันตัวเองด้วยกฎข้อเดียว คือเงินของกองทุนเองต้องเหลืออย่างน้อย 5% ของมูลค่าก้อนนี้เสมอ ถ้าต่ำกว่านั้น เจ้าหนี้จะเรียกเงินเพิ่มทันที

ของที่รู้ (ตัวเลขสมมติทั้งหมด):

  • มูลค่าสินทรัพย์ (ราคาตลาดของสินเชื่อบ้านมัดรวมทั้งก้อน) $A_0=\$10$ ล้าน
  • เงินตัวเองของกองทุน $E_0=\$1$ ล้าน
  • เงินกู้ $L=A_0-E_0=10-1=\$9$ ล้าน
  • เกณฑ์ของเจ้าหนี้ $m=5\%$ เรียกว่า maintenance margin คือเงินตัวเองต้องไม่ต่ำกว่า 5% ของมูลค่าสินทรัพย์ในวันนั้น

วันนี้เงินตัวเองคิดเป็น $E_0/A_0=1/10=10\%$ ของสินทรัพย์ แล้ววันหนึ่งราคาของก้อนนี้ลง 8%

ผู้จัดการกองทุนคิดว่า “ราคาลง 8% ก็แค่ทำให้ทุกอย่างในพอร์ตเล็กลง 8% เงินตัวเองยังเป็น 10% ของสินทรัพย์เหมือนเดิม สูงกว่าเกณฑ์ 5% สบาย ๆ ยังไม่ต้องทำอะไร”

ผู้จัดการคิดถูกไหม และถ้ากองทุนไม่มีเงินสดมาเติม ต้องขายสินทรัพย์เท่าไร?

ลองตอบก่อนเปิดเฉลย

ผิด เพราะราคาที่ลงทำให้สินทรัพย์เล็กลง แต่หนี้ไม่เล็กลงตาม หนี้ยังเป็น \$9 ล้านเท่าเดิม ขาดทุนทั้งหมดจึงไปตกที่เงินตัวเอง (หน่วยเป็นล้านดอลลาร์)

\[\begin{aligned}A&=10\times(1-0.08)=9.2,\\E&=A-L=9.2-9=0.2,\\\frac{E}{A}&=\frac{0.2}{9.2}=2.17\%\lt5\%.\end{aligned}\]

เงินตัวเองเหลือ \$200,000 ต่ำกว่าเกณฑ์แล้ว เจ้าหนี้อยากเห็นเงินตัวเอง $0.05\times9.2=\$0.46$ ล้าน จึงขาดอยู่ $0.46-0.2=\$0.26$ ล้าน หรือ \$260,000 ถ้าไม่มีเงินเติม ต้องขายสินทรัพย์ \$5.2 ล้าน คิดเป็น $5.2/9.2=56.5\%$ ของพอร์ต หน้านี้จะคำนวณตัวเลข \$5.2 ล้านให้ดูทีละขั้น

สังเกตว่าราคาลงแค่ 8% คือขาดทุน $10\times0.08=\$0.8$ ล้าน แต่ก้อนนี้เท่ากับ $0.8/1=80\%$ ของเงินตัวเอง และถ้ากองทุนหลายแห่งต้องขายของแบบเดียวกันพร้อมกัน ราคาจะลงต่ออีก

ภาพรวมก่อนลงสูตร

หน้า market efficiency และ limits to arbitrage เล่าเรื่องของดีลเดียว คนที่ซื้อด้วยเงินกู้อาจถูกบังคับปิดดีลก่อนที่ความคิดของเขาจะพิสูจน์ว่าถูก หน้านี้ขยายเรื่องเดียวกันจากคนเดียวไปเป็นทั้งตลาด

มีสองคำที่ต้องรู้ก่อน คำแรกคือฟองสบู่ (bubble) หมายถึงช่วงที่ราคาของบางอย่างสูงเกินกว่าที่เงินสดที่มันจะจ่ายในอนาคตอธิบายได้ คำที่สองคือวิกฤต หมายถึงช่วงที่เงินกู้ซึ่งใช้ของราคาแพงเหล่านั้นค้ำไว้ถูกเรียกคืนพร้อมกัน ทุกคนจึงต้องขายในวันเดียวกัน ราคาจึงไม่ได้แค่ลงมาเท่ามูลค่าจริง แต่ทะลุลงไปต่ำกว่า

ลำดับของหน้านี้:

  • วัดว่าส่วนไหนของราคาเป็นฟอง และทำไมฟองต้องโตเร็ว
  • ดูว่าเงินกู้ขยายกำไรและขาดทุนของเจ้าของอย่างไร
  • หาว่าราคาต้องลงแค่ไหน เจ้าหนี้จึงเรียกเงินเพิ่ม
  • คิดกองทุนในโจทย์ทีละขั้น จนถึงยอดที่ต้องขาย
  • haircut (ส่วนที่ผู้ให้กู้หักออกจากมูลค่าของที่เอามาค้ำ) คุมเงินกู้ของทั้งตลาดอย่างไร
  • สภาพคล่องสองแบบ คือหาเงินสดได้ไหม กับขายของได้ไหม
  • ขาดทุนเฉลี่ยต่างจากขาดทุนในวิกฤตแค่ไหน
  • คำพูดว่าเห็นการขยับขนาด “25 sigma” บอกอะไรเรา
  • กฎที่ออกหลังวิกฤตปี 2008 ตัดวงจรนี้ตรงไหน

รูปด้านล่างเล่าเรื่องทั้งหมดไว้ในกราฟเดียว

ศัพท์ที่ใช้ในหัวข้อนี้
มูลค่าพื้นฐาน และฟองสบู่ (bubble)
มูลค่าพื้นฐานคือเงินสดทั้งหมดที่สินทรัพย์จะจ่ายในอนาคต (เช่นเงินปันผลของหุ้น) แปลงเป็นเงินวันนี้แล้วรวมกัน ฟองคือส่วนของราคาที่เกินมูลค่านี้ ส่วนนี้ไม่มีเงินสดรองรับ มันอยู่ได้เพราะคนเชื่อว่าจะขายต่อให้คนอื่นได้แพงกว่า
สินทรัพย์ หนี้ และเงินตัวเอง
สินทรัพย์คือของทั้งหมดที่กองทุนถืออยู่ คิดตามราคาตลาด หนี้คือเงินที่กู้มา เงินตัวเอง (equity) คือส่วนที่เหลือของเจ้าของ เท่ากับสินทรัพย์ลบหนี้
Leverage (อัตราทด)
มูลค่าสินทรัพย์หารด้วยเงินตัวเอง เช่นเงินตัวเอง \$1 ล้าน ถือของ \$10 ล้าน คืออัตราทด 10 เท่า ตัวเลขนี้บอกว่ากำไรหรือขาดทุนของสินทรัพย์ถูกขยายกี่เท่าเมื่อไปถึงเจ้าของ
หลักประกัน (collateral)
ของที่ผู้กู้วางไว้กับเจ้าหนี้เพื่อค้ำเงินกู้ ถ้าผู้กู้ไม่จ่ายหนี้ เจ้าหนี้ยึดของนี้ไปขายได้ ในหน้านี้ หลักประกันคือสินทรัพย์ที่กองทุนซื้อมาด้วยเงินกู้นั่นเอง
Maintenance margin และ margin call
maintenance margin คือสัดส่วนขั้นต่ำของเงินตัวเองต่อสินทรัพย์ที่เจ้าหนี้กำหนด margin call (การเรียกหลักประกัน) คือตอนที่สัดส่วนนี้ต่ำกว่าเกณฑ์ แล้วเจ้าหนี้เรียกเงินสดเพิ่ม ถ้าไม่มีเงินเติม ผู้กู้ต้องขายสินทรัพย์ไปคืนหนี้
Repo และ haircut
repo คือการกู้เงินระยะสั้นโดยเอาหลักทรัพย์ไปวางค้ำ แล้วตกลงซื้อหลักทรัพย์นั้นคืนภายหลัง haircut คือส่วนที่ผู้ให้กู้หักออกจากมูลค่าหลักประกันก่อนให้กู้ เช่น haircut 25% แปลว่าของมูลค่า \$100 กู้ได้แค่ \$75 haircut จึงกำหนดอัตราทดสูงสุดไปในตัว
Fire sale (การขายเทกระจาด)
การขายแบบรีบร้อนเพื่อหาเงินสด จนต้องยอมขายถูกกว่าปกติ เมื่อหลายรายขายของแบบเดียวกันพร้อมกัน ราคาที่ลงทำให้รายอื่นโดนเรียกหลักประกันต่อเป็นทอด ๆ
Funding liquidity และ market liquidity
สภาพคล่องมีสองแบบ funding liquidity คือหาเงินสดหรือกู้ต่อได้ไหม market liquidity คือขายของได้เร็วไหมโดยที่ราคาไม่ทรุด ในวิกฤต สองอย่างนี้หายไปพร้อมกัน
Expected loss, PD, LGD, EAD
expected loss คือขาดทุนเฉลี่ยจากเงินที่ปล่อยกู้ คิดจากสามตัว PD (probability of default) คือโอกาสที่ลูกหนี้จะไม่จ่าย LGD (loss given default) คือสัดส่วนของยอดหนี้ที่เสียจริงเมื่อลูกหนี้ไม่จ่าย หลังยึดของค้ำไปขายแล้ว EAD (exposure at default) คือยอดหนี้ที่ค้างอยู่ตอนลูกหนี้หยุดจ่าย
Sigma (SD)
SD (standard deviation) ของผลตอบแทนรายวัน คือขนาดการขยับ “ปกติ” ของราคาในหนึ่งวัน การขยับ “25 sigma” คือวันที่ราคาขยับมากเป็น 25 เท่าของขนาดปกตินั้น
Stress test
การคิดขาดทุนในสถานการณ์เลวร้ายที่ตั้งไว้ล่วงหน้า ใช้ถามว่า “ถ้าเกิดเรื่องนี้ เงินทุนพอรับไหม” ไม่ได้ถามว่าโดยเฉลี่ยจะเสียเท่าไร

ขั้นที่ 1 — ฟองสบู่ในตัวเลข: ส่วนไหนของราคาไม่มีเงินสดรองรับ

จะบอกว่าราคา “แพงเกินไป” ได้ ต้องมีไม้บรรทัดไว้เทียบก่อน ไม้บรรทัดนั้นคือมูลค่าพื้นฐาน คือเงินปันผลทุกปีที่หุ้นจะจ่ายไปตลอด แปลงเป็นเงินวันนี้แล้วรวมกัน ตัวอย่างของหน้านี้ใช้หุ้นสมมติหนึ่งตัว:

  • เงินปันผลปีหน้า $D=\$4$ ต่อหุ้น
  • ปันผลโตปีละ $g=4\%$
  • ผลตอบแทนที่ผู้ถือต้องการ $r=8\%$ ต่อปี คือถ้าหุ้นให้ไม่ถึง 8% ต่อปี เขาจะไม่ถือ ตัวเลขนี้จึงใช้เป็นอัตราคิดลดเงินในอนาคตให้เป็นเงินวันนี้

ปันผลปีที่ $t$ คือ $D(1+g)^{t-1}$ และเงินที่ได้ในอีก $t$ ปีต้องหารด้วย $(1+r)^t$ จึงเป็นเงินวันนี้ (วิธีเดียวกับหน้ามูลค่าเงินตามเวลา) ผลรวมจึงเป็นอนุกรมเรขาคณิต

\[ \begin{aligned} F&=\frac{D}{1+r}+\frac{D(1+g)}{(1+r)^2}+\cdots\\ &=\frac{D/(1+r)}{1-\frac{1+g}{1+r}}=\frac{D}{r-g},\\ F&=\frac{4}{0.08-0.04}=\$100,\\ g=5\%&:\ F=\frac{4}{0.08-0.05}=\$133.33. \end{aligned} \]

แต่ละพจน์เท่ากับพจน์ก่อนหน้าคูณ $\frac{1+g}{1+r}=\frac{1.04}{1.08}$ ซึ่งน้อยกว่า 1 เพราะ $g\lt r$ ปันผลที่ไกลออกไปจึงมีค่าในวันนี้น้อยลงเรื่อย ๆ อนุกรมจึงรวมได้เป็นตัวเลขจำกัด ใช้สูตรผลรวมอนุกรมเรขาคณิต พจน์แรกหารด้วย 1 ลบอัตราส่วน แล้วคูณ $(1+r)$ ทั้งเศษและส่วนก็ได้ $D/(r-g)$

จุดอันตรายอยู่ที่ตัวหาร $r-g$ ซึ่งเป็นตัวเลขเล็ก ถ้าเชื่อว่าปันผลจะโตเร็วขึ้นแค่ 1 จุด จาก 4% เป็น 5% ตัวหารหดจาก 0.04 เหลือ 0.03 มูลค่าจึงพุ่ง $133.33/100-1=33\%$ เรื่องเล่าว่า “ครั้งนี้ไม่เหมือนเดิม” มักเป็นการขยับ $g$ ขึ้นนิดเดียวแบบนี้

ทีนี้สมมติว่าหุ้นตัวนี้ซื้อขายกันในตลาดที่ราคา \$150 ส่วนที่เกินมูลค่าพื้นฐานคือฟอง $B_0$ ฟองไม่จ่ายปันผลเลย แล้วทำไมยังมีคนยอมถือ? คนจะถือก็ต่อเมื่อฟองให้ผลตอบแทนเฉลี่ย 8% ต่อปีเท่ากับของอื่น สมมติว่าฟองมีโอกาสแตก (ราคาส่วนนี้หายไปเหลือศูนย์) ปีละ $\pi=10\%$ และถ้ายังไม่แตก ฟองโตปีละ $g_B$ เราอยากรู้ว่า $g_B$ ต้องเป็นเท่าไร

\[ \begin{aligned} B_0&=150-100=\$50,\\ \mathbb E[B_1]&=(1-\pi)B_0(1+g_B)+\pi\times0,\\ (1-\pi)B_0(1+g_B)&=B_0(1+r),\\ g_B&=\frac{1+r}{1-\pi}-1\\ &=\frac{1.08}{0.90}-1=20\%,\\ B_5&=50\times1.2^5=\$124.4. \end{aligned} \]

ค่าเฉลี่ยของฟองปีหน้ามาจากสองกรณี ใน 90% ของกรณีฟองรอดและโตเป็น $B_0(1+g_B)$ อีก 10% ฟองแตกเหลือศูนย์ คนจะยอมถือก็ต่อเมื่อค่าเฉลี่ยนี้เท่ากับเงินที่ได้ถ้าโต 8% คือ $B_0(1+r)$ เพราะฟองไม่มีปันผล ผลตอบแทนทั้งหมดต้องมาจากการที่ราคาโตขึ้น และเพราะบางปีมันหายเกลี้ยง ปีที่รอดจึงต้องโตมากกว่า 8% เพื่อชดเชย

คำตอบคือ 20% ต่อปี เร็วกว่ามูลค่าพื้นฐานถึง $20/4=5$ เท่า นี่คือเหตุที่เส้นแดงในรูปด้านบนโค้งขึ้นเร็วขึ้นเรื่อย ๆ ฟองที่ยังไม่แตกต้องเร่งตัว ห้าปีผ่านไปฟองเป็น \$124.4 แบบจำลองนี้เรียกว่า rational bubble (Blanchard และ Watson, 1982) สิ่งที่มันบอกคือฟองไม่ต้องอาศัยคนโง่ แค่ต้องมีคนเชื่อว่าจะขายต่อได้

ขั้นที่ 2 — เงินกู้คูณผลตอบแทนทั้งสองทิศ

ฟองโตได้นานเพราะคนจำนวนมากซื้อด้วยเงินกู้ ก่อนกลับไปที่กองทุนในโจทย์ เราต้องรู้ก่อนว่าเงินกู้ทำอะไรกับกำไรขาดทุนของเจ้าของ

ให้กองทุนมีสินทรัพย์ $A$ ซื้อด้วยเงินตัวเอง $E$ กับเงินกู้ $L$ ดังนั้น $A=L+E$ และอัตราทดคือ $\ell=A/E$ ในหนึ่งช่วงเวลา สินทรัพย์ทั้งก้อนให้ผลตอบแทน $R_A$ (เช่น +5% คือมูลค่าโตขึ้น 5%) แต่เจ้าของต้องจ่ายดอกเบี้ย $r_L$ ให้เงินที่กู้มา กำไรเป็นดอลลาร์ของเจ้าของจึงเป็น $A\,R_A-L\,r_L$ เอากำไรนี้หารด้วยเงินตัวเองก็ได้ผลตอบแทนของเจ้าของ $R_E$

\[ \begin{aligned} R_E&=\frac{A\,R_A-L\,r_L}{E}=\frac{A}{E}R_A-\frac{L}{E}r_L,\\ \frac{L}{E}&=\frac{A-E}{E}=\ell-1,\\ R_E&=\ell R_A-(\ell-1)r_L. \end{aligned} \]

ลองใส่ตัวเลขสมมติ อัตราทด $\ell=4$ (เงินตัวเอง \$1 ถือของ \$4) และดอกเบี้ยเงินกู้ $r_L=2\%$ แล้วดูสองกรณี สินทรัพย์ขึ้น 5% กับลง 5%

\[ \begin{aligned} R_E(+5\%)&=4(0.05)-3(0.02)\\ &=0.20-0.06=14\%,\\ R_E(-5\%)&=4(-0.05)-3(0.02)\\ &=-0.20-0.06=-26\%. \end{aligned} \]

สูตรบอกว่าผลตอบแทนของเจ้าของคือผลตอบแทนของสินทรัพย์คูณอัตราทด แล้วลบดอกเบี้ยของส่วนที่กู้ ขั้นที่ทำให้สูตรสั้นลงคือเขียน $L/E$ เป็น $\ell-1$ ซึ่งทำได้เพราะหนี้คือสินทรัพย์ลบเงินตัวเอง

ตัวคูณ $\ell=4$ ทำงานทั้งสองทิศ สินทรัพย์ +5% กลายเป็น +14% แต่สินทรัพย์ −5% กลายเป็น −26% ฝั่งขาดทุนหนักกว่าฝั่งกำไรเสมอ เพราะดอกเบี้ย $(\ell-1)r_L=3(0.02)=6\%$ ถูกหักทั้งตอนกำไรและตอนขาดทุน

ขั้นที่ 3 — ราคาต้องลงแค่ไหนจึงโดนเรียกหลักประกัน

ผู้จัดการในโจทย์คิดว่าราคาลงแล้วทุกอย่างหดเท่ากัน สัดส่วนเงินตัวเองจึงยังเป็น 10% ความคิดนี้จะถูกก็ต่อเมื่อหนี้หดตามราคาด้วย แต่หนี้เป็นตัวเลขดอลลาร์ที่ตกลงกันไว้ ราคาของจะลงแค่ไหน หนี้ก็ยังเท่าเดิม ขาดทุนทุกดอลลาร์จึงไปตกที่เงินตัวเอง ขั้นนี้หาว่าราคาลงได้มากที่สุดเท่าไรก่อนสัดส่วนเงินตัวเองจะต่ำกว่าเกณฑ์ $m$

ให้วันแรกมีสินทรัพย์ $A_0$ และอัตราทด $\ell_0=A_0/E_0$ แล้วราคาเปลี่ยนไป $R_A$ (ติดลบเมื่อราคาลง) หนี้ $L$ คงที่

\[ \begin{aligned} A_t&=A_0(1+R_A),\\ L&=A_0-E_0=A_0\left(1-\tfrac{1}{\ell_0}\right),\\ E_t&=A_t-L=A_0\left(R_A+\tfrac{1}{\ell_0}\right),\\ \frac{E_t}{A_t}&=\frac{R_A+1/\ell_0}{1+R_A}\lt m,\\ R_A+\frac1{\ell_0}&\lt m+mR_A,\\ R_A(1-m)&\lt-\left(\frac1{\ell_0}-m\right),\\ R_A&\lt-\frac{1/\ell_0-m}{1-m}. \end{aligned} \]

ใส่ตัวเลขของกองทุนในโจทย์ อัตราทด $\ell_0=10/1=10$ และเกณฑ์ $m=5\%$

\[ R_A\lt-\frac{0.10-0.05}{1-0.05}=-\frac{0.05}{0.95}=-5.26\%. \]

ดูที่สัดส่วน $E_t/A_t$ เศษคือเงินตัวเอง ซึ่งลดลงเต็มจำนวนของขาดทุน ส่วนตัวหารคือสินทรัพย์ ซึ่งลดลงแค่ตามเปอร์เซ็นต์ของราคา เศษจึงหดเร็วกว่าตัวหารมาก สัดส่วนจึงรูดลงเร็วกว่าราคา

ขั้นที่ต้องระวังคือการคูณ $(1+R_A)$ ข้ามไปอีกข้างของอสมการ ทำได้โดยเครื่องหมายไม่กลับ เพราะ $1+R_A$ เป็นบวกเสมอ (ราคาลงได้ไม่เกิน 100%) ผลคือราคาลงแค่ 5.26% กองทุนก็ถึงเกณฑ์แล้ว แต่กองทุนในโจทย์ลงไปถึง 8% จึงเลยเส้นไปแล้ว

ขั้นที่ 4 — กองทุนในโจทย์: ขาดหลักประกันเท่าไร

ตอนนี้กลับมาที่กองทุนในโจทย์เปิดหน้า เรารู้แล้วว่ามันเลยเส้นไปแล้ว คำถามต่อไปคือ เจ้าหนี้จะเรียกเงินเพิ่มเท่าไร ยอดนี้คือเงินที่ต้องเติม เพื่อให้เงินตัวเองกลับมาเป็น 5% ของสินทรัพย์

โจทย์ให้อะไรมาบ้าง:

  • สินทรัพย์วันแรก $A_0=\$10$ ล้าน
  • หนี้ $L=\$9$ ล้าน (อัตราทด $\ell_0=10/1=10$ เท่า)
  • ราคาลง 8%
  • เกณฑ์ของเจ้าหนี้ $m=5\%$
\[ \begin{aligned} A&=10{,}000{,}000\times(1-0.08)\\ &=\$9{,}200{,}000,\\ E&=A-L=9{,}200{,}000-9{,}000{,}000\\ &=\$200{,}000,\\ mA&=0.05\times9{,}200{,}000=\$460{,}000,\\ mA-E&=460{,}000-200{,}000=\$260{,}000. \end{aligned} \]

คำตอบ: เงินตัวเองเหลือ \$200,000 แต่เจ้าหนี้อยากเห็น $mA=\$460{,}000$ กองทุนจึงขาดอยู่ \$260,000 ยอดนี้คือ margin call ที่เจ้าหนี้จะเรียก สินทรัพย์ลงแค่ 8% แต่เงินตัวเองหายไปถึง 80%

ตรวจเองใน 10 วินาที: ขาดทุนคือ $0.08\times10{,}000{,}000=\$800{,}000$ ก้อนนี้ตกที่เงินตัวเองทั้งหมด จึงเหลือ $1{,}000{,}000-800{,}000=\$200{,}000$ คิดเป็น $800{,}000/1{,}000{,}000=80\%$ ของเงินตัวเองที่หายไป และสัดส่วนที่เหลือคือ $200{,}000/9{,}200{,}000=2.17\%$ ต่ำกว่า 5%

ขั้นที่ 5 — ไม่มีเงินเติม: ต้องขายเท่าไร

ถ้ากองทุนมีเงินสด \$260,000 ก็จ่ายเจ้าหนี้แล้วจบ ถ้าไม่มี ทางเดียวคือขายสินทรัพย์ออกไปมูลค่า $x$ แล้วเอาเงินที่ได้ทั้งหมดไปคืนหนี้

คนส่วนใหญ่ตอบว่าขาย \$260,000 ก็พอ ลองคิดดู สินทรัพย์เหลือ $9{,}200{,}000-260{,}000=\$8{,}940{,}000$ ส่วนเงินตัวเองยังเป็น \$200,000 สัดส่วนจึงเป็น $200{,}000/8{,}940{,}000=2.24\%$ ยังต่ำกว่า 5% อยู่มาก ทำไมไม่พอ? เพราะการขายของแล้วเอาเงินไปคืนหนี้ ทำให้สินทรัพย์กับหนี้ลดลงเท่ากัน เงินตัวเองจึงไม่เพิ่มเลย สิ่งเดียวที่เปลี่ยนคือตัวหาร ต้องขายจนเงินตัวเอง \$200,000 กลายเป็น 5% ของสินทรัพย์ที่เหลือ

\[ \begin{aligned} A'&=A-x,\quad L'=L-x,\\ E'&=A'-L'=A-L=E,\\ \frac{E}{A-x}&=m,\\ mA-mx&=E,\\ x&=\frac{mA-E}{m}=\frac{260{,}000}{0.05}\\ &=\$5{,}200{,}000. \end{aligned} \]

สูตรบอกว่ายอดที่ต้องขายคือเงินที่ขาด $mA-E$ หารด้วย $m$ เหตุผลคือ ขายสินทรัพย์ไป \$1 เจ้าหนี้ก็ลดยอดเงินตัวเองที่อยากเห็นลงแค่ $m=\$0.05$ เงินที่ขาดทุก \$1 จึงต้องขายสินทรัพย์ $1/m=1/0.05=\$20$ ขาด \$260,000 จึงต้องขาย $260{,}000\times20=\$5.2$ ล้าน คิดเป็น $5.2/9.2=56.5\%$ ของพอร์ต

ตรวจ: หลังขาย สินทรัพย์เหลือ $9.2-5.2=\$4.0$ ล้าน เงินตัวเองยังเป็น \$200,000 และ $200{,}000/4{,}000{,}000=5\%$ พอดี

ทีนี้ลองคิดว่ามีกองทุนหลายแห่งถือของคล้ายกัน และต้องขายพร้อมกัน ราคาจะลงต่อ กองทุนที่เมื่อวานยังไม่เลยเส้นก็กลายเป็นเลยเส้น แล้วต้องขายบ้าง การขายแบบรีบร้อนต่อกันเป็นทอด ๆ นี้เรียกว่า fire sale (การขายเทกระจาด) นี่คือเหตุที่เส้นแดงในรูปแรกทะลุลงไปต่ำกว่ามูลค่าพื้นฐาน

ขั้นที่ 6 — haircut คุมอัตราทดของทั้งตลาด

กองทุนอย่างในโจทย์มักกู้เงินจากตลาด repo คือเอาหลักทรัพย์ที่ถืออยู่ไปวางค้ำ แล้วกู้เงินสดระยะสั้นมา ผู้ให้กู้ในตลาดนี้ไม่ได้บอกว่า “ห้ามใช้อัตราทดเกินเท่านี้” ตรง ๆ แต่บอก haircut $h$ คือส่วนของมูลค่าหลักประกันที่เขาไม่ยอมให้กู้ เช่น $h=25\%$ แปลว่าของมูลค่า \$100 กู้ได้แค่ \$75 ส่วนที่เหลือผู้กู้ต้องใช้เงินตัวเอง ขั้นนี้แสดงว่า haircut คือเพดานอัตราทดที่แอบอยู่

\[ \begin{aligned} L&=A(1-h),\\ E&=A-L=Ah,\\ \ell_{\max}&=\frac{A}{E}=\frac{A}{Ah}=\frac1h,\\ h=25\%&:\ \ell_{\max}=\frac{1}{0.25}=4,\\ h=40\%&:\ \ell_{\max}=\frac{1}{0.40}=2.5. \end{aligned} \]

เงินตัวเองคือส่วนที่กู้ไม่ได้พอดี คือ $h$ ส่วนของสินทรัพย์ เมื่อหาอัตราทด $A/E$ ตัว $A$ ตัดกันหมด เหลืออัตราทดสูงสุดเท่ากับ $1/h$ ไม่ว่าพอร์ตจะใหญ่แค่ไหน

ทีนี้ดูว่าเกิดอะไรขึ้นถ้าผู้ให้กู้ขึ้น haircut กลางทาง สมมติกองทุนใช้อัตราทดเต็มเพดาน 4 เท่า คือสินทรัพย์ $A=4E$ แล้ววันหนึ่งผู้ให้กู้ขึ้น haircut จาก 25% เป็น 40% ราคายังไม่ได้ลงเลย เงินตัวเอง $E$ จึงเท่าเดิม แต่เพดานใหม่ให้ถือสินทรัพย์ได้แค่ $2.5E$ ส่วนที่เกินต้องขายไปคืนหนี้

\[ \begin{aligned} x&=4E-2.5E=1.5E,\\ \frac{x}{A}&=\frac{1.5E}{4E}=37.5\%. \end{aligned} \]

กองทุนต้องขาย 37.5% ของพอร์ตทันที ทั้งที่ราคาไม่ได้ลงแม้แต่ดอลลาร์เดียว การขายนี้เกิดจากการตัดสินใจของผู้ให้กู้ล้วน ๆ

ปัญหาคือผู้ให้กู้มักขึ้น haircut ตอนตลาดแย่ ซึ่งเป็นตอนที่ทุกคนต้องการเงินมากที่สุด การขายรอบนี้ทำให้ราคาลง ราคาที่ลงทำให้ผู้ให้กู้กลัวจนขึ้น haircut อีก แล้วก็ต้องขายอีก Brunnermeier และ Pedersen (2009) เรียกวงจรนี้ว่า liquidity spiral (เกลียวสภาพคล่อง)

ขั้นที่ 7 — สภาพคล่องสองแบบ หมดไม่พร้อมกัน

ทีมเทรดอาจมั่นใจว่าสินทรัพย์จะฟื้นภายใน 30 วัน แต่ถ้าผู้ให้กู้เรียกเงินวันนี้ ก็ต้องขายวันนี้ ความเสี่ยงจึงอยู่ที่ระหว่างทาง ไม่ได้อยู่ที่ราคาปลายทาง ระหว่างทางมีของสองอย่างที่หมดได้ และมันหมดไม่พร้อมกัน

  • funding liquidity คือเงินสดสำรองที่กองทุนเหลือไว้จ่าย margin call
  • market liquidity คือตลาดยังรับซื้อของได้ดีแค่ไหน ถ้าต่ำ การขายแต่ละครั้งจะกดราคาลงมาก

ใช้ตัวเลขสมมติวัดทั้งสองอย่างเป็นคะแนนเต็ม 100 ในวันที่ $t$ ของช่วงตึงเครียด:

  • เงินสดสำรอง $C(t)=100-2.2t$ ลดลงวันละ 2.2 คะแนนเท่า ๆ กัน เพราะต้องจ่าย margin call ทุกวัน
  • ดัชนีสภาพคล่องตลาด $M(t)=100-t-0.05t^2$ ลดเร็วขึ้นเรื่อย ๆ เพราะคนแห่ขายมากขึ้นทุกวัน
  • เกณฑ์ลงมือ 40 คะแนน คือถ้าเส้นไหนลงถึง 40 ทีมต้องเริ่มลดพอร์ต

คำถามคือ เส้นไหนถึงเกณฑ์ก่อน และสองเส้นสลับกันตอนไหน

\[ \begin{aligned} C(t)=40&:\ 100-2.2t=40,\\ &\quad t=\frac{60}{2.2}=27.3,\\ M(t)=40&:\ 0.05t^2+t-60=0,\\ &\quad t=\frac{-1+\sqrt{1+4(0.05)(60)}}{2(0.05)}\\ &\quad\ \ =\frac{-1+\sqrt{13}}{0.1}=26.1,\\ C(t)=M(t)&:\ 0.05t^2=1.2t,\\ &\quad t=\frac{1.2}{0.05}=24,\\ &\quad C(24)=100-2.2(24)=47.2. \end{aligned} \]

เส้นตรงหาวันถึงเกณฑ์ได้ด้วยการย้ายข้างธรรมดา ส่วนเส้นโค้งเป็นสมการกำลังสอง จึงใช้สูตรรากของสมการกำลังสอง แล้วเลือกรากที่เป็นบวกเพราะวันติดลบไม่มีความหมาย จุดตัดของสองเส้นหาได้จากการตั้ง $C(t)=M(t)$ ตัด 100 ทั้งสองข้างทิ้งแล้วจัดรูปได้ $0.05t^2=1.2t$ หารด้วย $t$ ได้ (เพราะสนใจ $t\gt0$)

ผลคือ ตลาดลงถึงเกณฑ์ในวันที่ 26.1 ก่อนเงินสดจะถึงเกณฑ์ในวันที่ 27.3 ทั้งที่ช่วงแรกเส้นตลาดอยู่สูงกว่า สองเส้นสลับกันในวันที่ 24 ที่ระดับ 47.2 หลังจากนั้นตลาดแย่กว่าเงินสดตลอด บทเรียนคือ ถ้ารอให้เงินสดใกล้หมดก่อนค่อยขาย จะได้ขายในวันที่ตลาดรับของได้แย่ที่สุด เกณฑ์ลงมือจึงต้องดูทั้งสองเส้น

ขั้นที่ 8 — ขาดทุนเฉลี่ยไม่ใช่ขาดทุนในวิกฤต

ธนาคารที่ปล่อยกู้ซื้อบ้านต้องกันเงินส่วนหนึ่งไว้รับหนี้เสีย ยอดที่กันไว้มักคิดจากขาดทุนเฉลี่ย (expected loss) ขั้นนี้แสดงว่าตัวเลขเฉลี่ยนี้บอกอะไรได้น้อยมากเรื่องวิกฤต

ขาดทุนจากเงินกู้มาจากสามตัวคูณกัน:

  • $D_{\text{def}}$ คือตัวบอกการผิดนัด เป็น 1 ถ้าลูกหนี้หยุดจ่าย และเป็น 0 ถ้าจ่ายครบ ค่าเฉลี่ยของมันคือโอกาสผิดนัด PD
  • LGD คือสัดส่วนของยอดหนี้ที่เสียจริงเมื่อลูกหนี้หยุดจ่าย หลังธนาคารยึดบ้านไปขายแล้ว
  • EAD คือยอดหนี้ที่ค้างอยู่ ตัวอย่างนี้คือพอร์ตสินเชื่อบ้านทั้งก้อน \$10 ล้าน

ตัวเลขสมมติ: ในเวลาปกติ PD = 2% และ LGD = 40% แต่ในช่วงวิกฤต PD = 15% และ LGD = 70%

\[ \begin{aligned} \mathcal L&=D_{\text{def}}\cdot\mathrm{LGD}\cdot\mathrm{EAD},\\ \mathbb E[\mathcal L]&=\mathrm{PD}\cdot\mathbb E[\mathrm{LGD}]\cdot\mathrm{EAD}\\ &=0.02\times0.40\times10{,}000{,}000\\ &=\$80{,}000,\\ \mathcal L_{\text{crisis}}&=0.15\times0.70\times10{,}000{,}000\\ &=\$1{,}050{,}000. \end{aligned} \]

ขั้นที่ต้องระวังคือการแยกค่าเฉลี่ยของผลคูณ $D_{\text{def}}\cdot\mathrm{LGD}$ ออกเป็น $\mathrm{PD}\cdot\mathbb E[\mathrm{LGD}]$ การแยกแบบนี้ถูกก็ต่อเมื่อ “ลูกหนี้หยุดจ่ายหรือไม่” กับ “เสียมากแค่ไหน” ไม่เกี่ยวกัน (เป็นอิสระต่อกัน) นี่เป็นสมมติฐาน ไม่ใช่ข้อเท็จจริง

ในวิกฤตสองอย่างนี้ขึ้นพร้อมกัน เพราะเหตุเดียวกัน คือราคาบ้านตก คนผ่อนไม่ไหวมากขึ้น และบ้านที่ยึดมาก็ขายได้ถูกลง ขาดทุนจึงกลายเป็น \$1,050,000 คิดเป็น $1{,}050{,}000/80{,}000=13.1$ เท่าของค่าเฉลี่ย สมมติฐานความเป็นอิสระพังในวันที่สำคัญที่สุด เรื่องเดียวกับที่ทำให้แบบจำลองในหน้าCDO และ Gaussian copulaประเมินความเสี่ยงต่ำเกินไปในปี 2007

อีกวิธีที่ใช้กันคือวางสถานการณ์ไว้สามแบบ แล้วกำหนดโอกาสให้แต่ละแบบ (ตัวเลขสมมติ):

  • ปกติ ขาดทุน \$0.8 ล้าน โอกาส 0.70
  • ไม่ดี ขาดทุน \$3.5 ล้าน โอกาส 0.25
  • วิกฤต ขาดทุน \$12.0 ล้าน โอกาส 0.05

ขาดทุนเฉลี่ยคือขาดทุนของแต่ละแบบคูณโอกาสของมันแล้วรวมกัน (หน่วยเป็นล้านดอลลาร์)

\[ \begin{aligned} \mathbb E[\mathcal L]&=0.70(0.8)+0.25(3.5)+0.05(12.0)\\ &=0.56+0.875+0.60\\ &=2.035. \end{aligned} \]

ค่าเฉลี่ยคือ \$2.035 ล้าน แต่ถ้าวิกฤตเกิดขึ้นจริง ธนาคารต้องมีทุนรับ \$12.0 ล้าน มากกว่าค่าเฉลี่ย $12.0/2.035=5.9$ เท่า รายงานแค่ค่าเฉลี่ยจึงซ่อนคำถามที่สำคัญที่สุด คือธนาคารจะรอดไหม

ขั้นที่ 9 — “25 sigma หลายวันติด” บอกอะไร

เดือนสิงหาคม 2007 กองทุน quant หลายแห่ง (กองทุนที่ใช้แบบจำลองทางสถิติเลือกหุ้น) ขาดทุนหนักพร้อมกันหลายวัน เพราะใช้กลยุทธ์คล้ายกันและถือหุ้นชุดคล้ายกัน CFO (ผู้บริหารฝ่ายการเงิน) ของ Goldman Sachs พูดว่าเห็นการเคลื่อนไหวขนาด 25 standard deviation หลายวันติดต่อกัน

25 standard deviation หรือ “25 sigma” คือวันที่ผลตอบแทนขยับมากเป็น 25 เท่าของขนาดการขยับปกติในหนึ่งวัน ถ้าผลตอบแทนรายวันมีรูปทรงระฆัง Normal จริง วันแบบนี้มีโอกาสเกิดเท่าไร? ให้ $Z$ คือการขยับในหนึ่งวัน วัดเป็นจำนวน SD และให้ $\varphi(t)=e^{-t^2/2}/\sqrt{2\pi}$ คือ density รูประฆังของมัน ตัวเลขที่ได้จะเล็กจนเครื่องคิดเลขแสดงไม่ได้ จึงหาขอบเขตบนก่อน แล้วคิดเป็นลอการิทึม

\[ \begin{aligned} P(Z\ge z)&=\int_z^\infty\varphi(t)\,dt\\ &\le\int_z^\infty\frac{t}{z}\,\varphi(t)\,dt=\frac{\varphi(z)}{z},\\ \ln P(Z\ge25)&\le-\ln\sqrt{2\pi}-\ln25-\frac{25^2}{2}\\ &=-0.9189-3.2189-312.5\\ &=-316.638,\\ \log_{10}P(Z\ge25)&\le\frac{-316.638}{\ln10}=\frac{-316.638}{2.302585}\\ &=-137.514,\\ P(Z\ge25)&\le10^{0.486}\times10^{-138}\\ &=3.06\times10^{-138}. \end{aligned} \]

ขั้นที่ทำให้อินทิเกรตได้คือการคูณเพิ่มด้วย $t/z$ ในช่วงที่อินทิเกรต $t\ge z$ ตัวนี้มีค่าอย่างน้อย 1 ผลจึงไม่น้อยลง และ $t\varphi(t)$ มี antiderivative ง่าย ๆ คือ $-\varphi(t)$ อินทิเกรตจึงเหลือ $\varphi(z)/z$ เมื่อใส่ $z=25$ แล้วใช้ $\ln$ ก็แตกเป็นผลบวกของสามพจน์ได้ หาร $\ln10$ เพื่อเปลี่ยนเป็นเลขยกกำลังของ 10 แล้วเขียน $-137.514=0.486-138$

ขอบเขตนี้แน่นมากเมื่อ $z$ ใหญ่ ขอบเขตคือ $10^{0.486}=3.062$ คูณ $10^{-138}$ ส่วนค่าจริงคือ $3.057\times10^{-138}$ (คำนวณในโค้ดท้ายหน้า) ต่างกันแค่ $3.062/3.057-1=0.16\%$

เล็กแค่ไหน? เอกภพมีอายุราว 13.8 พันล้านปี ปีหนึ่งมีราว $3.156\times10^7$ วินาที และหนึ่งวินาทีมี $10^6$ ไมโครวินาที อายุเอกภพจึงเป็น $13.8\times10^9\times3.156\times10^7\times10^6=4.4\times10^{23}$ ไมโครวินาที ต่อให้ทุกไมโครวินาทีตั้งแต่เอกภพเกิดเป็นวันซื้อขายหนึ่งวัน จำนวนครั้งที่ควรเห็นวัน 25 sigma ก็ยังเป็นแค่ $4.4\times10^{23}\times3.06\times10^{-138}=1.3\times10^{-114}$ ครั้ง คือไม่ควรเกิดแม้แต่ครั้งเดียว ถ้าแต่ละวันเป็นอิสระต่อกัน สองวันติดมีโอกาส $(10^{-137.514})^2=10^{-275.03}$ หรือราว $10^{-275}$

ทีนี้ลองใช้รูปทรงที่มีหางหนาแบบที่ราคาหุ้นจริงมี หางหนาแปลว่าวันที่ขยับแรงมาก ๆ เกิดบ่อยกว่าที่ระฆัง Normal บอก ตัวที่ใช้คือ t distribution ที่มี 3 degrees of freedom หาร $T$ ด้วย $\sqrt3$ ได้ $X=T/\sqrt3$ เพื่อให้ variance เท่ากับ 1 เท่ากับ Normal ($T$ มี variance $3/(3-2)=3$) $X$ จึงมี density ด้านล่าง อินทิเกรตหางตรง ๆ ได้

\[ \begin{aligned} p(x)&=\frac{2}{\pi(1+x^2)^2},\\ P(X\ge k)&=\frac{1}{\pi}\left(\arctan\frac1k-\frac{k}{1+k^2}\right),\\ k=25&:\ \frac{0.039978687-0.039936102}{\pi}\\ &\quad=1.3555\times10^{-5},\\ \frac{1}{1.3555\times10^{-5}}&=73{,}773. \end{aligned} \]

สูตรหางมาจาก $\int\frac{dx}{(1+x^2)^2}=\frac12\left(\arctan x+\frac{x}{1+x^2}\right)$ อินทิเกรตจาก $k$ ถึงอนันต์ แล้วใช้ $\frac\pi2-\arctan k=\arctan\frac1k$ ภายใต้หางหนา วัน 25 SD มีโอกาสราว $1.36\times10^{-5}$ ต่อวัน ส่วนกลับของโอกาสนี้คือ 73,773 แปลว่าเกิดราวหนึ่งครั้งในทุก 73,773 วันทำการ ปีหนึ่งมีวันทำการราว 252 วัน (วันที่ตลาดหุ้นสหรัฐฯ เปิด หลังหักเสาร์ อาทิตย์ และวันหยุด) จึงเท่ากับราวหนึ่งครั้งใน $73{,}773/252=293$ ปี หายาก แต่ไม่ใช่ปาฏิหาริย์

ข้อสรุปจึงไม่ใช่ “โชคร้ายสุดขีด” แต่คือ “แบบจำลองผิด” ผิดสองเรื่อง เรื่องแรกคือหาง ราคาจริงมีหางหนากว่า Normal มาก เรื่องที่สองคือความเป็นอิสระ เมื่อทุกกองทุนต้องขายหุ้นชุดเดียวกัน วันร้ายจึงมาติด ๆ กัน ไม่ได้มาแยกกันแบบสุ่ม

กฎหลังปี 2008 ตัดวงจรตรงไหน

วิกฤตการเงินปี 2008 เริ่มจากสินเชื่อบ้านในสหรัฐฯ แล้วลามไปทั้งระบบผ่านวงจรเดียวกับที่หน้านี้คำนวณ คือราคาลง เจ้าหนี้เรียกเงิน ทุกคนต้องขาย และราคาลงต่อ หลังจากนั้นทางการออกกฎหลายชุด ชุดหลักคือ Basel III (กฎสากลสำหรับธนาคาร) และ Dodd–Frank (กฎหมายปฏิรูปการเงินของสหรัฐฯ ปี 2010) ตารางนี้จับคู่กฎแต่ละข้อกับจุดในวงจรที่มันพยายามตัด

จุดในวงจรกฎทำอะไร
อัตราทดสูง ขาดทุนนิดเดียวก็กินเงินตัวเองหมด (ขั้นที่ 2 ถึง 4)ทุนขั้นต่ำ และ leverage ratio (เงินตัวเองหารด้วยสินทรัพย์ทั้งหมด) ของ Basel IIIบังคับให้ธนาคารใช้เงินตัวเองมากขึ้น อัตราทดจึงต่ำลง กันชนจึงหนาขึ้น
เงินสดหมดแล้วต้องขายในวันที่ตลาดไม่รับ (ขั้นที่ 5 ถึง 7)เกณฑ์สภาพคล่อง เช่น LCR (liquidity coverage ratio) ของ Basel IIIต้องถือสินทรัพย์ที่ขายเป็นเงินสดได้ทันที ให้พอจ่ายเงินที่ไหลออกตลอด 30 วันของสถานการณ์ตึงเครียด
ไม่มีใครรู้ว่าใครเป็นหนี้ใครเท่าไรcentral clearing (ให้สัญญาซื้อขายวิ่งผ่านศูนย์กลางที่เป็นคู่สัญญาให้ทุกฝ่าย) และการรายงานธุรกรรมตาม Dodd–Frankลดความเสี่ยงที่คู่สัญญาจะเบี้ยวหนี้ แต่ย้ายความเสี่ยงไปรวมที่ศูนย์กลาง ซึ่งเรียก margin จากทุกคนเหมือนกัน
ค่าเฉลี่ยซ่อนวิกฤต (ขั้นที่ 8)stress test ที่ทางการทำทุกปีถามว่าทุนของธนาคารพอรับสถานการณ์เลวร้ายไหม ไม่ได้ดูแค่ค่าเฉลี่ย

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

คิดว่าราคาลงแล้วสัดส่วนเงินตัวเองไม่เปลี่ยน: หนี้ไม่ลดตามราคา ขาดทุนทั้งหมดจึงตกที่เงินตัวเอง ความคิดผิดบอกว่าหลังราคาลง 8% เงินตัวเองยังเป็น 10% ของสินทรัพย์ ความจริงคือ $E/A=0.2/9.2=2.17\%$ และที่อัตราทด 10 เท่า ราคาลงแค่ $0.05/0.95=5.26\%$ ก็ถึงเกณฑ์ 5% แล้ว

ลืมว่าการขายไม่เพิ่มเงินตัวเอง: ขาด \$260,000 ไม่ได้แปลว่าขาย \$260,000 แล้วจบ ถ้าขายแค่นั้น สัดส่วนเป็น $200{,}000/8{,}940{,}000=2.24\%$ ยังต่ำกว่าเกณฑ์ ยอดที่ถูกคือ $x=260{,}000/0.05=\$5.2$ ล้าน

คูณ PD × LGD โดยถือว่าสองตัวนี้ไม่เกี่ยวกัน: ในวิกฤตทั้งสองขึ้นพร้อมกัน ตัวเลขเวลาปกติคือ $0.02\times0.40\times10{,}000{,}000=\$80{,}000$ แต่ตัวเลขในวิกฤตคือ $0.15\times0.70\times10{,}000{,}000=\$1{,}050{,}000$

เรียกเหตุการณ์ที่เห็นจริงว่าเป็นไปไม่ได้: ใต้ Normal วัน 25 sigma มีโอกาส $3.06\times10^{-138}$ ต่อวัน แต่ใต้หางหนา t ที่มี 3 degrees of freedom มีโอกาส $1.36\times10^{-5}$ คือราวหนึ่งครั้งใน 293 ปี ถ้าสิ่งที่ “เป็นไปไม่ได้” เกิดขึ้นจริง สิ่งที่ผิดคือแบบจำลอง

เชื่อสถิติแบบ “ตลาดหุ้นไม่เคยขาดทุนในช่วง 20 ปีใดเลย”: ข้อมูลร้อยปีมีช่วง 20 ปีที่ไม่ทับกันจริงแค่ $100/20=5$ ช่วง ช่วงที่ทับกันใช้ปีเดียวกันซ้ำ จึงไม่ใช่หลักฐานใหม่ อีกเรื่องคือตลาดที่ถูกยกมาพูดมักเป็นตลาดที่รอดมาให้เห็น เช่นสหรัฐฯ ไม่ใช่ตลาดที่ปิดตัวหายไป ตัวเลขนี้จึงเป็นหลักฐานที่อ่อนกว่าที่ฟังดูมาก

ปรับอัตราโตขึ้นนิดเดียวแล้วเชื่อมูลค่าที่ได้: $g$ จาก 4% เป็น 5% ทำให้มูลค่าพื้นฐานกระโดดจาก $4/0.04=\$100$ เป็น $4/0.03=\$133.33$ ราคาที่ดูเหมือน “มีเหตุผลรองรับ” จึงยืดได้มาก เมื่อตัวหาร $r-g$ เล็ก

ฝ่ายความเสี่ยงของกองทุนหรือธนาคารทำงานแบบเดียวกับขั้นที่ 3 ถึง 6 ทุกวัน สำหรับทุกบัญชีที่ใช้เงินกู้ เขาคำนวณว่าราคาลงแค่ไหนจึงโดนเรียกหลักประกัน ถ้าโดนเรียกจะขาดเงินเท่าไร ต้องขายของเท่าไร และถ้าผู้ให้กู้ขึ้น haircut จะต้องขายเพิ่มอีกเท่าไร

จากนั้นเขาดูว่าของที่ต้องขายเหมือนกับของที่คนอื่นถืออยู่แค่ไหน ถ้าเหมือนกันมาก วันที่ต้องขายจริงก็คือวันที่คนอื่นต้องขายด้วย ราคาที่ใช้คิดจึงควรเป็นราคาตอนที่ทุกคนแห่ขาย ไม่ใช่ราคาปิดของเมื่อวาน

แล้วรู้ได้ไหมว่าตอนนี้เป็นฟองสบู่? สัญญาณที่เห็นซ้ำ ๆ ก่อนฟองแตกมีอยู่ เช่นเงินกู้โตเร็ว ผู้ให้กู้ปล่อยกู้ง่ายขึ้น และเรื่องเล่าว่า “ครั้งนี้ไม่เหมือนเดิม” แต่ไม่มีใครบอกจังหวะที่ฟองจะแตกได้ คนที่ short (ยืมของมาขายก่อน หวังซื้อคืนถูกกว่าเมื่อราคาลง) เร็วเกินไปอาจเจ๊งก่อนฟองแตก เหมือนดีลหุ้นสองชั้น (ชั้น A กับชั้น B) ในหน้า market efficiency และ limits to arbitrage ที่ส่วนต่างราคาถ่างออกก่อนจะหุบ สัญญาณเหล่านี้จึงใช้เตรียมกันชนให้หนาขึ้น ไม่ใช่ใช้จับจังหวะ

โจทย์ตรวจความเข้าใจ

1. กองทุนอีกแห่งระวังกว่ากองทุนในโจทย์ ใช้อัตราทดแค่ $\ell_0=5$ เท่า (เงินตัวเอง \$1 ถือของ \$5) เจ้าหนี้ใช้เกณฑ์เดิม $m=5\%$ ราคาต้องลงเท่าไร กองทุนนี้จึงโดนเรียกหลักประกัน และทนได้มากกว่ากองทุนที่ใช้ 10 เท่ากี่เท่า?

เฉลย

ใช้เกณฑ์จากขั้นที่ 3

\[\begin{aligned}R_A&\lt-\frac{1/\ell_0-m}{1-m}=-\frac{0.20-0.05}{0.95}\\&=-\frac{0.15}{0.95}=-15.79\%.\end{aligned}\]

อัตราทดลดลงแค่ครึ่งเดียว (จาก 10 เป็น 5) แต่ทนราคาลงได้ $15.79/5.26=3.0$ เท่า เพราะกันชน $1/\ell_0-m$ หนาขึ้นจาก $0.10-0.05=5\%$ เป็น $0.20-0.05=15\%$ คือสามเท่าพอดี

2. กองทุนอีกแห่งถือพอร์ต \$20 ล้าน ใช้เงินตัวเอง \$2 ล้าน กู้มา $20-2=\$18$ ล้าน เจ้าหนี้ใช้เกณฑ์ $m=5\%$ แล้วราคาลง 6% กองทุนขาดหลักประกันเท่าไร และถ้าไม่มีเงินเติม ต้องขายของเท่าไร?

เฉลย

คิดแบบเดียวกับขั้นที่ 4 และ 5 (หน่วยเป็นล้านดอลลาร์)

\[\begin{aligned}A&=20\times(1-0.06)=18.8,\\E&=A-L=18.8-18=0.8,\\mA&=0.05\times18.8=0.94,\\mA-E&=0.94-0.8=0.14,\\x&=\frac{0.14}{0.05}=2.8.\end{aligned}\]

กองทุนขาด \$140,000 และถ้าไม่มีเงินเติม ต้องขาย \$2.8 ล้าน ตรวจ: หลังขาย สินทรัพย์เหลือ $18.8-2.8=16$ ล้าน และ $800{,}000/16{,}000{,}000=5\%$ พอดี

3. กลับไปที่หุ้นในขั้นที่ 1 หุ้นจ่ายปันผลปีหน้า \$4 และผู้ถือต้องการผลตอบแทน 8% ต่อปี (ก) ถ้าฟองเสี่ยงแตกมากขึ้นเป็นปีละ $\pi=20\%$ ฟองที่ยังไม่แตกต้องโตปีละเท่าไร (ข) ถ้าราคาวันนี้ \$150 แต่ตลาดเชื่อว่าปันผลจะโตปีละ 5% ไม่ใช่ 4% ส่วนไหนของราคาเป็นฟอง?

เฉลย

(ก) ใช้สูตร $g_B=\frac{1+r}{1-\pi}-1$ จากขั้นที่ 1: $g_B=\frac{1.08}{0.80}-1=35\%$ ต่อปี ยิ่งฟองเสี่ยงแตก ฟองที่รอดยิ่งต้องโตเร็ว

(ข) มูลค่าพื้นฐานใหม่คือ $F=\frac{4}{0.08-0.05}=\$133.33$ ฟองจึงเหลือ $150-133.33=\$16.67$ ไม่ใช่ \$50 ขนาดของฟองที่วัดได้ขึ้นกับว่าเชื่อ $g$ เท่าไร นี่คือเหตุที่คนมักบอกได้ชัดว่าเป็นฟองก็ต่อเมื่อมันแตกไปแล้ว

function num(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(name + ' must be a finite number');
  return x;
}
function fraction(name, x) {
  if (!(num(name, x) > 0 && x < 1)) throw new RangeError(name + ' must be strictly between 0 and 1');
  return x;
}

// Fundamental value of a growing dividend stream, and the growth a bubble needs if it can burst each year.
function gordon(D, r, g) {
  if (!(num('r', r) > num('g', g))) throw new RangeError('need r > g');
  return num('D', D) / (r - g);
}
function bubbleGrowth(r, burst) {
  fraction('burst', burst);
  return (1 + num('r', r)) / (1 - burst) - 1;
}

// Return on equity at leverage l = A/E, asset return rA, borrowing rate rL.
function equityReturn(l, rA, rL) {
  if (!(num('l', l) >= 1)) throw new RangeError('leverage must be at least 1');
  return l * num('rA', rA) - (l - 1) * num('rL', rL);
}

// Asset return at which equity/assets falls to the maintenance margin m (debt fixed).
function marginTrigger(l, m) {
  fraction('m', m);
  if (!(1 / l > m)) throw new RangeError('starting equity share must exceed the margin');
  return -(1 / l - m) / (1 - m);
}

// After a fall, how much cash is missing, and how much must be sold (proceeds repay debt) if no cash comes in.
function marginCall({assets, debt, fall, m}) {
  fraction('m', m);
  const A = num('assets', assets) * (1 - num('fall', fall)), E = A - num('debt', debt);
  if (E <= 0) throw new RangeError('equity is wiped out: this is default, not a margin call');
  const shortfall = Math.max(m * A - E, 0);
  return {A, E, shortfall, sell: shortfall / m, soldShare: shortfall / m / A};
}

// log10 of the standard Normal upper tail, via the continued fraction of the Mills ratio (no underflow).
function normalTailLog10(z) {
  if (!(num('z', z) > 0)) throw new RangeError('z must be positive');
  let f = z;
  for (let k = 200; k >= 1; k--) f = z + k / f;
  return (Math.log(1 / f) - z * z / 2 - 0.5 * Math.log(2 * Math.PI)) / Math.LN10;
}

// Upper tail of a Student-t with 3 degrees of freedom rescaled to variance 1, at k standard deviations.
function t3Tail(k) {
  const x = num('k', k);                       // T / sqrt(3) has variance 1, so P(X > k) = P(T > k sqrt 3)
  return 0.5 - (Math.atan(x) + x / (1 + x * x)) / Math.PI;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ฟองคือส่วนของราคาที่เกินมูลค่าพื้นฐาน (เงินปันผลทั้งหมดในอนาคต แปลงเป็นเงินวันนี้) ถ้าฟองแตกได้ ปีที่มันรอดต้องโตเร็วกว่าผลตอบแทนที่ผู้ถือต้องการ ในตัวอย่างคือ $g_B=1.08/0.90-1=20\%$ เทียบกับ 8%
  • อัตราทดขยายผลตอบแทนทั้งสองทิศ ตามสูตร $R_E=\ell R_A-(\ell-1)r_L$ ที่ 4 เท่า สินทรัพย์ +5% กลายเป็น +14% แต่ −5% กลายเป็น −26%
  • หนี้ไม่ลดตามราคา ที่อัตราทด 10 เท่า ราคาลงแค่ $0.05/0.95=5.26\%$ ก็ถึงเกณฑ์ 5% แล้ว
  • การขายของไปคืนหนี้ไม่ได้เพิ่มเงินตัวเอง ขาด \$260,000 จึงต้องขาย $260{,}000/0.05=\$5.2$ ล้าน คือเงินที่ขาดทุก \$1 ต้องขายของ $1/m$ ดอลลาร์ ส่วน haircut $h$ คืออัตราทดสูงสุด $1/h$ ที่แอบอยู่
  • ขาดทุนเฉลี่ยซ่อนวิกฤต \$80,000 ในเวลาปกติกลายเป็น \$1,050,000 ในวิกฤต เพราะโอกาสผิดนัดกับความเสียหายต่อครั้งขึ้นพร้อมกัน
  • “25 sigma” คือหลักฐานว่าแบบจำลองผิด ไม่ใช่โชคร้าย ใต้ Normal มีโอกาส $3\times10^{-138}$ ต่อวัน แต่ใต้หางหนาเกิดราวหนึ่งครั้งใน 293 ปี
