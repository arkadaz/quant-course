27.4 The Idiosyncratic Covariance Matrix and Off-Diagonal Clustering

factor model สมมติว่าส่วนเฉพาะตัวของหุ้นต่างตัวไม่สัมพันธ์กัน ซึ่งถูกกับเกือบทุกคู่ แต่ผิดแรงกับคู่ไม่กี่คู่ เช่นหุ้นสองชั้นของบริษัทเดียวกัน หน้านี้ประมาณแนวทแยงให้ดี หาคู่ที่ผิดด้วยเกณฑ์ที่คิดได้ แล้วใส่กลับโดยไม่ทำให้ matrix พัง

บริษัทหนึ่งมีหุ้นสองชั้นซื้อขายแยกกัน A กับ B ความผันผวนเฉพาะตัว 1.30% และ 2.21% ต่อวัน โต๊ะหนึ่งถือ long ทั้งคู่ข้างละ \$1 ล้าน อีกโต๊ะ long A \$1 ล้าน short B \$1 ล้าน เพื่อเก็บส่วนต่างราคา risk model ที่ถือว่าส่วนเฉพาะตัวไม่สัมพันธ์กันบอกว่าสองพอร์ตเสี่ยงเท่ากันที่ \$25,640 ต่อวัน ถ้าส่วนเฉพาะตัวของสองชั้นมี correlation 0.82 (ตัวเลขสมมติ) model ผิดกับพอร์ตไหน และผิดทางไหน?

ลองตอบก่อนเปิดเฉลย

ผิดทั้งคู่ และผิดคนละทิศ พอร์ตที่ long ทั้งคู่เสี่ยงจริง \$33,594 สูงกว่าที่รายงาน 31.0% พอร์ตเก็บส่วนต่างเสี่ยงจริงแค่ \$13,647 model รายงานสูงไป 87.9% ความผิดแบบหลังแพงกว่าที่เห็น: ใต้เพดานความเสี่ยงเดิม โต๊ะถูกบังคับให้ทำการเทรดที่ปลอดภัยที่สุดอันหนึ่งแค่ 53.2% ของขนาดที่ทำได้จริง และไม่มีรายงานไหนแสดงกำไรที่หายไป

สิ่งที่เราจะสร้าง

27.1 ให้ส่วนเฉพาะตัว $\hat\epsilon_{i,t}$ ของหุ้นทุกตัวทุกวัน 27.2 และ 27.3 จัดการฝั่ง factor หน้านี้สร้าง $\boldsymbol\Omega_\epsilon$ ซึ่งในพอร์ตที่กระจายดีคือก้อนความเสี่ยงที่ใหญ่กว่า (26.1) model บอกว่ามันเป็นแนวทแยง งานส่วนใหญ่จึงเป็นการประมาณ variance ทีละหุ้นให้ดี แต่ข้อสมมตินี้ผิดแรงกับคู่ไม่กี่คู่ที่คนเทรดมาก

ลำดับคือ ประมาณแนวทแยงและดึงหุ้นที่ข้อมูลน้อยเข้าหาค่าเฉลี่ย ดูว่าทำไม matrix เต็มจากข้อมูลใช้ไม่ได้ คิดว่าเสียงรบกวนล้วน ๆ สร้าง correlation ได้ใหญ่แค่ไหน และคู่จริงอยู่ตรงไหน ตัดด้วยเกณฑ์แล้วจับกลุ่มด้วยมือบนหุ้นหกตัว ดูว่าการตัดทำ matrix พังได้อย่างไร แล้วจบที่ราคาของการไม่ทำอะไรและทางเลือกสามทางกับกลุ่มที่เจอ

ขั้นที่ 1 — แนวทแยงก่อน: EWMA แล้วดึงหุ้นที่ข้อมูลน้อยเข้าหาค่าเฉลี่ย

งานส่วนใหญ่ของ $\boldsymbol\Omega_\epsilon$ คือแนวทแยง ใช้ EWMA ของ 25.5 กับ $\hat\epsilon^2$ ของหุ้นแต่ละตัว (model รายวันที่ตอบสนองเร็วใช้ half-life ราว 126 วัน) แล้วดึงเข้าหาค่าเฉลี่ยของทุกตัวเล็กน้อย สำหรับ matrix แนวทแยง shrinkage ของ 27.2 คือสิ่งนี้พอดี ตัวอย่างคือหุ้นที่เพิ่งเข้าตลาด มีข้อมูล 20 วัน วัดได้ 3.6% ขณะที่ค่าเฉลี่ยของตลาดคือ 2.2% และ $\delta=0.3$ (ค่าสมมติ)

\[ \begin{aligned} \hat\sigma_{i,t}^2&=\textstyle\sum_s w_s\hat\epsilon_{i,t-s}^2,\\ \tilde\sigma_i^2&=(1-\delta)\hat\sigma_i^2+\delta\bar\sigma^2,\\ \tfrac1{\sqrt{2(20)}}&=15.8\%,\\ \tilde\sigma^2&=0.7(3.6^2)+0.3(2.2^2)\\ &=9.072+1.452=10.524,\\ \tilde\sigma&=3.244\%. \end{aligned} \]

$w_s$ คือน้ำหนักของ EWMA ใน 27.2 และ $\bar\sigma^2$ คือค่าเฉลี่ยของ $\hat\sigma_i^2$ ทุกตัว ข้อมูล 20 วันให้ความผันผวนที่คลาดได้ 15.8% (สูตร $1/\sqrt{2N}$ ของ 27.2) ค่า 3.6% จึงอาจเป็น 3.0% หรือ 4.2% ได้ง่าย การดึงเข้าหาค่าเฉลี่ย 30% ขยับมันลง 0.356 จุดเหลือ 3.244% หุ้นที่มีข้อมูลเต็มปีคลาดน้อยกว่ามาก จึงควรดึงน้อยกว่า

ส่วนเฉพาะตัวต้องมาจาก regression ที่ใช้น้ำหนักของเมื่อวาน (27.1 ขั้นที่ 8) และวันประกาศผลประกอบการต้องผ่าน tent ของ 27.3 ขั้นที่ 7 ไม่อย่างนั้นข่าวของบริษัทไม่กี่แห่งจะดันความเสี่ยงของทั้งตลาด

ขั้นที่ 2 — ทำไมใช้ matrix เต็มจากข้อมูลตรง ๆ ไม่ได้

ทำไมไม่คิด covariance ของส่วนเฉพาะตัวทุกคู่จากข้อมูลไปเลย? นับดู จักรวาลของบทนี้มีหุ้น 600 ตัว ข้อมูลหนึ่งปี 251 วัน

\[ \begin{aligned} \operatorname{rank}(\hat{\boldsymbol\Omega}_\epsilon)&\le T=251,\\ 600-251&=349,\\ \tfrac{n(n-1)}2&=179{,}700,\\ \operatorname{sd}(\hat\rho_{ij})&\approx\frac{1-\rho_{ij}^2}{\sqrt T},\\ \rho_{ij}=0&:\ \tfrac1{\sqrt{251}}=0.0631. \end{aligned} \]

$\hat{\boldsymbol\Omega}_\epsilon$ คือผลรวมของ 251 matrix ที่แต่ละตัวมี rank หนึ่ง rank จึงไม่เกิน 251 (7.5) อีกอย่างน้อย 349 ทิศมี variance เฉพาะตัวเป็นศูนย์ optimizer จะหาพอร์ตที่ model บอกว่าไม่มีความเสี่ยงเฉพาะตัวเลย แบบเดียวกับ 26.1 ขั้นที่ 9

นอกแนวทแยงมี 179,700 คู่ แต่ละคู่วัดจาก 251 วัน คู่ที่ไม่เกี่ยวกันเลยยังให้ $\hat\rho$ แกว่ง ±0.0631 (ความคลาดของ correlation ใน 27.2 ขั้นที่ 7 ที่ $\rho=0$) matrix นี้จึงเป็นเสียงรบกวนเกือบทั้งหมด งานคือหาคู่ไม่กี่คู่ที่เป็นของจริงในกองนั้น

ขั้นที่ 3 — เสียงรบกวนล้วน ๆ ไปได้ไกลแค่ไหน

ถ้าทุกคู่ไม่เกี่ยวกันจริง $\hat\rho$ ของแต่ละคู่ใกล้ Normal ที่ SD 0.0631 จำนวนคู่ที่ขนาดเกินเกณฑ์ $\theta$ โดยเฉลี่ยคือจำนวนคู่คูณโอกาสสองหาง ตัวเลขนี้บอกว่าเกณฑ์ต้องสูงแค่ไหนจึงจะไม่มีคู่ปลอมหลุดเข้ามา

\[ \begin{aligned} N(\theta)&=179{,}700\times2Q(\theta\sqrt T),\\ Q(z)&=P(Z\gt z),\\ \theta=0.20&:\ z=3.17,\ N=275.3,\\ \theta=0.25&:\ z=3.96,\ N=13.4,\\ \theta=0.30&:\ z=4.75,\ N=0.36,\\ \theta=0.40&:\ z=6.34,\ N=0.00004. \end{aligned} \]

$\sqrt{251}=15.84$ จึง $z=\theta\times15.84$ และ $Q(z)$ คือพื้นที่หางขวาของ Normal มาตรฐาน ที่เกณฑ์ 0.20 คู่ปลอมหลุดเข้ามาราว 275 คู่ ซึ่งมากกว่าโครงสร้างจริงในตลาดหลายเท่า ที่ 0.30 เหลือโดยเฉลี่ยไม่ถึงครึ่งคู่ ที่ 0.40 แทบเป็นศูนย์

บทเรียนคือโครงสร้างจริงไม่ได้ซ่อนอยู่ในค่าเฉลี่ยหรือ SD ของ correlation ทั้ง 179,700 คู่ มันอยู่ที่หางขวาสุด ค่าเฉลี่ยกับ SD ของกองจะดูเหมือนเสียงรบกวนล้วนทุกประการ

ขั้นที่ 4 — เกณฑ์จากทฤษฎี และคู่จริงอยู่ตรงไหน

ทฤษฎีให้เกณฑ์ที่โตตาม $\sqrt{\ln n/T}$ (Cai และคณะ) แต่ค่าคงที่ $K$ ข้างหน้าไม่มีใครรู้แน่ ในหน้านี้ใช้ $K=2$ อีกด้านหนึ่งคือคู่จริงก็วัดได้คลาด ใช้สูตรความคลาดของขั้นที่ 2 กับคู่หุ้นสองชั้นที่ 0.82 และธีมที่ 0.58 แล้วดูว่าค่าที่วัดได้ต่ำได้แค่ไหน (สองเท่าของ SD)

\[ \begin{aligned} \theta_\star&=K\sqrt{\ln n/T}\\ &=2\sqrt{\ln600/251}=0.3193,\\ 0.82&:\ \operatorname{sd}=\tfrac{1-0.6724}{15.84}=0.0207,\\ &\quad0.82-2(0.0207)=0.779,\\ 0.58&:\ \operatorname{sd}=\tfrac{1-0.3364}{15.84}=0.0419,\\ &\quad0.58-2(0.0419)=0.496. \end{aligned} \]

ตอนนี้เห็นหน้าต่างทั้งสองข้าง ด้านล่างถูกจำกัดด้วยเสียงรบกวน ต่ำกว่า 0.30 คู่ปลอมเริ่มหลุดเข้ามา ด้านบนถูกจำกัดด้วยคู่จริงที่อ่อนที่สุด เหนือราว 0.50 ธีมเริ่มขาดหาย ระหว่างนั้นผลการจับกลุ่มไม่ควรเปลี่ยน เรียกว่าที่ราบ $\theta_\star=0.3193$ ตกในที่ราบพอดีเมื่อ $K=2$

วิธีที่ใช้จริงจึงไม่ใช่การเชื่อสูตร แต่คือลองหลายเกณฑ์แล้วดูว่ากลุ่มนิ่งไหม และเปิดดูว่ากลุ่มอธิบายได้ไหม ถ้า $n$ หรือ $T$ เปลี่ยน ที่ราบก็เลื่อน: ข้อมูลครึ่งปีทำให้เสียงรบกวนดังขึ้นและที่ราบแคบลง

ขั้นที่ 6 — การตัดทำ matrix พังได้: ตรวจ eigenvalue ทุกครั้ง

matrix ที่วัดได้เป็น positive definite เสมอ แต่หลังตัดไม่แน่ ลองหุ้นสามตัวที่วัดได้ 0.9 (1–2), 0.9 (2–3) และ 0.70 (1–3) ซึ่ง determinant คือ 0.024 เป็นบวก ถ้าตั้งเกณฑ์ที่ 0.75 คู่ 1–3 ถูกตัดทิ้ง แล้วลองพอร์ตที่ long ตัวริม short ตัวกลาง

\[ \begin{aligned} \mathbf R_\theta&=\begin{bmatrix}1&0.9&0\\0.9&1&0.9\\0&0.9&1\end{bmatrix},\\ \mathbf w&=\tfrac12\big(1,\ -\sqrt2,\ 1\big),\\ \mathbf R_\theta\mathbf w&=(1-0.9\sqrt2)\,\mathbf w,\\ \mathbf w^{\mathsf T}\mathbf R_\theta\mathbf w&=1-1.2728\\ &=-0.2728. \end{aligned} \]

คูณตรง ๆ ได้บรรทัดที่สาม: แถวแรกให้ $\tfrac12(1-0.9\sqrt2)$ แถวกลางให้ $\tfrac12(0.9-\sqrt2+0.9)=\tfrac12(1.8-\sqrt2)$ ซึ่งเท่ากับ $(1-0.9\sqrt2)\times(-\sqrt2/2)$ พอดี $\mathbf w$ จึงเป็น eigenvector ที่ eigenvalue $-0.2728$ และเพราะ $\lVert\mathbf w\rVert=1$ variance ของพอร์ตนี้จึงติดลบ ซึ่งเป็นไปไม่ได้ และ optimizer จะรีบใช้มัน

ต้นเหตุคือหุ้น 1 กับ 3 ต่างก็ติดกับหุ้น 2 แน่นมาก ถ้าไม่ให้มันสัมพันธ์กันเองเลย ตัวเลขชุดนั้นเป็นไปไม่ได้ ทางแก้คือตรวจ eigenvalue เล็กสุดทุกครั้งหลังตัด ถ้าติดลบให้ลดเกณฑ์ หรือผสมกับ $\mathbf I$: $(1-\delta)\mathbf R_\theta+\delta\mathbf I$ มี eigenvalue เล็กสุด $1-0.9\sqrt2(1-\delta)$ ซึ่งเป็นบวกเมื่อ $\delta\gt0.2143$

ขั้นที่ 7 — ราคาของการไม่ทำอะไร

โจทย์ให้อะไรมาบ้าง: คู่หุ้นสองชั้นของโจทย์เปิดหน้า (1.30% กับ 2.21% correlation 0.82) และธีมเหมืองทองห้าตัว แต่ละตัวผันผวนเฉพาะตัว 2.75% correlation 0.58 ทุกคู่ ถือตัวละ \$1 ล้าน ความเสี่ยงรายวันเป็นดอลลาร์คือ \$1 ล้าน × ความผันผวนของพอร์ตเป็น %

\[ \begin{aligned} \sigma_{\rm d}&=\sqrt{1.30^2+2.21^2}\\ &=\sqrt{6.5741}=2.5640\%,\\ \sigma_+&=\sqrt{6.5741+4.7117}\\ &=3.3594\%,\\ \sigma_-&=\sqrt{6.5741-4.7117}\\ &=1.3647\%,\\ \sigma_{\rm 5,d}&=2.75\sqrt5=6.1492\%,\\ \sigma_5&=2.75\sqrt{16.6}\\ &=11.2044\%. \end{aligned} \]

$\sigma_{\rm d}$ คือที่ model แนวทแยงเห็นสำหรับคู่นี้ $\sigma_+$ กับ $\sigma_-$ คือความจริงของพอร์ต long ทั้งคู่และพอร์ตเก็บส่วนต่าง $\sigma_{\rm 5,d}$ กับ $\sigma_5$ คือธีมห้าตัวแบบแนวทแยงและแบบจริง โดย $16.6=5+20(0.58)$ นับแนวทแยงห้าช่องกับช่องนอกแนวทแยง 20 ช่อง

คำตอบ: model แนวทแยงให้ \$25,640 กับทั้งพอร์ต long และพอร์ตเก็บส่วนต่าง เพราะมันไม่รู้จักเครื่องหมาย ความจริงคือ \$33,594 (สูงกว่า 31.0%) และ \$13,647 (model สูงไป 87.9%) พจน์ไขว้ $2(0.82)(1.30)(2.21)=4.7117$ บวกเข้าในพอร์ตแรกและลบออกในพอร์ตที่สอง ธีมห้าตัว model บอก \$61,492 ความจริงคือ \$112,044 สูงกว่า 82.2% ($\sqrt{16.6/5}=1.8221$) เพราะมี 20 พจน์ไขว้ที่ model ทิ้งไป

ตรวจเองใน 10 วินาที: $3.3594^2+1.3647^2=11.2858+1.8624=13.148=2\times6.5741$ พจน์ไขว้หักล้างกันพอดีเมื่อบวกสองพอร์ต

คำถามที่ควรถามออกมาดัง ๆ

ถ้าหุ้นสองชั้นขยับเกือบเหมือนกัน ทำไม factor ไม่จับมันไป? factor ต้องกระทบหุ้นจำนวนมากพอจะเห็นใน regression ข้ามหุ้นของ 27.1 คู่หุ้นสองตัวมีน้ำหนักแทบไม่มีใน regression ของหุ้น 600 ตัว สิ่งที่มันมีร่วมกันจึงตกไปอยู่ในส่วนเฉพาะตัวของทั้งคู่

ตั้งเกณฑ์ต่ำไว้ก่อน “กันพลาด” ไม่ดีกว่าหรือ? ที่ 0.20 ได้คู่ปลอมราว 275 คู่ ซึ่ง optimizer จะหาพอร์ตที่ใช้ประโยชน์จากความสัมพันธ์ที่ไม่มีอยู่จริง แย่กว่าไม่ใส่อะไรเลย

จะทำอย่างไรกับกลุ่มที่เจอ? มีสามทาง ใส่ correlation ที่รอดเกณฑ์ลงใน $\boldsymbol\Omega_\epsilon$ ตรง ๆ (เหมาะกับคู่และกลุ่มเล็ก) เพิ่ม factor ใหม่ เช่น factor ของ share class ด้วย push-out ของ 26.3 (เหมาะเมื่อกลุ่มใหญ่และเกิดซ้ำ) หรือถ้ากลยุทธ์ลงทุนตามพื้นฐานของบริษัท ให้เก็บแค่ชั้นที่สภาพคล่องดีที่สุดชั้นเดียว แล้วปัญหาหายไปเอง

ส่วนถ้ากลยุทธ์ตั้งใจเก็บส่วนต่างราคา ต้องมีทั้งสองชั้นและต้องใส่ correlation ให้ถูก

ความผิดที่ให้ตัวเลขผิดแบบเงียบ ๆ

ตั้งเกณฑ์ต่ำเพื่อไม่ให้พลาดอะไร: ที่ 0.20 คู่ปลอมเฉลี่ย 275.3 คู่ ที่ 0.25 ยังเหลือ 13.4 คู่ matrix ที่ได้เต็มไปด้วยความสัมพันธ์ที่ไม่มีอยู่จริง

ตัดแล้วไม่ตรวจ eigenvalue: ตัวอย่างสามหุ้นในขั้นที่ 6 ได้พอร์ตที่ variance −0.2728 ทั้งที่ matrix ก่อนตัดใช้ได้ การเติมหรือลบค่านอกแนวทแยงทีละคู่ไม่รับประกันอะไรเลย

เปลี่ยนกลุ่มเป็น factor โดยไม่คิดเรื่องรายงาน: กำไรจากการเทรดกลุ่มนั้นจะย้ายจากบรรทัดเฉพาะตัวไปบรรทัด factor ของ 26.6 ทันที และหายไปจากตัวเลขที่ใช้วัดฝีมือเลือกหุ้น ต้องตั้งใจเลือก

ใช้ทำอะไรบนโต๊ะจริง

ทีม risk model รันการตัดกับ correlation ของส่วนเฉพาะตัวเป็นรอบ ๆ ลองหลายเกณฑ์เพื่อหาที่ราบ เปิดดูรายชื่อในแต่ละกลุ่ม (หุ้นสองชั้น บริษัทที่จดสองตลาด บริษัทแม่กับบริษัทลูก หรือธีมแคบ ๆ) ตรวจ eigenvalue เล็กสุด แล้วส่งให้โต๊ะที่เทรดส่วนต่างราคาใช้ correlation เหล่านี้ ส่วนโต๊ะที่ลงทุนตามพื้นฐานมักตัดหุ้นชั้นที่สภาพคล่องต่ำออกจากจักรวาลตั้งแต่แรก

สามโจทย์ตรวจความเข้าใจ

1. หุ้นสองชั้นที่ผันผวนเฉพาะตัวเท่ากัน 1.5% correlation 0.9 พอร์ต long \$1 ล้าน short \$1 ล้าน model แนวทแยงรายงานเท่าไร ความจริงเท่าไร?

เฉลย

แนวทแยง $1.5\sqrt2=2.1213\%$ หรือ \$21,213 ความจริง $1.5\sqrt{2-2(0.9)}=1.5\sqrt{0.2}=0.6708\%$ หรือ \$6,708 model สูงไป 3.16 เท่า ยิ่ง correlation ใกล้ 1 ส่วนต่างยิ่งปลอดภัย และ model แนวทแยงยิ่งผิด

2. ถ้าจักรวาลมีหุ้น 1,000 ตัว ข้อมูล 251 วัน มีกี่คู่ เกณฑ์ $\theta_\star$ ที่ $K=2$ คือเท่าไร และที่เกณฑ์ 0.30 คาดว่าคู่ปลอมหลุดมากี่คู่?

เฉลย

$1{,}000\times999/2=499{,}500$ คู่ $\theta_\star=2\sqrt{\ln1{,}000/251}=2\sqrt{6.9078/251}=0.3318$ คู่ปลอมที่ 0.30 คือ $499{,}500\times2Q(4.75)=1.0$ คู่ มากกว่า 0.36 ของหุ้น 600 ตัว เพราะคู่เพิ่มขึ้น 2.78 เท่า เกณฑ์จึงต้องขยับขึ้นตาม $\sqrt{\ln n}$

3. ในตัวอย่างสามหุ้นของขั้นที่ 6 ต้องผสม $\mathbf R_\theta$ กับ $\mathbf I$ อย่างน้อยเท่าไร matrix จึงกลับมา positive definite?

เฉลย

eigenvalue เล็กสุดหลังผสมคือ $(1-\delta)(-0.2728)+\delta$ ตั้งให้มากกว่าศูนย์: $\delta\gt0.2728/1.2728=0.2143$ ผสมน้อยกว่านี้ยังมีพอร์ตที่ variance ติดลบ

คำนวณซ้ำด้วย JavaScript

โค้ดนี้คิดจำนวนคู่ปลอมที่คาดว่าจะหลุดแต่ละเกณฑ์ด้วยหางของ Normal (continued fraction) เกณฑ์จากทฤษฎี ช่วงของคู่จริง การดึง variance ของหุ้นใหม่ การตัดและจับกลุ่มหุ้นหกตัวด้วย union-find eigenvalue ก่อนและหลังตัดด้วยการหมุนของ Jacobi และความเสี่ยงเป็นดอลลาร์ของทุกพอร์ต แล้วพิมพ์ตัวเลขหลักหนึ่งบรรทัด

const {sqrt, abs, exp, log, PI} = Math;
// Upper Normal tail Q(x) = P(Z > x) from its continued fraction (accurate for x of 1 or more).
function normalTail(x) {
  if (!(x >= 1)) throw new RangeError('this tail formula is for x of 1 or more');
  let f = x;
  for (let k = 60; k >= 1; k--) f = x + k / f;
  return exp(-x * x / 2) / sqrt(2 * PI) / f;
}
function symmetric(name, A) {
  if (!Array.isArray(A) || !A.every(row => Array.isArray(row) && row.length === A.length && row.every(Number.isFinite))) {
    throw new TypeError(`${name} must be a square array of finite numbers`);
  }
  if (A.some((row, i) => row.some((x, j) => abs(x - A[j][i]) > 1e-12))) throw new RangeError(`${name} must be symmetric`);
  return A;
}
// Cyclic Jacobi rotations: all eigenvalues of a symmetric matrix, sorted.
function eigenvalues(S) {
  const n = symmetric('matrix', S).length, A = S.map(row => [...row]);
  for (let sweep = 0; sweep < 100; sweep++) {
    let off = 0;
    for (let i = 0; i < n; i++) for (let j = i + 1; j < n; j++) off += A[i][j] * A[i][j];
    if (off < 1e-30) break;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) {
      if (A[p][q] === 0) continue;
      const theta = (A[q][q] - A[p][p]) / (2 * A[p][q]);
      const t = (theta >= 0 ? 1 : -1) / (abs(theta) + sqrt(theta * theta + 1)), c = 1 / sqrt(t * t + 1), s = t * c;
      for (let k = 0; k < n; k++) { const akp = A[k][p], akq = A[k][q]; A[k][p] = c * akp - s * akq; A[k][q] = s * akp + c * akq; }
      for (let k = 0; k < n; k++) { const apk = A[p][k], aqk = A[q][k]; A[p][k] = c * apk - s * aqk; A[q][k] = s * apk + c * aqk; }
    }
  }
  return A.map((row, i) => row[i]).sort((a, b) => a - b);
}
// Keep correlations bigger than the threshold, then group stocks linked by kept pairs (union-find).
function threshold(R, theta) {
  symmetric('correlation matrix', R);
  if (!(theta > 0 && theta < 1)) throw new RangeError('threshold must be between 0 and 1');
  const n = R.length, kept = R.map((row, i) => row.map((x, j) => (i === j ? 1 : abs(x) > theta ? x : 0)));
  const parent = [...Array(n).keys()], find = i => (parent[i] === i ? i : (parent[i] = find(parent[i])));
  const pairs = [];
  for (let i = 0; i < n; i++) for (let j = i + 1; j < n; j++) if (kept[i][j] !== 0) { pairs.push([i + 1, j + 1]); parent[find(i)] = find(j); }
  const groups = {};
  for (let i = 0; i < n; i++) (groups[find(i)] = groups[find(i)] || []).push(i + 1);
  return {kept, pairs, clusters: Object.values(groups)};
}
// Daily risk in dollars of positions w (dollars) with daily vols (%) and a correlation matrix R.
function dollarRisk(w, vol, R) {
  let s = 0;
  for (let i = 0; i < w.length; i++) for (let j = 0; j < w.length; j++) s += w[i] * w[j] * vol[i] * vol[j] * R[i][j] / 1e4;
  if (s < 0) throw new RangeError('negative variance: the correlation matrix is not positive definite');
  return sqrt(s);
}
const n = 600, T = 251, pairsTotal = n * (n - 1) / 2;

const thetaTheory = 2 * sqrt(log(n) / T);
const realBand = rho => { const sd = (1 - rho * rho) / sqrt(T); return {sd, low: rho - 2 * sd}; };
const young = {measured: 3.6, average: 2.2, days: 20, delta: 0.3};           // step 1, assumed numbers

ที่มาที่ไป

การตัด correlation ที่เล็กทิ้งเพื่อประมาณ covariance ขนาดใหญ่ที่ช่องส่วนใหญ่เป็นศูนย์ ได้รับการศึกษาเชิงทฤษฎีโดย Peter Bickel และ Elizaveta Levina ในปี 2008 และโดย Tony Cai กับเพื่อนร่วมงานในปีต่อ ๆ มา ซึ่งเป็นที่มาของเกณฑ์ที่โตตาม $\sqrt{\ln n/T}$ ส่วน model ที่ยอมให้ส่วนเฉพาะตัวสัมพันธ์กันได้บ้างเรียกว่า approximate factor model ตามงานของ Gary Chamberlain และ Michael Rothschild ในปี 1983

ข้อจำกัด: สามทางกับกลุ่มที่เจอ

ทางสมมติอะไรของจริงผลเวลาใช้งาน
ใส่ correlation ที่รอดเกณฑ์ค่าที่วัดได้คงที่พอต้องประมาณใหม่ทุกรอบ และค่าเลื่อนได้ต้องตรวจ eigenvalue ทุกครั้ง
เพิ่ม factor ของกลุ่มกลุ่มใหญ่พอและเกิดซ้ำคู่เล็ก ๆ ทำ factor ไม่ได้กำไรย้ายจากบรรทัดเฉพาะตัวไปบรรทัด factor
เก็บชั้นเดียวที่สภาพคล่องดีสุดกลยุทธ์ไม่ได้เทรดส่วนต่างบางกลยุทธ์ต้องการทั้งสองชั้นง่ายที่สุด ถ้ากลยุทธ์อนุญาต
ใช้แนวทแยงอย่างเดียวส่วนเฉพาะตัวไม่สัมพันธ์กันเลยถูกเกือบทุกคู่ ผิดแรงไม่กี่คู่ความเสี่ยงผิดทั้งสองทิศ 31% ถึง 88%

สิ่งที่ควรตอบได้หลังอ่าน
