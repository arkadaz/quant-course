27.4 The Idiosyncratic Covariance Matrix and Off-Diagonal Clustering

factor model สมมติว่าส่วนเฉพาะตัวของหุ้นต่างตัวไม่สัมพันธ์กัน ข้อสมมตินี้ถูกกับเกือบทุกคู่ แต่ผิดแรงกับคู่ไม่กี่คู่ หน้านี้ประมาณแนวทแยงของ matrix ให้ดีก่อน แล้วหาคู่ที่ผิดด้วยเกณฑ์ที่คำนวณได้ จากนั้นใส่คู่นั้นกลับเข้าไปโดยไม่ทำให้ matrix พัง

บริษัทหนึ่งออกหุ้นสองชั้น (share class) เรียกว่าชั้น A กับชั้น B ทั้งสองชั้นเป็นเจ้าของบริษัทเดียวกัน ต่างกันแค่สิทธิ์บางอย่าง เช่นสิทธิ์ออกเสียง แต่ซื้อขายแยกกัน แต่ละชั้นจึงมีราคาของตัวเอง ราคาของสองชั้นขยับเกือบเหมือนกัน แต่ไม่เท่ากันทุกวัน

โต๊ะเทรดสองโต๊ะ (ทีมที่ซื้อขายด้วยเงินของบริษัท) ถือหุ้นคู่นี้คนละแบบ

  • โต๊ะแรก long ทั้งสองชั้น ข้างละ \$1 ล้าน (long คือซื้อมาถือไว้ ได้กำไรเมื่อราคาขึ้น)
  • โต๊ะที่สอง long ชั้น A \$1 ล้าน และ short ชั้น B \$1 ล้าน (short คือยืมหุ้นมาขายก่อน ได้กำไรเมื่อราคาลง) ถ้าสองชั้นขึ้นหรือลงพร้อมกัน กำไรของขาหนึ่งหักล้างกับขาดทุนของอีกขา พอร์ตนี้จึงได้หรือเสียเงินตามส่วนต่างราคาของสองชั้นเท่านั้น

บริษัทวัดความเสี่ยงของทุกพอร์ตด้วยแบบจำลองความเสี่ยง (risk model) ตัวเลขที่มันรายงานคือ SD (standard deviation) ของกำไรขาดทุนรายวัน เป็นดอลลาร์ แบบจำลองแยกผลตอบแทนรายวันของหุ้นแต่ละตัวเป็นสองส่วน ส่วนแรกขยับตาม factor คือปัจจัยร่วมที่กระทบหุ้นจำนวนมากพร้อมกัน เช่นทั้งตลาดหรือทั้งอุตสาหกรรม ส่วนที่เหลือเรียกว่าส่วนเฉพาะตัว คือส่วนที่หุ้นตัวนั้นขยับเอง หน้านี้ดูเฉพาะความเสี่ยงที่มาจากส่วนเฉพาะตัว

ของที่รู้:

  • ความผันผวนเฉพาะตัวของชั้น A (SD ของส่วนเฉพาะตัวรายวัน) $\sigma_A=1.30\%$ ต่อวัน
  • ความผันผวนเฉพาะตัวของชั้น B $\sigma_B=2.21\%$ ต่อวัน

แบบจำลองสมมติว่าส่วนเฉพาะตัวของหุ้นต่างตัวไม่สัมพันธ์กันเลย คือ correlation เป็นศูนย์ (correlation คือตัวเลขระหว่าง −1 ถึง 1 ที่บอกว่าสองอย่างขยับไปด้วยกันแค่ไหน) ภายใต้ข้อสมมตินี้ variance ของพอร์ตคือผลบวกของ variance ของแต่ละขา และขาที่ short ถูกยกกำลังสอง เครื่องหมายลบจึงหายไป สองพอร์ตจึงได้ตัวเลขเดียวกัน

\[ \begin{aligned} \sigma_{\rm d}&=\sqrt{\sigma_A^2+\sigma_B^2}\\ &=\sqrt{1.30^2+2.21^2}\\ &=\sqrt{6.5741}=2.564\%,\\ V_{\rm d}&=\$1{,}000{,}000\times2.564\%\\ &=\$25{,}640. \end{aligned} \]

$\sigma_{\rm d}$ คือความผันผวนเฉพาะตัวของพอร์ตตามแบบจำลองนี้ และ $V_{\rm d}$ คือตัวเลขเดียวกันเป็นดอลลาร์ต่อวัน ตัวห้อย d มาจาก diagonal ซึ่งเป็นชื่อเรียกแบบจำลองนี้ (ภาพรวมด้านล่างอธิบายที่มาของชื่อ) สรุปคือทั้งสองโต๊ะได้รายงานเดียวกัน ว่าความเสี่ยงเฉพาะตัวคือ \$25,640 ต่อวัน

แต่สองชั้นนี้เป็นบริษัทเดียวกัน ส่วนเฉพาะตัวของมันจึงน่าจะขยับไปด้วยกัน สมมติว่า correlation จริงของส่วนเฉพาะตัวของสองชั้นคือ $\rho=0.82$ (ตัวเลขสมมติ) แบบจำลองผิดกับพอร์ตไหน และผิดทางไหน?

ลองตอบก่อนเปิดเฉลย

ผิดทั้งสองพอร์ต และผิดคนละทิศ ตัวเลขทุกตัวในเฉลยนี้ หน้านี้จะคำนวณให้ดูทีละขั้นในขั้นสุดท้าย

พอร์ตที่ long ทั้งสองชั้นเสี่ยงจริง \$33,594 ต่อวัน มากกว่าที่รายงาน $33{,}594/25{,}640-1=31.0\%$ เพราะเมื่อสองชั้นขยับไปทางเดียวกัน สองขาก็ขาดทุนพร้อมกัน

พอร์ต long A short B เสี่ยงจริงแค่ \$13,647 ต่อวัน แบบจำลองรายงานสูงเกินไป $25{,}640/13{,}647-1=87.9\%$ เพราะส่วนที่สองชั้นขยับไปด้วยกันหักล้างกันระหว่างขา long กับขา short

ความผิดแบบหลังแพงกว่าที่เห็น โต๊ะมีเพดานความเสี่ยง คือความเสี่ยงสูงสุดที่บริษัทยอมให้ถือ และเพดานนี้วัดด้วยตัวเลขของแบบจำลอง แบบจำลองบอกว่าทุก \$1 ล้านเสี่ยง \$25,640 ทั้งที่จริงเสี่ยงแค่ \$13,647 โต๊ะจึงเทรดได้แค่ $13{,}647/25{,}640=53.2\%$ ของขนาดที่ความเสี่ยงจริงยอมให้ ทั้งที่นี่เป็นการเทรดที่ปลอดภัยที่สุดแบบหนึ่ง และไม่มีรายงานไหนแสดงกำไรที่หายไปนี้

ภาพรวมก่อนลงสูตร

ส่วนเฉพาะตัวของหุ้นได้มาจาก cross-sectional regression คือ regression ผลตอบแทนของหุ้นทุกตัวในวันเดียวกันบน factor ส่วนที่ regression อธิบายไม่ได้ (residual) ของหุ้น $i$ ในวัน $t$ คือส่วนเฉพาะตัว เขียนว่า $\hat\epsilon_{i,t}$

หน้านี้สร้าง covariance matrix ของส่วนเฉพาะตัว เขียนว่า $\boldsymbol\Omega_\epsilon$ มันเป็นตารางขนาด $n\times n$ เมื่อ $n$ คือจำนวนหุ้น ช่องบนแนวทแยง (แถวกับคอลัมน์เป็นหุ้นตัวเดียวกัน) คือ variance ของส่วนเฉพาะตัวของหุ้นตัวนั้น ช่องนอกแนวทแยงคือ covariance ระหว่างส่วนเฉพาะตัวของหุ้นสองตัว matrix นี้สำคัญ เพราะในพอร์ตของโต๊ะที่เลือกหุ้นทีละตัวและหักล้างความเสี่ยงจาก factor ออกไปแล้ว ความเสี่ยงจากส่วนเฉพาะตัวมักเป็นก้อนที่ใหญ่กว่าฝั่ง factor (ดู การแยกความเสี่ยงเป็นส่วนของ factor กับส่วนเฉพาะตัว)

factor model สมมติว่าส่วนเฉพาะตัวของหุ้นต่างตัวไม่สัมพันธ์กัน ช่องนอกแนวทแยงจึงเป็นศูนย์หมด เหลือค่าแค่บนแนวทแยง matrix แบบนี้เรียกว่า matrix แนวทแยง (diagonal matrix) และเป็นที่มาของตัวห้อย d ในโจทย์เปิดหน้า ถ้าข้อสมมตินี้ถูก งานส่วนใหญ่ก็คือประมาณ variance ของหุ้นทีละตัวให้ดี

ข้อสมมตินี้ถูกกับเกือบทุกคู่ แต่ผิดแรงกับคู่ไม่กี่คู่ และมักเป็นคู่ที่คนเทรดกันมาก ตัวอย่างเช่น

  • หุ้นสองชั้นของบริษัทเดียวกัน เช่น Berkshire Hathaway มีหุ้น BRK.A กับ BRK.B
  • บริษัทจีนที่จดทะเบียนทั้งในจีนแผ่นดินใหญ่และในฮ่องกง
  • ธีมแคบ ๆ เช่นบริษัทเหมืองทองไม่กี่แห่งที่ขยับตามราคาทองด้วยกัน

ทำไม factor จับคู่เหล่านี้ไม่ได้? เพราะ factor ต้องกระทบหุ้นจำนวนมาก (เรียกว่า pervasive) จึงจะมองเห็นได้ใน regression ที่ใช้หุ้นหลายร้อยตัว สิ่งที่หุ้นแค่สองสามตัวมีร่วมกันจึงไม่กลายเป็น factor มันตกไปอยู่ในส่วนเฉพาะตัวของหุ้นแต่ละตัวแทน ส่วนเฉพาะตัวของหุ้นกลุ่มนั้นจึงสัมพันธ์กัน

รูปด้านล่างเล่าทั้งเรื่องในภาพเดียว correlation ของส่วนเฉพาะตัวที่วัดได้ส่วนใหญ่เป็นค่าเล็ก ๆ ที่เกิดจากเสียงรบกวนของข้อมูล ถ้าตัดค่าเล็กทิ้งด้วยเกณฑ์ที่เลือกดี จะเหลือแค่กลุ่มไม่กี่กลุ่มที่อธิบายได้ หน้านี้ทำงานตามลำดับนี้

  1. ประมาณแนวทแยง และดึงหุ้นที่ข้อมูลน้อยเข้าหาค่าเฉลี่ย
  2. ดูว่าทำไม matrix เต็มที่คำนวณจากข้อมูลตรง ๆ ใช้ไม่ได้
  3. คำนวณว่าเสียงรบกวนล้วน ๆ สร้าง correlation ได้ใหญ่แค่ไหน
  4. เลือกเกณฑ์สำหรับตัด
  5. ตัดแล้วจับกลุ่มด้วยมือ กับหุ้นหกตัว
  6. ดูว่าการตัดทำให้ matrix พังได้อย่างไร
  7. คิดราคาของการไม่ทำอะไรเลย กับโจทย์เปิดหน้า
ศัพท์ที่ใช้ในหัวข้อนี้
Idiosyncratic covariance matrix
covariance matrix ขนาด $n\times n$ ของส่วนเฉพาะตัว เขียนว่า $\boldsymbol\Omega_\epsilon$ ส่วนเฉพาะตัวคือส่วนของผลตอบแทนที่ factor อธิบายไม่ได้ ช่องบนแนวทแยงคือ variance เฉพาะตัวของหุ้นแต่ละตัว ช่องนอกแนวทแยงคือ covariance ที่ยังเหลืออยู่ระหว่างหุ้นสองตัวหลังหัก factor ออกแล้ว
Share class และ dual listing
share class คือหุ้นคนละชั้นของบริษัทเดียวกัน dual listing คือบริษัทเดียวที่จดทะเบียนในสองตลาด ทั้งสองแบบราคาขยับเกือบเหมือนกันแต่ไม่เท่ากัน และเป็นตัวอย่างที่ชัดที่สุดของ correlation ที่ factor จับไม่ได้
EWMA
ค่าเฉลี่ยถ่วงน้ำหนักที่ให้ข้อมูลวันล่าสุดหนักกว่าวันเก่า น้ำหนักลดลงครึ่งหนึ่งทุก ๆ half-life วัน
Thresholding
การตั้ง correlation ที่ขนาดไม่เกินเกณฑ์ $\theta$ ให้เป็นศูนย์ เก็บไว้เฉพาะค่าที่ใหญ่พอจะไม่ใช่เสียงรบกวน
Cluster
กลุ่มหุ้นที่เดินถึงกันได้ผ่านคู่ที่รอดเกณฑ์ เช่นหุ้น 3 ติดกับหุ้น 4 และหุ้น 4 ติดกับหุ้น 5 ก็นับว่า 3, 4 และ 5 อยู่กลุ่มเดียวกัน (ในทฤษฎีกราฟเรียกว่า connected component) ต้องเปิดดูเสมอว่ากลุ่มนั้นอธิบายได้ไหม เช่นเป็นบริษัทเดียวกัน หรืออยู่ในธีมเดียวกัน
Positive definite
สมบัติของ covariance matrix ที่ทำให้ทุกพอร์ต (ที่ไม่ใช่ศูนย์) มี variance เป็นบวก ตรวจได้จาก eigenvalue ตัวที่เล็กที่สุดว่ามากกว่าศูนย์ไหม optimizer (โปรแกรมที่หาน้ำหนักพอร์ตที่ดีที่สุด) ต้องการสมบัตินี้
Shrinkage ของ variance เฉพาะตัว
การดึง variance ของหุ้นแต่ละตัวเข้าหาค่าเฉลี่ยของหุ้นทุกตัวเล็กน้อย ช่วยหุ้นที่มีข้อมูลน้อย ซึ่งค่าที่วัดได้เหวี่ยงมาก

ขั้นที่ 1 — แนวทแยงก่อน: EWMA แล้วดึงหุ้นที่ข้อมูลน้อยเข้าหาค่าเฉลี่ย

ก่อนจะสนใจช่องนอกแนวทแยง ต้องทำแนวทแยงให้ดีก่อน เพราะแนวทแยงคือ variance เฉพาะตัวของหุ้นทุกตัว และเป็นส่วนที่แบบจำลองใช้มากที่สุด งานนี้มีสองจังหวะ

  • ใช้ EWMA (ค่าเฉลี่ยที่ให้วันล่าสุดหนักกว่าวันเก่า) กับ $\hat\epsilon^2$ ของหุ้นแต่ละตัว แบบจำลองรายวันที่ต้องตอบสนองเร็วใช้ half-life ราว 126 วัน คือน้ำหนักลดลงครึ่งหนึ่งทุก 126 วันทำการ ราวครึ่งปี ($252/2=126$)
  • ดึงค่าที่ได้เข้าหาค่าเฉลี่ยของหุ้นทุกตัวเล็กน้อย เรียกว่า shrinkage เพราะหุ้นที่ข้อมูลน้อยวัดได้คลาดมาก
\[ \begin{aligned} \hat\sigma_{i,t}^2&=\textstyle\sum_s w_s\,\hat\epsilon_{i,t-s}^2,\\ \tilde\sigma_i^2&=(1-\delta)\,\hat\sigma_i^2+\delta\,\bar\sigma^2. \end{aligned} \]

EWMA ของส่วนเฉพาะตัวยกกำลังสองให้ $\hat\sigma_i^2$ คือ variance เฉพาะตัวของหุ้น $i$ ที่วัดจากข้อมูลของมันเอง $w_s$ คือน้ำหนักของข้อมูลเมื่อ $s$ วันก่อน น้ำหนักลดลงเมื่อข้อมูลเก่าขึ้น และรวมกันได้ 1

การดึงเข้าหาค่าเฉลี่ยให้ $\tilde\sigma_i^2$ โดย $\bar\sigma^2$ คือค่าเฉลี่ยของ $\hat\sigma_i^2$ ของหุ้นทุกตัว มันคือค่าเฉลี่ยถ่วงน้ำหนักระหว่างสิ่งที่หุ้นตัวนี้บอกเอง กับสิ่งที่หุ้นทั้งตลาดบอก $\delta=0$ คือเชื่อข้อมูลของหุ้นตัวนี้ทั้งหมด $\delta=1$ คือให้ทุกตัวได้ค่าเดียวกัน หน้า factor covariance ดึง matrix เข้าหา $\tfrac1n\operatorname{trace}\cdot\mathbf I$ ซึ่งสำหรับ matrix แนวทแยงก็คือสิ่งเดียวกันพอดี เพราะ trace หารด้วย $n$ คือค่าเฉลี่ยของแนวทแยง

ทำไมต้องดึง? ลองดูหุ้นที่เพิ่งเข้าตลาดตัวหนึ่ง (ตัวเลขสมมติ)

  • มีข้อมูลแค่ $N=20$ วัน
  • ความผันผวนเฉพาะตัวที่วัดได้ $\hat\sigma_i=3.6\%$ ต่อวัน
  • ค่าเฉลี่ยของ variance เฉพาะตัวของหุ้นทุกตัว $\bar\sigma^2=2.2^2$ คือความผันผวนเฉลี่ยราว 2.2% ต่อวัน
  • สัดส่วนที่ดึง $\delta=0.3$

ก่อนอื่นต้องรู้ว่าค่า 3.6% ที่วัดจาก 20 วันคลาดได้แค่ไหน ถ้าส่วนเฉพาะตัวแจกแจงแบบ Normal $\hat\epsilon^2$ ของแต่ละวันมี variance $3\sigma^4-\sigma^4=2\sigma^4$ (เพราะ moment ที่สี่ของ Normal คือ $3\sigma^4$) variance ที่วัดได้คือค่าเฉลี่ยของ $\hat\epsilon^2$ จำนวน $N$ วัน มันจึงมี variance $2\sigma^4/N$ จากนั้นแปลงเป็นความคลาดของความผันผวน

\[ \begin{aligned} \operatorname{sd}(\hat\sigma^2)&\approx\sqrt{2\sigma^4/N}=\sigma^2\sqrt{2/N},\\ \operatorname{sd}(\hat\sigma)&\approx\frac{\operatorname{sd}(\hat\sigma^2)}{2\sigma}=\frac{\sigma}{\sqrt{2N}},\\ N=20&:\ \tfrac{\operatorname{sd}(\hat\sigma)}{\sigma}=\tfrac1{\sqrt{40}}=15.8\%. \end{aligned} \]

จังหวะที่ต้องคิดคือการแปลงจาก $\hat\sigma^2$ เป็น $\hat\sigma$ เพราะ $\hat\sigma=\sqrt{\hat\sigma^2}$ และอนุพันธ์ของ $\sqrt x$ คือ $\tfrac1{2\sqrt x}$ ถ้า $\hat\sigma^2$ คลาดไป $\Delta$ ความผันผวนจึงคลาดไปราว $\Delta/(2\sigma)$ ผลคือความผันผวนที่วัดจาก 20 วันคลาดได้ราว 15.8% ของตัวมันเอง

คิดเป็นตัวเลข $3.6\times0.158=0.57$ ค่าจริงจึงอาจเป็น 3.0% หรือ 4.2% ได้ง่าย ๆ ส่วนหุ้นที่มีข้อมูลเต็มปีคลาดแค่ $1/\sqrt{2\times251}=4.5\%$ จึงควรดึงน้อยกว่ามาก

ทีนี้ดึงหุ้นตัวนี้เข้าหาค่าเฉลี่ยด้วย $\delta=0.3$ โดยใส่ตัวเลขลงในสูตรของ $\tilde\sigma_i^2$

\[ \begin{aligned} \tilde\sigma_i^2&=0.7\times3.6^2+0.3\times2.2^2\\ &=9.072+1.452\\ &=10.524,\\ \tilde\sigma_i&=\sqrt{10.524}=3.244\%. \end{aligned} \]

การดึงขยับความผันผวนลง $3.6-3.244=0.356$ จุด อยู่ในช่วงที่ค่าวัดได้คลาดอยู่แล้ว เราจึงแทบไม่เสียอะไร แต่ได้ค่าที่เหวี่ยงน้อยลงสำหรับหุ้นที่ข้อมูลน้อย

ข้อควรระวังเรื่องข้อมูลที่ป้อนเข้ามามีสองข้อ ข้อแรก regression ที่ให้ $\hat\epsilon$ ถ่วงน้ำหนักหุ้นแต่ละตัวด้วยความผันผวนเฉพาะตัว น้ำหนักนั้นต้องใช้ค่าที่รู้ถึงเมื่อวานเท่านั้น เพราะค่าของวันนี้ยังไม่มีใครรู้ ณ เวลาที่คำนวณ ข้อสอง รอบวันประกาศผลประกอบการ หุ้นที่ประกาศจะขยับแรงชั่วคราว ให้จัดการด้วย earnings tent ซึ่งเพิ่มความเสี่ยงเฉพาะหุ้นที่อยู่ในช่วงประกาศ ถ้าไปปรับหุ้นทุกตัวพร้อมกัน ข่าวของบริษัทไม่กี่แห่งจะดันความเสี่ยงของหุ้นหลายร้อยตัวที่ไม่มีข่าวขึ้นไปด้วย

ขั้นที่ 2 — ทำไมใช้ matrix เต็มจากข้อมูลตรง ๆ ไม่ได้

ทำไมไม่คำนวณ covariance ของส่วนเฉพาะตัวทุกคู่จากข้อมูลไปเลย? ลองนับขนาดของงานดู ตัวอย่างของบทนี้ใช้

  • จักรวาลหุ้น (universe คือรายชื่อหุ้นทั้งหมดที่แบบจำลองดูแล) $n=600$ ตัว
  • ข้อมูลย้อนหลังหนึ่งปี $T=251$ วันทำการ คือจำนวนวันที่ตลาดหุ้นสหรัฐเปิดในหนึ่งปี ซึ่งมีราว 250 ถึง 252 วัน

ปัญหาแรกคือ matrix ที่ได้มี “ทิศที่ไม่มีความเสี่ยง” matrix ที่คำนวณจากข้อมูลคือค่าเฉลี่ยของ matrix รายวัน 251 ตัว โดย $\hat{\boldsymbol\epsilon}_t$ คือ vector ขนาด 600 ที่เก็บส่วนเฉพาะตัวของหุ้นทุกตัวในวัน $t$

\[ \begin{aligned} \hat{\boldsymbol\Omega}_\epsilon&=\tfrac1T\textstyle\sum_{t=1}^{T}\hat{\boldsymbol\epsilon}_t\hat{\boldsymbol\epsilon}_t^{\mathsf T},\\ \operatorname{rank}(\hat{\boldsymbol\Omega}_\epsilon)&\le T=251,\\ n-T&=600-251=349. \end{aligned} \]

matrix รายวัน $\hat{\boldsymbol\epsilon}_t\hat{\boldsymbol\epsilon}_t^{\mathsf T}$ มี rank หนึ่ง เพราะทุกคอลัมน์ของมันเป็น $\hat{\boldsymbol\epsilon}_t$ คูณด้วยตัวเลขตัวหนึ่ง rank ของผลบวกไม่เกินผลบวกของ rank ผลบวกของ 251 ตัวจึงมี rank ไม่เกิน 251 แต่หุ้นมี 600 ตัว จึงเหลืออย่างน้อย 349 ทิศที่ matrix ให้ variance เป็นศูนย์

ทิศเหล่านี้คือพอร์ตที่แบบจำลองเชื่อว่าไม่มีความเสี่ยงเฉพาะตัวเลย optimizer จะเจอพอร์ตแบบนี้แล้วทุ่มเงินลงไป ทั้งที่ความเสี่ยงจริงไม่ใช่ศูนย์ matrix นี้จึงไม่ positive definite และยังไม่ sparse ด้วย (sparse คือช่องส่วนใหญ่เป็นศูนย์)

ปัญหาที่สองคือเสียงรบกวน แต่ละคู่วัดจากข้อมูลแค่ 251 วัน correlation ที่วัดได้จึงคลาดจากค่าจริง นับจำนวนคู่ก่อน แล้วดูว่าแต่ละคู่คลาดได้แค่ไหน

\[ \begin{aligned} \tfrac{n(n-1)}2&=\tfrac{600\times599}2=179{,}700,\\ \operatorname{sd}(\hat\rho_{ij})&\approx\frac{1-\rho_{ij}^2}{\sqrt T},\\ \rho_{ij}=0&:\ \tfrac1{\sqrt{251}}=\tfrac1{15.84}=0.0631. \end{aligned} \]

จำนวนคู่คือการเลือกหุ้นสองตัวจาก 600 ตัว นับคู่ละครั้ง สูตรความคลาดของ correlation เป็นสูตรเดียวกับที่หน้า factor covariance ใช้เลือก half-life ของ correlation คู่ที่ไม่เกี่ยวกันเลย ($\rho_{ij}=0$) จึงยังวัดได้ $\hat\rho$ แกว่งไปมาราว ±0.0631

ช่องนอกแนวทแยงทั้ง 179,700 ช่องจึงเป็นเสียงรบกวนเกือบทั้งหมด งานจริงคือหาคู่ไม่กี่คู่ที่เป็นของจริงในกองนั้น ส่วนการตั้งนอกแนวทแยงเป็นศูนย์หมดตามแบบจำลองแนวทแยง ก็คือ shrinkage แบบสุดทาง ซึ่งทิ้งคู่จริงไปด้วย

ขั้นที่ 3 — เสียงรบกวนล้วน ๆ ไปได้ไกลแค่ไหน

วิธีแก้ที่ตรงไปตรงมาคือเลือกเกณฑ์ $\theta$ แล้วเก็บไว้เฉพาะคู่ที่ $\lvert\hat\rho_{ij}\rvert\gt\theta$ คำถามคือเกณฑ์ต้องสูงแค่ไหน ถ้าต่ำไป คู่ปลอมจะหลุดเข้ามา คู่ปลอมคือคู่ที่จริง ๆ ไม่เกี่ยวกัน แต่บังเอิญวัดได้ correlation สูง

ลองสมมติว่าทุกคู่ไม่เกี่ยวกันจริง ($\rho_{ij}=0$) แล้ว $\hat\rho_{ij}$ ของแต่ละคู่มีการแจกแจงใกล้ Normal ที่ค่าเฉลี่ย 0 และ SD $1/\sqrt T=0.0631$ คู่หนึ่งรอดเกณฑ์เมื่อ $\hat\rho_{ij}$ เกิน $\theta$ หรือต่ำกว่า $-\theta$ จำนวนคู่ปลอมโดยเฉลี่ยจึงเท่ากับจำนวนคู่คูณโอกาสนั้น

\[ \begin{aligned} z&=\frac{\theta}{1/\sqrt T}=\theta\sqrt T=\theta\times15.84,\\ Q(z)&=P(Z\gt z),\\ N(\theta)&=179{,}700\times2Q(z). \end{aligned} \]

$z$ คือเกณฑ์ที่นับเป็นจำนวน SD ของเสียงรบกวน $Z$ คือตัวแปร Normal มาตรฐาน และ $Q(z)$ คือพื้นที่หางขวาของมันที่เลย $z$ ไป คูณสองเพราะคู่ปลอมหลุดได้ทั้งทางบวกและทางลบ $N(\theta)$ คือจำนวนคู่ปลอมที่คาดว่าจะรอดเกณฑ์ ค่า $Q(z)$ เปิดจากตาราง Normal หรือคำนวณด้วยโค้ดท้ายหน้า

ขั้นที่ 4 — เกณฑ์จากทฤษฎี และคู่จริงอยู่ตรงไหน

ขั้นที่แล้วให้ขอบล่างของเกณฑ์ ต่ำกว่าราว 0.30 คู่ปลอมเริ่มหลุดเข้ามา ขั้นนี้หาอีกสองอย่าง อย่างแรกคือเกณฑ์ที่ทฤษฎีแนะนำ อย่างที่สองคือขอบบน คือสูงแค่ไหนแล้วคู่จริงเริ่มถูกตัดทิ้ง

งานวิจัยเรื่องการตัด covariance matrix (Cai และคณะ) แสดงว่าเกณฑ์ควรโตตาม $\sqrt{\ln n/T}$ ส่วนค่าคงที่ $K$ ข้างหน้าทฤษฎีไม่ได้กำหนดแน่ หน้านี้ใช้ $K=2$ ซึ่งมีเหตุผลคร่าว ๆ ดังนี้ ค่าที่ใหญ่ที่สุดของตัวแปร Normal มาตรฐาน $m$ ตัวอยู่ราว $\sqrt{2\ln m}$ จำนวนคู่ $m$ มีราว $n^2/2$ ถ้าปัด $\ln(n^2/2)$ เป็น $\ln n^2$ คู่ปลอมตัวที่ใหญ่ที่สุดจึงอยู่ราว $\sqrt{2\ln n^2}=2\sqrt{\ln n}$ เท่าของ SD เสียง คูณด้วย SD เสียง $1/\sqrt T$ ได้ $2\sqrt{\ln n/T}$ ซึ่งคือสูตรเมื่อ $K=2$

\[ \begin{aligned} \theta_\star&=K\sqrt{\ln n/T}\\ &=2\sqrt{\ln600/251}\\ &=2\sqrt{6.397/251}\\ &=2\times0.1596=0.3193. \end{aligned} \]

เกณฑ์นี้คือ “ระดับที่คู่ปลอมตัวที่ใหญ่ที่สุดในกองน่าจะไปถึง” $\ln n$ อยู่ในสูตรเพราะยิ่งมีหุ้นมาก ก็ยิ่งมีคู่ให้บังเอิญวัดได้สูงมาก $T$ อยู่ในตัวหารเพราะยิ่งมีข้อมูลมาก เสียงของแต่ละคู่ก็ยิ่งเบา

ทีนี้มาหาขอบบน คู่จริงก็วัดได้คลาดเหมือนกัน ถ้าโชคร้าย ค่าที่วัดได้อาจต่ำกว่าค่าจริงมาก ใช้สูตรความคลาดของ correlation จากขั้นที่ว่าด้วย matrix เต็ม กับคู่หุ้นสองชั้นที่ $\rho=0.82$ และธีมที่ $\rho=0.58$ แล้วดูว่าค่าที่วัดได้ลงไปต่ำได้แค่ไหน ถ้าต่ำกว่าค่าจริงสองเท่าของ SD (โอกาสต่ำกว่านั้นราว 2 ครั้งใน 100)

\[ \begin{aligned} \rho=0.82&:\ \operatorname{sd}=\tfrac{1-0.6724}{15.84}=0.0207,\\ &\quad0.82-2\times0.0207=0.779,\\ \rho=0.58&:\ \operatorname{sd}=\tfrac{1-0.3364}{15.84}=0.0419,\\ &\quad0.58-2\times0.0419=0.496. \end{aligned} \]

ตอนนี้เห็นหน้าต่างทั้งสองข้าง ขอบล่างมาจากเสียงรบกวน ต่ำกว่า 0.30 คู่ปลอมเริ่มหลุดเข้ามา ขอบบนมาจากคู่จริงที่อ่อนที่สุด ซึ่งคือธีมที่ 0.58 เหนือราว 0.50 คู่ในธีมเริ่มเสี่ยงถูกตัด ระหว่างสองขอบนี้ ผลการจับกลุ่มไม่ควรเปลี่ยน ช่วงนี้เรียกว่าที่ราบ และ $\theta_\star=0.3193$ ตกในที่ราบพอดีเมื่อ $K=2$ ส่วนคู่หุ้นสองชั้นที่ 0.82 ปลอดภัยมาก เพราะแม้โชคร้ายก็ยังวัดได้ราว 0.779

วิธีที่ใช้จริงจึงไม่ใช่การเชื่อสูตร แต่คือลองหลายเกณฑ์แล้วดูสองอย่าง อย่างแรก กลุ่มนิ่งไหมเมื่อขยับเกณฑ์เล็กน้อย อย่างที่สอง กลุ่มอธิบายได้ไหม เช่นหุ้นอยู่อุตสาหกรรมเดียวกัน หรือมี loading ของ style factor คล้ายกัน (loading คือตัวเลขที่บอกว่าหุ้นขยับตาม factor นั้นแรงแค่ไหน)

ถ้า $n$ หรือ $T$ เปลี่ยน ที่ราบก็เลื่อนตาม เช่นถ้าใช้ข้อมูลแค่ครึ่งปี $T=125$ วัน เสียงของแต่ละคู่จะเป็น $1/\sqrt{125}=0.0894$ ดังขึ้นจาก 0.0631 ขอบล่างจึงขยับขึ้น ขอบบนขยับลง และที่ราบแคบลง

ขั้นที่ 6 — การตัดทำ matrix พังได้: ตรวจ eigenvalue ทุกครั้ง

ตัวอย่างหกหุ้นผ่านการตรวจ แต่ไม่ได้ผ่านเสมอไป matrix ที่วัดจากข้อมูลตรง ๆ เป็น positive semidefinite เสมอ คือไม่มีพอร์ตไหนมี variance ติดลบ เพราะมันเป็นค่าเฉลี่ยของ $\hat{\boldsymbol\epsilon}_t\hat{\boldsymbol\epsilon}_t^{\mathsf T}$ และพอร์ต $\mathbf w$ ใด ๆ ได้ $\mathbf w^{\mathsf T}\hat{\boldsymbol\epsilon}_t\hat{\boldsymbol\epsilon}_t^{\mathsf T}\mathbf w=(\mathbf w^{\mathsf T}\hat{\boldsymbol\epsilon}_t)^2\ge0$ ทุกวัน แต่พอตัดบางช่องทิ้ง matrix ก็ไม่ได้เป็นค่าเฉลี่ยแบบนั้นแล้ว จึงไม่มีอะไรรับประกัน ลองดูหุ้นสามตัว (ตัวเลขสมมติ)

  • correlation ที่วัดได้ของคู่ 1–2 คือ 0.9 คู่ 2–3 คือ 0.9 และคู่ 1–3 คือ 0.70
  • matrix นี้ใช้ได้ eigenvalue ของมันคือ 0.03, 0.30 และ 2.67 (คำนวณด้วยโค้ดท้ายหน้า) ทุกตัวเป็นบวก
  • ตั้งเกณฑ์ที่ 0.75 คู่ 1–3 ($0.70\lt0.75$) จึงถูกตั้งเป็นศูนย์ ส่วนสองคู่ที่ 0.9 รอด

ตรวจด้วย determinant ก่อนตัด ซึ่งต้องเท่ากับผลคูณของ eigenvalue

\[ \begin{aligned} \det\mathbf R&=1(1-0.81)-0.9(0.9-0.63)\\ &\quad+0.7(0.81-0.7)\\ &=0.19-0.243+0.077\\ &=0.024,\\ 0.03\times0.30\times2.67&=0.024. \end{aligned} \]

หลังตัด ลองพอร์ตที่ long หุ้นสองตัวริม และ short หุ้นตัวกลางหนักกว่า $\mathbf w=\tfrac12(1,\,-\sqrt2,\,1)$ ความยาวของมันคือ $\sqrt{\tfrac14(1+2+1)}=1$ เลือก $\mathbf w$ นี้เพราะมันเป็น eigenvector ของ matrix หลังตัด ดังที่จะตรวจด้านล่าง

\[ \begin{aligned} \mathbf R_\theta&=\begin{bmatrix}1&0.9&0\\0.9&1&0.9\\0&0.9&1\end{bmatrix},\\ \mathbf R_\theta\mathbf w&=(1-0.9\sqrt2)\,\mathbf w,\\ \mathbf w^{\mathsf T}\mathbf R_\theta\mathbf w&=(1-0.9\sqrt2)\,\mathbf w^{\mathsf T}\mathbf w\\ &=1-1.2728=-0.2728. \end{aligned} \]

ทำไม $\mathbf R_\theta\mathbf w=(1-0.9\sqrt2)\,\mathbf w$? คูณทีละแถวดู

\[ \begin{aligned} (\mathbf R_\theta\mathbf w)_1&=\tfrac12-0.9\tfrac{\sqrt2}2=\tfrac12(1-0.9\sqrt2),\\ (\mathbf R_\theta\mathbf w)_2&=0.9\tfrac12-\tfrac{\sqrt2}2+0.9\tfrac12\\ &=0.9-\tfrac{\sqrt2}2=-\tfrac{\sqrt2}2(1-0.9\sqrt2),\\ (\mathbf R_\theta\mathbf w)_3&=\tfrac12(1-0.9\sqrt2). \end{aligned} \]

ทุกช่องคือช่องเดียวกันของ $\mathbf w=(\tfrac12,\,-\tfrac{\sqrt2}2,\,\tfrac12)$ คูณด้วย $1-0.9\sqrt2$ จังหวะที่ต้องดูคือช่องกลาง: $-\tfrac{\sqrt2}2\times(-0.9\sqrt2)=0.9$ พอดี $\mathbf w$ จึงเป็น eigenvector ที่ eigenvalue $1-0.9\sqrt2=-0.2728$ และเพราะ $\mathbf w^{\mathsf T}\mathbf w=1$ variance ของพอร์ตนี้จึงเท่ากับ eigenvalue นั้น คือติดลบ ซึ่งเป็นไปไม่ได้ในโลกจริง แต่ optimizer จะเห็นพอร์ตที่ “ความเสี่ยงต่ำกว่าศูนย์” แล้วรีบใช้มัน

ต้นเหตุคือหุ้น 1 และหุ้น 3 ต่างก็ติดกับหุ้น 2 แน่นมาก ถ้าสองตัวนี้ใกล้หุ้น 2 ขนาดนั้น มันก็ต้องใกล้กันเองด้วย สำหรับหุ้นสามตัว correlation ของคู่ 1–3 ต้องไม่ต่ำกว่าค่านี้ matrix จึงจะใช้ได้

\[ \begin{aligned} \rho_{13}&\ge\rho_{12}\rho_{23}-\sqrt{(1-\rho_{12}^2)(1-\rho_{23}^2)}\\ &=0.81-\sqrt{0.19\times0.19}\\ &=0.81-0.19=0.62. \end{aligned} \]

ขอบนี้มาจากเงื่อนไขว่า determinant ของ matrix $3\times3$ ต้องไม่ติดลบ ค่าที่วัดได้ 0.70 อยู่เหนือ 0.62 จึงใช้ได้ แต่การตัดดันมันลงไปเป็น 0 ซึ่งต่ำกว่าขอบมาก ตัวเลขชุดหลังตัดจึงเป็นไปไม่ได้

ทางแก้คือตรวจ eigenvalue เล็กสุดทุกครั้งหลังตัด ถ้าติดลบ มีสองทาง ทางแรก ลดเกณฑ์ลงจนคู่ 1–3 รอด (ต่ำกว่า 0.70) ทางที่สอง ผสม matrix กับ $\mathbf I$ เป็น $(1-\delta)\mathbf R_\theta+\delta\mathbf I$ ซึ่งยก eigenvalue ทุกตัวเข้าหา 1 โจทย์ข้อ 3 ท้ายหน้าให้คำนวณว่าต้องผสมอย่างน้อยเท่าไร

เป็นบวกอย่างเดียวยังไม่พอ eigenvalue เล็กสุดควรห่างจากศูนย์พอสมควรด้วย matrix ที่ eigenvalue เล็กสุดเฉียดศูนย์เรียกว่า ill-conditioned optimizer จะเห็นพอร์ตที่ดูเหมือนแทบไม่มีความเสี่ยงแล้วทุ่มเงินลงไป ความคลาดเล็ก ๆ ในตัวเลขจึงกลายเป็นน้ำหนักพอร์ตที่ผิดมาก

ขั้นที่ 7 — ราคาของการไม่ทำอะไร

กลับไปที่โจทย์เปิดหน้า ขั้นนี้คำนวณว่าถ้าไม่ใส่ correlation ของส่วนเฉพาะตัวเลย ตัวเลขความเสี่ยงผิดไปเท่าไร และผิดทางไหน โดยดูทั้งคู่หุ้นสองชั้นและธีมเหมืองทอง

โจทย์ให้อะไรมาบ้าง:

  • คู่หุ้นสองชั้นของโจทย์เปิดหน้า $\sigma_A=1.30\%$ และ $\sigma_B=2.21\%$ ต่อวัน correlation ของส่วนเฉพาะตัว $\rho=0.82$
  • ธีมเหมืองทองห้าตัว แต่ละตัวมีความผันผวนเฉพาะตัว $\sigma=2.75\%$ ต่อวัน และทุกคู่มี correlation $\rho=0.58$ (ตัวเลขสมมติ)
  • ถือตัวละ \$1 ล้าน ขาที่ short ก็ \$1 ล้าน
  • ความเสี่ยงเป็นดอลลาร์ต่อวัน คือ \$1,000,000 คูณความผันผวนของพอร์ตที่เป็น %

เริ่มจากคู่หุ้นสองชั้น variance ของผลบวกหรือผลต่างของสองอย่างคือ variance ของแต่ละอย่าง บวกหรือลบสองเท่าของ covariance และ covariance คือ $\rho\sigma_A\sigma_B$ พอร์ต long ทั้งคู่ใช้เครื่องหมายบวก พอร์ต long A short B ใช้เครื่องหมายลบ

\[ \begin{aligned} \sigma_\pm^2&=\sigma_A^2+\sigma_B^2\pm2\rho\sigma_A\sigma_B,\\ \sigma_{\rm d}^2&=1.30^2+2.21^2=6.5741,\\ 2\rho\sigma_A\sigma_B&=2(0.82)(1.30)(2.21)\\ &=4.7117,\\ \sigma_+&=\sqrt{6.5741+4.7117}\\ &=\sqrt{11.2858}=3.3594\%,\\ \sigma_-&=\sqrt{6.5741-4.7117}\\ &=\sqrt{1.8624}=1.3647\%. \end{aligned} \]

แบบจำลองแนวทแยงทิ้งพจน์ไขว้ $2\rho\sigma_A\sigma_B$ ไป จึงเหลือแค่ $\sigma_{\rm d}^2$ เดียวกันสำหรับทั้งสองพอร์ต มันไม่รู้จักเครื่องหมายของขาเลย ความจริงคือพจน์ไขว้ 4.7117 บวกเข้าในพอร์ต long ทั้งคู่ และลบออกในพอร์ตเก็บส่วนต่าง ทิศของความผิดจึงกลับกันตามเครื่องหมายของขา

ต่อด้วยธีมห้าตัว variance ของพอร์ตคือผลบวกของทุกช่องใน covariance matrix $5\times5$ ช่องบนแนวทแยงมี 5 ช่อง ช่องละ $\sigma^2$ ช่องนอกแนวทแยงมี $5\times4=20$ ช่อง ช่องละ $\rho\sigma^2$

\[ \begin{aligned} \sigma_{5,\rm d}&=\sqrt{5\sigma^2}=2.75\sqrt5=6.1492\%,\\ \sigma_5^2&=\sigma^2\big(5+20\rho\big),\\ 5+20(0.58)&=16.6,\\ \sigma_5&=2.75\sqrt{16.6}=11.2044\%,\\ \sigma_5/\sigma_{5,\rm d}&=\sqrt{16.6/5}=1.8221. \end{aligned} \]

$\sigma_{5,\rm d}$ คือสิ่งที่แบบจำลองแนวทแยงเห็น และ $\sigma_5$ คือความจริง แบบจำลองนับแค่ 5 ช่องบนแนวทแยง แต่ทิ้ง 20 ช่องนอกแนวทแยงที่ทุกช่องเป็นบวก ยิ่งกลุ่มใหญ่ ช่องที่ถูกทิ้งยิ่งมากกว่าช่องที่นับ ความผิดจึงโตตามขนาดกลุ่ม

ตั้งเกณฑ์ต่ำเพื่อไม่ให้พลาดคู่จริง: ฟังดูปลอดภัย แต่เกณฑ์ต่ำปล่อยคู่ปลอมเข้ามาเป็นร้อย ที่ $\theta=0.20$ คาดว่าจะได้คู่ปลอม $179{,}700\times2Q(3.17)=275.3$ คู่ ที่ 0.25 ยังเหลือ 13.4 คู่ ส่วนที่ 0.30 ซึ่งอยู่ในที่ราบ เหลือแค่ 0.36 คู่ matrix ที่ได้จากเกณฑ์ต่ำเต็มไปด้วยความสัมพันธ์ที่ไม่มีอยู่จริง optimizer จะเชื่อว่าหุ้นสองตัวที่ไม่เกี่ยวกัน hedge กันได้ (คือขาดทุนของตัวหนึ่งถูกกำไรของอีกตัวหักล้าง) แล้วสร้างพอร์ตจากมัน ผลแย่กว่าไม่ใส่อะไรเลย

ตัดแล้วไม่ตรวจ eigenvalue: matrix ก่อนตัดของตัวอย่างสามหุ้นใช้ได้ (eigenvalue เล็กสุด 0.03) แต่หลังตัดคู่ 1–3 ทิ้ง พอร์ต $\mathbf w=\tfrac12(1,\,-\sqrt2,\,1)$ ได้ variance $1-0.9\sqrt2=-0.2728$ การแก้ช่องนอกแนวทแยงทีละคู่ไม่รับประกันอะไรเลย ต้องตรวจ eigenvalue เล็กสุดของทั้ง matrix ทุกครั้ง

เปลี่ยนกลุ่มเป็น factor โดยไม่คิดเรื่องรายงาน: การแยก PnL แบ่งกำไรขาดทุนเป็นบรรทัดของ factor กับบรรทัดเฉพาะตัว และบรรทัดเฉพาะตัวคือตัวเลขที่ใช้วัดฝีมือเลือกหุ้น ถ้าเปลี่ยนกลุ่มหนึ่งเป็น factor ใหม่ กำไรจากการเทรดกลุ่มนั้นจะย้ายจากบรรทัดเฉพาะตัวไปบรรทัด factor ทันที และหายไปจากตัวเลขที่ใช้วัดฝีมือ จึงต้องตั้งใจเลือก ไม่ใช่เปลี่ยนเพราะสะดวก

เชื่อกลุ่มที่อธิบายไม่ได้: กลุ่มที่โผล่มาแค่ที่เกณฑ์เดียวแล้วหายไปเมื่อขยับเกณฑ์ 0.05 หรือกลุ่มที่รวมหุ้นที่ไม่มีอะไรเหมือนกันเลย มักเป็นเสียงรบกวน ใส่มันเข้าไปก็เท่ากับใส่คู่ปลอม กลุ่มจริงอย่างหุ้นสองชั้นในข้อมูลจำลองอยู่รอดตลอดที่ราบตั้งแต่ 0.30 ถึง 0.55

ใช้ทำอะไรบนโต๊ะจริง

ทีมที่ดูแลแบบจำลองความเสี่ยงทำงานนี้เป็นรอบ ๆ ขั้นตอนคือ

  1. ตัด correlation ของส่วนเฉพาะตัวด้วยหลายเกณฑ์ เพื่อหาที่ราบที่กลุ่มไม่เปลี่ยน
  2. เปิดดูรายชื่อในแต่ละกลุ่ม ว่าอธิบายได้ไหม เช่นหุ้นสองชั้น บริษัทที่จดทะเบียนสองตลาด บริษัทแม่กับบริษัทลูก หรือธีมแคบ ๆ
  3. ตรวจ eigenvalue เล็กสุดของ matrix หลังตัด

จากนั้นเลือกหนึ่งในสามทางกับแต่ละกลุ่ม

  • ใส่ correlation ตรง ๆ: ใส่ correlation ที่รอดเกณฑ์ลงในช่องนอกแนวทแยงของ $\boldsymbol\Omega_\epsilon$ เหมาะกับคู่และกลุ่มเล็ก
  • เพิ่ม factor ใหม่: เช่น factor ของ share class โดยใช้ push-out เหมาะเมื่อกลุ่มใหญ่และเกิดซ้ำ เช่นบริษัทจีนที่มีหุ้นชั้น A, B และ H ซึ่งซื้อขายในตลาดต่างกัน ไม่ใช่หุ้นตัวเดียวกัน แต่ขยับใกล้กัน
  • เก็บแค่ชั้นเดียว: ถ้ากลยุทธ์ลงทุนตามพื้นฐานของบริษัท ให้ใส่แค่ชั้นที่ซื้อขายคล่องที่สุดชั้นเดียวในจักรวาลตั้งแต่แรก ปัญหาก็หายไปเอง

ทางที่สามใช้ไม่ได้กับโต๊ะที่ตั้งใจเก็บส่วนต่างราคาระหว่างสองชั้น เพราะโต๊ะนั้นต้องถือทั้งสองชั้น จึงต้องใส่ correlation ให้ถูก ไม่อย่างนั้นจะเจอปัญหาแบบโจทย์เปิดหน้า

โจทย์ตรวจความเข้าใจ

1. โต๊ะหนึ่งเก็บส่วนต่างราคาของหุ้นสองชั้นอีกคู่หนึ่ง ทั้งสองชั้นมีความผันผวนเฉพาะตัวเท่ากัน $\sigma=1.5\%$ ต่อวัน และ correlation ของส่วนเฉพาะตัว $\rho=0.9$ โต๊ะ long ชั้นหนึ่ง \$1 ล้าน และ short อีกชั้น \$1 ล้าน แบบจำลองแนวทแยงรายงานความเสี่ยงต่อวันเท่าไร และความจริงเท่าไร?

เฉลย

ใช้สูตร $\sigma_\pm^2$ ของขั้นสุดท้าย เมื่อสองขาผันผวนเท่ากันและเป็นพอร์ต long หนึ่ง short หนึ่ง

\[ \begin{aligned} \sigma_{\rm d}&=\sqrt{1.5^2+1.5^2}=1.5\sqrt2\\ &=2.1213\%,\\ \sigma_-&=\sqrt{2(1.5^2)-2(0.9)(1.5^2)}\\ &=1.5\sqrt{2-1.8}=1.5\sqrt{0.2}\\ &=0.6708\%,\\ \sigma_{\rm d}/\sigma_-&=\sqrt{2/0.2}=\sqrt{10}=3.16. \end{aligned} \]

แบบจำลองแนวทแยงรายงาน $10^6\times2.1213\%=\$21{,}213$ ต่อวัน ความจริงคือ $10^6\times0.6708\%=\$6{,}708$ ต่อวัน แบบจำลองสูงไป 3.16 เท่า ยิ่ง correlation ใกล้ 1 พอร์ตเก็บส่วนต่างยิ่งปลอดภัย และแบบจำลองแนวทแยงยิ่งผิดมาก

2. ทีมความเสี่ยงขยายจักรวาลเป็นหุ้น $n=1{,}000$ ตัว และยังใช้ข้อมูล $T=251$ วันเท่าเดิม มีกี่คู่ เกณฑ์ $\theta_\star$ ที่ $K=2$ คือเท่าไร และถ้ายังใช้เกณฑ์ 0.30 คาดว่าคู่ปลอมหลุดเข้ามากี่คู่?

เฉลย
\[ \begin{aligned} \tfrac{n(n-1)}2&=\tfrac{1{,}000\times999}2=499{,}500,\\ \theta_\star&=2\sqrt{\ln1{,}000/251}\\ &=2\sqrt{6.9078/251}=0.3318,\\ z&=0.30\times15.84=4.75,\\ N(0.30)&=499{,}500\times2Q(4.75)\\ &=499{,}500\times0.00000201=1.0. \end{aligned} \]

ได้ 499,500 คู่ เกณฑ์จากทฤษฎีขยับขึ้นเป็น 0.3318 และที่เกณฑ์ 0.30 คาดว่าคู่ปลอมหลุดเข้ามาราว 1 คู่ มากกว่า 0.36 คู่ของหุ้น 600 ตัว เพราะจำนวนคู่เพิ่มขึ้น $499{,}500/179{,}700=2.78$ เท่า ยิ่งมีคู่มาก ก็ยิ่งมีโอกาสที่บางคู่บังเอิญวัดได้สูง เกณฑ์จึงต้องขยับขึ้นตาม $\sqrt{\ln n}$

3. กลับไปที่หุ้นสามตัวที่การตัดทำให้ eigenvalue ติดลบ ทางแก้หนึ่งคือผสม matrix หลังตัดกับ $\mathbf I$ เป็น $(1-\delta)\mathbf R_\theta+\delta\mathbf I$ ต้องใช้ $\delta$ อย่างน้อยเท่าไร matrix จึงกลับมา positive definite?

เฉลย

ทุก vector เป็น eigenvector ของ $\mathbf I$ ที่ eigenvalue 1 การผสมจึงไม่เปลี่ยน eigenvector ของ $\mathbf R_\theta$ แค่เปลี่ยน eigenvalue $\lambda$ แต่ละตัวเป็น $(1-\delta)\lambda+\delta$ ตัวที่อันตรายคือตัวเล็กสุด $\lambda=-0.2728$

\[ \begin{aligned} \lambda_{\min}&=(1-\delta)(-0.2728)+\delta\\ &=-0.2728+1.2728\,\delta\gt0,\\ \delta&\gt0.2728/1.2728=0.2143. \end{aligned} \]

ต้องผสม $\mathbf I$ เข้าไปมากกว่า 21.43% ถ้าผสมน้อยกว่านี้ ยังมีพอร์ตที่ variance ติดลบ

// Upper Normal tail Q(x) = P(Z > x) from its continued fraction (accurate for x of 1 or more)
function normalTail(x) {
  let f = x;
  for (let k = 60; k >= 1; k--) f = x + k / f;
  return exp(-x * x / 2) / sqrt(2 * PI) / f;
}
function eigenvalues(S) {                               // cyclic Jacobi rotations, sorted
  const n = S.length, A = S.map(row => [...row]);
  for (let sweep = 0; sweep < 100; sweep++) {
    let off = 0;
    for (let i = 0; i < n; i++) for (let j = i + 1; j < n; j++) off += A[i][j] * A[i][j];
    if (off < 1e-30) break;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) {
      if (A[p][q] === 0) continue;
      const theta = (A[q][q] - A[p][p]) / (2 * A[p][q]);
      const t = (theta >= 0 ? 1 : -1) / (abs(theta) + sqrt(theta * theta + 1)), c = 1 / sqrt(t * t + 1), s = t * c;
      for (let k = 0; k < n; k++) { const akp = A[k][p], akq = A[k][q]; A[k][p] = c * akp - s * akq; A[k][q] = s * akp + c * akq; }
      for (let k = 0; k < n; k++) { const apk = A[p][k], aqk = A[q][k]; A[p][k] = c * apk - s * aqk; A[q][k] = s * apk + c * aqk; }
    }
  }
  return A.map((row, i) => row[i]).sort((a, b) => a - b);
}
// Keep correlations bigger than the threshold, then group stocks linked by kept pairs (union-find)
function threshold(R, theta) {
  const n = R.length, kept = R.map((row, i) => row.map((x, j) => (i === j ? 1 : abs(x) > theta ? x : 0)));
  const parent = [...Array(n).keys()], find = i => (parent[i] === i ? i : (parent[i] = find(parent[i])));
  const pairs = [];
  for (let i = 0; i < n; i++) for (let j = i + 1; j < n; j++) if (kept[i][j] !== 0) { pairs.push([i + 1, j + 1]); parent[find(i)] = find(j); }
  const groups = {};
  for (let i = 0; i < n; i++) (groups[find(i)] = groups[find(i)] || []).push(i + 1);
  return {kept, pairs, clusters: Object.values(groups)};
}
// Daily risk in dollars of positions w (dollars) with daily vols (%) and a correlation matrix R
function dollarRisk(w, vol, R) {
  let s = 0;
  for (let i = 0; i < w.length; i++) for (let j = 0; j < w.length; j++) s += w[i] * w[j] * vol[i] * vol[j] * R[i][j] / 1e4;
  if (s < 0) throw new RangeError('negative variance: the correlation matrix is not positive definite');
  return sqrt(s);
}

  • matrix เต็มที่คำนวณจาก 251 วันของหุ้น 600 ตัวใช้ตรง ๆ ไม่ได้ มันมีอย่างน้อย $600-251=349$ ทิศที่ความเสี่ยงเฉพาะตัวเป็นศูนย์ และ correlation ทั้ง 179,700 คู่แกว่งราว ±0.0631 จากเสียงรบกวนล้วน
  • จำนวนคู่ปลอมที่คาดว่าจะรอดเกณฑ์คือ $179{,}700\times2Q(\theta\sqrt T)$ ได้ 275.3 คู่ที่เกณฑ์ 0.20 และ 0.36 คู่ที่ 0.30 ส่วนคู่จริงที่อ่อนที่สุด (0.58) ยังวัดได้เหนือ 0.496 แม้โชคร้าย เกณฑ์จึงเลือกจากที่ราบระหว่างสองขอบนี้ และ $\theta_\star=0.3193$ ตกในนั้น
  • หลังตัดต้องตรวจ eigenvalue เล็กสุดทุกครั้ง ตัวอย่างสามหุ้นได้พอร์ตที่ variance −0.2728 จาก matrix ที่ก่อนตัดใช้ได้
  • ถ้าไม่ใส่ correlation ของส่วนเฉพาะตัวเลย ความเสี่ยงผิดได้ทั้งสองทิศ พอร์ต long ทั้งสองชั้นเสี่ยงจริงสูงกว่าที่รายงาน 31.0% ธีมห้าตัวสูงกว่าที่รายงาน 82.2% ส่วนพอร์ตเก็บส่วนต่างถูกรายงานสูงไป 87.9% จนโต๊ะเทรดได้แค่ 53.2% ของขนาดที่ความเสี่ยงจริงยอมให้
