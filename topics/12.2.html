12.2 The Gradient and First-Order Conditions

gradient บอกว่าถ้าขยับน้ำหนักสินทรัพย์แต่ละตัวนิดหนึ่ง ความเสี่ยงของพอร์ตจะเปลี่ยนเท่าไร และที่จุดต่ำสุด จะไม่มีทิศที่อนุญาตทิศไหนลดความเสี่ยงได้อีก

กองทุนแห่งหนึ่งถือพอร์ตที่มีสินทรัพย์สองอย่าง คือหุ้นกับพันธบัตร ทุกวันจะมีเทรดเดอร์มาขอซื้อของเพิ่ม และผู้ดูแลความเสี่ยงต้องตอบให้ได้ทันทีว่า แต่ละคำขอทำให้ความเสี่ยงของพอร์ตเพิ่มขึ้นเท่าไร

ของที่รู้ (ตัวเลขสมมติ):

  • NAV (net asset value) คือมูลค่ารวมของพอร์ต น้ำหนักของสินทรัพย์คือสัดส่วนของ NAV ที่ลงในสินทรัพย์ตัวนั้น
  • พอร์ตวันนี้เป็น “60/40” คือหุ้น $x_1=0.6$ และพันธบัตร $x_2=0.4$
  • ความผันผวนต่อปีของหุ้น $\sigma_1=20\%$ และของพันธบัตร $\sigma_2=10\%$ ความผันผวนคือ SD (standard deviation) ของผลตอบแทนรายปี บอกว่าผลตอบแทนแกว่งกว้างแค่ไหน
  • correlation ของหุ้นกับพันธบัตร $\rho=0.30$ correlation เป็นตัวเลขระหว่าง −1 ถึง 1 ที่บอกว่าสองอย่างขึ้นลงพร้อมกันแค่ไหน 0.30 แปลว่าขึ้นลงตามกันบ้างเล็กน้อย

ด้วยตัวเลขชุดนี้ พอร์ต 60/40 มีความผันผวน 13.74% ต่อปี (หน้านี้จะคำนวณให้ดูในขั้นที่ 3)

วันนี้มีคำขอสองคำขอ

  • เทรดเดอร์คนแรกขอซื้อหุ้นเพิ่มอีก 1% ของ NAV โดยกู้เงินมาซื้อ เงินกู้มีดอกเบี้ยที่รู้ล่วงหน้าแน่นอน มันจึงไม่แกว่ง และไม่เพิ่มความเสี่ยงเอง
  • เทรดเดอร์คนที่สองขอซื้อพันธบัตรเพิ่ม 1% ของ NAV ด้วยเงินกู้แบบเดียวกัน

หัวหน้าคิดแบบนี้: หุ้นแกว่งมากกว่าพันธบัตร $20\%/10\%=2$ เท่า ดังนั้นคำขอแรกควรเพิ่มความเสี่ยงของพอร์ตเป็น 2 เท่าของคำขอที่สอง ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก หน้านี้จะคำนวณตัวเลขเหล่านี้ให้ดูทีละขั้น (ขั้นที่ 3 และขั้นที่ 5)

  • คำขอแรกทำให้ความผันผวนของพอร์ตขึ้นราว 0.192 จุดเปอร์เซ็นต์ คือจาก 13.74% เป็นราว 13.93%
  • คำขอที่สองทำให้ขึ้นแค่ราว 0.055 จุดเปอร์เซ็นต์
  • สองคำขอต่างกัน $0.192133/0.055311\approx3.47$ เท่า ไม่ใช่ 2 เท่า

ที่หัวหน้าพลาดเพราะดูแค่ความผันผวนของสินทรัพย์ตัวเดียว แต่สิ่งที่กำหนดผลจริงคือสินทรัพย์ตัวนั้นขึ้นลงไปกับพอร์ตที่ถืออยู่แค่ไหน ตัววัดนี้คือ covariance ของสินทรัพย์กับพอร์ต ได้ 0.0264 สำหรับหุ้น และ 0.0076 สำหรับพันธบัตร พอร์ตนี้มีหุ้นอยู่แล้ว 60% หุ้นก้อนใหม่จึงขึ้นลงพร้อมกับหุ้นก้อนเดิม ความเสี่ยงจึงซ้อนกันเต็ม ๆ ชุดตัวเลขที่ตอบว่า “ขยับแต่ละตัวนิดหนึ่ง ความเสี่ยงเปลี่ยนเท่าไร” เรียกว่า gradient ของความเสี่ยง และเป็นเรื่องของหน้านี้

ภาพรวมก่อนลงสูตร

ในฟังก์ชันตัวแปรเดียว อนุพันธ์คือความชัน มันบอกว่าถ้าขยับ $x$ ไปทางขวานิดหนึ่ง ค่าของฟังก์ชันขึ้นหรือลงเท่าไร แต่ความเสี่ยงของพอร์ตขึ้นกับน้ำหนักหลายตัวพร้อมกัน เราจึงต้องมีความชันหนึ่งตัวต่อน้ำหนักหนึ่งตัว

ความชันแต่ละตัวตอบว่า “ขยับน้ำหนักตัวนี้ตัวเดียว ตัวอื่นอยู่กับที่ ความเสี่ยงเปลี่ยนเท่าไร” ความชันแบบนี้เรียกว่า partial derivative ถ้าเอา partial derivative ทุกตัวมาเรียงเป็น vector จะได้ gradient ในงานพอร์ต แต่ละช่องของ gradient ตอบคำถามที่เทรดเดอร์ถามทุกวัน: ถ้าเพิ่มสินทรัพย์ตัวนี้นิดหนึ่ง ความเสี่ยงของพอร์ตที่ถืออยู่เปลี่ยนเท่าไร

หน้านี้วัดความเสี่ยงด้วย variance ของพอร์ต เขียนเป็น $q$ variance คือความผันผวนยกกำลังสอง ($q=\sigma_p^2$) ใช้แทนความผันผวนเพราะคิดอนุพันธ์ง่ายกว่า แล้วค่อยแปลงกลับเป็นความผันผวนในขั้นที่ 5

รูปด้านล่างเป็นแผนที่เส้นระดับของ variance เหมือนแผนที่ภูเขาที่เส้นแต่ละเส้นเชื่อมจุดที่สูงเท่ากัน ในที่นี้แต่ละเส้นเชื่อมพอร์ตที่มี variance เท่ากัน gradient คือลูกศรที่ชี้ไปทางที่ variance ขึ้นเร็วที่สุด และมันตั้งฉากกับเส้นระดับเสมอ เพราะถ้าเดินเลียบเส้นระดับ ค่าไม่เปลี่ยนเลย ที่พอร์ต 60/40 ลูกศรชี้ไปทางแกนหุ้นเกือบตรง แปลว่าความเสี่ยงของพอร์ตนี้ไวต่อหุ้นมากที่สุด

ลำดับของหน้านี้

  • หา gradient ของ variance ด้วยมือ แล้วพิสูจน์สูตรทั่วไป $\nabla q=2Vx$ ($x$ คือ vector น้ำหนัก และ $V$ คือ covariance matrix ซึ่งขั้นที่ 1 จะสร้างให้ดู)
  • ใช้สูตรนี้ตอบคำขอของเทรดเดอร์ในโจทย์เปิดเรื่อง
  • วัดว่าการทำนายด้วยเส้นตรงพลาดเท่าไรเมื่อ trade ใหญ่ขึ้น
  • แปลงผลเป็นหน่วยความผันผวนที่คนคุยกันจริง
  • หาทิศที่ลดความเสี่ยงได้เร็วที่สุด
  • ตั้ง first-order condition (เงื่อนไขอันดับหนึ่ง): ที่จุดต่ำสุด ต้องไม่มีทิศที่อนุญาตทิศไหนลดความเสี่ยงต่อได้ สำหรับพอร์ตที่ต้องลงเงินครบ 100% เงื่อนไขนี้กลายเป็นกฎ “marginal risk เท่ากันทุกตัว”

ขั้นที่ 1 — partial derivative ทีละพจน์ของพอร์ตสองตัว

เราอยากรู้ว่า variance ของพอร์ตเปลี่ยนเท่าไรเมื่อขยับน้ำหนักทีละตัว จึงต้องเขียน variance เป็นสูตรของน้ำหนักก่อน หน้า ความเสี่ยงของพอร์ต ให้สูตร $q(x)=x^{\mathsf T}Vx$ ไว้แล้ว โดย $V$ คือ covariance matrix บนแนวทแยงคือ variance ของแต่ละตัว ($\sigma^2$) นอกแนวทแยงคือ covariance ของคู่นั้น ($\rho\sigma_1\sigma_2$) แทนตัวเลขของหุ้นกับพันธบัตรได้ดังนี้

\[ \begin{aligned} V_{11}&=\sigma_1^2=0.2^2=0.04,\\ V_{22}&=\sigma_2^2=0.1^2=0.01,\\ V_{12}&=\rho\sigma_1\sigma_2=0.3(0.2)(0.1)=0.006,\\ q(x)&=V_{11}x_1^2+2V_{12}x_1x_2+V_{22}x_2^2\\ &=0.04x_1^2+0.012x_1x_2+0.01x_2^2. \end{aligned} \]

พจน์กลางมีเลข 2 เพราะ $V_{12}=V_{21}$ และ $x^{\mathsf T}Vx$ นับคู่นี้สองครั้ง ($x_1V_{12}x_2$ กับ $x_2V_{21}x_1$) ต่อไปหา partial derivative เทียบ $x_1$ คือขยับ $x_1$ นิดเดียว โดยถือ $x_2$ เป็นค่าคงที่ แล้วหาอนุพันธ์ตามปกติ ทำแบบเดียวกันกับ $x_2$ แล้วเรียงผลทั้งสองเป็น vector ก็ได้ gradient

\[ \begin{aligned} \nabla q&=\begin{bmatrix}\partial q/\partial x_1\\ \partial q/\partial x_2\end{bmatrix},\\ \frac{\partial q}{\partial x_1}&=0.08x_1+0.012x_2+0,\\ \frac{\partial q}{\partial x_2}&=0+0.012x_1+0.02x_2,\\ \nabla q&=2\begin{bmatrix}0.04x_1+0.006x_2\\0.006x_1+0.01x_2\end{bmatrix}=2Vx. \end{aligned} \]

partial derivative ก็คืออนุพันธ์ธรรมดา แค่มองตัวแปรอื่นเป็นตัวเลข เมื่อหาเทียบ $x_1$ พจน์ $0.04x_1^2$ ให้ $0.08x_1$ ตามกฎ $d(ax^2)/dx=2ax$ พจน์กลาง $0.012x_1x_2$ เป็นแค่ “ค่าคงที่คูณ $x_1$” เพราะ $x_2$ ถูกตรึงไว้ อนุพันธ์จึงเหลือ $0.012x_2$ ส่วนพจน์ $0.01x_2^2$ ไม่มี $x_1$ เลย ขยับ $x_1$ แล้วมันไม่เปลี่ยน อนุพันธ์จึงเป็น 0

ส่วนที่น่าสนใจอยู่ตอนท้าย ถ้าดึงเลข 2 ออก ช่องบนที่เหลือคือ $0.04x_1+0.006x_2$ ซึ่งเป็นแถวแรกของ $V$ คูณกับ $x$ ช่องล่างก็เป็นแถวที่สองของ $V$ คูณกับ $x$ ทั้งก้อนจึงเป็น $Vx$ พอดี ผลนี้หน้าตาเหมือนกฎ $2ax$ ของตัวแปรเดียว แค่ตัวเลข $a$ กลายเป็น matrix $V$ แต่ที่ทำมานี้ใช้ได้กับสองสินทรัพย์เท่านั้น ขั้นถัดไปจึงพิสูจน์ว่าสูตรนี้จริงกับสินทรัพย์กี่ตัวก็ได้

ขั้นที่ 2 — กางพอร์ตหลัง trade ออกตรง ๆ แล้วได้ทั้ง gradient และตัวคลาดเคลื่อน

พอร์ตจริงมีสินทรัพย์เป็นร้อยตัว จึงต้องรู้ว่า $\nabla q=2Vx$ จริงกับ $n$ ตัวหรือไม่ วิธีที่ตรงกับงานที่สุดคือถามคำถามเดียวกับเทรดเดอร์: ถ้าน้ำหนักเปลี่ยนไปด้วย vector $d$ variance ใหม่ $q(x+d)$ เป็นเท่าไร (เช่น $d=(0.01, 0)$ คือซื้อหุ้นเพิ่ม 1% ของ NAV และพันธบัตรเท่าเดิม)

เราจะกางวงเล็บตรง ๆ โดยใช้ข้อเท็จจริงข้อเดียว: $V$ สมมาตร คือ $V_{ij}=V_{ji}$ เพราะ covariance ของ $i$ กับ $j$ เท่ากับของ $j$ กับ $i$ จากนั้นเลือก $d=he_k$ คือขยับน้ำหนักช่อง $k$ ช่องเดียวไป $h$ ($e_k$ คือ vector ที่ช่อง $k$ เป็น 1 ช่องอื่นเป็น 0) แล้วใช้นิยามของอนุพันธ์ สัญลักษณ์ $(Vx)_k$ คือช่องที่ $k$ ของ $Vx$ และ $V_{kk}$ คือตัวบนแนวทแยงช่องที่ $k$

\[ \begin{aligned} q(x+d)&=(x+d)^{\mathsf T}V(x+d)\\ &=x^{\mathsf T}Vx+x^{\mathsf T}Vd+d^{\mathsf T}Vx+d^{\mathsf T}Vd\\ &=q(x)+2\,d^{\mathsf T}Vx+d^{\mathsf T}Vd,\\ d=he_k:&\quad q(x+he_k)-q(x)\\ &=2h\,(Vx)_k+h^2V_{kk},\\ \frac{\partial q}{\partial x_k}&=\lim_{h\to0}\big(2(Vx)_k+hV_{kk}\big)\\ &=2(Vx)_k. \end{aligned} \]

ก้าวที่ต้องระวังคือการรวมสองพจน์กลาง $x^{\mathsf T}Vd$ กับ $d^{\mathsf T}Vx$ เป็น $2\,d^{\mathsf T}Vx$ ก้าวนี้ทำได้เพราะ $x^{\mathsf T}Vd$ เป็นตัวเลขตัวเดียว และตัวเลขตัวเดียว transpose แล้วได้ตัวเดิม: $x^{\mathsf T}Vd=(x^{\mathsf T}Vd)^{\mathsf T}=d^{\mathsf T}V^{\mathsf T}x=d^{\mathsf T}Vx$ เพราะ $V^{\mathsf T}=V$ หลังจากนั้นที่เหลือคือนิยามของอนุพันธ์: ขยับช่อง $k$ ไป $h$ หารผลเปลี่ยนด้วย $h$ แล้วให้ $h$ เล็กลงจนเป็นศูนย์ พจน์ $hV_{kk}$ จึงหายไป เหลือ $2(Vx)_k$ ซึ่งคือช่องที่ $k$ ของ $2Vx$ จริงกับทุก $k$ และทุก $n$

สมการ $q(x+d)=q(x)+2\,d^{\mathsf T}Vx+d^{\mathsf T}Vd$ ยังให้ของแถมที่ใช้ทั้งหน้า มันเป็นสมการเป๊ะ ไม่ใช่การประมาณ พจน์ $2\,d^{\mathsf T}Vx$ เท่ากับ $\nabla q^{\mathsf T}d$ คือส่วนที่ gradient ทำนาย ส่วน $d^{\mathsf T}Vd$ คือสิ่งที่การทำนายด้วยเส้นตรงทิ้งไป และมันคือ variance ของพอร์ต $d$ เอง จึงไม่มีวันติดลบ ดังนั้นสำหรับ variance การทำนายด้วย gradient ไม่เคยสูงกว่าผลจริง

ขั้นที่ 3 — แทนพอร์ต 60/40

ตอนนี้มีสูตรแล้ว จึงแทนตัวเลขของพอร์ตในโจทย์เปิดเรื่องเพื่อตอบคำถามของหัวหน้า

โจทย์ให้อะไรมาบ้าง:

  • น้ำหนัก $x=(0.6, 0.4)$ คือหุ้น 60% พันธบัตร 40%
  • covariance matrix $V$ จากขั้นที่ 1: ทแยง 0.04 และ 0.01 นอกทแยง 0.006

คูณแต่ละแถวของ $V$ กับน้ำหนักก่อน ได้ $Vx$ แล้วค่อยคูณ 2 เป็น gradient ส่วน variance ของพอร์ตได้จาก $q=x^{\mathsf T}(Vx)$ คือเอาน้ำหนักคูณกับ $Vx$ ทีละช่องแล้วบวกกัน

\[ \begin{aligned} Vx&=\begin{bmatrix}0.04(0.6)+0.006(0.4)\\0.006(0.6)+0.01(0.4)\end{bmatrix} =\begin{bmatrix}0.0264\\0.0076\end{bmatrix},\\ \nabla q&=2Vx=(0.0528,\ 0.0152),\\ q&=0.6(0.0264)+0.4(0.0076)\\ &=0.01584+0.00304=0.01888,\\ \sigma_p&=\sqrt{0.01888}\approx13.7405\%. \end{aligned} \]

คำตอบ: gradient คือ $(0.0528, 0.0152)$ ถ้าเพิ่มน้ำหนักเท่ากัน หุ้นดัน variance ขึ้นมากกว่าพันธบัตร $0.0528/0.0152\approx3.474$ เท่า ทั้งที่ความผันผวนของตัวเองต่างกันแค่ $20\%/10\%=2$ เท่า

ทำไมถึงเป็นแบบนั้น ช่องที่ $i$ ของ $Vx$ คือ covariance ของสินทรัพย์ $i$ กับพอร์ตทั้งก้อน ดูช่องหุ้นเป็นตัวอย่าง ผลตอบแทนของพอร์ตคือ $x_1r_1+x_2r_2$ ($r_1, r_2$ คือผลตอบแทนของหุ้นและพันธบัตร) covariance แยกคิดทีละพจน์ของผลบวกได้ และ covariance ของหุ้นกับตัวเองคือ variance ของหุ้น $V_{11}$ covariance ของหุ้นกับพอร์ตจึงเป็น

\[ \begin{aligned} \operatorname{Cov}(r_1,\ x_1r_1+x_2r_2)&=x_1V_{11}+x_2V_{12}\\ &=0.6(0.04)+0.4(0.006)\\ &=0.0264=(Vx)_1. \end{aligned} \]

หุ้นขึ้นลงไปกับพอร์ตนี้ด้วย covariance 0.0264 แต่พันธบัตรแค่ 0.0076 ส่วนใหญ่ของ 0.0264 มาจาก $0.6(0.04)=0.024$ คือหุ้น 60% ที่ถืออยู่แล้ว ตัวเลขนี้จึงขึ้นกับพอร์ต ถ้าเปลี่ยนน้ำหนัก ตัวเลขก็เปลี่ยน (โจทย์ข้อ 1 ท้ายหน้าลองที่พอร์ต 50/50)

ตรวจเองใน 10 วินาที: น้ำหนักคูณ gradient ต้องได้สองเท่าของ variance เพราะ $x^{\mathsf T}(2Vx)=2x^{\mathsf T}Vx=2q$

\[ \begin{aligned} x^{\mathsf T}\nabla q&=0.6(0.0528)+0.4(0.0152)\\ &=0.03168+0.00608=0.03776\\ &=2(0.01888). \end{aligned} \]

ขั้นที่ 4 — ทำนาย trade แล้ววัดว่าพลาดเท่าไร

gradient บอกอัตราเปลี่ยนที่จุดเดียว แต่ trade จริงมีขนาด เช่น 1% หรือ 10% ของ NAV เราจึงต้องรู้ว่าการทำนายด้วย gradient พลาดเท่าไรเมื่อ trade ใหญ่ขึ้น สมการเป๊ะจากขั้นที่ 2 แยกผลเปลี่ยนเป็นสองส่วนให้แล้ว: $\Delta q=\nabla q^{\mathsf T}d+d^{\mathsf T}Vd$

โจทย์ให้อะไรมาบ้าง:

  • คำขอแรกของโจทย์เปิดเรื่อง: ซื้อหุ้นเพิ่ม 1% ของ NAV คือ $d=(0.01, 0)$ เงินที่ใช้มาจากการกู้ ซึ่งไม่แกว่ง จึงไม่มีพจน์ของเงินกู้ใน $q$
  • gradient จากขั้นที่ 3 คือ $(0.0528, 0.0152)$ และ $V_{11}=0.04$
  • เพื่อเทียบ ลอง trade ใหญ่ขึ้นสิบเท่า $d=(0.10, 0)$

เพราะ $d$ มีแค่ช่องหุ้น พจน์ความโค้ง $d^{\mathsf T}Vd$ จึงเหลือแค่ $V_{11}d_1^2$

\[ \begin{aligned} \nabla q^{\mathsf T}d&=0.0528(0.01)=0.000528,\\ d^{\mathsf T}Vd&=0.04(0.01)^2=0.000004,\\ \Delta q&=0.000528+0.000004=0.000532,\\ d=(0.10, 0):&\quad0.0528(0.10)+0.04(0.10)^2\\ &=0.00528+0.0004=0.00568. \end{aligned} \]

คำตอบ: ที่ 1% เส้นตรงทำนายได้ $0.000528/0.000532\approx99.25\%$ ของผลจริง แต่ที่ 10% พจน์ความโค้งโตจาก 0.000004 เป็น 0.0004 คือ $(0.10/0.01)^2=100$ เท่า ขณะที่ส่วนเส้นตรงโตแค่ 10 เท่า เส้นตรงจึงพลาด $0.0004/0.00568\approx7.04\%$ ของผลจริง ส่วนที่ทิ้งไปโตตามกำลังสองของขนาด trade

กฎที่ใช้บนโต๊ะเทรดจึงเป็นแบบนี้: ใช้ marginal risk กับการปรับเล็ก ๆ ส่วน trade ก้อนใหญ่ให้คำนวณพอร์ตใหม่ทั้งก้อน ซึ่งสำหรับ variance ก็แค่บวก $d^{\mathsf T}Vd$ เข้าไป

ตรวจเองใน 10 วินาที: คำนวณ variance ตรง ๆ ที่พอร์ตหลัง trade $(0.61, 0.40)$ แล้วลบของเดิม

\[ \begin{aligned} q(0.61, 0.40)&=0.04(0.61)^2+0.012(0.61)(0.40)\\ &\quad+0.01(0.40)^2\\ &=0.014884+0.002928+0.0016\\ &=0.019412,\\ \Delta q&=0.019412-0.01888=0.000532. \end{aligned} \]

ตรงกับผลจากสมการเป๊ะ

ขั้นที่ 5 — แปลงเป็นหน่วยความผันผวนที่คนคุยกันจริง

0.0528 เป็นอัตราเปลี่ยนของ variance ซึ่งมีหน่วยเป็นผลตอบแทนยกกำลังสอง ไม่มีใครพูดในห้องประชุมว่า “variance ขึ้น 0.000528” คนพูดกันเป็นความผันผวน เช่น “ความผันผวนขึ้นจาก 13.74% เป็น 13.93%” เราจึงต้องแปลง gradient ของ variance เป็น gradient ของความผันผวน $\sigma_p=\sqrt q$

ใช้ chain rule: อนุพันธ์ของ $\sqrt q$ เทียบ $q$ คือ $1/(2\sqrt q)$ แล้วคูณด้วย $\partial q/\partial x_i=2(Vx)_i$ จากขั้นที่ 2 ค่าที่ต้องใช้คือ $\sigma_p=\sqrt{0.01888}\approx0.137405$ จากขั้นที่ 3

\[ \begin{aligned} \frac{\partial\sigma_p}{\partial x_i}&=\frac{1}{2\sqrt q}\cdot2(Vx)_i=\frac{(Vx)_i}{\sigma_p},\\ \frac{\partial\sigma_p}{\partial x_1}&=\frac{0.0264}{0.137405}\approx0.192133,\\ \frac{\partial\sigma_p}{\partial x_2}&=\frac{0.0076}{0.137405}\approx0.055311,\\ x_1\frac{\partial\sigma_p}{\partial x_1}&=0.6(0.192133)\approx0.115280,\\ x_2\frac{\partial\sigma_p}{\partial x_2}&=0.4(0.055311)\approx0.022124. \end{aligned} \]

ความไว 0.192133 แปลว่า ถ้าเพิ่มน้ำหนักหุ้น 1% ความผันผวนของพอร์ตขึ้นราว $0.01\times0.192133\approx0.00192$ คือ 0.192 จุดเปอร์เซ็นต์ (“จุด” คือหน่วยของผลต่างระหว่างสองเปอร์เซ็นต์ เช่นจาก 13.74% เป็น 13.93% คือขึ้น 0.19 จุด) ฝั่งพันธบัตร เพิ่ม 1% ทำนายได้ $0.01\times0.055311\approx0.000553$ คือ 0.0553 จุด นี่คือตัวเลขที่ตอบโจทย์เปิดเรื่อง

ลองเทียบกับการคำนวณตรง variance หลังเพิ่มหุ้น 1% คือ 0.019412 จากขั้นที่ 4 ส่วนหลังเพิ่มพันธบัตร 1% คือ $0.01888+0.0152(0.01)+0.01(0.01)^2=0.019033$ จากสมการเป๊ะแบบเดียวกัน

\[ \begin{aligned} \sqrt{0.019412}-\sqrt{0.01888}&\approx13.93270\%-13.74045\%\\ &\approx0.1922,\\ \sqrt{0.019033}-\sqrt{0.01888}&\approx13.79601\%-13.74045\%\\ &\approx0.0556. \end{aligned} \]

ผลตรงแทบเท่ากับที่ทำนาย อัตราส่วนของสองความไวคือ $0.192133/0.055311\approx3.474$ เท่ากับอัตราส่วนของ gradient ของ variance เพราะสองช่องหารด้วย $\sigma_p$ ตัวเดียวกัน

สองบรรทัดล่างคือ risk contribution: น้ำหนักคูณความไว ผลรวม $0.115280+0.022124\approx0.137405$ เท่ากับ $\sigma_p$ พอดี และไม่ใช่เรื่องบังเอิญ เพราะ $\sum_i x_i(Vx)_i/\sigma_p=x^{\mathsf T}Vx/\sigma_p=\sigma_p^2/\sigma_p=\sigma_p$ ความผันผวนของพอร์ตจึงแบ่งเป็นก้อนของแต่ละสินทรัพย์ได้ลงตัว หุ้นใช้เงิน 60% แต่แบกความเสี่ยง $0.115280/0.137405\approx83.90\%$

ระวังเรื่องเลข 2: gradient ของ variance คือ $2Vx$ แต่ gradient ของความผันผวนคือ $Vx/\sigma_p$ ไม่มีเลข 2 เพราะเลข 2 จาก $2Vx$ ตัดกับเลข 2 ใน $1/(2\sqrt q)$ ไปแล้ว

ขั้นที่ 6 — ทิศไหนลดความเสี่ยงเร็วที่สุด

ถึงตอนนี้เรารู้ว่าความเสี่ยงขึ้นเร็วแค่ไหนเมื่อเพิ่มของทีละตัว แต่ผู้ดูแลความเสี่ยงมักอยากได้คำถามกลับด้าน: ถ้าต้องลดความเสี่ยงให้เร็วที่สุด ควรขยับน้ำหนักไปทิศไหน trade จริงมักขยับหลายน้ำหนักพร้อมกัน เราจึงเขียนทิศเป็น vector $u$ ที่ยาว 1 (เช่น $u=(-1, 0)$ คือขายหุ้นอย่างเดียว) และให้ $t$ เป็นระยะที่เดินไปตามทิศนั้น

แทน $d=tu$ ลงในสมการเป๊ะของขั้นที่ 2 หารผลเปลี่ยนด้วย $t$ แล้วให้ $t$ เล็กลงจนเป็นศูนย์ จะได้อัตราเปลี่ยนตามทิศ $u$ เขียนว่า $D_uq$ (directional derivative) จากนั้นใช้ Cauchy–Schwarz จากหน้า inner product และมุม ซึ่งบอกว่า dot product ของสอง vector มีขนาดไม่เกินผลคูณของความยาว $|a^{\mathsf T}b|\le\lVert a\rVert\,\lVert b\rVert$ เพื่อหาว่าทิศไหนให้อัตราติดลบมากที่สุด

\[ \begin{aligned} \frac{q(x+tu)-q(x)}{t}&=\nabla q^{\mathsf T}u+t\,u^{\mathsf T}Vu,\\ D_uq&=\nabla q^{\mathsf T}u\\ &\ge-\lVert\nabla q\rVert\,\lVert u\rVert=-\lVert\nabla q\rVert,\\ \lVert\nabla q\rVert&=\sqrt{0.0528^2+0.0152^2}\approx0.054944,\\ u^\star&=-\nabla q/\lVert\nabla q\rVert\approx(-0.961,\ -0.277). \end{aligned} \]

อัตราเปลี่ยนตามทิศใด ๆ คือ dot product ของ gradient กับทิศนั้น และ dot product ติดลบได้มากที่สุดเท่ากับผลคูณของความยาว ซึ่งเกิดเมื่อสอง vector ชี้สวนกันพอดี ทิศที่ลดเร็วที่สุด $u^\star$ จึงเป็นทิศของ $-\nabla q$ หารด้วยความยาวของมันให้ยาว 1 ลูกศร gradient ชี้ขึ้นเขา เดินสวนมันคือเดินลงเขาชันที่สุด นี่คือที่มาของชื่อ gradient descent อัตราที่ได้คือ $-0.0549$ ต่อหนึ่งหน่วยระยะ

แต่อ่านตัวเลขของ $u^\star$ ดู มันติดลบทั้งสองช่อง คือสั่งขายทั้งหุ้นและพันธบัตร แล้วถือเงินสดแทน คำตอบนี้ถูกทางคณิตศาสตร์สำหรับ variance ที่เราเขียนไว้ แต่ผิดโจทย์ของกองทุนที่ต้องลงเงินครบ ทิศที่ไม่ทำให้เงินรวมเปลี่ยนคือขายตัวหนึ่งไปซื้ออีกตัวเท่ากัน เช่นขายหุ้นซื้อพันธบัตร $u=(-1, 1)/\sqrt2$ (หารด้วย $\sqrt2$ เพื่อให้ยาว 1)

\[ \begin{aligned} D_uq&=\nabla q^{\mathsf T}u=\frac{-0.0528+0.0152}{\sqrt2}\\ &=\frac{-0.0376}{1.4142}\approx-0.0266. \end{aligned} \]

ทิศนี้ยังลด variance ได้ แต่ได้ไม่ถึงครึ่งของทิศที่ชันที่สุด เพราะ $0.0266/0.0549\approx0.48$

ขั้นที่ 7 — เงื่อนไขอันดับหนึ่งแบบไม่มีข้อจำกัด: คำตอบถูกแต่ใช้ไม่ได้

ขั้นที่แล้วบอกว่า ตราบใดที่ยังมีทิศที่ลดได้ เราก็ยังไม่อยู่ที่จุดต่ำสุด ถ้าไม่มีข้อจำกัดเลย ทุกทิศใช้ได้ จุดต่ำสุดจึงต้องเป็นจุดที่ไม่มีทิศไหนลดได้ หน้า global กับ local minimum บอกไว้ว่า จุดต่ำสุดที่อยู่ข้างในพื้นผิวเรียบต้องมีความชันศูนย์ ในหลายตัวแปรหมายถึงทุกช่องของ gradient เป็นศูนย์ ลองตั้งเงื่อนไขนี้กับพอร์ตของเราโดยไม่ใส่ข้อจำกัดอะไร ($\det V$ คือ determinant ของ $V$)

\[ \begin{aligned} \nabla q&=2Vx=0,\\ \det V&=0.04(0.01)-0.006^2=0.000364\ne0,\\ x&=V^{-1}\,0=(0,\ 0). \end{aligned} \]

determinant ของ $V$ ไม่เป็นศูนย์ $V$ จึง invertible คือมี inverse (ดูหน้า rank และ invertibility) สมการ $Vx=0$ จึงมีคำตอบเดียว คือ vector ศูนย์ variance ของพอร์ตเป็นฟังก์ชัน convex คือมีรูปเป็นชามใบเดียว จุดที่ความชันเป็นศูนย์ของชามคือก้นชาม จึงเป็น global minimum แน่นอน ไม่ต้องตรวจอะไรเพิ่ม

แต่คำตอบคือ “ไม่ถืออะไรเลย” variance เป็น 0 ซึ่งถูกต้อง แต่ไม่มีประโยชน์ มันเป็นคำตอบที่ถูกของคำถามที่ผิด เพราะกองทุนไม่ได้ถามว่าจะลดความเสี่ยงอย่างไร แต่ถามว่าจะลงเงินทั้งหมดอย่างไรให้เสี่ยงน้อยที่สุด นี่คือเหตุผลที่โจทย์พอร์ตจริงต้องมีข้อจำกัดเสมอ

ขั้นที่ 8 — ลงเงินครบ: marginal risk ต้องเท่ากันทุกตัว

กองทุนต้องลงเงินครบ คือ $x_1+x_2=1$ เสมอ จึงซื้อเพิ่มด้วยเงินกู้หรือขายออกไปถือเงินสดไม่ได้ ทิศที่ยังทำได้มีแบบเดียว คือสลับ: ขายตัวหนึ่งไป $\delta$ แล้วเอาเงินไปซื้ออีกตัว $\delta$ เท่ากัน เขียนเป็น $d=(\delta, -\delta)$ ($\delta$ บวกคือขายพันธบัตรซื้อหุ้น $\delta$ ลบคือขายหุ้นซื้อพันธบัตร) น้ำหนักรวมจึงยังเป็น 1

แทน $d$ นี้ลงในสมการเป๊ะของขั้นที่ 2 ส่วนเส้นตรง $\nabla q^{\mathsf T}d$ เหลือแค่ผลต่างของ partial derivative สองตัว และส่วนความโค้ง $d^{\mathsf T}Vd$ คือ $\delta^2$ คูณ variance ของพอร์ต “หุ้น 1 ลบพันธบัตร 1” ลองที่ 60/40 กับ $\delta=-0.01$ คือขายหุ้น 1% ซื้อพันธบัตร 1% ค่าที่ใช้คือ gradient $(0.0528, 0.0152)$ จากขั้นที่ 3

\[ \begin{aligned} \Delta q&=\delta\Big(\frac{\partial q}{\partial x_1}-\frac{\partial q}{\partial x_2}\Big)\\ &\quad+\delta^2\,(V_{11}+V_{22}-2V_{12}),\\ \nabla q^{\mathsf T}d&=-0.01(0.0528-0.0152)\\ &=-0.000376,\\ d^{\mathsf T}Vd&=(-0.01)^2(0.04+0.01-0.012)\\ &=0.0001(0.038)=0.0000038,\\ \Delta q&=-0.000376+0.0000038\\ &=-0.0003722. \end{aligned} \]

การสลับนี้ลด variance ได้ 0.0003722 ความผันผวนลงจาก 13.7405% เป็น $\sqrt{0.01888-0.0003722}=\sqrt{0.0185078}\approx13.6043\%$ พอร์ต 60/40 จึงไม่ใช่จุดต่ำสุด

เหตุผลทั่วไปอยู่ที่ขนาดของสองพจน์ ถ้า partial derivative สองตัวไม่เท่ากัน ให้เลือกเครื่องหมายของ $\delta$ ให้ส่วนเส้นตรงติดลบ คือขายตัวที่ partial derivative สูงกว่า ไปซื้อตัวที่ต่ำกว่า ส่วนเส้นตรงโตตาม $|\delta|$ แต่ส่วนความโค้งโตตาม $\delta^2$ เมื่อ $\delta$ เล็กพอ ส่วนเส้นตรงจึงชนะเสมอ ที่ 60/40 ส่วนเส้นตรงคือ $0.0376|\delta|$ และส่วนความโค้งคือ $0.038\delta^2$ การสลับจึงลด variance ได้ทุกขนาดที่ $|\delta|\lt0.0376/0.038\approx0.99$

ดังนั้น ที่จุดต่ำสุดของพอร์ตที่ลงเงินครบ partial derivative ทุกตัวต้องเท่ากัน ไม่อย่างนั้นยังสลับแล้วลดได้อีก ให้หุ้นมีน้ำหนัก $a$ และพันธบัตร $1-a$ แทนลงในสูตร partial derivative จากขั้นที่ 1 แล้วตั้งให้เท่ากัน

\[ \begin{aligned} 0.08a+0.012(1-a)&=0.012a+0.02(1-a),\\ 0.068a+0.012&=0.02-0.008a,\\ 0.076a&=0.008,\\ a&=0.008/0.076=2/19\approx0.105263. \end{aligned} \]

ค่าร่วมของ partial derivative ทั้งสองที่จุดนี้ หาได้จากการแทน $a=2/19$ ในฝั่งซ้าย

\[ \begin{aligned} \frac{\partial q}{\partial x_1}&=0.068\Big(\frac{2}{19}\Big)+0.012\\ &=\frac{0.136+0.228}{19}=\frac{0.364}{19}\\ &\approx0.019158. \end{aligned} \]

ได้หุ้น 10.53% พันธบัตร 89.47% ตรงกับที่หน้า global กับ local minimum ได้ด้วยวิธีอื่น คือแทน $x_2=1-x_1$ แล้วหาจุดต่ำสุดของฟังก์ชันตัวแปรเดียว สองวิธีตอบตรงกัน

ค่าร่วม 0.019158 มีความหมายด้วย มันเท่ากับสองเท่าของ variance ต่ำสุด เพราะ $x^{\mathsf T}\nabla q=2q$ (ตรวจไว้แล้วในขั้นที่ 3) ถ้าทุกช่องของ $\nabla q$ เท่ากับค่าร่วม $\lambda$ จะได้ $x^{\mathsf T}\nabla q=\lambda(x_1+x_2)=\lambda$ เพราะน้ำหนักรวมเป็น 1 ดังนั้น $\lambda=2q^\star$ และ variance ต่ำสุดคือ $q^\star=0.019158/2\approx0.0095789$ ความผันผวน $\sqrt{0.0095789}\approx9.79\%$ หน้า Lagrange multipliers จะตั้งชื่อให้ค่าร่วมนี้ และอ่านมันเป็นราคาของการบังคับให้ลงเงินครบ

ขั้นที่ 9 — สูตรปิดของสองสินทรัพย์ และเส้นแบ่ง correlation 0.5

ขั้นที่ 8 แก้ด้วยตัวเลขของหุ้นกับพันธบัตรคู่นี้ ถ้าทำซ้ำด้วยตัวอักษร จะได้สูตรที่ใช้กับสินทรัพย์คู่ไหนก็ได้ และตอบได้อีกคำถามหนึ่ง: เมื่อไรสินทรัพย์ที่ผันผวนกว่าไม่ควรมีที่ในพอร์ตความเสี่ยงต่ำสุดเลย ตั้ง partial derivative สองตัวให้เท่ากันเหมือนเดิม (ตัดเลข 2 ที่อยู่ทั้งสองฝั่งออก) แล้วแก้หา $a$

\[ \begin{aligned} V_{11}a+V_{12}(1-a)&=V_{12}a+V_{22}(1-a),\\ a&=\frac{V_{22}-V_{12}}{V_{11}+V_{22}-2V_{12}}\\ &=\frac{0.01-0.006}{0.04+0.01-0.012}\\ &=\frac{0.004}{0.038}\approx0.105263. \end{aligned} \]

ตัวเลขตรงกับขั้นที่ 8 ต่อไปถามว่าเมื่อไร $a\gt0$ คือหุ้นยังมีที่ในพอร์ต ตัวส่วนเป็นบวกเสมอ (เหตุผลอยู่ใต้สูตร) เครื่องหมายของ $a$ จึงขึ้นกับตัวเศษ $V_{22}-V_{12}$ อย่างเดียว แทน $V_{22}=\sigma_2^2$ และ $V_{12}=\rho\sigma_1\sigma_2$ แล้วดึง $\sigma_1\sigma_2$ ออก

\[ \begin{aligned} V_{22}-V_{12}&=\sigma_2^2-\rho\sigma_1\sigma_2\\ &=\sigma_1\sigma_2\Big(\frac{\sigma_2}{\sigma_1}-\rho\Big). \end{aligned} \]

$\sigma_1\sigma_2$ เป็นบวก ตัวเศษจึงเป็นบวกเมื่อ $\rho\lt\sigma_2/\sigma_1=0.1/0.2=0.5$ เท่านั้น

ตัวส่วน $V_{11}+V_{22}-2V_{12}$ คือ variance ของพอร์ต “หุ้น 1 ลบพันธบัตร 1” จึงไม่ติดลบ และเป็นบวกเมื่อสองตัวไม่ใช่ของเดียวกัน ผลที่ได้คือ หุ้นยังมีที่ในพอร์ตความเสี่ยงต่ำสุดก็ต่อเมื่อ correlation ต่ำกว่าอัตราส่วนความผันผวน $\sigma_2/\sigma_1=0.5$ คู่ของเรามี $\rho=0.30$ ต่ำกว่า 0.5 หุ้นจึงได้ที่ 10.53%

ลองสองกรณี ที่ $\rho=0.5$ พอดี $V_{12}=0.5(0.2)(0.1)=0.01=V_{22}$ ตัวเศษเป็นศูนย์ คำตอบคือพันธบัตรล้วน และ gradient ที่ $(0, 1)$ คือ $2V(0, 1)^{\mathsf T}=(2V_{12}, 2V_{22})=(0.02, 0.02)$ เท่ากันตามกฎ ที่ $\rho=0.8$ จะได้ $V_{12}=0.8(0.2)(0.1)=0.016$ และ $a=(0.01-0.016)/(0.04+0.01-0.032)=-0.006/0.018=-1/3$ คำตอบคือ short หุ้น 1/3 ของ NAV (short คือยืมหุ้นมาขาย น้ำหนักจึงติดลบ) เพราะเมื่อพันธบัตรขึ้นลงตามหุ้นมาก การถือหุ้นติดลบช่วยหักล้างการแกว่งของพันธบัตร

กับดัก: หน่วยผิด เลข 2 หาย ที่มาของเงิน และการดูแค่ความผันผวนของตัวเอง

กับดักที่ 1: เอา gradient ของ variance ไปคูณเป็นเงินตรง ๆ 0.0528 คือ variance ที่เพิ่มต่อหนึ่งหน่วยน้ำหนัก ไม่ใช่ความผันผวน และไม่ใช่เงิน สมมติพอร์ตมี NAV \$100 ล้าน ผู้บริหารถามว่า “ซื้อหุ้นเพิ่ม 1% แล้วความเสี่ยงเพิ่มกี่ดอลลาร์” คำว่าความเสี่ยงเป็นดอลลาร์ในที่นี้คือความผันผวนของ P&L (กำไรขาดทุน) รายปี ซึ่งเท่ากับ $\sigma_p\times\text{NAV}$

  • ผิด: $0.0528\times\$100$ ล้าน $=\$5.28$ ล้าน ตัวเลขนี้ไม่มีความหมาย เพราะเอาหน่วยผลตอบแทนยกกำลังสองไปคูณเงิน
  • ถูก: ใช้ความไวของความผันผวนจากขั้นที่ 5 ความผันผวนขึ้น $0.01\times0.192133=0.00192133$ คิดเป็นเงิน $0.00192133\times\$100$ ล้าน $\approx\$192{,}133$ ต่อปี

ถ้าคำนวณตรงจากความผันผวนก่อนและหลัง trade จะได้ $(0.13932695-0.13740451)\times\$100$ ล้าน $=0.00192244\times\$100$ ล้าน $\approx\$192{,}244$ ใกล้กับตัวเลขที่ถูกมาก

กับดักที่ 2: ลืมเลข 2 หรือใส่เลข 2 เกิน ถ้ารายงาน $Vx=(0.0264, 0.0076)$ เป็น gradient ของ variance ทุกช่องจะเล็กไปครึ่งหนึ่งจากค่าจริง $(0.0528, 0.0152)$ แต่อัตราส่วนระหว่างสินทรัพย์ยังถูก การจัดอันดับจึงดูสมเหตุสมผล และความผิดรอดสายตาได้นาน ในทางกลับกัน ถ้าเอา $2Vx/\sigma_p$ ไปเป็นความไวของความผันผวน ช่องหุ้นจะได้ $0.0528/0.137405\approx0.3843$ ซึ่งใหญ่เป็นสองเท่าของค่าที่ถูก 0.192133

กับดักที่ 3: ไม่ถามว่าเงินมาจากไหน คำขอ “เพิ่มหุ้น 1%” ต้องบอกว่าเงินที่ใช้ซื้อมาจากไหน เพราะเป็นคนละ $d$ กัน

  • กู้เงินมาซื้อ: $d=(0.01, 0)$ ความผันผวนขึ้น 0.192 จุดเปอร์เซ็นต์ (ขั้นที่ 5)
  • ขายพันธบัตร 1% มาซื้อ: $d=(0.01, -0.01)$ ขาขายช่วยหักลบบางส่วน ความผันผวนขึ้นแค่ 0.1375 จุด ตามการคำนวณข้างล่าง
\[ \begin{aligned} \Delta q&=0.01(0.0528-0.0152)+0.01^2(0.038)\\ &=0.000376+0.0000038=0.0003798,\\ \sigma_p&=\sqrt{0.01888+0.0003798}\\ &=\sqrt{0.0192598}\approx13.8780\%,\\ \Delta\sigma_p&=13.8780-13.7405=0.1375. \end{aligned} \]

กับดักที่ 4: ตัดสินสินทรัพย์จากความผันผวนของตัวเอง สมมติมีสินทรัพย์ตัวที่สามที่กองทุนยังไม่ได้ถือ ($x_3=0$) มีความผันผวน $\sigma_3=30\%$ ซึ่งสูงกว่าหุ้น มี correlation กับหุ้น $\rho_{13}=-0.6$ คือมักขึ้นเมื่อหุ้นลง และไม่สัมพันธ์กับพันธบัตร ($\rho_{23}=0$) ถ้าดูแค่ 30% จะคิดว่าเพิ่มมันแล้วพอร์ตเสี่ยงขึ้น แต่ gradient บอกตรงข้าม เพราะสิ่งที่นับคือ covariance ของมันกับพอร์ต

\[ \begin{aligned} (Vx)_3&=x_1\rho_{13}\sigma_1\sigma_3+x_2(0)\\ &=0.6(-0.6)(0.2)(0.3)=-0.0216,\\ \frac{\partial q}{\partial x_3}&=2(-0.0216)=-0.0432,\\ \Delta q&=-0.0432(0.01)+0.3^2(0.01)^2\\ &=-0.000432+0.000009=-0.000423,\\ \sigma_p&=\sqrt{0.01888-0.000423}\\ &=\sqrt{0.018457}\approx13.5857\%. \end{aligned} \]

กู้เงินมาซื้อตัวที่สามเพิ่ม 1% ความผันผวนของพอร์ตกลับลดจาก 13.7405% เป็น 13.5857% สินทรัพย์ที่ผันผวนที่สุดกลับลดความเสี่ยงได้ เพราะ marginal risk ของมันติดลบ

ใช้ทำอะไรบนโต๊ะจริง

ฝ่ายความเสี่ยงมักทำตารางหนึ่งไว้ทุกเช้า: ถ้าเพิ่มสินทรัพย์แต่ละตัว 1% ของ NAV ความผันผวนของพอร์ตวันนี้จะขึ้นกี่จุด ตารางนี้ทำหน้าที่เป็นราคาความเสี่ยงภายในบริษัท ใช้ตอบคำขอเทรดได้ทันที โดยไม่ต้องรัน optimizer (โปรแกรมหาพอร์ตที่ดีที่สุด) ใหม่ทั้งก้อน แต่ตัวเลขในตารางขึ้นกับพอร์ต $x$ ที่ถืออยู่ จึงต้องคำนวณใหม่ทุกครั้งที่พอร์ตเปลี่ยนมาก รายงานแบ่งความเสี่ยงที่ใช้กันจริง (ดูหน้า risk decomposition และ MCR) ก็คือ risk contribution $x_i\,\partial\sigma_p/\partial x_i$ ที่หน้านี้คำนวณ

การตรวจว่าพอร์ตที่ลงเงินครบมีความเสี่ยงต่ำสุดแล้วหรือยังก็ง่าย ให้ดูว่า partial derivative ของ variance (marginal variance) ของทุกตัวที่ถือเท่ากันไหม ที่ 60/40 ได้ 0.0528 กับ 0.0152 ไม่เท่ากัน จึงยังลดได้ ที่หุ้น 10.53% พันธบัตร 89.47% ได้ 0.019158 เท่ากันทั้งคู่

ข้อควรระวังคือ ในวันวิกฤต correlation ระหว่างสินทรัพย์มักพุ่งขึ้น ทุกอย่างลงพร้อมกัน ตาราง marginal risk ที่คำนวณจาก covariance ของวันปกติจึงบอกความเสี่ยงต่ำกว่าความจริง ในวันที่ต้องใช้มันมากที่สุด

1. กองทุนอีกแห่งถือหุ้นกับพันธบัตรคู่เดียวกัน ($V$ เหมือนเดิม) แต่ถือแบบ 50/50 คือ $x=(0.5, 0.5)$ ที่พอร์ตนี้ gradient ของ variance เป็นเท่าไร ความไวของความผันผวนเป็นเท่าไร และหุ้นดันความเสี่ยงมากกว่าพันธบัตรกี่เท่า?

เฉลย

คำนวณ $Vx$ ก่อน แล้วได้ gradient variance และความผันผวน

\[ \begin{aligned} (Vx)_1&=0.04(0.5)+0.006(0.5)=0.023,\\ (Vx)_2&=0.006(0.5)+0.01(0.5)=0.008,\\ \nabla q&=2Vx=(0.046,\ 0.016),\\ q&=0.5(0.023)+0.5(0.008)=0.0155,\\ \sigma_p&=\sqrt{0.0155}\approx0.124499. \end{aligned} \]

ความไวของความผันผวนคือ $(Vx)_i/\sigma_p$

\[ \begin{aligned} \frac{\partial\sigma_p}{\partial x_1}&=\frac{0.023}{0.124499}\approx0.18474,\\ \frac{\partial\sigma_p}{\partial x_2}&=\frac{0.008}{0.124499}\approx0.06426,\\ \frac{0.18474}{0.06426}&=\frac{0.023}{0.008}=2.875. \end{aligned} \]

หุ้นดันความเสี่ยงมากกว่า 2.875 เท่า น้อยกว่า 3.474 เท่าของพอร์ต 60/40 เพราะพอร์ตนี้มีหุ้นน้อยลง หุ้นก้อนใหม่จึงซ้อนกับหุ้นก้อนเดิมน้อยลง ส่วนแบ่งความเสี่ยงของหุ้นคือ risk contribution หารด้วย $\sigma_p$ ซึ่งเท่ากับ $x_1(Vx)_1/q=0.5(0.023)/0.0155\approx74.19\%$ ของพอร์ต

2. ที่พอร์ต 60/40 เทรดเดอร์ขอขายพันธบัตร 5% ของ NAV แล้วเอาเงินไปซื้อหุ้น 5% variance ของพอร์ตจะเปลี่ยนเท่าไร และถ้าทำนายด้วยเส้นตรงอย่างเดียวจะพลาดกี่เปอร์เซ็นต์ของผลจริง?

เฉลย

trade นี้คือ $d=(0.05, -0.05)$ ใช้สมการของการสลับจากขั้นที่ 8 กับ $\delta=0.05$

\[ \begin{aligned} \nabla q^{\mathsf T}d&=0.05(0.0528-0.0152)=0.00188,\\ d^{\mathsf T}Vd&=0.05^2(0.04+0.01-0.012)\\ &=0.0025(0.038)=0.000095,\\ \Delta q&=0.00188+0.000095=0.001975,\\ \sigma_p&=\sqrt{0.01888+0.001975}\\ &=\sqrt{0.020855}\approx14.4413\%. \end{aligned} \]

ความผันผวนขึ้นจาก 13.7405% เป็น 14.4413% เส้นตรงทิ้งส่วนความโค้งไป จึงพลาด $0.000095/0.001975\approx4.81\%$ ของผลจริง

3. หุ้นกับพันธบัตรยังมีความผันผวน 20% กับ 10% เหมือนเดิม แต่ correlation เปลี่ยนได้ correlation ต้องเป็นเท่าไร พอร์ตความเสี่ยงต่ำสุดที่ลงเงินครบจึงไม่ถือหุ้นเลย และจะใช้กฎ “marginal risk เท่ากัน” ตรวจคำตอบนี้อย่างไร?

เฉลย

จากสูตรของขั้นที่ 9 หุ้นได้น้ำหนักศูนย์เมื่อตัวเศษเป็นศูนย์ โดย $V_{12}=\rho(0.2)(0.1)=0.02\rho$

\[ \begin{aligned} V_{22}-V_{12}&=0.01-0.02\rho=0,\\ \rho&=0.01/0.02=0.5. \end{aligned} \]

ตรวจที่พอร์ตพันธบัตรล้วน $x=(0, 1)$ ซึ่ง $V_{12}=0.02(0.5)=0.01$

\[ \begin{aligned} \frac{\partial q}{\partial x_1}&=2(Vx)_1=2V_{12}=0.02,\\ \frac{\partial q}{\partial x_2}&=2(Vx)_2=2V_{22}=0.02. \end{aligned} \]

สองตัวเท่ากัน ส่วนเส้นตรงของการสลับเล็ก ๆ จึงเป็นศูนย์ ไม่ว่าสลับทางไหน และส่วนความโค้งเป็นบวก การสลับจึงไม่ลด variance พอร์ตพันธบัตรล้วนจึงเป็นคำตอบ มี variance $V_{22}=0.01$ คือความผันผวน 10%

เปิดดูโค้ด 
const times = (V, x) => V.map(row => row.reduce((s, v, j) => s + v * x[j], 0));
const dot = (a, b) => a.reduce((s, v, i) => s + v * b[i], 0);
// Variance q = x'Vx and its gradient 2Vx (annual variance per unit of weight).
function risk(V, x) {
  const Vx = times(V, x), variance = dot(x, Vx);
  if (variance < 0) throw new RangeError('Negative variance: covariance is not PSD');
  return {Vx, gradient: Vx.map(v => 2 * v), variance, sd: Math.sqrt(variance)};
}
// d sigma / d x_i = (Vx)_i / sigma, defined only when the portfolio has risk.
function volSensitivity(V, x) {
  const r = risk(V, x);
  if (!(r.sd > 0)) throw new RangeError('Zero-risk portfolio');
  const slope = r.Vx.map(v => v / r.sd);
  return {slope, shares: slope.map((s, i) => s * x[i] / r.sd)};
}
// Exact change for a trade d: q(x+d) - q(x) = gradient'd + d'Vd.
function trade(V, x, d) {
  const r = risk(V, x), after = risk(V, x.map((v, i) => v + d[i]));
  return {linear: dot(r.gradient, d), curvature: dot(d, times(V, d)),
    exact: after.variance - r.variance, sdChange: after.sd - r.sd};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • variance ของพอร์ต $q=x^{\mathsf T}Vx$ มี gradient $\nabla q=2Vx$ และผลของ trade $d$ คือ $\nabla q^{\mathsf T}d+d^{\mathsf T}Vd$ เป๊ะ ส่วนหลังคือสิ่งที่การทำนายด้วยเส้นตรงทิ้งไป และโตตามกำลังสองของขนาด trade
  • marginal risk ขึ้นกับพอร์ตที่ถืออยู่ ไม่ใช่ความผันผวนของสินทรัพย์ตัวเดียว ที่ 60/40 เพิ่มหุ้น 1% ความผันผวนขึ้น 0.192 จุด เพิ่มพันธบัตร 1% ขึ้น 0.055 จุด ต่างกัน 3.47 เท่า ไม่ใช่ 2 เท่า
  • ความไวของความผันผวนคือ $Vx/\sigma_p$ (ไม่มีเลข 2) และน้ำหนักคูณความไว รวมกันได้ $\sigma_p$ พอดี ที่ 60/40 หุ้นใช้เงิน 60% แต่แบกความเสี่ยง 83.90%
  • gradient ตั้งฉากกับเส้นระดับ ทิศที่ลดเร็วที่สุดคือ $-\nabla q$ แต่ทิศนี้ไม่สนใจว่าต้องลงเงินครบ ถ้าไม่มีข้อจำกัด คำตอบคือไม่ถืออะไรเลย
  • เมื่อต้องลงเงินครบ จุดต่ำสุดต้องมี marginal variance เท่ากันทุกตัว สำหรับคู่นี้ได้หุ้น $2/19\approx10.53\%$ ที่ค่าร่วม 0.019158

หน้าถัดไป Hessian และเงื่อนไขอันดับสอง ถามต่อจากนี้: เมื่อเจอจุดที่ความชันเป็นศูนย์แล้ว จะรู้ได้อย่างไรว่าเป็นก้นหลุม ไม่ใช่ยอดเขาหรือจุดอานม้า (จุดที่ขึ้นในทิศหนึ่งแต่ลงในอีกทิศหนึ่ง) คำตอบอยู่ในความโค้งของฟังก์ชันหลายตัวแปร
