3.4 Confidence Intervals

confidence interval คือ estimate บวกลบ (ตัวคูณจากการแจกแจง × SE) และคำว่า 95% เป็นสมบัติของวิธีสร้างช่วง ไม่ใช่ของช่วงที่ได้มาแล้วหนึ่งช่วง

กองทุนสมมติมี active return เฉลี่ย 3% ต่อปีจากประวัติสี่ปี SD รายปี 6% ฝ่ายขายอยากเขียนในเอกสารว่า “กองทุนทำได้ 3% เหนือดัชนี” ฝ่ายความเสี่ยงขอให้ใส่ช่วงความไม่แน่นอนด้วย ช่วงนั้นควรกว้างแค่ไหน และมันครอบศูนย์หรือไม่

ลองตอบก่อนเปิดเฉลย

ถ้า 6% เป็น SD ที่รู้จากแหล่งอื่น ช่วง 95% คือ $3\pm1.96\times3=[-2.88\%,\ 8.88\%]$ ถ้า 6% ประมาณจากสี่ปีเดียวกัน ต้องเผื่อความไม่แน่นอนของ SD ด้วยตัวคูณ Student $t$ 3.182 ช่วงจะกว้างขึ้นเป็น $[-6.55\%,\ 12.55\%]$ ทั้งสองแบบครอบศูนย์ ข้อมูลสี่ปียังแยกกองทุนนี้ออกจากกองทุนที่ไม่มีฝีมือไม่ได้

ภาพรวมก่อนลงสูตร

ตัวเลข 3% ตัวเดียวซ่อนข้อมูลสำคัญที่สุดไว้ คือมันคลาดได้แค่ไหน confidence interval (CI) แก้ปัญหานี้ด้วยการรายงานช่วงของค่าที่ข้อมูลยังแยกออกจากกันไม่ได้ สูตรทุกแบบมีหน้าตาเดียวกัน: estimate บวกลบ ตัวคูณ × SE โดย SE มาจาก estimator และ standard error ส่วนตัวคูณมาจากพื้นที่ใต้การแจกแจง

ส่วนที่คนเข้าใจผิดมากที่สุดคือคำว่า 95% มันหมายถึงว่า วิธีสร้างช่วงนี้ ถ้าใช้ซ้ำกับข้อมูลชุดใหม่ ๆ จะได้ช่วงที่ครอบค่าจริง 95% ของครั้ง ไม่ได้แปลว่าช่วงที่ได้มาแล้วหนึ่งช่วงมีโอกาส 95% ที่ครอบค่าจริง รูปด้านล่างแสดงความหมายนี้ตรง ๆ

หน้านี้จะหาตัวคูณ 1.96 จากพื้นที่ จัดอสมการให้เป็นช่วง ดูว่าต้องมีข้อมูลกี่ปีช่วงจึงพ้นศูนย์ เปลี่ยนเป็น Student $t$ เมื่อ SD มาจากข้อมูล อธิบายความหมายของ 95% แล้วขยายไปสองเรื่องที่ใช้บ่อยบนโต๊ะ คือช่วงของหลายค่าพร้อมกัน และช่วงทำนายผลปีหน้า

ศัพท์ที่ใช้ในหน้านี้
Confidence interval (CI)
ช่วง $[L,U]$ ที่คำนวณจากข้อมูล โดยวิธีสร้างถูกออกแบบให้ครอบค่าจริงในสัดส่วนที่กำหนดเมื่อใช้ซ้ำ ใช้รายงานว่าข้อมูลยังแยกค่าใดออกจากกันไม่ได้
Coverage
สัดส่วนจริงที่ช่วงครอบค่าจริงเมื่อเก็บข้อมูลซ้ำ ถ้าข้อสมมติของสูตรผิด coverage จริงอาจต่ำกว่าตัวเลขที่ติดป้าย
Critical value / quantile
ขอบที่มีพื้นที่สะสมตามกำหนด เช่น 1.96 คือขอบที่ normal มาตรฐานมีพื้นที่ทางซ้าย 97.5% ใช้เป็นตัวคูณของ SE
Pivot
นิพจน์ที่รวมค่าจริงกับข้อมูล แต่มีการแจกแจงที่รู้และไม่ขึ้นกับค่าจริง เช่น $(\bar X-\mu)/(\sigma/\sqrt n)$ ใช้จัดอสมการให้กลายเป็นช่วง
Student $t$
การแจกแจงของค่าเฉลี่ยที่ standardize ด้วย sample SD แทน SD จริง หางหนากว่า normal เพื่อเผื่อความไม่แน่นอนของตัวหาร
Prediction interval
ช่วงของค่าใหม่หนึ่งค่า เช่นผลตอบแทนปีหน้า กว้างกว่า CI ของค่าเฉลี่ยเพราะรวมการแกว่งของค่าใหม่เข้าไปด้วย
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$\mu,\ \hat\mu=\bar X$ค่าเฉลี่ยจริงของ active return และค่าเฉลี่ยจากข้อมูลจุดเปอร์เซ็นต์ต่อปี
$\sigma,\ s$SD จริงและ sample SD ของ active return รายปีจุดเปอร์เซ็นต์
$n$จำนวนปีที่อิสระกันปี

$[L,U]$ขอบล่างและขอบบนของช่วงจุดเปอร์เซ็นต์ต่อปี

ขั้นที่ 1 — ตัวคูณ 1.96 มาจากพื้นที่ ไม่ใช่เลขที่ต้องท่อง

ก่อนสร้างช่วง ต้องรู้ว่าตัวแปร normal มาตรฐาน $Z$ อยู่ในช่วงไหนด้วยโอกาส 95% ช่วงที่แคบที่สุดคือช่วงสมมาตรรอบศูนย์ เหลือ 5% แบ่งไปหางละ 2.5% ขอบขวาจึงเป็นจุดที่พื้นที่ทางซ้ายเท่ากับ 97.5%

\[\begin{aligned} \Phi(z_{0.975})&=0.975,\qquad z_{0.975}\approx1.96,\\ P(-1.96\le Z\le1.96)&\approx0.95,\\ z_{0.95}\approx1.645,&\qquad z_{0.995}\approx2.576. \end{aligned}\]

ตัวคูณคือขอบที่กันพื้นที่ใต้ระฆังไว้ตามที่ต้องการ ($\Phi$ คือ CDF ของ normal มาตรฐาน) ช่วงสองด้าน 90% ใช้ 1.645 เพราะเหลือหางละ 5% ช่วง 99% ใช้ 2.576 ถ้าปัดเป็น 2 พื้นที่จริงคือ $2\Phi(2)-1\approx95.45\%$ ความมั่นใจที่สูงขึ้นแลกด้วยความกว้าง ช่วง 99% กว้างกว่าช่วง 95% ราว $2.576/1.96-1\approx31.4\%$ ทั้งที่ใช้ข้อมูลเดียวกัน

ขั้นที่ 2 — จัดอสมการให้ค่าจริงอยู่ตรงกลาง

ถ้าข้อมูลรายปีเป็น normal อิสระ และรู้ $\sigma$ จริง นิพจน์ $(\bar X-\mu)/(\sigma/\sqrt n)$ เป็น normal มาตรฐานพอดี (ถ้าข้อมูลไม่ normal ใช้ central limit theorem เป็นการประมาณ) นิพจน์นี้มี $\mu$ อยู่ข้างในแต่การแจกแจงของมันไม่ขึ้นกับ $\mu$ เราจึงพลิกอสมการให้ $\mu$ อยู่ตรงกลางได้

\[\begin{aligned} -z&\le\frac{\bar X-\mu}{\sigma/\sqrt n}\le z,\\ -z\frac{\sigma}{\sqrt n}&\le\bar X-\mu\le z\frac{\sigma}{\sqrt n},\\ \bar X-z\frac{\sigma}{\sqrt n}&\le\mu\le\bar X+z\frac{\sigma}{\sqrt n}. \end{aligned}\]

สามบรรทัดนี้เป็นเหตุการณ์เดียวกัน จึงมีโอกาส 95% เท่ากันเมื่อ $z=1.96$ บรรทัดสองคูณทุกข้างด้วย SE ซึ่งเป็นบวก ทิศอสมการจึงไม่เปลี่ยน บรรทัดสามลบ $\bar X$ ทุกข้างแล้วคูณด้วย −1 ซึ่งกลับทิศและสลับขอบซ้ายขวา ผลคือ estimate ± ตัวคูณ × SE จุดสำคัญคือในบรรทัดสุดท้าย ตัวที่สุ่มคือขอบ $\bar X\pm\ldots$ ส่วน $\mu$ คงที่ โอกาส 95% จึงเป็นของขอบที่จะได้ ไม่ใช่ของ $\mu$

ขั้นที่ 3 — รู้ SD จริง: สี่ปีให้ช่วงกว้างแค่ไหน

โจทย์ให้อะไรมาบ้าง: $\bar X=3$, $\sigma=6$ (รู้จากแหล่งอื่น), $n=4$ ปีอิสระ ข้อมูล normal ใช้ช่วง 95%

\[\begin{aligned} \mathrm{SE}&=\frac{6}{\sqrt4}=3,\\ 3\pm1.96(3)&=3\pm5.88,\\ {[L,U]}&=[-2.88,\ 8.88]. \end{aligned}\]

คำตอบ: ช่วงของค่าเฉลี่ย active return คือ −2.88% ถึง 8.88% ช่วงครอบศูนย์ แปลว่าข้อมูลยังไม่ปฏิเสธค่าเฉลี่ยศูนย์ ไม่ได้พิสูจน์ว่าฝีมือเป็นศูนย์ ค่า 5% หรือ 8% ก็ยังไม่ถูกปฏิเสธเช่นกัน ถ้าตรึงค่าเฉลี่ยที่เห็นไว้ที่ 3% แล้วเพิ่มปี: 1 ปีได้ [−8.76%, 14.76%] 5 ปีได้ [−2.26%, 8.26%] 9 ปีได้ [−0.92%, 6.92%] และ 16 ปีได้ [0.06%, 5.94%] ซึ่งเพิ่งพ้นศูนย์

ตรวจเองใน 10 วินาที: ครึ่งความกว้างที่ 16 ปีคือ $1.96\times6/4=2.94$ ครึ่งหนึ่งของ 5.88 ที่สี่ปีพอดี ข้อมูลสี่เท่าทำให้ช่วงแคบลงครึ่งเดียว

ขั้นที่ 4 — ต้องมีกี่ปีช่วงจึงพ้นศูนย์

คำถามบนโต๊ะมักถามกลับว่า “ต้องรออีกกี่ปี” ตั้งให้ขอบล่างเป็นบวก แล้วแก้หา $n$ โดยตรึงค่าเฉลี่ยกับ SD ไว้ตามที่เห็น

\[\begin{aligned} 3-1.96\frac{6}{\sqrt n}&\gt0,\\ \sqrt n&\gt\frac{1.96\times6}{3}=3.92,\\ n&\gt15.3664,\\ \frac{\bar X}{\sigma}=0.25:\quad n&\gt\Big(\frac{1.96}{0.25}\Big)^2=61.4656. \end{aligned}\]

จำนวนปีที่ต้องการคือ $(1.96\,\sigma/\bar X)^2$ ขึ้นกับกำลังสองของอัตราส่วน SD ต่อค่าเฉลี่ย กองทุนในโจทย์ต้อง 16 ปี กองทุนที่อัตราส่วนค่าเฉลี่ยต่อ SD เหลือ 0.25 ต้อง 62 ปี ตัวเลขนี้คือการคำนวณความกว้าง ไม่ใช่สัญญาว่าเมื่อครบ 16 ปีช่วงจะพ้นศูนย์ เพราะค่าเฉลี่ยของปีต่อ ๆ ไปอาจออกมาต่ำกว่า 3% ก็ได้ การวางแผนให้พ้นศูนย์ด้วยโอกาสสูงต้องใช้ power ใน การทดสอบสมมติฐาน และถ้าตรวจช่วงทุกปีแล้วหยุดทันทีที่พ้นศูนย์ coverage จริงจะต่ำกว่า 95% เพราะเราให้โอกาสตัวเองหลายครั้ง

ขั้นที่ 5 — SD มาจากข้อมูลเดียวกัน: เปลี่ยนเป็น Student t

ในชีวิตจริงเราแทบไม่เคยรู้ $\sigma$ ต้องใช้ sample SD $s$ จากสี่ปีเดียวกัน ตัวหารจึงสุ่มด้วย บางชุดข้อมูลได้ $s$ เล็กเกินจริงโดยบังเอิญ ทำให้อัตราส่วนพุ่งสูง การแจกแจงของอัตราส่วนจึงหางหนากว่า normal

\[\begin{aligned} T&=\frac{\bar X-\mu}{s/\sqrt n}\ \sim\ t_{n-1},\\ {[L,U]}&=\bar X\pm t_{0.975,\,n-1}\frac{s}{\sqrt n},\\ n=4:\quad t_{0.975,3}&\approx3.182,\\ 3\pm3.182\times3&=3\pm9.547. \end{aligned}\]

Student $t$ คือ normal ที่เผื่อความไม่แน่นอนของ SD ไว้ในหาง df (degrees of freedom) คือ $n-1$ เหตุผลเดียวกับตัวหาร $n-1$ ของ sample variance: ประมาณค่าเฉลี่ยไปแล้วหนึ่งทิศทาง ที่สี่ปีช่วงกลายเป็น [−6.55%, 12.55%] กว้างกว่าแบบรู้ SD ราว 62% ตัวคูณที่ df 3, 15 และ 29 คือราว 3.182, 2.131 และ 2.045 เข้าหา 1.96 เมื่อข้อมูลมากขึ้น ถ้าตรึงค่าเฉลี่ย 3% และ $s=6\%$ ไว้ ช่วงที่ 16 ปีคือ [−0.20%, 6.20%] ที่ 17 ปีคือ [−0.08%, 6.08%] และเพิ่งพ้นศูนย์ที่ 18 ปีด้วย [0.02%, 5.98%] Student $t$ ถูกต้องพอดีเมื่อข้อมูลเป็น normal ถ้าข้อมูลน้อยและเบ้มาก ก็ยังไม่ใช่เกราะป้องกัน ชื่อ Student มาจากนามแฝงของ William Gosset นักเคมีของโรงเบียร์ Guinness ที่ต้องตัดสินใจจากตัวอย่างข้าวบาร์เลย์เพียงไม่กี่แปลง

ขั้นที่ 6 — 95% เป็นสมบัติของวิธี: นับช่วงที่ครอบ

ก่อนเห็นข้อมูล ขอบ $L$ กับ $U$ ยังสุ่ม จึงพูดได้ว่าวิธีนี้จะครอบ $\mu$ ด้วยโอกาส 95% หลังเห็นข้อมูล ทั้งขอบและ $\mu$ เป็นตัวเลขคงที่ ช่วงนั้นครอบหรือไม่ครอบ เราไม่รู้ว่าอย่างไหน รูปช่วง 25 เส้นด้านบนคือภาพของความหมายนี้ ถ้าสร้างช่วงจากข้อมูลอิสระ 100 ชุดด้วยวิธีที่มี coverage 95% จริง จำนวนช่วงที่ครอบ $C$ เป็น binomial

\[\begin{aligned} C&\sim\operatorname{Binomial}(100,\ 0.95),\\ \mathbb E[C]&=95,\\ \operatorname{SD}(C)&=\sqrt{100(0.95)(0.05)}\approx2.18. \end{aligned}\]

จำนวนช่วงที่ครอบแกว่งรอบ 95 ด้วย SD ราว 2 ช่วง ได้ 91 ถึง 99 ช่วงก็ปกติ ในรูปด้านบน 23 จาก 25 (92%) ก็อยู่ในเกณฑ์ปกติ ถ้าต้องการพูดว่า “มีโอกาส 95% ที่ค่าจริงอยู่ในช่วงนี้” ต้องใช้กรอบ Bayes: กำหนดความเชื่อก่อนเห็นข้อมูล (prior) แล้วปรับด้วยข้อมูลผ่าน Bayes’ theorem ได้ credible interval ซึ่งตอบคำถามคนละข้อ เมื่อ prior กว้างมากและข้อมูล normal สองช่วงนี้มีตัวเลขใกล้กัน แต่ความหมายต่างกัน แนวคิด coverage ของ CI มาจาก Jerzy Neyman ในทศวรรษ 1930

ขั้นที่ 7 — ประมาณสองค่าพร้อมกัน: กล่องสองช่วงไม่ใช่ 95%

optimizer ต้องการค่าเฉลี่ยของหลายสินทรัพย์พร้อมกัน สมมติสองสินทรัพย์ไม่สัมพันธ์กัน ความผันผวน 20% ต่อปีทั้งคู่ เก็บข้อมูลรายเดือน 60 เดือน (ห้าปี) ได้ค่าเฉลี่ย 8% และ 4% SE ของแต่ละตัวคือ $20/\sqrt5\approx8.94$ จุด ถ้าวาดช่วง 95% ของแต่ละตัวแยกกันจะได้กล่อง คำถามคือกล่องนี้ครอบคู่ค่าจริงกี่เปอร์เซ็นต์

\[\begin{aligned} P(|Z_A|\le1.96,\ |Z_B|\le1.96)&=0.95^2=90.25\%,\\ Z_A^2+Z_B^2&\sim\chi^2_2,\\ P(\chi^2_2\gt r^2)&=e^{-r^2/2}=0.05,\\ r&=\sqrt{-2\ln0.05}\approx2.448. \end{aligned}\]

ให้ $Z_A$ และ $Z_B$ คือความคลาดของค่าประมาณแต่ละตัววัดเป็นจำนวน SE ความมั่นใจ 95% ต่อตัวไม่ได้รวมเป็น 95% ของทั้งคู่ เพราะต้องรอดทั้งสองช่วง ซึ่งเกิดด้วยโอกาส $0.95^2$ เมื่อสองค่าประมาณอิสระกัน บริเวณ 95% ที่ถูกต้องสำหรับคู่ค่าเฉลี่ยคือวงกลม (หรือวงรีถ้าสัมพันธ์กันหรือ SE ต่างกัน) รัศมีมาจาก $Z_A^2+Z_B^2$ ซึ่งเป็น chi-square สององศาเสรี การแจกแจงนี้มีหางที่เขียนเป็น exponential ได้พอดี รัศมีจึงคือ 2.448 SE หรือราว 21.9 จุด เทียบครึ่งความกว้างของกล่อง 17.5 จุด ข้อมูลห้าปีจึงแทบไม่บอกอะไรเลยว่าสินทรัพย์ไหนดีกว่า เมื่อมีหลายสิบสินทรัพย์ ปัญหานี้คือรากของ ปัญหาการทดสอบหลายครั้ง

ขั้นที่ 8 — ช่วงของค่าเฉลี่ยกับช่วงของปีหน้าเป็นคนละช่วง

ลูกค้ามักถามว่า “ปีหน้าจะได้เท่าไร” ซึ่งไม่ใช่คำถามเรื่องค่าเฉลี่ย ค่าปีหน้า $X_{\rm new}$ แกว่งรอบ $\mu$ ด้วย SD $\sigma$ และเรายังไม่รู้ $\mu$ ด้วย ความไม่แน่นอนสองชั้นนี้บวกกัน

\[\begin{aligned} \operatorname{Var}(X_{\rm new}-\bar X)&=\sigma^2+\frac{\sigma^2}{n},\\ 3\pm1.96\times6\sqrt{1+\tfrac14}&=3\pm13.15,\\ {[L,U]}&=[-10.15,\ 16.15]. \end{aligned}\]

ช่วงทำนายปีหน้ากว้างกว่าช่วงของค่าเฉลี่ยมาก และไม่หดเหลือศูนย์แม้มีข้อมูลไม่จำกัด บรรทัดแรกบวก variance ตรง ๆ ได้เพราะปีหน้าอิสระจากสี่ปีที่ผ่านมา เมื่อ $n$ โต พจน์ $\sigma^2/n$ หายไป แต่ $\sigma^2$ ยังอยู่ ช่วงทำนายจึงเข้าหา $\mu\pm1.96\sigma$ ไม่ใช่จุดเดียว ช่วงของค่าเฉลี่ย ±5.88 กับช่วงของปีหน้า ±13.15 ตอบคนละคำถาม การเอาช่วงแรกไปตอบคำถามที่สองทำให้ลูกค้าคาดหวังผลที่นิ่งกว่าความจริงมาก

ความผิดที่ทำให้ตัวเลขดูน่าเชื่อแต่ผิด

อ่าน “ครอบศูนย์” เป็น “ไม่มีผล”: ช่วง [−2.88%, 8.88%] ไม่ปฏิเสธศูนย์ แต่ก็ไม่ปฏิเสธ 8% เช่นกัน การไม่พบหลักฐานไม่ใช่หลักฐานว่าไม่มีผล

ใช้ 1.96 กับ SD ที่ประมาณจากสี่จุด: ช่วงที่ติดป้าย 95% จะครอบจริงราว 85.5% เท่านั้น ต้องใช้ 3.182

เปิดดูทุกปีแล้วหยุดเมื่อพ้นศูนย์: แต่ละครั้งที่เปิดดูคือโอกาสพลาดอีกครั้ง coverage ของกระบวนการทั้งหมดจึงต่ำกว่า 95% ถ้าจะดูหลายครั้ง ต้องใช้วิธีที่ออกแบบสำหรับการดูต่อเนื่อง

ข้อมูลไม่อิสระ: NAV ของกองทุนที่ถือสินทรัพย์สภาพคล่องต่ำมักถูกทำให้เรียบ ปีติดกันจึงสัมพันธ์กัน SE จริงใหญ่กว่า $\sigma/\sqrt n$ (ดูตัวคูณใน central limit theorem) ต้องใช้ HAC (Newey–West) หรือ block bootstrap

ช่วงของผู้ชนะที่ถูกคัดมา: ถ้ากองทุนนี้ถูกเลือกเพราะดีที่สุดจาก 200 กอง ช่วง 95% ธรรมดาครอบค่าจริงน้อยกว่า 95% มาก ดู ปัญหาการทดสอบหลายครั้ง

ใช้ทำอะไรบนโต๊ะจริง

รายงานที่ดีมีครบ: ปริมาณที่ประมาณ หน่วย ช่วงเวลา จำนวนข้อมูลอิสระ estimate, SE, ใช้ $z$ หรือ $t$, ระดับความมั่นใจ และข้อสมมติ ฝ่ายความเสี่ยงควรถามเสมอว่าช่วงนี้เป็นช่วงของค่าเฉลี่ยหรือช่วงทำนาย และถ้าเป็นการเลือกจากหลายตัว ได้ปรับเรื่องการเลือกแล้วหรือยัง ช่วงความมั่นใจของ alpha ใน CAPM หรือของ factor exposure ใน multi-factor models ใช้หลักเดียวกันนี้ทุกตัว

โจทย์ตรวจความเข้าใจ

1. ช่วง 95% ของค่าเฉลี่ยครอบศูนย์ แปลว่าค่าเฉลี่ยจริงเป็นศูนย์หรือไม่ และค่าใดอีกบ้างที่ยังไม่ถูกปฏิเสธ

เฉลย

ไม่ใช่ แปลว่าข้อมูลยังไม่ปฏิเสธศูนย์ด้วยวิธีนี้ ทุกค่าในช่วงก็ยังไม่ถูกปฏิเสธเช่นกัน ในตัวอย่างสี่ปีแบบรู้ SD คือทุกค่าตั้งแต่ −2.88% ถึง 8.88% ซึ่งรวมทั้งกองทุนแย่และกองทุนดีมาก

2. ค่าเฉลี่ย 3%, รู้ SD 6%, $n=4$ ถ้าเปลี่ยนจาก 95% เป็น 99% จะได้ช่วงอะไร และกว้างขึ้นกี่เปอร์เซ็นต์

เฉลย

ครึ่งความกว้าง $2.576\times3=7.728$ จุด ได้ $[-4.728\%,\ 10.728\%]$ กว้างขึ้น $7.728/5.88-1\approx31.4\%$ โดยไม่มีข้อมูลใหม่ ความมั่นใจที่สูงขึ้นจ่ายด้วยความกว้าง

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
// Two-sided Student-t critical value: substitute x = sqrt(df) tan(theta),
// so the density integral becomes the integral of cos(theta)^(df-1).
function integral(df, upper) {
  const steps = 2000, h = upper / steps, f = th => Math.cos(th) ** (df - 1);
  let s = f(0) + f(upper);
  for (let i = 1; i < steps; i++) s += (i % 2 ? 4 : 2) * f(i * h);
  return h * s / 3;
}
function tCrit(df, level = 0.95) {
  const total = integral(df, Math.PI / 2);
  let lo = 0, hi = Math.PI / 2;
  for (let i = 0; i < 60; i++) {
    const mid = (lo + hi) / 2;
    if (integral(df, mid) / total < level) lo = mid; else hi = mid;
  }
  return Math.sqrt(df) * Math.tan((lo + hi) / 2);
}
const mean = 3, sd = 6;
const zInterval = n => [mean - 1.96 * sd / Math.sqrt(n), mean + 1.96 * sd / Math.sqrt(n)];
const tInterval = n => { const h = tCrit(n - 1) * sd / Math.sqrt(n); return [mean - h, mean + h]; };
let firstT = 2;
while (tInterval(firstT)[0] <= 0) firstT++;
// Coverage of 25 simulated four-year histories (true mean 3, sd 6, known sd).
let seed = 3;
const u = () => { seed = (Math.imul(1664525, seed) + 1013904223) >>> 0; return (seed + 0.5) / 4294967296; };
const normal = () => Math.sqrt(-2 * Math.log(u())) * Math.cos(2 * Math.PI * u());
let covered = 0;
for (let r = 0; r < 25; r++) {
  let s = 0;
  for (let i = 0; i < 4; i++) s += mean + sd * normal();
  if (Math.abs(s / 4 - mean) <= 5.88) covered++;
}
const t3cdf = t => 0.5 + (t / (Math.sqrt(3) * (1 + t * t / 3)) + Math.atan(t / Math.sqrt(3))) / Math.PI;
const result = {
  z4: zInterval(4), z16: zInterval(16), z99: [mean - 2.576 * 3, mean + 2.576 * 3],
  yearsZ: (1.96 * sd / mean) ** 2, yearsZquarter: (1.96 / 0.25) ** 2,
  t3: tCrit(3), t15: tCrit(15), t29: tCrit(29), t4: tInterval(4), firstT,
  t3OutsideZ: 2 * (1 - t3cdf(1.96)),
  coverageCountSD: Math.sqrt(100 * 0.95 * 0.05), covered,
  boxJoint: 0.95 ** 2, circleRadius: Math.sqrt(-2 * Math.log(0.05)),
  seFiveYears: 20 / Math.sqrt(5),
  prediction: [mean - 1.96 * sd * Math.sqrt(1.25), mean + 1.96 * sd * Math.sqrt(1.25)]
};
console.log(JSON.stringify(result, null, 1));

สิ่งที่ควรตอบได้หลังอ่าน

  • ช่วงคือ estimate ± ตัวคูณ × SE และตัวคูณมาจากพื้นที่ใต้การแจกแจงที่ถูกต้อง: 1.96 สำหรับ normal, 3.182 สำหรับ $t_3$
  • สี่ปีที่ค่าเฉลี่ย 3% และ SD 6% ให้ช่วง [−2.88%, 8.88%] ถ้ารู้ SD และ [−6.55%, 12.55%] ถ้าประมาณ SD
  • 95% คืออัตราการครอบของวิธีเมื่อใช้ซ้ำ ไม่ใช่โอกาสที่ช่วงหนึ่งช่วงครอบค่าจริง
  • สองช่วง 95% แยกกันครอบคู่ค่าจริงเพียง 90.25% บริเวณร่วมที่ถูกต้องมีรัศมี 2.448 SE
  • ช่วงทำนายปีหน้า [−10.15%, 16.15%] กว้างกว่าช่วงของค่าเฉลี่ยมากและไม่หดเหลือศูนย์

ช่วงบอกว่าค่าใดยังเข้ากับข้อมูลได้ หน้าถัดไป การทดสอบสมมติฐานและการอนุมาน Sharpe ratio จะถามกลับด้าน: ถ้าค่าจริงเป็นศูนย์ ข้อมูลที่เห็นหายากแค่ไหน แล้วใช้คำตอบนั้นตัดสิน backtest ที่มี Sharpe 1.20
