3.4 Confidence Intervals

confidence interval คือ estimate บวกลบ (ตัวคูณจากการแจกแจง × SE) และคำว่า 95% เป็นสมบัติของวิธีสร้างช่วง ไม่ใช่ของช่วงที่ได้มาแล้วหนึ่งช่วง

กองทุนแห่งหนึ่ง (สมมติ) เปิดมาได้สี่ปี ฝ่ายขายอยากเขียนในเอกสารเสนอขายว่า “กองทุนชนะดัชนีปีละ 3%” ฝ่ายความเสี่ยงค้าน เพราะสี่ปีเป็นข้อมูลที่น้อยมาก ตัวเลข 3% อาจมาจากโชคก็ได้ ฝ่ายความเสี่ยงจึงขอให้เขียนเป็นช่วง เช่น “ชนะดัชนีปีละ 3% แต่ค่าจริงอาจอยู่ระหว่าง … ถึง …” แทนตัวเลขเดียว

ของที่รู้:

  • active return คือผลตอบแทนของกองทุนลบผลตอบแทนของดัชนีที่ใช้เทียบในปีเดียวกัน เช่น ปีหนึ่งกองทุนได้ 10% ดัชนีได้ 7% active return ของปีนั้นคือ $10\%-7\%=3\%$
  • จำนวนปีที่มีข้อมูล $n=4$ ปี
  • active return เฉลี่ยของสี่ปีนั้น $\bar X=3\%$ ต่อปี
  • SD (standard deviation) ของ active return รายปี $\sigma=6\%$ คือขนาดที่ตัวเลขแต่ละปีแกว่งไปรอบค่าเฉลี่ย หรือความผันผวนของมัน

คำถาม: ช่วงนี้ควรกว้างแค่ไหน และช่วงที่ได้ครอบศูนย์ไหม (ถ้าศูนย์อยู่ในช่วง แปลว่าข้อมูลยังบอกไม่ได้ว่ากองทุนชนะดัชนีจริง)

ลองตอบก่อนเปิดเฉลย

คำตอบขึ้นกับว่าตัวเลข 6% มาจากไหน

ถ้า 6% เป็น SD ที่รู้แน่จากแหล่งอื่น ค่าเฉลี่ยสี่ปีจะคลาดจากค่าจริงได้ประมาณ $\mathrm{SE}=\sigma/\sqrt n=6/\sqrt4=3$ จุด (SE หรือ standard error คือขนาดความคลาดของค่าเฉลี่ย ซึ่งเท่ากับ SD หารด้วยรากของจำนวนปี) ช่วง 95% คือค่าเฉลี่ยบวกลบ 1.96 เท่าของ SE:

\[\begin{aligned}3\pm1.96\times3&=3\pm5.88\\&=[-2.88\%,\ 8.88\%]\end{aligned}\]

ถ้า 6% คำนวณจากสี่ปีเดียวกัน ตัว SD เองก็คลาดได้ จึงต้องใช้ตัวคูณที่ใหญ่ขึ้น คือ 3.182 จากการแจกแจง Student $t$:

\[\begin{aligned}3\pm3.182\times3&=3\pm9.55\\&=[-6.55\%,\ 12.55\%]\end{aligned}\]

ทั้งสองช่วงครอบศูนย์ ข้อมูลสี่ปีจึงยังแยกกองทุนนี้ออกจากกองทุนที่ไม่มีฝีมือเลยไม่ได้ หน้านี้จะหาที่มาของ 1.96 และ 3.182 ให้ดูทีละขั้น

ภาพรวมก่อนลงสูตร

ตัวเลข 3% ตัวเดียวไม่บอกเรื่องที่สำคัญที่สุด คือมันคลาดจากค่าจริงได้แค่ไหน ถ้าย้อนเวลาไปเก็บข้อมูลสี่ปีชุดใหม่จากกองทุนเดิม ค่าเฉลี่ยจะไม่ออกมา 3% เท่าเดิม มันอาจต่ำหรือสูงกว่าไปหลายจุด (รูปด้านล่างจะให้เห็น) วิธีรายงานที่ซื่อสัตย์กว่าคือรายงานเป็นช่วง เรียกว่า confidence interval (CI) คือช่วงของค่าจริงที่ข้อมูลยังเข้ากันได้ ค่าใดอยู่ในช่วง ข้อมูลก็ยังปัดตกค่านั้นไม่ได้

CI ทุกแบบในหน้านี้มีหน้าตาเดียวกัน: เอาค่าประมาณจากข้อมูล (estimate เช่นค่าเฉลี่ย 3%) มาบวกลบด้วยตัวคูณ $c$ คูณ SE ได้ช่วง $[L,U]=\bar X\pm c\times\mathrm{SE}$ โดย $L$ คือขอบล่าง และ $U$ คือขอบบน SE (standard error) คือขนาดที่ค่าประมาณคลาดได้ ซึ่งหน้า estimator และ standard error หาไว้แล้ว ส่วนตัวคูณ $c$ เช่น 1.96 มาจากพื้นที่ใต้โค้งการแจกแจง ขั้นแรกของหน้านี้จะหาให้ดู

ส่วนที่คนเข้าใจผิดบ่อยที่สุดคือคำว่า 95% ให้นึกถึงเครื่องจักรที่ผลิตช่วง ป้อนข้อมูลหนึ่งชุด ได้ช่วงออกมาหนึ่งช่วง ถ้าป้อนข้อมูลชุดใหม่ซ้ำไปเรื่อย ๆ ประมาณ 95 ช่วงจาก 100 ช่วงจะครอบค่าจริง ตัวเลข 95% จึงเป็นคุณภาพของเครื่อง คือวิธีสร้างช่วง มันไม่ได้แปลว่าช่วงที่ได้มาแล้วหนึ่งช่วงมีโอกาส 95% ที่จะครอบค่าจริง รูปด้านล่างแสดงเรื่องนี้ตรง ๆ

หน้านี้จะเดินทีละขั้นตามลำดับนี้:

  • หาตัวคูณ 1.96 จากพื้นที่ใต้โค้ง normal
  • พลิกอสมการให้กลายเป็นช่วงของค่าจริง
  • คำนวณช่วงของกองทุนนี้ และถามว่าต้องมีข้อมูลกี่ปีช่วงจึงพ้นศูนย์
  • เปลี่ยนไปใช้ Student $t$ เมื่อ SD ก็ต้องคำนวณจากข้อมูล
  • ตรวจความหมายของ 95% ด้วยการนับ
  • ปิดด้วยสองเรื่องที่เจอบ่อยในงานจริง คือช่วงของหลายค่าพร้อมกัน และช่วงทำนายผลปีหน้า
ศัพท์ที่ใช้ในหน้านี้
Active return
ผลตอบแทนของกองทุนลบผลตอบแทนของดัชนีที่ใช้เทียบ ในช่วงเวลาเดียวกัน บวกแปลว่าชนะดัชนี ลบแปลว่าแพ้
Standard error (SE)
ขนาดที่ค่าประมาณคลาดจากค่าจริงโดยทั่วไป คือ SD ของค่าประมาณเมื่อเก็บข้อมูลใหม่ซ้ำ ค่าเฉลี่ยของ $n$ ปีที่อิสระกันมี $\mathrm{SE}=\sigma/\sqrt n$ ดูที่มาในหน้า estimator และ standard error
Confidence interval (CI)
ช่วง $[L,U]$ ที่คำนวณจากข้อมูล วิธีสร้างถูกออกแบบให้ครอบค่าจริงในสัดส่วนที่กำหนด เช่น 95 ครั้งจาก 100 ครั้ง เมื่อทำซ้ำกับข้อมูลชุดใหม่ ใช้บอกว่าค่าจริงค่าใดบ้างที่ข้อมูลยังเข้ากันได้
Coverage
สัดส่วนครั้งที่ช่วงครอบค่าจริงจริง ๆ เมื่อเก็บข้อมูลใหม่ซ้ำหลายครั้ง ถ้าข้อสมมติของสูตรผิด coverage จริงอาจต่ำกว่าตัวเลขบนป้าย เช่น ป้ายบอก 95% แต่ครอบจริงแค่ราว 85%
Critical value / quantile
จุดบนแกนที่พื้นที่ใต้โค้งทางซ้ายของมันเท่ากับสัดส่วนที่กำหนด เช่น 1.96 คือจุดที่พื้นที่ใต้โค้ง normal มาตรฐานทางซ้ายเท่ากับ 97.5% ใช้เป็นตัวคูณของ SE
Pivot
สูตรที่มีทั้งค่าจริงและข้อมูลอยู่ข้างใน แต่การแจกแจงของมันรู้แน่และไม่ขึ้นกับค่าจริง เช่น $(\bar X-\mu)/(\sigma/\sqrt n)$ ซึ่งเป็น normal มาตรฐานเสมอ จึงพลิกอสมการให้กลายเป็นช่วงของค่าจริงได้
Student $t$
การแจกแจงของความคลาดของค่าเฉลี่ยวัดเป็นจำนวน SE เมื่อ SE คำนวณจาก sample SD $s$ (SD ที่คำนวณจากข้อมูล) แทน SD จริง หางหนากว่า normal เพื่อเผื่อว่า $s$ เองก็คลาดได้
df (degrees of freedom)
ตัวเลขที่บอกว่าใช้ Student $t$ แบบไหน สำหรับค่าเฉลี่ยของ $n$ ค่า df คือ $n-1$ ยิ่ง df มาก Student $t$ ยิ่งใกล้ normal
Prediction interval
ช่วงของค่าใหม่หนึ่งค่า เช่นผลตอบแทนปีหน้า กว้างกว่า CI ของค่าเฉลี่ย เพราะต้องรวมการแกว่งของปีหน้าเองเข้าไปด้วย
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$\mu$ค่าเฉลี่ยจริงของ active return ค่าที่อยากรู้แต่มองไม่เห็นจุดเปอร์เซ็นต์ต่อปี
$\hat\mu=\bar X$ค่าเฉลี่ยที่คำนวณจากข้อมูล ก่อนเห็นข้อมูลมันยังสุ่มจุดเปอร์เซ็นต์ต่อปี
$\sigma,\ s$SD จริง และ sample SD (SD ที่คำนวณจากข้อมูล) ของ active return รายปีจุดเปอร์เซ็นต์
$n$จำนวนปีที่อิสระกันปี
$\mathrm{SE}=\sigma/\sqrt n$ขนาดความคลาดของค่าเฉลี่ย $n$ ปีจุดเปอร์เซ็นต์
$Z$ความคลาด $\bar X-\mu$ วัดเป็นจำนวน SE เป็น normal มาตรฐาน (ค่าเฉลี่ย 0 และ SD 1)ไม่มีหน่วย
$z_{0.975},\ t_{0.975,\nu}$ตัวคูณของ normal และของ Student $t$ ที่ df เท่ากับ $\nu$ไม่มีหน่วย
$[L,U]$ขอบล่างและขอบบนของช่วงจุดเปอร์เซ็นต์ต่อปี

ขั้นที่ 1 — ตัวคูณ 1.96 มาจากพื้นที่ ไม่ใช่เลขที่ต้องท่อง

ช่วงของเราจะมีรูป ค่าเฉลี่ย ± ตัวคูณ × SE จึงต้องรู้ก่อนว่าตัวคูณควรเป็นเท่าไร ความคลาดของค่าเฉลี่ยจากค่าจริงกระจายเป็นรูประฆัง normal (ขั้นถัดไปบอกว่าเพราะอะไร) ถ้าวัดความคลาดนั้นเป็นจำนวน SE จะได้ตัวแปร normal มาตรฐาน $Z$ ซึ่งมีค่าเฉลี่ย 0 และ SD 1 คำถามจึงกลายเป็น: $Z$ อยู่ระหว่าง $-z$ ถึง $z$ ด้วยโอกาส 95% เมื่อ $z$ เท่าไร

ช่วงที่วางสมมาตรรอบศูนย์แคบที่สุด เพราะโค้งสูงที่สุดตรงกลาง ช่วงตรงกลางจึงเก็บพื้นที่ได้มากที่สุดต่อความกว้าง พื้นที่ที่เหลือ $100\%-95\%=5\%$ แบ่งไปหางละ $5\%/2=2.5\%$ ขอบขวาจึงเป็นจุดที่พื้นที่ทางซ้ายทั้งหมดเท่ากับ $95\%+2.5\%=97.5\%$ เรียกจุดนี้ว่า $z_{0.975}$ และเขียน $\Phi(z)$ แทนพื้นที่ใต้โค้งทางซ้ายของ $z$

\[\begin{aligned} \Phi(z_{0.975})&=0.975,\qquad z_{0.975}\approx1.96,\\ P(-1.96\le Z\le1.96)&\approx0.95,\\ z_{0.95}\approx1.645,&\qquad z_{0.995}\approx2.576. \end{aligned}\]

ตัวคูณก็คือขอบที่กันพื้นที่ใต้ระฆังไว้ตรงกลางตามที่ต้องการ ค่า 1.96 ไม่ต้องท่อง มันคือคำตอบของ $\Phi(z)=0.975$ ซึ่งเปิดตาราง normal มาตรฐานหรือให้คอมพิวเตอร์หาก็ได้ ($\Phi$ คือ CDF หรือพื้นที่สะสมจากซ้าย)

ระดับอื่นคิดแบบเดียวกัน ช่วง 90% เหลือหางละ 5% ขอบขวาจึงอยู่ที่พื้นที่สะสม 95% ได้ 1.645 ช่วง 99% เหลือหางละ 0.5% ขอบขวาอยู่ที่ 99.5% ได้ 2.576 ถ้าปัด 1.96 เป็น 2 พื้นที่ตรงกลางคือพื้นที่ทางซ้ายของ 2 ลบพื้นที่ทางซ้ายของ −2 ได้ $\Phi(2)-(1-\Phi(2))=2\Phi(2)-1\approx95.45\%$ ไม่ใช่ 95% พอดี

ความมั่นใจที่สูงขึ้นต้องแลกด้วยช่วงที่กว้างขึ้น จากข้อมูลชุดเดียวกัน ช่วง 99% กว้างกว่าช่วง 95% ราว $2.576/1.96-1\approx31.4\%$

ขั้นที่ 2 — จัดอสมการให้ค่าจริงอยู่ตรงกลาง

ตอนนี้รู้แล้วว่า $Z$ อยู่ระหว่าง −1.96 ถึง 1.96 ด้วยโอกาส 95% แต่สิ่งที่อยากได้คือช่วงของ $\mu$ ค่าเฉลี่ยจริงที่มองไม่เห็น ขั้นนี้จะเปลี่ยนประโยคเรื่อง $Z$ ให้เป็นประโยคเรื่อง $\mu$

เริ่มจากข้อสมมติ: active return แต่ละปีเป็น normal อิสระกัน และรู้ SD จริง $\sigma$ ค่าเฉลี่ย $n$ ปีมี $\mathrm{SE}=\sigma/\sqrt n$ ความคลาด $\bar X-\mu$ วัดเป็นจำนวน SE คือ $(\bar X-\mu)/(\sigma/\sqrt n)$ ซึ่งเป็น normal มาตรฐานพอดี (ถ้าข้อมูลไม่ normal central limit theorem บอกว่ามันยังใกล้ normal เมื่อ $n$ มากพอ) ที่นี่ $\bar X$ เขียนตัวใหญ่ เพราะเป็นค่าเฉลี่ยก่อนเห็นข้อมูล ซึ่งยังสุ่มอยู่

สูตรนี้มี $\mu$ อยู่ข้างใน แต่การแจกแจงของมันไม่ขึ้นกับ $\mu$ สูตรแบบนี้เรียกว่า pivot และเพราะเหตุนี้ เราจึงจัดอสมการให้ $\mu$ ไปอยู่ตรงกลางได้

\[\begin{aligned} -z&\le\frac{\bar X-\mu}{\sigma/\sqrt n}\le z,\\ -z\frac{\sigma}{\sqrt n}&\le\bar X-\mu\le z\frac{\sigma}{\sqrt n},\\ \bar X-z\frac{\sigma}{\sqrt n}&\le\mu\le\bar X+z\frac{\sigma}{\sqrt n}. \end{aligned}\]

ทั้งสามแถวพูดถึงเหตุการณ์เดียวกัน แค่จัดรูปใหม่ ถ้าแถวหนึ่งจริง อีกสองแถวก็จริงด้วย ทั้งสามจึงมีโอกาส 95% เท่ากันเมื่อ $z=1.96$

จังหวะที่ต้องระวังคือเครื่องหมาย การคูณทุกข้างด้วย SE ไม่เปลี่ยนทิศอสมการ เพราะ SE เป็นบวก แต่การลบ $\bar X$ ทุกข้างแล้วคูณด้วย −1 กลับทิศอสมการ ขอบซ้ายกับขอบขวาจึงสลับกัน ผลที่ได้คือรูปที่จำง่าย estimate ± ตัวคูณ × SE

เรื่องที่สำคัญที่สุดอยู่ในแถวสุดท้าย ตัวที่สุ่มคือขอบ $\bar X\pm z\sigma/\sqrt n$ เพราะมี $\bar X$ อยู่ข้างใน ส่วน $\mu$ เป็นค่าคงที่ที่ไม่ขยับ โอกาส 95% จึงเป็นของขอบที่กำลังจะได้ ไม่ใช่ของ $\mu$ ขั้นที่ 6 จะกลับมาที่เรื่องนี้

ขั้นที่ 3 — รู้ SD จริง: สี่ปีให้ช่วงกว้างแค่ไหน

กลับมาที่กองทุนตอนต้นหน้า ขั้นนี้สมมติไปก่อนว่ารู้ SD จริง เช่น ได้มาจากกองทุนอื่นที่ใช้กลยุทธ์เดียวกันมาหลายสิบปี ขั้นที่ 5 จะตัดข้อสมมตินี้ออก

โจทย์ให้อะไรมาบ้าง:

  • ค่าเฉลี่ยจากข้อมูล $\bar X=3\%$ ต่อปี
  • SD รายปี $\sigma=6\%$ รู้แน่จากแหล่งอื่น
  • จำนวนปี $n=4$ แต่ละปีอิสระกัน และ active return รายปีเป็น normal
  • ระดับ 95% จึงใช้ตัวคูณ 1.96 จากขั้นที่ 1

คำนวณ SE ก่อน แล้วบวกลบ 1.96 เท่าของ SE:

\[\begin{aligned} \mathrm{SE}&=\frac{6}{\sqrt4}=3,\\ 3\pm1.96(3)&=3\pm5.88,\\ {[L,U]}&=[-2.88,\ 8.88]. \end{aligned}\]

คำตอบ: ช่วงของค่าเฉลี่ย active return คือ −2.88% ถึง 8.88% ช่วงนี้ครอบศูนย์ แปลว่าข้อมูลยังปัดตกความเป็นไปได้ที่ค่าเฉลี่ยจริงเป็นศูนย์ไม่ได้ แต่มันไม่ได้พิสูจน์ว่าฝีมือเป็นศูนย์ เพราะค่า 5% หรือ 8% ก็อยู่ในช่วง และยังปัดตกไม่ได้เช่นกัน

ถ้ามีข้อมูลมากขึ้น ช่วงจะแคบลงแค่ไหน ลองสมมติว่าค่าเฉลี่ยที่เห็นยังเป็น 3% แล้วเปลี่ยนแค่จำนวนปี $n$ ครึ่งความกว้างของช่วงคือ $1.96\times6/\sqrt n$:

ในตารางนี้ ขอบล่างเพิ่งพ้นศูนย์ที่ 16 ปี ขั้นถัดไปจะหาเลข 16 นี้ตรง ๆ จากอสมการ

ตรวจเองใน 10 วินาที: ครึ่งความกว้างที่ 16 ปีคือ $1.96\times6/\sqrt{16}=1.96\times1.5=2.94$ ซึ่งเท่ากับ $5.88/2$ ครึ่งหนึ่งของที่สี่ปีพอดี ข้อมูลมากขึ้น $16/4=4$ เท่า แต่ช่วงแคบลงแค่ครึ่งเดียว เพราะ SE หารด้วย $\sqrt n$ และ $\sqrt4=2$

ขั้นที่ 4 — ต้องมีกี่ปีช่วงจึงพ้นศูนย์

ผู้จัดการกองทุนจะถามต่อทันทีว่า “ต้องมีผลงานอีกกี่ปี ช่วงถึงจะไม่ครอบศูนย์” ตอบได้โดยตั้งเงื่อนไขว่าขอบล่าง $L=\bar X-1.96\,\sigma/\sqrt n$ ต้องมากกว่าศูนย์ แล้วแก้หา $n$ โดยตรึงค่าเฉลี่ย 3% และ SD 6% ไว้ตามที่เห็น แถวสุดท้ายทำแบบเดียวกันกับกองทุนอีกแบบหนึ่ง ที่ค่าเฉลี่ยเป็นแค่หนึ่งในสี่ของ SD

\[\begin{aligned} 3-1.96\frac{6}{\sqrt n}&\gt0,\\ \sqrt n&\gt\frac{1.96\times6}{3}=3.92,\\ n&\gt15.3664,\\ \frac{\bar X}{\sigma}=0.25:\quad n&\gt\Big(\frac{1.96}{0.25}\Big)^2=61.4656. \end{aligned}\]

แก้อสมการแบบเดียวกันโดยไม่แทนตัวเลข จะได้ $n\gt(1.96\,\sigma/\bar X)^2$ จำนวนปีที่ต้องรอจึงขึ้นกับกำลังสองของอัตราส่วน SD ต่อค่าเฉลี่ย กองทุนในโจทย์มี $\sigma/\bar X=6/3=2$ ได้ $n\gt(1.96\times2)^2\approx15.37$ และเพราะจำนวนปีต้องเป็นจำนวนเต็ม จึงต้อง 16 ปี

กองทุนในแถวสุดท้ายมี $\bar X/\sigma=0.25$ เช่น ค่าเฉลี่ย 1.5% กับ SD 6% ได้ $n\gt61.47$ คือต้อง 62 ปี นานกว่าช่วงชีวิตการทำงานของผู้จัดการกองทุนเสียอีก ค่าเฉลี่ยที่เล็กลงครึ่งหนึ่งทำให้ต้องรอนานขึ้นสี่เท่า

อย่าอ่านเลข 16 เป็นคำสัญญา มันคือการคำนวณความกว้างโดยสมมติว่าค่าเฉลี่ยจะยังเป็น 3% แต่ค่าเฉลี่ยของปีต่อ ๆ ไปอาจออกมาต่ำกว่านั้นก็ได้ ถ้าอยากวางแผนให้ช่วงพ้นศูนย์ด้วยโอกาสสูง ต้องใช้แนวคิด power (โอกาสที่การทดสอบจะจับผลที่มีอยู่จริงได้) ในหน้า การทดสอบสมมติฐาน

อีกกับดักหนึ่ง: ถ้าตรวจช่วงทุกปีแล้วหยุดทันทีที่พ้นศูนย์ coverage จริงจะต่ำกว่า 95% เพราะการตรวจแต่ละครั้งคือการให้โอกาสตัวเองโชคดีอีกครั้ง

ขั้นที่ 5 — SD มาจากข้อมูลเดียวกัน: เปลี่ยนเป็น Student t

ขั้นที่ 3 แอบโกงไว้ข้อหนึ่ง คือสมมติว่ารู้ SD จริง 6% ในชีวิตจริงแทบไม่มีใครรู้ เราต้องคำนวณ SD จากสี่ปีเดียวกันนั้นเอง เรียกว่า sample SD และเขียนว่า $s$ ปัญหาคือ $s$ ก็สุ่มเหมือน $\bar X$ บางชุดข้อมูลได้ $s$ เล็กกว่าความจริงโดยบังเอิญ

เมื่อตัวหารเล็กเกินจริง อัตราส่วน “ความคลาดหารด้วย SE” ก็พุ่งสูงเกินจริง ค่าสุดโต่งจึงเกิดบ่อยกว่าที่ normal ทำนาย การแจกแจงของอัตราส่วนนี้ชื่อ Student $t$ หางของมันหนากว่า normal ตัวคูณจึงต้องใหญ่ขึ้น ในสูตรข้างล่าง $t_{n-1}$ คือ Student $t$ ที่มี df เท่ากับ $n-1$ และ $t_{0.975,\,n-1}$ คือจุดที่พื้นที่ทางซ้ายเท่ากับ 97.5% ทำหน้าที่เดียวกับ 1.96 ของ normal

\[\begin{aligned} T&=\frac{\bar X-\mu}{s/\sqrt n}\ \sim\ t_{n-1},\\ {[L,U]}&=\bar X\pm t_{0.975,\,n-1}\frac{s}{\sqrt n},\\ n=4:\quad t_{0.975,3}&\approx3.182,\\ 3\pm3.182\times3&=3\pm9.547. \end{aligned}\]

Student $t$ คือ normal ที่เผื่อความคลาดของ SD ไว้ในหาง df (degrees of freedom) เท่ากับ $n-1$ ด้วยเหตุผลเดียวกับตัวหาร $n-1$ ของ sample variance: ส่วนต่างจากค่าเฉลี่ยของข้อมูลสี่ตัว (มีทั้งบวกและลบ) รวมกันต้องเป็นศูนย์เสมอ รู้สามตัวก็รู้ตัวที่สี่ จึงขยับได้อิสระจริงแค่ $4-1=3$ ตัว ค่า 3.182 เปิดจากตาราง Student $t$ ที่ df 3 หรือให้คอมพิวเตอร์หาก็ได้ (โค้ดท้ายหน้าหาให้ดู)

กลับมาที่กองทุนในโจทย์ ถ้าตัวเลข 6% คือ $s$ ที่คำนวณจากสี่ปีนั้นเอง SE ยังเป็น $s/\sqrt n=6/\sqrt4=3$ เท่าเดิม แต่ตัวคูณเปลี่ยนจาก 1.96 เป็น 3.182 ช่วงจึงกลายเป็น $3\pm9.547=[-6.55\%,\ 12.55\%]$ กว้างกว่าแบบรู้ SD ราว $9.547/5.88-1\approx62\%$ ส่วนที่กว้างขึ้นนี้คือราคาของการไม่รู้ SD

ข้อมูลยิ่งมาก $s$ ยิ่งใกล้ $\sigma$ ตัวคูณจึงลดเข้าหา 1.96 ที่ df 3, 15 และ 29 ตัวคูณคือราว 3.182, 2.131 และ 2.045 ถ้าตรึงค่าเฉลี่ย 3% และ $s=6\%$ ไว้เหมือนขั้นที่ 4 จะเห็นว่าต้องรอนานขึ้น:

  • 16 ปี (df 15): $3\pm2.1314\times6/\sqrt{16}=3\pm3.20$ ได้ [−0.20%, 6.20%] ยังครอบศูนย์
  • 17 ปี (df 16): $3\pm2.1199\times6/\sqrt{17}=3\pm3.08$ ได้ [−0.08%, 6.08%] ยังครอบศูนย์
  • 18 ปี (df 17): $3\pm2.1098\times6/\sqrt{18}=3\pm2.98$ ได้ [0.02%, 5.98%] เพิ่งพ้นศูนย์ ช้ากว่าแบบรู้ SD สองปี

Student $t$ ถูกต้องพอดีเมื่อข้อมูลรายปีเป็น normal ถ้าข้อมูลน้อยและเบ้มาก เช่นมีปีแย่ ๆ ไม่กี่ปีที่ลากค่าเฉลี่ยไปไกล มันก็ป้องกันไม่ได้ ชื่อ Student มาจากนามแฝงของ William Gosset นักเคมีของโรงเบียร์ Guinness ที่ต้องตัดสินใจจากตัวอย่างข้าวบาร์เลย์เพียงไม่กี่แปลง

ขั้นที่ 6 — 95% เป็นสมบัติของวิธี: นับช่วงที่ครอบ

ขั้นที่ 2 บอกว่าโอกาส 95% เป็นของขอบ ไม่ใช่ของ $\mu$ ขั้นนี้ทำให้ประโยคนั้นจับต้องได้ ก่อนเห็นข้อมูล ขอบ $L$ กับ $U$ ยังสุ่ม จึงพูดได้ว่า “วิธีนี้จะให้ช่วงที่ครอบ $\mu$ ด้วยโอกาส 95%” หลังเห็นข้อมูลแล้ว ทั้งขอบและ $\mu$ เป็นตัวเลขคงที่ ช่วงนั้นครอบ $\mu$ หรือไม่ครอบ มีแค่สองแบบ เพียงแต่เราไม่รู้ว่าเป็นแบบไหน

วิธีตรวจว่าวิธีหนึ่งครอบ 95% จริงไหม คือใช้มันซ้ำแล้วนับ แบบเดียวกับรูปช่วง 25 เส้นตอนต้นหน้า สมมติสร้างช่วงจากข้อมูลอิสระ 100 ชุดด้วยวิธีที่ครอบจริง 95% ให้ $C$ คือจำนวนช่วงที่ครอบค่าจริง แต่ละชุดเหมือนโยนเหรียญที่ออกหัว (ครอบ) ด้วยโอกาส 0.95 จำนวนหัวจาก 100 ครั้งจึงเป็น binomial ซึ่งมีค่าเฉลี่ย $\mathbb E[C]=100p$ และ SD เท่ากับ $\sqrt{100\,p(1-p)}$ เมื่อ $p=0.95$ คือโอกาสออกหัวในแต่ละครั้ง

\[\begin{aligned} C&\sim\operatorname{Binomial}(100,\ 0.95),\\ \mathbb E[C]&=95,\\ \operatorname{SD}(C)&=\sqrt{100(0.95)(0.05)}\approx2.18. \end{aligned}\]

จำนวนช่วงที่ครอบไม่ได้ออกมา 95 ทุกครั้ง มันแกว่งรอบ 95 ด้วย SD ราว 2.18 ช่วง ระยะ ±2 SD คือ $95\pm2\times2.18\approx95\pm4.4$ ได้ 91 ถึง 99 ช่วงจึงเป็นเรื่องปกติ รูปตอนต้นหน้ามี 25 ช่วง ค่าที่คาดคือ $25\times0.95=23.75$ ช่วง ได้ 23 ช่วง (92%) จึงปกติเช่นกัน

ถ้าอยากพูดประโยค “มีโอกาส 95% ที่ค่าจริงอยู่ในช่วงนี้” ได้ตรง ๆ ต้องเปลี่ยนไปใช้กรอบ Bayes คือกำหนดความเชื่อก่อนเห็นข้อมูล (prior) แล้วปรับด้วยข้อมูลผ่าน Bayes’ theorem ได้ช่วงที่เรียกว่า credible interval ซึ่งตอบคนละคำถามกับ CI ถ้า prior กว้างมากและข้อมูลเป็น normal ตัวเลขของสองช่วงจะใกล้กัน แต่ความหมายต่างกัน

แนวคิด coverage ของ CI มาจาก Jerzy Neyman ในทศวรรษ 1930

ขั้นที่ 7 — ประมาณสองค่าพร้อมกัน: กล่องสองช่วงไม่ใช่ 95%

ในงานจริง ค่าเฉลี่ยไม่ได้ถูกใช้ทีละตัว optimizer (โปรแกรมที่คำนวณว่าควรใส่เงินในสินทรัพย์แต่ละตัวเท่าไร) ต้องการค่าเฉลี่ยของหลายสินทรัพย์พร้อมกัน คำถามจึงเปลี่ยนเป็น: บริเวณที่ครอบค่าจริงทุกตัวพร้อมกันด้วยโอกาส 95% หน้าตาเป็นอย่างไร ลองดูกรณีเล็กที่สุดคือสองสินทรัพย์ (สมมติ)

  • สินทรัพย์ A และ B ไม่สัมพันธ์กัน (correlation เป็นศูนย์)
  • ความผันผวนต่อปี $\sigma=20\%$ ทั้งคู่
  • ข้อมูลรายเดือน 60 เดือน คือ $60/12=5$ ปี
  • ค่าเฉลี่ยรายปีที่ประมาณได้ 8% สำหรับ A และ 4% สำหรับ B

SE ของค่าเฉลี่ยรายปีขึ้นกับจำนวนปี ไม่ใช่จำนวนเดือน (เหตุผลอยู่ในหน้า estimator และ standard error) จึงได้ $\mathrm{SE}=20/\sqrt5\approx8.94$ จุดสำหรับแต่ละตัว ถ้าวาดช่วง 95% ของแต่ละตัวแยกกัน คือ $8\pm1.96\times8.94$ และ $4\pm1.96\times8.94$ แล้วนำมาซ้อนกันบนระนาบ จะได้กล่องสี่เหลี่ยม คำถามคือกล่องนี้ครอบคู่ค่าจริง $(\mu_A,\mu_B)$ ด้วยโอกาสเท่าไร

\[\begin{aligned} P(|Z_A|\le1.96,\ |Z_B|\le1.96)&=0.95^2=90.25\%,\\ Z_A^2+Z_B^2&\sim\chi^2_2,\\ P(\chi^2_2\gt r^2)&=e^{-r^2/2}=0.05,\\ r&=\sqrt{-2\ln0.05}\approx2.448. \end{aligned}\]

ให้ $Z_A$ และ $Z_B$ คือความคลาดของค่าประมาณแต่ละตัว วัดเป็นจำนวน SE กล่องครอบคู่ค่าจริงก็ต่อเมื่อทั้งสองช่วงครอบพร้อมกัน สองค่าประมาณอิสระกัน โอกาสจึงคูณกันได้ $0.95\times0.95=0.9025$ ความมั่นใจ 95% ต่อตัวจึงไม่ได้เป็น 95% ของทั้งคู่

บริเวณ 95% ที่ถูกต้องคือวงกลม เพราะ $Z_A^2+Z_B^2$ คือระยะกำลังสองจากคู่ค่าจริง จุดที่อยู่ห่างเท่ากันเรียงกันเป็นวงกลม (ถ้าสองตัวสัมพันธ์กันหรือ SE ต่างกัน วงกลมจะกลายเป็นวงรี) ผลรวมกำลังสองของ normal มาตรฐานอิสระสองตัวมีการแจกแจง chi-square สององศาเสรี เขียนว่า $\chi^2_2$ ซึ่งมีหางเป็น exponential พอดี คือ $P(\chi^2_2\gt x)=e^{-x/2}$ ตั้งหางนี้ให้เท่ากับ 5% แล้วแก้หารัศมี $r$: $r^2=-2\ln0.05\approx5.99$ ได้ $r\approx2.448$ SE

แปลงเป็นจุด รัศมีวงกลมคือ $2.448\times8.94\approx21.9$ จุด ส่วนครึ่งความกว้างของกล่องคือ $1.96\times8.94\approx17.5$ จุด ทั้งสองรูปทรงใหญ่มากเมื่อเทียบกับผลต่าง $8-4=4$ จุดระหว่างสองสินทรัพย์ ข้อมูลห้าปีจึงแทบไม่บอกเลยว่าตัวไหนดีกว่า เมื่อมีหลายสิบสินทรัพย์ ปัญหาเดียวกันนี้คือรากของ ปัญหาการทดสอบหลายครั้ง

ขั้นที่ 8 — ช่วงของค่าเฉลี่ยกับช่วงของปีหน้าเป็นคนละช่วง

ลูกค้าที่อ่านเอกสารเสนอขายมักไม่ได้ถามเรื่องค่าเฉลี่ยระยะยาว แต่ถามว่า “ปีหน้าจะได้เท่าไร” ช่วงที่ตอบคำถามนี้เรียกว่า prediction interval หรือช่วงทำนาย มันต้องกว้างกว่า CI ของค่าเฉลี่ย เพราะความไม่แน่นอนมีสองชั้น:

  • ชั้นแรก ผลปีหน้า $X_{\rm new}$ แกว่งรอบค่าเฉลี่ยจริง $\mu$ ด้วย SD $\sigma$ ต่อให้รู้ $\mu$ แน่ ก็ยังทายปีหน้าได้ไม่ตรง
  • ชั้นที่สอง เราไม่รู้ $\mu$ ต้องใช้ $\bar X$ แทน ซึ่งคลาดได้ด้วย SE $\sigma/\sqrt n$

ปีหน้าอิสระจากข้อมูลที่ผ่านมา ความคลาดสองชั้นจึงอิสระกัน และ variance บวกกันได้ตรง ๆ ตัวเลขใช้ชุดเดิมของขั้นที่ 3 คือ $\bar X=3$, $\sigma=6$ และ $n=4$

\[\begin{aligned} \operatorname{Var}(X_{\rm new}-\bar X)&=\sigma^2+\frac{\sigma^2}{n},\\ 3\pm1.96\times6\sqrt{1+\tfrac14}&=3\pm13.15,\\ {[L,U]}&=[-10.15,\ 16.15]. \end{aligned}\]

SD ของความคลาดรวมคือรากของ variance รวม $\sqrt{\sigma^2+\sigma^2/n}=\sigma\sqrt{1+1/n}=6\sqrt{1.25}\approx6.71$ จุด คูณด้วย 1.96 ได้ครึ่งความกว้าง $1.96\times6.71\approx13.15$ จุด ช่วงทำนายปีหน้าจึงกว้างกว่าช่วงของค่าเฉลี่ย (±5.88) มากกว่าสองเท่า

เรื่องที่สำคัญคือ เมื่อ $n$ โตขึ้น พจน์ $\sigma^2/n$ หายไป แต่ $\sigma^2$ ยังอยู่ ช่วงทำนายจึงไม่หดเหลือจุดเดียว มันหดเข้าหา $\mu\pm1.96\sigma=\mu\pm11.76$ จุดเท่านั้น ต่อให้มีข้อมูลร้อยปี ปีหน้าก็ยังแกว่งได้เท่าเดิม

ช่วงของค่าเฉลี่ย ±5.88 กับช่วงของปีหน้า ±13.15 ตอบคนละคำถาม ถ้าเอาช่วงแรกไปตอบคำถามที่สอง ลูกค้าจะคาดว่าผลตอบแทนนิ่งกว่าความจริงมาก

ความผิดที่ทำให้ตัวเลขดูน่าเชื่อแต่ผิด

อ่าน “ครอบศูนย์” เป็น “ไม่มีฝีมือ”: ช่วง [−2.88%, 8.88%] ปัดตกศูนย์ไม่ได้ก็จริง แต่ก็ปัดตก 8% ไม่ได้เช่นกัน การที่ข้อมูลยังไม่พบหลักฐานว่ามีฝีมือ ไม่ได้เป็นหลักฐานว่าไม่มีฝีมือ

ใช้ 1.96 กับ SD ที่คำนวณจากข้อมูลแค่สี่ปี: ช่วงที่ผิดคือ $3\pm1.96\times3=[-2.88\%,\ 8.88\%]$ ซึ่งติดป้าย 95% แต่ครอบจริงราว 85.5% เท่านั้น (พื้นที่ของ Student $t$ ที่ df 3 ระหว่าง ±1.96 ตามรูป Student t ด้านบน) ช่วงที่ถูกคือ $3\pm3.182\times3=[-6.55\%,\ 12.55\%]$

เปิดดูทุกปีแล้วหยุดเมื่อพ้นศูนย์: การเปิดดูแต่ละครั้งคือโอกาสพลาดอีกครั้ง coverage ของทั้งกระบวนการจึงต่ำกว่า 95% ถ้าจะดูหลายครั้ง ต้องใช้วิธีที่ออกแบบมาสำหรับการดูต่อเนื่องโดยเฉพาะ

ข้อมูลแต่ละปีไม่อิสระกัน: NAV (มูลค่าทรัพย์สินสุทธิต่อหน่วยของกองทุน) ของกองทุนที่ถือสินทรัพย์ขายยาก มักเรียบเกินจริง เพราะสินทรัพย์เหล่านั้นไม่มีราคาตลาดทุกวัน ต้องประเมินราคาเอาเอง ปีติดกันจึงสัมพันธ์กัน และ SE จริงใหญ่กว่า $\sigma/\sqrt n$ (ดูตัวคูณใน central limit theorem) ช่วงจากสูตรในหน้านี้จึงแคบเกินจริง ต้องใช้ SE ที่ทนต่อความสัมพันธ์ระหว่างปี เช่น HAC (Newey–West) หรือ block bootstrap

ช่วงของผู้ชนะที่ถูกคัดมา: ถ้ากองทุนนี้ถูกเลือกมาเพราะผลงานดีที่สุดจาก 200 กอง ค่าเฉลี่ยที่เห็นสูงส่วนหนึ่งเพราะโชค ช่วง 95% ธรรมดาจึงครอบค่าจริงน้อยกว่า 95% มาก ดู ปัญหาการทดสอบหลายครั้ง

ใช้ทำอะไรบนโต๊ะจริง

เวลาเขียนช่วงลงรายงาน ให้ใส่ข้อมูลครบพอที่คนอ่านจะคำนวณซ้ำได้เอง:

  • สิ่งที่ประมาณและหน่วย เช่น active return เฉลี่ย % ต่อปี
  • ช่วงเวลา และจำนวนข้อมูลที่อิสระกัน เช่น สี่ปี (ไม่ใช่ 48 เดือน)
  • ค่าประมาณ และ SE
  • ใช้ตัวคูณ $z$ หรือ $t$ และระดับความมั่นใจ
  • ข้อสมมติ เช่น แต่ละปีเป็น normal และอิสระกัน

ฝ่ายความเสี่ยงควรถามสองข้อเสมอ ข้อแรก ช่วงนี้เป็นช่วงของค่าเฉลี่ยหรือช่วงทำนายปีหน้า ข้อสอง ถ้ากองทุนนี้ถูกเลือกมาจากหลายกอง ได้ปรับผลของการเลือกแล้วหรือยัง ช่วงของ alpha (ผลตอบแทนส่วนที่ตลาดอธิบายไม่ได้) ใน CAPM และช่วงของ factor exposure (ความไวต่อปัจจัยเสี่ยงแต่ละตัว) ใน multi-factor models ก็ใช้หลักเดียวกันนี้ทุกตัว

โจทย์ตรวจความเข้าใจ

1. เพื่อนร่วมทีมเห็นช่วง 95% ของกองทุนตอนต้นหน้า คือ [−2.88%, 8.88%] แล้วสรุปว่า “ช่วงครอบศูนย์ แปลว่ากองทุนไม่มีฝีมือ” ข้อสรุปนี้ถูกไหม และค่าเฉลี่ยจริงค่าใดบ้างที่ข้อมูลยังปัดตกไม่ได้

เฉลย

ไม่ถูก ช่วงครอบศูนย์แปลแค่ว่าข้อมูลยังปัดตกค่าศูนย์ไม่ได้ ทุกค่าในช่วงก็ยังปัดตกไม่ได้เช่นกัน คือทุกค่าตั้งแต่ −2.88% ถึง 8.88% ซึ่งรวมทั้งกองทุนที่แพ้ดัชนี และกองทุนที่ชนะดัชนีปีละเกือบ 9%

2. ฝ่ายความเสี่ยงอยากได้ช่วงที่มั่นใจกว่าเดิม ใช้กองทุนเดิม: ค่าเฉลี่ย $\bar X=3\%$ รู้ SD $\sigma=6\%$ และ $n=4$ ปี จึงมี SE 3 จุด ถ้าเปลี่ยนจากระดับ 95% เป็น 99% (ตัวคูณ 2.576 จากขั้นที่ 1) จะได้ช่วงอะไร และช่วงกว้างขึ้นกี่เปอร์เซ็นต์

เฉลย

คูณ SE ด้วยตัวคูณใหม่ แล้วเทียบกับครึ่งความกว้างเดิม 5.88:

\[\begin{aligned}2.576\times3&=7.728,\\3\pm7.728&=[-4.728,\ 10.728],\\7.728/5.88-1&\approx31.4\%.\end{aligned}\]

ช่วง 99% คือ [−4.728%, 10.728%] กว้างขึ้นราว 31.4% ทั้งที่ไม่มีข้อมูลใหม่เลย ความมั่นใจที่สูงขึ้นจ่ายด้วยความกว้าง

3. ฝ่ายขายอยากให้ช่วงแคบลงครึ่งหนึ่ง จากครึ่งความกว้าง 5.88 เหลือ 2.94 จุด โดยยังรู้ SD 6% และใช้ระดับ 95% ต้องมีข้อมูลกี่ปีที่อิสระกัน มีคนเสนอว่า “ใช้ข้อมูลรายเดือนของสี่ปีเดิมแทน ได้ตัวเลขตั้ง 48 ตัว” จะได้ผลเท่ากันไหม

เฉลย

ตั้งครึ่งความกว้างให้เท่ากับ 2.94 แล้วแก้หา $n$:

\[\begin{aligned}1.96\times6/\sqrt n&=2.94,\\\sqrt n&=11.76/2.94=4,\\n&=16.\end{aligned}\]

ต้อง 16 ปี ไม่ใช่แปดปี เพราะความกว้างหดตาม $1/\sqrt n$ ช่วงแคบลงครึ่งหนึ่งต้องใช้ข้อมูลสี่เท่า

ข้อมูลรายเดือนของสี่ปีเดิมไม่ช่วย ลองคำนวณดู variance รายปีเท่ากับ 12 เท่าของ variance รายเดือน (เดือนอิสระกัน) SD รายเดือนจึงเป็น $6/\sqrt{12}$ ค่าเฉลี่ยของ 48 เดือนมี SE $\dfrac{6/\sqrt{12}}{\sqrt{48}}$ ต่อเดือน และค่าเฉลี่ยรายปีคือค่าเฉลี่ยรายเดือนคูณ 12:

\[\begin{aligned}\mathrm{SE}&=12\times\frac{6/\sqrt{12}}{\sqrt{48}}\\&=\frac{72}{\sqrt{12\times48}}=\frac{72}{24}=3\end{aligned}\]

SE ยังเป็น 3 จุดเท่าเดิม เพราะค่าเฉลี่ยรายปีจากข้อมูลรายเดือนขึ้นกับจุดต้นและจุดปลายของสี่ปีนั้นเท่านั้น การหั่นเป็นเดือนไม่ได้เพิ่มข้อมูลเรื่องค่าเฉลี่ย (เหตุผลเดียวกับ SE ของ drift ในหน้า estimator และ standard error)

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
// Two-sided Student-t critical value: substitute x = sqrt(df) tan(theta),
// so the density integral becomes the integral of cos(theta)^(df-1).
function integral(df, upper) {
  const steps = 2000, h = upper / steps, f = th => Math.cos(th) ** (df - 1);
  let s = f(0) + f(upper);
  for (let i = 1; i < steps; i++) s += (i % 2 ? 4 : 2) * f(i * h);
  return h * s / 3;
}
function tCrit(df, level = 0.95) {
  const total = integral(df, Math.PI / 2);
  let lo = 0, hi = Math.PI / 2;
  for (let i = 0; i < 60; i++) {
    const mid = (lo + hi) / 2;
    if (integral(df, mid) / total < level) lo = mid; else hi = mid;
  }
  return Math.sqrt(df) * Math.tan((lo + hi) / 2);
}
const mean = 3, sd = 6;
const zInterval = n => [mean - 1.96 * sd / Math.sqrt(n), mean + 1.96 * sd / Math.sqrt(n)];
const tInterval = n => { const h = tCrit(n - 1) * sd / Math.sqrt(n); return [mean - h, mean + h]; };
let firstT = 2;
while (tInterval(firstT)[0] <= 0) firstT++;
// Coverage of 25 simulated four-year histories (true mean 3, sd 6, known sd).
let seed = 3;
const u = () => { seed = (Math.imul(1664525, seed) + 1013904223) >>> 0; return (seed + 0.5) / 4294967296; };
const normal = () => Math.sqrt(-2 * Math.log(u())) * Math.cos(2 * Math.PI * u());
let covered = 0;
for (let r = 0; r < 25; r++) {
  let s = 0;
  for (let i = 0; i < 4; i++) s += mean + sd * normal();
  if (Math.abs(s / 4 - mean) <= 5.88) covered++;
}
const t3cdf = t => 0.5 + (t / (Math.sqrt(3) * (1 + t * t / 3)) + Math.atan(t / Math.sqrt(3))) / Math.PI;
const result = {
  z4: zInterval(4), z16: zInterval(16), z99: [mean - 2.576 * 3, mean + 2.576 * 3],
  yearsZ: (1.96 * sd / mean) ** 2, yearsZquarter: (1.96 / 0.25) ** 2,
  t3: tCrit(3), t15: tCrit(15), t29: tCrit(29), t4: tInterval(4), firstT,
  t3OutsideZ: 2 * (1 - t3cdf(1.96)),
  coverageCountSD: Math.sqrt(100 * 0.95 * 0.05), covered,
  boxJoint: 0.95 ** 2, circleRadius: Math.sqrt(-2 * Math.log(0.05)),
  seFiveYears: 20 / Math.sqrt(5),
  prediction: [mean - 1.96 * sd * Math.sqrt(1.25), mean + 1.96 * sd * Math.sqrt(1.25)]
};
console.log(JSON.stringify(result, null, 1));

โค้ดนี้คำนวณตัวเลขหลักของหน้านี้ซ้ำ ตัวคูณ Student $t$ หาจากพื้นที่ใต้โค้งโดยตรง ไม่ได้เปิดตาราง ควรได้ z4 [−2.88, 8.88], t3 ราว 3.182, firstT 18 (ปีแรกที่ช่วงแบบ Student $t$ พ้นศูนย์), covered 23 (จาก 25 ช่วงในรูปตอนต้นหน้า), t3OutsideZ ราว 0.145, circleRadius ราว 2.448 และ prediction ราว [−10.15, 16.15]

สิ่งที่ควรตอบได้หลังอ่าน

  • ช่วงคือ estimate ± ตัวคูณ × SE และตัวคูณมาจากพื้นที่ใต้โค้งการแจกแจงที่ถูกต้อง: 1.96 สำหรับ normal และ 3.182 สำหรับ Student $t$ ที่ df 3
  • กองทุนสี่ปีที่ค่าเฉลี่ย 3% และ SD 6% ได้ช่วง [−2.88%, 8.88%] ถ้ารู้ SD แน่ และ [−6.55%, 12.55%] ถ้า SD ก็คำนวณจากสี่ปีนั้น ทั้งสองช่วงครอบศูนย์
  • ช่วงหดตาม $1/\sqrt n$ อยากได้ช่วงแคบลงครึ่งหนึ่งต้องใช้ข้อมูลสี่เท่า
  • 95% คืออัตราที่วิธีสร้างช่วงครอบค่าจริงเมื่อใช้ซ้ำ ไม่ใช่โอกาสที่ช่วงหนึ่งช่วงที่ได้มาแล้วครอบค่าจริง
  • ช่วง 95% สองช่วงที่วาดแยกกันครอบคู่ค่าจริงพร้อมกันเพียง $0.95^2=90.25\%$ บริเวณ 95% ที่ถูกต้องคือวงกลมรัศมี 2.448 SE
  • ช่วงทำนายปีหน้า [−10.15%, 16.15%] กว้างกว่าช่วงของค่าเฉลี่ยมาก และไม่หดเหลือจุดเดียวแม้มีข้อมูลมากแค่ไหน

ช่วงบอกว่าค่าใดยังเข้ากับข้อมูลได้ หน้าถัดไป การทดสอบสมมติฐานและการอนุมาน Sharpe ratio จะถามกลับด้าน: ถ้าค่าจริงเป็นศูนย์ ข้อมูลที่เห็นหายากแค่ไหน แล้วใช้คำตอบนั้นตัดสิน backtest (การทดลองกลยุทธ์กับข้อมูลย้อนหลัง) ที่มี Sharpe ratio 1.20 โดย Sharpe ratio คือผลตอบแทนที่ได้เกินเงินฝาก หารด้วยความผันผวน
