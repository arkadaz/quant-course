9.5 Strange Properties of Brownian Paths

ยิ่งซูม เส้นทาง Brownian ยิ่งยาวไม่รู้จบ และไม่มีความชันให้วัด แต่ผลรวมของการขยับยกกำลังสองกลับนิ่ง และเท่ากับเวลาที่ผ่านไปพอดี ตัวเลขนี้คือสิ่งที่ใช้วัดความผันผวนของราคาจริง

นักวิเคราะห์คนหนึ่งอยากรู้ว่าวันนี้ราคา SPY แกว่งแรงแค่ไหน SPY คือกองทุนที่ซื้อขายเหมือนหุ้น และวิ่งตามดัชนี S&P 500 ของหุ้นใหญ่ 500 ตัวในสหรัฐ ก่อนใช้ข้อมูลจริง เขาลองกับวันจำลอง คือให้คอมพิวเตอร์สุ่มราคาทุกวินาทีตลอดหนึ่งวันทำการ ข้อดีของวันจำลองคือเรารู้คำตอบที่ถูกล่วงหน้า

ของที่ใส่ลงในการจำลอง (ตัวเลขสมมติ):

  • ราคาตอนเปิดตลาด $S_0=\$520$
  • ตลาดเปิดวันละ 6.5 ชั่วโมง คือ $6.5\times3{,}600=23{,}400$ วินาที
  • ความผันผวนรายวัน 1.2% คือ SD (standard deviation: ขนาดการแกว่งตามปกติ) ของการเปลี่ยนราคาทั้งวัน คิดเป็นดอลลาร์ได้ $0.012\times520=\$6.24$

เขาอยากรู้ว่าราคา “เดินทาง” ไกลแค่ไหนระหว่างวัน จึงแบ่งวันเป็นแท่ง แท่งคือช่วงเวลาสั้น ๆ ที่ยาวเท่ากัน เช่นแท่งละ 5 นาที ในแท่งที่ $i$ ราคาขยับไป $\Delta S_i$ ดอลลาร์ เขารวมขนาดการขยับของทุกแท่ง โดยไม่สนว่าขึ้นหรือลง ได้ระยะทาง $\sum_i|\Delta S_i|$ วัดเส้นทางเดียวกันด้วยแท่งสามขนาด ได้ตัวเลขนี้ (มาจากโค้ดท้ายหน้า และตาราง “ลองจริง” ด้านล่างแสดงครบทุกแถว):

เขาคิดว่ายิ่งแท่งสั้น ตัวเลขยิ่งเข้าใกล้ระยะทางจริง เหมือนวัดความยาวเส้นโค้งด้วยไม้บรรทัดที่สั้นลงเรื่อย ๆ ระยะทางจริงคือเท่าไร และเขาควรรายงานตัวเลขอะไรเป็นความผันผวนของวันนี้?

ลองตอบก่อนเปิดเฉลย

ไม่มีระยะทางจริงให้เข้าใกล้ หน้านี้จะพิสูจน์ว่าระยะทางที่วัดได้โตตามรากที่สองของจำนวนแท่ง จาก 5 นาทีเป็น 1 วินาที จำนวนแท่งเพิ่ม $23{,}400/78=300$ เท่า ระยะทางจึงควรโตราว $\sqrt{300}\approx17.3$ เท่า ของจริงโต $758.69/46.28\approx16.4$ เท่า และถ้าซอยต่อ ก็โตต่อไปไม่สิ้นสุด

ตัวเลขที่นิ่งคือรากของผลรวมการขยับยกกำลังสอง $\sqrt{\sum_i(\Delta S_i)^2}$ บนเส้นทางเดียวกันได้ \$6.54, \$6.46 และ \$6.23 ตามลำดับ ซึ่งเข้าใกล้ \$6.24 ที่ใส่ไว้ตอนจำลอง คิดเป็น $6.24/520=1.2\%$ ของราคา ตัวเลขนี้เรียกว่า realized volatility คือความผันผวนที่วัดจากการขยับที่เกิดขึ้นจริงในวันนั้น และเป็นตัวเลขที่ควรรายงาน

ภาพรวมก่อนลงสูตร

เส้นโค้งที่เคยเรียนใน calculus มีนิสัยหนึ่ง: ซูมเข้าไปใกล้พอ มันจะดูเป็นเส้นตรง เส้นตรงมีความชันชัดเจน เราจึงหาอนุพันธ์ได้ และวัดความยาวได้ เส้นทาง Brownian ไม่เป็นแบบนั้น ซูมเข้าไปกี่ชั้นก็ยังขรุขระเท่าเดิม

หน้านี้ดูนิสัยแปลก ๆ สามข้อของเส้นทาง Brownian:

  • ความชันไม่นิ่ง ยิ่งวัดในช่วงเวลาสั้น ความชันยิ่งเหวี่ยงแรง
  • ความยาวไม่จำกัด ยิ่งซอยช่วงเวลาละเอียด ความยาวยิ่งโต
  • ผลรวมของการขยับยกกำลังสองกลับนิ่ง และเท่ากับเวลาที่ผ่านไปพอดี ปริมาณนี้เรียกว่า quadratic variation

ทำไมต้องสนใจ เพราะสามข้อนี้คือเหตุผลที่ calculus ธรรมดาใช้กับราคาไม่ได้ และข้อที่สามคือที่มาของ realized volatility ที่คนดูแลความเสี่ยงดูทุกวัน ทุกข้อพิสูจน์ได้จากกฎรากที่สองในกติกาสามข้อของ Brownian motion กฎนี้บอกว่าการขยับในช่วงเวลายาว $\Delta t$ มี SD เท่ากับ $\sqrt{\Delta t}$ ไม่ใช่ $\Delta t$

ลำดับของหน้า: เริ่มจากเส้นเรียบเพื่อใช้เทียบ แล้วพิสูจน์ทีละข้อ จากนั้นลองซอยแท่งบนวันจำลองของ SPY ใช้ผลรวมกำลังสองวัด realized volatility และดูว่าทำไมวัดถี่เกินไปกลับได้ตัวเลขเพี้ยน หน้านี้ปิดด้วยนิสัยที่ขัดสัญชาตญาณที่สุด: เส้นทางกลับมาถึงระดับที่ตั้งไว้แน่นอน แต่เวลารอเฉลี่ยยาวไม่สิ้นสุด

รูปด้านล่างซูมเข้าไปในเส้นทางเดียวสองชั้น ทุกชั้นยืดแกนเวลา 16 เท่า แต่ยืดแกนตั้งแค่ $\sqrt{16}=4$ เท่า ทำไมแค่ 4 เท่า? เพราะในช่วงเวลาที่สั้นลง 16 เท่า การขยับเล็กลงแค่ 4 เท่าตามกฎรากที่สอง นี่คือกฎยืดเวลาแล้วบีบความสูงของ standard Brownian motion

ศัพท์ที่ใช้ในหัวข้อนี้
SBM (standard Brownian motion)
เส้นทางสุ่ม $W_t$ ที่เริ่มที่ 0 การขยับในช่วงเวลายาว $\Delta t$ เป็น Normal ที่มีค่าเฉลี่ย 0 และ variance $\Delta t$ และช่วงที่ไม่ทับกันขยับอิสระจากกัน ดูรายละเอียดในstandard Brownian motion
แท่ง (bar)
ช่วงเวลาสั้น ๆ ที่ยาวเท่ากัน ใช้อ่านราคา เช่นแท่ง 5 นาที การขยับของแท่งคือราคาตอนจบแท่งลบราคาตอนเริ่มแท่ง วันที่ตลาดเปิด 390 นาทีมีแท่ง 5 นาที $390/5=78$ แท่ง
Quadratic variation
เอาการขยับของทุกท่อนมายกกำลังสองแล้วบวกกัน จากนั้นซอยท่อนให้สั้นลงเรื่อย ๆ ค่าที่ผลรวมนี้เข้าใกล้คือ quadratic variation สำหรับ SBM บนช่วงยาว $T$ ค่านั้นคือ $T$ พอดี มันวัดว่าเส้นทางขรุขระแค่ไหน และเป็นฐานของ Itô's lemma
Total variation
ผลรวมของขนาดการขยับ $\sum|\Delta W|$ โดยไม่สนเครื่องหมาย คือระยะทางขึ้นลงทั้งหมดที่เส้นทางเดิน เส้นเรียบให้ค่าจำกัด เส้นทาง Brownian ให้ค่าที่โตไม่สิ้นสุดเมื่อซอยละเอียดขึ้น
Nowhere differentiable
หาอนุพันธ์ (ความชัน) ไม่ได้ที่จุดใดเลย เส้นทาง Brownian เกือบทุกเส้นเป็นแบบนี้ ในแบบจำลองนี้ “ความเร็วของราคา ณ ขณะหนึ่ง” จึงไม่มีความหมาย
Log return
ผลตอบแทนของแท่งหนึ่งที่วัดด้วย log: $r_i=\ln(S_i/S_{i-1})$ เมื่อการขยับเล็ก มันเกือบเท่ากับสัดส่วนที่ราคาเปลี่ยน เช่นราคาขึ้นจาก \$520 เป็น \$520.52 ได้ $\ln(520.52/520)\approx0.1\%$
Realized variance (RV)
ผลรวมของ log return ระหว่างวันยกกำลังสอง ใช้ประมาณ variance ที่เกิดขึ้นจริงของวันนั้น รากที่สองของ RV คือ realized volatility (การวัดกับข้อมูลจริงอยู่ในหน้าrealized volatility)
Drift
ผลตอบแทนเฉลี่ยต่อปี คือทิศที่ราคาค่อย ๆ ไหลไปโดยเฉลี่ย แยกจากการแกว่งแบบสุ่ม
Bid, ask และ spread
bid คือราคาสูงสุดที่มีคนเสนอซื้ออยู่ ask คือราคาต่ำสุดที่มีคนเสนอขายอยู่ spread คือ ask ลบ bid ราคาที่ซื้อขายจริงจึงเด้งไปมาระหว่างสองราคานี้
Microstructure noise
ความคลาดเล็ก ๆ ของราคาที่ซื้อขายจริงรอบราคาที่แท้จริง เช่นราคาที่เด้งไปมาระหว่าง bid กับ ask ขนาดราวครึ่งหนึ่งของ spread ยิ่งอ่านราคาถี่ ส่วนนี้ยิ่งถูกนับเป็นความผันผวนปลอม
Hitting time และ reflection principle
hitting time คือเวลาแรกที่เส้นทางแตะระดับที่กำหนด ใช้ตอบคำถามแบบ “ต้องรอนานแค่ไหนกว่าราคาจะกลับมา” reflection principle คือการพลิกส่วนของเส้นทางหลังแตะครั้งแรกให้กลับหัวรอบระดับนั้น ทำให้คำนวณโอกาสแตะได้ในบรรทัดเดียว

ขั้นที่ 1 — เส้นเรียบก่อน: ความยาวนิ่ง ผลรวมกำลังสองหายไป

จะบอกว่า Brownian แปลก ต้องรู้ก่อนว่าเส้นปกติทำตัวอย่างไรเมื่อซอยช่วงเวลา ขั้นนี้จึงดูเส้นเรียบก่อน ให้ $f$ เป็นเส้นที่หาความชันได้ทุกจุด และความชันไม่เกิน $M$ ซอยช่วงเวลายาว $T$ เป็น $n$ ท่อนเท่ากัน ท่อนละ $\Delta t=T/n$ ให้ $\Delta f_i$ คือการขยับของ $f$ ในท่อนที่ $i$

เราดูผลรวมสองแบบ แบบแรกคือผลรวมขนาดการขยับ ซึ่งก็คือความยาวแนวตั้งของเส้น แบบที่สองคือผลรวมของการขยับยกกำลังสอง

\[ \begin{aligned} \Delta f_i&\approx f'(t_i)\,\Delta t,\\ \sum_{i=1}^n|\Delta f_i|&\approx\sum_{i=1}^n|f'(t_i)|\,\Delta t\le MT,\\ \sum_{i=1}^n(\Delta f_i)^2&\approx\sum_{i=1}^n f'(t_i)^2\,\Delta t^2\\ &\le M^2\,T\,\Delta t\ \to\ 0. \end{aligned} \]

ทุกอย่างมาจากความหมายของความชัน: ในท่อนสั้น ๆ เส้นเรียบขยับประมาณ “ความชันคูณเวลา” ผลรวมขนาดการขยับจึงเป็นผลรวมแบบ Riemann ซึ่งเข้าใกล้ความยาวจริงของเส้น และไม่เกิน $MT$ ไม่ว่าจะซอยกี่ท่อน

จุดสำคัญอยู่ที่ผลรวมกำลังสอง พอยกกำลังสอง $\Delta t$ ก็กลายเป็น $\Delta t^2$ บวก $n$ ท่อนแล้วยังเหลือ $\Delta t$ ค้างอยู่หนึ่งตัว เพราะ $n\,\Delta t^2=T\,\Delta t$ ซอยละเอียดขึ้น $\Delta t$ เข้าใกล้ศูนย์ ผลรวมกำลังสองจึงหายไป

ลองกับเส้นตรงที่ราคาขึ้นจาก \$520 ถึง \$526.24 ในหนึ่งวัน ทุกท่อนขยับเท่ากัน คือ $6.24/n$ ดอลลาร์ ใช้ $n=78$ (แท่ง 5 นาที) และ $n=23{,}400$ (ทุกวินาที):

\[ \begin{aligned} \sum_{i=1}^n|\Delta f_i|&=n\times\frac{6.24}{n}=\$6.24,\\ \sum_{i=1}^n(\Delta f_i)^2&=n\times\Big(\frac{6.24}{n}\Big)^2=\frac{38.94}{n},\\ n=78&:\ 38.94/78\approx0.50,\\ n=23{,}400&:\ 38.94/23{,}400\approx0.0017. \end{aligned} \]

ความยาวเท่ากับ \$6.24 ทุก grid แต่ผลรวมกำลังสองหดลงตาม $1/n$ จนเกือบเป็นศูนย์ นี่คือนิสัยของเส้นเรียบทุกเส้น

ขั้นที่ 2 — ความชันของ Brownian ระเบิดเมื่อซูม

ตอนนี้ถามคำถามแบบ calculus กับเส้นทาง Brownian ตรง ๆ: ถ้าวัดความชันเฉลี่ยในช่วงสั้น ๆ ยาว $h$ ตัวเลขนิ่งลงไหมเมื่อ $h$ หดลง ความชันเฉลี่ยคือการขยับหารด้วยเวลา $(W_{t+h}-W_t)/h$

การขยับของ SBM ในช่วงยาว $h$ มี variance เท่ากับ $h$ ส่วนตัวหาร $h$ เป็นค่าคงที่ จึงดึงออกจาก variance ได้ในรูป $1/h^2$ เพราะ $\operatorname{Var}(aX)=a^2\operatorname{Var}(X)$

\[ \begin{aligned} \operatorname{Var}\Big(\frac{W_{t+h}-W_t}{h}\Big)&=\frac{h}{h^2}=\frac1h,\\ \operatorname{SD}&=\frac{1}{\sqrt h},\\ h=10^{-2},10^{-4},10^{-6}&:\ 10,\ 100,\ 1{,}000,\\ \frac{6.24}{\sqrt{1/390}}&=6.24\sqrt{390}\approx123.2,\\ \frac{6.24}{\sqrt{1/23{,}400}}&=6.24\sqrt{23{,}400}\approx954.5. \end{aligned} \]

เส้นเรียบทำตรงข้าม: ซูมเข้าไป ความชันนิ่งลงเป็นตัวเลขตัวเดียว ส่วนเส้นทาง Brownian ซูมเข้าไปร้อยเท่า ($h$ เล็กลง 100 เท่า) ความชันกลับเหวี่ยงแรงขึ้น $\sqrt{100}=10$ เท่า และไม่เข้าใกล้ตัวเลขใดเลย

แปลเป็น SPY ในวันจำลอง: การขยับทั้งวันมี SD \$6.24 ถ้านับเวลาเป็นวัน SD ของความชันคือ $6.24/\sqrt h$ ดอลลาร์ต่อวัน แท่ง 1 นาทียาว $h=1/390$ วัน เพราะวันหนึ่งมี 390 นาที ความชันจึงเหวี่ยงระดับ \$123 ต่อวัน แท่ง 1 วินาทียาว $h=1/23{,}400$ วัน ความชันเหวี่ยงระดับ \$955 ต่อวัน ทั้งที่ราคาทั้งวันขยับแค่ราว \$6

ต้นเหตุคือกฎรากที่สอง เมื่อ $h$ หดลง การขยับหดลงแค่ตาม $\sqrt h$ แต่ตัวหารหดลงตาม $h$ เต็ม ๆ อัตราส่วนจึงบานขึ้นเรื่อย ๆ และเพราะยืดเวลาแล้วบีบความสูงแล้วได้ SBM ตัวเดิม ความชันที่ระเบิดจึงเกิดที่ทุกระดับการซูม ตรงกับรูปซูมสองชั้นด้านบน ข้อนี้ยังเป็นแค่สัญชาตญาณ การพิสูจน์เต็มว่าไม่มีความชันที่จุดใดเลยยากกว่านี้มาก ขั้นที่ 5 จะให้เหตุผลที่แรงขึ้นอีกขั้นด้วยการนับกำลังของ $n$

ขั้นที่ 3 — สี่ก้าวด้วยมือ: ผลรวมหักกันได้ ผลรวมกำลังสองหักกันไม่ได้

สองขั้นแรกบอกว่าความชันใช้ไม่ได้กับ Brownian ขั้นนี้เริ่มดูของที่ใช้ได้ คือผลรวมกำลังสอง ก่อนพิสูจน์ ลองกรณีเล็กที่นับด้วยมือได้: โยนเหรียญสี่ครั้งในช่วงเวลา $T=1$ แต่ละท่อนยาว $\Delta t=1/4$ ออกหัวก้าวขึ้น ออกก้อยก้าวลง ขนาดก้าวตามกฎรากที่สองคือ $\sqrt{\Delta t}=\sqrt{1/4}=0.5$

ข้างล่างดูสามเส้นทาง เครื่องหมาย $+$ คือก้าวขึ้น และ $-$ คือก้าวลง

\[ \begin{aligned} \Delta t&=\tfrac14,\quad\Delta W=\pm0.5,\quad(\Delta W)^2=0.25,\\ {+}{-}{+}{-}&:\ \textstyle\sum\Delta W=0,\ \ \sum(\Delta W)^2=1,\\ {+}{+}{+}{+}&:\ \textstyle\sum\Delta W=2,\ \ \sum(\Delta W)^2=1,\\ {+}{+}{-}{+}&:\ \textstyle\sum\Delta W=1,\ \ \sum(\Delta W)^2=1. \end{aligned} \]

สามเส้นทางจบคนละที่ คือ 0, 2 และ 1 เพราะก้าวขึ้นกับก้าวลงหักล้างกันได้ แต่ผลรวมกำลังสองเท่ากับ 1 ทุกเส้น เพราะการยกกำลังสองลบเครื่องหมายทิ้ง ทุกก้าวจึงให้ 0.25 เท่ากัน รวมสี่ก้าวได้ $4\times0.25=1=T$ นี่คือปริมาณที่ไม่สุ่ม ทั้งที่อยู่บนเส้นทางที่สุ่ม

ก้าวของ Brownian จริงไม่ได้เป็น $\pm0.5$ พอดี ขนาดก้าวสุ่มไปรอบ ๆ แต่กำลังสองของก้าวยังมีค่าเฉลี่ย $\Delta t$ เท่าเดิม ผลรวมกำลังสองจึงแกว่งรอบ $T$ เล็กน้อย ขั้นถัดไปพิสูจน์ว่ามันแกว่งน้อยลงเรื่อย ๆ เมื่อซอยละเอียดขึ้น

ขั้นที่ 4 — ผลรวมกำลังสองเฉลี่ยเท่ากับ $T$ และแทบไม่สุ่มเมื่อซอยละเอียด

ตอนนี้ทำแบบเดียวกันกับ Brownian จริง ตั้งชื่อ $Q_n$ ให้ผลรวมของการขยับยกกำลังสองบน $n$ ท่อนเท่ากัน แต่ละท่อนยาว $\Delta t=T/n$ เราอยากรู้สองอย่าง: $Q_n$ มีค่าเฉลี่ยเท่าไร และมันแกว่งรอบค่าเฉลี่ยแค่ไหน ซึ่งวัดด้วย variance

ค่าเฉลี่ยใช้แค่สูตรลัด $\mathbb E[X^2]=\operatorname{Var}(X)+(\mathbb E[X])^2$ ส่วน variance ต้องเขียนการขยับเป็น $\Delta W_i=\sqrt{\Delta t}\,Z_i$ เมื่อ $Z_i$ เป็น Normal มาตรฐาน แล้วใช้ $\mathbb E[Z^4]=3$ ค่านี้หาได้ด้วยการอินทิเกรตทีละส่วน โดยใช้ $\varphi'(z)=-z\varphi(z)$ ของdensity ของ Normal ($\varphi$ คือ density ของ Normal มาตรฐาน)

\[ \begin{aligned} Q_n&:=\sum_{i=1}^{n}(\Delta W_i)^2,\\ \mathbb E\big[(\Delta W_i)^2\big]&=\operatorname{Var}(\Delta W_i)+0=\Delta t,\\ \mathbb E[Q_n]&=n\,\Delta t=T,\\ \mathbb E[Z^4]&=\big[-z^3\varphi\big]_{-\infty}^{\infty}+3\int z^2\varphi\,dz=3,\\ \operatorname{Var}\big((\Delta W_i)^2\big)&=3\Delta t^2-\Delta t^2=2\Delta t^2,\\ \operatorname{Var}(Q_n)&=n\cdot2\Big(\frac Tn\Big)^2=\frac{2T^2}{n}. \end{aligned} \]

ค่าเฉลี่ยของการขยับเป็นศูนย์ ค่าเฉลี่ยของกำลังสองจึงเท่ากับ variance ซึ่งเท่ากับความยาวท่อน $\Delta t$ พอดี บวก $n$ ท่อนได้ $n\times T/n=T$ ตัว $n$ หักกันหมด

เทียบกับเส้นเรียบ: กำลังสองของการขยับในหนึ่งท่อนของเส้นเรียบมีขนาด $\Delta t^2$ ส่วนของ Brownian มีขนาด $\Delta t$ ต่างกันแค่หนึ่งกำลัง และหนึ่งกำลังนี้คือความต่างทั้งหมดระหว่างผลรวมที่หายไปกับผลรวมที่เหลือ $T$

ค่า $\mathbb E[Z^4]=3$ มาจากการเขียน $z^4\varphi$ เป็น $z^3$ คูณ $z\varphi$ แล้วแทน $z\varphi=-\varphi'$ และอินทิเกรตทีละส่วน พจน์ที่ขอบเป็นศูนย์ เพราะ $\varphi$ ลดลงเร็วกว่าที่ $z^3$ โต ที่เหลือคือ $3\int z^2\varphi\,dz=3\times1$ เพราะ $\int z^2\varphi\,dz=\operatorname{Var}(Z)=1$

variance ของ $Q_n$ บวกกันทีละท่อนได้ เพราะท่อนที่ไม่ทับกันขยับอิสระกัน จังหวะชี้ขาดคือ $n$ ท่อนคูณ $1/n^2$ เหลือ $1/n$ ซอยยิ่งละเอียด variance ยิ่งเล็ก ที่ $T=1$ ได้ $\operatorname{SD}(Q_{100})=\sqrt{2/100}\approx0.141$ และ $\operatorname{SD}(Q_{10{,}000})=\sqrt{2/10{,}000}\approx0.0141$ ของที่สร้างจากความสุ่มล้วน ๆ กลับให้ตัวเลขที่แทบรู้ล่วงหน้า

ขั้นที่ 5 — กำลังเท่าไรจึงนิ่ง: ความยาวอนันต์ กำลังสามหาย กำลังสองพอดี

กำลังสองให้ $T$ แล้วกำลังอื่นล่ะ? ขั้นนี้ใช้กำลัง $p$ ใด ๆ แล้วนับว่าเหลือ $n$ อยู่กี่ตัว เขียนการขยับเป็น $\Delta W_i=\sqrt{\Delta t}\,Z_i$ จะได้ $|\Delta W_i|^p=\Delta t^{p/2}|Z_i|^p$ ให้ $V_n=\sum_i|\Delta W_i|$ คือความยาว ซึ่งเป็นกรณี $p=1$

ค่าเฉลี่ยที่ต้องใช้มีสองตัว density ของ Normal สมมาตร จึงเขียน $\mathbb E|Z|^p=\tfrac{2}{\sqrt{2\pi}}\int_0^\infty z^pe^{-z^2/2}dz$ ได้ แทน $u=z^2/2$ ได้อินทิกรัลเท่ากับ 1 เมื่อ $p=1$ และเท่ากับ 2 เมื่อ $p=3$ ดังนั้น

  • $\mathbb E|Z|=\sqrt{2/\pi}\approx0.798$ คือขนาดการขยับเฉลี่ยของ Normal มาตรฐาน
  • $\mathbb E|Z|^3=2\sqrt{2/\pi}\approx1.596$
\[ \begin{aligned} \mathbb E\sum_{i=1}^n|\Delta W_i|^p&=n\Big(\frac Tn\Big)^{p/2}\mathbb E|Z|^p\\ &=T^{p/2}\,\mathbb E|Z|^p\,n^{1-p/2},\\ p=1:\ \mathbb E[V_n]&=\sqrt{2T/\pi}\,\sqrt n\ \to\ \infty,\\ p=2:\ \mathbb E[Q_n]&=T,\\ p=3:\ \mathbb E\textstyle\sum|\Delta W_i|^3&=2\sqrt{2/\pi}\,T^{3/2}/\sqrt n\ \to\ 0. \end{aligned} \]

ทุกอย่างขึ้นกับเลขชี้กำลังของ $n$ คือ $1-p/2$ ถ้า $p$ น้อยกว่า 2 เลขชี้กำลังเป็นบวก ผลรวมจึงโตไม่สิ้นสุด ถ้า $p$ มากกว่า 2 เลขชี้กำลังเป็นลบ ผลรวมจึงหายไป $p=2$ พอดีคือจุดเดียวที่เลขชี้กำลังเป็นศูนย์ ผลรวมจึงเหลือตัวเลขจำกัดที่ไม่ใช่ศูนย์

ที่ $T=1$ ความยาวเฉลี่ยคือ $\sqrt{2/\pi}\,\sqrt8\approx2.26$ ที่ 8 ท่อน และ $\sqrt{2/\pi}\,\sqrt{32{,}768}\approx144.4$ ที่ 32,768 ท่อน

ข้อนี้ให้ข้อสรุปที่แรงกว่าการซูมดูความชัน ขั้นที่ 1 บอกว่าเส้นที่ความชันไม่เกิน $M$ มีความยาวไม่เกิน $MT$ ทุก grid แต่ความยาวของ Brownian แทบไม่แกว่งรอบค่าเฉลี่ย เพราะ variance ของมันคงที่:

\[ \begin{aligned} \operatorname{Var}(V_n)&=n\cdot\frac Tn\Big(1-\frac2\pi\Big)\approx0.36\,T,\\ \operatorname{SD}(V_n)&\approx0.60\sqrt T. \end{aligned} \]

ค่า $1-2/\pi$ มาจาก $\operatorname{Var}|Z|=\mathbb E[Z^2]-(\mathbb E|Z|)^2=1-2/\pi$ ค่าเฉลี่ยโตตาม $\sqrt n$ แต่ SD คงที่ เกือบทุกเส้นทางจึงยาวเกิน $MT$ ไม่ว่า $M$ จะใหญ่แค่ไหน ดังนั้นเส้นทาง Brownian จะมีความชันที่จำกัดบนช่วงไหนเลยไม่ได้

ขั้นที่ 7 — ตัวย่อที่ Itô calculus จะใช้ทุกหน้า

ขั้นที่ 4 พิสูจน์แล้วว่า $Q_n$ มีค่าเฉลี่ย $T$ และ variance ที่หดลงสู่ศูนย์ ดังนั้น $Q_n$ เข้าใกล้ $T$ เมื่อซอยละเอียดขึ้น ผลนี้ถูกใช้บ่อยมากใน Itô calculus ซึ่งเป็น calculus สำหรับเส้นทางสุ่ม จึงต้องมีชื่อและตัวย่อ สามบรรทัดข้างล่างไม่ใช่ผลใหม่ เป็นแค่ชื่อและวิธีจดสั้น ๆ ของผลเดิม

\[ \begin{aligned} [W]_T&:=\lim_{n\to\infty}Q_n=T,\\ [\sigma W]_T&=\sigma^2T,\\ (dW_t)^2&=dt. \end{aligned} \]

$[W]_T$ อ่านว่า quadratic variation ของ $W$ ถึงเวลา $T$ มันคือค่าที่ $Q_n$ เข้าใกล้ จึงเท่ากับ $T$

ราคาที่มีความผันผวน $\sigma$ ขยับเป็น $\sigma$ เท่าของ SBM ทุกการขยับถูกคูณด้วย $\sigma$ กำลังสองจึงถูกคูณด้วย $\sigma^2$ ส่วน drift ไม่มีผลเลย เพราะ drift เป็นส่วนที่เรียบ และขั้นที่ 1 แสดงแล้วว่าผลรวมกำลังสองของส่วนที่เรียบหายไป

$(dW_t)^2=dt$ เป็นตัวย่อ ไม่ใช่การคูณจำนวนเล็กจิ๋วสองตัว มันบอกว่าเมื่อบวกกำลังสองของการขยับเล็ก ๆ จำนวนมาก ผลจะเท่ากับการบวกเวลา จึงห้ามหารสองข้างด้วย $dW_t$ หรือถอดรากสองข้างแบบพีชคณิต หน้าทำไม calculus ธรรมดาใช้กับ Brownian motion ไม่ได้จะเริ่มจากตัวย่อนี้

ขั้นที่ 8 — realized volatility ของ SPY หนึ่งวัน และทำไมวัดถี่ช่วย variance แต่ไม่ช่วย drift

โจทย์ให้อะไรมาบ้าง: คราวนี้ใช้วิธีเดียวกับที่ใช้กับราคาจริง วันซื้อขายยาว 390 นาที แบ่งเป็นแท่ง 5 นาทีได้ $390/5=78$ แท่ง แต่ละแท่งมี log return $r_i$ คือผลตอบแทนของแท่งที่วัดด้วย $\ln$ ของราคาปลายแท่งหารด้วยราคาต้นแท่ง สมมติว่าผลรวมของ $r_i^2$ ทั้ง 78 แท่งคือ 0.000144 ผลรวมนี้เรียกว่า realized variance (RV)

เราอยากรู้สามเรื่อง เรื่องแรก ค่าเฉลี่ยของ $Q_n$ บอกว่า RV ประมาณ variance ของทั้งวัน รากของมันจึงเป็นความผันผวนรายวัน เรื่องที่สอง variance ของ $Q_n$ บอกว่าตัวเลขนี้คลาดได้เท่าไร เรื่องที่สาม drift (ผลตอบแทนเฉลี่ยต่อปี) ซึ่งประมาณด้วยผลรวมของผลตอบแทนแบบไม่ยกกำลัง จะแม่นขึ้นไหมถ้าวัดถี่ขึ้น สำหรับเรื่องนี้ ให้ข้อมูลยาว $T$ ปี แบ่งเป็น $n$ แท่ง และ $p_0,\ p_T$ คือ log ราคาตอนต้นและตอนจบ

\[ \begin{aligned} RV&=\sum_{i=1}^{78}r_i^2=0.000144,\\ \sigma_{\text{day}}&=\sqrt{0.000144}=0.012,\\ \sigma_{\text{yr}}&=0.012\sqrt{252}\approx0.1905,\\ \frac{\operatorname{SD}(RV)}{RV}&\approx\sqrt{2/78}\approx0.160,\\ \operatorname{SD}(\sigma_{\text{day}})&\approx\tfrac12(0.160)(0.012)=0.00096,\\ \hat\mu&=\frac1T\sum_{i=1}^{n}r_i=\frac{p_T-p_0}{T},\\ \operatorname{SD}(\hat\mu)&=\frac{\sigma_{\text{yr}}}{\sqrt T}. \end{aligned} \]

คำตอบ: ความผันผวนรายวัน 1.20% และรายปี 19.05% ตัวเลขรายปีได้จากการคูณ $\sqrt{252}$ เพราะปีหนึ่งมี 252 วันทำการ และ variance ของวันที่อิสระกันบวกกันได้ variance ทั้งปีจึงเป็น 252 เท่าของรายวัน SD จึงเป็น $\sqrt{252}$ เท่า

ตัวเลขนี้ยังคลาดได้ variance ของ $Q_n$ คือ $2T^2/n$ RV จาก 78 แท่งจึงมี SD ราว $\sqrt{2/78}\approx16\%$ ของตัวมันเอง ความผันผวนคือรากของ RV และรากของตัวเลขขยับแค่ครึ่งหนึ่งของสัดส่วนที่ตัวเลขขยับ เพราะ $\Delta\sqrt x/\sqrt x\approx\tfrac12\,\Delta x/x$ ความผันผวนรายวันจึงคลาดราว ±0.00096 คือ ±0.096 จุด และรายปีคลาดราว $0.096\times\sqrt{252}\approx1.5$ จุด

drift เป็นอีกเรื่อง ผลรวมของผลตอบแทนหักกันเองจนเหลือแค่ log ราคาตอนจบลบ log ราคาตอนต้น ไม่ว่าจะซอยกี่แท่ง ตัว $n$ จึงไม่อยู่ในสูตร SD ข้อมูลหนึ่งปี ($T=1$) ของ SPY จึงให้ค่าประมาณ drift ที่คลาดได้หนึ่ง SD ราว 19% ต่อปี ถ้า drift จริงคือ 8% ต่อปี (ตัวเลขสมมติ) ความคลาดนี้ใหญ่กว่าสิ่งที่อยากวัดเสียอีก วัดถี่ขึ้นช่วยความผันผวน เพราะกำลังสองไม่หักล้างกัน แต่ไม่ช่วย drift เลย ทางเดียวคือเก็บข้อมูลให้ยาวหลายปีขึ้น

ตรวจเองใน 10 วินาที: $0.012^2=0.000144$ และ $\sqrt{252}\approx15.87$ จึงได้ $1.2\%\times15.87\approx19.05\%$

ขั้นที่ 9 — วัดถี่เกินไป: noise ถูกนับเป็นความผันผวน และความถี่ที่ดีที่สุด

ขั้นก่อนบอกว่า RV ยิ่งซอยละเอียดยิ่งแม่น แล้วทำไมไม่วัดทุกวินาที? เพราะราคาที่เห็นในข้อมูลไม่ใช่ราคาที่แท้จริงพอดี ราคาที่ซื้อขายจริงเด้งไปมาระหว่าง bid (ราคาที่มีคนเสนอซื้อ) กับ ask (ราคาที่มีคนเสนอขาย) ส่วนต่างของสองราคานี้เรียกว่า spread

ขั้นนี้จำลองเรื่องนี้ด้วยสมมติฐานง่าย ๆ: log ราคาที่เห็นคือ log ราคาจริงบวก noise $\epsilon_i$ noise ของแต่ละแท่งอิสระกัน มีค่าเฉลี่ยศูนย์ และมี SD เท่ากับ $\omega$ ซึ่งมีขนาดราวครึ่งหนึ่งของ spread หารด้วยราคา ผลตอบแทนที่เห็น $\tilde r_i$ จึงเท่ากับผลตอบแทนจริง $r_i$ บวก noise ตอนจบแท่ง ลบ noise ตอนต้นแท่ง ให้ $IV$ คือ variance ที่แท้จริงของวัน เราจะหาว่า RV ที่เห็น ($\widetilde{RV}$) มีค่าเฉลี่ยเท่าไร และ $n$ เท่าไรให้ความคลาดรวมน้อยที่สุด

\[ \begin{aligned} \tilde r_i&=r_i+\epsilon_i-\epsilon_{i-1},\\ \mathbb E[\tilde r_i^2]&=\mathbb E[r_i^2]+2\omega^2,\\ \mathbb E[\widetilde{RV}]&=IV+2n\omega^2,\\ \text{err}^2(n)&=\Big(\frac{2n\omega^2}{IV}\Big)^2+\frac2n,\\ n^*&=\Big(\frac{2\omega^2}{IV}\Big)^{-2/3}. \end{aligned} \]

ทำไม noise ถึงทำให้ RV พอง? กระจาย $\tilde r_i^2$ ออกมา พจน์ไขว้ทุกตัวมีค่าเฉลี่ยศูนย์ เพราะ noise อิสระจากราคาจริงและอิสระจากกัน ที่เหลือคือ variance ของ noise สองก้อน คือ $\epsilon_i$ กับ $\epsilon_{i-1}$ ก้อนละ $\omega^2$ แต่ละแท่งจึงได้ส่วนเกิน $2\omega^2$ บวก $n$ แท่งได้ส่วนเกิน $2n\omega^2$ ส่วนเกินนี้โตตามจำนวนแท่ง ยิ่งวัดถี่ยิ่งพอง สวนทางกับความแม่นที่ได้จากการซอย

ความคลาดรวมวัดเป็นสัดส่วนของ $IV$ แล้วยกกำลังสอง มีสองส่วน ส่วนแรกคือ bias (ความเอียงจาก noise) ยกกำลังสอง ซึ่งโตตาม $n^2$ ส่วนที่สองคือ variance $2/n$ จากความสุ่ม ซึ่งหดลง สองแรงนี้ดึงคนละทาง จึงมีจุดต่ำสุด ให้ $a=2\omega^2/IV$ แล้วตั้งอนุพันธ์เป็นศูนย์:

\[ \begin{aligned} \frac{d}{dn}\Big(a^2n^2+\frac2n\Big)&=2a^2n-\frac{2}{n^2}=0,\\ n^3&=\frac1{a^2},\\ n^*&=a^{-2/3}. \end{aligned} \]

ใส่ตัวเลขของ SPY: spread 1 เซนต์ (\$0.01) ที่ราคา \$520 ครึ่งหนึ่งของ spread คือ \$0.005 และใช้ $IV=0.000144$ จากขั้นก่อน

\[ \begin{aligned} \omega&=0.005/520\approx9.6\times10^{-6},\\ a&=2\omega^2/IV\approx1.28\times10^{-6},\\ n^*&=a^{-2/3}\approx8{,}460,\\ \sqrt{(an^*)^2+2/n^*}&\approx0.019. \end{aligned} \]

แท่งที่ดีที่สุดของ SPY จึงยาว $23{,}400/8{,}460\approx2.8$ วินาที และคลาดราว 1.9% ถ้าวัดทุกวินาที ($n=23{,}400$) ส่วนเกินคือ $23{,}400\times a\approx0.030$ หรือแค่ 3.0% ของ $IV$ เพราะ spread ของ SPY แคบมากเมื่อเทียบกับราคา

ทีนี้ลองหุ้นราคา \$50 ที่ spread 5 เซนต์ และสมมติว่าผันผวนวันละ 1.2% เท่ากัน ($IV=0.000144$):

\[ \begin{aligned} \omega&=0.025/50=0.0005,\\ a&=2(0.0005)^2/0.000144\approx0.00347,\\ n=23{,}400&:\ 1+23{,}400a\approx82.25,\\ n=78&:\ 78a\approx0.27,\\ n=26&:\ 26a\approx0.09,\\ n^*&=a^{-2/3}\approx43.6. \end{aligned} \]

วัดทุกวินาที RV พองเป็นราว 82 เท่าของ $IV$ ความผันผวนรายวันจึงดูเป็น $1.2\%\times\sqrt{82.25}\approx10.9\%$ แทน 1.2% แท่ง 5 นาที ($n=78$) ยังพองเกินจริง 27% แท่ง 15 นาที ($n=26$) เกิน 9% จำนวนแท่งที่ดีที่สุดคือราว 44 แท่ง แท่งละ $23{,}400/43.6\approx537$ วินาที คือราว 9 นาที และแม้ที่จุดดีที่สุดก็ยังคลาดราว $\sqrt{(43.6a)^2+2/43.6}\approx26\%$

ขั้นที่ 10 — กลับมาแน่นอน แต่เวลารอเฉลี่ยเป็นอนันต์

นิสัยสุดท้ายขัดสัญชาตญาณที่สุด ลองนึกถึงนักลงทุนที่ขาดทุนอยู่ และรอให้ราคากลับมาเท่าทุน คำถามทางคณิตศาสตร์คือ SBM ที่เริ่มที่ 0 จะแตะระดับ $x\gt0$ ครั้งแรกเมื่อไร ให้ $\tau$ คือเวลานั้น เรียกว่า hitting time

เครื่องมือคือ reflection principle (ดูรูปด้านล่าง) ดูเส้นทางที่แตะ $x$ ก่อนเวลา $t$ แล้วจบต่ำกว่า $x$ ถ้าพลิกส่วนหลังจุดแตะให้กลับหัวรอบระดับ $x$ จะได้เส้นทางที่จบสูงกว่า $x$ การพลิกนี้จับคู่เส้นทางได้หนึ่งต่อหนึ่ง และสองเส้นในคู่มีโอกาสเกิดเท่ากัน เพราะหลังจุดแตะ การขยับขึ้นกับลงมีโอกาสเท่ากัน

อีกข้อหนึ่ง เส้นทางที่จบสูงกว่า $x$ ต้องเคยแตะ $x$ มาแล้ว เพราะเส้นทางต่อเนื่อง กระโดดข้ามไม่ได้ สองข้อนี้รวมกันได้บรรทัดแรก: โอกาสแตะภายในเวลา $t$ เป็นสองเท่าของโอกาสจบสูงกว่า $x$ ในสูตร $\Phi$ คือ CDF ของ Normal มาตรฐาน และ $W_t$ มี SD เท่ากับ $\sqrt t$ ตัวเลขข้างล่างใช้ $x=1$

\[ \begin{aligned} P(\tau\le t)&=2P(W_t\gt x)=2\Phi(-x/\sqrt t),\\ t=1&:\ 2\Phi(-1)\approx0.3173,\\ t=100&:\ 2\Phi(-0.1)\approx0.9203,\\ t=10{,}000&:\ 2\Phi(-0.01)\approx0.9920,\\ P(\tau\gt t)&=2\int_0^{1/\sqrt t}\varphi(z)\,dz\ \ge\ \frac{2\varphi(1)}{\sqrt t},\\ \mathbb E[\tau]&=\int_0^\infty P(\tau\gt t)\,dt\\ &\ge\int_1^\infty\frac{0.4839}{\sqrt t}\,dt=\infty. \end{aligned} \]

โอกาสแตะไต่ขึ้นหาหนึ่ง: 31.7%, 92.0% และ 99.2% ดังนั้นเส้นทางแตะระดับ $x$ แน่นอนในที่สุด แต่โอกาสที่ยังไม่แตะหดลงช้ามาก แค่ตาม $1/\sqrt t$

ขอบล่างของ $P(\tau\gt t)$ มาจากเหตุผลง่าย ๆ เมื่อ $t\ge1$ ช่วงอินทิเกรต $[0,1/\sqrt t]$ ยาวไม่เกิน 1 และ $\varphi$ ในช่วงนั้นไม่ต่ำกว่า $\varphi(1)\approx0.242$ พื้นที่ใต้ $\varphi$ จึงไม่น้อยกว่าความกว้างคูณความสูงต่ำสุด คือ $\varphi(1)/\sqrt t$ คูณด้วย 2 ที่อยู่หน้าอินทิกรัล ได้ $2\varphi(1)/\sqrt t\approx0.4839/\sqrt t$

เวลารอเฉลี่ยคือพื้นที่ใต้กราฟของโอกาสที่ยังไม่แตะ สูตร $\mathbb E[\tau]=\int_0^\infty P(\tau\gt t)\,dt$ ใช้ได้กับตัวแปรสุ่มที่ไม่ติดลบ และ $\int_1^\infty t^{-1/2}dt=\big[2\sqrt t\,\big]_1^\infty$ โตไม่สิ้นสุด เวลารอเฉลี่ยจึงเป็นอนันต์ จังหวะที่ขัดสัญชาตญาณคือ “แตะแน่นอน” กับ “รอเฉลี่ยนานไม่สิ้นสุด” จริงพร้อมกันได้ เพราะเส้นทางส่วนน้อยที่หลงไปไกลใช้เวลานานมากจนดึงค่าเฉลี่ยขึ้นไม่หยุด

อ่านเป็นเงิน: สมมติหุ้นที่ผันผวน 18% ต่อปี ไม่มี drift และราคาตกลงมาราว 18% จากจุดคุ้มทุน คือหนึ่ง SD ของปี ถ้านับเวลาเป็นปี ระยะนี้ตรงกับ $x=1$ โอกาสกลับถึงทุนภายในหนึ่งปีคือ 31.7% ภายในร้อยปีคือ 92.0% และเวลารอเฉลี่ยเป็นอนันต์ “ถือไว้เดี๋ยวก็กลับมา” จึงไม่ใช่แผน (เรื่องนี้กลับมาอีกครั้งในdrawdown และการลดความเสี่ยง)

ความผิดที่ดูเหมือนความละเอียด

ใช้ความยาวหรือความชันเป็นตัววัดความผันผวน: ตัวเลขทั้งสองขึ้นกับขนาดแท่งที่เลือกเอง บนเส้นทางเดียวกันในวันจำลองของ SPY ความยาวจากแท่ง 30 นาทีคือ \$19.19 แต่จากแท่ง 1 วินาทีคือ \$758.69 ต่างกัน $758.69/19.19\approx40$ เท่า สองทีมที่ใช้แท่งต่างกันจึงได้ตัวเลขต่างกันหลายสิบเท่า แล้วเถียงกันไม่จบ ตัวที่ถูกคือ $\sqrt{\sum\Delta S^2}$ ซึ่งได้ \$7.25 และ \$6.23 ทั้งสองอยู่ใกล้ \$6.24

วัด RV ถี่ที่สุดเท่าที่ข้อมูลมี: หุ้นราคา \$50 spread 5 เซนต์ ถ้าวัดทุกวินาทีจะได้ความผันผวนรายวัน $1.2\%\times\sqrt{82.25}\approx10.9\%$ แทนที่จะเป็น $\sqrt{0.000144}=1.2\%$ ขนาดแท่งที่เหมาะขึ้นกับ spread เทียบกับความผันผวน ไม่ใช่ยิ่งถี่ยิ่งดี สำหรับหุ้นนี้คือราว 9 นาที นอกจากนี้ หุ้นที่ซื้อขายน้อยกว่าหนึ่งครั้งต่อ 5 นาที ใช้แท่ง 1 นาทีไม่ได้เลย เพราะแท่งส่วนใหญ่ไม่มีราคาใหม่

คิดว่าข้อมูลถี่ขึ้นช่วยประมาณ drift: ผลรวมของผลตอบแทนหักกันจนเหลือ log ราคาตอนจบลบ log ราคาตอนต้น ข้อมูลรายวินาทีหนึ่งปีจึงบอก drift ได้แม่นเท่าราคาแค่สองจุด ความคลาดคือ $\sigma_{\text{yr}}/\sqrt T=0.19/\sqrt1=19\%$ ต่อปี ไม่ว่า $n$ จะเท่าไร ทางลดมีทางเดียวคือรอให้ $T$ ยาวขึ้น เช่นข้อมูล 4 ปีให้ $0.19/\sqrt4=9.5\%$

อ่าน $(dW_t)^2=dt$ เป็นพีชคณิต: มันเป็นตัวย่อของผลที่ว่า $Q_n$ เข้าใกล้ $T$ ใช้ได้เมื่อบวกกันหลายท่อนเท่านั้น และ $[W]_T=T$ เป็นของ SBM ที่ $\sigma=1$ ราคาที่มีความผันผวน $\sigma$ มี quadratic variation $\sigma^2T$ เช่นวันจำลองของ SPY ที่ $\sigma=\$6.24$ ต่อวันและ $T=1$ วัน ผลรวมการขยับยกกำลังสองคือ $6.24^2\times1\approx38.94$ ไม่ใช่ 1

ในบริษัทเทรด ทีมที่ดูแลความเสี่ยงและทีมที่ซื้อขาย option ดู realized volatility จากแท่ง 5 นาทีทุกวัน option คือสัญญาที่ให้สิทธิ์ซื้อหรือขายในราคาที่ตกลงไว้ ราคาของมันขึ้นกับความผันผวนที่ตลาดคาดไว้ ตัวเลขความผันผวนที่ถอดกลับมาจากราคา option เรียกว่า implied volatility ทีมจึงเทียบ realized กับ implied เพื่อดูว่าตลาดคาดไว้สูงหรือต่ำเกินไป (มีโจทย์อ่านความผันผวนจากราคา straddle ในหน้าstandard Brownian motion)

realized variance ยังใช้ชำระvariance swap ด้วย สัญญานี้จ่ายเงินตามผลรวมกำลังสองของผลตอบแทนรายวันที่เกิดขึ้นจริงตลอดอายุสัญญา การเลือกขนาดแท่งให้เหมาะกับสภาพคล่องของแต่ละสินทรัพย์ คือซื้อขายบ่อยแค่ไหนและ spread แคบแค่ไหน ก็คือการแก้สมการ $n^*$ ข้างบนในทางปฏิบัติ ที่มาของ noise อยู่ในหน้าmarket microstructure

ผลรวมกำลังสองที่ไม่หายไปคือเหตุผลที่ calculus ธรรมดาใช้กับราคาไม่ได้ ใน chain rule ปกติ พจน์กำลังสองของการขยับถูกทิ้ง เพราะสำหรับเส้นเรียบมันหายไป (ขั้นที่ 1) แต่ของ Brownian ไม่หาย มันเหลือเท่ากับเวลา (ขั้นที่ 4) Itô's lemma จึงต้องเก็บพจน์นั้นไว้

โจทย์ตรวจความเข้าใจ

1. ทีมหนึ่งมีราคา SPY แค่ทุก 30 นาที วันหนึ่งจึงมี $390/30=13$ แท่ง วันนั้นผลรวมของ log return ยกกำลังสองทั้ง 13 แท่งคือ 0.000150 (ตัวเลขสมมติ) ความผันผวนรายวันและรายปีเป็นเท่าไร และตัวเลขนี้คลาดได้มากกว่าการใช้แท่ง 5 นาทีแค่ไหน?

เฉลย

รากของ RV คือความผันผวนรายวัน คูณ $\sqrt{252}$ ได้รายปี และ SD สัมพัทธ์ของ RV คือ $\sqrt{2/n}$:

\[ \begin{aligned} \sigma_{\text{day}}&=\sqrt{0.000150}\approx1.225\%,\\ \sigma_{\text{yr}}&=1.225\%\times\sqrt{252}\approx19.44\%,\\ \frac{\operatorname{SD}(RV)}{RV}&\approx\sqrt{2/13}\approx0.39. \end{aligned} \]

แท่ง 5 นาทีให้ $\sqrt{2/78}\approx0.16$ แท่ง 30 นาทีจึงคลาดมากกว่า $0.39/0.16\approx2.4$ เท่า หรือราวสองเท่าครึ่ง นี่คือเหตุผลที่ต้องใช้แท่งสั้นลง จนกว่า noise จะเริ่มชนะ

2. กลับไปที่วันจำลองของ SPY ซึ่งการขยับทั้งวันมี SD \$6.24 ถ้าอ่านราคาด้วยแท่ง 10 วินาที ความยาวคาดหวังเป็นเท่าไร และยาวกว่าของแท่ง 5 นาทีกี่เท่า?

เฉลย

แท่ง 10 วินาทีมี $n=23{,}400/10=2{,}340$ แท่ง ใช้สูตรความยาวคาดหวัง $6.24\sqrt{2n/\pi}$:

\[ \begin{aligned} 6.24\sqrt{2(2{,}340)/\pi}&\approx\$240.84,\\ \sqrt{2{,}340/78}=\sqrt{30}&\approx5.48. \end{aligned} \]

ความยาวคาดหวังของแท่ง 5 นาทีคือ \$43.97 แท่ง 10 วินาทีจึงยาวกว่าราว 5.48 เท่า เพราะความยาวโตตาม $\sqrt n$ ตรวจได้จาก $43.97\times5.48\approx240.9$ ส่วนรากของผลรวมกำลังสองยังคาดว่าราว \$6.24 เท่าเดิม

3. นักลงทุนถือหุ้นที่ผันผวน 18% ต่อปี และสมมติว่าไม่มี drift เขาตั้งเป้าขายเมื่อราคาขึ้นไปหนึ่ง SD ของปี คือราว 18% โอกาสที่ราคาแตะเป้าภายใน 4 ปี และภายใน 25 ปี เป็นเท่าไร?

เฉลย

นับเวลาเป็นปี เป้าหนึ่ง SD ของปีคือ $x=1$ ใช้ $P(\tau\le t)=2\Phi(-x/\sqrt t)$ จาก reflection principle:

\[ \begin{aligned} P(\tau\le4)&=2\Phi(-1/\sqrt4)=2\Phi(-0.5)\approx0.617,\\ P(\tau\le25)&=2\Phi(-1/\sqrt{25})=2\Phi(-0.2)\approx0.841. \end{aligned} \]

รอนานขึ้น $25/4=6.25$ เท่า แต่โอกาสเพิ่มแค่ $84.1-61.7=22.4$ จุด และเวลารอเฉลี่ยยังเป็นอนันต์

// Simpson's rule on [a, b] with an even number of pieces.
function simpson(f, a, b, n = 20000) {
  const h = (b - a) / n;
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * f(a + i * h);
  return s * h / 3;
}
const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
const Phi = x => 0.5 + Math.sign(x) * simpson(phi, 0, Math.abs(x), 4000);
// E|Z|^p for a standard Normal, by integration.
const absMoment = p => simpson(z => 2 * z ** p * phi(z), 0, 12);
// mulberry32 + Box-Muller: seeded standard Normals.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// One simulated trading day, one price per second, in dollars: daily SD sdDay spread over n seconds.
function simulateDay(S0, sdDay, n, seed) {
  const z = normals(seed), step = sdDay / Math.sqrt(n), path = [S0];
  for (let i = 0; i < n; i++) path.push(path[i] + step * z());
  return path;
}
// Read the same path every `every` points: sum of |moves|, root of sum of squares, sum of |moves|^3, steepest slope.
function gridStats(path, every) {
  const n = path.length - 1;
  if (n % every !== 0) throw new RangeError('The grid step must divide the path length');
  let abs = 0, sq = 0, cube = 0, steep = 0;
  const h = every / n; // fraction of a day per step
  for (let i = every; i <= n; i += every) {
    const d = path[i] - path[i - every];
    abs += Math.abs(d); sq += d * d; cube += Math.abs(d) ** 3;
    steep = Math.max(steep, Math.abs(d) / h);
  }
  return {steps: n / every, length: abs, rootSumSquares: Math.sqrt(sq), sumCubes: cube, maxSlope: steep};
}
// Expected sum of |W increments|^p on n equal steps over time T: T^(p/2) E|Z|^p n^(1 - p/2).
const expectedPowerSum = (p, n, T = 1) => T ** (p / 2) * absMoment(p) * n ** (1 - p / 2);
// Microstructure noise: observed return = true return + e_i - e_(i-1), so E[RV] = IV + 2 n omega^2.
const noisyRV = (iv, n, omega) => iv + 2 * n * omega * omega;
// Relative error of RV: squared bias from noise plus sampling variance 2/n; and the n that minimises it.
const rvError = (iv, n, omega) => Math.sqrt((2 * n * omega * omega / iv) ** 2 + 2 / n);
const bestN = (iv, omega) => (2 * omega * omega / iv) ** (-2 / 3);
// Reflection principle: chance that W started at 0 has touched level x by time t.
const hitBy = (x, t) => 2 * Phi(-x / Math.sqrt(t));

สิ่งที่ควรตอบได้หลังอ่าน

  • ความชันเฉลี่ยในช่วงสั้น $h$ มี SD $1/\sqrt h$ ซูมเข้าไป 100 เท่า ความชันเหวี่ยงแรงขึ้น $\sqrt{100}=10$ เท่า และภาพที่ซูมขรุขระเท่าภาพเต็ม
  • ผลรวมการขยับยกกำลังสอง $Q_n$ มีค่าเฉลี่ย $T$ และ variance $2T^2/n$ จึงนิ่งที่ $T$ เมื่อซอยละเอียด ส่วนของเส้นเรียบหายไปเป็นศูนย์
  • ผลรวมกำลัง $p$ โตตาม $n^{1-p/2}$: ความยาว ($p=1$) โตไม่สิ้นสุด กำลังสามหายไป กำลังสองพอดี และความยาวที่ไม่จำกัดแปลว่าไม่มีความชันที่จำกัด
  • RV จาก 78 แท่ง 5 นาทีที่เท่ากับ 0.000144 ให้ความผันผวน $\sqrt{0.000144}=1.20\%$ ต่อวัน หรือ 19.05% ต่อปี และคลาดได้ราว ±1.5 จุดต่อปี วัดถี่ขึ้นช่วย variance แต่ไม่ช่วย drift และ noise เพิ่มส่วนเกิน $2n\omega^2$ จนมีจำนวนแท่งที่ดีที่สุด $n^*=(2\omega^2/IV)^{-2/3}$
  • SBM แตะระดับที่ตั้งไว้แน่นอนในที่สุด (โอกาส $2\Phi(-x/\sqrt t)$ จาก reflection principle) แต่เวลารอเฉลี่ยเป็นอนันต์

หน้าถัดไป geometric Brownian motion นำ Brownian motion ไปใส่ในเลขชี้กำลังของราคา ได้แบบจำลองที่ราคาติดลบไม่ได้ และผลตอบแทนเป็นสัดส่วนของราคา ส่วนผลรวมกำลังสองของหน้านี้จะกลับมาเป็นแกนของ Itô's lemma
