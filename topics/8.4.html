8.4 The Multivariate Normal Density

multivariate Normal คือระฆังกลมของตัวแปรอิสระที่ถูกยืดและเอียงด้วย matrix จน covariance เป็น $\Sigma$ ตามต้องการ

หุ้นสหรัฐสองตัวมีผลตอบแทนรายวันเฉลี่ยศูนย์ SD ตัวละ 2% และ correlation 0.82 ภายใต้แบบจำลอง joint Normal วันนี้ตัวหนึ่งขึ้น 3% อีกตัวลง 3% ถ้าดูทีละตัว แต่ละตัวห่างค่าเฉลี่ยแค่ 1.5 SD ซึ่งเกิดบ่อย ฝ่ายความเสี่ยงควรตั้งธงว่าวันนี้ผิดปกติไหม

ลองตอบก่อนเปิดเฉลย

ควร แบบจำลองบอกว่าสองตัวนี้เกือบจะขึ้นลงด้วยกัน การสวนทางกันจึงอยู่ไกลมากเมื่อวัดด้วยระยะที่คิด correlation แล้ว squared Mahalanobis distance ออกมา $q=25$ หรือระยะ $d=5$ โอกาสที่ผลตอบแทนจะไกลอย่างน้อยเท่านี้ในทิศใดก็ตามคือ $e^{-25/2}\approx3.7\times10^{-6}$ หรือประมาณหนึ่งวันในพันปีของวันทำการ ถ้าทั้งสองตัวขึ้น 3% พร้อมกัน ระยะจะเหลือแค่ $q=2.47$ ซึ่งเกิดได้ราว 29% ของวัน ตัวเลขนี้ไม่ใช่โอกาสของจุดนั้นจุดเดียว และไม่ใช่ “5-sigma” ของตัวแปรเดียว ท้ายหน้าจะคำนวณให้ดู

ภาพรวมก่อนลงสูตร

Normal distribution ตัวแปรเดียวคือระฆังที่มีศูนย์กลาง $\mu$ และความกว้าง $\sigma$ multivariate Normal (MVN) คือระฆังหลายมิติ ถ้ามองระฆังสองมิติจากด้านบน เส้นระดับความสูงเดียวกันจะเป็นวงรีซ้อนกัน วงรีเอียงไปตาม covariance และยืดยาวในทิศที่ผันผวนมาก

วิธีสร้างที่เข้าใจง่ายที่สุดคือเริ่มจากแหล่งสุ่มอิสระ $Z$ ซึ่งมีระฆังกลมเท่ากันทุกทิศ แล้วยืดและเอียงมันด้วย matrix $L$ ที่ทำให้ $LL^{\mathsf T}=\Sigma$ วงกลมจะกลายเป็นวงรี สูตร density ทั้งหมดได้จากการตามรอยการยืดนี้ย้อนกลับ: ระยะ Mahalanobis บอกว่าจุดอยู่บนวงรีวงไหน ส่วน determinant ปรับความสูงของระฆังให้ probability รวมยังเท่ากับ 1

หน้านี้จะสร้าง density ทีละชิ้น ใส่ตัวเลขของแบบจำลอง SPX/QQQ สมมติ (SD รายวัน 2% กับ 3% correlation 0.40) แยกความสูงของ density ออกจาก probability หาว่าวงรีวงไหนครอบคลุม 95% แล้วตอบคำถามเปิดซึ่งใช้หุ้นอีกคู่ (SD 2% เท่ากัน correlation 0.82) สองแบบจำลองนี้แยกกันตลอด ไม่สลับ parameter ระหว่างทาง

ศัพท์ที่ใช้ในหัวข้อนี้
Multivariate Normal (MVN)
joint distribution ที่ได้จาก affine transformation $\mu+LZ$ ของ standard Normal อิสระ เขียน $R\sim N_n(\mu,\Sigma)$ ใช้เป็นแบบจำลองมาตรฐานของผลตอบแทนหลายตัวพร้อมกัน
Standard MVN
MVN ที่ $\mu=0$ และ $\Sigma=I$ ทุก component เป็น standard Normal และอิสระกัน เป็นวัตถุดิบที่ใช้สร้าง MVN ทุกตัว
Mahalanobis distance
ระยะจากค่าเฉลี่ยที่วัดเทียบกับความกว้างและความเอียงของเมฆ $d=\sqrt{(r-\mu)^{\mathsf T}\Sigma^{-1}(r-\mu)}$ ใช้บอกว่าผลตอบแทนชุดหนึ่งผิดปกติแค่ไหนเมื่อคิดทุกตัวพร้อมกัน
Whitening
เปลี่ยนพิกัดด้วย $L^{-1}$ ให้ covariance เป็น identity ใช้คำนวณระยะ Mahalanobis โดยไม่ต้องสร้าง inverse ทั้ง matrix
Jacobian / determinant
ตัวคูณที่บอกว่าการเปลี่ยนพิกัดยืดพื้นที่หรือปริมาตรกี่เท่า density ต้องหารด้วยตัวนี้เพื่อให้ probability คงเดิม
Probability ellipse
วงรีที่ครอบคลุมผลลัพธ์ใหม่ตามสัดส่วนที่กำหนด เช่น 95% ภายใต้แบบจำลอง ไม่ใช่ช่วงความเชื่อมั่นของค่าเฉลี่ยที่ยังไม่รู้
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$R,\ r$vector ผลตอบแทนสุ่ม และค่าที่นำมาประเมินทศนิยม (2% = 0.02)
$\mu,\ \Sigma$mean vector และ covariance ของช่วงถือครองเดียวกันทศนิยม; ทศนิยม²
$Z,\ z$vector ของ standard Normal อิสระ และพิกัด whitenedไม่มีหน่วย
$L$matrix ที่ $LL^{\mathsf T}=\Sigma$ เช่น Choleskyทศนิยม
$s_i$คะแนนมาตรฐานรายตัว $(r_i-\mu_i)/\sigma_i$ ซึ่งยังสัมพันธ์กันได้ไม่มีหน่วย
$q,\ d$ระยะ Mahalanobis ยกกำลังสอง และระยะ $d=\sqrt q$ไม่มีหน่วย
$f_R$joint densityต่อหน่วยพื้นที่ (ทศนิยม$^{-2}$)

ขั้นที่ 1 — เริ่มจากแหล่งสุ่มอิสระ แล้วผสมด้วย matrix

ให้ $Z_1,\ldots,Z_n$ เป็น standard Normal ที่อิสระกัน density ร่วมจึงเป็นผลคูณของ density รายตัว นี่คือ standard MVN ที่ $\mu=0$ และ $\Sigma=I$ จากนั้นสร้าง $R=\mu+LZ$ ด้วย matrix $L$ คงที่

\[ \begin{aligned} f_Z(z)&=\prod_{i=1}^n\frac1{\sqrt{2\pi}}e^{-z_i^2/2}\\ &=(2\pi)^{-n/2}e^{-z^{\mathsf T}z/2},\\ R&:=\mu+LZ,\\ \mathbb E[R]&=\mu+L\,\mathbb E[Z]=\mu,\\ \operatorname{Cov}(R)&=L\,I\,L^{\mathsf T}=LL^{\mathsf T}=\Sigma. \end{aligned} \]

บรรทัดที่สองรวม exponent ของผลคูณเป็นผลบวก $\sum_iz_i^2=z^{\mathsf T}z$ ซึ่งขึ้นกับระยะจากศูนย์อย่างเดียว ระฆังจึงกลมทุกทิศ บรรทัดสุดท้ายใช้สูตร $\operatorname{Cov}(AR+a)=A\Sigma A^{\mathsf T}$ โดยแทน $A=L$ ส่วน $\mu$ เลื่อนตำแหน่ง $L$ ยืด หมุน และผสมการแกว่ง ความเป็น Gaussian มาจากการเลือก $Z$ เป็น Gaussian ตั้งแต่ต้น ไม่ได้มาจากการมี covariance matrix เพียงอย่างเดียว

สำหรับ density เต็มมิติ ต้องให้ $\Sigma$ เป็น symmetric positive definite จึงเลือก $L$ ที่ invertible ได้ เช่น Cholesky ที่เป็นสามเหลี่ยมล่าง ซึ่งการจำลอง MVN ด้วย Choleskyจะสร้างให้ละเอียด

ขั้นที่ 2 — ทำไมมี determinant อยู่ใต้ density

ถ้าอยากรู้ density ของ $R$ ที่จุด $r$ ให้ย้อนกลับไปหาว่าจุดนั้นมาจาก $z$ ไหน แล้วดูว่าบริเวณเล็ก ๆ รอบ $z$ ถูกยืดเป็นพื้นที่กี่เท่า probability ของบริเวณนั้นต้องเท่าเดิม เมื่อพื้นที่โตขึ้น density จึงต้องต่ำลงตามสัดส่วน

\[ \begin{aligned} z&=L^{-1}(r-\mu),\\ dr&=|\det L|\,dz,\\ \det\Sigma&=\det(LL^{\mathsf T})=(\det L)^2,\\ f_R(r)&=\frac{f_Z\big(L^{-1}(r-\mu)\big)}{|\det L|},\\ q(r)&:=z^{\mathsf T}z=(r-\mu)^{\mathsf T}\Sigma^{-1}(r-\mu),\\ f_R(r)&=\frac{e^{-q(r)/2}}{(2\pi)^{n/2}\sqrt{\det\Sigma}}. \end{aligned} \]

$dr$ กับ $dz$ หมายถึงปริมาตรย่อย $n$ มิติ (พื้นที่เมื่อ $n=2$) ไม่ใช่ระยะตามแกนเดียว บรรทัดที่ห้าใช้ $(L^{-1})^{\mathsf T}L^{-1}=(LL^{\mathsf T})^{-1}=\Sigma^{-1}$ ผลคือสูตร density ของ MVN ที่ใช้กันทั่วไป $q$ วัดความไกล ส่วน $\sqrt{\det\Sigma}$ ปรับความสูง ตรวจว่าพื้นที่รวมเป็น 1 ได้ด้วยการเปลี่ยนพิกัดกลับ: $\int f_R\,dr=\int f_Z\,dz=1$

ขั้นที่ 3 — ใส่ตัวเลขของแบบจำลอง SPX/QQQ ให้ครบก่อน

กำหนดผลตอบแทนหนึ่งวันสมมติ: SPX ค่าเฉลี่ย 0.04% SD 2% QQQ ค่าเฉลี่ย 0.03% SD 3% correlation 0.40 ตัวเลขเป็น parameter ของตัวอย่าง ไม่ใช่ค่าประมาณจากตลาดปัจจุบัน ใช้หน่วยทศนิยม

\[ \begin{aligned} \mu&=\begin{bmatrix}0.0004\\0.0003\end{bmatrix},\\ \Sigma_{12}&=(0.40)(0.02)(0.03)=0.00024,\\ \Sigma&=\begin{bmatrix}0.0004&0.00024\\0.00024&0.0009\end{bmatrix},\\ \det\Sigma&=(0.0004)(0.0009)-(0.00024)^2\\ &=3.024\times10^{-7},\\ \sqrt{\det\Sigma}&\approx0.000549909,\\ f_R(\mu)&=\frac1{2\pi\sqrt{\det\Sigma}}\approx289.42. \end{aligned} \]

ที่ $r=\mu$ ระยะ $q=0$ จึงเหลือแค่ตัวหาร ค่า 289 ดูใหญ่ แต่มันคือความสูงต่อหน่วยพื้นที่ทศนิยม² ซึ่งพื้นที่ $1\times1$ ในหน่วยนี้ใหญ่มากเมื่อเทียบกับผลตอบแทนรายวัน การใส่ correlation 0.40 ลงช่อง covariance ตรง ๆ แทน 0.00024 จะผิดทั้งขนาดและหน่วย

ตรวจ positive definiteness และหา inverse ด้วยมือ

ช่อง variance แรกเป็นบวกและ determinant เป็นบวก จึงเป็น PD สำหรับ symmetric 2×2 (eigenvalues และ positive definiteness) inverse ของ 2×2 คือสลับแนวทแยง เปลี่ยนเครื่องหมายนอกแนวทแยง แล้วหารด้วย determinant

\[ \begin{aligned} \Sigma^{-1}&=\frac1{3.024\times10^{-7}} \begin{bmatrix}0.0009&-0.00024\\-0.00024&0.0004\end{bmatrix}\\ &\approx\begin{bmatrix}2976.19&-793.65\\-793.65&1322.75\end{bmatrix}. \end{aligned} \]

ในโค้ดเราจะแก้สมการผ่าน $L$ แทนการสร้าง inverse เพราะต้องการแค่ $z$ และ $q$ เป็นวิธีคำนวณสูตรเดียวกันที่ปัดเศษน้อยกว่า

ขั้นที่ 4 — density 289 ไม่ได้แปลว่า probability เกิน 100%

โจทย์ให้อะไรมาบ้าง: แบบจำลอง SPX/QQQ ด้านบน หาโอกาสที่ผลตอบแทนทั้งสองตัวอยู่ห่างค่าเฉลี่ยไม่เกิน 0.1 จุดเปอร์เซ็นต์ (0.001 ในหน่วยทศนิยม) พร้อมกัน

บริเวณนี้คือสี่เหลี่ยมจัตุรัสด้าน 0.002 รอบ $\mu$ density แทบไม่เปลี่ยนภายในสี่เหลี่ยมเล็กขนาดนี้ จึงประมาณได้ด้วยความสูงที่ $\mu$ คูณพื้นที่

\[ \begin{aligned} \text{area}&=(0.002)^2=0.000004,\\ P&\approx f_R(\mu)\times\text{area}\\ &=289.42\times0.000004\\ &\approx0.001158=0.1158\%,\\ \text{integral}&\approx0.001157=0.1157\%. \end{aligned} \]

คำตอบ: ประมาณ 0.116% บรรทัดสุดท้ายคือการ integrate density บนสี่เหลี่ยมจริงด้วยตัวเลข ซึ่งต่ำกว่าเล็กน้อยเพราะ density ลดลงเมื่อห่างจากยอด โอกาสที่ผลตอบแทนจะเท่ากับ $\mu$ พอดีเป็นศูนย์ เพราะจุดเดียวไม่มีพื้นที่

ตรวจเองใน 10 วินาที: เปลี่ยนหน่วยแกนเป็นจุดเปอร์เซ็นต์ พื้นที่สี่เหลี่ยมโตขึ้น $100^2$ เท่าเป็น $0.2^2=0.04$ ส่วน density ลดลง $100^2$ เท่าเป็น 0.02894 ผลคูณ $0.04\times0.02894=0.001158$ เท่าเดิม probability ไม่ขึ้นกับหน่วย แต่ density ขึ้น

ขั้นที่ 5 — ทำไมขึ้นพร้อมกันกับสวนทางกันจึงไกลไม่เท่ากัน

เขียนคะแนนมาตรฐานรายตัว $s_i=(r_i-\mu_i)/\sigma_i$ ซึ่งยังสัมพันธ์กันด้วย $\rho$ แล้วกาง $q$ ของกรณีสองตัว

\[ \begin{aligned} \det\Sigma&=\sigma_1^2\sigma_2^2(1-\rho^2),\\ q&=\frac{s_1^2-2\rho s_1s_2+s_2^2}{1-\rho^2},\\ \rho=0.4,\ (1,\ 1):\ q&=\frac{1-0.8+1}{0.84}\approx1.43,\\ \rho=0.4,\ (1,\ -1):\ q&=\frac{1+0.8+1}{0.84}\approx3.33,\\ \frac{f_R(r)}{f_R(\mu)}&=e^{-q/2}. \end{aligned} \]

บรรทัดที่สองได้จากการเอา inverse ของ 2×2 คูณสองข้าง ตัวเศษคือหัวใจ: พจน์ $-2\rho s_1s_2$ เป็นลบเมื่อ $s_1,s_2$ เครื่องหมายเดียวกัน (ระยะสั้นลง) และเป็นบวกเมื่อเครื่องหมายตรงข้าม (ระยะยาวขึ้น) ตัวหาร $1-\rho^2$ ขยายทุกอย่างเมื่อ correlation สูง ทั้งสองจุดห่างค่าเฉลี่ย 1 SD ในแต่ละแกนเท่ากัน แต่ความสูงต่างกัน: $e^{-1.43/2}\approx0.490$ เทียบ $e^{-3.33/2}\approx0.189$ ของยอด หรือ 141.7 กับ 54.7 ในหน่วยทศนิยม

ถ้า $\rho=0$ จะได้ $q=s_1^2+s_2^2$ และ density แยกเป็นผลคูณของ density รายตัว ซึ่งคือเหตุผลที่ covariance ศูนย์แปลว่าอิสระเมื่อเป็น jointly Normal

ขั้นที่ 6 — whitening: วัดระยะด้วยวงกลมแทนวงรี

หา $q$ โดยไม่ต้องสร้าง inverse: เลือก $L$ เป็นสามเหลี่ยมล่าง แล้วแก้ $Lz=r-\mu$ ทีละแถว จาก $\Sigma=LL^{\mathsf T}$ ได้ $L_{11}=0.02$, $L_{21}=0.00024/0.02=0.012$ และ $L_{22}=\sqrt{0.0009-0.012^2}=\sqrt{0.000756}$

\[ \begin{aligned} L&=\begin{bmatrix}0.02&0\\0.012&\sqrt{0.000756}\end{bmatrix},\\ z_1&=\frac{r_1-0.0004}{0.02},\\ z_2&=\frac{r_2-0.0003-0.012\,z_1}{\sqrt{0.000756}},\\ q&=z_1^2+z_2^2. \end{aligned} \]

พจน์ $0.012\,z_1$ คือการหักส่วนที่ QQQ เคลื่อนตาม SPX ออกก่อน แล้วค่อยหารด้วย SD ของส่วนที่เหลือ นี่ต่างจากคะแนน $s_i$ ที่หารด้วย SD รายตัวเฉย ๆ เพราะ $z_1,z_2$ ไม่สัมพันธ์กันแล้ว ระยะจึงใช้พีทาโกรัสธรรมดาได้ ตัวอย่างเช่นวันที่ SPX ขึ้น 3% QQQ ลง 2% ได้ $z_1=1.48$, $z_2=(-0.0203-0.01776)/0.027495\approx-1.384$, $q\approx2.190+1.916=4.11$ และ density $289.42\,e^{-4.11/2}\approx37.1$ ถ้าคำนวณผ่าน $\Sigma^{-1}$ ในรายละเอียดด้านบนต้องได้ $q$ เท่ากัน ใช้ตรวจลำดับแกนและหน่วยได้

ขั้นที่ 7 — วงรีรัศมี 1 ครอบคลุมแค่ 39% ในสองมิติ

คนที่คุ้นกับ Normal ตัวแปรเดียวจะจำว่า ±1 SD ครอบคลุม 68% และ ±1.96 SD ครอบคลุม 95% แต่ในพิกัด whitened $Q=Z_1^2+Z_2^2$ และโอกาสอยู่ในวงกลมรัศมี $c$ หาได้ด้วย polar coordinates

\[ \begin{aligned} P(Q\le c^2)&=\int_0^{2\pi}\!\!\int_0^c\frac{e^{-u^2/2}}{2\pi}\,u\,du\,d\theta\\ &=\int_0^c u\,e^{-u^2/2}\,du\\ &=1-e^{-c^2/2},\\ c=1:\ \ &1-e^{-1/2}\approx39.35\%,\\ c=1.96:\ \ &1-e^{-1.9208}\approx85.35\%,\\ 95\%:\ \ c^2&=-2\ln0.05\approx5.991,\\ c&\approx2.448. \end{aligned} \]

ตัว $u$ ในอินทิกรัลคือพื้นที่ของวงแหวนบาง ๆ ใน polar coordinates ไม่ใช่ค่าคงที่ที่เติมเอง ยิ่งหลายมิติ ผลตอบแทนยิ่งมีโอกาสหลุดออกนอกวงในอย่างน้อยหนึ่งทิศ วงที่ครอบคลุม 95% จึงต้องใหญ่ขึ้นเป็น 2.45 สูตร $1-e^{-c^2/2}$ ใช้เฉพาะสองมิติ ถ้า $n$ มิติต้องใช้ distribution $\chi^2_n$ ในพิกัดเดิม วงรี 95% ของแบบจำลอง SPX/QQQ มีครึ่งแกนยาว $2.448\sqrt{\lambda_i}$ ตามแกน eigenvector คือประมาณ 7.73 กับ 4.26 จุดเปอร์เซ็นต์

วงรีนี้ครอบคลุมผลตอบแทนใหม่ 95% เมื่อแบบจำลองถูกและรู้ $\mu,\Sigma$ จริง ไม่ใช่ช่วงความเชื่อมั่นของค่าเฉลี่ย ถ้าประมาณ $\mu,\Sigma$ จากข้อมูลแล้วเอาข้อมูลชุดเดิมมาวัด ค่าที่ได้จะดูดีเกินจริง

ขั้นที่ 8 — ตอบคำถามเปิด: วันที่หุ้นคู่ correlation สูงสวนทางกัน

โจทย์ให้อะไรมาบ้าง: หุ้นสองตัวค่าเฉลี่ยศูนย์ SD 2% เท่ากัน correlation 0.82 joint Normal วันนี้ผลตอบแทน $(+3\%,\ -3\%)$ คะแนนมาตรฐานจึงเป็น $(1.5,\ -1.5)$

\[ \begin{aligned} -2\rho s_1s_2&=-2(0.82)(1.5)(-1.5)=3.69,\\ q&=\frac{2.25+3.69+2.25}{1-0.82^2}\\ &=\frac{8.19}{0.3276}=25,\qquad d=5,\\ P(Q\ge25)&=e^{-25/2}\approx3.73\times10^{-6},\\ 1/P&\approx268{,}000. \end{aligned} \]

คำตอบ: ตั้งธงได้ แบบจำลองให้โอกาสประมาณ 0.00037% ที่ผลตอบแทนจะไกลจากค่าเฉลี่ยอย่างน้อยเท่านี้ในทิศใดก็ตาม ถ้าตลาดเปิดปีละประมาณ 252 วัน นี่คือราวหนึ่งครั้งในหนึ่งพันปี ตัวเลขนี้ไม่ใช่โอกาสของจุด $(3\%,-3\%)$ ซึ่งเป็นศูนย์ และไม่ใช่โอกาสของทุกวันที่สองตัวสวนทางกัน

ตรวจเองใน 10 วินาที: ถ้าทั้งคู่ขึ้น 3% คะแนนเป็น $(1.5,\ 1.5)$ ได้ $q=(2.25-3.69+2.25)/0.3276\approx2.47$ และ $P(Q\ge2.47)=e^{-1.236}\approx29\%$ ขนาดของคะแนนรายตัวเท่ากัน แต่ทิศทางร่วมเปลี่ยนความหมายของระยะทั้งหมด

เหตุการณ์ที่แบบจำลองให้โอกาสต่ำขนาดนี้อาจเป็นวันที่หายากจริง หรือ parameter ผิด (correlation เปลี่ยน เช่นมีข่าวเฉพาะบริษัท) หรือข้อมูลผิด (ราคาไม่ได้ปรับ split) หรือ distribution จริงหางหนากว่า Normal ตัวเลขเดียวไม่บอกว่าเป็นสาเหตุไหน ต้องตรวจแยก

ขั้นที่ 9 — covariance singular: Gaussian ที่อยู่บนมิติต่ำกว่า

ให้ $R=(Z,\ Z)$ เมื่อ $Z$ เป็น standard Normal นี่เป็น Gaussian vector ที่ถูกต้อง แต่ covariance คือ $\begin{bmatrix}1&1\\1&1\end{bmatrix}$ ซึ่ง rank 1 และ determinant เป็นศูนย์ ผลลัพธ์ทุกครั้งอยู่บนเส้น $r_1=r_2$ เส้นนี้มีพื้นที่ศูนย์แต่มีโอกาสทั้งหมด จึงไม่มี density เทียบกับพื้นที่สองมิติ สูตรข้างบนหารด้วยศูนย์ ต้องทำงานในพิกัดบนเส้นนั้นแทน ไม่ใช่เปลี่ยน inverse เป็น pseudoinverse แล้วอ้างว่าได้ density

ในงานจริงเรื่องนี้เกิดเมื่อมีสินทรัพย์ซ้ำกัน (เช่น ETF กับดัชนีที่มันติดตาม) หรือเมื่อมีข้อมูลน้อยกว่าจำนวนสินทรัพย์ ส่วนในทางกลับกัน คู่ $X$ กับ $WX$ จากตัวอย่างเครื่องหมายสุ่มมี covariance เป็น identity ซึ่ง PD แต่ไม่ใช่ Gaussian เลย PD ทำให้สูตรใช้ได้ ไม่ได้พิสูจน์ว่าข้อมูลเป็น Gaussian

สิ่งที่ MVN ให้มาโดยไม่ต้องคำนวณใหม่

เพราะ MVN ทุกตัวคือ $\mu+LZ$ การทำอะไรเชิงเส้นกับมันก็ยังเป็น $\mu'+L'Z$ จึงยังเป็น MVN นี่ทำให้ได้ผลสำคัญสามข้อซึ่งหน้าถัด ๆ ไปจะพิสูจน์: marginal ของ MVN เป็น Normal โดยใช้ $\mu$ และ $\Sigma$ ส่วนที่เกี่ยวข้อง, conditional distribution ของบางส่วนเมื่อรู้อีกส่วนเป็น Normal และให้ hedge ratio, และ linear combination อย่างผลตอบแทนพอร์ตเป็น Normal ที่มี variance $w^{\mathsf T}\Sigma w$ เครื่องมือที่ทำให้พิสูจน์เรื่องเหล่านี้ได้สั้นที่สุดคือ moment generating function

ก่อนใช้ density หรือระยะตัดสินความเสี่ยง

  • marginal เป็น Normal ไม่ได้แปลว่า jointly Normal: ต้องดูหางร่วม เช่นวันที่หลายตัวลงหนักพร้อมกัน ซึ่งข้อมูลตลาดมักเกิดบ่อยกว่าที่ MVN ทำนาย
  • density ไม่ใช่ probability: density เปลี่ยนเมื่อเปลี่ยนหน่วย (289.42 ในหน่วยทศนิยม เป็น 0.02894 ในหน่วย %) probability ต้อง integrate บนบริเวณที่นิยามชัด
  • ใช้เกณฑ์ตัวแปรเดียวกับหลายตัว: รัศมี 1.96 ในสองมิติครอบคลุมแค่ 85.4% ต้องใช้ 2.45 สำหรับ 95% และยิ่งหลายมิติยิ่งต้องใหญ่ขึ้นตาม $\chi^2_n$
  • parameter ที่ประมาณมา: $q$ คำนวณได้ไม่ได้แปลว่าใช้ $\chi^2_n$ ได้ตรง ๆ เมื่อ $\mu,\Sigma$ ประมาณจากข้อมูลชุดเดียวกัน ระยะจะดูสั้นเกินจริง
  • density เล็กมากจนเป็นศูนย์ในเครื่อง: ใช้ log-density $-q/2-\ln\big((2\pi)^{n/2}\sqrt{\det\Sigma}\big)$ เวลาเทียบ likelihood ที่เล็กมาก

โจทย์ตรวจความเข้าใจ

1. เปลี่ยนหน่วยเป็น $U=100R$ (เลข 1 หมายถึง 1 จุดเปอร์เซ็นต์) mean, covariance, ความสูงที่ยอด และ $q$ ของจุดเดิมเปลี่ยนอย่างไร

เฉลย

mean คูณ 100 เป็น $(0.04,\ 0.03)$ covariance คูณ $100^2=10{,}000$ เป็น $\begin{bmatrix}4&2.4\\2.4&9\end{bmatrix}$ determinant คูณ $10^8$ รากของมันคูณ $10^4$ ความสูงที่ยอดจึงหารด้วย 10,000 เหลือ $289.42/10{,}000\approx0.02894$ ส่วน $q$ ของจุดเดียวกัน (เช่น $(3\%,-2\%)$) ยังเป็น 4.11 เพราะทั้ง $r-\mu$ และ $\Sigma^{-1}$ เปลี่ยนสเกลหักล้างกัน probability ของบริเวณเดิมจึงเท่าเดิม

2. ทีมหนึ่งตั้งธงผิดปกติเมื่อระยะ Mahalanobis ของผลตอบแทนสองสินทรัพย์เกิน 1.96 ธงจะขึ้นกี่เปอร์เซ็นต์ของวันถ้าแบบจำลองถูก ต้องใช้เกณฑ์เท่าไรจึงจะได้ 5%

เฉลย

โอกาสอยู่นอกรัศมี 1.96 คือ $e^{-1.96^2/2}=e^{-1.9208}\approx14.6\%$ ไม่ใช่ 5% ธงจะขึ้นเกือบสามเท่าของที่ตั้งใจ เกณฑ์ที่ถูกคือ $d\gt\sqrt{-2\ln0.05}\approx2.448$ หรือ $q\gt5.99$

3. คู่ $Y=WX$ เมื่อ $X$ เป็น standard Normal และ $W=\pm1$ อิสระ มี covariance เป็น identity จึงคำนวณ $Q=X^2+Y^2$ ได้ ใช้ $P(Q\le c^2)=1-e^{-c^2/2}$ กับคู่นี้ได้ไหม

เฉลย

ไม่ได้ เพราะ $Q=2X^2$ เสมอ จึงมี variance $4\operatorname{Var}(X^2)=4\times2=8$ ขณะที่ผลรวมกำลังสองของ standard Normal อิสระสองตัวมี variance $2+2=4$ ค่าเฉลี่ยเท่ากันคือ 2 แต่ distribution ต่างกัน เช่น $P(Q\le1)=P(X^2\le0.5)=2\Phi(0.707)-1\approx52\%$ ไม่ใช่ 39% การทำให้ covariance เป็น identity ไม่ได้สร้างความอิสระแบบ Gaussian ขึ้นมาเอง

// Normal สองตัวแปร: whitening ผ่าน L สามเหลี่ยมล่าง (ไม่สร้าง inverse)
function normal2(mu, S) {
  const s1 = Math.sqrt(S[0][0]), s2 = Math.sqrt(S[1][1]);
  const rho = S[0][1] / (s1 * s2);
  if (!(Math.abs(rho) < 1)) throw new RangeError('Need positive definite covariance');
  const L21 = rho * s2, L22 = s2 * Math.sqrt(1 - rho * rho);
  const logPeak = -Math.log(2 * Math.PI * s1 * L22);         // det L = s1 * L22
  const whiten = r => { const z1 = (r[0] - mu[0]) / s1;
    return [z1, (r[1] - mu[1] - L21 * z1) / L22]; };
  const q = r => whiten(r).reduce((s, z) => s + z * z, 0);
  const density = r => Math.exp(logPeak - q(r) / 2);
  return { whiten, q, density };
}
const mu = [0.0004, 0.0003], S = [[0.0004, 0.00024], [0.00024, 0.0009]];
const m = normal2(mu, S);
console.log(m.density(mu));                                  // 289.42
const sc = (a, b) => [mu[0] + 0.02 * a, mu[1] + 0.03 * b];
console.log(m.q(sc(1, 1)), m.q(sc(1, -1)));                  // 1.43 3.33
console.log(m.whiten([0.03, -0.02]), m.q([0.03, -0.02]));    // [1.48,-1.384] 4.11

// probability ของสี่เหลี่ยม ±0.001 รอบค่าเฉลี่ย (Simpson 2 มิติ)
function box(model, h = 0.001, n = 100) {
  const d = 2 * h / n, w = i => (i === 0 || i === n) ? 1 : (i % 2 ? 4 : 2);
  let s = 0;
  for (let i = 0; i <= n; i++) for (let j = 0; j <= n; j++)
    s += w(i) * w(j) * model.density([mu[0] - h + i * d, mu[1] - h + j * d]);
  return s * d * d / 9;
}
console.log(m.density(mu) * 0.002 ** 2, box(m));            // 0.001158 0.001157

// ความครอบคลุมในสองมิติ และคำถามเปิด
const cover = c => 1 - Math.exp(-c * c / 2);
console.log(cover(1), cover(1.96), Math.sqrt(-2 * Math.log(0.05)));   // .3935 .8535 2.448
const hook = normal2([0, 0], [[0.0004, 0.000328], [0.000328, 0.0004]]);
const qB = hook.q([0.03, -0.03]), qA = hook.q([0.03, 0.03]);
console.log(qB, Math.exp(-qB / 2), qA, Math.exp(-qA / 2));            // 25 3.7e-6 2.47 0.29

สิ่งที่ควรตอบได้หลังอ่าน

  • MVN คือ $\mu+LZ$ ของ standard Normal อิสระ มีค่าเฉลี่ย $\mu$ และ covariance $LL^{\mathsf T}=\Sigma$ density เต็มมิติต้องการ $\Sigma$ ที่ symmetric positive definite
  • density $e^{-q/2}/\big((2\pi)^{n/2}\sqrt{\det\Sigma}\big)$ มาจากการย้อนพิกัด: $q$ คือระยะ Mahalanobis ยกกำลังสอง และ $\sqrt{\det\Sigma}$ คือพื้นที่ที่สี่เหลี่ยมหน่วยถูกยืด
  • density ไม่ใช่ probability: ต้องคูณพื้นที่หรือ integrate และ density เปลี่ยนตามหน่วย แต่ probability ไม่เปลี่ยน
  • correlation ทำให้จุดที่ขึ้นลงตามกันอยู่ใกล้ และจุดที่สวนทางอยู่ไกล แม้คะแนนรายตัวเท่ากัน
  • ในสองมิติ วงรัศมี 1 ครอบคลุม 39.35% และต้องใช้ $q\le5.99$ ($d\le2.45$) สำหรับ 95% ไม่ใช่ 1.96

หน้าถัดไป moment generating function จะสร้างเครื่องมือที่เก็บทุก moment ไว้ในฟังก์ชันเดียว และใช้มันพิสูจน์ว่าทำไมราคาหุ้นเฉลี่ยในแบบจำลอง lognormal สูงกว่าราคาที่ได้จากผลตอบแทนเฉลี่ย
