6.3 Basis

Basis คือชุดแกนที่ไม่ซ้ำกันและไปถึงได้ทุกจุด พอร์ตทุกพอร์ตจึงเขียนเป็นพิกัดได้แบบเดียว การเปลี่ยนแกนเปลี่ยนแค่ตัวเลขที่ใช้บรรยาย ตัวพอร์ตไม่เปลี่ยน

ผู้จัดการกองทุนคนหนึ่งถือหุ้นสามตัวรวมกันเป็นพอร์ต (พอร์ตคือกลุ่มสินทรัพย์ทั้งหมดที่ถืออยู่) ตัวเลขทั้งหมดในหน้านี้เป็นตัวเลขสมมติ

  • AAPL (หุ้น Apple บริษัทเทคโนโลยี) มูลค่า \$6 ล้าน
  • JPM (หุ้น JPMorgan ซึ่งเป็นธนาคาร) มูลค่า \$5 ล้าน
  • XOM (หุ้น ExxonMobil บริษัทน้ำมัน) มูลค่า \$4 ล้าน

มูลค่ารวมจึงเป็น $6+5+4=15$ คือ \$15 ล้าน

ทีมวิเคราะห์ไม่ได้รายงานพอร์ตนี้เป็นรายหุ้น แต่รายงานเป็น “ตะกร้า” สามแบบ ตะกร้าแรกถือ AAPL กับ JPM เท่ากัน ตะกร้าที่สองถือ AAPL มากกว่า JPM ตะกร้าที่สามถือ XOM อย่างเดียว รายงานบอกว่าพอร์ตนี้คือตะกร้าแรก 5.5 หน่วย ตะกร้าที่สอง 0.5 หน่วย และตะกร้าที่สาม 4 หน่วย

หัวหน้าบวกตัวเลขในรายงานได้ $5.5+0.5+4=10$ จึงถามว่าเงินอีก \$5 ล้าน (มาจาก $15-10=5$) หายไปไหน

คำถามที่สองเรื่องผลตอบแทน ผลตอบแทน (return) คือเปอร์เซ็นต์ที่ราคาขยับในวันนั้น วันนี้ AAPL ขึ้น 1% JPM ลง 2% และ XOM ขึ้น 0.5% นักวิเคราะห์เอาสามตัวเลขนี้คูณกับ 5.5, 0.5, 4 ตรง ๆ เพื่อหา P&L ของวัน (กำไรหรือขาดทุนเป็นดอลลาร์) วิธีนี้ถูกไหม

ลองตอบก่อนเปิดเฉลย

ไม่มีเงินหาย ตัวเลขในรายงานคือ “จำนวนตะกร้า” ไม่ใช่ดอลลาร์ ตะกร้าแรกหนึ่งหน่วยถือ AAPL \$1 ล้านและ JPM \$1 ล้าน จึงมีมูลค่า \$2 ล้าน ตะกร้าที่สองหนึ่งหน่วยคือ long AAPL \$1 ล้าน (ซื้อหุ้นมาถือ) คู่กับ short JPM \$1 ล้าน (ยืมหุ้นมาขายก่อน) เงินที่จ่ายซื้อกับเงินที่ได้จากการขายหักกันพอดี มูลค่าสุทธิจึงเป็นศูนย์ ตะกร้าที่สามหนึ่งหน่วยถือ XOM \$1 ล้าน

แปลงกลับเป็นรายหุ้น และหามูลค่าสุทธิ $V$ (จำนวนตะกร้าคูณมูลค่าต่อตะกร้า แล้วรวมกัน) หน่วยเป็นล้านดอลลาร์

\[\begin{aligned}\text{AAPL}&=5.5+0.5=6,\\\text{JPM}&=5.5-0.5=5,\\\text{XOM}&=4,\\V&=2(5.5)+0(0.5)+1(4)=15.\end{aligned}\]

พอร์ตเหมือนเดิมทุกหุ้น และยังมีมูลค่า \$15 ล้าน

ส่วน P&L ของหุ้นหนึ่งตัวคือมูลค่าที่ถือคูณผลตอบแทน (1% เขียนเป็น 0.01) หน่วยเป็นล้านดอลลาร์ พอร์ตจริงจึงได้

\[6(0.01)+5(-0.02)+4(0.005)=-0.02\]

คือขาดทุน \$20,000 แต่ถ้าคูณตัวเลขในรายงานกับผลตอบแทนรายหุ้นตรง ๆ จะได้

\[5.5(0.01)+0.5(-0.02)+4(0.005)=0.065\]

คือกำไร \$65,000 ผิดทั้งขนาดและทิศ เพราะเอาผลตอบแทนของ AAPL หุ้นตัวเดียว ไปคูณกับจำนวนตะกร้าที่มีสองหุ้น ต้องแปลงผลตอบแทนให้เป็นของแต่ละตะกร้าก่อน หน้านี้จะแสดงวิธีแปลงด้านล่าง

ภาพรวมก่อนลงสูตร

ลองนึกถึงจุดหนึ่งในห้อง เราบอกตำแหน่งจุดด้วยระยะตามผนังสามด้าน ได้ตัวเลขสามตัว ถ้าหมุนแกนวัดไป จุดเดิมจะได้ตัวเลขชุดใหม่ ทั้งที่จุดไม่ได้ขยับเลย พอร์ตก็เหมือนกัน ตัวเลข $(6,5,4)$ คือพิกัดของพอร์ตเทียบกับแกนที่เราใช้โดยไม่ได้คิด คือหนึ่งแกนต่อหนึ่งหุ้น

ตะกร้าในรายงานของทีมวิเคราะห์ก็คือแกนชุดใหม่ แกนหนึ่งคือ “ถือ AAPL กับ JPM เท่ากัน” อีกแกนคือ “ถือ AAPL มากกว่า JPM” พอร์ตยังเป็นจุดเดิม สิ่งที่เปลี่ยนคือเส้นทางที่เดินไปถึงจุดนั้น ชุดแกนที่ใช้เป็นระบบพิกัดได้เรียกว่า basis ระยะที่เดินตามแต่ละแกนเรียกว่า coordinates หรือพิกัด

แกนชุดหนึ่งจะเป็น basis ได้ต้องผ่านสองเงื่อนไขจากหน้า linear independence และ linear combinations ข้อแรกคือ span ครบ แปลว่าผสมแกนแล้วไปถึงได้ทุกพอร์ต ข้อสองคือ independent แปลว่าไม่มีแกนไหนสร้างได้จากแกนอื่น พอร์ตหนึ่งจึงมีทางเดินแบบเดียว ถ้าผ่านทั้งสองข้อ การเปลี่ยนแกนย้อนกลับได้เสมอ ไม่มีเงินหรือข้อมูลหาย

หน้านี้จะทำทีละขั้น ดังนี้

  • หาพิกัดใหม่ แล้วแสดงว่าพิกัดมีชุดเดียว
  • เขียนการแปลงไปและกลับเป็น matrix
  • อธิบายว่าทำไมผลรวมพิกัดไม่ใช่มูลค่าพอร์ต
  • แปลงผลตอบแทนให้เข้าคู่กับพิกัดใหม่ เพื่อให้ P&L เท่าเดิม
  • ดูทางลัดที่ได้เมื่อแกนตั้งฉากกัน
  • แยก “เปลี่ยนแกน” ออกจาก “ตัดแกนทิ้ง”
ศัพท์ที่ใช้ในหัวข้อนี้
Basis
ชุดแกน (vector) ที่ใช้เป็นระบบพิกัดได้ ต้อง span ครบและ independent เช่น แกนรายหุ้น แกนตะกร้า หรือแกน factor
Span ครบ
ผสมแกนด้วยตัวคูณต่าง ๆ แล้วไปถึงได้ทุกจุดในพื้นที่ที่สนใจ อธิบายเต็มในหน้า linear independence และ linear combinations
Independent
ไม่มีแกนไหนสร้างได้จากการผสมแกนอื่น วิธีเดียวที่ผสมแกนแล้วได้ศูนย์ คือคูณทุกแกนด้วยศูนย์
Coordinates (พิกัด)
ตัวเลขที่คูณแต่ละแกนใน basis แล้วรวมกันได้ vector เดิม ต้องอ่านคู่กับ basis เสมอ เพราะพิกัดมีความหมายตามแกนที่มันคูณ
Standard basis
แกนที่มีเลข 1 ในช่องเดียว ช่องอื่นเป็น 0 เขียนว่า $\mathbf e_1,\mathbf e_2,\ldots$ พิกัดเทียบกับมันคือตัวเลขในแต่ละช่องตรง ๆ จึงเหมาะกับการส่งคำสั่งซื้อขายรายหุ้น
Change of basis
การแปลงพิกัดจาก basis หนึ่งไปอีก basis หนึ่ง ย้อนกลับได้ ไม่ใช่การซื้อขาย ข้อมูลไม่เพิ่มและไม่ลด
Dimension
จำนวนแกนใน basis ของพื้นที่นั้น ทุก basis ของพื้นที่เดียวกันมีจำนวนแกนเท่ากัน มันบอกว่าต้องใช้ตัวเลขกี่ตัวจึงบรรยายได้ครบ
Orthogonal และ orthonormal basis
basis ที่แกนทุกคู่ตั้งฉากกัน คือ dot product ของแต่ละคู่เป็นศูนย์ ถ้าทุกแกนยาวหนึ่งด้วยเรียกว่า orthonormal แกนแบบนี้หาพิกัดได้ด้วย dot product โดยไม่ต้องแก้สมการ
Long และ short
long คือซื้อหุ้นมาถือ ได้กำไรเมื่อราคาขึ้น short คือยืมหุ้นมาขายก่อนแล้วซื้อคืนทีหลัง ได้กำไรเมื่อราคาลง ในหน้านี้ short เขียนเป็นจำนวนติดลบ
ผลตอบแทนและ P&L
ผลตอบแทน (return) คือเปอร์เซ็นต์ที่ราคาขยับในช่วงหนึ่ง P&L (profit and loss) คือกำไรหรือขาดทุนเป็นดอลลาร์ P&L ของหุ้นหนึ่งตัวคือมูลค่าที่ถือคูณผลตอบแทน
Residual
ส่วนที่เหลือ ในหน้านี้คือส่วนของพอร์ตที่หายไปเมื่อทิ้งพิกัดบางตัว
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$\mathbf x=(x_A,x_J,x_X)$มูลค่าที่ถือ AAPL, JPM, XOM (ติดลบคือ short)ล้านดอลลาร์
$\mathbf e_1,\mathbf e_2,\mathbf e_3$แกนรายหุ้น (standard basis)ล้านดอลลาร์ต่อหนึ่งหน่วยพิกัด
$\mathbf b_1,\mathbf b_2,\mathbf b_3$แกนใหม่: common (ถือ AAPL กับ JPM เท่ากัน), relative (ถือ AAPL มากกว่า JPM) และ XOMล้านดอลลาร์ต่อหนึ่งหน่วยพิกัด
$\mathbf c=(c_1,c_2,c_3)$พิกัดของพอร์ตเทียบกับแกนใหม่ คือจำนวนหน่วยของแต่ละแกนหน่วยของแต่ละแกน
$B$matrix ที่วางแกนใหม่เป็นคอลัมน์—
$V$มูลค่าสุทธิของพอร์ตล้านดอลลาร์
$\mathbf r=(r_A,r_J,r_X)$ผลตอบแทนรายหุ้นของวันนี้เศษส่วน (0.01 คือ 1%)
$\mathbf g$P&L ต่อหนึ่งหน่วยของแต่ละแกนใหม่ล้านดอลลาร์ต่อหน่วย
$\hat{\mathbf x}$, $\boldsymbol\varepsilon$พอร์ตที่สร้างกลับหลังทิ้งพิกัด และ residual ที่หายไปล้านดอลลาร์

ขั้นที่ 1 — basis ที่ใช้อยู่แล้วโดยไม่รู้ตัว

ก่อนจะเปลี่ยนแกน ต้องเห็นก่อนว่าตัวเลข $(6,5,4)$ เองก็เป็นพิกัดเทียบกับแกนชุดหนึ่งอยู่แล้ว ช่องที่หนึ่ง สอง สาม คือ AAPL, JPM, XOM หน่วยเป็นล้านดอลลาร์ แกนชุดนี้เขียนว่า $\mathbf e_1,\mathbf e_2,\mathbf e_3$

\[ \begin{aligned} \mathbf e_1&=\begin{bmatrix}1\\0\\0\end{bmatrix},\ \mathbf e_2=\begin{bmatrix}0\\1\\0\end{bmatrix},\ \mathbf e_3=\begin{bmatrix}0\\0\\1\end{bmatrix},\\ \mathbf x&=6\mathbf e_1+5\mathbf e_2+4\mathbf e_3 =\begin{bmatrix}6\\5\\4\end{bmatrix}. \end{aligned} \]

แกน $\mathbf e_1$ แปลว่า “ถือ AAPL \$1 ล้าน ไม่ถือหุ้นอื่น” พอร์ตจึงเป็น $\mathbf e_1$ 6 หน่วย บวก $\mathbf e_2$ 5 หน่วย บวก $\mathbf e_3$ 4 หน่วย พิกัดเทียบกับ standard basis จึงเป็นตัวเลขในช่องตรง ๆ เราไม่เคยต้องคิดถึงแกนชุดนี้ เพราะมันตรงกับวิธีส่งคำสั่งซื้อขาย ซึ่งสั่งเป็นรายหุ้น

แต่ถ้าคำถามคือ “พอร์ตนี้เดิมพันว่า AAPL กับ JPM จะขึ้นลงไปด้วยกันแค่ไหน และเดิมพันว่า AAPL จะชนะ JPM แค่ไหน” แกนรายหุ้นตอบตรง ๆ ไม่ได้ เราจึงอยากได้แกนชุดใหม่ ตารางด้านล่างคือสามแกนที่ทีมวิเคราะห์ใช้ แต่ละแกนคือตะกร้าหุ้นหนึ่งแบบ แกน common วัดส่วนที่สองหุ้นขยับไปด้วยกัน แกน relative วัดว่าหุ้นหนึ่งชนะอีกหุ้นแค่ไหน มูลค่าสุทธิในตารางคือเงินที่ long ลบเงินที่ short

แกนใหม่หนึ่งหน่วยพิกัดคือมูลค่าสุทธิต่อหน่วย
$\mathbf b_1=(1,1,0)$ commonlong AAPL \$1 ล้าน และ long JPM \$1 ล้าน$1+1=2$ คือ \$2 ล้าน
$\mathbf b_2=(1,-1,0)$ relativelong AAPL \$1 ล้าน และ short JPM \$1 ล้าน$1-1=0$ คือศูนย์
$\mathbf b_3=(0,0,1)$ XOMlong XOM \$1 ล้าน\$1 ล้าน

ขั้นที่ 2 — สองเงื่อนไขของ basis: มีคำตอบ และมีคำตอบเดียว

แกนชุดใหม่ต้องทำได้สองอย่าง อย่างแรกคือบรรยายได้ทุกพอร์ต อย่างที่สองคือบรรยายได้แบบเดียว ถ้าพอร์ตเดียวบรรยายได้สองแบบ สองรายงานอาจให้ตัวเลขต่างกันสำหรับพอร์ตเดียวกัน แล้วไม่มีใครบอกได้ว่าอันไหนถูก ขั้นนี้แสดงว่า “บรรยายได้แบบเดียว” มาจาก independence พอดี วิธีพิสูจน์คือสมมติว่าพอร์ตเดียวมีพิกัดสองชุด คือ $\mathbf c=(c_1,c_2,c_3)$ และ $\mathbf d=(d_1,d_2,d_3)$ แล้วดูว่าเกิดอะไรขึ้น

\[ \begin{aligned} \sum_i c_i\mathbf b_i&=\sum_i d_i\mathbf b_i,\\ \sum_i(c_i-d_i)\,\mathbf b_i&=\mathbf 0,\\ c_i-d_i&=0,\quad i=1,2,3. \end{aligned} \]

ถ้าพอร์ตเดียวมีสองคำบรรยาย เอามาลบกันจะได้การผสมแกนที่ให้ผลเป็นศูนย์ โดยตัวคูณของแกนที่ $i$ คือ $c_i-d_i$ ตรงนี้คือจุดสำคัญ: independent แปลว่าวิธีเดียวที่ผสมแกนแล้วได้ศูนย์ คือคูณทุกแกนด้วยศูนย์ (นิยามจากหน้า linear independence) จึงได้ $c_i=d_i$ ทุกตัว พิกัดสองชุดนั้นคือชุดเดียวกัน

ส่วน “บรรยายได้ทุกพอร์ต” คือนิยามของ span ครบโดยตรง ถ้าขาด span จะมีพอร์ตที่เขียนด้วยแกนชุดนี้ไม่ได้ ถ้าขาด independence จะมีพอร์ตที่เขียนได้หลายแบบ

ผลที่ตามมาคือ ทุก basis ของพื้นที่สามมิติมีสามแกนพอดี ถ้ามีแค่สองแกน ผสมกันได้อย่างมากแค่ระนาบ เพราะ rank ไม่เกินจำนวนแกน ถ้ามีสี่แกน rank ก็ยังได้อย่างมาก 3 จึงต้องมีแกนหนึ่งที่สร้างได้จากแกนอื่น ด้วยเหตุนี้ กองทุน A กับ B ในหน้า linear combinations เป็น basis ของระนาบที่สองกองนั้นสร้างได้ แต่ไม่ใช่ basis ของทั้งสามมิติ

ดังนั้นทุกครั้งที่พูดถึง basis ต้องบอกว่าเป็น basis ของพื้นที่ไหน ตัวอย่างหนึ่งคือ range ของ matrix ซึ่งคือทุก vector ที่ได้จากการผสมคอลัมน์ของมัน จำนวนแกนใน basis ของ range คือ rank ของ matrix นั้น

ขั้นที่ 3 — หาพิกัดใหม่ แล้วคูณกลับเพื่อพิสูจน์

ตอนนี้แกนพร้อมแล้ว เราต้องการพิกัด $c_1,c_2,c_3$ ที่ทำให้ $\mathbf x=c_1\mathbf b_1+c_2\mathbf b_2+c_3\mathbf b_3$ ทั้งสองข้างเป็น vector สามช่อง เทียบทีละช่องจึงได้สามสมการ ช่อง AAPL ($x_A$) ได้จาก $\mathbf b_1$ และ $\mathbf b_2$ บวกกัน ช่อง JPM ($x_J$) ได้จาก $\mathbf b_1$ ลบ $\mathbf b_2$ ช่อง XOM ($x_X$) ได้จาก $\mathbf b_3$ อย่างเดียว

\[ \begin{aligned} c_1+c_2&=x_A,\\ c_1-c_2&=x_J,\\ c_3&=x_X,\\ c_1&=\frac{x_A+x_J}{2}=\frac{6+5}{2}=5.5,\\ c_2&=\frac{x_A-x_J}{2}=\frac{6-5}{2}=0.5,\\ c_3&=4. \end{aligned} \]

สมการสองข้อแรกแก้ง่าย เพราะบวกกันแล้ว $c_2$ หายไป ได้ $2c_1=x_A+x_J$ ส่วนลบกันแล้ว $c_1$ หายไป ได้ $2c_2=x_A-x_J$ ความหมายคือ common เป็นค่าเฉลี่ยของสองหุ้น ส่วน relative เป็นครึ่งหนึ่งของผลต่าง สูตรนี้ใช้ได้กับทุกพอร์ต (span ครบ) และให้คำตอบเดียว (independent)

ตรวจกลับด้วยการคูณแกนด้วยพิกัดแล้วรวมกัน: $5.5(1,1,0)+0.5(1,-1,0)+4(0,0,1)=(6,5,4)$ ตรงทุกช่อง

ถ้าต้องเขียนสามสมการแบบนี้ทุกครั้งจะยุ่งเกินไป ทางที่สั้นกว่าคือวางแกนใหม่เป็น คอลัมน์ ของ matrix $B$ การคูณกลับจะเป็น $\mathbf x=B\mathbf c$ และการหาพิกัดคือการคูณด้วย inverse $B^{-1}$

\[ \begin{aligned} B&=\begin{bmatrix}1&1&0\\1&-1&0\\0&0&1\end{bmatrix},\quad \mathbf x=B\mathbf c,\\ B^{-1}&=\begin{bmatrix}\tfrac12&\tfrac12&0\\\tfrac12&-\tfrac12&0\\0&0&1\end{bmatrix},\quad \mathbf c=B^{-1}\mathbf x,\\ \det B&=\bigl(1(-1)-1(1)\bigr)(1)=-2. \end{aligned} \]

ทำไมต้องวางเป็นคอลัมน์: $B\mathbf c$ คือการผสมคอลัมน์ของ $B$ โดยใช้ $\mathbf c$ เป็นตัวคูณ ซึ่งก็คือ $c_1\mathbf b_1+c_2\mathbf b_2+c_3\mathbf b_3$ พอดี (มุมมองคอลัมน์จากหน้า row และ column vectors) ส่วนแถวของ $B^{-1}$ อ่านได้จากสูตรที่เพิ่งแก้ แถวแรกหาค่าเฉลี่ยของ AAPL กับ JPM แถวสองหาครึ่งหนึ่งของผลต่าง แถวสามเก็บ XOM ไว้ตามเดิม

ตรวจว่า $B^{-1}$ ถูกด้วยการคูณ $B^{-1}B$ แถวแรกคูณคอลัมน์แรกได้ $\tfrac12+\tfrac12=1$ แถวแรกคูณคอลัมน์สองได้ $\tfrac12-\tfrac12=0$ ทำครบทุกช่องได้ identity $I$ ทำไม inverse ต้องมีอยู่: matrix จัตุรัสที่คอลัมน์ independent (rank เต็ม) มี inverse เสมอ อีกวิธีตรวจคือดูว่า determinant ไม่เป็นศูนย์ $B$ แยกได้เป็นมุมบนซ้ายขนาด $2\times2$ กับเลข 1 ของช่อง XOM determinant จึงเป็น determinant ของมุมบนซ้ายคูณ 1 ได้ $-2$ ซึ่งไม่ใช่ศูนย์

ขั้นที่ 4 — ทำไมพิกัดรวมได้ 10 แต่พอร์ตมี 15 ล้าน

หัวหน้าในตัวอย่างต้นหน้าบวกพิกัดเหมือนเป็นเงิน แต่พิกัดแต่ละตัวมีหน่วยเป็น “จำนวนหน่วยของแกนนั้น” ไม่ใช่ดอลลาร์ จึงต้องแปลงพิกัดแต่ละตัวเป็นเงินก่อนรวม โดยคูณกับมูลค่าสุทธิของแกนนั้นหนึ่งหน่วย ส่วนท้ายของสูตรด้านล่างลองย่อแกน common ลงครึ่งหนึ่ง เพื่อให้เห็นว่าตัวเลขพิกัดขึ้นกับขนาดของแกน

โจทย์ให้อะไรมาบ้าง: พิกัดของพอร์ต และมูลค่าต่อหนึ่งหน่วยของแต่ละแกน จากตารางแกนใหม่ด้านบน

  • พิกัด $\mathbf c=(5.5,\,0.5,\,4)$
  • common หนึ่งหน่วยมีมูลค่าสุทธิ \$2 ล้าน
  • relative หนึ่งหน่วยมีมูลค่าสุทธิศูนย์
  • XOM หนึ่งหน่วยมีมูลค่า \$1 ล้าน
\[ \begin{aligned} V&=2c_1+0\,c_2+1\,c_3\\ &=2(5.5)+0+4=15,\\ c_1+c_2+c_3&=5.5+0.5+4=10,\\ \tilde{\mathbf b}_1&=\tfrac12\mathbf b_1=(0.5,\,0.5,\,0),\\ 5.5\,\mathbf b_1&=11\,\tilde{\mathbf b}_1. \end{aligned} \]

คำตอบ: มูลค่าสุทธิยังเป็น \$15 ล้าน ไม่มีเงินหาย ผลรวม 10 ผิดเพราะนับ common เป็น 5.5 ทั้งที่ common หนึ่งหน่วยมีสองขา คือ AAPL \$1 ล้านกับ JPM \$1 ล้าน

อีกทางที่เห็นเรื่องนี้ชัด คือย่อแกน common ลงครึ่งหนึ่ง ให้หนึ่งหน่วยมีมูลค่า \$1 ล้าน แกนที่ย่อแล้วเขียนว่า $\tilde{\mathbf b}_1$ คือถือ AAPL กับ JPM อย่างละ \$0.5 ล้าน แกนเล็กลงครึ่งหนึ่ง พิกัดจึงต้องเพิ่มเป็น $5.5\times2=11$ จึงได้พอร์ตเดิมเป๊ะ ตัวเลขพิกัดใหญ่ขึ้นสองเท่าเพราะขนาดแกนเปลี่ยน ไม่ได้ซื้ออะไรเพิ่ม

ตรวจเองใน 10 วินาที: กับแกน $\tilde{\mathbf b}_1$ พิกัดคือ $(11,\,0.5,\,4)$ และ common หนึ่งหน่วยมีค่า \$1 ล้าน มูลค่าจึงเป็น $1(11)+0(0.5)+1(4)=15$ ตรงกัน

ขั้นที่ 5 — P&L ต้องเท่าเดิม ถ้าแปลงผลตอบแทนให้เข้าคู่กับพิกัด

พอร์ตเดียวกันต้องมี P&L เท่ากัน ไม่ว่าจะบรรยายด้วยแกนไหน ปัญหาคือ dot product ต้องจับของที่คู่กันมาคูณกัน มูลค่ารายหุ้นคู่กับผลตอบแทนรายหุ้น ส่วนพิกัดใหม่ต้องคู่กับ “P&L ต่อหนึ่งหน่วยของแกนใหม่” ขั้นนี้หาตัวนั้น

ผลตอบแทนของวันนี้ (ตัวเลขสมมติ) เขียนเป็นเศษส่วน

  • AAPL ขึ้น 1% คือ $r_A=0.01$
  • JPM ลง 2% คือ $r_J=-0.02$
  • XOM ขึ้น 0.5% คือ $r_X=0.005$

P&L ของหุ้นหนึ่งตัวคือมูลค่าที่ถือคูณผลตอบแทน รวมทั้งพอร์ตจึงเป็น dot product $\mathbf x^{\mathsf T}\mathbf r$ หน่วยเป็นล้านดอลลาร์

\[ \begin{aligned} \mathbf x^{\mathsf T}\mathbf r&=6(0.01)+5(-0.02)+4(0.005)\\ &=0.06-0.10+0.02=-0.02,\\ \mathbf x^{\mathsf T}\mathbf r&=(B\mathbf c)^{\mathsf T}\mathbf r =\mathbf c^{\mathsf T}(B^{\mathsf T}\mathbf r),\\ \mathbf g=B^{\mathsf T}\mathbf r&=\begin{bmatrix}r_A+r_J\\r_A-r_J\\r_X\end{bmatrix} =\begin{bmatrix}-0.01\\0.03\\0.005\end{bmatrix},\\ \mathbf c^{\mathsf T}\mathbf g&=5.5(-0.01)+0.5(0.03)+4(0.005)\\ &=-0.055+0.015+0.02=-0.02. \end{aligned} \]

ทั้งสองวิธีได้ $-0.02$ ล้าน คือขาดทุน \$20,000 เท่ากัน ท่าที่ทำให้สองวิธีตรงกันคือแทน $\mathbf x=B\mathbf c$ แล้วใช้กฎ transpose ของผลคูณ $(B\mathbf c)^{\mathsf T}=\mathbf c^{\mathsf T}B^{\mathsf T}$ (transpose แล้วลำดับสลับ) จากนั้นจับ $B^{\mathsf T}\mathbf r$ เป็นก้อนเดียว ตั้งชื่อว่า $\mathbf g$

แต่ละช่องของ $\mathbf g$ คือ dot product ของแกนหนึ่งกับผลตอบแทน ซึ่งก็คือ P&L ของแกนนั้นหนึ่งหน่วย common หนึ่งหน่วยถือ AAPL กับ JPM อย่างละ \$1 ล้าน จึงได้ $r_A+r_J=0.01-0.02=-0.01$ ล้าน relative หนึ่งหน่วย long AAPL และ short JPM จึงได้ $r_A-r_J=0.01+0.02=0.03$ ล้าน

ถ้าคูณ $\mathbf c$ กับ $\mathbf r$ ตรง ๆ จะได้ $5.5(0.01)+0.5(-0.02)+4(0.005)=0.065$ คือกำไร \$65,000 ผิดทั้งขนาดและทิศ เพราะเอาผลตอบแทนของ AAPL ตัวเดียว ไปคูณจำนวนตะกร้า common ที่มีสองหุ้น

สังเกตว่าผลตอบแทนแปลงด้วย $B^{\mathsf T}$ แต่พิกัดแปลงด้วย $B^{-1}$ ของสองอย่างนี้แปลงคนละแบบ เพื่อให้ผลคูณของมันเท่าเดิม เพราะ $(B^{-1})^{\mathsf T}B^{\mathsf T}=(BB^{-1})^{\mathsf T}=I$ สองการแปลงจึงหักล้างกันพอดี

ขั้นที่ 6 — basis ที่ตั้งฉากกันหาพิกัดได้ด้วย dot product

ตอนหาพิกัดด้านบน เราต้องแก้สมการ แต่แกนชุดนี้มีสมบัติพิเศษ คือตั้งฉากกันทุกคู่ ตรวจได้ด้วย dot product: $\mathbf b_1^{\mathsf T}\mathbf b_2=1(1)+1(-1)+0(0)=0$ ส่วน $\mathbf b_3$ ตั้งฉากกับอีกสองแกน เพราะช่องที่ไม่เป็นศูนย์ของมัน (ช่อง XOM) ไม่ทับกับช่องของแกนอื่นเลย สมบัตินี้ให้ทางลัด: ถ้าเอาพอร์ตไป dot กับแกนหนึ่ง พจน์ของแกนอื่นจะเป็นศูนย์หมด ในสูตรด้านล่าง $\mathbf b_k$ คือแกนที่ $k$ ที่เราอยากรู้พิกัด

\[ \begin{aligned} \mathbf b_k^{\mathsf T}\mathbf x&=\sum_i c_i\,\mathbf b_k^{\mathsf T}\mathbf b_i =c_k\,\mathbf b_k^{\mathsf T}\mathbf b_k,\\ c_k&=\frac{\mathbf b_k^{\mathsf T}\mathbf x}{\mathbf b_k^{\mathsf T}\mathbf b_k},\\ c_1&=\frac{6+5}{2}=5.5,\quad c_2=\frac{6-5}{2}=0.5,\\ B^{\mathsf T}B&=\begin{bmatrix}2&0&0\\0&2&0\\0&0&1\end{bmatrix}. \end{aligned} \]

ไอเดียคือเอา $\mathbf b_k$ ไป dot กับ $\mathbf x=\sum_ic_i\mathbf b_i$ ทุกพจน์ที่ $i\ne k$ เป็นศูนย์เพราะแกนตั้งฉากกัน จึงเหลือพจน์เดียว คือ $c_k$ คูณความยาวกำลังสองของแกน หารด้วยความยาวกำลังสองก็ได้พิกัด ไม่ต้องแก้ระบบสมการ ตัวอย่างเช่น $\mathbf b_1^{\mathsf T}\mathbf x=6+5=11$ และ $\mathbf b_1^{\mathsf T}\mathbf b_1=1^2+1^2=2$ จึงได้ $c_1=11/2=5.5$

$B^{\mathsf T}B$ บอกเรื่องเดียวกันในรูป matrix ช่องแถว $k$ คอลัมน์ $i$ ของมันคือ $\mathbf b_k^{\mathsf T}\mathbf b_i$ ช่องนอกแนวทแยงจึงเป็นศูนย์ ช่องบนแนวทแยงคือความยาวกำลังสอง 2, 2, 1 แต่มันยังไม่ใช่ $I$ เพราะ $\mathbf b_1,\mathbf b_2$ ยาว $\sqrt{1^2+1^2}=\sqrt2$ ไม่ใช่ 1 ดังนั้น $B^{-1}\ne B^{\mathsf T}$ ถ้าเอา $B^{\mathsf T}\mathbf x=(6+5,\,6-5,\,4)=(11,1,4)$ มาใช้เป็นพิกัด สองช่องแรกจะใหญ่เกินไปสองเท่า

ถ้าหารแต่ละแกนด้วยความยาวของมัน จะได้แกนที่ยาวหนึ่ง $\mathbf q_1=(1,1,0)/\sqrt2$, $\mathbf q_2=(1,-1,0)/\sqrt2$, $\mathbf q_3=\mathbf b_3$ ชุดนี้เป็น orthonormal วาง $\mathbf q$ เป็นคอลัมน์ของ $Q$ จะได้ $Q^{\mathsf T}Q=I$ และ $Q^{-1}=Q^{\mathsf T}$ คือหาพิกัดได้ด้วยการ transpose อย่างเดียว ทางลัดนี้ใช้ไม่ได้กับแกนที่ไม่ตั้งฉาก ดังรูปถัดไป การวัดส่วนที่อยู่ตามแกนด้วย dot product แบบนี้เรียกว่า projection ซึ่งดูต่อได้ในหน้า inner product, angle และ correlation

ขั้นที่ 7 — เปลี่ยนแกนไม่ใช่ตัดแกนทิ้ง

รายงานที่อยากสั้นลงมักทิ้งพิกัดที่ดูเล็ก เช่น relative 0.5 หน่วย ขั้นนี้วัดว่าการทิ้งพิกัดหนึ่งตัวเปลี่ยนพอร์ตไปเท่าไร และเปลี่ยน P&L ของวันนี้ไปเท่าไร

โจทย์ให้อะไรมาบ้าง: พอร์ตจริง พิกัด และผลตอบแทนชุดเดิม

  • พอร์ตจริง $\mathbf x=(6,\,5,\,4)$ มีพิกัด $(5.5,\,0.5,\,4)$
  • รายงานตั้ง $c_2=0$ แล้วสร้างพอร์ตกลับ เรียกพอร์ตที่ได้ว่า $\hat{\mathbf x}$
  • ผลตอบแทนวันนี้ $\mathbf r=(0.01,\,-0.02,\,0.005)$
  • P&L ของพอร์ตจริงจากขั้นที่แล้ว คือ $\mathbf x^{\mathsf T}\mathbf r=-0.02$ ล้าน

ส่วนที่หายไปเรียกว่า residual เขียนว่า $\boldsymbol\varepsilon=\mathbf x-\hat{\mathbf x}$ เพราะ $\hat{\mathbf x}=\mathbf x-\boldsymbol\varepsilon$ P&L ของพอร์ตที่สร้างกลับจึงเท่ากับ P&L จริงลบ P&L ของ residual

\[ \begin{aligned} \hat{\mathbf x}&=5.5\mathbf b_1+0\,\mathbf b_2+4\mathbf b_3 =(5.5,\,5.5,\,4),\\ \boldsymbol\varepsilon&=\mathbf x-\hat{\mathbf x}=(0.5,\,-0.5,\,0),\\ \boldsymbol\varepsilon^{\mathsf T}\mathbf r&=0.5(0.01)-0.5(-0.02)=0.015,\\ \hat{\mathbf x}^{\mathsf T}\mathbf r&=\mathbf x^{\mathsf T}\mathbf r-\boldsymbol\varepsilon^{\mathsf T}\mathbf r\\ &=-0.02-0.015=-0.035. \end{aligned} \]

คำตอบ: พอร์ตที่ทิ้ง relative ขาดทุน \$35,000 ในวันเดียวกัน ส่วนพอร์ตจริงขาดทุน \$20,000 ต่างกัน $35{,}000-20{,}000=\$15{,}000$ ทั้งที่มูลค่าเริ่มต้นเท่ากัน คือ $5.5+5.5+4=15$ ล้าน ถ้าคิดตรงจาก $\hat{\mathbf x}$ ก็ได้ผลเดียวกัน คือ $5.5(0.01)+5.5(-0.02)+4(0.005)=-0.035$ ส่วนต่างทั้งหมดมาจาก residual $\boldsymbol\varepsilon$ ซึ่งคือข้อมูลที่หายไปพร้อมพิกัดที่ทิ้ง

basis เต็มของสามมิติมีสามพิกัด การเปลี่ยนแกนจึงไม่ทำให้ข้อมูลหาย แต่การตัดแกนทิ้งคือการเปลี่ยนพอร์ต หรือถ้าตั้งใจให้เป็นการประมาณ ก็ต้องรายงาน residual ไปด้วย

หลักเดียวกันใช้กับ PCA ซึ่งเป็นวิธีหาแกนตั้งฉากชุดใหม่ ที่เรียงตามว่าแกนไหนอธิบายการขยับของข้อมูลได้มากที่สุด ถ้าเก็บครบทุกแกน PCA คือการเปลี่ยน basis ล้วน ๆ ถ้าเก็บแค่ไม่กี่แกนแรก คือการตัดแกน และความเสี่ยงที่อยู่ในแกนที่ทิ้งไม่ได้หายไปจากพอร์ตจริง

ความผิดที่เกิดเมื่ออ่านพิกัดแยกจากแกน

บวกพิกัดเหมือนเป็นเงิน: พิกัดของแกนที่มีหลายขาต้องคูณมูลค่าต่อหน่วยของแกนก่อนรวม ผิดคือ $5.5+0.5+4=10$ ถูกคือ $V=2(5.5)+0(0.5)+1(4)=15$ ล้าน

คูณพิกัดใหม่กับผลตอบแทนรายหุ้น: พิกัดใหม่ต้องคูณกับ $\mathbf g=B^{\mathsf T}\mathbf r$ ผิดคือ $\mathbf c^{\mathsf T}\mathbf r=5.5(0.01)+0.5(-0.02)+4(0.005)=0.065$ ล้าน (กำไร \$65,000) ถูกคือ $\mathbf c^{\mathsf T}\mathbf g=5.5(-0.01)+0.5(0.03)+4(0.005)=-0.02$ ล้าน (ขาดทุน \$20,000)

เทียบพิกัดข้ามรายงานที่ normalize แกนต่างกัน: normalize คือการปรับขนาดแกน ถ้าเมื่อวานรายงานใช้ $\mathbf b_1=(1,1,0)$ และวันนี้ใช้ $\tilde{\mathbf b}_1=(0.5,0.5,0)$ common 5.5 กับ 11 อาจเป็นพอร์ตเดียวกัน เพราะ $5.5(1,1,0)=11(0.5,0.5,0)=(5.5,5.5,0)$ จึงต้องเทียบแกนพร้อมพิกัดเสมอ

คิดว่า inverse คือ transpose: จริงเฉพาะ orthonormal basis เท่านั้น กับแกน $\mathbf b$ ในหน้านี้ ผิดคือ $B^{\mathsf T}\mathbf x=(6+5,\,6-5,\,4)=(11,1,4)$ ถูกคือ $B^{-1}\mathbf x=(5.5,\,0.5,\,4)$

คิดว่า relative ที่มูลค่าสุทธิศูนย์ไม่มีความเสี่ยง: มูลค่าสุทธิศูนย์ไม่ได้แปลว่า P&L ศูนย์ วันนี้ AAPL กับ JPM ขยับต่างกัน $r_A-r_J=0.01-(-0.02)=0.03$ คือ 3% relative 0.5 หน่วยจึงทำเงิน $0.5\times0.03=0.015$ ล้าน คือ \$15,000

ใช้ทำอะไรบนโต๊ะจริง

รายงานความเสี่ยงแทบทุกฉบับคือการเปลี่ยน basis ตัวอย่างใหญ่คือ factor model ซึ่งบรรยายพอร์ตหุ้นหลายร้อยตัวด้วยพิกัดบน factor ไม่กี่ตัว บวกส่วนที่เหลือรายหุ้น factor คือแกนที่เป็นแรงขับร่วมของหุ้นหลายตัว เช่น ตลาดทั้งตลาด ขนาดบริษัท หรือกลุ่มอุตสาหกรรม ส่วนการหมุนแกนของ factor ก็เปลี่ยนตัวเลขในรายงานได้ โดยที่พอร์ตไม่ขยับเลย

ดังนั้นเวลาเห็นพิกัดในรายงานเปลี่ยนข้ามวัน ต้องถามก่อนว่ามีการซื้อขายจริง หรือแค่แกนเปลี่ยน และเวลาจะส่งคำสั่งซื้อขาย ต้องแปลงกลับเป็นแกนรายหุ้นด้วย $\mathbf x=B\mathbf c$ เสมอ เพราะโบรกเกอร์รับคำสั่งเป็นหุ้น ไม่ใช่เป็นตะกร้า

โจทย์ตรวจความเข้าใจ

1. อีกพอร์ตหนึ่งถือ AAPL \$8 ล้าน JPM \$2 ล้าน และ XOM \$4 ล้าน ถ้าบรรยายด้วยแกน common, relative และ XOM แบบในหน้านี้ พิกัดคือเท่าไร และมูลค่าสุทธิเท่าไร

เฉลย

ใช้สูตรจากการแก้สมการด้านบน common คือค่าเฉลี่ยของสองหุ้น relative คือครึ่งหนึ่งของผลต่าง

\[\begin{aligned}c_1&=\frac{8+2}{2}=5,\\c_2&=\frac{8-2}{2}=3,\\c_3&=4.\end{aligned}\]

ตรวจกลับ: $(5+3,\,5-3,\,4)=(8,2,4)$ ตรงกับพอร์ต มูลค่าสุทธิคือ $V=2(5)+0(3)+1(4)=14$ ล้าน ไม่ใช่ผลรวมพิกัด $5+3+4=12$

2. กลับมาที่พอร์ตต้นหน้า $\mathbf x=(6,5,4)$ ซึ่งมีพิกัด $(5.5,0.5,4)$ ผู้จัดการอยากลด common จาก 5.5 เป็น 4.5 โดยคงพิกัดอื่นไว้ ต้องซื้อขายอะไร และนี่เป็นการเปลี่ยน basis หรือไม่

เฉลย

สร้างพอร์ตใหม่ $\mathbf x'$ จากพิกัดใหม่ แล้วลบด้วยพอร์ตเดิม

\[\begin{aligned}\mathbf x'&=4.5(1,1,0)+0.5(1,-1,0)+4(0,0,1)\\&=(5,\,4,\,4),\\\mathbf x'-\mathbf x&=(5,4,4)-(6,5,4)\\&=(-1,\,-1,\,0).\end{aligned}\]

ต้องขาย AAPL \$1 ล้าน และขาย JPM \$1 ล้าน ได้เงินสด $1+1=2$ คือ \$2 ล้าน (ก่อนหักต้นทุนการซื้อขาย) นี่คือการซื้อขายจริง ไม่ใช่การเปลี่ยน basis เพราะพิกัดเปลี่ยนแต่แกนเดิม การเปลี่ยน basis คือกลับกัน แกนเปลี่ยนแต่พอร์ตเดิม

3. ทีมอื่นใช้แกนอีกชุด คือ common $\mathbf b_1=(1,1,0)$, “AAPL อย่างเดียว” $\mathbf a=(1,0,0)$ และ XOM $\mathbf b_3=(0,0,1)$ จงหาพิกัดของพอร์ต $(6,5,4)$ หา P&L ต่อหนึ่งหน่วยของแต่ละแกนจากผลตอบแทนวันนี้ $\mathbf r=(0.01,-0.02,0.005)$ แล้วตรวจว่า P&L รวมยังเป็นขาดทุน \$20,000

เฉลย

ช่อง JPM มีแค่ $\mathbf b_1$ ที่ให้ค่า จึงได้ $c_1=5$ ทันที ช่อง AAPL ได้จากทั้ง $\mathbf b_1$ และ $\mathbf a$ คือ $5+c_2=6$ จึงได้ $c_2=1$ ช่อง XOM ให้ $c_3=4$ P&L ต่อหน่วยคือ dot ของแต่ละแกนกับ $\mathbf r$

\[\begin{aligned}\mathbf g&=(r_A+r_J,\ r_A,\ r_X)\\&=(-0.01,\ 0.01,\ 0.005),\\\mathbf c^{\mathsf T}\mathbf g&=5(-0.01)+1(0.01)+4(0.005)\\&=-0.02.\end{aligned}\]

ได้ $-0.02$ ล้าน คือขาดทุน \$20,000 ตรงกับเดิม ส่วนทางลัด $11/2=5.5$ ใช้ไม่ได้ เพราะ $\mathbf a^{\mathsf T}\mathbf b_1=1$ ไม่ใช่ศูนย์ แกนสองอันนี้ไม่ตั้งฉากกัน

คำนวณซ้ำด้วย JavaScript

สคริปต์นี้คำนวณตัวเลขทุกตัวในหน้านี้ซ้ำ มันแปลงพอร์ตไปเป็นพิกัดใหม่และแปลงกลับ ตรวจว่า P&L เท่าเดิมเมื่อใช้ $B^{\mathsf T}\mathbf r$ และแสดงว่าการทิ้งพิกัดเปลี่ยน P&L ไปเท่าไร (ในโค้ด residual ชื่อ e)

เปิดดูโค้ด 
const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);
const B = [[1, 1, 0], [1, -1, 0], [0, 0, 1]];        // columns are b1, b2, b3
const cols = B[0].map((_, j) => B.map(row => row[j]));
const toC = x => [(x[0] + x[1]) / 2, (x[0] - x[1]) / 2, x[2]];
const toX = c => B.map(row => dot(row, c));          // x = B c
const x = [6, 5, 4], r = [0.01, -0.02, 0.005];
const c = toC(x);                                     // 5.5, 0.5, 4
const g = cols.map(b => dot(b, r));                   // B^T r = -0.01, 0.03, 0.005
const viaDot = cols.map(b => dot(b, x) / dot(b, b));   // orthogonal shortcut
const dropped = toX([c[0], 0, c[2]]);
const e = x.map((v, i) => v - dropped[i]);
console.log({c, back: toX(c), value: 2 * c[0] + c[2], coordSum: c[0] + c[1] + c[2],
  pnl: 1e6 * dot(x, r), samePnl: 1e6 * dot(c, g), wrongPnl: 1e6 * dot(c, r),
  viaDot, BtX: cols.map(b => dot(b, x)),
  dropped, e, droppedPnl: 1e6 * dot(dropped, r), residualPnl: 1e6 * dot(e, r),
  exercise1: toC([8, 2, 4])});

สิ่งที่ควรตอบได้หลังอ่าน

  • basis ต้อง span ครบ (ทุกพอร์ตมีพิกัด) และ independent (พิกัดมีชุดเดียว) ทุก basis ของพื้นที่สามมิติมีสามแกนพอดี
  • วางแกนใหม่เป็นคอลัมน์ของ $B$ แล้ว $\mathbf x=B\mathbf c$ และ $\mathbf c=B^{-1}\mathbf x$ พอร์ต $(6,5,4)$ มีพิกัด $(5.5,0.5,4)$ ในแกน common, relative, XOM
  • พิกัดต้องอ่านคู่กับแกน ผลรวมพิกัด 10 ไม่ใช่มูลค่า \$15 ล้าน และถ้าย่อแกน common ลงครึ่งหนึ่ง พิกัดจะกลายเป็น 11 ทั้งที่พอร์ตไม่เปลี่ยน
  • ผลตอบแทนต้องแปลงด้วย $B^{\mathsf T}$ เพื่อให้ $\mathbf c^{\mathsf T}\mathbf g=\mathbf x^{\mathsf T}\mathbf r$ ทั้งสองแบบได้ขาดทุน \$20,000 เท่ากัน
  • แกนที่ตั้งฉากกันหาพิกัดได้ด้วย dot product และถ้าเป็น orthonormal inverse จะเท่ากับ transpose ส่วนการทิ้งพิกัดคือการเปลี่ยนพอร์ต ในวันตัวอย่าง P&L ต่างไป \$15,000

เมื่อบรรยายพอร์ตได้ครบแล้ว คำถามถัดไปคือพอร์ต “ใหญ่” แค่ไหน หน้าถัดไป norms แสดงว่ามีไม้บรรทัดหลายอัน และแต่ละอันตอบคนละคำถาม
