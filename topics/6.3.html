6.3 Basis

Basis คือชุดแกนที่ไม่ซ้ำกันและครอบคลุมครบ ทำให้พอร์ตทุกพอร์ตเขียนเป็นพิกัดได้แบบเดียว และการเปลี่ยนแกนเปลี่ยนแค่คำบรรยาย ไม่ได้เปลี่ยนพอร์ต

พอร์ตถือ AAPL \$6 ล้าน JPM \$5 ล้าน และ XOM \$4 ล้าน รวม \$15 ล้าน (ตัวเลขสมมติ) ทีมวิเคราะห์ส่งรายงานที่เขียนพอร์ตนี้ด้วย “แกนใหม่” ได้พิกัด 5.5, 0.5 และ 4 ซึ่งบวกกันได้แค่ 10 หัวหน้าถามว่าเงินอีก \$5 ล้านหายไปไหน และถ้าใช้ผลตอบแทนรายหุ้นของวันนี้ (1%, −2%, 0.5%) คูณพิกัดชุดใหม่ตรง ๆ จะได้ P&L ถูกไหม

ลองตอบก่อนเปิดเฉลย

ไม่มีเงินหาย พิกัด 5.5 หมายถึงตะกร้าที่ถือ AAPL และ JPM อย่างละ \$5.5 ล้าน (หนึ่งหน่วยมีสองขา) พิกัด 0.5 หมายถึง long AAPL \$0.5 ล้านคู่กับ short JPM \$0.5 ล้าน (มูลค่าสุทธิศูนย์) รวมกลับได้ AAPL 6, JPM 5, XOM 4 เหมือนเดิม มูลค่าสุทธิคือ $2(5.5)+0+4=15$ ล้าน ส่วน P&L ถ้าคูณพิกัดใหม่กับผลตอบแทนรายหุ้นตรง ๆ จะได้กำไร \$65,000 แต่พอร์ตจริงขาดทุน \$20,000 ต้องแปลงผลตอบแทนให้เป็นของแต่ละตะกร้าก่อน

ภาพรวมก่อนลงสูตร

ตัวเลข $(6,5,4)$ เป็นพิกัดเทียบกับแกนที่เราใช้โดยไม่รู้ตัว คือหนึ่งแกนต่อหนึ่งหุ้น แต่เราเลือกแกนชุดอื่นได้ เช่นแกน “ถือ AAPL กับ JPM เท่ากัน” และแกน “ถือ AAPL มากกว่า JPM” พอร์ตเดิมยังเป็นจุดเดิมในพื้นที่ สิ่งที่เปลี่ยนคือวิธีเดินไปถึงจุดนั้น ชุดแกนที่ใช้ได้เรียกว่า basis และจำนวนที่เดินตามแต่ละแกนเรียกว่า coordinates

แกนชุดหนึ่งจะใช้เป็น basis ได้ต้องผ่านสองเงื่อนไขจาก linear independence และ linear combinations: span ครบ (ไปถึงทุกพอร์ต) และ independent (ไม่มีแกนซ้ำ ทำให้มีวิธีเดินแบบเดียว) เมื่อผ่านทั้งสองข้อ การเปลี่ยนแกนย้อนกลับได้เสมอ ไม่มีเงินหรือข้อมูลหาย

หน้านี้จะหาพิกัดใหม่และพิสูจน์ว่าไม่กำกวม เขียนการแปลงเป็น matrix อธิบายว่าทำไมผลรวมพิกัดไม่ใช่มูลค่าพอร์ต แปลงผลตอบแทนให้เข้าคู่กับพิกัดใหม่ ดูว่า basis ที่ตั้งฉากกันมีทางลัดอะไร และแยก “เปลี่ยนแกน” ออกจาก “ตัดแกนทิ้ง”

ศัพท์ที่ใช้ในหัวข้อนี้
Basis
ชุดแกน (vector) ที่ independent และ span ครบพื้นที่ที่สนใจ ใช้เป็นระบบพิกัด เช่นแกนรายหุ้น แกนตะกร้า หรือแกน factor
Coordinates
ตัวเลขที่คูณแต่ละแกนใน basis แล้วรวมได้ vector เดิม อ่านแยกจาก basis ไม่ได้ เพราะความหมายของพิกัดมาจากแกนที่มันคูณ
Standard basis
แกนที่มี 1 ในช่องเดียวและ 0 ในช่องอื่น เขียน $\mathbf e_1,\mathbf e_2,\ldots$ พิกัดเทียบกับมันคือตัวเลขในแต่ละช่องตรง ๆ เหมาะกับการส่งคำสั่งซื้อขายรายหุ้น
Change of basis
การแปลงพิกัดจาก basis หนึ่งไปอีก basis หนึ่ง ย้อนกลับได้ ไม่ใช่การซื้อขาย และไม่ได้ลดหรือเพิ่มข้อมูล
Dimension
จำนวนแกนใน basis ใดก็ได้ของพื้นที่นั้น ทุก basis ของพื้นที่เดียวกันมีจำนวนแกนเท่ากัน ใช้บอกว่าต้องใช้ตัวเลขกี่ตัวจึงบรรยายได้ครบ
Orthogonal และ orthonormal basis
basis ที่ทุกคู่แกนตั้งฉากกัน (dot product เป็นศูนย์) ถ้าทุกแกนยาวหนึ่งด้วยเรียกว่า orthonormal ใช้หาพิกัดได้ด้วย dot product โดยไม่ต้องแก้สมการ

$\mathbf c=(c_1,c_2,c_3)$พิกัดของพอร์ตเทียบกับแกนใหม่หน่วยของแต่ละแกน

ขั้นที่ 1 — basis ที่ใช้อยู่แล้วโดยไม่รู้ตัว

ก่อนเปลี่ยนแกน ต้องเห็นก่อนว่าตัวเลข $(6,5,4)$ เองก็เป็นพิกัดเทียบกับแกนชุดหนึ่ง ลำดับช่องคือ AAPL, JPM, XOM หน่วยล้านดอลลาร์

\[ \begin{aligned} \mathbf e_1&=\begin{bmatrix}1\\0\\0\end{bmatrix},\ \mathbf e_2=\begin{bmatrix}0\\1\\0\end{bmatrix},\ \mathbf e_3=\begin{bmatrix}0\\0\\1\end{bmatrix},\\ \mathbf x&=6\mathbf e_1+5\mathbf e_2+4\mathbf e_3 =\begin{bmatrix}6\\5\\4\end{bmatrix}. \end{aligned} \]

แกน $\mathbf e_1$ คือ “ถือ AAPL \$1 ล้าน ไม่ถืออย่างอื่น” พิกัดเทียบกับ standard basis จึงเป็นตัวเลขในช่องตรง ๆ เราไม่เคยต้องคิดถึงมันเพราะมันสะดวกที่สุดสำหรับการส่งคำสั่งซื้อขาย แต่ถ้าคำถามคือ “พอร์ตนี้เดิมพันกับธนาคารเทียบกับเทคโนโลยีแค่ไหน” แกนรายหุ้นไม่ได้ตอบตรง ๆ จึงอยากได้แกนชุดใหม่

แกนใหม่หนึ่งหน่วยพิกัดคือมูลค่าสุทธิต่อหน่วย
$\mathbf b_1=(1,1,0)$ commonlong AAPL \$1 ล้าน และ long JPM \$1 ล้าน\$2 ล้าน
$\mathbf b_2=(1,-1,0)$ relativelong AAPL \$1 ล้าน และ short JPM \$1 ล้านศูนย์
$\mathbf b_3=(0,0,1)$ XOMlong XOM \$1 ล้าน\$1 ล้าน

ขั้นที่ 2 — สองเงื่อนไขของ basis: มีคำตอบ และมีคำตอบเดียว

แกนชุดใหม่ต้องบรรยายพอร์ตได้ทุกพอร์ต และต้องบรรยายได้แบบเดียว ไม่อย่างนั้นสองรายงานอาจให้ตัวเลขต่างกันสำหรับพอร์ตเดียวกัน ขั้นนี้แสดงว่าสองข้อนี้คือ span กับ independence พอดี

\[ \begin{aligned} \sum_i c_i\mathbf b_i&=\sum_i d_i\mathbf b_i,\\ \sum_i(c_i-d_i)\,\mathbf b_i&=\mathbf 0,\\ c_i-d_i&=0,\quad i=1,2,3. \end{aligned} \]

สมมติพอร์ตเดียวมีพิกัดสองชุด $\mathbf c$ และ $\mathbf d$ ลบสองคำบรรยายออกจากกันได้บรรทัดที่สอง ซึ่งเป็นการผสมแกนแล้วได้ศูนย์ ถ้าแกนเป็น independent ทางเดียวที่ผสมได้ศูนย์คือสัมประสิทธิ์เป็นศูนย์ทุกตัว (นิยามจาก linear independence) จึงได้ $\mathbf c=\mathbf d$ พิกัดไม่กำกวม ส่วนการมีพิกัดอย่างน้อยหนึ่งชุดสำหรับทุกพอร์ตคือนิยามของ span ครบ ขาดข้อแรกจะมีพอร์ตที่เขียนไม่ได้ ขาดข้อหลังจะมีพอร์ตที่เขียนได้หลายแบบ

ผลข้างเคียงสำคัญ: ทุก basis ของพื้นที่สามมิติมีสามแกนพอดี น้อยกว่าสามจะ span ได้อย่างมากแค่ระนาบ (rank ไม่เกินจำนวนแกน) มากกว่าสามจะต้องมีตัวซ้ำ ในทำนองเดียวกัน กองทุน A กับ B ใน linear combinations เป็น basis ของระนาบที่สองกองนั้นสร้างได้ แต่ไม่ใช่ basis ของทั้งสามมิติ ต้องบอกเสมอว่าเป็น basis ของพื้นที่ไหน และจำนวนแกนของ basis ของ range ของ matrix คือ rank ของมัน

ขั้นที่ 3 — หาพิกัดใหม่ แล้วคูณกลับเพื่อพิสูจน์

ตอนนี้แกนพร้อมแล้ว เขียน $\mathbf x=c_1\mathbf b_1+c_2\mathbf b_2+c_3\mathbf b_3$ ทีละช่องได้สามสมการ แก้ได้ทันทีโดยไม่ต้องเดา

\[ \begin{aligned} c_1+c_2&=x_A,\\ c_1-c_2&=x_J,\\ c_3&=x_X,\\ c_1&=\frac{x_A+x_J}{2}=\frac{6+5}{2}=5.5,\\ c_2&=\frac{x_A-x_J}{2}=\frac{6-5}{2}=0.5,\\ c_3&=4. \end{aligned} \]

บวกสองสมการแรกได้ $2c_1=x_A+x_J$ ลบกันได้ $2c_2=x_A-x_J$ สูตรนี้ใช้ได้กับทุกพอร์ต (span ครบ) และให้ค่าเดียว (independent) common จึงเป็นค่าเฉลี่ยของสองหุ้น relative เป็นครึ่งหนึ่งของผลต่าง ตรวจกลับ: $5.5(1,1,0)+0.5(1,-1,0)+4(0,0,1)=(6,5,4)$ ตรงทุกช่อง

วางแกนใหม่เป็น คอลัมน์ ของ matrix $B$ การคูณกลับกลายเป็น $\mathbf x=B\mathbf c$ และการหาพิกัดคือการคูณด้วย inverse

\[ \begin{aligned} B&=\begin{bmatrix}1&1&0\\1&-1&0\\0&0&1\end{bmatrix},\quad \mathbf x=B\mathbf c,\\ B^{-1}&=\begin{bmatrix}\tfrac12&\tfrac12&0\\\tfrac12&-\tfrac12&0\\0&0&1\end{bmatrix},\quad \mathbf c=B^{-1}\mathbf x,\\ \det B&=1(-1)-1(1)=-2. \end{aligned} \]

$B\mathbf c$ คือ linear combination ของคอลัมน์ของ $B$ ด้วยน้ำหนัก $\mathbf c$ ซึ่งคือ $c_1\mathbf b_1+c_2\mathbf b_2+c_3\mathbf b_3$ พอดี (มุมมองคอลัมน์จาก row และ column vectors) แถวของ $B^{-1}$ อ่านจากสูตรที่เพิ่งแก้: แถวแรกเอาค่าเฉลี่ย AAPL กับ JPM แถวสองเอาครึ่งผลต่าง แถวสามเก็บ XOM ตามเดิม ลองคูณ $B^{-1}B$ แถวแรกกับคอลัมน์แรกได้ $\tfrac12+\tfrac12=1$ แถวแรกกับคอลัมน์สองได้ $\tfrac12-\tfrac12=0$ ครบทุกช่องเป็น identity $I$ matrix จัตุรัสที่คอลัมน์ไม่ซ้ำกัน (rank เต็ม) มี inverse เสมอ และ determinant ที่ไม่เป็นศูนย์คือการตรวจอีกทาง

ขั้นที่ 4 — ทำไมพิกัดรวมได้ 10 แต่พอร์ตมี 15 ล้าน

คำถามในหัวหน้านี้มาจากการบวกพิกัดเหมือนเป็นมูลค่าหุ้น พิกัดแต่ละตัวมีหน่วยเป็น “จำนวนหน่วยของแกนนั้น” ต้องแปลงด้วยความหมายของแกนก่อนรวม

โจทย์ให้อะไรมาบ้าง: $\mathbf c=(5.5,0.5,4)$ หนึ่งหน่วย common มีมูลค่าสุทธิ \$2 ล้าน หนึ่งหน่วย relative มีศูนย์ หนึ่งหน่วย XOM มี \$1 ล้าน

\[ \begin{aligned} V&=2c_1+0\,c_2+1\,c_3\\ &=2(5.5)+0+4=15,\\ c_1+c_2+c_3&=10,\\ \tilde{\mathbf b}_1&=\tfrac12\mathbf b_1=(0.5,\,0.5,\,0),\\ 5.5\,\mathbf b_1&=11\,\tilde{\mathbf b}_1. \end{aligned} \]

คำตอบ: มูลค่าสุทธิยังเป็น \$15 ล้าน ผลรวม 10 นับตะกร้า common เป็น 5.5 ทั้งที่แต่ละหน่วยมีสองขา ถ้าย่อแกน common ให้หนึ่งหน่วยมีมูลค่า \$1 ล้าน ($\tilde{\mathbf b}_1$) พิกัดต้องเพิ่มเป็น 11 พอร์ตเดิมเป๊ะ ตัวเลขพิกัดใหญ่ขึ้นสองเท่าเพราะเปลี่ยนขนาดของแกน ไม่ได้ซื้ออะไรเพิ่ม

ตรวจเองใน 10 วินาที: พิกัดใหม่ $(11,0.5,4)$ กับแกน $\tilde{\mathbf b}_1$ ให้มูลค่า $1(11)+0+4=15$ ตรงกัน

ขั้นที่ 5 — P&L ต้องเท่าเดิม ถ้าแปลงผลตอบแทนให้เข้าคู่กับพิกัด

พอร์ตเดิม P&L เดิม ไม่ว่าจะบรรยายด้วยแกนไหน แต่ dot product ต้องจับคู่ของที่เป็นคู่กัน: พิกัดใหม่ต้องคูณกับ “P&L ต่อหนึ่งหน่วยของแกนใหม่” ไม่ใช่ผลตอบแทนรายหุ้น วันนี้ผลตอบแทน AAPL, JPM, XOM คือ 1%, −2%, 0.5%

\[ \begin{aligned} \mathbf x^{\mathsf T}\mathbf r&=6(0.01)+5(-0.02)+4(0.005)\\ &=0.06-0.10+0.02=-0.02,\\ \mathbf x^{\mathsf T}\mathbf r&=(B\mathbf c)^{\mathsf T}\mathbf r =\mathbf c^{\mathsf T}(B^{\mathsf T}\mathbf r),\\ \mathbf g=B^{\mathsf T}\mathbf r&=\begin{bmatrix}r_A+r_J\\r_A-r_J\\r_X\end{bmatrix} =\begin{bmatrix}-0.01\\0.03\\0.005\end{bmatrix},\\ \mathbf c^{\mathsf T}\mathbf g&=5.5(-0.01)+0.5(0.03)+4(0.005)\\ &=-0.055+0.015+0.02=-0.02. \end{aligned} \]

หน่วยเป็นล้านดอลลาร์ พอร์ตขาดทุน \$20,000 ทั้งสองวิธี ท่าสำคัญอยู่บรรทัดที่สอง: แทน $\mathbf x=B\mathbf c$ แล้วใช้กฎ transpose ของผลคูณ $(B\mathbf c)^{\mathsf T}=\mathbf c^{\mathsf T}B^{\mathsf T}$ (สลับลำดับเมื่อ transpose) วงเล็บ $B^{\mathsf T}\mathbf r$ คือ dot product ของแต่ละแกนกับผลตอบแทน: แกน common หนึ่งหน่วยถือ AAPL กับ JPM อย่างละ \$1 ล้าน จึงได้ $r_A+r_J=-0.01$ ล้าน แกน relative ได้ $r_A-r_J=+0.03$ ล้าน

ถ้าคูณ $\mathbf c$ กับ $\mathbf r$ ตรง ๆ จะได้ $5.5(0.01)+0.5(-0.02)+4(0.005)=0.065$ คือกำไร \$65,000 ผิดทั้งขนาดและเครื่องหมาย เพราะเอาผลตอบแทนของ AAPL ไปคูณจำนวนตะกร้า common สังเกตด้วยว่าตัวแปลงของผลตอบแทนคือ $B^{\mathsf T}$ ไม่ใช่ $B^{-1}$ ที่ใช้แปลงพิกัด ของสองชนิดนี้แปลงคนละแบบ เพื่อให้ dot product ของมันคงเดิม

ขั้นที่ 6 — basis ที่ตั้งฉากกันหาพิกัดได้ด้วย dot product

ตอนหาพิกัดใหม่ด้านบนเราต้องแก้สมการ แต่แกน $\mathbf b_1,\mathbf b_2,\mathbf b_3$ ชุดนี้ตั้งฉากกันทุกคู่ ($\mathbf b_1^{\mathsf T}\mathbf b_2=1-1+0=0$) ซึ่งเปิดทางลัด: dot product ของพอร์ตกับแกนหนึ่งจะฆ่าแกนอื่นทิ้งหมด

\[ \begin{aligned} \mathbf b_k^{\mathsf T}\mathbf x&=\sum_i c_i\,\mathbf b_k^{\mathsf T}\mathbf b_i =c_k\,\mathbf b_k^{\mathsf T}\mathbf b_k,\\ c_k&=\frac{\mathbf b_k^{\mathsf T}\mathbf x}{\mathbf b_k^{\mathsf T}\mathbf b_k},\\ c_1&=\frac{6+5}{2}=5.5,\quad c_2=\frac{6-5}{2}=0.5,\\ B^{\mathsf T}B&=\begin{bmatrix}2&0&0\\0&2&0\\0&0&1\end{bmatrix}. \end{aligned} \]

บรรทัดแรกได้จากการ dot $\mathbf b_k$ เข้ากับ $\mathbf x=\sum_ic_i\mathbf b_i$ ทุกพจน์ที่ $i\ne k$ เป็นศูนย์เพราะตั้งฉาก เหลือพจน์เดียว หารด้วยความยาวกำลังสองของแกนได้พิกัด ไม่ต้องแก้ระบบสมการ $B^{\mathsf T}B$ เป็น diagonal เพราะช่องนอกแนวทแยงคือ dot product ระหว่างแกนต่างกัน ซึ่งเป็นศูนย์ แต่มันยังไม่ใช่ $I$ เพราะ $\mathbf b_1,\mathbf b_2$ ยาว $\sqrt2$ ไม่ใช่ 1 ดังนั้น $B^{-1}\ne B^{\mathsf T}$: ถ้าใช้ $B^{\mathsf T}\mathbf x=(11,1,4)$ เป็นพิกัด จะผิดไปสองเท่าในสองช่องแรก

ถ้าหารแต่ละแกนด้วยความยาวของมัน ได้ $\mathbf q_1=(1,1,0)/\sqrt2$, $\mathbf q_2=(1,-1,0)/\sqrt2$, $\mathbf q_3=\mathbf b_3$ ซึ่งเป็น orthonormal จะได้ $Q^{\mathsf T}Q=I$ และ $Q^{-1}=Q^{\mathsf T}$: หาพิกัดด้วยการ transpose อย่างเดียว ทางลัดนี้ใช้ไม่ได้กับแกนที่ไม่ตั้งฉาก ดังรูปถัดไป แนวคิดเดียวกันเรื่องการวัดส่วนที่อยู่ตามแกนด้วย dot product คือ projection ใน inner product, angle และ correlation

ขั้นที่ 7 — เปลี่ยนแกนไม่ใช่ตัดแกนทิ้ง

รายงานที่อยากสั้นลงมักทิ้งพิกัดที่ดูเล็ก เช่น relative 0.5 ขั้นนี้วัดว่าการทิ้งพิกัดคือการเปลี่ยนพอร์ตเท่าไร

โจทย์ให้อะไรมาบ้าง: พอร์ต $\mathbf x=(6,5,4)$ พิกัด $(5.5,0.5,4)$ ตั้ง $c_2=0$ แล้วสร้างกลับ ผลตอบแทนวันนี้ $\mathbf r=(0.01,-0.02,0.005)$

\[ \begin{aligned} \hat{\mathbf x}&=5.5\mathbf b_1+0\,\mathbf b_2+4\mathbf b_3 =(5.5,\,5.5,\,4),\\ \mathbf e=\mathbf x-\hat{\mathbf x}&=(0.5,\,-0.5,\,0),\\ \mathbf e^{\mathsf T}\mathbf r&=0.5(0.01)-0.5(-0.02)=0.015,\\ \hat{\mathbf x}^{\mathsf T}\mathbf r&=-0.02-0.015=-0.035. \end{aligned} \]

คำตอบ: พอร์ตที่ทิ้ง relative ขาดทุน \$35,000 ในวันเดียวกัน ต่างจากพอร์ตจริง \$15,000 แม้มูลค่าเริ่มต้นยังเป็น \$15 ล้านเท่ากัน ส่วนต่าง $\mathbf e$ คือ residual: ข้อมูลที่หายไปพร้อมพิกัดที่ทิ้ง basis เต็มของสามมิติยังมีสามพิกัด การเปลี่ยนแกนจึงไม่ลดข้อมูล ส่วนการตัดแกนคือการเปลี่ยนพอร์ต หรือการประมาณที่ต้องรายงาน residual ด้วย

หลักเดียวกันใช้กับ PCA: ถ้าเก็บครบทุกแกนคือการเปลี่ยน basis ล้วน ๆ ถ้าเก็บแค่ไม่กี่แกนแรกคือการตัด และความเสี่ยงที่อยู่ในแกนที่ทิ้งไม่ได้หายไปจากพอร์ตจริง

ความผิดที่เกิดเมื่ออ่านพิกัดแยกจากแกน

บวกพิกัดเป็นมูลค่า: $5.5+0.5+4=10$ แต่มูลค่าคือ 15 พิกัดของแกนที่มีหลายขาต้องคูณมูลค่าต่อหน่วยของแกนก่อน

ใช้ผลตอบแทนรายหุ้นกับพิกัดใหม่: $\mathbf c^{\mathsf T}\mathbf r=+\$65{,}000$ แทน $-\$20{,}000$ ต้องใช้ $\mathbf g=B^{\mathsf T}\mathbf r$

เทียบพิกัดข้ามรายงานที่ normalize แกนต่างกัน: common 5.5 เมื่อวานกับ 11 วันนี้อาจเป็นพอร์ตเดียวกัน ถ้าวันนี้แกนเป็น $(0.5,0.5,0)$ ต้องเทียบแกนพร้อมพิกัดเสมอ

คิดว่า inverse คือ transpose: จริงเฉพาะ orthonormal basis กับแกน $\mathbf b$ ในหน้านี้ $B^{\mathsf T}\mathbf x=(11,1,4)$ ไม่ใช่พิกัด $(5.5,0.5,4)$

คิดว่า relative ที่มูลค่าสุทธิศูนย์ไม่มีความเสี่ยง: วันนี้ relative 0.5 หน่วยทำเงิน \$15,000 จากการที่ AAPL กับ JPM ขยับต่างกัน 3% มูลค่าสุทธิศูนย์ไม่ได้แปลว่า P&L ศูนย์

ใช้ทำอะไรบนโต๊ะจริง

รายงานความเสี่ยงแทบทุกฉบับเป็นการเปลี่ยน basis: factor model บรรยายพอร์ตหุ้นหลายร้อยตัวด้วยพิกัดของ factor ไม่กี่ตัว (ตลาด ขนาด อุตสาหกรรม) บวกส่วนที่เหลือรายหุ้น และการหมุนแกนของ factor ก็เปลี่ยนตัวเลขในรายงานโดยที่พอร์ตไม่ขยับ เวลาเห็นพิกัดเปลี่ยนข้ามวัน ต้องถามก่อนว่ามีการซื้อขายจริง หรือแค่แกนเปลี่ยน ส่วนการส่งคำสั่งต้องแปลงกลับเป็นแกนรายหุ้นเสมอด้วย $\mathbf x=B\mathbf c$ เพราะโบรกเกอร์รับคำสั่งเป็นหุ้น ไม่ใช่เป็นตะกร้า

โจทย์ตรวจความเข้าใจ

1. พอร์ต AAPL \$8 ล้าน JPM \$2 ล้าน XOM \$4 ล้าน มีพิกัดเท่าไรในแกน common, relative, XOM และมูลค่าสุทธิเท่าไร

เฉลย

$c_1=(8+2)/2=5$, $c_2=(8-2)/2=3$, $c_3=4$ ตรวจกลับ $(5+3,\,5-3,\,4)=(8,2,4)$ มูลค่าสุทธิ $2(5)+0(3)+4=14$ ล้าน ไม่ใช่ผลรวมพิกัด 12

2. จากพอร์ตต้นหน้า ถ้าลด common จาก 5.5 เป็น 4.5 โดยคงพิกัดอื่น ต้องซื้อขายอะไร และนี่เป็นการเปลี่ยน basis หรือไม่

เฉลย

พอร์ตใหม่ $4.5(1,1,0)+0.5(1,-1,0)+4(0,0,1)=(5,4,4)$ ต้องขาย AAPL \$1 ล้านและ JPM \$1 ล้าน ได้เงินสด \$2 ล้าน (ก่อนต้นทุน) นี่คือการซื้อขายจริง เพราะพิกัดเปลี่ยนแต่แกนเดิม ส่วนการเปลี่ยน basis คือแกนเปลี่ยนแต่พอร์ตเดิม

3. ใช้แกน common $\mathbf b_1=(1,1,0)$ กับ “AAPL อย่างเดียว” $\mathbf a=(1,0,0)$ และ XOM $\mathbf b_3$ หาพิกัดของ $(6,5,4)$ และ P&L ต่อหน่วยแกนสำหรับผลตอบแทนวันนี้

เฉลย

ช่อง JPM มาจาก $\mathbf b_1$ อย่างเดียว จึงได้ $c_1=5$ แล้ว AAPL $=5+c_2=6$ ได้ $c_2=1$ และ $c_3=4$ P&L ต่อหน่วยคือ dot ของแต่ละแกนกับ $\mathbf r$: $(0.01-0.02,\ 0.01,\ 0.005)=(-0.01,0.01,0.005)$ รวม $5(-0.01)+1(0.01)+4(0.005)=-0.02$ ล้าน ตรงกับเดิม ส่วนทางลัด $11/2=5.5$ ใช้ไม่ได้เพราะ $\mathbf a$ ไม่ตั้งฉากกับ $\mathbf b_1$

คำนวณซ้ำด้วย JavaScript

สคริปต์แปลงไปและกลับ ตรวจว่า P&L คงเดิมเมื่อใช้ $B^{\mathsf T}\mathbf r$ และแสดงผลของการตัดพิกัด

เปิดดูโค้ด 
const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);
const B = [[1, 1, 0], [1, -1, 0], [0, 0, 1]];        // columns are b1, b2, b3
const cols = B[0].map((_, j) => B.map(row => row[j]));
const toC = x => [(x[0] + x[1]) / 2, (x[0] - x[1]) / 2, x[2]];
const toX = c => B.map(row => dot(row, c));          // x = B c
const x = [6, 5, 4], r = [0.01, -0.02, 0.005];
const c = toC(x);                                     // 5.5, 0.5, 4
const g = cols.map(b => dot(b, r));                   // B^T r = -0.01, 0.03, 0.005
const viaDot = cols.map(b => dot(b, x) / dot(b, b));   // orthogonal shortcut
const dropped = toX([c[0], 0, c[2]]);
const e = x.map((v, i) => v - dropped[i]);
console.log({c, back: toX(c), value: 2 * c[0] + c[2], coordSum: c[0] + c[1] + c[2],
  pnl: 1e6 * dot(x, r), samePnl: 1e6 * dot(c, g), wrongPnl: 1e6 * dot(c, r),
  viaDot, BtX: cols.map(b => dot(b, x)),
  dropped, e, droppedPnl: 1e6 * dot(dropped, r), residualPnl: 1e6 * dot(e, r),
  exercise1: toC([8, 2, 4])});

สิ่งที่ควรตอบได้หลังอ่าน

  • basis ต้อง span ครบ (มีพิกัดเสมอ) และ independent (มีพิกัดชุดเดียว) ทุก basis ของสามมิติมีสามแกน
  • วางแกนเป็นคอลัมน์ของ $B$: $\mathbf x=B\mathbf c$ และ $\mathbf c=B^{-1}\mathbf x$ พอร์ต $(6,5,4)$ มีพิกัด $(5.5,0.5,4)$
  • พิกัดอ่านแยกจากแกนไม่ได้: ผลรวมพิกัด 10 ไม่ใช่มูลค่า 15 และ normalize แกนใหม่ทำให้พิกัดเปลี่ยนเป็น 11 โดยพอร์ตไม่เปลี่ยน
  • ผลตอบแทนแปลงด้วย $B^{\mathsf T}$ เพื่อให้ $\mathbf c^{\mathsf T}\mathbf g=\mathbf x^{\mathsf T}\mathbf r$ คงเดิม (ขาดทุน \$20,000 ทั้งสองแบบ)
  • แกนตั้งฉากหาพิกัดด้วย dot product ได้ และ orthonormal ให้ inverse เท่ากับ transpose ส่วนการทิ้งพิกัดคือการเปลี่ยนพอร์ต (ต่างกัน \$15,000 ในวันตัวอย่าง)

เมื่อบรรยายพอร์ตได้ครบแล้ว คำถามถัดไปคือพอร์ต “ใหญ่” แค่ไหน หน้าถัดไป norms แสดงว่ามีไม้บรรทัดหลายอัน และแต่ละอันตอบคนละคำถาม
