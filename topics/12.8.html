12.8 Mean-Variance with Transaction Costs

เมื่อการย้ายพอร์ตมีต้นทุน คำตอบขึ้นกับพอร์ตที่ถืออยู่: ต้นทุนแบบสัดส่วนสร้างแถบที่ไม่ควรเทรด ต้นทุนที่โตเร็วกว่าเส้นตรงทำให้ขยับทีละส่วน และเพดาน turnover ทำตัวเหมือนต้นทุนที่แพงขึ้น

กองทุน \$50 ล้าน ถือหุ้นสหรัฐฯ/พันธบัตร/หุ้นเทค 40/40/20 เพราะหุ้นเทควิ่งขึ้นจนเกินสัดส่วน optimizer ที่ห้าม short (ผลตอบแทนคาดหวัง 12%/6%/15%, $\gamma=2$) บอกว่าพอร์ตที่ดีที่สุดคือ 46.41/50.09/3.50 ค่าซื้อขาย 10 bp ของเงินที่ซื้อขาย และ mandate จำกัด turnover รอบนี้ไม่เกิน 10% ของเงินกองทุน ผู้จัดการจะขยับทุกตัว 60.6% ของระยะไปทางเป้าหมาย ซึ่งใช้ turnover 10% พอดี นี่คือพอร์ตที่ดีที่สุดภายใต้เพดานไหม

ลองตอบก่อนเปิดเฉลย

ไม่ใช่ พอร์ตที่ดีที่สุดคือไม่แตะหุ้นสหรัฐฯเลย ขายหุ้นเทค 10 จุดไปซื้อพันธบัตร 10 จุด ได้ 40/50/10 ค่าเป้าหมายสูงกว่าการเดินตามสัดส่วน 1.3 bp ต่อปี (ราว \$6,500 ต่อปี) ด้วย turnover และค่าธรรมเนียม \$10,000 เท่ากันเป๊ะ เมื่องบซื้อขายจำกัด เงินแต่ละดอลลาร์ต้องไปที่ที่ได้ประโยชน์มากที่สุดต่อหน่วย turnover ซึ่งคือย้ายจากหุ้นเทคไปพันธบัตร ตัวคูณของเพดาน $\theta=0.017$ บอกว่าการผ่อนเพดานมีค่าเท่าไร

ภาพรวมก่อนลงสูตร

ทุกหน้าก่อนหน้านี้คิดว่าย้ายพอร์ตได้ฟรี คำตอบจึงไม่สนว่าตอนนี้ถืออะไรอยู่ ของจริงมีค่าคอมมิชชัน ส่วนต่างราคาซื้อขาย และราคาที่ขยับหนีเมื่อสั่งก้อนใหญ่ หน้านี้ใส่ต้นทุนเหล่านั้นเข้าไปใน objective ตรง ๆ เพราะมันมีหน่วยเดียวกับผลตอบแทน แล้วใช้KKT conditionsจัดการจุดหักมุมของค่าสัมบูรณ์

รูปร่างของต้นทุนกำหนดรูปร่างของคำตอบ ต้นทุนแบบสัดส่วน (คงที่ต่อดอลลาร์) มีมุมแหลมที่ “ไม่เทรด” จึงเกิดแถบรอบเป้าหมายที่การอยู่เฉยดีที่สุด ถ้าอยู่นอกแถบ ให้เทรดแค่ถึงขอบแถบ ไม่ใช่ถึงเป้าหมาย ส่วนต้นทุนจากการดันราคาโตเร็วกว่าเส้นตรง จึงคุ้มกว่าที่จะขยับทีละส่วนทุกรอบ และเพดาน turnover ที่บีบคือต้นทุนแฝงที่ผลักคำตอบไปอยู่ที่มุม

หน้านี้จะนับการซื้อขายให้ไม่กำกวม ดูว่าต้นทุนมาจากไหน ตั้งเงื่อนไขที่จุดหักมุม แก้พอร์ตที่ดีที่สุดเมื่อมีต้นทุน หาแถบที่ไม่ควรเทรดทั้งแบบหนึ่งสินทรัพย์และสามสินทรัพย์ ใส่เพดาน turnover แล้วดูว่าทำไมการเดินตามสัดส่วนแพ้ และจบที่ต้นทุนจากการดันราคาซึ่งทำให้ขยับทีละส่วน

ศัพท์ที่ใช้ในหัวข้อนี้
Transaction cost
เงินที่เสียเมื่อเปลี่ยนสิ่งที่ถือ: ค่าคอมมิชชัน ครึ่งหนึ่งของ bid–ask spread และ market impact ใช้หักออกจากประโยชน์ของการเทรด
One-way turnover
ครึ่งหนึ่งของผลรวมการเปลี่ยนน้ำหนักแบบค่าสัมบูรณ์ เท่ากับฝั่งซื้อรวม (หรือฝั่งขายรวม) เป็นสัดส่วนของเงินกองทุน ใช้วัดว่าพอร์ตถูกเปลี่ยนหน้าไปเท่าไร
Gross traded notional
มูลค่าซื้อบวกมูลค่าขาย ไม่หักกลบกัน เป็นฐานที่ค่าธรรมเนียมคิดจริง
No-trade region
เขตรอบเป้าหมายที่ประโยชน์ส่วนเพิ่มของการขยับยังไม่ชนะต้นทุน คำตอบที่ดีที่สุดในเขตนี้คืออยู่เฉย ๆ นอกเขตให้เทรดแค่ถึงขอบ
Turnover cap
เพดานของ one-way turnover ต่อรอบ ใช้คุมต้นทุน ภาษี และภาระงานปฏิบัติการ ตัวคูณของมันคือราคาแฝงของการเทรด
Market impact
ราคาที่ขยับหนีเพราะคำสั่งของเราเอง ส่วนชั่วคราวคลายกลับหลังเทรดเสร็จ ส่วนถาวรค้างอยู่ ยิ่งสั่งก้อนใหญ่เทียบปริมาณซื้อขายของตลาด ต้นทุนต่อดอลลาร์ยิ่งสูง
Partial adjustment
การขยับไปทางเป้าหมายแค่สัดส่วนหนึ่งต่อรอบ เป็นคำตอบที่ดีที่สุดเมื่อต้นทุนโตตามกำลังสองของขนาดคำสั่ง
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$W$มูลค่ากองทุนก่อนปรับ \$50 ล้านดอลลาร์
$w_0,\ w,\ \Delta w$น้ำหนักเดิม น้ำหนักใหม่ และส่วนต่างสัดส่วนของเงินกองทุน
$c$ต้นทุนแบบสัดส่วน 10 bp = 0.001 ต่อเงินที่ซื้อขายหนึ่งดอลลาร์ดอลลาร์ต่อดอลลาร์ที่ซื้อขาย
$J(w)$ค่าเป้าหมาย mean-variance $\mu^{\mathsf T}w-2w^{\mathsf T}Vw$ผลตอบแทนเทียบเท่าต่อปี
$g_i,\ \nu$ประโยชน์ส่วนเพิ่ม $\partial J/\partial w_i$ และตัวคูณของงบลงเงินครบต่อหน่วยน้ำหนัก
$\tau,\ \theta$เพดาน turnover และตัวคูณของมันสัดส่วนของเงินกองทุน, ต่อหน่วย turnover
$\kappa,\ \varphi$ตัวคูณ impact แบบกำลังสอง และสัดส่วนที่ขยับต่อรอบสัดส่วนของเงินกองทุนต่อ (น้ำหนักที่ซื้อขาย)², ไม่มีหน่วย

ขั้นที่ 1 — นับการซื้อขายให้ไม่กำกวม

ก่อนคิดต้นทุนต้องตกลงว่า “ซื้อขายเท่าไร” นับอย่างไร เพราะซื้อหนึ่งขายหนึ่งนับเป็นหนึ่งหรือสองให้ผลต่างกันเท่าตัว ลองกับตัวเลขกลม ๆ: จาก 40/40/20 ไป 60/30/10 แยกส่วนต่างเป็นส่วนซื้อ $u_i=\max(\Delta w_i,\ 0)$ กับส่วนขาย $v_i=\max(-\Delta w_i,\ 0)$

\[ \begin{aligned} \Delta w&=(+0.20,\ -0.10,\ -0.10),\\ \mathbf1^{\mathsf T}\Delta w&=1-1=0,\\ \Delta w_i&=u_i-v_i\ \Rightarrow\ \textstyle\sum_iu_i=\sum_iv_i,\\ \lVert\Delta w\rVert_1&=\textstyle\sum_i(u_i+v_i)=2\sum_iu_i=0.40,\\ \text{TO}&=\tfrac12\lVert\Delta w\rVert_1=0.20,\\ \text{cost}&=c\,W\lVert\Delta w\rVert_1\\ &=0.001(50{,}000{,}000)(0.40)=20{,}000. \end{aligned} \]

บรรทัดที่สองมาจากงบ: ทั้งพอร์ตเดิมและพอร์ตใหม่รวมได้ 1 ส่วนต่างจึงรวมได้ศูนย์ ส่วนซื้อจึงเท่าส่วนขายเสมอ เงินที่ใช้ซื้อต้องมาจากการขาย ผลรวมค่าสัมบูรณ์ ($\lVert\cdot\rVert_1$ จากnorm) จึงนับเงินก้อนเดียวกันสองครั้ง one-way turnover หารสองเพื่อให้ได้สัดส่วนของพอร์ตที่ถูกเปลี่ยนหน้าจริง: 20% หรือ \$10 ล้าน

แต่ค่าธรรมเนียมคิดจากเงินที่ผ่านมือทั้งสองขา ฐานของต้นทุนจึงเป็น gross \$20 ล้าน (ซื้อ \$10 ล้าน ขาย \$10 ล้าน) ที่ 10 bp ได้ \$20,000 หรือ 4 bp ของเงินกองทุน

ขั้นที่ 2 — ต้นทุนมาจากไหน และโตตามขนาดคำสั่งอย่างไร

10 bp ต่อดอลลาร์เป็นแค่ส่วนแรกของต้นทุน ต้นทุนที่คาดไว้ของการเทรดหนึ่งครั้งแยกได้เป็นสามก้อน และแต่ละก้อนโตตามขนาดคำสั่ง $Q$ ไม่เท่ากัน

\[ \begin{aligned} \text{cost}&=\underbrace{c\,Q}_{\text{spread, fees}}\\ &\quad+\underbrace{\text{temporary}}_{\text{slippage}}\\ &\quad+\underbrace{\text{permanent}}_{\text{information}},\\ \frac{\text{cost}}{Q}&\approx Y\,\sigma\sqrt{\frac{Q}{V}},\qquad\text{cost}\propto Q^{3/2},\\ \frac{Q}{V}:\ 4\%\to16\%:&\quad\sqrt{4}=2,\quad4^{3/2}=8. \end{aligned} \]

ก้อนแรกคือค่าคอมมิชชันกับครึ่งหนึ่งของ bid–ask spread ที่จ่ายทุกครั้งที่ข้ามไปซื้อราคาเสนอขาย คิดเป็นอัตราคงที่ต่อดอลลาร์ ก้อนที่สองคือราคาที่ขยับหนีระหว่างเรากำลังเทรดแล้วคลายกลับทีหลัง ก้อนที่สามคือราคาที่ขยับแล้วไม่กลับ เพราะตลาดอ่านคำสั่งของเราเป็นข่าว สำหรับการจัดพอร์ต ก้อนแรกกับก้อนที่สองใหญ่ที่สุด

บรรทัดที่สองคือกฎรากที่สองของ impact: ต้นทุนต่อดอลลาร์แปรตามความผันผวน $\sigma$ คูณรากของสัดส่วนที่เราซื้อขายเทียบปริมาณซื้อขายของทั้งตลาดในช่วงเดียวกัน $V$ ($Y$ คือค่าคงที่ที่ต้องประมาณจากการเทรดจริงของแต่ละโต๊ะ) ที่มาของรากเป็นเหตุผลเรื่องหน่วย: ต้นทุนต่อดอลลาร์ไม่มีหน่วย ตัวแปรที่มีคือ $Q$ (ดอลลาร์) $V$ (ดอลลาร์ต่อวัน) และ $\sigma$ (ต่อรากของวัน) วิธีเดียวที่คูณกันแล้วหน่วยหายหมดโดยมี $\sigma$ ยกกำลังหนึ่งคือ $\sigma\sqrt{Q/V}$ ข้อมูลจริงให้เลขชี้กำลังราว 0.5 ถึง 0.6 ผลคือคำสั่งที่ใหญ่ขึ้นสี่เท่าจ่ายต่อดอลลาร์แพงขึ้นสองเท่า และจ่ายรวมแพงขึ้นแปดเท่า

ถ้าสมมติง่ายกว่านั้นว่าราคาขยับเป็นเส้นตรงตามเงินที่ซื้อไปแล้ว ต้นทุนรวมจะโตตามกำลังสอง ซึ่งใช้ในขั้นสุดท้าย สามรูปร่างนี้ (เส้นตรง กำลัง 1.5 กำลังสอง) ให้คำตอบหน้าตาต่างกัน และทั้งหมดมีหน่วยเป็นเงิน จึงควรหักออกจากค่าเป้าหมายตรง ๆ ด้วยตัวคูณ 1 แทนการใส่เป็นข้อบังคับลอย ๆ

ขั้นที่ 3 — เป้าหมายเมื่อไม่มีต้นทุน และการย้ายไปถึงคุ้มไหม

โจทย์ให้อะไรมาบ้าง: แบบจำลองสามสินทรัพย์ที่ห้าม short: $\mu=(0.12,\ 0.06,\ 0.15)$, ความผันผวน 20%/10%/35%, correlation 0.30/0.65/0.30, $\gamma=2$, ลงเงินครบ เป้าหมายเมื่อไม่มีต้นทุน (กฎห้าม short ไม่บีบ) คือ 46.41/50.09/3.50 ที่ $J=0.059175$ ค่าเป้าหมายเป็นผลตอบแทนเทียบเท่าต่อปี ส่วนต้นทุนจ่ายครั้งเดียว จึงเทียบกันบนสมมติฐานว่าถือพอร์ตใหม่หนึ่งปี

\[ \begin{aligned} Vw_0&=(0.0275,\ 0.0085,\ 0.0469),\\ w_0^{\mathsf T}Vw_0&=0.011+0.0034+0.00938=0.02378,\\ J(w_0)&=0.102-2(0.02378)=0.05444,\\ \Delta J&=0.059175-0.05444=0.004735,\\ \Delta w&\approx(+0.0641,\ +0.1009,\ -0.1650),\\ \text{TO}&\approx0.1650,\quad\text{cost}\approx\$16{,}502. \end{aligned} \]

คำตอบ: ย้ายไปเป้าหมายได้ประโยชน์ 0.004735 ต่อปี หรือ 47.3 bp (ราว \$236,700 บน \$50 ล้าน) จ่ายครั้งเดียว \$16,502 หรือ 3.30 bp คุ้มมาก พอร์ตเดิมเสี่ยงเกิน: ความผันผวน 15.42% เทียบ 12.61% ที่เป้าหมาย เพราะหุ้นเทค 20% ที่ correlation 0.65 กับหุ้นสหรัฐฯ

ตรวจเองใน 10 วินาที: ประโยชน์ส่วนเพิ่ม $g=\mu-4Vw_0=(0.0100,\ 0.0260,\ -0.0376)$ ต่างกันมาก หุ้นเทคติดลบคือยิ่งถือยิ่งแย่ ที่จุดดีที่สุดโดยไม่มีต้นทุน ค่าเหล่านี้ต้องเท่ากันทุกตัวที่ถือ (เงื่อนไขของตัวคูณ Lagrange) ที่นี่ห่างกัน 0.0636

ขั้นที่ 4 — objective ที่มีต้นทุน และเงื่อนไขที่จุดหักมุม

ต้นทุนแบบสัดส่วนคือ $c|w_i-w_{0i}|$ ต่อสินทรัพย์ มีมุมแหลมที่ $w_i=w_{0i}$ ทางขวาความชันคือ $+c$ ทางซ้ายคือ $-c$ ใช้เหตุผลแบบกำแพงของ KKT แยกเป็นสองข้างของมุม

\[ \begin{aligned} N(w)&=J(w)-c\textstyle\sum_i|w_i-w_{0i}|,\\ \text{buy}\ (w_i\gt w_{0i}):&\quad g_i-\nu=+c,\\ \text{sell}\ (w_i\lt w_{0i}):&\quad g_i-\nu=-c,\\ \text{hold}\ (w_i=w_{0i}):&\quad-c\le g_i-\nu\le c. \end{aligned} \]

$g_i-\nu$ คือประโยชน์สุทธิของการเพิ่มสินทรัพย์ $i$ หนึ่งหน่วยโดยเอาเงินมาจากก้อนรวม ($\nu$ คือราคาของงบ) ถ้าซื้อ ต้องซื้อจนประโยชน์ส่วนเพิ่มเหลือเท่าต้นทุน $c$ พอดี ถ้าขาย ต้องขายจนสิ่งที่เสียเท่าต้นทุนที่ประหยัด ถ้าไม่แตะเลย การขยับทางไหนก็ไม่คุ้ม: ประโยชน์ต้องอยู่ในช่วง $\pm c$ ค่าสัมบูรณ์เป็นชามหักมุม (convex) และ $J$ โค้งคว่ำ $N$ จึงโค้งคว่ำ เงื่อนไขชุดนี้จึงพอเพียงสำหรับคำตอบที่ดีที่สุด

ขั้นที่ 5 — คำตอบเมื่อมีต้นทุน 10 bp: หยุดก่อนเป้าหมายนิดเดียว

โจทย์ให้อะไรมาบ้าง: จาก 40/40/20 เดาทิศเหมือนขั้นที่แล้ว: ซื้อหุ้นสหรัฐฯ ซื้อพันธบัตร ขายหุ้นเทค เงื่อนไขสามข้อ ($g_i=\mu_i-4(Vw)_i$) กับงบอีกหนึ่ง เป็นระบบเชิงเส้นสี่ตัวที่ไม่รู้ ($w_1, w_2, w_3, \nu$)

\[ \begin{aligned} \mu_i-4(Vw)_i-\nu&=c\,s_i,\quad s=(+1,\ +1,\ -1),\\ w_1+w_2+w_3&=1,\\ w&\approx(0.45692,\ 0.50110,\ 0.04197),\\ \nu&\approx0.026227,\\ w^\star-w&\approx(+0.0072,\ -0.0002,\ -0.0070),\\ \text{TO}&\approx0.1580,\quad\text{cost}\approx\$15{,}803. \end{aligned} \]

คำตอบ: 45.69/50.11/4.20 ทิศการเทรดตรงกับที่เดา (ซื้อ ซื้อ ขาย) จึงผ่านเงื่อนไข หุ้นสหรัฐฯหยุดต่ำกว่าเป้าหมาย 0.72 จุด หุ้นเทคหยุดสูงกว่า 0.70 จุด เพราะช่วงท้ายของการย้าย ประโยชน์ส่วนเพิ่มเหลือน้อยกว่าต้นทุน 10 bp ค่าสุทธิหลังหักต้นทุน 0.058852 เทียบการเดินถึงเป้าหมายแล้วจ่ายเต็ม 0.058845 ดีกว่าแค่ 0.07 bp ต้นทุนเล็กขนาดนี้แทบไม่เปลี่ยนคำตอบเมื่อเทียบกับประโยชน์ทั้งปี

ตรวจเองใน 10 วินาที: ส่วนซื้อ $0.0569+0.1011=0.1580$ เท่าส่วนขาย 0.1580 ตามการนับการซื้อขายข้างบน พันธบัตรเกินเป้าหมาย 0.02 จุด ไม่ขัดกัน เพราะเมื่อหุ้นสหรัฐฯกับหุ้นเทคหยุดก่อน covariance ทำให้ส่วนผสมที่ดีที่สุดของตัวที่เหลือขยับตาม

ขั้นที่ 6 — แถบที่ไม่ควรเทรด และทำไมมันกว้างตามความถี่ที่คิดใหม่

ดูกรณีที่เล็กที่สุดก่อน: หุ้นหนึ่งตัว (ผลตอบแทนส่วนเกิน 10% ความผันผวน 20%) กับเงินสด $\gamma=2$ เป้าหมายเมื่อไม่มีต้นทุนคือ $w^\star=0.10/(2\cdot2\cdot0.04)=62.5\%$ ถ้าคิดใหม่ปีละ $n$ ครั้ง ผลตอบแทนคาดหวังและ variance ต่อรอบหารด้วย $n$ แต่ต้นทุนต่อการเทรดยังเท่าเดิม

\[ \begin{aligned} J_n(w)&=\frac{0.10w-0.08w^2}{n},\\ g_n(w)&=\frac{0.10-0.16w}{n},\\ \text{no trade}:&\quad|g_n(w_0)|\le c,\\ \text{band}&=w^\star\pm\frac{nc}{0.16},\\ n=1:&\quad61.875\%\ \text{to}\ 63.125\%,\\ n=12:&\quad55\%\ \text{to}\ 70\%,\\ n=52:&\quad30\%\ \text{to}\ 95\%. \end{aligned} \]

ขอบแถบคือจุดที่ประโยชน์ส่วนเพิ่มต่อรอบเท่ากับต้นทุนต่อหน่วยพอดี นอกแถบให้เทรดแค่ถึงขอบที่ใกล้ที่สุด ไม่ใช่ถึงเป้าหมาย เพราะหน่วยสุดท้ายก่อนถึงเป้าหมายได้ประโยชน์เกือบศูนย์แต่ยังเสีย 10 bp เต็ม นี่คือรูปภาพรวม: เริ่ม 40% ซื้อถึง 55% เริ่ม 80% ขายถึง 70% อยู่ที่ 60% ไม่ทำอะไร

ความกว้างโตตามความถี่ เพราะ optimizer ที่คิดทีละรอบเห็นประโยชน์ของการขยับแค่หนึ่งรอบ แต่จ่ายต้นทุนเต็ม คิดใหม่ทุกสัปดาห์จึงแทบไม่เทรดเลย (30% ถึง 95%) ข้อนี้ต้องระวังสองทาง: ถ้าถือตำแหน่งใหม่ต่อหลายรอบ ประโยชน์จริงอยู่นานกว่าหนึ่งรอบ คำตอบที่วางแผนหลายรอบจึงให้แถบแคบกว่าแบบรอบเดียว แต่หน้าตายังเป็นแถบเหมือนเดิม และถ้าไม่มีต้นทุนเลย ($c=0$) แถบหดเป็นจุด optimizer จะเทรดทุกครั้งที่ input ขยับ

ขั้นที่ 7 — เขตไม่เทรดของสามสินทรัพย์: 20 bp ในหน่วยประโยชน์ ไม่ใช่ในหน่วยน้ำหนัก

กลับมาที่สามสินทรัพย์และการถือหนึ่งปี คำตอบคือ “ไม่เทรดเลย” เมื่อทุกสินทรัพย์ผ่านเงื่อนไข hold พร้อมกัน คือมี $\nu$ ตัวเดียวที่ทำให้ทุก $g_i-\nu$ อยู่ในช่วง $\pm c$ ซึ่งเท่ากับว่า $g$ ที่มากที่สุดกับน้อยที่สุดห่างกันไม่เกิน $2c$ วัดความกว้างในหน่วยน้ำหนัก โดยเริ่มที่เป้าหมายแล้วเลื่อนไปทางซื้อหุ้นสหรัฐฯขายพันธบัตร $t$ หน่วย

\[ \begin{aligned} \max_ig_i-\min_ig_i&\le2c=0.002,\\ d&=(1,\ -1,\ 0),\quad Vd=(0.034,\ -0.004,\ 0.035),\\ g(w^\star+td)&=g(w^\star)-4t\,Vd\\ &=g(w^\star)+t\,(-0.136,\ 0.016,\ -0.140),\\ 0.156\,t&\le0.002,\quad t\le0.0128. \end{aligned} \]

ที่เป้าหมาย $g$ ทุกตัวเท่ากัน เลื่อนไป $t$ แล้วช่องที่ขึ้นมากที่สุด (พันธบัตร $+0.016t$) กับช่องที่ลงมากที่สุด (หุ้นเทค $-0.140t$) ห่างกัน $0.156t$ เขตจึงกว้าง $\pm1.28$ จุดของน้ำหนักในทิศนี้ ตรวจ: 47.61/48.89/3.50 ห่าง 0.00188 ไม่เทรด ส่วน 48.00/48.50/3.50 ห่าง 0.00249 เทรด ที่พอร์ตเดิม 40/40/20 ห่าง 0.0636 เกิน $2c$ ถึง 31.8 เท่า จึงต้องเทรด

ตัวเลข $2c=0.002$ อยู่ในหน่วยของประโยชน์ส่วนเพิ่ม ไม่ใช่น้ำหนัก ในหน่วยน้ำหนักเขตกว้างต่างกันตามทิศ: ทิศไหนที่ชามของความเสี่ยงแบน เขตในทิศนั้นยิ่งกว้าง และคำตอบที่ต้นทุน 10 bp (45.69/50.11/4.20) ตกที่มุมของเขตพอดี เพราะที่นั่น $g_1=g_2$ และทั้งคู่สูงกว่า $g_3$ เท่ากับ $2c$

ขั้นที่ 8 — เพดาน turnover 10%: คำตอบไปอยู่ที่มุม และการเดินตามสัดส่วนแพ้

ถ้าไม่มีเพดาน คำตอบใช้ turnover 15.80% เกิน 10% เพดานจึงบีบ เพดานเขียนเป็น $\tfrac12\sum_i|w_i-w_{0i}|\le0.10$ มีตัวคูณ $\theta\ge0$ ความชันของมันที่มุมคือ $\pm\theta/2$ มันจึงบวกเข้ากับ $c$ ในทุกเงื่อนไขที่จุดหักมุม เดาว่าไม่แตะหุ้นสหรัฐฯ แล้วใช้เพดานเต็ม: ขายหุ้นเทค 10 จุดซื้อพันธบัตร 10 จุด

\[ \begin{aligned} w&=(0.40,\ 0.50,\ 0.10),\\ g&=\mu-4Vw=(0.0258,\ 0.0262,\ 0.0072),\\ g_2-\nu&=c+\theta/2,\qquad g_3-\nu=-(c+\theta/2),\\ \nu&=\tfrac12(0.0262+0.0072)=0.0167,\\ c+\theta/2&=\tfrac12(0.0262-0.0072)=0.0095,\\ \theta&=2(0.0095-0.001)=0.017\ge0,\\ |g_1-\nu|&=0.0091\le0.0095,\\ w_{\text{prop}}&=w_0+0.606(w^\star-w_0)\\ &\approx(0.4388,\ 0.4612,\ 0.1000),\\ J(w_{\text{prop}})&\approx0.058440\lt J(w)=0.058570. \end{aligned} \]

บรรทัดของ $\nu$ และ $c+\theta/2$ ได้จากผลบวกกับผลต่างของสองสมการบน ตัวคูณของเพดานไม่ติดลบ และหุ้นสหรัฐฯที่ไม่แตะผ่านเงื่อนไข hold เงื่อนไขครบ โจทย์ convex จึงเป็นคำตอบที่ดีที่สุด เพดานที่บีบทำตัวเหมือนต้นทุน 95 bp ต่อขา แทนที่จะเป็น 10 bp คำตอบจึงเลือกเทรดเฉพาะคู่ที่คุ้มที่สุด: ที่พอร์ตเดิม ย้ายเงินหนึ่งหน่วยจากหุ้นเทคไปพันธบัตรได้ $0.0260-(-0.0376)=0.0636$ ไปหุ้นสหรัฐฯได้แค่ $0.0100+0.0376=0.0476$

แผนเดินตามสัดส่วน (60.6% ของทุกช่อง) ใช้ turnover และค่าธรรมเนียม \$10,000 เท่ากัน แต่แพ้ 1.30 bp ต่อปี ราว \$6,500 ต่อปี หุ้นเทคของทั้งสองแผนลงไปที่ 10.00% เท่ากัน ต่างกันแค่ว่าเงินไปไหน แผนสัดส่วนเอา 3.88 จุดไปหุ้นสหรัฐฯซึ่งขยับไปกับหุ้นเทค (correlation 0.65) จึงลดความเสี่ยงได้น้อยกว่า

ตัวคูณคือราคาของการผ่อนเล็ก ๆ: ผ่อนเพดานเป็น 10.1% ค่าสุทธิเพิ่ม 0.0000168 ตัวคูณทำนาย $0.017\times0.001=0.0000170$ แต่รูปแบบ “ไม่แตะหุ้นสหรัฐฯ” ใช้ได้ถึงเพดาน $4/39\approx10.26\%$ เท่านั้น ที่นั่นเงื่อนไข hold ของหุ้นสหรัฐฯชนขอบพอดี ($|g_1-\nu|=c+\theta/2$) เกินนั้นคำตอบเริ่มซื้อหุ้นสหรัฐฯด้วย ที่เพดาน 11% ได้ 40.76/50.24/9.00 และ $\theta$ ลดเหลือ 0.0137

ขั้นที่ 9 — ต้นทุนจากการดันราคา: โตตามกำลังสอง และทำให้ขยับทีละส่วน

10 bp คงที่ใช้ได้กับคำสั่งเล็ก คำสั่งใหญ่ดันราคาเอง สมมติว่าระหว่างซื้อ ราคาขยับขึ้นเป็นเส้นตรงตามเงินที่ซื้อไปแล้ว $x$ เทียบมูลค่าซื้อขายเฉลี่ยต่อวัน (ADV): ขึ้น $\eta x/\text{ADV}$ ต้นทุนส่วนเกินคือพื้นที่ใต้เส้นนั้น จากนั้นดูว่าต้นทุนกำลังสองเปลี่ยนรูปของคำตอบอย่างไร

\[ \begin{aligned} \text{extra}&=\int_0^{X}\eta\,\frac{x}{\text{ADV}}\,dx=\frac{\eta X^2}{2\,\text{ADV}},\\ X=qW:&\quad\frac{\text{extra}}{W}=\frac{\eta W}{2\,\text{ADV}}\,q^2=\kappa q^2,\\ \kappa&=\frac{0.06(50)}{2(250)}=0.006,\\ q=0.10:&\quad0.006(0.01)=0.00006,\\ 2\kappa q=c:&\quad q=\frac{0.001}{0.012}\approx0.0833,\\ \max_w&\ J_n(w)-\kappa(w-w_0)^2\\ \Rightarrow\ w&=w_0+\varphi\,(w^\star-w_0),\\ \varphi&=\frac{\gamma\sigma^2/n}{\gamma\sigma^2/n+\kappa}=\frac{0.00667}{0.01267}\approx0.526. \end{aligned} \]

ราคาขึ้นเป็นเส้นตรง พื้นที่ใต้เส้นจึงเป็นสามเหลี่ยม ได้กำลังสองหารสอง นี่คือที่มาของพจน์ $\kappa q^2$ ตัวเลข $\eta$ และ ADV เป็นสมมติ (ADV \$250 ล้าน เทียบกองทุน \$50 ล้าน ในหน่วยล้านดอลลาร์ และซื้อเท่ามูลค่าซื้อขายทั้งวันแล้วราคาขยับ 6%) ซื้อขาย 10% ของกองทุนเสียเพิ่ม 0.6 bp หรือ \$3,000 และที่ขนาดเกิน 8.33% ของกองทุน ต้นทุนส่วนเพิ่มจาก impact แซงค่าธรรมเนียม 10 bp $\kappa$ โตตามขนาดกองทุน $W$ กองใหญ่จึงถูกลงโทษหนักกว่าเมื่อเร่งเทรด

บรรทัดล่างคือกองทุนหุ้นกับเงินสดของแถบไม่เทรดข้างบน ที่คิดใหม่ทุกเดือน ($n=12$) แต่ต้นทุนเป็นกำลังสองแทนเส้นตรง ตั้ง derivative เป็นศูนย์: $0.16(w^\star-w)/n=2\kappa(w-w_0)$ จัดรูปได้ว่าต้องขยับสัดส่วน $\varphi$ ของระยะไปทางเป้าหมาย ไม่ใช่ทั้งหมด ไม่มีแถบ เพราะต้นทุนกำลังสองไม่มีมุม ขยับนิดเดียวเสียแทบศูนย์ จึงคุ้มที่จะขยับเสมอ แต่ขยับมากเสียแพง จาก 40% เดือนแรกไป 51.8% แล้ว 57.5%, 60.1%, 61.4% เข้าใกล้ 62.5% ทีละครึ่งทาง ยิ่งกลัวความเสี่ยงหรือหุ้นยิ่งผันผวน $\varphi$ ยิ่งใกล้ 1 (รีบปรับ) ยิ่ง impact แพง $\varphi$ ยิ่งเล็ก (ค่อย ๆ ปรับ) และถ้าเป้าหมายคือศูนย์ (ไม่มี edge แล้ว) กฎเดียวกันคือการขายออกแบบลดลงเป็นสัดส่วนคงที่ทุกรอบ

กับดัก: นิยาม turnover หน่วยของต้นทุน การเดินตามสัดส่วน และการไล่ noise

การเทรด 40/40/20 ไป 60/30/10 เดียวกัน ระบบหนึ่งรายงาน turnover 40% (ผลรวมค่าสัมบูรณ์) อีกระบบรายงาน 20% (one-way) ต่างกันสองเท่า ต้องเขียนนิยามกำกับเสมอ และต้นทุน 10 bp คิดบน gross ไม่ใช่บน one-way ถ้าคิดบน one-way จะได้ \$10,000 แทน \$20,000

ค่าเป้าหมายเป็นต่อปี ต้นทุนจ่ายต่อครั้ง ถ้าย้ายพอร์ตไปเป้าหมายแบบนั้นทุกเดือน ต้นทุนต่อปีคือราว 12 เท่าของ 3.30 bp และแถบไม่เทรดที่คำนวณด้วยประโยชน์ต่อปีจะแคบเกินไป 12 เท่า (±0.625 จุดแทน ±7.5 จุด ในตัวอย่างหุ้นกับเงินสด) ต้องเทียบในหน่วยเวลาเดียวกัน และอย่าอ่าน $2c=0.002$ ว่าเป็นความกว้าง 20 bp ของน้ำหนัก มันคือหน่วยประโยชน์ ในหน่วยน้ำหนักกว้าง ±1.28 จุดในทิศหนึ่งและแคบกว่านั้นมากในอีกทิศ

เดินตามสัดส่วนภายใต้เพดานแพ้คำตอบ KKT 1.30 bp ต่อปีโดยไม่มีใครเห็น เพราะค่าธรรมเนียมเท่ากันทุกดอลลาร์ และ optimizer ที่ไม่มีต้นทุนแล้วรันทุกวันจะเทรดทุกครั้งที่ input ขยับ ทั้งที่หน้า Markowitzแสดงว่าผลตอบแทนคาดหวังผิด 1 จุดขยับน้ำหนักได้ 6.58 จุด การเทรดตามนั้นคือจ่ายต้นทุนเพื่อไล่ noise แถบไม่เทรดคือสิ่งที่กันไม่ให้เกิดเรื่องนี้

ใช้ทำอะไรบนโต๊ะจริง

นโยบาย rebalance ส่วนใหญ่คือแถบไม่เทรดในรูปที่ง่ายขึ้น: ปล่อยให้น้ำหนักไหลได้ในช่วงหนึ่งรอบน้ำหนักเป้าหมายแล้วค่อยปรับกลับถึงขอบ แถบของหุ้นกับเงินสดและหกเหลี่ยมของสามสินทรัพย์บอกว่าความกว้างที่เหมาะขึ้นกับต้นทุน ความถี่ที่คิดใหม่ และความโค้งของความเสี่ยงในแต่ละทิศ ไม่ควรเป็นตัวเลขเดียวกันทุกสินทรัพย์ เพดาน turnover ต่อรอบเป็นเรื่องปกติของกองทุน แต่ถ้าเป้าจริงคือคุมต้นทุน การใส่ต้นทุนเข้า objective ตรง ๆ ดีกว่า เพราะราคาเป็นตัวเลขที่ตั้งไว้ก่อนและคงที่ ส่วนราคาแฝงของเพดาน ($\theta$) กระโดดตามสภาพตลาดโดยไม่มีใครเห็น ถ้าใช้เพดาน ควรรายงาน $\theta$ คู่กับคำตอบเสมอ

ต้นทุนจาก impact กำหนดว่ากลยุทธ์หนึ่งรับเงินได้เท่าไรก่อนผลตอบแทนหายหมด (strategy capacity) การแบ่งคำสั่งใหญ่ตามเวลาให้ต้นทุนรวมต่ำสุดคือ Almgren–Chriss execution ซึ่งใช้พจน์กำลังสองแบบเดียวกับ $\kappa q^2$ ข้างบน และกลไกของ spread กับ order book อยู่ที่market microstructure

โจทย์ตรวจความเข้าใจ

1. ในทิศสลับหุ้นสหรัฐฯกับพันธบัตร ความโค้งของ $-J$ คือ $h=2\gamma\,d^{\mathsf T}Vd=4(0.038)=0.152$ ถ้ามีแต่ต้นทุน impact $\kappa=0.006$ ต่อขา การสลับไปหาเป้าหมายที่ห่าง $t^\star$ ควรทำแค่ไหนในรอบนี้

เฉลย

สลับ $t$ หน่วยเสียประโยชน์ $\tfrac h2(t-t^\star)^2$ จากการยังไม่ถึงเป้า และเสีย impact $\kappa t^2$ สองขา รวม $2\kappa t^2$ ตั้ง derivative เป็นศูนย์: $-h(t-t^\star)-4\kappa t=0$ ได้ $t=\dfrac{h}{h+4\kappa}t^\star=\dfrac{0.152}{0.176}t^\star\approx0.864t^\star$ คือเดิน 86.4% ของทางต่อรอบ ต้นทุนกำลังสองให้การปรับบางส่วน ต่างจากต้นทุนเส้นตรงที่ให้แถบไม่เทรด สัดส่วนนี้สูงกว่า 52.6% ของกองทุนหุ้นกับเงินสด เพราะเทียบกับประโยชน์ทั้งปี ไม่ใช่รายเดือน

2. ถ้าค่าซื้อขายเป็น 20 bp แทน 10 bp คำตอบจาก 40/40/20 (ที่ 10 bp ได้ 45.69/50.11/4.20) และความกว้าง ±1.28 จุดของเขตไม่เทรดเปลี่ยนอย่างไร

เฉลย

แก้ระบบเดิมด้วย $c=0.002$ ได้ 44.97/50.13/4.90 ทิศการเทรดยังเป็นซื้อ ซื้อ ขาย จึงผ่าน หยุดห่างเป้าหมายมากขึ้นราวสองเท่า (หุ้นสหรัฐฯขาด 1.44 จุด) เขตไม่เทรดในทิศสลับหุ้นสหรัฐฯกับพันธบัตรเป็น $2(0.002)/0.156\approx2.56$ จุด กว้างขึ้นสองเท่าตามต้นทุน เพราะขอบเขตเป็นเส้นตรงในต้นทุน

function checkWeights(w, n = 3) {
  if (!Array.isArray(w) || w.length !== n || !w.every(Number.isFinite)) throw new TypeError(`Need ${n} finite weights`);
  if (Math.abs(w.reduce((s, v) => s + v, 0) - 1) > 1e-12) throw new RangeError('Weights must sum to 1');
}
// Trade accounting: one-way turnover is half the sum of absolute weight changes.
function tradeAccount(w0, w, nav, costRate) {
  checkWeights(w0, w0.length); checkWeights(w, w0.length);
  if (!(nav > 0) || !(costRate >= 0)) throw new RangeError('NAV must be positive and the cost rate non-negative');
  const dw = w.map((v, i) => v - w0[i]), l1 = dw.reduce((s, v) => s + Math.abs(v), 0);
  return {dw, l1, turnover: l1 / 2, grossUSD: nav * l1, costUSD: nav * costRate * l1, costFraction: costRate * l1};
}
function solveLinear(A, b) {
  const n = A.length, M = A.map((r, i) => [...r, b[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (Math.abs(M[r][c]) > Math.abs(M[p][c])) p = r;
    if (Math.abs(M[p][c]) < 1e-14) throw new RangeError('Singular system');
    [M[c], M[p]] = [M[p], M[c]];
    for (let r = 0; r < n; r++) { if (r === c) continue; const f = M[r][c] / M[c][c]; for (let k = c; k <= n; k++) M[r][k] -= f * M[c][k]; }
  }
  return M.map((r, i) => r[n] / r[i]);
}

// Kink conditions with a proportional cost k per unit traded: g_i - nu = k s_i for traded assets (s_i = +1 buy, -1 sell).
function solveSigns(signs, k, w0) {
  const traded = [0, 1, 2].filter(i => signs[i] !== 0), held = [0, 1, 2].filter(i => signs[i] === 0);
  const rows = [], rhs = [];
  traded.forEach(i => { rows.push([...traded.map(j => 2 * gamma * V[i][j]), 1]); rhs.push(mu[i] - k * signs[i] - held.reduce((s, j) => s + 2 * gamma * V[i][j] * w0[j], 0)); });
  rows.push([...traded.map(() => 1), 0]); rhs.push(1 - held.reduce((s, j) => s + w0[j], 0));
  const sol = solveLinear(rows, rhs), w = [...w0];
  traded.forEach((i, a) => { w[i] = sol[a]; });
  return {w, nu: sol[traded.length]};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • one-way turnover คือ $\tfrac12\lVert\Delta w\rVert_1$ ส่วนค่าธรรมเนียมคิดบน gross ซึ่งเป็นสองเท่า: 40/40/20 ไป 60/30/10 คือ turnover 20% gross \$20 ล้าน ต้นทุน \$20,000
  • ต้นทุนมีสามก้อน: spread กับค่าธรรมเนียม (เส้นตรง) impact ชั่วคราว และ impact ถาวร ต้นทุนต่อดอลลาร์ของ impact โตตามราก $\sqrt{Q/V}$: คำสั่งใหญ่สี่เท่าจ่ายรวมแพงแปดเท่า
  • ต้นทุนแบบสัดส่วนให้เงื่อนไข: ซื้อจน $g_i-\nu=c$ ขายจน $g_i-\nu=-c$ ไม่แตะเมื่อ $|g_i-\nu|\le c$ จาก 40/40/20 ได้ 45.69/50.11/4.20 ซึ่งอยู่ที่มุมของเขตไม่เทรด
  • แถบไม่เทรดคือที่ที่ประโยชน์ส่วนเพิ่มต่อรอบไม่ชนะต้นทุน: หุ้นกับเงินสดที่คิดใหม่ทุกเดือนได้ 55% ถึง 70% นอกแถบเทรดแค่ถึงขอบ และความกว้างโตตามความถี่ที่คิดใหม่
  • เพดาน turnover ที่บีบคือต้นทุนแฝง $c+\theta/2$: ที่ 10% คำตอบคือมุม 40/50/10 ด้วย $\theta=0.017$ และการเดินตามสัดส่วนแพ้ 1.3 bp ต่อปี
  • impact กำลังสองไม่มีมุม จึงไม่มีแถบ แต่ขยับทีละส่วน $\varphi=\gamma\sigma^2/(\gamma\sigma^2+\kappa)$: 52.6% ต่อเดือนในตัวอย่างหุ้นกับเงินสด
