12.8 Mean-Variance with Transaction Costs

เมื่อการซื้อขายเสียเงิน พอร์ตที่ดีที่สุดขึ้นกับว่าตอนนี้ถืออะไรอยู่: ค่าซื้อขายที่คงที่ต่อดอลลาร์ทำให้เกิดแถบที่ไม่ควรเทรด ต้นทุนที่โตเร็วกว่าเส้นตรงทำให้ค่อย ๆ ขยับทีละส่วน และเพดาน turnover ทำตัวเหมือนค่าซื้อขายที่แพงขึ้น

กองทุนแห่งหนึ่งมีเงิน \$50 ล้าน แบ่งลงของสามอย่าง: หุ้นสหรัฐฯ พันธบัตร (ตราสารหนี้ที่จ่ายดอกเบี้ยสม่ำเสมอ ราคานิ่งกว่าหุ้นมาก) และหุ้นเทค ปีนี้หุ้นเทควิ่งขึ้นแรง ส่วนของหุ้นเทคจึงโตจนกินเงินกองทุนไป 20% มากเกินกว่าที่ผู้จัดการต้องการ เขาอยากย้ายเงินออกจากหุ้นเทค แต่การซื้อขายทุกครั้งเสียเงิน และกติกาของกองทุนก็จำกัดว่ารอบนี้ซื้อขายได้ไม่เกินเท่าไร

ของที่รู้:

  • มูลค่ากองทุน $W=\$50$ ล้าน
  • น้ำหนักที่ถืออยู่ $w_0=(40\%,\ 40\%,\ 20\%)$ น้ำหนักคือสัดส่วนของเงินกองทุนที่อยู่ในแต่ละตัว เรียงเป็นหุ้นสหรัฐฯ พันธบัตร หุ้นเทค เสมอทั้งหน้า
  • พอร์ตเป้าหมาย $w^\star=(46.41\%,\ 50.09\%,\ 3.50\%)$ คือพอร์ตที่ดีที่สุดถ้าซื้อขายได้ฟรี หน้าKKT conditionsหาไว้แล้วด้วย optimizer (โปรแกรมที่หาน้ำหนักซึ่งให้คะแนนพอร์ตสูงสุด) โดยห้าม short คือห้ามยืมของมาขาย ขั้นที่ 3 ข้างล่างจะให้ตัวเลขที่ใช้ครบและตรวจซ้ำให้ดู
  • ค่าซื้อขาย $c$ คือ 10 bp ของเงินทุกดอลลาร์ที่ซื้อหรือขาย (bp หรือ basis point คือ 0.01%) จึงได้ $c=10\times0.0001=0.001$
  • กติกาของกองทุน (mandate) ให้ turnover รอบนี้ไม่เกิน $\tau=10\%$ (turnover คือส่วนของกองทุนที่เปลี่ยนมือ นับฝั่งซื้อฝั่งเดียว ขั้นที่ 1 อธิบายวิธีนับ)

ถ้าย้ายไปถึงเป้าหมายเลย turnover จะเป็น 16.50% (ขั้นที่ 3 คำนวณให้ดู) ซึ่งเกินเพดาน ผู้จัดการจึงย่อการย้ายลงให้พอดีเพดาน คือขยับทุกตัวไปทางเป้าหมายด้วยสัดส่วน $p$ เท่ากัน

\[ \begin{aligned} p&=\frac{0.10}{0.1650}=0.606,\\ w&=w_0+p\,(w^\star-w_0)\\ &\approx(43.88\%,\ 46.12\%,\ 10.00\%). \end{aligned} \]

นี่คือพอร์ตที่ดีที่สุดภายใต้เพดานไหม

ลองตอบก่อนเปิดเฉลย

ไม่ใช่ พอร์ตที่ดีที่สุดคือไม่แตะหุ้นสหรัฐฯเลย ขายหุ้นเทค 10 จุด แล้วเอาเงินนั้นไปซื้อพันธบัตร 10 จุด ได้ 40/50/10 ทั้งสองแผนซื้อ 10% และขาย 10% ของกองทุน เงินที่ผ่านมือรวม $0.10+0.10=0.20$ ของกองทุน จึงเสียค่าซื้อขายเท่ากันเป๊ะ

\[ \begin{aligned} \text{fee}&=c\,W\times0.20\\ &=0.001\times50{,}000{,}000\times0.20\\ &=\$10{,}000. \end{aligned} \]

แต่คะแนนของพอร์ต $J$ (ผลตอบแทนคาดหวังต่อปี หักค่าปรับความเสี่ยง ขั้นที่ 3 นิยามไว้) ไม่เท่ากัน ขั้นที่ 8 คำนวณให้ดู

\[ \begin{aligned} \Delta J&=0.058570-0.058440\\ &=0.000130,\\ \Delta J\times W&=0.000130\times50{,}000{,}000\\ &\approx\$6{,}500. \end{aligned} \]

แผน 40/50/10 จึงดีกว่า 1.30 bp ต่อปี หรือราว \$6,500 ต่อปี โดยจ่ายค่าซื้อขายเท่ากัน เหตุผลคือ เมื่อซื้อขายได้จำกัด เงินทุกดอลลาร์ที่ย้ายต้องไปที่ที่ได้ประโยชน์มากที่สุด การย้ายจากหุ้นเทคไปพันธบัตรได้ประโยชน์ต่อดอลลาร์สูงสุด แผนตามสัดส่วนเอาเงินส่วนหนึ่งไปหุ้นสหรัฐฯ ซึ่งขึ้นลงไปพร้อมหุ้นเทค จึงลดความเสี่ยงได้น้อยกว่า ขั้นที่ 8 ยังได้ตัวคูณของเพดาน $\theta=0.017$ ซึ่งบอกว่าถ้าผ่อนเพดานอีกนิด คะแนนจะเพิ่มเท่าไร

ภาพรวมก่อนลงสูตร

หน้าก่อน ๆ ในบทนี้หาพอร์ตที่ดีที่สุดโดยถือว่าย้ายเงินได้ฟรี คำตอบจึงไม่สนว่าตอนนี้ถืออะไรอยู่ ของจริงไม่ฟรี การซื้อขายแต่ละครั้งเสียเงินสามทาง คือค่าคอมมิชชันที่จ่ายให้โบรกเกอร์ ส่วนต่างระหว่างราคาซื้อกับราคาขายในตลาด (bid–ask spread) และราคาที่ขยับหนีเมื่อเราสั่งก้อนใหญ่ (market impact) ต้นทุนพวกนี้มีหน่วยเป็นเงิน เหมือนผลตอบแทน หน้านี้จึงหักมันออกจากคะแนนของพอร์ตตรง ๆ

ค่าซื้อขายที่คงที่ต่อดอลลาร์เขียนด้วยค่าสัมบูรณ์ $c\,|w_i-w_{0i}|$ กราฟของมันมีมุมหักตรงจุด “ไม่ซื้อไม่ขาย” ตรงมุมนั้นหา derivative ไม่ได้ เราจึงตั้ง derivative เป็นศูนย์แบบเดิมไม่ได้ เครื่องมือที่ใช้แทนคือKKT conditions ซึ่งแยกกรณีซื้อ ขาย และอยู่เฉย ออกจากกัน

สิ่งที่หน้านี้จะพบคือ รูปร่างของต้นทุนกำหนดรูปร่างของคำตอบ

  • ต้นทุนคงที่ต่อดอลลาร์ (โตเป็นเส้นตรงตามเงินที่เทรด) ทำให้เกิดแถบรอบเป้าหมาย ถ้าอยู่ในแถบ อยู่เฉยดีที่สุด ถ้าหลุดแถบ ให้เทรดแค่ถึงขอบแถบ ไม่ใช่ถึงเป้าหมาย
  • ต้นทุนที่โตเร็วกว่าเส้นตรง (ยิ่งสั่งก้อนใหญ่ ยิ่งแพงต่อดอลลาร์) ไม่มีแถบ แต่ทำให้ขยับไปทางเป้าหมายทีละส่วนทุกรอบ
  • เพดาน turnover ที่บีบ ทำตัวเหมือนค่าซื้อขายที่แพงขึ้น และดันคำตอบไปอยู่ที่มุม คือเทรดแค่บางตัว

ลำดับของหน้า: นับการซื้อขายให้ไม่กำกวม ดูว่าต้นทุนมาจากไหน ตรวจว่าการย้ายไปเป้าหมายคุ้มไหม ตั้งเงื่อนไขที่มุมหัก แก้พอร์ตเมื่อมีค่าซื้อขาย หาแถบที่ไม่ควรเทรด (หนึ่งสินทรัพย์ก่อน แล้วสามสินทรัพย์) ใส่เพดาน turnover และจบที่ต้นทุนจากการดันราคา

ศัพท์ที่ใช้ในหัวข้อนี้
bp (basis point)
หนึ่งในร้อยของหนึ่งเปอร์เซ็นต์ คือ 0.01% หรือ 0.0001 ค่าซื้อขาย 10 bp ของเงิน \$1,000,000 จึงเป็น $0.001\times1{,}000{,}000=\$1{,}000$
Rebalance
การซื้อขายเพื่อดึงน้ำหนักของพอร์ตกลับไปหาน้ำหนักที่ต้องการ หลังจากราคาที่ขึ้นลงทำให้น้ำหนักไหลออกไป
Short และ long-only
short คือยืมของมาขายก่อน แล้วซื้อคืนทีหลัง ทำให้น้ำหนักติดลบได้ กองทุน long-only ห้ามทำแบบนี้ น้ำหนักทุกตัวจึงต้องไม่ติดลบ
Mandate
กติกาที่ผู้ลงทุนตั้งให้กองทุนต้องทำตาม เช่น ห้าม short หรือซื้อขายต่อรอบได้ไม่เกินเท่าไร
Transaction cost
เงินที่เสียเมื่อซื้อขายเพื่อเปลี่ยนของที่ถือ มีค่าคอมมิชชัน ครึ่งหนึ่งของ bid–ask spread และ market impact หน้านี้หักมันออกจากประโยชน์ของการเทรด
Bid–ask spread
ในตลาดมีสองราคาเสมอ ราคาที่มีคนรอซื้อ (bid) ต่ำกว่าราคาที่มีคนรอขาย (ask) ถ้าซื้อทันทีต้องจ่าย ask ถ้าขายทันทีได้แค่ bid ช่องว่างนี้คือ spread เมื่อเทียบกับราคากลาง การซื้อหรือขายหนึ่งครั้งจึงเสียครึ่งหนึ่งของ spread
One-way turnover
ส่วนของกองทุนที่ถูกเปลี่ยน นับฝั่งซื้อฝั่งเดียว (ซึ่งเท่ากับฝั่งขาย) เท่ากับครึ่งหนึ่งของผลรวมค่าสัมบูรณ์ของการเปลี่ยนน้ำหนัก ใช้วัดว่าพอร์ตเปลี่ยนหน้าไปเท่าไร
Gross traded notional
เงินที่ซื้อบวกเงินที่ขาย ไม่หักกลบกัน ค่าซื้อขายคิดจากยอดนี้ จึงเป็นสองเท่าของ one-way turnover
No-trade region
แถบหรือเขตรอบเป้าหมาย ที่ประโยชน์ของการขยับอีกหนึ่งหน่วยยังไม่คุ้มค่าซื้อขาย ถ้าพอร์ตอยู่ในเขตนี้ อยู่เฉยดีที่สุด ถ้าอยู่นอกเขต ให้เทรดแค่ถึงขอบ
Turnover cap
เพดานของ one-way turnover ต่อรอบ กองทุนใช้คุมต้นทุน ภาษี และงานหลังบ้าน ตัวคูณของเพดานนี้บอกว่าการเทรดเพิ่มอีกหนึ่งหน่วยมีค่าเท่าไร
Market impact
ราคาที่ขยับหนีเพราะคำสั่งของเราเอง ส่วนชั่วคราวคลายกลับหลังเทรดเสร็จ ส่วนถาวรค้างอยู่ ยิ่งคำสั่งใหญ่เมื่อเทียบกับยอดซื้อขายของทั้งตลาด ต้นทุนต่อดอลลาร์ยิ่งสูง
ADV (average daily volume)
มูลค่าที่ทั้งตลาดซื้อขายหุ้นตัวหนึ่งต่อวันโดยเฉลี่ย ใช้เป็นตัวเทียบว่าคำสั่งของเราใหญ่แค่ไหน
Partial adjustment
การขยับไปทางเป้าหมายแค่บางส่วนในแต่ละรอบ เป็นวิธีที่ดีที่สุดเมื่อต้นทุนโตตามกำลังสองของขนาดคำสั่ง
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$W$มูลค่ากองทุนก่อนปรับ \$50 ล้านดอลลาร์
$w_0,\ w,\ \Delta w$น้ำหนักเดิม น้ำหนักใหม่ และส่วนต่าง $\Delta w=w-w_0$สัดส่วนของเงินกองทุน
$w^\star$พอร์ตเป้าหมาย คือพอร์ตที่ดีที่สุดถ้าซื้อขายได้ฟรีสัดส่วนของเงินกองทุน
$c$ค่าซื้อขายคงที่ 10 bp = 0.001 ต่อเงินที่ซื้อหรือขายหนึ่งดอลลาร์ดอลลาร์ต่อดอลลาร์ที่ซื้อขาย
$\mu,\ V$ผลตอบแทนคาดหวังต่อปีของแต่ละตัว และ covariance matrix ของผลตอบแทนต่อปี
$\gamma$ตัวเลขที่บอกว่ากองทุนกลัวความเสี่ยงแค่ไหน หน้านี้ใช้ 2ไม่มีหน่วย
$J(w)$คะแนนของพอร์ตแบบ mean-variance $\mu^{\mathsf T}w-\gamma\,w^{\mathsf T}Vw=\mu^{\mathsf T}w-2w^{\mathsf T}Vw$ คือผลตอบแทนคาดหวัง หักค่าปรับความเสี่ยงผลตอบแทนต่อปี
$g_i,\ \nu$ประโยชน์ส่วนเพิ่ม $g_i=\partial J/\partial w_i$ (คะแนนที่ได้เพิ่มเมื่อเพิ่มน้ำหนักตัว $i$ หนึ่งหน่วย) และตัวคูณ Lagrange ของข้อบังคับน้ำหนักรวมเป็น 1ต่อหน่วยน้ำหนัก
$\tau,\ \theta$เพดาน turnover และตัวคูณของเพดานนั้นสัดส่วนของเงินกองทุน, ต่อหน่วย turnover
$\kappa,\ \varphi$ตัวคูณของต้นทุน impact แบบกำลังสอง และสัดส่วนของระยะที่ขยับไปทางเป้าหมายต่อรอบสัดส่วนของเงินกองทุนต่อ (น้ำหนักที่ซื้อขาย)², ไม่มีหน่วย

ขั้นที่ 1 — นับการซื้อขายให้ไม่กำกวม

ค่าซื้อขายคิดตามเงินที่ซื้อขาย ก่อนคิดต้นทุนจึงต้องตกลงกันว่า “ซื้อขายไปเท่าไร” นับอย่างไร เรื่องนี้ไม่เล็ก ถ้าขายพันธบัตร \$1 แล้วเอาไปซื้อหุ้น \$1 ระบบหนึ่งนับเป็น \$1 อีกระบบนับเป็น \$2 ต่างกันสองเท่า

ลองนับกับตัวเลขกลม ๆ ก่อน: ย้ายจาก 40/40/20 ไป 60/30/10 ให้ $\Delta w_i$ คือน้ำหนักที่เปลี่ยนของตัว $i$ แล้วแยกเป็นส่วนซื้อ $u_i=\max(\Delta w_i,\ 0)$ กับส่วนขาย $v_i=\max(-\Delta w_i,\ 0)$ ทั้งสองส่วนไม่ติดลบ

\[ \begin{aligned} \Delta w&=(0.60-0.40,\ 0.30-0.40,\ 0.10-0.20)\\ &=(+0.20,\ -0.10,\ -0.10),\\ \textstyle\sum_i\Delta w_i&=1-1=0,\\ \Delta w_i&=u_i-v_i\ \Rightarrow\ \textstyle\sum_iu_i=\sum_iv_i,\\ \lVert\Delta w\rVert_1&=\textstyle\sum_i(u_i+v_i)=2\sum_iu_i\\ &=2(0.20)=0.40,\\ \text{TO}&=\tfrac12\lVert\Delta w\rVert_1=0.20,\\ \text{cost}&=c\,W\lVert\Delta w\rVert_1\\ &=0.001\times50{,}000{,}000\times0.40\\ &=\$20{,}000. \end{aligned} \]

สิ่งที่ต้องเห็นคือ ส่วนซื้อเท่าส่วนขายเสมอ เพราะน้ำหนักของพอร์ตเดิมรวมได้ 1 และน้ำหนักของพอร์ตใหม่ก็รวมได้ 1 การเปลี่ยนน้ำหนักจึงรวมได้ $1-1=0$ พูดง่าย ๆ คือเงินที่ใช้ซื้อต้องมาจากการขาย

ผลรวมค่าสัมบูรณ์ $\lVert\Delta w\rVert_1$ (L1 norm จากหน้าnorm) นับทั้งขาซื้อและขาขาย เงินก้อนเดียวกันจึงถูกนับสองครั้ง one-way turnover (TO) หารด้วยสอง เพื่อให้ได้ส่วนของพอร์ตที่เปลี่ยนจริง คือ 20% ของกองทุน หรือ $0.20\times\$50$ ล้าน $=\$10$ ล้าน

แต่ค่าซื้อขายคิดจากเงินที่ผ่านมือทั้งสองขา ฐานของต้นทุนจึงเป็นยอด gross \$20 ล้าน (ซื้อ \$10 ล้าน บวกขาย \$10 ล้าน) คูณด้วย 10 bp ได้ \$20,000 คิดเป็นส่วนของกองทุน $20{,}000/50{,}000{,}000=0.0004$ หรือ 4 bp

ขั้นที่ 2 — ต้นทุนมาจากไหน และโตตามขนาดคำสั่งอย่างไร

ขั้นที่แล้วถือว่าค่าซื้อขายคงที่ 10 bp ต่อดอลลาร์ ซึ่งจริงแค่กับคำสั่งเล็ก ๆ ก่อนใช้ตัวเลขนี้ต่อ เราต้องรู้ว่าต้นทุนจริงมาจากไหน และโตตามขนาดคำสั่งแบบไหน เพราะรูปร่างของต้นทุนจะกำหนดหน้าตาของคำตอบในขั้นหลัง ๆ ให้ $Q$ คือขนาดคำสั่งเป็นดอลลาร์ ต้นทุนที่คาดไว้ของคำสั่งหนึ่งแยกได้เป็นสามก้อน ส่วนสองแถวล่างเทียบคำสั่ง B ที่ใหญ่กว่าคำสั่ง A สี่เท่า

\[ \begin{aligned} \text{cost}&=\underbrace{c\,Q}_{\text{spread, fees}}\\ &\quad+\underbrace{\text{temporary}}_{\text{slippage}}\\ &\quad+\underbrace{\text{permanent}}_{\text{information}},\\ \frac{\text{cost}}{Q}&\approx Y\,\sigma\sqrt{\frac{Q}{V}},\\ \text{cost}&\approx Y\,\sigma\,\frac{Q^{3/2}}{\sqrt V},\\ \frac{(\text{cost}/Q)_B}{(\text{cost}/Q)_A}&=\sqrt{4}=2,\\ \frac{\text{cost}_B}{\text{cost}_A}&=4^{3/2}=8. \end{aligned} \]

ก้อนแรกคือค่าคอมมิชชันบวกครึ่งหนึ่งของ bid–ask spread ถ้าเราซื้อทันที ต้องจ่ายราคาที่คนรอขายตั้งไว้ ซึ่งสูงกว่าราคากลางอยู่ครึ่งหนึ่งของ spread ก้อนนี้คิดเป็นอัตราคงที่ต่อดอลลาร์ จึงเขียนเป็น $c\,Q$ ก้อนที่สองคือราคาที่ขยับหนีระหว่างที่เรากำลังทยอยซื้อ แล้วคลายกลับหลังเราหยุด (temporary impact หรือ slippage) ก้อนที่สามคือราคาที่ขยับแล้วไม่กลับ (permanent impact) เพราะตลาดอ่านคำสั่งของเราเป็นข่าวว่ามีคนรู้อะไรบางอย่าง สำหรับการปรับพอร์ต ก้อนแรกกับก้อนที่สองใหญ่ที่สุด

แถวที่มีรากที่สองคือกฎรากที่สองของ impact (square-root law) ซึ่งเป็นสิ่งที่วัดได้จากการเทรดจริง ตัวแปรของมันมีสี่ตัว: $Q$ ขนาดคำสั่ง (ดอลลาร์), $V$ มูลค่าที่ทั้งตลาดซื้อขายหุ้นตัวนั้นในช่วงเดียวกัน (ดอลลาร์ต่อวัน), $\sigma$ ความผันผวนรายวันของหุ้น และ $Y$ ค่าคงที่ที่แต่ละโต๊ะต้องประมาณจากการเทรดของตัวเอง

ทำไมต้องเป็นราก เหตุผลหนึ่งมาจากหน่วย ต้นทุนต่อดอลลาร์ไม่มีหน่วย $Q/V$ มีหน่วยเป็นวัน และ $\sigma$ มีหน่วยเป็นต่อรากของวัน วิธีเดียวที่ใช้ $\sigma$ ยกกำลังหนึ่งแล้วหน่วยหักล้างกันหมดคือ $\sigma\sqrt{Q/V}$ ข้อมูลการเทรดจริงก็ให้เลขชี้กำลังของ $Q/V$ ราว 0.5 ถึง 0.6 สอดคล้องกัน

ผลที่ตามมาดูได้จากสองแถวล่าง ถ้าคำสั่ง B ใหญ่กว่าคำสั่ง A สี่เท่า (เช่น 16% กับ 4% ของยอดซื้อขายทั้งวัน) B จ่ายต่อดอลลาร์แพงกว่า $\sqrt4=2$ เท่า และเพราะ B มีดอลลาร์มากกว่าสี่เท่า B จึงจ่ายรวมแพงกว่า $4\times2=8$ เท่า

ขั้นสุดท้ายของหน้าใช้แบบที่ง่ายกว่านี้ คือสมมติว่าราคาขยับเป็นเส้นตรงตามเงินที่ซื้อไปแล้ว แบบนั้นต้นทุนรวมโตตามกำลังสองของขนาดคำสั่ง รวมแล้วเรามีต้นทุนสามรูปร่าง: เส้นตรง ($Q$) กำลัง 1.5 ($Q^{3/2}$) และกำลังสอง ($Q^2$) แต่ละรูปร่างให้คำตอบหน้าตาต่างกัน ทุกแบบมีหน่วยเป็นเงิน จึงหักออกจากคะแนนของพอร์ตได้ตรง ๆ ดีกว่าการตั้งเป็นข้อบังคับลอย ๆ ที่ไม่มีราคา

ขั้นที่ 3 — เป้าหมายเมื่อไม่มีต้นทุน และการย้ายไปถึงคุ้มไหม

กลับมาที่กองทุนในโจทย์เปิดหน้า ก่อนคิดว่าต้นทุนเปลี่ยนคำตอบอย่างไร ต้องรู้ก่อนว่าการย้ายไปเป้าหมายได้ประโยชน์เท่าไร และเสียค่าซื้อขายเท่าไร ถ้าประโยชน์น้อยกว่าค่าซื้อขาย ก็ไม่ควรขยับเลย

โจทย์ให้อะไรมาบ้าง: ตัวเลขชุดเดียวกับหน้าKKT conditions (สมมติทั้งหมด) เรียงหุ้นสหรัฐฯ พันธบัตร หุ้นเทค

  • ผลตอบแทนคาดหวังต่อปี $\mu=(0.12,\ 0.06,\ 0.15)$
  • ความผันผวนต่อปี $\sigma=(20\%,\ 10\%,\ 35\%)$
  • correlation หุ้นสหรัฐฯ–พันธบัตร 0.30 หุ้นสหรัฐฯ–หุ้นเทค 0.65 พันธบัตร–หุ้นเทค 0.30
  • $\gamma=2$ น้ำหนักต้องรวมเป็น 1 (ลงเงินครบ) และห้ามติดลบ

covariance matrix $V$ สร้างจากความผันผวนกับ correlation: ช่องทแยงคือ $\sigma_i^2$ ช่องอื่นคือ $\rho_{ij}\sigma_i\sigma_j$ เช่นหุ้นสหรัฐฯ–หุ้นเทคได้ $0.65\times0.20\times0.35=0.0455$

\[ V=\begin{pmatrix}0.0400&0.0060&0.0455\\0.0060&0.0100&0.0105\\0.0455&0.0105&0.1225\end{pmatrix} \]

คะแนนของพอร์ตคือ $J(w)=\mu^{\mathsf T}w-\gamma\,w^{\mathsf T}Vw$ คือผลตอบแทนคาดหวัง หักค่าปรับความเสี่ยง หน่วยเป็นผลตอบแทนต่อปี หน้า KKT conditions หาเป้าหมาย $w^\star=(46.41\%,\ 50.09\%,\ 3.50\%)$ ไว้แล้ว ได้ $J(w^\star)=0.059175$ และกฎห้าม short ไม่บีบ เพราะทุกน้ำหนักเป็นบวกอยู่แล้ว ข้างล่างคำนวณคะแนนของพอร์ตเดิม แล้วเทียบกับค่าซื้อขาย ค่าซื้อขายจ่ายครั้งเดียว แต่คะแนนเป็นต่อปี จึงเทียบกันโดยสมมติว่าถือพอร์ตใหม่หนึ่งปี แถวแรกเริ่มจากแถวบนของ $V$ คูณ $w_0$: $0.04(0.4)+0.006(0.4)+0.0455(0.2)=0.0275$

\[ \begin{aligned} Vw_0&=(0.0275,\ 0.0085,\ 0.0469),\\ \mu^{\mathsf T}w_0&=0.048+0.024+0.030=0.102,\\ w_0^{\mathsf T}Vw_0&=0.40(0.0275)+0.40(0.0085)\\ &\quad+0.20(0.0469)=0.02378,\\ J(w_0)&=0.102-2(0.02378)=0.05444,\\ \Delta J&=0.059175-0.05444=0.004735,\\ \Delta w&=w^\star-w_0\\ &\approx(+0.06410,\ +0.10092,\ -0.16502),\\ \lVert\Delta w\rVert_1&=0.06410+0.10092+0.16502\\ &=0.33004,\\ \text{TO}&=\tfrac12(0.33004)=0.16502,\\ \text{cost}&=c\,W\lVert\Delta w\rVert_1\\ &=0.001\times50{,}000{,}000\times0.33004\\ &\approx\$16{,}502. \end{aligned} \]

คำตอบ: ย้ายไปเป้าหมายได้คะแนนเพิ่ม 0.004735 ต่อปี คือ 47.3 bp หรือ $0.004735\times\$50$ ล้าน $\approx\$236{,}700$ ต่อปี จ่ายครั้งเดียว \$16,502 คือ $16{,}502/50{,}000{,}000=0.00033$ หรือ 3.30 bp ของกองทุน คุ้มมาก

ทำไมพอร์ตเดิมแย่ เพราะเสี่ยงเกิน ความผันผวนของพอร์ตเดิมคือ $\sqrt{0.02378}=15.42\%$ ส่วนเป้าหมายมี $\mu^{\mathsf T}w^\star=0.09099$ จึงได้ $w^{\star\mathsf T}Vw^\star=(0.09099-0.059175)/2=0.01591$ และความผันผวน $\sqrt{0.01591}=12.61\%$ ตัวการคือหุ้นเทค 20% หุ้นเทคผันผวนที่สุด (35%) และขึ้นลงไปพร้อมหุ้นสหรัฐฯ (correlation 0.65) ความเสี่ยงของมันจึงไม่หักล้างกับตัวอื่น

ตรวจเองใน 10 วินาที: ประโยชน์ส่วนเพิ่มคือ derivative ของ $J$ คือ $g=\mu-2\gamma Vw=\mu-4Vw$ ที่พอร์ตเดิม $4Vw_0=(0.110,\ 0.034,\ 0.1876)$ จึงได้ $g=(0.0100,\ 0.0260,\ -0.0376)$ สามตัวต่างกันมาก หุ้นเทคติดลบ แปลว่ายิ่งถือเพิ่มยิ่งแย่ ที่จุดดีที่สุดเมื่อไม่มีต้นทุน $g$ ของทุกตัวที่ถือต้องเท่ากัน (เงื่อนไขของตัวคูณ Lagrange) ที่เป้าหมายทั้งสามเท่ากับ 0.02736 แต่ที่พอร์ตเดิมห่างกันถึง $0.0260-(-0.0376)=0.0636$

ขั้นที่ 4 — objective ที่มีต้นทุน และเงื่อนไขที่จุดหักมุม

ตอนนี้ใส่ค่าซื้อขายเข้าไปในคะแนน คะแนนสุทธิ $N(w)$ คือคะแนนเดิม $J(w)$ ลบค่าซื้อขาย $c\,|w_i-w_{0i}|$ ของทุกตัว ปัญหาคือกราฟของ $|w_i-w_{0i}|$ เป็นรูปตัว V มีมุมหักที่ $w_i=w_{0i}$ คือจุดที่ไม่ซื้อไม่ขาย ทางขวาของมุม (ซื้อ) ความชันของต้นทุนคือ $+c$ ทางซ้าย (ขาย) คือ $-c$ ตรงมุมไม่มี derivative เราจึงแยกคิดทีละกรณี แบบเดียวกับที่หน้าKKT conditionsแยกกรณีชนกำแพงกับไม่ชน ให้ $\nu$ คือตัวคูณ Lagrange ของข้อบังคับน้ำหนักรวมเป็น 1 และ $g_i=\partial J/\partial w_i$ เหมือนขั้นที่แล้ว

\[ \begin{aligned} N(w)&=J(w)-c\textstyle\sum_i|w_i-w_{0i}|,\\ \text{buy}\ (w_i\gt w_{0i}):&\quad g_i-\nu=+c,\\ \text{sell}\ (w_i\lt w_{0i}):&\quad g_i-\nu=-c,\\ \text{hold}\ (w_i=w_{0i}):&\quad-c\le g_i-\nu\le c. \end{aligned} \]

$g_i-\nu$ คือประโยชน์สุทธิของการเพิ่มตัว $i$ หนึ่งหน่วย โดยเอาเงินมาจากกองกลาง เงินต้องรวมเป็น 1 เงินที่ใส่ตัวหนึ่งจึงต้องดึงมาจากตัวอื่น $\nu$ คือราคาของเงินหนึ่งหน่วยในกองกลางนี้

ถ้าซื้อ ต้องซื้อไปจนประโยชน์ของหน่วยสุดท้ายเหลือเท่าค่าซื้อขาย $c$ พอดี ถ้ายังมากกว่า $c$ ก็ควรซื้อต่อ ถ้าน้อยกว่า แปลว่าซื้อเกินมาแล้ว ถ้าขาย ต้องขายไปจนสิ่งที่เสียจากการขายหน่วยสุดท้ายเท่ากับ $c$ ถ้าไม่แตะเลย แปลว่าการขยับทางไหนก็ไม่คุ้ม $g_i-\nu$ จึงต้องอยู่ในช่วง $-c$ ถึง $+c$

เงื่อนไขชุดนี้พอที่จะรับประกันว่าได้คำตอบที่ดีที่สุดจริง ไม่ใช่แค่จุดที่ดูดีในบริเวณใกล้ ๆ เพราะ $J$ โค้งคว่ำ และ $-c\,|w_i-w_{0i}|$ ก็โค้งคว่ำ (รูป V กลับหัว) ผลรวม $N$ จึงโค้งคว่ำ และมียอดเดียว

ขั้นที่ 5 — คำตอบเมื่อมีต้นทุน 10 bp: หยุดก่อนเป้าหมายนิดเดียว

ใช้เงื่อนไขของขั้นที่แล้วแก้พอร์ตของกองทุนจริง ๆ เมื่อค่าซื้อขายเป็น 10 bp คำถามคือ ค่าซื้อขายทำให้หยุดก่อนเป้าหมายแค่ไหน

โจทย์ให้อะไรมาบ้าง: เริ่มจาก $w_0=(0.40,\ 0.40,\ 0.20)$ และ $c=0.001$ เงื่อนไขของขั้นที่แล้วต้องรู้ก่อนว่าตัวไหนซื้อตัวไหนขาย เราจึงเดาทิศจากขั้นที่ 3: ซื้อหุ้นสหรัฐฯ ซื้อพันธบัตร ขายหุ้นเทค เขียนทิศเป็น $s=(+1,\ +1,\ -1)$ แล้วค่อยตรวจว่าเดาถูกไหม เมื่อแทน $g_i=\mu_i-4(Vw)_i$ เงื่อนไขสามข้อกับข้อบังคับเงินรวมเป็น 1 กลายเป็นสมการเชิงเส้นสี่สมการ มีตัวที่ไม่รู้สี่ตัว ($w_1,\ w_2,\ w_3,\ \nu$) แก้ได้ด้วยการกำจัดตัวแปรธรรมดา (โค้ดท้ายหน้าทำให้) แล้วนับการซื้อขายแบบขั้นที่ 1

\[ \begin{aligned} \mu_i-4(Vw)_i-\nu&=c\,s_i,\quad i=1,2,3,\\ w_1+w_2+w_3&=1,\\ w&\approx(0.45692,\ 0.50110,\ 0.04197),\\ \nu&\approx0.026227,\\ \Delta w&\approx(+0.05692,\ +0.10110,\ -0.15803),\\ \lVert\Delta w\rVert_1&=0.05692+0.10110+0.15803\\ &=0.31605,\\ \text{TO}&=\tfrac12(0.31605)\approx0.1580,\\ \text{cost}&=0.001\times50{,}000{,}000\times0.31605\\ &\approx\$15{,}803,\\ w^\star-w&\approx(+0.0072,\ -0.0002,\ -0.0070). \end{aligned} \]

คำตอบ: 45.69/50.11/4.20 ทิศที่ได้ตรงกับที่เดา (ซื้อ ซื้อ ขาย) การเดาจึงถูก หุ้นสหรัฐฯหยุดต่ำกว่าเป้าหมาย 0.72 จุด หุ้นเทคหยุดสูงกว่าเป้าหมาย 0.70 จุด เพราะช่วงท้ายของการย้าย ประโยชน์ของหน่วยที่เหลือน้อยกว่าค่าซื้อขาย 10 bp

หยุดก่อนแล้วดีกว่าไปให้ถึงแค่ไหน เทียบคะแนนสุทธิ $N=J-\text{cost}/W$ ของสองทาง ($J$ คิดด้วยสูตรเดียวกับขั้นที่ 3 และ $15{,}803/50{,}000{,}000=0.000316$)

\[ \begin{aligned} N(w)&=0.059168-0.000316=0.058852,\\ N(w^\star)&=0.059175-0.000330=0.058845,\\ N(w)-N(w^\star)&=0.000007. \end{aligned} \]

ต่างกันแค่ 0.07 bp ต่อปี ค่าซื้อขายที่เล็กขนาดนี้แทบไม่เปลี่ยนคำตอบ เมื่อเทียบกับประโยชน์ทั้งปี 47.3 bp

ตรวจเองใน 10 วินาที: ส่วนซื้อ $0.0569+0.1011=0.1580$ เท่าส่วนขาย 0.1580 ตามที่ขั้นที่ 1 บอก ที่คำตอบนี้ $g=(0.027227,\ 0.027227,\ 0.025227)$ จึงได้ $g_1-\nu=0.001=+c$ และ $g_3-\nu=-0.001=-c$ ตรงตามเงื่อนไขซื้อและขาย พันธบัตรเกินเป้าหมาย 0.02 จุด ไม่ขัดกัน เพราะเมื่อหุ้นสหรัฐฯกับหุ้นเทคหยุดก่อนเป้าหมาย covariance ทำให้น้ำหนักที่ดีที่สุดของพันธบัตรขยับตามไปด้วย

ขั้นที่ 6 — แถบที่ไม่ควรเทรด และทำไมมันกว้างตามความถี่ที่คิดใหม่

สามสินทรัพย์ทำให้เห็นภาพยาก ขั้นนี้จึงพักกองทุนเดิมไว้ก่อน แล้วดูกรณีที่เล็กที่สุด เพื่อให้เห็นว่า “แถบที่ไม่ควรเทรด” เกิดขึ้นอย่างไร กองทุนเลือกระหว่างหุ้นหนึ่งตัวกับเงินสด น้ำหนักหุ้นคือ $w$ ที่เหลือเป็นเงินสด

  • หุ้นให้ผลตอบแทนเกินเงินสด 10% ต่อปี (สมมติ)
  • ความผันผวนของหุ้น $\sigma=20\%$ ต่อปี จึงได้ $\sigma^2=0.04$
  • $\gamma=2$ และค่าซื้อขาย $c=0.001$ ต่อหน่วยที่ซื้อหรือขาย
  • กองทุนคิดพอร์ตใหม่ (rebalance) ปีละ $n$ ครั้ง

คะแนนต่อปีคือ $0.10w-\gamma\sigma^2w^2=0.10w-2(0.04)w^2=0.10w-0.08w^2$ ถ้าคิดใหม่ปีละ $n$ ครั้ง แต่ละรอบยาว $1/n$ ปี ผลตอบแทนคาดหวังและ variance ของหนึ่งรอบจึงหารด้วย $n$ แต่ค่าซื้อขายของการเทรดหนึ่งครั้งยังเท่าเดิม เราอยากรู้ว่าน้ำหนักเริ่มต้น $w_0$ แบบไหนที่ไม่ควรเทรดเลย

\[ \begin{aligned} J_n(w)&=\frac{0.10w-0.08w^2}{n},\\ g_n(w)&=\frac{0.10-0.16w}{n},\\ w^\star&=\frac{0.10}{0.16}=0.625,\\ g_n(w_0)&=\frac{0.16\,(w^\star-w_0)}{n},\\ \text{no trade}:&\quad|g_n(w_0)|\le c,\\ \text{band}&=w^\star\pm\frac{nc}{0.16},\\ n=1:&\quad\tfrac{1(0.001)}{0.16}=0.00625,\\ n=12:&\quad\tfrac{12(0.001)}{0.16}=0.075,\\ n=52:&\quad\tfrac{52(0.001)}{0.16}=0.325. \end{aligned} \]

เป้าหมาย $w^\star$ คือจุดที่ $g_n=0$ ท่าที่ทำให้ได้สูตรแถบคือเขียน $0.10-0.16w_0$ ใหม่เป็น $0.16(w^\star-w_0)$ ซึ่งทำได้เพราะ $0.10=0.16w^\star$ เงื่อนไข “ไม่เทรด” $|g_n(w_0)|\le c$ จึงกลายเป็น “อยู่ห่างเป้าหมายไม่เกิน $nc/0.16$” ขอบแถบคือจุดที่ประโยชน์ของการขยับหนึ่งหน่วยในรอบนี้เท่ากับค่าซื้อขายหนึ่งหน่วยพอดี แถบจึงเป็น 61.875% ถึง 63.125% ถ้าคิดใหม่ปีละครั้ง 55% ถึง 70% ถ้าคิดใหม่ทุกเดือน และ 30% ถึง 95% ถ้าคิดใหม่ทุกสัปดาห์

ถ้าอยู่นอกแถบ ให้เทรดแค่ถึงขอบที่ใกล้ที่สุด ไม่ใช่ถึงเป้าหมาย เพราะหน่วยสุดท้ายก่อนถึงเป้าหมายได้ประโยชน์เกือบศูนย์ แต่ยังเสีย 10 bp เต็ม นี่คือสิ่งที่รูปแรกของหน้าวาดไว้ (คิดใหม่ทุกเดือน): เริ่ม 40% ซื้อถึง 55% เริ่ม 80% ขายถึง 70% อยู่ที่ 60% ไม่ทำอะไร

แถบกว้างขึ้นตามความถี่ เพราะ optimizer ที่คิดทีละรอบเห็นประโยชน์ของการขยับแค่หนึ่งรอบ แต่จ่ายค่าซื้อขายเต็ม คิดใหม่ทุกสัปดาห์จึงแทบไม่เทรดเลย ข้อนี้ต้องระวังสองเรื่อง เรื่องแรก ถ้าถือน้ำหนักใหม่ต่อไปหลายรอบ ประโยชน์จริงอยู่นานกว่าหนึ่งรอบ การวางแผนหลายรอบพร้อมกันจึงให้แถบแคบกว่าแบบรอบเดียว แต่คำตอบยังเป็นแถบเหมือนเดิม เรื่องที่สอง ถ้าไม่มีค่าซื้อขายเลย ($c=0$) แถบหดเหลือจุดเดียว optimizer จะเทรดทุกครั้งที่ตัวเลขที่ป้อนเข้าไปขยับ

ขั้นที่ 7 — เขตไม่เทรดของสามสินทรัพย์: 20 bp ในหน่วยประโยชน์ ไม่ใช่ในหน่วยน้ำหนัก

กลับมาที่กองทุนสามสินทรัพย์ ถือพอร์ตใหม่หนึ่งปีเหมือนขั้นที่ 3 คำถามคือ พอร์ตเริ่มต้นแบบไหนที่ไม่ควรเทรดเลย คำตอบคือ “ไม่เทรด” เมื่อทุกตัวผ่านเงื่อนไข hold พร้อมกัน แปลว่ามี $\nu$ ตัวเดียวที่ทำให้ $g_i-\nu$ ของทุกตัวอยู่ในช่วง $-c$ ถึง $+c$ ซึ่งหาได้ก็ต่อเมื่อ $g$ ที่มากที่สุดกับ $g$ ที่น้อยที่สุดห่างกันไม่เกิน $2c$ (ตั้ง $\nu$ ไว้ตรงกลางระหว่างสองค่านั้น)

เพื่อวัดว่าเขตนี้กว้างแค่ไหนในหน่วยน้ำหนัก ให้เริ่มที่เป้าหมาย แล้วเลื่อนไปในทิศ $d=(1,\ -1,\ 0)$ คือเพิ่มหุ้นสหรัฐฯและลดพันธบัตรเท่ากัน $t$ หน่วย แล้วดูว่าเลื่อนได้ไกลแค่ไหนก่อนหลุดเขต $Vd$ คือคอลัมน์แรกของ $V$ ลบคอลัมน์ที่สอง เช่นช่องแรก $0.0400-0.0060=0.034$ และ $g$ เปลี่ยนไป $-4t\,Vd$ เพราะ $g=\mu-4Vw$

\[ \begin{aligned} \max_ig_i-\min_ig_i&\le2c=0.002,\\ Vd&=(0.034,\ -0.004,\ 0.035),\\ g(w^\star+td)&=g(w^\star)-4t\,Vd\\ &=g(w^\star)+t\,(-0.136,\ 0.016,\ -0.140),\\ (0.016+0.140)\,t&=0.156\,t\le0.002,\\ t&\le0.002/0.156=0.0128. \end{aligned} \]

ที่เป้าหมาย $g$ ทั้งสามตัวเท่ากัน เมื่อเลื่อนไป $t$ ตัวที่ขึ้นมากที่สุด (พันธบัตร $+0.016t$) กับตัวที่ลงมากที่สุด (หุ้นเทค $-0.140t$) แยกห่างกัน $0.156t$ เขตจึงกว้างข้างละ 1.28 จุดของน้ำหนักในทิศนี้

ลองตรวจกับสองพอร์ต พอร์ต 47.61/48.89/3.50 อยู่ห่างเป้าหมาย $t=0.012$ มี $g$ ห่างกัน 0.00188 ไม่ถึง 0.002 จึงไม่เทรด พอร์ต 48.00/48.50/3.50 อยู่ห่าง $t\approx0.0159$ มี $g$ ห่างกัน 0.00249 เกิน 0.002 จึงต้องเทรด ส่วนพอร์ตเดิม 40/40/20 มี $g$ ห่างกัน 0.0636 (ขั้นที่ 3) คิดเป็น $0.0636/0.002=31.8$ เท่าของ $2c$ จึงต้องเทรดแน่นอน

ระวังว่า $2c=0.002$ อยู่ในหน่วยของประโยชน์ส่วนเพิ่ม ไม่ใช่หน่วยน้ำหนัก ในหน่วยน้ำหนัก เขตกว้างไม่เท่ากันในแต่ละทิศ ทิศไหนที่ความเสี่ยงเปลี่ยนช้า (ชามความเสี่ยงแบน) $g$ ก็เปลี่ยนช้าเมื่อเลื่อนไป เขตในทิศนั้นจึงกว้าง ทิศที่ชามชันเขตก็แคบ และคำตอบที่ค่าซื้อขาย 10 bp (45.69/50.11/4.20) ตกที่มุมของเขตพอดี เพราะที่นั่น $g_1=g_2$ และทั้งคู่สูงกว่า $g_3$ อยู่ $0.027227-0.025227=0.002=2c$

ขั้นที่ 8 — เพดาน turnover 10%: คำตอบไปอยู่ที่มุม และการเดินตามสัดส่วนแพ้

กลับมาที่คำถามของโจทย์เปิดหน้า ถ้าไม่มีเพดาน คำตอบที่ 10 bp ใช้ turnover 15.80% (ขั้นที่ 5) เกินเพดาน 10% เพดานจึงบีบ เพดานเขียนเป็น $\tfrac12\sum_i|w_i-w_{0i}|\le\tau=0.10$ และมีตัวคูณ $\theta\ge0$ ตัวคูณนี้คือราคาของเพดาน คือคะแนนที่จะได้เพิ่มถ้าผ่อนเพดานออกหนึ่งหน่วย

เพดานก็เป็นค่าสัมบูรณ์เหมือนค่าซื้อขาย ความชันของมันต่อหน่วยที่ซื้อหรือขายคือ $\theta/2$ (ครึ่งหนึ่ง เพราะ turnover หารด้วยสอง) มันจึงบวกเข้ากับ $c$ ในทุกเงื่อนไขของขั้นที่ 4 ค่าซื้อขายต่อหน่วยจึงกลายเป็น $c+\theta/2$

จะเดาว่าเทรดตัวไหน ให้ดูประโยชน์ของการย้ายเงินหนึ่งหน่วยที่พอร์ตเดิม (ค่า $g$ จากขั้นที่ 3): ย้ายจากหุ้นเทคไปพันธบัตรได้ $0.0260-(-0.0376)=0.0636$ ย้ายจากหุ้นเทคไปหุ้นสหรัฐฯได้แค่ $0.0100-(-0.0376)=0.0476$ เมื่อเทรดได้จำกัด ก็ควรใช้กับคู่ที่คุ้มที่สุด จึงเดาว่าไม่แตะหุ้นสหรัฐฯ แล้วใช้เพดานเต็ม คือขายหุ้นเทค 10 จุด ซื้อพันธบัตร 10 จุด แล้วตรวจเงื่อนไข

\[ \begin{aligned} w&=(0.40,\ 0.50,\ 0.10),\\ 4Vw&=(0.0942,\ 0.0338,\ 0.1428),\\ g&=\mu-4Vw=(0.0258,\ 0.0262,\ 0.0072),\\ g_2-\nu&=c+\theta/2,\\ g_3-\nu&=-(c+\theta/2),\\ \nu&=\tfrac12(0.0262+0.0072)=0.0167,\\ c+\theta/2&=\tfrac12(0.0262-0.0072)=0.0095,\\ \theta&=2(0.0095-0.001)=0.017\ge0,\\ |g_1-\nu|&=|0.0258-0.0167|=0.0091,\\ 0.0091&\le0.0095. \end{aligned} \]

จากนั้นเทียบกับแผนตามสัดส่วนของผู้จัดการ ($p=0.606$ จากโจทย์เปิดหน้า) ด้วยคะแนน $J=\mu^{\mathsf T}w-2w^{\mathsf T}Vw$ ของขั้นที่ 3

\[ \begin{aligned} w_{\text{prop}}&=w_0+0.606\,(w^\star-w_0)\\ &\approx(0.4388,\ 0.4612,\ 0.1000),\\ J(w)&=0.093-2(0.017215)=0.058570,\\ J(w_{\text{prop}})&=0.09533-2(0.018445)=0.058440,\\ J(w)-J(w_{\text{prop}})&=0.000130. \end{aligned} \]

ท่าที่ใช้หา $\nu$ กับ $c+\theta/2$ คือบวกและลบสองสมการของพันธบัตรกับหุ้นเทค บวกกันแล้ว $c+\theta/2$ หักล้างกันหมด เหลือ $\nu$ ลบกันแล้ว $\nu$ หักล้าง เหลือ $c+\theta/2$ เงื่อนไขผ่านครบ: $\theta$ ไม่ติดลบ และหุ้นสหรัฐฯที่ไม่แตะผ่านเงื่อนไข hold เพราะ $0.0091\le0.0095$ โจทย์โค้งคว่ำ จึงเป็นคำตอบที่ดีที่สุดจริง ความหมายคือ เพดานที่บีบทำตัวเหมือนค่าซื้อขาย $0.0095$ หรือ 95 bp ต่อขา แทนที่จะเป็น 10 bp คำตอบจึงเทรดแค่คู่ที่คุ้มที่สุด

แผนตามสัดส่วนใช้ turnover 10% และเสียค่าซื้อขาย \$10,000 เท่ากัน แต่แพ้ 0.000130 คือ 1.30 bp ต่อปี หรือ $0.000130\times\$50$ ล้าน $\approx\$6{,}500$ ต่อปี หุ้นเทคของทั้งสองแผนลงไปที่ 10.00% เท่ากัน ต่างกันแค่ว่าเงินไปไหน แผนตามสัดส่วนเอา $0.4388-0.40=3.88$ จุดไปหุ้นสหรัฐฯ ซึ่งขึ้นลงไปพร้อมหุ้นเทค (correlation 0.65) จึงลดความเสี่ยงได้น้อยกว่าการเอาเงินทั้งหมดไปพันธบัตร

ตัวคูณ $\theta$ คือราคาของการผ่อนเพดานทีละนิด ถ้าผ่อนเพดานจาก 10% เป็น 10.1% (เพิ่ม 0.001) คะแนนสุทธิเพิ่มจริง 0.0000168 ส่วนตัวคูณทำนาย $0.017\times0.001=0.0000170$ ใกล้กันมาก

แต่แบบ “ไม่แตะหุ้นสหรัฐฯ” ใช้ได้ถึงเพดานค่าหนึ่งเท่านั้น ถ้าเพดานเป็น $\tau$ พอร์ตคือ $(0.40,\ 0.40+\tau,\ 0.20-\tau)$ แทนลงในสูตรเดิมได้ $g_1-\nu=0.0158-0.067\tau$ และ $c+\theta/2=0.0318-0.223\tau$ หุ้นสหรัฐฯยังอยู่เฉยได้ตราบที่ค่าแรกไม่เกินค่าที่สอง สองค่าเท่ากันที่ $0.156\tau=0.016$ คือ $\tau=0.016/0.156=4/39\approx10.26\%$ เกินนั้นคำตอบเริ่มซื้อหุ้นสหรัฐฯด้วย เช่นที่เพดาน 11% ได้ 40.76/50.24/9.00 และ $\theta$ ลดเหลือ 0.0137 (แก้ระบบสมการแบบขั้นที่ 5 โดยให้ $c+\theta/2$ เป็นตัวที่ไม่รู้ โค้ดท้ายหน้าทำให้)

ขั้นที่ 9 — ต้นทุนจากการดันราคา: โตตามกำลังสอง และทำให้ขยับทีละส่วน

ค่าซื้อขาย 10 bp ที่คงที่ใช้ได้กับคำสั่งเล็ก แต่คำสั่งใหญ่ดันราคาเอง ยิ่งซื้อมาก ราคายิ่งขึ้นหนี ขั้นนี้สร้างต้นทุนแบบนั้นจากสมมติฐานง่าย ๆ แล้วดูว่ามันเปลี่ยนหน้าตาของคำตอบอย่างไร สมมติว่าระหว่างที่ทยอยซื้อ ราคาขยับขึ้นเป็นเส้นตรงตามเงินที่ซื้อไปแล้ว

  • $x$ คือเงินที่ซื้อไปแล้ว (ดอลลาร์) และ $X$ คือขนาดคำสั่งทั้งหมด
  • ADV คือมูลค่าที่ทั้งตลาดซื้อขายหุ้นตัวนี้ต่อวันโดยเฉลี่ย สมมติว่า \$250 ล้าน
  • $\eta=0.06$ (สมมติ) แปลว่าถ้าซื้อเท่ายอดซื้อขายทั้งวัน ราคาจะขยับขึ้น 6% เมื่อซื้อไปแล้ว $x$ ราคาจึงขึ้นไป $\eta\,x/\text{ADV}$ (เป็นสัดส่วนของราคา)
  • กองทุน $W=\$50$ ล้าน และ $q$ คือขนาดคำสั่งเป็นสัดส่วนของกองทุน คือ $X=qW$

ตอนที่ซื้อไปแล้ว $x$ ดอลลาร์ ดอลลาร์ถัดไปต้องจ่ายแพงเกินราคาเดิม $\eta x/\text{ADV}$ ต่อดอลลาร์ ต้นทุนส่วนเกินทั้งหมดจึงเป็นผลรวมของส่วนเกินนี้ทุกดอลลาร์ คือพื้นที่ใต้เส้นจาก $0$ ถึง $X$ สองแถวล่างหาขนาดคำสั่งที่ค่า impact ของดอลลาร์ถัดไปเท่ากับค่าซื้อขาย $c$

\[ \begin{aligned} \text{extra}&=\int_0^{X}\eta\,\frac{x}{\text{ADV}}\,dx=\frac{\eta X^2}{2\,\text{ADV}},\\ \frac{\text{extra}}{W}&=\frac{\eta\,(qW)^2}{2\,\text{ADV}\cdot W}\\ &=\frac{\eta W}{2\,\text{ADV}}\,q^2=\kappa q^2,\\ \kappa&=\frac{0.06\times50}{2\times250}=0.006,\\ q=0.10:&\quad\kappa q^2=0.006\times0.01=0.00006,\\ \frac{d}{dq}\big(\kappa q^2\big)&=2\kappa q=c\\ \Rightarrow\ q&=\frac{0.001}{2(0.006)}\approx0.0833. \end{aligned} \]

ราคาขึ้นเป็นเส้นตรง พื้นที่ใต้เส้นจึงเป็นสามเหลี่ยม ฐานยาว $X$ สูง $\eta X/\text{ADV}$ พื้นที่เท่ากับครึ่งหนึ่งของฐานคูณสูง จึงได้ $X^2$ หารด้วยสอง นี่คือที่มาของพจน์ $\kappa q^2$ ตอนคิด $\kappa$ ใช้ $W$ กับ ADV ในหน่วยล้านดอลลาร์ทั้งคู่ หน่วยจึงหักล้างกัน

ตัวเลขที่ได้: ซื้อขาย 10% ของกองทุนเสียเพิ่ม 0.00006 ของกองทุน คือ 0.6 bp หรือ $0.00006\times\$50$ ล้าน $=\$3{,}000$ ส่วนสองแถวล่างบอกว่า ถ้าคำสั่งใหญ่เกิน 8.33% ของกองทุน ดอลลาร์ถัดไปเสียค่า impact มากกว่าค่าซื้อขาย 10 bp และเพราะ $\kappa$ โตตามขนาดกองทุน $W$ กองทุนใหญ่จึงถูกลงโทษหนักกว่าเมื่อรีบเทรด

ต่อไปเอาต้นทุนกำลังสองนี้ไปใช้แทนค่าซื้อขาย 10 bp ในกองทุนหุ้นกับเงินสดของขั้นที่ 6 ที่คิดใหม่ทุกเดือน ($n=12$) แล้วถามว่าแต่ละเดือนควรซื้อเท่าไร ตั้ง derivative ของคะแนนหักต้นทุนเป็นศูนย์ ซึ่งทำได้ตรง ๆ เพราะต้นทุนกำลังสองไม่มีมุม

\[ \begin{aligned} \max_w&\ J_n(w)-\kappa(w-w_0)^2,\\ \frac{0.16\,(w^\star-w)}{n}&=2\kappa\,(w-w_0),\\ w&=w_0+\varphi\,(w^\star-w_0),\\ \varphi&=\frac{0.16/n}{0.16/n+2\kappa}\\ &=\frac{\gamma\sigma^2/n}{\gamma\sigma^2/n+\kappa},\\ \gamma\sigma^2/n&=0.08/12=0.00667,\\ \varphi&=\frac{0.00667}{0.00667+0.006}\approx0.526,\\ w_1&=0.40+0.526\,(0.625-0.40)\\ &\approx0.5184. \end{aligned} \]

ฝั่งซ้ายของแถวที่สองคือ derivative ของ $J_n$ ซึ่งขั้นที่ 6 เขียนไว้เป็น $0.16(w^\star-w)/n$ ฝั่งขวาคือ derivative ของต้นทุน แก้หา $w$ ได้ว่าควรขยับเป็นสัดส่วน $\varphi$ ของระยะที่เหลือไปทางเป้าหมาย ไม่ใช่ทั้งหมด สูตรที่สองของ $\varphi$ ได้จากการแทน $0.16=2\gamma\sigma^2$ แล้วหารบนและล่างด้วยสอง

ต่างจากขั้นที่ 6 ตรงที่ไม่มีแถบ เพราะต้นทุนกำลังสองไม่มีมุม ขยับนิดเดียวเสียแทบศูนย์ จึงคุ้มที่จะขยับเสมอ แต่ขยับมากเสียแพง จาก 40% เดือนแรกไป 51.8% แล้วใช้สูตรเดิมซ้ำ เช่น $0.5184+0.526\,(0.625-0.5184)=0.5745$ ได้ 57.5%, 60.1%, 61.4% ระยะที่เหลือหดเหลือ $1-0.526=0.474$ เท่าทุกเดือน คือราวครึ่งหนึ่ง

$\varphi$ บอกนิสัยของนโยบาย ยิ่งกลัวความเสี่ยง ($\gamma$ สูง) หรือหุ้นยิ่งผันผวน ($\sigma$ สูง) $\varphi$ ยิ่งใกล้ 1 คือรีบปรับ ยิ่ง impact แพง ($\kappa$ สูง) $\varphi$ ยิ่งเล็ก คือค่อย ๆ ปรับ และถ้าเป้าหมายเป็นศูนย์ เช่นเหตุผลที่ถือหุ้นหมดไปแล้ว กฎเดียวกันบอกให้ขายออกเป็นสัดส่วนคงที่ของที่เหลือทุกรอบ

กับดัก: นิยาม turnover หน่วยของต้นทุน การเดินตามสัดส่วน และการไล่ noise

ไม่บอกว่า turnover นับแบบไหน การเทรด 40/40/20 ไป 60/30/10 เดียวกัน ระบบหนึ่งรายงาน $\lVert\Delta w\rVert_1=0.40$ คือ 40% อีกระบบรายงาน one-way $\tfrac12\lVert\Delta w\rVert_1=0.20$ คือ 20% ต่างกันสองเท่า จึงต้องเขียนนิยามกำกับตัวเลขเสมอ

คิดค่าซื้อขายจาก one-way แทน gross ค่าซื้อขายจ่ายทั้งขาซื้อและขาขาย ตัวอย่างเดียวกัน ถ้าคิดจาก one-way จะได้ $0.001\times50{,}000{,}000\times0.20=\$10{,}000$ ซึ่งผิด ที่ถูกคือคิดจาก gross $0.001\times50{,}000{,}000\times0.40=\$20{,}000$

เทียบประโยชน์ต่อปีกับค่าซื้อขายต่อครั้งตรง ๆ คะแนน $J$ เป็นต่อปี แต่ค่าซื้อขายจ่ายทุกครั้งที่เทรด ถ้าย้ายพอร์ตไปเป้าหมายแบบขั้นที่ 3 ทุกเดือน ค่าซื้อขายต่อปีคือราว $12\times3.30=39.6$ bp ไม่ใช่ 3.30 bp ในทางกลับกัน ถ้าคิดใหม่ทุกเดือนแต่หาแถบด้วยประโยชน์ทั้งปี ($n=1$) แถบจะแคบไป 12 เท่า ในตัวอย่างหุ้นกับเงินสด ผิดคือ $0.001/0.16=0.00625$ หรือข้างละ 0.625 จุด ถูกคือ $12(0.001)/0.16=0.075$ หรือข้างละ 7.5 จุด ต้องเทียบในหน่วยเวลาเดียวกัน

อ่าน $2c$ เป็นความกว้างของน้ำหนัก $2c=0.002$ คือ 20 bp ในหน่วยประโยชน์ส่วนเพิ่ม ไม่ได้แปลว่าเขตกว้าง 0.2 จุดของน้ำหนัก ในหน่วยน้ำหนัก เขตกว้าง $0.002/0.156=0.0128$ หรือข้างละ 1.28 จุดในทิศสลับหุ้นสหรัฐฯกับพันธบัตร และแคบกว่านั้นมากในทิศหุ้นเทค

ย่อการเทรดตามสัดส่วนเมื่อชนเพดาน สองแผนเสียค่าซื้อขาย \$10,000 เท่ากัน ความเสียหายจึงไม่โผล่ในรายงานค่าใช้จ่าย แต่คะแนนของแผนตามสัดส่วนต่ำกว่าคำตอบ KKT อยู่ $0.058570-0.058440=0.000130$ คือ 1.30 bp ต่อปี โดยไม่มีใครเห็น

รัน optimizer ที่ไม่มีต้นทุนทุกวัน มันจะเทรดทุกครั้งที่ตัวเลขที่ป้อนเข้าไปขยับ ทั้งที่หน้า Markowitzแสดงว่า ถ้าผลตอบแทนคาดหวังของหุ้นคลาดไป 1 จุด น้ำหนักที่ได้ขยับไปถึง 6.58 จุด และผลตอบแทนคาดหวังก็ประมาณได้ไม่แม่นอยู่แล้ว การเทรดตามทุกการขยับจึงคือการจ่ายเงินเพื่อไล่ noise แถบไม่เทรดคือสิ่งที่กันเรื่องนี้

ใช้ทำอะไรบนโต๊ะจริง

นโยบาย rebalance ของกองทุนส่วนใหญ่คือแถบไม่เทรดแบบง่าย: ปล่อยให้น้ำหนักลอยได้ในช่วงหนึ่งรอบเป้าหมาย เมื่อหลุดช่วงค่อยปรับกลับแค่ถึงขอบ หน้านี้บอกว่าความกว้างที่เหมาะขึ้นกับสามอย่าง คือค่าซื้อขาย ความถี่ที่คิดใหม่ และความชันของชามความเสี่ยงในแต่ละทิศ จึงไม่ควรใช้ตัวเลขเดียวกันกับทุกสินทรัพย์

เพดาน turnover ต่อรอบเป็นกติกาที่พบบ่อยในกองทุน แต่ถ้าเป้าจริงคือคุมค่าซื้อขาย การหักต้นทุนออกจากคะแนนตรง ๆ ดีกว่า เพราะราคาต่อหน่วยตั้งไว้ล่วงหน้าและคงที่ ส่วนราคาแฝงของเพดาน ($\theta$) ขึ้นลงตามสภาพตลาดโดยไม่มีใครเห็น เช่นในหน้านี้ เพดาน 10% มี $\theta=0.017$ แต่เพดาน 5% ในโจทย์ข้อ 3 มี $\theta=0.0393$ ถ้าใช้เพดาน ควรรายงาน $\theta$ คู่กับคำตอบเสมอ

ต้นทุนจาก impact กำหนดว่ากลยุทธ์หนึ่งรับเงินได้มากแค่ไหนก่อนผลตอบแทนหายหมด (strategy capacity) วิธีแบ่งคำสั่งใหญ่เป็นก้อนเล็กตามเวลาให้ต้นทุนรวมต่ำสุดคือ Almgren–Chriss execution ซึ่งใช้พจน์กำลังสองแบบเดียวกับ $\kappa q^2$ ข้างบน ส่วนกลไกของ spread และสมุดคำสั่งซื้อขาย (order book) อยู่ที่หน้าmarket microstructure

\[ \begin{aligned} L(t)&=\tfrac h2(t-t^\star)^2+2\kappa t^2,\\ L'(t)&=h(t-t^\star)+4\kappa t=0,\\ t&=\frac{h}{h+4\kappa}\,t^\star\\ &=\frac{0.152}{0.152+4(0.006)}\,t^\star\\ &=\frac{0.152}{0.176}\,t^\star\approx0.864\,t^\star. \end{aligned} \]

function solveLinear(A, b) {
  const n = A.length, M = A.map((r, i) => [...r, b[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;

  }
  return M.map((r, i) => r[n] / r[i]);
}

// Turnover cap: stocks untouched, bonds +tau, tech -tau; read the multipliers off the kink conditions.
function capCheck(w, k = c) {
  const g = marginal(w), nu = (g[1] + g[2]) / 2, perLeg = (g[1] - g[2]) / 2;
  return {w, g, nu, perLeg, theta: 2 * (perLeg - k), stockGap: Math.abs(g[0] - nu), holdsStock: Math.abs(g[0] - nu) <= perLeg};
}
const capped = capCheck([0.40, 0.50, 0.10]);
// Above the switch point stocks are bought too: signs (+,+,-), tech sold down to 0.20 - tau, unknown per-leg price k.
function capAllTraded(tau) {
  const w3 = 0.20 - tau, rows = [], rhs = [];
  [0, 1, 2].forEach(i => { rows.push([2 * gamma * V[i][0], 2 * gamma * V[i][1], 1, [1, 1, -1][i]]); rhs.push(mu[i] - 2 * gamma * V[i][2] * w3); });

  const [w1, w2, nu, k] = solveLinear(rows, rhs);
  return {w: [w1, w2, w3], nu, perLeg: k, theta: 2 * (k - c)};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • one-way turnover คือส่วนของกองทุนที่เปลี่ยนมือ $\tfrac12\lVert\Delta w\rVert_1$ ส่วนค่าซื้อขายคิดจาก gross ซึ่งเป็นสองเท่า: ย้าย 40/40/20 ไป 60/30/10 คือ turnover 20% ยอด gross \$20 ล้าน ค่าซื้อขาย $0.001\times\$20$ ล้าน $=\$20{,}000$
  • ต้นทุนการเทรดมีสามก้อน: spread กับค่าคอมมิชชัน (คงที่ต่อดอลลาร์) impact ชั่วคราว และ impact ถาวร ต้นทุนต่อดอลลาร์ของ impact โตตาม $\sqrt{Q/V}$ คำสั่งใหญ่สี่เท่าจึงจ่ายรวมแพง $4\times\sqrt4=8$ เท่า
  • ค่าซื้อขายคงที่ $c$ ให้เงื่อนไขสามกรณี: ซื้อจน $g_i-\nu=c$ ขายจน $g_i-\nu=-c$ และไม่แตะเมื่อ $|g_i-\nu|\le c$ กองทุนที่เริ่มจาก 40/40/20 หยุดที่ 45.69/50.11/4.20 ซึ่งอยู่ที่มุมของเขตไม่เทรด
  • แถบไม่เทรดคือช่วงที่ประโยชน์ของการขยับหนึ่งหน่วยในรอบนั้นยังไม่คุ้มค่าซื้อขาย หุ้นกับเงินสดที่คิดใหม่ทุกเดือนได้แถบ $0.625\pm12(0.001)/0.16$ คือ 55% ถึง 70% นอกแถบให้เทรดแค่ถึงขอบ และแถบกว้างขึ้นตามความถี่ที่คิดใหม่
  • เพดาน turnover ที่บีบทำตัวเหมือนค่าซื้อขายที่แพงขึ้นเป็น $c+\theta/2$ ที่เพดาน 10% คำตอบคือมุม 40/50/10 มี $\theta=0.017$ และแผนย่อตามสัดส่วนแพ้ 1.30 bp ต่อปี ทั้งที่ค่าซื้อขายเท่ากัน
  • impact แบบกำลังสองไม่มีมุม จึงไม่มีแถบ แต่ทำให้ขยับทีละส่วน $\varphi=\dfrac{\gamma\sigma^2/n}{\gamma\sigma^2/n+\kappa}$ ในตัวอย่างหุ้นกับเงินสดได้ $0.00667/0.01267\approx52.6\%$ ต่อเดือน
