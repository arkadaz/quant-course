12.6 Karush-Kuhn-Tucker (KKT) Conditions — Inequality Constraints

ข้อบังคับแบบอสมการอาจบีบคำตอบหรือไม่บีบเลยก็ได้ KKT บอกว่าข้อไหนบีบ และตัวคูณของข้อที่บีบคือราคาของมัน

กองทุน long-only (ห้าม short) ต้องลงเงินครบ 100% ในหุ้นสหรัฐฯ (ความผันผวน 20%) พันธบัตร (10%) และหุ้นเทค (35% correlation กับหุ้นสหรัฐฯ 0.65) และต้องการพอร์ตความเสี่ยงต่ำสุด สูตรพอร์ตความเสี่ยงต่ำสุดที่ได้จากตัวคูณ Lagrange สั่งหุ้นสหรัฐฯ 17.14% พันธบัตร 89.30% หุ้นเทค −6.44% ซึ่ง mandate ห้าม นักวิเคราะห์จึงตัดหุ้นเทคเป็นศูนย์แล้วย่อขยายสองตัวที่เหลือให้รวมได้ 100% ได้ 16.10% กับ 83.90% นี่คือพอร์ต long-only ที่เสี่ยงน้อยที่สุดไหม

ลองตอบก่อนเปิดเฉลย

ไม่ใช่ พอร์ตที่ถูกคือหุ้นสหรัฐฯ 10.53% พันธบัตร 89.47% หุ้นเทค 0% ความผันผวน 9.787% ส่วนพอร์ตที่ตัดแล้วย่อขยายได้ 9.847% เสี่ยงเกินไป 6.0 bp ต่อปีโดยไม่ได้อะไรเลย เมื่อหุ้นเทคหายไป ขา short ที่เคยหักล้างหุ้นสหรัฐฯก็หายไปด้วย สัดส่วนที่ดีที่สุดของอีกสองตัวจึงเปลี่ยน ต้องแก้ใหม่ ไม่ใช่ย่อขยาย KKT ยังบอกราคาของกฎด้วย: ตัวคูณของกฎห้าม short หุ้นเทคคือ $u_3=0.00921$ และทั้งกฎทำให้ความผันผวนขึ้น 15.3 bp จาก 9.634%

ภาพรวมก่อนลงสูตร

ตัวคูณ Lagrange รู้จักแค่ข้อบังคับที่เป็นสมการ แต่กฎจริงของพอร์ตส่วนใหญ่เป็นอสมการ: ห้าม short ถือตัวเดียวไม่เกิน 10% ความผันผวนไม่เกินงบ อสมการต่างจากสมการตรงที่มันอาจบีบคำตอบ หรืออาจยังเหลือที่ว่างและไม่มีผลอะไรเลย KKT conditions คือชุดเงื่อนไขที่แยกสองกรณีนี้ออกจากกันในตัว

ภาพที่ควรมีในหัวคือชามกับกำแพง ถ้าก้นชามอยู่ในเขตที่อนุญาต กำแพงไม่มีผล ความชันที่ก้นเป็นศูนย์เหมือนเดิม ถ้าก้นชามอยู่หลังกำแพง จุดที่ดีที่สุดคือจุดที่ชนกำแพง ตรงนั้นความชันไม่เป็นศูนย์ ชามยังอยากไหลต่อ และกำแพงต้องดันกลับด้วยแรงพอดี แรงนั้นคือตัวคูณ $u$ ซึ่งต้องไม่ติดลบ เพราะกำแพงดันได้ทางเดียว

หน้านี้จะเริ่มจากตัวแปรเดียว ขยายเป็นเงื่อนไขทั่วไปสี่ข้อ แก้พอร์ต long-only สามสินทรัพย์ด้วยการเดาว่ากำแพงไหนบีบแล้วสอบ อ่านราคาของกฎห้าม short ดูข้อมูลชุดเดิมที่เปลี่ยนเป้าหมายแล้วกฎไม่บีบ และจบที่งบความเสี่ยงซึ่งเป็นอสมการที่ไม่ใช่เส้นตรง

KKT conditions
เงื่อนไขสี่ข้อที่จุดดีที่สุดของโจทย์ที่มีอสมการต้องผ่าน ใช้ทั้งตรวจคำตอบและหาคำตอบ ชื่อมาจาก Karush, Kuhn และ Tucker
Active (binding) constraint
อสมการที่คำตอบชนขอบพอดี เช่นน้ำหนักเป็นศูนย์พอดี เป็นข้อที่กำลังบีบคำตอบและมีราคาได้
Inactive constraint
อสมการที่คำตอบยังห่างขอบ เช่นน้ำหนักเป็นบวก ข้อนี้ไม่มีผลต่อคำตอบ ราคาจึงเป็นศูนย์
Complementary slackness
กฎว่าตัวคูณคูณระยะห่างจากขอบต้องเป็นศูนย์ ข้อที่ยังไม่ชนขอบจึงไม่มีราคา และข้อที่มีราคาต้องชนขอบ
Dual feasibility
กฎว่าตัวคูณของอสมการต้องไม่ติดลบ (ในรูปมาตรฐาน) ถ้าคำนวณได้ติดลบแปลว่าปล่อยขอบแล้วดีกว่า เราเดาผิด
Active set

Penalty
การย้ายข้อบังคับไปเป็นพจน์หักใน objective ด้วยราคาที่ตั้งเอง ให้คำตอบเดียวกับข้อบังคับเมื่อราคาเท่ากับตัวคูณ แต่ไม่มีวันหาคำตอบไม่ได้

ขั้นที่ 1 — ตัวแปรเดียวกับกำแพงหนึ่งด้าน

เริ่มจากกรณีที่เล็กที่สุดเพื่อดูว่าเงื่อนไขหน้าตาอย่างไร หาค่าต่ำสุดของ $f(x)$ โดยห้าม $x$ ติดลบ มีได้สองแบบตามรูปข้างบน: คำตอบอยู่กลางเขต หรือชนกำแพงที่ศูนย์

\[ \begin{aligned} x^\star\gt0:&\quad f'(x^\star)=0,\\ x^\star=0:&\quad f'(0)\ge0,\\ u&:=f'(x^\star)\ge0,\quad u\,x^\star=0,\\ f=(x-2)^2:&\quad x^\star=2,\quad u=0,\\ f=(x+1)^2:&\quad x^\star=0,\quad u=f'(0)=2. \end{aligned} \]

กลางเขตเดินได้ทั้งซ้ายและขวา ความชันจึงต้องเป็นศูนย์แบบเงื่อนไขอันดับหนึ่ง ที่กำแพงเดินได้ทางเดียวคือเข้าไปทางขวา ถ้าความชันติดลบ เดินขวาแล้วต่ำลง จุดนั้นจึงยังไม่ใช่คำตอบ ความชันที่กำแพงจึงต้องไม่ติดลบ บรรทัดที่สามรวมสองกรณีเป็นเงื่อนไขเดียว: $u$ ไม่ติดลบ และ $u$ กับ $x^\star$ ต้องมีตัวหนึ่งเป็นศูนย์

ตัวอย่างที่สอง จุดต่ำสุดถ้าไม่มีกำแพงคือ −1 ซึ่งห้าม คำตอบจึงชนกำแพงที่ 0 และ $u=2$ คือแรงที่ชามดันกำแพง ถ้าถอยกำแพงไปทางลบนิดหนึ่ง $\varepsilon$ ค่าต่ำสุดจะลดราว $2\varepsilon$ ตัวคูณของอสมการจึงเป็นราคาของกำแพง แบบเดียวกับที่ตัวคูณ Lagrange เป็นราคาของสมการ

ขั้นที่ 2 — แบ่งทุนสองเดสก์: กฎบีบเมื่องบน้อย ไม่บีบเมื่องบมาก

โจทย์ให้อะไรมาบ้าง: โจทย์แบ่งทุนเดียวกับที่หน้าตัวคูณ Lagrangeใช้ และพังเมื่องบเหลือ \$0.5 ล้าน: สองเดสก์ทำกำไร $2\ln(1+x_1)+4\ln(1+x_2)$ ล้านดอลลาร์เมื่อได้ทุน $x_1, x_2$ ล้านดอลลาร์ ทุนรวม $b$ และทุนห้ามติดลบ กำไรส่วนเพิ่มของเดสก์คือ $2/(1+x_1)$ และ $4/(1+x_2)$ ใช้ขั้นที่แล้วทีละเดสก์กับราคาภายในของทุน $\nu$: เดสก์ที่ได้ทุนต้องมีกำไรส่วนเพิ่มเท่ากับ $\nu$ พอดี เดสก์ที่ได้ศูนย์ต้องมีกำไรส่วนเพิ่มไม่เกิน $\nu$ ส่วนต่าง $u_i$ ระหว่าง $\nu$ กับกำไรส่วนเพิ่มของเดสก์ $i$ ต้องไม่ติดลบ และคือตัวคูณของกฎห้ามทุนติดลบ

\[ \begin{aligned} \text{interior}:&\quad\frac{2}{1+x_1}=\frac{4}{1+x_2}\ \Rightarrow\ x_1=\frac{b-1}{3},\\ b=12:&\quad x=(11/3,\ 25/3),\quad\nu=3/7,\quad u=(0,\ 0),\\ b=0.5:&\quad x_1=-1/6\lt0\ \text{(fails)},\\ &\quad x=(0,\ 0.5),\quad\nu=\frac{4}{1.5}\approx2.667,\\ &\quad u_1=2.667-\frac{2}{1+0}\approx0.667\ge0. \end{aligned} \]

คำตอบ: ที่งบ \$12 ล้าน กฎไม่บีบ: ทุนบวกทั้งคู่ ตัวคูณเป็นศูนย์ และ KKT ลดรูปเป็น Lagrange ทุกตัวอักษร ที่งบ \$0.5 ล้าน สูตร Lagrange สั่งให้เดสก์ 1 ถือทุนติดลบ กฎห้ามทุนติดลบของเดสก์ 1 จึงบีบ: เดสก์ 1 ได้ศูนย์ และ $u_1=0.667$ คือส่วนที่กำไรส่วนเพิ่มของเดสก์ 1 (2) ต่ำกว่าราคาภายในของทุน (2.667)

ตรวจเองใน 10 วินาที: $u_1x_1=0.667\times0=0$ และที่งบ 12 $u_i=0$ คูณอะไรก็ศูนย์ เส้นแบ่งคืองบ \$1 ล้าน ที่นั่น $x_1=(1-1)/3=0$ พอดี และ $\nu=4/2=2$ เท่ากับกำไรส่วนเพิ่มของเดสก์ 1 ที่ศูนย์ กำแพงแตะแต่ไม่ดัน

ขั้นที่ 3 — เงื่อนไขทั่วไปสี่ข้อ และความหมายทางเรขาคณิต

หลายตัวแปรใช้เหตุผลเดียวกับชามกับกำแพงของตัวแปรเดียว ทีละกำแพง รูปมาตรฐานคือหาค่าต่ำสุด สมการเขียน $h(x)=0$ อสมการเขียน $g_i(x)\le0$ กฎห้าม short $x_i\ge0$ จึงเขียนเป็น $g_i=-x_i\le0$ ข้างล่างคือ Lagrangian และเงื่อนไขสี่ข้อ

\[ \begin{aligned} \mathcal L&=f(x)+\nu\,h(x)+\textstyle\sum_iu_ig_i(x),\\ \text{(1)}&\quad\nabla f+\nu\nabla h+\textstyle\sum_iu_i\nabla g_i=0,\\ \text{(2)}&\quad h(x)=0,\qquad g_i(x)\le0,\\ \text{(3)}&\quad u_i\ge0,\\ \text{(4)}&\quad u_i\,g_i(x)=0. \end{aligned} \]

ข้อ 1 คือความชันสมดุลแบบ Lagrange ข้อ 2 คือคำตอบต้องทำตามกฎ (primal feasibility) ข้อ 3 คือตัวคูณของอสมการไม่ติดลบ (dual feasibility) ข้อ 4 คือถ้ายังไม่ชนขอบ ตัวคูณต้องเป็นศูนย์ (complementary slackness) ตัวคูณ $\nu$ ของสมการไม่มีข้อ 3 เพราะสมการดันได้ทั้งสองทาง

อ่านข้อ 1 เป็นภาพ: ย้ายข้างได้ $-\nabla f=\nu\nabla h+\sum u_i\nabla g_i$ ทิศที่ค่าเป้าหมายลดเร็วที่สุด ($-\nabla f$) ต้องชี้ออกนอกเขตตรง ๆ เป็นผลรวมไม่ติดลบของทิศตั้งฉากกับกำแพงที่ชน ($\nabla g_i$ ชี้ออกนอกเขต) ถ้ามันเอียงไปตามกำแพงหรือชี้เข้าในเขต ก็ยังไถลไปต่ำกว่านี้ได้ จุดนั้นจึงไม่ใช่คำตอบ

สำหรับพอร์ตความเสี่ยงต่ำสุด $f=x^{\mathsf T}Vx$, $h=\mathbf1^{\mathsf T}x-1$, $g_i=-x_i$ ข้อ 1 จึงเป็น $2Vx+\nu\mathbf1-u=0$ หรือ $u_i=2(Vx)_i+\nu$ เมื่อ objective เป็นชามที่โค้งขึ้นทุกทิศ (โจทย์ convex มีก้นเดียว) และกฎเป็นเส้นตรง จุดที่ผ่านทั้งสี่ข้อคือคำตอบที่ดีที่สุดของทั้งโจทย์ ไม่ใช่แค่เฉพาะที่ ส่วนทิศกลับ (คำตอบต้องผ่าน KKT) ต้องการให้กำแพงไม่เรียงตัวแปลก ๆ ซึ่งกฎเชิงเส้นผ่านเสมอ เมื่อทุกอย่างเป็นเส้นตรง ข้อ 4 คือ complementary slackness ของ LP duality และตัวคูณคือตัวแปร dual ตัวเดียวกัน

ขั้นที่ 4 — พอร์ตสามสินทรัพย์: ถ้า short ได้ สูตรสั่ง short หุ้นเทค 6.44%

โจทย์ให้อะไรมาบ้าง: covariance สร้างจากความผันผวนกับ correlation: ทแยงคือ $\sigma_i^2$ นอกทแยงคือ $\rho_{ij}\sigma_i\sigma_j$ (covariance matrix) correlation หุ้นสหรัฐฯ–พันธบัตร 0.30 หุ้นสหรัฐฯ–หุ้นเทค 0.65 พันธบัตร–หุ้นเทค 0.30 (สมมติ) ตัดกฎห้าม short ทิ้งก่อน คือ $u=0$ ทั้งหมด เหลือพอร์ตความเสี่ยงต่ำสุด $x=V^{-1}\mathbf1/(\mathbf1^{\mathsf T}V^{-1}\mathbf1)$ แก้ระบบ $Vz=\mathbf1$ ขนาด 3×3 แล้วหารด้วยผลรวม

\[ \begin{aligned} V_{11}&=0.04,\quad V_{22}=0.01,\quad V_{33}=0.1225,\\ V_{12}&=0.30(0.20)(0.10)=0.006,\\ V_{13}&=0.65(0.20)(0.35)=0.0455,\\ V_{23}&=0.30(0.10)(0.35)=0.0105,\\ \mathbf1^{\mathsf T}V^{-1}\mathbf1&\approx107.7329,\\ x&\approx(0.171392,\ 0.893041,\ -0.064433),\\ \sigma^2&=1/107.7329\approx0.0092822,\quad\sigma\approx9.634\%. \end{aligned} \]

คำตอบ: สูตรอยาก short หุ้นเทค 6.44% ทั้งที่มันผันผวนที่สุด เพราะขา short ทำหน้าที่เป็นประกันของหุ้นสหรัฐฯ: $V_{13}=0.0455$ ใหญ่กว่า $V_{12}$ ถึง 7.6 เท่า เวลาหุ้นสหรัฐฯลง หุ้นเทคมักลงด้วย ขา short จึงได้กำไรมาหักล้าง ทางคณิตศาสตร์ถูก แต่ตกข้อ 2 ของ KKT ใน mandate นี้

ตรวจเองใน 10 วินาที: $0.171392+0.893041-0.064433=1$ และที่คำตอบนี้ $(Vx)_i$ ทั้งสามตัวเท่ากันที่ 0.0092822 ลายเซ็นของพอร์ตความเสี่ยงต่ำสุด: ทุกสินทรัพย์มี covariance กับพอร์ตเท่ากัน จึงไม่มีการย้ายเล็ก ๆ ไหนลดความเสี่ยงได้

ขั้นที่ 5 — เดาว่ากฎข้อไหนบีบ แล้วสอบทั้ง 7 กรณี

ไม่รู้ล่วงหน้าว่าตัวไหนจะเป็นศูนย์ วิธีตรงไปตรงมาคือเดา: บังคับตัวที่เดาให้เป็นศูนย์ แก้ตัวที่เหลือแบบ Lagrange แล้วคำนวณ $u_i=2(Vx)_i+\nu$ มาสอบ สามสินทรัพย์ แต่ละตัวเป็นศูนย์หรือไม่ ได้ $2^3=8$ กรณี ตัดกรณีศูนย์ทั้งหมดเพราะขัดกับงบ เหลือ 7

ขั้นที่ 6 — กรณีที่รอด: หุ้นเทคเป็นศูนย์ แล้วสอบครบสี่ข้อ

โจทย์ให้อะไรมาบ้าง: บังคับ $x_3=0$ แถวและหลักที่ 3 หลุดจากปัญหา เหลือพอร์ตความเสี่ยงต่ำสุดของหุ้นสหรัฐฯกับพันธบัตร ซึ่งคือ $(2/19,\ 17/19)$ แล้วคูณ $V$ ทั้ง 3×3 เพื่อหาตัวคูณของทุกข้อ

\[ \begin{aligned} x&=(0.105263,\ 0.894737,\ 0),\quad\sigma\approx9.787\%,\\ (Vx)_1&=0.04(0.105263)+0.006(0.894737)\\ &\approx0.0095789,\\ (Vx)_2&=0.006(0.105263)+0.01(0.894737)\\ &\approx0.0095789,\\ (Vx)_3&=0.0455(0.105263)+0.0105(0.894737)\\ &\approx0.0141842,\\ \nu&=-2(0.0095789)=-0.0191579,\\ u_3&=2(0.0141842)-0.0191579\approx0.0092105. \end{aligned} \]

คำตอบ: $x=(10.53\%,\ 89.47\%,\ 0)$, $\nu=-0.019158$, $u=(0,\ 0,\ 0.00921)$ ข้อ 1 ผ่านตามการสร้าง ข้อ 2 น้ำหนักไม่ติดลบและรวมได้ 1 ข้อ 3 ทุก $u$ ไม่ติดลบ ข้อ 4 $u_ix_i=0$ ทั้งสามคู่ กฎห้าม short ของหุ้นเทคบีบ กฎของอีกสองตัวไม่บีบ

ตรวจเองใน 10 วินาที: สองตัวที่ถือมี $(Vx)$ เท่ากันและเท่ากับ $\sigma^2=0.0095789$ ส่วน $u_3=2[(Vx)_3-\sigma^2]$ คือสองเท่าของส่วนที่หุ้นเทคแพงเกินพอร์ตในแง่ความเสี่ยง: เติมหุ้นเทคจากศูนย์แล้วความเสี่ยงขึ้น ถ้าวันหนึ่งส่วนนี้เป็นศูนย์ กฎห้าม short จะไม่มีราคา และ $\nu$ ติดลบไม่ผิดกติกา เพราะเป็นตัวคูณของสมการ

ขั้นที่ 7 — u₃ คือราคาของกฎห้าม short

ตามภาพชามกับกำแพงของตัวแปรเดียว ถ้าถอยกำแพงไป $\varepsilon$ ค่าต่ำสุดลดราว $u\varepsilon$ ทดสอบด้วยการยอมให้ short หุ้นเทคได้ 1% ($x_3=-0.01$) แล้วแก้สองตัวที่เหลือใหม่ด้วยงบ 1.01

\[ \begin{aligned} x&\approx(0.115526,\ 0.894474,\ -0.01),\\ \sigma^2&\approx0.0094940,\\ \text{drop}&=0.0095789-0.0094940\\ &\approx0.0000850,\\ u_3\varepsilon&=0.0092105(0.01)\approx0.0000921,\\ \sigma&:\ 9.7872\%\ \to\ 9.7437\%. \end{aligned} \]

variance ลดจริง 0.0000850 ตัวคูณทำนาย 0.0000921 สูงไป 8.4% เพราะตัวคูณเป็นความชันที่จุดเดียว ส่วนค่าต่ำสุดโค้ง (ราคาของกำแพงลดลงเรื่อย ๆ ระหว่างที่ถอย) ความผันผวนลด 4.35 bp บนพอร์ต \$5 พันล้าน ความผันผวนของ P&L รายปีลดจาก \$489.36 ล้าน เป็น \$487.19 ล้าน คือ \$2.17 ล้าน จากการ short แค่ 1%

ต้นทุนทั้งหมดของกฎคือความผันผวน 9.787% เทียบ 9.634% เมื่อ short ได้เต็มที่ ต่างกัน 15.3 bp ต่อปี ตัวคูณบอกราคาของการผ่อนเล็ก ๆ การผ่อนเต็มที่ต้องแก้ใหม่ทั้งโจทย์ เพราะ active set อาจเปลี่ยนทั้งชุด

ขั้นที่ 8 — ข้อมูลเดิม กฎเดิม เป้าหมายใหม่: กฎไม่บีบเลย

โจทย์ให้อะไรมาบ้าง: เปลี่ยนเป้าหมายเป็นค่าเป้าหมาย mean-variance ของ Markowitz $\mu^{\mathsf T}x-\gamma x^{\mathsf T}Vx$ ด้วย $\mu=(12\%,\ 6\%,\ 15\%)$ และ $\gamma=2$ ยังลงเงินครบและห้าม short เขียนเป็นการหาค่าต่ำสุดของ $-J$ ข้อ 1 กลายเป็น $u=2\gamma Vx-\mu+\nu\mathbf1$ เดาว่าหุ้นเทคยังเป็นศูนย์ คำตอบของสองสินทรัพย์ที่ $\gamma=2$ คือ (0.5, 0.5, 0) แล้วสอบ

\[ \begin{aligned} Vx&=(0.023,\ 0.008,\ 0.028),\\ u_1=0:&\quad4(0.023)-0.12+\nu=0,\quad\nu=0.028,\\ u_3&=4(0.028)-0.15+0.028=-0.010\lt0,\\ u=(0,\ 0,\ 0):&\quad x\approx(0.4641,\ 0.5009,\ 0.0350),\\ J&\approx0.059175\gt0.059. \end{aligned} \]

คำตอบ: การเดานั้นตก dual ($u_3$ ติดลบ) แปลว่าปล่อยหุ้นเทคเถอะ แก้ใหม่โดยไม่บังคับได้น้ำหนักบวกทั้งสามตัว หุ้นเทค 3.50% กฎห้าม short ไม่บีบเลย ตัวคูณเป็นศูนย์ทั้งหมด และ KKT ลดรูปเป็นคำตอบของ Markowitz ธรรมดา

ตรวจเองใน 10 วินาที: ข้อมูลและกฎเหมือนเดิมทุกตัว แต่ active set คนละชุด เป้าหมายแรกสนใจแค่ความเสี่ยง หุ้นเทคผันผวนเกินไปจึงถูกเตะออก เป้าหมายที่สองให้เครดิตผลตอบแทน 15% ของมัน จึงคุ้มที่จะถือ อย่าถามว่ากฎนี้บีบไหมลอย ๆ ต้องถามว่าภายใต้เป้าหมายไหน

ขั้นที่ 9 — อสมการที่ไม่ใช่เส้นตรง: งบความเสี่ยง

กฎที่โต๊ะใช้บ่อยที่สุดไม่ใช่ห้าม short แต่คือ “ความผันผวนไม่เกินงบ” ใช้หุ้นกับพันธบัตรจากหน้า Markowitz (ผลตอบแทนส่วนเกินเงินสด $e=(10\%,\ 4\%)$) เงินที่เหลือเก็บเป็นเงินสด หาผลตอบแทนส่วนเกินสูงสุดเมื่อความผันผวนไม่เกิน $\bar\sigma=10\%$ ในรูปมาตรฐานคือหาค่าต่ำสุดของ $-e^{\mathsf T}x$ โดย $g=x^{\mathsf T}Vx-\bar\sigma^2\le0$

\[ \begin{aligned} \text{(1)}&\quad-e+2\lambda Vx=0\ \Rightarrow\ x=\frac{V^{-1}e}{2\lambda},\\ \text{(4)}&\quad\lambda\,(x^{\mathsf T}Vx-\bar\sigma^2)=0,\\ \lambda\gt0:&\quad\frac{e^{\mathsf T}V^{-1}e}{4\lambda^2}=\bar\sigma^2,\\ \lambda&=\frac{\sqrt{e^{\mathsf T}V^{-1}e}}{2\bar\sigma}=\frac{\mathrm{SR}}{2\bar\sigma}=\frac{0.5645}{0.20}\\ &\approx2.8226,\\ x&=\frac{(2.0879,\ 2.7473)}{5.6452}\approx(0.3699,\ 0.4867),\\ e^{\mathsf T}x&=\mathrm{SR}\cdot\bar\sigma\approx5.645\%. \end{aligned} \]

ข้อ 1 ให้ทิศของพอร์ตทันทีคือ $V^{-1}e$ ทิศเดียวกับ tangency ส่วนขนาดถูกกำหนดด้วย $\lambda$ ข้อ 4 บอกว่ามีสองทาง: $\lambda=0$ ซึ่งข้อ 1 จะเหลือ $e=0$ (เป็นไปไม่ได้เมื่อมีสินทรัพย์ที่ให้ผลตอบแทนส่วนเกิน) หรือกฎชนขอบพอดี งบความเสี่ยงจึงบีบเสมอ ใครมี edge ก็ใช้งบความเสี่ยงจนหมด ถือหุ้น 36.99% พันธบัตร 48.67% เงินสด 14.35% ได้ผลตอบแทนส่วนเกิน 5.645% $=0.5645\times10\%$

$\lambda$ คือราคาของ variance หนึ่งหน่วย ทดสอบ: ขยายงบ variance จาก 0.0100 เป็น 0.0101 ผลตอบแทนส่วนเกินเพิ่ม 0.000282 หารด้วย 0.0001 ได้ 2.816 ใกล้ $\lambda=2.823$ และ $\lambda$ นี้คือ $\gamma$ ของแบบหักค่าปรับพอดี: $V^{-1}e/(2\times2.8226)$ ให้พอร์ตเดียวกัน ข้อสังเกตอีกข้อ: ถ้าคูณ $e$ ด้วย 2 (ประเมินผลตอบแทนสูงไปสองเท่าทุกตัว) $x$ ไม่เปลี่ยนเลย เพราะ $V^{-1}e$ กับ $\sqrt{e^{\mathsf T}V^{-1}e}$ โตเท่ากัน ภายใต้งบความเสี่ยง ขนาดของผลตอบแทนที่ประมาณผิดไม่ทำร้าย ขอแค่สัดส่วนระหว่างตัวถูก

ข้อบังคับกับค่าปรับให้คำตอบเดียวกันเมื่อราคาตรงกัน แต่ต่างกันสองเรื่อง: ราคาเงาของข้อบังคับรู้หลังแก้เสร็จ จึงอาจกระโดดมากเมื่อเลื่อนเพดานนิดเดียว ส่วนค่าปรับตั้งราคาไว้ก่อนและคงที่ข้ามวัน และข้อบังคับหลายข้ออาจขัดกันจนไม่มีคำตอบเลย (เหมือนราคาเป็นอนันต์) ขณะที่โจทย์ค่าปรับมีคำตอบเสมอ ถ้าราคามีความหมายชัด เช่นต้นทุนเป็นดอลลาร์ ใช้ค่าปรับดีกว่า

กับดัก: ตัดแล้วย่อขยาย สอบแค่ครึ่งเดียว และลืมว่ามุมทำให้คำตอบกระโดด

ตัดน้ำหนักที่ติดลบเป็นศูนย์แล้วย่อขยายที่เหลือให้รวมได้ 1 คือโจทย์เปิดเรื่อง: $(0.171392,\ 0.893041)/1.064433=(16.10\%,\ 83.90\%)$ ความผันผวน 9.847% แย่กว่าคำตอบ KKT 6.0 bp ต่อปี ถ้าไม่เคยคำนวณ KKT ก็ไม่มีวันรู้ว่าเสียไปเท่าไร

สอบแค่ว่าน้ำหนักไม่ติดลบและรวมได้ 1 (primal) ไม่พอ สามกรณีท้ายของตารางเดาผ่าน primal ทั้งหมด ถ้ายอมรับกรณีถือหุ้นเทคล้วน variance คือ 0.1225 สูงกว่าคำตอบจริง 12.8 เท่า ต้องสอบเครื่องหมายของตัวคูณ (dual) เสมอ และต้องเขียนรูปมาตรฐานให้ถูก: หาค่าต่ำสุด อสมการแบบ $g\le0$ ตัวคูณไม่ติดลบ สามอย่างนี้ไปด้วยกัน เปลี่ยนอย่างหนึ่งต้องกลับเครื่องหมายอีกสองอย่าง

มุมของเขต long-only ทำให้คำตอบไวในแบบที่สูตรเรียบ ๆ ไม่ไว ในโจทย์ mean-variance ข้างบน ตราบที่ผลตอบแทนคาดหวังของหุ้นเทคไม่เกิน 14% มันได้ศูนย์ ($u_3=0.14-\mu_3\ge0$) ไม่ว่าจะเป็น 10% หรือ 13.9% แต่พอเกิน 14% น้ำหนักโตขึ้น 3.5 จุดต่อทุก 1 จุดของ $\mu_3$ ตัวเลขที่ประมาณได้ใกล้ 14% จึงสลับระหว่าง “ไม่ถือ” กับ “ถือ” ได้ทุกวัน ถ้าไม่มีต้นทุนการเทรดมาถ่วง (mean-variance ที่มีต้นทุนการเทรด)

ใช้ทำอะไรบนโต๊ะจริง

mandate จริงมีอสมการเต็มไปหมด: long-only เพดานรายตัว ถือหุ้นไม่เกิน 5% ของบริษัท เพดาน factor exposure เพดาน tracking error ต่อดัชนีอ้างอิง เพดาน leverage $\sum_i|x_i|\le G$ ซึ่งดูไม่เป็นเส้นตรง แต่แยก $x_i=p_i-q_i$ เป็นขา long กับขา short ที่ไม่ติดลบทั้งคู่ แล้วเขียน $\sum_i(p_i+q_i)\le G$ ได้เป็นเส้นตรง (พอร์ตแบบ 130/30 คือ $G=1.6$ กับงบ 1) optimizer เชิงพาณิชย์คืนตัวคูณของทุกข้อมาพร้อมน้ำหนัก ตัวคูณเหล่านั้นคือใบเสร็จของกฎ: ข้อที่ตัวคูณเป็นศูนย์คือกฎที่เขียนไว้แต่ไม่ได้กัดอะไรในวันนี้ ข้อที่ตัวคูณใหญ่คือข้อที่ควรเอาไปคุยกับคณะกรรมการก่อน

ข้อบังคับทำให้ผลลัพธ์แย่ลงเสมอถ้า input ถูกเป๊ะ เพราะเขตเลือกเล็กลง แต่เมื่อผลตอบแทนคาดหวังมีความคลาดเคลื่อนมาก กฎห้าม short และเพดานน้ำหนักมักช่วย เพราะมันตัดตำแหน่งสุดโต่งที่เกิดจากการไล่ noise ออก ทำงานคล้ายการหด covariance (Ledoit–Wolf shrinkage) ส่วนกฎที่ทำให้เขตไม่ convex เช่นถือได้ไม่เกิน 30 ตัว ทำให้ KKT ไม่พอรับประกันคำตอบ และ solver อาจหาไม่เจอ ส่วนใหญ่ควรเลี่ยง แล้วใช้ต้นทุนการเทรดหรือเกณฑ์ตัดคำสั่งเล็ก ๆ ทิ้งแทน

คำตอบเดิมถือพันธบัตร 89.47% เกินเพดาน เดาว่าพันธบัตรชนเพดาน 0.8 หุ้นเทคยังเป็นศูนย์ หุ้นสหรัฐฯได้ 0.2 จากงบ $Vx=(0.0128,\ 0.0092,\ 0.0175)$ หุ้นสหรัฐฯถูกถืออิสระจึง $\nu=-2(0.0128)=-0.0256$ เพดานเขียนเป็น $x_2-0.8\le0$ ข้อ 1 ของพันธบัตรคือ $2(Vx)_2+\nu+w=0$ ได้ตัวคูณ $w=-[2(0.0092)-0.0256]=0.0072\ge0$ หุ้นเทค $u_3=2(0.0175)-0.0256=0.0094\ge0$ ผ่านครบ variance 0.00992 (ความผันผวน 9.960%) ตรวจราคา: เพดาน 81% ให้ variance 0.0098518 ลดลง 0.0000682 ใกล้ $0.0072\times0.01=0.000072$

3. งบความผันผวนของโจทย์งบความเสี่ยงข้างบน ลดจาก 10% เหลือ 8% หาน้ำหนัก เงินสด ผลตอบแทนส่วนเกิน และ $\lambda$ แล้วอธิบายว่าทำไม $\lambda$ ใหญ่ขึ้น

เฉลย

ทิศเดิม $V^{-1}e=(2.0879,\ 2.7473)$ ขนาด $\bar\sigma/\mathrm{SR}=0.08/0.5645=0.14172$ ได้หุ้น 29.59% พันธบัตร 38.93% เงินสด 31.48% ผลตอบแทนส่วนเกิน $0.5645\times8\%=4.516\%$ และ $\lambda=0.5645/(2\times0.08)=3.528$ ผลตอบแทนส่วนเกินเป็นเส้นตรงในความผันผวน $\bar\sigma$ แต่งบเขียนเป็น variance $\bar\sigma^2$ ผลตอบแทนต่อ variance หนึ่งหน่วยจึงเท่ากับ $\mathrm{SR}/(2\bar\sigma)$ ยิ่งงบแคบ variance ที่เพิ่มหนึ่งหน่วยยิ่งมีค่า

function covariance(sd, corr) {
  if (!sd.every(s => Number.isFinite(s) && s > 0)) throw new RangeError('Volatilities must be positive');
  corr.forEach((r, i) => r.forEach((c, j) => {
    if (!Number.isFinite(c) || Math.abs(c) > 1 || c !== corr[j][i] || (i === j && c !== 1)) throw new RangeError('Invalid correlation matrix');
  }));
  return corr.map((r, i) => r.map((c, j) => c * sd[i] * sd[j]));
}
function solveLinear(A, b) {
  const n = A.length, M = A.map((r, i) => [...r, b[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (Math.abs(M[r][c]) > Math.abs(M[p][c])) p = r;
    if (Math.abs(M[p][c]) < 1e-14) throw new RangeError('Singular system: active set not solvable');
    [M[c], M[p]] = [M[p], M[c]];
    for (let r = 0; r < n; r++) { if (r === c) continue; const f = M[r][c] / M[c][c]; for (let k = c; k <= n; k++) M[r][k] -= f * M[c][k]; }
  }
  return M.map((r, i) => r[n] / r[i]);
}
const times = (V, x) => V.map(r => r.reduce((s, v, j) => s + v * x[j], 0));
// Minimise gamma x'Vx - mu'x with sum x = total; assets outside `free` are held at `fixed` (default 0).
// Returns weights, budget multiplier nu and bound multipliers u = 2 gamma Vx - mu + nu 1.
function solveActiveSet(V, free, {mu = V.map(() => 0), gamma = 1, total = 1, fixed = {}} = {}) {
  const x = V.map((_, i) => fixed[i] ?? 0), m = free.length, rows = [];
  free.forEach(i => rows.push([...free.map(j => 2 * gamma * V[i][j]), 1]));
  rows.push([...free.map(() => 1), 0]);
  const rhs = free.map(i => mu[i] - 2 * gamma * V[i].reduce((s, v, j) => s + (free.includes(j) ? 0 : v * x[j]), 0));
  rhs.push(total - x.reduce((s, v, j) => s + (free.includes(j) ? 0 : v), 0));
  const sol = solveLinear(rows, rhs);
  free.forEach((i, a) => { x[i] = sol[a]; });
  const nu = sol[m], Vx = times(V, x), variance = x.reduce((s, v, i) => s + v * Vx[i], 0);
  const u = Vx.map((v, i) => 2 * gamma * v - mu[i] + nu);
  return {x, nu, u, Vx, variance, sd: Math.sqrt(variance), J: mu.reduce((s, v, i) => s + v * x[i], 0) - gamma * variance};
}
// The KKT checks for bounds x_i >= 0 (with a rounding tolerance).
function kkt(r, tol = 1e-12) {
  return {primal: r.x.every(v => v >= -tol) && Math.abs(r.x.reduce((s, v) => s + v, 0) - 1) <= tol,
    dual: r.u.every(v => v >= -tol), complementary: r.u.every((v, i) => Math.abs(v * r.x[i]) <= tol)};
}

function riskBudget(V2, e, budget) {
  const d = solveLinear(V2, e), sr = Math.sqrt(e.reduce((s, v, i) => s + v * d[i], 0));
  if (!(sr > 0)) return {x: e.map(() => 0), lambda: 0, binding: false};
  return {x: d.map(v => v * budget / sr), excess: sr * budget, lambda: sr / (2 * budget), sharpe: sr, binding: true};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ที่กำแพง ความชันเข้าหาเขตที่อนุญาตต้องไม่ติดลบ: ตัวคูณของอสมการ $u\ge0$ และ $u$ คูณระยะห่างจากขอบเป็นศูนย์
  • KKT มีสี่ข้อ: ความชันสมดุล ทำตามกฎ ตัวคูณไม่ติดลบ complementary slackness เมื่อโจทย์ convex สี่ข้อนี้พอเพียง และทิศลงเขาที่คำตอบต้องชี้ออกนอกเขตตั้งฉากกับกำแพงที่ชน
  • พอร์ต long-only ความเสี่ยงต่ำสุดคือ 10.53/89.47/0 ที่ 9.787% กฎห้าม short มีราคา 15.3 bp และ $u_3=0.00921$ ส่วนการตัดแล้วย่อขยายเสียฟรี 6.0 bp
  • กฎเดียวกันบีบบ้างไม่บีบบ้างตามเป้าหมาย: mean-variance ถือหุ้นเทค 3.50% โดยกฎไม่บีบ และน้ำหนักหักมุมที่ผลตอบแทนคาดหวัง 14%
  • งบความเสี่ยงบีบเสมอเมื่อมี edge: $\lambda=\mathrm{SR}/(2\bar\sigma)=2.82$ ที่งบ 10% และ $\lambda$ คือ $\gamma$ ของแบบหักค่าปรับที่ให้พอร์ตเดียวกัน

หน้าถัดไป gradient descent และ Newton's method ถามว่าเมื่อโจทย์ไม่มีสูตรปิด เครื่องคำนวณเดินไปหาคำตอบอย่างไร และเลือกขนาดก้าวอย่างไรไม่ให้ระเบิด
