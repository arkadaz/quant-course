12.6 Karush-Kuhn-Tucker (KKT) Conditions — Inequality Constraints

กฎแบบอสมการ เช่น “ห้ามถือติดลบ” อาจบีบคำตอบ หรือไม่มีผลเลยก็ได้ KKT บอกว่ากฎข้อไหนบีบ และตัวคูณของข้อที่บีบคือราคาของกฎข้อนั้น

กองทุนแห่งหนึ่งรับเงินลูกค้ามาลงทุนในของสามอย่าง คือหุ้นสหรัฐฯ พันธบัตร (ตราสารหนี้ที่ราคาแกว่งน้อย) และหุ้นเทค กองทุนอยากแบ่งเงินให้ความเสี่ยงของทั้งก้อนต่ำที่สุด ส่วนผสมแบบนั้นเรียกว่า “พอร์ตความเสี่ยงต่ำสุด” สัดส่วนเงินที่ลงในแต่ละตัวเรียกว่าน้ำหนัก

สัญญากับลูกค้า (เรียกว่า mandate) มีกฎสองข้อ

  • ต้องลงเงินครบ น้ำหนักทั้งสามตัวจึงต้องรวมกันได้ 100%
  • ห้าม short น้ำหนักทุกตัวจึงต้องไม่ติดลบ short คือยืมของมาขายก่อนแล้วซื้อคืนทีหลัง ได้กำไรเมื่อราคาลง ในสูตรมันคือน้ำหนักติดลบ กองทุนที่ห้าม short เรียกว่า long-only

ของที่รู้ (ตัวเลขสมมติ):

  • ความผันผวนต่อปี คือขนาดการแกว่งของผลตอบแทนในหนึ่งปี วัดเป็น SD (standard deviation คือขนาดการแกว่งตามปกติรอบค่าเฉลี่ย ดูvariance และ SD) หุ้นสหรัฐฯ $\sigma_1=20\%$ พันธบัตร $\sigma_2=10\%$ หุ้นเทค $\sigma_3=35\%$ หน้านี้วัดความเสี่ยงของพอร์ตด้วยความผันผวนของทั้งพอร์ตเช่นกัน
  • correlation คือตัวเลขระหว่าง −1 ถึง 1 ที่บอกว่าสองตัวขึ้นลงพร้อมกันแค่ไหน หุ้นสหรัฐฯ กับหุ้นเทคได้ 0.65 คือขึ้นลงด้วยกันบ่อย อีกสองคู่ได้ 0.30

ถ้าไม่มีกฎห้าม short สูตรพอร์ตความเสี่ยงต่ำสุดจากหน้าตัวคูณ Lagrange สั่งให้ถือหุ้นสหรัฐฯ 17.14% พันธบัตร 89.30% และหุ้นเทค −6.44% (หน้านี้จะคำนวณตัวเลขชุดนี้ให้ดูในขั้นที่ 4) หุ้นเทคติดลบคือ short ซึ่ง mandate ห้าม

นักวิเคราะห์จึงแก้แบบง่าย ๆ ตัดหุ้นเทคเป็นศูนย์ แล้วขยายสองตัวที่เหลือตามสัดส่วนเดิมให้รวมได้ 100%

\[\begin{aligned}17.14+89.30&=106.44,\\\frac{17.14}{106.44}&\approx16.10\%,\\\frac{89.30}{106.44}&\approx83.90\%.\end{aligned}\]

พอร์ต 16.10% / 83.90% / 0 นี้คือพอร์ต long-only ที่เสี่ยงน้อยที่สุดไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ใช่ พอร์ตที่ถูกคือหุ้นสหรัฐฯ 10.53% พันธบัตร 89.47% หุ้นเทค 0% มีความผันผวน 9.787% ต่อปี ส่วนพอร์ตที่ตัดแล้วขยายมีความผันผวน 9.847% (หน้านี้จะคำนวณตัวเลขแรกในขั้นที่ 6 และตัวเลขหลังในกับดักท้ายหน้า) ส่วนต่างคือ

\[9.847\%-9.787\%=0.060\%=6.0\ \text{bp}.\]

bp (basis point) คือ 0.01% พอร์ตที่ตัดแล้วขยายจึงเสี่ยงเกินจำเป็น 6.0 bp ต่อปี โดยไม่ได้อะไรกลับมาเลย

ทำไมการขยายตามสัดส่วนเดิมจึงผิด สัดส่วน 17 : 89 เดิมถูกเลือกมาคู่กับขา short หุ้นเทค ขา short นี้คอยหักล้างความเสี่ยงของหุ้นสหรัฐฯ เพราะสองตัวนี้ขึ้นลงด้วยกันบ่อย พอตัดหุ้นเทคทิ้ง ตัวหักล้างก็หายไปด้วย สัดส่วนที่ดีที่สุดของสองตัวที่เหลือจึงเปลี่ยน ต้องแก้โจทย์ใหม่ ไม่ใช่แค่ขยาย

KKT บอกราคาของกฎด้วย ตัวคูณของกฎห้าม short หุ้นเทคคือ $u_3=0.00921$ (ขั้นที่ 6) และกฎห้าม short ทั้งชุดทำให้ความผันผวนขึ้นจาก 9.634% เป็น 9.787% คือแพงขึ้น $9.787\%-9.634\%=0.153\%=15.3$ bp ต่อปี (ขั้นที่ 7)

ภาพรวมก่อนลงสูตร

หน้าตัวคูณ Lagrange แก้โจทย์ที่กฎเป็นสมการ คือต้องเท่ากับพอดี เช่น น้ำหนักรวมต้องเท่ากับ 100% แต่กฎจริงของพอร์ตส่วนใหญ่เป็นอสมการ คือห้ามเกินหรือห้ามต่ำกว่า เช่น

  • ห้าม short: น้ำหนักแต่ละตัวต้อง $\ge0$
  • ถือตัวเดียวได้ไม่เกิน 10%: น้ำหนักแต่ละตัวต้อง $\le10\%$
  • ความผันผวนของพอร์ตต้องไม่เกินงบที่ตั้งไว้

อสมการต่างจากสมการตรงที่มันมีได้สองสถานะ บางครั้งมันบีบคำตอบจริง ๆ คำตอบไปชนขอบของกฎพอดี บางครั้งคำตอบอยู่ห่างขอบ กฎข้อนั้นก็ไม่มีผลอะไรเลย KKT conditions (ตั้งชื่อตาม Karush, Kuhn และ Tucker) คือชุดเงื่อนไขที่ครอบทั้งสองสถานะไว้ในชุดเดียว เราจึงไม่ต้องรู้ล่วงหน้าว่ากฎข้อไหนบีบ

ภาพที่ควรมีในหัวคือลูกแก้วในชาม กับกำแพงที่กั้นบางส่วนของชามไว้ ก้นชามคือค่าต่ำสุดที่เราอยากได้ ถ้าก้นชามอยู่ในเขตที่อนุญาต ลูกแก้วกลิ้งไปหยุดที่ก้น กำแพงไม่ได้ทำอะไร ความชันที่ก้นเป็นศูนย์เหมือนโจทย์ที่ไม่มีกฎ ถ้าก้นชามอยู่หลังกำแพง ลูกแก้วกลิ้งไปชนกำแพงแล้วหยุดตรงนั้น จุดนั้นความชันไม่เป็นศูนย์ ลูกแก้วยังอยากไหลต่อ กำแพงจึงต้องดันกลับด้วยแรงที่พอดี แรงนี้คือตัวคูณ $u$ และ $u$ ต้องไม่ติดลบ เพราะกำแพงดันได้ทางเดียว ดึงไม่ได้

หน้านี้เริ่มจากตัวแปรตัวเดียว แล้วขยายเป็นเงื่อนไขทั่วไปสี่ข้อ จากนั้นกลับมาแก้กองทุนในโจทย์เปิดเรื่อง โดยเดาว่ากฎข้อไหนบีบแล้วสอบ อ่านราคาของกฎห้าม short ลองเปลี่ยนเป้าหมายของกองทุนแล้วดูกฎเดิมที่ไม่บีบเลย และจบที่งบความเสี่ยง ซึ่งเป็นอสมการที่ไม่ใช่เส้นตรง

KKT conditions
เงื่อนไขสี่ข้อที่คำตอบที่ดีที่สุดของโจทย์ที่มีอสมการต้องผ่าน ใช้ได้ทั้งตรวจคำตอบและหาคำตอบ ชื่อมาจาก Karush, Kuhn และ Tucker
Short และ long-only
short คือยืมของมาขายก่อนแล้วซื้อคืนทีหลัง ได้กำไรเมื่อราคาลง ในสูตรเป็นน้ำหนักติดลบ กองทุน long-only คือกองทุนที่ห้าม short
Mandate
สัญญาระหว่างกองทุนกับลูกค้า บอกว่ากองทุนลงทุนในอะไรได้ และต้องทำตามกฎอะไรบ้าง
Basis point (bp)
หนึ่งในร้อยของหนึ่งเปอร์เซ็นต์ คือ 1 bp = 0.01% ใช้วัดส่วนต่างเล็ก ๆ ของผลตอบแทนหรือความผันผวน
Active (binding) constraint
อสมการที่คำตอบชนขอบพอดี เช่นน้ำหนักเป็นศูนย์พอดี เป็นกฎที่กำลังบีบคำตอบ ตัวคูณของมันจึงเป็นบวกได้
Inactive constraint
อสมการที่คำตอบยังอยู่ห่างขอบ เช่นน้ำหนักเป็นบวก กฎข้อนี้ไม่มีผลต่อคำตอบ ตัวคูณของมันจึงเป็นศูนย์
Primal feasibility
เงื่อนไขว่าคำตอบต้องทำตามกฎทุกข้อ เช่นน้ำหนักไม่ติดลบและรวมได้ 1
Dual feasibility
เงื่อนไขว่าตัวคูณของอสมการต้องไม่ติดลบ (เมื่อเขียนโจทย์ในรูปมาตรฐาน) ถ้าคำนวณได้ติดลบ แปลว่าปล่อยขอบแล้วจะดีกว่า เราเดาผิด
Complementary slackness
เงื่อนไขว่าตัวคูณคูณกับระยะห่างจากขอบต้องได้ศูนย์ กฎที่ยังไม่ชนขอบจึงไม่มีราคา และกฎที่มีราคาต้องชนขอบ
Active set
ชุดของอสมการที่ชนขอบที่คำตอบ วิธีแก้แบบ active set คือเดาชุดนี้ แก้เหมือนเป็นสมการ แล้วสอบด้วยเครื่องหมายของตัวคูณ
Penalty
ค่าปรับ คือการเอากฎออก แล้วหักค่าปรับตามราคาที่ตั้งเองออกจากค่าเป้าหมายแทน ถ้าตั้งราคาเท่ากับตัวคูณ จะได้คำตอบเดียวกับการใช้กฎ ข้อดีคือโจทย์มีคำตอบเสมอ

ขั้นที่ 1 — ตัวแปรเดียวกับกำแพงหนึ่งด้าน

ก่อนแก้พอร์ตสามตัว เราดูกรณีที่เล็กที่สุดก่อน เพื่อให้เห็นว่าเงื่อนไขหน้าตาอย่างไร มีตัวแปรตัวเดียว $x$ มีค่าที่อยากให้ต่ำที่สุด $f(x)$ และมีกฎข้อเดียวคือ $x\ge0$ เรียกคำตอบว่า $x^\star$ คำตอบมีได้สองแบบตามรูปข้างบน คืออยู่กลางเขต ($x^\star\gt0$) หรือชนกำแพง ($x^\star=0$) เราเขียนเงื่อนไขของแต่ละแบบ แล้วรวมเป็นชุดเดียว

\[ \begin{aligned} x^\star\gt0:&\quad f'(x^\star)=0,\\ x^\star=0:&\quad f'(0)\ge0,\\ u&:=f'(x^\star)\ge0,\quad u\,x^\star=0. \end{aligned} \]

กลางเขต ลูกแก้วขยับได้ทั้งซ้ายและขวา ถ้าความชันไม่เป็นศูนย์ ก็ขยับไปทางที่ต่ำกว่าได้เสมอ ความชันจึงต้องเป็นศูนย์ แบบเงื่อนไขอันดับหนึ่ง ที่กำแพง ลูกแก้วขยับได้ทางเดียวคือไปทางขวา (เข้าเขต) ถ้าความชันติดลบ ขยับขวาแล้ว $f$ ต่ำลง จุดนั้นจึงยังไม่ใช่คำตอบ ดังนั้นที่กำแพง ความชันต้องไม่ติดลบ

เรียกความชันที่คำตอบว่า $u$ แล้วสองแบบรวมเป็นเงื่อนไขเดียวได้ คือ $u$ ต้องไม่ติดลบ และผลคูณ $u\,x^\star$ ต้องเป็นศูนย์ เพราะกลางเขตมี $u=0$ ส่วนที่กำแพงมี $x^\star=0$ ผลคูณจึงเป็นศูนย์ทั้งสองแบบ

ลองใช้กับสองชามในรูป หาความชันของแต่ละชาม แล้วดูว่าจุดที่ความชันเป็นศูนย์อยู่ในเขตหรือไม่

\[ \begin{aligned} f=(x-2)^2:&\quad f'(x)=2(x-2),\\ &\quad f'(2)=0,\ x^\star=2,\ u=0,\\ f=(x+1)^2:&\quad f'(x)=2(x+1),\\ &\quad f'(-1)=0,\ \text{but}\ -1\lt0,\\ &\quad x^\star=0,\ u=f'(0)=2. \end{aligned} \]

ชามแรกมีก้นที่ 2 ซึ่งอยู่ในเขต กำแพงไม่ได้ทำอะไร $u$ จึงเป็นศูนย์ ชามที่สองมีก้นที่ −1 ซึ่งอยู่ในเขตห้าม คำตอบจึงชนกำแพงที่ 0 และ $u=2$ คือแรงที่ชามดันกำแพง

ทำไมเรียก $u$ ว่าราคาของกำแพง ลองถอยกำแพงของชามที่สองจาก 0 ไปที่ $-\varepsilon$ ($\varepsilon$ คือระยะเล็ก ๆ ที่เป็นบวก) คำตอบใหม่ก็ชนกำแพงใหม่ที่ $-\varepsilon$ แล้วเทียบค่าต่ำสุดก่อนกับหลัง

\[ \begin{aligned} f(0)&=(0+1)^2=1,\\ f(-\varepsilon)&=(1-\varepsilon)^2=1-2\varepsilon+\varepsilon^2,\\ f(0)-f(-\varepsilon)&=2\varepsilon-\varepsilon^2\approx2\varepsilon. \end{aligned} \]

ค่าต่ำสุดลดลงราว $u\varepsilon=2\varepsilon$ เพราะเมื่อ $\varepsilon$ เล็ก ตัว $\varepsilon^2$ เล็กกว่ามากจนตัดทิ้งได้ ตัวคูณของอสมการจึงบอกว่ากำแพงทำให้เราเสียไปเท่าไรต่อการถอยหนึ่งหน่วย แบบเดียวกับที่ตัวคูณ Lagrange เป็นราคาของสมการ

ขั้นที่ 2 — แบ่งทุนสองเดสก์: กฎบีบเมื่องบน้อย ไม่บีบเมื่องบมาก

ขั้นนี้ใช้กฎของขั้นที่ 1 กับโจทย์จริงขนาดเล็ก เป็นโจทย์แบ่งทุนเดียวกับหน้าตัวคูณ Lagrange ซึ่งวิธี Lagrange พังเมื่องบเหลือน้อย เราจะดูว่า KKT ซ่อมมันอย่างไร

โจทย์ให้อะไรมาบ้าง: หัวหน้าฝ่ายเทรดแบ่งทุนให้สองเดสก์ (ทีมเทรดย่อย)

  • เดสก์ 1 ได้ทุน $x_1$ ล้านดอลลาร์ เดสก์ 2 ได้ $x_2$ ล้านดอลลาร์ ทุนรวมคือ $b$ ล้าน จึง $x_1+x_2=b$
  • กำไรคาดหวังต่อปี (แบบจำลองสมมติจากหน้าตัวคูณ Lagrange) คือ $2\ln(1+x_1)+4\ln(1+x_2)$ ล้านดอลลาร์
  • ทุนห้ามติดลบ: $x_1\ge0$ และ $x_2\ge0$

กำไรส่วนเพิ่มคือกำไรที่ได้เพิ่มจากทุนก้อนเล็ก ๆ ถัดไป หาได้จากอนุพันธ์ของกำไร เดสก์ 1 ได้ $2/(1+x_1)$ เดสก์ 2 ได้ $4/(1+x_2)$ ส่วน $\nu$ คือราคาภายในของทุน คือกำไรที่ทุนก้อนเล็ก ๆ ถัดไปทำได้ เมื่อแบ่งทุนดีที่สุดแล้ว

ใช้ขั้นที่ 1 ทีละเดสก์ เดสก์ที่ได้ทุนต้องมีกำไรส่วนเพิ่มเท่ากับ $\nu$ พอดี เพราะถ้าสูงกว่า ควรได้ทุนเพิ่ม ถ้าต่ำกว่า ควรถูกลดทุน เดสก์ที่ได้ศูนย์ต้องมีกำไรส่วนเพิ่มไม่เกิน $\nu$ เพราะลดทุนให้ต่ำกว่าศูนย์ไม่ได้ ส่วนต่าง $u_i$ ระหว่าง $\nu$ กับกำไรส่วนเพิ่มของเดสก์ $i$ ต้องไม่ติดลบ และมันคือตัวคูณของกฎห้ามทุนติดลบ

ลองแบบที่ทั้งสองเดสก์ได้ทุนก่อน (interior) กำไรส่วนเพิ่มต้องเท่ากัน แล้วใช้งบหา $x_1$ จากนั้นแทน $b=12$ กับ $b=0.5$

\[ \begin{aligned} \text{interior}:&\quad\frac{2}{1+x_1}=\frac{4}{1+x_2},\\ &\quad1+x_2=2(1+x_1),\\ &\quad x_2=2x_1+1,\\ x_1+x_2=b:&\quad3x_1+1=b,\ x_1=\frac{b-1}{3},\\ b=12:&\quad x_1=\tfrac{11}{3},\ x_2=12-\tfrac{11}{3}=\tfrac{25}{3},\\ &\quad\nu=\frac{2}{1+11/3}=\frac37,\quad u=(0,\ 0),\\ b=0.5:&\quad x_1=\frac{0.5-1}{3}=-\tfrac16\lt0\ \text{(fails)},\\ &\quad x=(0,\ 0.5),\quad\nu=\frac{4}{1+0.5}\approx2.667,\\ &\quad u_1=2.667-\frac{2}{1+0}\approx0.667\ge0. \end{aligned} \]

คำตอบ: ที่งบ \$12 ล้าน กฎห้ามทุนติดลบไม่บีบ ทั้งสองเดสก์ได้ทุนบวก ตัวคูณเป็นศูนย์ทั้งคู่ และ KKT ให้คำตอบเดียวกับวิธี Lagrange ทุกตัว ที่งบ \$0.5 ล้าน สูตร Lagrange สั่งให้เดสก์ 1 ถือทุน $-1/6$ ล้าน ซึ่งทำไม่ได้ กฎของเดสก์ 1 จึงบีบ เดสก์ 1 ได้ศูนย์ เดสก์ 2 ได้ทั้ง \$0.5 ล้าน และ $u_1=0.667$ คือส่วนที่กำไรส่วนเพิ่มของเดสก์ 1 (คือ 2) ต่ำกว่าราคาภายในของทุน (คือ 2.667)

ตรวจเองใน 10 วินาที: ที่งบ \$0.5 ล้าน $u_1x_1=0.667\times0=0$ ที่งบ \$12 ล้าน $u_i=0$ คูณอะไรก็ได้ศูนย์ ข้อ “ผลคูณเป็นศูนย์” จึงผ่านทั้งสองงบ เส้นแบ่งระหว่างสองแบบคืองบ \$1 ล้าน ที่นั่น $x_1=(1-1)/3=0$ พอดี และ $\nu=4/(1+1)=2$ เท่ากับกำไรส่วนเพิ่มของเดสก์ 1 ที่ทุนศูนย์ $2/(1+0)=2$ กำแพงแตะคำตอบแต่ไม่ต้องดัน

ขั้นที่ 3 — เงื่อนไขทั่วไปสี่ข้อ และความหมายทางเรขาคณิต

ขั้นที่ 1 และ 2 มีตัวแปรน้อย แต่พอร์ตจริงมีหลายตัวแปรและหลายกฎ เราจึงต้องมีเงื่อนไขชุดเดียวที่ใช้ได้กับทุกโจทย์ เหตุผลยังเป็นชามกับกำแพงเหมือนเดิม แค่คิดทีละกำแพง

ก่อนอื่นต้องเขียนโจทย์ในรูปมาตรฐาน เพื่อให้เครื่องหมายของตัวคูณมีความหมายเดียวกันทุกโจทย์

  • หาค่าต่ำสุดของ $f(x)$ ถ้าโจทย์หาค่าสูงสุด ให้หาค่าต่ำสุดของ $-f$ แทน
  • กฎแบบสมการเขียนเป็น $h(x)=0$ และมีตัวคูณ $\nu$
  • กฎแบบอสมการเขียนเป็น $g_i(x)\le0$ และมีตัวคูณ $u_i$ เช่นกฎห้าม short $x_i\ge0$ เขียนเป็น $g_i(x)=-x_i\le0$

Lagrangian $\mathcal L$ คือ $f$ บวกกฎทุกข้อคูณตัวคูณของมัน KKT คือเงื่อนไขสี่ข้อข้างล่าง

\[ \begin{aligned} \mathcal L&=f(x)+\nu\,h(x)+\textstyle\sum_iu_ig_i(x),\\ \text{(1)}&\quad\nabla f+\nu\nabla h+\textstyle\sum_iu_i\nabla g_i=0,\\ \text{(2)}&\quad h(x)=0,\qquad g_i(x)\le0,\\ \text{(3)}&\quad u_i\ge0,\\ \text{(4)}&\quad u_i\,g_i(x)=0. \end{aligned} \]

สี่ข้อนี้คือภาพชามกับกำแพงที่เขียนเป็นสมการ ข้อ (1) บอกว่าแรงไหลของชามกับแรงดันของกำแพงหักล้างกันพอดี (stationarity) ข้อ (2) บอกว่าคำตอบต้องทำตามกฎ (primal feasibility) ข้อ (3) บอกว่ากำแพงดันได้ทางเดียว (dual feasibility) ข้อ (4) บอกว่ากำแพงที่ไม่ได้แตะคำตอบต้องไม่ดัน ถ้า $g_i(x)\lt0$ ก็ต้องได้ $u_i=0$ (complementary slackness) ตัวคูณ $\nu$ ของสมการไม่ต้องผ่านข้อ (3) เพราะกฎแบบสมการเหมือนกำแพงสองด้าน ดันได้ทั้งสองทาง

อ่านข้อ (1) เป็นภาพ ย้ายข้างได้ $-\nabla f=\nu\nabla h+\sum_iu_i\nabla g_i$ ด้านซ้ายคือทิศที่ $f$ ลดเร็วที่สุด ด้านขวาคือผลรวมของทิศที่ตั้งฉากกับกำแพงที่ชน ($\nabla g_i$ ชี้ออกนอกเขต) คูณน้ำหนักที่ไม่ติดลบ สมการนี้จึงบอกว่าที่คำตอบ ทางลงเขาต้องชี้ออกนอกเขตตรง ๆ ถ้ามันเอียงไปตามกำแพง หรือชี้เข้าในเขต ลูกแก้วก็ยังไถลไปที่ต่ำกว่านี้ได้ จุดนั้นจึงไม่ใช่คำตอบ

ต่อไปใช้สี่ข้อนี้กับพอร์ตความเสี่ยงต่ำสุด สิ่งที่อยากให้ต่ำคือ variance ของพอร์ต $f=x^{\mathsf T}Vx$ ($V$ คือ covariance matrix) กฎสมการคือลงเงินครบ $h=\mathbf1^{\mathsf T}x-1=0$ และกฎห้าม short คือ $g_i=-x_i\le0$ เราหาความชันของแต่ละตัว แล้วแทนในข้อ (1)

\[ \begin{aligned} \nabla f&=2Vx,\\ \nabla h&=\mathbf1,\\ \textstyle\sum_iu_i\nabla g_i&=-u,\\ 2Vx+\nu\mathbf1-u&=0,\\ u_i&=2(Vx)_i+\nu. \end{aligned} \]

จุดที่ต้องระวังคือความชันของ $g_i=-x_i$ ฟังก์ชันนี้ขึ้นกับ $x_i$ ตัวเดียว ความชันจึงเป็น −1 ที่ตำแหน่ง $i$ และเป็นศูนย์ที่ตำแหน่งอื่น พอรวมทุก $i$ จึงเหลือ $-u$ สูตร $u_i=2(Vx)_i+\nu$ คือเครื่องมือที่จะใช้ตลอดหน้านี้ ตัวคูณของกฎห้าม short ของสินทรัพย์ $i$ คำนวณได้จาก $(Vx)_i$ ซึ่งคือ covariance ของสินทรัพย์ $i$ กับทั้งพอร์ต

สี่ข้อนี้พอไหม ถ้า $f$ เป็นชามที่โค้งขึ้นทุกทิศ (โจทย์ convex มีก้นเดียว) และกฎทุกข้อเป็นเส้นตรง จุดที่ผ่านทั้งสี่ข้อคือคำตอบที่ดีที่สุดของทั้งโจทย์ ไม่ใช่แค่ดีที่สุดในละแวกใกล้ ๆ ทางกลับก็จริง คือคำตอบที่ดีที่สุดต้องผ่าน KKT แต่ทางนี้ต้องการให้กำแพงไม่เรียงตัวแปลก ๆ ซึ่งกฎเชิงเส้นผ่านเสมอ เมื่อทุกอย่างเป็นเส้นตรง ข้อ (4) คือ complementary slackness ตัวเดียวกับในLP duality และตัวคูณก็คือตัวแปร dual ตัวเดียวกัน

ขั้นที่ 4 — พอร์ตสามสินทรัพย์: ถ้า short ได้ สูตรสั่ง short หุ้นเทค 6.44%

ตอนนี้กลับไปที่กองทุนในโจทย์เปิดเรื่อง ขั้นนี้คำนวณตัวเลข 17.14% / 89.30% / −6.44% ที่โจทย์เปิดเรื่องอ้างถึง โดยยังไม่ใส่กฎห้าม short เพื่อดูก่อนว่าสูตรอยากทำอะไร

โจทย์ให้อะไรมาบ้าง: ความผันผวนและ correlation จากโจทย์เปิดเรื่อง เรียงลำดับเป็น 1 หุ้นสหรัฐฯ 2 พันธบัตร 3 หุ้นเทค covariance matrix $V$ เก็บ covariance ของทุกคู่ (covariance matrix) และสร้างได้จากสองอย่างนี้ ช่องทแยงคือ $V_{ii}=\sigma_i^2$ ช่องนอกทแยงคือ $V_{ij}=\rho_{ij}\sigma_i\sigma_j$ โดย $\rho_{ij}$ คือ correlation ของคู่ $i,\ j$

ตัดกฎห้าม short ทิ้งก่อน คือให้ $u=0$ ทุกตัว สูตรของขั้นที่ 3 เหลือ $2Vx=-\nu\mathbf1$ แปลว่า $x$ ต้องชี้ทิศเดียวกับ $z=V^{-1}\mathbf1$ เราจึงแก้ระบบสมการ $Vz=\mathbf1$ ขนาด 3×3 (ด้วย Gaussian elimination หรือโค้ดท้ายหน้า) แล้วหาร $z$ ด้วยผลรวมของมัน $s$ ให้น้ำหนักรวมได้ 1

\[ \begin{aligned} V_{11}&=0.20^2=0.04,\\ V_{22}&=0.10^2=0.01,\\ V_{33}&=0.35^2=0.1225,\\ V_{12}&=0.30(0.20)(0.10)=0.006,\\ V_{13}&=0.65(0.20)(0.35)=0.0455,\\ V_{23}&=0.30(0.10)(0.35)=0.0105,\\ z&\approx(18.4645,\ 96.2099,\ -6.9416),\\ s&=\mathbf1^{\mathsf T}z\approx107.7329,\\ x&=z/s\approx(0.171392,\ 0.893041,\ -0.064433),\\ \sigma^2&=x^{\mathsf T}Vx=\frac{z^{\mathsf T}Vz}{s^2},\\ &=\frac{z^{\mathsf T}\mathbf1}{s^2}=\frac1s,\\ &=\frac{1}{107.7329}\approx0.0092822,\\ \sigma&=\sqrt{0.0092822}\approx9.634\%. \end{aligned} \]

ทางลัดตอนหา variance ใช้ $Vz=\mathbf1$ จึงแทน $Vz$ ด้วย $\mathbf1$ ได้ และ $z^{\mathsf T}\mathbf1$ ก็คือผลรวม $s$ นั่นเอง

คำตอบ: สูตรอยากถือหุ้นเทคติดลบ 6.44% คือ short ทั้งที่หุ้นเทคผันผวนที่สุด เหตุผลคือขา short ทำหน้าที่เป็นประกันให้หุ้นสหรัฐฯ หุ้นเทคขึ้นลงตามหุ้นสหรัฐฯ มากกว่าพันธบัตรมาก ดูได้จาก covariance $V_{13}/V_{12}=0.0455/0.006\approx7.6$ เท่า เวลาหุ้นสหรัฐฯ ลง หุ้นเทคมักลงด้วย ขา short หุ้นเทคจึงได้กำไรมาหักล้างส่วนที่ขาดทุน ทางคณิตศาสตร์ถูกต้อง แต่ตกข้อ (2) ของ KKT (ทำตามกฎ) ภายใต้ mandate นี้

ตรวจเองใน 10 วินาที: $0.171392+0.893041-0.064433=1$ และที่คำตอบนี้ $(Vx)_i$ ทั้งสามตัวเท่ากันที่ 0.0092822 เพราะ $u=0$ ทำให้ $(Vx)_i=-\nu/2$ ทุกตัว นี่คือลายเซ็นของพอร์ตความเสี่ยงต่ำสุด ทุกสินทรัพย์มี covariance กับพอร์ตเท่ากัน ถ้าย้ายเงินก้อนเล็ก $\delta$ จากตัว $j$ ไปตัว $i$ variance จะเปลี่ยนราว $2\delta[(Vx)_i-(Vx)_j]=0$ จึงไม่มีการย้ายเล็ก ๆ ไหนลดความเสี่ยงได้

ขั้นที่ 5 — เดาว่ากฎข้อไหนบีบ แล้วสอบทั้ง 7 กรณี

เรารู้แล้วว่าหุ้นเทคอยากติดลบ แต่ยังไม่รู้แน่ว่าเมื่อห้าม short แล้ว ตัวไหนจะเป็นศูนย์บ้าง บางทีพอหุ้นเทคเป็นศูนย์ ตัวอื่นอาจอยากติดลบตาม วิธีที่ตรงไปตรงมาที่สุดคือเดาแล้วสอบ

  1. เดาว่าตัวไหนเป็นศูนย์ แล้วล็อกตัวนั้นไว้ที่ศูนย์ ชุดที่ล็อกนี้เรียกว่า active set
  2. แก้ตัวที่เหลือแบบ Lagrange เหมือนขั้นที่ 4
  3. คำนวณตัวคูณ $u_i=2(Vx)_i+\nu$ แล้วสอบสองอย่าง น้ำหนักต้องไม่ติดลบ (primal) และตัวคูณต้องไม่ติดลบ (dual)

\[ \begin{aligned} Vx&=(0.006,\ 0.01,\ 0.0105),\\ u_2=0:&\quad\nu=-2(0.01)=-0.02,\\ u_1&=2(0.006)-0.02=-0.008\lt0. \end{aligned} \]

$u_1$ ติดลบแปลว่าถ้าปล่อยให้หุ้นสหรัฐฯ มีน้ำหนักบ้าง ความเสี่ยงจะลดลง การล็อกหุ้นสหรัฐฯ ไว้ที่ศูนย์กำลังทำร้ายพอร์ต การเดานี้จึงผิด

มีแบบเดียวที่ผ่าน และต้องมีแบบเดียว เพราะชามที่โค้งขึ้นทุกทิศมีก้นเดียว software จริงไม่ไล่ครบทุกแบบ เพราะหุ้น 500 ตัวมี $2^{500}$ แบบ มันใช้ active-set method ที่เดาฉลาดกว่า คือเริ่มจากชุดหนึ่ง ปล่อยตัวที่ $u$ ติดลบมากที่สุด และล็อกตัวที่วิ่งไปชนขอบก่อน หรือใช้ interior-point method ที่เดินอยู่ในเขต แล้วค่อย ๆ เข้าหาขอบ

ขั้นที่ 6 — กรณีที่รอด: หุ้นเทคเป็นศูนย์ แล้วสอบครบสี่ข้อ

ขั้นนี้คำนวณแบบที่รอดให้ดูครบทุกตัวเลข แล้วสอบ KKT ทั้งสี่ข้อทีละข้อ

โจทย์ให้อะไรมาบ้าง: ล็อกหุ้นเทคไว้ที่ $x_3=0$ แถวและหลักที่ 3 ของ $V$ จึงไม่มีผลต่อ variance เหลือโจทย์สองสินทรัพย์ คือหุ้นสหรัฐฯ $x_1$ กับพันธบัตร $x_2=1-x_1$ สองตัวนี้ถือได้อิสระ จึง $u_1=u_2=0$ และต้องมี $(Vx)$ เท่ากันตามลายเซ็นในขั้นที่ 4 แทน $x_2=1-x_1$ ลงในแถวที่ 1 และ 2 ของ $V$ ได้ $(Vx)_1=0.04x_1+0.006(1-x_1)$ กับ $(Vx)_2=0.006x_1+0.01(1-x_1)$ แล้วจับให้เท่ากัน

\[ \begin{aligned} (Vx)_1&=0.006+0.034x_1,\\ (Vx)_2&=0.01-0.004x_1,\\ 0.006+0.034x_1&=0.01-0.004x_1,\\ x_1&=0.004/0.038=2/19\approx0.105263,\\ x_2&=1-x_1=17/19\approx0.894737. \end{aligned} \]

ต่อไปคูณ $V$ เต็ม 3×3 กับ $x$ เพื่อหาตัวคูณของทุกข้อ $\nu$ มาจาก $u_1=0$ คือ $2(Vx)_1+\nu=0$ ส่วน variance ของพอร์ตคือ $x_1(Vx)_1+x_2(Vx)_2$ ซึ่งเท่ากับ $(Vx)_1$ เพราะสองตัวนี้เท่ากันและ $x_1+x_2=1$

\[ \begin{aligned} (Vx)_1&=0.04(0.105263)+0.006(0.894737)\\ &\approx0.0095789,\\ (Vx)_2&=0.006(0.105263)+0.01(0.894737)\\ &\approx0.0095789,\\ (Vx)_3&=0.0455(0.105263)+0.0105(0.894737)\\ &\approx0.0141842,\\ \sigma^2&=(Vx)_1\approx0.0095789,\\ \sigma&=\sqrt{0.0095789}\approx9.787\%,\\ \nu&=-2(0.0095789)=-0.0191579,\\ u_3&=2(0.0141842)-0.0191579\approx0.0092105. \end{aligned} \]

คำตอบ: $x=(10.53\%,\ 89.47\%,\ 0)$, $\nu=-0.019158$, $u=(0,\ 0,\ 0.00921)$ สอบทีละข้อ

  • ข้อ (1) ผ่าน เพราะเราสร้าง $u$ จากสูตร $u_i=2(Vx)_i+\nu$ เอง
  • ข้อ (2) ผ่าน น้ำหนักไม่ติดลบ และ $0.105263+0.894737+0=1$
  • ข้อ (3) ผ่าน $u$ ทุกตัวไม่ติดลบ
  • ข้อ (4) ผ่าน $u_ix_i=0$ ทั้งสามคู่ สองตัวแรกมี $u_i=0$ ตัวที่สามมี $x_3=0$

กฎห้าม short ของหุ้นเทคบีบ เพราะ $u_3\gt0$ ส่วนกฎของอีกสองตัวไม่บีบ

ตรวจเองใน 10 วินาที: เพราะ $\nu=-2\sigma^2$ เราเขียน $u_3$ ใหม่ได้เป็น $u_3=2[(Vx)_3-\sigma^2]=2(0.0141842-0.0095789)\approx0.00921$ ตรงกัน $(Vx)_3$ คือ covariance ของหุ้นเทคกับพอร์ต ซึ่งสูงกว่า variance ของพอร์ตเอง แปลว่าเติมหุ้นเทคจากศูนย์แล้วความเสี่ยงจะขึ้น $u_3$ จึงเป็นบวก ถ้าวันหนึ่ง $(Vx)_3$ ลดลงมาเท่ากับ $\sigma^2$ กฎห้าม short ก็จะไม่มีราคา ส่วน $\nu$ ที่ติดลบไม่ผิดกติกา เพราะเป็นตัวคูณของสมการ ซึ่งไม่ต้องผ่านข้อ (3)

ขั้นที่ 7 — u₃ คือราคาของกฎห้าม short

ขั้นที่ 1 บอกว่าถ้าถอยกำแพงไป $\varepsilon$ ค่าต่ำสุดจะลดราว $u\varepsilon$ ขั้นนี้ทดสอบคำทำนายนั้นกับพอร์ตจริง เพื่อดูว่า $u_3=0.0092105$ เป็นราคาที่เชื่อได้แค่ไหน

ทดสอบโดยยอมให้ short หุ้นเทคได้ 1% คือล็อก $x_3=-0.01$ แทน $x_3=0$ ($\varepsilon=0.01$) เงินสำหรับสองตัวที่เหลือจึงเป็น $x_1+x_2=1.01$ แล้วแก้สองตัวนั้นใหม่ด้วยลายเซ็นเดิม $(Vx)_1=(Vx)_2$ สัมประสิทธิ์มาจากแถว 1 ลบแถว 2 ของ $V$: $0.04-0.006=0.034$, $0.006-0.01=-0.004$ และ $(0.0455-0.0105)(-0.01)=-0.00035$

\[ \begin{aligned} (Vx)_1-(Vx)_2&=0.034x_1-0.004x_2-0.00035,\\ x_2=1.01-x_1:&\quad0.038x_1-0.00404-0.00035=0,\\ x_1&=0.00439/0.038\approx0.115526,\\ x&\approx(0.115526,\ 0.894474,\ -0.01),\\ \sigma^2&=x^{\mathsf T}Vx\approx0.00949399,\\ \text{drop}&=0.00957895-0.00949399\\ &\approx0.0000850,\\ u_3\varepsilon&=0.0092105(0.01)\approx0.0000921. \end{aligned} \]

variance ลดจริง 0.0000850 แต่ตัวคูณทำนายไว้ 0.0000921 คำทำนายสูงไป $0.0000921/0.0000850\approx1.084$ เท่า คือเกินราว 8.4% เพราะตัวคูณคือความชันที่จุดเดียว ส่วนค่าต่ำสุดเป็นเส้นโค้ง ยิ่งถอยกำแพง ราคาของกำแพงยิ่งลด การทำนายแบบเส้นตรงจึงเกินจริงเล็กน้อย

ตีเป็นเงินให้เห็นภาพ สมมติพอร์ตมีขนาด \$5,000 ล้าน (\$5 พันล้าน) ความผันผวนของกำไรขาดทุนต่อปี (P&L) เป็นดอลลาร์คือขนาดพอร์ตคูณความผันผวน หน่วยข้างล่างเป็นล้านดอลลาร์

\[ \begin{aligned} \sigma_{\text{before}}&=\sqrt{0.00957895}\approx9.7872\%,\\ \sigma_{\text{after}}&=\sqrt{0.00949399}\approx9.7437\%,\\ 5{,}000\times0.0978719&\approx489.36,\\ 5{,}000\times0.0974372&\approx487.19,\\ 489.36-487.19&=2.17. \end{aligned} \]

ความผันผวนลด $9.7872\%-9.7437\%=0.0435\%$ หรือ 4.35 bp ความผันผวนของ P&L จึงลดลงราว \$2.17 ล้านต่อปี จากการยอม short แค่ 1%

ต้นทุนทั้งหมดของกฎคือความผันผวน 9.787% (ห้าม short) เทียบกับ 9.634% (short ได้เต็มที่ จากขั้นที่ 4) ต่างกัน $9.787\%-9.634\%=0.153\%$ หรือ 15.3 bp ต่อปี ตัวคูณบอกราคาของการผ่อนกฎทีละนิดเท่านั้น ถ้าผ่อนเต็มที่ต้องแก้โจทย์ใหม่ทั้งหมด เพราะชุดของกฎที่บีบ (active set) อาจเปลี่ยนทั้งชุด

ขั้นที่ 8 — ข้อมูลเดิม กฎเดิม เป้าหมายใหม่: กฎไม่บีบเลย

ขั้นที่ 4 ถึง 7 สนใจแค่ความเสี่ยง ขั้นนี้ใช้ข้อมูลและกฎชุดเดิม แต่เปลี่ยนสิ่งที่กองทุนอยากได้ เพื่อดูว่ากฎข้อเดียวกันอาจไม่บีบเลยก็ได้

โจทย์ให้อะไรมาบ้าง:

  • ผลตอบแทนคาดหวังต่อปี $\mu=(12\%,\ 6\%,\ 15\%)$ สองตัวแรกเป็นตัวเลขของหุ้นกับพันธบัตรในหน้า Markowitz ตัวที่สามของหุ้นเทคเป็นตัวเลขสมมติ
  • เป้าหมายใหม่คือค่าเป้าหมาย mean-variance ของ Markowitz $J=\mu^{\mathsf T}x-\gamma\,x^{\mathsf T}Vx$ คือผลตอบแทนคาดหวังหักค่าปรับความเสี่ยง ยิ่งสูงยิ่งดี
  • $\gamma=2$ คือระดับความกลัวความเสี่ยง ยิ่ง $\gamma$ ใหญ่ ความเสี่ยงยิ่งถูกหักแรง
  • กฎเดิม คือลงเงินครบและห้าม short

รูปมาตรฐานต้องหาค่าต่ำสุด เราจึงหาค่าต่ำสุดของ $-J$ ความชันของ $-J$ คือ $-\mu+2\gamma Vx$ ข้อ (1) ของ KKT จึงให้ตัวคูณเป็น $u=2\gamma Vx-\mu+\nu\mathbf1$ ซึ่งที่ $\gamma=2$ คือ $u=4Vx-\mu+\nu\mathbf1$

ลองเดาแบบเดิมว่าหุ้นเทคเป็นศูนย์ ให้ $x=(a,\ 1-a,\ 0)$ หุ้นสหรัฐฯ กับพันธบัตรถือได้อิสระ จึง $u_1=u_2=0$ ใช้สองข้อนี้หา $a$ (ตัว $\nu$ หักล้างกันไป) จากนั้นหา $\nu$ แล้วสอบ $u_3$ สูตรของ $(Vx)_1$ และ $(Vx)_2$ มาจากขั้นที่ 6

\[ \begin{aligned} (Vx)_1&=0.006+0.034a,\\ (Vx)_2&=0.01-0.004a,\\ u_1=u_2:&\quad4(Vx)_1-0.12=4(Vx)_2-0.06,\\ &\quad0.136a-0.096=-0.016a-0.02,\\ a&=0.076/0.152=0.5,\\ Vx&=(0.023,\ 0.008,\ 0.028),\\ u_1=0:&\quad4(0.023)-0.12+\nu=0,\ \nu=0.028,\\ u_3&=4(0.028)-0.15+0.028=-0.010\lt0. \end{aligned} \]

คำตอบ: การเดานี้ตก dual เพราะ $u_3$ ติดลบ ตัวคูณติดลบแปลว่ากำแพงต้อง “ดึง” หุ้นเทคไว้ ซึ่งกำแพงทำไม่ได้ จึงควรปล่อยหุ้นเทค แก้ใหม่โดยไม่ล็อกตัวไหนเลย คือแก้ระบบสี่สมการ $u_1=u_2=u_3=0$ กับงบ (แก้ด้วยโค้ดท้ายหน้า) แล้วเทียบค่าเป้าหมายกับการเดา ซึ่งที่ $x=(0.5,\ 0.5,\ 0)$ มี $\mu^{\mathsf T}x=0.5(0.12)+0.5(0.06)=0.09$ และ $x^{\mathsf T}Vx=0.5(0.023)+0.5(0.008)=0.0155$

\[ \begin{aligned} x_{\text{free}}&\approx(0.4641,\ 0.5009,\ 0.0350),\\ J_{\text{free}}&\approx0.059175,\\ J_{\text{guess}}&=0.09-2(0.0155)=0.059. \end{aligned} \]

คำตอบใหม่มีน้ำหนักบวกทั้งสามตัว หุ้นเทคได้ 3.50% และค่าเป้าหมายสูงกว่าการเดา กฎห้าม short ไม่บีบเลย ตัวคูณเป็นศูนย์ทั้งหมด KKT จึงเหลือแค่คำตอบ Markowitz ธรรมดา

ตรวจเองใน 10 วินาที: ข้อมูลและกฎเหมือนเดิมทุกตัว แต่ชุดของกฎที่บีบคนละชุด เป้าหมายแรกสนใจแค่ความเสี่ยง หุ้นเทคผันผวนเกินไปจึงถูกเตะออก เป้าหมายที่สองให้เครดิตกับผลตอบแทน 15% ของมัน จึงคุ้มที่จะถือ อย่าถามลอย ๆ ว่ากฎนี้บีบไหม ต้องถามว่าบีบภายใต้เป้าหมายไหน

ขั้นที่ 9 — อสมการที่ไม่ใช่เส้นตรง: งบความเสี่ยง

กฎที่โต๊ะลงทุนใช้บ่อยที่สุดไม่ใช่ห้าม short แต่คือ “ความผันผวนของพอร์ตต้องไม่เกินงบ” กฎนี้เป็นอสมการที่ไม่ใช่เส้นตรง เพราะ variance คิดจากน้ำหนักคูณน้ำหนัก ขั้นนี้ดูว่า KKT ยังใช้ได้ และตัวคูณของกฎนี้บอกอะไร

ของที่รู้:

  • สินทรัพย์สองตัวจากหน้า Markowitz คือหุ้น (ผลตอบแทนคาดหวัง 12% ความผันผวน 20%) และพันธบัตร (6% และ 10%) correlation 0.30 $V$ จึงเป็น 2×2 มุมซ้ายบนของ $V$ ในขั้นที่ 4 คือ $V_{11}=0.04$, $V_{12}=0.006$, $V_{22}=0.01$
  • เงินสดให้ผลตอบแทน 2% แน่นอน ไม่มีความเสี่ยง เงินที่ไม่ได้ลงในหุ้นกับพันธบัตรเก็บเป็นเงินสด จึงไม่มีกฎลงเงินครบ
  • ผลตอบแทนส่วนเกิน คือผลตอบแทนที่ได้เกินเงินสด $e=(12\%-2\%,\ 6\%-2\%)=(10\%,\ 4\%)$
  • งบความผันผวน $\bar\sigma=10\%$ ต่อปี

เป้าหมายคือทำผลตอบแทนส่วนเกินของพอร์ต $e^{\mathsf T}x$ ให้สูงที่สุด โดยความผันผวนไม่เกินงบ ในรูปมาตรฐานคือหาค่าต่ำสุดของ $-e^{\mathsf T}x$ โดย $g=x^{\mathsf T}Vx-\bar\sigma^2\le0$ ตัวคูณของกฎนี้เรียก $\lambda$

ก่อนอื่นต้องมี $V^{-1}e$ เพราะมันจะโผล่ในคำตอบ $V$ ขนาด 2×2 กลับได้ด้วยมือ คือสลับช่องทแยง กลับเครื่องหมายช่องนอกทแยง แล้วหารด้วย determinant

\[ \begin{aligned} \det V&=0.04(0.01)-0.006^2=0.000364,\\ (V^{-1}e)_1&=\frac{0.01(0.10)-0.006(0.04)}{0.000364}\approx2.0879,\\ (V^{-1}e)_2&=\frac{-0.006(0.10)+0.04(0.04)}{0.000364}\approx2.7473,\\ e^{\mathsf T}V^{-1}e&=0.10(2.0879)+0.04(2.7473)\approx0.31868,\\ \mathrm{SR}&=\sqrt{0.31868}\approx0.5645. \end{aligned} \]

$\mathrm{SR}$ คือ Sharpe ratio (ผลตอบแทนส่วนเกินหารด้วยความผันผวน) ที่ดีที่สุดที่ผสมได้จากสองสินทรัพย์นี้ เป็นตัวเลขเดียวกับของ tangency portfolio ในหน้า Markowitz ต่อไปเขียน KKT ข้อ (1) และ (4) แล้วแก้หา $\lambda$ กับ $x$

\[ \begin{aligned} \text{(1)}&\quad-e+2\lambda Vx=0\ \Rightarrow\ x=\frac{V^{-1}e}{2\lambda},\\ \text{(4)}&\quad\lambda\,(x^{\mathsf T}Vx-\bar\sigma^2)=0,\\ \lambda\gt0:&\quad\frac{e^{\mathsf T}V^{-1}e}{4\lambda^2}=\bar\sigma^2,\\ \lambda&=\frac{\sqrt{e^{\mathsf T}V^{-1}e}}{2\bar\sigma}=\frac{\mathrm{SR}}{2\bar\sigma}=\frac{0.5645}{0.20}\\ &\approx2.8226,\\ x&=\frac{V^{-1}e}{2\lambda}=\frac{(2.0879,\ 2.7473)}{5.6452}\\ &\approx(0.369857,\ 0.486654),\\ e^{\mathsf T}x&=\frac{e^{\mathsf T}V^{-1}e}{2\lambda}=\mathrm{SR}\cdot\bar\sigma\\ &=0.5645\times10\%\approx5.645\%. \end{aligned} \]

ข้อ (1) ให้ทิศของพอร์ตทันที คือ $V^{-1}e$ ซึ่งเป็นทิศเดียวกับ tangency portfolio ส่วน $\lambda$ คุมแค่ขนาด แถว $\lambda\gt0$ ได้จากการแทน $x$ ลงใน $x^{\mathsf T}Vx=\bar\sigma^2$ ตัว $V$ ตรงกลางหักล้างกับ $V^{-1}$ หนึ่งตัว จึงเหลือ $e^{\mathsf T}V^{-1}e$ ข้อ (4) บอกว่ามีสองทาง ทางแรกคือ $\lambda=0$ แต่ข้อ (1) จะเหลือ $e=0$ ซึ่งเป็นไปไม่ได้เมื่อมีสินทรัพย์ที่ให้ผลตอบแทนเกินเงินสด จึงเหลือทางเดียว คือกฎชนขอบพอดี งบความเสี่ยงจึงบีบเสมอ ใครมี edge (ผลตอบแทนคาดหวังเกินเงินสด) ก็ใช้งบความเสี่ยงจนหมด

พอร์ตที่ได้คือหุ้น 36.99% พันธบัตร 48.67% และเงินสด $1-0.369857-0.486654\approx14.35\%$ ได้ผลตอบแทนส่วนเกิน 5.645% ต่อปี

$\lambda$ คือราคาของ variance หนึ่งหน่วย ลองทดสอบโดยขยายงบ variance $\bar\sigma^2$ จาก 0.0100 เป็น 0.0101 แล้วดูว่าผลตอบแทนส่วนเกิน $\mathrm{SR}\cdot\bar\sigma$ เพิ่มเท่าไร

function covariance(sd, corr) {
  if (!sd.every(s => Number.isFinite(s) && s > 0)) throw new RangeError('Volatilities must be positive');
  corr.forEach((r, i) => r.forEach((c, j) => {
    if (!Number.isFinite(c) || Math.abs(c) > 1 || c !== corr[j][i] || (i === j && c !== 1)) throw new RangeError('Invalid correlation matrix');
  }));
  return corr.map((r, i) => r.map((c, j) => c * sd[i] * sd[j]));
}
function solveLinear(A, b) {
  const n = A.length, M = A.map((r, i) => [...r, b[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (Math.abs(M[r][c]) > Math.abs(M[p][c])) p = r;
    if (Math.abs(M[p][c]) < 1e-14) throw new RangeError('Singular system: active set not solvable');
    [M[c], M[p]] = [M[p], M[c]];
    for (let r = 0; r < n; r++) { if (r === c) continue; const f = M[r][c] / M[c][c]; for (let k = c; k <= n; k++) M[r][k] -= f * M[c][k]; }
  }
  return M.map((r, i) => r[n] / r[i]);
}
const times = (V, x) => V.map(r => r.reduce((s, v, j) => s + v * x[j], 0));
// Minimise gamma x'Vx - mu'x with sum x = total; assets outside `free` are held at `fixed` (default 0).
// Returns weights, budget multiplier nu and bound multipliers u = 2 gamma Vx - mu + nu 1.
function solveActiveSet(V, free, {mu = V.map(() => 0), gamma = 1, total = 1, fixed = {}} = {}) {
  const x = V.map((_, i) => fixed[i] ?? 0), m = free.length, rows = [];
  free.forEach(i => rows.push([...free.map(j => 2 * gamma * V[i][j]), 1]));
  rows.push([...free.map(() => 1), 0]);
  const rhs = free.map(i => mu[i] - 2 * gamma * V[i].reduce((s, v, j) => s + (free.includes(j) ? 0 : v * x[j]), 0));
  rhs.push(total - x.reduce((s, v, j) => s + (free.includes(j) ? 0 : v), 0));
  const sol = solveLinear(rows, rhs);
  free.forEach((i, a) => { x[i] = sol[a]; });
  const nu = sol[m], Vx = times(V, x), variance = x.reduce((s, v, i) => s + v * Vx[i], 0);
  const u = Vx.map((v, i) => 2 * gamma * v - mu[i] + nu);
  return {x, nu, u, Vx, variance, sd: Math.sqrt(variance), J: mu.reduce((s, v, i) => s + v * x[i], 0) - gamma * variance};
}

  return {primal: r.x.every(v => v >= -tol) && Math.abs(r.x.reduce((s, v) => s + v, 0) - 1) <= tol,
    dual: r.u.every(v => v >= -tol), complementary: r.u.every((v, i) => Math.abs(v * r.x[i]) <= tol)};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ที่กำแพง ความชันในทิศที่เข้าเขตต้องไม่ติดลบ ตัวคูณของอสมการจึงต้อง $u\ge0$ และ $u$ คูณระยะห่างจากขอบต้องได้ศูนย์ กำแพงที่ไม่แตะคำตอบจึงไม่ดัน
  • KKT มีสี่ข้อ คือความชันหักล้างกันพอดี ทำตามกฎ ตัวคูณไม่ติดลบ และ complementary slackness เมื่อโจทย์ convex สี่ข้อนี้พอจะบอกว่าเป็นคำตอบที่ดีที่สุด ที่คำตอบ ทางลงเขาต้องชี้ออกนอกเขต ตั้งฉากกับกำแพงที่ชน
  • พอร์ต long-only ความเสี่ยงต่ำสุดของหน้านี้คือ 10.53% / 89.47% / 0 ที่ความผันผวน 9.787% ตัวคูณของกฎห้าม short หุ้นเทคคือ $u_3=0.00921$ กฎทั้งชุดมีราคา 15.3 bp ส่วนการตัดแล้วขยายเสียความเสี่ยงฟรีอีก 6.0 bp
  • กฎเดียวกันบีบหรือไม่บีบขึ้นกับเป้าหมาย พอเป้าหมายเป็น mean-variance กองทุนถือหุ้นเทค 3.50% โดยกฎไม่บีบ และน้ำหนักหุ้นเทคหักมุมที่ผลตอบแทนคาดหวัง 14%
  • งบความเสี่ยงบีบเสมอเมื่อมี edge ราคาของมันคือ $\lambda=\mathrm{SR}/(2\bar\sigma)=2.82$ ที่งบ 10% และ $\lambda$ นี้คือ $\gamma$ ของแบบหักค่าปรับที่ให้พอร์ตเดียวกัน
