3.2 The Central Limit Theorem

ค่าเฉลี่ยของข้อมูลอิสระจำนวนมากมีรูปร่างเกือบเป็นระฆัง normal เสมอ ไม่ว่าข้อมูลรายตัวจะหน้าตาแบบไหน เราจึงบอกได้ว่าค่าเฉลี่ยที่เห็นหายากแค่ไหน

กองทุนบำนาญแห่งหนึ่งกำลังเลือกว่าจะจ้างผู้จัดการกองทุนคนหนึ่งมาดูแลเงินดีไหม คนที่ตัดสินเรื่องนี้คือทีมคัดเลือกกองทุน ผู้จัดการคนนี้คิดค่าจ้างแพง ส่วนทางเลือกราคาถูกคือซื้อกองทุนดัชนี ซึ่งถือหุ้นตามดัชนี (index) เช่น S&P 500 ดัชนีคือตะกร้าหุ้นที่แทนทั้งตลาด การจ้างเขาจึงคุ้มก็ต่อเมื่อเขาชนะดัชนีได้ด้วยฝีมือ ไม่ใช่ด้วยโชค

ของที่รู้ (ตัวเลขสมมติ):

  • ประวัติของเขายาว $n=4$ ปี
  • ทุกปีเราวัดส่วนต่าง คือผลตอบแทนกองทุนของเขาลบผลตอบแทนดัชนี ส่วนต่างเฉลี่ยสี่ปีคือ $\bar X_4=3\%$ ต่อปี
  • ส่วนต่างแต่ละปีแกว่งขึ้นลงไม่เท่ากัน ขนาดการแกว่งวัดด้วย SD (standard deviation) คือระยะที่ตัวเลขมักห่างจากค่าเฉลี่ยตามปกติ สมมติว่ารู้จากแหล่งอื่นว่า $\sigma=6\%$ ต่อปี

ลองสมมติว่าเขาไม่มีฝีมือเลย คือถ้าดูไปนาน ๆ ส่วนต่างเฉลี่ยจริงของเขาเป็นศูนย์ และที่ดูดีเพราะโชคล้วน ๆ คำถามคือ ผลงานดีอย่างน้อยเท่านี้เกิดจากโชคได้บ่อยแค่ไหน

ลองตอบก่อนเปิดเฉลย

บ่อยกว่าที่คิดมาก ค่าเฉลี่ยสี่ปีคลาดจากค่าจริงได้ราวหนึ่ง SE (standard error) กฎจำนวนมาก หาไว้ว่า $\mathrm{SE}=\sigma/\sqrt n$ ถ้าค่าเฉลี่ยมีรูปร่างแบบ normal (ระฆัง) ซึ่งหน้านี้จะอธิบายว่าทำไม เราแปลงเป็นโอกาสได้ดังนี้

\[\begin{aligned}\mathrm{SE}&=6\%/\sqrt4=3\%,\\z&=(3\%-0)/3\%=1,\\P&=1-\Phi(1)\approx15.87\%.\end{aligned}\]

$z$ บอกว่าผล 3% ห่างจากศูนย์กี่ SE คำตอบคือแค่หนึ่ง SE ส่วน $\Phi(z)$ คือโอกาสที่ตัวแปร normal มาตรฐาน (ค่าเฉลี่ยศูนย์ SD หนึ่ง) ไม่เกิน $z$ เปิดตาราง normal ได้ $\Phi(1)\approx0.8413$

ดังนั้นในผู้จัดการไร้ฝีมือ 100 คน คาดว่า $100\times15.87\%\approx16$ คนจะมีประวัติสี่ปีที่ดูดีแบบนี้

ภาพรวมก่อนลงสูตร

หน้าที่แล้ว กฎจำนวนมาก ให้ของมาสองอย่าง ค่าเฉลี่ยของข้อมูลจำนวนมากวิ่งเข้าหาค่าจริง และมันคลาดจากค่าจริงได้ราว $\sigma/\sqrt n$ ซึ่งเรียกว่า SE

แต่ขนาดของความคลาดอย่างเดียวยังตอบคำถามกองทุนไม่ได้ รู้ว่าค่าเฉลี่ยสี่ปี “มักคลาดราว 3%” ไม่ได้บอกว่ามันจะสูงกว่าค่าจริงเกิน 3% บ่อยแค่ไหน คำตอบขึ้นกับรูปร่างของการแจกแจงของค่าเฉลี่ย ถ้ารูปร่างเป็นระฆัง normal จะได้ราว 16% อย่างที่เฉลยข้างบนคำนวณไว้ ถ้าเป็นรูปอื่นก็ได้ตัวเลขอื่น

central limit theorem (CLT) บอกรูปร่างนั้น เมื่อเราบวกชิ้นส่วนที่อิสระกันจำนวนมากเข้าด้วยกัน ผลรวมหรือค่าเฉลี่ยจะมีรูปร่างเข้าใกล้ normal เงื่อนไขสำคัญคือแต่ละชิ้นต้องมี variance (SD ยกกำลังสอง) ที่ไม่เป็นอนันต์ นอกจากนั้นแต่ละชิ้นจะแบน เบ้ หรือเป็นขั้นบันไดก็ได้

ทำไมจึงเป็นระฆัง เพราะผลรวมค่ากลาง ๆ เกิดได้หลายทาง ส่วนผลรวมค่าสุดขั้วต้องให้ทุกชิ้นสุดขั้วไปทางเดียวกันพร้อมกัน ซึ่งเกิดได้น้อยทาง

หน้านี้จะไปทีละขั้น นับลูกเต๋าให้เห็นระฆังเกิดขึ้นจริง อธิบายว่าทำไมต้องเป็น normal แล้วใช้มันตอบคำถามกองทุน ต่อด้วยการคำนวณว่าต้องดูประวัติกี่ปีจึงเห็นฝีมือ สุดท้ายดูสองกรณีที่ CLT ช่วยได้น้อยกว่าที่คิด คือหาง (ส่วนปลายของการแจกแจงที่เป็นเหตุการณ์หายาก) ของข้อมูลที่เบ้ และข้อมูลที่ปีติดกันสัมพันธ์กัน

ศัพท์ที่ใช้ในหน้านี้
i.i.d.
ย่อมาจาก independent and identically distributed ข้อมูลแต่ละตัวอิสระกัน (รู้ตัวหนึ่งแล้วไม่ได้รู้อะไรเพิ่มเกี่ยวกับตัวอื่น) และมาจากการแจกแจงเดียวกัน เช่นลูกเต๋าที่โยนซ้ำ
SE (standard error)
SD ของค่าเฉลี่ย บอกว่าค่าเฉลี่ยที่คำนวณจากข้อมูลมักคลาดจากค่าจริงเท่าไร สำหรับข้อมูล i.i.d. $n$ ตัว $\mathrm{SE}=\sigma/\sqrt n$
Sampling distribution
ถ้าเก็บข้อมูลชุดใหม่จากกลไกเดิมซ้ำหลายครั้ง แล้วคำนวณค่าเฉลี่ยทุกครั้ง ค่าเฉลี่ยจะออกมาไม่เท่ากัน การแจกแจงของค่าเฉลี่ยเหล่านั้นคือ sampling distribution เราใช้มันตอบว่า “ค่าเฉลี่ยที่เห็นหายากแค่ไหน”
Standardize (z-score)
ลบค่าเฉลี่ยแล้วหารด้วย SD คือ $z=(x-\mu)/\sigma$ ผลที่ได้บอกว่า $x$ ห่างจากค่าเฉลี่ยกี่ SD ทุกปัญหาจึงเทียบกับ normal มาตรฐานตัวเดียว (ค่าเฉลี่ยศูนย์ SD หนึ่ง) ได้
หาง (tail)
ส่วนปลายของการแจกแจง คือค่าที่ไกลจากค่าเฉลี่ยและเกิดไม่บ่อย หางหนาแปลว่าค่าสุดขั้วเกิดบ่อยกว่าที่ normal บอก
Continuity correction
เมื่อใช้โค้งต่อเนื่องประมาณตัวแปรที่เป็นจำนวนเต็ม แต่ละค่าจะเป็นแท่งกว้างหนึ่งหน่วย เช่นค่า 20 กินพื้นที่ 19.5 ถึง 20.5 เราจึงเลื่อนขอบไปครึ่งหน่วย เพื่อให้แท่งที่ขอบถูกนับครบ
MGF
moment generating function $M_X(t)=\mathbb E[e^{tX}]$ คือค่าเฉลี่ยของ $e^{tX}$ มองเป็นฟังก์ชันของ $t$ ข้อดีคือมันเปลี่ยนผลรวมของตัวแปรอิสระเป็นผลคูณ จึงใช้พิสูจน์ CLT แบบสั้นได้
Skewness
ความเบ้ $\gamma=\mathbb E[(X-\mu)^3]/\sigma^3$ บอกว่าหางข้างไหนยาวกว่า ศูนย์คือสมมาตร บวกคือหางขวายาว เราใช้มันดูว่า normal จะประมาณหางผิดไปทางไหน
Active return และ information ratio (IR)
active return คือผลตอบแทนพอร์ตลบผลตอบแทนดัชนีที่ใช้เทียบ IR คือค่าเฉลี่ยของ active return หารด้วย SD ของมัน IR สูงแปลว่าชนะดัชนีได้มาก เมื่อเทียบกับขนาดที่ผลงานแกว่งห่างจากดัชนี

ขั้นที่ 1 — ค่าเฉลี่ยมีการแจกแจงของมันเอง

จะตอบว่า “ผลแบบนี้หายากแค่ไหน” ต้องมีภาพของผลทั้งหมดที่อาจเกิดได้ก่อน ประวัติสี่ปีที่เห็นเป็นแค่หนึ่งชุด ถ้าย้อนเวลาไปเล่นสี่ปีนั้นใหม่ โชคจะออกไม่เหมือนเดิม ค่าเฉลี่ยก็จะไม่เท่าเดิม การแจกแจงของค่าเฉลี่ยจากการเล่นซ้ำแบบนี้เรียกว่า sampling distribution

สมมติว่า $X_1,\dots,X_n$ เป็น i.i.d. คือแต่ละปีอิสระกันและมาจากการแจกแจงเดียวกัน มีค่าเฉลี่ย $\mu$ และ variance $\sigma^2$ ที่มากกว่าศูนย์และไม่เป็นอนันต์ ($0\lt\sigma^2\lt\infty$) ค่าเฉลี่ยของ $n$ ปีคือ $\bar X_n=(X_1+\cdots+X_n)/n$

ค่าเฉลี่ยของแต่ละปัญหามีหน่วยและขนาดต่างกัน เราจึง standardize ก่อน คือลบค่าเฉลี่ยจริงแล้วหารด้วย SE ทุกปัญหาจะได้วัดบนไม้บรรทัดเดียวกัน ในสูตรข้างล่าง $\mathcal N(m,v)$ คือ normal ที่มีค่าเฉลี่ย $m$ และ variance $v$

\[\begin{aligned} Z_n&=\frac{\bar X_n-\mu}{\sigma/\sqrt n},\\ \mathbb E[Z_n]&=0,\qquad \operatorname{Var}(Z_n)=1,\\ P(Z_n\le z)&\ \longrightarrow\ \Phi(z),\\ \bar X_n&\approx\mathcal N\!\left(\mu,\ \frac{\sigma^2}{n}\right). \end{aligned}\]

การ standardize เองไม่ต้องใช้ CLT เลย ค่าเฉลี่ยศูนย์และ variance หนึ่งของ $Z_n$ จริงทุก $n$ เพราะ กฎจำนวนมาก หาไว้แล้วว่า $\bar X_n$ มีค่าเฉลี่ย $\mu$ และ SE $\sigma/\sqrt n$ การลบ $\mu$ ย้ายจุดกลางมาที่ศูนย์ การหารด้วย SE ทำให้ความกว้างเป็นหนึ่ง

สิ่งใหม่ที่ CLT ให้คือรูปร่าง ลูกศร $\longrightarrow$ อ่านว่า เมื่อ $n$ โตขึ้น โอกาสที่ $Z_n$ ไม่เกิน $z$ เข้าใกล้ $\Phi(z)$ ของ normal distribution มาตรฐาน พอแปลงกลับเป็นค่าเฉลี่ย จึงได้ว่า $\bar X_n$ เป็นระฆังที่มีจุดกลางอยู่ที่ $\mu$ และกว้าง $\sigma/\sqrt n$

เครื่องหมาย $\approx$ สำคัญ มันเป็นการประมาณที่ดีขึ้นเมื่อ $n$ โต ไม่ได้เท่ากันพอดีทุก $n$ และไม่มีเกณฑ์สากลว่า “30 ตัวพอเสมอ” ถ้า $X_i$ เป็น normal อยู่แล้ว ค่าเฉลี่ยก็เป็น normal พอดีทุก $n$ แต่ถ้า $X_i$ เบ้หรือหางหนามาก 30 ตัวอาจยังประมาณหางได้แย่ ขั้นที่ 6 จะวัดให้ดูว่าแย่แค่ไหน

ขั้นที่ 2 — นับลูกเต๋าให้เห็นระฆังเกิดขึ้นจริง

ก่อนเชื่อ CLT กับเงินจริง ลองกับของที่นับคำตอบจริงได้ครบทุกแบบก่อน ลูกเต๋าเหมาะที่สุด เพราะเรานับได้ว่าคำตอบที่ถูกคือเท่าไร แล้วดูว่า normal ประมาณได้ใกล้แค่ไหน

โจทย์ให้อะไรมาบ้าง:

  • ลูกเต๋ายุติธรรมสี่ลูก โยนอิสระกัน แต่ละลูกออกหน้า 1 ถึง 6 ด้วยโอกาสเท่ากัน หน้าละ $1/6$
  • $S_4$ คือผลรวมแต้มของสี่ลูก
  • คำถาม: โอกาสที่ $S_4\ge20$ เป็นเท่าไร นับให้ตรงก่อน แล้วเทียบกับคำตอบจาก normal

เริ่มจากสองลูกเพื่อดูว่าระฆังเกิดอย่างไร สองลูกออกได้ $6\times6=36$ แบบ ผลรวม 2 ต้องได้ 1 ทั้งคู่ จึงมีแบบเดียว ผลรวม 7 มีหกแบบ (1+6, 2+5, 3+4, 4+3, 5+2, 6+1) นับครบทุกผลรวมตั้งแต่ 2 ถึง 12 ได้ 1, 2, 3, 4, 5, 6, 5, 4, 3, 2, 1 แบบ ค่ากลาง ๆ ประกอบได้หลายทาง ค่าสุดขั้วมีทางเดียว นี่คือสามเหลี่ยมในรูปผลรวมลูกเต๋าข้างบน

สี่ลูกออกได้ $6^4=1{,}296$ แบบ โค้ดท้ายหน้านับให้ทุกผลรวม ผลรวม 14 มีมากที่สุด 146 แบบ ส่วนผลรวม 4 และ 24 มีอย่างละแบบเดียว

ผลรวม 20 ถึง 24 ที่โจทย์ถาม เรานับด้วยมือได้โดยใช้สองเคล็ด ให้ $N(s)$ คือจำนวนแบบที่ผลรวมออกมาเป็น $s$

  • เคล็ดแรก พลิกลูกเต๋าทุกลูกกลับหัว หน้า $x$ จะกลายเป็นหน้า $7-x$ ผลรวม $s$ จึงกลายเป็น $28-s$ ดังนั้น $N(s)=N(28-s)$ ผลรวมใหญ่จึงนับผ่านผลรวมเล็กได้
  • เคล็ดที่สอง ผลรวมเล็กนับง่าย ทุกลูกได้อย่างน้อย 1 แต้มอยู่แล้ว ผลรวม $s$ จึงเหลือแต้มส่วนเกิน $m=s-4$ แต้มให้แจกสี่ลูก ลองวางแต้ม $m$ อันกับไม้กั้น 3 อันเรียงเป็นแถวยาว $m+3$ ช่อง ไม้กั้นแบ่งแถวเป็นสี่กอง กองละลูก การเลือกว่าไม้กั้นอยู่ช่องไหนจึงมี $\binom{m+3}{3}$ แบบ (เมื่อ $m\le5$ ไม่มีลูกไหนเกิน 6 แต้ม)
\[\begin{aligned}N(20)&=N(8)=\tbinom{7}{3}=35,\\N(21)&=N(7)=\tbinom{6}{3}=20,\\N(22)&=N(6)=\tbinom{5}{3}=10,\\N(23)&=N(5)=\tbinom{4}{3}=4,\\N(24)&=N(4)=\tbinom{3}{3}=1.\end{aligned}\]

รวมหางขวาได้ $35+20+10+4+1=70$ แบบ คำตอบที่ถูกจึงเป็น $70/1{,}296$

ต่อไปต้องวางโค้ง normal ให้ตรงตำแหน่ง จึงต้องรู้ค่าเฉลี่ยและ SD ของ $S_4$ เริ่มจากลูกเดียว ให้ $X$ คือแต้มของลูกเดียว variance คือค่าเฉลี่ยของกำลังสอง ลบด้วยกำลังสองของค่าเฉลี่ย สี่ลูกอิสระกัน variance ของผลรวมจึงเป็นสี่เท่าของลูกเดียว (variance ของตัวแปรอิสระบวกกันได้ตรง ๆ ตามที่ กฎจำนวนมาก ใช้)

\[\begin{aligned}\mu&=\tfrac{1+2+3+4+5+6}{6}=\tfrac{21}{6}=3.5,\\\mathbb E[X^2]&=\tfrac{1+4+9+16+25+36}{6}=\tfrac{91}{6},\\\sigma^2&=\tfrac{91}{6}-3.5^2=\tfrac{35}{12},\\\mathbb E[S_4]&=4\times3.5=14,\\\operatorname{Var}(S_4)&=4\times\tfrac{35}{12}=\tfrac{35}{3},\\\operatorname{SD}(S_4)&=\sqrt{35/3}\approx3.416.\end{aligned}\]

เหลืออีกเรื่องเดียว ผลรวมเป็นจำนวนเต็ม ในรูปแท่ง ค่า 20 คือแท่งกว้างหนึ่งหน่วย ตั้งแต่ 19.5 ถึง 20.5 ถ้าจะให้พื้นที่ใต้โค้ง normal ครอบแท่งนี้ครบ ต้องเริ่มนับที่ 19.5 ไม่ใช่ 20 การเลื่อนขอบครึ่งหน่วยนี้เรียกว่า continuity correction

\[\begin{aligned}P(S_4\ge20)&=\tfrac{70}{1{,}296}\approx5.401\%,\\z&=\tfrac{19.5-14}{3.416}\approx1.610,\\P(S_4\ge20)&\approx1-\Phi(1.610)\approx5.367\%.\end{aligned}\]

คำตอบ: นับตรงได้ 5.401% normal ให้ 5.367% ต่างกันแค่ $5.401-5.367=0.034$ จุด ทั้งที่ลูกเต๋าลูกเดียวเป็นแท่งแบนราบที่ไม่เหมือนระฆังเลย และบวกกันแค่สี่ลูก

ถ้าลืม continuity correction แล้วตั้งขอบที่ 20 จะตัดครึ่งแท่งของค่า 20 ทิ้ง และได้ $1-\Phi\big((20-14)/3.416\big)=1-\Phi(1.757)\approx3.95\%$ ซึ่งต่ำกว่าคำตอบจริงไป $(5.401-3.95)/5.401\approx27\%$ ของคำตอบ

ตรวจเองใน 10 วินาที: $(19.5-14)/3.416\approx1.61$ เปิดตาราง normal ได้ $1-\Phi(1.61)\approx5.37\%$ ใกล้กับ $70/1{,}296$ ที่นับได้

ขั้นที่ 3 — ทำไมต้องเป็น normal: พจน์กำลังสองชนะทุกพจน์

ลูกเต๋าแสดงว่าระฆังเกิดขึ้นจริง แต่ยังไม่บอกว่าทำไมต้องเป็น normal ไม่ใช่รูปอื่น ขั้นนี้ตอบคำถามนั้น

เริ่มจาก standardize ข้อมูลแต่ละตัว ให้ $Y_i=(X_i-\mu)/\sigma$ ซึ่งมีค่าเฉลี่ยศูนย์และ variance หนึ่ง เครื่องมือที่ใช้คือ MGF $M_Y(t)=\mathbb E[e^{tY}]$ คือค่าเฉลี่ยของ $e^{tY}$ มองเป็นฟังก์ชันของ $t$

ทำไมต้อง MGF เหตุผลมีสองข้อ ข้อแรก $e^{a+b}=e^ae^b$ ผลรวมในเลขชี้กำลังจึงกลายเป็นผลคูณ และถ้าตัวแปรอิสระกัน ค่าเฉลี่ยของผลคูณเท่ากับผลคูณของค่าเฉลี่ย ข้อสอง ถ้า MGF ของสองการแจกแจงเท่ากัน การแจกแจงก็เท่ากัน ดังนั้นถ้าเราแสดงได้ว่า MGF ของ $Z_n$ เข้าใกล้ MGF ของ normal ก็แปลว่ารูปร่างของ $Z_n$ เข้าใกล้ normal บทพิสูจน์ย่อนี้สมมติเพิ่มว่า MGF ของ $Y$ มีค่าจำกัดเมื่อ $t$ อยู่ใกล้ศูนย์

ในสูตรข้างล่าง MGF ของตัวเดียวใช้ตัวแปร $s$ เพื่อไม่ให้ปนกับ $t$ ของ $Z_n$ เพราะเดี๋ยวเราจะแทน $s=t/\sqrt n$

\[\begin{aligned} M_Y(s)&=1+s\,\mathbb E[Y]+\tfrac{s^2}{2}\mathbb E[Y^2]+\cdots\\ &=1+\tfrac{s^2}{2}+\cdots,\\ Z_n&=\frac{Y_1+\cdots+Y_n}{\sqrt n},\\ M_{Z_n}(t)&=\left[M_Y\!\left(\tfrac{t}{\sqrt n}\right)\right]^n\\ &=\left[1+\tfrac{t^2}{2n}+\cdots\right]^n\ \longrightarrow\ e^{t^2/2}. \end{aligned}\]

ใจความคือ หลัง standardize แล้ว ทุกการแจกแจงหน้าตาเหมือนกันจนถึงพจน์กำลังสอง ความต่างของแต่ละการแจกแจงซ่อนอยู่ในพจน์ที่สูงกว่า และพจน์เหล่านั้นจางหายเมื่อบวกกันหลายตัว

$1+s^2/2$ มาจากการกระจาย $e^{sY}=1+sY+\tfrac{s^2}{2}Y^2+\cdots$ แบบ Taylor แล้วหาค่าเฉลี่ยทีละพจน์ พจน์ของ $s$ หายเพราะ $\mathbb E[Y]=0$ พจน์ของ $s^2$ เหลือ $s^2/2$ เพราะ $\mathbb E[Y^2]=1$ ส่วน $\cdots$ คือพจน์ตั้งแต่ $s^3$ ขึ้นไป ซึ่งเป็นที่อยู่ของ skewness และรูปร่างเฉพาะตัวอื่น ๆ

MGF ของ $Z_n$ มาจากความอิสระ เพราะ $e^{tZ_n}=e^{tY_1/\sqrt n}\cdots e^{tY_n/\sqrt n}$ และค่าเฉลี่ยของผลคูณของตัวแปรอิสระเท่ากับผลคูณของค่าเฉลี่ย จึงได้ MGF ของตัวเดียวที่ $s=t/\sqrt n$ คูณกัน $n$ ครั้ง

จุดที่คนส่วนใหญ่สะดุดคือ ทำไมทิ้งพจน์ที่สูงกว่าได้ ให้ดูขนาด พจน์กำลังสองมีขนาด $t^2/(2n)$ ต่อตัว สะสม $n$ ตัวแล้วเหลือค่าคงที่ $t^2/2$ พจน์กำลังสามมีขนาดราว $(t/\sqrt n)^3$ ต่อตัว คือราว $n^{-3/2}$ สะสม $n$ ตัวแล้วเหลือแค่ราว $n^{-1/2}$ ซึ่งหายไปเมื่อ $n$ โต สุดท้ายลิมิต $(1+a/n)^n\to e^a$ กับ $a=t^2/2$ ให้ $e^{t^2/2}$ ซึ่งคือ MGF ของ normal มาตรฐาน

ลองดูตัวเลขจริงที่ $t=1$ และ $n=10$ ถ้าตัดพจน์ที่สูงกว่าทิ้ง จะได้ $\left(1+\tfrac{1}{2\times10}\right)^{10}=1.05^{10}\approx1.6289$ ซึ่งใกล้ $e^{1/2}\approx1.6487$ แล้ว

ฉบับเต็มของ CLT ใช้ characteristic function $\mathbb E[e^{itY}]$ แทน MGF ฟังก์ชันนี้มีค่าเสมอ เพราะ $|e^{itY}|=1$ ส่วน MGF บางทีไม่มีค่า เช่น lognormal มี variance จำกัด แต่ MGF เป็นอนันต์ทุก $t\gt0$

ขั้นที่ 4 — กลับมาที่กองทุน: สี่ปีบอกอะไรได้จริง

ตอนนี้เรามีของครบสำหรับคำถามเปิดหน้าแล้ว ขนาดความคลาดมาจากกฎจำนวนมาก และรูปร่างระฆังมาจาก CLT ส่วนต่างรายปีระหว่างกองทุนกับดัชนีเรียกว่า active return

โจทย์ให้อะไรมาบ้าง:

  • ประวัติ $n=4$ ปี
  • ค่าเฉลี่ย active return ที่เห็น $\bar X_4=0.03$ คือ 3% ต่อปี
  • SD ของ active return รายปี $\sigma=0.06$ คือ 6% สมมติว่ารู้จากแหล่งอื่น ไม่ได้ประมาณจากสี่ปีนี้
  • active return แต่ละปีอิสระกันและเป็น normal สี่ปีน้อยเกินกว่าจะพึ่ง CLT ได้เต็มที่ เราจึงสมมติ normal ตรง ๆ ค่าเฉลี่ยของ normal ที่อิสระกันเป็น normal พอดีทุก $n$
  • สมมติว่าเขาไร้ฝีมือ คือค่าเฉลี่ยจริง $\mu=0$

คำถาม: ถ้า $\mu=0$ โอกาสที่ค่าเฉลี่ยสี่ปีได้อย่างน้อย 3% เป็นเท่าไร เราหา SE แล้วนับว่า 3% ห่างจากศูนย์กี่ SE

\[\begin{aligned} \mathrm{SE}&=\frac{0.06}{\sqrt4}=0.03,\\ z&=\frac{0.03-0}{0.03}=1,\\ P_{\mu=0}(\bar X_4\ge0.03)&=1-\Phi(1)\approx15.87\%. \end{aligned}\]

คำตอบ: 15.87% ผล 3% ห่างจากศูนย์แค่หนึ่ง SE ในผู้จัดการไร้ฝีมือ 100 คน คาดว่า $100\times15.87\%\approx15.9$ คนจะได้ผลระดับนี้หรือดีกว่า

ระวังอ่านกลับด้าน 15.87% คือโอกาสที่จะเห็นผลแบบนี้ เมื่อสมมติว่าเขาไร้ฝีมือ ไม่ใช่โอกาสที่เขาไร้ฝีมือ สองอย่างนี้ต่างกันมาก และจะกลับมาอีกครั้งในหน้า การทดสอบสมมติฐาน

ถ้า SD 6% ไม่ได้รู้จากที่อื่น แต่ประมาณจากสี่ปีเดียวกันนี้ ตัว SD เองก็คลาดได้อีกชั้นหนึ่ง เราต้องเปลี่ยนจาก normal เป็น Student $t$ ที่มี df (degrees of freedom) $=n-1=3$ การแจกแจงนี้หางหนากว่า normal โอกาสจึงเพิ่มเป็น $P(t_3\ge1)\approx19.55\%$ (โค้ดท้ายหน้าคำนวณให้ ส่วนหน้า confidence interval อธิบายว่าทำไมต้องใช้ $t$)

ขั้นที่ 5 — แปลงคุณภาพเป็นจำนวนปีที่ต้องรอ

ทีมคัดเลือกกองทุนถามกลับด้านด้วย ถ้าผู้จัดการมีฝีมือจริง ต้องดูประวัติกี่ปีจึงแยกเขาออกจากคนที่แค่โชคดีได้

ฝีมือวัดด้วย information ratio $\mathrm{IR}=\mu/\sigma$ คือค่าเฉลี่ยจริงของ active return หารด้วย SD ของมัน หน่วยต่อปี เช่นผู้จัดการที่ชนะดัชนีเฉลี่ย 3% ต่อปี และส่วนต่างแกว่ง 6% มี $\mathrm{IR}=0.03/0.06=0.5$

เกณฑ์ “เห็นฝีมือ” ที่ใช้กันบ่อยคือ $z\ge2$ แปลว่าค่าเฉลี่ยที่เห็นห่างศูนย์อย่างน้อยสอง SE ผู้จัดการไร้ฝีมือทำได้แค่ราว $1-\Phi(2)\approx2.3\%$ ของเวลา $z$ ตัวนี้คือตัวเดียวกับขั้นที่ 4 คือค่าเฉลี่ยที่เห็นหารด้วย SE คำถามคือ ถ้าค่าเฉลี่ยจริงคือ $\mu$ แล้ว $z$ จะออกมาเฉลี่ยเท่าไร

\[\begin{aligned} z&=\frac{\bar X_n}{\sigma/\sqrt n},\\ \mathbb E[z]&=\frac{\mu}{\sigma/\sqrt n}=\mathrm{IR}\sqrt n,\\ \mathbb E[z]=2&\ \Rightarrow\ n=\left(\frac{2}{\mathrm{IR}}\right)^2. \end{aligned}\]

หลักฐานโตตามรากของเวลา เพราะ SE หดตาม $1/\sqrt n$ ค่าเฉลี่ยของ $z$ จึงเป็น IR คูณ $\sqrt n$ ผลที่ตามมาคือเวลาที่ต้องรอขึ้นกับ IR ยกกำลังสอง ฝีมือดีขึ้นสองเท่าจึงลดเวลารอลงสี่เท่า

ใส่ตัวเลข ผู้จัดการที่ IR 0.5 ต่อปี (ถือว่าดีมาก) ต้องรอ $(2/0.5)^2=16$ ปี ถ้า IR 0.25 ต้องรอ $(2/0.25)^2=64$ ปี ถ้า IR 1 ใช้แค่ $(2/1)^2=4$ ปี ที่ IR 0.5 ค่าเฉลี่ยของ $z$ คือ $0.5\sqrt n$ ซึ่งได้ 1, 2, 3 และ 5 เมื่อมีข้อมูล 4, 16, 36 และ 100 ปี

จุดที่ถูกมองข้ามบ่อยคือ “$z$ เฉลี่ยถึง 2” ไม่ได้แปลว่าจะผ่านเกณฑ์ 2 แน่ ๆ $z$ ยังแกว่งรอบค่าเฉลี่ยของมันด้วย SD หนึ่ง (เพราะเราหารด้วย SE แล้ว) ถ้าค่าเฉลี่ยของ $z$ เท่ากับ 2 พอดี โอกาสผ่านคือ $1-\Phi(0)=50\%$ ถ้าอยากวางแผนให้ผ่านด้วยโอกาสสูงกว่านี้ ต้องใช้แนวคิด power ในหน้า การทดสอบสมมติฐาน

ขั้นที่ 6 — ความเบ้หดตาม √n แต่หางยังเพี้ยนได้

CLT บอกว่าค่าเฉลี่ยเข้าใกล้ normal แต่ไม่บอกว่า $n$ เท่าไรจึงใกล้พอ งานคุมความเสี่ยงสนใจหาง คือเหตุการณ์ขาดทุนหนักที่เกิดไม่บ่อย มากกว่าตรงกลาง จึงต้องรู้ว่าความเบ้ของข้อมูลหายไปเร็วแค่ไหนเมื่อเราเฉลี่ย

ให้ $Y_i$ อิสระกัน มีค่าเฉลี่ยศูนย์ variance หนึ่ง และ skewness $\gamma$ เพราะ SD ของ $Y_i$ เป็นหนึ่ง skewness จึงเท่ากับ $\mathbb E[Y_i^3]=\gamma$ ตรง ๆ ความเบ้ของค่าเฉลี่ยเท่ากับความเบ้ของผลรวม เพราะการหารด้วย $n$ เปลี่ยนแค่หน่วย ไม่เปลี่ยนรูปร่าง เราจึงคำนวณจากผลรวม

\[\begin{aligned} \mathbb E\!\left[\Big(\sum_iY_i\Big)^3\right]&=\sum_i\mathbb E[Y_i^3]=n\gamma,\\ \operatorname{skew}(\bar Y_n)&=\frac{n\gamma}{(\sqrt n)^3}=\frac{\gamma}{\sqrt n}. \end{aligned}\]

ความเบ้หดช้า แค่ตาม $1/\sqrt n$ ไม่ใช่ $1/n$ ที่มาคือ เมื่อกระจาย $(Y_1+\cdots+Y_n)^3$ จะได้พจน์สามแบบ คือ $Y_i^3$, $Y_i^2Y_j$ และ $Y_iY_jY_k$ สองแบบหลังมีตัวหนึ่งที่ปรากฏครั้งเดียว ตัวนั้นอิสระจากตัวอื่นและมีค่าเฉลี่ยศูนย์ พจน์ทั้งพจน์จึงเฉลี่ยเป็นศูนย์ เช่น $\mathbb E[Y_1^2Y_2]=\mathbb E[Y_1^2]\,\mathbb E[Y_2]=1\times0=0$ เหลือแค่ $n$ พจน์ $\mathbb E[Y_i^3]=\gamma$

skewness คือ moment ที่สามหารด้วย SD ยกกำลังสาม ผลรวม $n$ ตัวมี variance $n$ จึงมี SD $\sqrt n$ ตัวหารจึงเป็น $(\sqrt n)^3=n^{3/2}$ ตัวตั้งโตแค่ $n$ แต่ตัวหารโต $n^{3/2}$ ความเบ้จึงเหลือ $\gamma/\sqrt n$

ลองกับข้อมูลแบบ exponential ค่าเฉลี่ยหนึ่ง เช่นเวลารอจนเหตุการณ์ถัดไปเกิด ซึ่งมีหางขวายาว moment ของมันคือ $\mathbb E[X^k]=\int_0^\infty x^ke^{-x}\,dx=k!$ ดังนั้น variance คือ $2-1^2=1$ และ SD คือ 1 ความเบ้จึงเท่ากับ moment ที่สามรอบค่าเฉลี่ยตรง ๆ

\[\begin{aligned}\gamma&=\mathbb E[(X-1)^3]\\&=\mathbb E[X^3]-3\,\mathbb E[X^2]+3\,\mathbb E[X]-1\\&=6-6+3-1=2.\end{aligned}\]

เฉลี่ย 30 ตัวแล้วยังเหลือความเบ้ $2/\sqrt{30}\approx0.365$

ความเบ้ที่เหลือทำให้หางสองข้างผิดไม่เท่ากัน ค่าเฉลี่ย 30 ตัวมีค่าเฉลี่ย 1 และ SD $1/\sqrt{30}\approx0.183$ normal วางจุดตัดหางละ 1% ไว้ที่ $1\pm2.326/\sqrt{30}=1\pm0.4247$ คือ 1.4247 และ 0.5753 (2.326 คือระยะเป็นจำนวน SD ที่เหลือหาง 1% ของ normal) แต่ค่าเฉลี่ยของ exponential 30 ตัวมีการแจกแจงจริงที่รู้สูตร คือ gamma โค้ดท้ายหน้าคำนวณให้ ได้หางขวาจริง 1.70% และหางซ้ายจริง 0.34% ไม่ใช่ 1% ทั้งคู่

ทฤษฎีบท Berry–Esseen ยืนยันว่าความคลาดของ CDF (โอกาสที่ไม่เกินค่าหนึ่ง) ทั้งเส้นหดตาม $1/\sqrt n$ เช่นกัน ความคลาด $1.70\%-1\%=0.70$ จุดดูเล็ก แต่เมื่อเทียบกับหางขนาด 1% มันคือคลาดไป $0.70/1=70\%$ ถ้าจะใช้ CLT รับรอง VaR 99.9% (ระดับขาดทุนที่ควรถูกเกินแค่ 1 ครั้งใน 1,000 ช่วง) จึงต้องตรวจหางจริงเพิ่มเสมอ

ขั้นที่ 7 — ข้อมูลตามเวลา: ต้องนับคู่ที่สัมพันธ์กัน

ถึงตอนนี้เราสมมติว่าแต่ละปีอิสระกัน แต่ในงานจริง ปีที่ดีมักตามด้วยปีที่ดี โดยเฉพาะกองทุนที่ถือของซื้อขายยาก เช่นอาคารหรือหุ้นบริษัทนอกตลาด ของพวกนี้ไม่มีราคาตลาดทุกวัน ราคาที่รายงานมาจากการประเมินซึ่งค่อย ๆ ปรับตามความจริง ผลตอบแทนที่รายงานจึงเรียบเกินจริง และปีติดกันสัมพันธ์กัน

เมื่อปีไม่อิสระกัน สูตร SE เดิมใช้ไม่ได้ ให้แต่ละปีมี variance $\sigma^2$ และให้ $\rho_k$ คือ correlation ระหว่างปีหนึ่งกับปีที่ห่างไป $k$ ปี คู่นั้นจึงมี covariance $\rho_k\sigma^2$ เราต้องนับ covariance ของทุกคู่ เหมือนตารางคู่ในหน้า กฎจำนวนมาก

\[\begin{aligned} \operatorname{Var}(\bar X_n)&=\frac{\sigma^2}{n}\Big[1+2\sum_{k=1}^{n-1}\Big(1-\frac kn\Big)\rho_k\Big],\\ \rho_k=\rho^k:\quad1+2\sum_{k=1}^{\infty}\rho^k&=\frac{1+\rho}{1-\rho}. \end{aligned}\]

ความคิดหลักคือ ปีที่สัมพันธ์กันบอกเรื่องซ้ำกัน ข้อมูล $n$ ปีจึงมีหลักฐานน้อยกว่า $n$ ปีอิสระ วงเล็บในสูตรคือตัวคูณที่ขยาย variance ขึ้นตามความซ้ำนั้น

ตัวคูณ $2(1-k/n)$ มาจากการนับช่องในตาราง variance ของผลรวม $n$ ปีคือผลรวมของ covariance ทุกช่องในตาราง $n\times n$ ช่องบนแนวทแยงคือปีเดียวกันจับคู่กับตัวเอง รวมได้ $n\sigma^2$ ช่องที่ห่างจากแนวทแยง $k$ ช่องมี $n-k$ ช่องในแต่ละฝั่ง รวมสองฝั่งเป็น $2(n-k)$ ช่อง ช่องละ $\rho_k\sigma^2$ หารทั้งหมดด้วย $n^2$ เพื่อเป็น variance ของค่าเฉลี่ย แล้วดึง $\sigma^2/n$ ออกนอกวงเล็บ จะเหลือ $2(n-k)/n=2(1-k/n)$ คูณ $\rho_k$

ถ้าอนุกรมเป็นแบบ AR(1) คือปีนี้เท่ากับ $\rho$ คูณปีก่อนบวกส่วนใหม่ที่สุ่ม correlation จะจางลงเป็น $\rho_k=\rho^k$ เมื่อ $n$ ใหญ่ $1-k/n$ ใกล้หนึ่ง ผลรวมจึงเป็นอนุกรมเรขาคณิต $\sum_{k\ge1}\rho^k=\rho/(1-\rho)$ และ $1+2\rho/(1-\rho)=(1+\rho)/(1-\rho)$ ที่ $\rho=0.5$ ตัวคูณระยะยาวคือ $(1+0.5)/(1-0.5)=3$

ลองกับผู้จัดการ IR 0.5 ที่มีข้อมูล 16 ปี ($\sigma=6\%$) และสมมติว่าค่าเฉลี่ยที่เห็นเท่ากับค่าจริง $3\%$ พอดี ตัวคูณขยาย variance ดังนั้น SE ซึ่งเป็นรากของ variance จะขยายด้วยรากของตัวคูณ ให้ $\mathrm{SE}_{\text{iid}}$ คือ SE ถ้าถือว่าปีอิสระกัน $\mathrm{SE}_\infty$ คือ SE ที่ใช้ตัวคูณระยะยาว 3 และ $\mathrm{SE}_{16}$ คือ SE ที่ใช้ตัวคูณเต็มที่ 16 ปีพอดี ซึ่งโค้ดท้ายหน้าบวกสูตรเต็มให้ได้ 2.750

\[\begin{aligned}\mathrm{SE}_{\text{iid}}&=6\%/\sqrt{16}=1.5\%,\\z_{\text{iid}}&=3/1.5=2,\\\mathrm{SE}_\infty&=1.5\%\times\sqrt3\approx2.598\%,\\z_\infty&=3/2.598\approx1.155,\\\mathrm{SE}_{16}&=1.5\%\times\sqrt{2.750}\approx2.487\%,\\z_{16}&=3/2.487\approx1.206.\end{aligned}\]

หลักฐานที่ดูเหมือนสอง SE จึงเหลือแค่ราว 1.2 SE ถ้าใช้สูตรอิสระ เราจะเชื่อในฝีมือที่ยังพิสูจน์ไม่ได้

สูตร variance อย่างเดียวยังไม่พอรับประกันว่า CLT ใช้ได้กับข้อมูลที่สัมพันธ์กัน ความสัมพันธ์ต้องจางลงเร็วพอเมื่อระยะห่างเพิ่ม ในงานจริงนิยมสองวิธี คือ long-run variance ซึ่งประมาณตัวคูณในวงเล็บจากข้อมูล และ block bootstrap (Monte Carlo และ bootstrap) ซึ่งสุ่มข้อมูลเป็นช่วงต่อเนื่องเพื่อรักษาความสัมพันธ์ไว้

ความผิดที่ทำให้ตัวเลขดูน่าเชื่อแต่ผิด

คิดว่า CLT ทำให้ผลตอบแทนรายวันเป็น normal: CLT พูดถึงผลรวมหรือค่าเฉลี่ยของหลายชิ้น ผลตอบแทนวันเดียวคือชิ้นเดียว มันจึงยังหางหนาเหมือนเดิม ถ้าใช้ normal กับผลตอบแทนวันเดียว จะประเมินโอกาสของวันเลวร้ายต่ำไปมาก

ใช้กฎ “30 ตัวพอ” กับหาง: normal บอกว่าค่าเฉลี่ย 30 ตัวของข้อมูลแบบ exponential เกิน $1+2.326/\sqrt{30}=1.4247$ ได้ 1% ของเวลา แต่ของจริง (gamma) คือ 1.70% เหตุการณ์ที่คิดว่าเกิด 1 ครั้งใน 100 จริง ๆ เกิด $100\times1.70\%=1.7$ ครั้ง ถ้าใช้ตัวเลข normal คำนวณเงินสำรองสำหรับเหตุการณ์หายาก จะสำรองน้อยเกินไป

ใช้ $z$ ทั้งที่ประมาณ SD จากข้อมูลน้อย: ในโจทย์กองทุน ถ้า SD 6% ประมาณจากสี่ปีเดียวกัน คำตอบผิดคือ $1-\Phi(1)\approx15.87\%$ คำตอบถูกคือ $P(t_3\ge1)\approx19.55\%$ ส่วนต่างมาจากความไม่แน่นอนของ SD เอง

นับหน้าต่างที่ซ้อนกันเป็นข้อมูลอิสระ: ข้อมูลรายเดือน 10 ปีมี $10\times12=120$ เดือน ถ้าคำนวณผลตอบแทน 12 เดือนโดยเลื่อนทีละเดือน จะได้ $120-12+1=109$ แถว แต่สองแถวติดกันใช้ 11 เดือนร่วมกัน ช่วงที่ไม่ซ้อนกันจริงมีแค่ $120/12=10$ ช่วง ถ้าหาร SD ด้วย $\sqrt{109}$ แทน $\sqrt{10}$ จะได้ SE เล็กไป $\sqrt{109/10}\approx3.3$ เท่า

ใช้ทำอะไรบนโต๊ะจริง

บนโต๊ะเทรด ตัวเลขแบบ “ค่าประมาณ บวกลบสอง SE” มีอยู่ทุกที่ ช่วงนี้ครอบค่าจริงราว 95% ของเวลา และความหมายนี้มาจาก CLT ทั้งหมด ตัวอย่างที่เจอบ่อย:

  • ราคาจาก Monte Carlo คือการจำลองสุ่มหลายพันรอบแล้วเฉลี่ย ช่วงความคลาดของราคานั้นมาจาก CLT
  • การทดสอบว่ากลยุทธ์มีกำไรเฉลี่ยมากกว่าศูนย์จริง ไม่ใช่โชค
  • VaR (ระดับขาดทุนที่ไม่ควรถูกเกินบ่อยกว่าที่กำหนด) ของพอร์ตที่มีสถานะเล็ก ๆ อิสระกันจำนวนมาก

ทุกครั้งที่ใช้ ให้ถามสามข้อ ชิ้นส่วนอิสระกันพอไหม หางที่สนใจไกลแค่ไหน และข้อมูลมีกี่ชิ้นที่อิสระจริง

โจทย์ตรวจความเข้าใจ

1. ทีมคัดเลือกกองทุนเจอผู้จัดการที่เก่งพอใช้ เขาชนะดัชนีเฉลี่ย 1.5% ต่อปี และส่วนต่างรายปีแกว่ง SD 6% เขาจึงมี $\mathrm{IR}=0.015/0.06=0.25$ ต่อปี ต้องดูประวัติกี่ปี ค่าเฉลี่ยของ $z$ จึงถึง 2 และตอนนั้นโอกาสที่ $z$ จะเกิน 2 จริงเป็นเท่าไร

เฉลย

ใช้สูตรเวลารอ $n=(2/\mathrm{IR})^2$

\[\begin{aligned}n&=(2/0.25)^2=8^2=64,\\P(z\gt2)&=1-\Phi\big((2-2)/1\big)=1-\Phi(0)=50\%.\end{aligned}\]

ต้องดูประวัติ 64 ปี ตอนนั้น $z$ เป็น normal ที่มีค่าเฉลี่ย 2 และ SD หนึ่ง เกณฑ์ 2 จึงอยู่กลางระฆังพอดี ประวัติ 64 ปีก็ยังเหมือนโยนเหรียญว่าจะผ่านเกณฑ์หรือไม่

2. กลับไปที่ลูกเต๋าสี่ลูก คราวนี้ถามหางที่ไกลกว่าเดิม โอกาสที่ $S_4\ge22$ เป็นเท่าไร นับตรง แล้วประมาณด้วย normal พร้อม continuity correction จากนั้นเทียบความแม่นกับคำตอบที่ 20

เฉลย

จากตาราง $N(s)$ ในขั้นที่ 2 ผลรวม 22, 23, 24 มี 10, 4, 1 แบบ แท่งของค่า 22 เริ่มที่ 21.5

\[\begin{aligned}P(S_4\ge22)&=\tfrac{10+4+1}{1{,}296}=\tfrac{15}{1{,}296}\approx1.157\%,\\z&=\tfrac{21.5-14}{3.416}\approx2.196,\\1-\Phi(2.196)&\approx1.405\%,\\1.405/1.157&\approx1.21.\end{aligned}\]

normal ให้สูงกว่าจริงราว 21% ของคำตอบ ส่วนที่ขอบ 20 สองค่าต่างกันแค่ $(5.401-5.367)/5.401\approx0.6\%$ ยิ่งไปไกลในหาง การประมาณยิ่งผิดมากเมื่อเทียบกับขนาดคำตอบ ที่นี่ normal ให้เกินจริง เพราะผลรวมสี่ลูกไม่มีทางเกิน 24 แต่หางของ normal ยาวไปไม่สิ้นสุด

3. กองทุนอาคารแห่งหนึ่งรายงานผลตอบแทนจากราคาประเมิน ผลตอบแทนรายปีจึงสัมพันธ์กันแบบ AR(1) โดย correlation ระหว่างปีติดกัน $\rho=0.5$ ถ้าอยากให้ SE ของค่าเฉลี่ยเท่ากับกรณีที่มีข้อมูลอิสระ 16 ปี ต้องใช้ข้อมูลราวกี่ปี (ใช้ตัวคูณระยะยาว)

เฉลย

ตัวคูณระยะยาวที่ $\rho=0.5$ คือ $(1+0.5)/(1-0.5)=3$ จับ variance สองกรณีให้เท่ากัน

\[\begin{aligned}\frac{\sigma^2}{16}&=\frac{3\sigma^2}{n},\\n&=3\times16=48.\end{aligned}\]

ต้องใช้ข้อมูลราว 48 ปี ข้อมูลที่สัมพันธ์กันแบบนี้มีค่าแค่หนึ่งในสามของปีอิสระ

  const ax = Math.abs(x), d = Math.exp(-ax * ax / 2) / Math.sqrt(2 * Math.PI);
  if (ax < 3) {
    let term = ax, sum = ax;
    for (let k = 1; term > 1e-17 * sum; k++) { term *= ax * ax / (2 * k + 1); sum += term; }
    return x < 0 ? 0.5 - d * sum : 0.5 + d * sum;
  }
  let f = 0;
  for (let k = 300; k >= 1; k--) f = k / (ax + f);

}

สิ่งที่ควรตอบได้หลังอ่าน

  • CLT บอกรูปร่างของค่าเฉลี่ยหลัง standardize ว่าเข้าใกล้ normal มันไม่ได้ทำให้ข้อมูลรายตัวเป็น normal
  • ลูกเต๋าสี่ลูก นับตรงได้ $P(S_4\ge20)=70/1{,}296\approx5.401\%$ และ normal พร้อม continuity correction (เริ่มนับที่ 19.5) ให้ 5.367%
  • ผลงาน 3% จากสี่ปีที่ SD 6% ห่างศูนย์แค่ $3\%/(6\%/\sqrt4)=1$ SE ผู้จัดการไร้ฝีมือราว 16 ใน 100 คนทำได้
  • เวลาที่ต้องรอให้ $z$ เฉลี่ยถึง 2 คือ $(2/\mathrm{IR})^2$ ปี และตอนนั้นโอกาสผ่านเกณฑ์มีแค่ครึ่งเดียว
  • ความเบ้หดแค่ตาม $1/\sqrt n$ หางจึงผิดได้มากแม้ตรงกลางดูดี และข้อมูลที่ปีติดกันสัมพันธ์กันต้องขยาย SE ก่อนใช้ CLT

หน้านี้และหน้าที่แล้วสมมติว่ารู้ $\sigma$ หรือรู้กลไกที่สร้างข้อมูล หน้าถัดไป estimator, bias และ standard error จะถามว่าตัวเลขที่เราคำนวณจากข้อมูลจริงดีแค่ไหน ทำไม sample variance ต้องหารด้วย $n-1$ และทำไม drift (ผลตอบแทนเฉลี่ยต่อปี) ประมาณยากกว่าความผันผวนมาก
