23.2 Commodity Derivatives: Gas and Power

ก๊าซเก็บได้แต่มีต้นทุน ไฟฟ้าเก็บแทบไม่ได้ ความต่างข้อเดียวนี้ทำให้คลังก๊าซเป็น option บนส่วนต่างตามเวลา และโรงไฟฟ้าเป็น option บนส่วนต่างระหว่างไฟกับก๊าซ

จอของเทรดเดอร์แสดงราคาก๊าซ Henry Hub เดือนมิถุนายน \$2.80 ต่อ MMBtu เดือนธันวาคม \$4.20 บริษัทเช่าคลังใต้ดินพอสำหรับ 10,000 MMBtu ส่วนต่างบนจอคือ $1.40\times10{,}000=\$14{,}000$ แต่การเก็บก๊าซมีต้นทุน: ค่าอัดเข้า \$0.10 ค่าดึงออก \$0.05 ต่อ MMBtu ก๊าซหายระหว่างเก็บ 2% และต้องกู้เงินซื้อที่ 5% ต่อปีนานหกเดือน ดีลนี้ได้เท่าไรจริง และถ้าไม่ล็อกราคาขายไว้ ราคาธันวาคมต้องไม่ต่ำกว่าเท่าไร?

ลองตอบก่อนเปิดเฉลย

ได้ \$10,970 ไม่ใช่ \$14,000 ขายได้แค่ 9,800 MMBtu เพราะหาย 2% และต้นทุนรวม \$30,190 กำไรเหลือราว \$1.12 ต่อหน่วยที่ขาย จากส่วนต่างบนจอ 1.40 ถ้าไม่ล็อกราคาขาย ราคาธันวาคมต้องไม่ต่ำกว่า \$3.0806 จึงเท่าทุน ดีลที่ดีต้องขายธันวาคมล่วงหน้าตั้งแต่วันที่ซื้อ ไม่อย่างนั้นกำไรนี้คือการเดาว่าราคาจะไม่ลงเกิน 26.7%

ภาพรวมก่อนลงสูตร

หุ้นถือไว้ในบัญชีได้ฟรี แต่ก๊าซต้องเช่าที่เก็บ เสียค่าอัด ค่าดึง และหายไประหว่างทาง ส่วนไฟฟ้าแทบเก็บไม่ได้เลย ต้องผลิตและใช้ในชั่วโมงเดียวกัน ความต่างนี้ทำให้ราคาล่วงหน้าของสินค้าพลังงานไม่เดินตามสูตร cost of carry ของหุ้น และทำให้สินทรัพย์จริงสองชนิดกลายเป็น option: คลังก๊าซให้สิทธิ์ซื้อตอนถูกแล้วขายตอนแพง (ส่วนต่างตามเวลา) โรงไฟฟ้าให้สิทธิ์เปลี่ยนก๊าซเป็นไฟเมื่อไฟแพงกว่าก๊าซที่ต้องเผา (ส่วนต่างระหว่างสินค้า)

ครึ่งแรกเป็นเรื่องก๊าซ: คิดดีลคลังให้ครบทุกต้นทุน หาเพดานราคาล่วงหน้า ล็อกราคาด้วย swap แล้วมองคลังเป็น option ด้วยสมการเดินถอยหลังของ real options และ dynamic programming ครึ่งหลังเป็นเรื่องไฟฟ้า: โรงไฟฟ้าเป็น call บน spark spread ค่าติดเครื่องทำให้แต่ละชั่วโมงไม่แยกกัน สัญญาเช่าโรงไฟฟ้า (tolling) ตีราคาด้วยสมการเดียวกัน ราคาถูกดึงกลับและกระโดด แล้วจบที่การ hedge ค่าไฟ รูปด้านล่างคือดีลคลังก๊าซทั้งก้อน

ขั้นที่ 1 — ดีลคลังก๊าซ: \$14,000 บนจอเหลือเท่าไร

โจทย์ให้อะไรมาบ้าง: ซื้อ $Q=10{,}000$ MMBtu ที่ 2.80 ขายธันวาคมที่ 4.20 ค่าอัด 0.10 ต่อหน่วยที่อัด ค่าดึง 0.05 ต่อหน่วยที่ดึง ก๊าซหาย $\ell=2\%$ ดอกเบี้ยเงินกู้ซื้อ 5% ต่อปีแบบธรรมดา นานครึ่งปี ทุกต้นทุนนับ ณ วันขาย

\[ \begin{aligned} Q_{\text{sold}}&=10{,}000(1-0.02)=9{,}800,\\ \text{revenue}&=9{,}800(4.20)=41{,}160,\\ \text{cost}&=28{,}000+1{,}000+490+700\\ &=30{,}190,\\ \text{profit}&=41{,}160-30{,}190=10{,}970,\\ S^{\text{be}}_{\text{Dec}}&=\frac{30{,}190}{9{,}800}=3.0806. \end{aligned} \]

ต้นทุนสี่ก้อนคือ ค่าก๊าซ $10{,}000(2.80)$ ค่าอัด $10{,}000(0.10)$ ค่าดึง $9{,}800(0.05)$ ซึ่งคิดเฉพาะก๊าซที่เหลือให้ดึง และดอกเบี้ย $28{,}000(0.05)(0.5)$ ของเงินที่กู้ซื้อก๊าซ ก๊าซที่หายไม่ได้แค่ขายไม่ได้ เรายังจ่ายค่าซื้อและค่าอัดของมันไปแล้วด้วย

บรรทัดสุดท้ายเอาต้นทุนทั้งหมดหารด้วยหน่วยที่ขายได้จริง ได้ราคาธันวาคมที่แค่เท่าทุน ราคาตกจาก 4.20 ได้ $3.0806/4.20-1=-26.65\%$ ก่อนกำไรหมด อีกเรื่องที่คนมักพลาดคือนาฬิกาของเงิน ถ้าค่าอัด \$1,000 ต้องจ่ายตอนอัดในเดือนมิถุนายน ไม่ใช่ตอนขาย เงินก้อนนั้นก็ต้องกู้ครึ่งปีเหมือนกัน กำไรจึงลดอีก $1{,}000(0.05)(0.5)=25$ เหลือ 10,945 และกำไรนี้เป็นเงิน ณ เดือนธันวาคม ถ้าจะเทียบกับดีลอื่นวันนี้ต้องคิดลดกลับมาอีกครึ่งปี

คำตอบ: กำไร \$10,970 หรือ $10{,}970/9{,}800=\$1.12$ ต่อหน่วยที่ขาย ไม่ใช่ 1.40 ต่อหน่วยตามจอ ช่องว่าง \$3,030 คือรายได้ของก๊าซ 200 หน่วยที่หายไป $200(4.20)=\$840$ ค่าอัด \$1,000 ค่าดึง \$490 และดอกเบี้ย \$700

ตรวจเองใน 10 วินาที: $840+1{,}000+490+700=3{,}030$ และ $14{,}000-3{,}030=10{,}970$ ตรงกับการคิดรายรับลบต้นทุน

ขั้นที่ 2 — cash-and-carry: ทำไมราคาล่วงหน้าของก๊าซมีแต่เพดาน

หน้า cost of carry และ cash-and-carry ตั้งราคาล่วงหน้าของหุ้นด้วยสองรายการที่ไม่ใช้เงินตัวเอง: กู้มาซื้อของแล้วขายล่วงหน้า กับยืมของมาขายแล้วซื้อล่วงหน้า สองรายการบีบราคาจากสองข้างจนเหลือค่าเดียว กับก๊าซทำได้แค่รายการแรก เพราะรายการที่สองต้องยืมก๊าซมาขายวันนี้ ซึ่งไม่มีใครให้ยืมก๊าซจากใต้ดิน ผลคือราคาล่วงหน้ามีเพดาน แต่ไม่มีพื้น

\[ \begin{aligned} V_0&=-QS+QS=0,\\ V_T&=F_0(T)\,Q(1-\ell)-C_{\text{carry}}\le0,\\ F_0(T)&\le\frac{C_{\text{carry}}}{Q(1-\ell)}=\frac{30{,}190}{9{,}800}\\ &=3.0806,\\ F_0(T)&=S\,e^{(r+u-y)T},\\ y-(r+u)&=-\frac{\ln(3.00/4.30)}{0.25}=1.44. \end{aligned} \]

$V_0$ คือวันนี้: กู้เงินมาซื้อก๊าซ จึงไม่ใช้เงินตัวเองเลย $V_T$ คือวันส่งมอบ: ส่งก๊าซที่เหลือตามราคาล่วงหน้า แล้วจ่ายคืนต้นทุนทั้งหมด $C_{\text{carry}}$ (ค่าก๊าซ ค่าอัดดึง ดอกเบี้ย) ถ้าใครก็เช่าคลังได้ไม่จำกัด ผลนี้รู้แน่ตั้งแต่วันนี้ ถ้าเป็นบวกคือเงินฟรี ทุกคนจะทำจนราคาธันวาคมไม่เกิน 3.0806

แต่จอแสดง 4.20 เกินเพดานไปมาก เพราะคลังมีจำกัดและสร้างใหม่ใช้เวลาหลายปี คนที่ไม่มีคลังทำ cash-and-carry ไม่ได้ ส่วนต่าง \$10,970 จึงเป็นค่าเช่าที่คลังขนาด 10,000 MMBtu ทำได้ในรอบนี้ ถ้าผู้ให้เช่าคิดค่าเช่าเกินนี้ ดีลก็ไม่คุ้ม

บรรทัดที่สี่เป็นนิยาม ตลาดเขียนราคาเป็นอัตรา: $r$ คือดอกเบี้ย $u$ คือค่าเก็บ และ $y$ คือตัวที่ทำให้บรรทัดนั้นเท่ากับราคาตลาดพอดี เรียกว่า convenience yield บรรทัดสุดท้ายใช้เส้นราคาด้านบน มกราคม 4.30 ไปเมษายน 3.00 (หนึ่งไตรมาส) แก้หา $y$ ได้สูงกว่า $r+u$ ถึง 144% ต่อปี ในหน้าหนาว ของในมือมีค่ามากจนไม่มีใครอยากเก็บไว้ขายเมษายน เส้นราคาที่ลาดลงแบบนี้เรียกว่า backwardation ส่วนช่วงมิถุนายนถึงธันวาคมที่ลาดขึ้นเรียกว่า contango

ขั้นที่ 3 — ล็อกราคาด้วย swap: ราคาคงที่คือค่าเฉลี่ยถ่วงของราคาล่วงหน้า

ดีลคลังต้องล็อกราคาขาย ผู้ใช้ก๊าซอย่างโรงงานก็ต้องล็อกราคาซื้อหลายเดือนพร้อมกัน เครื่องมือมาตรฐานคือ swap ฝั่งที่จ่ายคงที่ $K$ และรับราคาตลาดจะได้ $Q(F_T-K)$ ในแต่ละงวด ราคา $K$ ที่ยุติธรรมคือราคาที่ทำให้สัญญามีค่าศูนย์ในวันที่เซ็น ตัวอย่างใช้สามเดือนท้ายของเส้นราคาด้านบน ตุลาคม 3.00 พฤศจิกายน 3.60 ธันวาคม 4.20

\[ \begin{aligned} 0&=\sum_i Q\,D_i\big(F_0(T_i)-K\big),\\ K^*&=\frac{\sum_i D_i\,F_0(T_i)}{\sum_i D_i},\\ K^*&=\frac{0.995(3.00)+0.990(3.60)+0.985(4.20)}{0.995+0.990+0.985}\\ &=\frac{10.686}{2.970}=3.5980. \end{aligned} \]

swap คือมัดของสัญญาล่วงหน้าหลายงวด แต่ละงวดมีค่าวันนี้เท่ากับส่วนต่างระหว่างราคาล่วงหน้ากับ $K$ คูณตัวคูณคิดลด $D_i$ ปริมาณเท่ากันทุกงวดจึงตัดออก ราคาคงที่เป็นค่าเฉลี่ยของราคาล่วงหน้าที่ถ่วงด้วยตัวคูณคิดลด เป็นสูตรเดียวกับอัตรา swap ดอกเบี้ย

ได้ 3.5980 ต่ำกว่าค่าเฉลี่ยธรรมดา 3.60 เล็กน้อย เพราะเดือนที่ราคาสูงอยู่ไกลกว่าและถูกคิดลดมากกว่า swap ไม่ได้ทำให้ก๊าซถูกลง มันทำให้รู้ราคาล่วงหน้า

ขั้นที่ 4 — คลังคือ option: สมการเดินถอยหลังที่มีสองสถานะ

ถ้าไม่ล็อกทุกอย่างตั้งแต่วันแรก เจ้าของคลังเลือกได้ทุกงวดว่าจะอัด ดึง หรืออยู่เฉย ๆ นี่คือสิทธิ์เลือกแบบเดียวกับเหมืองทองในหน้า real options แต่สถานะมีสองตัว คือราคากับก๊าซในคลัง เพราะการดึงวันนี้ทำให้พรุ่งนี้มีของน้อยลง ขั้นนี้เขียนสมการแล้วทดลองกับคลังเล็กที่สุด จุหนึ่งหน่วยและว่างอยู่

\[ \begin{aligned} V_T(I,P)&=0,\\ V_t(I,P)&=\max_z\big\{P\,\big(z-f(z,I)\big)-c\lvert z\rvert\\ &\qquad+\delta\,\mathbb E_q[V_{t+1}(I-z,P_{t+1})]\big\},\\ 0&\le I-z\le C,\quad -a\le z\le b,\\ V_1(1,4.50)&=4.50-0.10=4.40,\\ V_1(1,2.50)&=2.50-0.10=2.40,\\ V_0(0,3.00)&=\max\{0,\ -3.10+0.95(3.40)\}\\ &=0.13. \end{aligned} \]

$z$ คือปริมาณที่ดึงออก ($z$ ติดลบคืออัดเข้า) ก้อน $P\,(z-f)$ คือเงินจากการซื้อขายงวดนี้ โดย $f(z,I)$ คือก๊าซที่เสียไปตอนดึง ส่วนใหญ่ถูกเผาเป็นเชื้อเพลิงให้ปั๊ม และขึ้นกับว่าคลังมีก๊าซเหลือเท่าไร $c\lvert z\rvert$ คือค่าอัดหรือดึง ก้อนหลังคือค่าของคลังงวดหน้าที่คิดลดด้วย $\delta$ และต้องเป็นค่าเฉลี่ยใต้น้ำหนักตั้งราคา ไม่ใช่โอกาสจริง ข้อจำกัดคือคลังต้องไม่ติดลบและไม่เกินความจุ $C$ และอัดหรือดึงได้ไม่เกินกำลังท่อ $a,\ b$ ข้อจำกัดนี้เองที่ผูกการตัดสินใจวันนี้กับวันหน้า

ตัวอย่าง (ตัด $f$ ทิ้ง ให้ $c=0.10$): วันนี้ราคา 3.00 งวดหน้า 4.50 หรือ 2.50 ด้วยน้ำหนัก 0.5 เท่ากัน ($\delta=0.95$) งวดหน้าเป็นงวดสุดท้าย ทั้งสองกิ่งดึงขายหมด ถ่วงได้ 3.40 คิดลดได้ 3.23 ซื้ออัดวันนี้เสีย 3.10 เหลือ 0.13 ค่านี้เท่ากับการล็อกด้วยราคาล่วงหน้า 3.50 พอดี $0.95(3.50-0.10)-3.10=0.13$ เพราะไม่มีกิ่งไหนที่ไม่คุ้มขาย สิทธิ์เลือกจึงไม่เพิ่มค่า สิทธิ์เลือกเพิ่มค่าเมื่อมีกิ่งที่ถ้าถูกบังคับทำจะขาดทุน ซึ่งโรงไฟฟ้าในขั้นถัด ๆ ไปแสดงให้เห็น

คลังจริงมีหลายร้อยระดับของก๊าซในคลัง ทุก node ของต้นไม้ราคาจึงต้องเก็บค่า $V$ ของทุกระดับ งานจึงโตเป็นจำนวน node คูณจำนวนระดับ ทางออกที่ใช้กันคือประมาณ $V$ ด้วยฟังก์ชันง่าย ๆ ของปัจจัยไม่กี่ตัว (approximate dynamic programming) หรือจำลองเส้นทางราคาแล้วหานโยบายอัดดึงที่ดีที่สุดจาก simulation

ขั้นที่ 5 — โรงไฟฟ้า: heat rate และ spark spread

ข้ามมาฝั่งไฟฟ้า โรงไฟฟ้าก๊าซเปลี่ยนก๊าซเป็นไฟ ต้นทุนเชื้อเพลิงต่อ MWh จึงเป็นก๊าซที่เผาคูณราคาก๊าซ สิ่งที่เจ้าของสนใจคือส่วนต่างระหว่างราคาไฟกับค่าก๊าซนั้น บรรทัดแรกเป็นนิยาม ตัวเลขเป็นตัวอย่างสมมติ: โรงไฟฟ้า 100 MW เดิน 5 ชั่วโมงช่วงราคาสูง heat rate 7 ก๊าซ \$3.00 ต้นทุนผันแปรอื่น $c_{\text{var}}=\$5$ ต่อ MWh ราคาไฟ \$90 ต่อ MWh

\[ \begin{aligned} D&=P-hG=90-7(3.00)=69,\\ \pi&=\max(D-c_{\text{var}},\ 0)\\ &=\max(69-5,\ 0)=64,\\ Q&=100\ \text{MW}\times5\ \text{h}=500\ \text{MWh},\\ \Pi&=500(64)=32{,}000,\\ G^{\text{be}}&=\frac{90-5}{7}=12.14. \end{aligned} \]

$D$ คือ spark spread: ราคาไฟลบค่าก๊าซที่ต้องเผาเพื่อผลิตไฟหนึ่ง MWh max ในบรรทัดที่สองคือสิทธิ์ที่จะไม่เดินเครื่อง รูปเดียวกับสิทธิ์ที่จะไม่สร้างโรงไฟฟ้าในหน้า real options ทุกประการ โรงไฟฟ้าจึงเป็น call บนส่วนต่างระหว่างราคาไฟกับราคาก๊าซ โดยมีต้นทุนผันแปรอื่นเป็น strike

MW เป็นหน่วยกำลัง ต้องคูณชั่วโมงจึงเป็นพลังงาน MWh ถ้าลืมคูณ 5 กำไรจะเหลือ 6,400 ผิดห้าเท่า บรรทัดสุดท้ายบอกว่าก๊าซต้องแพงเกิน 12.14 ต้นทุนจึงแซงราคาไฟ

ขั้นที่ 6 — ชั่วโมงที่ยังไม่รู้ราคา: ค่าของสิทธิ์ที่จะไม่เดิน

โจทย์ให้อะไรมาบ้าง: โรงไฟฟ้าเดิม ราคาไฟช่วงหน้าจะเป็น 90 หรือ 6 ด้วยน้ำหนักตั้งราคา 0.5 เท่ากัน (ราคาล่วงหน้าของช่วงนั้นจึงเป็น 48) ก๊าซยัง 3.00 spark spread จึงเป็น 69 หรือ −15 หักต้นทุนอื่น 5 ได้ +64 หรือ −20 ต่อ MWh ห่างกันไม่กี่ชั่วโมงจึงไม่คิดลด

\[ \begin{aligned} \Pi_{\text{commit}}&=500\big(0.5(64)+0.5(-20)\big)\\ &=11{,}000,\\ \Pi_{\text{option}}&=500\big(0.5(64)+0.5(0)\big)\\ &=16{,}000,\\ \Pi_{\text{option}}-\Pi_{\text{commit}}&=500(0.5)(20)\\ &=5{,}000. \end{aligned} \]

คำตอบ: ถ้าขายไฟล่วงหน้าแล้วต้องเดินแน่ ได้ \$11,000 ถ้าเก็บสิทธิ์ไว้ตัดสินใจหลังเห็นราคา ได้ \$16,000 ส่วนต่าง \$5,000 คือค่าของการไม่ต้องเดินในกิ่งที่ขาดทุน 20 ต่อ MWh

ตรวจเองใน 10 วินาที: ใช้เอกลักษณ์ $\max(x,0)=x+\max(-x,0)$ เหมือนตอนแยกค่าใบอนุญาตเป็นเวลากับประกัน ก้อนแรกคือค่าเฉลี่ย $0.5(64)+0.5(-20)=22$ คูณ 500 ได้ 11,000 ก้อนหลังคือ put บน spread $500(0.5)(20)=5{,}000$ รวม 16,000 ตรงกัน

ขั้นที่ 7 — ค่าติดเครื่องทำให้แต่ละช่วงไม่แยกกัน

การมองแต่ละช่วงเป็น call แยกกันใช้ได้เมื่อเปิดปิดเครื่องได้ฟรี แต่กังหันก๊าซขนาดใหญ่ต้องเผาเชื้อเพลิงอุ่นเครื่องหลายชั่วโมงก่อนจ่ายไฟได้ ตัวอย่างสมมติ: โรงไฟฟ้าเดิมเปิดอยู่ ช่วงแรก 5 ชั่วโมงราคาไฟ 20 (เดินแล้วได้ $500(20-26)=-3{,}000$) ช่วงที่สอง 5 ชั่วโมงราคาไฟ 50 (ได้ $500(50-26)=12{,}000$) ค่าปิดเครื่อง $C_d=1{,}000$ ค่าติดเครื่อง $C_u=8{,}000$ สถานะเครื่องจึงต้องอยู่ในสมการ

\[ \begin{aligned} V_t(\text{on})&=\max\{\pi_t+V_{t+1}(\text{on}),\\ &\qquad -C_d+V_{t+1}(\text{off})\},\\ V_t(\text{off})&=\max\{V_{t+1}(\text{off}),\\ &\qquad -C_u+\pi_t+V_{t+1}(\text{on})\},\\ V_2(\text{on})&=\max\{12{,}000,\ -1{,}000\}=12{,}000,\\ V_2(\text{off})&=\max\{0,\ -8{,}000+12{,}000\}\\ &=4{,}000,\\ V_1(\text{on})&=\max\{-3{,}000+12{,}000,\\ &\qquad -1{,}000+4{,}000\}=9{,}000. \end{aligned} \]

สองบรรทัดแรกคือกฎเกมลูกเต๋าที่มีสองสถานะ เครื่องที่เปิดอยู่เลือกเดินต่อ (ได้ $\pi_t$) หรือปิด (เสีย $C_d$) เครื่องที่ปิดอยู่เลือกปิดต่อ หรือติดเครื่อง (เสีย $C_u$ แล้วได้ $\pi_t$) หลังช่วงที่ 2 ไม่มีอะไรเหลือ ค่าจึงเป็นศูนย์ เราจึงเริ่มจากช่วงที่ 2 แล้วถอยมาช่วงที่ 1

คำตอบคือยอมขาดทุน 3,000 แล้วเดินต่อ ได้ 9,000 ส่วนกฎ “ปิดเมื่อ spread ติดลบ” ได้แค่ 3,000 เพราะต้องจ่ายค่าติดเครื่องคืน และการมองเป็น call แยกช่วงให้ $\max(-3{,}000,0)+\max(12{,}000,0)=12{,}000$ เกินค่าจริง 3,000 ช่วงราคาที่เจ้าของยอมเดินขาดทุนเพื่อเลี่ยงค่าติดเครื่องเรียกว่า hysteresis

ขั้นที่ 8 — สัญญาเช่าโรงไฟฟ้า (tolling): สองโหมดเดินเครื่อง และค่าเช่า

บริษัทการค้าพลังงานมักไม่สร้างโรงไฟฟ้าเอง แต่เช่าสิทธิ์สั่งเดินเครื่องจากเจ้าของ เรียกว่า tolling agreement ผู้เช่าจ่ายค่าเช่า $K$ ทุกช่วงไม่ว่าเครื่องจะเดินหรือไม่ และเมื่อเครื่องเปิด เลือกเดินได้สองโหมด: เต็มกำลัง หรือกำลังต่ำ (เปลืองก๊าซต่อหน่วยกว่า เพราะเครื่องประสิทธิภาพตกเมื่อเดินไม่เต็ม) สมการคือสมการสองสถานะเดิม แค่ $\pi_t$ เลือกโหมดที่ดีกว่า

โจทย์ให้อะไรมาบ้าง: เต็มกำลัง 100 MW heat rate 7 ต้นทุน 26 ต่อ MWh กำลังต่ำ 50 MW heat rate 8 ต้นทุน $8(3.00)+5=29$ ต่อ MWh ช่วงละ 5 ชั่วโมง ราคาไฟ 20 แล้ว 50 เหมือนเดิม ค่าติดและค่าปิดเครื่องเท่าเดิม ค่าเช่า $K=1{,}500$ ต่อช่วง

\[ \begin{aligned} \pi_t&=\max\{\pi_t^{\text{hi}},\ \pi_t^{\text{lo}}\},\\ \pi_1^{\text{hi}}&=500(20-26)=-3{,}000,\\ \pi_1^{\text{lo}}&=250(20-29)=-2{,}250,\\ \pi_2&=\max\{500(24),\ 250(21)\}=12{,}000,\\ V_1(\text{on})&=\max\{-2{,}250+12{,}000,\ 3{,}000\}\\ &=9{,}750,\\ 9{,}750-2(1{,}500)&=6{,}750. \end{aligned} \]

ช่วงแรกขาดทุนแน่ถ้าเปิดเครื่อง แต่เดินกำลังต่ำขาดทุนน้อยกว่า เพราะผลิตไฟขาดทุนแค่ 250 MWh แทน 500 MWh ทั้งที่ขาดทุนต่อหน่วยมากกว่า (9 เทียบกับ 6) โหมดกำลังต่ำจึงเป็นวิธี “ประคองเครื่องไว้” ข้ามช่วงราคาต่ำโดยไม่ต้องจ่ายค่าติดเครื่องใหม่ ช่วงที่สองราคาดี เต็มกำลังชนะ ค่าของสัญญาขึ้นจาก 9,000 เป็น 9,750

ค่าเช่า $K$ ถูกหักเท่ากันในทุกกิ่งทุกสถานะ มันจึงไม่เปลี่ยนการตัดสินใจใดเลย แค่ลดค่าสุทธิของผู้เช่าเหลือ 6,750 ผู้เช่าจ่ายได้มากที่สุด $9{,}750/2=4{,}875$ ต่อช่วงก่อนสัญญาไม่คุ้ม ในงานจริงทั้งราคาไฟและราคาก๊าซสุ่ม ต้นไม้จึงมีสองมิติ และแต่ละ node เก็บค่าสองตัว ตัวหนึ่งเมื่อเครื่องเปิด อีกตัวเมื่อเครื่องปิด

คำตอบ: สัญญาเช่าสองช่วงมีค่า \$9,750 ก่อนหักค่าเช่า และ \$6,750 หลังหักค่าเช่า \$1,500 ต่อช่วง แผนที่ดีที่สุดคือเปิดเครื่องไว้ช่วงแรกที่กำลังต่ำ แล้วเดินเต็มกำลังช่วงที่สอง

ตรวจเองใน 10 วินาที: เส้นทางอื่นทั้งหมด: ปิดแล้วติดใหม่ $-1{,}000-8{,}000+12{,}000=3{,}000$ ปิดยาว $-1{,}000$ เต็มกำลังสองช่วง 9,000 ไม่มีตัวไหนเกิน 9,750

ขั้นที่ 9 — ราคาก๊าซถูกดึงกลับ: ความผันผวนมีเพดาน

ต้นไม้ของคลังและโรงไฟฟ้าต้องรู้ว่าราคาเดินอย่างไร ราคาหุ้นใน geometric Brownian motion เดินไปได้เรื่อย ๆ แต่ราคาก๊าซมีแรงดึงกลับ เมื่อราคาสูง ผู้ผลิตขุดเพิ่มและผู้ใช้ประหยัด ราคาจึงไหลกลับ เราแยกส่วนที่รู้ล่วงหน้าตามฤดู $s(t)$ ออกก่อน แล้วให้ส่วนที่เหลือ $X_t$ เดินแบบ Vasicek แล้วหาคำตอบของสมการ

\[ \begin{aligned} G_t&=s(t)+X_t,\\ dX_t&=\kappa(\theta-X_t)\,dt+\xi\,dW_t,\\ d\big(e^{\kappa t}X_t\big)&=e^{\kappa t}dX_t+\kappa e^{\kappa t}X_t\,dt\\ &=\kappa\theta e^{\kappa t}dt+\xi e^{\kappa t}dW_t,\\ X_t&=\theta+(X_0-\theta)e^{-\kappa t}\\ &\quad+\xi\int_0^t e^{-\kappa(t-v)}dW_v,\\ \mathrm{Var}(X_t)&=\xi^2\int_0^t e^{-2\kappa(t-v)}dv\\ &=\frac{\xi^2}{2\kappa}\big(1-e^{-2\kappa t}\big). \end{aligned} \]

จังหวะสำคัญคือคูณด้วย $e^{\kappa t}$ ซึ่งไม่สุ่ม กฎผลคูณของ Itô จึงไม่มีพจน์แก้เพิ่ม ก้อน $X_t\,dt$ หักล้างกันพอดี เหลือแต่ก้อนที่อินทิเกรตได้ตรง ๆ บรรทัด variance ใช้ Itô isometry จากหน้า Itô integral: variance ของอินทิกรัลเทียบ $dW$ คืออินทิกรัลตามเวลาของกำลังสองของสิ่งที่คูณ $dW$

ตัวอย่างสมมติ $\kappa=2$ ต่อปี $\xi=0.8$: variance มีเพดาน $0.64/4=0.16$ คือ SD \$0.40 ต่อ MMBtu ครบหนึ่งปีได้ $0.16(1-e^{-4})=0.1571$ (SD \$0.396) ถ้าไม่มีแรงดึงกลับจะได้ $0.64$ (SD \$0.80) ส่วนเบี่ยงหายไปครึ่งหนึ่งใน $\ln2/2=0.35$ ปี หรือราวสี่เดือน ผลต่อ option คือ option ระยะยาวบนก๊าซถูกกว่าที่แบบจำลองหุ้นจะบอกมาก

ขั้นที่ 10 — ราคาไฟกระโดด: เติมก้อน jump

ไฟฟ้าเก็บไม่ได้ วันที่อากาศร้อนจัดหรือโรงไฟฟ้าใหญ่หยุดกะทันหัน ราคาจึงพุ่งหลายเท่าในชั่วโมงเดียว แบบจำลองที่มีแต่ $dW$ ให้เส้นทางต่อเนื่อง ปรับตัวเลขอย่างไรก็สร้างการพุ่งแบบนั้นไม่ได้ จึงต้องเติมก้อนที่เป็นศูนย์เกือบตลอดเวลาแล้วกระโดดเป็นบางครั้ง นี่คือนิยามของแบบจำลองที่ใช้ในรูปจำลองด้านล่าง บนลอการิทึมของราคา

\[ \begin{aligned} y_{h+1}&=y_h+\kappa(\theta-y_h)+\sigma\varepsilon_h+J\,N_h,\\ \kappa&=0.25,\quad \theta=\ln70,\quad \sigma=0.03,\\ J&=\ln3,\quad N_h\sim\text{Poisson}(0.03),\\ e_h&=J(0.75)^h,\\ h_{1/2}&=\frac{\ln2}{-\ln0.75}=2.41,\\ e^{e_8}&=e^{J(0.75)^8}=1.116. \end{aligned} \]

$y_h$ คือลอการิทึมของราคาในชั่วโมงที่ $h$ สามก้อนแรกคือแรงดึงกลับแบบเดียวกับก๊าซ แต่ในเวลารายชั่วโมง ก้อน $J\,N_h$ คือ jump: $N_h$ นับว่าชั่วโมงนั้นเกิดการกระโดดกี่ครั้ง (นับแบบ Poisson เฉลี่ย 0.03 ครั้งต่อชั่วโมง) แต่ละครั้งบวก $\ln3$ ให้ลอการิทึม คือราคาคูณ 3

หลังกระโดด ส่วนเกินของลอการิทึม $e_h$ หายไป 25% ทุกชั่วโมง เพราะแรงดึงกลับ $\kappa=0.25$ ครึ่งหนึ่งหายใน $h_{1/2}=2.41$ ชั่วโมง ผ่านไป 8 ชั่วโมงราคายังสูงกว่าปกติ 11.6% ใน 48 ชั่วโมงคาดว่าจะเกิดการกระโดด $0.03(48)=1.44$ ครั้ง โอกาสไม่เกิดเลยคือ $e^{-1.44}=0.237$ โรงไฟฟ้าที่เป็น call บน spread ได้เงินก้อนใหญ่จากไม่กี่ชั่วโมงนี้

ขั้นที่ 11 — hedge ค่าไฟ: จ่ายคงที่ รับลอยตัว

โจทย์ให้อะไรมาบ้าง: โรงงานใช้ไฟ 500 MWh ในช่วงราคาสูง ซื้อตามราคาตลาด LMP ทำ swap จ่ายคงที่ $K=75$ รับ LMP บน 500 MWh ราคาที่เกิดจริงคือ 90 จากนั้นดูกรณีที่ใช้ไฟจริง 600 MWh

\[ \begin{aligned} \text{swap}&=500(90-75)=7{,}500,\\ \text{bill}&=500(90)-7{,}500\\ &=37{,}500=500(75),\\ \text{bill}_{600}&=600(90)-7{,}500=46{,}500,\\ 46{,}500-600(75)&=1{,}500=100(90-75). \end{aligned} \]

คำตอบ: ค่าไฟสุทธิคือ \$37,500 เท่ากับซื้อที่ 75 พอดี ไม่ว่าราคาตลาดจะเป็นเท่าไร แต่ถ้าใช้ 600 MWh ส่วนเกิน 100 MWh ไม่มี hedge ต้องจ่ายราคาตลาดเต็ม ค่าไฟจึงเป็น \$46,500 ไม่ใช่ \$45,000

ตรวจเองใน 10 วินาที: ที่ LMP 75 swap จ่ายศูนย์ ค่าไฟ 500 MWh คือ 37,500 เท่ากับกรณี 90 ทุกดอลลาร์ที่ค่าไฟแพงขึ้นถูกชดเชยด้วย swap สิ่งที่ swap แก้ไม่ได้คือปริมาณที่ไม่ตรง และจุดส่งมอบหรือชั่วโมงที่ไม่ตรงกับดัชนีในสัญญา (basis risk)

ขั้นที่ 12 — ราคาขายลดได้แค่ไหนก่อนกำไรหาย

เทียบสองธุรกิจของหน้านี้ภายใต้คำถามเดียว ถ้าราคาขายลดลง $x$ จากตัวอย่าง กำไรเป็นอย่างไร ดีลคลังที่ซื้อก๊าซแล้วแต่ยังไม่ล็อกราคาขาย เทียบกับโรงไฟฟ้าที่ราคาไฟ 90 ต้นทุน 26

\[ \begin{aligned} \Pi_{\text{storage}}(x)&=9{,}800(4.20)(1+x)-30{,}190,\\ \Pi_{\text{plant}}(x)&=500\max\big(90(1+x)-26,\ 0\big),\\ x_{\text{storage}}&=\frac{30{,}190}{41{,}160}-1=-26.7\%,\\ x_{\text{plant}}&=\frac{26}{90}-1=-71.1\%. \end{aligned} \]

ดีลคลังขาดทุนเป็นเส้นตรงเมื่อราคาธันวาคมลดเกิน 26.7% เพราะซื้อก๊าซไปแล้ว ไม่เหลือสิทธิ์เลือก ส่วนโรงไฟฟ้ากำไรลดลงจนเป็นศูนย์ที่ราคาไฟ 26 แล้วหยุดอยู่ที่ศูนย์ ไม่ติดลบ เพราะยังเลือกไม่เดินเครื่องได้ (ในตัวอย่างนี้ไม่คิดค่าติดเครื่อง) ของที่ถือ option อยู่มีพื้น ของที่ใช้ option ไปแล้วไม่มี

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

อ่านส่วนต่างบนจอเป็นกำไร: \$14,000 บนจอเหลือ \$10,970 หลังของหาย ค่าอัดดึง และดอกเบี้ย และเหลือ \$10,945 ถ้าค่าอัดจ่ายตอนอัด นาฬิกาของเงินแต่ละก้อนต้องตรงกับวันที่จ่ายจริง

ถือว่าราคาล่วงหน้าคือคำพยากรณ์: ราคาธันวาคม 4.20 สะท้อนความขาดแคลนคลัง convenience yield และค่าตอบแทนความเสี่ยง ไม่ใช่ราคาที่คาดว่าจะเกิด ใช้มันล็อกราคา ไม่ใช่เดาราคา

ลืมคูณชั่วโมง: 100 MW ไม่ใช่ 100 MWh กำไรช่วงราคาสูงจะกลายเป็น 6,400 แทน 32,000

ตีราคาโรงไฟฟ้าเป็น call แยกช่วง: ได้ 12,000 แทนค่าจริง 9,000 เมื่อมีค่าติดเครื่อง 8,000 ยิ่งค่าติดเครื่องสูง ยิ่งประเมินเกิน และถ้าลืมโหมดกำลังต่ำก็ประเมินต่ำไป 750

hedge ที่ Henry Hub แต่ส่งมอบที่อื่น: ราคาก๊าซในพื้นที่ที่โรงไฟฟ้าซื้อจริงอาจห่างจาก Henry Hub มากในวันที่ท่อแน่น hedge ลดความเสี่ยงของราคาอ้างอิงได้ แต่ส่วนต่างระหว่างสองจุด (basis) ยังอยู่

ใช้แบบจำลองที่ราคาติดลบไม่ได้: วันที่ 20 เมษายน 2020 สัญญาน้ำมัน WTI ส่งมอบเดือนพฤษภาคมปิดที่ −\$37.63 ต่อบาร์เรลเพราะที่เก็บเต็ม และราคาไฟติดลบได้เมื่อลมหรือแดดผลิตเกินความต้องการ แบบจำลอง jump บนลอการิทึมของราคาให้ราคาติดลบไม่ได้เลย ช่วงราคาต่ำสุดจึงถูกประเมินผิด

ใช้ทำอะไรบนโต๊ะจริง

เจ้าของคลังก๊าซใช้สมการคลังตั้งราคาค่าเช่าคลังและตัดสินใจอัดดึงรายวัน โดยล็อกส่วนต่างตามฤดูด้วย futures ส่วนบริษัทไฟฟ้าและเทรดเดอร์ใช้สมการสองสถานะตีราคาสัญญา tolling และตัดสินใจเดินเครื่องรายชั่วโมง โรงงานที่ใช้ไฟมากทำ swap เพื่อให้งบต้นทุนรู้ล่วงหน้า ทำไมไม่ใช้ Black–Scholes กับไฟฟ้าตรง ๆ? เพราะ Black–Scholes สร้าง option ซ้ำด้วยการถือของอ้างอิงแล้วปรับสัดส่วนไปเรื่อย ๆ แต่ไฟฟ้าของชั่วโมงหน้าถือไว้ไม่ได้ ราคาไฟแต่ละชั่วโมงจึงเป็นสินค้าคนละตัว และราคายังถูกดึงกลับกับกระโดด ซึ่งผิดสมมติฐานทั้งสองข้อ

function finite(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(name + ' must be a finite number');
  return x;
}
function nonNegative(name, x) {
  if (finite(name, x) < 0) throw new RangeError(name + ' must not be negative');
  return x;
}

// Summer-to-winter storage deal: buy Q, lose a fraction in storage, sell the rest; cash counted on the sale date.
function storageDeal({Q, buy, sell, cin, cout, r, T, loss}) {
  for (const [k, v] of Object.entries({Q, buy, sell, cin, cout, r, T})) nonNegative(k, v);
  if (finite('loss', loss) < 0 || loss >= 1) throw new RangeError('loss must be in 0 to 1');
  const sold = Q * (1 - loss);
  const cost = Q * buy + Q * cin + sold * cout + Q * buy * r * T;
  return {sold, revenue: sold * sell, cost, profit: sold * sell - cost, perUnit: (sold * sell - cost) / sold, breakeven: cost / sold};
}

// Fixed price of a swap: the discount-weighted average of the forward prices (equal volumes).
function swapFixed(discount, forward) {
  if (!Array.isArray(discount) || discount.length === 0 || discount.length !== forward.length) throw new RangeError('discount and forward need the same non-empty length');
  let num = 0, den = 0;
  discount.forEach((d, i) => { nonNegative('discount', d); num += d * finite('forward', forward[i]); den += d; });
  return num / den;
}

// One-period storage: empty unit today, sell next period in one of two branches (weights w, 1 - w).
function storageStep({spot, up, down, w, delta, move}) {
  if (!(w > 0 && w < 1)) throw new RangeError('w must be strictly between 0 and 1');
  const next = w * Math.max(0, up - move) + (1 - w) * Math.max(0, down - move);
  return {expectedNext: next, value: Math.max(0, -spot - move + delta * next)};
}

// Gas plant: spark spread, margin and profit for a block of MW over hours.
function plant({heatRate, gas, varCost, power, MW, hours}) {
  const spark = power - nonNegative('heatRate', heatRate) * nonNegative('gas', gas);
  const mwh = nonNegative('MW', MW) * nonNegative('hours', hours);
  return {mwh, spark, margin: spark - varCost, profit: mwh * Math.max(spark - varCost, 0), gasBreakeven: (power - varCost) / heatRate};
}

// Block profits with a start-up cost Cu and a shut-down cost Cd: best value when the plant starts "on".
function dispatch(profits, Cu, Cd) {
  nonNegative('Cu', Cu); nonNegative('Cd', Cd);
  let on = 0, off = 0;                            // value after the last block
  for (let h = profits.length - 1; h >= 0; h--) {
    const p = finite('profit', profits[h]);
    [on, off] = [Math.max(p + on, -Cd + off), Math.max(off, -Cu + p + on)];
  }
  return on;
}

// Best mode per block: full load or low load, each with its own MWh and cost per MWh.
function bestMode(power, modes) {
  return Math.max(...modes.map(m => m.mwh * (power - m.cost)));
}

  • ส่วนต่าง \$14,000 บนจอเหลือกำไรจริง \$10,970 เมื่อหักของหาย ค่าอัดดึง และดอกเบี้ย และราคาคุ้มทุนคือ 3.0806
  • cash-and-carry ให้ราคาล่วงหน้าของก๊าซแค่เพดาน เพราะยืมก๊าซมาขายไม่ได้ ส่วนที่เกินเพดานคือค่าเช่าคลัง ราคาคงที่ของ swap คือค่าเฉลี่ยของราคาล่วงหน้าที่ถ่วงด้วยตัวคูณคิดลด (3.5980)
  • คลังก๊าซคือ option ที่มีสองสถานะ ราคากับก๊าซในคลัง และข้อจำกัดความจุกับท่อผูกวันนี้กับวันหน้า
  • โรงไฟฟ้าคือ call บน spark spread สิทธิ์ที่จะไม่เดินมีค่า (16,000 เทียบ 11,000) แต่ค่าติดเครื่องทำให้ช่วงไม่แยกกัน (9,000 ไม่ใช่ 12,000) และโหมดกำลังต่ำเพิ่มค่าเป็น 9,750 ค่าเช่าใน tolling ไม่เปลี่ยนการตัดสินใจ
  • ราคาก๊าซถูกดึงกลับจน variance มีเพดาน $\xi^2/(2\kappa)$ ราคาไฟต้องมี jump และ hedge แก้ความเสี่ยงราคาได้ แต่ไม่แก้ปริมาณกับ basis
