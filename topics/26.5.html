26.5 The Frisch–Waugh–Lovell Theorem

เติมคอลัมน์ใหม่เข้า regression ทีละขั้นได้คำตอบเดียวกับการคำนวณใหม่ทั้งหมดทุกหลัก ถ้าหักส่วนที่ model เดิมอธิบายได้ออกจากคอลัมน์ใหม่ก่อน และเครื่องมือชุดเดียวกันบอกว่าค่าประมาณของ factor return คลาดได้แค่ไหน

ทีมความเสี่ยงของกองทุนแห่งหนึ่งใช้ factor model อธิบายว่าวันนี้หุ้นแต่ละตัวขึ้นหรือลงเพราะอะไร factor model แยกผลตอบแทนของหุ้นเป็นสองส่วน ส่วนแรกมาจากแรงร่วมไม่กี่ตัวที่หุ้นทุกตัวโดนพร้อมกัน แรงร่วมแต่ละตัวเรียกว่า factor ส่วนที่สองเป็นเรื่องเฉพาะของหุ้นตัวนั้น model ที่ทีมใช้อยู่มี factor สองตัว:

  • market: แรงที่หุ้นทุกตัวโดนเท่ากัน เช่นวันที่ทั้งตลาดขึ้นพร้อมกัน
  • momentum: หุ้นที่ขึ้นแรงในปีที่ผ่านมามักขยับไปด้วยกัน หุ้นแต่ละตัวมีคะแนน momentum ของตัวเอง คะแนนยิ่งสูง หุ้นยิ่งโดนแรงนี้มาก

นักวิจัยคนหนึ่งคิดคะแนนแบบใหม่ให้หุ้นทุกตัว หน้านี้เรียกคะแนนนี้ว่า “คุณสมบัติใหม่” เขาอยากรู้ว่าวันนี้หุ้นที่คะแนนใหม่สูงกว่ากันหนึ่งหน่วย ได้ผลตอบแทนต่างกันกี่ % ตัวเลขนี้เรียกว่า factor return ของคุณสมบัติใหม่ ข้อมูลที่มีคือหุ้น 12 ตัวในวันเดียว (ตารางอยู่ในขั้นที่ 1) มีคนคำนวณสองแบบ:

  • แบบทางลัด: ไม่แตะ model เดิม ใช้ model เดิมอธิบายผลตอบแทนวันนี้ก่อน ส่วนที่อธิบายไม่ได้เรียกว่า residual แล้วลากเส้นตรงที่ใกล้จุดที่สุดระหว่าง residual กับคะแนนใหม่ การลากเส้นแบบนี้เรียกว่า regress ความชันที่ได้คือ 0.5707% ต่อคะแนนหนึ่งหน่วย
  • แบบคำนวณใหม่ทั้งหมด: ใส่ market, momentum และคะแนนใหม่ลงไปพร้อมกัน แล้วหาตัวคูณของทั้งสามคอลัมน์ในครั้งเดียว ได้ 0.7496% ต่อคะแนนหนึ่งหน่วย

หน้านี้จะคำนวณทั้งสองตัวเลขให้ดูทีละขั้น คำถามคือ ใครถูก และสองตัวเลขต่างกันเพราะอะไร?

ลองตอบก่อนเปิดเฉลย

0.7496% ถูก ทางลัดได้ค่าที่หดเข้าหาศูนย์ และหดแบบนี้ทุกครั้ง ไม่ว่าคำตอบจริงจะเป็นบวกหรือลบ สาเหตุคือคะแนนใหม่มีส่วนที่ซ้ำกับ momentum หุ้นที่ momentum สูงมักมีคะแนนใหม่สูงด้วย model เดิมอธิบายส่วนที่ซ้ำนี้ไปแล้ว residual จึงไม่เหลืออะไรให้ส่วนนี้อธิบาย แต่ทางลัดยังนับส่วนที่ซ้ำไว้ในตัวหารของความชัน ความชันจึงเล็กลงด้วยตัวคูณ 0.7613 (ขั้นที่ 5 คำนวณตัวคูณนี้):

\[0.7496\times0.7613=0.5707.\]

ทางแก้คือหักส่วนที่ซ้ำออกจากคะแนนใหม่ก่อน แล้วค่อยลากเส้น วิธีนี้ได้ 0.7496% ตรงทุกหลัก และได้ residual ชุดเดียวกับการคำนวณใหม่ทั้งหมดด้วย ข้อเท็จจริงนี้มีชื่อว่าทฤษฎีบท Frisch–Waugh–Lovell (FWL)

ภาพรวมก่อนลงสูตร

ทำไมไม่คำนวณใหม่ทั้งหมดไปเลย? เพราะ factor model ที่ใช้งานจริงมีตัวเลขย้อนหลังหลายปี รายงานความเสี่ยงทุกฉบับอ้างอิงตัวเลขเหล่านั้น ถ้าเติมคอลัมน์ใหม่แล้วคำนวณใหม่ทั้งหมด ตัวเลขเก่าทุกตัวจะขยับ ทีมจึงอยากทำเป็นขั้น คือเก็บ model เดิมไว้ตามเดิม แล้วถามแค่ว่าคุณสมบัติใหม่อธิบายส่วนที่เหลือได้แค่ไหน

ทฤษฎีบท Frisch–Waugh–Lovell (เรียกสั้น ๆ ว่า FWL ตามชื่อนักเศรษฐมิติสามคนที่พิสูจน์มัน) บอกว่าทำเป็นขั้นได้ และได้ตัวเลขของคุณสมบัติใหม่ตรงกับการคำนวณใหม่ทั้งหมดทุกหลัก แต่มีเงื่อนไขหนึ่งข้อที่คนข้ามบ่อย คือต้องหักส่วนที่ model เดิมอธิบายได้ออกจากทั้งสองฝั่ง:

  • หักออกจากผลตอบแทน ได้ residual ของผลตอบแทน
  • หักออกจากคุณสมบัติใหม่ด้วย ได้ส่วนของคุณสมบัติใหม่ที่ model เดิมไม่มี

แล้วค่อย regress ส่วนที่เหลือของผลตอบแทนบนส่วนที่เหลือของคุณสมบัติใหม่ ทางลัดใน hook ทำแค่ข้อแรก จึงพลาด

รูปข้างล่างคือสองขั้นนี้กับข้อมูลของหน้านี้ แผงซ้ายหักส่วนที่ model เดิมอธิบายได้ออกจากคุณสมบัติใหม่ แผงขวาวาดผลตอบแทนที่เหลือเทียบกับคุณสมบัติที่เหลือ ความชันของเส้นในแผงขวาคือคำตอบ

หน้านี้เดินตามลำดับนี้:

  • ขั้นที่ 1: คำนวณทีเดียวทั้งสามคอลัมน์ เก็บไว้เป็นคำตอบอ้างอิง
  • ขั้นที่ 2–4: วิธีทีละขั้น การพิสูจน์ว่าได้ค่าเดียวกัน และตัวเลขจริง
  • ขั้นที่ 5–7: ทางลัดสองแบบที่พังคนละแบบ และตัวเลขของ model เดิมที่เอนไป
  • ขั้นที่ 8–9: กรณีที่ส่วนเฉพาะตัวของหุ้นแต่ละตัวแกว่งแรงไม่เท่ากัน ซึ่งให้สูตรว่าค่าประมาณของ factor return คลาดจากค่าจริงได้แค่ไหน
ศัพท์ที่ใช้ในหัวข้อนี้
Factor model
แบบจำลองที่เขียนผลตอบแทนของหุ้นแต่ละตัวเป็นผลรวมของแรงร่วมไม่กี่ตัว (factor) คูณด้วยความไวของหุ้นต่อแรงนั้น บวกส่วนเฉพาะตัวของหุ้น ใช้แยกว่าผลตอบแทนและความเสี่ยงมาจากไหน รายละเอียดอยู่ที่สมการ factor model
Loading
ความไวของหุ้นหนึ่งตัวต่อ factor หนึ่งตัว เช่นคะแนน momentum ของหุ้น หุ้นทุกตัวมี loading ของ market เท่ากับ 1 คำว่า exposure หมายถึงสิ่งเดียวกัน แต่มักใช้กับทั้งพอร์ต
Factor return
ผลตอบแทนที่ factor หนึ่งตัวจ่ายในวันนั้น ต่อ loading หนึ่งหน่วย ไม่มีใครเห็นตัวเลขนี้ตรง ๆ ต้องประมาณจากผลตอบแทนของหุ้นทุกตัวในวันเดียวกัน
Regression (regress)
การหาตัวคูณของคอลัมน์ข้อมูล ที่ทำให้ผลรวมของคอลัมน์ใกล้ $\mathbf y$ ที่สุด “regress $\mathbf y$ บน $\mathbf x$” คือหาตัวคูณ $b$ ที่ทำให้ $b\mathbf x$ ใกล้ $\mathbf y$ ที่สุด หน้านี้วัดความใกล้ด้วยผลรวมกำลังสองของส่วนต่าง ซึ่งเรียกว่า OLS
Residual
ส่วนที่ regression อธิบายไม่ได้ คือ $\mathbf y$ ลบส่วนที่คอลัมน์ทายได้ ใน factor model residual คือส่วนเฉพาะตัวของหุ้น
Frisch–Waugh–Lovell (FWL)
ทฤษฎีบทที่บอกว่า ตัวคูณของคอลัมน์ใหม่ใน regression เต็ม เท่ากับตัวคูณที่ได้จากการ regress ส่วนที่เหลือของ $\mathbf y$ บนส่วนที่เหลือของคอลัมน์ใหม่ เมื่อ “ส่วนที่เหลือ” หมายถึงหลังหักสิ่งที่คอลัมน์เดิมอธิบายได้ออกจากทั้งคู่ ทีมใช้มันเป็นใบอนุญาตให้ประมาณ model เป็นขั้น
Projection $\mathbf P_1$
matrix ที่เอาไปคูณ vector แล้วได้ส่วนของ vector นั้นที่คอลัมน์ของ model เดิมทายได้ เหมือนเงาของ vector ที่ตกลงบนพื้นที่ของคอลัมน์เดิม
Residual maker $\mathbf M$
matrix $\mathbf M=\mathbf I-\mathbf P_1$ เอาไปคูณ vector ใดก็ได้ แล้วได้ส่วนของ vector นั้นที่คอลัมน์ของ model เดิมอธิบายไม่ได้ คูณซ้ำอีกครั้งก็ได้ผลเดิม เพราะหักไปแล้วไม่มีอะไรให้หักอีก
Residualize
การหักส่วนที่คอลัมน์เดิมอธิบายได้ออกจากคอลัมน์ใหม่ ก่อนนำคอลัมน์ใหม่ไปใช้ เป็นขั้นกลางที่ข้ามไม่ได้
Normal equations
สมการ $\mathbf X^{\mathsf T}\mathbf e=\mathbf 0$ ที่ได้จากการตั้งอนุพันธ์ของผลรวมกำลังสองของ residual เป็นศูนย์ แปลว่า residual ของ OLS ตั้งฉากกับทุกคอลัมน์
Omitted variable bias
ความเอนของตัวคูณ เมื่อ model ขาดคอลัมน์ที่ขยับไปด้วยกันกับคอลัมน์ที่มีอยู่ คอลัมน์ที่มีอยู่จะรับเครดิตของคอลัมน์ที่ขาดไป
Variance inflation factor (VIF)
จำนวนเท่าที่ variance ของตัวคูณหนึ่งตัวโตขึ้น เพราะคอลัมน์ของมันทับกับคอลัมน์อื่น เท่ากับ $1/(1-\rho^2)$ เมื่อ $\rho$ คือ correlation กับคอลัมน์ที่ทับ
Weighted least squares (WLS)
least squares ที่ให้น้ำหนักแต่ละแถวเป็น $1/\sigma_i^2$ เมื่อ $\sigma_i$ คือความผันผวนของส่วนเฉพาะตัวของหุ้น $i$ หุ้นที่แกว่งแรงจึงได้น้ำหนักน้อยลง เป็นวิธีที่ใช้ประมาณ factor return ทุกวัน
Factor-mimicking portfolio
พอร์ตหุ้นที่มี exposure หนึ่งหน่วยต่อ factor ตัวหนึ่ง และศูนย์ต่อ factor ตัวอื่น โดยมีความเสี่ยงเฉพาะตัวต่ำที่สุดในบรรดาพอร์ตแบบนี้ ผลตอบแทนของพอร์ตนี้คือค่าประมาณของ factor return
Standard error (SE)
SD ของค่าประมาณ บอกว่าค่าประมาณแกว่งรอบค่าจริงได้ราวแค่ไหน SD (standard deviation) คือขนาดการแกว่งรอบค่าเฉลี่ย
$\mathbf G$
covariance ของความคลาดของค่าประมาณ factor return มีสูตร $\mathbf G=(\mathbf B^{\mathsf T}\boldsymbol\Omega_\epsilon^{-1}\mathbf B)^{-1}$ รากที่สองของตัวเลขบนแนวทแยงคือ SE ของ factor แต่ละตัว
Push-out
การเติม factor ใหม่โดยหักส่วนที่ factor เดิมอธิบายได้ออกจาก loading ใหม่ก่อน ตัวเลขของ factor เดิมจึงไม่ขยับ รายละเอียดอยู่ที่rotation, projection และ push-out

ขั้นที่ 2 — ทำทีละขั้น: สามขั้น และขั้นกลางที่ข้ามไม่ได้

ขั้นที่ 1 ได้คำตอบแล้ว แต่ต้องคำนวณทุกคอลัมน์ใหม่หมด ขั้นนี้เขียนวิธีที่ทีมอยากใช้ คือเก็บ model เดิมไว้ แล้วเติมคุณสมบัติใหม่ทีหลัง วิธีนี้มีสามขั้น:

  1. ใช้ model เดิมอธิบายผลตอบแทน แล้วเก็บส่วนที่เหลือไว้
  2. ขั้นกลาง: หักส่วนที่ model เดิมอธิบายได้ออกจากคุณสมบัติใหม่ด้วย
  3. regress ผลตอบแทนที่เหลือบนคุณสมบัติที่เหลือ

ข้อ 1 กับข้อ 2 ใช้เครื่องมือเดียวกัน คือ “หักส่วนที่ model เดิมอธิบายได้ออก” ขั้นนี้เขียนเครื่องมือนั้นเป็น matrix เพราะขั้นถัดไปต้องใช้ matrix นี้พิสูจน์ ให้ $\mathbf z$ เป็น vector 12 ช่องใดก็ได้ เช่นผลตอบแทน $\mathbf y$ หรือคุณสมบัติใหม่ $\mathbf x_2$ เครื่องมือนี้ทำงานสองจังหวะ:

  • regress $\mathbf z$ บน $\mathbf X_1$ ด้วยสูตร OLS เดียวกับขั้นที่ 1 ได้ตัวคูณ $(\mathbf X_1^{\mathsf T}\mathbf X_1)^{-1}\mathbf X_1^{\mathsf T}\mathbf z$ เอา $\mathbf X_1$ คูณตัวคูณนี้ ได้ส่วนของ $\mathbf z$ ที่ model เดิมทายได้ เขียนย่อว่า $\mathbf P_1\mathbf z$
  • เอา $\mathbf z$ ลบส่วนที่ทายได้ ได้ส่วนที่เหลือ เขียนย่อว่า $\mathbf M\mathbf z$

จากนั้นใช้ $\mathbf M$ กับทั้ง $\mathbf y$ และ $\mathbf x_2$ แล้ว regress ตัวหนึ่งบนอีกตัวหนึ่ง ทั้งหมดเขียนเป็นสูตรได้ดังนี้

\[ \begin{aligned} \mathbf P_1&=\mathbf X_1(\mathbf X_1^{\mathsf T}\mathbf X_1)^{-1}\mathbf X_1^{\mathsf T},\\ \mathbf M&=\mathbf I-\mathbf P_1,\\ \hat{\boldsymbol\eta}_1&=\mathbf M\mathbf y,\quad\tilde{\mathbf x}_2=\mathbf M\mathbf x_2,\\ \hat\gamma_2&=\frac{\tilde{\mathbf x}_2^{\mathsf T}\hat{\boldsymbol\eta}_1}{\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2},\\ \hat{\boldsymbol\eta}_2&=\hat{\boldsymbol\eta}_1-\tilde{\mathbf x}_2\hat\gamma_2. \end{aligned} \]

$\mathbf M$ ลบทุกอย่างที่ market กับ momentum พูดได้ “ทุกอย่างที่พูดได้” คือทุก vector ที่เขียนเป็น market คูณตัวเลขหนึ่ง บวก momentum คูณอีกตัวเลขหนึ่ง vector พวกนี้รวมกันเรียกว่า range ของ $\mathbf X_1$ การพิสูจน์ในขั้นถัดไปใช้คุณสมบัติของ $\mathbf M$ สามข้อ:

  • $\mathbf M\mathbf X_1=\mathbf 0$ เพราะ model เดิมทายคอลัมน์ของตัวเองได้ครบ ไม่มีอะไรเหลือ เขียนเป็นสูตรได้ $\mathbf P_1\mathbf X_1=\mathbf X_1(\mathbf X_1^{\mathsf T}\mathbf X_1)^{-1}\mathbf X_1^{\mathsf T}\mathbf X_1=\mathbf X_1$ เพราะ $(\mathbf X_1^{\mathsf T}\mathbf X_1)^{-1}$ คูณกับ $\mathbf X_1^{\mathsf T}\mathbf X_1$ ได้ $\mathbf I$
  • $\mathbf M\mathbf M=\mathbf M$ เพราะหักแล้วหักซ้ำก็ไม่มีอะไรให้หักอีก (เหตุผลเดียวกับที่ projection ทำซ้ำแล้วได้ผลเดิม)
  • $\mathbf M^{\mathsf T}=\mathbf M$ คือ $\mathbf M$ สมมาตร เพราะ transpose ของสูตร $\mathbf P_1$ ได้สูตรเดิม ($\mathbf X_1^{\mathsf T}\mathbf X_1$ สมมาตร inverse ของมันจึงสมมาตรด้วย)

ดังนั้น $\hat{\boldsymbol\eta}_1=\mathbf M\mathbf y$ คือ residual ของ model เดิม และ $\tilde{\mathbf x}_2=\mathbf M\mathbf x_2$ คือส่วนของคุณสมบัติใหม่ที่ model เดิมไม่มี ซึ่งก็คือเส้นส้มในรูปแรก ในภาษาเรขาคณิต $\tilde{\mathbf x}_2$ ตั้งฉากกับคอลัมน์ market และ momentum คือผลคูณจุดกับแต่ละคอลัมน์เป็นศูนย์

สูตรของ $\hat\gamma_2$ คือการ regress $\hat{\boldsymbol\eta}_1$ บน $\tilde{\mathbf x}_2$ คอลัมน์เดียว ทำไมไม่ต้องมีค่าคงที่? เพราะคอลัมน์ market ถูกหักออกไปแล้ว ทั้งสอง vector จึงมีค่าเฉลี่ยเป็นศูนย์อยู่แล้ว ตัวคูณ $g$ ที่ดีที่สุดคือค่าที่ทำให้ $\lVert\hat{\boldsymbol\eta}_1-\tilde{\mathbf x}_2g\rVert^2$ เล็กที่สุด ตั้งอนุพันธ์เทียบ $g$ เป็นศูนย์ได้ $-2\tilde{\mathbf x}_2^{\mathsf T}(\hat{\boldsymbol\eta}_1-\tilde{\mathbf x}_2g)=0$ ย้ายข้างแล้วได้ผลหารของผลคูณจุดสองตัวในสูตร จึงไม่ต้อง invert matrix เลย ส่วน $\hat{\boldsymbol\eta}_2$ คือ residual ที่เหลือหลังข้อ 3 วิธีทีละขั้นจะเก็บมันไว้เป็นส่วนเฉพาะตัวของหุ้น

ขั้นที่ 3 — พิสูจน์: ทำไมสองทางได้ตัวเดียวกัน

ตอนนี้มีสองวิธีแล้ว คือคำนวณทีเดียว (ขั้นที่ 1) กับทีละขั้น (ขั้นที่ 2) ขั้นนี้แสดงว่าสองวิธีให้ตัวคูณของคุณสมบัติใหม่ตัวเดียวกันเสมอ ไม่ใช่บังเอิญตรงกับข้อมูลชุดนี้ แผนคือเริ่มจากสมการของ regression เต็ม แล้วคูณทั้งสองข้างด้วย $\mathbf M$ เพื่อลบส่วนของ model เดิมทิ้ง แล้วดูว่าอะไรเหลือ

ต้องใช้ข้อเท็จจริงหนึ่งข้อของ OLS: residual $\mathbf e$ ของ regression เต็มตั้งฉากกับทุกคอลัมน์ เหตุผลคือ OLS เลือก $\hat{\boldsymbol\beta}$ ที่ทำให้ $\lVert\mathbf e\rVert^2$ เล็กที่สุด ตั้งอนุพันธ์เทียบ $\hat{\boldsymbol\beta}$ เป็นศูนย์ได้ $-2\mathbf X^{\mathsf T}\mathbf e=\mathbf 0$ สมการชุดนี้เรียกว่า normal equations แยกเขียนเป็นคอลัมน์เก่ากับคอลัมน์ใหม่ได้ดังนี้

\[ \begin{aligned} \mathbf y&=\mathbf X_1\hat{\boldsymbol\beta}_1+\mathbf x_2\hat\beta_2+\mathbf e,\\ \mathbf X_1^{\mathsf T}\mathbf e&=\mathbf 0,\\ \mathbf x_2^{\mathsf T}\mathbf e&=0. \end{aligned} \]

คูณสมการแรกด้วย $\mathbf M$ ทั้งสองข้าง $\mathbf M$ ทำกับแต่ละก้อนต่างกัน ก้อน $\mathbf X_1\hat{\boldsymbol\beta}_1$ หายไป เพราะ $\mathbf M\mathbf X_1=\mathbf 0$ ก้อน $\mathbf x_2\hat\beta_2$ กลายเป็น $\tilde{\mathbf x}_2\hat\beta_2$ ตามนิยาม ส่วนก้อน $\mathbf e$ ไม่เปลี่ยน เพราะ $\mathbf e$ ตั้งฉากกับ $\mathbf X_1$ อยู่แล้ว ไม่มีอะไรให้หัก

\[ \begin{aligned} \mathbf P_1\mathbf e&=\mathbf X_1(\mathbf X_1^{\mathsf T}\mathbf X_1)^{-1}\mathbf X_1^{\mathsf T}\mathbf e\\ &=\mathbf 0,\\ \mathbf M\mathbf e&=\mathbf e-\mathbf P_1\mathbf e=\mathbf e,\\ \mathbf M\mathbf y&=\tilde{\mathbf x}_2\hat\beta_2+\mathbf e. \end{aligned} \]

สมการนี้ยังมี $\mathbf e$ ปนอยู่ จะดึง $\hat\beta_2$ ออกมาต้องกำจัด $\mathbf e$ ก่อน วิธีคือคูณทั้งสองข้างด้วย $\tilde{\mathbf x}_2^{\mathsf T}$ เพราะ $\tilde{\mathbf x}_2$ ตั้งฉากกับ $\mathbf e$ (แถวแรกข้างล่าง ใช้ $\mathbf M^{\mathsf T}=\mathbf M$)

\[ \begin{aligned} \tilde{\mathbf x}_2^{\mathsf T}\mathbf e&=\mathbf x_2^{\mathsf T}\mathbf M\mathbf e=\mathbf x_2^{\mathsf T}\mathbf e=0,\\ \tilde{\mathbf x}_2^{\mathsf T}\mathbf M\mathbf y&=\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2\,\hat\beta_2,\\ \hat\beta_2&=\frac{\tilde{\mathbf x}_2^{\mathsf T}\hat{\boldsymbol\eta}_1}{\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2}=\hat\gamma_2,\\ \hat{\boldsymbol\eta}_1-\tilde{\mathbf x}_2\hat\gamma_2&=\mathbf e. \end{aligned} \]

ใจความของการพิสูจน์คือ $\mathbf M$ ลบ model เดิมออกจากสมการของ regression เต็มได้ทั้งก้อน โดยไม่แตะ $\hat\beta_2$ และไม่แตะ $\mathbf e$ สิ่งที่เหลือ $\mathbf M\mathbf y=\tilde{\mathbf x}_2\hat\beta_2+\mathbf e$ หน้าตาเหมือน regression ของ $\hat{\boldsymbol\eta}_1$ บน $\tilde{\mathbf x}_2$ คอลัมน์เดียว ที่ residual ตั้งฉากกับคอลัมน์นั้น ซึ่งคือเงื่อนไขของ OLS พอดี คำตอบของ regression นั้นจึงต้องเป็น $\hat\beta_2$ จุดที่ต้องระวังคือ $\mathbf M\mathbf e=\mathbf e$ ข้อนี้ใช้ได้เพราะ normal equations บอกว่า $\mathbf e$ ตั้งฉากกับ $\mathbf X_1$ อยู่แล้ว

แถวสุดท้ายคือ $\mathbf M\mathbf y=\tilde{\mathbf x}_2\hat\beta_2+\mathbf e$ ที่ย้ายข้าง มันบอกว่า residual ของวิธีทีละขั้นคือ $\mathbf e$ ของ regression เต็มทุกตัว สองทางจึงไม่ได้แค่ใกล้กัน มันคือการคำนวณเดียวกันที่จัดลำดับต่างกัน อีกมุมหนึ่ง: คอลัมน์ $[\mathbf X_1\ \tilde{\mathbf x}_2]$ กินพื้นที่เดียวกับ $[\mathbf X_1\ \mathbf x_2]$ เพราะ $\tilde{\mathbf x}_2$ คือ $\mathbf x_2$ ลบด้วย market คูณตัวเลขหนึ่งและ momentum คูณอีกตัวเลขหนึ่ง ค่าที่ fit ได้และ residual จึงเหมือนกัน และเพราะ $\tilde{\mathbf x}_2$ ตั้งฉากกับ $\mathbf X_1$ ตัวคูณของมันจึงคำนวณแยกได้

ขั้นที่ 4 — ตัวเลขของการทำทีละขั้น

ขั้นที่ 3 พิสูจน์แล้วว่าวิธีทีละขั้นต้องได้ 0.7496 ขั้นนี้ลองทำจริงกับตาราง 12 หุ้น เพื่อให้เห็นตัวเลขทุกตัวระหว่างทาง

โจทย์ให้อะไรมาบ้าง: ตารางของขั้นที่ 1 ทำสามอย่างตามลำดับ

  1. regress $\mathbf y$ บน (1, momentum) ได้ตัวคูณของ model เดิม $\hat{\boldsymbol\gamma}_1$ แล้วเก็บ residual $\hat{\boldsymbol\eta}_1$
  2. regress $\mathbf x_2$ บน (1, momentum) ได้ตัวคูณ $\boldsymbol\delta$ ซึ่งคือเส้นดำในแผงซ้ายของรูปแรก แล้วเก็บ residual $\tilde{\mathbf x}_2$
  3. ใช้สูตรผลหารของผลคูณจุดจากขั้นที่ 2

ตัวคูณของสอง regression ในข้อ 1 กับข้อ 2 คำนวณด้วยสูตร OLS เดียวกับขั้นที่ 1 (โค้ดท้ายหน้าทำให้) residual ของหุ้นแต่ละตัวคือค่าจริงลบค่าที่เส้นทาย ข้างล่างแสดงหุ้นตัวที่ 1 (momentum 1.10, $\mathbf x_2$ เท่ากับ −0.96, ผลตอบแทน 0.3333%) ให้ดูเป็นตัวอย่าง

\[ \begin{aligned} \hat{\boldsymbol\gamma}_1&=(0.4235,\ 1.1013)\%,\\ \boldsymbol\delta&=(0.1208,\ 0.4609),\\ \hat\eta_{1,1}&=0.3333-0.4235\\ &\quad-1.1013(1.10)=-1.3016,\\ \tilde x_{2,1}&=-0.96-0.1208\\ &\quad-0.4609(1.10)=-1.5878. \end{aligned} \]

ทำแบบนี้ครบ 12 หุ้น แล้วนำสอง vector มาคูณจุดกัน

\[ \begin{aligned} \tilde{\mathbf x}_2&=(-1.5878,\ 1.4125,\\ &\qquad 0.2782,\ \dots),\\ \tilde{\mathbf x}_2^{\mathsf T}\hat{\boldsymbol\eta}_1&=(-1.5878)(-1.3016)\\ &\quad+\dots=6.2133,\\ \tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2&=(-1.5878)^2+\dots\\ &=8.2894,\\ \hat\gamma_2&=\frac{6.2133}{8.2894}=0.7496\%. \end{aligned} \]

คำตอบ: ได้ 0.7496% ตรงกับการทำทีเดียว residual ทั้ง 12 ตัวของขั้นสุดท้ายก็ตรงกับ residual ของ regression เต็ม โค้ดวัดส่วนต่างได้ไม่เกิน $1.2\times10^{-15}$ จุดเปอร์เซ็นต์ ซึ่งเป็นแค่เศษจากการปัดทศนิยมในเครื่อง แต่ตัวคูณของคอลัมน์เดิมไม่ตรงกัน: model เดิมให้ $\hat{\boldsymbol\gamma}_1=(0.4235, 1.1013)$ ส่วน model เต็มให้ $\hat{\boldsymbol\beta}_1=(0.3330, 0.7558)$ เพราะทฤษฎีบทรับประกันเฉพาะคอลัมน์ที่เติมเข้ามา ขั้นที่ 6 จะอธิบายว่าส่วนต่างนี้มาจากไหน

ตรวจเองใน 10 วินาที: $\tilde{\mathbf x}_2$ ต้องตั้งฉากกับทั้งสองคอลัมน์ของ model เดิม ตั้งฉากกับคอลัมน์ market (เลข 1 ทุกแถว) แปลว่าผลรวมของ $\tilde{\mathbf x}_2$ เป็นศูนย์ และตั้งฉากกับ momentum แปลว่าผลคูณจุดกับ momentum เป็นศูนย์ โค้ดท้ายหน้าได้ทั้งสองค่าเล็กกว่า $10^{-15}$ ในรูปแผงซ้าย ผลรวมเป็นศูนย์คือ เส้นส้มเหนือเส้นดำกับใต้เส้นดำยาวรวมกันเท่ากันพอดี

ขั้นที่ 5 — ข้ามขั้นกลาง: ค่าหดเข้าหาศูนย์เสมอ

ทางลัดของ hook ทำข้อ 1 ของขั้นที่ 2 ถูก คือใช้ผลตอบแทนที่เหลือ $\hat{\boldsymbol\eta}_1$ แต่ข้ามข้อ 2 คือใช้คะแนนดิบ $\mathbf x_2$ แทน $\tilde{\mathbf x}_2$ ขั้นนี้ดูว่าการข้ามนั้นเปลี่ยนตัวตั้งและตัวหารของสูตรอย่างไร และทำไมผลจึงเล็กลงทุกครั้ง เขียน $\mathbf x_2$ ดิบเป็นสองชิ้น คือส่วนที่ model เดิมทายได้ $\mathbf P_1\mathbf x_2$ บวกส่วนใหม่ $\tilde{\mathbf x}_2$ แล้วดูว่าแต่ละชิ้นไปอยู่ที่ไหนในสูตร

\[ \begin{aligned} \hat\gamma_2^{\rm skip}&=\frac{\mathbf x_2^{\mathsf T}\hat{\boldsymbol\eta}_1}{\mathbf x_2^{\mathsf T}\mathbf x_2},\\ \mathbf x_2&=\mathbf P_1\mathbf x_2+\tilde{\mathbf x}_2,\\ \mathbf x_2^{\mathsf T}\hat{\boldsymbol\eta}_1&=\tilde{\mathbf x}_2^{\mathsf T}\hat{\boldsymbol\eta}_1=6.2133,\\ \mathbf x_2^{\mathsf T}\mathbf x_2&=\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2+\lVert\mathbf P_1\mathbf x_2\rVert^2,\\ \hat\gamma_2^{\rm skip}&=\hat\gamma_2\times k,\\ k&=\frac{\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2}{\mathbf x_2^{\mathsf T}\mathbf x_2}. \end{aligned} \]

ตัวตั้งไม่เปลี่ยน เพราะ $\hat{\boldsymbol\eta}_1$ ตั้งฉากกับ range ของ $\mathbf X_1$ ชิ้น $\mathbf P_1\mathbf x_2$ อยู่ใน range นั้น ผลคูณจุดของมันกับ $\hat{\boldsymbol\eta}_1$ จึงเป็นศูนย์ พูดง่าย ๆ คือ ส่วนที่ซ้ำกับ model เดิมไม่มีอะไรเหลือให้อธิบายในผลตอบแทนที่เหลือ แต่ตัวหารโตขึ้น เพราะสองชิ้นตั้งฉากกัน ความยาวกำลังสองจึงบวกกันแบบ Pythagoras ($\mathbf P_1\mathbf M=\mathbf P_1-\mathbf P_1\mathbf P_1=\mathbf 0$) ตัวหารของทางลัดจึงนับส่วนที่ซ้ำเข้าไปด้วย ตัวคูณ $k$ ไม่เกิน 1 เสมอ ค่าจึงหดเข้าหาศูนย์ ไม่ว่า $\hat\gamma_2$ จะบวกหรือลบ

ใส่ตัวเลข ตัวหารของทางลัดคือผลรวมกำลังสองของคอลัมน์ $\mathbf x_2$ ในตาราง ส่วน $\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2=8.2894$ มาจากขั้นที่ 4

\[ \begin{aligned} \mathbf x_2^{\mathsf T}\mathbf x_2&=(-0.96)^2+1.69^2\\ &\quad+\dots+0.07^2=10.888,\\ k&=\frac{8.2894}{10.888}=0.7613,\\ \hat\gamma_2^{\rm skip}&=0.7496\times0.7613\\ &=0.5707\%. \end{aligned} \]

$k$ เกี่ยวกับ correlation อย่างไร? correlation $\rho$ ระหว่าง momentum กับ $\mathbf x_2$ คือ 0.4812 (โค้ดท้ายหน้าคำนวณ) ถ้าค่าเฉลี่ยของ $\mathbf x_2$ เป็นศูนย์ $k$ จะเท่ากับ $1-\rho^2=1-0.4812^2=0.7684$ พอดี เพราะ regression เส้นตรงที่มีตัวแปรเดียวอธิบายความแกว่งของ $\mathbf x_2$ ได้สัดส่วน $\rho^2$ ส่วนที่เหลือคือ $1-\rho^2$ แต่ $\mathbf x_2$ มีค่าเฉลี่ย $-1.10/12=-0.0917$ ตัวหาร $\mathbf x_2^{\mathsf T}\mathbf x_2$ จึงมีก้อนของค่าเฉลี่ย $12\bar x_2^2=1.10^2/12=0.1008$ ติดมาด้วย ($\bar x_2$ คือค่าเฉลี่ยของ $\mathbf x_2$) ก้อนนี้คอลัมน์ market ดูดไปตั้งแต่แรก ความแกว่งรอบค่าเฉลี่ยจึงเหลือ $S_{xx}=10.888-0.1008=10.7872$ แล้ว $k=0.7684\times10.7872/10.888=0.7613$ ต่ำกว่า $1-\rho^2$ เล็กน้อย

ขั้นที่ 6 — model เดิมให้เครดิต momentum เกินจริงแค่ไหน

model เดิมซึ่งไม่มีคอลัมน์ใหม่ ให้ factor return ของ momentum 1.1013% (ขั้นที่ 4) แต่ model เต็มให้แค่ 0.7558% (ขั้นที่ 1) momentum ตัวเดียวกัน วันเดียวกัน แต่ตัวเลขต่างกันเกือบครึ่ง ส่วนต่างมาจากไหน? วิธีหาคือแทน $\mathbf y$ ของ regression เต็มลงในสูตร OLS ของ model เดิม แล้วดูทีละก้อน

\[ \begin{aligned} \hat{\boldsymbol\gamma}_1&=(\mathbf X_1^{\mathsf T}\mathbf X_1)^{-1}\mathbf X_1^{\mathsf T}\mathbf y,\\ \mathbf y&=\mathbf X_1\hat{\boldsymbol\beta}_1+\mathbf x_2\hat\beta_2+\mathbf e,\\ \hat{\boldsymbol\gamma}_1&=\hat{\boldsymbol\beta}_1+\boldsymbol\delta\,\hat\beta_2+\mathbf 0,\\ \boldsymbol\delta&=(\mathbf X_1^{\mathsf T}\mathbf X_1)^{-1}\mathbf X_1^{\mathsf T}\mathbf x_2. \end{aligned} \]

สูตร OLS ของ model เดิมทำกับแต่ละก้อนของ $\mathbf y$ ต่างกัน ก้อน $\mathbf X_1\hat{\boldsymbol\beta}_1$ ได้ $\hat{\boldsymbol\beta}_1$ คืนมาตรง ๆ เพราะ $(\mathbf X_1^{\mathsf T}\mathbf X_1)^{-1}\mathbf X_1^{\mathsf T}\mathbf X_1=\mathbf I$ ก้อน $\mathbf e$ หายไป เพราะ normal equations บอกว่า $\mathbf X_1^{\mathsf T}\mathbf e=\mathbf 0$ ก้อนที่น่าสนใจคือ $\mathbf x_2\hat\beta_2$ สูตรนี้ส่งก้อนนี้ไปเป็นเครดิตของคอลัมน์เดิม ด้วยอัตรา $\boldsymbol\delta$ ซึ่งก็คือตัวคูณของการ regress $\mathbf x_2$ บน (1, momentum) จากขั้นที่ 4 หรือเส้นดำในแผงซ้ายของรูปแรก ตัวเลขนี้บอกว่า หุ้นที่ momentum สูงกว่ากันหนึ่งหน่วย มีคุณสมบัติใหม่สูงกว่าโดยเฉลี่ย 0.4609 หน่วย

ใส่ตัวเลขของ momentum (ช่องที่สองของแต่ละ vector)

\[ \begin{aligned} \hat\gamma_{1,\rm mom}&=\hat\beta_{1,\rm mom}+\delta_{\rm mom}\hat\beta_2\\ &=0.7558+0.4609\times0.7496\\ &=0.7558+0.3455=1.1013,\\ \frac{1.1013}{0.7558}-1&=0.457=45.7\%. \end{aligned} \]

เมื่อ model ขาดคอลัมน์ใหม่ momentum จึงรับเครดิต 0.3455 จุดเปอร์เซ็นต์ที่เป็นของคุณสมบัติใหม่ไปเอง ตัวเลขเก่าไม่ได้คำนวณผิด มันเอนจริง (ความเอนแบบนี้เรียกว่า omitted variable bias) และการเพิ่มคอลัมน์คือการแก้ความเอนนั้น

แต่การมีสองคอลัมน์ที่ทับกันก็มีราคา คือค่าประมาณ $\hat\beta_2$ แกว่งมากขึ้น ขั้นที่ 3 ให้ $\hat\beta_2=\tilde{\mathbf x}_2^{\mathsf T}\mathbf y/\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2$ ถ้าส่วนเฉพาะตัวของทุกหุ้นมี variance $\sigma^2$ เท่ากันและไม่เกี่ยวกัน variance ของ $\hat\beta_2$ คือ $\sigma^2/\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2$ ตัวหารนี้คือ $(1-\rho^2)S_{xx}$ ซึ่งหดลงเมื่อ $\rho$ โตขึ้น เทียบกับกรณีที่ไม่ทับกันเลย ($\rho=0$) variance จึงโตขึ้น $1/(1-\rho^2)$ เท่า ตัวเลขนี้เรียกว่า variance inflation factor (VIF) ที่ $\rho=0.4812$ ได้ $1/(1-0.4812^2)=1/0.7684=1.301$ คือ variance โตขึ้น 30% ส่วน SE โต $\sqrt{1.301}=1.141$ เท่า ยังรับได้ แต่ถ้า $\rho=0.95$ จะได้ $1/(1-0.95^2)=10.26$ เท่า เรื่องเดียวกันเห็นได้จากสูตร $\sigma^2(\mathbf X^{\mathsf T}\mathbf X)^{-1}$ ของความคลาดใน multi-factor model: ยิ่งคอลัมน์เกือบซ้ำกัน $\mathbf X^{\mathsf T}\mathbf X$ ยิ่งเกือบหา inverse ไม่ได้

ขั้นที่ 7 — ทางลัดอีกแบบ: ค่าถูก แต่ residual ผิด

มีทางลัดอีกแบบที่คนใช้กัน คือทำข้อ 2 ของขั้นที่ 2 ถูก (ใช้ $\tilde{\mathbf x}_2$) แต่ข้ามข้อ 1 คือไม่หักส่วนของ model เดิมออกจากผลตอบแทนก่อน ขั้นนี้ดูว่าทางนี้ได้อะไรถูก และได้อะไรผิด

โจทย์ให้อะไรมาบ้าง: regress ผลตอบแทนดิบ $\mathbf y$ บน $\tilde{\mathbf x}_2$ ตรง ๆ แทน $\hat{\boldsymbol\eta}_1$ แล้วเก็บ $\mathbf y-\tilde{\mathbf x}_2\hat\gamma_2$ ไว้เป็นส่วนเฉพาะตัวของหุ้น เพื่อวัดว่า residual ใหญ่แค่ไหน ใช้ความยาว $\lVert\mathbf v\rVert$ ของ vector ซึ่งคือรากที่สองของผลรวมกำลังสองของทุกช่อง โค้ดท้ายหน้าคำนวณความยาวทั้งสองตัว

\[ \begin{aligned} \frac{\tilde{\mathbf x}_2^{\mathsf T}\mathbf y}{\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2}&=\frac{6.2133}{8.2894}=0.7496\%,\\ \lVert\mathbf y-\tilde{\mathbf x}_2\hat\gamma_2\rVert&=4.2088,\\ \lVert\mathbf e\rVert&=1.8360,\\ \frac{4.2088}{1.8360}&=2.29. \end{aligned} \]

คำตอบ: ตัวคูณถูกทุกหลัก เพราะ $\tilde{\mathbf x}_2$ ตั้งฉากกับ $\mathbf X_1$ ส่วนของ $\mathbf y$ ที่อยู่ใน range ของ $\mathbf X_1$ จึงไม่ถูกนับในผลคูณจุด เขียนเป็นสูตรได้ $\tilde{\mathbf x}_2^{\mathsf T}\mathbf y=\tilde{\mathbf x}_2^{\mathsf T}\mathbf M\mathbf y=\tilde{\mathbf x}_2^{\mathsf T}\hat{\boldsymbol\eta}_1=6.2133$ แต่ residual ใหญ่กว่าของจริง 2.29 เท่า เพราะทางนี้ไม่เคยหักสิ่งที่ market กับ momentum อธิบายได้ออกจาก $\mathbf y$ ส่วนที่ model เดิมทายได้ $\mathbf X_1\hat{\boldsymbol\gamma}_1$ จึงค้างอยู่ใน residual ทั้งก้อน ($\mathbf y-\tilde{\mathbf x}_2\hat\gamma_2=\mathbf X_1\hat{\boldsymbol\gamma}_1+\mathbf e$) ถ้าเอา residual นี้ไปประมาณความผันผวนเฉพาะตัว จะได้ค่าสูงเกินจริงราว 2.3 เท่า ในทางกลับกัน ถ้าต้องการแค่ factor return ของคอลัมน์ใหม่ ทางนี้ใช้ได้ และไม่ต้องเก็บ residual ของ model เดิมไว้

ตรวจเองใน 10 วินาที: แผงขวาของรูปข้างล่างเขียนความยาว residual ในหน่วยทศนิยม ไม่ใช่ % เช่น $1.8360\%=0.018360$ ซึ่งปัดเป็น 0.0184 สี่ตัวเลขในรูปคือ 1.8360%, 1.8360%, 4.2088% และ 2.1172% ตัวสุดท้ายคือ residual ของทางลัดที่ข้ามขั้นกลางในขั้นที่ 5 (โค้ดคำนวณ)

ขั้นที่ 8 — เมื่อหุ้นแต่ละตัวเสียงดังไม่เท่ากัน: WLS และความคลาด $\mathbf G$

ถึงตรงนี้หน้านี้ให้หุ้นทุกตัวมีน้ำหนักเท่ากันใน regression แต่ในตลาดจริง ส่วนเฉพาะตัวของหุ้นบางตัวแกว่งแรงกว่าตัวอื่นมาก เช่นหุ้นเล็กที่โดนข่าวของตัวเองบ่อย ผลตอบแทนของหุ้นแบบนี้บอกเรื่อง factor ได้น้อย เพราะการแกว่งเฉพาะตัวของมันกลบสัญญาณไว้ เราจึงควรฟังมันน้อยลง ขั้นนี้มีสองคำถาม: ควรถ่วงน้ำหนักอย่างไร และค่าประมาณ factor return ที่ได้คลาดจากค่าจริงได้แค่ไหน

ของที่ใช้มาจากสมการ factor model:

  • $\mathbf r=\mathbf B\mathbf f+\boldsymbol\epsilon$ คือผลตอบแทนของหุ้น $n$ ตัว เท่ากับ loading $\mathbf B$ คูณ factor return $\mathbf f$ บวกส่วนเฉพาะตัว $\boldsymbol\epsilon$
  • $\sigma_i$ คือความผันผวนของส่วนเฉพาะตัวของหุ้น $i$ และ $\boldsymbol\Omega_\epsilon$ คือ matrix แนวทแยงที่มี $\sigma_i^2$ เรียงบนแนวทแยง

วิธีถ่วงน้ำหนักคือหารแถวที่ $i$ ของสมการด้วย $\sigma_i$ หลังหาร ส่วนเฉพาะตัว $\epsilon_i/\sigma_i$ ของทุกแถวมี variance หนึ่งเท่ากัน OLS จึงใช้กับข้อมูลที่ปรับแล้วได้ตามปกติ ผลที่ได้เรียกว่า WLS เพราะเท่ากับการให้น้ำหนักแถวที่ $i$ เป็น $1/\sigma_i^2$ นี่คือวิธีที่ regression ข้ามหุ้นใช้หา factor return ทุกวัน

\[ \begin{aligned} \mathbf W&=\boldsymbol\Omega_\epsilon^{-1},\\ \hat{\mathbf f}&=\mathbf H\mathbf r,\\ \mathbf H&=\mathbf A^{-1}\mathbf B^{\mathsf T}\mathbf W,\\ \mathbf A&=\mathbf B^{\mathsf T}\mathbf W\mathbf B. \end{aligned} \]

$\mathbf H$ คือ matrix ที่แปลงผลตอบแทนของหุ้นเป็น factor return ที่ประมาณได้ ต่อไปหาความคลาด $\hat{\mathbf f}-\mathbf f$ ขั้นแรกคือดูว่า $\mathbf H$ ทำอะไรกับ $\mathbf B$ แล้วแทน $\mathbf r=\mathbf B\mathbf f+\boldsymbol\epsilon$

\[ \begin{aligned} \mathbf H\mathbf B&=\mathbf A^{-1}\mathbf B^{\mathsf T}\mathbf W\mathbf B\\ &=\mathbf A^{-1}\mathbf A=\mathbf I,\\ \hat{\mathbf f}-\mathbf f&=\mathbf H(\mathbf B\mathbf f+\boldsymbol\epsilon)-\mathbf f\\ &=\mathbf H\boldsymbol\epsilon. \end{aligned} \]

ความคลาดจึงมาจากส่วนเฉพาะตัวเท่านั้น ขนาดของมันวัดด้วย covariance เรียกว่า $\mathbf G$ ใช้กฎ $\operatorname{cov}(\mathbf H\boldsymbol\epsilon)=\mathbf H\operatorname{cov}(\boldsymbol\epsilon)\mathbf H^{\mathsf T}$ แล้วแทน $\mathbf H$ ทั้งสองข้าง ($\mathbf H^{\mathsf T}=\mathbf W\mathbf B\mathbf A^{-1}$ เพราะ $\mathbf W$ กับ $\mathbf A$ สมมาตร)

\[ \begin{aligned} \mathbf G&=\mathbf H\boldsymbol\Omega_\epsilon\mathbf H^{\mathsf T}\\ &=\mathbf A^{-1}\mathbf B^{\mathsf T}\mathbf W\boldsymbol\Omega_\epsilon\mathbf W\mathbf B\mathbf A^{-1},\\ \mathbf W\boldsymbol\Omega_\epsilon\mathbf W&=\mathbf W,\\ \mathbf G&=\mathbf A^{-1}\mathbf A\mathbf A^{-1}\\ &=(\mathbf B^{\mathsf T}\mathbf W\mathbf B)^{-1}. \end{aligned} \]

ใจความมีสองข้อ ข้อแรก $\mathbf H\mathbf B=\mathbf I$ แปลว่าถ้าวันไหนไม่มีส่วนเฉพาะตัวเลย WLS จะได้ factor return จริงพอดี ความคลาดทั้งหมดจึงมาจาก $\boldsymbol\epsilon$ ที่ส่งผ่าน $\mathbf H$ ข้อสอง จังหวะที่ทำให้สูตรสั้นลงคือ $\mathbf W\boldsymbol\Omega_\epsilon\mathbf W=\mathbf W$ ซึ่งจริงเพราะ $\mathbf W$ คือ inverse ของ $\boldsymbol\Omega_\epsilon$ น้ำหนัก $1/\sigma_i^2$ หักล้างกับ variance $\sigma_i^2$ พอดี ผลคือ $\mathbf G=(\mathbf B^{\mathsf T}\mathbf W\mathbf B)^{-1}$ ซึ่งเป็นสูตร $\sigma^2(\mathbf X^{\mathsf T}\mathbf X)^{-1}$ ของ OLS ในแบบถ่วงน้ำหนัก ถ้าทุกหุ้นมี $\sigma_i=\sigma$ เท่ากัน จะได้ $\mathbf W=\mathbf I/\sigma^2$ และ $\mathbf G=\sigma^2(\mathbf B^{\mathsf T}\mathbf B)^{-1}$ ตรงกับสูตรเดิม

แต่ละแถวของ $\mathbf H$ อ่านเป็นพอร์ตหุ้นได้ แถวที่ $j$ คือน้ำหนักของหุ้นทั้ง $n$ ตัว และผลตอบแทนของพอร์ตนี้คือ $\hat f_j$ ข้อ $\mathbf H\mathbf B=\mathbf I$ บอกว่าพอร์ตนี้มี exposure หนึ่งหน่วยต่อ factor ที่ $j$ และศูนย์ต่อ factor อื่น พอร์ตแบบนี้เรียกว่า factor-mimicking portfolio และในบรรดาพอร์ตที่มี exposure แบบนี้ พอร์ตของ WLS มีความเสี่ยงเฉพาะตัวต่ำที่สุด (นี่คือทฤษฎีบท Gauss–Markov ซึ่งบอกว่า WLS ที่ถ่วงด้วย $1/\sigma_i^2$ ให้ค่าประมาณที่แกว่งน้อยที่สุด ในบรรดาวิธีที่เป็นเชิงเส้นและไม่เอน)

FWL ยังใช้ได้หลังถ่วงน้ำหนัก เพราะ WLS ก็คือ OLS บนข้อมูลที่หารด้วย $\sigma_i$ แล้ว เพียงแต่ $\mathbf M$ กลายเป็น $\mathbf I-\mathbf X_1(\mathbf X_1^{\mathsf T}\mathbf W\mathbf X_1)^{-1}\mathbf X_1^{\mathsf T}\mathbf W$ โค้ดท้ายหน้าตรวจกับข้อมูล 12 หุ้น โดยสมมติความผันผวนเฉพาะตัวไว้ระหว่าง 1.2% ถึง 2.5% ได้ 0.7450% ทั้งแบบทีเดียวและแบบทีละขั้น ส่วน $\mathbf G$ คือสิ่งที่ต้องหักออกตอนประมาณ covariance ของ factor

ขั้นที่ 9 — ค่า $\mathbf G$ ของ model สี่หุ้น

สูตร $\mathbf G$ ยังเป็นสัญลักษณ์อยู่ ขั้นนี้ใส่ตัวเลขจริง เพื่อดูว่าเมื่อตลาดมีหุ้นแค่สี่ตัว ค่าประมาณ factor return รายวันคลาดจากค่าจริงได้แค่ไหน และคลาดมากหรือน้อยเมื่อเทียบกับขนาดการแกว่งของตัว factor เอง

โจทย์ให้อะไรมาบ้าง: หุ้นสี่ตัวกับ factor สามตัว (market, momentum, tech) จากตัวอย่างหุ้นสี่ตัวในหน้าสมการ factor model ตัวเลขทั้งหมดสมมติ

  • loading $\mathbf B$: market เป็น 1 ทุกตัว, momentum คือ 1.2, −0.4, 0.6, −1.4 และ tech เป็น 1 สำหรับหุ้นสองตัวแรกที่อยู่ในกลุ่มเทคโนโลยี เป็น 0 สำหรับสองตัวหลัง
  • ความผันผวนเฉพาะตัวต่อวัน $\sigma_i$: 1.80%, 2.20%, 1.50% และ 2.60%
  • factor return จริงของวันนี้ $\mathbf f=(0.80,\ -0.50,\ 0.30)\%$ ในชีวิตจริงไม่มีใครเห็นตัวเลขนี้ ตัวอย่างนี้กำหนดไว้เพื่อวัดว่าค่าประมาณคลาดเท่าไร
  • ส่วนเฉพาะตัวของวันนี้ $\boldsymbol\epsilon=(0.40,\ -0.25,\ 0.15,\ -0.60)\%$ ผลตอบแทนที่เห็นจึงเป็น $\mathbf r=\mathbf B\mathbf f+\boldsymbol\epsilon=(0.90,\ 1.05,\ 0.65,\ 0.90)\%$
  • ความผันผวนรายวันของตัว factor เอง: market 1.00%, momentum 0.35%, tech 0.55% (จากตัวอย่างความเสี่ยงของพอร์ตในหน้าเดียวกัน)

เริ่มจากน้ำหนัก $w_i=1/\sigma_i^2$ เช่น $1/1.80^2=0.3086$ แล้วสร้าง $\mathbf A=\mathbf B^{\mathsf T}\mathbf W\mathbf B$ แต่ละช่องของ $\mathbf A$ คือผลรวมทีละหุ้น $\sum_iw_iB_{ij}B_{ik}$ เช่นช่องของ momentum กับ tech มีแค่สองหุ้นแรกที่ tech ไม่เป็นศูนย์ จึงได้ $0.3086(1.2)(1)+0.2066(-0.4)(1)=0.2877$

\[ \begin{aligned} \mathbf B&=\begin{bmatrix}1&1.2&1\\1&-0.4&1\\1&0.6&0\\1&-1.4&0\end{bmatrix},\\ \mathbf W&=\operatorname{diag}(0.3086,\ 0.2066,\\ &\qquad 0.4444,\ 0.1479),\\ \mathbf A&=\begin{bmatrix}1.1076&0.3473&0.5153\\0.3473&0.9274&0.2877\\0.5153&0.2877&0.5153\end{bmatrix}. \end{aligned} \]

จากนั้น invert $\mathbf A$ ได้ $\mathbf G$ (โค้ดท้ายหน้าทำให้) ตัวเลขบนแนวทแยงของ $\mathbf G$ คือ variance ของความคลาดของ factor แต่ละตัว รากที่สองของมันคือ SE ส่วน $\hat{\mathbf f}=\mathbf H\mathbf r$ ก็คำนวณด้วยโค้ดเช่นกัน แล้วนำไปลบกับ $\mathbf f$ จริง

\[ \begin{aligned} \operatorname{diag}(\mathbf G)&=(1.7014,\ 1.3144,\\ &\qquad 3.9045),\\ \text{SE}&=(\sqrt{1.7014},\ \sqrt{1.3144},\\ &\qquad \sqrt{3.9045})\\ &=(1.30,\ 1.15,\ 1.98)\%,\\ \hat{\mathbf f}&=(0.7237,\ -0.1120,\\ &\qquad 0.2990)\%,\\ \hat{\mathbf f}-\mathbf f&=(0.7237-0.80,\\ &\qquad -0.1120+0.50,\\ &\qquad 0.2990-0.30)\\ &=(-0.0763,\ 0.3880,\\ &\qquad -0.0010)\%. \end{aligned} \]

คำตอบ: ด้วยหุ้นแค่สี่ตัว SE ของ momentum คือ 1.15% ต่อวัน ขณะที่ตัว momentum factor เองแกว่งแค่ 0.35% ต่อวัน ความคลาดจึงใหญ่กว่าสัญญาณ $1.1465/0.35=3.3$ เท่า ค่าประมาณรายวันเป็นเสียงรบกวนเกือบทั้งหมด วันนี้ค่าประมาณของ momentum คลาดไป 0.3880 จุดเปอร์เซ็นต์ คิดเป็น $0.3880/1.1465=0.34$ เท่าของ SE จึงเป็นความคลาดขนาดปกติ ไม่ใช่วันที่โชคร้าย

ถ้าตลาดใหญ่ขึ้นล่ะ? สมมติว่ามีหุ้น 400 ตัว ซึ่งเป็นหุ้นสี่ตัวนี้ซ้ำกัน 100 ชุด (loading และความผันผวนเหมือนเดิม) เพราะ $\mathbf A$ เป็นผลรวมทีละหุ้น หุ้นแต่ละชุดเติมก้อนเดิมเข้าไปหนึ่งก้อน $\mathbf A$ จึงโตขึ้น 100 เท่า $\mathbf G=\mathbf A^{-1}$ เล็กลง 100 เท่า และ SE เล็กลง $\sqrt{100}=10$ เท่า

\[ \begin{aligned} \text{SE}_{400}&=\tfrac{1}{10}(1.30,\ 1.15,\ 1.98)\\ &=(0.130,\ 0.115,\ 0.198)\%. \end{aligned} \]

ยิ่งตลาดมีหุ้นมาก ค่าประมาณรายวันยิ่งน่าเชื่อ

ตรวจเองใน 10 วินาที: WLS ต้องไม่แย่กว่า OLS ธรรมดาที่ให้ทุกหุ้นมีน้ำหนักเท่ากัน OLS ใช้ $\mathbf H_{\rm OLS}=(\mathbf B^{\mathsf T}\mathbf B)^{-1}\mathbf B^{\mathsf T}$ และความคลาดมี covariance $\mathbf H_{\rm OLS}\boldsymbol\Omega_\epsilon\mathbf H_{\rm OLS}^{\mathsf T}$ บนแนวทแยงได้ 1.9134, 1.3182 และ 4.3283 (โค้ดคำนวณ) มากกว่า 1.7014, 1.3144 และ 3.9045 ของ WLS ทุกตัว ตรงกับที่ทฤษฎีบท Gauss–Markov บอก

ความผิดที่ให้ตัวเลขผิดแบบไม่มีอาการ

ใช้คะแนนดิบกับผลตอบแทนที่เหลือ: ความผิดคือข้ามขั้นกลาง ไม่หักส่วนที่ model เดิมอธิบายได้ออกจากคุณสมบัติใหม่ ตัวหารจึงนับส่วนที่ซ้ำเข้าไปด้วย ผิดได้ $6.2133/10.888=0.5707\%$ ถูกคือ $6.2133/8.2894=0.7496\%$ ต่ำไป $1-0.5707/0.7496=23.9\%$ ความผิดนี้ดึงค่าเข้าหาศูนย์เสมอ คุณสมบัติที่ดีจริงจึงดูแย่กว่าที่เป็น และอาจถูกทิ้งเพราะไม่ผ่านการทดสอบนัยสำคัญ (การทดสอบว่าตัวเลขต่างจากศูนย์จริง หรือแค่บังเอิญ)

เก็บ residual จากทางลัดบนผลตอบแทนดิบ: ความผิดคือไม่หักส่วนของ model เดิมออกจากผลตอบแทนก่อน ตัวคูณยังถูก (0.7496%) แต่ residual ผิด ผิดได้ $\lVert\mathbf y-\tilde{\mathbf x}_2\hat\gamma_2\rVert=4.2088$ ถูกคือ $\lVert\mathbf e\rVert=1.8360$ ใหญ่เกิน $4.2088/1.8360=2.29$ เท่า residual คือส่วนเฉพาะตัวที่ทีมนำไปประมาณความเสี่ยงและวัดฝีมือการเลือกหุ้นต่อ ความผิดตรงนี้จึงไหลไปทุกที่

รายงานตัวเลขของ model เดิมเป็นค่าสุดท้าย: ความผิดคือเชื่อตัวคูณของ momentum จาก model ที่ยังขาดคอลัมน์ใหม่ ผิดได้ $0.7558+0.4609\times0.7496=1.1013\%$ ถูกคือ 0.7558% สูงเกิน $1.1013/0.7558-1=45.7\%$ เพราะ momentum รับเครดิตของคุณสมบัติที่ขาดไป ถ้าจะรายงานผลของ momentum หลังหักคุณสมบัติใหม่แล้ว ต้องใช้ model เต็ม

ลืม $\mathbf G$: ความผิดคือคิด variance ของ factor จากค่าประมาณรายวันตรง ๆ โดยลืมว่าค่าประมาณมีความคลาดปนอยู่ เพราะ $\hat{\mathbf f}=\mathbf f+\mathbf H\boldsymbol\epsilon$ และส่วนเฉพาะตัวไม่เกี่ยวกับ factor variance จึงบวกกัน: $\operatorname{var}(\hat f_j)=\operatorname{var}(f_j)+G_{jj}$ กับ momentum ใน model สี่หุ้น ผิดได้ $\sqrt{0.35^2+1.3144}=\sqrt{1.4369}=1.20\%$ ถูกคือ 0.35% ค่าที่ได้สูงเกินจริงเสมอ ต้องหัก $\mathbf G$ ออกก่อน

ใช้ทำอะไรบนโต๊ะจริง

เมื่อนักวิจัยเสนอ factor ใหม่ ทีมความเสี่ยงทำสี่ขั้น:

  1. หักส่วนที่ model เดิมอธิบายได้ออกจากคะแนนใหม่ด้วย WLS ได้ loading ใหม่ที่ตั้งฉากกับ factor เดิม
  2. ทุกวัน regress residual ของ model เดิมบน loading ใหม่นั้น ได้ factor return ใหม่ของวันนั้น (ขั้นที่ 7 บอกว่าใช้ผลตอบแทนดิบก็ได้ตัวคูณเดียวกัน)
  3. จากประวัติหลายปีของ factor return ใหม่ หาค่าเฉลี่ยและ Sharpe Ratio (ผลตอบแทนเฉลี่ยหารด้วยความผันผวน)
  4. ตัดสินว่าจะรับ factor นี้เข้า model หรือไม่

ตลอดสี่ขั้น ประวัติของ factor เก่าไม่ถูกแตะเลย การเติมแบบนี้คือ push-out ที่ทำงานจริง และ FWL คือเหตุผลที่ตัวเลขของ factor ใหม่ตรงกับการคำนวณใหม่ทั้งหมด

โจทย์ตรวจความเข้าใจ

1. นักวิจัยอีกคนเสนอคะแนนใหม่ที่ทับกับ momentum มากกว่าเดิม คือ correlation $\rho$ ระหว่างสองคะแนนเป็น 0.9 หรือ 0.95 เทียบกับกรณีที่ไม่ทับกันเลย variance ของตัวคูณของคะแนนใหม่โตขึ้นกี่เท่า และ SE โตขึ้นกี่เท่า (ใช้ VIF $1/(1-\rho^2)$ จากขั้นที่ 6)

เฉลย

SE คือรากที่สองของ variance จึงโตเป็น $\sqrt{\text{VIF}}$ เท่า

\[ \begin{aligned} \text{VIF}_{0.9}&=\frac{1}{1-0.9^2}=\frac{1}{0.19}=5.26,\\ \sqrt{5.26}&=2.29,\\ \text{VIF}_{0.95}&=\frac{1}{1-0.95^2}=\frac{1}{0.0975}\\ &=10.26,\\ \sqrt{10.26}&=3.20. \end{aligned} \]

เทียบกับ $\rho=0.4812$ ของหน้านี้ ที่ variance โตแค่ 1.30 เท่า และ SE โต 1.14 เท่า

2. ทีมไม่อยากให้ตัวเลขเก่าของ market กับ momentum ขยับ จึงเติม $\tilde{\mathbf x}_2$ (ไม่ใช่ $\mathbf x_2$ ดิบ) เข้าไปเป็นคอลัมน์ที่สาม แล้ว regress $\mathbf y$ บนสามคอลัมน์ (1, momentum, $\tilde{\mathbf x}_2$) แบบนี้คือ push-out ตัวคูณทั้งสามเป็นเท่าไร ตอบได้โดยไม่ต้องแก้ระบบสมการ ใช้ผลของขั้นที่ 4 กับ FWL

เฉลย

ได้ (0.4235, 1.1013, 0.7496)% เหตุผลคือ $\tilde{\mathbf x}_2$ ตั้งฉากกับคอลัมน์เดิม ช่องที่จับคู่ $\tilde{\mathbf x}_2$ กับคอลัมน์เดิมใน $\mathbf X^{\mathsf T}\mathbf X$ จึงเป็นศูนย์หมด regression จึงแยกเป็นสองชิ้นที่ไม่เกี่ยวกัน ชิ้นแรกคือ $\mathbf y$ บน (1, momentum) ซึ่งได้ $\hat{\boldsymbol\gamma}_1=(0.4235, 1.1013)$ ของ model เดิม ชิ้นที่สองคือ

\[\frac{\tilde{\mathbf x}_2^{\mathsf T}\mathbf y}{\tilde{\mathbf x}_2^{\mathsf T}\tilde{\mathbf x}_2}=\frac{6.2133}{8.2894}=0.7496,\]

เท่ากับ model เต็ม ประวัติของ market กับ momentum จึงไม่ขยับ แต่ตัวเลข 1.1013 ของ momentum ในรายงานนี้ยังรวมเครดิต $0.4609\times0.7496=0.3455$ จุดเปอร์เซ็นต์ของคุณสมบัติใหม่ ตามที่ขั้นที่ 6 แสดงไว้

3. ทีมอยากให้ค่าประมาณรายวันของ momentum แม่นพอ คือ SE ไม่เกิน 0.035% ซึ่งเป็นหนึ่งในสิบของความผันผวนของตัว momentum เอง ($0.35/10=0.035$) ถ้าตลาดคือหุ้นสี่ตัวของขั้นที่ 9 ซ้ำกัน $k$ ชุด ต้องมี $k$ อย่างน้อยเท่าไร และนั่นคือหุ้นกี่ตัว

เฉลย

ขั้นที่ 9 แสดงว่าเมื่อมี $k$ ชุด $\mathbf A$ โต $k$ เท่า SE จึงหารด้วย $\sqrt k$ เริ่มจาก SE ของชุดเดียว 1.1465%

\[ \begin{aligned} \frac{1.1465}{\sqrt k}&\le0.035,\\ \sqrt k&\ge\frac{1.1465}{0.035}=32.757,\\ k&\ge32.757^2=1{,}073.03. \end{aligned} \]

$k$ ต้องเป็นจำนวนเต็ม จึงต้อง 1,074 ชุด หรือหุ้น $4\times1{,}074=4{,}296$ ตัว ตรวจ: $1.1465/\sqrt{1{,}074}=0.03498$ ไม่เกิน 0.035 ตลาดที่มีหุ้นมากจึงสำคัญต่อคุณภาพของ factor return รายวัน

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด

รันใน Node.js ได้โดยไม่ต้องติดตั้งอะไร ตัวเลขทุกตัวที่หน้านี้บอกว่า “โค้ดคำนวณ” มาจากโค้ดนี้ ฟังก์ชัน wls แก้ WLS (ถ้าน้ำหนักเท่ากันทุกแถวก็คือ OLS) จากนั้นโค้ดหา residual ของ model เดิม ทำ FWL ทีละขั้น ลองทางลัดทั้งสองแบบ หาความเอนของ model เดิม ตรวจ FWL แบบถ่วงน้ำหนัก และคำนวณ $\mathbf H$ กับ $\mathbf G$ ของ model สี่หุ้น

const {sqrt, abs, max} = Math;
function checkMatrix(A, name) {
  if (!Array.isArray(A) || A.length === 0 || !A.every(row => Array.isArray(row) && row.length === A[0].length && row.every(Number.isFinite))) {
    throw new TypeError(name + ' must be a non-empty rectangular matrix of finite numbers');
  }
  return [A.length, A[0].length];
}
const dot = (a, b) => a.reduce((s, v, i) => s + v * b[i], 0);
const transpose = A => A[0].map((_, j) => A.map(row => row[j]));
const mul = (A, B) => A.map(row => B[0].map((_, j) => row.reduce((s, v, k) => s + v * B[k][j], 0)));
const matVec = (A, x) => A.map(row => dot(row, x));
const norm = x => sqrt(dot(x, x));
function inverse(A) {
  const n = A.length, M = A.map((row, i) => [...row, ...row.map((_, j) => (i === j ? 1 : 0))]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let i = c + 1; i < n; i++) if (abs(M[i][c]) > abs(M[p][c])) p = i;
    if (abs(M[p][c]) < 1e-12) throw new RangeError('Columns are collinear: the regression has no unique answer');
    [M[c], M[p]] = [M[p], M[c]];
    const piv = M[c][c];
    for (let j = 0; j < 2 * n; j++) M[c][j] /= piv;
    for (let i = 0; i < n; i++) if (i !== c) { const g = M[i][c]; for (let j = 0; j < 2 * n; j++) M[i][j] -= g * M[c][j]; }
  }
  return M.map(row => row.slice(n));
}
// Weighted least squares; weights all 1 give OLS. Returns the coefficients and (X'WX)^-1.
function wls(X, y, weights) {
  const [n] = checkMatrix(X, 'Design matrix');
  const w = weights || new Array(n).fill(1);
  if (!Array.isArray(y) || y.length !== n || !y.every(Number.isFinite)) throw new TypeError('Need one finite response per row');
  if (w.length !== n || !w.every(v => Number.isFinite(v) && v > 0)) throw new RangeError('Weights must be positive, one per row');
  const XtW = transpose(X).map(col => col.map((v, i) => v * w[i]));
  const G = inverse(mul(XtW, X));
  return {beta: matVec(G, matVec(XtW, y)), G};
}
// Residual maker: z minus its (weighted) fit on the columns of X1.
function residualize(X1, z, weights) {
  const fit = wls(X1, z, weights).beta;
  return z.map((v, i) => v - dot(X1[i], fit));
}
