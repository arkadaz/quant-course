9.4 Worked Computation — $\mathbb E_0[W_{t+s}W_s]$

ค่าของเส้นทางสุ่มที่สองเวลา คูณกันแล้วเฉลี่ย ได้ความยาวของช่วงเวลาที่ทั้งสองค่าเดินมาด้วยกัน ผลนี้อธิบายว่าทำไมผลเดือนแรกดูเหมือนบอกอะไรเกี่ยวกับทั้งปี ทั้งที่ไม่ได้บอก

สิ้นเดือนมกราคม กองทุนแห่งหนึ่งประชุมสรุปผล เดือนนี้กองทุนได้กำไร \$2 ล้าน ทุกคนในห้องอยากรู้ว่าผลเดือนแรกนี้บอกอะไรเกี่ยวกับผลทั้งปีได้บ้าง

ของที่รู้ (ตัวเลขสมมติ):

  • P&L (profit and loss) คือกำไรขาดทุนสะสมของกองทุนนับจากต้นปี เขียนว่า $P_t$ เมื่อ $t$ คือเวลาเป็นปี
  • P&L สิ้นมกราคม $P_{1/12}=\$2$ ล้าน (มกราคมคือ $1/12$ ของปี)
  • ความผันผวนของ P&L ทั้งปี $\sigma_P=\$12$ ล้าน คือ SD (standard deviation) ของผลทั้งปี แปลว่าในปีทั่วไป ผลทั้งปีมักห่างจากค่าเฉลี่ยราว \$12 ล้าน
  • แบบจำลอง: P&L เดินแบบ Brownian motion ไม่มี drift คือขยับขึ้นลงแบบสุ่ม ช่วงเวลาที่ไม่ทับกันขยับเป็นอิสระต่อกัน และไม่มีแนวโน้มขึ้นหรือลง (drift คือแนวโน้มนั้น)

ในห้องประชุมมีคนพูดสองประโยค ผู้บริหารพูดว่า “ด้วยจังหวะนี้ ทั้งปีจะได้ $2\times12=\$24$ ล้าน” นักวิเคราะห์เสริมว่า “ผลเดือนแรกมี correlation กับผลทั้งปี 0.29 จึงอธิบายผลทั้งปีได้ 29%” (correlation คือตัวเลขระหว่าง −1 ถึง 1 ที่บอกว่าสองค่าขยับไปด้วยกันแค่ไหน หน้านี้จะคำนวณ 0.29 ให้ดูทีละขั้น)

ใครพูดถูก และควรคาดผลทั้งปีเท่าไร?

ลองตอบก่อนเปิดเฉลย

ผิดทั้งคู่ ผลทั้งปีคือกำไรมกราคมที่ได้แล้ว บวกผลของสิบเอ็ดเดือนที่เหลือ ส่วนที่เหลือไม่มี drift จึงมีค่าเฉลี่ยศูนย์ คำทำนายทั้งปีจึงเป็น $2+0=\$2$ ล้าน ไม่ใช่ \$24 ล้าน

คำทำนายนี้ยังไม่แน่นอน เพราะสิบเอ็ดเดือนที่เหลือยังแกว่งได้ SD ของส่วนนั้นคือ $12\sqrt{11/12}\approx\$11.49$ ล้าน (หน้านี้จะหาที่มาของตัวเลขนี้ให้ดู)

ตัวเลข correlation 0.29 ของนักวิเคราะห์ถูก แต่ข้อสรุป 29% ผิด เพราะ “อธิบายได้กี่ %” ต้องยกกำลังสองก่อน:

\[\begin{aligned}\rho&=\sqrt{1/12}\approx0.289,\\\rho^2&=1/12\approx8.33\%.\end{aligned}\]

และ 8.33% นี้ก็ได้มาเพราะมกราคมเป็นส่วนหนึ่งของทั้งปีอยู่แล้ว ส่วนเรื่องของกุมภาพันธ์ถึงธันวาคม มกราคมบอกอะไรไม่ได้เลย (0%)

ภาพรวมก่อนลงสูตร

เพื่อตอบคำถามของกองทุน เราต้องรู้ว่าผลสิ้นมกราคมกับผลสิ้นปี “ขยับไปด้วยกัน” แค่ไหน ตัวที่วัดเรื่องนี้คือ covariance หรือค่าเฉลี่ยของผลคูณของสองค่า (เมื่อทั้งสองค่ามีค่าเฉลี่ยศูนย์ สองอย่างนี้เป็นตัวเดียวกัน)

หน้านี้ทำงานกับ $W_t$ คือ SBM (standard Brownian motion) เส้นทางสุ่มที่เริ่มจาก $W_0=0$ ถ้าดูการขยับในช่วงยาว $h$ ปี การขยับนั้นมีค่าเฉลี่ย 0 และ variance $h$ และการขยับในช่วงที่ไม่ทับกันเป็นอิสระต่อกัน (ดูหน้าstandard Brownian motion) แบบจำลอง P&L ของกองทุนคือ SBM ที่คูณด้วยความผันผวน $P_t=\sigma_PW_t$ เราจึงศึกษา $W$ ก่อน แล้วค่อยคูณ $\sigma_P$ กลับตอนท้าย

ปริมาณที่ต้องหาคือ $\mathbb E_0[W_{t+s}W_s]$ อ่านว่า “ค่าเฉลี่ยของ $W$ ที่เวลา $s$ คูณ $W$ ที่เวลาหลังกว่านั้นอีก $t$” โดย $\mathbb E_0$ คือค่าเฉลี่ยที่มองจากเวลา 0 สำหรับกองทุน $s=1/12$ (สิ้นมกราคม) และ $t+s=1$ (สิ้นปี) คำตอบที่หน้านี้จะพิสูจน์คือ

\[\mathbb E_0[W_{t+s}W_s]=s\]

คือความยาวของช่วงเวลาที่สองจุดเดินมาด้วยกัน ตัวเลข 0.289 ในห้องประชุมก็มาจากผลนี้

ทำไมต้องคำนวณให้ลำบาก เพราะ $W_s$ กับ $W_{t+s}$ พันกันอยู่ เส้นทางที่ไปถึงเวลา $t+s$ ต้องผ่านเวลา $s$ ก่อน แต่กติกาของ Brownian motion พูดถึงแค่ “การขยับในช่วงที่ไม่ทับกัน” ทางออกจึงเป็นทริกเดียวกับหน้าfiltration ในเวลาต่อเนื่อง: แยกค่าที่เวลาหลังเป็นส่วนที่รู้แล้วบวกส่วนใหม่ หลังจากนั้นหน้านี้จะขยายผลเป็นสูตร covariance $\min(u,v)$ แปลงเป็น correlation แล้วกลับมาตอบคำถามของกองทุนเป็นดอลลาร์

รูปด้านล่างคือความคิดทั้งหน้า สองจุดบนเส้นทางเดียวกันใช้ช่วงเวลาสีส้มร่วมกัน ส่วนช่วงสีเขียวเป็นของจุดหลังคนเดียว เมื่อคูณสองจุดแล้วเฉลี่ย จะเหลือแค่ความยาวของช่วงสีส้ม

ขั้นที่ 1 — แยกค่าที่เวลาหลังเป็นส่วนร่วมบวกส่วนใหม่

เราอยากเฉลี่ยผลคูณ $W_{t+s}W_s$ แต่สองค่านี้พันกัน และนิยามของ Brownian motion ไม่ได้บอกอะไรตรง ๆ เกี่ยวกับค่าที่พันกัน มันบอกแค่เรื่องการขยับในช่วงที่ไม่ทับกัน ขั้นแรกจึงเขียนทุกอย่างใหม่ให้เป็นการขยับ วิธีทำคือบวกและลบ $W_s$ เข้าไปใน $W_{t+s}$ (เครื่องหมาย $:=$ แปลว่า “นิยามให้เป็น”)

\[ \begin{aligned} A&:=W_s-W_0=W_s,\\ B&:=W_{t+s}-W_s,\\ W_{t+s}&=W_s+(W_{t+s}-W_s)\\ &=A+B. \end{aligned} \]

การแยก $W_{t+s}=A+B$ เป็นจริงทุกเส้นทาง ไม่ได้ประมาณอะไร เพราะเราแค่บวกและลบตัวเดียวกัน ค่าที่เวลาหลังจึงเท่ากับ “ที่เดินมาแล้วถึงเวลา $s$” บวก “ที่เดินต่อหลังจากนั้น”

จุดที่ต้องคิดคือ ทำไมต้องแยกที่เวลา $s$ พอดี คำตอบคือ $A$ เป็นการขยับในช่วง 0 ถึง $s$ ส่วน $B$ เป็นการขยับในช่วง $s$ ถึง $t+s$ สองช่วงนี้ไม่ทับกัน กติกาความเป็นอิสระจึงบอกว่า $A$ กับ $B$ เป็นอิสระต่อกัน ถ้าแยกที่เวลาอื่น สองก้อนจะมีช่วงเวลาทับกัน และความเป็นอิสระที่ต้องใช้ในขั้นต่อไปก็หายไป

กติกาเรื่องขนาดของการขยับยังบอกอีกว่า $A\sim\mathcal N(0,s)$ และ $B\sim\mathcal N(0,t)$ คือทั้งคู่เป็น Normal ที่มีค่าเฉลี่ย 0 และ variance เท่ากับความยาวช่วงของตัวเอง

ขั้นที่ 2 — กระจายผลคูณ ยังไม่ใช้สมบัติของ Brownian motion เลย

ตอนนี้แทน $W_{t+s}=A+B$ ลงในผลคูณ แล้วกระจายวงเล็บ ขั้นนี้ใช้แค่พีชคณิต กับกฎว่าค่าเฉลี่ยของผลบวกคือผลบวกของค่าเฉลี่ย (ดูหน้าค่าคาดหวัง) กฎนี้ใช้ได้เสมอ ไม่ต้องอาศัยความเป็นอิสระ จึงควรทำขั้นนี้ก่อนทุกครั้ง

\[ \begin{aligned} W_{t+s}W_s&=(A+B)\,A\\ &=A^2+AB,\\ \mathbb E_0[W_{t+s}W_s]&=\mathbb E_0[A^2]+\mathbb E_0[AB]. \end{aligned} \]

ปัญหาหนึ่งก้อนกลายเป็นสองก้อนที่ง่ายกว่า ก้อนแรก $A^2$ คือการขยับช่วงแรกยกกำลังสอง ก้อนที่สอง $AB$ เรียกว่าพจน์ไขว้ เพราะเป็นผลคูณของการขยับสองช่วงที่ไม่ทับกัน ถึงตรงนี้ยังไม่ได้ใช้สมบัติของ Brownian motion เลย สมบัติเหล่านั้นจะเข้ามาทำงานตอนหาค่าเฉลี่ยของสองก้อนนี้

ขั้นที่ 3 — พจน์ไขว้เป็นศูนย์ ตรวจได้สองทาง

เริ่มจากพจน์ไขว้ $\mathbb E_0[AB]$ เพราะดูยากที่สุด มันเป็นผลคูณของค่าสุ่มสองค่า เราจะคำนวณสองทาง แล้วดูว่าได้ผลตรงกันไหม ทางแรกใช้เครื่องมือของ filtration คือเฉลี่ยสองชั้น ชั้นในใช้ $\mathbb E_s$ หรือค่าเฉลี่ยที่มองจากเวลา $s$ ซึ่งตอนนั้นรู้ค่า $A$ แล้ว ทางที่สองใช้ความเป็นอิสระของ $A$ กับ $B$ ตรง ๆ

\[ \begin{aligned} \mathbb E_0[AB]&=\mathbb E_0\big[\mathbb E_s[AB]\big]\\ &=\mathbb E_0\big[A\,\mathbb E_s[B]\big]\\ &=\mathbb E_0[A\cdot0]=0,\\ \mathbb E_0[AB]&=\mathbb E_0[A]\,\mathbb E_0[B]=0\cdot0=0. \end{aligned} \]

ทางแรกคิดแบบคนที่ยืนรออยู่ที่เวลา $s$ เริ่มจาก tower property ซึ่งบอกว่าเฉลี่ยสองชั้นได้เท่ากับเฉลี่ยชั้นเดียว จังหวะที่ต้องระวังคือการดึง $A$ ออกจาก $\mathbb E_s$ ที่ทำได้เพราะคนที่ยืนที่เวลา $s$ เห็นค่า $A$ แล้ว สำหรับเขา $A$ เป็นตัวเลขธรรมดาเหมือนค่าคงที่ ที่เหลือคือ $\mathbb E_s[B]$ ค่าเฉลี่ยของการขยับหลังเวลา $s$ ซึ่งเป็นศูนย์ไม่ว่าอดีตจะเป็นอย่างไร ผลคูณจึงเป็น $A\cdot0=0$

ทางแรกนี้ใช้แค่ข้อเดียว คือ “การขยับในอนาคตมีค่าเฉลี่ยศูนย์เมื่อรู้อดีต” ข้อนี้อ่อนกว่าความเป็นอิสระ ทางนี้จึงใช้ได้กับ martingale ทั่วไปที่ไม่ใช่ Brownian motion ด้วย เช่นในหน้าItô integral

ทางที่สองสั้นกว่า เพราะ $A$ กับ $B$ เป็นอิสระต่อกัน และตัวแปรอิสระสองตัวมีค่าเฉลี่ยของผลคูณเท่ากับผลคูณของค่าเฉลี่ย (ดูหน้าผลของความเป็นอิสระ) แต่ทางนี้ต้องอาศัยความเป็นอิสระเต็มรูป ทั้งสองทางได้ศูนย์เหมือนกัน การที่ได้ผลตรงกันยืนยันว่าเราไม่ได้ใช้อะไรผิด

ขั้นที่ 4 — ก้อนที่เหลือ: ค่าเฉลี่ยของกำลังสอง ไม่ใช่กำลังสองของค่าเฉลี่ย

ก้อนที่เหลือคือ $\mathbb E_0[A^2]$ อย่าเพิ่งตอบว่าเป็นศูนย์ ค่าเฉลี่ยของ $A$ เป็นศูนย์ก็จริง แต่ $A^2$ ไม่เคยติดลบ และเป็นบวกทุกครั้งที่ $A\ne0$ ค่าเฉลี่ยของมันจึงเป็นศูนย์ไม่ได้ เครื่องมือที่ใช้คือสูตรลัดของ variance (ดูหน้าvariance และ SD) แล้วย้ายข้าง

\[ \begin{aligned} \operatorname{Var}(A)&=\mathbb E_0[A^2]-(\mathbb E_0[A])^2,\\ \mathbb E_0[A^2]&=\operatorname{Var}(A)+(\mathbb E_0[A])^2\\ &=s+0^2=s. \end{aligned} \]

สูตรลัดบอกว่า variance คือค่าเฉลี่ยของกำลังสอง ลบด้วยกำลังสองของค่าเฉลี่ย เมื่อย้ายข้าง ค่าเฉลี่ยของกำลังสองจึงเท่ากับ variance บวกกำลังสองของค่าเฉลี่ย สำหรับ $A=W_s\sim\mathcal N(0,s)$ ค่าเฉลี่ยเป็นศูนย์ ส่วนที่บวกเพิ่มจึงหายไป เหลือ variance $s$ พอดี

สรุปเป็นกฎจำง่าย: เมื่อค่าเฉลี่ยเป็นศูนย์ ค่าเฉลี่ยของกำลังสองก็คือ variance

ขั้นที่ 5 — รวมสองก้อน แล้วตรวจด้วยเหรียญสี่เส้นทาง

ตอนนี้มีครบทั้งสองก้อนแล้ว พจน์ไขว้เป็นศูนย์ และ $\mathbb E_0[A^2]=s$ แทนทั้งสองค่าลงในผลคูณที่กระจายวงเล็บไว้ ก็ได้คำตอบ

แต่คำตอบที่ได้จากพีชคณิตล้วน ๆ ควรตรวจกับกรณีที่นับด้วยมือได้ ใช้การโยนเหรียญแทน Brownian motion แต่ละก้าวขยับ $+1$ หรือ $-1$ โอกาสเท่ากันข้างละครึ่ง ค่าเฉลี่ยต่อก้าวจึงเป็น $\tfrac12(1)+\tfrac12(-1)=0$ และ variance ต่อก้าวเป็น $\tfrac12(1)^2+\tfrac12(-1)^2-0^2=1$ ก้าวต่าง ๆ เป็นอิสระต่อกัน เหมือนกติกาของ Brownian motion ให้ $s=1$ ก้าว และ $t=1$ ก้าว สูตรจึงทำนายว่า $\mathbb E[W_2W_1]=1$

\[ \begin{aligned} \mathbb E_0[W_{t+s}W_s]&=s+0=s,\\ W_1&=\pm1,\qquad W_2=W_1\pm1,\\ W_2W_1&:\ (2)(1),\ (0)(1),\ (0)(-1),\ (-2)(-1),\\ \tfrac14(2+0+0+2)&=1=s. \end{aligned} \]

สิ่งแรกที่ควรสังเกตคือคำตอบไม่มี $t$ อยู่เลย จะรอหลังเวลา $s$ นานเท่าไร ค่าเฉลี่ยของผลคูณก็เท่าเดิม เพราะทุกอย่างที่เกิดหลัง $s$ เป็นอิสระจากอดีตและเฉลี่ยเป็นศูนย์ สิ่งเดียวที่ทำให้สองจุดเกาะกันคือช่วง 0 ถึง $s$ ที่เดินมาด้วยกัน

การตรวจด้วยเหรียญตรงกับสูตร เหรียญสองครั้งมีสี่เส้นทาง (ขึ้นขึ้น ขึ้นลง ลงขึ้น ลงลง) แต่ละเส้นมีโอกาส $\tfrac14$ ผลคูณ $W_2W_1$ ของสี่เส้นคือ 2, 0, 0, 2 เฉลี่ยได้ 1 เท่ากับจำนวนก้าวที่ใช้ร่วมกันพอดี สองเส้นตรงกลางได้ผลคูณศูนย์ เพราะก้าวที่สองดึงเส้นกลับมาที่ศูนย์ โค้ดท้ายหน้านับครบทุกเส้นทางของกรณี $s=2$, $t=3$ ซึ่งมี $2^{5}=32$ เส้นทาง ได้ค่าเฉลี่ย 2 ตรงกับสูตร $s=2$

ขั้นที่ 6 — ขยายเป็น covariance ของสองเวลาใด ๆ

คำตอบหลักของหน้านี้ได้แล้ว แต่ในงานจริง สูตรที่ใช้บ่อยกว่าคือ covariance ของค่าที่สองเวลาใด ๆ เรียกสองเวลานั้นว่า $u$ และ $v$ covariance คือตัววัดว่าสองค่าขยับไปด้วยกันแค่ไหน นิยามจากค่าเฉลี่ยของผลคูณ ลบด้วยผลคูณของค่าเฉลี่ย สมมติก่อนว่า $u\le v$ แล้วตั้ง $s=u$ และ $t=v-u$ จุดหลังจะอยู่ที่ $t+s=v$ พอดี จึงใช้ผลที่เพิ่งได้ได้ทันที

\[ \begin{aligned} \operatorname{Cov}(W_u,W_v)&=\mathbb E[W_uW_v]-\mathbb E[W_u]\,\mathbb E[W_v]\\ &=\mathbb E[W_uW_v]-0\cdot0,\\ \mathbb E[W_uW_v]&=u\quad(s=u,\ t=v-u),\\ \operatorname{Cov}(W_u,W_v)&=\min(u,v). \end{aligned} \]

ค่าเฉลี่ยของ SBM เป็นศูนย์ทุกเวลา พจน์ที่ลบออกจึงเป็น $0\cdot0$ และ covariance เหลือแค่ค่าเฉลี่ยของผลคูณ ซึ่งเราเพิ่งพิสูจน์ว่าเท่ากับเวลาที่มาก่อน $u$ ถ้า $u\gt v$ ก็แค่สลับบทบาทกัน คำตอบจึงเป็นเวลาที่มาก่อนเสมอ เขียนสั้น ๆ ว่า $\min(u,v)$

ระวังการอ่าน $\min$ ในสูตรนี้หมายถึงเวลาที่มาก่อน ไม่ใช่ค่าของเส้นทางที่ต่ำกว่า มันคือความยาวของประวัติที่สองจุดใช้ร่วมกัน

สูตรนี้มีค่ามากกว่าที่เห็น ค่าของ SBM ที่หลายเวลา $(W_{t_1},\dots,W_{t_n})$ เป็นmultivariate normal เพราะทุกตัวเป็นผลบวกของการขยับ Normal ที่อิสระต่อกัน และ multivariate normal ถูกกำหนดครบด้วยค่าเฉลี่ยกับ covariance matrix เท่านั้น ค่าเฉลี่ยศูนย์กับ matrix ที่ช่อง $(i,j)$ เป็น $\min(t_i,t_j)$ จึงบอก distribution ร่วมของ SBM ที่ทุกชุดของเวลาได้ครบ ไม่ต้องรู้อะไรเพิ่ม

ขั้นที่ 7 — แปลงเป็น correlation: เหลือแค่สัดส่วนของเวลา

covariance ยังมีหน่วยเป็นเวลา จึงเทียบข้ามคู่ไม่ได้ เช่น covariance 0.3 ของคู่หนึ่ง อาจเกาะกันแน่นหรือหลวมก็ได้ ขึ้นกับว่าแต่ละค่าแกว่งมากแค่ไหน ทางแก้คือ correlation ซึ่งหาร covariance ด้วย SD ของทั้งสองค่า (ดูหน้าinner product มุม และ correlation) variance ของ $W_u$ คือ $u$ ดังนั้น SD ของ $W_u$ คือ $\sqrt u$ และ SD ของ $W_v$ คือ $\sqrt v$ ให้ $u\le v$ และเขียน $\rho_{u,v}$ แทน correlation ของสองค่านี้

\[ \begin{aligned} \rho_{u,v}&=\frac{\min(u,v)}{\sqrt u\,\sqrt v}=\frac{u}{\sqrt u\,\sqrt v}\\ &=\frac{\sqrt u}{\sqrt v}=\sqrt{\frac uv},\\ R^2&=\rho_{u,v}^2=\frac uv. \end{aligned} \]

จังหวะที่ตัวเลขตัดกันคือเขียน $u=\sqrt u\,\sqrt u$ แล้ว $\sqrt u$ ตัวหนึ่งตัดกับตัวส่วน ที่เหลือคือรากของ “เวลาสั้นหารด้วยเวลายาว” ซึ่งไม่มีหน่วยแล้ว ผลที่ตามมาคือ correlation ขึ้นกับสัดส่วนของเวลาเท่านั้น วันที่ 1 กับวันที่ 2 จึงเกาะกัน $\sqrt{1/2}\approx0.707$ เท่ากับปีที่ 1 กับปีที่ 2 พอดี

ผลสุดท้ายสำคัญที่สุดสำหรับคำถามในห้องประชุม $R^2$ หรือสัดส่วนที่อธิบายได้ เท่ากับสัดส่วนของเวลาที่เห็นไปแล้วพอดี ส่วน correlation เป็นรากของสัดส่วนนั้น และรากของเลขระหว่าง 0 ถึง 1 ใหญ่กว่าตัวมันเองเสมอ เช่น $\sqrt{0.25}=0.5\gt0.25$ correlation จึงดูใหญ่กว่าสัดส่วนที่อธิบายได้ทุกครั้ง

ขั้นที่ 8 — มกราคมเทียบทั้งปี

กลับมาที่ห้องประชุม คำถามของนักวิเคราะห์คือ ผลสิ้นมกราคมเกาะกับผลสิ้นปีแค่ไหน ตอนนี้เรามีสูตรพร้อมแล้ว เหลือแค่แทนตัวเลข ยังไม่ต้องใช้หน่วยดอลลาร์ เพราะ correlation ไม่มีหน่วย การคูณ $\sigma_P$ จึงไม่เปลี่ยนมัน

โจทย์ให้อะไรมาบ้าง:

  • ตลาดหุ้นสหรัฐเปิดซื้อขายราว 252 วันต่อปี (หักเสาร์อาทิตย์และวันหยุด) และมกราคมมีวันทำการราว 21 วัน มกราคมจึงยาว $21/252=1/12$ ปี
  • $J:=W_{1/12}$ คือค่าสิ้นมกราคม
  • $Y:=W_1$ คือค่าสิ้นปี
  • $Y-J$ คือการขยับตั้งแต่กุมภาพันธ์ถึงธันวาคม

แทน $u=1/12$ และ $v=1$ ลงในสูตร correlation และลองเทียบกับกรณีที่เห็นผลนานขึ้น เขียน $\rho_m$ แทน correlation ระหว่างผลสิ้นเดือนที่ $m$ กับผลสิ้นปี

\[ \begin{aligned} \rho_{J,Y}&=\sqrt{1/12}\approx0.2887,\\ R^2&=1/12\approx8.33\%,\\ \rho_3&=\sqrt{3/12}=0.5,\\ \rho_6&=\sqrt{6/12}\approx0.7071,\\ \rho_{11}&=\sqrt{11/12}\approx0.9574. \end{aligned} \]

คำตอบข้อแรก: correlation คือ 0.289 แต่สัดส่วนที่อธิบายได้คือ $R^2=8.33\%$ ไม่ใช่ 28.9% ถ้าเห็นผลนานขึ้น สัดส่วนที่อธิบายได้คือ $\rho_m^2=m/12$ ได้แก่ สามเดือน $0.5^2=25\%$ หกเดือน $6/12=50\%$ และสิบเอ็ดเดือน $11/12\approx91.7\%$ ทุกครั้งเท่ากับสัดส่วนของปีที่เห็นไปแล้ว

แต่คำถามที่ควรถามจริงคือ มกราคมบอกอะไรเกี่ยวกับสิบเอ็ดเดือนที่ยังไม่เกิดได้บ้าง คำตอบอยู่ใน covariance ของ $J$ กับ $Y-J$ ซึ่งหาได้เพราะ covariance แยกผลต่างออกเป็นสองพจน์ได้ และ $\operatorname{Cov}(J,J)=\operatorname{Var}(J)$ โดย $\operatorname{Cov}(J,Y)=\min(\tfrac1{12},1)=\tfrac1{12}$ และ $\operatorname{Var}(J)=\tfrac1{12}$

\[ \begin{aligned} \operatorname{Cov}(J,Y-J)&=\operatorname{Cov}(J,Y)-\operatorname{Var}(J)\\ &=\tfrac1{12}-\tfrac1{12}=0. \end{aligned} \]

คำตอบข้อสอง: มกราคมกับสิบเอ็ดเดือนที่เหลือมี covariance ศูนย์พอดี 8.33% ที่ “อธิบายได้” มาจากการที่มกราคมถูกนับอยู่ในทั้งปีอย่างเดียว ไม่ได้ทำนายอนาคตเลย

ตรวจเองใน 10 วินาที: $\sqrt{12}\approx3.464$ ดังนั้น $1/3.464\approx0.289$ และ $0.289^2\approx0.0833$

ขั้นที่ 9 — ใส่หน่วยดอลลาร์ แล้วทำนายทั้งปีหลังเห็นมกราคม

ถึงเวลาตอบผู้บริหารเป็นดอลลาร์ ใช้แบบจำลอง $P_t=\sigma_PW_t$ หน่วยล้านดอลลาร์ ของที่รู้คือ $\sigma_P=12$ และ P&L สิ้นมกราคม $P_{1/12}=2$ เราจะทำนายผลทั้งปี $P_1$ สองทาง แล้วดูว่าตรงกันไหม

ทางแรก แยกเหมือน $A+B$: ยืนที่สิ้นมกราคม ผลทั้งปีคือส่วนที่รู้แล้ว $P_{1/12}$ บวกส่วนที่ยังไม่เกิด $P_1-P_{1/12}$ SD ของแต่ละส่วนคือ $\sigma_P$ คูณรากของความยาวช่วง ($\sqrt{1/12}$ สำหรับมกราคม และ $\sqrt{11/12}$ สำหรับที่เหลือ) ส่วนที่ยังไม่เกิดมีค่าเฉลี่ยศูนย์ เพราะไม่มี drift

\[ \begin{aligned} \operatorname{SD}(P_{1/12})&=12\sqrt{1/12}\approx3.464,\\ \operatorname{SD}(P_1-P_{1/12})&=12\sqrt{11/12}\approx11.489,\\ \mathbb E_{1/12}[P_1]&=P_{1/12}+\mathbb E_{1/12}[P_1-P_{1/12}]\\ &=2+0=2. \end{aligned} \]

ทางที่สอง ใช้สูตร MVN: $P_{1/12}$ กับ $P_1$ เป็น Normal คู่หนึ่ง สูตรค่าเฉลี่ยแบบมีเงื่อนไขของ MVN บอกว่า ถ้าเห็นค่าแรก $X_1=x_1$ แล้ว ค่าเฉลี่ยของค่าที่สอง $X_2$ คือ $\mu_2+\beta(x_1-\mu_1)$ โดย $\beta=\Sigma_{21}/\Sigma_{11}$ คือ regression slope และ variance ที่เหลือคือ $\Sigma_{2\cdot1}=\Sigma_{22}-\Sigma_{21}^2/\Sigma_{11}$ ($\Sigma_{11}$ คือ variance ของค่าแรก $\Sigma_{22}$ คือ variance ของค่าที่สอง และ $\Sigma_{21}$ คือ covariance ของทั้งสองค่า) ในที่นี้ $X_1=P_{1/12}$, $X_2=P_1$ และค่าเฉลี่ยทั้งคู่เป็นศูนย์ เพราะ $P=12W$ ทุก variance และ covariance ของ $P$ จึงเท่ากับของ $W$ คูณ $\sigma_P^2=12^2=144$

\[ \begin{aligned} \Sigma_{11}&=144\times\tfrac1{12}=12,\\ \Sigma_{21}&=144\times\min(\tfrac1{12},1)=12,\\ \Sigma_{22}&=144\times1=144,\\ \beta&=\Sigma_{21}/\Sigma_{11}=12/12=1,\\ \mathbb E_{1/12}[P_1]&=0+1\times(2-0)=2,\\ \Sigma_{2\cdot1}&=144-12^2/12=132. \end{aligned} \]

สองทางให้คำทำนายเดียวกัน คือ \$2 ล้าน ความไม่แน่นอนที่เหลือก็ตรงกัน $\sqrt{132}\approx\$11.49$ ล้าน เท่ากับ SD ของสิบเอ็ดเดือนที่เหลือจากทางแรก variance ของสองช่วงบวกกันได้ $12+132=144=12^2$ พอดี เพราะสองช่วงไม่ทับกันจึงเป็นอิสระต่อกัน

slope $\beta=1$ คือหัวใจของคำตอบ กำไรมกราคมเพิ่มหนึ่งดอลลาร์ คำทำนายทั้งปีก็เพิ่มหนึ่งดอลลาร์ ไม่ใช่สิบสองดอลลาร์ เพราะดอลลาร์นั้นถูกนับอยู่ในผลทั้งปีแล้ว และไม่ได้บอกอะไรเกี่ยวกับเดือนที่เหลือ

แล้วกำไร \$2 ล้านดีแค่ไหน มกราคมมี SD \$3.46 ล้าน กำไรนี้จึงสูงกว่าศูนย์เพียง $2/3.464\approx0.58$ SD ตาราง Normal บอกว่าโอกาสที่เดือนหนึ่งจะดีอย่างน้อยเท่านี้คือ $\Pr(Z\ge0.58)\approx28\%$ ($Z$ คือตัวสุ่ม Normal มาตรฐาน) หรือราวหนึ่งเดือนในทุกสามถึงสี่เดือน เดือนแบบนี้จึงไม่ใช่หลักฐานของฝีมือ

ส่วนตัวเลข \$24 ล้านของผู้บริหารมาจาก $2\times12$ ซึ่งสมมติว่ากำไรมกราคมคือ drift ที่จะเกิดซ้ำทุกเดือน ถ้าเอาเดือนเดียวมาประมาณ drift ทั้งปีด้วย $12P_{1/12}$ ค่าประมาณนี้มี SD $12\times3.464\approx\$41.6$ ล้านต่อปี ตัวเลข “จังหวะนี้” จึงคลาดได้ ±\$41.6 ล้าน มากกว่าตัวเลขเองเกือบสองเท่า แปลว่าไม่มีความหมายเลย

ความเกี่ยวกันที่เกิดจากการนับซ้ำ

อ่าน correlation เป็น % ที่อธิบายได้ นี่คือความผิดของนักวิเคราะห์ในห้องประชุม correlation 0.289 ไม่ใช่ 28.9% ของอะไรเลย สัดส่วนที่อธิบายได้ต้องยกกำลังสองก่อน: ผิดคือ 28.9% ถูกคือ $R^2=0.289^2\approx8.33\%$ และแม้ 8.33% นั้นก็มาจากการที่มกราคมถูกนับอยู่ในทั้งปี ไม่ใช่การทำนาย

หน้าต่างย้อนหลังที่ทับกัน ตัวเลขที่วัดจากช่วงเวลาที่ทับกันจะดูเกาะกันเองทั้งที่ไม่มีอะไรทำนายอะไร ตัวอย่างคือผลตอบแทนย้อนหลัง 12 เดือนที่วัดทุกสิ้นเดือน สองค่าที่ติดกันใช้ 11 เดือนร่วมกัน (รูปด้านล่าง) เรียกสองค่านั้นว่า $R_1$ และ $R_2$ สมมติให้แต่ละเดือนเป็นอิสระต่อกันและมี variance $1/12$ เท่ากัน (เลือกหน่วยให้ variance ทั้งปีเป็น 1) แต่ละค่าเป็นผลบวกของ 12 เดือน

\[ \begin{aligned} \operatorname{Var}(R_1)&=12\times\tfrac1{12}=1,\\ \operatorname{Cov}(R_1,R_2)&=11\times\tfrac1{12}=\tfrac{11}{12},\\ \rho&=\frac{11/12}{\sqrt1\,\sqrt1}\approx0.917. \end{aligned} \]

covariance มาจาก 11 เดือนที่ใช้ร่วมกันเท่านั้น เพราะเดือนที่ไม่ร่วมกันเป็นอิสระต่อกัน ผลคือ correlation 0.917 ทั้งที่ทุกเดือนอิสระต่อกันหมด กราฟของค่าเหล่านี้จะดูเรียบและมีแนวโน้ม ซึ่งเป็นภาพลวงจากการนับเดือนเดียวกันซ้ำ สังเกตว่ากรณีนี้ correlation คือสัดส่วนตรง ๆ (ช่วงที่ทับกันหารด้วยความยาวหน้าต่าง) ไม่ใช่รากของสัดส่วนเหมือนมกราคมกับทั้งปี เพราะที่นี่เทียบการขยับสองช่วงที่ยาวเท่ากัน ไม่ใช่ค่าที่สองเวลา

ใช้ $\min(u,v)$ แทนค่าเฉลี่ยของผลคูณเมื่อมี drift สูตร $\mathbb E[W_uW_v]=\min(u,v)$ ใช้ได้เพราะค่าเฉลี่ยเป็นศูนย์ ถ้ามี drift ต้องบวกผลคูณของค่าเฉลี่ยกลับเข้าไป สมมติกองทุนมี drift \$6 ล้านต่อปี (ตัวเลขสมมติ) ค่าเฉลี่ยสิ้นมกราคมคือ $\mathbb E[P_{1/12}]=6\times\tfrac1{12}=0.5$ และค่าเฉลี่ยสิ้นปีคือ $\mathbb E[P_1]=6$ drift ไม่สุ่ม จึงไม่เปลี่ยน covariance ซึ่งยังเป็น 12

\[ \begin{aligned} \mathbb E[P_{1/12}P_1]&=\operatorname{Cov}(P_{1/12},P_1)\\ &\quad+\mathbb E[P_{1/12}]\,\mathbb E[P_1]\\ &=12+0.5\times6=15. \end{aligned} \]

ผิดคือ 12 ถูกคือ 15 ส่วน covariance ยังเป็น 12 เหมือนเดิม ดังนั้นต้องหักผลคูณของค่าเฉลี่ยออกก่อนเสมอ ก่อนจะใช้ $\min(u,v)$

ใช้ทำอะไรบนโต๊ะจริง

คณะกรรมการลงทุนใช้การคำนวณมกราคมเทียบทั้งปี เพื่อตอบว่าผลระหว่างปีบอกอะไรได้บ้าง และเพื่ออธิบายว่าทำไมไม่ควรตัดสินผู้จัดการกองทุนจากผลไตรมาสเดียว

ทีม risk ใช้การแบ่ง variance $12+132=144$ เพื่อแบ่งงบความเสี่ยงของปี งบความเสี่ยงคือ variance ของ P&L ที่กองทุนยอมรับได้ทั้งปี การแบ่งนี้บอกว่าใช้ไปแล้วเท่าไร ($12$ จาก $144$ หลังมกราคม) และเหลือเท่าไร ($132$)

นักวิจัยใช้กับดักหน้าต่างทับกันตรวจสถิติแบบ rolling ก่อนเชื่อว่าเห็นแนวโน้ม (rolling คือคำนวณซ้ำทุกงวดจากหน้าต่างย้อนหลังที่เลื่อนไปทีละงวด เช่นผลตอบแทน 12 เดือนล่าสุดที่วัดทุกเดือน)

ตาราง covariance $\min(t_i,t_j)$ ยังพากลับไปที่หน้าการจำลอง MVN ด้วย Cholesky ถ้าต้องจำลองค่า $W$ ที่หลายวันพร้อมกัน วิธีทั่วไปคือแยก covariance matrix เป็น $LL^{\mathsf T}$ (เรียกว่า Cholesky โดย $L$ เป็น matrix สามเหลี่ยมล่าง) แล้วคูณ $L$ เข้ากับตัวสุ่ม Normal อิสระ สำหรับตารางนี้ ผลที่ได้คือการบวกสะสมของก้อนสุ่มอิสระทีละก้อน ซึ่งก็คือวิธีจำลองแบบ $\sqrt{\Delta t}\,Z$ (บวกก้อน $\sqrt{\Delta t}\,Z$ ทีละท่อน โดย $\Delta t$ คือความยาวท่อนเวลา และ $Z$ คือตัวสุ่ม Normal มาตรฐาน) ในหน้าstandard Brownian motion นั่นเอง (ดูโจทย์ข้อ 2)

โจทย์ตรวจความเข้าใจ

1. กองทุนเดิมยังมีความผันผวนทั้งปี $\sigma_P=\$12$ ล้าน และ P&L ไม่มี drift เหมือนเดิม คราวนี้ผ่านไปหนึ่งไตรมาส (สามเดือน) แล้ว P&L สะสมสิ้นไตรมาสแรกคือ $P_{3/12}=\$5$ ล้าน ผลไตรมาสแรกมี correlation กับผลทั้งปีเท่าไร อธิบายผลทั้งปีได้กี่ % และควรคาดผลทั้งปีเท่าไร?

เฉลย

สามเดือนคือ $u=3/12$ ปี เทียบกับสิ้นปี $v=1$ ใช้ $\rho=\sqrt{u/v}$ และ $R^2=u/v$ คำทำนายคือส่วนที่ได้แล้วบวกค่าเฉลี่ยศูนย์ของเก้าเดือนที่เหลือ และ SD ที่เหลือมาจากเก้าเดือนนั้น

\[ \begin{aligned} \rho&=\sqrt{3/12}=0.5,\\ R^2&=0.5^2=25\%,\\ \mathbb E_{3/12}[P_1]&=5+0=\$5,\\ \operatorname{SD}(P_1-P_{3/12})&=12\sqrt{9/12}\approx\$10.39. \end{aligned} \]

คำทำนายทั้งปีคือ \$5 ล้าน ไม่ใช่ $5\times4=\$20$ ล้าน และยังคลาดได้ราว \$10.39 ล้าน

2. ทีมวิจัยต้องการจำลองค่า SBM ที่สิ้นปีที่ 1, 2 และ 3 พร้อมกัน เขียน covariance matrix ของ $(W_1,W_2,W_3)$ แล้วแยก Cholesky ($\Sigma=LL^{\mathsf T}$ โดย $L$ เป็นสามเหลี่ยมล่าง) ได้ $L$ หน้าตาอย่างไร และ $L$ บอกอะไรเกี่ยวกับวิธีจำลอง?

เฉลย

ช่อง $(i,j)$ ของ matrix คือ $\min(i,j)$ ได้

\[ \Sigma=\begin{pmatrix}1&1&1\\1&2&2\\1&2&3\end{pmatrix} \]

Cholesky หาช่องของ $L$ ทีละคอลัมน์ $j$ จากซ้ายไปขวา ช่องทแยงคือ $\ell_{jj}=\sqrt{\Sigma_{jj}-\sum_{k\lt j}\ell_{jk}^2}$ และช่องใต้ทแยง ($i\gt j$) คือ $\ell_{ij}=\big(\Sigma_{ij}-\sum_{k\lt j}\ell_{ik}\ell_{jk}\big)/\ell_{jj}$ แทนตัวเลขทีละช่อง

\[ \begin{aligned} \ell_{11}&=\sqrt1=1,\\ \ell_{21}&=1/1=1,\quad \ell_{31}=1/1=1,\\ \ell_{22}&=\sqrt{2-1^2}=1,\\ \ell_{32}&=(2-1\cdot1)/1=1,\\ \ell_{33}&=\sqrt{3-1^2-1^2}=1. \end{aligned} \]

$L$ คือ matrix สามเหลี่ยมล่างที่ทุกช่องเป็น 1 ถ้า $z_1,z_2,z_3$ เป็นตัวสุ่ม Normal มาตรฐานอิสระ $W=Lz$ จะได้ $W_1=z_1$, $W_2=z_1+z_2$ และ $W_3=z_1+z_2+z_3$ คือผลบวกสะสมของก้อนสุ่มอิสระทีละก้อน ตรงกับการจำลอง Brownian motion แบบบวกท่อนสุ่มอิสระทีละท่อน

3. กลับทิศคำถาม สิ้นปีนักบัญชีรายงานว่าทั้งปีกองทุนได้ $P_1=\$12$ ล้านพอดี แต่ยังไม่มีใครเห็นตัวเลขรายเดือน ควรเดาว่ามกราคมได้เท่าไร และทำไม slope จึงไม่เป็น 1 เหมือนตอนทำนายทั้งปีจากมกราคม?

เฉลย

คราวนี้ตัวที่ใช้ทำนายคือผลทั้งปี slope จึงหารด้วย variance ของผลทั้งปี ค่าเฉลี่ยทั้งคู่เป็นศูนย์

\[ \begin{aligned} \beta&=\frac{\operatorname{Cov}(P_{1/12},P_1)}{\operatorname{Var}(P_1)}=\frac{12}{144}=\frac1{12},\\ \mathbb E[P_{1/12}\mid P_1=12]&=0+\tfrac1{12}\times(12-0)=\$1. \end{aligned} \]

คำเดาคือ \$1 ล้าน เท่ากับแบ่งผลทั้งปีให้แต่ละเดือนเท่า ๆ กันตามเวลา correlation ยังเป็น 0.289 เท่ากันทั้งสองทิศ แต่ slope ต่างกัน เพราะ slope หารด้วย variance ของตัวที่ใช้ทำนาย มกราคมมี variance 12 ส่วนทั้งปีมี variance 144

const covBM = (u, v) => Math.min(u, v);
const corrBM = (u, v) => Math.min(u, v) / Math.sqrt(u * v);
// Correlation of two increments of equal length L whose windows overlap by `overlap`.

// Exact average of W_(s+t) * W_s over every coin path: s then t steps of +/-1 (each step has variance 1).
function coinAverage(s, t) {
  let total = 0;
  const count = 2 ** (s + t);
  for (let code = 0; code < count; code++) {
    let w = 0, ws = 0;
    for (let k = 0; k < s + t; k++) {
      w += (code >> k) & 1 ? 1 : -1;
      if (k === s - 1) ws = w;
    }
    total += w * ws;
  }
  return total / count;
}
// Covariance matrix of W at the given times, and its Cholesky factor.
const covMatrix = times => times.map(u => times.map(v => covBM(u, v)));
function cholesky(S) {
  const n = S.length, L = S.map(() => new Array(n).fill(0));
  for (let j = 0; j < n; j++) {
    let p = S[j][j];
    for (let k = 0; k < j; k++) p -= L[j][k] ** 2;
    if (!(p > 0)) throw new RangeError(`Not positive definite at pivot ${j + 1}`);
    L[j][j] = Math.sqrt(p);
    for (let i = j + 1; i < n; i++) {
      let x = S[i][j];
      for (let k = 0; k < j; k++) x -= L[i][k] * L[j][k];
      L[i][j] = x / L[j][j];
    }
  }
  return L;
}
// mulberry32 + Box-Muller: seeded standard Normals.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let x = Math.imul(a ^ (a >>> 15), a | 1);
    x ^= x + Math.imul(x ^ (x >>> 7), x | 61);
    return (((x ^ (x >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Simulate January and the other eleven months, then measure what the formulas predict.
function simulateYears(n, seed) {
  const z = normals(seed), s = 1 / 12;
  let sj = 0, sy = 0, sr = 0, jj = 0, yy = 0, rr = 0, jy = 0, jr = 0;
  for (let i = 0; i < n; i++) {
    const jan = Math.sqrt(s) * z(), rest = Math.sqrt(1 - s) * z(), year = jan + rest;
    sj += jan; sy += year; sr += rest; jj += jan * jan; yy += year * year; rr += rest * rest;
    jy += jan * year; jr += jan * rest;
  }
  const cov = (xy, sx, sz) => xy / n - (sx / n) * (sz / n);
  const cJY = cov(jy, sj, sy), cJJ = cov(jj, sj, sj), cYY = cov(yy, sy, sy), cRR = cov(rr, sr, sr), cJR = cov(jr, sj, sr);
  return {meanProduct: jy / n, corrJanYear: cJY / Math.sqrt(cJJ * cYY), corrJanRest: cJR / Math.sqrt(cJJ * cRR), slope: cJY / cJJ};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ค่าที่สองเวลาพันกัน จึงต้องแยก $W_{t+s}=W_s+(W_{t+s}-W_s)$ ที่เวลา $s$ พอดี เพื่อให้ได้สองก้อนที่อิสระต่อกัน แล้วค่อยกระจายผลคูณ
  • พจน์ไขว้เป็นศูนย์ได้สองทาง ทางแรกยืนที่เวลา $s$ แล้วดึงค่าที่รู้แล้วออกมา ทางที่สองใช้ความเป็นอิสระตรง ๆ ส่วน $\mathbb E_0[A^2]=s$ เพราะค่าเฉลี่ยเป็นศูนย์ รวมกันจึงได้ $\mathbb E_0[W_{t+s}W_s]=s$
  • $\operatorname{Cov}(W_u,W_v)=\min(u,v)$ คือความยาวของประวัติที่สองจุดใช้ร่วมกัน เมื่อ $u\le v$ correlation คือ $\sqrt{u/v}$ และ $R^2=u/v$ เท่ากับสัดส่วนของเวลาที่เห็นแล้ว
  • มกราคมได้ \$2 ล้าน คำทำนายทั้งปีจึงเป็น $2+0=\$2$ ล้าน คลาดได้ราว $12\sqrt{11/12}\approx\$11.49$ ล้าน มกราคมอธิบายผลทั้งปีได้ $1/12\approx8.33\%$ และอธิบายสิบเอ็ดเดือนที่เหลือได้ 0%
  • หน้าต่างวัดผลที่ใช้ 11 จาก 12 เดือนร่วมกัน ให้ correlation $11/12\approx0.917$ โดยไม่มีการทำนายใด ๆ
