14.3 Estimators, Bias, and Standard Error

แยก bias ที่ทำให้คำตอบเอนไปทางเดิม ออกจากความสั่นของคำตอบ

วัดสิ่งเดิมด้วยข้อมูลสั้นสองชุดแล้วได้คำตอบต่างกัน; คำตอบชุดใดคือความจริง หรือทั้งคู่กำลังสั่นตาม sample?

เฉลย: ยังเลือกไม่ได้จนแยก bias ออกจาก standard error—ทั้งคู่อาจคลาดจากความจริงได้คนละแบบ. estimator ช่วยบอกว่าความคลาดมาจากการเล็งผิดหรือจาก sample ที่สั่น; optimizer ไม่ควรเชื่อทุกทศนิยมที่ noise สร้างขึ้น.

estimator / estimate
estimator คือกฎที่รับข้อมูลแล้วคืนตัวเลข เช่นค่าเฉลี่ยตัวอย่าง; estimate คือผลลัพธ์ครั้งที่กฎนั้นคำนวณได้ ใช้แยกสูตรที่ออกแบบจากตัวเลขหนึ่งครั้งที่เห็น
bias
bias คือค่าเฉลี่ยของ estimator ลบค่าจริงหลังจินตนาการเก็บ sample ซ้ำมากครั้ง ใช้วัดการเล็งผิดอย่างเป็นระบบ ไม่ใช่ความผิดพลาดของ sample ครั้งเดียว
variance / standard error
variance วัดการกระจายของ estimator ข้าม samples ส่วน standard error คือรากที่สองของมัน ใช้วัดว่าค่าประมาณสั่นมากน้อยเพียงใดในหน่วยเดียวกับ parameter
mean squared error (MSE)
mean squared error คือความคลาดเคลื่อนกำลังสองเฉลี่ยจากทั้ง variance และ bias ใช้เปรียบเทียบ estimator ที่อาจเอียงเล็กน้อยแต่มีความผันผวนต่ำกว่า
shrinkage
shrinkage คือการดึง estimate ที่ noisy เข้าหาค่าอ้างอิงที่มีเหตุผล ใช้ลด mean squared error และลด turnover ที่เกิดจาก input เปลี่ยนสุ่ม
Bessel's correction
Bessel's correction คือการหารผลรวมกำลังสองด้วย แทน เมื่อใช้ค่าเฉลี่ยจาก sample เดียวกัน ใช้แก้ downward bias ของ sample variance
covariance
covariance คือการเคลื่อนไหวร่วมของ returns สองชุด ใช้สร้าง covariance matrix เพื่อวัดความเสี่ยงรวมและประโยชน์จาก diversification
beta / leverage
beta คือ sensitivity ของ return ต่อ benchmark ส่วน leverage คือการขยาย exposure ด้วยเงินกู้หรือ derivatives ใช้แยก market exposure ออกจากผลตอบแทนที่ดูดีเพราะขนาด position
standard error (SE)
standard error คือความไม่แน่นอนของ estimator เมื่อเก็บ samples ใหม่ภายใต้ process เดิม ใช้กำกับ input ของ optimizer และรายงานความแม่นยำของ estimate

Worked Example — โจทย์และสิ่งที่ให้มา

ของที่โจทย์ให้ทุกครั้งที่ code พิมพ์ expected return, beta หรือ volatility มันไม่ได้พบ ‘ค่าจริง’ มันใช้ estimator ผลิต estimate หนึ่งค่า. ถ้าโลก reset แล้วเก็บข้อมูลใหม่ ค่า estimate จะเปลี่ยน; คำถามมืออาชีพจึงเป็นสองข้อเรียงกัน: formula เล็งค่าจริงโดยเฉลี่ยหรือไม่ และเมื่อเล็งถูกมันสั่นกว้างเท่าไร

สำหรับ allocation ผลกระทบไม่เท่ากัน: mean เป็น input ที่ noisy มาก, volatility มักวัดได้คมกว่า และ covariance อยู่กลาง ๆ. การส่งทุกตัวเข้า optimizer ด้วยความเชื่อเท่ากันจึงเหมือนเชื่อเครื่องชั่งกับพยากรณ์อากาศในระดับเดียวกัน

คำตอบ ตรวจเอง และแปลว่าอะไร

คำตอบสมมติ annual expected return ที่ประมาณได้คือ 8% และ annual volatility 20% จากข้อมูลหนึ่งปี. standard error ของ expected return จึงราว 20%; normal 95% interval รอบ estimate 8% กว้างตั้งแต่ -31.2% ถึง 47.2%. half-width 39.2 percentage points ใหญ่กว่า mean estimate หลายเท่า จึงไม่ควรส่ง mean ดิบเข้า optimizer โดยไม่ลดขนาดหรือใส่ uncertainty control

สำหรับ volatility การมี 252 daily observations ให้ standard error โดยประมาณ 0.891 percentage points. minute bars 98,280 แถวให้ตัวเลขราว 0.045 points ได้ก็ต่อเมื่อ independence และ microstructure assumptions ใช้ได้; ความถี่ที่สูงขึ้นไม่ได้ทำให้ estimate ของ mean คมขึ้นโดยอัตโนมัติ

ตรวจเองใน 10 วินาทีคูณ 1.96*20%=39.2% แล้วบวกและลบจาก mean 8% ต้องได้ช่วง -31.2% ถึง 47.2%. ใช้ความกว้างนี้ shrink expected return ก่อนส่งเข้า optimizer.

ระวังตรงนี้

กับดัก: unbiased ไม่เท่ากับดีที่สุด และ shrinkage ไม่เท่ากับความจริง

Bessel's correction แก้ bias ของ variance ภายใต้ iid แต่ไม่ได้แก้ outlier, stale price หรือ overlapping return. ขณะเดียวกัน shrinkage ลด MSE เฉลี่ยเมื่อ target สมเหตุผล; หากย่อ expected return ทุก asset เข้าศูนย์ใน regime ที่มี carry ชัดเจน ก็สร้าง bias ใหม่

ใน production ให้ version target และ weight, backtest turn-over หลัง costs, stress target misspecification, และตั้ง guardrail ที่ weights ไม่ตอบสนองเต็มที่ต่อการแกว่งของ mean estimate. Portfolio ที่ยอมรับว่าไม่รู้บางส่วนมักอยู่รอดนานกว่า portfolio ที่ให้ optimizer พูดเสียงดังแทนข้อมูล.

ก่อนไปต่อ — สู่ confidence interval

bias และ standard error เปลี่ยน estimate จุดเดียวให้มีที่มาแล้ว. ขั้นต่อไปคือสื่อสารความไม่แน่นอนโดยตรง: สร้างช่วงที่ครอบค่าจริงตามความถี่ที่ประกาศ และอ่านประโยค ‘95% confidence’ ให้ถูก.

สรุปที่ใช้ได้จริง

  • estimator ต้องถูกตรวจทั้ง bias และ standard error; error สองชนิดนี้มีมาตรการแก้ต่างกัน.
  • one year ที่ volatility ให้ standard error ของ expected return ราว , แม้ volatility เองวัดได้คมกว่ามาก.
  • แก้ downward bias ของ sample variance แต่ไม่ซ่อม data quality หรือ dependence.
  • shrinkage เป็น risk control ต่อ noisy inputs เมื่อ target, units และ uncertainty ถูกกำกับอย่างชัดเจน.
