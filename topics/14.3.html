14.3 Estimators, Bias, and Standard Error

แยก bias ที่ทำให้คำตอบเอนไปทางเดิม ออกจากความสั่นของคำตอบ

วัดสิ่งเดิมด้วยข้อมูลสั้นสองชุดแล้วได้คำตอบต่างกัน; คำตอบชุดใดคือความจริง หรือทั้งคู่กำลังสั่นตาม sample?

เฉลย: ยังเลือกไม่ได้จนแยก bias ออกจาก standard error—ทั้งคู่อาจคลาดจากความจริงได้คนละแบบ. estimator ช่วยบอกว่าความคลาดมาจากการเล็งผิดหรือจาก sample ที่สั่น; optimizer ไม่ควรเชื่อทุกทศนิยมที่ noise สร้างขึ้น.

ศัพท์ที่ใช้ในหัวข้อนี้
estimator

คืออะไร: สูตรหรือวิธีการ ที่รับข้อมูลเข้าไปแล้วคายตัวเลขออกมา

ใช้ทำอะไร: เป็นสิ่งที่เราวิเคราะห์คุณสมบัติของมัน เช่นเอนเอียงไหม แม่นแค่ไหน

ทำไมต้องมองว่าเป็นสูตร: เพราะคุณสมบัติเหล่านั้นเป็นของวิธีการ ไม่ใช่ของตัวเลข ถามว่าตัวเลข 1.2 เอนเอียงไหมนั้นไม่มีความหมาย ต้องถามว่าวิธีที่ให้ 1.2 มาเอนเอียงไหม

estimate

คืออะไร: ตัวเลขจริงที่ได้ออกมา เมื่อใส่ข้อมูลชุดที่มีอยู่ลงในสูตรนั้น

ใช้ทำอะไร: เป็นตัวเลขที่เราเอาไปรายงานและใช้ตัดสินใจ

ทำไมต้องแยกให้ชัด: เพราะข้อมูลอีกชุดหนึ่งจะให้ตัวเลขอีกค่าหนึ่งจากสูตรเดียวกัน การเผลอคิดว่าตัวเลขที่ได้คือความจริง คือรากของความมั่นใจเกินเหตุทั้งบท

bias
bias คือค่าเฉลี่ยของ estimator ลบค่าจริงหลังจินตนาการเก็บ sample ซ้ำมากครั้ง ใช้วัดการเล็งผิดอย่างเป็นระบบ ไม่ใช่ความผิดพลาดของ sample ครั้งเดียว
variance

คืออะไร: ขนาดการกระจายแบบยกกำลังสอง ของสิ่งที่เรากำลังวัด

ใช้ทำอะไร: ใช้บอกว่าข้อมูลดิบแต่ละตัวกระจายกว้างแค่ไหน

ทำไมต้องแยกจากตัวถัดไป: เพราะตัวนี้พูดถึงข้อมูลแต่ละตัว ไม่ได้พูดถึงความแม่นของตัวเลขสรุปที่เราคำนวณจากข้อมูลทั้งชุด

mean squared error (MSE)
mean squared error คือความคลาดเคลื่อนกำลังสองเฉลี่ยจากทั้ง variance และ bias ใช้เปรียบเทียบ estimator ที่อาจเอียงเล็กน้อยแต่มีความผันผวนต่ำกว่า
shrinkage
shrinkage คือการดึง estimate ที่ noisy เข้าหาค่าอ้างอิงที่มีเหตุผล ใช้ลด mean squared error และลด turnover ที่เกิดจาก input เปลี่ยนสุ่ม
Bessel's correction
Bessel's correction คือการหารผลรวมกำลังสองด้วย $n-1$ แทน $n$ เมื่อใช้ค่าเฉลี่ยจาก sample เดียวกัน ใช้แก้ downward bias ของ sample variance
covariance
covariance คือการเคลื่อนไหวร่วมของ returns สองชุด ใช้สร้าง covariance matrix เพื่อวัดความเสี่ยงรวมและประโยชน์จาก diversification
beta

คืออะไร: ตัวเลขที่บอกว่าสินทรัพย์ของเราขยับกี่เท่าเมื่อตลาดโดยรวมขยับหนึ่งหน่วย

ใช้ทำอะไร: ใช้แยกว่าผลตอบแทนมาจากการตามตลาด หรือมาจากฝีมือจริง

ทำไมต้องแยก: เพราะการตามตลาดเป็นสิ่งที่ใครก็ทำได้ด้วยต้นทุนแทบเป็นศูนย์ ส่วนที่มีมูลค่าจึงเหลือเฉพาะสิ่งที่เกินจากนั้น

leverage

คืออะไร: การใช้เงินยืมเพื่อถือสถานะใหญ่กว่าเงินทุนที่มี

ใช้ทำอะไร: ใช้ขยายทั้งกำไรและขาดทุนด้วยตัวคูณเดียวกัน

ทำไมถึงทำให้สถิติหลอกได้: เพราะมันขยายผลตอบแทนเฉลี่ยขึ้นได้ตามใจ ตัวเลขที่ดูดีขึ้นจึงอาจไม่ได้มาจากฝีมือที่ดีขึ้นเลย

standard error (SE)

คืออะไร: ขนาดที่ตัวเลขสรุปของเราจะแกว่ง ถ้าเก็บข้อมูลใหม่อีกชุดหนึ่ง

ใช้ทำอะไร: เป็นตัวเลขที่บอกว่าคำตอบของเราเชื่อได้แค่ไหน

ทำไมถึงเล็กกว่าตัวบน: เพราะการเฉลี่ยหักล้างความสุ่มบางส่วนออกไป และมันเล็กลงตามรากของจำนวนข้อมูล ซึ่งแปลว่าอยากแม่นขึ้นเท่าตัวต้องเก็บเพิ่มสี่เท่า

สัญลักษณ์ที่ใช้ในหัวข้อนี้
สัญลักษณ์ความหมายหน่วย

ที่มาที่ไป: ตัวเลขที่คำนวณจากข้อมูล ไม่ใช่ความจริง

ความผิดพลาดพื้นฐานที่สุดในงานเชิงปริมาณคือ การลืมว่าตัวเลขที่คำนวณจากข้อมูลเป็นเพียงค่าประมาณ ไม่ใช่ค่าจริง

Ronald Fisher เป็นคนวางกรอบคิดเรื่องนี้ไว้ในช่วงต้นศตวรรษที่ยี่สิบ โดยแยกความผิดพลาดออกเป็นสองแบบ ที่ต้องแก้คนละวิธี

แบบแรกคือการเล็งเบี้ยวไปทางเดิมทุกครั้ง ซึ่งเพิ่มข้อมูลเท่าไรก็ไม่หาย ต้องแก้ที่วิธีคำนวณ

แบบที่สองคือการเล็งถูกแต่มือสั่น ซึ่งลดลงได้ด้วยการเพิ่มข้อมูล

การแยกสองแบบนี้ออกจากกันสำคัญมากในการเงิน เพราะมันนำไปสู่ข้อค้นพบที่ขัดสัญชาตญาณ คือการเก็บข้อมูลถี่ขึ้นช่วยวัดความผันผวนได้ดีขึ้นมาก แต่แทบไม่ช่วยวัดผลตอบแทนเฉลี่ยเลย

Worked Example — โจทย์และสิ่งที่ให้มา

โจทย์ให้อะไรมาบ้าง: ทุกครั้งที่ code พิมพ์ expected return, beta หรือ volatility มันไม่ได้พบ ‘ค่าจริง’ มันใช้ estimator ผลิต estimate หนึ่งค่า. ถ้าโลก reset แล้วเก็บข้อมูลใหม่ ค่า estimate จะเปลี่ยน; คำถามมืออาชีพจึงเป็นสองข้อเรียงกัน: formula เล็งค่าจริงโดยเฉลี่ยหรือไม่ และเมื่อเล็งถูกมันสั่นกว้างเท่าไร

สำหรับ allocation ผลกระทบไม่เท่ากัน: mean เป็น input ที่ noisy มาก, volatility มักวัดได้คมกว่า และ covariance อยู่กลาง ๆ. การส่งทุกตัวเข้า optimizer ด้วยความเชื่อเท่ากันจึงเหมือนเชื่อเครื่องชั่งกับพยากรณ์อากาศในระดับเดียวกัน

ขั้นที่ 1 — ลองด้วยมือ: สองข้อมูลก็พอพิสูจน์ว่าทำไมต้องหาร n − 1

ก่อนเชื่อสูตร ลองกับข้อมูลแค่สองตัว จะเห็นว่าทำไมการเอาจำนวนข้อมูลมาหารตรง ๆ ถึงให้ variance ต่ำไป

\[ \begin{aligned}n=2:&\quad\hat\mu=\frac{x_1+x_2}{2},\qquad x_1-\hat\mu=\frac{x_1-x_2}{2},\qquad x_2-\hat\mu=-\frac{x_1-x_2}{2}\\ \sum(x_i-\hat\mu)^2&=2\Big(\frac{x_1-x_2}{2}\Big)^2=\frac{(x_1-x_2)^2}{2}\\ E[(x_1-x_2)^2]&=\operatorname{Var}(x_1)+\operatorname{Var}(x_2)=2\sigma^2\qquad\Rightarrow\qquad E\Big[\sum(x_i-\hat\mu)^2\Big]=\sigma^2\\ \text{divide by }n=2:&\ E=\tfrac12\sigma^2\ (\text{too small}),\qquad\text{divide by }n-1=1:\ E=\sigma^2\ \checkmark\end{aligned} \]

ข้อมูลสองตัวเท่านั้น ค่าเฉลี่ยตัวอย่างอยู่ตรงกลางระหว่างมันพอดี ระยะห่างจากค่าเฉลี่ยจึงเท่ากันทั้งคู่ คือครึ่งหนึ่งของระยะระหว่างข้อมูลสองตัว

ผลรวมกำลังสองที่ได้ มีค่าเฉลี่ยเท่ากับ $\sigma^2$ *หนึ่งตัว* ไม่ใช่สองตัว เพราะค่าเฉลี่ยตัวอย่างถูกดึงไปอยู่ตรงกลางข้อมูลเสมอ มันจึง ‘กิน’ ระยะห่างไปหนึ่งหน่วย (หัวข้อ 6.5 ใช้ $\operatorname{Var}(x_1-x_2)=2\sigma^2$ เมื่ออิสระ)

เอา 2 มาหารจึงได้ครึ่งเดียวของความจริง เอา 1 มาหารได้พอดี กับ $n$ ทั่วไป เหตุผลเดียวกันให้ตัวหาร $n-1$ นี่คือ Bessel's correction ที่ขั้นถัดไปเขียนเป็นสูตร

ขั้นที่ 2 — สอง estimator พื้นฐาน และเหตุผลของ $n-1$

เริ่มจากสองสูตรที่ใช้กันทุกวัน พร้อมตอบคำถามที่ทุกคนสงสัยว่าทำไมต้องส่วนด้วยหนึ่งน้อยกว่าจำนวนข้อมูล เจ็ดบรรทัดนี้ตอบว่าเพราะค่าเฉลี่ยที่ใช้ก็ประมาณมาเหมือนกัน ระยะห่างที่วัดได้จึงเล็กกว่าความจริงอยู่พอดีหนึ่งหน่วย

\[ \begin{aligned}\hat\mu&=\frac1n\sum_{i=1}^{n}r_i,\qquad\hat\sigma^{2}=\frac{1}{n-1}\sum_{i=1}^{n}(r_i-\hat\mu)^{2}\\[4pt] r_i-\hat\mu&=(r_i-\mu)-(\hat\mu-\mu)\\ \sum_i(r_i-\hat\mu)^{2}&=\sum_i(r_i-\mu)^{2}-n(\hat\mu-\mu)^{2}\\ \mathbb E\Big[\sum_i(r_i-\mu)^{2}\Big]&=n\sigma^{2}\\ \mathbb E\big[(\hat\mu-\mu)^{2}\big]&=\operatorname{Var}(\hat\mu)=\frac{\sigma^{2}}{n}\\ \mathbb E\Big[\sum_i(r_i-\hat\mu)^{2}\Big]&=n\sigma^{2}-n\frac{\sigma^{2}}{n}=(n-1)\sigma^{2}\\ \Longrightarrow\ \mathbb E[\hat\sigma^{2}]&=\sigma^{2}\end{aligned} \]

สองบรรทัดแรกคือสูตรที่ใช้กันทุกวัน ส่วนที่เหลือทั้งหมดคือคำตอบว่าทำไมตัวหารเป็น $n-1$ ไม่ใช่ $n$

เติมและลบค่าจริงหนึ่งครั้ง เป็นกลวิธีเดิมที่ใช้ทั้งเล่ม ยกกำลังสองแล้วบวก พจน์ไขว้ยุบได้เพราะผลรวมของระยะห่างจากค่าจริง เท่ากับ $n$ เท่าของระยะห่างของค่าเฉลี่ย

ทีนี้เฉลี่ยทั้งสองก้อน ก้อนแรกคือ variance ตามนิยาม บวก $n$ ก้อน ส่วนก้อนที่สองใช้ผลของหัวข้อ 14.1 ว่าค่าเฉลี่ยตัวเองก็มีความกว้าง ลบกันเหลือ $n-1$ พอดี

รากของเรื่องคือ เราวัดระยะห่างจากค่าเฉลี่ยที่คำนวณจากข้อมูลชุดเดียวกัน ค่าเฉลี่ยตัวนั้นจึงเข้าข้างข้อมูลอยู่แล้ว ระยะห่างที่วัดได้จึงสั้นกว่าความจริงเสมอ การส่วนด้วย $n-1$ ชดเชยตรงนี้พอดี

ขั้นที่ 3 — แยกการเล็งผิดออกจากการสั่น

คำตอบผิดได้สองแบบที่ต้องแก้คนละวิธี แบบหนึ่งคือเล็งเบี้ยวไปทางเดิมทุกครั้ง อีกแบบคือเล็งถูกแต่มือสั่น หกบรรทัดนี้แสดงว่าสองแบบนี้บวกกันได้สนิท ไม่มีส่วนทับซ้อน ซึ่งเป็นสิ่งที่ทำให้การแลกอย่างหนึ่งกับอีกอย่างในขั้นที่ 6 เป็นไปได้

\[ \begin{aligned}\operatorname{Bias}(\hat\theta)&:=\mathbb E[\hat\theta]-\theta\\ \operatorname{MSE}(\hat\theta)&:=\mathbb E\big[(\hat\theta-\theta)^{2}\big]\\[4pt] \hat\theta-\theta&=\big(\hat\theta-\mathbb E\hat\theta\big)+\big(\mathbb E\hat\theta-\theta\big)\\ (\hat\theta-\theta)^{2}&=\big(\hat\theta-\mathbb E\hat\theta\big)^{2}+2\big(\hat\theta-\mathbb E\hat\theta\big)\operatorname{Bias}+\operatorname{Bias}^{2}\\ \mathbb E\big[\hat\theta-\mathbb E\hat\theta\big]&=0\;\Longrightarrow\;\text{cross term}=0\\ \operatorname{MSE}(\hat\theta)&=\operatorname{Var}(\hat\theta)+\operatorname{Bias}(\hat\theta)^{2}\end{aligned} \]

สองบรรทัดแรกเป็น นิยาม ของสองคำ คือการเล็งเบี้ยว กับความผิดพลาดเฉลี่ยยกกำลังสอง

เติมและลบค่าเฉลี่ยของ estimator เอง เพื่อแยกความผิดพลาดเป็นสองส่วน คือส่วนที่สั่นรอบจุดที่เล็ง กับส่วนที่จุดเล็งเบี้ยวจากเป้า ยกกำลังสองได้สามพจน์

พจน์ไขว้หายไปทั้งก้อน เพราะค่าเฉลี่ยของระยะห่างจากค่าเฉลี่ยตัวเองเป็นศูนย์เสมอ และการเล็งเบี้ยวเป็นเลขคงที่ที่ดึงออกมาได้

เหลือสองพจน์ที่แยกกันสนิท คือมือสั่นกับเล็งเบี้ยว สองอย่างนี้แก้คนละวิธี มือสั่นแก้ด้วยข้อมูลมากขึ้น ส่วนเล็งเบี้ยวไม่หายไม่ว่าจะเก็บข้อมูลอีกกี่ปี นั่นคือเหตุผลที่ต้องแยกมันออกจากกัน

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

การแยกความผิดพลาดสองแบบออกจากกัน บอกว่าควรแก้ปัญหาด้วยวิธีไหน

ใช้ตัดสินว่าจะเก็บข้อมูลถี่ขึ้นหรือยาวขึ้น เพราะสองอย่างนี้ช่วยคนละเรื่อง การเก็บถี่ช่วยวัดความผันผวน ส่วนการเก็บยาวช่วยวัดผลตอบแทนเฉลี่ย

ใช้รายงานค่าที่ประมาณมาพร้อมความคลาดเคลื่อน ซึ่งเป็นมาตรฐานขั้นต่ำของงานเชิงปริมาณ

ใช้เป็นเหตุผลของการยอมให้ค่าเบี้ยวเล็กน้อยเพื่อให้นิ่งขึ้น ซึ่งคือแนวคิดของหัวข้อ 17.8

ขั้นที่ 4 — mean กับ volatility ใช้ข้อมูลคนละแบบ

ข้อเท็จจริงที่สำคัญที่สุดของหัวข้อนี้ คือการเก็บข้อมูลถี่ขึ้นช่วยวัดความผันผวนได้ดีขึ้นมาก แต่แทบไม่ช่วยวัดผลตอบแทนเฉลี่ยเลย และเหตุผลอยู่ที่บรรทัดแรกบรรทัดเดียว นี่คือสาเหตุที่ optimizer ในหัวข้อ 17.3 ให้น้ำหนักสุดโต่ง

\[ \begin{aligned}\hat\mu_{\rm ann}&=\frac{\log P_{\rm end}-\log P_{\rm start}}{T}\\[4pt] \operatorname{SE}(\hat\mu)&\approx\frac{\sigma}{\sqrt T}\qquad(T:\ \mathrm{years})\\[4pt] \operatorname{SE}(\hat\sigma)&\approx\frac{\sigma}{\sqrt{2n}}\qquad(n:\ \mathrm{observations})\\[4pt] T=5,\ n=1{,}260:\quad\frac{\operatorname{SE}(\hat\sigma)/\sigma}{\operatorname{SE}(\hat\mu)/\sigma}&=\frac{1/\sqrt{2{,}520}}{1/\sqrt5}=\frac{\sqrt5}{\sqrt{2{,}520}}\approx0.045\end{aligned} \]

บรรทัดแรกคือเหตุผลทั้งหมดของหัวข้อนี้ ค่าเฉลี่ยของ log return ตลอดช่วง ยุบเหลือแค่จุดเริ่มกับจุดจบ เพราะพจน์กลางหักกันหมด ตามหัวข้อ 1.10

ถ้าอย่างนั้น ความแม่นของผลตอบแทนเฉลี่ยก็ขึ้นกับความยาวช่วงเวลาเท่านั้น ซอยถี่ขึ้นไม่ช่วยเลยสักนิด เพราะข้อมูลที่เพิ่มมาไม่ได้บอกอะไรใหม่เกี่ยวกับจุดเริ่มกับจุดจบ

ความเหวี่ยงต่างออกไปโดยสิ้นเชิง มันขึ้นกับจำนวนครั้งที่วัด ไม่ใช่ความยาวช่วง บรรทัดสามเป็นค่าประมาณที่ใช้ได้เมื่อข้อมูลเป็นระฆังและไม่เกี่ยวกัน

เทียบด้วยเลขจริง ห้าปีที่วัดรายวัน ความแม่นสัมพัทธ์ของความเหวี่ยงดีกว่าของผลตอบแทนราวยี่สิบเท่า ตัวเลขนี้ควรจำ เพราะมันอธิบายว่าทำไมคนถึงพยากรณ์ความเสี่ยงได้ดีกว่าพยากรณ์ผลตอบแทนมาก

ที่มาและเบื้องหลัง: ทำไม Merton จึงเตือนว่าอย่าพยายามเดา drift จากข้อมูลความถี่สูง

Robert C. Merton (ราว ๆ 1980) เสนอข้อสังเกตสำคัญในเปเปอร์คลาสสิกเกี่ยวกับการประมาณ expected return ว่าการซอยข้อมูลให้ถี่ขึ้นช่วยลดความไม่แน่นอนของ volatility ได้อย่างมหาศาล แต่แทบไม่ช่วย expected return เลย

นักปฏิบัติการจำนวนมากในยุคนั้นเชื่อว่า หากเปลี่ยนข้อมูลจากรายเดือนเป็นรายวันหรือรายนาที จะทำให้ model มองเห็นทิศทางของตลาดได้คมชัดขึ้น แต่ความจริงทางคณิตศาสตร์คือ ข้อมูลที่ซอยย่อยลงไปในกรอบเวลาเดิม $T$ เพียงแค่บันทึก noise เดิมซ้ำ ๆ ด้วย sample size $n$ ที่ใหญ่ขึ้น

สูตร $\sigma/\sqrt{2n}$ จึงเป็นสะพานเชื่อมที่บอกว่า ทำไมเราถึงวัด risk ได้แม่นยำมากจนนำไปคำนวณ VaR ได้ แต่ยังคงต้องเจอกับความมืดบอดเมื่อพยายามพยากรณ์ alpha หรือ drift

ขั้นที่ 5 — ที่มาของ standard error ของ volatility: พิสูจน์ด้วย moments และ Taylor expansion

สูตร $\sigma/\sqrt{2n}$ ไม่ได้เกิดขึ้นลอย ๆ แต่เป็นผลลัพธ์ของ Delta method บน sample variance ซึ่งยืนยันว่าการเก็บข้อมูลความถี่สูงช่วยให้เราเห็นความผันผวนได้อย่างคมชัด

\[ \begin{aligned}Z_i&:=\frac{r_i-\mu}{\sigma}\sim\mathcal N(0,1),\quad\mathbb E[Z_i^2]=1,\quad\mathbb E[Z_i^4]=3\\ \operatorname{Var}(Z_i^2)&=\mathbb E[Z_i^4]-(\mathbb E[Z_i^2])^2=3-1^2=2\\ \operatorname{Var}(\hat\sigma^2)&=\operatorname{Var}\!\left(\frac{\sigma^2}{n-1}\sum_{i=1}^{n-1}Z_i^2\right)=\frac{\sigma^4}{(n-1)^2}\cdot 2(n-1)=\frac{2\sigma^4}{n-1}\approx\frac{2\sigma^4}{n}\\ g(v)&:=\sqrt v,\quad g'(v)=\frac1{2\sqrt v},\quad g'(\sigma^2)=\frac1{2\sigma}\quad\text{(Delta method)}\\ \operatorname{Var}(\hat\sigma)&\approx\big[g'(\sigma^2)\big]^2\operatorname{Var}(\hat\sigma^2)=\frac1{4\sigma^2}\cdot\frac{2\sigma^4}{n}=\frac{\sigma^2}{2n}\\ \Longrightarrow\quad\operatorname{SE}(\hat\sigma)&=\sqrt{\operatorname{Var}(\hat\sigma)}\approx\frac{\sigma}{\sqrt{2n}}\end{aligned} \]

เริ่มจากพฤติกรรมของ standard normal ตัวแปรเดี่ยว พจน์กำลังสองมี expected value เท่ากับหนึ่ง และพจน์กำลังสี่เท่ากับสามจากการคำนวณ integral ตามแกนระฆังคว่ำ เมื่อลบกำลังสองของค่าเฉลี่ยออก variance ของกำลังสองจึงเท่ากับสองพอดี

เมื่อนำมาเฉลี่ยรวมกัน $n-1$ ตัวที่เป็นอิสระต่อกัน variance ของ sample variance $\hat\sigma^2$ จึงออกมาเป็น $2\sigma^4/(n-1)$ นี่คือความกว้างของการสั่นในแกนยกกำลังสอง

แต่สิ่งที่เราต้องการคือ volatility $\hat\sigma$ ไม่ใช่กำลังสอง เราจึงใช้ Delta method ซึ่งคือ Taylor expansion รอบจุดจริง $\sigma^2$ ตัว derivative ของ square root ดึงตัวคูณ $1/(2\sigma)$ ออกมา เมื่อยกกำลังสองจะกลายเป็น $1/(4\sigma^2)$ ไปตัดกับเลขสองในเศษ

ถอดรากที่สองออกมาจะได้สูตรที่คุ้นเคย: standard error ของ volatility หดตัวด้วยสเกล $1/\sqrt{2n}$ ยิ่งเพิ่มจำนวนการสังเกต $n$ มากขึ้นเท่าไร ตัวเลขความเหวี่ยงก็ยิ่งนิ่งและคมชัดขึ้นเท่านั้น

ลองแทนตัวเลขจริงหนึ่งปี ($n=252$ วัน) ที่ $\sigma=0.20$: จะได้ $\operatorname{SE}(\hat\sigma)\approx 0.20/\sqrt{504}\approx 0.0089$ หรือต่ำกว่า $1\%$ ขณะที่ $\operatorname{SE}(\hat\mu)$ สูงถึง $20\%$ ความแม่นยำจึงต่างกันกว่ายี่สิบเท่า

คำตอบ ตรวจเอง และแปลว่าอะไร

คำตอบและความหมาย: สมมติ annual expected return ที่ประมาณได้คือ 8% และ annual volatility 20% จากข้อมูลหนึ่งปี. standard error ของ expected return จึงราว 20%; normal 95% interval รอบ estimate 8% กว้างตั้งแต่ -31.2% ถึง 47.2%. half-width 39.2 percentage points ใหญ่กว่า mean estimate หลายเท่า จึงไม่ควรส่ง mean ดิบเข้า optimizer โดยไม่ลดขนาดหรือใส่ uncertainty control

สำหรับ volatility การมี 252 daily observations ให้ standard error โดยประมาณ 0.891 percentage points. minute bars 98,280 แถวให้ตัวเลขราว 0.045 points ได้ก็ต่อเมื่อ independence และ microstructure assumptions ใช้ได้; ความถี่ที่สูงขึ้นไม่ได้ทำให้ estimate ของ mean คมขึ้นโดยอัตโนมัติ

ตรวจเองใน 10 วินาที: คูณ 1.96*20%=39.2% แล้วบวกและลบจาก mean 8% ต้องได้ช่วง -31.2% ถึง 47.2%. ใช้ความกว้างนี้ shrink expected return ก่อนส่งเข้า optimizer.

ขั้นที่ 6 — ยอม bias เพื่อ MSE ที่ต่ำกว่า

บางครั้งการยอมให้เล็งเบี้ยวนิดหน่อย แลกกับมือที่นิ่งขึ้นมาก กลับให้คำตอบที่ดีกว่า เจ็ดบรรทัดนี้คือแนวคิดเบื้องหลัง shrinkage ทั้งหมดในหัวข้อ 17.8 ข้อควรระวังคือ $w^{*}$ ต้องใช้ค่าจริงที่เราไม่รู้ จึงใช้เพื่อเข้าใจ ไม่ใช่ใช้ตรง ๆ

\[ \begin{aligned}\tilde\mu&:=w\hat\mu,\qquad V:=\operatorname{Var}(\hat\mu)\\ \operatorname{Bias}&=\mathbb E[w\hat\mu]-\mu=w\mu-\mu=-(1-w)\mu\\ \operatorname{Var}(\tilde\mu)&=w^{2}V\\ \operatorname{MSE}(w)&=w^{2}V+(1-w)^{2}\mu^{2}\qquad\text{(step 3)}\\ \frac{d}{dw}\operatorname{MSE}&=2wV-2(1-w)\mu^{2}=0\\ w\big(V+\mu^{2}\big)&=\mu^{2}\\ w^{*}&=\frac{\mu^{2}}{\mu^{2}+V}\end{aligned} \]

ลองของแปลก ย่อค่าที่วัดได้เข้าหาศูนย์ด้วยตัวคูณระหว่างศูนย์กับหนึ่ง ฟังดูเหมือนทำให้แย่ลง เพราะมันสร้างการเล็งเบี้ยวที่ไม่เคยมี

แต่ดูสิ่งที่ได้มาแทน ความสั่นลดลงตามกำลังสองของตัวคูณ ในขณะที่การเล็งเบี้ยวโตแค่เชิงเส้น ประกอบสองอย่างด้วยสูตรของขั้นที่ 3 หา derivative แล้วตั้งเป็นศูนย์

แก้สมการได้ตัวคูณที่ดีที่สุด และมันอ่านความหมายได้ตรง ๆ ถ้าสัญญาณแรงเมื่อเทียบกับความสั่น ตัวคูณเข้าใกล้หนึ่ง คือแทบไม่ต้องย่อ

แต่ถ้าความสั่นใหญ่กว่าสัญญาณมาก ตัวคูณเข้าใกล้ศูนย์ ซึ่งแปลว่าเดาศูนย์ยังดีกว่าเชื่อข้อมูล นั่นคือข้อสรุปที่ขัดสัญชาตญาณที่สุดในบทนี้ และเป็นของจริง

กับดัก: unbiased ไม่เท่ากับดีที่สุด และ shrinkage ไม่เท่ากับความจริง

Bessel's correction แก้ bias ของ variance ภายใต้ iid แต่ไม่ได้แก้ outlier, stale price หรือ overlapping return. ขณะเดียวกัน shrinkage ลด MSE เฉลี่ยเมื่อ target สมเหตุผล; หากย่อ expected return ทุก asset เข้าศูนย์ใน regime ที่มี carry ชัดเจน ก็สร้าง bias ใหม่

ใน production ให้ version target และ weight, backtest turn-over หลัง costs, stress target misspecification, และตั้ง guardrail ที่ weights ไม่ตอบสนองเต็มที่ต่อการแกว่งของ mean estimate. Portfolio ที่ยอมรับว่าไม่รู้บางส่วนมักอยู่รอดนานกว่า portfolio ที่ให้ optimizer พูดเสียงดังแทนข้อมูล.

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
การวัดความคลาดเคลื่อนคำนวณความคลาดเคลื่อนได้สูตรมาตรฐานสมมติว่าข้อมูลเป็นอิสระความคลาดเคลื่อนที่รายงานแคบเกินจริงเกือบเสมอ
ความเบี้ยวรู้ว่าเบี้ยวไปทางไหนความเบี้ยวจากการเลือกข้อมูลมองไม่เห็นการเลือกช่วงเวลาที่ผลงานดีทำให้ทุกตัวเลขเบี้ยวโดยไม่มีสูตรใดจับได้
ความคงที่ค่าที่แท้จริงไม่เปลี่ยนมันเปลี่ยนการเพิ่มข้อมูลไม่ได้ทำให้แม่นขึ้นเสมอไป ถ้าข้อมูลเก่ามาจากคนละยุค

แถวกลางเป็นความเบี้ยวที่ใหญ่ที่สุดในงานการเงิน และไม่มีสูตรไหนแก้ได้ ต้องแก้ด้วยวิธีทำงาน

ก่อนไปต่อ — สู่ confidence interval

bias และ standard error เปลี่ยน estimate จุดเดียวให้มีที่มาแล้ว. ขั้นต่อไปคือสื่อสารความไม่แน่นอนโดยตรง: สร้างช่วงที่ครอบค่าจริงตามความถี่ที่ประกาศ และอ่านประโยค ‘95% confidence’ ให้ถูก.

สรุปที่ใช้ได้จริง

  • estimator ต้องถูกตรวจทั้ง bias และ standard error; error สองชนิดนี้มีมาตรการแก้ต่างกัน.
  • one year ที่ volatility $20\%$ ให้ standard error ของ expected return ราว $20\%$, แม้ volatility เองวัดได้คมกว่ามาก.
  • $n-1$ แก้ downward bias ของ sample variance แต่ไม่ซ่อม data quality หรือ dependence.
  • shrinkage เป็น risk control ต่อ noisy inputs เมื่อ target, units และ uncertainty ถูกกำกับอย่างชัดเจน.
