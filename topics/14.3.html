14.3 The Greeks

Greeks คืออนุพันธ์ของสูตร Black–Scholes เทียบราคาหุ้น เวลา ความผันผวน และดอกเบี้ย บอกว่าพอร์ตได้เสียเท่าไรเมื่อแต่ละอย่างขยับนิดหนึ่ง

คุณทำงานที่โต๊ะ option ของธนาคาร คือทีมที่ซื้อขายสัญญา option ทั้งวัน เช้านี้คุณเพิ่งขาย call ให้ลูกค้า call คือสัญญาที่ให้สิทธิ์ผู้ซื้อ ซื้อหุ้นในราคาที่ตกลงไว้ล่วงหน้าเมื่อสัญญาหมดอายุ ราคาที่ตกลงไว้นี้เรียกว่า strike

ถ้าวันหมดอายุหุ้นขึ้นไปสูงกว่า strike คุณซึ่งเป็นผู้ขายต้องจ่ายส่วนต่างให้ลูกค้า ถ้าหุ้นต่ำกว่า strike คุณไม่ต้องจ่ายอะไร เพื่อแลกกับความเสี่ยงนี้ ลูกค้าจ่ายเงินก้อนหนึ่งให้คุณวันนี้ เรียกว่า premium

ของที่รู้ (ตัวเลขสมมติ):

  • ราคาหุ้นวันนี้ $S=\$35$
  • strike $K=\$36$
  • อายุสัญญา 3 เดือน คือ $\tau=0.25$ ปี หรือ $0.25\times365=91.25$ วัน
  • ดอกเบี้ยเงินฝาก $r=2\%$ ต่อปี
  • ความผันผวน $\sigma=24\%$ ต่อปี คือขนาดการแกว่งของผลตอบแทนหุ้นในหนึ่งปี
  • ราคา call ต่อหุ้น $C=\$1.3154$ ได้จากสูตร Black–Scholes เมื่อใส่ตัวเลขห้าตัวข้างบน
  • คุณขาย 100 สัญญา สัญญาละ 100 หุ้น รวม $100\times100=10{,}000$ หุ้น จึงรับ premium $10{,}000\times\$1.3154=\$13{,}154$

ก่อนตลาดเปิด หัวหน้าถามสี่ข้อ

  1. ต้องซื้อหุ้นถือไว้กี่หุ้น เพื่อให้หุ้นขึ้นหรือลงนิดหน่อยแล้วคุณไม่ได้ไม่เสีย การถือหุ้นเพื่อหักล้างแบบนี้เรียกว่า hedge
  2. ถ้าความผันผวนที่ตลาดใช้ตั้งราคา option ขึ้น 1 จุด (จาก 24% เป็น 25%) คุณเสียเท่าไร
  3. ถ้าวันนี้หุ้นไม่ขยับเลย คุณได้เท่าไร
  4. เมื่อ hedge แล้ว หุ้นต้องแกว่งวันละกี่ดอลลาร์ คุณจึงเริ่มขาดทุน

เพื่อนร่วมโต๊ะตอบข้อสามทันที เขาให้เหตุผลว่า ถ้าหุ้นอยู่ที่ \$35 ไปจนหมดอายุ call จะไม่มีค่า premium \$13,154 จึงละลายเป็นกำไรของผู้ขายจนหมด เขาคิดว่ามันละลายเท่า ๆ กันทุกวัน จึงได้วันละ $13{,}154/91.25=\$144.15$ ถูกไหม

ลองตอบก่อนเปิดเฉลย

ไม่ถูก คำตอบทั้งสี่ข้อเป็นดังนี้ และหน้านี้จะคำนวณให้ดูทีละขั้น

  1. ซื้อหุ้น 4,471 หุ้น
  2. เสีย \$692
  3. ได้ \$98.85 ไม่ใช่ \$144.15 เพราะ premium ไม่ได้ละลายเป็นเส้นตรง ช่วงต้นละลายช้า ช่วงท้ายละลายเร็ว ถ้าหุ้นอยู่ที่ \$35 ตลอด ตอนเหลือ 5 วันจะละลายถึงวันละ \$246
  4. เมื่อ hedge แล้ว คุณขาดทุนเมื่อหุ้นแกว่งเกินวันละ ±\$0.44 คิดเป็น $0.44/35\approx1.26\%$ ตัวเลขนี้คือความผันผวน 24% ต่อปีแปลงเป็นรายวันพอดี

ภาพรวมก่อนลงสูตร

สูตร Black–Scholes ให้ราคา call วันนี้เป็นตัวเลขเดียว แต่โต๊ะ option อยากรู้มากกว่านั้น คำถามที่ถามกันทั้งวันคือ “ถ้าสิ่งหนึ่งขยับนิดเดียว ราคาเปลี่ยนเท่าไร” เช่น หุ้นขึ้น \$1 ความผันผวนขึ้น 1 จุด หรือเวลาผ่านไปหนึ่งวัน

คำถามแบบนี้คืออนุพันธ์ย่อย (partial derivative) ของสูตรราคา เทียบตัวแปรทีละตัว แต่ละตัวมีชื่อเรียกบนโต๊ะ และเรียกรวมกันว่า Greeks เพราะส่วนใหญ่ใช้อักษรกรีกเป็นสัญลักษณ์

  • delta $\Delta=\partial C/\partial S$ หุ้นขึ้น \$1 ราคา call ขึ้นกี่ดอลลาร์
  • gamma $\Gamma=\partial^2C/\partial S^2$ หุ้นขึ้น \$1 แล้ว delta เปลี่ยนเท่าไร
  • vega $\nu=\partial C/\partial\sigma$ ความผันผวนขึ้น ราคา call เปลี่ยนเท่าไร
  • theta $\Theta=\partial C/\partial t$ เวลาผ่านไป ราคา call เปลี่ยนเท่าไร
  • rho $\rho=\partial C/\partial r$ ดอกเบี้ยขึ้น ราคา call เปลี่ยนเท่าไร

ตอนสร้าง Black–Scholes PDE เราใช้มาแล้วสามตัวในชื่ออื่น คือ $C_S$ (delta) $C_{SS}$ (gamma) และ $C_t$ (theta) หน้านี้หาสูตรของทั้งห้าตัว

หน้านี้เดินตามลำดับนี้ เริ่มจากวิธีที่ง่ายที่สุด คือขยับตัวแปรแล้วคำนวณราคาใหม่ ต่อด้วยเอกลักษณ์หนึ่งบรรทัดที่ทำให้หาอนุพันธ์ง่ายขึ้นมาก แล้ว derive สูตรทั้งห้า จากนั้นแทนตัวเลขของ call ในโจทย์ แปลงเป็นเงินของ 100 สัญญา หาว่าหุ้นต้องแกว่งเท่าไรผู้ขายจึงขาดทุน และสุดท้ายดูว่าการประมาณด้วย Greeks ใช้ไม่ได้เมื่อไร

รูปด้านล่างแสดง Greeks สี่ตัวเป็นการขยับของเส้นราคา call delta คือความชันของเส้น gamma คือความโค้งที่ทำให้เส้นราคาแยกออกจากเส้นสัมผัส vega คือการที่ทั้งเส้นยกขึ้นเมื่อความผันผวนสูงขึ้น theta คือการที่ทั้งเส้นทรุดลงหา payoff เมื่อเวลาผ่านไป (payoff คือเงินที่ call จ่ายในวันหมดอายุ เท่ากับ $\max(S-K,\,0)$)

ขั้นที่ 1 — ลองด้วยมือ: ขยับหุ้นทีละ \$1 แล้วคำนวณใหม่

ก่อนจะหาอนุพันธ์ ลองตอบคำถามของ Greek ด้วยวิธีที่ไม่ต้องใช้แคลคูลัสเลย คือขยับราคาหุ้นจริง ๆ แล้วคำนวณราคา call ใหม่ วิธีนี้เรียกว่า bump-and-revalue ขั้นนี้ใช้ call อีกตัวหนึ่ง ซึ่งรูปหลายรูปในหน้านี้ใช้ด้วย

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ):

  • ราคาหุ้น $S=\$100$ และ strike $K=\$105$
  • อายุ $\tau=0.25$ ปี ดอกเบี้ย $r=4\%$ ต่อปี ความผันผวน $\sigma=20\%$ ต่อปี
  • ราคา call จากสูตร Black–Scholes $C(100)=\$2.390877$

คำถามมีสองข้อ หุ้นขยับ \$1 ราคา call เปลี่ยนเท่าไร (ความชัน) และความชันนั้นเองเปลี่ยนเท่าไร (ความโค้ง) วิธีคือใช้สูตร Black–Scholes คำนวณราคาที่หุ้น \$99, \$100 และ \$101 แล้วหาผลต่าง ความชันใช้ผลต่างแบบสมมาตรรอบ \$100 คือจาก \$99 ถึง \$101 ซึ่งห่างกัน \$2

\[ \begin{aligned} C(99)&=2.041834,\\ C(100)&=2.390877,\\ C(101)&=2.777570,\\ \text{slope}&\approx\frac{C(101)-C(99)}{101-99}\\ &=\frac{0.735736}{2}=0.367868,\\ \text{curvature}&\approx C(101)-2C(100)+C(99)\\ &=0.037650. \end{aligned} \]

ทำไมความโค้งเขียนแบบนี้ ความโค้งคือความชันเปลี่ยนเท่าไรเมื่อหุ้นขยับ \$1 ความชันช่วง \$100 ถึง \$101 คือ $C(101)-C(100)=0.386693$ ความชันช่วง \$99 ถึง \$100 คือ $C(100)-C(99)=0.349043$ ความชันเปลี่ยนไป $0.386693-0.349043=0.037650$ ซึ่งก็คือ $C(101)-2C(100)+C(99)$ เมื่อจัดพจน์ใหม่

คำตอบ: หุ้นขยับ \$1 ราคา call ขยับราว \$0.3679 และความชันเปลี่ยนราว 0.0377 ต่อ \$1 สองตัวนี้คือ delta กับ gamma แบบที่ขยับทีละ \$1 สูตรที่หน้านี้จะ derive ด้านล่างให้ 0.367719 และ 0.037681 ต่างกันที่ทศนิยมตำแหน่งที่สี่ เพราะ \$1 ยังไม่เล็กพอ ถ้าขยับน้อยลง ผลต่างจะเข้าใกล้อนุพันธ์จริง

ตรวจเองใน 10 วินาที: วิธีนี้ใช้ได้กับสัญญาทุกแบบ แม้สัญญาที่ไม่มีสูตรสำเร็จ แต่มีต้นทุน คือต้องคำนวณราคาสามครั้งต่อ Greek หนึ่งคู่ ถ้าพอร์ตมี 5,000 สัญญา ก็ต้องคำนวณ $3\times5{,}000=15{,}000$ ครั้งต่อการตอบคำถามหนึ่งข้อ ซึ่งช้าสำหรับสัญญาที่ราคาคำนวณยาก นี่คือเหตุผลที่สูตรของ Greeks มีค่า

ขั้นที่ 2 — เอกลักษณ์หนึ่งบรรทัดที่ทำให้อนุพันธ์ยุบ

ทวนสูตรราคา call จากสูตร Black–Scholes ก่อน $\Phi$ คือ CDF ของ standard Normal (พื้นที่ใต้ระฆังทางซ้ายของจุดหนึ่ง) และ $\phi$ คือ density ของมัน (ความสูงของระฆัง) $\phi(x)=e^{-x^2/2}/\sqrt{2\pi}$

\[ \begin{aligned} C&=S\Phi(d_1)-Ke^{-r\tau}\Phi(d_2),\\ d_2&=\frac{\ln(S/K)+(r-\tfrac12\sigma^2)\tau}{\sigma\sqrt\tau},\\ d_1&=d_2+\sigma\sqrt\tau. \end{aligned} \]

ทำไมต้องมีขั้นนี้ เพราะ $d_1$ และ $d_2$ มีทุกตัวแปรอยู่ข้างใน ($S$, $\sigma$, $\tau$, $r$) หาอนุพันธ์ของ $C$ เทียบตัวไหนก็ตาม กฎลูกโซ่จะดึงพจน์ $S\phi(d_1)$ และ $Ke^{-r\tau}\phi(d_2)$ ออกมาทุกครั้ง ขั้นนี้พิสูจน์ว่าสองก้อนนี้เท่ากันเสมอ พจน์ยุ่ง ๆ จึงหักกันในทุกอนุพันธ์ วิธีคือหาร density สองตัวด้วยกัน ค่าคงที่ $1/\sqrt{2\pi}$ ตัดกันไป เหลือแค่ผลต่างของกำลังสองในเลขชี้กำลัง

\[ \begin{aligned} \frac{\phi(d_1)}{\phi(d_2)}&=e^{-(d_1^2-d_2^2)/2},\\ d_1^2-d_2^2&=(d_1-d_2)(d_1+d_2)\\ &=\sigma\sqrt\tau\,\big(2d_2+\sigma\sqrt\tau\big)\\ &=2\big[\ln(S/K)+(r-\tfrac12\sigma^2)\tau\big]+\sigma^2\tau\\ &=2\ln(S/K)+2r\tau,\\ \frac{\phi(d_1)}{\phi(d_2)}&=e^{-\ln(S/K)-r\tau}=\frac{K}{S}e^{-r\tau},\\ S\phi(d_1)&=Ke^{-r\tau}\phi(d_2). \end{aligned} \]

ผลคือสองก้อนที่คูณ density อยู่มีค่าเท่ากันเสมอ ไม่ว่าหุ้น ดอกเบี้ย หรือเวลาจะเป็นเท่าไร จังหวะที่ต้องดูคือตอนกระจาย $\sigma\sqrt\tau\,(2d_2+\sigma\sqrt\tau)$ พจน์ $2d_2\sigma\sqrt\tau$ คือสองเท่าของตัวเศษของ $d_2$ พอดี เพราะ $d_2$ คือตัวเศษหารด้วย $\sigma\sqrt\tau$ แทนตัวเศษลงไปแล้ว $-\sigma^2\tau$ ในวงเล็บหักกับ $+\sigma^2\tau$ ที่เหลือ เหลือแค่ $2\ln(S/K)+2r\tau$ ซึ่งยกกำลัง $e$ แล้วกลายเป็นอัตราส่วน $K/S$ คูณตัวคิดลด $e^{-r\tau}$

ตรวจด้วยตัวเลขของ call \$105 ในขั้นก่อน ที่นั่น $d_1=-0.337902$, $d_2=-0.437902$ และ $Ke^{-r\tau}=105e^{-0.04\times0.25}=103.955233$ สองข้างได้ $100\times\phi(-0.337902)=100\times0.376805=37.6805$ และ $103.955233\times\phi(-0.437902)=103.955233\times0.362469=37.6805$ เท่ากันจริง

อีกข้อที่จะใช้ในทุกอนุพันธ์คือ $d_1-d_2=\sigma\sqrt\tau$ ซึ่งไม่มี $S$ และไม่มี $r$ อยู่เลย อนุพันธ์ของ $d_1$ กับ $d_2$ เทียบ $S$ หรือ $r$ จึงเท่ากันเสมอ ส่วนเทียบ $\sigma$ ต่างกัน $\partial(\sigma\sqrt\tau)/\partial\sigma=\sqrt\tau$ และเทียบ $\tau$ ต่างกัน $\partial(\sigma\sqrt\tau)/\partial\tau=\sigma/(2\sqrt\tau)$

ขั้นที่ 3 — delta: ความชันเหลือแค่ Φ(d₁)

delta ตอบคำถามแรกของหัวหน้า ว่าต้องถือหุ้นกี่หุ้น สูตรราคา $C=S\Phi(d_1)-Ke^{-r\tau}\Phi(d_2)$ อ่านได้เหมือนพอร์ตที่ถือหุ้น $\Phi(d_1)$ หุ้น และกู้เงิน $Ke^{-r\tau}\Phi(d_2)$ ดอลลาร์ ตอนสร้างBlack–Scholes PDE เราเห็นว่าพอร์ตที่เลียนแบบ call ได้ต้องถือหุ้นเท่ากับความชัน $C_S$ ขั้นนี้ตรวจว่าสองตัวนี้ตรงกันจริงหรือไม่ เนื่องจาก $d_1$ และ $d_2$ ก็ขึ้นกับ $S$ จึงต้องใช้กฎลูกโซ่กับทั้งสองพจน์

\[ \begin{aligned} \frac{\partial d_1}{\partial S}&=\frac{\partial d_2}{\partial S}=\frac{1}{S\sigma\sqrt\tau},\\ \Delta=\frac{\partial C}{\partial S}&=\Phi(d_1)+S\phi(d_1)\frac{\partial d_1}{\partial S}\\ &\quad-Ke^{-r\tau}\phi(d_2)\frac{\partial d_2}{\partial S}\\ &=\Phi(d_1)+\frac{S\phi(d_1)-Ke^{-r\tau}\phi(d_2)}{S\sigma\sqrt\tau}\\ &=\Phi(d_1),\\ \Delta_{\rm put}&=\Phi(d_1)-1. \end{aligned} \]

ผลคือ delta ของ call เหลือแค่ $\Phi(d_1)$ ตัวเดียว อนุพันธ์ของ $d_1$ เทียบ $S$ หาง่าย เพราะในตัวเศษ $S$ อยู่ใน $\ln S$ ที่เดียว อนุพันธ์ของ $\ln S$ คือ $1/S$ แล้วหารด้วยตัวส่วน $\sigma\sqrt\tau$ ส่วน $d_2$ ต่างจาก $d_1$ แค่ $\sigma\sqrt\tau$ ซึ่งไม่มี $S$ อนุพันธ์จึงเท่ากัน จังหวะสำคัญคือตัวเศษ $S\phi(d_1)-Ke^{-r\tau}\phi(d_2)$ ซึ่งเป็นศูนย์ตามเอกลักษณ์ของขั้นก่อน พจน์ที่มาจากกฎลูกโซ่จึงหายไปหมด

delta ของ put มาจาก put–call parity $P=C-S+Ke^{-r\tau}$ (put คือสิทธิ์ขายหุ้นในราคา strike) หาอนุพันธ์ทั้งสองข้างเทียบ $S$ พจน์ $-S$ ให้ $-1$ และ $Ke^{-r\tau}$ ไม่มี $S$ จึงให้ 0

ผลนี้ไม่ใช่เรื่องบังเอิญ สูตรราคาสร้างมาจากพอร์ตเลียนแบบ ถ้าความชันไม่เท่ากับจำนวนหุ้นที่พอร์ตถือ พอร์ตก็เลียนแบบ call ไม่ได้ตั้งแต่แรก และเพราะ $\Phi$ อยู่ระหว่าง 0 ถึง 1 delta ของ call จึงอยู่ระหว่าง 0 ถึง 1 ส่วนของ put อยู่ระหว่าง −1 ถึง 0 ถ้าหุ้นจ่ายเงินปันผลอัตรา $q$ ต่อปี ทั้งสองตัวจะคูณ $e^{-q\tau}$ เพิ่ม คือ call ได้ $e^{-q\tau}\Phi(d_1)$ และ put ได้ $e^{-q\tau}(\Phi(d_1)-1)$

ขั้นที่ 4 — gamma และ vega: มาจาก φ(d₁) ก้อนเดียวกัน

delta บอกว่าต้องถือหุ้นกี่หุ้น แต่ delta เองเปลี่ยนเมื่อหุ้นขยับ ผู้ขายจึงต้องคอยซื้อขายหุ้นเพื่อปรับ hedge gamma บอกว่าต้องปรับมากแค่ไหน มันคืออนุพันธ์ของ delta เทียบ $S$ อีกครั้ง ส่วน vega ตอบคำถามที่สองของหัวหน้า คือราคาเปลี่ยนเท่าไรเมื่อความผันผวนเปลี่ยน มันคืออนุพันธ์ของราคาเทียบ $\sigma$ ซึ่ง $\sigma$ อยู่ใน $d_1$ และ $d_2$ ทั้งคู่ จึงได้สองพจน์ แต่เอกลักษณ์ของ $\phi$ ยุบให้เหลือพจน์เดียว

\[ \begin{aligned} \Gamma&=\frac{\partial\Phi(d_1)}{\partial S}=\phi(d_1)\frac{\partial d_1}{\partial S}\\ &=\frac{\phi(d_1)}{S\sigma\sqrt\tau},\\ \nu=\frac{\partial C}{\partial\sigma}&=S\phi(d_1)\frac{\partial d_1}{\partial\sigma}\\ &\quad-Ke^{-r\tau}\phi(d_2)\frac{\partial d_2}{\partial\sigma}\\ &=S\phi(d_1)\Big(\frac{\partial d_1}{\partial\sigma}-\frac{\partial d_2}{\partial\sigma}\Big)\\ &=S\phi(d_1)\sqrt\tau,\\ \nu&=\Gamma\,S^2\sigma\tau. \end{aligned} \]

gamma ได้มาง่าย เพราะ delta คือ $\Phi(d_1)$ อนุพันธ์ของ $\Phi$ คือ $\phi$ แล้วคูณ $\partial d_1/\partial S=1/(S\sigma\sqrt\tau)$ ตามกฎลูกโซ่ ส่วน vega จังหวะสำคัญคือแทน $Ke^{-r\tau}\phi(d_2)$ ด้วย $S\phi(d_1)$ ตามเอกลักษณ์ สองพจน์จึงรวมเป็นพจน์เดียว สิ่งที่อยู่ในวงเล็บคืออนุพันธ์ของ $d_1-d_2=\sigma\sqrt\tau$ เทียบ $\sigma$ ซึ่งเท่ากับ $\sqrt\tau$ สมการสุดท้ายได้จากการหาร $\nu$ ด้วย $\Gamma$ คือ $S\phi(d_1)\sqrt\tau\big/\big(\phi(d_1)/(S\sigma\sqrt\tau)\big)=S^2\sigma\tau$

gamma เป็นบวกเสมอ เพราะเส้นราคา option โค้งหงาย ตาม payoff ที่หักมุมขึ้นที่ strike put มี gamma และ vega เท่ากับ call ทุกตัว เพราะ parity บอกว่า put ต่างจาก call แค่หุ้นหนึ่งหุ้นกับเงินสด ซึ่งไม่มีความโค้งและไม่ขึ้นกับความผันผวน

สมการ $\nu=\Gamma S^2\sigma\tau$ บอกว่า option ที่โค้งมากก็ไวต่อความผันผวนมากด้วย เพราะทั้งคู่มาจากความสูงของระฆัง $\phi(d_1)$ ก้อนเดียวกัน ทั้งคู่จึงสูงสุดเมื่อหุ้นอยู่ใกล้ strike ตรงนั้น $d_1$ ใกล้ 0 และ $\phi(d_1)$ ใกล้ยอดระฆัง $\phi(0)=1/\sqrt{2\pi}=1/2.5066=0.3989$

มีเรื่องแปลกที่ควรถาม แบบจำลองสมมติว่า $\sigma$ คงที่ แล้วเราหาอนุพันธ์เทียบ $\sigma$ ได้อย่างไร ทางคณิตศาสตร์มันขัดกันจริง vega ไม่ได้มาจากในแบบจำลอง มันเป็นคำถามจากข้างนอก ว่า “ถ้าเราใส่ $\sigma$ ผิด หรือตลาดเปลี่ยนค่าที่ใช้ตั้งราคา ราคาจะเปลี่ยนเท่าไร” สำหรับโต๊ะ option นี่คือความเสี่ยงที่ใหญ่ที่สุดตัวหนึ่ง แบบจำลองที่ให้ความผันผวนสุ่มได้จริงคือ Heston

ขั้นที่ 5 — theta และ rho

theta ตอบคำถามที่สามของหัวหน้า คือวันนี้ผ่านไปเฉย ๆ ราคาเปลี่ยนเท่าไร theta วัดตามเวลาปฏิทิน $t$ แต่สูตรเขียนด้วยเวลาที่เหลือ $\tau=T-t$ เมื่อ $t$ เดินไปหนึ่งวัน $\tau$ ก็ลดลงหนึ่งวัน สองตัวนี้เดินสวนกัน จึงได้ $\Theta=\partial C/\partial t=-\partial C/\partial\tau$ เวลาเข้าไปในราคาสองทาง ทางแรกผ่าน $\sigma\sqrt\tau$ ซึ่งบอกว่าหุ้นมีเวลาแกว่งได้กว้างแค่ไหน ทางที่สองผ่านตัวคิดลด $Ke^{-r\tau}$ คือมูลค่าวันนี้ของ strike ที่ผู้ซื้อจะจ่ายในอนาคต

rho คืออนุพันธ์เทียบดอกเบี้ย $r$ ซึ่งอยู่ในตัวคิดลดและอยู่ใน $d_1$, $d_2$ แต่พจน์ที่มาจาก $d$ หักกันหมด เพราะ $d_1-d_2=\sigma\sqrt\tau$ ไม่มี $r$

\[ \begin{aligned} \frac{\partial C}{\partial\tau}&=S\phi(d_1)\frac{\partial d_1}{\partial\tau}\\ &\quad+rKe^{-r\tau}\Phi(d_2)\\ &\quad-Ke^{-r\tau}\phi(d_2)\frac{\partial d_2}{\partial\tau}\\ &=S\phi(d_1)\frac{\sigma}{2\sqrt\tau}+rKe^{-r\tau}\Phi(d_2),\\ \Theta&=-\frac{S\phi(d_1)\sigma}{2\sqrt\tau}-rKe^{-r\tau}\Phi(d_2),\\ \rho=\frac{\partial C}{\partial r}&=\tau Ke^{-r\tau}\Phi(d_2)\\ &\quad+S\phi(d_1)\Big(\frac{\partial d_1}{\partial r}-\frac{\partial d_2}{\partial r}\Big)\\ &=\tau Ke^{-r\tau}\Phi(d_2). \end{aligned} \]

theta มีสองก้อน และสำหรับ call ทั้งสองก้อนติดลบ คือราคาลดลงเมื่อเวลาผ่านไป จังหวะสำคัญเหมือนเดิม คือใช้เอกลักษณ์ $S\phi(d_1)=Ke^{-r\tau}\phi(d_2)$ รวมสองพจน์ที่มี $\phi$ เป็นพจน์เดียว แล้วใช้ $\partial(\sigma\sqrt\tau)/\partial\tau=\sigma/(2\sqrt\tau)$

ก้อนแรก $-S\phi(d_1)\sigma/(2\sqrt\tau)$ คือค่าของความผันผวนที่ละลายไป เวลาที่เหลือน้อยลง หุ้นก็มีโอกาสแกว่งไปไกลน้อยลง สิทธิ์จึงมีค่าน้อยลง ก้อนนี้มี $1/\sqrt\tau$ ถ้าหุ้นอยู่ใกล้ strike มันจึงละลายเร็วขึ้นเรื่อย ๆ เมื่อใกล้หมดอายุ ก้อนที่สอง $-rKe^{-r\tau}\Phi(d_2)$ มาจากดอกเบี้ย ผู้ถือ call ยังไม่ต้องจ่าย strike จนวันหมดอายุ ระหว่างนั้นเงินก้อนนั้นได้ดอกเบี้ย วันที่เหลือลดลงหนึ่งวัน ข้อได้เปรียบนี้ก็ลดลงหนึ่งวัน

rho เป็นบวก เพราะดอกเบี้ยสูงขึ้นทำให้มูลค่าวันนี้ของ strike ที่ต้องจ่ายในอนาคตถูกลง และ rho มี $\tau$ คูณอยู่ตรง ๆ option อายุสั้นจึงแทบไม่ไวต่อดอกเบี้ย ตัวอย่าง call \$105 มี rho ดิบ 8.595247 (คำนวณจากสูตรนี้) ต่อ 1 bp จึงเป็น $8.595247\times0.0001=\$0.00086$ ต่อหุ้น หรือ $0.00086\times10{,}000=\$8.60$ ต่อ 10,000 หุ้น

ขั้นที่ 6 — แทนตัวเลขของ call \$36 บนหุ้น \$35

ตอนนี้มีสูตรครบทั้งห้าตัวแล้ว กลับมาที่ call ที่คุณขายในโจทย์ แล้วแทนตัวเลขจริง

โจทย์ให้อะไรมาบ้าง:

  • หุ้น $S=35$ ดอลลาร์ strike $K=36$ ดอลลาร์ อายุ $\tau=0.25$ ปี
  • ดอกเบี้ย $r=0.02$ ต่อปี ความผันผวน $\sigma=0.24$ ต่อปี

เริ่มจากตัวช่วยในสูตร Black–Scholes ก่อน คือ $\sigma\sqrt\tau$, $d_2$, $d_1$ และ strike ที่คิดลดแล้ว

\[ \begin{aligned} \sigma\sqrt\tau&=0.24\times\sqrt{0.25}=0.12,\\ d_2&=\frac{\ln(35/36)+(0.02-\tfrac12\cdot0.24^2)(0.25)}{0.12}\\ &=\frac{-0.028171-0.0022}{0.12}=-0.2530906,\\ d_1&=d_2+0.12=-0.1330906,\\ Ke^{-r\tau}&=36e^{-0.005}=35.820449. \end{aligned} \]

ค่า $\Phi(d_1)=0.4470608$ และ $\Phi(d_2)=0.4000991$ อ่านจาก CDF ของ Normal (ฟังก์ชันใน spreadsheet หรือในโค้ดท้ายหน้า) ราคา call คือ $C=35(0.4470608)-35.820449(0.4000991)=\$1.3154$ ตรงกับโจทย์ Greek สามในห้าตัวใช้ความสูงของระฆังที่ $d_1$ จึงหา $\phi(d_1)$ ก่อน แล้วแทนลงในสูตรทีละตัว ($0.398942=1/\sqrt{2\pi}$ คือยอดระฆัง)

\[ \begin{aligned} \phi(d_1)&=0.398942\,e^{-0.1330906^2/2}\\ &=0.398942(0.991183)=0.395425,\\ \Delta&=\Phi(d_1)=0.447061,\\ \Gamma&=\frac{0.395425}{35(0.24)(0.5)}=\frac{0.395425}{4.2}\\ &=0.094149,\\ \nu&=35(0.395425)(0.5)=6.919931,\\ \Theta&=-\frac{35(0.395425)(0.24)}{2(0.5)}\\ &\quad-0.02(35.820449)(0.4000991)\\ &=-3.321567-0.286635=-3.608201,\\ \rho&=36(0.25)e^{-0.005}(0.4000991)\\ &=8.955112(0.4000991)=3.582932. \end{aligned} \]

ขั้นที่ 7 — แปลงเป็นเงินของตำแหน่งขาย 100 สัญญา

ตัวเลขของขั้นก่อนเป็นของ call ใบเดียว ต่อหุ้น และอยู่ในหน่วยดิบ หัวหน้าอยากรู้เป็นเงินของทั้งตำแหน่ง จึงต้องทำสองอย่าง คือคูณด้วยจำนวนหุ้นพร้อมเครื่องหมาย และแปลงเป็นขนาดการขยับที่โต๊ะใช้จริง

โจทย์ให้อะไรมาบ้าง:

  • Greek ต่อหุ้นจากขั้นก่อน
  • คุณขาย 100 สัญญา สัญญาละ 100 หุ้น การขายมีเครื่องหมายลบ จึงได้ $N=-100\times100=-10{,}000$
  • ขนาดการขยับที่โต๊ะใช้ ความผันผวน 1 จุด (คูณ $\nu$ ด้วย $0.01$) หนึ่งวันปฏิทิน (หาร $\Theta$ ด้วย 365) และดอกเบี้ย 1% (คูณ $\rho$ ด้วย $0.01$)

  • vega −\$692 ต่อจุด ความผันผวนขึ้น 1 จุด คุณเสีย \$692 นี่คือคำตอบข้อสอง
  • theta +\$98.85 ต่อวัน วันที่ทุกอย่างนิ่ง คุณได้ \$98.85 นี่คือคำตอบข้อสาม
  • rho −\$358 ต่อ 1% ดอกเบี้ยขึ้น 1% คุณเสีย \$358

ขั้นที่ 8 — ตรวจทุกตัวพร้อมกันด้วย PDE

ก่อนเอาตัวเลขไปใช้ ควรมีวิธีตรวจว่าไม่ได้คำนวณผิด ตอนสร้างBlack–Scholes PDE เราได้สมการที่ราคา option ทุกตัวต้องทำให้เป็นจริง คือ $C_t+rSC_S+\tfrac12\sigma^2S^2C_{SS}=rC$ เขียนด้วยชื่อ Greeks ได้ว่า $\Theta+rS\Delta+\tfrac12\sigma^2S^2\Gamma=rC$ ถ้าแทน Greeks ที่คำนวณมาแล้วสองข้างไม่เท่ากัน แปลว่ามีตัวใดตัวหนึ่งผิด การตรวจนี้จับได้ทั้งเครื่องหมายผิดและหน่วยผิดในคราวเดียว

แทนตัวเลขของ call \$36 ทีละพจน์ ($\Theta$ มาจากขั้นแทนตัวเลข และพจน์ความโค้งเขียนด้วยสูตรของ $\Gamma$)

\[ \begin{aligned} rS\Delta&=0.02(35)(0.447061)=0.312943,\\ \tfrac12\sigma^2S^2\Gamma&=\tfrac12\sigma^2S^2\cdot\frac{\phi(d_1)}{S\sigma\sqrt\tau}\\ &=\frac{S\phi(d_1)\sigma}{2\sqrt\tau}=3.321567,\\ \Theta+rS\Delta+\tfrac12\sigma^2S^2\Gamma&=-3.608201+0.312943\\ &\quad+3.321567=0.026308,\\ rC&=0.02(1.315401)=0.026308. \end{aligned} \]

สองข้างเท่ากันทุกหลักที่แสดง Greeks ทั้งชุดจึงผ่านการตรวจ แต่ที่น่าสนใจกว่าคือ PDE แยกเป็นสองคู่ที่หักกันพอดี คู่แรกคือพจน์ความโค้ง เมื่อแทนสูตรของ $\Gamma$ มันกลายเป็น $S\phi(d_1)\sigma/(2\sqrt\tau)$ ซึ่งคือก้อนแรกของ theta พอดีแต่คนละเครื่องหมาย (3.321567 ทั้งคู่)

คู่ที่สองคือพจน์ที่เหลือ $rS\Delta-rKe^{-r\tau}\Phi(d_2)=r\big(S\Phi(d_1)-Ke^{-r\tau}\Phi(d_2)\big)=rC$ ตามสูตรราคา ตัวเลขคือ $0.312943-0.286635=0.026308$

คู่แรกคือที่มาของประโยคที่โต๊ะพูดกันว่า “theta คือค่าเช่าของ gamma” คนที่ถือ option ได้ประโยชน์จากความโค้ง (gamma) และจ่ายค่าเช่าเป็นมูลค่าที่ละลายไปทุกวัน (theta) สองอย่างมีขนาดเท่ากันเสมอ ขั้นต่อไปจะเห็นว่าใครได้ใครเสียในแต่ละวัน

ขั้นที่ 9 — หุ้นต้องแกว่งเท่าไร gamma จึงคุ้มค่าเวลา

ขั้นนี้ตอบคำถามสุดท้ายของหัวหน้า เมื่อ hedge แล้ว หุ้นต้องแกว่งวันละเท่าไรคุณจึงขาดทุน เริ่มจากเขียนว่าผู้ขาย call ที่ hedge แล้วถืออะไรบ้าง (คิดต่อหุ้นหนึ่งหุ้นของ call)

  • ขาย call หนึ่งใบ มูลค่า $-C$
  • ถือหุ้น $\Delta$ หุ้น มูลค่า $\Delta S$
  • เงินสด $B=C-\Delta S$ คือ premium ที่รับมา ลบเงินที่จ่ายซื้อหุ้น ตัวเลขนี้ติดลบ แปลว่าต้องกู้เงินมาส่วนหนึ่ง เงินสดได้ดอกเบี้ย (หรือเสียดอกเบี้ยถ้าติดลบ) $rB\,\delta t$

ให้เวลาผ่านไปหนึ่งวัน $\delta t=1/365$ ปี และหุ้นขยับ $x$ ดอลลาร์ ราคา call เปลี่ยนตามการกระจาย Taylor ถึงอันดับสองในราคาหุ้น คือ $\Theta\,\delta t+\Delta x+\tfrac12\Gamma x^2$ ผู้ขายเสียส่วนนี้ ขาหุ้นได้ $\Delta x$ แล้วใช้ PDE ของขั้นก่อนแทน $-\Theta+r(C-S\Delta)$ ด้วย $\tfrac12\sigma^2S^2\Gamma$

\[ \begin{aligned} \text{P\&L}&=-\big(\Theta\,\delta t+\Delta x+\tfrac12\Gamma x^2\big)\\ &\quad+\Delta x+r(C-S\Delta)\,\delta t\\ &=\tfrac12\sigma^2S^2\Gamma\,\delta t-\tfrac12\Gamma x^2\\ &=\tfrac12\Gamma\big(\sigma^2S^2\delta t-x^2\big),\\ x^*&=\sigma S\sqrt{\delta t}=\frac{0.24(35)}{\sqrt{365}}\\ &=\frac{8.4}{19.105}=0.4397,\\ \sigma^2S^2\delta t&=\frac{0.0576(1{,}225)}{365}=0.193315,\\ 10{,}000\cdot\tfrac12\Gamma\,\sigma^2S^2\delta t&=10{,}000(0.047074)(0.193315)\\ &=91.00. \end{aligned} \]

ผลนี้คือหัวใจของการเทรด option สองอย่างหายไปจากสมการ ขาหุ้นหักส่วน $\Delta x$ ทิ้ง และดอกเบี้ยของเงินกู้หักก้อนดอกเบี้ยของ theta ทิ้ง ที่เหลือคือการแข่งกันระหว่างสองตัว ตัวแรก $\sigma^2S^2\delta t$ คือขนาดการขยับยกกำลังสองที่ราคา option คิดไว้แล้ว ตัวที่สอง $x^2$ คือการขยับจริงยกกำลังสอง ไม่มีทิศทางของหุ้นอยู่เลย หุ้นขึ้นหรือลง \$1 ให้ผลเท่ากัน

ผู้ขายได้กำไรเมื่อ $x^2\lt\sigma^2S^2\delta t$ และขาดทุนเมื่อ $x^2\gt\sigma^2S^2\delta t$ จุดเท่าทุน $x^*$ คือจุดที่สองตัวเท่ากัน ได้ \$0.4397 ต่อวัน คิดเป็น $0.4397/35=1.256\%$ ของราคาหุ้น ซึ่งเท่ากับ $0.24/\sqrt{365}=0.24/19.105=1.256\%$ คือความผันผวนต่อปีแปลงเป็นรายวัน ที่หารด้วย $\sqrt{365}$ ไม่ใช่ 365 ก็เพราะ variance ของการขยับแต่ละวันบวกกันเป็น variance ของทั้งปี ความผันผวนซึ่งเป็นรากที่สองของ variance จึงโตตามรากของเวลา

วันที่หุ้นนิ่ง ($x=0$) ผู้ขายได้ \$91.00 ไม่ใช่ \$98.85 จาก theta ส่วนต่าง $98.85-91.00=\$7.85$ คือดอกเบี้ยของเงินที่กู้มาซื้อหุ้น เงินกู้คือ $156{,}471-13{,}154=\$143{,}317$ ดอกเบี้ยต่อวันคือ $143{,}317\times0.02/365=\$7.85$

ขั้นที่ 10 — ประมาณกำไรขาดทุนด้วย Greeks แล้วดูว่าใช้ได้ไกลแค่ไหน

พอร์ตจริงมีสัญญาเป็นพัน ๆ ระบบความเสี่ยงจึงไม่คำนวณราคาใหม่ทุกสัญญาทุกครั้งที่ตลาดขยับ มันใช้ Greeks ประมาณแทน ด้วยการกระจาย Taylor รอบจุดปัจจุบัน ราคาหุ้นขยับแรงที่สุด จึงเก็บถึงอันดับสอง ส่วนความผันผวน เวลา และดอกเบี้ยเก็บแค่อันดับหนึ่ง สมการแรกด้านล่างเป็นนิยามของการประมาณนี้ ไม่ใช่สมการที่จริงเป๊ะ

ถ้าสนใจแค่หุ้นขยับ สองพจน์แรกเรียกว่า delta-gamma approximation ซึ่งใช้กันมากในการคำนวณ VaR (ตัวเลขขาดทุนที่ไม่ควรเกินในวันปกติ เช่น 99 วันจาก 100 วัน) แบบที่ใช้ข้อมูลย้อนหลัง ลองทดสอบกับ call \$105 จากขั้นลองด้วยมือ เมื่อหุ้นขึ้น $h=\$1$

\[ \begin{aligned} \delta C&\approx\Delta h+\tfrac12\Gamma h^2+\nu\,\delta\sigma\\ &\quad+\Theta\,\delta t+\rho\,\delta r,\\ \Delta h&=0.367719(1)=0.367719,\\ \tfrac12\Gamma h^2&=\tfrac12(0.037681)(1)^2=0.018840,\\ \Delta h+\tfrac12\Gamma h^2&=0.367719+0.018840\\ &=0.386559,\\ C(101)-C(100)&=2.777570-2.390877\\ &=0.386693,\\ 0.386693-0.386559&=0.000134. \end{aligned} \]

ที่หุ้นขยับ \$1 การประมาณด้วย delta อย่างเดียวพลาด $0.386693-0.367719=0.018974$ หรือราว 0.0190 ต่อหุ้น พอเพิ่ม gamma เข้าไปพลาดเหลือแค่ 0.000134 ต่อหุ้น ดีขึ้นกว่าร้อยเท่า

สิ่งที่การประมาณทิ้งไปมีสองอย่าง คือพจน์อันดับสามขึ้นไป และพจน์ไขว้ เช่นตอนหุ้นกับความผันผวนขยับพร้อมกัน สองอย่างนี้เล็กเมื่อขยับนิดเดียว แต่โตขึ้นเร็วเมื่อขยับไกล รูปด้านล่างแสดงว่าไกลแค่ไหนจึงเริ่มพลาด

ขั้นที่ 11 — ถามเป็นเปอร์เซ็นต์: dollar delta และ dollar gamma

พอร์ตจริงมีหุ้นหลายตัว ราคาต่างกันมาก หุ้น \$35 ขยับ \$1 กับหุ้น \$500 ขยับ \$1 ไม่ใช่เรื่องขนาดเดียวกัน ระบบความเสี่ยงจึงถามเป็นเปอร์เซ็นต์ เช่น “ถ้าหุ้นทุกตัวขยับ 2% พอร์ตได้เสียเท่าไร” ขั้นนี้แปลง delta และ gamma ให้ตอบคำถามแบบนี้ได้

โจทย์ให้อะไรมาบ้าง:

  • ตำแหน่งขาย 10,000 call ที่ยังไม่ hedge คือ $N=-10{,}000$
  • หุ้น $S=\$35$, $\Delta=0.447061$, $\Gamma=0.094149$ จากขั้นแทนตัวเลข
  • หุ้นขยับ $h/S=\pm2\%$ คือ $h=\pm0.02\times35=\pm\$0.70$

วิธีคือเริ่มจากสองพจน์แรกของการประมาณด้วย Greeks คูณ $N$ แล้วเขียน $h=S\cdot(h/S)$ ตัวที่อยู่ในวงเล็บสองตัวไม่ขึ้นกับขนาดการขยับ จึงคำนวณเก็บไว้ได้ เรียกว่า dollar delta และ dollar gamma

\[ \begin{aligned} \delta V&\approx N\Delta h+\tfrac12N\Gamma h^2\\ &=(NS\Delta)\frac hS+\big(\tfrac12NS^2\Gamma\big)\Big(\frac hS\Big)^2,\\ NS\Delta&=-10{,}000(35)(0.447061)\\ &=-156{,}471,\\ \tfrac12NS^2\Gamma&=-10{,}000(\tfrac12\cdot35^2)(0.094149)\\ &=-10{,}000(612.5)(0.094149)\\ &=-576{,}661,\\ \delta V(+2\%)&=-156{,}471(0.02)-576{,}661(0.02)^2\\ &=-3{,}129.4-230.7=-3{,}360,\\ \delta V(-2\%)&=-156{,}471(-0.02)-576{,}661(-0.02)^2\\ &=+3{,}129.4-230.7=+2{,}899. \end{aligned} \]

คำตอบ: หุ้นขึ้น 2% เสีย \$3,360 หุ้นลง 2% ได้ \$2,899 สองข้างไม่เท่ากัน เพราะพจน์ gamma ติดลบ และ $(h/S)^2$ เป็นบวกทั้งขาขึ้นและขาลง มันจึงหักออก \$230.7 ทั้งสองทาง คำนวณราคาใหม่ทั้งสูตรได้ −\$3,359.73 และ +\$2,899.47 ตรงกันถึงหลักหน่วย

ข้อดีของสองตัวเลขนี้คือหน่วยเป็นดอลลาร์ต่อผลตอบแทนเหมือนกันทุกหุ้น ถ้าถามว่าหุ้นทุกตัวขยับ 2% พร้อมกัน ก็บวก dollar delta ของทุกสัญญาในพอร์ตได้ตรง ๆ dollar gamma ก็เช่นกัน

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

สลับ $\Phi$ กับ $\phi$: ใส่ CDF ในที่ที่ต้องใช้ density ทำให้ gamma สูงเกินจริง 13% ใน spreadsheet ฟังก์ชันเดียวกันให้ได้ทั้งสองตัว เช่น NORM.S.DIST(x, TRUE) ให้ $\Phi$ และ NORM.S.DIST(x, FALSE) ให้ $\phi$ ต่างกันแค่ argument ตัวท้าย ให้ $\tilde\Gamma$ คือค่าที่ได้เมื่อใส่ผิด เทียบกับค่าที่ถูก $\Gamma$

\[ \begin{aligned} \tilde\Gamma&=\frac{\Phi(d_1)}{S\sigma\sqrt\tau}=\frac{0.447061}{4.2}=0.1064,\\ \Gamma&=\frac{\phi(d_1)}{S\sigma\sqrt\tau}=\frac{0.395425}{4.2}=0.0941. \end{aligned} \]

$0.1064/0.0941=1.13$ ตัวเลขผิดยังดูสมเหตุสมผล จึงไม่มีใครสังเกต แต่การตรวจด้วย PDE จับได้ทันที เพราะพจน์ความโค้งกลายเป็น $35.28\times0.106443=3.755$ แทน 3.322 (โดย $\tfrac12\sigma^2S^2=\tfrac12(0.0576)(1{,}225)=35.28$) ผลรวมจึงได้ $-3.608201+0.312943+3.755311=0.460$ ไม่ใช่ $rC=0.026$

\[ \begin{aligned} N\Theta/365&=-10{,}000(-3.608201)/365=\$98.85,\\ N\Theta/252&=-10{,}000(-3.608201)/252=\$143.18. \end{aligned} \]

สัญญาเดียวกันได้ตัวเลขต่างกัน $143.18/98.85=1.45$ เท่า รายงานที่ไม่บอกว่าใช้นาฬิกาไหนจึงอ่านผิดได้ทั้งหน้า

บวก Greek ทีละตัวในวันที่ทุกอย่างขยับพร้อมกัน: ดูความเสี่ยงแยกทีละปัจจัย ทำให้เห็นภาพที่ดีเกินจริง วันที่หุ้นดิ่ง ความผันผวนมักพุ่งตาม ในตาราง scenario ช่องที่ขยับทีละปัจจัยเสียไม่เกิน \$1,424 แต่มุมที่ขยับพร้อมกันเสีย \$2,838 เกือบสองเท่า

ใช้ทำอะไรบนโต๊ะจริง

ทุกเช้าโต๊ะ option ได้รายงานที่รวม position Greek ของทุกสัญญาในพอร์ต ในหน่วยที่หน้านี้ใช้

  • delta เป็นจำนวนหุ้น หรือเป็น dollar delta
  • gamma เป็นหุ้นต่อ \$1
  • vega เป็นดอลลาร์ต่อความผันผวน 1 จุด แยกตามอายุสัญญา เพราะ option แต่ละอายุมีความผันผวนของตัวเอง (ดู volatility surface)
  • theta เป็นดอลลาร์ต่อวัน

ฝ่ายความเสี่ยงตั้งเพดานให้แต่ละตัวแยกกัน คือค่าสูงสุดที่โต๊ะถือได้ เทรดเดอร์ซื้อขายหุ้นเพื่อให้ delta อยู่ใกล้ศูนย์ตลอด แล้วตัดสินใจว่าจะถือ gamma กับ vega เท่าไร ตามมุมมองเรื่องความผันผวน ไม่ใช่เรื่องทิศทางของหุ้น ถ้าอยากได้ gamma โดยไม่มี vega ต้องผสม option หลายอายุเข้าด้วยกัน ดู volatility trading structures

ตาราง scenario ใช้ในวันที่ตลาดขยับแรง และใน stress test คือการทดสอบว่าพอร์ตจะเสียเท่าไรถ้าหลายอย่างขยับแรงพร้อมกัน ส่วนที่ยากไม่ใช่การคำนวณ แต่คือการเลือกว่าปัจจัยไหนจะขยับพร้อมกัน และขยับแรงแค่ไหนจึงจะเกิดขึ้นได้จริง สำหรับพอร์ตที่มีสัญญาซับซ้อนเรื่องนี้ยากมาก

// The five Greeks of a European call, checked by bump-and-revalue, the PDE and full repricing.
const { abs, exp, log, sqrt, PI } = Math;
function checkInputs(S, K, T, r, sigma) {
  if (![S, K, T, r, sigma].every(Number.isFinite)) throw new TypeError('Inputs must be finite numbers');
  if (S <= 0 || K <= 0) throw new RangeError('Spot and strike must be positive');
  if (T <= 0 || T > 30) throw new RangeError('Time to expiry must be in years, above 0 and at most 30');
  if (sigma <= 0 || sigma > 5) throw new RangeError('Volatility must be per year, above 0 and at most 5 (0.24 = 24%)');
}
const phi = x => exp(-0.5 * x * x) / sqrt(2 * PI);
function Phi(x) { // normal CDF: series near the centre, continued fraction in the tails
  const a = abs(x);
  if (a <= 3) { let t = a, s = a; for (let n = 1; n < 200 && t > 1e-17 * s; n++) { t *= a * a / (2 * n + 1); s += t; }
    return x >= 0 ? 0.5 + phi(a) * s : 0.5 - phi(a) * s; }
  let f = a; for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - phi(a) / f : phi(a) / f;
}
function greeks(S, K, T, r, sigma) { // raw units: vega per 1.00 of sigma, theta per year, rho per 1.00 of r
  checkInputs(S, K, T, r, sigma);
  const sT = sigma * sqrt(T), D = exp(-r * T);
  const d1 = (log(S / K) + (r + 0.5 * sigma * sigma) * T) / sT, d2 = d1 - sT;
  const thetaVol = -S * phi(d1) * sigma / (2 * sqrt(T)), thetaRate = -r * K * D * Phi(d2);
  return { d1, d2, pdf: phi(d1), price: S * Phi(d1) - K * D * Phi(d2), delta: Phi(d1), gamma: phi(d1) / (S * sT),
    vega: S * phi(d1) * sqrt(T), thetaVol, thetaRate, theta: thetaVol + thetaRate, rho: K * T * D * Phi(d2) };
}
const price = (S, K, T, r, sigma) => greeks(S, K, T, r, sigma).price;
function bump(S, K, T, r, sigma, h) { // central differences, no formula for the derivatives needed
  const up = price(S + h, K, T, r, sigma), mid = price(S, K, T, r, sigma), down = price(S - h, K, T, r, sigma);
  return { up, mid, down, slope: (up - down) / (2 * h), curvature: (up - 2 * mid + down) / (h * h) };
}
function position(g, contracts, multiplier = 100) { // desk units; contracts negative when sold
  const N = contracts * multiplier;
  return { units: N, shares: N * g.delta, gammaShares: N * g.gamma, vegaPerPoint: N * g.vega * 0.01,
    thetaPerDay: N * g.theta / 365, rhoPerPercent: N * g.rho * 0.01, rhoPerBp: N * g.rho * 1e-4 };
}
const big = greeks(100, 105, 0.25, 0.04, 0.2);
const S = 35, K = 36, T = 0.25, r = 0.02, sigma = 0.24;
const g = greeks(S, K, T, r, sigma), pos = position(g, -100), N = pos.units;
const at = (x, v = sigma, t = T) => price(x, K, t, r, v) - g.price;
const dollarDelta = N * S * g.delta, dollarGamma = N * 0.5 * S * S * g.gamma;

สิ่งที่ควรตอบได้หลังอ่าน

  • Greeks คืออนุพันธ์ของราคา option เทียบหุ้น ความผันผวน เวลา และดอกเบี้ย ตอบว่าถ้าสิ่งหนึ่งขยับนิดเดียว ราคาเปลี่ยนเท่าไร หาได้สองทาง คือขยับแล้วคำนวณใหม่ (ใช้ได้กับทุกสัญญา) หรือใช้สูตร (เร็วกว่ามาก)
  • เอกลักษณ์ $S\phi(d_1)=Ke^{-r\tau}\phi(d_2)$ ทำให้สูตรสั้นลง ได้ $\Delta=\Phi(d_1)$, $\Gamma=\phi(d_1)/(S\sigma\sqrt\tau)$, $\nu=S\phi(d_1)\sqrt\tau$, $\Theta=-S\phi(d_1)\sigma/(2\sqrt\tau)-rKe^{-r\tau}\Phi(d_2)$ และ $\rho=\tau Ke^{-r\tau}\Phi(d_2)$
  • delta ของ put คือ delta ของ call ลบ 1 ส่วน gamma และ vega เท่ากับของ call ใกล้หมดอายุ delta วิ่งไปหา 0 หรือ 1 และ gamma ของ option ที่ strike พุ่งขึ้นตาม $1/\sqrt\tau$
  • ขาย call \$36 บนหุ้น \$35 ไป 100 สัญญา ต้องซื้อหุ้น 4,471 หุ้น gamma −941 หุ้นต่อ \$1 vega −\$692 ต่อความผันผวน 1 จุด theta +\$98.85 ต่อวัน rho −\$358 ต่อดอกเบี้ย 1% และ premium ไม่ได้ละลายเป็นเส้นตรง
  • theta คือค่าเช่าของ gamma ผู้ขายที่ hedge แล้วได้ $\tfrac12\Gamma(\sigma^2S^2\delta t-x^2)$ ต่อหุ้นต่อวัน และเท่าทุนเมื่อหุ้นขยับ $\sigma S\sqrt{\delta t}=\$0.44$ ต่อวัน สิ่งที่ตัดสินกำไรคือหุ้นแกว่งจริงมากกว่าหรือน้อยกว่าที่ราคาคิดไว้ ไม่ใช่ทิศทาง
  • Greeks ใช้ได้ดีกับการขยับเล็ก วันที่ขยับแรงหรือหลายปัจจัยขยับพร้อมกันต้องคำนวณใหม่ทั้งสูตร และทุกตัวเลขต้องบอกหน่วย นาฬิกา (365 หรือ 252 วัน) และเครื่องหมายของตำแหน่ง
