9.2 Standard Brownian Motion (SBM)

เส้นทางสุ่มมาตรฐานแบบเดียวที่ได้จากการโยนเหรียญถี่ขึ้นเรื่อย ๆ เอาไปเลื่อนและยืดแล้วได้แบบจำลองราคาทุกขนาด

ทุกปี ทีมบริหารความเสี่ยงต้องบอก risk committee (คณะกรรมการที่คุมว่าบริษัทยอมเสี่ยงได้แค่ไหน) ว่าพอร์ตแต่ละพอร์ตอาจได้หรือเสียเงินได้ประมาณเท่าไรในหนึ่งปี พอร์ตในเรื่องนี้ถือ SPY อย่างเดียว SPY คือกองทุนที่ซื้อขายเหมือนหุ้นและวิ่งตามดัชนี S&P 500 ของหุ้นใหญ่ 500 ตัวในสหรัฐ

ของที่รู้ (ตัวเลขสมมติ แต่ใกล้ของจริง):

  • มูลค่าพอร์ต \$25 ล้าน
  • ความผันผวนรายวัน $\sigma_d=1.15\%$ คือ SD (standard deviation) ของผลตอบแทนหนึ่งวัน วัดจากข้อมูลย้อนหลัง คิดเป็นเงินได้ $25{,}000{,}000\times0.0115=\$287{,}500$ ต่อวัน
  • หนึ่งปีมีวันที่ตลาดหุ้นสหรัฐเปิด 252 วัน เรียกว่าวันทำการ (ปี 2024 มีวันจันทร์ถึงศุกร์ 262 วัน ลบวันหยุดตลาด 10 วัน)

ตัวเลขที่ต้องรายงานคือ SD ของ P&L (กำไรขาดทุนเป็นดอลลาร์) ในหนึ่งปี พนักงานใหม่คิดว่า ปีหนึ่งมี 252 วัน ความเสี่ยงก็ควรเป็น 252 เท่าของหนึ่งวัน จึงคูณตรง ๆ:

\[287{,}500\times252=\$72{,}450{,}000\]

ได้ \$72.45 ล้าน เกือบสามเท่าของเงินทั้งพอร์ต ตัวเลขนี้ถูกไหม ถ้าไม่ถูก ตัวเลขที่ถูกคือเท่าไร

คำถามที่สองใช้ความผันผวนชุดเดียวกัน ATM straddle คือการซื้อ option สองตัวพร้อมกัน ได้แก่ call (สิทธิ์ซื้อ) กับ put (สิทธิ์ขาย) ที่ราคาใช้สิทธิ์เท่ากับราคาวันนี้ ตอนหมดอายุมันจ่ายเงินเท่ากับระยะที่ราคาขยับไป ไม่ว่าขึ้นหรือลง วันนี้ SPY ราคา \$520 ถ้า straddle หมดอายุใน 30 วัน มันควรมีราคาราวเท่าไร?

ลองตอบก่อนเปิดเฉลย

ตัวเลขของพนักงานใหม่ผิด เพราะสิ่งที่บวกกันข้ามวันได้คือ variance ไม่ใช่ SD ดังนั้น SD โตตาม $\sqrt{252}$ ไม่ใช่ 252 (หน้านี้จะแสดงเหตุผลทีละขั้น) ความผันผวนรายปี $\sigma_{252}$ และ SD ของ P&L รายปีจึงเป็น

\[\begin{aligned}\sigma_{252}&=1.15\%\times\sqrt{252}\\&=1.15\%\times15.8745\approx18.26\%,\\\text{SD}&=25{,}000{,}000\times0.182557\\&\approx\$4{,}563{,}921.\end{aligned}\]

ตัวเลขที่ถูกจึงราว \$4.56 ล้าน ตัวเลขของพนักงานใหม่ใหญ่ไป $72.45/4.564\approx15.87$ เท่า ซึ่งก็คือ $\sqrt{252}$ พอดี

ส่วน straddle 30 วันควรมีราคาราว \$21.71 ต่อหุ้น หรือ $21.71/520\approx4.18\%$ ของราคาหุ้น สัญญาหนึ่งอ้างอิง 100 หุ้น จึงเป็น $100\times21.71\approx\$2{,}171$ ต่อสัญญา ครึ่งหลังของหน้านี้จะคำนวณตัวเลขนี้ทีละขั้น แล้วตรวจกับสูตร Black–Scholes เต็ม ซึ่งให้ \$21.71 เหมือนกัน

ภาพรวมก่อนลงสูตร

หน้าที่แล้ว (กติกาสามข้อของ Brownian motion) อธิบายว่า Brownian motion คือเส้นทางสุ่มที่ทำตามกติกาสามข้อ: การขยับในช่วงที่ไม่ทับกันเป็นอิสระต่อกัน การขยับในช่วงยาว $s$ เป็น Normal และเส้นทางไม่กระโดด มันมีตัวเลขปรับได้สองตัว คือ drift $\mu$ (ทิศทางเฉลี่ยต่อปี) และความผันผวน $\sigma$ (ขนาดการแกว่ง)

หน้านี้เลือกกรณีที่ง่ายที่สุดมาหนึ่งแบบ: เริ่มที่ 0, ไม่มี drift และ variance เท่ากับเวลาพอดี เรียกว่า standard Brownian motion (SBM) เขียนว่า $W_t$ ทำไมต้องมีแบบมาตรฐาน? เพราะแบบจำลองที่เหลือทุกแบบได้จากการเอา $W_t$ มาเลื่อนและยืด: $X_t=x+\mu t+\sigma W_t$ เหมือนวิศวกรที่มีชิ้นส่วนมาตรฐานชิ้นเดียว แล้วปรับขนาดใช้งานได้ทุกที่ ไม่ต้องออกแบบใหม่ทุกครั้ง

SBM ไม่ได้ลอยมาจากไหน มันคือการเดินแบบโยนเหรียญ: ทุกช่วงเวลาสั้น ๆ ยาว $\Delta t$ โยนเหรียญหนึ่งครั้ง ออกหัวก้าวขึ้น ออกก้อยก้าวลง ก้าวละ $\sqrt{\Delta t}$ แล้วซอยเวลาให้ถี่ขึ้นเรื่อย ๆ หน้านี้จะแสดงว่าทำไมก้าวต้องยาว $\sqrt{\Delta t}$ พอดี ในโลกราคา การเดินแบบนี้คือต้นไม้ binomial (แบบจำลองที่ราคาก้าวขึ้นหรือลงทีละขั้น) ที่ซอยเวลาละเอียดขึ้นเรื่อย ๆ รูปข้างล่างคือหน้าตาของเส้นทางที่ได้

จากนั้นเอา SBM ไปทำงานจริงสามอย่าง:

  • แปลงความเสี่ยงรายวันเป็นรายปีให้ risk committee ตามคำถามเปิดหน้า
  • สร้างเส้นทางบนคอมพิวเตอร์ โดยไม่ตกหลุมบั๊กที่พบบ่อยที่สุด
  • ตั้งราคา straddle 30 วันด้วยค่าเฉลี่ยของ $|Z|$ ซึ่งคือขนาดเฉลี่ยของเลขสุ่ม Normal มาตรฐาน $Z$ แล้วตรวจกับสูตร Black–Scholes

ขั้นที่ 1 — นิยาม SBM และค่าเฉลี่ยกับ variance ของมัน

ก่อนจะเอา SBM ไปสร้างอะไรต่อ ต้องตกลงให้แน่นอนก่อนว่ามันคืออะไร นิยามคือกติกาของหน้าที่แล้วที่ตั้ง $\mu=0$ และ $\sigma=1$ แล้วบังคับให้เริ่มที่ 0 สามบรรทัดแรกในกรอบข้างล่างคือนิยามนี้: เริ่มที่ 0, การขยับในช่วงยาว $s$ เป็น $\mathcal N(0,s)$ (Normal ที่มีค่าเฉลี่ย 0 และ variance $s$) และการขยับนั้นอิสระจากค่า $W_u$ ทุกค่าในอดีต ($u\le t$) สองบรรทัดสุดท้ายไม่ใช่นิยาม มันได้จากการใช้นิยามกับช่วงแรกสุด คือจาก 0 ถึง $t$

\[ \begin{aligned} &W_0=0,\\ &W_{t+s}-W_t\sim\mathcal N(0,s),\\ &W_{t+s}-W_t\ \text{independent of}\ W_u,\ u\le t,\\ &W_t=W_t-W_0\sim\mathcal N(0,t),\\ &\mathbb E[W_t]=0,\qquad\operatorname{Var}(W_t)=t. \end{aligned} \]

ข้อความเป็นอิสระพูดถึงเส้นทางทั้งเส้นในอดีต: การขยับหลังเวลา $t$ ไม่สนว่าก่อนหน้านั้นเส้นทางเดินมาแบบไหน ไม่ใช่แค่ไม่สนจุดสุดท้าย ข้อนี้แข็งกว่าที่ฟังดู หน้า filtration ในเวลาต่อเนื่อง จะใช้มันพิสูจน์ว่าการทำนายที่ดีที่สุดของ $W$ ในอนาคตคือค่าปัจจุบัน นอกจากนี้ เส้นทางต้องไม่กระโดด เหมือนกติกาข้อ 3 ของหน้าที่แล้ว

ค่าเฉลี่ยและ variance ของ $W_t$ ได้มาฟรีเพราะ $W_0=0$: ระดับ $W_t$ จึงเท่ากับการขยับจาก 0 ถึง $t$ ซึ่งนิยามบอกแล้วว่าเป็น $\mathcal N(0,t)$ ความหมายคือ ที่เวลา $t$ SBM มักอยู่ห่างศูนย์ราว $\sqrt t$ (หนึ่ง SD) ไม่ใช่ $t$ เช่นที่ 4 ปี ห่างราว $\sqrt4=2$ ไม่ใช่ 4 นี่คือพัดที่บานตามรากของเวลาในรูปหกเส้นทางข้างบน

ขั้นที่ 2 — จากการโยนเหรียญสู่ SBM

นิยามบอกว่า SBM ต้องมีสมบัติอะไร แต่ยังไม่บอกว่าจะสร้างมันจากของที่จับต้องได้อย่างไร วิธีที่ง่ายที่สุดคือโยนเหรียญ แบ่งเวลา $T$ ปีเป็น $n$ ก้าว ก้าวละ $\Delta t=T/n$ ปี ทุกก้าวโยนเหรียญหนึ่งครั้ง ให้ $\xi_k=+1$ ถ้าออกหัว และ $\xi_k=-1$ ถ้าออกก้อย โอกาสข้างละครึ่ง แล้วเดินขึ้นหรือลงตามนั้น

คำถามคือก้าวต้องยาวเท่าไร คำตอบถูกบังคับด้วยข้อ “variance เท่ากับเวลา” กรอบข้างล่างลองก้าวยาว $\sqrt{\Delta t}$ แล้วตรวจค่าเฉลี่ย variance และรูปทรงของตำแหน่งตอนจบ $W^{(n)}_T$ ($K$ ในขั้นนี้คือ excess kurtosis ตัวเลขที่บอกว่าหางหนาหรือบางกว่า Normal ซึ่งมี $K=0$ ไม่ใช่ strike) แถวสุดท้ายคือสิ่งเดียวกันในโลกราคา

\[ \begin{aligned} \Delta t&=T/n,\qquad\xi_k=\pm1,\ \ P=\tfrac12,\\ W^{(n)}_T&=\sqrt{\Delta t}\,(\xi_1+\cdots+\xi_n),\\ \mathbb E\big[W^{(n)}_T\big]&=\sqrt{\Delta t}\cdot n\,\mathbb E[\xi_1]=0,\\ \operatorname{Var}\big(W^{(n)}_T\big)&=\Delta t\cdot n\operatorname{Var}(\xi_1)\\ &=\Delta t\cdot n\cdot1=T,\\ K\big(W^{(n)}_T\big)&=-2/n\ \to\ 0,\\ u&=e^{\sigma\sqrt{\Delta t}},\qquad d=1/u. \end{aligned} \]

ทำไมก้าวต้องยาว $\sqrt{\Delta t}$? เพราะ $\xi_k^2=1$ เสมอ เหรียญหนึ่งครั้งจึงมี variance $\mathbb E[\xi_k^2]-0^2=1$ ก้าวยาว $\sqrt{\Delta t}$ จึงมี variance $(\sqrt{\Delta t})^2\times1=\Delta t$ ก้าวทั้ง $n$ อิสระกัน variance จึงบวกกันได้ $n\Delta t=T$ ไม่ว่าจะซอยกี่ก้าว ลองความยาวอื่นดู ถ้าก้าวยาว $\Delta t$ variance คือ $n\,\Delta t^2=T^2/n$ ซึ่งหายไปเมื่อ $n$ โต เส้นทางแบนเป็นเส้นตรง ถ้าก้าวยาวคงที่ $h$ ไม่หดตาม $n$ variance คือ $nh^2$ ซึ่งโตไม่หยุด รากของ $\Delta t$ จึงเป็นความยาวเดียวที่ให้ของที่มีความหมาย

ก้าวเหรียญไม่ใช่ Normal แต่ผลรวมของมันเข้าใกล้ Normal เหรียญหนึ่งครั้งมี $K=\mathbb E[\xi^4]/(\mathbb E[\xi^2])^2-3=1-3=-2$ และผลรวม $n$ ท่อนที่อิสระและเหมือนกันมี $K$ เป็น $1/n$ เท่าของท่อนเดี่ยว ที่ 252 ก้าวจึงเหลือ $-2/252\approx-0.008$ แทบเป็นศูนย์ นี่คือทฤษฎีบทลิมิตกลางที่กำลังทำงาน

ในโลกราคา การเดินแบบเดียวกันคือต้นไม้ binomial ทุกก้าว log ของราคาขยับขึ้นหรือลง $\sigma\sqrt{\Delta t}$ ซึ่งเท่ากับคูณราคาด้วย $u$ หรือ $d$ เช่น SPY ในหน้าที่แล้วมีความผันผวน $\sigma=18\%$ ต่อปี บน grid รายวัน $\Delta t=1/252$ ได้ $u=e^{0.18/\sqrt{252}}=e^{0.01134}\approx1.0114$ และ $d=1/1.0114\approx0.9887$ เมื่อ $n$ โตขึ้น เส้นทางของต้นไม้หน้าตาเหมือน Brownian และราคา option จากต้นไม้เข้าใกล้สูตร Black–Scholes

ขั้นที่ 3 — ประกอบแบบจำลองทุกขนาดจาก SBM

ราคาจริงไม่ได้เริ่มที่ศูนย์ มีทิศทาง และแต่ละตัวผันผวนไม่เท่ากัน แทนที่จะสร้างทฤษฎีใหม่ทุกครั้ง เราเอา SBM มาเลื่อนและยืดสามอย่าง: บวกจุดเริ่ม $x$, บวกเส้นตรง $\mu t$ และคูณการแกว่งด้วย $\sigma$ บรรทัดแรกในกรอบข้างล่างคือนิยามของสิ่งที่สร้าง (สัญลักษณ์ $:=$ แปลว่า “นิยามให้เท่ากับ”) ที่เหลือคือการตรวจว่ามันผ่านกติกาสามข้อของหน้าที่แล้ว โดยมี drift $\mu$ และความผันผวน $\sigma$ จริง

\[ \begin{aligned} X_t&:=x+\mu t+\sigma W_t,\\ \mathbb E[X_t]&=x+\mu t+\sigma\,\mathbb E[W_t]\\ &=x+\mu t,\\ \operatorname{Var}(X_t)&=\sigma^2\operatorname{Var}(W_t)=\sigma^2t,\\ X_{t+s}-X_t&=\mu s+\sigma(W_{t+s}-W_t)\\ &\sim\mathcal N(\mu s,\ \sigma^2s). \end{aligned} \]

หัวใจคือ $x$ กับ $\mu t$ ไม่สุ่ม มันเลื่อนทุกเส้นทางไปเท่ากัน จึงเปลี่ยนค่าเฉลี่ยแต่ไม่เพิ่ม variance ส่วนตัวคูณ $\sigma$ ออกมาเป็น $\sigma^2$ ใน variance เพราะ variance วัดเป็นกำลังสองของระยะ (variance ของตัวแปรที่คูณค่าคงที่) สุดท้าย Normal ที่คูณค่าคงที่แล้วบวกค่าคงที่ยังเป็น Normal การขยับของ $X$ จึงเป็น Normal ที่มีค่าเฉลี่ย $\mu s$ และ variance $\sigma^2s$ ตรงกับกติกาสามข้อพอดี และระดับ $X_t$ เองเป็น $\mathcal N(x+\mu t,\ \sigma^2t)$

ตัวอย่าง: หน้าที่แล้วใช้ SPY ราคา \$520 กับ drift 8% และความผันผวน 18% ต่อปี (ตัวเลขสมมติของโต๊ะ) สองตัวหลังเป็นสัดส่วนของราคา ถ้าจะใช้หน่วยดอลลาร์ ให้คูณด้วยราคา: $x=\$520$, $\mu=0.08\times520=\$41.6$ ต่อปี และ $\sigma=0.18\times520=\$93.6$ ต่อรากของปี ได้แบบจำลอง $X_t=520+41.6t+93.6W_t$ ซึ่งเป็นแบบที่หน้าที่แล้วใช้ตั้งกรอบเตือน 30 นาที และรูปถัดไปวาดมัน

ขั้นที่ 4 — แปลงความผันผวนรายวันเป็นรายสัปดาห์ รายเดือน รายปี

โจทย์ให้อะไรมาบ้าง: กลับมาที่พอร์ตในคำถามเปิดหน้า

  • มูลค่าพอร์ต \$25 ล้าน ถือ SPY อย่างเดียว
  • SD ของผลตอบแทนรายวัน $\sigma_d=1.15\%$ (ตัวเลขสมมติ แทนค่าที่วัดจากข้อมูลย้อนหลัง)
  • หนึ่งวันทำการยาว $1/252$ ปี ตัวเลข 252 มาจากปี 2024 ที่มีวันจันทร์ถึงศุกร์ 262 วัน แล้วลบวันหยุดของตลาดหุ้นสหรัฐ 10 วัน: $262-10=252$

ทำไมใช้แบบจำลองจากขั้นที่แล้วได้? เพราะ $X_t=x+\mu t+\sigma W_t$ บอกว่าการขยับในช่วงยาว $s$ ปีมี SD $\sigma\sqrt s$ ช่วงหนึ่งวันจึงมี SD $\sigma\sqrt{1/252}$ ซึ่งต้องเท่ากับ $\sigma_d$ ที่วัดได้ เราแก้สมการนี้หา $\sigma$ แล้วใช้กับช่วง $n$ วัน:

\[\begin{aligned}\sigma\sqrt{1/252}&=\sigma_d,\\\sigma&=\sigma_d\sqrt{252},\\\sigma_n&=\sigma\sqrt{n/252}=\sigma_d\sqrt n.\end{aligned}\]

จากนั้นแทนตัวเลข สัปดาห์มี 5 วันทำการ เดือนมีราว $252/12=21$ วันทำการ และปีมี 252 วันทำการ สองแถวสุดท้ายคือวิธีของพนักงานใหม่ที่คูณ 252 ตรง ๆ แล้วเทียบกับคำตอบที่ถูก

\[ \begin{aligned} \sigma_5&=1.15\%\times\sqrt5\approx2.571\%,\\ \sigma_{21}&=1.15\%\times\sqrt{21}\approx5.270\%,\\ \sigma_{252}&=1.15\%\times\sqrt{252}\\ &=1.15\%\times15.8745\approx18.256\%,\\ \text{SD}_{252}&=25{,}000{,}000\times0.182557\\ &\approx\$4{,}563{,}921,\\ 1.15\%\times252&=289.8\%,\\ 289.8\%/18.256\%&\approx15.87=\sqrt{252}. \end{aligned} \]

คำตอบ: คูณ \$25 ล้านกับความผันผวนแต่ละช่วง ได้ SD ของ P&L เป็น

  • ต่อวัน $25{,}000{,}000\times0.0115=\$287{,}500$
  • ต่อสัปดาห์ $25{,}000{,}000\times0.0257148\approx\$642{,}870$
  • ต่อเดือน $25{,}000{,}000\times0.0527=\$1{,}317{,}500$ หรือราว \$1.32 ล้าน
  • ต่อปีราว \$4.56 ล้าน ตามแถว $\text{SD}_{252}$ ในกรอบข้างบน

วิธีของพนักงานใหม่ให้ความผันผวน 289.8% ต่อปี หรือ \$72.45 ล้าน ผิดไป $\sqrt{252}\approx15.87$ เท่าพอดี ต้นเหตุคือ สิ่งที่บวกกันข้ามวันได้คือ variance ไม่ใช่ SD: variance ของ 252 วันที่อิสระกันคือ $252\,\sigma_d^2$ SD จึงเป็น $\sqrt{252\,\sigma_d^2}=\sigma_d\sqrt{252}$

ตรวจเองใน 10 วินาที: $\sqrt{252}\approx16$ เพราะ $16^2=256$ จึงอ่านเร็วได้ว่าความผันผวน 1% ต่อวันคือราว 16% ต่อปี และ $1.15\%\times16=18.4\%$ ใกล้ 18.26%

ขั้นที่ 5 — สร้างเส้นทางบนคอมพิวเตอร์ และบั๊กที่พบบ่อยที่สุด

คอมพิวเตอร์เก็บเวลาต่อเนื่องไม่ได้ ต้องแบ่งช่วง $T$ ปีเป็น $N$ ท่อน ท่อนละ $\Delta t$ ปี แล้วเดินทีละท่อน เหมือนการโยนเหรียญข้างบน แต่ใช้เลขสุ่ม Normal มาตรฐาน $Z_k$ (ค่าเฉลี่ย 0, SD 1) แทนเหรียญ คำถามเดิมกลับมา: ต้องคูณ $Z_k$ ด้วยเท่าไร กรอบข้างล่างตอบว่า $\sqrt{\Delta t}$ ด้วยเหตุผลเดียวกับเหรียญ สองแถวสุดท้ายคือสิ่งที่เกิดเมื่อลืมคูณ

\[ \begin{aligned} \Delta t&=T/N,\\ \Delta W_k&=\sqrt{\Delta t}\,Z_k,\quad Z_k\sim\mathcal N(0,1),\\ \operatorname{Var}(\Delta W_k)&=(\sqrt{\Delta t})^2\cdot1=\Delta t,\\ W_{k\Delta t}&=\Delta W_1+\cdots+\Delta W_k,\\ \operatorname{Var}(W_T)&=N\,\Delta t=T,\\ \operatorname{Var}\big(Z_1+\cdots+Z_N\big)&=N,\\ N=252:\ \sqrt N&\approx15.87. \end{aligned} \]

หัวใจของโค้ดคือคูณเลขสุ่มด้วย $\sqrt{\Delta t}$ ไม่ใช่ $\Delta t$ ท่อนหนึ่งจึงมี variance $\Delta t$ และ $N$ ท่อนที่อิสระกันรวมได้ $N\Delta t=T$ ไม่ว่าจะซอยกี่ท่อน Normal ยังมีข้อดีเหนือเหรียญหนึ่งข้อ: ผลรวมของ Normal เป็น Normal พอดี ค่าบนจุดของ grid จึงถูกต้องตามนิยาม SBM ทุกประการ ไม่ได้เป็นค่าประมาณ แม้ grid จะหยาบ

บั๊กที่พบบ่อยคือลืมคูณ $\sqrt{\Delta t}$ แล้วบวก $Z_k$ ตรง ๆ variance ปลายทางจึงเป็น $N$ แทน $T$ ถ้า $T=1$ ปีและซอยรายวัน ($N=252$) SD ปลายปีคือ $\sqrt{252}\approx15.87$ แทน 1 ถ้าซอยรายนาที ตลาดหุ้นสหรัฐเปิดวันละ 6.5 ชั่วโมง จึงมี $N=252\times6.5\times60=98{,}280$ นาทีต่อปี และ SD กลายเป็น $\sqrt{98{,}280}\approx313.5$ ยิ่งซอยละเอียดยิ่งผิดมาก โค้ดท้ายหน้าสุ่ม 20,000 เส้นทางบน grid รายวัน วัด SD ปลายปีได้ 0.996 เมื่อเขียนถูก และ 15.80 เมื่อมีบั๊ก

บั๊กนี้อันตรายเพราะมองไม่เห็น เส้นทางที่ผิดหน้าตาเหมือนเส้นทางราคาทั่วไป แค่ใหญ่ผิดขนาด วิธีจับคือวัด SD ของปลายทางแล้วเทียบกับ $\sqrt T$ ทุกครั้ง

ขั้นที่ 6 — ยืดเวลาแล้วบีบความสูง: ได้ SBM ตัวเดิม

ถ้าดูกราฟ SBM หนึ่งปีกับกราฟเก้าปีโดยปิดตัวเลขบนแกน จะแยกไม่ออกว่าอันไหนเป็นอันไหน ขั้นนี้อธิบายว่าทำไม ให้ $c$ เป็นตัวคูณที่ยืดแกนเวลา ($c\gt0$) แล้วสร้าง $Y_t$ โดยอ่านค่า $W$ ที่เวลา $ct$ แล้วหารด้วย $\sqrt c$ เราจะตรวจว่า $Y_t$ ผ่านนิยาม SBM ครบทุกข้อ

\[ \begin{aligned} Y_t&:=W_{ct}/\sqrt c,\qquad c\gt0,\\ Y_0&=W_0/\sqrt c=0,\\ Y_{t+s}-Y_t&=\frac{W_{ct+cs}-W_{ct}}{\sqrt c},\\ \mathbb E[Y_{t+s}-Y_t]&=0,\\ \operatorname{Var}(Y_{t+s}-Y_t)&=\frac{cs}{(\sqrt c)^2}=s. \end{aligned} \]

ทำไมต้องหารด้วย $\sqrt c$ ไม่ใช่ $c$? เพราะตัวเศษคือการขยับของ $W$ ในช่วงยาว $cs$ ซึ่งมี variance $cs$ ตามนิยาม การหารด้วย $\sqrt c$ ทำให้ variance ถูกหารด้วย $(\sqrt c)^2=c$ สองตัวตัดกันพอดี เหลือ $s$ ซึ่งคือ variance ที่ SBM ต้องมีในช่วงยาว $s$ ถ้าหารด้วย $c$ จะเหลือ $s/c$ ผิดนิยาม

ข้ออื่นตามมาเอง Normal หารด้วยค่าคงที่ยังเป็น Normal และการขยับของ $Y$ หลังเวลา $t$ สร้างจากการขยับของ $W$ หลังเวลา $ct$ ซึ่งอิสระจากอดีตอยู่แล้ว $Y$ จึงเป็น SBM โค้ดท้ายหน้าตรวจด้วยการสุ่ม $W_9$ แล้วหารด้วย $\sqrt9=3$ ได้ 68.3% ของเส้นทางอยู่ในช่วง ±1 ตรงกับ 68.27% ของ $\mathcal N(0,1)$

ผลที่ตามมาคือ เส้นทาง Brownian ไม่มีสเกลเวลาที่เป็นธรรมชาติ ซูมเข้าไปกี่ชั้นก็ขรุขระเท่าเดิม หน้าสมบัติแปลก ๆ ของเส้นทาง Brownianจะใช้ข้อนี้ต่อ

ขั้นที่ 7 — ค่าเฉลี่ยของขนาดการขยับ $\mathbb E|Z|$

ส่วนที่เหลือของหน้าใช้ SBM ตั้งราคา straddle ซึ่งจ่ายตามขนาดการขยับ $|S_T-S_0|$ โดยไม่สนทิศ ขั้นถัดไปจะแสดงว่าการขยับของราคาคือค่าคงที่คูณเลขสุ่ม Normal มาตรฐาน $Z$ สิ่งที่ต้องรู้จึงไม่ใช่ค่าเฉลี่ย $\mathbb E[Z]$ ซึ่งเป็นศูนย์ เพราะขึ้นกับลงหักล้างกัน แต่เป็นค่าเฉลี่ยของขนาด $\mathbb E|Z|$

วิธีคิด: ระฆังของ Normal สมมาตร ครึ่งซ้ายกับครึ่งขวาให้ค่าเท่ากัน จึงคิดแค่ครึ่งขวา ($z\ge0$ ซึ่ง $|z|=z$) แล้วคูณสอง โดย $\varphi(z)=e^{-z^2/2}/\sqrt{2\pi}$ คือ density ของ Normal มาตรฐาน

\[ \begin{aligned} \mathbb E|Z|&=2\int_0^\infty z\,\varphi(z)\,dz\\ &=\frac{2}{\sqrt{2\pi}}\int_0^\infty z\,e^{-z^2/2}\,dz\\ &=\frac{2}{\sqrt{2\pi}}\Big[-e^{-z^2/2}\Big]_0^\infty\\ &=\frac{2}{\sqrt{2\pi}}(0+1)=\sqrt{\frac{2}{\pi}}\\ &\approx0.797885. \end{aligned} \]

จังหวะที่ทำให้อินทิเกรตง่ายคือสังเกตว่าอนุพันธ์ของ $-e^{-z^2/2}$ คือ $z\,e^{-z^2/2}$ พอดี จึงได้ antiderivative ทันทีโดยไม่ต้องเปลี่ยนตัวแปร ที่ปลายอนันต์ $e^{-z^2/2}$ เป็นศูนย์ และที่ $z=0$ มันเป็น 1 ผลต่างจึงเป็น $0-(-1)=1$

อ่านผล: ขนาดการขยับเฉลี่ยคือราว 0.80 SD ไม่ใช่ 1 SD เพราะการขยับส่วนใหญ่เล็กกว่าหนึ่ง SD และการขยับใหญ่ที่ดึงค่าเฉลี่ยขึ้นเกิดไม่บ่อย จำเป็นกฎในหัวได้ว่า ค่าเฉลี่ยของ $|Z|$ ราว 0.8

ขั้นที่ 8 — ราคา straddle 30 วันด้วยทางลัด

โจทย์ให้อะไรมาบ้าง: กลับมาที่คำถามที่สองของเปิดหน้า

  • ราคา SPY วันนี้ $S_0=\$520$ และ strike (ราคาใช้สิทธิ์) ก็ \$520 เท่ากัน จึงเป็น ATM
  • อายุ 30 วันปฏิทิน คิดเป็นปีได้ $T=30/365$
  • ความผันผวน $\sigma=18.256\%$ ต่อปี ซึ่งได้จากการแปลง 1.15% ต่อวันในขั้นแปลงความผันผวนข้างบน
  • ดอกเบี้ยและเงินปันผลเป็นศูนย์ (สมมติเพื่อให้ง่าย)

ราคาที่ยุติธรรมของ option คือค่าเฉลี่ยของเงินที่มันจ่าย (ดอกเบี้ยเป็นศูนย์ จึงไม่ต้องคิดลดเงินในอนาคต) โดยคิดในโลกสมมติที่ใช้ตั้งราคา เรียกว่า risk-neutral measure ในโลกนั้น เมื่อดอกเบี้ยเป็นศูนย์ ราคาไม่มี drift หน้านั้นอธิบายว่าทำไม ที่นี่เรารับข้อนี้มาใช้

เราใช้แบบจำลองเส้นตรงจากขั้นประกอบแบบจำลองข้างบน โดยให้ $\mu=0$ และความผันผวนเป็นดอลลาร์คือ $S_0\sigma$: $S_T-S_0\approx S_0\sigma W_T$ ใน 30 วันราคาขยับไม่มาก แบบเส้นตรงจึงใกล้ของจริง (ขั้นถัดไปจะตรวจ) $W_T$ มี SD $\sqrt T$ จึงเขียนได้ว่า $W_T=\sqrt T\,Z$ แล้วใช้ $\mathbb E|Z|$ จากขั้นที่แล้วได้ตรง ๆ

\[ \begin{aligned} \text{payoff}&=|S_T-S_0|\approx S_0\sigma|W_T|\\ &=S_0\sigma\sqrt T\,|Z|,\\ \mathbb E[\text{payoff}]&\approx S_0\sigma\sqrt T\,\mathbb E|Z|,\\ T&=30/365\approx0.082192,\\ \sqrt T&\approx0.286691,\\ \sigma\sqrt T&=0.182557\times0.286691\\ &\approx0.052337,\\ \mathbb E[\text{payoff}]&\approx520\times0.052337\times0.797885\\ &\approx21.715. \end{aligned} \]

คำตอบ: straddle ควรมีราคาราว \$21.71 ต่อหุ้น หรือ $21.715/520\approx4.176\%$ ของราคาหุ้น สัญญา option ของ SPY หนึ่งสัญญาอ้างอิง 100 หุ้น จึงเป็น $100\times21.715\approx\$2{,}171$ ต่อสัญญา

สังเกตว่าการคำนวณนี้ใช้นาฬิกาสองแบบ อายุ option นับวันปฏิทิน 365 วัน เพราะสัญญาหมดอายุตามปฏิทินจริง ส่วน $\sigma$ นับ 252 วันทำการ เพราะราคาขยับเฉพาะตอนตลาดเปิด ถ้านับอายุเป็น 21 วันทำการแทน จะได้ $\sigma\sqrt{21/252}=1.15\%\times\sqrt{21}\approx5.270\%$ แทน 5.234% ที่ 30 วันต่างกันไม่มาก แต่ต้องรู้ตัวว่ากำลังใช้นาฬิกาไหน อย่าปนสองแบบในสูตรเดียวโดยไม่ตั้งใจ

ตรวจเองใน 10 วินาที: $0.8\times5.23\%\approx4.18\%$ และ $0.0418\times520\approx21.7$

ขั้นที่ 9 — ตรวจทางลัดกับสูตร Black–Scholes

ทางลัดใช้แบบจำลองเส้นตรง จึงต้องตรวจกับสูตรเต็มก่อนเชื่อ แถวแรกของกรอบข้างล่างคือสูตร Black–Scholesของ straddle ATM ที่ดอกเบี้ยเป็นศูนย์ หน้านั้นจะพิสูจน์ ที่นี่รับมาใช้ $\Phi$ คือ CDF ของ Normal มาตรฐาน (โอกาสที่ $Z$ ไม่เกินค่าที่ใส่) ซึ่งเปิดตารางหรือใช้ฟังก์ชัน Phi ในโค้ดท้ายหน้าได้ เราแทนตัวเลขก่อน แล้วดูว่าทำไมสองวิธีได้ตัวเลขใกล้กันขนาดนี้

\[ \begin{aligned} \text{BS}&=2S\big[\Phi(d)-\Phi(-d)\big],\quad d=\tfrac12\sigma\sqrt T,\\ d&=0.052337/2\approx0.026169,\\ \Phi(d)-\Phi(-d)&\approx0.020877,\\ \text{BS}&\approx2\times520\times0.020877\\ &\approx21.712,\\ \Phi(d)-\Phi(-d)&\approx2d\,\varphi(0),\\ \text{BS}&\approx S\sigma\sqrt T\cdot2\varphi(0),\\ 2\varphi(0)&=\frac{2}{\sqrt{2\pi}}=\sqrt{\frac{2}{\pi}}. \end{aligned} \]

สูตรเต็มให้ \$21.712 ทางลัดให้ \$21.715 ต่างกันราว $21.7148-21.7123\approx\$0.0025$ หรือ 0.25 เซนต์ ทำไมใกล้กันขนาดนี้? เพราะ $\Phi(d)-\Phi(-d)$ คือพื้นที่ใต้ระฆังระหว่าง $-d$ กับ $d$ เมื่อ $d$ เล็ก ยอดระฆังตรงนั้นแทบแบน พื้นที่จึงเกือบเท่ากับสี่เหลี่ยมที่สูง $\varphi(0)$ และกว้าง $2d$ แทน $d=\tfrac12\sigma\sqrt T$ กลับเข้าไปได้ $S\sigma\sqrt T\cdot2\varphi(0)$ และ $2\varphi(0)$ คือ $\sqrt{2/\pi}$ ตัวเดียวกับค่าเฉลี่ยของ $|Z|$ พอดี

ทางลัดจึงคือ Black–Scholes ที่ตัดพจน์เล็กทิ้ง มันเริ่มเพี้ยนเมื่อ $\sigma\sqrt T$ ใหญ่ เช่น option อายุยาวหรือหุ้นที่ผันผวนมาก เพราะยอดระฆังไม่แบนตลอดช่วงที่กว้างขึ้น ครึ่งหนึ่งของทางลัดคือกฎในหัวของคนเทรด option ว่า ATM call ราคาราว $\tfrac12\sqrt{2/\pi}\,S\sigma\sqrt T\approx0.4\,S\sigma\sqrt T$ (เมื่อดอกเบี้ยเป็นศูนย์ call กับ put ที่ ATM ราคาเท่ากัน แต่ละตัวจึงเป็นครึ่งหนึ่งของ straddle)

ทางลัดนี้มีประวัติยาว Louis Bachelier ใช้แบบจำลองเส้นตรงนี้ตั้งราคา option ในปารีสตั้งแต่ปี 1900 และ $S\sigma\sqrt T\sqrt{2/\pi}$ คือสูตรของเขาพอดี

ความผิดที่รันผ่านแต่ให้ตัวเลขผิด

คูณ SD ด้วยจำนวนวัน: ความผิดคือคิดว่า SD บวกกันข้ามวันได้ ตัวเลขผิดคือ $287{,}500\times252=\$72{,}450{,}000$ ตัวเลขถูกคือ $287{,}500\times\sqrt{252}\approx\$4{,}563{,}921$ ต่างกัน $\sqrt{252}\approx15.87$ เท่า spreadsheet ไม่เตือน เพราะสูตรคูณเลขทำงานปกติ วิธีจับในสองวินาที: เวลาสี่เท่าต้องให้ความเสี่ยง $\sqrt4=2$ เท่า ไม่ใช่สี่เท่า

ลืม $\sqrt{\Delta t}$ ในการจำลอง: ความผิดคือบวกเลขสุ่ม $Z_k$ ตรง ๆ แทน $\sqrt{\Delta t}\,Z_k$ SD ปลายปีที่ถูกคือ $\sqrt T=1$ แต่ที่ได้คือ $\sqrt N$: $\sqrt{252}\approx15.87$ ถ้าซอยรายวัน และ $\sqrt{98{,}280}\approx313.5$ ถ้าซอยรายนาที ความผิดแบบกลับด้านคือคูณ $\Delta t$ แทน $\sqrt{\Delta t}$ variance จะเป็น $N\,\Delta t^2=252\times(1/252)^2=1/252$ SD จึงเหลือ $1/\sqrt{252}\approx0.063$ เส้นทางแบนเกือบเป็นเส้นตรง วิธีจับทั้งสองแบบคือวัด SD ปลายทางเทียบกับ $\sqrt T$ ทุกครั้งที่เขียนโค้ดจำลองใหม่

ปนนาฬิกาสองแบบ: การใช้ $\sigma$ ที่วัดจาก 252 วันทำการกับอายุ option ที่นับ 365 วันปฏิทินไม่ผิด ถ้าตั้งใจ ความผิดคือแปลงความผันผวนรายวันด้วย $\sqrt{365}$ ทั้งที่ข้อมูลรายวันมาจากวันที่ตลาดเปิดเท่านั้น ตัวเลขผิดคือ $1.15\%\times\sqrt{365}\approx21.97\%$ ตัวเลขถูกคือ $1.15\%\times\sqrt{252}\approx18.26\%$ สูงไป $21.97/18.26\approx1.20$ เท่า หรือราว 20% ทั้งที่ไม่มีอะไรเปลี่ยน

ใช้ทางลัด straddle นอกขอบเขต: ทางลัด $S\sigma\sqrt T\sqrt{2/\pi}$ ใช้ได้เมื่อ strike เท่ากับราคาวันนี้ (ATM), ดอกเบี้ยต่ำ และ $\sigma\sqrt T$ เล็ก ถ้า strike ห่างจากราคาวันนี้มาก เงินที่ได้ไม่ใช่ $|S_T-S_0|$ อีกต่อไป ถ้า $\sigma\sqrt T$ ใหญ่ ยอดระฆังที่เราถือว่าแบนจะไม่แบนอีก เช่นหุ้นราคา \$100 ความผันผวน 50% ต่อปี อายุ 2 ปี มี $\sigma\sqrt T=0.5\times\sqrt2\approx0.7071$ ทางลัดให้ $100\times0.7071\times0.797885\approx\$56.42$ แต่ Black–Scholes ให้ $2\times100\times[\Phi(0.354)-\Phi(-0.354)]\approx\$55.27$ ทางลัดสูงไป $56.42/55.27-1\approx2\%$ เทียบกับ 0.01% ในตัวอย่าง 30 วัน

ใช้ทำอะไรบนโต๊ะจริง

ระบบ risk แทบทุกระบบใช้กฎรากที่สองของเวลาทุกวัน เพื่อแปลงความผันผวนรายวันเป็นรายเดือนหรือรายปีก่อนรายงาน

ระบบ Monte Carlo (การจำลองเส้นทางสุ่มจำนวนมากบนคอมพิวเตอร์) ทุกระบบเริ่มจากบรรทัด $\Delta W_k=\sqrt{\Delta t}\,Z_k$ แล้วค่อยเลื่อนและยืดเป็น $x+\mu t+\sigma W_t$ หรือเอาไปใส่เป็นเลขชี้กำลังของราคาใน geometric Brownian motion

คนเทรด option ใช้ทางลัด $0.8\,S\sigma\sqrt T$ แปลงราคา straddle เป็นความผันผวนในหัว ก่อนเปิดโปรแกรมคำนวณเต็ม เช่นเห็น straddle 30 วันราคา 4.18% ของหุ้น ก็อ่านได้ทันทีว่า $\sigma\sqrt T\approx4.18\%/0.8\approx5.2\%$

// Standard Normal CDF by Simpson's rule on the density.
function Phi(x) {
  if (!Number.isFinite(x) || Math.abs(x) > 8) throw new RangeError('Phi needs a finite score within 8');
  const n = 4000, h = Math.abs(x) / n, phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(x) * s * h / 3;
}
// SD over n periods from the one-period SD: variances add, so SD grows with sqrt(n).
const horizonSD = (sd1, n) => sd1 * Math.sqrt(n);
// E|Z| by integrating 2 z phi(z) from 0 to 12 (the tail beyond 12 is below 1e-30).
function meanAbsZ() {
  const n = 12000, h = 12 / n;
  let s = 0;
  for (let i = 0; i <= n; i++) {
    const z = i * h;
    s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * 2 * z * Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
  }
  return s * h / 3;
}
// ATM straddle, zero rates: small-move shortcut and the full Black-Scholes value.
const straddleShortcut = (S, sigma, T) => S * sigma * Math.sqrt(T) * meanAbsZ();
function straddleBS(S, sigma, T) {
  const half = sigma * Math.sqrt(T) / 2;
  return 2 * S * (Phi(half) - Phi(-half));
}
// Implied volatility: bisection on the Black-Scholes straddle price.
function impliedVol(price, S, T) {
  if (!(price > 0 && price < 2 * S)) throw new RangeError('Straddle price must be between 0 and 2S');
  let lo = 1e-6, hi = 5;
  for (let i = 0; i < 100; i++) {
    const mid = (lo + hi) / 2;
    if (straddleBS(S, mid, T) < price) lo = mid; else hi = mid;
  }
  return (lo + hi) / 2;
}
// mulberry32 + Box-Muller: seeded standard Normals.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Simulate W on a grid of `steps` over [0, T]; scaled=false reproduces the classic bug (no sqrt(dt)).
function terminalSD(paths, steps, T, seed, scaled = true) {
  const z = normals(seed), step = scaled ? Math.sqrt(T / steps) : 1;
  let sum = 0, sumSq = 0, inside = 0;
  for (let p = 0; p < paths; p++) {
    let w = 0;
    for (let k = 0; k < steps; k++) w += step * z();
    sum += w; sumSq += w * w;
    if (Math.abs(w) <= Math.sqrt(T)) inside++;
  }
  const mean = sum / paths;
  return {mean, sd: Math.sqrt((sumSq - paths * mean * mean) / (paths - 1)), inside: inside / paths};
}
// Coin walk: n steps of +/- sqrt(T/n); its end has mean 0, variance T and excess kurtosis -2/n.
function coinWalk(paths, n, T, seed) {
  const z = normals(seed); // the sign of a Normal is a fair coin
  let m2 = 0, m4 = 0;
  for (let p = 0; p < paths; p++) {
    let w = 0;
    for (let k = 0; k < n; k++) w += (z() > 0 ? 1 : -1) * Math.sqrt(T / n);
    m2 += w * w; m4 += w ** 4;
  }
  m2 /= paths; m4 /= paths;
  return {sd: Math.sqrt(m2), excessKurtosis: m4 / (m2 * m2) - 3, theory: -2 / n};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • SBM เริ่มที่ 0 การขยับในช่วงยาว $s$ เป็น $\mathcal N(0,s)$ และอิสระจากเส้นทางทั้งหมดที่ผ่านมา จึงได้ $\mathbb E[W_t]=0$ และ $\operatorname{Var}(W_t)=t$: ที่เวลา $t$ มันมักอยู่ห่างศูนย์ราว $\sqrt t$
  • SBM คือการโยนเหรียญที่ก้าวละ $\pm\sqrt{\Delta t}$ เมื่อ $\Delta t$ หดลง ก้าวต้องยาว $\sqrt{\Delta t}$ เพื่อให้ variance รวมเท่ากับเวลาพอดี ในโลกราคามันคือต้นไม้ binomial ที่ $u=e^{\sigma\sqrt{\Delta t}}$
  • $X_t=x+\mu t+\sigma W_t$ มีการขยับ $\mathcal N(\mu s,\sigma^2s)$ แบบจำลองทุกขนาดจึงสร้างจาก SBM แบบเดียว
  • ความผันผวน $n$ วันคือ $\sigma_d\sqrt n$ เพราะ variance บวกกันข้ามวัน แต่ SD ไม่บวก: 1.15% ต่อวันเป็น 18.26% ต่อปี หรือ \$4.56 ล้านบนพอร์ต \$25 ล้าน ไม่ใช่ \$72.45 ล้าน
  • การจำลองต้องคูณเลขสุ่มด้วย $\sqrt{\Delta t}$ และ $W_{ct}/\sqrt c$ เป็น SBM ตัวเดิม เส้นทาง Brownian จึงหน้าตาเหมือนกันทุกสเกลเวลา
  • ATM straddle ราคาราว $S\sigma\sqrt T\sqrt{2/\pi}\approx0.8\,S\sigma\sqrt T$: \$21.71 สำหรับ 30 วัน ตรงกับ Black–Scholes เพราะเป็นพจน์แรกของมันเมื่อ $\sigma\sqrt T$ เล็ก

หน้าถัดไป filtration ในเวลาต่อเนื่อง ถามว่า ณ เวลาหนึ่งเรารู้อะไรแล้วบ้าง มันใช้ข้อ “การขยับในอนาคตอิสระจากอดีตทั้งเส้น” พิสูจน์ว่าการทำนายที่ดีที่สุดของ SBM คือค่าปัจจุบัน และใช้หลักเดียวกันจับ backtest (การทดสอบกลยุทธ์กับข้อมูลย้อนหลัง) ที่แอบใช้ข้อมูลจากอนาคต
