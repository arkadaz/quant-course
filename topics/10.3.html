10.3 Three Properties GBM Inherits from Brownian Motion

การขยับอิสระกลายเป็นตัวคูณอิสระ เส้นทางต่อเนื่องยังต่อเนื่อง และความเป็น Normal ย้ายไปอยู่บน log ของราคา ผลคือเป้า +\$30 กับ −\$30 มีโอกาสไม่เท่ากัน

หุ้นสมมติราคา \$100 เดินตาม GBM ที่ $\mu=10\%$ และ $\sigma=25\%$ ต่อปี analyst ตั้งเป้าขึ้นที่ \$130 และจุดตัดขาดทุนที่ \$70 ห่างจากราคาวันนี้ \$30 เท่ากัน เพื่อนร่วมทีมบอกว่า “ห่างเท่ากัน โอกาสก็น่าจะใกล้กัน” ในหนึ่งปี โอกาสที่ราคาปิดเหนือ \$130 กับโอกาสที่ปิดใต้ \$70 เป็นเท่าไร?

ลองตอบก่อนเปิดเฉลย

21.93% กับ 4.44% ต่างกันเกือบห้าเท่า บนแกน log ขึ้น 30% คือ +0.262 แต่ลง 30% คือ −0.357 ซึ่งไกลกว่า และจุดกลางของ log return คือ 0.06875 ไม่ใช่ศูนย์ ถ้าเผลอใช้ $\mu=0.10$ เป็นจุดกลาง จะได้โอกาสเหนือ \$130 เป็น 25.80% สูงเกินไป 3.9 จุด และโอกาสที่ราคาจะแตะ \$70 ระหว่างปีคือ 10.13% ไม่ใช่ 4.44%

ภาพรวมก่อนลงสูตร

Brownian motion ถูกนิยามด้วยสามสมบัติ: การขยับในช่วงที่ไม่ทับกันเป็นอิสระ การขยับเป็น Normal ที่ variance เท่ากับความยาวช่วง และเส้นทางต่อเนื่อง (สามสมบัติของ Brownian motion) GBM คือ exponential ของ $\nu t+\sigma W_t$ ทั้งสามสมบัติจึงส่งผ่าน exponential มาถึงราคา แต่แต่ละข้อเปลี่ยนรูประหว่างทาง และรูปใหม่นั้นคือสิ่งที่ต้องใช้บนโต๊ะ

ข้อแรกกลายเป็น “ตัวคูณของช่วงข้างหน้าไม่สนว่าราคาเดินมาอย่างไร” ข้อสองยังอยู่ครบและห้ามราคากระโดด ข้อสามทำให้ log ของราคา เป็น Normal ซึ่งเป็นเครื่องมือที่ใช้ตอบคำถามเรื่องเป้าราคาและจุดตัดขาดทุน รูปด้านล่างรวมทั้งสามไว้ในภาพเดียว หน้านี้จะไล่ทีละข้อ ตอบคำถามเปิด ตรวจคำตอบด้วยการซอยปีเป็นสองครึ่ง และปิดด้วยความต่างระหว่าง “ปิดใต้ \$70” กับ “เคยแตะ \$70”

$S_{t+s}/S_t$ ตัวคูณของราคาในช่วงหนึ่ง เป็นสิ่งที่ GBM ทำให้อิสระจากอดีต ใช้แยกให้ออกว่าอะไรลืมอดีตและอะไรไม่ลืม
Independent increments
สมบัติที่การขยับในช่วงเวลาไม่ทับกันไม่บอกอะไรเกี่ยวกันเลย ใน Brownian motion เป็นการขยับแบบบวก ใน GBM กลายเป็นตัวคูณ
Continuous path
เส้นทางที่ลากได้โดยไม่ยกดินสอ ราคาผ่านทุกระดับระหว่างสองจุดเวลา ใช้เป็นเหตุผลว่าทำไม hedge และ stop-loss ในแบบจำลองได้ราคาที่ตั้งไว้พอดี
Gap
ราคาที่กระโดดข้ามช่วงหนึ่งโดยไม่มีการซื้อขายระหว่างทาง เช่นราคาเปิดหลังข่าวตอนตลาดปิด เป็นสิ่งที่ GBM ห้ามเกิด
Exceedance probability
$P(S_T\gt K)$ โอกาสที่ราคาปลายช่วงเกินเกณฑ์ $K$ ใช้ตอบคำถามเรื่องเป้าราคา จุดตัดขาดทุน และ payoff ของ option
Stop-loss
คำสั่งขายเมื่อราคาแตะระดับที่กำหนด ใช้จำกัดขาดทุน แต่ได้ราคาตามที่ตั้งก็ต่อเมื่อราคาเดินผ่านระดับนั้นจริง
Reflection principle
ผลที่ใช้หาโอกาสที่เส้นทางต่อเนื่องจะแตะระดับหนึ่งระหว่างช่วง ไม่ใช่แค่ที่ปลายช่วง ใช้ตอบว่า stop-loss จะถูกชนบ่อยแค่ไหน

ขั้นที่ 1 — สมบัติที่ 1: ตัวคูณในอนาคตลืมอดีต

สมบัติแรกของ Brownian motion พูดถึงการขยับแบบบวก เมื่อผ่าน exponential แล้วมันกลายเป็นอะไร? เขียนราคาที่เวลา $t+s$ ด้วยสูตรเดินหน้าของ GBM แล้วหารด้วยราคาวันนี้ เพื่อดูว่าตัวคูณของช่วงข้างหน้าขึ้นกับอะไรบ้าง

\[ \begin{aligned} S_{t+s}&=S_te^{\nu s+\sigma(W_{t+s}-W_t)},\\ R_{t,s}&:=\frac{S_{t+s}}{S_t}=e^{\nu s+\sigma(W_{t+s}-W_t)},\\ W_{t+s}-W_t&\sim\mathcal N(0,s). \end{aligned} \]

ฝั่งขวาของบรรทัดที่สองไม่มีราคาเหลืออยู่เลย มีแต่ค่าคงที่กับการขยับของ $W$ ที่เกิดหลังเวลา $t$ ซึ่งอิสระจากทุกอย่างที่รู้ถึงเวลา $t$ และ function ของตัวแปรอิสระก็ยังอิสระ (ความเป็นอิสระ) ตัวคูณของช่วงข้างหน้าจึงไม่ขึ้นกับว่าราคาเดินมาอย่างไร และ distribution ของมันขึ้นกับความยาวช่วง $s$ อย่างเดียว ไม่ขึ้นกับระดับราคา $S_t$ หุ้น \$20 กับหุ้น \$500 ที่ใช้ $\mu,\ \sigma$ เดียวกันมีตัวคูณหน้าตาเดียวกันทุกประการ ตัวคูณของช่วงที่ไม่ทับกันก็อิสระต่อกันด้วยเหตุผลเดียวกัน

ต้องระวังว่าสิ่งที่อิสระคือตัวคูณ ไม่ใช่ระดับราคา อดีตกำหนดว่าเราเริ่มจากไหน แต่ไม่กำหนดว่าจะไปทางไหนต่อ ขั้นถัดไปแสดงว่าส่วนต่างเป็นดอลลาร์ยังจำระดับราคาอยู่

ขั้นที่ 2 — ส่วนต่างเป็นดอลลาร์ยังจำระดับราคา

ความเสี่ยงบนโต๊ะวัดเป็นดอลลาร์ จึงต้องรู้ SD ของ $\Delta S=S_t(R-1)$ ค่าเฉลี่ยของ $R$ คือ moment generating function ของ log ratio ที่จุด 1 ซึ่งหน้า ราคาคาดหวังในอนาคต หาไว้แล้ว และค่าเฉลี่ยของ $R^2=e^{2X}$ คือ MGF ตัวเดียวกันที่จุด $u=2$ ตัวอย่างใช้ $\mu=0.10$, $\sigma=0.25$ และ $s=1$ ปี

\[ \begin{aligned} \mathbb E[R]&=M_X(1)=e^{\nu s+\frac12\sigma^2s}=e^{\mu s},\\ \mathbb E[R^2]&=M_X(2)=e^{2\nu s+2\sigma^2s}\\ &=e^{2\mu s+\sigma^2s},\\ \operatorname{Var}_t(\Delta S)&=S_t^2\big(\mathbb E[R^2]-\mathbb E[R]^2\big)\\ &=S_t^2e^{2\mu s}\big(e^{\sigma^2s}-1\big),\\ S_t=\$100:&\quad100e^{0.10}\sqrt{e^{0.0625}-1}\approx\$28.07,\\ S_t=\$20:&\quad20e^{0.10}\sqrt{e^{0.0625}-1}\approx\$5.61. \end{aligned} \]

$S_t$ ถูกดึงออกมาหน้าวงเล็บ variance จึงคูณด้วย $S_t^2$ และ SD คูณด้วย $S_t$ หุ้น \$100 มี SD ของส่วนต่างหนึ่งปี \$28.07 หุ้น \$20 ที่มีตัวคูณหน้าตาเดียวกันมีแค่ \$5.61 เล็กกว่าห้าเท่าตามสัดส่วนราคา และหุ้น \$500 มี variance เป็น $25^2=625$ เท่าของหุ้น \$20

ความผิดที่พบบ่อยคือคิดว่าเมื่อตัวคูณลืมอดีตแล้ว ส่วนต่างเป็นดอลลาร์ก็ลืมด้วย ไม่จริง: หุ้นที่ขึ้นจาก \$100 เป็น \$200 จะเหวี่ยงเป็นดอลลาร์แรงขึ้นสองเท่า การถือจำนวนหุ้นเท่าเดิมจึงแบกความเสี่ยงเป็นเงินมากขึ้นตามราคา

ขั้นที่ 3 — สมบัติที่ 2: ความต่อเนื่องรอดผ่าน exponential

สมบัติที่สองดูเหมือนไม่มีอะไร แต่ผลของมันหนักที่สุดบนโต๊ะ ตามโครงสร้างของสูตรจากข้างในออกมา: ข้างในสุดคือ $W_t$ ซึ่งต่อเนื่องตามนิยาม แล้วยืดและเลื่อนด้วยค่าคงที่ แล้วใส่ exponential

\[ \begin{aligned} \lim_{h\to0}W_{t+h}&=W_t,\\ \lim_{h\to0}\big(\nu(t+h)+\sigma W_{t+h}\big)&=\nu t+\sigma W_t,\\ \lim_{h\to0}S_{t+h}&=S_0\exp\Big(\lim_{h\to0}\big(\nu(t+h)+\sigma W_{t+h}\big)\Big)\\ &=S_0e^{\nu t+\sigma W_t}=S_t. \end{aligned} \]

ต่อเนื่องแปลว่าขยับเวลาไปนิดเดียว ค่าก็ขยับไปนิดเดียว คือ limit เท่ากับค่าที่จุดนั้น การคูณและบวกค่าคงที่แค่ยืดกับเลื่อนจึงไม่ทำให้เส้นขาด และย้าย limit เข้าไปใน exponential ได้เพราะ $e^x$ เองต่อเนื่อง ราคาจึงผ่านทุกระดับระหว่างสองจุดเวลา

แต่ต่อเนื่องไม่ได้แปลว่าเรียบ เส้นทางยังหยักจนหาความชันไม่ได้ เหมือนที่เห็นใน สมบัติแปลก ๆ ของเส้นทาง Brownian

ผลบนโต๊ะคือแบบจำลองนี้ห้ามราคากระโดด stop-loss ที่ \$70 ในแบบจำลองได้ราคา \$70 พอดีเสมอ เพราะราคาต้องเดินผ่าน \$70 ก่อนลงต่ำกว่านั้น ตลาดจริงไม่รับประกันแบบนั้น ถ้าข่าวร้ายออกตอนตลาดปิด ราคาเปิดวันรุ่งขึ้นอาจอยู่ที่ \$55 เลย

ขั้นที่ 4 — สมบัติที่ 3: ความเป็น Normal ย้ายไปอยู่บน log

สมบัติที่สามบอกว่า $W_T\sim\mathcal N(0,T)$ ผ่าน exponential แล้วราคาไม่ได้เป็น Normal สิ่งที่ยังเป็น Normal คือ log ของราคา ขั้นนี้เขียนให้ชัดเพราะทุกการคำนวณโอกาสต่อจากนี้เริ่มจากบรรทัดสุดท้าย

\[ \begin{aligned} \ln\frac{S_T}{S_0}&=\nu T+\sigma W_T,\\ \mathbb E\Big[\ln\frac{S_T}{S_0}\Big]&=\nu T,\\ \operatorname{Var}\Big(\ln\frac{S_T}{S_0}\Big)&=\sigma^2T,\\ \ln\frac{S_T}{S_0}&\sim\mathcal N\big(\nu T,\ \sigma^2T\big),\\ S_T&=S_0e^{\nu T+\sigma W_T}\gt0. \end{aligned} \]

จุดกลางมาจากค่าคงที่ $\nu T$ อย่างเดียวเพราะ $W_T$ มีค่าเฉลี่ยศูนย์ ความกว้างมาจาก $\sigma W_T$ อย่างเดียวเพราะค่าคงที่ไม่เหวี่ยง และการคูณกับบวกค่าคงที่ไม่ทำให้ Normal เลิกเป็น Normal SD เท่ากับ $\sigma\sqrt T$ คือเหตุที่กรวยในรูปแรกบานแบบรากที่สอง ไม่ใช่เส้นตรง

บรรทัดสุดท้ายคือเหตุที่ราคาติดลบไม่ได้ Normal บนแกน log มีหางซ้ายยาวไม่สิ้นสุด แต่หางนั้นแปลว่าราคาเข้าใกล้ศูนย์ ไม่ใช่ข้ามศูนย์ ราคาจึงเป็น lognormal ที่เบ้ขวา: บีบฝั่งซ้ายเข้าหาศูนย์ ยืดฝั่งขวาออกไม่จำกัด

ขั้นที่ 5 — แปลงเกณฑ์ราคาเป็นระยะบนแกน Normal

distribution ที่เรารู้อยู่บนแกน log ไม่ได้อยู่บนแกนราคา จึงต้องย้ายอสมการทั้งก้อนไปแกน log ใส่ log ทั้งสองข้างได้โดยไม่พลิกเครื่องหมายเพราะ log เพิ่มขึ้นตลอด และราคาเป็นบวกเสมอ จากนั้นลบจุดกลางและหารด้วย SD ทั้งสองข้าง แบบเดียวกับการอ่านตาราง Normal distribution

\[ \begin{aligned} P(S_T\gt K)&=P\Big(\ln\frac{S_T}{S_0}\gt\ln\frac{K}{S_0}\Big),\\ Z&:=\frac{\ln(S_T/S_0)-\nu T}{\sigma\sqrt T}\sim\mathcal N(0,1),\\ d&:=\frac{\ln(K/S_0)-\nu T}{\sigma\sqrt T},\\ P(S_T\gt K)&=P(Z\gt d)=1-\Phi(d),\\ P(S_T\lt K)&=\Phi(d). \end{aligned} \]

ต้องแปลงฝั่งขวาด้วยวิธีเดียวกับฝั่งซ้าย ไม่อย่างนั้นอสมการจะไม่เท่าเดิม ตัวหาร $\sigma\sqrt T$ เป็นบวก เครื่องหมายจึงไม่พลิก พอแปลงเสร็จ คำถามเรื่องราคากลายเป็นคำถามเรื่อง standard Normal ซึ่งอ่านจาก $\Phi$ ได้ทันที

$d$ ไม่มีหน่วย: ตัวเศษเป็น log ratio และตัวส่วนเป็น SD ของ log ratio เครื่องมือเดียวกันนี้จะกลับมาใน สูตร Black–Scholes ซึ่งต้องหาค่าเฉลี่ยของ payoff ของ option ไม่ใช่แค่โอกาส

ขั้นที่ 6 — ตอบคำถามเปิด: เหนือ \$130 และใต้ \$70

โจทย์ให้อะไรมาบ้าง: $S_0=\$100$, $\mu=0.10$, $\sigma=0.25$ และ $T=1$ ปี เกณฑ์ \$130 และ \$70

\[ \begin{aligned} \nu&=0.10-\tfrac12(0.25)^2=0.06875,\\ \ln1.30&\approx0.262364,\qquad \ln0.70\approx-0.356675,\\ d_{130}&=\frac{0.262364-0.06875}{0.25}\approx0.77446,\\ P(S_1\gt130)&=1-\Phi(0.77446)\approx21.93\%,\\ d_{70}&=\frac{-0.356675-0.06875}{0.25}\approx-1.70170,\\ P(S_1\lt70)&=\Phi(-1.70170)\approx4.44\%. \end{aligned} \]

คำตอบ: โอกาสเหนือ \$130 คือ 21.93% ใต้ \$70 คือ 4.44% และอยู่ระหว่างสองระดับ $1-0.21933-0.04441\approx73.63\%$ ต่างกันเกือบห้าเท่าด้วยสองเหตุผล: บนแกน log เป้าลงอยู่ไกลกว่า (0.357 เทียบ 0.262) และจุดกลาง 0.06875 เอียงไปทางขวา

ตรวจเองใน 10 วินาที: median คือ $100e^{0.06875}\approx\$107.12$ ทั้ง \$130 และ \$70 อยู่คนละฝั่งของ median สองโอกาสจึงต้องต่ำกว่า 50% ทั้งคู่ และ $d_{130}\approx0.77$ อยู่ระหว่าง 0 กับ 1 คำตอบจึงต้องอยู่ระหว่าง $1-\Phi(1)\approx15.9\%$ กับ 50% ซึ่ง 21.93% ผ่าน

ขั้นที่ 7 — ซอยปีเป็นสองครึ่งปี คำตอบต้องเท่าเดิม

ถ้าแบบจำลองถูก การมองรายครึ่งปีต้องให้ distribution หนึ่งปีตัวเดิม ขั้นนี้ใช้สมบัติที่ 1 เป็นใบอนุญาต: log return ของสองครึ่งปีอิสระกัน variance จึงบวกกันได้โดยไม่มีพจน์ covariance

\[ \begin{aligned} \frac{S_1}{S_0}&=\frac{S_{0.5}}{S_0}\cdot\frac{S_1}{S_{0.5}},\qquad \ln\frac{S_1}{S_0}=A+B,\\ A,\ B&\sim\mathcal N(0.034375,\ 0.03125),\\ \mathbb E[A+B]&=0.034375+0.034375=0.06875,\\ \operatorname{Var}(A+B)&=0.03125+0.03125=0.0625,\\ \operatorname{SD}(A+B)&=\sqrt{0.0625}=0.25,\\ \operatorname{SD}(A)+\operatorname{SD}(B)&=2(0.176777)\approx0.353553. \end{aligned} \]

log เปลี่ยนการคูณสองท่อนเป็นการบวก แต่ละท่อนยาวครึ่งปี จุดกลางและ variance จึงเป็นครึ่งหนึ่งของรายปี บวกกันแล้วได้ 0.06875 กับ 0.0625 เท่าเดิม โอกาส 21.93% จึงไม่ขึ้นกับว่าเรามองเป็นกี่ท่อน

บรรทัดสุดท้ายคือความผิดที่พบบ่อย: บวก SD ของสองท่อนได้ 0.3536 ไม่ใช่ 0.25 ถ้าใช้ตัวเลขนี้ โอกาสเหนือ \$130 จะกลายเป็น 29.20% สิ่งที่บวกกันได้คือ variance ไม่ใช่ SD และบวกได้ก็ต่อเมื่อสองท่อนอิสระกัน ถ้าไม่อิสระจะมีพจน์ $2\operatorname{Cov}(A,B)$ ค้างอยู่

ขั้นที่ 8 — คำตอบไวต่อ input แค่ไหน

21.93% ใช้ได้เมื่อพารามิเตอร์ถูก แต่ $\sigma$ เป็นค่าประมาณ และ $\mu$ ประมาณแทบไม่ได้ (ต้องใช้ข้อมูลหลายสิบปีกว่าจะเห็น drift ตามที่วัดไว้ใน นิยามของ GBM) ขั้นนี้วัดว่าคำตอบขยับเท่าไรเมื่อ input ผิดไปในสองแบบที่เจอบ่อย ให้ $d_\mu$ คือ $d$ ที่เผลอใช้ $\mu$ เป็นจุดกลาง และ $\nu_{30},\ d_{30}$ คือค่าที่ได้เมื่อ $\sigma=0.30$

\[ \begin{aligned} d_\mu&=\frac{0.262364-0.10}{0.25}\approx0.64946,\\ 1-\Phi(d_\mu)&\approx25.80\%,\\ \nu_{30}&=0.10-\tfrac12(0.30)^2=0.055,\\ d_{30}&=\frac{0.262364-0.055}{0.30}\approx0.69121,\\ 1-\Phi(d_{30})&\approx24.47\%. \end{aligned} \]

ใส่ $\mu$ แทน $\nu$ เป็นจุดกลางได้ 25.80% สูงเกินจริง 3.87 จุด เพราะให้เครดิตกับ drift ที่ไม่มีอยู่บนแกน log ส่วนการเปลี่ยน $\sigma$ จาก 25% เป็น 30% ดันโอกาสเป็น 24.47% ทั้งที่ drift เท่าเดิม ความผันผวนสูงขึ้นทำให้หางขวาหนาขึ้น แม้จุดกลางจะต่ำลง

ความไม่แน่นอนของ $\sigma$ เพียง 5 จุดขยับคำตอบ 2.5 จุด โอกาสที่รายงานจึงต้องมาพร้อมพารามิเตอร์ที่ใช้และช่วงที่มันขยับได้เสมอ

ขั้นที่ 9 — ปิดใต้ \$70 ไม่เท่ากับเคยแตะ \$70

คำตอบ 4.44% ที่เพิ่งได้บอกว่าราคาปลายปีต่ำกว่า \$70 บ่อยแค่ไหน แต่ stop-loss ทำงานทันทีที่ราคาแตะ \$70 ในวันไหนก็ได้ของปี เส้นทางที่ลงไปแตะแล้วกลับขึ้นมาปิดเหนือ \$70 ก็ชน stop-loss เหมือนกัน สูตรโอกาสแตะของเส้นทางต่อเนื่องมาจาก reflection principle ซึ่งเรายกมาใช้โดยไม่พิสูจน์ในหน้านี้ ให้ $L_T$ เป็นราคาต่ำสุดตลอดช่วง $0\le t\le T$ และ $b=\ln(K/S_0)\lt0$ เคยแตะ $K$ ก็คือ $L_T\le K$

\[ \begin{aligned} P(L_T\le K)&=\Phi\!\left(\frac{b-\nu T}{\sigma\sqrt T}\right)\\ &\quad+e^{2\nu b/\sigma^2}\,\Phi\!\left(\frac{b+\nu T}{\sigma\sqrt T}\right),\\ b&=\ln0.70\approx-0.356675,\\ e^{2(0.06875)(-0.356675)/0.0625}&\approx0.45626,\\ \Phi\!\left(\frac{-0.356675+0.06875}{0.25}\right)&=\Phi(-1.15170)\\ &\approx0.12472,\\ P(L_1\le70)&\approx0.04441+0.45626(0.12472)\\ &\approx10.13\%. \end{aligned} \]

พจน์แรกคือโอกาสปิดใต้ \$70 ตัวเดิม 4.44% พจน์ที่สองคือเส้นทางที่แตะแล้วกลับขึ้นมา มันใหญ่พอ ๆ กับพจน์แรก โอกาสที่ stop-loss ถูกชนในหนึ่งปีจึงราว 10.13% มากกว่าสองเท่าของ 4.44%

ตรวจความสมเหตุสมผลได้สองทาง: ถ้า $K$ เข้าใกล้ราคาวันนี้ $b$ เข้าใกล้ศูนย์ ทั้งสองพจน์รวมกันเข้าใกล้ $\Phi(-\nu\sqrt T/\sigma)+\Phi(\nu\sqrt T/\sigma)=1$ และถ้า $\nu=0$ ตัวคูณหน้าพจน์ที่สองเป็น 1 ได้ $2\Phi(b/(\sigma\sqrt T))$ ซึ่งคือรูปคลาสสิกของ reflection principle: ทุกเส้นทางที่แตะแล้วจบใต้เส้นมีคู่ที่สะท้อนกลับขึ้นไปจบเหนือเส้นพอดี

ความผิดที่ให้โอกาสผิดโดยไม่มีใครสังเกต

ใช้ $\mu$ เป็นจุดกลางใน $d$: ได้ 25.80% แทน 21.93% ตัวเลขดูสมเหตุสมผลจึงไม่มีใครสงสัย ตรวจหน่วยช่วยไม่ได้เพราะทั้งสองตัวเป็นอัตราต่อปี ต้องจำว่าบนแกน log จุดกลางคือ $\nu T$

ตั้งเป้าและจุดตัดขาดทุนห่างเท่ากันเป็นเงินแล้วคิดว่าเสี่ยงเท่ากัน: ในตัวอย่างโอกาสต่างกันเกือบห้าเท่า การเทียบกำไรที่หวังกับความเสี่ยงต้องใช้โอกาสที่คำนวณ ไม่ใช่ระยะเป็นเงิน

เชื่อว่า stop-loss ได้ราคาที่ตั้ง: ถือ 50,000 หุ้น ตั้ง stop-loss ที่ \$70 วางแผนขาดทุนไม่เกิน $50{,}000\times\$30=\$1.5$ ล้าน ถ้าราคาเปิดกระโดดจาก \$72 ลงไป \$55 ขายได้ที่ \$55 ขาดทุน \$2.25 ล้าน เกินแผน \$750,000 GBM ไม่มีวันให้คำตอบนี้เพราะสมบัติที่ 2

ใช้โอกาสปลายปีแทนโอกาสแตะ: 4.44% (ปิดใต้) กับ 10.13% (เคยแตะ) เป็นคนละคำถาม การประเมินว่า stop-loss จะถูกชนบ่อยแค่ไหนด้วยตัวเลขแรกทำให้ประเมินต่ำไปมากกว่าครึ่ง

บวก SD ข้ามช่วงเวลา: SD หนึ่งปีจากสองครึ่งปีคือ $\sqrt{0.03125+0.03125}=0.25$ ไม่ใช่ $0.177+0.177=0.354$ ความผิดนี้ทำให้โอกาสเหนือ \$130 พองเป็น 29.20%

ใช้ทำอะไรบนโต๊ะจริง

สูตร $1-\Phi(d)$ ตอบคำถามที่ลูกค้าถามบ่อยที่สุด: โอกาสที่หุ้นจะถึงเป้าในหนึ่งปีเป็นเท่าไร บทวิจัยที่ตั้งเป้า \$130 กำลังพูดถึงเหตุการณ์ที่แบบจำลองนี้ให้โอกาส 21.93% ไม่ใช่เหตุการณ์ที่ “น่าจะเกิด” และทีมบริหารความเสี่ยงใช้สูตรเดียวกันตั้งเกณฑ์เตือน เช่นระดับราคาที่มีโอกาสหลุดไม่เกิน 5%

ใน สูตร Black–Scholes พจน์ $N(d_2)$ คือ $1-\Phi(d)$ ตัวเดียวกันนี้เมื่อแทน $\mu$ ด้วยอัตราดอกเบี้ย: มันคือโอกาสภายใต้ risk-neutral measure ที่ call จะจบเหนือ strike ส่วนสมบัติที่ 2 บอกว่าต้องเติมอะไรเอง: ตัวเลขทุกตัวในหน้านี้ไม่รวม gap จากข่าว เงินปันผล และต้นทุนการซื้อขาย ก่อนอนุมัติวงเงินจึงต้องทำ gap stress แยกต่างหาก และรายงานโอกาสพร้อมป้ายกำกับเสมอว่าเป็นช่วงหนึ่งปี $\mu=10\%$, $\sigma=25\%$ ภายใต้ GBM ที่ไม่มีการกระโดด

โจทย์ตรวจความเข้าใจ

1. หุ้นสมมติ \$50 มี $\mu=8\%$ และ $\sigma=35\%$ ต่อปี ในหกเดือน โอกาสปิดเหนือ \$60 และใต้ \$40 เป็นเท่าไร?

เฉลย

$\nu T=(0.08-0.06125)(0.5)=0.009375$ และ $\sigma\sqrt T=0.35\sqrt{0.5}\approx0.247487$ เหนือ \$60: $d=(\ln1.2-0.009375)/0.247487=(0.182322-0.009375)/0.247487\approx0.69881$ โอกาส $1-\Phi(0.69881)\approx24.23\%$ ใต้ \$40: $d=(-0.223144-0.009375)/0.247487\approx-0.93952$ โอกาส $\Phi(-0.93952)\approx17.37\%$ ห่าง \$10 เท่ากันแต่โอกาสต่างกันราว 7 จุด

2. หุ้นในหน้านี้ถ้าตั้งเกณฑ์ล่างที่ $100/1.3\approx\$76.92$ ซึ่งสมมาตรกับ \$130 บนแกน log โอกาสปิดใต้เกณฑ์นี้เท่าไร?

เฉลย

$\ln(1/1.3)=-0.262364$ จึงได้ $d=(-0.262364-0.06875)/0.25\approx-1.32446$ และโอกาส $\Phi(-1.32446)\approx9.27\%$ ยังไม่ถึงครึ่งหนึ่งของ 21.93% ฝั่งขึ้น ความต่างที่เหลือนี้มาจาก log drift 0.06875 ที่ดันจุดกลางไปทางขวา

3. ราคาเท่าไรที่หุ้นในหน้านี้มีโอกาสปิดเหนือเพียง 10% ในหนึ่งปี?

เฉลย

ต้องการ $1-\Phi(d)=0.10$ คือ $d=z_{0.90}\approx1.281552$ ย้อนสูตรได้ $\ln(K/100)=0.06875+1.281552(0.25)=0.389138$ และ $K=100e^{0.389138}\approx\$147.57$

// Standard Normal CDF: Taylor series near the centre, continued fraction in the tails.
function normCdf(x) {
  const ax = Math.abs(x), density = Math.exp(-ax * ax / 2) / Math.sqrt(2 * Math.PI);
  if (ax < 3) {
    let term = ax, sum = ax;
    for (let k = 1; term > 1e-17 * sum; k++) { term *= ax * ax / (2 * k + 1); sum += term; }
    return x < 0 ? 0.5 - density * sum : 0.5 + density * sum;
  }
  let f = 0;
  for (let k = 300; k >= 1; k--) f = k / (ax + f);
  const tail = density / (ax + f);
  return x < 0 ? tail : 1 - tail;
}
function normInv(p) {
  let lo = -40, hi = 40;
  for (let i = 0; i < 200; i++) { const mid = (lo + hi) / 2; if (normCdf(mid) < p) lo = mid; else hi = mid; }
  return (lo + hi) / 2;
}
// ln(S_T / S_0) ~ N(m, sd^2) with m = (mu - sigma^2/2) T and sd = sigma sqrt(T).
function logLaw(mu, sigma, T) {
  if (!(sigma > 0 && T > 0)) throw new RangeError('Volatility and horizon must be positive');
  return {m: (mu - sigma * sigma / 2) * T, sd: sigma * Math.sqrt(T)};
}
// d = standardized distance from the centre of the log law to ln(K / S0).
function threshold(S0, K, mu, sigma, T) {
  if (!(S0 > 0 && K > 0)) throw new RangeError('Prices must be positive');
  const {m, sd} = logLaw(mu, sigma, T);
  return (Math.log(K / S0) - m) / sd;
}
const probAbove = (S0, K, mu, sigma, T) => 1 - normCdf(threshold(S0, K, mu, sigma, T));
const probBelow = (S0, K, mu, sigma, T) => normCdf(threshold(S0, K, mu, sigma, T));
// SD of the dollar change given S, from E[R] = M_X(1) and E[R^2] = M_X(2).
function dollarChangeSD(S, mu, sigma, s) {
  const {m, sd} = logLaw(mu, sigma, s), v = sd * sd;
  return S * Math.sqrt(Math.exp(2 * m + 2 * v) - Math.exp(2 * m + v));
}
// Chance that a continuous path touches K below S0 before T (reflection principle).
function probTouchBelow(S0, K, mu, sigma, T) {
  if (!(K < S0)) throw new RangeError('Barrier must be below the start price');
  const {m, sd} = logLaw(mu, sigma, T), b = Math.log(K / S0), nu = m / T;
  return normCdf((b - m) / sd) + Math.exp(2 * nu * b / (sigma * sigma)) * normCdf((b + m) / sd);
}
const law = logLaw(0.10, 0.25, 1), half = logLaw(0.10, 0.25, 0.5);
console.log(JSON.stringify({

  up: probAbove(100, 130, 0.10, 0.25, 1), down: probBelow(100, 70, 0.10, 0.25, 1),
  median: 100 * Math.exp(law.m), above100: probAbove(100, 100, 0.10, 0.25, 1),
  dollarSD: [dollarChangeSD(100, 0.10, 0.25, 1), dollarChangeSD(20, 0.10, 0.25, 1)],
  halves: {sd: Math.sqrt(2 * half.sd ** 2), wrongSD: 2 * half.sd,
    upWithWrongSD: 1 - normCdf((Math.log(1.3) - law.m) / (2 * half.sd))},
  wrongMu: 1 - normCdf((Math.log(1.3) - 0.10) / 0.25),
  sigma30: probAbove(100, 130, 0.10, 0.30, 1),
  touch70: probTouchBelow(100, 70, 0.10, 0.25, 1),
  exercises: {

    logSymmetric: probBelow(100, 100 / 1.3, 0.10, 0.25, 1),

สิ่งที่ควรตอบได้หลังอ่าน

  • ตัวคูณ $S_{t+s}/S_t$ อิสระจากอดีตและไม่ขึ้นกับระดับราคา แต่ส่วนต่างเป็นดอลลาร์มี SD เป็นสัดส่วนกับ $S_t$: \$28.07 ที่ราคา \$100 และ \$5.61 ที่ราคา \$20
  • เส้นทางต่อเนื่องจึงไม่มีการกระโดด ซึ่งเป็นข้อที่ผิดจากตลาดจริงมากที่สุดสำหรับ stop-loss และ hedge
  • log ของราคาเป็น Normal ราคาเป็น lognormal และ $P(S_T\gt K)=1-\Phi\big((\ln(K/S_0)-\nu T)/(\sigma\sqrt T)\big)$ โดยจุดกลางคือ $\nu T$ ไม่ใช่ $\mu T$
  • เป้า \$130 กับ \$70 ที่ห่างเท่ากันเป็นเงินมีโอกาส 21.93% กับ 4.44% และโอกาสแตะ \$70 ระหว่างปีคือ 10.13%
  • variance ของช่วงที่อิสระกันบวกกันได้ SD บวกกันไม่ได้

หน้าถัดไป ทำไม GBM จึงเป็นแบบจำลองราคาหุ้นที่สมเหตุสมผล จะชั่งน้ำหนักอย่างตรงไปตรงมาว่าสมมติฐานทั้งหมดนี้ใช้กับหุ้นได้แค่ไหน ด้วยตัวเลขจากทั้งแบบจำลองและข้อมูลจริง
