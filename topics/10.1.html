10.1 Definition of Geometric Brownian Motion (GBM)

เอาส่วนสุ่มของ Brownian motion ไปไว้บนเลขชี้กำลังของ $e$ ราคาจึงไม่มีวันติดลบ และทุกการขยับเป็นเปอร์เซ็นต์ของราคาวันนั้น

ทีมบริหารความเสี่ยงของธนาคารอยากรู้ว่า ราคาหุ้นตัวหนึ่งอาจไปอยู่ตรงไหนได้บ้างในอีกห้าปี วิธีที่ใช้กันคือให้คอมพิวเตอร์สุ่มเส้นทางราคาขึ้นมาเป็นหมื่นเส้น แต่ละเส้นเรียกว่าหนึ่ง scenario แล้วนับว่าผลแบบไหนเกิดบ่อยแค่ไหน ก่อนจะสุ่มได้ ทีมต้องเลือกกฎที่บอกว่าราคาขยับอย่างไร

ของที่รู้ (ตัวเลขสมมติ):

  • ราคาหุ้นวันนี้ $S_0=\$100$
  • ความผันผวนต่อปี 28% คือในหนึ่งปีราคาแกว่งขึ้นลงได้ราว 28% ของราคา วัดเป็น SD (standard deviation) คิดเป็นดอลลาร์ได้ว่า การขยับในหนึ่งปีมี SD $b=0.28\times100=\$28$
  • ระยะที่จำลอง $T=5$ ปี

คนหนึ่งเสนอกฎที่ง่ายที่สุด ให้เอา standard Brownian motion $W_t$ มาใช้ตรง ๆ $W_t$ คือเส้นสุ่มที่เริ่มที่ศูนย์ และหลัง $t$ ปีเป็น Normal ค่าเฉลี่ยศูนย์ variance $t$ กฎนี้เอา $W_T$ คูณ $b$ แล้วบวกเข้ากับราคาวันนี้ โดยไม่ใส่แนวโน้มขึ้นหรือลง (ไม่มี drift)

\[S_T=S_0+bW_T=100+28\,W_T\]

ใน scenario ทั้งหมด จะมีกี่เปอร์เซ็นต์ที่ราคาปลายปีที่ห้าติดลบ?

ลองตอบก่อนเปิดเฉลย

ราว 5.51% ขั้นที่ 1 ด้านล่างคำนวณให้ดูทีละขั้น ใจความคือ ราคาปลายปีที่ห้าเป็น Normal ค่าเฉลี่ย \$100 และ SD $b\sqrt T=28\sqrt5\approx\$62.61$ ราคาศูนย์อยู่ต่ำกว่าค่าเฉลี่ย $100/62.61\approx1.597$ SD จึงได้ $\Phi(-1.597)\approx5.51\%$ โดย $\Phi(x)$ คือโอกาสที่ standard Normal มีค่าต่ำกว่า $x$

ตัวเลขนี้ขัดกับโลกจริง เพราะราคาหุ้นติดลบไม่ได้ ผู้ถือหุ้นเสียได้ไม่เกินเงินที่ลงไป กฎนี้ยังมีปัญหาข้อที่สอง การขยับรายวันมี SD เป็นดอลลาร์คงที่ $b\sqrt{1/252}=28/\sqrt{252}\approx\$1.76$ ไม่ว่าราคาจะอยู่ตรงไหน (หนึ่งวันทำการคือ $1/252$ ปี และ SD ของ $W$ ในช่วง $\Delta t$ ปีคือ $\sqrt{\Delta t}$) ถ้าราคาร่วงเหลือ \$20 การขยับ \$1.76 เท่าเดิมคิดเป็น $1.76/20=8.8\%$ ต่อวัน หุ้นแกว่งแรงขึ้นห้าเท่าเพียงเพราะราคาลด

หน้านี้สร้างแบบจำลองที่แก้ทั้งสองข้อ ราคาไม่ติดลบเลยในทุก scenario และทุกการขยับเป็นสัดส่วนของราคาวันนั้น

ภาพรวมก่อนลงสูตร

Brownian motion $W_t$ มีสามสมบัติที่ใช้งานง่าย (สามสมบัติของ Brownian motion):

  • การขยับในช่วงเวลาที่ไม่ทับกันเป็นอิสระต่อกัน
  • การขยับในช่วงยาว $\Delta t$ ปีเป็น Normal ค่าเฉลี่ยศูนย์ variance $\Delta t$
  • เส้นทางต่อเนื่อง ไม่กระโดด

แต่คำถามเปิดเรื่องแสดงว่า ถ้าใช้ $W_t$ เป็นราคาตรง ๆ จะเจอสองปัญหา ข้อแรก ราคาติดลบได้ ข้อสอง การขยับเป็นดอลลาร์คงที่ ไม่ว่าราคาจะอยู่ที่ \$200 หรือ \$20

ทางแก้ใช้ $W_t$ ตัวเดิม แค่ย้ายที่ เราให้ log ของราคา เดินแบบ Brownian motion แล้วแปลงกลับด้วย exponential ราคาจึงอยู่ในรูป $S_t=S_0e^{X_t}$ โดย $X_t$ เป็นตัวสุ่ม ได้ประโยชน์สองข้อ:

  • $e$ ยกกำลังอะไรก็เป็นบวก ราคาจึงบวกเสมอ
  • $e^{X+0.1}=e^X\times e^{0.1}$ ถ้า $X_t$ ขยับขึ้น 0.1 ราคาจะถูกคูณด้วย $e^{0.1}\approx1.105$ คือขึ้นราว 10.5% เท่ากันทุกครั้ง ไม่ว่าราคาจะอยู่ระดับไหน

แบบจำลองนี้ชื่อ Geometric Brownian Motion (GBM) มันเป็นสมมติฐานของสูตร Black–Scholes ที่ใช้ตั้งราคา option (สัญญาที่ให้สิทธิ์ซื้อหรือขายหุ้นในราคาที่ตกลงไว้ล่วงหน้า)

ลำดับของหน้านี้คือ วัดว่าแบบบวกพังแค่ไหน ดูว่าเมื่อไม่มีความสุ่ม GBM คือดอกเบี้ยทบต้นต่อเนื่อง เขียนนิยาม สร้างสูตรเดินราคาไปข้างหน้าหนึ่งก้าว แล้วอธิบายว่าทำไมเลขชี้กำลังต้องมี $-\sigma^2/2$ จากนั้นเดินราคาสามวันด้วยมือ และอ่านช่วงของราคาหนึ่งปี หน้านี้ปิดด้วยคำถามที่โต๊ะเทรด (ทีมที่ซื้อขายหุ้นจริง) ถามบ่อย ต้องใช้ข้อมูลกี่ปีจึงจะเห็นว่าหุ้นมีแนวโน้มขึ้นจริง

ตลอดหน้าใช้หุ้นสมมติตัวเดียว:

  • ราคาวันนี้ $S_0=\$100$
  • drift $\mu=12\%$ ต่อปี คืออัตราที่ราคาโตโดยเฉลี่ยในหนึ่งปี
  • ความผันผวน $\sigma=28\%$ ต่อปี คือขนาดที่ราคาแกว่งขึ้นลงในหนึ่งปี วัดเป็น SD ของผลตอบแทน
ศัพท์ที่ใช้ในหัวข้อนี้
Scenario
เส้นทางราคาหนึ่งเส้นที่คอมพิวเตอร์สุ่มขึ้นมา การจำลองสร้างหลายพันเส้น แล้วนับว่าผลแบบไหนเกิดบ่อยแค่ไหน
Geometric Brownian Motion (GBM)
แบบจำลองราคาที่ให้ log ของราคาเดินแบบ Brownian motion ที่มี drift แล้วแปลงกลับด้วย exponential ราคาจึงบวกเสมอ และขยับเป็นเปอร์เซ็นต์ของราคาตัวเอง เป็นแบบจำลองตั้งต้นของราคาหุ้น ทั้งในการจำลองและการตั้งราคา option
Drift $\mu$
อัตราที่ราคาโตโดยเฉลี่ยต่อปี พูดให้ละเอียดคือ ในก้าวสั้น ๆ ยาว $\Delta t$ ปี เปอร์เซ็นต์ที่ราคาขยับมีค่าเฉลี่ย $\mu\Delta t$ มันบอกว่าราคา “โดยเฉลี่ย” ไปทางไหน แต่เส้นทางที่อยู่ตรงกลาง (median) โตช้ากว่านี้
Log drift $\nu$
อัตราต่อปีที่ log ของราคาเดินไปโดยเฉลี่ย เท่ากับ $\mu-\sigma^2/2$ และเป็นตัวกำหนด median ของราคา เราตั้งชื่อแยกไว้ไม่ให้ปนกับ $\mu$ หุ้นในหน้านี้มี $\mu=12\%$ แต่ $\nu=0.12-0.28^2/2=0.0808$ คือ 8.08% ต่อปี
ความผันผวน (volatility) $\sigma$
SD ของ log return ในหนึ่งปี ช่วงยาว $\Delta t$ ปีมี SD $\sigma\sqrt{\Delta t}$ เราใช้มันปรับขนาดของส่วนสุ่มให้เข้ากับความยาวก้าว
Log return
$\ln(S_{t+\Delta t}/S_t)$ ข้อดีคือบวกกันข้ามช่วงเวลาได้ ต่างจาก simple return $S_{t+\Delta t}/S_t-1$ (เปอร์เซ็นต์ที่ราคาเปลี่ยน) ที่ต้องเอา 1 บวก simple return ของแต่ละช่วงมาคูณกัน เราใช้ log return ทุกครั้งที่ต้องคำนวณโอกาสของราคา
Lognormal
distribution ของตัวแปรบวกที่ log ของมันเป็น Normal ราคาของ GBM ณ เวลาหนึ่งเป็น lognormal ส่วน log ของราคาเป็น Normal
Median และ quantile
quantile $q_p$ คือค่าที่ผลลัพธ์มีโอกาส $p$ จะออกมาต่ำกว่า เช่น 5% ของ scenario จบต่ำกว่า $q_{0.05}$ ส่วน median คือ $q_{0.50}$ ครึ่งหนึ่งของ scenario จบต่ำกว่า อีกครึ่งจบสูงกว่า
Exact update
สูตรเดินราคาไปข้างหน้าหนึ่งก้าวที่ให้ distribution ตรงกับแบบจำลองเป๊ะ ไม่ว่าก้าวจะยาวแค่ไหน ใช้แค่ราคาล่าสุดกับเลขสุ่มหนึ่งตัว ต่างจาก Euler step ที่เป็นการประมาณแบบเส้นตรงและแม่นเฉพาะตอนก้าวสั้น

ขั้นที่ 1 — วัดก่อนว่าแบบจำลองแบบบวกพังแค่ไหน

ก่อนสร้างของใหม่ เราวัดก่อนว่าของเดิมพังแค่ไหน แบบจำลองในคำถามเปิดเรื่องคือ $S_T=S_0+bW_T$ โดย

  • $S_0=\$100$ คือราคาวันนี้
  • $b=\$28$ ต่อรากที่สองของปี คือความผันผวนที่วัดเป็นดอลลาร์
  • $T=5$ ปี คือระยะที่จำลอง

เพราะ standard Brownian motion ที่เวลา $T$ เป็น Normal ค่าเฉลี่ยศูนย์ variance $T$ ราคา $S_T$ ซึ่งเป็นค่าคงที่บวกกับ $b$ คูณตัวแปร Normal จึงเป็น Normal ด้วย เราจึงถามได้ตรง ๆ ว่าโอกาสที่ $S_T$ ต่ำกว่าศูนย์เป็นเท่าไร โดยใช้ $\Phi$ ซึ่งให้โอกาสที่ standard Normal มีค่าต่ำกว่าตัวเลขที่ใส่

\[ \begin{aligned} S_T&=S_0+bW_T,\qquad W_T\sim\mathcal N(0,T),\\ P(S_T\lt0)&=P\big(W_T\lt-S_0/b\big)\\ &=\Phi\!\left(\frac{-S_0}{b\sqrt T}\right),\\ b\sqrt T&=28\sqrt5\approx62.61,\\ P(S_5\lt0)&=\Phi(-100/62.61)\\ &=\Phi(-1.597)\approx5.51\%. \end{aligned} \]

จังหวะสำคัญคือการหารด้วย $b\sqrt T$ มันเปลี่ยนคำถามเรื่อง $W_T$ ให้เป็นคำถามเรื่อง standard Normal ทำได้เพราะ SD ของ $bW_T$ คือ $b\sqrt T$ หารด้วย SD ของตัวเองจึงได้ตัวแปรที่ SD เท่ากับหนึ่ง ผล 5.51% ไม่ใช่โชคร้ายของการสุ่ม มันมาจากรูปร่างของ Normal เอง หางซ้ายของ Normal ยาวไม่สิ้นสุด และยิ่งถือนาน SD ยิ่งโตตาม $\sqrt T$ โอกาสติดลบจึงยิ่งมาก

ปัญหาที่สองซ่อนอยู่ใน $b$ เพราะ $b$ เป็นดอลลาร์คงที่ หนึ่งวันทำการคือ $\Delta t=1/252$ ปี (ขั้นที่ 6 นับที่มาของ 252 ให้ดู) การขยับรายวันจึงมี SD $b\sqrt{\Delta t}=28/\sqrt{252}\approx\$1.76$ ตอนราคา \$100 ตัวเลขนี้คือ $1.76/100=1.76\%$ ต่อวัน แต่ถ้าหุ้นร่วงเหลือ \$20 การขยับ \$1.76 เท่าเดิมคิดเป็น $1.76/20=8.8\%$ ต่อวัน หุ้นจริงไม่ได้แกว่งแรงขึ้นห้าเท่าเพียงเพราะราคาลดลง แบบจำลองที่ดีจึงต้องให้การขยับเป็นเปอร์เซ็นต์ของราคา

ขั้นที่ 2 — ถ้าไม่มีความผันผวน: ดอกเบี้ยทบต้นต่อเนื่อง

ก่อนใส่ความสุ่ม ลองดูกรณีง่ายสุดก่อน ราคาที่โต 12% ต่อปีแน่นอน ไม่แกว่งเลย เหมือนเงินฝากที่ได้ดอกเบี้ย แต่ “โต 12% ต่อปี” ยังพูดไม่ครบ เพราะผลขึ้นกับว่าคิดดอกเบี้ยทบต้นบ่อยแค่ไหน ถ้าทบ $n$ ครั้งต่อปี แต่ละครั้งได้ดอกเบี้ย $0.12/n$ ของเงินที่มีอยู่ เงิน \$1 หลังหนึ่งปีจะเป็น $(1+0.12/n)^n$ ลองดูว่าเกิดอะไรขึ้นเมื่อ $n$ โตขึ้นเรื่อย ๆ

\[ \begin{aligned} n=1:&\quad(1.12)^1=1.120000,\\ n=12:&\quad(1.01)^{12}\approx1.126825,\\ n=365:&\quad(1+0.12/365)^{365}\approx1.127475,\\ n\to\infty:&\quad\Big(1+\frac{0.12}{n}\Big)^n\to e^{0.12}\\ &\quad\approx1.127497,\\ \frac{dS}{dt}&=\mu S,\\ S_t&=S_0e^{\mu t}. \end{aligned} \]

ยิ่งทบถี่ เงินยิ่งโต แต่โตเพิ่มน้อยลงเรื่อย ๆ จนชนเพดาน ทบรายวันกับทบต่อเนื่องต่างกันแค่ $1.127497-1.127475=0.000022$ ต่อดอลลาร์ เพดานนั้นคือ $e^{0.12}$ เพราะ $(1+x/n)^n\to e^x$ เมื่อ $n\to\infty$ ซึ่งเป็นนิยามหนึ่งของ $e$

ทำไมการทบต่อเนื่องจึงเขียนเป็นสมการ $dS/dt=\mu S$ ได้ เพราะในช่วงสั้น ๆ $dt$ ราคาได้ดอกเบี้ยเพิ่ม $\mu S\,dt$ อัตราโตจึงเป็นสัดส่วน $\mu$ ของราคาเอง คำตอบของสมการนี้คือ $S_t=S_0e^{\mu t}$ ตรวจได้ด้วยการหาอนุพันธ์ $\frac{d}{dt}S_0e^{\mu t}=\mu S_0e^{\mu t}=\mu S$ นี่คือที่มาของฐาน $e$ และ $\mu$ ในเลขชี้กำลังอ่านได้ตรง ๆ ว่าเป็นอัตราทบต้นต่อเนื่องต่อปี

GBM คือสมการเดียวกันที่เติมความสุ่มเข้าไปในเลขชี้กำลัง ถ้าตั้ง $\sigma=0$ ในนิยามของขั้นถัดไป จะได้ $S_0e^{\mu t}$ คืนมาพอดี ความสุ่มทำให้แต่ละเส้นทางแกว่งรอบเส้นทบต้นนี้ และแกว่งเป็นสัดส่วนของราคา เหมือนที่ดอกเบี้ยคิดเป็นสัดส่วนของเงินต้น

ขั้นที่ 3 — นิยาม: ให้ log ของราคาเป็น Brownian motion

ตอนนี้ใส่ความสุ่มกลับเข้าไป ทางแก้ปัญหาทั้งสองข้อคือ ไม่ให้ราคาเป็น Brownian motion แต่ให้ log ของราคา เป็น Brownian motion ที่มี drift เราเรียก log ของราคาเทียบกับราคาเริ่มต้นว่า $X_t=\ln(S_t/S_0)$ มันมีสองส่วน:

  • ส่วนที่เดินสม่ำเสมอ $\nu t$ โดย $\nu$ คืออัตราต่อปีที่ $X_t$ เดินไปโดยเฉลี่ย (log drift)
  • ส่วนที่สุ่ม $\sigma W_t$ โดย $\sigma$ คือความผันผวนต่อปี

แถวแรกของสูตรบอกด้วยว่า $\nu=\mu-\sigma^2/2$ ไม่ใช่ $\mu$ ตอนนี้ให้รับไว้ก่อน ขั้นที่ 5 จะอธิบายว่าทำไม

\[ \begin{aligned} X_t&:=\nu t+\sigma W_t,\qquad \nu:=\mu-\tfrac12\sigma^2,\\ S_t&:=S_0e^{X_t}=S_0e^{\nu t+\sigma W_t},\\ S_t&\gt0\quad(S_0\gt0),\\ \ln\frac{S_t}{S_0}&=X_t\sim\mathcal N\big(\nu t,\ \sigma^2t\big). \end{aligned} \]

exponential รับค่าได้ทุกค่า ติดลบเท่าไรก็ได้ แต่ผลเป็นบวกเสมอ ราคาจึงเข้าใกล้ศูนย์ได้แต่ไม่มีวันแตะ และเพราะ $e^{X+h}=e^X\times e^h$ การที่ $X_t$ ขยับไป $h$ คือการคูณราคาด้วย $e^h$ เท่ากัน ไม่ว่าราคาจะอยู่ระดับไหน ปัญหาทั้งสองข้อของแบบบวก (ราคาติดลบ และการขยับเป็นดอลลาร์คงที่) จึงหายไปพร้อมกัน

แถวสุดท้ายคือสิ่งที่ต้องจำให้แม่น ตัวที่เป็น Normal คือ log ของราคา ส่วนตัวราคาเป็น lognormal ค่าเฉลี่ย $\nu t$ มาจากส่วนที่เดินสม่ำเสมอ ส่วน variance มาจากส่วนที่สุ่ม $\operatorname{Var}(\sigma W_t)=\sigma^2\operatorname{Var}(W_t)=\sigma^2t$ ดังนั้นทุกครั้งที่ต้องคำนวณโอกาสของราคา เราย้ายคำถามไปถามบนแกน log ก่อน

ขั้นที่ 4 — สูตรเดินหน้าหนึ่งก้าวที่ตรงเป๊ะ

นิยามในขั้นที่ 3 ให้ราคาเมื่อรู้ $W_t$ แต่โปรแกรมจำลองเดินทีละวัน ในมือมีแค่ราคาวันนี้ $S_t$ กับเลขสุ่มตัวใหม่ เราจึงต้องการสูตรที่ให้ราคาก้าวถัดไป $S_{t+\Delta t}$ จาก $S_t$ โดยตรง วิธีคือแยกเลขชี้กำลังที่เวลา $t+\Delta t$ ออกเป็นสองส่วน ส่วนที่เกิดไปแล้ว (ถึงเวลา $t$) กับส่วนที่ยังไม่เกิด (จาก $t$ ถึง $t+\Delta t$) $Z$ ในสูตรคือเลขสุ่มจาก standard Normal หนึ่งตัวต่อหนึ่งก้าว

\[ \begin{aligned} S_{t+\Delta t}&=S_0e^{\nu(t+\Delta t)+\sigma W_{t+\Delta t}}\\ &=S_0e^{\nu t+\sigma W_t}\\ &\quad\times e^{\nu\Delta t+\sigma(W_{t+\Delta t}-W_t)}\\ &=S_t\,e^{\nu\Delta t+\sigma(W_{t+\Delta t}-W_t)},\\ W_{t+\Delta t}-W_t&=\sqrt{\Delta t}\,Z,\qquad Z\sim\mathcal N(0,1),\\ S_{t+\Delta t}&=S_t\,e^{\nu\Delta t+\sigma\sqrt{\Delta t}\,Z}. \end{aligned} \]

การแยกใช้แค่ $e^{a+b}=e^a\times e^b$ ก้อนแรก $S_0e^{\nu t+\sigma W_t}$ คือ $S_t$ ตามนิยามพอดี จึงแทนด้วย $S_t$ ได้ ก้อนที่สองขึ้นกับการขยับของ $W$ จาก $t$ ถึง $t+\Delta t$ ซึ่งยังไม่เกิด ตาม สามสมบัติของ Brownian motion การขยับนี้อิสระจากอดีต และเป็น Normal ค่าเฉลี่ยศูนย์ variance $\Delta t$ มันจึงมี SD $\sqrt{\Delta t}$ และเขียนเป็น $\sqrt{\Delta t}\,Z$ ได้

สูตรนี้ตรงเป๊ะไม่ว่า $\Delta t$ ยาวแค่ไหน เดินรายวัน 252 ก้าว หรือกระโดดทีเดียวหนึ่งปี ก็ได้ distribution ปลายทางเดียวกัน เพราะผลรวมของ Normal ที่อิสระกันยังเป็น Normal และค่าเฉลี่ยกับ variance บวกกันได้ เลขชี้กำลังรวม 252 ก้าวมีค่าเฉลี่ย $252\times\nu/252=\nu$ และ variance $252\times\sigma^2/252=\sigma^2$ เท่ากับก้าวเดียวหนึ่งปีพอดี ข้อดีอีกข้อคือแต่ละก้าวใช้แค่ราคาล่าสุด ไม่ต้องเก็บประวัติ สมบัตินี้ชื่อ Markov และ GBM รับมาจาก Brownian motion

ขั้นที่ 5 — ทำไมเลขชี้กำลังต้องใช้ μ − σ²/2

คำถามที่ค้างไว้จากขั้นที่ 3 คือ ถ้าอยากให้ราคาโตเฉลี่ย $\mu$ ต่อปี ทำไมไม่ใส่ $\mu$ ลงในเลขชี้กำลังตรง ๆ ลองตัวอย่างเล็ก ๆ ก่อน หุ้น \$100 วันแรกขึ้น 1% วันที่สองลง 1% เปอร์เซ็นต์เฉลี่ยของสองวันคือ $(1\%-1\%)/2=0$ แต่ราคาจบที่ $100\times1.01\times0.99=\$99.99$ ต่ำกว่าเดิม ถ้าดูเป็น log return ค่าเฉลี่ยไม่เป็นศูนย์:

\[ \begin{aligned} \ln1.01+\ln0.99&\approx-0.0001,\\ \tfrac12(-0.0001)&=-0.00005\\ &=-\tfrac12(0.01)^2. \end{aligned} \]

ค่าเฉลี่ยของ log ต่ำกว่าค่าเฉลี่ยของเปอร์เซ็นต์อยู่ครึ่งหนึ่งของกำลังสองของการขยับ ขั้นนี้แสดงว่าเรื่องเดียวกันเกิดกับ GBM ทุกก้าว เราเรียกเลขชี้กำลังของหนึ่งก้าวว่า $Y$ และเรียกเปอร์เซ็นต์ที่ราคาขยับในก้าวนั้น (simple return) ว่า $R$ แล้วกระจาย $e^Y$ เป็น Taylor series เพื่อหาค่าเฉลี่ยของ $R$

\[ \begin{aligned} Y&:=\nu\Delta t+\sigma\sqrt{\Delta t}\,Z,\\ R&:=\frac{S_{t+\Delta t}}{S_t}-1=e^{Y}-1\\ &=Y+\tfrac12Y^2+\tfrac16Y^3+\cdots,\\ \mathbb E[Y]&=\nu\Delta t,\\ \mathbb E[Y^2]&=\nu^2\Delta t^2+\sigma^2\Delta t\,\mathbb E[Z^2]\\ &=\sigma^2\Delta t+\nu^2\Delta t^2,\\ \mathbb E[R]&\approx\nu\Delta t+\tfrac12\sigma^2\Delta t\\ &=\mu\Delta t. \end{aligned} \]

จังหวะที่คนสะดุดคือ $\mathbb E[Y^2]$ ยกกำลังสอง $Y$ แล้วได้สามพจน์ พจน์ไขว้ $2\nu\Delta t\,\sigma\sqrt{\Delta t}\,Z$ หายไปเพราะ $\mathbb E[Z]=0$ แต่ส่วนสุ่มยกกำลังสองได้ $\sigma^2\Delta t\,Z^2$ ซึ่งมีค่าเฉลี่ย $\sigma^2\Delta t$ เพราะ $\mathbb E[Z^2]=1$ พจน์นี้มีขนาด $\Delta t$ ไม่ใช่ $\Delta t^2$ เพราะการขยับสุ่มมีขนาด $\sqrt{\Delta t}$ ยกกำลังสองจึงได้ $\Delta t$ มันจึงไม่หายไปเมื่อก้าวสั้นลง ต่างจากแคลคูลัสปกติที่พจน์กำลังสองเล็กจนตัดทิ้งได้ เรื่องนี้ชื่อ quadratic variation คือผลรวมกำลังสองของการขยับของ $W$ เท่ากับเวลาที่ผ่านไป

ตอนสรุป $\mathbb E[R]$ เราตัดพจน์ $\tfrac12\nu^2\Delta t^2$ กับค่าเฉลี่ยของ $Y^3$ ขึ้นไปทิ้ง เพราะพจน์เหล่านี้เล็กระดับ $\Delta t^2$ ที่เหลือคือ $\mathbb E[R]\approx(\nu+\tfrac12\sigma^2)\Delta t$ ถ้าต้องการให้ค่านี้เท่ากับ $\mu\Delta t$ ต้องตั้ง $\nu=\mu-\tfrac12\sigma^2$ ซึ่งคือนิยามในขั้นที่ 3 แถวสุดท้ายจึงได้ $\mu\Delta t$ พอดี

ผลคือ เลขชี้กำลังต้องมีค่าเฉลี่ยน้อยกว่า $\mu\Delta t$ อยู่ $\tfrac12\sigma^2\Delta t$ เหตุผลในภาพคือ $e^Y$ เป็นเส้นโค้งหงาย ขาขึ้นได้มากกว่าขาลงเสีย ตัว $-\sigma^2/2$ จึงไม่ใช่ค่าปรับให้สูตรสวย แต่เป็นการหักส่วนที่ความโค้งดันค่าเฉลี่ยขึ้นไป

ในหนังสือและบทความอื่น GBM มักเขียนสั้น ๆ เป็น SDE (stochastic differential equation คือสมการอนุพันธ์ที่มีพจน์สุ่ม):

\[dS_t=\mu S_t\,dt+\sigma S_t\,dW_t\]

สมการนี้พูดเรื่องเดียวกับที่เราเพิ่งทำ ในก้าวสั้น ๆ $dt$ เปอร์เซ็นต์ที่ราคาขยับ $dS_t/S_t$ มีค่าเฉลี่ย $\mu\,dt$ และ SD $\sigma\sqrt{dt}$ ถ้าตั้ง $\sigma=0$ จะเหลือสมการทบต้นต่อเนื่อง $dS/dt=\mu S$ ของขั้นที่ 2 ตอนสร้าง Itô's lemma เราจะพิสูจน์ว่าสมการนี้กับนิยาม $S_t=S_0e^{\nu t+\sigma W_t}$ คือ process เดียวกัน และหน้า ราคาคาดหวังในอนาคต จะพิสูจน์ว่าราคาเฉลี่ยเท่ากับ $S_0e^{\mu T}$ พอดีในทุกระยะเวลา ไม่ใช่แค่โดยประมาณ

ขั้นที่ 6 — แปลงพารามิเตอร์รายปีเป็นตัวเลขรายวัน

โจทย์ให้อะไรมาบ้าง: โปรแกรมจำลองจะเดินราคาทีละวัน จึงต้องแปลงตัวเลขรายปีเป็นรายวันก่อน ของที่ใช้:

  • ราคาวันนี้ $S_0=\$100$
  • drift $\mu=0.12$ ต่อปี และความผันผวน $\sigma=0.28$ ต่อปี (ตัวเลขสมมติ)
  • ก้าวละหนึ่งวันทำการ $\Delta t=1/252$ ปี

252 คือจำนวนวันที่ตลาดหุ้นสหรัฐฯ เปิดในหนึ่งปี นับจากปี 2024 ได้ดังนี้ ปีนั้นมี 366 วัน หักเสาร์อาทิตย์ 104 วัน แล้วหักวันหยุดของตลาดหุ้นนิวยอร์ก (NYSE) อีก 10 วัน เช่น วันขึ้นปีใหม่ วันขอบคุณพระเจ้า และวันคริสต์มาส:

\[ \begin{aligned} 366-104&=262,\\ 262-10&=252. \end{aligned} \]

ต่อไปแปลงพารามิเตอร์ทีละตัว ส่วนที่เดินสม่ำเสมอรายวันคือ $\nu\Delta t$ ขนาดของส่วนสุ่มรายวันคือ $\sigma\sqrt{\Delta t}$ แถวที่ห้าเป็นตัวตรวจผลของขั้นที่ 5

\[ \begin{aligned} \sigma^2&=0.28^2=0.0784,\\ \nu&=0.12-0.0392=0.0808,\\ \nu\Delta t&=0.0808/252\approx0.000320635,\\ \tfrac12\sigma^2\Delta t&=0.0392/252\approx0.000155556,\\ \nu\Delta t+\tfrac12\sigma^2\Delta t&=0.12/252\approx0.000476190,\\ \sigma\sqrt{\Delta t}&=0.28/\sqrt{252}\approx0.0176383. \end{aligned} \]

คำตอบ: ตัวคูณราคารายวันคือ $e^{0.000320635+0.0176383Z}$ แถวที่ห้ายืนยันเรื่องความโค้งของ $e^Y$ ด้วยตัวเลข log drift รายวันบวกครึ่งหนึ่งของ variance รายวันได้ $0.12/252$ พอดี ซึ่งคือ $\mu\Delta t$ ตามที่ขั้นที่ 5 บอก

อีกเรื่องที่ควรเห็น ส่วนสุ่มรายวัน $\sigma\sqrt{\Delta t}\approx1.764\%$ (คนในวงการเรียกส่วนนี้ว่า noise หรือเสียงรบกวน) ใหญ่กว่า log drift รายวัน $\nu\Delta t\approx0.032\%$ อยู่ $0.0176383/0.000320635\approx55$ เท่า ในหนึ่งวัน การแกว่งจึงกลบแนวโน้มจนมองไม่เห็น

ตรวจเองใน 10 วินาที: $\sqrt{252}\approx15.875$ และ $0.28/15.875\approx0.01764$ ถ้าเผลอหารด้วย 252 แทน $\sqrt{252}$ จะได้ $0.28/252\approx0.00111$ เล็กไป $\sqrt{252}\approx15.9$ เท่า

ขั้นที่ 7 — เดินราคาสามวันด้วยมือ

โจทย์ให้อะไรมาบ้าง: ลองเดินราคาสามวันแรกด้วยมือ จะได้เห็นว่าโปรแกรมจำลองทำอะไรในแต่ละก้าว เครื่องสุ่มให้เลขจาก standard Normal สามตัว (ตัวเลขสมมติ):

  • วันที่ 1: $Z=+0.83$
  • วันที่ 2: $Z=-1.42$
  • วันที่ 3: $Z=+0.05$

แต่ละวันเอาราคาเมื่อวานคูณด้วยตัวคูณรายวัน $e^{0.000320635+0.0176383Z}$ จากขั้นที่ 6 และเก็บทศนิยมเต็มระหว่างทาง ไม่ปัดจนจบ

\[ \begin{aligned} S_1&=100\,e^{0.000320635+0.0176383(0.83)}\\ &=100\,e^{0.0149605}\approx101.5073,\\ S_2&=101.5073\,e^{0.000320635-0.0176383(1.42)}\\ &=101.5073\,e^{-0.0247258}\approx99.0282,\\ S_3&=99.0282\,e^{0.000320635+0.0176383(0.05)}\\ &=99.0282\,e^{0.0012026}\approx99.1474. \end{aligned} \]

คำตอบ: ราคาปิดสามวันคือ \$101.51, \$99.03 และ \$99.15

ทำไมต้องเก็บทศนิยมเต็ม ลองนึกถึงพอร์ตที่ถือหุ้นตัวนี้ 20,000 หุ้น (ตัวเลขสมมติ) กำไรวันแรกคือจำนวนหุ้นคูณราคาที่เพิ่มขึ้น ถ้าใช้ราคาเต็มกับราคาที่ปัดแล้วจะได้:

\[ \begin{aligned} 20{,}000\times(101.5073-100)&\approx\$30{,}146,\\ 20{,}000\times(101.51-100)&=\$30{,}200. \end{aligned} \]

แถวที่สองใช้ราคาที่ปัดเป็นสองตำแหน่งแล้ว กำไรจึงเกินจริง $30{,}200-30{,}146=\$54$ ความต่างนี้มาจากการปัดก่อนคูณจำนวนหุ้นเท่านั้น

ตรวจเองใน 10 วินาที: log return บวกกันข้ามวันได้ เลขชี้กำลังสามวันรวมกันได้ $0.0149605-0.0247258+0.0012026=-0.0085627$ และ $100e^{-0.0085627}\approx99.147$ ตรงกับ $S_3$ นี่คือข้อดีของ log return สามวันรวมเป็นก้าวเดียวได้

ขั้นที่ 8 — ราคาหนึ่งปีข้างหน้า: median และช่วง 5% ถึง 95%

เส้นทางเดียวเป็นแค่หนึ่งเรื่องที่อาจเกิด คนที่ต้องตัดสินใจอยากเห็นภาพของทุกเส้นทาง เช่น ราคาหนึ่งปีข้างหน้า “ตรงกลาง” อยู่ที่เท่าไร และแย่หรือดีได้แค่ไหน เราตอบด้วย quantile $q_p$ คือราคาที่ scenario สัดส่วน $p$ จบต่ำกว่า เช่น $q_{0.05}$ คือราคาที่ 5% ของ scenario จบต่ำกว่า และ $q_{0.50}$ คือ median ที่แบ่ง scenario ครึ่งต่อครึ่ง

วิธีหา จากขั้นที่ 3 log ของราคาหนึ่งปีเป็น Normal ค่าเฉลี่ย $\nu=0.0808$ และ SD $\sigma=0.28$ เราหา quantile บนแกน log ก่อน แล้วแปลงกลับด้วย exponential ทำแบบนี้ได้เพราะ exponential เพิ่มขึ้นตลอด จึงไม่สลับลำดับ ค่าที่ต่ำกว่า 5% บนแกน log ก็ยังต่ำกว่า 5% บนแกนราคา ส่วน $z_p$ คือ quantile ของ standard Normal (ตารางเดียวกับใน Normal distribution) และเพราะ Normal สมมาตร $z_{0.05}=-z_{0.95}$

\[ \begin{aligned} \ln\frac{S_1}{100}&\sim\mathcal N\big(0.0808,\ 0.28^2\big),\\ q_p&=100\,e^{0.0808+z_p(0.28)},\\ q_{0.50}&=100\,e^{0.0808}\approx108.42,\\ z_{0.95}&\approx1.644854,\\ 0.28\,z_{0.95}&\approx0.460559,\\ q_{0.05}&=100\,e^{0.0808-0.460559}\\ &\approx68.40,\\ q_{0.95}&=100\,e^{0.0808+0.460559}\\ &\approx171.83. \end{aligned} \]

median ใช้ $z_{0.50}=0$ จึงเท่ากับ $100e^{\nu}$ ขึ้นจาก \$100 เพียง 8.42% ไม่ใช่ 12% แปลว่าครึ่งหนึ่งของเส้นทางจบต่ำกว่า \$108.42 ทั้งที่ drift ของราคาคือ 12%

ช่วง 5% ถึง 95% ครอบ 90% ของ scenario และไม่สมมาตรรอบ median ด้านล่างห่างจาก median $108.42-68.40\approx\$40.0$ ด้านบนห่าง $171.83-108.42\approx\$63.4$ เหตุผลคือระยะเท่ากันบนแกน log เป็นสัดส่วนเท่ากันบนแกนราคา $108.42/68.40\approx171.83/108.42\approx e^{0.460559}\approx1.585$ ส่วนราคาเฉลี่ยไม่ได้อยู่ที่ median หน้า ราคาคาดหวังในอนาคต จะพิสูจน์ว่ามันคือ $100e^{0.12}\approx\$112.75$

ขั้นที่ 9 — ต้องใช้ข้อมูลกี่ปีจึงจะเห็น drift

ในหน้านี้เรากำหนด drift ให้หุ้นเอง แต่ในโลกจริงไม่มีใครบอก ต้องเดาจากข้อมูลราคาย้อนหลัง คำถามที่โต๊ะเทรดถามบ่อยคือ ต้องมีข้อมูลกี่ปีจึงจะพิสูจน์ได้ว่าหุ้นตัวนี้มี drift บวกจริง ไม่ใช่แค่โชค ขั้นที่ 6 เตือนไว้แล้วว่าเสียงรบกวนรายวันใหญ่กว่า log drift รายวันราว 55 เท่า จึงน่าจะต้องใช้ข้อมูลนาน

เครื่องมือคือ t-statistic ของค่าเฉลี่ย แบบเดียวกับใน การทดสอบสมมติฐาน เอาค่าเฉลี่ยที่วัดได้หารด้วย SE (standard error คือ SD ของค่าเฉลี่ยเอง) ถ้า $t$ ถึงราว 2 เราถือว่าค่าเฉลี่ยต่างจากศูนย์จริง ข้อมูลคือ log return รายวัน $Y_k$ จำนวน $N$ วัน ที่อิสระกันและมี distribution เดียวกัน รวมเป็นเวลา $T=N\Delta t$ ปี

\[ \begin{aligned} \bar Y&=\frac1N\sum_{k=1}^{N}Y_k,\qquad \mathbb E[\bar Y]=\nu\Delta t,\\ \operatorname{SE}(\bar Y)&=\frac{\sigma\sqrt{\Delta t}}{\sqrt N},\\ t&=\frac{\nu\Delta t\,\sqrt N}{\sigma\sqrt{\Delta t}}\\ &=\frac{\nu}{\sigma}\sqrt{N\Delta t}=\frac{\nu}{\sigma}\sqrt T,\\ t=2:\quad T&=\left(\frac{2\sigma}{\nu}\right)^2=\left(\frac{0.56}{0.0808}\right)^2\\ &\approx48.03\ \text{years},\\ N&=252T\approx12{,}105\ \text{days}. \end{aligned} \]

SE มาจาก SD รายวัน $\sigma\sqrt{\Delta t}$ หารด้วย $\sqrt N$ เพราะ variance ของค่าเฉลี่ยของ $N$ ตัวที่อิสระกันเล็กลง $N$ เท่า จังหวะที่ต้องสังเกตคือ $\Delta t$ ตัดกันหายไป เพราะ $\Delta t/\sqrt{\Delta t}=\sqrt{\Delta t}$ แล้วรวมกับ $\sqrt N$ ได้ $\sqrt{N\Delta t}=\sqrt T$ t-statistic จึงขึ้นกับจำนวนปีของข้อมูล $T$ อย่างเดียว ใช้ข้อมูลรายวันหรือรายนาทีก็ต้องรอเวลาปฏิทินเท่ากัน เก็บข้อมูลถี่ขึ้นไม่ช่วยให้เห็น drift เร็วขึ้น

ผล 48 ปีเปลี่ยนวิธีทำงานบนโต๊ะ ด้วยข้อมูลสามปี $t=\frac{0.0808}{0.28}\sqrt3\approx0.50$ ยังห่างจาก 2 มาก ใครอ้างว่าเห็น drift จากกราฟสามปี ส่วนใหญ่กำลังเห็นแค่เสียงรบกวน ตรงกันข้าม $\sigma$ ประมาณได้จากข้อมูลไม่กี่เดือน เพราะวัดจากกำลังสองของการขยับ และข้อมูลถี่ช่วยได้จริง (ผลรวมกำลังสองของการขยับเท่ากับเวลาที่ผ่านไป ตาม สมบัติแปลก ๆ ของเส้นทาง Brownian) สรุปคือ $\sigma$ วัดได้ แต่ $\mu$ แทบประมาณไม่ได้จากประวัติราคา

ความผิดที่รันผ่านแต่ให้ราคาผิด

ใส่ $\mu$ ลงในเลขชี้กำลังตรง ๆ โค้ดเขียน $S_{t+\Delta t}=S_te^{\mu\Delta t+\sigma\sqrt{\Delta t}Z}$ โดยคิดว่า drift คือ 12% ผลคือ log drift กลายเป็น 12% แทน 8.08% ทุก quantile ของราคาหนึ่งปีจึงสูงไปในสัดส่วนเดียวกัน ดูที่ median:

\[ \begin{aligned} q_{0.50}^{\text{wrong}}&=100e^{0.12}\approx\$112.75,\\ q_{0.50}&=100e^{0.0808}\approx\$108.42,\\ e^{0.12-0.0808}-1&=e^{0.0392}-1\approx4.00\%. \end{aligned} \]

ไม่มี error ขึ้นเลย โปรแกรมแค่มองโลกดีเกินไปอย่างเงียบ ๆ

คูณส่วนสุ่มด้วย $\Delta t$ แทน $\sqrt{\Delta t}$ SD รายวันที่ได้คือ $0.28\times\tfrac1{252}\approx0.111\%$ แต่ที่ถูกคือ $0.28\times\sqrt{1/252}\approx1.764\%$ ตัวที่ผิดเล็กไป $\sqrt{252}\approx15.9$ เท่า ราคาจำลองยังดูสมเหตุสมผล แต่ความเสี่ยงรายวันหายไปเกือบหมด

ใช้ Euler step กับก้าวยาว Euler step คือสูตรประมาณ $S_{t+\Delta t}=S_t(1+\mu\Delta t+\sigma\sqrt{\Delta t}Z)$ ที่ใช้เส้นตรงแทน exponential ถ้าก้าวเดียวยาวหนึ่งปี ราคาจะเป็น $100(1+0.12+0.28Z)$ คือ Normal ค่าเฉลี่ย \$112 และ SD \$28 ราคานี้ติดลบเมื่อ $1.12+0.28Z\lt0$:

\[ \begin{aligned} Z&\lt-1.12/0.28=-4,\\ P(S\lt0)&=\Phi(-4)\approx0.0032\%. \end{aligned} \]

โอกาสนี้น้อย แต่สูตร exact ให้ 0% พอดี และ Euler ยังไม่มีหางขวายาวแบบ lognormal สูตร exact ใช้ต้นทุนคำนวณเท่ากัน จึงไม่มีเหตุผลใช้ Euler กับ GBM (หน้า การจำลอง SDE เทียบสองวิธีกับ SDE ที่ไม่มีสูตรปิด)

เอาค่าเฉลี่ยของ log return รายวันคูณ 252 แล้วเรียกว่า $\mu$ ค่าเฉลี่ยของ log return รายวันคือ $\nu\Delta t$ ตัวที่ได้จึงเป็น $\nu$ ไม่ใช่ $\mu$ ถ้าต้องการ $\mu$ ต้องบวก $\sigma^2/2$ กลับ หุ้นในหน้านี้ได้ $0.0808+0.0392=0.12$ ต่างกัน 3.92 จุดต่อปี กลับกัน ถ้าเอกสารบอกว่า “log drift 12%” แปลว่า $\nu=0.12$ และ $\mu=0.12+0.0392=0.1592$ ทุกครั้งที่รับพารามิเตอร์มา ต้องถามว่าเป็น $\mu$ หรือ $\nu$

ใช้ทำอะไรบนโต๊ะจริง

สูตรเดินหน้าหนึ่งก้าว $S_{t+\Delta t}=S_te^{\nu\Delta t+\sigma\sqrt{\Delta t}Z}$ อยู่ในทุกระบบที่จำลองราคาหุ้น ตัวอย่างคือการคำนวณ VaR (Value at Risk คือขาดทุนที่พอร์ตไม่ควรเกินในวันปกติ เช่น 99 วันจาก 100 วัน) แบบ Monte Carlo (สุ่มเส้นทางเป็นพันเส้นแล้วนับผล) ระบบสร้างราคาวันพรุ่งนี้ของหุ้นทุกตัวในพอร์ตด้วยสูตรนี้ แล้วตีราคาพอร์ตใหม่ทีละเส้นทาง หุ้นจริงขยับไปด้วยกัน ระบบจึงป้อน $Z$ ที่ผสมกันด้วย Cholesky (วิธีแยก matrix ที่ใช้ผสมเลขสุ่มอิสระให้มี correlation ตามที่ต้องการ)

สูตร Black–Scholes ใช้ GBM ตัวเดียวกัน แต่เปลี่ยน $\mu$ เป็นอัตราดอกเบี้ย เหตุผลอยู่ที่ risk-neutral measure (วิธีคิดราคาที่ให้ทุกสินทรัพย์โตเฉลี่ยเท่าดอกเบี้ย)

งานวางแผนการลงทุนกับลูกค้าใช้ median และช่วง 5% ถึง 95% ของราคาหนึ่งปีจากขั้นที่ 8 (\$108.42 และ \$68.40 ถึง \$171.83) แทนการบอก “ผลตอบแทนคาดหวัง” ตัวเดียว เพราะตัวเลขเดียวซ่อนหางซ้ายไว้ และยังซ่อนความจริงที่ว่าเส้นทางส่วนใหญ่จบต่ำกว่าค่าเฉลี่ย \$112.75 โอกาสนี้หาได้บนแกน log เพราะ $\ln(112.75/100)\approx0.12$ และ log ของราคาเป็น Normal ค่าเฉลี่ย 0.0808 SD 0.28:

\[ \begin{aligned} P(S_1\lt112.75)&=\Phi\!\left(\frac{0.12-0.0808}{0.28}\right)\\ &=\Phi(0.14)\approx55.6\%. \end{aligned} \]

โจทย์ตรวจความเข้าใจ

1. ทีมอยากจำลองหุ้นอีกตัวแบบรายสัปดาห์ หุ้นสมมติตัวนี้มี

  • ราคาวันนี้ $S_0=\$50$
  • drift $\mu=8\%$ ต่อปี
  • ความผันผวน $\sigma=40\%$ ต่อปี
  • ก้าวละหนึ่งสัปดาห์ $\Delta t=1/52$ ปี (ปีหนึ่งมี 52 สัปดาห์)

จงหา log drift ต่อสัปดาห์ $\nu\Delta t$ SD ต่อสัปดาห์ $\sigma\sqrt{\Delta t}$ และราคาหลังหนึ่งสัปดาห์ ถ้าเลขสุ่มออกมา $Z=-1$

เฉลย
\[ \begin{aligned} \nu&=0.08-\tfrac12(0.40)^2\\ &=0.08-0.08=0,\\ \nu\Delta t&=0\times\tfrac1{52}=0,\\ \sigma\sqrt{\Delta t}&=0.40/\sqrt{52}\approx0.05547,\\ S_{1/52}&=50\,e^{0+0.05547\times(-1)}\\ &\approx\$47.30. \end{aligned} \]

log drift เป็นศูนย์พอดี หุ้นตัวนี้ราคาเฉลี่ยโต 8% ต่อปี แต่ median ไม่โตเลย เพราะ $\sigma^2/2=0.08$ กิน drift ของ log ไปหมด

2. ลูกค้าถามว่า ถ้าถือหุ้นในหน้านี้ ($S_0=\$100$, $\mu=12\%$, $\sigma=28\%$) ไปสองปี ราคาจะอยู่แถวไหน จงหา median และช่วง 5% ถึง 95% ของราคาปลายปีที่สอง

เฉลย

log ของราคาหลัง $T=2$ ปีเป็น Normal ค่าเฉลี่ย $\nu T$ และ SD $\sigma\sqrt T$ แล้วใช้ $z_{0.95}\approx1.644854$ เหมือนขั้นที่ 8:

\[ \begin{aligned} \nu T&=0.0808\times2=0.1616,\\ \sigma\sqrt T&=0.28\sqrt2\approx0.39598,\\ 1.644854\times0.39598&\approx0.65133,\\ q_{0.50}&=100e^{0.1616}\approx\$117.54,\\ q_{0.05}&=100e^{0.1616-0.65133}\\ &=100e^{-0.48973}\approx\$61.28,\\ q_{0.95}&=100e^{0.1616+0.65133}\\ &=100e^{0.81293}\approx\$225.45. \end{aligned} \]

ช่วงบนแกน log กว้างขึ้น $\sqrt2\approx1.41$ เท่าจากหนึ่งปี ไม่ใช่สองเท่า เพราะ SD โตตาม $\sqrt T$

3. หุ้นอีกตัวแกว่งน้อยกว่า ความผันผวน $\sigma=16\%$ ต่อปี แต่ drift ยัง $\mu=12\%$ ต่อปี ต้องใช้ข้อมูลกี่ปีจึงจะได้ t-statistic เท่ากับ 2?

เฉลย
\[ \begin{aligned} \nu&=0.12-\tfrac12(0.16)^2\\ &=0.12-0.0128=0.1072,\\ T&=\left(\frac{2\times0.16}{0.1072}\right)^2\\ &=(2.98507)^2\approx8.91. \end{aligned} \]

ราว 8.91 ปี ความผันผวนลดลงเกือบครึ่ง (จาก 28% เป็น 16%) แต่เวลาที่ต้องรอลดจาก 48 ปีเหลือไม่ถึง 9 ปี ลดลงมากกว่าครึ่งมาก เพราะได้สองต่อ $\sigma$ ในตัวเศษเล็กลง และ $\nu$ ในตัวส่วนโตขึ้น (หัก $\sigma^2/2$ น้อยลง) แล้วผลทั้งหมดยังถูกยกกำลังสอง

รันใน Node.js ได้โดยไม่ติดตั้งแพ็กเกจ โค้ดคำนวณตัวเลขทุกขั้นของหน้านี้ ใช้ Normal CDF (ฟังก์ชัน $\Phi$) ที่เขียนเอง และพิมพ์ผลเป็น JSON

เปิดดูโค้ด 
function positive(x, name) {
  if (typeof x !== 'number' || !Number.isFinite(x) || x <= 0) throw new RangeError(name + ' must be a positive number');
  return x;
}
// Standard Normal CDF: Taylor series near the centre, continued fraction in the tails.
function normCdf(x) {
  const ax = Math.abs(x), density = Math.exp(-ax * ax / 2) / Math.sqrt(2 * Math.PI);
  if (ax < 3) {
    let term = ax, sum = ax;
    for (let k = 1; term > 1e-17 * sum; k++) { term *= ax * ax / (2 * k + 1); sum += term; }
    return x < 0 ? 0.5 - density * sum : 0.5 + density * sum;
  }
  let f = 0;
  for (let k = 300; k >= 1; k--) f = k / (ax + f);
  const tail = density / (ax + f);
  return x < 0 ? tail : 1 - tail;
}
function normInv(p) {
  let lo = -40, hi = 40;
  for (let i = 0; i < 200; i++) { const mid = (lo + hi) / 2; if (normCdf(mid) < p) lo = mid; else hi = mid; }
  return (lo + hi) / 2;
}
// One exact GBM step of length dt years: log drift nu*dt and noise sigma*sqrt(dt).
function gbmStep(mu, sigma, dt) {
  positive(sigma, 'Volatility'); positive(dt, 'Time step');
  const nu = mu - sigma * sigma / 2;
  return {nu, drift: nu * dt, halfVariance: sigma * sigma / 2 * dt, diffusion: sigma * Math.sqrt(dt)};
}
function gbmPath(S0, mu, sigma, dt, shocks) {
  const {drift, diffusion} = gbmStep(mu, sigma, dt), prices = [];
  let S = positive(S0, 'Start price');
  for (const z of shocks) { S *= Math.exp(drift + diffusion * z); prices.push(S); }
  return prices;
}
// Price quantile at horizon T: log price is Normal, and exp keeps the order of quantiles.
function priceQuantile(S0, mu, sigma, T, p) {
  const {nu} = gbmStep(mu, sigma, 1);
  return S0 * Math.exp(nu * T + normInv(p) * sigma * Math.sqrt(T));
}
// Years of data before the mean daily log return reaches the chosen t-statistic.
function yearsToSeeDrift(mu, sigma, tStat = 2) {
  const {nu} = gbmStep(mu, sigma, 1);
  if (Math.abs(nu) < 1e-12) throw new RangeError('Log drift is zero: no amount of data makes it visible');
  return (tStat * sigma / nu) ** 2;
}
const S0 = 100, mu = 0.12, sigma = 0.28, day = 1 / 252;
const step = gbmStep(mu, sigma, day);
const path = gbmPath(S0, mu, sigma, day, [0.83, -1.42, 0.05]);
console.log(JSON.stringify({
  arithmeticBelowZero5y: normCdf(-100 / (28 * Math.sqrt(5))),
  compounding: [1, 12, 365].map(n => (1 + mu / n) ** n).concat(Math.exp(mu)),
  step, dailyMeanReturn: step.drift + step.halfVariance, muPerDay: mu * day,
  convexity: (Math.exp(0.28) + Math.exp(-0.28)) / 2,
  path, pnlDay1: 20000 * (path[0] - S0),
  oneYear: [0.05, 0.5, 0.95].map(p => priceQuantile(S0, mu, sigma, 1, p)),
  yearsToSeeDrift: yearsToSeeDrift(mu, sigma),
  exercises: {
    weekly: gbmPath(50, 0.08, 0.40, 1 / 52, [-1])[0],
    twoYears: [0.05, 0.5, 0.95].map(p => priceQuantile(S0, mu, sigma, 2, p)),
    lowVol: yearsToSeeDrift(0.12, 0.16)
  }
}));

สิ่งที่ควรตอบได้หลังอ่าน

  • GBM นิยามว่า $S_t=S_0e^{(\mu-\sigma^2/2)t+\sigma W_t}$ log ของราคาเป็น Normal ส่วนราคาเป็น lognormal และบวกเสมอ ถ้า $\sigma=0$ จะเหลือดอกเบี้ยทบต้นต่อเนื่อง $S_0e^{\mu t}$
  • สูตรเดินหน้าหนึ่งก้าว $S_{t+\Delta t}=S_te^{\nu\Delta t+\sigma\sqrt{\Delta t}Z}$ ตรงเป๊ะทุกความยาวก้าว และใช้แค่ราคาล่าสุดกับเลขสุ่มหนึ่งตัว
  • $\mu$ คือค่าเฉลี่ยของเปอร์เซ็นต์ที่ราคาขยับ แต่เลขชี้กำลังใช้ $\nu=\mu-\sigma^2/2$ เพราะ $e^Y$ โค้งหงาย หุ้นในหน้านี้ได้ $\nu=0.12-0.0392=0.0808$ คือ 8.08% ต่อปี
  • หุ้น \$100 ตัวนี้หลังหนึ่งปีมี median \$108.42 และช่วง 5% ถึง 95% จาก \$68.40 ถึง \$171.83 ซึ่งไม่สมมาตรรอบ median
  • จะเห็น drift ด้วย t-statistic เท่ากับ 2 ต้องใช้ข้อมูล $T=(2\sigma/\nu)^2$ ปี หุ้นตัวนี้คือราว 48 ปี และเก็บข้อมูลถี่ขึ้นไม่ช่วย

หน้าถัดไป ราคาคาดหวังในอนาคต: ทำไม drift คือ μ พอดี จะใช้ moment generating function ของ Normal (ฟังก์ชัน $\mathbb E[e^{sX}]$ ที่ให้ค่าเฉลี่ยของ $e$ ยกกำลังตัวแปรสุ่มได้ทันที) พิสูจน์ว่าราคาเฉลี่ยโตที่ $\mu$ พอดี และวัดว่าช่องว่างระหว่างค่าเฉลี่ยกับ median กว้างแค่ไหนเมื่อถือนาน
