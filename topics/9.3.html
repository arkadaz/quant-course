9.3 Filtrations in Continuous Time

filtration คือบัญชีว่า ณ แต่ละขณะเรารู้อะไรแล้วบ้าง และเป็นเครื่องมือที่ทั้งพิสูจน์ว่า Brownian motion ทำนายทิศไม่ได้ และจับ backtest ที่แอบดูอนาคต

ทีมหนึ่ง backtest กลยุทธ์ SPY ย้อนหลังห้าปี ทุกวันตัดสินใจตอน 10:00 แล้วถือถึงตลาดปิด 16:00 ผลคือ Sharpe รายปี 21 และไม่มีวันขาดทุนเลยสักวัน ตารางข้อมูล join ข้อมูลรายวันด้วยวันที่ แถวของ 10:00 จึงมีราคาปิดของวันเดียวกันติดมา และสัญญาณคือ “ซื้อถ้าราคาปิดสูงกว่าราคาตอนนี้ ขายถ้าต่ำกว่า” ผลนี้บอกว่ากลยุทธ์ดีมาก หรือบอกอย่างอื่น?

ลองตอบก่อนเปิดเฉลย

บอกว่าโค้ดมีเครื่องย้อนเวลา ตอน 10:00 ยังไม่มีใครรู้ราคาปิด ในแบบจำลองของหน้านี้ กฎใดก็ตามที่คำนวณจากข้อมูลถึง 10:00 เท่านั้น ได้กำไรเฉลี่ย \$0 ต่อหุ้น ส่วนกฎที่เห็นราคาปิดได้เงินเท่าขนาดการขยับทุกวัน เฉลี่ย \$4.52 SD \$3.41 จึงได้ Sharpe วันละ 1.32 หรือปีละ 21.0 ตัวเลข 21 จึงเป็นลายนิ้วมือของการรั่ว ไม่ใช่ฝีมือ

ภาพรวมก่อนลงสูตร

ทุก backtest และทุกสูตรตั้งราคาต้องตอบคำถามเดียวให้ได้ก่อน: ตอนตัดสินใจ เรารู้อะไรแล้วบ้าง คณิตศาสตร์เรียกบัญชีนี้ว่า filtration เขียน $\mathcal F_t$ ให้ข้อมูลที่มีถึงเวลา $t$ และเขียน $\mathbb E_t[\,\cdot\,]$ ให้ค่าเฉลี่ยเมื่อรู้ข้อมูลชุดนั้น หน้าfiltration และ martingaleสร้างมันในเวลาที่นับเป็นขั้น หน้านี้ขยายไปเวลาต่อเนื่อง ซึ่งไม่มี “ขั้นถัดไป” ให้นับ ข้อมูลตอนเวลา $t$ คือเส้นทางทั้งเส้นจนถึง $t$

เครื่องมือมีสามชิ้น: ของที่รู้แล้วดึงออกจากค่าเฉลี่ยได้, ค่าเฉลี่ยสองชั้นเท่ากับค่าเฉลี่ยชั้นเดียว และข้อเท็จจริงสำคัญของ Brownian motion ว่าฟังก์ชันใด ๆ ของการขยับหลังเวลา $t$ อิสระจากทุกอย่างที่รู้ตอน $t$ ด้วยสามชิ้นนี้เราจะพิสูจน์ว่า $W_t$, $W_t^2-t$ และ $e^{\sigma W_t-\sigma^2t/2}$ เป็น martingale ทั้งหมด ตั้งราคาปิดที่ทำนายได้ตอน 10:00 และคำนวณว่าทำไม backtest ข้างบนได้ Sharpe 21

รูปด้านล่างคือทั้งหน้าในภาพเดียว: ทางซ้ายของเส้นแดงคือสิ่งที่รู้แล้ว ทางขวาคืออนาคตที่ยังบานออก และเส้นเขียวคือคำทำนายที่ดีที่สุด ซึ่งแบนอยู่ที่ค่าปัจจุบัน

ศัพท์ที่ใช้ในหัวข้อนี้
Filtration $\mathcal F_t$
ข้อมูลที่มีจนถึงเวลา $t$ เรียงตามเวลาที่เดินไป โดยข้อมูลไม่เคยหาย ใช้กำหนดว่าสูตร สัญญาณ หรือ position มีสิทธิ์เห็นอะไร ณ แต่ละขณะ
รู้ได้ตอนเวลา $t$ (adapted)
ค่าที่คำนวณได้จากราคาที่เห็นแล้วจนถึงเวลา $t$ เช่นราคาสูงสุดตั้งแต่เปิดตลาดถึงตอนนี้ ใช้เป็นเกณฑ์ตรวจว่า feature ไหนใช้ได้
$\mathbb E_t[X]$
ย่อมาจาก $\mathbb E[X\mid\mathcal F_t]$ ค่าเฉลี่ยของ $X$ เมื่อรู้เส้นทางจนถึงเวลา $t$ เป็นการทำนายที่ดีที่สุดตอนนั้น ตัวมันเองรู้ได้ตอน $t$ แต่ถ้ามองจากเวลาก่อนหน้า มันยังสุ่ม
Martingale
สิ่งที่รู้ได้ตอนเวลา $t$, มีค่าเฉลี่ยของขนาดจำกัด และมีค่าเฉลี่ยของอนาคตเท่ากับค่าตอนนี้ คือแบบจำลองของเกมที่ยุติธรรม ต้องบอกเสมอว่าเทียบกับข้อมูลชุดไหน ถ้าค่าเฉลี่ยของอนาคตไม่ต่ำกว่าค่าตอนนี้เรียกว่า submartingale ถ้าไม่สูงกว่าเรียกว่า supermartingale
Tower property
กฎ $\mathbb E_{s}\big[\mathbb E_t[X]\big]=\mathbb E_s[X]$ เมื่อ $s\le t$ (law of iterated expectations) เฉลี่ยสองชั้นได้เท่ากับเฉลี่ยชั้นเดียว ใช้พิสูจน์ว่ากฎที่ซื่อสัตย์ได้ศูนย์
Look-ahead bias
ความผิดที่ backtest ใช้ข้อมูลที่ยังมาไม่ถึง ณ เวลาตัดสินใจ ผลที่ได้ดีเกินจริงเพราะการรั่วของเวลา ไม่ใช่เพราะสัญญาณ
Sharpe ratio
ค่าเฉลี่ยของผลตอบแทนหารด้วย SD ของมัน รายปีคูณ $\sqrt{252}$ กลยุทธ์จริงที่ดีมากมักอยู่ราว 1 ถึง 3 ตัวเลขระดับ 20 จึงเป็นสัญญาณเตือน (การอนุมาน Sharpe ratio)
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$S_u$ราคา SPY ที่เวลา $u$ ตัวห้อยเป็นเวลานาฬิกา เช่น $S_{10}$ คือ 10:00ดอลลาร์
$W_t$SBM ที่เวลา $t$รากของปี
$\mathcal F_t,\ \mathbb E_t,\ \operatorname{Var}_t$ข้อมูลถึงเวลา $t$ และค่าเฉลี่ยกับ variance เมื่อรู้ข้อมูลนั้นตามสิ่งที่อยู่ข้างใน
$h$position ที่เลือกตอนตัดสินใจ เช่น +1 ซื้อ −1 ขายหุ้น
$\Delta$การขยับหลังเวลา $t$ คือ $W_{t+s}-W_t$รากของปี
$M_t,\ Z_t$$W_t^2-t$ และ $e^{\sigma W_t-\sigma^2t/2}$ สอง martingale ที่สร้างจาก $W$ปี, ไม่มีหน่วย

ขั้นที่ 1 — ข้อมูลที่มีตอนเวลาหนึ่ง: ต้นไม้สองขั้นของ SPY

โจทย์ให้อะไรมาบ้าง: ตอน 10:00 SPY อยู่ที่ \$520 ภายใน 13:00 ราคาขึ้นหรือลง \$4 และภายใน 16:00 ขึ้นหรือลงอีก \$4 แต่ละครั้งโอกาสครึ่งต่อครึ่ง และสองครั้งไม่เกี่ยวกัน \$4 ไม่ได้เลือกลอย ๆ มันใกล้ SD ของสามชั่วโมงในแบบจำลองดอลลาร์ของ SPY ($\sigma=520\times0.18=93.60$ ดอลลาร์ต่อรากของปี): $93.60\sqrt{180/98{,}280}\approx4.006$

\[ \begin{aligned} (+,+)&:\ 520\to524\to528,\\ (+,-)&:\ 520\to524\to520,\\ (-,+)&:\ 520\to516\to520,\\ (-,-)&:\ 520\to516\to512. \end{aligned} \]

คำตอบ: ตอน 10:00 รู้แค่ \$520 ยังเป็นไปได้ทั้งสี่เส้นทาง ตอน 13:00 รู้ก้าวแรกแล้ว เหลือสองเส้นทาง ตอน 16:00 เหลือเส้นเดียว ค่าที่ “รู้ได้ตอนเวลา $t$” คือค่าที่คำนวณได้จากราคาที่เห็นแล้วถึง $t$: $S_{13}$ รู้ได้ตอน 13:00 แต่ไม่ใช่ตอน 10:00 และข้อมูลโตได้อย่างเดียว ไม่มีอะไรที่รู้ตอน 13:00 แล้วลืมตอน 16:00

ตรวจเองใน 10 วินาที: สี่เส้นทางมีโอกาส 1/4 เท่ากัน และราคาปิดที่เป็นไปได้คือ 528, 520, 512 ด้วยโอกาส 1/4, 1/2, 1/4

ขั้นที่ 2 — ค่าเฉลี่ยตามข้อมูลที่มี และค่าเฉลี่ยสองชั้น

คำทำนายราคาปิดขึ้นกับว่าถามตอนไหน ตอน 13:00 เรารู้ก้าวแรกแล้ว จึงเฉลี่ยเฉพาะเส้นทางที่ยังเป็นไปได้ ตอน 10:00 ต้องเฉลี่ยทั้งสี่เส้น เขียน $\mathbb E_{13}$ และ $\mathbb E_{10}$ ให้สองแบบนี้

\[ \begin{aligned} \text{up}:\ \mathbb E_{13}[S_{16}]&=\tfrac12(528)+\tfrac12(520)=524,\\ \text{down}:\ \mathbb E_{13}[S_{16}]&=\tfrac12(520)+\tfrac12(512)=516,\\ \mathbb E_{10}[S_{16}]&=\tfrac14(528+520+520+512)\\ &=520,\\ \tfrac12(524)+\tfrac12(516)&=520. \end{aligned} \]

ตอน 13:00 คำทำนายคือ 524 หรือ 516 เท่ากับราคาตอนนั้นพอดี เพราะก้าวที่เหลือมีค่าเฉลี่ยศูนย์ สังเกตว่า $\mathbb E_{13}[S_{16}]$ เป็นตัวเลขที่คำนวณได้ตอน 13:00 แต่ถ้ายืนอยู่ที่ 10:00 มันยังสุ่ม เป็น 524 หรือ 516 ครึ่งต่อครึ่ง

บรรทัดสุดท้ายคือ tower property: เอาคำทำนายตอน 13:00 มาเฉลี่ยอีกชั้นจากมุมของ 10:00 ได้คำทำนายตอน 10:00 พอดี เฉลี่ยทีละชั้นกับเฉลี่ยรวดเดียวต้องได้เท่ากัน เพราะเป็นการบวกสี่เส้นทางเดิมด้วยน้ำหนักเดิม แค่จัดกลุ่มต่างกัน

ขั้นที่ 3 — ของที่รู้แล้วดึงออกได้: ทำไมกฎที่ซื่อสัตย์ได้ศูนย์

ทีนี้ถามเรื่องเงิน กลยุทธ์เลือก position $h$ ตอน 13:00 แล้วถือถึง 16:00 เช่นกฎ momentum: ซื้อ 1 หุ้นถ้าราคาขึ้นมาแล้ว ขาย 1 หุ้นถ้าลงมาแล้ว กำไรคือ $h(S_{16}-S_{13})$ ตอน 13:00 ค่า $h$ เป็นตัวเลขที่รู้แล้ว จึงดึงออกจากค่าเฉลี่ยได้เหมือนค่าคงที่

\[ \begin{aligned} \mathbb E_{13}[h(S_{16}-S_{13})]&=h\,\mathbb E_{13}[S_{16}-S_{13}]\\ &=h\cdot0=0,\\ \mathbb E_{10}[h(S_{16}-S_{13})]&=\mathbb E_{10}\big[\mathbb E_{13}[h(S_{16}-S_{13})]\big]\\ &=\mathbb E_{10}[0]=0,\\ h_{\text{leak}}&=\operatorname{sign}(S_{16}-S_{13}),\\ h_{\text{leak}}(S_{16}-S_{13})&=|S_{16}-S_{13}|=4. \end{aligned} \]

กฎ momentum ให้ผลสี่เส้นทางเป็น +4, −4, −4, +4 เฉลี่ยศูนย์ตามบรรทัดบน ไม่ว่า $h$ จะคิดจากอะไร ขอแค่รู้ได้ตอน 13:00 ผลเฉลี่ยก็เป็นศูนย์ เพราะมันถูกดึงออกมาคูณกับก้าวที่เหลือซึ่งเฉลี่ยศูนย์ บรรทัดที่สามใช้ tower property ย้อนกลับไปมองจาก 10:00 ได้ศูนย์เหมือนกัน นี่คือเหตุผลเดียวกับที่ระบบเดิมพันแบบ martingaleซึ่งเพิ่มเงินเดิมพันเป็นสองเท่าทุกครั้งที่แพ้ เอาชนะเกมที่ยุติธรรมไม่ได้

สองบรรทัดล่างคือการรั่ว: $h_{\text{leak}}$ ใช้ราคา 16:00 จึงไม่ใช่ตัวเลขที่รู้ตอน 13:00 และดึงออกจากค่าเฉลี่ยไม่ได้ ผลคูณกลายเป็นขนาดการขยับ ได้ +4 ทุกเส้นทาง จุดที่การรั่วทำลายคือบรรทัดแรกของขั้นนี้พอดี

ขั้นที่ 4 — ข้อมูลในเวลาต่อเนื่อง: ทั้งเส้นทางจนถึงตอนนี้

ในเวลาต่อเนื่องไม่มีกิ่งให้นับ ราคาขยับทุกขณะ ข้อมูลตอนเวลา $t$ จึงเป็นเส้นทางราคาทั้งเส้นตั้งแต่เปิดตลาดจนถึง $t$ บรรทัดข้างล่างเป็นนิยาม เขียนด้วยช่วงเวลาแทนการนับกิ่ง ส่วนบรรทัดสุดท้ายคือข้อเท็จจริงที่ทำให้ Brownian motion คำนวณง่าย

\[ \begin{aligned} \mathcal F_{9:45}&:\ S_u,\ 9{:}30\le u\le9{:}45,\\ \mathcal F_{10:00}&:\ S_u,\ 9{:}30\le u\le10{:}00,\\ \mathcal F_{16:00}&:\ S_u,\ 9{:}30\le u\le16{:}00,\\ \mathbb E_t[X]&:=\mathbb E\big[X\mid W_u,\ 0\le u\le t\big],\\ \mathbb E_t\big[g(W_{t+s}-W_t)\big]&=\mathbb E\big[g(W_{t+s}-W_t)\big]. \end{aligned} \]

สามบรรทัดแรกซ้อนกันเอง: ทุกอย่างที่รู้ตอน 9:45 ยังรู้ตอน 10:00 และทุกอย่างที่รู้ตอน 10:00 ยังรู้ตอน 16:00 ชุดข้อมูลที่โตตามเวลาแบบไม่ลืมอะไรนี้คือ filtration ไม่มีอะไรมากกว่านั้น บรรทัดที่สี่นิยาม $\mathbb E_t$ ว่าเป็นค่าเฉลี่ยของ $X$ บนเส้นทางทั้งหมดที่ตรงกับสิ่งที่เห็นแล้วจนถึง $t$ แทนการเฉลี่ยบนกิ่งที่เหลือของต้นไม้

บรรทัดสุดท้ายคือข้อเท็จจริงสำคัญ: กติกาความเป็นอิสระของ Brownian motion บอกว่าการขยับหลังเวลา $t$ อิสระจากเส้นทางทั้งเส้นก่อนหน้า ดังนั้นฟังก์ชัน $g$ ใด ๆ ของการขยับนั้นก็อิสระจาก $\mathcal F_t$ ด้วย การรู้อดีตจึงไม่เปลี่ยนค่าเฉลี่ยของมัน และ $W_{t+s}-W_t$ ยังเป็น $\mathcal N(0,s)$ แม้จะเห็นอดีตแล้ว ทุกขั้นต่อจากนี้ใช้บรรทัดนี้กับ $g$ คนละตัว

ขั้นที่ 5 — การทำนายที่ดีที่สุดของ Brownian motion คือค่าปัจจุบัน

ใช้ทริกเดียวกับต้นไม้: แยกค่าในอนาคตเป็นส่วนที่รู้แล้วบวกส่วนที่ยังไม่เกิด แล้วจัดการแต่ละก้อนด้วยเหตุผลคนละแบบ บรรทัดสุดท้ายคือนิยามของ martingale ที่เราตรวจ

\[ \begin{aligned} W_{t+s}&=W_t+(W_{t+s}-W_t),\\ \mathbb E_t[W_{t+s}]&=\mathbb E_t[W_t]+\mathbb E_t[W_{t+s}-W_t]\\ &=W_t+\mathbb E[W_{t+s}-W_t]\\ &=W_t+0=W_t,\\ \mathbb E|W_t|&=\sqrt{2t/\pi}\lt\infty. \end{aligned} \]

บรรทัดแรกเป็นจริงทุกเส้นทาง เพราะบวกแล้วลบ $W_t$ ตัวเดียวกัน บรรทัดที่สามคือจุดที่ใช้เหตุผลสองแบบ: $W_t$ รู้แล้วตอน $t$ ค่าเฉลี่ยของมันจึงเป็นตัวมันเอง ส่วนการขยับที่ยังไม่เกิดใช้ข้อเท็จจริงสำคัญกับ $g(x)=x$ ค่าเฉลี่ยเมื่อรู้อดีตจึงเท่ากับค่าเฉลี่ยตอนไม่รู้อะไร ซึ่งเป็นศูนย์

martingale มีสองเงื่อนไข: ค่าเฉลี่ยของอนาคตเท่ากับค่าตอนนี้ (บรรทัดที่สี่) และค่าเฉลี่ยของขนาดต้องจำกัด (บรรทัดสุดท้าย ซึ่งใช้ $\mathbb E|Z|=\sqrt{2/\pi}$ จากหน้า standard Brownian motion) SBM ผ่านทั้งสองข้อ ผลคือคำทำนายที่ดีที่สุดของอนาคตคือค่าตอนนี้ ไม่ใช่ค่าที่หวัง ไม่ใช่ค่าเฉลี่ยของสัปดาห์ก่อน และไม่มีรูปแบบในอดีตไหนช่วยได้ ซึ่งคือเส้นเขียวแบนในรูปภาพรวม

ขั้นที่ 6 — กำลังสองทำนายได้: เอียงขึ้นเท่าเวลา หักเวลาออกแล้วแบน

ถ้า $W$ ทำนายไม่ได้ แล้ว $W^2$ ล่ะ? ลองแยกแบบเดิมแล้วกระจายกำลังสอง ให้ $\Delta:=W_{t+s}-W_t$ ซึ่งมีค่าเฉลี่ย 0 และ variance $s$ ไม่ว่าจะเห็นอดีตแบบไหน

\[ \begin{aligned} W_{t+s}^2&=W_t^2+2W_t\Delta+\Delta^2,\\ \mathbb E_t[W_{t+s}^2]&=W_t^2+2W_t\,\mathbb E_t[\Delta]+\mathbb E_t[\Delta^2]\\ &=W_t^2+0+s,\\ \operatorname{Var}_t(W_{t+s})&=W_t^2+s-W_t^2=s,\\ M_t&:=W_t^2-t,\\ \mathbb E_t[M_{t+s}]&=W_t^2+s-(t+s)=M_t. \end{aligned} \]

พจน์ไขว้หายด้วยเหตุผลเดียวกับกฎที่ซื่อสัตย์: $W_t$ รู้แล้ว ดึงออกมาคูณกับ $\mathbb E_t[\Delta]=0$ ส่วนพจน์สุดท้ายไม่หาย เพราะกำลังสองเป็นบวกเสมอ ขึ้นหรือลงก็บวก และเมื่อค่าเฉลี่ยของ $\Delta$ เป็นศูนย์ ค่าเฉลี่ยของ $\Delta^2$ ก็คือ variance พอดี $W^2$ จึงเป็น submartingale: ค่าเฉลี่ยของอนาคตสูงกว่าค่าตอนนี้ $s$ เสมอ

ส่วนที่เอียงขึ้นคือหนึ่งหน่วยต่อหนึ่งหน่วยเวลาพอดี บรรทัดที่ห้าจึงหักเวลาที่ผ่านไปออก เวลา $t+s$ เป็นตัวเลขที่รู้แน่นอน ผ่านค่าเฉลี่ยออกมาตรง ๆ แล้ว $s$ สองตัวหักกันพอดี ได้ martingale ตัวที่สอง ตรวจกับต้นไม้ได้: ทุกก้าว \$4 ทำให้ $(S-520)^2$ โตเฉลี่ย 16 ตัวที่หักแล้วคือ $(S-520)^2-16k$ เมื่อ $k$ คือจำนวนก้าว ตอน 16:00 ได้ $64-32$, $0-32$, $0-32$, $64-32$ เฉลี่ย 0 เท่ากับค่าเริ่ม การหักส่วนที่ทำนายได้ออกแบบนี้คือทริกเดียวกับmartingale จาก random walkที่หัก $n\mu$ ออกจากผลรวม

ขั้นที่ 7 — ฟังก์ชันเลขชี้กำลังของการขยับ: martingale ตัวที่สาม

ข้อเท็จจริงสำคัญใช้กับ $g$ อะไรก็ได้ ลอง $g(x)=e^{\sigma x}$ ซึ่งเป็นรูปที่ราคาหุ้นใช้ใน geometric Brownian motion คำถามคือ ค่าเฉลี่ยของ $e^{\sigma\Delta}$ เป็น 1 ไหม เมื่อ $\Delta$ เฉลี่ยศูนย์ เครื่องมือคือ moment generating function ของ Normal: $\mathbb E[e^{aX}]=e^{a^2v/2}$ เมื่อ $X\sim\mathcal N(0,v)$

\[ \begin{aligned} \mathbb E_t\big[e^{\sigma\Delta}\big]&=\mathbb E\big[e^{\sigma\Delta}\big]=e^{\sigma^2s/2},\\ \sigma=0.18,\ s=1&:\ e^{0.0162}\approx1.01633,\\ Z_t&:=e^{\sigma W_t-\sigma^2t/2},\\ \mathbb E_t[Z_{t+s}]&=Z_t\,e^{-\sigma^2s/2}\,\mathbb E_t\big[e^{\sigma\Delta}\big]\\ &=Z_t. \end{aligned} \]

บรรทัดแรกไม่ใช่ 1 แม้ $\Delta$ จะเฉลี่ยศูนย์ เพราะ $e^x$ โค้งขึ้น: ขาขึ้นได้มากกว่าที่ขาลงเสีย ค่าเฉลี่ยจึงเกิน 1 ไป $e^{\sigma^2s/2}$ ที่ความผันผวน 18% ต่อปีเกินไป 1.63% ต่อปี ตัวเลขนี้คือที่มาของพจน์ $-\sigma^2/2$ ใน GBM และเหตุผลที่ราคาที่คาดหวังของ GBMโตด้วยอัตรา $\mu$ ไม่ใช่ $\mu-\sigma^2/2$

บรรทัดที่สี่แยก $Z_{t+s}=Z_t\,e^{\sigma\Delta-\sigma^2s/2}$ ดึง $Z_t$ ที่รู้แล้วออก แล้วใช้บรรทัดแรก ตัวคูณสองตัวหักกันพอดี $Z$ จึงเป็น martingale: หักส่วนที่โค้งขึ้นออกแบบเดียวกับที่หัก $t$ ออกจาก $W^2$ โค้ดท้ายหน้าสุ่ม 200,000 ครั้งได้ค่าเฉลี่ยของ $e^{0.18Z}$ เป็น 1.0167 เทียบกับ 1.0163 ของสูตร และของตัวที่หักแล้วเป็น 1.0003

ขั้นที่ 8 — ราคาปิดที่ทำนายได้ตอน 10:00

โจทย์ให้อะไรมาบ้าง: ตอน 10:00 SPY อยู่ที่ \$520 ความผันผวน 18% ต่อปี ใช้แบบจำลองดอลลาร์ $\sigma=93.60$ ดอลลาร์ต่อรากของปี ตัด drift ออกก่อน (8% ต่อปีให้แค่ \$0.15 ใน 6 ชั่วโมง) 10:00 ถึง 16:00 คือ 360 นาทีจาก 98,280 นาทีซื้อขายต่อปี (252 วัน × 390 นาที)

\[ \begin{aligned} S_{16}-S_{10}&=93.60\,(W_{16}-W_{10}),\\ \Delta t&=360/98{,}280\approx0.003663,\\ \sqrt{\Delta t}&\approx0.060523,\\ \mathbb E_{10}[S_{16}]&=520,\\ \operatorname{SD}_{10}(S_{16})&=93.60(0.060523)\approx5.665,\\ \mathbb E_{10}[(S_{16}-520)^2]&=5.665^2\approx32.09. \end{aligned} \]

คำตอบ: ราคาปิดที่ทำนายได้ดีที่สุดตอน 10:00 คือ \$520 เท่าราคาตอนนั้น คลาดได้หนึ่ง SD ราว \$5.66 และค่าเฉลี่ยของกำลังสองของการขยับคือ 32.09 ซึ่งรู้ล่วงหน้าตามที่กำลังสองเอียงขึ้นเท่าเวลา ถ้าใส่ drift 8% คำทำนายขยับเพียง $520(0.08)(0.003663)\approx\$0.15$

ตรวจเองใน 10 วินาที: 360 นาทีคือ $360/390$ ของวัน SD หนึ่งวันคือ $93.60/\sqrt{252}\approx\$5.896$ คูณ $\sqrt{0.923}\approx0.961$ ได้ราว \$5.66

ขั้นที่ 9 — ราคาของการรั่ว: ทำไม backtest ได้ Sharpe 21

โจทย์ให้อะไรมาบ้าง: กฎที่รั่วคือถือ $\operatorname{sign}(S_{16}-S_{10})$ หุ้น กำไรต่อวันจึงเป็น $|S_{16}-S_{10}|=5.665|Z|$ ใช้ $\mathbb E|Z|=\sqrt{2/\pi}$ และ $\mathbb E[Z^2]=1$ ส่วนกฎที่ซื่อสัตย์ถือ $h=\pm1$ ที่ตัดสินจากข้อมูลถึง 10:00 กำไรคือ $h\cdot5.665Z$ ซึ่งยังเป็น $\mathcal N(0,5.665^2)$ เพราะ $h$ ไม่รู้อะไรเกี่ยวกับ $Z$

\[ \begin{aligned} \mathbb E[\text{P\&L}]&=5.665(0.797885)\approx4.520,\\ \operatorname{SD}(|Z|)&=\sqrt{1-2/\pi}\approx0.602810,\\ \operatorname{SD}(\text{P\&L})&=5.665(0.602810)\approx3.415,\\ \text{Sharpe}_{\text{day}}&=4.520/3.415\approx1.324,\\ \text{Sharpe}_{\text{year}}&=1.324\sqrt{252}\approx21.0. \end{aligned} \]

คำตอบ: กฎที่เห็นราคาปิดได้เงินเฉลี่ย \$4.52 ต่อหุ้นต่อวัน ไม่มีวันขาดทุนเพราะกำไรคือขนาดการขยับ และได้ Sharpe รายปี 21.0 พอดีกับ backtest ในโจทย์เปิดเรื่อง ส่วนกฎที่ซื่อสัตย์ทุกแบบได้ศูนย์ โค้ดท้ายหน้าจำลอง 1,260 วัน (ห้าปีของวันทำการ 252 วัน): กฎที่รั่วได้ Sharpe 21.1 และขาดทุน 0 วัน ส่วนกฎที่ใช้สัญญาณตอนเช้าได้ Sharpe −0.12 และขาดทุน 641 วัน

ตรวจเองใน 10 วินาที: Sharpe รายวัน $0.798/0.603\approx1.32$ ไม่ขึ้นกับขนาด SD เลย ทุกหุ้นที่รั่วแบบนี้ได้ 21 เท่ากันหมด และ $\sqrt{252}\approx15.9$ คูณกันได้ราว 21

// Two-step tree: SPY 520 at 10:00, moves +/-4 by 13:00 and again by 16:00, each with probability 1/2.
function tree(S0, step) {
  const paths = [];
  for (const a of [1, -1]) for (const b of [1, -1]) {
    paths.push({first: a, S13: S0 + a * step, S16: S0 + (a + b) * step, p: 0.25});
  }
  return paths;
}
// Average of f over the paths that agree with what is known: `known` maps a path to its visible part.
function conditional(paths, known, f) {
  const groups = new Map();
  for (const x of paths) {
    const key = JSON.stringify(known(x));
    const g = groups.get(key) || {p: 0, sum: 0};
    g.p += x.p; g.sum += x.p * f(x);
    groups.set(key, g);
  }
  return [...groups].map(([key, g]) => ({known: JSON.parse(key), value: g.sum / g.p, p: g.p}));
}
const mean = (paths, f) => paths.reduce((s, x) => s + x.p * f(x), 0);
// A feature is usable at the decision time only if its data window ends at or before that time.
const usable = (feature, decisionMinute) => feature.endsAt <= decisionMinute;
// Brownian forecast of the close from 10:00: price in dollars = S + sigma$ * (W_u - W_10).
function closeForecast(S, sigmaDollars, minutesLeft, minutesPerYear = 252 * 390) {
  const sd = sigmaDollars * Math.sqrt(minutesLeft / minutesPerYear);
  return {mean: S, sd, meanSquare: sd * sd};
}
// mulberry32 + Box-Muller: seeded standard Normals.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Backtest over simulated days: position h is chosen at 10:00, P&L = h * (close - price at 10:00).
function backtest(days, sd, rule, seed) {
  const z = normals(seed), pnl = [];
  for (let d = 0; d < days; d++) {
    const morning = z(), move = sd * z(); // morning: a signal known at 10:00; move: 10:00 -> 16:00
    pnl.push(rule(morning, move) * move);
  }
  const m = pnl.reduce((s, x) => s + x, 0) / days;
  const v = pnl.reduce((s, x) => s + (x - m) ** 2, 0) / (days - 1);
  return {mean: m, sd: Math.sqrt(v), sharpeYear: m / Math.sqrt(v) * Math.sqrt(252), losingDays: pnl.filter(x => x < 0).length};
}
// E[exp(sigma*D)] for D ~ N(0, s), and the compensated version that should average 1.
function expMartingale(sigma, s, n, seed) {
  const z = normals(seed);
  let raw = 0, comp = 0;
  for (let i = 0; i < n; i++) {
    const d = Math.sqrt(s) * z();
    raw += Math.exp(sigma * d); comp += Math.exp(sigma * d - sigma * sigma * s / 2);
  }
  return {theoryRaw: Math.exp(sigma * sigma * s / 2), simRaw: raw / n, simCompensated: comp / n};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • filtration คือข้อมูลที่มีจนถึงเวลา $t$ ซึ่งโตได้อย่างเดียว ค่าที่รู้ได้ตอน $t$ คือค่าที่คำนวณได้จากราคาที่เห็นแล้ว
  • ของที่รู้แล้วดึงออกจาก $\mathbb E_t$ ได้ และเฉลี่ยสองชั้นเท่ากับเฉลี่ยชั้นเดียว จึงได้ว่า position ที่ตัดสินจากข้อมูลถึง $t$ คูณก้าวที่เฉลี่ยศูนย์ได้ผลเฉลี่ยศูนย์
  • ฟังก์ชันใด ๆ ของการขยับหลัง $t$ อิสระจากข้อมูลถึง $t$ จึงได้ $\mathbb E_t[W_{t+s}]=W_t$, $\operatorname{Var}_t(W_{t+s})=s$ และ $W_t$, $W_t^2-t$, $e^{\sigma W_t-\sigma^2t/2}$ เป็น martingale
  • ตอน 10:00 ราคาปิดที่ทำนายได้คือ \$520 ± \$5.66 และกฎที่เห็นราคาปิดได้ Sharpe รายปี 21 ซึ่งเป็นลายนิ้วมือของการรั่ว
  • feature ใช้ได้เมื่อข้อมูลทุกตัวมาถึงก่อนเวลาตัดสินใจ ดูเวลาที่มาถึง ไม่ใช่วันที่บนแถว
