9.3 Matrix Multiplication

pipeline เดียวจาก positions ไป factor exposures

portfolio engine มี positions ของ AAPL, MSFT และ JPM แต่ risk service ต้องการ market, quality และ rates exposure การคูณทีละช่องด้วยมือทำให้เกิดทั้ง off-by-one และหน่วยผิด Matrix multiplication ทำหน้าที่เป็น mapping ที่ตรวจสอบได้

ศัพท์การเงินที่เพิ่งโผล่มา

matrix multiplication
การคูณที่แต่ละ output element เป็น dot product ของ row แรกกับ column หลัง ใช้ map input vector ไปเป็น output vector หลายมิติ
linear map
ฟังก์ชันที่รักษาการบวกและการคูณด้วย scalar ใช้แทนการเปลี่ยน positions เป็น factor exposures อย่างเป็นระบบ
dot product
ผลรวมของผลคูณคู่ element ใช้สร้างหนึ่ง cell ของผลลัพธ์จาก row และ column
dimension compatibility
เงื่อนไขที่จำนวน columns ของ matrix ซ้ายเท่ากับจำนวน rows ของ matrix ขวา ใช้ป้องกันการคูณที่ไม่มีความหมาย
position
จำนวนการถือครอง asset ใน portfolio ใช้เป็น input ของ risk mapping
United States (US)
ประเทศสหรัฐอเมริกา ใช้ระบุว่าตัวอย่าง equity และดัชนีในบทนี้มาจากตลาดสหรัฐฯ
SPX
ดัชนี S&P 500 ใช้เป็น market factor ของ United States (US) equity ใน mapping

ตอบเรื่อง mapping ให้ครบ

ถ้า เปลี่ยนจาก factor-by-asset เป็น asset-by-factor ต้อง transpose ก่อนใช้กับ ไม่ใช่สลับ labels ใน report เฉย ๆ ผลลัพธ์ที่ถูกต้องคือ vector สามแถวที่มี unit USD million และชื่อ factor ตรงตามลำดับ

กับดัก: คูณ element คู่ตำแหน่งแทน dot product

การคูณ element-by-element ให้ matrix คนละชนิดกับ matrix multiplication และไม่รวม information ตาม row กับ column ก่อนส่ง production ให้ทดสอบ shape, หน่วย และค่า output จากตัวอย่างเล็กที่คำนวณมือได้

สรุปที่ใช้ได้จริง

  • matrix multiplication สร้าง output cell จาก row–column dot product
  • shape คูณ ได้
  • เป็น portfolio-to-factor mapping ที่รักษาหน่วย USD million
  • composition ช่วยจัด pipeline หลายชั้น
