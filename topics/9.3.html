9.3 Filtrations in Continuous Time

filtration คือบัญชีว่า ณ เวลาหนึ่งเรารู้อะไรแล้วบ้าง ใช้พิสูจน์ว่าการทำนายที่ดีที่สุดของ Brownian motion คือค่าปัจจุบัน และใช้จับ backtest ที่แอบดูอนาคต

ทีมหนึ่ง backtest กลยุทธ์ SPY ย้อนหลังห้าปี ทุกวันตัดสินใจตอน 10:00 แล้วถือถึงตลาดปิด 16:00 ผลคือ Sharpe รายปี 21 และไม่มีวันขาดทุนเลยสักวัน ตารางข้อมูล join ข้อมูลรายวันด้วยวันที่ แถวของ 10:00 จึงมีราคาปิดของวันเดียวกันติดมา และสัญญาณคือ “ซื้อถ้าราคาปิดสูงกว่าราคาตอนนี้ ขายถ้าต่ำกว่า” ผลนี้บอกว่ากลยุทธ์ดีมาก หรือบอกอย่างอื่น?

ลองตอบก่อนเปิดเฉลย

บอกว่าโค้ดมีเครื่องย้อนเวลา ตอน 10:00 ยังไม่มีใครรู้ราคาปิด ในแบบจำลองของหน้านี้ กฎใดก็ตามที่คำนวณจากข้อมูลถึง 10:00 เท่านั้น ได้กำไรเฉลี่ย \$0 ต่อหุ้น ส่วนกฎที่เห็นราคาปิดได้เงินเท่าขนาดการขยับทุกวัน เฉลี่ย \$4.52 SD \$3.41 จึงได้ Sharpe วันละ 1.32 หรือปีละ 21.0 ตัวเลข 21 จึงเป็นลายนิ้วมือของการรั่ว ไม่ใช่ฝีมือ

สิ่งที่เราจะสร้าง

ทุก backtest ต้องตอบคำถามเดียวให้ได้ก่อน: ตอนตัดสินใจ เรารู้อะไรแล้วบ้าง คณิตศาสตร์เรียกบัญชีนี้ว่า filtration หัวข้อ 4.1 สร้างมันในเวลาที่นับเป็นขั้น หน้านี้เริ่มจากต้นไม้สองขั้นของ SPY ที่นับด้วยมือได้ แล้วขยายไปเวลาต่อเนื่อง ซึ่งไม่มี “ขั้นถัดไป” ให้นับ

เครื่องมือมีสองชิ้น: ของที่รู้แล้วดึงออกจากค่าเฉลี่ยได้ และค่าเฉลี่ยสองชั้นเท่ากับค่าเฉลี่ยชั้นเดียว ด้วยสองชิ้นนี้เราจะพิสูจน์ว่า Brownian motion เป็น martingale หา $W_t^2-t$ ที่เป็น martingale อีกตัว ตั้งราคาปิดที่ทำนายได้ตอน 10:00 และคำนวณว่าทำไม backtest ข้างบนได้ Sharpe 21

ศัพท์ที่ใช้ในหัวข้อนี้
Filtration
ข้อมูลที่มีจนถึงเวลา $t$ เรียงตามเวลาที่เดินไป โดยข้อมูลไม่เคยหาย ใช้กำหนดว่าสูตร สัญญาณ หรือ position มีสิทธิ์เห็นอะไร ณ แต่ละขณะ
รู้ได้ตอนเวลา $t$ (adapted)
ค่าที่คำนวณได้จากราคาที่เห็นแล้วจนถึงเวลา $t$ เช่นราคาสูงสุดตั้งแต่เปิดตลาดถึงตอนนี้ ใช้เป็นเกณฑ์ตรวจว่า feature ไหนใช้ได้
$\mathbb E_t[X]$
ค่าเฉลี่ยของ $X$ เมื่อรู้เส้นทางจนถึงเวลา $t$ เป็นการทำนายที่ดีที่สุดตอนนั้น ตัวมันเองรู้ได้ตอน $t$ แต่ถ้ามองจากเวลาก่อนหน้า มันยังสุ่ม
Martingale
สิ่งที่รู้ได้ตอนเวลา $t$ และมีค่าเฉลี่ยของอนาคตเท่ากับค่าตอนนี้ คือเกมที่ไม่มีทิศทางให้เก็บ ต้องบอกเสมอว่าเทียบกับข้อมูลชุดไหน
Tower rule
กฎ $\mathbb E_{s}\big[\mathbb E_t[X]\big]=\mathbb E_s[X]$ เมื่อ $s\le t$ จาก 2.1 เฉลี่ยสองชั้นได้เท่ากับเฉลี่ยชั้นเดียว ใช้พิสูจน์ว่ากฎที่ซื่อสัตย์ได้ศูนย์
Look-ahead bias
ความผิดที่ backtest ใช้ข้อมูลที่ยังมาไม่ถึง ณ เวลาตัดสินใจ ผลที่ได้ดีเกินจริงเพราะการรั่วของเวลา ไม่ใช่เพราะสัญญาณ
Sharpe ratio
ค่าเฉลี่ยของผลตอบแทนหารด้วย SD ของมัน รายปีคูณ $\sqrt{252}$ กลยุทธ์จริงที่ดีมากมักอยู่ราว 1 ถึง 3 ตัวเลขระดับ 20 จึงเป็นสัญญาณเตือน
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$S_u$ราคา SPY ที่เวลา $u$ ตัวห้อยเป็นเวลานาฬิกา เช่น $S_{10}$ คือ 10:00ดอลลาร์
$W_t$SBM ที่เวลา $t$$\sqrt{\text{yr}}$
$\mathbb E_t,\ \operatorname{Var}_t$ค่าเฉลี่ยและ variance เมื่อรู้เส้นทางจนถึงเวลา $t$ตามสิ่งที่อยู่ข้างใน
$h$position ที่เลือกตอนตัดสินใจ เช่น +1 ซื้อ −1 ขายหุ้น
$\Delta$การขยับหลังเวลา $t$ คือ $W_{t+s}-W_t$$\sqrt{\text{yr}}$
$M_t$$W_t^2-t$ ตัวที่หักการโตที่รู้ล่วงหน้าออกแล้วปี

ขั้นที่ 1 — ข้อมูลที่มีตอนเวลาหนึ่ง: ต้นไม้สองขั้นของ SPY

โจทย์ให้อะไรมาบ้าง: ตอน 10:00 SPY อยู่ที่ \$520 ภายใน 13:00 ราคาขึ้นหรือลง \$4 และภายใน 16:00 ขึ้นหรือลงอีก \$4 แต่ละครั้งโอกาสครึ่งต่อครึ่ง และสองครั้งไม่เกี่ยวกัน \$4 ไม่ได้เลือกลอย ๆ มันใกล้ SD ของสามชั่วโมงในแบบจำลองดอลลาร์ของ 9.2 คือ $93.60\sqrt{180/98{,}280}\approx4.006$

\[ \begin{aligned} (+,+)&:\ 520\to524\to528,\\ (+,-)&:\ 520\to524\to520,\\ (-,+)&:\ 520\to516\to520,\\ (-,-)&:\ 520\to516\to512. \end{aligned} \]

คำตอบ: ตอน 10:00 รู้แค่ \$520 ยังเป็นไปได้ทั้งสี่เส้นทาง ตอน 13:00 รู้ก้าวแรกแล้ว เหลือสองเส้นทาง ตอน 16:00 เหลือเส้นเดียว ค่าที่ “รู้ได้ตอนเวลา $t$” คือค่าที่คำนวณได้จากราคาที่เห็นแล้วถึง $t$: $S_{13}$ รู้ได้ตอน 13:00 แต่ไม่ใช่ตอน 10:00 และข้อมูลโตได้อย่างเดียว ไม่มีอะไรที่รู้ตอน 13:00 แล้วลืมตอน 16:00

ตรวจเองใน 10 วินาที: สี่เส้นทางมีโอกาส 1/4 เท่ากัน และราคาปิดที่เป็นไปได้คือ 528, 520, 512 ด้วยโอกาส 1/4, 1/2, 1/4

ขั้นที่ 2 — ค่าเฉลี่ยตามข้อมูลที่มี และค่าเฉลี่ยสองชั้น

คำทำนายราคาปิดขึ้นกับว่าถามตอนไหน ตอน 13:00 เรารู้ก้าวแรกแล้ว จึงเฉลี่ยเฉพาะเส้นทางที่ยังเป็นไปได้ ตอน 10:00 ต้องเฉลี่ยทั้งสี่เส้น เขียน $\mathbb E_{13}$ และ $\mathbb E_{10}$ ให้สองแบบนี้

\[ \begin{aligned} \text{up}:\ \mathbb E_{13}[S_{16}]&=\tfrac12(528)+\tfrac12(520)=524,\\ \text{down}:\ \mathbb E_{13}[S_{16}]&=\tfrac12(520)+\tfrac12(512)=516,\\ \mathbb E_{10}[S_{16}]&=\tfrac14(528+520+520+512)\\ &=520,\\ \tfrac12(524)+\tfrac12(516)&=520. \end{aligned} \]

ตอน 13:00 คำทำนายคือ 524 หรือ 516 เท่ากับราคาตอนนั้นพอดี เพราะก้าวที่เหลือมีค่าเฉลี่ยศูนย์ สังเกตว่า $\mathbb E_{13}[S_{16}]$ เป็นตัวเลขที่คำนวณได้ตอน 13:00 แต่ถ้ายืนอยู่ที่ 10:00 มันยังสุ่ม เป็น 524 หรือ 516 ครึ่งต่อครึ่ง

บรรทัดสุดท้ายคือ tower rule ของ 2.1: เอาคำทำนายตอน 13:00 มาเฉลี่ยอีกชั้นจากมุมของ 10:00 ได้คำทำนายตอน 10:00 พอดี เฉลี่ยทีละชั้นกับเฉลี่ยรวดเดียวต้องได้เท่ากัน เพราะเป็นการบวกสี่เส้นทางเดิมด้วยน้ำหนักเดิม แค่จัดกลุ่มต่างกัน

ขั้นที่ 3 — ของที่รู้แล้วดึงออกได้: ทำไมกฎที่ซื่อสัตย์ได้ศูนย์

ทีนี้ถามเรื่องเงิน กลยุทธ์เลือก position $h$ ตอน 13:00 แล้วถือถึง 16:00 เช่นกฎ momentum: ซื้อ 1 หุ้นถ้าราคาขึ้นมาแล้ว ขาย 1 หุ้นถ้าลงมาแล้ว กำไรคือ $h(S_{16}-S_{13})$ ขั้นนี้ใช้เครื่องมือชิ้นที่สอง: ตอน 13:00 ค่า $h$ เป็นตัวเลขที่รู้แล้ว จึงดึงออกจากค่าเฉลี่ยได้

\[ \begin{aligned} \mathbb E_{13}[h(S_{16}-S_{13})]&=h\,\mathbb E_{13}[S_{16}-S_{13}]\\ &=h\cdot0=0,\\ \mathbb E_{10}[h(S_{16}-S_{13})]&=\mathbb E_{10}\big[\mathbb E_{13}[h(S_{16}-S_{13})]\big]\\ &=\mathbb E_{10}[0]=0,\\ h_{\text{leak}}&=\operatorname{sign}(S_{16}-S_{13}),\\ h_{\text{leak}}(S_{16}-S_{13})&=|S_{16}-S_{13}|=4. \end{aligned} \]

กฎ momentum ให้ผลสี่เส้นทางเป็น +4, −4, −4, +4 เฉลี่ยศูนย์ตามบรรทัดบน ไม่ว่า $h$ จะคิดจากอะไร ขอแค่รู้ได้ตอน 13:00 ผลเฉลี่ยก็เป็นศูนย์ เพราะมันถูกดึงออกมาคูณกับก้าวที่เหลือซึ่งเฉลี่ยศูนย์

สองบรรทัดล่างคือการรั่ว: $h_{\text{leak}}$ ใช้ราคา 16:00 จึงไม่ใช่ตัวเลขที่รู้ตอน 13:00 และดึงออกจากค่าเฉลี่ยไม่ได้ ผลคูณกลายเป็นขนาดการขยับ ได้ +4 ทุกเส้นทาง จุดที่การรั่วทำลายคือบรรทัดแรกของขั้นนี้พอดี

ขั้นที่ 4 — ข้อมูลในเวลาต่อเนื่อง: ทั้งเส้นทางจนถึงตอนนี้

ในเวลาต่อเนื่องไม่มีกิ่งให้นับ ราคาขยับทุกขณะ ข้อมูลตอนเวลา $t$ จึงเป็นเส้นทางราคาทั้งเส้นตั้งแต่เปิดตลาดจนถึง $t$ บรรทัดข้างล่างเป็นนิยาม เขียนด้วยช่วงเวลาแทนการนับกิ่ง

\[ \begin{aligned} \text{info at }9{:}45&:\ S_u,\ 9{:}30\le u\le9{:}45,\\ \text{info at }10{:}00&:\ S_u,\ 9{:}30\le u\le10{:}00,\\ \text{info at }16{:}00&:\ S_u,\ 9{:}30\le u\le16{:}00,\\ \mathbb E_t[X]&:=\mathbb E\big[X\mid W_u,\ 0\le u\le t\big]. \end{aligned} \]

สามบรรทัดแรกซ้อนกันเอง: ทุกอย่างที่รู้ตอน 9:45 ยังรู้ตอน 10:00 และทุกอย่างที่รู้ตอน 10:00 ยังรู้ตอน 16:00 ชุดข้อมูลที่โตตามเวลาแบบไม่ลืมอะไรนี้คือ filtration ไม่มีอะไรมากกว่านั้น

บรรทัดสุดท้ายนิยาม $\mathbb E_t$ ว่าเป็นค่าเฉลี่ยของ $X$ บนเส้นทางทั้งหมดที่ตรงกับสิ่งที่เห็นแล้วจนถึง $t$ แทนการเฉลี่ยบนกิ่งที่เหลือของต้นไม้ เครื่องมือสองชิ้นใช้ได้เหมือนเดิม: ของที่รู้ได้ตอน $t$ ดึงออกได้ และ $\mathbb E_s\big[\mathbb E_t[X]\big]=\mathbb E_s[X]$ เมื่อ $s\le t$

ขั้นที่ 5 — การทำนายที่ดีที่สุดของ Brownian motion คือค่าปัจจุบัน

ใช้ทริกเดียวกับต้นไม้: แยกค่าในอนาคตเป็นส่วนที่รู้แล้วบวกส่วนที่ยังไม่เกิด แล้วจัดการแต่ละก้อนด้วยเหตุผลคนละแบบ นิยาม SBM ใน 9.2 ขั้นที่ 1 บอกว่าการขยับหลังเวลา $t$ อิสระจากเส้นทางก่อนหน้าทั้งเส้น

\[ \begin{aligned} W_{t+s}&=W_t+(W_{t+s}-W_t),\\ \mathbb E_t[W_{t+s}]&=\mathbb E_t[W_t]+\mathbb E_t[W_{t+s}-W_t]\\ &=W_t+\mathbb E[W_{t+s}-W_t]\\ &=W_t+0=W_t. \end{aligned} \]

บรรทัดแรกเป็นจริงทุกเส้นทาง เพราะบวกแล้วลบ $W_t$ ตัวเดียวกัน บรรทัดที่สามคือจุดที่ใช้เหตุผลสองแบบ: $W_t$ รู้แล้วตอน $t$ ค่าเฉลี่ยของมันจึงเป็นตัวมันเอง ส่วนการขยับที่ยังไม่เกิดไม่สนว่าเห็นอะไรมาแล้ว ค่าเฉลี่ยเมื่อรู้อดีตจึงเท่ากับค่าเฉลี่ยตอนไม่รู้อะไร ซึ่งเป็นศูนย์

ผลคือ SBM เป็น martingale: คำทำนายที่ดีที่สุดของอนาคตคือค่าตอนนี้ ไม่ใช่ค่าที่หวัง ไม่ใช่ค่าเฉลี่ยของสัปดาห์ก่อน และไม่มีรูปแบบในอดีตไหนช่วยได้ เพราะอดีตทั้งเส้นอิสระจากสิ่งที่จะเกิด

ขั้นที่ 6 — กำลังสองทำนายได้: มันโตเท่าเวลาที่ผ่านไป

ถ้า $W$ ทำนายไม่ได้ แล้ว $W^2$ ล่ะ? ลองแยกแบบเดิมแล้วกระจายกำลังสอง ให้ $\Delta:=W_{t+s}-W_t$ ซึ่งมีค่าเฉลี่ย 0 และ variance $s$ ไม่ว่าจะเห็นอดีตแบบไหน

\[ \begin{aligned} W_{t+s}^2&=W_t^2+2W_t\Delta+\Delta^2,\\ \mathbb E_t[W_{t+s}^2]&=W_t^2+2W_t\,\mathbb E_t[\Delta]\\ &\quad+\mathbb E_t[\Delta^2]\\ &=W_t^2+0+s,\\ \operatorname{Var}_t(W_{t+s})&=\mathbb E_t[W_{t+s}^2]-\big(\mathbb E_t[W_{t+s}]\big)^2\\ &=W_t^2+s-W_t^2=s. \end{aligned} \]

พจน์ไขว้หายด้วยเหตุผลเดียวกับขั้นที่ 3: $W_t$ รู้แล้ว ดึงออกมาคูณกับ $\mathbb E_t[\Delta]=0$ ส่วนพจน์สุดท้ายไม่หาย เพราะกำลังสองเป็นบวกเสมอ ขึ้นหรือลงก็บวก และเมื่อค่าเฉลี่ยของ $\Delta$ เป็นศูนย์ ค่าเฉลี่ยของ $\Delta^2$ ก็คือ variance พอดี

ผลแปลกแต่สำคัญ: ระดับทำนายไม่ได้ แต่กำลังสองรู้ล่วงหน้าว่าจะโตขึ้น $s$ และ variance ที่เหลือคือ $s$ ไม่ว่าตอนนี้เส้นทางจะอยู่สูงหรือต่ำ ความไม่แน่นอนขึ้นกับเวลาที่ต้องรออย่างเดียว

ขั้นที่ 7 — หักการโตที่รู้ล่วงหน้าออก ได้ martingale ตัวที่สอง

ขั้นที่ 6 บอกว่า $W^2$ เอียงขึ้นด้วยอัตราหนึ่งหน่วยต่อหนึ่งหน่วยเวลาพอดี ถ้าหักเวลาที่ผ่านไปออก ส่วนเอียงก็หาย บรรทัดแรกเป็นนิยามที่เลือกให้พอดีกับส่วนเกินที่คำนวณไว้ ที่เหลือคือการตรวจ

\[ \begin{aligned} M_t&:=W_t^2-t,\\ \mathbb E_t[M_{t+s}]&=\mathbb E_t[W_{t+s}^2]-(t+s)\\ &=W_t^2+s-t-s\\ &=W_t^2-t=M_t. \end{aligned} \]

เวลา $t+s$ เป็นตัวเลขที่รู้แน่นอน ไม่สุ่ม จึงผ่านค่าเฉลี่ยออกมาตรง ๆ แทนขั้นที่ 6 ลงไปแล้ว $s$ สองตัวหักกันพอดี

ตรวจกับต้นไม้ของขั้นที่ 1 ได้: ทุกก้าว \$4 ทำให้ $(S-520)^2$ โตเฉลี่ย 16 ตัวที่หักแล้วคือ $(S-520)^2-16k$ เมื่อ $k$ คือจำนวนก้าว ตอน 13:00 ได้ $16-16=0$ ทั้งสองกิ่ง และตอน 16:00 ได้ $64-32$, $0-32$, $0-32$, $64-32$ เฉลี่ย 0 เท่ากับค่าเริ่ม martingale ตัวนี้คือเครื่องวัดความเสี่ยงสะสม ซึ่ง 9.5 และบทที่ 13 ใช้ต่อ

ขั้นที่ 8 — ราคาปิดที่ทำนายได้ตอน 10:00

โจทย์ให้อะไรมาบ้าง: ตอน 10:00 SPY อยู่ที่ \$520 ความผันผวน 18% ต่อปี ใช้แบบจำลองดอลลาร์ของ 9.2 ที่ $\sigma=93.60$ ดอลลาร์ต่อ $\sqrt{\text{yr}}$ ตัด drift ออกก่อน (8% ต่อปีให้แค่ \$0.15 ใน 6 ชั่วโมง) 10:00 ถึง 16:00 คือ 360 นาทีจาก 98,280 นาทีซื้อขายต่อปี

\[ \begin{aligned} S_{16}-S_{10}&=93.60\,(W_{16}-W_{10}),\\ \Delta t&=360/98{,}280\approx0.003663,\\ \sqrt{\Delta t}&\approx0.060523,\\ \mathbb E_{10}[S_{16}]&=520,\\ \operatorname{SD}_{10}(S_{16})&=93.60(0.060523)\approx5.665,\\ \mathbb E_{10}[(S_{16}-520)^2]&=5.665^2\approx32.09. \end{aligned} \]

คำตอบ: ราคาปิดที่ทำนายได้ดีที่สุดตอน 10:00 คือ \$520 เท่าราคาตอนนั้น (ขั้นที่ 5) คลาดได้หนึ่ง SD ราว \$5.66 และค่าเฉลี่ยของกำลังสองของการขยับคือ 32.09 ซึ่งรู้ล่วงหน้าตามขั้นที่ 6 ถ้าใส่ drift 8% คำทำนายขยับเพียง $520(0.08)(0.003663)\approx\$0.15$

ตรวจเองใน 10 วินาที: 360 นาทีคือ $360/390$ ของวัน SD หนึ่งวันใน 9.1 คือ \$5.896 คูณ $\sqrt{0.923}\approx0.961$ ได้ราว \$5.66

ขั้นที่ 9 — ราคาของการรั่ว: ทำไม backtest ได้ Sharpe 21

โจทย์ให้อะไรมาบ้าง: กฎที่รั่วคือถือ $\operatorname{sign}(S_{16}-S_{10})$ หุ้น กำไรต่อวันจึงเป็น $|S_{16}-S_{10}|=5.665|Z|$ จากขั้นที่ 8 ใช้ $\mathbb E|Z|=\sqrt{2/\pi}$ จาก 9.2 และ $\mathbb E[Z^2]=1$

\[ \begin{aligned} \mathbb E[\text{P\&L}]&=5.665(0.797885)\approx4.520,\\ \operatorname{SD}(|Z|)&=\sqrt{1-2/\pi}\approx0.602810,\\ \operatorname{SD}(\text{P\&L})&=5.665(0.602810)\approx3.415,\\ \text{Sharpe}_{\text{day}}&=4.520/3.415\approx1.324,\\ \text{Sharpe}_{\text{year}}&=1.324\sqrt{252}\approx21.0. \end{aligned} \]

คำตอบ: กฎที่เห็นราคาปิดได้เงินเฉลี่ย \$4.52 ต่อหุ้นต่อวัน ไม่มีวันขาดทุนเพราะกำไรคือขนาดการขยับ และได้ Sharpe รายปี 21.0 พอดีกับ backtest ในโจทย์เปิดเรื่อง ส่วนกฎที่ซื่อสัตย์ทุกแบบได้ศูนย์ตามขั้นที่ 3 โค้ดท้ายหน้าจำลอง 1,260 วัน (ห้าปีของวันทำการ 252 วัน) ด้วย seed 931: กฎที่รั่วได้ Sharpe 21.1 และขาดทุน 0 วัน ส่วนกฎที่ใช้สัญญาณตอนเช้าได้ Sharpe −0.12 และขาดทุน 641 วัน

ตรวจเองใน 10 วินาที: Sharpe รายวัน $0.798/0.603\approx1.32$ ไม่ขึ้นกับขนาด SD เลย และ $\sqrt{252}\approx15.9$ คูณกันได้ราว 21

ขั้นที่ 10 — ตรวจ feature ทีละตัว: จบที่เวลาไหน

โจทย์ให้อะไรมาบ้าง: เวลาตัดสินใจคือ 10:00 กฎมีข้อเดียว: feature ใช้ได้ก็ต่อเมื่อข้อมูลทุกตัวที่ใช้คำนวณมันมาถึงไม่เกิน 10:00 ดูที่เวลาที่ข้อมูลมาถึง ไม่ใช่วันที่ที่ประทับบนแถว

คำถามที่ควรถามออกมาดัง ๆ

ถ้า martingale ทำนายไม่ได้ ทำไมคนยังทำ backtest? ขั้นที่ 5 เป็นผลของแบบจำลองที่สมมติว่าการขยับอิสระจากอดีต คำถามของ backtest คือข้อมูลจริงหลุดจากสมมติฐานนั้นหรือเปล่า ซึ่งตอบได้ก็ต่อเมื่อ backtest ใช้แต่ข้อมูลที่รู้ได้จริง ถ้ารั่ว มันจะเจอกำไรเสมอ แม้ในโลกที่ไม่มีอะไรให้เจอ

“เป็น martingale” เป็นสมบัติของราคาเองหรือ? ไม่ใช่ มันขึ้นกับข้อมูลชุดที่ใช้เฉลี่ย ในต้นไม้ ถ้าให้ข้อมูลตอน 13:00 รวมราคา 16:00 ด้วย คำทำนายจะเป็น $S_{16}$ เอง ไม่ใช่ $S_{13}$ ราคาจึงไม่เป็น martingale เทียบกับข้อมูลที่รั่ว การพูดว่า martingale ต้องบอกเสมอว่าเทียบกับ filtration ไหน

การรั่วที่มองไม่เห็นในโค้ด

วันที่ของข้อมูลไม่ใช่เวลาที่ข้อมูลมาถึง: งบบริษัทที่ประกาศหลังตลาดปิด ตัวเลขเศรษฐกิจที่ถูกแก้ย้อนหลัง และรายชื่อหุ้นที่ตัดบริษัทล้มละลายออกไป ทั้งหมดทำให้ข้อมูลในฐานข้อมูลวันนี้ต่างจากสิ่งที่ตลาดเห็นในวันนั้น ต้องใช้ข้อมูลรุ่นที่มีอยู่จริง ณ เวลานั้น

รู้ได้ ไม่ได้แปลว่าทำนายเก่ง: feature ที่ผ่านการตรวจขั้นที่ 10 แค่ไม่โกงเวลา ในแบบจำลองของหน้านี้มันยังได้ศูนย์ตามขั้นที่ 3 ความสามารถทำนายต้องพิสูจน์แยกด้วยสถิติของบทที่ 3

สามโจทย์ตรวจความเข้าใจ

1. ในต้นไม้ของขั้นที่ 1 หา $\mathbb E_{13}[(S_{16}-520)^2]$ ของแต่ละกิ่ง แล้วตรวจว่าเท่ากับ $(S_{13}-520)^2+16$ ตามขั้นที่ 6

เฉลย

2. ตอน 13:00 SPY อยู่ที่ \$523 ใช้แบบจำลองดอลลาร์เดิม $\sigma=93.60$ ไม่มี drift ราคาปิดที่ทำนายได้ดีที่สุดคือเท่าไร คลาดได้หนึ่ง SD เท่าไร?

เฉลย

// Two-step tree: SPY 520 at 10:00, moves +/-4 by 13:00 and again by 16:00, each with probability 1/2.
function tree(S0, step) {
  if (!(S0 > 0) || !(step > 0)) throw new RangeError('Need S0 > 0 and step > 0');
  const paths = [];
  for (const a of [1, -1]) for (const b of [1, -1]) {
    paths.push({first: a, S13: S0 + a * step, S16: S0 + (a + b) * step, p: 0.25});
  }
  return paths;
}
// Average of f over the paths that agree with what is known: `known` maps a path to its visible part.
function conditional(paths, known, f) {
  const groups = new Map();
  for (const x of paths) {
    const key = JSON.stringify(known(x));
    const g = groups.get(key) || {p: 0, sum: 0};
    g.p += x.p; g.sum += x.p * f(x);
    groups.set(key, g);
  }
  return [...groups].map(([key, g]) => ({known: JSON.parse(key), value: g.sum / g.p, p: g.p}));
}
const mean = (paths, f) => paths.reduce((s, x) => s + x.p * f(x), 0);
// A feature is usable at the decision time only if its data window ends at or before that time.
function usable(feature, decisionMinute) {
  if (!feature || !Number.isFinite(feature.endsAt) || !Number.isFinite(decisionMinute)) {
    throw new TypeError('Need a feature with a numeric endsAt and a numeric decision time');
  }
  return feature.endsAt <= decisionMinute;
}
// Brownian forecast of the close from 10:00: price in dollars = S + sigma$ * (W_u - W_10).
function closeForecast(S, sigmaDollars, minutesLeft, minutesPerYear = 252 * 390) {
  if (![S, sigmaDollars, minutesLeft].every(Number.isFinite) || sigmaDollars < 0 || minutesLeft < 0) {
    throw new RangeError('Need finite S, sigma >= 0 and minutes left >= 0');
  }
  const sd = sigmaDollars * Math.sqrt(minutesLeft / minutesPerYear);
  return {mean: S, sd, meanSquare: sd * sd};
}
// mulberry32 + Box-Muller: seeded standard Normals.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Backtest over simulated days: position h is chosen at 10:00, P&L = h * (close - price at 10:00).
function backtest(days, sd, rule, seed) {
  if (!Number.isInteger(days) || days < 2 || !(sd > 0) || typeof rule !== 'function') throw new RangeError('Need days >= 2, sd > 0 and a rule');
  const z = normals(seed), pnl = [];
  for (let d = 0; d < days; d++) {
    const morning = z(), move = sd * z(); // morning: a signal known at 10:00; move: 10:00 -> 16:00
    pnl.push(rule(morning, move) * move);
  }
  const m = pnl.reduce((s, x) => s + x, 0) / days;
  const v = pnl.reduce((s, x) => s + (x - m) ** 2, 0) / (days - 1);
  return {mean: m, sd: Math.sqrt(v), sharpeYear: m / Math.sqrt(v) * Math.sqrt(252), losingDays: pnl.filter(x => x < 0).length};
}
const paths = tree(520, 4);
const at13 = conditional(paths, x => x.first, x => x.S16);
const honest = mean(paths, x => Math.sign(x.S13 - 520) * (x.S16 - x.S13));
const leaky = mean(paths, x => Math.sign(x.S16 - x.S13) * (x.S16 - x.S13));
const square13 = conditional(paths, x => x.first, x => (x.S16 - 520) ** 2);
const spy = closeForecast(520, 520 * 0.18, 360);
const absZ = Math.sqrt(2 / Math.PI), sdAbsZ = Math.sqrt(1 - 2 / Math.PI);
const features = {
  yesterdayClose: {endsAt: -30}, highTo10: {endsAt: 30}, dailyHigh: {endsAt: 390},
  dailyVWAP: {endsAt: 390}, close: {endsAt: 390}, earningsAt1605: {endsAt: 395}
};

ที่มาที่ไป

คำว่า martingale เดิมเป็นชื่อระบบพนันในฝรั่งเศสที่เพิ่มเงินเดิมพันเป็นสองเท่าทุกครั้งที่แพ้ (4.3) Paul Lévy ใช้คำนี้ในทางคณิตศาสตร์ช่วงทศวรรษ 1930 และ Joseph Doob วางทฤษฎีให้เป็นระบบในหนังสือปี 1953 ในการเงิน Harrison กับ Kreps (1979) และ Harrison กับ Pliska (1981) ใช้ filtration และ martingale เขียนเงื่อนไขว่าตลาดไม่มีกำไรที่ไร้ความเสี่ยง ซึ่งเป็นฐานของการตั้งราคาในบทที่ 13 และ 14
