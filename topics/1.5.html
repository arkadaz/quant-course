1.5 The Binomial Distribution

นับจำนวนครั้งที่สำเร็จ และแยกผลงานที่พบได้ด้วยโอกาสออกจากหลักฐานเรื่องฝีมือ

ผู้จัดการกองทุนทำผลตอบแทนชนะ S&P 500 ได้ 8 ปีจาก 10 ปี ฟังดูน่าประทับใจ แต่เราควรถามต่อว่าอะไร: โอกาสชนะคือ 80% หรือถ้าแต่ละปีมีโอกาสชนะเพียงครึ่งหนึ่ง ผลงานระดับนี้เกิดได้ยากแค่ไหน?

สองคำถามนี้ไม่เหมือนกัน 80% เป็นสัดส่วนที่เห็นในข้อมูล ส่วนคำถามหลังต้องสร้างแบบจำลองแล้วคำนวณโอกาส เราจะเริ่มจากแบบจำลองง่ายที่สุดก่อน และดูว่าคำตอบเปลี่ยนอย่างไรเมื่อเลือกผู้จัดการที่ดีที่สุดจากหลายคน

สิ่งที่ Binomial นับ และเงื่อนไขที่ต้องกำหนด

Binomial distribution ใช้นับจำนวนครั้งที่เกิดเหตุการณ์ที่สนใจจากการทดลองจำนวนแน่นอน $n$ ครั้ง โดยแต่ละครั้งมีสองสถานะ: สำเร็จหรือไม่สำเร็จ โอกาสสำเร็จเท่ากับ $p$ เหมือนกันทุกครั้ง และผลแต่ละครั้งเป็นอิสระต่อกัน

คำว่า “สำเร็จ” เป็นเพียงชื่อสถานะที่เราจะนับ อาจเป็นการชนะ benchmark การผิดนัดชำระ หรือชิ้นงานที่เสียก็ได้ ไม่จำเป็นต้องเป็นสิ่งที่ดี ให้ $X$ เป็นจำนวนสำเร็จทั้งหมด จึงมีค่าตั้งแต่ 0 ถึง $n$

ระบุแบบจำลองของโจทย์ผู้จัดการให้ครบก่อนคำนวณ

ส่วนของแบบจำลองสิ่งที่กำหนดในตัวอย่าง
หนึ่งครั้งคืออะไรผลการดำเนินงานหนึ่งปี โดยเปรียบเทียบผลตอบแทนบนฐานเดียวกัน
นับอะไรเป็นสำเร็จผลตอบแทนสูงกว่า S&P 500; ต้องกำหนดการหักค่าธรรมเนียมและกรณีเท่ากันให้ชัด
จำนวนครั้ง$n=10$ ปีที่กำหนดไว้ก่อนดูผล
โอกาสภายใต้สมมติฐานตั้งต้น$p=0.5$ ทุกปี เป็นสมมติฐานสำหรับเปรียบเทียบ ไม่ใช่นิยามว่าผู้จัดการที่ไม่มีฝีมือต้องมีโอกาสชนะครึ่งหนึ่งเสมอ
ความสัมพันธ์ระหว่างปีสมมติว่าผลชนะหรือไม่ชนะในแต่ละปีเป็นอิสระกัน

หากกลยุทธ์ สภาวะตลาด หรือโอกาสชนะเปลี่ยนตามปี หรือผลหลายปีสัมพันธ์กัน Binomial แบบนี้อาจไม่ตรงโจทย์ การคำนวณสูตรถูกไม่ได้ยืนยันว่าเงื่อนไขเหล่านี้จริง

เริ่มจากลำดับเดียว ก่อนรวมทุกลำดับที่ให้จำนวนเท่ากัน

ทอยเหรียญยุติธรรมสามครั้ง ลำดับหัว–หัว–ก้อยมีโอกาส $(1/2)^3=1/8$ แต่เหตุการณ์ “ออกหัวสองครั้ง” มีอีกสองลำดับคือหัว–ก้อย–หัวและก้อย–หัว–หัว จึงมีโอกาส $3/8$

หลักเดียวกันใช้กับสิบปี ลำดับที่ชนะแปดปีแรกแล้วแพ้สองปีสุดท้ายเป็นเพียงหนึ่งลำดับ หากถาม “ชนะแปดปี” โดยไม่ระบุว่าปีใด ต้องรวมทุกตำแหน่งของสองปีที่แพ้ด้วย

ขั้นที่ 1 — หาโอกาสของลำดับที่ระบุไว้หนึ่งลำดับ

ภายใต้ independence ลำดับที่มีความสำเร็จ $r$ ครั้งและไม่สำเร็จ $n-r$ ครั้งมีโอกาสเป็นผลคูณของทั้ง $n$ ครั้ง

\[ \begin{aligned} P(\text{one specified sequence})&=p^r(1-p)^{n-r}\\ P(\text{WWWWWWWWLL})&=(0.5)^8(0.5)^2\\ &=(0.5)^{10}=\frac{1}{1{,}024} \end{aligned} \]

W แทนปีที่ชนะและ L แทนปีที่ไม่ชนะ ทุกลำดับที่มีจำนวน W เท่ากันมีโอกาสเท่ากันภายใต้ $p$ คงที่ แต่ถ้า $p$ เปลี่ยนตามปี ความเท่ากันนี้จะไม่ตามมาโดยอัตโนมัติ

ขั้นที่ 2 — นับจำนวนลำดับโดยไม่สลับนับซ้ำ

ชนะแปดจากสิบปีเท่ากับเลือกสองปีที่ไม่ชนะ เลือกปีแรกได้สิบแบบและปีที่สองได้เก้าแบบ แต่แต่ละคู่ถูกนับสองครั้ง เช่น คู่ปี 2 กับปี 7 จึงต้องหารด้วยสอง

\[ \begin{aligned} \#\{\text{8 wins in 10 years}\}&=\frac{10\times9}{2\times1}=45\\ \#\{\text{9 wins in 10 years}\}&=10\\ \#\{\text{10 wins in 10 years}\}&=1\\[4pt] \binom nr&\equiv\frac{n(n-1)\cdots(n-r+1)}{r!}\\ &=\frac{n!}{r!(n-r)!} \end{aligned} \]

$\binom nr$ อ่านว่า “เลือก $r$ ตำแหน่งจาก $n$ ตำแหน่ง” ตัวเศษนับการเลือกแบบเรียงลำดับ ตัวหาร $r!$ ตัดลำดับที่ต่างกันแต่ได้ตำแหน่งชุดเดิมออก ส่วน $r!$ คือผลคูณ $r(r-1)\cdots1$

เลือกตำแหน่งชนะหรือเลือกตำแหน่งแพ้ให้จำนวนเท่ากัน จึงได้ $\binom{10}{8}=\binom{10}{2}=45$ กรณีเลือกศูนย์ตำแหน่งมีหนึ่งวิธีคือไม่เลือกอะไรเลย จึงใช้ข้อตกลง $0!=1$ ให้สูตรครอบคลุมกรณีขอบด้วย

ขั้นที่ 3 — รวมลำดับที่ไม่ซ้ำกันเป็น Binomial PMF

ลำดับต่างกันเกิดพร้อมกันไม่ได้ในชุดทดลองเดียว เราจึงนำจำนวนลำดับคูณโอกาสของแต่ละลำดับ เขียนย่อว่า $X\sim\mathrm{Binomial}(n,p)$

\[ \begin{aligned} P(X=r)&=\binom nr p^r(1-p)^{n-r},\quad r=0,\ldots,n\\ P(X=8)&=45(0.5)^8(0.5)^2\\ &=\frac{45}{1{,}024}\approx4.3945\%\\ P(X=9)&=\frac{10}{1{,}024}\approx0.9766\%\\ P(X=10)&=\frac{1}{1{,}024}\approx0.0977\% \end{aligned} \]

PMF แบ่งผลลัพธ์ทั้งหมดตามจำนวนสำเร็จ ตั้งแต่ศูนย์ถึงสิบครั้ง แต่ละลำดับตกอยู่ในกลุ่มเดียว จึงไม่มีการนับซ้ำหรือตกหล่น เมื่อรวม PMF ทุกค่าแล้วต้องได้หนึ่ง เช่นเดียวกับกฎ PMF ในหัวข้อ 1.2

Worked Example — อย่างน้อยแปดปี ไม่ใช่แปดปีพอดี

ของที่มี: $X\sim\mathrm{Binomial}(10,0.5)$

คำถาม: ถ้ากำหนดเกณฑ์ผลงานไว้ว่าชนะอย่างน้อยแปดปี โอกาสผ่านเกณฑ์เป็นเท่าไร?

ให้เลือกแถวของ PMF ที่ผ่านเกณฑ์ก่อน ได้แก่ 8, 9 และ 10 ปี จากนั้นจึงบวกโอกาส ไม่ใช้เพียงแถว 8 ปี

ขั้นที่ 4 — รวมโอกาสหางที่ตรงกับคำถาม

\[ \begin{aligned} q\equiv P(X\ge8)&=P(X=8)+P(X=9)+P(X=10)\\ &=\frac{45+10+1}{1{,}024}\\ &=\frac{56}{1{,}024}\\ &=\boxed{5.46875\%} \end{aligned} \]

ภายใต้แบบจำลองที่ให้ ผู้จัดการซึ่งระบุไว้ล่วงหน้ามีโอกาสผ่านเกณฑ์นี้ประมาณ 5.47% ตัวเลขไม่ได้แปลว่ามีโอกาส “ไม่มีฝีมือ” 5.47% เพราะเราเพิ่งคำนวณโอกาสเห็นผลงานเมื่อกำหนดแบบจำลอง ไม่ได้คำนวณโอกาสของแบบจำลองหลังเห็นผลงาน

ตรวจคำตอบด้วยการนับลำดับทั้งหมด

ในสิบปีมีลำดับ W/L ทั้งหมด $2^{10}=1{,}024$ ลำดับ ภายใต้ $p=0.5$ และ independence ทุกลำดับมีโอกาสเท่ากัน มี 45 ลำดับที่ชนะแปดปี 10 ลำดับที่ชนะเก้าปี และหนึ่งลำดับที่ชนะสิบปี รวม 56 ลำดับจาก 1,024

ตรวจเองใน 10 วินาที: โอกาสชนะอย่างน้อยแปดปีต้องมากกว่าโอกาสชนะแปดปีพอดี และมากกว่าโอกาสชนะสิบปีเสมอ หากได้ผลกลับกัน ให้ตรวจขอบเขตผลรวม

ค่าเฉลี่ยและ variance ของจำนวนสำเร็จมาจากไหน

แทนผลการทดลองครั้งที่ $i$ ด้วยตัวแปร $B_i$ ซึ่งเป็น 1 เมื่อสำเร็จ และ 0 เมื่อไม่สำเร็จ ตัวแปรสองค่านี้เรียกว่า Bernoulli จากนั้นจำนวนสำเร็จรวมคือ $X=B_1+\cdots+B_n$

เพราะ $B_i$ มีเพียง 0 กับ 1 การยกกำลังสองไม่เปลี่ยนค่า จึงคำนวณ variance ได้จากสูตรที่เรียนในหัวข้อ 1.4 แล้วจึงบวกข้ามครั้งภายใต้ independence

ขั้นที่ 5 — สร้างค่าเฉลี่ยและ variance จาก Bernoulli

\[ \begin{aligned} \mathbb E[B_i]&=1(p)+0(1-p)=p\\ \mathbb E[B_i^2]&=1^2(p)+0^2(1-p)=p\\ \mathrm{Var}(B_i)&=p-p^2=p(1-p)\\[3pt] \mathbb E[X]&=\sum_{i=1}^n\mathbb E[B_i]=np\\ \mathrm{Var}(X)&=\sum_{i=1}^n\mathrm{Var}(B_i)=np(1-p)\\ \mathrm{SD}(X)&=\sqrt{np(1-p)}\\[3pt] n=10,\ p=0.5&:\quad\mathbb E[X]=5,\quad\mathrm{Var}(X)=2.5\\ &\mathrm{SD}(X)=\sqrt{2.5}\approx1.5811 \end{aligned} \]

ค่าเฉลี่ยห้าครั้งไม่แปลว่าทุกชุดต้องสำเร็จห้าครั้ง ส่วน standard deviation ประมาณ 1.58 มีหน่วยเป็นจำนวนครั้ง ไม่ใช่เปอร์เซ็นต์หรือเงิน สูตรค่าเฉลี่ยใช้ additivity แต่การบวก variance ในขั้นนี้อาศัย covariance ที่เป็นศูนย์จาก independence

ขั้นที่ 6 — ทำไมจำนวนสำเร็จจึงผันผวนที่สุดเมื่อ $p=0.5$

เมื่อจำนวนครั้ง $n$ คงที่ ความต่างของ variance อยู่ที่ $p(1-p)$ เขียนใหม่ด้วยการเติมกำลังสองได้โดยไม่ต้องใช้อนุพันธ์

\[ \begin{aligned} p(1-p)&=p-p^2\\ &=\frac14-\left(p-\frac12\right)^2\\ &\le\frac14\\ \mathrm{Var}(X)&\le\frac n4 \end{aligned} \]

กำลังสองไม่ติดลบ ค่าสูงสุดจึงเกิดเมื่อ $p=1/2$ ส่วน $p=0$ หรือ 1 ให้จำนวนสำเร็จแน่นอนเป็นศูนย์หรือ $n$ จึงมี variance ศูนย์ ข้อนี้พูดถึงความผันผวนของจำนวนสำเร็จภายใต้ $n$ เดิม ไม่ใช่ข้อสรุปว่ากลยุทธ์ที่ชนะครึ่งหนึ่งเสี่ยงที่สุดในหน่วยเงิน

ถ้าใช้ Normal ประมาณ ต้องแปลงขอบจำนวนเต็มให้ถูก

เมื่อทั้ง $np$ และ $n(1-p)$ มากพอ รูปร่าง Binomial อาจประมาณด้วย Normal ที่มีค่าเฉลี่ย $np$ และ variance $np(1-p)$ ได้ เกณฑ์อย่างทั้งสองค่าไม่น้อยกว่า 10 เป็นเพียงแนวทางเบื้องต้น ไม่ใช่ข้อรับประกันความแม่นยำของหางทุกระดับ

ในตัวอย่าง $n=10,p=0.5$ ทั้งสองค่ามีเพียง 5 เราจึงใช้สูตร Binomial เป็นคำตอบหลัก และลอง Normal เพื่อดูข้อผิดพลาด ถ้าถาม $X\ge8$ ให้มองแท่งที่ 8 เป็นช่วงรอบจำนวนเต็มตั้งแต่ 7.5 ถึง 8.5 ขอบหางจึงเริ่มที่ 7.5 ไม่ใช่ 8 วิธีนี้เรียกว่า continuity correction

ขั้นที่ 7 — เปรียบเทียบ Normal กับคำตอบที่นับได้

ให้ $Y$ เป็น Normal approximation ของ $X$ และ $\Phi$ เป็น CDF ของ Standard Normal

\[ \begin{aligned} P(X\ge8)&\approx P(Y\gt7.5)\\ &=1-\Phi\!\left(\frac{7.5-5}{\sqrt{2.5}}\right)\\ &=1-\Phi(1.5811)\approx5.69\%\\[3pt] P(Y\gt8)&=1-\Phi\!\left(\frac{8-5}{\sqrt{2.5}}\right)\\ &\approx2.89\%\\[3pt] P(X\ge8)&=5.46875\%\quad\text{(Binomial)} \end{aligned} \]

ในตัวอย่างนี้ continuity correction ทำให้ค่าประมาณใกล้คำตอบจริงขึ้นมาก แต่ไม่ได้ทำให้ตรงพอดี ส่วนการไม่ปรับขอบให้ค่าต่ำไปมาก ถ้าคำนวณ Binomial โดยตรงได้อยู่แล้ว ไม่มีเหตุผลต้องเลือกค่าประมาณเพียงเพราะคุ้นกับ Normal

เปลี่ยนคำถาม: ไม่ได้เลือกผู้จัดการคนนี้ไว้ก่อน แต่เลือกจาก 100 คน

โอกาส 5.47% ใช้กับคนหนึ่งที่ระบุไว้ก่อนดูผล หากเราค้นจากผู้จัดการ 100 คนแล้วนำคนที่ผลงานดีที่สุดมาเสนอ เรามีโอกาสพบคนผ่านเกณฑ์ได้หลายทาง ต้องคิดโอกาสของกระบวนการคัดเลือกด้วย

สำหรับแบบฝึกนี้ ให้ผู้จัดการทุกคนใช้แบบจำลองสิบปีเดิม และเพิ่มสมมติฐานอีกข้อว่าผลการผ่านเกณฑ์ของแต่ละคนเป็นอิสระกัน ความเป็นอิสระข้ามคนเป็นคนละข้อกับความเป็นอิสระข้ามปีที่ใช้สร้าง Binomial ของแต่ละคน

ขั้นที่ 8 — คำนวณโอกาสที่มีอย่างน้อยหนึ่งคนผ่านเกณฑ์

ให้ $M$ เป็นจำนวนคน และให้ $q=56/1024$ เป็นโอกาสผ่านเกณฑ์ของคนหนึ่ง เริ่มจากเหตุการณ์ตรงข้าม คือไม่มีใครผ่านเลย

\[ \begin{aligned} P(\text{one manager fails})&=1-q\\ P(\text{all }M\text{ fail})&=(1-q)^M\\ P(\text{at least one passes})&=1-(1-q)^M\\ M=100&:\quad1-\left(1-\frac{56}{1024}\right)^{100}\\ &\approx\boxed{99.64\%}\\[3pt] \mathbb E[\text{number passing}]&=Mq\\ &=100\left(\frac{56}{1024}\right)=5.46875 \end{aligned} \]

ภายใต้แบบจำลองนี้ การพบอย่างน้อยหนึ่งคนชนะตั้งแต่แปดปีขึ้นไปแทบไม่ใช่เรื่องน่าแปลกใจ ค่าเฉลี่ยจำนวนคนที่ผ่านคือประมาณ 5.47 คนต่อกลุ่ม 100 คน ไม่จำเป็นต้องเป็นจำนวนเต็ม เพราะเป็นค่าเฉลี่ยของจำนวนคน ส่วนสูตร $Mq$ ไม่ต้องใช้ independence ข้ามคน แต่สูตรโอกาสอย่างน้อยหนึ่งคนใช้

ยกระดับเกณฑ์แล้วโอกาสค้นพบคนผ่านเปลี่ยนอย่างไร

เกณฑ์ในสิบปีโอกาสของคนที่เลือกไว้ก่อนอย่างน้อยหนึ่งคนจาก 100 คนอิสระ
ชนะอย่างน้อย 8 ปี$56/1024\approx5.47\%$ประมาณ 99.64%
ชนะอย่างน้อย 9 ปี$11/1024\approx1.07\%$ประมาณ 66.04%
ชนะครบ 10 ปี$1/1024\approx0.0977\%$ประมาณ 9.31%

แต่ละค่าคอลัมน์ขวาใช้ $1-(1-q)^{100}$ ด้วย $q$ ของแถวนั้น หากเพิ่มจำนวนผู้จัดการเป็น 1,000 คน โอกาสพบอย่างน้อยหนึ่งคนชนะครบสิบปีจะเพิ่มเป็นประมาณ 62.36% ภายใต้สมมติฐาน independence เดิม

โอกาสเห็นผลงาน ไม่ใช่โอกาสที่ผู้จัดการมีฝีมือ

ถ้าเปลี่ยนเป็นอีกแบบจำลองที่ให้โอกาสชนะ 0.60 ทุกปี จะได้โอกาสชนะอย่างน้อยแปดจากสิบปีประมาณ 16.73% เทียบกับ 5.47% ภายใต้ $p=0.5$ เหตุการณ์ผ่านเกณฑ์จึงเกิดได้บ่อยกว่าประมาณ 3.06 เท่าในแบบจำลองแรก

แต่ห้ามแปลเป็นโอกาสมีฝีมือ 16.73% หรือ 94.53% การหาความน่าจะเป็นของแบบจำลองหลังเห็นข้อมูลต้องมีโอกาสก่อนเห็นข้อมูลและแบบจำลองทางเลือกด้วย ซึ่งเป็นหน้าที่ของ Bayes' theorem ในหัวข้อ 1.7 อีกทั้งถ้าข้อมูลที่สังเกตคือ “แปดปีพอดี” ต้องใช้โอกาสของข้อมูลนั้น ไม่ใช่หางตั้งแต่แปดปีโดยอัตโนมัติ

ลองทำเอง 1 — ชนะ 80% เท่ากัน แต่จำนวนข้อมูลต่างกัน

ใช้สมมติฐาน $p=0.5$ และ independence เหมือนเดิม เปรียบเทียบโอกาสชนะอย่างน้อย 8 จาก 10 ปี อย่างน้อย 16 จาก 20 ปี และอย่างน้อย 40 จาก 50 ปี เหตุใดเปอร์เซ็นต์ชนะเท่ากันจึงให้หลักฐานไม่เท่ากัน?

เปิดคำตอบและสูตรที่ใช้ตรวจ

คำนวณแต่ละกรณีด้วย $P(X\ge k)=\sum_{r=k}^{n}\binom nr(0.5)^n$ ได้ประมาณ 5.46875%, 0.590897% และ 0.00119307% ตามลำดับ

สัดส่วน 80% อยู่สูงกว่าค่าเฉลี่ยสัดส่วน 50% เท่าเดิม แต่เมื่อมีข้อมูลอิสระมากขึ้น ความผันผวนของสัดส่วนลดลง จึงเกิดความเบี่ยงเบนระดับนี้ได้ยากขึ้นภายใต้แบบจำลองเดิม การตีความยังต้องตรวจว่าข้อมูลแต่ละปีเป็นอิสระและใช้ $p$ เดียวกันจริงหรือไม่

ลองทำเอง 2 — เชื่อมกลับไปยัง PMF การซื้อขาย

แบบจำลอง TSLA มีโอกาสได้ +2R เท่ากับ 0.30 ต่อครั้ง สมมติว่าซื้อขาย 20 ครั้งอย่างเป็นอิสระด้วยโอกาสเดิม ให้ $K$ เป็นจำนวนครั้งที่ได้ +2R จงหา distribution ค่าเฉลี่ย และ variance ของ $K$ แล้วตอบว่าใช้ $K$ เพียงตัวเดียวหากำไรรวมได้หรือไม่

เปิดคำตอบ

$K\sim\mathrm{Binomial}(20,0.30)$ จึงมีค่าเฉลี่ย $20(0.30)=6$ ครั้ง และ variance $20(0.30)(0.70)=4.2$ ครั้ง²

$K$ ยังไม่กำหนดกำไรรวม เพราะครั้งที่ไม่ได้ +2R แบ่งเป็นขาดทุน −1R หรือเท่าทุน 0R ได้ต่างกัน Binomial นับเพียงเหตุการณ์สำเร็จที่กำหนด ไม่ได้เก็บขนาดกำไรขาดทุนทุกกรณีแทน PMF เดิม

ตรวจเองใน 10 วินาที: ถ้าสองชุดมีจำนวนชนะเท่ากัน แต่ชุดหนึ่งมีการขาดทุนมากกว่าและเท่าทุนน้อยกว่า กำไรรวมย่อมต่างกัน แม้ค่า $K$ จะเท่ากัน

ก่อนใช้กับข้อมูลจริง ต้องตรวจข้อไหน

เงื่อนไขเหตุที่อาจไม่ตรงกับข้อมูลผลต่อการตีความ
$n$ กำหนดไว้ก่อนเลือกช่วงเวลาที่ผลงานดีที่สุดหลังเห็นข้อมูล หรือหยุดเมื่อผลดูดีต้องรวมกติกาเลือกช่วงหรือหยุดเข้ากับการประเมิน ไม่ใช้หางของ $n$ ที่เลือกย้อนหลังอย่างเดียว
$p$ คงที่เปลี่ยนกลยุทธ์ ผู้จัดการ หรือสภาวะตลาดจำนวนสำเร็จอาจไม่เป็น Binomial ที่มีพารามิเตอร์เดียวตลอด
อิสระข้ามครั้งหลายปีได้รับแรงขับจากแนวโน้มเดียวกันโอกาสของลำดับและ variance อาจต่างจากแบบจำลอง
อิสระข้ามคนเมื่อใช้สูตรค้นหลายคนผู้จัดการถือหุ้นหรือใช้แนวคิดคล้ายกันสูตร $1-(1-q)^M$ อาจใช้ไม่ได้ แม้ค่าเฉลี่ยจำนวนคนผ่านยังเป็นผลรวมของโอกาสรายคน
ข้อมูลครบตามกลุ่มที่ตั้งใจศึกษาเห็นเฉพาะกองทุนที่รอดหรือเฉพาะผลงานที่ถูกเผยแพร่ต้องตรวจ selection bias และ survivorship bias ก่อนสรุปเรื่องฝีมือ
ศัพท์สำหรับกลับมาทบทวน
Bernoulli / Binomial
Bernoulli แทนสถานะสำเร็จของครั้งเดียวด้วย 0 หรือ 1 ส่วน Binomial นับผลรวมของ Bernoulli จำนวนแน่นอนที่เป็นอิสระและมีโอกาสสำเร็จเท่ากัน
combination / factorial
combination นับการเลือกตำแหน่งโดยไม่สนใจลำดับ ส่วน factorial นับการเรียงตำแหน่งที่ต่างกัน และใช้ตัดการนับซ้ำในสูตรเลือกตำแหน่ง
null model / tail probability
null model คือแบบจำลองตั้งต้นที่ใช้เปรียบเทียบ ส่วน tail probability คือโอกาสของผลลัพธ์ที่ผ่านเกณฑ์ที่กำหนด ไม่ใช่โอกาสที่แบบจำลองตั้งต้นเป็นจริง
continuity correction
การปรับขอบประมาณครึ่งหน่วยเมื่อใช้ distribution ต่อเนื่องประมาณเหตุการณ์บนจำนวนเต็ม ต้องเริ่มจากดูว่าโจทย์รวมจำนวนเต็มใดบ้าง
multiple comparisons / survivorship bias
การค้นหลายคนหรือหลายแบบเพิ่มโอกาสพบผลเด่น ส่วนการเห็นเฉพาะผู้รอดทำให้กลุ่มข้อมูลไม่แทนคนทั้งหมดที่เริ่มต้น ทั้งสองอาจทำให้ผลงานดูน่าเชื่อถือเกินจริง
สัญลักษณ์ที่ใช้ในโจทย์การนับ
สัญลักษณ์ความหมาย
$n,p,X,r$จำนวนครั้ง โอกาสสำเร็จต่อครั้ง จำนวนสำเร็จที่เป็นตัวแปรสุ่ม และจำนวนที่กำลังคำนวณโอกาส
$\binom nr$จำนวนวิธีเลือกตำแหน่งสำเร็จ $r$ ตำแหน่งจาก $n$
$B_i$ตัวแปร 0/1 ที่ระบุว่าครั้งที่ $i$ สำเร็จหรือไม่
$q,M$โอกาสที่คนหนึ่งผ่านเกณฑ์ / จำนวนคนที่ค้น ไม่ใช่พารามิเตอร์เดียวกับ $p,n$
$\Phi$CDF ของ Standard Normal ที่ใช้ในส่วนการประมาณ
ตรวจหาง Binomial และผลของการค้นหลายคนด้วย JavaScript 
function choose(n, r) {
  let result = 1;
  for (let j = 1; j <= Math.min(r, n - r); j++) {
    result = result * (n - j + 1) / j;
  }
  return result;
}
function tail(n, p, k) {
  let total = 0;
  for (let r = k; r <= n; r++) {
    total += choose(n, r) * p ** r * (1 - p) ** (n - r);
  }
  return total;
}
const q = tail(10, 0.5, 8);
console.log(q);                         // 0.0546875
console.log(tail(10, 0.5, 0));           // 1: PMF รวมครบทุกค่า
console.log(1 - (1 - q) ** 100);        // ประมาณ 0.9963897
console.log(tail(20, 0.5, 16));          // ประมาณ 0.005908966
console.log(tail(50, 0.5, 40));          // ประมาณ 0.00001193067
console.log(tail(10, 0.6, 8));           // ประมาณ 0.167289754

โค้ดนี้เหมาะกับขนาดโจทย์ที่แสดง ไม่ใช่ไลบรารีสถิติสำหรับ $n$ ใหญ่มากซึ่งอาจต้องจัดการ overflow และ underflow โดยเฉพาะ ค่าที่พิมพ์เป็นความน่าจะเป็นในช่วง 0–1 ต้องคูณ 100 เมื่อรายงานเป็นเปอร์เซ็นต์

สรุป — ก่อนนับ ต้องกำหนดเหตุการณ์และวิธีเลือกข้อมูล

  • Binomial ใช้กับจำนวนครั้งแน่นอน ผลสำเร็จ/ไม่สำเร็จ โอกาสสำเร็จคงที่ และ independence ข้ามครั้ง
  • PMF มาจากจำนวนลำดับที่ให้ความสำเร็จ $r$ ครั้ง คูณโอกาสของลำดับหนึ่ง: $\binom nr p^r(1-p)^{n-r}$
  • ภายใต้ $n=10,p=0.5$ โอกาสชนะแปดปีพอดีประมาณ 4.39% ส่วนอย่างน้อยแปดปีเท่ากับ 5.46875%
  • ค่าเฉลี่ยจำนวนสำเร็จคือ $np$ และ variance คือ $np(1-p)$ ต้องแยกจำนวนครั้งออกจากสัดส่วนและจากจำนวนเงิน
  • การเลือกคนที่ดีที่สุดจากหลายคนเป็นอีกเหตุการณ์หนึ่ง ไม่อาจใช้โอกาสของคนที่เลือกไว้ล่วงหน้าแทนได้ และ tail probability ไม่ใช่โอกาสมีฝีมือหลังเห็นข้อมูล

หัวข้อถัดไปจะเปลี่ยนจาก “สำเร็จกี่ครั้งในจำนวนครั้งที่กำหนด” เป็น “เกิดเหตุการณ์กี่ครั้งในช่วงเวลา” แล้วสร้าง Poisson distribution จากแบบจำลองการเกิดเหตุการณ์ที่ถี่และมีโอกาสน้อยในแต่ละช่วงย่อย
