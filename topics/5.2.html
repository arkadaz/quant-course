5.2 Marginal Distributions

ตอบคำถามของตัวแปรเดียว โดยรวมทุกกรณีของตัวแปรที่ไม่ได้ถาม

อยากรู้แค่ AAPL ทำไมต้องเลือกสถานะของ MSFT?

คุณมีตารางผลตอบแทนร่วมของหุ้นสองตัว แต่รายงานวันนี้ถามเพียงว่า “AAPL มีโอกาสลง 2% เท่าไร?” การเลือกเฉพาะวันที่ MSFT ลงจะเปลี่ยนคำถามโดยไม่รู้ตัว วิธีที่ถูกคือรวมทั้งกรณี MSFT ขึ้นและลง เราเรียกการดึงการแจกแจงรายตัวจากการแจกแจงร่วมว่า marginalization

คำว่า marginal มาจากผลรวมที่เขียนไว้ตามขอบตาราง ไม่ได้หมายถึงความเสี่ยงส่วนเพิ่ม ในหัวข้อนี้เราจะเริ่มจากบวกช่องในตาราง แล้วใช้เหตุผลเดียวกันกับอินทิกรัลที่มีขอบเขตไม่เป็นสี่เหลี่ยม

1. รวมให้ครบก่อนคำนวณเรื่องอื่น

ตารางต่อไปนี้เป็นแบบจำลองสมมติ ให้ $X$ เป็นผลตอบแทนรายวันของ AAPL หน่วยจุดเปอร์เซ็นต์ และ $Y$ เป็นสถานะ MSFT ขึ้นหรือลง ตัวเลขในช่องเป็นความน่าจะเป็น ไม่ใช่ขนาดผลตอบแทนของ MSFT

แถวแรกบอกว่า AAPL ลง 2% ได้ทั้งเมื่อ MSFT ขึ้นและลง สองกรณีนี้ไม่ทับกันและครอบคลุมสถานะของ $Y$ ทั้งหมด จึงบวกได้ $0.05+0.15=0.20$ ส่วน MSFT ขึ้นให้บวกทั้งคอลัมน์ ได้ $0.05+0.30+0.25=0.60$

\[ \begin{aligned} p_X(x)&=\sum_y p_{X,Y}(x,y),\\ p_Y(y)&=\sum_x p_{X,Y}(x,y). \end{aligned} \]

ตรวจผลรวมแยกกัน: $0.20+0.50+0.30=1$ และ $0.60+0.40=1$ ไม่ต้องนำ marginal ทั้งสองชุดมาบวกกันให้ได้หนึ่ง เพราะแต่ละชุดเป็นการแจกแจงคนละตัวแปร

2. จากการบวกช่อง สู่การรวมตามแกน

สำหรับตัวแปรต่อเนื่องที่มี joint PDF การถามว่า $X\le x$ โดยไม่จำกัด $Y$ คือการรวมทั้งแถบที่ทอดยาวตลอดแกน $Y$:

\[ \begin{aligned} F_X(x)&=P(X\le x)\\ &=\int_{-\infty}^{x}\int_{-\infty}^{\infty} f_{X,Y}(u,v)\,dv\,du,\\ f_X(x)&=\frac{dF_X(x)}{dx}\\ &=\int_{-\infty}^{\infty}f_{X,Y}(x,v)\,dv. \end{aligned} \]

เมื่อหาอนุพันธ์ตามขอบบน $x$ อินทิกรัลชั้นนอกหายไป แต่ยังต้องรวมทุกค่า $v$ ของอีกแกน ตรงนี้คือเหตุผล ไม่ใช่กฎจำว่า “ตัดอีกตัวทิ้ง” สำหรับ $f_Y$ ให้สลับบทบาทกัน:

\[ \begin{aligned} f_Y(y)&=\int_{-\infty}^{\infty}f_{X,Y}(u,y)\,du,\\ F_X(x)&=\int_{-\infty}^{x}f_X(u)\,du\\ &=\lim_{y\to\infty}F_{X,Y}(x,y). \end{aligned} \]

สูตรลิมิตของ CDF ใช้ได้แม้ไม่มี density ส่วนสูตรอินทิกรัลใช้ในกรณีที่มี density หากผลตอบแทนวัดเป็นจุดเปอร์เซ็นต์ joint PDF มีหน่วยต่อจุดเปอร์เซ็นต์กำลังสอง การอินทิเกรตหนึ่งแกนจึงเหลือหน่วยของ marginal PDF เป็นต่อจุดเปอร์เซ็นต์

\[ \int_{-\infty}^{\infty} f_X(x)\,dx =\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} f_{X,Y}(x,y)\,dy\,dx=1. \]

การรวมสลับลำดับทำได้สำหรับ density ที่ไม่ติดลบ และ normalization ของ joint ทำให้ marginal แต่ละตัวมีมวลหนึ่งโดยอัตโนมัติ การคำนวณเชิงตัวเลขอาจคลาดเล็กน้อยจากการตัดหางหรือความละเอียด แต่ค่าที่ผิดมากเป็นสัญญาณให้ย้อนดูขอบเขต

3. รูปช่วยแยก “รวมทั้งแกน” ออกจาก “เลือกรอยตัด”

รูป 5.2a ใช้ Gaussian สมมติที่ค่าเฉลี่ยศูนย์ $\sigma_X=2.5,\sigma_Y=3$ จุดเปอร์เซ็นต์ และ $\rho=0.6$ เส้นแดงด้านล่างคือ รูปทรง ของ marginal AAPL ซึ่งปรับสเกลและเลื่อนตำแหน่งเพื่อให้เห็นร่วมกับแผนที่ความหนาแน่น จึงห้ามอ่านระดับแนวตั้งของเส้นแดงเป็นผลตอบแทน MSFT หรือ density จริง

รูป 5.2b แสดง PDF รายตัวในสเกลจริง ทั้งสองเส้นมีพื้นที่ใต้กราฟทั่วแกนเท่ากับหนึ่ง MSFT มีส่วนเบี่ยงเบนมาตรฐานมากกว่า จึงกว้างและยอดต่ำกว่า ไม่ได้มีความน่าจะเป็นรวมมากกว่า

รูป 5.2c ตรึง $x=0$ แล้วลากไปตาม $y$ พื้นที่ใต้รอยตัดประมาณ 0.1596 เท่ากับ $f_X(0)=1/(2.5\sqrt{2\pi})$ นี่คือ ความสูงหนึ่งจุดของ marginal ไม่ใช่โอกาสที่ $X=0$ และไม่ใช่การแจกแจงตามเงื่อนไขที่ normalize แล้ว

รูป 5.2d เปลี่ยน PDF เป็น CDF โดยสะสมพื้นที่ เส้นทั้งคู่เข้าใกล้ 0 และ 1 ที่ปลายแกน สำหรับ Gaussian ต้องใช้ลิมิตที่อนันต์ ไม่จำเป็นต้องได้ 1 พอดีที่ขอบขวาของกราฟที่วาด

4. เมื่อ support เป็นสามเหลี่ยม ขอบอินทิกรัลต้องเปลี่ยน

พิจารณาตัวแปรไร้หน่วยในแบบจำลองของเล่น:

\[ f_{X,Y}(x,y)= \begin{cases}2,&0\le y\le x\le1,\\0,&\text{ที่อื่น}. \end{cases} \]

support คือบริเวณที่ density อาจเป็นบวก ที่นี่เป็นสามเหลี่ยมมุม $(0,0),(1,0),(1,1)$ มีพื้นที่ $1/2$ จึงมีมวลรวม $2(1/2)=1$ ความสูงคงที่ไม่ได้ทำให้ marginal เป็น uniform เพราะความยาวของรอยตัดเปลี่ยนไปตามจุดที่ตรึง

ตรึง $x$ แล้วลากแนวตั้ง: $y$ วิ่งได้จาก 0 ถึง $x$ แต่ตรึง $y$ แล้วลากแนวนอน: $x$ วิ่งจาก $y$ ถึง 1 เราจึงได้

\[ \begin{aligned} f_X(x)&=\int_0^x2\,dy=2x,&&0\le x\le1,\\ f_Y(y)&=\int_y^12\,dx=2(1-y),&&0\le y\le1. \end{aligned} \]

ทั้งคู่เป็นศูนย์นอกช่วง $[0,1]$ ถ้าอินทิเกรตค่าคงที่ 2 ตั้งแต่ 0 ถึง 1 ทุกครั้ง จะได้ marginal ผิดเป็น 2 ตลอดช่วงและมีมวลรวม 2 เพราะรวมบริเวณนอก support เข้าไปด้วย

\[ \begin{aligned} \int_0^1 2x\,dx&=1,&\int_0^1 2(1-y)\,dy&=1,\\ F_X(x)&=x^2,&F_Y(y)&=2y-y^2 \quad(0\le x,y\le1). \end{aligned} \]

นอกช่วงให้ CDF เป็น 0 ทางซ้ายและ 1 ทางขวา ที่เกณฑ์ 0.3 ได้ $f_X(0.3)=0.6$ แต่ $P(X\le0.3)=0.09$ ส่วน $f_Y(0.3)=1.4$ แต่ $P(Y\le0.3)=0.51$ จึงเห็นอีกครั้งว่า density สูงกว่า 1 ได้โดยไม่ละเมิดกฎความน่าจะเป็น

5. อ่านค่าเฉลี่ยจาก marginal ที่ได้

\[ \begin{aligned} E[X]&=\int_0^1x(2x)\,dx =2\left[\frac{x^3}{3}\right]_0^1=\frac23,\\ E[Y]&=\int_0^1y\,2(1-y)\,dy\\ &=2\left[\frac{y^2}{2}-\frac{y^3}{3}\right]_0^1=\frac13. \end{aligned} \]

$X$ มีแนวโน้มอยู่สูงกว่า $Y$ ซึ่งสอดคล้องกับข้อกำหนด $Y\le X$ ทั้งสอง marginal ไม่สมมาตรแม้ joint density คงที่ ผลรวมค่าเฉลี่ยเท่ากับ 1 เป็นคุณสมบัติของแบบจำลอง uniform บนสามเหลี่ยมนี้ ไม่ใช่กฎของทุก density บนสามเหลี่ยมเดียวกัน และไม่ได้บอกว่า $X+Y=1$ ทุกครั้ง

อีกวิธีสร้างแบบจำลองนี้คือสุ่ม $U,V$ อิสระแบบ uniform บน $[0,1]$ แล้วให้ $X=\max(U,V),Y=\min(U,V)$ การพับสี่เหลี่ยมตามเส้นทแยงทำให้แต่ละจุดภายในสามเหลี่ยมรับมวลจากสองจุด จึงได้ density 2 เราจะใช้แนวคิดนี้ตรวจค่าคาดหมายด้วยตารางจุดในโค้ด

ผลคาดหวังคือ marginal ของตาราง $[0.2,0.5,0.3]$ และ $[0.6,0.4]$ ส่วนค่าเฉลี่ยสามเหลี่ยมใกล้ $2/3,1/3$ การใช้ midpoint grid ทำให้ผลทำซ้ำได้โดยไม่ต้องใช้การสุ่ม

const joint = [[.05,.15],[.30,.20],[.25,.05]];
const rows = joint.map(row => row.reduce((a,b) => a+b,0));
const cols = [0,1].map(j => joint.reduce((s,row) => s+row[j],0));
function integrate(f,a,b,n=10000) {
  let s=0, h=(b-a)/n;
  for(let i=0;i<n;i++) s+=f(a+(i+.5)*h)*h;
  return s;
}
const fX = x => x<0 || x>1 ? 0 : integrate(() => 2,0,x,100);
const fY = y => y<0 || y>1 ? 0 : integrate(() => 2,y,1,100);
let maxMean=0, minMean=0;
const n=200;
for(let i=0;i<n;i++) for(let j=0;j<n;j++) {
  const u=(i+.5)/n, v=(j+.5)/n;
  maxMean+=Math.max(u,v)/(n*n);
  minMean+=Math.min(u,v)/(n*n);
}
console.log({rows,cols, fx:fX(.3),fy:fY(.3),
  normX:integrate(x => 2*x,0,1),
  normY:integrate(y => 2*(1-y),0,1),
  ex:integrate(x => 2*x*x,0,1),
  ey:integrate(y => 2*y*(1-y),0,1),
  cdfX:integrate(x => 2*x,0,.3),

6. เก็บทั้งกลุ่ม ไม่จำเป็นต้องเหลือตัวเดียว

แบ่งเวกเตอร์เป็น $\mathbf X=(X_1,\ldots,X_k)$ ที่อยากเก็บ และ $\mathbf Z=(X_{k+1},\ldots,X_n)$ ที่ไม่อยู่ในคำถาม marginal ของกลุ่มแรกคือ

\[ \begin{aligned} f_{\mathbf X}(\mathbf x) &=\int_{\mathbb R^{n-k}}f_{\mathbf X,\mathbf Z}(\mathbf x,\mathbf z)\,d\mathbf z,\\ F_{\mathbf X}(\mathbf x) &=F_{\mathbf X,\mathbf Z}(\mathbf x,+\infty,\ldots,+\infty). \end{aligned} \]

ผลลัพธ์ยังคงการแจกแจงร่วมของตัวแปรที่เก็บไว้ทั้งหมด เช่น การรวมปัจจัยตราสารหนี้ออกยังเหลือความสัมพันธ์ระหว่างหุ้นสองตัวได้ แต่หากเก็บเพียง marginal แยกรายตัว จะไม่สามารถย้อนสร้าง joint ได้โดยทั่วไป

ตรวจความเข้าใจ

  1. จากตารางแรก หา $P(X\le0)$ และ $E[X]$ พร้อมหน่วย
    เฉลย

    $P(X\le0)=0.20+0.50=0.70$ และ $E[X]=(-2)(0.20)+0(0.50)+2(0.30)=0.20$ จุดเปอร์เซ็นต์ หรือผลตอบแทนเฉลี่ย 0.2% ต่อวันในแบบจำลองสมมตินี้

  2. สำหรับสามเหลี่ยม หา $P(X\gt0.5)$ และ $P(Y\le0.5)$
    เฉลย

    $1-F_X(0.5)=1-0.25=0.75$ และ $F_Y(0.5)=1-0.25=0.75$ เหตุการณ์ต่างกันแต่มีโอกาสเท่ากันในแบบจำลองนี้

  3. คอลัมน์ MSFT ลงมีค่า $0.15,0.20,0.05$ นี่เป็น marginal ของ AAPL หรือไม่?
    เฉลย

    ไม่ใช่ เพราะยังไม่ได้รวมคอลัมน์ขึ้น และผลรวมเป็นเพียง 0.40 ถ้าหารแต่ละช่องด้วย 0.40 จะได้ conditional distribution ของหัวข้อถัดไป

ขอบเขตของคำตอบ

Marginalization ไม่ต้องสมมติความเป็นอิสระ แต่ต้องรวมทุกค่าที่เป็นไปได้ของตัวแปรที่ตัดออก การเห็น marginal สองเส้นเหมือนกันไม่ได้แปลว่าตัวแปรสัมพันธ์กันแบบใดแบบหนึ่ง ข้อมูลการเกิดพร้อมกันสูญหายไปเมื่อเหลือเพียงรายตัว

ใช้ marginal เพื่อรายงานความเสี่ยงรายสินทรัพย์ ตรวจแบบจำลอง และหาควอนไทล์ได้ แต่ห้ามบวก Value at Risk รายตัวแล้วเรียกว่า VaR ของพอร์ตโดยอัตโนมัติ ทิศทางของความคลาดเคลื่อนขึ้นอยู่กับการแจกแจงและมาตรวัดความเสี่ยง ไม่มีกฎว่าผลบวกต้องสูงกว่าความเสี่ยงรวมเสมอ

สรุปเส้นทางคิด

  • คำว่า “ไม่สนใจอีกตัว” หมายถึงรวมทุกค่าของมัน ไม่ใช่ตรึงมันไว้
  • แบบไม่ต่อเนื่องใช้ผลรวม แบบมี density ใช้อินทิกรัล และแต่ละ marginal ต้อง normalize เป็นหนึ่ง
  • วาด support ก่อนตั้งขอบ โดยเฉพาะเมื่อขอบของตัวหนึ่งขึ้นกับอีกตัว
  • marginal ของกลุ่มยังเก็บโครงสร้างร่วมภายในกลุ่ม แต่ marginal รายตัวไม่พอระบุความเสี่ยงของพอร์ต
