5.2 Marginal Distributions

ถ้าสนใจตัวแปรเดียว ให้รวมทุกกรณีของตัวแปรที่ไม่ได้ถาม ไม่ใช่เลือกกรณีใดกรณีหนึ่งของมัน

ทุกเช้า ทีมความเสี่ยงต้องรายงานว่าหุ้นแต่ละตัวมีโอกาสขาดทุนแรงแค่ไหน เช้านี้มีคำถามบรรทัดเดียว: “AAPL (หุ้นของ Apple) มีโอกาสลง 2% ในหนึ่งวันเท่าไร”

ปัญหาคือตารางที่ทีมมีไม่ได้นับ AAPL ตัวเดียว มันนับเป็นคู่: วันหนึ่ง AAPL ทำอะไร และวันเดียวกันนั้น MSFT (หุ้นของ Microsoft) ขึ้นหรือลง ตัวเลขในแต่ละช่องเรียกว่าโอกาสร่วม คือโอกาสที่สองเรื่องเกิดในวันเดียวกัน ตัวเลขทั้งหมดเป็นตัวเลขสมมติ

ของที่รู้:

  • โอกาสที่ AAPL ลง 2% และ MSFT ลง ในวันเดียวกัน: 0.15
  • โอกาสที่ AAPL ลง 2% และ MSFT ขึ้น ในวันเดียวกัน: 0.05
  • โอกาสที่ MSFT ลงในวันหนึ่ง ไม่ว่า AAPL จะทำอะไร: 0.40

นักวิเคราะห์คนแรกหยิบช่องแรกมาตอบเลย ได้ 0.15 คนที่สองเอาช่องแรกหารด้วยโอกาสที่ MSFT ลง ได้ $0.15/0.40=0.375$ ใครถูก?

ลองตอบก่อนเปิดเฉลย

ไม่มีใครถูก คำถามไม่ได้พูดถึง MSFT เลย วันที่ AAPL ลง 2% จึงนับทั้งวันที่ MSFT ขึ้นและวันที่ MSFT ลง สองกลุ่มนี้ไม่ทับกัน เพราะวันหนึ่ง MSFT ขึ้นหรือลงได้อย่างเดียว จึงบวกกันได้ตรง ๆ: $0.05+0.15=0.20$

คนแรกนับแค่วันที่ MSFT ลง จึงทิ้งวันที่ MSFT ขึ้นไป 0.05 คนที่สองตอบคำถามอื่น คือ “ถ้ารู้แล้วว่าวันนี้ MSFT ลง AAPL มีโอกาสลง 2% เท่าไร” คำถามแบบนั้นเป็นเรื่องของ conditional distribution หน้าถัดไป

ภาพรวมก่อนลงสูตร

ตารางในโจทย์เรียกว่า joint distribution (การแจกแจงร่วม) มันบอกโอกาสของทุกคู่ค่า: AAPL ทำอะไร และ MSFT ทำอะไร ในวันเดียวกัน ตารางแบบนี้ตอบได้ทุกคำถามเรื่องสองหุ้น แต่คำถามจำนวนมากถามถึงหุ้นตัวเดียว เหมือนคำถามเช้านี้

การแจกแจงของตัวแปรตัวเดียวที่ดึงออกมาจาก joint distribution เรียกว่า marginal distribution ขั้นตอนการดึงเรียกว่า marginalization หลักมีข้อเดียว: รวมทุกค่าของตัวแปรที่คำถามไม่ได้ถาม

ชื่อ marginal มาจากตำแหน่งในตาราง เมื่อบวกแต่ละแถว เรามักเขียนผลรวมไว้ที่ขอบ (margin) ของตาราง คำนี้จึงไม่ได้แปลว่า “ส่วนเพิ่ม” แบบ marginal cost ในวิชาเศรษฐศาสตร์

รูปด้านล่างวาดแต่ละค่าของ AAPL เป็นแท่งหนึ่งแท่ง แต่ละแท่งต่อจากสองท่อน ท่อนน้ำเงินคือวันที่ MSFT ขึ้น ท่อนส้มคือวันที่ MSFT ลง ความยาวรวมของแท่งคือ marginal ของ AAPL สีของท่อนไม่มีผลต่อความยาวรวม นี่คือความหมายของ “ไม่สนใจ MSFT”

ข้อมูลอาจส่งมาได้สามรูปแบบ หน้านี้จึงทำท่าเดียวกันสามแบบ:

  • ถ้าเป็นตาราง: บวกช่องตามแถว
  • ถ้าเป็น joint CDF (ฟังก์ชันที่บอกโอกาสที่ทั้งสองตัวไม่เกินค่าที่กำหนด): ดันเกณฑ์ของตัวที่ไม่สนใจไปที่อนันต์
  • ถ้าเป็น density (โอกาสต่อหนึ่งหน่วยพื้นที่บนระนาบ): อินทิเกรตตามแกนของตัวที่ไม่สนใจ

จากนั้นจะดูกรณีที่บริเวณที่ค่าเกิดขึ้นได้ (support) ไม่ใช่สี่เหลี่ยม กรณีนี้คนมักตั้งขอบของอินทิกรัลผิด สุดท้ายจะดูว่า marginal ทิ้งข้อมูลอะไรไป

ศัพท์ที่ใช้ในหัวข้อนี้
Joint distribution (การแจกแจงร่วม)
โอกาสของทุกคู่ค่าของสองตัวแปรที่เกิดพร้อมกัน เช่นตาราง AAPL–MSFT ในโจทย์ หน้า joint CDF และ joint PDF อธิบายไว้เต็ม
Marginal distribution
การแจกแจงของตัวแปรตัวเดียว (หรือกลุ่มย่อยของตัวแปร) ที่ได้จาก joint distribution โดยรวมทุกค่าของตัวแปรที่เหลือ เช่นโอกาสของแต่ละค่าผลตอบแทน AAPL โดยไม่สนว่า MSFT ทำอะไร ทีมความเสี่ยงใช้มันรายงานความเสี่ยงของหุ้นทีละตัว
Marginalization (การรวมทิ้ง)
ขั้นตอนที่ทำให้ตัวแปรที่คำถามไม่ได้ถามหายไป ถ้าข้อมูลเป็นตาราง ให้บวกตามแถวหรือคอลัมน์ ถ้าเป็น density ให้อินทิเกรตตามแกนที่ไม่สนใจ
Joint marginal
marginal ของตัวแปรมากกว่าหนึ่งตัว เช่น มีผลตอบแทน 50 หุ้น แต่ดึงออกมาเฉพาะคู่ AAPL กับ MSFT คู่ที่ดึงออกมายังเก็บความสัมพันธ์ระหว่างกันไว้ครบ
Support
บริเวณที่ density มากกว่าศูนย์ คือบริเวณที่ค่าของตัวแปรเกิดขึ้นได้จริง บริเวณนี้กำหนดขอบของอินทิกรัล ถ้าขอบของตัวหนึ่งขึ้นกับค่าของอีกตัว ช่วงที่อินทิเกรตก็เปลี่ยนตามค่าที่ตรึงไว้
Fréchet bounds
ช่วงของโอกาสที่สองเหตุการณ์เกิดพร้อมกัน เมื่อรู้แค่โอกาสของแต่ละเหตุการณ์แยกกัน ช่วงนี้แสดงว่า marginal อย่างเดียวบอกโอกาสเกิดพร้อมกันไม่ได้
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$p_{X,Y}(x,y)$โอกาสร่วมในตาราง: โอกาสที่ $X=x$ และ $Y=y$ ในวันเดียวกันไม่มีหน่วย
$p_X(x),\ p_Y(y)$marginal PMF (probability mass function): โอกาสที่ตัวแปรตัวเดียวมีค่านั้นไม่มีหน่วย
$F_{X,Y}(x,y)$joint CDF: โอกาสที่ $X\le x$ และ $Y\le y$ ในวันเดียวกันไม่มีหน่วย
$f_{X,Y}(x,y)$joint density: โอกาสต่อหนึ่งหน่วยพื้นที่บนระนาบต่อ (หน่วย $X$ × หน่วย $Y$)
$f_X(x)$marginal density ของ $X$: โอกาสต่อหนึ่งหน่วยความยาวบนแกน $X$ต่อหน่วย $X$

$E[X]$ค่าเฉลี่ยของ $X$: ผลรวมของ ค่า × โอกาสหน่วย $X$

ขั้นที่ 1 — บวกตามแถว: marginal จากตาราง

เริ่มจากรูปแบบที่ง่ายที่สุด คือตาราง เพราะเห็นได้ทุกช่องและบวกด้วยมือได้

โจทย์ให้อะไรมาบ้าง: ตารางสมมติด้านล่าง

  • $X$ คือผลตอบแทนรายวันของ AAPL หน่วยเป็นจุดเปอร์เซ็นต์ ตารางปัดให้เหลือสามค่า: $X=-2$ (ลง 2%), $X=0$ (ไม่ขยับ), $X=2$ (ขึ้น 2%)
  • $Y$ คือทิศทางของ MSFT ในวันเดียวกัน: ขึ้น หรือ ลง
  • ตัวเลขในช่องคือโอกาสร่วม $p_{X,Y}(x,y)$ ทุกช่องรวมกันได้ 1

คำถามถามแค่ AAPL จึงต้องเก็บทุกช่องในแถวของค่า $x$ นั้นมาบวกกัน ไม่ว่าช่องนั้นจะอยู่คอลัมน์ไหนของ MSFT ส่วนค่าเฉลี่ย $E[X]$ คือผลรวมของ “ค่า × โอกาส” ทุกแถว ซึ่งใช้แค่คอลัมน์ marginal

\[\begin{aligned} p_X(x)&=\sum_y p_{X,Y}(x,y),\\ p_X(-2)&=0.05+0.15=0.20,\\ p_Y(\text{down})&=0.15+0.20+0.05=0.40,\\ E[X]&=(-2)(0.20)+0(0.50)+2(0.30)\\ &=0.20. \end{aligned}\]

คำตอบ: AAPL ลง 2% ด้วยโอกาส 0.20 การบวกนี้ถูก เพราะวันหนึ่ง MSFT ขึ้นหรือลงได้อย่างเดียว สองช่องจึงไม่ทับกัน และสองช่องรวมกันครอบคลุมทุกวันที่ AAPL ลง 2% แต่ละวันจึงถูกนับครั้งเดียวพอดี

marginal ของ MSFT ได้จากการบวกตามคอลัมน์แบบเดียวกัน: $p_Y(\text{down})=0.40$ ตรงกับตัวเลข 0.40 ในโจทย์ ส่วนค่าเฉลี่ยผลตอบแทนของ AAPL คือ 0.20 จุดเปอร์เซ็นต์ต่อวัน ค่านี้คำนวณจาก marginal ได้เลย ไม่ต้องรู้ว่า MSFT ทำอะไร

ตรวจเองใน 10 วินาที: marginal แต่ละชุดต้องรวมได้ 1 แยกกัน: $0.20+0.50+0.30=1$ และ $0.60+0.40=1$ ไม่ต้องเอาสองชุดมาบวกกันให้ได้ 1 เพราะเป็นการแจกแจงของคนละตัวแปร

ขั้นที่ 2 — marginal จาก joint CDF: ปลดเงื่อนไขของอีกตัว

บางครั้งแบบจำลองไม่ได้ส่งตารางมา แต่ส่ง joint CDF มา joint CDF คือ $F_{X,Y}(x,y)=P(X\le x,\,Y\le y)$: โอกาสที่ $X$ ไม่เกิน $x$ และ $Y$ ไม่เกิน $y$ ในวันเดียวกัน (ดู joint CDF) สิ่งที่เราอยากได้คือ $F_X(x)=P(X\le x)$ ซึ่งไม่มีเงื่อนไขเรื่อง $Y$ เลย

วิธีคือทำให้เงื่อนไขของ $Y$ ไม่ตัดวันไหนทิ้ง โดยดันเกณฑ์ $y$ ไปที่อนันต์ ท่านี้ไม่ต้องบวกช่อง ใช้ได้กับการแจกแจงทุกชนิด และใช้กับกลุ่มตัวแปรหลายตัวได้ด้วย

\[\begin{aligned} F_X(x)&=P(X\le x)\\ &=\lim_{y\to\infty}P(X\le x,\,Y\le y)\\ &=F_{X,Y}(x,+\infty),\\ F_{X_i,X_j}(x_i,x_j)&=F_{\mathbf X}(\infty,\ldots,x_i,\ldots,x_j,\ldots,\infty). \end{aligned}\]

คิดเป็นวัน: เงื่อนไข $Y\le y$ ตัดวันที่ MSFT ขึ้นเกิน $y$ ทิ้ง ถ้า $y$ ใหญ่มาก เช่น 50% แทบไม่มีวันไหนถูกตัด เมื่อ $y\to\infty$ ก็ไม่มีวันไหนถูกตัดเลย เงื่อนไขเรื่อง $Y$ จึงหายไป เหลือแค่ $X\le x$

จุดที่ควรถามคือ ทำไมเขียน $P(X\le x)$ เป็นลิมิตของ $P(X\le x,\,Y\le y)$ ได้ คำตอบคือกลุ่มวันที่ $X\le x$ และ $Y\le y$ โตขึ้นเรื่อย ๆ เมื่อ $y$ เพิ่ม และสุดท้ายเท่ากับกลุ่มวันที่ $X\le x$ ทั้งหมด โอกาสของกลุ่มที่โตขึ้นทีละน้อยแบบนี้จะเข้าหาโอกาสของกลุ่มปลายทางเสมอ ตัวอย่างจากตาราง 100 วันในหน้า joint CDF: AAPL ลงถึง −1% ใน 20 วัน จึงได้ $F(-1,+\infty)=20/100=0.20$

ท่าเดียวกันใช้กับหุ้นหลายตัว สมมติมีผลตอบแทน 50 หุ้นในวันเดียวกัน เขียนเป็นเวกเตอร์ $\mathbf X=(X_1,\ldots,X_{50})$ ถ้าต้องการแค่หุ้นตัวที่ $i$ กับตัวที่ $j$ ให้ใส่ $\infty$ ทุกตำแหน่งยกเว้นสองตำแหน่งนั้น ผลที่ได้คือ joint CDF ของคู่นั้น เรียกว่า joint marginal ความสัมพันธ์ภายในคู่ยังอยู่ครบ สิ่งที่หายไปคือความสัมพันธ์กับอีก $50-2=48$ ตัว

ขั้นที่ 3 — กรณีต่อเนื่อง: อินทิเกรตอีกแกนทิ้ง

ในตาราง ผลตอบแทนมีแค่สามค่า แต่ผลตอบแทนจริงเป็นค่าใดก็ได้ เช่น −1.37% เมื่อตัวแปรต่อเนื่อง ข้อมูลจะมาเป็น joint density $f_{X,Y}(x,y)$ คือโอกาสต่อหนึ่งหน่วยพื้นที่บนระนาบ โอกาสของบริเวณหนึ่งได้จากการอินทิเกรต density บนบริเวณนั้น การบวกช่องในตารางจึงกลายเป็นอินทิกรัล

ขั้นนี้ไม่ได้ให้จำสูตร “อินทิเกรตอีกแกนทิ้ง” แต่จะสร้างสูตรนั้นจากท่าดันเกณฑ์ไปที่อนันต์ในขั้นก่อน $u$ และ $v$ ในสูตรคือตัวแปรที่ใช้ระหว่างอินทิเกรต แทนค่าของ $X$ และ $Y$ ตามลำดับ

\[\begin{aligned} F_X(x)&=F_{X,Y}(x,+\infty)\\ &=\int_{-\infty}^{x}\left[\int_{-\infty}^{\infty}f_{X,Y}(u,v)\,dv\right]du,\\ f_X(x)&=\frac{d}{dx}F_X(x)\\ &=\int_{-\infty}^{\infty}f_{X,Y}(x,v)\,dv,\\ f_Y(y)&=\int_{-\infty}^{\infty}f_{X,Y}(u,y)\,du. \end{aligned}\]

เริ่มจากท่าในขั้นก่อน $F_X(x)=F_{X,Y}(x,+\infty)$ joint CDF คืออินทิกรัลของ density บนมุมซ้ายล่างของจุด $(x,y)$ เมื่อขอบบน $y$ เป็นอนันต์ มุมนั้นกลายเป็นแถบแนวตั้งทั้งแถบทางซ้ายของ $x$ อินทิกรัลในวงเล็บเหลี่ยมรวม density ตามแนวตั้งที่ตำแหน่ง $u$ หนึ่ง นี่คือ “บวกตามแถว” แบบในตาราง เพียงแต่ทำแบบต่อเนื่อง

จังหวะที่ทำให้อินทิกรัลชั้นนอกหายไปคือการหาอนุพันธ์ ทฤษฎีบทหลักมูลของแคลคูลัสบอกว่า อนุพันธ์ของ $\int_{-\infty}^{x}g(u)\,du$ ตาม $x$ คือ $g(x)$ ในที่นี้ $g(u)$ คือวงเล็บเหลี่ยม จึงเหลือวงเล็บเหลี่ยมที่ $u=x$: ตัดระนาบด้วยเส้นแนวตั้งที่ $x$ แล้วรวม density ตลอดเส้น $f_Y$ ทำแบบเดียวกันโดยสลับบทบาท คือตัดแนวนอนที่ $y$ แล้วรวมตาม $u$

หน่วยลงตัวเอง joint density มีหน่วย ต่อ (จุดเปอร์เซ็นต์)² การอินทิเกรตตาม $v$ คูณด้วย $dv$ ซึ่งมีหน่วยจุดเปอร์เซ็นต์หนึ่งครั้ง จึงเหลือหน่วย ต่อจุดเปอร์เซ็นต์ ซึ่งเป็นหน่วยของ density ตัวแปรเดียว และพื้นที่รวมของ marginal เป็น 1 โดยอัตโนมัติ เพราะ $\int f_X(x)\,dx=\iint f_{X,Y}(x,v)\,dv\,dx=1$

ขั้นที่ 4 — support สามเหลี่ยม: ขอบอินทิกรัลเปลี่ยนตามจุดที่ตรึง

กับ Gaussian เราอินทิเกรตจาก $-\infty$ ถึง $\infty$ ได้ทุกครั้ง เพราะผลตอบแทนคู่ไหนก็เกิดขึ้นได้ แต่บางแบบจำลองมีข้อจำกัดระหว่างตัวแปร เช่นราคาต่ำสุดของวันไม่มีทางสูงกว่าราคาสูงสุดของวันเดียวกัน ข้อจำกัดแบบนี้ทำให้ support (บริเวณที่ค่าเกิดขึ้นได้) ไม่ใช่สี่เหลี่ยม แล้วขอบของอินทิกรัลต้องเปลี่ยนตามจุดที่ตรึง ขั้นนี้ใช้ตัวอย่างที่ง่ายที่สุดที่มีข้อจำกัดแบบนั้น

โจทย์ให้อะไรมาบ้าง:

  • $X$ และ $Y$ เป็นตัวเลขไร้หน่วยระหว่าง 0 ถึง 1 และ $Y$ ไม่เกิน $X$ เสมอ คิดว่า $X$ คือราคาสูงสุด $Y$ คือราคาต่ำสุด หลังปรับสเกลให้อยู่ในช่วง 0 ถึง 1
  • joint density $f_{X,Y}(x,y)=2$ เมื่อ $0\le y\le x\le1$ และเป็นศูนย์ที่อื่น
  • support จึงเป็นสามเหลี่ยมใต้เส้นทแยง $y=x$ มุมอยู่ที่ $(0,0),\ (1,0),\ (1,1)$

ทำไม density ต้องสูง 2: สามเหลี่ยมมีพื้นที่ $\tfrac12\times1\times1=\tfrac12$ มวลรวมต้องเป็น 1 จึงต้องได้ $2\times\tfrac12=1$ (กลไกที่ให้เลข 2 นี้จริง ๆ อยู่ในขั้นพับสี่เหลี่ยมด้านล่าง)

การหา $f_X(x)$ คือตรึง $x$ แล้วรวม density ตามแนวตั้ง แต่เส้นแนวตั้งที่ $x$ อยู่ในสามเหลี่ยมแค่ช่วง $0\le y\le x$ เหนือนั้นออกนอกสามเหลี่ยม ขอบบนของอินทิกรัลจึงเป็น $x$ ไม่ใช่ 1 การหา $f_Y(y)$ ก็ตรึง $y$ แล้วรวมตามแนวนอน ซึ่งอยู่ในสามเหลี่ยมแค่ช่วง $y\le x\le1$

\[\begin{aligned} f_X(x)&=\int_0^{x}2\,dy=2x,\\ f_Y(y)&=\int_y^{1}2\,dx=2(1-y),\\ f_X(0.6)&=2(0.6)=1.2,\\ f_Y(0.3)&=2(1-0.3)=1.4. \end{aligned}\]

คำตอบ: $f_X(x)=2x$ และ $f_Y(y)=2(1-y)$ บนช่วง 0 ถึง 1 นอกช่วงนี้ทั้งสองเป็นศูนย์ ความสูงของ density เท่ากันทุกจุดในสามเหลี่ยม แต่เส้นที่ตัดผ่านสามเหลี่ยมยาวไม่เท่ากัน marginal คือความสูง 2 คูณความยาวเส้นตัด จึงไม่เป็นค่าคงที่

ตรวจเองใน 10 วินาที: ถ้าลืมดู support แล้วอินทิเกรตจาก 0 ถึง 1 ทุกครั้ง จะได้ $f_X(x)=\int_0^1 2\,dy=2$ ทุกค่า $x$ และมวลรวม $\int_0^1 2\,dx=2$ ซึ่งเป็นไปไม่ได้ เพราะโอกาสรวมต้องเป็น 1 มวลรวมที่เกิน 1 คือสัญญาณว่าขอบอินทิกรัลผิด

ขั้นที่ 5 — CDF และค่าเฉลี่ยจาก marginal

เมื่อได้ marginal แล้ว เครื่องมือของตัวแปรเดียวก็ใช้ได้ทันที ขั้นนี้ทำสามอย่าง: ตรวจว่าพื้นที่รวมเป็น 1 หา CDF (โอกาสที่ไม่เกินค่าหนึ่ง) และหาค่าเฉลี่ย แล้วดูว่าทำไม density ที่สูงเกิน 1 จึงไม่ผิด

โจทย์ให้อะไรมาบ้าง: $f_X(x)=2x$ และ $f_Y(y)=2(1-y)$ บนช่วง 0 ถึง 1 ซึ่งได้จากรอยตัดของสามเหลี่ยมในขั้นก่อน

CDF คือพื้นที่ใต้ density จาก 0 ถึงค่าที่ถาม จึงหาได้ด้วยการอินทิเกรต ค่าเฉลี่ยของตัวแปรต่อเนื่องคืออินทิกรัลของ “ค่า × density” ซึ่งเป็นรูปต่อเนื่องของผลรวม “ค่า × โอกาส” ในตาราง

\[\begin{aligned} \int_0^1 2x\,dx&=1,\\ \int_0^1 2(1-y)\,dy&=1,\\ F_X(x)&=\int_0^x 2u\,du=x^2,\\ F_Y(y)&=\int_0^y 2(1-v)\,dv=2y-y^2,\\ P(X\le0.3)&=0.3^2=0.09,\\ P(Y\le0.3)&=2(0.3)-0.3^2=0.51,\\ E[X]&=\int_0^1 x\cdot2x\,dx=\tfrac23,\\ E[Y]&=\int_0^1 (2y-2y^2)\,dy=1-\tfrac23=\tfrac13. \end{aligned}\]

คำตอบ: $X$ มักอยู่สูง ($E[X]=2/3$) และ $Y$ มักอยู่ต่ำ ($E[Y]=1/3$) ซึ่งเข้ากับข้อจำกัด $Y\le X$: ราคาสูงสุดอยู่ค่อนไปทางบน ราคาต่ำสุดอยู่ค่อนไปทางล่าง

ที่ $y=0.3$ density ของ $Y$ สูง 1.4 ซึ่งเกิน 1 แต่โอกาสสะสม $P(Y\le0.3)=0.51$ ไม่เกิน 1 เพราะ density คือโอกาสต่อหนึ่งหน่วยความยาว ไม่ใช่โอกาส โอกาสได้จากพื้นที่ ความสูงจึงเกิน 1 ได้ ตราบที่ช่วงที่สูงนั้นแคบพอ

ตรวจเองใน 10 วินาที: ในแบบจำลองนี้ $E[X]+E[Y]=\tfrac23+\tfrac13=1$ เหตุผลอยู่ในขั้นพับสี่เหลี่ยมด้านล่าง แต่ไม่ได้แปลว่า $X+Y=1$ ทุกครั้ง เช่นคู่ $X=0.9,\ Y=0.2$ อยู่ในสามเหลี่ยมและรวมได้ 1.1

ขั้นที่ 6 — ที่มาของสามเหลี่ยม: พับสี่เหลี่ยมตามเส้นทแยง

density 2 บนสามเหลี่ยมดูเหมือนถูกตั้งขึ้นมาลอย ๆ ขั้นนี้แสดงว่ามันเกิดจากกลไกง่าย ๆ แล้วใช้กลไกนั้นหา CDF อีกทางหนึ่ง ถ้าได้ตรงกับขั้นก่อน ก็แปลว่า marginal ที่หามาถูก

โจทย์ให้อะไรมาบ้าง:

  • สุ่มตัวเลข $U$ และ $V$ แต่ละตัวเป็น uniform บนช่วง 0 ถึง 1 คือทุกค่าในช่วงมีโอกาสเท่ากัน ดังนั้นโอกาสที่ $U\le x$ เท่ากับความยาวช่วง 0 ถึง $x$: $P(U\le x)=x$
  • $U$ กับ $V$ สุ่มอย่างอิสระ คือค่าของตัวหนึ่งไม่บอกอะไรเกี่ยวกับอีกตัว
  • ตั้ง $X=\max(U,V)$ ตัวที่มากกว่า และ $Y=\min(U,V)$ ตัวที่น้อยกว่า เช่น $U$ และ $V$ คือราคาในสองช่วงเวลา $X$ คือราคาสูงสุด $Y$ คือราคาต่ำสุด (หลังปรับสเกลให้อยู่ในช่วง 0 ถึง 1)

หา CDF ของ max ได้ง่าย เพราะตัวที่มากกว่าไม่เกิน $x$ ก็ต่อเมื่อทั้งสองตัวไม่เกิน $x$ ส่วน min คิดฝั่งตรงข้ามง่ายกว่า เพราะตัวที่น้อยกว่าเกิน $y$ ก็ต่อเมื่อทั้งสองตัวเกิน $y$ แล้วค่อยเอา 1 ลบ

\[\begin{aligned} P(X\le x)&=P(U\le x,\,V\le x)\\ &=x\cdot x=x^2,\\ P(Y\gt y)&=P(U\gt y,\,V\gt y)\\ &=(1-y)(1-y)=(1-y)^2,\\ P(Y\le y)&=1-(1-y)^2=2y-y^2. \end{aligned}\]

คำตอบ: ได้ $F_X=x^2$ และ $F_Y=2y-y^2$ ตรงกับ CDF ที่อินทิเกรตจาก marginal density ในขั้นก่อนทั้งสองตัว ขั้นที่ต้องมีเหตุผลรองรับคือการคูณ $x\cdot x$: โอกาสที่สองเรื่องเกิดพร้อมกันเท่ากับผลคูณของโอกาสแต่ละเรื่อง ก็ต่อเมื่อสองเรื่องนั้นอิสระกัน ซึ่งเป็นจริงที่นี่เพราะ $U$ กับ $V$ สุ่มแยกกัน (ทำไมจึงคูณได้อยู่ใน independence)

ตรวจเองใน 10 วินาที: ตัวที่มากกว่าบวกตัวที่น้อยกว่าก็คือสองตัวบวกกัน: $X+Y=U+V$ เสมอ ค่าเฉลี่ยของ uniform บน 0 ถึง 1 คือ $\tfrac12$ จึงได้ $E[X]+E[Y]=E[U]+E[V]=\tfrac12+\tfrac12=1$ ตามที่สังเกตไว้ตอนหาค่าเฉลี่ยจาก marginal

ขั้นที่ 7 — marginal บอกโอกาสเกิดพร้อมกันไม่ได้

marginal สะดวกมาก แต่มันทิ้งข้อมูลบางอย่างไป ขั้นนี้ถามว่าทิ้งอะไร โดยใช้ตาราง 100 วันซื้อขาย (สมมติ) จากหน้า joint CDF ในตารางนั้น AAPL ลงถึง −1% ใน 20 วัน MSFT ลงถึง −1% ใน 20 วัน และลงถึง −1% พร้อมกันใน 10 วัน

สมมติว่าเรารู้แค่ 20 กับ 20 ซึ่งคือ marginal ของแต่ละหุ้น แต่ไม่รู้เลข 10 โอกาสที่สองหุ้นลงพร้อมกันอาจเป็นเท่าไรได้บ้าง

โจทย์ให้อะไรมาบ้าง:

  • $p=P(X\le-1)=20/100=0.20$ คือโอกาสที่ AAPL ลงถึง −1% ในวันหนึ่ง
  • $q=P(Y\le-1)=20/100=0.20$ คือโอกาสที่ MSFT ลงถึง −1% ในวันหนึ่ง
  • $j$ คือโอกาสที่ทั้งสองตัวลงถึง −1% ในวันเดียวกัน ซึ่งเราไม่รู้

เราหาขอบบนและขอบล่างของ $j$ จากเหตุผลสองข้อ ขอบบน: วันที่ลงทั้งคู่เป็นส่วนหนึ่งของวันที่ AAPL ลง และเป็นส่วนหนึ่งของวันที่ MSFT ลงด้วย $j$ จึงเกินตัวที่เล็กกว่าของ $p$ กับ $q$ ไม่ได้ ขอบล่าง: โอกาสที่อย่างน้อยหนึ่งตัวลงคือ $p+q-j$ (บวกสองตัวแล้วลบวันที่ถูกนับซ้ำ ตามหน้า joint CDF) และโอกาสนี้เกิน 1 ไม่ได้

\[\begin{aligned} j&\le\min(p,q)=0.20,\\ p+q-j&\le1,\\ j&\ge p+q-1=-0.60,\\ \max(0,\,p+q-1)&\le j\le\min(p,q),\\ 0&\le j\le0.20. \end{aligned}\]

ขอบล่างจากเหตุผลข้อสองคือ $0.20+0.20-1=-0.60$ แต่โอกาสติดลบไม่ได้ ขอบล่างจริงจึงเป็น 0 ซึ่งเป็นที่มาของ $\max(0,\,\cdot)$ ในสูตร

คำตอบ: โอกาสลงพร้อมกันเป็นค่าใดก็ได้ตั้งแต่ 0 ถึง 0.20 ช่วงนี้มีชื่อว่า Fréchet bounds ลองดูสี่จุดในช่วงนี้:

  • $j=0$: สองหุ้นไม่เคยลงวันเดียวกัน
  • $j=0.20\times0.20=0.04$: สองหุ้นอิสระกัน
  • $j=10/100=0.10$: ข้อมูลจริงในตาราง
  • $j=0.20$: ลงพร้อมกันทุกครั้ง

ทั้งสี่แบบมี marginal 0.20 กับ 0.20 เหมือนกันทุกตัว marginal จึงแยกสี่แบบนี้ออกจากกันไม่ได้

ตรวจเองใน 10 วินาที: เติมตาราง 2×2 ที่ $j=0.20$ ช่องลงทั้งคู่ 20 วัน ช่อง AAPL ลงตัวเดียว $20-20=0$ วัน ช่อง MSFT ลงตัวเดียว $20-20=0$ วัน ช่องไม่ลงเลย $100-20-0-0=80$ วัน ผลรวมที่ขอบยังเป็น 20 กับ 80 ทั้งสองหุ้น

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

อ่านช่องเดียวแทน marginal: คำถามไม่ได้พูดถึง MSFT แต่หยิบเฉพาะช่อง “MSFT ลง” มาตอบ ผิด: 0.15 ถูก: $0.05+0.15=0.20$ คำตอบผิดต่ำไป $\frac{0.20-0.15}{0.20}=25\%$ ทั้งคอลัมน์ MSFT ลงก็ไม่ใช่การแจกแจงของ AAPL เพราะรวมได้แค่ $0.15+0.20+0.05=0.40$ ไม่ใช่ 1

อินทิเกรตเต็มช่วงโดยไม่ดู support: ในสามเหลี่ยม ตั้งขอบเป็น 0 ถึง 1 ทุกครั้ง ผิด: $f_X(x)=\int_0^1 2\,dy=2$ มวลรวม $\int_0^1 2\,dx=2$ ถูก: $f_X(x)=\int_0^x 2\,dy=2x$ มวลรวม $\int_0^1 2x\,dx=1$ ทางแก้คือวาด support ก่อนตั้งขอบทุกครั้ง

เข้าใจว่ารอยตัดคือการแจกแจงของอีกตัว: รอยตัด Gaussian ที่ AAPL = 0% มีพื้นที่ 0.1596 ไม่ใช่ 1 ถ้าใช้มันเป็น density ของ MSFT ทั้งที่ยังไม่ได้หาร โอกาสทุกค่าจะเล็กไป $1/0.1596=6.3$ เท่า ทางที่ถูกคือหารรอยตัดด้วย 0.1596 ก่อน ซึ่งคือ conditional distribution ในหน้าถัดไป

คิดว่ารู้ความเสี่ยงของแต่ละหุ้นแล้ว ก็รู้ความเสี่ยงของพอร์ต: marginal 0.20 กับ 0.20 ยอมให้โอกาสลงพร้อมกันเป็นค่าใดก็ได้ตั้งแต่ 0 ถึง 0.20 ถ้าเดาว่าอิสระกัน จะได้ $0.20\times0.20=0.04$ แต่ข้อมูลจริงคือ 0.10 ต่ำไป $0.10/0.04=2.5$ เท่า ความผิดแบบเดียวกันเกิดกับ VaR (ยอดขาดทุนที่จะเกินเพียงไม่กี่วัน เช่น 1 วันใน 100 วัน): เอา VaR ของหุ้นแต่ละตัวมาบวกกันแล้วเรียกว่า VaR ของพอร์ต ผลรวมนั้นอาจสูงหรือต่ำกว่าค่าจริง ขึ้นกับการแจกแจงร่วม

ใช้ทำอะไรบนโต๊ะจริง

ทีมความเสี่ยงใช้ marginal ทุกวันในสามงาน:

  • รายงานความเสี่ยงของหุ้นทีละตัว เช่นโอกาสที่หุ้นแต่ละตัวขาดทุนเกิน 2% ในวันเดียว หรือควอนไทล์ 1% ของผลตอบแทน คือระดับที่ผลตอบแทนต่ำกว่านั้นเพียง 1 วันใน 100 วัน งานพวกนี้ใช้แค่ marginal ของหุ้นตัวนั้น
  • ตรวจแบบจำลองหลายตัวแปร การตรวจเริ่มที่ marginal ถ้าแบบจำลองให้ marginal ของแต่ละหุ้นไม่ตรงกับข้อมูล ส่วนที่บอกการเกิดร่วมก็ไม่น่าเชื่อเช่นกัน
  • สร้างแบบจำลองเป็นสองชั้น แนวคิด copula ในหน้า Gaussian copula ใช้การแยกนี้โดยตรง: ประมาณ marginal ของแต่ละหุ้นจากข้อมูลของมันเอง แล้วเลือกรูปแบบการเกิดร่วมแยกต่างหาก ส่วนการเกิดร่วมนี้คือส่วนที่ marginal บอกไม่ได้ ตามที่ Fréchet bounds แสดงไว้ข้างบน

โจทย์ตรวจความเข้าใจ

1. กลับไปที่ตาราง AAPL–MSFT ในขั้นบวกตามแถว ทีมความเสี่ยงอยากรู้สองอย่าง อย่างแรกคือโอกาสที่ AAPL ไม่ขึ้นในวันหนึ่ง คือ $P(X\le0)$ อย่างที่สองคือ marginal ของ MSFT จากนั้นถามต่อ: ถ้ามีแค่ marginal สองชุดนี้ ไม่มีตาราง จะหาโอกาส “AAPL ลง 2% และ MSFT ลง” ได้หรือไม่

เฉลย

AAPL ไม่ขึ้นคือ $X=-2$ หรือ $X=0$ จึงบวกสองแถวของ marginal: $P(X\le0)=0.20+0.50=0.70$

marginal ของ MSFT ได้จากการบวกตามคอลัมน์: ขึ้น $0.05+0.30+0.25=0.60$ ลง $0.15+0.20+0.05=0.40$

จาก marginal อย่างเดียวหาโอกาสร่วมไม่ได้ ได้แค่ช่วงตาม Fréchet bounds ใช้ $p=0.20$ (AAPL ลง 2%) และ $q=0.40$ (MSFT ลง) แล้วให้ $j_{\min}$ กับ $j_{\max}$ คือขอบล่างและขอบบนของโอกาสร่วม:

\[\begin{aligned}j_{\min}&=\max(0,\,0.20+0.40-1)=0,\\j_{\max}&=\min(0.20,\,0.40)=0.20.\end{aligned}\]

ค่าจริงในตาราง 0.15 อยู่ในช่วงนี้ ส่วนค่าที่ได้ถ้าสองหุ้นอิสระกันคือ $0.20\times0.40=0.08$

2. ใช้แบบจำลองราคาสูงสุด–ต่ำสุดแบบสามเหลี่ยมที่ใช้ในหน้านี้ จงหาโอกาสที่ราคาสูงสุดเกิน 0.5 คือ $P(X\gt0.5)$ และโอกาสที่ราคาต่ำสุดไม่เกิน 0.5 คือ $P(Y\le0.5)$

เฉลย

ใช้ CDF ที่หาไว้ $F_X(x)=x^2$ และ $F_Y(y)=2y-y^2$:

\[\begin{aligned}P(X\gt0.5)&=1-F_X(0.5)=1-0.5^2=0.75,\\P(Y\le0.5)&=2(0.5)-0.5^2=1-0.25=0.75.\end{aligned}\]

ได้ค่าเท่ากันแต่เป็นคนละเหตุการณ์ ตรวจด้วยกลไกพับ max เกิน 0.5 เมื่อ $U$ หรือ $V$ อย่างน้อยตัวหนึ่งเกิน 0.5 ซึ่งตรงข้ามกับ “ไม่เกิน 0.5 ทั้งคู่” จึงได้ $1-0.5\times0.5=0.75$ ส่วน min ไม่เกิน 0.5 เมื่ออย่างน้อยตัวหนึ่งไม่เกิน 0.5 ซึ่งตรงข้ามกับ “เกิน 0.5 ทั้งคู่” จึงได้ $1-0.5\times0.5=0.75$ เท่ากัน

3. ธนาคารปล่อยกู้ให้ลูกหนี้สองราย ลูกหนี้ “ผิดนัด” คือไม่จ่ายหนี้ตามกำหนด ทีมสินเชื่อประเมินโอกาสผิดนัดในหนึ่งปีไว้ดังนี้ (สมมติ ตัวเลขสูงขนาดนี้คือลูกหนี้ที่แย่มาก):

  • รายแรก $p=0.7$
  • รายที่สอง $q=0.6$

ถ้ารู้แค่สองตัวเลขนี้ โอกาสที่ผิดนัดทั้งคู่อาจเป็นเท่าไรได้บ้าง

เฉลย

ใช้ Fréchet bounds แบบเดียวกับตัวอย่างหุ้นลงพร้อมกัน ให้ $j_{\min}$ กับ $j_{\max}$ คือขอบล่างและขอบบนของโอกาสที่ผิดนัดทั้งคู่:

\[\begin{aligned}j_{\min}&=\max(0,\,0.7+0.6-1)=0.3,\\j_{\max}&=\min(0.7,\,0.6)=0.6.\end{aligned}\]

ช่วงนี้ไม่เริ่มที่ศูนย์ เพราะ $0.7+0.6=1.3$ เกิน 1 สองเหตุการณ์จึงต้องทับกันอย่างน้อย $1.3-1=0.3$ ถ้าลูกหนี้สองรายอิสระกันจะได้ $0.7\times0.6=0.42$ ซึ่งอยู่ในช่วง

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
// 1) table: rows X = -2, 0, 2 ; columns MSFT up, down
const joint = [[.05, .15], [.30, .20], [.25, .05]];
const xs = [-2, 0, 2];
const pX = joint.map(row => row[0] + row[1]);                 // [0.2, 0.5, 0.3]
const pY = [0, 1].map(j => joint.reduce((s, row) => s + row[j], 0)); // [0.6, 0.4]
const meanX = pX.reduce((s, p, i) => s + p * xs[i], 0);        // 0.2
console.log({ pX, pY, meanX });

// 2) triangle f = 2 on 0 <= y <= x <= 1: marginals by midpoint integration
const integrate = (g, a, b, n = 10000) => {
  let s = 0; const h = (b - a) / n;
  for (let i = 0; i < n; i++) s += g(a + (i + .5) * h) * h;
  return s;
};
const fX = x => (x < 0 || x > 1) ? 0 : integrate(() => 2, 0, x);   // 2x
const fY = y => (y < 0 || y > 1) ? 0 : integrate(() => 2, y, 1);   // 2(1-y)
console.log({ fX06: fX(.6), fY03: fY(.3),
  cdfX03: integrate(x => 2 * x, 0, .3), cdfY03: integrate(y => 2 * (1 - y), 0, .3),
  EX: integrate(x => 2 * x * x, 0, 1), EY: integrate(y => 2 * y * (1 - y), 0, 1) });

// 3) fold check: X = max(U,V), Y = min(U,V) on a fine grid of (U,V)
let below = 0, minBelow = 0; const m = 400;
for (let i = 0; i < m; i++) for (let j = 0; j < m; j++) {
  const u = (i + .5) / m, v = (j + .5) / m;
  if (Math.max(u, v) <= .3) below++;
  if (Math.min(u, v) <= .3) minBelow++;
}
console.log({ PmaxLE03: below / m / m, PminLE03: minBelow / m / m }); // 0.09, 0.51

// 4) Frechet bounds for marginals p and q
const frechet = (p, q) => [Math.max(0, p + q - 1), Math.min(p, q)];
console.log(frechet(.2, .2), frechet(.2, .4), frechet(.7, .6));
// [0, 0.2]  [0, 0.2]  [0.3, 0.6]

สิ่งที่ควรตอบได้หลังอ่าน

  • “ไม่สนใจอีกตัว” แปลว่ารวมทุกค่าของมัน: AAPL ลง 2% คือ $0.05+0.15=0.20$ ไม่ใช่ 0.15 (ทิ้งวันที่ MSFT ขึ้นไป) และไม่ใช่ 0.375 (ตอบคำถามที่รู้แล้วว่า MSFT ลง)
  • จาก joint CDF ได้ marginal โดยดันเกณฑ์ของอีกตัวไปที่อนันต์: $F_X(x)=F_{X,Y}(x,+\infty)$ ท่าเดียวกันดึงหุ้นบางตัวออกจากเวกเตอร์ของหุ้นหลายตัวได้
  • จาก density ได้ marginal โดยอินทิเกรตตามแกนที่ไม่สนใจ ขอบอินทิกรัลมาจาก support เช่นบนสามเหลี่ยมได้ $2x$ และ $2(1-y)$ ไม่ใช่ 2
  • marginal density สูงเกิน 1 ได้ เช่น $f_Y(0.3)=1.4$ แต่พื้นที่รวมต้องเป็น 1 เสมอ
  • marginal ไม่กำหนดโอกาสเกิดพร้อมกัน: marginal 0.20 กับ 0.20 ยอมให้โอกาสร่วมเป็นค่าใดก็ได้ตั้งแต่ 0 ถึง 0.20

marginal รวมทุกกรณีของอีกตัว หน้าถัดไป conditional distribution ทำตรงข้าม คือเลือกเฉพาะกรณีที่รู้แล้ว เช่นวันที่ MSFT ลง แล้วปรับสเกลให้รวมได้ 1 อีกครั้ง การปรับสเกลนั้นก็คือ $0.15/0.40=0.375$ คำตอบของนักวิเคราะห์คนที่สองในโจทย์ต้นหน้า
