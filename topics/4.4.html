4.4 Polya's Urn and Share Martingales

เมื่อผลในอดีตเพิ่มโอกาสของสีเดิม สัดส่วนยังเป็น martingale ที่มีค่าเฉลี่ยคงที่ แต่แต่ละโหลนิ่งลงที่ค่าต่างกันไปทั่วทั้งช่วง

หุ้นตัวเดียวกันมักซื้อขายได้ในหลายตลาด ตลาดในที่นี้คือ exchange ที่รับคำสั่งซื้อขายเข้ามา แล้วจับคู่คนซื้อกับคนขาย ทีมกลยุทธ์ของบริษัทหนึ่งกำลังดูตลาดใหม่สองแห่ง ชื่อ A กับ B ที่เปิดพร้อมกัน และอยากรู้ว่าในระยะยาว คำสั่งซื้อขายจะแบ่งไปที่สองตลาดอย่างไร

ส่วนแบ่งของตลาด A คือสัดส่วนของคำสั่งทั้งหมดที่ไปลงที่ A เช่นคำสั่ง 100 คำสั่ง ไปที่ A 60 คำสั่ง ส่วนแบ่งของ A คือ $60/100=60\%$ ทีมใช้แบบจำลองสมมติที่เรียบง่าย:

  • ตอนเริ่ม แต่ละตลาดมีคำสั่งเก่าอยู่ข้างละ 1 คำสั่ง ส่วนแบ่งจึงเท่ากันที่ $1/2=50\%$
  • คำสั่งใหม่แต่ละคำสั่งเลือกตลาด A ด้วยโอกาสเท่ากับส่วนแบ่งของ A ในตอนนั้น ถ้า A มีส่วนแบ่ง 60% คำสั่งถัดไปก็ไปที่ A ด้วยโอกาส 60%
  • เหตุผลของกติกานี้คือสภาพคล่อง (liquidity) ตลาดที่มีคำสั่งรออยู่มากจับคู่ได้เร็วและได้ราคาดี คนจึงอยากส่งคำสั่งไปตลาดที่ใหญ่กว่า ตลาดที่นำอยู่จึงยิ่งดึงคำสั่งเพิ่ม

เมื่อคำสั่งสะสมไปเป็นหมื่น ส่วนแบ่งจะเข้าใกล้ 50:50 เหมือนสัดส่วนหัวของการโยนเหรียญหรือไม่ และโอกาสที่สองตลาดยังสูสีกัน (ส่วนแบ่งของ A อยู่ระหว่าง 45% ถึง 55%) เป็นเท่าไร

ลองตอบก่อนเปิดเฉลย

ไม่เข้าใกล้ 50:50 ค่าเฉลี่ยของส่วนแบ่งยังเป็น 50% ทุกเวลา แต่ถ้ามีตลาดคู่แบบนี้หลายคู่ แต่ละคู่จะนิ่งลงที่ส่วนแบ่งต่างกัน และส่วนแบ่งระยะยาวกระจายเท่า ๆ กันทั่วช่วง 0 ถึง 1 หน้านี้จะพิสูจน์ข้อนี้ทีละขั้น

เมื่อโอกาสกระจายเท่ากันทั่วช่วงที่ยาว 1 โอกาสของช่วงย่อยใดก็ตามเท่ากับความยาวของช่วงนั้น โอกาสที่ส่วนแบ่งระยะยาวอยู่ระหว่าง 45% ถึง 55% จึงเป็นแค่ $0.55-0.45=0.10$ คือ 10% และโอกาสที่ A ได้ส่วนแบ่ง 90% ขึ้นไปก็เป็น $1-0.90=0.10$ เท่ากัน

เทียบกับเหรียญที่โยนอิสระ 10,000 ครั้ง สัดส่วนหัวมี SD (standard deviation คือระยะที่ค่ามักแกว่งห่างจากค่าเฉลี่ย) เท่ากับ $\sqrt{0.5\times0.5/10{,}000}=0.005$ ตามสูตรของ binomial distribution ขอบช่วง 45% และ 55% ห่างจาก 50% ข้างละ $0.05/0.005=10$ SD โอกาสที่เหรียญอยู่ในช่วงนี้จึงแทบเป็น 100%

ภาพรวมก่อนลงสูตร

เรื่องแบบนี้ศึกษาง่ายที่สุดด้วยของเล่นชิ้นเดียว คือโหลใส่ลูกบอล เรียกว่าโหลของ Pólya (Pólya's urn) ตามชื่อนักคณิตศาสตร์ George Pólya กติกามีสี่ข้อ:

  • เริ่มด้วยลูกแดง 1 ลูก และลูกเขียว 1 ลูก
  • หยิบสุ่มออกมาหนึ่งลูก แล้วดูสี
  • ใส่ลูกนั้นคืน แล้วเติมลูกสีเดียวกันลงไปอีกหนึ่งลูก
  • ทำซ้ำไปเรื่อย ๆ โหลจึงโตขึ้นครั้งละหนึ่งลูก

ลูกแดงคือคำสั่งที่ไปตลาด A ลูกเขียวคือคำสั่งที่ไปตลาด B สัดส่วนลูกแดงในโหลจึงคือส่วนแบ่งของ A และโอกาสหยิบได้แดงก็เท่ากับสัดส่วนแดงพอดี ตรงกับกติกาของทีมกลยุทธ์ สีที่ถูกหยิบได้ลูกเพิ่ม จึงมีโอกาสถูกหยิบอีกมากขึ้น เรียกว่าการเสริมแรง (reinforcement) ต่างจากเหรียญที่การโยนแต่ละครั้งไม่เกี่ยวกันเลย

เครื่องมือหลักของหน้านี้คือ martingale จาก filtration และ martingale martingale คือปริมาณสุ่มที่ค่าเฉลี่ยของค่าครั้งหน้า เมื่อรู้ทุกอย่างที่เห็นมาแล้ว เท่ากับค่าตอนนี้พอดี พูดง่าย ๆ คือมันไม่มีแนวโน้มขึ้นหรือลง (ไม่มี drift) คำถามแรกจึงเป็น: ในโหลนี้ อะไรเป็น martingale

จำนวนลูกแดงไม่ใช่ เพราะมันเพิ่มขึ้นได้อย่างเดียว แต่สัดส่วนลูกแดงเป็น martingale และสัดส่วนติดอยู่ระหว่าง 0 กับ 1 เสมอ ข้อนี้ทำให้มันต่างจาก ระบบเดิมพันแบบทบ (เพิ่มเงินเดิมพันเป็นสองเท่าทุกครั้งที่แพ้) ระบบทบมีโอกาสเล็กนิดเดียวที่จะขาดทุนก้อนใหญ่มาก สัดส่วนที่ติดอยู่ในช่วงแคบไม่มีก้อนใหญ่แบบนั้น ทฤษฎีจึงรับรองได้ว่าสัดส่วนต้องนิ่งลงที่ค่าหนึ่ง แต่ไม่ได้บอกว่าค่านั้นคือ ½

รูปด้านล่างคือสองครั้งแรกของโหล วางสูงต่ำตามสัดส่วนแดง จากนั้นหน้านี้เดินตามลำดับนี้:

  • ขั้นที่ 1 และ 2 เขียนกติกาเป็นโอกาส แล้วนับสองครั้งแรกด้วยมือ
  • ขั้นที่ 3 และ 4 พิสูจน์ว่าสัดส่วนเป็น martingale แล้วใช้มันพยากรณ์
  • ขั้นที่ 5 และ 6 หาการแจกแจงหลังหยิบ $n$ ครั้ง แล้วตอบคำถามสูสีที่ 100 ครั้ง
  • ขั้นที่ 7 แสดงว่าในระยะยาวสัดส่วนนิ่งลง และค่าที่นิ่งเป็น Uniform(0,1) คือทุกค่าระหว่าง 0 ถึง 1 มีโอกาสเท่ากัน
  • ขั้นที่ 8 มองโหลเป็นเหรียญที่ไม่รู้ว่าเอียงแค่ไหน แล้วเดาความเอียงแบบ Bayes
  • ขั้นที่ 9 ขยายไปโหลที่เริ่มด้วยแดง $a$ ลูก และเขียว $b$ ลูก
ศัพท์ที่ใช้ในหัวข้อนี้
สภาพคล่อง (liquidity)
ความง่ายในการซื้อขายได้ทันทีในราคาที่ดี ตลาดที่มีคำสั่งรออยู่มากมีสภาพคล่องสูง
Pólya's urn
โหลที่หยิบลูกออกมาหนึ่งลูก ใส่คืน แล้วเติมลูกสีเดียวกันอีกหนึ่งลูก ใช้เป็นแบบจำลองพื้นฐานของเรื่องที่ “ยิ่งนำยิ่งได้เปรียบ” เช่นส่วนแบ่งตลาดที่ยิ่งใหญ่ยิ่งดึงลูกค้า
การเสริมแรง (reinforcement) และ path dependence
ผลที่เกิดไปแล้วดันโอกาสครั้งต่อไปให้ไปทางเดิม ผลระยะยาวจึงขึ้นกับว่าช่วงแรกเกิดอะไรก่อน path dependence แปลตรง ๆ ว่าผลขึ้นกับเส้นทางที่เดินมา
Martingale และ submartingale
martingale คือปริมาณสุ่มที่ค่าเฉลี่ยของค่าครั้งหน้า เมื่อรู้ทุกอย่างที่เห็นมาแล้ว เท่ากับค่าตอนนี้ คือไม่มีแนวโน้มขึ้นหรือลง submartingale คือปริมาณที่ค่าเฉลี่ยครั้งหน้ามากกว่าหรือเท่ากับค่าตอนนี้ คือมีแนวโน้มขึ้น
Exchangeability
สลับลำดับของผล โดยให้จำนวนของแต่ละสีเท่าเดิม แล้วโอกาสไม่เปลี่ยน เช่นแดงแล้วเขียว กับเขียวแล้วแดง มีโอกาสเท่ากัน เงื่อนไขนี้อ่อนกว่าความเป็นอิสระมาก การหยิบจากโหลไม่อิสระกัน แต่ยังสลับลำดับได้ และมันทำให้การนับโอกาสง่ายขึ้นมาก
Martingale convergence theorem
ทฤษฎีบทที่บอกว่า martingale ที่ค่าไม่หลุดออกนอกช่วงจำกัด จะนิ่งลงที่ค่าหนึ่งในแทบทุกเส้นทาง นักคณิตศาสตร์เรียกว่าลู่เข้า “ด้วยความน่าจะเป็นหนึ่ง” หน้านี้ใช้มันรับรองว่าสัดส่วนแดงนิ่งลงแน่ แต่ทฤษฎีบทไม่ได้บอกว่านิ่งที่ไหน
Uniform(0,1)
การแจกแจงที่ทุกค่าระหว่าง 0 ถึง 1 มีโอกาสเท่ากัน density เป็น 1 ตลอดช่วง โอกาสของช่วงย่อยจึงเท่ากับความยาวของช่วงนั้น
Beta distribution
การแจกแจงบนช่วง 0 ถึง 1 ที่ density เป็นค่าคงที่คูณ $x^{a-1}(1-x)^{b-1}$ ใช้บรรยายสัดส่วนที่ยังไม่แน่นอน เช่นส่วนแบ่งระยะยาว หรือความเอียงของเหรียญที่ไม่รู้ค่า Beta(1,1) ก็คือ Uniform(0,1)
Doob martingale
คำพยากรณ์ของปริมาณ $Y$ ตัวเดียว ที่ปรับใหม่ทุกครั้งที่ได้ข้อมูลเพิ่ม เขียนเป็น $\mathbb E_n[Y]$ ลำดับคำพยากรณ์นี้เป็น martingale เสมอ ใช้ตรวจว่าการปรับคำพยากรณ์มีทิศที่ทายล่วงหน้าได้หรือไม่ ถ้าทายได้ แปลว่าคำพยากรณ์ยังใช้ข้อมูลไม่เต็มที่

ขั้นที่ 1 — เขียนกติกาเป็นโอกาสการเปลี่ยนสถานะ

ทุกการคำนวณในหน้านี้ใช้ข้อเท็จจริงเดียว: ถ้ารู้ว่าตอนนี้ในโหลมีอะไร ครั้งหน้าจะเป็นอะไรได้บ้าง และด้วยโอกาสเท่าไร ขั้นนี้จึงแปลกติกาของโหลเป็นสูตรก่อน

หลังหยิบ $n$ ครั้ง โหลมีลูกทั้งหมด $2+n$ ลูก เพราะเริ่มที่ 2 ลูก และแต่ละครั้งเติม 1 ลูก ถ้าตอนนี้มีแดง $k$ ลูก ก็มีเขียว $n+2-k$ ลูก การหยิบสุ่มให้ทุกลูกมีโอกาสเท่ากัน โอกาสได้แดงจึงเป็นจำนวนลูกแดงหารด้วยจำนวนลูกทั้งหมด สัญลักษณ์ $P(X_{n+1}=k+1\mid X_n=k)$ อ่านว่า โอกาสที่ครั้งหน้ามีแดง $k+1$ ลูก เมื่อรู้ว่าตอนนี้มีแดง $k$ ลูก

\[ \begin{aligned} P(X_{n+1}=k+1\mid X_n=k)&=\frac{k}{n+2}\\ P(X_{n+1}=k\mid X_n=k)&=\frac{n+2-k}{n+2} \end{aligned} \]

ได้แดงแปลว่าเติมแดง จำนวนแดงจึงขยับจาก $k$ เป็น $k+1$ ได้เขียวแปลว่าเติมเขียว จำนวนแดงจึงอยู่ที่ $k$ เท่าเดิม สองกรณีนี้ครอบคลุมทุกอย่างที่เกิดได้ โอกาสจึงรวมกันได้ $\frac{k+(n+2-k)}{n+2}=1$ พอดี

โอกาสครั้งหน้าขึ้นกับ $k$ ที่สะสมมา การหยิบแต่ละครั้งจึงไม่อิสระกันเหมือนการโยนเหรียญ แต่อดีตส่งผลผ่านตัวเลขตัวเดียวคือ $X_n$ เราไม่ต้องจำว่าสีไหนมาก่อนหลัง รู้แค่ว่าตอนนี้มีแดงกี่ลูกก็พอ

ขั้นที่ 2 — นับสองครั้งแรกด้วยมือ

ก่อนพิสูจน์อะไรแบบทั่วไป ลองนับทุกเส้นทางของสองครั้งแรกด้วยมือ จะได้เห็นว่าการเสริมแรงเปลี่ยนผลลัพธ์อย่างไร เมื่อเทียบกับการโยนเหรียญ

โจทย์ให้อะไรมาบ้าง:

  • เริ่มด้วยแดง 1 เขียว 1 ให้ R แทนหยิบได้แดง และ G แทนหยิบได้เขียว เช่น RG คือครั้งแรกได้แดง ครั้งที่สองได้เขียว
  • ครั้งแรกโหลมี 2 ลูก แต่ละสีจึงมีโอกาส $\tfrac12$
  • ถ้าครั้งแรกได้แดง โหลกลายเป็นแดง 2 เขียว 1 ครั้งที่สองจึงได้แดงด้วยโอกาส $\tfrac23$ และได้เขียวด้วยโอกาส $\tfrac13$ ถ้าครั้งแรกได้เขียว ก็กลับกัน

โอกาสของแต่ละเส้นทางคือโอกาสของครั้งแรกคูณโอกาสของครั้งที่สอง

\[ \begin{aligned} P(RR)&=\tfrac12\cdot\tfrac23=\tfrac13\\ P(RG)&=\tfrac12\cdot\tfrac13=\tfrac16\\ P(GR)&=\tfrac12\cdot\tfrac13=\tfrac16\\ P(GG)&=\tfrac12\cdot\tfrac23=\tfrac13 \end{aligned} \]

คำตอบ: หลังสองครั้ง จำนวนครั้งที่ได้แดงเป็น 0, 1 หรือ 2 และแต่ละค่ามีโอกาส ⅓ เท่ากัน ค่า 1 มาจากสองเส้นทางรวมกัน คือ $P(RG)+P(GR)=\tfrac16+\tfrac16=\tfrac13$ ตอนนั้นโหลมี 4 ลูก สัดส่วนแดงจึงเป็น $\tfrac14,\tfrac24,\tfrac34$ อย่างละ ⅓ ค่าเฉลี่ยของสัดส่วนคือ $\tfrac13(\tfrac14+\tfrac12+\tfrac34)=\tfrac12$ เท่ากับตอนเริ่ม

เทียบกับเหรียญยุติธรรมสองครั้ง ได้หัว 0 ครั้งด้วยโอกาส $\tfrac12\cdot\tfrac12=\tfrac14$ ได้หัว 2 ครั้งก็ $\tfrac14$ และได้หัว 1 ครั้งด้วยโอกาส $1-\tfrac14-\tfrac14=\tfrac12$ เหรียญจึงกองน้ำหนักไว้ตรงกลาง แต่โหลเกลี่ยน้ำหนักเท่ากันทุกค่า ทั้งที่ค่าเฉลี่ยเท่ากัน

ตรวจเองใน 10 วินาที: RG กับ GR มีโอกาสเท่ากันแม้ลำดับต่างกัน เพราะตัวส่วนเป็น $2\times3$ ทั้งคู่ (ขนาดโหลไม่ขึ้นกับสีที่ได้) และตัวเศษเป็น $1\times1$ ทั้งคู่ (ลูกแดงลูกเดียวตอนหยิบแดง และลูกเขียวลูกเดียวตอนหยิบเขียว) การสลับลำดับโดยให้จำนวนแต่ละสีเท่าเดิมแล้วโอกาสไม่เปลี่ยน เรียกว่า exchangeability ขั้นที่ 5 จะใช้สมบัตินี้นับการแจกแจงหลัง $n$ ครั้ง

ขั้นที่ 3 — จำนวนแดงโตขึ้น แต่สัดส่วนไม่มี drift

ตอนนี้ถึงคำถามหลักของหน้า คืออะไรในโหลเป็น martingale เหตุที่ต้องรู้คือ ถ้าได้ martingale มา คำพยากรณ์ก็ได้มาฟรี เพราะค่าเฉลี่ยของอนาคตคือค่าตอนนี้ ขั้นที่ 4 จะใช้ข้อนี้

ตัวเลือกแรกคือจำนวนแดง $X_n$ แต่มันไม่เคยลดลงและมีโอกาสเพิ่ม ค่าเฉลี่ยครั้งหน้าจึงต้องมากกว่าตอนนี้ ตัวเลือกที่สองคือสัดส่วน $M_n=X_n/(n+2)$ เราหาค่าเฉลี่ยครั้งหน้าของทั้งสองตัว ด้วยโอกาสจากขั้นที่ 1 โดยตั้ง $X_n=k$ ค่าเฉลี่ยคือผลของแต่ละกรณีคูณโอกาสของกรณีนั้น แล้วรวมกัน

\[ \begin{aligned} \mathbb E_n[X_{n+1}]&=(k+1)\frac{k}{n+2}+k\,\frac{n+2-k}{n+2}\\ &=\frac{k^2+k+kn+2k-k^2}{n+2}\\ &=\frac{k\,(n+3)}{n+2}\\ \mathbb E_n[M_{n+1}]&=\frac{\mathbb E_n[X_{n+1}]}{n+3}\\ &=\frac{k}{n+2}=M_n \end{aligned} \]

ค่าเฉลี่ยของจำนวนแดงครั้งหน้าคือ $k$ คูณ $\frac{n+3}{n+2}$ ซึ่งมากกว่า 1 จำนวนแดงจึงคาดว่าจะโตทุกครั้ง ปริมาณที่ค่าเฉลี่ยครั้งหน้าไม่ต่ำกว่าค่าตอนนี้แบบนี้เรียกว่า submartingale ไม่ใช่ martingale

จังหวะสำคัญคือการหารด้วย $n+3$ หลังหยิบครั้งที่ $n+1$ โหลมี $n+3$ ลูกแน่นอน ไม่ว่าจะได้สีอะไร ตัวหารนี้จึงไม่สุ่ม และดึงออกมานอกค่าเฉลี่ยได้ ตัวคูณการโต $n+3$ ของตัวเศษจึงหักกับตัวหารพอดี เหลือ $k/(n+2)$ ซึ่งก็คือสัดส่วนวันนี้ $M_n$

นิยาม martingale ใน filtration และ martingale ขออีกสองข้อ ข้อแรก $M_n$ ต้องคำนวณได้จากสิ่งที่เห็นแล้ว (adapted) ซึ่งจริงเพราะเรานับลูกในโหลได้ ข้อสอง ขนาดเฉลี่ยของ $M_n$ ต้องมีค่าจำกัด (integrable) ซึ่งจริงเพราะ $M_n$ อยู่ระหว่าง 0 กับ 1 ครบทั้งสามข้อ สัดส่วนแดงจึงเป็น martingale

ภาพของเรื่องนี้คือคานในรูปด้านล่าง ถ้าได้แดง สัดส่วนขยับขึ้นนิดเดียว ถ้าได้เขียว สัดส่วนขยับลงมาก แต่แดงมีโอกาสมากกว่า ในขนาดที่ชดเชยกันพอดี

ขั้นที่ 4 — พยากรณ์: แปลงจำนวนเป็นสัดส่วนก่อนเสมอ

ขั้นที่ 3 ให้ของมีค่ามา: ค่าเฉลี่ยของสัดส่วนในอนาคตเท่ากับสัดส่วนวันนี้ ข้อนี้ใช้ได้ไม่ใช่แค่ครั้งถัดไป แต่ทุกครั้งข้างหน้า เพราะต่อทีละครั้งได้ด้วย tower property เคล็ดคือต้องพยากรณ์ตัวที่เป็น martingale คือสัดส่วน แล้วค่อยแปลงกลับเป็นจำนวนลูก

โจทย์ให้อะไรมาบ้าง:

  • หยิบไปแล้ว $n=100$ ครั้ง โหลจึงมี $100+2=102$ ลูก
  • ในโหลมีแดง $X_{100}=70$ ลูก นับลูกตั้งต้นด้วย แปลว่าหยิบได้แดง $J_{100}=70-1=69$ ครั้ง
  • คำถาม: หลังหยิบครบ 200 ครั้ง โหลจะมีแดงเฉลี่ยกี่ลูก ตอนนั้นโหลมี $200+2=202$ ลูก
\[ \begin{aligned} M_{100}&=70/102\approx0.6863\\ \mathbb E_{100}[M_{200}]&=M_{100}=70/102\\ \mathbb E_{100}[X_{200}]&=202\times\frac{70}{102}\\ &\approx138.63 \end{aligned} \]

คำตอบ: ประมาณ 138.63 ลูก ขนาดโหลที่ 202 ลูกรู้แน่นอนล่วงหน้า จึงคูณกับสัดส่วนที่คาดได้ตรง ๆ ค่าเฉลี่ยไม่จำเป็นต้องเป็นจำนวนเต็ม แม้ในแต่ละเส้นทางจำนวนลูกจะเป็นจำนวนเต็มเสมอ

ตรวจเองใน 10 วินาที: ถ้าตอบ 70 แปลว่าถือว่าจำนวนแดงเป็น martingale ซึ่งเลือกผิดตัว ถ้าตอบ $202\times\tfrac12=101$ แปลว่าลืมข้อมูล 100 ครั้งที่เห็นแล้ว และกลับไปใช้สัดส่วนตอนเริ่ม ทั้งสองคำตอบห่างจาก 138.63 มาก

ขั้นที่ 5 — การแจกแจงหลัง $n$ ครั้ง: ทุกจำนวนแดงมีโอกาสเท่ากัน

หลังสองครั้ง ทุกค่าได้ ⅓ เท่ากัน หลังสิบครั้ง ทุกค่าได้ 1/11 เท่ากัน ขั้นนี้แสดงว่าเป็นแบบนี้ทุก $n$ แล้วใช้ผลนั้นวัดว่าสัดส่วนแดงของโหลหลาย ๆ ใบกระจายกว้างแค่ไหน

เริ่มจากลำดับเดียว ลองดู $n=3$ ที่ได้แดง 2 ครั้ง ซึ่งมีสามลำดับ โอกาสของแต่ละลำดับคือโอกาสทีละครั้งคูณกัน โดยแต่ละครั้งดูจากของที่อยู่ในโหลตอนนั้น

\[ \begin{aligned} P(RRG)&=\tfrac12\cdot\tfrac23\cdot\tfrac14=\tfrac1{12}\\ P(RGR)&=\tfrac12\cdot\tfrac13\cdot\tfrac24=\tfrac1{12}\\ P(GRR)&=\tfrac12\cdot\tfrac13\cdot\tfrac24=\tfrac1{12} \end{aligned} \]

ทั้งสามเท่ากัน เพราะตัวส่วนเป็น $2\cdot3\cdot4$ เสมอ ขนาดโหลโตครั้งละ 1 ไม่ว่าได้สีอะไร ส่วนตัวเศษฝั่งแดงเป็น $1\cdot2$ (จำนวนลูกแดงตอนหยิบแดงครั้งที่ 1 และครั้งที่ 2) และฝั่งเขียวเป็น $1$ แค่แทรกกันคนละลำดับ

กรณีทั่วไปคือหยิบ $n$ ครั้งได้แดง $j$ ครั้ง ตัวส่วนคือ $2\cdot3\cdots(n+1)=(n+1)!$ ตัวเศษฝั่งแดงคือ $1\cdot2\cdots j=j!$ และฝั่งเขียวคือ $(n-j)!$ จากนั้นคูณด้วยจำนวนลำดับที่มีแดง $j$ ครั้ง

\[ \begin{aligned} P(\text{one sequence})&=\frac{j!\,(n-j)!}{(n+1)!}\\ P(J_n=j)&=\binom nj\frac{j!\,(n-j)!}{(n+1)!}\\ &=\frac{n!}{(n+1)!}=\frac{1}{n+1} \end{aligned} \]

เมื่อ $J_n$ เป็น $0,1,\ldots,n$ อย่างละ $\tfrac1{n+1}$ ก็หาความกว้างได้ทันที ค่าเฉลี่ยคือ $n/2$ เพราะการแจกแจงสมมาตรรอบกลาง ค่าเฉลี่ยของ $J_n^2$ ใช้สูตรผลบวกกำลังสอง $\sum_{j=0}^n j^2=\frac{n(n+1)(2n+1)}6$ แล้ว variance คือค่าเฉลี่ยของกำลังสอง ลบกำลังสองของค่าเฉลี่ย สุดท้าย $M_n=(1+J_n)/(n+2)$ การบวก 1 ไม่เปลี่ยน variance ส่วนการหารด้วย $n+2$ หาร variance ด้วย $(n+2)^2$

\[ \begin{aligned} \mathbb E[J_n]&=\tfrac n2\\ \mathbb E[J_n^2]&=\frac1{n+1}\sum_{j=0}^n j^2\\ &=\frac{n(2n+1)}6\\ \operatorname{Var}(J_n)&=\frac{n(2n+1)}6-\frac{n^2}4\\ &=\frac{n(n+2)}{12}\\ \operatorname{Var}(M_n)&=\frac{\operatorname{Var}(J_n)}{(n+2)^2}\\ &=\frac{n}{12\,(n+2)} \end{aligned} \]

ผลที่สำคัญคือโอกาสของลำดับหนึ่งไม่ขึ้นกับว่าแดงมาก่อนหรือหลัง มันขึ้นกับจำนวนแดง $j$ เท่านั้น นี่คือ exchangeability ที่เห็นในสองครั้งแรก มันทำให้นับง่าย แค่คูณด้วยจำนวนลำดับ $\binom nj=\frac{n!}{j!\,(n-j)!}$ เหมือนใน binomial distribution แล้ว $j!$ กับ $(n-j)!$ ก็หักกันหมด เหลือ $\tfrac1{n+1}$ ซึ่งไม่มี $j$ อยู่เลย ทุกจำนวนแดงตั้งแต่ 0 ถึง $n$ จึงมีโอกาสเท่ากัน กรณีไม่ได้แดงเลยหรือได้แดงทุกครั้งก็ใช้สูตรเดียวกัน เพราะ $0!=1$

ความกว้างบอกเรื่องที่ค่าเฉลี่ยไม่บอก SD ของสัดส่วนคือรากที่สองของ variance หลัง 1 ครั้งได้ $\sqrt{1/(12\cdot3)}=\tfrac16\approx0.167$ หลัง 2 ครั้งได้ $\sqrt{2/(12\cdot4)}\approx0.204$ หลัง 2,000 ครั้งได้ $\sqrt{2000/(12\cdot2002)}\approx0.2885$ SD โตขึ้น และเข้าหา $\sqrt{1/12}\approx0.2887$ เพราะ $n/(n+2)$ เข้าหา 1 โหลแต่ละใบจึงยิ่งต่างกันมากขึ้น ตรงข้ามกับเหรียญ ที่ SD ของสัดส่วนหัวคือ $0.5/\sqrt n$ ซึ่งหดลงเรื่อย ๆ

ขั้นที่ 6 — หลัง 100 ครั้ง โอกาสที่ยังสูสีเท่าไร

ตอนนี้ตอบคำถามของทีมกลยุทธ์ได้แล้ว แต่ตอบที่จำนวนคำสั่งจำกัดก่อน คือ 100 คำสั่ง “สูสี” แปลว่าสัดส่วนแดง ซึ่งคือส่วนแบ่งของตลาด A อยู่ระหว่าง 45% ถึง 55% นับขอบด้วย

โจทย์ให้อะไรมาบ้าง:

  • หยิบ $n=100$ ครั้ง โหลมี 102 ลูก สัดส่วนแดงคือ $M_{100}=(1+J_{100})/102$
  • จากขั้นที่ 5 จำนวนครั้งที่ได้แดง $J_{100}$ เป็น $0,1,\ldots,100$ อย่างละ $1/101$

แปลงเงื่อนไขของสัดส่วนเป็นเงื่อนไขของ $J_{100}$ โดยคูณทุกข้างด้วย 102 แล้วลบ 1 จากนั้นนับว่ามีจำนวนเต็มกี่ค่าที่เข้าเงื่อนไข

\[ \begin{aligned} 0.45\le\frac{1+J_{100}}{102}&\le0.55\\ 45.9\le1+J_{100}&\le56.1\\ 44.9\le J_{100}&\le55.1\\ 45\le J_{100}&\le55\\ P(\text{near tie})&=\frac{11}{101}\approx10.9\% \end{aligned} \]

คำตอบ: ราว 10.9% จำนวนเต็มที่เข้าเงื่อนไขคือ 45 ถึง 55 มีทั้งหมด $55-45+1=11$ ค่า และแต่ละค่ามีโอกาส $1/101$

เทียบกับเหรียญยุติธรรม 100 ครั้ง ช่วงเดียวกันคือได้หัว 45 ถึง 55 ครั้ง บวกโอกาส binomial ของทุกค่าในช่วงตรง ๆ (โค้ดท้ายหน้า) ได้ราว 72.9% ตรวจด้วย normal approximation ก็ได้ตัวเลขเดียวกัน ในสูตรนี้ $\Phi$ คือโอกาสที่ Normal มาตรฐานไม่เกินค่าที่ใส่ และใช้ 55.5 แทน 55 เพราะแท่งของค่า 55 กว้างตั้งแต่ 54.5 ถึง 55.5 วิธีนี้เรียกว่าปรับความต่อเนื่อง (continuity correction)

\[ \begin{aligned} \text{SD}&=\sqrt{100\times0.5\times0.5}=5\\ z&=\frac{55.5-50}{5}=1.1\\ P&\approx2\,\Phi(1.1)-1\\ &=2(0.8643)-1\approx72.9\% \end{aligned} \]

ตรวจเองใน 10 วินาที: ช่วงยาว $0.55-0.45=0.10$ บนการแจกแจงที่เกือบราบทั้งช่วง 0 ถึง 1 จึงควรได้ราว 10% ตัวเลข 10.9% เกินมานิด เพราะค่าที่เป็นไปได้เป็นจุดห่างกัน และจุดที่ขอบทั้งสองข้างถูกนับเข้ามาด้วย ได้ 11 จุดจาก 101 จุด แทนที่จะเป็น 10 จาก 100

ขั้นที่ 7 — ลิมิตมีจริง และลิมิตเป็น Uniform(0,1)

ขั้นที่ 5 บอกว่าที่ $n$ ใด ๆ โหลหลายใบกระจายอย่างไร แต่ทีมกลยุทธ์ถามเรื่องระยะยาว ซึ่งมีสองคำถามย่อย ข้อแรก สัดส่วนของโหลใบเดียวนิ่งลงจริงไหม ข้อสอง ถ้านิ่ง นิ่งที่ไหน

ข้อแรกตอบด้วยทฤษฎี เพราะ $M_n$ เป็น martingale (ขั้นที่ 3) และติดอยู่ระหว่าง 0 กับ 1 ทุกเวลา martingale convergence theorem จึงรับรองว่าในแทบทุกเส้นทาง $M_n$ นิ่งลงที่ค่าหนึ่ง เรียกค่านั้นว่า $M_\infty$ ข้อสองตอบด้วยการนับ คือดูว่าการแจกแจงของขั้นที่ 5 เข้าหาอะไรเมื่อ $n$ โตขึ้น เครื่องมือคือ CDF (cumulative distribution function) $P(M_n\le x)$ คือโอกาสที่สัดส่วนไม่เกิน $x$

\[ \begin{aligned} P(M_n\le x)&\approx\frac{x\,(n+2)}{n+1}\\ \lim_{n\to\infty}P(M_n\le x)&=x,\qquad0\lt x\lt1\\ \mathbb E[M_\infty]&=\int_0^1x\,dx=\tfrac12\\ \operatorname{Var}(M_\infty)&=\int_0^1x^2\,dx-\tfrac14\\ &=\tfrac13-\tfrac14=\tfrac1{12} \end{aligned} \]

สูตรแรกมาจากการนับจุด $M_n$ มีค่าที่เป็นไปได้ $\tfrac{1}{n+2},\tfrac{2}{n+2},\ldots,\tfrac{n+1}{n+2}$ แต่ละจุดมีโอกาส $\tfrac1{n+1}$ จุดที่ไม่เกิน $x$ มีราว $x(n+2)$ จุด (ปัดลงเป็นจำนวนเต็ม) คูณกันได้สูตรแรก เช่น $n=100$ และ $x=0.3$ มีจุดที่ไม่เกิน 0.3 อยู่ $\lfloor0.3\times102\rfloor=30$ จุด โอกาสจึงเป็น $30/101\approx0.297$ ใกล้ 0.3 แล้ว

เมื่อ $n$ โตขึ้น $\frac{n+2}{n+1}$ เข้าหา 1 CDF จึงเข้าหา $x$ และ $P(M_\infty\le x)=x$ ก็คือ CDF ของ Uniform(0,1) พอดี ค่าเฉลี่ย ½ และ variance $\tfrac1{12}$ ของมันตรงกับค่าที่ขั้นที่ 5 เข้าหา

ทำไมทฤษฎีนี้ใช้ได้ที่นี่ แต่ใช้กับระบบเดิมพันแบบทบไม่ได้ ในระบบทบมีโอกาสเล็กมากที่จะแพ้ติดกันจนขาดทุนก้อนใหญ่มาก โอกาสเล็กคูณก้อนใหญ่ยังได้ตัวเลขที่ไม่เล็ก มันจึงพยุงค่าเฉลี่ยไว้ที่ศูนย์ พอผ่านลิมิต เส้นทางนั้นหายไป และค่าเฉลี่ยที่มันแบกไว้ก็หายไปด้วย สัดส่วนแดงไม่มีปัญหานี้ เพราะมันไม่มีวันเกิน 1 โอกาสเล็กจึงแบกได้แค่ค่าเล็ก ค่าเฉลี่ยจึงผ่านลิมิตมาได้ครบ $\mathbb E[M_\infty]=\tfrac12=M_0$ และใช้ optional stopping ได้กับทุกกติกาการหยุด (ค่าเฉลี่ยตอนหยุดเท่ากับค่าตอนเริ่ม แม้จะเลือกเวลาหยุดจากสิ่งที่เห็น)

ประโยคที่ต้องแยกให้ออก: “นิ่งลง” ไม่ได้แปลว่า “นิ่งลงที่ ½” โหลแต่ละใบนิ่งที่ค่าของตัวเอง และค่านั้นกระจายราบทั้งช่วง 0 ถึง 1 โอกาสที่ลิมิตเป็น 0 หรือ 1 พอดีคือศูนย์ เพราะจุดเดียวมีความยาวศูนย์ ฝ่ายหนึ่งจึงมักได้ส่วนใหญ่ แต่ไม่กินรวบทั้งหมด

ขั้นที่ 8 — มองอีกมุม: โหลคือเหรียญที่ไม่รู้ความเอียง

ขั้นที่ 7 ได้ลิมิต Uniform มาจากการนับ แต่ยังไม่ตอบว่าทำไมต้องเป็น Uniform พอดี มีอีกเรื่องหนึ่งที่ให้ผลเหมือนกันทุกประการ และอธิบายเหตุผลได้ชัดกว่า

ลองนึกถึงเหรียญที่เอียงโดยไม่มีใครบอกว่าเอียงแค่ไหน ความเอียง $\theta$ คือโอกาสออกแดงในแต่ละครั้ง ตอนเริ่ม มีคนสุ่ม $\theta$ มาจาก Uniform(0,1) หนึ่งครั้งแล้วเก็บเป็นความลับ จากนั้นโยนเหรียญนั้นซ้ำ ถ้ารู้ $\theta$ การโยนแต่ละครั้งอิสระกัน แต่เราไม่รู้ $\theta$ จึงได้แต่เดาจากผลที่เห็น ขั้นนี้คำนวณสองอย่างของเหรียญนี้ แล้วเทียบกับโหล คือโอกาสได้แดง $j$ ครั้งจาก $n$ ครั้ง และค่าเดาของ $\theta$ หลังเห็นผล

\[ \begin{aligned} P(J_n=j)&=\int_0^1\binom nj\theta^j(1-\theta)^{n-j}\,d\theta\\ &=\binom nj\frac{j!\,(n-j)!}{(n+1)!}=\frac1{n+1}\\ \mathbb E[\theta\mid J_n=j]&=\frac{\int_0^1\theta^{j+1}(1-\theta)^{n-j}\,d\theta}{\int_0^1\theta^{j}(1-\theta)^{n-j}\,d\theta}\\ &=\frac{(j+1)!\,(n-j)!\,/\,(n+2)!}{j!\,(n-j)!\,/\,(n+1)!}\\ &=\frac{j+1}{n+2}=M_n \end{aligned} \]

สูตรแรกหาโอกาสได้แดง $j$ ครั้ง ถ้ารู้ $\theta$ โอกาสนี้คือ binomial แต่เราไม่รู้ $\theta$ จึงเฉลี่ยโอกาส binomial ข้ามทุก $\theta$ ที่เป็นไปได้ โดยแต่ละ $\theta$ มีน้ำหนักเท่ากับ density ของ Uniform ซึ่งเป็น 1 การเฉลี่ยแบบนี้คือ tower property อินทิกรัลที่ได้เรียกว่า Beta integral $\int_0^1\theta^j(1-\theta)^{n-j}d\theta=\frac{j!\,(n-j)!}{(n+1)!}$ ผลคือ $1/(n+1)$ ตรงกับโหลทุกตัวอักษร ถ้าตัด $\binom nj$ ออก โอกาสของลำดับเดียวก็ตรงกับขั้นที่ 5 ด้วย โหลของ Pólya กับเหรียญเอียงแบบสุ่มจึงเป็นแบบจำลองเดียวกันที่เล่าคนละแบบ

สูตรที่สองคือค่าเดาของ $\theta$ หลังเห็นแดง $j$ ครั้งจาก $n$ ครั้ง Bayes' theorem บอกว่าความเชื่อเรื่อง $\theta$ หลังเห็นข้อมูล แปรตามความเชื่อเดิมคูณโอกาสของข้อมูล ความเชื่อเดิมคือ Uniform ซึ่งมี density เป็น 1 จึงเหลือแค่ $\theta^j(1-\theta)^{n-j}$ แล้วหารด้วยพื้นที่ใต้มันเพื่อให้รวมเป็น 1 ค่าเฉลี่ยของ $\theta$ จึงเป็นอัตราส่วนของ Beta integral สองตัว ตัวบนมี $\theta$ เพิ่มอีกหนึ่งตัว ใช้สูตร Beta integral กับทั้งสองตัว แล้วแฟกทอเรียลหักกันเหลือ $\frac{j+1}{n+2}$ ผลนี้มีชื่อว่า Laplace's rule of succession และมันเท่ากับสัดส่วนแดงในโหลพอดี

สัดส่วนแดง $M_n$ จึงคือค่าเดาล่าสุดของความเอียง เมื่อข้อมูลมากขึ้นไม่สิ้นสุด ค่าเดาก็เข้าหาความเอียงจริง $M_\infty=\theta$ และ $\theta$ ถูกสุ่มมาจาก Uniform นี่คือเหตุที่ลิมิตของโหลราบทั้งช่วง

มุมนี้ให้บทเรียนที่ใช้ได้ทั่วไป $M_n=\mathbb E_n[\theta]$ คือคำพยากรณ์ของปริมาณเดียว ($\theta$) ที่ปรับใหม่ทุกครั้งที่ได้ข้อมูลเพิ่ม คำพยากรณ์แบบนี้เป็น martingale เสมอ เรียกว่า Doob martingale เหตุผลคือ ถ้ารู้ล่วงหน้าว่าครั้งหน้าจะปรับขึ้น ก็ควรปรับขึ้นตั้งแต่ตอนนี้ คำพยากรณ์ที่ใช้ข้อมูลเต็มที่จึงไม่มีทิศการปรับที่ทายล่วงหน้าได้

ขั้นที่ 9 — เริ่มด้วยแดง $a$ เขียว $b$: ลิมิตเป็น Beta(a, b)

ตลาดจริงไม่ได้เริ่มจากศูนย์ ตลาดที่เปิดมานานมีคำสั่งสะสมอยู่แล้ว ในภาษาโหล นี่คือการเริ่มด้วยลูกมากกว่า ให้ $a$ คือจำนวนลูกแดงตอนเริ่ม และ $b$ คือจำนวนลูกเขียวตอนเริ่ม ทั้งคู่เป็นจำนวนเต็มบวก กติกาเติมสีเดิมครั้งละหนึ่งลูกเหมือนเดิม

โหลที่เริ่มใหญ่กว่าเฉื่อยกว่า เพราะลูกที่เติมหนึ่งลูกขยับสัดส่วนได้น้อยกว่า เช่นได้แดงครั้งแรก โหล 1:1 กระโดดจาก $\tfrac12$ เป็น $\tfrac23\approx0.667$ แต่โหล 10:10 ขยับจาก $\tfrac{10}{20}=0.5$ เป็นแค่ $\tfrac{11}{21}\approx0.524$

สัดส่วน $M_n=(a+J_n)/(a+b+n)$ ยังเป็น martingale ด้วยการพิสูจน์ก้าวเดียวแบบขั้นที่ 3 (เปลี่ยน $n+2$ เป็น $a+b+n$) ค่าเฉลี่ยจึงคงที่ที่ $a/(a+b)$ ตลอด ลิมิตของมันมีการแจกแจงแบบ Beta(a, b) เขียนว่า $M_\infty\sim\operatorname{Beta}(a,b)$ ข้างล่างเขียน density ของมัน แล้วแทนตัวเลขของโหล 10:10

\[ \begin{aligned} M_\infty&\sim\operatorname{Beta}(a,b)\\ f(x)&=C_{a,b}\,x^{a-1}(1-x)^{b-1}\\ C_{a,b}&=\frac{(a+b-1)!}{(a-1)!\,(b-1)!}\\ C_{10,10}&=\frac{19!}{9!\,9!}=923{,}780\\ f(0.5)&=923{,}780\times0.5^{9}\times0.5^{9}\\ &=923{,}780/262{,}144\approx3.52 \end{aligned} \]

เหตุผลเดียวกับมุมเหรียญเอียงในขั้นที่ 8 โหลเริ่ม $a:b$ ให้โอกาสทุกลำดับเท่ากับเหรียญที่ความเอียงสุ่มมาจาก Beta(a, b) ลิมิตจึงเป็น Beta(a, b) ตัวคงที่ $C_{a,b}$ มีไว้ให้พื้นที่ใต้ density เป็น 1 เพราะ Beta integral แบบเดียวกับขั้นที่ 8 ให้ $\int_0^1x^{a-1}(1-x)^{b-1}dx=\frac{(a-1)!\,(b-1)!}{(a+b-1)!}$ ลองแทน $a=b=1$ ได้ $C_{1,1}=\frac{1!}{0!\,0!}=1$ และ $f(x)=1$ คือ Uniform ตามเดิม

โหล 10:10 เริ่มที่สัดส่วน ½ เท่ากับโหล 1:1 แต่ลิมิตโป่งตรงกลาง density ที่ 0.5 สูงราว 3.52 ซึ่งเกิน 1 ได้ เพราะโอกาสคือพื้นที่ใต้เส้น ไม่ใช่ความสูง อินทิเกรต density นี้เชิงตัวเลข (Simpson's rule ในโค้ดท้ายหน้า) ได้ว่าโอกาสที่ลิมิตอยู่ใน 45% ถึง 55% คือราว 34.2% เทียบกับ 10% ของโหล 1:1 ส่วนสองปลาย คือต่ำกว่า 10% หรือสูงกว่า 90% อินทิเกรตแบบเดียวกันได้รวมกันแค่ราว 0.00079%

ขั้นนี้ยังอธิบายข้อมูลระหว่างทางด้วย โหล 1:1 ที่หยิบครั้งแรกได้แดง ตอนนี้มีแดง 2 เขียว 1 จึงเหมือนโหลที่เริ่มใหม่แบบ 2:1 ลิมิตเมื่อรู้ข้อมูลนี้คือ Beta(2,1) มี $C_{2,1}=\frac{2!}{1!\,0!}=2$ จึงได้ density $f(x)=2x$ และค่าเฉลี่ย $\tfrac{2}{2+1}=\tfrac23$ ถ้าครั้งแรกได้เขียว ลิมิตคือ Beta(1,2) ค่าเฉลี่ย $\tfrac13$ ก่อนรู้ผลครั้งแรก ค่าเฉลี่ยรวมจึงเป็น $\tfrac12\cdot\tfrac23+\tfrac12\cdot\tfrac13=\tfrac12$ ตาม tower property

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

พยากรณ์จำนวนแทนสัดส่วน: ความผิดคือคิดว่าจำนวนแดงเป็น martingale ทั้งที่มันเป็น submartingale โหลที่มีแดง 70 ลูกหลังหยิบ 100 ครั้ง ถ้าคาดว่าหลัง 200 ครั้งยังมี 70 ลูก จะผิด คำตอบที่ถูกพยากรณ์ผ่านสัดส่วน ได้ $202\times\tfrac{70}{102}\approx138.63$ ลูก คำตอบผิดต่ำไป $138.63-70=68.63$ ลูก

ใช้คำตอบของลิมิตกับจำนวนครั้งจำกัด: ความผิดคือใช้ Uniform ซึ่งเป็นคำตอบของระยะยาวเท่านั้น กับโหลที่เพิ่งหยิบไม่กี่ครั้ง ถามว่าหลังหยิบสองครั้ง สัดส่วนแดงอยู่ระหว่าง 0.20 ถึง 0.35 ด้วยโอกาสเท่าไร คำตอบผิดใช้ลิมิต ได้ $0.35-0.20=0.15$ คำตอบที่ถูกนับจุดจริง หลังสองครั้งสัดส่วนเป็นได้แค่ ¼, ½, ¾ อย่างละ ⅓ และมีแค่ $\tfrac14=0.25$ ที่อยู่ในช่วง โอกาสจริงจึงเป็น $\tfrac13\approx0.33$

เอากฎจำนวนมากของเหรียญมาใช้: ความผิดคือคิดว่าโหลจะเข้าใกล้ 50:50 เหมือนเหรียญ law of large numbers บอกว่าสัดส่วนหัวของเหรียญที่โยนอิสระเข้าใกล้ ½ แต่การหยิบจากโหลไม่อิสระกัน กฎนี้จึงใช้ตรง ๆ ไม่ได้ ดูที่ 2,000 ครั้ง เหรียญมี SD ของสัดส่วนหัว $\sqrt{0.5\times0.5/2000}\approx0.01118$ ขอบช่วง 45% ถึง 55% ห่างจากกลาง $0.05/0.01118\approx4.47$ SD เหรียญจึงอยู่ในช่วงเกือบ 100% ส่วนโหลนับแบบขั้นที่ 6 ได้ $J_{2000}$ ตั้งแต่ 900 ถึง 1,100 รวม 201 ค่า โอกาสจึงเป็นแค่ $201/2001\approx10.0\%$ ทั้งที่ค่าเฉลี่ยเท่ากัน

ใช้ผลของหน้านี้กับกติกาอื่น: ความผิดคือยืมผลไปใช้โดยไม่ตรวจกติกา ผลทั้งหน้าพึ่งกติกาสองข้อ คือเติมลูกสีเดิมครั้งละหนึ่งลูกเท่ากันทั้งสองสี และโอกาสเลือกเท่ากับสัดส่วนพอดี ถ้าเติมสีหนึ่งมากกว่าอีกสี หรือตลาดใหญ่ได้เปรียบเกินสัดส่วน (เช่นมีส่วนแบ่ง 60% แต่ดึงคำสั่งใหม่ได้ 70%) สัดส่วนอาจไม่ใช่ martingale และลิมิตไม่ใช่ Beta บางกติกาทำให้ฝ่ายหนึ่งกินรวบจริง ๆ

ใช้ทำอะไรบนโต๊ะจริง

โหลของ Pólya เป็นภาพตั้งต้นของ path dependence ในตลาด สภาพคล่องดึงคำสั่งเพิ่ม และคำสั่งที่เพิ่มก็สร้างสภาพคล่องเพิ่ม วงจรนี้เกิดกับส่วนแบ่งของตลาดซื้อขาย มาตรฐานของสัญญาซื้อขาย หรือผู้ออก ETF (กองทุนที่ซื้อขายในตลาดเหมือนหุ้น) ที่ทำกองทุนตามดัชนีเดียวกัน ผู้ที่ออกตัวก่อนอาจนิ่งที่ส่วนแบ่งที่ขึ้นกับโชคช่วงแรก ไม่ใช่คุณภาพอย่างเดียว

ตัวเลขที่สำคัญสำหรับการวางแผนจึงเป็นความกว้างของผลระยะยาว (Uniform หรือ Beta) ไม่ใช่ค่าเฉลี่ย ทีมที่วางแผนว่า “ค่าเฉลี่ยคือ 50% เราก็น่าจะได้ราว 50%” ประเมินความเสี่ยงต่ำไปมาก เพราะโหล 1:1 มีโอกาสสูสีแค่ 10%

มุมเหรียญเอียงใช้ติดตาม hit rate (สัดส่วนครั้งที่สัญญาณเทรดทายทิศถูก) ของสัญญาณที่ยังไม่รู้ค่าจริง เริ่มจากความเชื่อแบบ Beta แล้วบวกจำนวนครั้งที่ถูกและผิดเข้าไปตามที่เห็น แบบเดียวกับการเติมลูกในโหล มุม Doob martingale ใช้ตรวจคำพยากรณ์ ถ้านักวิเคราะห์ปรับตัวเลขกำไรของปีเดียวกันขึ้นติดกันหลายครั้ง จนทายได้ว่าครั้งหน้าจะปรับขึ้นอีก แปลว่าคำพยากรณ์นั้นยังใช้ข้อมูลไม่เต็มที่

ตามขั้นที่ 5 $J_3$ เป็น 0, 1, 2, 3 อย่างละ $\tfrac1{3+1}=\tfrac14$ หลังสามครั้งโหลมี $3+2=5$ ลูก และมีแดง $1+J_3$ ลูก สัดส่วนจึงเป็น $\tfrac15,\tfrac25,\tfrac35,\tfrac45$ อย่างละ ¼ ค่าเฉลี่ยคือ $\tfrac14\cdot\tfrac{1+2+3+4}{5}=\tfrac14\cdot2=\tfrac12$ เท่าตอนเริ่ม ตามที่ martingale บอก

2. โหล 1:1 หยิบครั้งแรกได้แดง และกำลังจะหยิบครั้งที่สอง ค่าเฉลี่ยของสัดส่วนแดงหลังครั้งที่สองเท่าไร และค่าเฉลี่ยของจำนวนลูกแดงหลังครั้งที่สองเท่าไร

เฉลย

ตอนนี้โหลมีแดง 2 เขียว 1 สัดส่วน ⅔ สัดส่วนเป็น martingale ค่าเฉลี่ยครั้งหน้าจึงเป็น ⅔ ตรงกับรูปคาน จำนวนแดงครั้งหน้าเป็น 3 (โอกาส ⅔) หรือ 2 (โอกาส ⅓) ค่าเฉลี่ยคือ $\tfrac23(3)+\tfrac13(2)=\tfrac83\approx2.67$ ลูก ตรวจ: หลังครั้งที่สองโหลมี 4 ลูก และ $\tfrac{8/3}{4}=\tfrac23$ ตรงกับสัดส่วน ข้อควรระวังคือหารด้วยขนาดโหลให้ถูกเวลา ตอนนี้ 3 ลูก ครั้งหน้า 4 ลูก

3. ตลาดสองแห่งเปิดมาสักพักแล้ว มีคำสั่งเก่าข้างละ 10 คำสั่ง จึงเป็นโหล 10:10 หลังจากนั้นมีคำสั่งใหม่ 20 คำสั่ง ไปตลาด A (แดง) 15 คำสั่ง ส่วนแบ่งของ A ตอนนี้เท่าไร ค่าเฉลี่ยของส่วนแบ่งระยะยาวเท่าไร และส่วนแบ่งระยะยาวเมื่อรู้ข้อมูลนี้มีการแจกแจงอะไร

เฉลย

แดง $10+15=25$ ลูก เขียว $10+(20-15)=15$ ลูก รวม $25+15=40$ ลูก ส่วนแบ่งตอนนี้คือ $25/40=0.625$ ค่าเฉลี่ยของลิมิตเท่ากับสัดส่วนตอนนี้ คือ 0.625 เพราะ martingale ที่ติดอยู่ในช่วง 0 ถึง 1 ส่งค่าเฉลี่ยผ่านลิมิตได้ (ขั้นที่ 7) ส่วนการแจกแจง ให้มองเหมือนเริ่มโหลใหม่แบบ 25:15 ตามขั้นที่ 9 ลิมิตจึงเป็น Beta(25, 15) ซึ่งมีค่าเฉลี่ย $\tfrac{25}{25+15}=0.625$ ตรงกัน

เปิดดูโค้ด 
// exact distribution of red draws J_n for an urn starting a red, b green
function urn(n, a = 1, b = 1) {
  let p = [1];
  for (let t = 0; t < n; t++) {
    const next = Array(t + 2).fill(0);
    p.forEach((mass, j) => {
      const red = (a + j) / (a + b + t);
      next[j] += mass * (1 - red);
      next[j + 1] += mass * red;
    });
    p = next;
  }
  return p;
}
console.log(urn(2), urn(10)[0]);              // [1/3,1/3,1/3], 1/11
// one-step martingale check from X_n = k red after n draws
const step = (n, k) => ((k + 1) * k / (n + 2) + k * (n + 2 - k) / (n + 2)) / (n + 3);
console.log(step(1, 2), 2 / 3);               // both 0.6667
console.log(202 * 70 / 102);                  // 138.63
const near = urn(100).slice(45, 56).reduce((s, x) => s + x, 0);
console.log(near, 11 / 101);                  // 0.1089
// coin with 100 tosses, 45..55 heads
let pr = 2 ** -100, coin = 0;
for (let h = 0; h <= 100; h++) { if (h >= 45 && h <= 55) coin += pr; pr *= (100 - h) / (h + 1); }
console.log(coin);                            // 0.7287
// Beta(10,10) area between 0.45 and 0.55 by Simpson's rule
const f = x => 923780 * x ** 9 * (1 - x) ** 9;
let s = f(0.45) + f(0.55); const h = 0.1 / 1000;
for (let i = 1; i < 1000; i++) s += (i % 2 ? 4 : 2) * f(0.45 + i * h);
console.log(s * h / 3, f(0.5));               // 0.3421, 3.524

สิ่งที่ควรตอบได้หลังอ่าน

  • จำนวนแดงเป็น submartingale (มีแนวโน้มโต) แต่สัดส่วนแดง $X_n/(n+2)$ เป็น martingale เพราะตัวหารโตตามจังหวะเดียวกันพอดี โหลที่มีแดง 70 ลูกหลังหยิบ 100 ครั้ง จึงคาดได้ $202\times\tfrac{70}{102}\approx138.63$ ลูกที่ 200 ครั้ง
  • โหล 1:1 ให้จำนวนครั้งที่ได้แดงกระจายสม่ำเสมอบน 0 ถึง $n$ อย่างละ $\tfrac1{n+1}$ SD ของสัดส่วนข้ามโหลโตขึ้นเข้าหา $\sqrt{1/12}\approx0.289$ ไม่หดลงแบบเหรียญ
  • สัดส่วนติดอยู่ในช่วง 0 ถึง 1 จึงนิ่งลงแน่นอน และลิมิตเป็น Uniform(0,1) โอกาสสูสี (45% ถึง 55%) ในระยะยาวคือ $0.55-0.45=10\%$ และหลัง 100 ครั้งคือ $11/101\approx10.9\%$
  • โหลคือเหรียญที่ความเอียงสุ่มมาจาก Uniform สัดส่วนแดงคือค่าเดาความเอียงแบบ Bayes และคำพยากรณ์ของสิ่งเดียวกันที่ปรับตามข้อมูลเป็น martingale เสมอ
  • โหลเริ่ม $a:b$ ให้ลิมิต Beta(a, b) โหลใหญ่เฉื่อยกว่า เช่นโหล 10:10 มีโอกาสสูสีราว 34.2%
