4.4 Polya's Urn and Share Martingales

ค่าเฉลี่ยคงที่ แต่แต่ละเส้นทางอาจลงเอยห่างกันมาก เมื่ออดีตเปลี่ยนโอกาสในอนาคต

ตลาดซื้อขายสองแห่งเริ่มด้วยส่วนแบ่งเท่ากัน หากคำสั่งซื้อขายใหม่มีแนวโน้มไหลไปยังตลาดที่มีส่วนแบ่งมากอยู่แล้ว เมื่อมีคำสั่งมากขึ้นส่วนแบ่งจะยิ่งใกล้ 50:50 เหมือนการโยนเหรียญหรือไม่?

เปิดคำตอบตั้งต้น

ไม่จำเป็น ในโหล Pólya ที่เริ่มแดงหนึ่งลูก เขียวหนึ่งลูก ส่วนแบ่งแดงมีค่าเฉลี่ย 50% ทุกเวลา แต่ส่วนแบ่งระยะยาวกระจายสม่ำเสมอทั่วช่วง 0 ถึง 1 โอกาสอยู่ใกล้เสมอในช่วง 45%–55% จึงมีเพียง 10% ไม่ได้เข้าใกล้ 100%

นี่เป็นแบบจำลองกลไกการเสริมแรง ไม่ใช่คำพยากรณ์ส่วนแบ่งตลาดจริง เราจะเริ่มจากการนับสองครั้ง แล้วพิสูจน์ว่าสิ่งที่เป็น martingale คือ สัดส่วน ไม่ใช่จำนวนลูกแดง

1. กติกาและตัวแปร: หยิบ คืน แล้วเติมสีเดิม

เริ่มโหลด้วยแดงหนึ่งลูกและเขียวหนึ่งลูก ทุกครั้งหยิบอย่างสม่ำเสมอจากลูกทั้งหมด ดูสี ใส่ลูกเดิมคืน และเติมลูกสีเดียวกันอีกหนึ่งลูก ขนาดโหลจึงเพิ่มครั้งละหนึ่ง ไม่ใช่การหยิบออกแล้วไม่คืน

สัญลักษณ์ความหมายหลังหยิบ $n$ ครั้งหน่วย
$J_n$จำนวนครั้งที่หยิบได้แดงครั้ง
$R_n=1+J_n$ลูกแดงในโหล รวมลูกตั้งต้นลูก
$n+2$ลูกทั้งหมดในโหลลูก
$M_n=R_n/(n+2)$สัดส่วนแดง และโอกาสได้แดงครั้งหน้าไม่มีหน่วย
$\mathcal F_n$ประวัติสีที่เห็นถึงครั้งที่ $n$ชุดข้อมูล

เมื่อรู้ $\mathcal F_n$ แล้ว ครั้งหน้าลูกแดงเพิ่มหนึ่งด้วยโอกาส $M_n$ หรือคงเดิมด้วยโอกาส $1-M_n$ การหยิบแต่ละครั้งจึงไม่เป็นอิสระ เพราะสีที่เห็นเปลี่ยนองค์ประกอบของโหล

2. นับสองครั้งแรกก่อนใช้สูตร

ให้ R แทนแดงและ G แทนเขียว ครั้งแรกแต่ละสีมีโอกาสครึ่งหนึ่ง แต่เมื่อได้แดงครั้งแรก โอกาสแดงครั้งต่อไปเพิ่มเป็น 2/3

\[ \begin{aligned} P(RR)&=\tfrac12\cdot\tfrac23=\tfrac13\\ P(RG)&=\tfrac12\cdot\tfrac13=\tfrac16\\ P(GR)&=\tfrac12\cdot\tfrac13=\tfrac16\\ P(GG)&=\tfrac12\cdot\tfrac23=\tfrac13 \end{aligned} \]

รวมตามจำนวนแดงที่หยิบได้ จะได้ $J_2=0,1,2$ อย่างละ 1/3 จึงมีสัดส่วนแดง $M_2=1/4,1/2,3/4$ อย่างละ 1/3 ค่าเฉลี่ยเท่ากับ $(1/4+1/2+3/4)/3=1/2$ แต่ไม่ได้กระจุกที่ 1/2 แบบเหรียญสองครั้งซึ่งให้จำนวนหัว 0, 1, 2 ด้วยโอกาส 1/4, 1/2, 1/4

RG และ GR มีโอกาสเท่ากันแม้ลำดับต่างกัน นี่คือตัวอย่างของ exchangeability: สลับตำแหน่งโดยคงจำนวนแต่ละสีแล้วโอกาสไม่เปลี่ยน สมบัตินี้อ่อนกว่าความเป็นอิสระมาก

3. จำนวนโต แต่สัดส่วนไม่มี conditional drift

จำนวนลูกแดงไม่ลดลง และมีโอกาสเพิ่ม จึงไม่ใช่ martingale คำนวณโดยถ่วงสองกรณีของครั้งหน้า

\[ \begin{aligned} \mathbb E_n[R_{n+1}]&=(R_n+1)\frac{R_n}{n+2}\\ &\quad+R_n\left(1-\frac{R_n}{n+2}\right)\\ &=R_n+\frac{R_n}{n+2}\\ &=R_n\frac{n+3}{n+2} \end{aligned} \]

แต่ตัวส่วนของสัดส่วนครั้งหน้าคือ $n+3$ ซึ่งรู้ล่วงหน้า จึงดึงออกจาก conditional expectation ได้

\[ \begin{aligned} \mathbb E_n[M_{n+1}]&=\frac{\mathbb E_n[R_{n+1}]}{n+3}\\ &=\frac{R_n}{n+2}=M_n \end{aligned} \]

$M_n$ คำนวณจากข้อมูลปัจจุบันจึง adapted และอยู่ระหว่าง 0 กับ 1 จึง integrable ครบสามเงื่อนไขของ martingale ถ้าครั้งแรกได้แดง $M_1=2/3$ ครั้งหน้าสัดส่วนเป็น 3/4 หรือ 2/4 และค่าเฉลี่ยคือ $(2/3)(3/4)+(1/3)(2/4)=2/3$ ไม่ใช่กลับไป 1/2

4. แปลงจำนวนเป็นสัดส่วนก่อนพยากรณ์

สมมติหยิบไป 100 ครั้ง มีแดงในโหล 70 ลูก คำถามคือหลังครบ 200 ครั้งจะมีแดงเฉลี่ยกี่ลูก? จำนวน 70 นี้รวมลูกตั้งต้นแล้ว จึงแปลว่าหยิบแดงมา 69 ครั้ง

\[ \begin{aligned} M_{100}&=70/102\approx0.686275\\ \mathbb E_{100}[M_{200}]&=70/102\\ \mathbb E_{100}[R_{200}]&=202\,(70/102)\\ &\approx138.62745\ \text{balls} \end{aligned} \]

คำตอบประมาณ 138.63 ลูกเป็นค่าเฉลี่ย ไม่จำเป็นต้องเป็นจำนวนเต็ม เส้นทางจริงยังมีจำนวนเต็มเสมอ ถ้าตอบ 70 กำลังถือว่าจำนวนเป็น martingale ผิดตัว ถ้าตอบ 101 กำลังลืมข้อมูลปัจจุบันแล้วกลับไปใช้สัดส่วนตั้งต้น 1/2

5. จากโอกาสของลำดับ ไปสู่โอกาสของจำนวน

พิจารณาลำดับหนึ่งที่หยิบ $n$ ครั้งแล้วได้แดง $j$ ครั้ง ตัวส่วนของโอกาสทุกครั้งรวมเป็น $2\cdot3\cdots(n+1)$ ตัวเศษฝั่งแดงวิ่งจาก 1 ถึง $j$ และฝั่งเขียวจาก 1 ถึง $n-j$ ไม่ว่าจะแทรกกันลำดับใด

\[ \begin{aligned} P(\text{one ordered sequence}) &=\frac{j!\,(n-j)!}{(n+1)!}\\ P(J_n=j)&=\binom nj\frac{j!\,(n-j)!}{(n+1)!}\\ &=\frac1{n+1},\qquad j=0,\ldots,n \end{aligned} \]

ต้องคูณ $\binom nj$ เพราะจำนวนแดงเดียวกันเกิดได้หลายลำดับ โดยนิยาม $0!=1$ สูตรจึงรวมกรณีไม่มีแดงหรือแดงทุกครั้งได้ด้วย ตรวจ normalization: มี $n+1$ ค่าคูณโอกาส $1/(n+1)$ รวมเป็นหนึ่ง

\[ M_n\in\left\{\frac1{n+2},\frac2{n+2},\ldots,\frac{n+1}{n+2}\right\}. \]

ทุกสัดส่วนในชุดนี้มีโอกาสเท่ากัน ไม่ใช่ทุกจำนวนจริงระหว่าง 0 กับ 1 มีโอกาสบวก เมื่อ $n=2{,}000$ มี 2,001 ค่าที่เป็นไปได้ แต่ละค่ามีโอกาส 1/2,001

6. หลัง 100 ครั้ง โอกาสใกล้เสมอเท่าไร?

กำหนด “ใกล้เสมอ” ว่าสัดส่วนแดงอยู่ในช่วง 45%–55% รวมขอบด้วย ต้องนับค่า $J_{100}$ ที่เข้าเงื่อนไข ไม่ใช่ใช้ความกว้างของช่วงทันที เพราะยังเป็นการแจกแจงไม่ต่อเนื่อง

\[ \begin{aligned} 0.45\le\frac{1+J_{100}}{102}\le0.55\\ 45.9\le1+J_{100}\le56.1\\ J_{100}\in\{45,46,\ldots,55\}\\ P(0.45\le M_{100}\le0.55)&=\frac{11}{101}\\ &\approx10.8911\% \end{aligned} \]

เทียบกับเหรียญอิสระยุติธรรม 100 ครั้ง ให้ $H$ เป็นจำนวนหัวและใช้สัดส่วน $H/100$ ช่วงเดียวกันคือ 45 ถึง 55 หัว นับทวินามตรง ๆ ได้ประมาณ 72.8747% ถ้าใช้ normal approximation ต้องบอกว่าเป็นค่าประมาณ: ค่าเฉลี่ย 50, SD 5 และการปรับความต่อเนื่องใช้ขอบ 44.5 ถึง 55.5

\[ \begin{aligned} z&=(55.5-50)/5=1.1\\ P(45\le H\le55)&\approx2\Phi(1.1)-1\\ &\approx72.8668\% \end{aligned} \]

ค่าเฉลี่ยเดียวกันไม่ได้กำหนดความกว้างของการแจกแจง การเสริมแรงจึงทำให้คำตอบต่างจากเหรียญอย่างมาก

7. ความกว้างข้ามเส้นทางเพิ่มขึ้นได้ แม้แต่ละเส้นเปลี่ยนน้อยลง

จาก $J_n$ ที่สม่ำเสมอบนจำนวนเต็ม 0 ถึง $n$ ใช้ผลรวมกำลังสองเพื่อหา variance แล้วหารด้วยกำลังสองของตัวส่วนเมื่อแปลงเป็นสัดส่วน

\[ \begin{aligned} \mathbb E[J_n]&=n/2\\ \mathbb E[J_n^2]&=\frac1{n+1}\sum_{j=0}^{n}j^2\\ &=\frac{n(2n+1)}6\\ \operatorname{Var}(J_n)&=\frac{n(2n+1)}6-\frac{n^2}4\\ &=\frac{n(n+2)}{12}\\ \operatorname{Var}(M_n)&=\frac{n}{12(n+2)} \end{aligned} \]

SD ของสัดส่วนหลังหนึ่งครั้งคือ $1/6\approx0.166667$ หลังสองครั้งคือ $\sqrt{1/24}\approx0.204124$ และหลัง 2,000 ครั้งคือประมาณ 0.288531 หน่วยนี้เป็นสัดส่วน: 0.288531 เท่ากับ 28.8531 จุดเปอร์เซ็นต์ ไม่ใช่ผลตอบแทน 28.8531%

ความกว้างนี้วัดการกระจายข้ามโหลจำนวนมาก ไม่ได้บอกว่าภายในโหลหนึ่งสัดส่วนกระโดดแรงขึ้น ที่จริงการเติมหนึ่งลูกมีผลต่อสัดส่วนน้อยลงเมื่อโหลใหญ่ขึ้น

8. ลิมิตมีจริง แล้วลิมิตกระจายอย่างไร?

เพราะ $M_n$ เป็น martingale ที่มีขอบเขต 0 ถึง 1 ทฤษฎี martingale convergence รับรองว่ามันลู่เข้า $M_\infty$ เกือบแน่นอน และขอบเขตเดียวกันทำให้สลับลิมิตกับค่าเฉลี่ยได้ จึงมี $\mathbb E[M_\infty]=1/2$ ตรงข้ามกับระบบทบเดิมพันไร้เพดานใน 4.3

เพื่อระบุการแจกแจงของลิมิต นับจุดที่ไม่เกิน $x$ โดยต้องจำกัดจำนวนจุดให้อยู่ระหว่างศูนย์กับ $n+1$ ด้วย

\[ \begin{aligned} P(M_n\le x)&=\frac{c_n(x)}{n+1}\\ c_n(x)&=\min\!\left(n+1,\max\!\left(0,\lfloor x(n+2)\rfloor\right)\right)\\ \lim_{n\to\infty}P(M_n\le x)&=x,\qquad0\lt x\lt1 \end{aligned} \]

นอกช่วงใช้ CDF เท่ากับ 0 เมื่อ $x\le0$ และเท่ากับ 1 เมื่อ $x\ge1$ การหนีบจำนวนจุดสำคัญ เช่น ที่ $x=1$ หากใช้เพียง $\lfloor x(n+2)\rfloor/(n+1)$ จะได้ค่ามากกว่าหนึ่ง การแจกแจงจึงลู่ไปสู่ Uniform(0,1) และเพราะมีลิมิตเกือบแน่นอนอยู่แล้ว ลิมิตนั้นต้องมีการแจกแจงนี้

\[ \begin{aligned} f_{M_\infty}(x)&=1,\qquad0\lt x\lt1\\ \mathbb E[M_\infty]&=\int_0^1x\,dx=\tfrac12\\ \operatorname{Var}(M_\infty)&=\int_0^1x^2\,dx-\tfrac14=\tfrac1{12}\\ \operatorname{SD}(M_\infty)&\approx0.288675 \end{aligned} \]

การลู่เข้าไม่ได้แปลว่าลู่สู่ค่าเฉลี่ย 1/2 ในทุกโหล และโอกาสที่ลิมิตเท่ากับ 0 หรือ 1 พอดีเป็นศูนย์ คำว่า “ฝ่ายหนึ่งได้ส่วนใหญ่” จึงตรงกว่าการบอกว่าฝ่ายหนึ่งได้ทั้งหมดแน่นอน

9. คำตอบระยะยาว และสิ่งที่ยังไม่ใช่คำตอบธุรกิจ

สำหรับ Uniform(0,1) โอกาสของช่วงเท่ากับความกว้างของช่วง

\[ \begin{aligned} P(0.45\le M_\infty\le0.55)&=0.55-0.45=0.10\\ P(M_\infty\le0.10\text{ or }M_\infty\ge0.90)&=0.10+0.10=0.20 \end{aligned} \]

ถ้าเป็นเหรียญอิสระ 2,000 ครั้ง สัดส่วนหัวมี SD $\sqrt{0.25/2000}\approx0.0111803$ ช่วง 45%–55% ห่างจากกลางประมาณ 4.4721 SD การประมาณปกติโดยยังไม่ปรับความต่อเนื่องให้โอกาสราว 0.999992 ไม่ใช่หนึ่งพอดี สองหางที่ไม่เกิน 10% หรือไม่น้อยกว่า 90% เล็กมากแต่ยังไม่เป็นศูนย์

หากทีม execution ใช้โหลนี้เป็นภาพสมมติเพื่อพิจารณางบ launch credit \$2,000,000 ตัวเลข 10% และ 20% ช่วยเตือนให้วางสถานการณ์หลายแบบ แต่ไม่ได้คำนวณผลตอบแทนของงบหรือบอกว่าควรจ่ายจริง การอนุมัติต้องมีความสัมพันธ์ระหว่างงบ กติกาการเสริมแรง และมูลค่าธุรกิจเพิ่มต่างหาก

10. เริ่มด้วยแดง $a$ ลูก เขียว $b$ ลูก

ให้ $a,b$ เป็นจำนวนเต็มบวก และยังเติมสีเดิมครั้งละหนึ่งลูก สัดส่วนเป็น $M_n=(a+J_n)/(a+b+n)$ ใช้การพิสูจน์ก้าวเดียวแบบเดิมจะได้ martingale ที่มีค่าเฉลี่ยตั้งต้น $a/(a+b)$ ส่วนการแจกแจงของจำนวนแดงที่หยิบได้เปลี่ยนไป

เขียน $(a)_j=a(a+1)\cdots(a+j-1)$ เป็นผลคูณเพิ่มขึ้น และกำหนด $(a)_0=1$ เพื่อครอบคลุมกรณีศูนย์ครั้ง

\[ \begin{aligned} P(J_n=j)&=\binom nj\frac{(a)_j(b)_{n-j}}{(a+b)_n}\\ (a)_j&=\frac{(a+j-1)!}{(a-1)!} \end{aligned} \]

นี่คือ beta-binomial distribution ไม่ใช่ binomial ที่โอกาสแดงคงที่ แทน $a=b=1$ จะกลับมาเป็น $1/(n+1)$ เพราะผลคูณกลายเป็นแฟกทอเรียลที่ตัดกันพอดี

เมื่อ $n$ ใหญ่และ $j/n$ ใกล้ $x$ ภายในช่วง $(0,1)$ ผลคูณ $(j+1)\cdots(j+a-1)$ มีขนาดใกล้ $j^{a-1}$ จึงเกิดรูปร่าง $x^{a-1}(1-x)^{b-1}$ ของ density ลิมิต การประมาณรูปร่างนี้ยังต้องใส่ตัวคงที่ให้พื้นที่รวมเป็นหนึ่ง

\[ \begin{aligned} M_\infty&\sim\operatorname{Beta}(a,b)\\ f(x)&=\frac{(a+b-1)!}{(a-1)!(b-1)!}\\ &\quad\cdot x^{a-1}(1-x)^{b-1},\quad0\lt x\lt1\\ \int_0^1x^{a-1}(1-x)^{b-1}\,dx &=\frac{(a-1)!(b-1)!}{(a+b-1)!} \end{aligned} \]

บรรทัดสุดท้ายอธิบาย normalization โดยตรง และเมื่อ $a=b=1$ ได้ density หนึ่งตามที่พิสูจน์ด้วย CDF แล้ว

11. โหล 10:10 มีความเฉื่อยมากกว่าโหล 1:1

ทั้งสองโหลเริ่มสัดส่วนเท่ากัน แต่เพิ่มหนึ่งลูกแล้วส่งผลไม่เท่ากัน ในโหล 10:10 ลิมิตเป็น Beta(10,10) ซึ่งโป่งกลางแทนที่จะราบ

\[ \begin{aligned} C&=\frac{19!}{9!9!}=923{,}780\\ f(0.5)&=C(0.5)^{18}\approx3.523941\\ f(0.1)&=C(0.1)^9(0.9)^9\approx0.000357891\\ f(0.5)/f(0.1)&\approx9{,}846.40 \end{aligned} \]

density มากกว่าหนึ่งได้ เพราะโอกาสคือ พื้นที่ ไม่ใช่ความสูง ณ จุดเดียว เมื่ออินทิเกรตจริง โอกาสลิมิตอยู่ 45%–55% คือประมาณ 34.2072% และสองปลาย 0%–10% กับ 90%–100% รวมประมาณ 0.00078598% ต้องแยกหน่วยนี้จากความน่าจะเป็น 0.0000078598

ถ้าโหล 1:1 หยิบครั้งแรกได้แดง เราเริ่มวิเคราะห์ต่อจากสถานะ 2:1 ได้ทันที ลิมิตเมื่อรู้ข้อมูลนี้เป็น Beta(2,1) ค่าเฉลี่ย 2/3 ไม่ใช่ 1/2; ค่าเฉลี่ยก่อนรู้ผลยังเป็น $(1/2)(2/3)+(1/2)(1/3)=1/2$ ตาม tower property

ลองเอง — อย่าสลับจำนวน สัดส่วน และความน่าจะเป็น

  1. โหล 1:1 หยิบแล้วสามครั้ง จำนวนแดงที่หยิบได้อาจเป็นค่าใดบ้าง แต่ละค่ามีโอกาสเท่าไร และสัดส่วนใดเป็นไปได้?
  2. หลังหยิบครั้งแรกได้แดง ค่าเฉลี่ยสัดส่วนครั้งหน้าเท่าไร? ค่าเฉลี่ยจำนวนแดงครั้งหน้าเท่าไร?
  3. ในโหล 1:1 ความน่าจะเป็นที่ลิมิตอยู่ระหว่าง 20% และ 35% เท่าไร? นำคำตอบนี้ไปใช้กับหลังหยิบสองครั้งได้หรือไม่?
เฉลยพร้อมเหตุผล
  1. $J_3=0,1,2,3$ อย่างละ 1/4; สัดส่วนเป็น $1/5,2/5,3/5,4/5$ อย่างละ 1/4 ค่าเฉลี่ยยังเป็น 1/2
  2. สัดส่วนเฉลี่ย 2/3 แต่จำนวนแดงเฉลี่ย $(2/3)3+(1/3)2=8/3$ ลูก อย่าทำให้ตัวส่วนคงที่ผิดเวลา
  3. ลิมิตให้ $0.35-0.20=0.15$ หลังสองครั้งมีเพียงสัดส่วน 1/4 ที่เข้าช่วง จึงให้ 1/3 ไม่ใช่ 0.15

ขอบเขตการตีความ: การเสริมแรงไม่ใช่หลักฐานว่าไม่มีวันเปลี่ยนผู้นำ

กฎจำนวนมากสำหรับเหรียญอิสระไม่ได้ใช้กับโหลนี้โดยตรง เพราะโอกาสครั้งหน้าขึ้นกับอดีต แต่ไม่ควรสรุปว่า dependence ทุกชนิดทำลายกฎจำนวนมากทุกแบบ บทเรียนคือจำเป็นต้องตรวจสมมติฐานของทฤษฎีที่ใช้

โหล Eggenberger–Pólya เป็นแบบจำลองคลาสสิกของการเสริมแรงและใช้เป็นภาพของ path dependence ได้ เช่น ส่วนแบ่งที่มากขึ้นอาจเพิ่มสภาพคล่องแล้วดึงคำสั่งใหม่ แต่ตลาดจริงมีคู่แข่งใหม่ การถอนคำสั่ง ข้อจำกัดความจุ และนโยบายเปลี่ยน ถ้าสองสีถูกเติมไม่เท่ากัน หรือโอกาสเลือกไม่เท่ากับสัดส่วน สูตร martingale และ Beta ข้างต้นไม่รับรองว่าจะยังจริง

JavaScript — นับการแจกแจงและอินทิเกรต Beta โดยไม่ใช้ไลบรารี
const near = (a, b, eps = 1e-9) => {
  if (!Number.isFinite(a) || Math.abs(a - b) > eps) throw new Error(`${a} != ${b}`);
};
function distribution(n, a = 1, b = 1, coin = false) {
  let p = [1];
  for (let t = 0; t < n; t++) {
    const next = Array(t + 2).fill(0);
    p.forEach((mass, j) => {
      const red = coin ? 0.5 : (a + j) / (a + b + t);
      next[j] += mass * (1 - red);
      next[j + 1] += mass * red;
    });
    p = next;
  }
  near(p.reduce((x, y) => x + y), 1);
  return p;
}
for (const n of [0, 2, 10, 100]) {
  const p = distribution(n);
  p.forEach(x => near(x, 1 / (n + 1)));
  near(p.reduce((s, mass, j) => s + mass * ((j + 1) / (n + 2) - 0.5) ** 2, 0), n / (12 * (n + 2)));
}
for (const [n, r] of [[1, 2], [5, 3], [40, 17]]) {
  const m = r / (n + 2);
  near(m * (r + 1) / (n + 3) + (1 - m) * r / (n + 3), m);
}
near(202 * 70 / 102, 138.62745098039215);
const urn100 = distribution(100).slice(45, 56).reduce((x, y) => x + y);
const coin100 = distribution(100, 1, 1, true).slice(45, 56).reduce((x, y) => x + y);
near(urn100, 11 / 101); near(coin100, 0.7287469759261653);
const cdf = (n, x) => Math.min(n + 1, Math.max(0, Math.floor(x * (n + 2)))) / (n + 1);
near(cdf(2, 0), 0); near(cdf(2, 1), 1); near(cdf(2, 0.25), 1 / 3);
near(cdf(2, -1), 0); near(cdf(2, 2), 1);
function integrate(f, lo, hi, steps = 10000) {
  const h = (hi - lo) / steps;
  let sum = f(lo) + f(hi);
  for (let i = 1; i < steps; i++) sum += (i % 2 ? 4 : 2) * f(lo + i * h);
  return sum * h / 3;
}
const density = x => 923780 * x ** 9 * (1 - x) ** 9;
near(integrate(density, 0, 1), 1);
const betaCenter = integrate(density, 0.45, 0.55);
const betaExtremes = 2 * integrate(density, 0, 0.1);
near(betaCenter, 0.3420718248432156);
near(betaExtremes, 0.000007859764654256006, 1e-12);
near(density(0.5), 3.5239410400390625);
near(density(0.5) / density(0.1), 9846.400420048505, 1e-7);
const normal = x => Math.exp(-x * x / 2) / Math.sqrt(2 * Math.PI);
near(2 * integrate(normal, 0, 1.1), 0.7286678781072347);
near(2 * integrate(normal, 0, Math.sqrt(20)), 0.999992255783569, 1e-9);
console.log({urn100, coin100, betaCenter, betaExtremes});

โปรแกรมนับสถานะทุกแบบด้วยการส่งต่อความน่าจะเป็น จึงไม่มี sampling error ส่วนอินทิเกรตใช้ Simpson approximation และตรวจพื้นที่รวมของ density ให้เป็นหนึ่ง ค่าที่พิมพ์เป็นความน่าจะเป็น ต้องคูณ 100 ก่อนเขียนเป็นเปอร์เซ็นต์

สรุปบทเรียนเรื่องส่วนแบ่ง

  • จำนวนแดงเพิ่มได้ แต่สัดส่วนแดงเป็น martingale เพราะทั้งตัวเศษและขนาดโหลโตตามกติกาที่สอดคล้องกัน
  • โหล 1:1 ให้ $J_n$ สม่ำเสมอบนจำนวนเต็ม 0 ถึง $n$ และลิมิตสัดส่วนเป็น Uniform(0,1)
  • แต่ละเส้นทางลู่เข้าได้พร้อมกับที่ผลลัพธ์ข้ามเส้นทางยังกระจายกว้าง ค่าเฉลี่ย 1/2 ไม่ใช่แรงดึงกลับเข้ากลาง
  • หลัง 100 ครั้งโอกาสใกล้เสมอคือ 11/101; ที่ลิมิตคือ 10% ต้องแยกจำนวนครั้งจำกัดออกจากระยะยาว
  • โหลเริ่ม $a:b$ ให้ลิมิต Beta(a,b) ภายใต้กติกาเติมสีเดิมเท่ากันครั้งละหนึ่งลูก
