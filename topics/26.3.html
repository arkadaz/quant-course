26.3 Rotations, Projections, and Push-Outs

factor model เดียวกันเขียนได้หลายแบบโดยที่ผลตอบแทน กำไรขาดทุนรวม และความเสี่ยงรวมไม่ขยับ แต่คำตอบว่า factor ไหนทำเงินหรือเสียเงินขยับตามแบบที่เลือก และการลดหรือเพิ่มจำนวน factor มีราคาที่ต้องจ่าย

พอร์ต dollar-neutral ที่ถือ A \$3 ล้าน B −\$2 ล้าน C \$4 ล้าน D −\$5 ล้าน เสียเงินจาก factor \$66,000 ในวันเดียว รายงาน A บอกว่า momentum เสีย \$69,000 tech ได้ \$3,000 และ market \$0 รายงาน B จาก risk model ตัวเดียวกันที่ผู้ให้บริการแปลงให้ factor ไม่สัมพันธ์กัน บอกว่า market เสีย \$5,528 momentum เสีย \$61,272 และ tech ได้ \$800 ผู้จัดการพอร์ตแย้งว่า “exposure ต่อ market ของเราเป็นศูนย์ รายงาน B ต้องผิด” จริงไหม?

ลองตอบก่อนเปิดเฉลย

ไม่จริง ทั้งสองฉบับถูก รวมได้ −\$66,000 เท่ากัน และให้ความเสี่ยงจาก factor \$48,063 ต่อวันเท่ากัน รายงาน B วัด factor แต่ละตัวหลังหักส่วนที่ขยับตามตลาดออก momentum ขยับตามตลาดด้วย correlation −0.20 เดิมพัน momentum \$13.8 ล้าน จึงพก beta ต่อตลาดไว้ $13.8\times(-0.07)=-0.966$ ล้าน tech พกอีก +0.275 ล้าน รวม −\$0.691 ล้าน วันที่ตลาดขึ้น 0.80% จึงเสีย \$5,528 ในบรรทัด market การแบ่งเป็นการเลือกระบบพิกัด ยอดรวมไม่เคยขึ้นกับมัน

ภาพรวมก่อนลงสูตร

ในสมการ factor model เราเขียน $\mathbf B\mathbf f$ ราวกับว่า loading และ factor return เป็นของที่มีอยู่จริงในธรรมชาติ แต่ถ้าแทรก $\mathbf C^{-1}\mathbf C$ ซึ่งคูณกันได้ identity เข้าไปตรงกลาง ผลคูณไม่เปลี่ยนเลย ที่เปลี่ยนคือสิ่งที่เราเรียกว่า “factor” ข้อมูลผลตอบแทนจึงเลือกแบบให้เราไม่ได้ ต้องเลือกเอง เหมือนเลือกทิศของแกนในกราฟ จุดเดิมอยู่ที่เดิม แต่พิกัดของมันเปลี่ยนตามแกน การแปลงแบบนี้เรียกว่า rotation

รูปข้างล่างคือความคิดทั้งหมดในภาพเดียว ลูกศรคือเดิมพันของพอร์ตในพิกัดที่ทำให้ความยาวเท่ากับความเสี่ยง วาดด้วยแกนสองชุด ความยาวเท่ากันทุกชุด (ความเสี่ยงรวมไม่ขยับ) แต่เงาบนแต่ละแกนต่างกัน (การแบ่งเปลี่ยน) จากนั้นหน้านี้ดูอีกสองการแปลงที่เปลี่ยนจำนวน factor คือ projection ที่ลด และ push-out ที่เพิ่ม ซึ่งไม่ฟรีเหมือน rotation

ศัพท์ที่ใช้ในหัวข้อนี้
Rotation
การเปลี่ยน loading เป็น $\mathbf B\mathbf C^{-1}$ และ factor return เป็น $\mathbf C\mathbf f$ พร้อมกัน ด้วย matrix $\mathbf C$ ที่มี inverse จำนวน factor เท่าเดิมและทุกอย่างที่วัดได้เท่าเดิม ใช้ให้มุมมองที่ต่างกันกับคนใช้ model คนละกลุ่ม
Rotational indeterminacy
ข้อเท็จจริงที่ factor model เขียนได้หลายแบบที่ทำนายเหมือนกันหมด ข้อมูลผลตอบแทนจึงเลือกแบบให้เราไม่ได้ ต้องเลือกเองแล้วตรึงไว้
Whitening
rotation ที่ทำให้ covariance ของ factor ใหม่เป็น identity คือไม่สัมพันธ์กันและ variance เป็นหนึ่ง ความเสี่ยงจาก factor จึงเป็นผลบวกกำลังสองของ exposure และอ่าน exposure เป็นความผันผวนได้ตรง ๆ
Centring และ z-scoring
การลบค่าเฉลี่ยออกจากคอลัมน์ loading (และหารด้วยส่วนเบี่ยงเบนมาตรฐาน) ให้อ่านง่ายว่าหุ้นรับ factor มากกว่าค่าเฉลี่ยแค่ไหน เป็น rotation ได้เฉพาะเมื่อ vector ที่เป็น 1 ทุกตัวอยู่ใน range ของ $\mathbf B$
Projection
การลดเหลือ factor น้อยลงโดยเลือก factor return ใหม่ที่ทำให้ส่วนของ factor ใกล้ของเดิมที่สุด ตัวดำเนินการของมันทำซ้ำแล้วได้ผลเดิม (idempotent)
Push-out
การเพิ่ม factor ใหม่โดยใช้เฉพาะส่วนของ loading ใหม่ที่ตั้งฉากกับทุกคอลัมน์เดิม factor return เก่าจึงไม่ขยับ
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$\mathbf C$matrix $m\times m$ ที่มี inverse ใช้ rotateตามการแปลง
$\tilde{\mathbf B},\ \tilde{\mathbf f},\ \tilde{\boldsymbol\Omega}_f,\ \tilde{\mathbf b}$loading, factor return, covariance และ exposure หลัง rotateตามการแปลง
$\mathbf L$Cholesky factor ที่ $\boldsymbol\Omega_f=\mathbf L\mathbf L^{\mathsf T}$% ต่อวัน
$\mathbf e,\ \mathbf a,\ \boldsymbol\nu$vector ที่เป็น 1 ทุกตัว, น้ำหนักที่ $\mathbf B\mathbf a=\mathbf e$ และค่าที่บวกเข้าแต่ละคอลัมน์ไม่มีหน่วย
$\mathbf A,\ \mathbf g,\ \mathbf H$loading ของ model ที่เล็กลง, factor return ของมัน และตัวแปลง $\mathbf g=\mathbf H\mathbf f$ไม่มีหน่วย, %, ไม่มีหน่วย
$\mathbf P$projection ลงบน range ของ matrix หนึ่งไม่มีหน่วย

ขั้นที่ 1 — rotation: อะไรคงที่และอะไรไม่

นี่เป็นแค่การเขียนใหม่ ไม่ใช่ข้อสมมติใหม่ แทรก $\mathbf C^{-1}\mathbf C=\mathbf I$ ระหว่าง $\mathbf B$ กับ $\mathbf f$ แล้วจับกลุ่มใหม่ จากนั้นตามดูว่า covariance, exposure, กำไรขาดทุนจาก factor และความเสี่ยงจาก factor เปลี่ยนอย่างไร

\[ \begin{aligned} \mathbf B\mathbf f&=\mathbf B\mathbf C^{-1}\mathbf C\mathbf f\\ &=(\mathbf B\mathbf C^{-1})(\mathbf C\mathbf f)=\tilde{\mathbf B}\tilde{\mathbf f},\\ \tilde{\boldsymbol\Omega}_f&=\operatorname{cov}(\mathbf C\mathbf f)=\mathbf C\boldsymbol\Omega_f\mathbf C^{\mathsf T},\\ \tilde{\mathbf b}&=\tilde{\mathbf B}^{\mathsf T}\mathbf w=\mathbf C^{-\mathsf T}\mathbf b,\\ \tilde{\mathbf b}^{\mathsf T}\tilde{\mathbf f}&=\mathbf b^{\mathsf T}\mathbf C^{-1}\mathbf C\mathbf f=\mathbf b^{\mathsf T}\mathbf f,\\ \tilde{\mathbf b}^{\mathsf T}\tilde{\boldsymbol\Omega}_f\tilde{\mathbf b}&=\mathbf b^{\mathsf T}\mathbf C^{-1}\mathbf C\boldsymbol\Omega_f\mathbf C^{\mathsf T}\mathbf C^{-\mathsf T}\mathbf b\\ &=\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b. \end{aligned} \]

บรรทัดแรกบอกว่าผลตอบแทนของหุ้นทุกตัวไม่ขยับ และคอลัมน์ของ $\tilde{\mathbf B}$ กินพื้นที่เดียวกับคอลัมน์ของ $\mathbf B$ บรรทัดที่สองคือกฎ covariance ของการแปลงเชิงเส้น บรรทัดที่สามใช้ $(\mathbf B\mathbf C^{-1})^{\mathsf T}=\mathbf C^{-\mathsf T}\mathbf B^{\mathsf T}$ ($\mathbf C^{-\mathsf T}$ คือ inverse ของ $\mathbf C^{\mathsf T}$) สองบรรทัดสุดท้ายคือหัวใจ ทุกคู่ $\mathbf C^{-1}\mathbf C$ ตัดกันหมด กำไรขาดทุนรวมจาก factor และความเสี่ยงรวมจาก factor จึงเท่าเดิมเสมอ ส่วนเฉพาะตัวไม่ถูกแตะเลย

สิ่งที่ขยับได้คือแต่ละก้อน $\tilde b_j\tilde f_j$ และความเสี่ยงราย factor นั่นคือเสรีภาพของเครื่องมือนี้ และเป็นอันตรายของมันด้วย ข้อดีคือเลือกแบ่งให้ตรงกับคำถามของคนอ่านได้ ข้อเสียคือคนอ่านสองคนที่ใช้คนละแบบจะเถียงกันเรื่องตัวเลขที่ถูกทั้งคู่

ขั้นที่ 2 — rotation แรก: ดึงค่าเฉลี่ยออกจากคอลัมน์ tech

โจทย์ให้อะไรมาบ้าง: model สี่หุ้นสาม factor เดิม อยากให้คอลัมน์ tech มีค่าเฉลี่ยศูนย์แทน (1, 1, 0, 0) ที่ค่าเฉลี่ย 0.5 การลบ 0.5 จากทุกแถวคือการบวก $\mathbf e\boldsymbol\nu^{\mathsf T}$ เข้าไปใน $\mathbf B$ และเพราะคอลัมน์ market คือ $\mathbf e$ พอดี จึงเขียน $\mathbf e=\mathbf B\mathbf a$ ได้ด้วย $\mathbf a=(1, 0, 0)$

\[ \begin{aligned} \boldsymbol\nu&=(0,\ 0,\ -0.5),\\ \tilde{\mathbf B}&=\mathbf B+\mathbf e\boldsymbol\nu^{\mathsf T}\\ &=\mathbf B(\mathbf I+\mathbf a\boldsymbol\nu^{\mathsf T}),\\ \mathbf C&=\mathbf I-\mathbf a\boldsymbol\nu^{\mathsf T},\\ \tilde{\mathbf f}&=\mathbf f-\mathbf a(\boldsymbol\nu^{\mathsf T}\mathbf f)\\ &=(0.95,\ -0.50,\ 0.30),\\ \tilde{\mathbf b}&=\mathbf b+\boldsymbol\nu\,(\mathbf e^{\mathsf T}\mathbf w),\\ \tilde\sigma_{\rm mkt}^2&=1+0.25(0.3025)+0.275\\ &=1.350625,\\ \tilde\sigma_{\rm mkt}&=1.1622. \end{aligned} \]

คำตอบ: $(\mathbf I+\mathbf a\boldsymbol\nu^{\mathsf T})(\mathbf I-\mathbf a\boldsymbol\nu^{\mathsf T})=\mathbf I$ เพราะ $\boldsymbol\nu^{\mathsf T}\mathbf a=0$ จึงเป็น rotation จริง คอลัมน์ tech กลายเป็น (0.5, 0.5, −0.5, −0.5) ครึ่งหนึ่งของ tech ที่ถูกดึงออกไปต้องไปอยู่ที่ไหนสักแห่ง มันไปอยู่ที่ market ซึ่งกลายเป็น $0.80+0.5(0.30)=0.95\%$ และความผันผวนของ market ใหม่เป็น 1.1622% ต่อวัน (บรรทัด $\tilde\sigma^2_{\rm mkt}$ คือ $\operatorname{var}(f_1+0.5f_3)=1+0.25\,\sigma_3^2+2(0.5)\operatorname{cov}(f_1,f_3)$) พอร์ตของเรามี $\mathbf e^{\mathsf T}\mathbf w=\text{NMV}=0$ exposure จึงเท่าเดิม และการแบ่งยังเป็น \$0, −\$69,000, +\$3,000 แต่พอร์ต long ล้วน (3, 2, 4, 5) ที่มี exposure (14, −1.8, 5) จะถูกแบ่งจาก +\$112,000, +\$9,000, +\$15,000 เป็น +\$133,000, +\$9,000, −\$6,000 รวม +\$136,000 เท่าเดิม

ตรวจเองใน 10 วินาที: exposure ต่อ tech ใหม่ของพอร์ต long คือ $5-0.5(14)=-2$ แปลว่าถือ tech น้อยกว่าครึ่งหนึ่งของตลาด บรรทัด tech จึงกลายเป็นลบ $-2(0.30)=-0.60$ หรือ −\$6,000

ขั้นที่ 3 — เมื่อไรการดึงค่าเฉลี่ยไม่ใช่ rotation

การดึงค่าเฉลี่ยที่เพิ่งทำได้ผลเพราะ $\mathbf e$ อยู่ใน range ของ $\mathbf B$ ลองดู model ปัจจัยเดียวที่ไม่มีคอลัมน์ market หุ้นสองตัวมี loading 1.5 กับ 0.5 ถ้าดึงค่าเฉลี่ย 1.0 ออก จะได้ 0.5 กับ −0.5 rotation ของ model ปัจจัยเดียวคือการคูณ loading ด้วยตัวเลข $c$ ตัวเดียว มี $c$ ตัวไหนไหมที่พาแบบแรกไปเป็นแบบที่สอง

\[ \begin{aligned} \mathbf B&=\begin{bmatrix}1.5\\0.5\end{bmatrix},\quad\tilde{\mathbf B}=\begin{bmatrix}0.5\\-0.5\end{bmatrix},\\ c(1.5)&=0.5\ \to\ c=\tfrac13,\\ c(0.5)&=-0.5\ \to\ c=-1. \end{aligned} \]

สองแถวต้องการ $c$ คนละค่า จึงไม่มี rotation ไหนพา model หนึ่งไปเป็นอีก model ในรูปข้างล่าง rotation พา loading ได้แค่ตามเส้นตรงผ่านจุดกำเนิด แต่การลบค่าเฉลี่ยพามันหลุดออกจากเส้น model เดิมบอกว่าสองหุ้นขยับทางเดียวกันเสมอ model ที่ดึงค่าเฉลี่ยบอกว่าขยับสวนทางกันเสมอ พอร์ตที่ถือสองตัวเท่ากัน \$1 ล้าน มี exposure 2 ใน model แรก แต่ 0 ใน model ที่สอง ถ้า factor ผันผวน 1% ต่อวัน model แรกบอกว่าเสี่ยง \$20,000 ต่อวัน model ที่สองบอกว่าไม่มีความเสี่ยงจาก factor เลย

กติกาคือ z-scoring จะเป็น rotation ได้เฉพาะเมื่อ $\mathbf e$ เขียนเป็นผลรวมถ่วงของคอลัมน์ loading ได้ ซึ่งเกิดในสองกรณีที่พบบ่อย คือ model มีคอลัมน์ market (เรียกอีกชื่อว่า country หรือ intercept) หรือมีชุด industry ที่รวมกันได้ 1 ทุกแถว ถ้าไม่มี มันคือ model ใหม่ที่ทำนายความเสี่ยงและแบ่งกำไรขาดทุนต่างออกไปจริง ๆ

ขั้นที่ 4 — rotation ที่สอง: ทำให้ factor ไม่สัมพันธ์กันด้วย Cholesky

โจทย์ให้อะไรมาบ้าง: $\boldsymbol\Omega_f$ ของสาม factor (ความผันผวนรายวัน 1.00%, 0.35%, 0.55% และ correlation −0.20, +0.50, −0.10) ต้องการ $\mathbf C$ ที่ทำให้ $\mathbf C\boldsymbol\Omega_f\mathbf C^{\mathsf T}=\mathbf I$ แยก $\boldsymbol\Omega_f=\mathbf L\mathbf L^{\mathsf T}$ ด้วย Cholesky แล้วใช้ $\mathbf C=\mathbf L^{-1}$ เพราะ $\mathbf L^{-1}\mathbf L\mathbf L^{\mathsf T}\mathbf L^{-\mathsf T}=\mathbf I$ จากนั้น $\tilde{\mathbf f}=\mathbf L^{-1}\mathbf f$ ได้จากการแทนค่าไปข้างหน้า และ $\tilde{\mathbf b}=\mathbf L^{\mathsf T}\mathbf b$

\[ \begin{aligned} L_{11}&=1,\ L_{21}=-0.07,\ L_{31}=0.275,\\ L_{22}&=\sqrt{0.1225-0.0049}\\ &=0.34293,\\ L_{32}&=\frac{-0.01925+0.01925}{0.34293}=0,\\ L_{33}&=\sqrt{0.3025-0.075625}\\ &=0.47631,\\ \tilde f_1&=0.80,\\ \tilde f_2&=\frac{-0.444}{0.34293}=-1.2947,\\ \tilde f_3&=\frac{0.08}{0.47631}=0.1680,\\ \tilde b_1&=-0.07(13.8)+0.275\\ &=-0.691,\\ \tilde b_2&=0.34293(13.8)=4.7324,\\ \tilde b_3&=0.47631(1)=0.4763. \end{aligned} \]

คำตอบ: $-0.444=-0.50-(-0.07)(0.80)$ และ $0.08=0.30-0.275(0.80)$ ก้อนกำไรขาดทุนคือ $(-0.691)(0.80)=-0.5528$, $4.7324(-1.2947)=-6.1272$ และ $0.4763(0.1680)=0.0800$ หรือ −\$5,528, −\$61,272 และ +\$800 รวม −\$66,000 เท่ารายงานเดิม ความเสี่ยงคือผลบวกกำลังสอง $0.4775+22.3957+0.2269=23.1001$ ตรงกับที่คำนวณไว้ตอนแยกความเสี่ยงสองก้อน จึงได้ \$48,063 เท่าเดิม นี่คือรายงาน B ของ hook

ตรวจเองใน 10 วินาที: $\mathbf L\mathbf L^{\mathsf T}$ ช่อง (2, 2) ต้องได้ $0.07^2+0.34293^2=0.0049+0.1176=0.1225$ ตรงกับ variance ของ momentum

ขั้นที่ 5 — อ่านรายงาน B: beta ต่อตลาดที่ซ่อนอยู่

ทำไมรายงาน B ใส่ −\$5,528 ในบรรทัด market ทั้งที่ $b_1=0$? เขียนสามก้อนที่เพิ่งได้ใหม่ด้วย beta ของ factor แต่ละตัวต่อ market คือ $\beta_2=-0.07/1$ และ $\beta_3=0.275/1$ (covariance หารด้วย variance ของ market) ให้ $f_1, f_2, f_3$ คือ market, momentum, tech

\[ \begin{aligned} \tilde b_1\tilde f_1&=(b_1+\beta_2b_2+\beta_3b_3)f_1,\\ \tilde b_2\tilde f_2&=b_2(f_2-\beta_2f_1),\\ \tilde b_3\tilde f_3&=b_3(f_3-\beta_3f_1),\\ \tilde b_1\tilde f_1&=(0-0.966+0.275)(0.80)\\ &=-0.5528. \end{aligned} \]

Cholesky ตามลำดับ market, momentum, tech คือการ regress factor แต่ละตัวบนตัวที่มาก่อน บรรทัด market จึงเก็บ beta ต่อตลาดของทุก exposure เดิมพัน momentum \$13.8 ล้าน พก beta $13.8(-0.07)=-0.966$ ล้าน ส่วน tech พก +0.275 ล้าน รวม −\$0.691 ล้าน บรรทัด momentum เหลือแค่ส่วนที่ไม่ขยับตามตลาด $-0.50+0.07(0.80)=-0.444\%$ บทเรียนคือ ผลตอบแทนของพอร์ตตอบสนองต่อ factor ผ่าน beta ไม่ใช่ผ่าน exposure พอร์ตที่ exposure ต่อ market เป็นศูนย์ยังขยับตามตลาดได้ผ่าน factor อื่นที่สัมพันธ์กับมัน

การวาง factor ที่สนใจไว้ลำดับแรกของ Cholesky ให้มันรับกำไรขาดทุนได้มากที่สุดเท่าที่ข้อมูลยอม วิธีนี้ใช้ในรายงานหลังจบงวดในชื่อ maximal attribution เช่นอยากรู้ว่าเสียเงินเพราะตลาดเท่าไรเมื่อนับทุกช่องทาง บรรทัด tech เป็นรูปง่ายแบบนี้เพราะในตัวอย่างนี้ $L_{32}=0$ พอดี คือ momentum กับ tech ไม่สัมพันธ์กันหลังหักตลาด ถ้าไม่เป็นศูนย์ บรรทัด tech จะเก็บส่วนที่ขยับตาม momentum ด้วย

ขั้นที่ 6 — whitening อีกแบบ ได้การแบ่งอีกแบบ

Cholesky ไม่ใช่ทางเดียวที่ทำให้ covariance เป็น identity อีกทางคือใช้ eigenvector แบบเดียวกับ PCA: $\boldsymbol\Omega_f=\mathbf U\mathbf S\mathbf U^{\mathsf T}$ แล้วใช้ $\mathbf C=\mathbf S^{-1/2}\mathbf U^{\mathsf T}$ ค่าในบรรทัดท้ายคำนวณด้วยโค้ดท้ายหน้า

\[ \begin{aligned} \mathbf C&=\mathbf S^{-1/2}\mathbf U^{\mathsf T},\\ \mathbf C\boldsymbol\Omega_f\mathbf C^{\mathsf T}&=\mathbf S^{-1/2}(\mathbf U^{\mathsf T}\mathbf U)\mathbf S\\ &\quad\times(\mathbf U^{\mathsf T}\mathbf U)\mathbf S^{-1/2}=\mathbf I,\\ \mathbf C'&=\mathbf Q\mathbf C,\\ \mathbf C'\boldsymbol\Omega_f\mathbf C'^{\mathsf T}&=\mathbf Q\mathbf Q^{\mathsf T}=\mathbf I,\\ \operatorname{diag}(\mathbf S)&=(1.1007,\ 0.2074,\\ &\qquad 0.1169),\\ \tilde b_j\tilde f_j&=-6{,}157,\ -21,\\ &\qquad -59{,}823. \end{aligned} \]

บรรทัดแรกใช้ $\mathbf U^{\mathsf T}\mathbf U=\mathbf I$ บรรทัดที่สองบอกว่าถ้าหมุนผลลัพธ์ต่อด้วย matrix ตั้งฉาก $\mathbf Q$ ใด ๆ ก็ยัง whiten อยู่ นี่คือสิ่งที่รูปแกนสองชุดตอนต้นหน้าวาด ในพิกัดที่ whiten แล้ว การเปลี่ยนแบบคือการหมุนแกนจริง ๆ ความยาว (ความเสี่ยง) จึงไม่เปลี่ยน “factor ที่ไม่สัมพันธ์กัน” มีได้นับไม่ถ้วนแบบ และแต่ละแบบแบ่งกำไรขาดทุนไม่เหมือนกัน

แบบ eigenvector ให้สามก้อนรวม −\$66,000 เท่าเดิม ทิศที่สามซึ่ง variance เล็กที่สุดเกือบเป็น momentum ล้วน (0.087, 0.996, −0.025) จึงรับไป −\$59,823 แต่ factor ใหม่ไม่มีชื่อที่คนอ่านรายงานเข้าใจ นี่คือราคาของการเลือก whitening แบบนี้ ยังมี rotation อีกแบบที่ใช้กัน คือทำให้คอลัมน์ loading ตั้งฉากกันและยาวหนึ่งหน่วย ($\tilde{\mathbf B}^{\mathsf T}\tilde{\mathbf B}=\mathbf I$) ด้วย SVD ของ $\mathbf B$

ขั้นที่ 7 — projection: สาม factor เหลือสอง

บางครั้งอยากได้ model ที่เล็กลง เพราะ loading บางคอลัมน์เปลี่ยนเร็วจน hedge ไม่ทัน เพราะไม่เชื่อ factor บางตัวของผู้ให้บริการ หรือเพราะคนใช้บางกลุ่มอยากได้ model ง่าย ๆ ให้ $\mathbf A$ คือสองคอลัมน์แรกของ $\mathbf B$ (market กับ momentum) เลือก factor return ใหม่ $\mathbf g$ ที่ทำให้ส่วนของ factor ใกล้ของเดิมที่สุด ซึ่งคือ least squares ของ OLS ที่ใช้ $\mathbf B\mathbf f$ เป็นตัวแปรตาม

\[ \begin{aligned} \mathbf g&=\operatorname*{arg\,min}_{\mathbf g}\lVert\mathbf B\mathbf f-\mathbf A\mathbf g\rVert^2\\ &=\mathbf H\mathbf f,\\ \mathbf H&=(\mathbf A^{\mathsf T}\mathbf A)^{-1}\mathbf A^{\mathsf T}\mathbf B\\ &=\begin{bmatrix}1&0&0.5\\0&1&0.2041\end{bmatrix},\\ \mathbf g&=(0.95,\ -0.4388),\\ \boldsymbol\Omega_g&=\mathbf H\boldsymbol\Omega_f\mathbf H^{\mathsf T},\\ \sqrt{\mathbf b_A^{\mathsf T}\boldsymbol\Omega_g\mathbf b_A}&=\$49{,}226. \end{aligned} \]

$\mathbf A^{\mathsf T}\mathbf A=\operatorname{diag}(4, 3.92)$ เพราะ momentum รวมกันได้ศูนย์ คอลัมน์ที่สามของ $\mathbf H$ จึงคือ regression ของ tech บน (1, momentum) ได้ค่าคงที่ 0.5 และความชัน $0.8/3.92=0.2041$ market ใหม่ดูดครึ่งหนึ่งของ tech และ momentum ใหม่ดูด 0.2041 ของ tech เพราะหุ้น tech ในตัวอย่างนี้มี momentum สูงกว่าเฉลี่ย

$\mathbf P=\mathbf A(\mathbf A^{\mathsf T}\mathbf A)^{-1}\mathbf A^{\mathsf T}$ ทำซ้ำแล้วได้ผลเดิม $\mathbf P\mathbf P=\mathbf P$ จึงเรียกว่า projection เหมือนเงาบนพื้น ฉายเงาซ้ำก็ได้เงาเดิม model เล็กรายงานความเสี่ยงจาก factor \$49,226 สูงกว่า \$48,063 อยู่ 2.4% เพราะผ่าน $\mathbf H$ exposure ต่อ momentum 13.8 พา exposure ต่อ tech $13.8(0.2041)=2.816$ มาด้วย แทนค่าจริง 1

ส่วนที่ทิ้งไป $\mathbf B\mathbf f-\mathbf A\mathbf g$ ไหลไปอยู่ใน residual วันนี้ −\$5,449 ย้ายจาก factor ไปเป็น “เฉพาะตัว” (−\$60,551 บวก −\$5,449 เท่ากับ −\$66,000) และ residual ใหม่มีส่วนร่วมของ tech ซึ่งขัดกับข้อสมมติว่า $\boldsymbol\Omega_\epsilon$ เป็น diagonal การใช้ที่พบบ่อยที่สุดคือแบบนี้ คือ model เล็กที่คอลัมน์เป็นส่วนหนึ่งของ model ใหญ่

ขั้นที่ 8 — push-out: เพิ่ม factor ใหม่ ใช้แค่ส่วนที่ใหม่จริง

โจทย์ให้อะไรมาบ้าง: model ที่สร้างจากข้อมูลช่วงหนึ่งอาจไม่เหมาะกับตลาดตอนนี้ แล้ว residual เริ่มมีโครงสร้างร่วมกัน นักวิจัยเสนอคุณสมบัติใหม่ $\mathbf a=(0.5, -1.5, 1.0, 0.0)$ เป็น loading ของ factor ที่สี่ ส่วนที่ model เดิมมีอยู่แล้วคือ $\mathbf P_B\mathbf a$ ส่วนที่ใหม่จริงคือ $(\mathbf I-\mathbf P_B)\mathbf a$ และใน 4 มิติ ส่วนที่ตั้งฉากกับทุกคอลัมน์ของ $\mathbf B$ มีทิศเดียวคือ $\mathbf u=(1, -1, -0.8, 0.8)$ ซึ่งหาได้ตอนหาพอร์ตที่ไม่มี exposure ต่อ factor ใดเลย

\[ \begin{aligned} \hat{\mathbf a}&=(\mathbf I-\mathbf P_B)\,\mathbf a\\ &=\frac{\mathbf a^{\mathsf T}\mathbf u}{\mathbf u^{\mathsf T}\mathbf u}\,\mathbf u=\frac{1.2}{3.28}\,\mathbf u\\ &=(0.3659,\ -0.3659,\\ &\qquad -0.2927,\ 0.2927),\\ \lVert\mathbf a\rVert&=\sqrt{3.5}=1.8708,\\ \lVert\hat{\mathbf a}\rVert&=0.6626,\\ \frac{\lVert\hat{\mathbf a}\rVert^2}{\lVert\mathbf a\rVert^2}&=\frac{0.4390}{3.5}=12.5\%. \end{aligned} \]

คำตอบ: $\mathbf a^{\mathsf T}\mathbf u=0.5+1.5-0.8+0=1.2$ ส่วนที่ใหม่จริงยาว 35.4% ของเดิม แต่ความยาวไม่บวกกัน ความยาวกำลังสองบวกกัน (แบบเดียวกับตอนแยก alpha spanned และ alpha orthogonal) จึงต้องอ่านว่า 87.5% ของคุณสมบัติที่เสนอมา model เดิมมีอยู่แล้ว เหลือของใหม่ 12.5% model ที่ขยายคือ $\mathbf r=\boldsymbol\alpha_\perp+\mathbf B\mathbf f+\hat{\mathbf a}g+\boldsymbol\eta$ โดย $\hat{\mathbf a}^{\mathsf T}\mathbf B=\mathbf 0$ เงื่อนไขนี้จำเป็น ถ้าคอลัมน์ใหม่มีส่วนที่ซ้ำกับคอลัมน์เก่า ส่วนนั้นจะเขียนเป็น $\mathbf B\mathbf c\,g$ แล้วบวกเข้า $\mathbf B\mathbf f$ ได้ factor return เดิมจึงต้องเปลี่ยนตาม

ตรวจเองใน 10 วินาที: $\hat{\mathbf a}$ ต้องรวมกันได้ศูนย์เพราะตั้งฉากกับคอลัมน์ market $0.3659-0.3659-0.2927+0.2927=0$

ขั้นที่ 9 — ทำไมต้องใช้ส่วนที่ตั้งฉาก: ตัวเลขเก่าไม่ขยับ

โจทย์ให้อะไรมาบ้าง: ผลตอบแทนวันนี้ (0.90, 1.05, 0.65, 0.90)% ประมาณ factor return ด้วย OLS ข้ามหุ้นสามแบบ คือบน $\mathbf B$ อย่างเดียว บน $\mathbf B$ บวก $\mathbf a$ ดิบ และบน $\mathbf B$ บวก $\hat{\mathbf a}$

\[ \begin{aligned} \hat{\mathbf f}_{\mathbf B}&=(0.7299,\ -0.1128,\ 0.2902),\\ \hat{\mathbf f}_{\mathbf B,\mathbf a}&=(0.6958,\ -0.1458,\\ &\qquad 0.3583,\ 0.0417),\\ \hat{\mathbf f}_{\mathbf B,\hat{\mathbf a}}&=(0.7299,\ -0.1128,\\ &\qquad 0.2902,\ 0.0417). \end{aligned} \]

คำตอบ: ใส่ $\mathbf a$ ดิบแล้ว factor return เก่าทั้งสามตัวขยับ market ของวันนี้จาก 0.7299% เป็น 0.6958% และจะขยับแบบนี้ทุกวันในประวัติ รายงานย้อนหลังทั้งหมดเปลี่ยน ใส่ $\hat{\mathbf a}$ แล้วสามตัวเดิมเท่าเดิมทุกหลัก และ factor ใหม่ได้ 0.0417 เท่ากันทั้งสองแบบ หน้า Frisch–Waugh–Lovell พิสูจน์ว่าเป็นแบบนี้เสมอ ค่าประมาณบน $\mathbf B$ ต่างจาก $\mathbf f$ จริง (0.80, −0.50, 0.30) เพราะหุ้นแค่สี่ตัวทำให้ส่วนเฉพาะตัวรั่วเข้าไปในค่าประมาณ หน้านั้นวัดขนาดของการรั่วนี้ด้วย

ตรวจเองใน 10 วินาที: ค่าของ factor ใหม่คือ $\hat{\mathbf a}^{\mathsf T}\mathbf r/\hat{\mathbf a}^{\mathsf T}\hat{\mathbf a}=0.01829/0.4390=0.0417$ ใช้แค่คอลัมน์ใหม่คอลัมน์เดียว เพราะมันตั้งฉากกับคอลัมน์เก่าทั้งหมด

ความผิดที่เปลี่ยนเรื่องเล่าโดยไม่มีอะไรจริงเปลี่ยน

เทียบ attribution ข้าม model คนละแบบ: บรรทัด momentum ของวันเดียวกันเป็น −\$69,000 ในรายงาน A และ −\$61,272 ในรายงาน B และไม่มีชื่อเลยในแบบ eigenvector ถ้าเปลี่ยนแบบกลางปีแล้วเทียบก่อนกับหลัง จะสรุปผิดเรื่องฝีมือทั้งที่โลกไม่ได้เปลี่ยน

z-score โดยไม่มีคอลัมน์ market: ตัวอย่างหุ้นสองตัวข้างบนแสดงว่าพอร์ตเดียวกันเสี่ยง \$20,000 ต่อวันใน model หนึ่ง และไม่มีความเสี่ยงจาก factor เลยในอีก model ตัวเลขทั้งสองดูสมเหตุสมผล จึงไม่มีใครสังเกต

คิดว่า model เล็กรายงานความเสี่ยงต่ำกว่าเสมอ: model สอง factor รายงานสูงกว่า 2.4% เพราะ exposure ที่ถูกตัดถูกพับเข้าไปใน factor ที่เหลือ ทิศของความคลาดขึ้นกับโครงสร้างของแต่ละกรณี ต้องวัดทุกครั้ง

เพิ่มคุณสมบัติใหม่แบบดิบ: market ของวันนี้ขยับ 0.034 จุดจากการเพิ่มคอลัมน์เดียว และขยับแบบนี้ทุกวันย้อนหลัง รายงานผลงานเก่าทั้งหมดเปลี่ยนโดยไม่มีใครตั้งใจ

ใช้ทำอะไรบนโต๊ะจริง

ผู้ให้บริการ risk model ส่ง model เดียวกันในหลายหน้าตา คือ loading ดิบ แบบที่ z-score แล้ว และบางครั้งแบบที่ factor ไม่สัมพันธ์กัน โต๊ะเลือกแบบเดียวที่คนอ่านรายงานเข้าใจแล้วตรึงไว้ รายงาน A ตอบว่า “เดิมพันไหนที่เราถือ” รายงาน B ตอบว่า “ถ้าหักตลาดออกแล้ว เดิมพันไหนทำงาน” แบบ eigenvector เหมาะกับการคำนวณ แต่ไม่มีชื่อให้คน

projection ใช้ทำ model ย่อให้คนที่ไม่ต้องการ factor ทั้งร้อยตัว โดยรู้ว่าส่วนที่ทิ้งไปไหลไปอยู่ใน residual และ push-out ใช้ทดสอบคุณสมบัติใหม่โดยไม่แตะ factor return ในประวัติ ถ้าไม่มีอะไรก็ทิ้งไป ถ้ามีค่อยตัดสินว่าจะรับเข้า model ถาวร

เปิดดูโค้ด

รันใน Node.js ได้โดยไม่ต้องติดตั้งอะไร โค้ด rotate model ด้วย matrix ใด ๆ ที่มี inverse แล้วคำนวณการดึงค่าเฉลี่ย, Cholesky สองลำดับ, eigenvector ด้วย Jacobi, projection, push-out และ OLS สามแบบ

const {sqrt, abs, sign} = Math;
function checkMatrix(A, name) {
  if (!Array.isArray(A) || A.length === 0 || !A.every(row => Array.isArray(row) && row.length === A[0].length && row.every(Number.isFinite))) {
    throw new TypeError(name + ' must be a non-empty rectangular matrix of finite numbers');
  }
  return [A.length, A[0].length];
}
const dot = (a, b) => a.reduce((s, v, i) => s + v * b[i], 0);
const transpose = A => A[0].map((_, j) => A.map(row => row[j]));
const mul = (A, B) => A.map(row => B[0].map((_, j) => row.reduce((s, v, k) => s + v * B[k][j], 0)));
const matVec = (A, x) => A.map(row => dot(row, x));
// Gauss-Jordan inverse; refuses a singular matrix (a rotation must be invertible).
function inverse(A) {
  const [n, m] = checkMatrix(A, 'Matrix');
  if (n !== m) throw new RangeError('Only a square matrix can be inverted');
  const M = A.map((row, i) => [...row, ...row.map((_, j) => (i === j ? 1 : 0))]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let i = c + 1; i < n; i++) if (abs(M[i][c]) > abs(M[p][c])) p = i;
    if (abs(M[p][c]) < 1e-12) throw new RangeError('Matrix is singular: not a valid rotation');
    [M[c], M[p]] = [M[p], M[c]];
    const piv = M[c][c];
    for (let j = 0; j < 2 * n; j++) M[c][j] /= piv;
    for (let i = 0; i < n; i++) if (i !== c) { const g = M[i][c]; for (let j = 0; j < 2 * n; j++) M[i][j] -= g * M[c][j]; }
  }
  return M.map(row => row.slice(n));
}
// Rotate the model by an invertible C: B~ = B C^-1, f~ = C f, Omega~ = C Omega C', b~ = B~' w.
function rotate(B, f, Of, w, C) {
  const Ci = inverse(C), Bt = mul(B, Ci), ft = matVec(C, f), Ot = mul(mul(C, Of), transpose(C));
  const b = matVec(transpose(Bt), w);
  return {B: Bt, f: ft, Of: Ot, b, pieces: b.map((x, j) => x * ft[j] * 1e4),
    total: dot(b, ft) * 1e4, risk: sqrt(dot(b, matVec(Ot, b))) * 1e4};
}
// Cholesky factor of a covariance matrix; refuses a matrix that is not positive definite.
function cholesky(S) {
  const [n] = checkMatrix(S, 'Covariance');
  const L = S.map(() => new Array(n).fill(0));
  for (let i = 0; i < n; i++) for (let j = 0; j <= i; j++) {
    let s = S[i][j];
    for (let k = 0; k < j; k++) s -= L[i][k] * L[j][k];
    if (i === j) {
      if (!(s > 0)) throw new RangeError('Covariance is not positive definite');
      L[i][i] = sqrt(s);
    } else L[i][j] = s / L[j][j];
  }
  return L;
}
// Eigen-decomposition by cyclic Jacobi rotations, sorted from the largest variance down.
function eigen(S) {
  const n = S.length, A = S.map(row => row.slice()), V = S.map((_, i) => S.map((__, j) => (i === j ? 1 : 0)));
  for (let sweep = 0; sweep < 50; sweep++) {
    let off = 0;
    for (let i = 0; i < n; i++) for (let j = i + 1; j < n; j++) off += A[i][j] ** 2;
    if (off < 1e-30) break;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) {
      if (A[p][q] === 0) continue;
      const th = (A[q][q] - A[p][p]) / (2 * A[p][q]);
      const t = sign(th || 1) / (abs(th) + sqrt(th * th + 1)), c = 1 / sqrt(t * t + 1), s = t * c;
      for (let k = 0; k < n; k++) { const x = A[k][p], y = A[k][q]; A[k][p] = c * x - s * y; A[k][q] = s * x + c * y; }
      for (let k = 0; k < n; k++) { const x = A[p][k], y = A[q][k]; A[p][k] = c * x - s * y; A[q][k] = s * x + c * y; }
      for (let k = 0; k < n; k++) { const x = V[k][p], y = V[k][q]; V[k][p] = c * x - s * y; V[k][q] = s * x + c * y; }
    }
  }
  const order = [...Array(n).keys()].sort((i, j) => A[j][j] - A[i][i]);
  return {values: order.map(i => A[i][i]), vectors: order.map(i => V.map(row => row[i]))};
}
// Least-squares coefficients of y on the columns of X (normal equations).
function ols(X, y) {
  checkMatrix(X, 'Design matrix');
  const Xt = transpose(X);
  return matVec(inverse(mul(Xt, X)), matVec(Xt, y));
}

function pushOut(B, a) {

  const fitted = matVec(B, matVec(inverse(mul(Bt, B)), matVec(Bt, a)));
  return a.map((x, i) => x - fitted[i]);
}

สิ่งที่ควรตอบได้หลังอ่าน

  • $\mathbf B\mathbf f=(\mathbf B\mathbf C^{-1})(\mathbf C\mathbf f)$ สำหรับ $\mathbf C$ ที่มี inverse ทุกตัว ผลตอบแทนหุ้น กำไรขาดทุนรวม และความเสี่ยงรวมจาก factor จึงไม่ขึ้นกับแบบที่เลือก แต่การแบ่งราย factor ขึ้นกับมันทั้งหมด
  • การดึงค่าเฉลี่ยออกจากคอลัมน์ย้ายส่วนนั้นไปที่ market (0.80 เป็น 0.95) และเป็น rotation ได้เฉพาะเมื่อ $\mathbf e$ อยู่ใน range ของ $\mathbf B$
  • whitening ด้วย Cholesky ใส่ beta ต่อตลาดของทุก exposure ไว้ในบรรทัด market พอร์ตที่ exposure ต่อ market เป็นศูนย์จึงเสีย \$5,528 ในบรรทัดนั้นได้ whitening มีนับไม่ถ้วนแบบ ต่างกันด้วยการหมุนแกน
  • projection ใช้ $\mathbf H=(\mathbf A^{\mathsf T}\mathbf A)^{-1}\mathbf A^{\mathsf T}\mathbf B$ ในตัวอย่างนี้รายงานความเสี่ยงสูงขึ้น 2.4% และย้าย \$5,449 ของวันนี้ไปอยู่ใน residual
  • push-out ใช้เฉพาะ $(\mathbf I-\mathbf P_B)\mathbf a$ คุณสมบัติในตัวอย่างเหลือของใหม่ 12.5% ของความยาวกำลังสอง และ factor return เก่าไม่ขยับเลย
