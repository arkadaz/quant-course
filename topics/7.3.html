7.3 Matrix Multiplication

การคูณ matrix คือการต่อเครื่องแปลงสองเครื่องให้เป็นเครื่องเดียว กติกาแถวคูณคอลัมน์ตามมาจากการแทนค่าขั้นแรกลงในขั้นที่สอง ไม่ได้ถูกตั้งขึ้นลอย ๆ

พอร์ตสมมติลงเงินในหุ้นสหรัฐ 50% หุ้นกู้สหรัฐ 30% และทองคำ 20% กรรมการถามว่าหุ้นซึ่งได้เงินครึ่งหนึ่ง แบกความเสี่ยงของพอร์ตครึ่งหนึ่งด้วยหรือเปล่า สมมติความผันผวนรายปี 18%, 6% และ 15% correlation หุ้นกับหุ้นกู้ −0.20 หุ้นกับทอง 0.05 หุ้นกู้กับทอง 0.25

ลองตอบก่อนเปิดเฉลย

ไม่ใช่ครึ่งเดียว หุ้นแบก 85.84% ของ variance พอร์ต หุ้นกู้ 1.46% ทองคำ 12.70% และพอร์ตมีความผันผวน 9.60% ต่อปี หุ้นทั้งผันผวนสูงสุด และหุ้นกู้ซึ่งสัมพันธ์ติดลบกับหุ้นยังช่วยหักความเสี่ยงบางส่วนออก ตัวเลขทั้งหมดได้จากการคูณ matrix สองรอบ: $\Sigma\mathbf w$ แล้ว $\mathbf w^{\mathsf T}(\Sigma\mathbf w)$

ภาพรวมก่อนลงสูตร

งานบน desk หลายอย่างเป็นสายพาน: เงินที่ถือกลายเป็น exposure ต่อ factor แล้ว exposure กลายเป็นกำไรขาดทุนใน scenario ต่าง ๆ หรือผลตอบแทนรายวันกลายเป็น covariance แล้ว covariance กับน้ำหนักกลายเป็นความเสี่ยง ทุกลูกศรในสายพานคือ matrix หนึ่งตัว และการคูณ matrix คือการรวมลูกศรสองอันเป็นอันเดียว

กติกาการคูณ “แถวคูณคอลัมน์” มาจากคำถามเดียว: ถ้าต่อเครื่องแปลงสองเครื่อง เครื่องรวมต้องหน้าตาอย่างไร คำตอบบังคับให้ลำดับสำคัญ ทำ $Q$ ก่อน $P$ กับทำ $P$ ก่อน $Q$ ได้ผลต่างกัน ดังรูปด้านล่าง แต่การจัดวงเล็บใหม่ไม่เปลี่ยนคำตอบ เปลี่ยนแค่ปริมาณงาน

หน้านี้สร้างกติกาจากการแทนค่า อ่านผลคูณได้สองแบบ ต่อสายพาน factor ไป scenario สร้าง sample covariance จากข้อมูลดิบด้วยการคูณครั้งเดียว แล้วตอบคำถามของกรรมการด้วยการแบ่งความเสี่ยงเป็นรายสินทรัพย์ ปิดด้วยตัวอย่าง asset class จริงแปดกลุ่ม

ศัพท์ที่ใช้ในหัวข้อนี้
Matrix multiplication $PQ$
matrix ของเครื่องรวมที่ทำ $Q$ ก่อนแล้วทำ $P$ ช่อง $(i,k)$ คือแถว $i$ ของ $P$ จับคู่กับคอลัมน์ $k$ ของ $Q$ ใช้ต่อสายพานการคำนวณ
Associativity
$(PQ)R=P(QR)$ จัดวงเล็บใหม่ได้โดยคำตอบไม่เปลี่ยน ใช้เลือกลำดับที่ใช้งานน้อยที่สุด
Non-commutativity
$PQ$ กับ $QP$ โดยทั่วไปไม่เท่ากัน แม้ทั้งสองคูณได้ ต้องรักษาลำดับของขั้นตอนเสมอ
Elementwise product
คูณช่องที่ตรงกันโดยไม่รวมตามดัชนีกลาง เป็นคนละ operation กับการคูณ matrix ใช้ทำตาราง contribution ก่อนรวม
Sample covariance
$X^{\mathsf T}X/(N-1)$ เมื่อ $X$ คือผลตอบแทน $N$ วันที่หักค่าเฉลี่ยแล้ว ใช้ประมาณ covariance จากข้อมูล
Risk contribution
$c_i=w_i(\Sigma\mathbf w)_i$ ส่วนของ variance พอร์ตที่ยกให้สินทรัพย์ $i$ ผลรวมทุกตัวเท่ากับ variance พอร์ตพอดี ใช้ตอบว่าความเสี่ยงมาจากไหน

ขั้นที่ 1 — ทำไมกติกาต้องเป็นแถวคูณคอลัมน์

ขั้นแรกแปลง input $\mathbf x$ ($p$ ช่อง) เป็น $\mathbf y=Q\mathbf x$ ($n$ ช่อง) ขั้นที่สองแปลง $\mathbf y$ เป็น $\mathbf z=P\mathbf y$ ($m$ ช่อง) เราอยากได้ตารางเดียวที่ส่ง $\mathbf x$ ไป $\mathbf z$ ตรง ๆ จึงแทนขั้นแรกลงในขั้นที่สอง แล้วจัดกลุ่มตาม input เดิม

\[\begin{aligned} y_j&=\sum_{k=1}^{p}Q_{jk}x_k,\\ z_i&=\sum_{j=1}^{n}P_{ij}y_j =\sum_{j=1}^{n}P_{ij}\sum_{k=1}^{p}Q_{jk}x_k\\ &=\sum_{k=1}^{p}\Big(\sum_{j=1}^{n}P_{ij}Q_{jk}\Big)x_k,\\ (PQ)_{ik}&:=\sum_{j=1}^{n}P_{ij}Q_{jk}. \end{aligned}\]

บรรทัดที่สามสลับลำดับของผลรวมสองชั้น ซึ่งทำได้เสมอกับผลรวมจำกัด แล้วสิ่งที่อยู่ในวงเล็บคือน้ำหนักที่ $x_k$ ส่งไปถึง $z_i$ ผ่านทุกทางกลาง $j$ นั่นคือนิยามของช่อง $(i,k)$ ของเครื่องรวม: แถว $i$ ของ $P$ จับคู่กับคอลัมน์ $k$ ของ $Q$ แล้วบวก กติกานี้จึงถูกเลือกมาเพื่อให้ $(PQ)\mathbf x=P(Q\mathbf x)$ พอดี

ดัชนีกลาง $j$ ต้องมีจำนวนเท่ากันทั้งสองตาราง ขนาดจึงต้องเป็น $(m\times n)(n\times p)\to m\times p$ แต่ขนาดตรงยังไม่พอ ชื่อของตัวกลางต้องตรงด้วย เช่น factor ในตารางแรกต้องเรียงลำดับเดียวกับ factor ในตารางที่สอง

ขั้นที่ 2 — ผลคูณเดียว อ่านได้สองแบบ

โจทย์ให้อะไรมาบ้าง: ตาราง payoff จาก Transpose แถวคือสถานะขึ้นและลง คอลัมน์คือสัญญาสามตัว หน่วยดอลลาร์ต่อสัญญา ถือ $\boldsymbol\theta=(2,6,4)^{\mathsf T}$

\[\begin{aligned} S\boldsymbol\theta&=\begin{bmatrix}2&3&7\\1&6&5\end{bmatrix}\begin{bmatrix}2\\6\\4\end{bmatrix} =\begin{bmatrix}2(2)+3(6)+7(4)\\1(2)+6(6)+5(4)\end{bmatrix}\\ &=2\begin{bmatrix}2\\1\end{bmatrix}+6\begin{bmatrix}3\\6\end{bmatrix}+4\begin{bmatrix}7\\5\end{bmatrix} =\begin{bmatrix}50\\58\end{bmatrix}. \end{aligned}\]

คำตอบ: \$50 ในสถานะขึ้น และ \$58 ในสถานะลง มุมแถวถามว่า “ในสถานะนี้ ทุกสัญญารวมกันจ่ายเท่าไร” มุมคอลัมน์ถามว่า “แต่ละสัญญาเติม payoff ให้ทุกสถานะเท่าไร” แล้วต่อลูกศรหัวต่อหางตามรูปด้านล่าง นับเงินก้อนเดียวกัน จึงได้ผลเดียวกัน

ถ้าคูณแต่ละคอลัมน์ด้วยจำนวนสัญญาแต่ไม่บวก จะได้ตาราง contribution $\begin{bmatrix}4&18&28\\2&36&20\end{bmatrix}$ ซึ่งมีประโยชน์ แต่ยังไม่ใช่ payoff ต้องบวกตามแถวอีกครั้ง ใน numpy เครื่องหมาย * ให้ตารางนี้ (คูณทีละช่องแบบ broadcasting) ส่วน @ ให้ผลคูณ matrix

ขั้นที่ 3 — จัดวงเล็บใหม่ได้ สลับลำดับไม่ได้

ใช้สองการเฉือนจากรูปภาพรวม $P=\begin{bmatrix}1&2\\0&1\end{bmatrix}$ และ $Q=\begin{bmatrix}1&0\\3&1\end{bmatrix}$ ส่ง input $(1,1)$ ผ่านทีละขั้น แล้วเทียบกับเครื่องรวม

\[\begin{aligned} Q\begin{bmatrix}1\\1\end{bmatrix}&=\begin{bmatrix}1\\4\end{bmatrix},\quad P\begin{bmatrix}1\\4\end{bmatrix}=\begin{bmatrix}9\\4\end{bmatrix},\\ PQ&=\begin{bmatrix}1+6&2\\3&1\end{bmatrix}=\begin{bmatrix}7&2\\3&1\end{bmatrix},\\ QP&=\begin{bmatrix}1&2\\3&7\end{bmatrix},\quad QP\begin{bmatrix}1\\1\end{bmatrix}=\begin{bmatrix}3\\10\end{bmatrix}. \end{aligned}\]

$PQ$ ส่ง $(1,1)$ ไป $(7+2,3+1)=(9,4)$ ตรงกับการทำทีละขั้น ส่วน $QP$ คือการทำ $P$ ก่อน จึงไปจบที่ $(3,10)$ ตัวเลขอ่านจากขวาไปซ้าย: ใน $PQ\mathbf x$ ตัวที่อยู่ติด $\mathbf x$ ทำงานก่อน

สามตาราง $P(QR)$ กับ $(PQ)R$ เท่ากันเสมอ เพราะช่อง $(i,\ell)$ ของทั้งสองแบบคือผลรวมก้อนเดียวกัน $\sum_j\sum_kP_{ij}Q_{jk}R_{k\ell}$ แค่บวกคนละลำดับ คุณสมบัตินี้เรียกว่า associativity เราจึงย้ายวงเล็บเพื่อประหยัดงานได้ แต่ห้ามสลับตำแหน่งของ matrix สองตัว

ขั้นที่ 4 — ต่อสายพาน: เงินที่ถือ ไป exposure ไป scenario

โจทย์ให้อะไรมาบ้าง: ตาราง loading $A$ ($3\times2$ หุ้นคูณ factor) และพอร์ต $\mathbf w=(2,-1,0.5)$ ล้านดอลลาร์จาก What a Matrix Is ซึ่งมี exposure $\mathbf e=A^{\mathsf T}\mathbf w=(2.25,0.95)$ และ scenario สมมติสามแบบเป็นแถวของ $F$ (คอลัมน์ Market, Quality)

\[\begin{aligned} F&=\begin{bmatrix}0.01&-0.02\\-0.03&0.01\\0.02&0.02\end{bmatrix},\\ F\mathbf e&=\begin{bmatrix}0.0225-0.0190\\-0.0675+0.0095\\0.0450+0.0190\end{bmatrix} =\begin{bmatrix}0.0035\\-0.0580\\0.0640\end{bmatrix},\\ FA^{\mathsf T}&=\begin{bmatrix}0.004&0.005&0.001\\-0.032&-0.025&-0.038\\0.032&0.022&0.044\end{bmatrix}. \end{aligned}\]

คำตอบ: กำไรขาดทุนจากแบบจำลองในสาม scenario คือ +\$3,500, −\$58,000 และ +\$64,000 ทาง $F(A^{\mathsf T}\mathbf w)$ ได้ผลเดียวกับ $(FA^{\mathsf T})\mathbf w$ เช่นแถวที่สอง $2(-0.032)-(-0.025)+0.5(-0.038)=-0.058$ ตาราง $FA^{\mathsf T}$ มีความหมายของตัวเอง: แถวคือ scenario คอลัมน์คือหุ้น ช่องคือผลตอบแทนแบบจำลองของหุ้นนั้นใน scenario นั้น

วงเล็บไม่เปลี่ยนคำตอบ แต่เปลี่ยนงานมาก การคูณ $m\times n$ กับ $n\times p$ แบบตรงไปตรงมาใช้การคูณตัวเลข $mnp$ ครั้ง ระบบจริงที่มี 500 หุ้น 10 factor และ 1,000 scenario ทำสองขั้นกับพอร์ตเดียวใช้ $500(10)+1{,}000(10)=15{,}000$ ครั้ง แต่ถ้าสร้าง $FA^{\mathsf T}$ ก่อนใช้ $1{,}000(10)(500)=5$ ล้านครั้ง แล้วยังต้องคูณกับพอร์ตอีก 500,000 ครั้ง สร้างตารางรวมก็ต่อเมื่อต้องการผลตอบแทนรายหุ้นในแต่ละ scenario จริง ๆ

ขั้นที่ 5 — sample covariance จากข้อมูลดิบด้วยการคูณครั้งเดียว

มีผลตอบแทน $N$ วันของสินทรัพย์ $d$ ตัว เรียงเป็นตาราง $X$ ขนาด $N\times d$ แถวคือวัน คอลัมน์คือสินทรัพย์ หลังหักค่าเฉลี่ยของแต่ละคอลัมน์แล้ว covariance ประมาณจากข้อมูลคือค่าเฉลี่ยของผลคูณส่วนเบี่ยงเบนทุกคู่ ซึ่งการคูณ $X^{\mathsf T}X$ ทำให้ครบในคำสั่งเดียว

\[\begin{aligned} (X^{\mathsf T}X)_{ij}&=\sum_{t=1}^{N}X_{ti}X_{tj},\\ X^{\mathsf T}X&=\sum_{t=1}^{N}\mathbf x_t\mathbf x_t^{\mathsf T},\\ \widehat\Sigma&=\frac{X^{\mathsf T}X}{N-1},\qquad N\ge2. \end{aligned}\]

บรรทัดแรก: แถว $i$ ของ $X^{\mathsf T}$ คือคอลัมน์ $i$ ของ $X$ (ข้อมูลทุกวันของสินทรัพย์ $i$) จึงจับคู่วันต่อวันกับสินทรัพย์ $j$ แล้วบวก บรรทัดที่สองมองอีกทาง: ทุกวัน $t$ ให้ outer product หนึ่งตาราง $\mathbf x_t\mathbf x_t^{\mathsf T}$ แล้วบวกทุกวัน ตัวหาร $N-1$ แทน $N$ ชดเชยการที่ค่าเฉลี่ยเองก็ประมาณจากข้อมูลชุดเดียวกัน ซึ่งทำให้ไม่มี bias เมื่อข้อมูลแต่ละวันอิสระและมาจากการแจกแจงเดียวกัน

ข้อมูลสามวันสมมติเป็นเปอร์เซ็นต์ ค่าเฉลี่ยแต่ละคอลัมน์เป็นศูนย์อยู่แล้ว

\[\begin{aligned} X&=\begin{bmatrix}2&-1\\-1&2\\-1&-1\end{bmatrix},\\ X^{\mathsf T}X&=\begin{bmatrix}4+1+1&-2-2+1\\-2-2+1&1+4+1\end{bmatrix} =\begin{bmatrix}6&-3\\-3&6\end{bmatrix},\\ \widehat\Sigma&=\begin{bmatrix}3&-1.5\\-1.5&3\end{bmatrix}. \end{aligned}\]

ช่องนอกแนวทแยง −3 คือผลรวมของพื้นที่สี่เหลี่ยมมีเครื่องหมายในรูปด้านล่าง หน่วยของตารางคือเปอร์เซ็นต์ยกกำลังสอง ถ้าแปลงผลตอบแทนเป็นเศษส่วนก่อน ทุกช่องจะเล็กลง $100^2=10{,}000$ เท่า ไม่ใช่ 100 เท่า ตรวจอีกทางด้วยพอร์ตน้ำหนัก $(0.6,0.4)$: ผลตอบแทนรายวันคือ $0.8,\ 0.2,\ -1$ variance ตัวอย่าง $(0.64+0.04+1)/2=0.84$ และสูตร $\mathbf w^{\mathsf T}\widehat\Sigma\mathbf w=0.36(3)+2(0.24)(-1.5)+0.16(3)=0.84$ ตรงกัน

ข้อสังเกตที่สำคัญมากในงานจริง: covariance ของ $d$ สินทรัพย์มีตัวเลขที่ต้องประมาณ $d(d+1)/2$ ตัว 500 หุ้นคือ 125,250 ตัว แต่วันเดียวให้แค่ outer product ตารางเดียวที่ทุกแถวเป็นรูปแบบเดียวกัน ข้อมูลไม่กี่วันจึงสร้างตารางที่ “ขาดทิศ” ซึ่ง rank และ invertibility จะนับให้ดูว่าขาดไปเท่าไร

ขั้นที่ 6 — คลี่ hook: เงินครึ่งหนึ่ง แบกความเสี่ยงเท่าไร

สร้าง covariance จากความผันผวนกับ correlation ก่อน ช่อง $\Sigma_{ij}=\rho_{ij}\sigma_i\sigma_j$ เขียนเป็นผลคูณ matrix สามตัวได้ เมื่อ $D$ คือ diagonal matrix ของความผันผวน และ $C$ คือ correlation matrix

\[\begin{aligned} \Sigma&=DCD,\quad D=\operatorname{diag}(0.18,\,0.06,\,0.15),\\ \Sigma&=\begin{bmatrix}0.0324&-0.00216&0.00135\\-0.00216&0.0036&0.00225\\0.00135&0.00225&0.0225\end{bmatrix},\\ \mathbf u=\Sigma\mathbf w&=\begin{bmatrix}0.015822\\0.000450\\0.005850\end{bmatrix},\quad \mathbf w=\begin{bmatrix}0.5\\0.3\\0.2\end{bmatrix},\\ V=\mathbf w^{\mathsf T}\mathbf u&=0.007911+0.000135+0.001170\\ &=0.009216,\qquad\sigma_p=\sqrt V=0.0960. \end{aligned}\]

$D$ ทางซ้ายคูณแถว $i$ ด้วย $\sigma_i$ $D$ ทางขวาคูณคอลัมน์ $j$ ด้วย $\sigma_j$ ช่อง $(i,j)$ จึงเป็น $\sigma_i\rho_{ij}\sigma_j$ เช่นหุ้นกับหุ้นกู้ $0.18(-0.2)(0.06)=-0.00216$ จากนั้นคูณสองรอบ รอบแรก $\mathbf u=\Sigma\mathbf w$ ให้ covariance ของแต่ละสินทรัพย์กับพอร์ต (ตามที่เห็นใน Transpose) รอบที่สองถ่วง $\mathbf u$ ด้วยน้ำหนักได้ variance พอร์ต

สามพจน์ในบรรทัด $V$ คือ $c_i=w_iu_i$ ผลรวมเท่ากับ $V$ พอดี จึงใช้แบ่ง variance ได้: หุ้น $0.007911/0.009216=85.84\%$ หุ้นกู้ $1.46\%$ ทองคำ $12.70\%$ ถ้าอยากแบ่งเป็นหน่วยความผันผวนก็หาร $c_i$ ด้วย $\sigma_p$ ได้ 8.24, 0.14 และ 1.22 จุดเปอร์เซ็นต์ ผลรวม 9.60 สัดส่วนเท่าเดิม

ส่วนแบ่งเหล่านี้ไม่ใช่โอกาส และไม่จำเป็นต้องอยู่ระหว่าง 0 ถึง 100% สินทรัพย์ที่ช่วย hedge พอร์ตจะมี $c_i$ ติดลบได้ ถ้าโปรแกรมรายงานตัดค่าติดลบเป็นศูนย์เพื่อให้กราฟวงกลมดูสวย ผลรวมจะไม่เท่ากับ variance อีกต่อไป

ขั้นที่ 7 — ย้ายเงินหนึ่งจุด ความเสี่ยงเปลี่ยนเท่าไร

กรรมการถามต่อ: ถ้าย้ายเงิน 1% จากหุ้นกู้ไปหุ้น ความผันผวนพอร์ตขึ้นเท่าไร ให้เพิ่มน้ำหนักตัว $i$ ทีละ $h$ โดยตรึงตัวอื่น จากการกระจาย $\mathbf w^{\mathsf T}\Sigma\mathbf w$ จะได้ $V_h=V+2hu_i+h^2\Sigma_{ii}$ แล้วหาอัตราเปลี่ยนของความผันผวน

\[\begin{aligned} \frac{\sigma_h-\sigma_p}{h}&=\frac{V_h-V}{h(\sigma_h+\sigma_p)} =\frac{2u_i+h\Sigma_{ii}}{\sigma_h+\sigma_p}\\ &\longrightarrow\frac{u_i}{\sigma_p}\quad(h\to0),\\ \frac{\mathbf u}{\sigma_p}&=\begin{bmatrix}0.1648\\0.0047\\0.0609\end{bmatrix},\\ \Delta\sigma&\approx0.01(0.1648-0.0047)=0.0016. \end{aligned}\]

บรรทัดแรกใช้ $\sigma_h-\sigma_p=(\sigma_h^2-\sigma_p^2)/(\sigma_h+\sigma_p)$ ซึ่งเลี่ยงการหาอนุพันธ์ของรากที่สองตรง ๆ เมื่อ $h$ เล็กลง $\sigma_h$ เข้าใกล้ $\sigma_p$ ตัวส่วนจึงเป็น $2\sigma_p$ ได้ marginal risk $u_i/\sigma_p$ การย้ายเงินเปลี่ยนสองน้ำหนักพร้อมกัน (+1% หุ้น −1% หุ้นกู้) จึงใช้ผลต่างของสองตัว ได้ประมาณ +0.16 จุดเปอร์เซ็นต์ คำนวณตรงด้วยน้ำหนัก $(0.51,0.29,0.20)$ ได้ 9.7609% เทียบกับ $9.60+0.16=9.76$ ต่างกันนิดเดียวเพราะพจน์ $h^2$

สังเกตความเชื่อมโยง: $\sum_iw_i\,(u_i/\sigma_p)=V/\sigma_p=\sigma_p$ marginal risk ถ่วงด้วยน้ำหนักให้ความผันผวนพอร์ตคืนมาพอดี เรื่องนี้ขยายเป็น การแยกความเสี่ยงด้วย MCR ใน factor model

ขั้นที่ 8 — risk parity: ให้ทุกสินทรัพย์แบกความเสี่ยงเท่ากัน

ถ้าต้องการให้ $c_i=w_i(\Sigma\mathbf w)_i$ เท่ากันทุกตัว เงื่อนไขเป็นสมการกำลังสองที่พันกัน วิธีง่ายคือหา $x_i\gt0$ ที่ทำให้ $x_i(\Sigma\mathbf x)_i=1$ ทุกตัว แล้วค่อยหารด้วยผลรวม ซึ่งไม่เปลี่ยนความเท่ากันของส่วนแบ่ง ตรึงตัวอื่นไว้ ให้ $b_i=\sum_{j\ne i}\Sigma_{ij}x_j$

\[\begin{aligned} \Sigma_{ii}x_i^2+b_ix_i-1&=0,\\ x_i&=\frac{-b_i+\sqrt{b_i^2+4\Sigma_{ii}}}{2\Sigma_{ii}},\\ \mathbf w_{\text{rp}}&\approx(0.2115,\ 0.5869,\ 0.2016),\\ \sigma_{\text{rp}}&\approx6.095\%. \end{aligned}\]

เลือกรากบวกของสมการกำลังสอง แล้ววนอัปเดตทีละตัวจนไม่ขยับ (โค้ดท้ายหน้าทำให้ดู) ผลคือหุ้นกู้ได้เงินมากที่สุดเพราะผันผวนน้อยและช่วย hedge หุ้น พอร์ตนี้ผันผวน 6.095% ถ้าอยากได้ความผันผวน 9.60% เท่าเดิม ต้องขยายทุกขาด้วย leverage $9.60/6.095\approx1.575$ เท่า ซึ่งต้องมีต้นทุนกู้ยืมและวงเงินรองรับ และ risk parity ไม่ได้รับประกันผลตอบแทนเฉลี่ยใด ๆ มันแค่จัดความเสี่ยงตาม covariance ที่ใส่เข้าไป

ขั้นที่ 9 — asset class จริงแปดกลุ่ม น้ำหนักเท่ากัน

โจทย์ให้อะไรมาบ้าง: covariance รายปีของ asset class แปดกลุ่มที่ประมาณจากข้อมูลในอดีต ความผันผวนตั้งแต่ 3.17% (พันธบัตรสหรัฐ) ถึง 32.0% (หุ้นเล็ก growth สหรัฐ) ลงเงินกลุ่มละ 12.5% เท่ากัน ตารางนี้สมมาตรครบทุกช่อง ถามว่าใครแบกความเสี่ยง

คำตอบ: คำนวณ $\mathbf u=\Sigma\mathbf w$ และ $c_i=w_iu_i$ แบบเดียวกับขั้นก่อน ได้ความผันผวนพอร์ต 14.73% ต่อปี พันธบัตรสองกลุ่มได้เงินรวม 25% แต่แบกความเสี่ยงรวมแค่ 0.27% หุ้นหกกลุ่มที่ได้เงิน 75% แบกถึง 99.73% หุ้นเล็ก growth สหรัฐกลุ่มเดียวแบก 24.43% เพราะผันผวนสูงและสัมพันธ์สูงกับหุ้นกลุ่มอื่น “กระจายเงินเท่ากัน” จึงไม่ได้แปลว่า “กระจายความเสี่ยงเท่ากัน”

ตรวจเองใน 10 วินาที: ผลรวมของแปดแท่งในรูปด้านล่างต้องเป็น 100% และเส้นประที่ 12.5% คือส่วนแบ่งที่ทุกกลุ่มจะได้ถ้าความเสี่ยงเท่ากับเงิน

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ไม่ได้หักค่าเฉลี่ย: บวก 5 จุดเปอร์เซ็นต์ให้ทุกวันของสินทรัพย์แรก ข้อมูลเป็น $(7,4,4)$ ค่า $(X^{\mathsf T}X)_{11}$ แบบไม่หักค่าเฉลี่ยกระโดดจาก 6 เป็น $49+16+16=81$ ทั้งที่การแกว่งไม่ได้เปลี่ยนเลย หักค่าเฉลี่ยก่อนจะได้ 6 เท่าเดิม

โค้ดตรวจว่าเครื่องรวมให้ผลเท่ากับการทำทีละขั้น สร้าง sample covariance แบ่งความเสี่ยงของพอร์ตใน hook และหาน้ำหนัก risk parity

เปิดดูโค้ด 
const T = A => A[0].map((_, j) => A.map(r => r[j]));
function mul(A, B) {
  if (A[0].length !== B.length) throw new Error('inner sizes do not match');
  const Bt = T(B);
  return A.map(r => Bt.map(c => r.reduce((s, x, k) => s + x * c[k], 0)));
}
const mv = (A, x) => A.map(r => r.reduce((s, a, j) => s + a * x[j], 0));
const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);

const P = [[1, 2], [0, 1]], Q = [[1, 0], [3, 1]];
console.log(mv(mul(P, Q), [1, 1]), mv(P, mv(Q, [1, 1])), mv(mul(Q, P), [1, 1]));

const A = [[1.2, 0.4], [0.9, 0.2], [1.5, 0.7]], w = [2, -1, 0.5];
const F = [[0.01, -0.02], [-0.03, 0.01], [0.02, 0.02]];
const e = mv(T(A), w);
console.log(mv(F, e), mv(mul(F, T(A)), w));       // 0.0035 -0.058 0.064 twice

const X = [[2, -1], [-1, 2], [-1, -1]];           // centred, percent
console.log(mul(T(X), X).map(r => r.map(v => v / 2))); // [[3,-1.5],[-1.5,3]]

const sd = [0.18, 0.06, 0.15];
const C = [[1, -0.2, 0.05], [-0.2, 1, 0.25], [0.05, 0.25, 1]];
const S = C.map((r, i) => r.map((c, j) => sd[i] * c * sd[j]));
function risk(wt) {
  const u = mv(S, wt), V = dot(wt, u);
  return { sd: Math.sqrt(V), shares: wt.map((x, i) => x * u[i] / V),
           marginal: u.map(x => x / Math.sqrt(V)) };
}
console.log(risk([0.5, 0.3, 0.2]));               // 0.096, 0.8584 0.0146 0.1270
console.log(risk([0.51, 0.29, 0.2]).sd);          // 0.09761

const x = S.map((r, i) => 1 / Math.sqrt(r[i]));
for (let it = 0; it < 500; it++) for (let i = 0; i < 3; i++) {
  const a = S[i][i], b = S[i].reduce((s, c, j) => s + (j === i ? 0 : c * x[j]), 0);
  x[i] = (-b + Math.sqrt(b * b + 4 * a)) / (2 * a);
}
const tot = x.reduce((s, v) => s + v, 0), rp = x.map(v => v / tot);
console.log(rp, risk(rp));                        // 0.2115 0.5869 0.2016, sd 0.06095

สิ่งที่ควรตอบได้หลังอ่าน

  • อธิบายว่ากติกา $(PQ)_{ik}=\sum_jP_{ij}Q_{jk}$ มาจากการแทนขั้นแรกลงในขั้นที่สอง และ $PQ\mathbf x$ ทำ $Q$ ก่อน
  • อ่าน $S\boldsymbol\theta$ ได้ทั้งแบบทีละแถวและแบบต่อคอลัมน์หัวต่อหาง และแยกมันออกจากการคูณทีละช่อง
  • ย้ายวงเล็บเพื่อประหยัดงานได้ (15,000 เทียบกับ 5 ล้านครั้ง) แต่สลับลำดับไม่ได้ ($(9,4)$ กับ $(3,10)$)
  • สร้าง sample covariance เป็น $X^{\mathsf T}X/(N-1)$ จากข้อมูลที่หักค่าเฉลี่ยแล้ว และระวังหน่วยยกกำลังสอง
  • แบ่ง variance พอร์ตด้วย $c_i=w_i(\Sigma\mathbf w)_i$: หุ้นที่ได้เงิน 50% แบก 85.84% และพอร์ตน้ำหนักเท่ากันแปดกลุ่มแบกความเสี่ยงหุ้น 99.73%

หน้านี้ใช้ matrix ทำการคำนวณ หน้าถัดไป Linear Functions and Linear Constraints ใช้ matrix เขียนข้อบังคับ: วงเงิน ห้าม short หรือ payoff ที่ต้องไม่ต่ำกว่าภาระ แล้วดูว่าชุดของแผนที่ผ่านทุกข้อหน้าตาเป็นอย่างไร
