7.3 Matrix Multiplication

คูณแถวกับคอลัมน์ เพื่อรวมหลายขั้นตอนโดยไม่ทำความหมายของข้อมูลหาย

พอร์ตสมมติลงเงินในหุ้นสหรัฐ 50% หุ้นกู้สหรัฐ 30% และทองคำที่วัดราคาเป็น USD อีก 20% หุ้นจึงแบกความเสี่ยงครึ่งหนึ่งด้วยหรือไม่?

ดูคำตอบภายใต้โมเดลที่จะคำนวณในบทนี้

ไม่จำเป็น ภายใต้ volatilities และ correlations ที่กำหนดด้านล่าง หุ้นได้ส่วนแบ่งความเสี่ยงประมาณ 85.84% และพอร์ตมี SD 9.60% ต่อปี นี่เป็นการจัดสรรความเสี่ยงจาก covariance model ไม่ใช่ความน่าจะเป็นที่หุ้นจะทำให้พอร์ตขาดทุน

เราจะสร้างกติกาการคูณจากการต่อการแปลงสองขั้น แล้วใช้กติกาเดียวกันกับ payoff, factor exposures และ covariance ไม่ต้องจำวิธีคำนวณคนละชุดสำหรับแต่ละงาน

1. ทำไมกติกาต้องเป็นแถวคูณคอลัมน์?

สมมติขั้นแรกแปลง input $\mathbf x$ เป็น $\mathbf y=Q\mathbf x$ แล้วขั้นที่สองแปลงเป็น $\mathbf z=P\mathbf y$ ถ้า $Q$ มีขนาด $n\times p$ และ $P$ มีขนาด $m\times n$ เราต้องการตารางเดียวที่รับ input $p$ ช่องแล้วส่ง output $m$ ช่อง

แทนสูตรของขั้นแรกลงในขั้นที่สอง แล้วจัดกลุ่มตาม input เดิม:

\[ \begin{aligned} y_j&=\sum_{k=1}^{p}Q_{jk}x_k,\\ z_i&=\sum_{j=1}^{n}P_{ij}y_j =\sum_{j=1}^{n}P_{ij}\sum_{k=1}^{p}Q_{jk}x_k\\ &=\sum_{k=1}^{p}\left(\sum_{j=1}^{n}P_{ij}Q_{jk}\right)x_k,\\ (PQ)_{ik}&:=\sum_{j=1}^{n}P_{ij}Q_{jk}. \end{aligned} \]

วงเล็บคือสัมประสิทธิ์ของ $x_k$ ที่ส่งถึง output $z_i$: แถว $i$ ของ $P$ จับคู่กับคอลัมน์ $k$ ของ $Q$ แล้วบวกทุกเส้นทางผ่านตัวกลาง $j$ นี่จึงเป็นกติกาที่ทำให้ $(PQ)\mathbf x=P(Q\mathbf x)$ ไม่ใช่กติกาที่ตั้งขึ้นโดยไม่มีเหตุผล

ดัชนีกลางมี $n$ ค่าเท่ากันทั้งสองตาราง จึงต้องมี shape $(m\times n)(n\times p)\to m\times p$ แต่ shape ตรงยังไม่พอ ชื่อและหน่วยของตัวกลางต้องตรงด้วย เช่นทั้งสองตารางต้องเรียง factors ในลำดับเดียวกัน

2. Matrix–vector อ่านได้ทั้งทีละแถวและทีละคอลัมน์

ใช้ payoff table เดิมจาก 7.2 แถวเป็นสองสถานะ คอลัมน์เป็นสามสัญญา แต่ละช่องมีหน่วย USD ต่อหน่วยสัญญา และถือจำนวนหน่วย $(2,6,4)$:

\[ \begin{aligned} S&=\begin{bmatrix}2&3&7\\1&6&5\end{bmatrix},\qquad \boldsymbol\theta=\begin{bmatrix}2\\6\\4\end{bmatrix},\\ S\boldsymbol\theta &=\begin{bmatrix}2(2)+3(6)+7(4)\\1(2)+6(6)+5(4)\end{bmatrix} =\begin{bmatrix}50\\58\end{bmatrix},\\ S\boldsymbol\theta &=2\begin{bmatrix}2\\1\end{bmatrix} +6\begin{bmatrix}3\\6\end{bmatrix} +4\begin{bmatrix}7\\5\end{bmatrix}. \end{aligned} \]

มุมมองแถวถามว่า “ในสถานะนี้ทุกสัญญารวมกันจ่ายเท่าไร” มุมมองคอลัมน์ถามว่า “แต่ละสัญญาเติม payoff เท่าไรให้ทุกสถานะ” ทั้งสองนับเงินชุดเดียวกัน จึงต้องได้ 50 และ 58 USD เหมือนกัน

หากคูณแต่ละคอลัมน์ด้วยจำนวนสัญญาแต่ยังไม่รวม จะได้ตาราง contributions $\begin{bmatrix}4&18&28\\2&36&20\end{bmatrix}$ ซึ่งมีประโยชน์ แต่ยังไม่ใช่ payoff รวม ต้องบวกแต่ละแถวอีกครั้ง อย่าสับสน elementwise multiplication หรือ broadcasting กับ matrix multiplication

ตัวอย่างขนาดที่ต่างกันชัด ๆ: ถ้า $v=(1,-2)^{\mathsf T}$ จะมี $v^{\mathsf T}v=1+4=5$ แต่ $vv^{\mathsf T}=\begin{bmatrix}1&-2\\-2&4\end{bmatrix}$ เป็นตาราง คอลัมน์ที่สองเท่ากับ −2 เท่าของคอลัมน์แรก จึงมีเพียงหนึ่งทิศอิสระ ไม่ได้กลับด้านได้เพียงเพราะมีสี่ช่อง

3. เปลี่ยนวงเล็บได้ แต่สลับลำดับไม่ได้

ให้ $P,Q$ เป็นกติกาสองขั้นดังนี้ และ input เป็น $(1,1)^{\mathsf T}$:

\[ \begin{aligned} P&=\begin{bmatrix}1&2\\0&1\end{bmatrix},\qquad Q=\begin{bmatrix}1&0\\3&1\end{bmatrix},\\ Q\begin{bmatrix}1\\1\end{bmatrix} &=\begin{bmatrix}1\\4\end{bmatrix},\qquad P\begin{bmatrix}1\\4\end{bmatrix}=\begin{bmatrix}9\\4\end{bmatrix},\\ PQ&=\begin{bmatrix}1+6&2\\3&1\end{bmatrix} =\begin{bmatrix}7&2\\3&1\end{bmatrix},\\ (PQ)\begin{bmatrix}1\\1\end{bmatrix} &=\begin{bmatrix}9\\4\end{bmatrix}. \end{aligned} \]

แต่ $QP=\begin{bmatrix}1&2\\3&7\end{bmatrix}$ ส่ง input เดิมไป $(3,10)^{\mathsf T}$ เพราะเป็นการทำ $P$ ก่อน $Q$ เราจึงเปลี่ยนวงเล็บเพื่อจัดงานได้ แต่ห้ามเปลี่ยนลำดับขั้นตอนโดยถือว่าคำตอบจะเหมือนเดิม

สำหรับสาม matrices ที่มิติต่อกันได้ ทั้ง $P(QR)$ และ $(PQ)R$ มีสมาชิกช่อง $i\ell$ เป็นผลรวมเดียวกัน $\sum_j\sum_k P_{ij}Q_{jk}R_{k\ell}$ จึงเท่ากันในเลขคณิตแม่นตรง นี่คือ associativity ไม่ใช่ commutativity

4. จากตำแหน่งหุ้นสู่ factor exposures

คราวนี้กำหนด $A$ ให้ แถวเป็น factors และคอลัมน์เป็น assets ตั้งแต่ต้น ต่างจากการจัดตารางใน 7.1–7.2 แถวเรียง Market/Quality/Rates และคอลัมน์เรียง AAPL/MSFT/JPM ทุก loading เป็นตัวเลขสมมติ:

\[ A=\begin{bmatrix}1.0&0.8&0.6\\0.3&0.5&0.2\\0.1&0.2&0.4\end{bmatrix}, \qquad \mathbf w=\begin{bmatrix}2\\-1\\1\end{bmatrix} \ \text{million USD}. \]

ทั้งสาม factors วัดเป็น returns ของพอร์ต factor ในงวดเดียวกันและสเกลที่กำหนดไว้ Rates ในตัวอย่างนี้จึงไม่ใช่การใส่ yield change เป็น basis points โดยตรง ถ้าเปลี่ยนหน่วย factor ต้องเปลี่ยน loadings ให้สอดคล้องกัน

\[ \begin{aligned} y_M&=1.0(2)+0.8(-1)+0.6(1)=1.8,\\ y_Q&=0.3(2)+0.5(-1)+0.2(1)=0.3,\\ y_R&=0.1(2)+0.2(-1)+0.4(1)=0.4,\\ \mathbf y=A\mathbf w&=\begin{bmatrix}1.8\\0.3\\0.4\end{bmatrix} \ \text{million USD}. \end{aligned} \]

ถ้าจะคำนวณสองพอร์ตพร้อมกัน วาง positions ของแต่ละพอร์ตเป็นคอลัมน์ของ $W$ แล้วใช้กติกาเดิมกับแต่ละคอลัมน์:

\[ \begin{aligned} W&=\begin{bmatrix}2&-1\\-1&2\\1&0\end{bmatrix},\\ AW&=\begin{bmatrix}1.8&0.6\\0.3&0.7\\0.4&0.3\end{bmatrix}. \end{aligned} \]

เช่นช่อง Market ของพอร์ตที่สองคือ $1(-1)+0.8(2)+0.6(0)=0.6$ ล้าน USD กติกาไม่ได้เปลี่ยนเมื่อเพิ่มจำนวนพอร์ต เพียงมี input หลายคอลัมน์

5. ต่อไปถึง P&L ในหลาย scenarios

ให้ $F$ มีแถวเป็น scenarios และคอลัมน์เป็น factor shocks เรียง Market/Quality/Rates เหมือน $A$:

\[ F=\begin{bmatrix}0.01&-0.02&0.005\\-0.02&0.01&-0.01\end{bmatrix}. \]

คำนวณ exposure ก่อนแล้วค่อยใส่ shocks ได้ $F(Aw)$ หรือรวมกติกาเป็น $FA$ ก่อนแล้วคูณ positions ทั้งสองทางต้องให้ส่วนของ P&L ที่โมเดลอธิบายเท่ากัน:

\[ \begin{aligned} FA&=\begin{bmatrix}0.0045&-0.001&0.004\\-0.018&-0.013&-0.014\end{bmatrix},\\ F(Aw)&=\begin{bmatrix}0.018-0.006+0.002\\-0.036+0.003-0.004\end{bmatrix}\\ &=(FA)w=\begin{bmatrix}0.014\\-0.037\end{bmatrix} \ \text{million USD}. \end{aligned} \]

$FA$ จึงเป็นตาราง modeled returns ของหุ้นในแต่ละ scenario ส่วนผลลัพธ์สุดท้ายเป็น 14,000 และ −37,000 USD ยังไม่รวม residual return, cash flows และต้นทุนอื่น การเปลี่ยนวงเล็บไม่ทำให้ส่วนที่โมเดลละไว้หายไป

ควรคูณ matrices รวมไว้ก่อนเสมอหรือไม่?

ไม่เสมอ การคูณ dense matrix $m\times n$ กับ $n\times p$ แบบตรงไปตรงมาใช้ scalar multiplications ประมาณ $mnp$ ครั้ง ไม่ได้โตแบบกำลังสามในทุก shape

เช่นแปลง 500 assets ผ่าน 3 factors ไป 1,000 scenarios การทำสองขั้นกับพอร์ตเดียวใช้ประมาณ $3(500)+1{,}000(3)=4{,}500$ ครั้ง แต่สร้าง matrix รวมก่อนใช้ $1{,}000(3)(500)=1{,}500{,}000$ ครั้ง แล้วแต่ละพอร์ตยังต้องคูณอีก 500,000 ครั้ง

จึงต้องดู shapes, จำนวนครั้งที่นำผลกลับมาใช้ และหน่วยความจำ ตัวเลขเหล่านี้เป็นการนับงานของวิธีพื้นฐาน ไม่ใช่ benchmark ของทุกไลบรารี และใน floating point การเปลี่ยนวงเล็บอาจให้ค่าท้ายทศนิยมต่างกันเมื่อเกิดการหักล้างของจำนวนต่างขนาด

6. นับทุกคู่ในข้อมูล: สร้าง sample covariance

ถ้าข้อมูลมี $N$ วันที่ตรงกันและ $d$ assets ให้ $X$ เป็น returns ที่ หักค่าเฉลี่ยของแต่ละคอลัมน์แล้ว ดังนั้น $X$ มีขนาด $N\times d$ การคูณ $X^{\mathsf T}X$ จะรวมผลคูณ return ของทุกคู่ assets ข้ามวันที่ตรงกัน:

\[ \begin{aligned} (X^{\mathsf T}X)_{ij}&=\sum_{t=1}^{N}X_{ti}X_{tj},\\ \widehat\Sigma_{ij}&=\frac{1}{N-1}\sum_{t=1}^{N}X_{ti}X_{tj},\\ \widehat\Sigma&=\frac{X^{\mathsf T}X}{N-1},\qquad N\ge2. \end{aligned} \]

นี่คือนิยาม sample covariance แบบตัวหาร $N-1$ การอ้างว่า unbiased ต้องมีสมมติฐาน เช่นข้อมูล i.i.d. ที่มี finite second moments การใช้ตัวหารนี้ไม่แก้ปัญหาวันไม่ตรง missing values หรือข้อมูลสัมพันธ์กันตามเวลาให้เอง

ตัวอย่างสามวันต่อไปนี้วัด return เป็นเปอร์เซ็นต์: 2 หมายถึง 2% ทั้งสองคอลัมน์มีค่าเฉลี่ยศูนย์อยู่แล้ว:

\[ \begin{aligned} X&=\begin{bmatrix}2&-1\\-1&2\\-1&-1\end{bmatrix},\\ X^{\mathsf T}X &=\begin{bmatrix}4+1+1&-2-2+1\\-2-2+1&1+4+1\end{bmatrix} =\begin{bmatrix}6&-3\\-3&6\end{bmatrix},\\ \widehat\Sigma&=\begin{bmatrix}3&-1.5\\-1.5&3\end{bmatrix}. \end{aligned} \]

หน่วยของตารางนี้คือจุดเปอร์เซ็นต์ยกกำลังสอง ถ้าแปลง returns เป็นเศษส่วนก่อน ตาราง covariance จะเล็กลง 10,000 เท่า ไม่ใช่ 100 เท่า พอร์ตน้ำหนัก $(0.6,0.4)$ มี returns $(0.8,0.2,-1)$ จุดเปอร์เซ็นต์ จึงมี sample variance $(0.64+0.04+1)/2=0.84$ ในหน่วยเดียวกัน

วันที่เดียวไม่พอสำหรับ sample covariance แบบนี้ เพราะตัวหารเป็นศูนย์ Outer product ของ observation เดียวจึงไม่ใช่ตัวประมาณ sample covariance แบบหัก sample mean นี้ และแม้มีหลายวัน matrix ก็อาจ singular ได้: centered columns มีผลรวมศูนย์ จึงอยู่ในพื้นที่มิติไม่เกิน $N-1$ เราจะศึกษาผลต่อ invertibility ใน 7.5

7. คลี่โจทย์เปิด: เงินครึ่งหนึ่ง แบกความเสี่ยงเท่าไร?

ตั้งสมมติฐานใหม่สำหรับ returns หนึ่งปี ไม่ใช่ใช้ข้อมูลสามวันข้างบนประมาณ: หุ้นสหรัฐมี SD 18%, หุ้นกู้สหรัฐ 6%, ทองคำในหน่วย USD 15% กำหนด correlations หุ้น–หุ้นกู้ −0.20, หุ้น–ทอง 0.05, หุ้นกู้–ทอง 0.25 และน้ำหนัก $w=(0.5,0.3,0.2)^{\mathsf T}$

ใช้ $\Sigma_{ij}=\rho_{ij}\sigma_i\sigma_j$ เช่น covariance หุ้น–หุ้นกู้คือ $(-0.2)(0.18)(0.06)=-0.00216$ จึงสร้างตารางในหน่วย return เศษส่วนยกกำลังสองได้:

\[ \Sigma=\begin{bmatrix} 0.0324&-0.00216&0.00135\\ -0.00216&0.0036&0.00225\\ 0.00135&0.00225&0.0225 \end{bmatrix}. \]

คูณรอบแรก $u=\Sigma w$ รวม covariance ของแต่ละ asset กับพอร์ต คูณรอบที่สอง $w^{\mathsf T}u$ รวมเป็น variance ตามสูตรที่พิสูจน์ใน 7.2:

\[ \begin{aligned} u_1&=0.0324(0.5)-0.00216(0.3)+0.00135(0.2)\\ &=0.015822,\\ u_2&=-0.00216(0.5)+0.0036(0.3)+0.00225(0.2)\\ &=0.000450,\\ u_3&=0.00135(0.5)+0.00225(0.3)+0.0225(0.2)\\ &=0.005850,\\ V=w^{\mathsf T}\Sigma w &=0.007911+0.000135+0.001170=0.009216,\\ \sigma_p&=\sqrt{V}=0.096=9.60\%. \end{aligned} \]

กำหนด variance contribution ของ asset $i$ เป็น $c_i=w_i u_i$ จะมี $\sum_i c_i=V$ โดยตรง หาก $\sigma_p\gt0$ กำหนด SD contribution เป็น $c_i/\sigma_p$ ผลรวมจะเป็น $V/\sigma_p=\sigma_p$ และส่วนแบ่งทั้งสองแบบเป็น $c_i/V$ เท่ากัน

สินทรัพย์น้ำหนักเงิน$c_i$ส่วนแบ่งความเสี่ยง
หุ้นสหรัฐ50%0.00791185.84%
หุ้นกู้สหรัฐ30%0.0001351.46%
ทองคำใน USD20%0.00117012.70%

หุ้นมี SD contribution $0.007911/0.096=0.08240625$ หรือประมาณ 8.24 จุดเปอร์เซ็นต์จาก SD รวม 9.60% นี่คือที่มาของคำตอบ 85.84% ไม่ใช่ “โอกาส 85.84% ที่หุ้นจะทำให้ขาดทุน” ส่วนแบ่งขึ้นกับทั้งน้ำหนักและ covariance ที่เลือกใช้

Contribution ติดลบก็เป็นไปได้เมื่อสินทรัพย์ช่วย hedge พอร์ต ส่วนแบ่งจึงไม่ใช่ probability และไม่จำเป็นต้องอยู่ในช่วง 0–100% ทุกตัว ไม่มีเหตุผลให้แปลงค่าติดลบเป็นศูนย์เพื่อทำให้รายงานดูสวย

8. ใช้ตัวเลขนี้ปรับพอร์ต ต้องถามเพิ่มอะไร?

Marginal risk: เพิ่มน้ำหนักตัวเดียว หรือย้ายเงินจากอีกตัว?

ถ้าตรึง weights อื่น จาก 7.2 จะมี $V_h=V+2hu_i+h^2\Sigma_{ii}$ เมื่อเพิ่ม weight ตัว $i$ ทีละ $h$ ให้ $\sigma_h=\sqrt{V_h}$ ใช้การคูณด้วยผลบวกของรากได้:

\[ \begin{aligned} \frac{\sigma_h-\sigma_p}{h} &=\frac{2u_i+h\Sigma_{ii}}{\sigma_h+\sigma_p} \longrightarrow\frac{u_i}{\sigma_p},\\ \frac{u}{\sigma_p}&=\begin{bmatrix}0.1648125\\0.0046875\\0.0609375\end{bmatrix}. \end{aligned} \]

แต่การย้ายเงินหนึ่งจุดเปอร์เซ็นต์จากหุ้นกู้ไปหุ้นเปลี่ยนสอง weights พร้อมกัน การประมาณอันดับแรกคือ $0.01(0.1648125-0.0046875)=0.00160125$ หรือ SD เพิ่มประมาณ 0.160125 จุดเปอร์เซ็นต์ คำนวณใหม่ด้วยน้ำหนัก $(0.51,0.29,0.20)$ ได้ SD 9.760877% ซึ่งต่างเล็กน้อยเพราะรวมผลไม่เชิงเส้นด้วย

Risk parity: เงินเท่ากันไม่ใช่เงื่อนไข เป้าหมายคือ contributions เท่ากัน

สำหรับสาม assets ในโมเดลนี้ risk parity แบบเท่ากันตั้งเป้า $w_i(\Sigma w)_i/V=1/3$ ทุกตัว ลองหาค่าบวก $x_i$ ที่ทำให้ $x_i(\Sigma x)_i=1$ ก่อน แล้วค่อย normalize เป็น $w_i=x_i/\sum_jx_j$ Contributions ทั้งสามจะถูกหารด้วยค่าร่วมเดียวกัน จึงยังเท่ากัน

เมื่อตรึง $x_j$ ตัวอื่นไว้ ให้ $b_i=\sum_{j\ne i}\Sigma_{ij}x_j$ สมการของตัวที่ $i$ เป็น quadratic ซึ่งเลือกรากบวกได้:

\[ \begin{aligned} \Sigma_{ii}x_i^2+b_ix_i-1&=0,\\ x_i&=\frac{-b_i+\sqrt{b_i^2+4\Sigma_{ii}}}{2\Sigma_{ii}}. \end{aligned} \]

อัปเดตทีละตัววนซ้ำจน contributions เข้าใกล้เป้าหมาย โค้ดท้ายบททำขั้นตอนนี้กับ $\Sigma$ ที่กำหนด ได้ weights ประมาณ $(0.2114644,0.5869298,0.2016058)$ และ SD 6.0950% ต่อปี ทุก variance contribution ประมาณ 0.001238303

หากใช้ weights ปัดสี่ตำแหน่ง $(0.2115,0.5869,0.2016)$ ส่วนแบ่งจะใกล้หนึ่งในสาม ไม่ใช่เท่ากันเป๊ะ การขยาย exposure ราว $9.60/6.0950\approx1.57506$ เท่าทำให้ SD กลับระดับเดิมภายใต้โมเดล แต่ไม่รับประกัน expected return และต้องนับ financing, costs และ leverage constraints แยกต่างหาก

function shape(A) {
  if (!Array.isArray(A) || !A.length || !Array.isArray(A[0]) || !A[0].length) {
    throw new TypeError('Need a nonempty rectangular matrix');
  }
  const n = A[0].length;
  if ([...A].some(row => !Array.isArray(row) || row.length !== n || ![...row].every(Number.isFinite))) {
    throw new TypeError('Need a finite rectangular matrix');
  }
  return [A.length, n];
}
function transpose(A) {
  const [, n] = shape(A);
  return Array.from({length: n}, (_, j) => A.map(row => row[j]));
}
function multiply(A, B) {
  const [, n] = shape(A), [m] = shape(B);
  if (n !== m) throw new RangeError('Matrix dimensions do not match');
  const Bt = transpose(B);
  return A.map(row => Bt.map(col => row.reduce((s, x, i) => s + x * col[i], 0)));
}
const column = xs => xs.map(x => [x]);
const matvec = (A, x) => multiply(A, column(x)).map(row => row[0]);
const dot = (a, b) => multiply([a], column(b))[0][0];
function sampleCovariance(rows) {
  const [N, n] = shape(rows);
  if (N < 2) throw new RangeError('Need at least two observations');
  // Shift before averaging so constant columns stay exactly zero.
  const offsets = rows.map(row => row.map((x, j) => x - rows[0][j]));
  const means = Array.from({length: n}, (_, j) => offsets.reduce((s, row) => s + row[j] / N, 0));
  const centered = offsets.map(row => row.map((x, j) => x - means[j]));
  return multiply(transpose(centered), centered).map(row => row.map(x => x / (N - 1)));
}
const Sigma = [[.0324, -.00216, .00135], [-.00216, .0036, .00225], [.00135, .00225, .0225]];
function risk(weights) {
  const u = matvec(Sigma, weights), V = dot(weights, u);
  if (!Number.isFinite(V) || V <= 0) throw new RangeError('Positive finite variance required for risk shares');
  const sd = Math.sqrt(V), contributions = weights.map((w, i) => w * u[i]);
  return {u, V, sd, contributions, shares: contributions.map(c => c / V),
    volContributions: contributions.map(c => c / sd), marginalVol: u.map(x => x / sd)};
}
function equalRiskExample() {
  // This iteration is for the fixed, positive-definite Sigma example above.
  const x = Sigma.map((row, i) => 1 / Math.sqrt(row[i]));
  for (let iteration = 0; iteration < 1000; iteration++) {
    for (let i = 0; i < x.length; i++) {
      const a = Sigma[i][i], b = Sigma[i].reduce((s, c, j) => s + (j === i ? 0 : c * x[j]), 0);
      x[i] = (-b + Math.sqrt(b * b + 4 * a)) / (2 * a);
    }
    const products = matvec(Sigma, x).map((u, i) => u * x[i]);
    if (Math.max(...products.map(p => Math.abs(p - 1))) < 1e-12) {
      const total = x.reduce((s, v) => s + v, 0);
      return {weights: x.map(v => v / total), iterations: iteration + 1, products};
    }
  }
  throw new Error('Equal-risk iteration did not converge');
}

ศัพท์ที่ใช้สรุปวิธีคิด
Matrix multiplication
การรวมผลคูณผ่านดัชนีกลาง เพื่อประกอบ linear maps หรือคำนวณหลาย dot products พร้อมกัน
Composition / associativity
การต่อกติกา / การเปลี่ยนวงเล็บโดยไม่เปลี่ยนลำดับ ในเลขคณิตแม่นตรง
Elementwise multiplication
คูณช่องที่จับคู่กันโดยยังไม่รวมตามดัชนีกลาง เป็นคนละ operation แม้อาจใช้สร้าง contributions ก่อนรวมได้
Risk contribution / risk parity
การแบ่งความเสี่ยงตาม covariance model / การเลือก weights ให้ contributions เป็นไปตามเป้าหมาย ไม่ใช่การทำนายว่า asset ใดจะทำให้ขาดทุน
ที่มาสั้น ๆ

กฎการคูณ matrices พัฒนาจากงานระบบสมการและการประกอบการแปลงในศตวรรษที่ 19 รวมถึงงานของ Binet และ Cayley สิ่งที่ควรจำไม่ใช่ชื่อกฎ แต่คือการแทนสมการขั้นแรกลงในขั้นที่สองแล้วรวมเส้นทางผ่านตัวแปรกลาง เหตุผลเดียวกันนี้ยังใช้กับการคำนวณพอร์ตและ covariance วันนี้

  • บอก input, output และตัวกลางให้ได้ก่อน: จำนวนมิติตรงกันไม่ได้แปลว่าชื่อหรือหน่วยตรงกัน
  • อ่านได้ทั้งแถวคูณคอลัมน์และการรวมคอลัมน์ถ่วงน้ำหนัก เปลี่ยนวงเล็บได้แต่ไม่สลับลำดับ
  • Sample covariance ต้อง center, align วันที่และระบุหน่วย จำนวนแถวมากขึ้นไม่ได้รับประกันว่าตารางกลับด้านได้

  • คำนวณได้ไม่เท่ากับโมเดลถูก ต้องแยกข้อจำกัดข้อมูล การประมาณ และต้นทุนการนำผลไปใช้
