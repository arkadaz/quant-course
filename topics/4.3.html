4.3 The Martingale Betting System

ทบเงินเดิมพันหลังแพ้ทำให้ชนะเกือบทุกรอบ แต่กำไรเฉลี่ยยังเป็นศูนย์ เพราะรอบที่แพ้ติดกันยาว ๆ เสียเงินมากพอจะลบกำไรเล็ก ๆ ทั้งหมด

ในบริษัทลงทุน กลยุทธ์ใหม่ที่อาจทำให้เสียเงินก้อนใหญ่ต้องผ่าน “คณะกรรมการความเสี่ยง” ก่อน คณะกรรมการนี้คือกลุ่มคนที่มีหน้าที่ถามคำถามเดียวซ้ำ ๆ ว่า ถ้าโชคร้าย เราจะเสียเงินเท่าไร

วันนี้มีคนเสนอกลยุทธ์หนึ่ง เกมที่ใช้เหมือนโยนเหรียญ ชนะหรือแพ้อย่างละครึ่ง ชนะได้เงินเท่าที่วาง แพ้เสียเงินที่วาง กติกาของกลยุทธ์มีแค่นี้:

  • ไม้แรกวาง \$1,000 (หนึ่ง “ไม้” คือการวางเงินเดิมพันหนึ่งครั้ง)
  • ถ้าแพ้ ไม้ต่อไปวางเป็นสองเท่าของไม้ก่อน คือ \$2,000, \$4,000, \$8,000, …
  • พอชนะครั้งแรก หยุด แล้วเริ่ม “รอบ” ใหม่ที่ \$1,000

พอร์ตที่ใช้เล่นมีทุน \$1,000,000 (พอร์ตคือเงินก้อนที่ทีมใช้ลงทุน) ผู้เสนอโชว์สถิติว่า กลยุทธ์นี้ชนะมากกว่า 99.8% ของรอบ หน้านี้จะคำนวณที่มาของตัวเลขนี้ให้ดูทีละขั้น

คณะกรรมการควรอนุมัติไหม

ลองตอบก่อนเปิดเฉลย

ไม่ควร ลองไล่ดูว่าถ้าแพ้ติดกัน เงินหายไปเท่าไร ไม้ที่ 1 ถึง 9 วาง \$1,000, \$2,000, …, \$256,000 ถ้าแพ้ครบเก้าไม้ เงินที่เสียรวมคือ

\[\begin{aligned}&1{,}000\,(1+2+4+\cdots+256)\\&\quad=1{,}000\times511=\$511{,}000\end{aligned}\]

ทุนจึงเหลือ $1{,}000{,}000-511{,}000=\$489{,}000$ แต่ไม้ที่ 10 ต้องวาง \$512,000 ซึ่งมากกว่าเงินที่เหลือ ทุนหนึ่งล้านจึงทบได้แค่ 9 ไม้

การแพ้ครบเก้าไม้ต้องแพ้ทุกไม้ ไม้ละครึ่ง โอกาสจึงเป็น $(1/2)^9=1/512\approx0.195\%$ ที่เหลือ $511/512\approx99.8\%$ คือรอบที่ชนะก่อนเงินหมด และได้ \$1,000 นี่คือที่มาของ 99.8%

ให้ $W$ คือกำไรของหนึ่งรอบ กำไรเฉลี่ย $\mathbb E[W]$ คือผลแต่ละแบบคูณโอกาสของมัน แล้วบวกกัน:

\[\begin{aligned}\mathbb E[W]&=\tfrac{511}{512}\times1{,}000-\tfrac1{512}\times511{,}000\\&=998.05-998.05=0\end{aligned}\]

อัตราชนะ 99.8% เป็นเรื่องจริง แต่ไม่ได้บอกว่ากลยุทธ์ทำเงิน เพราะรอบที่แพ้เสียหนักพอจะลบกำไรทั้งหมดพอดี ยิ่งถ้าเกมจริงเจ้ามือได้เปรียบ เช่นรูเล็ต กำไรเฉลี่ยจะติดลบราว \$271 ต่อรอบ ขั้นสุดท้ายของหน้านี้จะคำนวณตัวเลขนี้ให้ดู

ภาพรวมก่อนลงสูตร

กลยุทธ์ในโจทย์ข้างบนเก่าแก่มาก นักพนันเรียกมันว่า martingale แต่คำนี้ในคณิตศาสตร์มีความหมายอีกอย่าง หน้านี้จึงเรียกกลยุทธ์ว่า ระบบเดิมพันแบบทบ (doubling strategy) เพื่อไม่ให้สับสน

วิธีเล่นคือ ไม้แรกวาง $b$ ดอลลาร์ ($b$ คือเดิมพันฐาน) ถ้าแพ้ ไม้ต่อไปวางสองเท่าของไม้ก่อน แล้วหยุดทันทีที่ชนะครั้งแรก หน้านี้เรียกลำดับเดิมพันที่โตทีละสองเท่านี้ว่า “บันได” แต่ละขั้นของบันไดคือหนึ่งไม้ ข้ออ้างของระบบคือ ชนะครั้งเดียวก็ได้เงินที่แพ้มาคืนทั้งหมด แถมได้กำไร $b$ ถ้าเงินไม่มีวันหมด สักวันเราต้องชนะ ฟังดูเหมือนเงินฟรี

แต่คณิตศาสตร์บอกอีกเรื่อง เกมในโจทย์เป็น เกมยุติธรรม คือแต่ละไม้ได้กับเสียเฉลี่ยเท่ากัน กำไรเฉลี่ยต่อไม้เป็นศูนย์ ส่วน martingale ในคณิตศาสตร์คือลำดับสุ่มที่ ถ้ารู้ทุกอย่างที่เกิดมาแล้ว ค่าเฉลี่ยของก้าวถัดไปเท่ากับค่าตอนนี้พอดี โดยเฉลี่ยมันจึงไม่ขึ้นไม่ลง พูดอีกแบบคือไม่มี drift (drift คือแนวโน้มเฉลี่ยที่จะขึ้นหรือลงในแต่ละก้าว)

หน้านี้จะพิสูจน์ว่ากำไรสะสม $W_n$ ของระบบทบเป็น martingale ค่าเฉลี่ยของมันจึงเป็นศูนย์ทุกเวลา การเลือกขนาดเดิมพันจากผลที่เห็นแล้วสร้าง drift ไม่ได้

ถ้าอย่างนั้น เงินที่ “ได้แน่นอน” หายไปไหน รูปแรกด้านล่างให้คำตอบ รอบส่วนใหญ่จบที่ +\$1,000 แต่รอบที่แพ้ติดกันยาว ๆ ขาดทุนโตเป็นสองเท่าทุกไม้ เมื่อเอาขนาดขาดทุนคูณกับโอกาสที่มันเกิด ส่วนนี้หนักเท่ากับกำไรเล็ก ๆ ทั้งหมดพอดี

หน้านี้เดินทีละขั้น ตรวจก่อนว่าชนะครั้งเดียวคืนทุนจริง แล้วหาว่าทุนหนึ่งล้านทบได้กี่ไม้ พิสูจน์ว่า $W_n$ เป็น martingale ดูผลที่เป็นไปได้ของหนึ่งรอบ แล้วตอบสองคำถามที่ลึกที่สุด ทำไมการเลือกหยุดตอนชนะไม่ใช่ช่องโหว่ และทำไมทุนไม่จำกัดดูเหมือนชนะแน่นอน แต่ชนะได้แค่บนกระดาษ

ศัพท์ที่ใช้ในหัวข้อนี้
Doubling strategy (ระบบเดิมพันแบบทบ)
แพ้แล้วทบเดิมพันเป็นสองเท่าของไม้ก่อน หยุดเมื่อชนะครั้งแรก นักพนันเรียกว่า martingale หน้านี้ใช้มันเป็นตัวอย่างคลาสสิกว่า การปรับขนาดเดิมพันไม่ทำให้มีกำไรเฉลี่ยในเกมยุติธรรม
รอบ และ ไม้
หนึ่งไม้คือการวางเงินเดิมพันหนึ่งครั้ง หนึ่งรอบเริ่มที่เดิมพันฐาน $b$ และจบเมื่อชนะครั้งแรก หรือเมื่อเงินไม่พอวางไม้ถัดไป
บันได และ บันไดพัง
บันไดคือลำดับเดิมพัน $b, 2b, 4b, \ldots$ ที่โตทีละสองเท่า หนึ่งขั้นคือหนึ่งไม้ บันไดพังคือรอบที่แพ้ติดกันจนเงินที่เหลือไม่พอวางไม้ถัดไป
เกมยุติธรรม (fair game)
เกมที่กำไรเฉลี่ยต่อไม้เป็นศูนย์ เช่นโยนเหรียญ ชนะได้เท่าที่วาง แพ้เสียเท่าที่วาง อย่างละครึ่ง
Martingale
ลำดับสุ่มที่ ถ้ารู้ทุกอย่างที่เกิดมาแล้ว ค่าเฉลี่ยของค่าถัดไปเท่ากับค่าตอนนี้ จึงไม่มี drift ดูนิยามเต็มที่ นิยามของ martingale
Stopping time $\tau$
กติกาการหยุดที่ทุกไม้ $n$ เราบอกได้ทันทีว่าหยุดหรือยัง จากผลที่เห็นถึงไม้ $n$ โดยไม่ต้องรู้อนาคต “หยุดเมื่อชนะครั้งแรก” เป็น stopping time ส่วน “หยุดที่ราคาสูงสุดของวัน” ไม่ใช่ เพราะต้องรู้ราคาที่เหลือของวันก่อน
Optional stopping theorem
ทฤษฎีบทที่บอกว่า ถ้าหยุด martingale ด้วย stopping time ค่าเฉลี่ยตอนหยุดยังเท่ากับค่าตอนเริ่ม แต่ต้องมีเงื่อนไขบางข้อ เช่นเวลาหยุดไม่เกินจำนวนไม้ที่กำหนดไว้ล่วงหน้า ใช้พิสูจน์ว่าการเลือกเวลาหยุดไม่สร้างกำไรเฉลี่ย
Uniform integrability
เงื่อนไขว่า ไม่ว่าจะดูที่เวลาไหน ก็ไม่มีโอกาสเล็ก ๆ ที่พาเงินก้อนใหญ่มากหนีไปไกล ถ้าเงื่อนไขนี้ครบ เราสลับลำดับ “หาลิมิต” กับ “หาค่าเฉลี่ย” ได้ ขั้นที่ 6 แสดงกรณีที่มันไม่ครบ
Martingale transform
กำไรที่ได้เมื่อวางเดิมพันขนาด $H_k$ บนการขยับแต่ละครั้งของ martingale $X$ โดยเลือก $H_k$ จากอดีตเท่านั้น เขียนเป็น $\sum_k H_k\,(X_k-X_{k-1})$ ผลรวมนี้เป็น martingale เสมอ และเป็นต้นแบบของ Itô integral
House edge และ turnover
house edge คือส่วนที่เจ้ามือได้เปรียบ คิดเป็นสัดส่วนของเงินที่วาง เช่นรูเล็ตยุโรปเจ้ามือได้เฉลี่ย $1/37\approx2.7\%$ ของทุกดอลลาร์ที่วาง turnover คือยอดเงินที่วางรวมทุกไม้ ขาดทุนเฉลี่ยจึงเท่ากับ house edge คูณ turnover
VaR และ expected shortfall
สองตัวเลขที่ฝ่ายความเสี่ยงใช้วัดว่ากรณีแย่เสียเท่าไร VaR 99% (Value at Risk) คือผลที่ขอบของ 1% ที่แย่ที่สุด expected shortfall 99% คือค่าเฉลี่ยของ 1% ที่แย่ที่สุดทั้งก้อน ดูเต็มที่ VaR และ expected shortfall

ขั้นที่ 1 — ทำไมชนะครั้งเดียวคืนทุนทุกไม้

ข้ออ้างหลักของระบบคือ “ชนะเมื่อไรก็ได้กำไร $b$” ก่อนจะเชื่อ ต้องตรวจพีชคณิตก่อน เดิมพันโตทีละสองเท่า ไม้ 1 วาง $b$ ไม้ 2 วาง $2b$ ไม้ 3 วาง $4b$ ดังนั้นถ้าแพ้ $k-1$ ไม้แรก ไม้ที่ $k$ จะวาง $b\,2^{k-1}$

ให้ $L_k$ คือเงินที่เสียรวมเมื่อแพ้ครบ $k$ ไม้ เราต้องการสูตรของ $L_k$ ก่อน แล้วจึงดูว่าชนะที่ไม้ $k$ เหลือกำไรเท่าไร

\[ \begin{aligned} L_k&=b\,(1+2+4+\cdots+2^{k-1})\\ 2L_k-L_k&=b\,(2^k-1)\\ L_k&=b\,(2^k-1)\\ b\,2^{k-1}-L_{k-1}&=b\,2^{k-1}-b\,(2^{k-1}-1)\\ &=b \end{aligned} \]

ผลรวม $1+2+4+\cdots+2^{k-1}$ หาได้ด้วยท่าของอนุกรมเรขาคณิต คูณผลรวมด้วยสองจะได้ $2+4+\cdots+2^k$ แล้วลบผลรวมเดิมออก พจน์ตรงกลางหักกันหมด เหลือแค่ตัวท้ายสุดลบตัวแรกสุด คือ $2^k-1$ ลองกับ $k=3$ ก็ได้ $1+2+4=7=2^3-1$

สองแถวท้ายคือรอบที่ชนะครั้งแรกที่ไม้ $k$ ไม้นั้นวาง $b\,2^{k-1}$ และชนะได้เงินเท่านั้น เอาไปลบเงินที่เสียใน $k-1$ ไม้ก่อนหน้า $L_{k-1}=b\,(2^{k-1}-1)$ เหลือ $b$ พอดี ไม่ว่า $k$ จะเท่าไร ที่พอดีเพราะเดิมพันไม้ใหม่แต่ละไม้มากกว่าผลรวมของทุกไม้ก่อนหน้าอยู่ $b$ เสมอ

ผลคือ หลังไม้ที่ $n$ กำไรของรอบ $W_n$ มีได้แค่สองค่า เป็น $+b$ ถ้าชนะไปแล้ว หรือเป็น $-b\,(2^n-1)$ ถ้ายังแพ้ทุกไม้ เช่นเดิมพันฐาน $b=\$1$ จะได้ $W_n=1$ หรือ $W_n=1-2^n$ พีชคณิตถูกต้อง ปัญหาซ่อนอยู่ในเงื่อนไขที่ไม่ได้พูดออกมา คือเราต้องมีเงินวางไม้ที่ต้องการได้จริงทุกไม้

ตารางนี้ใส่ตัวเลขของโจทย์ $b=\$1{,}000$ เดิมพันไม้ที่ $k$ คือ $1{,}000\times2^{k-1}$ และเงินที่เสียรวมคือ $L_k=1{,}000\,(2^k-1)$ ช่องสุดท้ายเท่ากับ 1,000 ทุกแถว ตามที่เพิ่งพิสูจน์

ขั้นที่ 2 — ทุนหนึ่งล้านรองรับได้กี่ขั้น

ระบบทบทำงานได้ก็ต่อเมื่อมีเงินวางทุกไม้ ขั้นนี้หาว่าทุนของโจทย์ทบได้กี่ไม้ กรณีที่กินเงินมากที่สุดคือแพ้ติดกันทุกไม้ ทุนจึงต้องพอจ่ายเงินที่เสียรวมบนเส้นทางนั้น เงื่อนไขคือ $L_N\le B$ ไม่ใช่ $N\times b\le B$ เพราะเดิมพันโตทีละสองเท่า ไม่ได้เท่ากันทุกไม้

โจทย์ให้อะไรมาบ้าง:

  • เดิมพันฐาน $b=\$1{,}000$
  • ทุนที่ใช้ได้ $B=\$1{,}000{,}000$
  • สิ่งที่หา: $N$ คือจำนวนไม้มากที่สุดที่ยังจ่ายไหว

ใช้สูตร $L_N=b\,(2^N-1)$ จากขั้นที่ 1 แล้วย้ายข้าง:

\[ \begin{aligned} b\,(2^N-1)&\le B\\ 2^N&\le1+B/b=1{,}001\\ 2^9=512&\le1{,}001\lt1{,}024=2^{10}\\ N&=9 \end{aligned} \]

คำตอบ: ทบได้ 9 ไม้ เพราะ $2^9=512$ ยังไม่เกิน 1,001 แต่ $2^{10}=1{,}024$ เกินแล้ว ถ้าแพ้ครบ 9 ไม้ เงินที่เสียคือ $L_9=1{,}000\times(2^9-1)=\$511{,}000$ ทุนเหลือ $1{,}000{,}000-511{,}000=\$489{,}000$ แต่ไม้ที่ 10 ต้องวาง $1{,}000\times2^9=\$512{,}000$ ซึ่งมากกว่าเงินที่เหลือ ระบบจึงเดินต่อไม่ได้

หน้านี้เรียกเหตุการณ์นี้ว่า บันไดพัง บัญชีไม่ได้เหลือศูนย์ แต่ระบบเสียคุณสมบัติ “ชนะแล้วคืนทุน” ไปแล้ว เพราะวางไม้ที่ต้องการไม่ได้

ตรวจเองใน 10 วินาที: ทุนเพิ่มสองเท่าซื้อได้แค่หนึ่งไม้ เพราะไม้ที่เพิ่มต้องวางเท่ากับทุกไม้ก่อนหน้ารวมกันบวกอีก $b$ คิดคร่าว ๆ จาก $2^N\le1+B/b\approx B/b$ ถอด log ฐานสองทั้งสองข้าง ได้ $N\le\log_2(B/b)=\log_2(1{,}000)\approx9.97$ ปัดลงเป็น 9

ขั้นที่ 3 — พิสูจน์ว่ากำไรของรอบเป็น martingale

ทีนี้มาตรวจคำกล่าวหลักของหน้า คือกำไรของรอบ $W_n$ เป็น martingale ความหมายคือ ถ้ารู้ผลทุกไม้จนถึงไม้ที่ $n$ แล้ว ค่าเฉลี่ยของกำไรหลังไม้ถัดไปต้องเท่ากับกำไรตอนนี้พอดี เขียนเป็น $\mathbb E_n[W_{n+1}]=W_n$ โดย $\mathbb E_n[\,\cdot\,]$ คือค่าเฉลี่ยเมื่อรู้ผลถึงไม้ที่ $n$

จากขั้นที่ 1 ณ ไม้ที่ $n$ มีได้แค่สองกรณี:

  • ชนะไปแล้ว $W_n=b$ รอบจบแล้ว ไม่วางอะไรอีก จึงได้ $W_{n+1}=b=W_n$ กรณีนี้ผ่านทันที
  • ยังแพ้ทุกไม้ $W_n=-b\,(2^n-1)$ ไม้ถัดไปวาง $b\,2^n$ ถ้าชนะ กำไรของรอบกลายเป็น $b$ ถ้าแพ้ กลายเป็น $-b\,(2^{n+1}-1)$ แต่ละทางมีโอกาสครึ่งหนึ่ง

กรณีที่สองต้องคำนวณ เอาสองทางคูณโอกาสครึ่งหนึ่งแล้วบวกกัน:

\[ \begin{aligned} \mathbb E_n[W_{n+1}]&=\tfrac12\,b+\tfrac12\big[-b\,(2^{n+1}-1)\big]\\ &=\tfrac12 b-b\,2^{n}+\tfrac12 b\\ &=-b\,(2^n-1)\\ &=W_n \end{aligned} \]

ค่าเฉลี่ยของสองทางเท่ากับกำไรตอนนี้พอดี ท่าที่ต้องดูคือการกระจาย $\tfrac12\,b\,(2^{n+1}-1)=b\,2^n-\tfrac12 b$ แล้ว $\tfrac12 b$ สองตัวรวมกันเป็น $b$ เหลือ $-b\,2^n+b=-b\,(2^n-1)$ ซึ่งก็คือ $W_n$

นิยาม martingale ต้องการอีกสองข้อนอกจากสมการนี้ ข้อแรกคือ adapted แปลว่า $W_n$ ต้องคำนวณได้จากผลที่เห็นแล้ว ข้อนี้จริงเพราะ $W_n$ ขึ้นกับผลของไม้ที่ 1 ถึง $n$ เท่านั้น ข้อสองคือ integrable แปลว่าขนาดเฉลี่ยของ $W_n$ ต้องมีค่าจำกัด ข้อนี้ก็จริงเพราะ $|W_n|\le b\,2^n$ เสมอ จึงครบทั้งสามข้อ และใช้ tower property (กฎว่าค่าเฉลี่ยซ้อนค่าเฉลี่ย ยุบเหลือชั้นที่รู้น้อยกว่า) ต่อเป็นหลายไม้ได้ $\mathbb E_n[W_{n+m}]=W_n$

เหตุผลนี้ใช้ได้กว้างกว่าระบบทบ ให้ $C_k$ คือผลของไม้ที่ $k$ ในเกมยุติธรรม เป็น $+1$ ถ้าชนะ และ $-1$ ถ้าแพ้ อย่างละครึ่ง จึงมี $\mathbb E_{k-1}[C_k]=0$ ให้ $H_k$ คือขนาดเดิมพันไม้ที่ $k$ ซึ่งเลือกจากผลก่อนหน้าเท่านั้น กำไรของไม้นั้นคือ $H_kC_k$ เพราะ $H_k$ รู้ค่าแล้วก่อนไม้นี้เริ่ม จึงดึงออกนอกค่าเฉลี่ยได้ $\mathbb E_{k-1}[H_kC_k]=H_k\,\mathbb E_{k-1}[C_k]=0$

กำไรสะสม $\sum_k H_kC_k$ จึงเป็น martingale เสมอ ไม่ว่าจะเลือก $H_k$ ฉลาดแค่ไหน ผลรวมแบบนี้เรียกว่า martingale transform ข้อสรุปคือ การปรับขนาดเดิมพันจากอดีตเปลี่ยนรูปร่างของผลได้ แต่สร้าง drift ไม่ได้

ลองใส่ตัวเลขของโจทย์ แพ้มาแล้วสองไม้ (\$1,000 และ \$2,000) ไม้ที่สามจะวาง \$4,000 กำไรตอนนี้และสองทางที่เป็นไปได้คือ

\[\begin{aligned}W_2&=-1{,}000-2{,}000=-3{,}000\\\text{win}&:\ -3{,}000+4{,}000=+1{,}000\\\text{lose}&:\ -3{,}000-4{,}000=-7{,}000\\\mathbb E_2[W_3]&=\tfrac12(1{,}000)+\tfrac12(-7{,}000)\\&=-3{,}000=W_2\end{aligned}\]

ค่าเฉลี่ยหลังไม้ที่สามเท่ากับกำไรตอนนี้ ตรงตามสมการ รูปคานด้านล่างวาดตัวเลขชุดนี้

ขั้นที่ 4 — หนึ่งรอบมีสองผลลัพธ์: ค่าเฉลี่ยศูนย์ ความเสี่ยงไม่ศูนย์

ตอนนี้ใช้ผลของขั้นก่อน ๆ ตอบคำถามของคณะกรรมการตรง ๆ หนึ่งรอบที่ทบได้ไม่เกิน $N$ ไม้ มีผลแค่สองแบบ:

  • ชนะภายใน $N$ ไม้ ได้ $+b$ มีโอกาส $1-2^{-N}$
  • แพ้ครบ $N$ ไม้ (บันไดพัง) เสีย $b\,(2^N-1)$ มีโอกาส $(1/2)^N=2^{-N}$ เพราะต้องแพ้ทุกไม้ ไม้ละครึ่ง

เราอยากรู้สองอย่าง ค่าเฉลี่ย $\mathbb E[W]$ บอกว่าโดยเฉลี่ยได้หรือเสีย ส่วน variance และ SD (standard deviation คือรากที่สองของ variance) บอกว่าผลกระจายห่างจากค่าเฉลี่ยแค่ไหน

\[ \begin{aligned} \mathbb E[W]&=b\,(1-2^{-N})\\ &\qquad-b\,(2^N-1)\,2^{-N}\\ &=b-b\,2^{-N}-b+b\,2^{-N}=0\\ \operatorname{Var}(W)&=\mathbb E[W^2]\\ &=b^2(1-2^{-N})+b^2(2^N-1)^2\,2^{-N}\\ &=b^2\,(2^N-1)\\ \operatorname{SD}(W)&=b\sqrt{2^N-1}\\ &=1{,}000\sqrt{511}\approx22{,}605 \end{aligned} \]

ค่าเฉลี่ยคือผลแต่ละแบบคูณโอกาสแล้วบวกกัน พอกระจายวงเล็บ ทุกพจน์หักกันหมด ได้ศูนย์ ตรงกับที่ martingale บอกไว้ล่วงหน้า เพราะค่าเฉลี่ยต้องเท่ากับค่าตอนเริ่ม $W_0=0$

variance ปกติคือ $\mathbb E[W^2]-(\mathbb E[W])^2$ แต่ที่นี่ค่าเฉลี่ยเป็นศูนย์ จึงเหลือแค่ $\mathbb E[W^2]$ ท่าที่ทำให้ยุบได้คือเขียน $1-2^{-N}$ ใหม่เป็น $(2^N-1)\,2^{-N}$ แล้วดึง $b^2(2^N-1)$ ออกเป็นตัวร่วม ข้างในจะเหลือ $2^{-N}+(2^N-1)\,2^{-N}=2^N\cdot2^{-N}=1$

ใส่ตัวเลขของโจทย์ $b=1{,}000$ และ $N=9$ อัตราชนะคือ $1-2^{-9}=511/512\approx99.80\%$ โอกาสบันไดพังคือ $2^{-9}=1/512\approx0.195\%$ แต่ขาดทุนเมื่อพัง $1{,}000\times511=\$511{,}000$ ใหญ่กว่ากำไร \$1,000 อยู่ 511 เท่า รอบที่บันไดพังจึงเป็น “หาง” ของผล คือเหตุการณ์ที่เกิดยาก แต่เสียหนัก

SD ราว \$22,605 ไม่ใช่ขาดทุนสูงสุด มันวัดการกระจายโดยรวม ส่วนขาดทุนสูงสุดคือ \$511,000 สองตัวเลขนี้ตอบคนละคำถาม และไม่มีตัวไหนเห็นได้จากอัตราชนะ

ขั้นที่ 5 — การหยุดตอนชนะไม่ใช่ช่องโหว่: optional stopping

คนที่ยังไม่เชื่อมักแย้งว่า “แต่ผมเลือกหยุดตอนที่ได้เปรียบ” ขั้นนี้แสดงว่า การเลือกเวลาหยุดจากสิ่งที่เห็นแล้ว ก็สร้างกำไรเฉลี่ยไม่ได้เหมือนกัน ตราบใดที่เงื่อนไขบางข้อครบ

ก่อนอื่นต้องรู้จักคำว่า stopping time กติกาการหยุด $\tau$ (ไม้ที่เราหยุด) เป็น stopping time ถ้าทุกไม้ เราบอกได้ทันทีว่าหยุดหรือยัง จากผลที่เห็นถึงไม้นั้น โดยไม่ต้องรู้อนาคต “หยุดเมื่อชนะครั้งแรก” เป็น stopping time

ให้ $X_n$ เป็น martingale ใด ๆ เช่นกำไรของเกมยุติธรรม และให้ $\min(\tau,n)$ คือไม้ที่หยุด หรือไม้ที่ $n$ แล้วแต่อันไหนมาก่อน ความคิดหลักคือ มองการหยุดเป็นการเลือกขนาดเดิมพัน $H_k$ อีกแบบหนึ่ง:

\[ \begin{aligned} X_{\min(\tau,n)}&=X_0+\sum_{k=1}^{n}H_k\,(X_k-X_{k-1})\\ H_k&=1\ \ (k\le\tau),\qquad H_k=0\ \ (k\gt\tau)\\ \mathbb E\big[X_{\min(\tau,n)}\big]&=\mathbb E[X_0]\\ \mathbb E[X_\tau]&=\mathbb E[X_0]\qquad(\tau\le N) \end{aligned} \]

การหยุดก็คือการถือ 1 หน่วยไปเรื่อย ๆ จนกว่าจะหยุด หลังจากนั้นถือ 0 หน่วย ($H_k=0$) ผลรวมของการขยับที่เราถือไว้ จึงเท่ากับค่าของ $X$ ตอนหยุดพอดี

ท่าที่ต้องตรวจคือ $H_k$ เลือกจากอดีตจริงไหม การถือไม้ที่ $k$ แปลว่า $k\le\tau$ คือยังไม่หยุดก่อนไม้นี้ ข้อนี้รู้ได้จากผลถึงไม้ $k-1$ เพราะ $\tau$ เป็น stopping time ดังนั้นกระบวนการที่ถูกหยุดคือ martingale transform และเป็น martingale ด้วยเหตุผลเดียวกับขั้นที่ 3 ค่าเฉลี่ยของมันจึงคงที่เท่าค่าตอนเริ่ม

ถ้าเวลาหยุดมีเพดาน $N$ ที่รู้ล่วงหน้า คือ $\tau\le N$ เสมอ ก็แทน $n=N$ ได้เลย เพราะ $\min(\tau,N)=\tau$ ได้แถวสุดท้าย นี่คือ optional stopping theorem แบบง่ายที่สุด ระบบทบที่ทุนจำกัดเข้าเงื่อนไขนี้ เพราะรอบหนึ่งจบไม่เกิน 9 ไม้ ($\min(\tau,9)\le9$) ค่าเฉลี่ยตอนหยุดจึงเป็น $W_0=0$ ตรงกับที่ขั้นที่ 4 คำนวณไว้

ทฤษฎีบทนี้มีรูปอื่นที่ยอมให้เวลาหยุดไม่มีเพดาน แต่ต้องแลกด้วยเงื่อนไขอื่น เช่น แต่ละไม้ขยับได้ไม่เกินค่าคงที่ค่าหนึ่ง และเวลาหยุดเฉลี่ย $\mathbb E[\tau]$ มีค่าจำกัด หรือกระบวนการที่หยุดแล้วไม่มีวันออกนอกช่วงจำกัดช่วงหนึ่ง เงื่อนไขชุดเดียวกันนี้คือสิ่งที่ Wald's identity ต้องการ

ตัวอย่างที่ไม่ใช่ stopping time คือ “หยุดที่ราคาสูงสุดของวัน” เพราะ ณ เวลานั้นเรายังไม่รู้ว่าราคาจะขึ้นไปสูงกว่านี้อีกไหม ถ้าใช้กติกาแบบนี้ได้ ก็คือการแอบดูอนาคต ซึ่งข้อ adapted ของนิยาม martingale ห้ามไว้แล้ว

ขั้นที่ 6 — ทุนไม่จำกัด: ชนะเกือบแน่นอน แล้วค่าเฉลี่ยศูนย์หายไปไหน

ทีนี้ตัดเพดานทิ้ง สมมติว่าทุนไม่จำกัด ชนะครั้งแรกต้องมาถึงสักวัน และเมื่อมาถึงก็ได้ $W_\tau=b$ ทุกเส้นทาง ดูเหมือนค่าเฉลี่ยต้องเป็น $b$ ไม่ใช่ศูนย์ ซึ่งขัดกับขั้นที่ 5 ขั้นนี้หาว่าเหตุผลข้อไหนพัง โดยคำนวณสี่อย่าง โอกาสที่ยังไม่ชนะหลัง $n$ ไม้ เวลารอเฉลี่ย ส่วนที่เส้นทางที่ยังแพ้ดึงค่าเฉลี่ยลง และยอดเงินที่วางรวมโดยเฉลี่ย

\[ \begin{aligned} P(\tau\gt n)&=2^{-n}\\ \mathbb E[\tau]&=\sum_{k=1}^{\infty}P(\tau\ge k)\\ &=\sum_{k=1}^{\infty}2^{-(k-1)}=2\\ 2^{-n}\cdot b\,(2^n-1)&=b\,(1-2^{-n})\\ \mathbb E[\text{stake}]&=\sum_{k=1}^{\infty}2^{-(k-1)}\,b\,2^{k-1}\\ &=\sum_{k=1}^{\infty}b=\infty \end{aligned} \]

โอกาสที่ยังไม่ชนะหลัง $n$ ไม้คือ $2^{-n}$ เพราะต้องแพ้ทุกไม้ ไม้ละครึ่ง ค่านี้ลดลงสู่ศูนย์เมื่อ $n$ โต จึงชนะในเวลาจำกัดด้วยความน่าจะเป็นหนึ่ง เส้นทางที่แพ้ตลอดกาลยังเขียนออกมาได้ แต่มีโอกาสเป็นศูนย์

เวลารอเฉลี่ย $\mathbb E[\tau]$ ใช้สูตรของตัวนับ $\tau$ นับจำนวนไม้ที่เล่น ไม้ที่ $k$ ถูกนับก็ต่อเมื่อรอบยังไม่จบก่อนไม้นี้ คือ $\tau\ge k$ ค่าเฉลี่ยของ $\tau$ จึงเท่ากับผลรวมของ $P(\tau\ge k)$ ทุก $k$ เหตุการณ์ $\tau\ge k$ คือแพ้ $k-1$ ไม้แรก มีโอกาส $2^{-(k-1)}$ ผลรวมเป็นอนุกรมเรขาคณิต $1+\tfrac12+\tfrac14+\cdots=2$ รอเฉลี่ยแค่สองไม้ ทั้งหมดนี้จริง

เงินซ่อนอยู่ในผลคูณ $2^{-n}\cdot b\,(2^n-1)$ ผลคูณนี้คือส่วนที่เส้นทาง “ยังแพ้อยู่หลัง $n$ ไม้” ดึงค่าเฉลี่ยลง (โอกาสคูณขนาดขาดทุน) ได้ $b(1-2^{-n})$ ซึ่งไม่ลดลงเลย กลับเข้าใกล้ $b$ ทุกไม้ที่เพิ่ม เพราะโอกาสหดลงครึ่งหนึ่ง แต่ขนาดขาดทุนโตเป็นสองเท่า โอกาสนิดเดียวจึงพาเงินก้อนที่ใหญ่ขึ้นเรื่อย ๆ ลงไปทางลบ ส่วนนี้หักกับกำไร $b(1-2^{-n})$ ของเส้นทางที่ชนะแล้วพอดี ค่าเฉลี่ยจึงเป็นศูนย์ทุก $n$ ที่จำกัด คือ $\mathbb E[W_{\min(\tau,n)}]=0$

แต่พอให้ $n$ ไปถึงอนันต์ โอกาสของเส้นทางที่ยังแพ้กลายเป็นศูนย์ เส้นทางนั้นหายไปจากภาพ และพาส่วนที่มันดึงค่าเฉลี่ยลง (เกือบ $-b$) หายไปด้วย ทุกเส้นทางที่เหลือจบที่ $b$ ลิมิตของ $W_{\min(\tau,n)}$ จึงเป็น $b$ ทั้งที่ค่าเฉลี่ยก่อนถึงลิมิตเป็นศูนย์ทุกตัว แปลว่าเราสลับลำดับ “หาลิมิต” กับ “หาค่าเฉลี่ย” ไม่ได้ อาการนี้เรียกว่าขาด uniform integrability คือมีโอกาสเล็ก ๆ ที่พาเงินก้อนใหญ่มากหนีไป

แถวสุดท้ายบอกราคาของ “ชนะแน่นอน” ยอดเงินที่วางรวมโดยเฉลี่ย (stake) เป็นอนันต์ เพราะไม้ที่ $k$ เกิดด้วยโอกาส $2^{-(k-1)}$ และวาง $b\,2^{k-1}$ ผลคูณเป็น $b$ ทุกไม้ บวกกันไม่รู้จบ

ขาดทุนลึกสุดระหว่างทางก่อนชนะก็มีค่าเฉลี่ยเป็นอนันต์เหมือนกัน ถ้าชนะที่ไม้ $k$ (โอกาส $2^{-k}$) ระหว่างทางเคยเสียไป $b\,(2^{k-1}-1)$ ผลคูณ $2^{-k}\,b\,(2^{k-1}-1)=b\,(\tfrac12-2^{-k})$ เข้าใกล้ $b/2$ ทุกพจน์ ผลรวมจึงโตไม่จำกัด ไม่มีใครมีเงินขนาดนั้น และไม่มีคู่ค้าคนไหนยอมรับเดิมพันขนาดนั้น

ขั้นที่ 7 — เล่นซ้ำหลายรอบ: บันไดจะพังเมื่อไร

คณะกรรมการไม่ได้อนุมัติแค่รอบเดียว ระบบจะเล่นวันละหลายรอบ คำถามที่ถูกจึงเป็น ตลอดช่วงเวลาที่เล่น โอกาสที่จะไม่เจอบันไดพังเลยมีเท่าไร

โจทย์ให้อะไรมาบ้าง:

  • แต่ละรอบใช้ผลชุดใหม่ ไม่เกี่ยวกับรอบก่อน (รอบอิสระต่อกัน)
  • คง $b=\$1{,}000$ และ $N=9$ ไว้ตลอด ไม่เพิ่มเพดานตามกำไรที่สะสมได้
  • โอกาสบันไดพังต่อรอบคือ $1/512$ จากขั้นที่ 4 โอกาสรอดหนึ่งรอบจึงเป็น $511/512$
  • เลิกเล่นเมื่อบันไดพังครั้งแรก

ให้ $R$ คือจำนวนรอบ รอบอิสระต่อกัน โอกาสรอดทุกรอบจึงเอาโอกาสรอดแต่ละรอบมาคูณกัน $R$ ครั้ง “ครึ่งชีวิต” $R_{1/2}$ คือจำนวนรอบที่โอกาสรอดเหลือครึ่งหนึ่ง หาได้จากการแก้ $(511/512)^R=0.5$ ด้วยการถอด ln ทั้งสองข้าง

\[ \begin{aligned} P(\text{no failure in }R)&=\big(\tfrac{511}{512}\big)^R\\ R_{1/2}&=\frac{\ln0.5}{\ln(511/512)}\approx354.5\\ \mathbb E[\text{cycles to failure}]&=\frac{1}{1/512}=512 \end{aligned} \]

จำนวนรอบจนพังมีการแจกแจงแบบ geometric คือนับจำนวนครั้งที่ทำซ้ำจนเหตุการณ์หนึ่งเกิดครั้งแรก ค่าเฉลี่ยของมันคือ 1 หารด้วยโอกาสต่อรอบ จึงได้แถวสุดท้าย

คำตอบ: แทน $R$ เป็น 100, 500 และ 2,000 รอบ

\[\begin{aligned}\big(\tfrac{511}{512}\big)^{100}&\approx82.2\%\\\big(\tfrac{511}{512}\big)^{500}&\approx37.6\%\\\big(\tfrac{511}{512}\big)^{2000}&\approx2.0\%\end{aligned}\]

ครึ่งชีวิต 354.5 ไม่ใช่จำนวนเต็ม รอบที่ 355 จึงเป็นรอบแรกที่โอกาสรอดต่ำกว่าครึ่ง จำนวนรอบจนพังเฉลี่ย 512 รอบ รอบสุดท้ายคือรอบที่พัง ที่เหลือเป็นรอบที่ชนะ กำไรเฉลี่ยรวมจนพังจึงเป็น

\[\begin{aligned}\mathbb E[\text{wins}]&=512-1=511\\\mathbb E[\text{total}]&=511\times1{,}000-511{,}000\\&=0\end{aligned}\]

ได้ศูนย์พอดีอีกครั้ง

ตรวจเองใน 10 วินาที: เมื่อ $x$ เล็ก $\ln(1-x)\approx-x$ จึงได้ $(1-x)^R\approx e^{-Rx}$ แทน $x=1/512$ และ $R=500$ ได้ $Rx=500/512\approx0.977$ และ $e^{-0.977}\approx0.377$ ใกล้กับ 0.376 ที่คำนวณตรง

ขั้นที่ 8 — เพิ่มทุนซื้อเวลา ไม่ได้ซื้อความได้เปรียบ

ผู้เสนออาจแก้ว่า “งั้นเพิ่มทุนอีกนิด” ขั้นนี้ดูว่าเพิ่มทุนแล้วได้อะไร และเสียอะไร

โจทย์ให้อะไรมาบ้าง:

  • ทุนเพิ่มจาก \$1,000,000 เป็น \$1,023,000 ตัวเลขนี้เลือกให้พอดีกับเงินที่ต้องใช้ถ้าแพ้ครบ 10 ไม้ $L_{10}=1{,}000\times(2^{10}-1)=\$1{,}023{,}000$
  • เพดานจึงขยับจาก $N=9$ เป็น $N=10$
  • เดิมพันฐาน $b=\$1{,}000$ และเกมยุติธรรมเหมือนเดิม

คำนวณใหม่ด้วยสูตรเดิมจากขั้นที่ 4 และขั้นที่ 7 โดยเปลี่ยน 9 เป็น 10:

\[ \begin{aligned} P(\text{failure})&=2^{-10}=1/1{,}024\\ \mathbb E[W]&=\tfrac{1023}{1024}(1{,}000)-\tfrac{1}{1024}(1{,}023{,}000)\\ &=0\\ \big(\tfrac{1023}{1024}\big)^{500}&\approx61.4\%\\ R_{1/2}&=\frac{\ln0.5}{\ln(1023/1024)}\approx709.4 \end{aligned} \]

คำตอบ: ทุนเพิ่มขึ้นแค่ $23{,}000/1{,}000{,}000=2.3\%$ แต่โอกาสพังต่อรอบลดลงครึ่งหนึ่ง จาก 1/512 เป็น 1/1,024 ครึ่งชีวิตจึงยืดจาก 354.5 เป็น 709.4 รอบ และโอกาสรอด 500 รอบขึ้นจาก 37.6% เป็น 61.4%

แต่ค่าเฉลี่ยยังเป็นศูนย์ และขาดทุนเมื่อพังเกือบเป็นสองเท่า จาก \$511,000 เป็น \$1,023,000 สิ่งที่การเพิ่มทุนซื้อได้คือเวลาก่อนจะเจอหาง โดยแลกกับหางที่ลึกขึ้น

ตรวจเองใน 10 วินาที: โอกาสพังลดครึ่ง แต่ขนาดขาดทุนเพิ่มราวสองเท่า ผลคูณจึงยังราว 1,000 เท่าเดิม คือ $\tfrac1{1{,}024}\times1{,}023{,}000\approx999.0$ เทียบกับ $\tfrac1{512}\times511{,}000\approx998.0$ ส่วนนี้หักกับกำไรฝั่งชนะ $\tfrac{1023}{1024}\times1{,}000\approx999.0$ พอดีเหมือนเดิม

ขั้นที่ 9 — เมื่อเจ้ามือได้เปรียบ: รูเล็ตยุโรป 37 ช่อง

ทุกขั้นที่ผ่านมาใช้เกมยุติธรรม แต่เกมจริงไม่ยุติธรรม เจ้ามือ (คาสิโน) ได้เปรียบเสมอ ขั้นนี้ดูว่าระบบทบช่วยหลบความได้เปรียบนั้นได้ไหม ตัวอย่างที่ใช้คือรูเล็ตยุโรป วงล้อมี 37 ช่อง เป็นสีแดง 18 ช่อง สีดำ 18 ช่อง และช่องศูนย์สีเขียว 1 ช่อง ถ้าแทงสีแดง ลูกตกช่องแดงได้เงินเท่าที่วาง ลูกตกช่องอื่น (รวมช่องศูนย์) เสียเงินที่วาง

โจทย์ให้อะไรมาบ้าง:

  • โอกาสชนะต่อไม้ $p=18/37\approx0.4865$
  • โอกาสแพ้ต่อไม้ $q=19/37\approx0.5135$ (ดำ 18 ช่อง บวกช่องศูนย์)
  • $b=\$1{,}000$ และ $N=9$ เหมือนเดิม

ระบบทบเก้าไม้ยังมีปลายทางสองแบบเหมือนเดิม คือได้ $b$ หรือเสีย $b\,(2^N-1)$ แต่โอกาสแพ้ครบเก้าไม้เปลี่ยนเป็น $q^9$ เราจะหาค่าเฉลี่ย แล้วตรวจอีกทางด้วยยอดเงินที่วางรวม (turnover)

\[ \begin{aligned} \mathbb E[W]&=(1-q^N)\,b-q^N\,b\,(2^N-1)\\ &=b\,\big[1-(2q)^N\big]\\ (2q)^9&=(38/37)^9\approx1.2713\\ \mathbb E[W]&\approx1{,}000\,(1-1.2713)\\ &\approx-271.27\\ \mathbb E[\text{turnover}]&=\sum_{k=0}^{8}q^k\,b\,2^k\\ &=b\sum_{k=0}^{8}(2q)^k\\ &=b\,\frac{(2q)^9-1}{2q-1}\\ &=37\,b\,\big[(2q)^9-1\big]\approx10{,}036.89\\ \tfrac1{37}\,\mathbb E[\text{turnover}]&=b\,\big[(2q)^9-1\big]\approx271.27 \end{aligned} \]

ทำไม $(2q)^N$ ถึงสำคัญ กระจายแถวแรกได้ $b-bq^N-bq^N2^N+bq^N=b-b\,(2q)^N$ ถ้าเกมยุติธรรม $q=1/2$ จะได้ $2q=1$ และ $(2q)^N=1$ ค่าเฉลี่ยจึงเป็นศูนย์ตามเดิม แต่รูเล็ตมี $2q=38/37\approx1.027$ มากกว่าหนึ่งแค่ราว 2.7% พอยกกำลังเก้า ส่วนเกินนี้โตเป็นราว 27% ค่าเฉลี่ยจึงติดลบราว \$271 ต่อรอบ

ทางตรวจที่สองใช้ house edge ไม้ที่ $k+1$ เกิดขึ้นเมื่อแพ้มาก่อน $k$ ไม้ (โอกาส $q^k$) และวาง $b\,2^k$ ผลรวมเป็นอนุกรมเรขาคณิตอัตราส่วน $2q$ ตัวหารคือ $2q-1=38/37-1=1/37$ จึงกลายเป็นการคูณด้วย 37 ได้ยอดเงินที่วางเฉลี่ยราว \$10,037 ต่อรอบ

ทุกดอลลาร์ที่วางเสียเฉลี่ย $q-p=19/37-18/37=1/37\approx2.70\%$ นี่คือ house edge ขาดทุนเฉลี่ยจึงเป็น turnover หารด้วย 37 ได้ \$271.27 ตรงกับวิธีแรก ระบบทบไม่ได้หลบ house edge มันแค่ทำให้วางเงินรวมมากขึ้นราว 10 เท่าของเดิมพันฐาน จึงเสียมากขึ้นตาม

ในเกมนี้ ระหว่างที่ยังเดิมพันอยู่ ค่าเฉลี่ยของไม้ถัดไปต่ำกว่าค่าตอนนี้ คือ $\mathbb E_n[W_{n+1}]\lt W_n$ กระบวนการแบบนี้เรียกว่า supermartingale หมายถึงกระบวนการที่โดยเฉลี่ยไหลลง (มี drift ลง)

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ใช้อัตราชนะวัดว่ากลยุทธ์ดีไหม: อัตราชนะ 99.80% ของระบบทบฟังดูดีกว่า 50% ของการวาง \$1,000 ไม้เดียวแล้วหยุด แต่ทั้งสองแบบมีค่าเฉลี่ยศูนย์เท่ากัน ไม้เดียวได้ $\tfrac12(1{,}000)-\tfrac12(1{,}000)=0$ ระบบทบได้ $\tfrac{511}{512}(1{,}000)-\tfrac1{512}(511{,}000)=0$ ต่างกันแค่รูปร่าง ระบบทบแลกกำไรเล็ก ๆ บ่อย ๆ กับขาดทุน 511 เท่าของกำไรในบางรอบ จึงต้องดูขนาดขาดทุนต่อเหตุการณ์ด้วยทุกครั้ง

ใช้ VaR อย่างเดียวคุมความเสี่ยง: VaR 99% (Value at Risk) ตอบคำถามว่า ใน 1% ของรอบที่แย่ที่สุด ผลเริ่มต้นที่เท่าไร บันไดพังมีโอกาส 0.195% ซึ่งน้อยกว่า 1% ผลที่ขอบ 1% จึงยังเป็นรอบที่ชนะ VaR 99% รายงาน “กำไร \$1,000” ราวกับไม่มีความเสี่ยงเลย

expected shortfall 99% แก้ปัญหานี้ เพราะมันเฉลี่ย 1% ที่แย่ที่สุดทั้งก้อน ก้อนนี้มีรอบบันไดพัง $1/512\approx0.1953\%$ และรอบที่ชนะอีก $1\%-0.1953\%=0.8047\%$:

\[\begin{aligned}\text{ES}_{99}&=\big[\tfrac1{512}\times(-511{,}000)\\&\qquad+0.008047\times1{,}000\big]/0.01\\&=(-998.05+8.05)/0.01\\&=-99{,}000\end{aligned}\]

ตัวเลขนี้เห็นหาง ขณะที่ VaR 99% ไม่เห็น ดูวิธีคิดเต็มที่ VaR และ expected shortfall

เพิ่มเพดานตามกำไรสะสม: สูตร $(511/512)^R$ ใช้ได้เฉพาะเมื่อเพดานคงที่ ถ้าเอากำไรที่สะสมได้ไปเพิ่มจำนวนไม้ บันไดถัดไปจะลึกขึ้นทุกครั้ง และต้องคำนวณใหม่ทั้งหมด เช่นชนะมา 23 รอบ ทุนกลายเป็น $1{,}000{,}000+23\times1{,}000=\$1{,}023{,}000$ พอดีกับ 10 ไม้ตามขั้นที่ 8 ถ้ารอบถัดไปพังจะเสีย \$1,023,000 ไม่ใช่ \$511,000 ตัวเลข 37.6% ที่คิดจากเพดานเก้าไม้จึงใช้ไม่ได้อีก ผลมักแย่กว่าเดิม เพราะขาดทุนเมื่อพังโตตามกำไรที่สะสมมา

ลืมเพดานเดิมพันของคู่ค้า: คาสิโนจำกัดเดิมพันสูงสุดต่อไม้ ในตลาด ขนาดที่ซื้อขายได้ถูกจำกัดด้วยสภาพคล่อง (มีคนพร้อมซื้อขายด้วยมากแค่ไหน) และ margin (เงินประกันที่ต้องวางไว้กับโบรกเกอร์) สมมติเพดานคือ \$100,000 ต่อไม้ เดิมพันไม้ที่ $k$ คือ $1{,}000\times2^{k-1}$ ไม้ที่ 7 วาง $1{,}000\times2^6=\$64{,}000$ ยังผ่าน แต่ไม้ที่ 8 ต้องวาง $1{,}000\times2^7=\$128{,}000$ ซึ่งเกินเพดาน บันไดจึงพังที่ไม้ที่ 8 ทบได้แค่ 7 ไม้ ไม่ใช่ 9 ไม้ ไม่ว่าทุนจะมากแค่ไหน

ใช้ทำอะไรบนโต๊ะจริง

ไม่มีโต๊ะเทรดไหนเล่นรูเล็ต แต่รูปร่าง “กำไรเล็กบ่อย ขาดทุนใหญ่นาน ๆ ครั้ง” พบในกลยุทธ์จริงหลายแบบ เช่น

  • ขาย put option ที่ strike ห่างจากราคาปัจจุบันมาก put option คือสัญญาที่ให้สิทธิ์ผู้ซื้อขายหุ้นให้เราในราคาที่ตกลงไว้ (strike) คนขายได้ค่าสัญญาเล็ก ๆ ทุกครั้ง แต่ถ้าตลาดดิ่งแรง ต้องรับซื้อหุ้นแพงกว่าราคาตลาดมาก
  • ขายความผันผวน ได้เงินเมื่อตลาดสงบ เสียหนักเมื่อตลาดปั่นป่วน
  • carry trade กู้เงินสกุลที่ดอกเบี้ยต่ำไปฝากสกุลที่ดอกเบี้ยสูง เก็บส่วนต่างทุกวัน แต่ถ้าค่าเงินพลิกแรงจะขาดทุนก้อนใหญ่
  • ถัวเฉลี่ยขาลง คือซื้อเพิ่มทุกครั้งที่ราคาตกและขาดทุน ซึ่งคล้ายระบบทบโดยตรง

ไม่ได้แปลว่าทุกกลยุทธ์เหล่านี้คือระบบทบ หรือมีค่าเฉลี่ยศูนย์ แต่แปลว่า track record ที่ราบเรียบบอกเรื่องหางได้น้อย จึงต้องประเมินด้วยเครื่องมือที่มองเห็นหาง แทนอัตราชนะ ได้แก่ expected shortfall, drawdown สูงสุด คือระยะที่พอร์ตร่วงจากจุดสูงสุดลงถึงจุดต่ำสุด (drawdown และการลดความเสี่ยง) และ stress test คือการจำลองว่าพอร์ตเสียเท่าไรถ้าเกิดเหตุร้ายแรงที่กำหนดไว้

วงเงินขาดทุนสูงสุด และเพดานขนาดสถานะ (ถือของได้มากที่สุดเท่าไร) ที่ฝ่ายความเสี่ยงตั้งไว้ ก็คือการบังคับให้บันไดมีเพดานตั้งแต่ต้น

โจทย์ตรวจความเข้าใจ

1. ทีมเล็กอีกทีมอยากลองระบบทบแบบเดียวกันในเกมยุติธรรม (ชนะหรือแพ้อย่างละครึ่ง ได้หรือเสียเท่าที่วาง) ตัวเลขของทีมนี้ (สมมติ) คือ

  • ทุนที่ใช้ได้ $B=\$50{,}000$
  • เดิมพันฐาน $b=\$100$

ทีมนี้ทบได้กี่ไม้ ถ้าบันไดพังจะเสียเท่าไร โอกาสพังต่อรอบเท่าไร และกำไรเฉลี่ยกับ SD ต่อรอบเป็นเท่าไร

เฉลย

ใช้เงื่อนไข $L_N\le B$ จากขั้นที่ 2 แล้วใช้สูตรของขั้นที่ 4:

\[\begin{aligned}2^N&\le1+50{,}000/100=501\\2^8=256&\le501\lt512=2^9\\N&=8\\L_8&=100\times(2^8-1)=\$25{,}500\\P(\text{failure})&=2^{-8}=1/256\approx0.39\%\\\mathbb E[W]&=\tfrac{255}{256}(100)-\tfrac1{256}(25{,}500)\\&=99.61-99.61=0\\\operatorname{SD}(W)&=100\sqrt{2^8-1}=100\sqrt{255}\\&\approx\$1{,}596.87\end{aligned}\]

หลังแพ้ 8 ไม้ ทุนเหลือ $50{,}000-25{,}500=\$24{,}500$ แต่ไม้ที่ 9 ต้องวาง $100\times2^8=\$25{,}600$ จึงวางไม่ได้

2. ทีมเดียวกันใช้นโยบายจากข้อ 1 (ทบได้ 8 ไม้) เล่น 100 รอบ แต่ละรอบไม่เกี่ยวกัน โอกาสที่จะไม่เจอบันไดพังเลยมีเท่าไร และครึ่งชีวิต (จำนวนรอบที่โอกาสรอดเหลือครึ่งหนึ่ง) กี่รอบ

เฉลย

โอกาสรอดหนึ่งรอบคือ $1-1/256=255/256$ ใช้สูตรของขั้นที่ 7:

\[\begin{aligned}\big(\tfrac{255}{256}\big)^{100}&\approx67.6\%\\R_{1/2}&=\frac{\ln0.5}{\ln(255/256)}\approx177.1\end{aligned}\]

ครึ่งชีวิตได้ราวครึ่งหนึ่งของ 354.5 รอบในตัวอย่างหลัก เพราะโอกาสพังต่อรอบเป็นสองเท่า (1/256 เทียบกับ 1/512) สูตรนี้ใช้ได้กับเพดานแปดไม้ที่คงที่เท่านั้น

3. เพื่อนร่วมทีมแย้งว่า “ถ้าทุนไม่จำกัด เวลารอชนะครั้งแรกเฉลี่ยแค่ $\mathbb E[\tau]=2$ ไม้ ซึ่งเป็นค่าจำกัด optional stopping จึงต้องใช้ได้ แปลว่าระบบทบที่ทุนไม่จำกัดมีกำไรเฉลี่ยศูนย์ ไม่ใช่ $b$” เหตุผลนี้ผิดตรงไหน

เฉลย

ผิดตรงที่ $\mathbb E[\tau]$ จำกัดอย่างเดียวไม่พอ รูปของทฤษฎีบทที่ใช้ $\mathbb E[\tau]$ จำกัด ยังต้องการให้แต่ละไม้ขยับได้ไม่เกินค่าคงที่ค่าเดียว แต่ไม้ที่ $k$ ขยับได้ถึง $b\,2^{k-1}$ ซึ่งโตไม่มีขอบเขต รูปอื่นก็ใช้ไม่ได้ เพราะเวลาหยุดไม่มีเพดาน และกำไรระหว่างทางลงไปได้ลึกไม่จำกัด ไม่มีชุดเงื่อนไขไหนครบ ผลคือ $\mathbb E[W_\tau]=b$ ต่างจาก $W_0=0$ ได้จริงบนกระดาษ โดยแลกกับยอดเงินที่วางรวมเฉลี่ยเป็นอนันต์ ตามขั้นที่ 6

คำนวณซ้ำด้วย JavaScript

โค้ดนี้ไม่ได้สุ่ม แต่ไล่คิดโอกาสตรง ๆ ทั้งโอกาสชนะในแต่ละไม้ และโอกาสแพ้ติดกันครบเพดาน จึงไม่ต้องรอให้การสุ่มเจอเหตุการณ์หายากอย่างบันไดพัง ตัวเลขในคอมเมนต์ตรงกับที่หน้านี้คำนวณไว้

เปิดดูโค้ด 
// one cycle of the doubling system: base b, cap N rungs, loss prob q
function cycle(b, N, q) {
  const fail = q ** N, loss = b * (2 ** N - 1);
  const mean = (1 - fail) * b - fail * loss;
  const second = (1 - fail) * b * b + fail * loss * loss;
  let turnover = 0;
  for (let k = 1; k <= N; k++) turnover += q ** (k - 1) * b * 2 ** (k - 1);
  return {fail, loss, mean, sd: Math.sqrt(second - mean * mean), turnover};
}
const N = Math.floor(Math.log2(1 + 1e6 / 1000));   // 9
const fair = cycle(1000, N, 0.5);                   // mean 0, sd 22605.31
const survive = R => (1 - fair.fail) ** R;          // 100 -> 0.822
const half = Math.log(0.5) / Math.log(1 - fair.fail); // 354.54
const ten = cycle(1000, 10, 0.5);                   // loss 1,023,000
const roulette = cycle(1000, 9, 19 / 37);           // mean -271.27
// expected shortfall at 99% of one fair cycle (P&L, negative = loss)
const es99 = (fair.fail * -fair.loss + (0.01 - fair.fail) * 1000) / 0.01;
console.log({N, fair, s100: survive(100), s500: survive(500),
  s2000: survive(2000), half, ten, roulette,
  edgeCheck: roulette.turnover / 37, es99});        // es99 = -99000

สิ่งที่ควรตอบได้หลังอ่าน

  • ชนะครั้งเดียวคืนทุนได้จริง เพราะไม้ที่ $k$ วางมากกว่าเงินที่เสียมารวมอยู่ $b$ พอดี $b\,2^{k-1}-b\,(2^{k-1}-1)=b$ แต่ต้องมีเงินวางทุกไม้ ทุน \$1,000,000 กับเดิมพันฐาน \$1,000 ทบได้แค่ 9 ไม้
  • ในเกมยุติธรรม กำไรของระบบทบเป็น martingale การเลือกขนาดเดิมพันจากอดีตเปลี่ยนรูปร่างของผลได้ แต่สร้าง drift ไม่ได้
  • หนึ่งรอบเก้าไม้ชนะ 99.80% แต่ค่าเฉลี่ยเป็นศูนย์ SD ราว \$22,605 และขาดทุนสูงสุด \$511,000 VaR 99% มองไม่เห็นหางนี้ แต่ expected shortfall 99% เห็น (−\$99,000)
  • Optional stopping ใช้ได้เมื่อเวลาหยุดมีเพดาน หรือเมื่อเงื่อนไขทดแทนครบ ทุนไม่จำกัดได้ $b$ แน่นอนแค่บนกระดาษ เพราะขาด uniform integrability และต้องวางเงินรวมเฉลี่ยเป็นอนันต์
  • เมื่อเจ้ามือได้เปรียบ ระบบทบทำให้วางเงินรวมราว 10 เท่าของเดิมพันฐาน จึงเสียเฉลี่ยราว \$271 ต่อรอบ

หน้าถัดไป โหลของ Pólya เป็นภาพตรงข้าม เป็น martingale ที่มีขอบเขตในตัว คือสัดส่วนอยู่ระหว่าง 0 กับ 1 เสมอ จึงไม่มีโอกาสเล็ก ๆ ที่พาค่าก้อนใหญ่หนีไปไหน มันลู่เข้าค่าหนึ่งได้เสมอ แต่แต่ละโหลลู่เข้าคนละค่า
