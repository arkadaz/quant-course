9.1 Three Defining Properties of Brownian Motion

กติกาสามข้อของเส้นทางสุ่ม บังคับให้ความเสี่ยงโตตามรากของเวลา ไม่ใช่ตามเวลา และบังคับให้การขยับเป็นรูประฆัง

โต๊ะเทรด (ทีมที่ซื้อขายในตลาด) มีระบบที่ต้องส่งเสียงเตือนเมื่อราคา SPY ขยับแรงผิดปกติ SPY คือกองทุนที่ซื้อขายเหมือนหุ้น และวิ่งตามดัชนี S&P 500 ของหุ้นใหญ่ 500 ตัวในสหรัฐ วิธีที่ใช้กันคือตั้ง “กรอบเตือน 95%”

กรอบเตือนทำงานแบบนี้ ทุกครั้งที่เริ่มนับ 30 นาทีใหม่ ระบบตั้งกรอบราคาโดยให้ราคาตอนเริ่มอยู่ตรงกลาง พอครบ 30 นาที ระบบดูราคาตอนจบ ถ้าราคาตอนจบอยู่นอกกรอบ ระบบก็เตือน กรอบที่กว้างพอดีควรครอบราคาตอนจบไว้ได้ 95 ครั้งจาก 100 ครั้ง จึงเรียกว่ากรอบ 95% คำถามคือ กรอบนี้ควรกว้างข้างละกี่ดอลลาร์

ของที่รู้ (โต๊ะใช้แบบจำลองที่ให้ราคาขยับแบบสุ่ม โดยมีตัวเลขสองตัวคุมทิศทางกับขนาดการแกว่ง):

  • ราคาวันนี้ $S_0=\$520$
  • ผลตอบแทน คือการเปลี่ยนราคาคิดเป็นสัดส่วนของราคาตอนเริ่ม เช่น ราคาขึ้น \$5.2 จาก \$520 ได้ผลตอบแทน $5.2/520=1\%$
  • drift $\mu=8\%$ ต่อปี (ตัวเลขสมมติของโต๊ะ) คือผลตอบแทนเฉลี่ยต่อปี ราคาจึงคาดว่าจะโตขึ้นเฉลี่ยปีละ 8%
  • ความผันผวน $\sigma=18\%$ ต่อปี (ตัวเลขสมมติของโต๊ะ) คือขนาดการแกว่งของผลตอบแทนในหนึ่งปี วัดเป็น SD (standard deviation คือขนาดการแกว่งตามปกติรอบค่าเฉลี่ย ดูvariance และ SD)
  • ความผันผวนเป็นดอลลาร์ $\sigma S_0=0.18\times520=\$93.6$ ต่อปี คือ SD ของการเปลี่ยนราคาในหนึ่งปี
  • ปีหนึ่งมี 252 วันทำการ และวันหนึ่งตลาดเปิด 390 นาที (6.5 ชั่วโมง) ปีหนึ่งจึงมี $252\times390=98{,}280$ นาทีซื้อขาย
  • 30 นาทีคิดเป็นปีได้ $\Delta t=30/98{,}280\approx0.00030525$ ปี

พนักงานใหม่คิดว่า 30 นาทีเป็นเศษเสี้ยวเล็ก ๆ ของปี การแกว่งก็น่าจะเป็นเศษเสี้ยวเดียวกัน เขาจึงคูณ $\sigma S_0$ ด้วย $\Delta t$ ตรง ๆ ได้ SD ของ 30 นาที แล้วตั้งกรอบกว้างข้างละ $B$ ดอลลาร์ เท่ากับ 1.96 SD

ตัวเลข 1.96 มาจากตาราง Normal ถ้าการขยับมีรูปทรงเป็นระฆัง Normal (ค่ากลาง ๆ เกิดบ่อย ค่าที่ไกลออกไปเกิดน้อยลงเร็วมาก) ช่วงค่าเฉลี่ย ±1.96 SD จะครอบไว้ 95% พอดี

\[\begin{aligned}\text{SD}&=\sigma S_0\times\Delta t\\&=93.6\times0.00030525\approx\$0.0286,\\B&=1.96\times0.0286\approx\$0.056.\end{aligned}\]

กรอบ ±\$0.056 นี้ใช้ได้ไหม?

ลองตอบก่อนเปิดเฉลย

ใช้ไม่ได้ เพราะ SD ไม่ได้โตตามเวลา แต่โตตามรากของเวลา (หน้านี้จะพิสูจน์ว่าทำไม) SD ที่ถูกจึงเป็น

\[\begin{aligned}\sqrt{\Delta t}&=\sqrt{0.00030525}\approx0.01747,\\\text{SD}&=\sigma S_0\times\sqrt{\Delta t}\\&=93.6\times0.01747\approx\$1.635.\end{aligned}\]

SD ที่ถูกใหญ่กว่าของพนักงานใหม่กี่เท่า หารกันดู ตัว $\sigma S_0$ อยู่ทั้งบนและล่างจึงตัดกันหมด

\[\begin{aligned}\frac{\sigma S_0\sqrt{\Delta t}}{\sigma S_0\,\Delta t}&=\frac{1}{\sqrt{\Delta t}}\\&=\frac{1}{0.01747}\approx57.\end{aligned}\]

SD จริงจึงใหญ่กว่าที่เขาคิดราว 57 เท่า เพราะ $\Delta t$ เล็กมาก และรากของตัวเลขที่เล็กมากใหญ่กว่าตัวมันเองหลายเท่า

ขั้นที่ 9 (กรอบ 95% และราคาของความผิดแบบพนักงานใหม่) จะคำนวณกรอบที่ถูกให้ดูทีละขั้น ได้ −\$3.19 ถึง +\$3.22 รอบราคาเดิม หรือราคา \$516.81 ถึง \$523.22

ขั้นที่ 9 เดียวกันจะคำนวณด้วยว่ากรอบ ±\$0.056 แคบแค่ไหน ราคาตอนจบ 30 นาทีจะหลุดกรอบนี้ราว 97 ครั้งจาก 100 ครั้ง แทนที่จะเป็น 5 ครั้ง เสียงเตือนจะดังทั้งวันจนไม่มีใครฟัง

ภาพรวมก่อนลงสูตร

ราคาหุ้นระหว่างวันขยับขึ้นลงตลอดเวลา และเดาล่วงหน้าไม่ได้ Brownian motion คือแบบจำลองทางคณิตศาสตร์ของเส้นทางแบบนี้ เส้นทางสุ่มไม่มีสูตรให้เขียน เราจึงไม่นิยามตัวเส้น แต่ตั้งกติกาสามข้อให้ “การขยับ” ของมันแทน การขยับในช่วงหนึ่งคือค่าตอนปลายช่วงลบค่าตอนต้นช่วง เช่นราคาตอน 10:30 ลบราคาตอน 10:00

  1. การขยับของสองช่วงที่ไม่ทับกันไม่เกี่ยวกันเลย รู้ว่าช่วงเช้าขึ้นหรือลง ก็เดาช่วงบ่ายได้ไม่ดีขึ้น
  2. การขยับในช่วงที่ยาว $s$ ขึ้นกับความยาว $s$ อย่างเดียว ไม่ขึ้นกับว่าช่วงเริ่มเมื่อไร มันมีรูปทรงเป็นระฆัง Normal และค่าเฉลี่ยกับ variance ของมันเป็นสัดส่วนกับ $s$ (variance คือ SD ยกกำลังสอง ดูvariance และ SD)
  3. เส้นทางห้ามกระโดด คือวาดได้โดยไม่ยกปากกา

ทำไมต้องรู้ทีละข้อ เพราะกฎที่โต๊ะเทรดใช้ทุกวัน คือ “SD โตตามรากของเวลา” ไม่ได้มีใครตั้งขึ้นมาเอง มันออกมาจากกติกาเหล่านี้โดยตรง หน้านี้จะไล่ทีละขั้นว่า ทำไม variance ของหลายช่วงบวกกันได้ ทำไมมันต้องโตเป็นเส้นตรงกับเวลา ทำไมรูปทรงต้องเป็นระฆัง และทำไมกติกาห้ามกระโดดต้องเขียนแยก จากนั้นจะกลับมาตั้งกรอบเตือน 30 นาทีของ SPY ด้วยตัวเลขจริง

รูปด้านล่างคือภาพรวมของทั้งหน้า มีเส้นทางหนึ่งเส้นที่วาดโดยไม่ยกปากกา และมีสองช่วงเวลา (เรียกว่าหน้าต่าง) ที่ไม่ทับกัน ลูกศรในแต่ละหน้าต่างคือการขยับของหน้าต่างนั้น กติกาทั้งสามข้อพูดถึงลูกศรพวกนี้ ไม่ได้พูดถึงว่าเส้นอยู่สูงหรือต่ำ

ศัพท์ที่ใช้ในหัวข้อนี้
Brownian motion
เส้นทางสุ่มที่เดินในเวลาต่อเนื่อง และทำตามกติกาสามข้อของหน้านี้ ทั้งเล่มใช้มันเป็นแหล่งความสุ่มพื้นฐานของแบบจำลองราคา ประวัติสั้น ๆ: Bachelier ใช้มันกับราคาหุ้นในปารีสปี 1900, Einstein ใช้อธิบายอนุภาคที่สั่นในน้ำปี 1905 และ Wiener พิสูจน์ในทศวรรษ 1920 ว่าวัตถุแบบนี้มีอยู่จริงทางคณิตศาสตร์
Increment (การขยับ)
ค่าที่ปลายช่วงลบค่าที่ต้นช่วง เช่น $X_{t+s}-X_t$ บอกว่าช่วงนั้นขยับไปเท่าไร โดยไม่สนว่าก่อนเข้าช่วงเส้นอยู่ที่ระดับไหน
Independent increments
การขยับของช่วงที่ไม่ทับกันไม่บอกอะไรเกี่ยวกันเลย นี่คือกติกาข้อ 1 และเป็นเหตุผลที่ variance ของหลายช่วงบวกกันตรง ๆ ได้
Stationary increments
รูปทรงโอกาส (distribution) ของการขยับขึ้นกับความยาวช่วงอย่างเดียว ไม่ขึ้นกับว่าช่วงเริ่มเมื่อไร ครึ่งชั่วโมงตอนเช้ากับครึ่งชั่วโมงตอนบ่ายจึงหน้าตาเหมือนกัน
Drift และความผันผวน
drift $\mu$ คือค่าเฉลี่ยของการขยับในหนึ่งหน่วยเวลา ความผันผวน $\sigma$ คือ SD ของการขยับในหนึ่งหน่วยเวลา ช่วงที่ยาวไม่เท่าหนึ่งหน่วยต้องคูณ $\sigma$ ด้วยรากของความยาว (หน้านี้จะพิสูจน์ว่าทำไม) และเพราะหน้านี้ใช้ปีเป็นหน่วย จึงต้องแปลงเวลาเป็นปีก่อนแทนค่าเสมอ
Excess kurtosis
ตัวเลขที่บอกว่าหางของ distribution หนาแค่ไหน หางหนาคือค่าสุดโต่งเกิดบ่อยกว่า Normal สำหรับตัวแปรที่ค่าเฉลี่ยเป็นศูนย์ $K=\mathbb E[X^4]/\operatorname{Var}(X)^2-3$ Normal ได้ 0, uniform (ทุกค่าในช่วงมีโอกาสเท่ากัน) ได้ −1.2 และ distribution หางหนาได้ค่าบวก หน้านี้ใช้มันตอบว่าทำไมการขยับต้องเป็นระฆัง
Poisson process
ตัวนับเหตุการณ์ที่เกิดแบบสุ่ม เช่นจำนวนคำสั่งซื้อที่เข้ามา โดยเกิดเฉลี่ย $\lambda$ ครั้งต่อหน่วยเวลา มันเพิ่มขึ้นทีละหนึ่งเป็นขั้นบันได หน้านี้ใช้มันเป็นตัวอย่างของเส้นทางที่กระโดด

ขั้นที่ 1 — กติกาสามข้อที่นิยาม Brownian motion

ก่อนคำนวณอะไร ต้องเขียนกติกาสามข้อให้เป็นสัญลักษณ์ที่ชัดก่อน สิ่งที่อยู่ข้างล่างเป็นนิยาม คือข้อตกลงว่าเส้นทางที่เราต้องการมีนิสัยแบบนี้ ไม่ใช่สิ่งที่พิสูจน์ ให้ $X_t$ คือค่าของเส้นทางที่เวลา $t$ เลือกจุดเวลาเรียงกัน $t_0,t_1,\dots,t_n$ กี่จุดก็ได้ แล้วเรียกการขยับระหว่างจุดที่ติดกันว่า $\Delta_k$ ส่วน $P(\cdot)$ คือโอกาส และ $a_1,\dots,a_n$ คือตัวเลขใด ๆ

\[ \begin{aligned} &0\le t_0\lt t_1\lt\cdots\lt t_n,\\ &\Delta_k:=X_{t_k}-X_{t_{k-1}},\\ (1)\ \ &P(\Delta_1\le a_1,\dots,\Delta_n\le a_n)\\ &\quad=P(\Delta_1\le a_1)\cdots P(\Delta_n\le a_n),\\ (2)\ \ &X_{t+s}-X_t\sim\mathcal N(\mu s,\ \sigma^2 s),\\ (3)\ \ &\lim_{h\to0}X_{t+h}=X_t. \end{aligned} \]

ข้อ 1 คือความเป็นอิสระ โอกาสที่ทุกช่วงจะออกมาตามที่กำหนดพร้อมกัน เท่ากับโอกาสของแต่ละช่วงคูณกัน นี่คือนิยามของความเป็นอิสระที่เขียนด้วย CDF (CDF คือโอกาสที่ค่าจะไม่เกินตัวเลขที่กำหนด) ในภาษาคน เห็นช่วงเช้าแล้วก็ไม่ได้รู้อะไรเพิ่มเกี่ยวกับช่วงบ่าย

ข้อ 2 บอกสองเรื่อง เรื่องแรก การขยับขึ้นกับความยาวช่วง $s$ อย่างเดียว ไม่สนว่าช่วงเริ่มที่เวลา $t$ เท่าไร เรื่องที่สอง การขยับเป็น Normal ที่มีค่าเฉลี่ย $\mu s$ และ variance $\sigma^2 s$ (เครื่องหมาย $\sim$ อ่านว่า “มี distribution แบบ”) ข้อ 3 บอกว่าเมื่อช่วงสั้นลงเข้าหาศูนย์ ค่าของเส้นทางต้องเข้าหาค่าเดิม แปลว่าเส้นทางห้ามกระโดด เส้นทางที่ผ่านทั้งสามข้อเรียกว่า Brownian motion ที่มี drift $\mu$ และความผันผวน $\sigma$

ข้อ 2 ดูเหมือนเลือกมาตามใจ ทำไมต้องโตตาม $s$ และทำไมต้อง Normal สามขั้นถัดไปจะแสดงว่าทั้งสองอย่างถูกบังคับออกมาจากข้อ 1 จากการที่การขยับไม่ขึ้นกับเวลาเริ่ม และจากข้อ 3 กรณีพิเศษ $\mu=0$, $\sigma=1$ และเริ่มที่ 0 เรียกว่า standard Brownian motion เรียกมันว่า $W_t$ กรณีอื่นทุกกรณีได้จาก $W_t$ โดยยืดด้วย $\sigma$ แล้วเลื่อนด้วย $X_0+\mu t$ คือ $X_t=X_0+\mu t+\sigma W_t$

ขั้นที่ 2 — ช่วงยาวคือผลรวมของท่อนสั้น และ variance บวกกันได้

คำถามแรก: ถ้าช่วงเวลายาวขึ้น ความไม่แน่นอนสะสมขึ้นอย่างไร วิธีตอบคือหั่นช่วงยาว $s$ ออกเป็น $n$ ท่อนเท่า ๆ กัน ให้ $\Delta_i$ คือการขยับของท่อนที่ $i$ แล้วดูว่ากติกาข้อ 1 ทำอะไรกับผลรวมของท่อนเหล่านี้

\[ \begin{aligned} \Delta_i&:=X_{is/n}-X_{(i-1)s/n},\\ X_s-X_0&=\Delta_1+\Delta_2+\cdots+\Delta_n,\\ \operatorname{Var}(\Delta_1+\Delta_2)&=\operatorname{Var}\Delta_1+\operatorname{Var}\Delta_2\\ &\quad+2\operatorname{Cov}(\Delta_1,\Delta_2),\\ \operatorname{Cov}(\Delta_1,\Delta_2)&=0,\\ \operatorname{Var}(X_s-X_0)&=\sum_{i=1}^{n}\operatorname{Var}(\Delta_i). \end{aligned} \]

การขยับทั้งช่วงเท่ากับผลรวมของการขยับทุกท่อนพอดี ไม่ใช่การประมาณ เพราะพอบวกท่อนที่ติดกัน ค่ากลางทางทุกตัวหักกันหมด เหลือแค่ค่าปลายลบค่าต้น

จังหวะสำคัญคือ covariance เป็นศูนย์ variance ของผลรวมสองตัวมีพจน์ไขว้ $2\operatorname{Cov}$ ติดมาเสมอ แต่ตัวแปรที่อิสระกันไม่มี covariance (ผลของความเป็นอิสระ) กติกาข้อ 1 จึงลบพจน์ไขว้ทุกคู่ทิ้ง variance ของผลรวมเลยเท่ากับผลรวมของ variance ถ้าท่อนที่ติดกันมี correlation พจน์ไขว้จะค้างอยู่ และทุกอย่างต่อจากนี้จะผิด

สิ่งที่บวกกันได้คือ variance ไม่ใช่ SD ภาพที่ช่วยจำคือสามเหลี่ยมมุมฉาก การขยับสองช่วงที่อิสระกันเหมือนสองด้านที่ตั้งฉากกัน (correlation คือ cosine ของมุมระหว่างสองตัวแปร ตามinner product และมุม) SD ของผลรวมจึงเป็นด้านตรงข้ามมุมฉาก ตัวอย่างเช่น SPY ในโจทย์เปิดเรื่อง การเปลี่ยนราคาใน 30 นาทีมี SD \$1.6353 (ขั้นที่ 8 จะคำนวณตัวเลขนี้ให้ดู) สองช่วง 30 นาทีที่ติดกันรวมเป็นหนึ่งชั่วโมง จึงมี SD

\[\begin{aligned}\text{SD}_{1\,\text{hr}}&=\sqrt{1.6353^2+1.6353^2}\\&=\sqrt{5.348}\approx\$2.313,\end{aligned}\]

ไม่ใช่ $1.6353+1.6353\approx\$3.27$ ที่ได้จากการบวก SD ตรง ๆ

ขั้นที่ 3 — ทำไมค่าเฉลี่ยและ variance ต้องเป็นเส้นตรงกับเวลา

ขั้นที่แล้วบอกว่า variance ของท่อนต่าง ๆ บวกกันได้ แต่ยังไม่ได้บอกว่าแต่ละท่อนมี variance เท่าไร ขั้นนี้ใช้ส่วนแรกของกติกาข้อ 2 เป็นหลัก คือการขยับไม่ขึ้นกับเวลาเริ่ม (ยังไม่ใช้ส่วนที่บอกว่าเป็น Normal) ให้ $m(s)$ คือค่าเฉลี่ย และ $v(s)$ คือ variance ของการขยับในช่วงยาว $s$ แล้วดูว่าสองฟังก์ชันนี้ถูกบังคับให้มีรูปอะไร

\[ \begin{aligned} v(s)&:=\operatorname{Var}(X_{t+s}-X_t),\\ v(s)&=n\,v(s/n),\\ \frac{v(s)}{s}&=\frac{v(s/n)}{s/n},\\ v(1)&=n\,v(1/n),\\ v(k/n)&=k\,v(1/n)=\frac{k}{n}\,v(1),\\ v(s)&=\sigma^2 s,\qquad\sigma^2:=v(1),\\ m(s)&=n\,m(s/n)\ \Rightarrow\ m(s)=\mu s. \end{aligned} \]

ความคิดหลักคือ หั่นช่วงยาว $s$ เป็น $n$ ท่อนเท่า ๆ กัน ทุกท่อนยาว $s/n$ เท่ากัน และเพราะ variance ไม่สนว่าท่อนเริ่มเมื่อไร ทุกท่อนจึงมี variance $v(s/n)$ เท่ากันหมด ผลรวมจากขั้นที่แล้วจึงเท่ากับ $n\,v(s/n)$ พอหารด้วย $s$ ทั้งสองข้าง จะเห็นว่า variance ต่อหนึ่งหน่วยเวลาของช่วงยาว เท่ากับของท่อนสั้น ไม่ว่าจะหั่นกี่ท่อน

ใช้กฎเดียวกันกับช่วงหนึ่งปี ($s=1$) หั่นเป็น $n$ ท่อน ได้ $v(1)=n\,v(1/n)$ ต่อไปดูช่วงยาว $k/n$ ปี ซึ่งประกอบจาก $k$ ท่อนที่ยาว $1/n$ ปี จึงได้ $k\,v(1/n)$ แล้วแทน $v(1/n)=v(1)/n$ จากแถวก่อนหน้า ผลคือ $v$ เป็นสัดส่วนกับเวลาที่ทุกเวลาซึ่งเป็นเศษส่วน เวลาที่ไม่ใช่เศษส่วน (เช่น $\sqrt2$ ปี) ถูกบีบด้วยเศษส่วนที่อยู่ใกล้ ๆ ทั้งสองข้าง เพราะช่วงที่ยาวกว่ามี variance ไม่น้อยกว่า: $v(s+\epsilon)=v(s)+v(\epsilon)\ge v(s)$ เราตั้งชื่อ variance ของหนึ่งปีว่า $\sigma^2$

ค่าเฉลี่ยใช้การหั่นแบบเดียวกัน และง่ายกว่า เพราะค่าเฉลี่ยของผลรวมคือผลรวมของค่าเฉลี่ยเสมอ ไม่ต้องใช้ความเป็นอิสระเลย จึงได้ $m(s)=\mu s$ ทุกเวลาที่เป็นเศษส่วน

แต่ข้อบีบใช้กับค่าเฉลี่ยไม่ได้ เพราะช่วงที่ยาวกว่าไม่จำเป็นต้องมีค่าเฉลี่ยมากกว่า (drift ติดลบก็ได้) ต้องใช้เหตุผลอื่นแทน คือช่วงสั้นมาก $\epsilon$ แทบไม่มีเวลาให้ขยับ เพราะเส้นทางไม่กระโดดตามกติกาข้อ 3 $m(\epsilon)$ จึงเข้าหาศูนย์ ดังนั้น $m(s+\epsilon)=m(s)+m(\epsilon)$ เข้าหา $m(s)$ แปลว่า $m$ ไม่กระโดด และฟังก์ชันที่ไม่กระโดดซึ่งเท่ากับ $\mu s$ ทุกเศษส่วน ต้องเท่ากับ $\mu s$ ทุกเวลา (หน้านี้ข้ามรายละเอียดทางเทคนิคของขั้นนี้)

นี่คือที่มาของ $\mathcal N(\mu s,\sigma^2 s)$ ในกติกาข้อ 2 ทั้ง drift และ variance ต้องเป็น “อัตราต่อหน่วยเวลา” คูณความยาวช่วง ไม่มีใครเลือก มันเป็นทางเดียวที่เข้ากับกติกา

ขั้นที่ 4 — ถอดรากกลับมาเป็น SD: ที่มาของกฎรากที่สอง

variance มีหน่วยยกกำลังสอง เช่นดอลลาร์ยกกำลังสอง ซึ่งเอาไปคุยกับใครก็ไม่มีใครนึกภาพออก จึงต้องถอดรากกลับเป็น SD ซึ่งมีหน่วยเดียวกับสิ่งที่วัด (variance และ SD) การถอดรากนี่เองที่ทำให้ SD โตช้ากว่าเวลา ในขณะที่ค่าเฉลี่ย (drift) โตเท่าเวลา

\[ \begin{aligned} \operatorname{SD}(s)&=\sqrt{v(s)}=\sigma\sqrt s,\\ \frac{\operatorname{SD}(4s)}{\operatorname{SD}(s)}&=\sqrt4=2,\\ \frac{\operatorname{SD}(13s)}{\operatorname{SD}(s)}&=\sqrt{13}\approx3.606,\\ \frac{\operatorname{SD}(s)}{\sigma s}&=\frac{1}{\sqrt s}. \end{aligned} \]

ยืดเวลาสี่เท่า SD โตแค่สองเท่า เพราะ $\sqrt4=2$ ถ้าเริ่มจาก 30 นาที ช่วง 2 ชั่วโมงยาว $120/30=4$ เท่า จึงมี SD เป็นสองเท่า ทั้งวันทำการ 390 นาทียาว $390/30=13$ เท่า จึงมี SD เป็น $\sqrt{13}\approx3.606$ เท่า

อัตราส่วนสุดท้ายคือกับดักของโจทย์เปิดเรื่อง ถ้าคิดว่า SD เป็นสัดส่วนกับเวลาเหมือน drift จะได้ $\sigma s$ แทน $\sigma\sqrt s$ ซึ่งเล็กกว่าของจริง $1/\sqrt s$ เท่า เมื่อ $s$ น้อยกว่า 1 ปี ค่า $1/\sqrt s$ จะเกิน 1 และช่วงยิ่งสั้น ความผิดยิ่งใหญ่ 30 นาทียาว 0.00030525 ปี ความผิดจึงเป็น $1/\sqrt{0.00030525}=1/0.01747\approx57$ เท่า

สูตรนี้ตอบเรื่องหน่วยของ $\sigma$ ด้วย ตลาดพูดว่า “ความผันผวน 18% ต่อปี” จนเป็นนิสัย เพราะ 18% คือ SD ของช่วงหนึ่งปีพอดี: $\sigma\sqrt1=\sigma$

แต่ SD ของช่วงยาว $s$ ปีคือ $\sigma\sqrt s$ และ $\sqrt s$ มีหน่วยเป็นรากของปี ส่วน SD ของผลตอบแทนเป็นสัดส่วนเปล่า ๆ ไม่มีหน่วย ให้ $[\sigma]$ แทนหน่วยของ $\sigma$ หน่วยสองข้างของ $\text{SD}=\sigma\sqrt s$ ต้องตรงกัน

\[\begin{aligned}{[\sigma]}\times\sqrt{\text{yr}}&=1,\\{[\sigma]}&=1/\sqrt{\text{yr}}.\end{aligned}\]

หน่วยจริงของ $\sigma$ จึงเป็น “ต่อรากของปี” ต่อจากนี้หน้านี้จะเขียนหน่วยของ $\sigma$ และ $\sigma S_0$ แบบนี้ เช่น $\sigma S_0=\$93.6$ ต่อรากของปี

ขั้นที่ 5 — ทำไมต้องเป็นระฆัง: ลองใช้รูปทรงอื่นแล้วดูว่าพังตรงไหน

ขั้นที่แล้วได้ค่าเฉลี่ยกับ variance แล้ว แต่ยังไม่ได้บอกว่ารูปทรงต้องเป็นระฆัง คำถามคือ ทำไมกติกาข้อ 2 ต้องใช้ Normal ถ้าการขยับทุก 30 นาทีเป็น uniform (ทุกค่าในช่วงมีโอกาสเท่ากัน) จะผิดตรงไหน วิธีตรวจคือดูว่ารูปทรงของผลรวมเปลี่ยนไปอย่างไรเมื่อบวกท่อนที่อิสระกัน

เราวัดรูปทรงด้วย excess kurtosis $K$ ซึ่งบอกว่าหางหนาแค่ไหน (Normal ได้ 0) และใช้ตัวช่วยชื่อ cumulant ตัวที่สี่ $\kappa_4$ คือส่วนที่ $\mathbb E[X^4]$ เกินค่าของ Normal ข้อดีของ $\kappa_4$ คือมันบวกกันได้เหมือน variance ด้านล่างให้ $X$ กับ $Y$ เป็นการขยับของสองท่อนที่อิสระกัน มีค่าเฉลี่ยศูนย์ (ถ้ามี drift ให้หักค่าเฉลี่ยออกก่อน) และมี variance $\sigma_X^2$ กับ $\sigma_Y^2$

\[ \begin{aligned} &\mathbb E[X]=\mathbb E[Y]=0,\ \ X,Y\ \text{independent},\\ \mathbb E[(X+Y)^4]&=\mathbb E[X^4]+6\sigma_X^2\sigma_Y^2+\mathbb E[Y^4],\\ 3\operatorname{Var}(X+Y)^2&=3\sigma_X^4+6\sigma_X^2\sigma_Y^2+3\sigma_Y^4,\\ \kappa_4(X)&:=\mathbb E[X^4]-3\sigma_X^4,\\ \kappa_4(X+Y)&=\kappa_4(X)+\kappa_4(Y),\\ K&=\kappa_4/\sigma^4,\\ K_{\text{sum}}&=\frac{n\,\kappa_4}{(n\sigma^2)^2}=\frac{K_{\text{piece}}}{n}. \end{aligned} \]

กระจาย $(X+Y)^4$ ได้ห้าพจน์ สองพจน์ที่มีกำลังคี่ $4\mathbb E[X^3Y]$ กับ $4\mathbb E[XY^3]$ หายไป เพราะความเป็นอิสระแยกมันเป็น $\mathbb E[X^3]\,\mathbb E[Y]=0$ พจน์กลาง $6\mathbb E[X^2Y^2]$ ก็แยกได้ด้วยเหตุผลเดียวกัน เป็น $6\sigma_X^2\sigma_Y^2$ ส่วน $3\operatorname{Var}(X+Y)^2$ คือค่าเฉลี่ยของกำลังสี่ที่ $X+Y$ จะมีถ้ามันเป็น Normal เพราะ Normal มี $\mathbb E[X^4]=3\sigma^4$ เมื่อเอาสองค่านี้ลบกัน พจน์ $6\sigma_X^2\sigma_Y^2$ หักกันพอดี ส่วนที่เหลือคือ $\kappa_4(X)+\kappa_4(Y)$ นี่คือเหตุผลที่ $\kappa_4$ บวกกันได้

excess kurtosis คือ $\kappa_4$ หารด้วย $\sigma^4$ เพราะ $\mathbb E[X^4]/\sigma^4-3=(\mathbb E[X^4]-3\sigma^4)/\sigma^4$ ถ้ารวม $n$ ท่อนที่เหมือนกัน $\kappa_4$ โต $n$ เท่า แต่ variance ยกกำลังสองโต $n^2$ เท่า $K$ ของผลรวมจึงหดลง $n$ เท่า

อ่านกลับด้านก็ได้ ถ้าช่วงยาวมี excess kurtosis เท่ากับ $K$ ท่อนที่สั้นกว่า $n$ เท่าต้องมี excess kurtosis เท่ากับ $nK$

ก่อนลองรูปทรงจริง ต้องรู้อีกเรื่องหนึ่ง: $K$ มีพื้น ต่ำกว่า −2 ไม่ได้ เหตุผลคือ variance ของ $X^2$ ติดลบไม่ได้ และเมื่อค่าเฉลี่ยเป็นศูนย์ $\mathbb E[X^2]=\sigma^2$

\[\begin{aligned}\operatorname{Var}(X^2)&=\mathbb E[X^4]-\sigma^4\ge0,\\\mathbb E[X^4]/\sigma^4&\ge1,\\K=\mathbb E[X^4]/\sigma^4-3&\ge-2.\end{aligned}\]

ทีนี้ลองเลือกรูปทรงแล้วดูว่ารอดไหม แบบแรก สมมติว่าการขยับ 30 นาทีเป็น uniform บนช่วง $[-a,a]$ ซึ่งมี density สูงเท่ากันทั้งช่วงคือ $1/(2a)$ (เพื่อให้พื้นที่รวมเป็น 1) ต้องหา $\mathbb E[X^4]$ กับ $\sigma^2$ ของมันก่อน ด้วยการอินทิเกรตกำลังของ $x$ คูณ density

\[\begin{aligned}\mathbb E[X^4]&=\int_{-a}^{a}\frac{x^4}{2a}\,dx=\frac{a^4}{5},\\\sigma^2&=\int_{-a}^{a}\frac{x^2}{2a}\,dx=\frac{a^2}{3}.\end{aligned}\]

แทนสองค่านี้ในนิยาม $K=\mathbb E[X^4]/\sigma^4-3$ ได้ $K$ ของการขยับ 30 นาที จากนั้นผ่าครึ่ง 30 นาทีเป็นท่อน 15 นาทีสองท่อน ตามกฎข้างบน ท่อนที่สั้นกว่าสองเท่าต้องมี $K$ เป็นสองเท่า

\[ \begin{aligned} K_{30\,\text{min}}&=\frac{a^4/5}{(a^2/3)^2}-3\\ &=\frac95-3=-1.2,\\ K_{15\,\text{min}}&=2\times(-1.2)=-2.4\lt-2. \end{aligned} \]

uniform จึงใช้ไม่ได้ทันที ท่อน 15 นาทีต้องมี $K=-2.4$ ซึ่งต่ำกว่าพื้น −2 และไม่มีตัวแปรไหนทำได้ ค่า $K$ ติดลบทุกค่าพังแบบเดียวกันเมื่อหั่นละเอียดพอ เพราะทุกครั้งที่ผ่าครึ่ง $K$ ถูกคูณสอง

แบบที่สองคือหางหนา คือ $K$ เป็นบวก สมมติว่าการขยับรายวันมี $K=3$ (ตัวเลขสมมติ) วันหนึ่งมี 390 นาทีซื้อขาย การขยับรายวันจึงเป็นผลรวมของท่อน 1 นาที 390 ท่อน ท่อน 1 นาทีต้องมี $K$ เป็น 390 เท่าของรายวัน

\[ \begin{aligned} K_{\text{day}}&=3,\\ K_{1\,\text{min}}&=390\times3=1{,}170. \end{aligned} \]

หางหนารอดทางพีชคณิต เพราะคูณค่าบวกกี่ครั้งก็ไม่ต่ำกว่า −2 แต่ $K=1{,}170$ ของท่อน 1 นาทีหน้าตาเป็นอย่างไร ลองดูการขยับแบบง่ายที่สุดที่หางหนา คือเกือบทุกครั้งไม่ขยับเลย และนาน ๆ ทีโดดก้อนเดียว ให้มันเป็น 0 ด้วยโอกาส $1-p$ และเป็น $+c$ หรือ $-c$ ด้วยโอกาสรวม $p$

\[\begin{aligned}\sigma^2&=p\,c^2,\qquad\mathbb E[X^4]=p\,c^4,\\K&=\frac{p\,c^4}{(p\,c^2)^2}-3=\frac1p-3,\\\frac1p&=1{,}170+3=1{,}173.\end{aligned}\]

ในตัวอย่าง “นิ่งหรือโดด” นี้ $K=1{,}170$ แปลว่าราคาขยับราวหนึ่งนาทีใน 1,173 นาที (ราว $1{,}173/390\approx3$ วันทำการ) ส่วนนาทีอื่นนิ่งสนิท นั่นคือหน้าตาของ Poisson ตัวนับเหตุการณ์ที่ขยับทีละก้อน มันกระโดด และกติกาข้อ 3 ห้ามกระโดด

ที่เหลือรอดคือ $K=0$ ทุกช่วงเวลา ซึ่ง Normal ทำได้พอดี เพราะ Normal มาตรฐาน $Z$ มี $\mathbb E[Z^4]=3$ จึงได้ $K=3-3=0$ (คำนวณ $\mathbb E[Z^4]$ ได้จาก moment generating function) และศูนย์คูณอะไรก็ยังเป็นศูนย์

ข้อนี้ตรวจแค่ค่าเฉลี่ยของกำลังสี่ (โมเมนต์ที่สี่) ทฤษฎีบทเต็มของ Lévy บอกว่า การขยับที่อิสระกัน ไม่ขึ้นกับเวลาเริ่ม และเส้นทางที่ไม่กระโดด บังคับให้การขยับเป็น Normal ทุกช่วง หน้านี้ไม่พิสูจน์ แต่ภาพเดียวกันคุ้นอยู่แล้วจากทฤษฎีบทลิมิตกลาง คือบวกท่อนอิสระมาก ๆ แล้วรูปทรงเดิมถูกลบจนเหลือระฆัง โค้ดท้ายหน้าลองจริงด้วยผลรวมของ uniform 30 ท่อน วัดได้ $K\approx-0.055$ ใกล้กับ $-1.2/30=-0.04$ ที่สูตรทำนาย (ต่างกันเล็กน้อยเพราะเป็นการสุ่ม) และห่างจาก −1.2 ของท่อนเดี่ยวมาก

ขั้นที่ 6 — กติกาข้อ 3: ห้ามกระโดด และทำไมต้องเขียนแยก

ช่วงสั้น $h$ มี SD $\sigma\sqrt h$ ซึ่งหดเข้าหาศูนย์เมื่อ $h$ หดเข้าหาศูนย์ ฟังดูเหมือนห้ามกระโดดอยู่แล้ว ทำไมต้องเขียนกติกาข้อ 3 แยก เพราะมีตัวอย่างค้าน คือ Poisson process ตัวนับเหตุการณ์สุ่ม (เช่นจำนวนคำสั่งซื้อที่เข้ามา) ที่เกิดเฉลี่ย $\lambda$ ครั้งต่อหน่วยเวลา ให้ $N_t$ คือจำนวนเหตุการณ์จนถึงเวลา $t$ ตัวนับนี้ผ่านกติกาข้อ 1 และการขยับของมันก็ไม่ขึ้นกับเวลาเริ่ม แต่มันกระโดด

\[ \begin{aligned} N_{t+h}-N_t&\sim\text{Poisson}(\lambda h),\\ \operatorname{Var}(N_{t+h}-N_t)&=\lambda h\ \to\ 0,\\ Y_t&:=\frac{N_t-\lambda t}{\sqrt\lambda},\\ \operatorname{Var}(Y_t)&=t,\\ \text{jump of }Y&=1/\sqrt\lambda. \end{aligned} \]

Poisson ที่เกิดเฉลี่ย $\lambda h$ ครั้งในช่วง $h$ มี variance เท่ากับค่าเฉลี่ยคือ $\lambda h$ ซึ่งหดเข้าหาศูนย์เมื่อช่วงสั้นลง เหมือน Brownian ทุกประการ แต่ $N$ โดดขึ้นทีละหนึ่งทุกครั้งที่มีเหตุการณ์ เพื่อให้เทียบกับ Brownian มาตรฐานได้ตรง ๆ เราหักค่าเฉลี่ย $\lambda t$ ออกแล้วหารด้วย $\sqrt\lambda$ ได้ $Y_t$ ที่มี variance $\lambda t/\lambda=t$ เท่ากับเวลาพอดี $Y$ จึงเหมือน Brownian มาตรฐานทั้งค่าเฉลี่ย (ศูนย์) และ variance แต่ยังกระโดดทีละ $1/\sqrt\lambda$ ค่าเฉลี่ยกับ variance จึงจับการกระโดดไม่ได้ ต้องมีกติกาข้อ 3 แยกต่างหาก

ข้อ 3 แรงกว่าที่คิดเมื่อวัดเป็นตัวเลข ลองดูเหตุการณ์แบบที่ตลาดเจอได้จริง: ข่าวออกกลางวัน แล้วราคา SPY ข้ามจาก \$519.50 ไปเป็น \$514.20 ภายในหนึ่งวินาที (ตัวเลขสมมติ) ราคาที่ข้ามแบบนี้เรียกว่า gap แบบจำลองมองเหตุการณ์นี้อย่างไร ก่อนอื่นต้องแปลงหนึ่งวินาทีเป็นปี ปีหนึ่งมี 252 วันทำการ วันละ 390 นาที นาทีละ 60 วินาที จึงมี $252\times390\times60=5{,}896{,}800$ วินาทีซื้อขาย ให้ $h$ คือหนึ่งวินาทีในหน่วยปี

\[ \begin{aligned} h&=\frac{1}{5{,}896{,}800}\ \text{yr},\\ \sqrt h&=\frac{1}{\sqrt{5{,}896{,}800}}=\frac{1}{2{,}428.3},\\ \operatorname{SD}_{1\,\text{sec}}&=\sigma S_0\sqrt h=\frac{93.6}{2{,}428.3}\\ &\approx\$0.03854,\\ \text{gap}&=519.50-514.20=\$5.30,\\ \frac{5.30}{0.03854}&\approx137.5. \end{aligned} \]

ในแบบจำลองนี้ SPY แกว่งได้ราว 3.85 เซนต์ต่อวินาที นี่คือ SD ของหนึ่งวินาที gap \$5.30 จึงเท่ากับการขยับ 137.5 SD ในวินาทีเดียว ระฆัง Normal ให้โอกาสแบบนี้เล็กจนนับเป็นศูนย์ได้ในทางปฏิบัติ แบบจำลองจึงไม่ได้แค่บอกว่ามันไม่น่าเกิด มันบอกว่าในทางปฏิบัติไม่มีวันเกิด และถ้าย่อช่วงเวลาลงเป็นศูนย์ กติกาข้อ 3 ห้ามมันตรง ๆ

แต่ตลาดจริงกระโดดบ่อย เช่นตอนบริษัทประกาศงบ หรือตอนตลาดเปิดหลังมีข่าวกลางคืน ข้อ 3 จึงเป็นสมมติฐานที่เสี่ยงที่สุดในสามข้อ และเป็นข้อที่ทำให้ hedge แบบปรับต่อเนื่อง (ถือสินทรัพย์อีกตัวไว้หักล้างความเสี่ยง แล้วปรับจำนวนตลอดเวลา) เป็นไปได้ในทฤษฎี เหตุผลคือ ถ้าราคาไม่กระโดด คนที่ hedge มีเวลาปรับจำนวนเสมอก่อนราคาจะไปไกล แต่ถ้าราคากระโดด ราคาเปลี่ยนไปแล้วก่อนที่ใครจะทันซื้อขาย

ขั้นที่ 7 — แปลง 30 นาทีให้เป็นหน่วยปี

ตอนนี้กลับมาที่โจทย์เปิดเรื่อง drift และความผันผวนของโต๊ะใช้ปีเป็นหน่วยเวลา ส่วนคำถามถามถึง 30 นาที ก่อนแทนค่าในสูตรใด ๆ จึงต้องเปลี่ยน 30 นาทีให้เป็นหน่วยปีก่อน

โจทย์ให้อะไรมาบ้าง:

  • ราคา SPY วันนี้ $S_0=\$520$
  • drift $\mu=8\%$ ต่อปี (ตัวเลขสมมติของโต๊ะ)
  • ความผันผวน $\sigma=18\%$ ต่อรากของปี (ตัวเลขสมมติของโต๊ะ ที่ตลาดเรียกว่า 18% ต่อปี)
  • ช่วงเวลาที่ถาม 30 นาที
  • ตลาดหุ้นสหรัฐเปิด 9:30 ถึง 16:00 เวลานิวยอร์ก คือ 6.5 ชั่วโมง หรือ $6.5\times60=390$ นาทีต่อวัน
  • หนึ่งปีมี 252 วันทำการ ตัวเลขนี้มาจากปี 2024 ซึ่งมีวันจันทร์ถึงศุกร์ 262 วัน ลบวันหยุด 10 วันของ NYSE (ตลาดหลักทรัพย์นิวยอร์ก) ได้ $262-10=252$
\[ \begin{aligned} 252\times390&=98{,}280\ \text{min/yr},\\ \Delta t&=\frac{30}{98{,}280}\approx0.00030525\ \text{yr},\\ \sqrt{\Delta t}&\approx0.0174714. \end{aligned} \]

คำตอบ: 30 นาทีคือ 0.00030525 ปี ตัวหารนับเฉพาะนาทีที่ตลาดเปิด เพราะราคาขยับเฉพาะตอนมีการซื้อขาย นาฬิกาของแบบจำลองจึงหยุดเดินตอนกลางคืน ผลข้างเคียงคือ gap ตอนเปิดตลาด (ราคาเช้านี้ต่างจากราคาปิดเมื่อวาน) ไม่อยู่ในแบบจำลองนี้

ตรวจเองใน 10 วินาที: 30 นาทีคือ $1/13$ ของวันทำการ (เพราะ $390/30=13$) และวันหนึ่งคือ $1/252$ ของปี จึงได้ $1/(13\times252)=1/3{,}276\approx0.000305$

ขั้นที่ 8 — ค่าเฉลี่ยกับ SD ของการเปลี่ยนราคา

ได้ $\Delta t$ แล้ว ขั้นนี้หาว่าใน 30 นาที ราคาขยับเฉลี่ยเท่าไร และแกว่งได้แค่ไหน เพราะกรอบเตือนต้องใช้ทั้งสองตัว

โจทย์ให้อะไรมาบ้าง:

  • ราคาวันนี้ $S_0=\$520$
  • drift $\mu=0.08$ ต่อปี
  • ความผันผวน $\sigma=0.18$ ต่อรากของปี
  • $\Delta t=0.00030525$ ปี จากขั้นที่แล้ว

drift กับความผันผวนเป็นตัวเลขของผลตอบแทน (การเปลี่ยนราคาคิดเป็นสัดส่วนของราคา) ไม่ใช่ตัวเลขของดอลลาร์ เราจึงให้ผลตอบแทนเดินแบบ Brownian ก่อน แล้วค่อยแปลงเป็นดอลลาร์ ให้ $X_t$ คือผลตอบแทนสะสมตั้งแต่ตอนเริ่ม และให้มันเดินตามรูป $X_t=X_0+\mu t+\sigma W_t$ จากขั้นที่ 1

\[ \begin{aligned} X_{t+\Delta t}-X_t&=\mu\Delta t+\sigma\Delta W,\\ \Delta S&\approx S_0\,(X_{t+\Delta t}-X_t)\\ &=S_0(\mu\Delta t+\sigma\Delta W). \end{aligned} \]

ผลตอบแทนในช่วงยาว $\Delta t$ คือค่าตอนปลายลบค่าตอนต้น ตัว $X_0$ จึงหักกันหายไป เหลือพจน์ drift กับพจน์สุ่ม ในสูตรนี้ $\Delta S$ คือการเปลี่ยนราคาเป็นดอลลาร์ใน 30 นาที และ $\Delta W=W_{t+\Delta t}-W_t$ คือการขยับของ Brownian มาตรฐานในช่วงนั้น ตามกติกาข้อ 2 มันเป็น $\mathcal N(0,\Delta t)$

การเปลี่ยนราคาเป็นดอลลาร์ได้จากราคาตอนเริ่มคูณผลตอบแทน การใช้ $S_0$ คงที่เป็นการประมาณ เพราะจริง ๆ ราคาเปลี่ยนไประหว่างทาง แต่ใน 30 นาทีราคาแทบไม่เปลี่ยนเมื่อเทียบกับ \$520 จึงคลาดน้อยมาก (แบบจำลองที่ราคาโตแบบคูณจริง ๆ คือ geometric Brownian motion)

$\Delta W$ มีค่าเฉลี่ยศูนย์ และมี SD $\sqrt{\Delta t}$ ค่าเฉลี่ยของ $\Delta S$ จึงมาจากพจน์ drift อย่างเดียว ส่วน SD มาจากพจน์ $\sigma\Delta W$ อย่างเดียว เพราะพจน์ drift เป็นตัวเลขคงที่ซึ่งไม่แกว่ง

\[ \begin{aligned} \mathbb E[\Delta S]&=S_0\mu\Delta t\\ &=520(0.08)(0.00030525)\\ &\approx0.0127,\\ \operatorname{SD}(\Delta S)&=S_0\sigma\sqrt{\Delta t}\\ &=93.60(0.0174714)\\ &\approx1.6353,\\ \frac{1.6353}{0.0127}&\approx128.8. \end{aligned} \]

คำตอบ: ใน 30 นาที ราคาขยับขึ้นเฉลี่ยแค่ราว \$0.0127 หรือ 1.27 เซนต์ แต่ SD คือ \$1.635 ใหญ่กว่าค่าเฉลี่ยราว 129 เท่า

ทำไมห่างกันขนาดนี้ ลองหารสูตร SD ด้วยสูตรค่าเฉลี่ย ตัว $S_0$ ตัดกันหมด และที่เหลือแยกเป็นสองส่วน

\[ \begin{aligned} \frac{\text{SD}}{\text{mean}}&=\frac{S_0\sigma\sqrt{\Delta t}}{S_0\mu\,\Delta t}=\frac{\sigma}{\mu}\cdot\frac{1}{\sqrt{\Delta t}}\\ &=\frac{0.18}{0.08}\cdot\frac{1}{0.0174714}\\ &\approx2.25\times57.2\approx128.8. \end{aligned} \]

ส่วนแรก $\sigma/\mu=2.25$ คืออัตราส่วนเดียวกันของช่วงหนึ่งปี เพราะเมื่อ $\Delta t=1$ ส่วนที่สองเท่ากับ 1 ในหนึ่งปี การแกว่งจึงใหญ่กว่าทิศทางแค่ราวสองเท่า ส่วนที่สอง $1/\sqrt{\Delta t}\approx57.2$ มาจาก drift โตตามเวลา แต่ SD โตตามรากของเวลา เมื่อเวลาสั้นกว่าหนึ่งปี รากของเวลาใหญ่กว่าตัวเวลา ช่วงยิ่งสั้น ส่วนนี้ยิ่งใหญ่ ทิศทางขาขึ้นจึงจมหายใต้การแกว่ง

ตรวจเองใน 10 วินาที: $520\times0.18=93.60$ ดอลลาร์ต่อรากของปี และ $93.6\times0.0175\approx1.64$

ขั้นที่ 9 — กรอบ 95% และราคาของความผิดแบบพนักงานใหม่

ตอนนี้มีของครบแล้ว ขั้นนี้ตั้งกรอบเตือนที่ถูก แล้ววัดว่ากรอบของพนักงานใหม่ผิดไปแค่ไหน

โจทย์ให้อะไรมาบ้าง:

  • ค่าเฉลี่ยของการเปลี่ยนราคา \$0.0127 จากขั้นที่แล้ว
  • SD ของการเปลี่ยนราคา \$1.6353 จากขั้นที่แล้ว
  • $\Phi(z)$ คือโอกาสที่ Normal มาตรฐาน (Normal ที่มีค่าเฉลี่ย 0 และ SD 1) จะไม่เกินตัวเลข $z$ และตาราง Normal ให้ $\Phi(1.96)\approx0.975$
  • หางขวา (ส่วนของระฆังที่เกิน 1.96 SD) จึงเหลือ $1-0.975=2.5\%$ หางซ้ายก็ 2.5% เท่ากัน ตรงกลางเหลือ 95% ดังนั้นกรอบ 95% คือค่าเฉลี่ยบวกลบ 1.96 SD
  • กรอบของพนักงานใหม่ใช้ SD ผิดคือ $\sigma S_0\Delta t$ แทน $\sigma S_0\sqrt{\Delta t}$

งานแรกคือตั้งกรอบที่ถูก: ค่าเฉลี่ยบวกลบ 1.96 SD

\[ \begin{aligned} 1.96(1.6353)&\approx3.2052,\\ \text{low}&=0.0127-3.2052\approx-3.19,\\ \text{high}&=0.0127+3.2052\approx3.22. \end{aligned} \]

งานที่สองคือวัดว่ากรอบของพนักงานใหม่แคบแค่ไหน ให้ $B$ คือความกว้างข้างละของกรอบนั้น และให้ $z=B/\text{SD}$ คือ $B$ นับเป็นจำนวน SD ที่ถูก

\[ \begin{aligned} \text{wrong SD}&=93.60(0.00030525)\approx0.0286,\\ B&=1.96(0.0286)\approx0.056,\\ z=B/\text{SD}&=0.056/1.6353\approx0.0342. \end{aligned} \]

ราคาหลุดกรอบทางขวาเมื่อการเปลี่ยนราคาเกิน $B$ หรือเกิน $z$ SD ซึ่งมีโอกาส $1-\Phi(z)$ ระฆังสมมาตร ทางซ้ายจึงมีโอกาสเท่ากัน รวมสองทางจึงคูณสอง ตรงนี้ตัดค่าเฉลี่ย \$0.0127 ทิ้งได้ เพราะเล็กมากเมื่อเทียบกับ SD ส่วน $|\Delta S|$ คือขนาดการเปลี่ยนราคาโดยไม่สนทิศ

ต้องหา $\Phi(0.0342)$ แต่ตารางให้ค่าทีละ 0.01 โชคดีที่ $z$ นี้ใกล้ศูนย์มาก จึงประมาณเองได้ ระฆังตรงยอดแทบแบน พื้นที่จาก 0 ถึง $z$ จึงเกือบเป็นสี่เหลี่ยม สูงเท่ายอด $1/\sqrt{2\pi}\approx0.399$ และกว้าง $z$ ส่วนพื้นที่ทางซ้ายของ 0 คือครึ่งหนึ่งพอดี

\[ \begin{aligned} \Phi(z)&\approx0.5+z/\sqrt{2\pi},\\ \Phi(0.0342)&\approx0.5+0.0342(0.399)\\ &\approx0.5136,\\ P(|\Delta S|\gt B)&=2\big(1-\Phi(z)\big)\\ &=2(1-0.5136)\approx0.973. \end{aligned} \]

คำตอบ: กรอบ 95% คือ −\$3.19 ถึง +\$3.22 รอบราคาเดิม บวกกับราคาวันนี้ \$520 ได้ช่วงราคา $520-3.19=\$516.81$ ถึง $520+3.22=\$523.22$ กรอบไม่สมมาตรรอบ \$520 เล็กน้อย เพราะค่าเฉลี่ย \$0.0127 ดันกรอบขึ้นนิดหนึ่ง

ส่วนกรอบของพนักงานใหม่ ±\$0.056 ใช้ SD ที่เล็กไป $1/\sqrt{\Delta t}\approx57.2$ เท่า กรอบนั้นจึงกว้างข้างละแค่ 0.0342 SD ราคาจริงหลุดกรอบนี้ราว 97.3% ของทุกช่วง 30 นาที คือราว 97 ครั้งจาก 100 ครั้ง

ตรวจเองใน 10 วินาที: ใช้ 2 แทน 1.96 จะได้ $2\times1.64=3.28$ ใกล้กับ $1.96\times1.6353\approx3.21$ ที่คำนวณไว้ และกรอบผิดกว้างข้างละ $0.056/1.635\approx0.034$ SD ซึ่งแคบจนเกือบทุกการขยับทะลุ

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

คูณ SD ด้วยเวลาแทนรากของเวลา: นี่คือความผิดของพนักงานใหม่ในโจทย์เปิดเรื่อง สำหรับ 30 นาทีของ SPY

\[\begin{aligned}\text{wrong}&=93.6\times0.00030525\approx\$0.0286,\\\text{right}&=93.6\times\sqrt{0.00030525}\approx\$1.635.\end{aligned}\]

SD ผิดเล็กไป $1.635/0.0286\approx57$ เท่า และราคาทะลุกรอบเตือน 97.3% ของช่วง 30 นาที (ขั้นที่ 9) ความผิดแบบกลับด้านก็เกิดได้ คือแปลง SD รายวันเป็นรายปีด้วยการคูณ 252 แทน $\sqrt{252}$ ได้ตัวเลขใหญ่ไป $252/\sqrt{252}=\sqrt{252}\approx15.87$ เท่า (หน้า standard Brownian motion คำนวณให้ดูกับพอร์ต \$25 ล้าน)

ใช้กฎรากที่สองกับข้อมูลที่ไม่ผ่านกติกาข้อ 1: กฎรากที่สองต้องให้วันต่าง ๆ อิสระกัน ถ้าผลตอบแทนของวันที่ติดกันมี correlation 0.1 พจน์ไขว้จะไม่หายไป สมมติว่ามี correlation เฉพาะวันที่ติดกัน ส่วนวันที่ห่างกันกว่านั้นมี correlation ศูนย์

นับ variance เป็นหน่วยของ variance รายวัน ทุกวันจึงมี variance เท่ากับ 1 covariance ของวันที่ติดกันคือ correlation คูณ SD ของสองวัน คือ $0.1\times1\times1=0.1$ ใน 252 วันมีคู่วันที่ติดกัน $252-1=251$ คู่ และแต่ละคู่ถูกนับสองครั้งในสูตร variance ของผลรวม

\[\begin{aligned}\text{Var}&=\sum\operatorname{Var}+2\sum\operatorname{Cov},\\\text{wrong}&=252\times1=252,\\\text{right}&=252\times1+2\times251\times(0.1\times1)\\&=302.2,\\\sqrt{302.2/252}&\approx1.095.\end{aligned}\]

SD รายปีจริงจึงสูงกว่าที่กฎรากที่สองบอกราว 9.5% ทั้งที่ correlation 0.1 ดูเล็กมาก ในรูปสามเหลี่ยมมุมฉากข้างบน correlation บวกง้างมุมตรงจุดที่สองด้านต่อกันให้กว้างกว่ามุมฉาก ด้านที่ปิดสามเหลี่ยมจึงยาวขึ้น

เช็ค correlation ของผลตอบแทนแล้วคิดว่าผ่านข้อ 1: correlation ของผลตอบแทนใกล้ศูนย์ยังไม่พอ เพราะข้อมูลจริงมักมีความผันผวนเกาะกลุ่ม คือวันที่ขยับแรงมักตามด้วยวันที่ขยับแรง แม้จะเดาทิศไม่ได้ วันเหล่านี้จึงไม่อิสระกันจริง ต้องดู correlation ของผลตอบแทนยกกำลังสองด้วย เหตุผลคือการยกกำลังสองทิ้งเครื่องหมาย เหลือแค่ขนาดการขยับ “แรงตามด้วยแรง” จึงโผล่เป็น correlation บวกของกำลังสอง แม้เครื่องหมายจะเดาไม่ได้ก็ตาม (แบบจำลองที่จับเรื่องนี้คือ GARCH)

ลืมว่ากรอบเป็นของแบบจำลอง: กรอบ \$516.81 ถึง \$523.22 คิดบนสมมติฐานว่าราคาไม่กระโดด และการขยับเป็นระฆัง Normal ถ้ามีข่าวใหญ่ระหว่างวัน ราคาจะหลุดกรอบบ่อยกว่า 5 ครั้งจาก 100 มาก

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะเทรดใช้กฎรากที่สองทุกวัน งานแรกคือแปลงความผันผวนข้ามช่วงเวลา เช่นจากรายวันเป็นรายปี หรือเป็นรายชั่วโมง งานที่สองคือตั้งกรอบเตือนของระบบเทรด แบบโจทย์ SPY ข้างบน งานที่สามคือรายงานความเสี่ยงให้ผู้กำกับธนาคาร ตัวเลขที่รายงานเรียกว่า VaR คือยอดขาดทุนที่พอร์ต (กองสินทรัพย์ทั้งหมดที่ธนาคารถืออยู่) จะไม่เกินด้วยความมั่นใจระดับหนึ่ง เช่น 99%

กติกา Basel (มาตรฐานกลางของผู้กำกับธนาคารทั่วโลก) ให้รายงาน VaR ของ 10 วันทำการ ที่ความมั่นใจ 99% ถ้าการขยับเป็นระฆัง Normal และค่าเฉลี่ยแทบเป็นศูนย์ VaR 99% คือระยะ 2.33 SD เพราะตาราง Normal ให้ $\Phi(2.33)\approx0.99$ แปลว่าขาดทุนเกิน 2.33 SD มีโอกาสแค่ 1% ส่วน SD ของ 10 วันได้จากกฎรากที่สอง ให้ $\text{SD}_1$ กับ $\text{VaR}_1$ เป็นของหนึ่งวัน และ $\text{SD}_{10}$ กับ $\text{VaR}_{10}$ เป็นของ 10 วัน

\[\begin{aligned}\text{VaR}_1&=2.33\,\text{SD}_1,\\\text{SD}_{10}&=\sqrt{10}\,\text{SD}_1,\\\text{VaR}_{10}&=2.33\,\text{SD}_{10}\\&=\sqrt{10}\,(2.33\,\text{SD}_1)\\&=\sqrt{10}\,\text{VaR}_1\approx3.162\,\text{VaR}_1.\end{aligned}\]

VaR จึงโตตามรากของเวลาแบบเดียวกับ SD ธนาคารเอา VaR หนึ่งวันคูณ $\sqrt{10}\approx3.162$ ไม่ใช่คูณ 10

กติกาสามข้อยังเป็นฐานของ geometric Brownian motion และสูตร Black–Scholes ที่ใช้ตั้งราคา option (สัญญาที่ให้สิทธิ์ซื้อหรือขายสินทรัพย์ในราคาที่ตกลงไว้ ภายในวันหมดอายุ) ทุกครั้งที่สูตรเหล่านั้นมี $\sigma\sqrt T$ ($T$ คือเวลาที่เหลือจนสัญญา option หมดอายุ นับเป็นปี) มันกำลังใช้ “variance โตตามเวลา” ของหน้านี้ และทุกครั้งที่ใครพูดว่า “hedge ต่อเนื่อง” มันกำลังพึ่งกติกาห้ามกระโดด

1. ระบบเตือนตัวเดิมต้องการกรอบอีกชุดสำหรับ 2 ชั่วโมงข้างหน้า ใช้ SPY ตัวเดิม: ราคา $S_0=\$520$, drift $\mu=8\%$ ต่อปี และความผันผวน $\sigma=18\%$ ต่อรากของปี กรอบ 95% ของการเปลี่ยนราคาใน 2 ชั่วโมงคือเท่าไร

เฉลย

นับเงินเป็นล้านดอลลาร์ และนับ variance เป็นหน่วยของ variance หนึ่งวัน ($1^2=1$) ถ้าวันอิสระกัน variance ของ 10 วันคือ $10\times1=10$ ถ้ามี correlation 0.1 ระหว่างวันที่ติดกัน จะมีพจน์ไขว้เพิ่ม covariance ของแต่ละคู่คือ correlation คูณ SD ของสองวัน คือ $0.1\times1\times1=0.1$ ใน 10 วันมีคู่วันที่ติดกัน $10-1=9$ คู่ และแต่ละคู่ถูกนับสองครั้งในสูตร variance ของผลรวม

\[\begin{aligned}\text{SD}_{\text{indep}}&=\sqrt{10}\approx3.162,\\\text{Var}_{\text{corr}}&=10\times1+2\times9\times(0.1\times1)\\&=11.8,\\\text{SD}_{\text{corr}}&=\sqrt{11.8}\approx3.435,\\3.435/3.162&\approx1.086.\end{aligned}\]

ถ้าอิสระกัน SD 10 วันคือ \$3.162 ล้าน ไม่ใช่ \$10 ล้าน ถ้ามี correlation 0.1 จะเป็น \$3.435 ล้าน สูงกว่ากฎรากที่สองราว 8.6%

3. ทีมวิจัยวัด excess kurtosis ของผลตอบแทนรายชั่วโมงของหุ้นตัวหนึ่งได้ 0.6 คือหางหนากว่า Normal เล็กน้อย ถ้าผลตอบแทนรายนาทีอิสระกันและมีรูปทรงเหมือนกันทุกนาที ผลตอบแทนรายนาทีต้องมี excess kurtosis เท่าไร และถ้าวัดรายชั่วโมงได้ −0.5 แทน เป็นไปได้ไหม?

เฉลย

ใช้กฎจากขั้นที่ 5 กลับด้าน: ผลรวม $n$ ท่อนมี $K$ เป็น $1/n$ เท่าของท่อนเดี่ยว ท่อนเดี่ยวจึงมี $K$ เป็น $n$ เท่าของผลรวม หนึ่งชั่วโมงมี 60 นาที จึงใช้ $n=60$ แล้วเทียบกับตัวอย่าง “นิ่งหรือโดด” ในขั้นที่ 5 ซึ่งมี $K=1/p-3$

\[\begin{aligned}K_{1\,\text{min}}&=60\times0.6=36,\\1/p&=36+3=39.\end{aligned}\]

รายนาทีต้องมี $K=36$ ซึ่งหางหนามาก ในตัวอย่าง “นิ่งหรือโดด” ค่านี้คือราคาโดดราวหนึ่งนาทีใน 39 นาที และนิ่งในนาทีอื่น แปลว่ามีการกระโดดเล็ก ๆ ที่เกิดนาน ๆ ครั้ง

ส่วนค่า −0.5 ใช้กฎเดียวกัน

\[\begin{aligned}K_{1\,\text{min}}&=60\times(-0.5)=-30\lt-2.\end{aligned}\]

รายนาทีต้องมี $K=-30$ ซึ่งต่ำกว่าพื้น −2 มาก ไม่มีตัวแปรไหนมีได้ ผลวัด −0.5 จึงเป็นไปไม่ได้ภายใต้สมมติฐานของโจทย์

// Standard Normal CDF by Simpson's rule on the density: no library needed.
function Phi(x) {
  if (!Number.isFinite(x) || Math.abs(x) > 8) throw new RangeError('Phi needs a finite score within 8');
  const n = 4000, h = Math.abs(x) / n, phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(x) * s * h / 3;
}
// Arithmetic Brownian approximation of a price change over a short horizon.
function horizon(S0, mu, sigma, minutes, minutesPerYear = 252 * 390) {
  if (![S0, mu, sigma, minutes, minutesPerYear].every(Number.isFinite)) throw new TypeError('Inputs must be finite numbers');
  if (S0 <= 0 || sigma < 0 || minutes < 0 || minutesPerYear <= 0) throw new RangeError('Need price > 0, sigma >= 0, minutes >= 0');
  const dt = minutes / minutesPerYear; // years, the unit of mu and sigma
  return {dt, mean: S0 * mu * dt, sd: S0 * sigma * Math.sqrt(dt), wrongSD: S0 * sigma * dt};
}
// Share of windows whose true move leaves a band of +/- halfWidth around zero.
function breach(halfWidth, sd) {
  if (!(halfWidth >= 0) || !(sd > 0)) throw new RangeError('Need halfWidth >= 0 and sd > 0');
  return 2 * (1 - Phi(halfWidth / sd));
}
// Excess kurtosis each of n IID pieces must have so that their sum has excess kurtosis K.
function pieceKurtosis(K, n) {
  const k = K * n;
  if (k < -2) throw new RangeError(`Impossible: pieces would need excess kurtosis ${k} < -2`);
  return k;
}
// Variance of an n-day sum, in daily-variance units, when neighbouring days have correlation rho.
const sumVariance = (n, rho) => n + 2 * (n - 1) * rho;
// mulberry32: a small seeded generator so every reader gets the same numbers.
function uniforms(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
}
// Build moves from n uniform pieces with variance 1/n each; return SD and excess kurtosis.
function uniformSums(paths, n, seed) {
  const u = uniforms(seed), a = Math.sqrt(3 / n); // uniform on [-a, a] has variance a^2/3 = 1/n
  let m2 = 0, m4 = 0;
  for (let p = 0; p < paths; p++) {
    let x = 0;
    for (let i = 0; i < n; i++) x += a * (2 * u() - 1);
    m2 += x * x; m4 += x ** 4;
  }
  m2 /= paths; m4 /= paths;
  return {sd: Math.sqrt(m2), excessKurtosis: m4 / (m2 * m2) - 3};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • กติกาสามข้อ: การขยับของช่วงที่ไม่ทับกันอิสระกัน, การขยับขึ้นกับความยาวช่วงเท่านั้นและเป็น $\mathcal N(\mu s,\sigma^2 s)$, และเส้นทางไม่กระโดด
  • ความเป็นอิสระทำให้ variance บวกกันได้ (เหมือนด้านที่ตั้งฉากของสามเหลี่ยม) ส่วนการไม่ขึ้นกับเวลาเริ่มบังคับให้ $v(s)=n\,v(s/n)$ variance จึงเป็นเส้นตรงกับเวลา และ SD $=\sigma\sqrt s$
  • excess kurtosis ของผลรวม $n$ ท่อนหดเป็น $K/n$ และไม่มีวันต่ำกว่า −2 uniform จึงใช้ไม่ได้ หางหนาต้องอาศัยการกระโดด ที่เหลือรอดคือ Normal
  • กรอบ 30 นาทีของ SPY คือ $0.0127\pm1.96\times1.635$ คือ −\$3.19 ถึง +\$3.22 กรอบเกือบสมมาตรรอบศูนย์ เพราะ SD ใหญ่กว่าค่าเฉลี่ยราว 129 เท่า ถ้าคูณ SD ด้วยเวลาแทนรากของเวลา จะได้ SD เล็กไป $1/\sqrt{\Delta t}\approx57$ เท่า
  • กติกาห้ามกระโดดต้องเขียนแยก เพราะ Poisson ที่หักค่าเฉลี่ยแล้วมีค่าเฉลี่ยและ variance เหมือน Brownian ทุกประการ แต่กระโดด
