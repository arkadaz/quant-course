18.4 Delta Hedging P&L

delta hedge ลบความเสี่ยงเรื่องทิศทางออก สิ่งที่เหลือคือ gamma กับ theta ซึ่งรวมกันเป็นการเดิมพันว่าหุ้นจะแกว่งจริงมากกว่าที่ราคา option คิดไว้หรือไม่

โต๊ะถือ call 1,000 ตัว แต่ละตัวมี gamma 0.020 และทั้งก้อนเสียค่าเวลา (theta) \$18 ต่อวัน โต๊ะ hedge delta ไว้ตลอด วันนี้หุ้นเปิด \$100 ขึ้นไป \$102 แล้วกลับมาปิดที่ \$100 หัวหน้าถามว่าวันนี้ได้เสียเท่าไร ผู้ช่วยตอบว่า “ราคาปิดเท่าเดิม และเรา hedge แล้ว จึงเสียแค่ค่าเวลา \$18” ถูกไหม

ลองตอบก่อนเปิดเฉลย

ไม่ถูก วันนี้ได้ \$62 ตอนหุ้นขึ้นถึง \$102 delta ของทั้งก้อนเพิ่ม 40 หุ้น hedge จึงต้องขายหุ้นเพิ่ม 40 หุ้นที่ \$102 ตอนหุ้นกลับมา \$100 delta ลดลงเท่าเดิม จึงซื้อ 40 หุ้นนั้นคืน ขายแพงซื้อถูกได้ \$80 หักค่าเวลา \$18 เหลือ \$62 ราคาปิดบอกไม่ได้ว่า hedge ได้เสียเท่าไร เส้นทางระหว่างวันต่างหากที่บอก

ภาพรวมก่อนลงสูตร

ต้นไม้ binomial แสดงว่าถ้าปรับพอร์ตหุ้นกับเงินกู้ทุกกิ่ง ก็เลียนแบบ option ได้ครบ และสมการ Black–Scholes ทำแบบเดียวกันในเวลาต่อเนื่อง แต่โต๊ะจริงปรับได้เป็นช่วง ราคาไม่ได้ขยับตามแบบจำลอง และความผันผวนที่ใช้ตั้งราคาก็ไม่เท่ากับที่เกิดจริง หน้านี้นับว่าหลัง hedge แล้วเงินได้เสียมาจากไหน

คำตอบสั้นอยู่ในรูปด้านล่าง เมื่อ hedge delta แล้ว กำไรขาดทุนหนึ่งวันเป็นพาราโบลาของขนาดที่หุ้นขยับ ส่วนโค้งขึ้นคือเงินจาก gamma ที่ได้ไม่ว่าหุ้นจะขึ้นหรือลง ส่วนที่ทำให้พาราโบลาจมลงใต้ศูนย์คือ theta ที่จ่ายทุกวัน หุ้นต้องขยับเกินจุดคุ้มทุนจึงจะได้ และจุดคุ้มทุนนั้นถูกกำหนดด้วยความผันผวนที่จ่ายไปในราคา option พอดี

หน้านี้จะเดินตามคำสั่งซื้อขายด้วยมือ กาง Taylor ของราคา option ใช้สมการ Black–Scholes แสดงว่า theta คือราคาของ gamma ไล่ตัวอย่างห้าวัน นับต้นทุนการปรับ แล้วใช้แบบฝึกขาย call 100,000 ตัวดูผลของความถี่การปรับ ความผันผวนที่ใช้ผิด จังหวะที่หุ้นแกว่ง และวันที่หุ้นขยับแรงจน Taylor ใช้ไม่ได้

ศัพท์ที่ใช้ในหัวข้อนี้
Delta hedge
ถือหุ้นสวนทางกับ delta ของ option เพื่อให้พอร์ตไม่ได้เสียเมื่อหุ้นขยับนิดเดียว ต้องปรับจำนวนหุ้นใหม่เรื่อย ๆ เพราะ delta เปลี่ยนตามราคาและเวลา
Gamma และ theta
gamma คืออัตราที่ delta เปลี่ยนเมื่อหุ้นขยับ \$1 theta คือมูลค่าที่ option เสียไปเมื่อเวลาผ่านไปโดยหุ้นไม่ขยับ สองตัวนี้คือสิ่งที่เหลือหลัง hedge (นิยามเต็มอยู่ในหน้าthe Greeks)
Implied และ realized volatility
implied คือความผันผวนที่ใส่ใน Black–Scholes แล้วได้ราคาตลาด (ราคาที่จ่าย) realized คือความผันผวนที่หุ้นแกว่งจริงในช่วงที่ถือ (ของที่ได้)
Gamma scalping
ถือ option แล้ว hedge ไปเรื่อย ๆ ซึ่งบังคับให้ขายหุ้นตอนขึ้นและซื้อตอนลง กำไรจากการขายแพงซื้อถูกนี้คือเงินของ gamma
Vega
ราคา option เปลี่ยนเท่าไรเมื่อความผันผวนขยับ ใช้บอกขนาดของการเดิมพันความผันผวนเป็นเงิน
Dollar delta และ dollar gamma
dollar delta คือ $\Delta S$ หรือมูลค่าหุ้นที่พอร์ตเทียบเท่า dollar gamma คือ $\tfrac12\Gamma S^2$ คือเงินที่ได้ต่อผลตอบแทนยกกำลังสองหนึ่งหน่วย ใช้รวมความเสี่ยงของ option หลายตัวบนหุ้นหลายราคาให้เป็นเงินเดียวกัน
Self-financing
พอร์ตที่ปรับได้โดยไม่เติมหรือดึงเงิน เงินซื้อหุ้นเพิ่มมาจากเงินฝากหรือเงินกู้ของพอร์ตเอง เป็นเงื่อนไขที่ทำให้ต้นทุนตอนเริ่มคือต้นทุนทั้งหมด

ขั้นที่ 1 — เดินตามคำสั่งซื้อขายด้วยมือ: 100 ไป 102 แล้วกลับ 100

ก่อนมีสูตร ลองทำตามที่มือของคน hedge ต้องทำจริง call 1,000 ตัว gamma ตัวละ 0.020 แปลว่าหุ้นขึ้น \$1 delta ของทั้งก้อนเพิ่ม 20 หุ้น ตลอดวันต้องถือหุ้นชอร์ตเท่ากับ delta เสมอ และวันนี้ปรับสองครั้ง ตอนหุ้นถึง 102 กับตอนกลับมา 100

\[ \begin{aligned} \Gamma_{\rm book}&=1{,}000(0.020)=20,\\ \Delta_{102}-\Delta_{100}&=20(2)=40,\\ G&=40(102-100)=80,\\ G&=2\cdot\tfrac12(20)(2)^2=80,\\ \Pi&=G-18=62. \end{aligned} \]

ตอนหุ้นถึง 102 call ทั้งก้อนมีหุ้นเทียบเท่าเกินมา 40 หุ้น จึงขาย 40 หุ้นที่ 102 ตอนหุ้นกลับ 100 delta หดกลับ จึงซื้อ 40 หุ้นคืนที่ 100 ได้ \$80 โดยไม่ได้ทายทิศทางเลย ส่วน call เองกลับมามีค่าเท่าเดิมเพราะหุ้นกลับที่เดิม

แถวที่สี่คิด \$80 อีกทางด้วยสูตรความโค้ง $\tfrac12\Gamma(\Delta S)^2$ สองขา ขาละ \$40 ได้เท่ากัน ขั้นถัดไปจะแสดงว่าสูตรนี้มาจากไหน ค่าเวลา \$18 จ่ายทุกวันไม่ว่าหุ้นจะแกว่งหรือไม่

ขั้นที่ 2 — กาง Taylor ของราคา option แล้วเลือกว่าจะเก็บพจน์ไหน

ราคา option $V(S,t)$ ขึ้นกับราคาหุ้นและเวลา กาง Taylor สองตัวแปรถึงอันดับสอง แล้วดูขนาดจริงของแต่ละพจน์ในหนึ่งวัน ($\Delta t=1/252$ ปี เพราะตลาดหุ้นสหรัฐฯ เปิดทำการราว 252 วันต่อปี) และหุ้นขยับ \$2

\[ \begin{aligned} \Delta V&=V_S\Delta S+V_t\Delta t\\ &\quad+\tfrac12V_{SS}(\Delta S)^2\\ &\quad+V_{St}\Delta S\,\Delta t\\ &\quad+\tfrac12V_{tt}(\Delta t)^2+\cdots,\\ (\Delta S)^2&=4,\\ \Delta S\,\Delta t&=2/252=0.0079,\\ (\Delta t)^2&=0.0000157,\\ \Delta V&\approx\Delta\,\Delta S+\tfrac12\Gamma(\Delta S)^2\\ &\quad+\Theta\,\Delta t+\mathcal V\,\Delta\sigma,\\ \Delta V&\approx\Delta S\cdot\frac{\Delta S}{S}\\ &\quad+\tfrac12\Gamma S^2\Big(\frac{\Delta S}{S}\Big)^2+\cdots \end{aligned} \]

ใน calculus ปกติเราทิ้งพจน์กำลังสองทั้งหมด แต่ที่นี่ทิ้งไม่ได้ทั้งหมด $(\Delta S)^2=4$ ใหญ่กว่า $\Delta S\Delta t$ ห้าร้อยเท่า เพราะหุ้นขยับตามรากที่สองของเวลา (สมบัติของ Brownian motion) ไม่ใช่ตามเวลา จึงเก็บ $(\Delta S)^2$ และทิ้งสองพจน์ที่มี $\Delta t$ คูณอยู่

แถวที่เก้าตั้งชื่อตามthe Greeks $V_S=\Delta$, $V_{SS}=\Gamma$, $V_t=\Theta$ และเติมพจน์ vega คูณการขยับของความผันผวน เพราะ implied volatility ของตลาดเองก็ขยับทุกวัน แถวสุดท้ายเขียนใหม่เป็นผลตอบแทน $\Delta S/S$ ตัวคูณ $\Delta S$ คือ dollar delta และ $\tfrac12\Gamma S^2$ คือ dollar gamma รูปนี้ใช้กับพอร์ต option ทั้งเล่มได้ เพราะ dollar delta และ dollar gamma ของแต่ละตัวบวกกันได้ ข้อควรระวัง การทิ้งพจน์ใช้ไม่ได้ในวันที่หุ้นกระโดดแรง

ขั้นที่ 3 — หักขาหุ้นออก พจน์ทิศทางหายไปพอดี

พอร์ตที่ hedge คือ option หนึ่งตัวกับหุ้นชอร์ต $\Delta$ หุ้น ขาหุ้นได้เสีย $-\Delta\cdot\Delta S$ เอาไปรวมกับ Taylor ที่เพิ่งได้ (ให้ความผันผวนคงที่) แล้วใส่ตัวเลขของโจทย์เปิดหน้า หุ้นขยับ \$2 ในวันเดียวแล้วไม่กลับ

\[ \begin{aligned} \Delta\Pi&=\Delta V-\Delta\cdot\Delta S\\ &=\tfrac12\Gamma(\Delta S)^2+\Theta\,\Delta t,\\ G_1&=\tfrac12(20)(2)^2=40,\\ \Pi&=40-18=22,\\ \tfrac12(20)x^2&=18,\\ x&=\sqrt{1.8}=1.3416. \end{aligned} \]

พจน์ $\Delta\,\Delta S$ หักกันหมด นี่คือความหมายทั้งหมดของ delta hedge ไม่สนว่าหุ้นขึ้นหรือลง สิ่งที่เหลือคือความโค้ง ซึ่งบวกเสมอเพราะ $(\Delta S)^2$ ไม่ติดลบ ลบด้วยค่าเวลาที่จ่ายทุกวัน นี่คือพาราโบลาในรูปภาพรวม

สองแถวล่างหาจุดคุ้มทุน ก้อนนี้ต้องให้หุ้นขยับอย่างน้อย \$1.3416 ต่อวัน (ทางไหนก็ได้) จึงจะได้ gamma พอจ่ายค่าเวลา ขยับน้อยกว่านั้นขาดทุน

ขั้นที่ 4 — theta คือราคาที่จ่ายเพื่อซื้อ gamma

ทำไมค่าเวลาถึงเป็น \$18 ไม่ใช่ตัวเลขอื่น สมการ Black–Scholes คือ $\Theta+\tfrac12\sigma^2S^2\Gamma+rS\Delta-rV=0$ ถ้าดอกเบี้ยเป็นศูนย์ theta ถูกผูกกับ gamma ด้วยความผันผวนที่ใช้ตั้งราคา แทนกลับลงในกำไรขาดทุนของพอร์ตที่ hedge แล้ว

\[ \begin{aligned} r=0&:\ \Theta=-\tfrac12\sigma_{\rm imp}^2S^2\Gamma,\\ \Delta\Pi&=\tfrac12\Gamma S^2\Big[\big(\tfrac{\Delta S}{S}\big)^2\\ &\qquad-\sigma_{\rm imp}^2\Delta t\Big],\\ |\Delta S^*|&=\sigma_{\rm imp}S\sqrt{\Delta t},\\ \sigma_{\rm imp}&=\sqrt{\frac{2(18)(252)}{20(100)^2}}\\ &=21.30\%. \end{aligned} \]

วงเล็บเทียบของสองอย่าง $(\Delta S/S)^2$ คือความแปรปรวนที่หุ้นแกว่งจริงในวันนั้น $\sigma_{\rm imp}^2\Delta t$ คือความแปรปรวนที่จ่ายไปในราคา option ถ้าแกว่งจริงมากกว่าที่จ่าย ได้เงิน ถ้าน้อยกว่า เสีย จุดคุ้มทุน $|\Delta S^*|$ จึงเป็นการขยับหนึ่ง SD ต่อวันตามความผันผวนที่จ่ายไป ตัวคูณข้างหน้าคือ dollar gamma ซึ่งบอกว่าส่วนต่างนี้มีค่ากี่ดอลลาร์

แถวสุดท้ายอ่านโจทย์เปิดหน้ากลับทาง ค่าเวลา \$18 ต่อวันกับ gamma ทั้งก้อน 20 ที่หุ้น \$100 แปลว่าตลาดตั้งราคา option นี้ที่ความผันผวน 21.30% ต่อปี และ $0.2130(100)/\sqrt{252}=1.3416$ ตรงกับจุดคุ้มทุนที่หาไว้

ถ้าหุ้นแกว่งจริงเฉลี่ยวันละ $(\Delta S/S)^2=\sigma_{\rm real}^2\Delta t$ ได้วันละ $\tfrac12\Gamma S^2(\sigma_{\rm real}^2-\sigma_{\rm imp}^2)\Delta t$ ก้อนที่ $\tfrac12\Gamma S^2=\tfrac12(20)(100)^2=100{,}000$ ถ้าจ่าย 20% แต่หุ้นแกว่ง 30% ได้ $100{,}000(0.09-0.04)/252=\$19.84$ ต่อวัน การซื้อ option แล้ว hedge จึงเป็นการซื้อความผันผวน ตลาดมีสัญญาที่ซื้อขายเรื่องนี้ตรง ๆ ด้วย คือvariance swap

ขั้นที่ 5 — ห้าวันของ gamma scalping: ประมาณด้วยสูตร

โจทย์ให้อะไรมาบ้าง: ซื้อ call ตัวเดียว หุ้น \$100 strike 100 เหลือ 30 วันทำการ ($\tau=30/252=0.119048$ ปี) ความผันผวนที่จ่าย 20% ดอกเบี้ยศูนย์ hedge ทุกสิ้นวัน หุ้นปิดห้าวันที่ 101.8, 99.5, 99.9, 99.6, 101.7 คือขยับ +1.8, −2.3, +0.4, −0.3, +2.1

\[ \begin{aligned} d_1&=\tfrac12\sigma\sqrt\tau=0.034503,\\ \Gamma&=\frac{\varphi(d_1)}{S\sigma\sqrt\tau}=0.057778,\\ \Theta&=-\frac{0.2^2(100)^2\Gamma}{2(252)}\\ &=-0.045855,\\ \sum_i(\Delta S_i)^2&=13.19,\\ G&=\tfrac12\Gamma(13.19)\\ &=0.381045,\\ 5\Theta&=-0.229277,\\ \Pi&\approx0.151768. \end{aligned} \]

คำตอบ: ประมาณได้ +\$0.1518 ต่อ call ถ้าคิดราคา Black–Scholes ใหม่ทุกวันจริง (อายุลดวันละวัน delta ใหม่ทุกวัน) ได้ +\$0.1496 ต่างกัน 1.5% เพราะ gamma เปลี่ยนไปตามราคาและเวลาระหว่างทาง รายวันจริงคือ +0.0472, +0.1041, −0.0431, −0.0459, +0.0873

ตรวจเองใน 10 วินาที: $d_1$ มาจาก $\ln(S/K)=0$ และ $r=0$ จึงเหลือ $\tfrac12\sigma^2\tau/(\sigma\sqrt\tau)$ ส่วน $\sum(\Delta S_i)^2=3.24+5.29+0.16+0.09+4.41=13.19$

ขั้นที่ 6 — วันไหนได้ วันไหนเสีย: เทียบความผันผวนที่เกิดจริงกับที่จ่าย

วันที่หุ้นขยับเกิน $\sigma_{\rm imp}S\sqrt{\Delta t}$ คือวันที่ได้ ถ้ารวมห้าวันเป็นความผันผวนต่อปี ก็เทียบกับ 20% ที่จ่ายได้ตรง ๆ (ใช้การขยับเป็นดอลลาร์หารด้วย 100 และค่าเฉลี่ยเป็นศูนย์ ซึ่งพอสำหรับห้าวัน)

\[ \begin{aligned} |\Delta S^*|&=\frac{0.20(100)}{\sqrt{252}}=1.2599,\\ \sigma_{\rm real}&=\frac{\sqrt{13.19/5}}{100}\sqrt{252}\\ &=1.6242\%(15.8745)\\ &=25.78\%. \end{aligned} \]

วันที่ 1, 2 และ 5 หุ้นขยับ 1.8, 2.3 และ 2.1 เกินจุดคุ้มทุน จึงได้ วันที่ 3 และ 4 ขยับแค่ 0.4 และ 0.3 จึงเสียค่าเวลาไปเกือบเต็ม ทั้งห้าวันหุ้นแกว่งจริง 25.78% ต่อปี มากกว่า 20% ที่จ่าย ผลรวมจึงเป็นบวก

ถ้าหุ้นแกว่งแค่ 15% ต่อปี ($0.15(100)/\sqrt{252}=0.9449$ ทุกวัน) ห้าวันจะเสีย $5\cdot\tfrac12\Gamma(100)^2(0.0225-0.04)/252=\$0.1003$ ทั้งที่ไม่ได้ทายทิศทางผิดเลยสักวัน

ขั้นที่ 7 — ต้นทุนของการปรับ hedge ทุกวัน

โจทย์ให้อะไรมาบ้าง: การคิดราคาใหม่ทุกวันให้ delta ใหม่ทุกสิ้นวัน ต้องซื้อหรือขายหุ้นเท่าผลต่างของ delta ค่าซื้อขาย 10 bp (0.1%) ของมูลค่าที่ซื้อขาย

\[ \begin{aligned} Q&=0.1030+0.1334+0.0237\\ &\quad+0.0190+0.1296\\ &=0.4087,\\ M&=\sum_i|\Delta\delta_i|\,S_i=41.20,\\ c&=0.001(41.20)=0.0412,\\ \Pi_{\rm net}&=0.1496-0.0412\\ &=0.1084. \end{aligned} \]

คำตอบ: ซื้อขายรวม 0.4087 หุ้น มูลค่า \$41.20 เสียค่าซื้อขาย \$0.0412 หรือ 27.5% ของกำไร \$0.1496 เหลือ \$0.1084 วันที่ขยับมาก (1, 2, 5) ต้องซื้อขายมาก เพราะ delta เปลี่ยนตาม gamma คูณการขยับ

ตรวจเองใน 10 วินาที: วันแรก $\Gamma(1.8)=0.104$ ใกล้ 0.1030 ที่ซื้อขายจริง ถ้าปรับวันละ 4 ครั้ง แต่ละครั้งหุ้นขยับราวครึ่งหนึ่ง ($\sqrt{1/4}$) แต่ปรับสี่เท่า มูลค่าซื้อขายจึงโตราว $4\times\tfrac12=2$ เท่า ต้นทุน 10 bp นี้ยังไม่รวมส่วนต่างราคาเสนอซื้อขายและราคาที่ขยับเพราะคำสั่งของเราเอง ซึ่งหน้าถัดไปจะนับ

ขั้นที่ 8 — สูตรเดินพอร์ตทีละช่วง

ในโลกจริงเรา hedge เป็นช่วง ที่เวลา $t_0\lt t_1\lt\dots\lt t_n=T$ พอร์ตเดินทีละช่วงด้วยสูตรเดียว ถือหุ้น $\delta_i$ หุ้นในช่วงที่ $i$ ส่วนเงินที่เหลือ $V_i-\delta_iS_i$ อยู่ในบัญชีเงินฝาก (ติดลบคือกู้) ช่วงถัดไปพอร์ตได้จากหุ้น เงินปันผลอัตรา $c$ ต่อปี และดอกเบี้ย

\[ \begin{aligned} V_{i+1}&=V_i+\delta_i\big(S_{i+1}-S_i\\ &\qquad+S_ic\,\Delta t\big)\\ &\quad+(V_i-\delta_iS_i)(e^{r\Delta t}-1). \end{aligned} \]

ก้อนแรกคือกำไรของหุ้นที่ถือบวกเงินปันผลที่ได้ ก้อนที่สองคือดอกเบี้ยของเงินในบัญชี ไม่มีพจน์ไหนเป็นเงินที่เติมเข้าหรือดึงออก พอร์ตจึง self-financing แบบเดียวกับพอร์ตเลียนแบบทีละโหนดในต้นไม้ binomial ถ้า $\Delta t$ เข้าใกล้ศูนย์และความผันผวนที่ใช้ถูก $V_n$ จะเท่ากับ payoff ของ option พอดี ถ้าใช้ช่วงห่างหรือความผันผวนผิด $V_n$ ก็แค่ใกล้เคียง แบบฝึกข้างล่างไม่มีปันผล ($c=0$)

ขั้นที่ 9 — แบบฝึก: ขาย call 100,000 ตัว แล้วเลียนแบบด้วยการปรับ 50 ครั้ง

โจทย์ให้อะไรมาบ้าง: หุ้น \$50 call strike 50 อายุ 0.25 ปี ความผันผวน 30% ดอกเบี้ย 2% ต่อปีแบบต่อเนื่อง ขาย call 100,000 ตัว เอาเงินที่ได้สร้างพอร์ตเลียนแบบ ปรับ 50 ครั้ง ห่างกัน $\Delta t=0.005$ ปี (ราว 1.26 วันทำการ) บนเส้นทางราคาหุ้นสมมติ 51 จุดที่จบที่ \$54.4079

\[ \begin{aligned} d_1&=\frac{(0.02+0.045)(0.25)}{0.30(0.5)}\\ &=0.108333,\\ C_0&=27.1567-24.0486\\ &=3.1082,\\ V_0&=100{,}000C_0=310{,}815.12,\\ H_0&=10^5N(d_1)=54{,}313.44,\\ B_0&=V_0-50H_0\\ &=-2{,}404{,}856.67,\\ V_{50}&=496{,}180.85,\\ L&=10^5(54.4079-50)\\ &=440{,}787.27,\\ V_{50}-L&=55{,}393.58. \end{aligned} \]

คำตอบ: เริ่มด้วยเงินค่า call \$310,815.12 ซื้อหุ้นตาม delta 54,313.44 หุ้น ส่วนที่ขาดกู้มา \$2,404,856.67 ช่วงแรกหุ้นลงเป็น 49.5072 พอร์ตเหลือ $54{,}313.44(49.5072)-2{,}404{,}856.67e^{0.0001}=\$283{,}810.38$ แล้วลดหุ้นเหลือ 51,617.07 หุ้นตาม delta ใหม่ ครบ 50 ครั้งพอร์ตมี \$496,180.85 จ่ายตาม call \$440,787.27 เหลือกำไร \$55,393.58

ตรวจเองใน 10 วินาที: ทฤษฎีบอกว่า hedge ที่ปรับต่อเนื่องด้วยความผันผวนที่ถูกควรจบที่ศูนย์ แต่เส้นทางนี้แกว่งจริงแค่ 24.90% ต่อปี (sd ของ log return 50 ช่วง คูณ $\sqrt{200}$ เพราะหนึ่งปีมี 200 ช่วงขนาด 0.005) ต่ำกว่า 30% ที่ขาย คนขายที่ hedge จึงได้ส่วนต่าง ตรงกับการเทียบความผันผวนจริงกับที่จ่ายในมุมกลับ

ขั้นที่ 10 — ปรับถี่ขึ้นความคลาดลดช้า และความผันผวนที่ใช้ผิดเลื่อนผลทั้งก้อน

ถ้าหุ้นแกว่ง 30% ตามที่ขายพอดี hedge ที่ปรับเป็นช่วงก็ยังพลาดทุกช่วง เพราะแต่ละช่วงเป็น $\tfrac12\Gamma_iS_i^2(\ell_i^2-\sigma^2\Delta t)$ เมื่อ $\ell_i$ คือ log return ของช่วงนั้น ถ้า $\ell_i=\sigma\sqrt{\Delta t}\,Z$ ความพลาดต่อช่วงคือ $\tfrac12\Gamma_iS_i^2\sigma^2\Delta t\,(Z^2-1)$ ซึ่ง SD เป็นสัดส่วนกับ $\Delta t$ ช่วงต่าง ๆ อิสระกัน ความแปรปรวนจึงบวกกัน

\[ \begin{aligned} \mathrm{Var}\Big(\sum_{i=1}^{N}e_i\Big)&\propto N\Big(\frac TN\Big)^2=\frac{T^2}{N},\\ \mathrm{SD}&\propto\frac{T}{\sqrt N},\\ \frac{79{,}092}{36{,}722}&=2.15,\quad\sqrt5=2.24,\\ \mathcal V(0.05)&=991{,}520(0.05)\\ &=49{,}576. \end{aligned} \]

รูปถัดไปจำลอง 4,000 เส้นทางที่หุ้นแกว่ง 30% ปรับ 10, 50 และ 250 ครั้ง ได้ SD ของผล \$79,092, \$36,722 และ \$16,621 ค่าเฉลี่ยราวศูนย์ ปรับถี่ขึ้นห้าเท่า SD ลดราว $\sqrt5$ เท่า ไม่ใช่ห้าเท่า โค้ดท้ายหน้าจำลองซ้ำด้วยตัวสุ่มอีกชุดได้ 76,647, 36,251 และ 16,520 ต่างกันราว 3% ซึ่งเป็นความคลาดจากการสุ่ม

ถ้าหุ้นแกว่งจริง 25% แต่ขายและ hedge ด้วย 30% ผลไม่ได้แค่กว้าง แต่เลื่อนทั้งก้อน เฉลี่ย +\$50,288 (โค้ดได้ +\$49,917) ใกล้กับ vega ของทั้งก้อนคูณ 5 จุดคือ \$49,576 กำไร \$55,394 ของแบบฝึกจึงไม่ใช่โชค แต่เป็นผลของความผันผวนที่ต่ำกว่าที่ขาย ความผันผวนที่ผิดยังทำให้ delta ทุกช่วงผิดด้วย hedge จึงไม่ได้เลียนแบบ payoff แม้จะปรับถี่มาก

ขั้นที่ 11 — สี่เส้นทางเพิ่ม: vega บอกทิศ gamma บอกขนาด

ลองหุ้นอีกสี่เส้นทางสมมติ ทางละ 50 ช่วง ขาย call ที่ 30% และ hedge แบบเดียวกันทุกทาง กฎหยาบคือกำไร ≈ vega ของทั้งก้อน คูณส่วนต่างระหว่าง 30% กับความผันผวนจริงของทางนั้น กฎที่ละเอียดกว่าคือบวกความพลาดทีละช่วง ซึ่งถ่วงแต่ละช่วงด้วย dollar gamma ตอนนั้น

\[ \begin{aligned} \mathcal V&=n\,S_0\sqrt T\,\varphi(d_1)\\ &=10^5(50)(0.5)(0.396608)\\ &=991{,}520,\\ \Pi&\approx\mathcal V\,(0.30-\sigma_{\rm real}),\\ g_i&=\tfrac12n\,\Gamma_iS_i^2,\\ \Pi&\approx\sum_{i=0}^{49}g_i\big(0.3^2(0.005)-\ell_i^2\big). \end{aligned} \]

ทางที่ 3 แกว่ง 51.57% กฎ vega ทายว่าเสีย \$213,860 แต่เสียจริงแค่ \$122,867 เพราะสองในสามครั้งที่แกว่งแรงที่สุดเกิดตอนหุ้นอยู่ราว 61 และ 66 ซึ่ง call ลึกใน the money แล้ว gamma เหลือน้อย ($g_i$ ราว 378,000 และ 8,000 เทียบกับ 6.6 ล้านตอนหุ้น 48) การแกว่งสองครั้งนั้นจึงแทบไม่มีราคา

ทางที่ 2 แกว่ง 30.36% แทบเท่า 30% กฎ vega ทายว่าเสียแค่ \$3,564 แต่เสีย \$20,263 เพราะครั้งที่แกว่งแรงที่สุด (+4.98%) เกิดตอนหุ้นอยู่ 50.45 ใกล้ strike และใกล้หมดอายุ ซึ่ง gamma สูง ($g_i$ ราว 14.8 ล้าน) hedge เสียเมื่อหุ้นแกว่งแรงตรงจุดที่ gamma สูง ไม่ใช่แค่เมื่อความผันผวนเฉลี่ยสูง

ขั้นที่ 12 — วันที่หุ้นขยับแรง: Taylor พังและต้องใช้ตาราง scenario

โจทย์ให้อะไรมาบ้าง: ก้อนที่ขาย call 100,000 ตัวของแบบฝึก วันเริ่มต้น hedge delta แล้ว (หุ้น 50, ความผันผวน 30%, อายุ 0.25 ปี) ทั้งก้อนมี gamma 5,288 หุ้นต่อดอลลาร์ และ vega \$991,520 ต่อความผันผวน 1.00 ถามว่าถ้าหุ้นกระโดดทันที ±5%, ±10%, ±20% และความผันผวนอยู่เท่าเดิมหรือขึ้น 5 จุด ได้เสียเท่าไร เทียบสูตรสองพจน์กับการคิดราคาใหม่ทั้งก้อน

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

เรียก delta-neutral ว่าไม่มีความเสี่ยง: หนังสือที่ delta เป็นศูนย์ยังมี gamma, vega, การกระโดด และต้นทุน ก้อน call 1,000 ตัวในโจทย์เปิดหน้าได้ \$62 ในวันที่ราคาปิดเท่าเดิม ถ้าเป็นคนขายก็เสีย \$62

อ่านผลจากราคาปิดอย่างเดียว: เส้นทาง 0, +2, 0, −1, 0 ที่ปรับทุกจุดให้ gamma $\tfrac12(20)(4+4+1+1)=\$100$ ขณะที่เส้นแบนให้ \$0 ทั้งที่ราคาปิดเท่ากัน

ใช้ 365 วันแทน 252 วันทำการในจุดคุ้มทุน: $0.20(100)/\sqrt{365}=1.0468$ แทน 1.2599 จะคิดว่าวันที่หุ้นขยับ \$1.10 เป็นวันที่ได้ ทั้งที่ยังไม่พอจ่ายค่าเวลา

ลืมต้นทุนการปรับ: ตัวอย่างห้าวันเสีย 27.5% ของกำไรไปกับค่าซื้อขาย 10 bp ปรับถี่ขึ้นสี่เท่าจ่ายค่าซื้อขายราวสองเท่า แต่ความคลาดลดแค่สองเท่า โต๊ะจริงจึงมักปรับเมื่อ delta เคลื่อนเกินแถบที่ตั้งไว้ แทนการปรับตามนาฬิกา

ใช้กฎ vega กับเส้นทางที่ gamma เปลี่ยนมาก: ทางที่ 2 กฎ vega บอกเสีย \$3,564 แต่เสียจริง \$20,263 เกือบหกเท่า

ลืมก้อน vega: ถ้า implied volatility ของตลาดขยับ 1 จุด ก้อน call 100,000 ตัวเปลี่ยนมูลค่าราว \$9,915 ทันที โดยหุ้นไม่ต้องขยับเลย

ใช้ทำอะไรบนโต๊ะจริง

รายงานกำไรขาดทุนประจำวันของโต๊ะ option แยกเป็นก้อน delta, gamma, theta และ vega ตาม Taylor ข้างบน ถ้าก้อนที่อธิบายไม่ได้ใหญ่ แปลว่ามีความเสี่ยงที่แบบจำลองไม่เห็น คนขาย option ได้ค่าเวลาทุกวันที่เงียบ และเสียหนักในวันที่หุ้นกระโดด การตัดสินใจซื้อหรือขาย option แล้ว hedge คือการเทียบความผันผวนที่คาดว่าจะเกิดจริงกับ implied ในราคา ขนาดของการเดิมพันคือ vega ของทั้งก้อน และความเสี่ยงหางคือตาราง scenario ไม่ใช่สูตรสองพจน์ (ดูโครงสร้างที่ใช้ซื้อขายความผันผวนในvolatility trading structures)

const {exp, log, sqrt, abs, max, cos, PI} = Math;

// Standard normal CDF from its Taylor series around 0.
function normCdf(x) {
  if (x < -8) return 0;
  if (x > 8) return 1;
  let term = x, sum = x;
  for (let k = 1; k < 300 && abs(term) > 1e-17 * abs(sum); k++) { term *= x * x / (2 * k + 1); sum += term; }
  return 0.5 + sum * exp(-x * x / 2) / sqrt(2 * PI);
}
// Black-Scholes call with delta, gamma, vega (per 1.00 of volatility) and theta per year.
function call(S, K, tau, sigma, r = 0) {
  const d1 = (log(S / K) + (r + sigma * sigma / 2) * tau) / (sigma * sqrt(tau)), d2 = d1 - sigma * sqrt(tau);
  const pdf = exp(-d1 * d1 / 2) / sqrt(2 * PI);
  return {price: S * normCdf(d1) - K * exp(-r * tau) * normCdf(d2), delta: normCdf(d1), d1,
    gamma: pdf / (S * sigma * sqrt(tau)), vega: S * sqrt(tau) * pdf,
    theta: -S * pdf * sigma / (2 * sqrt(tau)) - r * K * exp(-r * tau) * normCdf(d2)};
}
// Delta-hedge n calls along a price path (steps of dt years); sign = -1 for the seller.
function hedgePath({path, K, T, sigma, r = 0, n = 1, sign = 1, dt}) {
  const o = call(path[0], K, T, sigma, r);
  let hold = n * o.delta, cash = n * o.price - hold * path[0], turnover = 0;
  for (let i = 1; i < path.length; i++) {
    cash *= exp(r * dt);
    const tau = T - i * dt;
    if (tau > 1e-12) {
      const next = n * call(path[i], K, tau, sigma, r).delta;
      turnover += abs(next - hold) * path[i];
      cash -= (next - hold) * path[i]; hold = next;
    }
  }
  const S = path[path.length - 1], tau = T - (path.length - 1) * dt;
  const optionValue = tau > 1e-12 ? n * call(S, K, tau, sigma, r).price : n * max(S - K, 0);
  return {pnl: sign * (optionValue - (hold * S + cash)), turnover};
}
function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}

// Instant scenarios on the hedged short book: two-term formula versus full repricing.
const scenario = dv => [-0.2, -0.1, -0.05, 0.05, 0.1, 0.2].map(m => {
  const dS = 50 * m;
  return {move: m, approx: -(0.5 * 1e5 * c0.gamma * dS * dS + 1e5 * c0.vega * dv),
    exact: -1e5 * (call(50 + dS, 50, 0.25, 0.30 + dv, 0.02).price - c0.price - c0.delta * dS)};
});

// Discrete hedging error on 4,000 simulated paths.
function simulate(steps, trueSigma, paths = 4000, seed = 1) {
  const rnd = mulberry32(seed), dt = 0.25 / steps, out = [];
  for (let m = 0; m < paths; m++) {
    const path = [50];
    for (let i = 0; i < steps; i++) {
      const z = sqrt(-2 * log(rnd() || 1e-12)) * cos(2 * PI * rnd());
      path.push(path[i] * exp((0.02 - trueSigma ** 2 / 2) * dt + trueSigma * sqrt(dt) * z));
    }
    out.push(hedgePath({path, ...book, dt}).pnl);
  }
  const avg = out.reduce((a, b) => a + b, 0) / paths;
  return {mean: avg, sd: sqrt(out.reduce((a, b) => a + (b - avg) ** 2, 0) / (paths - 1))};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • หลัง hedge แล้ว $\Delta\Pi\approx\tfrac12\Gamma(\Delta S)^2+\Theta\Delta t$ เป็นพาราโบลาของการขยับ ราคาปิดเท่าเดิมก็ยังได้ \$62 ถ้าหุ้นแกว่งระหว่างวัน
  • เมื่อดอกเบี้ยเป็นศูนย์ $\Theta=-\tfrac12\sigma_{\rm imp}^2S^2\Gamma$ จึงเป็นการเดิมพันความผันผวนจริงเทียบกับที่จ่าย และจุดคุ้มทุนต่อวันคือ $\sigma_{\rm imp}S/\sqrt{252}$
  • ห้าวันที่หุ้นแกว่ง 25.78% เทียบ 20% ที่จ่าย ได้ \$0.1518 ตามสูตร \$0.1496 เมื่อคิดราคาใหม่จริง และเสีย 27.5% ให้ค่าซื้อขาย
  • แบบฝึก 100,000 ตัวได้ \$55,393.58 เพราะเส้นทางแกว่งแค่ 24.90% ปรับถี่ขึ้นห้าเท่าลดความคลาดแค่ราว $\sqrt5$ เท่า และ gamma ตอนที่หุ้นแกว่งบอกขนาดของผล
  • วันที่หุ้นกระโดด 20% สูตรสองพจน์พลาดเป็นหมื่นดอลลาร์และไม่เห็นความไม่สมมาตร ต้องใช้ตาราง scenario ที่คิดราคาใหม่ทั้งก้อน
