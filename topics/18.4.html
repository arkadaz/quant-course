18.4 Delta Hedging P&L

หลัง delta hedge ทิศทางของหุ้นไม่มีผลกับเงินอีก สิ่งที่เหลือคือ gamma กับ theta และสองตัวนี้รวมกันเป็นการเดิมพันว่า หุ้นจะแกว่งจริงมากกว่าที่ราคา option คิดไว้หรือไม่

โต๊ะเทรด option ของธนาคาร (ทีมที่ซื้อขาย option ทั้งวัน) ถือ call ของหุ้นตัวหนึ่งไว้ call คือสิทธิ์ซื้อหุ้นในอนาคตที่ราคาตกลงไว้ หุ้นยิ่งขึ้น call ก็ยิ่งมีค่า เมื่อหุ้นขยับนิดเดียว call หนึ่งตัวขึ้นลงเหมือนถือหุ้นอยู่จำนวนหนึ่ง จำนวนหุ้นนี้เรียกว่า delta

โต๊ะไม่อยากเดิมพันว่าหุ้นจะขึ้นหรือลง จึงทำ delta hedge คือขายชอร์ตหุ้น (ยืมหุ้นมาขาย) เท่ากับ delta ของ call ทั้งหมด การขยับเล็ก ๆ ของ call จึงถูกหักล้างพอดี แต่พอหุ้นขยับ delta ก็เปลี่ยน โต๊ะจึงต้องซื้อขายหุ้นปรับตามไปเรื่อย ๆ

ของที่รู้ (ตัวเลขสมมติ):

  • จำนวน call $n=1{,}000$ ตัว
  • gamma ต่อตัว $\Gamma=0.020$ คืออัตราที่ delta เปลี่ยน หุ้นขึ้น \$1 delta ของ call หนึ่งตัวจะเพิ่ม 0.020 หุ้น
  • ค่าเวลา (theta) ของทั้งพอร์ต \$18 ต่อวัน คือถ้าหุ้นไม่ขยับเลย call ทั้งหมดจะเสียมูลค่ารวมวันละ \$18 เพราะเวลาเหลือน้อยลง
  • วันนี้หุ้นเปิดที่ \$100 ขึ้นไปถึง \$102 แล้วกลับลงมาปิดที่ \$100

หัวหน้าถามว่าวันนี้ได้หรือเสียเท่าไร ผู้ช่วยตอบว่า “ราคาปิดเท่าเดิม และเรา hedge แล้ว จึงเสียแค่ค่าเวลา \$18” ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก วันนี้ได้ \$62 ขั้นที่ 1 จะเดินตามทีละคำสั่งอย่างละเอียด สรุปสั้น ๆ คือ ตอนหุ้นขึ้นไปถึง \$102 delta ของ call ทั้งพอร์ตเพิ่มขึ้น 40 หุ้น hedge จึงต้องขายหุ้นเพิ่มอีก 40 หุ้นที่ \$102 ตอนหุ้นกลับมา \$100 delta ลดกลับเท่าเดิม จึงซื้อ 40 หุ้นนั้นคืนที่ \$100:

\[\begin{aligned}\text{shares}&=1{,}000\times0.020\times2=40,\\G&=40\times(102-100)=\$80,\\\Pi&=80-18=\$62.\end{aligned}\]

$G$ คือเงินจากการขายแพงซื้อถูก และ $\Pi$ คือเงินสุทธิของวัน ราคาปิดบอกไม่ได้ว่า hedge ได้เสียเท่าไร เส้นทางของราคาระหว่างวันต่างหากที่บอก

ภาพรวมก่อนลงสูตร

ในโลกของตำรา hedge ทำงานได้สมบูรณ์ ต้นไม้ binomial แสดงว่า ถ้าปรับจำนวนหุ้นกับเงินกู้ทุกกิ่งของต้นไม้ พอร์ตจะเลียนแบบ option ได้ครบทุกเส้นทาง สมการ Black–Scholes ทำแบบเดียวกันในเวลาต่อเนื่อง ผลคือ option บวก hedge ได้เสียเป็นศูนย์

โต๊ะจริงต่างจากตำราสามเรื่อง:

  • ปรับ hedge ได้เป็นช่วง เช่นวันละครั้ง ไม่ใช่ทุกเสี้ยววินาที
  • ราคาหุ้นไม่ได้ขยับตามแบบจำลองเป๊ะ ๆ บางวันกระโดดแรง
  • ความผันผวนที่ใช้ตั้งราคา option (ขนาดการแกว่งของหุ้นที่ราคา option คิดไว้) ไม่เท่ากับที่หุ้นแกว่งจริง

ดังนั้นหลัง hedge แล้วยังมีเงินได้เสียอยู่ หน้านี้นับว่าเงินนั้นมาจากไหน

คำตอบสั้นอยู่ในรูปด้านล่าง หลัง hedge delta แล้ว กำไรขาดทุนหนึ่งวันเป็นพาราโบลาของขนาดที่หุ้นขยับ ส่วนที่โค้งขึ้นคือเงินจาก gamma ซึ่งได้ทั้งตอนหุ้นขึ้นและตอนหุ้นลง ส่วนที่กดพาราโบลาลงใต้ศูนย์คือ theta ที่จ่ายทุกวัน หุ้นจึงต้องขยับเกินจุดคุ้มทุนก่อนจึงจะได้ หน้านี้จะแสดงว่าจุดคุ้มทุนนั้นมาจากความผันผวนที่จ่ายไปในราคา option พอดี

ลำดับของหน้านี้:

  • เดินตามคำสั่งซื้อขายของโจทย์เปิดหน้าด้วยมือ
  • กาง Taylor ของราคา option แล้วเลือกพจน์ที่ต้องเก็บ
  • ใช้สมการ Black–Scholes แสดงว่า theta คือราคาที่จ่ายเพื่อซื้อ gamma
  • ไล่ตัวอย่างห้าวัน แล้วนับต้นทุนการซื้อขาย
  • ใช้แบบฝึกขาย call 100,000 ตัว ดูผลของความถี่ในการปรับ ความผันผวนที่ใช้ผิด และจังหวะที่หุ้นแกว่ง
  • ดูวันที่หุ้นขยับแรงจน Taylor ใช้ไม่ได้
ศัพท์ที่ใช้ในหัวข้อนี้
Call และ strike
call คือสิทธิ์ซื้อหุ้นหนึ่งหุ้นในวันหมดอายุที่ราคาตกลงไว้ ราคาตกลงนี้เรียกว่า strike $K$ วันหมดอายุ call จ่าย $\max(S_T-K,\,0)$ เงินที่จ่ายนี้เรียกว่า payoff คนขาย call ต้องเป็นคนจ่ายเงินก้อนนี้
ชอร์ต (short)
ยืมหุ้นมาขายก่อน แล้วซื้อคืนทีหลัง ถือหุ้นติดลบ หุ้นลงจึงได้ หุ้นขึ้นจึงเสีย
Delta และ delta hedge
delta คือ option ขึ้นกี่ดอลลาร์เมื่อหุ้นขึ้น \$1 หรือเท่ากับจำนวนหุ้นที่ option ทำตัวเหมือนถืออยู่ delta hedge คือชอร์ตหุ้นเท่ากับ delta เพื่อให้พอร์ตไม่ได้ไม่เสียเมื่อหุ้นขยับนิดเดียว ต้องปรับจำนวนหุ้นใหม่เรื่อย ๆ เพราะ delta เปลี่ยนตามราคาหุ้นและเวลา
Gamma และ theta
gamma คือ delta เปลี่ยนเท่าไรเมื่อหุ้นขยับ \$1 theta คือมูลค่าที่ option เสียไปเมื่อเวลาผ่านไปโดยหุ้นไม่ขยับ สองตัวนี้คือสิ่งที่เหลือหลัง hedge (นิยามเต็มอยู่ในหน้าthe Greeks)
Implied และ realized volatility
implied volatility คือความผันผวนที่ต้องใส่ในสูตร Black–Scholes แล้วได้ราคาตลาดพอดี เป็นการแกว่งที่ “จ่ายไป” ในราคา option realized volatility คือความผันผวนที่หุ้นแกว่งจริงในช่วงที่ถือ เป็นการแกว่งที่ “ได้มา” ทั้งสองตัววัดเป็น SD (standard deviation) ของผลตอบแทนต่อปี
Gamma scalping
ถือ option แล้ว hedge ไปเรื่อย ๆ การ hedge บังคับให้ขายหุ้นตอนหุ้นขึ้นและซื้อตอนหุ้นลง กำไรจากการขายแพงซื้อถูกนี้คือเงินของ gamma
Vega
อัตราที่ราคา option เปลี่ยนเมื่อความผันผวนเปลี่ยน คิดต่อความผันผวน 1.00 (100 จุด) ใช้งานจริงจึงคูณด้วยการขยับจริง เช่นคูณ 0.05 เมื่อความผันผวนขึ้น 5 จุด vega บอกขนาดของการเดิมพันความผันผวนเป็นเงิน
จุดความผันผวน
ความผันผวนขยับ 1 จุด คือขยับ 1 percentage point เช่นจาก 30% เป็น 31% หรือ 0.01
Dollar delta และ dollar gamma
dollar delta คือ $\Delta\cdot S$ คือมูลค่าหุ้นที่ option ทำตัวเหมือนถืออยู่ dollar gamma คือ $\tfrac12\Gamma S^2$ คือเงินที่ได้ต่อผลตอบแทนยกกำลังสองหนึ่งหน่วย สองตัวนี้วัดเป็นดอลลาร์ จึงบวกกันได้ข้าม option หลายตัวบนหุ้นที่ราคาต่างกัน
In the money
call ที่หุ้นอยู่สูงกว่า strike “ลึกใน the money” คือหุ้นสูงกว่า strike มากจนเกือบแน่นอนว่าต้องจ่าย call แบบนี้ทำตัวเหมือนหุ้นหนึ่งหุ้น delta ใกล้ 1 และ gamma ใกล้ศูนย์
Basis point (bp)
หนึ่งในร้อยของหนึ่งเปอร์เซ็นต์ 10 bp จึงเท่ากับ 0.1%
Self-financing
พอร์ตที่ปรับได้โดยไม่เติมเงินเข้าและไม่ดึงเงินออก เงินซื้อหุ้นเพิ่มมาจากบัญชีเงินฝากหรือเงินกู้ของพอร์ตเอง เงื่อนไขนี้ทำให้เงินตอนเริ่มคือต้นทุนทั้งหมด

ขั้นที่ 1 — เดินตามคำสั่งซื้อขายด้วยมือ: 100 ไป 102 แล้วกลับ 100

ก่อนมีสูตร ลองทำตามที่มือของคน hedge ต้องทำจริงในวันของโจทย์เปิดหน้า กฎมีข้อเดียว: ตลอดวัน ต้องชอร์ตหุ้นเท่ากับ delta ของ call ทั้งพอร์ตเสมอ วันนี้ปรับสองครั้ง คือตอนหุ้นขึ้นถึง \$102 และตอนหุ้นกลับมา \$100

ก่อนอื่นต้องรู้ว่า delta ของทั้งพอร์ตเปลี่ยนเท่าไร gamma ของทั้งพอร์ต $\Gamma_{\rm book}$ คือจำนวน call คูณ gamma ต่อตัว แล้วคูณกับการขยับของหุ้นจะได้การเปลี่ยนของ delta $\Delta$ (ตัวห้อยคือราคาหุ้นตอนนั้น):

\[ \begin{aligned} \Gamma_{\rm book}&=1{,}000\times0.020=20,\\ \Delta_{102}-\Delta_{100}&=20\times2=40\ \text{shares},\\ G&=40\times(102-100)=\$80,\\ \Pi&=G-18=80-18=\$62. \end{aligned} \]

ตอนหุ้นถึง \$102 delta ของ call ทั้งพอร์ตเพิ่ม 40 หุ้น ถ้าไม่ทำอะไร พอร์ตจะเหมือนถือหุ้นเกินมา 40 หุ้น จึงต้องขายชอร์ตเพิ่ม 40 หุ้นที่ \$102 ตอนหุ้นกลับมา \$100 delta ลดกลับ 40 หุ้น จึงซื้อ 40 หุ้นนั้นคืนที่ \$100 ขายแพงซื้อถูกได้ $G=\$80$ โดยไม่ต้องทายทิศทางเลย ส่วน call กลับมามีค่าเท่าเดิม (ไม่นับค่าเวลา) เพราะหุ้นกลับมาที่เดิม

เงิน \$80 นี้คิดอีกทางได้จากความโค้งของราคา option สูตร $\tfrac12\Gamma(\Delta S)^2$ ให้เงินขาละ $\tfrac12(20)(2)^2=\$40$ ขาขึ้นกับขาลงรวมกันได้ $2\times40=\$80$ เท่ากันพอดี ขั้นถัดไปจะแสดงว่าสูตรนี้มาจากไหน ส่วนค่าเวลา \$18 ต้องจ่ายทุกวัน ไม่ว่าหุ้นจะแกว่งหรือไม่

ขั้นที่ 2 — กาง Taylor ของราคา option แล้วเลือกว่าจะเก็บพจน์ไหน

ขั้นที่ 1 ใช้สูตร $\tfrac12\Gamma(\Delta S)^2$ โดยยังไม่ได้บอกว่ามาจากไหน ขั้นนี้หาที่มา ราคา option $V(S,t)$ ขึ้นกับสองอย่าง คือราคาหุ้น $S$ และเวลา $t$ เมื่อหุ้นขยับ $\Delta S$ และเวลาผ่านไป $\Delta t$ ราคา option จะเปลี่ยนไป $\Delta V$ เครื่องมือที่ใช้แยกการเปลี่ยนนี้เป็นชิ้น ๆ คือ Taylor สองตัวแปร กางถึงอันดับสอง ($V_S$ คืออนุพันธ์ของ $V$ เทียบ $S$ และ $V_{SS}$, $V_t$, $V_{St}$, $V_{tt}$ ก็อ่านแบบเดียวกัน):

\[ \begin{aligned} \Delta V&=V_S\Delta S+V_t\Delta t\\ &\quad+\tfrac12V_{SS}(\Delta S)^2\\ &\quad+V_{St}\Delta S\,\Delta t\\ &\quad+\tfrac12V_{tt}(\Delta t)^2+\cdots \end{aligned} \]

พจน์ไหนเล็กพอจะทิ้งได้ ต้องดูขนาดจริงในหนึ่งวัน ใช้ตัวเลขของโจทย์เปิดหน้า หุ้นขยับ $\Delta S=\$2$ และหนึ่งวันคือ $\Delta t=1/252$ ปี เพราะตลาดหุ้นสหรัฐฯ เปิดทำการราว 252 วันต่อปี (ปีหนึ่งมี 365 วัน ลบเสาร์อาทิตย์ 104 วัน และวันหยุดตลาดราว 9 วัน $365-104-9=252$) หุ้นขยับเฉพาะวันที่ตลาดเปิด:

\[ \begin{aligned} (\Delta S)^2&=2^2=4,\\ \Delta S\,\Delta t&=2\times\tfrac{1}{252}=0.0079,\\ (\Delta t)^2&=\big(\tfrac{1}{252}\big)^2=0.0000157. \end{aligned} \]

ใน calculus ปกติ เราทิ้งพจน์อันดับสองทั้งหมด แต่ที่นี่ทิ้ง $(\Delta S)^2$ ไม่ได้ เพราะมันใหญ่กว่า $\Delta S\,\Delta t$ ราว $4/0.0079\approx500$ เท่า เหตุผลคือหุ้นขยับตามรากที่สองของเวลา ไม่ใช่ตามเวลา (สมบัติของ Brownian motion) ในช่วงสั้น $\Delta t$ หุ้นขยับราว $\sqrt{\Delta t}$ ดังนั้น $(\Delta S)^2$ มีขนาดราว $\Delta t$ เท่ากับพจน์ theta ส่วนพจน์ที่มี $\Delta t$ คูณอยู่ด้วยเล็กกว่านั้นมาก จึงเก็บ $(\Delta S)^2$ และทิ้ง $\Delta S\,\Delta t$ กับ $(\Delta t)^2$

พจน์ที่เหลือมีชื่อตามthe Greeks คือ $V_S=\Delta$ (delta), $V_{SS}=\Gamma$ (gamma) และ $V_t=\Theta$ (theta) แล้วเติมอีกพจน์หนึ่ง คือ vega $\mathcal V$ คูณการขยับของความผันผวน $\Delta\sigma$ เพราะ implied volatility ที่ตลาดใช้ตั้งราคาก็ขยับทุกวัน บรรทัดล่างเขียนสูตรเดิมใหม่ด้วยผลตอบแทน $\Delta S/S$ แทนการขยับเป็นดอลลาร์:

\[ \begin{aligned} \Delta V&\approx\Delta\cdot\Delta S+\tfrac12\Gamma(\Delta S)^2\\ &\quad+\Theta\,\Delta t+\mathcal V\,\Delta\sigma,\\ \Delta V&\approx(\Delta\cdot S)\,\frac{\Delta S}{S}\\ &\quad+\tfrac12\Gamma S^2\Big(\frac{\Delta S}{S}\Big)^2+\cdots \end{aligned} \]

บรรทัดล่างได้จากการคูณและหารด้วย $S$ เท่านั้น เช่น $\Delta\cdot\Delta S=(\Delta\cdot S)(\Delta S/S)$ ประโยชน์คือตัวคูณที่ได้มีหน่วยเป็นดอลลาร์ $\Delta\cdot S$ คือ dollar delta และ $\tfrac12\Gamma S^2$ คือ dollar gamma เมื่อพอร์ตมี option หลายตัวบนหุ้นที่ราคาต่างกัน ตัวคูณที่เป็นดอลลาร์บวกกันได้ตรง ๆ สูตรนี้จึงใช้กับพอร์ต option ทั้งพอร์ตได้ ข้อควรระวังคือ การทิ้งพจน์ใช้ได้เมื่อหุ้นขยับไม่มาก วันที่หุ้นกระโดดแรงจะใช้ไม่ได้ (ขั้นที่ 12)

ขั้นที่ 3 — หักขาหุ้นออก พจน์ทิศทางหายไปพอดี

ตอนนี้รู้แล้วว่า option ตัวเดียวเปลี่ยนค่าอย่างไร ขั้นนี้ใส่ขาหุ้นของ hedge เข้าไปด้วย เพื่อดูว่าพอร์ตทั้งชุดเหลืออะไร พอร์ตที่ hedge แล้วคือ option หนึ่งตัวกับหุ้นที่ชอร์ตไว้ $\Delta$ หุ้น ถ้าหุ้นขยับ $\Delta S$ ขาหุ้นได้เสีย $-\Delta\cdot\Delta S$ (ชอร์ตจึงติดลบ) ให้ความผันผวนคงที่ ($\Delta\sigma=0$) แล้วรวมสองขา:

\[ \begin{aligned} \Delta\Pi&=\Delta V-\Delta\cdot\Delta S\\ &=\tfrac12\Gamma(\Delta S)^2+\Theta\,\Delta t. \end{aligned} \]

พจน์ $\Delta\cdot\Delta S$ ของ option กับของหุ้นหักกันหมด นี่คือความหมายทั้งหมดของ delta hedge พอร์ตไม่สนว่าหุ้นขึ้นหรือลงอีกแล้ว สิ่งที่เหลือมีสองชิ้น ชิ้นแรกคือความโค้ง $\tfrac12\Gamma(\Delta S)^2$ ซึ่งเป็นบวกเสมอ เพราะ $(\Delta S)^2$ ไม่ติดลบ ชิ้นที่สองคือค่าเวลา $\Theta\,\Delta t$ ซึ่งติดลบทุกวัน ผลรวมคือพาราโบลาในรูปภาพรวม

ลองใส่ตัวเลขของโจทย์เปิดหน้า แต่คราวนี้หุ้นขยับ \$2 ในวันเดียวแล้วไม่กลับ gamma ของทั้งพอร์ตคือ 20 และค่าเวลาทั้งพอร์ตคือ \$18 ต่อวัน แล้วหาจุดคุ้มทุน $x$ คือการขยับที่ทำให้เงินจาก gamma เท่ากับค่าเวลาพอดี:

\[ \begin{aligned} G&=\tfrac12(20)(2)^2=\$40,\\ \Pi&=40-18=\$22,\\ \tfrac12(20)x^2&=18,\\ x^2&=18/10=1.8,\\ x&=\sqrt{1.8}=\$1.3416. \end{aligned} \]

พอร์ตนี้ต้องให้หุ้นขยับอย่างน้อย \$1.3416 ต่อวัน ขึ้นหรือลงก็ได้ เงินจาก gamma จึงจะพอจ่ายค่าเวลา ถ้าขยับน้อยกว่านั้นจะขาดทุน นี่คือจุดดำสองจุดในรูปภาพรวม

ขั้นที่ 4 — theta คือราคาที่จ่ายเพื่อซื้อ gamma

ในโจทย์เปิดหน้า ค่าเวลา \$18 ต่อวันเป็นตัวเลขที่ให้มาเฉย ๆ ขั้นนี้ถามว่า ทำไมต้องเป็น \$18 ไม่ใช่ตัวเลขอื่น คำตอบอยู่ในสมการ Black–Scholes ซึ่งผูก theta, gamma และ delta ไว้ด้วยกัน:

\[ \Theta+\tfrac12\sigma^2S^2\Gamma+rS\Delta-rV=0 \]

ในสมการนี้ $r$ คืออัตราดอกเบี้ยต่อปี และ $\sigma$ คือความผันผวนที่ใช้ตั้งราคา option ซึ่งหน้านี้เรียกว่า $\sigma_{\rm imp}$ (implied volatility) ถ้าดอกเบี้ยเป็นศูนย์ สองพจน์ที่มี $r$ หายไป เหลือ theta ผูกกับ gamma ตรง ๆ แล้วแทน $\Theta$ นี้ลงในกำไรขาดทุนของพอร์ตที่ hedge แล้วจากขั้นที่ 3:

\[ \begin{aligned} \Theta&=-\tfrac12\sigma_{\rm imp}^2S^2\Gamma,\\ \Delta\Pi&=\tfrac12\Gamma(\Delta S)^2\\ &\quad-\tfrac12\sigma_{\rm imp}^2S^2\Gamma\,\Delta t\\ &=\tfrac12\Gamma S^2\Big[\big(\tfrac{\Delta S}{S}\big)^2\\ &\qquad-\sigma_{\rm imp}^2\Delta t\Big],\\ |\Delta S^*|&=\sigma_{\rm imp}S\sqrt{\Delta t}. \end{aligned} \]

รูปที่มีวงเล็บได้จากการดึง $\tfrac12\Gamma S^2$ ออกมาเป็นตัวร่วม ในวงเล็บเหลือการเทียบของสองอย่าง $(\Delta S/S)^2$ คือผลตอบแทนยกกำลังสองที่หุ้นแกว่งจริงในวันนั้น $\sigma_{\rm imp}^2\Delta t$ คือความแปรปรวนของผลตอบแทนหนึ่งวันที่จ่ายไปในราคา option (ความแปรปรวนคือ SD ยกกำลังสอง และ SD หรือ standard deviation คือขนาดการแกว่งตามปกติรอบค่าเฉลี่ย) ถ้าหุ้นแกว่งจริงมากกว่าที่จ่าย ได้เงิน ถ้าน้อยกว่า เสียเงิน

จุดคุ้มทุน $|\Delta S^*|$ คือจุดที่วงเล็บเป็นศูนย์ คือ $(\Delta S/S)^2=\sigma_{\rm imp}^2\Delta t$ ถอดรากแล้วคูณ $S$ ได้บรรทัดสุดท้าย แปลว่าจุดคุ้มทุนคือการขยับหนึ่ง SD ของหนึ่งวัน ตามความผันผวนที่จ่ายไป ส่วนตัวคูณข้างหน้า $\tfrac12\Gamma S^2$ คือ dollar gamma ซึ่งแปลงส่วนต่างในวงเล็บเป็นดอลลาร์

ทีนี้อ่านโจทย์เปิดหน้ากลับทาง ค่าเวลาทั้งพอร์ตหนึ่งวันคือ $\tfrac12\sigma_{\rm imp}^2S^2\Gamma_{\rm book}\Delta t=\$18$ โดย $\Gamma_{\rm book}=20$, $S=\$100$ และ $\Delta t=1/252$ ย้ายข้างสมการเพื่อแก้หา $\sigma_{\rm imp}^2$ (คูณสองข้างด้วย $2\times252$ แล้วหารด้วย $\Gamma_{\rm book}S^2$) จะได้ว่าตลาดตั้งราคา option นี้ไว้ที่ความผันผวนเท่าไร:

\[ \begin{aligned} \sigma_{\rm imp}^2&=\frac{2\times18\times252}{20\times100^2}\\ &=\frac{9{,}072}{200{,}000}=0.04536,\\ \sigma_{\rm imp}&=\sqrt{0.04536}=0.21298\\ &=21.30\%,\\ |\Delta S^*|&=\frac{0.21298\times100}{\sqrt{252}}\\ &=\frac{21.298}{15.875}=\$1.3416. \end{aligned} \]

ค่าเวลา \$18 ต่อวันกับ gamma ทั้งพอร์ต 20 ที่หุ้น \$100 จึงแปลว่า ตลาดตั้งราคา option นี้ที่ความผันผวน 21.30% ต่อปี และจุดคุ้มทุนที่คิดจากความผันผวนนี้ได้ \$1.3416 ตรงกับที่ขั้นที่ 3 หาไว้จากอีกทาง ค่าเวลาจึงไม่ใช่ตัวเลขลอย ๆ มันคือราคาที่จ่ายเพื่อได้ gamma มา

ถ้าหุ้นแกว่งจริงด้วยความผันผวน $\sigma_{\rm real}$ ผลตอบแทนยกกำลังสองจะเฉลี่ยวันละ $(\Delta S/S)^2=\sigma_{\rm real}^2\Delta t$ ใส่ลงในวงเล็บจะได้เงินเฉลี่ยต่อวัน ลองกรณีสมมติที่ตลาดตั้งราคาที่ 20% แต่หุ้นแกว่งจริง 30% กับพอร์ตเดิม:

\[ \begin{aligned} \overline{\Delta\Pi}&=\tfrac12\Gamma S^2\,\Delta t\\ &\quad\times\big(\sigma_{\rm real}^2-\sigma_{\rm imp}^2\big),\\ \tfrac12\Gamma S^2&=\tfrac12(20)(100)^2=100{,}000,\\ \overline{\Delta\Pi}&=\frac{100{,}000\,(0.3^2-0.2^2)}{252}\\ &=\frac{100{,}000\times0.05}{252}=\$19.84. \end{aligned} \]

$\overline{\Delta\Pi}$ คือเงินเฉลี่ยต่อวัน พอร์ตนี้ได้วันละราว \$19.84 โดยไม่ต้องทายทิศทางของหุ้นเลย สิ่งที่ทายคือหุ้นจะแกว่งแรงกว่าที่ราคา option คิดไว้ การซื้อ option แล้ว hedge จึงเป็นการซื้อความผันผวน ตลาดมีสัญญาที่ซื้อขายเรื่องนี้ตรง ๆ ด้วย คือvariance swap

ขั้นที่ 5 — ห้าวันของ gamma scalping: ประมาณด้วยสูตร

สูตรพาราโบลาใช้กับวันเดียว ขั้นนี้ลองใช้กับหลายวันติดกัน แล้วเทียบกับการคิดราคาใหม่จริงทุกวัน เพื่อดูว่าสูตรแม่นแค่ไหน

โจทย์ให้อะไรมาบ้าง: นักเทรดซื้อ call ตัวเดียวแล้ว hedge delta ทุกสิ้นวัน ตัวเลขทั้งหมดสมมติ:

  • ราคาหุ้นวันนี้ $S=\$100$ และ strike $K=\$100$ (call ที่ strike เท่าราคาหุ้นพอดี)
  • อายุที่เหลือ 30 วันทำการ คิดเป็นปีได้ $\tau=30/252=0.119048$ ปี
  • ความผันผวนที่จ่ายไปในราคา $\sigma=20\%$ และดอกเบี้ย $r=0$
  • ราคาปิดห้าวันถัดไป 101.8, 99.5, 99.9, 99.6, 101.7 คือหุ้นขยับ $\Delta S_i$ = +1.8, −2.3, +0.4, −0.3, +2.1 ดอลลาร์

ขั้นแรกหา gamma ของ call จากสูตร Black–Scholes ต้องใช้ตัวช่วย $d_1=\dfrac{\ln(S/K)+(r+\tfrac12\sigma^2)\tau}{\sigma\sqrt\tau}$ เพราะ $S=K$ จึงได้ $\ln(S/K)=0$ และเพราะ $r=0$ จึงเหลือ $\tfrac12\sigma^2\tau/(\sigma\sqrt\tau)=\tfrac12\sigma\sqrt\tau$ ส่วน $\varphi$ คือความสูงของรูประฆัง Normal มาตรฐาน $\varphi(x)=e^{-x^2/2}/\sqrt{2\pi}$:

\[ \begin{aligned} \sqrt\tau&=\sqrt{0.119048}=0.345033,\\ d_1&=\tfrac12(0.20)(0.345033)=0.034503,\\ \varphi(d_1)&=0.398705,\\ \Gamma&=\frac{\varphi(d_1)}{S\sigma\sqrt\tau}=\frac{0.398705}{6.900656}\\ &=0.057778. \end{aligned} \]

ต่อมาหาค่าเวลาหนึ่งวันจากขั้นที่ 4 คือ $\Theta\,\Delta t=-\tfrac12\sigma^2S^2\Gamma/252$ แล้วรวมห้าวันด้วยสูตรพาราโบลา โดยถือว่า gamma คงที่ตลอดห้าวัน:

\[ \begin{aligned} \Theta\,\Delta t&=-\frac{0.2^2(100)^2(0.057778)}{2\times252}\\ &=-0.045855,\\ \textstyle\sum_i(\Delta S_i)^2&=3.24+5.29+0.16\\ &\quad+0.09+4.41=13.19,\\ G&=\tfrac12(0.057778)(13.19)\\ &=0.381045,\\ 5\,\Theta\,\Delta t&=5(-0.045855)=-0.229277,\\ \Pi&\approx0.381045-0.229277\\ &=0.151768. \end{aligned} \]

คำตอบ: สูตรประมาณได้ +\$0.1518 ต่อ call ถ้าคิดราคา Black–Scholes ใหม่จริงทุกวัน (อายุลดลงวันละหนึ่งวัน และใช้ delta ใหม่ทุกวัน) โค้ดท้ายหน้าได้ +\$0.1496 ต่างกัน $(0.1518-0.1496)/0.1496\approx1.5\%$ ที่ต่างเพราะ gamma ไม่ได้คงที่จริง มันเปลี่ยนตามราคาหุ้นและเวลาระหว่างทาง ผลรายวันจริงจากโค้ดคือ +0.0472, +0.1041, −0.0431, −0.0459, +0.0873 รวมกันได้ 0.1496

ตรวจเองใน 10 วินาที: วันที่ 2 หุ้นขยับมากที่สุด (2.3) และได้มากที่สุด (+0.1041) วันที่ 3 และ 4 หุ้นแทบไม่ขยับ จึงเสียเกือบเท่าค่าเวลาเต็มวัน 0.0459

ขั้นที่ 6 — วันไหนได้ วันไหนเสีย: เทียบความผันผวนที่เกิดจริงกับที่จ่าย

ผลห้าวันเป็นบวก แต่บางวันได้ บางวันเสีย ขั้นนี้แยกให้เห็นว่าวันไหนเป็นอย่างไร และทำไมผลรวมจึงเป็นบวก จากขั้นที่ 4 วันที่หุ้นขยับเกินจุดคุ้มทุน $\sigma_{\rm imp}S\sqrt{\Delta t}$ คือวันที่ได้ ส่วนการดูภาพรวมห้าวัน ให้แปลงการขยับทั้งห้าวันเป็นความผันผวนต่อปี แล้วเทียบกับ 20% ที่จ่ายไปตรง ๆ

วิธีแปลงแบบหยาบที่พอสำหรับห้าวัน: เฉลี่ยการขยับยกกำลังสอง ถอดราก ได้การขยับต่อวันเป็นดอลลาร์ หารด้วยราคาหุ้น \$100 ให้เป็นสัดส่วน แล้วคูณ $\sqrt{252}$ เพื่อแปลงจากต่อวันเป็นต่อปี (ความแปรปรวนของ 252 วันบวกกัน SD จึงโตตาม $\sqrt{252}$) วิธีนี้ถือว่าค่าเฉลี่ยของการขยับเป็นศูนย์:

\[ \begin{aligned} |\Delta S^*|&=\frac{0.20\times100}{\sqrt{252}}=\frac{20}{15.8745}\\ &=\$1.2599,\\ \sqrt{13.19/5}&=\sqrt{2.638}=\$1.6242,\\ \sigma_{\rm real}&=\frac{1.6242}{100}\times\sqrt{252}\\ &=0.016242\times15.8745\\ &=25.78\%. \end{aligned} \]

วันที่ 1, 2 และ 5 หุ้นขยับ 1.8, 2.3 และ 2.1 ดอลลาร์ เกินจุดคุ้มทุน \$1.26 จึงได้ วันที่ 3 และ 4 ขยับแค่ 0.4 และ 0.3 ดอลลาร์ จึงเสียค่าเวลาไปเกือบเต็ม ทั้งห้าวันหุ้นแกว่งจริง 25.78% ต่อปี มากกว่า 20% ที่จ่าย ผลรวมจึงเป็นบวก

ลองกรณีกลับกัน สมมติหุ้นแกว่งแค่ 15% ต่อปี และขยับเท่ากันทุกวัน คือวันละ $0.15\times100/\sqrt{252}=\$0.9449$ ใช้สูตรเงินเฉลี่ยต่อวันจากขั้นที่ 4 กับ $\tfrac12\Gamma S^2=\tfrac12(0.057778)(100)^2=288.89$:

\[ \begin{aligned} 5\,\overline{\Delta\Pi}&=5\times\frac{288.89\,(0.15^2-0.20^2)}{252}\\ &=5\times\frac{288.89\times(-0.0175)}{252}\\ &=-\$0.1003. \end{aligned} \]

ห้าวันเสีย \$0.1003 ทั้งที่ไม่ได้ทายทิศทางผิดเลยสักวัน ที่เสียเพราะหุ้นแกว่งน้อยกว่าที่จ่ายไปในราคา option

ขั้นที่ 7 — ต้นทุนของการปรับ hedge ทุกวัน

ทุกครั้งที่ปรับ hedge ต้องซื้อหรือขายหุ้นจริง และการซื้อขายแต่ละครั้งเสียค่าธรรมเนียม ขั้นนี้นับว่าค่าธรรมเนียมกินกำไรของห้าวันไปเท่าไร

โจทย์ให้อะไรมาบ้าง: ใช้ห้าวันจากขั้นที่ 5 ทุกสิ้นวันคิดราคาใหม่ได้ delta ใหม่ $\delta_i$ แล้วซื้อหรือขายหุ้นเท่าผลต่างของ delta $\Delta\delta_i=\delta_i-\delta_{i-1}$ ค่าซื้อขายคือ 10 bp (0.1%) ของมูลค่าที่ซื้อขาย (สมมติ) delta ที่โค้ดท้ายหน้าคำนวณได้ ตั้งแต่วันเริ่มถึงวันที่ 5 คือ 0.5138, 0.6167, 0.4833, 0.5070, 0.4879, 0.6176

จำนวนหุ้นที่ซื้อขายแต่ละวันคือผลต่างของ delta ไม่สนเครื่องหมาย รวมห้าวันได้ $Q$ มูลค่าที่ซื้อขาย $M$ คือจำนวนหุ้นคูณราคาปิดของวันนั้น แล้วค่าธรรมเนียม $F$ คือ 0.1% ของ $M$:

\[ \begin{aligned} Q&=\textstyle\sum_i|\Delta\delta_i|\\ &=0.1030+0.1334+0.0237\\ &\quad+0.0190+0.1296=0.4087,\\ M&=\textstyle\sum_i|\Delta\delta_i|\,S_i\\ &=0.1030(101.8)+0.1334(99.5)\\ &\quad+0.0237(99.9)+0.0190(99.6)\\ &\quad+0.1296(101.7)=\$41.20,\\ F&=0.001\times41.20=\$0.0412,\\ \Pi_{\rm net}&=0.1496-0.0412=\$0.1084. \end{aligned} \]

คำตอบ: ห้าวันซื้อขายรวม 0.4087 หุ้น มูลค่า \$41.20 เสียค่าซื้อขาย \$0.0412 คิดเป็น $0.0412/0.1496=27.5\%$ ของกำไร เหลือกำไรสุทธิ \$0.1084 วันที่หุ้นขยับมาก (วันที่ 1, 2, 5) ต้องซื้อขายมาก เพราะ delta เปลี่ยนเท่ากับ gamma คูณการขยับ

ตรวจเองใน 10 วินาที: วันแรก gamma คูณการขยับได้ $0.057778\times1.8=0.104$ ใกล้กับ 0.1030 ที่ซื้อขายจริง

ถ้าปรับวันละ 4 ครั้งแทนวันละครั้ง ต้นทุนเปลี่ยนไปเท่าไร แต่ละครั้งเวลาผ่านไป $\tfrac14$ วัน หุ้นจึงขยับราว $\sqrt{1/4}=\tfrac12$ ของการขยับต่อวัน (ขยับตามรากที่สองของเวลา) แต่ละครั้งจึงซื้อขายราวครึ่งเดียว แต่ซื้อขายบ่อยขึ้นสี่เท่า มูลค่าซื้อขายจึงโตราว $4\times\tfrac12=2$ เท่า ต้นทุน 10 bp นี้ยังไม่รวมส่วนต่างระหว่างราคาเสนอซื้อกับราคาเสนอขาย และราคาที่ขยับเพราะคำสั่งของเราเอง หน้าถัดไปจะนับสองเรื่องนี้

ขั้นที่ 8 — สูตรเดินพอร์ตทีละช่วง

ขั้นต่อไปจะเลียนแบบ option ทั้งอายุด้วยการปรับ 50 ครั้ง การคิดด้วยมือทีละคำสั่งจึงไม่ไหว ต้องมีสูตรที่เดินพอร์ตไปทีละช่วงได้ เราปรับ hedge ที่เวลา $t_0\lt t_1\lt\dots\lt t_n=T$ แต่ละช่วงยาว $\Delta t$ ของในพอร์ตมีสองอย่าง:

  • หุ้น $\delta_i$ หุ้น ถือไว้ตลอดช่วงที่ $i$ (ตั้งตาม delta ตอนต้นช่วง)
  • เงินที่เหลือ $V_i-\delta_iS_i$ อยู่ในบัญชีเงินฝาก ถ้าติดลบคือกู้มา โดย $V_i$ คือมูลค่าพอร์ตตอนต้นช่วง

ระหว่างช่วง พอร์ตได้เงินจากสามทาง คือราคาหุ้นที่ขยับ เงินปันผลอัตรา $c$ ต่อปี (เงินสดที่บริษัทจ่ายให้ผู้ถือหุ้น คิดเป็นสัดส่วนของราคาหุ้น) และดอกเบี้ยอัตรา $r$ ต่อปีแบบต่อเนื่อง:

\[ \begin{aligned} V_{i+1}&=V_i+\delta_i\big(S_{i+1}-S_i\\ &\qquad+S_ic\,\Delta t\big)\\ &\quad+(V_i-\delta_iS_i)(e^{r\Delta t}-1). \end{aligned} \]

ก้อนแรกคือกำไรของหุ้นที่ถือ บวกเงินปันผลที่ได้ ก้อนที่สองคือดอกเบี้ยของเงินในบัญชี เงินฝาก \$1 ดอกเบี้ยแบบต่อเนื่องจะโตเป็น $e^{r\Delta t}$ ในหนึ่งช่วง ดอกเบี้ยที่ได้จึงเป็น $e^{r\Delta t}-1$ ต่อเงินหนึ่งดอลลาร์ ถ้าเงินในบัญชีติดลบ ก้อนนี้ก็ติดลบ คือจ่ายดอกเบี้ยเงินกู้

ไม่มีพจน์ไหนเป็นเงินที่เติมเข้าหรือดึงออก พอร์ตจึง self-financing แบบเดียวกับพอร์ตเลียนแบบทีละโหนดในต้นไม้ binomial ถ้า $\Delta t$ เข้าใกล้ศูนย์และความผันผวนที่ใช้ถูกต้อง มูลค่าตอนจบ $V_n$ จะเท่ากับ payoff ของ option พอดี ถ้าช่วงห่าง หรือใช้ความผันผวนผิด $V_n$ จะแค่ใกล้เคียง แบบฝึกข้างล่างไม่มีปันผล ($c=0$)

ขั้นที่ 9 — แบบฝึก: ขาย call 100,000 ตัว แล้วเลียนแบบด้วยการปรับ 50 ครั้ง

ทีนี้สลับข้าง โต๊ะเป็นคนขาย call ได้เงินค่า call มาก่อน และวันหมดอายุต้องจ่าย payoff ให้คนซื้อ โต๊ะไม่อยากเดิมพันว่าหุ้นจะขึ้น จึงเอาเงินค่า call ไปสร้างพอร์ตเลียนแบบ คือพอร์ตหุ้นกับเงินกู้ที่ปรับตาม delta ให้มีค่าวิ่งตาม call เพื่อให้วันหมดอายุมีเงินพอจ่าย ขั้นนี้ใช้สูตรเดินพอร์ตจากขั้นที่ 8 ดูว่าจบแล้วเหลือเท่าไร

โจทย์ให้อะไรมาบ้าง: ตัวเลขทั้งหมดสมมติ

  • ราคาหุ้นวันนี้ $S_0=\$50$ และ strike $K=\$50$
  • อายุ call $T=0.25$ ปี (สามเดือน)
  • ความผันผวนที่ใช้ตั้งราคาและใช้ hedge $\sigma=30\%$
  • ดอกเบี้ย $r=2\%$ ต่อปีแบบต่อเนื่อง ไม่มีเงินปันผล
  • ขาย call $n=100{,}000$ ตัว
  • ปรับ 50 ครั้ง ห่างกัน $\Delta t=0.25/50=0.005$ ปี คิดเป็น $0.005\times252=1.26$ วันทำการ
  • เส้นทางราคาหุ้น 51 จุด (จุดเริ่มกับอีก 50 จุด) จบที่ \$54.4079 ตัวเลขทุกจุดอยู่ในโค้ดท้ายหน้า

ขั้นแรกหาราคา call ด้วยสูตร Black–Scholes $C_0=S_0N(d_1)-Ke^{-rT}N(d_2)$ โดย $N$ คือโอกาสสะสมของ Normal มาตรฐาน และ $d_2=d_1-\sigma\sqrt T$ เพราะ $S_0=K$ จึงได้ $\ln(S_0/K)=0$ ส่วน $\tfrac12\sigma^2=0.045$ และ $\sqrt T=0.5$ เงิน strike ที่คิดลดกลับมาวันนี้คือ $Ke^{-rT}=50e^{-0.005}=49.750624$:

\[ \begin{aligned} d_1&=\frac{(0.02+0.045)(0.25)}{0.30\times0.5}\\ &=\frac{0.01625}{0.15}=0.108333,\\ d_2&=0.108333-0.15=-0.041667,\\ S_0N(d_1)&=50\times0.5431344\\ &=27.1567179,\\ Ke^{-rT}N(d_2)&=49.750624\times0.4833822\\ &=24.0485667,\\ C_0&=27.1567179-24.0485667\\ &=\$3.1081512. \end{aligned} \]

ต่อมาตั้งพอร์ตเลียนแบบตอนเริ่ม เงินค่า call ทั้งหมดคือ $V_0$ ซื้อหุ้นเท่ากับ delta ของ call ทั้งหมด $H_0=nN(d_1)$ หุ้น เงินที่ขาดกู้มา คือเงินในบัญชี $B_0$ ติดลบ (ตัวเลขคิดเต็มทศนิยมแล้วค่อยปัด):

\[ \begin{aligned} V_0&=100{,}000\times3.1081512\\ &=\$310{,}815.12,\\ H_0&=10^5\,N(0.108333)\\ &=10^5\times0.543134359\\ &=54{,}313.4359\ \text{shares},\\ B_0&=V_0-50H_0\\ &\approx-\$2{,}404{,}856.67. \end{aligned} \]

ลองเดินช่วงแรกด้วยมือ หุ้นลงจาก \$50 เป็น \$49.5072 ใช้สูตรเดินพอร์ตจากขั้นที่ 8 โดยไม่มีปันผล เงินกู้โตด้วยดอกเบี้ย $e^{r\Delta t}=e^{0.02\times0.005}=e^{0.0001}$ มูลค่าพอร์ตตอนจบช่วงแรกคือหุ้นที่ถือ บวกเงินในบัญชี (ซึ่งติดลบ) ตรงนี้ต้องใช้ทศนิยมเต็ม เพราะจำนวนหุ้นคูณราคาเป็นเงินหลักล้าน ปัดนิดเดียวก็คลาดเป็นดอลลาร์:

\[ \begin{aligned} V_1&=54{,}313.4359\times49.5072262\\ &\quad-2{,}404{,}856.67\,e^{0.0001}\\ &=2{,}688{,}907.55-2{,}405{,}097.17\\ &=\$283{,}810.38. \end{aligned} \]

จากนั้นคิด delta ใหม่ที่หุ้น \$49.5072 และอายุที่เหลือ 0.245 ปี ได้ว่าต้องลดหุ้นเหลือ 51,617.07 หุ้น ทำแบบนี้ไปจนครบ 50 ครั้ง (โค้ดท้ายหน้าทำทุกช่วง)

ตอนจบ พอร์ตเลียนแบบมีค่า $V_{50}$ และต้องจ่าย payoff ของ call ทั้งหมด $L$ ส่วนที่เหลือคือกำไรของคนขาย:

\[ \begin{aligned} V_{50}&=\$496{,}180.85,\\ L&=10^5\times(54.4079-50)\\ &=\$440{,}787.27,\\ V_{50}-L&=\$55{,}393.58. \end{aligned} \]

คำตอบ: เริ่มด้วยเงินค่า call \$310,815.12 ซื้อหุ้นตาม delta 54,313.44 หุ้น ส่วนที่ขาดกู้มา \$2,404,856.67 ครบ 50 ครั้งพอร์ตมี \$496,180.85 จ่ายตาม call \$440,787.27 เหลือกำไร \$55,393.58

ตรวจเองใน 10 วินาที: ถ้าปรับต่อเนื่องและความผันผวนถูก hedge ควรจบที่ศูนย์ ทำไมได้กำไร? เพราะเส้นทางนี้แกว่งจริงแค่ 24.90% ต่อปี วิธีคิดคือหา SD ของ log return ทั้ง 50 ช่วง (log return ของช่วงที่ $i$ คือ $\ln(S_{i+1}/S_i)$ ซึ่งใกล้เคียงผลตอบแทนเป็นสัดส่วน) แล้วคูณ $\sqrt{200}$ เพราะหนึ่งปีมี $1/0.005=200$ ช่วง ความผันผวนจริงต่ำกว่า 30% ที่ขายไป คนขายที่ hedge จึงได้ส่วนต่าง นี่คือการเทียบความผันผวนจริงกับที่จ่ายของขั้นที่ 4 ในมุมของคนขาย

ขั้นที่ 10 — ปรับถี่ขึ้น ความคลาดลดช้า และความผันผวนที่ใช้ผิดเลื่อนผลทั้งกอง

กำไร \$55,394 ของแบบฝึกมาจากสองเรื่องปนกัน คือการปรับเป็นช่วง และความผันผวนจริงที่ไม่เท่ากับที่ขาย ขั้นนี้แยกสองเรื่องออกจากกัน เริ่มจากเรื่องแรก

สมมติหุ้นแกว่ง 30% ตามที่ขายพอดี hedge ที่ปรับเป็นช่วงก็ยังพลาดทุกช่วง จากขั้นที่ 4 ความพลาดของช่วงที่ $i$ คือ $e_i=\tfrac12\Gamma_iS_i^2(\ell_i^2-\sigma^2\Delta t)$ โดย $\ell_i$ คือ log return ของหุ้นในช่วงนั้น และ $\Gamma_i$, $S_i$ คือ gamma และราคาหุ้นตอนต้นช่วง (สำหรับคนขาย เครื่องหมายกลับกัน แต่ขนาดเท่ากัน) ถ้าหุ้นแกว่ง 30% จริง เขียน $\ell_i=\sigma\sqrt{\Delta t}\,Z$ ได้ โดย $Z$ คือตัวเลขสุ่มจากรูประฆัง Normal ที่ค่าเฉลี่ย 0 และ SD 1:

\[ \begin{aligned} e_i&=\tfrac12\Gamma_iS_i^2\,\sigma^2\Delta t\,(Z^2-1),\\ \mathrm{Var}\Big(\sum_{i=1}^{N}e_i\Big)&\propto N\Big(\frac TN\Big)^2=\frac{T^2}{N},\\ \mathrm{SD}&\propto\frac{T}{\sqrt N}. \end{aligned} \]

บรรทัดแรกได้จากการแทน $\ell_i^2=\sigma^2\Delta t\,Z^2$ ค่าเฉลี่ยของ $Z^2$ คือ 1 ความพลาดแต่ละช่วงจึงเฉลี่ยเป็นศูนย์ แต่ไม่ได้เป็นศูนย์ทุกช่วง ขนาดของมันโตตาม $\Delta t$ ถ้าแบ่งอายุ $T$ เป็น $N$ ช่วง แต่ละช่วงยาว $\Delta t=T/N$ ความแปรปรวนของแต่ละช่วงจึงโตตาม $(T/N)^2$ ช่วงต่าง ๆ สุ่มอิสระกัน ความแปรปรวนของผลรวมจึงเท่ากับผลรวมของความแปรปรวน $N$ ช่วง ได้บรรทัดที่สอง ถอดรากได้ SD ลดลงตาม $\sqrt N$ ไม่ใช่ตาม $N$

ทดสอบด้วยการจำลอง 4,000 เส้นทางที่หุ้นแกว่ง 30% จริง แล้ว hedge แบบแบบฝึก โดยปรับ 10, 50 และ 250 ครั้ง ได้ SD ของกำไรขาดทุน \$79,092, \$36,722 และ \$16,621 ตามลำดับ และค่าเฉลี่ยราวศูนย์ทั้งสามแบบ เทียบอัตราการลดกับทฤษฎี:

\[ \frac{79{,}092}{36{,}722}=2.15,\qquad\sqrt{\tfrac{50}{10}}=\sqrt5=2.24. \]

ปรับถี่ขึ้นห้าเท่า SD ลดราว $\sqrt5$ เท่า ไม่ใช่ห้าเท่า โค้ดท้ายหน้าจำลองซ้ำด้วยตัวเลขสุ่มอีกชุด ได้ 76,647, 36,251 และ 16,520 ต่างจากชุดแรกไม่เกินราว 3% ส่วนต่างนี้เป็นความคลาดจากการสุ่ม

ต่อมาเรื่องที่สอง สมมติหุ้นแกว่งจริง 25% แต่โต๊ะขายและ hedge ด้วย 30% คือความผันผวนต่างกัน 5 จุด ($0.30-0.25=0.05$) จำลองแบบเดิมโดยปรับ 50 ครั้ง ได้กำไรเฉลี่ย +\$50,288 (โค้ดได้ +\$49,917) เทียบกับ vega ของทั้งพอร์ต $\mathcal V=\$991{,}520$ ต่อความผันผวน 1.00 (ขั้นที่ 11 คำนวณตัวเลขนี้) คูณ 5 จุด:

\[ \mathcal V\times0.05=991{,}520\times0.05=\$49{,}576. \]

ความผันผวนที่ผิดไม่ได้ทำแค่ให้ผลกระจายกว้างขึ้น มันเลื่อนผลทั้งกองไปข้างหนึ่ง และระยะที่เลื่อนใกล้กับ vega คูณส่วนต่างความผันผวน กำไร \$55,394 ของแบบฝึกจึงไม่ใช่โชค แต่เป็นผลของความผันผวนจริงที่ต่ำกว่าที่ขาย อีกเรื่องที่ควรรู้คือ ความผันผวนที่ผิดทำให้ delta ทุกช่วงผิดไปด้วย hedge จึงไม่ได้เลียนแบบ payoff แม้จะปรับถี่มากก็ตาม

ขั้นที่ 11 — สี่เส้นทางเพิ่ม: vega บอกทิศ gamma บอกขนาด

ขั้นที่แล้วบอกว่า ระยะที่ผลเลื่อนใกล้กับ vega คูณส่วนต่างความผันผวน ขั้นนี้ถามว่ากฎนี้แม่นแค่ไหนกับเส้นทางจริงแต่ละเส้น ลองหุ้นอีกสี่เส้นทางสมมติ ทางละ 50 ช่วง ทุกทางขาย call ที่ 30% และ hedge แบบเดียวกับแบบฝึก แล้วเทียบกฎทำนายสองแบบ

กฎแบบหยาบใช้ vega ของทั้งพอร์ต vega บอกว่าราคา call เปลี่ยนกี่ดอลลาร์ต่อความผันผวน 1.00 ถ้าความผันผวนที่ “ควรเป็น” คือ $\sigma_{\rm real}$ call ที่ขายไปที่ 30% ก็แพงเกินไปราว $\mathcal V(0.30-\sigma_{\rm real})$ ซึ่งเป็นกำไรของคนขาย สูตร vega ของ call หนึ่งตัวคือ $S_0\sqrt T\,\varphi(d_1)$ โดย $d_1=0.108333$ จากขั้นที่ 9:

\[ \begin{aligned} \mathcal V&=n\,S_0\sqrt T\,\varphi(d_1)\\ &=10^5(50)(0.5)(0.396608)\\ &=\$991{,}520,\\ \Pi&\approx\mathcal V\,(0.30-\sigma_{\rm real}). \end{aligned} \]

กฎแบบละเอียดบวกความพลาดทีละช่วงจากขั้นที่ 10 ในมุมของคนขาย แต่ละช่วงถ่วงด้วย dollar gamma ของทั้งพอร์ตตอนต้นช่วง $g_i$ ส่วน $0.3^2\times0.005=0.00045$ คือผลตอบแทนยกกำลังสองที่ราคา call คิดไว้ต่อช่วง:

\[ \begin{aligned} g_i&=\tfrac12n\,\Gamma_iS_i^2,\\ \Pi&\approx\sum_{i=0}^{49}g_i\big(0.00045-\ell_i^2\big). \end{aligned} \]

กฎ vega ใช้แค่ความผันผวนเฉลี่ยของทั้งเส้นทาง กฎทีละช่วงรู้ด้วยว่าหุ้นแกว่งแรงตอนไหน ตารางข้างล่างแสดงว่าเรื่องนี้สำคัญมาก

ทางที่ 3 แกว่ง 51.57% กฎ vega ทายว่า $991{,}520\times(0.30-0.51569)=-\$213{,}860$ แต่เสียจริงแค่ \$122,867 เพราะสองในสามครั้งที่แกว่งแรงที่สุด เกิดตอนหุ้นอยู่ราว \$61 และ \$66 ตอนนั้น call ลึกใน the money แล้ว gamma จึงเหลือน้อย $g_i$ ราว 378,000 และ 8,000 เทียบกับราว 6.6 ล้านตอนหุ้นอยู่ \$48 การแกว่งสองครั้งนั้นจึงแทบไม่ทำให้เสียเงิน

ทางที่ 2 แกว่ง 30.36% แทบเท่า 30% กฎ vega ทายว่าเสียแค่ \$3,564 แต่เสียจริง \$20,263 เพราะครั้งที่แกว่งแรงที่สุด (+4.98%) เกิดตอนหุ้นอยู่ \$50.45 ซึ่งใกล้ strike และใกล้หมดอายุ ตรงนั้น gamma สูงมาก $g_i$ ราว 14.8 ล้าน ข้อสรุปคือ hedge เสียหนักเมื่อหุ้นแกว่งแรงตรงจุดที่ gamma สูง ไม่ใช่แค่เมื่อความผันผวนเฉลี่ยสูง

ขั้นที่ 12 — วันที่หุ้นขยับแรง: Taylor พังและต้องใช้ตาราง scenario

ทุกขั้นที่ผ่านมาใช้สูตร Taylor สองพจน์ ซึ่งแม่นเมื่อหุ้นขยับไม่มาก แต่บางวันหุ้นกระโดดแรง เช่นวันที่บริษัทประกาศข่าวใหญ่ วันแบบนั้นคือวันที่โต๊ะเสียหนักที่สุด ขั้นนี้ถามว่า วันนั้นสูตรยังเชื่อได้ไหม

โจทย์ให้อะไรมาบ้าง: ใช้พอร์ตที่ขาย call 100,000 ตัวของแบบฝึก ในวันเริ่มต้นที่ hedge delta แล้ว

  • หุ้น \$50 ความผันผวน 30% อายุเหลือ 0.25 ปี
  • gamma ของทั้งพอร์ต $\Gamma_{\rm book}=10^5\times0.052881=5{,}288.1$ หุ้นต่อดอลลาร์ (gamma ต่อตัวจากโค้ดท้ายหน้า)
  • vega ของทั้งพอร์ต $\mathcal V=\$991{,}520$ ต่อความผันผวน 1.00 (จากขั้นที่ 11)

คำถาม: ถ้าหุ้นกระโดดทันที ±5%, ±10% หรือ ±20% (คือ ±\$2.5, ±\$5, ±\$10 จากราคา \$50) และความผันผวนอยู่เท่าเดิม หรือขึ้น 5 จุด ($\Delta\sigma=0.05$) คนขายได้เสียเท่าไร ให้เทียบสูตรสองพจน์กับการคิดราคา call ใหม่ทั้งพอร์ต

สูตรสองพจน์ของคนขายคือพจน์ gamma บวกพจน์ vega ใส่เครื่องหมายลบ เพราะคนขายถือ option ติดลบ (หุ้นกระโดดทันที จึงไม่มีค่าเวลา):

\[ \begin{aligned} \Pi_{\rm approx}&=-\big[\tfrac12(5{,}288.1)(\Delta S)^2\\ &\qquad+991{,}520\,\Delta\sigma\big],\\ \Delta S=\pm\$5&:\ -\tfrac12(5{,}288.1)(5^2)\\ &\quad=-66{,}101,\\ \Delta S=\pm\$10&:\ -\tfrac12(5{,}288.1)(10^2)\\ &\quad=-264{,}405,\\ \Delta\sigma=0.05&:\ -991{,}520\times0.05\\ &\quad=-49{,}576\ \text{extra}. \end{aligned} \]

ตารางข้างล่างทำครบทุกช่อง แถว “คิดใหม่” คิดราคา call ทั้ง 100,000 ตัวด้วย Black–Scholes ที่ราคาหุ้นและความผันผวนใหม่ แล้วหักผลของหุ้นที่ hedge ไว้ (โค้ดท้ายหน้า ฟังก์ชัน scenario):

อีกเรื่องที่สูตรพลาดคือความสมมาตร สูตรให้ค่าเท่ากันทั้งหุ้นขึ้นและหุ้นลง แต่ของจริงไม่เท่า (−20% เสีย \$254,022 แต่ +20% เสีย \$212,469) มีสองเหตุผล ข้อแรก gamma เองเปลี่ยนเมื่อหุ้นเคลื่อนไปไกล เช่นเมื่อหุ้นขึ้นมาก call ลึกใน the money และ gamma เหลือน้อย ข้อสอง เมื่อหุ้นกับความผันผวนขยับพร้อมกัน ผลของสองอย่างไม่ได้แค่บวกกัน เพราะ gamma ก็เปลี่ยนตามความผันผวนด้วย แต่สูตรสองพจน์ไม่มีพจน์ที่จับผลร่วมนี้ วันที่หุ้นกระโดดแรงคือวันที่เสียหนักที่สุด และก็เป็นวันที่สูตรเชื่อไม่ได้ที่สุดด้วย

ตรวจเองใน 10 วินาที: ทุกช่องติดลบ คนขาย option ที่ hedge แล้วเสียเมื่อหุ้นกระโดดไม่ว่าทางไหน และเสียเพิ่มเมื่อความผันผวนขึ้น ตรงกับที่คนขายมี gamma และ vega ติดลบทั้งคู่ โต๊ะจริงจึงทำตารางแบบนี้ทุกวัน (หุ้นขยับหลายระดับ คูณความผันผวนขยับหลายระดับ) และใช้สูตรสองพจน์แค่ในวันปกติ หรือในVaR แบบ delta-gamma (VaR คือตัวเลขขาดทุนที่ควรเกินได้แค่ไม่กี่วันในร้อยวัน)

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

เรียกพอร์ตที่ delta เป็นศูนย์ว่าไม่มีความเสี่ยง: delta เป็นศูนย์แปลว่าไม่กลัวการขยับเล็ก ๆ เท่านั้น พอร์ตยังมี gamma, vega, การกระโดด และต้นทุนซื้อขาย คำตอบผิดคือ “hedge แล้ว ได้เสียเป็นศูนย์” คำตอบถูกของโจทย์เปิดหน้าคือ call 1,000 ตัวได้ $80-18=\$62$ ในวันที่ราคาปิดเท่าเดิม ถ้าเป็นคนขายก็เสีย \$62

อ่านผลจากราคาปิดอย่างเดียว: สองวันที่ราคาปิดเท่ากันอาจได้เงินต่างกันมาก ใช้พอร์ตของโจทย์เปิดหน้า ($\Gamma_{\rm book}=20$) วันแรกหุ้นวิ่ง 100, 102, 100, 99, 100 และปรับทุกจุด หุ้นขยับ +2, −2, −1, +1 เงินจาก gamma คือ $\tfrac12(20)(2^2+2^2+1^2+1^2)=\tfrac12(20)(10)=\$100$ วันที่สองหุ้นนิ่งอยู่ \$100 ทั้งวัน เงินจาก gamma คือ \$0

ใช้ 365 วันแทน 252 วันทำการในจุดคุ้มทุน: หุ้นขยับเฉพาะวันที่ตลาดเปิด หนึ่งวันจึงต้องเป็น 1/252 ปี ไม่ใช่ 1/365 คำตอบผิดคือ $0.20\times100/\sqrt{365}=\$1.0468$ คำตอบถูกคือ $0.20\times100/\sqrt{252}=\$1.2599$ คนที่ใช้ตัวเลขผิดจะคิดว่าวันที่หุ้นขยับ \$1.10 เป็นวันที่ได้ ทั้งที่ยังไม่พอจ่ายค่าเวลา

ลืมต้นทุนการปรับ: ตัวอย่างห้าวันเสียค่าซื้อขาย 10 bp ไป $0.0412/0.1496=27.5\%$ ของกำไร ถ้าปรับถี่ขึ้นสี่เท่า ค่าซื้อขายโตราว $4\times\tfrac12=2$ เท่า แต่ SD ของความคลาดลดแค่ $\sqrt4=2$ เท่า โต๊ะจริงจึงมักปรับเมื่อ delta เคลื่อนเกินแถบที่ตั้งไว้ แทนการปรับตามนาฬิกา

ใช้กฎ vega กับเส้นทางที่ gamma เปลี่ยนมาก: กฎ vega ดูแค่ความผันผวนเฉลี่ย ไม่ดูว่าหุ้นแกว่งตอนไหน ทางที่ 2 กฎ vega บอกเสีย \$3,564 แต่เสียจริง \$20,263 คิดเป็น $20{,}263/3{,}564=5.7$ เท่า

ลืมก้อน vega: ต่อให้หุ้นไม่ขยับเลย ราคา option ก็เปลี่ยนได้ ถ้า implied volatility ของตลาดขยับ 1 จุด (0.01) พอร์ต call 100,000 ตัวเปลี่ยนมูลค่าทันที $991{,}520\times0.01=\$9{,}915$

ใช้ทำอะไรบนโต๊ะจริง

ทุกเย็น โต๊ะ option ต้องรายงานว่าวันนี้ได้เสียเท่าไร และเงินมาจากไหน รายงานนี้แยกกำไรขาดทุนเป็นก้อน delta, gamma, theta และ vega ตาม Taylor ข้างบน ส่วนที่เหลือซึ่งอธิบายด้วยสี่ก้อนนี้ไม่ได้ ถ้าใหญ่ แปลว่ามีความเสี่ยงที่แบบจำลองมองไม่เห็น

คนขาย option ได้ค่าเวลาทุกวันที่ตลาดเงียบ และเสียหนักในวันที่หุ้นกระโดด การตัดสินใจซื้อหรือขาย option แล้ว hedge จึงเป็นการเทียบสองตัวเลข คือความผันผวนที่คาดว่าหุ้นจะแกว่งจริง กับ implied volatility ในราคา option ขนาดของการเดิมพันวัดด้วย vega ของทั้งพอร์ต ส่วนความเสี่ยงในวันที่หุ้นกระโดดแรง วัดด้วยตาราง scenario ไม่ใช่สูตรสองพจน์ (โครงสร้างที่โต๊ะใช้ซื้อขายความผันผวนอยู่ในหน้าvolatility trading structures)

เฉลย

คนขายถือ call ติดลบ gamma ของทั้งพอร์ตจึงติดลบ สูตรพาราโบลาจึงกลับหัว: เงินจาก gamma ติดลบ และค่าเวลาเป็นบวก:

\[\begin{aligned}\Gamma_{\rm book}&=-500\times0.03=-15,\\\Pi&=-\tfrac12(15)(3)^2+12\\&=-67.5+12=-\$55.5.\end{aligned}\]

จุดคุ้มทุน $x$ คือการขยับที่ทำให้เงินที่เสียจาก gamma เท่ากับค่าเวลาที่ได้พอดี:

\[\begin{aligned}\tfrac12(15)x^2&=12,\\x^2&=24/15=1.6,\\x&=\sqrt{1.6}=\$1.2649.\end{aligned}\]

วันที่หุ้นขยับน้อยกว่า \$1.2649 คนขายได้ วันที่ขยับมากกว่านั้นคนขายเสีย

\[\begin{aligned}\frac{0.40\times50}{\sqrt{252}}&=\frac{20}{15.8745}=\$1.2599,\\\frac{0.20\times100}{\sqrt{252}}&=\frac{20}{15.8745}=\$1.2599.\end{aligned}\]

เท่ากันพอดี เพราะจุดคุ้มทุนขึ้นกับ $\sigma S$ ซึ่งทั้งสองกรณีเท่ากับ \$20 ต่อปี แต่ถ้าคิดเป็นเปอร์เซ็นต์ของราคาหุ้น หุ้นตัวนี้ต้องขยับวันละ $1.2599/50=2.52\%$ ส่วนหุ้นในตัวอย่างห้าวันต้องขยับแค่ $1.2599/100=1.26\%$

3. ใช้พอร์ตที่ขาย call 100,000 ตัวของแบบฝึก ซึ่งขายที่ความผันผวน 30% และมี vega \$991,520 ต่อความผันผวน 1.00 ถ้าหุ้นแกว่งจริง 35% กฎ vega ทายว่าคนขายที่ hedge ได้เสียเท่าไร และควรระวังอะไร?

เฉลย

กฎ vega ทายว่า $991{,}520\times(0.30-0.35)=991{,}520\times(-0.05)=-\$49{,}576$

ตัวเลขนี้เป็นแค่ค่าประมาณ เพราะกฎ vega ไม่รู้ว่าหุ้นแกว่งตอนไหน ถ้าการแกว่งแรงเกิดตอนหุ้นใกล้ strike และใกล้หมดอายุ (gamma สูง) จะเสียมากกว่านี้ เหมือนทางที่ 2 ในตาราง ถ้าเกิดตอน call ลึกใน the money (gamma ต่ำ) จะเสียน้อยกว่านี้ เหมือนทางที่ 3

const {exp, log, sqrt, abs, max, cos, PI} = Math;

// Standard normal CDF from its Taylor series around 0.
function normCdf(x) {
  if (x < -8) return 0;
  if (x > 8) return 1;
  let term = x, sum = x;
  for (let k = 1; k < 300 && abs(term) > 1e-17 * abs(sum); k++) { term *= x * x / (2 * k + 1); sum += term; }
  return 0.5 + sum * exp(-x * x / 2) / sqrt(2 * PI);
}
// Black-Scholes call with delta, gamma, vega (per 1.00 of volatility) and theta per year.
function call(S, K, tau, sigma, r = 0) {
  const d1 = (log(S / K) + (r + sigma * sigma / 2) * tau) / (sigma * sqrt(tau)), d2 = d1 - sigma * sqrt(tau);
  const pdf = exp(-d1 * d1 / 2) / sqrt(2 * PI);
  return {price: S * normCdf(d1) - K * exp(-r * tau) * normCdf(d2), delta: normCdf(d1), d1,
    gamma: pdf / (S * sigma * sqrt(tau)), vega: S * sqrt(tau) * pdf,
    theta: -S * pdf * sigma / (2 * sqrt(tau)) - r * K * exp(-r * tau) * normCdf(d2)};
}
// Delta-hedge n calls along a price path (steps of dt years); sign = -1 for the seller.
function hedgePath({path, K, T, sigma, r = 0, n = 1, sign = 1, dt}) {
  const o = call(path[0], K, T, sigma, r);
  let hold = n * o.delta, cash = n * o.price - hold * path[0], turnover = 0;
  for (let i = 1; i < path.length; i++) {
    cash *= exp(r * dt);
    const tau = T - i * dt;
    if (tau > 1e-12) {
      const next = n * call(path[i], K, tau, sigma, r).delta;
      turnover += abs(next - hold) * path[i];
      cash -= (next - hold) * path[i]; hold = next;
    }
  }
  const S = path[path.length - 1], tau = T - (path.length - 1) * dt;
  const optionValue = tau > 1e-12 ? n * call(S, K, tau, sigma, r).price : n * max(S - K, 0);
  return {pnl: sign * (optionValue - (hold * S + cash)), turnover};
}
function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}

// Discrete hedging error on 4,000 simulated paths.
function simulate(steps, trueSigma, paths = 4000, seed = 1) {
  const rnd = mulberry32(seed), dt = 0.25 / steps, out = [];
  for (let m = 0; m < paths; m++) {
    const path = [50];
    for (let i = 0; i < steps; i++) {
      const z = sqrt(-2 * log(rnd() || 1e-12)) * cos(2 * PI * rnd());
      path.push(path[i] * exp((0.02 - trueSigma ** 2 / 2) * dt + trueSigma * sqrt(dt) * z));
    }
    out.push(hedgePath({path, ...book, dt}).pnl);
  }
  const avg = out.reduce((a, b) => a + b, 0) / paths;
  return {mean: avg, sd: sqrt(out.reduce((a, b) => a + (b - avg) ** 2, 0) / (paths - 1))};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • หลัง delta hedge กำไรขาดทุนหนึ่งวันคือ $\Delta\Pi\approx\tfrac12\Gamma(\Delta S)^2+\Theta\,\Delta t$ เป็นพาราโบลาของการขยับ ทิศทางไม่มีผล ในโจทย์เปิดหน้า ราคาปิดเท่าเดิมแต่ได้ $80-18=\$62$ เพราะหุ้นแกว่งระหว่างวัน
  • เมื่อดอกเบี้ยเป็นศูนย์ สมการ Black–Scholes ให้ $\Theta=-\tfrac12\sigma_{\rm imp}^2S^2\Gamma$ ค่าเวลาจึงเป็นราคาที่จ่ายเพื่อซื้อ gamma การถือ option แล้ว hedge คือการเดิมพันว่าหุ้นจะแกว่งจริงมากกว่าที่จ่ายไป และจุดคุ้มทุนต่อวันคือ $\sigma_{\rm imp}S/\sqrt{252}$
  • ห้าวันที่หุ้นแกว่งจริง 25.78% เทียบกับ 20% ที่จ่าย ได้ \$0.1518 ตามสูตร และ \$0.1496 เมื่อคิดราคาใหม่จริง ค่าซื้อขาย 10 bp กินกำไรไป 27.5%
  • แบบฝึกขาย call 100,000 ตัวได้ \$55,393.58 เพราะเส้นทางแกว่งจริงแค่ 24.90% เทียบกับ 30% ที่ขาย ปรับถี่ขึ้นห้าเท่าลดความคลาดได้แค่ราว $\sqrt5$ เท่า และ gamma ตอนที่หุ้นแกว่งแรงเป็นตัวกำหนดขนาดของผล
  • วันที่หุ้นขึ้น 20% ทันที สูตรสองพจน์พลาดไป \$51,936 แม้ความผันผวนจะไม่เปลี่ยน และมองไม่เห็นว่าขาขึ้นกับขาลงเสียไม่เท่ากัน ต้องใช้ตาราง scenario ที่คิดราคาใหม่ทั้งพอร์ต
