6.1 Row Vectors and Column Vectors

Vector คือรายการตัวเลขที่ทุกช่องมีชื่อ และการคูณแถวกับคอลัมน์คือการจับคู่ช่องชื่อเดียวกัน คูณ แล้วบวก ซึ่งให้ผลตอบแทนของพอร์ตในบรรทัดเดียว

ทุกเย็น ผู้จัดการพอร์ตต้องรายงานหัวหน้าว่าวันนี้พอร์ตได้หรือเสียเงินกี่ดอลลาร์ งานนี้ฟังดูง่าย แต่พอร์ตจริงถือหุ้นหลายตัว บางตัวซื้อไว้ บางตัว short ไว้ และผลตอบแทนของแต่ละหุ้นมาจากไฟล์ที่คนอื่นส่งมา หน้านี้ใช้พอร์ตเล็ก ๆ ที่มีหุ้นสามตัวเป็นตัวอย่าง ตัวเลขทั้งหมดเป็นตัวเลขสมมติ

คำที่ต้องรู้ก่อน

  • NAV (net asset value) คือมูลค่าสุทธิของพอร์ต คือของทุกอย่างที่พอร์ตมี รวมเงินสด หักสิ่งที่พอร์ตติดค้างคนอื่น พอร์ตนี้มี NAV $N=\$25$ ล้าน
  • short คือการยืมหุ้นของคนอื่นมาขายก่อน แล้วซื้อคืนทีหลังเพื่อคืนเจ้าของ ถ้าราคาลง เราซื้อคืนได้ถูกกว่าที่ขายไป จึงได้กำไร ถ้าราคาขึ้น เราเสีย
  • น้ำหนัก (weight) ของหุ้นตัวหนึ่ง คือเงินที่วางในหุ้นตัวนั้น หารด้วย NAV เช่น น้ำหนัก 50% คือวางเงินครึ่งหนึ่งของ NAV ไว้ในหุ้นตัวนั้น หุ้นที่ short ไว้มีน้ำหนักติดลบ
  • ผลตอบแทน (return) ของหุ้นวันนี้ คือราคาเปลี่ยนไปกี่ % จากเมื่อวาน

ข้อแรก วันนี้พอร์ตได้หรือเสียกี่ดอลลาร์

ข้อสอง ไฟล์ผลตอบแทนที่ส่งมาเรียงหุ้นเป็น NVDA, JPM, AAPL ซึ่งกลับลำดับกับตารางน้ำหนัก ถ้าไม่มีใครเรียงใหม่ก่อนคำนวณ ตัวเลขในรายงานจะผิดไปเท่าไร

ลองตอบก่อนเปิดเฉลย

ข้อแรก ก่อนอื่นแปลงน้ำหนักเป็นเงินที่ถือ คือน้ำหนักคูณ NAV

  • AAPL ถือ $0.50\times25=\$12.5$ ล้าน
  • JPM ถือ $0.30\times25=\$7.5$ ล้าน
  • NVDA short ไว้ $-0.20\times25=-\$5$ ล้าน

เงินที่หุ้นแต่ละตัวทำให้พอร์ตได้ คือเงินที่ถือคูณผลตอบแทน แล้วบวกทั้งสามตัว

\[ \begin{aligned} \Delta V_{\text{AAPL}}&=12{,}500{,}000\times0.012\\ &=\$150{,}000,\\ \Delta V_{\text{JPM}}&=7{,}500{,}000\times(-0.006)\\ &=-\$45{,}000,\\ \Delta V_{\text{NVDA}}&=-5{,}000{,}000\times0.004\\ &=-\$20{,}000,\\ \Delta V&=150{,}000-45{,}000-20{,}000\\ &=\$85{,}000. \end{aligned} \]

พอร์ตได้ \$85,000 คิดเป็น $85{,}000/25{,}000{,}000=0.0034=0.34\%$ ของ NAV ให้สังเกต NVDA: ราคาขึ้น แต่พอร์ตเสีย เพราะเรา short ไว้

ข้อสอง โปรแกรมจับคู่ตามตำแหน่ง ไม่ได้ดูชื่อหุ้น มันจึงเอาน้ำหนักของ AAPL ไปคูณผลตอบแทนของ NVDA และเอาน้ำหนักของ NVDA ไปคูณผลตอบแทนของ AAPL

\[ \begin{aligned} R_{\text{wrong}}&=0.50(0.004)+0.30(-0.006)\\ &\quad-0.20(0.012)\\ &=-0.0022,\\ \Delta V_{\text{wrong}}&=25{,}000{,}000\times(-0.0022)\\ &=-\$55{,}000. \end{aligned} \]

รายงานจะบอกว่าขาดทุน \$55,000 ทั้งที่จริงได้ \$85,000 ผิดไป $85{,}000-(-55{,}000)=\$140{,}000$ และโปรแกรมไม่เตือนอะไรเลย เพราะความยาวของรายการเท่ากันทุกอย่าง (คำตอบนี้ยังไม่รวมดอกเบี้ยของเงินสด ปันผล และค่ายืมหุ้นที่ short)

ภาพรวมก่อนลงสูตร

เฉลยข้อแรกทำงานแบบเดียวซ้ำสามครั้ง: เอาเงินที่ถือในหุ้นตัวหนึ่ง คูณกับผลตอบแทนของหุ้นตัวเดียวกัน ทำครบทุกตัว แล้วบวกกัน ถ้าพอร์ตมีหุ้น 500 ตัว ก็คูณ 500 คู่แล้วบวก วิธีเดิมทุกอย่าง คณิตศาสตร์มีภาษาสั้น ๆ สำหรับงานนี้ คือ vector กับ dot product

vector ในหนังสือเล่มนี้คือรายการตัวเลขที่เรียงตามลำดับ และแต่ละตำแหน่งมีความหมายตายตัว ในพอร์ตนี้ ตำแหน่งที่ 1 คือ AAPL ตำแหน่งที่ 2 คือ JPM ตำแหน่งที่ 3 คือ NVDA น้ำหนักของหุ้นทั้งสามจึงเป็น vector หนึ่งตัว เขียนว่า $\mathbf w$ ผลตอบแทนวันนี้ของหุ้นทั้งสามเป็นอีก vector หนึ่ง เขียนว่า $\mathbf r$ ตัวอักษรหนาบอกว่าเป็นรายการตัวเลข ไม่ใช่ตัวเลขตัวเดียว

dot product คือการจับคู่ตำแหน่งเดียวกันของสอง vector คูณกัน แล้วบวกทุกคู่ ผลที่ได้เป็นตัวเลขตัวเดียว เช่น น้ำหนักกับผลตอบแทนให้ผลตอบแทนพอร์ต จำนวนหุ้นกับราคาให้มูลค่าพอร์ต ในภาษา matrix (ตารางตัวเลขที่มีแถวและคอลัมน์) งานนี้เขียนเป็น “แถวคูณคอลัมน์” รูปด้านล่างแสดงผลคูณทีละคู่ที่สะสมกันจนได้ผลตอบแทนพอร์ต 0.34%

หน้านี้ไปทีละขั้นดังนี้

  • ตั้งชื่อและหน่วยให้ทุกช่องก่อนใส่ตัวเลข
  • แยกแถวกับคอลัมน์ด้วยขนาดของมัน
  • พิสูจน์ว่าทำไมผลตอบแทนพอร์ตคือ “น้ำหนักคูณผลตอบแทนแล้วบวก”
  • ดูว่าสลับลำดับการคูณแล้วได้ของคนละอย่าง
  • คิดเงินที่พอร์ตได้ในหลายสถานการณ์พร้อมกันด้วย matrix
  • แปลงน้ำหนักเป็นจำนวนหุ้นและรายการที่ต้องซื้อขาย
ศัพท์ที่ใช้ในหัวข้อนี้
Vector และ component
vector คือรายการตัวเลขที่เรียงตามลำดับ component คือตัวเลขในช่องหนึ่งของรายการ เราใช้ vector เก็บข้อมูลของหลายสินทรัพย์ในวันเดียวกัน ทุกช่องต้องตอบได้ว่าเป็นของสินทรัพย์ไหน วันไหน และหน่วยอะไร
Row vector และ column vector
row vector วางตัวเลขนอนเป็นหนึ่งแถว column vector วางตัวเลขตั้งเป็นหนึ่งคอลัมน์ ตัวเลขชุดเดียวกันวางได้ทั้งสองแบบ แต่การวางต่างกันทำให้ผลคูณต่างกัน แบบหนึ่งได้ตัวเลขตัวเดียว อีกแบบได้ตาราง
Shape
ขนาดของ vector หรือ matrix เขียนเป็น “จำนวนแถว × จำนวนคอลัมน์” เช่น $3\times1$ คือ 3 แถว 1 คอลัมน์ ใช้ตรวจว่าสองตัวคูณกันได้ไหม และผลคูณจะมีขนาดเท่าไร
Transpose
การพลิกคอลัมน์ให้นอนเป็นแถว หรือพลิกแถวให้ตั้งเป็นคอลัมน์ เขียนว่า $\mathbf w^{\mathsf T}$ ตัวเลขที่แถว $i$ คอลัมน์ $j$ ย้ายไปอยู่แถว $j$ คอลัมน์ $i$ ลำดับของสินทรัพย์ไม่เปลี่ยน
Dot product
คูณช่องที่ตรงกันของสอง vector แล้วบวกทุกคู่ ได้ตัวเลขตัวเดียว ใช้หาผลตอบแทนพอร์ต มูลค่าพอร์ต และต้นทุนของพอร์ต
Outer product
คอลัมน์คูณแถว ได้ตารางของผลคูณทุกคู่ รวมถึงคู่ที่ข้ามหุ้นกัน มันไม่ใช่ผลตอบแทนพอร์ต แต่จะได้ใช้จริงตอนสร้าง covariance matrix (ตารางที่บอกว่าหุ้นแต่ละคู่ขยับไปด้วยกันแค่ไหน) ในบทถัดไป
Short
ยืมหุ้นของคนอื่นมาขายก่อน แล้วซื้อคืนทีหลังเพื่อคืนเจ้าของ ได้กำไรเมื่อราคาลง หน้านี้เขียนสถานะ short เป็นตัวเลขติดลบ
NAV, net และ gross exposure
NAV คือมูลค่าสุทธิของพอร์ต รวมเงินสด net exposure คือเงินที่วางในหุ้นทุกตัวบวกกันตามเครื่องหมาย (short เป็นลบ) บอกว่าพอร์ตเอียงไปทางขึ้นหรือทางลงเท่าไร gross exposure คือเงินที่วางในหุ้นทุกตัวบวกกันโดยไม่สนเครื่องหมาย บอกว่าพอร์ตถือของรวมใหญ่แค่ไหน

ขั้นที่ 1 — ตั้งชื่อช่องและหน่วยก่อนใส่ตัวเลข

ข้อสองของหัวหน้าแสดงให้เห็นแล้วว่า ถ้าคูณผิดคู่ โปรแกรมก็ยังให้ตัวเลขออกมาโดยไม่เตือน ก่อนคูณอะไร เราจึงต้องตกลงให้ชัดว่าช่องไหนคือหุ้นตัวไหน ข้อมูลเป็นของวันไหน และวัดเป็นหน่วยอะไร ตารางด้านล่างวางทุกอย่างไว้ในที่เดียว

คอลัมน์ “เงินที่ถือ” คือ $d_i$ เงินที่พอร์ตวางในหุ้นตัวที่ $i$ หาจากน้ำหนักคูณ NAV เช่น JPM ถือ $0.30\times25=7.5$ ล้าน ส่วนเงินสด $C$ คือเงินที่เหลือ เริ่มจาก \$25 ล้าน จ่ายซื้อ AAPL กับ JPM ออกไป แล้วได้เงินเข้ามาจากการขาย NVDA ที่ยืมมา จึงได้ $C=25-12.5-7.5+5=10$ ล้าน

ช่องสินทรัพย์เงินที่ถือ $d_i$ (ล้านดอลลาร์)น้ำหนัก $w_i$ผลตอบแทนวันนี้ $r_i$

2JPM7.50.30−0.006
3NVDA (short)−5−0.200.004

ทีนี้เขียนน้ำหนักเป็นสูตร แล้ววางน้ำหนักกับผลตอบแทนเป็น vector สองตัวที่เรียงหุ้นลำดับเดียวกัน

\[ \begin{aligned} w_i&=\frac{d_i}{N},\\ w_{\text{AAPL}}&=\frac{12.5}{25}=0.50,\\ w_{\text{NVDA}}&=\frac{-5}{25}=-0.20,\\ w_c&=1-(0.50+0.30-0.20)\\ &=0.40,\\ \mathbf w&=\begin{bmatrix}0.50\\0.30\\-0.20\end{bmatrix},\quad \mathbf r=\begin{bmatrix}0.012\\-0.006\\0.004\end{bmatrix}. \end{aligned} \]

น้ำหนักคือเงินที่ถือหารด้วย NAV ของทั้งพอร์ต ไม่ใช่หารด้วยเงินส่วนที่อยู่ในหุ้น เครื่องหมายลบของ NVDA บอกว่าเรา short ไว้ ถ้าราคาขึ้น เราต้องซื้อคืนแพงขึ้น จึงเสียเงิน

น้ำหนักของเงินสด $w_c$ หาได้จากส่วนที่เหลือ เพราะทุกดอลลาร์ของ NAV ต้องอยู่ที่ไหนสักแห่ง น้ำหนักทุกช่องรวมเงินสดจึงต้องรวมกันได้ 1 พอดี ผลที่ได้ตรงกับ $C/N=10/25=0.40$

ใน $\mathbf w$ กับ $\mathbf r$ หุ้นเรียงลำดับเดียวกัน คือ AAPL, JPM, NVDA และผลตอบแทนถูกแปลงจาก % เป็นเศษส่วนแล้ว เช่น $1.2\%=0.012$ สองเรื่องนี้ต้องทำก่อนคูณอะไรทั้งสิ้น

เรื่องหนึ่งที่ควรรู้: พอร์ตที่ short หุ้นมักต้องวางเงินสดบางส่วนไว้กับโบรกเกอร์เป็นหลักประกัน จึงใช้เงินก้อนนี้ได้ไม่เต็มที่ แต่เวลานับ NAV เงินก้อนนี้ยังเป็นของพอร์ต

ขั้นที่ 2 — แถว คอลัมน์ และ transpose

ในขั้นที่ 1 เราวาง $\mathbf w$ เป็นคอลัมน์ แต่ตัวเลขชุดเดียวกันวางนอนเป็นแถวก็ได้ ความต่างนี้ดูเล็ก แต่ขั้นที่ 4 จะเห็นว่ามันตัดสินว่าการคูณจะได้ตัวเลขตัวเดียวหรือได้ทั้งตาราง เราจึงต้องมีวิธีพลิกจากแบบหนึ่งไปอีกแบบ เรียกว่า transpose และเขียนด้วยตัว $^{\mathsf T}$ ด้านล่างคือ $\mathbf w$ ที่พลิกเป็นแถว กฎทั่วไปของการพลิก และตัวอย่างกับ matrix $A$ ขนาด 2 แถว 3 คอลัมน์ ($A_{ij}$ คือตัวเลขที่แถว $i$ คอลัมน์ $j$ ของ $A$)

\[ \begin{aligned} \mathbf w^{\mathsf T}&=\begin{bmatrix}0.50&0.30&-0.20\end{bmatrix},\\ (A^{\mathsf T})_{ij}&=A_{ji},\\ A&=\begin{bmatrix}2&3&7\\1&6&5\end{bmatrix},\\ A^{\mathsf T}&=\begin{bmatrix}2&1\\3&6\\7&5\end{bmatrix}. \end{aligned} \]

$\mathbf w$ มี shape $3\times1$ คือ 3 แถว 1 คอลัมน์ ส่วน $\mathbf w^{\mathsf T}$ มี shape $1\times3$ ตัวเลขทุกตัวยังเรียงเหมือนเดิม สิ่งเดียวที่ transpose ทำ คือสลับเลขแถวกับเลขคอลัมน์ของทุกช่อง ตัวเลขที่เคยอยู่แถว $j$ คอลัมน์ $i$ ย้ายไปอยู่แถว $i$ คอลัมน์ $j$ กฎ $(A^{\mathsf T})_{ij}=A_{ji}$ เขียนเรื่องนี้เป็นสัญลักษณ์

ดูจากตัวอย่าง $A$ ขนาด $2\times3$ พลิกแล้วกลายเป็น $3\times2$ แถวแรกของ $A$ คือ $(2,3,7)$ กลายเป็นคอลัมน์แรกของ $A^{\mathsf T}$

ถ้าพลิกสองครั้งจะได้ของเดิม เพราะสลับเลขแถวกับเลขคอลัมน์สองรอบก็กลับที่เดิม $((A^{\mathsf T})^{\mathsf T})_{ij}=(A^{\mathsf T})_{ji}=A_{ij}$ หนังสือเล่มนี้เก็บ vector เป็นคอลัมน์เสมอ เมื่ออยากได้แถวก็ใส่ $^{\mathsf T}$ ซอฟต์แวร์บางตัวเก็บ vector เป็นแถวแทน ซึ่งไม่ผิด แต่ต้องรู้ว่าใช้แบบไหนก่อนเอาสูตรไปต่อกัน

ขั้นที่ 3 — สูตรผลตอบแทนพอร์ตมาจากไหน

ในเฉลยต้นหน้า เราใช้ “น้ำหนักคูณผลตอบแทนแล้วบวก” ราวกับเป็นเรื่องที่รู้กันอยู่แล้ว ขั้นนี้จะพิสูจน์ว่ามันถูก โดยเริ่มจากนิยามของผลตอบแทนพอร์ต $R_p$ ซึ่งคือ มูลค่าปลายงวดลบมูลค่าต้นงวด แล้วหารด้วยมูลค่าต้นงวด

ตอนต้นงวด พอร์ตมีมูลค่า $N$ ถ้าหุ้นตัวที่ $i$ ให้ผลตอบแทน $r_i$ เงิน $d_i$ ที่วางไว้จะกลายเป็น $d_i(1+r_i)$ เงินสดก็ได้ดอกเบี้ย $r_c$ จึงกลายเป็น $C(1+r_c)$ มูลค่าปลายงวด $V_1$ คือผลรวมของทั้งหมดนี้

\[ \begin{aligned} V_1&=\sum_i d_i(1+r_i)+C(1+r_c),\\ N&=\sum_i d_i+C,\\ R_p=\frac{V_1-N}{N}&=\sum_i\frac{d_i}{N}\,r_i+\frac{C}{N}\,r_c\\ &=\mathbf w^{\mathsf T}\mathbf r+w_cr_c. \end{aligned} \]

จุดที่ต้องดูคือตอนลบ $N$ ออกจาก $V_1$ เมื่อกระจายวงเล็บ $d_i(1+r_i)=d_i+d_ir_i$ ส่วน $d_i$ ของทุกหุ้นบวกกับ $C$ ได้ $\sum_i d_i+C=N$ พอดี มันจึงหักกับ $N$ หมด เหลือแค่ส่วนที่โตขึ้น $d_ir_i$ และ $Cr_c$

จากนั้นหารด้วย $N$ ทีละพจน์ เพราะ $d_i/N$ ก็คือน้ำหนัก $w_i$ และ $C/N$ คือ $w_c$ จึงได้น้ำหนักคูณผลตอบแทนบวกกัน เราไม่ได้สมมติอะไรเพิ่มเลย และสูตรนี้ใช้กับ short ได้ด้วย เพราะไม่มีขั้นไหนห้าม $d_i$ ติดลบ

ผลรวม $\sum_iw_ir_i$ คือ dot product ของ $\mathbf w$ กับ $\mathbf r$ ในภาษา matrix เขียนว่า $\mathbf w^{\mathsf T}\mathbf r$ คือแถว $\mathbf w^{\mathsf T}$ คูณคอลัมน์ $\mathbf r$

ทีนี้ใส่ตัวเลขของพอร์ตเรา เงินสดในตัวอย่างนี้ไม่ได้ดอกเบี้ย จึงให้ $r_c=0$

\[ \begin{aligned} \mathbf w^{\mathsf T}\mathbf r &=0.50(0.012)+0.30(-0.006)\\ &\quad-0.20(0.004)\\ &=0.0060-0.0018-0.0008\\ &=0.0034,\\ R_p&=0.0034+0.40(0)=0.34\%,\\ \Delta V&=NR_p=25{,}000{,}000(0.0034)\\ &=85{,}000. \end{aligned} \]

ได้คำตอบเดียวกับเฉลยต้นหน้า คือกำไร \$85,000 และสามพจน์ $0.0060$, $-0.0018$, $-0.0008$ ก็คือสามแท่งในรูปน้ำตก ถ้าคูณ NAV จะได้ \$150,000, −\$45,000 และ −\$20,000 ตามลำดับ

สังเกตว่าเราใช้ผลตอบแทนของ NVDA ตามที่เกิดจริง คือ $+0.004$ ไม่ได้กลับเครื่องหมาย เพราะเครื่องหมายลบของ short อยู่ในน้ำหนัก $-0.20$ แล้ว

อย่าสับสน 0.34% กับค่าเฉลี่ยของผลตอบแทนสามหุ้น ซึ่งคือ $(1.2-0.6+0.4)/3\approx0.33\%$ สองตัวเลขนี้บังเอิญใกล้กัน แต่ค่าเฉลี่ยไม่สนว่าเราวางเงินในหุ้นแต่ละตัวเท่าไร และไม่สนว่าตัวไหน short ส่วน 0.34% คือผลตอบแทนของ NAV ทั้งก้อน

ขั้นที่ 4 — มิติด้านในต้องเท่ากัน และลำดับการคูณเปลี่ยนชนิดคำตอบ

ขั้นที่ 3 เราคูณแถวกับคอลัมน์แล้วได้ตัวเลขตัวเดียว ถ้าสลับให้คอลัมน์อยู่หน้าแถวล่ะ จะได้อะไร ก่อนตอบ ต้องรู้กฎการคูณ matrix แบบทั่วไปก่อน เพราะแถวคูณคอลัมน์เป็นแค่กรณีที่เล็กที่สุดของมัน

ให้ $A$ มี $m$ แถว $d$ คอลัมน์ และ $B$ มี $d$ แถว $p$ คอลัมน์ ผลคูณ $AB$ มีตัวเลขที่แถว $i$ คอลัมน์ $j$ เขียนว่า $c_{ij}$ ตัวเลขนี้คือแถว $i$ ของ $A$ dot กับคอลัมน์ $j$ ของ $B$ ($a_{ik}$ คือตัวเลขแถว $i$ คอลัมน์ $k$ ของ $A$ และ $b_{kj}$ ก็อ่านแบบเดียวกัน)

\[ \begin{aligned} c_{ij}&=\sum_{k=1}^{d}a_{ik}b_{kj},\\ (m\times d)(d\times p)&\to m\times p,\\ (1\times3)(3\times1)&\to1\times1,\\ (3\times1)(1\times3)&\to3\times3. \end{aligned} \]

ดู shape ที่เขียนเรียงกัน $(m\times d)(d\times p)$ เลขสองตัวที่อยู่ติดกันตรงกลาง (ตัว $d$ ทั้งคู่) ต้องเท่ากัน เพราะแถวของ $A$ ต้องยาวเท่าคอลัมน์ของ $B$ ไม่อย่างนั้นจะมีช่องที่ไม่มีคู่ให้คูณ เลขสองตัวที่อยู่ริมนอก ($m$ กับ $p$) บอก shape ของผลคูณ

แถวคูณคอลัมน์ $(1\times3)(3\times1)$ จึงได้ $1\times1$ คือตัวเลขตัวเดียว ถ้าสลับเป็นคอลัมน์คูณแถว $(3\times1)(1\times3)$ เลขตรงกลางคือ 1 กับ 1 ซึ่งเท่ากัน จึงคูณได้ แต่ได้ตาราง $3\times3$ ที่เก็บผลคูณทุกคู่ รวมทั้งคู่ที่ข้ามหุ้นกัน ตารางนี้เรียกว่า outer product

ด้านล่างคือ outer product $\mathbf r\mathbf w^{\mathsf T}$ ของพอร์ตเรา ส่วนตัวอย่างที่สองคือ matrix $2\times3$ คูณคอลัมน์ $3\times1$ เพื่อดูว่ากฎ $c_{ij}$ ทำงานอย่างไรกับตัวเลขง่าย ๆ

\[ \begin{aligned} \mathbf r\mathbf w^{\mathsf T} &=\begin{bmatrix} 0.0060&0.0036&-0.0024\\ -0.0030&-0.0018&0.0012\\ 0.0020&0.0012&-0.0008 \end{bmatrix},\\ \begin{bmatrix}2&3&7\\1&6&5\end{bmatrix} \begin{bmatrix}2\\6\\4\end{bmatrix} &=\begin{bmatrix}2(2)+3(6)+7(4)\\1(2)+6(6)+5(4)\end{bmatrix}\\ &=\begin{bmatrix}50\\58\end{bmatrix}. \end{aligned} \]

ตัวเลขที่แถว $i$ คอลัมน์ $j$ ของ outer product คือ $r_iw_j$ เช่น แถวบนสุด คอลัมน์กลาง คือ $0.012\times0.30=0.0036$ นี่คือผลตอบแทนของ AAPL คูณน้ำหนักของ JPM ซึ่งไม่ได้แทนเงินก้อนไหนในพอร์ตเลย ตัวเลขที่มีความหมายมีแค่แนวทแยง $0.0060$, $-0.0018$, $-0.0008$ ซึ่งคือส่วนที่หุ้นแต่ละตัวให้พอร์ต และผลรวมแนวทแยง $0.0060-0.0018-0.0008=0.0034$ ก็เท่ากับ dot product พอดี บทเรียนคือ shape ที่คูณได้ไม่ได้รับประกันว่าเราตอบคำถามที่ถูก

ตัวอย่างที่สองแสดงกฎ $c_{ij}$ ตรง ๆ: matrix $2\times3$ คูณคอลัมน์ $3\times1$ ได้ $2\times1$ เพราะแต่ละแถวของ matrix dot กับคอลัมน์แยกกัน ได้หนึ่งคำตอบต่อหนึ่งแถว

กฎนี้มีประโยชน์จริงเมื่อเรามีผลตอบแทนหลายวัน ให้แต่ละแถวของ matrix $R$ เป็นผลตอบแทนของหุ้นสามตัวในหนึ่งวัน แถวแรกคือวันนี้ แถวที่สองคือวันถัดไป (ตัวเลขสมมติ) แล้วคูณด้วย $\mathbf w$ ครั้งเดียว ได้ผลตอบแทนพอร์ตทั้งสองวันพร้อมกัน

\[ \begin{aligned} R&=\begin{bmatrix}0.012&-0.006&0.004\\-0.010&0.005&-0.020\end{bmatrix},\\ (R\mathbf w)_1&=0.0060-0.0018-0.0008\\ &=0.0034,\\ (R\mathbf w)_2&=0.50(-0.010)+0.30(0.005)\\ &\quad-0.20(-0.020)\\ &=-0.0050+0.0015+0.0040\\ &=0.0005. \end{aligned} \]

วันแรกพอร์ตได้ 0.34% เหมือนเดิม วันที่สองได้ 0.05% การคูณครั้งเดียวทำงานแทนการวน loop ทีละวัน แต่มีเงื่อนไขซ่อนอยู่: เราใช้ $\mathbf w$ ชุดเดียวกับทั้งสองวัน ซึ่งถูกต้องก็ต่อเมื่อทุกเช้าพอร์ตปรับกลับไปที่น้ำหนักเดิม ถ้าถือจำนวนหุ้นคงที่ไว้เฉย ๆ หุ้นที่ราคาขึ้นจะมีน้ำหนักมากขึ้นเอง น้ำหนักจึงลอยไปตามราคา และใช้ $\mathbf w$ ชุดเดิมกับวันที่สองไม่ได้

ขั้นที่ 5 — มองตามคอลัมน์: เงินที่พอร์ตได้ในแต่ละสถานการณ์

ผู้จัดการพอร์ตไม่ได้ถามแค่ว่าวันนี้ได้เท่าไร เขาถามด้วยว่า “ถ้าปีหน้าตลาดขึ้น พอร์ตจะมีเงินเท่าไร และถ้าตลาดลงล่ะ” คำถามนี้ใช้ matrix คูณคอลัมน์แบบเดียวกับขั้นที่ 4 แต่เราจะเห็นอีกวิธีอ่านผลคูณ ที่สำคัญมากสำหรับหน้าถัดไป

ตัวอย่างนี้เป็นโลกจำลองที่เล็กที่สุด (ตัวเลขสมมติ)

  • ปีหน้าเกิดได้แค่สองสถานการณ์: ตลาดขึ้น หรือตลาดลง
  • หุ้น วันนี้ราคา \$100 ปีหน้ามีค่า \$120 ถ้าตลาดขึ้น และ \$80 ถ้าตลาดลง
  • bond (ตราสารหนี้ที่สัญญาว่าจะจ่ายเงินจำนวนแน่นอน) วันนี้ราคา \$100 ปีหน้าจ่าย \$105 ไม่ว่าตลาดจะขึ้นหรือลง
  • เราถือหุ้น 10 หน่วย และ bond 5 หน่วย

เงินที่สินทรัพย์หนึ่งหน่วยจ่ายตอนปลายงวดเรียกว่า payoff เราจัด payoff ของทุกสินทรัพย์ในทุกสถานการณ์ลงตาราง $S$ ให้แถวคือสถานการณ์ (แถว 1 ตลาดขึ้น แถว 2 ตลาดลง) และคอลัมน์คือสินทรัพย์ (คอลัมน์ 1 หุ้น คอลัมน์ 2 bond) จำนวนที่ถือเก็บใน $\boldsymbol\theta$ และราคาวันนี้เก็บใน $\mathbf p=(100,100)$

\[ \begin{aligned} S&=\begin{bmatrix}120&105\\80&105\end{bmatrix},\quad \boldsymbol\theta=\begin{bmatrix}10\\5\end{bmatrix},\\ \mathbf p^{\mathsf T}\boldsymbol\theta&=100(10)+100(5)=1{,}500,\\ S\boldsymbol\theta&=\begin{bmatrix}120(10)+105(5)\\80(10)+105(5)\end{bmatrix}\\ &=\begin{bmatrix}1{,}725\\1{,}325\end{bmatrix},\\ S\boldsymbol\theta&=10\begin{bmatrix}120\\80\end{bmatrix} +5\begin{bmatrix}105\\105\end{bmatrix}. \end{aligned} \]

ต้นทุนวันนี้ $\mathbf p^{\mathsf T}\boldsymbol\theta$ คือราคาคูณจำนวนแล้วบวก ได้ \$1,500 ผลคูณ $S\boldsymbol\theta$ คือเงินที่พอร์ตได้ปีหน้า และอ่านได้สองแบบ

อ่านทีละแถว: แต่ละแถวคือหนึ่งสถานการณ์ dot กับจำนวนที่ถือ ถ้าตลาดขึ้น พอร์ตได้ \$1,725 ถ้าตลาดลง ได้ \$1,325 นี่คือวิธีที่เราใช้มาตลอดในขั้นที่ 4

อ่านทีละคอลัมน์ (แถวสุดท้ายของสูตร): payoff ของพอร์ตคือคอลัมน์ของหุ้นคูณ 10 บวกคอลัมน์ของ bond คูณ 5 ลองบวกดู $10(120)+5(105)=1{,}725$ และ $10(80)+5(105)=1{,}325$ ได้ตัวเลขเดียวกัน เพราะเป็นผลบวกของพจน์ชุดเดียวกัน แค่จัดกลุ่มต่างกัน

ทำไมต้องสนใจแบบคอลัมน์ เพราะมันเปลี่ยนคำถามการเงินให้เป็นคำถามเรขาคณิต ให้แกนนอนคือ “เงินที่ได้ถ้าตลาดขึ้น” และแกนตั้งคือ “เงินที่ได้ถ้าตลาดลง” payoff ของสินทรัพย์แต่ละตัวก็เป็นลูกศรในระนาบนี้ (ดูรูปถัดไป) คำถามว่า “ใช้หุ้นกับ bond สร้างพอร์ตที่จ่ายแบบไหนได้บ้าง” จึงกลายเป็นคำถามว่า “ลูกศรสองเส้นนี้ผสมกันไปถึงจุดไหนได้บ้าง”

ขั้นที่ 6 — จากน้ำหนักเป็นดอลลาร์: net, gross และ NAV

กลับมาที่พอร์ตสามหุ้น ทุกวันฝ่ายบริหารความเสี่ยงจะถามสองคำถามที่ผลตอบแทนตอบไม่ได้ ข้อแรก พอร์ตเอียงไปทางไหน คือถ้าทั้งตลาดขึ้น พอร์ตได้หรือเสีย และมากแค่ไหน ข้อสอง พอร์ตถือของรวมใหญ่แค่ไหน สองคำถามนี้ตอบด้วยตัวเลขสองตัวชื่อ net exposure กับ gross exposure ทั้งคู่คิดจาก vector เงินที่ถือ $\mathbf d=N\mathbf w$ คือน้ำหนักทุกช่องคูณ NAV (หน่วยล้านดอลลาร์) $|d_i|$ คือขนาดของ $d_i$ โดยทิ้งเครื่องหมาย

\[ \begin{aligned} \mathbf d=N\mathbf w&=\begin{bmatrix}12.5\\7.5\\-5\end{bmatrix},\\ \text{net}=\sum_i d_i&=15,\\ \text{gross}=\sum_i|d_i|&=25,\\ \text{NAV}=\text{net}+C&=15+10=25. \end{aligned} \]

net บวกตามเครื่องหมาย ส่วนที่ short จึงหักล้างส่วนที่ซื้อไว้ $12.5+7.5-5=15$ ได้ \$15 ล้าน คิดเป็น $15/25=60\%$ ของ NAV แปลว่าพอร์ตเอียงไปทางได้ประโยชน์เมื่อตลาดขึ้น

gross บวกขนาดโดยทิ้งเครื่องหมาย $12.5+7.5+5=25$ ได้ \$25 ล้าน คิดเป็น $25/25=100\%$ ของ NAV ที่ gross เท่ากับ NAV พอดีเป็นความบังเอิญ ไม่ใช่กฎ ถ้า short เพิ่มอีก gross จะเกิน NAV ได้ หน้า norms จะเรียก gross ว่า L1 norm ของ $\mathbf d$

ทำไม net จึงบอกความเอียงต่อตลาด ลองให้หุ้นทั้งสามขึ้น 1% พร้อมกัน ทุกช่องของ $\mathbf r$ เป็น 0.01 จึงดึง 0.01 ออกมานอกผลบวกได้ $\mathbf w^{\mathsf T}\mathbf r=0.01(0.50+0.30-0.20)=0.01\times0.60=0.60\%$ ของ NAV ตัว 0.60 ที่เหลืออยู่คือ net หารด้วย NAV นั่นเอง

แต่ตลาดจริงไม่ได้ให้หุ้นทุกตัวขยับเท่ากัน พอร์ตที่ net เป็นศูนย์จึงยังขาดทุนได้ ถ้าหุ้นฝั่งที่ซื้อไว้ราคาลง ขณะที่หุ้นฝั่งที่ short ราคาขึ้น

ขั้นที่ 7 — แปลงน้ำหนักเป็นจำนวนหุ้น แล้ว rebalance ด้วยการลบ vector

ผู้จัดการพอร์ตคิดเป็นน้ำหนัก แต่โบรกเกอร์ (บริษัทที่รับคำสั่งไปซื้อขายในตลาด) ไม่รับคำสั่งว่า “ซื้อ A ให้ได้ 35%” คำสั่งต้องเป็นจำนวนหุ้น ขั้นนี้จึงแปลงน้ำหนักเป็นจำนวนหุ้น แล้วดูว่าเมื่อเปลี่ยนน้ำหนักเป้าหมาย ต้องซื้อขายอะไรบ้าง การปรับพอร์ตให้กลับไปตรงน้ำหนักเป้าหมายแบบนี้เรียกว่า rebalance

ขั้นนี้ใช้พอร์ตสมมติอีกชุด เป็นกองทุนใหม่ที่เพิ่งได้เงินมา

  • NAV $N=\$10$ ล้าน ทั้งหมดเป็นเงินสดก่อนเริ่มซื้อ
  • หุ้นสี่ตัวชื่อ A, B, C, D ราคา $\mathbf p=(142,68,205,33)$ ดอลลาร์ต่อหุ้น
  • น้ำหนักเป้าหมาย 35%, 25%, 30% และ 10% ตามลำดับ
  • ซื้อได้เฉพาะหุ้นเต็มตัว จึงปัดจำนวนเป็นจำนวนเต็มที่ใกล้ที่สุด

จำนวนหุ้นที่ต้องการ $n_i^*$ (ก่อนปัด) คือเงินที่อยากวางในหุ้นตัวนั้น หารด้วยราคาหนึ่งหุ้น หลังปัดแล้ว มูลค่าหุ้นรวม $V$ คือ dot product ของจำนวนหุ้นกับราคา และเงินสดคือ NAV ลบมูลค่าหุ้น

\[ \begin{aligned} n_i^*&=\frac{Nw_i}{p_i},\\ n_A^*&=\frac{10{,}000{,}000(0.35)}{142}\approx24{,}647.9,\\ V&=\mathbf n^{\mathsf T}\mathbf p=10{,}000{,}005,\\ C&=10{,}000{,}000-V=-5. \end{aligned} \]

หุ้นตัวอื่นคิดแบบเดียวกับ A ตารางด้านล่างคือผลหลังปัด คอลัมน์มูลค่าคือจำนวนคูณราคา เช่น $24{,}648\times142=3{,}500{,}016$ และ $V$ ในสูตรบนคือผลรวมของคอลัมน์นี้

หุ้นราคา (ดอลลาร์)เป้าหมายจำนวนที่ปัดมูลค่า (ดอลลาร์)
A14235%24,6483,500,016

คำตอบ: มูลค่าหุ้นรวมคือ \$10,000,005 เกินเงินที่มีอยู่ \$5 การปัดเศษไม่ได้เสกเงิน \$5 ขึ้นมา มันทำให้เงินสดติดลบ \$5 แทน คือติดค้างโบรกเกอร์อยู่ \$5 ส่วน NAV ยังเป็น \$10 ล้านเท่าเดิม ถ้ากองทุนห้ามเงินสดติดลบ ให้ซื้อ D น้อยลงหนึ่งหุ้น เงินสดจะกลายเป็น $-5+33=\$28$

ต่อมาผู้จัดการเปลี่ยนใจ อยากได้น้ำหนัก 25% เท่ากันทุกตัว ราคายังเท่าเดิม เราคำนวณจำนวนหุ้นใหม่ $\mathbf n_{\text{new}}$ ด้วยสูตรเดิมแล้วปัด เช่น $n_{A,\text{new}}=2{,}500{,}000/142\approx17{,}605.6$ ปัดเป็น 17,606 รายการที่ต้องส่งให้โบรกเกอร์คือผลต่าง $\Delta\mathbf n=\mathbf n_{\text{new}}-\mathbf n$ ลบกันทีละช่อง ค่าลบคือขาย ค่าบวกคือซื้อ

จากนั้นเราถามสองเรื่อง เรื่องแรก ต้องจ่ายเงินสดออกไปสุทธิเท่าไร คือ $\Delta\mathbf n^{\mathsf T}\mathbf p$ ซึ่งบวกมูลค่าคำสั่งตามเครื่องหมาย (net) เรื่องที่สอง คำสั่งทั้งหมดรวมกันใหญ่แค่ไหน คือ $\sum_i|\Delta n_i|\,p_i$ ซึ่งบวกมูลค่าคำสั่งโดยทิ้งเครื่องหมาย (gross)

\[ \begin{aligned} \mathbf n_{\text{new}}&=\begin{bmatrix}17{,}606\\36{,}765\\12{,}195\\75{,}758\end{bmatrix},\quad \Delta\mathbf n=\begin{bmatrix}-7{,}042\\0\\-2{,}439\\45{,}455\end{bmatrix},\\ \Delta\mathbf n^{\mathsf T}\mathbf p&=56,\\ \textstyle\sum_i|\Delta n_i|\,p_i&=2{,}999{,}974. \end{aligned} \]

คำตอบ: คำสั่งมีสามรายการ B ไม่ต้องทำอะไร

\[ \begin{aligned} \text{A}&:\;-7{,}042\times142=-\$999{,}964,\\ \text{C}&:\;-2{,}439\times205=-\$499{,}995,\\ \text{D}&:\;45{,}455\times33=+\$1{,}500{,}015. \end{aligned} \]

net ของคำสั่งคือ $1{,}500{,}015-999{,}964-499{,}995=\$56$ เงินที่จ่ายซื้อ D มากกว่าเงินที่ได้จากการขาย A กับ C อยู่ \$56 เงินสดจึงลดจาก $-\$5$ เป็น $-5-56=-\$61$ ก่อนหักค่าธรรมเนียม

แต่ gross ของคำสั่งคือ $999{,}964+499{,}995+1{,}500{,}015=\$2{,}999{,}974$ เกือบ \$3 ล้าน ค่าซื้อขายคิดจากตัวเลขนี้ ถ้าค่าซื้อขายคือ 10 basis points ของยอดรวม (1 basis point คือ 0.01% จึง 10 basis points คือ 0.001) จะเสีย $0.001\times2{,}999{,}974\approx\$3{,}000$ ไม่ใช่ $0.001\times56$ ซึ่งแทบเป็นศูนย์

ความผิดที่ทำให้ตัวเลขผิดโดยไม่มี error

ความผิดทุกข้อในส่วนนี้ให้ shape ที่ถูกต้อง โปรแกรมจึงคำนวณต่อไปได้โดยไม่ขึ้น error ตัวเลขที่ผิดจะไปโผล่ในรายงานเลย คำตอบที่ถูกของพอร์ตสามหุ้นคือ $\mathbf w^{\mathsf T}\mathbf r=0.0034$ หรือกำไร \$85,000

ลำดับช่องไม่ตรงกัน: ไฟล์ผลตอบแทนเรียง NVDA, JPM, AAPL แต่น้ำหนักเรียง AAPL, JPM, NVDA ผลที่ได้คือ $0.50(0.004)+0.30(-0.006)-0.20(0.012)=-0.0022$ คูณ NAV ได้ $25{,}000{,}000\times(-0.0022)=-\$55{,}000$ แทนที่จะเป็นกำไร \$85,000 วิธีป้องกันคือจับคู่ข้อมูลด้วยรหัสหุ้นและวันที่ก่อน แล้วค่อยแปลงเป็น vector

ลืมแปลง % เป็นเศษส่วน: ใส่ $(1.2,-0.6,0.4)$ แทน $(0.012,-0.006,0.004)$ จะได้ $\mathbf w^{\mathsf T}\mathbf r=0.34$ ถ้าเอาไปคูณ NAV ตรง ๆ ได้ $25{,}000{,}000\times0.34=\$8.5$ ล้าน ใหญ่กว่าความจริง $8{,}500{,}000/85{,}000=100$ เท่า เพราะทุกผลตอบแทนใหญ่ไป 100 เท่า

กลับเครื่องหมายของ short ซ้ำสองรอบ: น้ำหนัก NVDA ติดลบอยู่แล้ว ถ้ากลับเครื่องหมายผลตอบแทนเป็น $-0.004$ อีก ส่วนของ NVDA จะกลายเป็น $(-0.20)(-0.004)=+0.0008$ ผลรวมเป็น $0.0060-0.0018+0.0008=0.0050$ หรือ $25{,}000{,}000\times0.0050=\$125{,}000$ สูงเกินจริง $125{,}000-85{,}000=\$40{,}000$

หารด้วยเงินส่วนที่อยู่ในหุ้น แต่คูณกลับด้วย NAV: net ของหุ้นคือ \$15 ล้าน ถ้าคิดน้ำหนักโดยหารด้วย 15 แทน 25 จะได้

\[ \begin{aligned} \tilde{\mathbf w}&=\tfrac{1}{15}(12.5,\,7.5,\,-5)\\ &=(0.833,\,0.5,\,-0.333),\\ \tilde{\mathbf w}^{\mathsf T}\mathbf r&=0.833(0.012)+0.5(-0.006)\\ &\quad-0.333(0.004)\\ &\approx0.00567. \end{aligned} \]

0.567% นี้คือผลตอบแทนต่อเงินที่อยู่ในหุ้น ไม่ใช่ต่อ NAV ถ้าคูณกลับด้วย \$15 ล้าน ได้ $15{,}000{,}000\times0.00567\approx\$85{,}000$ ถูกต้อง แต่ถ้าเผลอคูณด้วย NAV จะได้ $25{,}000{,}000\times0.00567\approx\$141{,}667$ ตัวที่ใช้หารกับตัวที่ใช้คูณกลับต้องเป็นตัวเดียวกัน

ผสมเวลา: ใช้น้ำหนักตอนปิดตลาดกับผลตอบแทนของวันเดียวกัน สมมติว่าตอนปิดตลาดเพิ่งซื้อหุ้นตัวหนึ่งเข้ามา น้ำหนักตอนปิดตลาดจะมีหุ้นตัวนั้นอยู่ เราจึงนับกำไรของทั้งวันให้หุ้นที่ไม่ได้ถือระหว่างวันเลย น้ำหนักที่ถูกต้องคือน้ำหนักตอนต้นงวด ตอนที่ผลตอบแทนเริ่มนับ

ใช้ทำอะไรบนโต๊ะจริง

ระบบที่คิดกำไรขาดทุน (P&L ย่อมาจาก profit and loss) ของโต๊ะเทรด ไม่ได้เก็บพอร์ตเป็นรายการตัวเลขเปล่า ๆ มันเก็บเป็นตารางที่มีรหัสหุ้นกำกับทุกแถว แล้วค่อยแปลงเป็น vector ตอนจะคำนวณ เพื่อกันความผิดแบบลำดับช่องไม่ตรงกัน

รูปน้ำตกต้นหน้ามีชื่อเรียกว่า P&L attribution คือการแยกว่ากำไรขาดทุนของวันมาจากหุ้นตัวไหนเท่าไร ผู้จัดการพอร์ตดูรายงานแบบนี้ทุกเย็น

ส่วนตาราง payoff $S$ เป็นจุดเริ่มของงาน hedge คือการถือสินทรัพย์ไว้เพื่อให้มีเงินพอจ่ายภาระ (เงินที่พอร์ตต้องจ่ายคนอื่น) ไม่ว่าเกิดสถานการณ์ไหน คำถามคือ ควรถือ $\boldsymbol\theta$ เท่าไร ให้ต้นทุนวันนี้ $\mathbf p^{\mathsf T}\boldsymbol\theta$ ต่ำที่สุด โดยที่เงินที่ได้ $S\boldsymbol\theta$ ยังพอจ่ายภาระในทุกแถว ปัญหาแบบนี้เรียกว่า linear program คือการหาค่าที่ดีที่สุด เมื่อทั้งเป้าหมายและเงื่อนไขเป็นผลบวกของตัวแปรคูณค่าคงที่

โจทย์ตรวจความเข้าใจ

1. พอร์ตสามหุ้นเดิม น้ำหนักเดิม $\mathbf w=(0.50,0.30,-0.20)$ และ NAV \$25 ล้าน วันนี้ AAPL ขึ้น 1.2% และ JPM ลง 0.6% เหมือนต้นหน้า แต่ NVDA ซึ่งเรา short ไว้ ลง 0.4% แทนที่จะขึ้น พอร์ตได้หรือเสียกี่ดอลลาร์

เฉลย

เปลี่ยนแค่ช่องที่ 3 ของ $\mathbf r$ เป็น $-0.004$ แล้วคูณใหม่

\[ \begin{aligned} \mathbf w^{\mathsf T}\mathbf r&=0.50(0.012)+0.30(-0.006)\\ &\quad+(-0.20)(-0.004)\\ &=0.0060-0.0018+0.0008\\ &=0.0050,\\ \Delta V&=25{,}000{,}000\times0.0050\\ &=\$125{,}000. \end{aligned} \]

พอร์ตได้ \$125,000 มากกว่าเดิม $125{,}000-85{,}000=\$40{,}000$ เพราะหุ้นที่เรา short ไว้ราคาลง เราจึงซื้อคืนได้ถูกลง

2. ผู้จัดการอยากได้ผลตอบแทนมากขึ้น จึงเพิ่มน้ำหนักหุ้นทั้งสามเป็นสองเท่า $\mathbf w=(1.00,0.60,-0.40)$ NAV ยังเป็น \$25 ล้าน ถ้าวันนี้ผลตอบแทนเหมือนต้นหน้า พอร์ตได้เท่าไร และ net, gross, เงินสด เป็นเท่าไร

เฉลย
\[ \begin{aligned} \mathbf w^{\mathsf T}\mathbf r&=1.00(0.012)+0.60(-0.006)\\ &\quad-0.40(0.004)\\ &=0.0068,\\ \Delta V&=25{,}000{,}000\times0.0068\\ &=\$170{,}000,\\ \mathbf d=N\mathbf w&=(25,\,15,\,-10),\\ \text{net}&=25+15-10=30,\\ \text{gross}&=25+15+10=50,\\ C&=N-\text{net}=25-30=-5. \end{aligned} \]

ผลตอบแทนเป็นสองเท่าของเดิมคือ 0.68% หรือ \$170,000 net \$30 ล้าน gross \$50 ล้าน และเงินสดติดลบ \$5 ล้าน แปลว่าพอร์ตต้องกู้เงินมา \$5 ล้านเพื่อถือหุ้นมากกว่า NAV ที่มี การคูณ vector น้ำหนักด้วย 2 ทำให้ทุกตัวเลขที่คำนวณแบบคูณแล้วบวกเป็นสองเท่าตาม แต่ดอกเบี้ยเงินกู้และค่ายืมหุ้นที่ต้องจ่ายจริงยังไม่อยู่ในการคำนวณนี้

3. กลับไปที่โลกสองสถานการณ์ในขั้นที่ 5 หุ้นวันนี้ราคา \$100 ปีหน้าจ่าย \$120 ถ้าตลาดขึ้น หรือ \$80 ถ้าตลาดลง bond วันนี้ราคา \$100 ปีหน้าจ่าย \$105 เสมอ ครั้งนี้เรา short หุ้น 5 หน่วยและซื้อ bond 10 หน่วย ต้นทุนวันนี้เท่าไร และปีหน้าได้เงินเท่าไรในแต่ละสถานการณ์

เฉลย

short หุ้น 5 หน่วยเขียนเป็นจำนวนติดลบ จึงได้ $\boldsymbol\theta=(-5,10)$ แล้วใช้ $\mathbf p^{\mathsf T}\boldsymbol\theta$ กับ $S\boldsymbol\theta$ แบบเดียวกับขั้นที่ 5

\[ \begin{aligned} \mathbf p^{\mathsf T}\boldsymbol\theta&=100(-5)+100(10)=500,\\ (S\boldsymbol\theta)_{\text{up}}&=120(-5)+105(10)=450,\\ (S\boldsymbol\theta)_{\text{down}}&=80(-5)+105(10)=650. \end{aligned} \]

ต้นทุนวันนี้ \$500 ปีหน้าได้ \$450 ถ้าตลาดขึ้น และ \$650 ถ้าตลาดลง พอร์ตนี้ได้มากกว่าเมื่อหุ้นลง ในรูประนาบ payoff จุด $(450,650)$ อยู่เหนือเส้นทแยง 45 องศา เพราะพิกัดแนวตั้ง (เงินเมื่อตลาดลง) มากกว่าพิกัดแนวนอน (เงินเมื่อตลาดขึ้น)

array ใน JavaScript ไม่รู้ว่าตัวเองเป็นแถวหรือคอลัมน์ มันเป็นแค่รายการตัวเลข โค้ดนี้จึงเขียน dot product เอง ตรวจว่าสองรายการยาวเท่ากันก่อนคูณ และจัดเรียงผลตอบแทนตามชื่อหุ้นก่อน เพื่อกันความผิดแบบลำดับช่องไม่ตรงกัน ตัวเลขหลักของหน้านี้ เช่น \$85,000, outer product, payoff และรายการซื้อขาย ออกมาจากสคริปต์นี้

function dot(a, b) {
  if (a.length !== b.length) throw new RangeError('Mismatched lengths');
  return a.reduce((s, x, i) => s + x * b[i], 0);
}
const names = ['AAPL', 'JPM', 'NVDA'];
const w = [0.50, 0.30, -0.20];
const byName = {NVDA: 0.004, AAPL: 0.012, JPM: -0.006};
const r = names.map(n => byName[n]);          // align by name first
const nav = 25e6;
const contrib = w.map((x, i) => x * r[i]);    // 0.006, -0.0018, -0.0008
const Rp = dot(w, r);                          // 0.0034
const wrong = dot(w, [0.004, -0.006, 0.012]);  // -0.0022
const outer = r.map(ri => w.map(wj => ri * wj));
const days = [r, [-0.010, 0.005, -0.020]].map(row => dot(row, w));
const S = [[120, 105], [80, 105]], theta = [10, 5];
const payoff = S.map(row => dot(row, theta)); // 1725, 1325
const cost = dot([100, 100], theta);           // 1500
const d = w.map(x => nav * x);
const net = d.reduce((s, x) => s + x, 0), gross = d.reduce((s, x) => s + Math.abs(x), 0);
const p = [142, 68, 205, 33], target = [0.35, 0.25, 0.30, 0.10], cap = 1e7;
const n = target.map((t, i) => Math.round(cap * t / p[i]));
const nNew = p.map(pi => Math.round(cap / 4 / pi));
const dn = nNew.map((x, i) => x - n[i]);
console.log({contrib, Rp, pnl: nav * Rp, wrongPnl: nav * wrong, outer, days,
  payoff, cost, d, net, gross, cash: nav - net,
  n, stockValue: dot(n, p), nNew, dn, netTrade: dot(dn, p),
  grossTrade: dot(dn.map(Math.abs), p)});

สิ่งที่ควรตอบได้หลังอ่าน

  • ทุกช่องของ vector ต้องบอกได้ว่าเป็นสินทรัพย์ไหน วันไหน หน่วยอะไร shape ที่คูณกันได้ไม่ได้แปลว่าข้อมูลจับคู่ถูก ไฟล์ที่เรียงผิดเปลี่ยนกำไร \$85,000 เป็นขาดทุน \$55,000 โดยไม่มี error
  • ผลตอบแทนพอร์ต $R_p=\mathbf w^{\mathsf T}\mathbf r+w_cr_c$ มาจากนิยามของผลตอบแทนโดยตรง เพราะเงินต้นของทุกสถานะรวมกันเท่ากับ NAV แล้วหักกับ NAV หมด เหลือแค่ส่วนที่โตขึ้น
  • $(m\times d)(d\times p)$ ได้ $m\times p$ เลขตรงกลางต้องเท่ากัน เลขริมนอกบอก shape ของคำตอบ แถวคูณคอลัมน์ได้ตัวเลขตัวเดียว คอลัมน์คูณแถวได้ตาราง และ matrix คูณ vector ได้หนึ่งคำตอบต่อหนึ่งแถว
  • $S\boldsymbol\theta$ อ่านได้สองแบบ แบบแถวคือเงินที่ได้ทีละสถานการณ์ แบบคอลัมน์คือคอลัมน์ payoff ของแต่ละสินทรัพย์คูณจำนวนที่ถือแล้วบวกกัน
  • net (บวกตามเครื่องหมาย) กับ gross (บวกโดยทิ้งเครื่องหมาย) เป็นคนละตัวเลข ทั้งของเงินที่ถือและของรายการซื้อขาย ค่าซื้อขายคิดจาก gross

หน้าถัดไป linear combinations และ linear independence ใช้มุมมองคอลัมน์เต็มตัว: ถามว่าคอลัมน์ของสินทรัพย์ที่มีอยู่ผสมกันไปถึง payoff หรือพอร์ตแบบไหนได้บ้าง และกองทุนชื่อใหม่เพิ่มทางเลือกจริงหรือแค่ซ้ำของเดิม
