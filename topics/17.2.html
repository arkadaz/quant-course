17.2 The Kelly Criterion

Kelly เลือกสัดส่วนของทุนที่เสี่ยงต่อรอบให้ค่าเฉลี่ยของ log การเติบโตสูงสุด เพราะเงินคูณกันข้ามรอบ ไม่ได้บวกกัน

ทุน \$1,000,000 เกมหนึ่งชนะ 55% แพ้ 45% จ่ายหนึ่งต่อหนึ่ง เสี่ยง \$1 ชนะได้ \$1 แพ้เสีย \$1 เทรดเดอร์คนหนึ่งบอกว่า “ได้เปรียบอยู่แล้ว ยิ่งลงมากยิ่งได้มาก ลงรอบละ 20% ของทุนไปเลย” ควรเสี่ยงกี่เปอร์เซ็นต์ของทุนต่อรอบจึงจะโตเร็วที่สุดในระยะยาว และรอบละ 20% จะเป็นอย่างไร

ลองตอบก่อนเปิดเฉลย

ขนาด Kelly คือ 10% ของทุน ให้ค่าเฉลี่ยของ log ผลตอบแทนประมาณ 0.501% ต่อรอบ ถ้า 100 รอบชนะ 55 แพ้ 45 จะเหลือทุน 1.65 เท่า แต่ถ้าลง 40% ด้วยจำนวนชนะเท่ากัน จะเหลือ 1.13% ของทุนตั้งต้น

ที่ขนาด 20% ค่าเฉลี่ยของ log กลับติดลบประมาณ −0.014% ต่อรอบ เพราะเลยจุดศูนย์ที่ 19.87% ไปแล้ว แม้โอกาสชนะยังเป็น 55 ต่อ 45 เท่าเดิม ได้เปรียบแต่ลงใหญ่เกิน ทุนก็ค่อย ๆ หดได้

ภาพรวมก่อนลงสูตร

VaR และ Expected Shortfall วัดว่าพอร์ตอาจเสียเท่าไร หน้านี้ถามอีกด้าน เมื่อรู้ว่าได้เปรียบ ควรเสี่ยงเท่าไร คำตอบไม่ได้มาจากกำไรเฉลี่ยต่อรอบ เพราะเงินไม่ได้บวกกันข้ามรอบ มันคูณกัน แพ้ 50% ต้องชนะ 100% จึงกลับที่เดิม และ log เปลี่ยนการคูณเป็นการบวก (เหมือนตอนสร้าง lognormal distribution)

Kelly criterion เลือกสัดส่วน $f$ ที่ทำให้ค่าเฉลี่ยของ log ตัวคูณทุนต่อรอบสูงสุด ค่านี้คืออัตราที่ทุนของเส้นทางทั่วไปโตจริงในระยะยาว ในระยะยาวมาก กลยุทธ์ Kelly ทิ้งกลยุทธ์สัดส่วนคงที่แบบอื่นห่างออกไปเรื่อย ๆ แต่มันแกว่งแรง คนใช้จริงจึงมักลงแค่ครึ่งเดียว ซึ่งยังได้อัตราโตราวสามในสี่

หน้านี้คูณ 20 รอบด้วยมือก่อน แล้วใส่ log หาขนาดที่ดีที่สุดด้วย derivative ดูว่าครึ่งขนาดซื้ออะไรมา ทำไมค่าเฉลี่ยของเงินหลอกเรา และเกิดอะไรขึ้นเมื่อประเมินโอกาสชนะสูงไป จากนั้นเขียนแบบต่อเนื่องด้วย Itô จนได้ขนาดที่ขึ้นกับ Sharpe ratio

ขั้นที่ 1 — ลองด้วยมือ: 20 รอบ ชนะ 11 แพ้ 9 กับสี่ขนาด

ก่อนมี log และ derivative ลองคูณตรง ๆ ในเกม 55% ผลที่ “ปกติที่สุด” ของ 20 รอบคือชนะ 11 แพ้ 9 ชนะแต่ละรอบทุนคูณ $1+f$ แพ้คูณ $1-f$ ลำดับไม่สำคัญเพราะการคูณสลับที่ได้ ลองสี่ขนาดแล้วดูว่าไม้ใหญ่ให้เงินมากกว่าจริงไหม

\[ \begin{aligned} W_{20}&=W_0(1+f)^{11}(1-f)^{9},\\ f=0.05&:\ 1.71034(0.63025)=1.0779,\\ f=0.10&:\ 2.85312(0.38742)=1.1054,\\ f=0.20&:\ 7.43008(0.134218)=0.9972,\\ f=0.50&:\ 86.4976(0.00195313)\\ &=0.1689. \end{aligned} \]

เสี่ยง 5% ได้ +7.8% เสี่ยง 10% ได้ +10.5% แต่เสี่ยง 20% กลับขาดทุน 0.3% และเสี่ยงครึ่งทุนเหลือ 17% ของเงิน ทั้งที่ชนะมากกว่าแพ้สองรอบ เหตุคือแพ้ 50% ต้องชนะ 100% จึงกลับที่เดิม การคูณลงโทษการแกว่งแรงกว่าที่มันให้รางวัล

ขนาดที่ดีที่สุดอยู่แถว 10% ขั้นถัดไปจะหาด้วย calculus โดยใส่ log ให้บรรทัดแรก แล้วหารด้วยจำนวนรอบ

ขั้นที่ 2 — log เปลี่ยนผลคูณเป็นผลบวก

ทุนหลัง $n$ รอบเป็นผลคูณ ซึ่งวิเคราะห์ยาก ใส่ log แล้วมันกลายเป็นผลบวก และพอเป็นค่าเฉลี่ยของผลบวก law of large numbers ก็ใช้ได้ ให้แพ้แล้วเสีย $f$ ส่วนชนะแล้วได้ $bf$ เพื่อให้ใช้ได้กับอัตราจ่ายอื่นด้วย

\[ \begin{aligned} W_n&=W_0(1+bf)^{n_+}(1-f)^{n_-},\\ \frac1n\ln\frac{W_n}{W_0}&=\frac{n_+}{n}\ln(1+bf)\\ &\quad+\frac{n_-}{n}\ln(1-f),\\ \frac{n_+}{n}&\to p,\qquad \frac{n_-}{n}\to q,\\ g(f)&=p\ln(1+bf)+q\ln(1-f),\\ W_n&\approx W_0\,e^{n\,g(f)}. \end{aligned} \]

สมมติแต่ละรอบอิสระและใช้โอกาสชนะ $p$ เดิม เมื่อเล่นนาน สัดส่วนรอบที่ชนะเข้าใกล้ $p$ อัตราโตของ log ต่อรอบจึงเข้าใกล้ $g(f)$ ทุนของเส้นทางทั่วไปจึงโตราว $e^{ng}$ Kelly เลือก $f$ ที่ทำให้ $g$ สูงสุด ซึ่งเป็นคนละเป้าหมายกับการทำให้ค่าเฉลี่ยของเงินสูงสุด (เห็นชัดตอนนับครบ 400 รอบข้างล่าง)

บรรทัดสุดท้ายเป็นแค่ “ประมาณ” เพราะกฎจำนวนมากควบคุมค่าเฉลี่ยของ log ไม่ได้ควบคุมอัตราส่วนทุนจริงต่อ $W_0e^{ng}$ ทุนจริงหลัง 400 รอบอาจห่างจากเส้นนี้หลายเท่าได้ เงื่อนไข $0\le f\lt1$ ทำให้ทุนเป็นบวกหลังทุกผลลัพธ์ ถ้า $f=1$ แพ้รอบเดียวก็เหลือศูนย์ และ $\ln0$ เป็นลบอนันต์

ขั้นที่ 3 — หาจุดสูงสุด: $f^*=(pb-q)/b$

ตอนนี้ $g$ เป็นฟังก์ชันตัวแปรเดียวที่เรียบ หาจุดที่ความชันเป็นศูนย์ แล้วตรวจว่าเป็นยอด ไม่ใช่ก้นหลุม

\[ \begin{aligned} g'(f)&=\frac{pb}{1+bf}-\frac{q}{1-f}=0,\\ pb(1-f)&=q(1+bf),\\ pb-q&=bf(p+q)=bf,\\ f^*&=\frac{pb-q}{b}\\ &=\frac{0.55(1)-0.45}{1}=0.10,\\ g''(f)&=-\frac{pb^2}{(1+bf)^2}-\frac{q}{(1-f)^2}\\ &\lt0. \end{aligned} \]

คูณไขว้ได้บรรทัดที่สอง กระจายแล้วย้ายพจน์ที่มี $f$ ไปข้างเดียว เหลือ $bf(p+q)=bf$ ตัวเศษ $pb-q$ คือ edge หรือกำไรเฉลี่ยต่อเงินเสี่ยง \$1 ถ้า edge ไม่เป็นบวก คำตอบคือ $\max(0,(pb-q)/b)=0$ ไม่ลงเลย $g''$ เป็นลบทุกจุด จึงมียอดเดียว

อย่าอ่านเฉพาะตัวหาร $b$ เมื่ออัตราจ่ายเปลี่ยน ตัวเศษก็เปลี่ยนด้วย คง $p=0.55$ ไว้ จ่ายหนึ่งต่อหนึ่งได้ $f^*=0.10$ แต่จ่ายสองต่อหนึ่งได้ $(0.55\times2-0.45)/2=0.325$ จ่ายมากขึ้นจึงเสี่ยงมากขึ้น

รูปทั่วไปกว่านี้คือ ลงเงินสัดส่วน $x$ ชนะได้ $r_w$ ต่อ \$1 แพ้เสีย $r_l$ ต่อ \$1 ทำแบบเดียวกันได้ $x^*=p/r_l-q/r_w$ เขียนใหม่เป็น $\frac{p}{r_l}\big(1-\frac{1}{(p/q)(r_w/r_l)}\big)$ ขนาดโตตาม “อัตราชนะต่อแพ้” $p/q$ และ “ความเบ้ของการชนะ” $r_w/r_l$ ถ้าผลคูณของสองตัวนี้ไม่เกิน 1 ก็ไม่ควรลง เกมของเราคือ $r_w=r_l=1$ ได้ $0.55-0.45=0.10$ เท่ากัน ทุน \$1,000,000 จึงเสี่ยง \$100,000 ในรอบแรก

ขั้นที่ 4 — อัตราโตที่ห้าขนาด: ยอดที่ 10% หน้าผาเลย 20%

แทนค่า $g$ ที่ห้าขนาด แต่ละบรรทัดคือก้อนชนะถ่วงด้วย 0.55 ลบก้อนแพ้ถ่วงด้วย 0.45 เพื่อดูหน้าตาของเส้นโค้งรอบยอดในรูปภาพรวมข้างบน

\[ \begin{aligned} g(0.10)&=0.55\ln1.10+0.45\ln0.90\\ &=0.0524206-0.0474122\\ &=0.0050084,\\ g(0.05)&=0.0268346-0.0230820\\ &=0.0037526,\\ g(0.15)&=0.0768691-0.0731335\\ &=0.0037356,\\ g(0.20)&=0.1002769-0.1004146\\ &=-0.0001377,\\ g(0.40)&=0.1850597-0.2298715\\ &=-0.0448118. \end{aligned} \]

$\ln0.9=-0.10536$ ลึกกว่า $\ln1.1=0.09531$ ทั้งที่ขยับ 10% เท่ากัน ขาดทุน 10% เจ็บกว่ากำไร 10% เสมอเมื่อนับแบบทบต้น เพิ่มขนาด ก้อนแพ้จึงโตเร็วกว่าก้อนชนะ จนแซงที่ 19.87% (หาด้วย bisection) ที่ 20% หรือสองเท่าของ Kelly อัตราโตจึงติดลบแล้ว

ครึ่งขนาดให้ $0.0037526/0.0050084=0.749$ ของอัตราโตสูงสุด ถ้า 100 รอบชนะ 55 แพ้ 45 ขนาดเต็มให้ $e^{0.50084}\approx1.65$ เท่า ครึ่งขนาดให้ $e^{0.37526}\approx1.46$ เท่า และสี่เท่าของ Kelly ให้ $e^{-4.4812}\approx0.0113$ หรือเหลือ 1.13%

อีกมุมหนึ่งคือเวลาที่ใช้ทำทุนให้ถึงเป้า ทุนถึง $C$ เท่าเมื่อ $ng\approx\ln C$ ทำทุนเป็นสองเท่าใช้ราว $\ln2/0.0050084=138$ รอบที่ขนาดเต็ม และ $\ln2/0.0037526=185$ รอบที่ครึ่งขนาด ขนาด Kelly ถึงเป้าเร็วที่สุด และในระยะยาวมาก ทุนของ Kelly หารด้วยทุนของกลยุทธ์สัดส่วนคงที่ใดที่มี $g$ ต่ำกว่า จะโตไปไม่มีขอบเขตแทบแน่นอน ส่วนกลยุทธ์ใดที่ $g\lt0$ ทุนจะเข้าใกล้ศูนย์ แม้ได้เปรียบทุกรอบ

ขั้นที่ 5 — Kelly สั่งเป็นสัดส่วน ไม่ใช่จำนวนเงิน

สูตรให้สัดส่วน $f$ ของทุนปัจจุบัน ไม่ใช่เงินก้อนเดิมทุกรอบ ดูว่าหลังรอบแรกเงินเสี่ยงเปลี่ยนอย่างไร และทำไมสิ่งนี้กันไม่ให้ทุนถึงศูนย์

\[ \begin{aligned} W_1^{+}&=1{,}100{,}000,\quad 0.10\,W_1^{+}=110{,}000,\\ W_1^{-}&=900{,}000,\quad 0.10\,W_1^{-}=90{,}000,\\ W_2&=1{,}000{,}000(1.1)(0.9)\\ &=990{,}000,\\ W_{10}&=1{,}000{,}000(0.9)^{10}\\ &=348{,}678. \end{aligned} \]

ชนะแล้วเสี่ยงเพิ่ม แพ้แล้วเสี่ยงลด ชนะหนึ่งแพ้หนึ่งไม่ว่าลำดับไหนเหลือ \$990,000 หาย 1% ทั้งที่ขึ้นลงเท่ากัน นี่คือ volatility drag ตัวเดียวกับที่ $\ln0.9$ ลึกกว่า $\ln1.1$

บรรทัดสุดท้ายคือแพ้สิบรอบติด ซึ่งในเกม 45% มีโอกาส $0.45^{10}=0.034\%$ ถ้าเสี่ยงเป็นสัดส่วน ทุนเหลือ \$348,678 ถ้าเสี่ยง \$100,000 คงที่ทุกรอบ สิบรอบก็หมดเงินพอดี

ขั้นที่ 6 — ครึ่งขนาดซื้ออะไรมา: นับครบ 400 รอบโดยไม่ต้องสุ่ม

ครึ่งขนาดได้อัตราโต 75% ของขนาดเต็ม อีกฝั่งของการแลกคืออะไร ใน 400 รอบ ทุนตอนจบขึ้นกับจำนวนครั้งที่ชนะ $k$ อย่างเดียว และ $k$ เป็น binomial(400, 0.55) จึงหาเส้นทางตรงกลาง เส้นทางที่เปอร์เซ็นไทล์ 5 และค่าเฉลี่ยของเงินได้ตรง ๆ

\[ \begin{aligned} W_{400}&=(1+f)^k(1-f)^{400-k},\\ P(k\le219)&=0.4793,\quad P(k\le220)=0.5194,\\ P(k\le203)&=0.0489,\quad P(k\le204)=0.0599,\\ f=0.10,\ k=220&:\ e^{20.9682-18.9649}=7.41,\\ f=0.05,\ k=220&:\ e^{10.7338-9.2328}=4.49,\\ f=0.10,\ k=204&:\ e^{19.4433-20.6507}=0.299,\\ f=0.05,\ k=204&:\ e^{9.9532-10.0535}=0.905,\\ \mathbb E[W_n]&=W_0\big(1+f(p-q)\big)^n,\\ f=0.10&:\ 1.01^{400}=53.52. \end{aligned} \]

median ของ $k$ คือ 220 เพราะ $P(k\le220)$ ข้าม 0.5 ตรงนั้น และเปอร์เซ็นไทล์ 5 คือ 204 ทุนเป็นฟังก์ชันเพิ่มของ $k$ เส้นทางตรงกลางจึงจบที่ 7.41 เท่าสำหรับขนาดเต็ม และ 4.49 เท่าสำหรับครึ่งขนาด แต่ที่เปอร์เซ็นไทล์ 5 ขนาดเต็มเหลือ 0.299 เท่า คือเสีย 70% ขณะที่ครึ่งขนาดยังเหลือ 0.905 เท่า เส้นทางเดียวกันทุกประการ (ชนะ 204 จาก 400) ต่างกันแค่ขนาดที่เลือก

คำถามว่า “ระหว่างทางทุนเคยลงไปถึงครึ่งหนึ่งไหม” ขึ้นกับลำดับ จึงต้องนับทีละรอบ เก็บโอกาสของแต่ละจำนวนชนะ เมื่อทุนแตะครึ่งก็ย้ายโอกาสนั้นออกไปนับ โค้ดข้างล่างทำครบ 400 รอบได้ 0.436 สำหรับขนาดเต็ม และ 0.104 สำหรับครึ่งขนาด ครึ่งขนาดเสียอัตราโตหนึ่งในสี่ แต่ลดโอกาสเจ็บหนักระหว่างทางเหลือราวหนึ่งในสี่

สองบรรทัดล่างตอบว่าทำไมไม่ทำให้ค่าเฉลี่ยของเงินสูงสุดแทน ค่าเฉลี่ยของตัวคูณหนึ่งรอบคือ $1+f(p-q)$ รอบอิสระกัน ค่าเฉลี่ยของผลคูณจึงเป็นผลคูณของค่าเฉลี่ย ซึ่งเพิ่มตาม $f$ ตลอด จึงสั่งให้ลงหมดทุกรอบ ที่ $f=1$ ค่าเฉลี่ยคือ $1.1^{400}\approx3.6\times10^{16}$ เท่า แต่มาจากเส้นทางเดียวที่ชนะครบ 400 รอบ ซึ่งมีโอกาส $0.55^{400}\approx10^{-104}$ เส้นทางอื่นจบที่ศูนย์หมด แม้ที่ขนาด Kelly ค่าเฉลี่ย 53.52 เท่าก็สูงกว่ามัธยฐาน 7.41 เท่าราวเจ็ดเท่า ค่าเฉลี่ยตอบว่า “ถ้ามีจักรวาลคู่ขนานนับไม่ถ้วน” แต่เรามีเส้นทางเดียว

ขั้นที่ 7 — ถ้าโอกาสชนะจริงคือ 52% ไม่ใช่ 55%

โอกาสชนะไม่ได้มาจากฟ้า มันประมาณจากข้อมูลย้อนหลัง และ standard error ของตัวประมาณ บอกว่าค่าเฉลี่ยที่ประมาณคลาดได้ง่าย สมมติเราเชื่อ 55% จึงลง 10% แต่ความจริงคือ 52% ที่อัตราจ่ายหนึ่งต่อหนึ่ง $f^*=p-q=2p-1$

\[ \begin{aligned} f^*_{\text{true}}&=2(0.52)-1=0.04,\\ g_{0.52}(0.10)&=0.52\ln1.1+0.48\ln0.9\\ &=0.049561-0.050573\\ &=-0.001012,\\ g_{0.52}(0.05)&=0.025371-0.024621\\ &=0.000750,\\ g_{0.52}(0.04)&=0.020395-0.019595\\ &=0.000800. \end{aligned} \]

โอกาสชนะคลาดไป 3 จุด ขนาดที่ใช้กลายเป็น 2.5 เท่าของขนาดที่ถูก ซึ่งเลยจุดศูนย์ของเกม 52% (7.99%) ไปแล้ว ค่าเฉลี่ยของ log ติดลบประมาณ 0.101% ต่อรอบ แม้กำไรคาดหวังต่อเงินเสี่ยงยังเป็นบวก ทุนของเส้นทางทั่วไปจึงหดลงเรื่อย ๆ

ถ้าใช้ครึ่ง Kelly ของความเชื่อเดิม คือ 5% การลงนี้ยังได้ 0.075% ต่อรอบ หรือ 94% ของค่าสูงสุดของเกม 52% เพราะเส้นโค้งลงทางขวาชันกว่าทางซ้าย การลงเล็กไปจึงเสียน้อย การลงใหญ่ไปเสียมาก ครึ่ง Kelly จึงเป็นประกันราคาถูกต่อการประเมินโอกาสชนะสูงเกิน ไม่ได้รับรองกำไร ถ้าคลาดมากกว่านี้ก็ขาดทุนได้

ขั้นที่ 8 — แบบต่อเนื่อง: log ให้พจน์ลบครึ่งมาเอง

เปลี่ยนเป็นตลาดจริงที่ราคาขยับต่อเนื่อง ถือสัดส่วน $a$ ของทุนในสินทรัพย์เสี่ยง ที่เหลืออยู่ในบัญชีเงินสด คงสัดส่วนนี้ด้วยการปรับพอร์ตตลอดเวลา ไม่มีต้นทุนซื้อขาย และกู้หรือฝากได้ที่อัตรา $r$ เดียวกัน เราต้องการอัตราโตของ $\ln W$ ซึ่งหาได้ด้วย Itô's lemma

\[ \begin{aligned} \frac{dW_t}{W_t}&=\big[r+a(\mu-r)\big]dt+a\sigma\,dB_t,\\ d\ln W_t&=\frac{dW_t}{W_t}-\frac12\Big(\frac{dW_t}{W_t}\Big)^2,\\ \Big(\frac{dW_t}{W_t}\Big)^2&=a^2\sigma^2\,dt,\\ d\ln W_t&=g(a)\,dt+a\sigma\,dB_t,\\ g(a)&=r+a(\mu-r)-\tfrac12a^2\sigma^2. \end{aligned} \]

บรรทัดที่สองคือ Itô กับ $\ln W$ derivative แรกคือ $1/W$ ส่วนที่สองคือ $-1/W^2$ พจน์ลำดับสองจึงติดลบเพราะ log โค้งคว่ำ บรรทัดที่สามใช้ $(dB_t)^2=dt$ (quadratic variation) และ $dt^2$ กับ $dt\,dB_t$ เล็กจนทิ้งได้

พจน์ $-\tfrac12a^2\sigma^2$ คือ volatility drag ตัวเดียวกับ $1.1\times0.9=0.99$ กำไรโตเป็นเส้นตรงตาม $a$ แต่ราคาของความผันผวนโตตาม $a^2$ จึงต้องมีจุดที่การเพิ่มขนาดเริ่มทำร้ายตัวเอง

ของจริงที่ถือสัดส่วนคงที่แบบนี้มีขายในตลาด คือ leveraged ETF ซึ่งปรับให้ได้ $\beta$ เท่าของผลตอบแทนรายวันของดัชนีทุกวัน ทุกคนที่ถือมันจึงจ่าย drag นี้ ราว $\tfrac12(\beta^2-\beta)$ คูณผลบวกของกำลังสองของ log ผลตอบแทนรายวัน ดัชนี 100 ขึ้นเป็น 105 แล้วกลับมา 100 ETF สองเท่าไป 110 แล้วลง $110(1-2\times0.047619)=99.52$ ETF กลับทิศ ($\beta=-1$) ไป 95 แล้วขึ้น $95(1+0.047619)=99.52$ ทั้งคู่ขาดทุนทั้งที่ดัชนีกลับที่เดิม สูตรประมาณให้ $100e^{-(0.04879^2+0.04879^2)}=99.525$ ใกล้มาก

ขั้นที่ 9 — หุ้น 9% ความผันผวน 18% เงินฝาก 2%: ถือกี่เท่าของทุน

โจทย์ให้อะไรมาบ้าง: $\mu=9\%$ $\sigma=18\%$ $r=2\%$ ต่อปี และ $g(a)$ จากแบบต่อเนื่องข้างบน ซึ่งเป็นพาราโบลาคว่ำ หายอดด้วย derivative ตัวเดียว ส่วนเกินต่อความผันผวน $(\mu-r)/\sigma$ คือ Sharpe ratio (SR)

\[ \begin{aligned} g'(a)&=(\mu-r)-a\sigma^2=0,\\ a^*&=\frac{\mu-r}{\sigma^2}=\frac{0.07}{0.0324}\\ &=2.1605,\\ g(a^*)&=r+\frac{(\mu-r)^2}{2\sigma^2}=r+\frac{\mathrm{SR}^2}{2},\\ \mathrm{SR}&=\frac{0.07}{0.18}=0.38889,\\ g(a^*)&=0.02+0.0756173=9.56\%,\\ g(\lambda a^*)-r&=(2\lambda-\lambda^2)\frac{\mathrm{SR}^2}{2},\\ g(\tfrac12a^*)&=0.02+\tfrac34(0.0756173)\\ &=7.67\%,\\ g(2a^*)&=0.02+0\cdot(0.0756173)=r. \end{aligned} \]

คำตอบ: ถือหุ้นประมาณ 216% ของทุน โดยกู้อีก 116% ค่า 9.56% คืออัตราโตของ log ต่อปี ไม่ใช่กำไรธรรมดา หากเริ่ม \$1,000,000 มัธยฐานของทุนหลังหนึ่งปีในแบบจำลองนี้คือ $1{,}000{,}000e^{0.0956173}\approx\$1{,}100{,}338$ หรือกำไรราว 10.03%

ความผันผวนของพอร์ตคือ $a^*\sigma=2.1605(18\%)=38.89\%$ เท่ากับ SR พอดี เพราะ $a^*\sigma=(\mu-r)/\sigma$ จึงได้กฎจำง่ายว่า “ความผันผวนเป็นเงินต่อทุน เท่ากับ Sharpe ratio” ทั้งสองต้องวัดในหน่วยเวลาเดียวกัน ตัวอย่างเช่นกลยุทธ์ market-neutral ที่มี Sharpe ratio รายปี 2 กับทุน \$1 พันล้าน ขนาด Kelly คือความผันผวนรายปีราว \$2 พันล้าน

บรรทัด $\lambda$ ได้จากแทน $a=\lambda a^*$ ลงใน $g$ แล้วจัดรูป ครึ่งขนาด ($\lambda=\tfrac12$) ได้ $\tfrac34$ ของส่วนเกิน คือ 7.67% ที่ความผันผวนครึ่งเดียว 19.44% สัดส่วนสามในสี่นี้ไม่ขึ้นกับ $\mu$, $r$ หรือ $\sigma$ และใกล้กับ 0.749 ของเกมเป็นรอบ ส่วนสองเท่า ($\lambda=2$) ได้อัตราโตเท่าเงินฝากพอดี ทั้งที่แบกความผันผวน 77.8%

ตัวอย่างนี้ใกล้ของจริง ตลาดหุ้นสหรัฐช่วงปี 1926 ถึง 2018 มี Sharpe ratio ราว 0.42 และความผันผวนราว 19% ต่อปี สูตรเดียวกันให้ $0.42/0.19\approx2.2$ เท่าของทุน Kelly บอกให้กู้มาลงหุ้น แต่ใครทำจริงต้องรับการลงลึกระหว่างทางที่โหดมาก

ตรวจเองใน 10 วินาที: $0.07/0.18=0.389$ ยกกำลังสองได้ 0.151 ครึ่งหนึ่งคือ 0.0756 บวกเงินฝาก 0.02 ได้ 9.56%

ขั้นที่ 10 — ไม่รู้ค่าเฉลี่ยแน่นอน Kelly ก็หดเอง

ค่า $\mu$ ที่ใส่สูตรเป็นค่าประมาณ ความผันผวน 18% กับข้อมูล 25 ปี ให้ standard error ของค่าเฉลี่ยราว $0.18/\sqrt{25}=3.6\%$ ต่อปี ลองใส่ความไม่แน่นอนนี้เข้าไปตรง ๆ ให้ผลตอบแทนส่วนเกินของงวดหนึ่งปีเป็น $R=\theta+\sigma\xi$ โดย $\theta$ คือค่าเฉลี่ยที่เราไม่รู้แน่ มีค่าเฉลี่ย $m$ และ variance $\tau^2$ ส่วน $\xi$ คือการสุ่มปกติที่ variance 1

\[ \begin{aligned} \ln(1+aR)&\approx aR-\tfrac12a^2R^2,\\ \mathbb E[R]&=m,\\ \mathbb E[R^2]&=m^2+\tau^2+\sigma^2,\\ \mathbb E[\ln(1+aR)]&\approx am-\tfrac12a^2(m^2+\sigma^2+\tau^2),\\ a^*_{\tau}&\approx\frac{m}{m^2+\sigma^2+\tau^2},\\ \tau=0&:\ \frac{0.07}{0.0049+0.0324}=1.877,\\ \tau=0.04&:\ \frac{0.07}{0.0049+0.0324+0.0016}\\ &=1.799. \end{aligned} \]

บรรทัดแรกคือ Taylor ของ log ถึงกำลังสอง ใช้ได้เมื่อ $aR$ ไม่ใหญ่นัก บรรทัดที่สามคือ $\mathbb E[R^2]=(\mathbb E R)^2+\operatorname{Var}R$ และ variance ของ $R$ มีสองก้อน คือการสุ่มของตลาด $\sigma^2$ กับความไม่รู้ของเรา $\tau^2$ ความไม่รู้จึงทำตัวเหมือนความผันผวนเพิ่ม ทำให้ตัวหารโตและขนาดหดลง

ตัวเลข 1.877 ต่ำกว่า 2.1605 ของแบบต่อเนื่อง เพราะสูตรประมาณนี้ปรับพอร์ตปีละครั้งและมี $m^2$ ในตัวหาร ถ้าทิ้ง $m^2$ ไป (เมื่อ $m$ เล็กเทียบ $\sigma$) จะได้ $m/\sigma^2=2.1605$ เท่าสูตรต่อเนื่อง สิ่งที่ควรดูคือทิศทาง ความไม่แน่นอน 4% ทำให้ขนาดลดราว 4% และถ้า $\tau=10\%$ ก็ลดจาก 1.877 เป็น $0.07/0.0473=1.480$ ความไม่แน่นอนอย่างเดียวจึงยังไม่พอจะอธิบายการลงครึ่ง Kelly เหตุหลักคือค่าประมาณมักเอนไปทางสูงเกิน (แบบโอกาสชนะ 52% ที่เชื่อว่า 55%) บวกกับการลงลึกระหว่างทางที่คนรับไม่ไหว

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

อ่าน $f^*$ เป็นมูลค่าที่ซื้อ: $f^*$ คือเงินที่จะหายเมื่อแพ้ ถ้าตั้ง stop-loss ห่าง 5% ของราคา เงินเสี่ยง 10% ของทุนแปลว่าซื้อ $10\%/5\%=200\%$ ของทุน (เมื่อขายออกได้ตรง stop พอดี) คนที่ซื้อแค่ 10% ของทุนเล่นเล็กกว่าที่ตั้งใจ 20 เท่า

ใช้ Kelly แยกทีละกลยุทธ์: สองกลยุทธ์ที่เคลื่อนไหวเหมือนกันทุกประการ ต่างคนต่างลงขนาดเต็ม รวมกันคือสองเท่าของ Kelly ซึ่งตัวอย่างหุ้นข้างบนแสดงว่าโตแค่เท่าเงินฝาก ต้องคิดจากพอร์ตรวมพร้อม covariance

เสี่ยงเป็นเงินคงที่: \$100,000 ทุกรอบ แพ้สิบรอบติดก็หมดทุน (โอกาส 0.034% ต่อช่วงสิบรอบ ไม่ใช่ศูนย์) เสี่ยงเป็นสัดส่วนยังเหลือ \$348,678

ตัดสินขนาดด้วย Sharpe ratio: ทุกขนาด $a$ ของพอร์ตหุ้นกับเงินสดมี Sharpe ratio เท่ากันหมด คือ 0.389 เพราะทั้งส่วนเกินและความผันผวนคูณ $a$ เท่ากัน แต่ $a=1$ โตปีละ $0.02+0.07-0.0162=7.38\%$ ส่วน $a=2.16$ โต 9.56% และ $a=4.32$ โตแค่ 2% Sharpe ratio วัดฝีมือการเลือก ไม่ได้บอกว่าควรลงเท่าไร

ใช้ Kelly ในวันที่ราคากระโดด: สูตรสมมติว่าขาดทุนหยุดที่ $f$ พอดีและปรับขนาดได้ตลอด ถ้าราคาเปิดกระโดดข้าม stop-loss ขาดทุนจริงเกิน $f$ และวันที่ตลาดแย่ที่สุดก็คือวันที่ปรับพอร์ตยากที่สุด

ใช้ทำอะไรบนโต๊ะจริง

desk ใช้ Kelly เป็นเพดาน ไม่ใช่เป้าหมาย คำนวณ $a^*$ จาก Sharpe ratio ที่ประมาณได้ แล้วลงครึ่งหนึ่งหรือน้อยกว่า และลดขนาดเมื่อทุนลด กฎตรวจเร็วคือความผันผวนของพอร์ตต่อทุนไม่ควรเกิน Sharpe ratio ผู้จัดการกองทุนจำนวนมากที่ “คุมความผันผวนต่อทุนให้คงที่” ทำ fractional Kelly อยู่โดยไม่รู้ตัว

การคงสัดส่วนต้องซื้อขายตลอด และทิศของการซื้อขายขึ้นกับ leverage ถ้าหุ้นขึ้น 1% วันหนึ่ง พอร์ตที่ถือ $a$ เท่าของทุน \$1,000,000 ต้องซื้อเพิ่ม $a(a-1)\times1{,}000{,}000\times0.01$ ที่ $a=2.1605$ คือซื้อเพิ่มราว \$25,073 Kelly ที่ใช้ leverage จึงซื้อตอนขึ้นและขายตอนลง ส่วนพอร์ตที่ $a\lt1$ ทำกลับกัน ต้นทุนซื้อขายเหล่านี้กินอัตราโตที่สูตรไม่ได้นับ และโตเร็วกว่าเส้นตรงเมื่อทุนใหญ่ขึ้น

อีกแบบหนึ่งคือผูกขนาดกับการลงลึกจากยอดเดิม ยิ่งทุนห่างจากจุดสูงสุดเท่าไรยิ่งลดสัดส่วนลง จนถึงศูนย์เมื่อแตะเพดานการลงลึกที่ยอมรับได้ ซึ่งจะกลับมาในหน้า drawdown และการลดความเสี่ยง

โจทย์ตรวจความเข้าใจ

1. สินทรัพย์หนึ่งขึ้น 100% หรือลง 50% ด้วยโอกาสเท่ากัน ผลตอบแทนคาดหวัง 25% ต่อรอบ ถ้าปรับให้ถือสัดส่วน $x$ ของทุนทุกรอบ ควรใช้ $x$ เท่าไร อัตราโตต่อรอบเท่าไร และถ้าลงหมดทุน ($x=1$) จะโตเท่าไร

เฉลย

ใช้รูปทั่วไป $x^*=p/r_l-q/r_w$ กับ $r_w=1$, $r_l=0.5$, $p=q=0.5$ ได้ $0.5/0.5-0.5/1=0.5$ อัตราโต $g=0.5\ln1.5+0.5\ln0.75=0.5(0.405465)+0.5(-0.287682)=0.0589$ หรือ 5.89% ต่อรอบ ถ้า $x=1$ ได้ $0.5\ln2+0.5\ln0.5=0$ ทุนไม่โตเลยในระยะยาว ทั้งที่ผลตอบแทนคาดหวังคือ 25% ต่อรอบ

2. สินทรัพย์ $\mu=7\%$ $\sigma=20\%$ เงินฝาก $r=3\%$ หา $a^*$ อัตราโตที่ยอด และอัตราโตที่ครึ่งขนาด

เฉลย

$a^*=0.04/0.04=1.0$ ถือเต็มทุนไม่กู้ SR $=0.04/0.2=0.2$ อัตราโต $0.03+0.2^2/2=5\%$ ครึ่งขนาด $0.03+0.5(0.04)-\tfrac12(0.25)(0.04)=4.5\%$ ได้ส่วนเกิน 1.5 จาก 2 จุด คือสามในสี่ ความผันผวนของพอร์ตเต็มคือ 20% เท่ากับ SR ตามกฎ

3. ทุน \$2 ล้าน กลยุทธ์ชนะ 55% ตั้งเป้ากำไรเท่ากับระยะ stop-loss 4% ของราคา Kelly สั่งให้ซื้อหุ้นมูลค่าเท่าไร

เฉลย

จ่ายหนึ่งต่อหนึ่ง $f^*=0.10$ เงินที่จะหายเมื่อแพ้คือ \$200,000 เท่ากับ 4% ของมูลค่าที่ซื้อ จึงซื้อ $200{,}000/0.04=\$5$ ล้าน หรือ 2.5 เท่าของทุน ครึ่ง Kelly คือ \$2.5 ล้าน

// Log growth per round: win b per 1 at risk with probability p, lose the stake otherwise
const growth = (f, p, b = 1) => p * Math.log1p(b * f) + (1 - p) * Math.log1p(-f);
const kelly = (p, b = 1) => Math.max(0, (p * b - (1 - p)) / b);

// Where growth crosses zero above f*, by bisection
function zeroGrowth(p, b = 1) {
  let lo = kelly(p, b), hi = 1 - 1e-12;
  for (let i = 0; i < 200; i++) { const m = (lo + hi) / 2; if (growth(m, p, b) > 0) lo = m; else hi = m; }
  return lo;
}

// Exact n-round statistics of the 1:1 game: final wealth depends only on the number of wins k
function pathStats(f, p, n) {
  const pmf = [(1 - p) ** n];
  for (let k = 1; k <= n; k++) pmf.push(pmf[k - 1] * (n - k + 1) / k * p / (1 - p));
  const wealth = k => Math.exp(k * Math.log1p(f) + (n - k) * Math.log1p(-f));
  const quantileK = u => { let c = 0; for (let k = 0; k <= n; k++) { c += pmf[k]; if (c >= u) return k; } return n; };
  // Probability that wealth ever touches half its start: carry surviving mass round by round
  let alive = [1], everHalf = 0;
  for (let i = 1; i <= n; i++) {
    const next = new Array(i + 1).fill(0);
    alive.forEach((m, k) => { next[k + 1] += m * p; next[k] += m * (1 - p); });
    next.forEach((m, k) => {
      if (m && k * Math.log1p(f) + (i - k) * Math.log1p(-f) <= Math.log(0.5)) { everHalf += m; next[k] = 0; }
    });
    alive = next;
  }
  const kMed = quantileK(0.5), k5 = quantileK(0.05);
  return {kMed, k5, median: wealth(kMed), p5: wealth(k5), mean: (1 + f * (2 * p - 1)) ** n, everHalf};
}

// Continuous version: g(a) = r + a(mu - r) - a^2 sigma^2 / 2
const gCont = (mu, r, s, a) => r + a * (mu - r) - 0.5 * a * a * s * s;
const aStar = (mu, r, s) => (mu - r) / (s * s);

สิ่งที่ควรตอบได้หลังอ่าน

  • เงินคูณกันข้ามรอบ log เปลี่ยนเป็นผลบวก และ law of large numbers ให้อัตราโตของเส้นทางทั่วไป $g(f)=p\ln(1+bf)+q\ln(1-f)$
  • เกม 55% จ่ายหนึ่งต่อหนึ่ง $f^*=10\%$ ให้ราว 0.501% ต่อรอบ จุดศูนย์อยู่ที่ 19.87% ราวสองเท่าของ Kelly
  • ครึ่ง Kelly ให้อัตราโตราวสามในสี่ที่ความผันผวนครึ่งเดียว และใน 400 รอบลดโอกาสที่ทุนเคยลงถึงครึ่งจาก 43.6% เป็น 10.4%
  • การทำให้เงินเฉลี่ยสูงสุดสั่งให้ลงหมด ซึ่งทำให้เส้นทางแทบทั้งหมดจบที่ศูนย์ Kelly ทำให้ค่าเฉลี่ยของ log สูงสุดแทน
  • แบบต่อเนื่อง $a^*=(\mu-r)/\sigma^2$ ความผันผวนต่อทุนเท่ากับ Sharpe ratio และอัตราโตส่วนเกินคือ $\mathrm{SR}^2/2$ ความไม่แน่นอนของค่าเฉลี่ยทำตัวเหมือนความผันผวนเพิ่ม และทำให้ขนาดหด

Kelly เดิมพันทีละตัว หน้าถัดไป Markowitz portfolio theory ขยายไปหลายสินทรัพย์ที่ขึ้นลงร่วมกัน น้ำหนักที่ได้ชี้ไปทางเดียวกับ $\Sigma^{-1}(\mu-r\mathbf 1)$ ซึ่งเป็นรูปหลายมิติของ $(\mu-r)/\sigma^2$ ในหน้านี้
