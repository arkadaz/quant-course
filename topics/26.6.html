26.6 Performance Attribution: Factor PnL and Idiosyncratic PnL

แยกกำไรขาดทุนที่เกิดขึ้นจริงเป็นส่วนที่มาจากการเทรด จาก factor และจากการเลือกหุ้น แล้วถามว่าแต่ละบรรทัดบอกฝีมือได้แค่ไหน เมื่อทั้งโชคและความคลาดของ model ปนอยู่

สิ้นปี ทีมที่บริหารพอร์ตหุ้นพอร์ตหนึ่งได้รายงานผลงานทั้งปี พอร์ตทำกำไร \$3.50 ล้าน รายงานไม่ได้บอกแค่ยอดนี้ แต่แยกให้ดูด้วยว่ากำไรมาจากไหน (ตัวเลขสมมติ)

  • market คือส่วนที่ได้หรือเสียเพราะหุ้นทั้งตลาดขึ้นลงพร้อมกัน −\$0.37 ล้าน
  • style คือส่วนที่มาจากลักษณะของหุ้นที่วัดเป็นตัวเลขได้ เช่น momentum (หุ้นที่ราคาวิ่งดีกว่าเพื่อนในปีที่ผ่านมา) +\$0.77 ล้าน
  • industry คือส่วนที่มาจากกลุ่มอุตสาหกรรม เช่น หุ้นเทคโนโลยีขึ้นพร้อมกันทั้งกลุ่ม +\$0.27 ล้าน
  • ส่วนเฉพาะตัวคือส่วนที่มาจากข่าวของหุ้นแต่ละตัวเอง ซึ่งก็คือฝีมือเลือกหุ้น +\$3.58 ล้าน
  • ต้นทุนการเทรดคือเงินที่เสียไปตอนซื้อขาย เช่น ค่าคอมมิชชัน −\$0.75 ล้าน

สามบรรทัดแรกคือกลุ่มของ factor (ตัวขับผลตอบแทนที่หุ้นหลายตัวมีร่วมกัน) ห้าบรรทัดรวมกันได้กำไรทั้งปีพอดี

\[-0.37+0.77+0.27+3.58-0.75=3.50\]

ผู้จัดการพอร์ตอ่านแล้วบอกว่า “ในกลุ่ม factor, style ทำเงินมากที่สุด ปีหน้าขยาย style เป็นสองเท่า” ควรทำตามไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ควร หน้านี้จะคำนวณเหตุผลสามข้อนี้ให้ดูทีละขั้น

  • ปีเดียวแยกฝีมือออกจากโชคไม่ได้ Sharpe Ratio (กำไรต่อความเสี่ยงหนึ่งหน่วย) ของ style ปีนี้วัดได้ 0.74 แต่ตัวเลขนี้เมื่อวัดจากข้อมูลปีเดียวคลาดได้ราว ±1.00
  • ถ้าใช้ Sharpe Ratio ที่ทีมประเมินไว้ล่วงหน้า (style 0.8) การขยายสองเท่าทำให้ Sharpe Ratio คาดหวังของทั้งพอร์ตลดลงจาก 1.5515 เป็น 1.5087 ขนาดที่ดีที่สุดคือเพิ่ม style แค่ราว 18% และได้แค่ 1.5553
  • บรรทัดที่ควรคุยก่อนคือต้นทุน −\$0.75 ล้าน มันกิน Sharpe Ratio ไป 0.287 และเป็นบรรทัดเดียวที่รู้ทิศล่วงหน้า

ภาพรวมก่อนลงสูตร

พอจบปี บัญชีบอกตัวเลขเดียว คือได้หรือเสียเงินเท่าไร performance attribution (การไล่หาที่มาของกำไรขาดทุน) ถามต่อว่าได้เพราะอะไร คำตอบมาจากสามแหล่ง

  • factor ที่พอร์ตถืออยู่ ไม่ว่าจะตั้งใจถือหรือไม่
  • การเลือกหุ้น คือส่วนเฉพาะตัวของหุ้นที่ถือ
  • การซื้อขายระหว่างงวด ทั้งต้นทุนและจังหวะเข้าออก

รายงานนี้มีไว้กันเราหลอกตัวเอง สมมติว่าปีที่แล้วพอร์ตได้เงินเพราะเดิมพันที่เราไม่ได้ตั้งใจถือ ยอดกำไรดูเหมือนข่าวดี แต่จริง ๆ เป็นข่าวร้าย เพราะเงินก้อนนั้นมาจากโชค ไม่ได้มาจากสิ่งที่เรารู้ ปีหน้าโชคอาจกลับข้างได้

รูปข้างล่างวาดรายงานของ hook เป็นแท่งต่อกัน หลังจากนั้นหน้านี้จะเดินตามลำดับนี้

  1. นิยามสามบรรทัดของบัญชี
  2. ทำบัญชีสองวันของพอร์ตสี่หุ้นด้วยมือ
  3. รวมตารางเดียวกันได้สองทาง คือรายวัน หรือราย factor
  4. แยกฝีมือเลือกหุ้นต่อเป็นสองส่วน คือ selection กับ sizing
  5. กลับมาที่รายงานทั้งปี แล้วถามว่าแต่ละบรรทัดมีโชคปนแค่ไหน ต้นทุนกิน Sharpe Ratio เท่าไร และคำแนะนำเรื่อง style ถูกไหม
  6. ปิดด้วยข้อจำกัด factor return ที่ใช้ทำบัญชีเป็นแค่ค่าประมาณ การแบ่งกำไรจึงคลาดได้ด้วย
ศัพท์ที่ใช้ในหัวข้อนี้
Performance attribution
การไล่ว่ากำไรขาดทุนที่เกิดขึ้นจริงมาจากแหล่งไหน ทำหลังจบงวด ใช้แยกฝีมือออกจากเดิมพันที่ถือโดยบังเอิญ และออกจากต้นทุน ผลของมันยังใช้ตัดสินค่าตอบแทนของผู้จัดการพอร์ตด้วย
PnL
ย่อจาก profit and loss คือกำไรขาดทุน บวกคือได้เงิน ลบคือเสียเงิน
Epoch
เวลาที่ถ่ายภาพพอร์ต เช่น ตอนปิดตลาดของทุกวัน ช่วงระหว่างสอง epoch ที่ติดกันคือหนึ่งงวดของบัญชี
Exposure
ขนาดที่พอร์ตเดิมพันกับ factor แต่ละตัว หาได้จากเอา loading ของหุ้น (หุ้นตัวนั้นขยับตาม factor แรงแค่ไหน) คูณเงินที่ถือ แล้วบวกกันทุกตัว ดูวิธีคิดในสมการ factor model
Position PnL
กำไรขาดทุนที่จะได้ถ้าถือพอร์ตตอนต้นงวดไว้นิ่ง ๆ จนจบงวด แยกต่อได้เป็นสองส่วน คือ factor PnL (ส่วนที่มาจาก factor) กับ idiosyncratic PnL (ส่วนที่มาจากข่าวเฉพาะตัวของหุ้น)
Trading PnL
กำไรขาดทุนจริง ลบด้วย position PnL มันเก็บทุกอย่างที่การซื้อขายระหว่างงวดทำให้ต่างไป ทั้งต้นทุนและกำไรจากจังหวะเข้าออก
Selection และ sizing
สองส่วนของฝีมือเลือกหุ้น selection คืออยู่ถูกฝั่งบ่อยแค่ไหน (ซื้อตัวที่ขึ้น short ตัวที่ลง) sizing คือลงเงินมากกับเดิมพันที่ถูกหรือเปล่า
Sharpe Ratio
ผลตอบแทนเฉลี่ยต่อปี หารด้วยความผันผวนต่อปี บอกว่าได้เงินเท่าไรต่อความเสี่ยงหนึ่งหน่วย ยิ่งสูงยิ่งคุ้ม หน้าการแบ่งความเสี่ยงใช้มันตัดสินว่าควรขยายหรือหดแต่ละกลุ่ม
Ex ante และ ex post
ex ante คือตัวเลขที่คาดไว้ก่อนเกิด เช่น ความเสี่ยงและ Sharpe Ratio ที่ทีมประเมินไว้ ex post คือตัวเลขที่วัดได้หลังเกิดแล้ว ทั้งหน้านี้เทียบสองอย่างนี้

ขั้นที่ 1 — สามบรรทัดของบัญชี

ก่อนจะนับเงิน ต้องตกลงกันก่อนว่าบัญชีมีกี่บรรทัด และแต่ละบรรทัดคืออะไร ขั้นนี้จึงเป็นนิยาม ไม่ใช่ผลที่พิสูจน์

เริ่มจากคำถามง่าย ๆ ว่า ถ้าวันนี้เราไม่ซื้อขายอะไรเลย จะได้เงินเท่าไร พอร์ตตอนต้นวันคือ $\mathbf w_t$ หุ้นให้ผลตอบแทน $\mathbf r_t$ กำไรจึงเป็น $\mathbf w_t^{\mathsf T}\mathbf r_t=\sum_iw_{t,i}r_{t,i}$ คือเงินที่ถือหุ้นแต่ละตัว คูณผลตอบแทนของมัน แล้วบวกกัน แต่บัญชีจริงบันทึก $\text{PnL}_t$ ซึ่งรวมผลของการซื้อขายระหว่างวันไว้ด้วย ส่วนต่างของสองตัวนี้เรียกว่า trading PnL

จากนั้นแยก $\mathbf w_t^{\mathsf T}\mathbf r_t$ ต่อ โดยแทนผลตอบแทนของหุ้นด้วยสมการ factor model $\mathbf r_t=\boldsymbol\alpha+\mathbf B\mathbf f_t+\boldsymbol\epsilon_t$ แบบเดียวกับการอ่านสมการ factor model ทั้งพอร์ต แล้วบวกทุกวันของงวด

\[ \begin{aligned} \text{TPnL}_t&:=\text{PnL}_t-\mathbf w_t^{\mathsf T}\mathbf r_t,\\ \mathbf w_t^{\mathsf T}\mathbf r_t&=\mathbf w_t^{\mathsf T}(\boldsymbol\alpha+\mathbf B\mathbf f_t+\boldsymbol\epsilon_t)\\ &=\mathbf b_t^{\mathsf T}\mathbf f_t\\ &\quad+\mathbf w_t^{\mathsf T}(\boldsymbol\alpha_\perp+\boldsymbol\epsilon_t),\\ \sum_t\text{PnL}_t&=\sum_t\mathbf b_t^{\mathsf T}\mathbf f_t\\ &\quad+\sum_t\mathbf w_t^{\mathsf T}(\boldsymbol\alpha_\perp+\boldsymbol\epsilon_t)\\ &\quad+\sum_t\text{TPnL}_t. \end{aligned} \]

สูตรบอกว่ากำไรทั้งงวดแยกได้สามก้อนเสมอ ก้อนแรกคือ factor PnL ก้อนที่สองคือ idiosyncratic PnL สองก้อนนี้รวมกันคือ position PnL คือกำไรที่จะได้ถ้าซื้อขายได้ทันทีโดยไม่เสียต้นทุน ก้อนที่สามคือ trading PnL

จังหวะที่ต้องดูคือตอนได้ $\mathbf b_t^{\mathsf T}\mathbf f_t$ ซึ่งมีสองเรื่อง เรื่องแรกแค่จัดวงเล็บใหม่ $\mathbf w_t^{\mathsf T}\mathbf B\mathbf f_t=(\mathbf B^{\mathsf T}\mathbf w_t)^{\mathsf T}\mathbf f_t=\mathbf b_t^{\mathsf T}\mathbf f_t$ เรื่องที่สองคือ $\boldsymbol\alpha$ (ผลตอบแทนเฉลี่ยที่หุ้นให้เกินกว่าที่ factor อธิบาย) แยกได้สองส่วนตามหน้า alpha spanned และ alpha orthogonal ส่วน spanned เขียนเป็น $\mathbf B\boldsymbol\lambda$ ได้ หน้าตาจึงเหมือน factor return ที่ได้เพิ่ม $\boldsymbol\lambda$ ทุกวัน เมื่อวัด factor return จากข้อมูล ส่วนนี้จึงติดมาใน $\mathbf f_t$ อยู่แล้ว ส่วนที่เหลือคือ $\boldsymbol\alpha_\perp$ ซึ่งไปอยู่กับส่วนเฉพาะตัว

ก้อนที่สามเก็บทุกอย่างที่เกิดจากการซื้อขายระหว่างวัน ได้แก่ ค่าคอมมิชชัน, spread (ส่วนต่างระหว่างราคาเสนอซื้อกับราคาเสนอขาย) ราคาที่ขยับเพราะคำสั่งของเราเอง และกำไรจากจังหวะเข้าออกภายในวัน

กรณีสุดขั้วช่วยให้เห็นก้อนที่สามชัดขึ้น คนเทรดความถี่สูงที่ปิดสถานะหมดทุกสิ้นวันมี $\mathbf w_t=\mathbf 0$ ทุก epoch position PnL ของเขาจึงเป็นศูนย์ทั้งหมด แต่กำไรจริงไม่เป็นศูนย์ ทุกดอลลาร์ของเขาอยู่ใน trading PnL ทั้งกำไรจากราคาที่ขยับระหว่างวัน ส่วนแบ่งของ spread ที่ได้จากการวาง limit order (คำสั่งที่รอซื้อขายที่ราคาที่ตั้งไว้) และต้นทุนจากการส่ง market order (คำสั่งที่ซื้อขายทันทีที่ราคาตลาด)

ขั้นที่ 2 — บัญชีสองวันของพอร์ตสี่หุ้น

นิยามยังเป็นสัญลักษณ์อยู่ ลองทำบัญชีจริงสองวันด้วยมือ วันแรกโต๊ะถือพอร์ตชุดหนึ่ง ตอนปิดตลาดโต๊ะปรับพอร์ตเล็กน้อย แล้ววันที่สองถือพอร์ตใหม่ เราอยากรู้ว่าการปรับครั้งนั้นไปโผล่ในบรรทัดไหนของบัญชี

โจทย์ให้อะไรมาบ้าง: หุ้นสี่ตัว A, B, C, D กับ factor สามตัว (market, momentum, tech) ชุดเดียวกับตัวอย่างหนึ่งวันของสมการ factor model ตัวเลขทั้งหมดสมมติ

  • loadings: market เป็น 1 ทุกตัว momentum ของ A, B, C, D คือ 1.2, −0.4, 0.6, −1.4 และ tech เป็น 1 สำหรับ A กับ B เป็น 0 สำหรับ C กับ D
  • พอร์ตวันที่ 1 $\mathbf w_1=(3,\ -2,\ 4,\ -5)$ \$ ล้าน (ลบคือ short)
  • วันที่ 1 factor return $\mathbf f_1=(0.80,\ -0.50,\ 0.30)\%$ และส่วนเฉพาะตัว $\boldsymbol\epsilon_1=(0.40,\ -0.25,\ 0.15,\ -0.60)\%$
  • ตอนปิดตลาดวันที่ 1 โต๊ะอยากลดเดิมพันกับ momentum จึงขาย C \$2 ล้าน และซื้อ D คืน \$2 ล้าน (ลด short ของ D) เสียต้นทุน 3 bp ของเงินที่ซื้อขาย (bp ย่อจาก basis point คือ 0.01% ดังนั้น 3 bp คือ 0.03%)
  • พอร์ตวันที่ 2 จึงเป็น $\mathbf w_2=(3,\ -2,\ 2,\ -3)$ \$ ล้าน
  • วันที่ 2 $\mathbf f_2=(-1.00,\ 0.40,\ -0.20)\%$ และ $\boldsymbol\epsilon_2=(0.10,\ 0.30,\ -0.20,\ 0.05)\%$
  • บัญชีบันทึกกำไรขาดทุนจริง วันที่ 1 −\$14,200 และวันที่ 2 +\$28,700

เงินมีหน่วย \$ ล้าน ผลตอบแทนมีหน่วย % ผลคูณของสองอย่างนี้จึงมีหน่วย \$10,000 เพราะ $1{,}000{,}000\times1\%=10{,}000$ ทุกบรรทัดข้างล่างใช้หน่วยนี้ เช่น −1.42 คือ −\$14,200

ต้นทุนหาได้ก่อน เงินที่ซื้อขายรวม $2+2=\$4$ ล้าน ต้นทุนจึงเป็น $4{,}000{,}000\times0.0003=\$1{,}200$ ต่อมาต้องรู้ว่าแต่ละวันพอร์ตเดิมพันกับ factor แค่ไหน exposure $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$ คือเอา loading ของหุ้นคูณเงินที่ถือ แล้วบวกกันทีละ factor

\[ \begin{aligned} b_{1,\rm mkt}&=3-2+4-5=0,\\ b_{1,\rm mom}&=3(1.2)-2(-0.4)\\ &\quad+4(0.6)-5(-1.4)\\ &=13.8,\\ b_{1,\rm tech}&=3-2=1,\\ b_{2,\rm mom}&=3(1.2)-2(-0.4)\\ &\quad+2(0.6)-3(-1.4)\\ &=9.8. \end{aligned} \]

วันที่ 2 exposure ต่อ market ยังเป็น $3-2+2-3=0$ และต่อ tech ยังเป็น $3-2=1$ ที่เปลี่ยนมีแค่ momentum ซึ่งลดจาก 13.8 เหลือ 9.8 เพราะขาย C ลดไป $2\times0.6=1.2$ และลด short ของ D อีก $2\times1.4=2.8$ รวม $13.8-1.2-2.8=9.8$

ตอนนี้แยกบัญชีได้แล้ว factor PnL คือ exposure คูณ factor return $F_t=\mathbf b_t^{\mathsf T}\mathbf f_t$ idiosyncratic PnL คือเงินที่ถือคูณส่วนเฉพาะตัว $I_t=\mathbf w_t^{\mathsf T}\boldsymbol\epsilon_t$ ส่วน trading PnL คือสิ่งที่บัญชีบันทึก ลบด้วยสองก้อนนั้น $X_t=\text{PnL}_t-(F_t+I_t)$

\[ \begin{aligned} F_1&=13.8(-0.50)+1(0.30)\\ &=-6.60,\\ I_1&=3(0.40)-2(-0.25)\\ &\quad+4(0.15)-5(-0.60)\\ &=5.30,\\ X_1&=-1.42-(-6.60+5.30)\\ &=-0.12,\\ F_2&=9.8(0.40)+1(-0.20)\\ &=3.72,\\ I_2&=3(0.10)-2(0.30)\\ &\quad+2(-0.20)-3(0.05)\\ &=-0.85,\\ X_2&=2.87-(3.72-0.85)=0. \end{aligned} \]

ไม่มีพจน์ของ market ใน $F_1$ และ $F_2$ เพราะ exposure ต่อ market เป็นศูนย์ทั้งสองวัน สุดท้ายรวมสองวันทีละบรรทัด

\[ \begin{aligned} F_1+F_2&=-6.60+3.72=-2.88,\\ I_1+I_2&=5.30-0.85=4.45,\\ X_1+X_2&=-0.12+0=-0.12,\\ F+I+X&=-2.88+4.45-0.12\\ &=1.45. \end{aligned} \]

คำตอบ: สองวันรวมกัน factor PnL −\$28,800 idiosyncratic PnL +\$44,500 trading PnL −\$1,200 position PnL คือ $-2.88+4.45=1.57$ หรือ +\$15,700 และยอดรวม +\$14,500 ตรงกับบัญชี $-14{,}200+28{,}700=14{,}500$

วันที่ 1 การเลือกหุ้นทำเงิน +\$53,000 แต่ factor เสีย −\$66,000 ซึ่งเกือบทั้งหมดมาจากเดิมพัน momentum $13.8\times(-0.50)=-6.90$ หรือ −\$69,000 วันที่ 2 ไม่มีการซื้อขาย trading PnL จึงเป็นศูนย์

การปรับพอร์ตมีราคาที่ต้องจ่าย วันที่ 2 momentum กลับขึ้น 0.40% พอร์ตใหม่ได้จาก momentum $9.8\times0.40=3.92$ หรือ \$39,200 ถ้ายังถือพอร์ตเดิมจะได้ $13.8\times0.40=5.52$ หรือ \$55,200 การปรับจึงพลาดกำไรวันนั้นไป $55{,}200-39{,}200=\$16{,}000$ สิ่งที่ได้คืนมาคือเดิมพันที่ไม่ได้ตั้งใจถือเล็กลง

ตรวจเองใน 10 วินาที: วันที่ 1 ไม่มีการซื้อขายอื่นนอกจากการปรับพอร์ตตอนปิด $X_1$ จึงต้องเท่ากับต้นทุนพอดี $-0.12$ คือ −\$1,200 ตรงกับ $4{,}000{,}000\times0.0003=1{,}200$

ขั้นที่ 3 — ตารางเดียว รวมได้สองทาง

บัญชีของขั้นที่แล้วรวมเป็นรายวัน แต่คนอ่านรายงานมักอยากรู้อีกแบบด้วย คือเดิมพันไหนเสียเงิน ขั้นนี้แสดงว่าตัวเลขชุดเดียวกันตอบได้ทั้งสองคำถาม

ลองวาง factor PnL เป็นตาราง วันเป็นแถว factor เป็นคอลัมน์ ช่องของวัน $t$ กับ factor $j$ คือ exposure คูณ factor return $b_{t,j}f_{t,j}$ ถ้ารวมตามแถวก่อน จะได้ factor PnL รายวัน ถ้ารวมตามคอลัมน์ก่อน จะได้ factor PnL ราย factor ผลรวมสุดท้ายต้องเท่ากัน เพราะเป็นการบวกช่องชุดเดียวกัน แค่สลับลำดับ

ขั้นที่ 4 — ฝีมือเลือกหุ้นแยกต่อเป็น selection กับ sizing

idiosyncratic PnL บอกว่าการเลือกหุ้นได้เงินเท่าไร แต่ยังไม่บอกว่าเก่งแบบไหน ผู้จัดการพอร์ตอาจเก่งเพราะอยู่ถูกฝั่งบ่อย (ซื้อตัวที่ขึ้น short ตัวที่ลง) หรือเพราะลงเงินมากกับตัวที่ถูก สองแบบนี้แก้ไขคนละวิธี จึงควรแยกออกจากกัน

ก่อนอื่นต้องทำให้ตัวเลขเทียบกันได้ข้ามวัน วันที่พอร์ตใหญ่ย่อมได้หรือเสียเงินมากกว่า จึงหาร idiosyncratic PnL ของวันด้วยความเสี่ยงเฉพาะตัวของพอร์ตวันนั้น อัตราส่วนนี้เรียกว่า $\text{IR}_t$ (information ratio ของวัน) การแยกต้องใช้ของสี่อย่าง

  • $\sigma_i$ คือความผันผวนเฉพาะตัวรายวันของหุ้น $i$ หรือ SD ของ $\epsilon_i$
  • $z_i=\epsilon_i/\sigma_i$ คือส่วนเฉพาะตัววันนี้ นับเป็นจำนวนเท่าของความผันผวนของหุ้นตัวนั้นเอง หุ้นที่ปกติแกว่งแรงจึงไม่ได้คะแนนมากเพียงเพราะมันแกว่งแรง
  • $x_i=z_i\operatorname{sign}(w_i)$ คือ $z_i$ ที่กลับเครื่องหมายเมื่อเรา short หุ้นตัวนั้น ($\operatorname{sign}(w_i)$ เป็น +1 เมื่อซื้อ และ −1 เมื่อ short) $x_i$ จึงเป็นบวกเมื่ออยู่ถูกฝั่ง
  • $\tilde w_i=\sigma_iw_i$ คือขนาดเดิมพันที่วัดเป็นความเสี่ยงแทนการวัดเป็นเงิน

จากนิยาม กำไรเฉพาะตัวของหุ้นหนึ่งตัวเขียนใหม่ได้ว่า $w_i\epsilon_i=(\sigma_iw_i)(\epsilon_i/\sigma_i)=\tilde w_iz_i=\lvert\tilde w_i\rvert x_i$ ขั้นสุดท้ายใช้ $\tilde w_i=\lvert\tilde w_i\rvert\operatorname{sign}(w_i)$ เพราะ $\sigma_i$ เป็นบวก ความเสี่ยงเฉพาะตัวของพอร์ตคือ $\lVert\tilde{\mathbf w}\rVert_2=\sqrt{\sum_i\tilde w_i^2}$ เพราะส่วนเฉพาะตัวของหุ้นต่างตัวไม่สัมพันธ์กัน variance จึงบวกกันได้ตรง ๆ และให้ $\lVert\tilde{\mathbf w}\rVert_1=\sum_i\lvert\tilde w_i\rvert$ คือขนาดเดิมพันรวม

\[ \begin{aligned} \text{IR}_t&=\frac{\sum_iw_i\epsilon_i}{\lVert\tilde{\mathbf w}\rVert_2} =\frac{\sum_i\lvert\tilde w_i\rvert x_i}{\lVert\tilde{\mathbf w}\rVert_2},\\ \textstyle\sum_i\lvert\tilde w_i\rvert x_i&=n\,\widehat{\operatorname{cov}}(x,\lvert\tilde w\rvert)\\ &\quad+\bar x\,\lVert\tilde{\mathbf w}\rVert_1,\\ \text{IR}_t&=\bar x\cdot\frac{\lVert\tilde{\mathbf w}\rVert_1}{\lVert\tilde{\mathbf w}\rVert_2} +\frac{n\,\widehat{\operatorname{cov}}(x,\lvert\tilde w\rvert)}{\lVert\tilde{\mathbf w}\rVert_2}. \end{aligned} \]

สูตรบอกว่า IR ของวันแยกได้เป็น selection × diversification + sizing

  • $\bar x$ คือ selection ค่าเฉลี่ยว่าอยู่ถูกฝั่งแค่ไหน วัดเป็น z-score จึงไม่ให้รางวัลหุ้นที่ผันผวนมาก
  • $\lVert\tilde{\mathbf w}\rVert_1/\lVert\tilde{\mathbf w}\rVert_2$ คือ diversification (การกระจายเดิมพัน) ถ้าเดิมพันทั้ง $n$ ตัวเท่ากัน มันเป็น $n/\sqrt n=\sqrt n$ ถ้ามีเดิมพันเดียว มันเป็น 1 ยกกำลังสองแล้วได้จำนวนเดิมพันที่มีผลจริง
  • ชิ้นสุดท้ายคือ sizing เป็นบวกเมื่อเดิมพันที่ใหญ่คือเดิมพันที่ถูก

จังหวะที่ต้องดูคือบรรทัดกลาง มันมาจากนิยามของ covariance ข้ามหุ้น $\widehat{\operatorname{cov}}(x,y)=\frac1n\sum_ix_iy_i-\bar x\bar y$ คูณทั้งสองข้างด้วย $n$ แล้วย้ายข้าง ได้ $\sum_ix_iy_i=n\,\widehat{\operatorname{cov}}+\bar x\,(n\bar y)$ แทน $y_i=\lvert\tilde w_i\rvert$ แล้ว $n\bar y=\lVert\tilde{\mathbf w}\rVert_1$ จึงได้บรรทัดกลาง หารทั้งก้อนด้วย $\lVert\tilde{\mathbf w}\rVert_2$ ก็ได้บรรทัดสุดท้าย

ลองใช้กับวันที่ 1 ของบัญชีสองวัน ความผันผวนเฉพาะตัวรายวันของ A, B, C, D คือ 1.80%, 2.20%, 1.50% และ 2.60% (สมมติ ชุดเดียวกับหน้า Frisch–Waugh–Lovell) เครื่องหมายของพอร์ตคือ $(+,\ -,\ +,\ -)$ ส่วนเฉพาะตัว B กับ D ติดลบ และเรา short ทั้งคู่ $x$ ของสองตัวนี้จึงเป็นบวก

\[ \begin{aligned} z&=(\tfrac{0.40}{1.80},\ \tfrac{-0.25}{2.20},\\ &\qquad\tfrac{0.15}{1.50},\ \tfrac{-0.60}{2.60}),\\ x&=(0.22222,\ 0.11364,\\ &\qquad 0.10000,\ 0.23077),\\ \bar x&=0.66663/4=0.16666,\\ \lvert\tilde{\mathbf w}\rvert&=(3(1.80),\ 2(2.20),\\ &\qquad 4(1.50),\ 5(2.60))\\ &=(5.4,\ 4.4,\ 6.0,\ 13.0),\\ \lVert\tilde{\mathbf w}\rVert_1&=5.4+4.4+6.0+13.0\\ &=28.8,\\ \lVert\tilde{\mathbf w}\rVert_2&=\sqrt{29.16+19.36+36+169}\\ &=\sqrt{253.52}=15.922,\\ \frac{\lVert\tilde{\mathbf w}\rVert_1}{\lVert\tilde{\mathbf w}\rVert_2}&=\frac{28.8}{15.922}=1.8088. \end{aligned} \]

sizing ไม่ต้องหา covariance ตรง ๆ เพราะผลรวม $\sum_i\lvert\tilde w_i\rvert x_i$ ก็คือ $\sum_iw_i\epsilon_i=I_1=5.30$ ที่รู้แล้ว

\[ \begin{aligned} n\,\widehat{\operatorname{cov}}&=5.30-0.16666(28.8)\\ &=5.30-4.80=0.50,\\ \text{sizing}&=0.50/15.922=0.0314,\\ \text{IR}_1&=0.16666(1.8088)+0.0314\\ &=0.3015+0.0314=0.3329. \end{aligned} \]

ได้ 0.3329 เท่ากับการหารตรง ๆ $I_1/\lVert\tilde{\mathbf w}\rVert_2=5.30/15.922=0.3329$ วันนี้ฝีมือเกือบทั้งหมดมาจากการอยู่ถูกฝั่ง เพราะ $x$ เป็นบวกทั้งสี่ตัว diversification ยกกำลังสองได้ $1.8088^2=3.27$ คือมีเดิมพันที่มีผลจริงราว 3.27 จาก 4 ตัว ไม่ถึง 4 เพราะ short D ใหญ่กว่าตัวอื่นมาก ($\lvert\tilde w_D\rvert=13.0$) เดิมพันใหญ่สุดนี้บังเอิญถูกมากที่สุดด้วย ($x_D=0.23077$) sizing จึงบวกเล็กน้อย ถ้า sizing ติดลบเป็นประจำ แปลว่าเดิมพันใหญ่มักเป็นตัวที่ผิด ผู้จัดการพอร์ตคนนั้นควรลงเดิมพันเท่า ๆ กันทุกตัว (วัดเป็นความเสี่ยง)

ขั้นที่ 5 — รายงานของทั้งปี

ตอนนี้กลับมาที่รายงานทั้งปีของ hook ตัวเลขในรายงานนั้นไม่ได้มาจากตลาดจริง แต่มาจากปีจำลอง คือสุ่มกำไรขาดทุนรายวันขึ้นมาเองตามการออกแบบที่รู้ทุกค่า ข้อดีคือเรารู้ว่าค่าเฉลี่ยที่แท้จริงของแต่ละบรรทัดคือเท่าไร จึงวัดได้ว่าโชคทำให้ตัวเลขของปีคลาดไปแค่ไหน

โจทย์ให้อะไรมาบ้าง: การออกแบบใช้พอร์ตของหน้าการแบ่งความเสี่ยง ตัวเลขสมมติทั้งหมด

  • จำนวนวันทำการ 251 วัน ปีหนึ่งมี 365 วัน หักเสาร์อาทิตย์ $52\times2=104$ วัน เหลือวันธรรมดา $365-104=261$ วัน ปีนี้สมมติว่าตลาดหยุดอีก 10 วัน จึงเหลือ $261-10=251$ วัน
  • ความผันผวนรายวันของกำไรขาดทุนแต่ละกลุ่ม market \$40,000, style \$70,000, industry \$50,000 และเฉพาะตัว \$120,000
  • correlation ระหว่างกลุ่มชุดเดียวกับหน้านั้น ความเสี่ยงรวมของพอร์ตจึงเป็น $v=\$159{,}844$ ต่อวัน ตามที่หน้านั้นคำนวณไว้
  • Sharpe Ratio ต่อปีที่ออกแบบ market 0, style 0.8, industry 0 และเฉพาะตัว 1.6
  • ต้นทุนการเทรดเป็นบวกทุกวัน สุ่มรอบค่าเฉลี่ยวันละ $c=\$3{,}000$

สุ่มครบ 251 วันแล้วรวมแต่ละบรรทัดทั้งปี ได้ตัวเลขของ hook หน่วย \$ ล้าน คือ market −0.37, style +0.77, industry +0.27, เฉพาะตัว +3.58 และต้นทุน −0.75 จากนั้นรวมทีละชั้นตามสามบรรทัดของบัญชี

\[ \begin{aligned} \text{factor}&=-0.37+0.77+0.27=0.67,\\ \text{position}&=0.67+3.58=4.25,\\ \text{book}&=4.25-0.75=3.50,\\ \frac{\text{idio}}{\text{book}}&=\frac{3.58}{3.50}=102\%. \end{aligned} \]

คำตอบ: factor PnL +\$0.67 ล้าน position PnL +\$4.25 ล้าน และหลังหักต้นทุนเหลือ +\$3.50 ล้าน ส่วนเฉพาะตัวคิดเป็น 102% ของกำไรทั้งปี มันเกิน 100% ได้ เพราะบรรทัดอื่นรวมกันติดลบ $0.67-0.75=-0.08$ ถ้าไม่มี factor และไม่มีต้นทุน พอร์ตจะได้ \$3.58 ล้าน มากกว่าที่ได้จริง

บรรทัด market เสีย \$0.37 ล้าน ทั้งที่ market เป็นเดิมพันที่ไม่จ่ายผลตอบแทน (Sharpe Ratio ที่ออกแบบเป็น 0) หน้าการแบ่งความเสี่ยงก็แนะนำให้ hedge market ออกอยู่แล้ว (hedge คือซื้อขายสวนทางเพื่อตัดเดิมพันนั้นทิ้ง) ส่วนต้นทุนทั้งปีตามที่ออกแบบคือ $3{,}000\times251=\$753{,}000$ ใกล้กับ \$0.75 ล้านที่เกิดจริงมาก

ตรวจเองใน 10 วินาที: รูปกำไรสะสมข้างล่างจบปีที่ +3.58, +0.67, −0.75 และ +3.50 ล้าน ตรงกับรูปน้ำตกตอนต้นหน้า และเส้นทั้งพอร์ตต้องเท่ากับผลรวมของสามเส้นแรก $3.58+0.67-0.75=3.50$

ขั้นที่ 6 — ปีเดียวแยกฝีมือออกจากโชคได้แค่ไหน

คำถามของ hook คือ style ที่ได้ \$0.77 ล้านเป็นฝีมือหรือโชค เพราะเรารู้การออกแบบ จึงคำนวณได้ว่าแต่ละบรรทัดควรได้เท่าไรโดยเฉลี่ย และแกว่งได้แค่ไหนในหนึ่งปี แล้วดูว่าตัวเลขของปีอยู่ห่างจากค่าเฉลี่ยกี่เท่าของการแกว่ง

ต้องแปลงของรายวันเป็นรายปีก่อน ให้ $v$ เป็นความผันผวนรายวันของบรรทัดหนึ่ง กำไรขาดทุนของแต่ละวันไม่สัมพันธ์กัน variance ของผลรวม 251 วันจึงเป็นผลบวก $251v^2$ ความผันผวนรายปีจึงเป็น $\sqrt{251v^2}=v\sqrt{251}$ ส่วน Sharpe Ratio ต่อปีคือกำไรเฉลี่ยต่อปีหารด้วยความผันผวนต่อปี ย้ายข้างแล้วกำไรเฉลี่ยทั้งปีคือ $\text{SR}\times v\sqrt{251}$ ตัวเลข $\sqrt{251}=15.843$ ใช้ตลอดขั้นนี้

\[ \begin{aligned} \mathbb E[\text{style}]&=0.8(70{,}000)\sqrt{251}\\ &=\$887{,}207,\\ \mathbb E[\text{idio}]&=1.6(120{,}000)\sqrt{251}\\ &=\$3{,}041{,}852,\\ \text{SD}_{\rm style}&=70{,}000\sqrt{251}\\ &=\$1{,}109{,}009. \end{aligned} \]

market กับ industry มี Sharpe Ratio ที่ออกแบบเป็น 0 ค่าเฉลี่ยของสองบรรทัดนี้จึงเป็นศูนย์ ความผันผวนรายปีของสามบรรทัดที่เหลือหาแบบเดียวกัน คือ $40{,}000\sqrt{251}=\$633{,}719$, $50{,}000\sqrt{251}=\$792{,}149$ และ $120{,}000\sqrt{251}=\$1{,}901{,}158$ ทีนี้วัดระยะของแต่ละบรรทัด คือเอาตัวเลขของปีลบค่าเฉลี่ย แล้วหารด้วยความผันผวนรายปี (หน่วย \$ ล้าน)

\[ \begin{aligned} \text{style}&:\ \frac{0.77-0.887}{1.109}=-0.11,\\ \text{market}&:\ \frac{-0.37-0}{0.634}=-0.58,\\ \text{industry}&:\ \frac{0.27-0}{0.792}=0.34,\\ \text{idio}&:\ \frac{3.58-3.042}{1.901}=0.28. \end{aligned} \]

ทุกบรรทัดห่างจากค่าเฉลี่ยไม่ถึง 1 เท่าของการแกว่งรายปี ซึ่งเป็นระยะของโชคธรรมดา (ในรูประฆัง Normal ราว 68% ของปีจะห่างไม่เกิน 1 เท่า) style ได้ต่ำกว่าค่าเฉลี่ยที่ออกแบบด้วยซ้ำ ตัวเลข \$0.77 ล้านจึงไม่ได้บอกอะไรพิเศษเกี่ยวกับ style เลย

อีกทางหนึ่งคือดูที่ Sharpe Ratio ที่วัดได้ในปีนี้ (กำไรทั้งปีหารด้วยความผันผวนที่วัดได้จริงในปี) ปีจำลองให้ market −0.61, style 0.74, industry 0.33 และเฉพาะตัว 1.79 ตัวเลขพวกนี้คลาดได้แค่ไหน สูตรจากหน้าความคลาดของ Sharpe Ratio ให้ SE (standard error คือขนาดที่ตัวเลขที่คำนวณจากข้อมูลมักคลาดจากค่าจริง) เมื่อมีข้อมูล $q$ จุดต่อปี เป็นเวลา $T$ ปี ที่นี่ใช้ข้อมูลรายวัน $q=251$ และ $T=1$ ปี

\[ \begin{aligned} \text{SE}(\widehat{\text{SR}})&=\sqrt{\frac{1+\text{SR}^2/(2q)}{T}},\\ \text{style}&:\ \sqrt{1+\frac{0.74^2}{502}}=1.0005,\\ \text{idio}&:\ \sqrt{1+\frac{1.79^2}{502}}=1.0032. \end{aligned} \]

SE ของทุกบรรทัดได้ราว 1.00 เพราะ $\text{SR}^2/502$ เล็กมากเมื่อเทียบกับ 1 Sharpe Ratio 0.74 ของ style ห่างจากศูนย์ไม่ถึง 1 SE จึงแยกไม่ออกจากศูนย์ แม้ 1.79 ของส่วนเฉพาะตัวก็ห่างจากศูนย์แค่ $1.79/1.0032=1.78$ เท่าของ SE ยังไม่ถึง 1.96 ซึ่งเป็นระยะที่ครอบ 95% ของรูประฆัง Normal ปีเดียวจึงเป็นจุดเริ่มของการคุย ไม่ใช่ข้อสรุป

ขั้นที่ 7 — ต้นทุนกิน Sharpe Ratio เต็ม ๆ

บรรทัดต้นทุนต่างจากบรรทัดอื่น มันแทบไม่แกว่ง แต่ลดกำไรลงทุกวัน ขั้นนี้คำนวณว่ามันกิน Sharpe Ratio ไปเท่าไร ของที่ต้องใช้มีสามอย่าง

  • ต้นทุนเฉลี่ยวันละ $c=\$3{,}000$
  • ต้นทุนแกว่งวันละราว $\sqrt2\times1{,}500=\$2{,}121$ เพราะ SD ของการแจกแจง gamma คือ $\sqrt{\text{shape}}\times\text{scale}$
  • ความผันผวนรายวันของ position PnL $v=\$159{,}844$

ต้นทุนแกว่งน้อยกว่าพอร์ตราว $159{,}844/2{,}121=75$ เท่า มันจึงลดค่าเฉลี่ยโดยแทบไม่เพิ่มความเสี่ยง ให้ $\mu$ เป็นกำไรเฉลี่ยรายวันก่อนหักต้นทุน Sharpe Ratio ต่อปีหลังหักต้นทุนคือกำไรเฉลี่ยต่อปี $251(\mu-c)$ หารด้วยความผันผวนต่อปี $v\sqrt{251}$ ถ้าความผันผวนแทบไม่เปลี่ยน มันแยกเป็นสองก้อนได้

\[ \begin{aligned} \text{SR}_{\rm book}&\approx\frac{251(\mu-c)}{v\sqrt{251}}=\frac{(\mu-c)\sqrt{251}}{v}\\ &=\text{SR}_{\rm pos}-\frac{c\sqrt{251}}{v},\\ \frac{c\sqrt{251}}{v}&=\frac{3{,}000(15.843)}{159{,}844}\\ &=0.297. \end{aligned} \]

สูตรบอกว่าต้นทุนลบออกจาก Sharpe Ratio ตรง ๆ เป็นก้อน $c\sqrt{251}/v$ ซึ่งคือต้นทุนต่อปีที่วัดเป็นจำนวนเท่าของความผันผวนต่อปี ขั้นที่ต้องดูคือ $\approx$ ในบรรทัดแรก มันมาจากการใช้ $v$ เดิมเป็นตัวหาร ทั้งที่ต้นทุนเพิ่มความแกว่งเข้ามานิดหนึ่ง ถ้าต้นทุนไม่สัมพันธ์กับกำไรของพอร์ต variance ของสองก้อนบวกกันได้ ความผันผวนจึงเพิ่มแค่ $\sqrt{159{,}844^2+2{,}121^2}-159{,}844=\$14$ ต่อวัน การใช้ $v$ เดิมจึงแทบไม่ผิด

เทียบกับปีจำลอง Sharpe Ratio ที่วัดได้ก่อนหักต้นทุนคือ 1.619 และหลังหักคือ 1.332 (ดูรูปถัดไป) ลดไป $1.619-1.332=0.287$ ใกล้กับ 0.297 ที่ออกแบบไว้มาก ต่างจากบรรทัดอื่นที่โชคทำให้แกว่งได้ ±1.00

ข้อนี้ทำให้ต้นทุนเป็นเป้าที่คุ้มที่สุด ถ้าลดต้นทุนลงครึ่งหนึ่ง Sharpe Ratio จะคืนมาราว $0.297/2=0.15$ แทบแน่นอน ส่วนการหา alpha ใหม่ที่ให้ผลเท่ากันนั้นไม่แน่นอนเลย

ขั้นที่ 8 — ตอบคำถามเรื่อง style

ตอนนี้ตอบคำถามของ hook ได้แล้ว ขั้นที่ 6 บอกว่าตัวเลขของปีเดียวใช้ตัดสินไม่ได้ จึงต้องใช้ค่าที่ออกแบบไว้ แล้วถามว่าถ้าขยาย style ไป Sharpe Ratio คาดหวังของทั้งพอร์ตจะเป็นเท่าไร

โจทย์ให้อะไรมาบ้าง: พอร์ตของหน้าการแบ่งความเสี่ยง ให้ $x$ เป็นตัวคูณขนาดของ style ($x=1$ คือวันนี้ $x=2$ คือสองเท่า) ความผันผวนรายวันของ style จึงเป็น $70x$ พันดอลลาร์ ส่วนกลุ่มอื่นคงเดิม

  • ตัวเศษของ Sharpe Ratio ใช้สูตรเดียวกับหน้านั้น คือ $\sum_i\text{SR}_iv_i$ (ตัวคูณ $\sqrt{251}$ ของตัวเศษกับตัวส่วนตัดกันไป) market กับ industry มี Sharpe Ratio เป็น 0 จึงเหลือ $0.8(70x)+1.6(120)=56x+192$
  • ตัวส่วนคือความเสี่ยงรวม $\sqrt{\text{variance}}$ ช่องของ variance แบ่งได้สามแบบตามจำนวน $x$ ที่คูณอยู่
    • ช่อง style กับ style คือ $(70x)^2=4{,}900x^2$
    • ช่องไขว้ของ style กับ market คือ covariance $0.25(40)(70)=700$ และกับ industry คือ $-0.15(70)(50)=-525$ แต่ละช่องมีคู่แฝดอีกฝั่งของแนวทแยง รวมได้ $2(700-525)x=350x$
    • ช่องที่ไม่เกี่ยวกับ style ไม่เปลี่ยน รวมได้ $25{,}550-4{,}900-350=20{,}300$

ใส่สองอย่างนี้ลงในสูตร Sharpe Ratio แล้วลองที่วันนี้กับที่สองเท่า

\[ \begin{aligned} \text{SR}(x)&=\frac{56x+192}{\sqrt{4{,}900x^2+350x+20{,}300}},\\ \text{SR}(1)&=\frac{248}{\sqrt{25{,}550}}=1.5515,\\ \text{SR}(2)&=\frac{112+192}{\sqrt{19{,}600+700+20{,}300}}\\ &=\frac{304}{\sqrt{40{,}600}}=1.5087. \end{aligned} \]

สองเท่าแย่กว่าวันนี้ แล้วขนาดไหนดีที่สุด ให้ $N=56x+192$ และ $D=4{,}900x^2+350x+20{,}300$ แล้ว $\text{SR}=N/\sqrt D$ อนุพันธ์ของมันคือ $(N'D-\tfrac12ND')/D^{3/2}$ จุดยอดจึงอยู่ตรงที่ $N'D=\tfrac12ND'$ โดย $N'=56$ และ $\tfrac12D'=4{,}900x+175$ พจน์ $x^2$ ของสองข้างเท่ากัน ($56\times4{,}900=274{,}400$) จึงตัดกันหายไป

\[ \begin{aligned} 56D&=(56x+192)(4{,}900x+175),\\ 19{,}600x+1{,}136{,}800&=950{,}600x+33{,}600,\\ x^\ast&=\frac{1{,}103{,}200}{931{,}000}=1.185,\\ \text{SR}(x^\ast)&=\frac{56(1.185)+192}{\sqrt{27{,}595}}\\ &=\frac{258.36}{166.12}=1.5553. \end{aligned} \]

คำตอบ: ขยาย style สองเท่าทำให้ Sharpe Ratio คาดหวังลดจาก 1.5515 เป็น 1.5087 ขนาดที่ดีที่สุดคือ $x^\ast=1.185$ คือเพิ่ม style ราว 18% ได้ 1.5553 สูงกว่าวันนี้แค่ $1.5553-1.5515=0.004$ คำแนะนำคือเพิ่ม style ได้เล็กน้อย แต่สองเท่าไม่ได้ และการตัดสินใจนี้ใช้ Sharpe Ratio ที่ออกแบบไว้ ไม่ใช่ตัวเลขของปีเดียว

แล้วทำไมหน้าการแบ่งความเสี่ยงบอกว่า style ควรขยาย หน้านั้นหาความชันของ Sharpe Ratio เทียบกับขนาดของ style ได้ +0.060 ต่อ \$100,000 ของความผันผวนรายวัน ความชันเป็นบวก แปลว่าขยายนิดหน่อยแล้วดีขึ้น แต่ความชันใช้ได้แค่ใกล้จุด $x=1$ การขยายสองเท่าเพิ่มความผันผวนของ style \$70,000 หรือ 0.70 หน่วยของ \$100,000 เส้นตรงจึงทาย $1.5515+0.060(0.70)=1.594$ ทั้งที่ค่าจริงคือ 1.5087 เพราะเส้นโค้งเลยยอดไปแล้ว

ตรวจเองใน 10 วินาที: ที่ $x=1$ variance ต้องคืนค่าวันนี้ $4{,}900+350+20{,}300=25{,}550$ ตรงกับความเสี่ยงรวมของพอร์ตนั้น $\sqrt{25{,}550}=159.844$ พันดอลลาร์

ขั้นที่ 9 — factor return เป็นค่าประมาณ การแบ่งจึงคลาดได้

ทุกขั้นที่ผ่านมาทำเหมือนเรารู้ factor return ของจริง $\mathbf f_t$ ในงานจริงไม่มีใครรู้ สิ่งที่มีคือค่าประมาณ $\hat{\mathbf f}_t=\mathbf H\mathbf r_t$ จากregression ข้ามหุ้น (เอาผลตอบแทนของหุ้นทุกตัวในวันนั้นมา regress บน loadings) หน้า Frisch–Waugh–Lovell แสดงไว้ว่าค่าประมาณนี้คลาดจากค่าจริง และความคลาดมี covariance $\mathbf G$ ขั้นนี้ถามว่า ถ้าเอาค่าประมาณมาทำบัญชี ความคลาดจะไปตกที่บรรทัดไหน

ต้องใช้ข้อเท็จจริงสองข้อจากหน้านั้น ข้อแรก $\mathbf H\mathbf B=\mathbf I$ คือถ้าผลตอบแทนมาจาก factor ล้วน ๆ การประมาณจะคืน factor return มาให้พอดี ข้อสอง covariance ของ $\mathbf H\boldsymbol\epsilon_t$ คือ $\mathbf G$ เพื่อให้เห็นภาพชัด ให้ $\boldsymbol\alpha_\perp=\mathbf 0$ ผลตอบแทนของหุ้นจึงเป็น $\mathbf r_t=\mathbf B\mathbf f_t+\boldsymbol\epsilon_t$ บรรทัด factor ที่รายงานใช้ $\hat{\mathbf f}_t$ แทน $\mathbf f_t$ ส่วนบรรทัดเฉพาะตัวที่รายงานคือส่วนที่เหลือ คือ position PnL ลบบรรทัด factor ที่รายงาน

\[ \begin{aligned} \hat{\mathbf f}_t&=\mathbf H(\mathbf B\mathbf f_t+\boldsymbol\epsilon_t)\\ &=\mathbf f_t+\mathbf H\boldsymbol\epsilon_t,\\ \hat F_t&=\mathbf b_t^{\mathsf T}\hat{\mathbf f}_t\\ &=F_t+\mathbf b_t^{\mathsf T}\mathbf H\boldsymbol\epsilon_t,\\ \hat I_t&=\mathbf w_t^{\mathsf T}\mathbf r_t-\hat F_t\\ &=I_t-\mathbf b_t^{\mathsf T}\mathbf H\boldsymbol\epsilon_t,\\ \operatorname{var}(\mathbf b_t^{\mathsf T}\mathbf H\boldsymbol\epsilon_t)&=\mathbf b_t^{\mathsf T}\mathbf G\mathbf b_t. \end{aligned} \]

ให้ $e_t=\mathbf b_t^{\mathsf T}\mathbf H\boldsymbol\epsilon_t$ เป็นความคลาดของวัน สูตรบอกว่ามันเข้าบรรทัด factor ด้วยเครื่องหมายบวก และออกจากบรรทัดเฉพาะตัวด้วยเครื่องหมายลบ เหมือนไม้กระดก ผลรวมของสองบรรทัดจึงถูกเสมอ แต่การแบ่งคลาดได้

บรรทัด $\hat I_t$ ได้มาจาก $\mathbf w_t^{\mathsf T}\mathbf r_t=F_t+I_t$ ลบ $\hat F_t$ ส่วนบรรทัดสุดท้ายใช้กฎ $\operatorname{var}(\mathbf a^{\mathsf T}\mathbf y)=\mathbf a^{\mathsf T}\operatorname{cov}(\mathbf y)\mathbf a$ กับ $\mathbf a=\mathbf b_t$ และ $\mathbf y=\mathbf H\boldsymbol\epsilon_t$ ขนาดของความคลาดจึงวัดด้วย SD $\sqrt{\mathbf b_t^{\mathsf T}\mathbf G\mathbf b_t}$ และเพราะความคลาดของสองบรรทัดคือ $+e_t$ กับ $-e_t$ covariance ของสองความคลาดนี้จึงเป็น $-\operatorname{var}(e_t)=-\mathbf b_t^{\mathsf T}\mathbf G\mathbf b_t$ คือสวนทางกันเต็มที่

ข้อนี้อธิบายปริศนาสองข้อที่คนทำรายงานเจอ ทั้งสองข้อเกี่ยวกับ factor-mimicking portfolio คือพอร์ตหุ้นที่ผลตอบแทนของมันคือค่าประมาณของ factor return ตัวหนึ่ง (แต่ละแถวของ $\mathbf H$ คือน้ำหนักของพอร์ตแบบนี้หนึ่งพอร์ต)

  • ปริศนาข้อแรก factor-mimicking portfolio มีความเสี่ยงเฉพาะตัว เพราะมันถือหุ้นจริงที่มีข่าวของตัวเอง แต่ idiosyncratic PnL ที่รายงานของมันเป็นศูนย์ทุกวัน เหตุผลคือผลตอบแทนของมันถูกนิยามให้เป็น factor return ทั้งก้อน ส่วนเฉพาะตัวจริงของมันจึงถูกนับเป็น factor ไปหมด ซึ่งก็คือความคลาด $e_t$ นั่นเอง
  • ปริศนาข้อสอง เอาพอร์ตที่ไม่มี exposure ต่อ factor เลย แล้วเติม factor-mimicking portfolio เข้าไป ไม่ว่าจะเติมขนาดเท่าไร idiosyncratic PnL ที่รายงานก็ไม่เปลี่ยน (เพราะส่วนที่เติมมีบรรทัดเฉพาะตัวเป็นศูนย์ตามข้อแรก) ทั้งที่ความเสี่ยงเฉพาะตัวจริงเปลี่ยน

ทางออกคือยอมรับว่า factor return เป็นค่าประมาณ แล้วรายงานช่วงความคลาด $\sqrt{\mathbf b^{\mathsf T}\mathbf G\mathbf b}$ คู่กับทุกบรรทัด ในปริศนาข้อสอง exposure $\mathbf b$ โตตามขนาดของส่วนที่เติม ช่วงความคลาดจึงโตตามไปด้วย ตัวเลขที่รายงานไม่เปลี่ยน แต่ความไม่แน่นอนของมันเปลี่ยน ซึ่งตรงกับความเสี่ยงที่เปลี่ยนไปจริง

ขั้นที่ 10 — ถ้าประมาณ factor return จากสี่หุ้นนี้เอง

ลองดูขนาดของปัญหาด้วยตัวเลข ใช้วันที่ 1 ของบัญชีสองวัน ซึ่งเรารู้ค่าจริงของทุกบรรทัดแล้ว (factor −\$66,000 และเฉพาะตัว +\$53,000) แล้วสมมติว่า risk model (ชุดตัวเลขของ factor model ที่ใช้ทำรายงาน) ไม่รู้ factor return จริง ต้องประมาณจากหุ้นสี่ตัวนี้เอง

โจทย์ให้อะไรมาบ้าง: หน่วยของเงินยังเป็น \$10,000 เหมือนขั้นที่ 2

  • วิธีประมาณคือ WLS (regression ที่ให้น้ำหนักหุ้นที่แกว่งน้อยมากกว่า) จากหุ้นสี่ตัว ความผันผวนเฉพาะตัว 1.80%, 2.20%, 1.50% และ 2.60%
  • หน้า Frisch–Waugh–Lovell คำนวณค่าประมาณของวันนี้ไว้แล้ว ที่นี่เขียนหกตำแหน่งเพื่อให้คูณได้แม่น $\hat{\mathbf f}_1=(0.723691,\ -0.111986,\ 0.298992)\%$ เทียบกับค่าจริง $(0.80,\ -0.50,\ 0.30)\%$
  • ช่องของ $\mathbf G=(\mathbf B^{\mathsf T}\boldsymbol\Omega_\epsilon^{-1}\mathbf B)^{-1}$ ที่ต้องใช้ ($\boldsymbol\Omega_\epsilon$ คือ matrix แนวทแยงของ variance เฉพาะตัว หน่วยของ $\mathbf G$ คือ %²) $G_{\rm mom,mom}=1.31444$, $G_{\rm tech,tech}=3.90447$ และ $G_{\rm mom,tech}=-0.60183$
  • exposure วันที่ 1 $\mathbf b_1=(0,\ 13.8,\ 1)$ \$ ล้าน และ position PnL $\mathbf w_1^{\mathsf T}\mathbf r_1=F_1+I_1=-6.60+5.30=-1.30$

บรรทัด factor ที่รายงานใช้ $\hat{\mathbf f}_1$ แทนค่าจริง บรรทัดเฉพาะตัวที่รายงานคือ position PnL ลบบรรทัด factor นั้น แล้วหาขนาดของความคลาดจาก $\mathbf b_1^{\mathsf T}\mathbf G\mathbf b_1$ ซึ่ง market ไม่เข้ามาเกี่ยว เพราะ exposure ต่อ market เป็นศูนย์

\[ \begin{aligned} \hat F_1&=13.8(-0.111986)+1(0.298992)\\ &=-1.2464,\\ \hat I_1&=-1.30-(-1.2464)\\ &=-0.0536,\\ \mathbf b_1^{\mathsf T}\mathbf G\mathbf b_1&=13.8^2(1.31444)+1^2(3.90447)\\ &\quad+2(13.8)(1)(-0.60183)\\ &=250.32+3.90-16.61\\ &=237.62,\\ \sqrt{237.62}&=15.41. \end{aligned} \]

คำตอบ: รายงานจะบอกว่า factor เสีย \$12,464 และการเลือกหุ้นเสีย \$536 ทั้งที่ค่าจริงคือ factor −\$66,000 และเฉพาะตัว +\$53,000 บรรทัด factor คลาดไป $\hat F_1-F_1=-1.2464-(-6.60)=5.3536$ หรือ +\$53,536 บรรทัดเฉพาะตัวคลาดไปเท่ากันในทิศตรงข้าม $\hat I_1-I_1=-0.0536-5.30=-5.3536$ เงิน \$53,536 จึงย้ายจากบรรทัดเฉพาะตัวไปอยู่บรรทัด factor

ความคลาดขนาดนี้ไม่แปลก SD ของความคลาดคือ $15.41\times\$10{,}000$ หรือ \$154,148 ต่อวัน ความคลาดของวันนี้เป็นแค่ $53{,}536/154{,}148=0.35$ เท่าของ SD ต้นเหตุคือมีหุ้นแค่สี่ตัว ถ้าประมาณจากหุ้น 400 ตัว ที่ loading และความผันผวนซ้ำชุดเดิม 100 ชุด $\mathbf G$ จะหารด้วย 100 ตามที่หน้า Frisch–Waugh–Lovell แสดง SD ของความคลาดจึงหารด้วย $\sqrt{100}=10$ เหลือ \$15,415 ต่อวัน ยังใหญ่พอจะบิดรายงานรายวันได้

แต่ความคลาดของแต่ละวันไม่เกี่ยวกัน ถ้า exposure ใกล้เดิมทุกวัน variance ของผลรวมทั้งปีจะโต 251 เท่า SD จึงโตแค่ $\sqrt{251}$ เท่า ได้ $15{,}415\times15.843=\$244{,}220$ ต่อปี ไม่ใช่ $15{,}415\times251$

ตรวจเองใน 10 วินาที: $\hat F_1+\hat I_1=-1.2464-0.0536=-1.30$ เท่ากับ $F_1+I_1=-6.60+5.30=-1.30$ ผลรวมไม่เคยผิด ผิดได้แค่การแบ่ง

รายงานการแบ่งโดยไม่มีช่วงความคลาด: เมื่อประมาณ factor return จากหุ้นน้อย บรรทัด factor ของวันที่ 1 รายงานได้ −\$12,464 แทนค่าจริง −\$66,000 เงิน \$53,536 ย้ายจากการเลือกหุ้นไปเป็น factor ในวันเดียว ทั้งที่ SD ของความคลาดคือ $\sqrt{237.62}\times\$10{,}000=\$154{,}148$ ความคลาดของสองบรรทัดสวนทางกันเสมอ จึงต้องรายงาน $\sqrt{\mathbf b^{\mathsf T}\mathbf G\mathbf b}$ คู่กันทุกบรรทัด ถ้าปีไหนบรรทัดเฉพาะตัวติดลบ ให้ดูก่อนว่าศูนย์อยู่ในช่วงความคลาดหรือเปล่า

ใช้ทำอะไรบนโต๊ะจริง

รายงานรายเดือนของโต๊ะหุ้นมักมีบรรทัด trading, กลุ่ม factor (market, style, industry) และเฉพาะตัว แต่ละบรรทัดมีสามคอลัมน์ คือดอลลาร์ ความผันผวนที่ใช้ไป และ Sharpe Ratio ซึ่งคือคอลัมน์แรกหารด้วยคอลัมน์ที่สอง คอลัมน์ที่สามคือคอลัมน์ที่ใช้ตัดสินใจ

แต่ละบรรทัดมีคนใช้ต่างกัน บรรทัดเฉพาะตัวพร้อมช่วงความคลาดใช้คุยเรื่องค่าตอบแทนของผู้จัดการพอร์ต เพราะกำไรจาก factor ซื้อได้ถูกจากที่อื่น เช่น กองทุนที่ถือ factor ตามกติกาที่ประกาศไว้ บรรทัด trading ใช้คุยกับทีมเทรดเรื่องต้นทุน

อีกข้อที่ควรรู้คือ รายงานย้อนหลังไม่ต้องใช้ risk model ตัวเดียวกับที่ใช้สร้างพอร์ต หลังจบงวดจะดูพอร์ตผ่าน risk model อื่นก็ได้ เช่น model ทั้งโลกที่เห็น exposure ข้ามประเทศ

เปิดดูโค้ด

รันใน Node.js ได้โดยไม่ต้องติดตั้งอะไร โค้ดทำบัญชีสองวันแยกเป็นสามบรรทัดพร้อมรวมราย factor และรายหุ้น แยก selection กับ sizing คำนวณค่าที่ออกแบบของปีจำลอง ความคลาดของ Sharpe Ratio ต้นทุนที่กิน Sharpe Ratio การปรับขนาด style และการแบ่งที่ได้เมื่อใช้ factor return ที่ประมาณจากสี่หุ้น

const {sqrt, abs, sign} = Math;
const dot = (a, b) => a.reduce((s, v, i) => s + v * b[i], 0);
const transpose = A => A[0].map((_, j) => A.map(row => row[j]));
const matVec = (A, x) => A.map(row => dot(row, x));
const UNIT = 1e4; // one million dollars times 1% is 10,000 dollars
// Attribution ledger: positions held at the start of each day, factor and idiosyncratic returns, recorded PnL.
function attribute(B, days) {
  if (!Array.isArray(B) || !B.length || !Array.isArray(days) || !days.length) throw new TypeError('Need loadings and at least one day');
  const n = B.length, m = B[0].length, Bt = transpose(B);
  const byFactor = new Array(m).fill(0), byStock = new Array(n).fill(0);
  const rows = days.map(({w, f, eps, recorded}) => {
    if (w.length !== n || eps.length !== n || f.length !== m) throw new RangeError('Each day needs n positions, n idiosyncratic returns and m factor returns');
    if (!Number.isFinite(recorded)) throw new TypeError('Each day needs the recorded PnL');
    const b = matVec(Bt, w);
    b.forEach((x, j) => { byFactor[j] += x * f[j] * UNIT; });
    w.forEach((x, i) => { byStock[i] += x * eps[i] * UNIT; });
    const factor = dot(b, f) * UNIT, idio = dot(w, eps) * UNIT;
    return {b, factor, idio, position: factor + idio, trading: recorded - factor - idio, recorded};
  });
  const sum = key => rows.reduce((s, r) => s + r[key], 0);
  return {rows, byFactor, byStock, factor: sum('factor'), idio: sum('idio'), position: sum('position'), trading: sum('trading'), total: sum('recorded')};
}
// One-day information ratio split into selection x diversification + sizing.
function selectionSizing(w, eps, sig) {
  const n = w.length;
  if (eps.length !== n || sig.length !== n || !sig.every(s => s > 0)) throw new RangeError('Need matching positions, returns and positive volatilities');
  const x = eps.map((e, i) => e / sig[i] * sign(w[i])), size = w.map((v, i) => abs(v * sig[i]));
  const mx = x.reduce((s, v) => s + v, 0) / n, my = size.reduce((s, v) => s + v, 0) / n;
  const l1 = size.reduce((s, v) => s + v, 0), l2 = sqrt(dot(size, size));
  const cov = dot(x, size) / n - mx * my;
  return {selection: mx, diversification: l1 / l2, sizing: n * cov / l2, ir: dot(w, eps) / l2};
}
// One year of the risk-decomposition book as designed: expected dollars per line, and the cost drag on the Sharpe Ratio.
function designYear(vols, sharpes, bookVol, costPerDay, days) {
  if (!(days > 1) || !(bookVol > 0) || !(costPerDay >= 0)) throw new RangeError('Need days > 1, a positive book volatility and a non-negative cost');
  const root = sqrt(days);
  const expected = vols.map((v, i) => sharpes[i] * v * root), annualVol = vols.map(v => v * root);
  const positionSharpe = dot(sharpes, vols) / bookVol;
  return {expected, annualVol, cost: costPerDay * days, positionSharpe, drag: costPerDay * root / bookVol, bookSharpe: positionSharpe - costPerDay * root / bookVol};
}
// Standard error of an annual Sharpe Ratio estimated from q observations a year over T years.
const sharpeSE = (sr, q, years) => sqrt((1 + sr * sr / (2 * q)) / years);
// Sharpe of the risk-decomposition book when the style group is scaled by x.
function sharpeWithStyle(x) {
  const v = [40, 70, 50, 120], C = [[1, 0.25, 0.45, 0], [0.25, 1, -0.15, 0], [0.45, -0.15, 1, 0], [0, 0, 0, 1]], sr = [0, 0.8, 0, 1.6];
  const vs = v.map((q, i) => q * (i === 1 ? x : 1));
  let variance = 0;
  for (let i = 0; i < 4; i++) for (let j = 0; j < 4; j++) variance += C[i][j] * vs[i] * vs[j];
  return dot(sr, vs) / sqrt(variance);
}
function inverse(A) {
  const n = A.length, M = A.map((row, i) => [...row, ...row.map((_, j) => (i === j ? 1 : 0))]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let i = c + 1; i < n; i++) if (abs(M[i][c]) > abs(M[p][c])) p = i;
    if (abs(M[p][c]) < 1e-12) throw new RangeError('Loadings are collinear');
    [M[c], M[p]] = [M[p], M[c]];
    const piv = M[c][c];
    for (let j = 0; j < 2 * n; j++) M[c][j] /= piv;
    for (let i = 0; i < n; i++) if (i !== c) { const g = M[i][c]; for (let j = 0; j < 2 * n; j++) M[i][j] -= g * M[c][j]; }
  }
  return M.map(row => row.slice(n));
}
