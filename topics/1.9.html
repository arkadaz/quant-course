1.9 The Normal (Gaussian) Distribution and Quantile-Quantile (QQ) Diagnostics

Normal ใช้แค่ค่าเฉลี่ยกับความผันผวนก็คำนวณโอกาสได้ทุกช่วง ส่วน QQ plot บอกว่าข้อมูลจริงหลุดออกจากมันตรงไหน

กองทุนแห่งหนึ่งถือพอร์ตหุ้นมูลค่า \$50 ล้าน ผู้จัดการพอร์ตอยากรู้ว่า “วันแย่ ๆ” จะมาบ่อยแค่ไหน ทีมความเสี่ยงจึงสร้างแบบจำลองง่าย ๆ ขึ้นมา คือสมมติว่าผลตอบแทนรายวันของพอร์ตกระจายตัวเป็นรูประฆังที่เรียกว่า Normal distribution แล้วใช้รูประฆังนั้นคำนวณโอกาสขาดทุน

ของที่รู้ (ตัวเลขของพอร์ตเป็นตัวเลขสมมติ):

  • มูลค่าพอร์ต \$50 ล้าน
  • ผลตอบแทนรายวัน $R$ คือมูลค่าพอร์ตเปลี่ยนไปกี่ % ในหนึ่งวัน เช่นวันที่ $R=-2\%$ พอร์ตขาดทุน $0.02\times\$50{,}000{,}000=\$1{,}000{,}000$
  • ค่าเฉลี่ยของผลตอบแทนรายวัน $\mu=0.04\%$ แปลว่าโดยเฉลี่ยพอร์ตโตขึ้นนิดหน่อยทุกวัน
  • ความผันผวนรายวัน $\sigma=1.10\%$ คือ SD (standard deviation) ของผลตอบแทนรายวัน บอกว่าผลตอบแทนมักแกว่งห่างจากค่าเฉลี่ยราวเท่าไร คิดเป็นเงินได้ $0.011\times\$50{,}000{,}000=\$550{,}000$
  • ปีหนึ่งมี 252 วันซื้อขาย คือจำนวนวันที่ตลาดหุ้นสหรัฐเปิดในปีทั่วไป: 365 วัน หักเสาร์อาทิตย์ 104 วัน และวันหยุดตลาดราว 9 วัน ได้ $365-104-9=252$

ทีมความเสี่ยงรายงานว่า วันที่ขาดทุนเกิน 2% จะเกิดเฉลี่ยราว 8 วันต่อปี (ขั้นที่ 2 จะคำนวณตัวเลขนี้ให้ดู) ผู้จัดการพอร์ตคิดต่อว่า ถ้าเกณฑ์ขาดทุนเพิ่มเป็นสองเท่า ความถี่ก็น่าจะลดลงครึ่งหนึ่ง จึงถามว่า “ขาดทุนเกิน 4% ก็น่าจะเกิดราว $8/2=4$ วันต่อปีใช่ไหม”

ลองตอบก่อนเปิดเฉลย

ไม่ใช่ ภายใต้ Normal ตัวเดียวกันนี้ โอกาสขาดทุนเกิน 4% ในหนึ่งวันมีแค่ราว 0.012% หรือ 0.00012 (ขั้นที่ 3 จะคำนวณให้ดู) จำนวนวันต่อปีจึงเป็น $252\times0.00012\approx0.0302$ วัน คือต้องรอเฉลี่ยราว $1/0.0302\approx33$ ปีจึงจะเจอสักครั้ง

เทียบกับขาดทุนเกิน 2% ซึ่งมีโอกาสราว 3.18% หรือ 0.0318 ต่อวัน วันขาดทุนเกิน 4% หายากกว่าถึง $0.0318/0.00012\approx265$ เท่า ไม่ใช่ 2 เท่า

เหตุผลคือหางของ Normal บางลงเร็วมาก หาง (tail) คือส่วนปลายของรูประฆังที่อยู่ไกลจากค่าเฉลี่ย ซึ่งแทนวันที่ผลตอบแทนสุดโต่ง ยิ่งห่างจากค่าเฉลี่ย ความสูงของระฆังยิ่งหดเร็วขึ้น คำถามต่อมาคือหางของข้อมูลหุ้นจริงบางแบบนั้นไหม คำตอบคือมักไม่บาง ครึ่งหลังของหน้านี้จะตรวจเรื่องนี้กับข้อมูลจริง

ภาพรวมก่อนลงสูตร

Normal distribution (อีกชื่อคือ Gaussian) คือรูประฆังที่สมมาตรรอบค่าเฉลี่ย $\mu$ ส่วนความกว้างของระฆังกำหนดด้วย SD $\sigma$ (ทบทวน SD ได้ที่ Variance and Standard Deviation) ความสูงของเส้นที่แต่ละจุดเรียกว่า density และโอกาสที่ค่าจะตกในช่วงหนึ่งคือพื้นที่ใต้เส้นในช่วงนั้น ตามที่ ตัวแปรสุ่มต่อเนื่องและ PDF ปูไว้

จุดแข็งของ Normal คือ ทุกตัวเป็นตัวเดียวกันที่ถูกเลื่อนและยืด ตัวต้นแบบเรียกว่า Normal มาตรฐาน มีค่าเฉลี่ย 0 และ SD 1 Normal ตัวไหนก็ได้มาจากการยืดตัวต้นแบบด้วย $\sigma$ แล้วเลื่อนไปวางที่ $\mu$ เราจึงตอบคำถามเรื่องโอกาสได้ทุกข้อด้วยตารางเดียว (หรือ function เดียวในคอมพิวเตอร์) ขั้นที่ 1 จะแสดงว่าพื้นที่รอบค่าเฉลี่ยมีตัวเลขจำง่ายสามตัว: ช่วง ±1σ มีพื้นที่ 68.3% ช่วง ±2σ มี 95.4% และช่วง ±3σ มี 99.7%

จุดอ่อนอยู่ที่หาง เมื่ออยู่ห่างจากค่าเฉลี่ย $z$ เท่าของ σ ความสูงของระฆังลดลงตาม $e^{-z^2/2}$ ซึ่งลดเร็วมาก ในหางไกล ขยับออกไปอีกหนึ่ง σ โอกาสหดลงหลายสิบเท่า (ขั้นที่ 5 จะคำนวณให้ดู) แต่ข้อมูลผลตอบแทนหุ้นจริงมีวันสุดโต่งบ่อยกว่านั้น ถ้าใช้ Normal โดยไม่ตรวจ ตัวเลขความเสี่ยงของวันร้าย ๆ จะต่ำกว่าความจริง

หน้านี้จึงแบ่งเป็นสองครึ่ง

  • ครึ่งแรก (ขั้นที่ 1–5) ใช้ Normal กับพอร์ต \$50 ล้าน หาโอกาสขาดทุน จำนวนวันต่อปี และ VaR คือขาดทุนระดับที่วันปกติจะเกินได้แค่ 1 วันใน 100 วัน แล้วดูว่าทำไมหางของ Normal บางขนาดนั้น
  • ครึ่งหลัง (ขั้นที่ 6–9) หาที่มาของรูประฆัง และของเลข 3 ใน kurtosis ซึ่งเป็นตัวเลขวัดว่าหางหนาแค่ไหน แล้วใช้ QQ plot คือกราฟที่เทียบข้อมูลจริงกับ Normal ทีละอันดับ ตรวจกับข้อมูลจริงว่าสมมติฐาน Normal พังตรงไหน
ศัพท์ที่ใช้ในหน้านี้
ผลตอบแทนรายวัน และความผันผวน
ผลตอบแทนรายวันคือมูลค่าเปลี่ยนไปกี่ % ในหนึ่งวัน ความผันผวนรายวันคือ SD ของผลตอบแทนรายวัน หน้านี้เขียนแทนด้วย $\sigma$
Normal มาตรฐาน และ z-score
Normal มาตรฐาน $Z$ คือ Normal ที่มีค่าเฉลี่ย 0 และ SD 1 (variance จึงเท่ากับ 1 ด้วย) z-score $z=(x-\mu)/\sigma$ บอกว่าค่า $x$ อยู่ห่างจากค่าเฉลี่ยกี่เท่าของ σ เช่นผลตอบแทน −2% ของพอร์ตในหน้านี้มี $z=(-0.02-0.0004)/0.011=-1.85$ เราใช้ z-score แปลงคำถามของ Normal ตัวไหนก็ได้ ให้ไปอ่านจากตารางของ Normal มาตรฐานตารางเดียว
$\phi$ และ $\Phi$
$\phi(z)$ คือ density ของ Normal มาตรฐาน คือความสูงของระฆังที่จุด $z$ ส่วน $\Phi(z)$ คือ CDF (cumulative distribution function) คือพื้นที่ใต้ระฆังทางซ้ายของ $z$ ซึ่งเท่ากับโอกาส $P(Z\le z)$ จำง่าย ๆ: ตัวเล็กให้ความสูง ตัวใหญ่ให้พื้นที่ $\Phi$ ไม่มีสูตรปิด ต้องอ่านจากตารางหรือให้คอมพิวเตอร์คำนวณ
quantile และ VaR
quantile คือการถามกลับทิศของ $\Phi$: แทนที่จะให้ค่าบนแกนแล้วถามพื้นที่ เราให้พื้นที่แล้วถามว่าค่าบนแกนอยู่ตรงไหน เขียนว่า $\Phi^{-1}(p)$ เช่น $\Phi^{-1}(0.01)=-2.33$ แปลว่าพื้นที่ทางซ้ายของ −2.33 เท่ากับ 1% VaR (Value at Risk) 99% หนึ่งวัน คือเงินขาดทุนระดับที่วันปกติจะเกินได้แค่ 1 วันใน 100 วัน หาได้จาก quantile 1% ของผลตอบแทน แล้วแปลงเป็นเงินขาดทุน
QQ plot
QQ ย่อจาก quantile-quantile เป็นกราฟที่เรียงข้อมูลจากน้อยไปมาก แล้วจับคู่แต่ละตัวกับค่าที่ Normal คาดไว้ที่อันดับเดียวกัน ถ้าข้อมูลมาจาก Normal จริง จุดจะเรียงเป็นเส้นตรง จุดที่หลุดจากเส้นบอกว่าข้อมูลต่างจาก Normal ตรงกลางหรือที่หาง
moment และ MGF
moment ลำดับ $m$ ของ $Z$ คือ $\mathbb E[Z^m]$ คือค่าเฉลี่ยของ $Z$ ยกกำลัง $m$ ส่วน MGF (moment generating function) คือ $\mathbb E[e^{tZ}]$ เมื่อกระจายเป็นอนุกรมกำลังของ $t$ สัมประสิทธิ์แต่ละตัวจะให้ moment แต่ละลำดับ
kurtosis
ค่าเฉลี่ยของ $(X-\mu)^4$ หารด้วย $\sigma^4$ การยกกำลังสี่ทำให้ค่าที่อยู่ไกลจากค่าเฉลี่ยมีน้ำหนักมาก ตัวเลขนี้จึงวัดว่าค่าสุดโต่งเกิดบ่อยแค่ไหน Normal มีค่า 3 พอดี (ขั้นที่ 7 พิสูจน์) ค่าที่มากกว่า 3 บอกว่าข้อมูลมีค่าสุดโต่งบ่อยกว่า Normal บางตำราใช้ค่านี้ลบ 3 แล้ว เรียกว่า excess kurtosis
heavy tails (หางหนา)
distribution ที่โอกาสในหางไกลลดลงช้ากว่า Normal วันที่ราคาขยับแรงมาก ๆ จึงเกิดบ่อยกว่าที่ Normal บอก ผลตอบแทนรายวันของหุ้นจริงหางหนาแทบทุกตัว ขั้นที่ 9 มีตัวเลขจริงให้ดู

สัญลักษณ์ความหมายหน่วย
$\mu,\ \sigma$ค่าเฉลี่ยและ SD (ความผันผวน) ของผลตอบแทนรายวันต่อวัน (ทศนิยม)
$Z,\ z$Normal มาตรฐาน และ z-score คือระยะจากค่าเฉลี่ยนับเป็นจำนวนเท่าของ σไม่มีหน่วย

ขั้นที่ 1 — ทุก Normal คือ Normal มาตรฐานที่เลื่อนและยืด

ก่อนจะคำนวณอะไรกับพอร์ต ต้องรู้ก่อนว่าจะอ่านโอกาสจาก Normal อย่างไร ปัญหาคือ Normal มีได้นับไม่ถ้วนแบบ ตามค่า $\mu$ และ $\sigma$ ที่เลือก ขั้นนี้แสดงว่าทุกแบบโยงกลับไปหา Normal มาตรฐานตัวเดียวได้

ตัวที่ใช้ในขั้นนี้

  • $X$ คือ Normal ที่มีค่าเฉลี่ย $\mu$ และ SD $\sigma$ เช่นผลตอบแทนรายวันของพอร์ต และ $f(x)$ คือ density ของ $X$
  • $Z$ คือ Normal มาตรฐาน และ $\phi(z)$ คือ density ของ $Z$
  • $k$ คือระยะจากค่าเฉลี่ย นับเป็นจำนวนเท่าของ σ
\[ \begin{aligned} f(x)&=\frac{1}{\sqrt{2\pi\sigma^2}}\,e^{-(x-\mu)^2/(2\sigma^2)}\\ \phi(z)&=\frac{1}{\sqrt{2\pi}}\,e^{-z^2/2}\\ X&=\mu+\sigma Z\\ z&=\frac{x-\mu}{\sigma}\\ P(X\le x)&=\Phi\!\left(\frac{x-\mu}{\sigma}\right)\\ P(|X-\mu|\le k\sigma)&=\Phi(k)-\Phi(-k)\\ &=\Phi(k)-\big(1-\Phi(k)\big)\\ &=2\Phi(k)-1\\ k=1&:\ 2(0.8413)-1=0.683\\ k=2&:\ 2(0.9772)-1=0.954\\ k=3&:\ 2(0.99865)-1=0.997 \end{aligned} \]

สูตรของ $f(x)$ ขึ้นกับ $x$ ผ่านก้อนเดียวคือ $(x-\mu)^2/\sigma^2$ ซึ่งก็คือ $z^2$ นั่นเอง Normal ทุกตัวจึงมีรูปทรงเดียวกัน ต่างกันแค่ตำแหน่ง ($\mu$) กับความกว้าง ($\sigma$) ส่วน $\sigma$ ที่ซ่อนอยู่ใน $\sqrt{2\pi\sigma^2}$ ข้างหน้า ทำให้พื้นที่ใต้เส้นยังเท่ากับหนึ่งหลังจากยืดระฆังให้กว้างขึ้น

เหตุที่ใช้ตารางเดียวได้คือ เหตุการณ์ $X\le x$ กับเหตุการณ์ $Z\le(x-\mu)/\sigma$ เป็นเหตุการณ์เดียวกัน เพราะเราแค่ลบ $\mu$ แล้วหารด้วย $\sigma$ ทั้งสองข้างของอสมการ และ $\sigma$ เป็นบวก ทิศของอสมการจึงไม่กลับ

ช่วงรอบค่าเฉลี่ยใช้ความสมมาตรของระฆัง: พื้นที่ทางซ้ายของ $-k$ เท่ากับพื้นที่ทางขวาของ $+k$ จึงได้ $\Phi(-k)=1-\Phi(k)$ ค่า $\Phi(1)=0.8413$, $\Phi(2)=0.9772$ และ $\Phi(3)=0.99865$ อ่านจากตาราง หรือจากโค้ดท้ายหน้า ข้อควรระวังมีสองข้อ ข้อแรก 68.3% เป็นพื้นที่รวมสองข้างของค่าเฉลี่ย ไม่ใช่ข้างเดียว ข้อสอง ตัวเลขชุดนี้ใช้ได้เฉพาะเมื่อข้อมูลเป็น Normal จริง การคำนวณ z-score ได้ไม่ได้ทำให้ข้อมูลกลายเป็น Normal

ขั้นที่ 2 — โอกาสขาดทุนเกิน 2% และจำนวนวันต่อปี

ตอนนี้ใช้เครื่องมือของขั้นที่ 1 กับพอร์ต \$50 ล้าน เพื่อตรวจตัวเลข “8 วันต่อปี” ในรายงาน ผลตอบแทนรายวัน $R$ เป็น Normal ที่มี $\mu=0.0004$ (0.04%) และ $\sigma=0.011$ (1.10%)

ขาดทุนเกิน 2% คือเหตุการณ์ $R\lt-0.02$ วิธีทำมีสามจังหวะ จังหวะแรก แปลงเกณฑ์ −0.02 เป็น z-score โดยลบค่าเฉลี่ยก่อน แล้วหารด้วย σ จังหวะที่สอง อ่านพื้นที่ทางซ้ายจาก $\Phi$ ได้โอกาสต่อวัน $p_2$ จังหวะที่สาม คูณด้วย 252 วันซื้อขายต่อปี

\[ \begin{aligned} z_2&=\frac{-0.02-0.0004}{0.011}\\ &=\frac{-0.0204}{0.011}\approx-1.8545\\ p_2&=\Phi(-1.8545)\approx0.03183\\ 252\,p_2&=252\times0.03183\approx8.02 \end{aligned} \]

ขาดทุน 2% อยู่ห่างจากค่าเฉลี่ย 1.85 เท่าของ σ ไม่ใช่ $0.02/0.011=1.82$ เท่า เพราะค่าเฉลี่ยอยู่ที่ +0.04% ไม่ใช่ศูนย์ ระยะจาก +0.04% ลงไปถึง −2% จึงเป็น 2.04% ไม่ใช่ 2% ค่า $\Phi(-1.8545)$ อ่านจากตารางหรือโค้ดท้ายหน้า ได้โอกาส 3.18% ต่อวัน และได้จำนวนวันเฉลี่ย 8.02 วันต่อปี

ทำไมคูณ 252 ได้เลย ให้ $N$ คือจำนวนวันที่ขาดทุนเกิน 2% ในหนึ่งปี $N$ คือผลบวกของตัวนับรายวัน 252 ตัว ตัวนับของแต่ละวันเป็น 1 ถ้าวันนั้นขาดทุนเกิน 2% และเป็น 0 ถ้าไม่ ค่าเฉลี่ยของตัวนับแต่ละตัวคือ $p_2$ และค่าเฉลี่ยของผลบวกเท่ากับผลบวกของค่าเฉลี่ยเสมอ จึงได้ $\mathbb E[N]=252\,p_2$ ข้อนี้ไม่ต้องสมมติว่าแต่ละวันอิสระกัน แต่ 8.02 เป็นแค่ค่าเฉลี่ย ไม่ได้รับประกันว่าทุกปีจะเจอ 8 วันพอดี

ขั้นที่ 3 — ขยับเกณฑ์เป็น 4%: หางบางลงเร็วแค่ไหน

ตอนนี้ตอบคำถามของผู้จัดการพอร์ตได้แล้ว เขาถามว่าถ้าเกณฑ์ขาดทุนเพิ่มจาก 2% เป็น 4% ความถี่จะลดลงแค่ครึ่งเดียวหรือไม่ เราทำสามจังหวะเดิมทุกอย่าง แค่เปลี่ยนเกณฑ์เป็น −0.04 แล้วเทียบผลกับ $p_2$ ของขั้นที่ 2

\[ \begin{aligned} z_4&=\frac{-0.04-0.0004}{0.011}\\ &=\frac{-0.0404}{0.011}\approx-3.6727\\ p_4&=\Phi(-3.6727)\approx0.000120\\ 252\,p_4&=252\times0.000120\approx0.0302\\ \frac{p_2}{p_4}&=\frac{0.03183}{0.000120}\approx265\\ \frac{1}{p_4}&=\frac{1}{0.000120}\approx8{,}333\\ \frac{8{,}333}{252}&\approx33 \end{aligned} \]

วันขาดทุนเกิน 4% เกิดเฉลี่ยแค่ 0.0302 วันต่อปี เกณฑ์เพิ่มแค่สองเท่า แต่โอกาสลดลง 265 เท่า ทำไม เพราะเกณฑ์ขยับจาก 1.85σ ไป 3.67σ และในช่วงนั้นความสูงของระฆังลดตาม $e^{-z^2/2}$ ซึ่งยิ่งไกลยิ่งลดเร็ว ลองเทียบความสูงที่สองจุดนี้: $e^{-(3.6727^2-1.8545^2)/2}=e^{-5.02}\approx1/152$ คือความสูงที่ 3.67σ เหลือแค่ราว 1/152 ของความสูงที่ 1.85σ

$1/p_4$ คือจำนวนวันที่ต้องรอโดยเฉลี่ยจนจะเจอวันแบบนี้หนึ่งวัน ถ้าแต่ละวันอิสระกันและโอกาสคงที่ หารด้วย 252 เพื่อแปลงวันซื้อขายเป็นปี ได้ราว 33 ปี ตัวเลขนี้ไม่ได้แปลว่าวันแบบนี้จะเว้นระยะ 33 ปีพอดี และไม่ใช่การพยากรณ์ตลาดจริง มันบอกแค่ว่าแบบจำลองเชื่ออะไร ครึ่งหลังของหน้าจะตรวจว่าความเชื่อนี้ตรงกับข้อมูลจริงไหม

ขั้นที่ 4 — ย้อนจากโอกาส 1% ไปเป็น VaR 99%

ฝ่ายความเสี่ยงของกองทุนมักถามกลับทิศ แทนที่จะให้เกณฑ์แล้วถามโอกาส เขาให้โอกาสแล้วถามเกณฑ์: “ขาดทุนระดับไหนที่วันปกติจะเกินได้แค่ 1 วันใน 100 วัน” ตัวเลขนี้เรียกว่า VaR 99% หนึ่งวัน (VaR ย่อจาก Value at Risk) และเป็นตัวเลขที่ธนาคารและกองทุนรายงานกันทุกวัน

ขั้นนี้หาผลตอบแทน $r_{0.01}$ ที่มีพื้นที่ทางซ้าย 1% ซึ่งเรียกว่า quantile 1% แล้วแปลงเป็นเงินขาดทุน ขาดทุนรายงานเป็นจำนวนบวก จึงมีเครื่องหมายลบนำหน้า

\[ \begin{aligned} P(R\le r_{0.01})&=0.01\\ \Phi^{-1}(0.01)&\approx-2.3263\\ r_{0.01}&=\mu+\sigma\,\Phi^{-1}(0.01)\\ &=0.0004+0.011\times(-2.3263)\\ &=0.0004-0.02559\\ &\approx-0.02519\\ \text{VaR}_{99\%}&=-\$50{,}000{,}000\times r_{0.01}\\ &\approx\$50{,}000{,}000\times0.02519\\ &\approx\$1{,}259{,}500 \end{aligned} \]

$\Phi^{-1}(0.01)=-2.3263$ คือจุดบน Normal มาตรฐานที่มีพื้นที่ทางซ้าย 1% อ่านจากตารางในทิศกลับ หรือจากโค้ดท้ายหน้า จากนั้นใช้ $X=\mu+\sigma Z$ ของขั้นที่ 1 ในทิศกลับ: quantile ของผลตอบแทนพอร์ตคือ $\mu$ บวก $\sigma$ คูณ quantile ของ $Z$ ที่ทำแบบนี้ได้เพราะการคูณด้วย $\sigma$ ที่เป็นบวกแล้วบวก $\mu$ ไม่เปลี่ยนลำดับของค่า จุดที่มีพื้นที่ทางซ้าย 1% จึงยังเป็นจุดเดียวกัน ถ้าใช้ทศนิยมครบจากโค้ด จะได้ VaR \$1,259,491 หรือราว \$1.26 ล้าน

ความหมายคือ ในวันทั่วไป มีโอกาส 1% ที่พอร์ตจะขาดทุนเกินจำนวนนี้ VaR ไม่ใช่ขาดทุนสูงสุด และไม่ได้บอกว่าในวันที่เกินแล้ว ขาดทุนเฉลี่ยเท่าไร คำถามหลังนี้ตอบด้วย expected shortfall ใน VaR และ expected shortfall

ขั้นที่ 5 — ทำไมหาง Normal บางขนาดนั้น และตัวเลข 10−94

ขั้นที่ 2 ถึง 4 เปิดตารางหรือใช้โค้ดหาค่า $\Phi$ ขั้นนี้มีสองเป้าหมาย เป้าหมายแรก หาค่าประมาณของโอกาสในหางไกลด้วยมือ เป้าหมายที่สอง ดูให้เห็นจากสูตรว่าทำไมหางของ Normal บางขนาดนั้น

ให้ $a\gt0$ คือระยะของเกณฑ์จากค่าเฉลี่ย นับเป็นจำนวนเท่าของ σ โอกาสที่ต้องการคือ $P(Z\lt-a)$ ระฆังสมมาตร โอกาสนี้จึงเท่ากับพื้นที่ทางขวาของ $+a$ เครื่องมือที่ใช้คือ integration by parts กับสมบัติ $\phi'(z)=-z\,\phi(z)$ ซึ่งได้จากการหาอนุพันธ์ของ $e^{-z^2/2}$ ด้วย chain rule

\[ \begin{aligned} P(Z\lt-a)&=\int_a^\infty\phi(z)\,dz\\ &=\int_a^\infty\frac{1}{z}\,\big(z\,\phi(z)\big)\,dz\\ &=\frac{\phi(a)}{a}-\int_a^\infty\frac{\phi(z)}{z^2}\,dz\\ \int_a^\infty\frac{\phi(z)}{z^2}\,dz&\le\frac{1}{a^2}\,P(Z\lt-a)\\ \frac{a\,\phi(a)}{a^2+1}&\le P(Z\lt-a)\le\frac{\phi(a)}{a} \end{aligned} \]

กลเม็ดคือแยก $\phi(z)$ เป็น $1/z$ คูณ $z\,\phi(z)$ เพราะ $z\,\phi(z)$ มี antiderivative ง่าย ๆ คือ $-\phi(z)$ ทำ integration by parts แล้ว พื้นที่หางเท่ากับ $\phi(a)/a$ ลบ integral ตัวหนึ่งที่เป็นบวก ขอบบน $\phi(a)/a$ จึงเกินค่าจริงเสมอ

ขอบล่างมาจากข้อสังเกตว่า ในช่วง $z\ge a$ ค่า $1/z^2$ ไม่เกิน $1/a^2$ integral ที่ลบออกจึงไม่เกิน $P/a^2$ เมื่อ $P$ คือ $P(Z\lt-a)$ แทนกลับเข้าไปจะได้ $P\ge\phi(a)/a-P/a^2$ ย้าย $P/a^2$ ไปรวมทางซ้ายแล้วหารด้วย $1+1/a^2$ ได้ขอบล่าง ยิ่ง $a$ ใหญ่ ตัวคูณ $a^2/(a^2+1)$ ระหว่างสองขอบยิ่งใกล้ 1 สองขอบจึงยิ่งชิดกัน

ลองตรวจกับ $p_4$ ของขั้นที่ 3 ซึ่งมี $a=3.6727$ และค่าจริง 0.000120 ต้องหา $\phi(a)$ ก่อน โดย $3.6727^2/2=6.7444$ และ $3.6727^2+1=14.489$

\[ \begin{aligned} \phi(3.6727)&=\frac{e^{-6.7444}}{\sqrt{2\pi}}\\ &=\frac{0.0011775}{2.5066}\approx0.000470\\ \frac{\phi(a)}{a}&=\frac{0.000470}{3.6727}\approx0.000128\\ \frac{a\,\phi(a)}{a^2+1}&=\frac{3.6727\times0.000470}{14.489}\\ &\approx0.000119 \end{aligned} \]

สองขอบ 0.000119 และ 0.000128 หนีบค่าจริง 0.000120 ไว้แน่น โดยไม่ต้องเปิดตารางเลย

ต่อไปดูว่าทำไมหางบาง เราเทียบความสูงของระฆังที่ระยะ $a+1$ กับที่ระยะ $a$ คือถามว่าขยับออกไปอีก 1σ ความสูงเหลือกี่ส่วน

\[ \begin{aligned} \frac{\phi(a+1)}{\phi(a)}&=e^{-(a+1)^2/2+a^2/2}\\ &=e^{-a-1/2}\\ a=2&:\ e^{-2.5}\approx0.082\approx1/12\\ a=3&:\ e^{-3.5}\approx0.030\approx1/33 \end{aligned} \]

นี่คือหัวใจของคำว่า “หางบาง” ทุกครั้งที่ขยับออกไปอีก 1σ ความสูงของระฆังถูกคูณด้วย $e^{-a-1/2}$ และตัวคูณนี้เล็กลงเรื่อย ๆ เมื่อ $a$ โต ขยับจาก 2σ ไป 3σ ความสูงถูกหารด้วยราว 12 ขยับจาก 3σ ไป 4σ ถูกหารด้วยราว 33 ยิ่งไกลยิ่งหารหนัก

ลองใช้กับเหตุการณ์จริง วันที่ 19 ตุลาคม 1987 ซึ่งเรียกกันว่า Black Monday ดัชนี Dow Jones (ดัชนีของหุ้นใหญ่ 30 ตัวของสหรัฐ) ลดลงราว 22.6% ในวันเดียว ถ้าใช้ $\mu$ และ $\sigma$ ของพอร์ตในหน้านี้ การลดลงนั้นอยู่ห่างค่าเฉลี่ยกี่ σ และมีโอกาสเท่าไร ระยะจากค่าเฉลี่ย +0.04% ลงไปถึง −22.6% คือ 22.64% หรือ 0.2264 เราหารด้วย σ ได้ $a$ แล้วใช้ขอบบน $\phi(a)/a$ เป็นค่าประมาณ ที่ $a$ ใหญ่ขนาดนี้ ขอบบนแทบเท่ากับค่าจริง เพราะตัวคูณ $a^2/(a^2+1)$ ระหว่างสองขอบเกือบเป็น 1

\[ \begin{aligned} a&=\frac{0.226+0.0004}{0.011}\approx20.58\\ \frac{a^2}{2}&=\frac{20.58^2}{2}\approx211.8\\ e^{-211.8}&\approx1.0\times10^{-92}\\ \phi(20.58)&\approx\frac{1.0\times10^{-92}}{2.5066}\approx4.1\times10^{-93}\\ P&\approx\frac{4.1\times10^{-93}}{20.58}\approx2.0\times10^{-94} \end{aligned} \]

ตัวเลขนี้เล็กแค่ไหน ถ้าโอกาสต่อวันคือ $2\times10^{-94}$ ต้องรอเฉลี่ย $1/(2\times10^{-94})=5\times10^{93}$ วันซื้อขาย หรือ $5\times10^{93}/252\approx2\times10^{91}$ ปี จักรวาลมีอายุราว $1.4\times10^{10}$ ปี เวลารอจึงยาวกว่าอายุจักรวาลราว $\dfrac{2\times10^{91}}{1.4\times10^{10}}\approx1.4\times10^{81}$ เท่า

แต่วันนั้นเกิดขึ้นจริง ข้อสรุปจึงไม่ใช่ว่าตลาดทำสิ่งที่เป็นไปไม่ได้ ข้อสรุปคือ Normal ที่ความผันผวนคงที่ใช้บรรยายหางไกลไม่ได้

ขั้นที่ 6 — ที่มาของรูประฆัง: นับลำดับหัวก้อย

ครึ่งแรกใช้ $e^{-z^2/2}$ มาตลอด แต่ยังไม่ได้ตอบว่ารูปนี้มาจากไหน เส้นระฆังไม่ได้ถูกเลือกเพราะสวย มันโผล่ขึ้นมาเองเมื่อเรารวมผลเล็ก ๆ ที่อิสระกันจำนวนมาก ตัวอย่างที่ง่ายที่สุดคือทอยเหรียญยุติธรรม 100 ครั้งแล้วนับจำนวนหัว จำนวนหัวเป็น Binomial distribution ที่มี

  • ค่าเฉลี่ย $100\times0.5=50$
  • variance $100\times0.5\times0.5=25$ จึงมี SD $\sqrt{25}=5$

ให้ $p_n$ คือโอกาสได้หัว $n$ ครั้งพอดี เราจะเทียบความสูงของแท่งที่อยู่ห่างจากแท่งกลาง $k$ แท่ง กับความสูงของแท่งกลาง แล้วดูว่าอัตราส่วนนี้มีหน้าตาอย่างไร

\[ \begin{aligned} p_n&=\binom{100}{n}\Big/2^{100}\\ \frac{p_{50+k}}{p_{50}}&=\frac{50!\,50!}{(50+k)!\,(50-k)!}\\ &=\prod_{j=1}^{k}\frac{51-j}{50+j}\\ \ln\frac{p_{50+k}}{p_{50}}&=\sum_{j=1}^{k}\Big[\ln\!\big(1-\tfrac{j-1}{50}\big)-\ln\!\big(1+\tfrac{j}{50}\big)\Big]\\ &\approx-\frac{1}{50}\sum_{j=1}^{k}(2j-1)=-\frac{k^2}{50}\\ \frac{p_{50+k}}{p_{50}}&\approx e^{-k^2/(2\cdot25)}\\ k=5&:\ 0.6091\ \text{vs}\ e^{-0.5}=0.6065 \end{aligned} \]

ผลคูณมาจากการตัดแฟกทอเรียลที่ซ้ำกันทิ้ง แต่ละพจน์ $\tfrac{51-j}{50+j}$ หารบนล่างด้วย 50 ได้ $\big(1-\tfrac{j-1}{50}\big)\big/\big(1+\tfrac{j}{50}\big)$ แล้วใส่ log ทั้งสองข้าง เพื่อเปลี่ยนผลคูณเป็นผลบวกที่จัดการง่ายกว่า

ขั้นที่ประมาณมีขั้นเดียว คือ $\ln(1+u)\approx u$ เมื่อ $u$ เล็ก ซึ่งใช้ได้เมื่อ $k$ เล็กเมื่อเทียบกับ 50 เช่น $\ln1.1=0.0953$ ใกล้ 0.1 หลังประมาณ แต่ละพจน์เหลือ $-\tfrac{j-1}{50}-\tfrac{j}{50}=-\tfrac{2j-1}{50}$ และผลบวกของเลขคี่ $1+3+\cdots+(2k-1)$ เท่ากับ $k^2$ พอดี (เช่น $1+3+5=9=3^2$) เลขชี้กำลังจึงเป็นระยะห่างยกกำลังสอง

50 ในตัวหารคือ $2\times25$ คือสองเท่าของ variance ถ้านับระยะเป็นจำนวนเท่าของ SD คือ $z=k/5$ จะได้ $k^2/50=z^2/2$ อัตราส่วนจึงเป็น $e^{-z^2/2}$ ซึ่งเป็นรูปของ $\phi$ พอดี ที่ $k=5$ ค่าจริงได้จากการคูณห้าพจน์ $\tfrac{50}{51}\times\tfrac{49}{52}\times\tfrac{48}{53}\times\tfrac{47}{54}\times\tfrac{46}{55}=0.6091$ ต่างจาก $e^{-0.5}=0.6065$ ไม่ถึง 0.5%

ผลตอบแทนรายวันของหุ้นก็เป็นผลรวมของการซื้อขายเล็ก ๆ จำนวนมากในวันนั้น นี่คือเหตุผลที่ Normal เป็นจุดเริ่มต้นที่สมเหตุสมผล เงื่อนไขที่ทำให้ผลรวมเข้าใกล้ Normal จริงจะเรียนใน central limit theorem

ขั้นที่ 7 — พื้นที่รวมเท่ากับหนึ่ง และเลข 3 ของ kurtosis

ขั้นที่ 1 ใช้ $\phi$ โดยยังไม่ได้ตรวจสองเรื่อง เรื่องแรก พื้นที่ใต้ $e^{-z^2/2}$ ต้องเท่ากับ $\sqrt{2\pi}$ พอดี ตัวหาร $\sqrt{2\pi}$ จึงทำให้พื้นที่รวมเป็นหนึ่ง เรื่องที่สอง Normal มี kurtosis เท่ากับ 3 ตัวเลขนี้คือเกณฑ์ที่ขั้นที่ 9 ใช้ตัดสินว่าข้อมูลจริงหางหนาหรือไม่

เรื่องแรกใช้เทคนิคยกกำลังสองแล้วเปลี่ยนเป็นพิกัดเชิงขั้ว (polar coordinates คือบอกตำแหน่งด้วยระยะ $r$ จากจุดกำเนิดและมุม $\theta$) ให้ $I$ คือพื้นที่ที่ต้องการ

\[ \begin{aligned} I&=\int_{-\infty}^{\infty}e^{-z^2/2}\,dz\\ I^2&=\int\!\!\int e^{-(x^2+y^2)/2}\,dx\,dy\\ &=\int_0^{2\pi}\!\!\int_0^\infty e^{-r^2/2}\,r\,dr\,d\theta\\ &=2\pi\times\Big[-e^{-r^2/2}\Big]_0^\infty=2\pi\times1\\ I&=\sqrt{2\pi} \end{aligned} \]

integral ของ $e^{-z^2/2}$ ไม่มี antiderivative ที่เขียนเป็นสูตรได้ กลเม็ดคือคูณ $I$ กับตัวมันเอง โดยเรียกตัวแปรของสองก้อนว่า $x$ และ $y$ ปัญหาหนึ่งมิติจึงกลายเป็นปริมาตรใต้ภูเขาสองมิติที่กลมและสมมาตรรอบจุดกำเนิด เพราะ $x^2+y^2=r^2$ ในพิกัดเชิงขั้ว ชิ้นพื้นที่เล็ก ๆ คือ $r\,dr\,d\theta$ ตัว $r$ ที่เพิ่มเข้ามานี้เองที่ทำให้ integral หาค่าได้ เพราะ $-e^{-r^2/2}$ คือ antiderivative ของ $r\,e^{-r^2/2}$

เรื่องที่สองใช้ MGF (moment generating function) คือ $\mathbb E[e^{tZ}]$ ซึ่งเมื่อกระจายเป็นอนุกรมของ $t$ จะให้ moment $\mathbb E[Z^m]$ ทุกลำดับในคราวเดียว จังหวะสำคัญคือเติมกำลังสองในเลขชี้กำลัง

\[ \begin{aligned} tz-\tfrac{z^2}{2}&=-\tfrac{(z-t)^2}{2}+\tfrac{t^2}{2}\\ \mathbb E[e^{tZ}]&=\int e^{tz}\,\frac{e^{-z^2/2}}{\sqrt{2\pi}}\,dz\\ &=e^{t^2/2}\int\frac{e^{-(z-t)^2/2}}{\sqrt{2\pi}}\,dz=e^{t^2/2}\\ e^{t^2/2}&=1+\frac{t^2}{2}+\frac{t^4}{8}+\cdots\\ \mathbb E[Z^2]&=2!\cdot\tfrac12=1\\ \mathbb E[Z^4]&=4!\cdot\tfrac18=3\\ \text{kurt}&=\frac{\mathbb E[(X-\mu)^4]}{\sigma^4}=\mathbb E[Z^4]=3 \end{aligned} \]

หลังเติมกำลังสอง integral ที่เหลือคือพื้นที่ใต้ Normal ที่ถูกเลื่อนไปที่ $t$ ซึ่งเท่ากับหนึ่ง MGF ของ Normal มาตรฐานจึงเป็นแค่ $e^{t^2/2}$ อนุกรมของ $e^{u}$ คือ $1+u+u^2/2!+\cdots$ แทน $u=t^2/2$ ได้พจน์ $t^4$ เป็น $(t^2/2)^2/2=t^4/8$

ทำไมสัมประสิทธิ์บอก moment เพราะ $e^{tZ}=1+tZ+\tfrac{t^2Z^2}{2!}+\cdots$ เอาค่าเฉลี่ยทั้งสองข้าง สัมประสิทธิ์ของ $t^m$ คือ $\mathbb E[Z^m]/m!$ จึงต้องคูณกลับด้วย $m!$ ได้ variance เท่ากับ 1 และ $\mathbb E[Z^4]=3$ สำหรับ kurtosis เราใช้ $(X-\mu)/\sigma=Z$ จากขั้นที่ 1 เศษส่วนจึงยุบเหลือ $\mathbb E[Z^4]$ Normal ทุกตัวจึงมี kurtosis เท่ากับ 3 ไม่ว่า $\mu$ และ $\sigma$ จะเป็นเท่าไร

ขั้นที่ 8 — สร้าง QQ plot และอ่านจุดซ้ายสุดด้วยมือ

ทุกอย่างก่อนหน้านี้สมมติว่า Normal ถูก ตอนนี้ถึงเวลาตรวจกับข้อมูลจริง ข้อมูลที่ใช้คือผลตอบแทนรายวันของ SPY ตลอดปี 2024 SPY คือกองทุนที่ซื้อขายในตลาดเหมือนหุ้นหนึ่งตัว และวิ่งตามดัชนี S&P 500 ซึ่งรวมหุ้นใหญ่ 500 ตัวของสหรัฐ ตัวเลขที่คำนวณจากข้อมูลจริงมีดังนี้

  • จำนวนวัน $n=252$ คือวันที่ตลาดสหรัฐเปิดในปี 2024
  • ค่าเฉลี่ย $\bar r=0.0863\%$ ต่อวัน
  • SD $s=0.7929\%$ ต่อวัน
  • วันที่แย่ที่สุดของปี $r_{(1)}=-2.98\%$

ทำไมไม่ดู histogram ก็พอ เพราะเราสนใจหาง และแท่งที่หางมีข้อมูลแค่ไม่กี่วัน แท่งจึงสูงต่ำไม่สม่ำเสมอจนอ่านไม่ออก QQ plot แก้ปัญหานี้โดยไม่แบ่งแท่งเลย มันเรียงข้อมูลจากน้อยไปมาก ให้ $r_{(i)}$ คือค่าอันดับที่ $i$ แล้วจับคู่แต่ละตัวกับค่าที่ Normal คาดไว้ที่อันดับเดียวกัน Normal ที่ใช้เทียบมีค่าเฉลี่ยและ SD เท่ากับข้อมูล คือ $\mu=\bar r$ และ $\sigma=s$ ค่าที่ Normal ตัวนี้คาดไว้ที่อันดับ $i$ เขียนว่า $q_i$

\[ \begin{aligned} p_i&=\frac{i-0.5}{n}\\ z_i&=\Phi^{-1}(p_i)\\ \text{plot}&:\ (z_i,\ r_{(i)})\\ \text{line}&:\ r=\mu+\sigma z\\ p_1&=\frac{0.5}{252}\approx0.00198\\ z_1&=\Phi^{-1}(0.00198)\approx-2.881\\ q_1&=0.0863\%+0.7929\%\times(-2.881)\\ &=0.0863\%-2.284\%\approx-2.198\%\\ r_{(1)}-q_1&=-2.980\%-(-2.198\%)\\ &\approx-0.78\% \end{aligned} \]

$p_i$ คือพื้นที่ทางซ้ายที่จุดอันดับ $i$ “ควรจะ” มี ถ้าแบ่งพื้นที่ทั้งหมดเป็น 252 ช่องเท่า ๆ กัน จุดอันดับ $i$ ควรอยู่กลางช่องที่ $i$ จึงลบ 0.5 การลบ 0.5 ยังกันไม่ให้จุดแรกและจุดสุดท้ายไปตกที่พื้นที่ 0 หรือ 1 ซึ่ง $\Phi^{-1}$ เป็นอนันต์ ส่วน $z_i$ คือตำแหน่งบน Normal มาตรฐานที่มีพื้นที่ทางซ้ายเท่ากับ $p_i$

เส้นอ้างอิงตัดแกนตั้งที่ $\mu$ และมีความชัน $\sigma$ ไม่ใช่เส้น 45 องศา เพราะแกนนอนนับเป็นจำนวนเท่าของ SD ส่วนแกนตั้งเป็น % ถ้าข้อมูลเป็น Normal จริง ค่าอันดับ $i$ ควรอยู่ใกล้ $q_i=\mu+\sigma z_i$ ซึ่งเป็นการกลับทิศแบบเดียวกับขั้นที่ 4

ผลคือวันที่แย่ที่สุดของปี (−2.98%) อยู่ต่ำกว่าค่าที่ Normal คาดไว้ที่อันดับนั้น (−2.20%) ราว 0.78 จุดเปอร์เซ็นต์ (จุดเปอร์เซ็นต์คือผลต่างของสองค่าที่เป็น % อยู่แล้ว) แต่จุดเดียวยังตัดสินไม่ได้ เพราะจุดปลายสุดแกว่งมากตามธรรมชาติ ต้องดูทั้งแนว ซึ่งรูปด้านล่างและขั้นที่ 9 ทำต่อ

ขั้นที่ 9 — อ่านรูปทรงของ QQ และวัดหางด้วย kurtosis

จุดห้าจุดพอให้เห็นทิศ แต่ต้องรู้ว่ารูปทรงแบบไหนแปลว่าอะไร รูปแบบที่ควรจำคือ ถ้าข้อมูลหางหนากว่า Normal จุดใน QQ plot จะเรียงเป็นรูปตัว S: ปลายซ้ายจมใต้เส้น ปลายขวาลอยเหนือเส้น และตรงกลางแบนกว่าเส้นเล็กน้อย (ดูรูปแรกด้านล่าง)

เพื่อยืนยันด้วยตัวเลข เราคำนวณ kurtosis จากข้อมูลแล้วเทียบกับ 3 ของ Normal จากขั้นที่ 7 ในข้อมูลเราไม่รู้ $\mu$ และ $\sigma$ ที่แท้จริง จึงใช้ moment ตัวอย่าง $m_k$ แทน $m_k$ คือค่าเฉลี่ยของระยะห่างจากค่าเฉลี่ยตัวอย่าง $\bar r$ ยกกำลัง $k$ อีกตัวเลขที่ใช้ตรวจคือนับวันที่ผลตอบแทนต่ำกว่า $\bar r-2s$ แล้วเทียบกับจำนวนที่ Normal คาดไว้

\[ \begin{aligned} m_k&=\frac1n\sum_{i=1}^{n}(r_i-\bar r)^k\\ \widehat{\text{kurt}}&=\frac{m_4}{m_2^2}\\ \text{SPY 2024}&:\ m_2=0.62612,\ m_4=1.8417\\ \widehat{\text{kurt}}&=\frac{1.8417}{0.62612^2}=\frac{1.8417}{0.39203}\\ &\approx4.70\\ \bar r-2s&=0.0863\%-2\times0.7929\%\\ &\approx-1.50\%\\ 252\,\Phi(-2)&=252\times0.02275\approx5.7 \end{aligned} \]

$m_2$ และ $m_4$ คำนวณจากข้อมูลจริงทั้ง 252 วันในหน่วยเปอร์เซ็นต์ $m_2$ มีหน่วย %² และ $m_4$ มีหน่วย %⁴ อัตราส่วน $m_4/m_2^2$ จึงไม่มีหน่วย ตรวจความสอดคล้องได้ด้วย $\sqrt{m_2}=\sqrt{0.62612}=0.7913\%$ ซึ่งใกล้ SD 0.7929% ที่ต่างกันนิดหน่อยเพราะ SD หารด้วย $n-1=251$ แทน $n$

ปี 2024 เป็นปีที่ตลาดค่อนข้างสงบ แต่ยังได้ kurtosis 4.70 ซึ่งมากกว่า 3 พอนับจากข้อมูล วันที่ผลตอบแทนต่ำกว่า −1.50% มี 9 วัน ทั้งที่ Normal คาดไว้ราว 5.7 วัน ($\Phi(-2)=0.02275$ คือโอกาสที่ Normal จะต่ำกว่าค่าเฉลี่ยเกิน 2 SD)

ข้อมูลระยะยาวชัดกว่านี้มาก ตาราง 2.1 ในหนังสือ The Elements of Quantitative Investing ของ Giuseppe Paleologo วัด kurtosis ของผลตอบแทนรายวันช่วงปี 2001–2017 ของหุ้นและกองทุนห้าตัว ได้ระหว่าง 5.7 ถึง 29.8 (รูปที่สองด้านล่าง) แม้ขอบล่างของช่วงความเชื่อมั่น 99% ก็ยังเกิน 3 ทุกตัว ช่วงความเชื่อมั่นคือช่วงที่ค่าจริงน่าจะอยู่ เมื่อคิดเผื่อว่าข้อมูลมีจำกัด

ข้อควรระวังคือ kurtosis ไวต่อค่าสุดโต่งมาก เพราะยกกำลังสี่ วันเดียวที่ราคาขยับแรงเปลี่ยนตัวเลขนี้ได้มาก จึงต้องใช้คู่กับ QQ plot ไม่ใช่ใช้แทนกัน

ข้อมูลจริงยังบอกอีกสองเรื่อง เรื่องแรก ผลตอบแทนรายสัปดาห์หรือรายเดือนมีหางใกล้ Normal มากกว่ารายวัน เพราะแต่ละตัวเป็นผลรวมของหลายวัน เรื่องที่สอง หางหนาส่วนหนึ่งมาจากความผันผวนที่เปลี่ยนไปตามเวลา ช่วงตลาดปั่นป่วนกับช่วงตลาดสงบปนกันอยู่ในข้อมูลชุดเดียว พอรวมกันจึงได้หางหนา แบบจำลองที่จับเรื่องนี้คือ ARCH และ GARCH

ความผิดพลาดที่ให้คำตอบผิดแบบเงียบ ๆ

ใส่ σ ในช่องของ variance: สัญลักษณ์ $N(\mu,\sigma^2)$ ใส่ variance ไว้ในช่องที่สอง ไม่ใช่ σ เช่นพอร์ตในหน้านี้คือ $N(0.0004,\ 0.011^2)$ ช่องที่สองคือ $0.011^2=0.000121$ ถ้าเห็น $N(0,4)$ ต้องได้ $\sigma=\sqrt4=2$ ถ้าเผลอใช้ $\sigma=4$ ทุกโอกาสจะผิด เช่น $P(X\lt-4)$ ผิด: $\Phi(-4/4)=\Phi(-1)=15.9\%$ ถูก: $\Phi(-4/2)=\Phi(-2)=2.28\%$

ลืมลบค่าเฉลี่ย: เกณฑ์ −2% ต้องลบค่าเฉลี่ยก่อนหารด้วย σ ผิด: $\Phi(-0.02/0.011)=\Phi(-1.82)=3.45\%$ ถูก: $\Phi(-0.0204/0.011)=\Phi(-1.85)=3.18\%$ ค่าที่ผิดสูงเกินไป $3.45/3.18\approx1.08$ เท่า คือผิดราว 8% และจะผิดมากขึ้นเมื่อค่าเฉลี่ยใหญ่ขึ้น เช่นในผลตอบแทนรายปี

ใช้ 68% เป็นโอกาสข้างเดียว: ช่วง ±1σ มีพื้นที่ 68.3% รวมสองข้าง โอกาสที่จะต่ำกว่า $\mu-\sigma$ ข้างเดียวคือ $(1-0.683)/2\approx15.9\%$ ไม่ใช่ $1-0.68=32\%$

คิดว่า VaR จาก Normal ต่ำกว่าความจริงทุกระดับ: หางหนาไม่ได้แปลว่าโอกาสสูงกว่า Normal ทุกเกณฑ์ ลองเทียบ Normal มาตรฐานกับ Student-t สามองศาที่ปรับ variance ให้เท่ากับ 1 (ตัวเดียวกับรูปตัว S ในขั้นที่ 9) ค่าของ Student-t คำนวณจาก CDF ของมันด้วยคอมพิวเตอร์ ที่เกณฑ์ 1.85σ Student-t ให้ 2.44% ซึ่งต่ำกว่า Normal ที่ให้ $\Phi(-1.85)=3.18\%$ แต่ที่เกณฑ์ 4σ Student-t ให้ 0.308% ขณะที่ Normal ให้ $\Phi(-4)=0.00317\%$ ต่างกัน $0.00308/0.0000317\approx97$ เท่า CDF ของสอง distribution ตัดกัน หางหนาจึงเพิ่มความเสี่ยงเฉพาะที่หางไกล ส่วนช่วงกลาง ๆ อาจน้อยกว่า Normal ด้วยซ้ำ

คำนวณ $1-\Phi(a)$ ด้วยคอมพิวเตอร์เมื่อ $a$ ใหญ่: คอมพิวเตอร์เก็บเลขทศนิยมแบบ floating point (double) ได้ราว 16 หลัก ที่ $a=20.58$ ค่าจริงคือ $\Phi(a)=1-2\times10^{-94}$ ซึ่งต่างจาก 1 ที่หลักที่ 94 คอมพิวเตอร์จึงเก็บเป็น 1.0 พอดี ผลลบออกมาเป็น $1-1=0$ ทั้งที่ค่าจริงคือ $2\times10^{-94}$ ให้คำนวณ $\Phi(-a)$ โดยตรง หรือใช้ค่าประมาณ $\phi(a)/a$ จากขั้นที่ 5 แทน

ใช้ทำอะไรบนโต๊ะจริง

Normal คือภาษากลางของงานความเสี่ยง เครื่องมือหลายตัวบนโต๊ะเทรดเริ่มจาก $\Phi$ ทั้งนั้น

  • VaR แบบ parametric คือ VaR ที่คำนวณจาก $\mu$ และ $\sigma$ ด้วยสูตรแบบขั้นที่ 4
  • ช่วงความเชื่อมั่นของค่าประมาณ เช่นช่วงที่น่าจะครอบค่าเฉลี่ยจริงของผลตอบแทน
  • z-score ของสัญญาณเทรด คือวัดว่าตัวเลขวันนี้ห่างจากระดับปกติกี่ SD
  • ราคาของ option (สัญญาที่ให้สิทธิ์ซื้อหรือขายในราคาที่ตกลงไว้ล่วงหน้า) ใน สูตร Black–Scholes

งานที่ต้องทำคู่กันเสมอคือตรวจหาง วาด QQ plot ของผลตอบแทน นับวันที่ขาดทุนเกิน VaR แล้วเทียบกับจำนวนที่ Normal คาดไว้ (วิธีตรวจแบบเป็นระบบอยู่ใน VaR backtesting) และทำ stress test คือลองคำนวณว่าพอร์ตจะเสียเท่าไรถ้าเหตุการณ์แบบ Black Monday เกิดซ้ำ ทั้งที่แบบจำลองบอกว่าเกิดไม่ได้

(ค) แปลงเงินเป็นเปอร์เซ็นต์ของพอร์ตใหม่ก่อน: $\$1{,}000{,}000/\$25{,}000{,}000=0.04=4\%$ (บนพอร์ตเดิม \$1 ล้านคือแค่ 2%) โอกาสจึงเป็น $p_4\approx0.012\%$ จากขั้นที่ 3 ไม่ใช่ 3.18% บทเรียนคือต้องแปลงเกณฑ์ที่เป็นเงินให้เป็นเปอร์เซ็นต์ของพอร์ตทุกครั้ง

2. ทีมความเสี่ยงอยากได้ช่วงผลตอบแทนรายวันที่สมมาตรรอบค่าเฉลี่ย และครอบวันทั้งหมดไว้ 95% เพื่อใช้แยกวันปกติออกจากวันผิดปกติ ใช้พอร์ตเดิม ($\mu=0.04\%$, $\sigma=1.10\%$) ช่วงนี้เริ่มและจบที่เท่าไร

เฉลย

ช่วง $\mu\pm k\sigma$ มีพื้นที่ $2\Phi(k)-1$ ตามขั้นที่ 1 จึงตั้งให้เท่ากับ 0.95 แล้วแก้หา $k$

\[\begin{aligned}2\Phi(k)-1&=0.95\\\Phi(k)&=\frac{1+0.95}{2}=0.975\\k&=\Phi^{-1}(0.975)\approx1.96\\k\sigma&=1.96\times1.10\%=2.156\%\\\mu-k\sigma&=0.04\%-2.156\%=-2.116\%\\\mu+k\sigma&=0.04\%+2.156\%=2.196\%\end{aligned}\]

ช่วงคือ −2.116% ถึง +2.196% ตรวจ: หางแต่ละข้างเหลือ $(1-0.95)/2=2.5\%$ รวมสองข้างเป็น 5%

3. เกมทอยเหรียญยุติธรรม 100 ครั้ง ถามว่าโอกาสได้หัวตั้งแต่ 60 ครั้งขึ้นไปเป็นเท่าไร ให้ใช้ Normal ประมาณ แล้วเทียบกับค่าจริง 2.844% (ค่าจริงได้จากการบวกโอกาส Binomial ของ 60, 61, …, 100 หัวด้วยคอมพิวเตอร์)

เฉลย

จำนวนหัวมีค่าเฉลี่ย $100\times0.5=50$ และ SD $\sqrt{100\times0.5\times0.5}=5$ จำนวนหัวเป็นจำนวนเต็ม แต่ Normal เป็นเส้นต่อเนื่อง ถ้ามองแต่ละค่าเป็นแท่งกว้าง 1 หน่วย แท่งของ 60 กินพื้นที่จาก 59.5 ถึง 60.5 เราจึงเริ่มนับที่ 59.5 วิธีนี้เรียกว่า continuity correction

\[\begin{aligned}1-\Phi\!\left(\frac{59.5-50}{5}\right)&=1-\Phi(1.9)\\&=1-0.97128\approx2.872\%\end{aligned}\]

ได้ใกล้ค่าจริง 2.844% มาก ถ้าเริ่มที่ 60 ตรง ๆ จะได้ $1-\Phi(2)=1-0.97725\approx2.275\%$ ต่ำไป $(2.844-2.275)/2.844\approx20\%$ เพราะตัดครึ่งแท่งของ 60 ทิ้ง

const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
function Phi(z) {                         // Simpson integration, fine for |z| < 8
  const n = 10000, h = Math.abs(z) / n;
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(z) * h * s / 3;
}
function quantile(p) {                    // invert Phi by bisection
  let lo = -8, hi = 8;
  for (let i = 0; i < 70; i++) { const m = (lo + hi) / 2; if (Phi(m) < p) lo = m; else hi = m; }
  return (lo + hi) / 2;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ทุก Normal คือ $\mu+\sigma Z$ จึงตอบทุกคำถามได้ด้วย $\Phi\big((x-\mu)/\sigma\big)$ และช่วง ±1σ, ±2σ, ±3σ มีพื้นที่ 68.3%, 95.4%, 99.7% นับรวมสองข้าง
  • พอร์ต \$50 ล้านในตัวอย่างมีโอกาสขาดทุนเกิน 2% ราว 3.18% ต่อวัน (8 วันต่อปี) แต่โอกาสขาดทุนเกิน 4% มีแค่ 0.012% ต่อวัน หายากกว่า 265 เท่า ไม่ใช่ 2 เท่า เพราะหางลดตาม $e^{-z^2/2}$
  • VaR 99% หนึ่งวันคือ $-\big(\mu+\sigma\Phi^{-1}(0.01)\big)$ คูณมูลค่าพอร์ต ได้ราว \$1.26 ล้าน VaR เป็นขอบของหาง ไม่ใช่ขาดทุนสูงสุด
  • Normal มี kurtosis เท่ากับ 3 พิสูจน์ได้จาก MGF $e^{t^2/2}$ ข้อมูลรายวันจริงให้ตั้งแต่ 4.7 (SPY ปี 2024) ถึง 29.8 (WAT ปี 2001–2017)
  • QQ plot ของข้อมูลหางหนาเป็นรูปตัว S: ปลายซ้ายจมใต้เส้น ปลายขวาลอยเหนือเส้น

Normal ใช้กับผลตอบแทนได้ แต่ใช้กับราคาโดยตรงไม่ได้ เพราะราคาติดลบไม่ได้ และผลตอบแทนหลายช่วงทบต้นกันด้วยการคูณ ไม่ใช่การบวก หน้าถัดไป Lognormal distribution แก้เรื่องนี้โดยให้ log ของราคาเป็น Normal แทน
