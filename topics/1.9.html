1.9 The Normal (Gaussian) Distribution and Quantile-Quantile (QQ) Diagnostics

ใช้รูประฆังคำนวณความเสี่ยง แล้วตรวจว่าหางของข้อมูลเข้ากับมันหรือไม่

ถ้าการขาดทุนเกิน 2% เกิดได้ประมาณแปดวันต่อปี การขาดทุนเกิน 4% ควรเกิดประมาณสี่วันต่อปีหรือไม่?

เปิดคำตอบของแบบจำลองที่จะใช้

ไม่ใช่ ภายใต้ Normal ตัวอย่างนี้ โอกาสขาดทุนเกิน 4% ต่ำกว่าขาดทุนเกิน 2% ประมาณ 265 เท่า ไม่ใช่สองเท่า หางของ distribution มีผลอย่างมากต่อคำตอบ จึงต้องตรวจหาง ไม่ใช่เลือกเส้นที่ดูเหมือนข้อมูลตรงกลางอย่างเดียว

ครึ่งแรกของบทจะคำนวณความเสี่ยงและอ่าน QQ plot ส่วนท้ายพิสูจน์ที่มาของเส้นระฆังและ moment ต่าง ๆ ผู้อ่านที่ยังไม่คล่อง calculus สามารถทำโจทย์หลักก่อนแล้วกลับมาอ่านส่วนพิสูจน์ได้

Normal บอกอะไร และไม่ได้บอกอะไร

Normal หรือ Gaussian เป็น distribution ต่อเนื่องที่สมมาตรรอบค่าเฉลี่ย $\mu$ และกำหนดความกว้างด้วย standard deviation $\sigma\gt0$ เขียน $X\sim N(\mu,\sigma^2)$ พารามิเตอร์ตัวที่สองในสัญลักษณ์นี้คือ variance ไม่ใช่ standard deviation

เส้นมีหางไปได้ทั้งสองด้านโดยไม่มีขอบจำกัด ค่าเฉลี่ยและ standard deviation จึงไม่กำหนดขาดทุนสูงสุด อีกทั้งการรู้สองค่านี้จากข้อมูลยังไม่ได้พิสูจน์ว่า distribution เป็น Normal

ขั้นที่ 1 — ใช้เส้นมาตรฐานเดียวผ่านการเปลี่ยนหน่วย

นิยาม Standard Normal ด้วย PDF $\phi$ และ CDF $\Phi$ แล้วเลื่อนและยืดแกนเพื่อสร้าง Normal ทั่วไป ส่วนพิสูจน์ท้ายบทจะตรวจพื้นที่รวมและ moment ของเส้นนี้

\[ \begin{aligned} \phi(z)&\equiv\frac1{\sqrt{2\pi}}e^{-z^2/2}\\ \Phi(z)&\equiv\int_{-\infty}^{z}\phi(u)\,du\\ X&=\mu+\sigma Z,\quad Z\sim N(0,1)\\ z&=\frac{x-\mu}{\sigma}\\ f_X(x)&=\frac1\sigma\phi\left(\frac{x-\mu}{\sigma}\right)\\ F_X(x)&=\Phi\left(\frac{x-\mu}{\sigma}\right) \end{aligned} \]

z-score วัดว่าค่าที่ถามห่างจากค่าเฉลี่ยกี่ standard deviation สูตร z-score ใช้กับตัวแปรอื่นได้ด้วย แต่การนำไปอ่าน probability จาก $\Phi$ ต้องสมมติ Normal เพิ่ม ห้ามถือว่าการ standardize ทำให้ทุก distribution กลายเป็น Normal

อ่านตาราง Standard Normal ให้ตรงด้านของหาง

ค่าขอบ $z$พื้นที่ซ้าย $\Phi(z)$ความหมาย
−1.6448540.05เกณฑ์หางซ้าย 5%
−1.9599640.025เกณฑ์หางซ้าย 2.5%
−2.3263480.01เกณฑ์หางซ้าย 1%
−3.0902320.001เกณฑ์หางซ้าย 0.1%

พื้นที่หางขวาที่ $z$ คือ $1-\Phi(z)$ และความสมมาตรให้ $\Phi(-z)=1-\Phi(z)$ เช่นขอบบวก 1.959964 มีพื้นที่ขวา 2.5% เมื่อรวมสองหางจึงเป็น 5% ไม่ใช่ 2.5%

ขั้นที่ 2 — กฎ 68–95–99.7% เป็นพื้นที่รอบค่าเฉลี่ย

\[ \begin{aligned} P(\mu-k\sigma\le X\le\mu+k\sigma) &=\Phi(k)-\Phi(-k)\\ &=2\Phi(k)-1\\ k=1&:\quad68.2689\%\\ k=2&:\quad95.4500\%\\ k=3&:\quad99.7300\% \end{aligned} \]

68% เป็นพื้นที่รวมสองข้างรอบค่าเฉลี่ย ไม่ใช่โอกาสในแต่ละข้าง และไม่ใช่โอกาสกำไร ถ้า $\mu$ ไม่เป็นศูนย์ ช่วงนี้ก็ไม่ได้มีศูนย์เป็นจุดกลาง ข้อสรุปใช้กับ Normal ไม่ใช่ทุก distribution ที่มี standard deviation

Worked Example — พอร์ต \$50 ล้านภายใต้ Normal สมมติ

โจทย์ให้อะไรมาบ้าง: มูลค่าพอร์ตต้นวัน \$50 ล้าน ผลตอบแทนรายวัน $R\sim N(0.0004,0.011^2)$ หรือค่าเฉลี่ย 0.04% และ standard deviation 1.10% ใช้ 252 วันซื้อขายต่อปี และคิด P&L เป็นมูลค่าต้นวันคูณผลตอบแทน

ตัวเลขเป็นสมมติฐานเพื่อฝึกคำนวณ ไม่ใช่ผลประมาณของพอร์ตจริง เราจะถามสามข้อ: โอกาสขาดทุนเกิน 2%, โอกาสขาดทุนเกิน 4%, และเกณฑ์ขาดทุนหนึ่งวันที่มีโอกาสเกินเพียง 1% ตามแบบจำลอง

ค่าเฉลี่ย P&L คือ \$20,000 ส่วน standard deviation คือ \$550,000 ช่วงหนึ่ง standard deviation รอบค่าเฉลี่ยจึงเป็น −\$530,000 ถึง +\$570,000 ไม่ใช่ ±\$550,000 รอบศูนย์

ขั้นที่ 3 — โอกาสขาดทุนเกิน 2% และจำนวนวันที่คาดหมาย

\[ \begin{aligned} z_2&=\frac{-0.02-0.0004}{0.011}\approx-1.854545\\ p_2&=P(R\lt-0.02)=\Phi(z_2)\\ &\approx0.0318306=3.18306\%\\ \mathbb E[\text{number of days}]&=252p_2\\ &\approx\boxed{8.02\text{ days}} \end{aligned} \]

ขั้นแรกต้องลบค่าเฉลี่ยด้วย ไม่ใช่ใช้ −2% หาร 1.10% ตรง ๆ จำนวน 8.02 เป็นค่าเฉลี่ยของจำนวนวันในแบบจำลอง ไม่ใช่คำรับรองว่าทุกปีต้องมีแปดวัน การหาค่าเฉลี่ยนี้ไม่ต้องใช้ independence หากทุกวันมีโอกาส $p_2$ ตามที่กำหนด

ขั้นที่ 4 — ขยับเกณฑ์เป็น 4% แล้วเปรียบเทียบ

\[ \begin{aligned} z_4&=\frac{-0.04-0.0004}{0.011}\approx-3.672727\\ p_4&=\Phi(z_4)\approx0.000119988\\ &\approx0.0119988\%\\ 252p_4&\approx0.03024\text{ days}\\ \frac{p_2}{p_4}&\approx\boxed{265.28} \end{aligned} \]

ความเสียหายที่เป็นเกณฑ์เพิ่มเป็นสองเท่า แต่โอกาสลดลงประมาณ 265 เท่า เพราะหาง Normal ลดลงเร็วมาก ผลนี้อธิบายความไวของ risk report ต่อการเลือก distribution ไม่ใช่กฎของตลาดทุกแบบ

ถ้าสมมติเพิ่มว่าแต่ละวันเป็นอิสระและ $p_4$ คงที่ เวลารอเฉลี่ยจะเป็น $1/p_4$ วันซื้อขาย หรือประมาณ 33.07 ปีเมื่อหาร 252 ไม่ใช่เหตุการณ์ที่จะเว้นระยะ 33 ปีพอดี และไม่ใช่พยากรณ์ความถี่วิกฤติจริง

ขั้นที่ 5 — ย้อนจากโอกาส 1% ไปสู่เกณฑ์ VaR 99%

หา return quantile $r_{0.01}$ ก่อน แล้วเปลี่ยนเป็นจำนวนเงินขาดทุนบวกบนพอร์ตคงที่ \$50 ล้าน อย่าสับสน return quantile ที่ติดลบกับ loss VaR ที่รายงานเป็นบวก

\[ \begin{aligned} P(R\le r_{0.01})&=0.01\\ \frac{r_{0.01}-\mu}{\sigma}&=\Phi^{-1}(0.01)\approx-2.326348\\ r_{0.01}&=\mu+\sigma\Phi^{-1}(0.01)\\ &\approx0.0004+0.011(-2.326348)\\ &\approx-0.02518983=-2.518983\%\\ \mathrm{VaR}_{99\%}&=-\$50{,}000{,}000\,r_{0.01}\\ &\approx\boxed{\$1{,}259{,}491} \end{aligned} \]

ตาม Normal นี้ มีโอกาสประมาณ 1% ที่ขาดทุนเกินระดับดังกล่าวในหนึ่งวัน VaR ไม่บอกว่าขาดทุนใน 1% ที่เหลือเฉลี่ยเท่าไร และไม่ใช่ขาดทุนสูงสุด เรื่องความรุนแรงเฉลี่ยในหางเป็นคำถามของ Expected Shortfall ซึ่งจะเรียนต่อภายหลัง

คำนวณแล้วต้องตรวจรูปทรง: QQ plot ทำหน้าที่อะไร

Histogram เปลี่ยนหน้าตาตามการเลือกช่วง จึงอาจซ่อนความต่างในหาง QQ plot เปรียบเทียบ quantile ของข้อมูลกับ quantile ของแบบจำลองที่อันดับเดียวกัน เพื่อดูว่าความคลาดเคลื่อนอยู่ตรงกลางหรือปลายหาง

วิธีสร้างคือเรียงข้อมูลจากน้อยไปมาก ให้ $r_{(i)}$ เป็นค่าลำดับที่ $i$ เลือก plotting position $p_i=(i-0.5)/n$ แล้วหา $z_i=\Phi^{-1}(p_i)$ คู่อันดับที่นำไปวาดในภาพนี้คือ $(z_i,r_{(i)})$

หากข้อมูลเข้ากับ Normal จุดควรใกล้เส้นอ้างอิง $r=\mu+\sigma z$ ภายใต้ความผันผวนของตัวอย่าง เส้นจึงมีจุดตัด $\mu$ และความชัน $\sigma$ ไม่จำเป็นต้องเป็นเส้น 45 องศา เพราะสองแกนใช้คนละหน่วย

ข้อมูลที่ใช้ในกราฟ SPY 2024 ของบทนี้

รายการค่าที่คำนวณจาก 252 ผลตอบแทนประกอบกราฟ
จำนวนข้อมูล $n$252 วัน
ค่าเฉลี่ย0.086302% ต่อวัน
Sample standard deviation ใช้ตัวหาร $n-1$0.792855% ต่อวัน
ผลตอบแทนต่ำสุด−2.980349%
จำนวนวันต่ำกว่าค่าเฉลี่ยลบสอง sample SD9 วัน

นี่เป็นคนละชุดพารามิเตอร์กับพอร์ตสมมติ \$50 ล้านข้างต้น ตัวเลขคำนวณจากข้อมูลที่ฝังในแหล่งข้อมูลประกอบ Figure 1.9e การตรวจเลขชุดนี้ไม่เท่ากับการตรวจแหล่งราคาหรือการปรับ corporate actions ใหม่ทั้งหมด

ขั้นที่ 6 — สร้างจุดซ้ายสุดของ QQ plot ด้วยมือ

\[ \begin{aligned} p_1&=\frac{1-0.5}{252}=\frac{0.5}{252}\approx0.00198413\\ z_1&=\Phi^{-1}(p_1)\approx-2.880674\\ q_1&=0.086302\%+0.792855\%(-2.880674)\\ &\approx-2.197654\%\\ r_{(1)}&=-2.980349\%\\ r_{(1)}-q_1&\approx-0.782694\text{ percentage points} \end{aligned} \]

จุดแรกจึงอยู่ใต้เส้นอ้างอิงประมาณ 0.783 จุดเปอร์เซ็นต์ แต่ $q_1$ เป็น theoretical quantile ตาม plotting position ที่เลือก ไม่ใช่ขอบล่างที่ Normal อนุญาต และไม่ใช่ expected minimum แบบตรงของตัวอย่าง 252 วัน

ใช้ kurtosis เสริม แต่ไม่ให้ตัวเลขเดียวตัดสินทุกอย่าง

สำหรับ distribution ที่มี moment ลำดับสี่ นิยาม kurtosis เป็น $\mathbb E[(X-\mu)^4]/\sigma^4$ Normal มีค่า 3 ส่วน excess kurtosis คือค่านี้ลบ 3 หากข้อมูลมี extreme observations ค่าเฉลี่ยกำลังสี่จะไวต่อข้อมูลเหล่านั้นมาก

สำหรับข้อมูลตัวอย่าง นิยาม $m_k=n^{-1}\sum_i(r_i-\bar r)^k$ แล้วใช้ $m_4/m_2^2$ ชุด SPY ในกราฟให้ $m_2\approx0.626124$ และ $m_4\approx1.841660$ ในหน่วยเปอร์เซ็นต์ยกกำลังที่สอดคล้องกัน จึงได้ kurtosis ประมาณ 4.6977 หรือ 4.70

นี่เป็น moment estimator ที่ระบุไว้ ไม่ใช่สูตรปรับ bias ทุกแบบ ค่าเกิน 3 และหาง QQ ที่เบนเป็นสัญญาณให้ตรวจต่อ แต่ไม่พิสูจน์ว่าโอกาสขาดทุนเกินทุกเกณฑ์สูงกว่า Normal เสมอ หรือระบุ distribution ทางเลือกได้เพียงชนิดเดียว

อีกการเปรียบเทียบคือ Normal ให้วันต่ำกว่า $\mu-2\sigma$ เฉลี่ย $252\Phi(-2)\approx5.73$ วัน ข้อมูลนี้นับได้ 9 วัน ความต่างไม่ใช่การทดสอบนัยสำคัญด้วยตัวเอง โดยเฉพาะเมื่อประมาณค่าเฉลี่ยและ SD จากข้อมูลเดียวกัน และวันต่าง ๆ อาจสัมพันธ์กัน

ส่วนพิสูจน์: ทำไมการนับจึงพาไปถึงรูประฆัง

ทอยเหรียญยุติธรรมอย่างเป็นอิสระ 100 ครั้ง จำนวนหัวมี Binomial(100, 0.5) ค่าเฉลี่ย 50 และ variance 25 การได้จำนวนใกล้ 50 เกิดจากลำดับหัวก้อยได้หลายแบบ ส่วนค่าที่ไกลจากกลางเกิดจากลำดับได้น้อยกว่า

CLT อธิบายการเข้าหา Normal ของผลรวมที่นำมาปรับหน่วย ภายใต้เงื่อนไข เช่นตัวแปรอิสระที่มี distribution เดียวกันและ variance จำกัดเป็นบวก ไม่ได้บอกว่าข้อมูลดิบทุกตัวเป็น Normal หรือผลรวมขนาดจำกัดมีหางตรงกับ Normal ทุกระดับ

ขั้นที่ 7 — ดูว่าแท่ง Binomial ลดลงรอบกลางอย่างไร

ให้ $p_k=P(H=50+k)$ เปรียบเทียบกับแท่งกลาง $p_0$ แล้วใช้ $\ln(1+u)\approx u$ สำหรับ $u$ เล็ก การประมาณนี้ใช้กับ $k$ เล็กเมื่อเทียบกับ 50 ไม่ใช่ค่าปลายทุกค่าของ Binomial

\[ \begin{aligned} \frac{p_k}{p_0}&=\frac{50!50!}{(50+k)!(50-k)!}\\ &=\prod_{j=1}^{k}\frac{51-j}{50+j}\\ \ln\frac{p_k}{p_0}&=\sum_{j=1}^{k}\ln\left(1-\frac{j-1}{50}\right)\\ &\quad-\sum_{j=1}^{k}\ln\left(1+\frac j{50}\right)\\ &\approx-\frac1{50}\sum_{j=1}^{k}(2j-1)=-\frac{k^2}{50}\\ \frac{p_k}{p_0}&\approx e^{-k^2/(2\cdot25)}\\ k=5&:\quad0.609056\text{ (Binomial)},\quad e^{-0.5}\approx0.606531 \end{aligned} \]

ผลรวมจำนวนคี่ $1+3+\cdots+(2k-1)$ เท่ากับ $k^2$ จึงเกิดเลขชี้กำลังเป็นระยะห่างยกกำลังสอง เมื่อหารระยะห่างด้วย standard deviation 5 จะได้รูปร่าง $e^{-z^2/2}$ นี่ยังเป็นคำอธิบายผ่านการประมาณ ไม่ใช่หลักฐานว่าทั้งสอง distribution เท่ากันพอดี

ขั้นที่ 8 — ปรับพื้นที่ของเส้นให้เท่ากับหนึ่ง

ส่วนนี้ใช้ double integral และพิกัดเชิงขั้ว ให้ $I$ เป็นพื้นที่ใต้ $e^{-z^2/2}$ ยกกำลังสองเพื่อรวมพื้นที่สองแกน แล้วเปลี่ยนเป็นรัศมี $r$ และมุม $\theta$ ซึ่งมีส่วนพื้นที่ $r\,dr\,d\theta$

\[ \begin{aligned} I&\equiv\int_{-\infty}^{\infty}e^{-z^2/2}\,dz\\ I^2&=\iint_{\mathbb R^2}e^{-(x^2+y^2)/2}\,dx\,dy\\ &=\int_0^{2\pi}\int_0^\infty e^{-r^2/2}r\,dr\,d\theta\\ &=2\pi[-e^{-r^2/2}]_0^\infty=2\pi\\ I&=\sqrt{2\pi}\\ \int_{-\infty}^{\infty}\frac{e^{-z^2/2}}{\sqrt{2\pi}}\,dz&=1 \end{aligned} \]

$I$ เป็นบวกจึงเลือกรากบวก นี่คือเหตุผลของตัวหาร $\sqrt{2\pi}$ ใน Standard Normal ส่วนตัวหาร $\sigma$ ของ Normal ทั่วไปมาจากการยืดความกว้างของแกนโดยรักษาพื้นที่ไว้ ตามที่ทำในหัวข้อ 1.8

ขั้นที่ 9 — สร้าง MGF แล้วหา moment โดยเทียบสัมประสิทธิ์

ใช้ $Z\sim N(0,1)$ และนิยาม $M_Z(t)=\mathbb E[e^{tZ}]$ เติมกำลังสองในเลขชี้กำลังแล้วแยกส่วนที่ไม่ขึ้นกับ $z$ ออก

\[ \begin{aligned} tz-\frac{z^2}{2}&=-\frac{(z-t)^2}{2}+\frac{t^2}{2}\\ M_Z(t)&=e^{t^2/2}\int_{-\infty}^{\infty}\frac{e^{-(z-t)^2/2}}{\sqrt{2\pi}}\,dz\\ &=e^{t^2/2}\\ &=\sum_{k=0}^{\infty}\frac{t^{2k}}{2^kk!}\\ M_Z(t)&=\sum_{m=0}^{\infty}\frac{\mathbb E[Z^m]}{m!}t^m\\[3pt] \mathbb E[Z^{2k+1}]&=0\\ \mathbb E[Z^{2k}]&=\frac{(2k)!}{2^kk!}=(2k-1)!! \end{aligned} \]

Integral ที่เหลือเป็นเส้น Normal ที่เลื่อนไป จึงยังมีพื้นที่หนึ่ง อนุกรมมีเฉพาะกำลังคู่ ดังนั้น moment คี่เป็นศูนย์ ส่วน $!!$ หมายถึงคูณจำนวนคี่ลดทีละสอง เช่น $5!!=5\times3\times1$ ไม่ใช่ทำ factorial สองครั้ง

จึงได้ $\mathbb E[Z]=0$ และ $\mathrm{Var}(Z)=1-0^2=1$ เมื่อ $X=\mu+\sigma Z$ กฎ linearity และการปรับ variance ให้ $\mathbb E[X]=\mu$ และ $\mathrm{Var}(X)=\sigma^2$ ส่วน kurtosis ของ Normal คือ $\mathbb E[Z^4]=3$ ไม่ใช่การเดาจากรูปร่างยอด

ขั้นที่ 10 — ตรวจค่าประมาณด้วยโจทย์เหรียญที่รู้คำตอบตรง

กลับไปที่ $H\sim\mathrm{Binomial}(100,0.5)$ ถามโอกาสหัวตั้งแต่ 60 ครั้ง ใช้ค่าเฉลี่ย 50 และ standard deviation 5 แต่เริ่มพื้นที่ที่ 59.5 เพื่อครอบแท่ง 60 ตาม continuity correction

\[ \begin{aligned} P(H\ge60)&=\sum_{h=60}^{100}\binom{100}{h}(0.5)^{100}\\ &\approx2.84440\%\\ P(H\ge60)&\approx1-\Phi\left(\frac{59.5-50}{5}\right)\\ &=1-\Phi(1.9)\approx2.87166\%\\ \text{without correction}&:\quad1-\Phi(2)\approx2.27501\% \end{aligned} \]

ค่าที่ปรับขอบใกล้คำตอบ Binomial มากกว่าในตัวอย่างนี้ แต่ยังมีความคลาดเคลื่อน การคำนวณเร็วขึ้นเป็นข้อดีของ approximation ไม่ใช่เหตุผลให้ลืมว่าใช้การประมาณ โดยเฉพาะเมื่อถามหางที่ไกลออกไป

Stress comparison: ถ้าใช้พารามิเตอร์เดิมกับการตก 22.6%

Black Monday ปี 1987 มีการลดลงของ DJIA ประมาณ 22.6% ในวันเดียว ลองนำขนาดการลดลงนี้มาเทียบกับพอร์ตสมมติที่ใช้ $\mu=0.04\%,\sigma=1.10\%$ จะอยู่ห่างค่าเฉลี่ยประมาณ 20.58 standard deviation

นี่เป็นการสาธิตความบางของหางเมื่อใช้พารามิเตอร์คงที่ ไม่ใช่การ fit DJIA ก่อนเหตุการณ์ และไม่ใช่การพิสูจน์จากสินทรัพย์คนละตัวว่า Normal ทุกแบบใช้ไม่ได้ การตีความจริงยังต้องดู volatility ที่เปลี่ยนตามเวลาและกลไกของตลาด

ขั้นที่ 11 — คำนวณหางเล็กมากโดยไม่ลบ CDF ที่ปัดเป็นหนึ่ง

ให้ $Q=\Phi(-a)$ และ $a\gt0$ ใช้ integration by parts จะได้เทอมหลัก $\phi(a)/a$ ลบเศษที่เป็นบวก เศษนั้นไม่เกิน $Q/a^2$ จึงสร้างขอบล่างและขอบบนได้

\[ \begin{aligned} a&=\frac{0.226+0.0004}{0.011}\approx20.581818\\ Q&=\frac{\phi(a)}a-\int_a^\infty\frac{\phi(z)}{z^2}\,dz\\ \frac{a\phi(a)}{a^2+1}&\le Q\le\frac{\phi(a)}a\\ 1.9971\times10^{-94}&\lesssim Q\lesssim2.0018\times10^{-94} \end{aligned} \]

ตัวเลขเล็กมากแต่ไม่เป็นศูนย์ หากคำนวณ $1-\Phi(a)$ ด้วย CDF ที่ปัดเป็นหนึ่ง อาจได้ศูนย์จากข้อจำกัดตัวเลขคอมพิวเตอร์แทนคำตอบจริง ควรใช้ survival function, log-CDF หรือวิธีคำนวณหางโดยตรงในงานจริง

Normal เป็นจุดอ้างอิง ไม่ใช่ขอบล่างหรือขอบบนของความเสี่ยงทุกแบบ

Distribution สองแบบที่มีค่าเฉลี่ยและ variance เท่ากันอาจมี CDF ตัดกันได้ จึงไม่มีเหตุผลทั่วไปที่ Normal VaR ต้องต่ำกว่าค่าจริงทุก confidence level การพบหางอ้วนในข้อมูลบางช่วงไม่ได้ให้คำรับประกันเช่นนั้น

ใช้ Normal เป็น benchmark ที่คำนวณง่าย แล้วตรวจ QQ plot, exceedances, ความไม่แน่นอนของพารามิเตอร์ และช่วง stress การเลือก empirical distribution, Student-t หรือแบบจำลอง volatility ที่เปลี่ยนตามเวลาแต่ละแบบก็ยังต้องตรวจข้อจำกัดของมันเอง

ลองทำเอง — แยกเปอร์เซ็นต์ของผลตอบแทนออกจากจำนวนเงิน

พอร์ตเดิมมีมูลค่าลดเหลือ \$25 ล้าน แต่กำหนด distribution ของผลตอบแทนเท่าเดิม โอกาสขาดทุนเกิน 2% และ VaR 99% ในหน่วยเงินเปลี่ยนอย่างไร?

เปิดคำตอบ

โอกาสขาดทุนเกิน 2% ยังคงประมาณ 3.18306% เพราะเกณฑ์และ distribution ของผลตอบแทนไม่เปลี่ยน ส่วน VaR ในหน่วยเงินลดครึ่งหนึ่งเป็นประมาณ \$629,746 เนื่องจากใช้มูลค่าพอร์ตคูณ return quantile เดิม

ถ้าถามโอกาสขาดทุนเกิน \$1 ล้าน คำตอบจะเปลี่ยน เพราะ \$1 ล้านเท่ากับ 4% ของพอร์ตใหม่ แทนที่จะเป็น 2% ของพอร์ตเดิม ต้องแปลงเกณฑ์ก่อนคำนวณทุกครั้ง

ตรวจเองใน 10 วินาที: VaR เป็นเกณฑ์ ไม่ใช่เพดาน และการเปลี่ยนขนาดพอร์ตอย่างเดียวไม่เปลี่ยน shape ของ return distribution ภายใต้สมมติฐานที่กำหนดไว้

const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
function Phi(z) {
  const n = 10000, h = Math.abs(z) / n;
  let sum = 0;
  for (let i = 0; i <= n; i++) {
    sum += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  }
  return 0.5 + Math.sign(z) * h * sum / 3;
}
function quantile(p) {
  let lo = -8, hi = 8;
  for (let i = 0; i < 70; i++) {
    const mid = (lo + hi) / 2;
    if (Phi(mid) < p) lo = mid; else hi = mid;
  }
  return (lo + hi) / 2;
}
const mu = 0.0004, sd = 0.011;
const p2 = Phi((-0.02 - mu) / sd);
const p4 = Phi((-0.04 - mu) / sd);
console.log([p2, 252 * p2, p4, 252 * p4, p2 / p4]);
console.log(-50_000_000 * (mu + sd * quantile(0.01)));
console.log([1, 2, 3].map(k => 2 * Phi(k) - 1));
console.log([1 - Phi(1.9), 1 - Phi(2)]);
console.log(quantile(0.5 / 252));

สรุป — Normal ช่วยคำนวณ แต่ข้อมูลต้องช่วยตรวจ

  • ใช้ $z=(x-\mu)/\sigma$ แล้วอ่าน $\Phi$ ได้เมื่อกำหนด Normal ไม่ใช่เพราะ standardize แล้วทุกข้อมูลจะเป็น Normal
  • พอร์ตตัวอย่างมีโอกาสขาดทุนเกิน 2% ประมาณ 3.1831% และเกิน 4% ประมาณ 0.0120% ความต่างของหางมีขนาดมาก
  • VaR 99% หนึ่งวันประมาณ \$1.2595 ล้าน เป็นเกณฑ์ที่ยังมีโอกาสขาดทุนเกิน ไม่ใช่เพดานความเสียหาย
  • QQ plot เปรียบเทียบ quantile ตามอันดับ จุดหลุดจากเส้นเป็นเรื่องให้ตรวจ ไม่ใช่หลักฐานว่า Normal ห้ามค่านั้นเกิด
  • Normal มี kurtosis 3 ส่วนข้อมูลประกอบรูปมี moment kurtosis ประมาณ 4.70 ต้องพิจารณา estimator, sample uncertainty และความสัมพันธ์ของข้อมูลประกอบด้วย

หัวข้อถัดไปจะดูว่าถ้า log ของตัวแปรเป็น Normal ตัวแปรเดิมมี Lognormal distribution อย่างไร และเหตุใดการบวกผลตอบแทนกับการคูณราคาจึงต้องแยกกัน
