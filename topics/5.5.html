5.5 Consequences of Independence

ทางลัดสามข้อที่ได้จากความเป็นอิสระ แต่ละข้อต้องการเงื่อนไขไม่เท่ากัน: ค่าเฉลี่ยของผลรวมบวกกันได้เสมอ ค่าเฉลี่ยของผลคูณแยกได้เมื่อสองตัวอิสระกัน และ variance ของผลรวมบวกกันได้เมื่อ covariance เป็นศูนย์

ธนาคารแห่งหนึ่งมีทีมเทรดเล็ก ๆ ที่คนในวงการเรียกว่า desk ทีมนี้ถือ “สถานะ” (position) อยู่สองก้อน สถานะคือของที่ถือไว้แล้วได้กำไรหรือขาดทุนตามราคา เช่นหุ้นชุดหนึ่ง กำไรของแต่ละก้อนเปลี่ยนไปทุกวัน บางวันได้มาก บางวันเสีย ของที่รู้ (ตัวเลขสมมติทั้งหมด):

  • กำไรรายวันของสถานะแรกเรียกว่า $X$ มีค่าเฉลี่ย $\mu_X=\$300$
  • กำไรรายวันของสถานะที่สองเรียกว่า $Y$ มีค่าเฉลี่ย $\mu_Y=\$200$
  • ทั้งสองก้อนมี SD (standard deviation) ของกำไรรายวันเท่ากัน $\sigma_X=\sigma_Y=\$100$ ตัวเลขนี้บอกว่ากำไรแต่ละวันมักห่างจากค่าเฉลี่ยราวเท่าไร

หัวหน้า desk สนใจกำไรรวม $X+Y$ ต่อวัน จึงถามสองข้อ: ค่าเฉลี่ยของกำไรรวมเท่าไร และ SD ของกำไรรวมเท่าไร มีคนตอบข้อหลังทันทีว่า $\sigma_X+\sigma_Y=100+100=\$200$ คำตอบนี้ถูกไหม

ลองตอบก่อนเปิดเฉลย

ข้อแรกตอบได้ทันที และถูกเสมอ ไม่ว่าสองก้อนจะเกี่ยวข้องกันอย่างไร: $\mu_X+\mu_Y=300+200=\$500$

ข้อหลังยังตอบไม่ได้ จนกว่าจะรู้ว่ากำไรสองก้อนขึ้นลงไปด้วยกันแค่ไหน ตัวเลขที่วัดเรื่องนี้คือ correlation $\rho$ ซึ่งอยู่ระหว่าง −1 ถึง 1 ถ้า $\rho=1$ สองก้อนขึ้นลงพร้อมกันเสมอ ถ้า $\rho=0$ ไม่มีแนวโน้มขึ้นลงร่วมกันแบบเส้นตรง ถ้า $\rho=-1$ ก้อนหนึ่งขึ้นเมื่ออีกก้อนลงเสมอ สูตรของ SD รวมจะพิสูจน์ในขั้น variance ของผลรวมด้านล่าง ตอนนี้ขอแทนตัวเลขให้ดูก่อน:

\[\begin{aligned} \text{SD}(X+Y)&=\sqrt{100^2+100^2+2\rho(100)(100)},\\ \rho=0:&\quad\sqrt{20{,}000}=\$141.42,\\ \rho=0.5:&\quad\sqrt{30{,}000}=\$173.21,\\ \rho=1:&\quad\sqrt{40{,}000}=\$200,\\ \rho=-1:&\quad\sqrt{0}=\$0. \end{aligned}\]

คำตอบ \$200 จึงถูกเฉพาะกรณี $\rho=1$ ซึ่งเป็นกรณีเลวร้ายที่สุด ไม่ใช่คำตอบทั่วไป เมื่อสองก้อนไม่สัมพันธ์กัน สิ่งที่บวกกันได้คือ variance (SD ยกกำลังสอง) ไม่ใช่ SD

ภาพรวมก่อนลงสูตร

หน้า independence นิยามความเป็นอิสระไว้แล้ว สองตัวแปรสุ่มอิสระกันเมื่อรู้ค่าตัวหนึ่งแล้ว ไม่ได้ข้อมูลอะไรเพิ่มเกี่ยวกับอีกตัวเลย เขียนเป็นสูตรว่า โอกาสที่สองเหตุการณ์เกิดพร้อมกัน เท่ากับโอกาสของแต่ละเหตุการณ์คูณกัน หน้านี้ถามต่อว่า นิยามนี้ช่วยให้คำนวณอะไรง่ายขึ้นบ้าง

คำตอบคือทางลัดสามข้อ ที่ใช้ทุกวันเวลาคำนวณพอร์ต (กลุ่มของสถานะทั้งหมดที่ถืออยู่) แต่แต่ละข้อต้องการเงื่อนไขไม่เท่ากัน:

  • ค่าเฉลี่ยของผลรวม เท่ากับผลรวมของค่าเฉลี่ย ข้อนี้ใช้ได้เสมอ ไม่ต้องมีเงื่อนไข
  • ค่าเฉลี่ยของผลคูณ เท่ากับผลคูณของค่าเฉลี่ย ข้อนี้ต้องให้สองตัวอิสระกัน
  • variance ของผลรวม เท่ากับผลรวมของ variance ข้อนี้ต้องการแค่ให้ covariance เป็นศูนย์ ซึ่งเป็นเงื่อนไขที่อ่อนกว่าความเป็นอิสระ covariance คือตัวเลขที่บอกว่าสองตัวมักอยู่เหนือค่าเฉลี่ยของตัวเองพร้อมกันหรือไม่ ส่วน correlation คือ covariance ที่ปรับสเกลให้อยู่ระหว่าง −1 ถึง 1

รูปด้านล่างตอบคำถามของหัวหน้า desk ครบทุกกรณี แกนนอนคือ correlation ของสองสถานะ แกนตั้งคือ SD ของกำไรรวม ค่าเฉลี่ย \$500 ไม่ขยับเลยไม่ว่าจุดจะอยู่ตรงไหน แต่ SD ไล่ตั้งแต่ \$0 ถึง \$200 คำตอบ “บวก SD ตรง ๆ” ตรงกับจุดขวาสุดจุดเดียว

หน้านี้จะพิสูจน์ทางลัดแต่ละข้อจาก joint density เพื่อให้เห็นว่าเงื่อนไขถูกใช้ตรงจุดไหน joint density คือฟังก์ชันที่บอกว่าคู่ค่า $(x,y)$ แต่ละคู่มีโอกาสเกิดมากน้อยแค่ไหน จากนั้นจะนำไปใช้กับสามเรื่องจริง:

  • แปลงความผันผวนรายวันของหุ้น (SD ของผลตอบแทนรายวัน) เป็นรายปี
  • หาค่าเฉลี่ยและ SD ของมูลค่าหุ้นที่ได้ เมื่อทั้งจำนวนหุ้นและราคาสุ่ม
  • หาราคาปลายปี ซึ่งค่าเฉลี่ยไม่เท่ากับค่ากลาง (ค่ากลางคือราคาที่ผลลัพธ์ครึ่งหนึ่งอยู่ต่ำกว่า)
ศัพท์ที่ใช้ในหัวข้อนี้
Linearity of expectation
ค่าเฉลี่ยของผลรวมคือผลรวมของค่าเฉลี่ย เขียนเป็น $E[aX+bY+c]=aE[X]+bE[Y]+c$ จริงเสมอ ขอแค่ค่าเฉลี่ยของแต่ละตัวมีอยู่ ไม่ต้องอิสระกัน ใช้หาค่าเฉลี่ยของพอร์ตจากค่าเฉลี่ยรายตัว
Product rule ของค่าเฉลี่ย
ค่าเฉลี่ยของผลคูณคือผลคูณของค่าเฉลี่ย $E[h(X)g(Y)]=E[h(X)]\,E[g(Y)]$ จริงเมื่อ $X,Y$ อิสระกัน โดย $h,g$ เป็นฟังก์ชันใดก็ได้ ใช้กับมูลค่าที่เป็นผลคูณ เช่นจำนวนหุ้นคูณราคา หรือราคาที่ทบต้นหลายวัน
Covariance
$\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]$ เป็นบวกเมื่อสองตัวมักสูงกว่าค่าเฉลี่ยพร้อมกัน เป็นลบเมื่อตัวหนึ่งสูงแล้วอีกตัวมักต่ำ เป็นพจน์ไขว้ที่ทำให้ variance ของผลรวมไม่เท่ากับผลรวมของ variance
Correlation $\rho$
covariance หารด้วย SD ของทั้งสองตัว $\rho=\operatorname{Cov}(X,Y)/(\sigma_X\sigma_Y)$ ได้ตัวเลขไม่มีหน่วยระหว่าง −1 ถึง 1 จึงเทียบกันข้ามคู่ได้
Joint density และ marginal density
joint density $f_{X,Y}(x,y)$ บอกว่าคู่ค่า $(x,y)$ มีโอกาสเกิดมากน้อยแค่ไหน marginal density $f_X(x)$ คือ density ของ $X$ ตัวเดียว ได้จากการอินทิเกรต joint density ทิ้งแกน $y$ ดู marginal distribution
Indicator $\mathbf 1_A(X)$
ตัวแปรที่เป็น 1 เมื่อเหตุการณ์ $A$ เกิด และเป็น 0 เมื่อไม่เกิด ค่าเฉลี่ยของมันจึงเท่ากับโอกาสของ $A$ ใช้แปลงคำถามเรื่องโอกาสให้เป็นคำถามเรื่องค่าเฉลี่ย
Log return
ผลตอบแทนแบบ log ของวันที่ $i$ คือ $r_i=\ln(S_i/S_{i-1})$ เมื่อ $S_i$ คือราคาปิดของวันที่ $i$ ราคาจึงเปลี่ยนด้วยตัวคูณ $e^{r_i}$ และ log return หลายวันบวกกันได้ตรง ๆ
ค่ากลาง (median)
ค่าที่ผลลัพธ์ครึ่งหนึ่งอยู่ต่ำกว่า อีกครึ่งอยู่สูงกว่า ถ้าการแจกแจงมีหางข้างหนึ่งยาวกว่า ค่ากลางกับค่าเฉลี่ยจะไม่เท่ากัน
Bienaymé identity
ชื่อของข้อเท็จจริงว่า variance ของผลรวมของตัวแปรที่ไม่สัมพันธ์กัน (covariance เป็นศูนย์ทุกคู่) เท่ากับผลรวมของ variance ใช้ขยายความผันผวนรายวันเป็นรายปีด้วยรากที่สองของจำนวนวัน
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$X,\ Y$กำไรรายวันของสองสถานะ (ตัวอย่างของ desk)ดอลลาร์
$\mu_X,\ \mu_Y$ค่าเฉลี่ยของ $X$ และ $Y$ดอลลาร์
$\sigma_X,\ \sigma_Y$SD (standard deviation) ของ $X$ และ $Y$ดอลลาร์
$a,\ b$จำนวนเท่าของแต่ละสถานะที่ถือ เป็นค่าคงที่ เช่น $a=2$ คือถือสถานะแรกสองเท่าไม่มีหน่วย
$\operatorname{Var},\ \operatorname{Cov}$variance และ covarianceดอลลาร์กำลังสอง

ขั้นที่ 1 — ค่าเฉลี่ยของผลรวม: ไม่ต้องใช้ความเป็นอิสระ

หัวหน้า desk ถามข้อแรกว่ากำไรรวมเฉลี่ยเท่าไร คำตอบ \$500 มาจากการบวกค่าเฉลี่ยตรง ๆ ขั้นนี้ตรวจว่าการบวกแบบนั้นถูกเสมอจริงไหม และใช้เงื่อนไขอะไรบ้าง

วิธีคือเขียนค่าเฉลี่ยเป็นอินทิกรัล ค่าเฉลี่ยของฟังก์ชันใด ๆ ของ $X$ และ $Y$ คือการเอาค่าของฟังก์ชันที่ทุกคู่ $(x,y)$ ถ่วงด้วย joint density $f_{X,Y}(x,y)$ แล้วรวมกันทั้งระนาบ ในขั้นนี้ฟังก์ชันคือผลรวม $x+y$

\[\begin{aligned} E[X+Y]&=\iint(x+y)\,f_{X,Y}(x,y)\,dx\,dy\\ &=\int x\Big[\int f_{X,Y}(x,y)\,dy\Big]dx\\ &\quad+\int y\Big[\int f_{X,Y}(x,y)\,dx\Big]dy\\ &=\int x\,f_X(x)\,dx+\int y\,f_Y(y)\,dy\\ &=E[X]+E[Y],\\ E[aX+bY+c]&=aE[X]+bE[Y]+c. \end{aligned}\]

จุดสำคัญคือตอนแยกอินทิกรัลตามเครื่องหมายบวก พจน์ที่มี $x$ เหลือแค่การอินทิเกรต joint density ทิ้งแกน $y$ สิ่งที่อยู่ในวงเล็บเหลี่ยมจึงกลายเป็น marginal density $f_X(x)$ ตามที่ได้ใน marginal distribution พจน์ที่มี $y$ ก็เหมือนกัน ตลอดทางไม่มีตรงไหนแทน joint density ด้วยผลคูณของ marginal เลย สูตรนี้จึงใช้ได้แม้สองตัวพึ่งพากันมาก ถ้าตัวแปรไม่ต่อเนื่อง ก็แค่เปลี่ยนอินทิกรัลเป็นผลบวก

รูปทั่วไป $E[aX+bY+c]$ ดึง $a,b,c$ ออกนอกอินทิกรัลได้ เพราะเป็นค่าคงที่ แทนตัวเลขของ desk ได้ทันที: $E[X+Y]=300+200=\$500$ เงื่อนไขเดียวคือค่าเฉลี่ยของแต่ละตัวต้องมีอยู่ คือค่าเฉลี่ยของ $|X|$ และ $|Y|$ ต้องไม่เป็นอนันต์ แต่ถ้าขนาดสถานะ $a$ เองสุ่ม $a$ ก็ไม่ใช่ค่าคงที่อีกต่อไป ปัญหาจะกลายเป็นค่าเฉลี่ยของผลคูณ ซึ่งเป็นเรื่องของขั้นถัดไป

ขั้นที่ 2 — ค่าเฉลี่ยของผลคูณ: ความเป็นอิสระเข้ามาตรงนี้

มูลค่าของสิ่งที่ถืออยู่มักเป็นผลคูณ เช่นจำนวนหุ้นคูณราคา ถ้าทั้งสองตัวสุ่ม เราต้องการค่าเฉลี่ยของผลคูณ ขั้นนี้ทำแบบเดียวกับขั้นก่อน แต่เปลี่ยนฟังก์ชันเป็น $xy$ แล้วดูว่าตรงไหนต้องใช้ความเป็นอิสระ

\[\begin{aligned} E[XY]&=\iint xy\,f_{X,Y}(x,y)\,dx\,dy\\ &=\iint xy\,f_X(x)\,f_Y(y)\,dx\,dy\\ &=\Big(\int x\,f_X(x)\,dx\Big)\Big(\int y\,f_Y(y)\,dy\Big)\\ &=E[X]\,E[Y],\\ E[h(X)\,g(Y)]&=E[h(X)]\,E[g(Y)]. \end{aligned}\]

ความเป็นอิสระถูกใช้ครั้งเดียว ตรงที่แทน joint density $f_{X,Y}(x,y)$ ด้วยผลคูณ $f_X(x)\,f_Y(y)$ ซึ่งคือนิยามของ independence สำหรับตัวแปรต่อเนื่อง พอแทนแล้ว สิ่งที่อยู่ใต้อินทิกรัลเป็น “ฟังก์ชันของ $x$ คูณฟังก์ชันของ $y$” อินทิกรัลสองชั้นจึงแยกเป็นอินทิกรัลชั้นเดียวสองตัวคูณกันได้ ถ้าสองตัวไม่อิสระกัน การแทนนี้ผิด และผลทั้งหมดใช้ไม่ได้

รูปทั่วไปในแถวท้ายใช้ได้กับฟังก์ชัน $h$ และ $g$ ใด ๆ เช่น $X^2$, $e^Y$ หรือ payoff ของ option (เงินที่ option จ่ายตามราคาในวันหมดอายุ) ขอแค่ค่าเฉลี่ยที่ต้องใช้มีอยู่ ส่วนตัวอย่างที่สูตรพังเมื่อสองตัวพึ่งพากัน: ให้ $X$ เป็น +1 หรือ −1 อย่างละครึ่ง และให้ $Y=X$ เพราะ $X^2=1$ เสมอ จึงได้ $E[XY]=E[X^2]=1$ แต่ $E[X]\,E[Y]=0\times0=0$

อย่าอ่านสูตรนี้กลับด้าน ความเท่ากัน $E[XY]=E[X]E[Y]$ จริงได้แม้สองตัวไม่อิสระ ตัวอย่างจากหน้า independence คือให้ $X$ เป็น uniform บนช่วง −1 ถึง 1 (ทุกค่าในช่วงมีโอกาสเท่ากัน density เท่ากับ $\tfrac12$) และ $Y=X^2$ ตัวหนึ่งกำหนดอีกตัวเต็ม ๆ แต่

\[\begin{aligned} E[XY]&=E[X^3]=0,\\ E[Y]&=\int_{-1}^{1}\tfrac12x^2\,dx=\tfrac13,\\ E[X]\,E[Y]&=0\times\tfrac13=0. \end{aligned}\]

$E[X]$ และ $E[X^3]$ เป็นศูนย์ เพราะ $x$ และ $x^3$ สมมาตรรอบศูนย์ ส่วนบวกกับส่วนลบหักล้างกันพอดี สองข้างจึงเท่ากันทั้งที่ไม่อิสระ ความเท่ากันของค่าเฉลี่ยคู่เดียวบอกได้แค่ว่า covariance เป็นศูนย์

ขั้นที่ 3 — เหตุการณ์คือฟังก์ชันชนิดหนึ่ง

หน้า independence นิยามความเป็นอิสระด้วยโอกาส แต่ขั้นที่แล้วพูดถึงค่าเฉลี่ย สองเรื่องนี้ดูเหมือนคนละเรื่อง ขั้นนี้แสดงว่าเป็นเรื่องเดียวกัน เครื่องมือคือ indicator $\mathbf 1_A(X)$ ตัวแปรที่เป็น 1 เมื่อ $X$ ตกในช่วง $A$ และเป็น 0 เมื่อไม่ตก

ในขั้นนี้ $a,b,c,d$ คือขอบของช่วง ไม่ใช่ขนาดสถานะ ให้ $A$ คือช่วงที่ $X$ อยู่ระหว่าง $a$ กับ $b$ และ $B$ คือช่วงที่ $Y$ อยู่ระหว่าง $c$ กับ $d$

\[\begin{aligned} P(a\lt X\le b,\ c\lt Y\le d)&=E\big[\mathbf 1_{A}(X)\,\mathbf 1_{B}(Y)\big]\\ &=E\big[\mathbf 1_{A}(X)\big]\,E\big[\mathbf 1_{B}(Y)\big]\\ &=P(a\lt X\le b)\,P(c\lt Y\le d). \end{aligned}\]

ผลคูณ $\mathbf 1_A(X)\,\mathbf 1_B(Y)$ เป็น 1 ก็ต่อเมื่อทั้งสองเหตุการณ์เกิด นอกนั้นเป็น 0 ค่าเฉลี่ยของมันจึงเท่ากับโอกาสที่สองเหตุการณ์เกิดพร้อมกัน จากนั้นใช้ product rule จากขั้นที่แล้ว โดยเลือก $h=\mathbf 1_A$ และ $g=\mathbf 1_B$ ผลคือนิยามความเป็นอิสระแบบโอกาส กลายเป็นกรณีพิเศษของ product rule ของค่าเฉลี่ย

ทางกลับก็จริง ถ้า product rule ใช้ได้กับ indicator ทุกคู่ช่วง ก็สรุปได้ว่าสองตัวอิสระกัน แต่ถ้าตรวจแค่คู่เดียว $h(x)=x$ และ $g(y)=y$ จะรู้แค่ว่า covariance เป็นศูนย์ ยิ่งตรวจกับฟังก์ชันหลากหลายมากขึ้น ก็ยิ่งเข้าใกล้ความเป็นอิสระ

ขั้นที่ 4 — variance ของผลรวม: พจน์ covariance ต้องอยู่จนกว่าจะรู้ค่า

กลับมาที่คำถามข้อสองของหัวหน้า desk: SD ของกำไรรวมเท่าไร วิธีคือหา variance ของกำไรรวมก่อน แล้วถอดรากที่สองให้ได้ SD variance คือค่าเฉลี่ยของ (ค่าลบค่าเฉลี่ย) ยกกำลังสอง จึงเท่ากับ SD ยกกำลังสอง ดู variance and standard deviation ขั้นนี้กระจายกำลังสองของผลรวมออกตรง ๆ แล้วดูว่าพจน์ไหนหายไปเมื่อไร

ใช้ $\mu_X,\mu_Y$ แทนค่าเฉลี่ย และ $\sigma_X,\sigma_Y$ แทน SD ของ $X,Y$ ส่วน $a,b$ คือจำนวนเท่าของแต่ละสถานะที่ถือ

\[\begin{aligned} \operatorname{Var}(aX+bY)&=E\Big[\big(a(X-\mu_X)+b(Y-\mu_Y)\big)^2\Big]\\ &=a^2\sigma_X^2+b^2\sigma_Y^2\\ &\quad+2ab\operatorname{Cov}(X,Y),\\ \operatorname{Cov}(X,Y)&=E[(X-\mu_X)(Y-\mu_Y)]\\ &=E[XY]-E[X]\,E[Y],\\ \operatorname{SD}(X+Y)&=\sqrt{100^2+100^2+2\rho(100)(100)}\\ &=100\sqrt{2+2\rho}. \end{aligned}\]

ความคิดหลักคือ ระยะห่างจากค่าเฉลี่ยของผลรวม เท่ากับผลรวมของระยะห่างแต่ละตัว ค่าเฉลี่ยของ $aX+bY$ คือ $a\mu_X+b\mu_Y$ จาก linearity ในขั้นแรก ระยะห่างของผลรวมจึงเป็น $u+v$ เมื่อ $u=a(X-\mu_X)$ และ $v=b(Y-\mu_Y)$ จากนั้นกระจาย $(u+v)^2=u^2+v^2+2uv$ แล้วใช้ linearity กับแต่ละพจน์ พจน์ $u^2$ และ $v^2$ ให้ $a^2\sigma_X^2$ และ $b^2\sigma_Y^2$ ส่วนพจน์ไขว้ $2uv$ ให้ $2ab$ คูณ covariance รูปที่สองของ covariance ได้จากการกระจาย $(X-\mu_X)(Y-\mu_Y)$ แล้วใช้ linearity อีกครั้ง

ความเป็นอิสระเข้ามาตรงไหน ถ้าสองตัวอิสระกัน product rule ให้ $E[XY]=E[X]\,E[Y]$ covariance จึงเป็นศูนย์ และ variance บวกกันได้ตรง ๆ แต่สิ่งที่สูตรต้องการจริง ๆ คือ covariance เป็นศูนย์ เท่านั้น ซึ่งอ่อนกว่าความเป็นอิสระ

แถวท้ายแทนตัวเลขของ desk: $a=b=1$ และ $\sigma_X=\sigma_Y=100$ ส่วน covariance เขียนเป็น $\rho\sigma_X\sigma_Y=\rho(100)(100)$ ตามนิยามของ correlation จะได้ $\rho=0$ ให้ $100\sqrt2=\$141.42$, $\rho=0.5$ ให้ $100\sqrt3=\$173.21$ และ $\rho=1$ ให้ $100\sqrt4=\$200$ ตรงกับเฉลยตอนต้นหน้า

อีกตัวอย่างหนึ่ง ที่ถือสองสถานะไม่เท่ากัน (ตัวเลขสมมติ): desk อีกทีมถือสถานะแรกสองเท่า ($a=2$) และสถานะที่สองหนึ่งเท่า ($b=1$) SD ของกำไรต่อหนึ่งเท่าคือ $\sigma_X=\$30$ และ $\sigma_Y=\$40$ และ covariance เป็นศูนย์

\[\begin{aligned} \operatorname{Var}&=2^2(30^2)+1^2(40^2)\\ &=3600+1600=5200,\\ \operatorname{SD}&=\sqrt{5200}=\$72.11. \end{aligned}\]

คำตอบไม่ใช่ $2(30)+40=\$100$ สังเกตว่าน้ำหนัก $a$ เข้าไปในสูตรเป็น $a^2$ เพราะ variance มีหน่วยเป็นดอลลาร์กำลังสอง

ขั้นที่ 5 — หลายวัน: variance โตตามจำนวนวัน SD โตตามราก

ทีมดูแลความเสี่ยงมักวัดความผันผวนจากข้อมูลรายวัน แต่รายงานและเพดานความเสี่ยงมักพูดเป็นรายปี จึงต้องแปลงจากรายวันเป็นรายปี สูตร variance ของผลรวมขยายไปกี่ตัวก็ได้ ขั้นนี้ใช้มันกับผลรวมของ 252 วัน

โจทย์ให้อะไรมาบ้าง: หุ้นตัวหนึ่ง (ตัวเลขสมมติ) วัดผลตอบแทนเป็น log return รายวัน $r_i=\ln(S_i/S_{i-1})$ เมื่อ $S_i$ คือราคาปิดของวันที่ $i$ ข้อดีของ log return คือ log return ทั้งปีเท่ากับผลรวมของรายวัน เพราะ $S_{252}/S_0=(S_1/S_0)(S_2/S_1)\cdots(S_{252}/S_{251})$ และ log ของผลคูณคือผลรวมของ log

  • ค่าเฉลี่ยรายวัน $\mu=0.04\%=0.0004$
  • ความผันผวนรายวัน คือ SD ของ log return รายวัน $\sigma=1.1\%=0.011$
  • จำนวนวันซื้อขายต่อปี $n=365-104-9=252$ วัน คือ 365 วันปฏิทิน หักเสาร์อาทิตย์ 104 วัน และวันหยุดตลาดหุ้นสหรัฐราว 9 วัน
  • สมมติว่าผลตอบแทนของวันที่ต่างกันไม่สัมพันธ์กัน (covariance เป็นศูนย์ทุกคู่วัน)

คำถามคือ log return ทั้งปี $r_1+\cdots+r_{252}$ มีค่าเฉลี่ยและความผันผวนเท่าไร

\[\begin{aligned} E\Big[\sum_{i=1}^{252}r_i\Big]&=252(0.0004)=0.1008,\\ \operatorname{Var}\Big(\sum_{i=1}^{252}r_i\Big)&=\sum_{i=1}^{252}\operatorname{Var}(r_i)\\ &=252(0.011^2)=0.030492,\\ \operatorname{SD}&=0.011\sqrt{252}=0.1746. \end{aligned}\]

คำตอบ: ค่าเฉลี่ยทั้งปี $0.1008=10.08\%$ และความผันผวนทั้งปี $0.1746=17.46\%$ ค่าเฉลี่ยใช้แค่ linearity จึงไม่ต้องมีเงื่อนไขอะไร ส่วน variance ต้องให้ covariance ของทุกคู่วันเป็นศูนย์ ถ้าไม่เป็นศูนย์ จะมีพจน์ไขว้ $\operatorname{Cov}(r_i,r_j)$ เพิ่มเข้ามาทุกคู่ $i\ne j$ ซึ่งมี $252\times251=63{,}252$ พจน์ สมมติฐานนี้ทำให้ทั้งหมดหายไป ผลคือค่าเฉลี่ยโตตามจำนวนวัน $n$ แต่ SD โตตาม $\sqrt n$ นี่คือที่มาของกฎ “คูณ $\sqrt{252}$” ที่ใช้แปลงความผันผวนรายวันเป็นรายปี

ตรวจเองใน 10 วินาที: สมมติว่าผลตอบแทนของวันติดกันมี correlation 0.1 แต่วันที่ห่างกันมากกว่านั้นยังไม่สัมพันธ์ คู่วันติดกันมี 251 คู่ แต่ละคู่โผล่ในผลรวมสองครั้ง (เป็น $i,j$ และ $j,i$) และแต่ละพจน์มี covariance $0.1\times0.011^2$

\[\begin{aligned} \operatorname{Var}&=0.011^2\,(252+2\times251\times0.1)\\ &=0.000121\times302.2=0.036566,\\ \operatorname{SD}&=\sqrt{0.036566}=0.1912. \end{aligned}\]

ความผันผวนทั้งปีจึงเป็น 19.12% แทน 17.46% สมมติฐาน “ไม่สัมพันธ์กัน” จึงเปลี่ยนคำตอบได้จริง

ขั้นที่ 6 — ผลคูณของจำนวนหุ้นสุ่มกับตัวคูณราคาสุ่ม

มูลค่าที่ถือคือจำนวนหุ้นคูณราคา ถ้าทั้งสองอย่างสุ่ม ค่าเฉลี่ยของมูลค่าต้องใช้ product rule ส่วน variance ต้องใช้ second moment คือค่าเฉลี่ยของกำลังสอง $E[V^2]$ ขั้นนี้ทำครบทั้งสองอย่าง

โจทย์ให้อะไรมาบ้าง: นักลงทุนคนหนึ่งยื่นจองซื้อหุ้นที่กำลังจะเข้าตลาดครั้งแรก (IPO) คนจองมีมากกว่าหุ้นที่ขาย ผู้ขายจึงสุ่มว่าใครได้หุ้นเท่าไร นักลงทุนจึงไม่รู้ล่วงหน้าว่าจะได้หุ้นกี่หุ้น และไม่รู้ว่าราคาจะไปทางไหน ของที่รู้ (ตัวเลขสมมติทั้งหมด):

  • จำนวนหุ้นที่ได้ $X$ นับเป็นพันหุ้น ได้ 5 ด้วยโอกาส 0.2 และได้ 0 ด้วยโอกาส 0.8
  • ราคาเปลี่ยนจากราคาต้นงวดด้วยตัวคูณ $e^Y$ โดย log return $Y$ เป็น normal มาตรฐาน (ค่าเฉลี่ย 0, SD 1)
  • $X$ อิสระจาก $Y$ เพราะจำนวนที่สุ่มได้ไม่เกี่ยวกับราคาที่จะเกิด
  • มูลค่า $V=Xe^Y$ นับเป็น “จำนวนพันหุ้น คูณราคาต้นงวด” ถ้าจะแปลงเป็นดอลลาร์ ให้คูณด้วย 1,000 และราคาต้นงวด

ค่าเฉลี่ยของ $X$ และ $X^2$ คิดจากสองกรณีได้ทันที:

\[\begin{aligned} E[X]&=0.2(5)+0.8(0)=1,\\ E[X^2]&=0.2(5^2)+0.8(0^2)=5. \end{aligned}\]

ส่วน $E[e^Y]$ และ $E[e^{2Y}]$ ต้องคิดจาก density ของ normal จึงหาสูตรทั่วไป $E[e^{tY}]$ ก่อน แล้วแทน $t=1$ และ $t=2$

\[\begin{aligned} E[e^{tY}]&=\int\frac{e^{ty-y^2/2}}{\sqrt{2\pi}}\,dy,\\ ty-\tfrac{y^2}{2}&=-\tfrac{(y-t)^2}{2}+\tfrac{t^2}{2},\\ E[e^{tY}]&=e^{t^2/2}\int\frac{e^{-(y-t)^2/2}}{\sqrt{2\pi}}\,dy\\ &=e^{t^2/2},\\ E[V]&=E[X]\,E[e^Y]=1\cdot e^{1/2}=1.6487,\\ E[V^2]&=E[X^2]\,E[e^{2Y}]=5e^2,\\ \operatorname{Var}(V)&=E[V^2]-(E[V])^2\\ &=5e^2-e\\ &=36.945-2.718=34.227,\\ \operatorname{SD}(V)&=\sqrt{34.227}=5.850. \end{aligned}\]

คำตอบ: เคล็ดของ $E[e^{tY}]$ คือเติมกำลังสองสมบูรณ์ในเลขชี้กำลัง พอดึง $e^{t^2/2}$ ออกมา สิ่งที่เหลือใต้อินทิกรัลคือ density ของ normal ที่มีค่าเฉลี่ย $t$ พื้นที่ใต้ density ใด ๆ เท่ากับ 1 จึงได้ $E[e^{tY}]=e^{t^2/2}$ จากนั้นใช้ product rule สองครั้ง ครั้งแรกกับ $h(X)=X$ และ $g(Y)=e^Y$ ครั้งที่สองกับ $X^2$ และ $e^{2Y}$ ซึ่งยังอิสระกัน เพราะฟังก์ชันของตัวแปรที่อิสระกันก็อิสระกันด้วย

ถ้าราคาต้นงวดคือ \$100 ต่อหุ้น (สมมติ) หนึ่งหน่วยของ $V$ มีค่า $1{,}000\times\$100=\$100{,}000$ มูลค่าเฉลี่ยจึงเป็น $100{,}000\times1.64872=\$164{,}872$ และ SD ของมูลค่าเป็น $100{,}000\times5.85038=\$585{,}038$ SD สูงกว่าค่าเฉลี่ยมาก เพราะ 8 ครั้งใน 10 ครั้งนักลงทุนไม่ได้หุ้นเลย

ตรวจเองใน 10 วินาที: $E[e^Y]=1.6487$ ไม่ใช่ $e^{E[Y]}=e^0=1$ เพราะ $e^y$ โค้งหงาย ดูที่ $Y=\pm1$ ซึ่งมีโอกาสเท่ากัน ขาขึ้นได้ $e^{1}-1=1.718$ แต่ขาลงเสียแค่ $1-e^{-1}=0.632$ ฝั่งบวกดันค่าเฉลี่ยขึ้นมากกว่าที่ฝั่งลบดึงลง ผลเดียวกันนี้คือที่มาของค่าเฉลี่ย $e^{\mu+\sigma^2/2}$ ของ lognormal distribution

ขั้นที่ 7 — ราคาปลายปี: ค่าเฉลี่ยไม่เท่ากับค่ากลาง

ขั้นที่แล้วใช้ product rule กับผลคูณของสองตัว ราคาที่ทบต้นหลายวันก็เป็นผลคูณเหมือนกัน แต่เป็นผลคูณของตัวคูณรายวันหลายตัว product rule ขยายไปหลายตัวได้ เมื่อทุกตัวอิสระร่วมกัน คือรู้ค่าของบางวันแล้วไม่ได้ข้อมูลอะไรเกี่ยวกับวันอื่นเลย จึงหาค่าเฉลี่ยของราคาปลายปีได้ทันที

โจทย์ให้อะไรมาบ้าง: หุ้นตัวเดียวกับตอนแปลงความผันผวนรายวันเป็นรายปี นักลงทุนอยากรู้สองอย่าง คือราคาปลายปีเฉลี่ยเท่าไร และค่ากลางของราคาปลายปีเท่าไร ของที่รู้ (ตัวเลขสมมติ ไม่รวมปันผล):

  • ราคาต้นปี $S_0=\$100$
  • log return รายวัน $r_1,\dots,r_{252}$ เป็น normal ทุกตัว ค่าเฉลี่ย $\mu=0.0004$ และ SD $\sigma=0.011$
  • ทั้ง 252 วันอิสระร่วมกัน ซึ่งเป็นเงื่อนไขที่แรงกว่าแค่ “ไม่สัมพันธ์กัน”

แต่ละวันราคาคูณด้วย $e^{r_i}$ ราคาปลายปี $S_T$ จึงเป็นราคาต้นปีคูณตัวคูณ 252 ตัว เพื่อหาค่าเฉลี่ยของตัวคูณหนึ่งตัว ให้เขียน $r_i=\mu+\sigma Z$ เมื่อ $Z$ เป็น normal มาตรฐาน แล้วใช้ $E[e^{tZ}]=e^{t^2/2}$ จากขั้นที่แล้ว โดยแทน $t=\sigma$

\[\begin{aligned} S_T&=100\prod_{i=1}^{252}e^{r_i},\\ E[e^{r_i}]&=e^{\mu}\,E[e^{\sigma Z}]=e^{\mu+\sigma^2/2},\\ E[S_T]&=100\prod_{i=1}^{252}E[e^{r_i}]\\ &=100\,e^{252(0.0004+0.011^2/2)}\\ &=100\,e^{0.116046}=112.30,\\ \operatorname{median}(S_T)&=100\,e^{252(0.0004)}\\ &=100\,e^{0.1008}=110.61. \end{aligned}\]

คำตอบ: ราคาปลายปีเฉลี่ย \$112.30 แต่ค่ากลางคือ \$110.61 ค่าเฉลี่ยของผลคูณแยกเป็นผลคูณของค่าเฉลี่ยได้ เพราะทุกวันอิสระร่วมกัน ส่วนค่ากลางมาจากอีกทาง log return ทั้งปีคือผลรวมของ normal ที่อิสระกัน จึงยังเป็น normal ค่าเฉลี่ย $252\times0.0004=0.1008$ normal สมมาตร ค่ากลางจึงเท่ากับค่าเฉลี่ย และ $e^x$ เป็นฟังก์ชันเพิ่ม ไม่สลับลำดับว่าผลไหนมากกว่าผลไหน ค่ากลางจึงส่งผ่าน $e^x$ ได้ตรง ๆ

ตรวจเองใน 10 วินาที: เลขชี้กำลังของค่าเฉลี่ยกับค่ากลางต่างกัน $0.116046-0.1008=0.015246$ ซึ่งก็คือ $252\times0.011^2/2$ หรือครึ่งหนึ่งของ variance ทั้งปี 0.030492 ค่าเฉลี่ยจึงสูงกว่าค่ากลาง $e^{0.015246}-1=1.5\%$ ต่อมา ราคาปลายปีต่ำกว่า \$100 ก็ต่อเมื่อ log return ทั้งปีติดลบ log return ทั้งปีเป็น normal ค่าเฉลี่ย 0.1008 และ SD 0.1746 ตามที่คำนวณไว้ตอนแปลงรายวันเป็นรายปี จึงได้

\[\begin{aligned} P(S_T\lt100)&=\Phi\Big(\frac{0-0.1008}{0.1746}\Big)\\ &=\Phi(-0.577)=28.2\%. \end{aligned}\]

$\Phi(z)$ คือโอกาสที่ normal มาตรฐานมีค่าต่ำกว่า $z$ ดู normal distribution การลบค่าเฉลี่ยแล้วหารด้วย SD เปลี่ยนคำถามให้เป็นคำถามของ normal มาตรฐาน

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

บวก SD แทนการบวก variance: บวก SD ของสองสถานะได้ $100+100=\$200$ แต่ถ้าสองสถานะไม่สัมพันธ์กัน ค่าจริงคือ $\sqrt{100^2+100^2}=\$141.42$ คำตอบผิดสูงไป $200/141.42=1.41$ เท่า หรือเกินไป 41% การบวก SD ถูกเฉพาะเมื่อ correlation เป็น 1

ทิ้งพจน์ covariance โดยไม่ตรวจ: ที่ correlation 0.5 ค่าจริงคือ $\sqrt{100^2+100^2+2(0.5)(100)(100)}=\$173.21$ ถ้าทิ้งพจน์ไขว้จะได้ \$141.42 ต่ำไป $1-141.42/173.21=18\%$ ความผิดนี้ทำให้ตัวเลขต่ำหรือสูงเกินไป ขึ้นกับเครื่องหมายของ $ab\operatorname{Cov}(X,Y)$ ถ้าสถานะหนึ่ง long (ซื้อไว้ ได้กำไรเมื่อราคาขึ้น) และอีกสถานะ short (ขายไว้ก่อน ได้กำไรเมื่อราคาลง) จะได้ $ab\lt0$ covariance ที่เป็นบวกจึงกลับลดความเสี่ยง และการทิ้งพจน์นี้ทำให้ความเสี่ยงสูงเกินจริง

แทน $E[e^Y]$ ด้วย $e^{E[Y]}$: ในตัวอย่างจำนวนหุ้นสุ่ม จะได้ $e^0=1$ แทน $e^{0.5}=1.6487$ ในตัวอย่างราคาปลายปี จะได้ $100e^{0.1008}=\$110.61$ แทน \$112.30 ความผิดแบบนี้ให้ค่าเฉลี่ยต่ำไปเสมอ เมื่อฟังก์ชันโค้งหงายแบบ $e^y$

คูณ variance เพื่อหา variance ของผลคูณ: ในตัวอย่างจำนวนหุ้นสุ่ม $\operatorname{Var}(X)=5-1^2=4$ และ $\operatorname{Var}(e^Y)=E[e^{2Y}]-(E[e^Y])^2=e^2-e=4.671$ คูณกันได้ $4\times4.671=18.68$ แต่ค่าจริงคือ 34.23 การคูณ variance ทิ้งผลของค่าเฉลี่ยทั้งสองตัว ต้องเริ่มจาก $\operatorname{Var}(V)=E[V^2]-(E[V])^2$ เสมอ

ใช้ $\sqrt{252}$ กับผลตอบแทนที่สัมพันธ์ข้ามวัน: ถ้าวันติดกันมี correlation 0.1 ความผันผวนทั้งปีคือ $0.011\sqrt{302.2}=19.12\%$ ไม่ใช่ $0.011\sqrt{252}=17.46\%$

ใช้ product rule เมื่อขนาดสถานะขึ้นกับผลตอบแทน: ถ้า desk ซื้อเพิ่มหลังราคาขึ้น จำนวนหุ้นกับผลตอบแทนก็ไม่อิสระกันแล้ว $E[XY]$ ต้องคำนวณจาก joint distribution จริง จะใช้ $E[X]\,E[Y]$ แทนไม่ได้

ใช้ทำอะไรบนโต๊ะจริง

ทุกครั้งที่ desk คำนวณความเสี่ยงของพอร์ตจากความเสี่ยงรายตัว ก็คือการใช้สูตร variance ของผลรวมซ้ำกับทุกคู่สถานะ เมื่อมีหลายสถานะ สูตรนี้เขียนเป็น matrix ได้กระชับ ดู linear transformations และความเสี่ยงพอร์ต

การแปลงความผันผวนรายวันเป็นรายปีใช้การคูณ $\sqrt{252}$ แบบด้านบน ส่วนค่าเฉลี่ยของราคาที่ทบต้น เช่นใน GBM ที่มี drift μ ใช้ product rule แบบตัวอย่างราคาปลายปี GBM (geometric Brownian motion) คือแบบจำลองราคาหุ้นที่ใช้กันมาก ซึ่ง log return แต่ละช่วงเป็น normal และอิสระกัน เหมือนตัวอย่างนั้น

จุดที่ต้องระวังคือต้องรู้ว่ากำลังใช้เงื่อนไขระดับไหน ค่าเฉลี่ยรวมไม่สนว่าสถานะต่าง ๆ เกี่ยวกันอย่างไร แต่ความเสี่ยงรวมขึ้นกับความเกี่ยวกันนั้นทั้งหมด

โจทย์ตรวจความเข้าใจ

1. กลับไปที่สองสถานะของ desk ตอนต้นหน้า กำไรรายวันเฉลี่ย \$300 และ \$200 และ SD \$100 ทั้งคู่ (ก) ถ้า correlation เป็น −0.5 ค่าเฉลี่ยและ SD ของกำไรรวมเท่าไร (ข) ถ้า desk ถือสถานะแรกสองเท่า ($a=2,\ b=1$) และ correlation เป็น 0.5 ค่าเฉลี่ยและ SD ของกำไรรวมเท่าไร

เฉลย

(ก) ค่าเฉลี่ยไม่ขึ้นกับ correlation จึงยังเป็น $300+200=\$500$ ส่วน SD คิดจาก covariance ก่อน

\[\begin{aligned} \operatorname{Cov}&=-0.5(100)(100)=-5000,\\ \operatorname{Var}&=100^2+100^2+2(-5000)\\ &=10{,}000,\\ \operatorname{SD}&=\sqrt{10{,}000}=\$100. \end{aligned}\]

(ข) ค่าเฉลี่ยเป็น $2(300)+200=\$800$ ส่วน covariance ของ $X$ กับ $Y$ คือ $0.5(100)(100)=5000$

\[\begin{aligned} \operatorname{Var}&=2^2(100^2)+1^2(100^2)\\ &\quad+2(2)(1)(5000)\\ &=40{,}000+10{,}000+20{,}000\\ &=70{,}000,\\ \operatorname{SD}&=\sqrt{70{,}000}=\$264.58. \end{aligned}\]

2. ตัวอย่างจำนวนหุ้นสุ่มหา variance ของผลคูณ $V=Xe^Y$ ด้วยตัวเลขเฉพาะ ข้อนี้หาสูตรทั่วไป ให้ $X,Y$ อิสระกัน มีค่าเฉลี่ย $\mu_X,\mu_Y$ และ SD $\sigma_X,\sigma_Y$ จงหา $\operatorname{Var}(XY)$ แล้วตรวจกับตัวอย่างนั้น โดยให้ตัวที่สองคือตัวคูณราคา $e^Y$ (ต้องได้ 34.227)

เฉลย
\[\begin{aligned} \operatorname{Var}(XY)&=E[X^2]\,E[Y^2]-(\mu_X\mu_Y)^2\\ &=(\sigma_X^2+\mu_X^2)(\sigma_Y^2+\mu_Y^2)-\mu_X^2\mu_Y^2\\ &=\sigma_X^2\sigma_Y^2+\sigma_X^2\mu_Y^2+\mu_X^2\sigma_Y^2. \end{aligned}\]

เริ่มจากนิยาม $\operatorname{Var}(XY)=E[(XY)^2]-(E[XY])^2$ ความเป็นอิสระถูกใช้ในแถวแรก ผ่าน product rule สองครั้ง คือ $E[X^2Y^2]=E[X^2]\,E[Y^2]$ (เลือก $h(X)=X^2$ และ $g(Y)=Y^2$) และ $E[XY]=\mu_X\mu_Y$ ส่วน $E[X^2]=\sigma_X^2+\mu_X^2$ ได้จากการย้ายข้างนิยาม $\sigma_X^2=E[X^2]-\mu_X^2$

ตรวจกับตัวอย่าง: $X$ มี $\mu_X=1$ และ $\sigma_X^2=5-1^2=4$ ตัวที่สองคือ $e^Y$ มีค่าเฉลี่ย $e^{0.5}$ จึงได้ $\mu_Y^2=(e^{0.5})^2=e$ และ variance $\sigma_Y^2=e^2-e=4.671$

\[\begin{aligned} \operatorname{Var}(V)&=4(4.671)+4(e)+1^2(4.671)\\ &=18.683+10.873+4.671\\ &=34.227. \end{aligned}\]

ตรงกับตัวอย่าง พจน์ $\sigma_X^2\sigma_Y^2=18.683$ คือส่วนเดียวที่การคูณ variance ตรง ๆ ให้ อีกสองพจน์คือส่วนที่มันลืม

3. นักวิเคราะห์คนหนึ่งตรวจข้อมูลของสองตัวแปร แล้วพบว่า $E[XY]=E[X]E[Y]$ เขาสรุปได้ไหมว่า $X,Y$ อิสระกัน และใช้สูตร variance ของผลรวมแบบไม่มีพจน์ไขว้ได้ไหม

เฉลย

สรุปว่าอิสระไม่ได้ ตัวอย่างคือ $X$ เป็น uniform บน −1 ถึง 1 และ $Y=X^2$ จากหน้า independence คู่นี้มี $E[XY]=E[X^3]=0$ และ $E[X]E[Y]=0\times\tfrac13=0$ เท่ากัน ทั้งที่ $Y$ ถูกกำหนดโดย $X$ ทั้งหมด แต่ใช้สูตร variance ของผลรวมแบบไม่มีพจน์ไขว้ได้ เพราะความเท่ากันนี้แปลว่า $\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]=0$ พอดี ซึ่งเป็นเงื่อนไขเดียวที่สูตรนั้นต้องการ

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
// 1) desk: two positions, SD 100 each, mean 300 and 200
const sdTotal = rho => Math.sqrt(100**2 + 100**2 + 2 * rho * 100 * 100);
console.log([-1, -0.5, 0, 0.5, 1].map(r => [r, +sdTotal(r).toFixed(2)]));
// [-1,0] [-0.5,100] [0,141.42] [0.5,173.21] [1,200]
console.log({ weighted: Math.sqrt(4 * 30**2 + 40**2) });          // 72.11

// 2) daily to yearly: 252 trading days
const mu = 0.0004, s = 0.011, n = 252;
console.log({ yearMean: n * mu, yearSD: s * Math.sqrt(n),        // 0.1008, 0.1746
  withLag1Corr: s * Math.sqrt(n + 2 * (n - 1) * 0.1) });         // 0.1912

// 3) E[e^{tY}] for standard normal Y by midpoint integration
const phi = y => Math.exp(-y * y / 2) / Math.sqrt(2 * Math.PI);
const integrate = (g, a, b, m = 40000) => {
  let t = 0; const h = (b - a) / m;
  for (let i = 0; i < m; i++) t += g(a + (i + .5) * h) * h;
  return t;
};
const e1 = integrate(y => Math.exp(y) * phi(y), -12, 12);       // e^0.5
const e2 = integrate(y => Math.exp(2 * y) * phi(y), -12, 12);   // e^2
const EX = .2 * 5, EX2 = .2 * 25;                                 // 1, 5
const meanV = EX * e1, varV = EX2 * e2 - meanV ** 2;
console.log({ e1, e2, meanV, varV, sdV: Math.sqrt(varV),
  dollarMean: 1e5 * meanV, dollarSD: 1e5 * Math.sqrt(varV),
  wrongProductOfVariances: (EX2 - EX ** 2) * (e2 - e1 ** 2) });  // 18.68

// 4) year-end price: mean vs median
const yearVar = n * s * s;
console.log({ mean: 100 * Math.exp(n * mu + yearVar / 2),       // 112.30
  median: 100 * Math.exp(n * mu) });                             // 110.61

สิ่งที่ควรตอบได้หลังอ่าน

  • ค่าเฉลี่ยของผลรวมบวกกันได้เสมอ $E[aX+bY+c]=aE[X]+bE[Y]+c$ กำไรรวมเฉลี่ยของ desk คือ $300+200=\$500$ ไม่ว่า correlation เป็นเท่าไร
  • ค่าเฉลี่ยของผลคูณแยกได้ $E[h(X)g(Y)]=E[h(X)]E[g(Y)]$ เมื่อสองตัวอิสระกัน ความเป็นอิสระถูกใช้ตรงจุดเดียว คือตอนแทน joint density ด้วยผลคูณของ marginal แต่ความเท่ากัน $E[XY]=E[X]E[Y]$ คู่เดียวไม่พิสูจน์ว่าอิสระกัน
  • variance ของผลรวมมีพจน์ไขว้ $2ab\operatorname{Cov}(X,Y)$ ซึ่งหายไปเมื่อ covariance เป็นศูนย์ SD รวมของ desk ที่ $\rho=0$ คือ $100\sqrt2=\$141.42$ ไม่ใช่ \$200
  • ถ้าผลตอบแทนต่างวันไม่สัมพันธ์กัน ความผันผวนรายปีคือ $0.011\sqrt{252}=17.46\%$ แต่ถ้าวันติดกันมี correlation 0.1 ตัวเลขจะขึ้นเป็น 19.12%
  • variance ของผลคูณต้องหา second moment $E[V^2]$ ก่อน และค่าเฉลี่ยของราคาทบต้นสูงกว่าค่ากลาง (\$112.30 เทียบกับ \$110.61) เพราะ $E[e^Y]\gt e^{E[Y]}$

หน้านี้ใช้ความเป็นอิสระแบบตรง ๆ แต่ในงานเครดิต คือการปล่อยกู้หรือถือหุ้นกู้ที่เสียเงินเมื่อผู้กู้ผิดนัดชำระ ลูกหนี้สองรายแทบไม่เคยอิสระกันจริง เพราะเจอเศรษฐกิจเดียวกัน เศรษฐกิจแย่ทีไรก็ผิดนัดพร้อมกันได้ หน้าถัดไป conditional independence และ Gaussian copula แสดงวิธีที่ desk เครดิตใช้ คือสมมติว่าลูกหนี้อิสระกันเมื่อรู้ภาวะเศรษฐกิจแล้ว แล้วเฉลี่ยข้ามภาวะเศรษฐกิจทุกแบบ
