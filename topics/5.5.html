สารบัญ · Part 1 · บทที่ 5

5.5 Consequences of Independence

ค่าเฉลี่ยของผลรวมบวกกันได้เสมอ ค่าเฉลี่ยของผลคูณแยกได้เมื่ออิสระ และ variance ของผลรวมบวกกันได้เมื่อ covariance เป็นศูนย์ ซึ่งเป็นเงื่อนไขสามระดับที่ต้องแยกให้ออก

desk ถือสองสถานะ (สมมติ) สถานะแรกทำกำไรเฉลี่ยวันละ \$300 สถานะที่สองวันละ \$200 แต่ละสถานะมีส่วนเบี่ยงเบนมาตรฐานของกำไรรายวัน \$100 หัวหน้า desk ถามสองข้อ: กำไรรวมต่อวันเฉลี่ยเท่าไร และส่วนเบี่ยงเบนมาตรฐานของกำไรรวมเท่าไร มีคนตอบข้อหลังว่า \$200 เพราะ “100 บวก 100”

ลองตอบก่อนเปิดเฉลย

ค่าเฉลี่ยคือ \$500 เสมอ ไม่ว่าสองสถานะจะเกี่ยวข้องกันอย่างไร ส่วนเบี่ยงเบนมาตรฐานตอบไม่ได้จนกว่าจะรู้ correlation: ถ้า correlation เป็นศูนย์ได้ $\sqrt{100^2+100^2}=\$141.42$ ถ้า 0.5 ได้ \$173.21 ถ้าเป็น 1 จึงจะได้ \$200 และถ้าเป็น −1 ได้ \$0 คำตอบ \$200 จึงเป็นกรณีเลวร้ายที่สุด ไม่ใช่คำตอบทั่วไป สิ่งที่บวกกันได้คือ variance ไม่ใช่ส่วนเบี่ยงเบนมาตรฐาน

ภาพรวมก่อนลงสูตร

independence นิยามว่าโอกาสร่วมเป็นผลคูณ หน้านี้ถามว่าแล้วได้อะไรจากมัน คำตอบคือทางลัดสามสูตรที่ใช้ทุกวันในการคำนวณพอร์ต แต่ทั้งสามสูตรต้องการเงื่อนไขไม่เท่ากัน: ค่าเฉลี่ยของผลรวมไม่ต้องการเงื่อนไขอะไรเลย ค่าเฉลี่ยของผลคูณต้องการความเป็นอิสระ และ variance ของผลรวมต้องการแค่ covariance เป็นศูนย์ ซึ่งอ่อนกว่าความเป็นอิสระ

รูปด้านล่างตอบคำถามของ desk ทั้งช่วง: แกนนอนคือ correlation ของสองสถานะ แกนตั้งคือส่วนเบี่ยงเบนมาตรฐานของกำไรรวม ค่าเฉลี่ย \$500 ไม่ขยับเลยไม่ว่าจุดจะอยู่ตรงไหน แต่ความเสี่ยงไล่ตั้งแต่ 0 ถึง \$200 และคำตอบ “บวก SD ตรง ๆ” คือจุดขวาสุดจุดเดียว

หน้านี้จะพิสูจน์แต่ละสูตรจาก joint density เพื่อชี้ให้เห็นบรรทัดที่ใช้เงื่อนไข แล้วนำไปใช้กับสามเรื่องจริง: ความผันผวนของผลตอบแทนหลายวัน มูลค่าที่เป็นผลคูณของจำนวนหุ้นสุ่มกับราคาสุ่ม และราคาปลายปีที่ค่าเฉลี่ยไม่เท่ากับค่ากลาง

ศัพท์ที่ใช้ในหัวข้อนี้
Linearity of expectation
$E[aX+bY+c]=aE[X]+bE[Y]+c$ จริงเสมอเมื่อค่าเฉลี่ยมีอยู่ ไม่ต้องอิสระ ใช้หาค่าเฉลี่ยของพอร์ตจากค่าเฉลี่ยรายตัว
Product rule ของค่าเฉลี่ย
$E[h(X)g(Y)]=E[h(X)]\,E[g(Y)]$ เมื่อ $X,Y$ อิสระ ใช้คำนวณมูลค่าที่เป็นผลคูณ เช่นจำนวนหุ้นคูณราคา หรือราคาที่ทบต้นหลายวัน
Covariance
$\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]$ วัดว่าสองตัวขยับไปด้วยกันเชิงเส้นแค่ไหน เป็นพจน์ไขว้ที่ทำให้ variance ของผลรวมไม่เท่ากับผลรวมของ variance
Indicator $\mathbf 1_A(X)$
ตัวแปรที่เป็น 1 เมื่อเหตุการณ์ $A$ เกิด และ 0 เมื่อไม่เกิด ค่าเฉลี่ยของมันคือโอกาสของ $A$ ใช้แปลงคำถามเรื่องโอกาสให้เป็นคำถามเรื่องค่าเฉลี่ย
Bienaymé identity
ชื่อของข้อเท็จจริงว่า variance ของผลรวมของตัวแปรที่ไม่สัมพันธ์กันเท่ากับผลรวมของ variance ใช้ขยายความผันผวนรายวันเป็นรายปีด้วยรากที่สองของจำนวนวัน
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$X,\ Y$กำไรรายวันของสองสถานะ (ช่วงแรก)ดอลลาร์
$a,\ b$ตัวคูณขนาดสถานะที่กำหนดตายตัวไม่มีหน่วย
$\sigma_X,\ \sigma_Y$ส่วนเบี่ยงเบนมาตรฐานดอลลาร์
$\operatorname{Var},\ \operatorname{Cov}$variance และ covarianceดอลลาร์กำลังสอง
$\rho$correlation $=\operatorname{Cov}(X,Y)/(\sigma_X\sigma_Y)$ไม่มีหน่วย
$r_i$log return ของวันที่ $i$ไม่มีหน่วย

ขั้นที่ 1 — ค่าเฉลี่ยของผลรวม: ไม่ต้องใช้ความเป็นอิสระ

ค่าเฉลี่ยของฟังก์ชันใด ๆ ของสองตัวแปรคือการถ่วงทุกคู่ผลลัพธ์ด้วย joint density เลือกฟังก์ชันเป็นผลรวม แล้วดูว่าเงื่อนไขใดถูกใช้บ้าง

\[\begin{aligned} E[X+Y]&=\iint(x+y)\,f_{X,Y}(x,y)\,dx\,dy\\ &=\int x\Big[\int f_{X,Y}(x,y)\,dy\Big]dx\\ &\quad+\int y\Big[\int f_{X,Y}(x,y)\,dx\Big]dy\\ &=\int x\,f_X(x)\,dx+\int y\,f_Y(y)\,dy\\ &=E[X]+E[Y],\\ E[aX+bY+c]&=aE[X]+bE[Y]+c. \end{aligned}\]

บรรทัดที่สองแยกอินทิกรัลตามเครื่องหมายบวก แล้วจัดลำดับให้อินทิกรัลชั้นในเป็นการรวมอีกแกนทิ้ง วงเล็บเหลี่ยมจึงเป็น marginal density ตามที่ได้ใน marginal distribution ไม่มีบรรทัดไหนแทน joint ด้วยผลคูณของ marginal สูตรนี้จึงใช้ได้แม้สองตัวพึ่งพากันมาก ตัวแปรไม่ต่อเนื่องก็เหมือนกัน แค่เปลี่ยนอินทิกรัลเป็นผลรวม

บรรทัดสุดท้ายดึง $a,b,c$ ออกเพราะเป็นค่าคงที่ ใช้กับ desk ได้ทันที: $E[X+Y]=300+200=\$500$ เงื่อนไขเดียวคือค่าเฉลี่ยของแต่ละตัวต้องมีอยู่ (ค่าเฉลี่ยของค่าสัมบูรณ์จำกัด) ถ้าขนาดสถานะ $a$ เองเป็นตัวแปรสุ่ม มันไม่ใช่ค่าคงที่อีกต่อไป และปัญหากลายเป็นค่าเฉลี่ยของผลคูณ ซึ่งคือขั้นถัดไป

ขั้นที่ 2 — ค่าเฉลี่ยของผลคูณ: ความเป็นอิสระเข้ามาตรงนี้

ทำแบบเดียวกันกับผลคูณ แล้วหาว่าบรรทัดไหนต้องใช้ความเป็นอิสระ

\[\begin{aligned} E[XY]&=\iint xy\,f_{X,Y}(x,y)\,dx\,dy\\ &=\iint xy\,f_X(x)\,f_Y(y)\,dx\,dy\\ &=\Big(\int x\,f_X(x)\,dx\Big)\Big(\int y\,f_Y(y)\,dy\Big)\\ &=E[X]\,E[Y],\\ E[h(X)\,g(Y)]&=E[h(X)]\,E[g(Y)]. \end{aligned}\]

บรรทัดที่สองคือบรรทัดเดียวที่ใช้ความเป็นอิสระ: แทน joint density ด้วยผลคูณของ marginal ตาม independence หลังจากนั้นอินทิกรัลสองชั้นแยกเป็นผลคูณของสองอินทิกรัลได้ เพราะตัวที่ถูกอินทิเกรตเป็น “ฟังก์ชันของ $x$ คูณฟังก์ชันของ $y$” ถ้าไม่อิสระ บรรทัดนี้ผิด และสูตรทั้งหมดพัง

บรรทัดสุดท้ายเป็นรูปทั่วไป: ใช้ได้กับฟังก์ชันใด ๆ เช่น $X^2$, $e^Y$ หรือ payoff ของ option ตราบเท่าที่ค่าเฉลี่ยที่ต้องใช้มีอยู่ ตัวอย่างที่สูตรพังเมื่อพึ่งพากัน: ถ้า $Y=X$ และ $X$ เป็น +1 หรือ −1 อย่างละครึ่ง จะได้ $E[XY]=E[X^2]=1$ แต่ $E[X]E[Y]=0$

อย่าอ่านกลับด้าน: $E[XY]=E[X]E[Y]$ จริงได้แม้ไม่อิสระ ตัวอย่าง $(X,X^2)$ ใน independence มี $E[X\cdot X^2]=0=E[X]E[X^2]$ ทั้งที่ตัวหนึ่งกำหนดอีกตัว ความเท่ากันของค่าเฉลี่ยคู่เดียวบอกแค่ว่า covariance เป็นศูนย์

ขั้นที่ 3 — เหตุการณ์คือฟังก์ชันชนิดหนึ่ง

สูตรผลคูณของค่าเฉลี่ยกับนิยามความเป็นอิสระด้วยโอกาสดูเหมือนคนละเรื่อง ขั้นนี้เชื่อมสองเรื่องเข้าด้วยกันด้วย indicator

\[\begin{aligned} P(a\lt X\le b,\ c\lt Y\le d)&=E\big[\mathbf 1_{A}(X)\,\mathbf 1_{B}(Y)\big]\\ &=E\big[\mathbf 1_{A}(X)\big]\,E\big[\mathbf 1_{B}(Y)\big]\\ &=P(a\lt X\le b)\,P(c\lt Y\le d). \end{aligned}\]

ให้ $\mathbf 1_A(X)$ เป็น 1 เมื่อ $X$ อยู่ในช่วง $A$ (ระหว่าง $a$ กับ $b$) และเป็น 0 เมื่อไม่อยู่ ผลคูณของ indicator สองตัวเป็น 1 ก็ต่อเมื่อทั้งสองเหตุการณ์เกิด ค่าเฉลี่ยของมันจึงเป็นโอกาสร่วม บรรทัดที่สองคือสูตรผลคูณของค่าเฉลี่ยด้านบน โดยเลือก $h=\mathbf 1_A$ และ $g=\mathbf 1_B$ ผลคือนิยามความเป็นอิสระด้วยโอกาสกลับมาเป็นกรณีพิเศษของสูตรค่าเฉลี่ย

ทางกลับก็จริง: ถ้าสูตรผลคูณใช้ได้กับ indicator ทุกคู่ช่วง ก็พิสูจน์ความเป็นอิสระได้ ต่างจากการตรวจแค่ $h(x)=x$ และ $g(y)=y$ ซึ่งบอกแค่ covariance ศูนย์ ยิ่งตรวจฟังก์ชันได้หลากหลาย ยิ่งเข้าใกล้ความเป็นอิสระ

ขั้นที่ 4 — variance ของผลรวม: พจน์ covariance ต้องอยู่จนกว่าจะรู้ค่า

กลับมาที่คำถามของ desk ขั้นนี้เปิดกำลังสองของผลรวมออกตรง ๆ แล้วดูว่าพจน์ไหนหายเมื่อใด

\[\begin{aligned} \operatorname{Var}(aX+bY)&=E\Big[\big(a(X-\mu_X)+b(Y-\mu_Y)\big)^2\Big]\\ &=a^2\sigma_X^2+b^2\sigma_Y^2\\ &\quad+2ab\operatorname{Cov}(X,Y),\\ \operatorname{Cov}(X,Y)&=E[(X-\mu_X)(Y-\mu_Y)]\\ &=E[XY]-E[X]\,E[Y],\\ \operatorname{SD}(X+Y)&=\sqrt{100^2+100^2+2\rho(100)(100)}\\ &=100\sqrt{2+2\rho}. \end{aligned}\]

บรรทัดแรกคือนิยามของ variance ใช้ค่าเฉลี่ยของ $aX+bY$ คือ $a\mu_X+b\mu_Y$ จาก linearity บรรทัดที่สองกระจายกำลังสอง $(u+v)^2=u^2+v^2+2uv$ แล้วใช้ linearity กับแต่ละพจน์ พจน์ไขว้คือ $2ab$ คูณ covariance บรรทัดที่สามกระจาย $(X-\mu_X)(Y-\mu_Y)$ แล้วใช้ linearity อีกครั้ง

เมื่อสองตัวอิสระ สูตรผลคูณให้ $E[XY]=E[X]E[Y]$ covariance จึงเป็นศูนย์และ variance บวกกันได้ แต่สิ่งที่ต้องการจริง ๆ คือ covariance ศูนย์ เท่านั้น ซึ่งอ่อนกว่าความเป็นอิสระ บรรทัดสุดท้ายแทนตัวเลข desk โดยเขียน covariance เป็น $\rho\sigma_X\sigma_Y$: $\rho=0$ ได้ 141.42, $\rho=0.5$ ได้ $100\sqrt3=173.21$, $\rho=1$ ได้ 200

อีกตัวอย่างหนึ่งที่มีน้ำหนักไม่เท่ากัน: $a=2,\ b=1,\ \sigma_X=\$30,\ \sigma_Y=\$40$ และ covariance ศูนย์ ได้ variance $4(900)+1600=5200$ ดอลลาร์กำลังสอง SD $\sqrt{5200}=\$72.11$ ไม่ใช่ $2(30)+40=\$100$ สังเกตว่าน้ำหนักเข้าไปเป็นกำลังสอง เพราะ variance มีหน่วยกำลังสอง

ขั้นที่ 5 — หลายวัน: variance โตตามจำนวนวัน ส่วนเบี่ยงเบนโตตามราก

สูตร variance ของผลรวมขยายไปกี่ตัวก็ได้ การใช้ที่สำคัญที่สุดคือแปลงความผันผวนรายวันเป็นรายปี

โจทย์ให้อะไรมาบ้าง: log return รายวันของหุ้นตัวหนึ่ง (สมมติ) มีค่าเฉลี่ย 0.04% และส่วนเบี่ยงเบน 1.1% ปีหนึ่งมีประมาณ 252 วันซื้อขาย (365 วันปฏิทินหักเสาร์อาทิตย์ 104 วันและวันหยุดตลาดราว 9 วัน) log return ทั้งปีคือผลรวม $r_1+\cdots+r_{252}$ สมมติว่าผลตอบแทนต่างวันไม่สัมพันธ์กัน

\[\begin{aligned} E\Big[\sum_{i=1}^{252}r_i\Big]&=252(0.0004)=0.1008,\\ \operatorname{Var}\Big(\sum_{i=1}^{252}r_i\Big)&=\sum_{i=1}^{252}\operatorname{Var}(r_i)\\ &=252(0.011^2)=0.030492,\\ \operatorname{SD}&=0.011\sqrt{252}=0.1746. \end{aligned}\]

คำตอบ: ค่าเฉลี่ยทั้งปี 10.08% ส่วนเบี่ยงเบนทั้งปี 17.46% บรรทัดแรกใช้ linearity ซึ่งไม่ต้องการเงื่อนไขอะไร บรรทัดที่สองต้องการให้ covariance ของทุกคู่วันเป็นศูนย์ พจน์ไขว้ $252\times251$ พจน์จึงหายหมด ค่าเฉลี่ยโตตามจำนวนวัน แต่ส่วนเบี่ยงเบนโตตามรากที่สองของจำนวนวัน นี่คือที่มาของกฎ “คูณ $\sqrt{252}$”

ตรวจเองใน 10 วินาที: ถ้าผลตอบแทนวันติดกันมี correlation 0.1 (และวันที่ห่างกันกว่านั้นไม่สัมพันธ์) จะมีพจน์ไขว้เพิ่ม $2\times251\times0.1\times0.011^2$ variance เป็น $0.011^2(252+50.2)$ ส่วนเบี่ยงเบน 19.12% แทน 17.46% สมมติฐาน “ไม่สัมพันธ์” จึงมีราคา

ขั้นที่ 6 — ผลคูณของจำนวนหุ้นสุ่มกับตัวคูณราคาสุ่ม

มูลค่าพอร์ตคือจำนวนหุ้นคูณราคา ถ้าทั้งสองสุ่ม ค่าเฉลี่ยของมูลค่าต้องใช้สูตรผลคูณ และ variance ต้องใช้ second moment ขั้นนี้ทำครบทั้งสองอย่าง

โจทย์ให้อะไรมาบ้าง: (สมมติ) จำนวนหุ้นที่ได้รับจัดสรร $X$ หน่วยพันหุ้น เป็น 5 ด้วยโอกาส 0.2 และเป็น 0 ด้วยโอกาส 0.8 จึงมี $E[X]=1$ และ $E[X^2]=5$ ราคาเปลี่ยนด้วยตัวคูณ $e^Y$ โดย log return $Y$ เป็น normal มาตรฐาน และ $X$ อิสระจาก $Y$ ให้ $V=Xe^Y$ คือมูลค่าในหน่วยพันหุ้นที่ราคาต้นงวด

\[\begin{aligned} E[e^{tY}]&=\int\frac{e^{ty-y^2/2}}{\sqrt{2\pi}}\,dy,\\ ty-\tfrac{y^2}{2}&=-\tfrac{(y-t)^2}{2}+\tfrac{t^2}{2},\\ E[e^{tY}]&=e^{t^2/2}\int\frac{e^{-(y-t)^2/2}}{\sqrt{2\pi}}\,dy=e^{t^2/2},\\ E[V]&=E[X]\,E[e^Y]=1\cdot e^{1/2}=1.6487,\\ E[V^2]&=E[X^2]\,E[e^{2Y}]=5e^2,\\ \operatorname{Var}(V)&=5e^2-e=34.227,\\ \operatorname{SD}(V)&=5.850. \end{aligned}\]

คำตอบ: บรรทัดที่สองเติมกำลังสองสมบูรณ์ในเลขชี้กำลัง อินทิกรัลที่เหลือเป็นพื้นที่ใต้ density ของ normal ที่ค่าเฉลี่ย $t$ จึงเท่ากับ 1 สองบรรทัดถัดไปใช้สูตรผลคูณของค่าเฉลี่ยกับ $h(X)=X$, $g(Y)=e^Y$ และกับ $X^2$, $e^{2Y}$ (ซึ่งยังอิสระกันเพราะเป็นฟังก์ชันของตัวแปรที่อิสระกัน) ถ้าราคาต้นงวด \$100 ต่อหุ้น มูลค่าเป็นดอลลาร์คือ $100\times1000\times V$ ค่าเฉลี่ย \$164,872 ส่วนเบี่ยงเบน \$585,038

ตรวจเองใน 10 วินาที: $E[e^Y]=1.6487$ ไม่ใช่ $e^{E[Y]}=e^0=1$ เพราะ $e^y$ โค้งหงาย วันที่ $Y$ บวกดันค่าขึ้นมากกว่าวันที่ $Y$ ลบดึงลง ผลเดียวกันนี้คือที่มาของค่าเฉลี่ย $e^{\mu+\sigma^2/2}$ ของ lognormal distribution

ขั้นที่ 7 — ราคาปลายปี: ค่าเฉลี่ยไม่เท่ากับค่ากลาง

ราคาที่ทบต้นหลายวันคือผลคูณของตัวคูณรายวัน สูตรผลคูณของหลายตัวที่อิสระร่วมกันทำให้หาค่าเฉลี่ยได้ทันที

โจทย์ให้อะไรมาบ้าง: ราคาต้นปี \$100 log return รายวัน 252 วันอิสระร่วมกัน แต่ละวันเป็น normal ค่าเฉลี่ย 0.0004 ส่วนเบี่ยงเบน 0.011 (แบบจำลองเดียวกับตอนแปลงความผันผวนรายวันเป็นรายปี ไม่รวมปันผล)

\[\begin{aligned} S_T&=100\prod_{i=1}^{252}e^{r_i},\\ E[S_T]&=100\prod_{i=1}^{252}E[e^{r_i}]\\ &=100\,e^{252(0.0004+0.011^2/2)}\\ &=100\,e^{0.116046}=112.30,\\ \operatorname{median}(S_T)&=100\,e^{0.1008}=110.61. \end{aligned}\]

คำตอบ: ค่าเฉลี่ยของราคาปลายปี \$112.30 แต่ค่ากลาง \$110.61 บรรทัดที่สองแยกผลคูณเพราะทุกวันอิสระร่วมกัน บรรทัดที่สามใช้ $E[e^{r}]=e^{\mu+\sigma^2/2}$ ซึ่งได้จาก $E[e^{tZ}]=e^{t^2/2}$ ของ normal มาตรฐานด้านบน โดยแทน $r=\mu+\sigma Z$ ค่ากลางมาจากผลรวม log return ซึ่งเป็น normal ค่าเฉลี่ย 0.1008 มีค่ากลางเท่ากับค่าเฉลี่ย และ $e^x$ เป็นฟังก์ชันเพิ่ม จึงส่งค่ากลางต่อได้ตรง ๆ

ตรวจเองใน 10 วินาที: ส่วนต่างของเลขชี้กำลังคือ $252\times0.011^2/2=0.015246$ คือครึ่งหนึ่งของ variance ทั้งปี 0.030492 ค่าเฉลี่ยจึงสูงกว่าค่ากลางราว 1.5% และโอกาสที่ราคาปลายปีต่ำกว่า \$100 คือ $\Phi(-0.1008/0.1746)=\Phi(-0.577)=28.2\%$

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

บวกส่วนเบี่ยงเบนแทน variance: 100 บวก 100 ได้ \$200 แต่ถ้าสองสถานะไม่สัมพันธ์กัน ค่าจริงคือ \$141.42 สูงไป 41% การบวก SD ถูกเฉพาะเมื่อ correlation เป็น 1

ละพจน์ covariance โดยไม่ตรวจ: ที่ correlation 0.5 ค่าจริงคือ \$173.21 ถ้าละพจน์ไขว้จะได้ \$141.42 ต่ำไป 18% เครื่องหมายของผลกระทบขึ้นกับ $ab\operatorname{Cov}(X,Y)$: ถ้าสถานะหนึ่ง long อีกสถานะ short ($ab\lt0$) covariance บวกกลับลดความเสี่ยง

แทน $E[e^Y]$ ด้วย $e^{E[Y]}$: ได้ 1 แทน 1.6487 ในตัวอย่างจำนวนหุ้นสุ่ม และได้ \$110.61 แทน \$112.30 ในตัวอย่างราคาปลายปี ความผิดนี้ประเมินค่าเฉลี่ยของสิ่งที่เป็นฟังก์ชันโค้งหงายต่ำไปเสมอ

คูณ variance ของผลคูณ: $\operatorname{Var}(X)\operatorname{Var}(e^Y)=4\times(e^2-e)=18.68$ ไม่ใช่ 34.23 สูตรนี้ทิ้งผลของค่าเฉลี่ยทั้งสองตัว ต้องเริ่มจาก $E[V^2]-(E[V])^2$ เสมอ

ใช้ $\sqrt{252}$ กับผลตอบแทนที่สัมพันธ์ข้ามวัน: correlation 0.1 ระหว่างวันติดกันทำให้ความผันผวนทั้งปีเป็น 19.12% ไม่ใช่ 17.46%

ใช้สูตรผลคูณเมื่อขนาดสถานะขึ้นกับผลตอบแทน: ถ้า desk เพิ่มสถานะหลังจากราคาขึ้น จำนวนหุ้นกับผลตอบแทนไม่อิสระกัน $E[XY]$ ต้องคำนวณจาก joint distribution จริง ไม่ใช่จากผลคูณของค่าเฉลี่ย

ใช้ทำอะไรบนโต๊ะจริง

ทุกครั้งที่ desk คำนวณความเสี่ยงของพอร์ตจากความเสี่ยงรายตัว คือการใช้สูตร variance ของผลรวมซ้ำกับทุกคู่ ซึ่งเขียนเป็น matrix ได้กระชับใน linear transformations และความเสี่ยงพอร์ต การแปลงความผันผวนรายวันเป็นรายปีใช้ราก 252 แบบด้านบน และการตั้งราคาสิ่งที่ขึ้นกับราคาทบต้น เช่นค่าเฉลี่ยของราคาใน GBM ที่มี drift μ ใช้สูตรผลคูณแบบราคาปลายปี จุดที่ต้องระวังคือแยกให้ออกว่ากำลังใช้เงื่อนไขระดับไหน: ค่าเฉลี่ยรวมไม่ต้องสนใจโครงสร้างร่วม แต่ความเสี่ยงรวมขึ้นกับมันทั้งหมด

โจทย์ตรวจความเข้าใจ

1. สองสถานะของ desk มีค่าเฉลี่ย \$300 และ \$200 ส่วนเบี่ยงเบน \$100 ทั้งคู่ ถ้า correlation เป็น −0.5 จงหาค่าเฉลี่ยและส่วนเบี่ยงเบนของกำไรรวม และถ้าถือสถานะแรกสองเท่า ($a=2,\ b=1$) ที่ correlation 0.5 ล่ะ

เฉลย

ค่าเฉลี่ยยังเป็น \$500 covariance $=-0.5(100)(100)=-5000$ variance $10000+10000-10000=10000$ ส่วนเบี่ยงเบน \$100 กรณีที่สอง: ค่าเฉลี่ย $2(300)+200=\$800$ variance $4(10000)+10000+2(2)(1)(0.5)(100)(100)=40000+10000+20000=70000$ ส่วนเบี่ยงเบน $\sqrt{70000}=\$264.58$

2. ให้ $X,Y$ อิสระกัน มีค่าเฉลี่ย $\mu_X,\mu_Y$ และส่วนเบี่ยงเบน $\sigma_X,\sigma_Y$ จงหา $\operatorname{Var}(XY)$ แล้วตรวจกับตัวอย่างจำนวนหุ้นสุ่มคูณตัวคูณราคา

เฉลย
\[\begin{aligned} \operatorname{Var}(XY)&=E[X^2]\,E[Y^2]-(\mu_X\mu_Y)^2\\ &=(\sigma_X^2+\mu_X^2)(\sigma_Y^2+\mu_Y^2)-\mu_X^2\mu_Y^2\\ &=\sigma_X^2\sigma_Y^2+\sigma_X^2\mu_Y^2+\mu_X^2\sigma_Y^2. \end{aligned}\]

บรรทัดแรกใช้สูตรผลคูณกับ $X^2$ และ $Y^2$ ตรวจ: ตัวอย่างจำนวนหุ้นสุ่มมี $\sigma_X^2=4,\ \mu_X=1$ และสำหรับ $e^Y$: $\mu=e^{0.5}$, $\sigma^2=e^2-e=4.671$ ได้ $4(4.671)+4(e)+1(4.671)=18.683+10.873+4.671=34.227$ ตรงกัน พจน์ $\sigma_X^2\sigma_Y^2$ คือส่วนที่การคูณ variance ตรง ๆ ได้ สองพจน์ที่เหลือคือสิ่งที่มันลืม

3. ถ้ารู้แค่ว่า $E[XY]=E[X]E[Y]$ จะสรุปว่า $X,Y$ อิสระกันได้ไหม และจะใช้สูตร variance ของผลรวมแบบไม่มีพจน์ไขว้ได้ไหม

เฉลย

สรุปความเป็นอิสระไม่ได้ ตัวอย่าง $X$ uniform บน −1 ถึง 1 กับ $Y=X^2$ ใน independence มีความเท่ากันนี้แต่ตัวหนึ่งกำหนดอีกตัว แต่ใช้สูตร variance ของผลรวมได้ เพราะความเท่ากันนี้คือ covariance ศูนย์พอดี ซึ่งเป็นเงื่อนไขเดียวที่สูตรนั้นต้องการ

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
// 1) desk: two positions, SD 100 each, mean 300 and 200
const sdTotal = rho => Math.sqrt(100**2 + 100**2 + 2 * rho * 100 * 100);
console.log([-1, -0.5, 0, 0.5, 1].map(r => [r, +sdTotal(r).toFixed(2)]));
// [-1,0] [-0.5,100] [0,141.42] [0.5,173.21] [1,200]
console.log({ weighted: Math.sqrt(4 * 30**2 + 40**2) });          // 72.11

// 2) daily to yearly: 252 trading days
const mu = 0.0004, s = 0.011, n = 252;
console.log({ yearMean: n * mu, yearSD: s * Math.sqrt(n),        // 0.1008, 0.1746
  withLag1Corr: s * Math.sqrt(n + 2 * (n - 1) * 0.1) });         // 0.1912

// 3) E[e^{tY}] for standard normal Y by midpoint integration
const phi = y => Math.exp(-y * y / 2) / Math.sqrt(2 * Math.PI);
const integrate = (g, a, b, m = 40000) => {
  let t = 0; const h = (b - a) / m;
  for (let i = 0; i < m; i++) t += g(a + (i + .5) * h) * h;
  return t;
};
const e1 = integrate(y => Math.exp(y) * phi(y), -12, 12);       // e^0.5
const e2 = integrate(y => Math.exp(2 * y) * phi(y), -12, 12);   // e^2
const EX = .2 * 5, EX2 = .2 * 25;                                 // 1, 5
const meanV = EX * e1, varV = EX2 * e2 - meanV ** 2;
console.log({ e1, e2, meanV, varV, sdV: Math.sqrt(varV),
  dollarMean: 1e5 * meanV, dollarSD: 1e5 * Math.sqrt(varV),
  wrongProductOfVariances: (EX2 - EX ** 2) * (e2 - e1 ** 2) });  // 18.68

// 4) year-end price: mean vs median
const yearVar = n * s * s;
console.log({ mean: 100 * Math.exp(n * mu + yearVar / 2),       // 112.30
  median: 100 * Math.exp(n * mu) });                             // 110.61

สิ่งที่ควรตอบได้หลังอ่าน

  • $E[aX+bY+c]=aE[X]+bE[Y]+c$ จริงเสมอ: กำไรรวมเฉลี่ย \$500 ไม่ว่า correlation เป็นเท่าไร
  • $E[h(X)g(Y)]=E[h(X)]E[g(Y)]$ ต้องใช้ความเป็นอิสระที่บรรทัด “แทน joint ด้วยผลคูณ” และความเท่ากันของค่าเฉลี่ยคู่เดียวไม่พิสูจน์ความเป็นอิสระ
  • variance ของผลรวมมีพจน์ $2ab\operatorname{Cov}(X,Y)$ ซึ่งหายเมื่อ covariance เป็นศูนย์: SD รวม 141.42 ที่ $\rho=0$ ไม่ใช่ 200
  • ผลตอบแทนที่ไม่สัมพันธ์ข้ามวันให้ส่วนเบี่ยงเบนรายปี $0.011\sqrt{252}=17.46\%$ แต่ correlation 0.1 ระหว่างวันติดกันดันขึ้นเป็น 19.12%
  • ผลคูณสุ่มต้องหา second moment ก่อน และค่าเฉลี่ยของราคาทบต้นสูงกว่าค่ากลาง (\$112.30 กับ \$110.61) เพราะ $E[e^Y]\gt e^{E[Y]}$

หน้านี้ใช้ความเป็นอิสระแบบไม่มีเงื่อนไข แต่ในเครดิต ลูกหนี้สองรายแทบไม่เคยอิสระกันจริง เพราะเผชิญเศรษฐกิจเดียวกัน หน้าถัดไป conditional independence และ Gaussian copula แสดงวิธีที่ desk เครดิตใช้: สมมติว่าอิสระกันเมื่อรู้ภาวะเศรษฐกิจแล้ว แล้วเฉลี่ยข้ามภาวะ
