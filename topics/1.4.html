1.4 Variance and Standard Deviation

Variance วัดว่าผลจริงอยู่ห่างจากค่าเฉลี่ยแค่ไหน โดยเอาระยะห่างมายกกำลังสองแล้วเฉลี่ย ส่วน standard deviation คือรากที่สองของ variance ซึ่งกลับมาอยู่ในหน่วยเดียวกับข้อมูล

ผู้จัดการพอร์ตต้องเลือกวิธีหาเงินหนึ่งในสองทาง ทั้งสองทางได้เงินเฉลี่ยเท่ากัน แต่เขากลัวอยู่เรื่องหนึ่ง คือทำงานมาทั้งปีแล้วผลรวมยังติดลบ

  • ทาง A: ได้ \$50 ทุกครั้งแน่นอน ไม่มากไม่น้อยกว่านี้
  • ทาง B: กลยุทธ์ซื้อขายหุ้น TSLA จากหน้า PMF แต่ละครั้งจบได้สามแบบ คือเสีย \$1,000 (โอกาส 55%) เท่าทุน (โอกาส 15%) หรือได้ \$2,000 (โอกาส 30%)

ค่าเฉลี่ยต่อครั้งของทาง B เรียกว่า $\mu_B$ คิดแบบถ่วงโอกาสตามหน้า expected value ได้เท่ากับทาง A พอดี

\[\begin{aligned} \mu_B&=(-1{,}000)(0.55)+0(0.15)\\ &\quad+2{,}000(0.30)\\ &=-550+0+600=\$50 \end{aligned}\]

สมมติว่าเลือกทาง B แล้วทำซ้ำ 1,000 ครั้ง ซึ่งใกล้กับจำนวนครั้งในหนึ่งปีที่หน้า expected value นับได้ ($4\times252=1{,}008$ ครั้ง) โอกาสที่ผลรวมทั้ง 1,000 ครั้งติดลบมีเท่าไร

ลองตอบก่อนเปิดเฉลย

ประมาณ 11% ทั้งที่ทุกครั้งได้เปรียบ หน้านี้จะคำนวณทุกตัวเลขด้านล่างให้ดูทีละขั้น ภาพรวมเป็นแบบนี้

  • ผลรวม 1,000 ครั้งคาดว่าได้ $1{,}000\times\$50=\$50{,}000$
  • แต่ผลจริงแกว่งรอบ \$50,000 ด้วย standard deviation ราว \$41,803 (standard deviation คือระยะที่ผลจริงมักอยู่ห่างจากค่าเฉลี่ย)
  • ศูนย์จึงอยู่ต่ำกว่าค่าเฉลี่ยแค่ $50{,}000/41{,}803\approx1.2$ เท่าของ standard deviation ซึ่งไม่ไกลเลย

ถ้าประมาณด้วยระฆัง normal (รูปทรงระฆังที่ผลรวมของการสุ่มหลายครั้งมักออกมาเป็น) จะได้โอกาสติดลบ 11.58% ถ้านับทุกกรณีตรง ๆ ได้ 11.32% ส่วนทาง A ไม่มีวันติดลบ ค่าเฉลี่ยมองไม่เห็นความต่างนี้ เราจึงต้องมีตัวเลขที่วัดการกระจาย ตัวเลขนั้นคือ variance

ภาพรวมก่อนลงสูตร

expected value บอกว่าจุดศูนย์กลางของผลอยู่ตรงไหน แต่ไม่บอกว่าผลจริงอยู่ห่างจากจุดนั้นแค่ไหน ทาง A กับทาง B มีจุดศูนย์กลางที่ \$50 เหมือนกัน ทาง A ไม่เคยห่างจาก \$50 เลย ส่วนทาง B มักห่างเป็นพันดอลลาร์ ครั้งที่เสีย \$1,000 อยู่ห่าง $50-(-1{,}000)=\$1{,}050$ และครั้งที่ได้ \$2,000 อยู่ห่าง $2{,}000-50=\$1{,}950$ เราต้องการตัวเลขตัวเดียวที่สรุปความห่างนี้

วิธีมาตรฐานคือวัดระยะของแต่ละผลจากค่าเฉลี่ย ยกกำลังสอง แล้วเฉลี่ยแบบถ่วงโอกาส ผลที่ได้เรียกว่า variance ทำไมต้องยกกำลังสอง มีสองเหตุผล ข้อแรก ระยะฝั่งบวกกับฝั่งลบจะไม่หักล้างกัน ข้อสอง ถ้าผลแต่ละครั้งอิสระกัน (รู้ผลครั้งหนึ่งแล้วไม่ได้บอกอะไรเกี่ยวกับอีกครั้ง) variance ของผลรวมจะเท่ากับ variance ของแต่ละครั้งบวกกันตรง ๆ เล่มนี้ใช้สมบัตินี้ทุกบท

ราคาที่ต้องจ่ายคือหน่วยกลายเป็นกำลังสอง เช่น ดอลลาร์กำลังสอง ซึ่งไม่มีใครเข้าใจ เราจึงถอดรากกลับ ได้ standard deviation ที่มีหน่วยเดียวกับข้อมูล

เพื่อให้ตัวเลขเล็กและอ่านง่าย หน้านี้คิดเป็นหน่วย R เหมือนหน้า PMF โดย 1R = \$1,000 คือเงินที่แผนซื้อขายยอมเสียต่อครั้ง ผลสามแบบของทาง B จึงเป็น −1R, 0R และ +2R ส่วนค่าเฉลี่ยต่อครั้งคือ $\mu=\$50/\$1{,}000=0.05R$ ถ้าอยากได้ดอลลาร์กลับมา ก็คูณด้วย \$1,000

หน้านี้จะไปทีละขั้น ลองวิธีที่ง่ายที่สุดก่อนแล้วดูว่าพังตรงไหน สร้างนิยามของ variance และคำนวณสองวิธี ดูว่าการขยายขนาดการซื้อขายเปลี่ยนตัวเลขอย่างไร หา variance ของผลรวมซึ่งต้องมี covariance แล้วใช้กฎ “ค่าเฉลี่ยโตตามจำนวนครั้ง $n$ แต่ standard deviation โตแค่ตาม $\sqrt n$” ตอบคำถามของผู้จัดการ

ขั้นที่ 1 — เฉลี่ยระยะห่างตรง ๆ ได้ศูนย์เสมอ

เราอยากได้ตัวเลขตัวเดียวที่บอกว่าผลของทาง B อยู่ห่างจากค่าเฉลี่ยแค่ไหน ความคิดแรกที่ตรงที่สุดคือ เอาแต่ละผลลบค่าเฉลี่ยให้ได้ระยะห่าง แล้วเฉลี่ยระยะเหล่านั้นแบบถ่วงโอกาส ให้ $X$ คือผลของการซื้อขายหนึ่งครั้งในหน่วย R และ $\mu=0.05$ คือค่าเฉลี่ยของมัน ลองทำดู

\[\begin{aligned} -1-0.05&=-1.05\\ 0-0.05&=-0.05\\ 2-0.05&=+1.95\\[4pt] \mathbb E[X-\mu]&=(-1.05)(0.55)\\ &\quad+(-0.05)(0.15)\\ &\quad+(1.95)(0.30)\\ &=-0.5775-0.0075+0.585\\ &=0\\[4pt] \mathbb E[X-\mu]&=\mathbb E[X]-\mu\\ &=\mu-\mu=0 \end{aligned}\]

ผลออกมาเป็นศูนย์พอดี และจะเป็นศูนย์เสมอ ไม่ว่าผลจะกระจายกว้างแค่ไหน เหตุผลคือค่าเฉลี่ยเป็นจุดสมดุลของผลทั้งหมด เหมือนจุดหมุนของไม้กระดกในหน้า expected value ระยะฝั่งลบที่ถ่วงโอกาสแล้ว ($-0.5775-0.0075=-0.585$) จึงหักล้างกับระยะฝั่งบวกที่ถ่วงโอกาสแล้ว ($+0.585$) พอดี

จังหวะที่อาจสะดุดคือการแยก $\mathbb E[X-\mu]$ ออกเป็น $\mathbb E[X]-\mu$ ทำได้เพราะ $\mu$ เป็นตัวเลขคงที่ ไม่ได้สุ่ม ค่าเฉลี่ยของตัวเลขคงที่ก็คือตัวมันเอง (นี่คือ linearity จากหน้า expected value) สรุปว่าการเฉลี่ยระยะตรง ๆ ใช้วัดการกระจายไม่ได้ เราต้องวัดขนาดของระยะโดยไม่สนเครื่องหมาย

ขั้นที่ 2 — ยกกำลังสองแล้วเฉลี่ย: นิยามของ variance

ทางแก้คือยกกำลังสองระยะก่อนเฉลี่ย กำลังสองทำให้ทุกระยะเป็นบวก จึงหักล้างกันไม่ได้อีก และยังให้น้ำหนักกับผลที่อยู่ไกลมากกว่าผลที่อยู่ใกล้ ผลที่อยู่ไกลกว่า 2 เท่าจะมีส่วนมากกว่า $2^2=4$ เท่า ซึ่งตรงกับความรู้สึกของคนดูแลความเสี่ยง ที่กลัวผลไกล ๆ มากกว่าผลใกล้ ๆ ค่าเฉลี่ยของระยะยกกำลังสองนี้คือนิยามของ variance เครื่องหมาย $\equiv$ ด้านล่างแปลว่า “นิยามว่า”

\[\begin{aligned} \mathrm{Var}(X)&\equiv\mathbb E\big[(X-\mu)^2\big]\\[4pt] (-1.05)^2&=1.1025\\ (-0.05)^2&=0.0025\\ (1.95)^2&=3.8025\\[4pt] \mathrm{Var}(X)&=1.1025(0.55)+0.0025(0.15)\\ &\quad+3.8025(0.30)\\ &=0.606375+0.000375\\ &\quad+1.14075\\ &=\boxed{1.7475\ R^2} \end{aligned}\]

แต่ละพจน์คือพื้นที่ของสี่เหลี่ยมจัตุรัสที่มีด้านยาวเท่าระยะห่าง คูณด้วยโอกาสของผลนั้น ดูได้จากรูปด้านล่าง ผล +2R อยู่ไกลที่สุด สี่เหลี่ยมของมันจึงใหญ่ที่สุด มันให้ variance ถึง $1.14075/1.7475\approx65\%$ ทั้งที่โอกาสมีแค่ 0.30 ส่วนผล 0R อยู่ใกล้ค่าเฉลี่ยมาก จึงแทบไม่มีส่วนเลย หน่วย R² อ่านว่า R กำลังสอง

คำถามที่ควรถามคือ ทำไมไม่ใช้ค่าสัมบูรณ์ $|X-\mu|$ ซึ่งก็ไม่สนเครื่องหมายเหมือนกันและดูตรงกว่า คำตอบคือค่าสัมบูรณ์บวกข้ามผลรวมไม่ได้ แต่กำลังสองบวกได้ ลองดูเหรียญสองเหรียญที่อิสระกัน แต่ละเหรียญให้ +1 หรือ −1 อย่างละครึ่ง ค่าเฉลี่ยของแต่ละเหรียญจึงเป็นศูนย์ และแต่ละเหรียญมี $|\pm1|=1$ กับ $(\pm1)^2=1$ เท่ากัน สองเหรียญออกได้สี่แบบที่โอกาสเท่ากัน คือ (+1, +1), (+1, −1), (−1, +1) และ (−1, −1) ผลรวม $S$ จึงเป็น −2, 0 หรือ +2 ด้วยโอกาส 1/4, 2/4 = 1/2 และ 1/4

\[\begin{aligned} \mathbb E|S|&=2(\tfrac14)+0(\tfrac12)+2(\tfrac14)\\ &=1\ne1+1\\[4pt] \mathbb E[S^2]&=4(\tfrac14)+0(\tfrac12)+4(\tfrac14)\\ &=2=1+1 \end{aligned}\]

ค่าสัมบูรณ์เฉลี่ยของผลรวมได้ 1 ไม่ใช่ $1+1=2$ เพราะบางครั้งสองเหรียญหักล้างกัน แต่กำลังสองเฉลี่ยได้ 2 พอดี สมบัติ “บวกกันได้” นี้คือเหตุผลหลักที่ทั้งวงการใช้ variance

ขั้นที่ 3 — สูตรลัด: ค่าเฉลี่ยของกำลังสอง ลบ กำลังสองของค่าเฉลี่ย

วิธีในขั้นที่แล้วต้องหาระยะห่างของทุกผลก่อน ถ้ามีผลเป็นร้อยแบบก็เหนื่อย และบางครั้งเรารู้ค่าเฉลี่ยของ $X^2$ อยู่แล้ว จึงมีสูตรที่เร็วกว่า สูตรนี้ได้จากการกางกำลังสอง $(X-\mu)^2=X^2-2\mu X+\mu^2$ ออก แล้วเฉลี่ยทีละพจน์

\[\begin{aligned} \mathrm{Var}(X)&=\mathbb E[X^2-2\mu X+\mu^2]\\ &=\mathbb E[X^2]-2\mu\,\mathbb E[X]+\mu^2\\ &=\mathbb E[X^2]-2\mu^2+\mu^2\\ &=\mathbb E[X^2]-\mu^2\\[4pt] \mathbb E[X^2]&=1(0.55)+0(0.15)+4(0.30)\\ &=1.75\\ \mathrm{Var}(X)&=1.75-0.05^2=1.7475 \end{aligned}\]

สูตรลัดบอกว่า variance คือ “ค่าเฉลี่ยของกำลังสอง ลบด้วยกำลังสองของค่าเฉลี่ย” จังหวะสำคัญคือตอนเฉลี่ยทีละพจน์ $2\mu$ และ $\mu^2$ เป็นตัวเลขคงที่ จึงดึงออกจาก $\mathbb E$ ได้ตาม linearity พอแทน $\mathbb E[X]=\mu$ ก็ได้ $-2\mu^2+\mu^2=-\mu^2$ ส่วน $\mathbb E[X^2]$ คือค่าเฉลี่ยของ $(-1)^2=1$, $0^2=0$ และ $2^2=4$ ถ่วงด้วยโอกาส ทั้งสองวิธีได้ 1.7475 ตรงกัน จึงใช้ตรวจกันเองได้

ระวังอย่าสับสน $\mathbb E[X^2]=1.75$ กับ $(\mathbb E[X])^2=0.05^2=0.0025$ สองตัวนี้ห่างกันมาก และจะเท่ากันได้ก็ต่อเมื่อ variance เป็นศูนย์ คือผลไม่กระจายเลย เหมือนทาง A อีกเรื่องหนึ่งเกิดบนคอมพิวเตอร์ ถ้าข้อมูลมีค่าใหญ่แต่แกว่งนิดเดียว $\mathbb E[X^2]$ กับ $\mu^2$ จะใหญ่และใกล้กันมาก การลบสองตัวนี้ทำให้ทศนิยมหลักท้าย ๆ หายไป โปรแกรมสถิติจึงมักคำนวณตามนิยามแทน

ขั้นที่ 4 — standard deviation และผลของการเปลี่ยนขนาด

variance 1.7475 R² อ่านเป็นเงินไม่ได้ เพราะหน่วยเป็นกำลังสอง ไม่มีใครพูดว่า “เสี่ยง 1.7475 R กำลังสอง” เราจึงถอดรากกลับมาเป็นหน่วยเดิม แล้วถามต่อว่า ถ้าขยายขนาดการซื้อขาย หรือหักค่าใช้จ่ายคงที่ทุกครั้ง ตัวเลขนี้เปลี่ยนอย่างไร ให้ $a$ คือตัวคูณขนาด และ $b$ คือค่าคงที่ที่บวกเพิ่มทุกครั้ง ($b$ ติดลบถ้าเป็นค่าใช้จ่าย) ค่าเฉลี่ยของ $aX+b$ คือ $a\mu+b$ ตามหน้า expected value

\[\begin{aligned} \sigma&\equiv\sqrt{\mathrm{Var}(X)}\\ &=\sqrt{1.7475}\approx 1.3219R\\[4pt] \mathrm{Var}(aX+b)&=\mathbb E\big[(aX+b-a\mu-b)^2\big]\\ &=\mathbb E\big[a^2(X-\mu)^2\big]\\ &=a^2\,\mathrm{Var}(X)\\ \mathrm{SD}(aX+b)&=|a|\,\sigma\\[4pt] \mathrm{SD}(1{,}000X-20)&=1{,}000\times1.32193\\ &\approx\$1{,}321.93 \end{aligned}\]

การบวกค่าคงที่ $b$ เลื่อนทั้งผลและค่าเฉลี่ยไปเท่ากัน $b$ จึงตัดกันหายในวงเล็บ และระยะห่างไม่เปลี่ยน ค่าใช้จ่ายคงที่ทุกครั้งจึงไม่เปลี่ยนการกระจายเลย ส่วนการคูณด้วย $a$ ยืดทุกระยะออก $a$ เท่า พื้นที่สี่เหลี่ยมจึงโต $a^2$ เท่า และ standard deviation โต $|a|$ เท่า ต้องใส่ค่าสัมบูรณ์เพราะ standard deviation ติดลบไม่ได้ แม้ $a$ จะติดลบ เช่น ถือสถานะกลับด้าน

ในตัวอย่างนี้ ผลเป็นดอลลาร์คือ $1{,}000X$ เพราะ 1R = \$1,000 ถ้าหักค่าใช้จ่าย \$20 ต่อครั้งเหมือนในหน้า expected value จะได้ $1{,}000X-20$ คือ $a=1{,}000$ และ $b=-20$ ทีนี้เทียบสองตัวเลขต่อครั้งก่อนหักค่าใช้จ่าย ค่าเฉลี่ยคือ \$50 แต่ standard deviation คือ \$1,322 ใหญ่กว่า $1{,}322/50\approx26.4$ เท่า ผลแค่ครั้งสองครั้งจึงแทบไม่บอกอะไรเรื่อง edge ชนะ \$2,000 ครั้งเดียวไม่ได้พิสูจน์ว่ากลยุทธ์ดี แพ้ครั้งเดียวก็ไม่ได้พิสูจน์ว่าแย่

ขั้นที่ 5 — variance ของผลรวมต้องมี covariance

คำถามของผู้จัดการเป็นเรื่องผลรวมหลายครั้ง เราจึงต้องรู้ว่า variance ของผลรวมคิดอย่างไร ค่าเฉลี่ยของผลรวมคือผลรวมของค่าเฉลี่ยเสมอ แต่ variance ไม่ง่ายแบบนั้น เพราะกำลังสองของผลรวมมีพจน์ไขว้ เหมือน $(u+v)^2=u^2+v^2+2uv$ ลองดูกรณีสองสถานะก่อน (สถานะ หรือ position คือสิ่งที่ถืออยู่ในพอร์ต) ให้ $A$ และ $B$ เป็นผลของสองสถานะในหน่วย R (ตรงนี้ $A$ กับ $B$ คือสองสถานะ ไม่ใช่ทาง A กับทาง B ของผู้จัดการ) ส่วน $a$ และ $b$ เป็นขนาดที่ถือแต่ละสถานะ ระยะห่างของ $aA+bB$ จากค่าเฉลี่ยของมันคือ $a(A-\mu_A)+b(B-\mu_B)$ ยกกำลังสองแล้วเฉลี่ยจะได้

\[\begin{aligned} \mathrm{Cov}(A,B)&\equiv\mathbb E\big[(A-\mu_A)(B-\mu_B)\big]\\[4pt] \mathrm{Var}(aA+bB)&=a^2\mathrm{Var}(A)+b^2\mathrm{Var}(B)\\ &\quad+2ab\,\mathrm{Cov}(A,B) \end{aligned}\]

ทีนี้ลองสามกรณี ทุกกรณีใช้ $a=b=1$ และทั้งสองสถานะมี variance 1.7475 เท่ากัน ต่างกันแค่ covariance

\[\begin{aligned} B=A:\ \mathrm{Var}&=1.7475+1.7475\\ &\quad+2(1.7475)=6.99\\[4pt] \mathrm{Cov}=0:\ \mathrm{Var}&=1.7475+1.7475\\ &=3.495\\[4pt] B=0.1-A:\ \mathrm{Var}&=1.7475+1.7475\\ &\quad-2(1.7475)=0 \end{aligned}\]

covariance คือพจน์ไขว้ มันวัดว่าสองสถานะ “ขยับไปด้วยกัน” แค่ไหน ถ้าสองตัวมักอยู่เหนือค่าเฉลี่ยพร้อมกันและใต้ค่าเฉลี่ยพร้อมกัน ระยะห่างของสองตัวมีเครื่องหมายเดียวกัน ผลคูณจึงเป็นบวก covariance เป็นบวก และความเสี่ยงรวมโตขึ้น สามกรณีด้านบนอ่านได้แบบนี้

  • $B=A$ คือส่งสัญญาณซื้อขายเดียวกันเข้าสองบัญชี ผลสองบัญชีเหมือนกันทุกครั้ง covariance จึงเท่ากับ variance คือ $\mathrm{Cov}(A,A)=\mathrm{Var}(A)=1.7475$ variance รวม 6.99 เป็นสองเท่าของกรณีอิสระ
  • $\mathrm{Cov}=0$ คือสองบัญชีอิสระกัน ผลบัญชีหนึ่งไม่บอกอะไรเกี่ยวกับอีกบัญชี ชิ้นไขว้หายไป variance รวมเหลือ 3.495
  • $B=0.1-A$ คือสถานะที่สองจ่ายสวนทางกับสถานะแรกพอดี ค่าเฉลี่ยของมันคือ $0.1-0.05=0.05$ เท่าเดิม แต่ระยะห่างกลับเครื่องหมายทุกครั้ง $B-\mu_B=-(A-\mu_A)$ covariance จึงเป็น $-\mathrm{Var}(A)=-1.7475$ ผลรวม $A+B=0.1R$ ทุกครั้ง variance จึงเป็นศูนย์ นี่คือหลักของการ hedge

ถ้าสองตัวอิสระกัน covariance เป็นศูนย์เสมอ เพราะค่าเฉลี่ยของผลคูณแยกเป็นผลคูณของค่าเฉลี่ยได้ คือ $\mathbb E[A-\mu_A]\,\mathbb E[B-\mu_B]=0\times0=0$ (ค่าเฉลี่ยของระยะห่างเป็นศูนย์ตามขั้นที่ 1) แต่ทางกลับไม่จริง covariance เป็นศูนย์ได้ทั้งที่สองตัวเกี่ยวกันแน่นอน ให้ $X$ เป็น −1, 0 หรือ 1 ด้วยโอกาสเท่ากัน และ $Y=X^2$ ใช้สูตรลัดแบบเดียวกับขั้นที่ 3 คือ $\mathrm{Cov}(X,Y)=\mathbb E[XY]-\mathbb E[X]\,\mathbb E[Y]$ จะได้

\[\begin{aligned} \mathrm{Cov}(X,Y)&=\mathbb E[X^3]-\mathbb E[X]\,\mathbb E[X^2]\\ &=0-0\times\tfrac23=0 \end{aligned}\]

$\mathbb E[X^3]=\tfrac13(-1+0+1)=0$ และ $\mathbb E[X]=0$ เหมือนกัน covariance จึงเป็นศูนย์ ทั้งที่รู้ $X$ แล้วรู้ $Y$ แน่นอน เพราะ covariance จับได้แค่ความสัมพันธ์แบบเส้นตรง (zero covariance ไม่ได้แปลว่า independence)

ขั้นที่ 6 — 1,000 ครั้ง: ค่าเฉลี่ยโตตาม n แต่ความผันผวนโตตาม √n

ตอนนี้มีเครื่องมือครบแล้ว กลับไปที่คำถามของผู้จัดการ ให้ $X_i$ คือผลของการซื้อขายครั้งที่ $i$ และ $W=X_1+\cdots+X_n$ คือผลรวมของ $n$ ครั้ง เราสมมติว่าแต่ละครั้งอิสระกัน และมีโอกาสของผลสามแบบเท่าเดิมทุกครั้ง (ใช้ PMF เดียวกัน) เพราะอิสระกัน covariance ทุกคู่จึงเป็นศูนย์ variance ของผลรวมเหลือแค่ชิ้นทแยง คือ variance ของแต่ละครั้งบวกกัน $n$ ชิ้น

\[\begin{aligned} \mathbb E[W]&=n\mu=1{,}000(0.05)=50R\\ \mathrm{Var}(W)&=n\sigma^2=1{,}000(1.7475)\\ &=1{,}747.5\ R^2\\ \mathrm{SD}(W)&=\sqrt{n\sigma^2}=\sigma\sqrt n\\ &=1.32193\times31.6228\\ &\approx 41.80R\approx\$41{,}803\\[4pt] \frac{\mathbb E[W]}{\mathrm{SD}(W)}&=\frac{n\mu}{\sigma\sqrt n}=\frac{\mu}{\sigma}\sqrt n\\ &=\frac{50}{41.80}\approx 1.196 \end{aligned}\]

ค่าเฉลี่ยรวมคือผลรวมของ 1,000 ชิ้นที่เท่ากัน จึงโตเป็นเส้นตรงตาม $n$ variance ก็โตเป็นเส้นตรงเหมือนกัน เพราะไม่มีชิ้นไขว้ แต่ standard deviation คือรากที่สองของ variance จึงโตแค่ตาม $\sqrt n$ ทำซ้ำ 1,000 ครั้ง ค่าเฉลี่ยโต 1,000 เท่า แต่ standard deviation โตแค่ $\sqrt{1{,}000}\approx31.6$ เท่า

นี่คือเหตุผลที่การทำซ้ำช่วยคนที่มี edge อัตราส่วนค่าเฉลี่ยต่อ standard deviation โตตาม $\sqrt n$ ถ้าทำครั้งเดียว อัตราส่วนนี้คือ $\mu/\sigma=0.05/1.3219\approx0.03782$ แทบมองไม่เห็น พอทำ 1,000 ครั้ง อัตราส่วนโตเป็น $0.03782\times31.623\approx1.196$

ความผิดพลาดที่พบบ่อยคือเอา standard deviation ต่อครั้งคูณ 1,000 ตรง ๆ ได้ $1{,}000\times\$1{,}322=\$1.32$ ล้าน ซึ่งใหญ่เกินจริง $\sqrt{1{,}000}\approx32$ เท่า การคูณแบบนั้นถูกเฉพาะเมื่อทุกครั้งให้ผลเหมือนกันหมด เหมือนกรณี $B=A$ ในขั้นที่แล้ว ที่ชิ้นไขว้เต็มทุกชิ้น

อีกคำถามที่มีประโยชน์คือ ต้องทำกี่ครั้งค่าเฉลี่ยรวมจึงไล่ทัน standard deviation รวม ตั้งให้สองตัวเท่ากันแล้วแก้หา $n$

\[\begin{aligned} n\mu&=\sigma\sqrt n\\ \sqrt n&=\sigma/\mu\\ n&=\frac{\sigma^2}{\mu^2}=\frac{1.7475}{0.0025}=699 \end{aligned}\]

ก่อนถึง 699 ครั้ง ความผันผวนของผลรวมยังใหญ่กว่า edge ที่สะสมได้ กฎ $\sqrt n$ เดียวกันนี้คือที่มาของการแปลง Sharpe ratio ข้ามช่วงเวลา ซึ่งหน้าการทดสอบ Sharpe ratioจะใช้ต่อ

ขั้นที่ 7 — แปลงเป็นโอกาสขาดทุน

ค่าเฉลี่ย 50R กับ standard deviation 41.8R ยังไม่ใช่โอกาส ถ้าจะแปลงเป็นโอกาส ต้องรู้รูปร่างของ distribution ด้วย (distribution คือภาพรวมว่าผลแต่ละค่ามีโอกาสเท่าไร) ข่าวดีคือผลรวมของการซื้อขายอิสระจำนวนมากมีรูปร่างเข้าใกล้ระฆังที่เรียกว่า normal distribution ไม่ว่าการซื้อขายแต่ละครั้งจะมีรูปร่างแบบไหน ข้อเท็จจริงนี้ชื่อ central limit theorem

ระฆัง normal ทุกใบมีรูปร่างเหมือนกัน ถ้าวัดระยะเป็นจำนวน standard deviation จากค่าเฉลี่ย เราจึงทำสองอย่าง อย่างแรก วัดว่าศูนย์อยู่ห่างจากค่าเฉลี่ยกี่ standard deviation เรียกตัวเลขนี้ว่า $z$ อย่างที่สอง อ่านพื้นที่ของระฆังมาตรฐานที่อยู่ทางซ้ายของ $z$ ด้วย $\Phi(z)$ ซึ่งคือ CDF ของ standard normal เราเขียนค่าที่ได้จากระฆังว่า $P_{\mathrm{normal}}$ และค่าที่ได้จากการนับทุกกรณีตรง ๆ ว่า $P_{\mathrm{exact}}$

\[\begin{aligned} z&=\frac{0-\mathbb E[W]}{\mathrm{SD}(W)}\\ &=\frac{-50}{41.80}\approx-1.196\\[4pt] P_{\mathrm{normal}}(W\lt 0)&=\Phi(-1.196)\approx 11.58\%\\ P_{\mathrm{exact}}(W\lt 0)&=11.32\% \end{aligned}\]

คำตอบของผู้จัดการคือ กลยุทธ์ที่ได้เปรียบทุกครั้งยังมีโอกาสราวหนึ่งในเก้า ($1/9\approx11\%$) ที่จะจบ 1,000 ครั้งด้วยผลรวมติดลบ ค่า $z$ บอกว่าศูนย์อยู่ต่ำกว่าค่าเฉลี่ย 1.196 standard deviation ตัวเลข 1.196 นี้ก็คืออัตราส่วนค่าเฉลี่ยต่อ standard deviation จากขั้นที่แล้ว แค่กลับเครื่องหมาย $P_{\mathrm{normal}}$ จึงอ่านว่า “พื้นที่ของระฆังที่อยู่ต่ำกว่าค่าเฉลี่ยเกิน 1.196 standard deviation”

$P_{\mathrm{exact}}$ ไม่ใช้ normal เลย ความคิดคือไล่สร้างโอกาสของผลรวมทีละครั้ง ให้ $p_n(k)$ คือโอกาสที่หลัง $n$ ครั้งผลรวมเท่ากับ $k$R ผลรวม $k$ หลังครั้งที่ $n+1$ มาได้สามทาง คือเดิมมี $k+1$ แล้วแพ้ (−1) เดิมมี $k$ แล้วเท่าทุน (0) หรือเดิมมี $k-2$ แล้วชนะ (+2)

\[\begin{aligned} p_{n+1}(k)&=0.55\,p_n(k+1)\\ &\quad+0.15\,p_n(k)\\ &\quad+0.30\,p_n(k-2) \end{aligned}\]

เริ่มจาก $p_0(0)=1$ (ก่อนเริ่ม ผลรวมเป็นศูนย์แน่นอน) ทำซ้ำ 1,000 รอบ แล้วรวมโอกาสของทุก $k\lt0$ โค้ดท้ายหน้าทำแบบนี้และได้ 11.32% ใกล้ค่าจาก normal มาก แต่ถ้าทำแค่ 20 ครั้ง การนับได้ 41.02% ขณะที่ normal ซึ่งมีค่าเฉลี่ย $20\times0.05=1$R ให้ $\Phi\big(-1/\sqrt{20\times1.7475}\big)=\Phi(-0.169)\approx43.28\%$ ต่างกัน $43.28-41.02=2.26$ จุด สรุปคือค่าจาก normal แม่นขึ้นเมื่อจำนวนครั้งมากขึ้น และถ้านับตรงได้ก็ควรนับตรวจ

จุดที่พลาดแล้วได้คำตอบผิดโดยไม่รู้ตัว

เอา standard deviation คูณจำนวนครั้ง ผลรวมของการซื้อขายอิสระ 1,000 ครั้งไม่ได้กระจายกว้างขึ้น 1,000 เท่า ตัวเลขผิดคือ $1{,}000\times\$1{,}322=\$1.32$ ล้าน ตัวเลขถูกคือ $\sqrt{1{,}000}\times\$1{,}321.93=31.623\times\$1{,}321.93\approx\$41{,}803$ ตัวเลขผิดใหญ่เกินไป $\sqrt{1{,}000}\approx32$ เท่า และทำให้กลยุทธ์ที่ดีดูเสี่ยงจนไม่มีใครกล้าทำ

ลบ variance ตอนหาผลต่าง ถ้าถือสถานะ $A$ แล้วขายสถานะ $B$ ที่อิสระกัน (ผลคือ $A-B$) คนมักคิดว่าความเสี่ยงหักล้างกันจนเหลือ $1.7475-1.7475=0$ แต่ $b=-1$ และ $b^2=(-1)^2=+1$ จึงได้

\[\begin{aligned} \mathrm{Var}(A-B)&=1^2(1.7475)+(-1)^2(1.7475)\\ &=3.495 \end{aligned}\]

การขายสถานะที่ไม่เกี่ยวกันไม่ได้ลดความเสี่ยง มีแต่เพิ่ม ความเสี่ยงลดได้เฉพาะเมื่อ covariance เป็นบวกและใหญ่พอ

ขยายขนาดสองเท่าแล้วคิดว่า variance สองเท่า ตัวเลขผิดคือ $2\times1.7475=3.495$ ตัวเลขถูกคือ $\mathrm{Var}(2X)=2^2\times1.7475=6.99$ ส่วน standard deviation โตสองเท่าพอดี $2\times1.3219=2.64R$ ถ้าวงเงินความเสี่ยงคิดเป็น variance การเพิ่มขนาดสองเท่าจะกินวงเงินสี่เท่า

ใช้กฎ 68–95–99.7 กับทุกอย่าง กฎนี้บอกว่าผลอยู่ห่างจากค่าเฉลี่ยไม่เกิน 1, 2 และ 3 standard deviation ด้วยโอกาส 68%, 95% และ 99.7% แต่สัดส่วนนี้เป็นของ normal เท่านั้น การซื้อขายครั้งเดียวของเราไม่ใช่ระฆัง ผล +2R อยู่ห่างจากค่าเฉลี่ย $(2-0.05)/1.3219\approx1.48$ standard deviation ถ้าเป็น normal โอกาสอยู่สูงกว่านั้นมีแค่ $1-\Phi(1.48)\approx7\%$ แต่ของจริงมีโอกาสถึง 30% มันจึงไม่ใช่เหตุการณ์หายากแบบที่ normal จะบอก

ใช้ทำอะไรบนโต๊ะจริง

ในตลาดจริง คนมักรู้ความผันผวนรายวันของหุ้น แต่ต้องรายงานเป็นรายปี กฎ $\sigma\sqrt n$ ของหน้านี้คือเครื่องมือที่ใช้แปลง เพราะผลตอบแทนทั้งปีคือผลรวมของผลตอบแทนรายวันทุกวัน ปีหนึ่งมีวันซื้อขายราว 252 วัน (365 วัน หักเสาร์อาทิตย์และวันหยุดตลาด ตามที่หน้า expected value นับไว้) ถ้าผลตอบแทนแต่ละวันอิสระกัน ความผันผวนรายปีจึงเท่ากับความผันผวนรายวันคูณ $\sqrt{252}\approx15.87$

ตัวอย่าง (ตัวเลขสมมติ) หุ้นตัวหนึ่งมีความผันผวนรายวัน $\sigma_{\mathrm{day}}=1.2\%$

\[\begin{aligned} \sigma_{\mathrm{year}}&=\sigma_{\mathrm{day}}\sqrt{252}\\ &=1.2\%\times15.87\approx19.0\% \end{aligned}\]

ส่วนผลตอบแทนเฉลี่ยโตตามจำนวนวันตรง ๆ คือคูณ 252 Sharpe ratio ซึ่งเป็นผลตอบแทนเฉลี่ย (ส่วนที่เกินดอกเบี้ยเงินฝาก) หารด้วยความผันผวน จึงโตตาม $252/\sqrt{252}=\sqrt{252}$ คือ Sharpe ratio รายปีเท่ากับรายวันคูณ $\sqrt{252}$ ตัวเลขเหล่านี้ถูกเท่าที่สมมติฐาน “แต่ละวันอิสระกัน” ถูก ถ้าผลตอบแทนวันนี้เกี่ยวกับวันพรุ่งนี้ ต้องเพิ่มชิ้นไขว้ของขั้นที่ 5 กลับเข้าไป

โจทย์ตรวจความเข้าใจ

1. ผู้จัดการรู้สึกว่าเงินแกว่งมากเกินไป จึงลดขนาดการซื้อขายลงครึ่งหนึ่ง ให้ 1R เหลือ \$500 แทน \$1,000 โดยโอกาสของผลสามแบบเท่าเดิม แล้วทำ 1,000 ครั้งอย่างอิสระ ค่าเฉลี่ยและ standard deviation ต่อครั้งและของผลรวมเป็นเท่าไรในหน่วยดอลลาร์ อัตราส่วนค่าเฉลี่ยต่อ standard deviation ของผลรวมเปลี่ยนไหม

เฉลย

ผลเป็นดอลลาร์คือ $500X$ จึงใช้กฎการเปลี่ยนขนาดจากขั้นที่ 4 ด้วย $a=500$ แล้วใช้กฎ $n$ กับ $\sqrt n$ จากขั้นที่ 6

\[\begin{aligned} 500\mu&=500\times0.05=\$25\\ 500\sigma&=500\times1.32193\approx\$660.97\\[4pt] \mathbb E[W]&=1{,}000\times\$25=\$25{,}000\\ \mathrm{SD}(W)&=\$660.97\times\sqrt{1{,}000}\\ &\approx\$20{,}902\\[4pt] \frac{\mathbb E[W]}{\mathrm{SD}(W)}&=\frac{25{,}000}{20{,}902}\approx1.196 \end{aligned}\]

อัตราส่วนยังเป็น 1.196 เท่าเดิม เพราะทั้งเศษและส่วนถูกคูณด้วย 500 เท่ากัน ส่วน variance ในหน่วยดอลลาร์กำลังสองลดเหลือ $(500/1{,}000)^2=1/4$ ของเดิม สรุปคือการลดขนาดลดความเสี่ยงที่เป็นเงิน แต่ไม่ได้ทำให้โอกาสจบขาดทุนเปลี่ยน

2. ในชีวิตจริง จำนวนครั้งที่ซื้อขายในหนึ่งปีไม่แน่นอน เพราะขึ้นกับว่าสัญญาณซื้อขายเกิดบ่อยแค่ไหน สมมติว่าปีหน้าจะซื้อขาย 900 หรือ 1,100 ครั้ง โอกาสอย่างละครึ่ง และจำนวนครั้งไม่เกี่ยวกับผลของแต่ละครั้ง variance ของผลรวมทั้งปีในหน่วย R² เป็นเท่าไร

เฉลย

ก่อนอื่นคิดแยกสองกรณี ด้วยกฎ $n\mu$ และ $n\sigma^2$ จากขั้นที่ 6

\[\begin{aligned} n=900:\ \mathbb E&=900\times0.05=45R\\ \mathrm{Var}&=900\times1.7475=1{,}572.75\\[4pt] n=1{,}100:\ \mathbb E&=1{,}100\times0.05=55R\\ \mathrm{Var}&=1{,}100\times1.7475=1{,}922.25 \end{aligned}\]

ผลรวมทั้งปีแกว่งได้จากสองแหล่ง แหล่งแรกคือการแกว่งภายในแต่ละกรณี เฉลี่ยสองกรณีได้ $\tfrac12(1{,}572.75+1{,}922.25)=1{,}747.5$ แหล่งที่สองคือค่าเฉลี่ยของสองกรณีไม่เท่ากัน (45 กับ 55) จึงแกว่งรอบค่าเฉลี่ยรวม 50 ไปข้างละ 5 ได้ $\tfrac12(5^2)+\tfrac12(5^2)=25$

\[\begin{aligned} \mathrm{Var}(W)&=1{,}747.5+25=1{,}772.5\ R^2\\ \mathrm{SD}(W)&=\sqrt{1{,}772.5}\approx42.10R \end{aligned}\]

การแยกการแกว่งเป็นสองแหล่งแบบนี้คือ law of total variance

3. นักวิเคราะห์คนหนึ่งมีกลยุทธ์อิสระสองตัว $A$ กับ $B$ แต่ละตัวมี variance 1.7475 R² เขาเสนอว่าถ้าซื้อตัวหนึ่งพร้อมกับขายอีกตัว (ถือ $A-B$) สองตัวจะหักล้างกันและความเสี่ยงจะลดลง จริงไหม standard deviation ของ $A-B$ คือเท่าไร

เฉลย

ไม่จริง ใช้สูตรของขั้นที่ 5 ด้วย $a=1$, $b=-1$ และ covariance เป็นศูนย์เพราะอิสระกัน

\[\begin{aligned} \mathrm{Var}(A-B)&=1^2(1.7475)+(-1)^2(1.7475)\\ &\quad-2\,\mathrm{Cov}(A,B)\\ &=3.495-0=3.495\\ \mathrm{SD}(A-B)&=\sqrt{3.495}\approx1.87R \end{aligned}\]

1.87R สูงกว่าถือตัวเดียว (1.32R) การขายตัวหนึ่งลดความเสี่ยงได้ก็ต่อเมื่อสองตัวขยับไปด้วยกัน คือ covariance เป็นบวก

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
const pmf = [[-1, 0.55], [0, 0.15], [2, 0.30]];
const E = f => pmf.reduce((s, [x, p]) => s + f(x) * p, 0);
const mu = E(x => x);
const v1 = E(x => (x - mu) ** 2);        // นิยาม
const v2 = E(x => x * x) - mu ** 2;      // สูตรลัด
console.log(mu, v1, v2, Math.sqrt(v1));  // 0.05 1.7475 1.7475 1.3219

const n = 1000;
const sdW = Math.sqrt(n * v1);
console.log(n * mu, sdW, (n * mu) / sdW); // 50 41.80 1.196
console.log(v1 / mu ** 2);                // 699

// นับ distribution ของผลรวมตรง ๆ (ไม่ใช้ normal)
function lossProb(trades) {
  let dist = new Map([[0, 1]]);
  for (let i = 0; i < trades; i++) {
    const next = new Map();
    for (const [total, pr] of dist)
      for (const [x, p] of pmf)
        next.set(total + x, (next.get(total + x) || 0) + pr * p);
    dist = next;
  }
  let loss = 0;
  for (const [total, pr] of dist) if (total < 0) loss += pr;
  return loss;
}
console.log(lossProb(2), lossProb(20), lossProb(1000)); // 0.4675 0.4102 0.1132
console.log(Math.sqrt(252), 1.2 * Math.sqrt(252));     // 15.87 19.05

สิ่งที่ควรตอบได้หลังอ่าน

  • variance คือค่าเฉลี่ยของระยะห่างจากค่าเฉลี่ยยกกำลังสอง $\mathbb E[(X-\mu)^2]=\mathbb E[X^2]-\mu^2$ กลยุทธ์ TSLA ได้ 1.7475 R² ถอดรากได้ standard deviation 1.32R หรือ \$1,322 ต่อครั้ง ใหญ่กว่าค่าเฉลี่ย \$50 ราว 26 เท่า
  • การบวกค่าคงที่ไม่เปลี่ยนการกระจาย การคูณด้วย $a$ ทำให้ variance โต $a^2$ เท่า และ standard deviation โต $|a|$ เท่า
  • variance ของผลรวมต้องมีชิ้นไขว้ $\mathrm{Var}(aA+bB)=a^2\mathrm{Var}(A)+b^2\mathrm{Var}(B)+2ab\,\mathrm{Cov}(A,B)$ covariance บวกทำให้ความเสี่ยงรวมโตขึ้น covariance ศูนย์ไม่เพิ่มไม่ลด covariance ลบทำให้ความเสี่ยงลดลงจนหายได้
  • ถ้าแต่ละครั้งอิสระกัน ค่าเฉลี่ยรวมโตตาม $n$ แต่ standard deviation โตแค่ตาม $\sqrt n$ หลัง 1,000 ครั้งได้ค่าเฉลี่ย 50R กับ standard deviation 41.8R ซึ่งยังใกล้กัน จึงยังมีโอกาสจบขาดทุนราว 11.3%
  • กฎรากที่สองเดียวกันใช้แปลงความผันผวนรายวันเป็นรายปี โดยคูณ $\sqrt{252}\approx15.87$

หน้าถัดไป binomial distribution จะใช้ค่าเฉลี่ยและ variance ของผลรวมจากหน้านี้กับตัวแปรที่เป็นได้แค่ 0 หรือ 1 (แพ้หรือชนะ) เพื่อนับว่าผู้จัดการกองทุนที่ไม่มีฝีมือจะชนะตลาดได้กี่ปีจากสิบปี
