1.4 Variance and Standard Deviation

วัดสิ่งที่ค่าเฉลี่ยซ่อนไว้: ผลจริงอาจห่างจากสิ่งที่คาดเพียงใด

ทางเลือก A จ่าย \$50 แน่นอน ทางเลือก B เป็นแบบจำลองเดิม: ได้ \$2,000 ด้วยโอกาส 30% เสีย \$1,000 ด้วยโอกาส 55% และได้ศูนย์ด้วยโอกาส 15% ทั้งคู่มีค่าเฉลี่ย \$50 แต่ไม่ได้มีความเสี่ยงเท่ากัน

เราจะวัดความต่างนี้จากระยะห่างของผลลัพธ์รอบค่าเฉลี่ย แล้วตอบคำถามต่อว่า หากทำซ้ำ 1,000 ครั้ง กำไรคาดหวังที่เป็นบวกยังปล่อยให้จบช่วงขาดทุนได้มากเพียงใด

กำหนดสิ่งที่วัดและหน่วยให้ตรงกันก่อน

ใช้ $X$ เป็นผลลัพธ์ต่อครั้งในหน่วย R โดยมีค่า −1, 0 และ +2 ด้วยโอกาส 0.55, 0.15 และ 0.30 ตามลำดับ ค่าเฉลี่ยจากหัวข้อ 1.3 คือ $\mu=\mathbb E[X]=0.05R$ และให้ 1R เท่ากับ \$1,000

หน้านี้ยังไม่หักค่าใช้จ่าย และใช้ 1,000 ครั้งสำหรับตัวอย่างผลรวมเพื่อให้อ่านตัวเลขง่าย ต่างจากตัวอย่าง 1,008 ครั้งในบทเรียนก่อน ถ้าจะนำไปใช้จริง ต้องเลือกจำนวนครั้งและต้นทุนตามโจทย์ ไม่ใช่คัดลอกตัวเลขจากคนละตัวอย่างมารวมกัน

ดูระยะห่างจากค่าเฉลี่ยทีละกรณี

ผลลัพธ์ $x$โอกาสระยะห่าง $x-0.05$ระยะห่างยกกำลังสอง
−1R0.55−1.05R1.1025 R²
0R0.15−0.05R0.0025 R²
+2R0.30+1.95R3.8025 R²

แม้ผลลัพธ์ 0R จะเท่าทุน แต่มันต่ำกว่าค่าเฉลี่ย 0.05R จึงมีระยะห่าง −0.05R “เท่าทุน” กับ “เท่าค่าเฉลี่ย” ไม่ใช่เงื่อนไขเดียวกัน

ขั้นที่ 1 — ทำไมเฉลี่ยระยะห่างตรง ๆ ไม่ได้

ระยะห่างที่มีเครื่องหมายบวกและลบหักล้างกันพอดี เราพิสูจน์ได้จาก linearity ที่เพิ่งเรียน โดยใช้ข้อเท็จจริงว่า $\mu$ เป็นค่าคงที่

\[ \begin{aligned} \mathbb E[X-\mu]&=\mathbb E[X]-\mu=0\\[3pt] (-1.05)(0.55)&+(-0.05)(0.15)+(1.95)(0.30)\\ &=-0.5775-0.0075+0.585\\ &=0 \end{aligned} \]

ค่าเป็นศูนย์ไม่ได้หมายความว่าผลลัพธ์ไม่กระจาย แต่หมายความว่าด้านที่สูงกว่าค่าเฉลี่ยกับด้านที่ต่ำกว่าค่าเฉลี่ยหักล้างกัน เราจึงต้องวัดขนาดโดยไม่ให้เครื่องหมายหักล้าง เช่น ใช้ค่าสัมบูรณ์หรือยกกำลังสอง

เลือกกำลังสองเพราะอะไร

การใช้ค่าสัมบูรณ์เป็นตัววัดการกระจายก็มีประโยชน์ แต่ variance เลือกใช้กำลังสอง เพราะมีสมบัติที่ช่วยคำนวณการกระจายของผลรวมได้สะดวก ก่อนใช้สูตรทั่วไป ลองดูตัวแปรจากเหรียญสองเหรียญที่เป็นอิสระกัน

ให้แต่ละเหรียญมีค่า +1 หรือ −1 ด้วยโอกาสเท่ากัน ค่าเฉลี่ยของแต่ละตัวเป็นศูนย์ และทั้งค่าสัมบูรณ์กับกำลังสองเท่ากับ 1 เสมอ ส่วนผลรวมของสองเหรียญมีค่า −2, 0 และ +2 ด้วยโอกาส 1/4, 1/2 และ 1/4

ขั้นที่ 2 — เปรียบเทียบค่าสัมบูรณ์กับกำลังสองของผลรวม

ให้ $A$ และ $B$ เป็นค่าจากเหรียญทั้งสอง ในตัวอย่างนี้ค่าเฉลี่ยเป็นศูนย์ ระยะห่างจากค่าเฉลี่ยจึงเท่ากับค่าของตัวแปรเอง

\[ \begin{aligned} \mathbb E[|A+B|]&=2(1/4)+0(1/2)+2(1/4)=1\\ \mathbb E[|A|]+\mathbb E[|B|]&=1+1=2\\[4pt] \mathbb E[(A+B)^2]&=4(1/4)+0(1/2)+4(1/4)=2\\ \mathbb E[A^2]+\mathbb E[B^2]&=1+1=2 \end{aligned} \]

ค่าสัมบูรณ์เฉลี่ยของผลรวมไม่เท่ากับผลบวกของค่าสัมบูรณ์เฉลี่ยแต่ละตัว แต่กำลังสองเฉลี่ยในกรณีนี้บวกกันได้ เพราะตัวแปรเป็นอิสระและมีค่าเฉลี่ยศูนย์ นี่คือสมบัติที่เราจะใช้สร้างสูตร variance ของผลรวม ไม่ใช่ข้อสรุปว่ากำลังสองเป็นวิธีวัดความเสี่ยงที่ดีที่สุดทุกสถานการณ์

ขั้นที่ 3 — นิยาม variance และสร้างสูตรคำนวณ

Variance เขียนว่า $\mathrm{Var}(X)$ หรือ $\sigma^2$ คือค่าเฉลี่ยแบบถ่วงโอกาสของระยะห่างจากค่าเฉลี่ยที่ยกกำลังสอง เมื่อขยายวงเล็บจะได้สูตรอีกแบบที่มักคำนวณสะดวกกว่า

\[ \begin{aligned} \mathrm{Var}(X)&\equiv\mathbb E[(X-\mu)^2]\\ &=\mathbb E[X^2-2\mu X+\mu^2]\\ &=\mathbb E[X^2]-2\mu\mathbb E[X]+\mu^2\\ &=\mathbb E[X^2]-2\mu^2+\mu^2\\ &=\boxed{\mathbb E[X^2]-\mu^2} \end{aligned} \]

สูตรทั้งสองวัดสิ่งเดียวกัน แบบแรกเฉลี่ยระยะห่างยกกำลังสองโดยตรง แบบที่สองเฉลี่ยผลลัพธ์ยกกำลังสองก่อนแล้วลบกำลังสองของค่าเฉลี่ย อย่าสลับ $\mathbb E[X^2]$ กับ $(\mathbb E[X])^2$ เพราะโดยทั่วไปไม่เท่ากัน

ขั้นที่ 4 — คำนวณ variance ด้วยสองวิธีเพื่อตรวจคำตอบ

\[ \begin{aligned} \mathbb E[X^2]&=1(0.55)+0(0.15)+4(0.30)=1.75\\ \sigma^2&=1.75-(0.05)^2=1.7475\;R^2\\[4pt] \mathbb E[(X-\mu)^2] &=1.1025(0.55)+0.0025(0.15)\\ &\quad+3.8025(0.30)\\ &=0.606375+0.000375+1.14075\\ &=\boxed{1.7475\;R^2} \end{aligned} \]

ทั้งสองวิธีได้ 1.7475 R² ตรงกัน หน่วยเป็นกำลังสองเพราะเรายกกำลังสองระยะห่าง จึงยังไม่ควรอ่าน 1.7475 เป็นจำนวนเงินหรือจำนวน R ที่มักจะเสีย

ขั้นที่ 5 — ถอดรากเพื่อกลับมาใช้หน่วยเดิม

Standard deviation นิยามเป็นรากที่สองของ variance ใช้สัญลักษณ์ $\sigma$ ถ้าคูณตัวแปรด้วยค่าคงที่ $a$ ระยะห่างก็ถูกคูณด้วย $a$ จึงทำให้ variance คูณด้วย $a^2$

\[ \begin{aligned} \sigma&\equiv\sqrt{\sigma^2}=\sqrt{1.7475}\approx1.32193R\\ \mathrm{Var}(aX)&=\mathbb E[(aX-a\mu)^2]\\ &=a^2\mathbb E[(X-\mu)^2]=a^2\sigma^2\\ \mathrm{SD}(aX)&=|a|\sigma\\[3pt] \mathrm{SD}(1{,}000X)&=1{,}000\sqrt{1.7475}\\ &\approx\boxed{\$1{,}321.93} \end{aligned} \]

ค่า \$1,321.93 วัดขนาดการกระจายรอบกำไรคาดหวัง \$50 ไม่ใช่ขาดทุนสูงสุด ไม่ใช่ระยะห่างเฉลี่ยแบบค่าสัมบูรณ์ และไม่ได้แปลว่าผลทุกครั้งจะอยู่ในช่วงค่าเฉลี่ยบวกลบหนึ่ง standard deviation

ตีความตัวเลข — ค่าเฉลี่ยเล็กเมื่อเทียบกับการกระจาย

ของที่มี: กำไรคาดหวัง 0.05R และ standard deviation ประมาณ 1.32193R ต่อครั้ง

คำถาม: standard deviation ใหญ่กว่ากำไรคาดหวังกี่เท่า?

คำตอบ: $1.32193/0.05\approx26.44$ เท่า ดังนั้น ผลเพียงหนึ่งหรือสองครั้งให้ข้อมูลน้อยมากว่าค่าเฉลี่ยจริงของกลยุทธ์เป็นบวกหรือไม่ การชนะครั้งใหญ่ไม่ได้ยืนยันว่ามี edge และการแพ้ครั้งเดียวก็ไม่ได้หักล้างค่าเฉลี่ยบวก

ตรวจเองใน 10 วินาที: ใช้หน่วยดอลลาร์ได้ $1{,}321.93/50\approx26.44$ เท่ากัน การเปลี่ยนหน่วยไม่ควรเปลี่ยนอัตราส่วนนี้

เมื่อนำหลายครั้งมารวมกัน ต้องตรวจ covariance ด้วย

ให้ $W=X_1+\cdots+X_n$ เป็นผลรวมจากจำนวนครั้งที่กำหนด $n$ ครั้ง ค่าเฉลี่ยรวมบวกกันได้เสมอเมื่อค่าเฉลี่ยมีอยู่ แต่ variance ไม่ได้บวกตรง ๆ เสมอ เพราะกำลังสองของผลรวมมีพจน์ผลคูณระหว่างตัวแปรด้วย

Covariance ของตัวแปรสองตัวนิยามเป็นค่าเฉลี่ยของผลคูณระยะห่างจากค่าเฉลี่ยของทั้งคู่ ถ้าทั้งสองมักสูงหรือต่ำกว่าค่าเฉลี่ยพร้อมกัน covariance จะเป็นบวก ถ้ามักเคลื่อนไหวสวนทางกันอาจเป็นลบ รายละเอียดจะอยู่ในหัวข้อ 5.5

ขั้นที่ 6 — แยกความผันผวนของแต่ละครั้งออกจากความสัมพันธ์

เริ่มที่ผลรวมสองตัว $A+B$ แล้วใช้กฎกระจายกำลังสอง หากตัวแปรเป็นอิสระ ค่าเฉลี่ยของผลคูณระยะห่างแยกเป็นผลคูณของค่าเฉลี่ยซึ่งเป็นศูนย์ทั้งคู่ได้

\[ \begin{aligned} \mathrm{Cov}(A,B)&\equiv\mathbb E[(A-\mu_A)(B-\mu_B)]\\ \mathrm{Var}(A+B)&=\mathbb E[((A-\mu_A)+(B-\mu_B))^2]\\ &=\mathrm{Var}(A)+\mathrm{Var}(B)\\ &\quad+2\mathrm{Cov}(A,B)\\[4pt] \mathrm{Var}(W)&=\sum_{i=1}^{n}\mathrm{Var}(X_i)\\ &\quad+2\sum_{i\lt j}\mathrm{Cov}(X_i,X_j) \end{aligned} \]

ถ้า covariance ของทุกคู่เป็นศูนย์ เราจึงบวก variance ได้ตรง ๆ independence เป็นเงื่อนไขหนึ่งที่ทำให้เกิดผลนี้เมื่อมี variance จำกัด แต่ covariance เป็นศูนย์ไม่ได้รับประกัน independence หากผลรวม covariance เป็นบวก ความผันผวนจะสูงขึ้น หากเป็นลบก็อาจต่ำลง

ขั้นที่ 7 — คำนวณผลรวม 1,000 ครั้งภายใต้ independence

สมมติว่าทุกครั้งเป็นอิสระ มีค่าเฉลี่ย 0.05R และ variance 1.7475 R² เหมือนกัน โดย 1R คงที่ \$1,000 ตลอดช่วง

\[ \begin{aligned} \mathbb E[W]&=n\mu=1{,}000(0.05)=50R\\ \mathrm{Var}(W)&=n\sigma^2=1{,}000(1.7475)=1{,}747.5\;R^2\\ \mathrm{SD}(W)&=\sqrt{n\sigma^2}=\sigma\sqrt n\\ &=\sqrt{1{,}747.5}\approx41.8031R\\[3pt] \mathbb E[W_{\$}]&=\$50{,}000\\ \mathrm{SD}(W_{\$})&\approx\$41{,}803.11 \end{aligned} \]

ค่าเฉลี่ยเพิ่มตามจำนวนครั้ง แต่ standard deviation เพิ่มตามรากที่สองของจำนวนครั้ง เพราะต้องถอดรากจาก variance รวม อย่าสับสนว่า standard deviation ต่อครั้งคูณ 1,000 แล้วจะเป็น standard deviation ของผลรวมภายใต้ independence

ขั้นที่ 8 — อัตราส่วนค่าเฉลี่ยต่อความผันผวนบอกอะไร

Sharpe ratio ตามปกติใช้ค่าเฉลี่ยผลตอบแทนส่วนเกินหารด้วย standard deviation ของผลตอบแทนส่วนเกินนั้น ตัวอย่างนี้สมมติฐานเงินทุนคงที่และผลตอบแทนอ้างอิงเป็นศูนย์ จึงใช้อัตราส่วนของ P&L ในหน่วย R แทนได้

\[ \begin{aligned} \frac{\mathbb E[W]}{\mathrm{SD}(W)} &=\frac{n\mu}{\sigma\sqrt n}\\ &=\frac{\mu}{\sigma}\sqrt n\\ &=\frac{0.05}{\sqrt{1.7475}}\sqrt{1{,}000}\\ &\approx1.1961 \end{aligned} \]

กำไรคาดหวังของผลรวมมีขนาดประมาณ 1.20 เท่าของ standard deviation ไม่ใช่ความน่าจะเป็น 120% และไม่ใช่หลักฐานจากข้อมูลจริงว่ากลยุทธ์ทำได้ตามนี้ หากหักต้นทุน ค่าเฉลี่ยส่วนบนลดลงและอัตราส่วนนี้ต้องคำนวณใหม่

ขั้นที่ 9 — จุดตัดประมาณ 699 ครั้งไม่ใช่เส้นรับประกันกำไร

หา $n$ ที่ค่าเฉลี่ยรวมเท่ากับหนึ่ง standard deviation โดยใช้ $\mu\gt0$ ตามตัวอย่างนี้

\[ \begin{aligned} n\mu&=\sigma\sqrt n\\ \sqrt n&=\frac{\sigma}{\mu}\\ n&=\frac{\sigma^2}{\mu^2}\\ &=\frac{1.7475}{0.05^2}=699 \end{aligned} \]

ครบ 699 ครั้งแล้วอัตราส่วนค่าเฉลี่ยต่อ standard deviation เท่ากับหนึ่งเท่านั้น ยังมีโอกาสขาดทุน และยังไม่ใช่การพิสูจน์ว่าแบบจำลองมี edge จริงจากข้อมูล การวัดความไม่แน่นอนของค่าเฉลี่ยและการทดสอบหลักฐานอยู่ในบทที่ 3

จะเปลี่ยนค่าเฉลี่ยกับ variance เป็นโอกาสขาดทุนได้อย่างไร

ค่าเฉลี่ยกับ variance เพียงสองค่าไม่กำหนด distribution ทั้งหมด จึงยังบอกโอกาสขาดทุนไม่ได้แน่นอน ในตัวอย่างที่ทดลองอย่างเป็นอิสระด้วย distribution เดียวกันและมี variance จำกัด เราจะใช้ Normal ประมาณผลรวม โดยอาศัย Central Limit Theorem (CLT) ซึ่งจะศึกษารายละเอียดในหัวข้อ 3.2

ให้ $\Phi(z)$ เป็น CDF ของ Standard Normal และ $z$ เป็นระยะจากค่าเฉลี่ยวัดด้วย standard deviation เราต้องหาว่าขอบกำไรศูนย์อยู่ต่ำกว่าค่าเฉลี่ยเท่าไร แล้วอ่านพื้นที่หางซ้ายจาก Normal

ขั้นที่ 10 — ประมาณโอกาสขาดทุนหลัง 1,000 ครั้ง

\[ \begin{aligned} z_{\text{zero}}&=\frac{0-\mathbb E[W]}{\mathrm{SD}(W)}\\ &=\frac{-50}{\sqrt{1{,}747.5}}\approx-1.1961\\ P(W\lt0)&\approx\Phi(-1.1961)\\ &\approx\boxed{11.6\%} \end{aligned} \]

ภายใต้แบบจำลองและการประมาณนี้ ผลรวม 1,000 ครั้งยังมีโอกาสติดลบประมาณ 11.6% แม้ทุกครั้งมีกำไรคาดหวังบวก ตัวเลขนี้ไม่ใช่ตารางเวลาว่าจะขาดทุนทุกกี่ปี และไม่ใช่คำตอบที่ใช้ได้กับทุกกลยุทธ์ซึ่งมี Sharpe เท่ากัน

เมื่อจำนวนครั้งน้อย ลองนับผลรวมตรง ๆ ก่อน

ผลลัพธ์ในหน่วย R ยังเป็นจำนวนเต็ม แม้เราจะวาดเส้น Normal ทับไว้ หลังสองครั้ง การขาดทุนเกิดได้จากแพ้ทั้งคู่ หรือแพ้หนึ่งครั้งกับเท่าทุนหนึ่งครั้ง ซึ่งสลับลำดับได้สองแบบ

ขั้นที่ 11 — เริ่มนับสองครั้ง แล้วสร้างกฎสำหรับหลายครั้ง

ให้ $q_n(k)$ เป็นโอกาสที่ผลรวมหลัง $n$ ครั้งเท่ากับ $kR$ เริ่มจากยังไม่ทดลอง: $q_0(0)=1$ และค่าอื่นเป็นศูนย์ แต่ละครั้งยังเป็นอิสระและใช้ PMF เดิม

\[ \begin{aligned} P(W_2\lt0)&=0.55^2+2(0.55)(0.15)\\ &=0.3025+0.165=0.4675\\[4pt] q_{n+1}(k)&=0.55q_n(k+1)\\ &\quad+0.15q_n(k)\\ &\quad+0.30q_n(k-2)\\[4pt] P(W_{20}\lt0)&=\sum_{k\lt0}q_{20}(k)\\ &\approx\boxed{41.0205\%} \end{aligned} \]

ผลรวมใหม่เป็น $kR$ ได้สามทาง: เดิมมี $(k+1)R$ แล้วแพ้ 1R เดิมมี $kR$ แล้วเท่าทุน หรือเดิมมี $(k-2)R$ แล้วชนะ 2R สูตรจึงบวกโอกาสของสามทางนี้ เมื่อคำนวณซ้ำครบยี่สิบรอบแล้วรวมค่าติดลบ จะได้โอกาสขาดทุนโดยไม่ใช้ Normal

ตรวจการประมาณ — ผลรวม 20 ครั้ง

หลัง 20 ครั้ง ค่าเฉลี่ยรวมคือ $20(0.05)=1R$ และ variance รวมคือ $20(1.7475)=34.95$ R² ถ้าใช้ Normal โดยไม่ปรับสำหรับความเป็น discrete จะได้ $\Phi(-1/\sqrt{34.95})\approx43.3\%$

การนับตรง ๆ ให้ประมาณ 41.0% ต่างกันราว 2.3 จุดเปอร์เซ็นต์ จึงไม่ควรสรุปว่าการประมาณใช้ได้แม่นยำเพียงเพราะวาดเส้นโค้งดูเรียบ หากคำนวณคำตอบตรง ๆ ได้ ให้ใช้ตรวจคุณภาพของการประมาณก่อน

ตรวจเองใน 10 วินาที: กฎนับผลรวมต้องรักษาโอกาสรวมเป็นหนึ่งทุกขั้น และเมื่อมีเพียงสองครั้ง ต้องคืนค่าโอกาสขาดทุน 0.4675 ที่นับด้วยมือได้

ต่อยอด — จำนวนครั้งสุ่มเพิ่มแหล่งความผันผวนอีกส่วน

สมมติว่า $N$ เป็นจำนวนครั้งสุ่มที่เป็นอิสระจากผลการซื้อขาย และแต่ละครั้งเป็นอิสระ มีค่าเฉลี่ย $\mu$ กับ variance $\sigma^2$ เท่ากัน เมื่อรู้ว่า $N=n$ เรารู้จากด้านบนแล้วว่าค่าเฉลี่ยรวมเป็น $n\mu$ และ variance รวมเป็น $n\sigma^2$

ใช้สูตร $\mathbb E[W^2]=\mathrm{Var}(W)+(\mathbb E[W])^2$ ย้อนกลับภายใต้แต่ละค่า $n$ แล้วเฉลี่ยข้ามค่าของ $N$ จะเห็นว่ามีความผันผวนจากจำนวนครั้งเพิ่มเข้ามา วิธีคิดนี้เป็นกรณีหนึ่งของ Law of Total Variance ในหัวข้อ 2.2

ขั้นที่ 12 — แยกผลของจำนวนครั้งออกจากผลของแต่ละครั้ง

\[ \begin{aligned} \mathbb E[W^2\mid N=n]&=n\sigma^2+n^2\mu^2\\ \mathbb E[W^2]&=\sigma^2\mathbb E[N]+\mu^2\mathbb E[N^2]\\ \mathbb E[W]&=\mu\mathbb E[N]\\[3pt] \mathrm{Var}(W)&=\mathbb E[W^2]-(\mathbb E[W])^2\\ &=\sigma^2\mathbb E[N]\\ &\quad+\mu^2\big(\mathbb E[N^2]-(\mathbb E[N])^2\big)\\ &=\boxed{\sigma^2\mathbb E[N]+\mu^2\mathrm{Var}(N)} \end{aligned} \]

พจน์แรกคือความผันผวนของผลแต่ละครั้งที่สะสมตามจำนวนครั้งเฉลี่ย พจน์ที่สองคือการที่จำนวนครั้งเปลี่ยนแล้วค่าเฉลี่ยรวมเปลี่ยนตาม เมื่อเปรียบเทียบกับจำนวนครั้งคงที่ที่มีค่าเท่ากับ $\mathbb E[N]$ พจน์เพิ่มนี้ไม่ติดลบ และเป็นศูนย์ได้ถ้า $\mu=0$

Worked Example — 900 หรือ 1,100 ครั้ง

ให้จำนวนครั้งเป็น 900 หรือ 1,100 ด้วยโอกาสอย่างละครึ่ง จึงได้ $\mathbb E[N]=1{,}000$ และ $\mathrm{Var}(N)=\tfrac12(900-1000)^2+\tfrac12(1100-1000)^2=10{,}000$

ใช้ค่าเฉลี่ยต่อครั้ง 0.05R และ variance 1.7475 R² เดิม จะได้ $\mathrm{Var}(W)=1.7475(1000)+0.05^2(10000)=1{,}772.5$ R² เทียบกับ 1,747.5 R² เมื่อจำนวนครั้งตรึงที่ 1,000

ถ้าภายหลังเลือก $N$ เป็น Poisson ที่มีค่าเฉลี่ย 1,000 ซึ่งมี variance 1,000 ด้วย จะได้ $1.7475(1000)+0.05^2(1000)=1{,}750$ R² สมบัติของ Poisson นี้จะสร้างในหัวข้อ 1.6 สำหรับตอนนี้ให้ถือเป็นข้อมูลที่โจทย์กำหนด

ลองทำเอง — ลดขนาดการซื้อขายครึ่งหนึ่ง

ของที่มี: ทุกครั้งยังเป็นอิสระและมีโอกาสเดิม แต่ลด 1R จาก \$1,000 เหลือ \$500 จำนวนครั้งยังเป็น 1,000 และยังไม่หักต้นทุน

คำถาม: ค่าเฉลี่ยและ standard deviation ต่อครั้งกับของผลรวมเปลี่ยนอย่างไร? อัตราส่วนค่าเฉลี่ยต่อ standard deviation เปลี่ยนหรือไม่?

เปิดคำตอบและเหตุผล

ค่าเฉลี่ยต่อครั้งลดครึ่งหนึ่งเป็น \$25 ส่วน standard deviation ลดครึ่งหนึ่งเป็นประมาณ \$660.97 เพราะทั้งคู่ถูกแปลงเป็นดอลลาร์ด้วยตัวคูณเดียวกัน

ผลรวมมีค่าเฉลี่ย \$25,000 และ standard deviation ประมาณ \$20,901.55 อัตราส่วนยังเป็นประมาณ 1.1961 ส่วน variance ในหน่วยดอลลาร์กำลังสองลดเหลือหนึ่งในสี่ ไม่ใช่ครึ่งหนึ่ง

การลดขนาดลดความเสี่ยงหน่วยเงิน แต่ไม่ได้สร้างความได้เปรียบใหม่หรือแก้สมมติฐานที่ผิด และถ้าต้นทุนไม่แปรตามขนาดอย่างเดียว อัตราส่วนหลังต้นทุนอาจเปลี่ยนได้

ตรวจ variance และนับโอกาสขาดทุนจริงหลัง 20 ครั้งด้วย JavaScript 
const pmf = [[-1, 0.55], [0, 0.15], [2, 0.30]];
const mean = pmf.reduce((s, [x, p]) => s + x * p, 0);
const variance = pmf.reduce((s, [x, p]) => s + (x - mean) ** 2 * p, 0);
console.log(mean, variance, Math.sqrt(variance));
let mass = new Map([[0, 1]]);
for (let n = 0; n < 20; n++) {
  const next = new Map();
  for (const [total, probability] of mass) {
    for (const [x, p] of pmf) {
      next.set(total + x, (next.get(total + x) || 0) + probability * p);
    }
  }
  mass = next;
}
const loss = [...mass].filter(([k]) => k < 0)
  .reduce((s, [k, p]) => s + p, 0);
console.log(loss); // ประมาณ 0.4102049308
console.log([...mass.values()].reduce((s, p) => s + p, 0)); // ประมาณ 1

การนับนี้ไม่ใช้ Normal approximation แต่ยังใช้สมมติฐาน PMF เดิมและ independence เหมือนโจทย์ ความถูกต้องของอัลกอริทึมไม่ยืนยันความเหมาะสมของสมมติฐานในตลาดจริง

สรุป — ค่าเฉลี่ยต้องมีตัววัดการกระจายประกอบ

  • variance คือ $\mathbb E[(X-\mu)^2]$ และเท่ากับ $\mathbb E[X^2]-\mu^2$ ส่วน standard deviation เป็นรากที่สองของมัน
  • แบบจำลองนี้ได้ variance 1.7475 R² และ standard deviation ประมาณ 1.32193R เทียบกับกำไรคาดหวังเพียง 0.05R
  • เมื่อผลแต่ละครั้งมี variance เท่ากันและ covariance ระหว่างคู่เป็นศูนย์ ค่าเฉลี่ยรวมเพิ่มตาม $n$ ส่วน standard deviation เพิ่มตาม $\sqrt n$
  • หลัง 1,000 ครั้ง แบบจำลองให้กำไรคาดหวัง \$50,000 และ standard deviation ประมาณ \$41,803 การใช้ Normal ประมาณจึงยังให้โอกาสขาดทุนราว 11.6%
  • หลัง 20 ครั้ง การนับตรง ๆ ให้โอกาสขาดทุนประมาณ 41.0% ต่างจาก Normal ที่ไม่ปรับความเป็น discrete ซึ่งให้ประมาณ 43.3% ต้องตรวจวิธีประมาณ ไม่ใช่เชื่อจากรูปกราฟ

สี่หัวข้อแรกทำให้เรารู้วิธีแจกโอกาส หาค่าเฉลี่ย และวัดการกระจาย ต่อไปจะนำเครื่องมือเหล่านี้ไปสร้าง Binomial distribution สำหรับนับจำนวนครั้งที่สำเร็จจากการทดลองซ้ำที่มีเงื่อนไขชัดเจน
