1.3 Expected Value

ค่าเฉลี่ยบอกความคุ้มภายใต้สมมติฐาน ไม่ได้บอกกำไรครั้งถัดไป

ผลการซื้อขายเป็นได้เพียงกำไร \$2,000 ขาดทุน \$1,000 หรือเท่าทุน แล้วประโยคว่า “กลยุทธ์นี้ได้เฉลี่ยครั้งละ \$50” มาจากไหน ทั้งที่ไม่มีผลลัพธ์ใดจ่าย \$50?

คำตอบอยู่ที่การถ่วงผลลัพธ์ด้วยโอกาส เราจะคำนวณค่าเฉลี่ยนี้จากตารางเดิม แล้วใช้มันตอบคำถามที่จำเป็นกว่า: หักต้นทุนแล้วเหลือเท่าไร รวมหลายครั้งอย่างไร และสมมติฐานเปลี่ยนได้แค่ไหนก่อนกำไรคาดหวังจะหายไป

ข้อมูลตั้งต้น — ใช้ PMF จากหัวข้อ 1.2

ผลลัพธ์ในหน่วย Rกำไรขาดทุน เมื่อ 1R = \$1,000โอกาส
−1R−\$1,0000.55
0R\$00.15
+2R+\$2,0000.30

โอกาสเป็นสมมติฐานของโจทย์ ไม่ใช่ข้อมูลยืนยันของ TSLA และผลลัพธ์ยังไม่หักต้นทุน ให้ $X$ เป็นผลลัพธ์ในหน่วย R ส่วน $Y=1{,}000X$ เป็นกำไรขาดทุนหน่วยดอลลาร์

เหตุใดจึงต้องถ่วงด้วยโอกาส

ลองจัดกรณีสมมติ 100 ครั้งให้ตรงกับสัดส่วนในตาราง: แพ้ 55 ครั้ง เท่าทุน 15 ครั้ง และชนะ 30 ครั้ง เงินรวมจะเป็น $55(-1{,}000)+15(0)+30(2{,}000)=\$5{,}000$ หาร 100 ได้ \$50 ต่อครั้ง

การยกตัวอย่าง 100 ครั้งช่วยให้เห็นวิธีคิด แต่ไม่ได้บอกว่าการทดลองจริงทุก 100 ครั้งต้องมีจำนวนแพ้ชนะเช่นนี้ เราสามารถนิยามค่าเฉลี่ยจาก distribution ได้โดยไม่ต้องรอให้ทดลองครบจำนวนใดก่อน

ขั้นที่ 1 — สร้าง expected value จากผลลัพธ์และน้ำหนัก

ให้ $x_i$ เป็นผลลัพธ์แบบที่ $i$ และ $p_i$ เป็นโอกาสของมัน Expected value เขียนว่า $\mathbb E[X]$ นิยามโดยนำผลลัพธ์คูณโอกาสแล้วรวมครบทุกกรณี

\[ \begin{aligned} \mathbb E[X]&\equiv\sum_i x_i p_i\\ &=(-1)(0.55)+0(0.15)+2(0.30)\\ &=-0.55+0+0.60\\ &=\boxed{0.05R} \end{aligned} \]

โอกาสเป็นน้ำหนักที่ไม่มีหน่วย ค่าเฉลี่ยจึงมีหน่วยเดียวกับผลลัพธ์ ฝั่งแพ้ลดค่าเฉลี่ยลง 0.55R ฝั่งชนะเพิ่ม 0.60R เหลือกำไรคาดหวัง 0.05R ไม่มีเหตุผลที่ค่านี้ต้องตรงกับผลลัพธ์ใดผลลัพธ์หนึ่งในตาราง

อย่าเฉลี่ยชื่อผลลัพธ์เหมือนมีน้ำหนักเท่ากัน

การคำนวณ $(-1+0+2)/3=1/3R$ ใช้โอกาส 1/3 กับทุกแถว จึงเป็นค่าเฉลี่ยของอีกแบบจำลองหนึ่ง ไม่ใช่ตารางที่โจทย์ให้ คำตอบจริงคือ 0.05R เพราะแถวขาดทุนมีน้ำหนักมากกว่าแถวกำไร

เมื่อคิดจากข้อมูล ให้ใช้ความถี่ของแต่ละผลลัพธ์ เมื่อคิดจากแบบจำลอง ให้ใช้โอกาสของแต่ละผลลัพธ์ อย่าสลับสองอย่างนี้โดยไม่บอกว่ากำลังประมาณอะไร

ค่าเฉลี่ยในข้อมูลเกี่ยวข้องกับ expected value อย่างไร

ให้ $N$ เป็นจำนวนการทดลองทั้งหมด และ $N_i$ เป็นจำนวนครั้งที่ได้ผลลัพธ์ $x_i$ ค่าเฉลี่ยของข้อมูลคำนวณได้สองทาง: รวมผลทุกครั้งแล้วหาร $N$ หรือรวมผลลัพธ์แต่ละแบบคูณสัดส่วนที่แบบนั้นเกิด

ขั้นที่ 2 — แยกค่าเฉลี่ยจากข้อมูลออกจากค่าเฉลี่ยของแบบจำลอง

\[ \begin{aligned} \overline X_N&=\frac{\sum_{k=1}^{N}X_k}{N}\\ &=\sum_i x_i\frac{N_i}{N}\\[3pt] \frac{N_i}{N}&\longrightarrow p_i\\ \overline X_N&\longrightarrow\sum_i x_i p_i=\mathbb E[X] \end{aligned} \]

สองบรรทัดแรกเป็นการจัดกลุ่มข้อมูลแบบเดียวกัน จึงจริงกับข้อมูลที่มีอยู่ ส่วนลูกศรสองบรรทัดท้ายต้องอาศัยเงื่อนไขของ Law of Large Numbers (LLN) เช่น การทดลองเป็นอิสระ ใช้ distribution เดียวกัน และมีค่าเฉลี่ยจำกัด

LLN ไม่กำหนดว่าทำครบ 100 หรือ 1,000 ครั้งแล้วค่าเฉลี่ยต้องใกล้เท่าไร และไม่ได้ป้องกันการหมดทุนระหว่างทาง หาก distribution เปลี่ยนไป การอ้างค่าเฉลี่ยของแบบจำลองเดิมก็ต้องทบทวนด้วย

แพ้บ่อยกว่า แต่ค่าเฉลี่ยยังเป็นบวกได้

อัตราชนะต้องอ่านคู่กับขนาดเงินที่ชนะและแพ้ ในตัวอย่างนี้โอกาสแพ้เป็น $0.55/0.30\approx1.83$ เท่าของโอกาสชนะ แต่กำไรครั้งที่ชนะมีขนาดสองเท่าของขาดทุน จึงชดเชยกันได้ในค่าเฉลี่ยก่อนต้นทุน

ถ้าเปลี่ยนกำไรเป็นเพียง +1R โดยใช้โอกาสเดิม ค่าเฉลี่ยจะเป็น $0.30-0.55=-0.25R$ ทั้งที่อัตราชนะยัง 30% เท่าเดิม จำนวนเงินของแต่ละกรณีจึงสำคัญพอ ๆ กับความถี่

ขั้นที่ 3 — แปลงเป็นดอลลาร์และหักค่าคงที่ด้วย linearity

ถ้า $a$ และ $b$ เป็นค่าคงที่ เราสามารถคูณและบวกก่อนหรือหลังหา expected value ก็ได้ เหตุผลมาจากการกระจายผลรวมและการที่โอกาสทุกกรณีรวมเป็นหนึ่ง

\[ \begin{aligned} \mathbb E[aX+b]&=\sum_i(ax_i+b)p_i\\ &=a\sum_i x_i p_i+b\sum_i p_i\\ &=a\mathbb E[X]+b\\[4pt] \mathbb E[Y]&=1{,}000\mathbb E[X]\\ &=1{,}000(0.05)=\$50\\ \mathbb E[Y-20]&=\$50-\$20=\$30 \end{aligned} \]

1R เท่ากับ \$1,000 จึงแปลงค่าเฉลี่ย 0.05R เป็น \$50 ได้ทันที หากต้นทุนคงที่ \$20 ต่อครั้ง ค่าเฉลี่ยสุทธิเหลือ \$30 แต่ถ้าขนาดการลงทุนหรือต้นทุนเปลี่ยนตามผลสุ่ม ห้ามดึงออกจาก expected value ราวกับเป็นค่าคงที่

Worked Example — ต้นทุน 2% ของเงินที่เสี่ยง กินกำไรเฉลี่ยเท่าไร

ของที่มี: กำไรคาดหวังก่อนต้นทุน 0.05R ต่อครั้ง และต้นทุน 0.02R ต่อครั้ง เมื่อ 1R เท่ากับ \$1,000

คำถาม: ต้นทุนคิดเป็นกี่เปอร์เซ็นต์ของกำไรคาดหวัง และเหลือกำไรคาดหวังสุทธิกี่ดอลลาร์?

คำตอบ: $0.02/0.05=40\%$ ของกำไรคาดหวังเดิม และเหลือ $(0.05-0.02)(1{,}000)=\$30$ ต่อครั้ง ต้นทุนเท่ากับ 2% ของ 1R แต่เท่ากับ 40% ของค่าเฉลี่ยกำไร เพราะใช้ตัวหารคนละตัว

ตรวจเองใน 10 วินาที: คิดเป็นเงินโดยตรงได้ $\$20/\$50=40\%$ เหมือนกัน หากต้นทุนเพิ่มถึง \$50 ค่าเฉลี่ยสุทธิจะเป็นศูนย์

ต้นทุนไม่ได้มีเพียงค่าธรรมเนียม

commission คือค่าธรรมเนียมที่เรียกเก็บตามเงื่อนไขบัญชี spread คือช่องว่างระหว่างราคาที่มีผู้พร้อมซื้อกับราคาที่มีผู้พร้อมขาย และ slippage คือส่วนต่างระหว่างราคาที่ใช้เป็นฐานเปรียบเทียบกับราคาที่ซื้อขายได้จริง ต้องกำหนดวิธีรวมต้นทุนให้ชัดเพื่อไม่ให้นับส่วนเดียวกันซ้ำ

ถ้าต้นทุน $C$ ไม่คงที่ ยังใช้ $\mathbb E[Y-C]=\mathbb E[Y]-\mathbb E[C]$ ได้เมื่อค่าเฉลี่ยมีอยู่ โดยไม่ต้องสมมติ independence แต่ต้องประมาณค่าเฉลี่ยต้นทุนให้เหมาะกับสภาวะที่เกิดจริง เช่น วันที่สภาพคล่องลดลงอาจมีต้นทุนต่างจากวันปกติ

รวมหลายครั้งได้อย่างไร ถ้าผลแต่ละครั้งเกี่ยวข้องกัน

ค่าเฉลี่ยของผลรวมเท่ากับผลรวมของค่าเฉลี่ย เรียกว่า additivity ซึ่งเป็นส่วนหนึ่งของ linearity สมบัตินี้ไม่ต้องใช้ independence แต่ต้องระบุค่าเฉลี่ยของแต่ละครั้งให้ถูกต้อง

ลองกรณีที่ผลสองครั้งเหมือนกันเสมอ ผลรวมจะเป็น −2R, 0R หรือ +4R ด้วยโอกาส 0.55, 0.15 และ 0.30 ค่าเฉลี่ยรวมคือ $(-2)(0.55)+4(0.30)=0.10R$ เท่ากับ $0.05+0.05$ แม้ผลทั้งสองจะสัมพันธ์กันเต็มที่

ขั้นที่ 4 — พิสูจน์ additivity โดยไม่แอบใช้ independence

ให้ $A$ และ $B$ เป็นผลของสองครั้ง และให้ $p_{ij}$ เป็นโอกาสที่ทั้ง $A=a_i$ และ $B=b_j$ เมื่อรวม $p_{ij}$ ครบทุกค่า $j$ จะได้โอกาสของ $A=a_i$ เพียงอย่างเดียว

\[ \begin{aligned} \mathbb E[A+B]&=\sum_i\sum_j(a_i+b_j)p_{ij}\\ &=\sum_i a_i\sum_jp_{ij}\\ &\quad+\sum_j b_j\sum_ip_{ij}\\ &=\sum_i a_iP(A=a_i)\\ &\quad+\sum_j b_jP(B=b_j)\\ &=\mathbb E[A]+\mathbb E[B] \end{aligned} \]

เราเพียงแยกผลรวมออกเป็นสองส่วน ไม่เคยแทนโอกาสร่วมด้วยผลคูณของโอกาส สมบัติจึงไม่ต้องใช้ independence เมื่อนำเหตุผลนี้ไปใช้ซ้ำกับหลายครั้ง ก็รวมค่าเฉลี่ยทีละครั้งได้ แต่ห้ามนำข้อสรุปเดียวกันไปใช้กับผลคูณ เช่น $\mathbb E[AB]$ โดยไม่ตรวจเงื่อนไขเพิ่มเติม

ขั้นที่ 5 — จากกำไรคาดหวังต่อครั้งเป็นหนึ่งปี

โจทย์กำหนดให้ซื้อขายวันละ 4 ครั้ง เป็นเวลา 252 วัน รวม $n$ ครั้ง และให้ทุกครั้งมีค่าเฉลี่ยก่อนต้นทุน \$50 กับต้นทุนเฉลี่ย \$20 โดยไม่เปลี่ยนขนาด 1R

\[ \begin{aligned} n&=4(252)=1{,}008\\ \mathbb E[\text{gross total}]&=\sum_{i=1}^{1008}\$50\\ &=\$50{,}400\\ \mathbb E[\text{total cost}]&=1{,}008(\$20)\\ &=\$20{,}160\\ \mathbb E[\text{net total}]&=\$50{,}400-\$20{,}160\\ &=\boxed{\$30{,}240} \end{aligned} \]

นี่คือผลรวมคาดหวังตามจำนวนครั้งและขนาดเงินที่กำหนด ไม่ใช่สูตรดอกเบี้ยทบต้น หากนำกำไรกลับมาเพิ่มขนาดการซื้อขาย หรือค่าเฉลี่ยต่อครั้งเปลี่ยนตามสภาวะตลาด ต้องสร้างแบบจำลองให้ตรงกับกติกาใหม่

ถ้าจำนวนครั้งเองก็ยังไม่แน่นอน

กรณีนี้ต้องระวังมากขึ้น สมมติว่ามีโอกาสเท่ากันที่จะซื้อขาย 908 หรือ 1,108 ครั้ง และจำนวนครั้ง $N$ เป็นอิสระจากผลการซื้อขาย แต่ละครั้งยังมีกำไรคาดหวังก่อนต้นทุน \$50 เราจะแยกคำนวณสองกรณีก่อน แล้วค่อยถ่วงด้วยโอกาสของจำนวนครั้ง

ขั้นที่ 6 — เฉลี่ยผลรวมเมื่อจำนวนครั้งเป็นตัวแปรสุ่ม

ให้ $W$ เป็นกำไรรวม และ $\mu$ เป็นค่าเฉลี่ยหน่วยดอลลาร์ต่อครั้ง เงื่อนไข independence ที่ให้ทำให้การรู้ $N$ ไม่เปลี่ยนค่าเฉลี่ยของแต่ละครั้ง

\[ \begin{aligned} \mathbb E[W\mid N=908]&=908(\$50)=\$45{,}400\\ \mathbb E[W\mid N=1108]&=1{,}108(\$50)=\$55{,}400\\ \mathbb E[W]&=\tfrac12(\$45{,}400)+\tfrac12(\$55{,}400)\\ &=\$50{,}400\\[3pt] \mathbb E[N]&=\tfrac12(908)+\tfrac12(1{,}108)=1{,}008\\ \mathbb E[W]&=\mu\mathbb E[N] \end{aligned} \]

เครื่องหมาย $\mid N=n$ อ่านว่า “เมื่อกำหนดว่าจำนวนครั้งเป็น $n$” วิธีแยกกรณีนี้ให้ผลเป็นค่าเฉลี่ยจำนวนครั้งคูณค่าเฉลี่ยกำไรต่อครั้ง สำหรับตัวอย่างที่กำหนดเงื่อนไขไว้ แต่ถ้าหยุดหรือเพิ่มการซื้อขายตามผลที่ผ่านมา ห้ามใช้สูตรทันที เงื่อนไขทั่วไปของ Wald's identity จะอยู่ในหัวข้อ 2.3

หาเส้นคุ้มทุน ก่อนสมมติว่าความได้เปรียบจะอยู่ตลอด

ให้โอกาสชนะเป็น $w$ และตรึงโอกาสเท่าทุนไว้ที่ 0.15 โอกาสแพ้จึงต้องเป็น $0.85-w$ เพื่อให้น้ำหนักรวมเป็นหนึ่ง โดย $w$ อยู่ระหว่าง 0 กับ 0.85 กำไรเมื่อชนะยังเป็น +2R และขาดทุนเมื่อแพ้ยังเป็น −1R

ขั้นที่ 7 — แก้หา breakeven win rate ก่อนและหลังต้นทุน

Breakeven win rate คือโอกาสชนะที่ทำให้กำไรคาดหวังเท่ากับศูนย์ ไม่ใช่โอกาสชนะที่ทำให้ทุกช่วงเวลามีกำไร

\[ \begin{aligned} \mathbb E[X]&=2w-(0.85-w)+0(0.15)\\ &=3w-0.85\\ 0&=3w_{\text{gross}}-0.85\\ w_{\text{gross}}&=\frac{0.85}{3}\approx28.33\%\\[3pt] 0&=3w_{\text{net}}-0.85-0.02\\ w_{\text{net}}&=\frac{0.87}{3}=29.00\% \end{aligned} \]

ก่อนต้นทุน สมมติฐานชนะ 30% สูงกว่าจุดคุ้มทุนประมาณ 1.67 จุดเปอร์เซ็นต์ หลังต้นทุน 0.02R เหลือระยะห่างเพียง 1 จุดเปอร์เซ็นต์ หากต้นทุนหรือโอกาสเท่าทุนเปลี่ยน สูตรจุดคุ้มทุนก็ต้องเปลี่ยนตาม

ใน 1,008 ครั้ง การเปลี่ยนจากชนะเป็นแพ้ประมาณ $1{,}008(0.30-0.85/3)=16.8$ ครั้งจะลบกำไรเฉลี่ยก่อนต้นทุนเดิมได้ แต่การนับนี้ตรึงจำนวนครั้งที่เท่าทุนและขนาดผลลัพธ์ไว้ ไม่ใช่กฎทั่วไปของทุกกลยุทธ์

ลองทำเอง 1 — ต้นทุนเพิ่ม แต่ PMF เดิม

ของที่มี: ผลลัพธ์และโอกาสเดิม แต่ต้นทุนเพิ่มเป็น 0.035R ต่อครั้ง ใช้ 1R เท่ากับ \$1,000 และ 1,008 ครั้งต่อปี

คำถาม: ค่าเฉลี่ยสุทธิต่อครั้งและทั้งปีเป็นเท่าไร? หากโอกาสเท่าทุนยังเป็น 0.15 ต้องชนะกี่เปอร์เซ็นต์จึงคุ้มทุนหลังต้นทุน?

เปิดวิธีคิด

ค่าเฉลี่ยสุทธิ $0.05-0.035=0.015R$ หรือ \$15 ต่อครั้ง ทั้งปีจึงคาดหวัง $1{,}008(15)=\$15{,}120$

ตั้ง $3w-0.85-0.035=0$ ได้ $w=0.885/3=29.5\%$ ระยะห่างจากสมมติฐาน 30% เหลือเพียง 0.5 จุดเปอร์เซ็นต์

ตรวจเองใน 10 วินาที: ต้นทุนเพิ่มต้องทำให้กำไรคาดหวังลดลง และทำให้อัตราชนะที่คุ้มทุนสูงขึ้น

ลองทำเอง 2 — วงล้อที่รางวัลเฉลี่ยไม่ใช่รางวัลที่ได้

วงล้อมีสี่ช่องขนาดเท่ากัน ให้รางวัล \$0, \$0, \$0 และ \$40 จ่ายค่าหมุนครั้งละ \$8 ทุกช่องมีโอกาสออกเท่ากัน ถามเงินรางวัลคาดหวัง กำไรคาดหวัง และค่าหมุนที่ทำให้กำไรคาดหวังเป็นศูนย์

เปิดคำตอบและข้อจำกัด

เงินรางวัลคาดหวังคือ $0(3/4)+40(1/4)=\$10$ กำไรคาดหวังหลังค่าหมุนคือ $10-8=\$2$ และค่าหมุนที่คุ้มทุนในค่าเฉลี่ยคือ \$10

ไม่ได้หมายความว่าทุกคนควรยอมจ่าย \$10 เพราะผู้เล่นอาจไม่ต้องการรับความเสี่ยงหรือมีเงินจำกัด ค่าเฉลี่ยช่วยบอกเงื่อนไขคุ้มทุน แต่ไม่ตัดสินความเหมาะสมแทนผู้เล่น

สำหรับตัวแปรต่อเนื่อง และกรณีที่ค่าเฉลี่ยไม่จำกัด

ถ้าตัวแปรมี Probability Density Function (PDF) ชื่อ $f(x)$ เราใช้พื้นที่เล็ก ๆ แทนโอกาสทีละค่า แล้วรวมด้วย integral นิยามจึงเป็น $\mathbb E[X]=\int_{-\infty}^{\infty}x f(x)\,dx$ สำหรับค่าเฉลี่ยจำกัด ต้องมีผลรวมของขนาดผลลัพธ์ถ่วงโอกาสที่จำกัดด้วย แนวคิดเรื่อง PDF และ integral จะอธิบายในหัวข้อ 1.8

ตัวอย่างที่เตือนว่า “ค่าเฉลี่ย” อาจใช้ตรง ๆ ไม่ได้คือเกม St. Petersburg: โยนเหรียญยุติธรรมจนออกหัวครั้งแรก ถ้าออกครั้งที่ $n$ ได้เงิน $2^n$ ดอลลาร์ โอกาสของกรณีนั้นเป็น $2^{-n}$ แต่ละกรณีจึงเพิ่มเงินคาดหวัง \$1 และเมื่อรวมทุก $n$ จะไม่สิ้นสุด นี่ไม่ได้แปลว่าผู้เล่นควรยอมจ่ายไม่จำกัด

ในงานของ Daniel Bernoulli ปัญหานี้นำไปสู่การพิจารณาคุณค่าของเงินต่อผู้รับและความสามารถรับความเสี่ยง บทเรียนที่ใช้กับการเงินคือ ตัวเลขค่าเฉลี่ยไม่อาจแทนทุกมิติของการตัดสินใจได้ แม้ในกรณีที่คำนวณค่าเฉลี่ยได้ก็ตาม

สิ่งที่คำนวณได้สิ่งที่ยังต้องตรวจ
กำไรคาดหวังเป็นบวกผลลัพธ์กระจายกว้างแค่ไหน และมีโอกาสขาดทุนหนักหรือหมดทุนหรือไม่
ค่าเฉลี่ยจาก backtest เป็นบวกข้อมูลมีอคติหรือไม่ ค่าประมาณไม่แน่นอนแค่ไหน และสมมติฐานยังเหมาะกับอนาคตหรือไม่

รู้ค่าเฉลี่ยต่อครั้งจำนวนครั้ง ขนาดเงิน และกติกาหยุดซื้อขายคงที่หรือขึ้นกับผลที่ผ่านมา

ศัพท์ที่ควรแยกให้ออก
expected value / sample mean
ค่าแรกเป็นค่าเฉลี่ยของ distribution ส่วนค่าหลังคำนวณจากข้อมูลที่เกิดขึ้นจริง อาจใกล้กันเมื่อมีเงื่อนไขและข้อมูลเพียงพอ แต่ไม่ใช่สิ่งเดียวกัน
linearity / additivity
linearity ให้กระจาย expected value ผ่านผลรวมที่คูณด้วยค่าคงที่ได้ ส่วน additivity เน้นกรณีค่าเฉลี่ยของผลรวมเท่ากับผลรวมของค่าเฉลี่ย
edge / breakeven
edge คือความได้เปรียบของกลยุทธ์ภายใต้สมมติฐานและต้นทุนที่เหมาะสม ส่วน breakeven ในหน้านี้หมายถึงจุดที่กำไรคาดหวังสุทธิเป็นศูนย์
LLN / Wald's identity
LLN เชื่อมค่าเฉลี่ยจากข้อมูลกับค่าเฉลี่ยของ distribution ภายใต้เงื่อนไข ส่วน Wald's identity เกี่ยวกับค่าเฉลี่ยของผลรวมที่มีจำนวนพจน์สุ่ม ต้องตรวจเงื่อนไขก่อนใช้

$\mathbb E[X]$ / $\overline X_N$ค่าเฉลี่ยตาม distribution / ค่าเฉลี่ยจากข้อมูล $N$ ครั้ง

ตรวจค่าเฉลี่ย ต้นทุน และจุดคุ้มทุนด้วย JavaScript 
const outcomes = [[-1, 0.55], [0, 0.15], [2, 0.30]];
const meanR = outcomes.reduce((s, [x, p]) => s + x * p, 0);
const trades = 4 * 252;
const riskUSD = 1000;
const costR = 0.02;
console.log(meanR);                         // ประมาณ 0.05
console.log(meanR * riskUSD);               // ประมาณ 50
console.log(trades * meanR * riskUSD);      // ประมาณ 50400
console.log(trades * costR * riskUSD);      // 20160
console.log(trades * (meanR - costR) * riskUSD); // ประมาณ 30240
console.log(0.85 / 3);                      // ประมาณ 0.283333
console.log((0.85 + costR) / 3);             // 0.29
console.log(0.5 * 908 * 50 + 0.5 * 1108 * 50); // 50400

ผลทศนิยมอาจมีเศษจากการแทนเลขในคอมพิวเตอร์ ให้ปัดเมื่อรายงานคำตอบ ไม่ใช่ปัดทุกขั้นก่อนนำไปคำนวณต่อ

สรุป — ใช้ค่าเฉลี่ยให้ตรงหน้าที่

  • expected value ถ่วงผลลัพธ์ด้วยโอกาส ไม่ใช่เฉลี่ยค่าที่ต่างกันทุกค่าเท่า ๆ กัน และไม่จำเป็นต้องเป็นผลลัพธ์ที่เกิดได้จริง
  • กำไรคาดหวัง 0.05R เท่ากับ \$50 เมื่อ 1R เป็น \$1,000 ถ้าต้นทุน 0.02R ค่าเฉลี่ยสุทธิเหลือ \$30
  • ค่าเฉลี่ยของผลรวมเท่ากับผลรวมของค่าเฉลี่ยโดยไม่ต้องใช้ independence แต่ไม่ได้หมายความว่าความสัมพันธ์ไม่สำคัญต่อความเสี่ยง
  • จำนวนครั้งสุ่มหรือขนาดลงทุนที่เปลี่ยนตามผลต้องมีแบบจำลองรองรับ ห้ามคูณค่าเฉลี่ยสองตัวโดยอัตโนมัติ
  • จุดคุ้มทุนต้องรวมต้นทุนและสมมติฐานเรื่อง payoff ด้วย ในตัวอย่างนี้อัตราชนะคุ้มทุนเพิ่มจากประมาณ 28.33% เป็น 29% เมื่อคิดต้นทุน 0.02R

หัวข้อถัดไปจะเติมสิ่งที่ค่าเฉลี่ยไม่บอก: ผลจริงกระจายห่างจากค่าเฉลี่ยเท่าไร และเพราะเหตุใดกลยุทธ์ที่มีกำไรคาดหวังจึงยังขาดทุนในช่วงเวลาที่เราลงทุนได้
