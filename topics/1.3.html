1.3 Expected Value

Expected value คือค่าเฉลี่ยของผลลัพธ์ โดยถ่วงแต่ละผลด้วยโอกาสของมัน มันคือจุดสมดุลของ PMF และบอกว่าถ้าทำซ้ำไปนาน ๆ จะได้เฉลี่ยครั้งละเท่าไร แต่ไม่ได้บอกว่าครั้งหน้าจะได้เท่าไร

ในหน้า PMF เทรดเดอร์คนหนึ่งซื้อหุ้น TSLA 200 หุ้นที่ราคา \$200 แล้ววางทางออกไว้สองทาง ถ้าราคาลงถึง \$195 เขาขายตัดขาดทุน ถ้าราคาขึ้นถึง \$210 เขาขายเอากำไร

เงินที่เขายอมเสียต่อครั้งคือระยะลง \$5 ต่อหุ้น คูณ 200 หุ้น: $200\times\$5=\$1{,}000$ เราเรียกเงินก้อนนี้ว่า 1R แล้ววัดผลทุกครั้งเป็นจำนวนเท่าของมัน ระยะขึ้นคือ \$10 ต่อหุ้น จึงได้กำไร $200\times\$10=\$2{,}000$ หรือ 2R การซื้อขายหนึ่งครั้งจึงจบได้แค่สามแบบ

  • ขาดทุน \$1,000 หรือ −1R โอกาส 55%
  • เท่าทุน \$0 หรือ 0R โอกาส 15%
  • กำไร \$2,000 หรือ +2R โอกาส 30%

โอกาสทั้งสามเป็นตัวเลขสมมติ ซึ่งได้จากการลองกลยุทธ์กับข้อมูลราคาย้อนหลัง (เรียกว่า backtest)

ผู้จัดการพอร์ตอ่านรายงานที่เขียนว่า “กลยุทธ์นี้ได้เฉลี่ยครั้งละ \$50” เขาสงสัยสองเรื่อง

ข้อแรก \$50 มาจากไหน ในเมื่อไม่มีการซื้อขายครั้งไหนจบที่ \$50 เลย

ข้อสอง การซื้อขายทุกครั้งมีต้นทุน คือค่าธรรมเนียมที่จ่ายให้โบรกเกอร์ และส่วนต่างระหว่างราคาซื้อกับราคาขายในตลาด สมมติว่าต้นทุนนี้เป็นครั้งละ \$20 ถ้าซื้อขายวันละ 4 ครั้งทุกวันที่ตลาดเปิดตลอดหนึ่งปี จะคาดว่าได้กำไรสุทธิเท่าไร

ลองตอบก่อนเปิดเฉลย

\$50 คือค่าเฉลี่ยที่ถ่วงแต่ละผลด้วยโอกาสของมัน ให้ $Y$ เป็นกำไรขาดทุนของหนึ่งครั้งเป็นดอลลาร์ ก่อนหักต้นทุน

\[\begin{aligned}\mathbb E[Y]&=(-1{,}000)(0.55)+0(0.15)\\&\quad+2{,}000(0.30)\\&=-550+0+600=\$50\end{aligned}\]

\$50 เป็นจุดสมดุลของผลทั้งสามแบบ ไม่ใช่ผลที่ออกได้จริง หักต้นทุนแล้วเหลือ $\$50-\$20=\$30$ ต่อครั้ง

ตลาดหุ้นสหรัฐเปิดซื้อขายปีละประมาณ 252 วัน (ขั้นที่ 6 จะแสดงว่าตัวเลขนี้มาจากไหน) ให้ $n$ เป็นจำนวนครั้งที่ซื้อขายในหนึ่งปี และ $\mathbb E[\text{net}]$ เป็นกำไรสุทธิทั้งปีที่คาดว่าจะได้

\[\begin{aligned}n&=4\times252=1{,}008\\\mathbb E[\text{net}]&=1{,}008\times\$30\\&=\$30{,}240\end{aligned}\]

จุดที่น่ากลัวคือ ต้นทุน \$20 กินกำไรเฉลี่ยไปถึง $20/50=40\%$

ภาพรวมก่อนลงสูตร

PMF คือตารางที่บอกว่าผลแต่ละแบบมีโอกาสเท่าไร ตารางนี้มีข้อมูลครบ แต่ยังตอบผู้จัดการไม่ได้ เขาต้องการตัวเลขเดียวที่ตอบว่า “ถ้าทำแบบนี้ไปเรื่อย ๆ จะได้หรือเสียเฉลี่ยครั้งละเท่าไร”

ตัวเลขนั้นเรียกว่า expected value (ค่าคาดหวัง) เขียนว่า $\mathbb E[X]$ โดย $X$ คือผลของการซื้อขายหนึ่งครั้ง วิธีหาคือเอาผลแต่ละแบบคูณโอกาสของมัน แล้วบวกกันทั้งหมด

ภาพที่ช่วยให้เข้าใจที่สุดคือไม้กระดก วางผลแต่ละแบบเป็นตำแหน่งบนไม้ แล้ววางก้อนน้ำหนักที่หนักเท่ากับโอกาสไว้ตรงนั้น expected value คือตำแหน่งจุดหมุนที่ทำให้ไม้สมดุลพอดี ในกลยุทธ์ TSLA ก้อนขาดทุนหนักที่สุด (0.55) แต่อยู่ใกล้ศูนย์ที่ −1R ส่วนก้อนกำไรเบากว่า (0.30) แต่อยู่ไกลกว่าที่ +2R สองก้อนนี้เกือบหักล้างกัน จุดสมดุลจึงอยู่เลยศูนย์ไปนิดเดียว ขั้นที่ 1 จะคำนวณให้ดูว่าอยู่ที่ 0.05R

หน้านี้จะไปทีละขั้นดังนี้

  • สร้างนิยามของ expected value จากการนับ
  • ดูว่าค่าเฉลี่ยของข้อมูลจริงวิ่งเข้าหา expected value ช้าแค่ไหน
  • ใช้สมบัติที่ชื่อ linearity (ค่าคงที่ที่คูณหรือบวกอยู่ ดึงออกนอกค่าเฉลี่ยได้) เพื่อเปลี่ยนหน่วยเป็นดอลลาร์และหักต้นทุน
  • มองโอกาสเป็นค่าเฉลี่ยของตัวแปรที่เป็น 0 หรือ 1 เพื่อนับจำนวนครั้งที่ชนะ
  • รวมค่าเฉลี่ยของหลายครั้งเป็นทั้งปี
  • หาอัตราชนะต่ำสุดที่กลยุทธ์ยังไม่ขาดทุน
ศัพท์ที่ใช้ในหน้านี้
1R
เงินที่ยอมเสียในการซื้อขายหนึ่งครั้ง ในหน้านี้ 1R = \$1,000 ผลทุกครั้งวัดเป็นจำนวนเท่าของ 1R เช่น กำไร \$2,000 คือ +2R
backtest
การลองกลยุทธ์กับข้อมูลราคาย้อนหลัง เพื่อนับว่าผลแต่ละแบบเกิดบ่อยแค่ไหน
expected value
$\mathbb E[X]=\sum_i x_i p_i$ คือค่าเฉลี่ยของผลลัพธ์ที่ถ่วงด้วยโอกาส ($x_i$ คือผลแบบที่ $i$ และ $p_i$ คือโอกาสของมัน) ใช้วัดว่ากลยุทธ์ได้เปรียบหรือเสียเปรียบเฉลี่ยครั้งละเท่าไร
sample mean
ค่าเฉลี่ยธรรมดาของผลที่เกิดขึ้นจริง ใช้ประมาณ expected value ที่เราไม่รู้ ยิ่งข้อมูลน้อย มันยิ่งแกว่งห่างจาก expected value มาก
linearity
ค่าคงที่ที่คูณหรือบวกอยู่ ดึงออกนอกค่าเฉลี่ยได้ $\mathbb E[aX+b]=a\mathbb E[X]+b$ และค่าเฉลี่ยของผลรวมคือผลรวมของค่าเฉลี่ย $\mathbb E[A+B]=\mathbb E[A]+\mathbb E[B]$ ใช้เปลี่ยนหน่วย หักต้นทุน และรวมหลายครั้ง โดยไม่ต้องรู้ว่าแต่ละครั้งเกี่ยวกันหรือไม่
indicator
ตัวแปรที่เป็น 1 เมื่อเหตุการณ์เกิด และเป็น 0 เมื่อไม่เกิด ค่าเฉลี่ยของมันคือโอกาสของเหตุการณ์ ใช้เปลี่ยนคำถามเรื่องการนับให้เป็นคำถามเรื่องค่าเฉลี่ย
independence
สองครั้งเป็นอิสระกัน เมื่อรู้ผลครั้งหนึ่งแล้วก็เดาอีกครั้งไม่ได้ดีขึ้นเลย
edge
ความได้เปรียบ คือกำไรเฉลี่ยต่อครั้ง ถ้าหักต้นทุนแล้วเรียกว่า edge สุทธิ กลยุทธ์ TSLA มี edge 0.05R และ edge สุทธิ 0.03R ตัวเลขหลังคือตัวที่ตัดสินว่ากลยุทธ์ควรทำต่อหรือไม่
breakeven win rate
อัตราชนะที่คุ้มทุน คืออัตราชนะที่ทำให้กำไรเฉลี่ยเป็นศูนย์พอดี ถ้าอัตราชนะจริงต่ำกว่านี้ กลยุทธ์ขาดทุน ระยะห่างจากอัตราชนะที่สมมติไว้บอกว่าสมมติฐานผิดได้แค่ไหน

ขั้นที่ 1 — จินตนาการ 100 ครั้ง แล้วเขียนเป็นสูตร

ผู้จัดการถามว่า \$50 มาจากไหน วิธีตอบที่เห็นภาพที่สุดคือนึกถึงการซื้อขาย 100 ครั้ง ที่ผลออกตามโอกาสพอดี คือแพ้ 55 ครั้ง เท่าทุน 15 ครั้ง และชนะ 30 ครั้ง แล้วหาค่าเฉลี่ยธรรมดาของ 100 ครั้งนั้น: รวมเงินทั้งหมด แล้วหารด้วย 100

\[\begin{aligned} &55(-\$1{,}000)+15(\$0)+30(\$2{,}000)\\ &\quad=-\$55{,}000+\$60{,}000=\$5{,}000\\ &\$5{,}000\div 100=\$50 \end{aligned}\]

ทีนี้เขียนแบบเดียวกันเป็นสูตรทั่วไป ให้ $x_i$ เป็นผลแบบที่ $i$ วัดเป็น R และ $p_i$ เป็นโอกาสของมัน เครื่องหมาย $\sum_i$ แปลว่าบวกทุกแบบ และ $\equiv$ แปลว่า “นิยามว่า”

\[\begin{aligned} \mathbb E[X]&\equiv\sum_i x_i\,p_i\\ &=(-1)(0.55)+0(0.15)+2(0.30)\\ &=-0.55+0.60=0.05R\\ 0.05R&=0.05\times\$1{,}000=\$50 \end{aligned}\]

ทำไมเลข 100 หายไปได้ เพราะการหารด้วย 100 เปลี่ยนจำนวนครั้งให้เป็นโอกาส เช่น $55/100=0.55$ หลังหารแล้วจึงเหลือแค่ “ผลแต่ละแบบคูณโอกาสของมัน แล้วบวกกัน” นิยามนี้จึงใช้ได้ทันที โดยไม่ต้องรอให้ซื้อขายครบร้อยครั้งจริง

โอกาสไม่มีหน่วย ค่าเฉลี่ยจึงมีหน่วยเดียวกับผลลัพธ์ ถ้าวัดผลเป็น R ก็ได้ 0.05R ถ้าวัดเป็นดอลลาร์ก็ได้ \$50 ทั้งสองค่าไม่ใช่ผลที่ออกได้จริง เหมือนประเทศที่ครอบครัวมีลูกเฉลี่ย 1.6 คน ไม่มีบ้านไหนมีลูก 1.6 คน ค่าเฉลี่ยคือจุดสมดุลของ PMF ตามรูปไม้กระดกด้านบน

ขั้นที่ 2 — ค่าเฉลี่ยจากข้อมูลวิ่งเข้าหา expected value แต่ช้า

ขั้นที่ 1 ใช้ PMF ที่มีคนบอกมาแล้ว แต่ในชีวิตจริงไม่มีใครรู้ PMF ที่แท้จริง เรามีแต่ผลการซื้อขายที่เกิดขึ้นแล้ว สิ่งที่ทำได้คือหาค่าเฉลี่ยธรรมดาของผลเหล่านั้น เรียกว่า sample mean คำถามคือ ค่าเฉลี่ยนี้เกี่ยวกับ $\mathbb E[X]$ อย่างไร เราใช้สัญลักษณ์ดังนี้

  • $N$ คือจำนวนการซื้อขายทั้งหมดที่มีข้อมูล
  • $X_k$ คือผลของครั้งที่ $k$ วัดเป็น R
  • $N_i$ คือจำนวนครั้งที่ได้ผลแบบที่ $i$ เช่น จำนวนครั้งที่ได้ −1R
  • $\overline X_N$ คือค่าเฉลี่ยของผล $N$ ครั้ง
  • ลูกศร $\longrightarrow$ อ่านว่า “เข้าใกล้ เมื่อ $N$ โตขึ้นเรื่อย ๆ”
\[\begin{aligned} \overline X_N&=\frac{1}{N}\sum_{k=1}^{N}X_k\\ &=\sum_i x_i\,\frac{N_i}{N}\\[4pt] \frac{N_i}{N}&\longrightarrow p_i\\ \overline X_N&\longrightarrow\sum_i x_i\,p_i=\mathbb E[X] \end{aligned}\]

การเปลี่ยนจาก “บวกทีละครั้ง” มาเป็น “บวกทีละแบบ” เป็นแค่การจัดกลุ่มใหม่ เรารวมครั้งที่ได้ผลเหมือนกันไว้กองเดียว เช่น กอง −1R มี $N_{-1}$ ครั้ง ผลรวมของกองนี้คือ $(-1)\times N_{-1}$ การจัดกลุ่มนี้จริงกับข้อมูลชุดไหนก็ได้ สูตรที่ได้หน้าตาเหมือนนิยามในขั้นที่ 1 ทุกอย่าง ต่างกันแค่ใช้สัดส่วนที่เห็นในข้อมูล $N_i/N$ แทนโอกาสจริง $p_i$

ลูกศรคือส่วนที่ต้องมีเหตุผลเพิ่ม เงื่อนไขมีสามข้อ คือการซื้อขายแต่ละครั้งเป็นอิสระกัน (ผลครั้งก่อนไม่บอกอะไรเกี่ยวกับครั้งต่อไป) ทุกครั้งใช้ PMF เดียวกัน และค่าเฉลี่ยมีค่าจำกัด เมื่อครบสามข้อ สัดส่วนที่เห็นจะเข้าใกล้โอกาสจริงเมื่อ $N$ โตขึ้น ผลนี้ชื่อ law of large numbers

law of large numbers บอกว่าเข้าใกล้ แต่ไม่ได้บอกว่าเร็วแค่ไหน ค่าเฉลี่ยจาก $N$ ครั้งมักพลาดจาก $\mathbb E[X]$ ราว $1.32/\sqrt N$ R ตัวเลข 1.32R คือ standard deviation ต่อครั้ง คือขนาดที่ผลหนึ่งครั้งแกว่งห่างจากค่าเฉลี่ยตามปกติ หน้า variance และ standard deviationจะคำนวณตัวเลขนี้และที่มาของ $\sqrt N$ ให้ดูทีละขั้น ที่ 1,000 ครั้ง ค่าที่พลาดได้ตามปกติคือ $1.32/\sqrt{1{,}000}=1.32/31.6\approx0.04R$

ค่าพลาด 0.04R นี้เกือบเท่ากับ edge 0.05R ทั้งก้อน ดังนั้นกลยุทธ์ที่ได้เปรียบจริง ก็อาจมีค่าเฉลี่ยติดลบหลังซื้อขายไป 1,000 ครั้งได้ ตามรูปด้านล่าง

ขั้นที่ 3 — เปลี่ยนหน่วยและหักต้นทุนด้วย linearity

ผู้จัดการอยากได้คำตอบเป็นดอลลาร์หลังหักต้นทุน ไม่ใช่เป็น R ก่อนหักต้นทุน กำไรสุทธิของหนึ่งครั้งเป็นดอลลาร์คือ $1{,}000X-20$ คือคูณผลที่เป็น R ด้วย \$1,000 เพื่อเปลี่ยนเป็นดอลลาร์ แล้วลบต้นทุน \$20

เราไม่ต้องสร้าง PMF ใหม่ของกำไรสุทธิ เพราะค่าคงที่ที่คูณอยู่ (เรียกว่า $a$) และค่าคงที่ที่บวกอยู่ (เรียกว่า $b$) ดึงออกนอกเครื่องหมาย $\mathbb E$ ได้ มาดูว่าทำไม แล้วแทน $a=1{,}000$ และ $b=-20$

\[\begin{aligned} \mathbb E[aX+b]&=\sum_i(ax_i+b)\,p_i\\ &=a\sum_i x_i p_i+b\sum_i p_i\\ &=a\,\mathbb E[X]+b\\[4pt] \mathbb E[1{,}000X-20]&=1{,}000(0.05)-20\\ &=\$50-\$20=\$30 \end{aligned}\]

ขั้นสำคัญคือการแยกผลรวมเป็นสองก้อน ก้อนแรกดึง $a$ ออกมาหน้าผลรวมได้ เพราะ $a$ เหมือนกันทุกพจน์ สิ่งที่เหลือข้างในคือ $\mathbb E[X]$ พอดี ก้อนหลังใช้ข้อเท็จจริงว่าโอกาสทุกแบบรวมกันได้หนึ่ง $\sum_i p_i=1$ จึงเหลือ $b$ เดิม นี่คือเหตุผลที่หักต้นทุนคงที่ \$20 ออกจากค่าเฉลี่ยได้ตรง ๆ

ระวังว่าเปอร์เซ็นต์นั้นเทียบกับอะไร ต้นทุน \$20 เทียบกับ 1R เป็นแค่ $20/1{,}000=2\%$ แต่เทียบกับกำไรเฉลี่ยเป็น $20/50=40\%$ ตัวเลขแรกฟังดูเล็ก ตัวเลขหลังบอกความจริงว่าต้นทุนกินความได้เปรียบไปเกือบครึ่ง ถ้าต้นทุนขึ้นถึง \$50 กำไรเฉลี่ยจะเหลือ $\$50-\$50=\$0$ ความได้เปรียบหายหมด

ขั้นที่ 4 — โอกาสก็คือค่าเฉลี่ยของตัวแปร 0/1

ต่อไปผู้จัดการอยากรู้ว่าในหนึ่งปีจะชนะกี่ครั้งโดยเฉลี่ย นี่เป็นคำถามเรื่องการนับ ไม่ใช่เรื่องเงิน แต่เราเปลี่ยนมันเป็นคำถามเรื่องค่าเฉลี่ยได้ ด้วยตัวแปรที่เรียกว่า indicator คือตัวแปรที่เป็น 1 เมื่อเหตุการณ์เกิด และเป็น 0 เมื่อไม่เกิด เราใช้สัญลักษณ์ดังนี้

  • $\mathbf 1_{\mathrm{win}}$ คือ indicator ของการชนะ (ได้ +2R) ในการซื้อขายหนึ่งครั้ง
  • $\mathbf 1_{\mathrm{win},k}$ คือ indicator ตัวเดียวกันของครั้งที่ $k$
  • $n$ คือจำนวนการซื้อขายในหนึ่งปี และ $K$ คือจำนวนครั้งที่ชนะในปีนั้น
  • $P(X=2)$ คือโอกาสที่ผลออกมาเป็น +2R
\[\begin{aligned} \mathbf 1_{\mathrm{win}}&=\begin{cases}1,&X=2\\0,&X\ne 2\end{cases}\\[4pt] \mathbb E[\mathbf 1_{\mathrm{win}}]&=1(0.30)+0(0.70)\\ &=0.30=P(X=2)\\[4pt] K&=\sum_{k=1}^{n}\mathbf 1_{\mathrm{win},k}\\ \mathbb E[K]&=\sum_{k=1}^{n}0.30=0.30\,n\\ &=0.30\times1{,}008=302.4 \end{aligned}\]

ทำไมค่าเฉลี่ยของ indicator คือโอกาส เพราะมันเป็น 1 ด้วยโอกาส 0.30 และเป็น 0 ด้วยโอกาส 0.70 พจน์ที่คูณศูนย์หายไป เหลือ $1\times0.30$ ข้อเท็จจริงเล็ก ๆ นี้ทำให้ทุกเครื่องมือของค่าเฉลี่ยใช้กับโอกาสได้ด้วย

จำนวนครั้งที่ชนะ $K$ คือผลรวมของ indicator ทีละครั้ง เพราะครั้งที่ชนะเพิ่ม 1 และครั้งที่ไม่ชนะเพิ่ม 0 ค่าเฉลี่ยของผลรวมคือผลรวมของค่าเฉลี่ย (ขั้นที่ 5 จะพิสูจน์ว่าทำไมทำได้) จึงได้ 0.30 บวกกัน $n$ ตัว เมื่อ $n=1{,}008$ ครั้งต่อปี (จากเฉลยตอนต้นหน้า) จะชนะเฉลี่ย 302.4 ครั้ง ตัวเลขที่มีทศนิยมนี้เป็นค่าเฉลี่ย ไม่ใช่จำนวนที่นับได้จริงในปีใดปีหนึ่ง

วิธีนี้คือที่มาของค่าเฉลี่ย $np$ ในหน้า binomial distribution ซึ่งนับจำนวนครั้งที่สำเร็จจาก $n$ ครั้ง เมื่อแต่ละครั้งสำเร็จด้วยโอกาส $p$ และเป็นวิธีเดียวกับที่ใช้หาจำนวนเฉลี่ยของเหตุการณ์ที่ถูกคัดออกมาบางส่วน เช่น คำสั่งซื้อขายที่ส่งเข้ามาแล้วจับคู่สำเร็จ ในหน้า Poisson thinning

ขั้นที่ 5 — ค่าเฉลี่ยของผลรวมบวกกันได้เสมอ แต่ผลคูณไม่ได้

ขั้นที่ 4 แอบใช้สมบัติสำคัญข้อหนึ่ง คือค่าเฉลี่ยของผลรวมเท่ากับผลรวมของค่าเฉลี่ย ต้องเช็กว่าสมบัตินี้ต้องให้แต่ละครั้งเป็นอิสระกันหรือไม่ (independence คือรู้ผลครั้งหนึ่งแล้วก็เดาอีกครั้งไม่ได้ดีขึ้น) เพราะการซื้อขายจริงมักเกี่ยวกัน เช่น วันที่ตลาดตกแรง การซื้อขายหลายครั้งอาจแพ้พร้อมกัน เราใช้สัญลักษณ์ดังนี้

  • $A$ และ $B$ คือผลของการซื้อขายสองครั้ง วัดเป็น R
  • $a_i$ และ $b_j$ คือค่าที่ $A$ และ $B$ ออกได้
  • $p_{ij}$ คือโอกาสที่ $A=a_i$ และ $B=b_j$ เกิดพร้อมกัน
\[\begin{aligned} \mathbb E[A+B]&=\sum_i\sum_j(a_i+b_j)\,p_{ij}\\ &=\sum_i a_i\sum_j p_{ij}+\sum_j b_j\sum_i p_{ij}\\ &=\mathbb E[A]+\mathbb E[B] \end{aligned}\]

ขั้นสำคัญคือการแยกผลรวมเป็นสองก้อน แล้วใช้ว่า $\sum_j p_{ij}$ คือโอกาสที่ $A=a_i$ ไม่ว่า $B$ จะออกอะไร เพราะการบวกโอกาสทุกค่าของ $B$ เหลือแค่โอกาสของ $A$ ก้อนแรกจึงเป็น $\mathbb E[A]$ และก้อนหลังเป็น $\mathbb E[B]$ ด้วยเหตุผลเดียวกัน ไม่มีจุดไหนต้องเขียน $p_{ij}$ เป็นผลคูณของโอกาสสองตัว สมบัตินี้จึงจริง แม้สองครั้งจะเกี่ยวกันเต็มที่

ลองกับกรณีสุดขั้ว ส่งสัญญาณซื้อขายเดียวกันเข้าสองบัญชี ผลสองบัญชีจึงเหมือนกันทุกครั้ง คือ $A=B=X$ เทียบค่าเฉลี่ยของผลรวมกับค่าเฉลี่ยของผลคูณ เมื่อ $A=B=X$ ผลคูณ $AB$ ก็คือ $X^2$

\[\begin{aligned} \mathbb E[A+B]&=0.05+0.05=0.10R\\[4pt] \mathbb E[AB]&=\mathbb E[X^2]\\ &=(-1)^2(0.55)+0^2(0.15)+2^2(0.30)\\ &=0.55+1.20=1.75\\ \mathbb E[A]\,\mathbb E[B]&=0.05\times0.05=0.0025 \end{aligned}\]

ผลรวมยังใช้สมบัติเดิมได้ ค่าเฉลี่ยรวมเป็น 0.10R แม้สองบัญชีเกี่ยวกันเต็มที่ แต่ผลคูณไม่เป็นแบบนั้น $\mathbb E[AB]=1.75$ ขณะที่ $\mathbb E[A]\,\mathbb E[B]=0.0025$ ต่างกัน $1.75/0.0025=700$ เท่า การแยกค่าเฉลี่ยของผลคูณให้เป็นผลคูณของค่าเฉลี่ย ต้องให้ $p_{ij}$ แยกเป็นโอกาสของ $A$ คูณโอกาสของ $B$ ได้ ซึ่งก็คือ independence พอดี เรื่องนี้ขยายในหน้าผลของ independence

ขั้นที่ 6 — จากต่อครั้งเป็นหนึ่งปี

ตอนนี้ตอบคำถามข้อสองของผู้จัดการได้ ก่อนอื่นต้องรู้ว่าปีหนึ่งซื้อขายกี่ครั้ง ตลาดหุ้นสหรัฐเปิดซื้อขายปีละประมาณ 252 วัน ตัวเลขนี้มาจากปฏิทิน เช่น ปี 2024 มี 366 วัน เป็นเสาร์อาทิตย์ 104 วัน และเป็นวันหยุดตลาดอีก 10 วัน จึงเหลือวันซื้อขาย $366-104-10=252$ วัน กลยุทธ์ซื้อขายวันละ 4 ครั้ง และทุกครั้งเสี่ยง 1R = \$1,000 เท่ากัน

ให้ $\mathbb E[\text{gross}]$ เป็นกำไรคาดหวังทั้งปีก่อนหักต้นทุน $\mathbb E[\text{cost}]$ เป็นต้นทุนทั้งปี และ $\mathbb E[\text{net}]$ เป็นกำไรสุทธิทั้งปี

\[\begin{aligned} n&=4\times252=1{,}008\\[4pt] \mathbb E[\text{gross}]&=1{,}008\times\$50=\$50{,}400\\ \mathbb E[\text{cost}]&=1{,}008\times\$20=\$20{,}160\\ \mathbb E[\text{net}]&=\$50{,}400-\$20{,}160\\ &=\boxed{\$30{,}240} \end{aligned}\]

ทำไมคูณ 1,008 ได้ตรง ๆ เพราะกำไรทั้งปีคือผลรวมของ 1,008 ครั้ง และขั้นที่ 5 เพิ่งพิสูจน์ว่าค่าเฉลี่ยของผลรวมคือผลรวมของค่าเฉลี่ย จึงไม่ต้องรู้ว่าผลแต่ละวันเกี่ยวกันหรือไม่

แต่ \$30,240 คือค่าคาดหวังทั้งปี ไม่ใช่ยอดที่จะเห็นตอนสิ้นปี ผลจริงจะแกว่งรอบ \$30,240 กว้างมาก หน้า variance และ standard deviationจะวัดว่ากว้างแค่ไหน อีกข้อหนึ่ง สูตรนี้ใช้ได้เพราะทุกครั้งเสี่ยง \$1,000 เท่ากัน ถ้านำกำไรกลับไปเพิ่มขนาด 1R ระหว่างปี ผลแต่ละครั้งจะมีขนาดเงินไม่เท่ากัน ต้องสร้างแบบจำลองใหม่

ขั้นที่ 7 — อัตราชนะที่คุ้มทุน และที่ว่างให้ผิด

อัตราชนะ 30% มาจาก backtest ซึ่งอาจผิดได้ คำถามสุดท้ายจึงเป็น ถ้าอัตราชนะจริงต่ำกว่า 30% จะต่ำได้แค่ไหนก่อนกลยุทธ์เริ่มขาดทุน อัตราชนะที่ทำให้กำไรเฉลี่ยเป็นศูนย์พอดี เรียกว่า breakeven win rate (อัตราชนะที่คุ้มทุน) เราใช้สัญลักษณ์และสมมติฐานดังนี้

  • $w$ คือโอกาสชนะ (ได้ +2R)
  • โอกาสเท่าทุนตรึงไว้ที่ 0.15 เท่าเดิม
  • โอกาสแพ้จึงเป็น $1-0.15-w=0.85-w$ เพื่อให้โอกาสรวมเป็นหนึ่ง
  • ต้นทุนต่อครั้งวัดเป็น R ได้ $\$20/\$1{,}000=0.02R$
  • $w_{\mathrm{gross}}$ คืออัตราชนะที่คุ้มทุนก่อนหักต้นทุน และ $w_{\mathrm{net}}$ คืออัตราชนะที่คุ้มทุนหลังหักต้นทุน
\[\begin{aligned} \mathbb E[X]&=2w+0(0.15)-1(0.85-w)\\ &=3w-0.85\\[4pt] 3w_{\mathrm{gross}}-0.85&=0\\ w_{\mathrm{gross}}&=0.85/3\approx 28.33\%\\[4pt] 3w_{\mathrm{net}}-0.85-0.02&=0\\ w_{\mathrm{net}}&=0.87/3=29\% \end{aligned}\]

ทำไมสัมประสิทธิ์หน้า $w$ เป็น 3 เพราะทุกครั้งที่ผลหนึ่งครั้งย้ายจากแพ้ไปเป็นชนะ เราไม่ต้องเสีย 1R และได้ 2R แทน ผลต่างคือ $2-(-1)=3$R เส้นกำไรเฉลี่ยจึงชันเป็น 3 ก่อนหักต้นทุน จุดคุ้มทุนอยู่ที่ 28.33% หลังหักต้นทุน 0.02R ต่อครั้ง ทั้งเส้นเลื่อนลง 0.02 จุดคุ้มทุนจึงขยับขึ้นมาที่ 29%

ที่ว่างให้ผิดจึงเหลือแค่ $30\%-29\%=1$ จุดเปอร์เซ็นต์ ลองแปลเป็นจำนวนครั้ง กำไรเฉลี่ยหลังหักต้นทุนคือ $0.05-0.02=0.03$R ต่อครั้ง ทั้งปีจึงมี edge สุทธิ $1{,}008\times0.03R=30.24R$ การชนะที่กลายเป็นแพ้หนึ่งครั้งทำให้เสีย 3R ดังนั้นการพลิกแค่ $30.24/3\approx10$ ครั้งจาก 1,008 ครั้ง (ราว 1% ของทั้งหมด ตรงกับที่ว่าง 1 จุดเปอร์เซ็นต์) ก็ลบกำไรคาดหวังทั้งปีหมด ตัวเลขนี้คือเหตุผลที่ต้องสงสัยอัตราชนะจาก backtest ให้มาก

จุดที่พลาดแล้วได้คำตอบผิดโดยไม่รู้ตัว

เฉลี่ยผลทั้งสามแบบโดยไม่ถ่วงโอกาส ค่าที่ผิดคือ $(-1+0+2)/3=0.33R$ สูตรนี้แอบให้ผลทุกแบบมีโอกาสเท่ากัน 1/3 ซึ่งเป็นกลยุทธ์อีกตัวหนึ่ง ค่าที่ถูกคือ $(-1)(0.55)+0(0.15)+2(0.30)=0.05R$ ค่าที่ผิดสูงกว่าค่าที่ถูก $0.33/0.05\approx6.7$ เท่า

คิดว่าค่าเฉลี่ยของฟังก์ชันเท่ากับฟังก์ชันของค่าเฉลี่ย สมมติผู้จัดการได้ส่วนแบ่งเฉพาะครั้งที่มีกำไร ครั้งที่ขาดทุนนับเป็นศูนย์ สิ่งที่ต้องเฉลี่ยจึงเป็น $\max(X,0)$ คือเอา $X$ ถ้าเป็นบวก ไม่อย่างนั้นเอา 0 ค่าที่ผิดได้จากการเฉลี่ยก่อนแล้วค่อยตัดส่วนติดลบ: $\max(\mathbb E[X],0)=\max(0.05,0)=0.05R$ ค่าที่ถูกได้จากการตัดส่วนติดลบของแต่ละผลก่อน แล้วค่อยเฉลี่ย

\[\begin{aligned} \mathbb E[\max(X,0)]&=0(0.55)+0(0.15)+2(0.30)\\ &=0.60R \end{aligned}\]

สองค่าต่างกัน $0.60/0.05=12$ เท่า ความไม่เท่ากันแบบนี้คือเหตุผลที่สัญญาซึ่งจ่ายเฉพาะด้านบวก เช่น option (สัญญาที่ให้สิทธิ์ซื้อหรือขายที่ราคาตกลงไว้ แต่ไม่บังคับให้ใช้สิทธิ์) มีมูลค่ามากกว่าที่ค่าเฉลี่ยตรง ๆ บอก

เชื่อว่าการเปลี่ยนขนาดเดิมพันตามผลสร้างกำไรได้ วิธีแทงทบคือเริ่มแทง \$1 ถ้าแพ้ก็แทงเพิ่มเป็นสองเท่า ทำไปจนกว่าจะชนะ ถ้าชนะที่ตาที่ $k$ จะได้ $2^{k-1}$ และเสียไปก่อนหน้า $1+2+\cdots+2^{k-2}=2^{k-1}-1$ จึงได้สุทธิ \$1 เสมอ ดูเหมือนเป็นเงินฟรี ลองเกมโยนเหรียญยุติธรรม (ชนะได้เท่าที่แทง แพ้เสียเท่าที่แทง โอกาสครึ่งต่อครึ่ง) ที่เงินพอเล่นได้ไม่เกินสิบตา ให้ $G$ เป็นเงินสุทธิของทั้งเกม

  • แพ้ครบสิบตา มีโอกาส $(1/2)^{10}=1/1{,}024$ และเสียรวม $1+2+\cdots+512=2^{10}-1=\$1{,}023$
  • ชนะก่อนครบสิบตา มีโอกาส $1-1/1{,}024=1{,}023/1{,}024$ และได้สุทธิ \$1
\[\begin{aligned} \mathbb E[G]&=\tfrac{1{,}023}{1{,}024}(\$1)+\tfrac{1}{1{,}024}(-\$1{,}023)\\ &=\$0 \end{aligned}\]

ค่าเฉลี่ยเป็นศูนย์พอดี การจัดลำดับเดิมพันเปลี่ยนรูปร่างของผลได้ (ได้เล็ก ๆ บ่อย แต่เสียก้อนใหญ่นาน ๆ ครั้ง) แต่สร้าง edge จากเกมที่ไม่มี edge ไม่ได้ (martingale betting system)

เชื่อว่าค่าเฉลี่ยมีอยู่เสมอ เกม St. Petersburg คือโยนเหรียญไปเรื่อย ๆ จนกว่าจะออกหัว ถ้าหัวออกครั้งแรกที่ตาที่ $k$ ผู้เล่นได้ $2^k$ ดอลลาร์ กรณีนี้มีโอกาส $2^{-k}$ เพราะต้องออกก้อย $k-1$ ตาติดกันแล้วออกหัว ให้ $W$ เป็นเงินรางวัล แต่ละกรณีเพิ่มค่าเฉลี่ย $2^k\times2^{-k}=\$1$ เท่ากันทุกกรณี และมีกรณีไม่สิ้นสุด

\[\begin{aligned} \mathbb E[W]&=\sum_{k=1}^{\infty}2^k\cdot2^{-k}\\ &=1+1+1+\cdots \end{aligned}\]

ผลรวมนี้โตไม่หยุด ค่าเฉลี่ยจึงไม่มีอยู่จริง ค่าเฉลี่ยของข้อมูลจากเกมแบบนี้จะไม่นิ่ง ไม่ว่าเก็บข้อมูลนานเท่าไร ผลตอบแทนที่หางหนัก (ผลสุดขั้วเกิดบ่อยกว่าที่คาด) มีปัญหาแบบเดียวกันในระดับที่เบากว่า

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะเทรด (ทีมที่ซื้อขายในตลาด) ต้องตั้งเป้ากำไรขาดทุนของปีล่วงหน้า และเป้านี้เริ่มจากสามตัวเลขในหน้านี้ คือ edge ต่อครั้งหลังหักต้นทุน จำนวนครั้งต่อปี และอัตราชนะที่คุ้มทุน

ทีมความเสี่ยงจะถามเสมอสองข้อ ข้อแรก ที่ว่างระหว่างอัตราชนะที่สมมติกับอัตราชนะที่คุ้มทุนกว้างแค่ไหน ข้อสอง edge นั้นวัดจากข้อมูลกี่ครั้ง ตามรูปค่าเฉลี่ยสะสม ข้อมูล 1,000 ครั้งยังพลาดได้ราว 0.04R ซึ่งใหญ่เกือบเท่า edge 0.05R ข้อมูลขนาดนี้จึงยังบอกไม่ชัดว่า edge มากกว่าศูนย์จริง วิธีทดสอบเรื่องนี้อย่างเป็นระบบอยู่ในหน้า hypothesis testing และ Sharpe ratio

โจทย์ตรวจความเข้าใจ

1. โบรกเกอร์ขึ้นค่าธรรมเนียม จนต้นทุนของกลยุทธ์ TSLA กลายเป็น 0.035R ต่อครั้ง (สมมติ) PMF ยังเหมือนเดิม 1R ยังเป็น \$1,000 และยังซื้อขาย 1,008 ครั้งต่อปี จงหา (ก) กำไรเฉลี่ยสุทธิต่อครั้ง (ข) กำไรเฉลี่ยสุทธิทั้งปี (ค) อัตราชนะที่คุ้มทุนหลังหักต้นทุน

เฉลย

ใช้ linearity หักต้นทุนออกจาก $\mathbb E[X]=0.05R$ ตรง ๆ แล้วแปลงเป็นดอลลาร์ จากนั้นคูณจำนวนครั้งต่อปี และหาจุดคุ้มทุนจากเส้น $3w-0.85$ ที่เลื่อนลงด้วยต้นทุนใหม่

\[\begin{aligned}\mathbb E[X-0.035]&=0.05-0.035=0.015R\\0.015R&=0.015\times\$1{,}000=\$15\\1{,}008\times\$15&=\$15{,}120\\3w-0.85-0.035&=0\\w&=0.885/3=29.5\%\end{aligned}\]

ที่ว่างให้ผิดเหลือ $30\%-29.5\%=0.5$ จุดเปอร์เซ็นต์ ต้นทุนที่ขึ้นทำให้จุดคุ้มทุนขยับเข้าหาอัตราชนะที่สมมติไว้เสมอ

2. ร้านในงานวัดมีวงล้อที่แบ่งเป็นสี่ช่องขนาดเท่ากัน หมุนแล้วแต่ละช่องมีโอกาสออก 1/4 สามช่องให้รางวัล \$0 อีกหนึ่งช่องให้รางวัล \$40 ผู้เล่นจ่ายค่าหมุนครั้งละ \$8 จงหารางวัลเฉลี่ย กำไรเฉลี่ยต่อครั้งของผู้เล่น และค่าหมุนที่ทำให้กำไรเฉลี่ยเป็นศูนย์

เฉลย

ให้ $V$ เป็นรางวัลของหนึ่งครั้ง และ $c$ เป็นค่าหมุน หารางวัลเฉลี่ยก่อน แล้วใช้ linearity หักค่าหมุน

\[\begin{aligned}\mathbb E[V]&=0(3/4)+40(1/4)=\$10\\\mathbb E[V-8]&=10-8=\$2\\10-c&=0\\c&=\$10\end{aligned}\]

ผู้เล่นได้กำไรเฉลี่ย \$2 ต่อครั้ง และค่าหมุนที่คุ้มทุนคือ \$10 แต่สามในสี่ครั้ง ผู้เล่นเสีย \$8 ค่าเฉลี่ยที่เป็นบวกจึงไม่ได้แปลว่าคนที่มีเงินจำกัดควรเล่น

3. ปีหน้าตลาดอาจคึกหรือเงียบ จำนวนการซื้อขายจึงยังไม่แน่นอน อาจเป็น 908 หรือ 1,108 ครั้ง โอกาสเท่ากันคือครึ่งหนึ่ง (สมมติ) และจำนวนครั้งนี้ไม่ขึ้นกับผลของการซื้อขาย แต่ละครั้งได้เฉลี่ย \$50 ก่อนหักต้นทุน กำไรคาดหวังทั้งปีก่อนหักต้นทุนคือเท่าไร

เฉลย

แยกสองกรณีก่อน แต่ละกรณีใช้วิธีของขั้นที่ 6 แล้วถ่วงสองกรณีด้วยโอกาสครึ่งหนึ่งเท่ากัน

\[\begin{aligned}908\times\$50&=\$45{,}400\\1{,}108\times\$50&=\$55{,}400\\\tfrac12(45{,}400)+\tfrac12(55{,}400)&=\$50{,}400\end{aligned}\]

จำนวนครั้งเฉลี่ยคือ $\tfrac12(908)+\tfrac12(1{,}108)=1{,}008$ และ $1{,}008\times\$50=\$50{,}400$ ได้เท่ากันพอดี ผลแบบ “ค่าเฉลี่ยต่อครั้งคูณจำนวนครั้งเฉลี่ย” นี้มีชื่อและเงื่อนไขของมันในหน้า random sums และ Wald's identity

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
const pmf = [[-1, 0.55], [0, 0.15], [2, 0.30]];
const E = f => pmf.reduce((s, [x, p]) => s + f(x) * p, 0);
const meanR = E(x => x);
console.log(meanR);                       // 0.05
console.log(E(x => 1000 * x - 20));        // 30 (linearity)
console.log(E(x => (x === 2 ? 1 : 0)));    // 0.30 (indicator)
console.log(E(x => x * x), meanR ** 2);    // 1.75  0.0025
console.log(E(x => Math.max(x, 0)));       // 0.60

const n = 4 * 252;                         // 1008 ครั้ง
console.log(n * 50, n * 20, n * 30);       // 50400 20160 30240
console.log(0.85 / 3, 0.87 / 3);           // 0.2833  0.29
console.log(n * 0.03 / 3);                 // ≈ 10 ครั้งที่พลิกจากชนะเป็นแพ้

สิ่งที่ควรตอบได้หลังอ่าน

  • $\mathbb E[X]=\sum_i x_i p_i$ คือจุดสมดุลของ PMF กลยุทธ์ TSLA ได้ 0.05R หรือ \$50 ต่อครั้ง ซึ่งไม่ใช่ผลที่ออกได้จริง
  • ค่าเฉลี่ยจากข้อมูลเข้าหา expected value ตาม law of large numbers แต่ช้า ที่ 1,000 ครั้งยังพลาดได้ราว $1.32/\sqrt{1{,}000}\approx0.04R$ ซึ่งใหญ่พอ ๆ กับ edge 0.05R
  • linearity ทำให้เปลี่ยนหน่วยและหักต้นทุนได้ตรง ๆ ค่าเฉลี่ยของผลรวมคือผลรวมของค่าเฉลี่ยเสมอ โดยไม่ต้องใช้ independence แต่การแยกค่าเฉลี่ยของผลคูณต้องใช้
  • โอกาสคือค่าเฉลี่ยของ indicator จึงหาจำนวนครั้งเฉลี่ยได้ด้วยการบวก เช่น ชนะเฉลี่ย $0.30\times1{,}008=302.4$ ครั้งต่อปี
  • ปีหนึ่งคาดว่าได้สุทธิ \$30,240 แต่อัตราชนะที่คุ้มทุนหลังหักต้นทุนคือ 29% ห่างจากอัตราชนะที่สมมติไว้ 30% แค่ 1 จุดเปอร์เซ็นต์

expected value บอกจุดศูนย์กลาง แต่ไม่บอกว่าผลจริงกระจายห่างจากมันแค่ไหน หน้าถัดไป variance และ standard deviation จะวัดการกระจายนั้น แล้วตอบว่ากลยุทธ์ที่ได้เฉลี่ยเป็นบวก ยังมีโอกาสจบปีด้วยการขาดทุนเท่าไร
