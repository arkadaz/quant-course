1.3 Expected Value

คูณผลลัพธ์ด้วยโอกาส ก่อนตัดสินว่าเกมหนึ่งคุ้มแค่ไหน

วงล้อให้รางวัล \$0, \$0, \$0 และ \$40 อย่างละช่อง ถ้าหมุนหนึ่งครั้ง ‘เงินเฉลี่ย’ ควรอยู่ที่ \$10 หรือ \$20?

เฉลย: สามช่องว่างลากจุดสมดุลลงมาเป็น \$10 — วงล้อไม่ได้โกง แค่น้ำหนักของผลลัพธ์ไม่เท่ากัน

ตัวเลขล่วงหน้าที่ถ่วงทุกผลลัพธ์ด้วยโอกาสนี้เรียก Expected Value: ค่าที่ใช้เปรียบเทียบเกมหรือผลลัพธ์สุ่มซ้ำ ๆ โดยไม่หลงกับรางวัลก้อนเดียว

ศัพท์ที่ใช้ในหัวข้อนี้
expected value
ค่าเฉลี่ยถ่วงน้ำหนักความน่าจะเป็นของผลลัพธ์ทั้งหมด เป็นจุดศูนย์ถ่วงที่บอกว่าในระยะยาวกลยุทธ์มีกำไรสุทธิต่อไม้หรือไม่
R (R-multiple)
หน่วยวัดกำไรขาดทุนเทียบกับเงินที่ยอมเสี่ยงต่อไม้ เช่น เสี่ยง \$1,000 แล้วได้กำไร \$2,000 คือผลลัพธ์ +2R
edge
ความได้เปรียบสุทธิของกลยุทธ์เมื่อ expected value เป็นบวก ($\mathbb{E}[X]>0$) ทำให้มีเหตุผลในการลงทุนระยะยาว
breakeven win rate (BE)
อัตราชนะขั้นต่ำที่ทำให้ $\mathbb{E}[X]=0$ พอดี หากอัตราชนะจริงต่ำกว่านี้ กลยุทธ์จะขาดทุนสุทธิ
linearity of expectation
คุณสมบัติที่ค่าคงที่คูณตัวแปร สามารถดึงออกมาคูณข้างนอกได้ตรง ๆ $\mathbb{E}[aX]=a\mathbb{E}[X]$ ช่วยแปลงหน่วยจาก R เป็น USD ได้ทันที
additivity
คุณสมบัติที่ expected value ของผลรวมเท่ากับผลรวมของ expected value แต่ละตัว $\mathbb{E}[\sum X_i]=\sum \mathbb{E}[X_i]$ โดยไม่ต้องพึ่งสมมติฐาน independence
commission

คืออะไร: ค่าธรรมเนียมที่โบรกเกอร์เก็บทุกครั้งที่เราส่งคำสั่ง เป็นจำนวนที่รู้ล่วงหน้า

ใช้ทำอะไร: หักออกจากกำไรเฉลี่ยต่อไม้ ก่อนตัดสินว่ากลยุทธ์คุ้มหรือไม่

ทำไมต้องหัก: เพราะกลยุทธ์ที่มีความได้เปรียบบาง ๆ แต่เทรดบ่อย จ่ายค่านี้บ่อยกว่ากลยุทธ์ที่เทรดน้อย ตัวเลขที่ดูดีก่อนหักจึงหลอกได้

slippage

คืออะไร: ส่วนต่างระหว่างราคาที่เราตั้งใจได้ กับราคาที่ได้จริงตอนคำสั่งจับคู่

ใช้ทำอะไร: หักออกจากกำไรเช่นเดียวกัน แต่ต้องประมาณเอาเพราะไม่รู้ล่วงหน้า

ทำไมต้องระวังกว่าตัวแรก: เพราะมันแย่ที่สุดในวันที่ตลาดวิ่งแรง ซึ่งเป็นวันเดียวกับที่กลยุทธ์ส่วนใหญ่ทำกำไรได้มากที่สุด

spread

คืออะไร: ช่องว่างระหว่างราคาที่มีคนพร้อมซื้อ กับราคาที่มีคนพร้อมขาย ณ ขณะเดียวกัน

ใช้ทำอะไร: เป็นต้นทุนที่จ่ายทันทีที่เปิดสถานะ แม้ราคาจะยังไม่ขยับเลย

ทำไมต้องนับเป็นต้นทุน: เพราะถ้าเปิดแล้วปิดทันที เราจะขาดทุนเท่าช่องว่างนี้พอดี มันจึงเป็นหลุมที่ต้องปีนขึ้นมาก่อนทุกไม้

variance
ตัววัดการเหวี่ยงตัวรอบค่าเฉลี่ย บอกว่าแม้ expected value จะเป็นบวก แต่ระหว่างทางพอร์ตจะแกว่งตัวกว้างแค่ไหน (ศึกษาเต็มในหัวข้อ 1.4)
drawdown
ระยะที่มูลค่าพอร์ตลดลงจากจุดสูงสุดก่อนหน้า ใช้วัดความเสียหายสะสมที่เงินทุนต้องแบกรับระหว่างทาง
payoff
ผลตอบแทนที่ได้รับตามผลลัพธ์ของไม้เทรด เช่น ชนะได้ +2R ขาดทุนเสีย -1R
backtest
การจำลองกลยุทธ์กับข้อมูลราคาจริงในอดีตเพื่อประมาณความน่าจะเป็นของแต่ละผลลัพธ์
P&L
ผลกำไรขาดทุนสุทธิของไม้เทรดหรือของพอร์ตการลงทุน
law of large numbers (LLN)
หลักการที่ระบุว่าเมื่อทำการทดลองสุ่มซ้ำ ๆ จำนวนมาก ค่าเฉลี่ยของผลการทดลองจะลู่เข้าหา expected value ทางทฤษฎี ใช้เป็นสะพานเชื่อมระหว่างข้อมูลจริงกับแบบจำลอง
conditional expectation
expected value ของ random variable ภายใต้เงื่อนไขว่าเรารู้ข้อมูลของอีกตัวแปรหนึ่งแล้ว ใช้คำนวณผลตอบแทนสะสมเมื่อจำนวนไม้หรือสภาวะตลาดมีความไม่แน่นอน
Wald's identity
เอกลักษณ์ความน่าจะเป็นที่ระบุว่า expected value ของผลรวมที่จำนวนพจน์เป็น random variable เท่ากับผลคูณของค่าเฉลี่ยต่อพจน์กับค่าเฉลี่ยของจำนวนพจน์ ใช้คำนวณกำไรรวมของกลยุทธ์

Worked Example — ข้อมูลจาก Probability Mass Function (PMF)

โจทย์ให้ผลของหนึ่งไม้ไว้สามแบบ: ชนะ +2R ที่โอกาส 30%, เสีย -1R ที่ 55%, และเสมอตัว 0R ที่ 15% น้ำหนักทั้งสามรวมกันครบ 100%

เราต้องหา expected value ต่อไม้ แล้วแปลงด้วย $1R=\$1{,}000$ เป็นเงินต่อไม้ จากนั้นใช้ 4 ไม้ต่อวันและ 250 วันต่อปีหาค่ารวมทั้งปี สุดท้ายจะหาอัตราชนะที่พอดีไม่กำไรไม่ขาดทุน

อย่าเพิ่งเฉลี่ย 2, -1 และ 0 ตรง ๆ เพราะสามผลลัพธ์ไม่ได้เกิดบ่อยเท่ากัน จุดสำคัญคือจับ “ขนาด” คู่กับ “โอกาส” ให้ถูกตัว

ที่มาที่ไป: จากการแบ่งเงินพนัน สู่การตัดสินใจทางธุรกิจ

คำตอบของ Pascal กับ Fermat ในปี 1654 ไม่ได้หยุดอยู่แค่การแบ่งเงิน มันให้ของที่มีค่ากว่านั้น คือตัวเลขตัวเดียวที่สรุปว่าเกมหนึ่งมีค่าเท่าไรก่อนจะเล่น

ก่อนหน้านั้นคนตัดสินเกมด้วยการดูรางวัลสูงสุด หรือดูว่าชนะบ่อยไหม ซึ่งทั้งสองอย่างหลอกได้ง่าย ล็อตเตอรี่มีรางวัลสูงมากแต่แทบไม่มีใครได้ ส่วนเกมที่ชนะเก้าครั้งจากสิบอาจขาดทุนหนักในครั้งที่สิบ

สิ่งที่ทั้งสองคนเสนอคือให้คูณผลลัพธ์แต่ละอย่างด้วยโอกาสของมันก่อนแล้วค่อยรวม ตัวเลขที่ได้เป็นตัวเดียวที่เปรียบเทียบเกมที่หน้าตาต่างกันโดยสิ้นเชิงได้อย่างยุติธรรม

หัวข้อนี้ใช้แนวคิดเดียวกันกับไม้เทรด ซึ่งก็คือเกมที่เล่นซ้ำนั่นเอง

ที่มาทางประวัติศาสตร์: จากสัญญาการพนันของ Huygens สู่เกม St. Petersburg

ในปี 1657 Christiaan Huygens นักฟิสิกส์และคณิตศาสตร์ชาวดัตช์ ตีพิมพ์ตำราความน่าจะเป็นเล่มแรกของโลกชื่อ De Ratiociniis in Ludo Aleae โดยนิยามคำว่า expectation ให้เป็นราคาซื้อขายที่ยุติธรรมของสัญญา หากสัญญาให้สิทธิ์รับผลตอบแทนที่ไม่แน่นอน มูลค่าที่ควรจ่ายล่วงหน้าคือค่าเฉลี่ยถ่วงน้ำหนักของทุกหน้า

ต่อมาในปี 1738 ปัญหา St. Petersburg Paradox ซึ่งเป็นเกมโยนเหรียญที่มี expected value เป็นอนันต์ ได้แสดงให้เห็นว่าในโลกความเป็นจริงไม่มีใครยอมจ่ายเงินก้อนโตเพื่อแลกกับการเล่น ปัญหานี้เป็นจุดเริ่มต้นที่ทำให้นักวิเคราะห์ตระหนักว่า expected value เป็นเพียงเกณฑ์เบื้องต้น และจำเป็นต้องพิจารณา variance ควบคู่กับความพึงพอใจต่อความเสี่ยงเสมอ

ขั้นที่ 1 — นิยาม 1.3 — Expected Value

นิยามของ expected value วางอยู่บนรากฐานของการหาค่าเฉลี่ยจากการทดลองจริง โดยอาศัย law of large numbers (LLN) เป็นตัวเชื่อมโยงความถี่เชิงประจักษ์เข้ากับความน่าจะเป็นทางทฤษฎี

เมื่อจำนวนการทดลองเพิ่มขึ้นไม่สิ้นสุด สัดส่วนของแต่ละหน้าจะลู่เข้าหา probability $p(x_i)$ อย่างแม่นยำ ทำให้ค่าเฉลี่ยกลายเป็นผลรวมถ่วงน้ำหนัก สำหรับกรณีต่อเนื่อง การแบ่งช่วงย่อยแล้วหา limit จะเปลี่ยนผลบวกให้เป็น integral

\[ \begin{aligned} \bar{X}_N &= \frac{1}{N}\sum_{k=1}^{N} X_k = \sum_{i=1}^m x_i \frac{N_i}{N} \\ \frac{N_i}{N} &\xrightarrow{\text{LLN}} P(X = x_i) = p(x_i) \quad \text{as } N \to \infty \\ \mathbb{E}[X] &= \lim_{N \to \infty} \bar{X}_N = \sum_{i=1}^m x_i\,p(x_i) \\ \text{Continuous: } \mathbb{E}[X] &= \lim_{\Delta x \to 0} \sum x_i f(x_i)\Delta x = \int_{-\infty}^\infty x\,f(x)\,dx \end{aligned} \]

ค่า expected value ไม่ได้มาจากการเดา แต่เป็น limit ของค่าเฉลี่ยจากการทดลองจริงเมื่อจำนวนครั้งเข้าสู่อเนกอนันต์

กฎ law of large numbers (LLN) ประกันว่าสัดส่วนความถี่ของแต่ละหน้าจะลู่เข้าหา probability ทางทฤษฎี ผลรวมถ่วงน้ำหนักจึงเกิดขึ้นมาโดยอัตโนมัติ

สำหรับกรณีต่อเนื่อง เราแบ่งพื้นที่ออกเป็นแถบกว้าง $\Delta x$ แล้วรวมน้ำหนัก เมื่อบีบแถบให้แคบลง ผลรวมจะเปลี่ยนรูปเป็น integral อย่างสมบูรณ์

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

ค่าเฉลี่ยถ่วงน้ำหนักคือเครื่องมือตัดสินใจที่ใช้ซ้ำทั้งเล่ม

ใช้ตัดสินว่ากลยุทธ์ควรเปิดหรือปิด ถ้าค่าเฉลี่ยต่อไม้เป็นลบหลังหักต้นทุนแล้ว ไม่มีขนาดสถานะไหนช่วยได้ ต้องแก้ที่กลยุทธ์

ใช้ตั้งราคาสัญญา derivative ราคายุติธรรมของสัญญาส่วนใหญ่คือค่าเฉลี่ยของเงินที่จะได้ คิดลดกลับมาเป็นวันนี้ ซึ่งเราจะทำจริงตั้งแต่หัวข้อ 13.2

ใช้เปรียบเทียบทางเลือกที่หน้าตาไม่เหมือนกัน เช่นเทียบกลยุทธ์ชนะบ่อยกำไรน้อย กับกลยุทธ์ชนะนานทีกำไรก้อนใหญ่ ค่าเฉลี่ยทำให้สองอันนี้วางเทียบกันได้

กับดัก: อย่าเฉลี่ยแบบธรรมดา

สัญชาตญาณแรกคือการนำผลลัพธ์ทั้งสามมาบวกกันแล้วหารสาม แต่นั่นคือการสมมติผิด ๆ ว่าทุกผลลัพธ์มีโอกาสเกิดเท่ากัน ทั้งที่ฝั่งขาดทุนเกิดบ่อยกว่าฝั่งกำไรเกือบสองเท่า จึงต้องถ่วงน้ำหนักด้วยความน่าจะเป็นจริงเสมอ

ขั้นที่ 2 — กับดัก — ค่าเฉลี่ยธรรมดาให้คำตอบผิด

ถ้าเฉลี่ยโดยไม่ถ่วงน้ำหนัก จะได้ตัวเลขที่สูงเกินจริงและสร้างความเข้าใจผิด:

\[ \frac{(+2) + 0 + (-1)}{3} = 0.33R \quad \text{(wrong)} \]

การบวกผลลัพธ์ $+2, 0, -1$ แล้วหาร 3 จะได้ $0.33R$ ซึ่งสูงเกินจริง เพราะแอบสมมติว่าทุกหน้ามีโอกาสเท่ากันที่ $1/3$ ทั้งที่ในความเป็นจริงหน้าขาดทุน $-1R$ มีโอกาสสูงถึง $0.55$

ขั้นที่ 3 — คูณน้ำหนักทีละหน้าแล้วรวม

คูณผลลัพธ์แต่ละหน้าด้วยโอกาสของหน้านั้น แล้วรวมแรงดึงฝั่งบวกกับฝั่งลบในกล่องเดียว

\[ \begin{aligned} (+2)(0.30)&=+0.60R\\ (-1)(0.55)&=-0.55R\\ (0)(0.15)&=0R\\[2pt] \mathbb{E}[X]&=0.60-0.55+0=\boxed{+0.05R}\end{aligned} \]

ฝั่งชนะดึงขึ้น $0.60R$, ฝั่งแพ้ดึงลง $0.55R$, และหน้าเสมอตัวไม่ขยับค่าเฉลี่ย จึงเหลือ expected value $+0.05R$ ต่อไม้

คำตอบข้อ ก

ภายใต้ตารางผลลัพธ์นี้ ค่าเฉลี่ยก่อนต้นทุนคือ $+0.05R$ ต่อไม้ เพราะกำไรเมื่อชนะมีขนาดใหญ่พอชดเชยการแพ้ที่บ่อยกว่า ยังไม่ใช่การรับรองกำไรจริง: ต้องหักต้นทุนและตรวจว่าโอกาสกับขนาดผลลัพธ์ยังเหมือนสมมติฐานหรือไม่

ขนาดคูณความถี่: ทำไมฝั่งชนะเฉียดชนะ

ทำไมฝั่งชนะจึงเอาชนะได้ ทั้งที่แพ้บ่อยกว่าชนะเกือบสองเท่า? คำตอบอยู่ที่การเปรียบเทียบระหว่างอัตราส่วนความถี่กับอัตราส่วนขนาดของผลตอบแทน

ขั้นที่ 4 — เทียบความถี่

คำนวณว่าไม้แพ้เกิดขึ้นถี่กว่าไม้ชนะกี่เท่า

\[ \frac{p(-1)}{p(+2)} = \frac{0.55}{0.30} = 1.83 \]

นำความน่าจะเป็นแพ้ $0.55$ ส่วนด้วยความน่าจะเป็นชนะ $0.30$ ได้ $1.83$ เท่า แสดงว่าฝั่งแพ้เกิดถี่กว่าฝั่งชนะ $1.83$ เท่า

ขั้นที่ 5 — เทียบขนาด payoff

คำนวณว่าไม้ชนะจ่ายเงินก้อนใหญ่กว่าไม้แพ้กี่เท่า

\[ \frac{|x_1|}{|x_2|} = \frac{2}{1} = 2.00 \]

ขนาดไม้ชนะ $2R$ เทียบกับขนาดไม้แพ้ $1R$ คิดเป็นอัตราส่วน $2.00$ เท่า เพราะ $2.00 > 1.83$ ขนาดที่ใหญ่กว่าจึงเอาชนะความถี่ที่เสียเปรียบได้

ปุ่มสองปุ่มของธุรกิจเทรด

ธุรกิจการเทรดมีกลไกขับเคลื่อนหลักเพียงสองปุ่ม คือ Payoff Ratio (ขนาดกำไรต่อขาดทุน) กับ Win Rate (ความถี่ในการชนะ) กลยุทธ์แบบตามแนวโน้มจะเน้นหมุนปุ่มแรกให้ใหญ่โดยยอมรับอัตราชนะต่ำ ส่วนกลยุทธ์แบบดักกลับตัวจะเน้นหมุนปุ่มหลังให้สูงโดยยอมรับขนาดกำไรที่เล็กลง

ขั้นที่ 6 — Linearity แปลงหน่วย

แปลงหน่วยจาก R เป็นเงินดอลลาร์ด้วยสมบัติ Linearity ของ Expected Value: ค่าคงที่ $a$ คูณกับ random variable สามารถดึงออกมาคูณผลลัพธ์ภายนอกได้โดยตรง

\[ \begin{aligned}\mathbb E[aX]&=\sum_i (ax_i)p_i\\ &=a\sum_i x_i p_i\\ &=a\mathbb E[X]\end{aligned} \]

บรรทัดแรกแปลงผลลัพธ์ทุกหน้าเป็น $ax_i$ ก่อนถ่วงโอกาส $p_i$ บรรทัดสองดึงตัวคูณเดียวกัน $a$ ออกจากผลบวก เหมือน $au+av=a(u+v)$ บรรทัดสามเรียกผลรวมที่เหลือว่า $\mathbb E[X]$ จึงไม่ต้องสร้างตารางใหม่ กฎนี้ใช้เมื่อค่าเฉลี่ยมีค่าจำกัดและ $a$ เป็นค่าคงที่

แก้ข้อ ข: แปลงเป็นดอลลาร์

ใช้สมบัติ Linearity แปลง expected value จากหน่วย R เป็นดอลลาร์ โดยกำหนดให้ $1R = \$1,000$ ตามขนาดความเสี่ยงของไม้นี้

ขั้นที่ 7 — แปลงเป็น USD แล้วตรวจซ้ำ

คูณ $0.05R$ ด้วยมูลค่า $1R=\$1,000$ แล้วตรวจด้วยการถ่วงเงินของทั้งสามผลลัพธ์โดยตรง

\[ \begin{aligned}\mathbb{E}[\text{PnL}]&=(\$1{,}000/R)(0.05R)=\$50\\ &=(\$2{,}000)(0.30)-(\$1{,}000)(0.55)+(\$0)(0.15)=\$50\end{aligned} \]

ทั้งวิธีแปลงหน่วยและวิธีถ่วงเงินทีละหน้าให้ $\$50$ ต่อไม้เหมือนกัน ถ้าไม่ตรงกัน แปลว่าหน่วยหรือเครื่องหมายผิด

คำตอบข้อ ข ต่อไม้ — แปลว่าอะไร

ทั้งสองวิธีให้ค่าเฉลี่ย 50 USD ต่อไม้ ไม้ถัดไปยังออกได้เป็นกำไร ขาดทุน หรือเสมอตัว การทำซ้ำแบบอิสระด้วยตารางเดิมทำให้ค่าเฉลี่ยตัวอย่างเข้าใกล้ค่านี้เมื่อจำนวนครั้งเพิ่มขึ้น; แค่รู้ค่าเฉลี่ยของแต่ละไม้ยังไม่พอรับรองว่าผลเฉลี่ยจริงจะเข้าใกล้มัน

ขั้นที่ 8 — Additivity รวมหลายไม้

รวมผลลัพธ์ $n$ ไม้ตลอดทั้งปีด้วยสมบัติ additivity: ค่าเฉลี่ยของผลรวม เท่ากับผลรวมของค่าเฉลี่ยเสมอ ห้าบรรทัดบนคือเหตุผลทั้งหมด และจุดสำคัญคือ ไม่มีบรรทัดไหนต้องสมมติว่าสองไม้ไม่เกี่ยวกัน

\[ \begin{aligned}\mathbb{E}[X+Y]&=\sum_i\sum_j (x_i+y_j)\,p_{ij}\\ &=\sum_i\sum_j x_i p_{ij}+\sum_i\sum_j y_j p_{ij}\\ &=\sum_i x_i\Big(\sum_j p_{ij}\Big)+\sum_j y_j\Big(\sum_i p_{ij}\Big)\\ &=\sum_i x_i\,P(X=x_i)+\sum_j y_j\,P(Y=y_j)\\ &=\mathbb{E}[X]+\mathbb{E}[Y]\\[4pt] \Longrightarrow\;\mathbb{E}\Big[\sum_{i=1}^{n}X_i\Big]&=\sum_{i=1}^{n}\mathbb{E}[X_i]\end{aligned} \]

$p_{ij}$ คือโอกาสที่ไม้แรกออก $x_i$ และไม้สองออก $y_j$ พร้อมกัน บรรทัดแรกจึงเป็นแค่นิยามค่าเฉลี่ยที่ใช้กับผลรวมของสองไม้ จากนั้นกระจายวงเล็บแล้วแยกเป็นสองก้อน ทำได้เพราะการบวกสลับที่ได้ แล้วดึงของที่ไม่ขึ้นกับตัวนับข้างในออกมา

บรรทัดสี่คือจุดที่ทุกอย่างคลี่ออก: รวมโอกาสของทุกหน้าของอีกไม้จนหมด สิ่งที่เหลือคือโอกาสของไม้เดียว สังเกตว่าเราไม่เคยต้องแยก $p_{ij}$ เป็นผลคูณเลยสักครั้ง นั่นคือเหตุผลที่กฎนี้ไม่ต้องขอ independence และใช้ซ้ำจนครบ $n$ ไม้ได้ ขอแค่ค่าเฉลี่ยทุกตัวมีค่าจำกัด

ขั้นที่ 9 — นับไม้แล้วรวมเป็นหนึ่งปี

สี่ไม้ต่อวันคูณ 250 วันได้ 1,000 ไม้ จากนั้น Additivity เปลี่ยนผลรวม 1,000 ไม้เป็นจำนวนไม้คูณ expected P&L ต่อไม้

\[ \begin{aligned}n&=4\times250=1{,}000\;\text{trades/year}\\ \mathbb{E}[\text{PnL}_{\text{year}}]&=\sum_{i=1}^{1000}\mathbb{E}[\text{PnL}_i]\\ &=1{,}000(\$50)=\boxed{\$50{,}000}\end{aligned} \]

จำนวนไม้ $1,000$ คูณกำไรคาดหวัง $\$50$ ต่อไม้ ได้ $\$50,000$ ต่อปี โดยไม่ต้องสมมติว่าแต่ละไม้ independent

ขั้นที่ 10 — ผลรวมเมื่อจำนวนไม้เป็น random variable (Wald's identity)

ในการเทรดจริง จำนวนไม้ในหนึ่งปีมักไม่คงที่ แต่เป็น random variable $N$ ที่ขึ้นกับสภาวะตลาด

เมื่อ $N$ เป็นอิสระจากผลตอบแทนของแต่ละไม้ เราใช้กฎ conditional expectation identity เพื่อหา expected value รวมของพอร์ตได้โดยตรงตาม Wald's identity

\[ \begin{aligned} W &= \sum_{i=1}^{N} X_i, \quad N \text{ independent of } X_i \\ \mathbb{E}[W \mid N = n] &= \mathbb{E}\left[\sum_{i=1}^n X_i \;\middle|\; N = n\right] = \sum_{i=1}^n \mathbb{E}[X_i] = n \mu_X \\ \mathbb{E}[W \mid N] &= N \mu_X \\ \mathbb{E}[W] &= \mathbb{E}\big[\mathbb{E}[W \mid N]\big] = \mathbb{E}[N \mu_X] = \mu_X \mathbb{E}[N] \\ \mathbb{E}[N] = 1{,}000, \ \mu_X = \$50 &\implies \mathbb{E}[W] = 1{,}000 \times \$50 = \boxed{\$50{,}000} \end{aligned} \]

ผลรวมของไม้เทรดที่มีจำนวนครั้งไม่แน่นอน สามารถคลี่ออกได้ด้วยการคิดสองชั้น ชั้นแรกสมมติให้จำนวนไม้คงที่ชั่วคราวเป็น $n$ ซึ่งทำให้ดึงค่าเฉลี่ยต่อไม้ $\mu_X$ ออกมาได้

เมื่อปล่อยให้จำนวนไม้แปรผันตามธรรมชาติ expected value แบบมีเงื่อนไขจะกลายเป็น random variable $N \mu_X$ ที่ขึ้นกับจำนวนไม้ $N$

กฎ conditional expectation identity บังคับให้หา expected value ซ้ำอีกรอบ ส่งผลให้เราคูณ expected value ของจำนวนไม้ เข้ากับ expected value ต่อไม้ได้ทันที ให้คำตอบห้าหมื่นดอลลาร์เช่นเดิม

จุดที่ทรงพลังที่สุด

จุดเด่นที่สุดของสูตร Additivity คือไม่มีเงื่อนไข independence (independence) บังคับไว้เลย ต่อให้ไม้เทรดจะเกาะกลุ่มกัน เช่น แพ้ติดกันในตลาดแกว่งตัว หรือชนะติดกันในตลาดมีแนวโน้ม ผลรวม expected value $\sum \mathbb{E}[X_i]$ ก็ยังคงเป็น \$50,000 เท่าเดิม สิ่งที่ความสัมพันธ์ระหว่างไม้ส่งผลกระทบคือความผันผวน (Variance) ไม่ใช่ค่าเฉลี่ย ซึ่งจะศึกษาอย่างละเอียดในหัวข้อ 1.4

ขั้นที่ 11 — แก้ breakeven win rate

ให้ $w$ เป็นอัตราชนะ ตรึงโอกาสเสมอตัวไว้ที่ 0.15 จึงเหลือโอกาสแพ้ $0.85-w$ ตั้ง expected value เท่ากับศูนย์แล้วแก้สมการต่อเนื่อง

\[ \begin{aligned}2w-(0.85-w)+0(0.15)&=0\\ 3w&=0.85\\ w_{\text{BE}}&=\frac{0.85}{3}=\boxed{28.33\%}\end{aligned} \]

ฝั่งชนะต้องชดเชยฝั่งแพ้พอดี จึงได้ breakeven win rate $28.33\%$ ต่ำกว่าอัตราชนะจริง $30\%$ เพียง $1.67$ percentage points

Worked Example — โจทย์จิ๋วที่คำนวณได้

โจทย์ให้อะไรมาบ้าง: expected edge ก่อนต้นทุน 0.05R ต่อไม้, ต้นทุน 0.02R, เทรด 1,000 ไม้ และ 1R เท่ากับ USD 1,000.

คำตอบ: edge สุทธิคือ $0.05R-0.02R=0.03R$; กำไรคาดหวังทั้งปีคือ USD 30,000.

ตรวจเองใน 10 วินาที: $0.03\times1{,}000\times1{,}000=30{,}000$; คำตอบต้องต่ำกว่า 50,000 ก่อนต้นทุน.

แปลว่าอะไรบนโต๊ะ: กลยุทธ์ยังมี edge แต่ต้นทุนกินกำไรเดิม 40%. กับดักคือเห็น expected value บวกแล้วคิดว่าทุกปีต้องกำไร.

กับดัก: ต้นทุนกัดเอดจ์ไม่เป็นสัดส่วน

สมมติค่าคอมมิชชันและต้นทุนซื้อขายรวมกัน

$0.02R$ ต่อไม้ หรือ 20 USD

เมื่อ $1R=1{,}000 \mathrm{USD}$

เทียบกับหนึ่งหน่วยความเสี่ยงคือต้นทุน 2%

แต่เทียบกับแต้มต่อ $0.05R$ ต้องหาร 0.02 ด้วย 0.05 ได้ 0.40

จึงกินกำไรคาดหวังก่อนต้นทุนไป 40%

ฐานที่นำมาเทียบต่างกันจึงได้เปอร์เซ็นต์ต่างกัน

ขั้นที่ 12 — หักต้นทุนแล้วดูว่าเหลือจริงเท่าไร

หักต้นทุนต่อไม้ออกจาก edge ก่อน แล้วคูณจำนวนไม้กับมูลค่าของ 1R; บรรทัดสุดท้ายเทียบกับกำไรก่อนต้นทุน

\[ \begin{aligned}0.05R-0.02R&=0.03R\\ 1{,}000(0.03R)(\$1{,}000/R)&=\$30{,}000\\ \$50{,}000-\$30{,}000&=\boxed{\$20{,}000\;(40\%)}\end{aligned} \]

ต้นทุน $0.02R$ ทำให้ edge เหลือ $0.03R$ ต่อไม้ กำไรคาดหวังทั้งปีจึงเหลือ $\$30,000$ และต้นทุนกินกำไรเดิมไป $40\%$

กับดัก: อย่าคาดหวัง 0.05R จากไม้ถัดไป

expected value $+0.05R$ ไม่ใช่ผลลัพธ์ที่ไม้ถัดไปจะส่งมอบ เพราะในไม้เดี่ยวผลลัพธ์ออกได้เพียง $+2R, -1R$ หรือ $0R$ เท่านั้น expected value คือคุณสมบัติของระบบในระยะยาวเมื่อทำซ้ำจำนวนมาก จึงใช้ประเมินคุณภาพของระบบ ไม่ใช่การพยากรณ์ผลลัพธ์ของไม้ถัดไป

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
สิ่งที่มันบอกบอกค่าเฉลี่ยระยะยาวเราเทรดในระยะสั้นด้วยเงินจำกัดค่าเฉลี่ยเป็นบวกไม่ได้กันการเจ๊งระหว่างทาง
จำนวนครั้งเล่นซ้ำได้ไม่จำกัดทุนหมดก่อนก็จบเกมต้องดูขนาดสถานะคู่กันเสมอ ซึ่งคือหัวข้อ 17.2
ความเหวี่ยงไม่พูดถึงความเหวี่ยงเลยสองกลยุทธ์ค่าเฉลี่ยเท่ากันอาจเสี่ยงต่างกันสิบเท่าต้องอ่านคู่กับหัวข้อ 1.4 เสมอ ห้ามดูตัวเดียว

ค่าเฉลี่ยเป็นตัวเลขที่ถูกต้องแต่ไม่พอ ทั้งบทที่เหลือคือการเติมสิ่งที่มันไม่ได้บอก

สรุปที่ใช้ได้จริง

  • $\mathbb{E}[X]=\sum_i x_i p(x_i)$ ต้องถ่วงน้ำหนักด้วยความถี่จริงจาก PMF เสมอ ห้ามเฉลี่ยเลขคณิตแบบธรรมดา
  • Linearity $\mathbb{E}[aX]=a\mathbb{E}[X]$ ใช้แปลงหน่วยเป็นเงินดอลลาร์ และ Additivity $\mathbb{E}[\sum X_i]=\sum\mathbb{E}[X_i]$ ใช้รวมผลตอบแทนเป็นรายปีได้ตรง ๆ โดยไม่ต้องมีสมมติฐาน independence
  • คำนวณระยะห่างจาก breakeven win rate เสมอ — ในตัวอย่างนี้ระยะห่าง 1.67 percentage points หมายถึงแต้มต่อแขวนอยู่บนความต่างเพียง 17 ไม้ใน 1,000 ไม้
  • ต้นทุนการทำธุรกรรม (commission, spread, slippage) หักออกจากแต้มต่อโดยตรง ไม่ได้หักจากขนาดไม้ ยิ่งเทรดถี่ สัดส่วนกำไรที่ถูกกลืนกินยิ่งสูงขึ้น
  • หัวใจของธุรกิจการเทรดเชิงปริมาณ: ค้นหาแต้มต่อที่เป็นบวกแม้เพียงเล็กน้อย ($\mathbb{E}[X]>0$) แล้วทำซ้ำให้มากที่สุดเท่าที่ต้นทุนธุรกรรมจะอนุญาต
