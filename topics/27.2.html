27.2 Estimating the Factor Covariance Matrix

covariance ของ factor ที่คิดตรง ๆ จาก factor return รายวันผิดสี่ทาง: สูงเกินจริงเสมอ พลิกกลับไม่มั่นคงเมื่อ factor เยอะ ลืมอดีตด้วยความเร็วเดียวกันทั้งที่ไม่ควร และมองไม่เห็นความจำเล็ก ๆ ของ factor return หน้านี้แก้ทีละข้อด้วยตัวเลข

ทีมความเสี่ยงเก็บ factor return ของ momentum ไว้ 251 วัน จาก regression ข้ามหุ้นของ 27.1 ที่รันบนหุ้น 600 ตัวทุกคืน คิดความผันผวนตรง ๆ ได้ 0.3693% ต่อวัน (ตัวเลขสมมติที่ตรงกับค่าคาดหมายพอดี) กำลังจะส่งเข้า optimizer เพื่อนในทีมเตือนว่า “หารด้วย 250 แทน 251 จะได้ไม่เอน” ความผันผวนจริงของ momentum คือเท่าไร และคำเตือนนั้นช่วยไหม?

ลองตอบก่อนเปิดเฉลย

ความผันผวนจริงคือ 0.35% ต่อวัน factor return ที่ได้ทุกคืนคือผลตอบแทนของพอร์ตหุ้นจริง จึงพกส่วนเฉพาะตัวของหุ้นในพอร์ตมาด้วย variance ที่วัดได้จึงเกินจริงเสมอ $G=0.013907$ (%²) หรือ 11.35% ของ variance จริง การหารด้วย 250 ทำให้ตัวเลขใหญ่ขึ้นอีก 0.4% ไปผิดทาง ทางแก้คือหัก $G$ ออก: $\sqrt{0.3693^2-0.013907}=0.35$

สิ่งที่เราจะสร้าง

27.1 ให้ factor return $\hat{\mathbf f}_t$ มาวันละหนึ่งชุด หน้านี้เอา 251 ชุดของหนึ่งปีมาทำเป็น covariance matrix $\boldsymbol\Omega_f$ ที่ใช้คิดความเสี่ยงของพอร์ตตาม 26.1 ทางลัดคือเฉลี่ยผลคูณ $\hat{\mathbf f}_t\hat{\mathbf f}_t^{\mathsf T}$ ตาม 8.1 แต่ทางลัดนี้ผิดสี่ทาง และแต่ละทางมีทางแก้ของมันเอง

ลำดับคือ ดูว่าทำไมค่าที่วัดได้สูงเกินจริงเสมอ แล้วคิดขนาดด้วยพอร์ตของ 27.1 ด้วยมือ จากนั้นดูว่าเมื่อ factor มี 40 ตัวแต่ข้อมูลมีแค่ครึ่งปี eigenvalue กระจายออกเองจนพลิกกลับไม่มั่นคง และแก้ด้วย shrinkage ต่อด้วยเหตุผลที่ความผันผวนกับ correlation ต้องลืมอดีตคนละความเร็ว และจบที่ autocorrelation เล็ก ๆ ที่ทำให้ความเสี่ยงรายปีต่ำเกินจริง

ขั้นที่ 1 — ค่าที่วัดได้คือ factor บวกเสียงของพอร์ต

ก่อนคิด covariance ต้องถามว่าตัวเลขที่เอามาเฉลี่ยคืออะไร 27.1 บอกว่า $\hat{\mathbf f}_t=\mathbf H\mathbf r_t$ แทนผลตอบแทนหุ้นด้วยสมการของ factor model แล้วดูว่าเหลืออะไร

\[ \begin{aligned} \hat{\mathbf f}_t&=\mathbf H\mathbf r_t\\ &=\mathbf H\mathbf B\mathbf f_t+\mathbf H\boldsymbol\epsilon_t\\ &=\mathbf f_t+\mathbf H\boldsymbol\epsilon_t,\\ \operatorname{cov}(\hat{\mathbf f}_t)&=\boldsymbol\Omega_f+\mathbf G,\\ \mathbf G&=\mathbf H\boldsymbol\Omega_\epsilon\mathbf H^{\mathsf T}. \end{aligned} \]

บรรทัดที่สามใช้ $\mathbf H\mathbf B\mathbf f=\mathbf f$ ของ 27.1 (ในทาง C ที่ตั้งเงื่อนไขถ่วงมูลค่าตลาด factor return จริงก็นิยามใต้เงื่อนไขเดียวกัน จึงเท่ากันพอดี) ค่าที่วัดได้จึงเป็นของจริงบวกก้อน $\mathbf H\boldsymbol\epsilon_t$ ซึ่งคือส่วนเฉพาะตัวของหุ้นที่ factor-mimicking portfolio ถือไว้

บรรทัดที่สี่ไม่มีพจน์ไขว้ เพราะส่วนเฉพาะตัวไม่เกี่ยวกับ factor (26.1) variance ของผลรวมสองก้อนที่ไม่เกี่ยวกันคือผลรวมของ variance ทั้งสอง $\mathbf G$ ไม่มีวันติดลบ ค่าที่วัดได้จึงสูงเกินจริงเสมอ ไม่ใช่สูงบ้างต่ำบ้าง

26.5 ขั้นที่ 8 แสดงว่า $\mathbf G=(\mathbf B^{\mathsf T}\boldsymbol\Omega_\epsilon^{-1}\mathbf B)^{-1}$ เมื่อ $\mathbf B$ มี rank เต็ม แต่สูตร $\mathbf H\boldsymbol\Omega_\epsilon\mathbf H^{\mathsf T}$ ใช้ได้ทุกกรณี

ขั้นที่ 2 — ขนาดของ $\mathbf G$ คิดด้วยมือจากพอร์ต momentum ของ 27.1

โจทย์ให้อะไรมาบ้าง: แถว momentum ของ $\mathbf H$ จาก 27.1 ขั้นที่ 6 (ทุกทางแก้ของ 27.1 ให้แถวนี้เท่ากัน) ความผันผวนเฉพาะตัว $\sigma_i$ ชุดเดิม และจักรวาลจริง 600 ตัวที่สมมติว่าเป็นหุ้นแปดตัวของ 27.1 ซ้ำกัน 75 ชุด (loading กับ $\sigma_i$ เหมือนกัน แต่ส่วนเฉพาะตัวของแต่ละตัวเป็นอิสระกัน) เพราะ $\boldsymbol\Omega_\epsilon$ เป็นแนวทแยง แนวทแยงของ $\mathbf G$ จึงเหลือผลรวมกำลังสอง

\[ \begin{aligned} \mathbf h_{\rm mom}&=(0.2003,\ -0.2107,\\ &\qquad 0.0103,\ -0.2230,\\ &\qquad 0.2230,\ -0.0950,\\ &\qquad 0.1717,\ -0.0767),\\ G_{\rm mom}&=\textstyle\sum_i h_i^2\sigma_i^2\\ &=0.13004+0.21485\\ &\quad+0.00024+0.33602\\ &\quad+0.19883+0.05193\\ &\quad+0.08516+0.02595\\ &=1.0430\ (\%^2),\\ G_{600}&=\tfrac{1.0430}{75}=0.013907. \end{aligned} \]

คำตอบ: ด้วยหุ้นแค่แปดตัว ความคลาดของ momentum รายวันคือ $\sqrt{1.0430}=1.0213\%$ ใหญ่กว่าความผันผวนของ momentum เอง (0.35%) เกือบสามเท่า ในจักรวาล 600 ตัว หุ้นแบบที่ $i$ มีอยู่ 75 ตัว พอร์ตแบ่งน้ำหนัก $h_i$ ให้พวกมันตัวละ $h_i/75$ ผลรวมกำลังสองของทั้ง 75 ตัวจึงเป็น $75\times(h_i/75)^2\sigma_i^2=h_i^2\sigma_i^2/75$ ทุกพจน์หารด้วย 75 $G$ จึงเหลือ 0.013907 (%²) หรือความคลาด 0.1179% ต่อวัน ทำแบบเดียวกันกับพอร์ตของ market (ทาง C) ได้ $G_{\rm mkt}=0.5274/75=0.007032$

ตรวจเองใน 10 วินาที: พจน์ที่ห้า $0.2230^2\times2.0^2=0.0497\times4=0.1989$ ใกล้ 0.19883 (ต่างเพราะปัด $h$) และพจน์ที่ใหญ่ที่สุดมาจากหุ้นตัวที่ 4 ซึ่งทั้งถือน้ำหนักมากและเหวี่ยงแรงที่สุด ($\sigma=2.6\%$)

ขั้นที่ 3 — เอนเท่าไร และทำไมมองด้วยตาไม่เห็น

ตอนนี้เทียบ $G$ กับ variance จริงของ factor โดยสมมติว่า market ผันผวน 1.0% ต่อวัน และ momentum 0.35% ต่อวัน แล้วเทียบความเอนกับความคลาดแบบสุ่มของ variance ที่วัดจากข้อมูลปีเดียว

\[ \begin{aligned} \frac{\operatorname{var}(\hat f_k)}{\operatorname{var}(f_k)}&=1+\frac{G_{kk}}{\operatorname{var}(f_k)},\\ \text{mom}&:\ 1+\frac{0.013907}{0.35^2}=1.1135,\\ \text{mkt}&:\ 1+\frac{0.007032}{1.0^2}=1.0070,\\ \sqrt{1.1135}&=1.0552,\\ \sqrt{2/251}&=0.0893,\\ \hat{\boldsymbol\Omega}_f&=\hat{\boldsymbol\Sigma}-\mathbf G. \end{aligned} \]

factor ใหญ่แทบไม่เป็นไร market เอน 0.70% แต่ factor เล็กเจ็บหนัก momentum เอน 11.35% ใน variance หรือ 5.52% ในความผันผวน ทั้งที่ $G$ ของสองตัวต่างกันแค่สองเท่า เพราะ $G$ ถูกหารด้วย variance ของ factor เอง

factor เล็กคือตัวที่ hedge กันบ่อยที่สุด optimizer จึงเสียเงิน hedge ความเสี่ยงที่ไม่มีอยู่จริงทุกวัน

ทำไมไม่มีใครเห็น: ถ้าผลตอบแทนเป็น Normal แต่ละ $\hat f_t^2$ มี variance $2\sigma^4$ ค่าเฉลี่ย 251 ตัวจึงคลาดสัมพัทธ์ $\sqrt{2/251}=8.93\%$ ความเอน 11.35% จึงจมอยู่ในความคลาดของปีเดียว แต่มันไม่หายเมื่อเฉลี่ยหลายปี เพราะมันไปทางเดียวเสมอ ต้องหักด้วยสูตร ไม่ใช่รอให้เห็น

บรรทัดสุดท้ายคือทางแก้ ส่วนการหารด้วย 250 คูณทุกอย่างด้วย $251/250=1.004$ ซึ่งแก้อีกปัญหาหนึ่ง (การหักค่าเฉลี่ย) และไปผิดทาง

ขั้นที่ 4 — factor 40 ตัว ข้อมูลครึ่งปี: eigenvalue กระจายเอง

model จริงมีราว 40 factor (style กับ industry) และมักใช้ข้อมูล 126 วันหรือครึ่งปีเพื่อให้ตอบสนองเร็ว ลองกรณีที่ง่ายที่สุด: covariance จริงคือ $\mathbf I$ ทุก factor ผันผวนเท่ากันและไม่สัมพันธ์กัน eigenvalue จริงทุกตัวคือ 1 ผลของ Marchenko และ Pastur (1967) บอกว่า eigenvalue ของ sample covariance กระจายอยู่ระหว่างสองขอบนี้เมื่อ $m$ กับ $T$ ใหญ่ที่อัตราส่วน $q$ คงที่

\[ \begin{aligned} q&=\frac mT=\frac{40}{126}=0.3175,\\ \lambda_{\min}&\approx(1-\sqrt q)^2=0.1906,\\ \lambda_{\max}&\approx(1+\sqrt q)^2=2.4443,\\ \frac{\lambda_{\max}}{\lambda_{\min}}&=12.83,\\ \frac1{\sqrt{0.1906}}&=2.29. \end{aligned} \]

ความจริงมี condition number 1 แต่ข้อมูลครึ่งปีทำให้มันดูเหมือน 12.83 โดยไม่มีโครงสร้างอะไรเลย eigenvalue ใหญ่ถูกดันขึ้น ตัวเล็กถูกกดลง โค้ดท้ายหน้าจำลองครึ่งปีแบบนี้ 40 รอบ (seed 27) ได้ค่าเฉลี่ยตัวเล็กสุด 0.2175 และใหญ่สุด 2.3235 ใกล้ขอบของสูตร ต่างเพราะ 40 factor ยังไม่ใหญ่พอให้ขอบคม

บรรทัดสุดท้ายคือราคาบนโต๊ะ optimizer ชอบทิศที่ model บอกว่าเสี่ยงน้อย พอร์ตตาม eigenvector ของ 0.1906 ถูกบอกว่าผันผวน $\sqrt{0.1906}=0.437$ ทั้งที่จริงคือ 1 ความเสี่ยงจริงสูงกว่าที่เห็น 2.29 เท่า และพอร์ตที่ optimizer เลือกจะเอียงไปหาทิศพวกนี้พอดี

ที่ 10 factor กับ 251 วัน $q=0.0398$ ขอบแคบลงเหลือ 0.6406 ถึง 1.4390 ปัญหาจึงเป็นเรื่องของ model ใหญ่ที่ข้อมูลสั้น

ขั้นที่ 5 — ดึงเข้าหาเป้า: eigenvalue ขยับเข้าหาค่าเฉลี่ย

ทางแก้คือผสม covariance ที่หัก $\mathbf G$ แล้วกับ matrix แนวทแยงที่ค่าเท่ากับค่าเฉลี่ยของ eigenvalue นี่คือนิยามของ shrinkage แบบ Ledoit–Wolf คำถามคือมันทำอะไรกับ eigenvalue: คูณทั้งสองข้างด้วย eigenvector $\mathbf e$ ของ $\mathbf S$ ที่มี eigenvalue $\lambda$

\[ \begin{aligned} \mathbf S&=\hat{\boldsymbol\Sigma}-\mathbf G,\quad\bar\lambda=\tfrac1m\operatorname{trace}\mathbf S,\\ \boldsymbol\Omega(\delta)&=(1-\delta)\mathbf S+\delta\bar\lambda\mathbf I,\\ \boldsymbol\Omega(\delta)\mathbf e&=(1-\delta)\lambda\mathbf e+\delta\bar\lambda\mathbf e,\\ \lambda(\delta)&=(1-\delta)\lambda+\delta\bar\lambda,\\ \delta=0.2&:\ 0.3525,\ 2.1555,\\ \tfrac{2.1555}{0.3525}&=6.12,\quad\tfrac1{\sqrt{0.3525}}=1.68. \end{aligned} \]

จังหวะสำคัญคือบรรทัดที่สาม $\mathbf I$ คูณ vector ไหนก็ได้ตัวเดิม eigenvector จึงไม่เปลี่ยน มีแค่ eigenvalue ที่ถูกลากเข้าหา $\bar\lambda$ เป็นเส้นตรง ตัวเล็กขึ้น ตัวใหญ่ลง condition number หดลงเสมอ และ trace ไม่เปลี่ยน ความเสี่ยงรวมโดยเฉลี่ยจึงเท่าเดิม

ตัวเลขใช้ขอบของขั้นที่ 4 กับ $\bar\lambda=1$ condition number ตกจาก 12.83 เหลือ 6.12 และทิศที่แย่ที่สุดคลาดเหลือ 1.68 เท่าแทน 2.29 ที่ $\delta=0.5$ ได้ 0.5953 กับ 1.7222 condition number 2.89

ราคาที่จ่ายคือความเอน ถ้าความจริงไม่แบน เช่น market ผันผวน 1.0% แต่ momentum 0.35% การลากทุกอย่างเข้าหาค่าเฉลี่ยลบความต่างที่มีจริงทิ้งด้วย $\delta$ ที่ดีที่สุดจึงขึ้นกับว่าความจริงห่างจากเป้าแค่ไหน

สูตรของ Ledoit และ Wolf ประมาณ $\delta$ จากข้อมูลเอง และคนทำงานมักยอมดึงมากกว่านั้นเพื่อแลกกับ matrix ที่มั่นคง

ขั้นที่ 6 — ค่าเฉลี่ยที่ลืมอดีตมีข้อมูลเท่าไร

ข้อที่สามเริ่มจากคำถามว่า EWMA ของ 25.5 ที่ half-life หนึ่งมีข้อมูลเท่ากับค่าเฉลี่ยธรรมดากี่วัน และข้อมูลของมันเก่าเฉลี่ยกี่วัน สองตัวเลขนี้คือราคากับของที่ได้เมื่อเลือก half-life ให้ $y_s$ เป็นข้อมูลที่เป็นอิสระกัน variance เท่ากัน

\[ \begin{aligned} w_s&=(1-\lambda)\lambda^s,\\ \operatorname{var}\Big(\textstyle\sum_s w_sy_s\Big)&=\operatorname{var}(y)\textstyle\sum_s w_s^2,\\ \textstyle\sum_s w_s^2&=\frac{(1-\lambda)^2}{1-\lambda^2}=\frac{1-\lambda}{1+\lambda},\\ N_{\rm eff}&=\frac{1+\lambda}{1-\lambda},\\ \bar s&=\textstyle\sum_s s\,w_s=\frac{\lambda}{1-\lambda}. \end{aligned} \]

$s=0,1,2,\ldots$ คืออายุของข้อมูลเป็นวัน บรรทัดที่สองใช้ variance ของผลรวมถ่วงของสิ่งที่เป็นอิสระกัน บรรทัดที่สามคืออนุกรมเรขาคณิตอัตราส่วน $\lambda^2$ แล้วแยก $1-\lambda^2=(1-\lambda)(1+\lambda)$

ค่าเฉลี่ยธรรมดาของ $N$ ตัวมี $\sum w^2=1/N$ จึงอ่านบรรทัดที่สี่ได้ว่า EWMA มีข้อมูลเท่ากับ $N_{\rm eff}$ วัน บรรทัดสุดท้ายคืออายุเฉลี่ยของข้อมูลที่ใช้ ได้จากอนุกรม $\sum s\lambda^s=\lambda/(1-\lambda)^2$

ขั้นที่ 7 — ความผันผวนเร็ว correlation ช้า: คิดเป็นตัวเลข

โจทย์ให้อะไรมาบ้าง: แยก $\boldsymbol\Omega_f=\mathbf V\mathbf C\mathbf V$ เป็นความผันผวน $\mathbf V$ (แนวทแยง) กับ correlation $\mathbf C$ แล้วประมาณแต่ละชิ้นด้วย EWMA ของตัวเอง ความผันผวนใช้ half-life 63 วัน correlation ใช้ 500 วัน ช่วงสามเดือนถึงสองปีนี้คือช่วงที่ model หุ้นรายวันใช้กัน ความคลาดของ correlation จากข้อมูล $N$ ตัวที่เป็น Normal ประมาณได้ด้วย $(1-\rho^2)/\sqrt N$ ที่ $\rho=0.30$

\[ \begin{aligned} h=63&:\ \lambda=0.98906,\\ &\quad N_{\rm eff}=181.8,\\ &\quad \bar s=90.4,\\ h=500&:\ \lambda=0.998615,\\ &\quad N_{\rm eff}=1{,}442.7,\\ &\quad \bar s=720.8,\\ \text{vol}&:\ \tfrac1{\sqrt{2(181.8)}}=5.24\%,\\ \rho&:\ \tfrac{0.91}{\sqrt{181.8}}=0.0675,\\ &\quad\tfrac{0.91}{\sqrt{1{,}442.7}}=0.0240. \end{aligned} \]

คำตอบ: ที่ half-life 63 วัน ความผันผวนคลาดแค่ 5.24% (คิดแบบเดียวกับขั้นที่ 3: variance คลาด $\sqrt{2/N}$ ความผันผวนคลาดครึ่งหนึ่งของนั้น) แต่ correlation 0.30 คลาด ±0.0675 หรือเกือบหนึ่งในสี่ของตัวมันเอง correlation จึงต้องการข้อมูลมากกว่า ที่ 500 วันเหลือ ±0.0240 แต่ข้อมูลเก่าเฉลี่ย 720.8 วัน หรือเกือบสามปี ถ้าใช้ half-life นี้กับความผันผวนด้วย ตัวเลขความเสี่ยงจะเล่าเรื่องของตลาดเมื่อสามปีก่อน

ตรวจเองใน 10 วินาที: $\lambda=0.5^{1/63}$ และ $\lambda^{63}=0.5$ พอดี $N_{\rm eff}\approx2h/\ln2=2(63)/0.6931=181.8$ ตรงกับบรรทัดที่สอง

มีรายละเอียดหนึ่งในสูตรของ correlation: ต้องหาร $\hat f_{k,t}$ ด้วยความผันผวนของวันนั้นก่อน แล้วค่อยเฉลี่ยผลคูณ ถ้าไม่หาร วันที่ความผันผวนของ factor หนึ่งพุ่งจะครองค่าเฉลี่ย สมมติครึ่งหนึ่งของวันความผันผวนของ factor แรกเป็นสามเท่า อีกตัวคงเดิม และ correlation จริง 0.30 ทุกวัน ค่าที่ได้คือ $0.30\times(1+3)/\sqrt{(1+9)(1+1)}=0.2683$ ต่ำกว่าความจริงทั้งที่ correlation ไม่ได้เปลี่ยนเลย

ขั้นที่ 8 — ความจำเล็ก ๆ ที่ทำให้ความเสี่ยงรายปีต่ำเกินจริง

ข้อสุดท้าย: factor return รายวันมี autocorrelation เล็ก ๆ ที่ไม่เป็นศูนย์ ถ้ามองเป็น AR(1) ของ 16.2 ที่ $\phi=0.12$ (ค่าสมมติ) variance ของผลรวม $T$ วันไม่ใช่ $T$ เท่าของ variance รายวัน กางผลรวมออกแล้วนับพจน์ไขว้

\[ \begin{aligned} S_T&=x_1+x_2+\cdots+x_T,\\ \operatorname{var}(S_T)&=T\gamma_0\\ &\quad+2\textstyle\sum_{l=1}^{T-1}(T-l)\gamma_l,\\ \gamma_l&=\phi^l\gamma_0,\\ \frac{\operatorname{var}(S_T)}{T\gamma_0}&\to1+\frac{2\phi}{1-\phi}\\ &=\frac{1+\phi}{1-\phi}=\frac{1.12}{0.88}\\ &=1.2727,\\ \sqrt{1.2727}&=1.1282. \end{aligned} \]

คู่วันที่ห่างกัน $l$ วันมีอยู่ $T-l$ คู่ และแต่ละคู่นับสองครั้งในตาราง $T\times T$ จึงได้บรรทัดที่สอง หารด้วย $T\gamma_0$ แล้วให้ $T$ โต น้ำหนัก $1-l/T$ เข้าใกล้ 1 เหลืออนุกรม $2\sum\phi^l=2\phi/(1-\phi)$ ที่ $T=251$ พอดีได้ 1.2715 แทบเท่ากัน

autocorrelation แค่ 0.12 ซึ่งหลายคนปัดทิ้ง ทำให้ความผันผวนรายปีจริงสูงกว่าการคูณ $\sqrt{251}$ ตรง ๆ 12.82% กองทุนที่ตั้งเป้าความเสี่ยง 10% ต่อปีจะวิ่งจริงที่ 11.28% หรือพูดอีกทางว่าตัวเลขที่รายงานต่ำกว่าความจริง 11.36% ถ้า $\phi$ ติดลบ ทุกอย่างกลับทิศ ความเสี่ยงรายปีจะถูกรายงานสูงเกินจริงแทน

ขั้นที่ 9 — Newey–West: เติม lag กลับเข้าไป

ทางแก้คือประมาณ variance ระยะยาวตรง ๆ โดยเติม autocovariance $\mathbf C_l=\tfrac1T\sum_t\hat{\mathbf f}_t\hat{\mathbf f}_{t-l}^{\mathsf T}$ เข้าไป ถ่วงด้วยน้ำหนักที่ลดลงเป็นเส้นตรง นี่คือนิยามของ Newey–West (1987) น้ำหนักแบบนี้รับประกันว่าผลลัพธ์ไม่มีทิศที่ variance ติดลบ แล้วคิดค่าคาดหมายของมันกับ AR(1) ของขั้นที่ 8 ซึ่ง $\mathbf C_l$ มีค่าคาดหมาย $(1-l/T)\gamma_l$

\[ \begin{aligned} \hat{\boldsymbol\Omega}_L&=\mathbf C_0+\textstyle\sum_{l=1}^{L}k_l\mathbf D_l,\\ \mathbf D_l&=\mathbf C_l+\mathbf C_l^{\mathsf T},\\ k_l&=1-\frac{l}{L+1},\\ R_L&=\tfrac{1-\phi}{1+\phi}\big(1+2A_L\big),\\ A_L&=\textstyle\sum_{l=1}^{L}k_l\big(1-\tfrac lT\big)\phi^l,\\ R_0,\ R_1&=78.57,\ 87.96\%,\\ R_2,\ R_5&=91.84,\ 95.87\%,\\ R_{10}&=97.70\%. \end{aligned} \]

$R_L$ คือค่าคาดหมายของ $\hat\Omega_L$ หารด้วย variance ระยะยาว $\Omega_{\rm long}=\gamma_0(1+\phi)/(1-\phi)$ ซึ่งคือสิ่งที่ต้องการจริง ได้มาจากการแทน $\mathrm E[\mathbf C_l]=(1-l/T)\phi^l\gamma_0$ ลงในบรรทัดแรก

ถ้าไม่เติม lag เลย ($L=0$) ได้แค่ $0.88/1.12=78.57\%$ ของมัน ความเสี่ยงหายไปหนึ่งในห้า ห้า lag ได้คืน 95.87% หลังจากนั้นได้คืนช้าลงมาก เพราะ $\phi^l$ หดเร็ว และน้ำหนัก $k_l$ ยังกด lag ไกล ๆ ไว้ ถ้าลองกับ $\phi=0$ ทุกบรรทัดให้ 100% พอดี การแก้ไม่ทำร้ายข้อมูลที่ไม่มีความจำ

คำถามที่ควรถามออกมาดัง ๆ

ถ้า $G$ ของ market เล็กกว่า variance ของมันกว่าร้อยเท่า (0.007032 เทียบ 1.0) ทำไมต้องสนใจ? เพราะ $\mathbf G$ ไม่ได้เล็กเท่ากันเมื่อเทียบกับทุก factor momentum ที่เล็กกว่า market เกือบสามเท่าในความผันผวนเอนถึง 11.35% และ factor เล็กคือตัวที่ถูก hedge และถูกใช้ตัดสินขนาดพอร์ต

function matrix(name, A) {
  if (!Array.isArray(A) || A.length === 0 || !A.every(row => Array.isArray(row) && row.length === A[0].length && row.every(Number.isFinite))) {
    throw new TypeError(`${name} must be a non-empty rectangular array of finite numbers`);

}

const mul = (A, B) => A.map(row => B[0].map((_, j) => row.reduce((s, a, k) => s + a * B[k][j], 0)));
// Gauss-Jordan inverse with partial pivoting.
function inverse(A) {
  const n = matrix('A', A).length, M = A.map((row, i) => [...row, ...row.map((_, j) => (i === j ? 1 : 0))]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let i = c + 1; i < n; i++) if (abs(M[i][c]) > abs(M[p][c])) p = i;
    if (abs(M[p][c]) < 1e-12) throw new RangeError('matrix is singular');
    [M[c], M[p]] = [M[p], M[c]];
    const v = M[c][c];
    for (let j = 0; j < 2 * n; j++) M[c][j] /= v;
    for (let i = 0; i < n; i++) if (i !== c) { const g = M[i][c]; for (let j = 0; j < 2 * n; j++) M[i][j] -= g * M[c][j]; }
  }
  return M.map(row => row.slice(n));
}
// Steps 1-2: constrained WLS of 27.1 (way C). The bordered inverse gives H and G = H Omega_eps H'.
function factorMimicking(B, sigma, c) {
  matrix('B', B);
  if (!Array.isArray(sigma) || sigma.length !== B.length || !sigma.every(s => Number.isFinite(s) && s > 0)) throw new RangeError('every idiosyncratic volatility must be positive, one per stock');
  const BW = T(B).map(row => row.map((x, i) => x / (sigma[i] * sigma[i])));
  const K = mul(BW, B).map((row, i) => [...row, c[i]]);
  K.push([...c, 0]);
  const P = inverse(K).slice(0, c.length).map(row => row.slice(0, c.length));
  return {H: mul(P, BW), G: P};
}

    const v = rnd(), R = sqrt(-2 * log(u));
    spare = R * sin(2 * PI * v);
    return R * cos(2 * PI * v);
  };
}
// Cyclic Jacobi rotations: all eigenvalues of a symmetric matrix, sorted.
function eigenvalues(S) {
  const n = matrix('S', S).length, A = S.map(row => [...row]);
  if (A.some((row, i) => row.length !== n || row.some((x, j) => abs(x - A[j][i]) > 1e-12 * (abs(x) + 1)))) throw new RangeError('matrix must be square and symmetric');
  for (let sweep = 0; sweep < 100; sweep++) {
    let off = 0;
    for (let i = 0; i < n; i++) for (let j = i + 1; j < n; j++) off += A[i][j] * A[i][j];
    if (off < 1e-26) break;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) {
      if (A[p][q] === 0) continue;
      const theta = (A[q][q] - A[p][p]) / (2 * A[p][q]);
      const t = (theta >= 0 ? 1 : -1) / (abs(theta) + sqrt(theta * theta + 1)), c = 1 / sqrt(t * t + 1), s = t * c;
      for (let k = 0; k < n; k++) { const akp = A[k][p], akq = A[k][q]; A[k][p] = c * akp - s * akq; A[k][q] = s * akp + c * akq; }
      for (let k = 0; k < n; k++) { const apk = A[p][k], aqk = A[q][k]; A[p][k] = c * apk - s * aqk; A[q][k] = s * apk + c * aqk; }
    }
  }
  return A.map((row, i) => row[i]).sort((a, b) => a - b);
}
// Sample covariance (divide by n, no mean removed) of m independent unit-variance factors: the truth is I.
function sampleCovariance(m, n, z) {
  const X = Array.from({length: m}, () => Array.from({length: n}, z));
  return X.map(a => X.map(b => a.reduce((s, x, t) => s + x * b[t], 0) / n));
}

  if (typeof h !== 'number' || !Number.isFinite(h) || !(h > 0)) throw new RangeError('half-life must be a positive number of days');

// Steps 8-9: AR(1) variance ratio and the expected share of the long-run variance Newey-West captures.
function ar1Ratio(phi, n) {
  if (typeof phi !== 'number' || !(abs(phi) < 1)) throw new RangeError('autocorrelation must be strictly between -1 and 1');
  let s = 1;
  for (let l = 1; l < n; l++) s += 2 * (1 - l / n) * phi ** l;
  return s;
}
function neweyWestShare(phi, lags, n) {
  if (!Number.isInteger(lags) || lags < 0) throw new RangeError('lags must be a whole number, 0 or more');
  let s = 1;
  for (let l = 1; l <= lags; l++) s += 2 * (1 - l / (lags + 1)) * (1 - l / n) * phi ** l;
  return s * (1 - phi) / (1 + phi);
}

ที่มาที่ไป

Vladimir Marchenko กับ Leonid Pastur หารูปการกระจายของ eigenvalue ของ sample covariance ในปี 1967 Tim Bollerslev เสนอในปี 1990 ให้ความผันผวนเปลี่ยนตามเวลาแต่ correlation คงที่ และ Robert Engle ขยายเป็น dynamic conditional correlation ในปี 2002 Whitney Newey กับ Kenneth West เสนอตัวประมาณ variance ระยะยาวที่ไม่ติดลบในปี 1987 และ Olivier Ledoit กับ Michael Wolf เสนอ shrinkage เข้าหาเป้าพร้อมสูตรเลือก $\delta$ จากข้อมูลในปี 2003–2004

ข้อจำกัด: สี่การแก้ สมมติอะไรไว้

หัก $\mathbf G$รู้ $\boldsymbol\Omega_\epsilon$ และ model ถูก$\sigma_i$ เองก็ประมาณมา (27.4)หักได้เกือบถูก ต้องดึงเข้าหาเป้ากันค่าติดลบ
shrinkage เข้าหาแนวทแยงแบนเป้าที่ทุก factor เหมือนกันไม่ไกลจากความจริงfactor ผันผวนต่างกันหลายเท่าดึงมากไปลบความต่างที่มีจริง
