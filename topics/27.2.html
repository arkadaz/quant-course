27.2 Estimating the Factor Covariance Matrix

ทีมความเสี่ยงต้องรู้ว่า factor แต่ละตัวแกว่งแค่ไหน และแต่ละคู่ขยับไปด้วยกันแค่ไหน วิธีตรง ๆ คือเฉลี่ยจาก factor return รายวัน แต่วิธีนี้ผิดสี่ทาง หน้านี้แก้ทีละทาง: หักเสียงของพอร์ตออก ดึง eigenvalue เข้าหากัน ให้ความผันผวนกับ correlation ลืมอดีตคนละความเร็ว และนับความเกี่ยวกันของวันติดกันกลับเข้าไป

กองทุนหุ้นแห่งหนึ่งมีโปรแกรมชื่อ optimizer ทำหน้าที่เลือกว่าจะถือหุ้นตัวไหนเท่าไร ให้ได้ผลตอบแทนดีโดยความเสี่ยงไม่เกินที่ตั้งไว้ โปรแกรมนี้ต้องรู้ว่าตัวขับเคลื่อนร่วมของหุ้นแต่ละตัวแกว่งแรงแค่ไหน ตัวขับเคลื่อนร่วมเหล่านี้เรียกว่า factor ตัวอย่างหนึ่งคือ momentum: หุ้นที่ราคาวิ่งดีมาก่อนมักวิ่งต่อ หุ้นที่แย่มาก่อนมักแย่ต่อ

ทุกคืนทีมความเสี่ยงรัน cross-sectional regression บนหุ้น 600 ตัว ผลที่ได้คือ factor return ของวันนั้น คือ factor แต่ละตัวพาหุ้นขึ้นหรือลงกี่เปอร์เซ็นต์ในวันนั้น ทีมเก็บตัวเลขของ momentum ไว้ครบหนึ่งปี:

  • จำนวนข้อมูล $T=251$ วัน เพราะหนึ่งปีมี 252 วันทำการ และผลตอบแทนหนึ่งตัวต้องใช้ราคาสองวันติดกัน จึงได้ $252-1=251$ ตัว
  • ความผันผวน (SD หรือ standard deviation ของผลตอบแทนรายวัน) ที่คิดตรง ๆ จาก 251 ตัวนี้ โดยหารด้วย 251 ได้ $\hat\sigma=0.3693\%$ ต่อวัน (ตัวเลขสมมติ เลือกให้เท่ากับค่าที่การวัดแบบนี้ให้โดยเฉลี่ย หน้านี้จะคำนวณให้ดูว่ามาจากไหน)

ก่อนส่งตัวเลขนี้เข้า optimizer เพื่อนในทีมเตือนว่า “หารด้วย 250 แทน 251 สิ จะได้ไม่เอน” (เอน คือคลาดไปทางเดียวกันเสมอ ไม่ใช่สูงบ้างต่ำบ้าง) ความผันผวนจริงของ momentum คือเท่าไร และคำเตือนนั้นช่วยไหม?

ลองตอบก่อนเปิดเฉลย

ความผันผวนจริงคือ 0.35% ต่อวัน (ค่าจริงที่หน้านี้สมมติไว้) ตัวเลข factor return ที่ได้ทุกคืนไม่ใช่ค่าจริง มันคือผลตอบแทนของพอร์ตหุ้นพอร์ตหนึ่ง พอร์ตนั้นพกการขยับเฉพาะตัวของหุ้นที่ถืออยู่มาด้วย ส่วนเกินนี้ทำให้ variance ที่วัดได้สูงเกินจริงเสมอ หน้านี้เรียกส่วนเกินนี้ว่า $G$ และจะคำนวณให้ดูว่า $G=0.013907$ (หน่วย %²)

\[\begin{aligned}\hat\sigma^2&=\sigma^2+G\\&=0.35^2+0.013907\\&=0.1225+0.013907\\&=0.1364=0.3693^2,\\\frac{G}{\sigma^2}&=\frac{0.013907}{0.1225}=11.35\%.\end{aligned}\]

variance ที่วัดได้จึงสูงเกินจริง 11.35% ส่วนการหารด้วย 250 แทน 251 คือการคูณ variance ด้วย $251/250=1.004$ ตัวเลขจึงใหญ่ขึ้นอีก 0.4% ซึ่งไปผิดทาง ทางแก้ที่ถูกคือหัก $G$ ออก: $\sqrt{0.3693^2-0.013907}=\sqrt{0.1225}=0.35$

ภาพรวมก่อนลงสูตร

ทำไมต้องสนใจ covariance ของ factor: ใน factor model ความเสี่ยงของพอร์ตคิดจากสูตร $\sigma_P^2=\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b+\sigma_{\rm idio}^2$ โดย $\mathbf b$ คือ exposure (พอร์ตไวต่อ factor แต่ละตัวแค่ไหน) $\sigma_{\rm idio}^2$ คือ variance ส่วนเฉพาะตัวของหุ้น และ $\boldsymbol\Omega_f$ คือ factor covariance matrix ตารางนี้บอกว่า factor แต่ละตัวแกว่งแค่ไหน และแต่ละคู่ขยับไปด้วยกันแค่ไหน ถ้า $\boldsymbol\Omega_f$ ผิด ตัวเลขความเสี่ยงทุกตัวที่ optimizer เห็นก็ผิดตาม

วัตถุดิบมีวันละหนึ่งชุด คือ vector $\hat{\mathbf f}_t$ ที่เก็บ factor return ของทุก factor ในวันที่ $t$ (หมวก $\hat{\ }$ แปลว่าเป็นค่าที่ประมาณได้ ไม่ใช่ค่าจริง) ทางลัดที่ใคร ๆ ก็คิดได้คือเฉลี่ยผลคูณ $\hat{\mathbf f}_t\hat{\mathbf f}_t^{\mathsf T}$ หลาย ๆ วันแบบ covariance matrix ทั่วไป และให้วันใหม่มีน้ำหนักมากกว่าวันเก่าแบบ EWMA (ค่าเฉลี่ยที่น้ำหนักของแต่ละวันหดลงทีละนิดตามอายุ) รูปด้านล่างแสดงทางลัดนี้

ทางลัดนี้ผิดสี่ทาง หน้านี้แก้ทีละทาง:

  • ทางที่ 1 (ขั้นที่ 1–3) ตัวเลขแต่ละวันไม่ใช่ factor return จริง มันมีเสียงของพอร์ตปนมา variance ที่วัดได้จึงสูงเกินเสมอ เราจะคิดขนาดของเสียงนี้ด้วยมือ และดูว่าทำไมมองด้วยตาไม่เห็น
  • ทางที่ 2 (ขั้นที่ 4–5) เมื่อมี factor 40 ตัวแต่ข้อมูลแค่ครึ่งปี matrix ที่ได้จะบิด ทิศที่ดูปลอดภัยที่สุดกลับเสี่ยงกว่าที่เห็นมาก ทางแก้คือ shrinkage (ดึง matrix เข้าหาแบบที่เรียบง่ายกว่า)
  • ทางที่ 3 (ขั้นที่ 6–7) ความเร็วในการลืมข้อมูลย้อนหลังที่เหมาะกับความผันผวน ไม่เหมาะกับ correlation เราจะวัดว่าค่าเฉลี่ยแบบลืมอดีตมีข้อมูลเท่ากับกี่วัน แล้วได้เหตุผลที่ต้องใช้ half-life สองค่า
  • ทางที่ 4 (ขั้นที่ 8–9) ผลตอบแทนของวันติดกันเกี่ยวกันนิดหน่อย (เรียกว่า autocorrelation) การแปลงความผันผวนรายวันเป็นรายปีด้วยการคูณ $\sqrt{T}$ จึงต่ำเกินจริง ทางแก้คือ Newey–West

factor return คือ factor ตัวหนึ่งพาหุ้นขึ้นหรือลงกี่เปอร์เซ็นต์ในวันหนึ่ง ค่าที่ได้จาก cross-sectional regression เท่ากับผลตอบแทนของพอร์ตหุ้นจริงพอร์ตหนึ่งพอดี พอร์ตนั้นเรียกว่า factor-mimicking portfolio (พอร์ตที่เลียนแบบ factor)
เสียงของพอร์ต ($\mathbf G$)
ส่วนที่ factor return ที่วัดได้คลาดจากค่าจริง มาจากการขยับเฉพาะตัวของหุ้นที่ factor-mimicking portfolio ถืออยู่ $\mathbf G$ คือ covariance ของส่วนนี้ ต้องหักออกจาก covariance ที่วัดได้
Shrinkage
ผสม covariance ที่วัดได้กับเป้าที่เรียบง่าย ในหน้านี้เป้าคือ matrix แนวทแยงที่ค่าบนแนวทแยงเท่ากันหมด เรายอมเอนนิดหนึ่งเพื่อให้ความคลาดรวมลดลง ใช้เมื่อจำนวน factor ไม่เล็กเมื่อเทียบกับจำนวนวัน
Condition number
eigenvalue ใหญ่สุดหารด้วย eigenvalue เล็กสุด บอกว่าการผกผัน matrix ขยายความคลาดได้มากแค่ไหน สำคัญเพราะ optimizer ต้องผกผัน covariance ทุกวัน

Half-life และ effective sample size
half-life คือจำนวนวันที่น้ำหนักของข้อมูลหดเหลือครึ่ง (แบบเดียวกับ EWMA) effective sample size คือจำนวนข้อมูลที่ถ้าเฉลี่ยธรรมดา จะคลาดเท่ากับค่าเฉลี่ยถ่วงนั้น
Autocorrelation
correlation ระหว่างค่าของวันนี้กับค่าของ $l$ วันก่อน ($l$ เรียกว่า lag) ถ้าเป็นบวก วันที่ขึ้นมักตามด้วยวันที่ขึ้นอีกนิด autocovariance คือ covariance แบบเดียวกัน ยังไม่หารด้วย variance
Long-run variance และ Newey–West
long-run variance คือ variance ของผลรวมหลายวัน หารด้วยจำนวนวัน ถ้าข้อมูลมี autocorrelation ค่านี้ไม่เท่ากับ variance รายวัน Newey–West ประมาณค่านี้โดยบวก autocovariance หลาย lag เข้าไป ถ่วงด้วยน้ำหนักที่ลดลงตาม lag

ขั้นที่ 1 — ค่าที่วัดได้คือ factor บวกเสียงของพอร์ต

ก่อนจะเฉลี่ยอะไร ต้องถามก่อนว่าตัวเลขที่เอามาเฉลี่ยคืออะไรกันแน่ เริ่มจากสองข้อเท็จจริงที่มีอยู่แล้ว

  • factor model บอกว่าผลตอบแทนของหุ้นทุกตัวในวันที่ $t$ คือ $\mathbf r_t=\mathbf B\mathbf f_t+\boldsymbol\epsilon_t$ คือส่วนที่ factor พาไป ($\mathbf B\mathbf f_t$) บวกส่วนที่หุ้นแต่ละตัวขยับเอง ($\boldsymbol\epsilon_t$) โดย $\mathbf f_t$ คือ factor return จริงที่ไม่มีใครเห็น
  • cross-sectional regression คำนวณ factor return จากผลตอบแทนหุ้นด้วยการคูณ matrix $\hat{\mathbf f}_t=\mathbf H\mathbf r_t$ แถวที่ $k$ ของ $\mathbf H$ คือน้ำหนักที่ให้หุ้นแต่ละตัว $\hat f_{k,t}$ จึงเป็นผลตอบแทนของพอร์ตหุ้นจริงพอร์ตหนึ่ง คือ factor-mimicking portfolio ของ factor ที่ $k$

แทนสมการแรกลงในสมการที่สอง แล้วดูว่าเหลืออะไร

\[ \begin{aligned} \hat{\mathbf f}_t&=\mathbf H\mathbf r_t\\ &=\mathbf H\mathbf B\mathbf f_t+\mathbf H\boldsymbol\epsilon_t\\ &=\mathbf f_t+\mathbf H\boldsymbol\epsilon_t,\\ \operatorname{cov}(\hat{\mathbf f}_t)&=\boldsymbol\Omega_f+\mathbf G,\\ \mathbf G&=\mathbf H\boldsymbol\Omega_\epsilon\mathbf H^{\mathsf T},\\ \hat{\boldsymbol\Omega}_f&=\hat{\boldsymbol\Sigma}-\mathbf G. \end{aligned} \]

ใจความของขั้นนี้คือ ค่าที่วัดได้เท่ากับค่าจริงบวกเสียงของพอร์ต จังหวะที่ทำให้ $\mathbf f_t$ โผล่ออกมาเดี่ยว ๆ คือ $\mathbf H\mathbf B=\mathbf I$ ทำไมใช้ได้: regression ถูกสร้างมาให้พอร์ตของ factor ที่ $k$ มี exposure 1 ต่อ factor ของตัวเอง และ 0 ต่อ factor อื่นทุกตัว นั่นคือความหมายของคำว่า “เลียนแบบ factor” (ถ้าใช้เงื่อนไขถ่วงมูลค่าตลาดแบบในหน้า cross-sectional regression ค่าจริง $\mathbf f_t$ ก็นิยามใต้เงื่อนไขเดียวกัน จึงยังได้ $\mathbf f_t$ พอดี) ส่วนที่เหลือ $\mathbf H\boldsymbol\epsilon_t$ คือการขยับเฉพาะตัวของหุ้นที่พอร์ตนั้นถืออยู่

ทำไม covariance ของผลรวมไม่มีพจน์ไขว้: factor model สมมติว่าส่วนเฉพาะตัวไม่เกี่ยวกับ factor และ variance ของผลรวมสองก้อนที่ไม่เกี่ยวกัน เท่ากับผลรวมของ variance ทั้งสอง ก้อนที่สองคือ $\mathbf G=\mathbf H\boldsymbol\Omega_\epsilon\mathbf H^{\mathsf T}$ ซึ่งไม่มีวันติดลบ เพราะมันคือ variance ของพอร์ต ค่าที่วัดได้จึงสูงเกินจริงเสมอ ไม่ใช่สูงบ้างต่ำบ้าง ทางแก้จึงตรงไปตรงมา: เอา covariance ที่วัดจาก $\hat{\mathbf f}_t$ (เรียกว่า $\hat{\boldsymbol\Sigma}$) มาหัก $\mathbf G$ ออก

$\mathbf G$ หาได้จากของที่มีอยู่แล้ว ถ้า $\mathbf B$ มี rank เต็ม และ regression ถ่วงหุ้นแต่ละตัวด้วย $1/\sigma_i^2$ (คือ $\boldsymbol\Omega_\epsilon^{-1}$) จะได้ $\mathbf G=(\mathbf B^{\mathsf T}\boldsymbol\Omega_\epsilon^{-1}\mathbf B)^{-1}$ ซึ่งคือความคลาดของ factor return ที่คิดไว้แล้วในหน้า cross-sectional regression กรณีง่ายสุดช่วยให้เห็นภาพ ถ้า $\mathbf B^{\mathsf T}\mathbf B=\mathbf I$ และ $\boldsymbol\Omega_\epsilon=\mathbf I$ จะได้ $\mathbf G=\mathbf I$ การแก้คือลบ 1 ออกจากทุกช่องบนแนวทแยง

ขั้นที่ 2 — ขนาดของ $\mathbf G$ คิดด้วยมือจากพอร์ต momentum

รู้แล้วว่าต้องหัก $\mathbf G$ คำถามต่อไปคือมันใหญ่แค่ไหน ถ้าเล็กมากก็ไม่ต้องสนใจ ขั้นนี้คิดช่อง momentum ของ $\mathbf G$ ด้วยมือ

โจทย์ให้อะไรมาบ้าง:

  • น้ำหนักของพอร์ต momentum $\mathbf h_{\rm mom}$ (แถว momentum ของ $\mathbf H$) จากหุ้นแปดตัวในตัวอย่างของหน้า cross-sectional regression แถวนี้ออกมาเท่ากันไม่ว่าจะแก้ความกำกวมของ market กับ industry ด้วยวิธีไหน
  • ความผันผวนเฉพาะตัวของหุ้นแปดตัว $\sigma_i=1.8,\ 2.2,\ 1.5,\ 2.6,\ 2.0,\ 2.4,\ 1.7,\ 2.1$ (% ต่อวัน) ชุดเดียวกับหน้านั้น
  • จักรวาลจริงมีหุ้น 600 ตัว หน้านี้สมมติว่าเป็นหุ้นแปดตัวนั้นซ้ำกัน 75 ชุด ($8\times75=600$) แต่ละชุดมี loading และ $\sigma_i$ เหมือนกัน แต่การขยับเฉพาะตัวของหุ้นทุกตัวเป็นอิสระกัน

ทำไมสูตรเหลือแค่ผลรวมกำลังสอง: ส่วนเฉพาะตัวของหุ้นต่างตัวไม่เกี่ยวกัน $\boldsymbol\Omega_\epsilon$ จึงเป็น matrix แนวทแยง ช่อง momentum ของ $\mathbf G$ คือ $\mathbf h_{\rm mom}^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf h_{\rm mom}$ ซึ่งเหลือผลรวมของ $h_i^2\sigma_i^2$ ทีละตัว

\[ \begin{aligned} \mathbf h_{\rm mom}&=(0.2003,\ -0.2107,\\ &\qquad 0.0103,\ -0.2230,\\ &\qquad 0.2230,\ -0.0950,\\ &\qquad 0.1717,\ -0.0767),\\ G_{\rm mom}&=\textstyle\sum_i h_i^2\sigma_i^2\\ &=0.13004+0.21485\\ &\quad+0.00024+0.33602\\ &\quad+0.19883+0.05193\\ &\quad+0.08516+0.02595\\ &=1.0430\ (\%^2),\\ G_{600}&=\tfrac{1.0430}{75}=0.013907. \end{aligned} \]

คำตอบ: ถ้าจักรวาลมีหุ้นแค่แปดตัว ความคลาดรายวันของ momentum คือ $\sqrt{1.0430}=1.0213\%$ ซึ่งใหญ่กว่าความผันผวนจริงของ momentum เอง ($0.35\%$) ถึง $1.0213/0.35=2.92$ เท่า ตัวเลขที่วัดได้แทบเป็นเสียงล้วน

จักรวาล 600 ตัวช่วยได้มาก เพราะหุ้นแบบที่ $i$ มีอยู่ 75 ตัว พอร์ตจึงแบ่งน้ำหนัก $h_i$ ให้พวกมันตัวละ $h_i/75$ และการขยับเฉพาะตัวของทั้ง 75 ตัวหักล้างกันเอง

\[\begin{aligned}75\times\Big(\frac{h_i}{75}\Big)^2\sigma_i^2&=\frac{h_i^2\sigma_i^2}{75},\\G_{600}&=\frac{1.0430}{75}=0.013907,\\\sqrt{0.013907}&=0.1179\%.\end{aligned}\]

ทุกพจน์หารด้วย 75 เสียงของพอร์ตจึงเหลือ variance 0.013907 (%²) หรือความคลาด 0.1179% ต่อวัน ทำแบบเดียวกันกับแถว market ($h_{\rm mkt}$ ทาง C ในตารางของหน้า cross-sectional regression) ได้ผลรวม 0.5274 (โค้ดท้ายหน้าคิดซ้ำ) จึงได้ $G_{\rm mkt}=0.5274/75=0.007032$

ตรวจเองใน 10 วินาที: พจน์ที่ห้า $0.2230^2\times2.0^2=0.0497\times4=0.1989$ ใกล้ 0.19883 (ต่างกันเพราะปัด $h$) พจน์ที่ใหญ่ที่สุดมาจากหุ้นตัวที่ 4 เพราะพอร์ตถือมันน้ำหนักมาก และมันแกว่งแรงที่สุด ($\sigma_4=2.6\%$)

ขั้นที่ 3 — เอนเท่าไร และทำไมมองด้วยตาไม่เห็น

$G$ เป็นตัวเลขเปล่า ๆ ยังบอกไม่ได้ว่าเยอะหรือน้อย ต้องเทียบกับ variance จริงของ factor ตัวนั้น ขั้นนี้สมมติความผันผวนจริงสองตัว

  • market (factor ที่พาหุ้นทั้งตลาดขึ้นลงพร้อมกัน) ผันผวน $1.0\%$ ต่อวัน
  • momentum ผันผวน $0.35\%$ ต่อวัน

จากขั้นที่ 1 variance ที่วัดได้คือ variance จริงบวก $G$ หารทั้งสองข้างด้วย variance จริง จะได้ว่าค่าที่วัดได้ใหญ่เกินจริงกี่เท่า แถวสุดท้ายเตรียมไว้ใช้ในคำอธิบายด้านล่าง

\[ \begin{aligned} \frac{\operatorname{var}(\hat f_k)}{\operatorname{var}(f_k)}&=1+\frac{G_{kk}}{\operatorname{var}(f_k)},\\ \text{mom}&:\ 1+\frac{0.013907}{0.35^2}=1.1135,\\ \text{mkt}&:\ 1+\frac{0.007032}{1.0^2}=1.0070,\\ \sqrt{1.1135}&=1.0552,\\ \sqrt{2/251}&=0.0893. \end{aligned} \]

factor ใหญ่แทบไม่เป็นไร แต่ factor เล็กเจ็บหนัก variance ของ market เกินจริงแค่ 0.70% ส่วนของ momentum เกิน 11.35% ถ้าวัดเป็นความผันผวน momentum เกิน $\sqrt{1.1135}-1=5.52\%$ ที่น่าสังเกตคือ $G$ ของสองตัวต่างกันแค่ $0.013907/0.007032=1.98$ เท่า ความต่างมาจากตัวหาร: $G$ ถูกหารด้วย variance ของ factor เอง ซึ่งของ momentum เล็กกว่าของ market $1.0^2/0.35^2=8.2$ เท่า

ผลบนโต๊ะคือ optimizer เห็นความเสี่ยงของ factor เล็กมากเกินจริง จึงเสียเงิน hedge (ถือสถานะตรงข้ามเพื่อหักล้าง) ความเสี่ยงส่วนที่ไม่มีอยู่จริงทุกวัน

แล้วทำไมไม่มีใครสังเกตเห็น เพราะ variance ที่วัดจากข้อมูลปีเดียวก็แกว่งเองอยู่แล้ว ถ้าผลตอบแทนเป็น Normal ที่ค่าเฉลี่ยศูนย์ ตัวเลข $\hat f_t^2$ ของแต่ละวันมี variance $\mathrm E[\hat f^4]-(\mathrm E[\hat f^2])^2=3\sigma^4-\sigma^4=2\sigma^4$ ค่าเฉลี่ยของ 251 วันจึงมี variance $2\sigma^4/251$ ถอดรากได้ขนาดความคลาด แล้วหารด้วย $\sigma^2$ ซึ่งเป็นตัวที่เราวัด เพื่อดูว่าคลาดกี่เปอร์เซ็นต์ของตัวมันเอง

\[\begin{aligned}\frac{\sqrt{2\sigma^4/251}}{\sigma^2}&=\sqrt{2/251}=8.93\%,\\\frac{11.35}{8.93}&=1.27.\end{aligned}\]

ความเอน 11.35% ใหญ่กว่าความแกว่งปกติของปีเดียวแค่ 1.27 เท่า ปีเดียวจึงแยกไม่ออกว่าเป็นความเอนหรือเป็นโชค แต่ความเอนไม่หายเมื่อเฉลี่ยหลายปี เพราะมันไปทางเดียวเสมอ จึงต้องหักด้วยสูตร จะรอให้เห็นในข้อมูลไม่ได้

ส่วนคำเตือนของเพื่อน การหารด้วย 250 คือการคูณ variance ด้วย $251/250=1.004$ วิธีนี้แก้ปัญหาอื่น คือความเอนที่เกิดจากการหักค่าเฉลี่ยของข้อมูลชุดนั้นออกก่อน และมันทำให้ตัวเลขใหญ่ขึ้น ซึ่งไปผิดทาง

ขั้นที่ 4 — factor 40 ตัว ข้อมูลครึ่งปี: eigenvalue กระจายเอง

ปัญหาที่สองเกิดจากข้อมูลไม่พอ แบบจำลองความเสี่ยงของหุ้นที่ใช้จริงมี factor ตั้งแต่ไม่กี่ตัวจนถึงราว 100 ตัว และใช้ข้อมูลตั้งแต่ 126 วัน (ครึ่งปีทำการ) ถึง 500 วัน (ราวสองปี) จำนวน factor จึงไม่ได้เล็กมากเมื่อเทียบกับจำนวนวัน แล้วมันทำอะไรกับ matrix ที่ได้

ก่อนตอบ ทวนความหมายของ eigenvalue ในงานนี้ ถ้าพอร์ตมีน้ำหนักตาม eigenvector $\mathbf e$ (ยาว 1 หน่วย) ของ covariance $\boldsymbol\Sigma$ variance ของพอร์ตคือ $\mathbf e^{\mathsf T}\boldsymbol\Sigma\mathbf e=\lambda$ eigenvalue จึงเป็นความเสี่ยงของพอร์ตในทิศนั้นตรง ๆ

ลองกรณีที่ง่ายที่สุด:

  • มี factor $m=40$ ตัว ข้อมูล $T=126$ วัน
  • covariance จริงคือ $\mathbf I$ คือทุก factor ผันผวนเท่ากันและไม่เกี่ยวกันเลย eigenvalue จริงทุกตัวจึงเท่ากับ 1 ทุกทิศเสี่ยงเท่ากันหมด

ผลของ Marchenko และ Pastur (1967) บอกว่า เมื่อ $m$ กับ $T$ ใหญ่ทั้งคู่โดยอัตราส่วน $q=m/T$ คงที่ eigenvalue ของ sample covariance จะกระจายอยู่ระหว่างสองขอบนี้

\[ \begin{aligned} q&=\frac mT=\frac{40}{126}=0.3175,\\ \sqrt q&=0.5634,\\ \lambda_{\min}&\approx(1-\sqrt q)^2=0.4366^2=0.1906,\\ \lambda_{\max}&\approx(1+\sqrt q)^2=1.5634^2=2.4443,\\ \frac{\lambda_{\max}}{\lambda_{\min}}&=\frac{2.4443}{0.1906}=12.83,\\ \frac1{\sqrt{0.1906}}&=2.29. \end{aligned} \]

ความจริงแบนราบ ทุกทิศเสี่ยงเท่ากัน condition number (eigenvalue ใหญ่สุดหารด้วยเล็กสุด) จึงเท่ากับ 1 แต่ข้อมูลครึ่งปีทำให้มันดูเหมือน 12.83 ทั้งที่ไม่มีโครงสร้างอะไรอยู่เลย eigenvalue ตัวใหญ่ถูกดันขึ้น ตัวเล็กถูกกดลง ล้วนเป็นผลของข้อมูลไม่พอ สูตรนี้เป็นค่าเมื่อ $m$ ใหญ่มาก โค้ดท้ายหน้าจึงลองจำลองข้อมูลครึ่งปีแบบนี้ 40 รอบ ได้ eigenvalue เล็กสุดเฉลี่ย 0.2175 และใหญ่สุดเฉลี่ย 2.3235 ใกล้ขอบของสูตร ที่ต่างกันนิดหน่อยเพราะ 40 factor ยังไม่มากพอให้ขอบคม

ราคาที่ต้องจ่ายบนโต๊ะอยู่ที่ทิศเล็กสุด optimizer ชอบทิศที่แบบจำลองบอกว่าเสี่ยงน้อย พอร์ตตาม eigenvector ของ 0.1906 ถูกบอกว่าผันผวน $\sqrt{0.1906}=0.437$ ทั้งที่ความจริงคือ 1 ความเสี่ยงจริงจึงสูงกว่าที่เห็น $1/0.437=2.29$ เท่า และพอร์ตที่ optimizer เลือกจะเอียงไปหาทิศแบบนี้พอดี นี่คือเรื่องเดียวกับที่ทำให้ต้องใช้ Ledoit–Wolf shrinkage กับ covariance ของหุ้น

ถ้าแบบจำลองเล็กและข้อมูลยาว ปัญหาจะเบาลงมาก เช่น 10 factor กับ 251 วัน ได้ $q=10/251=0.0398$ ขอบแคบลงเหลือ 0.6406 ถึง 1.4390 (โจทย์ข้อ 2 ท้ายหน้าคิดให้ดู) ปัญหานี้จึงเป็นเรื่องของแบบจำลองใหญ่ที่ใช้ข้อมูลสั้น

ขั้นที่ 5 — ดึงเข้าหาเป้า: eigenvalue ขยับเข้าหาค่าเฉลี่ย

เมื่อ eigenvalue กระจายเกินจริง ทางแก้ที่ตรงที่สุดคือดึงมันกลับเข้าหากัน วิธีที่ใช้กันคือผสม covariance ที่หัก $\mathbf G$ แล้ว (เรียกว่า $\mathbf S$) กับเป้าที่เรียบง่าย คือ matrix แนวทแยงที่ทุกช่องบนแนวทแยงเท่ากับค่าเฉลี่ยของ eigenvalue $\bar\lambda$ สัดส่วนที่ผสมเข้าไปเรียกว่า $\delta$ (0 คือไม่ดึงเลย 1 คือใช้แต่เป้า) นี่คือ shrinkage แบบ Ledoit–Wolf

คำถามคือการผสมนี้ทำอะไรกับ eigenvalue วิธีดูคือเอา matrix ที่ผสมแล้วไปคูณ eigenvector $\mathbf e$ ของ $\mathbf S$ ที่มี eigenvalue $\lambda$ แล้วดูว่าได้อะไรกลับมา

\[ \begin{aligned} \mathbf S&=\hat{\boldsymbol\Sigma}-\mathbf G,\quad\bar\lambda=\tfrac1m\operatorname{trace}\mathbf S,\\ \boldsymbol\Omega(\delta)&=(1-\delta)\mathbf S+\delta\bar\lambda\mathbf I,\\ \boldsymbol\Omega(\delta)\mathbf e&=(1-\delta)\lambda\mathbf e+\delta\bar\lambda\mathbf e,\\ \lambda(\delta)&=(1-\delta)\lambda+\delta\bar\lambda,\\ \delta=0.2&:\ 0.8(0.1906)+0.2=0.3525,\\ &\quad\ 0.8(2.4443)+0.2=2.1555,\\ \tfrac{2.1555}{0.3525}&=6.12,\quad\tfrac1{\sqrt{0.3525}}=1.68. \end{aligned} \]

จังหวะสำคัญอยู่ที่เป้า $\bar\lambda\mathbf I$ เพราะ $\mathbf I$ คูณ vector ไหนก็ได้ vector ตัวเดิม $\mathbf e$ จึงยังเป็น eigenvector ของ matrix ที่ผสมแล้ว ทิศไม่เปลี่ยนเลย สิ่งที่เปลี่ยนมีแค่ eigenvalue ซึ่งถูกลากเข้าหา $\bar\lambda$ เป็นเส้นตรง ตัวเล็กขยับขึ้น ตัวใหญ่ขยับลง condition number จึงหดลงเสมอ ส่วน trace (ผลรวมของ eigenvalue) ไม่เปลี่ยน ความเสี่ยงรวมโดยเฉลี่ยจึงเท่าเดิม

ตัวเลขใช้ขอบจากขั้นที่ 4 กับ $\bar\lambda=1$ (ค่าเฉลี่ยของ eigenvalue เมื่อความจริงคือ $\mathbf I$) ที่ $\delta=0.2$ condition number ตกจาก 12.83 เหลือ 6.12 และทิศที่แย่ที่สุดถูกประเมินต่ำเหลือ 1.68 เท่า แทน 2.29 เท่า ถ้าดึงแรงขึ้นเป็น $\delta=0.5$

\[\begin{aligned}\lambda_{\min}&=0.5(0.1906)+0.5=0.5953,\\\lambda_{\max}&=0.5(2.4443)+0.5=1.7222,\\\tfrac{1.7222}{0.5953}&=2.89.\end{aligned}\]

ราคาที่ต้องจ่ายคือความเอน ถ้าความจริงไม่แบน เช่น market ผันผวน 1.0% แต่ momentum แค่ 0.35% การลากทุกอย่างเข้าหาค่าเฉลี่ยจะลบความต่างที่มีจริงทิ้งไปด้วย $\delta$ ที่ดีที่สุดจึงขึ้นกับว่าความจริงห่างจากเป้าแค่ไหน สูตรของ Ledoit และ Wolf ประมาณ $\delta$ จากข้อมูลเอง และคนทำงานมักยอมดึงแรงกว่านั้นเพื่อแลกกับ matrix ที่นิ่ง ลำดับที่ถูกคือหัก $\mathbf G$ ก่อน แล้วค่อยดึงเข้าหาเป้า เพราะเป้า $\bar\lambda$ ควรคิดจากตัวเลขที่ล้างเสียงของพอร์ตออกแล้ว

ขั้นที่ 6 — ค่าเฉลี่ยที่ลืมอดีตมีข้อมูลเท่าไร

ปัญหาที่สามคือจะลืมอดีตเร็วแค่ไหน EWMA ให้น้ำหนักวันนี้มากที่สุด แล้วหดน้ำหนักลงทีละนิดตามอายุของข้อมูล ถ้าหดเร็ว ตัวเลขตามตลาดทัน แต่ใช้ข้อมูลน้อยจึงแกว่ง ถ้าหดช้า ตัวเลขนิ่ง แต่เล่าเรื่องเก่า จะเลือกให้ดีต้องวัดสองอย่างเป็นตัวเลข

  • ของที่ได้: ค่าเฉลี่ยแบบนี้มีข้อมูลเท่ากับค่าเฉลี่ยธรรมดากี่วัน (effective sample size $N_{\rm eff}$)
  • ราคาที่จ่าย: ข้อมูลที่ใช้มีอายุเฉลี่ยกี่วัน ($\bar s$)

ให้ $y_s$ คือข้อมูลของวันที่มีอายุ $s=0,1,2,\ldots$ วัน (0 คือวันนี้) สมมติว่าแต่ละวันเป็นอิสระกันและมี variance เท่ากัน น้ำหนักของวันที่อายุ $s$ คือ $w_s$ และตัวคูณการลืมต่อวันคือ $\lambda$ (น้ำหนักหดลงเหลือ $\lambda$ เท่าทุกครั้งที่อายุเพิ่มหนึ่งวัน) ตัวคูณ $(1-\lambda)$ ข้างหน้ามีไว้ให้น้ำหนักทุกวันรวมกันได้ 1 ระวังว่า $\lambda$ ตรงนี้คนละตัวกับ eigenvalue ในขั้นที่ 4–5 ที่ใช้ตัวอักษรเดียวกันเพราะเป็นชื่อที่ใช้กันทั่วไปของ EWMA

\[ \begin{aligned} w_s&=(1-\lambda)\lambda^s,\quad \lambda^h=\tfrac12,\\ \operatorname{var}\Big(\textstyle\sum_s w_sy_s\Big)&=\operatorname{var}(y)\textstyle\sum_s w_s^2,\\ \textstyle\sum_s w_s^2&=\frac{(1-\lambda)^2}{1-\lambda^2}=\frac{1-\lambda}{1+\lambda},\\ N_{\rm eff}&=\frac{1+\lambda}{1-\lambda},\\ \bar s&=\textstyle\sum_s s\,w_s=\frac{\lambda}{1-\lambda}. \end{aligned} \]

ความคิดหลักคือ ความแม่นของค่าเฉลี่ยถ่วงขึ้นกับผลรวมของน้ำหนักยกกำลังสอง $\sum_s w_s^2$ เพราะข้อมูลแต่ละวันเป็นอิสระกัน พจน์ไขว้จึงเป็นศูนย์ เหลือแค่ $w_s^2\operatorname{var}(y)$ ของแต่ละวันบวกกัน ผลรวม $\sum_s w_s^2$ เป็นอนุกรมเรขาคณิตที่อัตราส่วน $\lambda^2$ แล้วแยก $1-\lambda^2=(1-\lambda)(1+\lambda)$ ตัว $(1-\lambda)$ ตัดกันหนึ่งตัว

ต่อมาเทียบกับค่าเฉลี่ยธรรมดาของ $N$ ตัว ซึ่งทุกตัวได้น้ำหนัก $1/N$ จึงมี $\sum w^2=N\times(1/N)^2=1/N$ ตั้งให้ $1/N=(1-\lambda)/(1+\lambda)$ แล้วแก้หา $N$ ก็ได้ $N_{\rm eff}$ แปลว่า EWMA แกว่งเท่ากับค่าเฉลี่ยธรรมดาของ $N_{\rm eff}$ วัน ส่วนอายุเฉลี่ย $\bar s$ ได้จากอนุกรม $\sum_s s\lambda^s=\lambda/(1-\lambda)^2$ คูณด้วย $(1-\lambda)$ ค่า $\lambda$ เองได้จากนิยามของ half-life $h$: น้ำหนักที่อายุ $h$ วันเหลือครึ่งของวันนี้ $\lambda^h=\tfrac12$ จึงได้ $\lambda=0.5^{1/h}$

สองสูตรนี้ดึงกันคนละทาง $\lambda$ ใกล้ 1 (half-life ยาว) ทำให้ $N_{\rm eff}$ ใหญ่ ข้อมูลเยอะ แต่ $\bar s$ ก็ใหญ่ ข้อมูลเก่า half-life สั้นตามตลาดทัน แต่ข้อมูลน้อย ไม่มีค่าไหนดีกับทุกอย่าง

ขั้นที่ 7 — ความผันผวนเร็ว correlation ช้า: คิดเป็นตัวเลข

สูตรของขั้นที่ 6 พร้อมแล้ว ขั้นนี้ใช้มันตอบคำถามจริง: ความผันผวนกับ correlation ควรใช้ half-life เดียวกันไหม ทางที่ทำได้คือแยก factor covariance เป็นสองชิ้น แล้วให้แต่ละชิ้นมี EWMA ของตัวเอง

โจทย์ให้อะไรมาบ้าง:

  • แยก $\boldsymbol\Omega_f=\mathbf V\mathbf C\mathbf V$ โดย $\mathbf V$ คือ matrix แนวทแยงที่มีความผันผวนของแต่ละ factor และ $\mathbf C$ คือ correlation matrix
  • ความผันผวนใช้ half-life $h=63$ วัน หรือราวสามเดือน ($252/4=63$ วันทำการ)
  • correlation ใช้ half-life $h=500$ วัน หรือราวสองปี ($500/252=1.98$ ปี) ช่วงสามเดือนถึงสองปีนี้คือช่วงที่แบบจำลองหุ้นรายวันใช้กัน
  • correlation จริงของคู่ factor ที่ใช้ทดลองคือ $\rho=0.30$ (สมมติ) ถ้าข้อมูลเป็น Normal ค่า correlation ที่วัดจากข้อมูล $N$ ตัวคลาดประมาณ $(1-\rho^2)/\sqrt N$ โดย $1-0.30^2=0.91$
  • ความผันผวนที่วัดจากข้อมูล $N$ ตัวคลาดประมาณ $1/\sqrt{2N}$ เท่าของตัวมันเอง เหตุผล: ขั้นที่ 3 ได้ว่า variance คลาด $\sqrt{2/N}$ และความผันผวนเป็นรากที่สองของ variance จึงคลาดครึ่งหนึ่ง $\tfrac12\sqrt{2/N}=1/\sqrt{2N}$

แทน $\lambda=0.5^{1/h}$ ลงในสูตร $N_{\rm eff}=\frac{1+\lambda}{1-\lambda}$ และ $\bar s=\frac{\lambda}{1-\lambda}$ ของขั้นที่ 6 แล้วใช้ $N_{\rm eff}$ แทน $N$ ในสูตรความคลาด

\[ \begin{aligned} h=63&:\ \lambda=0.5^{1/63}=0.98906,\\ &\quad N_{\rm eff}=\tfrac{1.98906}{0.01094}=181.8,\\ &\quad \bar s=\tfrac{0.98906}{0.01094}=90.4,\\ h=500&:\ \lambda=0.5^{1/500}=0.998615,\\ &\quad N_{\rm eff}=\tfrac{1.998615}{0.001385}=1{,}443,\\ &\quad \bar s=\tfrac{0.998615}{0.001385}=721,\\ \text{vol}&:\ \tfrac1{\sqrt{2(181.8)}}=\tfrac1{19.07}=5.24\%,\\ \rho&:\ \tfrac{0.91}{\sqrt{181.8}}=\tfrac{0.91}{13.48}=0.0675,\\ &\quad\tfrac{0.91}{\sqrt{1{,}443}}=\tfrac{0.91}{37.99}=0.0240. \end{aligned} \]

คำตอบ: ที่ half-life 63 วัน ความผันผวนคลาดแค่ 5.24% ของตัวมันเอง ใช้ได้สบาย แต่ correlation 0.30 คลาด ±0.0675 หรือ $0.0675/0.30=22.5\%$ ของตัวมันเอง เกือบหนึ่งในสี่ correlation จึงต้องการข้อมูลมากกว่า

ที่ half-life 500 วัน correlation คลาดเหลือ ±0.0240 แต่ข้อมูลที่ใช้มีอายุเฉลี่ย 721 วัน หรือเกือบสามปี ถ้าใช้ half-life นี้กับความผันผวนด้วย ตัวเลขความเสี่ยงจะเล่าเรื่องของตลาดเมื่อหลายปีก่อน ข้อสรุปคือ half-life ของ correlation ต้องยาวกว่าของความผันผวน

ตรวจเองใน 10 วินาที: เมื่อ $h$ ใหญ่ $1-\lambda\approx\ln2/h$ และ $1+\lambda\approx2$ จึงได้ทางลัด $N_{\rm eff}\approx2h/\ln2=2(63)/0.6931=181.8$ ตรงกับค่าในสูตร

ยังมีรายละเอียดหนึ่งในการวัด correlation: ต้องหาร factor return ของแต่ละวันด้วยความผันผวนของวันนั้นก่อน (คือใช้ $\mathbf V_t^{-1}\hat{\mathbf f}_t$) แล้วค่อยเฉลี่ยผลคูณ ถ้าไม่หาร วันที่ factor ตัวหนึ่งแกว่งแรงจะครองค่าเฉลี่ย ลองดูตัวอย่างสมมติ

  • factor สองตัวมี correlation จริง $0.30$ ทุกวัน ไม่เปลี่ยนเลย
  • factor ตัวแรกมีความผันผวน 1 ในครึ่งหนึ่งของวัน และ 3 ในอีกครึ่ง
  • factor ตัวที่สองมีความผันผวน 1 ทุกวัน

ค่าเฉลี่ยของผลคูณคือครึ่งหนึ่งของ covariance ในแต่ละช่วงบวกกัน ($\operatorname{cov}=\rho\sigma_1\sigma_2$) ทำแบบเดียวกันกับกำลังสอง แล้วหารแบบ correlation

\[\begin{aligned}\overline{x_1x_2}&=\tfrac12(0.30\cdot1\cdot1)+\tfrac12(0.30\cdot3\cdot1)\\&=0.15+0.45=0.60,\\\overline{x_1^2}&=\tfrac12(1+9)=5,\quad\overline{x_2^2}=1,\\\hat\rho&=\frac{0.60}{\sqrt{5\times1}}=0.2683.\end{aligned}\]

ได้ 0.2683 ต่ำกว่าความจริง 0.30 ทั้งที่ correlation ไม่ได้เปลี่ยนเลย เหตุผลคือช่วงที่แกว่งแรงดัน covariance ขึ้น 3 เท่า แต่ดัน variance ของตัวแรกขึ้น $3^2=9$ เท่า ตัวหารจึงโตเร็วกว่าตัวตั้ง ถ้าหารด้วยความผันผวนของแต่ละวันก่อน ทุกวันจะมีความผันผวน 1 เท่ากัน และได้ 0.30 พอดี

ขั้นที่ 8 — ความจำเล็ก ๆ ที่ทำให้ความเสี่ยงระยะยาวต่ำเกินจริง

ปัญหาสุดท้ายเกิดตอนแปลงความเสี่ยงรายวันเป็นความเสี่ยงระยะยาว ผู้จัดการกองทุนมักถือพอร์ตเป็นสัปดาห์หรือเป็นเดือน และรายงานความเสี่ยงเป็นรายปี วิธีที่ใช้กันคือคูณความผันผวนรายวันด้วย $\sqrt T$ เมื่อ $T$ คือจำนวนวัน วิธีนี้ถูกก็ต่อเมื่อแต่ละวันไม่เกี่ยวกันเลย เพราะเมื่อนั้น variance ของผลรวม $T$ วันเท่ากับ $T$ เท่าของ variance รายวัน

แต่ factor return รายวันมักมี autocorrelation เล็ก ๆ ที่ไม่เป็นศูนย์ คือวันนี้ขึ้น พรุ่งนี้มีแนวโน้มขึ้นตามอีกนิด หน้านี้ใช้แบบจำลอง AR(1) คือ $x_t=\phi x_{t-1}+u_t$ ที่ $\phi=0.12$ (ค่าสมมติ) โดย $x_t$ คือ factor return ของวันที่ $t$ และ $u_t$ คือส่วนใหม่ที่สุ่มขึ้นในวันนั้น ในแบบจำลองนี้ autocovariance ที่ lag $l$ คือ $\gamma_l=\phi^l\gamma_0$ เมื่อ $\gamma_0$ คือ variance รายวัน คำถามคือ variance ของผลรวม $T$ วันเป็นเท่าไร วิธีคือกางผลรวมออกแล้วนับพจน์ไขว้

\[ \begin{aligned} S_T&=x_1+x_2+\cdots+x_T,\\ \operatorname{var}(S_T)&=T\gamma_0\\ &\quad+2\textstyle\sum_{l=1}^{T-1}(T-l)\gamma_l,\\ \gamma_l&=\phi^l\gamma_0,\\ \frac{\operatorname{var}(S_T)}{T\gamma_0}&\to1+\frac{2\phi}{1-\phi}\\ &=\frac{1+\phi}{1-\phi}=\frac{1.12}{0.88}\\ &=1.2727,\\ \sqrt{1.2727}&=1.1282. \end{aligned} \]

ภาพที่ช่วยได้คือตาราง $T\times T$ ที่ช่อง $(i,j)$ คือ $\operatorname{cov}(x_i,x_j)$ variance ของผลรวมคือผลรวมของทุกช่องในตาราง แนวทแยงมี $T$ ช่อง ช่องละ $\gamma_0$ ส่วนคู่วันที่ห่างกัน $l$ วันมีอยู่ $T-l$ คู่ และแต่ละคู่โผล่สองครั้ง (เหนือและใต้แนวทแยง) จึงได้ $2(T-l)\gamma_l$ การคูณ $\sqrt T$ ตรง ๆ คือการทิ้งช่องนอกแนวทแยงทั้งหมด

จังหวะที่เหลือคือหารด้วย $T\gamma_0$ แล้วให้ $T$ โต น้ำหนัก $(T-l)/T=1-l/T$ เข้าใกล้ 1 จึงเหลืออนุกรมเรขาคณิต $2\sum_{l\ge1}\phi^l=2\phi/(1-\phi)=0.24/0.88=0.2727$ ถ้าใช้ $T=251$ พอดี โดยไม่ให้ $T$ โต จะได้ 1.2715 (โค้ดท้ายหน้าคิดให้) แทบเท่ากับ 1.2727 หน้านี้จึงใช้ค่าเพดาน 1.2727

autocorrelation แค่ 0.12 ซึ่งหลายคนปัดทิ้ง ทำให้ความผันผวนรายปีจริงเป็น 1.1282 เท่าของการคูณ $\sqrt{251}$ ตรง ๆ คือสูงกว่า 12.82% กองทุนที่ตั้งเป้าความเสี่ยงไว้ 10% ต่อปีจะวิ่งจริงที่ $10\%\times1.1282=11.28\%$ พูดอีกทางคือ ตัวเลขที่รายงานต่ำกว่าความจริง $1-1/1.1282=11.36\%$ ถ้า $\phi$ ติดลบ ทุกอย่างกลับทิศ ความเสี่ยงระยะยาวจะถูกรายงานสูงเกินจริงแทน

ขั้นที่ 9 — Newey–West: เติม lag กลับเข้าไป

ขั้นที่ 8 บอกว่าการคูณ $\sqrt T$ ทิ้งช่องนอกแนวทแยงไป ทางแก้จึงเป็นการเติมช่องเหล่านั้นกลับเข้าไปใน covariance ตั้งแต่ต้น ของที่ต้องใช้คือ autocovariance ที่วัดจากข้อมูล

\[\mathbf C_l=\tfrac1T\textstyle\sum_t\hat{\mathbf f}_t\hat{\mathbf f}_{t-l}^{\mathsf T},\]

คือค่าเฉลี่ยของ factor return วันนี้คูณกับของ $l$ วันก่อน ($\mathbf C_0$ คือ covariance ธรรมดา) Newey–West (1987) บวก $\mathbf C_l$ เข้าไป $L$ lag ถ่วงด้วยน้ำหนัก $k_l$ ที่ลดลงเป็นเส้นตรง ทำไมต้องลดลง ไม่ใช้น้ำหนัก 1 ทุก lag: น้ำหนักแบบนี้รับประกันว่าผลลัพธ์ไม่มีทิศไหนที่ variance ติดลบ

วิธีนี้ได้คืนมากแค่ไหน ลองกับ AR(1) ของขั้นที่ 8 ซึ่งรู้คำตอบอยู่แล้ว ข้อมูล $T$ วันมีคู่ที่ห่างกัน $l$ วันแค่ $T-l$ คู่ แต่หารด้วย $T$ ค่าคาดหมายของ $\mathbf C_l$ จึงเป็น $(1-l/T)\gamma_l$

\[ \begin{aligned} \hat{\boldsymbol\Omega}_L&=\mathbf C_0+\textstyle\sum_{l=1}^{L}k_l\mathbf D_l,\\ \mathbf D_l&=\mathbf C_l+\mathbf C_l^{\mathsf T},\\ k_l&=1-\frac{l}{L+1},\\ R_L&=\tfrac{1-\phi}{1+\phi}\big(1+2A_L\big),\\ A_L&=\textstyle\sum_{l=1}^{L}k_l\big(1-\tfrac lT\big)\phi^l,\\ R_0,\ R_1&=78.57,\ 87.96\%,\\ R_2,\ R_5&=91.84,\ 95.87\%,\\ R_{10}&=97.70\%. \end{aligned} \]

$R_L$ คือสัดส่วนที่ Newey–West จับได้: ค่าคาดหมายของ $\hat\Omega_L$ หารด้วย long-run variance ที่ต้องการจริง $\Omega_{\rm long}=\gamma_0(1+\phi)/(1-\phi)$ จากขั้นที่ 8 ได้มาจากการแทน $\mathrm E[\mathbf C_l]=(1-l/T)\phi^l\gamma_0$ ลงในสูตรของ $\hat{\boldsymbol\Omega}_L$ แล้วหาร ตัวอย่างที่ $L=1$ น้ำหนักคือ $k_1=1-\tfrac12=\tfrac12$

\[\begin{aligned}A_1&=0.5\big(1-\tfrac1{251}\big)(0.12)=0.05976,\\R_1&=\tfrac{0.88}{1.12}(1+2\times0.05976)\\&=0.7857\times1.1195=0.8796.\end{aligned}\]

$L$ อื่นทำแบบเดียวกัน (โค้ดท้ายหน้าคิดซ้ำ) ถ้าไม่เติม lag เลย ($L=0$) ได้แค่ $0.88/1.12=78.57\%$ variance ระยะยาวหายไป $100-78.57=21.43\%$ ราวหนึ่งในห้า เติมห้า lag ได้คืนเป็น 95.87% หลังจากนั้นได้คืนช้าลงมาก เพราะ $\phi^l$ หดเร็ว ($0.12^5=0.000025$) และน้ำหนัก $k_l$ ก็กด lag ไกล ๆ ไว้ ลองแทน $\phi=0$ ทุก $L$ ให้ 100% พอดี การแก้นี้จึงไม่ทำร้ายข้อมูลที่ไม่มีความจำ

ความผิดที่ให้ตัวเลขผิดแบบเงียบ ๆ

หัก $\mathbf G$ อย่างเดียว แล้วได้ variance ติดลบ ลองกับ factor ที่ผันผวนจริงแค่ 0.05% ต่อวัน (สมมติ) variance จริงของมันคือ $0.05^2=0.0025$ เล็กกว่า $G=0.013907$ ของจักรวาล 600 ตัว ในปีที่โชคไม่ดี ค่าที่วัดได้อาจต่ำกว่าค่าเฉลี่ยของมันไปสองเท่าของความคลาดปกติ คือต่ำไป $2\times8.93\%$ (ความคลาดปกติของข้อมูลปีเดียวจากขั้นที่ 3)

\[\begin{aligned}\mathrm E[\hat\sigma^2]&=0.0025+0.013907=0.016407,\\\hat\sigma^2&=0.016407(1-2\times0.0893)\\&=0.016407\times0.8214=0.013477,\\\hat\sigma^2-G&=0.013477-0.013907=-0.00043.\end{aligned}\]

variance ติดลบเป็นไปไม่ได้ ถอดรากก็ไม่ได้ และทำให้ optimizer พัง ทางที่ถูกคือหัก $\mathbf G$ แล้วดึงเข้าหาเป้าในขั้นเดียวกัน การดึงจะยก eigenvalue ที่เล็กเกินไปให้กลับมาเป็นบวก

ใช้ half-life เดียวกันกับทุกอย่าง ถ้าสั้นทั้งคู่ ($h=63$) correlation 0.30 จะแกว่ง ±0.0675 ไปตามข่าวรายสัปดาห์ ถ้ายาวทั้งคู่ ($h=500$) ความผันผวนจะใช้ข้อมูลที่อายุเฉลี่ย 721 วัน และตามวิกฤตไม่ทัน ซึ่งเป็นตอนที่ต้องการตัวเลขแม่นที่สุด

เฉลี่ยผลคูณโดยไม่หารด้วยความผันผวนของวันนั้น correlation 0.30 ที่ไม่เปลี่ยนเลยถูกวัดเป็น $0.60/\sqrt5=0.2683$ (ตัวอย่างในขั้นที่ 7) เพียงเพราะครึ่งหนึ่งของวัน factor ตัวหนึ่งแกว่งแรงขึ้นสามเท่า

คูณ $\sqrt{251}$ โดยไม่ดู autocorrelation ที่ $\phi=0.12$ ความผันผวนรายปีจริงคือ $1.1282$ เท่าของตัวเลขที่รายงาน กองทุนที่ตั้งเพดานความเสี่ยง 10% ต่อปี จึงวิ่งจริงที่ $10\%\times1.1282=11.28\%$ โดยไม่มีรายงานไหนเตือน

  1. หา factor return ของวันนั้น $\hat{\mathbf f}_t$ ด้วย cross-sectional regression และเก็บ $\mathbf G$ ของวันนั้นไว้
  2. อัปเดตความผันผวนของแต่ละ factor ด้วย half-life สั้น (เช่น 63 วัน)
  3. หาร factor return ด้วยความผันผวนของวันนั้น แล้วอัปเดต correlation ด้วย half-life ยาว (เช่น 500 วัน)
  4. เติม lag แบบ Newey–West
  5. หัก $\mathbf G$ แล้วดึงเข้าหาเป้า ก่อนส่งให้ optimizer

ตัวเลขที่ควรเฝ้าดูทุกวันคือ condition number ถ้ามันพุ่งขึ้น แปลว่ามีทิศที่แบบจำลองเชื่อว่าเสี่ยงน้อยเกินจริง และ optimizer กำลังจะเอียงพอร์ตไปทางนั้น

แบบจำลองที่รวมหุ้นหลายประเทศเจอ autocorrelation หนักกว่านี้ เพราะตลาดแต่ละแห่งปิดคนละเวลา ข่าวที่ตลาดหนึ่งเห็นวันนี้ อีกตลาดจะเห็นในวันถัดไป ผลตอบแทนของวันติดกันจึงเกี่ยวกันมากขึ้น Newey–West จึงเป็นเครื่องมือมาตรฐานของแบบจำลองแบบนี้ด้วย

โจทย์ตรวจความเข้าใจ

1. ทีมความเสี่ยงขยายแบบจำลองไปใช้กับตลาดที่ใหญ่ขึ้น จักรวาลมีหุ้น 8,000 ตัว สมมติแบบเดิมว่าเป็นหุ้นแปดตัวในขั้นที่ 2 ซ้ำกัน 1,000 ชุด ความผันผวนจริงของ momentum ยังเป็น 0.35% ต่อวัน variance ของ momentum ที่วัดได้จะเกินจริงกี่เปอร์เซ็นต์ และความผันผวนเกินกี่เปอร์เซ็นต์?

เฉลย

ใช้ผลรวม $1.0430$ จากขั้นที่ 2 แต่หารด้วย 1,000 ชุดแทน 75 แล้วเทียบกับ variance จริง $0.35^2=0.1225$

\[\begin{aligned}G&=\frac{1.0430}{1{,}000}=0.001043,\\1+\frac{0.001043}{0.1225}&=1.0085,\\\sqrt{1.0085}&=1.0042.\end{aligned}\]

variance เกินจริง 0.85% ความผันผวนเกิน 0.42% จักรวาลใหญ่ขึ้น $8{,}000/600=13.33$ เท่า ความเอนจึงหดลงเท่ากัน $11.35/13.33=0.85\%$ ตลาดที่มีหุ้นมากจึงให้ covariance ที่สะอาดกว่า

2. อีกทีมใช้แบบจำลองเล็ก มี factor $m=10$ ตัว และใช้ข้อมูล $T=251$ วัน ถ้า covariance จริงคือ $\mathbf I$ (eigenvalue จริงทุกตัวเท่ากับ 1) eigenvalue ที่วัดได้จะกระจายอยู่ระหว่างเท่าไร และ condition number ราวเท่าไร?

เฉลย

ใช้สูตร Marchenko–Pastur จากขั้นที่ 4

\[\begin{aligned}q&=10/251=0.0398,\quad\sqrt q=0.1996,\\\lambda_{\min}&\approx(1-0.1996)^2=0.6406,\\\lambda_{\max}&\approx(1+0.1996)^2=1.4390,\\\tfrac{1.4390}{0.6406}&=2.25.\end{aligned}\]

condition number 2.25 ต่างจาก 12.83 ของ 40 factor กับ 126 วันมาก shrinkage จึงสำคัญน้อยกว่าในแบบจำลองเล็กที่ใช้ข้อมูลยาว

3. factor ตัวหนึ่งมักกลับทิศในวันถัดไปเล็กน้อย autocorrelation รายวันของมันคือ $\phi=-0.05$ ถ้าทีมแปลงความผันผวนรายวันเป็นรายปีด้วยการคูณ $\sqrt{251}$ ตัวเลขรายปีจะผิดไปทางไหน และกี่เปอร์เซ็นต์?

เฉลย

ใช้อัตราส่วน $(1+\phi)/(1-\phi)$ จากขั้นที่ 8 แทน $\phi=-0.05$

\[\begin{aligned}\frac{1+\phi}{1-\phi}&=\frac{0.95}{1.05}=0.9048,\\\sqrt{0.9048}&=0.9512,\\\tfrac1{0.9512}-1&=5.13\%.\end{aligned}\]

ความผันผวนรายปีจริงเป็นแค่ 0.9512 เท่าของการคูณตรง ๆ การคูณตรง ๆ จึงรายงานสูงเกินจริง 5.13% ทิศของความผิดตามเครื่องหมายของ $\phi$ เสมอ

function inverse(A) {                                   // Gauss-Jordan with partial pivoting
  const n = A.length, M = A.map((row, i) => [...row, ...row.map((_, j) => (i === j ? 1 : 0))]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let i = c + 1; i < n; i++) if (abs(M[i][c]) > abs(M[p][c])) p = i;
    if (abs(M[p][c]) < 1e-12) throw new RangeError('matrix is singular');
    [M[c], M[p]] = [M[p], M[c]];
    const v = M[c][c];
    for (let j = 0; j < 2 * n; j++) M[c][j] /= v;
    for (let i = 0; i < n; i++) if (i !== c) { const g = M[i][c]; for (let j = 0; j < 2 * n; j++) M[i][j] -= g * M[c][j]; }
  }
  return M.map(row => row.slice(n));
}
// Noise of the factor-mimicking portfolios: WLS with cap-weighted industries summing to zero.
// The top-left block P of the bordered inverse gives H = P B'W and G = H Omega_eps H' = P.
function factorMimicking(B, sigma, c) {
  const BW = T(B).map(row => row.map((x, i) => x / (sigma[i] * sigma[i])));
  const K = mul(BW, B).map((row, i) => [...row, c[i]]);
  K.push([...c, 0]);
  const P = inverse(K).slice(0, c.length).map(row => row.slice(0, c.length));
  return {H: mul(P, BW), G: P};
}

function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}
function normals(rnd) {
  let spare = null;
  return () => {
    if (spare !== null) { const s = spare; spare = null; return s; }
    let u = 0;
    while (u === 0) u = rnd();
    const v = rnd(), R = sqrt(-2 * log(u));
    spare = R * sin(2 * PI * v);
    return R * cos(2 * PI * v);
  };
}
function eigenvalues(S) {                               // cyclic Jacobi rotations, sorted
  const n = S.length, A = S.map(row => [...row]);
  for (let sweep = 0; sweep < 100; sweep++) {
    let off = 0;
    for (let i = 0; i < n; i++) for (let j = i + 1; j < n; j++) off += A[i][j] * A[i][j];
    if (off < 1e-26) break;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) {
      if (A[p][q] === 0) continue;
      const theta = (A[q][q] - A[p][p]) / (2 * A[p][q]);
      const t = (theta >= 0 ? 1 : -1) / (abs(theta) + sqrt(theta * theta + 1)), c = 1 / sqrt(t * t + 1), s = t * c;
      for (let k = 0; k < n; k++) { const akp = A[k][p], akq = A[k][q]; A[k][p] = c * akp - s * akq; A[k][q] = s * akp + c * akq; }
      for (let k = 0; k < n; k++) { const apk = A[p][k], aqk = A[q][k]; A[p][k] = c * apk - s * aqk; A[q][k] = s * apk + c * aqk; }
    }
  }
  return A.map((row, i) => row[i]).sort((a, b) => a - b);
}

สิ่งที่ควรตอบได้หลังอ่าน

  • factor return ที่วัดได้คือค่าจริงบวกเสียงของพอร์ต $\hat{\mathbf f}_t=\mathbf f_t+\mathbf H\boldsymbol\epsilon_t$ covariance ที่วัดได้จึงเท่ากับ $\boldsymbol\Omega_f+\mathbf G$ เสมอ โดย $\mathbf G$ คือ variance เฉพาะตัวของ factor-mimicking portfolio ต้องหักออก
  • ในจักรวาล 600 ตัว variance ของ momentum เกินจริง 11.35% แต่ของ market เกินแค่ 0.70% เพราะ $G$ ถูกหารด้วย variance ของ factor เอง ความเอนนี้ใหญ่กว่าความแกว่งปกติ 8.93% ของข้อมูลปีเดียวแค่ 1.27 เท่า จึงต้องหักด้วยสูตร จะรอให้เห็นในข้อมูลไม่ได้
  • 40 factor กับข้อมูล 126 วันทำให้ eigenvalue ที่ความจริงเป็น 1 ทุกตัว กระจายเป็น 0.19 ถึง 2.44 ทิศที่ดูปลอดภัยที่สุดเสี่ยงจริง 2.29 เท่าของที่เห็น shrinkage ลาก eigenvalue เข้าหาค่าเฉลี่ยเป็นเส้นตรง โดยไม่เปลี่ยน eigenvector
  • EWMA มีข้อมูลเทียบเท่า $N_{\rm eff}=(1+\lambda)/(1-\lambda)$ วัน half-life 63 วันให้ 181.8 วัน ซึ่งพอสำหรับความผันผวน แต่ correlation ต้องการราว 1,443 วัน (half-life 500 วัน) จึงต้องใช้ half-life ต่างกัน และต้องหารด้วยความผันผวนของวันนั้นก่อนเฉลี่ย correlation
  • autocorrelation แค่ 0.12 ทำให้ความเสี่ยงรายปีจริงสูงกว่าการคูณ $\sqrt{251}$ ตรง ๆ 12.82% Newey–West ที่ห้า lag จับ long-run variance ได้ 95.87% แทนที่จะได้แค่ 78.57%
