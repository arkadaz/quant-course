2.4 แบ่งกระแส Poisson: ทำไมสายย่อยจึงเป็นอิสระได้?

ถ้าสุ่มติดป้ายให้เหตุการณ์ใน Poisson process ทีละตัว โดยแต่ละตัวไม่ขึ้นกับตัวอื่น เหตุการณ์ของแต่ละป้ายจะเป็น Poisson process ของตัวเอง และทุกสายอิสระกัน

ตลาดหุ้นรับคำสั่งซื้อขายจากคนจำนวนมาก คำสั่งเข้ามาทีละคำสั่งแบบสุ่ม ไม่มีใครนัดกัน ทีม execution ของบริษัท (ทีมที่ดูแลการส่งคำสั่งซื้อขายให้ได้ราคาดี) เฝ้าดูกระแสคำสั่งนี้ทุกนาที เพราะจำนวนและแบบของคำสั่งบอกว่าคนในตลาดกำลังรีบแค่ไหน

คำสั่งมีสองแบบ แบบแรกเรียกว่า marketable คือคำสั่งที่ยอมรับราคาที่มีคนเสนอไว้แล้ว จึงจับคู่ได้ทันที หน้านี้เรียกว่าแบบ A แบบที่สองเรียกว่า passive คือคำสั่งที่ตั้งราคาของตัวเองไว้ แล้วรอให้คนอื่นมาจับคู่ ระหว่างรอ คำสั่งนี้อยู่ใน order book (รายการคำสั่งที่ยังไม่มีคู่) หน้านี้เรียกว่าแบบ B

ของที่รู้ (แบบจำลองสมมติ):

  • คำสั่งทั้งหมดเข้ามาเฉลี่ย $\lambda=20$ คำสั่งต่อนาที แบบ Poisson process คือเข้ามาทีละคำสั่งแบบสุ่ม และจำนวนคำสั่งในแต่ละนาทีเป็น Poisson ค่าเฉลี่ย 20
  • แต่ละคำสั่งเป็นแบบ A ด้วยโอกาส $p=0.6$ และเป็นแบบ B ด้วยโอกาส $1-p=0.4$
  • แบบของแต่ละคำสั่งไม่ขึ้นกับแบบของคำสั่งอื่น และไม่ขึ้นกับว่านาทีนั้นมีคำสั่งกี่คำสั่ง

ทีมถามสองข้อ ข้อแรก นาทีที่เห็นคำสั่ง A เยอะผิดปกติ ควรคาดว่าคำสั่ง B ในนาทีเดียวกันจะน้อยลงไหม ข้อสอง ถ้ารู้แล้วว่านาทีนี้มีคำสั่งรวม 20 คำสั่งพอดี จำนวน A แกว่งได้แค่ไหน

ลองตอบก่อนเปิดเฉลย

ข้อแรก คำตอบคือไม่ ก่อนรู้ยอดรวม จำนวน A ในหนึ่งนาทีเป็น Poisson ค่าเฉลี่ย $20\times0.6=12$ จำนวน B เป็น Poisson ค่าเฉลี่ย $20\times0.4=8$ และสองจำนวนนี้อิสระกัน (หน้านี้จะพิสูจน์ทีละขั้น) A เยอะจึงไม่บอกอะไรเกี่ยวกับ B เลย

ข้อสอง ให้ $N$ คือจำนวนคำสั่งรวมในนาทีนั้น เมื่อรู้ว่า $N=20$ สิ่งเดียวที่ยังสุ่มคือแบบของ 20 คำสั่งนั้น เหมือนโยนเหรียญ 20 ครั้งที่ออกหัวด้วยโอกาส 0.6 จำนวน A จึงเป็น Binomial(20, 0.6) การแกว่งวัดด้วย variance ซึ่งคือ SD ยกกำลังสอง (SD หรือ standard deviation คือระยะที่ค่ามักห่างจากค่าเฉลี่ย) สูตรของ Binomial ให้

\[\begin{aligned}E[A\mid N=20]&=20\times0.6=12,\\\operatorname{Var}(A\mid N=20)&=20\times0.6\times0.4=4.8.\end{aligned}\]

$E[A\mid N=20]$ อ่านว่า ค่าเฉลี่ยของ A เมื่อรู้ว่า $N=20$ ค่าเฉลี่ยยังเป็น 12 เท่าเดิม แต่ variance เหลือ 4.8 แทนที่จะเป็น 12 (Poisson มี variance เท่ากับค่าเฉลี่ย) SD จึงหดจาก $\sqrt{12}\approx3.46$ เหลือ $\sqrt{4.8}\approx2.19$ คำสั่ง และ B ถูกล็อกเป็น $B=20-A$ ทันที A มากขึ้นหนึ่ง B ต้องน้อยลงหนึ่ง

สองคำตอบไม่ขัดกัน เพราะใช้ข้อมูลคนละชุด ข้อแรกยังไม่รู้ยอดรวม ข้อสองรู้แล้ว

ภาพรวมก่อนลงสูตร

หน้านี้เรียกกระแสคำสั่งทั้งหมดว่า “กระแสแม่” การแยกกระแสแม่ออกเป็นสายย่อยเรียกว่า thinning หรือ splitting วิธีคือโยนเหรียญให้ทุกเหตุการณ์ ออกหัวก็ส่งไปสาย A ออกก้อยก็ส่งไปสาย B รูปด้านล่างคือหนึ่งนาทีสมมติ เส้นบนคือคำสั่งทั้งหมด แต่ละขีดถูกส่งลงไปที่สายของตัวเองตามสี

ผลที่น่าแปลกใจมีสองข้อ ข้อแรก แต่ละสายยังเป็น Poisson process โดยอัตราของสายคืออัตราของกระแสแม่คูณโอกาสของป้าย คือ $20\times0.6=12$ และ $20\times0.4=8$ คำสั่งต่อนาที ข้อสอง สองสายอิสระกันโดยสิ้นเชิง ทั้งที่มาจากกระแสเดียวกัน

ข้อสองขัดกับสามัญสำนึก เพราะ A กับ B แย่งคำสั่งชุดเดียวกัน คำสั่งที่ไปสาย A แล้วจะไปสาย B ไม่ได้ หน้านี้จึงคลายปมทีละขั้น

  • เริ่มจากกรณี “รู้ยอดรวมแล้ว” ในกรณีนี้จำนวน A เป็น Binomial และ A กับ B สวนทางกัน
  • ต่อด้วยกรณี “ยังไม่รู้ยอดรวม” หาค่าเฉลี่ยด้วย tower property ซึ่งบอกว่าค่าเฉลี่ยรวมคือค่าเฉลี่ยของค่าเฉลี่ยในแต่ละกรณี และหา variance ด้วย law of total variance ซึ่งบอกว่า variance รวมมาจากสองส่วน คือการแกว่งภายในแต่ละกรณี กับการที่ค่าเฉลี่ยของแต่ละกรณีต่างกัน
  • พิสูจน์การแจกแจงทั้งก้อนด้วย pmf (โอกาสของแต่ละค่า) และ joint pmf (โอกาสที่ A และ B ได้ค่าคู่หนึ่งพร้อมกัน)
  • ดูว่ามีแรงสองแรงที่ผูก A กับ B ไว้ และทำไมสองแรงนี้หักล้างกันพอดี

ท้ายหน้าเป็นเรื่องเงิน fill คือคำสั่งที่มีคนมาจับคู่สำเร็จ ขั้นที่ 8 แปลงจำนวน fill เป็นกำไรต่อชั่วโมง แล้วถามว่าถ้าโอกาส fill ลดจาก 35% เหลือ 25% (ลด 10 จุด) กำไรจะหายไปกี่เปอร์เซ็นต์ คำตอบไม่ใช่ 10%

ศัพท์ที่ใช้ในหัวข้อนี้
Poisson process
กระแสเหตุการณ์ที่มาทีละครั้งแบบสุ่ม อัตราเฉลี่ย $\lambda$ ครั้งต่อหน่วยเวลา มีสองสมบัติ จำนวนในช่วงยาว $t$ เป็น Poisson ค่าเฉลี่ย $\lambda t$ และจำนวนในช่วงเวลาที่ไม่ทับกันอิสระกัน ใช้เป็นแบบจำลองพื้นฐานของคำสั่งซื้อขายที่เข้ามา การผิดนัดชำระหนี้ หรือการเคลมประกัน
Marketable order และ passive order
marketable order ยอมรับราคาที่มีคนเสนอไว้แล้ว จึงจับคู่ได้ทันที passive order ตั้งราคาของตัวเองไว้ แล้วรอใน order book จนกว่าจะมีคนมาจับคู่
Order book
รายการคำสั่งซื้อและคำสั่งขายที่ยังไม่มีคู่ เรียงตามราคา
Fill
คำสั่งที่จับคู่ได้สำเร็จ คือซื้อหรือขายได้จริง
Thinning (splitting)
การสุ่มติดป้ายให้แต่ละเหตุการณ์ด้วยโอกาสคงที่ โดยแต่ละตัวไม่ขึ้นกับตัวอื่น แล้วแยกเหตุการณ์ตามป้าย ใช้แตกกระแสคำสั่งตามแบบคำสั่ง ตามฝั่งซื้อหรือขาย หรือตามตลาดที่ส่งไป
Superposition
ทิศกลับของ thinning คือเอา Poisson process ที่อิสระกันหลายสายมารวมกัน ได้ Poisson process ที่มีอัตราเท่ากับผลบวกของอัตรา ใช้รวมกระแสจากหลายแหล่ง
pmf และ joint pmf
pmf (probability mass function) บอกโอกาสของแต่ละค่า เช่น $P(A=k)$ ส่วน joint pmf บอกโอกาสที่สองตัวแปรได้ค่าคู่หนึ่งพร้อมกัน เช่น $P(A=k,\,B=j)$
Probability generating function (PGF)
$G_N(z)=E[z^N]$ ฟังก์ชันที่เก็บโอกาส $P(N=n)$ ไว้เป็นสัมประสิทธิ์ของ $z^n$ ใช้กับจำนวนนับ ($N=0,1,2,\ldots$) ถ้า PGF เหมือนกัน การแจกแจงก็เหมือนกัน จึงใช้พิสูจน์การแจกแจงและความอิสระได้สั้น ๆ
Covariance
ตัววัดว่าสองตัวแปรมักขยับไปทางเดียวกัน (ค่าบวก) หรือสวนทางกัน (ค่าลบ) แค่ไหน ถ้าสองตัวแปรอิสระกัน covariance เป็นศูนย์ แต่ covariance ศูนย์ไม่ได้แปลว่าอิสระ
Overdispersion
จำนวนนับที่มี variance มากกว่าค่าเฉลี่ย เช่นคำสั่งที่เกาะกลุ่มกันเข้ามาตามข่าว ทำให้สายย่อยขยับขึ้นลงไปด้วยกัน และไม่อิสระอีกต่อไป
Coefficient of variation (CV)

ขั้นที่ 1 — แบบจำลอง: กระแสแม่กับป้ายที่สุ่มอย่างอิสระ

ก่อนคำนวณ ต้องเขียนให้ชัดว่าแบบจำลองสมมติอะไรบ้าง เพราะทุกผลในหน้านี้ใช้ได้ก็ต่อเมื่อสมมติฐานสามข้อนี้จริง

  • กระแสแม่เป็น Poisson process อัตราคงที่ $\lambda$ ครั้งต่อนาที ให้ $N$ คือจำนวนเหตุการณ์ทั้งหมดในช่วงยาว $t$ นาที
  • แต่ละเหตุการณ์ได้ป้าย A ด้วยโอกาส $p$ เท่ากันทุกตัว ป้ายของแต่ละตัวไม่ขึ้นกับป้ายของตัวอื่น และไม่ขึ้นกับว่ากระแสแม่มีกี่เหตุการณ์
  • ทุกเหตุการณ์ได้ป้ายเดียว ไม่ A ก็ B ให้ $A$ และ $B$ คือจำนวนที่ได้ป้าย A และป้าย B ในช่วงเดียวกัน

นอกจากนี้ต้องแปลงอัตราเป็นจำนวนเฉลี่ยในช่วงที่สนใจก่อน เพราะ Poisson distribution ใช้จำนวนเฉลี่ย $\theta$ เป็นพารามิเตอร์ ไม่ใช่อัตรา

\[ \begin{aligned} N&\sim\operatorname{Poisson}(\theta),\quad\theta=\lambda t,\\ A+B&=N,\\ \theta&=20\times1=20\ \ (t=1),\\ \theta&=20\times5=100\ \ (t=5). \end{aligned} \]

จำนวนเฉลี่ยในช่วงคืออัตราคูณความยาวช่วง $\theta=\lambda t$ เหมือนรถที่วิ่ง 20 กิโลเมตรต่อชั่วโมง ห้าชั่วโมงจะได้ 100 กิโลเมตร จุดที่พลาดบ่อยคือหน่วย ถ้า $\lambda$ เป็นต่อนาที $t$ ก็ต้องเป็นนาทีด้วย หนึ่งนาทีจึงมี $\theta=20$ และห้านาทีมี $\theta=100$ ตัวเลข $\theta$ นี้คือพารามิเตอร์ของ Poisson distribution

สมการ $A+B=N$ มาจากสมมติฐานข้อสาม มันจริงในทุกนาที ไม่ใช่แค่โดยเฉลี่ย เพราะทุกเหตุการณ์ต้องไปสายใดสายหนึ่ง ในช่วงห้านาที A และ B จึงมีค่าเฉลี่ย $100\times0.6=60$ และ $100\times0.4=40$ ซึ่งรวมกันได้ 100 พอดี (ขั้นที่ 3 จะแสดงว่าทำไมค่าเฉลี่ยของ A คือ $p\theta$)

ขั้นที่ 2 — รู้ยอดรวมแล้ว: เหลือแค่การนับหัวก้อย

เริ่มจากกรณีที่ง่ายกว่า สมมติว่ารู้แล้วว่านาทีนี้มี $N=n$ คำสั่ง สิ่งเดียวที่ยังสุ่มคือป้ายของ $n$ คำสั่งนั้น ซึ่งเหมือนโยนเหรียญ $n$ ครั้ง แต่ละครั้งออกหัว (ป้าย A) ด้วยโอกาส $p$ และไม่ขึ้นกับครั้งอื่น

\[ \begin{aligned} P(A=k\mid N=n)&=\binom nk p^k(1-p)^{n-k},\\ E[A\mid N]&=Np,\\ \operatorname{Var}(A\mid N)&=Np(1-p),\\ B&=N-A. \end{aligned} \]

สูตรแรกคือ binomial distribution ตรงตัว คือโอกาสที่ได้ป้าย A $k$ ครั้งจาก $n$ ครั้ง ใช้กับ $k=0,1,\ldots,n$ ตัว $\binom nk$ คือจำนวนวิธีเลือกว่าเหตุการณ์ไหนบ้างที่ได้ A

ค่าเฉลี่ยของ binomial คือ $np$ และ variance คือ $np(1-p)$ ในสูตรเขียน $N$ แทน $n$ เพื่อเตือนว่าสองค่านี้ขึ้นกับยอดรวม ซึ่งยังสุ่มอยู่ถ้ายังไม่รู้ยอดรวม $E[A\mid N]$ อ่านว่า ค่าเฉลี่ยของ A เมื่อรู้ $N$ ถ้า $N=20$ จะได้ค่าเฉลี่ย $20\times0.6=12$ และ variance $20\times0.6\times0.4=4.8$

สมการ $B=N-A$ คือจุดสำคัญ เมื่อรู้ยอดรวม B ถูกกำหนดโดย A ทันที A มากขึ้นหนึ่ง B ต้องน้อยลงหนึ่ง ในโลกที่รู้ยอดรวม สองสายจึงพึ่งพากันเต็มที่

ขั้นที่ 3 — ยังไม่รู้ยอดรวม: เฉลี่ยกลับด้วยกฎสองข้อของบทนี้

ในงานจริง ก่อนนาทีหน้าจะเริ่ม เราไม่รู้ว่าจะมีกี่คำสั่ง ผลจากขั้นที่แล้ว คือ $E[A\mid N]=Np$ และ $\operatorname{Var}(A\mid N)=Np(1-p)$ ยังขึ้นกับ $N$ ที่สุ่มอยู่ จึงต้องเฉลี่ยข้ามทุกค่าของ $N$ ค่าเฉลี่ยใช้ tower property ส่วน variance ใช้ law of total variance

\[ \begin{aligned} E[A]&=E\big[E[A\mid N]\big]=E[Np]=p\theta,\\ \operatorname{Var}(A)&=E\big[Np(1-p)\big]+\operatorname{Var}(Np)\\ &=p(1-p)\theta+p^2\theta\\ &=p\theta. \end{aligned} \]

ค่าเฉลี่ยตรงไปตรงมา ถ้ารู้ $N$ ค่าเฉลี่ยของ A คือ $Np$ เฉลี่ยอีกชั้นข้ามทุก $N$ ได้ $p\,E[N]=p\theta$ เช่นหนึ่งนาทีได้ $0.6\times20=12$

law of total variance แบ่ง variance เป็นสองส่วน $\operatorname{Var}(A)=E\big[\operatorname{Var}(A\mid N)\big]+\operatorname{Var}\big(E[A\mid N]\big)$ (ชื่อเล่น EVVE ตามลำดับตัวอักษรในสูตร) ส่วนแรกคือการแกว่งของการติดป้ายเมื่อรู้ยอดรวมแล้ว เอา $Np(1-p)$ มาเฉลี่ยข้ามทุกยอดรวม ได้ $p(1-p)\,E[N]=p(1-p)\theta$

ส่วนที่สองคือการแกว่งของยอดรวมเอง ค่าเฉลี่ย $Np$ เลื่อนขึ้นลงตาม $N$ จึงมี variance $\operatorname{Var}(Np)=p^2\operatorname{Var}(N)$ ค่าคงที่ $p$ ออกมาเป็นกำลังสอง เพราะ variance วัดระยะห่างจากค่าเฉลี่ยยกกำลังสอง

ท่าที่ทำให้ทุกอย่างลงตัวคือ Poisson มี variance เท่ากับค่าเฉลี่ย $\operatorname{Var}(N)=\theta$ ส่วนที่สองจึงเป็น $p^2\theta$ และสองส่วนรวมกันได้ $p\theta\big[(1-p)+p\big]=p\theta$ พอดี ตัวเลขของหนึ่งนาทีคือ

\[\begin{aligned}p(1-p)\theta&=0.6\times0.4\times20=4.8,\\p^2\theta&=0.6^2\times20=7.2,\\\operatorname{Var}(A)&=4.8+7.2=12.\end{aligned}\]

variance 12 เท่ากับค่าเฉลี่ย 12 เหมือน Poisson ส่วนแรก 4.8 คือ variance ของกรณีรู้ยอดรวมในคำถามต้นหน้า ส่วนที่สอง 7.2 คือสิ่งที่เพิ่มเข้ามาเพราะยังไม่รู้ยอดรวม

มองอีกทางได้ ให้ $I_i$ เป็น 1 เมื่อเหตุการณ์ที่ $i$ ได้ป้าย A และเป็น 0 เมื่อได้ป้าย B ตัวแปรแบบนี้เรียกว่า indicator แล้ว $A=\sum_{i=1}^{N}I_i$ คือ random sum (ผลรวมที่จำนวนพจน์ก็สุ่ม) indicator แต่ละตัวมีค่าเฉลี่ย $\mu=p$ และ variance $\sigma^2=p(1-p)$ สูตรของ random sum จึงให้ผลเดียวกัน

แต่ระวัง ค่าเฉลี่ยเท่ากับ variance ยังไม่ใช่ หลักฐานว่า A เป็น Poisson เพราะการแจกแจงอื่นก็มีสองค่านี้เท่ากันได้ เช่นตัวแปร $X$ ที่เป็น 0 หรือ 2 ด้วยโอกาสอย่างละครึ่ง มี $E[X]=\tfrac12(0)+\tfrac12(2)=1$ และ $\operatorname{Var}(X)=\tfrac12(0-1)^2+\tfrac12(2-1)^2=1$ แต่ไม่ใช่ Poisson ขั้นถัดไปจึงต้องหาโอกาสของทุกค่า

ขั้นที่ 4 — พิสูจน์ว่าสายเดียวเป็น Poisson

ค่าเฉลี่ยกับ variance ตรงกับ Poisson แล้ว แต่ยังไม่พอ ขั้นนี้หาโอกาส $P(A=k)$ ของทุกค่า $k$ โดยตรง วิธีคิดคือ จะได้ $A=k$ ยอดรวมต้องเป็นค่า $n$ สักค่าที่ไม่น้อยกว่า $k$ จึงบวกโอกาสของทุกกรณี $n=k,k+1,k+2,\ldots$ แต่ละกรณีคือโอกาสที่ยอดรวมเป็น $n$ คูณโอกาสที่ $n$ เหตุการณ์นั้นได้ป้าย A $k$ ตัว

\[ \begin{aligned} P(A=k)&=\sum_{n=k}^{\infty}P(N=n)\,P(A=k\mid N=n)\\ &=\sum_{n=k}^{\infty}e^{-\theta}\frac{\theta^n}{n!}\\ &\qquad\times\frac{n!}{k!\,(n-k)!}p^k(1-p)^{n-k}\\ &=e^{-\theta}\frac{(\theta p)^k}{k!}\sum_{j=0}^{\infty}\frac{[\theta(1-p)]^j}{j!}\\ &=e^{-\theta}\frac{(\theta p)^k}{k!}\,e^{\theta(1-p)}\\ &=e^{-\theta p}\frac{(\theta p)^k}{k!}. \end{aligned} \]

จุดเริ่มคือแยกตามยอดรวมทุกค่าที่เป็นไปได้แล้วบวกกัน (law of total probability ซึ่งก็คือ tower property ที่ใช้กับเหตุการณ์ $A=k$) จากนั้นแทนโอกาสของ Poisson $P(N=n)=e^{-\theta}\theta^n/n!$ และโอกาสของ Binomial เข้าไป $n!$ บนและล่างตัดกันทันที

ท่าสำคัญคือเปลี่ยนตัวนับเป็น $j=n-k$ ซึ่งคือจำนวนที่ได้ป้าย B แล้วแยก $\theta^n=\theta^k\theta^j$ ทุกอย่างที่ไม่มี $j$ คือ $e^{-\theta}$, $(\theta p)^k$ และ $k!$ ยกออกนอกผลรวมได้ ที่เหลือในผลรวมคือ $\sum_{j\ge0}x^j/j!$ โดย $x=\theta(1-p)$ ซึ่งคืออนุกรมของ $e^x$ สุดท้ายรวมเลขชี้กำลัง $-\theta+\theta(1-p)=-\theta p$ ได้ pmf ของ Poisson ค่าเฉลี่ย $\theta p$ ตรงตัว

ทำแบบเดียวกันกับ B ได้ Poisson ค่าเฉลี่ย $\theta(1-p)$ กรณีขอบ $p=0$ หรือ $t=0$ ให้ Poisson(0) คือเป็นศูนย์แน่นอน ซึ่งสมเหตุสมผล เพราะไม่มีเหตุการณ์ไหนได้ป้าย A หรือไม่มีเวลาให้เกิดเหตุการณ์เลย

ขั้นที่ 5 — พิสูจน์สองสายพร้อมกัน จึงสรุปความอิสระได้

รู้ว่าแต่ละสายเป็น Poisson ยังไม่พอจะบอกว่าสองสายอิสระกัน ต้องดูโอกาสร่วม $P(A=k,\,B=j)$ แล้วตรวจว่ามันเท่ากับ $P(A=k)\,P(B=j)$ ทุกช่องไหม ขั้นนี้ง่ายกว่าขั้นที่แล้ว เพราะ $A=k$ และ $B=j$ พร้อมกันบังคับให้ $N=k+j$ จึงมีกรณีเดียว ไม่ต้องบวกอะไรเลย

\[ \begin{aligned} P(A=k,\,B=j)&=P(N=k+j)\binom{k+j}{k}p^k(1-p)^j\\ &=e^{-\theta}\frac{\theta^{k+j}}{(k+j)!}\\ &\quad\times\frac{(k+j)!}{k!\,j!}p^k(1-p)^j\\ &=e^{-\theta p}\frac{(\theta p)^k}{k!}\\ &\quad\times e^{-\theta(1-p)}\frac{[\theta(1-p)]^j}{j!}\\ &=P(A=k)\,P(B=j). \end{aligned} \]

หลังแทนโอกาสของ Poisson และ Binomial $(k+j)!$ บนและล่างตัดกัน ท่าที่ต้องเห็นคือแยกสองก้อน $e^{-\theta}=e^{-\theta p}e^{-\theta(1-p)}$ และ $\theta^{k+j}=\theta^k\theta^j$ แล้วจับของที่มี $k$ ไว้ด้วยกัน ของที่มี $j$ ไว้ด้วยกัน ก้อนที่มี $k$ คือ pmf ของ Poisson($\theta p$) ก้อนที่มี $j$ คือ pmf ของ Poisson($\theta(1-p)$)

โอกาสร่วมจึงเป็นผลคูณของโอกาสของแต่ละสาย และเป็นอย่างนี้ทุก $k$ และ $j$ นี่คือนิยามของ independence: สองตัวแปรอิสระกันเมื่อโอกาสร่วมทุกช่องเป็นผลคูณของโอกาสของแต่ละตัว

ตรวจด้วยตัวเลขเล็ก ให้ $\theta=2$ และ $p=\tfrac12$ แล้วหาโอกาสที่ $A=1$ และ $B=1$ สองทาง ทางแรกผ่านกระแสแม่ ทางที่สองใช้ผลคูณ โดยแต่ละสายเป็น Poisson ค่าเฉลี่ย $2\times\tfrac12=1$

\[\begin{aligned}P(N=2)&=e^{-2}\tfrac{2^2}{2!}=2e^{-2},\\P(A=1\mid N=2)&=\tbinom21\tfrac12\cdot\tfrac12=\tfrac12,\\P(A=1,\,B=1)&=2e^{-2}\times\tfrac12=e^{-2},\\P(A=1)\,P(B=1)&=e^{-1}\times e^{-1}=e^{-2}.\end{aligned}\]

ทั้งสองทางได้ $e^{-2}\approx0.1353$ ตรงกัน

ผลนี้พูดถึงจำนวนในช่วงเดียว แต่กระแสแม่เป็น Poisson process จำนวนในช่วงเวลาที่ไม่ทับกันจึงอิสระกันอยู่แล้ว และป้ายของแต่ละเหตุการณ์ก็อิสระกัน รวมสองข้อนี้ได้ว่าสองสายเป็น Poisson process ที่อิสระกันทั้งกระบวนการ ไม่ใช่แค่จำนวนในช่วงเดียว

ขั้นที่ 6 — อีกทางที่สั้นกว่า: probability generating function

การพิสูจน์ด้วย pmf ต้องจัดพจน์ทีละตัว ขั้นนี้ทำเรื่องเดียวกันด้วย PGF ซึ่งสั้นกว่า และขยายไปหลายป้ายได้ทันที PGF ของจำนวนนับ $N$ คือ $G_N(z)=E[z^N]$ มันใช้ได้เพราะสองข้อ ข้อแรก ถ้า PGF เหมือนกัน การแจกแจงก็เหมือนกัน ข้อสอง ถ้าค่าเฉลี่ยร่วม $E[s^Au^B]$ แยกเป็นฟังก์ชันของ $s$ คูณฟังก์ชันของ $u$ ได้ A กับ B ก็อิสระกัน ขั้นนี้ใช้ $0\le s\le1$ และ $0\le u\le1$ ซึ่งทำให้ทุกค่าเฉลี่ยมีค่าจำกัด

\[ \begin{aligned} G_N(z)&=E[z^N]=\sum_{n\ge0}e^{-\theta}\frac{(\theta z)^n}{n!}\\ &=e^{\theta(z-1)},\\ E[s^Au^B\mid N=n]&=\big(ps+(1-p)u\big)^n,\\ E[s^Au^B]&=G_N\big(ps+(1-p)u\big)\\ &=e^{\theta p(s-1)}\,e^{\theta(1-p)(u-1)}. \end{aligned} \]

PGF ของ Poisson หาได้จากอนุกรมของ $e^x$ อีกครั้ง โดยใช้ $x=\theta z$ ได้ $\sum_{n\ge0}(\theta z)^n/n!=e^{\theta z}$ คูณกับ $e^{-\theta}$ ได้ $e^{\theta(z-1)}$

หัวใจอยู่ที่ $E[s^Au^B\mid N=n]$ เมื่อรู้ $N=n$ แต่ละเหตุการณ์ให้ตัวคูณ $s$ ถ้าได้ป้าย A (โอกาส $p$) หรือตัวคูณ $u$ ถ้าได้ป้าย B (โอกาส $1-p$) ค่าเฉลี่ยของตัวคูณหนึ่งตัวจึงเป็น $ps+(1-p)u$ และเพราะป้ายอิสระกัน ค่าเฉลี่ยของผลคูณ $n$ ตัวจึงเท่ากับผลคูณของค่าเฉลี่ย $n$ ตัว ได้ยกกำลัง $n$

จากนั้นใช้ tower property เฉลี่ยข้าม $N$ ซึ่งก็คือแทน $z$ ใน $G_N(z)$ ด้วย $ps+(1-p)u$ แล้วแยกเลขชี้กำลังโดยใช้ $1=p+(1-p)$:

\[\begin{aligned}&\theta\big(ps+(1-p)u-1\big)\\&=\theta p(s-1)+\theta(1-p)(u-1).\end{aligned}\]

ผลลัพธ์คือฟังก์ชันของ $s$ คูณฟังก์ชันของ $u$ แยกกันเด็ดขาด ก้อนแรกคือ PGF ของ Poisson ค่าเฉลี่ย $\theta p$ ก้อนที่สองคือ PGF ของ Poisson ค่าเฉลี่ย $\theta(1-p)$ จึงได้ทั้งการแจกแจงและความอิสระในครั้งเดียว ถ้ามี $r$ ป้ายด้วยโอกาส $p_1,\ldots,p_r$ ที่รวมกันได้ 1 ผลคูณจะมี $r$ ก้อน และทุกสายเป็น Poisson ที่อิสระกัน

ขั้นที่ 7 — คลายปม: แรงสองแรงที่หักล้างกันพอดี

ยังเหลือคำถามว่า ทำไมรู้ยอดรวมแล้วสองสายสวนทางกัน แต่ไม่รู้ยอดรวมกลับอิสระ ขั้นนี้แยกแรงสองแรงที่ผูก A กับ B ไว้ แล้ววัดแต่ละแรงด้วย covariance (ค่าบวกคือขยับไปทางเดียวกัน ค่าลบคือสวนทางกัน) เครื่องมือคือ law of total covariance ซึ่งเป็นรูป covariance ของ law of total variance พิสูจน์แบบเดียวกันทุกขั้น แค่ใช้ผลคูณ $(A-E[A])(B-E[B])$ แทนกำลังสอง

\[ \begin{aligned} \operatorname{Cov}(A,B)&=E\big[\operatorname{Cov}(A,B\mid N)\big]\\ &\quad+\operatorname{Cov}\big(E[A\mid N],E[B\mid N]\big)\\ &=E\big[-Np(1-p)\big]\\ &\quad+\operatorname{Cov}\big(Np,\,N(1-p)\big)\\ &=p(1-p)\big(\operatorname{Var}(N)-E[N]\big). \end{aligned} \]

แรงแรกเป็นลบ เมื่อรู้ $N$ แล้ว B คือ $N-A$ ส่วน $N$ กลายเป็นค่าคงที่ซึ่งไม่แกว่งร่วมกับใคร covariance เมื่อรู้ $N$ จึงเหลือแค่ลบ variance ของ A

\[\begin{aligned}\operatorname{Cov}(A,B\mid N)&=\operatorname{Cov}(A,\,N-A\mid N)\\&=-\operatorname{Var}(A\mid N)\\&=-Np(1-p).\end{aligned}\]

เฉลี่ยข้าม $N$ ได้แรงแรกเท่ากับ $-p(1-p)\,E[N]$

แรงที่สองเป็นบวก นาทีที่คำสั่งรวมเยอะ ค่าเฉลี่ยของทั้ง A และ B สูงขึ้นพร้อมกัน ขนาดของแรงนี้คือ $\operatorname{Cov}\big(Np,\,N(1-p)\big)=p(1-p)\operatorname{Var}(N)$ รวมสองแรงได้ $p(1-p)\big(\operatorname{Var}(N)-E[N]\big)$

Poisson มี $\operatorname{Var}(N)=E[N]$ สองแรงจึงหักล้างกันพอดี และ covariance เป็นศูนย์ เช่นที่ $p=0.6$ และ $\theta=20$ จะได้ $p(1-p)=0.6\times0.4=0.24$ แรงลบคือ $-0.24\times20=-4.8$ แรงบวกคือ $0.24\times20=+4.8$

ระวัง covariance ศูนย์อย่างเดียวไม่พอจะบอกว่าอิสระ (zero covariance is not independence) ความอิสระเต็มรูปมาจาก joint pmf ในขั้นที่ 5 แต่สูตรนี้บอกว่าถ้ากระแสแม่ไม่ใช่ Poisson จะเกิดอะไร ถ้าคำสั่งเกาะกลุ่มกันจน variance มากกว่าค่าเฉลี่ย สองสายจะขยับไปด้วยกัน ถ้ายอดรวมคงที่ (variance ศูนย์) สองสายจะสวนทางกัน

ขั้นที่ 8 — จาก fill เป็นกำไรรายชั่วโมง

ทีม execution สนใจเงิน ไม่ใช่จำนวนคำสั่ง ขั้นนี้ใช้ thinning หาจำนวน fill (คำสั่งที่จับคู่สำเร็จ) แล้วแปลงเป็นกำไร โดยสมมติก่อนว่าทุก fill ได้กำไรเท่ากัน

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ):

  • บริษัทส่ง passive order เข้าตลาดแบบ Poisson process อัตรา 120 คำสั่งต่อชั่วโมง
  • แต่ละคำสั่งได้ fill ด้วยโอกาส 0.35 และไม่ขึ้นกับคำสั่งอื่น นี่คือการติดป้าย “fill” กับ “ไม่ fill” แบบ thinning
  • ทุก fill ได้กำไร \$45 เท่ากัน

ให้ $K$ คือจำนวน fill ในหนึ่งชั่วโมง และ $Q=45K$ คือกำไรในชั่วโมงนั้นเป็นดอลลาร์ thinning บอกว่า $K$ เป็น Poisson ค่าเฉลี่ย $120\times0.35=42$ เพราะ Poisson มี variance เท่ากับค่าเฉลี่ย SD ของ $K$ จึงเป็น $\sqrt{42}$ กำไรคือ $K$ คูณ 45 ดังนั้นทั้งค่าเฉลี่ยและ SD ของกำไรก็คูณ 45

\[ \begin{aligned} K&\sim\operatorname{Poisson}(120\times0.35=42),\\ E[Q]&=45(42)=1{,}890,\\ \operatorname{SD}(Q)&=45\sqrt{42}\approx291.63,\\ \frac{\operatorname{SD}(Q)}{E[Q]}&=\frac{1}{\sqrt{42}}\approx15.4\%. \end{aligned} \]

คำตอบ: กำไรเฉลี่ย \$1,890 ต่อชั่วโมง และ SD \$291.63 ตัวเลขสุดท้ายคือ coefficient of variation (CV) คือ SD หารด้วยค่าเฉลี่ย บอกว่าการแกว่งใหญ่แค่ไหนเมื่อเทียบกับค่าเฉลี่ย ในเศษส่วนนี้ 45 บนและล่างตัดกัน จึงเหลือ $\dfrac{45\sqrt{42}}{45\times42}=\dfrac{1}{\sqrt{42}}$

ถ้าทำงานวันละ 7 ชั่วโมงที่อัตราเดิม จำนวน fill ทั้งวันเป็น Poisson ค่าเฉลี่ย $7\times42=294$ เพราะจำนวนในแต่ละชั่วโมงอิสระกัน (สมบัติของ Poisson process) ให้ $Q_7$ คือกำไรทั้งวัน ค่าเฉลี่ยโต 7 เท่า แต่ SD โตแค่ $\sqrt7$ เท่า

\[\begin{aligned}E[Q_7]&=7\times1{,}890=\$13{,}230,\\\operatorname{SD}(Q_7)&=45\sqrt{294}\approx\$771.59.\end{aligned}\]

ต่อไปถามว่า ถ้าคู่แข่งส่งคำสั่งได้เร็วกว่าจนแย่งคู่ไปก่อน โอกาส fill ลดจาก 0.35 เหลือ 0.25 (ลด 10 จุด) กำไรจะหายไปเท่าไร คำนวณซ้ำด้วยสูตรเดิม

\[\begin{aligned}K&\sim\operatorname{Poisson}(120\times0.25=30),\\E[Q]&=45\times30=\$1{,}350,\\\operatorname{SD}(Q)&=45\sqrt{30}\approx\$246.48,\\\operatorname{CV}&=1/\sqrt{30}\approx18.3\%.\end{aligned}\]

กำไรหายไป $1{,}890-1{,}350=\$540$ ต่อชั่วโมง คิดเป็น $540/1{,}890\approx28.6\%$ ไม่ใช่ 10% เพราะ 10 จุดนั้นลดจากฐาน 35 ไม่ใช่จากฐาน 100 fill จึงหายไป $0.10/0.35\approx28.6\%$ และกำไรหายตามในสัดส่วนเดียวกัน SD เป็นดอลลาร์ลดลงก็จริง แต่ CV เพิ่มจาก 15.4% เป็น 18.3% กำไรจึงแกว่งมากขึ้นเมื่อเทียบกับขนาดของมัน

ตรวจเองใน 10 วินาที: $\sqrt{42}\approx6.48$ และ $45\times6.48\approx292$ ส่วน $0.25/0.35\approx0.714$ คือเหลือกำไร 71.4% หายไป $100\%-71.4\%=28.6\%$

ขั้นที่ 9 — กำไรต่อ fill ไม่คงที่: กลับไปใช้ random sum

ในความจริงกำไรต่อ fill ไม่เท่ากัน บาง fill กำไร บาง fill ขาดทุน ขั้นนี้ให้กำไรต่อ fill สุ่ม แล้วดูว่าความเสี่ยงที่คิดจากจำนวน fill อย่างเดียวในขั้นที่ 8 ต่ำไปแค่ไหน

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ):

  • จำนวน fill ต่อชั่วโมง $K\sim\operatorname{Poisson}(42)$ เหมือนขั้นที่ 8
  • กำไรของแต่ละ fill สุ่ม มีค่าเฉลี่ย $\mu=\$45$ และ SD $\sigma=\$200$
  • กำไรของแต่ละ fill อิสระกันและมาจากการแจกแจงเดียวกัน (iid) และไม่ขึ้นกับ $K$

กำไรทั้งชั่วโมงจึงเป็น random sum ใช้สูตร variance ของ compound Poisson จาก random sums คือ $\operatorname{Var}(Q)=E[K]\,\sigma^2+\operatorname{Var}(K)\,\mu^2$ โดย Poisson มี $\operatorname{Var}(K)=E[K]=42$

\[ \begin{aligned} E[Q]&=42(45)=1{,}890,\\ \operatorname{Var}(Q)&=42(200^2)+42(45^2)\\ &=1{,}680{,}000+85{,}050\\ &=1{,}765{,}050,\\ \operatorname{SD}(Q)&\approx1{,}328.55. \end{aligned} \]

คำตอบ: SD \$1,328.55 ต่อชั่วโมง เทียบกับ \$291.63 ในขั้นที่ 8 ใหญ่กว่า $1{,}328.55/291.63\approx4.56$ เท่า

เหตุผลอยู่ที่สองพจน์ของ variance พจน์ $42\times45^2=85{,}050$ คือความเสี่ยงจากจำนวน fill อย่างเดียว มันเท่ากับ variance ของขั้นที่ 8 พอดี เพราะ $(45\sqrt{42})^2=45^2\times42=85{,}050$ ส่วนพจน์ $42\times200^2=1{,}680{,}000$ มาจากกำไรของแต่ละ fill ที่แกว่ง พจน์นี้ใหญ่กว่าพจน์แรก $1{,}680{,}000/85{,}050\approx19.8$ เท่า ความเสี่ยงที่คิดจากจำนวน fill อย่างเดียวจึงเป็นแค่ส่วนเล็ก ๆ

ข้อควรระวังในตลาดจริงคือ adverse selection คือการถูกเลือกโดยคนที่รู้มากกว่า passive order มักได้ fill ตอนที่อีกฝ่ายรู้ข้อมูลดีกว่า เช่น อีกฝ่ายรู้ว่าราคากำลังจะลง จึงรีบขายให้เรา fill ที่ได้มาง่ายจึงมักเป็น fill ที่ขาดทุน โอกาส fill กับกำไรต่อ fill จึงผูกกัน ป้าย “fill” ไม่อิสระจากผลลัพธ์อีกต่อไป และสูตรของหน้านี้ใช้ตรง ๆ ไม่ได้

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ใช้ Poisson หลังรู้ยอดรวมแล้ว: ถ้ารู้แล้วว่านาทีนี้มี 20 คำสั่ง จำนวน A เป็น Binomial ไม่ใช่ Poisson variance ที่ถูกคือ $20\times0.6\times0.4=4.8$ ไม่ใช่ 12 ถ้าใช้ 12 ช่วงที่บอกว่า A น่าจะอยู่ระหว่างเท่าไรจะกว้างเกินไป ความกว้างของช่วงแปรตาม SD ช่วงจึงกว้างเกินจริง $\sqrt{12}/\sqrt{4.8}=\sqrt{2.5}\approx1.58$ เท่า

แบ่งแบบสลับกันแทนการสุ่ม: ถ้าส่งคำสั่งเข้า A, B, A, B สลับกันไปเรื่อย ๆ จำนวนในสองสายจะต่างกันไม่เกินหนึ่งเสมอ เช่นเริ่มที่ A แล้วรู้ว่า A มี 10 คำสั่ง B ต้องเป็น 9 หรือ 10 เท่านั้น ป้ายจึงไม่อิสระกัน สายลูกไม่ใช่ Poisson และไม่อิสระกัน การแบ่งให้เท่ากันกับการแบ่งแบบสุ่มเป็นคนละเรื่อง

กระแสแม่เกาะกลุ่ม: ถ้าจำนวนคำสั่งรวมมีค่าเฉลี่ย 20 แต่ variance 40 (คำสั่งเกาะกลุ่มกันตามข่าว) สูตรของขั้นที่ 3 และขั้นที่ 7 ให้

\[\begin{aligned}\operatorname{Var}(A)&=0.6\times0.4\times20+0.6^2\times40\\&=4.8+14.4=19.2,\\\operatorname{Cov}(A,B)&=0.24\times(40-20)=+4.8.\end{aligned}\]

ไม่ใช่ 12 และ 0 แบบ Poisson สองสายขึ้นลงพร้อมกันตามข่าว

ใช้ correlation จากข้อมูลที่ใกล้ศูนย์เป็นหลักฐาน: correlation ใกล้ศูนย์บอกแค่ว่าไม่มีความสัมพันธ์เชิงเส้น ไม่ได้แปลว่าอิสระ เช่นเดียวกับที่ค่าเฉลี่ยเท่ากับ variance ไม่ได้แปลว่าเป็น Poisson (ตัวแปรที่เป็น 0 หรือ 2 อย่างละครึ่งมีทั้งสองค่าเป็น 1 ตามที่คำนวณในขั้นที่ 3) ต้องตรวจการแจกแจงทั้งก้อน

หน่วยของอัตรากับเวลาไม่ตรงกัน: อัตรา 20 ต่อนาทีกับช่วง 30 วินาที ต้องแปลงเวลาเป็นนาทีก่อน $t=30/60=0.5$ นาที จึงได้ $\theta=20\times0.5=10$ ไม่ใช่ $20\times30=600$ ซึ่งเอาอัตราต่อนาทีไปคูณวินาที

ใช้ทำอะไรในงานจริง

Thinning ใช้แตกกระแสคำสั่งตามฝั่ง (ซื้อหรือขาย) ตามตลาดปลายทาง หรือตามแบบคำสั่ง แล้วสร้างแบบจำลองแต่ละสายแยกกันได้ เพราะรู้ว่าแต่ละสายเป็น Poisson และอิสระกัน superposition ใช้ในทิศกลับ เช่น คำสั่งจากตลาดสามแห่งที่อิสระกัน อัตรา 5, 8 และ 7 คำสั่งต่อนาที รวมเป็น Poisson อัตรา $5+8+7=20$ คำสั่งต่อนาที

อีกงานที่ใช้บ่อยคือจำลองกระแสที่อัตราเปลี่ยนตามเวลา เช่นคำสั่งเข้ามา 40 คำสั่งต่อนาทีตอนเปิดตลาด แต่เหลือ 10 คำสั่งต่อนาทีตอนเที่ยง ให้ $\lambda(t)$ คืออัตรา ณ เวลา $t$ วิธี thinning ของ Lewis และ Shedler ทำสองขั้น ขั้นแรก สร้างเหตุการณ์ด้วยอัตราคงที่เท่ากับอัตราสูงสุด 40 คำสั่งต่อนาที ขั้นที่สอง เก็บเหตุการณ์ที่เวลา $t$ ไว้ด้วยโอกาส $\lambda(t)/40$ แล้วทิ้งที่เหลือ เช่นตอนเที่ยงเก็บไว้ $10/40=25\%$ ผลของ thinning บอกว่าสายที่เก็บไว้มีอัตรา $40\times\lambda(t)/40=\lambda(t)$ พอดี วิธีนี้เป็นงานประจำของ Monte Carlo (การจำลองแบบสุ่มหลายรอบแล้วเฉลี่ยผล) สำหรับคำสั่งซื้อขายและการผิดนัดชำระของสินเชื่อ

โจทย์ตรวจความเข้าใจ

1. กระแสเหตุการณ์หนึ่งเป็น Poisson process เฉลี่ย 10 ครั้งต่อนาที แต่ละเหตุการณ์ได้ป้าย A ด้วยโอกาส 0.3 และไม่ขึ้นกับเหตุการณ์อื่น ดูช่วงสองนาที (ก) ก่อนรู้ยอดรวม A และ B มีการแจกแจงอะไร (ข) ถ้ารู้ว่ายอดรวมในสองนาทีคือ 20 variance ของ A เป็นเท่าไร

เฉลย

(ก) แปลงอัตราเป็นจำนวนเฉลี่ยในช่วงก่อน แล้วแบ่งตามโอกาสของป้าย

\[\begin{aligned}\theta&=10\times2=20,\\E[A]&=20\times0.3=6,\\E[B]&=20\times0.7=14.\end{aligned}\]

A เป็น Poisson(6) B เป็น Poisson(14) และสองตัวอิสระกัน (ข) เมื่อรู้ยอดรวม 20 A เป็น Binomial(20, 0.3) จึงมี variance $20\times0.3\times0.7=4.2$ ไม่ใช่ 6

2. แม่ไก่ตัวหนึ่งออกไข่ จำนวนไข่เป็น Poisson ค่าเฉลี่ย 10 ฟอง แต่ละฟองฟักเป็นลูกไก่ด้วยโอกาส 0.3 และไม่ขึ้นกับฟองอื่น (ก) โอกาสที่ไม่ได้ลูกไก่เลยเป็นเท่าไร (ข) ถ้ามีคนบอกว่ามีไข่ที่ไม่ฟัก 5 ฟอง ค่าเฉลี่ยของจำนวนลูกไก่เปลี่ยนไหม

เฉลย

(ก) การฟักคือการติดป้าย จำนวนลูกไก่จึงเป็น Poisson ค่าเฉลี่ย $10\times0.3=3$ โอกาสได้ศูนย์ตัวคือ $P(0)=e^{-3}\tfrac{3^0}{0!}=e^{-3}\approx0.0498$ หรือราว 5%

(ข) ไม่เปลี่ยน ไข่ที่ไม่ฟักเป็น Poisson ค่าเฉลี่ย $10\times0.7=7$ ที่อิสระจากจำนวนลูกไก่ การรู้ว่ามีไข่ไม่ฟัก 5 ฟองจึงไม่บอกอะไรเกี่ยวกับลูกไก่ ค่าเฉลี่ยยังเป็น 3 ต่างจากการรู้จำนวนไข่ทั้งหมด ซึ่งทำให้จำนวนลูกไก่กลายเป็น Binomial เช่นรู้ว่ามีไข่ 12 ฟอง ค่าเฉลี่ยจะเป็น $12\times0.3=3.6$

3. สมมติว่าคำสั่งเกาะกลุ่มกันตามข่าว จำนวนคำสั่งรวมต่อนาทีมีค่าเฉลี่ย 20 แต่ variance 40 แต่ละคำสั่งยังได้ป้าย A ด้วยโอกาส 0.6 และไม่ขึ้นกับคำสั่งอื่น จงหา $E[A]$, $\operatorname{Var}(A)$ และ $\operatorname{Cov}(A,B)$

เฉลย

ใช้สามสูตรของหน้านี้ คือ $E[A]=p\,E[N]$ จาก tower property, $\operatorname{Var}(A)=p(1-p)E[N]+p^2\operatorname{Var}(N)$ จาก law of total variance และ $\operatorname{Cov}(A,B)=p(1-p)\big(\operatorname{Var}(N)-E[N]\big)$ จากขั้นที่ 7 แต่ใส่ $\operatorname{Var}(N)=40$ แทนที่จะเท่ากับค่าเฉลี่ย

\[\begin{aligned}E[A]&=0.6\times20=12,\\\operatorname{Var}(A)&=0.6\times0.4\times20+0.6^2\times40\\&=4.8+14.4=19.2,\\\operatorname{Cov}(A,B)&=0.24\times(40-20)=4.8.\end{aligned}\]

ค่าเฉลี่ยยังเท่าเดิม แต่ variance ของ A (19.2) มากกว่าค่าเฉลี่ย (12) A จึงไม่ใช่ Poisson และ covariance เป็นบวก A กับ B จึงไม่อิสระกัน

โค้ดนี้ตรวจสามเรื่อง เรื่องแรก joint pmf ที่สร้างจากกระแสแม่ ($\theta=5$, $p=0.6$) เท่ากับผลคูณของ Poisson(3) กับ Poisson(2) ในทุกช่องของตาราง $A,B=0,\ldots,30$ เรื่องที่สอง variance แบบรู้และไม่รู้ยอดรวม และ covariance ของกระแสที่เกาะกลุ่ม เรื่องที่สาม ตัวเลขกำไรต่อชั่วโมงของขั้นที่ 8 และขั้นที่ 9

เปิดดูโค้ด 
const fact = n => { let v = 1; for (let i = 2; i <= n; i++) v *= i; return v; };
const pois = (k, th) => Math.exp(-th) * th ** k / fact(k);
const choose = (n, k) => fact(n) / (fact(k) * fact(n - k));
// P(A = k, B = j) built from the parent stream
const joint = (k, j, th, p) =>
  pois(k + j, th) * choose(k + j, k) * p ** k * (1 - p) ** j;

let maxError = 0;
for (let k = 0; k <= 30; k++) for (let j = 0; j <= 30; j++) {
  const gap = joint(k, j, 5, 0.6) - pois(k, 3) * pois(j, 2);
  maxError = Math.max(maxError, Math.abs(gap));
}
const tiny = joint(1, 1, 2, 0.5);                 // e^-2 = 0.1353

const varGiven20 = 20 * 0.6 * 0.4;                // 4.8
const varBefore = 20 * 0.6 * 0.4 + 0.6 ** 2 * 20; // 12
const covOver = 0.24 * (40 - 20);                 // 4.8

const hour = p => {
  const fills = 120 * p;
  return {fills, mean: 45 * fills, sd: 45 * Math.sqrt(fills), cv: 1 / Math.sqrt(fills)};
};
const base = hour(0.35), slower = hour(0.25);     // 1890 / 291.63, 1350 / 246.48
const randomVar = 42 * (200 ** 2 + 45 ** 2);      // 1765050
console.log({maxError, tiny, varGiven20, varBefore, covOver, base, slower,
  lost: base.mean - slower.mean, randomSD: Math.sqrt(randomVar)});

สิ่งที่ควรตอบได้หลังอ่าน

  • เมื่อรู้ยอดรวม $N=n$ แล้ว การสุ่มติดป้ายทำให้ A เป็น Binomial($n$, $p$) และสองสายสวนทางกันเต็มที่ เพราะ $B=n-A$
  • เมื่อยังไม่รู้ยอดรวม ถ้ากระแสแม่เป็น Poisson($\theta$) สาย A เป็น Poisson($\theta p$) สาย B เป็น Poisson($\theta(1-p)$) และสองสายอิสระกัน เช่นอัตรา 20 คำสั่งต่อนาทีแยกเป็น $20\times0.6=12$ กับ $20\times0.4=8$
  • tower property ให้ค่าเฉลี่ย law of total variance ให้ variance แต่ต้องใช้ joint pmf หรือ PGF จึงพิสูจน์การแจกแจงและความอิสระได้
  • covariance ของสองสายคือ $p(1-p)\big(\operatorname{Var}(N)-E[N]\big)$ Poisson ซึ่งมี variance เท่ากับค่าเฉลี่ย เป็นกรณีที่สองแรงหักล้างกันพอดี กระแสที่เกาะกลุ่มให้ covariance บวก ยอดรวมคงที่ให้ covariance ลบ
  • โอกาส fill ที่ลด 10 จุดจาก 35% ทำให้กำไรหาย $0.10/0.35\approx28.6\%$ และเมื่อกำไรต่อ fill สุ่ม (SD \$200) ความเสี่ยงสูงกว่าที่คิดจากจำนวน fill อย่างเดียว 4.56 เท่า
