6.5 Inner Product, Angle, and Correlation

Correlation คือ cosine ของมุมระหว่างสองชุดผลตอบแทนหลังหักค่าเฉลี่ย และขนาด hedge ที่ดีที่สุดคือเงาของชุดหนึ่งที่ตกบนอีกชุด

ผลตอบแทนสามวันของหุ้น A คือ 1%, 2%, 3% ของหุ้น B คือ 3%, 2%, 1% (ตัวเลขสมมติ) ทั้งคู่บวกทุกวัน และผลคูณวันต่อวันรวมกันเป็นบวก $1(3)+2(2)+3(1)=10$ นักวิเคราะห์จึงสรุปว่า “สองตัวนี้ไปทางเดียวกัน ใช้ hedge กันไม่ได้” สรุปถูกไหม correlation ของสองชุดนี้เท่าไร

ลองตอบก่อนเปิดเฉลย

สรุปผิด ทั้งสองชุดเฉลี่ย 2% หักออกแล้วได้ $(-1,0,1)$ กับ $(1,0,-1)$ ซึ่งชี้ตรงข้ามกันพอดี correlation จึงเป็น −1: วันไหน A ดีกว่าค่าเฉลี่ย B แย่กว่าค่าเฉลี่ยเท่ากันพอดี ตัวเลข 10 ที่บวกนั้นมาจากค่าเฉลี่ยร่วมที่เป็นบวก ถ้าคิด cosine ของข้อมูลดิบจะได้ $10/14\approx0.71$ ซึ่งตอบคนละคำถาม

ภาพรวมก่อนลงสูตร

norms วัดว่า vector ยาวแค่ไหน หน้านี้วัดว่าสอง vector ชี้ไปทางเดียวกันแค่ไหน เครื่องมือคือ inner product หรือ dot product ตัวเดิมจาก row และ column vectors: คูณช่องต่อช่องแล้วบวก หารด้วยความยาวทั้งสองได้ cosine ของมุมระหว่างมัน

เมื่อเอาผลตอบแทนหลายวันมาเป็น vector (หนึ่งช่องต่อหนึ่งวัน) แล้วหักค่าเฉลี่ยของตัวเองออกก่อน cosine ของมุมนั้นคือ sample correlation พอดี การหักค่าเฉลี่ยมีความหมายทางเรขาคณิตที่ชัดเจน: ตัดส่วนที่ชี้ไปทาง “ทุกวันเท่ากัน” ออก รูปด้านล่างแสดงว่าทำไมโจทย์ต้นหน้าจึงกลับจากมุม 44 องศาเป็น 180 องศา

หน้านี้จะพิสูจน์ว่าทำไม dot product บอกมุมได้ ทำไม cosine ไม่หลุดช่วง −1 ถึง 1 เชื่อมมุมกับ correlation อ่าน correlation จริงของสินทรัพย์แปดกลุ่ม ใช้มุมอธิบายความเสี่ยงของพอร์ตสองสินทรัพย์ แล้วใช้ projection หาขนาด hedge ที่ทำให้ส่วนเหลือสั้นที่สุด ซึ่งคือ beta ของ CAPM

ศัพท์ที่ใช้ในหัวข้อนี้
Inner product (dot product)
$\mathbf x^{\mathsf T}\mathbf y=\sum_ix_iy_i$ ใช้วัดว่าสอง vector จับคู่กันไปทางเดียวกันแค่ไหน และให้ความยาว $\|\mathbf x\|_2=\sqrt{\mathbf x^{\mathsf T}\mathbf x}$
Orthogonal
สอง vector ที่ dot product เป็นศูนย์ คือตั้งฉากกัน สำหรับข้อมูลที่หักค่าเฉลี่ยแล้ว แปลว่า correlation ในตัวอย่างเป็นศูนย์
Centering
หักค่าเฉลี่ยของชุดตัวเองออกจากทุกค่า ทำให้ vector ตั้งฉากกับทิศ (1, 1, …, 1) ต้องทำก่อนอ่าน cosine เป็น correlation
Correlation
covariance หารด้วยผลคูณ standard deviation ซึ่งเท่ากับ cosine ของมุมระหว่างข้อมูลที่หักค่าเฉลี่ยแล้ว อยู่ระหว่าง −1 ถึง 1 ใช้วัดการเคลื่อนไหวร่วมแบบเส้นตรง
Projection
ส่วนของ vector หนึ่งที่อยู่ตามทิศของอีก vector หนึ่ง เหมือนเงาที่ตกตั้งฉาก ใช้หาว่า hedge ตัดความเสี่ยงออกได้เท่าไร
Residual
ส่วนที่เหลือหลังลบ projection ออก ตั้งฉากกับทิศที่ใช้ hedge คือความเสี่ยงที่ hedge ตัวนั้นเอาออกไม่ได้
Hedge ratio และ beta
ตัวคูณ $h=\operatorname{cov}(x,y)/\operatorname{var}(y)$ ที่ทำให้ variance ของ $x-hy$ ต่ำสุด เมื่อ $y$ คือตลาด ตัวคูณนี้เรียกว่า beta
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$\mathbf a,\mathbf b$ผลตอบแทนดิบของสองสินทรัพย์ $n$ วัน% หรือเศษส่วน
$\mathbf x,\mathbf y$ผลตอบแทนหลังหักค่าเฉลี่ย $x_i=a_i-\bar a$เหมือน $\mathbf a$
$\theta$มุมระหว่างสอง vectorองศา
$s_x$, $s_{xy}$sample standard deviation และ sample covariance%, %²
$\hat\rho$sample correlationไม่มีหน่วย
$h$, $\mathbf e$hedge ratio และ residual $\mathbf x-h\mathbf y$ไม่มีหน่วย, เหมือน $\mathbf x$

ขั้นที่ 1 — inner product: จับคู่ช่องแล้วบวก

ทุกอย่างในหน้านี้สร้างจากการคูณแถวกับคอลัมน์ตัวเดียว ขั้นแรกจึงทวนนิยามและคุณสมบัติที่จะใช้ทุกขั้นถัดไป

\[ \begin{aligned} \mathbf x^{\mathsf T}\mathbf y&=\sum_{i=1}^nx_iy_i,\\ \mathbf x^{\mathsf T}\mathbf y&=\mathbf y^{\mathsf T}\mathbf x,\\ \mathbf x^{\mathsf T}(a\mathbf y+b\mathbf z)&=a\,\mathbf x^{\mathsf T}\mathbf y+b\,\mathbf x^{\mathsf T}\mathbf z,\\ \mathbf x^{\mathsf T}\mathbf x&=\|\mathbf x\|_2^2. \end{aligned} \]

สลับลำดับได้ (บรรทัดสอง) เพราะ $x_iy_i=y_ix_i$ ทุกช่อง กระจายเข้าวงเล็บได้ (บรรทัดสาม) เพราะเป็นผลบวกของผลคูณ และ dot product ของ vector กับตัวเองคือผลรวมกำลังสอง ซึ่งคือ L2 ยกกำลังสอง ค่านี้บวกเสมอถ้า vector ไม่เป็นศูนย์ แต่ dot product ของสอง vector ต่างกันเป็นบวก ศูนย์ หรือลบก็ได้ เครื่องหมายนั้นแหละที่บอกทิศ

เมื่อช่องคือวันซื้อขาย ต้องจับคู่วันเดียวกันก่อน วันที่ข้อมูลขาดตัวใดตัวหนึ่งต้องตัดทิ้งทั้งคู่ ถ้าเติมวันที่ขาดด้วยศูนย์หรือเลื่อนวันผิดหนึ่งวัน สูตรยังคำนวณได้ แต่ได้ตัวเลขของคำถามอื่น

ขั้นที่ 2 — ทำไม dot product บอกมุมได้

เรขาคณิตมัธยมมีกฎโคไซน์สำหรับสามเหลี่ยมที่มีด้าน $\mathbf x$, $\mathbf y$ และ $\mathbf x-\mathbf y$ ส่วนพีชคณิตกระจาย $\|\mathbf x-\mathbf y\|^2$ ได้อีกแบบ เทียบสองแบบแล้วมุมโผล่ออกมาเอง

\[ \begin{aligned} \|\mathbf x-\mathbf y\|^2&=\|\mathbf x\|^2+\|\mathbf y\|^2-2\|\mathbf x\|\|\mathbf y\|\cos\theta,\\ \|\mathbf x-\mathbf y\|^2&=(\mathbf x-\mathbf y)^{\mathsf T}(\mathbf x-\mathbf y)\\ &=\|\mathbf x\|^2+\|\mathbf y\|^2-2\,\mathbf x^{\mathsf T}\mathbf y,\\ \cos\theta&=\frac{\mathbf x^{\mathsf T}\mathbf y}{\|\mathbf x\|\,\|\mathbf y\|}. \end{aligned} \]

บรรทัดแรกคือกฎโคไซน์ บรรทัดสองกับสามกระจายผลคูณด้วยคุณสมบัติจากขั้นก่อน ($\mathbf x^{\mathsf T}\mathbf y=\mathbf y^{\mathsf T}\mathbf x$ จึงรวมพจน์ไขว้เป็น $2\mathbf x^{\mathsf T}\mathbf y$) สองบรรทัดนี้คือความยาวด้านเดียวกัน ตัดส่วนที่เหมือนกันทิ้งได้บรรทัดสุดท้าย (หน้านี้ $\|\cdot\|$ หมายถึง L2 เสมอ) dot product บวกคือมุมแหลม ศูนย์คือมุมฉาก ลบคือมุมป้าน ถ้า vector ใดเป็นศูนย์ ไม่มีทิศให้วัด มุมจึงไม่มีนิยาม อย่าแทนด้วยศูนย์องศา

ตัวอย่างในรูปถัดไป: $\mathbf x=(3,1)$, $\mathbf y=(1,2)$ ได้ $\mathbf x^{\mathsf T}\mathbf y=5$, $\|\mathbf x\|=\sqrt{10}$, $\|\mathbf y\|=\sqrt5$ cosine $=5/\sqrt{50}\approx0.707$ คือ 45 องศา ตรวจกับกฎโคไซน์: $\mathbf x-\mathbf y=(2,-1)$ ยาวกำลังสอง 5 และ $10+5-2(5)=5$ ตรงกัน

ขั้นที่ 3 — Cauchy–Schwarz: ทำไม cosine ไม่หลุดช่วง

สูตรมุมใช้ได้ก็ต่อเมื่อเศษส่วนอยู่ระหว่าง −1 ถึง 1 เสมอ ในมิติสูงเรามองไม่เห็นสามเหลี่ยม จึงต้องพิสูจน์ด้วยพีชคณิต ใช้ความจริงง่าย ๆ ว่าความยาวกำลังสองไม่ติดลบ

\[ \begin{aligned} 0&\le\|\mathbf x-t\mathbf y\|^2\\ &=\|\mathbf x\|^2-2t\,\mathbf x^{\mathsf T}\mathbf y+t^2\|\mathbf y\|^2,\\ t&=\frac{\mathbf x^{\mathsf T}\mathbf y}{\|\mathbf y\|^2},\\ 0&\le\|\mathbf x\|^2-\frac{(\mathbf x^{\mathsf T}\mathbf y)^2}{\|\mathbf y\|^2},\\ |\mathbf x^{\mathsf T}\mathbf y|&\le\|\mathbf x\|\,\|\mathbf y\|. \end{aligned} \]

บรรทัดแรกจริงสำหรับทุก $t$ เพราะเป็นความยาวกำลังสอง เราเลือก $t$ ตัวที่ทำให้ด้านขวาเล็กที่สุด (จุดต่ำสุดของพาราโบลาใน $t$) แทนลงไปได้บรรทัดสี่ คูณ $\|\mathbf y\|^2$ แล้วถอดรากได้ Cauchy–Schwarz ดังนั้น $-1\le\cos\theta\le1$ เสมอ และเท่ากับปลายช่วงเฉพาะเมื่อ $\mathbf x-t\mathbf y=\mathbf 0$ คือสอง vector อยู่บนเส้นเดียวกัน $t$ ตัวนี้จะกลับมาอีกครั้งในฐานะ hedge ratio

ขั้นที่ 4 — correlation คือ cosine หลังหักค่าเฉลี่ย

นิยามทางสถิติของ sample correlation คือ covariance หารด้วยผลคูณ standard deviation ขั้นนี้แสดงว่าถ้าเขียนข้อมูลที่หักค่าเฉลี่ยแล้วเป็น vector สูตรนี้คือ cosine พอดี ให้ $x_i=a_i-\bar a$ และ $y_i=b_i-\bar b$ สำหรับ $n\ge2$ วัน

\[ \begin{aligned} s_{xy}&=\frac{\sum_ix_iy_i}{n-1}=\frac{\mathbf x^{\mathsf T}\mathbf y}{n-1},\\ s_x&=\frac{\|\mathbf x\|}{\sqrt{n-1}},\quad s_y=\frac{\|\mathbf y\|}{\sqrt{n-1}},\\ \hat\rho&=\frac{s_{xy}}{s_xs_y} =\frac{\mathbf x^{\mathsf T}\mathbf y}{\|\mathbf x\|\,\|\mathbf y\|}=\cos\theta. \end{aligned} \]

ตัวหาร $n-1$ ในเศษกับส่วนตัดกันพอดี จึงเหลือ cosine ล้วน ๆ แต่การตัดนี้ไม่ได้ทำให้ข้ามการหักค่าเฉลี่ยได้ โจทย์ต้นหน้า: ข้อมูลดิบ $\mathbf a^{\mathsf T}\mathbf b=10$, $\|\mathbf a\|^2=\|\mathbf b\|^2=14$ ได้ cosine $10/14\approx0.714$ (44 องศา) หลังหักค่าเฉลี่ย $\mathbf x=(-1,0,1)$, $\mathbf y=(1,0,-1)$ ได้ $\mathbf x^{\mathsf T}\mathbf y=-2$, $\|\mathbf x\|^2=\|\mathbf y\|^2=2$ ได้ $\hat\rho=-1$

ทำไมต้องหัก: vector $\mathbf a$ แยกได้เป็น $\bar a(1,\ldots,1)+\mathbf x$ ส่วนแรกคือเงาของ $\mathbf a$ บนทิศ “ทุกวันเท่ากัน” ส่วนที่สองตั้งฉากกับทิศนั้น (ผลรวมของ $x_i$ เป็นศูนย์) ถ้าสองหุ้นมีค่าเฉลี่ยเป็นบวกทั้งคู่ ส่วนแรกจะดันมุมให้แคบลงโดยไม่เกี่ยวกับว่าวันไหนดีวันไหนแย่ตามกัน รูปต้นหน้าคือภาพนี้ ถ้าข้อมูลชุดใดคงที่ทุกวัน $\mathbf x=\mathbf 0$ standard deviation เป็นศูนย์ และ correlation ไม่มีนิยาม

ขั้นที่ 5 — มุม 60, 90 และ 150 องศาจากข้อมูลสามวัน

ข้อมูลสามวันที่หักค่าเฉลี่ยแล้วทุกชุดอยู่บนระนาบเดียวกัน (ระนาบที่ตั้งฉากกับ $(1,1,1)$) จึงวาดมุมจริงในสองมิติได้ ขั้นนี้คำนวณมุมของสี่ชุดเทียบกับชุดแรก

โจทย์ให้อะไรมาบ้าง: หน่วยเป็นจุดเปอร์เซ็นต์ ทุกชุดเฉลี่ยศูนย์อยู่แล้ว $\mathbf x=(1,-1,0)$, $\mathbf y=(1,0,-1)$, $\mathbf z=(1,1,-2)$, $\mathbf u=(-1,2,-1)$

\[ \begin{aligned} \mathbf x^{\mathsf T}\mathbf y&=1,\quad \|\mathbf x\|^2=\|\mathbf y\|^2=2,\\ \hat\rho_{xy}&=\frac{1}{\sqrt2\sqrt2}=0.5,\quad \theta=60^\circ,\\ \mathbf x^{\mathsf T}\mathbf z&=1-1+0=0,\quad \theta=90^\circ,\\ \mathbf x^{\mathsf T}\mathbf u&=-1-2+0=-3,\\ \hat\rho_{xu}&=\frac{-3}{\sqrt2\sqrt6}=-\frac{\sqrt3}{2}\approx-0.866,\quad \theta=150^\circ. \end{aligned} \]

คำตอบ: correlation 0.5, 0 และ −0.866 คือมุม 60, 90 และ 150 องศา covariance ของคู่แรกคือ $1/(3-1)=0.5$ และ standard deviation ทั้งคู่คือ $\sqrt{2/2}=1$ จึงได้ 0.5 ตรงกับ cosine

ตรวจเองใน 10 วินาที: $\cos60^\circ=0.5$, $\cos90^\circ=0$, $\cos150^\circ=-0.866$

ขั้นที่ 6 — อ่าน correlation จริงจาก covariance matrix ของสินทรัพย์แปดกลุ่ม

งานจริงไม่ค่อยเริ่มจากผลตอบแทนรายวัน แต่เริ่มจาก covariance matrix ที่ประมาณไว้แล้ว ความสัมพันธ์ $\sigma_{ij}=\rho_{ij}\sigma_i\sigma_j$ กลับด้านได้เป็น $\rho_{ij}=\sigma_{ij}/(\sigma_i\sigma_j)$ ตัวเลขต่อไปนี้มาจาก covariance matrix รายปีใน workbook ของคอร์สเรื่อง mean-variance

โจทย์ให้อะไรมาบ้าง: variance ของ US Large Growth 0.059852 ของ US Small Growth 0.102488 ของ US Bonds 0.001005 covariance ระหว่าง Large Growth กับ Small Growth 0.063497 ระหว่าง Large Growth กับ Bonds −0.000579

\[ \begin{aligned} \sigma_{LG}&=\sqrt{0.059852}=24.46\%,\quad \sigma_{SG}=32.01\%,\\ \rho_{LG,SG}&=\frac{0.063497}{0.2446(0.3201)}\approx0.811,\\ \theta&=\arccos0.811\approx35.8^\circ,\\ \rho_{LG,B}&=\frac{-0.000579}{0.2446(0.0317)}\approx-0.075,\\ \theta&\approx94.3^\circ. \end{aligned} \]

คำตอบ: หุ้นใหญ่สายเติบโตกับหุ้นเล็กสายเติบโตชี้ห่างกันแค่ 36 องศา ส่วน bond สหรัฐเกือบตั้งฉากกับหุ้น (94 องศา) correlation −0.075 ใกล้ศูนย์มาก นี่คือเหตุผลเชิงเรขาคณิตที่ bond ช่วยกระจายความเสี่ยงของพอร์ตหุ้นได้ดีในข้อมูลชุดนี้

ขั้นที่ 7 — ความเสี่ยงของพอร์ตสองสินทรัพย์คือความยาวของผลบวกลูกศร

ถ้าสินทรัพย์เป็นลูกศรที่ยาวเท่าความผันผวนและทำมุม $\arccos\rho$ กัน พอร์ตก็เป็นผลบวกของลูกศรที่ย่อตามน้ำหนัก ความผันผวนของพอร์ตคือความยาวของผลบวกนั้น ใช้ตัวอย่างสองสินทรัพย์จากคอร์ส: variance 0.1 กับ 0.5 correlation 0.25 ถือ $x$ ในตัวแรกและ $1-x$ ในตัวที่สอง

\[ \begin{aligned} \sigma_{12}&=\rho\,\sigma_1\sigma_2=0.25\sqrt{0.1(0.5)}\approx0.0559,\\ \sigma_p^2&=x^2\sigma_1^2+(1-x)^2\sigma_2^2\\ &\quad+2x(1-x)\sigma_{12},\\ x=0.5:\ \sigma_p^2&=0.025+0.125+0.02795\\ &=0.17795,\quad \sigma_p\approx0.4218. \end{aligned} \]

สูตร variance ของพอร์ตคือ $\|x\mathbf v_1+(1-x)\mathbf v_2\|^2$ ที่กระจายด้วย dot product: กำลังสองของสองลูกศรบวกพจน์ไขว้ $2x(1-x)\,\mathbf v_1^{\mathsf T}\mathbf v_2$ และ $\mathbf v_1^{\mathsf T}\mathbf v_2=\|\mathbf v_1\|\|\mathbf v_2\|\cos\theta=\sigma_1\sigma_2\rho=\sigma_{12}$ พจน์ไขว้จึงเป็น covariance พอดี ไม่ใช่เรื่องบังเอิญ

ลูกศรครึ่งหนึ่งยาว $0.5\sqrt{0.1}=0.158$ กับ $0.5\sqrt{0.5}=0.354$ ถ้าชี้ทางเดียวกัน ($\rho=1$) ความยาวรวมคือ $0.158+0.354=0.512$ ถ้าตั้งฉาก ($\rho=0$) คือ $\sqrt{0.025+0.125}=0.387$ ถ้าตรงข้าม ($\rho=-1$) เหลือ $0.354-0.158=0.195$ ที่ $\rho=0.25$ ได้ 0.422 การกระจายความเสี่ยงช่วยมากแค่ไหนจึงขึ้นกับมุม: ยิ่งมุมกว้าง ผลบวกยิ่งสั้นกว่าผลรวมความยาว

ขั้นที่ 8 — projection หา hedge ที่ทำให้ส่วนเหลือสั้นที่สุด

ถือ basket ที่ผลตอบแทนหักค่าเฉลี่ยแล้วคือ $\mathbf x$ และจะ short เครื่องมือ hedge ที่ผลตอบแทนหักค่าเฉลี่ยแล้วคือ $\mathbf y$ เป็นสัดส่วน $h$ ของ basket ผลที่เหลือคือ $\mathbf e=\mathbf x-h\mathbf y$ เลือก $h$ ให้ความยาวกำลังสองของ $\mathbf e$ (คือ sample variance คูณ $n-1$) ต่ำที่สุด

\[ \begin{aligned} \|\mathbf x-h\mathbf y\|^2&=\|\mathbf x\|^2-2h\,\mathbf x^{\mathsf T}\mathbf y+h^2\|\mathbf y\|^2,\\ h^*&=\frac{\mathbf x^{\mathsf T}\mathbf y}{\|\mathbf y\|^2}=\frac{s_{xy}}{s_y^2}=\hat\rho\,\frac{s_x}{s_y},\\ \mathbf e^{\mathsf T}\mathbf y&=\mathbf x^{\mathsf T}\mathbf y-h^*\|\mathbf y\|^2=0,\\ s_e^2&=s_x^2-\frac{s_{xy}^2}{s_y^2}=s_x^2\big(1-\hat\rho^2\big). \end{aligned} \]

บรรทัดแรกเป็นพาราโบลาใน $h$ อนุพันธ์ $-2\mathbf x^{\mathsf T}\mathbf y+2h\|\mathbf y\|^2=0$ ให้ $h^*$ ในบรรทัดสอง ซึ่งคือ $t$ ตัวเดียวกับในการพิสูจน์ Cauchy–Schwarz หาร $n-1$ ทั้งเศษและส่วนได้รูปสถิติ บรรทัดสามบอกว่าที่ $h^*$ ส่วนเหลือตั้งฉากกับ hedge พอดี: ถ้ายังไม่ตั้งฉาก แปลว่ายังมีส่วนที่ชี้ตาม $\mathbf y$ ให้ตัดเพิ่มได้ บรรทัดสุดท้ายแทน $h^*$ กลับ ได้ variance ที่เหลือเป็นสัดส่วน $1-\hat\rho^2$ ของเดิม

ตัวอย่างสามวัน $\mathbf x=(1,-1,0)$, $\mathbf y=(1,0,-1)$: $h^*=1/2$, $\mathbf e=(0.5,-1,0.5)$ ตรวจ $\mathbf e^{\mathsf T}\mathbf y=0.5-0.5=0$ และ $\|\mathbf e\|^2=1.5=2(1-0.5^2)$ ถ้าใช้ $h=1$ แทน ส่วนเหลือคือ $(0,-1,1)$ ยาวกำลังสอง 2 ยาวกว่า

ขั้นที่ 9 — beta คือ projection: hedge หุ้นเล็กด้วยหุ้นใหญ่

regression ของผลตอบแทนส่วนเกินของสินทรัพย์ $j$ บนผลตอบแทนส่วนเกินของตลาด ให้ค่าสัมประสิทธิ์ $\beta_j=\operatorname{cov}(r_j,r_m)/\operatorname{var}(r_m)$ ซึ่งคือ $h^*$ ตัวเดียวกัน residual ไม่สัมพันธ์กับตลาด (ตั้งฉาก) และความเสี่ยงแยกเป็นสองส่วนแบบพีทาโกรัส: $\sigma_j^2=\beta_j^2\sigma_m^2+\operatorname{var}(\varepsilon)$ ตาม CAPM ขั้นนี้ใช้ตัวเลขจริงจาก covariance matrix ชุดเดิม

โจทย์ให้อะไรมาบ้าง: long US Small Growth \$12 ล้าน และ hedge ด้วย US Large Growth ใช้ variance และ covariance รายปี 0.102488, 0.059852, 0.063497 จากขั้นอ่าน correlation ด้านบน

\[ \begin{aligned} \beta&=\frac{0.063497}{0.059852}\approx1.061,\\ \hat\rho^2&=0.811^2\approx0.657,\\ \sigma_e&=0.3201\sqrt{1-0.657}\approx18.74\%,\\ \beta\sigma_{LG}&=1.061(24.46\%)\approx25.95\%,\\ 25.95^2+18.74^2&\approx32.01^2. \end{aligned} \]

คำตอบ: short US Large Growth $1.061\times\$12$ ล้าน $\approx\$12.73$ ล้าน ความผันผวนลดจาก 32.01% เหลือ 18.74% ต่อปี variance หายไป 65.7% แต่ความผันผวนลดลงแค่ 41.5% เพราะความผันผวนคือรากของ variance บรรทัดสุดท้ายคือพีทาโกรัส: ส่วนที่ตลาดอธิบายได้กับส่วนเหลือตั้งฉากกัน กำลังสองจึงบวกกันได้พอดี

ตัวเลขนี้เป็นค่าประมาณจากข้อมูลในอดีต covariance ในอนาคตเปลี่ยนได้ โดยเฉพาะช่วงตลาดตึงเครียดที่ correlation มักสูงขึ้น และยังมีต้นทุนการ short ค่าซื้อขาย และการปรับ hedge เมื่อราคาเปลี่ยน

ความผิดที่ทำให้อ่านมุมผิด

ไม่หักค่าเฉลี่ย: โจทย์ต้นหน้า cosine ของข้อมูลดิบคือ 0.714 แต่ correlation คือ −1 ทิศของคำตอบกลับกันเลย

ตั้งฉากไม่ได้แปลว่าเป็นอิสระ: ให้ $X$ เป็น −1, 0, 1 อย่างละหนึ่งในสาม และ $Y=X^2$ จะได้ $E[X]=0$ และ $E[XY]=E[X^3]=0$ covariance จึงเป็นศูนย์ แต่รู้ $X$ ก็รู้ $Y$ ทันที correlation ศูนย์บอกแค่ว่าไม่มีความสัมพันธ์แบบเส้นตรง (ดูต่อใน zero covariance is not independence)

ใช้ correlation เป็น hedge ratio: correlation ของหุ้นเล็กกับหุ้นใหญ่คือ 0.811 แต่ hedge ratio คือ 1.061 ต้องคูณอัตราส่วนความผันผวน $32.01/24.46$ ด้วย ถ้าใช้ 0.811 จะ hedge ขาดไปราว \$3 ล้านบนสถานะ \$12 ล้าน

สับสนการลด variance กับการลดความผันผวน: variance ลด 65.7% แต่ความผันผวนลด 41.5% รายงานว่า “ความเสี่ยงลดสองในสาม” จึงเกินจริง

คิดว่า $\hat\rho$ เป็นลบแปลว่าต้อง short hedge มากขึ้น: ถ้า $\hat\rho\lt0$ จะได้ $h^*\lt0$ ซึ่งแปลว่าต้อง long เครื่องมือ hedge เพราะ residual นิยามเป็น $\mathbf x-h\mathbf y$

ใช้ทำอะไรบนโต๊ะจริง

ทุกครั้งที่โต๊ะ hedge พอร์ตหุ้นด้วย index future หรือ ETF ขนาดที่ใช้คือ beta ซึ่งคือ projection ของหน้านี้ ตัวเลขที่ต้องรายงานคู่กันเสมอคือ $1-\hat\rho^2$ ซึ่งบอกว่ายังเหลือความเสี่ยงเท่าไรหลัง hedge เมื่อมีเครื่องมือ hedge หลายตัว หลักเดียวกันขยายเป็นการ project ลงบน span ของหลายทิศพร้อมกัน ซึ่งคือ OLS regression และ Frisch–Waugh–Lovell ส่วนการเก็บ correlation ของทุกคู่ไว้ในตารางเดียวคือ covariance matrix ใน mean vector และ covariance matrix

คำนวณซ้ำด้วย JavaScript

สคริปต์หักค่าเฉลี่ยก่อนเสมอ ปฏิเสธข้อมูลคงที่ แล้วคำนวณ correlation มุม hedge ratio และ residual รวมถึงตัวเลขจาก covariance matrix ของคอร์ส

เปิดดูโค้ด 
const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);
const center = a => { const m = a.reduce((s, x) => s + x, 0) / a.length; return a.map(x => x - m); };
const cosine = (a, b) => {
  const na = Math.sqrt(dot(a, a)), nb = Math.sqrt(dot(b, b));
  if (na === 0 || nb === 0) throw new RangeError('angle undefined for a zero vector');
  return Math.max(-1, Math.min(1, dot(a, b) / (na * nb)));
};
function stats(a, b) {
  if (a.length !== b.length || a.length < 2) throw new RangeError('need matching pairs');
  const x = center(a), y = center(b), rho = cosine(x, y), h = dot(x, y) / dot(y, y);
  const e = x.map((v, i) => v - h * y[i]);
  return {rho, degrees: Math.acos(rho) * 180 / Math.PI, h, e, eDotY: dot(e, y), ee: dot(e, e)};
}
const deg = c => Math.acos(c) * 180 / Math.PI;
// course covariance matrix entries (annual)
const vLG = 0.059852, vSG = 0.102488, vB = 0.001005, cLGSG = 0.063497, cLGB = -0.000579;
const rhoSG = cLGSG / Math.sqrt(vLG * vSG), rhoB = cLGB / Math.sqrt(vLG * vB);
const beta = cLGSG / vLG, residVol = Math.sqrt(vSG * (1 - rhoSG ** 2));
const s1 = Math.sqrt(0.1), s2 = Math.sqrt(0.5), s12 = 0.25 * s1 * s2;
console.log({
  rawCosine: cosine([1, 2, 3], [3, 2, 1]), hook: stats([1, 2, 3], [3, 2, 1]),
  three: stats([1, -1, 0], [1, 0, -1]),
  angles: [[1, 0, -1], [1, 1, -2], [-1, 2, -1]].map(v => deg(cosine([1, -1, 0], v))),
  rhoSG, angleSG: deg(rhoSG), rhoB, angleB: deg(rhoB),
  portfolioSD: Math.sqrt(0.25 * 0.1 + 0.25 * 0.5 + 2 * 0.25 * s12),
  beta, residVol, volCut: 1 - residVol / Math.sqrt(vSG), shortDollars: 12e6 * beta,
  fiveDay: stats([1.2, -0.8, 0.5, -1.5, 0.6], [0.9, -0.3, 1.1, -1.2, -0.5])
});

สิ่งที่ควรตอบได้หลังอ่าน

  • $\cos\theta=\mathbf x^{\mathsf T}\mathbf y/(\|\mathbf x\|\|\mathbf y\|)$ มาจากการเทียบกฎโคไซน์กับการกระจาย dot product และ Cauchy–Schwarz รับประกันว่าอยู่ระหว่าง −1 ถึง 1
  • sample correlation คือ cosine ของข้อมูลที่หักค่าเฉลี่ยแล้ว ไม่หักจะได้ 0.714 แทน −1 ในโจทย์ต้นหน้า
  • อ่าน correlation จาก covariance matrix ด้วย $\rho_{ij}=\sigma_{ij}/(\sigma_i\sigma_j)$: หุ้นใหญ่กับหุ้นเล็กสายเติบโตห่างกัน 36 องศา bond เกือบตั้งฉากกับหุ้น
  • ความผันผวนของพอร์ตคือความยาวของผลบวกลูกศร พจน์ covariance คือ dot product ของลูกศร ยิ่งมุมกว้างยิ่งกระจายความเสี่ยงได้มาก
  • hedge ที่ดีที่สุดคือ projection: $h^*=s_{xy}/s_y^2$ ส่วนเหลือตั้งฉาก และ variance เหลือ $1-\hat\rho^2$ (beta 1.061 ตัด variance 65.7% แต่ตัดความผันผวนแค่ 41.5%)
