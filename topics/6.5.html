6.5 Inner Product, Angle, and Correlation

Correlation คือ cosine ของมุมระหว่างสองชุดผลตอบแทนหลังหักค่าเฉลี่ย และขนาด hedge ที่ดีที่สุดคือเงาของชุดหนึ่งที่ตกบนอีกชุด

นักลงทุนคนหนึ่งถือหุ้น A อยู่ และกลัวว่าราคาจะร่วง เขาจึงมองหาหุ้นอีกตัวที่มักขยับสวนทางกับ A มาถือคู่กัน วันที่ A ขาดทุน อีกตัวจะได้กำไรมาชดเชย การจับคู่แบบนี้เรียกว่า hedge (ถือของอีกตัวไว้กันความเสี่ยง) ตัวเลขที่ใช้ดูว่าสองหุ้นขยับตามกันหรือสวนกันคือ correlation ซึ่งเป็นตัวเลขระหว่าง −1 ถึง 1 ค่า 1 แปลว่าขึ้นลงพร้อมกันเสมอ ค่า −1 แปลว่าสวนกันเสมอ

ของที่รู้คือผลตอบแทนรายวันของสองหุ้นในสามวันเดียวกัน (ตัวเลขสมมติ) ผลตอบแทนรายวันคือราคาเปลี่ยนไปกี่เปอร์เซ็นต์ในวันนั้น

  • หุ้น A: 1%, 2%, 3%
  • หุ้น B: 3%, 2%, 1%

นักวิเคราะห์เห็นว่าทั้งคู่บวกทุกวัน เขาจึงเอาผลตอบแทนวันเดียวกันมาคูณกัน แล้วบวกทั้งสามวัน:

\[ 1\times3+2\times2+3\times1=3+4+3=10 \]

ผลรวมออกมาเป็นบวก เขาจึงสรุปว่า “สองตัวนี้ไปทางเดียวกัน ใช้ B hedge A ไม่ได้” สรุปนี้ถูกไหม และ correlation ของสองชุดนี้เท่าไร

ลองตอบก่อนเปิดเฉลย

สรุปผิด ต้องดูว่าแต่ละวันดีกว่าหรือแย่กว่าค่าเฉลี่ยของตัวเอง ไม่ใช่ดูว่าบวกหรือลบ ทั้งสองชุดมีค่าเฉลี่ยเท่ากัน

\[ \bar a=\frac{1+2+3}{3}=2,\qquad \bar b=\frac{3+2+1}{3}=2 \]

หักค่าเฉลี่ยออกจากทุกวัน A เหลือ $(-1,0,1)$ และ B เหลือ $(1,0,-1)$ วันแรก A แย่กว่าปกติ 1 แต่ B ดีกว่าปกติ 1 วันที่สามกลับกัน สองชุดนี้สวนกันพอดีทุกวัน correlation จึงเป็น −1 ซึ่งเป็นคู่ hedge ที่ดีที่สุดเท่าที่เป็นไปได้

ตัวเลข 10 ที่เป็นบวกมาจากค่าเฉลี่ย 2% ที่ทั้งคู่มีเหมือนกัน ไม่ได้มาจากการขยับตามกัน ถ้ามองแต่ละชุดเป็นลูกศร ความยาวของลูกศร A คือ $\sqrt{1^2+2^2+3^2}=\sqrt{14}$ และ B ยาวเท่ากัน เอา 10 หารด้วยความยาวสองตัวคูณกัน (หน้านี้จะอธิบายว่าทำไมต้องหาร) จะได้ $10/(\sqrt{14}\times\sqrt{14})=10/14\approx0.71$ ตัวเลขนี้ตอบคำถามอื่น คือ “ทั้งคู่บวกพร้อมกันไหม”

ภาพรวมก่อนลงสูตร

หน้า norms วัดว่า vector หนึ่งตัวยาวแค่ไหน หน้านี้ถามต่อว่า vector สองตัวชี้ไปทางเดียวกันแค่ไหน เครื่องมือคือ inner product หรือ dot product ตัวเดิมจากหน้า row และ column vectors วิธีคิดคือเอาตัวเลขช่องเดียวกันมาคูณกัน แล้วบวกทุกช่อง เช่น $(1,2)$ กับ $(3,4)$ ได้ $1\times3+2\times4=11$ เอาผลนี้หารด้วยความยาวของ vector ทั้งสอง จะได้ cosine ของมุมระหว่างมัน

เรื่องนี้เกี่ยวกับการเงินเพราะผลตอบแทนหลายวันเขียนเป็น vector ได้ คือช่องที่ 1 เป็นวันที่ 1 ช่องที่ 2 เป็นวันที่ 2 ไปเรื่อย ๆ ถ้าหักค่าเฉลี่ยของแต่ละชุดออกก่อน แล้วหา cosine ของมุม จะได้ sample correlation พอดี (correlation ที่คำนวณจากข้อมูลจริงชุดหนึ่ง) การหักค่าเฉลี่ยก็มีภาพทางเรขาคณิต คือการตัดส่วนของลูกศรที่ชี้ไปทาง “ทุกวันเท่ากัน” ทิ้ง รูปด้านล่างแสดงว่าทำไมโจทย์ต้นหน้าจึงเปลี่ยนจากมุมแคบ 44 องศาเป็นมุมตรงข้าม 180 องศา

หน้านี้ทำทีละขั้นดังนี้

  • ทวน dot product แล้วพิสูจน์ว่าทำไมมันบอกมุมได้ และทำไม cosine ไม่มีวันหลุดช่วง −1 ถึง 1
  • แสดงว่า correlation คือ cosine ของข้อมูลที่หักค่าเฉลี่ยแล้ว
  • อ่าน correlation จริงของสินทรัพย์แปดกลุ่มจาก workbook ของคอร์ส
  • ใช้ภาพลูกศรอธิบายว่าทำไมพอร์ตที่ถือสองสินทรัพย์จึงแกว่งน้อยกว่าผลรวมของแต่ละตัว
  • ใช้ projection (เงาของลูกศรหนึ่งที่ตกบนอีกลูกศร) หาขนาด hedge ที่ทำให้ความเสี่ยงที่เหลือน้อยที่สุด ขนาดนี้คือ beta ใน CAPM ซึ่งบอกว่าหุ้นตัวหนึ่งขยับกี่เท่าของตลาด
ศัพท์ที่ใช้ในหัวข้อนี้
Inner product (dot product)
เอาตัวเลขช่องเดียวกันของสอง vector มาคูณกัน แล้วบวกทุกช่อง เขียนว่า $\mathbf x^{\mathsf T}\mathbf y=\sum_ix_iy_i$ เช่น $(1,2)$ กับ $(3,4)$ ได้ $1\times3+2\times4=11$ ใช้วัดว่าสอง vector ไปทางเดียวกันแค่ไหน และถ้าทำกับตัวเองจะได้ความยาวกำลังสอง $\|\mathbf x\|^2=\mathbf x^{\mathsf T}\mathbf x$
Orthogonal (ตั้งฉาก)
สอง vector ที่ dot product เป็นศูนย์ เช่น $(1,2)$ กับ $(2,-1)$ ได้ $1\times2+2\times(-1)=0$ ถ้าเป็นข้อมูลที่หักค่าเฉลี่ยแล้ว ตั้งฉากแปลว่า sample correlation เป็นศูนย์
Centering (หักค่าเฉลี่ย)
ลบค่าเฉลี่ยของชุดตัวเองออกจากทุกค่า เช่น $(1,2,3)$ มีค่าเฉลี่ย 2 จึงเหลือ $(-1,0,1)$ ผลรวมหลังหักเป็นศูนย์เสมอ ซึ่งแปลว่า vector ตั้งฉากกับทิศ $(1,1,\ldots,1)$ ต้องทำขั้นนี้ก่อนจะอ่าน cosine เป็น correlation
Variance และ standard deviation (SD)
variance คือค่าเฉลี่ยของกำลังสองของระยะห่างจากค่าเฉลี่ย SD คือรากที่สองของ variance จึงมีหน่วยเดียวกับข้อมูล ในการเงิน SD ของผลตอบแทนเรียกว่าความผันผวน (volatility)
Covariance
ค่าเฉลี่ยของผลคูณ (ระยะห่างจากค่าเฉลี่ยของตัวหนึ่ง) คูณ (ระยะห่างจากค่าเฉลี่ยของอีกตัว) เป็นบวกเมื่อสองตัวมักอยู่เหนือค่าเฉลี่ยพร้อมกัน เป็นลบเมื่อตัวหนึ่งมักอยู่เหนือขณะที่อีกตัวอยู่ใต้
Correlation
covariance หารด้วย SD ของสองตัวคูณกัน หน้านี้จะแสดงว่ามันเท่ากับ cosine ของมุมระหว่างข้อมูลที่หักค่าเฉลี่ยแล้ว จึงอยู่ระหว่าง −1 ถึง 1 เสมอ วัดได้เฉพาะการขยับตามกันแบบเส้นตรง
Projection
ส่วนของ vector หนึ่งที่ชี้ไปตามทิศของอีก vector หนึ่ง เหมือนเงาที่ตกลงบนเส้นเมื่อส่องไฟตั้งฉากลงมา ใช้หาว่า hedge ตัดความเสี่ยงออกได้เท่าไร
Residual (ส่วนเหลือ)
สิ่งที่เหลือหลังลบ projection ออก มันตั้งฉากกับทิศของเครื่องมือ hedge จึงเป็นความเสี่ยงที่ hedge ตัวนั้นเอาออกไม่ได้
Long และ short
long คือซื้อถือไว้ ได้กำไรเมื่อราคาขึ้น short คือยืมของมาขายก่อนแล้วซื้อคืนทีหลัง ได้กำไรเมื่อราคาลง
Hedge ratio และ beta
hedge ratio $h$ คือจำนวนดอลลาร์ของเครื่องมือ hedge ที่ short ต่อพอร์ตหนึ่งดอลลาร์ ค่าที่ดีที่สุดคือ $h=\operatorname{cov}(x,y)/\operatorname{var}(y)$ ซึ่งทำให้ variance ของ $x-hy$ ต่ำสุด ถ้า $y$ คือตลาด ตัวเลขนี้เรียกว่า beta

ขั้นที่ 1 — inner product: จับคู่ช่องแล้วบวก

ทุกขั้นในหน้านี้ใช้การคำนวณแบบเดียว คือคูณช่องต่อช่องแล้วบวก ขั้นแรกจึงทวนนิยามของมัน และกฎสามข้อที่ขั้นถัด ๆ ไปต้องใช้ ในสูตรข้างล่าง $\mathbf x,\mathbf y,\mathbf z$ คือ vector ที่มี $n$ ช่องเท่ากัน $x_i$ คือตัวเลขช่องที่ $i$ ของ $\mathbf x$ และ $a,b$ คือตัวเลขธรรมดาสองตัว

\[ \begin{aligned} \mathbf x^{\mathsf T}\mathbf y&=\sum_{i=1}^nx_iy_i,\\ \mathbf x^{\mathsf T}\mathbf y&=\mathbf y^{\mathsf T}\mathbf x,\\ \mathbf x^{\mathsf T}(a\mathbf y+b\mathbf z)&=a\,\mathbf x^{\mathsf T}\mathbf y+b\,\mathbf x^{\mathsf T}\mathbf z,\\ \mathbf x^{\mathsf T}\mathbf x&=\|\mathbf x\|^2. \end{aligned} \]

สลับลำดับ $\mathbf x$ กับ $\mathbf y$ ได้ เพราะในแต่ละช่อง $x_iy_i=y_ix_i$ ดึงตัวเลข $a$ และ $b$ ออกมานอกวงเล็บได้ เพราะ dot product เป็นแค่ผลบวกของผลคูณ ส่วน dot product ของ vector กับตัวเองคือผลรวมกำลังสองของทุกช่อง ซึ่งก็คือความยาวกำลังสองแบบที่หน้า norms เรียกว่า L2 (หน้านี้ $\|\cdot\|$ หมายถึงความยาวแบบนี้เสมอ)

ความยาวกำลังสองเป็นบวกเสมอ ยกเว้น vector ที่เป็นศูนย์ทุกช่อง แต่ dot product ของสอง vector ที่ต่างกันเป็นบวก ศูนย์ หรือลบก็ได้ เครื่องหมายนี้เองที่บอกทิศ เช่น $(1,2)^{\mathsf T}(3,4)=3+8=11$ เป็นบวก ส่วน $(1,2)^{\mathsf T}(2,-1)=2-2=0$ ขั้นถัดไปจะแสดงว่าศูนย์แปลว่าตั้งฉาก

เมื่อช่องคือวันซื้อขาย ต้องจับคู่วันเดียวกันก่อนคูณ ถ้าวันไหนข้อมูลของตัวใดตัวหนึ่งขาด ต้องตัดวันนั้นทิ้งทั้งคู่ ถ้าเติมวันที่ขาดด้วยศูนย์ หรือเลื่อนวันผิดไปหนึ่งวัน สูตรยังคำนวณออกมาได้ แต่ตัวเลขที่ได้ตอบคำถามอื่น

ขั้นที่ 2 — ทำไม dot product บอกมุมได้

ตอนนี้เรามีตัวเลขหนึ่งตัวคือ dot product แต่สิ่งที่อยากรู้คือมุม $\theta$ ระหว่างสองลูกศร สะพานที่เชื่อมสองอย่างนี้คือสามเหลี่ยมที่มีสามด้านเป็น $\mathbf x$, $\mathbf y$ และ $\mathbf x-\mathbf y$ (ลูกศรจากปลาย $\mathbf y$ ไปปลาย $\mathbf x$) ความยาวของด้านที่สาม $\|\mathbf x-\mathbf y\|$ หาได้สองทาง ทางแรกคือกฎโคไซน์จากเรขาคณิตมัธยม ซึ่งมีมุมอยู่ในสูตร ทางที่สองคือกระจายด้วย dot product ซึ่งไม่มีมุมเลย ทั้งสองทางต้องได้ความยาวเดียวกัน จึงจับมาเท่ากันได้

\[ \begin{aligned} \|\mathbf x-\mathbf y\|^2&=\|\mathbf x\|^2+\|\mathbf y\|^2\\ &\quad-2\|\mathbf x\|\|\mathbf y\|\cos\theta,\\ \|\mathbf x-\mathbf y\|^2&=(\mathbf x-\mathbf y)^{\mathsf T}(\mathbf x-\mathbf y)\\ &=\|\mathbf x\|^2+\|\mathbf y\|^2-2\,\mathbf x^{\mathsf T}\mathbf y,\\ \cos\theta&=\frac{\mathbf x^{\mathsf T}\mathbf y}{\|\mathbf x\|\,\|\mathbf y\|}. \end{aligned} \]

สองสูตรแรกบอกความยาวด้านเดียวกัน และมี $\|\mathbf x\|^2+\|\mathbf y\|^2$ เหมือนกัน ส่วนที่เหลือจึงต้องเท่ากันด้วย: $\|\mathbf x\|\|\mathbf y\|\cos\theta=\mathbf x^{\mathsf T}\mathbf y$ หารด้วย $\|\mathbf x\|\|\mathbf y\|$ ก็ได้สูตรมุม จุดที่ต้องระวังคือตอนกระจาย $(\mathbf x-\mathbf y)^{\mathsf T}(\mathbf x-\mathbf y)$ จะได้พจน์ไขว้สองตัวคือ $-\mathbf x^{\mathsf T}\mathbf y$ กับ $-\mathbf y^{\mathsf T}\mathbf x$ ที่รวมเป็น $-2\,\mathbf x^{\mathsf T}\mathbf y$ ได้ เพราะกฎสลับลำดับจากขั้นก่อน

ความยาวเป็นบวกเสมอ เครื่องหมายของ cosine จึงมาจาก dot product ล้วน ๆ บวกคือมุมแหลม ศูนย์คือมุมฉาก ลบคือมุมป้าน ถ้า vector ตัวใดเป็นศูนย์ทุกช่อง มันไม่มีทิศให้วัด สูตรหารด้วยศูนย์ มุมจึงไม่มีนิยาม อย่าใส่ศูนย์องศาแทน

ลองกับตัวอย่างที่วาดในรูปถัดไป ให้ $\mathbf x=(3,1)$ และ $\mathbf y=(1,2)$

\[ \begin{aligned} \mathbf x^{\mathsf T}\mathbf y&=3\times1+1\times2=5,\\ \|\mathbf x\|&=\sqrt{3^2+1^2}=\sqrt{10},\\ \|\mathbf y\|&=\sqrt{1^2+2^2}=\sqrt5,\\ \cos\theta&=\frac{5}{\sqrt{10}\sqrt5}=\frac{5}{\sqrt{50}}\approx0.707,\\ \theta&=\arccos0.707=45^\circ. \end{aligned} \]

ตรวจกับกฎโคไซน์ ด้านที่สามคือ $\mathbf x-\mathbf y=(2,-1)$ ทั้งสองทางต้องได้ความยาวกำลังสองเท่ากัน

\[ \begin{aligned} \|\mathbf x-\mathbf y\|^2&=2^2+(-1)^2=5,\\ 10+5-2\,\mathbf x^{\mathsf T}\mathbf y&=10+5-2\times5=5. \end{aligned} \]

ขั้นที่ 3 — Cauchy–Schwarz: ทำไม cosine ไม่หลุดช่วง

สูตรมุมจากขั้นก่อนเป็นเศษส่วน และ cosine ของมุมใด ๆ อยู่ระหว่าง −1 ถึง 1 ถ้าเศษส่วนนี้ออกมาเป็น 1.2 ได้ สูตรก็ใช้ไม่ได้ ในสองหรือสามมิติเรามองเห็นสามเหลี่ยม จึงเชื่อได้ แต่ผลตอบแทนรายวันหนึ่งปีมีราว 252 ตัว (ตลาดหุ้นสหรัฐเปิดซื้อขายราว 252 วันต่อปี) จึงเป็น vector 252 มิติ ซึ่งมองไม่เห็นอะไรเลย จึงต้องพิสูจน์ด้วยพีชคณิตแทน ทริกที่ใช้มีข้อเดียว: ความยาวกำลังสองไม่มีวันติดลบ

ให้ $t$ เป็นตัวเลขอะไรก็ได้ แล้วดูความยาวของ $\mathbf x-t\mathbf y$ (สมมติว่า $\mathbf y$ ไม่ใช่ศูนย์ ถ้าเป็นศูนย์ ทั้งสองข้างของผลลัพธ์เป็นศูนย์ จริงอยู่แล้ว)

\[ \begin{aligned} 0&\le\|\mathbf x-t\mathbf y\|^2\\ &=\|\mathbf x\|^2-2t\,\mathbf x^{\mathsf T}\mathbf y+t^2\|\mathbf y\|^2,\\ t&=\frac{\mathbf x^{\mathsf T}\mathbf y}{\|\mathbf y\|^2},\\ 0&\le\|\mathbf x\|^2-2\frac{(\mathbf x^{\mathsf T}\mathbf y)^2}{\|\mathbf y\|^2}\\ &\quad+\frac{(\mathbf x^{\mathsf T}\mathbf y)^2}{\|\mathbf y\|^2}\\ &=\|\mathbf x\|^2-\frac{(\mathbf x^{\mathsf T}\mathbf y)^2}{\|\mathbf y\|^2},\\ (\mathbf x^{\mathsf T}\mathbf y)^2&\le\|\mathbf x\|^2\,\|\mathbf y\|^2,\\ |\mathbf x^{\mathsf T}\mathbf y|&\le\|\mathbf x\|\,\|\mathbf y\|. \end{aligned} \]

ความยาวกำลังสองของ $\mathbf x-t\mathbf y$ ไม่ติดลบสำหรับทุก $t$ ถ้าแสดงว่าแม้แต่ค่าที่เล็กที่สุดของมันก็ไม่ติดลบ เราจะได้เงื่อนไขที่แรงที่สุด เมื่อกระจายออกมา มันเป็นพาราโบลาใน $t$ ที่หงายขึ้น จุดต่ำสุดอยู่ที่อนุพันธ์เทียบกับ $t$ เป็นศูนย์: $-2\,\mathbf x^{\mathsf T}\mathbf y+2t\|\mathbf y\|^2=0$ แก้สมการได้ค่า $t$ ที่เขียนไว้ในกล่อง แทน $t$ นี้กลับเข้าไป พจน์กลางกับพจน์ท้ายรวมกันได้ เพราะมีส่วนเหมือนกัน แล้วคูณทั้งสองข้างด้วย $\|\mathbf y\|^2$ ซึ่งเป็นบวก เครื่องหมาย $\le$ จึงไม่กลับ ถอดรากแล้วได้อสมการ Cauchy–Schwarz

หารทั้งสองข้างด้วย $\|\mathbf x\|\|\mathbf y\|$ ได้ $-1\le\cos\theta\le1$ เสมอ ไม่ว่า vector จะมีกี่มิติ cosine จะเท่ากับ 1 หรือ −1 ได้ก็ต่อเมื่อ $\mathbf x-t\mathbf y=\mathbf 0$ คือ $\mathbf x$ เป็นตัวคูณของ $\mathbf y$ สองลูกศรอยู่บนเส้นเดียวกัน ตัวอย่างขั้นก่อนตรวจได้: $|5|\le\sqrt{10}\sqrt5=\sqrt{50}\approx7.07$ จริง จำ $t$ ตัวนี้ไว้ มันจะกลับมาเป็น hedge ratio ในขั้น projection

ขั้นที่ 4 — correlation คือ cosine หลังหักค่าเฉลี่ย

ถึงตรงนี้เรารู้วิธีหามุมระหว่าง vector ใด ๆ แล้ว ขั้นนี้เชื่อมมุมเข้ากับสถิติ ตำราสถิตินิยาม sample correlation ว่า covariance หารด้วย SD ของสองตัวคูณกัน เราจะเขียนทุกตัวในสูตรนั้นด้วย dot product แล้วดูว่าเหลืออะไร

ของที่ใช้ มีข้อมูล $n$ วัน ($n\ge2$):

  • $a_i$ และ $b_i$ คือผลตอบแทนของสินทรัพย์ A และ B ในวันที่ $i$
  • $\bar a$ และ $\bar b$ คือค่าเฉลี่ยของแต่ละชุด
  • $x_i=a_i-\bar a$ และ $y_i=b_i-\bar b$ คือระยะที่วันนั้นห่างจากค่าเฉลี่ย (ข้อมูลที่หักค่าเฉลี่ยแล้ว)

sample covariance $s_{xy}$ คือผลรวมของ $x_iy_i$ หารด้วย $n-1$ ส่วน SD $s_x$ คือรากที่สองของผลรวม $x_i^2$ หารด้วย $n-1$ (การหารด้วย $n-1$ แทน $n$ เป็นธรรมเนียมเวลาประมาณจากข้อมูล ในขั้นนี้ตัวหารจะตัดกันหายไป จึงไม่มีผลกับคำตอบ)

\[ \begin{aligned} s_{xy}&=\frac{\sum_ix_iy_i}{n-1}=\frac{\mathbf x^{\mathsf T}\mathbf y}{n-1},\\ s_x&=\frac{\|\mathbf x\|}{\sqrt{n-1}},\quad s_y=\frac{\|\mathbf y\|}{\sqrt{n-1}},\\ \hat\rho&=\frac{s_{xy}}{s_xs_y} =\frac{\mathbf x^{\mathsf T}\mathbf y}{\|\mathbf x\|\,\|\mathbf y\|}=\cos\theta. \end{aligned} \]

ในเศษมี $n-1$ หนึ่งตัว ในส่วนมี $\sqrt{n-1}\times\sqrt{n-1}=n-1$ อีกหนึ่งตัว สองตัวนี้ตัดกันพอดี จึงเหลือสูตร cosine จากขั้นที่หามุม correlation จึงเป็นมุมระหว่างสองลูกศร และ Cauchy–Schwarz รับประกันว่ามันไม่หลุดช่วง −1 ถึง 1 แต่ต้องจำว่า $\mathbf x$ และ $\mathbf y$ ในสูตรคือข้อมูลที่หักค่าเฉลี่ยแล้ว การตัด $n-1$ ไม่ได้ทำให้ข้ามขั้นหักค่าเฉลี่ยได้

ทำไมต้องหักค่าเฉลี่ย ลองแยก vector $\mathbf a$ เป็นสองส่วน คือ $\mathbf a=\bar a(1,1,\ldots,1)+\mathbf x$ ส่วนแรกชี้ไปตามทิศ “ทุกวันเท่ากัน” ส่วนที่สองตั้งฉากกับทิศนั้น เพราะ $\mathbf x^{\mathsf T}(1,\ldots,1)=\sum_ix_i=0$ (ผลรวมของระยะห่างจากค่าเฉลี่ยเป็นศูนย์เสมอ) ถ้าสองหุ้นมีค่าเฉลี่ยเป็นบวกทั้งคู่ ส่วนแรกของทั้งคู่ชี้ไปทางเดียวกัน มันจึงบีบมุมให้แคบลง ทั้งที่ไม่เกี่ยวเลยว่าวันไหนดีหรือแย่ตามกัน รูปแรกของหน้านี้คือภาพของเรื่องนี้ ถ้าข้อมูลชุดใดเท่ากันทุกวัน จะได้ $\mathbf x=\mathbf 0$ SD เป็นศูนย์ และ correlation ไม่มีนิยาม

ลองกับโจทย์ต้นหน้า ถ้าลืมหักค่าเฉลี่ย ใช้ข้อมูลดิบ $\mathbf a=(1,2,3)$ และ $\mathbf b=(3,2,1)$ ตรง ๆ จะได้

\[ \begin{aligned} \mathbf a^{\mathsf T}\mathbf b&=1\times3+2\times2+3\times1=10,\\ \|\mathbf a\|^2&=1^2+2^2+3^2=14=\|\mathbf b\|^2,\\ \cos\theta&=\frac{10}{\sqrt{14}\sqrt{14}}=\frac{10}{14}\approx0.714,\\ \theta&=\arccos0.714\approx44^\circ. \end{aligned} \]

ถ้าหักค่าเฉลี่ย 2 ออกจากทุกวันก่อน จะได้

\[ \begin{aligned} \mathbf x&=(1-2,\ 2-2,\ 3-2)=(-1,0,1),\\ \mathbf y&=(3-2,\ 2-2,\ 1-2)=(1,0,-1),\\ \mathbf x^{\mathsf T}\mathbf y&=-1+0-1=-2,\\ \|\mathbf x\|^2&=1+0+1=2=\|\mathbf y\|^2,\\ \hat\rho&=\frac{-2}{\sqrt2\sqrt2}=-1,\quad\theta=180^\circ. \end{aligned} \]

ขั้นที่ 5 — มุม 60, 90 และ 150 องศาจากข้อมูลสามวัน

correlation อย่าง 0.5 หรือ −0.866 ฟังดูเป็นแค่ตัวเลข ขั้นนี้แปลงมันเป็นมุมที่มองเห็นได้ เราใช้ข้อมูลสามวันชุดเล็ก ๆ เพราะข้อมูลสามวันที่หักค่าเฉลี่ยแล้วมีผลรวมเป็นศูนย์ทุกชุด จึงตั้งฉากกับ $(1,1,1)$ ทุกชุด ลูกศรทั้งหมดที่ตั้งฉากกับทิศเดียวกันในสามมิติอยู่บนแผ่นระนาบแผ่นเดียว เราจึงวาดลงกระดาษได้โดยมุมไม่เพี้ยน

โจทย์ให้อะไรมาบ้าง: ผลตอบแทนสามวันของสี่สินทรัพย์ (ตัวเลขสมมติ หน่วยเป็นจุดเปอร์เซ็นต์ หักค่าเฉลี่ยไว้แล้ว ผลรวมแต่ละชุดเป็นศูนย์)

  • $\mathbf x=(1,-1,0)$ เป็นชุดอ้างอิง ทุกมุมวัดจากชุดนี้
  • $\mathbf y=(1,0,-1)$
  • $\mathbf z=(1,1,-2)$
  • $\mathbf u=(-1,2,-1)$

เนื่องจากหักค่าเฉลี่ยแล้ว correlation จึงเป็น cosine ของมุมตรง ๆ ต้องใช้ dot product กับความยาวของแต่ละชุด

\[ \begin{aligned} \|\mathbf x\|^2&=1+1+0=2=\|\mathbf y\|^2,\\ \|\mathbf u\|^2&=1+4+1=6,\\ \mathbf x^{\mathsf T}\mathbf y&=1(1)+(-1)(0)+0(-1)=1,\\ \hat\rho_{xy}&=\frac{1}{\sqrt2\sqrt2}=0.5,\quad \theta=60^\circ,\\ \mathbf x^{\mathsf T}\mathbf z&=1(1)+(-1)(1)+0(-2)=0,\\ \hat\rho_{xz}&=0,\quad \theta=90^\circ,\\ \mathbf x^{\mathsf T}\mathbf u&=1(-1)+(-1)(2)+0(-1)=-3,\\ \hat\rho_{xu}&=\frac{-3}{\sqrt2\sqrt6}=\frac{-3}{\sqrt{12}}\approx-0.866,\\ \theta&=150^\circ. \end{aligned} \]

คำตอบ: correlation 0.5, 0 และ −0.866 คือมุม 60, 90 และ 150 องศาตามลำดับ

ลองคิดคู่แรกด้วยสูตรสถิติดูว่าได้เท่ากันไหม ข้อมูลมี $n=3$ วัน

\[ \begin{aligned} s_{xy}&=\frac{1}{3-1}=0.5,\\ s_x&=\sqrt{\frac{2}{3-1}}=1=s_y,\\ \hat\rho_{xy}&=\frac{0.5}{1\times1}=0.5. \end{aligned} \]

ได้ 0.5 ตรงกับ cosine

ตรวจเองใน 10 วินาที: $\cos60^\circ=0.5$, $\cos90^\circ=0$, $\cos150^\circ=-0.866$

ขั้นที่ 6 — อ่าน correlation จริงจาก covariance matrix ของสินทรัพย์แปดกลุ่ม

ทีมจัดพอร์ตอยากรู้ว่าสินทรัพย์คู่ไหนขยับตามกัน คู่ไหนไม่ค่อยเกี่ยวกัน ในงานจริง ทีมแทบไม่เคยเริ่มจากผลตอบแทนรายวันเอง แต่ได้ covariance matrix ที่ประมาณไว้แล้วมาหนึ่งตาราง (ดูหน้า mean vector และ covariance matrix) ตารางนี้มีหนึ่งแถวและหนึ่งคอลัมน์ต่อสินทรัพย์หนึ่งตัว ช่องบนเส้นทแยงคือ variance ของสินทรัพย์ตัวนั้น ช่องนอกเส้นทแยงคือ covariance ของคู่นั้น correlation ไม่ได้อยู่ในตาราง ต้องคำนวณเอง

วิธีคำนวณมาจากนิยามของ correlation ที่ใช้มาตลอด: correlation คือ covariance หารด้วย SD สองตัวคูณกัน และ SD คือรากที่สองของ variance บนเส้นทแยง

\[ \sigma_i=\sqrt{\sigma_{ii}},\qquad \rho_{ij}=\frac{\sigma_{ij}}{\sigma_i\,\sigma_j} \]

ในสูตรนี้ $\sigma_{ii}$ คือ variance ของสินทรัพย์ $i$ และ $\sigma_{ij}$ คือ covariance ของสินทรัพย์ $i$ กับ $j$

โจทย์ให้อะไรมาบ้าง: ตัวเลขจาก covariance matrix รายปีของสินทรัพย์แปดกลุ่ม ใน workbook ของคอร์สเรื่อง mean-variance ขั้นนี้ใช้แค่สามกลุ่ม

  • US Large Growth (หุ้นบริษัทใหญ่ในสหรัฐที่ตลาดคาดว่าจะโตเร็ว ย่อ LG): variance 0.059852
  • US Small Growth (หุ้นบริษัทเล็กในสหรัฐแบบเดียวกัน ย่อ SG): variance 0.102488
  • US Bonds (พันธบัตรสหรัฐ คือตราสารหนี้ที่จ่ายดอกเบี้ยตามกำหนด ย่อ B): variance 0.001005
  • covariance ระหว่าง LG กับ SG: 0.063497
  • covariance ระหว่าง LG กับ B: −0.000579
\[ \begin{aligned} \sigma_{LG}&=\sqrt{0.059852}=0.2446=24.46\%,\\ \sigma_{SG}&=\sqrt{0.102488}=0.3201=32.01\%,\\ \sigma_{B}&=\sqrt{0.001005}=0.0317=3.17\%,\\ \rho_{LG,SG}&=\frac{0.063497}{0.2446\times0.3201}\approx0.811,\\ \theta&=\arccos0.811\approx35.8^\circ,\\ \rho_{LG,B}&=\frac{-0.000579}{0.2446\times0.0317}\approx-0.075,\\ \theta&=\arccos(-0.075)\approx94.3^\circ. \end{aligned} \]

คำตอบ: ถ้ามองเป็นลูกศร หุ้นใหญ่สายเติบโตกับหุ้นเล็กสายเติบโตชี้ห่างกันแค่ 36 องศา สองกลุ่มนี้ขึ้นลงตามกันมาก ส่วนพันธบัตรสหรัฐเกือบตั้งฉากกับหุ้นใหญ่ (94 องศา) correlation −0.075 ใกล้ศูนย์มาก วันที่หุ้นร่วง พันธบัตรจึงไม่ได้ร่วงตาม นี่คือภาพทางเรขาคณิตของการกระจายความเสี่ยง: ถือของที่ลูกศรชี้คนละทาง ขาดทุนของตัวหนึ่งจึงไม่ค่อยมาพร้อมขาดทุนของอีกตัว (อย่างน้อยในข้อมูลชุดนี้)

ขั้นที่ 7 — ความเสี่ยงของพอร์ตสองสินทรัพย์คือความยาวของผลบวกลูกศร

นักลงทุนแบ่งเงินในพอร์ตให้สองสินทรัพย์ แล้วอยากรู้ว่าพอร์ตทั้งก้อนจะแกว่งแค่ไหน ขั้นก่อนให้ภาพไว้แล้ว: สินทรัพย์แต่ละตัวเป็นลูกศรที่ยาวเท่าความผันผวน และสองลูกศรทำมุม $\theta$ กันโดย $\cos\theta=\rho$ ภาพนี้ใช้ได้จริงเพราะความผันผวนคือความยาวของ vector ผลตอบแทนที่หักค่าเฉลี่ยแล้ว (หารด้วย $\sqrt{n-1}$) และ correlation คือ cosine ของมุมระหว่างสอง vector นั้น ตามขั้นที่แสดงว่า correlation คือ cosine

ให้ $x$ คือสัดส่วนเงินในสินทรัพย์ตัวแรก และ $1-x$ คือสัดส่วนในตัวที่สอง ผลตอบแทนของพอร์ตคือผลตอบแทนของแต่ละตัวคูณสัดส่วนแล้วบวกกัน ลูกศรของพอร์ตจึงเป็น $x\mathbf v_1+(1-x)\mathbf v_2$ เมื่อ $\mathbf v_1,\mathbf v_2$ คือลูกศรของสองสินทรัพย์ ความผันผวนของพอร์ต $\sigma_p$ คือความยาวของลูกศรนี้ เราหาความยาวกำลังสองด้วย dot product

\[ \begin{aligned} \sigma_p^2&=\|x\mathbf v_1+(1-x)\mathbf v_2\|^2\\ &=x^2\|\mathbf v_1\|^2+(1-x)^2\|\mathbf v_2\|^2\\ &\quad+2x(1-x)\,\mathbf v_1^{\mathsf T}\mathbf v_2,\\ \mathbf v_1^{\mathsf T}\mathbf v_2&=\|\mathbf v_1\|\|\mathbf v_2\|\cos\theta\\ &=\sigma_1\sigma_2\rho=\sigma_{12},\\ \sigma_p^2&=x^2\sigma_1^2+(1-x)^2\sigma_2^2\\ &\quad+2x(1-x)\sigma_{12}. \end{aligned} \]

สูตร variance ของพอร์ตสองสินทรัพย์ที่ตำราการเงินใช้ คือความยาวกำลังสองของผลบวกลูกศรนั่นเอง ส่วน $x^2\sigma_1^2$ และ $(1-x)^2\sigma_2^2$ มาจากลูกศรแต่ละตัว ส่วนพจน์ไขว้มาจาก dot product ของสองลูกศร ซึ่งเท่ากับความยาวคูณความยาวคูณ cosine ของมุม และนั่นคือ covariance $\sigma_{12}$ พอดี พจน์ covariance ในสูตรพอร์ตจึงไม่ใช่เรื่องบังเอิญ มันคือส่วนที่บอกว่าสองลูกศรชี้ไปทางเดียวกันแค่ไหน

ลองใส่ตัวเลข ใช้ตัวอย่างสองสินทรัพย์จากคอร์ส:

  • variance ของสินทรัพย์ตัวแรก $\sigma_1^2=0.1$ จึงได้ $\sigma_1=\sqrt{0.1}=0.316$
  • variance ของสินทรัพย์ตัวที่สอง $\sigma_2^2=0.5$ จึงได้ $\sigma_2=\sqrt{0.5}=0.707$
  • correlation ระหว่างสองตัว $\rho=0.25$
  • แบ่งเงินครึ่งต่อครึ่ง $x=0.5$
\[ \begin{aligned} \sigma_{12}&=\rho\,\sigma_1\sigma_2=0.25\sqrt{0.1\times0.5}\\ &\approx0.0559,\\ \sigma_p^2&=0.5^2(0.1)+0.5^2(0.5)\\ &\quad+2(0.5)(0.5)(0.0559)\\ &=0.025+0.125+0.02795\\ &=0.17795,\\ \sigma_p&=\sqrt{0.17795}\approx0.422. \end{aligned} \]

มุมทำให้ต่างแค่ไหน ลองเปลี่ยน $\rho$ แต่คงความยาวลูกศรครึ่งหนึ่งไว้ คือ $0.5\sigma_1=0.5\times0.316=0.158$ และ $0.5\sigma_2=0.5\times0.707=0.354$

\[ \begin{aligned} \rho=1:\ \sigma_p&=0.158+0.354=0.512,\\ \rho=0.25:\ \sigma_p&=0.422,\\ \rho=0:\ \sigma_p&=\sqrt{0.025+0.125}=0.387,\\ \rho=-1:\ \sigma_p&=0.354-0.158=0.195. \end{aligned} \]

ที่ $\rho=1$ สองลูกศรชี้ทางเดียวกัน ความยาวจึงบวกกันตรง ๆ ที่ $\rho=0$ สองลูกศรตั้งฉาก จึงใช้พีทาโกรัส (พจน์ไขว้เป็นศูนย์) ที่ $\rho=-1$ สองลูกศรชี้สวนกัน ความยาวจึงหักลบกัน การกระจายความเสี่ยงช่วยได้มากแค่ไหนจึงขึ้นกับมุม: ยิ่งมุมกว้าง ลูกศรผลบวกยิ่งสั้นกว่าผลรวมความยาวของสองลูกศร

ขั้นที่ 8 — projection หา hedge ที่ทำให้ส่วนเหลือสั้นที่สุด

เทรดเดอร์คนหนึ่งถือ basket คือหุ้นหลายตัวที่ถือรวมกันเป็นก้อนเดียว เขากลัวว่าตลาดทั้งตลาดจะร่วง จึงจะ short เครื่องมือ hedge ที่ราคาวิ่งตาม basket พอสมควร เช่นกองทุนที่วิ่งตามดัชนีตลาด วันที่ basket ขาดทุน ฝั่ง short จะได้กำไรมาชดเชย คำถามคือควร short เท่าไร ถ้าน้อยไปก็ยังเสี่ยงอยู่มาก ถ้ามากไป ฝั่ง short ก็กลายเป็นความเสี่ยงใหม่

ตั้งชื่อของที่ใช้:

  • $\mathbf x$ คือผลตอบแทนรายวันของ basket หลังหักค่าเฉลี่ย
  • $\mathbf y$ คือผลตอบแทนรายวันของเครื่องมือ hedge หลังหักค่าเฉลี่ย
  • $h$ คือ hedge ratio: ถือ basket \$1 ก็ short เครื่องมือ hedge มูลค่า $h$ ดอลลาร์
  • $\mathbf e=\mathbf x-h\mathbf y$ คือผลตอบแทนของสถานะรวมหลัง hedge (ส่วนเหลือ)

เป้าหมายคือเลือก $h$ ให้สถานะรวมแกว่งน้อยที่สุด variance ของส่วนเหลือคือ $s_e^2=\|\mathbf e\|^2/(n-1)$ แบบเดียวกับ $s_x$ ในขั้นที่แสดงว่า correlation คือ cosine การทำให้ variance ต่ำที่สุดจึงเหมือนกับการทำให้ลูกศร $\mathbf e$ สั้นที่สุด

\[ \begin{aligned} \|\mathbf x-h\mathbf y\|^2&=\|\mathbf x\|^2-2h\,\mathbf x^{\mathsf T}\mathbf y\\ &\quad+h^2\|\mathbf y\|^2,\\ 0&=-2\,\mathbf x^{\mathsf T}\mathbf y+2h^*\|\mathbf y\|^2,\\ h^*&=\frac{\mathbf x^{\mathsf T}\mathbf y}{\|\mathbf y\|^2}=\frac{s_{xy}}{s_y^2}\\ &=\hat\rho\,\frac{s_x}{s_y},\\ \mathbf e^{\mathsf T}\mathbf y&=\mathbf x^{\mathsf T}\mathbf y-h^*\|\mathbf y\|^2=0,\\ s_e^2&=s_x^2-\frac{s_{xy}^2}{s_y^2}=s_x^2\big(1-\hat\rho^2\big). \end{aligned} \]

ความยาวกำลังสองของส่วนเหลือเป็นพาราโบลาหงายใน $h$ จุดต่ำสุดอยู่ที่อนุพันธ์เทียบกับ $h$ เป็นศูนย์ แก้สมการได้ $h^*$ ซึ่งคือ $t$ ตัวเดียวกับในการพิสูจน์ Cauchy–Schwarz ถ้าหารทั้งเศษและส่วนด้วย $n-1$ จะได้รูปสถิติ $s_{xy}/s_y^2$ และถ้าแทน $s_{xy}=\hat\rho\,s_xs_y$ จะได้ $\hat\rho\,s_x/s_y$

ข้อเท็จจริงสำคัญคือที่ $h^*$ ส่วนเหลือ $\mathbf e$ ตั้งฉากกับ $\mathbf y$ พอดี เหตุผลคือ ถ้ายังไม่ตั้งฉาก แปลว่า $\mathbf e$ ยังมีส่วนที่ชี้ตาม $\mathbf y$ อยู่ ซึ่ง short เพิ่มหรือลดอีกนิดก็ตัดทิ้งได้ ลูกศรจึงยังสั้นลงได้อีก ส่วนบรรทัดสุดท้ายได้จากการแทน $h^*$ กลับเข้าไปแล้วหารด้วย $n-1$ ซึ่งให้นิพจน์เดียวกับในการพิสูจน์ Cauchy–Schwarz จากนั้นดึง $s_x^2$ ออกมา และใช้ $s_{xy}^2/(s_x^2s_y^2)=\hat\rho^2$ ความหมายคือ variance ที่เหลือหลัง hedge เป็นสัดส่วน $1-\hat\rho^2$ ของ variance เดิม

ลองกับข้อมูลสามวันชุดเดิม ให้ basket $\mathbf x=(1,-1,0)$ และเครื่องมือ hedge $\mathbf y=(1,0,-1)$ ซึ่งมี $\mathbf x^{\mathsf T}\mathbf y=1$, $\|\mathbf y\|^2=2$ และ $\hat\rho=0.5$ ตามที่คำนวณไว้ในขั้นมุม 60 องศา

\[ \begin{aligned} h^*&=\frac{1}{2}=0.5,\\ \mathbf e&=(1,-1,0)-0.5(1,0,-1)\\ &=(0.5,\,-1,\,0.5),\\ \mathbf e^{\mathsf T}\mathbf y&=0.5(1)+(-1)(0)+0.5(-1)=0,\\ \|\mathbf e\|^2&=0.25+1+0.25=1.5,\\ \|\mathbf x\|^2(1-\hat\rho^2)&=2(1-0.5^2)=1.5. \end{aligned} \]

ส่วนเหลือตั้งฉากกับ hedge จริง และสั้นลงตามสัดส่วน $1-\hat\rho^2$ จริง ถ้าลอง short เท่าตัว ($h=1$) แทน ส่วนเหลือคือ $\mathbf x-\mathbf y=(0,-1,1)$ ยาวกำลังสอง $0+1+1=2$ ซึ่งยาวกว่า 1.5

ขั้นที่ 9 — beta คือ projection: hedge หุ้นเล็กด้วยหุ้นใหญ่

โต๊ะเทรดแห่งหนึ่งถือหุ้นเล็กสหรัฐสายเติบโต (US Small Growth) อยู่ \$12 ล้าน หุ้นกลุ่มนี้แกว่งแรง โต๊ะจึงอยากลดความเสี่ยงโดย short หุ้นใหญ่สายเติบโต (US Large Growth) ซึ่งขยับตามกันมาก (มุม 36 องศาจากขั้นอ่าน correlation) คำถามคือต้อง short กี่ดอลลาร์ และหลัง hedge แล้วยังเหลือความเสี่ยงเท่าไร

เครื่องมือคือ $h^*$ จากขั้นก่อน เมื่อเครื่องมือ hedge คือ “ตลาด” ตัวเลขนี้มีชื่อเรียกว่า beta ในทฤษฎี CAPM beta ของสินทรัพย์ $j$ คือความชันของเส้นตรงที่ลากผ่านจุดข้อมูล (ผลตอบแทนตลาด, ผลตอบแทนสินทรัพย์) ให้ใกล้ที่สุด ซึ่งเรียกว่า regression และได้สูตรเดียวกับ $h^*$:

\[ \beta_j=\frac{\operatorname{cov}(r_j,r_m)}{\operatorname{var}(r_m)} \]

ในสูตรนี้ $r_j$ คือผลตอบแทนของสินทรัพย์ $j$ และ $r_m$ คือผลตอบแทนของตลาด (CAPM ใช้ผลตอบแทนที่หักดอกเบี้ยเงินฝากแล้ว แต่หลักคิดเหมือนกัน) ขั้นก่อนยังบอกอีกเรื่อง: ส่วนเหลือตั้งฉากกับตลาด และ $\mathbf x=h^*\mathbf y+\mathbf e$ ความเสี่ยงจึงแยกเป็นสองด้านของสามเหลี่ยมมุมฉาก ใช้พีทาโกรัสได้

\[ \begin{aligned} \|\mathbf x\|^2&=h^{*2}\|\mathbf y\|^2+\|\mathbf e\|^2,\\ \sigma_j^2&=\beta_j^2\sigma_m^2+\sigma_e^2. \end{aligned} \]

บรรทัดแรกได้จากการกระจาย $\|h^*\mathbf y+\mathbf e\|^2$ ด้วย dot product พจน์ไขว้คือ $2h^*\,\mathbf e^{\mathsf T}\mathbf y$ ซึ่งเป็นศูนย์เพราะ $\mathbf e$ ตั้งฉากกับ $\mathbf y$ บรรทัดที่สองได้จากการหารบรรทัดแรกด้วย $n-1$ ส่วนแรกคือความเสี่ยงที่มาจากตลาด ส่วนที่สองคือความเสี่ยงเฉพาะตัวที่ hedge ด้วยตลาดเอาออกไม่ได้

โจทย์ให้อะไรมาบ้าง: ตัวเลขรายปีจาก covariance matrix ชุดเดียวกับขั้นอ่าน correlation

  • สถานะ: long US Small Growth \$12 ล้าน
  • variance ของ US Small Growth 0.102488 ความผันผวน $\sigma_{SG}=32.01\%$
  • variance ของ US Large Growth 0.059852 ความผันผวน $\sigma_{LG}=24.46\%$
  • covariance ของสองกลุ่ม 0.063497 correlation $\hat\rho=0.8107$ (คำนวณไว้แล้ว ปัดเป็น 0.811)
\[ \begin{aligned} \beta&=\frac{\sigma_{LG,SG}}{\sigma_{LG}^2}=\frac{0.063497}{0.059852}\approx1.061,\\ \hat\rho^2&=0.8107^2\approx0.6573,\\ \sigma_e&=\sigma_{SG}\sqrt{1-\hat\rho^2}\\ &=0.3201\sqrt{1-0.6573}\\ &=0.3201\times0.5854\approx18.74\%,\\ \beta\sigma_{LG}&=1.061\times24.46\%\approx25.95\%,\\ 25.95^2+18.74^2&=673.4+351.2=1024.6,\\ 32.01^2&=1024.6. \end{aligned} \]

คำตอบ: ขนาดที่ต้อง short คือ beta คูณสถานะ: $1.061\times12\approx12.73$ คือ short US Large Growth ประมาณ \$12.73 ล้าน มากกว่าสถานะ \$12 ล้านเล็กน้อย เพราะ beta เกิน 1 หลัง hedge ความผันผวนลดจาก 32.01% เหลือ 18.74% ต่อปี

ระวังการอ่านตัวเลขนี้ variance หายไป $\hat\rho^2=65.7\%$ แต่ความผันผวนลดลงแค่ $1-18.74/32.01=1-0.585=41.5\%$ เหตุผลคือความผันผวนเป็นรากที่สองของ variance: variance เหลือ $1-0.6573=0.3427$ ของเดิม ความผันผวนจึงเหลือ $\sqrt{0.3427}=0.585$ ของเดิม สองบรรทัดสุดท้ายในกล่องคำนวณคือการตรวจพีทาโกรัส ส่วนที่มาจากตลาดกับส่วนเหลือตั้งฉากกัน กำลังสองของทั้งสองจึงบวกกันได้กำลังสองของความผันผวนรวมพอดี

ตัวเลขเหล่านี้ประมาณจากข้อมูลในอดีต covariance ในอนาคตเปลี่ยนได้ โดยเฉพาะช่วงตลาดตึงเครียด ซึ่ง correlation มักสูงขึ้น นอกจากนี้ยังมีต้นทุนจริงที่สูตรไม่ได้นับ เช่นค่ายืมหุ้นมา short ค่าซื้อขาย และการต้องปรับขนาด hedge ใหม่เมื่อราคาเปลี่ยน

ความผิดที่ทำให้อ่านมุมผิด

ลืมหักค่าเฉลี่ยก่อนหา cosine: ค่าเฉลี่ยที่ทั้งสองชุดมีร่วมกันจะบีบมุมให้แคบ ในโจทย์ต้นหน้า ข้อมูลดิบให้ $\cos\theta=10/14\approx0.714$ ซึ่งดูเหมือนไปทางเดียวกัน แต่ค่าที่ถูกคือ $\hat\rho=-2/(\sqrt2\sqrt2)=-1$ คือสวนกันพอดี คำตอบกลับทิศเลย

คิดว่าตั้งฉากแปลว่าเป็นอิสระ: correlation ศูนย์บอกแค่ว่าไม่มีความสัมพันธ์แบบเส้นตรง ตัวอย่าง: ให้ $X$ เป็น −1, 0 หรือ 1 โอกาสอย่างละ $1/3$ และ $Y=X^2$ ใช้ $E[\cdot]$ แทนค่าเฉลี่ยถ่วงด้วยโอกาส (expected value)

\[ \begin{aligned} E[X]&=\tfrac13(-1)+\tfrac13(0)+\tfrac13(1)=0,\\ E[XY]&=E[X^3]=\tfrac13(-1)+\tfrac13(0)+\tfrac13(1)=0,\\ \operatorname{cov}(X,Y)&=E[XY]-E[X]E[Y]=0-0=0. \end{aligned} \]

covariance เป็นศูนย์ แต่รู้ $X$ ก็รู้ $Y$ ทันที สองตัวนี้ไม่อิสระกันเลย (ดูต่อในหน้า zero covariance is not independence)

ใช้ correlation เป็น hedge ratio ตรง ๆ: hedge ratio ต้องคูณอัตราส่วนความผันผวนด้วย เพราะสองสินทรัพย์แกว่งแรงไม่เท่ากัน ในตัวอย่าง hedge หุ้นเล็กด้วยหุ้นใหญ่ ถ้าใช้ correlation อย่างเดียวจะ short แค่ $0.811\times12=9.73$ คือ \$9.73 ล้าน ค่าที่ถูกคือ $h^*=0.811\times32.01/24.46\approx1.061$ ซึ่งต้อง short $1.061\times12=12.73$ คือ \$12.73 ล้าน การใช้ 0.811 จึง hedge ขาดไปราว $12.73-9.73=3$ คือ \$3 ล้าน

สับสนการลด variance กับการลดความผันผวน: ตัวเลข 65.7% คือส่วนของ variance ที่หายไป ($\hat\rho^2$) ไม่ใช่ความผันผวน ความผันผวนลดแค่ $1-\sqrt{1-0.6573}=1-0.585=41.5\%$ การรายงานว่า “ความเสี่ยงลดไปสองในสาม” จึงเกินจริง

คิดว่า $\hat\rho$ เป็นลบแปลว่าต้อง short มากขึ้น: ถ้า $\hat\rho\lt0$ สูตร $h^*=\hat\rho\,s_x/s_y$ ให้ $h^*\lt0$ ส่วนเหลือคือ $\mathbf x-h^*\mathbf y=\mathbf x+|h^*|\,\mathbf y$ ซึ่งแปลว่าต้องซื้อ (long) เครื่องมือ hedge ไม่ใช่ short เพราะมันมักขึ้นในวันที่ basket ลงอยู่แล้ว (ดูโจทย์ข้อ 3 ด้านล่าง)

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะเทรดมัก hedge พอร์ตหุ้นด้วย index future (สัญญาซื้อขายล่วงหน้าที่ราคาวิ่งตามดัชนีตลาด) หรือ ETF (กองทุนที่ซื้อขายในตลาดเหมือนหุ้นและวิ่งตามดัชนี) ทุกครั้งที่ทำ ขนาดที่ short คือ beta คูณมูลค่าพอร์ต ซึ่งก็คือ projection ของหน้านี้ ตัวเลขที่ควรรายงานคู่กันเสมอคือ $1-\hat\rho^2$ เพราะมันบอกว่าหลัง hedge ยังเหลือ variance กี่ส่วนของเดิม

ถ้ามีเครื่องมือ hedge หลายตัว หลักเดียวกันยังใช้ได้ เพียงแต่ฉายเงาลงบนพื้นที่ที่เครื่องมือทุกตัวผสมกันได้ (เรียกว่า span) แทนที่จะเป็นเส้นเดียว เรื่องนี้คือ OLS regression และ Frisch–Waugh–Lovell ส่วนการเก็บ variance และ covariance ของทุกคู่ไว้ในตารางเดียวคือหน้า mean vector และ covariance matrix

โจทย์ตรวจความเข้าใจ

1. นักวิเคราะห์ได้ข้อมูลผลตอบแทนรายวันของหุ้น A และ B มาแล้วคำนวณ correlation ไว้ จากนั้นพบว่าแหล่งข้อมูลทำสองอย่างผิด คือบวก 7 เข้าไปในผลตอบแทนของ A ทุกวัน และคูณผลตอบแทนของ B ทุกวันด้วย 3 correlation ที่คำนวณได้จากข้อมูลผิดนี้ต่างจากของจริงไหม ถ้าคูณ B ด้วย −3 แทนล่ะ

เฉลย

บวก 7 ไม่เปลี่ยนอะไร เพราะค่าเฉลี่ยก็เพิ่ม 7 ด้วย พอหักค่าเฉลี่ยแล้ว 7 หายไป: $(a_i+7)-(\bar a+7)=a_i-\bar a=x_i$ ได้ $\mathbf x$ เดิมทุกช่อง คูณ 3 ทำให้ $\mathbf y$ กลายเป็น $3\mathbf y$ ยาวขึ้น 3 เท่าแต่ทิศเดิม เลข 3 ตัดกันในเศษกับส่วนของ cosine:

\[ \frac{\mathbf x^{\mathsf T}(3\mathbf y)}{\|\mathbf x\|\,\|3\mathbf y\|}=\frac{3\,\mathbf x^{\mathsf T}\mathbf y}{3\,\|\mathbf x\|\,\|\mathbf y\|}=\hat\rho \]

คูณ −3 ทำให้เศษเป็น $-3\,\mathbf x^{\mathsf T}\mathbf y$ แต่ส่วนยังเป็น $3\|\mathbf x\|\|\mathbf y\|$ เพราะความยาวไม่ติดลบ ผลจึงเป็น $-\hat\rho$ คือ $\mathbf y$ กลับทิศ correlation เปลี่ยนเครื่องหมาย แต่ขนาดเท่าเดิม

2. ผู้จัดการพอร์ตถือหุ้น A และกำลังพิจารณาใช้หุ้น B เป็นเครื่องมือ hedge เขามีผลตอบแทนห้าวัน (ตัวเลขสมมติ หน่วยจุดเปอร์เซ็นต์ ผลรวมแต่ละชุดเป็นศูนย์ จึงหักค่าเฉลี่ยไว้แล้ว) A $=(1.2,-0.8,0.5,-1.5,0.6)$ และ B $=(0.9,-0.3,1.1,-1.2,-0.5)$ จงหา correlation มุม และ hedge ratio ของ A ด้วย B และบอกว่าหลัง hedge เหลือ variance กี่ส่วนของเดิม

เฉลย

ต้องใช้ dot product และความยาวกำลังสองของทั้งสองชุด

\[ \begin{aligned} \mathbf a^{\mathsf T}\mathbf b&=1.08+0.24+0.55+1.80-0.30\\ &=3.37,\\ \|\mathbf a\|^2&=1.44+0.64+0.25+2.25+0.36\\ &=4.94,\\ \|\mathbf b\|^2&=0.81+0.09+1.21+1.44+0.25\\ &=3.80,\\ \hat\rho&=\frac{\mathbf a^{\mathsf T}\mathbf b}{\|\mathbf a\|\,\|\mathbf b\|}=\frac{3.37}{\sqrt{4.94\times3.80}}\\ &=\frac{3.37}{4.333}\approx0.778,\\ \theta&=\arccos0.778\approx38.9^\circ,\\ h^*&=\frac{\mathbf a^{\mathsf T}\mathbf b}{\|\mathbf b\|^2}=\frac{3.37}{3.80}\approx0.887,\\ 1-\hat\rho^2&=1-0.778^2\approx0.395. \end{aligned} \]

correlation ราว 0.778 คือมุมราว 38.9 องศา hedge ratio 0.887 คือถือ A \$1 ให้ short B \$0.887 หลัง hedge เหลือ variance ราว 39.5% ของเดิม

3. เทรดเดอร์ถือ basket ที่มีความผันผวน $s_x=2\%$ ต่อวัน เครื่องมือที่หามาได้มีความผันผวน $s_y=1\%$ ต่อวัน และ correlation กับ basket $\hat\rho=-0.5$ คือมักขยับสวนกับ basket ตามสูตร hedge ที่ทำให้ variance ต่ำสุด เขาต้องทำอะไรกับเครื่องมือนี้ ขนาดเท่าไร และความผันผวนที่เหลือเป็นเท่าไร

เฉลย
\[ \begin{aligned} h^*&=\hat\rho\,\frac{s_x}{s_y}=-0.5\times\frac{2}{1}=-1,\\ s_e&=s_x\sqrt{1-\hat\rho^2}=2\%\sqrt{1-(-0.5)^2}\\ &=2\%\sqrt{0.75}\\ &=2\%\times0.866\approx1.73\%. \end{aligned} \]

$h^*=-1$ ติดลบ จึงต้องซื้อเครื่องมือนี้ ไม่ใช่ short ขนาดเท่ากับมูลค่า basket เพราะมันมักขึ้นในวันที่ basket ลงอยู่แล้ว ความผันผวนที่เหลือราว 1.73% ต่อวัน

const center = a => { const m = a.reduce((s, x) => s + x, 0) / a.length; return a.map(x => x - m); };
const cosine = (a, b) => {
  const na = Math.sqrt(dot(a, a)), nb = Math.sqrt(dot(b, b));
  if (na === 0 || nb === 0) throw new RangeError('angle undefined for a zero vector');
  return Math.max(-1, Math.min(1, dot(a, b) / (na * nb)));
};
function stats(a, b) {
  if (a.length !== b.length || a.length < 2) throw new RangeError('need matching pairs');
  const x = center(a), y = center(b), rho = cosine(x, y), h = dot(x, y) / dot(y, y);
  const e = x.map((v, i) => v - h * y[i]);
  return {rho, degrees: Math.acos(rho) * 180 / Math.PI, h, e, eDotY: dot(e, y), ee: dot(e, e)};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • สูตรมุม $\cos\theta=\mathbf x^{\mathsf T}\mathbf y/(\|\mathbf x\|\|\mathbf y\|)$ มาจากการหาความยาวด้านที่สามของสามเหลี่ยมสองทาง (กฎโคไซน์ และการกระจาย dot product) แล้วจับมาเท่ากัน ส่วน Cauchy–Schwarz รับประกันว่าค่านี้อยู่ระหว่าง −1 ถึง 1 ในทุกมิติ
  • sample correlation คือ cosine ของข้อมูลที่หักค่าเฉลี่ยแล้ว ถ้าลืมหัก ค่าเฉลี่ยที่มีร่วมกันจะบีบมุม ในโจทย์ต้นหน้าจะได้ 0.714 แทนค่าจริง −1
  • อ่าน correlation จาก covariance matrix ด้วย $\rho_{ij}=\sigma_{ij}/(\sigma_i\sigma_j)$ ในข้อมูลของคอร์ส หุ้นใหญ่กับหุ้นเล็กสายเติบโตห่างกันแค่ 36 องศา ส่วนพันธบัตรเกือบตั้งฉากกับหุ้น
  • ความผันผวนของพอร์ตคือความยาวของผลบวกลูกศร พจน์ covariance ในสูตรคือ dot product ของสองลูกศร ยิ่งมุมกว้าง ผลบวกยิ่งสั้น การกระจายความเสี่ยงยิ่งได้ผล
  • hedge ที่ดีที่สุดคือ projection: $h^*=s_{xy}/s_y^2$ ส่วนเหลือตั้งฉากกับเครื่องมือ hedge และ variance เหลือ $1-\hat\rho^2$ ของเดิม ในตัวอย่างหุ้นเล็กกับหุ้นใหญ่ beta 1.061 ตัด variance ได้ 65.7% แต่ตัดความผันผวนได้แค่ 41.5%
