23.1 Real Options and Dynamic Programming

สิทธิ์ในการรอ ลงทุน หรือหยุดโครงการเมื่อข้อมูลใหม่เข้ามา

เครื่องอบขนมราคา 9,000 USD วันนี้ แต่พรุ่งนี้อาจรู้ว่ายอดจองเยอะหรือเงียบ. ถ้ารอหนึ่งวัน คุณเสียอะไร และได้สิทธิ์อะไรกลับมา?

ถ้าสร้างทันที ผลอาจเป็น 12,000 หรือ 6,000 USD. ถ้ารอ คุณเลือกจ่ายเฉพาะทางที่คุ้ม. จึงมีมูลค่ามากกว่าการบวกตัวเลขเฉลี่ยแบบทื่อ ๆ.

เฉลย: การรอมีค่าเพราะทิ้งทางแย่ได้ แต่ยังเก็บทางดีไว้. สิทธิ์ที่จะรอ ขยาย ลด หรือหยุดโครงการเรียก real option. การคิดย้อนจากผลลัพธ์อนาคตมาเลือกวันนี้เรียก dynamic programming. การรอไม่ใช่ผัดวันประกันพรุ่งเมื่อมันซื้อสิทธิ์ปฏิเสธข่าวร้าย.

ศัพท์ที่ต้องรู้ก่อนเริ่ม
real option
สิทธิ์แต่ไม่ใช่หน้าที่ในการตัดสินใจเรื่องสินทรัพย์จริง เช่น ลงทุน ขยาย หยุด หรือเลื่อนโครงการ ใช้วัดมูลค่าความยืดหยุ่นเมื่อข้อมูลอนาคตยังไม่ครบ
net present value (NPV)
มูลค่าปัจจุบันของกระแสเงินสดโครงการหักเงินลงทุน ใช้เป็นเกณฑ์ว่าถ้าต้องตัดสินใจทันทีโครงการสร้างมูลค่าเหนือเงินทุนหรือไม่
dynamic programming
วิธีแก้ปัญหาที่แบ่งการตัดสินใจหลายช่วงเวลาเป็น subproblem แล้วคำนวณจากอนาคตย้อนกลับมา ใช้เลือก action ที่ดีที่สุดเมื่อ state เปลี่ยนได้
decision tree
แผนผังที่แยก state ของโลกและ action ในแต่ละเวลา ใช้ทำให้ทางเลือกในการลงทุนและ payoff ที่ปลายกิ่งตรวจสอบทีละกิ่ง
state variable
ตัวแปรที่สรุปข้อมูลปัจจุบันซึ่งพอสำหรับการตัดสินใจอนาคต ในตัวอย่างคือมูลค่าโครงการที่ยังไม่ได้ลงทุน หน่วยเป็น USD
continuation value
มูลค่าของการยังไม่ใช้สิทธิ์และรอไปช่วงถัดไป ใช้เปรียบเทียบกับมูลค่าการ exercise ทันทีในแต่ละ state
exercise
การใช้สิทธิ์ของ real option เช่น จ่ายเงินลงทุนเพื่อเริ่มโครงการ ใช้เปลี่ยน option ให้เป็นสินทรัพย์ที่สร้างกระแสเงินสด
risk-neutral probability
น้ำหนักเชิงราคาที่ทำให้ discounted expected value เดินตาม no-arbitrage ใช้คำนวณราคา option ไม่ใช่ความน่าจะเป็นเชิงพยากรณ์ของผู้จัดการ
no-arbitrage
หลักที่ไม่เปิดให้สร้างเงินกำไรแน่นอนโดยไม่รับความเสี่ยงและไม่ใช้เงินสุทธิ ใช้เป็นเหตุผลว่ากระแสเงินสดที่จำลองได้ต้องมีราคาสอดคล้องกัน
sunk cost
ต้นทุนที่จ่ายไปแล้วและเรียกคืนไม่ได้ ใช้เตือนว่าการตัดสินใจปัจจุบันควรเทียบ incremental cash flow ไม่ใช่พยายามกู้เงินเก่าคืน
martingale
กระบวนการที่ค่า discounted ในอนาคตมี expected value เท่ากับค่าปัจจุบัน ใช้ตรวจความสอดคล้องของ pricing measure กับ no-arbitrage
convexity
ความโค้งที่ทำให้ upside และ downside ไม่ชดเชยกันเป็นเส้นตรง ใช้อธิบายว่าการมีสิทธิ์ไม่ลงทุนช่วยจำกัดขาดทุน
volatility
ขนาดการกระจายของการเปลี่ยนแปลงราคา ใช้บอกความกว้างของ state และมูลค่าของ option ที่มี downside จำกัด
strike
ค่าหรือราคาที่กำหนดไว้เป็นเส้นแบ่งของการใช้สิทธิ์ ใช้เทียบกับ project value เพื่อดูว่า exercise แล้วคุ้มหรือไม่
payoff
เงินที่สิทธิ์หรือสัญญาจ่ายเมื่อเกิด state หนึ่ง ใช้เป็นปลายทางของ decision tree ก่อน discount กลับมาวันนี้
สัญกรณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$t$ลำดับเวลาของ decision dateปี
$T$horizon สุดท้ายของ optionปี
$X_t$มูลค่าปัจจุบันของโครงการก่อนจ่ายเงินลงทุน ณ เวลา tUSD
$I$เงินลงทุนเพื่อ exercise โครงการUSD
$u,d$ตัวคูณ up และ down ของ state value ในหนึ่งช่วงเวลาไม่มีหน่วย
$R$gross risk-free growth factor ต่อหนึ่งช่วงเวลาไม่มีหน่วยต่อช่วงเวลา
$q$risk-neutral probability ของ up stateไม่มีหน่วย
$V_t(X_t)$มูลค่าของ real option ณ state และเวลา tUSD
$\tau$เวลาที่ตัดสินใจ exercise เป็นครั้งแรกปี

ที่มาที่ไป: การลงทุนที่มีสิทธิ์เลือก ไม่ใช่ภาระผูกพัน

วิธีประเมินโครงการแบบมาตรฐานคือคำนวณมูลค่าปัจจุบันของกระแสเงินแล้วดูว่าเป็นบวกไหม ซึ่งสมมติเงียบ ๆ ว่าตัดสินใจครั้งเดียวแล้วเดินหน้าไปตลอด

Stewart Myers ชี้ในปี 1977 ว่าสมมติฐานนั้นทิ้งมูลค่าไปมาก เพราะผู้บริหารมีสิทธิ์เลือกอยู่ตลอดทาง ทั้งจะรอ จะขยาย จะย่อ หรือจะเลิก

สิทธิ์เหล่านั้นมีมูลค่า และมูลค่าของมันเพิ่มขึ้นเมื่อความไม่แน่นอนสูงขึ้น ซึ่งตรงข้ามกับวิธีประเมินแบบเดิมที่ลงโทษความไม่แน่นอนเสมอ

เขาเรียกสิทธิ์เหล่านี้ว่า real options เพราะโครงสร้างของมันเหมือนกับ option ในตลาดการเงินพอดี จึงประเมินด้วยเครื่องมือชุดเดียวกันได้

ทำไม NPV แบบจุดเดียวตอบไม่พอ

ถ้าผู้บริหารต้องจ่าย \$9.0M วันนี้ ให้ใช้มูลค่าโครงการวันนี้ \$10.0M หักเงินลงทุน จึงได้ NPV ทันที \$1.0M แต่โครงการที่ยังไม่ลงทุนมีสิทธิ์รอ: ถ้าราคาพลังงาน กำลังส่ง หรือกฎตลาดดีขึ้น มูลค่าโครงการอาจสูงขึ้น; ถ้าแย่ลง ก็ปล่อยให้สิทธิ์หมดโดยไม่จ่าย \$9.0M เงินลงทุนจึงเป็นราคา strike ของสิทธิ์ และการรอมีมูลค่าแม้ NPV วันนี้จะไม่ใช่คำตอบเต็มรูปแบบ

วิศวกรคุ้นกับ feedback control: state ปัจจุบันนำไปสู่ action และ state ถัดไป ในที่นี้ action คือ exercise หรือ wait ส่วน value function คือกฎที่บอกว่าทางเลือกที่เหลือมีค่าเท่าไร การมองเช่นนี้ทำให้เห็นว่า uncertainty ไม่ได้มีแต่ต้นทุน เพราะ flexibility เปลี่ยน uncertainty ให้เป็นสิทธิ์เลือกได้

ขั้นที่ 1 — นิยามของเงินที่ได้ถ้าลงทุนทันที

บรรทัดนี้เป็น นิยาม ของผลตอบแทนจากการตัดสินใจลงทุนเดี๋ยวนี้ ไม่ใช่ผลที่พิสูจน์ รูปของมันเหมือน payoff ของ call ในหัวข้อ 13.2 ทุกประการ โดยมูลค่าโครงการเล่นบทของราคาหุ้น และเงินลงทุนเล่นบทของราคาใช้สิทธิ์ ตัวเลือกกับศูนย์มีความหมายจริง: ถ้าโครงการมีมูลค่าน้อยกว่าเงินที่ต้องลง ก็ไม่ลง และไม่เสียอะไร การเห็นว่ามันเป็นรูปเดียวกันคือทั้งหมดที่ทำให้หัวข้อนี้ใช้เครื่องมือของบทที่ 13 ได้

\[ E_t(X_t)=\max(X_t-I,0) \]

$E_t$ คือ payoff จากการ exercise ณ เวลา $t$; $X_t$ คือมูลค่าโครงการก่อนลงทุนและมีหน่วย USD; $I$ คือเงินลงทุน USD; function max ทำให้ผู้ถือเลือกไม่ลงทุนได้เมื่อส่วนต่างติดลบ

ก่อนใช้น้ำหนัก Q ต้องมีอะไรให้ hedge

แบบฝึกนี้สมมติว่ามูลค่าโครงการก่อนลงทุนมีสินทรัพย์ซื้อขายได้ที่เลียนแบบ cash flow และความเสี่ยงของมันได้ จึงใช้หลัก no-arbitrage สร้าง pricing weight แบบบทที่ 13 ได้ อีกสมมติฐานคือไม่มี cash flow ที่เสียไประหว่างรอ และยังมีสิทธิ์ลงทุนครบสองปี

ถ้าโครงการซื้อขายหรือ hedge ไม่ได้ครบ เช่นเครื่องอบของร้านเล็ก ค่า q จากสูตรไม่ใช่ราคายุติธรรมที่ตลาดบังคับให้มีค่าเดียว ต้องใช้ scenario โลกจริงร่วมกับเกณฑ์รับความเสี่ยงหรือ stochastic discount factor ที่อธิบายได้ โครงคิดย้อนกลับยังใช้ได้ แต่ตัวเลข valuation ต้องมีฐานรองรับเพิ่ม

ขั้นที่ 2 — นิยามของโครงตาข่ายสองสถานะ และเงื่อนไขที่ตัวเลขต้องผ่าน

บรรทัดนี้เป็น นิยาม ของแบบจำลองที่เราเลือก ไม่ใช่ผลที่พิสูจน์ มูลค่าโครงการขยับได้สองทาง คือคูณด้วยตัวคูณขาขึ้นหรือขาลง เงื่อนไขในบรรทัดเดียวกันสำคัญกว่าตัวแบบจำลอง: ตัวคูณขาลงต้องน้อยกว่าการฝากเงิน และขาขึ้นต้องมากกว่า ถ้าไม่เป็นแบบนั้น จะมีทางทำกำไรฟรีทันที เช่นถ้าขาลงยังดีกว่าฝากเงิน ก็กู้มาลงทุนได้ไม่จำกัด ซึ่งแปลว่าแบบจำลองไม่สมเหตุสมผล และต้องแก้ตัวเลขก่อนทำอะไรต่อ

\[ X_u=uX_0,\qquad X_d=dX_0,\qquad 0 \lt d \lt R \lt u \]

$X_0$ คือมูลค่าเริ่มต้น USD; $u$ และ $d$ เป็นตัวคูณไม่มีหน่วย; $R$ คือเงินหนึ่งดอลลาร์ที่โตเป็นเท่าไรในหนึ่งปี; เงื่อนไข $d \lt R \lt u$ ป้องกัน risk-neutral probability ติดลบหรือเกินหนึ่ง

ขั้นที่ 3 — หา pricing weight

เมื่อจะตั้งราคาด้วยการถ่วงน้ำหนักแล้วคิดลด น้ำหนักนั้นถูกบังคับ ไม่ได้เลือกเอง หกบรรทัดนี้แสดงว่ามันคือคำตอบของสมการเดียว และเงื่อนไขที่ดูเหมือนข้อกำหนดทางเทคนิค ในขั้นที่ 2 แท้จริงคือเงื่อนไขว่าน้ำหนักต้องใช้ได้จริง

\[ \begin{aligned}\frac{qX_u+(1-q)X_d}{R}&=X_0\\ q\,uX_0+(1-q)\,dX_0&=RX_0\\ qu+(1-q)d&=R\\ q(u-d)&=R-d\\ q&=\frac{R-d}{u-d}\\[4pt] d \lt R \lt u\;&\Longrightarrow\;0 \lt q \lt 1\end{aligned} \]

เงื่อนไขที่กำหนดน้ำหนักคู่นี้มีข้อเดียว ถ้าใช้มันถ่วงสองสถานะแล้วคิดลด ต้องได้ราคาของตัวโครงการเองกลับมาถูกต้อง ไม่อย่างนั้นมันใช้ตั้งราคาอะไรไม่ได้เลย

แทนสองสถานะจากขั้นที่ 2 แล้วตัดมูลค่าตั้งต้นออกทั้งสองข้าง เหลือสมการที่มีตัวไม่รู้ค่าตัวเดียว ย้ายข้างและหารก็จบ

บรรทัดสุดท้ายคือเหตุผลที่เงื่อนไขในขั้นที่ 2 ต้องจริง ถ้าตัวคูณขาลงไม่น้อยกว่าการฝากเงิน น้ำหนักที่ได้จะติดลบ ซึ่งใช้เป็นน้ำหนักไม่ได้ และนั่นก็คือสถานการณ์ที่มีเงินฟรีให้เก็บพอดี

ข้อควรระวังที่ต้องย้ำทุกครั้ง $q$ ไม่ใช่โอกาสที่จะขึ้นจริง มันเป็นน้ำหนักสำหรับตั้งราคาเท่านั้น

ขั้นที่ 4 — backward induction

เริ่มจาก terminal payoff แล้วถอยกลับหนึ่งช่วงเวลา เปรียบเทียบการใช้สิทธิ์ทันทีและการรอ

\[ \begin{aligned}V_T(X_T)&=E_T(X_T)\\ H_t(X_t)&=\frac{qV_{t+1}(uX_t)}{R}\\ &\quad+\frac{(1-q)V_{t+1}(dX_t)}{R}\\ V_t(X_t)&=\max\{E_t(X_t),H_t(X_t)\}\end{aligned} \]

$V_T$ คือ option value ที่ terminal date; $V_t$ คือค่าที่ตัดสินใจได้ ณ ปัจจุบัน; พจน์แรกคือ exercise ทันที; พจน์ที่สองคือ continuation value ที่ discount ด้วย $R$; max บังคับ optimal stopping

$H_t(X_t)$ เป็นชื่อย่อของมูลค่าการรอต่อ: เอามูลค่าขาขึ้นและขาลงถ่วงน้ำหนักด้วย $q$ และ $1-q$ แล้วส่วนด้วย $R$ เพื่อคิดกลับมาวันนี้ จากนั้นเทียบกับมูลค่าการตัดสินใจทันที $E_t(X_t)$

ทำไมต้องเดินถอยหลัง — เดินหน้าตรง ๆ ติดตรงไหน

หลักการนี้มีชื่อว่า dynamic programming และ Richard Bellman ตั้งขึ้นในทศวรรษ 1950 ใจความคือ ถ้าเส้นทางทั้งเส้นดีที่สุด ทุกท่อนย่อยของมันก็ต้องดีที่สุดด้วย จึงแก้ทีละท่อนจากปลายทางย้อนกลับมาได้ โดยไม่ต้องไล่ทุกเส้นทางที่เป็นไปได้

ผลในทางปฏิบัติคือประหยัดมหาศาล ตาข่าย 30 งวดมีเส้นทางเป็นพันล้านเส้น แต่มี node แค่หลักร้อย การเดินถอยหลังแตะแต่ละ node ครั้งเดียว จึงเปลี่ยนปัญหาที่คำนวณไม่ไหวให้เสร็จในพริบตา

\[ \begin{aligned}V_T\left(s\right)&=\Pi\left(s\right)\\ V_t\left(s\right)&=\max\left\{\Pi\left(s\right),\ e^{-r\Delta t}\mathbb{E}^{Q}\left[V_{t+1}\mid s\right]\right\}\\ V_0^{\text{Euro}}&=e^{-rT}\mathbb{E}^{Q}\left[\Pi\left(S_T\right)\right]\\ V_0^{\text{Amer}}&\leftarrow V_1\leftarrow V_2\leftarrow\cdots\leftarrow V_T\end{aligned} \]

เริ่มจากสังเกตว่าคอลัมน์สุดท้ายเป็นคอลัมน์เดียวที่ตอบได้ฟรี วันหมดอายุไม่มีอะไรให้รออีกแล้ว มูลค่าจึงเท่ากับเงินที่ได้ตรง ๆ ไม่ต้องคิดอะไรเลย

พอถอยมาหนึ่งช่อง ทุกอย่างเปลี่ยน เพราะตรงนี้มีทางเลือก จะรับเงินตอนนี้ หรือจะรอดูอีกงวด และการจะรู้ว่าอันไหนดีกว่า ต้องรู้ก่อนว่ารอแล้วได้เท่าไร

จุดที่เดินหน้าแล้วติดอยู่ตรงนี้ ค่าของการรอไม่ใช่ข้อมูลที่โจทย์ให้มา มันคือคำตอบของช่องถัดไป ซึ่งยังไม่ได้คำนวณ ถ้าเดินหน้าก็ต้องใช้ของที่ยังไม่มี

option แบบยุโรปไม่มีปัญหานี้เพราะไม่มีทางเลือกระหว่างทาง เฉลี่ยตอนจบแล้วคิดลดทีเดียวจบ ความต่างทั้งหมดจึงไม่ได้อยู่ที่คณิตศาสตร์ยากขึ้น แต่อยู่ที่มีคนต้องตัดสินใจระหว่างทาง

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

การมองการตัดสินใจลงทุนเป็นสิทธิ์ ไม่ใช่ภาระผูกพัน เปลี่ยนวิธีประเมินโครงการไปทั้งหมด

ใช้ประเมินโครงการที่เลื่อนการตัดสินใจได้ ซึ่งการรอมีมูลค่าที่วิธีมาตรฐานมองไม่เห็น

ใช้ประเมินสิทธิ์ในการขยาย ย่อ หรือปิดกิจการ ซึ่งเป็นสิทธิ์ที่ผู้บริหารมีอยู่จริง

ใช้กับการลงทุนในทรัพยากรธรรมชาติ ที่เลือกจะขุดหรือรอได้ตามราคาตลาด

ขั้นที่ 5 — ตัวเลขของโครงการโรงไฟฟ้า

ตั้งสมมติฐานที่ตรวจได้: มูลค่าโครงการก่อนลงทุนวันนี้ \$10.0M เงินลงทุน \$9.0M ตัวคูณ up 1.4 ตัวคูณ down 0.8 และ risk-free rate 5% ต่อปีแบบ annual compounding

\[ X_0=\$10.0\text{M},\quad I=\$9.0\text{M},\quad u=1.4,\quad d=0.8,\quad R=1.05 \]

$X_0$ และ $I$ เป็น USD million; $u,d$ ไม่มีหน่วย; $R=1+5\%$ คือ growth factor ของเงิน USD หนึ่งปี; horizon ของแต่ละ lattice step คือหนึ่งปี

ขั้นที่ 6 — คำนวณทุก node

คูณมูลค่าโครงการตามกิ่งก่อน แล้วคำนวณ payoff เมื่อหมดเวลารอ

\[ X_1^u=10.0(1.4)=14.0,\quad X_1^d=10.0(0.8)=8.0;\qquad X_2^{uu}=19.6,\quad X_2^{ud}=11.2,\quad X_2^{dd}=6.4\quad(\$\text{M}) \]

$X_1^u$ และ $X_1^d$ คือมูลค่าในปี 1; $X_2^{uu},X_2^{ud},X_2^{dd}$ คือมูลค่าปี 2 ในสาม state; ทุกค่ามีหน่วย USD million

ขั้นที่ 7 — terminal exercise payoff

ใช้กฎ max ที่ปี 2: โครงการที่มูลค่าต่ำกว่าเงินลงทุนไม่ถูกเริ่ม

\[ E_2^{uu}=\max(19.6-9.0,0)=10.6,\quad E_2^{ud}=\max(11.2-9.0,0)=2.2,\quad E_2^{dd}=\max(6.4-9.0,0)=0\quad(\$\text{M}) \]

นำ $X_2-I$ ของแต่ละ state มาหักกัน; ค่า 10.6, 2.2 และ 0 เป็น USD million; state dd ไม่ exercise เพราะจ่ายเงินลงทุนแล้วคุ้มค่าน้อยกว่า

ขั้นที่ 8 — continuation value ในปี 1

หา q ก่อน แล้ว discount expected terminal payoff กลับมาปี 1

\[ q=\frac{1.05-0.8}{1.4-0.8}=0.4166667,\qquad C_1^u=\frac{0.4166667(10.6)+0.5833333(2.2)}{1.05}=5.4286\quad(\$\text{M}) \]

$q$ เท่ากับ 0.4166667 ไม่มีหน่วย; $C_1^u$ คือ continuation value ที่ up node ในปี 1; 0.5833333 คือ $1-q$; ตัวหาร 1.05 discount USD million หนึ่งปี

ขั้นที่ 9 — เปรียบเทียบ exercise กับ wait

ที่ up node การ exercise ทันทีให้ $14.0-9.0=5.0$ million USD แต่การรอให้ $5.4286$ million USD จึงควรรอ; ที่ down node exercise ให้ศูนย์และ continuation ยังมีค่า

\[ V_1^u=\max(5.0,5.4286)=5.4286,\qquad C_1^d=\frac{0.4166667(2.2)+0.5833333(0)}{1.05}=0.8730,\qquad V_1^d=\max(0,0.8730)=0.8730\quad(\$\text{M}) \]

$V_1^u$ และ $V_1^d$ คือ option value ใน up และ down node; exercise payoff ของ up คือ 5.0 USD million; continuation ของ down คือ 0.8730 USD million; max แสดงว่าทั้งสอง node เลือกรอ

คูณน้ำหนักก่อนหารหนึ่งปี

\[ \begin{aligned}&C_1^u=[(5/12)(10.6)+(7/12)(2.2)]/1.05\\ &=(4.4166667+1.2833333)/1.05=5.4285714\\ &C_1^d=[(5/12)(2.2)]/1.05=0.9166667/1.05=0.8730159\\ &V_0=\frac{(5/12)(5.4285714)}{1.05}+\frac{(7/12)(0.8730159)}{1.05}\\ &=(2.2619048+0.5092593)/1.05=2.6392038\end{aligned} \]

ทุกจำนวนเป็นล้าน USD ใช้ q เท่ากับห้าในสิบสองและอีกฝั่งเจ็ดในสิบสองเพื่อไม่ปัดระหว่างทาง เอามูลค่าลูกแต่ละ node คูณน้ำหนักแล้วบวกก่อนหาร 1.05

การรอชนะในตัวอย่างนี้ส่วนหนึ่งเพราะไม่มีรายได้ระหว่างทางที่เราสละไป หากมีรายได้ที่ได้เฉพาะเมื่อลงทุนแล้ว ต้องใส่มันในทาง exercise และปรับ model ของมูลค่าโครงการให้สอดคล้องกัน จึงห้ามสรุปว่ารอชนะทุกโครงการ

ขั้นที่ 10 — มูลค่า real option วันนี้

discount ค่า option จากปี 1 กลับมาวันนี้ แล้วเทียบกับการลงทุนทันที

\[ V_0=\frac{0.4166667(5.4286)+0.5833333(0.8730)}{1.05}=\$2.6392\text{M},\qquad NPV_{\text{now}}=10.0-9.0=\$1.0000\text{M} \]

$V_0$ คือมูลค่าของสิทธิ์รอวันนี้ 2.6392 USD million; $NPV_{now}$ คือมูลค่าถ้าบังคับลงทุนทันที 1.0000 USD million; ส่วนต่าง 1.6392 USD million คือ value of flexibility ภายใต้สมมติฐานนี้

ขั้นที่ 11 — กรณีศึกษาเหมืองทอง: สัญญาเช่าที่มีสิทธิ์หยุดผลิต

โจทย์ให้อะไรมาบ้าง: สัญญาเช่าเหมืองทองสิบค้า ราคาทองวันนี้ \$400 ต่อออนซ์ แต่ละปีราคาคูณด้วย 1.2 หรือ 0.9 ต้นทุนขุด \$200 ต่อออนซ์ ขุดได้ปีละไม่เกินหมื่นออนซ์ อัตราดอกเบี้ย 10% และเมื่อครบสัญญามูลค่าเป็นศูนย์

ตัวที่เพิ่มจากตัวอย่างโรงไฟฟ้าคือ เครื่องหมาย max ในบรรทัดสุดท้าย ซึ่งแทนสิทธิ์ที่จะหยุดขุด

\[ \begin{aligned}S_0&=400,\quad u=1.2,\quad d=0.9,\quad C=200\quad\text{per oz}\\ G&=10{,}000\ \text{oz/yr},\quad r=0.10,\quad T=10\ \text{years}\\[6pt] q\,u+(1-q)\,d=1+r&\quad\Longrightarrow\quad q=\frac{1.1-0.9}{1.2-0.9}=\frac23\\[4pt] V_{10}(s)&=0\\[6pt] V_{t}(s)&=\underbrace{\max\{s-C,0\}\,G}_{\text{produce or stop}}+\frac{q\,V_{t+1}(us)+(1-q)V_{t+1}(ds)}{1+r}\end{aligned} \]

น้ำหนักความน่าจะเป็นที่ใช้ตั้งราคาถูกบังคับโดยต้นไม้อีกครั้ง ไม่ได้เลือกจากความเชื่อเรื่องทิศทางทอง แก้สมการเดียวได้สองในสาม และค่าความน่าจะเป็นทางกายภาพที่โจทย์ให้มาไม่ถูกใช้เลยในการคิดราคา

บรรทัดสุดท้ายคือหัวใจ: รายได้ของปีนี้คือผลต่างระหว่างราคาทองกับต้นทุนขุด คูณกับกำลังผลิต ถ้าผลต่างติดลบก็หยุดขุด รายได้เป็นศูนย์ ไม่ใช่ขาดทุน เพราะหยุดแล้วไม่มีค่าใช้จ่าย

ส่วนที่เหลือคือมูลค่าของการถือสิทธิ์ต่อไป หาค่าเฉลี่ยถ่วงน้ำหนักด้วยน้ำหนักตั้งราคา แล้วคิดลดหนึ่งปี การเดินถอยหลังจากปีที่สิบที่มีค่าเป็นศูนย์จึงเริ่มได้ทันที

เครื่องหมาย max ทำให้หลายสาขาของต้นไม้มีค่าเป็นศูนย์พอดี ซึ่งเป็นสาขาที่ราคาทองต่ำกว่าต้นทุน และนั่นคือส่วนที่ทำให้สัญญาเช่ามีค่ามากกว่าผลรวมรายได้ที่คิดลดแล้ว เพราะสิทธิ์ที่จะไม่ขุดมีค่าเสมอ

ขั้นที่ 12 — ตัวเลขจากการเดินถอยหลังทั้งต้นไม้

สองบรรทัดแรกคือปีสุดท้ายของการขุด ซึ่งไม่ต้องคิดลดอะไรต่อ เพราะสัญญาจบแล้ว สาขาที่ราคาสูงให้ค่ามาก ส่วนสาขาที่ราคาต่ำกว่าต้นทุนให้ศูนย์

บรรทัดกลางคือการตรวจด้วยมือที่ราคาปัจจุบัน และบรรทัดสุดท้ายคือผลของการเดินถอยหลังครบทั้งต้นไม้

\[ \begin{aligned}V_9(s)&=10{,}000\max\{s-200,\,0\}\\[4pt] s=400(1.2)^{9}&=2{,}063.91\ \Rightarrow\ V_9=18{,}639{,}121\\[4pt] s=400(0.9)^{9}&=154.97\ \Rightarrow\ V_9=0\\[6pt] V_8(400)&=10{,}000(400-200)+\frac{\frac23(2{,}800{,}000)+\frac13(1{,}600{,}000)}{1.10}\\[4pt] &=2{,}000{,}000+2{,}181{,}818=4{,}181{,}818\\[6pt] V_0&=26{,}482{,}002\end{aligned} \]

ที่ปีที่เก้า มูลค่าคือรายได้ปีเดียว เพราะปีที่สิบมูลค่าเป็นศูนย์ตามเงื่อนไขสัญญา สาขาบนสุดราคาทองขึ้นไปถึงสองพันกว่าดอลลาร์ จึงขุดเต็มกำลังและได้ค่ามากถึงสิบแปดล้านกว่า

สาขาล่างสุดราคาตกไปเหลือประมาณหนึ่งร้อยห้าสิบห้าดอลลาร์ ต่ำกว่าต้นทุนขุด จึงหยุดขุดทั้งปีและมูลค่าเป็นศูนย์พอดี ไม่ใช่ค่าติดลบ

ตรวจด้วยมือที่ราคาปัจจุบันในปีที่แปด: ขุดได้สองล้านบาทแรก แล้วบวกกับค่าเฉลี่ยถ่วงน้ำหนักของปีถัดไป อีกสองล้านหนึ่งแสน ซึ่งยืนยันว่าการเดินถอยหลังให้ผลตรงกับที่คำนวณมือ

ผลรวมทั้งต้นไม้ให้ค่าสัญญาเช่าวันนี้ยี่สิบหกล้านกว่าดอลลาร์ สูงกว่าผลรวมรายได้ที่คิดลดแล้ว ส่วนต่างนั้นคือมูลค่าของสิทธิ์ที่จะหยุดขุด ซึ่งเป็นสิ่งที่การคิดแบบมูลค่าปัจจุบันสุทธิแบบจุดเดียวไม่เห็น

worked example — กลับไปตอบผู้บริหาร

ของที่มี: project value วันนี้ \$10.0M, investment \$9.0M, up multiplier 1.4, down multiplier 0.8 และ risk-free rate 5% ต่อปี.

ถามว่าลงทุนทันทีหรือเก็บสิทธิ์รอ?

คำตอบ: NPV ลงทุนทันทีคือ \$1.0000M แต่ real option ที่รอได้มีมูลค่า \$2.6392M จึงยังไม่ลงทุนวันนี้.

ตรวจเองใน 10 วินาที: ที่ up node continuation \$5.4286M ต้องมากกว่า exercise payoff \$5.0M.

เอาไปใช้จริง: capital-allocation team ใช้ logic นี้กับโครงการที่เลื่อนหรือหยุดได้ แทนบังคับ NPV จุดเดียวตัดสินทุกอย่าง.

จากสูตรสู่ implementation และการควบคุม

ในระบบ pricing ให้เก็บ lattice เป็น array ของเวลาและ state แล้วทำ backward induction จาก terminal node; อย่าปัดค่าระหว่าง node เพราะการปัดหลายชั้นทำให้ boundary เปลี่ยน ตรวจ unit test ด้วย one-step tree ที่คำนวณมือได้ และทดสอบ limiting cases: ถ้า volatility เป็นศูนย์ option ควรเท่ากับ discounted deterministic payoff; ถ้า I สูงมากค่า option ควรเข้าใกล้ศูนย์; ถ้าให้ exercise ได้ทันทีทุก node ต้องไม่ต่ำกว่า immediate NPV

สำหรับ risk report ให้แยก sensitivity ต่อ $I$, $R$, volatility, horizon และ correlation กับราคาสินค้า อย่ารายงานเพียงราคาเดียว: ติดตาม exercise boundary, model version, input market data timestamp และการอนุมัติ parameter ด้วย ฝ่าย trading ใช้ option value ตัดสินใจว่าจะ lock capacity หรือรอ ส่วนฝ่าย control ต้องตรวจว่า cash flow ที่ใช้สร้าง $X_t$ เป็น incremental จริงและไม่ใส่ sunk cost ซ้ำ เครื่องคิดเลขไม่ควรได้รับ promotion เป็น investment committee เพียงเพราะมันกดปุ่มเร็วกว่า

ตัวอย่างที่สอง — คำตอบและวิธีเช็ก

คำตอบ: สัญญาเช่ามีมูลค่าวันนี้ \$26,482,002 และตัวเลขนี้สูงกว่าผลรวมรายได้ที่คิดลดแล้ว เพราะมีสิทธิ์หยุดขุดในปีที่ราคาต่ำกว่าต้นทุน

ตรวจเองใน 10 วินาที: ที่สาขาล่างสุดของปีที่เก้า ราคาทองต่ำกว่าต้นทุน ดังนั้นมูลค่าต้องเป็นศูนย์พอดี ถ้าได้ค่าติดลบแสดงว่าใช้สูตรผิด

ใช้ตัดสินใจ: เวลาประเมินโครงการที่มีทางเลือกให้หยุด ให้ใส่ max เข้าไปในสูตร เพราะการไม่ใส่จะประเมินค่าต่ำไป และส่วนที่ประเมินต่ำไปคือมูลค่าของความยืดหยุ่นนั่นเอง

กับดัก: risk-neutral probability ไม่ใช่ forecast

ค่า $q=0.4166667$ ถูกสร้างเพื่อให้การ discount สอดคล้องกับ no-arbitrage ไม่ได้บอกว่า analyst เชื่อว่าโครงการมีโอกาสขึ้น 41.66667% ในโลกจริง การประเมินลงทุนต้องใช้ scenario หรือ real-world probability แยกต่างหาก ส่วนการตั้งราคา option ต้องใช้ pricing measure และ discount curve ที่เหมาะสม อีกกับดักคือใช้ volatility สูงแล้วสรุปว่า option ดีเสมอ: ถ้าโครงการมี downside cash outflow, abandonment cost, liquidity constraint หรือ capacity ที่ขยายไม่ได้ ความ convexity อาจหายไป

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
การสร้างซ้ำมีสินทรัพย์ในตลาดที่เลียนแบบโครงการได้โครงการจริงมักไม่มีของแบบนั้นการใช้ราคาที่ปรับความเสี่ยงแล้วในกรณีนี้ไม่มีฐานรองรับเท่ากับกรณี derivative
สิทธิ์ที่แท้จริงเรามีสิทธิ์เลือกจริงคู่แข่งอาจลงมือก่อนจนสิทธิ์หายไปการรอมีต้นทุนที่แบบจำลองพื้นฐานไม่ได้คิด
ตัวเลขที่ใส่รู้ความผันผวนของมูลค่าโครงการประมาณยากมากเพราะไม่มีราคาตลาดมูลค่าที่คำนวณได้ไวต่อค่านี้มาก และค่านี้แทบจะเป็นการเดา

แถวล่างเป็นเหตุผลที่วิธีนี้ใช้เป็นกรอบคิดได้ดี แต่ใช้เป็นตัวเลขตัดสินใจต้องระวังมาก

จุดที่บทถัดไปรับช่วง: จาก lattice เดียวสู่ commodity derivatives

lattice นี้มี state เดียวและจุดตัดสินใจห่างกันหนึ่งปี แต่โครงการพลังงานจริงมีราคาก๊าซ ราคาพลังงาน สภาพอากาศ inventory และ transmission constraint พร้อมกัน ขั้นต่อไปคือ commodity derivatives: storage ทำหน้าที่เหมือน real option ที่เลือก inject หรือ withdraw และ electricity มี price spike กับ non-storability ซึ่งทำให้ต้องเปลี่ยนจากต้นไม้ทบต้นแบบง่ายไปสู่ mean-reverting และ jump model

สรุปที่ใช้ได้จริง

  • real option แยกมูลค่าการลงทุนทันทีออกจากมูลค่าความยืดหยุ่นในการรอ
  • dynamic programming แก้จาก terminal payoff ย้อนกลับด้วย max ของ exercise และ continuation value
  • risk-neutral probability ใช้ตั้งราคา ไม่ใช่ forecast ความน่าจะเป็นจริง
  • implementation ที่ดีต้องตรวจ exercise boundary, limiting cases, units, input timestamp และ model version
  • โครงการจริงอาจมีหลาย state, transaction cost และข้อจำกัดการหยุดหรือขยาย จึงต้อง stress test นอก lattice ง่าย
  • ต้องเดินถอยหลังเพราะค่าของการรอคือคำตอบของช่องถัดไป ไม่ใช่ข้อมูลที่มีอยู่ option ยุโรปไม่มีทางเลือกระหว่างทางจึงเดินหน้าได้ครั้งเดียวจบ ส่วนของที่เลือกได้ทุกงวดต้องเริ่มจากวันหมดอายุที่ไม่มีอะไรให้รอ
  • สิทธิ์ที่จะหยุดผลิตเขียนเป็น max{s-C, 0} ในสูตร ทำให้สาขาที่ราคาต่ำกว่าต้นทุนมีค่าเป็นศูนย์พอดี และทำให้โครงการมีค่ามากกว่าผลรวมรายได้ที่คิดลดแล้ว
  • กรณีศึกษาเหมืองทอง: q = 2/3 มาจากต้นไม้ ไม่ได้มาจากความเชื่อเรื่องทิศทางราคา และมูลค่าสัญญาเช่าคือ \$26,482,002
