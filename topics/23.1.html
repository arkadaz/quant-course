23.1 Real Options and Dynamic Programming

สิทธิ์ที่จะรอ ขยาย หรือเลิกโครงการจริงมีราคา และหาราคานั้นได้ด้วยการคิดย้อนจากปลายทางทีละ node

บริษัทพลังงานถือใบอนุญาตสร้างโรงไฟฟ้า ถ้าสร้างวันนี้ โรงไฟฟ้ามีมูลค่า \$10 ล้าน (มูลค่าปัจจุบันของเงินสดทั้งหมดที่มันจะทำได้) ค่าก่อสร้าง \$9 ล้าน NPV จึงเป็น +\$1 ล้าน ใบอนุญาตให้เลื่อนการสร้างได้ถึงสองปี แต่ละปีมูลค่าโรงไฟฟ้าคูณ 1.4 หรือคูณ 0.8 ดอกเบี้ยไม่มีความเสี่ยง 5% ต่อปี ฝ่ายวางแผนเสนอว่า “NPV เป็นบวก สร้างวันนี้เลย” ควรเซ็นอนุมัติไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ควร ใบอนุญาตที่ยังไม่ใช้มีค่า \$2.6392 ล้าน ส่วนการสร้างวันนี้ได้แค่ \$1 ล้าน การเซ็นวันนี้จึงทิ้งมูลค่าไป \$1.6392 ล้าน ค่าของการรอมาจากสองแหล่ง คือได้จ่ายค่าก่อสร้างช้าลงสองปี (มีค่า \$1.8367 ล้าน) และได้สิทธิ์ที่จะไม่สร้างเลยถ้ามูลค่าตกเหลือ \$6.4 ล้าน (มีค่า \$0.8025 ล้าน) NPV บวกบอกว่าโครงการดี แต่ไม่ได้บอกว่าวันนี้คือวันที่ดีที่สุด

ภาพรวมก่อนลงสูตร

NPV ตอบคำถามเดียว: ถ้าต้องตัดสินใจเดี๋ยวนี้แบบทำหรือไม่ทำเลย คุ้มไหม แต่ผู้บริหารตัวจริงแทบไม่เคยเจอคำถามแบบนั้น เขาเลื่อนได้ ขยายทีหลังได้ หยุดกลางทางได้ หรือเปลี่ยนวิธีเดินเครื่องได้ ทุกข้อเป็นสิทธิ์ ไม่ใช่หน้าที่ จึงเป็น option ชนิดหนึ่ง แต่สิ่งที่อ้างอิงคือสินทรัพย์จริง เช่นโรงไฟฟ้า เหมือง หรือโรงงาน จึงเรียกว่า real option

โครงการจริงมีความไม่แน่นอนหลายชั้น: ราคาและความต้องการของตลาด อุตสาหกรรม (การควบรวม เทคโนโลยีใหม่) เทคนิค (ผลวิจัยจะสำเร็จไหม) คนในองค์กร และการเมือง (กฎหมาย สงคราม) ความยืดหยุ่นคือเครื่องมือรับมือความไม่แน่นอนเหล่านี้ และการบริหารโครงการก็คือการบริหารความยืดหยุ่น คำถามของหน้านี้คือความยืดหยุ่นมีราคาเท่าไร

วิธีตอบคือวางมูลค่าโครงการบนต้นไม้ราคาสองกิ่ง แล้วเดินจากปลายทางย้อนมา ในทุก node เทียบ “ใช้สิทธิ์เดี๋ยวนี้” กับ “รออีกหนึ่งก้าว” แล้วเก็บตัวที่มากกว่า วิธีคิดย้อนแบบนี้เรียกว่า dynamic programming เราจะเริ่มจากเกมลูกเต๋า ตีราคาใบอนุญาตโรงไฟฟ้า แยกคำตอบเป็นค่าของเวลากับค่าของประกัน ดูสิทธิ์ทิ้งกับสิทธิ์ขยาย แล้วจบที่เหมืองทอง Simplico ซึ่งมีสิทธิ์อัปเกรดเครื่องจักรที่ต้องเลือกจังหวะ รูปด้านล่างคือคำตอบทั้งหมดของโรงไฟฟ้าในภาพเดียว

ศัพท์ที่ใช้ในหัวข้อนี้
Real option
สิทธิ์ (ไม่ใช่หน้าที่) ที่จะลงทุน เลื่อน ขยาย ลดขนาด หยุด หรือเปลี่ยนวิธีใช้สินทรัพย์จริง ใช้ตีราคาความยืดหยุ่นที่ NPV จุดเดียวมองไม่เห็น
NPV (net present value)
มูลค่าปัจจุบันของเงินสดที่โครงการสร้าง ลบเงินลงทุน ตอบว่าถ้าต้องตัดสินใจเดี๋ยวนี้ คุ้มไหม แต่ไม่ถามว่ารอแล้วดีกว่าไหม
Backward induction
แก้ปัญหาหลายช่วงเวลาโดยเริ่มจากช่วงสุดท้ายซึ่งไม่เหลือทางเลือก แล้วถอยมาทีละช่วง จำเป็นเพราะกฎตัดสินใจวันนี้ต้องรู้ค่าของอนาคตก่อน
Dynamic programming
วิธีแตกปัญหาใหญ่เป็นปัญหาย่อยทีละ node แล้วใช้คำตอบของ node ลูกซ้ำ แทนการไล่ทุกเส้นทาง ต้นไม้สิบปีมี 66 node แต่มี 1,024 เส้นทาง
Continuation value
มูลค่าของการยังไม่ใช้สิทธิ์และรอไปอีกหนึ่งช่วง เป็นคู่เทียบของมูลค่าการใช้สิทธิ์ทันทีในทุก node
Pricing weight (risk-neutral weight)
น้ำหนักที่ทำให้ต้นไม้ตั้งราคาตัวโครงการเองได้ถูก ใช้ถ่วงกิ่งเพื่อตั้งราคา ไม่ใช่โอกาสจริงที่มูลค่าจะขึ้น
Exercise และ exercise boundary
exercise คือการใช้สิทธิ์ เช่นจ่ายค่าก่อสร้างหรือค่าอัปเกรด หลังจากนั้นสิทธิ์ก็หมดไป exercise boundary คือเส้นแบ่งบนต้นไม้ระหว่าง node ที่ควรใช้สิทธิ์ทันทีกับ node ที่ควรรอ

ขั้นที่ 1 — เกมลูกเต๋า: ทำไมต้องคิดจากปลายทาง

ก่อนแตะโรงไฟฟ้า ลองเกมที่ตรวจเองได้ทุกตัวเลข ทอยลูกเต๋าได้ไม่เกินสามครั้ง หลังแต่ละครั้งเลือกหยุดแล้วรับเงินเท่าแต้มที่ออก (ดอลลาร์) หรือทิ้งแต้มนั้นแล้วทอยใหม่ ค่าเข้าเล่นที่ยุติธรรมคือเท่าไร?

โจทย์ให้อะไรมาบ้าง: ลูกเต๋าหกหน้า แต่ละหน้าออกด้วยโอกาส 1/6 คำถามที่ติดทันทีคือ ครั้งแรกได้ 4 ควรเก็บไหม? ตอบไม่ได้จนกว่าจะรู้ว่าการทอยต่อมีค่าเท่าไร และค่าของการทอยต่อก็ขึ้นกับกฎของครั้งหลัง ๆ เราจึงต้องเริ่มจากครั้งที่สาม ซึ่งไม่มีอะไรให้เลือกแล้ว

\[ \begin{aligned} V_3&=\frac{1+2+3+4+5+6}{6}=3.5,\\ V_2&=\frac{4+5+6}{6}+\frac36(3.5)\\ &=2.5+1.75=4.25,\\ V_1&=\frac{5+6}{6}+\frac46(4.25)\\ &=1.8333+2.8333=4.6667. \end{aligned} \]

ครั้งที่สามต้องรับแต้มที่ออก ค่าเฉลี่ยคือ 3.5 ถอยมาครั้งที่สอง ตอนนี้รู้แล้วว่าทอยต่อมีค่า 3.5 จึงเก็บ 4, 5, 6 (ดีกว่า 3.5) และทอยใหม่เมื่อได้ 1, 2, 3 ก้อนแรกของ $V_2$ คือแต้มที่เก็บถ่วงด้วยโอกาส ก้อนที่สองคือครึ่งหนึ่งของเวลาที่ทอยใหม่ซึ่งมีค่า 3.5

ครั้งแรก เกณฑ์ขยับขึ้นเป็น 4.25 จึงเก็บแค่ 5 กับ 6 เกณฑ์หยุดสูงกว่าเมื่อยังเหลือโอกาสมาก นี่คือหน้าตาของทุกปัญหาในหน้านี้: ในแต่ละจุด เทียบเงินที่ได้ถ้าหยุดเดี๋ยวนี้กับค่าของการรอ แล้วเลือกตัวที่มากกว่า

คำตอบ: ค่าเข้าเล่นที่ยุติธรรมคือ \$4.6667 (= 14/3) กฎเล่นคือ ครั้งแรกเก็บเฉพาะ 5 หรือ 6 ครั้งที่สองเก็บ 4 ขึ้นไป ครั้งที่สามรับอะไรก็ได้ที่ออก

ตรวจเองใน 10 วินาที: $6\times4.6667=28=5+6+4(4.25)=11+17$ ถ้าเล่นได้ 1,000 ครั้ง เกณฑ์จะสูงจนเก็บแต่ 6 และค่าของเกมเข้าใกล้ 6

ขั้นที่ 2 — สิทธิ์ที่จะสร้างคือ call option

กลับมาที่โรงไฟฟ้า ถ้าปีใดตัดสินใจสร้าง บริษัทจ่าย $I$ แล้วได้โรงไฟฟ้ามูลค่า $X_t$ ถ้า $X_t$ ต่ำกว่า $I$ บริษัทแค่ไม่สร้าง ไม่มีใครบังคับ เงินที่ได้จากการใช้สิทธิ์จึงนิยามได้แบบนี้ และต่างจากกรณีถูกบังคับสร้างตรงกิ่งที่แย่

\[ \begin{aligned} P_t&=\max(X_t-I,\ 0),\\ X-I&=6.4-9.0=-2.6,\\ \max(6.4-9.0,\ 0)&=0. \end{aligned} \]

รูปเดียวกับ payoff ของ call บนต้นไม้ราคาสองกิ่ง: $X_t$ เล่นบทราคาหุ้น $I$ เล่นบท strike ต่างกันแค่ “หุ้น” ตัวนี้คือโครงการที่ยังไม่ได้สร้าง มุมหักที่ $I$ คือแหล่งมูลค่าทั้งหมด กิ่งที่แย่ถูกตัดที่ศูนย์ ส่วนกิ่งที่ดียังเก็บไว้ครบ

ขั้นที่ 3 — ต้นไม้ของมูลค่าโครงการ และน้ำหนักตั้งราคา q

ต้องมีแบบจำลองว่า $X$ เดินอย่างไร เราใช้ต้นไม้สองกิ่ง ปีละหนึ่งก้าว ขึ้นคูณ $u$ ลงคูณ $d$ นี่คือสมมติฐานที่เราเลือก ไม่ใช่ผลที่พิสูจน์ จากนั้นต้องรู้ว่าจะถ่วงสองกิ่งด้วยอะไร น้ำหนักนั้นต้องตั้งราคาตัวโครงการเองให้ถูกก่อน ไม่อย่างนั้นก็ใช้ตั้งราคาอะไรไม่ได้ เงื่อนไขข้อเดียวนี้กำหนด $q$ ออกมาทันที

\[ \begin{aligned} X_{t+1}&=uX_t\quad\text{or}\quad dX_t,\\ 0&\lt d\lt R\lt u,\\ X_1&=14.0\quad\text{or}\quad 8.0,\\ X_2&=19.6,\quad 11.2,\quad 6.4,\\ \frac{q\,uX_0+(1-q)\,dX_0}{R}&=X_0,\\ q=\frac{R-d}{u-d}&=\frac{1.05-0.8}{1.4-0.8}=\frac{5}{12}. \end{aligned} \]

ทำไมต้อง $d\lt R\lt u$: ถ้าแม้แต่กิ่งลงยังโตกว่าเงินฝาก ใครก็ยืมเงินที่ 5% มาถือโครงการแล้วกำไรทุกกิ่ง เงินฟรีแบบนี้อยู่ไม่ได้ ถ้า $u\le R$ ก็กลับด้านกัน ตัวเลขชุดนี้ $0.8\lt1.05\lt1.4$ ผ่าน และขึ้นแล้วลงกับลงแล้วขึ้นมาที่เดียวกัน ($14.0\times0.8=8.0\times1.4=11.2$) ปีที่ 2 จึงมี 3 node ไม่ใช่ 4

บรรทัดที่ห้าบอกว่าถ่วงสองกิ่งแล้วหารด้วย $R$ ต้องได้มูลค่าวันนี้กลับมา หาร $X_0$ ออกทั้งสองข้างได้ $qu+(1-q)d=R$ เหลือตัวไม่รู้ตัวเดียว ตรวจ: $\big(\tfrac{5}{12}(14)+\tfrac{7}{12}(8)\big)/1.05=10.5/1.05=10$ เงื่อนไข $d\lt R\lt u$ คือเงื่อนไขที่ทำให้ $0\lt q\lt1$ พอดี

$q=5/12\approx0.4167$ ไม่ใช่โอกาสจริงที่มูลค่าจะขึ้น ต่อให้ทีมวิเคราะห์เชื่อว่าโอกาสขึ้นคือ 60% คำตอบก็ไม่เปลี่ยน เพราะความเชื่อนั้นอยู่ในราคา 10 วันนี้แล้ว แต่การใช้ $q$ แบบนี้มีเงื่อนไขซ่อนอยู่: ต้องมีของในตลาดที่ซื้อและขายชอร์ตได้ซึ่งเคลื่อนไหวเหมือนมูลค่าโครงการ เพื่อสร้างพอร์ต hedge ได้ ทองคำในเหมืองท้ายหน้านี้ซื้อขายได้ จึงเข้าเงื่อนไข ส่วนโรงไฟฟ้าพอ hedge ได้บางส่วนด้วยการขายไฟล่วงหน้า

ขั้นที่ 4 — สมการเดียวที่ใช้ทั้งหน้า

รวมกฎของเกมลูกเต๋ากับน้ำหนัก $q$ ที่ปลายต้นไม้สิทธิ์หมดอายุ มูลค่าจึงเท่ากับเงินที่ได้ถ้าใช้สิทธิ์ ก่อนหน้านั้นทุก node เทียบใช้สิทธิ์เดี๋ยวนี้กับรออีกหนึ่งก้าว

\[ \begin{aligned} V_T(X)&=P_T(X)=\max(X-I,\ 0),\\ H_t(X)&=\frac{q\,V_{t+1}(uX)+(1-q)\,V_{t+1}(dX)}{R},\\ V_t(X)&=\max\{P_t(X),\ H_t(X)\}. \end{aligned} \]

บรรทัดที่สองคือ continuation value: มูลค่าของลูกสองตัว ถ่วงด้วย $q$ แล้วหารด้วย $R$ บรรทัดที่สามคือกฎของเกมลูกเต๋า สมการรูปนี้เรียกว่าสมการ Bellman ชื่อ dynamic programming มาจากตรงนี้ แต่ละ node ใช้คำตอบของลูกที่คิดไว้แล้ว ไม่ต้องไล่ทุกเส้นทาง

ต้นไม้ $T$ ก้าวมี $(T+1)(T+2)/2$ node แต่มีเส้นทาง $2^T$ เส้น สองปีคือ 6 node กับ 4 เส้นทาง สิบปีคือ 66 node กับ 1,024 เส้นทาง ยิ่งต้นไม้ลึก ส่วนต่างยิ่งมหาศาล

ขั้นที่ 5 — เดินถอยหลังสองปี: รอชนะในทุก node

โจทย์ให้อะไรมาบ้าง: มูลค่าปีที่ 2 จากต้นไม้ 19.6, 11.2, 6.4 ค่าก่อสร้าง $I=9.0$ และ $q=5/12$ ปีที่ 2 เป็นปีสุดท้าย จึงสร้างเฉพาะกิ่งที่คุ้ม แล้วถอยมาปีที่ 1 และวันนี้ด้วยสมการ Bellman ที่เพิ่งเขียน

\[ \begin{aligned} V_2&=10.6,\quad 2.2,\quad 0,\\ H_1^u&=\frac{\frac{5}{12}(10.6)+\frac{7}{12}(2.2)}{1.05}\\ &=\frac{4.4167+1.2833}{1.05}=5.4286,\\ V_1^u&=\max(14.0-9.0,\ 5.4286)=5.4286,\\ H_1^d&=\frac{\frac{5}{12}(2.2)+\frac{7}{12}(0)}{1.05}=0.8730,\\ V_1^d&=\max(0,\ 0.8730)=0.8730,\\ H_0&=\frac{\frac{5}{12}(5.4286)+\frac{7}{12}(0.8730)}{1.05}\\ &=\frac{2.2619+0.5093}{1.05}=2.6392,\\ V_0&=\max(1.0,\ 2.6392)=2.6392. \end{aligned} \]

คำตอบ: ใบอนุญาตมีค่า \$2.6392 ล้าน สร้างวันนี้ได้ \$1.0 ล้าน ส่วนต่าง \$1.6392 ล้านคือค่าของความยืดหยุ่น การเซ็นสร้างวันนี้คือการขายสิทธิ์ที่มีค่า 2.6392 ในราคา 1.0 แม้แต่กิ่งบนของปีที่ 1 ที่สร้างแล้วได้ทันที 5.0 ก็ยังควรรอ เพราะการรอมีค่า 5.4286

ตรวจเองใน 10 วินาที: จากกิ่งบนของปีที่ 1 ลูกทั้งสอง (19.6 และ 11.2) เกิน 9 จึงสร้างแน่ ค่าของการรอจึงเท่ากับ $14.0-9.0/1.05=14.0-8.5714=5.4286$ ส่วนต่าง 0.4286 คือดอกเบี้ยหนึ่งปีของค่าก่อสร้างที่ยังไม่ต้องจ่าย และค่าวันนี้ต้องไม่ต่ำกว่า NPV 1.0 เพราะสิทธิ์รวมทางเลือก “สร้างวันนี้” ไว้แล้ว

ขั้นที่ 6 — 2.6392 มาจากไหน: ค่าของเวลา บวกค่าของประกัน

ตัวเลขเดียวไม่บอกว่าความยืดหยุ่นมาจากไหน สังเกตว่าไม่มี node ไหนเลือกสร้างก่อนปีที่ 2 สิทธิ์นี้จึงเท่ากับ call ที่ใช้สิทธิ์ได้แค่ปีที่ 2 และแยกได้ด้วยเอกลักษณ์ของ max ข้างล่าง

\[ \begin{aligned} \max(X-I,0)&=(X-I)+\max(I-X,0),\\ V_0&=\frac{\mathbb E_q[X_2]-I}{R^2}\\ &\quad+\frac{\mathbb E_q[\max(I-X_2,0)]}{R^2}\\ &=10-\frac{9}{1.05^2}+\frac{(7/12)^2(2.6)}{1.05^2}\\ &=10-8.1633+0.8025\\ &=1.8367+0.8025=2.6392. \end{aligned} \]

บรรทัดแรกจริงทั้งสองกรณี: ถ้า $X\ge I$ ก้อนหลังเป็นศูนย์ ถ้า $X\lt I$ สองก้อนรวมกันได้ศูนย์ บรรทัดที่สี่ใช้สองอย่าง $\mathbb E_q[X_2]/R^2=X_0=10$ เพราะ $q$ ถูกสร้างมาให้ตั้งราคาโครงการถูกทีละก้าว (ใช้สองครั้ง) และมีกิ่งเดียวที่ $I-X_2$ เป็นบวก คือ 6.4 ซึ่งมีน้ำหนัก $(7/12)^2=0.3403$ และขาดอยู่ 2.6

ก้อนแรก 1.8367 คือค่าของการจ่ายค่าก่อสร้างช้าสองปี ต่อให้สัญญาว่าจะสร้างแน่ในปีที่ 2 ก็ได้เท่านี้แล้ว ก้อนที่สอง 0.8025 คือประกัน: สิทธิ์ที่จะไม่สร้างในกิ่งที่แย่ ซึ่งก็คือ put บนโครงการ นี่คือ put–call parity (call = ของอ้างอิง − strike ที่คิดลด + put) ในชุดของโครงการจริง

ขั้นที่ 7 — ความไม่แน่นอนเพิ่มค่าเฉพาะเมื่อมีกิ่งที่ขาดทุน

คนมักพูดว่าความผันผวนสูงทำให้ option มีค่ามากขึ้น ซึ่งจริงแค่ครึ่งเดียว ลองตรึงค่ากลางของตัวคูณไว้ที่ 1.1 แล้วถ่างช่องห่าง $g=u-d$ ดูว่ากิ่งล่างสุดตกต่ำกว่า 9 เมื่อไร

\[ \begin{aligned} u&=1.1+g/2,\quad d=1.1-g/2,\\ 10d^2&\ge9,\qquad d_{\min}=\sqrt{0.9}=0.94868,\\ g_{\max}&=2(1.1-0.94868)=0.30263,\\ V_0(g\le g_{\max})&=10-\frac{9}{1.05^2}=1.8367,\\ V_0(0.4)&=2.1556,\quad V_0(0.6)=2.6392,\\ V_0(1.0)&=3.3184. \end{aligned} \]

กิ่งล่างสุดของปีที่ 2 คือ $10d^2$ ซึ่งไม่ต่ำกว่า 9 ตราบที่ $d\ge d_{\min}$ หรือช่องห่างไม่เกิน $g_{\max}$ ถ้ากิ่งที่แย่ที่สุดยังเกิน 9 สิทธิ์ที่จะไม่สร้างไม่เคยถูกใช้ ก้อนประกันของการแยกเวลากับประกันเป็นศูนย์ เหลือแค่ค่าของเวลา 1.8367 ไม่ว่าช่องห่างเท่าไร เมื่อ $g$ เกิน 0.30263 กิ่งล่างสุดเริ่มขาดทุน ประกันจึงเริ่มมีค่าและโตตามช่องห่าง

ตัวอย่าง $g=1.0$: $u=1.6$, $d=0.6$, $q=(1.05-0.6)/1.0=0.45$ ปีที่ 2 ได้ 25.6, 9.6, 3.6 สร้างได้ 16.6, 0.6, 0 ค่าวันนี้ $\big(0.45^2(16.6)+2(0.45)(0.55)(0.6)\big)/1.05^2=3.3184$ ช่องห่างต้องเกิน 0.1 ด้วย เพราะ $d=1.1-g/2$ ต้องต่ำกว่า $R=1.05$ กราฟข้างล่างจึงเริ่มที่ 0.12

ขั้นที่ 8 — สิทธิ์ทิ้งคือ put สิทธิ์ขยายคือ call

สิทธิ์รอเป็นแค่หนึ่งในครอบครัว ลองสมมติว่าบริษัทสร้างโรงไฟฟ้าวันนี้ไปแล้ว (NPV 1.0) และสัญญามีสิทธิ์เพิ่มสองข้อที่ใช้ได้ในปีที่ 1 ข้อแรก ขายโรงไฟฟ้าให้ผู้ซื้อรายหนึ่งที่ตกลงรับซื้อไว้ \$9 ล้าน ข้อสอง จ่าย \$3 ล้านเพื่อขยายกำลังผลิต ทำให้มูลค่าเพิ่ม 30%

โจทย์ให้อะไรมาบ้าง: ปีที่ 1 มูลค่าเป็น 14 หรือ 8 น้ำหนัก 5/12 กับ 7/12 หารด้วย 1.05 สิทธิ์ทิ้งจ่าย $\max(9-X_1,0)$ สิทธิ์ขยายจ่าย $\max(0.3X_1-3,0)$

\[ \begin{aligned} A_1&=\max(9-X_1,\ 0)=0\ \text{or}\ 1,\\ A_0&=\frac{\frac{7}{12}(1)}{1.05}=0.5556,\\ E_1&=\max(0.3X_1-3,\ 0)=1.2\ \text{or}\ 0,\\ E_0&=\frac{\frac{5}{12}(1.2)}{1.05}=0.4762,\\ 1.0+0.5556+0.4762&=2.0318. \end{aligned} \]

สิทธิ์ทิ้ง (abandon) ให้เงินเฉพาะกิ่งลง: มูลค่า 8 แต่ขายได้ 9 ได้ส่วนต่าง 1 มันคือ put บนโครงการที่มีราคาขายทิ้งเป็น strike สิทธิ์ขยาย (expand) ให้เงินเฉพาะกิ่งขึ้น: 30% ของ 14 คือ 4.2 จ่าย 3 ได้ 1.2 ส่วนกิ่งลง 30% ของ 8 คือ 2.4 ไม่คุ้ม 3 จึงไม่ขยาย มันคือ call บนส่วนที่ขยาย

บรรทัดสุดท้ายบวกกันได้ตรง ๆ เพราะสองสิทธิ์ถูกใช้คนละกิ่ง ถ้ามีกิ่งที่อยากใช้ทั้งคู่ บวกกันไม่ได้ เพราะทิ้งโครงการแล้วก็ไม่มีอะไรให้ขยาย ครอบครัวที่เหลือมีหน้าตาเดียวกัน: ลดขนาด (put บนส่วนที่ตัดทิ้ง) สลับวิธีเดินเครื่อง (โรงไฟฟ้าที่เปิดปิดตามราคา ซึ่งเป็นเรื่องของหน้าถัดไป) ทำเป็นเฟส (ยาใหม่ที่ทดลองทีละเฟสและหยุดได้ทุกเฟส แต่ละเฟสคือ option บนเฟสถัดไป) และ option ต่อยอด (โครงการนำร่องที่ NPV ติดลบ แต่เปิดทางให้โครงการรุ่นถัดไปที่ทำกำไร)

คำตอบ: สิทธิ์ทิ้งมีค่า \$0.5556 ล้าน สิทธิ์ขยายมีค่า \$0.4762 ล้าน โครงการที่สร้างวันนี้พร้อมสองสิทธิ์มีค่า \$2.0318 ล้าน ยังน้อยกว่าการถือใบอนุญาตแล้วรอ (\$2.6392 ล้าน) ในตัวเลขชุดนี้

ตรวจเองใน 10 วินาที: put กับ call ที่ strike ต่างกันได้ศูนย์คนละกิ่ง เลยไม่ต้องเลือกระหว่างกัน ถ้าราคาขายทิ้งขึ้นเป็น 14 สิทธิ์ทิ้งจะจ่ายในกิ่งลง 6 และกิ่งขึ้น 0 ค่ากลายเป็น $\tfrac{7}{12}(6)/1.05=3.3333$

ขั้นที่ 9 — เหมืองทอง Simplico: สิทธิ์หยุดขุดที่เกิดซ้ำทุกปี

โรงไฟฟ้ามีการตัดสินใจครั้งเดียว ตัวอย่างคลาสสิกจากตำรา Investment Science ของ David Luenberger (เหมือง Simplico) มีการตัดสินใจทุกปี สัญญาเช่าเหมืองทอง 10 ปี ราคาทองวันนี้ \$400 ต่อออนซ์ แต่ละปีคูณ 1.2 (โอกาสจริง 0.75) หรือคูณ 0.9 (โอกาสจริง 0.25) ต้นทุนขุด \$200 ต่อออนซ์ ขุดได้ไม่เกิน 10,000 ออนซ์ต่อปี ดอกเบี้ย 10% ทองที่ขุดในปีหนึ่งขายตอนสิ้นปีด้วยราคาต้นปี และหยุดขุดปีไหนก็ได้โดยไม่มีค่าใช้จ่าย

\[ \begin{aligned} q&=\frac{1.1-0.9}{1.2-0.9}=\frac23,\\ V_{10}(s)&=0,\\ V_t(s)&=\frac{G\max(s-C,\ 0)}{1+r}\\ &\quad+\frac{q\,V_{t+1}(us)+(1-q)\,V_{t+1}(ds)}{1+r}. \end{aligned} \]

บรรทัดแรกคือสูตร $q$ เดิมกับตัวเลขของเหมือง โอกาสจริง 0.75 ไม่ปรากฏที่ไหนเลย เพราะทองซื้อขายและขายชอร์ตได้ ราคา 400 วันนี้จึงรวมความเชื่อทั้งหมดไว้แล้ว $V_{10}=0$ เพราะสัญญาเช่าหมดแล้วเหมืองกลับไปเป็นของเจ้าของ

ก้อนแรกของบรรทัดสุดท้ายคือกำไรปีนี้ ถ้าราคาต่ำกว่าต้นทุนก็หยุดขุด ได้ศูนย์ ไม่ใช่ติดลบ นี่คือ max ของสิทธิ์ที่จะไม่สร้างที่เกิดซ้ำทุกปี เงินได้ตอนสิ้นปีจึงอยู่ใต้ตัวหาร $1+r$ ก้อนที่สองคือมูลค่าสัญญาปีหน้า ถ่วงด้วย $q$ แล้วหารหนึ่งปี ต่างจากโรงไฟฟ้าตรงที่ไม่มีการเทียบใช้สิทธิ์กับรอ เพราะการหยุดขุดปีนี้ไม่ทำให้เสียสิทธิ์ปีหน้า การตัดสินใจแต่ละปีจึงแยกจากกัน

ขั้นที่ 10 — ตรวจสอง node ด้วยมือ แล้วอ่านค่าวันนี้

โจทย์ให้อะไรมาบ้าง: สมการเหมืองที่เพิ่งเขียน ราคาปีที่ 9 บนสุด $400(1.2)^9=2{,}063.91$ ล่างสุด $400(0.9)^9=154.97$ และ node ตรงกลางของปีที่ 6 ราคา $400(1.2)^3(0.9)^3=503.88$ ซึ่งลูกสองตัวคิดไว้แล้วจากรอบก่อน: $V_7(604.66)=11{,}517{,}071$ และ $V_7(453.50)=7{,}394{,}377$

\[ \begin{aligned} V_9(2{,}063.91)&=\frac{10{,}000(1{,}863.91)}{1.1}\\ &=16{,}944{,}656,\\ V_9(154.97)&=0,\\ V_6(503.88)&=\frac{13{,}181{,}688}{1.1}=11{,}983{,}353,\\ V_0(400)&=24{,}074{,}547,\\ V_0^{\text{forced}}&=\sum_{t=0}^{9}\Big(\frac{G\,S_0}{1.1}-\frac{G\,C}{1.1^{t+1}}\Big)\\ &=36{,}363{,}636-12{,}289{,}134\\ &=24{,}074{,}502. \end{aligned} \]

สามบรรทัดล่างตรวจคำตอบด้วยวิธีที่สอง: ถ้าถูกบังคับขุดทุกปี ทองที่ขุดในปี $t$ มีมูลค่าวันนี้ $G\,S_0/1.1$ เท่ากันทุกปี เพราะภายใต้ $q$ ราคาเฉลี่ยโตปีละ $qu+(1-q)d=1.1$ พอดีกับดอกเบี้ย ส่วนต้นทุน $G\,C=2{,}000{,}000$ ที่จ่ายไกลออกไปถูกคิดลดมากขึ้น ผลรวมตัวคูณคิดลดสิบปีคือ $6.1446$ จึงได้ 12,289,134

ชั้นแรก $V^{\text{up}}$ คือมูลค่าเหมืองถ้ามีเครื่องใหม่อยู่แล้วที่ node นั้น คิดด้วยสมการเหมืองเดิม แค่เปลี่ยนตัวเลข ชั้นที่สอง $A$ คือขุดด้วยเครื่องเก่าปีนี้แล้วถือสิทธิ์ไว้ต่อ ลูกของมันจึงเป็น $U$ ไม่ใช่ $V$ เพราะปีหน้ายังอัปเกรดได้ ชั้นที่สาม $U$ คือกฎเกมลูกเต๋าอีกครั้ง: เทียบใช้สิทธิ์เดี๋ยวนี้ (ได้เหมืองที่อัปเกรดแล้ว หักค่าเครื่อง) กับค่าของการรอ

โจทย์ให้อะไรมาบ้าง: ตาราง $V^{\text{up}}$ และ $A$ จากการเดินถอยหลังของสมการสามชั้น ส่วนต่าง $\Delta V=V^{\text{up}}-4{,}000{,}000-A$ บอกว่า node นั้นควรอัปเกรดทันที (บวก) หรือรอ (ไม่บวก)

คำตอบ: วันนี้ไม่อัปเกรด การอัปเกรดทันทีทำลาย \$1.61 ล้านเมื่อเทียบกับการถือสิทธิ์ไว้ มูลค่าเหมืองรวมสิทธิ์คือ \$24,633,143 สิทธิ์อัปเกรดเองมีค่า \$558,595 node ที่ควรอัปเกรดทันทีมีสิบ node: ปี 3 ที่ \$691.20 ปี 4 ที่ \$829.44 และสอง node บนสุดของปี 5, 6, 7, 8 (เช่นปี 8 ที่ \$1,719.93 ได้ $\Delta V\approx$ \$2.08 ล้าน) ปีที่ 9 ไม่มีเลย

ตรวจเองใน 10 วินาที: ปีที่ 9 เหลือขุดปีเดียว เครื่องใหม่ให้เงินเพิ่ม $\big(12{,}500(s-240)-10{,}000(s-200)\big)/1.1=(2{,}500s-1{,}000{,}000)/1.1$ ต้องเกิน 4,000,000 จึงต้องได้ $s\gt2{,}160$ แต่ราคาสูงสุดที่เป็นไปได้ในปีนั้นคือ 2,063.91

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ใช้โอกาสจริงแทน q: ถ้าถ่วงเหมืองด้วยโอกาสจริง 0.75 กับ 0.25 แล้วหารด้วย 1.1 สัญญาเช่าจะมีค่า \$28,028,124 แพงเกิน 16% เพราะภายใต้โอกาสจริงราคาทองเฉลี่ยโตปีละ $0.75(1.2)+0.25(0.9)=1.125$ เร็วกว่าดอกเบี้ย แต่ส่วนเกินนั้นคือค่าตอบแทนความเสี่ยงที่ราคา 400 วันนี้คิดไว้แล้ว ตรวจทุกครั้งว่าน้ำหนักตั้งราคาของอ้างอิงได้ถูก: $(0.75(480)+0.25(360))/1.1=409.09$ ไม่ใช่ 400

นับเงินสดผิดเวลา: ถ้าถือว่าทองขายตอนต้นปีโดยไม่หาร 1.1 ทุก node ใหญ่ขึ้น 1.1 เท่า ได้ \$26,482,002 แทน \$24,074,547 แพงเกินไป 10% พอดี เวลารับเงินต้องตรงกับตัวหาร

เชื่อว่าความผันผวนเพิ่มค่าเสมอ: ใบอนุญาตโรงไฟฟ้ามีค่าคงที่ 1.8367 ไม่ว่าจะผันผวนแค่ไหน ตราบที่ไม่มีกิ่งที่ขาดทุน และสิทธิ์หยุดขุดของเหมืองมีค่าแค่ \$45 เพราะราคาแทบไม่ต่ำกว่าต้นทุน ถ้าการหยุดโครงการมีค่าใช้จ่าย ก้อนประกันจะเล็กลงอีก

ใช้ V แทน U ในสิทธิ์อัปเกรด: ถ้าลูกของ $A$ ใช้มูลค่าเหมืองแบบไม่มีสิทธิ์ ($V$) จะลืมไปว่าปีหน้ายังอัปเกรดได้ ค่าของการรอจึงต่ำเกินไปและจะอัปเกรดเร็วเกินจริง

บวกค่าสิทธิ์หลายตัวโดยไม่ดูว่าชนกันไหม: สิทธิ์ทิ้งกับสิทธิ์ขยายบวกกันได้ในตัวอย่างนี้เพราะใช้คนละกิ่ง ถ้ากิ่งเดียวกันอยากใช้ทั้งคู่ ทิ้งแล้วก็ขยายไม่ได้ ต้องคิดทั้งสองในต้นไม้เดียวกัน

ใช้ทำอะไรบนโต๊ะจริง

ทีมจัดสรรเงินทุนใช้กรอบนี้ถามคำถามที่ NPV ไม่ถาม: โครงการนี้เลื่อนได้ไหม แบ่งเป็นเฟสแล้วหยุดกลางทางได้ไหม ขยายทีหลังได้ไหม ตัวอย่างที่ใช้กันจริงคือสัญญาเช่าเหมือง สิทธิ์อัปเกรดเครื่องจักร การพัฒนายาที่หยุดได้ทุกเฟส โรงงานที่มีกำลังผลิตเหลือแล้วรับจ้างผลิตให้คนอื่นได้ แหล่งน้ำมันที่เลือกเจาะเมื่อราคาคุ้ม (สัญญาสัมปทานที่หมดอายุคือ option จำนวนจำกัด) และสัญญาเช่าโรงไฟฟ้ากับคลังก๊าซ ซึ่งเป็นเรื่องของก๊าซและไฟฟ้า

ข้อควรระวังมีสองข้อ ข้อแรก เหมือง Simplico เป็นตัวอย่างที่สะอาด เพราะความไม่แน่นอนทั้งหมดมาจากราคาทอง ซึ่งซื้อขายได้ $q$ จึงเป็นราคาที่ตลาดบังคับ โครงการจริงมักมีความไม่แน่นอนที่ไม่มีตลาดรองรับด้วย เช่นปริมาณทองที่ขุดได้จริง หรือต้นทุนขุดที่ผันผวน ส่วนนั้นตัวเลขเป็นแค่กรอบคิด ข้อสอง ตัวอย่างโรงไฟฟ้าสมมติว่ารอได้ฟรี ของจริงคู่แข่งอาจลงมือก่อน และโรงไฟฟ้าที่สร้างแล้วทำเงินทุกปี คนที่รอจะไม่ได้เงินก้อนนั้น เหมือน call บนหุ้นที่จ่ายปันผล ซึ่งอาจควรใช้สิทธิ์ก่อนกำหนด เหมืองที่อัปเกรดที่ราคาสูงแสดงเรื่องนี้ให้เห็น

โจทย์ตรวจความเข้าใจ

1. โรงไฟฟ้าเดิม แต่ค่าก่อสร้างเป็น \$12 ล้าน NPV วันนี้เป็นเท่าไร และใบอนุญาตสองปีมีค่าเท่าไร?

เฉลย

NPV วันนี้ $10-12=-2$ ปีที่ 2 มีแค่กิ่ง 19.6 ที่คุ้ม ได้ 7.6 กิ่งบนปีที่ 1: สร้างทันทีได้ 2.0 รอได้ $\tfrac{5}{12}(7.6)/1.05=3.0159$ จึงรอ กิ่งล่างได้ 0 วันนี้ $V_0=\tfrac{5}{12}(3.0159)/1.05=1.1968$ ตรวจ $(5/12)^2(7.6)/1.05^2=1.1968$ โครงการที่ NPV ติดลบ \$2 ล้าน ยังมีใบอนุญาตที่มีค่า \$1.1968 ล้าน

2. เกมลูกเต๋าเดิม ถ้าทอยได้ไม่เกินสี่ครั้ง ค่าของเกมเป็นเท่าไร และครั้งแรกควรเก็บแต้มอะไร?

เฉลย

สามครั้งหลังคือเกมเดิม มีค่า 4.6667 ครั้งแรกจึงเก็บเฉพาะ 5 และ 6 ค่าของเกม $\tfrac{5+6}{6}+\tfrac46(4.6667)=1.8333+3.1111=4.9444$ หรือ 89/18 ครั้งที่เพิ่มมาให้ค่าเพิ่มแค่ 0.28 เพราะเกณฑ์เข้าใกล้ 6 แล้ว

3. ถ้าค่าอัปเกรดเหมืองลดจาก \$4 ล้าน เป็น \$3 ล้าน ปีที่ 9 มี node ที่ควรอัปเกรดไหม?

เฉลย

เงื่อนไขปีที่ 9 กลายเป็น $(2{,}500s-1{,}000{,}000)/1.1\gt3{,}000{,}000$ คือ $s\gt1{,}720$ node บนสุด 2,063.91 ผ่าน ได้เพิ่ม $(5{,}159{,}780-1{,}000{,}000)/1.1-3{,}000{,}000\approx781{,}619$ node ถัดลงมา $400(1.2)^8(0.9)=1{,}547.93$ ไม่ผ่าน ปีที่ 9 จึงมีหนึ่ง node

function positive(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x) || x <= 0) throw new RangeError(name + ' must be a positive finite number');
  return x;
}
function steps(T) {
  if (!Number.isInteger(T) || T < 1 || T > 500) throw new RangeError('T must be an integer from 1 to 500');
  return T;
}
function pricingWeight(u, d, R) {
  positive('u', u); positive('d', d); positive('R', R);
  if (!(d < R && R < u)) throw new RangeError('Need d < R < u, otherwise the tree gives free money');
  return (R - d) / (u - d);
}

// Dice: stop and take the face, or throw again; n throws at most.
function dice(n) {
  steps(n);
  const values = [3.5];
  for (let k = 1; k < n; k++) {
    let sum = 0;
    for (let face = 1; face <= 6; face++) sum += Math.max(face, values[k - 1]);
    values.push(sum / 6);
  }
  return values.reverse();                     // values[0] = value before the first throw
}

// Right to invest I in a project worth X0, decided once a year for T years (American call on a tree).
function investOption({X0, I, u, d, R, T}) {
  positive('X0', X0); positive('I', I); steps(T);
  const q = pricingWeight(u, d, R);
  let V = [];
  for (let k = 0; k <= T; k++) V.push(Math.max(X0 * u ** k * d ** (T - k) - I, 0));
  const waitNodes = [];
  for (let t = T - 1; t >= 0; t--) {
    const next = [];
    for (let k = 0; k <= t; k++) {
      const X = X0 * u ** k * d ** (t - k);
      const now = Math.max(X - I, 0);
      const wait = (q * V[k + 1] + (1 - q) * V[k]) / R;
      if (wait >= now) waitNodes.push([t, k]);
      next.push(Math.max(now, wait));
    }
    V = next;
  }
  return {q, value: V[0], npvNow: X0 - I, waitNodes};
}

// One-step options on a built project: abandon for salvage L (put), expand by share e for cost K (call).
function abandonExpand({X0, u, d, R, L, e, K}) {
  const q = pricingWeight(u, d, R);
  const abandon = (q * Math.max(L - u * X0, 0) + (1 - q) * Math.max(L - d * X0, 0)) / R;
  const expand = (q * Math.max(e * u * X0 - K, 0) + (1 - q) * Math.max(e * d * X0 - K, 0)) / R;
  return {abandon, expand};
}

// Mine lease: each year mine G oz at cost C if the price s beats C; cash arrives at year end.
function leaseTable({S0, u, d, r, C, G, T}) {
  positive('S0', S0); positive('C', C); positive('G', G); steps(T);
  const q = pricingWeight(u, d, 1 + r);
  const V = Array.from({length: T + 1}, (_, t) => new Array(t + 1).fill(0));
  for (let t = T - 1; t >= 0; t--) {
    for (let k = 0; k <= t; k++) {
      const s = S0 * u ** k * d ** (t - k);
      V[t][k] = (G * Math.max(s - C, 0) + q * V[t + 1][k + 1] + (1 - q) * V[t + 1][k]) / (1 + r);
    }
  }
  return V;
}

// Same lease if forced to mine every year: revenue PV is G*S0/(1+r) each year, cost is discounted.
function forcedLease({S0, r, C, G, T}) {
  let v = 0;
  for (let t = 0; t < T; t++) v += G * S0 / (1 + r) - G * C / (1 + r) ** (t + 1);
  return v;
}

// Option to upgrade once (pay cost, switch to the "up" lease) at any node before the lease ends.
function upgradeOption(base, up, cost) {
  positive('cost', cost);
  const T = base.T, q = pricingWeight(base.u, base.d, 1 + base.r);
  const Vup = leaseTable(up), plain = leaseTable(base);
  let U = new Array(T + 1).fill(0);
  const exercise = [];
  let dV0 = null;
  for (let t = T - 1; t >= 0; t--) {
    const next = [];
    for (let k = 0; k <= t; k++) {
      const s = base.S0 * base.u ** k * base.d ** (t - k);
      const A = (base.G * Math.max(s - base.C, 0) + q * U[k + 1] + (1 - q) * U[k]) / (1 + base.r);
      const E = Vup[t][k] - cost;
      if (E > A) exercise.push([t, Math.round(s * 100) / 100]);
      if (t === 0) dV0 = E - A;
      next.push(Math.max(E, A));
    }
    U = next;
  }
  return {lease: plain[0][0], leaseUp: Vup[0][0], withOption: U[0], option: U[0] - plain[0][0], dV0, exercise};
}

  • NPV บวกบอกว่าโครงการดี แต่ไม่ได้บอกว่าวันนี้ควรลงทุน ใบอนุญาตโรงไฟฟ้ามีค่า \$2.6392 ล้าน เทียบกับ NPV \$1 ล้าน
