17.1 Value at Risk and Expected Shortfall

VaR คือขาดทุนที่ขีดเส้นแบ่งวันร้ายออกจากวันปกติ ส่วน Expected Shortfall คือขาดทุนเฉลี่ยของวันร้ายที่อยู่เลยเส้นนั้นไป

พอร์ต \$500 ล้านมีความผันผวนรายวัน 1.2% สมมติค่าเฉลี่ยเป็นศูนย์ ฝ่ายความเสี่ยงรายงาน VaR 99% หนึ่งวัน \$13.96 ล้าน เทรดเดอร์อ่านว่า “พรุ่งนี้เสียได้มากสุด \$13.96 ล้าน” อ่านถูกไหม และถ้าวันที่แย่ที่สุด 1% มาถึงจริง จะเสียเฉลี่ยเท่าไร ลองตอบทั้งกรณีที่ผลตอบแทนเป็น Normal และกรณีที่หางหนาแบบ Student-t โดยความผันผวนเท่าเดิม

ลองตอบก่อนเปิดเฉลย

อ่านผิด \$13.96 ล้านคือจุดที่หาง 1% เริ่ม ไม่ใช่เพดาน ทุกวันที่อยู่ในหางเสียมากกว่านี้ ถ้าเป็น Normal ค่าเฉลี่ยของวันในหาง (ES 99%) คือ \$15.99 ล้าน ถ้าเป็น Student-t 4 degrees of freedom ที่ปรับให้ความผันผวนเป็น 1.2% เท่าเดิม จุดตัดขยับเป็น \$15.90 ล้าน แต่ค่าเฉลี่ยในหางกระโดดเป็น \$22.15 ล้าน

ความผันผวนเท่ากันทุกกรณี จุดตัดเปลี่ยน 13.9% แต่ค่าเฉลี่ยในหางเปลี่ยน 38.5% ตัวเลขที่ไวต่อรูปทรงของหางคือ ES ไม่ใช่ VaR

ภาพรวมก่อนลงสูตร

variance วัดความเสี่ยงได้ดีเมื่อผลตอบแทนเป็นรูประฆัง แต่มีจุดอ่อนสองข้อ มันลงโทษวันกำไรมากเท่ากับวันขาดทุนมาก และมันมองไม่เห็นว่าหางยาวแค่ไหน คนคุมความเสี่ยงสนใจฝั่งเดียวคือฝั่งขาดทุน และสนใจเฉพาะปลายสุดของฝั่งนั้น จึงต้องมีตัววัดที่มองที่หาง

VaR ที่ระดับ $c$ เช่น 99% คือขาดทุนที่วันจำนวน $c$ ส่วนของทั้งหมดเสียไม่เกิน มันคือเส้นตัดหาง Expected Shortfall (ES) คือค่าเฉลี่ยของขาดทุนในหางที่เหลือ $1-c$ ES จึงไม่ต่ำกว่า VaR เสมอ ถ้าตัดพื้นที่หางในรูปข้างล่างเป็นแผ่นแล้ววางบนปลายนิ้ว จุดที่แผ่นสมดุลคือ ES

หน้านี้นับขาดทุน 100 วันด้วยมือก่อน แล้วเขียนนิยามที่ใช้ได้ทั้งกับข้อมูลและกับสูตร คิดสูตรปิดของ Normal ยืดเป็น 10 วัน นับจากข้อมูลจริง 60 เดือน แล้วดูสองเหตุที่ทำให้ ES ชนะ คือหางหนาที่ VaR แทบมองไม่เห็น และตัวอย่างที่ VaR ลงโทษการกระจายความเสี่ยง

ศัพท์ที่ใช้ในหัวข้อนี้
Value at Risk (VaR)
ขาดทุนที่เป็นเส้นแบ่ง ในสัดส่วน $c$ ของวัน ขาดทุนไม่เกินเส้นนี้ ใช้ตั้งเพดานความเสี่ยงของแต่ละ desk เพราะเป็นตัวเลขเดียวหน่วยเงินที่เทียบข้ามสินทรัพย์ได้
Expected Shortfall (ES)
ค่าเฉลี่ยของขาดทุนในส่วน $1-c$ ที่แย่ที่สุด ตอบคำถามที่ VaR ไม่ตอบว่าเมื่อวันร้ายมาถึงจะเสียเท่าไร มีชื่ออื่นว่า CVaR (Conditional VaR) และ tail conditional expectation
Quantile
จุดตัดที่มีสัดส่วนที่กำหนดของข้อมูลหรือของโอกาสอยู่ต่ำกว่าหรือเท่า เช่น quantile 0.99 ของขาดทุน ใช้หาขอบของหาง
Historical simulation
การเอาผลตอบแทนที่เกิดจริงในอดีตมาเรียงแล้วนับ แทนการสมมติรูปทรง ตรวจง่าย แต่หางมีข้อมูลแค่ไม่กี่ตัว
Student-t distribution
รูปทรงคล้ายระฆังแต่หางหนากว่า ยิ่ง degrees of freedom น้อยหางยิ่งหนา ใช้แทนตลาดที่วันร้ายมาบ่อยกว่าที่ Normal ทำนาย
Subadditivity
กติกาว่าความเสี่ยงของสองสถานะรวมกันต้องไม่เกินผลบวกของความเสี่ยงแยกกัน ตัววัดที่ไม่ผ่านกติกานี้จะลงโทษการกระจายความเสี่ยง ES ผ่าน VaR ไม่ผ่าน

ขั้นที่ 1 — ลองด้วยมือ: ขาดทุน 100 วัน เรียงแล้วนับ

ก่อนมีสูตร ลองกับข้อมูลที่นับได้ desk หนึ่งมีขาดทุน 100 วัน (ตัวเลขสมมติ หน่วยพันดอลลาร์) หกวันที่แย่ที่สุดคือ 620, 540, 410, 380, 350 และ 330 อีก 94 วันเสียน้อยกว่า 330 หรือได้กำไร คำถามมีสองข้อ วันร้ายเริ่มที่ไหน และข้างในเฉลี่ยลึกเท่าไร

\[ \begin{aligned} \mathrm{VaR}_{0.99}&=540,\\ \mathrm{ES}_{0.99}&=620,\\ \mathrm{VaR}_{0.95}&=330,\\ \mathrm{ES}_{0.95}&=\frac{620+540+410+380+350}{5}\\ &=\frac{2{,}300}{5}=460. \end{aligned} \]

ระดับ 99% ถามหาขาดทุนที่ 99 วันจาก 100 ไม่แย่กว่า วันที่แย่ที่สุด 620 มีวันเดียว ส่วนวันที่สอง 540 มี 99 วันที่เสียไม่เกินมัน 540 จึงเป็น VaR แล้ว ES ถามต่อว่าหนึ่งวันที่เลยเส้นไปเสียเฉลี่ยเท่าไร คำตอบคือ 620

ระดับ 95% หางคือห้าวัน VaR จึงเป็นวันที่หก 330 และ ES เฉลี่ยห้าวันแย่สุดได้ 460 แต่ในห้าวันนั้นยังมีวันที่เสีย 620 ES จึงไม่ใช่ขาดทุนสูงสุดเหมือนกัน มันเป็นค่าเฉลี่ย

ขั้นที่ 2 — นิยามที่ใช้ได้ทั้งกับข้อมูลและกับสูตร

การนับร้อยวันง่ายเพราะ 100 แบ่งหาง 1% และ 5% ได้ลงตัว ถ้ามี 250 วัน หาง 1% คือ 2.5 วัน จะหยิบวันไหน ต้องมีนิยามที่ไม่ขึ้นกับการหารลงตัว ให้ $Q_L(u)$ คือขาดทุนที่มีสัดส่วน $u$ ของวันอยู่ต่ำกว่าหรือเท่า สองบรรทัดแรกเป็นนิยาม ที่เหลือคือการใช้กับข้อมูล $N$ วัน

\[ \begin{aligned} \mathrm{VaR}_c&=Q_L(c),\\ \mathrm{ES}_c&=\frac{1}{1-c}\int_c^1 Q_L(u)\,du,\\ Q_L(u)&=L_{(k)},\quad \frac{k-1}{N}\lt u\le\frac{k}{N},\\ \mathrm{VaR}_c&=L_{(K)},\quad K=\lceil cN\rceil,\\ \mathrm{ES}_{0.95}&=\frac{0.01(350+380+410+540+620)}{0.05}\\ &=\frac{23}{0.05}=460. \end{aligned} \]

VaR คือขาดทุนที่เล็กที่สุดที่ทำให้ $P(L\le\ell)\ge c$ ส่วน ES เฉลี่ยจุดตัดทุกจุดที่ลึกกว่า $c$ ตัวหาร $1-c$ คือความยาวของช่วงที่เฉลี่ย ES จึงเฉลี่ยหางกว้าง $1-c$ พอดีเสมอ ไม่มากไม่น้อย

กับข้อมูล $N$ วัน แต่ละวันมีน้ำหนัก $1/N$ ฟังก์ชัน $Q_L$ จึงเป็นขั้นบันได บันไดขั้นที่ $k$ กว้าง $1/N$ และสูงเท่าขาดทุนอันดับ $k$ VaR คือความสูงของบันไดขั้นที่ $K=\lceil cN\rceil$ (ปัดขึ้น) ที่ $c=0.95,\ N=100$ ได้ $K=95$ คือวันที่หกจากบน 330 และช่วง 0.95 ถึง 1 มีห้าขั้นกว้างขั้นละ 0.01 พื้นที่ใต้ขั้นบันไดหารด้วย 0.05 ได้ 460 ตรงกับการนับ

ทำไมไม่นิยาม ES ว่า “ค่าเฉลี่ยของวันที่เสียตั้งแต่ VaR ขึ้นไป” ให้ง่าย เพราะวันที่เท่ากับ VaR พอดีถูกนับเข้ามาด้วย ที่ 99% จะได้ $(620+540)/2=580$ ซึ่งเฉลี่ย 2% ของวัน ไม่ใช่ 1% นิยามแบบ integral ไม่มีปัญหานี้ ถ้าหางมีเศษ เช่น 2.5 วัน วันขอบก็นับแค่ครึ่งเดียว (โจทย์ข้อ 2) และกับ distribution แบบต่อเนื่อง สองแบบให้ค่าเท่ากัน คือ $\mathbb E[L\mid L\ge \mathrm{VaR}_c]$

ขั้นที่ 3 — จากผลตอบแทนเป็นขาดทุน: VaR ของพอร์ต \$500 ล้าน

ตอนนี้แทนการนับด้วยแบบจำลอง สมมติผลตอบแทนหนึ่งวัน $R$ เป็น Normal ค่าเฉลี่ย $\mu$ ความผันผวน $\sigma$ ขาดทุนเป็นบวกเมื่อเสีย จึงกลับเครื่องหมายแล้วคูณมูลค่าพอร์ต จุดที่ต้องระวังมีจุดเดียว คือการกลับเครื่องหมายพลิกอสมการ

\[ \begin{aligned} L&=-VR,\\ P(L\le\ell)&=P\Big(R\ge-\frac{\ell}{V}\Big)=c,\\ P(R\ge\mu-\sigma z_c)&=\Phi(z_c)=c,\\ -\frac{\ell}{V}&=\mu-\sigma z_c,\\ \mathrm{VaR}_c&=V(\sigma z_c-\mu),\\ \sigma V&=0.012(500{,}000{,}000)\\ &=6{,}000{,}000,\\ \mathrm{VaR}_{0.99}&=2.3263479(6{,}000{,}000)\\ &=13{,}958{,}087,\\ \mathrm{VaR}_{0.95}&=1.6448536(6{,}000{,}000)\\ &=9{,}869{,}122. \end{aligned} \]

ขาดทุนไม่เกิน $\ell$ แปลว่าผลตอบแทนไม่ต่ำกว่า $-\ell/V$ บรรทัดที่สามใช้ความสมมาตรของระฆัง โอกาสที่ $R$ อยู่เหนือจุดซึ่งต่ำกว่าค่าเฉลี่ย $z_c$ เท่าของ $\sigma$ เท่ากับ $\Phi(z_c)$ เทียบสองบรรทัดแล้วย้ายข้าง ได้ VaR เป็นความผันผวนคูณระยะมาตรฐาน หักด้วยกำไรที่คาดไว้ ตัวคูณ $z_c$ หาจากการเปิดตาราง Normal distribution ย้อนกลับ $\Phi(z)=c$

ตัวอย่างนี้ตั้งค่าเฉลี่ยรายวันเป็นศูนย์ ถ้าคาดว่าโตปีละ 10% ค่าเฉลี่ยรายวันคือราว $0.10/252\approx0.04\%$ (252 คือจำนวนวันทำการของตลาดหุ้นสหรัฐในหนึ่งปี) เล็กกว่า $\sigma$ ราว 30 เท่า จึงตัดทิ้งได้สำหรับหนึ่งวัน แต่ไม่ใช่ทุกช่วงเวลา เพราะค่าเฉลี่ยโตตามจำนวนวันเร็วกว่าความผันผวน

VaR 99% คือ 2.79% ของพอร์ต และเป็นเส้นตรงตาม $V$ และ $\sigma$ ลดพอร์ตครึ่งหนึ่ง VaR ลดครึ่งหนึ่งพอดี คุณสมบัตินี้ทำให้ตั้งเพดานของแต่ละ desk ได้ง่าย และทำให้คิดได้ทันทีว่าต้องลดพอร์ตเท่าไรเมื่อ GARCH พยากรณ์ว่าความผันผวนพรุ่งนี้สูงขึ้น

ขั้นที่ 4 — ES ของ Normal: เฉลี่ย quantile ทุกตัวในหาง

นิยามบอกว่า ES คือค่าเฉลี่ยของ $Q_L(u)$ ตั้งแต่ $u=c$ ถึง 1 สำหรับ Normal ทุก quantile คือ $V(\sigma\Phi^{-1}(u)-\mu)$ จึงต้องหา integral ของ $\Phi^{-1}$ ปกติการอินทิเกรตหางของระฆังทำด้วยมือไม่ได้ แต่ integral ตัวนี้ทำได้ เพราะ derivative ของ $\varphi$ มีรูปพิเศษ

\[ \begin{aligned} Q_L(u)&=V\big(\sigma\,\Phi^{-1}(u)-\mu\big),\\ u&=\Phi(z),\quad du=\varphi(z)\,dz,\\ \int_c^1\Phi^{-1}(u)\,du&=\int_{z_c}^{\infty}z\,\varphi(z)\,dz,\\ \varphi'(z)&=-z\,\varphi(z),\\ \int_{z_c}^{\infty}z\,\varphi(z)\,dz&=\Big[-\varphi(z)\Big]_{z_c}^{\infty}\\ &=\varphi(z_c),\\ \mathrm{ES}_c&=V\Big(\frac{\sigma\,\varphi(z_c)}{1-c}-\mu\Big),\\ \varphi(2.3263479)&=0.3989423\,e^{-2.7059472}\\ &=0.026652142,\\ \mathrm{ES}_{0.99}&=2.6652142(6{,}000{,}000)\\ &=15{,}991{,}285,\\ \mathrm{ES}_{0.95}&=2.0627128(6{,}000{,}000)\\ &=12{,}376{,}277. \end{aligned} \]

บรรทัดที่สองเปลี่ยนตัวแปรจากระดับ $u$ เป็นจุดบนระฆัง $z$ ช่วง $u$ จาก $c$ ถึง 1 กลายเป็น $z$ จาก $z_c$ ถึงอนันต์ จังหวะที่ทำให้ทุกอย่างง่ายคือบรรทัดที่สี่ $z\varphi(z)$ เป็นค่าลบของ derivative ของ $\varphi$ integral ของหางจึงแค่ย้อน derivative ปลายอนันต์เป็นศูนย์เพราะระฆังลงถึงศูนย์ เหลือแค่ความสูงของระฆังที่จุดตัด หารด้วยความกว้างของหาง $1-c$ ก็เป็นค่าเฉลี่ย

ที่ 99% ระฆังสูงเหลือ 6.68% ของยอด ($e^{-2.7059}=0.0668$) ES 99% คือ \$15.99 ล้าน มากกว่า VaR \$2.03 ล้าน อัตราส่วน $2.6652/2.3263=1.146$ ที่ 95% ใช้ $\varphi(1.6448536)=0.10313564$ หารด้วย 0.05 ได้ \$12.38 ล้าน อัตราส่วน 1.254

ยิ่งลึกในหาง อัตราส่วน ES ต่อ VaR ยิ่งเข้าใกล้ 1 เพราะระฆังลดลงเร็วมากจนมวลในหางกองอยู่ชิดขอบ นี่คือลายเซ็นของหางบาง ตลาดที่หางหนาไม่เป็นแบบนี้ ดังที่จะเห็นตอนเปลี่ยนเป็น Student-t ข้างล่าง สังเกตด้วยว่าใต้ Normal ทั้ง VaR และ ES ถูกกำหนดโดย $\mu$ กับ $\sigma$ ล้วน ๆ จึงไม่ได้บอกอะไรเพิ่มจาก variance เลย ตัววัดหางมีประโยชน์จริงเมื่อหางไม่ใช่ระฆัง

ขั้นที่ 5 — จาก 1 วันเป็น 10 วัน

กฎ Basel ปี 1996 ถามความเสี่ยงสิบวันทำการ เพราะการปิดสถานะก้อนใหญ่ใช้เวลา ถ้าผลตอบแทนรายวันอิสระกันและความผันผวนคงที่ variance ของผลรวมสิบวันคือผลบวกของ variance เพราะ covariance ข้ามวันเป็นศูนย์ (หลักเดียวกับ ความเสี่ยงของพอร์ตจาก covariance matrix)

\[ \begin{aligned} \operatorname{Var}(R_1+\dots+R_{10})&=10\,\sigma^2,\\ \sigma_{10}&=\sqrt{10}\,\sigma\\ &=3.1622777(0.012)\\ &=0.037947,\\ \mathrm{VaR}_{0.99,10}&=13.958087\sqrt{10}\\ &=44.139,\\ \mathrm{ES}_{0.99,10}&=15.991285\sqrt{10}\\ &=50.569,\\ \mathrm{VaR}_{c,h}&=V\big(\sigma\sqrt h\,z_c-h\mu\big). \end{aligned} \]

สองบรรทัดกลางเป็นล้านดอลลาร์ สิบวัน VaR 99% คือ \$44.14 ล้าน และ ES \$50.57 ล้าน การคูณ $\sqrt{10}$ ทั้งก้อนใช้ได้เพราะค่าเฉลี่ยเป็นศูนย์ ถ้าไม่เป็นศูนย์ ค่าเฉลี่ยบวกกันเป็นเส้นตรง คูณ $h$ แต่ความผันผวนโตแบบราก คูณ $\sqrt h$ ตามบรรทัดสุดท้าย

กฎรากนี้อาศัยสามข้อพร้อมกัน วันอิสระกัน ความผันผวนเท่ากันทุกวัน และขาดทุนรวมยังเป็น Normal ถ้าพอร์ตมี option ซึ่งขาดทุนไม่เป็นเส้นตรงตามราคา ต้องตีราคาสัญญาใหม่ในแต่ละสถานการณ์แทน และหลังช็อกใหญ่ ความผันผวนที่พยากรณ์ของแต่ละวันไม่เท่ากัน ต้องรวม variance ที่พยากรณ์ไว้ทีละวัน

ขั้นที่ 6 — นับจากข้อมูลจริง: 60 เดือนของพอร์ตสามสินทรัพย์

ชุดข้อมูลหนึ่งมีผลตอบแทนรายเดือน 60 เดือน (ห้าปี) ของสินทรัพย์สามตัว ถือเท่ากันตัวละหนึ่งในสาม แล้วถาม VaR และ ES 95% แบบ historical simulation คือใช้นิยามขั้นบันไดตรง ๆ โดยไม่สมมติรูปทรงเลย

\[ \begin{aligned} L_t&=-\tfrac13\big(R_{1,t}+R_{2,t}+R_{3,t}\big),\\ L_1&=-\tfrac13(3.3504)=-1.1168\%,\\ L_3&=-\tfrac13(-4.1261)=1.3754\%,\\ K&=\lceil0.95(60)\rceil=57,\\ \widehat{\mathrm{VaR}}_{0.95}&=L_{(57)}=1.9191\%,\\ \widehat{\mathrm{ES}}_{0.95}&=\frac{1.9877+2.1450+2.3707}{3}\\ &=2.1678\%,\\ \mathrm{VaR}_{\mathcal N}&=-0.096905\\ &\quad+1.6448536(1.147563)\\ &=1.7907\%,\\ \mathrm{ES}_{\mathcal N}&=-0.096905\\ &\quad+2.0627128(1.147563)\\ &=2.2702\%. \end{aligned} \]

เดือนแรกสามตัวให้ 2.1675, −1.8883 และ 3.0712% รวม 3.3504 พอร์ตได้กำไร ขาดทุนจึงติดลบ เดือนที่สามคือ −2.5194, 1.5773 และ −3.1840% พอร์ตเสีย 1.3754% คิดครบ 60 เดือนแล้ว ห้าเดือนที่เสียมากที่สุดคือ 2.3707, 2.1450, 1.9877, 1.9191 และ 1.8807%

$0.95\times60=57$ พอดี VaR คือตัวที่ 57 เมื่อเรียงจากน้อยไปมาก คือขาดทุนใหญ่อันดับสี่ 1.9191% หาง 5% คือ 3 เดือนเต็ม ES จึงเป็นค่าเฉลี่ยของสามเดือนที่แย่กว่านั้น 2.1678% ทั้งหางมีข้อมูลแค่สามตัว เปลี่ยนเดือนเดียวตัวเลขก็ขยับมาก

สองบรรทัดล่างสมมติ Normal แทน ใช้ค่าเฉลี่ยของขาดทุน $-5.8143/60=-0.096905\%$ และความผันผวน 1.147563% (หารด้วย $N-1=59$ แบบ sample variance เพื่อไม่ให้ ตัวประมาณเอนเอียง) ได้ VaR ต่ำกว่าการนับ (1.7907 เทียบ 1.9191) แต่ ES สูงกว่า (2.2702 เทียบ 2.1678) ตัวเลข 2.0627128 คือ $\varphi(z_{0.95})/0.05$ จากสูตร ES ของ Normal

ขั้นที่ 7 — หางหนา: Student-t ที่ความผันผวนเท่าเดิม

ผลตอบแทนรายวันจริงมีวันร้ายบ่อยกว่าที่ระฆังทำนาย (ดู ทำไมใช้ GBM กับราคาหุ้น และ สวนสัตว์ของ distribution) กลับไปที่พอร์ต \$500 ล้าน แล้วเปลี่ยนรูปทรงเป็น Student-t 4 degrees of freedom ปรับขนาดให้ความผันผวนเป็น 1.2% เท่าเดิม คำถามคือ VaR กับ ES ขยับเท่ากันไหม

\[ \begin{aligned} f(t)&=\tfrac38\Big(1+\frac{t^2}{4}\Big)^{-5/2},\\ \operatorname{Var}(T)&=\frac{4}{4-2}=2,\\ F(q)&=\frac12+\frac{q(q^2+6)}{2(q^2+4)^{3/2}}\\ &=0.99,\\ q&=3.7469474,\\ \mathrm{VaR}_{0.99}&=\frac{q}{\sqrt2}(6{,}000{,}000)\\ &=2.6494919(6{,}000{,}000)\\ &=15{,}896{,}951,\\ \int_q^{\infty}t f(t)\,dt&=\tfrac12\Big(1+\frac{q^2}{4}\Big)^{-3/2}\\ &=\tfrac12(4.5099037)^{-3/2}\\ &=0.05220584,\\ \mathrm{ES}_{0.99}&=\frac{0.05220584}{0.01\sqrt2}(6{,}000{,}000)\\ &=22{,}149{,}063. \end{aligned} \]

บรรทัดแรกคือ density ของ t ที่ $\nu=4$ ซึ่งมี variance $\nu/(\nu-2)=2$ หารด้วย $\sqrt2$ จึงได้ความผันผวน 1 เหมือนระฆังมาตรฐาน $F$ ของ $\nu=4$ มีสูตรปิด (ลอง differentiate จะได้ $f$ คืนมา) แต่แก้ $F(q)=0.99$ ด้วยมือไม่ได้ จึงหา $q$ ด้วย bisection แล้วตรวจโดยแทนกลับ $75.087/(2\times76.620)=0.49$ บวก 0.5 ได้ 0.99 พอดี

integral ของหางใช้ท่าเดียวกับสูตร ES ของ Normal คือหาสิ่งที่ differentiate แล้วได้ integrand ตั้ง $u=1+t^2/4$ จะได้ $du=\tfrac t2\,dt$ integrand กลายเป็น $\tfrac34u^{-5/2}\,du$ ซึ่ง integral คือ $-\tfrac12u^{-3/2}$ ที่ปลายอนันต์เป็นศูนย์ เหลือค่าที่ $q$ หารด้วย 0.01 และ $\sqrt2$ ก็เป็น ES

ความผันผวนเท่ากัน แต่ VaR เพิ่ม 13.9% และ ES เพิ่ม 38.5% อัตราส่วน ES ต่อ VaR เป็น 1.393 เทียบ 1.146 ของ Normal ส่วนต่าง \$6.16 ล้านของ ES คือสิ่งที่ Normal มองไม่เห็นทั้งที่ประมาณความผันผวนถูก ลองดูอีกมุม โอกาสที่ขาดทุนเกิน 4 เท่าของความผันผวน (\$24 ล้าน) ใต้ Normal คือ 0.0032% หรือราวหนึ่งวันใน 125 ปี ใต้ t คือ 0.24% หรือราวหนึ่งวันในทุก 1.65 ปี

เรื่องการนับอันดับ กับข้อมูล 1,000 วันที่ 99% หาง 1% คือ 10 วันเต็ม ES เฉลี่ย 10 วันแย่สุด แต่ตามนิยามขั้นบันได VaR คือตัวที่ $\lceil0.99\times1{,}000\rceil=990$ คือแย่เป็นอันดับ 11 หลาย desk หยิบอันดับ 10 แทน จึงต้องระบุเสมอว่าใช้แบบไหน

ขั้นที่ 8 — variance เกือบเท่ากัน แต่ VaR กับ ES ขยับคนละทิศ

ใช้พอร์ต \$500 ล้านเดิม แล้วสร้างตลาดที่มีสองอารมณ์ วันปกติ 75% ของเวลามีความผันผวน 0.76 เท่าของเดิม วันปั่นป่วน 25% มีความผันผวน 1.5 เท่า ทั้งสองกลุ่มค่าเฉลี่ยศูนย์ นี่คือ Normal ผสมสองกลุ่ม แบบที่ใช้จำลองตลาดซึ่งมีโอกาส 25% จะเข้าช่วงผันผวนสูง เราจะเทียบที่ระดับ 95%

\[ \begin{aligned} \operatorname{Var}&=0.75(0.76)^2+0.25(1.5)^2\\ &=0.4332+0.5625\\ &=0.9957,\\ F(x)&=0.75\,\Phi\Big(\frac{x}{0.76}\Big)\\ &\quad+0.25\,\Phi\Big(\frac{x}{1.5}\Big),\\ F(x)=0.95&:\ x=1.58761593,\\ \int_x^{\infty}\frac ys\,\varphi\Big(\frac ys\Big)dy&=s\,\varphi\Big(\frac xs\Big),\\ \mathrm{ES}&=\frac{0.0256567+0.0854448}{0.05}\\ &=2.22203006,\\ \mathrm{VaR}&=1.58761593(6{,}000{,}000)\\ &=9{,}525{,}696,\\ \mathrm{ES}&=2.22203006(6{,}000{,}000)\\ &=13{,}332{,}180. \end{aligned} \]

variance ของแบบผสมเป็น 0.9957 เท่าของ Normal ต่ำกว่าเพียง 0.43% VaR หาโดยแก้ $F(x)=0.95$ ด้วย bisection ตรวจจากค่าปัดเศษ $0.75(0.981645)+0.25(0.855066)\approx0.95$

ES ใช้ท่าเดียวกับสูตร ES ของ Normal ทีละก้อน ตั้ง $z=y/s$ แล้ว integral ของก้อนที่มีความผันผวน $s$ เท่ากับ $s\varphi(x/s)$ ถ่วงด้วยน้ำหนักของก้อน ก้อนสงบให้ $0.75(0.76)(0.0450117)=0.0256567$ ก้อนปั่นป่วนให้ $0.25(1.5)(0.2278529)=0.0854448$ ในหาง 5% นี้ 77% ของ integral มาจากก้อนปั่นป่วน แม้มันมีน้ำหนักแค่ 25%

ผลคือ VaR ของแบบผสมต่ำกว่า Normal \$343,426 (9.53 เทียบ 9.87 ล้าน) แต่ ES สูงกว่า \$955,904 (13.33 เทียบ 12.38 ล้าน) t ที่ $\nu=4$ ก็เป็นแบบเดียวกันที่ 95% แทน $q=2.1318468$ ลงในสูตรของ t ข้างบน ได้ VaR \$9.04 ล้าน ต่ำกว่า Normal แต่ ES \$13.59 ล้าน สูงกว่า หางหนาดึงมวลจากไหล่ไปไว้ที่ปลาย จุดตัดตื้นขึ้นได้ ขณะที่ค่าเฉลี่ยในหางลึกขึ้น

ขั้นที่ 9 — ตัวอย่างค้าน: กระจายเงินแล้ว VaR กลับแย่ลง

โจทย์ให้อะไรมาบ้าง: พันธบัตรสองตัว โอกาสผิดนัดตัวละ 3% อิสระกัน ผิดนัดแล้วเสียเงินต้นทั้งหมด เทียบการถือตัวเดียว \$100 ล้าน ($L_1$) กับแบ่งถือตัวละ \$50 ล้าน ($L_2$) หน่วยในสูตรเป็นล้านดอลลาร์ ใช้นิยามขั้นบันไดกับ distribution ที่มีไม่กี่ค่า

\[ \begin{aligned} P(L_1=100)&=0.03\lt0.05,\\ \mathrm{VaR}_{0.95}(L_1)&=0,\\ \mathrm{ES}_{0.95}(L_1)&=\frac{0.03(100)}{0.05}=60,\\ P(L_2=100)&=0.03^2=0.0009,\\ P(L_2=50)&=2(0.03)(0.97)\\ &=0.0582,\\ P(L_2\ge50)&=0.0591\gt0.05,\\ \mathrm{VaR}_{0.95}(L_2)&=50,\\ \mathrm{ES}_{0.95}(L_2)&=\frac{0.0009(100)+0.0491(50)}{0.05}\\ &=\frac{0.09+2.455}{0.05}\\ &=50.9,\\ \mathrm{VaR}&:\ 50\gt0+0,\\ \mathrm{ES}&:\ 50.9\le30+30. \end{aligned} \]

คำตอบ: VaR บอกว่าการแบ่งทำให้แย่ลง จาก 0 เป็น \$50 ล้าน แต่ ES บอกว่าดีขึ้น จาก \$60 ล้านเป็น \$50.9 ล้าน

ถือตัวเดียว โอกาสเสีย 3% น้อยกว่าหาง 5% จุดตัดจึงตกที่ยังไม่เสียอะไร VaR เป็นศูนย์ทั้งที่มีโอกาสเสีย \$100 ล้าน ES เห็นความเสียหายนั้น หาง 5% มีกรณีเสีย 100 อยู่ 3% และกรณีไม่เสียอีก 2% เฉลี่ยได้ 60

แบ่งถือ โอกาสที่อย่างน้อยหนึ่งตัวผิดนัดเกิน 5% จุดตัดจึงกระโดดเป็น 50 แต่ VaR ของแต่ละตัว \$50 ล้านเป็นศูนย์ทั้งคู่ (โอกาส 3%) VaR ของพอร์ตรวมจึงเกินผลบวกของส่วนย่อย ละเมิด subadditivity การกระจายถูกลงโทษ ส่วนหาง 5% ของพอร์ตแบ่งมีกรณีผิดนัดทั้งคู่ 0.09% กับกรณีตัวเดียว 4.91% ที่เหลือ เฉลี่ยได้ 50.9 ไม่เกิน 30 บวก 30 ของสองส่วนย่อย (ตัวละ $0.03\times50/0.05=30$)

ตัวอย่างนี้ยังแสดงว่าทำไมนิยามขั้นบันไดต้องตัดหางให้กว้าง 5% พอดี ถ้าเฉลี่ยทุกกรณีที่เสียตั้งแต่ VaR ขึ้นไป จะเฉลี่ยพื้นที่ 5.91% ได้ $(0.09+2.91)/0.0591=50.76$ ไม่ใช่ 50.9

ตรวจเองใน 10 วินาที: $1-0.97\times0.97=0.0591$ มากกว่า 0.05 จุดตัดจึงอยู่ที่ 50 และ $0.0009+0.0491=0.05$ คือหางที่ ES เฉลี่ยพอดี

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

อ่าน VaR เป็นขาดทุนสูงสุด และ tail stuffing: กลยุทธ์หนึ่งได้วันละ 0.1% แต่มีโอกาส 0.5% ต่อวันที่จะเสีย 20% โอกาสเสีย 0.5% น้อยกว่าหาง 1% VaR 99% จึงเป็น −0.1% คือกำไร ดูปลอดภัยสุด ๆ แต่ ES 99% คือ $(0.005\times20+0.005\times(-0.1))/0.01=9.95\%$ ต่อวัน ใครถูกวัดด้วย VaR อย่างเดียวจะถูกดึงไปหากลยุทธ์ที่ยัดความเสี่ยงไว้หลังจุดตัดแบบนี้ (เช่นขาย option ไกลเงิน)

ใช้ 1.96 กับ VaR 95%: 1.96 คือจุดตัดของช่วง 95% แบบสองด้าน ซึ่งเหลือหางข้างละ 2.5% VaR สนใจหางเดียว ใช้ 1.96 จะได้ \$11.76 ล้าน แทน \$9.87 ล้าน สูงไป 19%

บวกเกินหนึ่งตัว: สูตรลัดที่พบบ่อยคือบวกขาดทุนตั้งแต่อันดับ $K$ ถึง $N$ แล้วหารด้วย $(1-c)N$ กับ 60 เดือนที่ 95% สูตรนี้บวกอันดับ 57 ถึง 60 ซึ่งมีสี่ตัว แต่หารด้วยสาม ได้ 2.8075% แทน 2.1678% สูงไป 29.5% เมื่อข้อมูลเป็นพันตัวความต่างนี้เล็ก แต่ที่ 60 ตัวมันใหญ่กว่าความต่างระหว่างการนับกับ Normal เสียอีก

คูณ $\sqrt{10}$ ในช่วงที่ความผันผวนเกาะกลุ่ม: หลังวันร่วงแรง GARCH พยากรณ์ว่าวันถัด ๆ ไปแรงกว่าปกติแล้วค่อย ๆ ลดลง ความผันผวนสิบวันจึงไม่ใช่ $\sqrt{10}$ เท่าของค่าวันเดียว ต้องรวม variance ที่พยากรณ์ของแต่ละวัน การใช้ค่าจากช่วงสงบจะต่ำไป

เชื่อ ES จากข้อมูลน้อย: ES เป็นค่าเฉลี่ย จึงไวต่อค่าสุดโต่งไม่กี่ตัว ใน 60 เดือน ES 95% ใช้ข้อมูลสามตัว ถ้าเดือนที่แย่ที่สุด 2.3707% เปลี่ยนเป็น 5% ES กระโดดจาก 2.17% เป็น 3.04% ขณะที่ VaR (อันดับ 57) ไม่ขยับเลย

VaR เกิดที่ J.P. Morgan ต้นทศวรรษ 1990 เพื่อทำรายงานหน้าเดียวทุกวันว่าทั้งธนาคารเสี่ยงเท่าไร ข้อดีของมันคือประมาณจากข้อมูลได้นิ่ง เพราะขึ้นกับอันดับ ไม่ขึ้นกับขนาดของวันสุดโต่ง และตรวจย้อนหลังได้ง่ายแค่นับวันที่ขาดทุนเกิน VaR ข้อเสียคือมองไม่เห็นอะไรหลังจุดตัด เปิดช่องให้ tail stuffing และไม่ subadditive

ES มองเห็นทั้งหาง ผ่าน subadditivity และเมื่อมีชุดสถานการณ์จำกัดกับขาดทุนที่เป็นเส้นตรงตามน้ำหนัก การเลือกพอร์ตให้ ES ต่ำสุดเขียนเป็น linear program ได้ จึงแก้ได้เร็วมาก ข้อเสียคือเป็นค่าเฉลี่ยของข้อมูลไม่กี่ตัว จึงไวต่อค่าสุดโต่ง กรอบ FRTB ที่ประกาศปี 2016 ย้ายความเสี่ยงตลาดในวิธีแบบจำลองภายในจาก VaR 99% ไปใช้ ES 97.5% ใต้ Normal ของพอร์ตนี้ ES 97.5% คือ $\varphi(1.959964)/0.025\approx2.3378$ เท่าของ $\sigma V$ หรือ \$14.03 ล้าน ใกล้ VaR 99% \$13.96 ล้านมาก แต่ใต้ t ที่ $\nu=4$ ES 97.5% คือ \$16.94 ล้าน สูงกว่า VaR 99% ของ t เอง (\$15.90 ล้าน) ตัวเลขใหม่จึงลงโทษหางหนาโดยตรง

สำหรับพอร์ตที่มี option ใช้ Monte Carlo สร้างสถานการณ์ ตีราคาสัญญาในแต่ละสถานการณ์ แล้วใช้นิยามขั้นบันไดกับผลขาดทุนที่ได้

โจทย์ตรวจความเข้าใจ

1. พอร์ต \$80 ล้าน ความผันผวนรายวัน 2% ค่าเฉลี่ยศูนย์ ผลตอบแทนเป็น Normal หา VaR 99% และ ES 97.5% หนึ่งวัน

เฉลย

$\sigma V=0.02(80{,}000{,}000)=1{,}600{,}000$ VaR 99% คือ $2.3263479(1{,}600{,}000)=\$3{,}722{,}157$ ES 97.5% คือ $\varphi(1.959964)/0.025=0.0584451/0.025=2.3378028$ คูณ $1{,}600{,}000$ ได้ $\$3{,}740{,}484$ มากกว่ากันแค่ 0.49% อัตราส่วนนี้ไม่เปลี่ยนเมื่อขยายขนาดพอร์ต ตราบที่ค่าเฉลี่ยเป็นศูนย์

2. ข้อมูล 250 วัน ขาดทุนสี่วันที่มากที่สุดคือ 5.2, 4.1, 3.6 และ 3.0 ล้านดอลลาร์ หา VaR 99% และ ES 99% ตามนิยามขั้นบันได

เฉลย

$0.99\times250=247.5$ ปัดขึ้นเป็น $K=248$ คืออันดับสามจากบน VaR คือ \$3.6 ล้าน หาง 1% คือ 2.5 วัน สองวันแรกนับเต็ม และวันอันดับ 248 นับครึ่งเดียว ES $=(5.2+4.1+0.5\times3.6)/2.5=11.1/2.5=\$4.44$ ล้าน ถ้าเฉลี่ยสองวันจะได้ 4.65 ถ้าเฉลี่ยสามวันได้ 4.30 ทั้งคู่ไม่ใช่หาง 1%

3. พันธบัตรแบบตัวอย่างการกระจายเงินข้างบน แต่โอกาสผิดนัดตัวละ 4% หา VaR และ ES 95% ของการถือตัวเดียว \$100 ล้าน และของการแบ่งตัวละ \$50 ล้าน

เฉลย

ตัวเดียว: 4% น้อยกว่า 5% VaR คือ 0 ES คือ $0.04(100)/0.05=80$ แบ่งถือ: $1-0.96^2=7.84\%$ เกิน 5% VaR คือ 50 ES คือ $(0.0016(100)+0.0484(50))/0.05=(0.16+2.42)/0.05=51.6$ VaR แย่ลงจาก 0 เป็น 50 แต่ ES ดีขึ้นจาก 80 เป็น 51.6

// Standard Normal: erf by power series (small x) or continued fraction (large x)
function erf(x) {
  const t = Math.abs(x);
  if (t < 2.5) {
    let sum = 0, term = t;
    for (let k = 0; k < 200; k++) {
      const add = term / (2 * k + 1);
      sum += add;
      if (Math.abs(add) < 1e-17 * sum) break;
      term *= -t * t / (k + 1);
    }
    return Math.sign(x) * 2 / Math.sqrt(Math.PI) * sum;
  }
  let f = t;
  for (let k = 120; k >= 1; k--) f = t + (k / 2) / f;
  return Math.sign(x) * (1 - Math.exp(-t * t) / Math.sqrt(Math.PI) / f);
}
const Phi = z => 0.5 * (1 + erf(z / Math.SQRT2));
const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);

// Solve F(x) = p for an increasing F by bisection
function solve(F, p, lo, hi) {
  for (let i = 0; i < 200; i++) {
    const mid = (lo + hi) / 2;
    if (F(mid) < p) lo = mid; else hi = mid;
  }
  return (lo + hi) / 2;
}

// Historical: each loss weighs 1/N; ES averages exactly the worst (1 - c) share
function historical(losses, c) {
  const s = [...losses].sort((a, b) => a - b);
  const N = s.length, cN = c * N, K = Math.ceil(cN - 1e-9);
  let tail = 0;
  for (let k = 1; k <= N; k++) tail += s[k - 1] * Math.min(1, Math.max(0, k - cN));
  return {K, VaR: s[K - 1], ES: tail / (N - cN)};
}

// Discrete loss given as [loss, probability] pairs
function discreteRisk(outcomes, c) {
  const rows = [...outcomes].sort((a, b) => a[0] - b[0]);
  let cum = 0, VaR = null, tail = 0;
  for (const [x, p] of rows) {
    const before = cum;
    cum += p;
    if (VaR === null && cum >= c - 1e-12) VaR = x;
    tail += x * Math.max(0, cum - Math.max(before, c));
  }
  return {VaR, ES: tail / (1 - c)};
}

// Student-t with 4 degrees of freedom, rescaled to variance 1
const t4Cdf = t => 0.5 + t * (t * t + 6) / (2 * (t * t + 4) ** 1.5);
function t4Risk(c) {
  const q = solve(t4Cdf, c, 0, 1e4);
  const tail = 0.5 * (1 + q * q / 4) ** -1.5;
  return {VaR: q / Math.SQRT2, ES: tail / (1 - c) / Math.SQRT2};
}

// Mixture of zero-mean Normals with weights w and scales s
function mixtureRisk(w, s, c) {
  const F = x => w.reduce((a, wi, i) => a + wi * Phi(x / s[i]), 0);
  const q = solve(F, c, 0, 100);
  const ES = w.reduce((a, wi, i) => a + wi * s[i] * phi(q / s[i]), 0) / (1 - c);
  return {VaR: q, ES};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • VaR คือจุดเริ่มของหาง ES คือค่าเฉลี่ยของหางที่กว้าง $1-c$ พอดี ข้อมูล 100 วันให้ 540 กับ 620 ที่ 99% และ 330 กับ 460 ที่ 95%
  • พอร์ต \$500 ล้านที่ความผันผวน 1.2% ต่อวัน: VaR 99% \$13.96 ล้าน ES \$15.99 ล้าน สิบวัน \$44.14 และ \$50.57 ล้าน
  • ES ของ Normal ได้มาจาก $\varphi'(z)=-z\varphi(z)$ และของ t ได้มาจากการแทน $u=1+t^2/4$
  • ความผันผวนเท่ากันแต่หางหนา VaR 99% ขึ้น 13.9% แต่ ES ขึ้น 38.5% และที่ 95% หางหนาทำให้ VaR ลดลงขณะที่ ES เพิ่มขึ้น
  • VaR ลงโทษการกระจายได้ (0 เป็น 50) และถูกหลบได้ด้วย tail stuffing ES ไม่มีปัญหานี้ แต่ประมาณจากข้อมูลได้ไม่นิ่งเท่า

หน้านี้ถามว่าจะเสียเท่าไร หน้าถัดไป Kelly criterion ถามอีกด้าน เมื่อรู้ว่าได้เปรียบ ควรเสี่ยงเท่าไรให้ทุนโตเร็วที่สุดในระยะยาว และทำไมคนใช้จริงลงแค่ครึ่งหนึ่งของขนาดนั้น
