17.1 Value at Risk and Expected Shortfall

VaR คือขาดทุนที่ขีดเส้นแบ่งวันร้ายออกจากวันปกติ ส่วน Expected Shortfall คือขาดทุนเฉลี่ยของวันร้ายที่อยู่เลยเส้นนั้นไป

ธนาคารและกองทุนต้องตอบคำถามเดียวกันทุกเช้า: ถ้าพรุ่งนี้ตลาดเลวร้าย เราจะเสียเงินได้มากแค่ไหน ฝ่ายความเสี่ยงจึงย่อคำตอบให้เหลือตัวเลขเดียวส่งให้ผู้บริหาร ตัวเลขที่นิยมที่สุดชื่อ VaR (Value at Risk)

VaR 99% หนึ่งวัน คือยอดขาดทุนที่ 99 วันจาก 100 วันเสียไม่เกินยอดนี้ อีก 1 วันที่เหลือเสียมากกว่า กลุ่มวันที่เสียหนักที่สุดนี้เรียกว่า “หาง” (tail) ของผลขาดทุน

ของที่รู้ (ตัวเลขสมมติ):

  • มูลค่าพอร์ตวันนี้ $V=\$500$ ล้าน
  • ความผันผวนรายวัน $\sigma=1.2\%$ คือ SD (standard deviation) ของผลตอบแทนหนึ่งวัน คิดเป็นเงินได้ $\sigma V=0.012\times500=\$6$ ล้าน
  • ผลตอบแทนเฉลี่ยต่อวัน $\mu=0$ เพราะในหนึ่งวันค่าเฉลี่ยเล็กมากเมื่อเทียบกับความผันผวน (หน้านี้จะแสดงว่าเล็กแค่ไหน)

ฝ่ายความเสี่ยงรายงานว่า VaR 99% หนึ่งวันของพอร์ตนี้คือ \$13.96 ล้าน หน้านี้จะคำนวณตัวเลขนี้ให้ดูทีละขั้น เทรดเดอร์คนหนึ่งอ่านรายงานแล้วพูดว่า “พรุ่งนี้เสียได้มากสุด \$13.96 ล้าน”

คำถามมีสองข้อ ข้อแรก เทรดเดอร์อ่านถูกไหม ข้อสอง ถ้าวันร้าย 1% นั้นมาถึงจริง จะเสียเฉลี่ยเท่าไร ลองตอบสองกรณี กรณีแรก ผลตอบแทนเป็นรูประฆัง Normal กรณีที่สอง เป็น Student-t ซึ่งหน้าตาคล้ายระฆังแต่ “หางหนา” คือวันร้ายสุดโต่งเกิดบ่อยกว่า ทั้งสองกรณีใช้ความผันผวน 1.2% เท่ากัน

ลองตอบก่อนเปิดเฉลย

อ่านผิด \$13.96 ล้านไม่ใช่เพดาน มันคือจุดที่หาง 1% เริ่มต้น ทุกวันที่ตกอยู่ในหางเสียมากกว่ายอดนี้

ค่าเฉลี่ยของขาดทุนในหางมีชื่อว่า Expected Shortfall (ES) หน้านี้จะคำนวณให้ดูว่า

  • ถ้าเป็น Normal: VaR 99% คือ \$13.96 ล้าน และ ES 99% คือ \$15.99 ล้าน
  • ถ้าเป็น Student-t แบบ 4 degrees of freedom (ตัวเลขที่คุมความหนาของหาง) ที่ปรับให้ความผันผวนเป็น 1.2% เท่าเดิม: VaR 99% ขยับเป็น \$15.90 ล้าน แต่ ES 99% กระโดดเป็น \$22.15 ล้าน

เทียบสองกรณีด้วยอัตราส่วน t ต่อ Normal ($\mathcal N$ แทน Normal):

\[\begin{aligned}\frac{\mathrm{VaR}_t}{\mathrm{VaR}_{\mathcal N}}&=\frac{15.90}{13.96}=1.139,\\\frac{\mathrm{ES}_t}{\mathrm{ES}_{\mathcal N}}&=\frac{22.15}{15.99}=1.385.\end{aligned}\]

ความผันผวนเท่ากัน แต่จุดตัดขยับแค่ 13.9% ขณะที่ค่าเฉลี่ยในหางขยับ 38.5% ตัวเลขที่ไวต่อรูปทรงของหางคือ ES ไม่ใช่ VaR

ภาพรวมก่อนลงสูตร

ทำไมไม่ใช้ variance หรือความผันผวนวัดความเสี่ยงไปเลย variance ใช้ได้ดีเมื่อผลตอบแทนเป็นรูประฆัง แต่มีจุดอ่อนสองข้อ ข้อแรก มันนับวันที่กำไรมากเป็นความเสี่ยงเท่ากับวันที่ขาดทุนมาก ข้อสอง มันไม่บอกว่าหางยาวแค่ไหน แต่คนคุมความเสี่ยงสนใจฝั่งเดียวคือฝั่งขาดทุน และสนใจเฉพาะปลายสุดของฝั่งนั้น จึงต้องมีตัววัดที่มองที่หางโดยตรง

ตัววัดแรกคือ VaR เริ่มจากเลือกระดับ $c$ เช่น $c=0.99$ แล้ว VaR ที่ระดับ $c$ คือยอดขาดทุนที่วันส่วนใหญ่ (สัดส่วน $c$ ของวันทั้งหมด) เสียไม่เกิน VaR จึงเป็นเส้นที่ตัดหางออกมา หางที่เหลือมีสัดส่วน $1-c$ ของวัน เช่น 1%

ตัววัดที่สองคือ Expected Shortfall (ES) คือค่าเฉลี่ยของขาดทุนในหาง $1-c$ นั้น ทุกวันในหางเสียไม่น้อยกว่า VaR ค่าเฉลี่ยของมันจึงไม่น้อยกว่า VaR เสมอ ภาพที่ช่วยจำคือ ตัดพื้นที่หางในรูปข้างล่างออกมาเป็นแผ่น แล้ววางบนปลายนิ้ว จุดที่แผ่นทรงตัวได้คือ ES

ลำดับของหน้านี้ เริ่มจากนับขาดทุน 100 วันด้วยมือ แล้วเขียนนิยามที่ใช้ได้ทั้งกับข้อมูลและกับสูตร จากนั้นหาสูตรปิดเมื่อผลตอบแทนเป็น Normal ยืดจาก 1 วันเป็น 10 วัน และนับจากข้อมูล 60 เดือน สุดท้ายดูสองเหตุที่ทำให้ ES ดีกว่า VaR ข้อแรก หางหนาที่ VaR แทบมองไม่เห็น ข้อสอง ตัวอย่างที่ VaR ลงโทษการกระจายความเสี่ยง

ศัพท์ที่ใช้ในหัวข้อนี้
หาง (tail)
ปลายด้านขาดทุนหนักของผลขาดทุนทั้งหมด เช่น หาง 1% คือ 1 วันจาก 100 วันที่เสียหนักที่สุด
Value at Risk (VaR)
ยอดขาดทุนที่เป็นเส้นแบ่งหาง ในสัดส่วน $c$ ของวัน ขาดทุนไม่เกินยอดนี้ ธนาคารใช้ตั้งเพดานความเสี่ยงของแต่ละ desk (ทีมเทรดที่ดูแลพอร์ตของตัวเอง) เพราะเป็นตัวเลขเดียว หน่วยเป็นเงิน และเทียบข้ามสินทรัพย์ได้
Expected Shortfall (ES)
ค่าเฉลี่ยของขาดทุนในหาง $1-c$ ตอบคำถามที่ VaR ไม่ตอบ คือเมื่อวันร้ายมาถึงจริงจะเสียเฉลี่ยเท่าไร มีชื่ออื่นว่า CVaR (Conditional VaR) และ tail conditional expectation
Quantile
จุดตัดที่ข้อมูล (หรือโอกาส) ตามสัดส่วนที่กำหนดอยู่ต่ำกว่าหรือเท่ากับมัน เช่น quantile 0.99 ของขาดทุนคือยอดที่ 99% ของวันเสียไม่เกิน VaR ก็คือ quantile ตัวหนึ่ง
Historical simulation
วิธีหา VaR และ ES โดยเอาผลตอบแทนที่เกิดขึ้นจริงในอดีตมาเรียงแล้วนับ ไม่ต้องสมมติรูปทรง ตรวจง่าย แต่ในหางมีข้อมูลแค่ไม่กี่ตัว
Student-t distribution
รูปทรงคล้ายระฆังแต่หางหนากว่า ตัวคุมความหนาคือ degrees of freedom $\nu$ ยิ่ง $\nu$ น้อย หางยิ่งหนา ใช้แทนตลาดที่วันร้ายมาบ่อยกว่าที่ Normal ทำนาย
Subadditivity
กติกาว่าความเสี่ยงของสองสถานะ (position คือของที่ถืออยู่ เช่น พันธบัตรก้อนหนึ่ง) เมื่อรวมกัน ต้องไม่เกินความเสี่ยงของแต่ละสถานะบวกกัน ตัววัดที่ไม่ผ่านกติกานี้จะลงโทษการกระจายความเสี่ยง ES ผ่าน VaR ไม่ผ่าน

ขั้นที่ 1 — ลองด้วยมือ: ขาดทุน 100 วัน เรียงแล้วนับ

ก่อนมีสูตร ลองกับข้อมูลที่นับด้วยมือได้ desk หนึ่งจดผลกำไรขาดทุนไว้ 100 วัน (ตัวเลขสมมติ หน่วยพันดอลลาร์ นับขาดทุนเป็นบวก) หกวันที่เสียหนักที่สุด เรียงจากมากไปน้อย คือ 620, 540, 410, 380, 350 และ 330 อีก 94 วันเสียน้อยกว่า 330 หรือได้กำไร

เราอยากรู้สองอย่าง วันร้ายเริ่มที่ยอดไหน (VaR) และวันร้ายเหล่านั้นเสียเฉลี่ยเท่าไร (ES) ที่ระดับ 99% หางมี $100\times0.01=1$ วัน ที่ระดับ 95% หางมี $100\times0.05=5$ วัน

\[ \begin{aligned} \mathrm{VaR}_{0.99}&=540,\\ \mathrm{ES}_{0.99}&=620,\\ \mathrm{VaR}_{0.95}&=330,\\ \mathrm{ES}_{0.95}&=\frac{620+540+410+380+350}{5}\\ &=\frac{2{,}300}{5}=460. \end{aligned} \]

ระดับ 99% ถามหายอดที่ 99 วันจาก 100 วันเสียไม่เกิน วันที่เสีย 620 มีวันเดียว และเป็นหาง 1% พอดี วันถัดมาคือ 540 ทุกวันยกเว้นวัน 620 เสียไม่เกิน 540 รวมเป็น 99 วัน ดังนั้น 540 คือ VaR 99% แล้ว ES ถามต่อว่าวันในหางเสียเฉลี่ยเท่าไร หางมีวันเดียว ค่าเฉลี่ยจึงเป็น 620 เอง

ระดับ 95% หางมีห้าวัน คือ 620 ลงไปถึง 350 VaR จึงเลื่อนไปเป็นวันที่หก 330 เพราะมี $94+1=95$ วันที่เสียไม่เกิน 330 ส่วน ES คือค่าเฉลี่ยของห้าวันในหาง ได้ 460 สังเกตว่าในหางยังมีวันที่เสีย 620 ซึ่งมากกว่า 460 ES จึงไม่ใช่ขาดทุนสูงสุด มันเป็นค่าเฉลี่ย ไม่ใช่เพดาน

ขั้นที่ 2 — นิยามที่ใช้ได้ทั้งกับข้อมูลและกับสูตร

การนับ 100 วันง่าย เพราะหาง 1% และ 5% เป็นจำนวนวันเต็ม ถ้ามีข้อมูล 250 วัน (ราวหนึ่งปีของวันทำการ) หาง 1% คือ $250\times0.01=2.5$ วัน แล้วจะหยิบวันไหน เราจึงต้องการนิยามที่ไม่ขึ้นกับการหารลงตัว

เครื่องมือที่ใช้คือ $Q_L(u)$ ซึ่งตอบคำถามว่า “ยอดขาดทุนเท่าไร ที่สัดส่วน $u$ ของวันเสียไม่เกินยอดนั้น” เช่น $Q_L(0.99)$ คือยอดที่ 99% ของวันเสียไม่เกิน สูตรข้างล่างเขียนนิยามของ VaR และ ES ด้วย $Q_L$ ก่อน แล้วนำไปใช้กับข้อมูล $N$ วัน โดย $L_{(k)}$ คือขาดทุนอันดับ $k$ เมื่อเรียงจากน้อยไปมาก

\[ \begin{aligned} \mathrm{VaR}_c&=Q_L(c),\\ \mathrm{ES}_c&=\frac{1}{1-c}\int_c^1 Q_L(u)\,du,\\ Q_L(u)&=L_{(k)},\quad \frac{k-1}{N}\lt u\le\frac{k}{N},\\ \mathrm{VaR}_c&=L_{(K)},\quad K=\lceil cN\rceil,\\ \mathrm{ES}_{0.95}&=\frac{0.01(350+380+410+540+620)}{0.05}\\ &=\frac{23}{0.05}=460. \end{aligned} \]

VaR คือ quantile ที่ระดับ $c$ ตรง ๆ คือขาดทุน $\ell$ ที่เล็กที่สุดซึ่งทำให้ $P(L\le\ell)\ge c$ ส่วน ES ไม่ได้หยิบจุดเดียว มันเฉลี่ย quantile ทุกตัวที่ลึกกว่า $c$ ตั้งแต่ $u=c$ ถึง $u=1$ ตัว integral คือผลรวมของ quantile ตลอดช่วงนั้น และตัวหาร $1-c$ คือความยาวของช่วง ผลรวมหารด้วยความยาวจึงเป็นค่าเฉลี่ย หางที่ ES เฉลี่ยจึงกว้าง $1-c$ พอดีเสมอ ไม่มากไม่น้อย

กับข้อมูล $N$ วัน แต่ละวันมีน้ำหนัก $1/N$ ฟังก์ชัน $Q_L$ จึงเป็นขั้นบันได ขั้นที่ $k$ กว้าง $1/N$ และสูงเท่าขาดทุนอันดับ $k$ VaR คือความสูงของขั้นที่ $K=\lceil cN\rceil$ (เครื่องหมาย $\lceil\ \rceil$ แปลว่าปัดขึ้น) กับข้อมูล 100 วันที่ 95% ได้ $K=\lceil0.95\times100\rceil=95$ อันดับ 95 จากน้อยไปมากคืออันดับ $100-95+1=6$ จากบน คือ 330

ส่วน ES ช่วง $u$ จาก 0.95 ถึง 1 มีห้าขั้น กว้างขั้นละ $1/100=0.01$ พื้นที่ใต้ขั้นบันไดคือ $0.01\times2{,}300=23$ หารด้วยความกว้างของหาง 0.05 ได้ 460 ตรงกับที่นับด้วยมือ

ทำไมไม่นิยาม ES ง่าย ๆ ว่า “ค่าเฉลี่ยของวันที่เสียตั้งแต่ VaR ขึ้นไป” เพราะวันที่เสียเท่ากับ VaR พอดีจะถูกนับเข้ามาด้วย ที่ 99% จะได้ $(620+540)/2=580$ ซึ่งเป็นค่าเฉลี่ยของ 2 วัน หรือ 2% ของข้อมูล ไม่ใช่หาง 1% นิยามแบบ integral ไม่มีปัญหานี้ ถ้าหางมีเศษวัน เช่น 2.5 วัน วันที่อยู่ขอบหางจะถูกนับแค่ครึ่งเดียว (ดูโจทย์ข้อ 2 ท้ายหน้า) ส่วน distribution แบบต่อเนื่องอย่าง Normal มีโอกาสเป็นศูนย์ที่ขาดทุนจะเท่ากับ VaR พอดี สองนิยามจึงให้ค่าเท่ากัน คือ $\mathbb E[L\mid L\ge \mathrm{VaR}_c]$ แปลว่าค่าคาดหวังของขาดทุน เมื่อรู้ว่าขาดทุนเลย VaR ไปแล้ว

เรื่องการนับอันดับต้องระวัง กับข้อมูล 1,000 วันที่ระดับ 99% หาง 1% คือ $1{,}000\times0.01=10$ วันเต็ม ES เฉลี่ย 10 วันที่แย่ที่สุด แต่ VaR ตามนิยามขั้นบันไดคืออันดับ $\lceil0.99\times1{,}000\rceil=990$ จากน้อยไปมาก คืออันดับ $1{,}000-990+1=11$ จากบน หลาย desk หยิบอันดับ 10 แทน เวลารายงานจึงต้องบอกเสมอว่าใช้แบบไหน

ขั้นที่ 3 — จากผลตอบแทนเป็นขาดทุน: VaR ของพอร์ต \$500 ล้าน

การนับใช้ได้เมื่อมีข้อมูล ตอนนี้กลับไปที่พอร์ต \$500 ล้านในตอนต้น แล้วใช้แบบจำลองแทนการนับ สมมติว่าผลตอบแทนหนึ่งวัน $R$ เป็น Normal ที่มีค่าเฉลี่ย $\mu$ และความผันผวน $\sigma$ เงินที่ได้ในหนึ่งวันคือ $VR$ เราอยากนับขาดทุนเป็นบวก จึงกลับเครื่องหมายเป็น $L=-VR$

เป้าหมายคือหายอด $\ell$ ที่ $P(L\le\ell)=c$ เครื่องมือคือ $z_c$ จุดบนระฆังมาตรฐานที่พื้นที่ทางซ้ายเท่ากับ $c$ จุดที่ต้องระวังมีจุดเดียว: การกลับเครื่องหมายทำให้อสมการพลิกด้าน

\[ \begin{aligned} L&=-VR,\\ P(L\le\ell)&=P\Big(R\ge-\frac{\ell}{V}\Big)=c,\\ P(R\ge\mu-\sigma z_c)&=\Phi(z_c)=c,\\ -\frac{\ell}{V}&=\mu-\sigma z_c,\\ \mathrm{VaR}_c&=V(\sigma z_c-\mu),\\ \sigma V&=0.012(500{,}000{,}000)\\ &=6{,}000{,}000,\\ \mathrm{VaR}_{0.99}&=2.3263479(6{,}000{,}000)\\ &=13{,}958{,}087,\\ \mathrm{VaR}_{0.95}&=1.6448536(6{,}000{,}000)\\ &=9{,}869{,}122. \end{aligned} \]

ขาดทุนไม่เกิน $\ell$ แปลว่าผลตอบแทนไม่ต่ำกว่า $-\ell/V$ คำถามจึงกลายเป็นว่า จุดไหนที่ $R$ มีโอกาส $c$ จะอยู่เหนือมัน รูประฆังสมมาตร โอกาสที่ $R$ อยู่เหนือจุดที่ต่ำกว่าค่าเฉลี่ย $z_c$ เท่าของ $\sigma$ จึงเท่ากับโอกาสที่ระฆังมาตรฐานอยู่ใต้ $z_c$ คือ $\Phi(z_c)=c$ จับสองจุดนี้ให้เท่ากันแล้วย้ายข้าง ได้ว่า VaR คือความผันผวนคูณระยะมาตรฐาน $z_c$ หักด้วยกำไรที่คาดไว้ $\mu$ แล้วคูณมูลค่าพอร์ต

ตัวคูณ $z_c$ หาจากการเปิดตาราง Normal distribution ย้อนกลับ คือหาค่า $z$ ที่ $\Phi(z)=c$ ได้ $z_{0.99}=2.3263479$ และ $z_{0.95}=1.6448536$

ตัวอย่างนี้ตั้ง $\mu=0$ ตัดทิ้งได้จริงไหม ลองดูขนาด ถ้าคาดว่าพอร์ตโตปีละ 10% และตลาดหุ้นสหรัฐมีวันทำการปีละ 252 วัน ค่าเฉลี่ยรายวันคือ $\mu=0.10/252\approx0.0004$ หรือ 0.04% เทียบกับความผันผวนได้ $\sigma/\mu=0.012/0.0004=30$ เท่า ในหนึ่งวัน $\mu$ จึงเล็กจนตัดทิ้งได้ แต่ไม่ใช่ทุกช่วงเวลา เพราะค่าเฉลี่ยโตตามจำนวนวัน $h$ ส่วนความผันผวนโตตาม $\sqrt h$ (ขั้นถัดไปจะแสดง) ถือนานพอ ค่าเฉลี่ยก็ตามทันจนตัดทิ้งไม่ได้

VaR 99% เทียบกับขนาดพอร์ตคือ $13.96/500=2.79\%$ สูตรนี้เป็นเส้นตรงตาม $V$ และ $\sigma$ ลดพอร์ตลงครึ่งหนึ่ง VaR ก็ลดลงครึ่งหนึ่งพอดี คุณสมบัตินี้ทำให้ตั้งเพดานของแต่ละ desk ได้ง่าย และเมื่อ GARCH (แบบจำลองที่พยากรณ์ความผันผวนของพรุ่งนี้จากวันก่อน ๆ) บอกว่าความผันผวนพรุ่งนี้สูงขึ้น ก็คิดได้ทันทีว่าต้องลดพอร์ตลงเท่าไร

ขั้นที่ 4 — ES ของ Normal: เฉลี่ย quantile ทุกตัวในหาง

VaR ได้แล้ว ต่อไปคือ ES นิยามบอกว่า ES คือค่าเฉลี่ยของ $Q_L(u)$ ตั้งแต่ $u=c$ ถึง 1 กับ Normal ทุก quantile มีสูตรเดียวกับ VaR แค่เปลี่ยน $c$ เป็น $u$ คือ $V(\sigma\Phi^{-1}(u)-\mu)$ โดย $\Phi^{-1}(u)$ คือจุด $z$ ที่ $\Phi(z)=u$ งานจึงเหลือการหา integral ของ $\Phi^{-1}$

ปกติ integral ของหางระฆังทำด้วยมือไม่ได้ แต่ตัวนี้ทำได้ เพราะความสูงของระฆังมาตรฐาน $\varphi(z)=e^{-z^2/2}/\sqrt{2\pi}$ มี derivative รูปพิเศษ

\[ \begin{aligned} Q_L(u)&=V\big(\sigma\,\Phi^{-1}(u)-\mu\big),\\ u&=\Phi(z),\quad du=\varphi(z)\,dz,\\ \int_c^1\Phi^{-1}(u)\,du&=\int_{z_c}^{\infty}z\,\varphi(z)\,dz,\\ \varphi'(z)&=-z\,\varphi(z),\\ \int_{z_c}^{\infty}z\,\varphi(z)\,dz&=\Big[-\varphi(z)\Big]_{z_c}^{\infty}\\ &=\varphi(z_c),\\ \mathrm{ES}_c&=V\Big(\frac{\sigma\,\varphi(z_c)}{1-c}-\mu\Big),\\ \varphi(2.3263479)&=0.3989423\,e^{-2.7059472}\\ &=0.026652142,\\ \mathrm{ES}_{0.99}&=2.6652142(6{,}000{,}000)\\ &=15{,}991{,}285,\\ \mathrm{ES}_{0.95}&=2.0627128(6{,}000{,}000)\\ &=12{,}376{,}277. \end{aligned} \]

จังหวะแรกคือเปลี่ยนตัวแปร แทนที่จะเดินตามระดับ $u$ ให้เดินตามจุดบนระฆัง $z$ โดย $u=\Phi(z)$ ช่วง $u$ จาก $c$ ถึง 1 กลายเป็น $z$ จาก $z_c$ ถึงอนันต์ และ $\Phi^{-1}(u)$ กลายเป็น $z$ เฉย ๆ

จังหวะที่ทำให้ทุกอย่างง่ายคือ $\varphi'(z)=-z\varphi(z)$ ซึ่งได้จากการ differentiate $e^{-z^2/2}$ แล้วมี $-z$ หลุดออกมาคูณ ดังนั้น $z\varphi(z)$ คือ derivative ของ $-\varphi(z)$ integral ของหางจึงแค่ย้อน derivative กลับ ที่ปลายอนันต์ระฆังลงถึงศูนย์ เหลือแค่ความสูงของระฆังที่จุดตัด $\varphi(z_c)$ หารด้วยความกว้างของหาง $1-c$ ก็เป็นค่าเฉลี่ย

ที่ 99% ระฆังที่จุดตัดสูงเหลือ $e^{-z_{0.99}^2/2}=e^{-2.7059}=0.0668$ คือ 6.68% ของยอดระฆัง ES 99% คือ \$15.99 ล้าน มากกว่า VaR อยู่ $15.99-13.96=\$2.03$ ล้าน คิดเป็นอัตราส่วน $2.6652/2.3263=1.146$ ที่ 95% ตัวคูณคือ $\varphi(1.6448536)/0.05=0.10313564/0.05=2.0627128$ คูณ \$6 ล้าน ได้ \$12.38 ล้าน อัตราส่วนคือ $2.0627/1.6449=1.254$

ยิ่งลึกในหาง อัตราส่วน ES ต่อ VaR ยิ่งเข้าใกล้ 1 (1.254 ที่ 95% และ 1.146 ที่ 99%) เพราะระฆังลดลงเร็วมาก ขาดทุนในหางจึงกองอยู่ชิดจุดตัด นี่คือลายเซ็นของหางบาง ตลาดที่หางหนาไม่เป็นแบบนี้ ซึ่งจะเห็นตอนเปลี่ยนเป็น Student-t ข้างล่าง สังเกตอีกข้อ ใต้ Normal ทั้ง VaR และ ES ขึ้นกับ $\mu$ กับ $\sigma$ เท่านั้น จึงไม่ได้บอกอะไรเพิ่มจาก variance ตัววัดหางมีประโยชน์จริงเมื่อหางไม่ใช่ระฆัง

ขั้นที่ 5 — จาก 1 วันเป็น 10 วัน

ถึงตรงนี้ทุกตัวเลขเป็นความเสี่ยงหนึ่งวัน แต่ธนาคารที่ถือสถานะก้อนใหญ่ขายทิ้งในวันเดียวไม่ได้ เพราะขายมากเกินไปจะกดราคาตัวเอง กติกาของ Basel Committee (คณะกรรมการที่ออกกติกากลางให้ผู้คุมธนาคารทั่วโลก) ปี 1996 จึงถามความเสี่ยงของ 10 วันทำการ คำถามคือ จากตัวเลขหนึ่งวัน จะได้ตัวเลขสิบวันอย่างไร

สมมติว่าผลตอบแทนแต่ละวัน $R_1,\dots,R_{10}$ อิสระกัน และมีความผันผวน $\sigma$ เท่ากันทุกวัน ผลตอบแทนสิบวันคือผลรวมของมัน variance ของผลรวมคือผลบวกของ variance เพราะ covariance ข้ามวันเป็นศูนย์ (หลักเดียวกับ ความเสี่ยงของพอร์ตจาก covariance matrix) ให้ $\sigma_{10}$ คือความผันผวนของสิบวัน และ $h$ คือจำนวนวันที่ถือ

\[ \begin{aligned} \operatorname{Var}(R_1+\dots+R_{10})&=10\,\sigma^2,\\ \sigma_{10}&=\sqrt{10}\,\sigma\\ &=3.1622777(0.012)\\ &=0.037947,\\ \mathrm{VaR}_{0.99,10}&=13.958087\sqrt{10}\\ &=44.139,\\ \mathrm{ES}_{0.99,10}&=15.991285\sqrt{10}\\ &=50.569,\\ \mathrm{VaR}_{c,h}&=V\big(\sigma\sqrt h\,z_c-h\mu\big). \end{aligned} \]

ผลที่ได้คือความผันผวนโตตามรากของจำนวนวัน ไม่ใช่ตามจำนวนวัน ถือ 10 วัน ความผันผวนโต $\sqrt{10}=3.16$ เท่า ไม่ใช่ 10 เท่า เพราะวันดีกับวันร้ายหักล้างกันบางส่วน

เมื่อ $\mu=0$ ทั้ง VaR และ ES เป็นความผันผวนคูณค่าคงที่ จึงคูณ $\sqrt{10}$ ได้ทั้งก้อน ตัวเลขในสูตรเป็นหน่วยล้านดอลลาร์ VaR 99% สิบวันคือ \$44.14 ล้าน และ ES คือ \$50.57 ล้าน ถ้า $\mu$ ไม่เป็นศูนย์ คูณทั้งก้อนไม่ได้ เพราะค่าเฉลี่ยบวกกันตรง ๆ จึงโต $h$ เท่า แต่ความผันผวนโตแค่ $\sqrt h$ เท่า ตามสูตรทั่วไปที่ท้ายสุด

กฎรากนี้ต้องอาศัยสามข้อพร้อมกัน: วันอิสระกัน ความผันผวนเท่ากันทุกวัน และขาดทุนรวมยังเป็น Normal ถ้าพอร์ตมี option (สัญญาที่ให้สิทธิ์ซื้อหรือขายในราคาที่ตกลงไว้ มูลค่าของมันไม่ขยับเป็นเส้นตรงตามราคาสินทรัพย์) ข้อสุดท้ายพัง ต้องตีราคาสัญญาใหม่ในแต่ละสถานการณ์แทน และหลังช็อกใหญ่ ความผันผวนที่พยากรณ์ของแต่ละวันไม่เท่ากัน ข้อสองพัง ต้องรวม variance ที่พยากรณ์ไว้ทีละวัน

ขั้นที่ 6 — นับจากข้อมูล: 60 เดือนของพอร์ตสามสินทรัพย์

ขั้นนี้กลับไปนับแบบขั้นแรก แต่ใช้ข้อมูลชุดใหญ่ขึ้น ชุดข้อมูลตัวอย่างนี้มีผลตอบแทนรายเดือนของสินทรัพย์สามตัว ยาว 60 เดือน (ห้าปี) พอร์ตถือสามตัวเท่ากัน ตัวละหนึ่งในสามของเงิน เราจะหา VaR และ ES 95% รายเดือนด้วย historical simulation คือใช้นิยามขั้นบันไดกับข้อมูลตรง ๆ ไม่สมมติรูปทรงเลย สัญลักษณ์ที่ใช้:

  • $R_{i,t}$ คือผลตอบแทนของสินทรัพย์ตัวที่ $i$ ในเดือนที่ $t$ หน่วย %
  • $L_t$ คือขาดทุนของพอร์ตในเดือนที่ $t$ เป็นบวกเมื่อเสีย
  • $\widehat{\mathrm{VaR}}$ และ $\widehat{\mathrm{ES}}$ (มีหมวก) คือค่าที่นับจากข้อมูล
  • $\mathrm{VaR}_{\mathcal N}$ และ $\mathrm{ES}_{\mathcal N}$ คือค่าที่ได้ถ้าสมมติว่าขาดทุนเป็น Normal
\[ \begin{aligned} L_t&=-\tfrac13\big(R_{1,t}+R_{2,t}+R_{3,t}\big),\\ L_1&=-\tfrac13(3.3504)=-1.1168\%,\\ L_3&=-\tfrac13(-4.1261)=1.3754\%,\\ K&=\lceil0.95(60)\rceil=57,\\ \widehat{\mathrm{VaR}}_{0.95}&=L_{(57)}=1.9191\%,\\ \widehat{\mathrm{ES}}_{0.95}&=\frac{1.9877+2.1450+2.3707}{3}\\ &=2.1678\%,\\ \mathrm{VaR}_{\mathcal N}&=-0.096905\\ &\quad+1.6448536(1.147563)\\ &=1.7907\%,\\ \mathrm{ES}_{\mathcal N}&=-0.096905\\ &\quad+2.0627128(1.147563)\\ &=2.2702\%. \end{aligned} \]

ขาดทุนของพอร์ตคือค่าเฉลี่ยของสามตัวแล้วกลับเครื่องหมาย ตัวอย่างสองเดือน เดือนแรกสามตัวให้ 2.1675%, −1.8883% และ 3.0712% เดือนที่สามให้ −2.5194%, 1.5773% และ −3.1840% ผลรวมของแต่ละเดือนคือ

\[\begin{aligned}\textstyle\sum_i R_{i,1}&=2.1675-1.8883+3.0712\\&=3.3504,\\\textstyle\sum_i R_{i,3}&=-2.5194+1.5773-3.1840\\&=-4.1261.\end{aligned}\]

เดือนแรกพอร์ตได้กำไร ขาดทุนจึงติดลบ $L_1=-1.1168\%$ เดือนที่สามพอร์ตเสีย $L_3=1.3754\%$ ทำแบบนี้ครบ 60 เดือนแล้วเรียง ห้าเดือนที่เสียมากที่สุดคือ 2.3707%, 2.1450%, 1.9877%, 1.9191% และ 1.8807%

หาง 5% ของ 60 เดือนคือ $0.05\times60=3$ เดือนเต็ม VaR คืออันดับ $K=57$ จากน้อยไปมาก คืออันดับ $60-57+1=4$ จากบน ได้ 1.9191% ES คือค่าเฉลี่ยของสามเดือนที่แย่กว่านั้น ได้ 2.1678% จุดอ่อนอยู่ตรงนี้: ทั้งหางมีข้อมูลแค่สามตัว เปลี่ยนเดือนเดียว ES ก็ขยับมาก

สองค่าสุดท้ายในสูตรลองสมมติว่าขาดทุนรายเดือนเป็น Normal แล้วใช้สูตรของ Normal จากข้างบน สูตรเดิมเขียนด้วยค่าเฉลี่ยของผลตอบแทน $\mu$ แต่ที่นี่เราวัดค่าเฉลี่ยของขาดทุนโดยตรง ซึ่งเท่ากับ $-\mu$ VaR จึงเป็นค่าเฉลี่ยของขาดทุน บวก $z_c$ เท่าของความผันผวน

ขาดทุนทั้ง 60 เดือนรวมกันได้ −5.8143% ค่าเฉลี่ยจึงเป็น $-5.8143/60=-0.096905\%$ ติดลบเพราะโดยเฉลี่ยพอร์ตได้กำไร ความผันผวนที่คำนวณจากข้อมูลชุดเดียวกันคือ 1.147563% คิดแบบ sample variance ที่หารด้วย $N-1=59$ เพื่อไม่ให้ตัวประมาณเอนเอียง ตัวคูณ 2.0627128 ของ ES คือ $\varphi(z_{0.95})/0.05$ จากสูตร ES ของ Normal ผลคือ Normal ให้ VaR ต่ำกว่าการนับ (1.7907% เทียบ 1.9191%) แต่ให้ ES สูงกว่า (2.2702% เทียบ 2.1678%)

ขั้นที่ 7 — หางหนา: Student-t ที่ความผันผวนเท่าเดิม

ผลตอบแทนรายวันจริงมีวันร้ายสุดโต่งบ่อยกว่าที่ระฆัง Normal ทำนาย (ดู ทำไมใช้ GBM กับราคาหุ้น และ สวนสัตว์ของ distribution) ขั้นนี้ทดลองว่าเรื่องนี้กระทบ VaR และ ES แค่ไหน

กลับไปที่พอร์ต \$500 ล้าน คงความผันผวน 1.2% ไว้เท่าเดิม แต่เปลี่ยนรูปทรงจาก Normal เป็น Student-t ที่ degrees of freedom $\nu=4$ ซึ่งหางหนาพอสมควร ให้ $T$ เป็นตัวแปร t มาตรฐานที่มี density $f$ พื้นที่สะสม $F$ และให้ $q$ คือ quantile ที่ $F(q)=0.99$ คำถามคือ VaR กับ ES ขยับเท่ากันไหม

\[ \begin{aligned} f(t)&=\tfrac38\Big(1+\frac{t^2}{4}\Big)^{-5/2},\\ \operatorname{Var}(T)&=\frac{4}{4-2}=2,\\ F(q)&=\frac12+\frac{q(q^2+6)}{2(q^2+4)^{3/2}}\\ &=0.99,\\ q&=3.7469474,\\ \mathrm{VaR}_{0.99}&=\frac{q}{\sqrt2}(6{,}000{,}000)\\ &=2.6494919(6{,}000{,}000)\\ &=15{,}896{,}951,\\ \int_q^{\infty}t f(t)\,dt&=\tfrac12\Big(1+\frac{q^2}{4}\Big)^{-3/2}\\ &=\tfrac12(4.5099037)^{-3/2}\\ &=0.05220584,\\ \mathrm{ES}_{0.99}&=\frac{0.05220584}{0.01\sqrt2}(6{,}000{,}000)\\ &=22{,}149{,}063. \end{aligned} \]

t ที่ $\nu=4$ มี variance $\nu/(\nu-2)=4/2=2$ ไม่ใช่ 1 ถ้าจะเทียบกับระฆังมาตรฐานอย่างยุติธรรม ต้องหาร $T$ ด้วย $\sqrt2$ ให้ความผันผวนเป็น 1 ก่อน แล้วจึงคูณ \$6 ล้าน เหมือนกรณี Normal VaR จึงเป็น $q/\sqrt2$ คูณ \$6 ล้าน

$F$ ของ $\nu=4$ มีสูตรปิด (differentiate แล้วจะได้ $f$ คืนมา) แต่แก้สมการ $F(q)=0.99$ ด้วยมือไม่ได้ จึงหา $q$ ด้วย bisection คือแบ่งครึ่งช่วงที่คำตอบอยู่ไปเรื่อย ๆ จนแคบพอ ตรวจคำตอบโดยแทนกลับ:

\[\begin{aligned}q(q^2+6)&=75.087,\\2(q^2+4)^{3/2}&=153.240,\\F(q)&=0.5+\frac{75.087}{153.240}\\&=0.5+0.49=0.99.\end{aligned}\]

integral ของหางใช้ท่าเดียวกับ ES ของ Normal คือหาสิ่งที่ differentiate แล้วได้ตัวที่อยู่ใน integral ตั้ง $u=1+t^2/4$ จะได้ $du=\tfrac t2\,dt$ ดังนั้น $t f(t)\,dt$ กลายเป็น $\tfrac34u^{-5/2}\,du$ ซึ่งมี antiderivative $-\tfrac12u^{-3/2}$ ที่ปลายอนันต์ค่านี้เป็นศูนย์ เหลือค่าที่ $q$ คือ 0.05220584 หารด้วยความกว้างของหาง 0.01 หารด้วย $\sqrt2$ เพื่อปรับความผันผวนเป็น 1 แล้วคูณ \$6 ล้าน ก็เป็น ES

เทียบกับ Normal ที่ความผันผวนเท่ากัน (หน่วยล้านดอลลาร์):

\[\begin{aligned}\frac{\mathrm{VaR}_t}{\mathrm{VaR}_{\mathcal N}}&=\frac{15.897}{13.958}=1.139,\\\frac{\mathrm{ES}_t}{\mathrm{ES}_{\mathcal N}}&=\frac{22.149}{15.991}=1.385,\\\frac{\mathrm{ES}_t}{\mathrm{VaR}_t}&=\frac{22.149}{15.897}=1.393.\end{aligned}\]

ความผันผวนเท่ากัน แต่ VaR เพิ่ม 13.9% ขณะที่ ES เพิ่ม 38.5% อัตราส่วน ES ต่อ VaR ของ t คือ 1.393 เทียบกับ 1.146 ของ Normal ส่วนต่างของ ES $22.15-15.99=\$6.16$ ล้าน คือความเสียหายที่ Normal มองไม่เห็น ทั้งที่ประมาณความผันผวนถูกแล้ว

ลองดูอีกมุม วันที่ขาดทุนเกิน 4 เท่าของความผันผวน คือเกิน $4\times6=\$24$ ล้าน เกิดบ่อยแค่ไหน ใต้ t เงื่อนไข $T/\sqrt2\gt4$ คือ $T\gt4\sqrt2=5.657$ แล้วแปลงโอกาสต่อวันเป็นจำนวนปีที่ต้องรอ โดยปีหนึ่งมีวันทำการ 252 วัน:

\[\begin{aligned}P_{\mathcal N}&=1-\Phi(4)=0.0000317,\\\frac{1}{0.0000317\times252}&=125,\\P_t&=1-F(5.657)=0.0024,\\\frac{1}{0.0024\times252}&=1.65.\end{aligned}\]

ใต้ Normal วันแบบนี้มีโอกาส 0.0032% ต่อวัน คือราวหนึ่งวันใน 125 ปี ใต้ t มีโอกาส 0.24% ต่อวัน คือราวหนึ่งวันทุก 1.65 ปี

ขั้นที่ 8 — variance เกือบเท่ากัน แต่ VaR กับ ES ขยับคนละทิศ

ขั้นนี้สร้างตลาดหางหนาอีกแบบที่นึกภาพง่ายกว่า t ตลาดมีสองอารมณ์ บางวันสงบ บางวันปั่นป่วน แต่ละวันสุ่มก่อนว่าจะเป็นแบบไหน แล้วจึงสุ่มผลตอบแทนจาก Normal ของแบบนั้น เรียกว่า Normal ผสม (mixture) ใช้พอร์ต \$500 ล้านเดิม และวัดความผันผวนเป็นจำนวนเท่าของ 1.2% เดิม (ตัวเลขสมมติ):

  • วันสงบ: เกิด 75% ของวัน ความผันผวน 0.76 เท่าของเดิม
  • วันปั่นป่วน: เกิด 25% ของวัน ความผันผวน 1.5 เท่าของเดิม
  • ทั้งสองแบบมีค่าเฉลี่ยศูนย์

ตัวเลข 0.76 และ 1.5 เลือกมาให้ variance รวมเกือบเท่ากับ Normal เดิม การเทียบจึงยุติธรรม ขั้นนี้เทียบที่ระดับ 95% ให้ $s$ คือความผันผวนของแต่ละก้อน (0.76 หรือ 1.5) $x$ คือ VaR ในหน่วยเท่าของความผันผวนเดิม และ $F$ คือพื้นที่สะสมของแบบผสม

\[ \begin{aligned} \operatorname{Var}&=0.75(0.76)^2+0.25(1.5)^2\\ &=0.4332+0.5625\\ &=0.9957,\\ F(x)&=0.75\,\Phi\Big(\frac{x}{0.76}\Big)\\ &\quad+0.25\,\Phi\Big(\frac{x}{1.5}\Big),\\ F(x)=0.95&:\ x=1.58761593,\\ \int_x^{\infty}\frac ys\,\varphi\Big(\frac ys\Big)dy&=s\,\varphi\Big(\frac xs\Big),\\ \mathrm{ES}&=\frac{0.0256567+0.0854448}{0.05}\\ &=2.22203006,\\ \mathrm{VaR}&=1.58761593(6{,}000{,}000)\\ &=9{,}525{,}696,\\ \mathrm{ES}&=2.22203006(6{,}000{,}000)\\ &=13{,}332{,}180. \end{aligned} \]

ทั้งสองก้อนมีค่าเฉลี่ยศูนย์ variance ของแบบผสมจึงเป็นค่าเฉลี่ยถ่วงน้ำหนักของ variance สองก้อน ได้ 0.9957 เท่าของ Normal ต่ำกว่าเพียง $1-0.9957=0.0043$ หรือ 0.43%

VaR หาโดยแก้ $F(x)=0.95$ ด้วย bisection เหมือนกรณี t ได้ $x=1.58761593$ ตรวจโดยแทนกลับ ที่จุดนี้ $x/0.76=2.0890$ และ $x/1.5=1.0584$ เปิดตารางได้ $\Phi(2.0890)=0.981645$ และ $\Phi(1.0584)=0.855066$ แล้ว $0.75(0.981645)+0.25(0.855066)=0.95$ พอดี

ES ใช้ท่าเดียวกับ ES ของ Normal ทีละก้อน ก้อนที่มีความผันผวน $s$ มี density $\tfrac1s\varphi(y/s)$ ตั้ง $z=y/s$ แล้ว integral ของหางเท่ากับ $s\varphi(x/s)$ คูณน้ำหนักของก้อนแล้วรวมกัน:

\[\begin{aligned}0.75(0.76)\,\varphi(2.0890)&=0.0256567,\\0.25(1.5)\,\varphi(1.0584)&=0.0854448,\\\frac{0.0854448}{0.0256567+0.0854448}&=0.77.\end{aligned}\]

ในหาง 5% นี้ 77% ของ integral มาจากก้อนปั่นป่วน ทั้งที่มันเกิดแค่ 25% ของวัน วันร้ายส่วนใหญ่จึงมาจากช่วงปั่นป่วน เทียบกับ Normal ที่ 95% (หน่วยล้านดอลลาร์) แบบผสมมี VaR ต่ำกว่า $9.87-9.53=\$0.34$ ล้าน แต่มี ES สูงกว่า $13.33-12.38=\$0.95$ ล้าน

t ที่ $\nu=4$ ก็เป็นแบบเดียวกันที่ระดับ 95% แก้ $F(q)=0.95$ ได้ $q=2.1318468$ แล้วแทนลงในสูตรของ t ข้างบน:

\[\begin{aligned}\mathrm{VaR}&=\frac{2.1318468}{\sqrt2}(6)=9.04,\\\tfrac12\Big(1+\frac{q^2}{4}\Big)^{-3/2}&=0.16014,\\\mathrm{ES}&=\frac{0.16014}{0.05\sqrt2}(6)=13.59.\end{aligned}\]

VaR ของ t คือ \$9.04 ล้าน ต่ำกว่า Normal (\$9.87 ล้าน) แต่ ES คือ \$13.59 ล้าน สูงกว่า Normal (\$12.38 ล้าน) เหตุผลคือหางหนาดึงโอกาสจาก “ไหล่” ของระฆัง (ช่วงขาดทุนปานกลาง) ไปไว้ที่ปลายสุด จุดตัด 95% จึงตื้นขึ้นได้ ขณะที่ค่าเฉลี่ยในหางลึกขึ้น

ขั้นที่ 9 — ตัวอย่างค้าน: กระจายเงินแล้ว VaR กลับแย่ลง

สามัญสำนึกบอกว่า แบ่งเงินไปลงหลายที่ปลอดภัยกว่าลงที่เดียว ตัววัดความเสี่ยงที่ดีจึงควรให้คะแนนการกระจายเงินดีขึ้น ตัวอย่างเล็ก ๆ นี้แสดงว่า VaR ทำกลับกันได้ ตัวอย่างใช้พันธบัตร (bond) คือการให้บริษัทกู้เงิน บริษัทจ่ายดอกเบี้ยและคืนเงินต้นตามกำหนด ถ้าบริษัทล้มและไม่จ่าย เรียกว่าผิดนัด (default)

โจทย์ให้อะไรมาบ้าง: (ตัวเลขสมมติ)

  • พันธบัตรสองตัวจากสองบริษัท แต่ละตัวมีโอกาสผิดนัด 3% ในช่วงเวลาที่วัด
  • สองบริษัทผิดนัดอิสระกัน
  • ถ้าผิดนัด เสียเงินต้นทั้งหมด
  • ทางเลือกแรก ถือตัวเดียว \$100 ล้าน ขาดทุนคือ $L_1$
  • ทางเลือกที่สอง แบ่งถือตัวละ \$50 ล้าน ขาดทุนคือ $L_2$

คำถามคือ ที่ระดับ 95% VaR และ ES ชอบทางเลือกไหน หน่วยในสูตรเป็นล้านดอลลาร์ ขาดทุนมีได้ไม่กี่ค่า (0, 50 หรือ 100) จึงใช้นิยามขั้นบันไดตรง ๆ

\[ \begin{aligned} P(L_1=100)&=0.03\lt0.05,\\ \mathrm{VaR}_{0.95}(L_1)&=0,\\ \mathrm{ES}_{0.95}(L_1)&=\frac{0.03(100)}{0.05}=60,\\ P(L_2=100)&=0.03^2=0.0009,\\ P(L_2=50)&=2(0.03)(0.97)\\ &=0.0582,\\ P(L_2\ge50)&=0.0591\gt0.05,\\ \mathrm{VaR}_{0.95}(L_2)&=50,\\ \mathrm{ES}_{0.95}(L_2)&=\frac{0.0009(100)+0.0491(50)}{0.05}\\ &=\frac{0.09+2.455}{0.05}\\ &=50.9,\\ \mathrm{VaR}&:\ 50\gt0+0,\\ \mathrm{ES}&:\ 50.9\le30+30. \end{aligned} \]

คำตอบ: VaR บอกว่าการแบ่งทำให้แย่ลง จาก 0 เป็น \$50 ล้าน แต่ ES บอกว่าดีขึ้น จาก \$60 ล้านเป็น \$50.9 ล้าน

ถือตัวเดียว: โอกาสเสีย 3% น้อยกว่าหาง 5% เมื่อเรียงขาดทุนจากน้อยไปมาก โอกาส 97% แรกเป็นขาดทุน 0 ซึ่งเกิน 95% แล้ว จุดตัดจึงตกที่ 0 VaR เป็นศูนย์ ทั้งที่มีโอกาสเสีย \$100 ล้าน ES เห็นความเสียหายนั้น หาง 5% ประกอบด้วยกรณีเสีย 100 ที่โอกาส 3% และกรณีเสีย 0 อีก 2% ค่าเฉลี่ยคือ $(0.03\times100+0.02\times0)/0.05=60$

แบ่งถือ: มีสามกรณี ผิดนัดทั้งคู่ด้วยโอกาส $0.03^2=0.0009$ ผิดนัดตัวเดียวด้วยโอกาส $2(0.03)(0.97)=0.0582$ (คูณ 2 เพราะเป็นตัวไหนก็ได้) โอกาสที่เสียอย่างน้อย 50 คือ $0.0009+0.0582=0.0591$ เกิน 5% จุดตัดจึงกระโดดเป็น 50

ทีนี้มองทีละตัว พันธบัตร \$50 ล้านแต่ละตัวมีโอกาสเสียแค่ 3% VaR ของแต่ละตัวจึงเป็นศูนย์ VaR ของพอร์ตรวม (50) จึงเกินผลบวกของ VaR ส่วนย่อย ($0+0$) นี่คือการละเมิด subadditivity VaR ลงโทษการกระจายความเสี่ยง

ES ไม่มีปัญหานี้ หาง 5% ของพอร์ตแบ่งมีกรณีผิดนัดทั้งคู่ 0.09% และกรณีผิดนัดตัวเดียวอีก $5\%-0.09\%=4.91\%$ ค่าเฉลี่ยได้ 50.9 ส่วน ES ของพันธบัตร \$50 ล้านแต่ละตัวคือ $0.03\times50/0.05=30$ และ 50.9 ไม่เกิน $30+30=60$

ตัวอย่างนี้ยังบอกว่าทำไมนิยามขั้นบันไดต้องตัดหางให้กว้าง 5% พอดี ถ้าเฉลี่ยทุกกรณีที่เสียตั้งแต่ VaR ขึ้นไป จะเฉลี่ยพื้นที่ 5.91% แทน 5%:

\[\begin{aligned}&\frac{0.0009(100)+0.0582(50)}{0.0591}\\&=\frac{0.09+2.91}{0.0591}=\frac{3}{0.0591}=50.76.\end{aligned}\]

ได้ 50.76 ไม่ใช่ 50.9 เพราะพื้นที่ที่เฉลี่ยกว้างเกินหาง 5% จึงดึงกรณีเสีย 50 เข้ามามากเกินไป

ตรวจเองใน 10 วินาที: โอกาสที่ไม่มีตัวไหนผิดนัดคือ $0.97\times0.97=0.9409$ จึงมีโอกาสเสียอย่างน้อย 50 อยู่ $1-0.9409=0.0591$ มากกว่า 0.05 จุดตัดจึงอยู่ที่ 50 และ $0.0009+0.0491=0.05$ คือหางที่ ES เฉลี่ยพอดี

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

อ่าน VaR เป็นขาดทุนสูงสุด และ tail stuffing: VaR บอกแค่ว่าหางเริ่มตรงไหน จึงซ่อนความเสี่ยงไว้หลังจุดตัดได้ เรียกว่า tail stuffing (ยัดความเสี่ยงไว้ในหาง) ตัวอย่าง (สมมติ) กลยุทธ์หนึ่งได้กำไรวันละ 0.1% ด้วยโอกาส 99.5% แต่มีโอกาส 0.5% ต่อวันที่จะเสีย 20% โอกาสเสีย 0.5% น้อยกว่าหาง 1% จุดตัด 99% จึงตกในกลุ่มวันกำไร ส่วนหาง 1% มีวันเสีย 20% อยู่ครึ่งหนึ่ง และวันกำไร 0.1% อีกครึ่งหนึ่ง:

\[\begin{aligned}\mathrm{VaR}_{0.99}&=-0.1\%,\\\mathrm{ES}_{0.99}&=\frac{0.005(20)+0.005(-0.1)}{0.01}\\&=\frac{0.0995}{0.01}=9.95\%.\end{aligned}\]

VaR ติดลบ คือรายงานว่าเป็นกำไร ดูปลอดภัยมาก แต่ ES บอกว่าวันร้ายเสียเฉลี่ย 9.95% ต่อวัน ใครถูกวัดด้วย VaR อย่างเดียวจะถูกดึงไปหากลยุทธ์แบบนี้ เช่น ขาย option ที่ห่างจากราคาตลาดมาก ซึ่งได้เงินค่าขายก้อนเล็กแทบทุกวัน แต่เสียหนักเมื่อตลาดพลิกแรง

ใช้ 1.96 กับ VaR 95%: 1.96 คือจุดตัดของช่วง 95% แบบสองด้าน ซึ่งเหลือหางข้างละ 2.5% แต่ VaR สนใจหางเดียวคือฝั่งขาดทุน ตัวคูณที่ถูกคือ $z_{0.95}=1.645$ กับพอร์ต \$500 ล้าน ใช้ 1.96 จะได้ $1.96\times6=\$11.76$ ล้าน แทนที่จะเป็น $1.645\times6=\$9.87$ ล้าน มากกว่าค่าที่ถูก $11.76/9.87=1.19$ เท่า คือสูงเกินไป 19%

บวกเกินหนึ่งตัว: สูตรลัดที่พบบ่อยคือบวกขาดทุนตั้งแต่อันดับ $K$ ถึง $N$ แล้วหารด้วยจำนวนวันในหาง $(1-c)N$ ปัญหาคืออันดับ $K$ คือ VaR เองซึ่งอยู่นอกหาง กับ 60 เดือนที่ 95% สูตรนี้บวกอันดับ 57 ถึง 60 ซึ่งมีสี่ตัว แต่หารด้วยสาม:

\[\begin{aligned}&\frac{1.9191+1.9877+2.1450+2.3707}{3}\\&=\frac{8.4225}{3}=2.8075\%.\end{aligned}\]

ค่าที่ถูกคือ 2.1678% สูตรลัดให้ค่ามากกว่า $2.8075/2.1678=1.295$ เท่า คือสูงเกินไป 29.5% เมื่อข้อมูลเป็นพันตัว ความต่างนี้เล็ก แต่ที่ 60 ตัว มันใหญ่กว่าความต่างระหว่างการนับกับ Normal เสียอีก ($2.8075-2.1678=0.64$ เทียบกับ $2.2702-2.1678=0.10$)

คูณ $\sqrt{10}$ ตอนที่ความผันผวนเกาะกลุ่ม: หลังวันที่ตลาดร่วงแรง GARCH พยากรณ์ว่าวันถัด ๆ ไปจะแกว่งแรงกว่าปกติ แล้วค่อย ๆ สงบลง ความผันผวนสิบวันจึงไม่ใช่ $\sqrt{10}$ เท่าของค่าวันเดียว ให้ $s_d$ คือความผันผวนที่พยากรณ์ของวันที่ $d$ ความผันผวนสิบวันที่ถูกคือ $\sqrt{s_1^2+s_2^2+\dots+s_{10}^2}$ ถ้าเอาความผันผวนจากช่วงสงบมาคูณ $\sqrt{10}$ ตัวเลขจะต่ำเกินจริง

เชื่อ ES จากข้อมูลน้อย: ES เป็นค่าเฉลี่ย จึงไวต่อค่าสุดโต่งไม่กี่ตัว ใน 60 เดือน ES 95% ใช้ข้อมูลแค่สามตัว ถ้าเดือนที่แย่ที่สุดเปลี่ยนจาก 2.3707% เป็น 5% ES จะกลายเป็น

\[\begin{aligned}&\frac{1.9877+2.1450+5}{3}\\&=\frac{9.1327}{3}=3.04\%.\end{aligned}\]

ES กระโดดจาก 2.17% เป็น 3.04% ขณะที่ VaR (อันดับ 57) ยังเป็น 1.9191% ไม่ขยับเลย

ใช้ทำอะไรบนโต๊ะจริง

VaR เกิดที่ธนาคาร J.P. Morgan ต้นทศวรรษ 1990 ผู้บริหารอยากได้รายงานหน้าเดียวทุกวันว่าทั้งธนาคารเสี่ยงเท่าไร ข้อดีของ VaR มีสองข้อ ข้อแรก ประมาณจากข้อมูลได้นิ่ง เพราะขึ้นกับอันดับ ไม่ขึ้นกับขนาดของวันสุดโต่ง ข้อสอง ตรวจย้อนหลังได้ง่าย แค่นับว่ามีกี่วันที่ขาดทุนเกิน VaR ข้อเสียคือมองไม่เห็นอะไรหลังจุดตัด เปิดช่องให้ tail stuffing และไม่ผ่าน subadditivity

ES มองเห็นทั้งหางและผ่าน subadditivity ข้อดีอีกข้อคือ ถ้ามีชุดสถานการณ์จำนวนจำกัด และขาดทุนเป็นเส้นตรงตามน้ำหนักของพอร์ต การเลือกพอร์ตให้ ES ต่ำสุดเขียนเป็น linear program (ปัญหาหาค่าต่ำสุดที่ทุกเงื่อนไขเป็นเส้นตรง) ได้ จึงแก้ได้เร็วมาก ข้อเสียคือ ES เป็นค่าเฉลี่ยของข้อมูลไม่กี่ตัว จึงไวต่อค่าสุดโต่ง

ผู้คุมกฎหันมาใช้ ES แล้ว กรอบ FRTB (Fundamental Review of the Trading Book กติกาของ Basel ที่ประกาศปี 2016) เปลี่ยนตัววัดความเสี่ยงตลาดของธนาคารที่ใช้แบบจำลองของตัวเอง จาก VaR 99% เป็น ES 97.5% ลองคิดกับพอร์ต \$500 ล้านใต้ Normal:

\[\begin{aligned}\frac{\varphi(1.959964)}{0.025}&=\frac{0.05844507}{0.025}\\&=2.3378,\\\mathrm{ES}_{0.975}&=2.3378(6)=14.03.\end{aligned}\]

ES 97.5% คือ \$14.03 ล้าน ใกล้ VaR 99% \$13.96 ล้านมาก ใต้ Normal การเปลี่ยนตัววัดจึงแทบไม่เปลี่ยนตัวเลข แต่ใต้ t ที่ $\nu=4$ (ใช้สูตร ES ของ t ข้างบนกับ $c=0.975$) ES 97.5% คือ \$16.94 ล้าน สูงกว่า VaR 99% ของ t เอง (\$15.90 ล้าน) ตัวเลขใหม่จึงลงโทษหางหนาโดยตรง

สำหรับพอร์ตที่มี option สูตรปิดใช้ไม่ได้ ธนาคารใช้ Monte Carlo สุ่มสร้างสถานการณ์ตลาดจำนวนมาก ตีราคาสัญญาใหม่ในแต่ละสถานการณ์ แล้วใช้นิยามขั้นบันไดกับผลขาดทุนที่ได้ เหมือนการนับข้อมูล 100 วันในขั้นแรก

// Standard Normal: erf by power series (small x) or continued fraction (large x)
function erf(x) {
  const t = Math.abs(x);
  if (t < 2.5) {
    let sum = 0, term = t;
    for (let k = 0; k < 200; k++) {
      const add = term / (2 * k + 1);
      sum += add;
      if (Math.abs(add) < 1e-17 * sum) break;
      term *= -t * t / (k + 1);
    }
    return Math.sign(x) * 2 / Math.sqrt(Math.PI) * sum;
  }
  let f = t;
  for (let k = 120; k >= 1; k--) f = t + (k / 2) / f;
  return Math.sign(x) * (1 - Math.exp(-t * t) / Math.sqrt(Math.PI) / f);
}
const Phi = z => 0.5 * (1 + erf(z / Math.SQRT2));
const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);

// Solve F(x) = p for an increasing F by bisection
function solve(F, p, lo, hi) {
  for (let i = 0; i < 200; i++) {
    const mid = (lo + hi) / 2;
    if (F(mid) < p) lo = mid; else hi = mid;
  }
  return (lo + hi) / 2;
}

// Historical: each loss weighs 1/N; ES averages exactly the worst (1 - c) share
function historical(losses, c) {
  const s = [...losses].sort((a, b) => a - b);
  const N = s.length, cN = c * N, K = Math.ceil(cN - 1e-9);
  let tail = 0;
  for (let k = 1; k <= N; k++) tail += s[k - 1] * Math.min(1, Math.max(0, k - cN));
  return {K, VaR: s[K - 1], ES: tail / (N - cN)};
}

// Discrete loss given as [loss, probability] pairs
function discreteRisk(outcomes, c) {
  const rows = [...outcomes].sort((a, b) => a[0] - b[0]);
  let cum = 0, VaR = null, tail = 0;
  for (const [x, p] of rows) {
    const before = cum;
    cum += p;
    if (VaR === null && cum >= c - 1e-12) VaR = x;
    tail += x * Math.max(0, cum - Math.max(before, c));
  }
  return {VaR, ES: tail / (1 - c)};
}

// Student-t with 4 degrees of freedom, rescaled to variance 1
const t4Cdf = t => 0.5 + t * (t * t + 6) / (2 * (t * t + 4) ** 1.5);
function t4Risk(c) {
  const q = solve(t4Cdf, c, 0, 1e4);
  const tail = 0.5 * (1 + q * q / 4) ** -1.5;
  return {VaR: q / Math.SQRT2, ES: tail / (1 - c) / Math.SQRT2};
}

// Mixture of zero-mean Normals with weights w and scales s
function mixtureRisk(w, s, c) {
  const F = x => w.reduce((a, wi, i) => a + wi * Phi(x / s[i]), 0);
  const q = solve(F, c, 0, 100);
  const ES = w.reduce((a, wi, i) => a + wi * s[i] * phi(q / s[i]), 0) / (1 - c);
  return {VaR: q, ES};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • VaR คือจุดเริ่มของหาง ES คือค่าเฉลี่ยของหางที่กว้าง $1-c$ พอดี กับข้อมูล 100 วันในขั้นแรก (หน่วยพันดอลลาร์) ได้ VaR 540 กับ ES 620 ที่ 99% และ VaR 330 กับ ES 460 ที่ 95%
  • พอร์ต \$500 ล้าน ความผันผวน 1.2% ต่อวัน แบบ Normal: VaR 99% หนึ่งวันคือ \$13.96 ล้าน ES คือ \$15.99 ล้าน ถือสิบวันคูณ $\sqrt{10}$ ได้ \$44.14 ล้าน และ \$50.57 ล้าน
  • ES ของ Normal หาด้วยมือได้เพราะ $\varphi'(z)=-z\varphi(z)$ ส่วน ES ของ t หาได้ด้วยการแทน $u=1+t^2/4$
  • ความผันผวนเท่ากันแต่หางหนา: ที่ 99% VaR ขึ้น 13.9% แต่ ES ขึ้น 38.5% ที่ 95% หางหนาทำให้ VaR ลดลง ขณะที่ ES เพิ่มขึ้น
  • VaR ลงโทษการกระจายความเสี่ยงได้ (จาก 0 เป็น \$50 ล้าน) และถูกหลบได้ด้วย tail stuffing ES ไม่มีสองปัญหานี้ แต่ประมาณจากข้อมูลได้ไม่นิ่งเท่า VaR
