26.1 The Factor Model Equation and Three Ways to Read It

ผลตอบแทนของหุ้นทุกตัวคือแรงร่วมไม่กี่ตัวคูณ loading บวกส่วนที่เป็นเรื่องของหุ้นตัวนั้นเอง และสมการเดียวนี้แยกทั้งกำไรขาดทุนและความเสี่ยงของพอร์ตออกเป็นสองก้อน

พอร์ต long–short หุ้นสี่ตัวถือ A \$3 ล้าน B −\$2 ล้าน C \$4 ล้าน และ D −\$5 ล้าน เงินฝั่งซื้อเท่าฝั่งขายพอดี วันนี้ตลาดขึ้น 0.80% แต่พอร์ตขาดทุน \$13,000 ผู้จัดการพอร์ตบอกว่า “พอร์ตเป็นกลางต่อตลาดแล้ว ขาดทุนนี้จึงเป็นวันที่เลือกหุ้นพลาด” ข้อสรุปนี้ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ผิดทั้งสองครึ่ง การเลือกหุ้นวันนี้ทำเงินได้ \$53,000 ส่วนที่ขาดทุนคือ factor ซึ่งเสีย \$66,000 พอร์ตนี้ไม่มี exposure ต่อตลาดจริง แต่มี exposure ต่อ momentum \$13.8 ล้าน จาก GMV \$14 ล้าน วันนี้ momentum ลง 0.50% จึงเสีย \$69,000 และ tech ได้คืน \$3,000 เงินสองฝั่งที่เท่ากันไม่ได้แปลว่าไม่มีเดิมพันซ่อนอยู่ หน้านี้แยกตัวเลขทั้งหมดนี้ให้ดูทีละบรรทัด

ภาพรวมก่อนลงสูตร

หุ้นไม่ได้ขยับแยกกัน วันที่ตลาดขึ้น หุ้นส่วนใหญ่ขึ้นตาม วันที่หุ้นที่เคยวิ่งแรงถูกเทขาย หุ้นกลุ่มนั้นลงพร้อมกัน factor model เขียนความจริงข้อนี้เป็นสมการ ผลตอบแทนของหุ้นหนึ่งตัวในหนึ่งวันมีสองชั้น ชั้นแรกมาจากแรงร่วมไม่กี่ตัวที่เรียกว่า factor ซึ่งหุ้นทุกตัวเห็นตัวเลขเดียวกัน แต่รับมากหรือน้อยตาม loading ของตัวเอง ชั้นที่สองเป็นเรื่องของหุ้นตัวนั้นล้วน ๆ เช่นงบออกดีกว่าคาด เรียกว่าส่วนเฉพาะตัว

ทำไมต้องมีโครงสร้างนี้? เพราะทางเลือกอื่นแย่กว่า ถ้าทำเหมือนหุ้นแต่ละตัวขยับอิสระ เราจะพลาดการขยับร่วมซึ่งเป็นความเสี่ยงก้อนใหญ่ที่สุด ถ้าประมาณ covariance ของทุกคู่หุ้นตรง ๆ ข้อมูลที่มีก็ไม่พอ factor model บังคับให้การขยับร่วมทุกอย่างผ่านแรงร่วมไม่กี่ตัว แล้วปล่อยส่วนที่เหลือให้เป็นของหุ้นแต่ละตัว

หน้านี้จะเขียนสมการพร้อมข้อสมมติ คำนวณหุ้นสี่ตัวในวันเดียวด้วยมือ แล้วอ่านสมการเดิมสามทาง คือเป็นกราฟของเส้นเชื่อม เป็นผลรวมของคอลัมน์ และเป็นผลคูณจุดที่ย่อทั้งพอร์ตให้เหลือไม่กี่ตัวเลข ทางที่สามตอบคำถามข้างบน เพราะมันแยกกำไรขาดทุนและความเสี่ยงของพอร์ตเป็นส่วน factor กับส่วนเฉพาะตัว รูปข้างล่างคือตัวเลขของวันนี้ที่ทั้งหน้าจะใช้

ศัพท์ที่ใช้ในหัวข้อนี้
Factor return
ผลตอบแทนของแรงร่วมหนึ่งตัวในหนึ่งวัน เช่น market วันนี้ +0.80% หุ้นทุกตัวเห็นตัวเลขเดียวกัน ต่างกันแค่รับมากหรือน้อยตาม loading ใช้อธิบายการขยับร่วมของหุ้นทั้งตลาด
Loading และ loadings matrix
loading บอกว่าหุ้นรับแรงจาก factor หนึ่งมากแค่ไหน วางเป็นตาราง $\mathbf B$ ขนาด $n\times m$ แถวละหุ้น คอลัมน์ละ factor ใน model ที่ใช้คุณสมบัติบริษัท loading รู้ก่อนวันเริ่ม ไม่ต้องประมาณ
Idiosyncratic return
ส่วนของผลตอบแทนที่เหลือหลังหักแรงร่วม เป็นเรื่องของหุ้นตัวนั้นล้วน ๆ บางคนเรียก residual หรือ specific ใช้เป็นตัววัดกำไรจากการเลือกหุ้น
Factor exposure
ผลรวมของ loading ถ่วงด้วยเงินที่ถือ $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$ บอกว่าทั้งพอร์ตรับแรงจากแต่ละ factor กี่ดอลลาร์ ย่อพอร์ตหุ้นหลายพันตัวให้เหลือตัวเลขเท่าจำนวน factor
NMV และ GMV
NMV คือเงินฝั่งซื้อลบฝั่งขาย GMV คือผลรวมของขนาดทุกตำแหน่งโดยไม่สนเครื่องหมาย พอร์ตที่ NMV เป็นศูนย์เรียกว่า dollar-neutral ซึ่งไม่ได้แปลว่าไม่มี exposure ต่อ factor
Strict และ approximate factor model
strict คือ model ที่สมมติว่าส่วนเฉพาะตัวของหุ้นต่างตัวไม่สัมพันธ์กันเลย covariance ของมันจึงเป็น diagonal ถ้ายอมให้บางคู่สัมพันธ์กันได้เล็กน้อย เรียกว่า approximate
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$n,\ m,\ T$จำนวนหุ้น จำนวน factor และจำนวนวันของข้อมูลนับ
$\mathbf r_t$ผลตอบแทนส่วนเกินของหุ้นทุกตัวในวัน $t$ (ผลตอบแทนลบดอกเบี้ยไร้ความเสี่ยง)% ต่อวัน
$\boldsymbol\alpha$ผลตอบแทนคาดหวังส่วนที่ factor ไม่ได้ให้ (หน้านี้ตั้งเป็นศูนย์)% ต่อวัน
$\mathbf B,\ B_{ij}$loadings matrix $n\times m$ และ loading ของหุ้น $i$ ต่อ factor $j$ไม่มีหน่วย
$\mathbf f_t,\ \boldsymbol\epsilon_t$factor return ($m$ ตัว) และ idiosyncratic return ($n$ ตัว)% ต่อวัน
$\mathbf w,\ \mathbf b$เงินที่ถือแต่ละหุ้น (ติดลบคือ short) และ factor exposure $\mathbf B^{\mathsf T}\mathbf w$\$ ล้าน
$\boldsymbol\Omega_f,\ \boldsymbol\Omega_\epsilon,\ \boldsymbol\Omega_r$covariance ของ factor return ($m\times m$) ของส่วนเฉพาะตัว ($n\times n$) และของผลตอบแทนหุ้น%² ต่อวัน
$\sigma_i$ความผันผวนเฉพาะตัวของหุ้น $i$ ($\sigma_i^2$ อยู่บนแนวทแยงของ $\boldsymbol\Omega_\epsilon$)% ต่อวัน

ขั้นที่ 1 — สมการ และสิ่งที่มันสมมติ

เริ่มจากนิยาม ผลตอบแทนส่วนเกินของหุ้นทุกตัวในวัน $t$ เขียนเป็นสามก้อน ก้อนแรกคงที่ ก้อนที่สองมาจากแรงร่วม ก้อนที่สามเป็นของหุ้นแต่ละตัว สามบรรทัดล่างคือข้อสมมติที่ทำให้สมการนี้มีประโยชน์ ไม่ใช่ผลที่พิสูจน์ได้

\[ \begin{aligned} \mathbf r_t&=\boldsymbol\alpha+\mathbf B\mathbf f_t+\boldsymbol\epsilon_t,\\ \mathbb E[\boldsymbol\epsilon_t]&=\mathbf 0,\\ \operatorname{cov}(\mathbf f_t,\boldsymbol\epsilon_t)&=\mathbf 0,\\ \operatorname{cov}(\boldsymbol\epsilon_t)&=\boldsymbol\Omega_\epsilon\\ &=\operatorname{diag}(\sigma_1^2,\dots,\sigma_n^2). \end{aligned} \]

$\mathbf B$ มี $n$ แถว $m$ คอลัมน์ โดย $m$ เล็กกว่า $n$ มาก เช่นหุ้น 500 ตัวกับ factor 60 ตัว $\mathbf f_t$ จึงเป็นตัวสุ่มไม่กี่ตัวที่ขับหุ้นทั้งตลาด ส่วน $\boldsymbol\epsilon_t$ มีตัวละหุ้น $\boldsymbol\alpha$ คือผลตอบแทนคาดหวังที่ factor ไม่ได้ให้ หน้าถัดไปเรื่อง alpha spanned และ alpha orthogonal จะแยกว่ามันเป็นของจริงแค่ไหน หน้านี้ตั้งเป็นศูนย์ นอกจากนี้ยังสมมติว่าคู่ $(\mathbf f_t,\boldsymbol\epsilon_t)$ มีการแจกแจงเหมือนเดิมทุกวัน หรือเปลี่ยนช้ามาก

ข้อสมมติที่หนักที่สุดคือบรรทัดสุดท้าย ส่วนเฉพาะตัวของหุ้นสองตัวไม่สัมพันธ์กัน แปลว่าการขยับร่วมทุกอย่างต้องผ่าน factor ถ้า model ขาด factor ที่ควรมี การขยับร่วมส่วนนั้นจะไปโผล่เป็น correlation ระหว่างส่วนเฉพาะตัว ซึ่งเป็นร่องรอยที่ใช้ตรวจตอน ประมาณ covariance ของส่วนเฉพาะตัว

ขั้นที่ 2 — หุ้นสี่ตัว หนึ่งวัน

โจทย์ให้อะไรมาบ้าง: หุ้น A, B, C, D กับ factor สามตัว คือ market ที่ทุกหุ้นมี loading 1, momentum ที่ loading เป็น z-score ของผลตอบแทนย้อนหลังราวหนึ่งปี และ tech ที่เป็น 1 ถ้าหุ้นอยู่ในกลุ่ม tech (A กับ B) วันนี้ factor return คือ market +0.80% momentum −0.50% tech +0.30% ส่วนเฉพาะตัวของสี่หุ้นคือ +0.40%, −0.25%, +0.15% และ −0.60% ตัวเลขทั้งหมดสมมติ และใช้ต่อทั้งบท

\[ \begin{aligned} \mathbf B&=\begin{bmatrix}1&1.2&1\\1&-0.4&1\\1&0.6&0\\1&-1.4&0\end{bmatrix},\\ r_A&=0.80+1.2(-0.50)\\ &\quad+0.30+0.40=0.90\%,\\ r_B&=0.80-0.4(-0.50)\\ &\quad+0.30-0.25=1.05\%,\\ r_C&=0.80+0.6(-0.50)\\ &\quad+0.15=0.65\%,\\ r_D&=0.80-1.4(-0.50)\\ &\quad-0.60=0.90\%. \end{aligned} \]

คำตอบ: ผลตอบแทนวันนี้คือ 0.90%, 1.05%, 0.65% และ 0.90% B กับ D มี momentum ติดลบทั้งคู่ จึงได้ประโยชน์จากวันที่ momentum ร่วง แต่ B อยู่ใน tech ที่ขึ้น 0.30% ขณะที่ D โดนข่าวเฉพาะตัว −0.60% ผลตอบแทนที่เห็นเป็นผลรวมของหลายเรื่องเสมอ และสมการนี้แยกมันออกจากกันได้ ตรงกับรูปแท่งสองชั้นด้านบน

ตรวจเองใน 10 วินาที: A กับ D ได้ 0.90% เท่ากันทั้งที่ที่มาต่างกันหมด A ได้ $0.80-0.60+0.30=0.50$ จาก factor บวก 0.40 ของตัวเอง ส่วน D ได้ $0.80+0.70=1.50$ จาก factor ลบ 0.60 ของตัวเอง

ขั้นที่ 3 — อ่านแบบที่หนึ่ง: กราฟของเส้นเชื่อม

ตอนนี้อ่านสมการเดิมสามทาง ทางแรกมองทีละหุ้น ถ้ารู้ factor return ของวันนี้แล้ว หุ้น $i$ ควรได้เท่าไร ส่วนเฉพาะตัวมีค่าเฉลี่ยศูนย์จึงหายไป เหลือผลคูณจุดของแถว $i$ ของ $\mathbf B$ กับ $\mathbf f$

\[ \begin{aligned} \mathbb E[r_i-\alpha_i\mid\mathbf f]&=\sum_{j=1}^{m}B_{ij}f_j\\ &=\langle\mathbf B_{i\cdot},\ \mathbf f\rangle,\\ \mathbf B_{A\cdot}&=(1,\ 1.2,\ 1),\\ \langle\mathbf B_{A\cdot},\ \mathbf f\rangle&=0.80-0.60+0.30\\ &=0.50\%. \end{aligned} \]

ภาพที่ควรมีในหัวคือกราฟข้างล่าง วงกลมข้างบนคือ factor สี่เหลี่ยมข้างล่างคือหุ้น เส้นเชื่อมคือ loading ผลตอบแทนที่คาดของหุ้นหนึ่งตัวคือผลรวมของ factor return ที่ไหลลงมาตามเส้นที่ชี้เข้าหามัน model ของทั้งภูมิภาคมีหุ้นราวหมื่นตัวกับ factor ราวร้อยตัว แต่หุ้นหนึ่งตัวแตะแค่ market, industry และ country อย่างละตัว กับ style อีกสิบกว่าตัว ช่องส่วนใหญ่ของ $\mathbf B$ จึงเป็นศูนย์ และกราฟจริงมีเส้นน้อยกว่าที่คิด

ทางนี้ตอบคำถามระดับหุ้น เช่นข่าวดีของ A วันนี้ใหญ่แค่ไหน จาก 0.90% ที่เห็น มี 0.50 จุดที่ใครถือหุ้นที่ loading แบบ A ก็ได้เหมือนกัน เหลือ 0.40 จุดที่เป็นของ A เอง

ขั้นที่ 4 — อ่านแบบที่สอง: ผลรวมของคอลัมน์

ทางที่สองมองทุกหุ้นพร้อมกัน จัดการคูณ matrix $\mathbf B\mathbf f$ ตามคอลัมน์แทนแถว ส่วนที่ factor อธิบายได้ของทุกหุ้นคือผลรวมของคอลัมน์ของ $\mathbf B$ ถ่วงด้วย factor return ของวันนั้น

\[ \begin{aligned} \mathbf B\mathbf f&=\sum_{j=1}^{m}\mathbf B_{\cdot j}\,f_j\\ &=0.80\begin{bmatrix}1\\1\\1\\1\end{bmatrix}-0.50\begin{bmatrix}1.2\\-0.4\\0.6\\-1.4\end{bmatrix}\\ &\quad+0.30\begin{bmatrix}1\\1\\0\\0\end{bmatrix}=\begin{bmatrix}0.50\\1.30\\0.50\\1.50\end{bmatrix}. \end{aligned} \]

คอลัมน์ market เลื่อนทุกหุ้นขึ้น 0.80 เท่ากัน คอลัมน์ momentum ถูกคูณด้วยค่าติดลบ หุ้นที่ momentum สูงอย่าง A จึงเสีย 0.60 จุด ส่วน D ได้ 0.70 จุด คอลัมน์ tech ยก A กับ B ขึ้น 0.30 ผลรวมคือ (0.50, 1.30, 0.50, 1.50) ซึ่งคือแท่งน้ำเงินของรูปแรก

ทางนี้ทำให้เห็นมิติ ผลตอบแทนของหุ้นสี่ตัวเป็นจุดใน 4 มิติ แต่ส่วนของ factor ถูกขังในrange ของ $\mathbf B$ ซึ่งมีแค่ 3 มิติ (ทุกผลรวมถ่วงของคอลัมน์) ที่หุ้น 500 ตัวกับ factor 60 ตัว ส่วนของ factor อยู่ใน 60 มิติ อีก 440 มิติเป็นของส่วนเฉพาะตัวทั้งหมด ที่ว่างนี้คือที่อยู่ของ alpha ชนิดที่มีค่าที่สุดในหน้าถัดไป

ขั้นที่ 5 — อ่านแบบที่สาม: ทั้งพอร์ต

ทางที่สามคือทางที่ใช้ทุกวัน คูณสมการด้วยเงินที่ถือ $\mathbf w$ แล้วจับกลุ่มใหม่ กำไรขาดทุนของพอร์ตแยกเป็นสองก้อน และก้อนแรกขึ้นกับพอร์ตผ่าน vector $\mathbf b$ ที่ยาวแค่ $m$ ตัว ไม่ว่าจะถือหุ้นกี่ตัว

\[ \begin{aligned} \mathbf w^{\mathsf T}\mathbf r&=\mathbf w^{\mathsf T}\mathbf B\mathbf f+\mathbf w^{\mathsf T}(\boldsymbol\alpha+\boldsymbol\epsilon)\\ &=\mathbf b^{\mathsf T}\mathbf f+\mathbf w^{\mathsf T}(\boldsymbol\alpha+\boldsymbol\epsilon),\\ \mathbf b&:=\mathbf B^{\mathsf T}\mathbf w,\\ b_{\rm mkt}&=3-2+4-5=0,\\ b_{\rm mom}&=3.6+0.8+2.4+7.0\\ &=13.8,\\ b_{\rm tech}&=3-2=1. \end{aligned} \]

บรรทัดที่สองใช้ $\mathbf w^{\mathsf T}\mathbf B=(\mathbf B^{\mathsf T}\mathbf w)^{\mathsf T}$ (กฎของ transpose ที่กลับลำดับผลคูณ) ก้อนแรกเรียกว่า factor PnL ก้อนที่สองเรียกว่า idiosyncratic PnL exposure ต่อ market คือ NMV พอดี เพราะคอลัมน์ market เป็น 1 ทุกแถว พอร์ตนี้ NMV เป็นศูนย์จึงไม่มี exposure ต่อตลาดจริง

แต่ momentum รวมได้ \$13.8 ล้าน หุ้นที่ซื้อ (A, C) มี momentum บวก หุ้นที่ขาย (B, D) มี momentum ลบ เช่น $-0.4\times(-2)=+0.8$ และ $-1.4\times(-5)=+7.0$ ลบคูณลบได้บวก ทุกตำแหน่งจึงเดิมพันทางเดียวกันว่า momentum จะขึ้น โดยไม่มีใครตั้งใจ

ขั้นที่ 6 — แยกกำไรขาดทุนของวันนี้

โจทย์ให้อะไรมาบ้าง: exposure ที่เพิ่งได้ $\mathbf b=(0, 13.8, 1)$ และตัวเลขวันนี้ของหุ้นสี่ตัว เงินเป็น \$ ล้าน ผลตอบแทนเป็น % หน่วยของผลคูณจึงเป็น \$1 ล้าน × 1% = \$10,000

\[ \begin{aligned} \mathbf b^{\mathsf T}\mathbf f&=0(0.80)+13.8(-0.50)\\ &\quad+1(0.30)\\ &=-6.90+0.30=-6.60,\\ \mathbf w^{\mathsf T}\boldsymbol\epsilon&=3(0.40)-2(-0.25)\\ &\quad+4(0.15)-5(-0.60)\\ &=1.20+0.50+0.60+3.00\\ &=5.30,\\ \mathbf w^{\mathsf T}\mathbf r&=-6.60+5.30=-1.30. \end{aligned} \]

คำตอบ: factor PnL คือ −\$66,000 แยกเป็น market \$0, momentum −\$69,000 และ tech +\$3,000 idiosyncratic PnL คือ +\$53,000 มากกว่าครึ่งมาจากการขาย D ที่โดนข่าวร้าย (+\$30,000) รวมทั้งพอร์ต −\$13,000 คำพูดของผู้จัดการพอร์ตผิดทั้งสองส่วน การเลือกหุ้นวันนี้ดีมาก ที่เสียคือเดิมพัน momentum ที่ไม่รู้ตัวว่าถืออยู่

ตรวจเองใน 10 วินาที: คูณเงินกับผลตอบแทนตรง ๆ $3(0.90)-2(1.05)+4(0.65)-5(0.90)=2.70-2.10+2.60-4.50=-1.30$ ได้เท่ากัน สองทางเป็นผลบวกเดียวกันที่จัดกลุ่มต่างกัน จึงต้องตรงกันเสมอ

ขั้นที่ 7 — ความเสี่ยงก็แยกเป็นสองก้อน

กำไรขาดทุนแยกได้แล้ว ความเสี่ยงล่ะ? หา covariance ของ $\mathbf r=\boldsymbol\alpha+\mathbf B\mathbf f+\boldsymbol\epsilon$ ค่าคงที่ $\boldsymbol\alpha$ ไม่มีผลต่อ covariance ที่เหลือคือผลบวกของสองก้อนที่ไม่สัมพันธ์กันตามข้อสมมติของสมการ

\[ \begin{aligned} \operatorname{cov}(\mathbf B\mathbf f+\boldsymbol\epsilon)&=\operatorname{cov}(\mathbf B\mathbf f)\\ &\quad+\operatorname{cov}(\boldsymbol\epsilon)+\mathbf 0,\\ \operatorname{cov}(\mathbf B\mathbf f)&=\mathbf B\boldsymbol\Omega_f\mathbf B^{\mathsf T},\\ \boldsymbol\Omega_r&=\mathbf B\boldsymbol\Omega_f\mathbf B^{\mathsf T}+\boldsymbol\Omega_\epsilon,\\ \mathbf w^{\mathsf T}\boldsymbol\Omega_r\mathbf w&=\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b\\ &\quad+\mathbf w^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf w. \end{aligned} \]

เลข $\mathbf 0$ ในบรรทัดแรกคือพจน์ไขว้สองก้อน $\mathbf B\operatorname{cov}(\mathbf f,\boldsymbol\epsilon)$ กับตัว transpose ของมัน ซึ่งเป็นศูนย์เพราะ factor ไม่เกี่ยวกับส่วนเฉพาะตัว บรรทัดที่สองคือกฎ covariance ของการแปลงเชิงเส้น ช่อง $(i,k)$ ของ $\operatorname{cov}(\mathbf B\mathbf f)$ คือ $\sum_{j,l}B_{ij}[\boldsymbol\Omega_f]_{jl}B_{kl}$ ซึ่งคือสูตรเดียวกับ covariance ของ multi-factor model

บรรทัดสุดท้ายได้จากการคูณ $\mathbf w$ สองข้าง แล้วใช้ $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$ อีกครั้ง ความเสี่ยงจาก factor ขึ้นกับพอร์ตผ่าน exposure $m$ ตัวเท่านั้น ส่วนความเสี่ยงเฉพาะตัวคือ $\sum_iw_i^2\sigma_i^2$ เพราะ $\boldsymbol\Omega_\epsilon$ เป็น diagonal สูตรนี้มีงานสองอย่าง คือพยากรณ์ความเสี่ยงล่วงหน้าของพอร์ต และแบ่งมันเป็นส่วนที่ตั้งใจถือกับส่วนที่ไม่ตั้งใจ

ขั้นที่ 8 — ความเสี่ยงของพอร์ตในโจทย์

โจทย์ให้อะไรมาบ้าง: ความผันผวนรายวันของ factor คือ market 1.00% momentum 0.35% tech 0.55% correlation ระหว่าง market กับ momentum −0.20, market กับ tech +0.50, momentum กับ tech −0.10 ความผันผวนเฉพาะตัวของ A, B, C, D คือ 1.80%, 2.20%, 1.50% และ 2.60% ต่อวัน (สมมติ) เพราะ $b_{\rm mkt}=0$ แถวและคอลัมน์ของ market ใน $\boldsymbol\Omega_f$ จึงไม่ถูกใช้ ให้ $\omega_{mm}$, $\omega_{tt}$, $\omega_{mt}$ เป็นช่อง momentum, tech และช่องไขว้ของ $\boldsymbol\Omega_f$ และเรียกสองก้อนว่า $v_f=\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b$ กับ $v_\epsilon=\mathbf w^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf w$

\[ \begin{aligned} \omega_{mm}&=0.35^2=0.1225,\\ \omega_{tt}&=0.55^2=0.3025,\\ \omega_{mt}&=-0.10(0.35)(0.55)\\ &=-0.01925,\\ v_f&=13.8^2\omega_{mm}+\omega_{tt}\\ &\quad+2(13.8)\,\omega_{mt}\\ &=23.3289+0.3025\\ &\quad-0.5313=23.1001,\\ v_\epsilon&=9(3.24)+4(4.84)\\ &\quad+16(2.25)\\ &\quad+25(6.76)=253.52,\\ v_f+v_\epsilon&=276.6201,\\ \sqrt{276.6201}&=16.6319. \end{aligned} \]

คำตอบ: คูณรากที่สองด้วย \$10,000 ความเสี่ยงจาก factor คือ $\sqrt{23.1001}=4.8063$ หรือ \$48,063 ต่อวัน ความเสี่ยงเฉพาะตัวคือ $\sqrt{253.52}=15.9223$ หรือ \$159,223 รวมทั้งพอร์ต \$166,319 ต่อวัน ส่วนเฉพาะตัวครอง $253.52/276.6201=91.65\%$ ของ variance เพราะพอร์ตมีแค่สี่หุ้น ถ้ากระจายเงินก้อนเดิมไปหุ้น $n$ ตัว variance เฉพาะตัวจะลดลงราว $1/n$ เท่า (ผลรวมของตัวแปรที่ไม่สัมพันธ์กัน แบบเดียวกับกฎจำนวนมาก) ขณะที่เดิมพัน momentum ไม่ลดถ้ายังเลือกหุ้นแบบเดิม สัดส่วนจึงพลิกไปทาง factor ได้ง่าย

ตรวจเองใน 10 วินาที: ความผันผวนไม่บวกกันตรง ๆ $48{,}063+159{,}223=207{,}286$ ไม่ใช่คำตอบ ที่ถูกคือ $\sqrt{48{,}063^2+159{,}223^2}=166{,}319$ เพราะสองก้อนไม่สัมพันธ์กัน variance จึงบวกกันได้ ความผันผวนบวกไม่ได้

ขั้นที่ 9 — ทำไมต้องบังคับให้การขยับร่วมผ่าน factor

ทางเลือกอีกทางคือประมาณ covariance ของทุกคู่ตรง ๆ จากข้อมูลหนึ่งปี ซึ่งมีราว 252 วันทำการ (วันธรรมดา 261 วัน หักวันหยุดตลาดหุ้นสหรัฐราว 9 วัน) กับหุ้น 500 ตัว covariance หนึ่ง matrix มีตัวเลขอิสระ $n(n+1)/2$ ตัว ในขณะที่ factor model ที่ loading เป็นข้อมูลบริษัทซึ่งรู้อยู่แล้ว เหลือต้องประมาณแค่ $\boldsymbol\Omega_f$ กับ variance เฉพาะตัว $n$ ตัว

\[ \begin{aligned} \frac{n(n+1)}{2}&=\frac{500(501)}{2}\\ &=125{,}250,\\ \frac{m(m+1)}{2}+n&=1{,}830+500\\ &=2{,}330,\\ \frac{125{,}250}{2{,}330}&\approx53.8,\\ \operatorname{rank}(\hat{\boldsymbol\Omega}_r)&\le T-1=251,\\ 500-251&=249,\\ \mathbf w^{\mathsf T}\boldsymbol\Omega_r\mathbf w&\ge\sum_{i=1}^{n}w_i^2\sigma_i^2\gt0. \end{aligned} \]

ปัญหาจริงไม่ใช่แค่ตัวเลขเยอะ covariance จากข้อมูล 252 วันมี rank ไม่เกิน 251 เพราะหลังหักค่าเฉลี่ยแล้วข้อมูลเหลือ 251 แถวที่อิสระกัน หุ้น 500 ตัวจึงมีอย่างน้อย 249 ทิศ (พอร์ต) ที่ข้อมูลบอกว่าความเสี่ยงเป็นศูนย์พอดี และ optimizer จะเทเงินลงทิศเหล่านั้นก่อน ยิ่งกว่านั้น matrix ที่มีทิศความเสี่ยงศูนย์หา inverse ไม่ได้ ซึ่ง Markowitz ต้องใช้

covariance ของ factor model ไม่มีทิศแบบนั้น ก้อน $\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b$ ไม่ติดลบเพราะ $\boldsymbol\Omega_f$ เป็น covariance และก้อนเฉพาะตัวบวก $w_i^2\sigma_i^2$ ทุกครั้งที่ถือหุ้นสักตัว บรรทัดสุดท้ายจึงเป็นบวกเสมอ ไม่ว่าข้อมูลจะสั้นแค่ไหน

ขั้นที่ 10 — พอร์ตที่ไม่มี exposure ต่อ factor ใดเลย

โจทย์ให้อะไรมาบ้าง: หาพอร์ต $\mathbf u$ ที่ $\mathbf B^{\mathsf T}\mathbf u=\mathbf 0$ ได้สามสมการ คือ $u_A+u_B+u_C+u_D=0$, $1.2u_A-0.4u_B+0.6u_C-1.4u_D=0$ และ $u_A+u_B=0$ ตั้ง $u_A=1$ สมการที่สามให้ $u_B=-1$ สมการแรกจึงเหลือ $u_D=-u_C$ แทนลงสมการที่สองได้ $1.2+0.4+0.6u_C+1.4u_C=1.6+2u_C=0$

\[ \begin{aligned} \mathbf u&=(1,\ -1,\ -0.8,\ 0.8),\\ b_{\rm mkt}&=1-1-0.8+0.8=0,\\ b_{\rm mom}&=1.2+0.4-0.48-1.12\\ &=0,\\ b_{\rm tech}&=1-1=0,\\ \mathbf u^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf u&=3.24+4.84\\ &\quad+0.64(2.25+6.76)\\ &=13.8464,\\ \sqrt{13.8464}&=3.7211. \end{aligned} \]

คำตอบ: ซื้อ A \$1 ล้าน ขาย B \$1 ล้าน ขาย C \$0.8 ล้าน และซื้อ D \$0.8 ล้าน พอร์ตนี้ไม่มี exposure ต่อ factor ไหนเลย แต่ยังเสี่ยง \$37,211 ต่อวัน ซึ่งเป็นความเสี่ยงเฉพาะตัวทั้งหมด ในโลกสี่หุ้นสาม factor นี่คือทิศเดียวที่ทำแบบนี้ได้ ทุกคำตอบอื่นเป็นผลคูณของ $\mathbf u$ หน้าถัดไปจะใช้ทิศนี้แยก alpha

ตรวจเองใน 10 วินาที: $\mathbf u$ มีสี่ตัวแต่ต้องทำให้สามสมการเป็นศูนย์ จึงเหลืออิสระแค่หนึ่งมิติ ตรงกับ $n-m=4-3=1$ ที่เห็นตอนอ่านสมการเป็นผลรวมของคอลัมน์

ความผิดที่ทำให้อ่านพอร์ตผิด

คิดว่า dollar-neutral คือไม่มีความเสี่ยงจาก factor: พอร์ตในโจทย์มี NMV ศูนย์และ exposure ต่อ market ศูนย์ แต่มี exposure ต่อ momentum \$13.8 ล้าน บน GMV \$14 ล้าน คือ 98.6% ของขนาดพอร์ตเป็นเดิมพันเดียว คนเลือกหุ้นทีละตัวมักสะสม exposure แบบนี้ เพราะเหตุผลที่ใช้เลือกหุ้น เช่นราคาวิ่งดี มักเป็น style factor อยู่แล้ว

บวกความผันผวนของสองก้อนตรง ๆ: ได้ \$207,286 ต่อวัน สูงกว่าค่าจริง \$166,319 อยู่ 24.6% ความผิดนี้ทำให้วงเงินความเสี่ยงถูกใช้ไม่เต็ม และทำให้ส่วนแบ่งความเสี่ยงของแต่ละก้อนผิดทั้งหมด

ใช้ loading ที่ประทับวันผิด: ผู้ให้บริการข้อมูลส่วนใหญ่ประทับวันที่ $t$ ให้ข้อมูลที่รู้ตอนจบช่วงวัน $t-1$ ถึง $t$ loading ที่ใช้อธิบายผลตอบแทนของวัน $t$ ต้องเป็นของที่รู้ก่อนวัน $t$ เริ่ม ถ้าเลื่อนผิดหนึ่งวัน ผลตอบแทนของวันนั้นจะรั่วเข้าไปใน loading แล้ว model ดูเหมือนอธิบายผลตอบแทนได้ดีเกินจริง ตรวจเรื่องนี้ทุกครั้งที่ใช้ข้อมูลเชิงพาณิชย์

ใช้ทำอะไรบนโต๊ะจริง

factor model เป็นภาษากลางของโต๊ะหุ้น risk manager ใช้มันพยากรณ์และแบ่งความเสี่ยง ผู้จัดการพอร์ตใช้มันสร้างพอร์ต และหลังจบงวดใช้แยกฝีมือออกจากโชค นักวิจัยใช้มันแยก alpha ของจริงออกจากเดิมพัน factor รายงานตอนเช้าคือ vector $\mathbf b$ ทั้ง 60 ถึง 100 ตัวพร้อมเพดานของแต่ละตัว เลข 13.8 ของพอร์ตในโจทย์จะถูกจับได้ในเช้าวันแรกในระบบแบบนี้ แต่รอดสายตาได้ทั้งเดือนในระบบที่ดูแค่ NMV กับ GMV

model ในตลาดมีสามแบบตามสิ่งที่รู้และสิ่งที่ต้องประมาณ แบบแรกใช้คุณสมบัติบริษัทเป็น loading เช่นกลุ่มอุตสาหกรรมและ momentum แล้วประมาณ factor return ทุกวันด้วย regression ข้ามหุ้น แบบที่สองรู้แค่ผลตอบแทน ต้องประมาณทั้ง loading และ factor return จากข้อมูล เช่นด้วย PCA แบบที่สามใช้ตัวแปรเศรษฐกิจเป็น factor return แล้วประมาณ loading ด้วย regression ตามเวลาแบบ multi-factor model หน้านี้สมมติว่ารู้ทั้ง $\mathbf B$ และ $\mathbf f$ แล้ว

โจทย์ตรวจความเข้าใจ

1. วันถัดมา factor return คือ market −1.00% momentum +0.40% tech −0.20% และส่วนเฉพาะตัวคือ +0.10%, +0.30%, −0.20%, +0.05% พอร์ตเดิม กำไรขาดทุนแยกเป็นอะไรบ้าง

เฉลย

factor PnL $=0(-1.00)+13.8(0.40)+1(-0.20)=5.32$ หรือ +\$53,200 idiosyncratic PnL $=3(0.10)-2(0.30)+4(-0.20)-5(0.05)=0.30-0.60-0.80-0.25=-1.35$ หรือ −\$13,500 รวม +\$39,700 ตรวจตรง ๆ ผลตอบแทนหุ้นคือ −0.62%, −1.06%, −0.96%, −1.51% และ $3(-0.62)-2(-1.06)+4(-0.96)-5(-1.51)=3.97$ ตลาดลง 1% แต่พอร์ตได้เงิน เพราะเดิมพัน momentum พลิกมาเข้าข้าง และวันนี้การเลือกหุ้นเสียเงิน ตรงข้ามกับเมื่อวานทุกอย่าง

2. ถ้าอยากให้ exposure ต่อ momentum เป็นศูนย์โดยปรับเฉพาะตำแหน่งของ C ต้องถือ C เท่าไร แล้ว exposure ต่อ market จะเป็นเท่าไร

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด

รันใน Node.js ได้โดยไม่ต้องติดตั้งอะไร โค้ดคำนวณผลตอบแทนหุ้นสี่ตัว exposure การแยกกำไรขาดทุนและความเสี่ยงของพอร์ต พอร์ตที่เป็นกลางต่อทุก factor จำนวนตัวเลขที่ต้องประมาณ และโจทย์ท้ายหน้า

const {sqrt, abs} = Math;
function checkMatrix(A, name) {
  if (!Array.isArray(A) || A.length === 0 || !A.every(row => Array.isArray(row) && row.length === A[0].length && row.every(Number.isFinite))) {
    throw new TypeError(name + ' must be a non-empty rectangular matrix of finite numbers');
  }
  return [A.length, A[0].length];
}
function checkVector(x, n, name) {
  if (!Array.isArray(x) || x.length !== n || !x.every(Number.isFinite)) throw new TypeError(name + ' must hold ' + n + ' finite numbers');
  return x;
}
const dot = (a, b) => a.reduce((s, v, i) => s + v * b[i], 0);
const matVec = (A, x) => A.map(row => dot(row, x));
const transpose = A => A[0].map((_, j) => A.map(row => row[j]));
const UNIT = 1e4; // one million dollars times 1% is 10,000 dollars
// One day of r = B f + eps (alpha = 0 on this page).
function oneDay(B, f, eps) {
  const [n, m] = checkMatrix(B, 'Loadings B');
  checkVector(f, m, 'Factor returns');
  checkVector(eps, n, 'Idiosyncratic returns');
  const factorPart = matVec(B, f);
  return {factorPart, r: factorPart.map((v, i) => v + eps[i])};
}
// Reading 3: the book collapses to its exposures b = B'w; PnL splits into b'f and w'eps.
function pnlSplit(B, w, f, eps) {
  const [n] = checkMatrix(B, 'Loadings B');
  checkVector(w, n, 'Positions');
  const b = matVec(transpose(B), w), {r} = oneDay(B, f, eps);
  return {b, nmv: w.reduce((s, x) => s + x, 0), gmv: w.reduce((s, x) => s + abs(x), 0),
    perFactor: b.map((x, j) => x * f[j] * UNIT), perStock: w.map((x, i) => x * eps[i] * UNIT),
    factor: dot(b, f) * UNIT, idio: dot(w, eps) * UNIT, direct: dot(w, r) * UNIT};
}
function covarianceFromVols(vols, corr) {
  const [k, k2] = checkMatrix(corr, 'Correlation');
  if (k !== k2 || !Array.isArray(vols) || vols.length !== k) throw new RangeError('Need one volatility per row of a square correlation matrix');
  if (!vols.every(v => Number.isFinite(v) && v > 0)) throw new RangeError('Volatilities must be positive');
  for (let i = 0; i < k; i++) {
    if (corr[i][i] !== 1) throw new RangeError('Correlation diagonal must be 1');
    for (let j = 0; j < i; j++) if (corr[i][j] !== corr[j][i] || abs(corr[i][j]) > 1) throw new RangeError('Correlation must be symmetric with entries between -1 and 1');
  }
  return corr.map((row, i) => row.map((c, j) => c * vols[i] * vols[j]));
}
// Risk splits the same way: b' Omega_f b + w' Omega_eps w (diagonal Omega_eps).
function riskSplit(B, w, Of, idioVols) {
  const [n] = checkMatrix(B, 'Loadings B');
  checkVector(w, n, 'Positions');
  checkVector(idioVols, n, 'Idiosyncratic volatilities');
  if (!idioVols.every(s => s > 0)) throw new RangeError('Every idiosyncratic volatility must be positive');
  const b = matVec(transpose(B), w);
  const factorVar = dot(b, matVec(Of, b)), idioVar = w.reduce((s, x, i) => s + x * x * idioVols[i] ** 2, 0);
  return {factorVar, idioVar, factorUSD: sqrt(factorVar) * UNIT, idioUSD: sqrt(idioVar) * UNIT,
    totalUSD: sqrt(factorVar + idioVar) * UNIT, idioShare: idioVar / (factorVar + idioVar)};
}
function counts(n, m, T) {
  if (![n, m, T].every(Number.isInteger) || n < 1 || m < 1 || T < 2) throw new RangeError('Need whole numbers n, m >= 1 and T >= 2');
  const direct = n * (n + 1) / 2, factor = m * (m + 1) / 2 + n;
  return {direct, factor, ratio: direct / factor, zeroDirections: Math.max(0, n - (T - 1))};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • $\mathbf r_t=\boldsymbol\alpha+\mathbf B\mathbf f_t+\boldsymbol\epsilon_t$ แยกผลตอบแทนเป็นส่วนคงที่ ส่วนแรงร่วม และส่วนเฉพาะตัว โดยสมมติว่าส่วนเฉพาะตัวไม่เกี่ยวกับ factor และไม่สัมพันธ์กันข้ามหุ้น
  • อ่านได้สามทาง เป็นกราฟที่ factor ไหลลงหุ้นตามเส้น loading เป็นผลรวมของคอลัมน์ที่ขังส่วนของ factor ไว้ใน $m$ มิติ และเป็นผลคูณจุดที่ย่อทั้งพอร์ตเหลือ exposure $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$
  • พอร์ตในโจทย์ขาดทุน \$13,000 เพราะ factor −\$66,000 ทั้งที่เลือกหุ้นได้ +\$53,000 dollar-neutral ไม่ได้แปลว่าไม่มีเดิมพัน momentum
  • ความเสี่ยงแยกเป็น $\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b+\mathbf w^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf w$ และบวกกันแบบ variance: \$48,063 กับ \$159,223 รวมได้ \$166,319 ไม่ใช่ \$207,286
  • หุ้น 500 ตัวกับ 252 วัน covariance จากข้อมูลมีทิศความเสี่ยงศูนย์อย่างน้อย 249 ทิศ factor model ต้องประมาณ 2,330 ตัวแทน 125,250 ตัว และให้ความเสี่ยงเป็นบวกเสมอ

หน้าถัดไป alpha spanned และ alpha orthogonal ถามว่า $\boldsymbol\alpha$ อยู่ตรงไหนของภาพนี้ ส่วนที่อยู่ใน range ของ $\mathbf B$ กับส่วนที่ตั้งฉากกับมัน อย่างหลังคือทิศแบบ $\mathbf u$ ในขั้นสุดท้าย และมีค่ามากกว่าอย่างแรกหลายเท่าเมื่อหุ้นมีหลายร้อยตัว
