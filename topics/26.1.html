26.1 The Factor Model Equation and Three Ways to Read It

ผลตอบแทนของหุ้นทุกตัวคือแรงร่วมไม่กี่ตัวคูณ loading บวกส่วนที่เป็นเรื่องของหุ้นตัวนั้นเอง และสมการเดียวนี้แยกทั้งกำไรขาดทุนและความเสี่ยงของพอร์ตออกเป็นสองก้อน

ผู้จัดการกองทุนคนหนึ่งเลือกหุ้นเอง เขาซื้อหุ้นที่คิดว่าราคาจะขึ้น และ short หุ้นที่คิดว่าราคาจะลง (short คือยืมหุ้นมาขายก่อน แล้วซื้อคืนทีหลัง จึงได้กำไรเมื่อราคาลง) พอร์ตที่มีทั้งสองฝั่งแบบนี้เรียกว่าพอร์ต long–short เขาถือหุ้นสี่ตัว (ตัวเลขสมมติ):

  • หุ้น A ซื้อ \$3 ล้าน
  • หุ้น B short \$2 ล้าน เขียนเป็น −\$2 ล้าน เพราะเงินฝั่งนี้ได้กำไรเมื่อราคาลง
  • หุ้น C ซื้อ \$4 ล้าน
  • หุ้น D short \$5 ล้าน เขียนเป็น −\$5 ล้าน

ฝั่งซื้อรวม $3+4=\$7$ ล้าน ฝั่ง short รวม $2+5=\$7$ ล้าน เท่ากันพอดี ผู้จัดการจึงเชื่อว่าพอร์ต “เป็นกลางต่อตลาด” คือถ้าหุ้นทั้งตลาดขึ้นหรือลงพร้อมกัน กำไรฝั่งหนึ่งจะหักล้างขาดทุนอีกฝั่งหมด

วันนี้ตลาดหุ้นโดยรวมขึ้น 0.80% แต่พอร์ตขาดทุน \$13,000 (หน้านี้จะคำนวณตัวเลขนี้ให้ดูทีละขั้น) ผู้จัดการสรุปว่า “พอร์ตเป็นกลางต่อตลาดแล้ว ขาดทุนนี้จึงมาจากการเลือกหุ้นพลาด” ข้อสรุปนี้ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ผิดทั้งสองครึ่ง หน้านี้จะคำนวณตัวเลขข้างล่างให้ดูทีละขั้น ผลสรุปคือ

  • การเลือกหุ้นไม่ได้พลาด ส่วนที่มาจากข่าวของหุ้นแต่ละตัวทำเงินได้ +\$53,000
  • ที่ขาดทุนคือแรงร่วมที่ลากหุ้นหลายตัวไปพร้อมกัน แรงแบบนี้เรียกว่า factor และวันนี้มันทำให้พอร์ตเสีย \$66,000 รวมสองส่วนได้ $-66{,}000+53{,}000=-\$13{,}000$
  • พอร์ตไม่ได้เดิมพันกับตลาดจริง แต่แอบเดิมพันกับ momentum (แรงที่ทำให้หุ้นที่ราคาวิ่งแรงมาทั้งปียังวิ่งต่อ) เป็นเงิน \$13.8 ล้าน จากเงินทั้งพอร์ต $7+7=\$14$ ล้าน วันนี้ momentum ลง 0.50% พอร์ตจึงเสีย $13{,}800{,}000\times(-0.0050)=-\$69{,}000$ ส่วนหุ้นกลุ่ม tech ให้คืนมา \$3,000 รวมเป็น $-69{,}000+3{,}000=-\$66{,}000$

บทเรียนคือ เงินสองฝั่งที่เท่ากันไม่ได้แปลว่าไม่มีเดิมพันซ่อนอยู่

ภาพรวมก่อนลงสูตร

หุ้นไม่ได้ขยับแยกกัน วันที่ตลาดขึ้น หุ้นส่วนใหญ่ก็ขึ้นตาม วันที่นักลงทุนเทขายหุ้นที่ราคาวิ่งแรงมาทั้งปี หุ้นกลุ่มนั้นก็ลงพร้อมกัน factor model คือการเขียนความจริงข้อนี้เป็นสมการ

สมการนี้มองผลตอบแทนของหุ้นหนึ่งตัวในหนึ่งวัน (ราคาเปลี่ยนไปกี่เปอร์เซ็นต์) ว่ามีสองชั้น

  • ชั้นแรกมาจากแรงร่วมไม่กี่ตัว เรียกว่า factor เช่น “ตลาดทั้งตลาด” หรือ “หุ้นที่วิ่งแรงมาทั้งปี” ในวันหนึ่ง หุ้นทุกตัวเห็นแรงเดียวกัน แต่แต่ละตัวรับแรงมากหรือน้อยต่างกัน ตัวคูณที่บอกว่ารับมากแค่ไหนเรียกว่า loading
  • ชั้นที่สองเป็นเรื่องของหุ้นตัวนั้นล้วน ๆ เช่นบริษัทประกาศกำไรดีกว่าที่คาด ชั้นนี้เรียกว่าส่วนเฉพาะตัว

ทำไมต้องมองแบบนี้? เพราะทางอื่นแย่กว่า ถ้าทำเหมือนหุ้นแต่ละตัวขยับอิสระ เราจะมองไม่เห็นการขยับพร้อมกัน ซึ่งเป็นความเสี่ยงก้อนใหญ่ที่สุดของพอร์ต แต่ถ้าจะวัดการขยับพร้อมกันของหุ้นทุกคู่ตรง ๆ (ตัวเลขนี้เรียกว่า covariance) ข้อมูลที่มีก็ไม่พอ หน้านี้จะนับให้ดูว่าขาดไปเท่าไร factor model แก้ปัญหานี้ด้วยการบังคับว่า การขยับพร้อมกันทุกอย่างต้องมาจากแรงร่วมไม่กี่ตัว ที่เหลือเป็นของหุ้นแต่ละตัว

หน้านี้เริ่มจากเขียนสมการพร้อมข้อสมมติ แล้วคำนวณหุ้นสี่ตัวในวันเดียวด้วยมือ จากนั้นอ่านสมการเดิมสามทาง

  • ทีละหุ้น: แรงจาก factor ไหลลงหุ้นตามเส้นเชื่อม
  • ทุกหุ้นพร้อมกัน: ผลรวมของคอลัมน์ใน matrix
  • ทั้งพอร์ต: ย่อพอร์ตให้เหลือตัวเลขไม่กี่ตัว

ทางที่สามตอบคำถามข้างบน เพราะมันแยกกำไรขาดทุนและความเสี่ยงของพอร์ตออกเป็นส่วนของ factor กับส่วนเฉพาะตัว รูปข้างล่างคือตัวเลขของหุ้นสี่ตัวในวันนี้ ที่ทั้งหน้าจะใช้

ศัพท์ที่ใช้ในหัวข้อนี้
Long และ short
long คือซื้อหุ้นถือไว้ ได้กำไรเมื่อราคาขึ้น short คือยืมหุ้นมาขายก่อนแล้วซื้อคืนทีหลัง ได้กำไรเมื่อราคาลง หน้านี้เขียนเงินฝั่ง short เป็นเลขติดลบ
PnL
ย่อจาก profit and loss คือกำไรหรือขาดทุนเป็นดอลลาร์ของพอร์ตในช่วงหนึ่ง เช่นหนึ่งวัน
Factor return
ผลตอบแทนของแรงร่วมหนึ่งตัวในหนึ่งวัน เช่นวันนี้ factor market ให้ +0.80% หุ้นทุกตัวเห็นตัวเลขเดียวกันนี้ แต่รับมากหรือน้อยต่างกันตาม loading ของตัวเอง
Momentum
factor ที่จับแนวโน้มว่าหุ้นที่ราคาวิ่งแรงมาราวหนึ่งปียังวิ่งต่อ หุ้นที่วิ่งดีกว่าเพื่อนมี loading บวก หุ้นที่วิ่งแย่กว่าเพื่อนมี loading ลบ
Loading และ loadings matrix
loading คือตัวคูณที่บอกว่าหุ้นตัวหนึ่งรับแรงจาก factor หนึ่งมากแค่ไหน เอามาวางเป็นตาราง $\mathbf B$ ขนาด $n\times m$ แถวละหุ้น คอลัมน์ละ factor ใน model ที่สร้าง loading จากข้อมูลบริษัท (เช่นอยู่อุตสาหกรรมไหน ราคาวิ่งมาแรงแค่ไหน) loading รู้ตั้งแต่ก่อนวันนั้นเริ่ม จึงไม่ต้องประมาณ
z-score
วิธีทำให้ตัวเลขของหุ้นทุกตัวเทียบกันได้ ถ้า $x_i$ คือค่าของหุ้น $i$ (เช่นผลตอบแทนย้อนหลังหนึ่งปี) $\bar x$ คือค่าเฉลี่ยของทุกหุ้น และ $s$ คือ SD ของทุกหุ้น (SD หรือ standard deviation วัดว่าตัวเลขกระจายห่างจากค่าเฉลี่ยแค่ไหน) z-score คือ $z_i=(x_i-\bar x)/s$ ตัวเลขที่ได้เฉลี่ยเป็นศูนย์ บวกคือสูงกว่าเพื่อน ลบคือต่ำกว่าเพื่อน และ $z_i=1.2$ แปลว่าสูงกว่าค่าเฉลี่ย 1.2 SD
Idiosyncratic return
ส่วนของผลตอบแทนที่เหลือหลังหักส่วนที่ factor ให้ เป็นเรื่องของหุ้นตัวนั้นล้วน ๆ บางคนเรียก residual หรือ specific return ใช้วัดว่าการเลือกหุ้นทำเงินได้เท่าไร
Factor exposure
เงินที่ทั้งพอร์ตเดิมพันกับ factor แต่ละตัว คำนวณจาก loading ของแต่ละหุ้นคูณเงินที่ถือ แล้วรวมทุกหุ้น เขียนเป็น $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$ หน่วยเป็นดอลลาร์ พอร์ตหุ้นหลายพันตัวจึงย่อเหลือตัวเลขเท่าจำนวน factor
NMV และ GMV
NMV (net market value) คือเงินฝั่งซื้อลบเงินฝั่ง short GMV (gross market value) คือผลรวมขนาดของทุกตำแหน่งโดยไม่สนเครื่องหมาย พอร์ตในหน้านี้มี NMV $=3-2+4-5=0$ และ GMV $=3+2+4+5=\$14$ ล้าน พอร์ตที่ NMV เป็นศูนย์เรียกว่า dollar-neutral ซึ่งไม่ได้แปลว่าไม่มี exposure ต่อ factor
Strict และ approximate factor model
strict คือ model ที่สมมติว่าส่วนเฉพาะตัวของหุ้นต่างตัวไม่สัมพันธ์กันเลย covariance ของส่วนนี้จึงเป็น diagonal (มีตัวเลขแค่บนแนวทแยง) ถ้ายอมให้บางคู่สัมพันธ์กันได้เล็กน้อย เรียกว่า approximate

ขั้นที่ 1 — สมการ และสิ่งที่มันสมมติ

ก่อนจะคำนวณอะไร ต้องเปลี่ยนความคิด “แรงร่วม บวก เรื่องเฉพาะตัว” ให้เป็นสมการก่อน ตัวที่เราอธิบายคือผลตอบแทนส่วนเกิน หมายถึงผลตอบแทนของหุ้นลบดอกเบี้ยที่ได้จากเงินฝากที่ไม่มีความเสี่ยงในวันเดียวกัน เราหักดอกเบี้ยออกเพราะส่วนนั้นได้ฟรีโดยไม่ต้องถือหุ้น

เอาผลตอบแทนส่วนเกินของหุ้นทั้ง $n$ ตัวในวัน $t$ มาเรียงเป็น vector $\mathbf r_t$ แล้วเขียนมันเป็นสามก้อน

  • $\boldsymbol\alpha$ ก้อนคงที่ เป็นผลตอบแทนเฉลี่ยที่หุ้นได้เกินจากส่วนที่ factor ให้
  • $\mathbf B\mathbf f_t$ ก้อนที่มาจากแรงร่วม: $\mathbf f_t$ คือ factor return ของวันนั้น $m$ ตัว และ $\mathbf B$ คือตาราง loading
  • $\boldsymbol\epsilon_t$ ก้อนเฉพาะตัว หุ้นละหนึ่งตัวเลข

ใต้สมการมีข้อสมมติอีกสามข้อ ข้อสมมติเหล่านี้ไม่ใช่สิ่งที่พิสูจน์ได้ เราตั้งมันขึ้นเพราะมันทำให้สมการใช้งานได้ $\mathbb E[\cdot]$ คือค่าคาดหวัง (ค่าเฉลี่ยที่ได้ถ้าวันแบบนี้เกิดซ้ำหลายครั้ง) และ $\operatorname{cov}(\cdot)$ คือ covariance

\[ \begin{aligned} \mathbf r_t&=\boldsymbol\alpha+\mathbf B\mathbf f_t+\boldsymbol\epsilon_t,\\ \mathbb E[\boldsymbol\epsilon_t]&=\mathbf 0,\\ \operatorname{cov}(\mathbf f_t,\boldsymbol\epsilon_t)&=\mathbf 0,\\ \operatorname{cov}(\boldsymbol\epsilon_t)&=\boldsymbol\Omega_\epsilon\\ &=\operatorname{diag}(\sigma_1^2,\dots,\sigma_n^2). \end{aligned} \]

หัวใจของสมการอยู่ที่ขนาดของ $\mathbf B$ มันมี $n$ แถว (หุ้น) และ $m$ คอลัมน์ (factor) โดย $m$ เล็กกว่า $n$ มาก model ทั่วไปมีหุ้นราว 500 ตัวกับ factor ราว 60 ตัว แปลว่าหุ้นหลายร้อยตัวถูกขับด้วยตัวแปรสุ่มเพียงไม่กี่สิบตัวใน $\mathbf f_t$ ที่เหลือใน $\boldsymbol\epsilon_t$ เป็นเรื่องของหุ้นแต่ละตัว หน้านี้ตั้ง $\boldsymbol\alpha=\mathbf 0$ เพื่อให้เห็นโครงก่อน หน้าถัดไปเรื่อง alpha spanned และ alpha orthogonal จะกลับมาดูว่า $\boldsymbol\alpha$ ซ่อนอยู่ตรงไหน

ข้อสมมติสามข้อพูดเป็นภาษาคนได้ว่า

  • ส่วนเฉพาะตัวเฉลี่ยแล้วเป็นศูนย์ คือข่าวดีกับข่าวร้ายหักล้างกันในระยะยาว
  • ส่วนเฉพาะตัวไม่ขยับตาม factor
  • ส่วนเฉพาะตัวของหุ้นต่างตัวไม่ขยับตามกัน จึงเขียน covariance ของมันเป็น $\operatorname{diag}(\sigma_1^2,\dots,\sigma_n^2)$ คือ matrix ที่มีตัวเลขเฉพาะบนแนวทแยง ช่องอื่นเป็นศูนย์หมด

เรายังสมมติเพิ่มอีกข้อว่า $\mathbf f_t$ กับ $\boldsymbol\epsilon_t$ มีการแจกแจงเหมือนเดิมทุกวัน หรือเปลี่ยนช้ามาก

ข้อที่หนักที่สุดคือข้อสุดท้าย เพราะมันบังคับว่าการขยับพร้อมกันทุกอย่างต้องผ่าน factor ถ้า model ขาด factor ที่ควรมี การขยับพร้อมกันส่วนนั้นไม่หายไปไหน มันจะไปโผล่เป็น correlation ระหว่างส่วนเฉพาะตัวของหุ้นต่างตัว ร่องรอยนี้คือสิ่งที่ใช้ตรวจตอนประมาณ covariance ของส่วนเฉพาะตัว

ขั้นที่ 2 — หุ้นสี่ตัว หนึ่งวัน

สมการยังเป็นสัญลักษณ์อยู่ ลองใส่ตัวเลขจริงดูสักวันหนึ่ง เพื่อให้เห็นว่าผลตอบแทนของหุ้นแต่ละตัวประกอบขึ้นจากอะไร

โจทย์ให้อะไรมาบ้าง: หุ้นสี่ตัวของพอร์ตตอนต้นหน้า คือ A, B, C, D กับ factor สามตัว ตัวเลขทั้งหมดสมมติ และใช้ต่อทั้งบท

  • market คือแรงของตลาดทั้งตลาด หุ้นทุกตัวรับแรงนี้เต็ม ๆ จึงมี loading 1 วันนี้ factor return $f_{\rm mkt}=+0.80\%$
  • momentum คือแรงที่หุ้นซึ่งราคาวิ่งแรงมาทั้งปียังวิ่งต่อ loading ของมันคือ z-score ของผลตอบแทนย้อนหลังราวหนึ่งปี (บวกคือราคาวิ่งดีกว่าเพื่อน ลบคือแย่กว่าเพื่อน) ได้ A $+1.2$, B $-0.4$, C $+0.6$, D $-1.4$ วันนี้ $f_{\rm mom}=-0.50\%$
  • tech คือแรงที่ลากหุ้นกลุ่มเทคโนโลยีไปด้วยกัน loading เป็น 1 ถ้าหุ้นอยู่ในกลุ่มนี้ (A กับ B) และเป็น 0 ถ้าไม่ใช่ (C กับ D) วันนี้ $f_{\rm tech}=+0.30\%$
  • ส่วนเฉพาะตัววันนี้ (ข่าวของหุ้นแต่ละตัว): A $+0.40\%$, B $-0.25\%$, C $+0.15\%$, D $-0.60\%$

เอา loading มาวางเป็น matrix $\mathbf B$ แถวละหุ้น คอลัมน์ละ factor เรียงเป็น market, momentum, tech จากนั้นใช้สมการในขั้นที่แล้วกับหุ้นทีละตัว ผลตอบแทนของหุ้น $i$ คือ loading แต่ละช่องในแถว $i$ คูณ factor return ของคอลัมน์นั้น บวกกัน แล้วบวกส่วนเฉพาะตัว

\[ r_i=B_{i1}f_{\rm mkt}+B_{i2}f_{\rm mom}+B_{i3}f_{\rm tech}+\epsilon_i \]
\[ \begin{aligned} \mathbf B&=\begin{bmatrix}1&1.2&1\\1&-0.4&1\\1&0.6&0\\1&-1.4&0\end{bmatrix},\\ r_A&=0.80+1.2(-0.50)\\ &\quad+0.30+0.40=0.90\%,\\ r_B&=0.80-0.4(-0.50)\\ &\quad+0.30-0.25=1.05\%,\\ r_C&=0.80+0.6(-0.50)\\ &\quad+0.15=0.65\%,\\ r_D&=0.80-1.4(-0.50)\\ &\quad-0.60=0.90\%. \end{aligned} \]

คำตอบ: ผลตอบแทนวันนี้ของ A, B, C, D คือ 0.90%, 1.05%, 0.65% และ 0.90% ให้ดู B กับ D ทั้งสองตัวมี loading momentum ติดลบ วันที่ momentum ร่วง ลบคูณลบจึงได้บวก: B ได้ $-0.4\times(-0.50)=+0.20\%$ และ D ได้ $-1.4\times(-0.50)=+0.70\%$ แต่หลังจากนั้นสองตัวแยกทางกัน B อยู่ในกลุ่ม tech ที่ขึ้น 0.30% ส่วน D โดนข่าวร้ายของตัวเอง −0.60% ผลตอบแทนที่เห็นจึงเป็นผลรวมของหลายเรื่องเสมอ และสมการนี้แยกแต่ละเรื่องออกมาให้ดูได้ ตรงกับรูปแท่งสองชั้นด้านบน

ตรวจเองใน 10 วินาที: A กับ D ได้ 0.90% เท่ากันทั้งที่ที่มาต่างกันหมด ส่วนที่ factor ให้ A คือ $0.80-0.60+0.30=0.50$ แล้วบวกข่าวของตัวเอง $0.50+0.40=0.90$ ส่วนที่ factor ให้ D คือ $0.80+0.70=1.50$ แล้วลบข่าวของตัวเอง $1.50-0.60=0.90$

ขั้นที่ 3 — อ่านแบบที่หนึ่ง: กราฟของเส้นเชื่อม

สมการเดียวกันอ่านได้สามทาง และแต่ละทางตอบคำถามคนละแบบ ทางแรกมองทีละหุ้น คำถามคือ ถ้ารู้ factor return ของวันนี้แล้ว หุ้น $i$ ควรได้ผลตอบแทนเท่าไร เขียนเป็น $\mathbb E[\,\cdot\mid\mathbf f]$ คือค่าคาดหวังเมื่อรู้ $\mathbf f$ แล้ว ส่วนเฉพาะตัวมีค่าคาดหวังเป็นศูนย์จึงหายไป เหลือผลคูณจุดของแถว $i$ ของ $\mathbf B$ (เขียนว่า $\mathbf B_{i\cdot}$) กับ $\mathbf f$

\[ \begin{aligned} \mathbb E[r_i-\alpha_i\mid\mathbf f]&=\sum_{j=1}^{m}B_{ij}f_j\\ &=\langle\mathbf B_{i\cdot},\ \mathbf f\rangle,\\ \mathbf B_{A\cdot}&=(1,\ 1.2,\ 1),\\ \langle\mathbf B_{A\cdot},\ \mathbf f\rangle&=0.80-0.60+0.30\\ &=0.50\%. \end{aligned} \]

ภาพที่ควรมีในหัวคือกราฟข้างล่าง วงกลมข้างบนคือ factor สี่เหลี่ยมข้างล่างคือหุ้น เส้นเชื่อมคือ loading ผลตอบแทนที่คาดของหุ้นหนึ่งตัวได้จากการเอา factor return แต่ละตัวคูณ loading บนเส้นที่ชี้เข้าหาหุ้นนั้น แล้วรวมกัน เช่น A ได้ $1(0.80)+1.2(-0.50)+1(0.30)=0.50\%$

ภาพนี้ยังบอกด้วยว่า $\mathbf B$ ของจริงมีช่องที่เป็นศูนย์เยอะ model ที่ครอบคลุมหุ้นทั้งภูมิภาค เช่นทั้งยุโรป มีหุ้นได้ราวหมื่นตัวกับ factor ราวร้อยตัว แต่หุ้นหนึ่งตัวต่อเส้นกับ market ตัวเดียว industry (อุตสาหกรรม) ตัวเดียว country (ประเทศ) ตัวเดียว และ style factor อีกสิบกว่าตัว จากร้อยเส้นที่ต่อได้ หุ้นหนึ่งตัวจึงต่อจริงแค่ราวยี่สิบเส้น ช่องส่วนใหญ่ของ $\mathbf B$ เป็นศูนย์ และกราฟจริงมีเส้นน้อยกว่าที่คิด

ทางนี้ตอบคำถามระดับหุ้น เช่นข่าวดีของ A วันนี้ใหญ่แค่ไหน A ขึ้น 0.90% แต่ 0.50% ในนั้นเป็นสิ่งที่หุ้นตัวไหนก็ได้ ถ้ามี loading แบบเดียวกับ A ดังนั้นส่วนที่เป็นของ A เองจริง ๆ มีแค่ $0.90-0.50=0.40\%$

ขั้นที่ 4 — อ่านแบบที่สอง: ผลรวมของคอลัมน์

ทางแรกต้องคำนวณทีละหุ้น ถ้ามีหุ้น 500 ตัวก็ต้องทำ 500 รอบ ทางที่สองมองทุกหุ้นพร้อมกัน โดยจัดการคูณ matrix $\mathbf B\mathbf f$ ตามคอลัมน์แทนตามแถว ให้ $\mathbf B_{\cdot j}$ คือคอลัมน์ที่ $j$ ของ $\mathbf B$ (loading ของทุกหุ้นต่อ factor $j$) ส่วนที่ factor ให้หุ้นทุกตัวคือคอลัมน์เหล่านี้คูณด้วย factor return ของวันนั้น แล้วบวกกัน

\[ \begin{aligned} \mathbf B\mathbf f&=\sum_{j=1}^{m}\mathbf B_{\cdot j}\,f_j\\ &=0.80\begin{bmatrix}1\\1\\1\\1\end{bmatrix}-0.50\begin{bmatrix}1.2\\-0.4\\0.6\\-1.4\end{bmatrix}\\ &\quad+0.30\begin{bmatrix}1\\1\\0\\0\end{bmatrix}=\begin{bmatrix}0.50\\1.30\\0.50\\1.50\end{bmatrix}. \end{aligned} \]

แต่ละคอลัมน์ทำงานแยกกัน คอลัมน์ market ยกทุกหุ้นขึ้น 0.80% เท่ากัน คอลัมน์ momentum ถูกคูณด้วย factor return ที่ติดลบ หุ้นที่ loading momentum เป็นบวกอย่าง A จึงเสีย $1.2\times(-0.50)=-0.60\%$ ส่วน D ที่ loading ติดลบกลับได้ $-1.4\times(-0.50)=+0.70\%$ คอลัมน์ tech ยก A กับ B ขึ้น 0.30% ผลรวมคือ (0.50, 1.30, 0.50, 1.50) ซึ่งคือแท่งน้ำเงินของรูปแรก

สิ่งที่ทางนี้ให้เห็นคือจำนวนมิติ ผลตอบแทนของหุ้นสี่ตัวเป็น vector ที่มีสี่ช่อง จึงเป็นจุดหนึ่งในที่ว่าง 4 มิติ แต่ส่วนที่ factor ให้ต้องเป็นคอลัมน์ของ $\mathbf B$ คูณตัวเลขแล้วบวกกันเสมอ ผลลัพธ์ทุกแบบที่ได้จากการคูณแล้วบวกแบบนี้เรียกรวมว่าrange ของ $\mathbf B$ มันมีแค่ 3 มิติ เท่ากับจำนวนคอลัมน์

ดังนั้นส่วนของ factor ถูกขังอยู่ใน 3 มิติ และเหลือ $4-3=1$ มิติที่มีแต่ส่วนเฉพาะตัว ถ้ามีหุ้น 500 ตัวกับ factor 60 ตัว ส่วนของ factor อยู่ใน 60 มิติ และเหลือ $500-60=440$ มิติที่เป็นของส่วนเฉพาะตัวล้วน ๆ หน้าถัดไปจะชี้ว่า alpha ชนิดที่มีค่าที่สุดอยู่ในที่ว่างนี้

ขั้นที่ 5 — อ่านแบบที่สาม: ทั้งพอร์ต

ผู้จัดการพอร์ตไม่ได้สนผลตอบแทนของหุ้นทีละตัว เขาสนว่าทั้งพอร์ตได้หรือเสียกี่ดอลลาร์ ทางที่สามจึงเป็นทางที่ใช้ทุกวัน

ให้ $\mathbf w$ คือเงินที่ถือแต่ละหุ้น หน่วยเป็น \$ ล้าน ติดลบคือ short พอร์ตในโจทย์มี $\mathbf w=(3,\ -2,\ 4,\ -5)$ กำไรขาดทุนของพอร์ตคือเงินที่ถือคูณผลตอบแทนของแต่ละหุ้น แล้วรวมทุกหุ้น เขียนสั้น ๆ ได้ว่า $\mathbf w^{\mathsf T}\mathbf r=\sum_iw_ir_i$ ต่อไปเราแทน $\mathbf r$ ด้วยสมการของ factor model แล้วจับกลุ่มใหม่ เพื่อดูว่าเงินที่ได้หรือเสียมาจาก factor เท่าไร และจากหุ้นแต่ละตัวเท่าไร

\[ \begin{aligned} \mathbf w^{\mathsf T}\mathbf r&=\mathbf w^{\mathsf T}\mathbf B\mathbf f+\mathbf w^{\mathsf T}(\boldsymbol\alpha+\boldsymbol\epsilon)\\ &=\mathbf b^{\mathsf T}\mathbf f+\mathbf w^{\mathsf T}(\boldsymbol\alpha+\boldsymbol\epsilon),\\ \mathbf b&:=\mathbf B^{\mathsf T}\mathbf w,\\ b_{\rm mkt}&=3-2+4-5=0,\\ b_{\rm mom}&=1.2(3)-0.4(-2)\\ &\quad+0.6(4)-1.4(-5)\\ &=3.6+0.8+2.4+7.0\\ &=13.8,\\ b_{\rm tech}&=1(3)+1(-2)=1. \end{aligned} \]

ท่าที่ทำให้ทุกอย่างง่ายลงคือย้ายวงเล็บ $\mathbf w^{\mathsf T}\mathbf B$ เขียนใหม่ได้เป็น $(\mathbf B^{\mathsf T}\mathbf w)^{\mathsf T}$ ตามกฎของ transpose ที่กลับลำดับผลคูณ เราตั้งชื่อ $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$ แล้วเรียกมันว่า factor exposure ช่องที่ $j$ ของ $\mathbf b$ คือ loading ต่อ factor $j$ ของแต่ละหุ้น คูณเงินที่ถือ แล้วรวมทุกหุ้น ไม่ว่าพอร์ตจะถือหุ้นกี่พันตัว $\mathbf b$ ก็ยาวแค่ $m$ ตัว

กำไรขาดทุนจึงแยกเป็นสองก้อน ก้อน $\mathbf b^{\mathsf T}\mathbf f$ เรียกว่า factor PnL คือเงินที่ได้หรือเสียจากแรงร่วม ก้อน $\mathbf w^{\mathsf T}(\boldsymbol\alpha+\boldsymbol\epsilon)$ เรียกว่า idiosyncratic PnL คือเงินที่ได้หรือเสียจากการเลือกหุ้น

exposure ต่อ market เท่ากับ NMV พอดี เพราะคอลัมน์ market เป็น 1 ทุกแถว ผลรวมจึงเป็น $\sum_i1\cdot w_i=\sum_iw_i$ พอร์ตนี้ NMV เป็นศูนย์ จึงไม่มี exposure ต่อตลาดจริงตามที่ผู้จัดการคิด แต่ exposure ต่อ momentum รวมได้ \$13.8 ล้าน เพราะหุ้นที่ซื้อ (A, C) มี loading momentum บวก และหุ้นที่ short (B, D) มี loading momentum ลบ ฝั่ง short ลบคูณลบจึงได้บวก เช่น $-0.4\times(-2)=+0.8$ และ $-1.4\times(-5)=+7.0$ ทุกตำแหน่งจึงเดิมพันทางเดียวกันว่า momentum จะขึ้น โดยที่ไม่มีใครตั้งใจ

ขั้นที่ 6 — แยกกำไรขาดทุนของวันนี้

ตอนนี้มีเครื่องมือครบแล้ว กลับไปตอบคำถามตอนต้นหน้า ว่าขาดทุน \$13,000 ของวันนี้มาจากไหน

โจทย์ให้อะไรมาบ้าง:

  • exposure ที่เพิ่งคำนวณ $\mathbf b=(0,\ 13.8,\ 1)$ หน่วย \$ ล้าน
  • factor return วันนี้ $\mathbf f=(0.80,\ -0.50,\ 0.30)$ หน่วย %
  • เงินที่ถือ $\mathbf w=(3,\ -2,\ 4,\ -5)$ หน่วย \$ ล้าน และส่วนเฉพาะตัว $\boldsymbol\epsilon=(0.40,\ -0.25,\ 0.15,\ -0.60)$ หน่วย %

เงินเป็นหน่วย \$ ล้าน และผลตอบแทนเป็นหน่วย % ผลคูณหนึ่งหน่วยจึงเท่ากับ $\$1{,}000{,}000\times0.01=\$10{,}000$ ตัวเลขที่คำนวณได้ต้องคูณ \$10,000 ก่อนจะอ่านเป็นดอลลาร์

\[ \begin{aligned} \mathbf b^{\mathsf T}\mathbf f&=0(0.80)+13.8(-0.50)\\ &\quad+1(0.30)\\ &=-6.90+0.30=-6.60,\\ \mathbf w^{\mathsf T}\boldsymbol\epsilon&=3(0.40)-2(-0.25)\\ &\quad+4(0.15)-5(-0.60)\\ &=1.20+0.50+0.60+3.00\\ &=5.30,\\ \mathbf w^{\mathsf T}\mathbf r&=-6.60+5.30=-1.30. \end{aligned} \]

คำตอบ: คูณทุกตัวด้วย \$10,000

  • factor PnL คือ $-6.60\times\$10{,}000=-\$66{,}000$ แยกเป็น market $0\times0.80=0$ คือ \$0, momentum $13.8\times(-0.50)=-6.90$ คือ −\$69,000 และ tech $1\times0.30=0.30$ คือ +\$3,000
  • idiosyncratic PnL คือ $5.30\times\$10{,}000=+\$53{,}000$ ก้อนใหญ่ที่สุดมาจากการ short D ที่โดนข่าวร้าย $-5\times(-0.60)=3.00$ คือ +\$30,000 เกินครึ่งของก้อนนี้
  • รวมทั้งพอร์ต $-1.30\times\$10{,}000=-\$13{,}000$

ผู้จัดการพอร์ตจึงผิดทั้งสองส่วน การเลือกหุ้นวันนี้ทำเงินได้ดีมาก ที่เสียคือเดิมพัน momentum ที่เขาไม่รู้ตัวว่าถืออยู่

ตรวจเองใน 10 วินาที: คูณเงินกับผลตอบแทนรวมของแต่ละหุ้นตรง ๆ ได้ $3(0.90)-2(1.05)+4(0.65)-5(0.90)=2.70-2.10+2.60-4.50=-1.30$ เท่ากัน เพราะสองทางคือผลบวกชุดเดียวกันที่แค่จัดกลุ่มต่างกัน จึงต้องตรงกันเสมอ

ขั้นที่ 7 — ความเสี่ยงก็แยกเป็นสองก้อน

กำไรขาดทุนของวันนี้เป็นเรื่องที่ผ่านไปแล้ว สิ่งที่ผู้จัดการต้องรู้ล่วงหน้าคือ พรุ่งนี้พอร์ตอาจได้หรือเสียได้มากแค่ไหน ตัวเลขที่ใช้วัดเรื่องนี้คือความเสี่ยง หมายถึง SD (standard deviation) ของกำไรขาดทุน ส่วน variance คือ SD ยกกำลังสอง

จะหาความเสี่ยงของพอร์ตได้ ต้องรู้ covariance matrix ของผลตอบแทนหุ้นทุกตัวก่อน คำถามคือ matrix นี้แยกเป็นสองก้อนเหมือนกำไรขาดทุนได้ไหม เริ่มจาก $\mathbf r=\boldsymbol\alpha+\mathbf B\mathbf f+\boldsymbol\epsilon$ ค่าคงที่ $\boldsymbol\alpha$ ไม่แกว่ง จึงไม่มีผลต่อ covariance ที่เหลือคือ $\mathbf B\mathbf f$ กับ $\boldsymbol\epsilon$ ซึ่งข้อสมมติบอกว่าไม่สัมพันธ์กัน

\[ \begin{aligned} \operatorname{cov}(\mathbf B\mathbf f+\boldsymbol\epsilon)&=\operatorname{cov}(\mathbf B\mathbf f)\\ &\quad+\operatorname{cov}(\boldsymbol\epsilon)+\mathbf 0,\\ \operatorname{cov}(\mathbf B\mathbf f)&=\mathbf B\boldsymbol\Omega_f\mathbf B^{\mathsf T},\\ \boldsymbol\Omega_r&=\mathbf B\boldsymbol\Omega_f\mathbf B^{\mathsf T}+\boldsymbol\Omega_\epsilon,\\ \mathbf w^{\mathsf T}\boldsymbol\Omega_r\mathbf w&=\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b\\ &\quad+\mathbf w^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf w. \end{aligned} \]

ใจความคือ ความเสี่ยงของหุ้นทุกตัวแยกเป็นส่วนของ factor บวกส่วนเฉพาะตัว โดยไม่มีพจน์ไขว้ พจน์ไขว้ที่หายไป (เลข $\mathbf 0$) คือ $\mathbf B\operatorname{cov}(\mathbf f,\boldsymbol\epsilon)$ กับ transpose ของมัน ซึ่งเป็นศูนย์เพราะข้อสมมติบอกว่า factor ไม่ขยับตามส่วนเฉพาะตัว

ท่าที่ต้องใช้ในการหา $\operatorname{cov}(\mathbf B\mathbf f)$ คือกฎ covariance ของการแปลงเชิงเส้น ถ้าคูณตัวสุ่มด้วย matrix $\mathbf B$ covariance จะถูกคูณด้วย $\mathbf B$ ทั้งข้างหน้าและข้างหลัง ช่อง $(i,k)$ ของมันคือ $\sum_{j,l}B_{ij}[\boldsymbol\Omega_f]_{jl}B_{kl}$ ซึ่งเป็นสูตรเดียวกับ covariance ของ multi-factor model

กำไรขาดทุนของพอร์ตคือ $\mathbf w^{\mathsf T}\mathbf r$ ซึ่งเป็นการแปลงเชิงเส้นอีกแบบหนึ่ง กฎเดียวกันจึงให้ variance ของมันเป็น $\mathbf w^{\mathsf T}\boldsymbol\Omega_r\mathbf w$ คือคูณ $\mathbf w$ ทั้งสองข้าง แล้วใช้ $\mathbf w^{\mathsf T}\mathbf B=\mathbf b^{\mathsf T}$ อีกครั้ง ผลที่ได้บอกสองเรื่อง

  • ความเสี่ยงจาก factor ขึ้นกับพอร์ตผ่าน exposure $m$ ตัวเท่านั้น ไม่ว่าพอร์ตจะมีหุ้นกี่ตัว
  • ความเสี่ยงเฉพาะตัวคือ $\sum_iw_i^2\sigma_i^2$ เพราะ $\boldsymbol\Omega_\epsilon$ มีตัวเลขแค่บนแนวทแยง

สูตรนี้มีงานสองอย่าง คือพยากรณ์ความเสี่ยงของพอร์ตล่วงหน้า และแบ่งความเสี่ยงเป็นส่วนที่ตั้งใจถือกับส่วนที่ไม่ได้ตั้งใจ

ขั้นที่ 8 — ความเสี่ยงของพอร์ตในโจทย์

ใส่ตัวเลขลงสูตรความเสี่ยง เพื่อดูว่าพอร์ตในโจทย์แกว่งได้วันละกี่ดอลลาร์ และก้อนไหนใหญ่กว่า

โจทย์ให้อะไรมาบ้าง: ตัวเลขทั้งหมดสมมติ

  • ความผันผวนรายวันของ factor return: market 1.00%, momentum 0.35%, tech 0.55%
  • correlation ระหว่าง factor: market กับ momentum −0.20, market กับ tech +0.50, momentum กับ tech −0.10
  • ความผันผวนเฉพาะตัวรายวัน $\sigma_i$: A 1.80%, B 2.20%, C 1.50%, D 2.60%
  • exposure $\mathbf b=(0,\ 13.8,\ 1)$ และเงินที่ถือ $\mathbf w=(3,\ -2,\ 4,\ -5)$ จากขั้นก่อน ๆ

ขั้นแรกต้องสร้าง $\boldsymbol\Omega_f$ จากตัวเลขเหล่านี้ ให้ $s_j$ คือความผันผวนของ factor $j$ และ $\rho_{jl}$ คือ correlation ของ factor $j$ กับ factor $l$

  • ช่องบนแนวทแยงคือ variance ของ factor หนึ่งตัว เท่ากับความผันผวนยกกำลังสอง $s_j^2$
  • ช่องนอกแนวทแยงคือ covariance ของสอง factor เท่ากับ $\rho_{jl}s_js_l$ เพราะ correlation คือ covariance ที่หารด้วยความผันผวนของทั้งสองตัวไว้แล้ว เราจึงคูณกลับ

เรียกความเสี่ยงสองก้อน (หน่วย variance) ว่า $v_f=\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b$ และ $v_\epsilon=\mathbf w^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf w=\sum_iw_i^2\sigma_i^2$ ถ้ากางผลคูณ $v_f$ ออก จะได้ผลรวมของ $b_jb_l$ คูณช่อง $(j,l)$ ของ $\boldsymbol\Omega_f$ ทุกคู่ $j,l$ เพราะ $b_{\rm mkt}=0$ ทุกพจน์ที่มี market ถูกคูณด้วยศูนย์ จึงไม่ต้องคำนวณ เหลือแค่ momentum กับ tech

ให้ $\omega_{mm}$ คือ variance ของ momentum, $\omega_{tt}$ คือ variance ของ tech และ $\omega_{mt}$ คือ covariance ของสองตัวนี้ พจน์ไขว้ $\omega_{mt}$ อยู่ในช่อง (momentum, tech) และช่อง (tech, momentum) จึงนับสองครั้ง ใน $v_f$ จึงมีเลข 2 นำหน้า

\[ \begin{aligned} \omega_{mm}&=0.35^2=0.1225,\\ \omega_{tt}&=0.55^2=0.3025,\\ \omega_{mt}&=-0.10(0.35)(0.55)\\ &=-0.01925,\\ v_f&=13.8^2\omega_{mm}+1^2\omega_{tt}\\ &\quad+2(13.8)(1)\,\omega_{mt}\\ &=190.44(0.1225)+0.3025\\ &\quad+27.6(-0.01925)\\ &=23.3289+0.3025\\ &\quad-0.5313=23.1001,\\ v_\epsilon&=3^2(1.80^2)+2^2(2.20^2)\\ &\quad+4^2(1.50^2)+5^2(2.60^2)\\ &=9(3.24)+4(4.84)\\ &\quad+16(2.25)\\ &\quad+25(6.76)=253.52,\\ v_f+v_\epsilon&=276.6201,\\ \sqrt{276.6201}&=16.6319. \end{aligned} \]

คำตอบ: หน่วยของ variance คือ (\$ ล้าน × %)² รากที่สองของมันจึงมีหน่วย \$ ล้าน × % ซึ่งหนึ่งหน่วยเท่ากับ \$10,000 ตามที่หาไว้ในขั้นแยกกำไรขาดทุน

  • ความเสี่ยงจาก factor $\sqrt{23.1001}=4.8063$ คือ $4.8063\times\$10{,}000=\$48{,}063$ ต่อวัน
  • ความเสี่ยงเฉพาะตัว $\sqrt{253.52}=15.9223$ คือ $15.9223\times\$10{,}000=\$159{,}223$ ต่อวัน
  • ความเสี่ยงรวมทั้งพอร์ต $\sqrt{276.6201}=16.6319$ คือ $16.6319\times\$10{,}000=\$166{,}319$ ต่อวัน

ส่วนเฉพาะตัวครอง $253.52/276.6201=91.65\%$ ของ variance เหตุผลคือพอร์ตมีแค่สี่หุ้น เงินกองอยู่ในไม่กี่ตัว ข่าวของหุ้นตัวเดียวจึงแรง

ถ้ากระจายเงินไปหลายหุ้น ก้อนนี้จะเล็กลง ลองดูกรณีง่าย ๆ แบ่งเงินก้อนเดิม $W$ ไปหุ้น $n$ ตัวเท่า ๆ กัน ตัวละ $W/n$ และให้ทุกตัวมีความผันผวนเฉพาะตัว $\sigma$ เท่ากัน

\[ \begin{aligned} v_\epsilon&=\sum_{i=1}^{n}\Big(\frac{W}{n}\Big)^2\sigma^2\\ &=n\cdot\frac{W^2}{n^2}\sigma^2=\frac{W^2\sigma^2}{n}. \end{aligned} \]

ก้อนเฉพาะตัวจึงลดลงตาม $1/n$ แบบเดียวกับกฎจำนวนมาก เพราะข่าวของหุ้นต่างตัวไม่ขยับตามกันและหักล้างกันเอง แต่เดิมพัน momentum ไม่ลดลง ถ้ายังเลือกหุ้นด้วยเหตุผลเดิม หุ้นทุกตัวที่เพิ่มเข้ามาก็เติมเดิมพันเดิม พอร์ตใหญ่จึงมักมีความเสี่ยงจาก factor เป็นก้อนหลักแทน

ตรวจเองใน 10 วินาที: ความเสี่ยงสองก้อนบวกกันตรง ๆ ไม่ได้ ผลรวม $48{,}063+159{,}223=207{,}286$ ไม่ใช่คำตอบ ที่ถูกคือ $\sqrt{48{,}063^2+159{,}223^2}=166{,}319$ เพราะสองก้อนไม่สัมพันธ์กัน สิ่งที่บวกกันได้คือ variance ไม่ใช่ SD

ขั้นที่ 9 — ทำไมต้องบังคับให้การขยับร่วมผ่าน factor

วิศวกรที่เห็นโจทย์นี้ครั้งแรกมักถามว่า ทำไมไม่วัด covariance ของหุ้นทุกคู่ตรง ๆ จากข้อมูลไปเลย ขั้นนี้ตอบว่าทำไมทางนั้นพัง

ลองนึกถึงหุ้น $n=500$ ตัว กับข้อมูลผลตอบแทนรายวันย้อนหลังหนึ่งปี ปีหนึ่งมีวันที่ตลาดหุ้นสหรัฐเปิดราว $T=252$ วัน ตัวเลขนี้มาจากวันจันทร์ถึงศุกร์ราว 261 วันต่อปี หักวันหยุดตลาด (เช่นปีใหม่ คริสต์มาส) ราว 9 วัน ได้ $261-9=252$ วัน

  • วัดตรง ๆ: covariance matrix ขนาด $n\times n$ สมมาตร ตัวเลขที่ต้องประมาณจึงมีแนวทแยง $n$ ตัว บวกครึ่งบนของช่องที่เหลือ $n(n-1)/2$ ตัว รวม $n(n+1)/2$ ตัว
  • ใช้ factor model ที่มี $m=60$ factor และ loading มาจากข้อมูลบริษัทซึ่งรู้อยู่แล้ว: ต้องประมาณแค่ $\boldsymbol\Omega_f$ ซึ่งมีตัวเลข $m(m+1)/2$ ตัวด้วยเหตุผลเดียวกัน บวก variance เฉพาะตัวอีก $n$ ตัว

นอกจากจำนวนตัวเลขแล้ว ยังต้องดู rank ของ covariance ที่ประมาณจากข้อมูล ซึ่งเขียนว่า $\hat{\boldsymbol\Omega}_r$ (หมวกบนหัวแปลว่าประมาณจากข้อมูล) rank คือจำนวนทิศที่ matrix มองเห็นจริง สุดท้ายจึงเทียบกับความเสี่ยงของพอร์ตที่ factor model ให้

\[ \begin{aligned} \frac{n(n+1)}{2}&=\frac{500(501)}{2}\\ &=125{,}250,\\ \frac{m(m+1)}{2}+n&=1{,}830+500\\ &=2{,}330,\\ \frac{125{,}250}{2{,}330}&\approx53.8,\\ \operatorname{rank}(\hat{\boldsymbol\Omega}_r)&\le T-1=251,\\ 500-251&=249,\\ \mathbf w^{\mathsf T}\boldsymbol\Omega_r\mathbf w&\ge\sum_{i=1}^{n}w_i^2\sigma_i^2\gt0. \end{aligned} \]

วัดตรง ๆ ต้องประมาณตัวเลขมากกว่าราว 54 เท่า แต่ปัญหาจริงหนักกว่าแค่ตัวเลขเยอะ covariance ที่คำนวณจากข้อมูล 252 วันมี rank ไม่เกิน 251 เพราะหลังหักค่าเฉลี่ยออกแล้ว ข้อมูล 252 แถวเหลือแถวที่อิสระกันแค่ 251 แถว หุ้น 500 ตัวมี 500 ทิศ จึงเหลืออย่างน้อย 249 ทิศที่ข้อมูลมองไม่เห็น แต่ละทิศคือพอร์ตหนึ่งพอร์ต ซึ่งข้อมูลบอกว่าความเสี่ยงเป็นศูนย์พอดี ทั้งที่ของจริงไม่ใช่

ผลเสียตามมาสองอย่าง optimizer (โปรแกรมที่หาน้ำหนักพอร์ตที่ดีที่สุด) จะเทเงินลงทิศเหล่านี้ก่อน เพราะมันดูเหมือนได้ผลตอบแทนโดยไม่ต้องรับความเสี่ยงเลย และ matrix ที่มีทิศความเสี่ยงศูนย์หา inverse ไม่ได้ ซึ่งวิธีจัดพอร์ตของ Markowitz ต้องใช้ inverse นี้

covariance ของ factor model ไม่มีทิศแบบนั้น ก้อน $\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b$ ไม่ติดลบเพราะ $\boldsymbol\Omega_f$ เป็น covariance และก้อนเฉพาะตัวบวก $w_i^2\sigma_i^2\gt0$ เข้ามาทุกครั้งที่ถือหุ้นสักตัว ความเสี่ยงของพอร์ตที่ถือหุ้นจริงจึงเป็นบวกเสมอ ไม่ว่าข้อมูลจะสั้นแค่ไหน

ขั้นที่ 10 — พอร์ตที่ไม่มี exposure ต่อ factor ใดเลย

ถ้าผู้จัดการอยากให้กำไรขาดทุนมาจากการเลือกหุ้นล้วน ๆ โดยไม่มีเดิมพัน factor ใดซ่อนอยู่เลย เขาต้องถือพอร์ตแบบไหน คำถามนี้เขียนเป็นสมการได้ตรง ๆ ให้ $\mathbf u$ คือเงินที่ถือหุ้น A, B, C, D (หน่วย \$ ล้าน) เราต้องการให้ exposure ทุกตัวเป็นศูนย์ คือ $\mathbf B^{\mathsf T}\mathbf u=\mathbf 0$

โจทย์ให้อะไรมาบ้าง:

  • matrix $\mathbf B$ ของหุ้นสี่ตัวจากตัวอย่างหนึ่งวัน
  • ความผันผวนเฉพาะตัวรายวันของ A, B, C, D คือ 1.80%, 2.20%, 1.50%, 2.60% จากตัวอย่างความเสี่ยงของพอร์ต

$\mathbf B^{\mathsf T}\mathbf u=\mathbf 0$ คือสามสมการ หนึ่งสมการต่อ factor (market, momentum, tech) แต่มีตัวแปรสี่ตัว จึงเลือกตัวหนึ่งได้อิสระ เราตั้ง $u_A=1$ แล้วแก้หาที่เหลือ สมการ tech บอกทันทีว่า $u_B=-u_A$ พอแทนลงสมการ market ก็ได้ $u_D=-u_C$ เหลือสมการ momentum ไว้หา $u_C$

\[ \begin{aligned} u_A+u_B+u_C+u_D&=0,\\ 1.2u_A-0.4u_B+0.6u_C-1.4u_D&=0,\\ u_A+u_B&=0,\\ u_A=1\ \Rightarrow\ u_B&=-1,\\ u_C+u_D=0\ \Rightarrow\ u_D&=-u_C,\\ 1.2+0.4+0.6u_C+1.4u_C&=0,\\ 1.6+2u_C=0\ \Rightarrow\ u_C&=-0.8. \end{aligned} \]

ได้ $u_D=-u_C=0.8$ จากนั้นตรวจว่า exposure ทั้งสามเป็นศูนย์จริง แล้วหาความเสี่ยงของพอร์ตนี้ เพราะ exposure เป็นศูนย์ ก้อน factor $\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b$ จึงเป็นศูนย์ด้วย เหลือแต่ก้อนเฉพาะตัว $\sum_iu_i^2\sigma_i^2$ ในก้อนนี้ $u_A^2=u_B^2=1$ และ $u_C^2=u_D^2=0.8^2=0.64$

\[ \begin{aligned} \mathbf u&=(1,\ -1,\ -0.8,\ 0.8),\\ b_{\rm mkt}&=1-1-0.8+0.8=0,\\ b_{\rm mom}&=1.2+0.4-0.48-1.12\\ &=0,\\ b_{\rm tech}&=1-1=0,\\ \mathbf u^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf u&=1(1.80^2)+1(2.20^2)\\ &\quad+0.64(1.50^2+2.60^2)\\ &=3.24+4.84\\ &\quad+0.64(2.25+6.76)\\ &=13.8464,\\ \sqrt{13.8464}&=3.7211. \end{aligned} \]

คำตอบ: ซื้อ A \$1 ล้าน short B \$1 ล้าน short C \$0.8 ล้าน และซื้อ D \$0.8 ล้าน พอร์ตนี้ไม่มี exposure ต่อ factor ไหนเลย แต่ยังเสี่ยง $3.7211\times\$10{,}000=\$37{,}211$ ต่อวัน และทั้งหมดเป็นความเสี่ยงเฉพาะตัว

ในโลกที่มีหุ้นสี่ตัวกับ factor สามตัว นี่คือทิศเดียวที่ทำแบบนี้ได้ คำตอบอื่นทุกคำตอบคือ $\mathbf u$ คูณตัวเลขตัวหนึ่ง เช่น $2\mathbf u$ หรือ $-\mathbf u$ คือขยายหรือกลับด้านพอร์ตเดิม หน้าถัดไปจะใช้ทิศนี้แยก alpha

ตรวจเองใน 10 วินาที: $\mathbf u$ มีสี่ตัวแปรแต่ต้องทำให้สามสมการเป็นศูนย์ จึงเหลืออิสระแค่หนึ่งมิติ ตรงกับ $n-m=4-3=1$ มิติที่เหลือให้ส่วนเฉพาะตัว ตอนอ่านสมการเป็นผลรวมของคอลัมน์

ความผิดที่ทำให้อ่านพอร์ตผิด

คิดว่า dollar-neutral คือไม่มีความเสี่ยงจาก factor: เงินสองฝั่งเท่ากันลบได้แค่เดิมพันกับตลาด ไม่ได้ลบเดิมพันกับ factor อื่น พอร์ตในโจทย์มี NMV เป็นศูนย์ exposure ต่อ market จึงเป็นศูนย์ แต่ exposure ต่อ momentum เป็น \$13.8 ล้าน เทียบกับ GMV \$14 ล้าน ได้ $13.8/14=98.6\%$ คือเงินเกือบทั้งพอร์ตเป็นเดิมพันเดียว คนเลือกหุ้นทีละตัวมักสะสม exposure แบบนี้โดยไม่รู้ตัว เพราะเหตุผลที่ใช้เลือกหุ้น เช่น “ราคาวิ่งดี” ก็คือ style factor ตัวหนึ่งอยู่แล้ว

บวกความเสี่ยงของสองก้อนตรง ๆ: ผิดคือ $48{,}063+159{,}223=\$207{,}286$ ต่อวัน ถูกคือ $\sqrt{48{,}063^2+159{,}223^2}=\$166{,}319$ ต่อวัน ค่าที่ผิดสูงเกินไป $207{,}286/166{,}319-1=24.6\%$ โต๊ะเทรดมีวงเงินความเสี่ยง คือเพดานว่าพอร์ตแกว่งได้วันละไม่เกินเท่าไร ถ้าคิดความเสี่ยงสูงเกินจริง จะถือของได้น้อยกว่าที่วงเงินอนุญาต และสัดส่วนว่าความเสี่ยงมาจากก้อนไหนเท่าไรก็ผิดไปด้วย

ใช้ loading ผิดวัน: loading ที่ใช้อธิบายผลตอบแทนของวัน $t$ ต้องเป็นตัวเลขที่รู้ก่อนวัน $t$ เริ่ม แต่ผู้ให้บริการข้อมูลส่วนใหญ่ติดป้ายวันที่ $t$ ให้ข้อมูลที่รู้ตอนจบวัน $t$ ถ้าใช้ป้ายตรง ๆ โดยไม่เลื่อนหนึ่งวัน ผลตอบแทนของวัน $t$ จะรั่วเข้าไปใน loading เช่น loading momentum ของวันนั้นนับรวมราคาที่เพิ่งวิ่งไปในวันเดียวกันแล้ว model จึงดูเหมือนอธิบายผลตอบแทนได้ดีเกินจริง เพราะมันแอบเห็นคำตอบก่อน ต้องตรวจเรื่องนี้ทุกครั้งที่ซื้อข้อมูลจากผู้ให้บริการ

ใช้ทำอะไรบนโต๊ะจริง

ในทีมเทรดหุ้น factor model คือภาษากลางที่ทุกคนใช้ คนดูแลความเสี่ยง (risk manager) ใช้มันพยากรณ์ความเสี่ยงและแบ่งว่ามาจากไหน ผู้จัดการพอร์ตใช้มันสร้างพอร์ต และพอจบงวดก็ใช้แยกฝีมือออกจากโชค นักวิจัยใช้มันแยก alpha ของจริงออกจากเดิมพัน factor

รายงานที่ผู้จัดการเห็นทุกเช้าคือ vector $\mathbf b$ ทั้ง 60 ถึง 100 ตัว พร้อมเพดานของแต่ละตัว exposure momentum \$13.8 ล้านของพอร์ตในโจทย์จะถูกจับได้ตั้งแต่เช้าวันแรกในระบบแบบนี้ แต่อาจรอดสายตาได้ทั้งเดือนในระบบที่ดูแค่ NMV กับ GMV

model ที่ใช้กันในตลาดมีสามแบบ แยกตามว่าอะไรรู้อยู่แล้วและอะไรต้องประมาณ

  • แบบแรกรู้ loading จากข้อมูลบริษัท เช่นอุตสาหกรรมและ momentum แล้วประมาณ factor return ทุกวันด้วย regression ข้ามหุ้น
  • แบบที่สองรู้แค่ผลตอบแทนของหุ้น จึงต้องประมาณทั้ง loading และ factor return จากข้อมูล เช่นด้วย PCA
  • แบบที่สามใช้ตัวแปรเศรษฐกิจเป็น factor return แล้วประมาณ loading ด้วย regression ตามเวลา แบบ multi-factor model

หน้านี้ข้ามเรื่องการประมาณไปก่อน โดยสมมติว่ารู้ทั้ง $\mathbf B$ และ $\mathbf f$ แล้ว

โจทย์ตรวจความเข้าใจ

1. พรุ่งนี้ผู้จัดการยังถือพอร์ตเดิม $\mathbf w=(3,\ -2,\ 4,\ -5)$ \$ ล้าน ตลาดวันนั้นลง และตัวเลขของวันเป็นดังนี้ (สมมติ)

  • factor return: market −1.00%, momentum +0.40%, tech −0.20%
  • ส่วนเฉพาะตัวของ A, B, C, D: +0.10%, +0.30%, −0.20%, +0.05%

กำไรขาดทุนของวันนั้นแยกเป็นส่วน factor และส่วนเฉพาะตัวได้เท่าไร

เฉลย

ใช้ $\mathbf b=(0,\ 13.8,\ 1)$ เดิม แล้วคูณผลทุกตัวด้วย \$10,000

\[ \begin{aligned} \mathbf b^{\mathsf T}\mathbf f&=0(-1.00)+13.8(0.40)\\ &\quad+1(-0.20)\\ &=5.52-0.20=5.32,\\ \mathbf w^{\mathsf T}\boldsymbol\epsilon&=3(0.10)-2(0.30)\\ &\quad+4(-0.20)-5(0.05)\\ &=0.30-0.60-0.80-0.25\\ &=-1.35,\\ \mathbf w^{\mathsf T}\mathbf r&=5.32-1.35=3.97. \end{aligned} \]

แปลงเป็นดอลลาร์

  • factor PnL คือ $5.32\times\$10{,}000=+\$53{,}200$
  • idiosyncratic PnL คือ $-1.35\times\$10{,}000=-\$13{,}500$
  • รวม $3.97\times\$10{,}000=+\$39{,}700$

ตรวจอีกทางด้วยผลตอบแทนรวมของแต่ละหุ้น คือ loading คูณ factor return ของวันนั้น บวกส่วนเฉพาะตัว แล้วคูณเงินที่ถือ

\[ \begin{aligned} r_A&=-1.00+1.2(0.40)\\ &\quad-0.20+0.10=-0.62\%,\\ r_B&=-1.00-0.4(0.40)\\ &\quad-0.20+0.30=-1.06\%,\\ r_C&=-1.00+0.6(0.40)\\ &\quad-0.20=-0.96\%,\\ r_D&=-1.00-1.4(0.40)\\ &\quad+0.05=-1.51\%,\\ \mathbf w^{\mathsf T}\mathbf r&=3(-0.62)-2(-1.06)\\ &\quad+4(-0.96)-5(-1.51)\\ &=-1.86+2.12-3.84+7.55\\ &=3.97. \end{aligned} \]

ได้ 3.97 ตรงกัน ตลาดลง 1% แต่พอร์ตได้เงิน เพราะเดิมพัน momentum พลิกมาเข้าข้าง ส่วนการเลือกหุ้นวันนั้นเสียเงิน ตรงข้ามกับวันแรกทุกอย่าง

2. ผู้จัดการเห็นรายงานแล้วอยากลบเดิมพัน momentum ทิ้ง โดยแก้เฉพาะเงินที่ถือ C ให้เป็น $c$ (\$ ล้าน) ส่วน A, B, D เหมือนเดิม ต้องตั้ง $c$ เท่าไร exposure ต่อ momentum จึงเป็นศูนย์ และหลังแก้แล้ว exposure ต่อ market จะเป็นเท่าไร

เฉลย
\[ \begin{aligned} b_{\rm mom}&=1.2(3)-0.4(-2)\\ &\quad+0.6c-1.4(-5)\\ &=3.6+0.8+7.0+0.6c\\ &=11.4+0.6c=0,\\ c&=-11.4/0.6=-19,\\ b_{\rm mkt}&=3-2-19-5=-23. \end{aligned} \]

$c$ ติดลบ แปลว่าต้องเปลี่ยนจากซื้อ C \$4 ล้าน เป็น short C \$19 ล้าน แต่ NMV จะกลายเป็น −\$23 ล้าน ซึ่งก็คือ exposure ต่อ market −\$23 ล้าน เดิมพัน momentum หายไป แต่เกิดเดิมพันก้อนใหม่ว่าตลาดจะลงขึ้นมาแทน

บทเรียนคือ แก้หุ้นตัวเดียว มีตัวแปรให้ปรับแค่ตัวเดียว จึงทำให้สอง exposure เป็นศูนย์พร้อมกันไม่ได้ ทิศที่ทำให้ทุก exposure เป็นศูนย์คือ $\mathbf u$ ในตัวอย่างพอร์ตที่ไม่มี exposure ต่อ factor ใดเลยเท่านั้น

3. กองทุนใหญ่แห่งหนึ่งดูหุ้น $n=3{,}000$ ตัว ใช้ model ที่มี $m=80$ factor และมีข้อมูลรายวันสองปี $T=2\times252=504$ วัน ถ้าวัด covariance ตรง ๆ กับใช้ factor model ต้องประมาณตัวเลขกี่ตัว และ covariance จากข้อมูลจะมีทิศที่บอกว่าไม่มีความเสี่ยงอย่างน้อยกี่ทิศ

เฉลย
\[ \begin{aligned} \frac{n(n+1)}{2}&=\frac{3{,}000(3{,}001)}{2}\\ &=4{,}501{,}500,\\ \frac{m(m+1)}{2}+n&=\frac{80(81)}{2}+3{,}000\\ &=3{,}240+3{,}000=6{,}240,\\ \frac{4{,}501{,}500}{6{,}240}&\approx721.4,\\ \operatorname{rank}(\hat{\boldsymbol\Omega}_r)&\le504-1=503,\\ 3{,}000-503&=2{,}497. \end{aligned} \]

วัดตรง ๆ ต้องประมาณตัวเลขมากกว่า factor model ราว 721 เท่า และ covariance จากข้อมูลมีทิศที่บอกว่าความเสี่ยงเป็นศูนย์อย่างน้อย 2,497 ทิศ ข้อมูลสองปีเห็นความเสี่ยงได้แค่ 503 ทิศจาก 3,000 ทิศ

const {sqrt, abs} = Math;
function checkMatrix(A, name) {
  if (!Array.isArray(A) || A.length === 0 || !A.every(row => Array.isArray(row) && row.length === A[0].length && row.every(Number.isFinite))) {
    throw new TypeError(name + ' must be a non-empty rectangular matrix of finite numbers');
  }
  return [A.length, A[0].length];
}
function checkVector(x, n, name) {
  if (!Array.isArray(x) || x.length !== n || !x.every(Number.isFinite)) throw new TypeError(name + ' must hold ' + n + ' finite numbers');
  return x;
}
const dot = (a, b) => a.reduce((s, v, i) => s + v * b[i], 0);
const matVec = (A, x) => A.map(row => dot(row, x));
const transpose = A => A[0].map((_, j) => A.map(row => row[j]));
const UNIT = 1e4; // one million dollars times 1% is 10,000 dollars
// One day of r = B f + eps (alpha = 0 on this page).
function oneDay(B, f, eps) {
  const [n, m] = checkMatrix(B, 'Loadings B');
  checkVector(f, m, 'Factor returns');
  checkVector(eps, n, 'Idiosyncratic returns');
  const factorPart = matVec(B, f);
  return {factorPart, r: factorPart.map((v, i) => v + eps[i])};
}
// Reading 3: the book collapses to its exposures b = B'w; PnL splits into b'f and w'eps.
function pnlSplit(B, w, f, eps) {
  const [n] = checkMatrix(B, 'Loadings B');
  checkVector(w, n, 'Positions');
  const b = matVec(transpose(B), w), {r} = oneDay(B, f, eps);
  return {b, nmv: w.reduce((s, x) => s + x, 0), gmv: w.reduce((s, x) => s + abs(x), 0),
    perFactor: b.map((x, j) => x * f[j] * UNIT), perStock: w.map((x, i) => x * eps[i] * UNIT),
    factor: dot(b, f) * UNIT, idio: dot(w, eps) * UNIT, direct: dot(w, r) * UNIT};
}
function covarianceFromVols(vols, corr) {
  const [k, k2] = checkMatrix(corr, 'Correlation');
  if (k !== k2 || !Array.isArray(vols) || vols.length !== k) throw new RangeError('Need one volatility per row of a square correlation matrix');
  if (!vols.every(v => Number.isFinite(v) && v > 0)) throw new RangeError('Volatilities must be positive');
  for (let i = 0; i < k; i++) {
    if (corr[i][i] !== 1) throw new RangeError('Correlation diagonal must be 1');
    for (let j = 0; j < i; j++) if (corr[i][j] !== corr[j][i] || abs(corr[i][j]) > 1) throw new RangeError('Correlation must be symmetric with entries between -1 and 1');
  }
  return corr.map((row, i) => row.map((c, j) => c * vols[i] * vols[j]));
}
// Risk splits the same way: b' Omega_f b + w' Omega_eps w (diagonal Omega_eps).
function riskSplit(B, w, Of, idioVols) {
  const [n] = checkMatrix(B, 'Loadings B');
  checkVector(w, n, 'Positions');
  checkVector(idioVols, n, 'Idiosyncratic volatilities');
  if (!idioVols.every(s => s > 0)) throw new RangeError('Every idiosyncratic volatility must be positive');
  const b = matVec(transpose(B), w);
  const factorVar = dot(b, matVec(Of, b)), idioVar = w.reduce((s, x, i) => s + x * x * idioVols[i] ** 2, 0);
  return {factorVar, idioVar, factorUSD: sqrt(factorVar) * UNIT, idioUSD: sqrt(idioVar) * UNIT,
    totalUSD: sqrt(factorVar + idioVar) * UNIT, idioShare: idioVar / (factorVar + idioVar)};
}
function counts(n, m, T) {
  if (![n, m, T].every(Number.isInteger) || n < 1 || m < 1 || T < 2) throw new RangeError('Need whole numbers n, m >= 1 and T >= 2');
  const direct = n * (n + 1) / 2, factor = m * (m + 1) / 2 + n;
  return {direct, factor, ratio: direct / factor, zeroDirections: Math.max(0, n - (T - 1))};
}
const B = [[1, 1.2, 1], [1, -0.4, 1], [1, 0.6, 0], [1, -1.4, 0]];
const f = [0.80, -0.50, 0.30], eps = [0.40, -0.25, 0.15, -0.60], w = [3, -2, 4, -5];
const Of = covarianceFromVols([1.00, 0.35, 0.55], [[1, -0.20, 0.50], [-0.20, 1, -0.10], [0.50, -0.10, 1]]);
const idioVols = [1.80, 2.20, 1.50, 2.60];
const day = oneDay(B, f, eps), book = pnlSplit(B, w, f, eps), risk = riskSplit(B, w, Of, idioVols);
const u = [1, -1, -0.8, 0.8], neutral = riskSplit(B, u, Of, idioVols);
const day2 = pnlSplit(B, w, [-1.00, 0.40, -0.20], [0.10, 0.30, -0.20, 0.05]);

สิ่งที่ควรตอบได้หลังอ่าน

  • $\mathbf r_t=\boldsymbol\alpha+\mathbf B\mathbf f_t+\boldsymbol\epsilon_t$ แยกผลตอบแทนของหุ้นเป็นสามก้อน คือก้อนคงที่ ก้อนจากแรงร่วม และก้อนเฉพาะตัว โดยสมมติว่าก้อนเฉพาะตัวไม่ขยับตาม factor และไม่ขยับตามกันข้ามหุ้น
  • สมการเดียวอ่านได้สามทาง ทีละหุ้นคือ factor ไหลลงหุ้นตามเส้น loading ทุกหุ้นพร้อมกันคือผลรวมของคอลัมน์ ซึ่งขังส่วนของ factor ไว้ใน $m$ มิติ และทั้งพอร์ตคือย่อพอร์ตให้เหลือ exposure $\mathbf b=\mathbf B^{\mathsf T}\mathbf w$ แค่ $m$ ตัว
  • พอร์ตในโจทย์ขาดทุน $-66{,}000+53{,}000=-\$13{,}000$ เพราะ factor ทำให้เสีย \$66,000 ทั้งที่การเลือกหุ้นทำเงินได้ \$53,000 เงินสองฝั่งเท่ากัน (dollar-neutral) ไม่ได้แปลว่าไม่มีเดิมพัน momentum
  • ความเสี่ยงแยกเป็น $\mathbf b^{\mathsf T}\boldsymbol\Omega_f\mathbf b+\mathbf w^{\mathsf T}\boldsymbol\Omega_\epsilon\mathbf w$ สิ่งที่บวกกันได้คือ variance ไม่ใช่ SD: \$48,063 กับ \$159,223 รวมได้ $\sqrt{48{,}063^2+159{,}223^2}=\$166{,}319$ ไม่ใช่ \$207,286
  • หุ้น 500 ตัวกับข้อมูล 252 วัน covariance ที่วัดตรง ๆ มีทิศที่บอกว่าความเสี่ยงเป็นศูนย์อย่างน้อย $500-251=249$ ทิศ factor model ต้องประมาณตัวเลขแค่ 2,330 ตัวแทน 125,250 ตัว และให้ความเสี่ยงเป็นบวกเสมอ

หน้าถัดไป alpha spanned และ alpha orthogonal ถามว่า $\boldsymbol\alpha$ อยู่ตรงไหนของภาพนี้ แบ่งเป็นส่วนที่อยู่ใน range ของ $\mathbf B$ กับส่วนที่ตั้งฉากกับมัน ส่วนหลังคือทิศแบบพอร์ต $\mathbf u$ ที่ไม่มี exposure ต่อ factor ใดเลย และเมื่อหุ้นมีหลายร้อยตัว ส่วนนี้มีค่ามากกว่าส่วนแรกหลายเท่า
