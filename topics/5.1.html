5.1 Joint CDF และ Joint PDF

รู้ว่าหุ้นแต่ละตัวลงบ่อยแค่ไหนยังไม่พอ ต้องรู้ว่ามันลงพร้อมกันบ่อยแค่ไหน และ joint CDF กับ joint PDF คือเครื่องมือที่เก็บข้อมูลส่วนนั้นไว้

ข้อมูลย้อนหลัง 100 วันซื้อขาย (สมมติ) ของ AAPL และ MSFT บอกว่าแต่ละตัวมีวันที่ผลตอบแทนไม่เกิน −1% อยู่ 20 วัน หรือ 20% ของวัน risk manager อยากรู้ว่าสองตัวลงถึง −1% พร้อมกัน บ่อยแค่ไหน เพราะวันแบบนั้นคือวันที่พอร์ตเจ็บที่สุด เพื่อนร่วมทีมตอบทันทีว่า $0.2\times0.2=4\%$ ของวัน ถูกไหม และโอกาสที่อย่างน้อยหนึ่งตัวลงถึง −1% เป็นเท่าไร

ลองตอบก่อนเปิดเฉลย

นับจากข้อมูลได้ 10 วันจาก 100 วัน คือ 10% มากกว่าคำตอบ 4% ถึง 2.5 เท่า การคูณ $0.2\times0.2$ ใช้ได้เฉพาะเมื่อสองหุ้นเป็นอิสระกัน ซึ่งหุ้นเทคโนโลยีสองตัวไม่ใช่ ส่วนโอกาสที่อย่างน้อยหนึ่งตัวลงคือ $0.20+0.20-0.10=0.30$ ต้องลบวันที่ลงพร้อมกันออกหนึ่งครั้ง เพราะวันเหล่านั้นถูกนับไปแล้วทั้งในฝั่ง AAPL และฝั่ง MSFT

ภาพรวมก่อนลงสูตร

การแจกแจงของตัวแปรเดียวตอบได้ว่าหุ้นตัวหนึ่งลงบ่อยแค่ไหน แต่พอร์ตเจ็บจริงในวันที่หลายตัวลงพร้อมกัน ข้อมูลส่วนนี้อยู่ใน joint distribution ซึ่งบอกว่าคู่ผลลัพธ์ $(X,Y)$ ตกตรงไหนบนระนาบบ่อยแค่ไหน รูปด้านล่างวาด 100 วันเป็น 100 จุด แต่ละจุดคือหนึ่งวัน ตำแหน่งแนวนอนคือผลตอบแทน AAPL ตำแหน่งแนวตั้งคือผลตอบแทน MSFT

เครื่องมือมีสองชิ้น joint CDF $F(x,y)$ นับมวลในมุมซ้ายล่างของจุด $(x,y)$ คือโอกาสที่ทั้งสองตัวไม่เกินเกณฑ์ของตัวเองพร้อมกัน ส่วน joint PDF $f(x,y)$ บอกว่ามวลหนาแน่นแค่ไหนต่อพื้นที่หนึ่งหน่วย โอกาสของบริเวณใดคือปริมาตรใต้ density เหนือบริเวณนั้น เหมือนนับจุดในบริเวณเมื่อมีจุดเป็นล้าน ๆ จุด

หน้านี้จะนิยามทั้งสองอย่าง ใช้กฎสี่มุมหาโอกาสของกรอบใดก็ได้จาก CDF แปลง CDF กลับเป็น PDF ด้วยอนุพันธ์ผสม แล้วดูว่าคำถามพอร์ตจริง เช่น “พอร์ต 50/50 ขาดทุนเกิน 1%” เป็นบริเวณรูปอื่นที่ไม่ใช่มุมซ้ายล่าง

ศัพท์ที่ใช้ในหัวข้อนี้
Joint distribution
กฎที่บอกโอกาสของทุกเหตุการณ์ที่เกี่ยวกับหลายตัวแปรพร้อมกัน ใช้ตอบคำถามเรื่องการเกิดพร้อมกัน ซึ่งการแจกแจงรายตัวตอบไม่ได้
Joint CDF $F_{X,Y}(x,y)$
โอกาสที่ $X\le x$ และ $Y\le y$ พร้อมกัน ใช้ได้กับตัวแปรทุกชนิด ทั้งแบบนับได้และแบบต่อเนื่อง และเป็นจุดตั้งต้นของกฎสี่มุม
Joint PDF $f_{X,Y}(x,y)$
ความหนาแน่นของโอกาสต่อพื้นที่หนึ่งหน่วยบนระนาบ ตัวมันเองไม่ใช่โอกาส ต้องอินทิเกรตเหนือบริเวณจึงได้โอกาส ใช้หาโอกาสของบริเวณรูปร่างใดก็ได้
กฎสี่มุม (rectangle rule)
สูตรบวกลบค่า CDF ที่สี่มุมของกรอบเพื่อหาโอกาสที่คู่ผลลัพธ์ตกในกรอบ ใช้ได้แม้การแจกแจงไม่มี density
Support
บริเวณที่ density เป็นบวก นอก support โอกาสเป็นศูนย์ ต้องรู้ก่อนตั้งขอบอินทิกรัล และก่อนแทนค่าลงสูตร CDF ที่เขียนไว้เฉพาะในบริเวณนั้น
Marginal
การแจกแจงของตัวแปรเดียวที่ดึงออกมาจาก joint ได้ เช่น $F_X(x)=F_{X,Y}(x,+\infty)$ รายละเอียดอยู่ใน marginal distribution
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$X,\ Y$ผลตอบแทนรายวันของ AAPL และ MSFT ($X=-1$ คือ −1%)จุดเปอร์เซ็นต์
$F_{X,Y}(x,y)$joint CDF: โอกาสที่ $X\le x$ และ $Y\le y$ไม่มีหน่วย (0 ถึง 1)
$f_{X,Y}(x,y)$joint PDF: โอกาสต่อพื้นที่ต่อ (จุดเปอร์เซ็นต์)²
$F_X,\ F_Y$CDF ของแต่ละตัวแปร (marginal)ไม่มีหน่วย
$a\lt b,\ c\lt d$ขอบของกรอบ: $X$ อยู่ระหว่าง $a$ กับ $b$ และ $Y$ อยู่ระหว่าง $c$ กับ $d$จุดเปอร์เซ็นต์

ขั้นที่ 1 — นับโอกาสร่วมจากตาราง

โจทย์ให้อะไรมาบ้าง: ตารางนับวันจาก 100 วันซื้อขาย (สมมติ) แยกตามว่าแต่ละหุ้นลงถึง −1% หรือไม่ ตัวเลขในตารางคือสี่ส่วนของรูปภาพรวมด้านบน

AAPL $X\le-1$101020

\[\begin{aligned} P(X\le-1,\,Y\le-1)&=\tfrac{10}{100}=0.10,\\ P(X\le-1)\,P(Y\le-1)&=0.20\times0.20\\ &=0.04,\\ P(\text{at least one})&=0.20+0.20-0.10\\ &=0.30. \end{aligned}\]

คำตอบ: สองหุ้นลงพร้อมกัน 10% ของวัน ไม่ใช่ 4% ผลคูณ 0.04 คือสิ่งที่จะเห็นถ้ารู้ AAPL แล้วไม่ได้ช่วยบอกอะไรเกี่ยวกับ MSFT เลย ข้อมูลนี้ไม่เป็นแบบนั้น: ในวันที่ AAPL ลง MSFT ลงตาม 10 ใน 20 วัน หรือครึ่งหนึ่ง ทั้งที่ในวันทั่วไป MSFT ลงแค่ 1 ใน 5 ส่วนบรรทัดสุดท้าย วันที่ลงพร้อมกัน 10 วันถูกนับทั้งใน 20 วันของ AAPL และ 20 วันของ MSFT จึงต้องหักออกหนึ่งครั้ง

ตรวจเองใน 10 วินาที: วันที่ไม่มีตัวไหนลงเลยมี 70 วัน ดังนั้นวันที่มีอย่างน้อยหนึ่งตัวลงต้องเป็น $100-70=30$ วัน ตรงกับ 0.30

ขั้นที่ 2 — Joint CDF: นับมวลในมุมซ้ายล่าง

ตารางตอบได้เฉพาะเกณฑ์ −1% ถ้าพรุ่งนี้ถามเกณฑ์ −2% หรือ −3% ต้องนับใหม่ joint CDF คือฟังก์ชันที่ตอบคำถามนี้ได้ทุกคู่เกณฑ์ในตัวเดียว

\[\begin{aligned} F_{X,Y}(x,y)&=P(X\le x,\,Y\le y),\\ F_{X,Y}(-1,-1)&=0.10,\\ F_{X,Y}(x,+\infty)&=F_X(x),\\ F_{X,Y}(-\infty,y)&=0,\\ F_{X,Y}(+\infty,+\infty)&=1. \end{aligned}\]

จุลภาคในวงเล็บแปลว่า “และ” เรานับเฉพาะวันที่ผ่านทั้งสองเกณฑ์ ค่า $F(-1,-1)=0.10$ ไม่ได้แปลว่าผลตอบแทนเท่ากับ −1% พอดี มันรวมทุกวันที่ต่ำกว่านั้นด้วย เหมือนนับจุดทั้งหมดในมุมซ้ายล่างของจุด $(-1,-1)$ ในรูปภาพรวม

บรรทัดที่สามคือท่าที่จะใช้บ่อยที่สุด ถ้าดันเกณฑ์ของ $Y$ ไปถึง $+\infty$ ก็เท่ากับไม่จำกัด $Y$ เลย เหลือแค่เงื่อนไขของ $X$ จึงได้ CDF ของ $X$ ตัวเดียว ในตารางคือ $F(-1,+\infty)=20/100=0.20$ ส่วนสองบรรทัดสุดท้ายบอกว่าถ้าบังคับให้ตัวหนึ่งต่ำกว่าทุกจำนวน โอกาสเป็นศูนย์ และถ้าไม่จำกัดทั้งคู่ก็ได้ทุกวัน คือ 1

เลื่อนเกณฑ์ไปทางขวาหรือขึ้นข้างบน มุมซ้ายล่างใหญ่ขึ้น $F$ จึงไม่ลดลง แต่แค่นั้นยังไม่พอจะเป็น joint CDF ที่ใช้ได้ ทุกกรอบสี่เหลี่ยมยังต้องมีโอกาสไม่ติดลบด้วย ซึ่งตรวจด้วยกฎสี่มุมในขั้นถัดไป

ขั้นที่ 3 — กฎสี่มุม: โอกาสของกรอบใดก็ได้

CDF ให้แค่มุมซ้ายล่าง แต่คำถามจริงมักเป็นกรอบ เช่น “AAPL อยู่ระหว่าง −2% ถึง 1% และ MSFT อยู่ระหว่าง −1% ถึง 2%” เราต้องตัดกรอบนั้นออกจากมุมซ้ายล่างหลายอัน

\[\begin{aligned} &P(a\lt X\le b,\ c\lt Y\le d)\\ &=F(b,d)-F(a,d)\\ &\quad-F(b,c)+F(a,c). \end{aligned}\]

เริ่มจากมุมซ้ายล่างของมุมขวาบน $F(b,d)$ ซึ่งใหญ่เกินกรอบ ตัดแถบซ้ายออกด้วย $F(a,d)$ แล้วตัดแถบล่างออกด้วย $F(b,c)$ จุดที่คนลืมคือมุมเล็กซ้ายล่างของกรอบ $F(a,c)$ อยู่ทั้งในแถบซ้ายและแถบล่าง จึงถูกตัดไปสองครั้ง ต้องบวกคืนหนึ่งครั้ง ดูรูปด้านล่าง

ใช้กับตาราง: วันที่ ไม่มี ตัวไหนลงถึง −1% คือกรอบ $a=-1,\ b=+\infty,\ c=-1,\ d=+\infty$ ได้ $F(+\infty,+\infty)-F(-1,+\infty)-F(+\infty,-1)+F(-1,-1)=1-0.20-0.20+0.10=0.70$ ตรงกับ 70 วันในตาราง ถ้าลืมบวกมุมคืนจะได้ 0.60 ผิดไป 10 วัน

ขั้นนี้ไม่ต้องใช้ density เลย จึงใช้ได้กับตารางนับวันและกับแบบจำลองต่อเนื่องเหมือนกัน ข้อควรระวังเดียวคือปลายเปิดปลายปิด สูตรนี้ใช้กรอบที่ไม่รวมขอบซ้ายและขอบล่าง ($a\lt X$) แต่รวมขอบขวาและขอบบน ($X\le b$) ตัวแปรต่อเนื่องไม่ต่างกัน แต่ตัวแปรที่มีมวลอยู่บนขอบพอดีจะต่าง

ขั้นที่ 4 — Joint PDF: โอกาสคือปริมาตร ไม่ใช่ความสูง

เมื่อผลตอบแทนเป็นตัวเลขต่อเนื่อง โอกาสที่จะได้คู่ค่าใดค่าหนึ่งพอดีเป็นศูนย์ สิ่งที่มีความหมายคือโอกาสต่อพื้นที่ ซึ่งคือ density ให้ $P_A$ แทนโอกาสที่คู่ $(X,Y)$ ตกในบริเวณ $A$

\[\begin{aligned} P_A&=\iint_A f_{X,Y}(u,v)\,du\,dv,\\ 1&=\iint_{\mathbb R^2} f_{X,Y}(u,v)\,du\,dv,\\ F_{X,Y}(x,y)&=\int_{-\infty}^{x}\!\int_{-\infty}^{y} f_{X,Y}(u,v)\,dv\,du,\\ P_{\text{box}}&\approx f_{X,Y}(x,y)\,\Delta x\,\Delta y. \end{aligned}\]

บรรทัดแรกคือนิยาม: density ต้องไม่ติดลบ และโอกาสของบริเวณคือปริมาตรใต้ผิว density เหนือบริเวณนั้น บรรทัดที่สองบอกว่าทั้งระนาบต้องรวมได้ 1 บรรทัดที่สามคือกรณีพิเศษที่บริเวณเป็นมุมซ้ายล่าง จึงเชื่อม PDF เข้ากับ CDF

บรรทัดสุดท้ายบอกวิธีอ่านตัวเลข density: ในกล่องเล็กกว้าง $\Delta x$ สูง $\Delta y$ density แทบคงที่ โอกาสจึงประมาณความสูงคูณพื้นที่ หน่วยของ $f$ จึงเป็น “ต่อจุดเปอร์เซ็นต์กำลังสอง” ไม่ใช่โอกาส ตัวอย่างจากแบบจำลอง Gaussian ในรูปด้านบน: ความสูงที่จุดศูนย์กลางคือ $1/(2\pi\times2.5\times3\times\sqrt{1-0.6^2})=1/(2\pi\times6)=0.0265$ ต่อ (จุดเปอร์เซ็นต์)² (สูตร density อยู่ใน multivariate normal density ที่จุดศูนย์กลางเลขชี้กำลังเป็นศูนย์) กล่องกว้าง 0.1 จุดสูง 0.1 จุดรอบจุดนั้นจึงมีโอกาส $0.0265\times0.01=0.000265$

ถ้าเปลี่ยนไปวัดผลตอบแทนเป็นทศนิยม (−1% เป็น −0.01) แต่ละแกนหดลง 100 เท่า พื้นที่หด $10{,}000$ เท่า density จึงต้องสูงขึ้น $10{,}000$ เท่าเป็น 265 เพื่อให้ปริมาตรเท่าเดิม ความสูงเกิน 1 ได้โดยไม่ผิดกฎอะไร เพราะความสูงไม่ใช่โอกาส

ขั้นที่ 5 — ตัวอย่างที่คำนวณได้ทั้งสองทาง

แบบจำลอง Gaussian อินทิเกรตด้วยมือไม่ได้ ขั้นนี้จึงใช้ density ของเล่นที่คิดได้ครบทุกบรรทัด เพื่อดูว่าทาง CDF กับทาง PDF ให้คำตอบเดียวกันจริง

โจทย์ให้อะไรมาบ้าง: ตัวแปรไร้หน่วย $f(x,y)=x+y$ บนสี่เหลี่ยม $0\le x\le1,\ 0\le y\le1$ และเป็นศูนย์นอกสี่เหลี่ยม ต้องการโอกาสของกรอบ $0.3\lt X\le0.8,\ 0.4\lt Y\le0.9$

\[\begin{aligned} \int_0^1(x+y)\,dy&=x+\tfrac12,\\ \int_0^1\big(x+\tfrac12\big)\,dx&=\tfrac12+\tfrac12=1,\\ F(x,y)&=\int_0^x\!\int_0^y(u+v)\,dv\,du\\ &=\frac{x^2y+xy^2}{2},\\ P_{\text{box}}&=F(0.8,0.9)-F(0.3,0.9)\\ &\quad-F(0.8,0.4)+F(0.3,0.4)\\ &=0.612-0.162-0.192+0.042\\ &=0.300,\\ \int_{0.3}^{0.8}\!\int_{0.4}^{0.9}(x+y)\,dy\,dx &=\int_{0.3}^{0.8}(0.5x+0.325)\,dx\\ &=0.1375+0.1625=0.300. \end{aligned}\]

คำตอบ: โอกาส 0.300 ทั้งสองทาง สองบรรทัดแรกตรวจก่อนว่า density รวมได้ 1 จริง บรรทัด CDF ได้จากการอินทิเกรตทีละแกน: ตาม $v$ ได้ $uy+y^2/2$ แล้วตาม $u$ ได้ $x^2y/2+xy^2/2$ บรรทัดสุดท้ายอินทิเกรต $x+y$ ตาม $y$ ในช่วงยาว 0.5 ได้ $0.5x+\tfrac12(0.9^2-0.4^2)=0.5x+0.325$ แล้วอินทิเกรตตาม $x$

ตรวจเองใน 10 วินาที: density เป็นเส้นตรงใน $x$ และ $y$ ค่าเฉลี่ยในกรอบจึงเท่ากับค่าที่จุดกลางกรอบ $0.55+0.65=1.2$ คูณพื้นที่ $0.5\times0.5=0.25$ ได้ 0.30 ตรงกัน

ขั้นที่ 6 — จาก CDF กลับมาเป็น PDF

ตอนนิยาม joint PDF เราไปจาก PDF สู่ CDF ด้วยการอินทิเกรต ทางกลับคือหาอนุพันธ์ ใช้กฎสี่มุมกับกล่องเล็กกว้าง $h$ สูง $k$ แล้วหารด้วยพื้นที่กล่อง จะได้ density เฉลี่ยในกล่อง

\[\begin{aligned} D_{h,k}&=\frac{1}{hk}\Big[F(x+h,y+k)-F(x,y+k)\\ &\qquad-F(x+h,y)+F(x,y)\Big],\\ \lim_{h,k\to0}D_{h,k}&=\frac{\partial^2F(x,y)}{\partial x\,\partial y}=f(x,y). \end{aligned}\]

วงเล็บเหลี่ยมคือโอกาสของกล่องเล็กจากกฎสี่มุม หารด้วยพื้นที่ $hk$ จึงเป็นโอกาสต่อพื้นที่ ซึ่งคือนิยามของ density เมื่อกล่องเล็กลงจนเป็นจุด ผลลัพธ์คืออนุพันธ์ผสม: หาอนุพันธ์ตาม $x$ หนึ่งครั้งและตาม $y$ หนึ่งครั้ง

ลองกับ $F=(x^2y+xy^2)/2$ ที่จุด $(0.5,0.2)$ ซึ่ง density จริงคือ $0.5+0.2=0.7$: กล่องขนาด $h=k=0.1$ ให้ $D=0.80$ ขนาด 0.01 ให้ 0.71 ขนาด 0.0001 ให้ 0.7001 แทนค่าตรง ๆ ได้ $D_{h,k}=x+y+(h+k)/2$ ส่วนเกิน $(h+k)/2$ หายไปเมื่อกล่องหด และหาอนุพันธ์ผสมของ $F$ ตรง ๆ ก็ได้ $x+y$ กลับมาพอดี

ทางนี้ใช้ได้ตรงจุดที่ $F$ เรียบพอ และไม่ใช่ทุก joint CDF จะมี density สองมิติ เช่นถ้า $Y=X$ ทุกครั้ง มวลทั้งหมดอยู่บนเส้นทแยงซึ่งมีพื้นที่ศูนย์ CDF ยังมีอยู่ คือ $F(x,y)=F_X(\min(x,y))$ แต่ไม่มีฟังก์ชัน $f$ ใดที่อินทิเกรตบนพื้นที่แล้วได้มวลบนเส้น นี่คือเหตุผลที่นิยามหลักของ joint distribution คือ CDF ไม่ใช่ PDF

ขั้นที่ 7 — คำถามพอร์ตไม่ใช่มุมซ้ายล่าง

CDF ตอบคำถามแบบ “ทั้งสองตัวต่ำกว่าเกณฑ์” แต่ desk มักถามเรื่องพอร์ต เช่น “พอร์ตที่ลงทุนครึ่งต่อครึ่งขาดทุนเกิน 1% บ่อยแค่ไหน” วันที่ AAPL −3% กับ MSFT +0.5% ก็ทำให้พอร์ตขาดทุน 1.25% ได้ ทั้งที่ MSFT ไม่ได้ลงเลย

โจทย์ให้อะไรมาบ้าง: แบบจำลอง Gaussian เดิม ค่าเฉลี่ยศูนย์ ส่วนเบี่ยงเบนมาตรฐาน 2.5 และ 3 จุดเปอร์เซ็นต์ correlation 0.6 พอร์ตคือ $0.5X+0.5Y$

\[\begin{aligned} \sigma_P^2&=0.25(2.5^2)+0.25(3^2)\\ &\quad+2(0.25)(0.6)(2.5)(3)\\ &=1.5625+2.25+2.25=6.0625,\\ \sigma_P&=2.462,\\ P(0.5X+0.5Y\le-1)&=\Phi\!\left(\tfrac{-1}{2.462}\right)=\Phi(-0.406)\\ &=0.342. \end{aligned}\]

คำตอบ: พอร์ตขาดทุนเกิน 1% ราว 34.2% ของวัน บริเวณที่ต้องอินทิเกรตคือครึ่งระนาบใต้เส้น $x+y=-2$ ไม่ใช่มุมซ้ายล่าง สูตร variance ของพอร์ตมีพจน์ covariance $2(0.25)(0.6)(2.5)(3)$ ซึ่งจะพิสูจน์ใน ผลที่ตามมาของความเป็นอิสระ และการที่ผลรวมเชิงเส้นของ Gaussian ร่วมยังเป็น Gaussian อยู่ใน linear combinations ของ MVN $\Phi$ คือ CDF ของ normal มาตรฐาน

ตรวจเองใน 10 วินาที: มุมซ้ายล่าง $X\le-1,\ Y\le-1$ อยู่ใต้เส้นทั้งหมด เพราะถ้าทั้งคู่ไม่เกิน −1 ค่าเฉลี่ยของสองตัวก็ไม่เกิน −1 คำตอบ 0.342 จึงต้องมากกว่า $F(-1,-1)=0.219$ และก็มากกว่าจริง

ขั้นที่ 8 — หลายตัวแปร: เงื่อนไขทุกตัวพร้อมกัน

พอร์ตจริงมีหุ้นหลายสิบตัว นิยามเดิมขยายได้ตรง ๆ: ให้ $\mathbf X=(X_1,\ldots,X_n)$ เป็นเวกเตอร์ของผลตอบแทน

\[\begin{aligned} F_{\mathbf X}(x_1,\ldots,x_n)&=P(X_1\le x_1,\ldots,X_n\le x_n),\\ F_{\mathbf X}(\mathbf x)&=\int_{-\infty}^{x_1}\!\!\cdots\int_{-\infty}^{x_n} f_{\mathbf X}(\mathbf u)\,du_n\cdots du_1,\\ F_{X_i,X_j}(x_i,x_j)&=F_{\mathbf X}(\infty,\ldots,x_i,\ldots,x_j,\ldots,\infty). \end{aligned}\]

บรรทัดแรกยังเป็นการนับมุม แต่เป็นมุมใน $n$ มิติ บรรทัดที่สองใช้เมื่อมี density และทางกลับคือหาอนุพันธ์ตามทุกพิกัดครั้งละหนึ่งครั้ง บรรทัดสุดท้ายเป็นท่าเดียวกับตอนดึง CDF ของ $X$ ออกจาก joint CDF: ดันเกณฑ์ของตัวแปรที่ไม่สนใจไปที่ $+\infty$ ก็จะได้ joint distribution ของคู่ที่สนใจ เช่นจากหุ้น 50 ตัว ดึงเฉพาะ AAPL กับ MSFT ออกมา

ปัญหาในทางปฏิบัติคือข้อมูล ตารางสองหุ้นแบ่งเป็น 4 ช่อง ถ้าแต่ละหุ้นแบ่งเป็นสองกลุ่มแบบเดียวกัน หุ้น 10 ตัวต้องใช้ $2^{10}=1{,}024$ ช่อง และวันซื้อขายประมาณ 252 วันต่อปีไม่พอจะเติมทุกช่อง นี่คือเหตุผลที่งานจริงใช้แบบจำลองที่มีพารามิเตอร์น้อย เช่น Gaussian ที่ใช้แค่ค่าเฉลี่ยกับ covariance matrix หรือ Gaussian copula

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

คูณโอกาสรายตัวแทนโอกาสร่วม: ตารางให้ 0.10 แต่ผลคูณให้ 0.04 ต่ำไป 2.5 เท่า ในแบบจำลอง Gaussian ก็ต่ำไปจาก 0.219 เหลือ 0.127 ความผิดนี้ทำให้ความเสี่ยงวันที่หุ้นลงพร้อมกันดูเล็กกว่าจริงเสมอเมื่อหุ้นขยับไปทางเดียวกัน

ลืมบวกมุมคืน: $1-0.20-0.20=0.60$ แทนที่จะเป็น 0.70 ต่างไป 10 วันจาก 100 วัน คือวันที่ลงพร้อมกันซึ่งถูกลบสองครั้ง

อ่านความสูงของ density เป็นโอกาส: สำหรับ $f=x+y$ ค่า $f(0.5,0.5)=1$ แต่ $F(0.5,0.5)=(0.125+0.125)/2=0.125$ ตัวแรกเป็นความหนาแน่นที่จุด ตัวหลังเป็นโอกาสสะสม และในแบบจำลอง Gaussian ที่วัดเป็นทศนิยม ความสูงคือ 265 ซึ่งไม่ใช่โอกาสแน่นอน

แทนค่านอก support ลงสูตรตรง ๆ: แทน $x=y=2$ ลงใน $(x^2y+xy^2)/2$ ได้ 8 ซึ่งเป็นโอกาสไม่ได้ สูตรนี้ใช้ได้เฉพาะในสี่เหลี่ยมหน่วย นอกนั้นต้องตัดค่าแต่ละพิกัดให้อยู่ในช่วง 0 ถึง 1 ก่อน จึงได้ $F(2,2)=F(1,1)=1$

เปลี่ยนหน่วยแล้วไม่ปรับ density: เปลี่ยนจากจุดเปอร์เซ็นต์เป็นทศนิยมโดยไม่คูณ density ด้วย $10{,}000$ จะได้ปริมาตรรวมเหลือ $1/10{,}000$ แทนที่จะเป็น 1

ใช้ทำอะไรบนโต๊ะจริง

ฝ่ายความเสี่ยงใช้โอกาสร่วมในการทดสอบภาวะวิกฤต (stress test) เช่นโอกาสที่หุ้นกลุ่มเดียวกันลงแรงพร้อมกัน หรือโอกาสที่ลูกหนี้หลายรายผิดนัดในปีเดียวกัน การหาความเสียหายของพอร์ตที่ระดับความเชื่อมั่นหนึ่ง เช่น VaR และ expected shortfall ก็คือการหาโอกาสของครึ่งระนาบแบบพอร์ต 50/50 ด้านบน แต่ในหลายมิติ และเมื่อข้อมูลไม่พอจะประมาณ joint distribution ตรง ๆ desk จะแยกงานเป็นสองส่วน คือการแจกแจงรายตัวกับรูปแบบการเกิดร่วม ซึ่งเป็นแนวคิดของ Gaussian copula

โจทย์ตรวจความเข้าใจ

1. จากตาราง 100 วัน จงหาโอกาสที่ AAPL ลงถึง −1% แต่ MSFT ไม่ลงถึง และเขียนเป็นกฎสี่มุมด้วยค่า $F$

เฉลย

นับตรงได้ 10 วัน คือ 0.10 ในรูปกฎสี่มุม กรอบคือ $X\le-1$ (ให้ $a=-\infty,\ b=-1$) และ $Y\gt-1$ (ให้ $c=-1,\ d=+\infty$) จึงได้ $F(-1,+\infty)-F(-\infty,+\infty)-F(-1,-1)+F(-\infty,-1)=0.20-0-0.10+0=0.10$ เทอมที่มี $-\infty$ เป็นศูนย์ทั้งหมด

2. สำหรับ $f=x+y$ บนสี่เหลี่ยมหน่วย จงหา $P(X\le0.5)$ จาก joint CDF แล้วตรวจด้วยการอินทิเกรต density ตรง ๆ

เฉลย

ดันเกณฑ์ของ $Y$ ไปที่ขอบบนของ support: $F(0.5,1)=(0.25\times1+0.5\times1)/2=0.375$ ตรวจ: จากตัวอย่าง $x+y$ ด้านบน การอินทิเกรตตาม $y$ ได้ $x+\tfrac12$ แล้ว $\int_0^{0.5}(x+\tfrac12)\,dx=0.125+0.25=0.375$ ตรงกัน ฟังก์ชัน $x+\tfrac12$ นี้คือ marginal density ของ $X$

3. แบบจำลอง Gaussian เดิม ถ้าพอร์ตถือ AAPL อย่างเดียว โอกาสขาดทุนเกิน 1% เป็นเท่าไร เทียบกับพอร์ตครึ่งต่อครึ่ง 0.342 แล้วการกระจายช่วยลดโอกาสขาดทุนเกิน 1% มากไหม

เฉลย

$P(X\le-1)=\Phi(-1/2.5)=\Phi(-0.4)=0.345$ พอร์ตครึ่งต่อครึ่งได้ 0.342 ลดลงนิดเดียว เพราะส่วนเบี่ยงเบนมาตรฐานของพอร์ต 2.462 แทบไม่ต่างจาก 2.5 ของ AAPL ตัวเดียว correlation 0.6 ทำให้สองหุ้นขยับไปด้วยกันจนการกระจายช่วยได้น้อย ถ้า correlation เป็นศูนย์ variance ของพอร์ตจะเหลือ $1.5625+2.25=3.8125$ ส่วนเบี่ยงเบน 1.953 และโอกาสลดเหลือ $\Phi(-0.512)=0.304$

เปิดดูโค้ด 
// 1) the 100-day table: rows X<=-1, X>-1 ; columns Y<=-1, Y>-1
const days = [[10, 10], [10, 70]];
const n = 100;
const both = days[0][0] / n;                       // 0.10
const fx = (days[0][0] + days[0][1]) / n;          // 0.20
const fy = (days[0][0] + days[1][0]) / n;          // 0.20
console.log({ both, product: fx * fy, atLeastOne: fx + fy - both,
  neither: 1 - fx - fy + both });                  // 0.04, 0.30, 0.70

// 2) toy density f = x + y on the unit square
const clip = t => Math.max(0, Math.min(1, t));
const F = (x, y) => { x = clip(x); y = clip(y); return (x*x*y + x*y*y) / 2; };
const box = F(.8, .9) - F(.3, .9) - F(.8, .4) + F(.3, .4);
let integral = 0;
const m = 200, step = .5 / m;
for (let i = 0; i < m; i++) for (let j = 0; j < m; j++) {
  const x = .3 + (i + .5) * step, y = .4 + (j + .5) * step;
  integral += (x + y) * step * step;
}
console.log({ box, integral, total: F(1, 1), F22: F(2, 2) });  // 0.3, 0.3, 1, 1

// 3) mixed difference quotient -> density 0.7 at (0.5, 0.2)
for (const h of [0.1, 0.01, 1e-4]) {
  const D = (F(.5+h, .2+h) - F(.5, .2+h) - F(.5+h, .2) + F(.5, .2)) / (h*h);
  console.log(h, D.toFixed(4));                   // 0.8000, 0.7100, 0.7001
}

// 4) Gaussian model: centre density and the 50/50 portfolio
function Phi(x) {                                  // normal CDF by series
  const a = Math.abs(x); let t = a, s = a;
  for (let k = 1; k < 200; k++) { t *= a*a / (2*k + 1); s += t; }
  const half = Math.exp(-a*a/2) / Math.sqrt(2*Math.PI) * s;
  return x < 0 ? .5 - half : .5 + half;
}
const sx = 2.5, sy = 3, r = .6;
const f00 = 1 / (2 * Math.PI * sx * sy * Math.sqrt(1 - r*r));
const varP = .25*sx*sx + .25*sy*sy + 2*.25*r*sx*sy;
console.log({ f00, f00decimal: f00 * 1e4, varP,
  portfolio: Phi(-1 / Math.sqrt(varP)), aaplOnly: Phi(-1 / sx) });
// f00 0.0265, 265.26 ; varP 6.0625 ; portfolio 0.342 ; aaplOnly 0.345

สิ่งที่ควรตอบได้หลังอ่าน

  • joint CDF $F(x,y)=P(X\le x,\,Y\le y)$ คือมวลในมุมซ้ายล่าง และตารางสมมติให้ $F(-1,-1)=0.10$ ไม่ใช่ผลคูณ 0.04
  • โอกาสของกรอบใดก็ได้คือ $F(b,d)-F(a,d)-F(b,c)+F(a,c)$ มุมเล็กถูกลบสองครั้งจึงต้องบวกคืน
  • joint PDF เป็นโอกาสต่อพื้นที่ ต้องอินทิเกรตเหนือบริเวณ ความสูงเกิน 1 ได้และมีหน่วยต่อพื้นที่
  • อนุพันธ์ผสมของ CDF คืน density ($x+y$ ในตัวอย่าง) แต่ไม่ใช่ทุก joint distribution จะมี density
  • คำถามพอร์ตเป็นครึ่งระนาบ ไม่ใช่มุม: พอร์ต 50/50 ขาดทุนเกิน 1% มีโอกาส 0.342 มากกว่ามุมซ้ายล่าง 0.219

นิยามของ joint CDF แอบใช้ท่าหนึ่งไปแล้ว คือดันเกณฑ์ของอีกตัวไปที่ $+\infty$ เพื่อเหลือตัวแปรเดียว หน้าถัดไป marginal distribution ทำท่านี้ให้เป็นระบบ ทั้งกับตาราง กับ density และกับ support ที่ไม่ใช่สี่เหลี่ยม
