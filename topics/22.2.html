22.2 Prepayment Risk and the Public Securities Association Benchmark

ผู้กู้ซื้อบ้านคืนหนี้ก่อนกำหนดได้ทุกเมื่อ เงินต้นของกองสินเชื่อ “30 ปี” จึงกลับมาเร็วหรือช้าตามอัตราดอกเบี้ย และราคาของ MBS ขึ้นยากแต่ลงง่าย

ในสหรัฐฯ คนส่วนใหญ่ซื้อบ้านด้วยเงินกู้ที่ผ่อนเท่ากันทุกเดือนนาน 30 ปี ธนาคารเอาเงินกู้แบบเดียวกันหลายพันก้อนมารวมเป็นกองเดียว เรียกว่า pool แล้วขายสิทธิ์รับเงินจากกองนี้ให้นักลงทุน ตราสารนี้เรียกว่า pass-through เพราะเงินที่ผู้กู้จ่ายมาทุกเดือน “ผ่าน” ไปถึงผู้ถือเลย มันคือ MBS (mortgage-backed security) แบบที่ง่ายที่สุด ดูตารางผ่อนของสินเชื่อบ้านและ pass-through

นักลงทุนคนหนึ่งกำลังจะซื้อ pass-through ก้อนหนึ่ง เขาอยากรู้ว่าเงินต้นที่ได้คืนจะกลับมาเมื่อไร เพราะเงินที่กลับมาต้องเอาไปลงทุนต่อ กลับเร็วหรือกลับช้าจึงให้ผลต่างกัน

ของที่รู้ (pool ตัวอย่างในไฟล์ Excel ชื่อ MBS_Structure ของคอร์ส ซึ่งหน้านี้เรียกว่า workbook):

  • หนี้ที่ยังค้างทั้ง pool $B_0=\$400$ ล้าน
  • ผู้กู้จ่ายดอกเบี้ย 8.125% ต่อปี ตัวเลขนี้เรียกว่า WAC คืออัตราเฉลี่ยของผู้กู้ทุกคนใน pool
  • ผู้ลงทุนได้ 7.50% ต่อปี เรียกว่า pass-through rate ส่วนต่าง $8.125\%-7.50\%=0.625\%$ เป็นค่าจ้างคนเก็บเงินจากผู้กู้ (servicing fee)
  • สัญญาผ่อน 30 ปี คือ $30\times12=360$ งวด ปล่อยกู้มาแล้ว 3 เดือน จึงเหลือ $360-3=357$ งวด

ผู้ขายเปิดตารางผ่อน (ตารางที่บอกว่าผู้กู้จ่ายเงินต้นเดือนละเท่าไร) แล้วตอบว่าเงินต้นกลับมาเฉลี่ยในราว 20.4 ปี (ขั้นที่ 4 จะคำนวณตัวเลขนี้ให้ดู)

แต่ผู้กู้ในสหรัฐฯ คืนหนี้ก่อนครบกำหนดได้ทุกเมื่อ เช่น ขายบ้าน หรือกู้ก้อนใหม่ที่ดอกเบี้ยถูกกว่ามาปิดก้อนเดิม ตลาดจึงพูดถึงความเร็วที่ผู้กู้คืนก่อนกำหนดด้วยหน่วยมาตรฐานชื่อ PSA “100 PSA” คือความเร็วปกติตามเส้นมาตรฐาน “200 PSA” คือเร็วเป็นสองเท่าของเส้นนั้น (ขั้นที่ 2 จะอธิบายเส้นนี้)

ถ้าผู้กู้คืนก่อนกำหนดที่ 100 PSA เงินต้นจะกลับมาเฉลี่ยในกี่ปี และถ้าอัตราดอกเบี้ยลดลงจนผู้กู้คืนเร็วเป็น 200 PSA ล่ะ?

ลองตอบก่อนเปิดเฉลย

ที่ 100 PSA เงินต้นกลับมาเฉลี่ยใน 11.67 ปี ไม่ใช่ 20.38 ปี และที่ 200 PSA เหลือแค่ 7.69 ปี ขั้นที่ 4 จะคำนวณทั้งสามตัวเลขนี้ให้ดูทีละขั้น

pool ที่เรียกว่า “30 ปี” จึงทำตัวเหมือนพันธบัตร (ตราสารหนี้ที่จ่ายเงินตามตารางตายตัว) อายุราว 12 ปี หรือ 8 ปีก็ได้ แล้วแต่ว่าผู้กู้ตัดสินใจอย่างไร ผู้ถือไม่รู้ล่วงหน้าว่าจะเป็นแบบไหน ความไม่รู้นี้เรียกว่า prepayment risk

ภาพรวมก่อนลงสูตร

ตารางผ่อนของสินเชื่อบ้านสมมติว่าผู้กู้จ่ายตามตารางทุกเดือนจนครบ 30 ปี ของจริงไม่เป็นแบบนั้น ผู้กู้ในสหรัฐฯ คืนเงินต้นเกินตารางได้ทุกเมื่อโดยไม่เสียค่าปรับ เงินต้นส่วนที่เกินตารางนี้เรียกว่า prepayment (การคืนก่อนกำหนด) มันเกิดได้หลายทาง

  • ผู้กู้ขายบ้าน จึงต้องปิดหนี้ทั้งก้อน
  • อัตราดอกเบี้ยในตลาดลดลง ผู้กู้จึงกู้ก้อนใหม่ที่ถูกกว่ามาปิดก้อนเดิม เรียกว่า refinance
  • ผู้กู้ผิดนัด แล้ว agency (หน่วยงานที่รับประกัน pool เช่น Fannie Mae) จ่ายหนี้ที่เหลือแทน
  • บ้านเสียหายจากไฟหรือน้ำท่วม แล้วเงินประกันมาปิดหนี้
  • ผู้กู้โปะเงินต้นเพิ่มเอง

ทุกทางให้ผลเหมือนกัน คือเงินต้นมาถึงผู้ถือ MBS เร็วกว่าตาราง หน้านี้ไล่ทีละขั้นว่าจะวัดและตีราคาเรื่องนี้อย่างไร

  • ขั้นที่ 1: วัดความเร็วการคืนก่อนเป็นอัตราต่อปี เรียกว่า CPR แล้วแปลงเป็นอัตราต่อเดือน เรียกว่า SMM เพราะตารางผ่อนเดินทีละเดือน
  • ขั้นที่ 2: ใช้เส้นมาตรฐานของ Public Securities Association (PSA) เป็นหน่วยวัดความเร็ว
  • ขั้นที่ 3: เดินเงินของ pool ทีละเดือน
  • ขั้นที่ 4: สรุปว่าเงินต้นกลับมาเฉลี่ยเมื่อไร ตัวเลขนี้เรียกว่า average life
  • ขั้นที่ 5 และ 6: ตัด pool เป็นชิ้นที่ได้แต่เงินต้น (PO) กับชิ้นที่ได้แต่ดอกเบี้ย (IO) เพื่อดูว่าความเร็วย้ายมูลค่าไปทางไหน
  • ขั้นที่ 7: ใช้แบบจำลองของ Richard และ Roll ทำให้ความเร็วขึ้นกับอัตราดอกเบี้ย
  • ขั้นที่ 8: ดูว่าราคาของ MBS ตอบสนองต่ออัตราอย่างไร และทำไม duration (ราคาเปลี่ยนกี่เปอร์เซ็นต์เมื่ออัตราขยับ) กับ convexity (ความโค้งของราคา) ของพันธบัตรธรรมดาใช้กับ MBS ตรง ๆ ไม่ได้

รูปด้านล่างคือภาพรวมของทั้งหน้า pool เดียวกัน สัญญาเดียวกัน แต่หนี้หายไปเร็วต่างกันมาก แล้วแต่ว่าผู้กู้คืนก่อนกำหนดเร็วแค่ไหน

ศัพท์ที่ใช้ในหัวข้อนี้
Pool และ pass-through
pool คือกองสินเชื่อบ้านแบบเดียวกันหลายพันก้อนที่รวมไว้ด้วยกัน pass-through คือ MBS (ตราสารที่มีกองสินเชื่อบ้านหนุนหลัง) แบบที่ง่ายที่สุด มันส่งดอกเบี้ยและเงินต้นที่เก็บได้ต่อให้ผู้ถือทุกเดือน หลังหักค่าบริการ
WAC และ pass-through rate
WAC (weighted-average coupon) คืออัตราดอกเบี้ยเฉลี่ยที่ผู้กู้ใน pool จ่าย ในหน้านี้คือ 8.125% ต่อปี pass-through rate คืออัตราที่ผู้ลงทุนได้ ในหน้านี้คือ 7.50% ต่อปี ส่วนต่างเป็นค่าจ้างคนเก็บเงินจากผู้กู้ (servicing fee)
Prepayment
เงินต้นที่ผู้กู้คืนเกินตาราง มาจากการขายบ้าน การกู้ใหม่เพื่อปิดหนี้เดิม (refinance) การโปะเพิ่ม หรือเงินที่ผู้รับประกันจ่ายแทนเมื่อผู้กู้ผิดนัดหรือบ้านเสียหาย เงินก้อนนี้ส่งต่อให้ผู้ถือ MBS ทันที
CPR และ SMM
CPR (conditional prepayment rate) คือสัดส่วนของหนี้ที่ยังค้างซึ่งถูกคืนก่อนกำหนดในหนึ่งปี SMM (single monthly mortality) คืออัตราเดียวกันแต่เป็นรายเดือน ได้จากการทบ ไม่ใช่การหาร ตลาดคุยกันเป็น CPR แต่การคำนวณเดินด้วย SMM
PSA benchmark
เส้น CPR มาตรฐานที่ไต่ขึ้นตามอายุสินเชื่อนาน 30 เดือน แล้วคงที่ที่ 6% ต่อปี ความเร็วอื่นพูดเป็นกี่เท่าของเส้นนี้ เช่น 200 PSA คือสองเท่า มันเป็นภาษากลางในการเสนอราคา ไม่ใช่คำพยากรณ์
Average life
เวลาเฉลี่ยที่เงินต้นแต่ละดอลลาร์กลับมาถึงผู้ถือ ใช้บอกว่าตราสารที่ผ่อนคืนมีอายุจริงเท่าไร ตัวเลขนี้ขึ้นกับความเร็วการคืนก่อนที่สมมติ
Contraction risk และ extension risk
contraction risk คือเมื่ออัตราลง เงินต้นกลับมาเร็วในวันที่เอาไปลงทุนต่อได้แค่อัตราต่ำ extension risk คือเมื่ออัตราขึ้น เงินต้นค้างอยู่นานในวันที่อยากได้คืนไปลงทุนที่อัตราสูง ผู้ถือ MBS เสียทั้งสองทาง
Principal-only (PO) และ interest-only (IO)
สองชิ้นที่ตัดจาก pass-through PO ได้เงินต้นทุกดอลลาร์ IO ได้ดอกเบี้ยทุกดอลลาร์ ใช้แยกผลของความเร็ว เพราะการคืนเร็วทำให้ PO ได้เงินเร็วขึ้น แต่ทำให้ IO เสียหนี้ที่ใช้คิดดอกเบี้ย
Effective duration และ negative convexity
duration บอกว่าราคาเปลี่ยนกี่เปอร์เซ็นต์เมื่ออัตราขยับหนึ่งจุด convexity บอกความโค้งของราคา effective duration และ effective convexity วัดสองค่านี้โดยคิดราคาใหม่ทั้งชุดเมื่ออัตราขยับ เพราะเงินสดของ MBS เปลี่ยนตามอัตรา MBS มี convexity ติดลบ คือราคาขึ้นน้อยเมื่ออัตราลง แต่ลงเต็มที่เมื่ออัตราขึ้น

ขั้นที่ 1 — อัตราคืนก่อนกำหนดรายปีเป็นรายเดือน

ตลาดพูดถึงความเร็วการคืนก่อนเป็นอัตราต่อปี เรียกว่า CPR (conditional prepayment rate) ถ้าบอกว่า CPR เท่ากับ 6% แปลว่าในหนึ่งปี หนี้ที่ยังค้างอยู่ 6% ถูกคืนก่อนกำหนด แต่ตารางผ่อนเดินทีละเดือน เราจึงต้องการอัตราต่อเดือน เรียกว่า SMM (single monthly mortality) ซึ่งถ้าใช้ซ้ำ 12 เดือนแล้วต้องได้ 6% ต่อปีพอดี

ดูหนี้หนึ่งดอลลาร์ ในแต่ละเดือน มันถูกคืนก่อนไปสัดส่วน SMM จึงเหลือ $1-\mathrm{SMM}$ เท่าของเดือนก่อน ผ่านไป 12 เดือนจึงเหลือ $(1-\mathrm{SMM})^{12}$ ส่วนที่เหลือนี้ต้องเท่ากับส่วนที่เหลือทั้งปีตามนิยามของ CPR คือ $1-\mathrm{CPR}$

\[ \begin{aligned} (1-\mathrm{SMM})^{12}&=1-\mathrm{CPR},\\ \mathrm{SMM}&=1-(1-\mathrm{CPR})^{1/12},\\ \mathrm{SMM}&=1-(1-0.06)^{1/12}\\ &=1-0.994857\\ &=0.5143\%. \end{aligned} \]

หนี้หนึ่งดอลลาร์จะรอดจากการถูกคืนก่อนตลอดทั้งปีได้ ต้องรอดทุกเดือนติดกัน 12 เดือน สัดส่วนที่รอดจึงคูณกัน ไม่ได้บวกกัน ตรรกะเดียวกับโอกาสรอดจากการผิดนัดในhazard rate และโอกาสรอด จุดที่ต้องคิดกลับด้านคือ เรารู้ผลของทั้งปี แต่ต้องการอัตราของเดือน จึงถอดราก 12 ทั้งสองข้าง แล้วย้าย SMM ไปไว้ข้างเดียว ใส่ CPR 6% ได้ 0.5143% ต่อเดือน

ทำไมไม่หาร 6% ด้วย 12 เฉย ๆ ลองดู การหารให้ $0.06/12=0.5\%$ ต่อเดือน ทบกลับครบปี หนี้เหลือ $0.995^{12}=0.9416$ จึงถูกคืนไปแค่ $1-0.9416=5.84\%$ ไม่ใช่ 6% วิธีหารต่ำไปเดือนละ $0.5143\%-0.5\%=0.0143$ จุด ตัวเลขนี้ดูเล็ก แต่มันคูณกับหนี้ทั้ง pool ทุกเดือน

ขั้นที่ 2 — เส้นมาตรฐาน PSA

ความเร็วการคืนก่อนไม่ได้คงที่ตลอดอายุสินเชื่อ สินเชื่อที่เพิ่งปล่อยแทบไม่มีใครคืนก่อน เพราะผู้กู้เพิ่งจ่ายค่าธรรมเนียมกู้และเพิ่งย้ายเข้าบ้าน ความเร็วจึงค่อย ๆ ไต่ขึ้นตามอายุ สมาคม Public Securities Association (PSA) จึงตั้งเส้นมาตรฐานของการไต่นี้ไว้สำหรับสินเชื่อ 30 ปี ให้ทั้งตลาดใช้เป็นหน่วยร่วมกัน

ให้ $a$ คืออายุของสินเชื่อเป็นเดือน นับจากวันปล่อยกู้ ให้ $m(a)$ คือ CPR ของเส้นมาตรฐาน (100 PSA) ที่อายุ $a$ และให้ $k$ คือความเร็วเป็นกี่เท่าของเส้นมาตรฐาน เช่น 100 PSA คือ $k=1$ และ 200 PSA คือ $k=2$

\[ \begin{aligned} \mathrm{CPR}(a)&=k\,m(a),\\ m(a)&=6\%\cdot\frac{a}{30},\quad a\le30,\\ m(a)&=6\%,\quad a\gt30. \end{aligned} \]

เส้นมาตรฐานไต่เป็นเส้นตรงจาก 0 ถึง 6% ในเวลา 30 เดือน จึงขึ้นเดือนละ $6\%/30=0.2$ จุด หลังจากนั้นแบนอยู่ที่ 6% ตัวคูณ $k$ ยืดทั้งเส้นขึ้นหรือลง 200 PSA จึงแบนที่ $2\times6\%=12\%$ และ 50 PSA แบนที่ $0.5\times6\%=3\%$

จุดที่พลาดง่ายคือ $a$ นับจากวันปล่อยกู้ ไม่ใช่จากวันที่เราซื้อ pool ในโจทย์ปล่อยกู้มาแล้ว 3 เดือน เดือนแรกที่เราถือจึงเป็นอายุ $a=4$ ที่ 100 PSA ได้ CPR $=6\%\times4/30=0.8\%$

สังเกตว่าสูตร PSA ไม่มีอัตราดอกเบี้ยอยู่เลย มันจึงไม่ได้บอกว่าผู้กู้จะทำอะไรจริง ตลาดใช้มันเป็นไม้บรรทัดเท่านั้น แล้วผู้ซื้อกับผู้ขายเถียงกันว่า pool นี้จะคืนที่กี่ PSA

ขั้นที่ 3 — เดินเงินของ pool หนึ่งเดือน ตาม workbook ของคอร์ส

ตอนนี้แปลงความเร็วเป็นอัตรารายเดือนได้แล้ว ขั้นนี้เดินเงินของ pool หนึ่งเดือนเต็ม เพื่อให้เห็นว่าเงินที่ผู้กู้จ่ายมาแยกเป็นดอกเบี้ย เงินต้นตามตาราง และเงินคืนก่อนกำหนดอย่างไร ลำดับในหนึ่งเดือนเป็นแบบเดียวกับ workbook

  • คิดค่างวด $A_t$ ใหม่จากหนี้ต้นเดือน $B_{t-1}$ และจำนวนงวดที่เหลือ ด้วยสูตรค่างวดเท่ากันทุกงวดจากตารางผ่อนของสินเชื่อบ้าน
  • แยกค่างวดเป็นดอกเบี้ย $I_t=rB_{t-1}$ กับเงินต้นตามตาราง $P_t=A_t-I_t$
  • หักเงินต้นตามตารางออกก่อน แล้วคูณหนี้ที่เหลือด้วย SMM ได้เงินคืนก่อนกำหนด $PP_t$
  • หนี้ปลายเดือน $B_t$ คือหนี้ต้นเดือนลบเงินต้นทั้งสองก้อน

โจทย์ให้อะไรมาบ้าง:

  • pool ในโจทย์ หนี้ต้นเดือนแรก $B_0=400$ (ตัวเลขทุกตัวในขั้นนี้เป็นล้านดอลลาร์)
  • อัตราของผู้กู้ต่อเดือน $r=0.08125/12=0.0067708$
  • เหลือ 357 งวด
  • ความเร็ว 100 PSA เดือนแรกที่ถือคืออายุ 4 จึงใช้ CPR 0.8% (จากขั้นที่ 2)
\[ \begin{aligned} A_1&=\frac{B_0\,r}{1-(1+r)^{-357}}\\ &=\frac{400\times0.0067708}{1-1.0067708^{-357}}\\ &=\frac{2.70833}{1-0.08990}=2.9759,\\ I_1&=B_0\,r=400\times0.0067708\\ &=2.7083,\\ P_1&=A_1-I_1\\ &=2.97587-2.70833\approx0.2675,\\ \mathrm{SMM}_1&=1-(1-0.008)^{1/12}\\ &=0.0006691,\\ PP_1&=(B_0-P_1)\,\mathrm{SMM}_1\\ &=399.7325\times0.0006691\\ &=0.2675,\\ B_1&=B_0-P_1-PP_1\\ &=400-0.2675-0.2675\\ &=399.4650. \end{aligned} \]

คำตอบ: เดือนแรก เงินต้นกลับมาถึงผู้ถือ $P_1+PP_1=0.2675+0.2675=\$0.535$ ล้าน ครึ่งหนึ่งมาตามตาราง อีกครึ่งเป็นการคืนก่อนกำหนด

ดอกเบี้ย \$2.7083 ล้านที่ผู้กู้จ่ายไม่ได้ถึงผู้ลงทุนทั้งหมด ผู้ลงทุนได้ตาม pass-through rate คือ $400\times0.075/12=\$2.5$ ล้าน ส่วนที่เหลือ $2.7083-2.5=\$0.2083$ ล้าน คือ servicing fee 0.625% ต่อปี เพราะ $400\times0.00625/12=0.2083$

เมื่อ pool อายุมากขึ้น ความเร็วไต่ขึ้น การคืนก่อนจึงกลายเป็นก้อนหลัก ดูเดือนที่ 15 ที่เราถือ ซึ่งคืออายุ $15+3=18$ เดือน CPR $=6\%\times18/30=3.6\%$ เดินตารางต่อจนถึงเดือนนั้นได้ $P_{15}=0.2868$ และ $PP_{15}=1.1779$ ล้าน การคืนก่อนจึงเป็น $1.1779/(0.2868+1.1779)=80.4\%$ ของเงินต้นที่กลับมาในเดือนนั้น ถ้ารวมครบ 357 เดือน เงินต้น 65.9% ของ \$400 ล้านมาจากการคืนก่อน (โค้ดท้ายหน้าเดินครบทุกเดือนและพิมพ์ตัวเลขเหล่านี้)

ตรวจเองใน 10 วินาที: $400\times0.0006691\approx0.268$ ใกล้กับ $PP_1=0.2675$ เพราะเงินต้นที่หักออกก่อนมีแค่ 0.27 จาก 400 และทุกช่องของเดือนแรกตรงกับ workbook ถึงทศนิยมที่สี่

ทำไมต้องคิดค่างวดใหม่ทุกเดือน? บ้านที่คืนก่อนกำหนดออกจาก pool ไปทั้งหลัง บ้านที่เหลือยังจ่ายค่างวดเดิมของตัวเอง ค่างวดรวมของ pool จึงหดตามสัดส่วนของหนี้ที่ยังไม่ถูกคืนก่อน ลองเช็กที่เดือนที่ 30 หลังผ่านไป 29 เดือน สัดส่วนที่ยังไม่ถูกคืนก่อนคือผลคูณของส่วนที่รอดทุกเดือน $\prod_{t=1}^{29}(1-\mathrm{SMM}_t)=0.915362$ ค่างวดรวมจึงเป็น $2.9759\times0.915362=2.7240$ ซึ่งตรงกับค่างวดที่คิดใหม่จากหนี้ต้นเดือนที่ 30 และงวดที่เหลือพอดี

ขั้นที่ 4 — average life: เงินต้นกลับมาเฉลี่ยเมื่อไร

ถ้าเดินแบบหนึ่งเดือนข้างบนซ้ำจนครบ 357 เดือน จะได้เงินต้นที่กลับมาในทุกเดือน $P_t+PP_t$ คำถามต้นหน้าคือเงินต้นกลับมาโดยเฉลี่ยเมื่อไร เราจึงหาค่าเฉลี่ยของเดือน $t$ โดยให้เดือนที่เงินต้นกลับมามากมีน้ำหนักมาก แล้วหารด้วย 12 ให้เป็นปี ค่าเฉลี่ยนี้เรียกว่า average life (AL)

\[ \begin{aligned} \mathrm{AL}&=\frac{\sum_t t\,(P_t+PP_t)}{12\sum_t(P_t+PP_t)},\\ \mathrm{AL}(0\ \mathrm{PSA})&=20.38,\\ \mathrm{AL}(50\ \mathrm{PSA})&=15.13,\\ \mathrm{AL}(100\ \mathrm{PSA})&=11.67,\\ \mathrm{AL}(200\ \mathrm{PSA})&=7.69,\\ \mathrm{AL}(300\ \mathrm{PSA})&=5.64. \end{aligned} \]

ตัวหาร $\sum_t(P_t+PP_t)$ คือเงินต้นทั้งหมด \$400 ล้าน เพราะทุกดอลลาร์ต้องกลับมาสักเดือน น้ำหนัก $(P_t+PP_t)/400$ จึงรวมกันได้หนึ่ง ลองนึกว่าเงินต้นแต่ละดอลลาร์เป็นก้อนมวลที่วางอยู่บนไม้บรรทัดเวลา AL คือจุดที่ไม้บรรทัดนั้นสมดุลพอดี

ตัวเลขห้าตัวได้จากการเดินครบ 357 เดือนที่แต่ละความเร็ว แล้วใส่ลงสูตร (โค้ดท้ายหน้าคำนวณซ้ำได้) ที่ 0 PSA คือตารางผ่อนล้วน ได้ 20.38 ปี ตรงกับที่ผู้ขายต้นหน้าตอบ ที่ 100 PSA เหลือ 11.67 ปี ตรงกับ workbook และที่ 200 PSA เหลือ 7.69 ปี ความเร็วยิ่งสูง AL ยิ่งสั้นเสมอ เพราะความเร็วแค่ดึงเงินต้นก้อนเดิมมาข้างหน้า ไม่ได้เพิ่มเงินต้นเลย

ผลคือความเสี่ยงสองทิศ ถ้าอัตราดอกเบี้ยลง คนแห่กู้ใหม่ เงินต้นกลับเร็วในวันที่เอาไปลงทุนต่อได้แค่อัตราต่ำ เรียกว่า contraction risk ถ้าอัตราขึ้น ไม่มีใครกู้ใหม่ เงินต้นค้างอยู่นานในวันที่อยากได้คืนไปลงทุนที่อัตราสูง เรียกว่า extension risk

ขั้นที่ 5 — PO และ IO เมื่อยังไม่มีการคืนก่อนกำหนด

ขั้นนี้ถามคำถามใหม่ ถ้าตัด pass-through เป็นสองชิ้น ชิ้นหนึ่งได้เงินต้นอย่างเดียว เรียกว่า principal-only (PO) อีกชิ้นได้ดอกเบี้ยอย่างเดียว เรียกว่า interest-only (IO) สองชิ้นนี้มีมูลค่าวันนี้เท่าไร ทำไมต้องตัด? เพราะความเร็วการคืนก่อนกระทบสองชิ้นนี้ในทิศตรงข้ามกัน การดูทีละชิ้นจึงเห็นผลของความเร็วชัดที่สุด เริ่มจากกรณีง่ายที่สุดก่อน คือไม่มีใครคืนก่อนเลย ซึ่งมีสูตรปิด

ใช้สินเชื่อก้อนเดียวจากตารางผ่อนของสินเชื่อบ้าน ของที่รู้มีดังนี้

  • ยอดกู้ \$100,000 อัตรา 8.125% ต่อปี ผ่อน $n=360$ งวด อัตราต่อเดือน $r=0.08125/12=0.0067708$
  • ค่างวด $A=\$742.49718$ ดอกเบี้ยงวดแรก $100{,}000\times0.08125/12=\$677.08333$ เงินต้นงวดแรกจึงเป็น $P_1=742.49718-677.08333=\$65.41385$
  • เงินต้นแต่ละงวดโตทบต้น $P_k=P_1(1+r)^{k-1}$
  • เงินแต่ละงวดคิดลดเป็นมูลค่าวันนี้ด้วยอัตรา $r_f$ ต่อเดือน
\[ \begin{aligned} V_{PO}&=\sum_{k=1}^{n}\frac{P_1(1+r)^{k-1}}{(1+r_f)^k}\\ &=P_1\,\frac{(1+r_f)^n-(1+r)^n}{(r_f-r)(1+r_f)^n}. \end{aligned} \]

กรณีที่ง่ายที่สุดคือคิดลดด้วยอัตราของสินเชื่อเอง $r_f=r$ ซึ่งให้ตัวเลขดังนี้ ($D$ คือ duration เป็นปี อธิบายด้านล่าง)

\[ \begin{aligned} V_{PO}&=\frac{n\,P_1}{1+r}=\frac{360\times65.41385}{1.0067708}\\ &=23{,}390.61,\\ V_{IO}&=100{,}000-V_{PO}\\ &=76{,}609.39,\\ D_{PO}&=\frac{1+2+\cdots+n}{12\,n}\\ &=\frac{n+1}{24}=\frac{361}{24}=15.04,\\ D_{\rm loan}&=\frac{\sum_k k\,A(1+r)^{-k}}{12\times100{,}000}\\ &=9.49,\\ D_{IO}&=\frac{100{,}000\,D_{\rm loan}-V_{PO}D_{PO}}{V_{IO}}\\ &=7.80. \end{aligned} \]

เงินต้นแต่ละงวดโตด้วย $1+r$ แต่ถูกคิดลดด้วย $1+r_f$ แต่ละพจน์จึงเท่ากับพจน์ก่อนคูณ $(1+r)/(1+r_f)$ ผลรวมจึงเป็นอนุกรมเรขาคณิต และใช้สูตรผลรวมของอนุกรมเรขาคณิตได้เลย

จุดที่สะดุดคือกรณี $r_f=r$ สูตรผลรวมมี $r_f-r$ อยู่ที่ตัวหาร จึงใส่ตรง ๆ ไม่ได้ แต่ย้อนไปดูอนุกรมเดิมก็จบ เงินต้นโตด้วยอัตราเดียวกับที่ถูกคิดลด ทุกพจน์จึงเหลือ $P_1/(1+r)$ เท่ากันหมด $n$ พจน์รวมกันได้ $nP_1/(1+r)$ ส่วน IO ไม่ต้องรวมทีละงวด เพราะเงินของสินเชื่อทั้งก้อนคือเงินต้นบวกดอกเบี้ย และถ้าคิดลดด้วยอัตราของสินเชื่อเอง มูลค่าทั้งก้อนเท่ากับหนี้ \$100,000 พอดี IO จึงเท่ากับ \$100,000 ลบ PO

duration ในที่นี้คือเวลาเฉลี่ยที่เงินกลับมา โดยถ่วงด้วยมูลค่าวันนี้ของเงินแต่ละก้อน วัดเป็นปี PO มีมูลค่าวันนี้เท่ากันทุกเดือน ($P_1/(1+r)$ ทุกพจน์) จึงได้ค่าเฉลี่ยธรรมดาของเดือน 1 ถึง 360 แล้วหารด้วย 12

IO หาตรง ๆ ยากกว่า จึงอ้อมผ่านสินเชื่อทั้งก้อน สินเชื่อจ่ายค่างวด $A$ เท่ากันทุกเดือน รวม 360 พจน์ของ $D_{\rm loan}$ ได้ 9.49 ปี (ตัวหารคือมูลค่ารวม \$100,000) เงินของสินเชื่อแต่ละเดือนคือเงินของ PO บวกเงินของ IO ผลรวมเวลาถ่วงมูลค่าจึงแยกเป็นสองส่วนได้ $100{,}000\,D_{\rm loan}=V_{PO}D_{PO}+V_{IO}D_{IO}$ แก้สมการนี้หา $D_{IO}$ ได้ 7.80 ปี IO สั้นกว่า PO ราวครึ่งหนึ่ง เพราะดอกเบี้ยช่วงแรกสูง เงินก้อนใหญ่ของ IO จึงมาช่วงต้น

ทีนี้ลองคิดลดด้วย 0.5% ต่อเดือนแทน (ต่ำกว่าอัตราของสินเชื่อ) สูตรผลรวมให้ PO \$32,680.56 มูลค่าขึ้น $32{,}680.56/23{,}390.61-1=39.7\%$ ส่วน IO หาแบบเดิม มูลค่าทั้งก้อนคือค่างวดคูณ annuity factor (ผลรวมของตัวคิดลดทั้ง 360 งวด) $742.49718\times(1-1.005^{-360})/0.005=\$123{,}842.30$ ลบ PO ได้ $123{,}842.30-32{,}680.56\approx\$91{,}161.75$ ขึ้นแค่ $91{,}161.75/76{,}609.39-1=19.0\%$ ชิ้นที่รอเงินนานกว่า (duration ยาวกว่า) จึงไวต่ออัตรามากกว่า แต่ทั้งหมดนี้ยังเป็นโลกที่ไม่มีใครคืนก่อน

ขั้นที่ 6 — ใส่ความเร็วเข้าไป: PO กับ IO แย่งมูลค่ากัน

ตอนนี้ใส่การคืนก่อนกำหนดกลับเข้าไป แล้วตัด pool \$400 ล้านในโจทย์เป็น PO กับ IO แบบเดียวกัน ทั้งสองชิ้นคิดลดด้วยอัตราเดียวกับที่ผู้ลงทุนได้ คือ 7.50% ต่อปีทบรายเดือน หรือ $i=0.075/12=0.00625$ ต่อเดือน ทำไมเลือกอัตรานี้? เพราะมันทำให้มูลค่ารวมไม่ขึ้นกับความเร็ว (จะเห็นด้านล่าง) สิ่งที่เปลี่ยนไปจึงเป็นผลของความเร็วล้วน ๆ

ผู้ถือได้ดอกเบี้ยเดือน $t$ เท่ากับ $iB_{t-1}$ เหมือนเดิม แต่ตอนนี้ $B_{t-1}$ ไม่มีสูตรปิดแล้ว ต้องเดินทีละเดือนแบบขั้นที่ 3 เราจึงคิดมูลค่าแบบย้อนจากเดือนสุดท้ายกลับมา ให้ $V_t$ คือมูลค่าของ pass-through ทั้งก้อน ณ ปลายเดือน $t$ หลังจ่ายเงินของเดือนนั้นแล้ว ยืนอยู่ปลายเดือน $t-1$ ผู้ถือจะได้เงินของเดือน $t$ คือดอกเบี้ย $iB_{t-1}$ กับเงินต้น $P_t+PP_t$ แล้วยังถือของที่มีค่า $V_t$ ต่อ ทั้งหมดนี้คิดลดกลับหนึ่งเดือนด้วยการหารด้วย $1+i$

\[ \begin{aligned} V_{t-1}&=\frac{iB_{t-1}+P_t+PP_t+V_t}{1+i},\\ V_t=B_t\ \Rightarrow\ V_{t-1}&=\frac{iB_{t-1}+B_{t-1}}{1+i}\\ &=B_{t-1},\\ V_{PO}(0)&=104.22,\\ V_{IO}(0)&=295.78,\\ V_{PO}(100)&=195.09,\\ V_{IO}(100)&=204.91,\\ V_{PO}(200)&=244.99,\\ V_{IO}(200)&=155.01. \end{aligned} \]

การย้อนทีละเดือนคือการคิดลดโดยไม่ต้องรู้สูตรปิดของ $B_t$ เริ่มที่เดือนสุดท้าย หนี้เป็นศูนย์และมูลค่าก็เป็นศูนย์ จึงจริงว่า $V_t=B_t$ ที่ปลายทาง จุดสำคัญคือ เงินต้นที่จ่ายในเดือนหนึ่งบวกหนี้ที่เหลือ ต้องเท่ากับหนี้ต้นเดือน $P_t+PP_t+B_t=B_{t-1}$ ไม่ว่าเงินต้นจะมาตามตารางหรือมาก่อนกำหนด ถ้า $V_t=B_t$ ตัวเศษจึงเป็น $(1+i)B_{t-1}$ หารด้วย $1+i$ แล้วได้ $V_{t-1}=B_{t-1}$ ย้อนแบบนี้ทีละเดือนจนถึงวันนี้ มูลค่าทั้งก้อนจึงเท่ากับหนี้ค้าง \$400 ล้าน ไม่ว่าความเร็วจะเป็นเท่าไร

ตัวเลขหกตัวได้จากการแยกคิดลดสองชิ้นที่ 0, 100 และ 200 PSA (โค้ดท้ายหน้า) ตัวในวงเล็บคือความเร็วเป็น PSA PO รับเงินต้น $P_t+PP_t$ และ IO รับดอกเบี้ย $iB_{t-1}$ ทุกคู่รวมกันได้ 400 เช่น $195.09+204.91=400$ ความเร็วจึงไม่ได้สร้างหรือทำลายมูลค่ารวม มันแค่ย้ายมูลค่าระหว่างสองชิ้น

จาก 100 เป็น 200 PSA PO ได้เพิ่ม $244.99-195.09=\$49.90$ ล้าน หรือ $49.90/195.09=+25.6\%$ เพราะได้เงินต้นเร็วขึ้น IO เสีย $204.91-155.01=\$49.90$ ล้าน หรือ $49.90/204.91=-24.4\%$ เพราะหนี้ที่ใช้คิดดอกเบี้ยหายเร็วขึ้น

IO จึงเป็นตราสารแปลก ราคามักลงเมื่ออัตราดอกเบี้ยลง ซึ่งกลับทางกับพันธบัตรทั่วไป เพราะอัตราลงทำให้คนกู้ใหม่ หนี้ที่ IO ใช้คิดดอกเบี้ยจึงหายเร็ว เมื่ออัตราขึ้น IO ได้ดอกเบี้ยนานขึ้นเพราะคนคืนช้าลง แต่เงินเหล่านั้นก็ถูกคิดลดหนักขึ้น ผลสุทธิจึงขึ้นหรือลงก็ได้

ขั้นที่ 7 — ความเร็วมาจากไหน: แบบจำลองของ Richard and Roll

PSA ไม่รู้จักอัตราดอกเบี้ย แต่ผู้กู้รู้ ถ้าอัตราในตลาดลดลงมาก ผู้กู้จะกู้ใหม่ ความเร็วจึงควรขึ้นกับอัตรา การสร้างแบบจำลองแบบนี้ยาก เพราะข้อมูลการคืนก่อนที่เปิดเผยมีน้อย แบบที่เปิดเผยสูตรและใช้สอนกันมากคือของ Richard และ Roll (1989) แบบนี้คูณตัวคูณสี่ตัวเข้าด้วยกัน แต่ละตัวแทนเหตุผลหนึ่งข้อที่คนคืนก่อน

  • $RI$ (refinancing incentive) คือแรงจูงใจกู้ใหม่ ขึ้นกับส่วนต่าง $\Delta$ = WAC ของ pool ลบอัตราพันธบัตรรัฐบาลสหรัฐฯ อายุ 10 ปี (แบบจำลองใช้อัตรา 10 ปีแทนอัตราสินเชื่อบ้านใหม่ เพราะสองอัตรานี้ขยับไปด้วยกัน) ถ้าผู้กู้จ่ายอยู่สูงกว่าอัตราในตลาดมาก การกู้ใหม่ก็คุ้ม
  • $AGE$ คือผลของอายุสินเชื่อ ไต่ขึ้น 30 เดือนแบบ PSA
  • $MM$ (monthly multiplier) คือฤดูกาลย้ายบ้าน
  • $BM$ (burnout multiplier) คือผลของ burnout ซึ่งอธิบายด้านล่าง

ตัวอย่างตัวเลขของ $RI$: ถ้าอัตรา 10 ปีเท่ากับ WAC พอดี ส่วนต่างคือ $\Delta=0$ ถ้าอัตรา 10 ปีอยู่ที่ 6% ส่วนต่างคือ $\Delta=8.125\%-6\%=2.125\%$

\[ \begin{aligned} \mathrm{CPR}&=RI\cdot AGE\cdot MM\cdot BM,\\ RI(\Delta)&=0.28+0.14\arctan x,\\ x&=-8.57+430\,\Delta,\\ AGE&=\min(1,\ a/30),\\ BM&=0.3+0.7\,B_{t-1}/B_0,\\ RI(0)&=0.28+0.14\arctan(-8.57)\\ &=0.28-0.14(1.4546)=7.64\%,\\ RI(2.125\%)&=0.28+0.14\arctan(0.5675)\\ &=0.28+0.14(0.5162)=35.23\%,\\ RI_{\min}&=0.28-0.14(\pi/2)=6.01\%,\\ RI_{\max}&=0.28+0.14(\pi/2)=49.99\%. \end{aligned} \]

$RI$ เป็นรูปตัว S เพราะ arctan มีค่าอยู่ระหว่าง $-\pi/2$ ถึง $\pi/2$ เสมอ $RI$ จึงมีพื้นที่ 6.01% และเพดานที่ 49.99% ไม่ว่าส่วนต่างจะเป็นเท่าไร ที่ $\Delta=2.125\%$ ค่า $x=-8.57+430\times0.02125=0.5675$ จุดกลางของตัว S คือที่ $x=0$ ซึ่งคือ $\Delta=8.57/430=1.99\%$

ความหมายคือ ถ้าส่วนต่างต่ำกว่าราว 2 จุด การกู้ใหม่ยังไม่คุ้ม ผู้กู้ส่วนใหญ่ไม่กู้ใหม่ เหลือแต่คนที่ย้ายบ้าน ความเร็วจึงอยู่ราว 6 ถึง 8% ต่อปี ถ้าส่วนต่างเกินนั้น คนแห่กู้ใหม่ และความเร็วพุ่งเข้าหาเพดาน

$AGE$ คือการไต่ 30 เดือนแบบเดียวกับ PSA $MM$ คือฤดูกาล คนย้ายบ้านกันมากในฤดูร้อน ตัวอย่างในหน้านี้ตั้ง $MM=1$ ทุกเดือน $BM$ คือ burnout ผู้กู้ที่กู้ใหม่ได้ง่ายออกจาก pool ไปแล้ว คนที่ยังเหลือจึงคืนช้าลง แม้แรงจูงใจจะเท่าเดิม $BM$ วัดเรื่องนี้จากสัดส่วนหนี้ที่ยังเหลือ $B_{t-1}/B_0$ pool ใหม่มี $BM=0.3+0.7\times1=1$ ส่วน pool ที่หดเกือบหมดมี $BM$ ใกล้ 0.3 burnout ทำให้เงินของแต่ละเดือนขึ้นกับว่าอัตราเคยเดินมาอย่างไร ไม่ใช่แค่อัตราวันนี้

ขั้นที่ 8 — ราคาที่ขึ้นยากแต่ลงง่าย: effective duration และ convexity

สูตร duration และ convexity ของพันธบัตรธรรมดาสมมติว่าเงินสดที่จะได้รับคงที่ แล้วถามว่าราคาเปลี่ยนเท่าไรเมื่ออัตราคิดลดขยับ แต่เงินของ pass-through เปลี่ยนตามอัตรา เพราะผู้กู้คืนเร็วขึ้นเมื่ออัตราลง สูตรเดิมจึงใช้ไม่ได้ วิธีที่ใช้แทนคือคิดราคาใหม่ทั้งชุดที่อัตราขยับลงและขยับขึ้น โดยให้ความเร็วเปลี่ยนตามอัตราด้วย แล้ววัดความชันและความโค้งจากสามราคา ผลที่ได้เรียกว่า effective duration และ effective convexity

โจทย์ให้อะไรมาบ้าง:

  • pool เดียวกับโจทย์ (\$400 ล้าน WAC 8.125% pass-through rate 7.50% เหลือ 357 งวด) บอกราคาเป็นดอลลาร์ต่อหนี้ \$100
  • คิดลดด้วยอัตรา $y$ ต่อปี ทบรายเดือน เริ่มที่ $y=7\%$ แล้วขยับ $\Delta y=0.5\%$ ลงไปที่ 6.5% และขึ้นไปที่ 7.5%
  • สมมติว่าอัตรา 10 ปีขยับเท่ากับ $y$ ส่วนต่างในแบบจำลองตัว S จึงเป็น $\Delta=8.125\%-y$
  • CPR ช่วงคงที่ (หลังอายุ 30 เดือน) คือ $RI(8.125\%-y)$ ช่วงแรกไต่ 30 เดือนแบบ PSA ไม่มี burnout ($BM=1$) และ $MM=1$

ขั้นแรก หา CPR ช่วงคงที่ที่สามอัตรา ด้วยสูตร $RI$ จากขั้นที่ 7 เช่นที่ $y=6.5\%$ ส่วนต่างคือ $8.125\%-6.5\%=1.625\%$ และ $x=-8.57+430\times0.01625=-1.5825$ อีกสองอัตราทำแบบเดียวกัน ส่วนต่างที่ 7% คือ 1.125% และที่ 7.5% คือ 0.625%

\[ \begin{aligned} RI(1.625\%)&=0.28+0.14\arctan(-1.5825)\\ &=13.90\%,\\ RI(1.125\%)&=0.28+0.14\arctan(-3.7325)\\ &=9.67\%,\\ RI(0.625\%)&=0.28+0.14\arctan(-5.8825)\\ &=8.37\%. \end{aligned} \]

ขั้นต่อมา ใส่แต่ละความเร็วเข้าการเดินทีละเดือนแบบขั้นที่ 3 แล้วคิดลดเงินทุกเดือนด้วย $y$ ของจุดนั้น (โค้ดท้ายหน้าทำขั้นนี้) ได้สามราคา $P_-$, $P_0$ และ $P_+$

จากสามราคา เราประมาณอนุพันธ์ด้วยผลต่าง duration คือความชันของราคาเทียบกับอัตรา หารด้วยราคา ความชันประมาณได้จากผลต่างของราคาสองข้าง หารด้วยระยะห่าง $2\Delta y$ เราเขียน $P_--P_+$ (ราคาตอนอัตราต่ำลบราคาตอนอัตราสูง) เพื่อให้ duration เป็นบวก เพราะราคาลงเมื่ออัตราขึ้น convexity คือความชันที่เปลี่ยนไป คือความชันฝั่งขวาลบความชันฝั่งซ้าย หารด้วย $\Delta y$ อีกครั้ง แล้วหารด้วยราคา ใช้ราคาทศนิยมสามตำแหน่ง เพราะ convexity ไวต่อการปัดเศษมาก

\[ \begin{aligned} P_-&=105.005\quad(y=6.5\%),\\ P_0&=102.927\quad(y=7\%),\\ P_+&=100.000\quad(y=7.5\%),\\ D_{\rm eff}&=\frac{P_--P_+}{2P_0\,\Delta y}\\ &=\frac{105.005-100.000}{2(102.927)(0.005)}\\ &=4.86,\\ C_{\rm eff}&=\frac{P_++P_--2P_0}{P_0(\Delta y)^2}\\ &=\frac{205.005-205.854}{102.927(0.005)^2}\\ &=-330. \end{aligned} \]

คำตอบ: $D_{\rm eff}=4.86$ ปี และ $C_{\rm eff}=-330$ ติดลบ ดูจากราคาตรง ๆ ก็เห็น อัตราลง 0.5 จุด ราคาขึ้นแค่ $105.005-102.927=2.08$ แต่อัตราขึ้น 0.5 จุด ราคาลง $102.927-100.000=2.93$ ขาขึ้นเล็กกว่าขาลง นี่คือความหมายของ convexity ติดลบ

เทียบกับพันธบัตรธรรมดา ถ้าตรึงความเร็วไว้ที่ CPR 9.67% ทั้งสามจุด เงินสดจะคงที่แบบพันธบัตร ราคาที่ 7% ยังเป็น 102.927 เพราะใช้ความเร็วเดียวกัน ราคาที่ 7.5% ยังเป็น 100.000 แต่ราคาที่ 6.5% กลายเป็น 106.007 แทน 105.005 ตัวหารเหมือนเดิม คือ $2P_0\,\Delta y=1.02927$ และ $P_0(\Delta y)^2=0.0025732$

\[ \begin{aligned} D_{\rm eff}&=\frac{106.007-100.000}{1.02927}=5.84,\\ C_{\rm eff}&=\frac{206.007-205.854}{0.0025732}=+59.5. \end{aligned} \]

การที่ผู้กู้เร่งคืนเมื่ออัตราลง จึงกินกำไรขาขึ้นไป $106.007-105.005=1.00$ ต่อหนี้ 100 ส่วนขาลงที่ 7.5% ราคาเท่ากันทั้งสองแบบ เพราะที่อัตราคิดลดเท่ากับ pass-through rate ความเร็วไม่มีผลต่อราคาเลย ตามการย้อนทีละเดือนในขั้นที่ 6

ตรวจเองใน 10 วินาที: $P_++P_-=205.005$ น้อยกว่า $2P_0=205.854$ ตัวเศษของ $C_{\rm eff}$ จึงติดลบ convexity จึงติดลบ

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

หาร CPR ด้วย 12: ความเร็วรายเดือนจะต่ำไปทุกเดือน ที่ CPR 6% วิธีผิดได้ $0.06/12=0.5\%$ ต่อเดือน ค่าที่ถูกคือ $1-0.94^{1/12}=0.5143\%$ วิธีผิดจึงต่ำไป $1-0.5/0.5143=2.8\%$ ของค่าที่ถูกในทุกเดือน และทบกลับเป็นปีได้แค่ $1-0.995^{12}=5.84\%$ ไม่ใช่ 6%

ไม่คิดค่างวดใหม่: ถ้าใช้ค่างวดตอนเริ่มไปตลอด เงินต้นตามตารางจะสูงเกินจริง ตัวอย่างคือ pool ใหม่ \$100 ล้าน อัตรา 6% ต่อปี 360 งวด ที่ 100 PSA (pool เดียวกับโจทย์ข้อ 2 ท้ายหน้า) ค่างวดตอนเริ่มคือ $100{,}000{,}000\times0.005/(1-1.005^{-360})=\$599{,}550.53$ ในเดือนที่ 30 ค่างวดที่คิดใหม่จากหนี้ที่เหลือคือ \$556,802.62 (โจทย์ข้อ 2 คำนวณให้ดู) ถ้าใช้ค่างวดเดิม เงินต้นตามตารางจะเกินไป $599{,}550.53-556{,}802.62\approx\$42{,}748$ ในเดือนนั้นเดือนเดียว และความผิดนี้ทบต่อไปทุกเดือน

ลืมอายุของ pool: ถ้านับอายุจากวันที่ซื้อแทนวันปล่อยกู้ การคืนก่อนช่วงแรกจะต่ำเกินจริง pool ในโจทย์ปล่อยกู้มาแล้ว 3 เดือน เดือนแรกที่ถือจึงเป็นอายุ 4 ได้ CPR $6\%\times4/30=0.8\%$ และ SMM 0.0006691 ถ้านับเป็นอายุ 1 จะได้ CPR $6\%\times1/30=0.2\%$ และ SMM $1-0.998^{1/12}=0.0001668$ การคืนก่อนเดือนแรกจึงต่ำไป $0.0006691/0.0001668=4.0$ เท่า

ใช้ duration ของพันธบัตรกับ MBS: duration ที่คิดโดยตรึงเงินสดจะยาวเกินจริง ตัวอย่างในขั้นที่ 8 ให้ 5.84 ถ้าตรึงความเร็ว แต่ค่าที่ถูกคือ 4.86 คนที่ hedge (ขายพันธบัตรไว้เพื่อหักล้างความเสี่ยงเรื่องอัตรา) ด้วยตัวเลขแรก จะขายพันธบัตรมากเกินไป $5.84/4.86-1=20\%$ และเมื่ออัตราขยับไกล convexity ติดลบทำให้ขาดทุนทั้งสองทิศ

เสนอ yield โดยไม่บอกความเร็ว: yield ของ MBS ไม่มีความหมายถ้าไม่บอกว่าสมมติความเร็วเท่าไร yield คืออัตราคิดลดที่ทำให้มูลค่าของเงินสดเท่ากับราคาที่จ่าย และเงินสดของ MBS สร้างจากความเร็วที่สมมติ yield “7.5%” ที่ 100 PSA กับที่ 300 PSA จึงมาจากเงินสดคนละชุด เทียบกันตรง ๆ ไม่ได้

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะเทรด (desk) ที่ถือ MBS รายงานราคาพร้อมตารางความเร็วเสมอ เช่น average life ที่ 50, 100, 200 และ 300 PSA ซึ่งสำหรับ pool นี้คือ 15.13, 11.67, 7.69 และ 5.64 ปี (จากขั้นที่ 4) โต๊ะยังคิด effective duration ใหม่ทุกวัน เพราะมันเปลี่ยนตามอัตรา

สมมติว่าโต๊ะ hedge ไว้ด้วยการขายพันธบัตร เมื่ออัตราลง ผู้กู้คืนเร็วขึ้น duration ของ MBS จึงหด โต๊ะต้องซื้อพันธบัตรคืนบางส่วนเพื่อให้ hedge ยังพอดี เมื่ออัตราขึ้น duration ยืด โต๊ะต้องขายพันธบัตรเพิ่ม โต๊ะจึงซื้อหลังราคาพันธบัตรขึ้นแล้ว และขายหลังราคาลงแล้ว เสียเงินเล็กน้อยทุกครั้งที่ปรับ การปรับ hedge ตามหลังตลาดแบบนี้คือต้นทุนของการขาย option ให้ผู้กู้ ผลตอบแทนที่ MBS ให้เกินพันธบัตรรัฐบาลคือค่าตอบแทนของต้นทุนนี้

yield ที่เสนอกันมักแปลงเป็นแบบทบครึ่งปี เพื่อให้เทียบกับพันธบัตรรัฐบาลสหรัฐฯ ซึ่งจ่ายดอกเบี้ยทุกครึ่งปีได้ เรียกว่า bond-equivalent yield เช่น 7.5% ต่อปีทบรายเดือน คือเดือนละ $0.075/12=0.625\%$ หกเดือนทบกันได้ $1.00625^6-1=3.809\%$ ต่อครึ่งปี คูณ 2 เป็นอัตราต่อปีแบบทบครึ่งปี $2\times3.809\%=7.62\%$

แต่ตัวเลขที่ตลาดใช้เทียบ MBS กันจริง ๆ คือ option-adjusted spread (OAS) วิธีคิดมีสี่ขั้น

  • สุ่มเส้นทางอัตราดอกเบี้ยในอนาคตหลายพันเส้น ด้วยแบบจำลองอัตราที่ปรับให้ตรงตลาด
  • ในแต่ละเส้น ใช้ความเร็วแบบ Richard and Roll สร้างเงินสดของ pool ทีละเดือน
  • คิดลดเงินของแต่ละเส้นด้วยอัตราของเส้นนั้นบวกส่วนต่างคงที่ค่าหนึ่ง แล้วเฉลี่ยทุกเส้นแบบMonte Carlo
  • ปรับส่วนต่างนั้นจนค่าเฉลี่ยเท่ากับราคาตลาด ส่วนต่างที่ได้คือ OAS

ทำไมต้องลำบากขนาดนี้? เพราะ burnout ทำให้เงินของแต่ละเดือนขึ้นกับเส้นทางที่อัตราเดินมา จึงไม่มีสูตรปิด และการคำนวณใช้เวลามาก

โจทย์ตรวจความเข้าใจ

1. pool หนึ่งคืนก่อนกำหนดที่ 200 PSA และอายุเกิน 30 เดือนแล้ว จึงอยู่ในช่วงที่ CPR แบน SMM ของ pool นี้เท่าไร และถ้ามีคนเอา CPR หารด้วย 12 แทน ทบกลับครบปีจะได้ความเร็วต่อปีเท่าไร?

เฉลย

200 PSA แบนที่สองเท่าของ 6% แล้วใช้สูตร SMM จากขั้นที่ 1

\[\begin{aligned}\mathrm{CPR}&=2\times6\%=12\%,\\\mathrm{SMM}&=1-(1-0.12)^{1/12}\\&=1-0.88^{1/12}=1.0596\%.\end{aligned}\]

ถ้าหาร 12 จะได้ $12\%/12=1\%$ ต่อเดือน ทบครบปีได้ $1-0.99^{12}=11.36\%$ ต่ำกว่า 12% อยู่ $12-11.36=0.64$ จุด

2. pool ใหม่ (เพิ่งปล่อยกู้ อายุเริ่มที่ 1 เดือน) หนี้ \$100 ล้าน อัตรา 6% ต่อปี ผ่อน 360 งวด คืนก่อนที่ 100 PSA เดินตารางมาจนถึงต้นเดือนที่ 30 หนี้เหลือ $B_{29}=\$89{,}992{,}477.55$ (ตัวเลขนี้ให้มา) ในเดือนที่ 30 เงินต้นตามตาราง และเงินคืนก่อนกำหนดเป็นเท่าไร?

เฉลย

อัตราต่อเดือนคือ $r=0.06/12=0.005$ งวดที่เหลือนับรวมเดือนนี้คือ $360-30+1=331$ งวด เดินตามลำดับของขั้นที่ 3

\[\begin{aligned}A_{30}&=\frac{89{,}992{,}477.55\times0.005}{1-1.005^{-331}}\\&=\$556{,}802.62,\\I_{30}&=0.005\times89{,}992{,}477.55\\&=\$449{,}962.39,\\P_{30}&=556{,}802.62-449{,}962.39\\&=\$106{,}840.23,\\B_{29}-P_{30}&=89{,}992{,}477.55-106{,}840.23\\&\approx\$89{,}885{,}637.31.\end{aligned}\]

pool นี้อายุ 30 เดือนพอดี CPR จึงเป็น 6% และ SMM $=1-0.94^{1/12}=0.005143013$ จากขั้นที่ 1 (เก็บทศนิยมไว้หลายตำแหน่ง เพราะคูณกับหนี้เกือบ 90 ล้าน)

\[\begin{aligned}PP_{30}&=89{,}885{,}637.31\times0.005143013\\&=\$462{,}282.99,\\\frac{PP_{30}}{P_{30}}&=\frac{462{,}282.99}{106{,}840.23}=4.33.\end{aligned}\]

เงินคืนก่อนกำหนดมากกว่าเงินต้นตามตารางถึง 4.33 เท่า

3. ใช้แบบจำลองตัว S ของ Richard and Roll ในขั้นที่ 7 สมมติว่าอัตรา 10 ปีลดลงจนส่วนต่าง WAC ลบอัตรา 10 ปีเป็น 1.5 จุด $RI$ เท่าไร ถ้า pool ใหม่อยู่ในเดือนที่ 15 (อายุ 15 เดือน) หนี้หดเหลือ 95% ของตอนเริ่ม และไม่มีผลฤดูกาล ($MM=1$) CPR เป็นเท่าไร?

เฉลย
\[\begin{aligned}x&=-8.57+430\times0.015=-2.12,\\RI&=0.28+0.14\arctan(-2.12)\\&=0.28-0.14(1.1300)=12.18\%,\\AGE&=\min(1,\ 15/30)=0.5,\\BM&=0.3+0.7\times0.95=0.965,\\\mathrm{CPR}&=0.1218\times0.5\times1\times0.965\\&=5.88\%.\end{aligned}\]

ถ้าส่วนต่างเป็น 2.125 จุด $RI=35.23\%$ (จากขั้นที่ 7) CPR จะเป็น $0.3523\times0.5\times0.965=17.0\%$ ส่วนต่างเพิ่มแค่ $2.125-1.5=0.625$ จุด แต่ความเร็วเพิ่มเป็น $17.0/5.88=2.9$ เท่า เพราะช่วงนี้อยู่ตรงส่วนที่ชันที่สุดของตัว S

เปิดดูโค้ด 
const {min, atan} = Math;
function num(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(`${name} must be a finite number`);
  return x;
}

// Monthly rate that compounds to the annual CPR.
function smm(cpr) {
  if (!(num('cpr', cpr) >= 0 && cpr < 1)) throw new RangeError('cpr must be in [0, 1)');
  return 1 - (1 - cpr) ** (1 / 12);
}
// PSA benchmark: k times min(0.2% per month of age, 6%).
function psaCPR(age, k) {
  if (!Number.isInteger(age) || age < 1) throw new RangeError('age must be a whole month, at least 1');
  if (!(num('k', k) >= 0)) throw new RangeError('k must not be negative');
  return k * min(0.002 * age, 0.06);
}
// Richard and Roll refinancing multiplier for gap = WAC minus the 10-year rate.
function refiIncentive(gap) { return 0.28 + 0.14 * atan(-8.57 + 430 * num('gap', gap)); }

// Pool month by month: payment recomputed on what is left, scheduled principal first, then prepayment.
function passThrough({B = 400, wac = 0.08125, pt = 0.075, N = 360, season = 3, cprAt}) {
  if (!(num('pt', pt) > 0 && pt <= num('wac', wac))) throw new RangeError('pass-through rate must be positive and at most the WAC');
  if (!Number.isInteger(season) || season < 0 || season >= N) throw new RangeError('season must be a whole month below N');
  const r = wac / 12, rows = [];
  for (let t = 1; t <= N - season && B > 1e-12; t++) {
    const n = N - season - t + 1, A = B * r / (1 - (1 + r) ** -n);
    const I = B * r, P = A - I, s = smm(cprAt(t + season)), PP = (B - P) * s;
    rows.push({t, A, I, net: pt / 12 * B, P, PP, prin: P + PP});
    B -= P + PP;
  }
  return rows;
}
function averageLife(rows) {
  let tw = 0, w = 0;
  for (const x of rows) { tw += x.t * x.prin; w += x.prin; }
  return tw / (12 * w);
}
// PO and IO values at an annual yield y compounded monthly.
function strips(rows, y) {
  let po = 0, io = 0;
  for (const x of rows) { const d = (1 + num('y', y) / 12) ** -x.t; po += x.prin * d; io += x.net * d; }
  return {po, io};
}
const psaPool = k => passThrough({cprAt: a => psaCPR(a, k)});
// Price per 100 when the plateau speed follows the refinancing incentive at yield y.
function price(y, plateau = refiIncentive(0.08125 - y)) {
  const v = strips(passThrough({cprAt: a => plateau * min(1, a / 30)}), y);
  return (v.po + v.io) / 4;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • CPR คือความเร็วการคืนก่อนต่อปี SMM คือต่อเดือน SMM ได้จากการทบ ไม่ใช่การหาร $\mathrm{SMM}=1-(1-\mathrm{CPR})^{1/12}$ CPR 6% จึงเป็น 0.5143% ต่อเดือน ไม่ใช่ 0.5%
  • PSA เป็นไม้บรรทัดของความเร็ว ไม่ใช่คำพยากรณ์ 100 PSA ไต่ขึ้นเดือนละ 0.2 จุดจนถึง 6% ที่อายุ 30 เดือน และอายุต้องนับจากวันปล่อยกู้
  • ในแต่ละเดือน ให้คิดค่างวดใหม่จากหนี้ที่เหลือ หักเงินต้นตามตารางก่อน แล้วคูณหนี้ที่เหลือด้วย SMM
  • average life ของ pool ในโจทย์คือ 20.38 ปีถ้าไม่มีใครคืนก่อน 11.67 ปีที่ 100 PSA และ 7.69 ปีที่ 200 PSA
  • ที่อัตราคิดลดเท่ากับ pass-through rate ความเร็วไม่เปลี่ยนมูลค่ารวม แต่ย้ายมูลค่าจาก IO ไป PO
  • เมื่อความเร็วตอบสนองต่ออัตรา อัตราขยับ 0.5 จุด ราคาขึ้นแค่ 2.08 แต่ลง 2.93 convexity จึงติดลบ (−330)
