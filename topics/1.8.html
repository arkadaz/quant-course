1.8 Continuous Random Variables and the Probability Density Function (PDF)

โอกาสของช่วงมาจากพื้นที่ใต้เส้น ไม่ใช่ความสูงที่จุดเดียว

วัดเวลารอรถของคน 1,000 คนแล้วแบ่งช่องละ 1 นาที ถ้าเปลี่ยนเป็นช่องละ 10 วินาที แท่งแต่ละแท่งจะสูงหรือต่ำลง — และโอกาสรวมเปลี่ยนไหม?

เฉลย: แท่งถูกหั่นละเอียดจนเตี้ยลงได้ แต่พื้นที่รวมยังต้องเท่าเดิม; ความสูงล้วน ๆ จึงไม่ใช่โอกาส เหมือนตัดพิซซ่าชิ้นเล็กแล้วอ้างว่าอาหารหายไป

Continuous Random Variable บอกผลลัพธ์ที่วัดละเอียดได้ไม่สิ้นสุด และ Probability Density Function (PDF) บอก density รอบค่า; เราใช้พื้นที่ใต้เส้นเพื่อหาโอกาสของช่วงค่า

Continuous Random Variable
Continuous Random Variable คือค่าที่วัดละเอียดบนเส้นจำนวนจริงได้ไม่รู้จบ เช่น ผลตอบแทนของสินทรัพย์
Probability Density Function (PDF)
Probability Density Function — เส้นโค้ง f(x) ที่บอก density ณ แต่ละจุด ไม่ใช่ความน่าจะเป็นตรง ๆ ความน่าจะเป็นจริงคือพื้นที่ใต้เส้นโค้ง
Cumulative Distribution Function (CDF)
CDF คือพื้นที่สะสมใต้เส้น PDF จากปลายซ้ายถึงจุดที่เลือก ใช้อ่าน probability ของช่วงและตรวจว่าพื้นที่รวมครบหนึ่ง
Mass vs Density
มวลความน่าจะเป็น เทียบกับ density — มวลคือ probability ก้อนจริง (0 ถึง 1) ส่วน density คือความสูงของกราฟ (พุ่งเกิน 1 ได้ถ้าสเกลแกนนอนแคบ)
narrow-interval approximation
ทางลัดสำหรับช่วงที่แคบมาก: เอา density แถวจุดนั้นคูณความกว้างของช่วง เพื่อประมาณ probability ของแถบเล็ก ๆ
volatility
ขนาดการแกว่งของ return ใช้ตั้งสเกลแกนนอนและบอกว่าค่าหนึ่งอยู่ไกลจากค่ากลางแค่ไหน

จาก histogram สู่เส้นโค้งเรียบ

สมมติว่าเราเก็บ daily return ของ QQQ 3,000 วัน ถ้าพล็อต histogram ด้วย 8 bins จะเห็นเพียงแท่งหยาบ ๆ พอเพิ่มเป็น 32 แล้ว 128 bins ขอบแท่งเริ่มตามรูปโค้งมากขึ้น เมื่อบีบความกว้างของแต่ละ bin เข้าใกล้ศูนย์ ขอบนั้นจะเข้าใกล้เส้น Probability Density Function (PDF) ซึ่งเขียนเป็น

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

การคิดโอกาสเป็นพื้นที่ใต้เส้นเป็นภาษาที่ใช้กับทุกอย่างที่วัดเป็นตัวเลขต่อเนื่อง

ใช้กับผลตอบแทน ราคา และอัตราดอกเบี้ย ซึ่งไม่ได้มาเป็นค่าแยกชิ้นเหมือนการทอยลูกเต๋า

ใช้ตอบคำถามแบบช่วง เช่นโอกาสที่ผลตอบแทนพรุ่งนี้จะอยู่ระหว่างลบสองถึงบวกสองเปอร์เซ็นต์

ใช้เป็นฐานของการตั้งราคา option ทุกสูตร เพราะราคาคือค่าเฉลี่ยของ payoff ซึ่งคำนวณด้วยการรวมพื้นที่ใต้เส้นแบบนี้

ที่มาที่ไป: เมื่อผลลัพธ์นับไม่ได้ วิธีนับแบบเดิมก็ใช้ไม่ได้

เครื่องมือในหัวข้อก่อนหน้าใช้ได้ดีเมื่อผลลัพธ์แยกเป็นค่า ๆ นับได้ เช่นชนะหรือแพ้ แต่ราคาและผลตอบแทนไม่ได้เป็นแบบนั้น มันเป็นค่าต่อเนื่อง

พอเป็นค่าต่อเนื่อง วิธีเดิมพังทันที เพราะถ้าถามว่าโอกาสที่ผลตอบแทนจะเท่ากับ 1.37% พอดีเป๊ะเป็นเท่าไร คำตอบคือศูนย์ ไม่ว่าจะดูอย่างไรก็ตาม ซึ่งฟังดูเหมือนพังทั้งระบบ

ทางออกคือเปลี่ยนสิ่งที่เราถาม จากการถามค่าจุดเดียว เป็นการถามค่าเป็นช่วง แล้วเปลี่ยนวิธีตอบจากการนับ เป็นการวัดพื้นที่ใต้เส้น

การเปลี่ยนมุมนี้ทำให้ความสูงของเส้นไม่ใช่โอกาสอีกต่อไป ซึ่งเป็นจุดที่คนสับสนกันมากที่สุด และเป็นเหตุผลที่ค่าความสูงเกินหนึ่งได้โดยไม่ผิดอะไรเลย

Worked Example — โจทย์จิ๋วที่คำนวณได้

ของที่โจทย์ให้daily return เป็น continuous random variable และถาม probability ที่จะเท่ากับ 1.2345% ตรงทุกหลัก.

คำตอบprobability ที่จุดเดียวเท่ากับ 0 แม้ PDF ที่จุดนั้นมีความสูงประมาณ 17.05.

ตรวจเองใน 10 วินาทีพื้นที่แถบโดยประมาณคือความสูงคูณความกว้าง; เมื่อความกว้างเป็น 0 จะได้ 17.05*0=0.

แปลว่าอะไรPDF เป็น density หรือความสูงต่อหนึ่งหน่วยบนแกน ต้องคูณความกว้างของช่วงก่อนจึงเป็น probability. กับดักคือเห็นความสูงเกิน 1 แล้วคิดว่า probability ผิด.

ระวังตรงนี้

กับดักมือใหม่: อย่าสับสนระหว่าง "ความสูง density" กับ "ความน่าจะเป็น"

เห็น density ที่ศูนย์เท่ากับ 21.11 แล้วอย่าอ่านว่า QQQ มีโอกาสปิด flat 2,111%: probability ไม่มีทางเกิน 1 แต่ density เป็นความสูงต่อหนึ่งหน่วยของแกนนอน จึงเกิน 1 ได้เมื่อสเกลแคบ พื้นที่ใต้เส้นต่างหากที่เป็น probability — อย่าเอาความสูงของภูเขาไปตอบว่าที่ดินกว้างกี่ตารางเมตร

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
จุดเดียวโอกาสของค่าจุดเดียวเป็นศูนย์คนอยากรู้โอกาสของค่าเป๊ะ ๆต้องถามเป็นช่วงเสมอ การถามจุดเดียวไม่มีความหมาย
ความสูงของเส้นความสูงไม่ใช่โอกาสคนอ่านกราฟมักเข้าใจว่าเป็นโอกาสค่าความสูงเกินหนึ่งได้ ซึ่งไม่ผิดอะไรเลย
ความเรียบราคาขยับต่อเนื่องราคากระโดดตอนมีข่าวโอกาสของการขยับแรงมากถูกประเมินต่ำเกินจริง

อุปมาจำง่าย: population density บนแผนที่

ลองนึกถึง population density บนแผนที่: 70,000 คนต่อตารางกิโลเมตรไม่ได้แปลว่ามีคนมายืนซ้อนกันที่พิกัดเดียว แต่มันบอกจำนวนคนโดยประมาณเมื่อเลือกพื้นที่กว้างหนึ่งตารางกิโลเมตร ถ้าตัดพื้นที่เหลือ 0.01 ตารางกิโลเมตรก็จะเจอคนราว 700 คน ส่วนจุดเดี่ยวที่ไม่มีพื้นที่มีจำนวนคนเป็นศูนย์ หลักการเดียวกัน: ต้องคูณ density ด้วยความกว้างของช่วงก่อนจึงได้ probability

นำไปใช้จริงใน risk report และการบริหารความเสี่ยง

ทุกครั้งที่เห็นกราฟ density ของผลตอบแทนหรือ P&L ให้ฝึกสายตามองหา "พื้นที่ (Area)" เสมอ อย่ามองแค่ความสูงของยอดกราฟ ถ้าต้องการประเมินความเสี่ยงขาลงรุนแรง (tail risk) สิ่งที่ต้องทำคือการแรเงาพื้นที่หางซ้ายใต้กราฟ แล้วคำนวณขนาดพื้นที่ด้วย CDF () เพื่อหาความน่าจะเป็นที่พอร์ตจะขาดทุนเกินระดับที่กำหนด

สรุปที่ใช้ได้จริง

  • สำหรับ continuous random variable เสมอทุกจุดเดี่ยว — ในทางปฏิบัติอย่าถามหาความน่าจะเป็นของตัวเลขจุดเป๊ะ ให้ถามหาความน่าจะเป็นของช่วงผลตอบแทน () แทนเสมอ
  • คือ probability density (density ต่อหน่วย) ไม่ใช่ probability ตรง ๆ — ความน่าจะเป็นจริงอ่านได้จากพื้นที่ใต้กราฟ เท่านั้น
  • ความสูงของ density พุ่งเกิน 1 ได้เป็นเรื่องปกติ โดยเฉพาะเมื่อแกนนอนมีสเกลเล็กละเอียด เช่น daily return — ตัวเลขที่ถูกล็อกให้อยู่ในช่วง 0 ถึง 1 เสมอคือ CDF และ probability
  • สำหรับช่วงแคบมากกว้าง รอบจุด : เป็นสูตรประมาณพื้นที่แบบสี่เหลี่ยมผืนผ้า (local interval mass) ที่รวดเร็วและแม่นยำ
  • ในหัวข้อถัดไป (1.9) เราจะนำ function ระฆังคว่ำมาตรฐาน (Normal distribution) มาใช้คำนวณพื้นที่ความเสี่ยงของพอร์ตจริง ทำให้หา probability ได้โดยไม่ต้องอินทิเกรตด้วยมือทุกครั้ง
