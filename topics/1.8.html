1.8 Continuous Random Variables and the Probability Density Function (PDF)

เมื่อความสูงไม่ใช่ความน่าจะเป็น: อ่าน density ด้วยความกว้างและพื้นที่

กราฟผลตอบแทนมีค่าบนแกนตั้งสูงถึง 21.11 ขณะเดียวกันผู้สร้างแบบจำลองบอกว่าโอกาสได้ผลตอบแทน 0% พอดีเท่ากับศูนย์ สองข้อความนี้อยู่ด้วยกันได้อย่างไร?

เปิดคำตอบก่อนเริ่มคำนวณ

กราฟนั้นเป็น probability density ไม่ใช่ PMF ความสูง 21.11 ต้องนำไปรวมกับความกว้างของช่วงจึงได้ความน่าจะเป็น ส่วนจุดเดียวไม่มีความกว้าง ในแบบจำลองที่มี density จึงมีโอกาสศูนย์ ไม่ว่าความสูงที่จุดนั้นจะมากเพียงใด

เราจะสร้างแนวคิดนี้จากเวลารอที่คิดพื้นที่ด้วยสามเหลี่ยมและสี่เหลี่ยมคางหมูได้ แล้วจึงกลับไปอ่านกราฟผลตอบแทน

เปลี่ยนจากนับค่าที่แยกกัน เป็นวัดโอกาสของช่วง

PMF ในหัวข้อ 1.2 ให้โอกาสแก่แต่ละค่า เช่นเสีย −1R หรือได้ +2R แต่เวลารออาจเป็น 3 นาที 3.1 นาที หรือ 3.123 นาที เราจึงอาจใช้แบบจำลองต่อเนื่องที่ให้ค่าได้ตลอดช่วง และถามโอกาสรอระหว่าง 3 ถึง 4 นาทีแทนการถามจุดเดียว

การวัดจริงยังมีความละเอียดจำกัด เช่นปัดเวลาเป็นวินาทีหรือราคาเป็นเซนต์ แบบจำลองต่อเนื่องจึงต้องแยกจากวิธีบันทึกข้อมูล ในหัวข้อนี้เราศึกษาแบบจำลองที่มี PDF โดยเฉพาะ ไม่ได้สมมติว่าข้อมูลตัวเลขทุกชนิดมี PDF เสมอ

เริ่มจาก histogram: แท่งสูงเท่ากันอาจแทนโอกาสไม่เท่ากัน

สมมติข้อมูลเวลารอ 1,000 ครั้ง มี 510 ครั้งรอไม่เกิน 3 นาที และ 640 ครั้งรอไม่เกิน 4 นาที จึงมี $640-510=130$ ครั้งอยู่ในช่วงมากกว่า 3 ถึง 4 นาที สัดส่วนของช่วงนี้คือ $130/1000=0.13$

ถ้าวาดแท่งให้ความสูงเท่ากับสัดส่วน 0.13 แกนตั้งจะเป็น relative frequency แต่ถ้าจะให้พื้นที่ของแท่งเป็นสัดส่วน ต้องหารด้วยความกว้างด้วย สำหรับแท่งกว้างหนึ่งนาที ความสูงจึงเป็น $0.13/1=0.13$ ต่อนาที

ขั้นที่ 1 — สร้างความสูงของ density histogram

ให้ $c$ เป็นจำนวนข้อมูลในช่วง $N$ เป็นจำนวนข้อมูลทั้งหมด และ $w$ เป็นความกว้างของช่วง นิยามความสูงให้พื้นที่ย้อนกลับไปเป็นสัดส่วนเดิม

\[ \begin{aligned} \text{height}&\equiv\frac{c/N}{w}\\ \text{area}&=\text{height}\times w=\frac cN\\[3pt] c=130,\ N=1000,\ w=1&:\quad\text{height}=0.13\ \text{per minute}\\ \text{area}&=0.13\times1=0.13 \end{aligned} \]

เมื่อแท่งกว้างไม่เท่ากัน ต้องเปรียบเทียบพื้นที่หากถามจำนวนหรือสัดส่วนข้อมูล ส่วนความสูงตอบความหนาแน่นต่อหน่วยเวลา ข้อมูลในช่วงหนึ่งนาทีไม่ได้บอกว่า 130 ครั้งนั้นกระจายเท่ากันทุกวินาที

แยกข้อมูลออกจากเส้นแบบจำลองที่จะใช้

ต่อไปเราสมมติ density ของเวลารอเป็นเส้นตรงลดจาก 0.2 ต่อนาทีที่เวลา 0 ไปถึงศูนย์ที่ 10 นาที และเป็นศูนย์นอกช่วงนี้ แบบจำลองนี้ให้โอกาสช่วง 3–4 นาทีตรงกับสัดส่วน 0.13 ข้างต้น แต่ข้อมูลสองจุดไม่ได้บังคับว่าต้องเลือกเส้นนี้เพียงเส้นเดียว

ให้ $T$ เป็นเวลารอเป็นนาที และใช้ $f(t)$ แทน PDF หรือ probability density function พื้นที่ใต้เส้นทุกช่วงต้องไม่ติดลบ และพื้นที่รวมทั้งหมดต้องเท่ากับหนึ่ง

ขั้นที่ 2 — กำหนด PDF ให้ครบทั้งในและนอกช่วง

\[ \begin{aligned} f(t)&\equiv \begin{cases} 0.2-0.02t,&0\le t\le10,\\ 0,&\text{otherwise} \end{cases}\\[3pt] \text{total area}&=\frac12(10)(0.2)=1\\ f(3)&=0.14,\qquad f(4)=0.12 \end{aligned} \]

พื้นที่รวมเป็นสามเหลี่ยมฐาน 10 นาที สูง 0.2 ต่อนาที จึงไม่มีหน่วยเหลืออยู่และเท่ากับหนึ่ง ถ้านำเส้นตรงไปใช้เลย 10 นาทีจะได้ density ติดลบ นั่นคือเหตุผลที่ต้องระบุขอบเขตและค่าศูนย์ภายนอก ไม่เขียนแค่สมการเส้นตรงลอย ๆ

ขั้นที่ 3 — หาโอกาสช่วง 3 ถึง 4 นาทีจากพื้นที่

ใต้เส้นตรงระหว่าง 3 กับ 4 เป็นสี่เหลี่ยมคางหมู พื้นที่เท่ากับค่าเฉลี่ยของความสูงสองข้างคูณความกว้าง

\[ \begin{aligned} P(3\lt T\le4)&=\frac{f(3)+f(4)}2(4-3)\\ &=\frac{0.14+0.12}{2}(1)\\ &=\boxed{0.13=13\%} \end{aligned} \]

ความสูงสองข้างไม่เท่ากัน จึงไม่ควรเอา $f(3)$ คูณหนึ่งนาทีแล้วถือเป็นคำตอบตรง ในแบบจำลองนี้ค่าเฉลี่ยความสูงเท่ากับ $f(3.5)=0.13$ เพราะเส้นเป็นเส้นตรง ไม่ใช่สมบัติที่ใช้ได้กับ PDF ทุกเส้น

Integral เป็นชื่อของการรวมพื้นที่ ไม่ใช่สูตรคนละเรื่อง

ถ้าเส้นโค้งไม่ใช่เส้นตรง เราแบ่งช่วงเป็นชิ้นเล็ก ๆ แล้วบวกพื้นที่ประมาณ $f(t)\Delta t$ ของแต่ละชิ้น เมื่อแบ่งละเอียดขึ้นตามเงื่อนไขของการอินทิเกรต ผลรวมนี้ให้พื้นที่ใต้เส้น เขียนเป็น $\int_a^b f(t)\,dt$

CDF ที่เรียนในหัวข้อ 1.1 ยังหมายถึง $F(t)=P(T\le t)$ เหมือนเดิม สำหรับแบบจำลองที่มี PDF ค่านี้คือพื้นที่สะสมใต้ density จากซ้ายสุดถึง $t$

ขั้นที่ 4 — สร้าง CDF ด้วยพื้นที่สะสม

\[ \begin{aligned} F(t)&=\int_{-\infty}^{t}f(u)\,du\\ 0\le t\le10&:\quad F(t)=\int_0^t(0.2-0.02u)\,du\\ &=[0.2u-0.01u^2]_0^t=0.2t-0.01t^2\\[3pt] F(t)&= \begin{cases} 0,&t\lt0,\\ 0.2t-0.01t^2,&0\le t\le10,\\ 1,&t\gt10 \end{cases}\\[3pt] F(3)&=0.6-0.09=0.51\\ F(4)&=0.8-0.16=0.64\\ P(3\lt T\le4)&=F(4)-F(3)=0.13 \end{aligned} \]

$u$ เป็นเพียงตัวนับตำแหน่งขณะรวมพื้นที่ ส่วน $t$ เป็นปลายช่วงที่ถาม หากยังไม่คุ้นกับ integral ให้คิดพื้นที่ตั้งแต่ศูนย์ถึง $t$ เป็นสี่เหลี่ยมผืนผ้า $0.2t$ ลบสามเหลี่ยม $0.01t^2$ ก็ได้คำตอบเดียวกัน

ขั้นที่ 5 — PDF กลับมาเป็นความชันของ CDF ได้อย่างไร

เมื่อ $h\gt0$ ผลต่างของ CDF ให้โอกาสในช่วง หารด้วยความกว้างจึงได้ density เฉลี่ยของช่วง เมื่อบีบช่วงเข้าหาจุดที่ PDF ต่อเนื่อง จะได้ความสูงที่จุดนั้น

\[ \begin{aligned} \frac{F(t+h)-F(t)}h&=\frac{P(t\lt T\le t+h)}h\\ \lim_{h\to0^+}\frac{F(t+h)-F(t)}h&=F'(t)=f(t)\\[3pt] 0\lt t\lt10&:\quad F'(t)=0.2-0.02t\\ \frac{F(3.51)-F(3.49)}{0.02}&=\frac{0.0026}{0.02}\\ &=0.13=f(3.5) \end{aligned} \]

ในตัวอย่างเส้นตรง ช่วงสมมาตรรอบ 3.5 ให้ค่าเฉลี่ย density เท่าค่าตรงกลางพอดี โดยทั่วไป $f=F'$ ใช้ตรงจุดที่อนุพันธ์และเงื่อนไขที่เกี่ยวข้องเป็นจริง ไม่ควรอ้างว่าทุก CDF มีอนุพันธ์เป็น PDF ทุกจุด โดยเฉพาะ CDF แบบมีขั้นจาก PMF

ขั้นที่ 6 — ถามช่วงสั้นรอบจุด แทนการถามความสูงอย่างเดียว

สำหรับช่วงกว้าง $\varepsilon$ ที่มีศูนย์กลาง $t_0$ ถ้า PDF เปลี่ยนไม่มากในช่วงนั้น ใช้พื้นที่สี่เหลี่ยมประมาณพื้นที่จริงได้

\[ \begin{aligned} P\left(t_0-\frac\varepsilon2\lt T\le t_0+\frac\varepsilon2\right) &=\int_{t_0-\varepsilon/2}^{t_0+\varepsilon/2}f(t)\,dt\\ &\approx\varepsilon f(t_0)\\[3pt] t_0=3.5,\quad\varepsilon=10/60&:\quad\varepsilon f(t_0)\\ &=\frac16(0.13)\approx0.021667 \end{aligned} \]

ช่วงสิบวินาทีที่อยู่รอบ 3.5 นาทีจึงมีโอกาสประมาณ 2.17% สำหรับเส้นตรงและช่วงสมมาตรนี้วิธีสี่เหลี่ยมให้ค่าตรงพอดี แต่ถ้าใช้ช่วงเริ่มที่ 3.5 แล้วไปข้างหน้า หรือใช้ PDF โค้ง ต้องแยกค่าประมาณออกจากค่าที่อินทิเกรตได้

ทำไมจุดเดียวมีโอกาสศูนย์ แต่ค่าที่วัดได้ยังเกิดขึ้นได้

ในแบบจำลองที่มี PDF โอกาสของช่วงรอบจุดจะเข้าใกล้ศูนย์เมื่อความกว้างเข้าใกล้ศูนย์ จึงได้ $P(T=t_0)=0$ หรือดูจาก CDF ที่ไม่มีการกระโดดก็ได้ ผลนี้ไม่ได้แปลว่าจุดนั้นอยู่นอกขอบเขตค่าที่เป็นไปได้

ต้องมีค่าใดค่าหนึ่งเกิดขึ้น แต่ไม่มีค่าใดได้รับมวลความน่าจะเป็นบวกเป็นรายจุด เราไม่สามารถบวกศูนย์ทีละจุดบนจำนวนจุดที่นับไม่ได้ แล้วสรุปว่าโอกาสทั้งช่วงเป็นศูนย์ กฎบวกความน่าจะเป็นทีละเหตุการณ์ใช้กับครอบครัวที่นับได้

หากนาฬิกาแสดง 3.50 นาทีจากการปัดทศนิยมสองตำแหน่ง ข้อมูลนั้นแทนช่วงประมาณ 3.495 ถึง 3.505 นาที ไม่ได้ยืนยันค่าจริงเป็น 3.500000… พอดี โอกาสของค่าที่บันทึกจึงอาจเป็นบวกได้

กลับสู่ผลตอบแทน: กำหนด Normal เป็นแบบจำลองทดลอง

สมมติผลตอบแทนรายวันของ QQQ มี Normal distribution ค่าเฉลี่ยศูนย์ และ annualized volatility 30% โดยใช้ 252 วันซื้อขายต่อปี ตัวเลขนี้เป็นสมมติฐานเพื่อสาธิต PDF ไม่ใช่การยืนยันว่า QQQ มี distribution หรือ volatility ตามนี้จริง

หัวข้อ 1.9 จะอธิบาย Normal โดยละเอียด ที่นี่ใช้รูป density ที่กำหนดให้เพื่อฝึกแยกความสูงออกจากพื้นที่ ใช้ $X$ เป็นผลตอบแทนในหน่วยทศนิยม เช่น 1.2345% เขียนเป็น $x_0=0.012345$

ขั้นที่ 7 — จัดหน่วยของ volatility และ density ให้ตรงกัน

ใช้การ annualize แบบรากเวลา: ผลตอบแทนรายวันมี variance เท่ากันและไม่มี covariance ข้ามวันในแบบจำลองการรวมที่ใช้ ไม่ใช่การคูณผลตอบแทนทบต้นแบบตรงทุกกรณี

\[ \begin{aligned} \sigma_{\text{annual}}^2&=252\sigma_{\text{daily}}^2\\ \sigma&=\frac{0.30}{\sqrt{252}}\approx0.0188982\\ z&=\frac{x_0-0}{\sigma}\approx0.653236\\[3pt] \phi(z)&\equiv\frac{e^{-z^2/2}}{\sqrt{2\pi}}\\ f(x_0)&=\frac1\sigma\phi\left(\frac{x_0}{\sigma}\right)\\ &\approx\boxed{17.0541} \end{aligned} \]

$\phi$ เป็น density ของ Standard Normal ที่กำหนดให้ในตัวอย่างนี้ การเปลี่ยนแกนจาก $z$ เป็นผลตอบแทนทำให้ความกว้างคูณด้วย $\sigma$ ความสูงจึงต้องหารด้วย $\sigma$ เพื่อรักษาพื้นที่ ค่า 17.0541 มีหน่วยต่อหนึ่งหน่วยผลตอบแทนทศนิยม ไม่ใช่โอกาส 1,705.41%

บีบช่วงรอบ 1.2345% แล้วพื้นที่ลดลงอย่างไร

ขั้นที่ 8 — ตรวจแถวแรกด้วย CDF สองขอบ

ให้ $\Phi$ เป็น CDF ของ Standard Normal ใช้ขอบ $x_0-0.004$ และ $x_0+0.004$ แล้วปรับหน่วยเป็น z-score ก่อนอ่าน CDF

\[ \begin{aligned} z_{\text{lo}}&=\frac{0.012345-0.004}{\sigma}\approx0.441576\\ z_{\text{hi}}&=\frac{0.012345+0.004}{\sigma}\approx0.864896\\ P&=\Phi(z_{\text{hi}})-\Phi(z_{\text{lo}})\\ &\approx0.80645209-0.67060193\\ &\approx0.13585016\\ \varepsilon f(x_0)&\approx0.008(17.054092)\\ &\approx0.13643274 \end{aligned} \]

ทั้งสองคำตอบอยู่ใกล้กัน แต่ความกว้างคูณความสูงยังเป็นค่าประมาณสำหรับเส้นโค้งนี้ ความต่างประมาณ 0.0583 จุดเปอร์เซ็นต์ เมื่อช่วงแคบลงเส้นเปลี่ยนความสูงน้อยลง ค่าประมาณจึงแม่นขึ้นในตัวอย่างนี้

ขั้นที่ 9 — เหตุใด density เกินหนึ่งจึงไม่ผิดกฎ

จุดสูงสุดของ Normal ตัวอย่างนี้อยู่ที่ศูนย์ ค่า exponential ตรงนั้นเป็นหนึ่ง จากนั้นลองเปลี่ยนหน่วยแกนนอนเป็นเปอร์เซ็นต์โดยให้ $Y=100X$

\[ \begin{aligned} f_X(0)&=\frac1{\sigma\sqrt{2\pi}}\approx21.1100\\ y&=100x,\qquad dy=100\,dx\\ f_Y(y)\,dy&=f_X(x)\,dx\\ f_Y(y)&=\frac{f_X(y/100)}{100}\\ f_Y(0)&\approx0.211100 \end{aligned} \]

เปลี่ยนหน่วยแล้วความสูงจาก 21.11 กลายเป็น 0.2111 แต่พื้นที่ไม่เปลี่ยน ดังนั้นความสูงเพียงตัวเดียวไม่ใช่ probability อีกตัวอย่างที่ง่ายคือ Uniform บนช่วง 0 ถึง 0.01: density สูง 100 และกว้าง 0.01 จึงมีพื้นที่หนึ่ง

ขั้นที่ 10 — ตอบคำถามความเสี่ยงด้วยพื้นที่หาง

ใช้แบบจำลอง Normal เดิม ถามโอกาสขาดทุนมากกว่า 3% ต่อวัน และจำนวนวันคาดหมายใน 252 วันซึ่งทุกวันมีความน่าจะเป็นนี้

\[ \begin{aligned} P(X\lt-0.03)&=\Phi\left(\frac{-0.03}{\sigma}\right)\\ &\approx0.0562053=5.62053\%\\ \mathbb E[\text{number of such days}]&=252(0.0562053)\\ &\approx14.16 \end{aligned} \]

จำนวน 14.16 เป็น expectation ไม่ใช่จำนวนที่ทุกปีต้องพบ การคูณจำนวนวันกับโอกาสเพื่อหาค่าเฉลี่ยไม่ต้องอาศัย independence แต่ต้องมีโอกาสรายวันตามที่ใช้ ส่วนการหา distribution ของจำนวนวันหรือโอกาสเกิดติดกันต้องมีข้อมูลความสัมพันธ์เพิ่ม

อย่าสับสน “มี PDF” กับ “ราคาขยับเรียบตามเวลา”

PDF บอก distribution ของตัวแปรที่กำหนด ไม่ได้บอกเส้นทางราคาตามเวลา แบบจำลองที่ราคากระโดดก็อาจมี density ของผลตอบแทนได้ ปัญหาว่า Normal ประเมินหางได้ดีหรือไม่จึงเป็นอีกคำถามหนึ่ง ไม่ใช่ผลอัตโนมัติจากการใช้ PDF

บางแบบจำลองมีทั้งมวลที่จุดเดียวกับส่วนต่อเนื่อง เช่นโอกาสจับคู่คำสั่งได้ทันที 20% และเวลาเมื่อไม่ได้ทันทีมี density แบบเวลารอข้างต้น ในกรณีนี้ $P(T=0)=0.20$ ต้องนับมวลนั้นเพิ่ม ไม่สามารถใช้ PDF ส่วนต่อเนื่องเพียงอย่างเดียวแทน distribution ทั้งหมด

ความต่อเนื่องของ CDF อย่างเดียวก็ไม่ได้รับรองว่ามี PDF เสมอ บทนี้จำกัดอยู่ที่แบบจำลองที่เขียนโอกาสเป็น integral ของ density ได้ การเขียนขอบเขตนี้ช่วยให้ใช้สูตรได้ตรงประเภทของตัวแปร

ลองทำเอง 1 — เวลาที่บันทึกกับเวลาจริง

ในแบบจำลองเวลารอเดิม นาฬิกาปัดเป็นทศนิยมสองตำแหน่ง จงหาโอกาสที่หน้าจอแสดง 3.50 นาที แล้วเปรียบเทียบกับโอกาสที่เวลาจริงเท่ากับ 3.50 นาทีพอดี

เปิดคำตอบ

ค่าที่ปัดเป็น 3.50 อยู่ในช่วงกว้าง 0.01 นาทีรอบจุด 3.5 การรวมเส้นตรงในช่วงสมมาตรให้โอกาส $0.01f(3.5)=0.0013=0.13\%$ จะรวมขอบด้านใดก็ไม่เปลี่ยนคำตอบในแบบจำลองนี้

เวลาจริงที่เป็น 3.500000… พอดีมีโอกาสศูนย์ ข้อมูลบนจอจึงไม่ใช่คำถามเดียวกับค่าจริงทุกหลัก แม้จะเขียนตัวเลขออกมาคล้ายกัน

ลองทำเอง 2 — ผลตอบแทนอยู่ภายใน ±2%

ใช้ Normal และ $\sigma$ เดิม หาความน่าจะเป็นของช่วง −2% ถึง +2% และอธิบายว่าเหตุใดไม่ใช่ $f(0)$ เพียงตัวเดียว

เปิดคำตอบ

ใช้ $\Phi(0.02/\sigma)-\Phi(-0.02/\sigma)\approx0.710082$ หรือประมาณ 71.01% ส่วน $f(0)$ เป็นความสูงที่จุดกลาง ยังไม่ได้รวมพื้นที่ตลอดช่วง

ถ้าประมาณด้วยความสูงกลางคูณความกว้าง จะได้ $21.1100(0.04)\approx0.8444$ ซึ่งสูงกว่าคำตอบมาก เพราะช่วงนี้กว้างจน density ลดลงจากยอดอย่างชัดเจน ทางลัดช่วงแคบไม่เหมาะกับทุกช่วง

ตรวจเองใน 10 วินาที: โอกาสต้องอยู่ระหว่างศูนย์กับหนึ่ง หากเปลี่ยนหน่วยแกนจากทศนิยมเป็นเปอร์เซ็นต์แล้ว probability เปลี่ยน แสดงว่ายังปรับ density หรือความกว้างไม่ครบ

จากโอกาสของช่วง ไปสู่ค่าเฉลี่ยของ payoff

แนวคิดเดียวกันใช้กับ expectation: แทนผลรวม $\sum_x g(x)p(x)$ ด้วย $\int g(x)f(x)\,dx$ เมื่อ expectation นั้นมีอยู่ นี่คือวิธีถ่วงผลตอบแทนแต่ละค่าโดยใช้ density แทน PMF

ในการตั้งราคา option ยังต้องระบุ distribution ภายใต้มาตรวัดที่ใช้ตั้งราคาและการคิดลด ไม่ใช่นำ PDF ที่ fit จากผลตอบแทนในอดีตไปเฉลี่ย payoff แล้วถือว่าเป็นราคาที่ถูกต้องทันที

const waitF = t => t < 0 ? 0 : t > 10 ? 1 : 0.2 * t - 0.01 * t * t;
console.log([waitF(3), waitF(4), waitF(4) - waitF(3)]);
console.log(waitF(3.505) - waitF(3.495)); // 0.0013
const sigma = 0.30 / Math.sqrt(252);
const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
// Simpson integration from zero; used here only for the small z values below.
function Phi(z) {
  const n = 4000, h = Math.abs(z) / n;
  let sum = 0;
  for (let i = 0; i <= n; i++) {
    const weight = i === 0 || i === n ? 1 : i % 2 ? 4 : 2;
    sum += weight * phi(i * h);
  }
  return 0.5 + Math.sign(z) * sum * h / 3;
}
const x = 0.012345;
const density = phi(x / sigma) / sigma;
console.log([sigma, density, phi(0) / sigma]);
for (const width of [0.008, 0.0008, 0.00008]) {
  const area = Phi((x + width / 2) / sigma) - Phi((x - width / 2) / sigma);
  console.log([area, width * density]);
}
console.log([Phi(-0.03 / sigma), 252 * Phi(-0.03 / sigma)]);
console.log(Phi(0.02 / sigma) - Phi(-0.02 / sigma));

สรุป — อ่าน probability จากพื้นที่ ไม่ใช่จากยอดเส้น

  • PDF มีหน่วยกลับของแกนนอน ต้องรวมกับความกว้างจึงได้ probability ความสูงจึงเกินหนึ่งได้
  • สำหรับแบบจำลองที่มี PDF ใช้ $P(a\lt X\le b)=\int_a^b f(x)\,dx=F(b)-F(a)$ และ probability ที่จุดเดียวเป็นศูนย์
  • เวลาที่ปัดหรือราคาที่บันทึกเป็น tick ไม่ใช่ค่าต่อเนื่องทุกหลัก ต้องกำหนดให้ชัดว่าถามค่าจริงหรือค่าที่บันทึก
  • ความกว้างคูณความสูงเป็นค่าประมาณของพื้นที่ ไม่ใช่คำตอบตรงสำหรับทุกเส้นหรือทุกช่วง
  • ใน Normal ตัวอย่าง พื้นที่หางต่ำกว่า −3% ประมาณ 5.62% ต่อวัน ตัวเลขนี้เป็นผลของแบบจำลองที่เลือก ไม่ใช่ความเสี่ยงตลาดที่ตรวจยืนยันแล้ว
