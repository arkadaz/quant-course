13.1 Why Ordinary Calculus Fails on Brownian Motion

chain rule ทิ้งพจน์กำลังสองของการขยับได้เพราะบนเส้นเรียบมันหายไป แต่บนเส้นทาง Brownian ผลรวมของพจน์นั้นเท่ากับเวลาที่ผ่านไป จึงต้องเก็บไว้

สัญญาสมมติตัวหนึ่งจ่ายเงิน \$1 ล้าน คูณกำลังสองของผลตอบแทนหนึ่งปีของ SPY โต๊ะใช้แบบจำลอง Brownian motion ที่มี drift คือผลตอบแทนสะสม $R_t=\mu t+\sigma W_t$ ด้วย drift 8% และความผันผวน 18% ต่อปี นักวิเคราะห์ใช้ chain rule ที่เรียนมา $d(R^2)=2R\,dR$ เห็นว่าค่าเฉลี่ยของ $dR$ คือ $\mu\,dt$ จึงได้ $\mathbb E[R_1^2]=\mu^2=0.0064$ หรือสัญญาจ่ายเฉลี่ย \$6,400 ใช้ตัวเลขนี้ตั้งราคาขายได้ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ได้ ค่าเฉลี่ยจริงคือ $\mu^2+\sigma^2=0.0064+0.0324=0.0388$ หรือจ่ายเฉลี่ย \$38,800 มากกว่าที่คิดราว 6 เท่า ส่วนที่หายไป \$32,400 คือ $\sigma^2$ คูณหนึ่งปี มันมาจากผลรวมกำลังสองของการขยับเล็ก ๆ ที่ chain rule ทิ้งไป ถ้าขายที่ \$6,400 จะขาดทุนเฉลี่ย \$32,400 ต่อสัญญา (ยังไม่นับดอกเบี้ย)

ภาพรวมก่อนลงสูตร

chain rule $df=f'(x)\,dx$ ที่เรียนกันมาซ่อนการตัดสินใจไว้หนึ่งอย่าง: ใน Taylor ของการขยับหนึ่งก้าว มันเก็บพจน์ $f'\,\Delta x$ แล้วทิ้งพจน์ $\tfrac12f''(\Delta x)^2$ เพราะบนเส้นเรียบ ถ้าซอยเวลาละเอียดขึ้น ผลรวมของ $(\Delta x)^2$ ทุกท่อนหดเป็นศูนย์ การทิ้งจึงไม่เสียอะไร

เส้นทาง Brownian ไม่เป็นแบบนั้น แต่ละก้าวขยับขนาดราว $\sqrt{\Delta t}$ ซึ่งใหญ่กว่า $\Delta t$ มากเมื่อก้าวสั้น กำลังสองของการขยับจึงมีขนาด $\Delta t$ และบวกทั้งปีได้เวลาหนึ่งปีพอดี ไม่หดเลย รูปด้านล่างแสดงเรื่องนี้เรื่องเดียว: เส้นเขียวของเส้นเรียบจมลงหาศูนย์ ส่วนเส้นน้ำเงินของเส้นทาง Brownian นิ่งเข้าหาเวลาที่ผ่านไป

หน้านี้จะวัดผลรวมนั้นด้วยมือ หาค่าเฉลี่ยและความคลาดของมัน เห็นมันในต้นไม้ binomial ที่โต๊ะใช้ตั้งราคา option ตอบโจทย์ \$1 ล้าน พิสูจน์ว่าทำไม $(dW)^2$ แทนด้วย $dt$ ได้ ได้ตารางคูณของ Itô กับ chain rule ฉบับแก้ แล้วจบที่ผลบนโต๊ะ: ความผันผวนวัดได้แม่น แต่ drift วัดแทบไม่ได้

Chain rule
กฎหาการเปลี่ยนของ $f(x)$ จากการเปลี่ยนของ $x$ คือ $df=f'(x)\,dx$ ใช้ทุกครั้งที่มูลค่าเป็นฟังก์ชันของราคา เช่นราคา option ที่ขึ้นกับราคาหุ้น มันถูกบนเส้นเรียบเพราะพจน์กำลังสองทิ้งได้
Increment
การขยับของเส้นทางในหนึ่งท่อนเวลา $\Delta W_i=W_{t_i}-W_{t_{i-1}}$ เป็นก้อนที่เอามายกกำลังแล้วบวก
Quadratic variation
ค่าที่ผลรวมการขยับยกกำลังสองเข้าใกล้เมื่อซอยเวลาละเอียดขึ้น ของ Brownian motion มาตรฐานคือเวลาที่ผ่านไป $T$ ใช้วัดความขรุขระสะสมของเส้นทาง และเป็นพจน์ที่ chain rule ปกติทิ้งไป
Itô correction
พจน์ $\tfrac12f''\,dt$ ที่ต้องเติมใน chain rule เมื่อสิ่งข้างในเป็นเส้นทาง Brownian มีอยู่เพราะความโค้งของ $f$ ทำงานกับกำลังสองของการขยับที่ไม่หาย
Itô multiplication table
กฎย่อสามข้อ $(dW)^2=dt$, $dW\,dt=0$ และ $(dt)^2=0$ เป็นตัวย่อของผลรวมทั้งช่วงที่พิสูจน์ในหน้านี้ ใช้ตัดสินว่าพจน์ไหนใน Taylor เก็บ พจน์ไหนทิ้ง
Realized variance
ผลรวมผลตอบแทนยกกำลังสองของช่วงหนึ่ง คือ quadratic variation ที่วัดจากข้อมูลจริง ใช้ประมาณความผันผวน และเป็นตัวที่ variance swap จ่ายตาม

ขั้นที่ 1 — บนเส้นเรียบ chain rule ทิ้งพจน์กำลังสองได้

เริ่มจาก identity ที่ไม่ประมาณอะไรเลย ตำแหน่งท้ายท่อนคือตำแหน่งต้นท่อนบวกการขยับ ยกกำลังสองแล้วกระจาย จากนั้นบวกทุกท่อน ฝั่งซ้ายหักกันเหลือปลายลบต้น ลองกับเส้นตรง $x(t)=t$ บนหนึ่งปี ซอย $n$ ท่อนเท่ากัน ท่อนละ $\Delta x_i=1/n$

\[ \begin{aligned} x_i^2-x_{i-1}^2&=(x_{i-1}+\Delta x_i)^2-x_{i-1}^2\\ &=2x_{i-1}\Delta x_i+(\Delta x_i)^2,\\ x_T^2-x_0^2&=\sum_{i=1}^n2x_{i-1}\Delta x_i\\ &\quad+\sum_{i=1}^n(\Delta x_i)^2,\\ \sum_{i=1}^n(\Delta x_i)^2&=n\cdot\frac1{n^2}=\frac1n,\\ n=4,\ 252,\ 1{,}000&:\ 0.25,\ 0.00397,\ 0.001. \end{aligned} \]

บรรทัดที่สามเป็นจริงทุก $n$ ไม่มีการตัดพจน์ ผลรวมแรกคือสิ่งที่ chain rule $d(x^2)=2x\,dx$ นับ ผลรวมที่สองคือส่วนที่มันทิ้ง บนเส้นตรงผลรวมที่สองเป็น $1/n$ ซอยละเอียดขึ้นก็หายไป ส่วนผลรวมแรกเป็น $(n-1)/n$ ซึ่งเข้าหา $x_1^2=1$ พอดี (0.75 ที่ 4 ท่อน และ 0.999 ที่ 1,000 ท่อน)

ทำไมหาย? แต่ละท่อนขยับขนาด $\Delta t$ กำลังสองจึงมีขนาด $\Delta t^2$ บวก $n$ ท่อนแล้วยังเหลือ $\Delta t$ ค้างหนึ่งตัว ทุกเส้นที่มีความชันจำกัดเป็นแบบนี้ นี่คือเหตุผลเดียวที่ chain rule ทิ้งพจน์กำลังสองได้ และเป็นเส้นเขียวในรูปภาพรวมด้านบน

ขั้นที่ 2 — identity เดียวกันบนเส้นทาง Brownian: สี่ก้าวด้วยมือ

โจทย์ให้อะไรมาบ้าง: identity บนเส้นเรียบใช้แค่พีชคณิต จึงเป็นจริงกับเส้นทาง Brownian ด้วย ใช้หนึ่งปีซอยสี่ท่อน $\Delta t=0.25$ แต่ละท่อน $\Delta W_i=\sqrt{0.25}\,Z_i=0.5Z_i$ (การขยับของ Brownian motion มาตรฐาน ในเวลา $\Delta t$ เป็น Normal ที่มี variance $\Delta t$) และเลขสุ่มสี่ตัว $Z=(0.31, -1.20, 0.85, 0.47)$

\[ \begin{aligned} \Delta W&=(0.155,\ -0.6,\ 0.425,\ 0.235),\\ W_1,\ldots,W_4&=0.155,\ -0.445,\ -0.02,\ 0.215,\\ Q_4&=0.024025+0.36\\ &\quad+0.180625+0.055225\\ &=0.619875,\\ \textstyle\sum_i2W_{i-1}\Delta W_i&=0-0.186-0.37825\\ &\quad-0.0094=-0.57365,\\ -0.57365+0.619875&=0.046225=0.215^2. \end{aligned} \]

คำตอบ: ผลรวมแรก −0.574 บวกผลรวมกำลังสอง 0.620 ได้ $W_4^2=0.046225$ พอดี แต่ผลรวมกำลังสองตรงนี้ไม่ได้เล็กเลย ใหญ่กว่าคำตอบทั้งก้อนกว่าสิบเท่า เทียบกับเส้นตรงที่ 4 ท่อนได้ 0.25 แล้วหายไปเมื่อซอยละเอียด คำถามคือของเส้นทาง Brownian จะหายไหม

ตรวจเองใน 10 วินาที: ท่อนที่สามใช้ตำแหน่งก่อนก้าว $W_2=-0.445$ คูณการขยับ 0.425 ได้ $2(-0.445)(0.425)=-0.37825$ การอ่านตัวคูณที่ต้นท่อนแบบนี้คือหัวใจของ Itô integral

ขั้นที่ 3 — ผลรวมกำลังสองไม่หาย: เฉลี่ยเท่ากับเวลาพอดี

ต้องรู้สองอย่างของ $Q_n$ คือค่าเฉลี่ยและความคลาด ใช้ $\Delta W_i=\sqrt{\Delta t}\,Z_i$, $\mathbb E[Z^2]=1$, $\mathbb E[Z^4]=3$ (ทั้งสองค่ามาจากการอินทิเกรต density ของ Normal ทีละส่วนใน สมบัติแปลก ๆ ของเส้นทาง Brownian) และความจริงที่ว่าท่อนที่ไม่ทับกันเป็นอิสระต่อกัน variance ของผลรวมจึงเท่ากับผลรวมของ variance

\[ \begin{aligned} (\Delta W_i)^2&=\Delta t\,Z_i^2,\\ \mathbb E[(\Delta W_i)^2]&=\Delta t,\\ \operatorname{Var}\big((\Delta W_i)^2\big)&=\Delta t^2(3-1)=2\Delta t^2,\\ \mathbb E[Q_n]&=n\,\Delta t=T,\\ \operatorname{SD}(Q_n)&=\sqrt{n\cdot2\Delta t^2}=T\sqrt{2/n},\\ T=1,\ n=4&:\ \operatorname{SD}=0.707,\\ n=252&:\ \operatorname{SD}=0.0891,\\ n=98{,}280&:\ \operatorname{SD}=0.00451. \end{aligned} \]

ความต่างกับเส้นเรียบอยู่ที่บรรทัดแรก การขยับของเส้นทาง Brownian มีขนาด $\sqrt{\Delta t}$ กำลังสองจึงมีขนาด $\Delta t$ ไม่ใช่ $\Delta t^2$ บวก $n$ ท่อนแล้ว $n$ ตัดกับ $1/n$ พอดี เหลือ $T$ ไม่ว่าจะซอยกี่ท่อน ขณะที่ความคลาดรอบ $T$ หดตาม $1/\sqrt n$

ค่า 0.620 ของสี่ก้าวด้วยมือต่ำกว่า 1 อยู่ $0.38/0.707\approx0.54$ SD ซึ่งปกติสำหรับ 4 ท่อน ถ้าซอยรายวัน 252 ท่อน (จำนวนวันทำการของตลาดหุ้นสหรัฐในหนึ่งปี) ผลรวมจะอยู่ในช่วง $1\pm0.089$ ราวสองในสามของเส้นทาง และถ้าซอยรายนาที 98,280 ท่อน ($252\times390$ นาทีของวันทำการ 9:30 ถึง 16:00) มันแทบเป็นค่าคงที่ 1

ขั้นที่ 4 — ต้นไม้ binomial: ผลรวมกำลังสองเท่ากับ σ²T ทุกเส้นทาง

โจทย์ให้อะไรมาบ้าง: โต๊ะที่ตั้งราคา option ด้วย ต้นไม้ binomial มักตั้งตัวคูณขาขึ้น $u=e^{\sigma\sqrt{\Delta t}}$ และขาลง $d=1/u$ จากความผันผวน $\sigma$ แล้วซอยละเอียดขึ้นจนเส้นทางในต้นไม้หน้าตาเหมือนเส้นทาง Brownian และราคาเข้าหาสูตร Black–Scholes ใช้ $\sigma=0.18$ หนึ่งปีซอยสี่ไตรมาส ราคาเริ่ม \$100 ดูสองเส้นทาง: ขึ้น ขึ้น ลง ขึ้น และ ลงสี่ครั้ง

\[ \begin{aligned} \ln u&=0.18\sqrt{0.25}=0.09,\quad u=1.0942,\\ \Delta\ln S&=\pm0.09,\quad(\Delta\ln S)^2=0.0081,\\ \textstyle\sum_{i=1}^4(\Delta\ln S_i)^2&=4(0.0081)=0.0324=\sigma^2T,\\ 0.09+0.09-0.09+0.09&=+0.18,\\ 4(-0.09)&=-0.36,\\ 252\big(0.18/\sqrt{252}\big)^2&=0.0324. \end{aligned} \]

คำตอบ: สองเส้นทางจบคนละที่ เส้นแรกจบที่ $100e^{0.18}=\$119.72$ เส้นที่สองจบที่ $100e^{-0.36}=\$69.77$ แต่ผลรวมกำลังสองของการขยับใน log ราคาเท่ากันที่ 0.0324 ทุกเส้นทางทั้ง 16 เส้น และยังเป็น 0.0324 เมื่อซอยรายวัน ต้นไม้ฝัง quadratic variation $\sigma^2T$ ไว้ในทุกเส้นทางโดยตรง พารามิเตอร์ $\sigma$ ของต้นไม้จึงคือ “ผลรวมกำลังสองของการขยับต่อปี” นั่นเอง

ตรวจเองใน 10 วินาที: $0.09^2=0.0081$ และ $0.18^2=0.0324$ เท่ากับสี่เท่าของ 0.0081 พอดี ส่วนผลรวมของการขยับเอง (ไม่ยกกำลัง) ขึ้นกับว่าขึ้นกี่ครั้ง จึงสุ่ม

ขั้นที่ 5 — ผลรวมแรกเฉลี่ยศูนย์ คำตอบทั้งหมดอยู่ในส่วนที่ถูกทิ้ง

รู้แล้วว่าผลรวมกำลังสองเฉลี่ย $T$ แล้วผลรวมแรกล่ะ? ในท่อนที่ $i$ ตัวคูณ $W_{i-1}$ ถูกกำหนดแล้วก่อนก้าว ส่วน $\Delta W_i$ เป็นอิสระจากทุกอย่างที่เกิดก่อนหน้า (สมบัติ independent increments ของ Brownian motion ซึ่งทำให้การขยับข้างหน้าไม่ขึ้นกับข้อมูลที่มีถึงวันนี้) ค่าเฉลี่ยของผลคูณจึงแยกเป็นผลคูณของค่าเฉลี่ยได้

\[ \begin{aligned} \mathbb E[W_{i-1}\Delta W_i]&=\mathbb E[W_{i-1}]\,\mathbb E[\Delta W_i]\\ &=\mathbb E[W_{i-1}]\cdot0=0,\\ \mathbb E\Big[\textstyle\sum_i2W_{i-1}\Delta W_i\Big]&=0,\\ \mathbb E[W_T^2]&=0+\mathbb E[Q_n]=T. \end{aligned} \]

ผลรวมแรกซึ่งเป็นสิ่งเดียวที่ chain rule ปกตินับ มีค่าเฉลี่ยศูนย์ทุกความละเอียด คำตอบทั้งหมดของ $\mathbb E[W_T^2]$ จึงมาจากผลรวมที่ chain rule ทิ้ง และได้ $T$ ตรงกับ $\operatorname{Var}(W_T)=T$ ที่รู้อยู่แล้วจากนิยามของ Brownian motion มาตรฐาน chain rule ปกติตอบ 0 ให้ค่าเฉลี่ยของสิ่งที่ไม่เคยติดลบ

จังหวะที่ใช้ความอิสระคือการแยกค่าเฉลี่ย ทำได้เพราะ $W_{i-1}$ รู้ค่าก่อนก้าว ถ้าเผลอใช้ $W_i$ ปลายท่อนแทน ผลคูณจะลาก $(\Delta W_i)^2$ เข้ามาด้วย แล้วค่าเฉลี่ยไม่เป็นศูนย์อีก (ดูความผิดข้อที่สองท้ายหน้า)

ขั้นที่ 6 — คำตอบของโจทย์เปิดเรื่อง: สัญญาจ่าย \$1 ล้าน คูณ R²

โจทย์ให้อะไรมาบ้าง: $R_t=\mu t+\sigma W_t$ โดย $\mu=0.08$, $\sigma=0.18$, $T=1$ ปี และ notional \$1 ล้าน ทุกท่อนขยับ $\Delta R_i=\mu\Delta t+\sigma\Delta W_i$ ใช้ identity บนเส้นเรียบกับ $R$ แทน $x$ แล้วหาค่าเฉลี่ยของสองผลรวมทีละก้อน

\[ \begin{aligned} (\Delta R_i)^2&=\mu^2\Delta t^2+2\mu\sigma\,\Delta t\,\Delta W_i\\ &\quad+\sigma^2(\Delta W_i)^2,\\ \mathbb E\textstyle\sum_i(\Delta R_i)^2&=\mu^2T^2/n+0+\sigma^2T,\\ \mathbb E[R_{i-1}]&=\mu(i-1)\Delta t,\\ \mathbb E[2R_{i-1}\Delta R_i]&=2\mu^2(i-1)\Delta t^2,\\ \textstyle\sum_{i=1}^n2\mu^2(i-1)\Delta t^2&=\mu^2T^2\,\frac{n-1}{n},\\ \mathbb E[R_T^2]&=\mu^2T^2+\sigma^2T\\ &=0.0064+0.0324=0.0388. \end{aligned} \]

คำตอบ: สัญญาจ่ายเฉลี่ย 0.0388 ของ \$1 ล้าน คือ \$38,800 ผลรวมแรกที่ chain rule เห็นให้แค่ $\mu^2T^2=0.0064$ หรือ \$6,400 อีก \$32,400 มาจาก $\sigma^2(\Delta W_i)^2$ ที่รวมกันได้ $\sigma^2T$ พจน์อื่นในกำลังสองของ $\Delta R_i$ หายไปเมื่อซอยละเอียด: $\mu^2T^2/n$ เหลือ 0.0000254 ที่ 252 ท่อน และพจน์ไขว้มีค่าเฉลี่ยศูนย์ สองก้อนรวมกันได้ $\mu^2T^2+\sigma^2T$ พอดีทุก $n$

ตรวจเองใน 10 วินาที: $R_1$ เป็น Normal ค่าเฉลี่ย 0.08 SD 0.18 ค่าเฉลี่ยของกำลังสองคือ variance บวกค่าเฉลี่ยกำลังสอง (สูตรลัดของ variance) $0.0324+0.0064=0.0388$ ได้ผลเดียวกันโดยไม่ใช้ calculus หน้านี้เลือกตัวอย่างที่ตอบได้สองทางโดยตั้งใจ เพื่อให้เห็นว่าทางไหนพลาด

ขั้นที่ 7 — ทำไม (dW)² แทนด้วย dt ได้ แม้มีตัวคูณ

ในผลรวมกำลังสองที่ผ่านมา ทุกท่อนมีน้ำหนัก 1 แต่เมื่อ $f$ ไม่ใช่ $x^2$ พจน์กำลังสองจะมีตัวคูณ $\tfrac12f''(W_{i-1})$ ที่เปลี่ยนไปตามเส้นทาง ยังแทน $(\Delta W_i)^2$ ด้วย $\Delta t$ ได้ไหม? ให้ $g_{i-1}$ เป็นตัวคูณใด ๆ ที่รู้ค่าตอนต้นท่อน และมีค่าเฉลี่ยกำลังสองไม่เกิน $G^2$ แล้ววัดผลรวมของส่วนต่าง $e_i:=(\Delta W_i)^2-\Delta t$

\[ \begin{aligned} D_n&:=\textstyle\sum_{i=1}^n g_{i-1}e_i,\\ \mathbb E[g_{i-1}e_i]&=\mathbb E[g_{i-1}]\,\mathbb E[e_i]=0,\\ \mathbb E[g_{i-1}e_i\,g_{j-1}e_j]&=0\quad(i\lt j),\\ \operatorname{Var}(D_n)&=\textstyle\sum_i\mathbb E[g_{i-1}^2]\,\mathbb E[e_i^2]\\ &\le n\,G^2\cdot2\Delta t^2\\ &=2G^2T\,\Delta t\ \to\ 0. \end{aligned} \]

บรรทัดที่สามคือหัวใจ: เมื่อ $i\lt j$ ทุกอย่างยกเว้น $e_j$ รู้ค่าแล้วตอนต้นท่อน $j$ และ $e_j$ อิสระจากมันพร้อมค่าเฉลี่ยศูนย์ ค่าเฉลี่ยของผลคูณจึงเป็นศูนย์ variance ของผลรวมเหลือแค่พจน์ทแยง $n$ พจน์ พจน์ละขนาด $\Delta t^2$ รวมแล้วหายไปตาม $\Delta t$

ข้อสรุปคือ $\sum g_{i-1}(\Delta W_i)^2$ กับ $\sum g_{i-1}\Delta t$ ต่างกันน้อยลงเรื่อย ๆ จนเป็นศูนย์ นี่คือความหมายเต็มของ $(dW)^2=dt$: ภายในผลรวมที่ตัวคูณรู้ค่าก่อนก้าว กำลังสองของการขยับใช้เวลาแทนได้

ลองกับ $g_{i-1}=W_{i-1}$ ซึ่งมี $\mathbb E[W_{i-1}^2]=(i-1)\Delta t$: variance คือ $\sum_i(i-1)\Delta t\cdot2\Delta t^2=T^3(n-1)/n^2$ ได้ SD 0.0629 ที่ 252 ท่อน และ 0.0032 ที่ 98,280 ท่อน

ขั้นที่ 8 — ตารางคูณของ Itô: พจน์ไหนรอด

การขยับเล็ก ๆ มีสองชนิด คือเวลา $\Delta t$ กับการขยับสุ่ม $\Delta W$ ผลคูณอันดับสองมีสามแบบ และกำลังสามจะโผล่เป็นเศษใน Taylor วัดขนาดแบบเดียวกับผลรวมกำลังสอง: บวกทุกท่อนหนึ่งปีแล้วดูว่าเหลือเท่าไร ใช้ $\mathbb E|Z|=\sqrt{2/\pi}$ และ $\mathbb E|Z|^3=2\sqrt{2/\pi}$ ซึ่งได้จากการอินทิเกรต density ของ Normal ครึ่งขวาแล้วคูณสอง

\[ \begin{aligned} \textstyle\sum_i(\Delta t)^2&=n\,\Delta t^2=T^2/n,\\ \mathbb E\textstyle\sum_i|\Delta W_i|\,\Delta t&=n\,\Delta t^{3/2}\,\mathbb E|Z|\\ &=\sqrt{2/\pi}\;T^{3/2}/\sqrt n,\\ \mathbb E\textstyle\sum_i|\Delta W_i|^3&=n\,\Delta t^{3/2}\,\mathbb E|Z|^3\\ &=2\sqrt{2/\pi}\;T^{3/2}/\sqrt n,\\ n=252&:\ 0.0040,\ 0.0503,\ 0.1005,\\ n=98{,}280&:\ 0.00001,\ 0.0025,\ 0.0051. \end{aligned} \]

ทั้งสามหายไปเมื่อ $n$ โต เพราะขนาดต่อท่อนมีเวลามากกว่าหนึ่งกำลัง ($\Delta t^2$ หรือ $\Delta t^{3/2}$) บวก $n$ ท่อนแล้วยังเหลือ $n$ หรือ $\sqrt n$ อยู่ในตัวหาร มีแค่ $(\Delta W)^2$ ที่ขนาดต่อท่อนเป็น $\Delta t$ พอดี จึงรอดและรวมได้ $T$ กฎทั่วไปคือ $|\Delta W|^p$ มีขนาดต่อท่อน $\Delta t^{p/2}$ บวก $n$ ท่อนได้สัดส่วนกับ $n^{1-p/2}$: กำลังต่ำกว่าสองโตไม่สิ้นสุด เกินสองหายไป สองพอดีคือเส้นแบ่ง Taylor จึงต้องไปถึงพจน์ที่สองพอดี และไม่ต้องไปถึงพจน์ที่สาม

เขียนผลเป็นตัวย่อได้ตารางสามข้อ $(dt)^2=0$, $dW\,dt=0$ และ $(dW)^2=dt$ ตัวย่อนี้อ่านว่า “เมื่อบวกทั้งช่วง” เสมอ ไม่ใช่สมการของท่อนเดียว

ขั้นที่ 9 — chain rule ของ Itô สำหรับ f(W)

ตอนนี้มีของครบที่จะซ่อม chain rule สำหรับ $f$ ใด ๆ ที่มีอนุพันธ์ถึงอันดับสาม และอนุพันธ์อันดับสามมีขนาดไม่เกิน $M$ เขียน Taylor ของแต่ละท่อนถึงพจน์กำลังสอง เศษที่เหลือไม่เกิน $\tfrac M6|\Delta W_i|^3$ แล้วบวกทุกท่อน

\[ \begin{aligned} f(W_i)-f(W_{i-1})&=f'(W_{i-1})\,\Delta W_i\\ &\quad+\tfrac12f''(W_{i-1})(\Delta W_i)^2+r_i,\\ |r_i|&\le\tfrac M6|\Delta W_i|^3,\\ f(W_T)-f(W_0)&=\textstyle\sum_i f'(W_{i-1})\,\Delta W_i\\ &\quad+\tfrac12\textstyle\sum_i f''(W_{i-1})(\Delta W_i)^2\\ &\quad+\textstyle\sum_i r_i,\\ \tfrac12\textstyle\sum_i f''(W_{i-1})(\Delta W_i)^2&\to\tfrac12\int_0^Tf''(W_t)\,dt,\\ \textstyle\sum_i|r_i|&\to0,\\ df(W_t)&=f'(W_t)\,dW_t+\tfrac12f''(W_t)\,dt. \end{aligned} \]

บรรทัดที่หกคือผลของตัวคูณที่รู้ค่าก่อนก้าว โดยใช้ $g_{i-1}=\tfrac12f''(W_{i-1})$ จึงแทน $(\Delta W_i)^2$ ด้วย $\Delta t$ ได้ แล้วผลรวมกลายเป็นพื้นที่ใต้กราฟตามเวลา บรรทัดที่เจ็ดคือตารางคูณ: เศษกำลังสามรวมกันแล้วหายไป บรรทัดสุดท้ายเป็นตัวย่อของสามบรรทัดก่อนหน้า

เทียบกับ chain rule ปกติ $df=f'\,dW$ ส่วนที่เพิ่มคือ $\tfrac12f''\,dt$ เรียกว่า Itô correction ถ้า $f$ โค้งหงาย ($f''\gt0$) มันดันค่าเฉลี่ยของ $f$ ขึ้น ใส่ $f(w)=w^2$ ได้ $f''=2$ และ $d(W^2)=2W\,dW+dt$ คือผลรวมแรกที่เฉลี่ยศูนย์บวกเวลา ในรูปย่อ

ขั้นที่ 10 — ตรวจด้วยการสุ่ม: 20,000 เส้นทาง ท่อนละหนึ่งวันทำการ

โจทย์ให้อะไรมาบ้าง: โค้ดท้ายหน้าสร้าง 20,000 เส้นทางหนึ่งปี ท่อนละหนึ่งวันทำการ (252 ท่อน) ด้วย seed 131 วัดค่าเฉลี่ยของ $W_1^2$ และสองผลรวมของมัน และลองฟังก์ชัน $f(w)=e^w$ ที่ Itô กับ chain rule ปกติทำนายต่างกัน ฟังก์ชันนี้มี $f'=f''=e^w$ เอาค่าเฉลี่ยของสองข้าง พจน์ $e^W dW$ หายเพราะตัวคูณรู้ค่าก่อนก้าว เหลือสมการของค่าเฉลี่ยที่แก้ได้ด้วย calculus ธรรมดา

\[ \begin{aligned} de^{W_t}&=e^{W_t}dW_t+\tfrac12e^{W_t}dt,\\ m(t)&:=\mathbb E[e^{W_t}],\qquad m(0)=1,\\ m'(t)&=\tfrac12m(t),\\ m(1)&=e^{1/2}\approx1.6487. \end{aligned} \]

ขั้นที่ 11 — ผลบนโต๊ะ: ความผันผวนวัดได้แม่น drift วัดแทบไม่ได้

ผลรวมกำลังสองที่ไม่หายคือเครื่องวัดความผันผวน ถ้าผลตอบแทนรายวันคือ $r_i=\sigma\Delta W_i$ (drift ของหนึ่งวันเล็กจนทิ้งได้) ผลรวม $r_i^2$ ของหนึ่งปีคือ $\sigma^2Q_{252}$ ส่วน drift ต้องประมาณจากผลรวมของผลตอบแทนเอง ซึ่งเท่ากับ $R_T$ ไม่ว่าจะซอยกี่ท่อน

\[ \begin{aligned} \widehat{\sigma^2}&=\textstyle\sum_{i=1}^{252}r_i^2=\sigma^2Q_{252},\\ \operatorname{SD}(\widehat{\sigma^2})&=\sigma^2\sqrt{2/252}\approx0.002886,\\ \operatorname{SD}(\hat\sigma)&\approx\frac{0.002886}{2(0.18)}\approx0.0080,\\ \hat\mu&=R_T/T=\mu+\sigma W_T/T,\\ \operatorname{SD}(\hat\mu)&=\sigma/\sqrt T,\\ 2\sigma/\sqrt T&=0.08,\\ T&=(0.36/0.08)^2=20.25. \end{aligned} \]

หนึ่งปีของข้อมูลรายวันวัดความผันผวน 18% ได้แม่นราว ±0.80 จุด บรรทัดที่สามใช้ว่ารากของตัวเลขขยับครึ่งหนึ่งของสัดส่วนที่ตัวเลขขยับ ($\sqrt{v+\delta}\approx\sqrt v+\delta/(2\sqrt v)$) ถ้าซอยถี่ขึ้น SD นี้ลดลงอีกตาม $1/\sqrt n$

drift ไม่ได้อะไรจากการซอยเลย $\hat\mu$ ขึ้นกับปลายทาง $R_T$ ตัวเดียว หนึ่งปีให้ SD 18% ใหญ่กว่า drift 8% เอง จะเห็น drift 8% ห่างศูนย์สอง SD ต้องใช้ข้อมูล 20.25 ปี นี่คือเหตุผลที่ตลาดตั้งราคา option ด้วยความผันผวนได้ แต่ไม่มีใครตกลงกันได้เรื่อง expected return

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

ใช้ chain rule ปกติกับ payoff ที่โค้ง: สัญญาในโจทย์เปิดเรื่องถูกตั้งราคา \$6,400 แทน \$38,800 ส่วนที่ขาดคือ $\tfrac12f''$ คูณ quadratic variation ในที่นี้ $\tfrac12(2)(\sigma^2T)=0.0324$ ของ notional ทุก payoff ที่โค้งหงายถูกตีราคาต่ำไปแบบนี้ ส่วน payoff ที่โค้งคว่ำถูกตีสูงไป

ใช้ตัวคูณจากปลายท่อน: ถ้าคูณการขยับด้วย $W_i$ แทน $W_{i-1}$ ผลรวมจะเป็น $\sum2W_{i-1}\Delta W_i+2Q_n$ ค่าเฉลี่ยกลายเป็น $2T$ แทน 0 ในสี่ก้าวด้วยมือได้ $-0.57365+2(0.619875)=0.6661$ แทน −0.574 ใน backtest นี่คือการใช้ราคาที่ยังไม่เกิด ซึ่ง Itô integral วัดเป็นดอลลาร์ให้ดู

อ่าน $(dW)^2=dt$ เป็นสมการของวันเดียว: ก้าวเดียวมี $(\Delta W)^2=\Delta t\,Z^2$ ซึ่ง SD $\sqrt2\,\Delta t$ ใหญ่กว่าค่าเฉลี่ยของมันเอง ผลของ gamma ต่อ P&L ของวันหนึ่งคือ $\tfrac12\Gamma(\Delta S)^2$ ที่เกิดจริง ไม่ใช่ $\tfrac12\Gamma S^2\sigma^2\Delta t$ ทั้งสองมีค่าเฉลี่ยเท่ากัน แต่วันที่ราคาขยับ 3 SD ตัวแรกใหญ่กว่าตัวที่สอง 9 เท่า การอธิบาย P&L รายวันด้วยตัวที่สองจะผิดทุกวันที่ตลาดขยับแรง

ใช้ทำอะไรบนโต๊ะจริง

realized variance ที่โต๊ะ option ดูทุกวันคือ $\sigma^2Q_n$ ของผลบนโต๊ะด้านบน และสัญญาในโจทย์เปิดเรื่องเป็นญาติของ variance swap ซึ่งจ่ายตาม realized variance โดยตรง ส่วน Itô correction $\tfrac12f''\,dt$ จะกลับมาใน สมการ Black–Scholes เป็นพจน์ gamma ที่แลกกับการเสื่อมมูลค่าตามเวลาของ option

ตลาดจริงวัดหรือ hedge ได้วันละไม่กี่ครั้ง ที่ 252 ท่อนต่อปี $Q$ คลาดได้ 8.9% ของค่า กฎ $(dW)^2=dt$ จึงเป็นการประมาณที่ดีขึ้นเมื่อวัดถี่ขึ้น และ P&L ของการ delta hedge จะวัดว่าการปรับวันละครั้งทำให้ผลคลาดไปเท่าไร ราคาจริงยังกระโดดตอนข่าว ซึ่งทำให้ผลรวมกำลังสองรวมกำลังสองของการกระโดดเข้าไปด้วย และถ้าวัดถี่ระดับวินาที ราคาที่เด้งระหว่าง bid กับ ask จะทำให้ realized variance พองเกินจริง (realized volatility ดูเรื่องนี้ละเอียด)

งานประจำวันอีกอย่างคือตรวจโค้ดจำลอง: realized variance ของเส้นทางที่จำลองได้ต้องอยู่ใกล้ $\sigma^2T$ ภายใน $\sigma^2T\sqrt{2/n}$ ถ้าห่างกว่าหลายเท่า แปลว่าโค้ดลืมคูณ $\sqrt{\Delta t}$ หรือใช้หน่วยเวลาผิด

ใช้ $\mathbb E[R_T^2]=\mu^2T^2+\sigma^2T$ กับ $T=0.5$: $0.0064(0.25)+0.0324(0.5)=0.0016+0.0162=0.0178$ จ่ายเฉลี่ย \$17,800 chain rule ปกติเห็นแค่ $\mu^2T^2=0.0016$ หรือ \$1,600 ส่วนที่ขาด \$16,200 คือ $\sigma^2T$ ซึ่งโตตามเวลาตรง ๆ ส่วนของ drift โตตามกำลังสองของเวลา ช่วงยิ่งสั้น ส่วนของความผันผวนยิ่งครอง

2. ใช้ chain rule ของ Itô หา $\mathbb E[W_1^4]$ โดยไม่อินทิเกรต density

เฉลย

$f(w)=w^4$ มี $f'=4w^3$ และ $f''=12w^2$ จึงได้ $d(W^4)=4W^3dW+6W^2dt$ เอาค่าเฉลี่ย พจน์ $dW$ หายเพราะตัวคูณรู้ค่าก่อนก้าว เหลือ $\mathbb E[W_T^4]=6\int_0^T\mathbb E[W_t^2]\,dt=6\int_0^Tt\,dt=3T^2$ ที่ $T=1$ ได้ 3 ตรงกับ $\mathbb E[Z^4]=3$ ที่ได้จากการอินทิเกรต density ของ Normal ทีละส่วน

3. ต้องใช้ผลตอบแทนรายวันกี่วันจึงวัดความผันผวน 18% ได้ SD ±0.5 จุด และถ้าใช้แท่ง 5 นาทีตลอดหนึ่งปีจะได้ SD เท่าไร?

เฉลย

จากผลบนโต๊ะ SD ของ $\hat\sigma$ จาก $n$ ผลตอบแทนคือ $\sigma\sqrt{2/n}/2=\sigma/\sqrt{2n}$ ตั้ง $0.18/\sqrt{2n}=0.005$ ได้ $2n=36^2=1{,}296$ คือ $n=648$ วัน ราว 2.57 ปีของวันทำการ วันทำการหนึ่งวันมี 390 นาที จึงมีแท่ง 5 นาที 78 แท่งต่อวัน หนึ่งปีได้ $78\times252=19{,}656$ แท่ง SD คือ $0.18/\sqrt{39{,}312}\approx0.00091$ หรือ ±0.09 จุด แต่ drift ยังมี SD 18% เท่าเดิม เพราะไม่ได้อะไรจากการซอย

function check(n, T) {
  if (!Number.isInteger(n) || n < 1) throw new RangeError('Need a whole number of steps n >= 1');
  if (!(T > 0) || !Number.isFinite(T)) throw new RangeError('Need a finite horizon T > 0');
}
// Smooth path x(t) = t on [0, T]: x_T^2 = sum 2 x dx + sum dx^2, and the second sum is T^2/n.
function smoothSums(n, T = 1) {
  check(n, T);
  return {first: T * T * (n - 1) / n, squares: T * T / n};
}
// The same exact identity on a Brownian path built from given standard Normals.
function handPath(z, dt) {
  const dW = z.map(x => Math.sqrt(dt) * x), W = [0];
  for (const d of dW) W.push(W[W.length - 1] + d);
  const ito = dW.reduce((s, d, i) => s + 2 * W[i] * d, 0);
  const Q = dW.reduce((s, d) => s + d * d, 0);
  return {W, ito, Q, total: ito + Q, WT2: W[W.length - 1] ** 2};
}
// Binomial tree with u = exp(sigma sqrt(dt)): every log step is +-sigma sqrt(dt), so the squares add to sigma^2 T on every path.
function treeSquares(sigma, T, n) {
  check(n, T);
  const step = sigma * Math.sqrt(T / n);
  return {logStep: step, u: Math.exp(step), squareSum: n * step * step};
}
// Sum of squared increments Q_n: mean T and SD T sqrt(2/n), because E[Z^2] = 1 and Var(Z^2) = 2.
const qvSD = (n, T = 1) => T * Math.sqrt(2 / n);
// SD of sum W_(i-1) [(dW_i)^2 - dt]: the weight is known before each step, so cross terms vanish.
const weightedSD = (n, T = 1) => Math.sqrt(T ** 3 * (n - 1) / (n * n));
// Expected size of the three products that the multiplication table sends to zero.
function tableSizes(n, T = 1) {
  check(n, T);
  const absZ = Math.sqrt(2 / Math.PI);
  return {dtdt: T * T / n, dWdt: absZ * T ** 1.5 / Math.sqrt(n), cube: 2 * absZ * T ** 1.5 / Math.sqrt(n)};
}
// Contract paying notional * R_T^2 with R_t = mu t + sigma W_t (Brownian motion with drift).
function squaredReturnPayout(mu, sigma, T, notional) {
  const chainRule = notional * mu * mu * T * T;
  return {chainRule, ito: chainRule + notional * sigma * sigma * T, missing: notional * sigma * sigma * T};
}
// mulberry32 + Box-Muller: seeded standard Normals, so every reader gets the same numbers.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Simulate paths on a grid and average W_T^2, its two pieces, e^(W_T) and R_T^2.
function simulate(paths, steps, T, mu, sigma, seed) {
  check(steps, T);
  const z = normals(seed), sq = Math.sqrt(T / steps);
  let w2 = 0, ito = 0, q = 0, qq = 0, ew = 0, r2 = 0;
  for (let p = 0; p < paths; p++) {
    let w = 0, s = 0, Q = 0;
    for (let k = 0; k < steps; k++) {
      const d = sq * z();
      s += 2 * w * d; Q += d * d; w += d;
    }
    const R = mu * T + sigma * w;
    w2 += w * w; ito += s; q += Q; qq += Q * Q; ew += Math.exp(w); r2 += R * R;
  }
  const meanQ = q / paths;
  return {meanW2: w2 / paths, meanIto: ito / paths, meanQ, sdQ: Math.sqrt((qq - paths * meanQ * meanQ) / (paths - 1)),
    meanExpW: ew / paths, meanR2: r2 / paths};
}
const mu = 0.08, sigma = 0.18, N = 20000;
const hand = handPath([0.31, -1.20, 0.85, 0.47], 0.25);
const sim = simulate(N, 252, 1, mu, sigma, 131);
const se = sd => sd / Math.sqrt(N); // standard error from the exact one-path SD
const sdRV = sigma * sigma * Math.sqrt(2 / 252);
console.log(JSON.stringify({

สิ่งที่ควรตอบได้หลังอ่าน

  • $x_T^2-x_0^2=\sum2x_{i-1}\Delta x_i+\sum(\Delta x_i)^2$ เป็นจริงทุกเส้นทาง chain rule ปกตินับแค่ผลรวมแรก
  • บนเส้นเรียบผลรวมกำลังสองหายตาม $1/n$ บนเส้นทาง Brownian มันเฉลี่ย $T$ และคลาด $T\sqrt{2/n}$ ส่วนต้นไม้ binomial ที่ $u=e^{\sigma\sqrt{\Delta t}}$ ได้ $\sigma^2T$ พอดีทุกเส้นทาง
  • $(dW)^2=dt$ แปลว่า $\sum g_{i-1}(\Delta W_i)^2$ กับ $\sum g_{i-1}\Delta t$ ต่างกันจนเป็นศูนย์เมื่อตัวคูณรู้ค่าก่อนก้าว ส่วน $dW\,dt$, $(dt)^2$ และกำลังสามหายไป
  • $df=f'\,dW+\tfrac12f''\,dt$: สัญญา \$1 ล้าน คูณ $R^2$ จ่ายเฉลี่ย \$38,800 ไม่ใช่ \$6,400 และ $\mathbb E[e^{W_1}]=1.6487$ ไม่ใช่ 1
  • ข้อมูลรายวันหนึ่งปีวัดความผันผวน 18% ได้ ±0.80 จุด แต่ต้องใช้ 20.25 ปีจึงเห็น drift 8% ห่างศูนย์สอง SD

หน้าถัดไป Itô's lemma ใช้ Taylor แบบเดียวกันกับ $f(t,X_t)$ ที่ $X$ มีทั้ง drift และความผันผวน ได้กฎเต็มรูป แล้วใช้มันถามว่าราคา SPY ปีหน้าอยู่ตรงกลางที่ไหน
