13.1 Why Ordinary Calculus Fails on Brownian Motion

chain rule ทิ้งพจน์กำลังสองของการขยับ เพราะบนเส้นเรียบผลรวมของพจน์นี้หายไป แต่บนเส้นทาง Brownian ผลรวมนี้เท่ากับเวลาที่ผ่านไป จึงทิ้งไม่ได้

ลูกค้าขอซื้อสัญญาตัวหนึ่งจากโต๊ะเทรดของธนาคาร สัญญานี้ผูกกับ SPY (SPY คือกองทุนที่ซื้อขายเหมือนหุ้นและวิ่งตามดัชนี S&P 500) ครบหนึ่งปีแล้วสัญญาจ่ายเงินตามว่า SPY ขยับไปไกลแค่ไหน ไม่สนว่าขึ้นหรือลง เช่น SPY ขึ้น 10% หรือลง 10% สัญญาจ่ายเท่ากัน คือ $\$1{,}000{,}000\times0.10^2=\$10{,}000$ โต๊ะต้องรู้ว่าโดยเฉลี่ยสัญญาจะจ่ายเท่าไร จึงจะตั้งราคาขายได้โดยไม่ขาดทุน

ของที่รู้ (ตัวเลขสมมติ):

  • เงินตั้งต้นของสัญญา (notional) $N=\$1$ ล้าน ครบปีสัญญาจ่าย $N\times R_1^2$ โดย $R_1$ คือผลตอบแทนของ SPY ตลอดหนึ่งปี เช่น ขึ้น 10% คือ $R_1=0.10$
  • โต๊ะจำลองผลตอบแทนสะสมถึงเวลา $t$ ปีด้วย Brownian motion ที่มี drift: $R_t=\mu t+\sigma W_t$ ก้อน $\mu t$ คือส่วนที่โตสม่ำเสมอ ก้อน $\sigma W_t$ คือส่วนที่สุ่ม โดย $W_t$ เป็นเส้นทางสุ่มที่มีค่าเฉลี่ยศูนย์
  • drift $\mu=8\%$ ต่อปี คือผลตอบแทนเฉลี่ยต่อปี
  • ความผันผวน $\sigma=18\%$ ต่อปี คือขนาดที่ผลตอบแทนหนึ่งปีแกว่งรอบค่าเฉลี่ย วัดเป็น SD (standard deviation)

นักวิเคราะห์ใช้ chain rule จากวิชา calculus: $d(R^2)=2R\,dR$ เขาให้เหตุผลว่าส่วนสุ่มเฉลี่ยเป็นศูนย์ ค่าเฉลี่ยของ $R_t$ จึงเป็น $\mu t$ และค่าเฉลี่ยของการขยับ $dR$ เป็น $\mu\,dt$ การขยับข้างหน้าไม่ขึ้นกับค่าที่ผ่านมา ค่าเฉลี่ยของ $R\,dR$ จึงเป็นผลคูณของสองค่าเฉลี่ยนี้ จากนั้นบวกทั้งปี:

\[\begin{aligned}\mathbb E[d(R^2)]&=2(\mu t)(\mu\,dt),\\\mathbb E[R_1^2]&=\int_0^12\mu^2t\,dt=\mu^2\\&=0.08^2=0.0064,\\N\,\mathbb E[R_1^2]&=0.0064\times\$1{,}000{,}000\\&=\$6{,}400.\end{aligned}\]

โต๊ะขายสัญญานี้ที่ราว \$6,400 ได้ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ได้ ค่าเฉลี่ยจริงของ $R_1^2$ มีอีกก้อนหนึ่งคือ $\sigma^2$ ซึ่ง chain rule มองไม่เห็น หน้านี้จะพิสูจน์ทีละขั้นในขั้นที่ 6:

\[\begin{aligned}\mathbb E[R_1^2]&=\mu^2+\sigma^2\\&=0.0064+0.0324=0.0388,\\N\,\mathbb E[R_1^2]&=0.0388\times\$1{,}000{,}000\\&=\$38{,}800.\end{aligned}\]

สัญญาจ่ายเฉลี่ยมากกว่าที่นักวิเคราะห์คิดราว $38{,}800/6{,}400\approx6$ เท่า ก้อนที่หายไปคือ $38{,}800-6{,}400=\$32{,}400$ ซึ่งเท่ากับ $\sigma^2$ คูณเวลาหนึ่งปีคูณ $N$ ก้อนนี้มาจากการขยับเล็ก ๆ ที่ยกกำลังสองแล้วบวกกัน ซึ่ง chain rule ทิ้งไป ถ้าขายที่ \$6,400 ธนาคารจะขาดทุนเฉลี่ย \$32,400 ต่อสัญญา (ยังไม่นับดอกเบี้ย)

ภาพรวมก่อนลงสูตร

นักวิเคราะห์พลาดตรงไหน? ต้องย้อนดูว่า chain rule มาจากไหน ถ้า $x$ ขยับไปเล็กน้อย $\Delta x$ ค่าของ $f(x)$ เปลี่ยนตาม Taylor ดังนี้

\[\Delta f=f'(x)\,\Delta x+\tfrac12f''(x)(\Delta x)^2+\cdots\]

chain rule $df=f'(x)\,dx$ เก็บแค่พจน์แรก แล้วทิ้งพจน์กำลังสอง $\tfrac12f''(\Delta x)^2$ การทิ้งนี้ถูกเมื่อ $x$ เดินเป็นเส้นเรียบ เพราะถ้าซอยเวลาเป็นท่อนเล็กลงเรื่อย ๆ แล้วบวก $(\Delta x)^2$ ของทุกท่อน ผลรวมจะหดเป็นศูนย์

เส้นทาง Brownian คือเส้นทางสุ่มที่ใช้จำลองการแกว่งของราคา มันไม่เป็นแบบเส้นเรียบ ในเวลาสั้น ๆ $\Delta t$ มันขยับราว $\sqrt{\Delta t}$ ซึ่งใหญ่กว่า $\Delta t$ มาก เช่น $\Delta t=0.01$ ปี ขยับราว $\sqrt{0.01}=0.1$ กำลังสองของการขยับจึงมีขนาดราว $\Delta t$ พอบวกทุกท่อนในหนึ่งปี ผลรวมได้ราวหนึ่งปีพอดี และไม่หดเลย

รูปด้านล่างแสดงเรื่องนี้เรื่องเดียว เส้นเขียวของเส้นเรียบจมลงหาศูนย์ ส่วนเส้นน้ำเงินของเส้นทาง Brownian นิ่งเข้าหาเวลาที่ผ่านไป หน้านี้จะเดินตามลำดับนี้

  • วัดผลรวมกำลังสองด้วยมือ แล้วหาค่าเฉลี่ยกับความคลาดของมัน
  • เห็นผลรวมนี้ในต้นไม้ binomial ที่โต๊ะใช้ตั้งราคา option (สัญญาที่ให้สิทธิ์ซื้อหรือขายหุ้นในราคาที่ตกลงไว้ล่วงหน้า)
  • ตอบโจทย์สัญญา \$1 ล้าน
  • พิสูจน์ว่าทำไม $(dW)^2$ แทนด้วย $dt$ ได้ แล้วได้ตารางคูณของ Itô กับ chain rule ฉบับแก้
  • จบที่โต๊ะ: ข้อมูลหนึ่งปีวัดความผันผวนได้แม่น แต่วัด drift แทบไม่ได้

Brownian motion
เส้นทางสุ่มที่เริ่มที่ศูนย์ ในทุกช่วงเวลายาว $\Delta t$ มันขยับสุ่มแบบ Normal ที่มีค่าเฉลี่ยศูนย์และ variance $\Delta t$ และช่วงที่ไม่ทับกันขยับอิสระต่อกัน โต๊ะใช้มันเป็นส่วนสุ่มของราคา
Drift
ส่วนที่โตสม่ำเสมอของผลตอบแทน คือผลตอบแทนเฉลี่ยต่อปี เขียนด้วย $\mu$
Chain rule
กฎหาว่า $f(x)$ เปลี่ยนเท่าไรเมื่อ $x$ เปลี่ยน คือ $df=f'(x)\,dx$ โต๊ะใช้มันทุกครั้งที่มูลค่าของสัญญาขึ้นกับราคา เช่นราคา option ขึ้นกับราคาหุ้น มันถูกบนเส้นเรียบ เพราะบนเส้นเรียบพจน์กำลังสองทิ้งได้
Increment
การขยับของเส้นทางในหนึ่งท่อนเวลา $\Delta W_i=W_{t_i}-W_{t_{i-1}}$ หน้านี้เอามันมายกกำลังสองแล้วบวกกัน
Quadratic variation
ซอยช่วงเวลาเป็นท่อน ยกกำลังสองการขยับของทุกท่อนแล้วบวกกัน แล้วซอยให้ละเอียดขึ้นเรื่อย ๆ ค่าที่ผลรวมนี้เข้าใกล้เรียกว่า quadratic variation สำหรับ Brownian motion มาตรฐาน ค่านี้คือเวลาที่ผ่านไป $T$ มันวัดว่าเส้นทางขรุขระสะสมแค่ไหน และเป็นก้อนที่ chain rule ปกติทิ้งไป
Itô correction
พจน์ $\tfrac12f''\,dt$ ที่ต้องเติมใน chain rule เมื่อสิ่งที่อยู่ข้างใน $f$ เป็นเส้นทาง Brownian มันเกิดเพราะความโค้ง $f''$ คูณกับกำลังสองของการขยับ ซึ่งไม่หาย
Itô multiplication table
กฎย่อสามข้อ $(dW)^2=dt$, $dW\,dt=0$ และ $(dt)^2=0$ แต่ละข้อย่อผลรวมทั้งช่วงที่หน้านี้พิสูจน์ ใช้ตัดสินว่าพจน์ไหนใน Taylor ต้องเก็บ พจน์ไหนทิ้งได้
Realized variance
เอาผลตอบแทนของแต่ละวัน (หรือแต่ละช่วง) มายกกำลังสองแล้วบวกกัน มันคือ quadratic variation ที่วัดจากข้อมูลจริง ใช้ประมาณความผันผวน และเป็นตัวที่ variance swap (สัญญาที่จ่ายตาม realized variance) ใช้คิดเงิน

ขั้นที่ 1 — บนเส้นเรียบ chain rule ทิ้งพจน์กำลังสองได้

ก่อนอื่นต้องเห็นให้ชัดว่า chain rule ทิ้งอะไรไป วิธีคือเขียนสมการที่จริงเสมอ ไม่ประมาณอะไรเลย แล้วชี้ว่าก้อนไหนคือก้อนที่ chain rule นับ ก้อนไหนคือก้อนที่มันทิ้ง

ซอยช่วงเวลาเป็น $n$ ท่อน ให้ $x_i$ คือตำแหน่งที่ปลายท่อนที่ $i$ และ $\Delta x_i=x_i-x_{i-1}$ คือการขยับในท่อนนั้น ตำแหน่งปลายท่อนเท่ากับตำแหน่งต้นท่อนบวกการขยับ ยกกำลังสองแล้วกระจาย จากนั้นบวกทุกท่อน ฝั่งซ้ายหักกันเป็นทอด ๆ จนเหลือแค่ปลายลบต้น $x_T^2-x_0^2$ ตัวอย่างที่ใช้คือเส้นตรง $x(t)=t$ บนหนึ่งปี ซอย $n$ ท่อนเท่ากัน ท่อนละ $\Delta x_i=1/n$

\[ \begin{aligned} x_i^2-x_{i-1}^2&=(x_{i-1}+\Delta x_i)^2-x_{i-1}^2\\ &=2x_{i-1}\Delta x_i+(\Delta x_i)^2,\\ x_T^2-x_0^2&=\sum_{i=1}^n2x_{i-1}\Delta x_i\\ &\quad+\sum_{i=1}^n(\Delta x_i)^2,\\ \sum_{i=1}^n(\Delta x_i)^2&=n\cdot\frac1{n^2}=\frac1n,\\ n=4,\ 252,\ 1{,}000&:\ 0.25,\ 0.00397,\ 0.001. \end{aligned} \]

สมการผลรวมจริงทุก $n$ เพราะได้จากพีชคณิตล้วน ๆ ไม่มีการตัดพจน์ ผลรวมแรก $\sum2x_{i-1}\Delta x_i$ คือสิ่งที่ chain rule $d(x^2)=2x\,dx$ นับ ผลรวมที่สอง $\sum(\Delta x_i)^2$ คือก้อนที่มันทิ้ง บนเส้นตรงก้อนที่ทิ้งเหลือ $1/n$ ซอยละเอียดขึ้นก็หายไป ส่วนผลรวมแรกเท่ากับ $1-1/n$ ซึ่งเข้าหา $x_1^2=1$ เช่น $1-1/4=0.75$ และ $1-1/1{,}000=0.999$

ทำไมก้อนที่สองหาย? บนเส้นที่ความชันไม่เกิน $c$ แต่ละท่อนขยับไม่เกิน $c\,\Delta t$ กำลังสองจึงไม่เกิน $c^2\Delta t^2$ บวก $n$ ท่อนได้ไม่เกิน $n\,c^2\Delta t^2=c^2T\,\Delta t$ ยังมี $\Delta t$ ค้างอยู่หนึ่งตัว ผลรวมจึงหดเป็นศูนย์เมื่อ $\Delta t$ หด นี่คือเหตุผลเดียวที่ chain rule ทิ้งพจน์กำลังสองได้ และคือเส้นเขียวในรูปแรกของหน้า

ขั้นที่ 2 — สมการเดียวกันบนเส้นทาง Brownian: สี่ก้าวด้วยมือ

โจทย์ให้อะไรมาบ้าง: สมการผลรวมในขั้นที่แล้วใช้แค่พีชคณิต จึงจริงกับเส้นทาง Brownian ด้วย ทีนี้ลองสร้างเส้นทาง Brownian สั้น ๆ ด้วยมือ ในแต่ละท่อน Brownian motion มาตรฐาน ขยับสุ่มแบบ Normal ที่มี variance เท่ากับความยาวท่อน $\Delta t$ SD ของการขยับจึงเป็น $\sqrt{\Delta t}$ วิธีสร้างคือสุ่มเลข $Z_i$ จาก Normal ค่าเฉลี่ย 0 SD 1 แล้วคูณด้วย $\sqrt{\Delta t}$

  • ช่วงเวลา $T=1$ ปี ซอย $n=4$ ท่อน ท่อนละ $\Delta t=0.25$ ปี
  • การขยับในแต่ละท่อน $\Delta W_i=\sqrt{0.25}\,Z_i=0.5Z_i$
  • เลขสุ่มสี่ตัว (เลือกมาเป็นตัวอย่าง) $Z=(0.31,\ -1.20,\ 0.85,\ 0.47)$
  • เริ่มที่ $W_0=0$ แล้วบวกการขยับทีละท่อน $W_i=W_{i-1}+\Delta W_i$

ด้านล่างคำนวณการขยับ ตำแหน่ง ผลรวมกำลังสอง $Q_4=\sum(\Delta W_i)^2$ และผลรวมแรก $\sum2W_{i-1}\Delta W_i$ แล้วบวกสองผลรวมเทียบกับ $W_4^2$

\[ \begin{aligned} \Delta W&=(0.155,\ -0.6,\ 0.425,\ 0.235),\\ W_1,\ldots,W_4&=0.155,\ -0.445,\ -0.02,\ 0.215,\\ Q_4&=0.024025+0.36\\ &\quad+0.180625+0.055225\\ &=0.619875,\\ \textstyle\sum_i2W_{i-1}\Delta W_i&=0-0.186-0.37825\\ &\quad-0.0094=-0.57365,\\ -0.57365+0.619875&=0.046225=0.215^2. \end{aligned} \]

คำตอบ: ผลรวมแรก −0.574 บวกผลรวมกำลังสอง 0.620 ได้ $W_4^2=0.215^2=0.046225$ พอดี สมการผลรวมจึงจริงบนเส้นทางนี้ แต่ดูขนาดของก้อนที่ chain rule ทิ้ง $Q_4=0.620$ ไม่เล็กเลย มันใหญ่กว่าคำตอบทั้งก้อน $0.619875/0.046225\approx13.4$ เท่า เส้นตรงที่ 4 ท่อนก็มีก้อนนี้ (0.25) แต่มันหายไปเมื่อซอยละเอียด คำถามคือของเส้นทาง Brownian จะหายไหม

ตรวจเองใน 10 วินาที: ท่อนที่สามใช้ตำแหน่งก่อนก้าว $W_2=-0.445$ คูณการขยับ $\Delta W_3=0.425$ ได้ $2(-0.445)(0.425)=-0.37825$ การหยิบตัวคูณจากต้นท่อนแบบนี้คือหัวใจของ Itô integral

ขั้นที่ 3 — ผลรวมกำลังสองไม่หาย: เฉลี่ยเท่ากับเวลาพอดี

สี่ก้าวด้วยมือเป็นแค่เส้นทางเดียว ถ้าจะรู้ว่าผลรวมกำลังสองหายไหมเมื่อซอยละเอียด ต้องรู้สองอย่างของ $Q_n$ คือค่าเฉลี่ย และความคลาดรอบค่าเฉลี่ย (SD) เครื่องมือที่ใช้มีสามชิ้น

  • $\Delta W_i=\sqrt{\Delta t}\,Z_i$ ดังนั้น $(\Delta W_i)^2=\Delta t\,Z_i^2$
  • $\mathbb E[Z^2]=1$ เพราะ $Z$ มีค่าเฉลี่ย 0 และ variance 1 ส่วน $\mathbb E[Z^4]=3$ มาจากการอินทิเกรต density ของ Normal ทีละส่วน ใน สมบัติแปลก ๆ ของเส้นทาง Brownian สองค่านี้ให้ $\operatorname{Var}(Z^2)=3-1^2=2$
  • ท่อนที่ไม่ทับกันขยับอิสระต่อกัน variance ของผลรวมจึงเท่ากับผลรวมของ variance
\[ \begin{aligned} (\Delta W_i)^2&=\Delta t\,Z_i^2,\\ \mathbb E[(\Delta W_i)^2]&=\Delta t,\\ \operatorname{Var}\big((\Delta W_i)^2\big)&=\Delta t^2(3-1)=2\Delta t^2,\\ \mathbb E[Q_n]&=n\,\Delta t=T,\\ \operatorname{SD}(Q_n)&=\sqrt{n\cdot2\Delta t^2}=T\sqrt{2/n},\\ T=1,\ n=4&:\ \operatorname{SD}=0.707,\\ n=252&:\ \operatorname{SD}=0.0891,\\ n=98{,}280&:\ \operatorname{SD}=0.00451. \end{aligned} \]

จุดที่ต่างจากเส้นเรียบอยู่ที่ขนาดต่อท่อน การขยับของเส้นทาง Brownian มีขนาด $\sqrt{\Delta t}$ กำลังสองจึงมีขนาด $\Delta t$ ไม่ใช่ $\Delta t^2$ บวก $n$ ท่อนได้ $n\times\Delta t=n\times T/n=T$ พอดี ไม่ว่าจะซอยกี่ท่อน ไม่มี $\Delta t$ ค้างไว้ให้หดเหมือนเส้นเรียบ ส่วนความคลาดรอบ $T$ หดตาม $1/\sqrt n$ ซอยยิ่งละเอียด ผลรวมยิ่งนิ่งอยู่ที่ $T$

ค่า 0.620 ของสี่ก้าวด้วยมือต่ำกว่า 1 อยู่ $(1-0.620)/0.707\approx0.54$ SD ซึ่งปกติสำหรับ 4 ท่อน ถ้าซอยรายวัน ปีหนึ่งมี 252 ท่อน (จำนวนวันทำการของตลาดหุ้นสหรัฐในหนึ่งปี) ผลรวมจะอยู่ในช่วง $1\pm0.089$ ราวสองในสามของเส้นทาง เพราะช่วงหนึ่ง SD ของ Normal ครอบราว 68% ถ้าซอยรายนาที วันทำการเปิด 9:30 ถึง 16:00 คือ $6.5\times60=390$ นาที ปีหนึ่งจึงมี $252\times390=98{,}280$ ท่อน SD เหลือ 0.0045 ผลรวมแทบเป็นค่าคงที่ 1

ขั้นที่ 4 — ต้นไม้ binomial: ผลรวมกำลังสองเท่ากับ σ²T ทุกเส้นทาง

โจทย์ให้อะไรมาบ้าง: โต๊ะที่ตั้งราคา option มักใช้ ต้นไม้ binomial แบบจำลองนี้ซอยเวลาเป็นท่อน ในแต่ละท่อนราคามีแค่สองทาง คือขึ้นหรือลง ขาขึ้นคูณราคาด้วย $u$ ขาลงคูณด้วย $d$ โต๊ะนิยมตั้ง $u=e^{\sigma\sqrt{\Delta t}}$ และ $d=1/u$ เพราะทำให้ log ราคาขยับ $\pm\sigma\sqrt{\Delta t}$ ทุกท่อน ขนาดก้าวนี้เท่ากับ SD ของ $\sigma\,\Delta W$ ในหนึ่งท่อนพอดี เมื่อซอยละเอียดขึ้น เส้นทางในต้นไม้จึงหน้าตาเหมือนเส้นทาง Brownian และราคา option จากต้นไม้เข้าหาสูตร Black–Scholes (สูตรมาตรฐานของราคา option)

  • ความผันผวน $\sigma=0.18$ ต่อปี (เท่ากับโจทย์เปิดเรื่อง)
  • หนึ่งปีซอยเป็นสี่ไตรมาส $\Delta t=0.25$ ปี
  • ราคาเริ่ม $S_0=\$100$ (สมมติ)
  • ดูสองเส้นทาง: ขึ้น ขึ้น ลง ขึ้น และลงสี่ครั้ง

ด้านล่างหาขนาดก้าวของ log ราคา กำลังสองของมัน ผลรวมสี่ก้าว ปลายทางของสองเส้นทาง และผลรวมเมื่อซอยรายวัน 252 ท่อน

\[ \begin{aligned} \ln u&=0.18\sqrt{0.25}=0.09,\quad u=1.0942,\\ \Delta\ln S&=\pm0.09,\quad(\Delta\ln S)^2=0.0081,\\ \textstyle\sum_{i=1}^4(\Delta\ln S_i)^2&=4(0.0081)=0.0324=\sigma^2T,\\ 0.09+0.09-0.09+0.09&=+0.18,\\ 4(-0.09)&=-0.36,\\ 252\big(0.18/\sqrt{252}\big)^2&=0.0324. \end{aligned} \]

คำตอบ: สองเส้นทางจบคนละที่ เส้นแรกจบที่ $100e^{0.18}=\$119.72$ เส้นที่สองจบที่ $100e^{-0.36}=\$69.77$ แต่ทุกก้าวยาว 0.09 เท่ากัน กำลังสองของทุกก้าวจึงเป็น 0.0081 และสี่ก้าวรวมกันได้ 0.0324 เท่ากันทุกเส้นทาง ทั้ง $2^4=16$ เส้น ถ้าซอยรายวัน 252 ท่อน ผลรวมก็ยังเป็น 0.0324 ตามบรรทัดสุดท้าย ต้นไม้จึงฝัง quadratic variation $\sigma^2T$ ไว้ในทุกเส้นทาง พูดอีกแบบคือ $\sigma^2$ ของต้นไม้ก็คือผลรวมกำลังสองของการขยับของ log ราคาในหนึ่งปีนั่นเอง

ตรวจเองใน 10 วินาที: $0.09^2=0.0081$ และ $0.18^2=0.0324=4\times0.0081$ พอดี ส่วนผลรวมของการขยับเอง (ไม่ยกกำลัง) ขึ้นกับว่าขึ้นกี่ครั้ง จึงสุ่ม เส้นแรกได้ $+0.18$ เส้นที่สองได้ $-0.36$

ขั้นที่ 5 — ผลรวมแรกเฉลี่ยศูนย์ คำตอบทั้งหมดอยู่ในส่วนที่ถูกทิ้ง

รู้แล้วว่าก้อนที่ chain rule ทิ้ง ($Q_n$) เฉลี่ยเท่ากับ $T$ ทีนี้ก้อนที่ chain rule นับ คือผลรวมแรก $\sum2W_{i-1}\Delta W_i$ มีค่าเฉลี่ยเท่าไร?

ดูทีละท่อน ในท่อนที่ $i$ ตัวคูณ $W_{i-1}$ คือตำแหน่งตอนต้นท่อน มันรู้ค่าแล้วก่อนก้าว ส่วนการขยับ $\Delta W_i$ ยังไม่เกิด และไม่ขึ้นกับอะไรที่เกิดก่อนหน้า นี่คือสมบัติ independent increments ของ Brownian motion: การขยับข้างหน้าไม่ขึ้นกับข้อมูลที่มีถึงวันนี้ สองตัวที่อิสระกัน ค่าเฉลี่ยของผลคูณเท่ากับผลคูณของค่าเฉลี่ย

\[ \begin{aligned} \mathbb E[W_{i-1}\Delta W_i]&=\mathbb E[W_{i-1}]\,\mathbb E[\Delta W_i]\\ &=\mathbb E[W_{i-1}]\cdot0=0,\\ \mathbb E\Big[\textstyle\sum_i2W_{i-1}\Delta W_i\Big]&=0,\\ \mathbb E[W_T^2]&=0+\mathbb E[Q_n]=T. \end{aligned} \]

ก้อนที่ chain rule ปกตินับมีค่าเฉลี่ยศูนย์ ไม่ว่าจะซอยกี่ท่อน คำตอบทั้งหมดของ $\mathbb E[W_T^2]$ จึงมาจากก้อนที่ chain rule ทิ้ง และได้ $T$ ซึ่งตรงกับ $\operatorname{Var}(W_T)=T$ ที่รู้อยู่แล้วจากนิยามของ Brownian motion มาตรฐาน ถ้าเชื่อ chain rule ปกติ จะได้ค่าเฉลี่ยของ $W_T^2$ เป็น 0 ทั้งที่ $W_T^2$ ไม่เคยติดลบ

จังหวะที่ต้องระวังคือการแยกค่าเฉลี่ยของผลคูณ มันทำได้เพราะ $W_{i-1}$ รู้ค่าก่อนก้าว ถ้าเผลอใช้ตำแหน่งปลายท่อน $W_i$ แทน ผลคูณจะลาก $(\Delta W_i)^2$ เข้ามาด้วย แล้วค่าเฉลี่ยไม่เป็นศูนย์อีก (ดูความผิดข้อที่สองท้ายหน้า)

ขั้นที่ 6 — คำตอบของโจทย์เปิดเรื่อง: สัญญาจ่าย \$1 ล้าน คูณ R²

โจทย์ให้อะไรมาบ้าง: กลับมาที่สัญญาตอนเปิดหน้า ตอนนี้มีเครื่องมือครบที่จะหาค่าเฉลี่ยของ $R_1^2$ ให้ถูก

  • ผลตอบแทนสะสม $R_t=\mu t+\sigma W_t$ เริ่มที่ $R_0=0$
  • drift $\mu=0.08$ ต่อปี และความผันผวน $\sigma=0.18$ ต่อปี
  • ช่วงเวลา $T=1$ ปี และ notional $N=\$1$ ล้าน สัญญาจ่าย $N\,R_T^2$

ซอยหนึ่งปีเป็น $n$ ท่อน ในท่อนที่ $i$ ผลตอบแทนขยับ $\Delta R_i=\mu\,\Delta t+\sigma\,\Delta W_i$ ใช้สมการผลรวมของขั้นที่ 1 กับ $R$ แทน $x$ จะได้ $R_T^2=\sum2R_{i-1}\Delta R_i+\sum(\Delta R_i)^2$ แล้วหาค่าเฉลี่ยของสองผลรวมทีละก้อน ก้อนกำลังสองต้องกระจาย $(\Delta R_i)^2$ ก่อน ก้อนแรกใช้ว่า $\Delta R_i$ อิสระจาก $R_{i-1}$ เหมือนขั้นที่ 5 และค่าเฉลี่ยของ $R_{i-1}$ มีแค่ส่วน drift เพราะส่วนสุ่มเฉลี่ยศูนย์

\[ \begin{aligned} (\Delta R_i)^2&=\mu^2\Delta t^2+2\mu\sigma\,\Delta t\,\Delta W_i\\ &\quad+\sigma^2(\Delta W_i)^2,\\ \mathbb E\textstyle\sum_i(\Delta R_i)^2&=\mu^2T^2/n+0+\sigma^2T,\\ \mathbb E[R_{i-1}]&=\mu(i-1)\Delta t,\\ \mathbb E[2R_{i-1}\Delta R_i]&=2\mu^2(i-1)\Delta t^2,\\ \textstyle\sum_{i=1}^n2\mu^2(i-1)\Delta t^2&=\mu^2T^2\,\frac{n-1}{n},\\ \mathbb E[R_T^2]&=\mu^2T^2+\sigma^2T\\ &=0.0064+0.0324=0.0388. \end{aligned} \]

คำตอบ: ค่าเฉลี่ยของ $R_1^2$ คือ 0.0388 สัญญาจึงจ่ายเฉลี่ย $0.0388\times\$1{,}000{,}000=\$38{,}800$ เงินก้อนนี้มาจากสองที่

  • ผลรวมแรก ก้อนที่ chain rule นับ เข้าหา $\mu^2T^2=0.0064$ หรือ $0.0064\times\$1{,}000{,}000=\$6{,}400$ ตรงกับที่นักวิเคราะห์ได้
  • ผลรวมกำลังสอง ก้อนที่ chain rule ทิ้ง เข้าหา $\sigma^2T=0.0324$ หรือ \$32,400 มันมาจาก $\sigma^2(\Delta W_i)^2$ ซึ่งรวมกันได้ $\sigma^2T$ ตามขั้นที่ 3

พจน์อื่นในกำลังสองของ $\Delta R_i$ หายเมื่อซอยละเอียด พจน์ไขว้ $2\mu\sigma\,\Delta t\,\Delta W_i$ มีค่าเฉลี่ยศูนย์ ส่วน $\mu^2\Delta t^2$ รวมแล้วเหลือ $\mu^2T^2/n$ เช่นที่ 252 ท่อนเหลือ $0.0064/252=0.0000254$ เศษ $\mu^2T^2/n$ นี้แค่ย้ายจากก้อนแรกมาอยู่ก้อนที่สอง สองก้อนรวมกันจึงได้ $\mu^2T^2+\sigma^2T$ พอดีทุก $n$

ตรวจเองใน 10 วินาที: ในแบบจำลองนี้ $R_1$ เป็น Normal ค่าเฉลี่ย $\mu=0.08$ SD $\sigma=0.18$ สูตรลัดของ variance บอกว่าค่าเฉลี่ยของกำลังสองคือ variance บวกกำลังสองของค่าเฉลี่ย: $\mathbb E[R_1^2]=\sigma^2+\mu^2=0.0324+0.0064=0.0388$ ได้ผลเดียวกันโดยไม่ใช้ calculus หน้านี้เลือกตัวอย่างที่ตอบได้สองทางโดยตั้งใจ เพื่อให้เห็นว่าทางไหนพลาด

ขั้นที่ 7 — ทำไม (dW)² แทนด้วย dt ได้ แม้มีตัวคูณ

ผลรวมกำลังสองที่ผ่านมามีน้ำหนักท่อนละ 1 เท่ากันหมด แต่ถ้า $f$ ไม่ใช่ $x^2$ พจน์กำลังสองใน Taylor จะมีตัวคูณ $\tfrac12f''(W_{i-1})$ ซึ่งเปลี่ยนไปตามเส้นทาง คำถามคือ เมื่อแต่ละท่อนมีตัวคูณไม่เท่ากัน ยังแทน $(\Delta W_i)^2$ ด้วย $\Delta t$ ได้ไหม

ให้ $g_{i-1}$ คือตัวคูณใด ๆ ที่รู้ค่าแล้วตั้งแต่ต้นท่อนที่ $i$ และค่าเฉลี่ยของ $g_{i-1}^2$ ไม่เกินค่าคงที่ $G^2$ และให้ $e_i=(\Delta W_i)^2-\Delta t$ คือส่วนที่กำลังสองของการขยับต่างจากเวลา $e_i$ มีค่าเฉลี่ย 0 และ $\mathbb E[e_i^2]=\operatorname{Var}\big((\Delta W_i)^2\big)=2\Delta t^2$ จากขั้นที่ 3 ถ้าผลรวมถ่วงน้ำหนักของส่วนต่างนี้ ($D_n$ ด้านล่าง) หดเป็นศูนย์ ก็แทนได้

\[ \begin{aligned} D_n&:=\textstyle\sum_{i=1}^n g_{i-1}e_i,\\ \mathbb E[g_{i-1}e_i]&=\mathbb E[g_{i-1}]\,\mathbb E[e_i]=0,\\ \mathbb E[g_{i-1}e_i\,g_{j-1}e_j]&=0\quad(i\lt j),\\ \operatorname{Var}(D_n)&=\textstyle\sum_i\mathbb E[g_{i-1}^2]\,\mathbb E[e_i^2]\\ &\le n\,G^2\cdot2\Delta t^2\\ &=2G^2T\,\Delta t\ \to\ 0. \end{aligned} \]

หัวใจอยู่ที่พจน์ไขว้ ($i\lt j$) ตอนต้นท่อน $j$ ทุกตัวในผลคูณ $g_{i-1}e_i\,g_{j-1}$ รู้ค่าแล้ว เหลือ $e_j$ ตัวเดียวที่ยังไม่เกิด $e_j$ อิสระจากของที่รู้แล้วและมีค่าเฉลี่ยศูนย์ ค่าเฉลี่ยของผลคูณจึงเป็นศูนย์ variance ของผลรวมจึงเหลือแค่พจน์ทแยง $n$ พจน์ พจน์ละขนาด $\Delta t^2$ รวมกันแล้วยังมี $\Delta t$ ค้างหนึ่งตัว จึงหดเป็นศูนย์

ข้อสรุปคือ $\sum g_{i-1}(\Delta W_i)^2$ กับ $\sum g_{i-1}\Delta t$ ต่างกันน้อยลงเรื่อย ๆ จนเป็นศูนย์ นี่คือความหมายเต็มของ $(dW)^2=dt$: ในผลรวมที่ตัวคูณรู้ค่าก่อนก้าว ใช้เวลาแทนกำลังสองของการขยับได้

ลองกับ $g_{i-1}=W_{i-1}$ ซึ่งมี $\mathbb E[W_{i-1}^2]=(i-1)\Delta t$ variance คือ $\sum_i(i-1)\Delta t\cdot2\Delta t^2=T^3(n-1)/n^2$ ที่ 252 ท่อน SD คือ $\sqrt{251/252^2}=0.0629$ ที่ 98,280 ท่อน SD เหลือ $\sqrt{98{,}279/98{,}280^2}\approx0.0032$

ขั้นที่ 8 — ตารางคูณของ Itô: พจน์ไหนรอด

Taylor มีผลคูณเล็ก ๆ มากกว่าแค่ $(\Delta W)^2$ การขยับเล็ก ๆ มีสองชนิด คือเวลา $\Delta t$ กับการขยับสุ่ม $\Delta W$ ผลคูณของสองตัวนี้มีสามแบบ คือ $(\Delta t)^2$, $\Delta W\,\Delta t$ และ $(\Delta W)^2$ ส่วนเศษที่ตัดทิ้งท้าย Taylor มีขนาดราว $|\Delta W|^3$ ต้องรู้ว่าตัวไหนรอดเมื่อบวกทั้งปี ตัวไหนหาย วิธีวัดเหมือนขั้นที่ 3: บวกทุกท่อนในหนึ่งปี แล้วดูว่าเหลือเท่าไร

ต้องใช้ค่าเฉลี่ยของ $|Z|$ และ $|Z|^3$ ทั้งสองได้จากการอินทิเกรต density ของ Normal ครึ่งขวาแล้วคูณสอง: $\mathbb E|Z|=\sqrt{2/\pi}\approx0.798$ และ $\mathbb E|Z|^3=2\sqrt{2/\pi}\approx1.596$

\[ \begin{aligned} \textstyle\sum_i(\Delta t)^2&=n\,\Delta t^2=T^2/n,\\ \mathbb E\textstyle\sum_i|\Delta W_i|\,\Delta t&=n\,\Delta t^{3/2}\,\mathbb E|Z|\\ &=\sqrt{2/\pi}\;T^{3/2}/\sqrt n,\\ \mathbb E\textstyle\sum_i|\Delta W_i|^3&=n\,\Delta t^{3/2}\,\mathbb E|Z|^3\\ &=2\sqrt{2/\pi}\;T^{3/2}/\sqrt n,\\ n=252&:\ 0.0040,\ 0.0503,\ 0.1005,\\ n=98{,}280&:\ 0.00001,\ 0.0025,\ 0.0051. \end{aligned} \]

ทั้งสามตัวหายเมื่อ $n$ โต เพราะขนาดต่อท่อนมีเวลามากกว่าหนึ่งกำลัง ($\Delta t^2$ หรือ $\Delta t^{3/2}$) บวก $n$ ท่อนแล้วยังเหลือ $n$ หรือ $\sqrt n$ ค้างอยู่ในตัวหาร มีแค่ $(\Delta W)^2$ ที่ขนาดต่อท่อนเป็น $\Delta t$ พอดี จึงรอดและรวมได้ $T$

กฎทั่วไปคือ $|\Delta W|^p$ มีขนาดต่อท่อน $\Delta t^{p/2}$ บวก $n$ ท่อนได้ $n\,(T/n)^{p/2}$ ซึ่งแปรตาม $n^{1-p/2}$ ถ้า $p\lt2$ ผลรวมโตไม่สิ้นสุด ถ้า $p\gt2$ ผลรวมหาย $p=2$ พอดีคือเส้นแบ่ง Taylor จึงต้องเขียนถึงพจน์กำลังสอง แต่ไม่ต้องไปถึงพจน์กำลังสาม

เขียนผลเป็นตัวย่อได้ตารางสามข้อ $(dt)^2=0$, $dW\,dt=0$ และ $(dW)^2=dt$ ตัวย่อนี้หมายถึง “เมื่อบวกทั้งช่วง” เสมอ ไม่ใช่สมการของท่อนเดียว

ขั้นที่ 9 — chain rule ของ Itô สำหรับ f(W)

ตอนนี้มีของครบที่จะซ่อม chain rule ให้ $f$ เป็นฟังก์ชันใด ๆ ที่หาอนุพันธ์ได้ถึงอันดับสาม และ $|f'''|$ ไม่เกินค่าคงที่ $M$ ทุกจุด ในแต่ละท่อนเขียน Taylor ถึงพจน์กำลังสอง ส่วนที่เหลือเรียกว่า $r_i$ ซึ่ง Taylor รับประกันว่าไม่เกิน $\tfrac M6|\Delta W_i|^3$ แล้วบวกทุกท่อน ฝั่งซ้ายหักกันเป็นทอด ๆ เหลือปลายลบต้น เหมือนขั้นที่ 1

\[ \begin{aligned} f(W_i)-f(W_{i-1})&=f'(W_{i-1})\,\Delta W_i\\ &\quad+\tfrac12f''(W_{i-1})(\Delta W_i)^2+r_i,\\ |r_i|&\le\tfrac M6|\Delta W_i|^3,\\ f(W_T)-f(W_0)&=\textstyle\sum_i f'(W_{i-1})\,\Delta W_i\\ &\quad+\tfrac12\textstyle\sum_i f''(W_{i-1})(\Delta W_i)^2\\ &\quad+\textstyle\sum_i r_i,\\ \tfrac12\textstyle\sum_i f''(W_{i-1})(\Delta W_i)^2&\to\tfrac12\int_0^Tf''(W_t)\,dt,\\ \textstyle\sum_i|r_i|&\to0,\\ df(W_t)&=f'(W_t)\,dW_t+\tfrac12f''(W_t)\,dt. \end{aligned} \]

ผลรวมก้อนที่สองมีตัวคูณ $\tfrac12f''(W_{i-1})$ ซึ่งรู้ค่าก่อนก้าว ขั้นที่ 7 (ใช้ $g_{i-1}=\tfrac12f''(W_{i-1})$) จึงยอมให้แทน $(\Delta W_i)^2$ ด้วย $\Delta t$ ผลรวมนี้จึงกลายเป็นพื้นที่ใต้กราฟของ $\tfrac12f''(W_t)$ ตามเวลา ส่วนเศษ $r_i$ รวมกันไม่เกิน $\tfrac M6\sum|\Delta W_i|^3$ ซึ่งขั้นที่ 8 บอกว่าหายไป บรรทัดสุดท้ายเป็นแค่ตัวย่อของสามบรรทัดก่อนหน้า

เทียบกับ chain rule ปกติ $df=f'\,dW$ ส่วนที่เพิ่มคือ $\tfrac12f''\,dt$ เรียกว่า Itô correction ถ้า $f$ โค้งหงาย ($f''\gt0$) มันดันค่าเฉลี่ยของ $f$ ขึ้น ลองใส่ $f(w)=w^2$ ซึ่งมี $f'=2w$ และ $f''=2$ จะได้ $d(W^2)=2W\,dW+dt$ นี่คือผลของขั้นที่ 5 ในรูปย่อ: ผลรวมแรกที่เฉลี่ยศูนย์ บวกเวลา

ขั้นที่ 10 — ตรวจด้วยการสุ่ม: 20,000 เส้นทาง ท่อนละหนึ่งวันทำการ

โจทย์ให้อะไรมาบ้าง: ทุกสูตรพิสูจน์ด้วยมือแล้ว ทีนี้ตรวจกับการสุ่มบนคอมพิวเตอร์ โค้ดท้ายหน้าสร้างเส้นทางดังนี้

  • 20,000 เส้นทาง แต่ละเส้นยาวหนึ่งปี
  • ท่อนละหนึ่งวันทำการ คือ 252 ท่อน
  • seed 131 (ตัวเลขตั้งต้นของเครื่องสุ่ม ทุกคนที่รันจึงได้เลขชุดเดิม)

โค้ดวัดค่าเฉลี่ยของ $W_1^2$ และของสองผลรวมของมัน แล้วลองฟังก์ชัน $f(w)=e^w$ ซึ่ง Itô กับ chain rule ปกติทำนายต่างกัน ฟังก์ชันนี้มี $f'=f''=e^w$ ใส่ใน chain rule ของ Itô แล้วเอาค่าเฉลี่ยทั้งสองข้าง พจน์ $e^{W}dW$ เฉลี่ยเป็นศูนย์ เพราะตัวคูณรู้ค่าก่อนก้าว (แบบขั้นที่ 5) เหลือสมการของค่าเฉลี่ย $m(t)$ ซึ่งแก้ได้ด้วย calculus ธรรมดา

\[ \begin{aligned} de^{W_t}&=e^{W_t}dW_t+\tfrac12e^{W_t}dt,\\ m(t)&:=\mathbb E[e^{W_t}],\qquad m(0)=1,\\ m'(t)&=\tfrac12m(t),\\ m(1)&=e^{1/2}\approx1.6487. \end{aligned} \]

สมการ $m'=\tfrac12m$ ที่เริ่มจาก $m(0)=1$ มีคำตอบ $m(t)=e^{t/2}$ เพราะอนุพันธ์ของ $e^{t/2}$ คือครึ่งหนึ่งของตัวมันเอง ตารางด้านล่างเทียบทฤษฎีกับค่าที่สุ่มได้ คอลัมน์สุดท้ายวัดระยะห่างเป็นจำนวน SE (standard error) คือความคลาดที่คาดได้ของค่าเฉลี่ยจากการสุ่ม SE เท่ากับ SD ของค่าในหนึ่งเส้นทาง หารด้วย $\sqrt{20{,}000}\approx141.4$ ระยะห่างไม่เกินราว 2 SE ถือว่าปกติ

ขั้นที่ 11 — ผลบนโต๊ะ: ความผันผวนวัดได้แม่น drift วัดแทบไม่ได้

โต๊ะอยากรู้สองค่าของ SPY จากข้อมูลจริง คือความผันผวน $\sigma$ และ drift $\mu$ ข้อมูลที่มีคือผลตอบแทนรายวันหนึ่งปี 252 ค่า ผลรวมกำลังสองที่ไม่หายใช้เป็นเครื่องวัดความผันผวนได้ทันที ส่วน drift วัดยากกว่ามาก ขั้นนี้หาว่าแต่ละค่าวัดได้แม่นแค่ไหน

ให้ผลตอบแทนวันที่ $i$ คือ $r_i=\sigma\,\Delta W_i$ โดยทิ้ง drift ของวันเดียว เพราะมันเล็กมาก: $\mu\,\Delta t=0.08/252=0.00032$ ขณะที่การแกว่งของวันเดียวคือ $\sigma\sqrt{\Delta t}=0.18/\sqrt{252}=0.0113$ ใหญ่กว่าราว 36 เท่า ผลรวม $r_i^2$ ของหนึ่งปีคือ $\sigma^2Q_{252}$ ส่วน drift ต้องประมาณจากผลรวมของผลตอบแทนเอง ซึ่งเท่ากับผลตอบแทนทั้งปี $R_T$ ไม่ว่าจะซอยกี่ท่อน

\[ \begin{aligned} \widehat{\sigma^2}&=\textstyle\sum_{i=1}^{252}r_i^2=\sigma^2Q_{252},\\ \operatorname{SD}(\widehat{\sigma^2})&=\sigma^2\sqrt{2/252}\approx0.002886,\\ \operatorname{SD}(\hat\sigma)&\approx\frac{0.002886}{2(0.18)}\approx0.0080,\\ \hat\mu&=R_T/T=\mu+\sigma W_T/T,\\ \operatorname{SD}(\hat\mu)&=\sigma/\sqrt T,\\ 2\sigma/\sqrt T&=0.08,\\ T&=(0.36/0.08)^2=20.25. \end{aligned} \]

ผลแรก: ข้อมูลรายวันหนึ่งปีวัดความผันผวน 18% ได้แม่นราว ±0.80 จุด เพราะ $\operatorname{SD}(\hat\sigma)\approx0.0080$ ที่มาคือ $\widehat{\sigma^2}$ เป็น $\sigma^2$ คูณ $Q_{252}$ ความคลาดของมันจึงเป็น $\sigma^2$ คูณ SD ของ $Q_{252}$ จากขั้นที่ 3: $0.0324\times0.0891=0.002886$ การเปลี่ยนจากความคลาดของ $\widehat{\sigma^2}$ เป็นความคลาดของ $\hat\sigma$ ใช้สูตรประมาณของราก $\sqrt{v+\delta}\approx\sqrt v+\delta/(2\sqrt v)$ กับ $\sqrt v=\sigma=0.18$ จึงหารด้วย $2\times0.18$ ถ้าวัดถี่ขึ้น SD นี้ลดลงอีกตาม $1/\sqrt n$

ผลที่สอง: drift ไม่ได้อะไรจากการซอยเลย เพราะ $\hat\mu$ ขึ้นกับปลายทาง $R_T$ ตัวเดียว ส่วนสุ่มของมันคือ $\sigma W_T/T$ ซึ่งมี SD $\sigma\sqrt T/T=\sigma/\sqrt T$ ข้อมูลหนึ่งปีให้ SD $\sigma/\sqrt1=18\%$ ใหญ่กว่าตัว drift 8% เสียอีก ถ้าอยากเห็น drift 8% ห่างศูนย์สอง SD ต้องมี $2\sigma/\sqrt T=0.08$ ซึ่งแก้ได้ $T=20.25$ ปี นี่คือเหตุผลที่ตลาดตั้งราคา option ด้วยความผันผวนได้ แต่ไม่มีใครตกลงกันได้ว่าหุ้นจะให้ผลตอบแทนเฉลี่ยเท่าไร

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

ใช้ chain rule ปกติกับ payoff ที่โค้ง: chain rule ปกติลืมก้อน $\tfrac12f''$ คูณ quadratic variation เงินที่สัญญาในโจทย์เปิดเรื่องจ่าย (payoff) คือ $f(R)=N R^2$ ซึ่งโค้งหงาย ราคาที่ผิดคือ $N\mu^2T^2=\$6{,}400$ ราคาที่ถูกคือ $N(\mu^2T^2+\sigma^2T)=\$38{,}800$ ก้อนที่ขาดต่อ notional คือ $\tfrac12(2)(\sigma^2T)=0.0324$ หรือ \$32,400 ทุก payoff ที่โค้งหงายจะถูกตีราคาต่ำไปแบบนี้ ส่วน payoff ที่โค้งคว่ำจะถูกตีราคาสูงไป

ใช้ตัวคูณจากปลายท่อน: ถ้าคูณการขยับด้วยตำแหน่งปลายท่อน $W_i$ แทนตำแหน่งต้นท่อน $W_{i-1}$ ผลรวมจะลากผลรวมกำลังสองเข้ามาสองเท่า เพราะ $W_i=W_{i-1}+\Delta W_i$:

\[\begin{aligned}\textstyle\sum_i2W_i\Delta W_i&=\textstyle\sum_i2W_{i-1}\Delta W_i+2Q_n,\\\mathbb E\big[\textstyle\sum_i2W_i\Delta W_i\big]&=0+2T=2T.\end{aligned}\]

ค่าเฉลี่ยกลายเป็น $2T$ แทน 0 ในสี่ก้าวด้วยมือได้ $-0.57365+2(0.619875)=0.6661$ แทน −0.574 ใน backtest (การทดสอบกลยุทธ์ย้อนหลังด้วยข้อมูลจริง) ความผิดนี้คือการใช้ราคาที่ยังไม่เกิด ณ ตอนตัดสินใจ หน้า Itô integral วัดให้ดูว่าพลาดแบบนี้แล้วผิดไปกี่ดอลลาร์

อ่าน $(dW)^2=dt$ เป็นสมการของวันเดียว: กฎนี้จริงเมื่อบวกหลายท่อนเท่านั้น ก้าวเดียวมี $(\Delta W)^2=\Delta t\,Z^2$ ซึ่งมีค่าเฉลี่ย $\Delta t$ แต่ SD $\sqrt2\,\Delta t$ ใหญ่กว่าค่าเฉลี่ยของมันเอง ตัวอย่างบนโต๊ะ option: gamma $\Gamma$ คือความโค้งของราคา option เทียบกับราคาหุ้น $S$ กำไรขาดทุน (P&L) ที่ gamma ทำให้ในหนึ่งวันคือ $\tfrac12\Gamma(\Delta S)^2$ ของการขยับที่เกิดจริง ไม่ใช่ค่าเฉลี่ยของมัน $\tfrac12\Gamma S^2\sigma^2\Delta t$ สองตัวนี้มีค่าเฉลี่ยเท่ากัน แต่ในวันที่ราคาขยับ 3 SD คือ $\Delta S=3\sigma S\sqrt{\Delta t}$ จะได้

\[\tfrac12\Gamma(\Delta S)^2=9\times\tfrac12\Gamma S^2\sigma^2\Delta t.\]

ตัวแรกใหญ่กว่าตัวที่สอง 9 เท่า ถ้าอธิบาย P&L รายวันด้วยตัวที่สอง จะผิดทุกวันที่ตลาดขยับแรง

ใช้ทำอะไรบนโต๊ะจริง

realized variance ที่โต๊ะ option ดูทุกวัน คือ $\sigma^2Q_n$ ในขั้นที่ 11: เอาผลตอบแทนของแต่ละช่วงมายกกำลังสองแล้วบวกกัน สัญญาในโจทย์เปิดเรื่องเป็นญาติของ variance swap ซึ่งเป็นสัญญาที่จ่ายตาม realized variance โดยตรง ส่วน Itô correction $\tfrac12f''\,dt$ จะกลับมาใน สมการ Black–Scholes เป็นพจน์ gamma ที่แลกกับการเสื่อมมูลค่าตามเวลาของ option

ตลาดจริงต่างจากแบบจำลองสามเรื่อง

  • โต๊ะวัดราคาหรือปรับ hedge (การถือหุ้นสวนทางเพื่อหักล้างความเสี่ยงของ option) ได้วันละไม่กี่ครั้ง ที่ 252 ท่อนต่อปี $Q$ คลาดได้ $\sqrt{2/252}=8.9\%$ ของค่า กฎ $(dW)^2=dt$ จึงเป็นค่าประมาณที่ดีขึ้นเมื่อวัดถี่ขึ้น หน้า P&L ของการ delta hedge วัดว่าการปรับวันละครั้งทำให้ผลคลาดไปเท่าไร
  • ราคาจริงกระโดดตอนมีข่าว ผลรวมกำลังสองจึงรวมกำลังสองของการกระโดดเข้าไปด้วย
  • ถ้าวัดถี่ระดับวินาที ราคาที่ซื้อขายจริงเด้งไปมาระหว่าง bid (ราคาที่มีคนรอซื้อ) กับ ask (ราคาที่มีคนรอขาย) ทำให้ realized variance พองเกินจริง หน้า realized volatility ดูเรื่องนี้ละเอียด

งานประจำวันอีกอย่างคือตรวจโค้ดจำลอง realized variance ของเส้นทางที่จำลองได้ต้องอยู่ใกล้ $\sigma^2T$ และห่างได้ราว $\sigma^2T\sqrt{2/n}$ เช่นหนึ่งปีรายวันที่ $\sigma=0.18$ ห่างได้ราว $0.0324\times0.0891=0.0029$ ถ้าห่างกว่านี้หลายเท่า แปลว่าโค้ดลืมคูณ $\sqrt{\Delta t}$ หรือใช้หน่วยเวลาผิด

1. ลูกค้าอีกรายขอสัญญาแบบเดียวกับโจทย์เปิดเรื่อง (notional $N=\$1$ ล้าน จ่าย $N R_T^2$ ด้วย $\mu=8\%$ และ $\sigma=18\%$ ต่อปี) แต่อายุแค่หกเดือน คือ $T=0.5$ ปี สัญญาจ่ายเฉลี่ยเท่าไร และ chain rule ปกติจะบอกเท่าไร?

เฉลย

ใช้ $\mathbb E[R_T^2]=\mu^2T^2+\sigma^2T$ จากขั้นที่ 6 กับ $T=0.5$:

\[\begin{aligned}\mu^2T^2&=0.0064\times0.25=0.0016,\\\sigma^2T&=0.0324\times0.5=0.0162,\\\mathbb E[R_{0.5}^2]&=0.0016+0.0162=0.0178.\end{aligned}\]

สัญญาจ่ายเฉลี่ย $0.0178\times\$1{,}000{,}000=\$17{,}800$ chain rule ปกติเห็นแค่ $\mu^2T^2=0.0016$ หรือ \$1,600 ก้อนที่ขาด $17{,}800-1{,}600=\$16{,}200$ คือ $\sigma^2T$ ก้อนนี้โตตามเวลาตรง ๆ แต่ก้อนของ drift โตตามกำลังสองของเวลา ช่วงยิ่งสั้น ก้อนของความผันผวนยิ่งใหญ่กว่า

2. ค่าเฉลี่ยของ $W_1^4$ ปกติต้องหาด้วยการอินทิเกรต density ของ Normal ทีละส่วน ลองใช้ chain rule ของ Itô หา $\mathbb E[W_1^4]$ แทน โดยไม่อินทิเกรต density

เฉลย

ใช้ $f(w)=w^4$ ซึ่งมี $f'=4w^3$ และ $f''=12w^2$ ใส่ใน chain rule ของ Itô ได้ $d(W^4)=4W^3dW+\tfrac12(12W^2)\,dt=4W^3dW+6W^2dt$ เอาค่าเฉลี่ยทั้งสองข้าง พจน์ $dW$ เฉลี่ยเป็นศูนย์ เพราะตัวคูณรู้ค่าก่อนก้าว เหลือ

\[\begin{aligned}\mathbb E[W_T^4]&=6\int_0^T\mathbb E[W_t^2]\,dt\\&=6\int_0^Tt\,dt=3T^2.\end{aligned}\]

ที่ $T=1$ ได้ 3 ตรงกับ $\mathbb E[Z^4]=3$ ที่ได้จากการอินทิเกรต density

3. โต๊ะอยากวัดความผันผวนของ SPY (ราว 18% ต่อปี) ให้แม่นถึง SD ±0.5 จุด ต้องใช้ผลตอบแทนรายวันกี่วัน? และถ้าใช้ผลตอบแทนทุก 5 นาที (แท่ง 5 นาที) ตลอดหนึ่งปี จะได้ SD เท่าไร?

เฉลย

จากขั้นที่ 11 SD ของ $\hat\sigma$ ที่ได้จากผลตอบแทน $n$ ค่าคือ $\sigma\sqrt{2/n}/2=\sigma/\sqrt{2n}$ ตั้งให้เท่ากับ 0.005 แล้วแก้หา $n$:

\[\begin{aligned}0.18/\sqrt{2n}&=0.005,\\\sqrt{2n}&=0.18/0.005=36,\\2n&=36^2=1{,}296,\\n&=648.\end{aligned}\]

ต้องใช้ 648 วันทำการ คือ $648/252\approx2.57$ ปี วันทำการหนึ่งวันมี 390 นาที จึงมีแท่ง 5 นาที $390/5=78$ แท่งต่อวัน หนึ่งปีได้ $78\times252=19{,}656$ แท่ง

\[\begin{aligned}\operatorname{SD}(\hat\sigma)&=0.18/\sqrt{2\times19{,}656}\\&=0.18/\sqrt{39{,}312}\approx0.00091.\end{aligned}\]

คือแม่นถึง ±0.09 จุด แต่ drift ยังมี SD 18% เท่าเดิม เพราะ drift ไม่ได้อะไรจากการซอย

function check(n, T) {
  if (!Number.isInteger(n) || n < 1) throw new RangeError('Need a whole number of steps n >= 1');
  if (!(T > 0) || !Number.isFinite(T)) throw new RangeError('Need a finite horizon T > 0');
}
// Smooth path x(t) = t on [0, T]: x_T^2 = sum 2 x dx + sum dx^2, and the second sum is T^2/n.
function smoothSums(n, T = 1) {
  check(n, T);
  return {first: T * T * (n - 1) / n, squares: T * T / n};
}
// The same exact identity on a Brownian path built from given standard Normals.
function handPath(z, dt) {
  const dW = z.map(x => Math.sqrt(dt) * x), W = [0];
  for (const d of dW) W.push(W[W.length - 1] + d);
  const ito = dW.reduce((s, d, i) => s + 2 * W[i] * d, 0);
  const Q = dW.reduce((s, d) => s + d * d, 0);
  return {W, ito, Q, total: ito + Q, WT2: W[W.length - 1] ** 2};
}
// Binomial tree with u = exp(sigma sqrt(dt)): every log step is +-sigma sqrt(dt), so the squares add to sigma^2 T on every path.
function treeSquares(sigma, T, n) {
  check(n, T);
  const step = sigma * Math.sqrt(T / n);
  return {logStep: step, u: Math.exp(step), squareSum: n * step * step};
}
// Sum of squared increments Q_n: mean T and SD T sqrt(2/n), because E[Z^2] = 1 and Var(Z^2) = 2.
const qvSD = (n, T = 1) => T * Math.sqrt(2 / n);
// SD of sum W_(i-1) [(dW_i)^2 - dt]: the weight is known before each step, so cross terms vanish.
const weightedSD = (n, T = 1) => Math.sqrt(T ** 3 * (n - 1) / (n * n));
// Expected size of the three products that the multiplication table sends to zero.
function tableSizes(n, T = 1) {
  check(n, T);
  const absZ = Math.sqrt(2 / Math.PI);
  return {dtdt: T * T / n, dWdt: absZ * T ** 1.5 / Math.sqrt(n), cube: 2 * absZ * T ** 1.5 / Math.sqrt(n)};
}
// Contract paying notional * R_T^2 with R_t = mu t + sigma W_t (Brownian motion with drift).
function squaredReturnPayout(mu, sigma, T, notional) {
  const chainRule = notional * mu * mu * T * T;
  return {chainRule, ito: chainRule + notional * sigma * sigma * T, missing: notional * sigma * sigma * T};
}
// mulberry32 + Box-Muller: seeded standard Normals, so every reader gets the same numbers.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Simulate paths on a grid and average W_T^2, its two pieces, e^(W_T) and R_T^2.
function simulate(paths, steps, T, mu, sigma, seed) {
  check(steps, T);
  const z = normals(seed), sq = Math.sqrt(T / steps);
  let w2 = 0, ito = 0, q = 0, qq = 0, ew = 0, r2 = 0;
  for (let p = 0; p < paths; p++) {
    let w = 0, s = 0, Q = 0;
    for (let k = 0; k < steps; k++) {
      const d = sq * z();
      s += 2 * w * d; Q += d * d; w += d;
    }
    const R = mu * T + sigma * w;
    w2 += w * w; ito += s; q += Q; qq += Q * Q; ew += Math.exp(w); r2 += R * R;
  }
  const meanQ = q / paths;
  return {meanW2: w2 / paths, meanIto: ito / paths, meanQ, sdQ: Math.sqrt((qq - paths * meanQ * meanQ) / (paths - 1)),
    meanExpW: ew / paths, meanR2: r2 / paths};
}

const hand = handPath([0.31, -1.20, 0.85, 0.47], 0.25);
const sim = simulate(N, 252, 1, mu, sigma, 131);
const se = sd => sd / Math.sqrt(N); // standard error from the exact one-path SD

สิ่งที่ควรตอบได้หลังอ่าน

  • สมการ $x_T^2-x_0^2=\sum2x_{i-1}\Delta x_i+\sum(\Delta x_i)^2$ จริงทุกเส้นทาง chain rule ปกตินับแค่ผลรวมแรก
  • บนเส้นเรียบ ผลรวมกำลังสองหายตาม $1/n$ บนเส้นทาง Brownian มันเฉลี่ย $T$ และคลาดแค่ $T\sqrt{2/n}$ ส่วนต้นไม้ binomial ที่ตั้ง $u=e^{\sigma\sqrt{\Delta t}}$ ได้ $\sigma^2T$ พอดีทุกเส้นทาง
  • $(dW)^2=dt$ แปลว่า เมื่อตัวคูณรู้ค่าก่อนก้าว $\sum g_{i-1}(\Delta W_i)^2$ กับ $\sum g_{i-1}\Delta t$ ต่างกันน้อยลงจนเป็นศูนย์ ส่วน $dW\,dt$, $(dt)^2$ และกำลังสามหายไป
  • chain rule ของ Itô คือ $df=f'\,dW+\tfrac12f''\,dt$ สัญญา \$1 ล้าน คูณ $R^2$ จึงจ่ายเฉลี่ย \$38,800 ไม่ใช่ \$6,400 และ $\mathbb E[e^{W_1}]=1.6487$ ไม่ใช่ 1
  • ข้อมูลรายวันหนึ่งปีวัดความผันผวน 18% ได้แม่น ±0.80 จุด แต่ต้องใช้ข้อมูล 20.25 ปีจึงเห็น drift 8% ห่างศูนย์สอง SD

หน้าถัดไป Itô's lemma ใช้ Taylor แบบเดียวกันกับ $f(t,X_t)$ เมื่อ $X$ มีทั้ง drift และความผันผวน จนได้กฎเต็มรูป แล้วใช้กฎนั้นหาว่าราคา SPY ปีหน้ามี median อยู่ที่ไหน และทำไมมันไม่เท่ากับค่าเฉลี่ย
