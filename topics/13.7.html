13.7 The Feynman–Kac Formula

ราคาที่ได้จากการเฉลี่ยเส้นทางข้างหน้า กับราคาที่ได้จากการแก้สมการเชิงอนุพันธ์ย่อยย้อนจากวันครบกำหนด คือฟังก์ชันเดียวกัน จึงเลือกทางที่เหมาะกับโจทย์ แล้วใช้อีกทางตรวจคำตอบได้

ธนาคารแห่งหนึ่งจะขาย note ให้ลูกค้า note คือสัญญาที่ธนาคารสัญญาว่าจะจ่ายเงินให้ครั้งเดียวในวันครบกำหนด จำนวนเงินคิดจากราคาหุ้นในวันนั้นตามสูตรที่ตกลงกันไว้ ธนาคารต้องตั้งราคาขายวันนี้ แต่สองทีมในธนาคารคิดราคาได้ไม่เท่ากัน

ของที่รู้ (ตัวเลขสมมติทั้งหมด):

  • ราคาหุ้นวันนี้ $S_0=\$200$
  • ความผันผวนต่อปี $\sigma=30\%$ คือขนาดการแกว่งของผลตอบแทนหุ้นในหนึ่งปี วัดเป็น SD (standard deviation)
  • ดอกเบี้ยเงินฝาก $r=4\%$ ต่อปี คิดทบต่อเนื่อง เงิน \$1 ฝากไว้หนึ่งปีจึงโตเป็น $e^{0.04}=\$1.0408$
  • note ครบกำหนดในอีก $T=1$ ปี และวันนั้นจ่าย $g(S_1)=S_1^2/200$ ดอลลาร์ โดย $S_1$ คือราคาหุ้นในอีกหนึ่งปี และ $g$ คือสูตรเงินที่จ่าย เช่น ถ้าหุ้นไปอยู่ที่ \$250 note จ่าย $250^2/200=\$312.50$

กฎตั้งราคาที่ทั้งสองทีมใช้มาจากหน้า risk-neutral measure: นึกถึงโลกสมมติชื่อ $Q$ ที่หุ้นโตเฉลี่ยเท่าดอกเบี้ยเงินฝากพอดี หาค่าเฉลี่ยของเงินที่ note จ่ายในโลกนั้น แล้ว “คิดลด” คือคูณด้วย $e^{-rT}$ เพื่อแปลงเงินปีหน้าเป็นเงินวันนี้

นักวิเคราะห์คนหนึ่งใช้ทางลัด เขาหาราคาหุ้นเฉลี่ยปีหน้าในโลก $Q$ ก่อน ใส่ตัวเลขนั้นลงในสูตรเงินที่จ่าย แล้วคิดลด:

\[\begin{aligned}\mathbb E^Q[S_1]&=200\,e^{0.04}=\$208.16,\\g(208.16)&=\frac{208.16^2}{200}=\$216.66,\\\text{price}&=e^{-0.04}(216.66)=\$208.16.\end{aligned}\]

อีกทีมเขียนโปรแกรมที่เริ่มจากวันครบกำหนด วันนั้นรู้เงินที่จ่ายแน่นอนทุกราคาหุ้น แล้วโปรแกรมถอยหลังทีละก้าวเล็ก ๆ บนตารางของเวลาและราคา จนถึงวันนี้ ทีมนี้ได้ \$227.77 ใครถูก?

ลองตอบก่อนเปิดเฉลย

ทีมที่ได้ \$227.77 ถูก ทางที่สามคือสุ่มราคาหุ้นปีหน้าหลายแสนครั้ง คิดเงินที่จ่ายของแต่ละครั้ง เฉลี่ย แล้วคิดลด ทางนี้ก็ได้ใกล้ \$227.77 ภายในความคลาดของการสุ่ม

นักวิเคราะห์ผิดตรงลำดับ เขาเฉลี่ยราคาก่อนแล้วค่อยยกกำลังสอง แต่ราคาที่ถูกต้องยกกำลังสองก่อนแล้วค่อยเฉลี่ย สำหรับเงินที่จ่ายที่โค้งหงายแบบ $S^2$ ลำดับแรกให้ค่าต่ำกว่าเสมอ ทางลัดจึงต่ำไป $227.7657-208.1622=\$19.60$ คิดเป็น $19.60/227.77=8.61\%$ ของราคาที่ถูก หน้านี้จะคำนวณ \$227.77 ให้ดูทีละขั้น และวาดรูปว่าทำไมทางลัดต่ำไปเสมอ

ภาพรวมก่อนลงสูตร

สัญญาที่จ่ายเงินตามราคาหุ้นในอนาคต (option, note) ตั้งราคาได้สองทาง ทั้งสองทางใช้โลกสมมติ $Q$ ที่หุ้นโตเฉลี่ยเท่าดอกเบี้ยเงินฝาก

  • ทางเดินหน้า: สุ่มเส้นทางราคาหุ้นในโลก $Q$ จากวันนี้ไปถึงวันครบกำหนดหลายแสนเส้น คิดเงินที่จ่ายของแต่ละเส้น เฉลี่ย แล้วคิดลด เขียนเป็นสูตรได้ $V_0=e^{-rT}\,\mathbb E^Q[g(S_T)]$ โดย $V_0$ คือราคาวันนี้ และ $\mathbb E^Q$ คือค่าเฉลี่ยในโลก $Q$ การสุ่มแบบนี้เรียกว่า Monte Carlo
  • ทางเดินย้อน: เริ่มที่วันครบกำหนด วันนั้นมูลค่าของสัญญาเท่ากับเงินที่จ่าย จึงรู้แน่นอนทุกราคาหุ้น แล้วถอยเวลากลับทีละก้าวบนตาราง จนถึงวันนี้ ทุกก้าวใช้สมการเชิงอนุพันธ์ย่อย (PDE) ตัวหนึ่ง วิธีนี้คือฉบับละเอียดของการตั้งราคาบนต้นไม้ binomial

Feynman–Kac formula บอกว่าสองทางนี้คำนวณฟังก์ชันเดียวกัน คือ $f(t,S)$ มูลค่าของสัญญาเมื่อเวลาเป็น $t$ และราคาหุ้นเป็น $S$ ประโยชน์คือเลือกทางที่ง่ายกับโจทย์ แล้วใช้อีกทางตรวจคำตอบ

ทำไมสองทางจึงเท่ากัน เหตุผลมีสองชิ้นที่เคยเห็นแล้ว ชิ้นแรกคือ tower property: ค่าเฉลี่ยของค่าเฉลี่ยแบบมีเงื่อนไขเท่ากับค่าเฉลี่ยเดิม ผลคือมูลค่าที่คิดลดแล้วไม่มี drift คือไม่มีแนวโน้มขึ้นหรือลงที่คาดได้ ชิ้นที่สองคือ Itô's lemma กฎลูกโซ่ของเส้นทางสุ่ม ซึ่งแปลงคำว่า “ไม่มี drift” ให้เป็น PDE รูปด้านล่างวางสองทางนี้ไว้บนระนาบเดียวกัน

ลำดับของหน้านี้:

  • ลองทั้งสองทางด้วยมือบนต้นไม้สามงวด
  • สร้างสะพานจากค่าเฉลี่ยไปสู่ PDE
  • คิดราคา note ของโจทย์เปิดเรื่องสี่วิธี: สูตรปิด ตารางที่เดินย้อน การสุ่มที่เดินหน้า และการอินทิเกรตเงินที่จ่ายกับ density ของราคาหุ้นปีหน้าตรง ๆ
  • ขยายไปกรณีที่ดอกเบี้ยเองก็ขึ้นลงแบบสุ่ม แล้วคิดราคาพันธบัตรของแบบจำลอง Vasicek ทั้งสองทาง
ศัพท์ที่ใช้ในหัวข้อนี้
Note
สัญญาที่ผู้ขายจ่ายเงินให้ผู้ซื้อในวันครบกำหนด จำนวนเงินคิดจากราคาหุ้นในวันนั้นตามสูตรที่ตกลงกันไว้ ในหน้านี้สูตรคือ $S_1^2/200$
Risk-neutral measure $Q$
โลกสมมติที่หุ้นทุกตัวโตเฉลี่ยเท่าดอกเบี้ยเงินฝาก ราคาที่ไม่มีใครได้เงินฟรีคือค่าเฉลี่ยของเงินที่จ่ายในโลกนี้ คิดลดกลับมาเป็นเงินวันนี้ (Girsanov and the risk-neutral measure)
คิดลด (discount)
การแปลงเงินในอนาคตเป็นเงินวันนี้ เงิน \$1 ในอีก $T$ ปีมีค่าวันนี้ $e^{-rT}$ ดอลลาร์ เพราะถ้าฝาก $e^{-rT}$ ไว้ $T$ ปี จะโตเป็น \$1 พอดี
Feynman–Kac formula
ผลที่ว่าค่าเฉลี่ยของเงินที่จ่ายตอนจบ เมื่อคิดลดแล้ว เป็นคำตอบของ PDE ตัวหนึ่งที่มีเงื่อนไขในวันครบกำหนด จึงสลับไปมาระหว่างการสุ่มกับการแก้สมการบนตารางได้
Partial differential equation (PDE)
สมการเชิงอนุพันธ์ย่อย คือสมการที่ผูกอนุพันธ์ของมูลค่าตามเวลาและตามราคาเข้าด้วยกัน ใช้เดินมูลค่าย้อนจากวันครบกำหนดมาหาวันนี้
Terminal condition
เงื่อนไขในวันครบกำหนด: มูลค่าวันนั้นเท่ากับเงินที่สัญญาจ่าย $f(T,S)=g(S)$ เงื่อนไขนี้ทำให้ PDE มีคำตอบเหลือตัวเดียว
Martingale
กระบวนการสุ่มที่ไม่มีแนวโน้ม: ถ้ารู้ค่าวันนี้ ค่าเฉลี่ยของค่าในอนาคตก็เท่ากับค่าวันนี้ (filtrations and martingales)
Backward induction
การคิดมูลค่าจากปลายต้นไม้ย้อนมาราก โดยแต่ละจุดคือค่าเฉลี่ยของสองจุดถัดไปที่คิดลดแล้ว เป็นต้นแบบของการแก้ PDE บนตาราง
Monte Carlo
การสุ่มเส้นทางจำนวนมาก แล้วเฉลี่ยเงินที่จ่ายที่คิดลดแล้ว เหมาะเมื่อมีหลายตัวแปร หรือเมื่อเงินที่จ่ายขึ้นกับทั้งเส้นทาง ความคลาดหดตาม $1/\sqrt n$ เมื่อ $n$ คือจำนวนเส้นทาง
Standard error (SE)
SD ของค่าเฉลี่ยที่ได้จากการสุ่ม บอกว่าค่าเฉลี่ยคลาดจากค่าจริงได้ราวเท่าไร เท่ากับ SD ของผลหนึ่งครั้งหารด้วย $\sqrt n$
Finite difference
การแทนอนุพันธ์ด้วยผลต่างของค่าบนตาราง เช่น $f_{SS}\approx(f_{i+1}-2f_i+f_{i-1})/\Delta S^2$ ใช้แก้ PDE ย้อนเวลาทีละก้าว
Delta และ gamma
delta คือ $f_S$ บอกว่ามูลค่าสัญญาเปลี่ยนกี่ดอลลาร์เมื่อหุ้นขึ้น \$1 จึงบอกว่าผู้ขายต้องถือหุ้นกี่หุ้นเพื่อหักล้างความเสี่ยง (hedge) gamma คือ $f_{SS}$ บอกว่า delta เปลี่ยนเร็วแค่ไหน (the Greeks)
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$S_t,\ r,\ \sigma$ราคาหุ้นใต้ $Q$, ดอกเบี้ย, ความผันผวนดอลลาร์ต่อหุ้น, ต่อปี, ต่อ $\sqrt{\text{yr}}$
$T,\ \tau$วันครบกำหนด และเวลาที่เหลือ $T-t$ปี
$g(S),\ K$เงินที่จ่าย $S^2/K$ และค่าคงที่ที่ทำให้หน่วยเป็นดอลลาร์ดอลลาร์, ดอลลาร์ต่อหุ้น
$f(t,S)$มูลค่าสัญญาที่เวลา $t$ เมื่อราคาเป็น $S$ดอลลาร์

$r_t,\ \kappa,\ \theta,\ \sigma_V$short rate (ดอกเบี้ยของเงินกู้ระยะสั้นมาก ณ เวลา $t$), ความเร็วที่ดอกเบี้ยถูกดึงกลับ, ระดับที่ดอกเบี้ยถูกดึงเข้าหา และความผันผวนของดอกเบี้ยในแบบจำลอง Vasicekต่อปี

ขั้นที่ 1 — ต้นไม้สามงวดด้วยมือ: เดินย้อนกับเดินหน้าได้เท่ากัน

ก่อนเจอสมการ ลองดูสองทางบนของเล่นที่คิดด้วยมือได้ก่อน ของเล่นนี้คือต้นไม้ binomial: หุ้นขยับเป็นงวด แต่ละงวดมีแค่สองทาง คือขึ้นหรือลง

โจทย์ให้อะไรมาบ้าง:

  • ราคาหุ้นวันนี้ $S_0=\$100$
  • แต่ละงวด หุ้นขึ้นเป็น $u=1.07$ เท่า หรือลงเป็น $d=1/1.07=0.934579$ เท่า
  • เงินฝากโต $R=1.01$ เท่าต่องวด
  • สัญญาคือ call: สิทธิ์ซื้อหุ้นหลังสามงวดในราคาที่ตกลงไว้ล่วงหน้า ราคานี้เรียกว่า strike และในที่นี้คือ \$100 ถ้าวันนั้นหุ้นอยู่ที่ $S_3$ ผู้ถือ call ซื้อหุ้นที่ \$100 แล้วขายที่ $S_3$ ได้ จึงได้ $S_3-100$ เมื่อเป็นบวก ถ้าไม่เป็นบวกก็ไม่ใช้สิทธิ์ ได้ 0

ในโลก $Q$ หุ้นต้องโตเฉลี่ยเท่าเงินฝาก โอกาสขาขึ้น $q$ จึงต้องทำให้ $qu+(1-q)d=R$ แก้สมการได้

\[ \begin{aligned} q&=\frac{R-d}{u-d}=\frac{1.01-0.934579}{1.07-0.934579}\\ &=\frac{0.075421}{0.135421}=0.5569,\\ 1-q&=0.4431. \end{aligned} \]

ในวันครบกำหนด หุ้นมีสี่ราคาที่เป็นไปได้: ขึ้นสามงวดได้ $100(1.07^3)=\$122.50$ ขึ้นสองลงหนึ่งได้ $100(1.07)=\$107$ ขึ้นหนึ่งลงสองได้ $100/1.07=\$93.46$ และลงสามงวดได้ $100/1.07^3=\$81.63$ call จึงจ่าย $122.50-100=\$22.50$, $107-100=\$7$, 0 และ 0 ตามลำดับ

ทางเดินย้อนเริ่มจากเงินที่จ่ายสี่ค่านี้ แล้วถอยทีละชั้น จุดหนึ่งมีค่าเท่ากับค่าเฉลี่ยของสองจุดถัดไปในโลก $Q$ หารด้วย $R$ เขียนเป็น $C=\big(q\,C_{\rm up}+(1-q)\,C_{\rm down}\big)/R$ โดย $C$ คือมูลค่า call ตัวห้อยบอกงวดและตำแหน่งของจุด เช่น $C_{2,\rm top}$ คือจุดบนสุดของงวดที่ 2 และ $C_0$ คือราก ส่วนทางเดินหน้ารวมทุกเส้นทางที่ไปจบตรงที่ call จ่ายเงิน แล้วคิดลดสามงวดรวดเดียว

\[ \begin{aligned} C_{2,\text{top}}&=\tfrac{0.5569(22.50)+0.4431(7)}{1.01}\\ &=15.48,\\ C_{2,\text{mid}}&=\tfrac{0.5569(7)}{1.01}=3.86,\\ C_{1,\text{up}}&=\tfrac{0.5569(15.48)+0.4431(3.86)}{1.01}\\ &=10.23,\\ C_{1,\text{down}}&=\tfrac{0.5569(3.86)}{1.01}=2.13,\\ C_0&=\tfrac{0.5569(10.23)+0.4431(2.13)}{1.01}\\ &=6.57,\\ q^3&=0.5569^3=0.1727,\\ 3q^2(1-q)&=3(0.3102)(0.4431)\\ &=0.4123,\\ \text{forward}&=\tfrac{q^3(22.50)+3q^2(1-q)(7)}{1.01^3}\\ &=\tfrac{0.1727(22.50)+0.4123(7)}{1.0303}\\ &=6.57. \end{aligned} \]

ในทางเดินหน้า $q^3$ คือโอกาสที่หุ้นขึ้นสามงวดติด ส่วน $3q^2(1-q)$ คือโอกาสที่หุ้นขึ้นสองงวดและลงหนึ่งงวด ซึ่งเกิดได้สามลำดับ (ขึ้นขึ้นลง, ขึ้นลงขึ้น, ลงขึ้นขึ้น) และทุกลำดับไปจบที่ \$107 เหมือนกัน

คำตอบ: สองทางได้ \$6.57 เท่ากัน ทางเดินย้อนใช้กฎเดียวซ้ำ ๆ คือ “แต่ละจุดเท่ากับค่าเฉลี่ยของลูกสองตัว หารด้วย $R$” กฎนี้คือต้นแบบของ PDE ทางเดินหน้าคิดน้ำหนักของทั้งเส้นทางในครั้งเดียว ซึ่งคือต้นแบบของ Monte Carlo ทั้งสองทางเท่ากันเพราะการเฉลี่ยซ้อนกันทีละชั้นให้ผลเท่ากับการเฉลี่ยครั้งเดียว นี่คือ tower property

ตรวจเองใน 10 วินาที: ถ้า \$6.57 เป็นราคาที่ถูก ต้องมีพอร์ตหุ้นกับเงินฝากที่ราคา \$6.57 และมีมูลค่าเท่ากับ call ทั้งตอนหุ้นขึ้นและตอนหุ้นลง พอร์ตนี้เรียกว่าพอร์ตเลียนแบบ จำนวนหุ้นคือการเปลี่ยนของมูลค่า call หารด้วยการเปลี่ยนของราคาหุ้นในงวดแรก ที่เหลือเป็นเงินสด (ติดลบแปลว่ายืมเงินมา)

\[ \begin{aligned} \text{shares}&=\frac{10.23-2.13}{107-93.46}=0.5982,\\ \text{cash}&=6.574-0.5982(100)\\ &=-\$53.25,\\ \text{up}&=0.5982(107)-53.25(1.01)\\ &=64.01-53.78=10.23. \end{aligned} \]

ถ้าหุ้นขึ้นเป็น \$107 หุ้น 0.5982 หุ้นมีค่า \$64.01 และหนี้ \$53.25 โตตามเงินฝากเป็น \$53.78 พอร์ตจึงมีค่า \$10.23 เท่ากับมูลค่า call ที่จุดนั้นพอดี

ขั้นที่ 2 — นิยามมูลค่าด้วยค่าเฉลี่ยของเส้นทางข้างหน้า

จากนี้กลับไปที่ note ของโจทย์เปิดเรื่อง: หุ้น \$200 ดอกเบี้ย 4% และความผันผวน 30% ตอนนี้เวลาไหลต่อเนื่อง ไม่ได้ขยับเป็นงวดแบบต้นไม้แล้ว เราอยากรู้มูลค่าของ note ไม่ใช่แค่วันนี้ แต่ทุกเวลา $t$ และทุกราคาหุ้น $S$ เพราะทางเดินย้อนต้องใช้ค่าทุกจุดบนตาราง

ในโลก $Q$ ราคาหุ้นเคลื่อนตามสมการแรกด้านล่าง ก้อน $rS_t\,dt$ บอกว่าหุ้นโตเฉลี่ยเท่าดอกเบี้ย (ผลของการเปลี่ยน measure) ก้อน $\sigma S_t\,dW_t^Q$ คือการแกว่งแบบสุ่ม โดย $W^Q$ คือ Brownian motion ในโลก $Q$ เรานิยาม $f(t,S)$ ด้วยกฎตั้งราคาเดิม แต่เริ่มนับจากเวลา $t$ แทนวันนี้ ค่า $\mathbb E^Q[\,\cdot\mid S_t=S]$ คือค่าเฉลี่ยในโลก $Q$ เมื่อรู้ว่าที่เวลา $t$ หุ้นอยู่ที่ $S$ นี่คือทางเดินหน้าของต้นไม้ในเวลาต่อเนื่อง

\[ \begin{aligned} dS_t&=rS_t\,dt+\sigma S_t\,dW_t^Q,\\ g(S)&=S^2/K,\\ S_0&=K=200,\\ r&=0.04,\quad\sigma=0.30,\quad T=1,\\ f(t,S)&:=e^{-r(T-t)}\\ &\quad\times\mathbb E^Q\big[g(S_T)\mid S_t=S\big]. \end{aligned} \]

$f(t,S)$ ตอบคำถามว่า “ถ้าวันที่ $t$ หุ้นอยู่ที่ $S$ สัญญามีค่าเท่าไร” ได้ตัวเลขหนึ่งตัวต่อหนึ่งจุดบนระนาบเวลาและราคา ตัวคิดลด $e^{-r(T-t)}$ ใช้เวลาที่เหลือ $T-t$ ไม่ใช่ $T$ เพราะเงินจ่ายในอีก $T-t$ ปีนับจากจุดนั้น ค่าคงที่ $K=200$ มีไว้ให้หน่วยถูก: $S^2$ มีหน่วยดอลลาร์กำลังสอง หารด้วย $K$ ที่มีหน่วยดอลลาร์จึงเหลือดอลลาร์

นิยามนี้บอกวิธีคำนวณ (สุ่มแล้วเฉลี่ย) แต่ยังไม่บอกว่า $f$ ต้องแก้สมการอะไร ขั้นถัดไปจะหาสมการนั้น

ขั้นที่ 3 — สะพาน: มูลค่าที่คิดลดไม่มี drift แล้วใช้ Itô

เราอยากได้สมการของ $f$ เคล็ดลับคือมองมูลค่าที่คิดลดกลับมาเป็นเงินวันนี้ เรียกว่า $M_u$ แล้วถามว่ามันมีแนวโน้มขึ้นหรือลงไหม

ในต้นไม้ แต่ละจุดเท่ากับค่าเฉลี่ยของจุดถัดไปหารด้วย $R$ แปลว่ามูลค่าที่คิดลดแล้วไม่มีแนวโน้มเลย ในเวลาต่อเนื่องก็เป็นแบบเดียวกัน $M_u$ เขียนเป็นค่าเฉลี่ยของเงินที่จ่ายที่คิดลดถึงวันนี้ได้ เพราะ $e^{-ru}\cdot e^{-r(T-u)}=e^{-rT}$ โดย $\mathbb E^Q_u$ คือค่าเฉลี่ยในโลก $Q$ เมื่อรู้เส้นทางถึงเวลา $u$ ถ้ายืนอยู่ที่เวลา $s$ ก่อนหน้า ($s\lt u$) แล้วเฉลี่ย $M_u$ อีกชั้น tower property ยุบค่าเฉลี่ยสองชั้นเหลือชั้นเดียว ได้ $M_s$ คืนมา $M$ จึงเป็น martingale ในโลก $Q$ คือไม่มีแนวโน้ม

จากนั้นหาว่า $M$ เปลี่ยนอย่างไรในช่วงเวลาสั้น $du$ ใช้กฎผลคูณกับ $e^{-ru}\times f$ และใช้ Itô's lemma กับ $f(u,S_u)$ Itô's lemma คือกฎลูกโซ่ของเส้นทางสุ่ม ต่างจากกฎลูกโซ่ปกติตรงที่มีพจน์ $\tfrac12\sigma^2S^2f_{SS}$ เพิ่มมา เพราะ $(dS)^2=\sigma^2S^2\,du$ ไม่เล็กจนตัดทิ้งได้

\[ \begin{aligned} &M_u:=e^{-ru}f(u,S_u)\\ &\quad=e^{-rT}\,\mathbb E^Q_u[g(S_T)],\\ &\mathbb E^Q_s[M_u]\\ &\quad=e^{-rT}\,\mathbb E^Q_s\big[\mathbb E^Q_u[g(S_T)]\big]\\ &\quad=e^{-rT}\,\mathbb E^Q_s[g(S_T)]=M_s,\\ &dM_u=-re^{-ru}f\,du+e^{-ru}\,df,\\ &df=\Big(f_t+rSf_S\\ &\qquad+\tfrac12\sigma^2S^2f_{SS}\Big)\,du\\ &\quad+\sigma Sf_S\,dW^Q,\\ &dM_u=e^{-ru}\Big(f_t+rSf_S\\ &\qquad+\tfrac12\sigma^2S^2f_{SS}-rf\Big)\,du\\ &\quad+e^{-ru}\sigma Sf_S\,dW^Q. \end{aligned} \]

$dM_u$ แยกเป็นสองก้อน ก้อนที่คูณ $dW^Q$ คือการแกว่งแบบสุ่ม เมื่อสะสมแล้วเป็น Itô integral ซึ่งเฉลี่ยเป็นศูนย์ จึงไม่ทำให้ $M$ มีแนวโน้ม ก้อนที่คูณ $du$ คือแนวโน้ม ถ้าวงเล็บของก้อนนี้ไม่เป็นศูนย์ที่เวลาและราคาใด $M$ จะไหลขึ้นหรือลงอย่างคาดได้จากจุดนั้น ซึ่งขัดกับข้อที่ว่า $M$ เป็น martingale วงเล็บจึงต้องเป็นศูนย์ทุกจุดบนระนาบ

กฎผลคูณปกติของ Itô มีพจน์ไขว้ $d(e^{-ru})\,df$ ด้วย แต่ $e^{-ru}$ ขึ้นกับเวลาอย่างเดียว ไม่มีส่วนที่สุ่ม พจน์ไขว้จึงเป็นศูนย์

ขั้นที่ 4 — PDE ที่เดินย้อน พร้อมเงื่อนไขตอนจบ

วงเล็บที่ต้องเป็นศูนย์คือ PDE ที่เราตามหา แต่ PDE ตัวเดียวมีคำตอบได้หลายตัว ต้องมีเงื่อนไขอีกข้อมาล็อก เงื่อนไขนั้นคือวันครบกำหนด: วันนั้นไม่มีเวลาเหลือ มูลค่าจึงเท่ากับเงินที่จ่าย เหมือนชั้นปลายของต้นไม้

จากนั้นแปลง PDE เป็นสูตรที่คอมพิวเตอร์ใช้เดินย้อนได้ทีละก้าว วางตารางที่ราคาห่างกัน $\Delta S$ และเวลาห่างกัน $\Delta t$ ให้ $f^{n}_i$ คือมูลค่าที่ราคา $S_i$ และเวลาก้าวที่ $n$ โดยก้าว $n+1$ อยู่ถัดไปทางวันครบกำหนด แล้วแทนอนุพันธ์แต่ละตัวด้วยผลต่างของจุดข้างเคียง (finite difference) ในสูตรของ $f_S$ และ $f_{SS}$ ละตัวยก $n+1$ ไว้เพื่อให้สั้น ทุกตัวในนั้นคือค่าที่ก้าว $n+1$ ซึ่งรู้แล้ว

\[ \begin{aligned} &f_t+rSf_S+\tfrac12\sigma^2S^2f_{SS}-rf=0,\\ &f(T,S)=g(S),\\ &f_t\approx\frac{f^{n+1}_i-f^{n}_i}{\Delta t},\\ &f_S\approx\frac{f_{i+1}-f_{i-1}}{2\Delta S},\\ &f_{SS}\approx\frac{f_{i+1}-2f_i+f_{i-1}}{\Delta S^2},\\ &f^{n}_i=f^{n+1}_i+\Delta t\Big(rS_if_S\\ &\qquad+\tfrac12\sigma^2S_i^2f_{SS}-rf^{n+1}_i\Big). \end{aligned} \]

PDE บอกว่า ถ้าถือสัญญาไว้ช่วงสั้น ๆ มูลค่าที่งอกขึ้นเฉลี่ยต้องเท่ากับดอกเบี้ยของเงินก้อนเดียวกันพอดี มูลค่างอกจากสามแหล่ง: เวลาที่ผ่านไป ($f_t$) หุ้นที่โตเฉลี่ยตามดอกเบี้ย ($rSf_S$) และความโค้งของมูลค่าที่เจอการแกว่งของหุ้น ($\tfrac12\sigma^2S^2f_{SS}$ โดย $\sigma^2S^2$ คือ variance ของการขยับของราคาต่อปี) ผลรวมนี้ต้องเท่ากับ $rf$ ที่เงินฝากให้ PDE ตัวเดียวกันนี้หาได้อีกทางจากพอร์ตเลียนแบบ ในหน้า Black–Scholes PDE

สูตรเดินย้อนได้จากการแทนผลต่างทั้งสามลงใน PDE แล้วย้าย $f^n_i$ ไปไว้ข้างซ้าย ถ้ารู้ค่าทั้งแถวที่เวลาก้าว $n+1$ ก็คำนวณจุดหนึ่งของแถวก่อนหน้าได้จากสามจุดข้างเคียง เหมือนต้นไม้ที่แต่ละจุดใช้ลูกสองตัว

มีข้อควรระวังสองข้อ ข้อแรก สะพานจากค่าเฉลี่ยไป PDE ต้องการเงื่อนไขทางเทคนิค: เงินที่จ่ายต้องไม่โตเร็วเกินไปเมื่อราคาสูงขึ้น และก้อน $dW^Q$ ต้องเฉลี่ยเป็นศูนย์จริงตลอดช่วง ข้อสอง ตารางแบบนี้ต้องใช้ก้าวเวลาเล็กพอ คือ $\Delta t$ ไม่เกินราว $\Delta S^2/(\sigma^2S^2)$ ไม่เช่นนั้นความคลาดจะขยายทุกก้าวจนตัวเลขพุ่งเป็นค่ามหาศาล รายละเอียดอยู่ในหน้าการตั้งราคาด้วย finite difference

ขั้นที่ 5 — ทางเดินหน้า: ค่าเฉลี่ยของ S² ใต้ Q จาก Itô

เงินที่จ่ายของ note เป็นแค่ $S^2$ หาร 200 ค่าเฉลี่ยในนิยามจึงคำนวณได้ตรง ๆ ไม่ต้องสุ่ม เราจะได้คำตอบที่ถูกต้องแน่นอนไว้เทียบกับทางอื่น

วิธีคือใช้ Itô's lemma กับ $x^2$ เพื่อดูว่า $S^2$ เคลื่อนอย่างไรในโลก $Q$ (ที่หุ้นโตเฉลี่ย $r$) แล้วหาค่าเฉลี่ย ก้อน $dW^Q$ เฉลี่ยเป็นศูนย์ จึงเหลือค่าเฉลี่ย $m(u)$ ที่โตด้วยอัตราคงที่ เมื่อ $\tau=T-t$ คือเวลาที่เหลือ จากนั้นหารด้วย $K$ และคิดลดตามนิยามในขั้นที่ 2

\[ \begin{aligned} &d(S^2)=2S\,dS+(dS)^2\\ &\quad=2S(rS\,dt+\sigma S\,dW^Q)\\ &\qquad+\sigma^2S^2\,dt\\ &\quad=(2r+\sigma^2)S^2\,dt\\ &\qquad+2\sigma S^2\,dW^Q,\\ &m(u):=\mathbb E^Q\big[S_u^2\mid S_t=S\big],\\ &\frac{dm}{du}=(2r+\sigma^2)\,m,\quad m(t)=S^2,\\ &m(T)=S^2e^{(2r+\sigma^2)\tau},\\ &f(t,S)=e^{-r\tau}\,\frac{m(T)}{K}\\ &\quad=\frac{S^2}{K}\,e^{(r+\sigma^2)\tau},\\ &r+\sigma^2=0.04+0.09=0.13,\\ &f(0,200)=\frac{200^2}{200}\,e^{0.13}\\ &\quad=200(1.138828)=227.77. \end{aligned} \]

$S^2$ โตเฉลี่ยเร็วกว่าสองเท่าของหุ้น อัตรา $2r$ มาจากความชันของ $x^2$ ส่วน $\sigma^2$ ที่เพิ่มมามาจากความโค้ง: Itô ให้ $\tfrac12\cdot2\cdot\sigma^2=\sigma^2$ ค่าเฉลี่ยของเงินที่จ่ายจึงโตด้วยอัตรา $2r+\sigma^2=0.08+0.09=0.17$ ต่อปี ก่อนคิดลดได้ $200\,e^{0.17}=\$237.06$ คิดลดแล้วหัก $r$ ออกหนึ่งตัว เหลือ $r+\sigma^2=0.13$

สิ่งที่ควรสังเกตคือ ความผันผวนทำให้ราคาสูงขึ้น เพราะเงินที่จ่ายโค้งหงาย หุ้นที่แกว่งขึ้นได้เงินเพิ่มมากกว่าที่แกว่งลงเสียไป ทางลัดของนักวิเคราะห์ไม่มี $\sigma^2$ ตัวนี้เลย

ขั้นที่ 6 — ทางเดินย้อน: แทนลง PDE แล้วทุกพจน์หักกัน

ขั้นที่แล้วได้ $f$ จากทางเดินหน้า ถ้า Feynman–Kac ถูก $f$ ตัวเดียวกันนี้ต้องแก้ PDE ของทางเดินย้อนได้ด้วย ลองแทนดู หาอนุพันธ์สามตัวแล้วเขียนกลับในรูปของ $f$ เอง จะหักกันได้ง่าย $f_t$ มีเครื่องหมายลบ เพราะเวลาที่เหลือ $\tau=T-t$ ลดลงเมื่อ $t$ เพิ่ม สุดท้ายตรวจเงื่อนไขในวันครบกำหนด

\[ \begin{aligned} &f_t=-(r+\sigma^2)f,\\ &f_S=\frac{2f}{S},\quad f_{SS}=\frac{2f}{S^2},\\ &-(r+\sigma^2)f+rS\,\frac{2f}{S}\\ &\quad+\tfrac12\sigma^2S^2\,\frac{2f}{S^2}-rf\\ &=(-r-\sigma^2+2r+\sigma^2-r)\,f\\ &=0,\\ &f(T,S)=\frac{S^2}{K}e^0=g(S). \end{aligned} \]

ทุกพจน์กลายเป็นตัวเลขคูณ $f$ เพราะ $S$ ตัดกับ $1/S$ ในพจน์ $f_S$ และ $S^2$ ตัดกับ $1/S^2$ ในพจน์ $f_{SS}$ จากนั้นก้อนของ $r$ คือ $-r+2r-r=0$ และก้อนของ $\sigma^2$ คือ $-\sigma^2+\sigma^2=0$ หักกันหมดทุกเวลาและทุกราคา ขั้นนี้ใช้แค่ calculus ธรรมดา ไม่มีความน่าจะเป็นเลย แต่ได้คำตอบเดียวกับการเฉลี่ยของทางเดินหน้า นี่คือ Feynman–Kac ที่เห็นกับตา

ตรวจเองใน 10 วินาที: SE ที่โค้ดรายงานหาจากสูตรได้ เริ่มจาก SD ของเงินที่จ่ายที่คิดลดแล้วหนึ่งครั้ง แล้วหารด้วย $\sqrt n$ เมื่อ $n=200{,}000$ ครั้ง variance ของ $S_1^2$ ต้องใช้ $\mathbb E^Q[S_1^4]$ ซึ่งหาแบบเดียวกับขั้นที่ 5 โดยใช้ Itô กับ $x^4$ แทน $x^2$ ได้ $S_0^4e^{4r+6\sigma^2}$ หักกำลังสองของค่าเฉลี่ยออกได้ variance ถอดรากที่สองแล้วคูณด้วย $e^{-r}/K$ ได้ SD ของเงินที่จ่ายที่คิดลดแล้ว ซึ่งเท่ากับ $f\sqrt{e^{4\sigma^2}-1}$ เพราะ $e^{-r}\,\mathbb E^Q[S_1^2]/K=f$ และ $4\sigma^2=0.36$

\[ \begin{aligned} \operatorname{Var}(S_1^2)&=\mathbb E^Q[S_1^4]\\ &\quad-\big(\mathbb E^Q[S_1^2]\big)^2\\ &=S_0^4e^{4r+6\sigma^2}\\ &\quad-S_0^4e^{4r+2\sigma^2}\\ &=\big(\mathbb E^Q[S_1^2]\big)^2(e^{4\sigma^2}-1),\\ \text{SD}&=227.77\sqrt{e^{0.36}-1}\\ &=227.77(0.6583)=\$149.93,\\ \text{SE}&=\frac{149.93}{\sqrt{200{,}000}}=\frac{149.93}{447.2}\\ &=\$0.335. \end{aligned} \]

ใกล้กับ \$0.333 ที่โค้ดวัดจากตัวอย่างที่สุ่มได้จริง

ขั้นที่ 8 — คำตอบของโจทย์เปิดเรื่อง และ delta กับ gamma

ตอนนี้มีราคาที่ถูก $f=200\,e^{0.13}$ แล้ว จึงวัดได้ว่าทางลัดของนักวิเคราะห์พลาดไปเท่าไร ทางลัดใส่ราคาเฉลี่ยในโลก $Q$ เข้าไปในสูตรเงินที่จ่ายก่อน แล้วค่อยคิดลด เรียกผลนี้ว่า $f_{\rm plug}$

ธนาคารที่ขาย note ยังต้องรู้อีกเรื่อง คือจะซื้อหุ้นไว้กี่หุ้นเพื่อหักล้างความเสี่ยง (hedge) ตัวเลขนี้คือ delta $\Delta=f_S$ มูลค่า note เปลี่ยนกี่ดอลลาร์เมื่อหุ้นขึ้น \$1 ส่วน gamma $\Gamma=f_{SS}$ บอกว่า delta เปลี่ยนเร็วแค่ไหน สูตรของทั้งสองได้มาแล้วตอนแทนลง PDE ในขั้นที่ 6: $f_S=2f/S$ และ $f_{SS}=2f/S^2$

\[ \begin{aligned} &f_{\rm plug}=e^{-0.04}\frac{(200e^{0.04})^2}{200}\\ &\qquad=200\,e^{0.04}\approx208.16,\\ &\frac{f_{\rm plug}}{f}=\frac{200\,e^{0.04}}{200\,e^{0.13}}=e^{-0.09},\\ &1-\frac{f_{\rm plug}}f=1-e^{-0.09}\approx8.61\%,\\ &\frac{f}{f_{\rm plug}}-1=e^{0.09}-1\approx9.42\%,\\ &\Delta=\frac{2(227.77)}{200}=2.2777,\\ &\Gamma=\frac{2(227.77)}{200^2}\approx0.01139. \end{aligned} \]

ทางลัดใช้แค่ราคาเฉลี่ย และทิ้งเรื่องที่ราคาปีหน้ากระจายกว้างแค่ไหนไปทั้งหมด จึงหาย $e^{\sigma^2}=e^{0.09}$ ไปทั้งตัว ราคาทางลัดต่ำไป 8.61% เมื่อเทียบกับราคาที่ถูก หรือราคาที่ถูกสูงกว่า 9.42% เมื่อเทียบกับราคาทางลัด ตัวเลขสองตัวนี้พูดถึงช่องว่างเดียวกัน แต่ใช้ฐานต่างกัน เวลารายงานจึงต้องบอกฐานของเปอร์เซ็นต์ให้ชัด

delta 2.2777 แปลว่า note หนึ่งฉบับขยับเหมือนหุ้นราว 2.28 หุ้น ธนาคารที่ขาย note หนึ่งฉบับจึงถือหุ้นราว 2.28 หุ้นเพื่อหักล้าง gamma 0.01139 แปลว่าเมื่อหุ้นขึ้น \$1 delta เพิ่มราว 0.011 หุ้น ธนาคารจึงต้องซื้อหุ้นเพิ่มเมื่อราคาขึ้น รูปด้านล่างแสดงว่าทำไมทางลัดต่ำไปเสมอเมื่อเงินที่จ่ายโค้งหงาย

ขั้นที่ 9 — เมื่อดอกเบี้ยเองก็สุ่ม: พันธบัตรของ Vasicek

จนถึงตรงนี้ดอกเบี้ยคงที่ 4% ตลอด แต่ในตลาดจริง ดอกเบี้ยขึ้นลงทุกวัน คำถามของขั้นนี้คือ พันธบัตรที่จ่าย \$1 ในอีกหนึ่งปี (zero-coupon bond: ไม่จ่ายดอกเบี้ยระหว่างทาง จ่ายก้อนเดียวตอนครบกำหนด) ควรราคาเท่าไรวันนี้ ถ้าดอกเบี้ยเองก็สุ่ม

ตัวแปรสุ่มตอนนี้คือ short rate $r_t$ คือดอกเบี้ยของเงินกู้ระยะสั้นมาก ณ เวลา $t$ คิดเป็นต่อปี เมื่อดอกเบี้ยเปลี่ยนตามเวลา การคิดลดต้องใช้ดอกเบี้ยตลอดทาง คือ $D_T=e^{-\int_0^Tr_u\,du}$ แทน $e^{-rT}$ และตัวคิดลดนี้สุ่ม จึงดึงออกนอกค่าเฉลี่ยไม่ได้อีกแล้ว ให้ $P(0,1)$ คือราคาวันนี้ของพันธบัตรที่จ่าย \$1 ในอีกหนึ่งปี กฎตั้งราคาเดิมให้ $P(0,1)=\mathbb E^Q[D_1\times1]=\mathbb E^Q[D_1]$

ดอกเบี้ยเคลื่อนตามแบบจำลอง Vasicek: $dr=\kappa(\theta-r)\,dt+\sigma_V\,dW^Q$ ก้อนแรกดึงดอกเบี้ยเข้าหาระดับ $\theta$ ยิ่งห่างยิ่งดึงแรง ก้อนที่สองคือการแกว่งแบบสุ่ม ตัวเลขที่ใช้ (สมมติว่าเป็นค่าของโลก $Q$):

  • ดอกเบี้ยวันนี้ $r_0=1.5\%$
  • ระดับที่ดอกเบี้ยถูกดึงเข้าหา $\theta=3\%$
  • ความเร็วที่ดึง $\kappa=0.8$ ต่อปี
  • ความผันผวนของดอกเบี้ย $\sigma_V=1.2\%$ ต่อปี

ทางเดินย้อน: หลักเดิมยังใช้ได้ มูลค่าที่คิดลดแล้ว $D_tf(t,r_t)$ เป็น martingale ในโลก $Q$ เหมือนในต้นไม้ของดอกเบี้ย ที่แต่ละจุดคือค่าเฉลี่ยของจุดถัดไป หารด้วย 1 บวกดอกเบี้ยของจุดนั้นเอง ทำสะพานเดิมซ้ำ (ใช้ $dD=-rD\,dt$) ได้ PDE ในสองแถวแรกด้านล่าง ต่างจากเดิมตรงที่ $r$ ในพจน์ $-rf$ เป็นตัวแปร ไม่ใช่ค่าคงที่ และพันธบัตรจ่าย \$1 แน่นอน เงื่อนไขในวันครบกำหนดจึงเป็น $f(T,r)=1$

ทางเดินหน้า: $\int_0^Tr_t\,dt$ คือผลรวมของ shock แบบ Normal ที่คูณน้ำหนักคงที่ จึงเป็น Normal ด้วย รู้แค่ค่าเฉลี่ยกับ variance ก็พอ ให้ $m_t=\mathbb E^Q[r_t]$ คือดอกเบี้ยเฉลี่ยที่เวลา $t$ และ $h(s)$ คือน้ำหนักรวมที่ shock ณ เวลา $s$ ส่งต่อไปถึงวันครบกำหนด

\[ \begin{aligned} &f_t+\kappa(\theta-r)f_r\\ &\quad+\tfrac12\sigma_V^2f_{rr}-rf=0,\\ &f(T,r)=1,\\ &m_t=\theta+(r_0-\theta)e^{-\kappa t},\\ &h(s)=\frac{1-e^{-\kappa(T-s)}}{\kappa},\\ &\int_0^Tr_t\,dt=\int_0^Tm_t\,dt\\ &\quad+\sigma_V\int_0^Th(s)\,dW_s^Q,\\ &\int_0^Tm_t\,dt=\theta T\\ &\quad+(r_0-\theta)\frac{1-e^{-\kappa T}}{\kappa},\\ &T=1:\ 1-e^{-0.8}=0.550671,\\ &\quad0.03-0.015\,\frac{0.550671}{0.8}\\ &\qquad=0.019675,\\ &\operatorname{Var}^Q\Big(\int_0^Tr_t\,dt\Big)\\ &=\frac{\sigma_V^2}{\kappa^2}\Big(T-\frac{2(1-e^{-\kappa T})}{\kappa}\\ &\qquad+\frac{1-e^{-2\kappa T}}{2\kappa}\Big),\\ &T=1:\ \frac{0.012^2}{0.8^2}=0.000225,\\ &\quad1-\frac{2(0.550671)}{0.8}+\frac{0.798103}{1.6}\\ &\qquad=1-1.376678+0.498815\\ &\qquad=0.122137,\\ &\quad0.000225(0.122137)\\ &\qquad\approx0.0000275,\\ &P(0,1)\approx e^{-0.019675+\frac12(0.0000275)}\\ &\qquad\approx0.980531. \end{aligned} \]

$m_t$ คือคำตอบของ Vasicek เมื่อตัด shock ออก: ดอกเบี้ยเฉลี่ยเริ่มที่ $r_0$ แล้วเข้าหา $\theta$ โดยช่องว่างหดลงเป็น $e^{-\kappa t}$ เท่า อินทิเกรต $m_t$ จาก 0 ถึง $T$ ได้ค่าเฉลี่ยของดอกเบี้ยสะสม 0.019675 ซึ่งน้อยกว่า $\theta=0.03$ เพราะดอกเบี้ยเริ่มที่ 1.5% และยังไต่ไม่ถึง 3%

$h(s)$ มาจากคำตอบของ Vasicek เช่นกัน: shock ที่เวลา $s$ ส่งผลต่อดอกเบี้ย $r_t$ ทุกตัวหลังจากนั้น ด้วยน้ำหนัก $e^{-\kappa(t-s)}$ ที่จางลงตามเวลา รวมน้ำหนักตั้งแต่ $t=s$ ถึง $T$ ได้ $(1-e^{-\kappa(T-s)})/\kappa$ variance ได้จาก isometry ของ Itô integral: variance คือ integral ของกำลังสองของน้ำหนัก $\sigma_V^2\int_0^Th(s)^2\,ds$ ซึ่งกระจายออกมาเป็นวงเล็บสามพจน์ข้างบน ราคาพันธบัตรใช้สูตรของ Normal: ถ้า $X$ เป็น Normal ที่ค่าเฉลี่ย $m$ และ variance $v$ แล้ว $\mathbb E[e^{-X}]=e^{-m+v/2}$

ราคา 0.980531 คิดเป็น yield (ผลตอบแทนต่อปีที่พันธบัตรให้ถ้าถือจนครบกำหนด) $-\ln(0.980531)/1=1.9661\%$ ต่อปี ถ้าไม่คิด variance จะได้ $e^{-0.019675}=0.980517$ ต่างกันแค่ $0.98053084-0.98051737=0.0000135$ ผลของ variance เล็กเพราะดอกเบี้ยสะสมทั้งปีมี SD แค่ $\sqrt{0.0000275}=0.0052$ หรือราว 0.52 จุดเปอร์เซ็นต์ ส่วนทางเดินย้อน ตารางในโค้ดที่แก้ PDE จากเงื่อนไข $f(1,r)=1$ ได้ 0.980532 ตรงกันถึงทศนิยมตำแหน่งที่ห้า

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

ใส่ราคาเฉลี่ยเข้าสูตรเงินที่จ่ายที่โค้ง: ความผิดคือเฉลี่ยราคาก่อนแล้วค่อยใส่สูตร แทนที่จะใส่สูตรก่อนแล้วค่อยเฉลี่ย ผลผิดคือ $e^{-0.04}(208.16^2/200)=\$208.16$ ผลถูกคือ $200\,e^{0.13}=\$227.77$ ต่ำไป 8.61% เงินที่จ่ายที่โค้งหงายทำให้ทางลัดได้ค่าต่ำกว่าหรือเท่ากับค่าที่ถูกเสมอ เงินที่จ่ายที่โค้งคว่ำกลับกัน ทางลัดได้ค่าสูงกว่าหรือเท่ากับค่าที่ถูก สองทางเท่ากันได้เฉพาะเมื่อเงินที่จ่ายเป็นเส้นตรงตลอดช่วงราคาที่เกิดขึ้นได้

ใช้ drift ของโลกจริงแทนดอกเบี้ย: ความผิดคือให้หุ้นโตตามที่คาดว่าจะโตจริง (สมมติ 10% ต่อปี) แทนที่จะโตเท่าดอกเบี้ย 4% ไม่ว่าใน PDE หรือในการสุ่ม ค่าเฉลี่ยของเงินที่จ่ายจะโตด้วยอัตรา $2(0.10)+0.09=0.29$ แทน 0.17 ผลผิดคือ $200\,e^{0.29-0.04}=200\,e^{0.25}=\$256.81$ ผลถูกคือ \$227.77 สูงเกินไป $256.81-227.77=\$29.04$ สัญญาณที่จับได้คือราคาในระบบเปลี่ยนตามความเห็นเรื่องทิศทางตลาด ซึ่งราคาที่ถูกไม่ควรขึ้นกับเรื่องนี้

ลืมพจน์ $-rf$ (ลืมคิดลด): ความผิดคือตาราง PDE ไม่มีพจน์ $-rf$ ผลที่ได้คือค่าเฉลี่ยของเงินที่จ่ายที่ยังไม่คิดลด $200\,e^{0.17}=\$237.06$ ผลถูกคือ $200\,e^{0.13}=\$227.77$ สูงเกินไป $237.061-227.766=\$9.30$ ความผิดนี้ซ่อนง่าย เพราะพจน์อื่นในสมการยังอยู่ครบ

วางขอบตารางหรือขอบ integral ใกล้เกินไป: ความผิดคือหยุดคำนวณที่ราคาสูงสุดที่ยังไม่สูงพอ ตัดการอินทิเกรตที่ \$800 ได้ \$227.7595 ผลถูกคือ \$227.7657 ขาดไป $227.7657-227.7595=\$0.006$ สำหรับ note นี้ ตารางที่ขอบบนอยู่แค่สองเท่าของราคาวันนี้ก็คลาดในทำนองเดียวกัน เพราะเงินที่จ่ายที่โตตามราคายังมีมูลค่าในหางขวา วิธีตรวจคือเลื่อนขอบออกไปอีก แล้วดูว่าคำตอบนิ่งไหม

ใช้ทำอะไรบนโต๊ะจริง

ระบบตั้งราคาจริงเลือกทางตามโจทย์ ถ้าเป็น option ตัวเดียวบนหุ้นตัวเดียว ระบบมักแก้ PDE บนตาราง (finite-difference pricing) เพราะได้ทั้งราคา delta และ gamma ในคราวเดียว ทุกจุดบนตารางอยู่ติดกัน หาอนุพันธ์จากผลต่างได้ทันที

ถ้าสัญญาอ้างอิงหลายสินทรัพย์ ระบบใช้การสุ่ม เพราะตารางโตแบบทวีคูณตามจำนวนตัวแปร ถ้าแต่ละตัวแปรใช้ 200 จุด ตัวแปรเดียวมี 200 จุด แต่สามตัวแปรมี $200^3=8{,}000{,}000$ จุดในทุกก้าวเวลา เกินราวสามตัวแปรตารางจึงใหญ่เกินไป การสุ่มไม่มีปัญหานี้ แต่แม่นขึ้นช้า SE หดตาม $1/\sqrt n$ ถ้าอยากให้ SE เหลือครึ่งหนึ่งต้องสุ่มเพิ่มสี่เท่า เพราะ $1/\sqrt{4n}=\tfrac12\cdot1/\sqrt n$

การอินทิเกรตกับ density ใช้ได้ดีเมื่อรู้ density ของราคาปลายทาง หรือรู้ characteristic function ของ log ราคา (ค่าเฉลี่ยของ $e^{iu\ln S_T}$ โดย $i$ คือหน่วยจินตภาพ ค่านี้หาง่ายในหลายแบบจำลอง) วิธีนี้คือฐานของการตั้งราคาด้วย Fourier และ FFT

American option คือ option ที่ใช้สิทธิ์ก่อนวันครบกำหนดได้ สัญญาแบบนี้เข้ากับทางเดินย้อนอย่างเป็นธรรมชาติ ที่แต่ละจุดของต้นไม้หรือตาราง เทียบมูลค่าถ้าใช้สิทธิ์ทันทีกับมูลค่าถ้าถือต่อ แล้วเก็บตัวที่มากกว่า ทางเดินหน้าทำแบบนี้ยาก เพราะระหว่างที่สุ่มเส้นทางไปข้างหน้า เรายังไม่รู้ว่ามูลค่าถ้าถือต่อเป็นเท่าไร

ทีมที่ดีคิดสัญญาใหม่ทั้งสองทางอย่างน้อยหนึ่งครั้งก่อนปล่อยโค้ดขึ้นระบบ และจำไว้ว่าสองทางตรงกันแปลว่าโค้ดทำตามแบบจำลองถูก ไม่ได้แปลว่าแบบจำลองตรงกับตลาด

function checkPositive(values, message) {
  if (!values.every(v => Number.isFinite(v) && v > 0)) throw new RangeError(message);
}
// n-period tree with gross rate R per period: backward induction layer by layer, and the forward sum over paths.
function tree(S0, u, R, n, payoff) {
  checkPositive([S0, u, R], 'Need S0, u and R > 0');
  const d = 1 / u, q = (R - d) / (u - d);
  if (!(q > 0 && q < 1)) throw new RangeError('No-arbitrage needs d < R < u');
  let V = Array.from({length: n + 1}, (_, j) => payoff(S0 * u ** j * d ** (n - j)));
  const leaves = V.slice(), layers = [V];
  for (let i = n - 1; i >= 0; i--) {
    V = Array.from({length: i + 1}, (_, j) => (q * V[j + 1] + (1 - q) * V[j]) / R);
    layers.unshift(V);
  }
  let forward = 0, binom = 1;
  for (let j = 0; j <= n; j++) {
    forward += binom * q ** j * (1 - q) ** (n - j) * leaves[j];
    binom = binom * (n - j) / (j + 1);
  }
  const shares = (layers[1][1] - layers[1][0]) / (S0 * u - S0 * d);
  return {q, layers, backward: layers[0][0], forward: forward / R ** n, shares, cash: layers[0][0] - shares * S0};
}
// Power note paying S_T^2 / K under Q: f(t, S) = (S^2 / K) e^((r + sigma^2)(T - t)).
function powerNote(S, K, r, sigma, tau) {
  checkPositive([S, K, sigma, tau], 'Need S, K, sigma and time to expiry > 0');
  const f = S * S / K * Math.exp((r + sigma * sigma) * tau);
  return {f, delta: 2 * f / S, gamma: 2 * f / (S * S)};
}
// Backward side on a grid: explicit finite differences for f_t + r S f_S + sigma^2 S^2 f_SS / 2 - r f = 0.
function gridPowerNote(S0, K, r, sigma, T, nS, nT) {
  checkPositive([S0, K, sigma, T], 'Need S0, K, sigma and T > 0');
  const dS = 4 * S0 / nS, dt = T / nT;
  if (dt * (sigma * sigma * nS * nS + r) > 1) throw new RangeError('Time step too large for the explicit scheme');
  let f = Array.from({length: nS + 1}, (_, i) => (i * dS) ** 2 / K);   // payoff at expiry
  for (let n = 0; n < nT; n++) {
    const g = f.slice();
    for (let i = 1; i < nS; i++) {
      const S = i * dS, fS = (f[i + 1] - f[i - 1]) / (2 * dS), fSS = (f[i + 1] - 2 * f[i] + f[i - 1]) / (dS * dS);
      g[i] = f[i] + dt * (r * S * fS + 0.5 * sigma * sigma * S * S * fSS - r * f[i]);
    }
    g[0] = f[0] * (1 - r * dt);                        // at S = 0 only discounting remains
    g[nS] = 3 * g[nS - 1] - 3 * g[nS - 2] + g[nS - 3];  // far edge: zero third difference
    f = g;
  }
  return f[Math.round(S0 / dS)];
}
// Third route: integrate the payoff against the lognormal density of S_T under Q (trapezoid rule).
function densityIntegral(S0, K, r, sigma, T, eta, upper) {
  checkPositive([S0, K, sigma, T, eta, upper], 'Need positive inputs');
  const m = Math.log(S0) + (r - 0.5 * sigma * sigma) * T, s = sigma * Math.sqrt(T), N = Math.round(upper / eta);
  const dens = x => x <= 0 ? 0 : Math.exp(-0.5 * ((Math.log(x) - m) / s) ** 2) / (x * s * Math.sqrt(2 * Math.PI));
  let sum = 0;
  for (let j = 0; j <= N; j++) sum += (j === 0 || j === N ? 0.5 : 1) * eta * (j * eta) ** 2 / K * dens(j * eta);
  return Math.exp(-r * T) * sum;
}
// mulberry32 + Box-Muller: seeded standard Normals, the same generator on every page of this chapter.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Forward side: exact draws of S_T under Q, discounted average of the payoff and its standard error.
function monteCarlo(S0, K, r, sigma, T, draws, seed) {
  checkPositive([S0, K, sigma, T], 'Need S0, K, sigma and T > 0');
  const z = normals(seed), disc = Math.exp(-r * T);
  let s = 0, s2 = 0;
  for (let i = 0; i < draws; i++) {
    const ST = S0 * Math.exp((r - 0.5 * sigma * sigma) * T + sigma * Math.sqrt(T) * z()), x = disc * ST * ST / K;
    s += x; s2 += x * x;
  }
  const mean = s / draws;
  return {mean, se: Math.sqrt((s2 / draws - mean * mean) / (draws - 1))};
}
// Vasicek bond: the integral of r over [0, T] is Normal, so E[exp(-integral)] = exp(-mean + variance / 2).
function vasicekBond(r0, theta, kappa, sigma, T) {
  checkPositive([kappa, sigma, T], 'Need kappa, sigma and T > 0');
  const e1 = Math.exp(-kappa * T), e2 = Math.exp(-2 * kappa * T);
  const mean = theta * T + (r0 - theta) * (1 - e1) / kappa;
  const variance = sigma * sigma / (kappa * kappa) * (T - 2 * (1 - e1) / kappa + (1 - e2) / (2 * kappa));
  const price = Math.exp(-mean + 0.5 * variance);
  return {mean, variance, price, yield: -Math.log(price) / T, noConvexity: Math.exp(-mean)};
}
// Backward side for the bond: explicit grid for f_t + kappa (theta - r) f_r + sigma^2 f_rr / 2 - r f = 0, f(T, r) = 1.
function gridBond(r0, theta, kappa, sigma, T, lo, hi, n, nT) {
  const dr = (hi - lo) / n, dt = T / nT;
  if (dt * (sigma * sigma / (dr * dr) + Math.max(Math.abs(lo), Math.abs(hi))) > 1) throw new RangeError('Time step too large for the explicit scheme');
  let f = new Array(n + 1).fill(1);
  for (let m = 0; m < nT; m++) {
    const g = f.slice();
    for (let i = 1; i < n; i++) {
      const x = lo + i * dr, fr = (f[i + 1] - f[i - 1]) / (2 * dr), frr = (f[i + 1] - 2 * f[i] + f[i - 1]) / (dr * dr);
      g[i] = f[i] + dt * (kappa * (theta - x) * fr + 0.5 * sigma * sigma * frr - x * f[i]);
    }
    g[0] = 2 * g[1] - g[2]; g[n] = 2 * g[n - 1] - g[n - 2];   // straight-line extension at the far edges
    f = g;
  }
  const j = (r0 - lo) / dr, i0 = Math.floor(j), w = j - i0;
  return f[i0] * (1 - w) + f[i0 + 1] * w;
}

  • ราคาของสัญญาหาได้สองทาง ทางเดินหน้าสุ่มเส้นทางในโลก $Q$ แล้วเฉลี่ยเงินที่จ่ายที่คิดลดแล้ว ทางเดินย้อนเริ่มจากเงินที่จ่ายในวันครบกำหนด แล้วถอยเวลากลับบนตาราง Feynman–Kac บอกว่าสองทางได้ฟังก์ชัน $f(t,S)$ ตัวเดียวกัน
  • ในต้นไม้สามงวด สองทางได้ \$6.57 เท่ากัน เพราะการเฉลี่ยซ้อนกันทีละชั้นเท่ากับการเฉลี่ยครั้งเดียว (tower property) พอร์ตเลียนแบบที่รากคือหุ้น 0.598 หุ้นกับเงินสด −\$53.25
  • มูลค่าที่คิดลดแล้ว $e^{-rt}f(t,S_t)$ ไม่มีแนวโน้ม (เป็น martingale) ในโลก $Q$ Itô's lemma จึงบังคับให้ $f_t+rSf_S+\tfrac12\sigma^2S^2f_{SS}-rf=0$ พร้อมเงื่อนไข $f(T,S)=g(S)$ ตารางเดินย้อนคำนวณแต่ละจุดจากสามจุดของก้าวเวลาถัดไป
  • note ที่จ่าย $S_1^2/200$ ราคา $200\,e^{0.13}=\$227.77$ สูตรปิด ตาราง การสุ่ม และการอินทิเกรตกับ density ได้ตัวเลขนี้ภายในความคลาดของแต่ละวิธี delta คือ 2.2777 หุ้น และ gamma คือ 0.01139 หุ้นต่อดอลลาร์ ทางลัดที่ใส่ราคาเฉลี่ยลงในสูตรได้ \$208.16 ต่ำกว่าราคาที่ถูก 8.61% เพราะเงินที่จ่ายโค้งหงาย
  • เมื่อดอกเบี้ยสุ่ม ตัวคิดลดคือ $e^{-\int r\,dt}$ และ PDE มีพจน์ $-rf$ ที่ $r$ เป็นตัวแปร พันธบัตร Vasicek ที่จ่าย \$1 ในหนึ่งปีราคา 0.980531 จากทางเดินหน้า และ 0.980532 จากตารางของทางเดินย้อน
