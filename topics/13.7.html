13.7 The Feynman–Kac Formula

ราคาที่ได้จากการเฉลี่ยเส้นทางข้างหน้า กับราคาที่ได้จากการแก้สมการเชิงอนุพันธ์ย่อยย้อนจากวันครบกำหนด คือฟังก์ชันเดียวกัน จึงเลือกทางที่เหมาะกับโจทย์ แล้วใช้อีกทางตรวจคำตอบได้

หุ้นสมมติราคา \$200 ความผันผวน 30% ต่อปี ดอกเบี้ย 4% note ตัวหนึ่งจ่าย $S_1^2/200$ ดอลลาร์ในอีกหนึ่งปี นักวิเคราะห์ใช้ risk-neutral pricing แบบลัด: ค่าเฉลี่ยของราคาใต้ $Q$ คือ $200e^{0.04}=\$208.16$ ใส่เข้าสูตรเงินที่จ่ายได้ \$216.66 คิดลดกลับได้ \$208.16 อีกทีมเขียนโปรแกรมแก้สมการย้อนจากวันครบกำหนดบนตาราง ได้ \$227.77 ใครถูก?

ลองตอบก่อนเปิดเฉลย

ตาราง \$227.77 ถูก และการสุ่มเส้นทางไปข้างหน้าแล้วเฉลี่ยเงินที่จ่ายก็ให้ \$227.77 เช่นกัน (ภายในความคลาดของการสุ่ม) นักวิเคราะห์ใส่ราคาเฉลี่ยเข้าไปในเงินที่จ่ายที่โค้งหงาย ซึ่งให้ค่าต่ำกว่าค่าเฉลี่ยของเงินที่จ่ายเสมอ ต่ำไป \$19.60 หรือ 8.61% ของราคาที่ถูก (ถ้าใช้ราคาทางลัดเป็นฐาน ราคาที่ถูกสูงกว่า $e^{\sigma^2}-1=9.42\%$)

ภาพรวมก่อนลงสูตร

Risk-neutral measure ให้สูตรราคา $V_0=e^{-rT}\mathbb E^Q[H_T]$ ซึ่งเป็นการมองไปข้างหน้า: สุ่มเส้นทางของหุ้นในโลกที่หุ้นโตเท่าดอกเบี้ย เฉลี่ยเงินที่จ่าย แล้วคิดลด แต่โต๊ะ option จำนวนมากตั้งราคาอีกทาง คือเริ่มจากเงินที่จ่ายในวันครบกำหนด ซึ่งรู้แน่นอนทุกราคา แล้วเดินย้อนเวลาทีละก้าวบนตาราง แบบเดียวกับการตั้งราคาบนต้นไม้ binomial

Feynman–Kac บอกว่าสองทางนี้คำนวณฟังก์ชันเดียวกัน $f(t,S)$ คือมูลค่าของสัญญาเมื่อเวลาเป็น $t$ และราคาเป็น $S$ เหตุผลมีสองชิ้นที่รู้จักแล้ว: tower property (ค่าเฉลี่ยของค่าเฉลี่ยแบบมีเงื่อนไขคือค่าเฉลี่ยเดิม) ทำให้มูลค่าที่คิดลดไม่มี drift และ Itô's lemma แปลงคำว่า “ไม่มี drift” ให้เป็นสมการเชิงอนุพันธ์ย่อย (PDE) รูปด้านล่างวางสองทิศนี้ไว้บนระนาบเดียวกัน

หน้านี้เริ่มจากต้นไม้สามงวดด้วยมือ สร้างสะพานจากค่าเฉลี่ยไปสู่ PDE คิด note ของโจทย์เปิดเรื่องด้วยสูตรปิด ตารางที่เดินย้อน การสุ่มที่เดินหน้า และการอินทิเกรตเงินที่จ่ายกับ density ใต้ $Q$ ตรง ๆ แล้วขยายไปกรณีที่ดอกเบี้ยเองก็สุ่ม โดยคิดราคาพันธบัตรของแบบจำลอง Vasicek ทั้งสองทาง

Monte Carlo

ขั้นที่ 1 — ต้นไม้สามงวดด้วยมือ: เดินย้อนกับเดินหน้าได้เท่ากัน

โจทย์ให้อะไรมาบ้าง: หุ้น \$100 แต่ละงวดขึ้น $u=1.07$ เท่าหรือลง $d=1/1.07$ เท่า เงินฝากโต $R=1.01$ ต่องวด call ที่ strike \$100 ครบกำหนดหลังสามงวด โอกาสขาขึ้นใต้ $Q$ คือ $q=(R-d)/(u-d)=0.5569$ (หุ้นต้องโตเท่าเงินฝาก) คิดราคาสองทาง: เดินย้อนทีละชั้นโดยให้แต่ละจุดเป็นค่าเฉลี่ยคิดลดของสองจุดถัดไป กับรวมทุกเส้นทางที่ปลายทางตรง ๆ

\[ \begin{aligned} C_{2,\text{top}}&=\tfrac{0.5569(22.50)+0.4431(7)}{1.01}\\ &=15.48,\\ C_{2,\text{mid}}&=\tfrac{0.5569(7)}{1.01}=3.86,\\ C_{1,\text{up}}&=\tfrac{0.5569(15.48)+0.4431(3.86)}{1.01}\\ &=10.23,\\ C_{1,\text{down}}&=\tfrac{0.5569(3.86)}{1.01}=2.13,\\ C_0&=\tfrac{0.5569(10.23)+0.4431(2.13)}{1.01}\\ &=6.57,\\ \text{forward}&=\tfrac{q^3(22.50)+3q^2(1-q)(7)}{1.01^3}\\ &=\tfrac{0.1727(22.50)+0.4123(7)}{1.0303}\\ &=6.57. \end{aligned} \]

คำตอบ: สองทางได้ \$6.57 เท่ากัน ทางเดินย้อนใช้แค่ “แต่ละจุดเท่ากับค่าเฉลี่ยคิดลดของลูกสองตัว” ซึ่งคือต้นแบบของ PDE ทางเดินหน้ารวมน้ำหนักของเส้นทางทั้งเส้น ($q^3$ สำหรับขึ้นสามครั้ง และ $3q^2(1-q)$ สำหรับขึ้นสองลงหนึ่งซึ่งมีสามแบบ) ซึ่งคือต้นแบบของ Monte Carlo ที่เท่ากันเพราะค่าเฉลี่ยซ้อนค่าเฉลี่ยยุบเหลือค่าเฉลี่ยเดียว (tower property)

ตรวจเองใน 10 วินาที: ที่ราก พอร์ตเลียนแบบถือหุ้น $(10.23-2.13)/(107-93.46)=0.598$ หุ้น และเงินสด $6.57-59.82=-53.25$ ดอลลาร์ ถ้าหุ้นขึ้นเป็น \$107 พอร์ตมีค่า $0.598(107)-53.25(1.01)=10.23$ เท่ากับมูลค่า call ที่จุดนั้นพอดี

ขั้นที่ 2 — นิยามมูลค่าด้วยค่าเฉลี่ยของเส้นทางข้างหน้า

จากนี้กลับไปใช้หุ้น \$200 ดอกเบี้ย 4% และความผันผวน 30% ของโจทย์เปิดเรื่อง ในเวลาต่อเนื่อง ใต้ $Q$ หุ้นโตเท่าดอกเบี้ย (ผลของการเปลี่ยน measure) นิยามมูลค่าที่เวลา $t$ เมื่อราคาเป็น $S$ ด้วยสูตรราคาแบบ risk-neutral ที่เริ่มนับจากเวลา $t$ นี่คือทางเดินหน้าของต้นไม้ในเวลาต่อเนื่อง

\[ \begin{aligned} dS_t&=rS_t\,dt+\sigma S_t\,dW_t^Q,\\ g(S)&=S^2/K,\\ S_0&=K=200,\\ r&=0.04,\quad\sigma=0.30,\quad T=1,\\ f(t,S)&:=e^{-r(T-t)}\\ &\quad\times\mathbb E^Q\big[g(S_T)\mid S_t=S\big]. \end{aligned} \]

$S^2$ มีหน่วยดอลลาร์กำลังสอง หารด้วย $K$ ที่มีหน่วยดอลลาร์จึงได้ดอลลาร์ $f(t,S)$ คือ “ถ้าวันที่ $t$ หุ้นอยู่ที่ $S$ สัญญามีค่าเท่าไร” ซึ่งเป็นตัวเลขหนึ่งตัวต่อหนึ่งจุดบนระนาบเวลาและราคา คำถามของหน้านี้คือฟังก์ชันที่นิยามด้วยค่าเฉลี่ยนี้ต้องแก้สมการอะไร

ขั้นที่ 3 — สะพาน: มูลค่าที่คิดลดไม่มี drift แล้วใช้ Itô

ให้ $M_u:=e^{-ru}f(u,S_u)=e^{-rT}\mathbb E^Q_u[g(S_T)]$ มองจากเวลาก่อนหน้า ค่าเฉลี่ยของค่าเฉลี่ยแบบมีเงื่อนไขยุบเหลือค่าเฉลี่ยเดียว $M$ จึงเป็น martingale ใต้ $Q$ นี่คือข้อสังเกตของต้นไม้ (แต่ละจุดเท่ากับค่าเฉลี่ยคิดลดของจุดถัดไป) ในเวลาต่อเนื่อง ใช้กฎผลคูณกับ $e^{-ru}$ คูณ $f$ และ Itô's lemma กับ $f(u,S_u)$

\[ \begin{aligned} &dM_u=-re^{-ru}f\,du+e^{-ru}\,df,\\ &df=\Big(f_t+rSf_S\\ &\qquad+\tfrac12\sigma^2S^2f_{SS}\Big)\,du\\ &\quad+\sigma Sf_S\,dW^Q,\\ &dM_u=e^{-ru}\Big(f_t+rSf_S\\ &\qquad+\tfrac12\sigma^2S^2f_{SS}-rf\Big)\,du\\ &\quad+e^{-ru}\sigma Sf_S\,dW^Q. \end{aligned} \]

$e^{-ru}$ เป็นฟังก์ชันของเวลาอย่างเดียว ไม่มีส่วน $dW$ พจน์ไขว้ของกฎผลคูณจึงเป็นศูนย์ ก้อนที่คูณ $dW^Q$ เป็น Itô integral ที่เฉลี่ยศูนย์ ถ้าก้อนที่คูณ $du$ ไม่เป็นศูนย์ที่เวลาและราคาใด $M$ จะไหลขึ้นหรือลงอย่างคาดได้จากจุดนั้น ซึ่งขัดกับการเป็น martingale วงเล็บจึงต้องเป็นศูนย์ทุกจุดบนระนาบ

ขั้นที่ 4 — PDE ที่เดินย้อน พร้อมเงื่อนไขตอนจบ

เขียนวงเล็บที่ต้องเป็นศูนย์ให้ครบ ที่วันครบกำหนดไม่มีเวลาเหลือ มูลค่าจึงเท่ากับเงินที่จ่าย เงื่อนไขนี้คือชั้นปลายของต้นไม้ แล้วแปลง PDE เป็นสูตรเดินย้อนหนึ่งก้าวบนตาราง โดยแทนอนุพันธ์ด้วยผลต่างของจุดข้างเคียง ($f^{n}_i$ คือค่าที่ราคา $S_i$ และเวลาก้าวที่ $n$)

\[ \begin{aligned} &f_t+rSf_S+\tfrac12\sigma^2S^2f_{SS}-rf=0,\\ &f(T,S)=g(S),\\ &f_S\approx\frac{f_{i+1}-f_{i-1}}{2\Delta S},\\ &f_{SS}\approx\frac{f_{i+1}-2f_i+f_{i-1}}{\Delta S^2},\\ &f^{n}_i=f^{n+1}_i+\Delta t\Big(rS_if_S\\ &\qquad+\tfrac12\sigma^2S_i^2f_{SS}-rf^{n+1}_i\Big). \end{aligned} \]

อ่านทีละพจน์: มูลค่าเปลี่ยนตามเวลา บวกผลของ drift $r$ บวกผลของความโค้งคูณ variance ต้องเท่ากับผลตอบแทนของเงินฝาก $rf$ พอดี นี่คือสมการที่ Black–Scholes PDE จะได้อีกทางจากพอร์ตเลียนแบบ บรรทัดสุดท้ายคือการเดินย้อน: รู้ค่าที่เวลาถัดไปทั้งแถว ก็คำนวณจุดหนึ่งของแถวก่อนหน้าจากสามจุดข้างเคียงได้ เหมือนต้นไม้ที่แต่ละจุดใช้ลูกสองตัว

สะพานนี้ต้องการเงื่อนไขทางเทคนิค: เงินที่จ่ายต้องไม่โตเร็วเกินไป และก้อน $dW^Q$ ต้องเฉลี่ยศูนย์จริงไม่ใช่แค่ในช่วงสั้น ส่วนตารางแบบนี้ต้องใช้ก้าวเวลาเล็กพอ ($\Delta t$ ไม่เกินราว $\Delta S^2/(\sigma^2S^2)$) ไม่เช่นนั้นความคลาดจะขยายจนตัวเลขระเบิด รายละเอียดอยู่ในการตั้งราคาด้วย finite difference

ขั้นที่ 5 — ทางเดินหน้า: ค่าเฉลี่ยของ S² ใต้ Q จาก Itô

ใช้ Itô's lemma กับ $x^2$ หา SDE ของ $S^2$ ใต้ $Q$ (drift ของหุ้นคือ $r$) แล้วเอาค่าเฉลี่ย ก้อน $dW^Q$ เฉลี่ยศูนย์ เหลือสมการของค่าเฉลี่ยที่โตด้วยอัตราคงที่ จากนั้นคิดลดตามนิยามมูลค่าด้านบน

\[ \begin{aligned} &d(S^2)=(2r+\sigma^2)S^2\,dt\\ &\qquad+2\sigma S^2\,dW^Q,\\ &\mathbb E^Q\big[S_T^2\mid S_t=S\big]\\ &\qquad=S^2e^{(2r+\sigma^2)\tau},\\ &f(t,S)=\frac{S^2}{K}\,e^{(r+\sigma^2)\tau},\\ &f(0,200)=200\,e^{0.13}\\ &\qquad\approx200(1.138828)\approx227.77. \end{aligned} \]

drift ของ $S^2$ คือ $2r$ จากพจน์ความชันบวก $\sigma^2$ จากความโค้ง ($\tfrac12\cdot2\cdot\sigma^2$) ค่าเฉลี่ยจึงโตด้วยอัตรา $2r+\sigma^2=0.17$ ตัวคิดลดหัก $r$ ออกหนึ่งตัว เหลือ $r+\sigma^2=0.13$ ความผันผวนโผล่ในราคาเป็นบวกเพราะเงินที่จ่ายโค้งหงาย

ขั้นที่ 6 — ทางเดินย้อน: แทนลง PDE แล้วทุกพจน์หักกัน

ตรวจว่าคำตอบของทางเดินหน้าแก้ PDE ได้จริง หาอนุพันธ์สามตัวโดยเขียนกลับในรูปของ $f$ เอง (เวลาที่เหลือ $\tau=T-t$ ลดลงเมื่อ $t$ เพิ่ม จึงมีเครื่องหมายลบใน $f_t$) แทนทีละพจน์ แล้วตรวจเงื่อนไขตอนจบ

\[ \begin{aligned} &f_t=-(r+\sigma^2)f,\\ &f_S=\frac{2f}{S},\quad f_{SS}=\frac{2f}{S^2},\\ &-(r+\sigma^2)f+rS\,\frac{2f}{S}\\ &\quad+\tfrac12\sigma^2S^2\,\frac{2f}{S^2}-rf\\ &=(-r-\sigma^2+2r+\sigma^2-r)\,f\\ &=0,\\ &f(T,S)=\frac{S^2}{K}e^0=g(S). \end{aligned} \]

$S$ ตัดกับ $1/S$ ในพจน์ delta และ $S^2$ ตัดกับ $1/S^2$ ในพจน์ gamma ก้อนของ $r$ คือ $-r+2r-r$ ก้อนของ $\sigma^2$ คือ $-\sigma^2+\sigma^2$ หักกันหมดทุกเวลาและทุกราคา ขั้นนี้เป็น calculus ธรรมดา ไม่ใช้ความน่าจะเป็นเลย แต่ได้คำตอบเดียวกับค่าเฉลี่ยของทางเดินหน้า

ขั้นที่ 7 — สี่โปรแกรม หนึ่งราคา

ขั้นที่ 8 — คำตอบของโจทย์เปิดเรื่อง และ delta กับ gamma

ทางลัดของนักวิเคราะห์ใส่ราคาเฉลี่ยใต้ $Q$ เข้าไปในเงินที่จ่ายก่อนเฉลี่ย เทียบกับค่าที่ถูก แล้วใช้อนุพันธ์ที่หาได้ตอนแทนลง PDE ($f_S=2f/S$, $f_{SS}=2f/S^2$) ที่ราคา \$200 บอกโต๊ะว่าต้อง hedge ด้วยหุ้นกี่หุ้น

\[ \begin{aligned} &f_{\rm plug}=e^{-0.04}\frac{(200e^{0.04})^2}{200}\\ &\qquad=200\,e^{0.04}\approx208.16,\\ &1-\frac{f_{\rm plug}}f=1-e^{-0.09}\approx8.61\%,\\ &\frac{f}{f_{\rm plug}}-1=e^{0.09}-1\approx9.42\%,\\ &\Delta=\frac{2(227.77)}{200}=2.2777,\\ &\Gamma=\frac{2(227.77)}{200^2}\approx0.01139. \end{aligned} \]

ทางลัดทิ้งการกระจายของราคาปลายทางไปทั้งหมด จึงต่ำไป \$19.60 หรือ 8.61% ของราคาที่ถูก ส่วน $e^{\sigma^2}-1$ คือ 9.42% ของราคาทางลัด ต้องบอกฐานของเปอร์เซ็นต์ให้ชัด note หนึ่งฉบับไวต่อราคาเท่ากับหุ้น 2.28 หุ้น และเมื่อราคาขึ้น \$1 delta เพิ่มราว 0.011 หุ้น รูปด้านล่างแสดงว่าทำไมทางลัดต่ำไปเสมอเมื่อเงินที่จ่ายโค้งหงาย

ขั้นที่ 9 — เมื่อดอกเบี้ยเองก็สุ่ม: พันธบัตรของ Vasicek

ถ้าดอกเบี้ยเปลี่ยนตามเวลา ตัวคิดลดดึงออกนอกค่าเฉลี่ยไม่ได้อีกแล้ว ต้องคิดลดด้วยดอกเบี้ยตลอดทาง $D_t=e^{-\int_0^tr_u\,du}$ ซึ่ง $dD=-rD\,dt$ หลักเดิมยังใช้ได้: มูลค่าหารด้วยบัญชีเงินฝาก $1/D_t$ เป็น martingale ใต้ $Q$ เหมือนในต้นไม้ของดอกเบี้ยที่แต่ละจุดคือค่าเฉลี่ยของจุดถัดไปหารด้วย 1 บวกดอกเบี้ยของจุดนั้นเอง ทำสะพานเดิมซ้ำกับ $Df(t,r_t)$ ได้ PDE ที่ $-rf$ มี $r$ เป็นตัวแปร ใช้ดอกเบี้ยของแบบจำลอง Vasicek ($r_0=1.5\%$, $\theta=3\%$, $\kappa=0.8$, $\sigma_V=1.2\%$ สมมติว่าเป็นพารามิเตอร์ของโลก $Q$) ทางเดินหน้า: $\int_0^Tr_t\,dt$ เป็น Normal เพราะเป็นผลรวมเชิงเส้นของ shock ที่เป็น Normal ให้ $m_t=\mathbb E^Q[r_t]$ และ $h(s)$ เป็นน้ำหนักสะสมของ shock ที่เวลา $s$

\[ \begin{aligned} &f_t+\kappa(\theta-r)f_r\\ &\quad+\tfrac12\sigma_V^2f_{rr}-rf=0,\\ &f(T,r)=1,\\ &h(s)=\frac{1-e^{-\kappa(T-s)}}{\kappa},\\ &\int_0^Tr_t\,dt=\int_0^Tm_t\,dt\\ &\quad+\sigma_V\int_0^Th(s)\,dW_s^Q,\\ &\mathbb E^Q\Big[\int_0^1r_t\,dt\Big]\approx0.019675,\\ &\operatorname{Var}^Q\Big(\int_0^Tr_t\,dt\Big)\\ &=\frac{\sigma_V^2}{\kappa^2}\Big(T-\frac{2(1-e^{-\kappa T})}{\kappa}\\ &\qquad+\frac{1-e^{-2\kappa T}}{2\kappa}\Big),\\ &T=1:\ 0.000225(0.122137)\\ &\qquad\approx0.0000275,\\ &P(0,1)\approx e^{-0.019675+\frac12(0.0000275)}\\ &\qquad\approx0.980531. \end{aligned} \]

สูตร $h(s)$ มาจากคำตอบของ Vasicek: shock ที่เวลา $s$ ส่งผลต่อ $r_t$ ทุกตัวหลังจากนั้นด้วยน้ำหนัก $e^{-\kappa(t-s)}$ ที่จางลงตามเวลา รวมน้ำหนักนั้นตั้งแต่ $t=s$ ถึง $T$ ได้ $(1-e^{-\kappa(T-s)})/\kappa$ variance ได้จาก isometry ของ Itô integral (variance คือ integral ของกำลังสองของน้ำหนัก) บรรทัดสุดท้ายใช้ $\mathbb E[e^{-X}]=e^{-m+v/2}$ ของ Normal

ราคาพันธบัตร 0.980531 คือ yield 1.9661% ต่อปี ถ้าไม่คิด variance ได้ $e^{-0.019675}=0.980517$ ต่างกันแค่ 0.0000135 ความโค้งของ $e^{-x}$ มีผลน้อยเมื่อดอกเบี้ยเฉลี่ยทั้งปีแกว่งแค่ราว 0.52 จุดเปอร์เซ็นต์ ทางเดินย้อน: ตารางที่แก้ PDE จากเงื่อนไข $f(1,r)=1$ ในโค้ดได้ 0.980532

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

ใส่ราคาเฉลี่ยเข้าสูตรเงินที่จ่ายที่โค้ง: ได้ \$208.16 แทน \$227.77 ต่ำกว่าราคาที่ถูก 8.61% สำหรับเงินที่จ่ายที่โค้งหงาย ทางลัดนี้ให้ค่าไม่เกินค่าที่ถูก ส่วนเงินที่จ่ายที่โค้งคว่ำจะได้ค่าไม่ต่ำกว่าค่าที่ถูก เท่ากันได้เฉพาะเมื่อเงินที่จ่ายเป็นเส้นตรงตลอดช่วงราคาที่เกิดขึ้น

ใส่ drift ของโลกจริงแทนดอกเบี้ย: ถ้าใช้ drift 10% ใน PDE หรือในการสุ่ม ค่าเฉลี่ยของ $S^2$ โตด้วย $2(0.10)+0.09$ คิดลดที่ 4% ได้ $200e^{0.25}=\$256.81$ สูงเกิน \$29.04 สัญญาณที่จับได้คือราคาในระบบเปลี่ยนเมื่อความเห็นเรื่องทิศทางตลาดเปลี่ยน

ลืมพจน์ $-rf$ (ลืมคิดลด): ได้ค่าเฉลี่ยของเงินที่จ่าย $200e^{0.17}=\$237.06$ แทนราคา \$227.77 สูงเกิน \$9.30 บนตาราง PDE ความผิดนี้ซ่อนง่ายเพราะสมการยังดูครบทุกพจน์อื่น

วางขอบตารางหรือขอบ integral ใกล้เกินไป: ตัดการอินทิเกรตที่ \$800 ขาดไป \$0.006 สำหรับ note นี้ ตารางที่ขอบบนแค่สองเท่าของราคาวันนี้ก็คลาดในทำนองเดียวกัน เพราะเงินที่จ่ายที่โตตามราคายังมีมูลค่าในหางขวา ต้องลองเลื่อนขอบออกแล้วดูว่าคำตอบนิ่ง

ใช้ทำอะไรบนโต๊ะจริง

ระบบตั้งราคาจริงเลือกทางตามโจทย์ option ตัวเดียวบนหุ้นตัวเดียวแก้ PDE บนตาราง (finite-difference pricing) ได้ทั้งราคา delta และ gamma ในคราวเดียว สัญญาที่อ้างอิงหลายสินทรัพย์ใช้การสุ่ม เพราะตารางโตแบบทวีคูณตามจำนวนตัวแปร เกินราวสามตัวแปรก็ใหญ่เกินไป ความคลาดของการสุ่มหดตาม $1/\sqrt n$ แม่นขึ้นสองเท่าต้องสุ่มเพิ่มสี่เท่า ส่วนการอินทิเกรตกับ density ใช้ได้ดีเมื่อรู้ density หรือ characteristic function ของ log ราคา ซึ่งคือฐานของการตั้งราคาด้วย Fourier และ FFT

สัญญาที่ใช้สิทธิ์ก่อนครบกำหนดได้ (American option) เข้ากับทางเดินย้อนเป็นธรรมชาติ: ที่แต่ละจุดของต้นไม้หรือตาราง เทียบมูลค่าถ้าใช้สิทธิ์ทันทีกับมูลค่าถ้าถือต่อ แล้วเก็บตัวที่มากกว่า ทางเดินหน้าทำแบบนี้ยากเพราะเส้นทางที่สุ่มไม่รู้ว่ามูลค่าถ้าถือต่อเป็นเท่าไร ทีมที่ดีคิดสัญญาใหม่ทั้งสองทางอย่างน้อยหนึ่งครั้งก่อนปล่อยโค้ดขึ้นระบบ และจำไว้ว่าสองทางตรงกันแปลว่าโค้ดทำตามแบบจำลองถูก ไม่ได้แปลว่าแบบจำลองตรงกับตลาด

ด้านดอกเบี้ย สูตรราคาพันธบัตรของ Vasicek คือฐานของการ calibrate Vasicek และ CIR ให้เข้ากับเส้นอัตราผลตอบแทน

function checkPositive(values, message) {
  if (!values.every(v => Number.isFinite(v) && v > 0)) throw new RangeError(message);
}
// n-period tree with gross rate R per period: backward induction layer by layer, and the forward sum over paths.
function tree(S0, u, R, n, payoff) {
  checkPositive([S0, u, R], 'Need S0, u and R > 0');
  const d = 1 / u, q = (R - d) / (u - d);
  if (!(q > 0 && q < 1)) throw new RangeError('No-arbitrage needs d < R < u');
  let V = Array.from({length: n + 1}, (_, j) => payoff(S0 * u ** j * d ** (n - j)));
  const leaves = V.slice(), layers = [V];
  for (let i = n - 1; i >= 0; i--) {
    V = Array.from({length: i + 1}, (_, j) => (q * V[j + 1] + (1 - q) * V[j]) / R);
    layers.unshift(V);
  }
  let forward = 0, binom = 1;
  for (let j = 0; j <= n; j++) {
    forward += binom * q ** j * (1 - q) ** (n - j) * leaves[j];
    binom = binom * (n - j) / (j + 1);
  }
  const shares = (layers[1][1] - layers[1][0]) / (S0 * u - S0 * d);
  return {q, layers, backward: layers[0][0], forward: forward / R ** n, shares, cash: layers[0][0] - shares * S0};
}
// Power note paying S_T^2 / K under Q: f(t, S) = (S^2 / K) e^((r + sigma^2)(T - t)).
function powerNote(S, K, r, sigma, tau) {
  checkPositive([S, K, sigma, tau], 'Need S, K, sigma and time to expiry > 0');
  const f = S * S / K * Math.exp((r + sigma * sigma) * tau);
  return {f, delta: 2 * f / S, gamma: 2 * f / (S * S)};
}
// Backward side on a grid: explicit finite differences for f_t + r S f_S + sigma^2 S^2 f_SS / 2 - r f = 0.
function gridPowerNote(S0, K, r, sigma, T, nS, nT) {
  checkPositive([S0, K, sigma, T], 'Need S0, K, sigma and T > 0');
  const dS = 4 * S0 / nS, dt = T / nT;
  if (dt * (sigma * sigma * nS * nS + r) > 1) throw new RangeError('Time step too large for the explicit scheme');
  let f = Array.from({length: nS + 1}, (_, i) => (i * dS) ** 2 / K);   // payoff at expiry
  for (let n = 0; n < nT; n++) {
    const g = f.slice();
    for (let i = 1; i < nS; i++) {
      const S = i * dS, fS = (f[i + 1] - f[i - 1]) / (2 * dS), fSS = (f[i + 1] - 2 * f[i] + f[i - 1]) / (dS * dS);
      g[i] = f[i] + dt * (r * S * fS + 0.5 * sigma * sigma * S * S * fSS - r * f[i]);
    }
    g[0] = f[0] * (1 - r * dt);                        // at S = 0 only discounting remains
    g[nS] = 3 * g[nS - 1] - 3 * g[nS - 2] + g[nS - 3];  // far edge: zero third difference
    f = g;
  }
  return f[Math.round(S0 / dS)];
}
// Third route: integrate the payoff against the lognormal density of S_T under Q (trapezoid rule).
function densityIntegral(S0, K, r, sigma, T, eta, upper) {
  checkPositive([S0, K, sigma, T, eta, upper], 'Need positive inputs');
  const m = Math.log(S0) + (r - 0.5 * sigma * sigma) * T, s = sigma * Math.sqrt(T), N = Math.round(upper / eta);
  const dens = x => x <= 0 ? 0 : Math.exp(-0.5 * ((Math.log(x) - m) / s) ** 2) / (x * s * Math.sqrt(2 * Math.PI));
  let sum = 0;
  for (let j = 0; j <= N; j++) sum += (j === 0 || j === N ? 0.5 : 1) * eta * (j * eta) ** 2 / K * dens(j * eta);
  return Math.exp(-r * T) * sum;
}
// mulberry32 + Box-Muller: seeded standard Normals, the same generator on every page of this chapter.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Forward side: exact draws of S_T under Q, discounted average of the payoff and its standard error.
function monteCarlo(S0, K, r, sigma, T, draws, seed) {
  checkPositive([S0, K, sigma, T], 'Need S0, K, sigma and T > 0');
  const z = normals(seed), disc = Math.exp(-r * T);
  let s = 0, s2 = 0;
  for (let i = 0; i < draws; i++) {
    const ST = S0 * Math.exp((r - 0.5 * sigma * sigma) * T + sigma * Math.sqrt(T) * z()), x = disc * ST * ST / K;
    s += x; s2 += x * x;
  }
  const mean = s / draws;
  return {mean, se: Math.sqrt((s2 / draws - mean * mean) / (draws - 1))};
}
// Vasicek bond: the integral of r over [0, T] is Normal, so E[exp(-integral)] = exp(-mean + variance / 2).
function vasicekBond(r0, theta, kappa, sigma, T) {
  checkPositive([kappa, sigma, T], 'Need kappa, sigma and T > 0');
  const e1 = Math.exp(-kappa * T), e2 = Math.exp(-2 * kappa * T);
  const mean = theta * T + (r0 - theta) * (1 - e1) / kappa;
  const variance = sigma * sigma / (kappa * kappa) * (T - 2 * (1 - e1) / kappa + (1 - e2) / (2 * kappa));
  const price = Math.exp(-mean + 0.5 * variance);
  return {mean, variance, price, yield: -Math.log(price) / T, noConvexity: Math.exp(-mean)};
}
// Backward side for the bond: explicit grid for f_t + kappa (theta - r) f_r + sigma^2 f_rr / 2 - r f = 0, f(T, r) = 1.
function gridBond(r0, theta, kappa, sigma, T, lo, hi, n, nT) {
  const dr = (hi - lo) / n, dt = T / nT;
  if (dt * (sigma * sigma / (dr * dr) + Math.max(Math.abs(lo), Math.abs(hi))) > 1) throw new RangeError('Time step too large for the explicit scheme');
  let f = new Array(n + 1).fill(1);
  for (let m = 0; m < nT; m++) {
    const g = f.slice();
    for (let i = 1; i < n; i++) {
      const x = lo + i * dr, fr = (f[i + 1] - f[i - 1]) / (2 * dr), frr = (f[i + 1] - 2 * f[i] + f[i - 1]) / (dr * dr);
      g[i] = f[i] + dt * (kappa * (theta - x) * fr + 0.5 * sigma * sigma * frr - x * f[i]);
    }
    g[0] = 2 * g[1] - g[2]; g[n] = 2 * g[n - 1] - g[n - 2];   // straight-line extension at the far edges
    f = g;
  }
  const j = (r0 - lo) / dr, i0 = Math.floor(j), w = j - i0;
  return f[i0] * (1 - w) + f[i0 + 1] * w;
}
