13.7 Stochastic Volatility and the Heston Model

ให้ความแกว่งเปลี่ยนตามเวลาเพื่ออธิบายราคาที่โค้งเอียง

ถ้าความแกว่งของราคาวิ่งขึ้นลงเอง volatility คงที่เส้นเดียวจะอธิบายราคาสิทธิ์ทุก strike ได้หรือไม่?

เฉลย: volatility คงที่เส้นเดียวอธิบายราคาสิทธิ์ทุก strike ไม่ได้ เพราะ downside options ที่แพงกว่าบอกว่าความเสี่ยงกับราคากำลังเคลื่อนร่วมกัน

Heston stochastic volatility model ให้ volatility ขยับเอง จึงทำให้ smile มีที่มาใน model

stochastic volatility
stochastic volatility คือแบบจำลองที่ให้ variance เป็น random variable ของตัวเองแทนค่าคงที่ ใช้สร้างการเปลี่ยนแปลงของ smile, skew และ volatility clustering ตามเส้นทาง
Heston model / square-root variance process
Heston model คือ stochastic-volatility model แบบ affine ที่ให้ราคาถูกขับด้วยราก variance และ variance เดินด้วย square-root process ใช้ตั้งราคา European options ผ่าน characteristic function
mean reversion / long-run variance
mean reversion คือแรงดึง variance กลับระดับระยะยาว และ long-run variance คือระดับ ที่แรงดึงมุ่งหา ใช้แยก shock ระยะสั้นจาก anchor ระยะยาว
volatility of volatility
volatility of volatility หรือ vol-of-vol คือ parameter ที่กำหนดขนาดความสุ่มของ variance ใช้ควบคุมความโค้งและความไม่แน่นอนของ smile
leverage effect / instantaneous correlation
leverage effect คือรูปแบบที่ราคาลงสัมพันธ์กับ volatility เพิ่ม และ instantaneous correlation วัดความสัมพันธ์ของแรง Brownian สองตัวในช่วงสั้น ใช้สร้าง downside skew เมื่อ
Feller condition
Feller condition คือ ซึ่งเพียงพอให้ variance process ไม่แตะศูนย์ ใช้เป็น diagnostic ด้าน boundary behavior แต่การไม่ผ่านไม่ได้ทำให้ model หรือ calibration ใช้ไม่ได้โดยอัตโนมัติ
affine model / characteristic function / Fourier inversion
affine model มี log characteristic function เป็นเส้นตรงใน state variables, characteristic function คือ expectation ของ complex exponential และ Fourier inversion คือการกู้ probability-weighted payoff จาก function นั้น ใช้ตั้งราคาเร็วหลาย strike
calibration / identifiability
calibration คือการเลือก parameter ให้ model prices ใกล้ market prices และ identifiability คือความสามารถแยกได้ว่า parameter ใดสร้างรูปที่เห็น ใช้เตือนว่าหลายชุด parameter อาจ fit ใกล้กันแต่ให้ hedge ต่างกัน
full-truncation Euler / discretization bias
full-truncation Euler คือ numerical scheme ที่ใช้ส่วนบวกของ variance ใน drift กับ diffusion เพื่อลดปัญหาค่าติดลบ และ discretization bias คือความคลาดเคลื่อนจาก time step จำกัด ใช้จำลอง path อย่างโปร่งใสแต่ไม่ใช่ exact simulation
branch cut / numerical integration
branch cut คือการเลือกกิ่งของ complex square root หรือ logarithm และ numerical integration คือการประมาณ integral ด้วยคอมพิวเตอร์ ใช้ระบุ failure modes ของสูตร Heston ที่อาจให้ discontinuity หรือ cancellation
partial differential equation / ordinary differential equation
partial differential equation มี derivatives ตามหลาย state variables ส่วน ordinary differential equation มีตัวแปรอิสระเดียว ใช้เชื่อม pricing equation กับ Riccati equations ของ characteristic function
Monte Carlo
Monte Carlo คือการประมาณ expectation ด้วยเส้นทางจำลองจำนวนมาก ใช้เป็น independent numerical check และประเมิน path-dependent claims พร้อมช่วงความคลาดเคลื่อนทางสถิติ
stochastic alpha beta rho (SABR) / Dupire local volatility / Merton jump-diffusion / compound Poisson process
stochastic alpha beta rho (SABR) เป็นแบบจำลอง forward กับ stochastic volatility, Dupire local volatility ให้ volatility เป็น deterministic function ของ spot กับเวลา และ Merton jump-diffusion เพิ่ม compound Poisson process ซึ่งนับจำนวน jumps แบบสุ่ม ใช้เป็น model alternatives ที่ fit หรือสร้าง dynamics ต่างจาก Heston
alpha / beta / rho in SABR
alpha กำหนดระดับ volatility เริ่มต้น beta กำหนด elasticity ของ forward และ rho กำหนด correlation ระหว่าง forward กับ volatility ใน SABR ใช้อ่านว่า parameter แต่ละตัวเปลี่ยนระดับ รูป และ skew อย่างไร

Calibrate แล้วต้องตรวจอะไรต่อ

เลือกก่อนว่าจะเทียบความคลาดเคลื่อนใน price space หรือ implied-vol space แบบถ่วง vega ใช้ bid–ask เป็นกรอบ และประกาศขอบเขต เช่น กับ ลองจุดเริ่มหลายชุด แล้วเก็บ objective, ความนิ่งของ parameter, residual heatmap และราคานอกชุด fit

คำนวณราคาเร็วไม่ได้แปลว่า hedge ถูก ลองขยับ input หลายขนาดแล้วเทียบ Greeks แบบ finite difference ตรวจ branch ของ characteristic function, จุดตัด integration และ put–call parity พร้อมเทียบ Monte Carlo หรือ numerical pricing equation บางจุด

สุดท้าย stress parameter หลายชุดที่ให้ราคาใกล้กัน เพราะหน้าร้านติดป้ายราคาเหมือนกันได้ แต่ของข้างในอาจตอบสนองต่อ shock คนละแบบ

Model ข้างเคียงตอบคนละคำถาม

SABR มักใช้กับ forward smile และให้ parameter หนึ่งตัวคุมว่า volatility เปลี่ยนตามระดับ forward แค่ไหน ส่วน Dupire local volatility ยอมให้ volatility เป็นค่าที่ขึ้นกับ spot กับเวลา จึง fit ภาพ surface วันนี้ได้เมื่อข้อมูลเรียบ แต่การเคลื่อนของ smile วันหน้าอาจต่างจาก stochastic volatility

Merton jump-diffusion เพิ่มการกระโดดของราคา จึงช่วยอธิบายปีกอายุสั้น แต่ทำให้ต้องรับ jump-risk premium และ hedge ที่ปิดความเสี่ยงไม่หมด ไม่มี model ใดชนะทุกโจทย์ ต้องเลือกจาก payoff ที่ต้องตั้งราคา เครื่องมือ hedge ที่ซื้อขายได้ และผลทดสอบ

Heston สร้าง integrated variance จาก dynamics ที่สมมติไว้ ส่วนหัวข้อ 13.8 จะหา fair variance จาก option strip กับ log contract โดยพึ่ง static no-arbitrage มากกว่า parameter fit นี่คือความต่างระหว่างเครื่องสร้างสถานการณ์จาก model กับการประกอบ payoff จากราคาตลาด

คำตอบ ตรวจเอง และแปลว่าอะไร

คำตอบparameter set ให้ expected variance ปลายปี 0.04676676, expected average variance 0.06161662 และ call strike 100 ราคา 10.43477605 USD ราคานี้สะท้อนทั้ง stochastic variance กับ negative correlation หาก desk ต้อง hedge exotic ที่ไวต่อ path หรือ forward skew ควรเทียบ Heston กับ local-vol, jump และ richer multi-factor models ไม่ควรเลือกเพียงเพราะ fit vanilla snapshot ดี

ตรวจเองใน 10 วินาทีลบ expected terminal variance 0.04676676 ออกจาก expected average variance 0.06161662 ต้องได้ 0.01484986. ใช้ช่องว่างนี้กันการเอาค่าปลายปีไปแทน integrated variance ตอนตั้งราคา option.

ระวังตรงนี้

กับดัก: fit ดีแล้วเรียก parameter ว่าเป็นความจริง

optimizer สามารถส่ง parameter ห้าตัวที่แต่งตัวเข้าชุดกับ smile วันนี้ แต่พรุ่งนี้แต่ละตัวอาจเปลี่ยนบทเหมือนนักแสดงละครเย็น วิธีป้องกันคือรายงาน identifiability, confidence จาก bid–ask, stability ข้ามวัน และ hedge backtest พร้อม model alternatives ไม่ใช่เพียง root-mean-square error ต่ำ

สรุปที่ใช้ได้จริง

  • Heston เพิ่ม stochastic variance, mean reversion, vol-of-vol และ price–variance correlation เพื่อสร้าง skew กับ dynamics
  • expected terminal variance ต่างจาก expected average variance ซึ่งเกี่ยวกับ exposure ตลอดอายุ
  • Feller condition เป็น sufficient boundary diagnostic ไม่ใช่ตราประทับว่าชุดที่ไม่ผ่านผิดเสมอ
  • affine characteristic function ให้ราคา vanilla เร็ว แต่ branch, integration และ numerical checks เป็นส่วนของ model
  • calibration fit ไม่รับประกัน identifiability หรือ hedge quality; ต้องตรวจ stability และ model risk
