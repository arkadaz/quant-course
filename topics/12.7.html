12.7 Algorithms in Practice — Gradient Descent and Newton's Method

gradient descent เดินลงเขาทีละก้าว โดยเราต้องเลือกความยาวก้าวเอง ความโค้งของพื้นเป็นตัวตัดสินว่าก้าวแบบไหนเร็ว แบบไหนซิกแซก แบบไหนระเบิด ส่วน Newton ใช้ความโค้งเลือกความยาวก้าวให้เอง

หน้าจอซื้อขาย option แสดงราคา call ตัวหนึ่งที่ \$10.45 ต่อหุ้น call คือสิทธิ์ (ไม่ใช่ภาระ) ที่จะซื้อหุ้นในราคาที่ตกลงไว้ล่วงหน้า เมื่อถึงวันครบอายุ ราคาที่ตกลงไว้นี้เรียกว่า strike

เทรดเดอร์ไม่ได้สนใจราคาเป็นดอลลาร์มากนัก เขาอยากรู้ว่าราคานี้บอกว่าตลาดคาดให้หุ้นแกว่งแรงแค่ไหน ตัวเลขนั้นเรียกว่า implied volatility คือความผันผวนที่ใส่ลงในสูตร Black–Scholes แล้วได้ราคา \$10.45 พอดี สูตร Black–Scholes คือสูตรมาตรฐานที่คำนวณราคา call จากราคาหุ้น strike อายุ ดอกเบี้ย และความผันผวนของหุ้น

ของที่รู้ (ตัวเลขสมมติ):

  • ราคาหุ้นวันนี้ $S=\$100$
  • strike $K=\$100$
  • อายุของ call $T=1$ ปี
  • ดอกเบี้ย $r=2\%$ ต่อปี
  • ราคา call ในตลาด $C_{\text{mkt}}=\$10.45$ ต่อหุ้น

สูตร Black–Scholes รับความผันผวน $\sigma$ แล้วคืนราคา $C(\sigma)$ แต่กลับด้านด้วยพีชคณิตไม่ได้ คอมพิวเตอร์จึงต้องเดา $\sigma$ แล้วแก้ทีละก้าว มันวัดว่าเดาผิดแค่ไหนด้วย loss $f(\sigma)=\tfrac12\big(C(\sigma)-C_{\text{mkt}}\big)^2$ คือส่วนต่างระหว่างราคาจากสูตรกับราคาตลาด ยกกำลังสอง แล้วหารด้วยสอง ยิ่งเดาใกล้คำตอบ $f$ ยิ่งใกล้ศูนย์

ระบบนี้เริ่มเดาที่ $\sigma_0=30\%$ แล้วใช้ gradient descent ทุกก้าวขยับ $\sigma$ สวนทางกับความชัน $f'$ ของ loss โดยมีตัวคูณ $\eta$ ที่เรียกว่าขนาดก้าว ซึ่งคนตั้งระบบต้องเลือกเอง

\[\sigma_{k+1}=\sigma_k-\eta\,f'(\sigma_k)\]

ที่ $\eta=0.0005$ ระบบเข้าใกล้คำตอบจนคลาดไม่เกิน $10^{-6}$ ใน 8 ก้าว (หน้านี้จะคำนวณให้ดูในขั้นที่ 6) เทรดเดอร์ใจร้อนเปลี่ยนเป็น $\eta=0.002$ ซึ่งใหญ่กว่าเดิม $0.002/0.0005=4$ เท่า หวังให้เร็วขึ้นสี่เท่า จะเกิดอะไรขึ้น

ลองตอบก่อนเปิดเฉลย

ระเบิด หน้านี้จะคำนวณตัวเลขเหล่านี้ให้ดูทีละขั้น (ขั้นที่ 6 ถึงขั้นที่ 8)

  • ความผันผวนเดิน 30% → 11.5% → 49.2% → −25.7% แต่ละก้าวกระโดดข้ามคำตอบ (ราว 23.9%) และไปไกลกว่าเดิม
  • ก้าวที่สามได้ความผันผวนติดลบ ซึ่งไม่มีความหมาย สูตรราคาจึงคำนวณต่อไม่ได้

เหตุผลคือ ใกล้คำตอบ ระยะห่างจากคำตอบ (error) ถูกคูณด้วย $1-\eta f''$ ทุกก้าว โดย $f''$ คือความโค้งของ loss ซึ่งโจทย์นี้มีค่าราว 1,527 (ขั้นที่ 6)

\[\begin{aligned}\eta=0.0005:&\quad1-0.0005(1527)=0.24,\\ \eta=0.002:&\quad1-0.002(1527)=-2.05.\end{aligned}\]

ตัวคูณ 0.24 ทำให้ error เหลือราวหนึ่งในสี่ทุกก้าว แต่ตัวคูณ −2.05 ทำให้ error สลับข้างและโตสองเท่าทุกก้าว ขนาดก้าวต้องทำให้ตัวคูณอยู่ระหว่าง −1 กับ 1 คือ $\eta\lt2/f''=2/1527\approx0.00131$ ส่วนวิธีของ Newton ไม่ต้องเลือกขนาดก้าวเลย สองก้าวได้ 23.92363% คลาดแค่ $1.4\times10^{-10}$ (ขั้นที่ 7)

ภาพรวมก่อนลงสูตร

หน้าก่อน ๆ ของบทนี้หาจุดต่ำสุดด้วยสูตรปิด คือตั้งความชันให้เป็นศูนย์ แล้วแก้สมการออกมาเป็นตัวเลข แต่งานจริงส่วนใหญ่แก้สมการแบบนั้นไม่ได้ ตัวอย่างแรกคือการหา implied volatility ในโจทย์เปิดเรื่อง ตัวอย่างที่สองคือการ calibrate แบบจำลอง คือปรับตัวเลขในแบบจำลองจนราคาที่แบบจำลองคำนวณได้ตรงกับราคาตลาด งานแบบนี้คอมพิวเตอร์ต้องเดาคำตอบก่อน แล้วเดินเข้าหาคำตอบทีละก้าว

วิธีหลักมีสองวิธี

  • gradient descent ใช้แค่ความชัน (gradient) มันก้าวไปทางที่ลงชันที่สุด ความยาวก้าวคือขนาดก้าว $\eta$ คูณความชัน และเราต้องเลือก $\eta$ เอง
  • Newton ใช้ความโค้งด้วย (Hessian) มันวาดพาราโบลาที่แนบพื้นรอบจุดปัจจุบัน แล้วกระโดดไปก้นพาราโบลานั้น ความโค้งจึงเลือกความยาวก้าวให้เอง

รูปด้านล่างสรุปความต่างของสองวิธี พื้นในรูปคือความเสี่ยงของพอร์ตที่มีสามสินทรัพย์ มันเป็นชามรูปวงรี ทิศที่ลงชันที่สุดไม่ได้ชี้ไปก้นชาม แต่ชี้ข้ามหุบแคบ gradient descent จึงเดินซิกแซกไปมา แม้เลือกขนาดก้าวที่ดีที่สุดแล้ว ระยะถึงก้นก็หดได้แค่เหลือ 72% ต่อก้าว จึงต้องใช้ราว 41 ก้าวกว่าระยะจะหดเหลือหนึ่งในล้าน (ขั้นที่ 2 จะคำนวณตัวเลขนี้) Newton ใช้ความโค้งดัดชามให้กลม จึงถึงก้นในก้าวเดียว

ลำดับของหน้านี้

  • ชามหนึ่งมิติ: หาว่าขนาดก้าวเท่าไรจึงปลอดภัย
  • ชามสองมิติ: ดูว่าทำไม gradient descent ซิกแซก
  • สร้าง Newton แล้วดูว่ามันพลาดตรงไหนบนพื้นที่ไม่ใช่ชาม
  • ใช้ทั้งสองวิธีหา implied volatility แล้วตั้งใจทำให้มันพัง
  • รั้วกันพังที่ระบบจริงต้องมี
ศัพท์ที่ใช้ในหัวข้อนี้
Gradient descent
วิธีหาจุดต่ำสุดโดยเดินลงเขาทีละก้าว แต่ละก้าวไปทางตรงข้ามกับความชัน และยาวเท่ากับขนาดก้าว $\eta$ คูณความชัน: $x_{k+1}=x_k-\eta\,\nabla f(x_k)$ ใช้ได้แม้มีตัวแปรเป็นล้าน เพราะต้องรู้แค่ความชัน
Step size (learning rate)
ตัวคูณ $\eta$ ในสูตรข้างบน ซึ่งเราต้องเลือกเอง ถ้าเล็กไปก็เดินช้า ถ้าใหญ่ไปก็กระโดดข้ามคำตอบไปมาหรือระเบิด ค่าที่พอดีขึ้นกับความโค้งและหน่วยของโจทย์ หน้านี้ใช้ตั้งแต่ 0.0005 ถึง 30
Condition number
ความโค้งในทิศที่โค้งมากที่สุด หารด้วยความโค้งในทิศที่โค้งน้อยที่สุด: $\kappa=\lambda_{\max}/\lambda_{\min}$ ชามกลมมี $\kappa=1$ ชามที่เป็นหุบแคบยาวมี $\kappa$ ใหญ่ ยิ่ง $\kappa$ ใหญ่ gradient descent ยิ่งซิกแซกและยิ่งช้า
Newton's method
วาดพาราโบลาที่แนบ function ที่จุดปัจจุบัน (Taylor อันดับสอง) แล้วกระโดดไปจุดที่ความชันของพาราโบลาเป็นศูนย์ ความโค้งเลือกความยาวก้าวให้เอง จึงไม่ต้องเลือก $\eta$ และเร็วมากเมื่อเริ่มใกล้คำตอบ
Linear / quadratic convergence
สองแบบของความเร็วในการเข้าหาคำตอบ linear คือ error ถูกคูณด้วยตัวเลขคงที่ทุกก้าว เช่นเหลือ 24% ทุกก้าว quadratic คือ error ใหม่ประมาณค่าคงที่คูณ error เดิมยกกำลังสอง จำนวนหลักทศนิยมที่ถูกจึงเพิ่มราวเท่าตัวทุกก้าว
Line search (backtracking)
ลองก้าวยาวก่อน ถ้า loss ลดลงไม่พอ ก็หั่นความยาวก้าวครึ่งหนึ่งแล้วลองใหม่ ใช้กันไม่ให้ก้าวที่ใหญ่เกินพาไประเบิด
Loss
ตัวเลขที่วัดว่าคำตอบที่ลองยังผิดแค่ไหน เราต้องการทำให้มันต่ำที่สุด หน้านี้ใช้ส่วนต่างราคายกกำลังสองหารด้วยสอง $f(\sigma)=\tfrac12\big(C(\sigma)-C_{\text{mkt}}\big)^2$
Call option และ strike
call คือสิทธิ์ (ไม่ใช่ภาระ) ที่จะซื้อหุ้นในราคาที่ตกลงไว้ เมื่อถึงวันครบอายุ ราคาที่ตกลงไว้คือ strike ราคาของ call คำนวณได้จากสูตร Black–Scholes
Implied volatility และ vega
implied volatility คือความผันผวนที่ใส่ในสูตรราคา option แล้วได้ราคาเท่าตลาด vega คือราคา option ขยับเท่าไรเมื่อความผันผวนขยับหนึ่งหน่วย $\mathcal V=dC/d\sigma$ มันคือความชันของโจทย์หาราก และเป็นตัวหารในก้าวของ Newton
จุดอานม้า (saddle point)
จุดที่ความชันเป็นศูนย์ แต่ไม่ใช่ก้นหลุม เดินทิศหนึ่งค่าขึ้น อีกทิศค่าลง เหมือนอานม้าที่ต่ำสุดในแนวหัวถึงหาง แต่สูงสุดในแนวซ้ายขวา
Bisection
หารากโดยผ่าครึ่งช่วงที่รู้ว่ามีคำตอบอยู่ข้างใน แล้วเก็บครึ่งที่ยังคร่อมคำตอบไว้ ทำซ้ำไปเรื่อย ๆ ช้าแต่ไม่มีทางหลุด

ก่อนลงมือกับ implied volatility ขอฝึกกับโจทย์ที่รู้คำตอบแน่นอนก่อน จะได้วัด error ได้ทุกก้าว โจทย์คือพอร์ตที่ลงเงินครบ 100% ในหุ้นกับพันธบัตร ถ้าลงหุ้นเป็นสัดส่วน $a$ ก็ลงพันธบัตร $1-a$ เราต้องการ $a$ ที่ทำให้ variance ของพอร์ตต่ำที่สุด variance คือความผันผวนยกกำลังสอง ใช้แทนความผันผวนเพราะคิด derivative ง่ายกว่า

ของที่รู้ (ตัวเลขสมมติ):

  • ความผันผวนต่อปีของหุ้น $\sigma_s=20\%$
  • ความผันผวนต่อปีของพันธบัตร $\sigma_b=10\%$
  • correlation ของหุ้นกับพันธบัตร $\rho=0.30$ คือสองตัวนี้ขึ้นลงตามกันบ้างเล็กน้อย

สูตร variance ของพอร์ตสองสินทรัพย์ (gradient และเงื่อนไขอันดับหนึ่ง) ทำให้ variance เป็นกำลังสองของ $a$ จุดต่ำสุดอยู่ตรงที่ความชันเป็นศูนย์

\[ \begin{aligned} q(a)&=0.2^2a^2+0.1^2(1-a)^2\\ &\quad+2(0.3)(0.2)(0.1)\,a(1-a)\\ &=0.038a^2-0.008a+0.01,\\ q'(a)&=0.076a-0.008=0,\\ a^\star&=\frac{0.008}{0.076}=\frac{2}{19}\approx0.105. \end{aligned} \]

variance ของพอร์ตไม่ใช่แค่ผลรวมของสองสินทรัพย์ เพราะต้องบวกพจน์ที่สองตัวขึ้นลงพร้อมกันด้วย คือพจน์ที่มี $\rho$ พอกระจายวงเล็บ $0.04a^2+0.01(1-2a+a^2)+0.012(a-a^2)$ แล้วรวมพจน์ จะได้กำลังสองที่สั้นลง คำตอบคือหุ้นราว 10.5% พันธบัตรราว 89.5% ตอนนี้เรารู้คำตอบแล้ว จึงวัดได้ว่า gradient descent เข้าหามันเร็วแค่ไหน

ทีนี้ให้ gradient descent หาคำตอบเอง โดยแกล้งทำเป็นไม่รู้ $a^\star$ กฎของมันคือ $a_{k+1}=a_k-\eta\,q'(a_k)$ เราอยากรู้ว่า error $a_k-a^\star$ เปลี่ยนอย่างไรในแต่ละก้าว เคล็ดลับคือเขียนความชันใหม่ ให้อยู่ในรูประยะห่างจากคำตอบ

\[ \begin{aligned} q'(a)&=0.076\,(a-a^\star)=h\,(a-a^\star),\\ a_{k+1}&=a_k-\eta\,h\,(a_k-a^\star),\\ a_{k+1}-a^\star&=(a_k-a^\star)-\eta h\,(a_k-a^\star)\\ &=(1-\eta h)\,(a_k-a^\star). \end{aligned} \]

ความชันของกำลังสองเป็นเส้นตรงที่เป็นศูนย์ตรงคำตอบพอดี จึงเขียนเป็นความโค้ง $h=0.076$ คูณระยะห่างจากคำตอบได้ (ตรวจได้: $0.076\times2/19=0.008$) พอลบ $a^\star$ ออกจากสองข้างของกฎ gradient descent จะได้ว่า error ใหม่คือ error เดิมคูณ $(1-\eta h)$ ตัวคูณนี้เท่าเดิมทุกก้าว ไม่ว่าตอนนี้อยู่ตรงไหนของชาม

ถ้าตัวคูณอยู่ระหว่าง 0 กับ 1 error หดลงและอยู่ข้างเดิม ถ้าอยู่ระหว่าง −1 กับ 0 error หดลงแต่สลับข้างทุกก้าว คือกระโดดข้ามคำตอบไปมา ถ้าขนาดของตัวคูณเกิน 1 error โตขึ้นทุกก้าว นี่คือการระเบิด

ขนาดก้าวที่ปลอดภัยจึงต้องทำให้ตัวคูณอยู่ระหว่าง −1 กับ 1 แก้หาช่วงของ $\eta$ แล้วลองสามค่า

\[ \begin{aligned} -1\lt1-\eta h&\lt1,\\ 0\lt\eta h&\lt2,\\ 0\lt\eta&\lt\frac2h=\frac{2}{0.076}\approx26.3,\\ \eta=10:&\quad1-10(0.076)=0.24,\\ \eta=20:&\quad1-20(0.076)=-0.52,\\ \eta=30:&\quad1-30(0.076)=-1.28. \end{aligned} \]

ขั้นที่ 2 — สองมิติ: ชามรีทำให้เดินซิกแซก

ชามหนึ่งมิติมีทิศเดียว เราจึงเลือกขนาดก้าวให้พอดีกับความโค้งได้เสมอ ปัญหาจริงเริ่มเมื่อมีสองทิศที่โค้งไม่เท่ากัน ลองเพิ่มสินทรัพย์ตัวที่สามคือหุ้นเทค ให้พอร์ตมีหุ้นสหรัฐฯ $a$ หุ้นเทค $t$ และพันธบัตรได้ส่วนที่เหลือ $1-a-t$ จุดบนระนาบในรูปภาพรวมเขียนเป็น $z=(a,\ t)$

ของที่เพิ่ม (ตัวเลขสมมติ):

  • ความผันผวนต่อปีของหุ้นเทค $\sigma_t=35\%$
  • correlation ของหุ้นเทคกับหุ้นสหรัฐฯ 0.65 และกับพันธบัตร 0.30

covariance ของแต่ละคู่คือ correlation คูณความผันผวนของทั้งสองตัว หุ้นสหรัฐฯ กับพันธบัตรได้ $0.30\times0.20\times0.10=0.006$ หุ้นเทคกับหุ้นสหรัฐฯ ได้ $0.65\times0.20\times0.35=0.0455$ และหุ้นเทคกับพันธบัตรได้ $0.30\times0.35\times0.10=0.0105$

ตอนนี้ความโค้งไม่ใช่ตัวเลขตัวเดียวแล้ว มันเป็น matrix $H$ ของ derivative อันดับสอง (Hessian) วิธีหาที่ง่ายคือเขียนผลตอบแทนของพอร์ต $R_p$ ใหม่ ให้พันธบัตรเป็นฐาน แล้วบวกส่วนที่ย้ายไปหุ้นสองตัว ($R_s$, $R_t$, $R_b$ คือผลตอบแทนของหุ้นสหรัฐฯ หุ้นเทค และพันธบัตร)

\[ \begin{aligned} R_p&=R_b+a\,(R_s-R_b)+t\,(R_t-R_b),\\ H_{aa}&=2\,\mathrm{Var}(R_s-R_b)\\ &=2(0.04+0.01-2\times0.006)=0.076,\\ H_{tt}&=2\,\mathrm{Var}(R_t-R_b)\\ &=2(0.1225+0.01-2\times0.0105)=0.223,\\ H_{at}&=2\,\mathrm{Cov}(R_s-R_b,\ R_t-R_b)\\ &=2(0.0455-0.006-0.0105+0.01)=0.078. \end{aligned} \]

เขียนแบบนี้แล้ว variance ของพอร์ตเป็นกำลังสองของ $a$ และ $t$ สัมประสิทธิ์หน้า $a^2$ คือ variance ของ $R_s-R_b$ derivative อันดับสองจึงเป็นสองเท่าของมัน เหมือน $d^2(ca^2)/da^2=2c$ พจน์ไขว้ $at$ ให้ $H_{at}$ ในแบบเดียวกัน ตัวเลขในวงเล็บมาจากสองกฎของ variance คือ $\mathrm{Var}(X-Z)=\mathrm{Var}\,X+\mathrm{Var}\,Z-2\,\mathrm{Cov}(X,Z)$ และ $\mathrm{Cov}(X-Z,\ Y-Z)=\mathrm{Cov}(X,Y)-\mathrm{Cov}(X,Z)-\mathrm{Cov}(Y,Z)+\mathrm{Var}\,Z$ โดย variance ของหุ้นสหรัฐฯ หุ้นเทค และพันธบัตรคือ $0.2^2=0.04$, $0.35^2=0.1225$ และ $0.1^2=0.01$

กฎ gradient descent ในสองมิติคือ $z_{k+1}=z_k-\eta\,\nabla q(z_k)$ ความชันเขียนเป็น $\nabla q(z)=H(z-z^\star)$ ได้เหมือนขั้นที่ 1 error จึงถูกคูณด้วย matrix $(I-\eta H)$ แทนตัวเลขตัวเดียว matrix นี้คูณ error ในทิศ eigenvector แต่ละทิศของ $H$ ด้วยตัวคูณของทิศนั้นเอง (eigenvalue และ positive definiteness) เราจึงต้องหา eigenvalue ทั้งสองตัว โดยใช้ trace (ผลบวกแนวทแยง) และ determinant ของ $H$

\[ \begin{aligned} z_{k+1}-z^\star&=(I-\eta H)(z_k-z^\star),\\ \operatorname{tr}H&=0.076+0.223=0.299,\\ \det H&=0.076(0.223)-0.078^2=0.010864,\\ \lambda&=\frac{0.299}{2}\pm\sqrt{\frac{0.299^2}{4}-0.010864}\\ &=0.1495\pm0.10717,\\ \lambda_{\max}&\approx0.25667,\quad\lambda_{\min}\approx0.04233,\\ \kappa&=\frac{0.25667}{0.04233}\approx6.06. \end{aligned} \]

eigenvalue ทั้งสองบวก ชามจึงโค้งขึ้นทุกทิศ แต่ทิศชันโค้งกว่าทิศราบราว 6 เท่า นี่คือ condition number $\kappa\approx6.06$ ทิศชันหาได้จาก $(0.076-0.2567)v_1+0.078v_2=0$ ได้ $v_2\approx2.32v_1$ คือทิศ $(0.40,\ 0.92)$ ซึ่งส่วนใหญ่คือเพิ่มหุ้นเทค ทิศราบตั้งฉากกับมัน คือ $(0.92,\ -0.40)$ เพิ่มหุ้นสหรัฐฯ พร้อมลดหุ้นเทค

ขนาดก้าวตัวเดียวต้องใช้กับทั้งสองทิศ ทิศชันเป็นตัวกำหนดเพดาน ส่วนทิศราบเป็นตัวกำหนดความเร็ว ลองดูว่าเลือกได้ดีที่สุดแค่ไหน

\[ \begin{aligned} \eta&\lt\frac{2}{\lambda_{\max}}=\frac{2}{0.2567}\approx7.79,\\ \eta=7:&\quad1-7(0.0423)\approx0.70,\\ \eta_{\text{best}}&=\frac{2}{\lambda_{\max}+\lambda_{\min}}=\frac{2}{0.299}\approx6.69,\\ 1-\eta_{\text{best}}\lambda_{\min}&=1-6.69(0.0423)\approx0.717,\\ 0.717^{\,n}=10^{-6}:&\quad n=\frac{\ln10^{-6}}{\ln0.717}\approx41.5. \end{aligned} \]

ทิศชันบังคับให้ $\eta$ ต่ำกว่า 7.79 ไม่งั้นระเบิด แต่ที่ $\eta$ ระดับนั้น ทิศราบหดได้แค่เหลือราว 0.70 ต่อก้าว ค่าที่ดีที่สุดคือ $\eta$ ที่ทำให้สองทิศหดเท่ากัน แต่สลับเครื่องหมาย: $1-\eta\lambda_{\min}=-(1-\eta\lambda_{\max})$ แก้ได้ $\eta_{\text{best}}=2/(\lambda_{\max}+\lambda_{\min})$ ถ้าเล็กกว่านี้ ทิศราบช้าลง ถ้าใหญ่กว่านี้ ทิศชันแย่ลง ตัวคูณที่ได้เขียนเป็น $\kappa$ ล้วน ๆ ได้ $1-\frac{2\lambda_{\min}}{\lambda_{\max}+\lambda_{\min}}=\frac{\kappa-1}{\kappa+1}=\frac{5.06}{7.06}\approx0.717$ ต้องใช้ราว 41.5 ก้าว error จึงหดเหลือหนึ่งในล้าน

ภาพในรูปภาพรวมคือเรื่องเดียวกัน ทิศของก้าวตั้งฉากกับวงรี ซึ่งชี้ข้ามหุบมากกว่าชี้ไปก้น ก้าวจึงเด้งไปมาระหว่างสองผนังหุบ ถ้า $\kappa$ เป็น 1,000 ซึ่งเจอบ่อยเมื่อ parameter มีหน่วยต่างกันมาก ตัวคูณจะเป็น $999/1001\approx0.998$ และต้องใช้ $\ln10^{-6}/\ln0.998\approx6{,}900$ ก้าว

ขั้นที่ 3 — Newton: กระโดดไปก้นพาราโบลาที่ประมาณไว้

ต้นเหตุของการซิกแซกคือ $\eta$ ตัวเดียวต้องใช้กับทุกทิศ ทั้งที่แต่ละทิศโค้งไม่เท่ากัน Newton แก้ตรงนี้ มันใช้ความโค้งของแต่ละทิศเลือกความยาวก้าวในทิศนั้น วิธีคือประมาณ function $f$ รอบจุดปัจจุบัน $x$ ด้วย Taylor อันดับสอง (Hessian และเงื่อนไขอันดับสอง) ได้พาราโบลา $m(p)$ ซึ่งบอกค่าของ $f$ เมื่อก้าวไป $p$ แล้วหาก้าวที่ทำให้ความชันของพาราโบลาเป็นศูนย์

\[ \begin{aligned} m(p)&=f(x)+\nabla f^{\mathsf T}p+\tfrac12p^{\mathsf T}Hp,\\ \nabla m(p)&=\nabla f+Hp=0,\\ p&=-H^{-1}\nabla f. \end{aligned} \]

ก้าวของ Newton คือ gradient descent ที่เอาตัวเลข $\eta$ ออก แล้วใส่ matrix $H^{-1}$ แทน ตัวคูณของ error $(I-\eta H)$ จึงกลายเป็น $I-H^{-1}H=0$ ในทุกทิศพร้อมกัน บน function กำลังสอง พาราโบลาที่ประมาณคือ function จริงทุกจุด Newton จึงถึงก้นในก้าวเดียว

ลองกับชามทั้งสองของหน้านี้ ชามหนึ่งมิติเริ่มที่ $a_0=1$ ชามสองมิติเริ่มที่ $z_0=(0.50,\ -0.15)$ ความชันของชามสองมิติหาได้จากรูป $R_p$ ในขั้นที่ 2 ที่พอร์ตพันธบัตรล้วน $z=(0,\ 0)$ ความชันคือ $c=\big(2(0.006-0.01),\ 2(0.0105-0.01)\big)=(-0.008,\ 0.001)$ คือสองเท่าของ covariance ระหว่างพันธบัตรกับส่วนที่ย้ายไปหุ้นแต่ละตัว พอขยับออกจากจุดนั้น ความชันเพิ่มขึ้น $Hz$

\[ \begin{aligned} \text{1-D}:&\quad a_1=1-\frac{q'(1)}{h}=1-\frac{0.068}{0.076}=\frac{2}{19},\\ \nabla q(z)&=c+Hz,\\ \nabla q(z_0)&=(-0.008+0.0263,\ 0.001+0.00555)\\ &=(0.0183,\ 0.00655),\\ H^{-1}&=\frac{1}{0.010864}\begin{bmatrix}0.223&-0.078\\-0.078&0.076\end{bmatrix},\\ p&=-H^{-1}\nabla q(z_0)=(-0.3286,\ 0.0856),\\ z_1&=(0.50,\ -0.15)+p=(0.1714,\ -0.0644). \end{aligned} \]

ทั้งสองชามถึงก้นในก้าวเดียว ชามหนึ่งมิติได้ $2/19$ ตรงกับขั้นที่ 1 โดย $q'(1)=0.076-0.008=0.068$ ชามสองมิติได้ $z^\star=(17.14\%,\ -6.44\%)$ คือพอร์ตที่ความผันผวนต่ำที่สุด เมื่อยอมให้ short หุ้นเทค ค่า $Hz_0=\big(0.076(0.5)+0.078(-0.15),\ 0.078(0.5)+0.223(-0.15)\big)=(0.0263,\ 0.00555)$ ส่วน $H^{-1}$ มาจากสูตรกลับ matrix 2×2 คือสลับตัวบนซ้ายกับล่างขวา เปลี่ยนเครื่องหมายสองตัวที่เหลือ แล้วหารด้วย $\det H=0.010864$ จากขั้นที่ 2

ความผันผวนที่ก้นชามได้จากการเขียน variance เป็นกำลังสองเต็มรูป $q(z)=0.01+c^{\mathsf T}z+\tfrac12z^{\mathsf T}Hz$ โดย 0.01 คือ variance ของพันธบัตรล้วน ที่ก้นชาม $Hz^\star=-c$ พจน์สุดท้ายจึงเท่ากับ $-\tfrac12c^{\mathsf T}z^\star$

\[ \begin{aligned} q(z^\star)&=0.01+\tfrac12c^{\mathsf T}z^\star\\ &=0.01+\tfrac12(-0.0013712-0.0000644)\\ &=0.01-0.000718=0.009282,\\ \sqrt{0.009282}&\approx0.09634=9.634\%. \end{aligned} \]

สองพจน์ในวงเล็บคือ $-0.008\times0.1714$ และ $0.001\times(-0.0644)$ ความผันผวน 9.634% นี้คือก้นชามในรูปภาพรวม ราคาของความเร็วแบบ Newton คือต้องมี $H$ และต้องแก้ระบบสมการเชิงเส้นทุกก้าว พอร์ต 500 หุ้นมี Hessian $500\times500=250{,}000$ ช่อง

ขั้นที่ 4 — Newton บนพื้นที่ไม่ใช่ชาม: เร็ว แต่แยกก้นหลุมกับอานม้าไม่ออก

ชามในขั้นก่อนเป็นกำลังสองพอดี แต่ function ส่วนใหญ่ไม่ใช่ ถ้า function ไม่ใช่กำลังสอง พาราโบลาของ Newton เป็นแค่ค่าประมาณ Newton จึงต้องเดินหลายก้าว และอาจพาไปผิดที่ได้ ลองกับ function ทดสอบเล็ก ๆ ที่รู้คำตอบ คือ $f(x_1,\ x_2)=x_1^2+3x_1x_2+x_2^3$ เริ่มจากหาทุกจุดที่ความชันเป็นศูนย์ แล้วใช้ Hessian ตัดสินว่าแต่ละจุดเป็นอะไร

\[ \begin{aligned} \nabla f&=(2x_1+3x_2,\ \ 3x_1+3x_2^2),\\ H&=\begin{bmatrix}2&3\\3&6x_2\end{bmatrix},\\ 2x_1+3x_2=0:&\quad x_1=-1.5x_2,\\ 3x_2^2-4.5x_2=0:&\quad x_2=0,\ \ x_2=1.5,\\ (0,\ 0):&\quad\det H=2(0)-9=-9\lt0,\\ (-2.25,\ 1.5):&\quad\det H=2(9)-9=9\gt0,\\ f(-2.25,\ 1.5)&=5.0625-10.125+3.375\\ &=-1.6875. \end{aligned} \]

แทน $x_1=-1.5x_2$ ลงในช่องที่สองของ $\nabla f$ ได้ $-4.5x_2+3x_2^2=0$ จึงมีสองจุด determinant ของ Hessian คือผลคูณของความโค้งสองทิศหลัก (eigenvalue สองตัว) ที่ $(0,\ 0)$ มันติดลบ แปลว่าทิศหนึ่งโค้งขึ้น อีกทิศโค้งลง จุดนี้จึงเป็นอานม้า ที่ $(-2.25,\ 1.5)$ มันเป็นบวก และตัวบนซ้าย 2 ก็บวก ความโค้งทั้งสองทิศจึงบวก จุดนี้จึงเป็นก้นหลุม มีค่า $f=-1.6875$

ทีนี้ปล่อย Newton จากสองจุดเริ่ม คือ P $=(-1.5,\ 1)$ และ Q $=(-0.5,\ 0.5)$ ก้าวแรกจาก P คิดด้วยมือได้ดังนี้ ก้าวต่อไปทำแบบเดียวกัน (โค้ดท้ายหน้าพิมพ์ทุกก้าว)

\[ \begin{aligned} \nabla f(\text{P})&=(-3+3,\ \ -4.5+3)=(0,\ -1.5),\\ H(\text{P})&=\begin{bmatrix}2&3\\3&6\end{bmatrix},\quad\det H=3,\\ p&=-\frac13\begin{bmatrix}6&-3\\-3&2\end{bmatrix}\begin{bmatrix}0\\-1.5\end{bmatrix}=\begin{bmatrix}-1.5\\1\end{bmatrix},\\ \text{P}:&\ (-1.5,\ 1)\to(-3,\ 2)\to(-2.4,\ 1.6)\\ &\to(-2.2588,\ 1.5059)\to(-2.25003,\ 1.50002),\\ \text{Q}:&\ (-0.5,\ 0.5)\to(0.75,\ -0.5)\to(0.15,\ -0.1)\\ &\to(0.0088,\ -0.0059)\to(0,\ 0). \end{aligned} \]

นี่คือพื้นผิวทดสอบเดียวกับที่หน้า Hessianใช้แยกอานม้ากับก้นหลุม จาก P ให้ดูว่า $x_1$ ห่างจาก −2.25 เท่าไร: 0.75, 0.15, 0.00882, 0.0000343 ระยะใหม่ประมาณค่าคงที่คูณระยะเดิมยกกำลังสอง ($0.00882/0.15^2\approx0.39$ และ $0.0000343/0.00882^2\approx0.44$) จำนวนหลักที่ถูกจึงเพิ่มราวเท่าตัวทุกก้าว เรียกว่า quadratic convergence

แต่ก้าวแรกพาไปที่ $(-3,\ 2)$ ซึ่ง $f=9-18+8=-1$ สูงกว่าจุดเริ่ม $f(\text{P})=2.25-4.5+1=-1.25$ เพราะก้าวนั้นยาว และไกลจากจุดเริ่ม พาราโบลาก็ไม่ตรงกับ function จริงแล้ว Newton เปล่า ๆ จึงไม่รับประกันว่าค่าลดลงทุกก้าว

จาก Q เกิดเรื่องที่แย่กว่า Newton วิ่งเข้าอานม้า $(0,\ 0)$ ซึ่งมี $f=0$ ทั้งที่จุดเริ่ม $f(\text{Q})=0.25-0.75+0.125=-0.375$ ต่ำกว่าอยู่แล้ว ดูที่ Q ว่าเกิดอะไรขึ้น

\[ \begin{aligned} \nabla f(\text{Q})&=(-1+1.5,\ \ -1.5+0.75)=(0.5,\ -0.75),\\ H(\text{Q})&=\begin{bmatrix}2&3\\3&3\end{bmatrix},\quad\det H=6-9=-3,\\ p&=-H^{-1}\nabla f=(1.25,\ -1),\\ \nabla f^{\mathsf T}p&=0.5(1.25)+(-0.75)(-1)=1.375\gt0. \end{aligned} \]

ที่ Q determinant ติดลบ พาราโบลาที่ Newton ใช้จึงเป็นอานม้า ไม่ใช่ชาม มันไม่มีก้น Newton จึงกระโดดไปจุดที่ความชันของอานม้าเป็นศูนย์แทน $\nabla f^{\mathsf T}p$ คือความชันของ $f$ เมื่อเดินไปตามทิศ $p$ ค่าบวกแปลว่าเดินทางนี้แล้ว $f$ ขึ้น คือขึ้นเขา Newton หาจุดที่ความชันเป็นศูนย์ มันไม่สนว่าเป็นก้นหลุม ยอดเขา หรืออานม้า จึงต้องตรวจ Hessian ก่อนเชื่อคำตอบ (global กับ local minimum) ทางแก้ที่ใช้จริงคือยอมรับก้าวของ Newton เฉพาะเมื่อ $\nabla f^{\mathsf T}p\lt0$ คือเป็นทิศลงเขา ถ้าไม่ใช่ ให้ถอยไปใช้ทิศ $-\nabla f$ ของ gradient descent และใส่ line search ทุกครั้ง

ขั้นที่ 5 — implied volatility: เปลี่ยนราคาเป็นรากและเป็น loss

กลับมาที่โจทย์เปิดเรื่อง เราต้องการ $\sigma$ ที่ทำให้ราคาจากสูตร $C(\sigma)$ เท่ากับราคาตลาด $C_{\text{mkt}}=\$10.45$ เขียนเป็นคณิตศาสตร์ได้สองแบบ แบบแรกคือหาราก คือหา $\sigma$ ที่ทำให้ส่วนต่างราคา $g(\sigma)$ เป็นศูนย์ แบบที่สองคือหาจุดต่ำสุดของ loss $f(\sigma)$ คือส่วนต่างยกกำลังสองหารด้วยสอง loss ไม่เคยติดลบ และเป็นศูนย์เฉพาะตรงคำตอบ จุดต่ำสุดของมันจึงเป็นคำตอบเดียวกับรากของ $g$ ส่วนเลขสองที่หารใส่ไว้ให้ตัดกับเลขสองที่ได้ตอนหา derivative

เพื่อเชื่อมสองแบบเข้าด้วยกัน หา derivative ของ loss ด้วย chain rule ให้ vega $\mathcal V=C'(\sigma)$ คือราคาขยับเท่าไรเมื่อความผันผวนขยับหนึ่งหน่วย

\[ \begin{aligned} g(\sigma)&=C(\sigma)-C_{\text{mkt}},\qquad f(\sigma)=\tfrac12g(\sigma)^2,\\ f'(\sigma)&=g\,\mathcal V,\qquad\mathcal V=C'(\sigma),\\ f''(\sigma)&=\mathcal V^2+g\,C''(\sigma),\\ f''(\sigma^\star)&=\mathcal V(\sigma^\star)^2\quad(g=0),\\ -\frac{f'}{\mathcal V^2}&=-\frac{g\,\mathcal V}{\mathcal V^2}=-\frac{g}{\mathcal V}. \end{aligned} \]

$f''$ มาจากกฎผลคูณของ $g\mathcal V$ derivative ของ $g$ คือ $\mathcal V$ จึงได้ $\mathcal V\cdot\mathcal V$ และ derivative ของ $\mathcal V$ คือ $C''$ ที่คำตอบ $g=0$ พจน์ที่สองหายไป ความโค้งของ loss จึงเท่ากับ vega ยกกำลังสองพอดี ใกล้คำตอบ ก้าวของ Newton บน loss คือ $-f'/f''\approx-f'/\mathcal V^2=-g/\mathcal V$ ซึ่งก็คือ Newton สำหรับหาราก คือลากเส้นสัมผัสของเส้นราคาจากจุดปัจจุบัน แล้วเดินไปจุดที่เส้นสัมผัสตัดราคาตลาด สองแบบของโจทย์จึงพาไปทางเดียวกัน

ต่อไปต้องมีตัวเลขจริง สูตรราคาและ vega มาจากสูตร Black–Scholes และthe Greeks หน้านี้ใช้เป็นกล่องที่คำนวณได้ ไม่ได้พิสูจน์ $\Phi$ คือ CDF ของstandard Normal คือพื้นที่ใต้เส้นระฆังทางซ้ายของจุดนั้น และ $\phi$ คือ density คือความสูงของเส้นระฆัง แทนตัวเลขที่จุดเริ่ม $\sigma_0=0.30$ ตรงนี้ $S=K$ จึงได้ $\ln(S/K)=\ln1=0$

\[ \begin{aligned} C(\sigma)&=S\,\Phi(d_1)-Ke^{-rT}\Phi(d_2),\\ d_1&=\frac{\ln(S/K)+(r+\sigma^2/2)T}{\sigma\sqrt T},\\ d_2&=d_1-\sigma\sqrt T,\qquad\mathcal V=S\,\phi(d_1)\sqrt T,\\ d_1&=\frac{0+0.02+0.30^2/2}{0.30}=\frac{0.065}{0.30}=0.216667,\\ d_2&=0.216667-0.30=-0.083333,\\ \Phi(d_1)&=0.585766,\quad\Phi(d_2)=0.466793,\\ Ke^{-rT}&=100e^{-0.02}=98.0199,\\ C(0.30)&=100(0.585766)-98.0199(0.466793)\\ &\approx58.5766-45.7550=12.8216,\\ g&=12.821581-10.45=2.371581,\\ \phi(d_1)&=\frac{e^{-0.216667^2/2}}{\sqrt{2\pi}}=0.389687,\\ \mathcal V&=100(0.389687)(1)=38.9687,\\ f'&=g\,\mathcal V=2.371581(38.9687)=92.4175. \end{aligned} \]

ค่า $\Phi$ อ่านจากตาราง Normal หรือคำนวณด้วยเครื่อง คิดมือด้วยค่าที่ปัดแล้วได้ $C(0.30)\approx12.8216$ ส่วนเลขหกตำแหน่ง 12.821581 มาจากโค้ดท้ายหน้าที่คิดด้วยทศนิยมเต็ม ตรงกันถึงทศนิยมตำแหน่งที่สี่ ที่ 30% สูตรให้ราคาสูงกว่าตลาด \$2.37 ความผันผวนที่ลองจึงสูงเกินไป ต้องลดลง vega 38.97 แปลว่าถ้าความผันผวนขยับ 1 จุด (0.01) ราคาขยับราว $38.97\times0.01\approx\$0.39$ ระวังว่า $\phi(d_1)=0.389687$ คือความสูงของเส้นระฆัง ไม่ใช่พื้นที่

ขั้นที่ 6 — gradient descent ที่ η = 0.0005: error หดเหลือ 23.6% ทุกก้าว

ขั้นที่ 7 — Newton: หลักที่ถูกเพิ่มเป็นเท่าตัว

gradient descent ต้องให้เราเลือก $\eta$ เอง ส่วน Newton ใช้ความชันของเส้นราคา (vega) เลือกความยาวก้าวให้ กฎสำหรับหารากคือ $\sigma_{k+1}=\sigma_k-g(\sigma_k)/\mathcal V(\sigma_k)$ (ขั้นที่ 5) เริ่มด้วย $g$ และ $\mathcal V$ ที่ 30% จากขั้นที่ 5 แล้ววัด error ทุกก้าว ค่า $g$ และ $\mathcal V$ ที่ $\sigma_1$ คำนวณด้วยสูตรเดิมของขั้นที่ 5 (โค้ดท้ายหน้า)

\[ \begin{aligned} \sigma_1&=0.30-\frac{2.371581}{38.9687}=0.30-0.060859\\ &=0.2391414,\\ g(\sigma_1)&=-0.003709,\quad\mathcal V(\sigma_1)=39.0790,\\ \sigma_2&=0.2391414+\frac{0.003709}{39.0790}\\ &=0.2391414+0.0000949=0.2392363,\\ |\sigma_k-\sigma^\star|&:\ 6.1\times10^{-2},\ 9.5\times10^{-5},\ 1.4\times10^{-10}. \end{aligned} \]

error ก้าวต่อก้าวคือ $6.1\times10^{-2}$, $9.5\times10^{-5}$ และ $1.4\times10^{-10}$ จำนวนหลักทศนิยมที่ถูกเพิ่มจาก 1 เป็น 4 เป็น 9 ราวเท่าตัวทุกก้าว นี่คือ quadratic convergence เหตุผลคือ Newton เดินตามเส้นสัมผัส ซึ่งทิ้งพจน์อันดับสองของ Taylor ไป ความคลาดที่เหลือจึงแปรตามกำลังสองของ error เดิม เช่น $9.5\times10^{-5}\approx0.026\times(6.1\times10^{-2})^2$ เทียบกันแล้ว gradient descent ใช้ 8 ก้าวกว่าจะถึง $10^{-6}$ แต่ Newton ใช้ 2 ก้าวได้ $10^{-10}$

ก้าวแรกของ Newton เท่ากับก้าวของ gradient descent ที่เลือก $\eta=1/\mathcal V(0.30)^2$ พอดี เพราะ $f'=g\,\mathcal V$ ทำให้ $g/\mathcal V=f'/\mathcal V^2$

\[ \begin{aligned} \eta&=\frac{1}{38.9687^2}=\frac{1}{1518.56}=0.000659,\\ \eta f'&=\frac{92.4175}{1518.56}=0.060859. \end{aligned} \]

ก้าวยาว 0.060859 เท่ากับก้าวแรกของ Newton ข้างบน ค่า 0.0005 ที่เราเดาจึงเล็กกว่าค่าพอดี $1-0.0005/0.000659\approx24\%$ Newton ให้ความโค้งเลือก $\eta$ ใหม่ทุกก้าว จึงไม่ต้องจูนเลย

ขั้นที่ 8 — ทำให้มันพัง: η = 0.0013 แกว่ง η = 0.002 ระเบิด แล้วซ่อมด้วย line search

ขั้นที่ 1 บอกว่าขนาดก้าวต้องต่ำกว่า $2/h$ โดย $h$ คือความโค้ง ในโจทย์นี้ความโค้งใกล้คำตอบคือ $f''(\sigma^\star)=\mathcal V^2=1527.16$ (ขั้นที่ 6) จึงหาเพดานของ $\eta$ ได้ แล้วลองสองค่ารอบเพดาน ค่าหนึ่งต่ำกว่าเพดานนิดเดียว อีกค่าเกินเพดาน

\[ \begin{aligned} \eta_{\max}&=\frac{2}{f''(\sigma^\star)}=\frac{2}{1527.16}\approx0.00131,\\ \eta=0.0013:&\quad1-0.0013(1527.16)=-0.985,\\ &\quad0.300,\ 0.1799,\ 0.2978,\ 0.1819,\ 0.2958,\\ \eta=0.002:&\quad1-0.002(1527.16)=-2.05,\\ \sigma_1&=0.30-0.002(92.418)=0.1152,\\ \sigma_2&=0.1152-0.002(-188.196)=0.4916,\\ \sigma_3&=0.4916-0.002(374.407)=-0.2573. \end{aligned} \]

$\eta=0.0013$ อยู่ใต้เพดานนิดเดียว ตัวคูณ −0.985 ทำให้กระโดดข้ามคำตอบ (0.239) ไปมาระหว่างราว 0.18 กับ 0.30 และระยะหดแค่ 1.5% ต่อก้าว $\eta=0.002$ เกินเพดาน ตัวคูณ −2.05 ทำให้ทุกก้าวกระโดดไกลขึ้นราวสองเท่า ความชันที่ใช้ในแต่ละก้าวคือ $f'=g\,\mathcal V$ ที่ $\sigma_1=0.1152$ สูตรให้ราคา \$5.6048 ความชันจึงเป็น $(5.6048-10.45)(38.8417)=-188.196$ ที่ $\sigma_2=0.4916$ สูตรให้ราคา \$20.2281 ความชันจึงเป็น $(20.2281-10.45)(38.2904)=374.407$ ภายในสามก้าว $\sigma$ ติดลบ ทำให้ $\sigma\sqrt T$ ในตัวหารของ $d_1$ ติดลบ สูตรราคาจึงไม่มีความหมายอีกต่อไป โค้ดท้ายหน้าหยุดและรายงานว่าหลุดโดเมนที่ก้าวที่ 3

สรุปพฤติกรรมตามขนาดก้าว โดยใช้ $1/f''=1/1527.16\approx0.000655$ และ $2/f''\approx0.00131$

  • $\eta$ ต่ำกว่า 0.000655: ตัวคูณอยู่ระหว่าง 0 กับ 1 เข้าหาคำตอบจากด้านเดียว ปลอดภัยแต่ช้า
  • $\eta$ ใกล้ 0.000655: ตัวคูณใกล้ศูนย์ เร็วที่สุด
  • $\eta$ ระหว่าง 0.000655 กับ 0.00131: ตัวคูณอยู่ระหว่าง −1 กับ 0 ยิงเลยแล้วเด้งกลับ แต่ยังเข้า
  • $\eta$ เกิน 0.00131: ตัวคูณติดลบเกิน −1 ระเบิด

ทางซ่อมมาตรฐานคือไม่เชื่อก้าวแรกที่เสนอ backtracking line search ลองก้าว $\eta$ แล้วยอมรับก็ต่อเมื่อ loss ลดลงอย่างน้อยครึ่งหนึ่งของที่ความชันทำนาย ถ้าความชันคงที่ ก้าวยาว $\eta f'$ จะลด loss ได้ $\eta f'\times f'=\eta f'^2$ เกณฑ์จึงเป็น

\[f(\sigma-\eta f')\le B(\eta)=f(\sigma)-\tfrac12\eta f'^2\]

ถ้าไม่ผ่าน ก็หั่น $\eta$ ครึ่งแล้วลองใหม่ ลองที่ $\sigma_0=0.30$ ซึ่งมี $f=\tfrac12(2.371581)^2=2.8122$ และ $f'^2=92.4175^2=8541.0$ โดยเริ่มที่ $\eta=0.002$

\[ \begin{aligned} B(0.002)&=2.8122-\tfrac12(0.002)(8541.0)=-5.73,\\ f(0.1152)&=11.74\gt-5.73,\\ B(0.001)&=2.8122-4.2705=-1.46\lt0,\\ B(0.0005)&=2.8122-2.1353=0.6769,\\ f(0.2538)&=\tfrac12(0.568652)^2=0.1617\le0.6769. \end{aligned} \]

ที่ 0.002 loss พุ่งจาก 2.81 เป็น 11.74 จึงถูกปฏิเสธ ที่ 0.001 เกณฑ์ติดลบ ซึ่ง loss ที่เป็นกำลังสองไม่มีทางต่ำกว่าได้ จึงถูกปฏิเสธเช่นกัน ที่ 0.0005 ผ่าน ทุกก้าวต่อจากนั้นเริ่มลองที่ 0.002 ใหม่ แล้วจบที่ 0.0005 เองทุกครั้ง ได้เส้นทางเดียวกับตาราง gradient descent ในขั้นที่ 6 โดยไม่มีใครต้องจูน

ขั้นที่ 9 — รั้วกันพังก่อนเชื่อคำตอบ

ระบบจริงต้องกันพังสองเรื่อง ก่อนเริ่มเดิน มันต้องรู้ก่อนว่ามีคำตอบไหม และระหว่างเดิน มันต้องไม่หารด้วยเลขที่ใกล้ศูนย์ เรื่องแรกตรวจได้จากราคาที่ขอบสองข้าง คือเมื่อความผันผวนเข้าใกล้ศูนย์ และเมื่อความผันผวนโตไม่หยุด

\[ \begin{aligned} \sigma\to0:&\quad C\to S-Ke^{-rT}\\ &\quad=100-98.019867=1.980133,\\ \sigma\to\infty:&\quad C\to S=100,\\ &\quad1.980133\lt10.45\lt100. \end{aligned} \]

เมื่อ $\sigma$ เข้าใกล้ศูนย์ ตัวเศษของ $d_1$ คือ $0.02$ ซึ่งบวก หารด้วย $\sigma$ ที่เล็กมาก $d_1$ และ $d_2$ จึงพุ่งไปบวกอนันต์ ทั้ง $\Phi(d_1)$ และ $\Phi(d_2)$ เข้าใกล้ 1 ราคาจึงเหลือ $S-Ke^{-rT}$ คือหุ้นลบ strike ที่จ่ายในอีกหนึ่งปี คิดเป็นมูลค่าวันนี้ เมื่อ $\sigma$ โตไม่หยุด $d_1$ พุ่งไปบวกอนันต์ แต่ $d_2=d_1-\sigma\sqrt T$ พุ่งไปลบอนันต์ $\Phi(d_2)$ จึงเข้าใกล้ 0 ราคาจึงเข้าใกล้ราคาหุ้นเอง ราคาตลาดต้องอยู่ระหว่างสองขอบนี้ ถ้าต่ำกว่า \$1.98 จะไม่มีความผันผวนไหนให้ราคานั้นได้ โปรแกรมต้องตอบว่าราคาผิด ไม่ใช่วนหาไปเรื่อย ๆ

เพราะ vega เป็นบวกตลอด ราคาจึงขึ้นตาม $\sigma$ เสมอ และคำตอบมีหนึ่งเดียว bisection ที่ผ่าครึ่งช่วง 1% ถึง 100% จึงรับประกันว่าเจอ แต่ช่วงหดแค่ครึ่งต่อก้าว ช่วงกว้าง 0.99 จึงต้องใช้ 20 ก้าวเพื่อให้แคบกว่า $10^{-6}$: $0.99/2^{19}=1.9\times10^{-6}$ ยังไม่พอ แต่ $0.99/2^{20}=9.4\times10^{-7}$ พอ

เรื่องที่สองคือกับดักของ Newton เพราะก้าวของมันหารด้วย vega ลองกับ call อีกตัวที่ strike $K=160$ หุ้นยังอยู่ที่ \$100 ถ้าความผันผวนจริงคือ 25% สูตรให้ราคา \$0.4443 (โค้ดท้ายหน้าคำนวณ) ถ้าระบบเริ่มเดาที่ $\sigma_0=5\%$ จะได้

\[ \begin{aligned} d_1&=\frac{\ln(100/160)+0.02+0.05^2/2}{0.05}\\ &=\frac{-0.4700+0.02125}{0.05}=-8.975,\\ \mathcal V&=100\,\phi(-8.975)\approx1.286\times10^{-16},\\ \frac{g}{\mathcal V}&\approx\frac{0-0.4443}{1.286\times10^{-16}}\approx-3.45\times10^{15}. \end{aligned} \]

ที่ความผันผวน 5% โอกาสที่หุ้น \$100 จะขึ้นไปเกิน \$160 ในหนึ่งปีแทบเป็นศูนย์ ราคา call จากสูตรจึงแทบเป็นศูนย์ (ราว $1.5\times10^{-14}$) และขยับความผันผวนนิดหน่อยก็ไม่เปลี่ยนราคา vega จึงแทบเป็นศูนย์ ราว $1.3\times10^{-16}$ ก้าวของ Newton คือส่วนต่างราคาหารด้วยเลขเกือบศูนย์ จึงยาวราว $3.45\times10^{15}$ โค้ดท้ายหน้าปฏิเสธก้าวนี้ ถ้าเริ่มที่ 60% แทน Newton เดิน 0.346, 0.275, 0.253, 0.2501 แล้วถึง 0.25 ใน 6 ก้าว ระบบจริงจึงผสมสองวิธี ใช้ Newton เมื่อก้าวยังอยู่ในช่วงที่รู้ว่าคร่อมคำตอบ และถอยไปใช้ bisection เมื่อก้าวหลุดช่วง

กับดัก: ยก η จากโจทย์หนึ่งไปอีกโจทย์ หยุดผิดเวลา และเชื่อ Newton โดยไม่ดู Hessian

ยก $\eta$ จากโจทย์หนึ่งไปใช้กับอีกโจทย์ $\eta=0.0005$ ใช้ได้เพราะความโค้งของโจทย์นี้ราว 1,527 ถ้าหุ้นราคา \$1,000 และ strike \$1,000 แทน \$100 ค่า $d_1$ และ $d_2$ ไม่เปลี่ยน เพราะ $\ln(S/K)$ เท่าเดิม ราคา call และ vega จึงโตสิบเท่าตาม $S$ และ $K$ ส่วนความโค้ง (vega ยกกำลังสอง) โตร้อยเท่า

\[ \begin{aligned} f''&=1527.16\times10^2=152{,}716,\\ \eta_{\max}&=\frac{2}{152{,}716}=1.31\times10^{-5},\\ 1-0.0005(152{,}716)&\approx-75. \end{aligned} \]

ค่า 0.0005 เดิมเกินเพดาน $0.0005/(1.31\times10^{-5})\approx38$ เท่า ตัวคูณ −75 ทำให้ error โต 75 เท่าทุกก้าว ระเบิดทันที ค่าที่ถูกต้องต่ำกว่า $1.31\times10^{-5}$ ต้องคำนวณเพดานใหม่ทุกโจทย์ หรือใช้ line search ที่ปรับก้าวเอง

หยุดเพราะก้าวสั้นอย่างเดียว ก้าวสั้นไม่ได้แปลว่าใกล้คำตอบ ถ้าใช้ $\eta=10^{-5}$ ก้าวแรกยาวแค่ $10^{-5}\times92.4175\approx0.0009$ ทั้งที่ยังห่างคำตอบ $0.30-0.2392=0.061$ ให้ตรวจส่วนต่างราคาด้วย เช่นหยุดเมื่อ $|C(\sigma)-10.45|\lt0.0001$ ในหลายมิติ ก้าวที่สั้นลงอาจแค่แปลว่ากำลังคลานไปตามทิศราบของหุบแคบ ชามในขั้นที่ 2 มี $\kappa$ แค่ 6 ก็ยังต้องใช้ 41 ก้าว

เชื่อ Newton โดยไม่ดู Hessian Newton ที่ลู่เข้าเร็วไม่ได้แปลว่าเจอจุดต่ำ จาก Q บนพื้นผิว $x_1^2+3x_1x_2+x_2^3$ มันลู่เข้าอานม้าภายใน 5 ก้าว เร็วแบบกำลังสองเหมือนกัน ตรวจ Hessian ที่คำตอบทุกครั้ง ที่ $(0,\ 0)$ determinant คือ $2(0)-3^2=-9$ ติดลบ จุดนี้จึงไม่ใช่ก้นหลุม ก้นหลุมจริงอยู่ที่ $(-2.25,\ 1.5)$ ซึ่ง determinant เป็น $+9$

หน้าจอ option แปลงราคาเป็น implied volatility หลายพันครั้งต่อวินาที ด้วย Newton ที่มีรั้วกันพังครบ เริ่มจากค่าเดาที่สมเหตุสมผล ตรวจขอบ arbitrage ก่อนเริ่ม (ขอบ arbitrage คือช่วงที่ราคาต้องอยู่ ถ้าหลุดช่วง จะมีคนซื้อถูกขายแพงได้กำไรแน่นอน) จำกัด $\sigma$ ไว้ในช่วงที่รู้ว่าคร่อมคำตอบ และถ้าก้าวของ Newton ออกนอกช่วง ก็ถอยไปใช้ bisection วิธีมาตรฐานชื่อ Brent's method ก็คือการผสม bisection กับการประมาณด้วยเส้นโค้งแบบนี้

การ calibrate แบบจำลองที่มีหลาย parameter ยากกว่านั้น ตัวอย่างคือแบบจำลอง Heston ซึ่งมีห้าตัวเลขที่ต้องปรับพร้อมกัน (optimizer หลายตัวแปรสำหรับ calibration) ตัวเลือกมีสามแบบ

  • grid search ลองทุกจุดบนตาราง จึงได้จุดที่ดีที่สุดบนตารางแน่นอน แต่ถ้าแบ่ง parameter ละ 10 ค่า ห้าตัวก็เป็น $10^5=100{,}000$ ชุด และทุกชุดต้องคำนวณราคาทุก option
  • Nelder–Mead ค้นหาโดยไม่ใช้ความชันเลย
  • BFGS เป็นแบบ quasi-Newton มันสร้างค่าประมาณของ Hessian จากความชันที่เปลี่ยนไประหว่างก้าว จึงได้ความเร็วใกล้ Newton โดยไม่ต้องคำนวณ Hessian ตรง ๆ

const phi = x => Math.exp(-x * x / 2) / Math.sqrt(2 * Math.PI);
// Standard Normal CDF by Simpson's rule on [0, |x|]; enough intervals for 1e-12 accuracy here.
function Phi(x) {
  if (!Number.isFinite(x)) throw new RangeError('Phi needs a finite argument');
  const n = 2 * Math.ceil(500 * Math.max(1, Math.abs(x))), h = Math.abs(x) / n;
  let sum = 0;
  for (let i = 0; i <= n; i++) sum += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  const half = sum * h / 3;
  return Math.min(1, Math.max(0, x >= 0 ? 0.5 + half : 0.5 - half));
}
// Black-Scholes call and vega, taken as given here.
function bs(sigma, {S = 100, K = 100, r = 0.02, T = 1} = {}) {
  if (!(Number.isFinite(sigma) && sigma > 0)) throw new RangeError('Volatility must be positive');
  const d1 = (Math.log(S / K) + (r + sigma * sigma / 2) * T) / (sigma * Math.sqrt(T)), d2 = d1 - sigma * Math.sqrt(T);
  return {d1, d2, price: S * Phi(d1) - K * Math.exp(-r * T) * Phi(d2), vega: S * phi(d1) * Math.sqrt(T)};
}
function checkQuote(quote, opts = {}) {
  const {S = 100, K = 100, r = 0.02, T = 1} = opts, low = Math.max(S - K * Math.exp(-r * T), 0);
  if (!(quote > low && quote < S)) throw new RangeError(`Price outside no-arbitrage bounds (${low.toFixed(6)}, ${S})`);
  return low;
}
const loss = (s, quote, opts) => 0.5 * (bs(s, opts).price - quote) ** 2;
// Gradient descent on f = (C - quote)^2 / 2; optional backtracking halves eta until f drops enough.
function descend(quote, sigma0, eta, steps, {backtrack = false, ...opts} = {}) {
  checkQuote(quote, opts);
  const path = [sigma0], etas = [];
  for (let k = 0; k < steps; k++) {
    const s = path[k], {price, vega} = bs(s, opts), g = (price - quote) * vega;
    let step = eta;
    if (backtrack) while (!(s - step * g > 0 && loss(s - step * g, quote, opts) <= loss(s, quote, opts) - 0.5 * step * g * g)) step /= 2;
    const next = s - step * g;
    path.push(next); etas.push(step);
    if (!(next > 0)) return {path, etas, leftDomainAt: k + 1};
  }
  return {path, etas, leftDomainAt: null};
}
function newton(quote, sigma0, steps, opts = {}) {
  checkQuote(quote, opts);
  const path = [sigma0];
  for (let k = 0; k < steps; k++) {
    const {price, vega} = bs(path[k], opts);
    if (vega < 1e-8 * (opts.S ?? 100)) throw new RangeError(`Vega too small at sigma = ${path[k]}: Newton step unsafe, bracket first`);
    path.push(path[k] - (price - quote) / vega);
  }
  return path;
}
function bisect(quote, lo, hi, tol, opts = {}) {
  checkQuote(quote, opts);
  let steps = 0;
  while (hi - lo > tol) { const mid = (lo + hi) / 2; if (bs(mid, opts).price > quote) hi = mid; else lo = mid; steps++; }
  return {root: (lo + hi) / 2, steps};
}
