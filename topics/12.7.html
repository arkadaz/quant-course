12.7 The Feynman–Kac Formula

เดินย้อนด้วยสมการหรือเดินหน้าด้วยการจำลอง ก็ต้องได้ราคาเดียวกัน

โปรแกรมหนึ่งเดินย้อนจากคำตอบปลายทาง อีกโปรแกรมสุ่มเส้นทางไปข้างหน้า; ถ้าใช้สมมติฐานเดียวกัน ทั้งคู่ควรให้ราคาเดียวกันหรือไม่?

เฉลย: เมื่อใช้สมมติฐานเดียวกัน ทั้งสองโปรแกรมควรได้ราคาเดียวกัน

Feynman–Kac เชื่อม partial differential equation (PDE) ที่เดินมูลค่าย้อนเวลา กับ conditional expectation ที่เฉลี่ยผลลัพธ์จากเส้นทางข้างหน้า

คนหนึ่งเดินถอยหลัง อีกคนเดินสุ่มไปข้างหน้า แล้วนัดเจอกันที่คำตอบเดียว

Feynman–Kac formula
theorem ที่เชื่อม discounted conditional expectation กับคำตอบของ backward partial differential equation ใช้สลับระหว่าง Monte Carlo และ grid methods โดยไม่เปลี่ยน model
partial differential equation (PDE)
สมการที่เชื่อม derivatives ของ value ตามเวลาและ state หลายทิศ ใช้เดิน terminal payoff ย้อนกลับมาหา value วันนี้
Monte Carlo
วิธีสุ่ม paths จำนวนมากแล้วเฉลี่ย discounted payoffs ใช้ตั้งราคาเมื่อ dimension สูงหรือ payoff ขึ้นกับหลาย state
terminal condition
ค่าของ pricing function ที่กำหนดไว้ ณ expiry ใช้ยึดคำตอบของ backward equation ให้ตรงกับ contract payoff
payoff
เงินสดที่ contract จ่ายตาม state และเงื่อนไขที่กำหนด ใช้เป็น random variable ปลายทางที่ต้องคิดราคา
power note
สัญญาตัวอย่างที่ payoff แปรตามราคายกกำลังและมีตัวหารปรับหน่วย ใช้ทดสอบ Feynman–Kac กับ convex payoff ที่มี closed form
delta
first derivative ของ contract value ต่อ underlying price ใช้กำหนดจำนวน shares สำหรับ local hedge
gamma
second derivative ของ contract value ต่อ underlying price ใช้วัดว่า delta เปลี่ยนเร็วเพียงใดเมื่อราคาเคลื่อน
Geometric Brownian Motion (GBM)
price model ที่เปอร์เซ็นต์การเปลี่ยนแปลงมี drift และ volatility คงที่ ใช้ให้ terminal price เป็น lognormal และคำนวณ moments ได้
random variable
quantity ที่ค่าขึ้นกับผลลัพธ์สุ่ม ใช้แทน terminal payoff ก่อนนำไปหา expectation
moment generating function
function ที่หา expected value ของ exponential ของ random variable ใช้คำนวณ moments ของ Normal distribution แบบปิด
discount factor
ตัวคูณที่แปลงเงินอนาคตกลับเป็นมูลค่าปัจจุบัน ใช้เชื่อม terminal payoff กับราคา ณ วันนี้
convexity
ความโค้งขึ้นที่ทำให้ average payoff สูงกว่า payoff ณ average state ใช้อธิบายผลของ variance ต่อ power note
forward price
ราคาส่งมอบอนาคตที่สอดคล้องกับ carry ภายใต้สมมติฐานตลาด ใช้เป็น benchmark แยกจาก expected physical price
expiry
เวลาสิ้นสุดสัญญาที่ terminal payoff ถูกกำหนด ใช้เป็นขอบปลายเวลาของ pricing problem

ที่มาที่ไป: สองศาสตร์ที่มาบรรจบกันโดยบังเอิญ

Richard Feynman พัฒนาวิธีคิดแบบรวมทุกเส้นทางขึ้นในงานฟิสิกส์ควอนตัม และ Mark Kac เห็นในปี 1949 ว่าโครงสร้างเดียวกันปรากฏในทฤษฎีความน่าจะเป็น

ผลที่ได้คือสะพานเชื่อมสองโลกที่ดูไม่เกี่ยวกัน คือโลกของสมการเชิง derivative ที่แก้ย้อนจากปลาย กับโลกของค่าเฉลี่ยที่คำนวณจากการเดินหน้าไปข้างหน้า

สำหรับงานตั้งราคา สะพานนี้มีค่ามหาศาลสองอย่าง อย่างแรกคือเลือกทางคำนวณที่เร็วกว่าได้ตามลักษณะปัญหา

อย่างที่สองสำคัญกว่า คือมันให้เครื่องมือตรวจงานที่ทรงพลังที่สุดที่มี ถ้าเขียนโค้ดสองแบบแล้วได้คำตอบไม่ตรงกัน แปลว่าอย่างน้อยหนึ่งอันผิด

ระวังตรงนี้

กับดัก: ใส่ price drift แทน funding rate

Feynman–Kac สำหรับ no-arbitrage pricing ใช้ risk-neutral generator ไม่ใช่ forecast drift มุกที่ช่วยจับ bug คือถ้า bullish view ทำให้ vanilla option library เปลี่ยนราคา คุณไม่ได้เพิ่ม alpha—คุณถอด replication ออกจาก model แล้ว

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
เงื่อนไขที่ต้องจริงสองทางให้คำตอบเดียวกันเสมอต้องมีเงื่อนไขทางเทคนิคหลายข้อในกรณีที่ payoff โตเร็วมาก ความเท่ากันอาจไม่จริง
ความเร็วเลือกทางไหนก็ได้การสุ่มช้ามากเมื่อต้องการความแม่นสูงการเพิ่มความแม่นสองเท่าต้องเพิ่มงานสี่เท่า
มิติใช้ได้ทุกจำนวนมิติการแก้สมการช้าลงมากเมื่อมิติเพิ่มเกินสามมิติมักต้องหันไปใช้การสุ่มแทน
แถวล่างคือกฎหลักในการเลือกวิธี คือดูจำนวนมิติของปัญหาเป็นอันดับแรก
