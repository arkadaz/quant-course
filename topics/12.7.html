12.7 The Feynman–Kac Formula

เดินย้อนด้วยสมการหรือเดินหน้าด้วยการจำลอง ก็ต้องได้ราคาเดียวกัน

โปรแกรมหนึ่งเดินย้อนจากคำตอบปลายทาง อีกโปรแกรมสุ่มเส้นทางไปข้างหน้า; ถ้าใช้สมมติฐานเดียวกัน ทั้งคู่ควรให้ราคาเดียวกันหรือไม่?

เฉลย: เมื่อใช้สมมติฐานเดียวกัน ทั้งสองโปรแกรมควรได้ราคาเดียวกัน

Feynman–Kac เชื่อม partial differential equation (PDE) ที่เดินมูลค่าย้อนเวลา กับ conditional expectation ที่เฉลี่ยผลลัพธ์จากเส้นทางข้างหน้า

คนหนึ่งเดินถอยหลัง อีกคนเดินสุ่มไปข้างหน้า แล้วนัดเจอกันที่คำตอบเดียว

ศัพท์ที่ใช้ในหัวข้อนี้
Feynman–Kac formula
theorem ที่เชื่อม discounted conditional expectation กับคำตอบของ backward partial differential equation ใช้สลับระหว่าง Monte Carlo และ grid methods โดยไม่เปลี่ยน model
partial differential equation (PDE)
สมการที่เชื่อม derivatives ของ value ตามเวลาและ state หลายทิศ ใช้เดิน terminal payoff ย้อนกลับมาหา value วันนี้
Monte Carlo
วิธีสุ่ม paths จำนวนมากแล้วเฉลี่ย discounted payoffs ใช้ตั้งราคาเมื่อ dimension สูงหรือ payoff ขึ้นกับหลาย state
terminal condition
ค่าของ pricing function ที่กำหนดไว้ ณ expiry ใช้ยึดคำตอบของ backward equation ให้ตรงกับ contract payoff
payoff
เงินสดที่ contract จ่ายตาม state และเงื่อนไขที่กำหนด ใช้เป็น random variable ปลายทางที่ต้องคิดราคา
power note
สัญญาตัวอย่างที่ payoff แปรตามราคายกกำลังและมีตัวหารปรับหน่วย ใช้ทดสอบ Feynman–Kac กับ convex payoff ที่มี closed form
delta

gamma

Geometric Brownian Motion (GBM)
price model ที่เปอร์เซ็นต์การเปลี่ยนแปลงมี drift และ volatility คงที่ ใช้ให้ terminal price เป็น lognormal และคำนวณ moments ได้
random variable

moment generating function
function ที่หา expected value ของ exponential ของ random variable ใช้คำนวณ moments ของ Normal distribution แบบปิด
discount factor
ตัวคูณที่แปลงเงินอนาคตกลับเป็นมูลค่าปัจจุบัน ใช้เชื่อม terminal payoff กับราคา ณ วันนี้
convexity
ความโค้งขึ้นที่ทำให้ average payoff สูงกว่า payoff ณ average state ใช้อธิบายผลของ variance ต่อ power note
forward price
ราคาส่งมอบอนาคตที่สอดคล้องกับ carry ภายใต้สมมติฐานตลาด ใช้เป็น benchmark แยกจาก expected physical price
expiry
เวลาสิ้นสุดสัญญาที่ terminal payoff ถูกกำหนด ใช้เป็นขอบปลายเวลาของ pricing problem

ที่มาที่ไป: สองศาสตร์ที่มาบรรจบกันโดยบังเอิญ

Richard Feynman พัฒนาวิธีคิดแบบรวมทุกเส้นทางขึ้นในงานฟิสิกส์ควอนตัม และ Mark Kac เห็นในปี 1949 ว่าโครงสร้างเดียวกันปรากฏในทฤษฎีความน่าจะเป็น

ผลที่ได้คือสะพานเชื่อมสองโลกที่ดูไม่เกี่ยวกัน คือโลกของสมการเชิง derivative ที่แก้ย้อนจากปลาย กับโลกของค่าเฉลี่ยที่คำนวณจากการเดินหน้าไปข้างหน้า

สำหรับงานตั้งราคา สะพานนี้มีค่ามหาศาลสองอย่าง อย่างแรกคือเลือกทางคำนวณที่เร็วกว่าได้ตามลักษณะปัญหา

อย่างที่สองสำคัญกว่า คือมันให้เครื่องมือตรวจงานที่ทรงพลังที่สุดที่มี ถ้าเขียนโค้ดสองแบบแล้วได้คำตอบไม่ตรงกัน แปลว่าอย่างน้อยหนึ่งอันผิด

ที่มาในประวัติศาสตร์: จากควอนตัมของ Feynman สู่สมการความร้อนของ Kac และการตั้งราคาในวอลล์สตรีท

ในช่วงทศวรรษ 1940 Richard Feynman กำลังหาทางสร้างกลศาสตร์ควอนตัมขึ้นใหม่ ในยุคนั้นฟิสิกส์มีสมการคลื่นของ Schrödinger ซึ่งเป็น partial differential equation (PDE) แต่ Feynman ต้องการมองการเคลื่อนที่ของอนุภาคผ่าน Lagrangian โดยคิดว่าอนุภาคไม่ได้เดินตามเส้นทางเดียว แต่เดินผ่านทุกเส้นทางที่เป็นไปได้พร้อมกัน แล้วนำผลของทุกเส้นทางมาบวกทบกันจนเกิดเป็น path integral

ในปี 1949 Mark Kac นักคณิตศาสตร์ที่ Cornell University นั่งฟังบรรยายของ Feynman แล้วสะดุดตากับโครงสร้างทางคณิตศาสตร์ Kac มองเห็นทันทีว่าหากเปลี่ยนเวลาจินตภาพ $it$ ให้เป็นเวลาจริง $t$ ก้อนคณิตศาสตร์ของ Feynman จะกลายร่างเป็น Wiener integral บนเส้นทางของ Brownian motion ทันที Kac จึงพิสูจน์ทฤษฎีบทเชื่อมโยง PDE แบบพาราโบลิกเข้ากับ conditional expectation ของ stochastic process จนเกิดเป็น Feynman–Kac formula

ในโลกการเงิน ยุคแรกก่อนปี 1973 ไม่มีใครรู้วิธีตั้งราคา derivative อย่างเป็นระบบ จนกระทั่ง Black–Scholes และ Merton (ซึ่งจะสร้างอย่างสมบูรณ์ในบทที่ 13) พิสูจน์ว่าราคาต้องสอดคล้องกับ PDE เพื่อขจัด arbitrage ต่อมา Cox, Ross, Harrison และ Kreps แสดงว่าราคาเดียวกันนี้คือ discounted expectation ภายใต้ risk-neutral measure $Q$ ทฤษฎีบท Feynman–Kac จึงกลายเป็นสะพานเชื่อมสองสำนักเข้าด้วยกัน เพื่อรับประกันว่าไม่ว่าจะแก้วิธีไหน ตัวเลขดอลลาร์ที่ได้ต้องตรงกันเสมอ

ขั้นที่ 1 — risk-neutral state และ payoff ที่หน่วยถูก

ตั้งโจทย์ให้ชัดก่อน คือมีตัวแปรสถานะเดินตามสมการหนึ่ง และมีเงินที่จะได้รับตอนจบก้อนหนึ่ง คำถามเดียวคือวันนี้มันมีค่าเท่าไร

\[ dS_t=rS_t\,dt+\sigma S_t\,dW_t^Q,\qquad g(S_T)=\frac{S_T^2}{K} \]

AAPL price $S_t$ โตด้วย funding rate $r$ ภายใต้ risk-neutral measure และผันผวนด้วย $\sigma$; หาร squared terminal price ด้วย level $K$ หน่วย USD/share ทำให้ payoff มีหน่วย USD

ขั้นที่ 2 — นิยามของด้านที่เป็นค่าเฉลี่ย แล้วอ้างว่ามันเท่ากับด้าน PDE

บรรทัดนี้เป็น นิยาม ของมูลค่าที่คำนวณจากด้านค่าเฉลี่ย ซึ่งมาจากหัวข้อ 12.6 ส่วนสิ่งที่หัวข้อนี้จะแสดงคือ ของก้อนนี้แก้สมการในขั้นที่ 4 ได้ด้วย หัวใจของหัวข้อนี้คือคำตอบเดียวกันเขียนได้สองแบบ แบบหนึ่งเป็นค่าเฉลี่ยของอนาคต อีกแบบเป็นสมการที่เดินย้อนกลับมา และขั้นที่ 5 ถึง 8 จะตรวจด้วยตัวอย่างที่คำนวณมือได้

\[ f(t,S)=e^{-r(T-t)}\mathbb E_Q[g(S_T)\mid S_t=S] \]

$f(t,S)$ คือ value วันนี้เมื่อ state เท่ากับ $S$; เฉลี่ย terminal payoff $g(S_T)$ ภายใต้ $Q$ แล้ว discount จาก $T$ กลับมาที่ $t$ ด้วย rate $r$

ขั้นที่ 3 — พิสูจน์สะพานเชื่อม Feynman–Kac จากสมบัติ martingale และ Itô's Lemma

เราไม่ยอมรับการอ้างลอย ๆ ว่าสองด้านนี้เท่ากัน แต่จะสร้างสะพานเชื่อมทีละขั้นจากนิยามของ martingale และ Itô's Lemma

ไอเดียหลักคือการนำตัวคิดลด $e^{-ru}$ ไปคูณกับราคา $f(u, S_u)$ เพื่อหักล้างการเติบโตจาก funding rate ทำให้กระบวนการที่ได้กลายเป็น martingale ที่ไม่มี drift หลงเหลืออยู่เลย

\[ \begin{aligned}M_u&=e^{-ru}f(u,S_u)=e^{-rT}\mathbb E_Q\big[g(S_T)\mid\mathcal F_u\big]\\ \mathbb E_Q\big[M_{u_2}\mid\mathcal F_{u_1}\big]&=\mathbb E_Q\Big[\mathbb E_Q\big[e^{-rT}g(S_T)\mid\mathcal F_{u_2}\big]\mid\mathcal F_{u_1}\Big]=M_{u_1}\quad(u_1\le u_2)\\ dM_u&=d\big(e^{-ru}\big)f+e^{-ru}\,df+d\big(e^{-ru}\big)\,df\\ &=-r e^{-ru}f\,du+e^{-ru}\Big[f_t\,du+f_S\,dS_u+\tfrac12 f_{S\,S}(dS_u)^2\Big]+0\\ &=-r e^{-ru}f\,du+e^{-ru}\Big[f_t\,du+f_S\big(rS_u\,du+\sigma S_u\,dW_u^Q\big)+\tfrac12\sigma^2S_u^2f_{S\,S}\,du\Big]\\ &=e^{-ru}\Big[f_t+rS_u f_S+\tfrac12\sigma^2S_u^2f_{S\,S}-rf\Big]du+e^{-ru}\sigma S_u f_S\,dW_u^Q\\ \mathbb E_Q\big[dM_u\mid\mathcal F_u\big]&=0\;\Longrightarrow\;f_t+rSf_S+\tfrac12\sigma^2S^2f_{S\,S}-rf=0\end{aligned} \]

นิยามกระบวนการ $M_u$ โดยนำ discount factor ไปคูณกับราคา มูลค่าที่คิดลดแล้วของ payoff ปลายทางเป็น martingale ภายใต้ $Q$ โดยอัตโนมัติจาก tower property เพราะค่าเฉลี่ยซ้อนค่าเฉลี่ยจะยุบเหลือค่าเฉลี่ย ณ จุดเวลาแรกเสมอ

กระจาย $dM_u$ ด้วย product rule และใช้ Itô's Lemma แยกการเปลี่ยนแปลงของ $f$ ออกมา พจน์ร่วมของตัวคิดลดกับ $df$ เป็นศูนย์เพราะ discount factor มีแต่เวลา ไม่มี Brownian shock จึงไม่มี quadratic variation ร่วม

แทน $dS_u$ ใต้ $Q$ แล้วจัดกลุ่มแยกส่วน $du$ กับส่วน $dW_u^Q$ สมบัติของ martingale บังคับให้ expected increment ในช่วงเวลาถัดไปต้องเป็นศูนย์ ทำให้ก้อนตัวคูณหน้า $du$ ต้องเท่ากับศูนย์ทุกจุดเวลา จึงได้ backward PDE ออกมาโดยไม่ต้องจำสูตร

ขั้นที่ 4 — backward equation

เขียนด้านที่เป็นสมการออกมาให้ครบ พร้อมเงื่อนไขตอนจบ ซึ่งเป็นตัวที่ล็อกคำตอบให้เหลือค่าเดียว

\[ f_t+rSf_S+\frac12\sigma^2S^2f_{S\,S}-rf=0,\qquad f(T,S)=g(S) \]

time decay $f_t$, drift contribution $rSf_S$, diffusion-curvature contribution และ discount term $-rf$ ต้องรวมเป็น 0; terminal condition บังคับ value ที่ expiry ให้เท่ากับ payoff

ที่มา: นิยามราคาจาก discounted expectation แล้วใช้ tower property ทำให้ $e^{-rt}f(t,S_t)$ เป็น martingale ใช้ Itô กับ $f$ และ product rule กับตัวคูณ $e^{-rt}$ ได้ drift เป็น $e^{-rt}[f_t+rSf_S+\sigma^2S^2f_{S\,S}/2-rf]dt$ ส่วนที่คูณ Brownian increment มีconditional expectationเป็นศูนย์

ถ้า ส่วน drift ที่คูณ dtไม่เป็นศูนย์ ค่าที่ discount แล้วจะยังเพิ่มหรือลดโดยคาดหมาย จึงขัดกับ martingale ต้องตั้งส่วน drift ทั้งก้อนเป็นศูนย์ ได้ PDE นี้ โดยต้องมีความเรียบและ integrability ที่ใช้ Itô และย้ายค่าเฉลี่ยได้ ที่ปลายเวลา $t=T$ ไม่มีเวลาค้าง จึงเหลือ payoff $g(S)$

เงื่อนไขขอบเขตและสิ่งที่พังเมื่อสมมติฐานไม่ครบ (side conditions)

สมการ Feynman–Kac ไม่ได้เป็นจริงแบบครอบจักรวาล แต่ต้องการเงื่อนไขสองข้อที่ต้องตรวจเสมอ ข้อแรกคือ integrability หรือเงื่อนไขการเติบโตของ payoff function $g(S)$ ต้องไม่โตเร็วกว่า polynomial หาก payoff โตเร็วเกินไป เช่น $e^{S^2}$ ค่าเฉลี่ยจะระเบิดเป็นอนันต์ และคำตอบของ PDE จะสูญเสียความมีอยู่หรือความเป็นหนึ่งเดียว

ข้อสองคือ stochastic integral หน้าเทอม $dW_u^Q$ ต้องเป็น true martingale ไม่ใช่เพียง local martingale หาก diffusion coefficient รุนแรงเกินไปจนเงื่อนไข square-integrability ไม่ผ่าน เช่นใน strict local martingale หรือ local volatility model ที่ diffusion ระเบิดเร็ว ค่าเฉลี่ยของส่วนสุ่มจะไม่เป็นศูนย์ ทำให้สะพาน Feynman–Kac ขาด และเกิดปรากฏการณ์ฟองสบู่ที่ราคาตลาดต่ำกว่า discounted expectation

Worked Example — โจทย์และสิ่งที่ให้มา

โจทย์ให้อะไรมาบ้าง: terminal GBM moment คำนวณตรงได้ จึงใช้ด้าน expectation เป็นคำตอบก่อน แล้วนำกลับไปตรวจสมการอีกด้าน นี่เป็น model validation ที่แรงกว่าการเชื่อ output เครื่องเดียว

ขั้นที่ 5 — second moment ใต้ Q

ลองกับตัวอย่างที่คำนวณมือได้จริง เริ่มจากหาค่าเฉลี่ยของ payoff ก่อน หกบรรทัดนี้เป็นเรื่องเดียวกับขั้นที่ 24 ถึง 25 ของหัวข้อ 1.10 ต่างแค่ชื่อของ drift และจุดเริ่มต้น จึงไม่ต้องพิสูจน์อะไรใหม่เลย

\[ \begin{aligned}S_T&=S\,e^{(r-\frac12\sigma^{2})(T-t)+\sigma\sqrt{T-t}\,Z},\qquad Z\sim\mathcal N(0,1)\\ S_T^{2}&=S^{2}e^{(2r-\sigma^{2})(T-t)+2\sigma\sqrt{T-t}\,Z}\\ \mathbb E\big[e^{aZ}\big]&=e^{a^{2}/2},\qquad a=2\sigma\sqrt{T-t}\\ \frac{a^{2}}{2}&=\frac{4\sigma^{2}(T-t)}{2}=2\sigma^{2}(T-t)\\ \mathbb E_Q\big[S_T^{2}\mid S_t=S\big]&=S^{2}e^{(2r-\sigma^{2})(T-t)}e^{2\sigma^{2}(T-t)}\\ &=S^{2}e^{(2r+\sigma^{2})(T-t)}\end{aligned} \]

สูตรราคาภายใต้น้ำหนักชุดใหม่เหมือนหัวข้อ 11.1 ทุกอย่าง ต่างแค่ drift เปลี่ยนจาก $\mu$ เป็น $r$ ตามผลของหัวข้อ 12.6 ยกกำลังสองแล้วเลขชี้กำลังคูณสองทั้งก้อน

ที่เหลือคือใช้ผลที่หัวข้อ 1.10 พิสูจน์ด้วย integral โดยตัวคูณของก้อนสุ่มคราวนี้ใหญ่ขึ้นเป็นสองเท่า พอยกกำลังสองจึงได้สี่เท่า แล้วหารสองเหลือสองเท่า

คูณสองก้อนเข้าด้วยกันแล้วรวมเลขชี้กำลัง พจน์ลบหนึ่ง $\sigma^{2}$ กับบวกสอง $\sigma^{2}$ รวมเป็นบวกหนึ่ง $\sigma^{2}$ พอดี

สังเกตว่าความเหวี่ยงโผล่มาในคำตอบด้วยเครื่องหมายบวก ทั้งที่ค่าเฉลี่ยของราคาเองไม่มีมันเลย ของที่เป็นกำลังสองจึงได้ประโยชน์จากความเหวี่ยง ซึ่งคือความโค้งในภาษาของหัวข้อ 12.2

ขั้นที่ 6 — discount เป็น closed-form value

คิดลดค่าเฉลี่ยนั้นกลับมาเป็นมูลค่าวันนี้ หกบรรทัดนี้ให้คำตอบจากด้านหนึ่ง ค่าที่สูงกว่าราคาปัจจุบันยกกำลังสองหารค่าคงที่ ไม่ใช่เรื่องแปลก เพราะ payoff โค้งขึ้น ความเหวี่ยงจึงเพิ่มมูลค่า ซึ่งเป็นเรื่องเดียวกับหัวข้อ 1.10

\[ \begin{aligned}g(S_T)&=\frac{S_T^{2}}{K}\\ \mathbb E_Q\big[g(S_T)\mid S_t=S\big]&=\frac{1}{K}\,\mathbb E_Q\big[S_T^{2}\mid S_t=S\big]\\ &=\frac{S^{2}}{K}e^{(2r+\sigma^{2})(T-t)}\\ f(t,S)&=e^{-r(T-t)}\cdot\frac{S^{2}}{K}e^{(2r+\sigma^{2})(T-t)}\\ &=\frac{S^{2}}{K}e^{(2r+\sigma^{2}-r)(T-t)}\\ &=\frac{S^{2}}{K}e^{(r+\sigma^{2})(T-t)}\end{aligned} \]

payoff ที่โจทย์เลือกเป็นกำลังสองส่วนด้วยค่าคงที่ ดึงค่าคงที่ออกนอกค่าเฉลี่ยตามกฎของหัวข้อ 1.3 แล้วแทนผลของขั้นที่ 5 ลงไปได้ทันที

คิดลดกลับมาที่วันนี้ตามนิยามในขั้นที่ 2 แล้วรวมเลขชี้กำลังของฐานเดียวกัน ตัวคิดลดหักหนึ่ง $r$ ออกไป เหลือ $r$ ตัวเดียวบวกความเหวี่ยง

นี่คือคำตอบที่ได้จากด้านค่าเฉลี่ย ขั้นถัดไปจะเดินย้อนอีกทางคือจากสมการ แล้วดูว่าได้ของเดียวกันไหม การได้คำตอบเดียวกันจากสองทางที่ไม่เกี่ยวกัน คือวิธีตรวจที่แข็งแรงที่สุดที่เรามี

ขั้นที่ 7 — derivatives สำหรับตรวจ PDE

ทีนี้ตรวจอีกด้าน โดยหา derivative ของคำตอบที่เพิ่งได้ ห้าบรรทัดนี้ไม่ได้ใช้ความน่าจะเป็นเลย มันเป็น calculus ธรรมดาล้วน ๆ และการเขียนผลกลับในรูปของ $f$ คือกลวิธีที่ทำให้ขั้นถัดไปตรวจได้ด้วยตาเปล่า

\[ \begin{aligned}f&=\frac{S^{2}}{K}e^{(r+\sigma^{2})(T-t)}\\ \frac{\partial}{\partial t}e^{(r+\sigma^{2})(T-t)}&=-(r+\sigma^{2})e^{(r+\sigma^{2})(T-t)}\\ f_t&=-(r+\sigma^{2})f\\[4pt] \frac{\partial}{\partial S}\frac{S^{2}}{K}&=\frac{2S}{K}\;\Longrightarrow\;f_S=\frac{2S}{K}e^{(r+\sigma^{2})(T-t)}=\frac{2f}{S}\\ \frac{\partial}{\partial S}\frac{2S}{K}&=\frac{2}{K}\;\Longrightarrow\;f_{S\,S}=\frac{2}{K}e^{(r+\sigma^{2})(T-t)}=\frac{2f}{S^{2}}\end{aligned} \]

เอาคำตอบของขั้นที่ 6 มาหา derivative ทั้งสามตัวที่สมการต้องใช้ เริ่มจากเทียบเวลา เครื่องหมายลบมาจากกฎลูกโซ่ เพราะเวลาที่เหลือลดลงเมื่อเวลาเดินหน้า

กลเม็ดที่ทำให้ขั้นนี้เบาลงมากคือการเขียนผลกลับในรูปของ $f$ เอง แทนที่จะลาก exponential ยาว ๆ ไปทุกบรรทัด ทำได้เพราะทุก derivative ยังมีก้อน exponential เดิมติดอยู่ครบ

เทียบราคาก็เช่นกัน ส่วนที่ขึ้นกับเวลาเป็นตัวคูณคงที่จึงติดมาทั้งก้อน ทำสองครั้งได้ค่าคงที่ แล้วเขียนกลับในรูปของ $f$ เหมือนเดิม

สามผลนี้จะถูกแทนลงในสมการของขั้นที่ 4 เพื่อดูว่ามันหักกันเป็นศูนย์จริงหรือไม่

ขั้นที่ 8 — terms หักล้าง

แทน derivatives ลงใน PDE ทีละพจน์เพื่อตรวจดูว่าสมการเป็นจริงทุกจุดเวลาและทุกระดับราคาจริงหรือไม่

ความมหัศจรรย์ของแบบจำลองกำลังสองนี้คือ ราคาสินทรัพย์ $S$ จะตัดกันหมดพอดีในทุกพจน์ ทำให้เหลือเพียงการบวกเลขของอัตราดอกเบี้ยและความผันผวน

\[ \begin{aligned}\text{LHS}&=f_t+rSf_S+\tfrac12\sigma^2S^2f_{S\,S}-rf\\ &=-(r+\sigma^2)f+rS\Big(\frac{2f}{S}\Big)+\tfrac12\sigma^2S^2\Big(\frac{2f}{S^2}\Big)-rf\\ &=-(r+\sigma^2)f+2rf+\sigma^2f-rf\\ &=\big[-(r+\sigma^2)+2r+\sigma^2-r\big]f\\ &=(-r+2r-r-\sigma^2+\sigma^2)f=0=\text{RHS}\end{aligned} \]

นำ partial derivatives ทั้งหมดที่หาไว้ในขั้นก่อนหน้ามาแทนลงในด้านซ้ายของ PDE ทีละพจน์

สังเกตว่า $S$ ตัดกับ $1/S$ ในพจน์ delta และ $S^2$ ตัดกับ $1/S^2$ ในพจน์ gamma ทำให้ตัวแปรราคา $S$ หายไปหมด เหลือเพียงตัวคูณคงที่หน้า $f$

เมื่อดึงตัวร่วม $f$ ออกมา ก้อนตัวคูณของ funding rate คือ $-r + 2r - r = 0$ และก้อนของ volatility คือ $-\sigma^2 + \sigma^2 = 0$ หักล้างกันหมดเกลี้ยงเป็นศูนย์ ยืนยันว่า closed form ที่ได้จากการคำนวณ expectation แก้ PDE ย้อนเวลาได้อย่างสมบูรณ์แบบ

ขั้นที่ 9 — ใช้กรณี note มูลค่า 200 USD

แปลผลลัพธ์กลับเป็นเงินจริงของโจทย์

\[ f(0,200)=\frac{200^2}{200}e^{(0.04+0.30^2)}=\$227.77,\quad \Delta=\frac{2f}{S}=2.2777,\quad \Gamma=\frac{2f}{S^2}=0.01139 \]

ใช้ spot และ normalization 200 USD/share, rate 4%, volatility 30% และ maturity 1 ปี ได้ note value 227.77 USD, delta 2.2777 shares และ gamma 0.01139 share ต่อ USD

ขั้นที่ 10 — expose shortcut ที่ผิด

ปิดท้ายด้วยทางลัดที่คนใช้ผิดบ่อยที่สุด คือเอาค่าเฉลี่ยของตัวแปรไปเข้าสูตรแทน การหาค่าเฉลี่ยของผลลัพธ์ สองอย่างนี้ไม่เท่ากัน

\[ e^{-0.04}\frac{(\mathbb E_Q[S_1])^2}{200}=\$200e^{0.04}=\$208.16,\qquad \frac{227.77}{208.16}-1=e^{0.30^2}-1=9.42\% \]

เอา risk-neutral mean price ไป square ก่อนให้ value 208.16 USD; average ของ convex payoff ที่ถูกสูงกว่า 9.42% เพราะ shortcut ลบ variance ของ terminal price ทิ้ง

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

การที่ราคาหาได้สองทางและต้องเท่ากัน ให้เครื่องมือตรวจงานที่ทรงพลังมาก

ใช้เลือกวิธีคำนวณให้เหมาะกับปัญหา บางสัญญาแก้สมการเร็วกว่า บางสัญญาสุ่มเร็วกว่า

ใช้ตรวจงานข้ามวิธี ถ้าโค้ดสองแบบให้คำตอบไม่ตรงกัน แปลว่าอย่างน้อยหนึ่งอันผิด ซึ่งเป็นวิธีจับบั๊กที่ดีที่สุดในงานตั้งราคา

ใช้เป็นสะพานระหว่างบทที่แล้วกับบทที่ 13 และ 21 ที่ใช้ทั้งสองวิธี

คำตอบ ตรวจเอง และแปลว่าอะไร

คำตอบและความหมาย: analytic value และ grid target คือ \$227.77; Monte Carlo ควรครอบเลขนี้ด้วย confidence interval เมื่อใช้ dynamics, discounting และ payoff เดียวกัน ความต่างเกิน sampling error ให้ตรวจ time convention, terminal payoff units และ discount factor ก่อนกล่าวโทษ random seed

ตรวจเองใน 10 วินาที: กด $200e^{0.04+0.09}$ ต้องได้ประมาณ 227.77 USD; shortcut ที่ได้ 208.16 ต่ำไปราว 19.61 USD. ใช้เทียบ PDE grid กับ Monte Carlo ก่อนรับราคา note.

กับดัก: ใส่ price drift แทน funding rate

Feynman–Kac สำหรับ no-arbitrage pricing ใช้ risk-neutral generator ไม่ใช่ forecast drift มุกที่ช่วยจับ bug คือถ้า bullish view ทำให้ vanilla option library เปลี่ยนราคา คุณไม่ได้เพิ่ม alpha—คุณถอด replication ออกจาก model แล้ว

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
เงื่อนไขที่ต้องจริงสองทางให้คำตอบเดียวกันเสมอต้องมีเงื่อนไขทางเทคนิคหลายข้อในกรณีที่ payoff โตเร็วมาก ความเท่ากันอาจไม่จริง
ความเร็วเลือกทางไหนก็ได้การสุ่มช้ามากเมื่อต้องการความแม่นสูงการเพิ่มความแม่นสองเท่าต้องเพิ่มงานสี่เท่า
มิติใช้ได้ทุกจำนวนมิติการแก้สมการช้าลงมากเมื่อมิติเพิ่มเกินสามมิติมักต้องหันไปใช้การสุ่มแทน

แถวล่างคือกฎหลักในการเลือกวิธี คือดูจำนวนมิติของปัญหาเป็นอันดับแรก
