20.6 Defaultable Bonds, Hazard Rates, and Survival

พันธบัตรเอกชนจ่ายคูปองและเงินต้นเฉพาะเมื่อผู้ออกยังไม่ผิดนัด และจ่ายเงินคืนบางส่วนเมื่อผิดนัด ราคาจึงเป็นเงินแต่ละก้อนคูณโอกาสที่มันจะมาจริง แล้วคิดลดตามวันที่มันมา

หุ้นกู้เอกชนอายุ 5 ปี หน้าตั๋ว \$10,000,000 คูปอง 5% ต่อปี อัตราไร้ความเสี่ยง 4.5% ต่อปี (ทบต่อเนื่อง) อัตราผิดนัด (hazard rate) คงที่ 1.8% ต่อปี ถ้าผิดนัดได้คืน 40% ของหน้าตั๋วทันที (ตัวเลขสมมติ) พันธบัตรเดียวกันที่ไม่มีทางผิดนัดราคา \$10,173,877.69 เพื่อนคิดว่าห้าปีมีโอกาสผิดนัด $5(1.8\%)=9\%$ เสียเงิน 60% ของหน้าตั๋ว จึงหักไป $0.09(0.6)(10^7)=\$540{,}000$ ได้ \$9,633,877.69 ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก ราคาที่ถูกคือ \$9,684,390.68 เพื่อนต่ำไป \$50,512.99 เพราะพลาดสองเรื่อง โอกาสผิดนัดห้าปีคือ $1-e^{-0.09}=8.6069\%$ ไม่ใช่ 9% เพราะคนที่ผิดนัดไปแล้วผิดนัดซ้ำไม่ได้ และความเสียหายเกิดในอนาคต จึงต้องคิดลด ต้องแยกคิดสามบัญชี: คูปองที่ได้เมื่อรอด \$2,077,689.22 เงินต้นที่ได้เมื่อรอดถึงปีที่ 5 \$7,297,888.74 และเงินคืนเมื่อผิดนัด \$308,812.72

ภาพรวมก่อนลงสูตร

ทุกหน้าก่อนหน้านี้สมมติว่าเงินที่สัญญาไว้จ่ายครบแน่นอน หน้านี้เพิ่มความเป็นไปได้ที่ผู้ออกหยุดจ่าย (default หรือผิดนัด) มีสองวิธีคิด วิธี structural ของ Merton มองว่าบริษัทผิดนัดเมื่อมูลค่าสินทรัพย์ต่ำกว่าหนี้ แต่มูลค่าสินทรัพย์มองไม่เห็น วิธีของหน้านี้คือ reduced-form: เลิกถามว่าทำไมบริษัทผิดนัด บอกแค่ว่ามันผิดนัดด้วยอัตราเท่าไรต่อปีของคนที่ยังรอด (hazard rate) แล้วให้ราคาตลาดบอกตัวเลขนั้น

พอมีโอกาสรอดถึงแต่ละวัน การตั้งราคาก็ง่าย: คูปองและเงินต้นมาเฉพาะในโลกที่ยังรอด จึงคูณด้วยโอกาสรอด เงินคืนมาเฉพาะในปีที่ผิดนัด จึงคูณด้วยโอกาสผิดนัดในปีนั้น แล้วคิดลดทุกก้อนด้วย discount factor ของวันที่มันมา รูปด้านล่างวาดเส้นทางทั้งหมดของพันธบัตรในโจทย์เปิดหน้า

หน้านี้จะสร้างโอกาสรอดจากการนับผู้รอด เขียนราคาเป็นสามบัญชี เทียบกับพันธบัตรไร้ความเสี่ยง ได้สูตรลัดของ credit spread วัดความไว ใส่การผิดนัดลงในต้นไม้ของอัตรา แล้วแกะ hazard จากราคาพันธบัตรห้าตัวของบริษัทเดียวกัน

ขั้นที่ 1 — นับผู้รอด: จาก hazard ถึงโอกาสรอด

เริ่มจากตัวเลขที่จับต้องได้ ลูกหนี้ 10,000 รายที่ยังไม่ผิดนัด hazard 1.8% ต่อปี หนึ่งเดือนคาดว่าผิดนัด $10{,}000(0.018)/12=15$ ราย เดือนถัดไปนับจากคนที่เหลือ 9,985 ราย ไม่ใช่ 10,000 เขียนการนับนี้เป็นสัดส่วน $Q(t)$ ของผู้ที่ยังรอด แล้วให้ช่วงเวลาสั้นลง

\[ \begin{aligned} Q(t+\Delta t)&\approx Q(t)\,\big[1-\lambda(t)\Delta t\big],\\ \frac{dQ}{dt}&=-\lambda(t)\,Q(t),\\ \frac{d\ln Q}{dt}&=-\lambda(t),\\ Q(T)&=e^{-\int_0^T\lambda(u)\,du}. \end{aligned} \]

แถวแรกคือนิยามของ hazard: ในช่วงสั้น $\Delta t$ ผู้รอดหายไปสัดส่วน $\lambda\Delta t$ ของผู้ที่ยังรอด ลบ $Q(t)$ แล้วหารด้วย $\Delta t$ ได้อนุพันธ์ หารด้วย $Q$ ให้เป็นอนุพันธ์ของ log แล้วอินทิเกรตจาก 0 โดย $Q(0)=1$ ได้รูปเดียวกับการทบต้นต่อเนื่อง ต่างแค่สิ่งที่หดคือผู้รอด ไม่ใช่เงินที่โต

ทั้งหมดนี้อยู่ใต้ $\mathbb Q$ ของการตั้งราคา hazard ที่แกะจากราคาตลาดรวมค่าชดเชยความเสี่ยงไว้แล้ว ถ้าจะพยากรณ์การผิดนัดจริงต้องประมาณแยกจากข้อมูลย้อนหลัง

ขั้นที่ 2 — hazard คงที่: โอกาสรอด และโอกาสผิดนัดในแต่ละช่วง

ถ้า $\lambda$ คงที่ อินทิเกรตเหลือ $\lambda T$ ได้ปริมาณที่ต้องใช้ต่อสามตัว ตัวที่สามคือโอกาสผิดนัดในปีที่ $i$ พอดี ซึ่งต้องใช้ถ่วงเงินคืน ในไฟล์คำนวณที่เดินเป็นงวด ใช้โอกาสต่องวด $h$ แทน $\lambda$ แล้วคูณ $1-h$ ทีละงวด

\[ \begin{aligned} Q(T)&=e^{-\lambda T},\\ F(T)&=1-e^{-\lambda T},\\ Q(i-1)-Q(i)&=e^{-\lambda(i-1)}\big(1-e^{-\lambda}\big),\\ Q(5)&=e^{-0.09}=0.913931,\\ F(5)&=0.086069,\\ Q(0)-Q(1)&=1-e^{-0.018}=0.01784,\\ Q_k&=(1-h)^k,\\ Q_{k-1}-Q_k&=Q_{k-1}\,h. \end{aligned} \]

ห้าปีมีโอกาสผิดนัด 8.6069% ไม่ใช่ $5(1.8\%)=9\%$ เพราะผู้ที่ผิดนัดแล้วผิดนัดซ้ำไม่ได้ ฐานผู้รอดจึงหดลงทุกปี เวลาผิดนัดจึงเป็น Exponential distribution ซึ่งมีสมบัติไม่จำอดีต: รอดมากี่ปีก็มีอัตราผิดนัดเท่าเดิม เป็นทั้งความง่ายและข้อจำกัดของการเลือก hazard คงที่

สองแถวล่างคือรุ่นที่เดินเป็นงวด ที่ $h=2\%$ ต่องวด โอกาสรอดคือ 0.98, 0.9604 และ 0.941192 ในงวดที่ 1 ถึง 3 และโอกาสผิดนัดในแต่ละงวด $Q_{k-1}h$ คือ 0.02, 0.0196 และ 0.019208 ลดลงทุกงวดทั้งที่ $h$ คงที่ ด้วยเหตุผลเดียวกัน รูปด้านล่างวาดทั้งสองอย่างคู่กัน

ขั้นที่ 3 — ราคาเป็นสามบัญชี แยกตามเหตุการณ์ที่ทำให้ได้เงิน

เงินแต่ละก้อนมีเงื่อนไขของมัน: คูปองวันที่ $t_k$ ได้ก็ต่อเมื่อรอดถึง $t_k$ คือ $cI(t_k)$ เงินต้นได้เมื่อรอดถึงวันครบกำหนด คือ $FI(t_n)$ เงินคืนได้เมื่อผิดนัดในงวดที่ $k$ คือ $RF\,(I(t_{k-1})-I(t_k))$ ซึ่งเป็น 1 เฉพาะงวดที่เพิ่งผิดนัด ราคาคือค่าเฉลี่ยใต้ $\mathbb Q$ ของเงินทั้งหมดหารด้วยบัญชีเงินสด เมื่อสมมติว่าการผิดนัดไม่เกี่ยวกับอัตราดอกเบี้ย ค่าเฉลี่ยของผลคูณจึงแยกเป็นผลคูณของค่าเฉลี่ย: $\mathbb E[I(t)]=Q(t)$ และค่าเฉลี่ยของการคิดลดคือ $d(0,t)$

\[ \begin{aligned} \bar P&=\sum_{k=1}^{n}c\,Q(t_k)\,d(0,t_k)\\ &\quad+F\,Q(t_n)\,d(0,t_n)\\ &\quad+RF\sum_{k=1}^{n}\big(Q(t_{k-1})-Q(t_k)\big)d(0,t_k),\\ PV_{\rm cpn}&=\sum_{i=1}^{T}Nc\,e^{-(r+\lambda)i},\\ PV_{\rm prin}&=N\,e^{-(r+\lambda)T},\\ PV_{\rm rec}&=RN\int_0^Te^{-rt}\,\lambda e^{-\lambda t}\,dt\\ &=RN\frac{\lambda}{r+\lambda}\big(1-e^{-(r+\lambda)T}\big). \end{aligned} \]

สามแถวแรกคือสูตรทั่วไปแบบงวด ใช้ได้กับ curve ใด ๆ และ hazard ที่เปลี่ยนตามงวด แถวที่เหลือคือกรณี $r$ และ $\lambda$ คงที่ เงินคืนจ่าย ณ วันผิดนัดจริง: ผลรวมของงวดกลายเป็นอินทิเกรต โดยโอกาสผิดนัดในช่วงสั้น $dt$ คือ density $\lambda e^{-\lambda t}\,dt$

$e^{-rt}e^{-\lambda t}=e^{-(r+\lambda)t}$ คือหัวใจของหน้านี้: เงินที่จ่ายเมื่อรอดถูกคิดลดด้วยอัตรา $r+\lambda$ โอกาสผิดนัดจึงทำตัวเหมือนดอกเบี้ยส่วนเพิ่ม นี่คือเหตุที่ตลาดพูดถึงความเสี่ยงเครดิตเป็นส่วนต่างของอัตรา ในบัญชีที่สาม $\lambda/(r+\lambda)$ คูณ $1-e^{-(r+\lambda)T}$ คือโอกาสผิดนัดก่อนครบกำหนดที่คิดลดแล้ว ถ้าเอาเงินคืนไปรวมกับเงินต้นที่ปีที่ 5 จะนับเวลาผิด

ขั้นที่ 4 — คำตอบของโจทย์เปิดหน้า

โจทย์ให้อะไรมาบ้าง: $N=\$10{,}000{,}000$ $c=5\%$ ($Nc=\$500{,}000$) $r=4.5\%$ $\lambda=1.8\%$ $R=40\%$ $T=5$ ปี อัตราคิดลดรวม $r+\lambda=6.3\%$ ตัวคิดลดห้าปีคือ 0.938943, 0.881615, 0.827787, 0.777245 และ 0.729789

\[ \begin{aligned} PV_{\rm cpn}&=500{,}000(4.155378)\\ &=2{,}077{,}689.22,\\ PV_{\rm prin}&=10^7(0.729789)\\ &=7{,}297{,}888.74,\\ PV_{\rm rec}&=4\times10^6\Big(\frac{0.018}{0.063}\Big)\\ &\quad\times(0.270211)\\ &=308{,}812.72,\\ P_{\rm def}&=9{,}684{,}390.68. \end{aligned} \]

คำตอบ: ราคา \$9,684,390.68 หรือ 96.8439 ต่อหน้าตั๋ว 100 คูปองห้างวดคิดลดแล้วคือ \$469,471.74, \$440,807.42, \$413,893.25, \$388,622.37 และ \$364,894.44 เงินคืนเป็นก้อนเล็กที่สุดเพราะโอกาสผิดนัดในห้าปีมีแค่ 8.6% และได้คืนแค่ 40%

ตรวจเองใน 10 วินาที: $4.155378$ คือผลบวกของตัวคิดลดห้าตัว $0.270211=1-0.729789$ และ $0.018/0.063=0.285714$

ขั้นที่ 5 — เทียบกับพันธบัตรที่ไม่ผิดนัด และ yield

พันธบัตรเดียวกันที่ไม่มีทางผิดนัดคิดลดด้วย $r$ อย่างเดียว ส่วนต่างของราคาคือสิ่งที่ตลาดหักไว้เพราะความเสี่ยงเครดิต แล้วแปลงราคาเป็น yield แบบที่ตลาด quote (ทบปีละครั้ง) ด้วย bisection แบบเดียวกับการหา yield ในหน้า yield curve และ duration

\[ \begin{aligned} P_{\rm rf}&=2{,}188{,}715.50\\ &\quad+7{,}985{,}162.19\\ &=10{,}173{,}877.69,\\ P_{\rm rf}-P_{\rm def}&=489{,}487.01,\\ y_{\rm def}&=5.744035\%,\\ y_{\rm rf}&=e^{0.045}-1=4.6028\%. \end{aligned} \]

ส่วนต่าง \$489,487.01 ไม่เท่ากับความเสียหายที่คาดแบบง่าย $0.086069(0.6)(10^7)=\$516{,}412.89$ วิธีหักตรง ๆ แบบนี้ได้ \$9,657,464.80 ยังต่ำไป \$26,925.87 เพราะความเสียหายเกิดในอนาคตจึงต้องคิดลด และเมื่อผิดนัดก็ได้เงินคืนเร็วกว่ารอถึงปีที่ 5

รูปด้านล่างแยกสองราคาเป็นบัญชี: คูปองหายไป \$111,026.28 เงินต้นหายไป \$687,273.45 และเงินคืนเติมกลับ \$308,812.72 yield 5.744% เป็นอัตราเดียวที่ยุบเงินทุกก้อนให้เท่าราคา ไม่ใช่ hazard และไม่ได้แยก recovery หรือเวลา ต่างจาก yield ไร้ความเสี่ยง 114.1 bp เมื่อ quote ทบปีละครั้ง

ขั้นที่ 6 — สูตรลัด: credit spread ≈ hazard × loss given default

คนในตลาดแปลงไปมาระหว่าง spread กับ hazard ด้วยสูตรบรรทัดเดียว มาจากพันธบัตรหนึ่งปี: รอดได้ \$1 ผิดนัดได้ $R$ ใช้ Taylor อันดับหนึ่งกับ $e^{-\lambda}\approx1-\lambda$ แล้วใช้ $1-x\approx e^{-x}$ กลับ

\[ \begin{aligned} \tilde P&=e^{-r}\big[e^{-\lambda}+(1-e^{-\lambda})R\big]\\ &\approx e^{-r}\big[1-\lambda(1-R)\big]\\ &\approx e^{-(r+\lambda(1-R))},\\ s&\approx\lambda(1-R)\\ &=0.018(0.60)=108\ \text{bp}. \end{aligned} \]

อ่านว่า spread คือ “อัตราที่เสียต่อปี” = โอกาสผิดนัดต่อปีคูณส่วนที่เสียเมื่อผิดนัด ตรวจกับพันธบัตรห้าปี: yield ทบต่อเนื่องที่ให้ราคา \$9,684,390.68 คือ 5.5851% ส่วนต่างจาก 4.5% คือ 108.51 bp ใกล้ 108 bp มาก ถ้าคิดลดทุกก้อนด้วย $4.5\%+1.08\%$ ได้ \$9,686,642.11 สูงไปแค่ \$2,251.43 สูตรลัดดีเมื่อ hazard เล็ก แต่ไม่ใช่เครื่องตั้งราคา: มันไม่แยกเวลาของเงินคืน สภาพคล่อง หรือคูปองที่ต่างกัน

ขั้นที่ 7 — credit01: ขยับ hazard 1 bp แล้วคิดราคาใหม่

โต๊ะเครดิตถามว่าถ้าเครดิตแย่ลงนิดเดียวจะเสียเท่าไร ขยับ $\lambda$ จาก 1.8% เป็น 1.81% คงอย่างอื่นไว้ แล้วคิดราคาใหม่ทั้งสามบัญชี ทำแบบเดียวกันกับพันธบัตรอายุ 1 ถึง 10 ปี

\[ \begin{aligned} P(0.0181)&=9{,}681{,}787.65,\\ \mathrm{Credit01}&=9{,}681{,}787.65\\ &\quad-9{,}684{,}390.68\\ &=-2{,}603.02. \end{aligned} \]

ผู้ถือเสีย \$2,603.02 ต่อ hazard 1 bp เทียบกับ DV01: ขยับ $\lambda$ ขยับอัตราคิดลดของคูปองและเงินต้นเหมือนขยับ $r$ แต่โอกาสได้เงินคืนเพิ่มขึ้นด้วย จึงเสียน้อยกว่าการขยับ $r$ 1 bp ซึ่งเสีย \$4,318.24 พันธบัตร 1, 5 และ 10 ปีมี credit01 \$601.65, \$2,603.02 และ \$4,386.60 โตตามอายุแต่ช้าลงเรื่อย ๆ

ขั้นที่ 8 — ใส่การผิดนัดลงในต้นไม้ของอัตรา

ถ้าอยากให้การผิดนัดสัมพันธ์กับระดับอัตรา ต้องใส่มันลงในต้นไม้ short rate แยกทุกจุด $(i,j)$ เป็นสองสถานะ: ยังไม่ผิดนัด และผิดนัดแล้ว จากจุดที่ยังไม่ผิดนัด แต่ละกิ่ง (ขึ้นด้วย $q_u$ ลงด้วย $q_d$) แตกอีกทีเป็นรอดด้วย $1-h_{ij}$ และผิดนัดด้วย $h_{ij}$ สถานะผิดนัดเข้าแล้วออกไม่ได้ zero ที่จ่าย \$1 เมื่อรอดถึงวันครบกำหนด และ $R$ ตอนสิ้นงวดที่ผิดนัด ตีราคาย้อนแบบเดิม

\[ \begin{aligned} \bar Z_{i,j}&=\frac{1-h_{ij}}{1+r_{ij}}\big[q_u\bar Z_{i+1,j+1}\\ &\qquad+q_d\bar Z_{i+1,j}\big]+\frac{h_{ij}R}{1+r_{ij}},\\ R=0&:\ \frac{1-0.02}{1.05}=0.933333,\\ e^{-(0.05+0.02)}&=0.932394,\\ R=0.4&:\ 0.933333+\frac{0.008}{1.05}\\ &\qquad=0.940952. \end{aligned} \]

ก้อนแรกคือทางรอด ต้องรอดด้วย $1-h_{ij}$ ก่อนจึงได้ค่าของงวดหน้า ก้อนที่สองคือทางผิดนัด ได้ $R$ ตอนสิ้นงวด (เพราะ $q_u+q_d=1$ จึงเหลือ $h_{ij}R$) ทั้งสองคิดลดด้วย $1+r_{ij}$ ตัวอย่างหนึ่งงวดที่ $r=5\%$ และ $h=2\%$: ถ้าไม่มีเงินคืน ราคาเกือบเท่า $e^{-(r+h)}$ (ต่างกัน 0.0009) $h_{ij}$ จึงทำหน้าที่เป็น credit spread ของหนึ่งงวด ตรงกับการคิดลดด้วย $r+\lambda$ ในขั้นสามบัญชี

$h_{ij}$ ขึ้นกับจุดได้ คือการผิดนัดสัมพันธ์กับระดับอัตรา ส่วนพันธบัตรไร้ความเสี่ยงมีราคาเท่ากันทั้งสองสถานะ จึง calibrate ต้นไม้อัตรากับราคาพันธบัตรรัฐบาลได้เหมือนเดิมก่อน แล้วค่อยแกะ $h$ จากราคาพันธบัตรเอกชน

ขั้นที่ 9 — hazard ไม่ขึ้นกับจุด: พันธบัตร 1 ปีทีละช่อง

โจทย์ให้อะไรมาบ้าง: ถ้า $h_{ij}=h_i$ การผิดนัดไม่เกี่ยวกับอัตรา จึงใช้สูตรสามบัญชีแบบงวดได้เลย ตัวเลขชุดนี้มาจาก workbook ของคอร์ส: อัตรา 5% ทบครึ่งปี $h=2\%$ ต่อครึ่งปี พันธบัตร 1 ปีจ่ายคูปอง 5 ต่อครึ่งปี (หน้าตั๋ว 100) ผิดนัดได้คืน 10 ตอนสิ้นงวด

\[ \begin{aligned} d(0,0.5)&=1/1.025=0.975610,\\ d(0,1)&=1/1.025^2=0.951814,\\ \bar P&=0.975610\big[5(0.98)\\ &\qquad+10(0.02)\big]\\ &\quad+0.951814\big[105(0.9604)\\ &\qquad+10(0.0196)\big]\\ &=4.975610+96.169423\\ &=101.145033. \end{aligned} \]

คำตอบ: 101.145033 ในวงเล็บแรกคืองวดแรก รอดได้คูปอง 5 ผิดนัดได้ 10 ในวงเล็บที่สองคืองวดสุดท้าย รอดได้ 105 และโอกาสผิดนัดในงวดนี้คือ $0.98(0.02)=0.0196$ ไม่ใช่ 0.02 พันธบัตรอีกสี่ตัวใช้สูตรเดียวกันแค่ยาวขึ้น ได้ 92.548108, 107.346606, 104.023189 และ 145.815844 (ตารางข้างล่าง)

ตรวจเองใน 10 วินาที: $0.975610(5.1)=4.9756$ และ $0.951814(100.842+0.196)=96.169$ รวม 101.145

ขั้นที่ 10 — แกะ hazard จากราคาพันธบัตรห้าตัว

พันธบัตรทุกตัวออกโดยบริษัทเดียว การผิดนัดครั้งเดียวทำให้ทุกตัวผิดนัดพร้อมกัน จึงใช้ hazard ชุดเดียว ให้ hazard คงที่ในแต่ละปี (สองงวดครึ่งปีเท่ากัน) แล้วหาชุดที่ไม่ติดลบซึ่งทำให้ราคาแบบจำลองใกล้ราคาตลาดที่สุด ห้าตัวกับห้าปีพอดี จึงแกะได้ตรงทีละตัวจากสั้นไปยาวแบบเดียวกับbootstrapping ของ zero rate

\[ \begin{aligned} f(h)&=\sum_{i=1}^{5}\big(P_i^{\rm mkt}-P_i(h)\big)^2,\\ P_1(h_1)&=101.188179,\\ h_1&=1.9763\%,\\ P_2(h_1,h_2)&=92.549107,\\ h_2&=2.0239\%,\\ h_3,\ h_4,\ h_5&=1.8944,\ 2.0782,\\ &\qquad2.0102\%. \end{aligned} \]

พันธบัตร 1 ปีขึ้นกับ $h_1$ อย่างเดียว แก้ด้วย bisection พันธบัตร 2 ปีใช้ $h_1$ ที่ได้แล้วแก้ $h_2$ ต่อไปเรื่อย ๆ ได้ $f=0$ ทุกราคาตรง สัญญาณรบกวนไม่เกิน 0.1 ในราคาทำให้ hazard ห่างจาก 2% ได้ถึง 0.11 จุด (ปีที่ 3) พันธบัตรที่เงินคืนสูง (50) ไวต่อ hazard น้อย ราคาที่คลาดนิดเดียวจึงกลายเป็น hazard ที่คลาดมาก

workbook เก็บคำตอบของ Solver ไว้ที่ 2.0141, 1.9443, 1.9977, 2.0124 และ 1.9476% พร้อม $f=0.014950$ ไม่ใช่ศูนย์ เพราะราคาตลาดสร้างด้วยคำสั่งสุ่มของ Excel ซึ่งสุ่มใหม่ทุกครั้งที่ไฟล์คำนวณ Solver จึงเห็นราคาอีกชุด บทเรียนคือตรึงข้อมูลก่อน calibrate

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

คูณ hazard ด้วยจำนวนปี: $5(1.8\%)=9\%$ แทน 8.6069% แล้วหักความเสียหายจากราคาไร้ความเสี่ยงตรง ๆ ได้ \$9,633,877.69 ต่ำไป \$50,512.99

หักความเสียหายที่คาดโดยไม่คิดลด: ใช้ 8.6069% ที่ถูกแล้วแต่ไม่คิดเวลา ได้ \$9,657,464.80 ยังต่ำไป \$26,925.87

ใช้โอกาสผิดนัดต่องวดเท่ากันทุกงวด: ที่ $h=2\%$ งวดที่สองผิดนัดจริง 1.96% ไม่ใช่ 2% ถ้าใช้ 0.02 ทุกงวดและให้โอกาสรอดเป็น 0.96 พันธบัตร 1 ปีจะได้ $0.951814[105(0.96)+10(0.02)]+4.975610=101.11$ แทน 101.145 (ต้องใช้ 0.9604 และ 0.0196)

สลับ hazard ใต้ $\mathbb Q$ กับอัตราผิดนัดที่เกิดจริง: ใช้อัตราผิดนัดย้อนหลังตั้งราคาได้ราคาสูงเกินไป ใช้ hazard จากราคาตลาดพยากรณ์ความเสียหายได้ตัวเลขแย่เกินจริง

ไม่บอกว่า recovery เป็นสัดส่วนของอะไร: หน้านี้ใช้ 40% ของหน้าตั๋วจ่ายทันทีที่ผิดนัด บางแบบจำลองใช้ 40% ของมูลค่าพันธบัตรก่อนผิดนัด (recovery of market value) ซึ่งให้สมการราคาต่างกัน ต้องประกาศทุกครั้ง

เชื่อ hazard รายปีจากราคาที่มีสัญญาณรบกวน: ราคาคลาดไม่เกิน 0.1 ทำให้ hazard ปีที่ 3 เหลือ 1.8944% ทั้งที่ของจริงคือ 2%

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะเครดิตแกะ hazard เป็นช่วงอายุจากพันธบัตรหรือ CDS ของผู้ออกรายเดียวกันบน curve ไร้ความเสี่ยงที่ตรึงไว้ ตรวจว่าทุกตราสารคิดราคากลับได้และโอกาสรอดไม่เพิ่มตามเวลา แล้วขยับ quote ทีละตัวเพื่อดู credit01 แยกตามอายุ แยกความเสี่ยงอัตราดอกเบี้ย (DV01) ออกจากความเสี่ยงเครดิต พันธบัตรเอกชนต่างกันเรื่องลำดับการชำระหนี้ สภาพคล่อง ภาษี และสิทธิ์ไถ่ถอนก่อน จึงมักต้อง fit แบบถ่วงน้ำหนักมากกว่าแกะทีละตัว

ข้อจำกัดที่ต้องจำ: hazard คงที่เป็นช่วงไม่ตามวัฏจักรเศรษฐกิจ การผิดนัดที่สมมติว่าไม่เกี่ยวกับอัตราดอกเบี้ยพลาดในช่วงวิกฤตที่ทั้งสองเปลี่ยนพร้อมกัน recovery จริงต่ำที่สุดตอนที่ผิดนัดกันมาก และ spread ที่เห็นรวมสภาพคล่องกับภาษีไว้ด้วย hazard ที่แกะได้จึงมักสูงกว่าความเสี่ยงผิดนัดจริง

1. zero-coupon bond ห้าปีของผู้ออกเดียวกัน (ไม่มีคูปอง ไม่มีเงินคืน) หน้าตั๋ว \$1,000,000 ราคาเท่าไร และ yield ส่วนเกินเท่าไร?

เฉลย

$10^6e^{-(0.045+0.018)5}=10^6(0.729789)=\$729{,}788.87$ yield ทบต่อเนื่อง $-\ln(0.729789)/5=6.3\%$ ส่วนเกิน 180 bp เท่ากับ hazard พอดี เพราะไม่มีเงินคืน ($R=0$ ในสูตรลัด $\lambda(1-R)$)

2. ถ้า recovery ของหุ้นกู้ในโจทย์เปิดหน้าเป็น 60% แทน 40% ราคาเป็นเท่าไร?

เฉลย

สองบัญชีแรกเท่าเดิม บัญชีเงินคืนโตตาม $R$: $308{,}812.72(0.6/0.4)=463{,}219.07$ ราคา $2{,}077{,}689.22+7{,}297{,}888.74+463{,}219.07=\$9{,}838{,}797.04$ หรือ 98.388 ต่อ 100 ตรงกับเส้น recovery 60% ในรูป hazard กับ recovery ด้านบนที่ hazard 1.8%

3. ถ้าตลาดบอกว่า spread ของพันธบัตรนี้คือ 150 bp และเชื่อว่า recovery 40% hazard โดยประมาณเป็นเท่าไร และโอกาสผิดนัดห้าปีเท่าไร?

เฉลย

$\lambda\approx s/(1-R)=0.015/0.6=2.5\%$ ต่อปี โอกาสผิดนัดห้าปี $1-e^{-0.125}=11.75\%$ ถ้าเชื่อ recovery 20% แทน จะได้ $\lambda\approx0.015/0.8=1.875\%$ และ $1-e^{-0.09375}=8.95\%$ ตัวเลขโอกาสผิดนัดจึงขึ้นกับ recovery ที่สมมติ spread บอกแค่ผลคูณ $\lambda(1-R)$

เปิดดูโค้ด

โค้ดนี้คิดโอกาสรอดและโอกาสผิดนัด ราคาสามบัญชีแบบ hazard คงที่ ราคาไร้ความเสี่ยง yield ด้วย bisection spread ทบต่อเนื่อง credit01 ตามอายุ ตัวอย่างต้นไม้หนึ่งงวด ราคาพันธบัตรห้าตัวใน workbook และแกะ hazard ทีละตัว แล้วพิมพ์ตัวเลขหลักหนึ่งบรรทัด

const {exp, log} = Math;

function check(x, name, lo = 0, hi = Infinity) {
  if (!Number.isFinite(x) || x < lo || x > hi) throw new RangeError(`${name} must be a number between ${lo} and ${hi}`);
  return x;
}
// Constant hazard lambda, constant rate r (both continuous), recovery R of par paid at default.
function riskyBond({N, c, r, lambda, R, T}) {
  check(N, 'face', 1e-9); check(lambda, 'hazard'); check(R, 'recovery', 0, 1);
  if (!Number.isInteger(T) || T < 1) throw new RangeError('maturity must be a whole number of years');
  const k = r + lambda, df = Array.from({length: T}, (_, i) => exp(-k * (i + 1)));
  const coupons = N * c * df.reduce((s, d) => s + d, 0);
  const principal = N * df[T - 1];
  const recovery = lambda > 0 ? R * N * lambda / k * (1 - df[T - 1]) : 0;
  return {df, coupons, principal, recovery, price: coupons + principal + recovery};
}
// Annual-effective yield that reprices given annual cash flows (bisection).
function yieldOf(price, flows) {
  const pv = y => flows.reduce((s, cf, i) => s + cf / (1 + y) ** (i + 1), 0);
  let lo = -0.5, hi = 1;
  if (!(pv(lo) > price && pv(hi) < price)) throw new RangeError('price outside the yield search range');
  for (let i = 0; i < 200; i++) { const m = (lo + hi) / 2; if (pv(m) > price) lo = m; else hi = m; }
  return (lo + hi) / 2;
}
// Workbook: half-year periods, rate 5% compounded twice a year, hazard h[k] per half-year, recovery paid at period end.
function fileBond(h, periods, coupon, recovery) {
  let Q = 1, value = 0;
  for (let k = 1; k <= periods; k++) {
    const d = 1 / 1.025 ** k, Qk = Q * (1 - check(h[k - 1], 'period hazard', 0, 1));
    value += d * ((coupon + (k === periods ? 100 : 0)) * Qk + recovery * (Q - Qk));
    Q = Qk;
  }
  return value;
}

const deal = {N: 1e7, c: 0.05, r: 0.045, lambda: 0.018, R: 0.4, T: 5};
const b = riskyBond(deal), rf = riskyBond({...deal, lambda: 0});
const flows = [5e5, 5e5, 5e5, 5e5, 10.5e6];
// Continuously compounded yield of the same cash flows (bisection).
function contYield(price) {
  const pv = y => flows.reduce((s, cf, i) => s + cf * exp(-y * (i + 1)), 0);
  let lo = 0, hi = 1;
  for (let i = 0; i < 200; i++) { const m = (lo + hi) / 2; if (pv(m) > price) lo = m; else hi = m; }
  return (lo + hi) / 2;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • hazard คืออัตราผิดนัดของผู้ที่ยังรอด โอกาสรอดคือ $e^{-\int\lambda}$ ห้าปีที่ 1.8% มีโอกาสผิดนัด 8.6069% ไม่ใช่ 9% และโอกาสผิดนัดในแต่ละปีลดลงทีละนิด (1.78%, 1.75%, …)
  • ราคาพันธบัตรที่ผิดนัดได้คือคูปองที่รอด เงินต้นที่รอด และเงินคืนเมื่อผิดนัด: \$2,077,689.22 + \$7,297,888.74 + \$308,812.72 = \$9,684,390.68 โดยแยกค่าเฉลี่ยได้เพราะสมมติว่าการผิดนัดไม่เกี่ยวกับอัตรา
  • เงินที่จ่ายเมื่อรอดถูกคิดลดด้วย $r+\lambda$ spread จึงประมาณ $\lambda(1-R)$ = 108 bp เทียบของจริง 108.51 bp
  • credit01 ของหุ้นกู้ห้าปีคือ −\$2,603.02 ต่อ hazard 1 bp โตตามอายุแต่ช้าลง และน้อยกว่า DV01 เพราะเงินคืนชดเชยบางส่วน
  • บนต้นไม้ แต่ละจุดแตกเป็นรอดกับผิดนัด และแกะ hazard ทีละช่วงจากราคาพันธบัตรได้แบบ bootstrapping แต่ราคาที่คลาด 0.1 ทำให้ hazard คลาดได้ 0.11 จุด
