12.5 Markowitz Portfolio Selection

แบ่งเงินลงหุ้นกับพันธบัตร ผลตอบแทนที่คาดว่าจะได้เป็นค่าเฉลี่ยถ่วงน้ำหนักของสองตัวพอดี แต่ความผันผวนต่ำกว่าค่าเฉลี่ยนั้น หน้านี้ใช้ช่องว่างนี้หาส่วนผสมที่ดีที่สุด แล้วแสดงว่าเมื่อมีเงินสดให้ผสม ทุกคนควรถือส่วนผสมของหุ้นกับพันธบัตรในสัดส่วนเดียวกัน

ผู้จัดการกองทุนคนหนึ่งดูแลเงินของลูกค้า เขาเลือกได้สามที่: หุ้น พันธบัตร (ตราสารหนี้ที่จ่ายดอกเบี้ย ราคาแกว่งน้อยกว่าหุ้น) และเงินสด (เงินฝากที่ได้ดอกเบี้ยแน่นอน) เขาอยากได้ผลตอบแทนมาก แต่ไม่อยากให้ราคาพอร์ตแกว่งแรง คำถามคือควรแบ่งเงินอย่างไร

ทีมวิจัยให้ตัวเลขรายปีชุดหนึ่ง (สมมติ ใช้ทั้งหน้า):

  • หุ้น: ผลตอบแทนคาดหวัง (ผลตอบแทนเฉลี่ยที่คาดว่าจะได้ต่อปี) $\mu_1=12\%$ และความผันผวน (SD หรือ standard deviation ของผลตอบแทนรายปี บอกว่าผลตอบแทนแกว่งรอบค่าเฉลี่ยแรงแค่ไหน) $\sigma_1=20\%$
  • พันธบัตร: $\mu_2=6\%$ และ $\sigma_2=10\%$
  • correlation ระหว่างหุ้นกับพันธบัตร $\rho=0.30$ (ตัวเลขจาก −1 ถึง 1 ที่บอกว่าสองตัวขยับไปทางเดียวกันบ่อยแค่ไหน)
  • เงินสดได้ $r_f=2\%$ ต่อปีแน่นอน ไม่แกว่งเลย

วิธีเทียบความคุ้มที่ใช้กันคือ Sharpe ratio: เอาผลตอบแทนที่ได้เกินเงินสด หารด้วยความผันผวน ยิ่งสูง ยิ่งได้ผลตอบแทนเกินเงินสดมากต่อความเสี่ยงหนึ่งหน่วย

\[\begin{aligned}\mathrm{SR}_1&=\frac{\mu_1-r_f}{\sigma_1}=\frac{12\%-2\%}{20\%}=0.50,\\ \mathrm{SR}_2&=\frac{\mu_2-r_f}{\sigma_2}=\frac{6\%-2\%}{10\%}=0.40.\end{aligned}\]

ผู้จัดการจึงสรุปว่า “หุ้นคุ้มกว่าต่อความเสี่ยงหนึ่งหน่วย ใครอยากได้ Sharpe สูงสุดก็ถือหุ้นล้วน ถ้ากลัวก็ค่อยเอาเงินบางส่วนไปพักเป็นเงินสด” ข้อสรุปนี้ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก ลองย้ายเงินแค่ 5% จากหุ้นไปพันธบัตร (หุ้น $w=0.95$ พันธบัตร $0.05$) แล้วคิด Sharpe ใหม่ด้วยสูตรความผันผวนของพอร์ตสองสินทรัพย์ที่ขั้นที่ 1 จะอธิบาย

\[\begin{aligned}\mu_p&=0.95(12\%)+0.05(6\%)=11.7\%,\\ \sigma_p^2&=0.95^2(0.04)+0.05^2(0.01)\\ &\quad+2(0.95)(0.05)(0.006)\\ &=0.0361+0.000025+0.00057\\ &=0.036695,\\ \sigma_p&=\sqrt{0.036695}=19.156\%,\\ \mathrm{SR}_p&=\frac{11.7\%-2\%}{19.156\%}=0.5064.\end{aligned}\]

Sharpe ขึ้นจาก 0.50 เป็น 0.5064 ทั้งที่เอาเงินไปใส่ตัวที่ Sharpe ต่ำกว่า เหตุผลคือพันธบัตรขยับไปกับหุ้นไม่มาก ($\rho=0.30$) มันจึงลดความผันผวนของพอร์ตได้มากกว่าผลตอบแทนที่เสียไป (0.006 ในสูตรคือ covariance $\rho\sigma_1\sigma_2=0.30\times0.20\times0.10$) ถ้าย้ายต่อไปเรื่อย ๆ Sharpe จะขึ้นไปสูงสุดที่ 0.5645 เมื่อถือหุ้น 43.18% พันธบัตร 56.82% หน้านี้จะคำนวณตัวเลขนี้ให้ดูทีละขั้น และจะแสดงว่าเงื่อนไขจริงคือ Sharpe ของพันธบัตรต้องเกิน $\rho\times\mathrm{SR}_1=0.30\times0.50=0.15$ ไม่ใช่ต้องเกิน 0.50

ภาพรวมก่อนลงสูตร

ในปี 1952 Harry Markowitz ถามคำถามเดียวกับผู้จัดการในโจทย์ แต่ถามให้เป็นคณิตศาสตร์: ถ้าวัดความเสี่ยงด้วย variance (กำลังสองของความผันผวน) พอร์ตที่ดีที่สุดหน้าตาเป็นอย่างไร

คำตอบเริ่มจากข้อสังเกตข้อเดียว เมื่อผสมสองสินทรัพย์ ผลตอบแทนคาดหวังของส่วนผสมเป็นค่าเฉลี่ยถ่วงน้ำหนักของสองตัวพอดี แต่ความผันผวนของส่วนผสมต่ำกว่าค่าเฉลี่ยถ่วงน้ำหนักทุกครั้งที่ correlation ต่ำกว่า 1 เพราะในช่วงที่สองตัวขยับไม่พร้อมกัน การแกว่งของตัวหนึ่งจะหักล้างกับอีกตัวไปบางส่วน

ถ้าวาดทุกส่วนผสมลงบนกราฟ (แกนนอนคือความผันผวน แกนตั้งคือผลตอบแทนคาดหวัง) จะได้เส้นโค้งที่ป่องไปทางซ้าย ครึ่งบนของเส้นนี้คือ “เมนู” ของพอร์ตที่ดี ไม่มีพอร์ตอื่นที่ได้ผลตอบแทนสูงกว่าโดยเสี่ยงไม่มากกว่า เมนูนี้เรียกว่า efficient frontier

พอมีเงินสดให้ผสม ให้ลากเส้นตรงจากจุดของเงินสดไปแตะเมนู เส้นที่ชันที่สุดจะแตะเมนูที่จุดเดียว เรียกว่า tangency portfolio ความชันของเส้นนี้คือ Sharpe ratio ทุกคนที่เชื่อตัวเลขชุดเดียวกันจึงควรถือส่วนผสมเสี่ยงสัดส่วนนี้ ต่างกันแค่ถือมากหรือน้อย ที่เหลือเก็บเป็นเงินสด ข้อสรุปนี้พาไปสู่ CAPM ซึ่งเป็นแบบจำลองที่บอกว่าหุ้นแต่ละตัวควรให้ผลตอบแทนคาดหวังเท่าไร

หน้านี้จะทำทีละขั้น:

  • ดูว่าทำไมความผันผวนของส่วนผสมต่ำกว่าค่าเฉลี่ย
  • แก้โจทย์หาพอร์ตที่ดีที่สุดด้วยตัวคูณ Lagrange และอ่านว่าตัวคูณแปลว่าอะไร
  • แยกคำตอบเป็นสองกองทุน วาด efficient frontier และหา tangency
  • อธิบายว่าทำไมผสมตัวที่ Sharpe ต่ำกว่าแล้ว Sharpe รวมสูงขึ้น แล้วต่อไปถึง CAPM
  • จบที่จุดอ่อนใหญ่ที่สุด: คำตอบไวมากต่อผลตอบแทนคาดหวัง ซึ่งเป็นตัวเลขที่ประมาณได้หยาบที่สุด

ขั้นที่ 1 — ความเสี่ยงของส่วนผสมไม่ใช่ค่าเฉลี่ย

ก่อนจะหาส่วนผสมที่ดีที่สุด ต้องรู้ก่อนว่าส่วนผสมหนึ่ง ๆ ได้ผลตอบแทนเท่าไรและเสี่ยงเท่าไร ให้ $w$ เป็นน้ำหนักหุ้น ที่เหลือ $1-w$ อยู่ในพันธบัตร ผลตอบแทนของพอร์ตคือค่าเฉลี่ยถ่วงน้ำหนักธรรมดา ส่วน variance ของพอร์ตมาจากสูตรของผลรวมสองตัวแปรสุ่ม (ความเสี่ยงของพอร์ตจาก covariance)

\[ \begin{aligned} \mu_p&=w\mu_1+(1-w)\mu_2,\\ \sigma_p^2&=w^2\sigma_1^2+(1-w)^2\sigma_2^2\\ &\quad+2w(1-w)\rho\sigma_1\sigma_2. \end{aligned} \]

สองพจน์แรกคือการแกว่งของแต่ละตัวที่ถูกย่อด้วยน้ำหนักยกกำลังสอง พจน์สุดท้ายคือพจน์ไขว้ มันบอกว่าสองตัวแกว่งไปด้วยกันแค่ไหน และเป็นที่เดียวที่ $\rho$ เข้ามา ถ้า $\rho$ ต่ำ พจน์นี้เล็ก variance ของพอร์ตก็เล็กตาม

ลองแทนตัวเลขกับส่วนผสมครึ่งต่อครึ่ง ($w=0.5$) โดยคิดสามพจน์แยกกันก่อน เพราะพจน์ไขว้จะถูกคูณด้วย $\rho$ ที่เราจะเปลี่ยนค่าเล่น

\[ \begin{aligned} \mu_p&=0.5(12\%)+0.5(6\%)=9\%,\\ w^2\sigma_1^2&=0.25(0.04)=0.01,\\ (1-w)^2\sigma_2^2&=0.25(0.01)=0.0025,\\ 2w(1-w)\sigma_1\sigma_2&=0.5(0.20)(0.10)=0.01. \end{aligned} \]

ทีนี้เปลี่ยน correlation สามค่า: 0.3 ของหน้านี้ 1 (ขยับไปด้วยกันเป๊ะ) และ −1 (ขยับสวนกันเป๊ะ)

\[ \begin{aligned} \rho=0.3:\ \sigma_p^2&=0.01+0.0025+0.3(0.01)\\ &=0.0155,\quad\sigma_p=12.45\%,\\ \rho=1:\ \sigma_p^2&=0.01+0.0025+0.01\\ &=0.0225,\quad\sigma_p=15\%,\\ \rho=-1:\ \sigma_p^2&=0.01+0.0025-0.01\\ &=0.0025,\quad\sigma_p=5\%. \end{aligned} \]

ผลตอบแทนเป็น 9% ทุกกรณี เพราะมันเป็นค่าเฉลี่ยตรง ๆ และไม่มี $\rho$ อยู่ในสูตร แต่ความผันผวนต่างกันมาก กรณี $\rho=1$ ได้ 15% ซึ่งเท่ากับค่าเฉลี่ยถ่วงน้ำหนัก $0.5(20\%)+0.5(10\%)$ พอดี กรณีอื่นต่ำกว่านี้เสมอ เพราะพจน์ไขว้เล็กลงตาม $\rho$ ส่วนที่หายไปคือช่วงที่สองตัวขยับไม่พร้อมกัน การแกว่งจึงหักล้างกันเอง

ที่ $\rho=-1$ หักล้างได้หมดถ้าเลือกน้ำหนักให้การแกว่งของสองฝั่งเท่ากันพอดี คือ $0.20w=0.10(1-w)$ แก้ได้ $w=1/3$ พอร์ตนี้ไม่แกว่งเลย และได้ผลตอบแทน $\tfrac13(12\%)+\tfrac23(6\%)=8\%$

ดูผลเดียวกันในกรณีสุดโต่ง สมมติมี $d$ สินทรัพย์ ความผันผวน $\sigma$ เท่ากันหมด และไม่สัมพันธ์กันเลย ($\rho=0$ ทุกคู่ พจน์ไขว้จึงหายหมด) ถือตัวละ $1/d$ ได้ variance $d\cdot(1/d)^2\sigma^2=\sigma^2/d$ ผลตอบแทนคาดหวังเท่าถือตัวเดียว แต่ถ้า $\sigma=20\%$ และกระจาย 25 ตัว ความผันผวนเหลือ $20\%/\sqrt{25}=4\%$ นี่คือเหตุผลทั้งหมดของการกระจายความเสี่ยง

รู้แล้วว่าส่วนผสมดีกว่าถือตัวเดียว คำถามต่อไปคือส่วนผสมไหนดีที่สุด เพื่อให้สูตรใช้ได้กับกี่สินทรัพย์ก็ได้ เราเขียนด้วย vector และ matrix:

  • $x$ คือ vector น้ำหนัก ผลรวมน้ำหนักคือ $\mathbf1^{\mathsf T}x$ ($\mathbf1$ คือ vector ที่ทุกช่องเป็น 1)
  • $\mu$ คือ vector ผลตอบแทนคาดหวัง ผลตอบแทนของพอร์ตจึงเป็น $\mu^{\mathsf T}x$
  • $V$ คือ covariance matrix ช่องทแยงคือ variance ของแต่ละตัว ช่องนอกทแยงคือ covariance variance ของพอร์ตคือ $x^{\mathsf T}Vx$ ซึ่งเป็นสูตรของขั้นที่ 1 ที่เขียนให้สั้นลง

คำถาม “ส่วนผสมไหนดีที่สุด” ถามได้สามแบบ ทุกแบบบังคับให้ลงเงินครบ ($\mathbf1^{\mathsf T}x=1$) และยอมให้ short ส่วน “s.t.” ย่อมาจาก subject to แปลว่า “ภายใต้เงื่อนไข”

\[ \begin{aligned} \text{(a)}&\quad\min\ x^{\mathsf T}Vx\ \ \text{s.t.}\ \mu^{\mathsf T}x=m,\\ \text{(b)}&\quad\max\ \mu^{\mathsf T}x\ \ \text{s.t.}\ x^{\mathsf T}Vx\le\bar\sigma^2,\\ \text{(c)}&\quad\max\ \mu^{\mathsf T}x-\gamma\,x^{\mathsf T}Vx. \end{aligned} \]

แบบ (a) ถามว่า ถ้าต้องการผลตอบแทน $m$ พอดี ความเสี่ยงต่ำสุดได้เท่าไร แบบ (b) ถามกลับด้าน ถ้ายอมให้ความผันผวนไม่เกิน $\bar\sigma$ ผลตอบแทนสูงสุดได้เท่าไร แบบ (c) ตั้งราคา $\gamma$ ให้ variance หนึ่งหน่วย แล้วหักออกจากผลตอบแทน ทั้งสามแบบให้พอร์ตชุดเดียวกัน ต่างกันแค่ปุ่มที่หมุน: เป้าผลตอบแทน เพดานความเสี่ยง หรือความกลัว ถ้าแก้ (b) ด้วยตัวคูณ Lagrange ตัวคูณของเพดานความเสี่ยงจะเท่ากับ $\gamma$ ของ (c) ที่ให้คำตอบเดียวกัน

แล้ว $\gamma$ มาจากไหน? ให้ $U$ เป็น function ที่บอกว่าเงินจำนวนหนึ่งทำให้เราพอใจแค่ไหน มันโค้งคว่ำ เพราะเงินดอลลาร์ที่เพิ่มขึ้นมีค่าน้อยลงเรื่อย ๆ ถ้ากาง Taylor อันดับสองรอบเงินที่มีวันนี้ แล้วหาค่าคาดหวัง จะเหลือแค่สองพจน์ คือผลตอบแทนคาดหวัง กับ variance ที่คูณด้วยตัวเลขจากความโค้งของ $U$ ตัวเลขนั้นคือ $\gamma$ ยิ่ง $U$ โค้งมาก คนนั้นยิ่งกลัวความเสี่ยง

ทุกคำตอบข้างล่างมี $V^{-1}$ อยู่ข้างใน จึงคำนวณมันไว้ก่อน เริ่มจากสร้าง $V$: ช่องทแยงคือ $\sigma_1^2=0.20^2=0.04$ กับ $\sigma_2^2=0.10^2=0.01$ ช่องนอกทแยงคือ covariance $\rho\sigma_1\sigma_2=0.30\times0.20\times0.10=0.006$ ส่วน inverse ของ matrix 2×2 ทำได้ด้วยมือ: สลับสองช่องทแยง เปลี่ยนเครื่องหมายช่องนอกทแยง แล้วหารด้วย determinant (rank และการกลับ matrix)

\[ \begin{aligned} \mu&=\begin{bmatrix}0.12\\0.06\end{bmatrix},\quad V=\begin{bmatrix}0.04&0.006\\0.006&0.01\end{bmatrix},\\ \det V&=0.04(0.01)-0.006^2=0.000364,\\ V^{-1}&=\frac{1}{0.000364}\begin{bmatrix}0.01&-0.006\\-0.006&0.04\end{bmatrix}\\ &\approx\begin{bmatrix}27.4725&-16.4835\\-16.4835&109.8901\end{bmatrix}. \end{aligned} \]

ตัวเลขใน $V^{-1}$ ใหญ่ เพราะหารด้วย determinant ที่เล็กมาก (0.000364) อย่าอ่าน 109.89 ว่าพันธบัตรเสี่ยง หน่วยของ $V^{-1}$ คือหนึ่งส่วน variance ช่องที่ใหญ่สุดจึงตกกับตัวที่นิ่งที่สุด พูดง่าย ๆ คือ $V^{-1}$ ให้รางวัลกับความนิ่ง ตรวจว่ากลับถูก: แถวแรกของ $V$ คูณหลักแรกของ $V^{-1}$ ต้องได้ 1 และได้จริง $0.04(27.4725)+0.006(-16.4835)=1.0989-0.0989=1$

ขั้นที่ 3 — Lagrange: γ = 2 ได้ครึ่งต่อครึ่ง และ ν คือราคาของงบ

เริ่มจากแบบ (c) เพราะมันมีข้อบังคับข้อเดียว คือลงเงินครบ 100% เราจะใช้วิธีตัวคูณ Lagrange: ติดราคา $\nu$ ให้ข้อบังคับนี้ แล้วหักออกจากคะแนน จากนั้นหา derivative เทียบ $x$ ตั้งเป็นศูนย์ แล้วแก้หา $x$ โดยคูณ $V^{-1}$ ทางซ้าย (matrix หารกันไม่ได้ จึงใช้การคูณด้วย inverse แทน)

\[ \begin{aligned} \mathcal L&=\mu^{\mathsf T}x-\gamma x^{\mathsf T}Vx-\nu(\mathbf1^{\mathsf T}x-1),\\ 0&=\mu-2\gamma Vx-\nu\mathbf1,\\ x&=\tfrac{1}{2\gamma}V^{-1}(\mu-\nu\mathbf1),\\ 1&=\mathbf1^{\mathsf T}x=\frac{B-\nu A}{2\gamma},\\ \nu&=\frac{B-2\gamma}{A}. \end{aligned} \]

การหา derivative ใช้ข้อเท็จจริงว่า gradient ของ $x^{\mathsf T}Vx$ คือ $2Vx$ (gradient และเงื่อนไขอันดับหนึ่ง) เหมือนที่ derivative ของ $ax^2$ คือ $2ax$ เมื่อ $x$ เป็นตัวเลขตัวเดียว จังหวะที่ต้องสังเกตคือตอนหา $\nu$: เรายังไม่รู้ $\nu$ แต่รู้ว่าผลรวมน้ำหนักต้องเป็น 1 จึงเอา $\mathbf1^{\mathsf T}$ คูณคำตอบของ $x$ ตรงนี้มีตัวเลขสองตัวโผล่ออกมา คือ $A=\mathbf1^{\mathsf T}V^{-1}\mathbf1$ กับ $B=\mathbf1^{\mathsf T}V^{-1}\mu$ ทั้งคู่เป็นแค่ตัวเลข สมการจึงเหลือ $\nu$ ตัวเดียว แก้ได้ทันที

จุดที่ได้เป็นยอดจริง ไม่ใช่ก้นหลุม เพราะความโค้งของคะแนนคือ $-2\gamma V$ ซึ่งคว่ำทุกทิศ (Hessian และเงื่อนไขอันดับสอง) มันจึงเป็นยอดเดียวของพอร์ตลงเงินครบทั้งหมด ไม่ใช่แค่ยอดเล็ก ๆ ในละแวกนั้น

ทีนี้ใส่ตัวเลข $V^{-1}\mathbf1$ คือผลรวมของแต่ละแถวของ $V^{-1}$ และ $A$ คือผลรวมของทุกช่อง

\[ \begin{aligned} (V^{-1}\mathbf1)_1&=27.4725-16.4835=10.9890,\\ (V^{-1}\mathbf1)_2&=-16.4835+109.8901=93.4066,\\ A&=10.9890+93.4066=104.3956,\\ (V^{-1}\mu)_1&=27.4725(0.12)-16.4835(0.06)\\ &=3.2967-0.9890=2.3077,\\ (V^{-1}\mu)_2&=-16.4835(0.12)+109.8901(0.06)\\ &=-1.9780+6.5934=4.6154,\\ B&=2.3077+4.6154=6.9231. \end{aligned} \]

เลือกลูกค้าที่กลัวความเสี่ยงระดับ $\gamma=2$ (สมมติ) แล้วแทนตามสูตรทีละตัว: หา $\nu$ ก่อน แล้วหา $\mu-\nu\mathbf1$ แล้วคูณ $V^{-1}$

\[ \begin{aligned} \nu&=\frac{B-2\gamma}{A}=\frac{6.9231-4}{104.3956}=0.028,\\ \mu-\nu\mathbf1&=(0.12-0.028,\ 0.06-0.028)\\ &=(0.092,\ 0.032),\\ x_1&=\tfrac14\big(27.4725(0.092)-16.4835(0.032)\big)\\ &=\tfrac14(2.5275-0.5275)=0.5,\\ x_2&=\tfrac14\big(-16.4835(0.092)+109.8901(0.032)\big)\\ &=\tfrac14(-1.5165+3.5165)=0.5. \end{aligned} \]

คำตอบคือหุ้นครึ่งพันธบัตรครึ่ง ขั้นที่ 1 คำนวณไว้แล้วว่าพอร์ตนี้ได้ผลตอบแทน 9% และ variance 0.0155 คะแนนจึงเป็น $J=0.09-2(0.0155)=0.059$ ซึ่งชนะการถือหุ้นล้วน $0.12-2(0.04)=0.04$ และชนะพันธบัตรล้วน $0.06-2(0.01)=0.04$ ตรวจคำตอบได้ใน 10 วินาที: $0.5+0.5=1$ คือข้อบังคับที่ $\nu$ ถูกสร้างมาบังคับ ถ้าผลรวมไม่ได้ 1 แปลว่า $\nu$ ผิด

$\nu$ ไม่ใช่แค่ตัวช่วยคำนวณ มันคือราคาของงบ ถ้าผ่อนให้ลงเงินได้ 101% แทน 100% คะแนนจะเพิ่มประมาณ $\nu\times0.01=0.028\times0.01=0.00028$ (แก้โจทย์ใหม่จริง ๆ ได้ 0.000278 ใกล้กันมาก)

$\nu$ ติดลบได้ด้วย ลองลูกค้าที่กลัวกว่านี้ $\gamma=4$ จะได้ $\nu=(6.9231-8)/104.3956=-0.0103$ คือ −1.03% แปลว่าถ้าลงเงินได้น้อยกว่า 100% คะแนนของเขาจะสูงขึ้น คนที่กลัวขนาดนี้อยากเก็บเงินบางส่วนไว้เฉย ๆ แต่ข้อบังคับลงเงินครบกำลังบังคับให้เขาเสี่ยงเกินใจ

ขั้นที่ 4 — แยกคำตอบ: GMV บวกพอร์ตเก็งกำไรที่ไม่ใช้เงิน

ขั้นก่อนได้คำตอบของลูกค้าคนเดียว ($\gamma=2$) ถ้ามีลูกค้าหลายคนที่กลัวไม่เท่ากัน เราอยากเห็นคำตอบของทุก $\gamma$ พร้อมกัน วิธีคือแทน $\nu=(B-2\gamma)/A$ กลับเข้าไปในสูตรของ $x$ แล้วแยกพจน์ที่มี $\gamma$ ออกจากพจน์ที่ไม่มี

\[ \begin{aligned} x(\gamma)&=\frac{V^{-1}\mu}{2\gamma}-\frac{B-2\gamma}{2\gamma A}V^{-1}\mathbf1\\ &=\frac{V^{-1}\mathbf1}{A}+\frac{1}{2\gamma}\,z,\\ z&=V^{-1}\mu-\tfrac BAV^{-1}\mathbf1. \end{aligned} \]

การจัดรูปมีจังหวะเดียว คือแยกเศษส่วน $\frac{B-2\gamma}{2\gamma A}=\frac{B}{2\gamma A}-\frac1A$ เครื่องหมายลบหน้าเศษส่วนทำให้ $-\frac1A$ กลายเป็น $+\frac1A$ ได้ก้อนแรก $V^{-1}\mathbf1/A$ ที่ไม่มี $\gamma$ ที่เหลือมี $\frac{1}{2\gamma}$ คูณอยู่ทุกตัว จึงดึงออกมาได้ เหลือ $z$ ในวงเล็บ

ใส่ตัวเลขจากขั้นก่อน ($V^{-1}\mathbf1=(10.9890,\ 93.4066)$, $V^{-1}\mu=(2.3077,\ 4.6154)$, $A=104.3956$, $B=6.9231$)

\[ \begin{aligned} \frac{V^{-1}\mathbf1}{A}&=\frac{(10.9890,\ 93.4066)}{104.3956}\\ &=(0.105263,\ 0.894737),\\ \tfrac BA&=\frac{6.9231}{104.3956}=0.066316,\\ z_1&=2.3077-0.066316(10.9890)=1.578947,\\ z_2&=4.6154-0.066316(93.4066)=-1.578947,\\ x_1(\gamma)&=0.105263+\frac{1.578947}{2\gamma}\\ &=\frac{2}{19}+\frac{15}{19\gamma}. \end{aligned} \]

ตัวเลขทศนิยมสองตัวเป็นเศษส่วนสวย ๆ คือ $0.105263=2/19$ และ $1.578947/2=0.789474=15/19$ คำตอบจึงมีสองก้อน ก้อนแรกคือ GMV พอร์ตที่ความผันผวนต่ำที่สุด มันไม่มี $\gamma$ และไม่มี $\mu$ เลย ทุกคนถือก้อนนี้เท่ากัน ก้อนที่สอง $z$ มีผลรวมน้ำหนักเป็นศูนย์ เพราะ $\mathbf1^{\mathsf T}z=B-\tfrac BA A=0$ มันคือการซื้อหุ้น 1.58 ส่วน แล้ว short พันธบัตร 1.58 ส่วน เงินที่ได้จากการ short จ่ายค่าหุ้นพอดี จึงไม่ใช้เงินเลย เป็นพอร์ตเก็งกำไรล้วน ๆ ขนาดของมันคือ $1/(2\gamma)$ ยิ่งกลัว ยิ่งถือก้อนเก็งกำไรน้อย

ลองใช้สูตรนี้กับลูกค้าสามแบบ ทุกแถวในตารางข้างล่างคิดแบบเดียวกัน: หา $x_1$ จากสูตร แล้วคิดผลตอบแทนจาก $\mu_p=0.12x_1+0.06(1-x_1)$ และความผันผวนจากสูตรของขั้นที่ 1 ตัวอย่างเต็มของ $\gamma=1$:

\[ \begin{aligned} x_1&=\tfrac{2}{19}+\tfrac{15}{19}=\tfrac{17}{19}=0.8947,\\ \mu_p&=0.12(0.8947)+0.06(0.1053)=11.37\%,\\ \sigma_p^2&=0.04(0.8947)^2+0.01(0.1053)^2\\ &\quad+2(0.8947)(0.1053)(0.006)\\ &=0.032022+0.000111+0.001130\\ &=0.033263,\quad\sigma_p=18.24\%. \end{aligned} \]

แถว $\gamma=2$ ได้ 50% ตรงกับขั้นก่อน จึงเป็นการตรวจว่าการจัดรูปไม่ผิด แถวสุดท้ายคือเมื่อความกลัวโตไม่หยุด ก้อนเก็งกำไร $\frac{1}{2\gamma}z$ หดเป็นศูนย์ เหลือแค่ GMV ผลตอบแทนและ variance ของ GMV หาได้ตรง ๆ จากน้ำหนัก $x=V^{-1}\mathbf1/A$: ผลตอบแทนคือ $\mu^{\mathsf T}V^{-1}\mathbf1/A=B/A=6.9231/104.3956=6.63\%$ และ variance คือ $\mathbf1^{\mathsf T}V^{-1}VV^{-1}\mathbf1/A^2=A/A^2=1/A$ ความผันผวนจึงเป็น $1/\sqrt{104.3956}=9.79\%$

ขั้นที่ 5 — efficient frontier ด้วยสองตัวคูณ และ two-fund theorem

ทีนี้ถามแบบ (a): ถ้าต้องการผลตอบแทน $m$ พอดี พอร์ตไหน variance ต่ำที่สุด คำตอบของทุก $m$ ต่อกันเป็นเส้น efficient frontier ในรูปแรก โจทย์นี้มีสองข้อบังคับ (ลงเงินครบ และได้ผลตอบแทน $m$) จึงต้องมีตัวคูณสองตัว เราตั้งชื่อเป็น $2\alpha$ และ $2\beta$ เพื่อให้เลข 2 ตัดกับเลข 2 ที่จะได้จาก derivative ของ $x^{\mathsf T}Vx$ พอดี ($\beta$ ตรงนี้เป็นแค่ชื่อตัวคูณ ไม่ใช่ beta ของขั้นที่ 8)

\[ \begin{aligned} \mathcal L&=x^{\mathsf T}Vx-2\alpha(\mathbf1^{\mathsf T}x-1)\\ &\quad-2\beta(\mu^{\mathsf T}x-m),\\ 0&=2Vx-2\alpha\mathbf1-2\beta\mu,\\ x&=V^{-1}(\alpha\mathbf1+\beta\mu),\\ 1&=A\alpha+B\beta,\quad m=B\alpha+C\beta,\\ \alpha&=\frac{C-Bm}{D},\quad\beta=\frac{Am-B}{D},\\ \sigma^2(m)&=x^{\mathsf T}(\alpha\mathbf1+\beta\mu)=\alpha+\beta m\\ &=\frac{Am^2-2Bm+C}{D}. \end{aligned} \]

หลังได้รูปของ $x$ ยังไม่รู้ $\alpha$ กับ $\beta$ จึงเอา $x$ ไปแทนในข้อบังคับทั้งสอง: คูณด้วย $\mathbf1^{\mathsf T}$ ได้ผลรวมน้ำหนัก คูณด้วย $\mu^{\mathsf T}$ ได้ผลตอบแทน ได้สมการเชิงเส้นสองตัว สองตัวแปร ตัวเลขสรุปตัวที่สามคือ $C=\mu^{\mathsf T}V^{-1}\mu$ และ $D=AC-B^2$ คือ determinant ของระบบนี้ แก้ด้วยการกลับ matrix 2×2 แบบเดียวกับขั้นที่ 2

จังหวะที่สวยที่สุดคือแถวของ $\sigma^2(m)$ เราไม่ต้องคูณ matrix ยาว ๆ เลย เพราะสมการ derivative บอกอยู่แล้วว่า $Vx=\alpha\mathbf1+\beta\mu$ พอคูณ $x^{\mathsf T}$ เข้าไป ก็ได้ $\alpha$ คูณผลรวมน้ำหนัก (ซึ่งเป็น 1) บวก $\beta$ คูณผลตอบแทน (ซึ่งเป็น $m$) สองค่านี้ข้อบังคับกำหนดไว้แล้ว

สูตรนี้ต้องมี $D\gt0$ ซึ่งเป็นจริงเมื่อผลตอบแทนคาดหวังของสินทรัพย์ไม่เท่ากันทุกตัว ถ้าทุกตัวคาดหวังเท่ากัน ทุกพอร์ตก็ได้ผลตอบแทนเท่ากัน จะตั้งเป้า $m$ อื่นไม่ได้ ถ้ามี $d$ สินทรัพย์ วิธีเดียวกันให้สมการเชิงเส้น $d+2$ ตัว ($d$ น้ำหนัก กับตัวคูณสองตัว)

ใส่ตัวเลข $C$ คิดจาก $V^{-1}\mu=(2.3077,\ 4.6154)$ ของขั้นที่ 3 แล้วตรวจสูตรกับพอร์ตที่รู้คำตอบอยู่แล้ว คือ 50/50 ที่ $m=9\%$ ซึ่งขั้นที่ 1 คิด variance ได้ 0.0155

\[ \begin{aligned} C&=0.12(2.3077)+0.06(4.6154)\\ &=0.276923+0.276923=0.553846,\\ D&=104.3956(0.553846)-6.9231^2\\ &=57.8191-47.9290=9.8901,\\ Am^2&=104.3956(0.09)^2=0.845604,\\ 2Bm&=2(6.9231)(0.09)=1.246154,\\ \sigma^2(9\%)&=\frac{0.845604-1.246154+0.553846}{9.8901}\\ &=\frac{0.153296}{9.8901}=0.0155. \end{aligned} \]

ได้ 0.0155 ตรงกับ 50/50 สูตรจึงใช้ได้ ตรวจอีกจุดหนึ่ง: $\sigma^2(m)$ เป็นพาราโบลาใน $m$ จุดต่ำสุดอยู่ที่ derivative เป็นศูนย์ คือ $2Am-2B=0$ หรือ $m=B/A$ แทนกลับได้ $\sigma^2=(C-B^2/A)/D=(AC-B^2)/(AD)=1/A$ ตรงกับผลตอบแทนและ variance ของ GMV ในขั้นที่ 4 ครึ่งบนของพาราโบลานี้ (ตั้งแต่ GMV ขึ้นไป) คือ efficient frontier ที่วาดไว้ในรูปแรก

ดูสูตรของ $\alpha$ และ $\beta$ อีกครั้ง ทั้งคู่เป็นเส้นตรงใน $m$ และ $x=V^{-1}(\alpha\mathbf1+\beta\mu)$ เป็นเส้นตรงใน $\alpha,\beta$ น้ำหนัก $x(m)$ จึงเป็นเส้นตรงใน $m$ ด้วย ผลที่ตามมาคือเราผสมพอร์ตบน frontier สองพอร์ตแล้วได้พอร์ตบน frontier อีกพอร์ตเสมอ ให้ $x^{(1)}$ และ $x^{(2)}$ เป็นพอร์ตบน frontier ที่ผลตอบแทน $m_1\ne m_2$ แล้วผสมด้วยสัดส่วน $\theta$

\[ \begin{aligned} Vx^{(1)}&=\alpha_1\mathbf1+\beta_1\mu,\\ Vx^{(2)}&=\alpha_2\mathbf1+\beta_2\mu,\\ y&=(1-\theta)x^{(1)}+\theta x^{(2)},\\ Vy&=\bar\alpha\mathbf1+\bar\beta\mu,\\ \bar\alpha&=(1-\theta)\alpha_1+\theta\alpha_2,\\ \mu^{\mathsf T}y&=(1-\theta)m_1+\theta m_2. \end{aligned} \]

พอร์ตจะอยู่บน frontier ได้ต้องผ่านเงื่อนไข derivative คือ $Vx=\alpha\mathbf1+\beta\mu$ กับตัวคูณสักคู่ เงื่อนไขนี้เป็นเส้นตรงทั้งใน $x$ และในตัวคูณ ส่วนผสม $y$ จึงผ่านเงื่อนไขเดียวกัน โดยใช้ตัวคูณที่ผสมในสัดส่วนเดียวกัน ($\bar\beta$ คิดแบบเดียวกับ $\bar\alpha$) $y$ ยังลงเงินครบด้วย เพราะผสมสองพอร์ตที่ลงเงินครบ ถ้าต้องการผลตอบแทน $m$ ใด ๆ ก็เลือก $\theta=(m-m_1)/(m_2-m_1)$

นี่คือ two-fund theorem: ทุกพอร์ตบน frontier สร้างได้จากสองกองทุนบน frontier ถ้าทุกคนเชื่อ $\mu$ และ $V$ ชุดเดียวกัน ตลาดต้องการแค่สองกองทุน ที่โลกจริงมีกองทุนเป็นพันก็เพราะคนเชื่อตัวเลขต่างกัน และมีข้อบังคับต่างกัน

ในตลาดสองสินทรัพย์ ทฤษฎีนี้ดูธรรมดาไป เพราะข้อบังคับสองข้อตรึงน้ำหนักไว้หมดแล้ว (หุ้น $x_1$ ต้องทำให้ $0.06+0.06x_1=m$ จึงได้ $x_1=(m-0.06)/0.06$) ลองเพิ่มสินทรัพย์ตัวที่สามให้เห็นของจริง คือหุ้นเทค (สมมติ):

ขั้นที่ 6 — มีเงินสด: one-fund theorem และ tangency portfolio

ถึงตอนนี้ผู้จัดการต้องลงเงินครบในหุ้นกับพันธบัตร ทีนี้ให้เขาพักเงินเป็นเงินสดได้ด้วย เงินสดให้ $r_f=2\%$ แน่นอน ให้ $x_0$ เป็นสัดส่วนที่อยู่ในเงินสด งบจึงเป็น $x_0+\mathbf1^{\mathsf T}x=1$ ถ้า $x_0$ ติดลบ แปลว่ากู้เงินมาลงเพิ่ม เคล็ดคือแทน $x_0=1-\mathbf1^{\mathsf T}x$ ลงในคะแนน แล้วข้อบังคับจะหายไปเลย

\[ \begin{aligned} J&=r_fx_0+\mu^{\mathsf T}x-\gamma x^{\mathsf T}Vx\\ &=r_f+(\mu-r_f\mathbf1)^{\mathsf T}x-\gamma x^{\mathsf T}Vx,\\ x(\gamma)&=\tfrac{1}{2\gamma}V^{-1}(\mu-r_f\mathbf1). \end{aligned} \]

แถวที่สองได้จากการกระจาย $r_f(1-\mathbf1^{\mathsf T}x)=r_f-r_f\mathbf1^{\mathsf T}x$ แล้วรวมกับ $\mu^{\mathsf T}x$ ความหมายคือ เงินที่ย้ายจากเงินสดไปสินทรัพย์ $i$ ได้เพิ่มแค่ส่วนเกิน $\mu_i-r_f$ เพราะต้องสละดอกเบี้ยเงินสดไป เมื่อไม่มีข้อบังคับเหลือ ก็แก้ได้ด้วยการตั้ง gradient เป็นศูนย์ ตรง ๆ ได้แถวที่สาม

ให้ดูแถวที่สามให้ดี $\gamma$ อยู่แค่ใน $\frac{1}{2\gamma}$ ข้างหน้า ทุก $\gamma$ จึงได้ vector ที่ชี้ทิศเดียวกัน ต่างกันแค่ขนาด ถ้าหารด้วยผลรวมของมัน จะได้ส่วนผสมเสี่ยงที่ลงเงินครบ $x_T$ ซึ่งไม่มี $\gamma$ เลย

ใส่ตัวเลข ให้ $e=\mu-r_f\mathbf1=(12\%-2\%,\ 6\%-2\%)=(0.10,\ 0.04)$ คือผลตอบแทนที่ได้เกินเงินสด

\[ \begin{aligned} (V^{-1}e)_1&=27.4725(0.10)-16.4835(0.04)\\ &=2.7473-0.6593=2.0879,\\ (V^{-1}e)_2&=-16.4835(0.10)+109.8901(0.04)\\ &=-1.6484+4.3956=2.7473,\\ x_T&=\frac{(2.0879,\ 2.7473)}{2.0879+2.7473}\\ &=\frac{(2.0879,\ 2.7473)}{4.8352}=(0.4318,\ 0.5682),\\ \mu_T&=0.4318(12\%)+0.5682(6\%)=8.591\%,\\ \sigma_T^2&=0.04(0.4318)^2+0.01(0.5682)^2\\ &\quad+2(0.4318)(0.5682)(0.006)\\ &=0.007459+0.003228+0.002944\\ &=0.013631,\quad\sigma_T=11.675\%,\\ \mathrm{SR}_T&=\frac{8.591\%-2\%}{11.675\%}=0.5645. \end{aligned} \]

นี่คือ one-fund theorem: ทุกคนถือเงินสดกับส่วนผสม $x_T$ (หุ้น 43.18% พันธบัตร 56.82%) ตัวเดียว ต่างกันแค่ว่าใส่ $x_T$ มากแค่ไหน ขนาดนั้นคือผลรวมของ $x(\gamma)$ ซึ่งเท่ากับ $4.8352/(2\gamma)$ ลูกค้า $\gamma=2$ ใส่ $4.8352/4=1.2088$ คือ 120.88% ของเงิน จึงต้องกู้เงินสดมา 20.88% ลูกค้า $\gamma=4$ ใส่ $4.8352/8=0.6044$ คือ 60.44% ที่เหลือ $100\%-60.44\%=39.56\%$ เก็บเป็นเงินสด

ทำไม $x_T$ ถึงเป็นจุดที่เส้นจากเงินสดแตะ frontier? ถ้าถือ $x_T$ สัดส่วน $t$ และเงินสด $1-t$ จะได้ผลตอบแทน $r_f+t(\mu_T-r_f)$ และความผันผวน $\sigma=t\sigma_T$ แทน $t=\sigma/\sigma_T$ ได้ผลตอบแทน $r_f+\mathrm{SR}_T\,\sigma$ ซึ่งเป็นเส้นตรงชัน $\mathrm{SR}_T$ เส้นนี้คือ capital market line ถ้าผสมเงินสดกับส่วนผสมเสี่ยงตัวอื่น จะได้เส้นที่ชันเท่ากับ Sharpe ของตัวนั้น ซึ่งต่ำกว่า $x_T$ จึงให้เส้นที่ชันที่สุด และเป็นจุดที่เส้นแตะ frontier พอดีในรูปแรก

ตรวจ Sharpe อีกทางโดยไม่ผ่านน้ำหนัก เพราะ $x_T$ ชี้ทิศเดียวกับ $V^{-1}e$ ถ้าแทน $x\propto V^{-1}e$ ลงใน Sharpe ตัวเศษจะเป็น $e^{\mathsf T}V^{-1}e$ และตัวส่วนเป็นรากของค่าเดียวกัน (ตัวคูณขนาดตัดกันหมด) Sharpe ยกกำลังสองจึงเป็น $e^{\mathsf T}V^{-1}e$ แล้วกระจาย $e=\mu-r_f\mathbf1$ ออกเป็นตัวเลขสรุปที่มีอยู่แล้ว

\[ \begin{aligned} \mathrm{SR}_T^2&=(\mu-r_f\mathbf1)^{\mathsf T}V^{-1}(\mu-r_f\mathbf1)\\ &=C-2r_fB+r_f^2A\\ &=0.553846-0.04(6.9231)\\ &\quad+0.0004(104.3956)\\ &=0.553846-0.276923+0.041758\\ &=0.318681,\\ \mathrm{SR}_T&=\sqrt{0.318681}=0.5645. \end{aligned} \]

ขั้นที่ 7 — ทำไมผสมตัวที่ Sharpe ต่ำกว่า แล้ว Sharpe รวมสูงขึ้น

นี่คือจุดที่ผู้จัดการในโจทย์เปิดเรื่องพลาด เขาคิดว่าเติมตัวที่ Sharpe ต่ำกว่าแล้ว Sharpe รวมต้องลด มาพิสูจน์กันตรง ๆ เริ่มจากหุ้นล้วน แล้วย้ายน้ำหนักเล็ก ๆ $\varepsilon$ ไปพันธบัตร คำถามคือ Sharpe ขึ้นหรือลง ซึ่งก็คือถามว่า derivative ของ Sharpe เทียบ $\varepsilon$ ที่ $\varepsilon=0$ เป็นบวกหรือลบ ให้ $e_1=0.10$ และ $e_2=0.04$ เป็นผลตอบแทนที่หุ้นและพันธบัตรได้เกินเงินสด

\[ \begin{aligned} e(\varepsilon)&=(1-\varepsilon)e_1+\varepsilon e_2,\\ \sigma(\varepsilon)^2&=(1-\varepsilon)^2\sigma_1^2+\varepsilon^2\sigma_2^2\\ &\quad+2\varepsilon(1-\varepsilon)\rho\sigma_1\sigma_2,\\ \sigma'(0)&=\frac{-2\sigma_1^2+2\rho\sigma_1\sigma_2}{2\sigma_1}=-\sigma_1+\rho\sigma_2,\\ \mathrm{SR}'(0)&=\frac{(e_2-e_1)\sigma_1-e_1\sigma'(0)}{\sigma_1^2}\\ &=\frac{e_2\sigma_1-e_1\rho\sigma_2}{\sigma_1^2}\\ &=\frac{0.04(0.2)-0.10(0.3)(0.1)}{0.04}=0.125. \end{aligned} \]

การหา $\sigma'(0)$ ใช้ chain rule ของราก: derivative ของ $\sigma$ คือ derivative ของ $\sigma^2$ หารด้วย $2\sigma$ ที่ $\varepsilon=0$ พจน์ $\varepsilon^2\sigma_2^2$ ไม่เหลืออะไร พจน์แรกให้ $-2\sigma_1^2$ และพจน์ไขว้ให้ $2\rho\sigma_1\sigma_2$ ส่วน $\mathrm{SR}'(0)$ ใช้กฎผลหารของ $e/\sigma$ แล้วแทน $\sigma'(0)$ ลงไป พจน์ $e_1\sigma_1$ ตัดกันเอง เหลือตัวเศษสั้น ๆ

Sharpe จะขึ้นเมื่อตัวเศษเป็นบวก คือ $e_2\sigma_1\gt e_1\rho\sigma_2$ หารด้วย $\sigma_1\sigma_2$ ทั้งสองข้างได้เงื่อนไขที่อ่านง่าย $e_2/\sigma_2\gt\rho\,e_1/\sigma_1$ คือ Sharpe ของพันธบัตรต้องเกิน $\rho$ คูณ Sharpe ของหุ้น พันธบัตรได้ 0.40 จึงต้องเกินแค่ $0.30\times0.50=0.15$ ไม่ต้องเกิน 0.50 อย่างที่ผู้จัดการคิด ตรวจด้วยตัวเลขในโจทย์: ย้าย 5% derivative ทำนายว่าได้ $0.50+0.05(0.125)=0.50625$ ส่วนการคำนวณตรงในเฉลยโจทย์ได้ 0.5064 ใกล้กันมาก

มีอีกมุมหนึ่งที่ให้คำตอบเดียวกัน และเห็นภาพชัดกว่า แทนที่จะวัดตำแหน่งเป็นสัดส่วนเงิน ให้วัดเป็นความเสี่ยงที่ใส่ลงไป $v_i=x_i\sigma_i$ แล้วเขียน covariance matrix เป็น $V=\Sigma R\Sigma$ โดย $\Sigma$ คือ matrix ทแยงของความผันผวน และ $R$ คือ correlation matrix ทิศของ tangency $x\propto V^{-1}e=\Sigma^{-1}R^{-1}\Sigma^{-1}e$ จึงกลายเป็น $v=\Sigma x\propto R^{-1}s$ โดย $s=\Sigma^{-1}e$ คือ vector ของ Sharpe แต่ละตัว $(0.50,\ 0.40)$

\[ \begin{aligned} v&\propto R^{-1}s=\frac{1}{1-\rho^2}\begin{bmatrix}1&-\rho\\-\rho&1\end{bmatrix}\begin{bmatrix}0.50\\0.40\end{bmatrix}\\ &=\frac{(0.50-0.3(0.40),\ 0.40-0.3(0.50))}{1-0.09}\\ &=\frac{(0.38,\ 0.25)}{0.91}=(0.4176,\ 0.2747),\\ x&\propto\Big(\frac{0.4176}{0.20},\ \frac{0.2747}{0.10}\Big)=(2.088,\ 2.747). \end{aligned} \]

ได้ทิศเดียวกับ $V^{-1}e=(2.0879,\ 2.7473)$ ของขั้นที่ 6 ทุกหลัก มุมนี้บอกอะไรเพิ่ม: Sharpe ของแต่ละตัวถูกหักด้วย $\rho$ คูณ Sharpe ของอีกตัว ช่องของพันธบัตรคือ $0.40-0.30\times0.50$ ซึ่งจะติดลบ (พันธบัตรถูก short) ก็ต่อเมื่อ Sharpe ของมันต่ำกว่า $\rho\times0.50$ ซึ่งเป็นเงื่อนไขเดียวกับ derivative ข้างบน ยิ่ง correlation สูง ตัวที่ Sharpe ต่ำกว่ายิ่งถูกหักมาก จนถึงจุดหนึ่งมันกลายเป็นตัว hedge (ตัวที่ถือเพื่อหักล้างความเสี่ยงของอีกตัว ไม่ได้ถือเพื่อผลตอบแทน)

ตารางนี้รวมทุกพอร์ตที่คำนวณมาแล้วในหน้านี้ คอลัมน์ Sharpe คิดจาก (ผลตอบแทน − 2%) หารด้วยความผันผวน เช่น GMV ได้ $(6.6316\%-2\%)/9.7872\%=0.4732$

ขั้นที่ 8 — จาก tangency สู่ CAPM: beta กำหนดผลตอบแทนเกินเงินสด

tangency มีสมบัติแปลกอย่างหนึ่ง: ผลตอบแทนเกินเงินสดของสินทรัพย์ทุกตัว ถูกกำหนดด้วยว่ามันขยับไปกับ tangency แรงแค่ไหน มาดูว่าทำไม เริ่มจากสูตรที่สร้าง tangency $x_T\propto V^{-1}(\mu-r_f\mathbf1)$ คูณ $V$ ทั้งสองข้างได้ $Vx_T=k(\mu-r_f\mathbf1)$ โดย $k$ เป็นค่าคงที่บวกสักตัว ช่องที่ $j$ ของ $Vx_T$ คือ $\sum_iV_{ji}x_{T,i}$ ซึ่งก็คือ covariance ของสินทรัพย์ $j$ กับพอร์ต tangency ($r_j$ และ $r_T$ คือผลตอบแทนของสินทรัพย์ $j$ และของ tangency) เขียนออกมาแล้วกำจัด $k$ ทิ้ง

\[ \begin{aligned} \operatorname{Cov}(r_j,r_T)&=(Vx_T)_j=k(\mu_j-r_f),\\ \sigma_T^2&=x_T^{\mathsf T}Vx_T=k(\mu_T-r_f),\\ \mu_j-r_f&=\beta_j(\mu_T-r_f),\\ \beta_j&=\frac{\operatorname{Cov}(r_j,r_T)}{\sigma_T^2}. \end{aligned} \]

แถวที่สองได้จากการเอาแถวแรกคูณน้ำหนัก $x_{T,j}$ แล้วรวมทุก $j$ ฝั่งซ้ายรวมกันเป็น variance ของ tangency ฝั่งขวาได้ $k$ คูณผลตอบแทนเกินเงินสดของ tangency เพราะผลรวมของ $x_T$ คือ 1 จากนั้นเอาแถวแรกหารด้วยแถวที่สอง $k$ ตัดกันหมด เหลือแถวที่สาม อัตราส่วน covariance ต่อ variance ที่โผล่ออกมาคือ beta

ตรวจด้วยตัวเลข ใช้ $x_T=(0.4318,\ 0.5682)$ และ $\mu_T-r_f=8.591\%-2\%=6.591\%$ จากขั้นที่ 6

\[ \begin{aligned} (Vx_T)_1&=0.04(0.4318)+0.006(0.5682)\\ &=0.017273+0.003409=0.020682,\\ (Vx_T)_2&=0.006(0.4318)+0.01(0.5682)\\ &=0.002591+0.005682=0.008273,\\ \sigma_T^2&=0.4318(0.020682)+0.5682(0.008273)\\ &=0.008931+0.004701=0.013631,\\ \beta_1&=0.020682/0.013631=1.5172,\\ \beta_2&=0.008273/0.013631=0.6069,\\ \beta_1(0.06591)&=0.1000,\quad\beta_2(0.06591)=0.0400. \end{aligned} \]

หุ้นมี beta 1.52 คูณผลตอบแทนเกินเงินสด 6.59% ของ tangency ได้ 10% พันธบัตรมี beta 0.61 ได้ 4% ตรงกับผลตอบแทนเกินเงินสดที่ใส่เข้าไปตอนต้นพอดี นี่ไม่ใช่การประมาณ แต่เป็นสมบัติของ tangency เอง ลองคิดกลับด้าน ถ้ามีสินทรัพย์ตัวไหนให้ผลตอบแทนเกินเส้นนี้ การเพิ่มมันอีกนิดจะดัน Sharpe ขึ้น ซึ่งขัดกับที่ tangency เป็นยอดของ Sharpe อยู่แล้ว

ทีนี้สมมติว่านักลงทุนทุกคนเชื่อ $\mu$ และ $V$ ชุดเดียวกัน และเลือกพอร์ตด้วย mean-variance ตาม one-fund theorem ทุกคนจะถือ $x_T$ เมื่อรวมสิ่งที่ทุกคนถือ ก็ได้ทั้งตลาด $x_T$ จึงต้องเป็น market portfolio คือพอร์ตที่ถือทุกสินทรัพย์ตามสัดส่วนมูลค่าในตลาด แทน tangency ด้วยตลาด ได้ $\mu_j-r_f=\beta_j(\mu_m-r_f)$ ซึ่งคือ CAPM ความหมายคือ ผลตอบแทนเกินเงินสดขึ้นกับ beta เท่านั้น ความเสี่ยงส่วนที่ไม่ขยับไปกับตลาดกระจายทิ้งได้ จึงไม่มีใครจ่ายค่าตอบแทนให้

ยังมีอีกทางที่ได้สูตรเดียวกัน ลากเส้นของส่วนผสมระหว่างสินทรัพย์ $j$ กับตลาด เส้นนี้ต้องแตะ capital market line ที่จุดตลาดพอดี เพราะถ้ามันตัดข้ามไป จะมีส่วนผสมที่อยู่เหนือ capital market line ซึ่งเป็นไปไม่ได้ เมื่อตั้งให้ความชันของสองเส้นที่จุดนั้นเท่ากัน ก็ได้ beta ออกมา

ขั้นที่ 9 — ทำให้มันพัง: ผลตอบแทนคาดหวังผิด 1 จุด น้ำหนักขยับ 6.58 จุด

คำตอบทุกข้อข้างบนเชื่อว่าหุ้นให้ผลตอบแทนคาดหวัง 12% พอดี แต่ตัวเลขนี้ประมาณมาจากข้อมูลย้อนหลัง จึงผิดได้ ถ้าความจริงคือ 13% น้ำหนักที่ดีที่สุดจะเปลี่ยนไปแค่ไหน? สูตรของขั้นที่ 3 คือ $x=\tfrac{1}{2\gamma}V^{-1}(\mu-\nu\mathbf1)$ และ $\nu=(B-2\gamma)/A$ โดย $B=\mathbf1^{\mathsf T}V^{-1}\mu$ ทั้ง $x$ และ $\nu$ จึงเป็นเส้นตรงใน $\mu$ เราหา derivative ของน้ำหนักหุ้นเทียบ $\mu_1$ ได้ตรง ๆ ที่ $\gamma=2$ เริ่มจาก $\nu$ เพราะ $\nu$ ขยับตาม $\mu_1$ ด้วย

\[ \begin{aligned} \frac{\partial\nu}{\partial\mu_1}&=\frac{1}{A}\frac{\partial B}{\partial\mu_1}=\frac{(V^{-1}\mathbf1)_1}{A}\\ &=\frac{10.9890}{104.3956}=0.105263,\\ \frac{\partial x_1}{\partial\mu_1}&=\tfrac{1}{2\gamma}\Big((V^{-1})_{11}-(V^{-1}\mathbf1)_1\tfrac{\partial\nu}{\partial\mu_1}\Big)\\ &=\frac{27.4725-10.9890(0.105263)}{4}\\ &=\frac{27.4725-1.1567}{4}=6.5789,\\ x_1(13\%)&=0.50+0.01(6.5789)=0.5658. \end{aligned} \]

$\partial B/\partial\mu_1$ คือผลรวมของหลักแรกของ $V^{-1}$ ซึ่งเท่ากับ $(V^{-1}\mathbf1)_1$ เพราะ $V^{-1}$ สมมาตร ผลลัพธ์บอกว่าผลตอบแทนคาดหวังผิด 1 จุด น้ำหนักหุ้นขยับ 6.58 จุด ตัวขยายนี้มาจาก $V^{-1}$ ซึ่งมีตัวเลขใหญ่เพราะ determinant เล็ก (ขั้นที่ 2)

ความผิด 1 จุดถือว่าใหญ่ไหม? ถ้าประมาณผลตอบแทนคาดหวังจากค่าเฉลี่ยของข้อมูลรายปี 10 ปี ค่าเฉลี่ยนั้นจะคลาดจากค่าจริงโดยทั่วไปประมาณหนึ่ง standard error (SE คือ SD ของตัวประมาณ) สำหรับหุ้นที่ความผันผวน 20% SE ของค่าเฉลี่ย 10 ปีคือ $0.20/\sqrt{10}=0.0632$ คือ 6.32 จุด (standard error ของตัวประมาณ) ความคลาดขนาดหนึ่ง SE จึงขยับน้ำหนักได้ $6.58\times6.32=41.6$ จุด น้ำหนัก 50% จึงอาจควรเป็น $50-41.6=8.4\%$ หรือ $50+41.6=91.6\%$ ก็ได้

ที่แย่กว่าความไม่แน่นอนคือทิศของความผิด optimizer (โปรแกรมที่หาน้ำหนักที่ดีที่สุด) ไม่ได้ผิดแบบสุ่ม แต่ผิดไปทางเดียวเสมอ ดูตัวอย่างสมมติ: มีสองสินทรัพย์ที่เหมือนกันทุกอย่าง ผลตอบแทนจริง 8% ความผันผวน $\sigma=20\%$ และไม่สัมพันธ์กัน คำตอบที่ถูกคือ 50/50 แต่ข้อมูลทำให้ประมาณได้ 10% กับ 6% (ผิด +2 กับ −2 จุด เฉลี่ยแล้วไม่เอนเอียง) เมื่อ $V=\sigma^2I$ สูตรของขั้นที่ 3 ให้ผลต่างน้ำหนัก $x_1-x_2=(\mu_1-\mu_2)/(2\gamma\sigma^2)$ เพราะ $\nu$ ตัดกันเองตอนลบ

\[ \begin{aligned} x_1-x_2&=\frac{0.10-0.06}{2(2)(0.04)}=\frac{0.04}{0.16}=0.25,\\ x_1&=\tfrac{1+0.25}{2}=0.625,\quad x_2=0.375,\\ \hat\mu_p&=0.625(10\%)+0.375(6\%)=8.5\%,\\ \mu_p&=0.625(8\%)+0.375(8\%)=8\%,\\ \sigma_p^2&=0.04(0.625^2+0.375^2)=0.02125,\\ J&=0.08-2(0.02125)=0.0375,\\ J_{50/50}&=0.08-2\big(0.04(0.5^2+0.5^2)\big)\\ &=0.08-2(0.02)=0.04. \end{aligned} \]

$\hat\mu_p$ คือผลตอบแทนที่ optimizer สัญญาจากตัวเลขที่ประมาณ ส่วน $\mu_p$ คือที่ได้จริง optimizer ทุ่มเงินให้ตัวที่บังเอิญดูดีในข้อมูล (62.5/37.5) มันสัญญา 8.5% แต่ได้จริง 8% เท่าเดิม และความผันผวนกลับสูงขึ้นเป็น $\sqrt{0.02125}=14.58\%$ แทนที่จะเป็น $\sqrt{0.02}=14.14\%$ ของ 50/50 คะแนนจริงจึงแพ้ 50/50 ($0.0375\lt0.04$) ทั้งที่ค่าประมาณไม่เอนเอียงเลย เพราะ optimizer เลือกเฉพาะตัวที่ประมาณสูงเกินจริงมาใส่เพิ่ม นี่คือเหตุที่คนเรียก mean-variance ที่ใช้แบบไม่ระวังว่า “ตัวขยายความผิดพลาด” และยิ่งยอมให้ short มาก ยิ่งขยายแรง

กับดัก: ทศนิยมหลายตำแหน่งไม่ได้แปลว่าแม่น

กับดักที่ 1: รายงานน้ำหนักละเอียดเกินกว่าข้อมูลจะรองรับ ที่ $\gamma=2$ optimizer ตอบว่า “หุ้น 50.00%” แต่ขั้นที่ 9 แสดงว่าความคลาดหนึ่ง SE ของผลตอบแทนคาดหวังขยับน้ำหนักได้ $6.58\times6.32=41.6$ จุด คำตอบที่ซื่อตรงคือ “หุ้นอยู่ระหว่าง $50-41.6=8.4\%$ ถึง $50+41.6=91.6\%$” ทศนิยมสองตำแหน่งจึงเป็นความแม่นปลอม

ข้อมูลจริงยิ่งชัดกว่านี้ สเปรดชีตตัวอย่างของคอร์สที่หนังสือเล่มนี้อ้างอิงใช้ค่าเฉลี่ยย้อนหลังของ 8 กลุ่มสินทรัพย์ (พันธบัตรและหุ้นหลายกลุ่ม) ในช่วงที่หุ้นส่วนใหญ่ให้ผลตอบแทนติดลบ และใช้อัตราเงินสด 1.5% tangency ที่ได้ถือพันธบัตรสหรัฐฯ 124.6% และ short หุ้นประเทศพัฒนาแล้วนอกสหรัฐฯ 33.6% โดยมี Sharpe 0.76 ไม่มีใครควรถือพอร์ตแบบนี้จริง ตัวเลขพวกนี้สะท้อน noise ของค่าเฉลี่ยมากกว่าความรู้

ทางแก้ที่ใช้กันจริงมีหลายทาง:

  • หด covariance (และผลตอบแทน) ที่ประมาณได้ เข้าหาค่าเป้าหมายที่เรียบกว่า เพื่อลด noise (Ledoit–Wolf shrinkage)
  • เริ่มจากผลตอบแทนที่ราคาตลาดบอกเป็นนัย แล้วค่อยผสมมุมมองของเราเข้าไปทีละน้อย (Black–Litterman)
  • ใส่ข้อบังคับห้าม short หรือเพดานน้ำหนัก ซึ่งต้องใช้ KKT conditions
  • ทิ้ง $\mu$ ไปเลย แล้วถือ GMV ซึ่งไม่ต้องประมาณผลตอบแทน

ปัญหาหนักขึ้นอีกเมื่อมีสินทรัพย์มาก ถ้ามีหุ้น 500 ตัวแต่มีข้อมูลแค่ 250 วัน sample covariance (covariance ที่คำนวณจากข้อมูล) จะมี rank ไม่เกิน $250-1=249$ เพราะข้อมูล 250 แถวที่หักค่าเฉลี่ยแล้วเหลือทิศที่เป็นอิสระต่อกันได้แค่ 249 ทิศ (covariance matrix) matrix ขนาด 500×500 ที่ rank แค่ 249 กลับไม่ได้ $V^{-1}$ จึงไม่มีด้วยซ้ำ

กับดักที่ 2: ใส่ correlation ลงในช่องที่ต้องเป็น covariance ช่องนอกทแยงของ $V$ ต้องเป็น $\rho\sigma_1\sigma_2$ ไม่ใช่ $\rho$ ถ้าเผลอใส่ 0.30 ลงไปตรง ๆ determinant จะออกมาต่างกันลิบ

  • ผิด (ใส่ $\rho$): $\det V=0.04(0.01)-0.30^2=-0.0896$
  • ถูก (ใส่ $\rho\sigma_1\sigma_2=0.006$): $\det V=0.04(0.01)-0.006^2=0.000364$

determinant ติดลบแปลว่า matrix นี้ไม่ใช่ covariance ของอะไรเลย สูตรจะยังคำนวณต่อได้ แต่จะให้พอร์ตที่มี “variance ติดลบ” ซึ่งไร้ความหมาย เห็น determinant ติดลบเมื่อไรให้หยุด แล้วกลับไปสร้าง $V$ ใหม่ โค้ดท้ายหน้าปฏิเสธกรณีนี้ให้อัตโนมัติ

กับดักที่ 3: คิดว่าพอร์ตที่เสี่ยงน้อยที่สุดคือพอร์ตที่คุ้มที่สุด GMV เสี่ยงน้อยที่สุด แต่ Sharpe ของมันคือ $(6.6316\%-2\%)/9.7872\%=0.4732$ ต่ำกว่าหุ้นล้วนที่ได้ 0.50 ด้วยซ้ำ ส่วนพอร์ตที่คุ้มที่สุดคือ tangency ที่ได้ 0.5645 ถ้าคณะกรรมการสั่งทั้ง “เสี่ยงน้อยที่สุด” และ “คุ้มที่สุด” นั่นคือสองคำสั่งที่ขัดกัน ต้องถามกลับให้ชัดว่าต้องการอันไหน

กับดักที่ 4: ลืมว่า variance มองไม่เห็นอะไรบ้าง variance ลงโทษการขึ้นแรงเท่ากับการลงแรง และบอกความเสี่ยงได้ครบเฉพาะเมื่อผลตอบแทนเป็น Normal ถ้าผลตอบแทนมีหางหนา (ขาดทุนก้อนใหญ่เกิดบ่อยกว่าที่ Normal บอก) ต้องดูขาดทุนก้อนใหญ่โดยตรงด้วย VaR และ expected shortfall อีกข้อหนึ่ง น้ำหนักติดลบในคำตอบคือการ short ซึ่งขาดทุนได้ไม่จำกัด เพราะราคาขึ้นได้ไม่มีเพดาน ต่างจากการซื้อถือ (long) ที่เสียได้มากสุดแค่เงินที่ลงไป

บริษัทจัดการกองทุนมักขายกองทุนผสมสามแบบ: กล้าเสี่ยง สมดุล และระมัดระวัง ในภาษาของหน้านี้ ทั้งสามคือ $\gamma$ ต่างกัน one-fund theorem บอกว่าโครงของทั้งสามกองควรเหมือนกัน คือส่วนผสมเสี่ยงสัดส่วนเดียวกันในขนาดต่างกัน แล้วเติมหรือกู้เงินสด ถ้าลงเงินครบและไม่มีเงินสด ก็คือ GMV บวกพอร์ตเก็งกำไรในขนาดต่างกัน (ขั้นที่ 4)

ความชันของ capital market line ใช้เป็น “ราคาของความเสี่ยง” เพื่อคัดโครงการลงทุนได้ โครงการที่ให้ผลตอบแทนต่ำกว่าเส้นนี้ที่ความผันผวนเท่ากัน แพ้การผสมตลาดกับเงินสดอยู่แล้ว จึงไม่ควรลงทุน (ดูโจทย์ข้อ 3)

ตัวเลขของหน้านี้เป็นจุดเริ่มคุย ไม่ใช่คำสั่งซื้อขาย ข่าวดีคือพอร์ตที่ “เกือบถูก” เสียน้อยกว่าที่คิด 50/50 ได้ Sharpe 0.5623 เทียบกับยอด 0.5645 เพราะยอดของ Sharpe แบนมาก การไล่น้ำหนักให้ตรงยอดเป๊ะจึงไม่คุ้ม เมื่อตัวเลข $\mu$ เองอาจผิดได้หลายจุด

  const det = V[0][0] * V[1][1] - V[0][1] * V[1][0];
  if (!(det > 0 && V[0][0] > 0)) throw new RangeError(`Covariance must be positive definite (det = ${det})`);
  return [[V[1][1] / det, -V[0][1] / det], [-V[1][0] / det, V[0][0] / det]];
}
const times = (M, x) => M.map(r => r.reduce((t, v, j) => t + v * x[j], 0));
const dot = (a, b) => a.reduce((t, v, i) => t + v * b[i], 0);
function summaries(V, mu) {
  const inv = inverse2(V), Vinv1 = times(inv, [1, 1]), Vinvmu = times(inv, mu);
  const A = Vinv1[0] + Vinv1[1], B = Vinvmu[0] + Vinvmu[1], C = dot(mu, Vinvmu);
  return {inv, Vinv1, Vinvmu, A, B, C, D: A * C - B * B};
}
// max mu'x - gamma x'Vx with weights summing to 1: x = V^-1 (mu - nu 1) / (2 gamma)
function meanVariance(V, mu, gamma) {
  if (!(gamma > 0)) throw new RangeError('gamma must be positive');
  const s = summaries(V, mu), nu = (s.B - 2 * gamma) / s.A;
  const x = times(s.inv, [mu[0] - nu, mu[1] - nu]).map(v => v / (2 * gamma));
  const variance = dot(x, times(V, x)), ret = dot(mu, x);
  return {nu, x, ret, sd: Math.sqrt(variance), J: ret - gamma * variance};
}

function tangency(V, mu, rf) {
  const s = summaries(V, mu), e = times(s.inv, [mu[0] - rf, mu[1] - rf]), total = e[0] + e[1];
  if (!(total > 0)) throw new RangeError('Cash rate at or above the GMV return: no tangency on the upper branch');

}

function frontierWeights(V, mu, m) {
  const n = mu.length, M = V.map((r, i) => [...r.map(v => 2 * v), -1, -mu[i], 0]);
  M.push([...mu.map(() => 1), 0, 0, 1], [...mu, 0, 0, m]);
  for (let c = 0; c < n + 2; c++) {
    let p = c;
    for (let r = c + 1; r < n + 2; r++) if (Math.abs(M[r][c]) > Math.abs(M[p][c])) p = r;
    [M[c], M[p]] = [M[p], M[c]];
    for (let r = 0; r < n + 2; r++) if (r !== c) { const f = M[r][c] / M[c][c]; for (let k = c; k <= n + 2; k++) M[r][k] -= f * M[c][k]; }
  }
  return M.slice(0, n).map((r, i) => r[n + 2] / r[i]);
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ผลตอบแทนของส่วนผสมเป็นค่าเฉลี่ยถ่วงน้ำหนัก แต่ความผันผวนต่ำกว่าค่าเฉลี่ยถ่วงน้ำหนักเมื่อ correlation ต่ำกว่า 1 เพราะการแกว่งหักล้างกันบางส่วน หุ้นครึ่งพันธบัตรครึ่งจึงผันผวน 12.45% ไม่ใช่ 15%
  • พอร์ตที่ลงเงินครบและคะแนน mean-variance สูงสุดคือ $x=V^{-1}(\mu-\nu\mathbf1)/(2\gamma)$ โดย $\nu=(B-2\gamma)/A$ ที่ $\gamma=2$ ได้ 50/50 ทุกคำตอบแยกได้เป็น GMV (หุ้น 10.53%) บวกพอร์ตเก็งกำไรที่ไม่ใช้เงิน ขนาด $1/(2\gamma)$
  • efficient frontier คือ $\sigma^2(m)=(Am^2-2Bm+C)/D$ น้ำหนักบนเส้นเป็นเส้นตรงใน $m$ จึงสร้างทุกพอร์ตบนเส้นได้จากสองกองทุน
  • เมื่อมีเงินสด 2% ทุกคนถือ tangency (หุ้น 43.18% Sharpe 0.5645) ต่างกันแค่ขนาด ที่เหลือฝากหรือกู้เงินสด พันธบัตรช่วยเพิ่ม Sharpe เพราะ Sharpe ของมันผ่านเงื่อนไข $0.40\gt\rho\times0.50=0.15$
  • ที่ tangency สินทรัพย์ทุกตัวได้ $\mu_j-r_f=\beta_j(\mu_T-r_f)$ (หุ้น beta 1.52 พันธบัตร 0.61) ถ้าทุกคนเชื่อตัวเลขเดียวกัน tangency คือตลาด และสูตรนี้คือ CAPM
  • ผลตอบแทนคาดหวังผิด 1 จุด น้ำหนักขยับ 6.58 จุด ขณะที่ค่าเฉลี่ยจากข้อมูล 10 ปีคลาดได้ราว 6.32 จุด (หนึ่ง SE) น้ำหนักจาก optimizer จึงเป็นจุดเริ่มคุย ไม่ใช่คำสั่งซื้อขาย
