12.5 Markowitz Portfolio Selection

ผลตอบแทนเฉลี่ยตามน้ำหนักเป็นเส้นตรง แต่ความเสี่ยงไม่ใช่ ช่องว่างนี้ทำให้ส่วนผสมชนะสินทรัพย์ที่ดีที่สุดตัวเดียว และตัวคูณ Lagrange วาดเมนูของส่วนผสมทั้งหมดออกมาเป็นเส้นเดียว

แบบจำลองรายปีของบทนี้: หุ้นคาดหวัง 12% SD 20% พันธบัตรคาดหวัง 6% SD 10% correlation 0.30 เงินสดได้ 2% ผลตอบแทนส่วนเกินเงินสดต่อหน่วยความเสี่ยง (Sharpe ratio) ของหุ้นคือ 10%/20% = 0.50 ของพันธบัตรคือ 4%/10% = 0.40 ผู้จัดการกองทุนคนหนึ่งบอกว่าหุ้นคุ้มกว่าต่อหน่วยความเสี่ยง ใครอยากได้ Sharpe สูงสุดก็ควรถือหุ้นล้วน แล้วค่อยปรับระดับความเสี่ยงด้วยเงินสด ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก พอร์ตหุ้น 43.18% พันธบัตร 56.82% ได้ Sharpe 0.5645 สูงกว่าหุ้นล้วน แค่ย้ายหุ้น 5% ไปพันธบัตร Sharpe ก็ขึ้นเป็น 0.5064 แล้ว เพราะพันธบัตรที่ correlation กับหุ้นแค่ 0.30 หักความผันผวนได้มากกว่าผลตอบแทนที่เสียไป ส่วนกองทุนที่ต้องลงเงินครบและกลัวความเสี่ยงระดับ $\gamma=2$ ควรถือ 50/50 ซึ่งได้ Sharpe 0.5623 ใกล้ยอดมาก

สิ่งที่เราจะสร้าง

12.3 หาพอร์ตที่ดีที่สุดเมื่อมีเงินสดไม่จำกัด 12.4 ให้เครื่องมือ Lagrange สำหรับข้อบังคับ หน้านี้เอาสองอย่างมารวมกันเป็นโจทย์ของ Harry Markowitz: เลือกน้ำหนักให้ผลตอบแทนคาดหวังหักค่าปรับความเสี่ยงดีที่สุด เมื่อต้องลงเงินครบ 100%

เราจะกลับ covariance ด้วยมือ แก้โจทย์ด้วยตัวคูณหนึ่งตัว อ่านความหมายของมัน แยกคำตอบเป็นพอร์ตความเสี่ยงต่ำสุดบวกพอร์ตเก็งกำไรที่ปรับขนาดตาม $\gamma$ วาด efficient frontier ด้วยตัวคูณสองตัว หา tangency portfolio เมื่อมีเงินสด อธิบายว่าทำไมผสมตัวที่ Sharpe ต่ำกว่าแล้ว Sharpe รวมสูงขึ้น และจบที่จุดอ่อนใหญ่ที่สุด: คำตอบไวต่อผลตอบแทนคาดหวังที่ประมาณได้หยาบ

ขั้นที่ 1 — ตั้งโจทย์ และกลับ covariance ด้วยมือ

โจทย์คือหา $x$ ที่ทำให้ $\mu^{\mathsf T}x-\gamma x^{\mathsf T}Vx$ สูงสุด โดย $\mathbf1^{\mathsf T}x=1$ และติดลบได้ (short ได้) ทุกคำตอบในหน้านี้ผ่าน $V^{-1}$ จึงคำนวณมันก่อน inverse ของ 2×2 คือสลับทแยง เปลี่ยนเครื่องหมายนอกทแยง แล้วหารด้วย determinant (7.5)

\[ \begin{aligned} \mu&=\begin{bmatrix}0.12\\0.06\end{bmatrix},\\ V&=\begin{bmatrix}0.04&0.006\\0.006&0.01\end{bmatrix},\\ \det V&=0.04(0.01)-0.006^2=0.000364,\\ V^{-1}&=\frac{1}{0.000364}\begin{bmatrix}0.01&-0.006\\-0.006&0.04\end{bmatrix}\\ &\approx\begin{bmatrix}27.4725&-16.4835\\-16.4835&109.8901\end{bmatrix},\\ (VV^{-1})_{11}&=0.04(27.4725)+0.006(-16.4835)\\ &=1.0989-0.0989=1. \end{aligned} \]

ตัวเลขในตารางกลับใหญ่เพราะหารด้วย determinant ที่เล็ก 109.89 ไม่ได้แปลว่าพันธบัตรเสี่ยง 109 เท่า มันมีหน่วยเป็นหนึ่งส่วน variance ช่องใหญ่สุดตกกับตัวที่เงียบที่สุด เพราะ $V^{-1}$ ให้รางวัลกับความนิ่ง ตรวจครบทั้งสี่ช่องของ $VV^{-1}$ ได้ตาราง identity (โค้ดท้ายหน้าพิมพ์ให้)

ขั้นที่ 2 — Lagrangian ให้คำตอบทั่วไป แล้วงบเป็นตัวหา ν

ใช้สูตรของ 12.4 ติดราคา $\nu$ ให้ข้อบังคับลงเงินครบ หา derivative เทียบ $x$ ตั้งเป็นศูนย์ ย้ายข้าง แล้วคูณ $V^{-1}$ ทางซ้ายแทนการ “หารด้วย matrix”

\[ \begin{aligned} \mathcal L&=\mu^{\mathsf T}x-\gamma x^{\mathsf T}Vx-\nu(\mathbf1^{\mathsf T}x-1),\\ 0&=\mu-2\gamma Vx-\nu\mathbf1,\\ x&=\frac{1}{2\gamma}V^{-1}(\mu-\nu\mathbf1),\\ 1&=\mathbf1^{\mathsf T}x=\frac{B-\nu A}{2\gamma},\\ \nu&=\frac{B-2\gamma}{A}. \end{aligned} \]

บรรทัดที่สองใช้ gradient ของ 12.2 และ 12.3 บรรทัดที่สี่เอา $\mathbf1^{\mathsf T}$ คูณคำตอบ แล้วตั้งชื่อ $A=\mathbf1^{\mathsf T}V^{-1}\mathbf1$ และ $B=\mathbf1^{\mathsf T}V^{-1}\mu$ ซึ่งเป็นแค่ตัวเลขสองตัว ข้อบังคับจึงให้ $\nu$ ออกมาทันที ต่อไปนี้ทุกอย่างสร้างจาก $V^{-1}\mathbf1$ กับ $V^{-1}\mu$

\[ \begin{aligned} (V^{-1}\mathbf1)_1&\approx27.4725-16.4835=10.9890,\\ (V^{-1}\mathbf1)_2&\approx-16.4835+109.8901=93.4066,\\ (V^{-1}\mu)_1&\approx3.2967-0.9890=2.3077,\\ (V^{-1}\mu)_2&\approx-1.9780+6.5934=4.6154,\\ A&\approx104.3956,\quad B\approx6.9231,\\ C&=\mu^{\mathsf T}V^{-1}\mu\approx0.2769+0.2769=0.553846. \end{aligned} \]

ขั้นที่ 3 — γ = 2: ครึ่งต่อครึ่งพอดี

โจทย์ให้อะไรมาบ้าง: $\gamma=2$ จึง $2\gamma=4$ ใช้ $A$ กับ $B$ ของขั้นที่ 2 หา $\nu$ ก่อน หักออกจากผลตอบแทนคาดหวังทุกตัว แล้วคูณ $V^{-1}$

\[ \begin{aligned} \nu&=\frac{6.9231-4}{104.3956}=0.028,\\ \mu-\nu\mathbf1&=(0.092,\ 0.032),\\ V^{-1}(\mu-\nu\mathbf1)&\approx(2.5275-0.5275,\ -1.5165+3.5165)\\ &=(2,\ 2),\qquad x=(0.5,\ 0.5),\\ \mu_p&=0.09,\quad\sigma_p^2=0.0155,\quad\sigma_p\approx12.45\%,\\ J&=0.09-2(0.0155)=0.059. \end{aligned} \]

คำตอบ: หุ้นครึ่งพันธบัตรครึ่ง ผลตอบแทน 9.00% ความผันผวน 12.45% ค่าเป้าหมาย 0.059 ชนะถือตัวเดียว ซึ่งได้ $0.12-2(0.04)=0.04$ และ $0.06-2(0.01)=0.04$ เท่ากันพอดี ความโค้งของ $J$ คือ $-4V$ (12.3) คงที่และคว่ำทุกทิศ จุดนี้จึงเป็นยอดสูงสุดของทั้งเส้นลงเงินครบ

ตรวจเองใน 10 วินาที: $0.5+0.5=1$ ข้อบังคับที่ $\nu$ ถูกสร้างมาเพื่อบังคับ ถ้าผลรวมไม่ได้ 1 แปลว่าคำนวณ $\nu$ ผิด ไม่ใช่ $x$ ผิด ส่วน variance ต้องกางเต็ม: $0.25(0.04)+0.25(0.01)+2(0.25)(0.006)=0.0155$ ต่ำกว่าค่าเฉลี่ยของ 0.04 กับ 0.01 ที่ 0.025 มาก ผลตอบแทนเฉลี่ยเป็นเส้นตรง ความเสี่ยงไม่ใช่

ขั้นที่ 4 — ν = 2.8% คือราคาของงบ และติดลบได้

ตามขั้นที่ 5 ของ 12.4 ตัวคูณคืออัตราเปลี่ยนของค่าเป้าหมายที่ดีที่สุดต่องบ ทดสอบด้วยการแก้โจทย์ใหม่ที่งบ 101% ใช้สูตรเดิมแต่ $\nu=(B-2\gamma b)/A$

\[ \begin{aligned} \nu(1.01)&=\frac{6.9231-4.04}{104.3956}\approx0.027617,\\ x(1.01)&\approx(0.501053,\ 0.508947),\\ J(1.01)&\approx0.059278,\\ \frac{J(1.01)-J(1)}{0.01}&\approx0.0278. \end{aligned} \]

อัตรา 0.0278 อยู่ระหว่าง $\nu(1)=0.028$ กับ $\nu(1.01)=0.0276$ เพราะราคาเงาลดลงระหว่างที่เพิ่มงบ เหมือนที่ 12.4 เห็นกับทุนของเดสก์ อ่านเป็นภาษาโต๊ะ: ถ้าผ่อนให้ลงเงินได้ 101% ค่าเป้าหมายเพิ่มราว 2.8% ของเงินส่วนที่เพิ่ม

$\nu$ ของข้อบังคับแบบสมการติดลบได้ ที่ $\gamma=4$ ได้ $\nu=(6.9231-8)/104.3956\approx-0.0103$ แปลว่าคนที่กลัวมากขนาดนี้อยากลงเงินน้อยกว่า 100% ถ้าทำได้ ข้อบังคับกำลังบังคับให้เขาเสี่ยงเกินใจ ไม่ใช่ความผิดพลาดของการคำนวณ

ขั้นที่ 5 — แยกคำตอบ: พอร์ตความเสี่ยงต่ำสุด บวกพอร์ตเก็งกำไรที่ปรับขนาดด้วย γ

แทน $\nu=(B-2\gamma)/A$ กลับในคำตอบของขั้นที่ 2 แล้วจัดกลุ่มตามว่าพจน์ไหนมี $\gamma$ จะเห็นโครงของคำตอบทุก $\gamma$ พร้อมกัน

\[ \begin{aligned} x(\gamma)&=\frac{V^{-1}\mu}{2\gamma}-\frac{B-2\gamma}{2\gamma A}V^{-1}\mathbf1\\ &=\frac{V^{-1}\mathbf1}{A}+\frac{1}{2\gamma}\Big(V^{-1}\mu-\frac BAV^{-1}\mathbf1\Big),\\ \frac{V^{-1}\mathbf1}{A}&\approx(0.105263,\ 0.894737),\\ z&=V^{-1}\mu-\frac BAV^{-1}\mathbf1\approx(1.578947,\ -1.578947),\\ x_1(\gamma)&=\frac{2}{19}+\frac{15}{19\gamma}. \end{aligned} \]

ก้อนแรกคือพอร์ตความเสี่ยงต่ำสุด (GMV) ของ 12.4 ไม่มี $\gamma$ และไม่มี $\mu$ ก้อนที่สอง $z$ มีผลรวมน้ำหนักเป็นศูนย์ ($\mathbf1^{\mathsf T}z=B-B=0$) คือพอร์ต long หุ้น short พันธบัตรที่ไม่ใช้เงิน ขนาดของมันคือ $1/(2\gamma)$ ยิ่งกลัว ยิ่งถือก้อนเก็งกำไรน้อย

ตรวจ: $\gamma=2$ ได้ $2/19+7.5/19=0.5$ ตรงกับขั้นที่ 3 $\gamma=1$ ได้หุ้น 89.47% ผลตอบแทน 11.37% SD 18.24% $\gamma=4$ ได้หุ้น 30.26% ผลตอบแทน 7.82% SD 10.52% และเมื่อ $\gamma$ โตไม่หยุด เหลือ GMV หุ้น 10.53% SD 9.787% ผลตอบแทน $B/A\approx6.63\%$

ขั้นที่ 6 — efficient frontier: สองข้อบังคับ สองตัวคูณ

แทนที่จะไล่ $\gamma$ ถามอีกแบบ: ถ้าต้องการผลตอบแทน $m$ พอดี variance ต่ำสุดเท่าไร ข้อบังคับมีสองข้อ ($\mathbf1^{\mathsf T}x=1$ และ $\mu^{\mathsf T}x=m$) จึงมีตัวคูณสองตัว ความชันศูนย์ของ Lagrangian ให้ $Vx$ เป็นผลรวมของ $\mathbf1$ กับ $\mu$ (ตัวคูณที่หารสองแล้วเรียก $\alpha$, $\beta$)

\[ \begin{aligned} x&=V^{-1}(\alpha\mathbf1+\beta\mu),\\ 1&=A\alpha+B\beta,\qquad m=B\alpha+C\beta,\\ \alpha&=\frac{C-Bm}{D},\qquad\beta=\frac{Am-B}{D},\\ \sigma^2(m)&=x^{\mathsf T}Vx=x^{\mathsf T}(\alpha\mathbf1+\beta\mu)=\alpha+\beta m\\ &=\frac{Am^2-2Bm+C}{D},\\ D&=AC-B^2\approx57.8191-47.9290=9.8901. \end{aligned} \]

แทนรูปของ $x$ ลงในสองข้อบังคับ ได้ระบบเชิงเส้น 2×2 ของ $\alpha$, $\beta$ แก้ด้วยกฎกลับ 2×2 จังหวะเด็ดคือบรรทัดที่สี่: $Vx$ คือ $\alpha\mathbf1+\beta\mu$ พอดี คูณ $x^{\mathsf T}$ เข้าไปได้ผลรวมน้ำหนัก (=1) กับผลตอบแทน (=$m$) ซึ่งข้อบังคับกำหนดไว้แล้ว ต้องมี $D\gt0$ คือผลตอบแทนคาดหวังของสองตัวไม่เท่ากัน

ตรวจสองจุดที่รู้คำตอบ: $m=9\%$ ตัวเศษ $0.845604-1.246154+0.553846=0.153296$ หาร $D$ ได้ 0.0155 ตรงกับขั้นที่ 3 และที่ $m=B/A$ ได้ $1/A$ ตรงกับ GMV เส้นเป็นพาราโบลาใน $m$ ครึ่งบนตั้งแต่ GMV คือ efficient frontier

สองข้อที่ต้องรู้: $\alpha$ กับ $\beta$ เป็นเส้นตรงใน $m$ น้ำหนัก $x(m)$ จึงเป็นเส้นตรงใน $m$ ด้วย พอร์ตบนเส้นทุกพอร์ตจึงเป็นส่วนผสมของสองพอร์ตบนเส้น นี่คือ two-fund separation และในกรณีสองสินทรัพย์ ข้อบังคับสองข้อตรึงน้ำหนักไว้แล้ว (หุ้น $=(m-0.06)/0.06$) สูตร frontier มีพลังจริงเมื่อมีสามสินทรัพย์ขึ้นไป ซึ่งสูตรเดิมใช้ได้ทุกตัวอักษร

ขั้นที่ 7 — มีเงินสด 2%: tangency portfolio

เมื่อผสมพอร์ตเสี่ยงกับเงินสดได้ พอร์ตเสี่ยงที่ดีที่สุดคือตัวที่ Sharpe สูงสุด เพราะเส้นจากเงินสดผ่านมันชันที่สุด 12.3 หาพอร์ตนี้ในรูปที่ขยายแล้ว คือ $V^{-1}(\mu-r_f\mathbf1)$ หารด้วย $2\gamma$ ที่นี่หารด้วยผลรวมแทน เพื่อให้เป็นพอร์ตเสี่ยงที่ลงเงินครบ

\[ \begin{aligned} V^{-1}(\mu-r_f\mathbf1)&=V^{-1}(0.10,\ 0.04)\\ &\approx(2.0879,\ 2.7473),\\ 2.0879+2.7473&=4.8352,\\ x_T&\approx(0.431818,\ 0.568182),\\ \mu_T&\approx0.085909,\quad\sigma_T\approx0.116753,\\ \mathrm{SR}_T&=\frac{0.085909-0.02}{0.116753}\approx0.5645,\\ \mathrm{SR}_{\max}^2&=C-2r_fB+r_f^2A\\ &\approx0.553846-0.276923+0.041758=0.318681. \end{aligned} \]

หุ้น 43.18% ($=19/44$) พันธบัตร 56.82% Sharpe 0.5645 บรรทัดสุดท้ายตรวจโดยไม่ผ่านน้ำหนักเลย: $\sqrt{0.318681}=0.5645$ ตรงกัน (มาจากการกาง $(\mu-r_f\mathbf1)^{\mathsf T}V^{-1}(\mu-r_f\mathbf1)$ ด้วย $A, B, C$) สูตรไม่มี $\gamma$ เพราะส่วนผสมที่ดีที่สุดไม่ขึ้นกับว่ากลัวแค่ไหน

พอร์ตของ 12.3 ที่ $\gamma=2$ คือส่วนผสมนี้ขยาย 120.88% โดยกู้เงินสด 20.88% ส่วนคนที่ $\gamma=4$ ถือส่วนผสมเดียวกัน 60.44% ที่เหลือเป็นเงินสด ทุกคนถือพอร์ตเสี่ยงหน้าตาเดียวกัน ต่างกันแค่ขนาด

ขั้นที่ 8 — ทำไมผสมตัวที่ Sharpe ต่ำกว่า แล้ว Sharpe รวมสูงขึ้น

นี่คือจุดที่ผู้จัดการในโจทย์เปิดเรื่องพลาด เริ่มจากหุ้นล้วน แล้วย้ายน้ำหนัก $\varepsilon$ ไปพันธบัตร ดูว่า Sharpe เปลี่ยนทิศไหน ให้ $e_1=0.10$, $e_2=0.04$ เป็นผลตอบแทนส่วนเกิน

\[ \begin{aligned} e(\varepsilon)&=(1-\varepsilon)e_1+\varepsilon e_2,\\ \sigma(\varepsilon)^2&=(1-\varepsilon)^2\sigma_1^2+\varepsilon^2\sigma_2^2\\ &\quad+2\varepsilon(1-\varepsilon)\rho\sigma_1\sigma_2,\\ \sigma'(0)&=\frac{-2\sigma_1^2+2\rho\sigma_1\sigma_2}{2\sigma_1}=-\sigma_1+\rho\sigma_2,\\ \mathrm{SR}'(0)&=\frac{(e_2-e_1)\sigma_1-e_1\sigma'(0)}{\sigma_1^2}\\ &=\frac{e_2\sigma_1-e_1\rho\sigma_2}{\sigma_1^2}\\ &=\frac{0.04(0.2)-0.10(0.3)(0.1)}{0.04}=0.125. \end{aligned} \]

บรรทัดที่สามคือ derivative ของ $\sigma^2$ ที่ $\varepsilon=0$ หารด้วย $2\sigma$ (chain rule ของราก) บรรทัดที่สี่คือกฎผลหาร Sharpe ขึ้นเมื่อตัวเศษบวก คือ $e_2/\sigma_2\gt\rho\,e_1/\sigma_1$: Sharpe ของพันธบัตร 0.40 ขอแค่เกิน $0.30\times0.50=0.15$ ไม่ต้องเกิน 0.50

ตรวจด้วยตัวเลข: ย้าย 5% ทำนาย $0.50+0.05(0.125)=0.50625$ คำนวณตรงได้ 0.50637 ตารางข้างล่างคือ Sharpe ของทุกพอร์ตในหน้านี้

ขั้นที่ 9 — ทำให้มันพัง: ผลตอบแทนคาดหวังผิด 1 จุด น้ำหนักขยับ 6.58 จุด

คำตอบทุกข้อข้างบนเชื่อว่าหุ้นคาดหวัง 12% พอดี ถ้าจริง ๆ เป็น 13% ล่ะ เพราะ $x$ เป็นเส้นตรงใน $\mu$ (ขั้นที่ 2 โดย $\nu$ ก็เป็นเส้นตรงใน $\mu$) หา derivative ของน้ำหนักหุ้นเทียบ $\mu_1$ ได้ตรง ๆ

\[ \begin{aligned} \frac{\partial\nu}{\partial\mu_1}&=\frac{(V^{-1}\mathbf1)_1}{A}=\frac{10.9890}{104.3956}\approx0.105263,\\ \frac{\partial x_1}{\partial\mu_1}&=\frac{1}{2\gamma}\Big((V^{-1})_{11}-(V^{-1}\mathbf1)_1\frac{\partial\nu}{\partial\mu_1}\Big)\\ &\approx\frac{27.4725-1.1567}{4}\approx6.5789,\\ \mu_1=13\%:&\quad x_1\approx0.50+0.065789=0.565789. \end{aligned} \]

ผลตอบแทนคาดหวังผิด 1 จุด น้ำหนักหุ้นขยับ 6.58 จุด ตัวขยายนี้มาจาก $V^{-1}$ ซึ่งใหญ่เพราะ determinant เล็ก ความผิด 1 จุดใหญ่แค่ไหน? ค่าเฉลี่ยจากข้อมูลรายปี 10 ปีของหุ้นที่ SD 20% มี standard error $0.20/\sqrt{10}\approx6.32$ จุด (3.3) หนึ่ง SE ของความไม่แน่นอนจึงขยับน้ำหนักได้ $6.58\times6.32\approx41.6$ จุด จาก 50% ไปได้ทั้ง 8.4% และ 91.6%

คำถามที่ควรถามออกมาดัง ๆ

หุ้นผันผวนเป็นสองเท่า ทำไมได้ครึ่งหนึ่งที่ γ = 2? เพราะผลตอบแทนส่วนเกินของมันก็สูงกว่า 2.5 เท่า (10% กับ 4%) คำตอบเป็นการชั่งทั้งสองอย่างผ่าน $V^{-1}$ ไม่ใช่ดู SD อย่างเดียว ถ้าลด $\mu_1$ ลง 1 จุด หุ้นหายไป 6.58 จุดทันที

สินทรัพย์ที่ผลตอบแทนคาดหวังต่ำกว่า ν จะถูก short เสมอไหม? ไม่เสมอ น้ำหนักแต่ละตัวคือแถวหนึ่งของ $V^{-1}$ คูณ $\mu-\nu\mathbf1$ ทั้ง vector เครื่องหมายจึงขึ้นกับผลตอบแทนส่วนเกินของทุกตัวและ correlation ไม่ใช่ของตัวเองตัวเดียว

กับดัก: ทศนิยมหลายตำแหน่งไม่ได้แปลว่าแม่น

ขั้นที่ 9 คือกับดักหลัก รายงานน้ำหนัก 50.00% ขณะที่หนึ่ง SE ของ input ขยับมันได้ 41.6 จุด คือความแม่นปลอม ทางแก้ที่โต๊ะใช้: หด covariance (17.8) ผสมมุมมองกับค่ากลางของตลาด (17.9) ใส่เพดานน้ำหนักด้วย KKT (12.6) หรือทิ้ง $\mu$ แล้วใช้ GMV ซึ่งไม่ต้องประมาณผลตอบแทนเลย ถ้ามี 500 หุ้นแต่ข้อมูลแค่ 250 วัน sample covariance มี rank ไม่เกิน 249 (8.1) $V^{-1}$ ไม่มีด้วยซ้ำ

อย่าใส่ correlation แทน covariance ถ้าเผลอใส่ 0.30 ในช่องนอกทแยง determinant จะเป็น $0.04(0.01)-0.09=-0.0896$ matrix นี้ไม่ใช่ covariance และสูตรจะให้พอร์ตที่ “variance ติดลบ” เห็น determinant ติดลบเมื่อไรให้หยุดแล้วกลับไปขั้นที่ 1 โค้ดท้ายหน้าปฏิเสธกรณีนี้

ความเสี่ยงต่ำสุดกับความคุ้มสูงสุดเป็นคนละพอร์ต GMV มี Sharpe 0.4732 ต่ำกว่าหุ้นล้วนด้วยซ้ำ ถ้าคณะกรรมการสั่งทั้ง “เสี่ยงน้อยที่สุด” และ “คุ้มที่สุด” นั่นคือสองคำสั่งที่ขัดกัน ต้องถามกลับให้ชัด

function inverse2(V) {
  if (!Array.isArray(V) || V.length !== 2 || V.some(r => !Array.isArray(r) || r.length !== 2 || !r.every(Number.isFinite))) {
    throw new TypeError('Need a finite 2 by 2 covariance');
  }
  if (V[0][1] !== V[1][0]) throw new RangeError('Covariance must be symmetric');
  const det = V[0][0] * V[1][1] - V[0][1] * V[1][0];
  if (!(det > 0 && V[0][0] > 0)) throw new RangeError(`Covariance must be positive definite (det = ${det})`);
  return {det, inv: [[V[1][1] / det, -V[0][1] / det], [-V[1][0] / det, V[0][0] / det]]};
}
const times = (M, x) => M.map(r => r[0] * x[0] + r[1] * x[1]);
const dot = (a, b) => a[0] * b[0] + a[1] * b[1];
// The four numbers that summarise the two-asset universe.
function summaries(V, mu) {
  if (!Array.isArray(mu) || mu.length !== 2 || !mu.every(Number.isFinite)) throw new TypeError('Need two finite expected returns');
  const {det, inv} = inverse2(V), Vinv1 = times(inv, [1, 1]), Vinvmu = times(inv, mu);
  const A = Vinv1[0] + Vinv1[1], B = Vinvmu[0] + Vinvmu[1], C = dot(mu, Vinvmu);
  return {det, inv, Vinv1, Vinvmu, A, B, C, D: A * C - B * B};
}
// max mu'x - gamma x'Vx with weights summing to b: x = V^-1 (mu - nu 1) / (2 gamma).
function meanVariance(V, mu, gamma, b = 1) {
  if (!Number.isFinite(gamma) || gamma <= 0) throw new RangeError('gamma must be positive for a maximum');
  const s = summaries(V, mu), nu = (s.B - 2 * gamma * b) / s.A;
  const x = times(s.inv, [mu[0] - nu, mu[1] - nu]).map(v => v / (2 * gamma));
  const variance = dot(x, times(V, x)), ret = dot(mu, x);
  return {nu, x, ret, sd: Math.sqrt(variance), J: ret - gamma * variance};
}
// Lowest variance for target return m with weights summing to 1.
function frontierVariance(V, mu, m) {
  const s = summaries(V, mu);
  if (!(s.D > 1e-12 * s.A * s.C)) throw new RangeError('Equal expected returns: the frontier collapses to one point');
  return (s.A * m * m - 2 * s.B * m + s.C) / s.D;
}
function tangency(V, mu, rf) {
  const s = summaries(V, mu), e = times(s.inv, [mu[0] - rf, mu[1] - rf]), total = e[0] + e[1];
  if (!(total > 0)) throw new RangeError('Cash rate at or above the minimum-variance return: no tangency on the efficient branch');
  const x = e.map(v => v / total), ret = dot(mu, x), sd = Math.sqrt(dot(x, times(V, x)));
  return {x, ret, sd, sharpe: (ret - rf) / sd, sharpeClosed: Math.sqrt(s.C - 2 * rf * s.B + rf * rf * s.A)};
}

ที่มาที่ไป

Harry Markowitz ตีพิมพ์ “Portfolio Selection” ใน Journal of Finance ปี 1952 ข้อเสนอหลักคือความเสี่ยงของพอร์ตขึ้นกับ covariance ไม่ใช่ผลรวมความเสี่ยงรายตัว ก่อนหน้านั้นตำราลงทุนเน้นหาหุ้นที่ดีที่สุดทีละตัว James Tobin เพิ่มเงินสดเข้ามาในปี 1958 และแสดงว่าทุกคนควรถือพอร์ตเสี่ยงเดียวกันต่างกันแค่ขนาด Markowitz ได้รางวัลโนเบลสาขาเศรษฐศาสตร์ปี 1990 ร่วมกับ Merton Miller และ William Sharpe

สิ่งที่ควรตอบได้หลังอ่าน

  • mean-variance ที่ลงเงินครบให้ $x=V^{-1}(\mu-\nu\mathbf1)/(2\gamma)$ และงบให้ $\nu=(B-2\gamma)/A$ ที่ $\gamma=2$ ได้ 50/50, $\nu=2.8\%$
  • ทุกคำตอบคือ GMV (หุ้น 10.53%) บวกพอร์ตเก็งกำไรที่ไม่ใช้เงินขนาด $1/(2\gamma)$: หุ้น $=2/19+15/(19\gamma)$

  • tangency ที่เงินสด 2% คือหุ้น 43.18% Sharpe 0.5645 สูงกว่าหุ้นล้วน 0.50 เพราะพันธบัตรผ่านเงื่อนไข $0.40\gt0.30\times0.50$
  • ผลตอบแทนคาดหวังผิด 1 จุด ขยับน้ำหนัก 6.58 จุด และ SE ของค่าเฉลี่ย 10 ปีคือ 6.32 จุด ตัวเลขจึงเป็นจุดเริ่มคุย ไม่ใช่คำสั่ง
