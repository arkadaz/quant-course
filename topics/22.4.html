22.4 CDOs, Synthetic CDOs, and the Gaussian Copula

CDO เอาความเสียหายของพอร์ตเงินกู้มาแบ่งเป็นชั้น ชั้นล่างรับก่อน ชั้นบนรับทีหลัง ขาดทุนเฉลี่ยของทั้งพอร์ตไม่ขึ้นกับ correlation แต่ขาดทุนของแต่ละชั้นขึ้นกับมันมาก Gaussian copula คือแบบจำลองที่ตลาดใช้ใส่ correlation ตัวนี้เข้าไป

ลองนึกถึงพอร์ตเงินกู้ของบริษัท 125 แห่ง บางบริษัทอาจผิดนัด (default) คือจ่ายหนี้คืนไม่ได้ ความเสียหายของทั้งพอร์ตถูกแบ่งเป็นชั้นเหมือนตึก ชั้นล่างรับความเสียหายก่อน ชั้นบนจะเสียก็ต่อเมื่อความเสียหายทะลุชั้นล่างทั้งหมดขึ้นมาแล้ว โครงสร้างนี้เรียกว่า CDO

ธนาคารแห่งหนึ่งรับประกันชั้นบนสุด (super senior) แลกกับเบี้ยรายปี ภาษาตลาดเรียกว่า “ขาย protection” ถ้าความเสียหายขึ้นมาถึงชั้นนี้ ธนาคารต้องจ่ายชดเชย ธนาคารจึงต้องรู้ว่าชั้นนี้จะเสียเฉลี่ยเท่าไร

ของที่รู้:

  • จำนวนบริษัท $N=125$ ให้กู้บริษัทละ \$1 ล้าน
  • โอกาสที่แต่ละบริษัทผิดนัดภายใน 1 ปี $q=2\%$ (สมมติ)
  • บริษัทที่ผิดนัดคืนเงินไม่ได้เลย แต่ละรายจึงทำให้พอร์ตเสีย \$1 ล้านเต็ม
  • ชั้น super senior เริ่มเสียเมื่อบริษัทรายที่ 7 ผิดนัด เพราะความเสียหายของ 6 รายแรกชั้นล่างรับไปแล้ว

จำนวนบริษัทที่ผิดนัดโดยเฉลี่ยคือ $Nq=125\times0.02=2.5$ ราย ขาดทุนเฉลี่ยของพอร์ตใน 1 ปีจึงเป็น \$2.5 ล้าน

ตัวเลขนี้ยังไม่ได้บอกว่าบริษัทผิดนัดพร้อมกันบ่อยแค่ไหน สิ่งที่วัดเรื่องนี้คือ correlation ของมูลค่าบริษัท ถ้าเป็น 0 แต่ละบริษัทล้มของใครของมัน ถ้าสูง เศรษฐกิจแย่ครั้งเดียวก็ลากหลายบริษัทล้มพร้อมกัน ธนาคารคิดว่า “ขาดทุนเฉลี่ยของพอร์ตไม่ขึ้นกับ correlation ชั้นของเราก็เสี่ยงเท่าเดิม”

ถ้าบริษัทผิดนัดอิสระกัน (correlation 0) ชั้น super senior เสียเฉลี่ย \$18,286 ต่อปี หน้านี้จะคำนวณตัวเลขนี้ให้ดูทีละขั้น ถ้า correlation เป็น 0.5 ชั้นนี้จะเสียเฉลี่ยเท่าไร?

ลองตอบก่อนเปิดเฉลย

\$1,235,442 ซึ่งมากกว่าเดิม $1{,}235{,}442/18{,}286=67.6$ เท่า ทั้งที่ขาดทุนเฉลี่ยของพอร์ตยังเป็น \$2.5 ล้านเท่าเดิม correlation ไม่ได้เพิ่มขาดทุนรวม มันย้ายขาดทุนจากชั้นล่างขึ้นไปชั้นบน ชั้นล่างสุด (equity ซึ่งรับความเสียหาย 3 รายแรก) เสียเฉลี่ยลดลงจาก \$2.09 ล้านเหลือ \$0.84 ล้าน หน้านี้คิดตัวเลขเหล่านี้ครบทุกชั้นด้วยแบบจำลองที่ตลาดใช้จริง

ภาพรวมก่อนลงสูตร

ลองนึกถึงคนสองกลุ่มที่อยากลงทุนในพอร์ตเงินกู้เดียวกัน hedge fund อยากได้ผลตอบแทนสูงและรับความเสี่ยงได้ บริษัทประกันอยากได้ของที่ปลอดภัยมาก collateralized debt obligation (CDO) ทำให้ทั้งสองกลุ่มได้ของที่ต้องการจากพอร์ตเดียว

CDO รวมหุ้นกู้หรือเงินกู้ของหลายบริษัทไว้ด้วยกัน แล้วแบ่งความเสียหายเป็นชั้น ชั้นล่างรับความเสียหายก่อน จึงได้ผลตอบแทนสูง ชั้นบนเสียก็ต่อเมื่อความเสียหายทะลุชั้นล่างทั้งหมด จึงได้อันดับความน่าเชื่อถือ AAA ซึ่งสูงที่สุด CMO ในหน้าก่อนแบ่งเงินต้นตามลำดับเวลา ส่วน CDO แบ่งความเสียหายตามลำดับว่าใครเจ็บก่อน

ชั้นบนจะเสียได้ก็ต่อเมื่อหลายบริษัทผิดนัดพร้อมกัน ราคาของชั้นบนจึงขึ้นกับคำถามเดียว: บริษัทผิดนัดพร้อมกันบ่อยแค่ไหน คำถามนี้ตอบตรง ๆ ไม่ได้ เพราะพอร์ต 125 บริษัทมีคู่บริษัทถึง $\dfrac{125\times124}{2}=7{,}750$ คู่ ยังไม่นับกลุ่มละสามหรือสี่บริษัท

ตลาดจึงย่อเรื่องทั้งหมดเหลือตัวเลขเดียวด้วย Gaussian copula แนวคิดคือ มูลค่าของทุกบริษัทขยับตามปัจจัยร่วมตัวเดียว (นึกถึงสภาพเศรษฐกิจ) บวกส่วนที่เป็นเรื่องของบริษัทเอง บริษัทผิดนัดเมื่อมูลค่าต่ำกว่าเกณฑ์ ถ้ารู้สภาพเศรษฐกิจแล้ว ที่เหลือคือส่วนของแต่ละบริษัทซึ่งอิสระกัน การนับจำนวนผิดนัดจึงเป็น binomial ธรรมดา จากนั้นค่อยเฉลี่ยข้ามทุกสภาพเศรษฐกิจ

หน้านี้เดินตามลำดับนี้:

  • เขียนขาดทุนของชั้นจากขาดทุนของพอร์ต
  • ดูลูกหนี้สองรายที่ขาดทุนเฉลี่ยเท่ากัน แต่ชั้นบนเสียต่างกันสิบเท่า
  • สร้างแบบจำลองปัจจัยเดียว แล้วใช้กับพอร์ต 125 บริษัทของโจทย์ ซึ่งเป็นพอร์ตตัวอย่างจากบทความของ Donnelly และ Embrechts
  • ตั้งราคาชั้นจากเงินสองฝั่งแบบเดียวกับ CDS: เบี้ยที่ผู้ซื้อ protection จ่าย กับเงินชดเชยที่ผู้ขายจ่าย
  • นับการผิดนัดเมื่อแต่ละบริษัทมีโอกาสไม่เท่ากัน
  • ดูว่า correlation ตัวเดียวมองไม่เห็นอะไร
ศัพท์ที่ใช้ในหัวข้อนี้
ผิดนัด (default) และ recovery
บริษัทผิดนัดเมื่อจ่ายหนี้คืนไม่ได้ตามสัญญา recovery คือสัดส่วนของหนี้ที่เจ้าหนี้ยังได้คืนหลังบริษัทผิดนัด หน้านี้สมมติ recovery เป็นศูนย์ เพื่อให้ตัวเลขง่าย
CDO, CLO และ tranche
CDO คือตราสารที่รวมหนี้ของหลายบริษัทไว้ด้วยกัน แล้วแบ่งความเสียหายของพอร์ตเป็นชั้น (tranche) แต่ละชั้นกำหนดด้วยช่วงความเสียหายที่มันรับ ถ้าพอร์ตเป็นเงินกู้ธนาคาร เรียกว่า collateralized loan obligation (CLO) จุดประสงค์คือสร้างของเสี่ยงมากและของเสี่ยงน้อยจากพอร์ตเดียว
Attachment และ detachment point
attachment คือระดับขาดทุนของพอร์ตที่ชั้นหนึ่งเริ่มเสีย detachment คือระดับที่ชั้นนั้นเสียหมด เช่นชั้น 3%–7% เริ่มเสียเมื่อพอร์ตขาดทุนเกิน 3% และหมดชั้นเมื่อพอร์ตขาดทุนถึง 7% ส่วนต่าง $7-3=4$ คือความหนาของชั้น
Equity, mezzanine, senior, super senior
ชื่อของชั้นจากล่างขึ้นบน: ชั้นล่างสุด ชั้นกลาง ชั้นบน และชั้นบนสุดซึ่ง detachment เป็น 100% equity รับความเสียหายก้อนแรก จึงได้ผลตอบแทนสูงสุด senior เสียก็ต่อเมื่อความเสียหายทะลุชั้นล่างทั้งหมด
Protection: ผู้ซื้อและผู้ขาย
สัญญาที่ทำงานเหมือนประกัน ผู้ซื้อ protection จ่ายเบี้ยเป็นงวด ผู้ขาย protection จ่ายชดเชยเมื่อเกิดความเสียหายตามสัญญา “ขาย protection บนชั้นหนึ่ง” จึงแปลว่า รับเบี้ย แล้วรับความเสียหายของชั้นนั้นแทน
Cash CDO และ synthetic CDO
cash CDO ซื้อหุ้นกู้หรือเงินกู้มาถือจริง synthetic CDO ไม่ได้ถือหนี้ แต่ตกลงกันบนรายชื่อบริษัทชุดหนึ่งผ่าน credit default swap (CDS) ซึ่งเป็นสัญญา protection ของบริษัทเดียว ผู้ขาย protection ของชั้นรับเบี้ย และจ่ายเงินเมื่อความเสียหายขึ้นมาถึงชั้น
Premium leg และ default leg
“ขา” (leg) คือกระแสเงินของฝั่งหนึ่งในสัญญา ขาเบี้ย (premium leg) คือเงินที่ผู้ซื้อ protection จ่ายทุกงวด คิดบนส่วนของชั้นที่ยังไม่เสียหาย ขาชดเชย (default leg) คือเงินที่ผู้ขาย protection จ่าย เท่ากับความเสียหายที่เพิ่งเข้าชั้น เบี้ยยุติธรรมคือเบี้ยที่ทำให้มูลค่าวันนี้ของสองขาเท่ากัน
Gaussian copula แบบปัจจัยเดียว
แบบจำลองที่ให้มูลค่าของทุกบริษัทขยับตามปัจจัยร่วมตัวเดียว บวกส่วนที่เป็นเรื่องของบริษัทเอง บริษัทผิดนัดเมื่อมูลค่าต่ำกว่าเกณฑ์ แบบจำลองนี้ผูกโอกาสผิดนัดของแต่ละบริษัทเข้าด้วยกันด้วย correlation ตัวเดียว
Implied correlation และ tail dependence
implied correlation คือค่า $\rho$ ที่ทำให้ราคาจากแบบจำลองตรงกับราคาตลาด tail dependence คือโอกาสที่ค่าสุดขั้วของสองตัวแปรเกิดพร้อมกัน correlation ตัวเดียวบอกเรื่องนี้ไม่ได้

สัญลักษณ์ความหมายหน่วย

$L$ขาดทุนของพอร์ต (เป็นสัดส่วน หรือจำนวนบริษัทที่ผิดนัดเมื่อได้คืนศูนย์)สัดส่วน หรือบริษัท

$q,\ c$โอกาสผิดนัดของแต่ละบริษัทถึงวันครบกำหนด และเกณฑ์ $c=\Phi^{-1}(q)$สัดส่วน, ไม่มีหน่วย

ขั้นที่ 1 — ขาดทุนของพอร์ตกลายเป็นขาดทุนของชั้น

ก่อนจะคุยเรื่องโอกาส ต้องมีกติกาก่อนว่า ถ้ารู้ว่าพอร์ตขาดทุนเท่าไร แต่ละชั้นเสียเท่าไร กติกานี้ไม่มีเรื่องโอกาสเลย เป็นแค่การตัดระดับน้ำเป็นช่วง ๆ ตามรูปด้านบน

โจทย์ให้อะไรมาบ้าง:

  • พอร์ตขนาด \$100 ล้าน ปีนี้ขาดทุน $L=5\%$ หรือ \$5 ล้าน
  • สามชั้นตามรูปด้านบน: equity 0%–3%, mezzanine 3%–7% และ senior 7%–100%

เขียนชั้นหนึ่งเป็น $[a,b]$ โดย $a$ คือ attachment (พื้นของชั้น) และ $b$ คือ detachment (เพดานของชั้น) ชั้นนี้ไม่เสียถ้า $L$ ยังไม่ถึง $a$ เสียเท่าส่วนที่เกิน $a$ และเสียเต็มความหนา $b-a$ เมื่อ $L$ ถึง $b$ เขียนเป็นสูตรได้ดังนี้ โดยวัด $L$, $a$ และ $b$ เป็นเปอร์เซ็นต์ของพอร์ต ซึ่งในพอร์ต \$100 ล้านก็คือล้านดอลลาร์พอดี

\[ \begin{aligned} \ell(L)&=\min\big(\max(L-a,0),\\ &\qquad\quad b-a\big)\\ &=\max\big(\min(L,b)-a,\ 0\big),\\ \ell_{0,3}(5)&=\min(5,\ 3)=3,\\ \ell_{3,7}(5)&=\min(2,\ 4)=2,\\ \ell_{7,100}(5)&=\min(0,\ 93)=0. \end{aligned} \]

คำตอบ: equity เสียเต็มชั้น \$3 ล้าน mezzanine เสีย \$2 ล้าน คือครึ่งหนึ่งของความหนา \$4 ล้าน ส่วน senior ไม่เสียเลย

สูตรมีสองหน้าตา แต่เป็นเรื่องเดียวกัน หน้าตาแรกอ่านว่า $\max(L-a,0)$ คือส่วนที่ทะลุพื้นขึ้นมา แล้ว $\min(\cdot,\ b-a)$ ตัดไม่ให้เกินความหนาของชั้น หน้าตาที่สองตัดขาดทุนที่เพดาน $b$ ก่อน แล้วค่อยลบพื้น $a$ ชั้นเดียวกันจึงอาจไม่เสียเลย เสียบางส่วน หรือเสียหมด แล้วแต่ว่าขาดทุนรวมขึ้นไปถึงไหน

ตรวจเองใน 10 วินาที: $3+2+0=5$ เท่ากับขาดทุนของพอร์ตพอดี กติกานี้ส่งขาดทุนต่อกันเป็นทอด ๆ เหมือน waterfall (กติกาส่งเงินเป็นทอด) ของ CMO ขาดทุนจึงไม่หายไปและไม่เกิดเพิ่ม

ขั้นที่ 2 — ขาดทุนเฉลี่ยเท่ากัน แต่ชั้นบนเจ็บต่างกันสิบเท่า

กติกาของชั้นบอกว่าชั้นบนเสียเมื่อขาดทุนรวมสูง ขั้นนี้ใช้ตัวอย่างที่เล็กที่สุดเท่าที่ทำได้ เพื่อแสดงว่าขาดทุนรวมจะสูงบ่อยแค่ไหนขึ้นกับการผิดนัดพร้อมกัน รู้แค่โอกาสผิดนัดของแต่ละรายไม่พอ

โจทย์ให้อะไรมาบ้าง:

  • ลูกหนี้สองราย รายละ \$50 พอร์ตรวม \$100
  • แต่ละรายมีโอกาสผิดนัด 10% และถ้าผิดนัดได้คืนศูนย์
  • ชั้นบนรับขาดทุนส่วนที่เกิน \$50 ชั้นนี้จึงเสีย \$50 เฉพาะเมื่อลูกหนี้ผิดนัดทั้งคู่

เทียบสองโลกที่โอกาสรายตัวเท่ากัน โลกแรกสองรายผิดนัดอิสระกัน โลกที่สองผิดนัดพร้อมกันเสมอ ในแต่ละโลก เขียนโอกาสที่พอร์ตขาดทุน \$0, \$50 และ \$100 เรียงเป็น $p$ ตัวห้อย ind คือโลกอิสระ (independent) และ tog คือโลกพร้อมกัน (together) $L$ คือขาดทุนของพอร์ต และ $\ell$ คือขาดทุนของชั้นบน

โลกอิสระใช้ผลของความเป็นอิสระ: โอกาสที่สองเรื่องเกิดพร้อมกันคือผลคูณ ไม่มีใครผิดนัดเลยมีโอกาส $0.9^2=0.81$ ผิดนัดรายเดียวมีโอกาส $2(0.1)(0.9)=0.18$ (คูณ 2 เพราะเป็นรายไหนก็ได้) ผิดนัดทั้งคู่มีโอกาส $0.1^2=0.01$ โลกพร้อมกันมีแค่สองกรณี คือรอดทั้งคู่ 90% หรือผิดนัดทั้งคู่ 10% ขาดทุนเฉลี่ยคือขาดทุนแต่ละกรณีคูณโอกาสของมัน แล้วบวกกัน

\[ \begin{aligned} p_{\rm ind}&=(0.81,\ 0.18,\ 0.01),\\ p_{\rm tog}&=(0.90,\ 0,\ 0.10),\\ E_{\rm ind}[L]&=0.18(50)+0.01(100)\\ &=10,\\ E_{\rm tog}[L]&=0.10(100)=10,\\ E_{\rm ind}[\ell]&=0.01(50)=0.50,\\ E_{\rm tog}[\ell]&=0.10(50)=5.00. \end{aligned} \]

คำตอบ: ขาดทุนเฉลี่ยของพอร์ตเป็น \$10 ทั้งสองโลก แต่ชั้นบนเสียเฉลี่ย \$0.50 เมื่ออิสระกัน และ \$5.00 เมื่อผิดนัดพร้อมกัน ต่างกัน $5.00/0.50=10$ เท่า เหตุผลคือชั้นบนเสียเฉพาะกรณีขาดทุน \$100 และโอกาสของกรณีนี้คือ 0.01 ในโลกหนึ่ง กับ 0.10 ในอีกโลก การตั้งราคาชั้นจึงต้องรู้โอกาสที่ผิดนัดพร้อมกัน รู้แค่โอกาสรายตัวไม่พอ

ตรวจเองใน 10 วินาที: โอกาสในแต่ละโลกต้องรวมได้ 1: $0.81+0.18+0.01=1$ และ $0.90+0+0.10=1$ และในโลกอิสระ ลูกหนี้หนึ่งรายยังผิดนัดด้วยโอกาส $0.01+0.18/2=0.10$ ตามโจทย์

ขั้นที่ 3 — Gaussian copula แบบปัจจัยเดียว

ตัวอย่างสองลูกหนี้กำหนดโอกาสผิดนัดพร้อมกันได้ด้วยมือ แต่พอร์ตจริงมีหลายสิบหรือหลายร้อยบริษัท การกำหนดโอกาสนี้ทีละคู่ทีละกลุ่มทำไม่ได้ แบบจำลองนี้ย่อทุกอย่างเหลือตัวเลขเดียวคือ $\rho$ ด้วยสองความคิด:

  • ให้บริษัท $i$ มี “มูลค่าที่ปรับมาตรฐาน” $X_i$ นึกถึงคะแนนสุขภาพของบริษัทที่ปรับให้ค่าเฉลี่ยเป็น 0 และ SD เป็น 1 ค่ายิ่งต่ำ บริษัทยิ่งใกล้ล้ม
  • บริษัทผิดนัดเมื่อ $X_i$ ต่ำกว่าเกณฑ์ $c$ ซึ่งเลือกให้โอกาสผิดนัดตรงกับที่ตลาดเห็น

$X_i$ มีสองส่วน ส่วนแรกมาจากปัจจัยร่วม $M$ ที่ทุกบริษัทใช้ตัวเดียวกัน (นึกถึงสภาพเศรษฐกิจ) ส่วนที่สอง $\varepsilon_i$ เป็นเรื่องของบริษัท $i$ เอง ทั้ง $M$ และ $\varepsilon_i$ ทุกตัวเป็น normal มาตรฐานที่อิสระต่อกัน $\rho$ เป็นตัวเลขระหว่าง 0 ถึง 1 ที่บอกว่าปัจจัยร่วมมีน้ำหนักแค่ไหน $\Phi$ คือ CDF ของ normal มาตรฐาน และ $q=2\%$ คือโอกาสผิดนัดใน 1 ปีของโจทย์

\[ \begin{aligned} X_i&=\sqrt{\rho}\,M+\sqrt{1-\rho}\,\varepsilon_i,\\ \mathrm{Var}(X_i)&=\rho+(1-\rho)=1,\\ \mathrm{Cov}(X_i,X_j)&=\rho\,\mathrm{Var}(M)=\rho,\\ P(X_i\le c)&=\Phi(c)=q,\\ c&=\Phi^{-1}(0.02)=-2.0537. \end{aligned} \]

น้ำหนัก $\sqrt\rho$ กับ $\sqrt{1-\rho}$ ดูแปลก แต่ถูกเลือกมาเพื่อเหตุผลเดียว คือให้ $X_i$ ยังเป็น normal มาตรฐาน เพราะ $M$ กับ $\varepsilon_i$ อิสระกัน variance ของผลรวมจึงเท่ากับผลรวมของ variance แต่ละส่วน ค่าคงที่ที่คูณอยู่ออกมาเป็นกำลังสอง และ variance ของ $M$ กับ $\varepsilon_i$ เป็น 1 ทั้งคู่ จึงได้ $(\sqrt\rho)^2+(\sqrt{1-\rho})^2=\rho+(1-\rho)=1$

covariance ของสองบริษัทเหลือแค่ส่วนที่มาจาก $M$ ร่วมกัน เพราะ $\varepsilon_i$ กับ $\varepsilon_j$ ไม่เกี่ยวกัน และไม่เกี่ยวกับ $M$ จึงได้ $\sqrt\rho\cdot\sqrt\rho\cdot\mathrm{Var}(M)=\rho$ และเมื่อ variance ของแต่ละตัวเป็น 1 covariance ก็คือ correlation นี่คือการสร้าง normal หลายตัวแปรจากตัวแปรอิสระ แบบเดียวกับการจำลอง MVN ด้วย Cholesky แบบทั่วไปให้บริษัท $i$ มีน้ำหนักของตัวเอง $a_i$ แทน $\sqrt\rho$ แล้ว correlation ของคู่ $i,j$ คือ $a_ia_j$

เกณฑ์ $c$ ได้จากเงื่อนไขว่าบริษัทต้องผิดนัดด้วยโอกาส $q=2\%$ จึงต้องหาจุดที่พื้นที่ใต้ normal มาตรฐานทางซ้ายเท่ากับ 0.02 จุดนั้นคือ $\Phi^{-1}(0.02)=-2.0537$ ในตลาดจริง ตัวเลข $q$ หาได้จาก spread ของ CDS (เบี้ยประกันการผิดนัดต่อปี) หรือจากราคาหุ้นกู้ของบริษัท สังเกตว่าในการหา $c$ ไม่มี $\rho$ อยู่เลย โอกาสผิดนัดรายตัวจึงไม่ขึ้นกับ $\rho$ หน้าที่เดียวของ $\rho$ คือกำหนดว่าบริษัทต่าง ๆ ผิดนัดพร้อมกันแค่ไหน

ขั้นที่ 4 — รู้ปัจจัยร่วมแล้ว ทุกบริษัทอิสระกัน

ขั้นนี้คือกลเม็ดที่ทำให้แบบจำลองคำนวณได้เร็ว สมมติว่ารู้แล้วว่าปีนี้ปัจจัยร่วม $M$ ออกมาเป็นค่า $m$ ส่วนที่ยังสุ่มของแต่ละบริษัทเหลือแค่ $\varepsilon_i$ ซึ่งอิสระกัน (conditional independence คืออิสระกันเมื่อรู้ $m$)

ทุกบริษัทจึงเหมือนเหรียญที่ออก “ผิดนัด” ด้วยโอกาสเท่ากัน $q(m)$ จำนวนบริษัทที่ผิดนัด $L$ ใน $N$ บริษัทจึงเป็น binomial ธรรมดา ($\tbinom{N}{l}$ คือจำนวนวิธีเลือกว่า $l$ บริษัทไหนเป็นรายที่ผิดนัด) จากนั้นค่อยเฉลี่ยข้ามทุกค่า $m$ โดยถ่วงด้วย density ของ normal มาตรฐาน $\phi(m)$

\[ \begin{aligned} q(m)&=P\Big(\varepsilon_i\le\frac{c-\sqrt\rho\,m}{\sqrt{1-\rho}}\Big)\\ &=\Phi\Big(\frac{c-\sqrt\rho\,m}{\sqrt{1-\rho}}\Big),\\ P(L=l\mid m)&=\tbinom{N}{l}q(m)^l\\ &\quad\times\big(1-q(m)\big)^{N-l},\\ P(L=l)&=\int P(L=l\mid m)\\ &\quad\times\phi(m)\,dm,\\ E[L]&=N\int q(m)\phi(m)\,dm\\ &=Nq. \end{aligned} \]

$q(m)$ มาจากการแก้อสมการ $X_i\le c$ เมื่อแทน $M=m$: ย้าย $\sqrt\rho\,m$ ไปอีกข้าง แล้วหารด้วย $\sqrt{1-\rho}$ ทั้งสองข้าง ซึ่งทำได้โดยเครื่องหมายไม่กลับ เพราะ $\sqrt{1-\rho}\gt0$ ผลคือพื้นที่แดงอ่อนในรูปด้านบน ลองแทนสามสภาพเศรษฐกิจที่ $\rho=0.5$ ซึ่งมี $\sqrt\rho=\sqrt{1-\rho}=0.7071$:

\[ \begin{aligned} q(0)&=\Phi\big(\tfrac{-2.0537}{0.7071}\big)\\ &=\Phi(-2.904)=0.18\%,\\ q(-2)&=\Phi\big(\tfrac{-2.0537+1.4142}{0.7071}\big)\\ &=\Phi(-0.904)=18.29\%,\\ q(-3)&=\Phi\big(\tfrac{-2.0537+2.1213}{0.7071}\big)\\ &=\Phi(0.096)=53.81\%. \end{aligned} \]

ปีปกติ ($m=0$) แทบไม่มีบริษัทไหนผิดนัด ปีแย่มาก ($m=-3$) บริษัทราวครึ่งหนึ่งผิดนัดพร้อมกัน

สูตรสุดท้ายอธิบายว่าทำไมขาดทุนเฉลี่ยของพอร์ตไม่ขึ้นกับ $\rho$ ค่าเฉลี่ยของ $q(m)$ ข้ามทุก $m$ ต้องกลับมาเป็นโอกาสผิดนัดรายตัว $q$ เหตุผลคือ tower property: เฉลี่ยในแต่ละสภาพเศรษฐกิจก่อน แล้วเฉลี่ยข้ามสภาพเศรษฐกิจอีกที ได้ค่าเฉลี่ยเดิม พอร์ต 125 บริษัทที่ $q=2\%$ จึงผิดนัดเฉลี่ย $Nq=125\times0.02=2.5$ รายเสมอ ไม่ว่า $\rho$ เท่าไร

อินทิกรัลเหล่านี้ไม่มีสูตรปิด หน้านี้จึงคิดเป็นตัวเลขด้วยกฎสี่เหลี่ยมคางหมู แบ่ง $m$ จาก −10 ถึง 10 เป็นช่วงละ 0.01 (ดูโค้ดท้ายหน้า)

ขั้นที่ 5 — correlation ย้ายโอกาสไปที่ศูนย์และที่หาง

ตอนนี้นับได้แล้วว่าในหนึ่งปีจะมีกี่บริษัทผิดนัด ขั้นนี้เทียบรูปร่างของการกระจายนี้ระหว่างโลกที่ไม่มีปัจจัยร่วม กับโลกที่ปัจจัยร่วมแรง เพื่อดูว่า correlation ย้ายโอกาสไปไว้ตรงไหน

โจทย์ให้อะไรมาบ้าง: พอร์ต 125 บริษัทของโจทย์ แต่ละบริษัทมี $q=2\%$ และได้คืนศูนย์ ขาดทุน $L$ นับเป็นจำนวนบริษัทที่ผิดนัด เทียบ $\rho=0$ กับ $\rho=0.5$

ที่ $\rho=0$ ไม่มีปัจจัยร่วม $L$ จึงเป็น binomial ตรง ๆ ปีที่ไม่มีใครผิดนัดคือปีที่ทั้ง 125 บริษัทรอดพร้อมกัน แต่ละบริษัทรอดด้วยโอกาส $1-0.02=0.98$ จึงคูณกัน 125 ครั้ง

ส่วนที่ $\rho=0.5$ ต้องใช้สูตรอินทิกรัลของขั้นที่แล้วโดยแทน $l=0$ ซึ่งคิดเป็นตัวเลขด้วยโค้ดท้ายหน้า ตัวห้อยของ $P$ ข้างล่างคือค่า $\rho$ และ $P(L\ge9)$ คือผลรวมของ $P(L=l)$ ตั้งแต่ $l=9$ ถึง 125

\[ \begin{aligned} P_{0}(L=0)&=0.98^{125}=8.00\%,\\ P_{0.5}(L=0)&=\textstyle\int\big(1-q(m)\big)^{125}\\ &\qquad\times\phi(m)\,dm\\ &=61.78\%,\\ P_{0}(L\ge9)&=0.0976\%,\\ P_{0.5}(L\ge9)&=8.11\%. \end{aligned} \]

คำตอบ: correlation 0.5 ทำให้ปีที่ไม่มีใครผิดนัดเลยเพิ่มจาก 8.00% เป็น 61.78% และทำให้ปีที่ผิดนัดตั้งแต่ 9 รายขึ้นไป (มากกว่าค่าเฉลี่ย 2.5 รายหลายเท่า) เพิ่มจาก 0.0976% เป็น 8.11% หรือ $8.11/0.0976\approx83$ เท่า ค่าเฉลี่ยยังเป็น 2.5 รายเท่าเดิม เพราะโอกาสที่ย้ายไปกองที่ศูนย์ ถูกชดเชยด้วยโอกาสที่ย้ายไปอยู่ที่หาง

ตรวจเองใน 10 วินาที: $125\ln0.98=125\times(-0.0202)=-2.525$ และ $e^{-2.525}\approx0.080$ ตรงกับ 8.00%

ขั้นที่ 6 — ขาดทุนเฉลี่ยของแต่ละชั้น และคำตอบของโจทย์

มีการกระจายของจำนวนผิดนัดแล้ว ขั้นนี้แปลงมันเป็นขาดทุนเฉลี่ยของแต่ละชั้น ซึ่งเป็นคำตอบของโจทย์ วิธีคือเอาสูตรขาดทุนของชั้น $\ell(L)$ จากขั้นแรกมาเฉลี่ย โดยถ่วงด้วยโอกาสของแต่ละ $L$

คำตอบของโจทย์อยู่ในคอลัมน์ super senior: จาก 0.0183 ราย เป็น 1.2354 ราย คูณ \$1 ล้านต่อราย โดยใช้ทศนิยมเต็มจากโค้ด ได้ $0.018286\times\$1{,}000{,}000=\$18{,}286$ และ $1.235442\times\$1{,}000{,}000=\$1{,}235{,}442$

รูปแบบในตารางอ่านได้ง่าย equity เสียน้อยลงเรื่อย ๆ เมื่อ $\rho$ สูงขึ้น เพราะมีปีที่ไม่มีใครผิดนัดมากขึ้น super senior เสียมากขึ้นเรื่อย ๆ เพราะหางหนาขึ้น ในทุกแถว equity ≥ mezzanine ≥ senior เพราะสามชั้นนี้หนาเท่ากัน และชั้นล่างโดนก่อนเสมอ

mezzanine ไม่ค่อยไวต่อ $\rho$ และไม่ได้ไปทางเดียว มันขึ้นแล้วลง จุดสูงสุดอยู่ราว 0.549 ที่ $\rho\approx0.15$ (คิดแบบเดียวกับตาราง โดยไล่ $\rho$ ทีละ 0.01) ผลที่ตามมาคือ ถ้าราคาตลาดของชั้นนี้ตรงกับขาดทุนเฉลี่ย 0.45 จะมี $\rho$ สองค่าที่ให้ค่านี้ คือ 0.021 และ 0.442 และถ้าราคาตลาดตรงกับขาดทุนเฉลี่ยที่เกิน 0.549 จะไม่มี $\rho$ ไหนให้ได้เลย correlation ที่หาย้อนจากราคาชั้นกลาง (implied correlation) จึงอาจมีสองคำตอบ หรือไม่มีคำตอบ

ขั้นที่ 7 — synthetic CDO: ราคายุติธรรมของชั้นจากสองขา

ถึงตอนนี้รู้ขาดทุนเฉลี่ยของชั้นแล้ว แต่ตลาดซื้อขายชั้นด้วยเบี้ยรายปี ขั้นนี้แปลงขาดทุนเฉลี่ยเป็นเบี้ยที่ยุติธรรม

ใน synthetic CDO ไม่มีใครถือหนี้จริง มีแค่สัญญาระหว่างสองฝ่ายบนชั้นหนึ่ง ผู้ซื้อ protection จ่ายเบี้ยในอัตรา $s$ ต่อปี คิดบนส่วนของชั้นที่ยังไม่ถูกขาดทุนกิน ผู้ขาย protection จ่ายเงินเท่าขาดทุนที่เข้ามาในชั้นในแต่ละปี

สัญญานี้ต่างจากCDS ของบริษัทเดียวตรงที่ไม่จบเมื่อบริษัทแรกผิดนัด สัญญาเดินต่อ แต่ฐานที่ใช้คิดเบี้ยเล็กลงตามส่วนที่เหลือ เบี้ยยุติธรรม $s^*$ คือเบี้ยที่ทำให้มูลค่าวันนี้ของสองฝั่งเท่ากัน เหมือน swap ที่มูลค่าตอนเริ่มสัญญาเป็นศูนย์

โจทย์ให้อะไรมาบ้าง:

  • พอร์ต 125 บริษัทเดิม ดูชั้น mezzanine 3–6 ซึ่งหนา 3 ราย ที่ $\rho=0.3$
  • สัญญา 2 ปี จ่ายเบี้ยตอนสิ้นปี คิดบนส่วนของชั้นที่เหลืออยู่ตอนต้นปี
  • อัตราคิดลด $r=3\%$ ต่อปี (สมมติ) เงิน \$1 ที่ได้ตอนสิ้นปีที่ $t$ มีค่าวันนี้ $d_t=1/(1+r)^t$ จึงได้ $d_1=1/1.03=0.9709$ และ $d_2=1/1.03^2=0.9426$
  • โอกาสผิดนัดภายในปีแรกคือ 2% โอกาสผิดนัดภายใน 2 ปีคือ 1 ลบโอกาสที่รอดสองปีติดกัน: $1-0.98^2=3.96\%$
  • ขาดทุนสะสมเฉลี่ยของชั้นถึงสิ้นปีแรกคือ $E[\ell_1]=0.5136$ (ตารางด้านบน แถว $\rho=0.3$) ถึงสิ้นปีที่ 2 คือ $E[\ell_2]=0.9946$ (คิดแบบเดียวกันด้วย $q=3.96\%$ ในโค้ดท้ายหน้า) และตอนเริ่มสัญญายังไม่มีขาดทุน $E[\ell_0]=0$

ขาเบี้ย $PL$ (premium leg) คือมูลค่าวันนี้ของเบี้ยทั้งหมด แต่ละปีได้ $s$ คูณส่วนที่เหลือ $3-E[\ell_{t-1}]$ แล้วคิดลดด้วย $d_t$ ขาชดเชย $DL$ (default leg) คือมูลค่าวันนี้ของขาดทุนใหม่ในแต่ละปี $E[\ell_t]-E[\ell_{t-1}]$ ตั้งสองขาให้เท่ากันแล้วแก้หา $s$

\[ \begin{aligned} PL&=s\sum_t d_t\big(3-E[\ell_{t-1}]\big)\\ &=s\,[0.9709(3)\\ &\qquad+0.9426(3-0.5136)]\\ &=5.2563\,s,\\ DL&=\sum_t d_t\big(E[\ell_t]-E[\ell_{t-1}]\big)\\ &=0.9709(0.5136)\\ &\quad+0.9426(0.9946-0.5136)\\ &=0.9521,\\ s^*&=0.9521/5.2563=18.11\%. \end{aligned} \]

คำตอบ: เบี้ยยุติธรรมของชั้นนี้คือ 18.11% ต่อปี เบี้ยสูงขนาดนี้เพราะตัวอย่างเสี่ยงมาก คือได้คืนศูนย์ และโอกาสผิดนัดสูงถึง 2% ต่อปี

คิดแบบเดียวกันกับกรณีอื่นด้วยโค้ดท้ายหน้า ได้ดังนี้:

  • ชั้น mezzanine เดียวกันที่ $\rho=0$: เบี้ย 29.37% ต่อปี
  • super senior: เบี้ย 0.19% ต่อปีที่ $\rho=0$ ขึ้นเป็น 0.92% ต่อปีที่ $\rho=0.3$
  • equity ที่ $\rho=0$: ต้องจ่ายเบี้ยถึง 72.39% ต่อปี

เบี้ยของ equity สูงจนไม่สะดวกจะซื้อขาย ตลาดจึงให้ผู้ซื้อ protection ของ equity จ่ายเบี้ยคงที่ 5% ต่อปี บวกเงินก้อนตอนเริ่มสัญญา (upfront) ลองคิด upfront ของ equity ที่ $\rho=0.3$ ขาดทุนสะสมเฉลี่ยของ equity ถึงสิ้นปีแรกคือ 1.2172 (จากตาราง) และถึงสิ้นปีที่ 2 คือ 1.7734 (คิดแบบเดียวกับ mezzanine ในโค้ดท้ายหน้า) ใช้สูตรสองขาเดิมกับความหนา 3 โดยให้เบี้ยเป็น 1 ต่อปีไปก่อน:

\[ \begin{aligned} PL_1&=0.9709(3)\\ &\quad+0.9426(3-1.2172)\\ &=4.5931,\\ DL&=0.9709(1.2172)\\ &\quad+0.9426(1.7734-1.2172)\\ &=1.7061. \end{aligned} \]

ให้ $U$ คือ upfront คิดเป็นสัดส่วนของความหนา 3 ผู้ขาย protection ได้เงิน $3U$ วันนี้ บวกเบี้ย 5% ต่อปีซึ่งมีมูลค่าวันนี้ $0.05\times PL_1$ เงินที่ได้ต้องเท่ากับเงินที่คาดว่าต้องจ่าย $DL$:

\[ \begin{aligned} 3U+0.05\times4.5931&=1.7061,\\ U&=\frac{1.7061-0.2297}{3}\\ &=49.21\%. \end{aligned} \]

ผู้ซื้อ protection ของ equity จึงต้องจ่ายเกือบครึ่งหนึ่งของความหนาชั้นตั้งแต่วันแรก

ตรวจเองใน 10 วินาที: ถ้าไม่มีขาดทุนเลยในปีแรก ฐานของเบี้ยจะเป็น 3 ทั้งสองปี ขาเบี้ยจะเป็น $3(0.9709+0.9426)=5.74\,s$ ขาดทุน 0.5136 ในปีแรกทำให้ฐานปีที่สองหดเหลือ $3-0.5136=2.4864$ ขาเบี้ยจึงเหลือ $5.2563\,s$ ซึ่งน้อยกว่า ถูกทิศ

ขั้นที่ 8 — เมื่อแต่ละบริษัทมีโอกาสไม่เท่ากัน

ทุกขั้นที่ผ่านมาสมมติว่าทุกบริษัทมีโอกาสผิดนัดเท่ากัน binomial ใช้ได้ก็เพราะข้อนี้ แต่พอร์ตจริงมีบริษัทแข็งแรงและบริษัทอ่อนแอปนกัน ขั้นนี้นับจำนวนผิดนัดเมื่อโอกาสไม่เท่ากัน

โจทย์ให้อะไรมาบ้าง: แบบฝึกหัดของคอร์สให้ลูกหนี้ 20 ราย และให้สมมติว่าผิดนัดอิสระกัน โอกาสผิดนัดของรายที่ 1 ถึง 20 คือ 20%, 20%, 6%, 30%, 40%, 65%, 30%, 23%, 2%, 12%, 13.4%, 21%, 8%, 10%, 10%, 2%, 30%, 1.5%, 20% และ 3% ต่ำสุด 1.5% สูงสุด 65%

จำนวนผิดนัดในกรณีนี้มีการกระจายชื่อ Poisson-binomial ซึ่งไม่มีสูตรสั้น ๆ แบบ binomial แต่คิดได้ด้วยการเพิ่มลูกหนี้ทีละราย ให้ $p_i$ คือโอกาสผิดนัดของรายที่ $i$ และ $\pi_i(k)$ คือโอกาสที่ใน $i$ รายแรกมีผิดนัดพอดี $k$ ราย เริ่มจาก $\pi_0(0)=1$ เพราะเมื่อยังไม่มีลูกหนี้ ก็ยังไม่มีใครผิดนัด ในขั้นนี้ $N$ คือจำนวนรายที่ผิดนัดจาก 20 ราย

\[ \begin{aligned} \pi_i(k)&=\pi_{i-1}(k)(1-p_i)\\ &\quad+\pi_{i-1}(k-1)\,p_i,\\ \pi_2&=(0.64,\ 0.32,\ 0.04),\\ E[N]&=\textstyle\sum_ip_i=3.669,\\ \mathrm{Var}(N)&=\textstyle\sum_ip_i(1-p_i)=2.5352,\\ P(N\ge5)&=28.76\%. \end{aligned} \]

สูตรแรกมาจากคำถามว่า จะมีผิดนัด $k$ รายใน $i$ รายแรกได้อย่างไร คำตอบมีสองทางที่ไม่ทับกัน ทางแรก $i-1$ รายแรกผิดนัด $k$ รายแล้วรายใหม่รอด ทางที่สองผิดนัด $k-1$ รายแล้วรายใหม่ผิดนัด รายใหม่อิสระจากรายเก่า โอกาสของแต่ละทางจึงเป็นผลคูณ แล้วบวกสองทางเข้าด้วยกัน

สองรายแรกมีโอกาส 20% ทั้งคู่ จึงได้ $\pi_2=(0.8^2,\ 2(0.2)(0.8),\ 0.2^2)=(0.64,\ 0.32,\ 0.04)$ ทำต่อจนครบ 20 ราย ได้ $P(N=0)$ ถึง $P(N=4)$ เป็น 1.10%, 6.46%, 16.29%, 23.99% และ 23.40% ตามลำดับ (และ $P(N=5)=16.17\%$) โอกาสที่ผิดนัด 5 รายขึ้นไปจึงเป็น

\[ \begin{aligned} P(N\ge5)&=1-(1.10+6.46+16.29\\ &\qquad+23.99+23.40)\%\\ &=1-71.24\%=28.76\%. \end{aligned} \]

ค่าเฉลี่ยกับ variance ไม่ต้องใช้ตาราง ลูกหนี้แต่ละรายเป็นตัวแปรที่เป็น 1 (ผิดนัด) หรือ 0 (รอด) ซึ่งมีค่าเฉลี่ย $p_i$ และ variance $p_i(1-p_i)$ เมื่ออิสระกัน ทั้งค่าเฉลี่ยและ variance บวกกันได้ตรง ๆ

ถ้าใช้ binomial ที่ค่าเฉลี่ยเท่ากันแทน คือให้ทุกรายมี $p=3.669/20=0.18345$ จะได้ variance $20(0.18345)(0.81655)=2.9959$ และ $P(N\ge5)=29.93\%$ variance สูงเกินจริง $2.9959/2.5352=1.18$ เท่า เหตุผลคือ $\sum_ip_i(1-p_i)=\sum_ip_i-\sum_ip_i^2$ เมื่อ $\sum_ip_i$ คงที่ $\sum_ip_i^2$ จะน้อยที่สุดเมื่อทุก $p_i$ เท่ากัน ความต่างของโอกาสรายตัวจึงทำให้ variance เล็กลง และการกระจายแคบลง

ถ้ามีปัจจัยร่วม ให้ทำ recursion นี้ที่แต่ละค่า $m$ โดยใช้โอกาสผิดนัดแบบมีเงื่อนไขของแต่ละราย $p_i(m)=\Phi\big((\Phi^{-1}(p_i)-a_im)/\sqrt{1-a_i^2}\big)$ แล้วอินทิเกรตข้าม $m$ แบบเดิม $a_i$ ตรงนี้คือน้ำหนักของปัจจัยร่วมของรายที่ $i$ ซึ่งมาแทน $\sqrt\rho$ ไม่ใช่ attachment

ขั้นที่ 9 — correlation เท่ากัน แต่หางไม่เท่ากัน

ขั้นสุดท้ายถามว่า correlation ตัวเดียวพอไหม หลายคนคิดว่า ถ้ารู้การกระจายของตัวแปรแต่ละตัว (เรียกว่า marginal) และรู้ correlation ก็รู้พฤติกรรมของทั้งคู่ครบแล้ว ความคิดนี้ผิด เพราะ correlation วัดแค่ความสัมพันธ์เชิงเส้นโดยเฉลี่ย ไม่ได้บอกว่าค่าสุดขั้วเกิดพร้อมกันบ่อยแค่ไหน และค่าสุดขั้วพร้อมกันคือสิ่งเดียวที่ชั้นบนของ CDO สนใจ

ขั้นนี้เทียบสองแบบจำลองของตัวแปรคู่หนึ่ง ทั้งสองแบบให้แต่ละตัวเป็น normal มาตรฐาน และให้ความสัมพันธ์ใกล้เคียงกัน:

  • normal สองตัวแปรที่ $\rho=0.7$ ซึ่งเป็นแบบที่ Gaussian copula ใช้
  • meta-Gumbel คือใช้ Gumbel copula ผูกสองตัวแปรเข้าด้วยกัน แล้วแปลงแต่ละตัวให้เป็น normal มาตรฐาน Gumbel copula ของคู่ $(u,v)$ ที่แต่ละตัวอยู่ระหว่าง 0 ถึง 1 คือ $C(u,v)=\exp\!\big(-[(-\ln u)^\theta+(-\ln v)^\theta]^{1/\theta}\big)$ โดย $\theta\ge1$ ยิ่ง $\theta$ ใหญ่ สองตัวยิ่งผูกกันแน่น

สองแบบจับคู่กันด้วย Kendall's tau $\tau$ ซึ่งวัดความสัมพันธ์จากลำดับ: สุ่มสองจุด แล้วดูว่าจุดที่ค่าแรกมากกว่ามีแนวโน้มจะมีค่าที่สองมากกว่าด้วยแค่ไหน สองสูตรที่ใช้ข้างล่าง คือ $\tau=\tfrac{2}{\pi}\arcsin\rho$ สำหรับ normal และ $\tau=1-1/\theta$ สำหรับ Gumbel เป็นผลที่พิสูจน์ไว้ในตำรา Quantitative Risk Management ของ McNeil, Frey และ Embrechts หน้านี้นำมาใช้ตรง ๆ คำถามคือ โอกาสที่ทั้งสองตัวเกิน 2.5 พร้อมกันเป็นเท่าไรในแต่ละแบบ

\[ \begin{aligned} u&=\Phi(2.5)=0.993790,\\ \tau&=\tfrac{2}{\pi}\arcsin(0.7)=0.4936,\\ \theta&=1/(1-\tau)=1.9749,\\ P_{\rm Gumbel}&=1-2u+u^{2^{1/\theta}}\\ &=0.3610\%,\\ P_{\rm normal}&=0.1486\%,\\ \lambda_U&=2-2^{1/\theta}=0.58. \end{aligned} \]

$u=\Phi(2.5)$ คือโอกาสที่ตัวแปรหนึ่งไม่เกิน 2.5 โอกาสที่ทั้งคู่เกิน 2.5 คือ 1 ลบโอกาสที่ตัวใดตัวหนึ่งไม่เกิน ซึ่งเท่ากับ $1-2u+C(u,u)$ เพราะการลบ $u$ สองครั้งหักกรณีที่ทั้งคู่ไม่เกินซ้ำไปหนึ่งครั้ง จึงต้องบวก $C(u,u)$ คืน

สำหรับ Gumbel แทน $v=u$ ในสูตร copula ได้ $C(u,u)=\exp\big(-2^{1/\theta}(-\ln u)\big)=u^{2^{1/\theta}}$ โดย $2^{1/\theta}=2^{1/1.9749}=1.4205$ ส่วน $P_{\rm normal}$ ไม่มีสูตรปิด ต้องอินทิเกรต density ของตัวแรก คูณโอกาสที่ตัวที่สองเกิน 2.5 เมื่อรู้ค่าตัวแรก ถ้าตัวแรกเป็น $x$ ตัวที่สองจะเป็น normal ที่ค่าเฉลี่ย $0.7x$ และ SD $\sqrt{1-0.7^2}=0.714$ จึงได้

\[ \begin{aligned} P_{\rm normal}&=\int_{2.5}^{\infty}\phi(x)\Big[1-\\ &\quad\Phi\Big(\frac{2.5-0.7x}{0.714}\Big)\Big]dx\\ &=0.1486\%. \end{aligned} \]

รูปข้างล่างมีจุดสุ่มภาพละ 5,000 จุด จำนวนจุดที่คาดว่าทั้งสองตัวเกิน 2.5 คือ $5{,}000\times0.003610=18.1$ จุดสำหรับ meta-Gumbel และ $5{,}000\times0.001486=7.4$ จุดสำหรับ normal ต่างกัน $0.3610/0.1486=2.4$ เท่า ทั้งที่ความสัมพันธ์ใกล้เคียงกัน

$\lambda_U$ (upper tail dependence) ตอบคำถามว่า ถ้าตัวหนึ่งสุดขั้วแล้ว โอกาสที่อีกตัวสุดขั้วด้วยเป็นเท่าไร เมื่อเลื่อนเกณฑ์ “สุดขั้ว” สูงขึ้นไปเรื่อย ๆ Gumbel ให้ $2-1.4205=0.58$ แต่ normal ที่ $\rho\lt1$ ให้ศูนย์ นี่คือสิ่งที่ Gaussian copula ตัดทิ้ง: เหตุการณ์ที่ทุกอย่างแย่พร้อมกันจริง ๆ ซึ่งเป็นเหตุการณ์เดียวที่ชั้นบนสุดสนใจ

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ตั้งราคาชั้นจากขาดทุนเฉลี่ยของพอร์ต: ขาดทุนเฉลี่ยของพอร์ตเป็น $Nq=2.5$ รายทุกค่า $\rho$ จึงดูเหมือนไม่ต้องสนใจ $\rho$ แต่ super senior เสียเฉลี่ย 0.018286 รายที่ $\rho=0$ และ 1.235442 รายที่ $\rho=0.5$ ต่างกัน $1.235442/0.018286=67.6$ เท่า

สลับเปอร์เซ็นต์กับสัดส่วน: ใส่ $L=5$ (ตั้งใจหมายถึง 5%) ลงในสูตรที่ใช้ $a=0.03,\ b=0.07$ จะได้ $\min(\max(5-0.03,0),\ 0.04)=0.04$ คือชั้นเสียเต็ม 100% ค่าที่ถูกคือ $\min(\max(0.05-0.03,0),\ 0.04)=0.02$ คือเสีย $0.02/0.04=50\%$

คิดเบี้ยบนความหนาเต็มตลอดสัญญา: ลืมว่าขาดทุนปีแรกกินฐานของเบี้ยปีที่สอง ในสัญญา 2 ปีของชั้นกลาง ขาเบี้ยจะกลายเป็น $5.7404\,s$ แทน $5.2563\,s$ เบี้ยยุติธรรมจึงออกมา $0.9521/5.7404=16.59\%$ แทน $0.9521/5.2563=18.11\%$ ผู้ขาย protection ขายถูกเกินไป

ใช้ $\rho$ ตัวเดียวทุกชั้น: ราคาตลาดของแต่ละชั้นหาย้อนออกมาได้ implied correlation ไม่เท่ากัน (เรียกว่า correlation skew) การยก $\rho$ ของชั้นหนึ่งไปตั้งราคาอีกชั้นให้ราคาผิดโดยไม่มีสัญญาณเตือน ตัวอย่างจาก mezzanine ข้างบน ถ้าราคาตรงกับขาดทุนเฉลี่ย 0.45 จะหา $\rho$ ได้ทั้ง 0.021 และ 0.442 เอา $\rho=0.021$ ไปตั้งราคา super senior จะได้ขาดทุนเฉลี่ย 0.0507 ราย เอา $\rho=0.442$ ไปใช้จะได้ 1.1050 ราย (คิดด้วยโค้ดท้ายหน้า) ต่างกัน $1.1050/0.0507\approx22$ เท่า

ใช้ binomial เมื่อโอกาสรายตัวไม่เท่ากัน: ลูกหนี้ 20 รายของแบบฝึกหัดมี $P(N\ge5)=28.76\%$ แต่ binomial ที่ $p=3.669/20$ ให้ 29.93% และให้ variance 2.9959 แทน 2.5352 เกินจริง $2.9959/2.5352=1.18$ เท่า หรือ 18%

ใช้ทำอะไรบนโต๊ะจริง

CDO รุ่นแรกเกิดกลางทศวรรษ 1990 เป็น cash CDO ที่ธนาคารสร้างจากหุ้นกู้ในงบดุลของตัวเอง แรงจูงใจคือเงินทุน กฎของผู้กำกับดูแลบังคับให้ธนาคารกันเงินทุนไว้รองรับความเสียหายของหุ้นกู้เหล่านี้ในอัตราสูง ธนาคารจึงแบ่งชั้น ขายชั้นบนออกไป แล้วเก็บ equity ไว้เอง

ผลตอบแทนและความเสี่ยงส่วนใหญ่ยังอยู่กับธนาคาร เพราะ equity รับความเสียหายก้อนแรก แต่เงินทุนที่ต้องกันลดลงมาก การทำแบบนี้จึงเป็นการหลบเกณฑ์เงินทุน (regulatory arbitrage) มากกว่าการลดความเสี่ยง cash CDO ต้องมีผู้จัดการพอร์ต มีเอกสารยาวที่กำหนดว่าเงินไหลอย่างไร (waterfall) มีกลไกกันชนความเสียหาย (credit enhancement) และทุกชั้นต้องได้อันดับจากบริษัทจัดอันดับ

synthetic CDO เกิดเพราะคนแต่ละกลุ่มอยากได้ของต่างกัน hedge fund อยากได้ชั้นเสี่ยง บริษัทประกันอยากได้ชั้น AAA และตลาด CDS โตพอที่จะอ้างอิงรายชื่อบริษัทได้โดยไม่ต้องถือหนี้จริง synthetic CDO ต่างจาก cash CDO สองข้อ ข้อแรก ธนาคารขาย protection บนชั้นเดียวได้ โดยไม่ต้องขายชั้นอื่น ข้อสอง ธนาคารไม่ได้ถือหุ้นกู้จริง จึงต้องลดความเสี่ยง (hedge) ด้วย CDS ของแต่ละบริษัทหรือของดัชนีอยู่ตลอด และสัดส่วนการ hedge ก็มาจากแบบจำลองเดียวกันนี้

ตลาดเห็นเบี้ย $s$ ของแต่ละชั้น แล้วหาย้อนเป็น implied correlation ผลคือแต่ละชั้นได้ $\rho$ ไม่เท่ากัน และบางชั้นหาไม่ได้เลย แบบจำลองนี้นิยมเพราะคำนวณเร็ว ไม่ใช่เพราะถูกต้อง

โต๊ะเทรดที่ถือชั้นของ CDO ต้องรายงานว่ามูลค่าไวแค่ไหนต่อ spread ของแต่ละบริษัท ต่อ $\rho$ และต่อ recovery ไม่ใช่แค่ต่อ spread ของดัชนี เหตุการณ์จริงสองครั้งแสดงว่าทำไม

ครั้งแรกคือพฤษภาคม 2005 Ford และ General Motors ถูกลดอันดับเป็น junk คือต่ำกว่าระดับที่ถือว่าน่าลงทุน ชั้น equity กับ mezzanine ขยับสวนทางกับที่แบบจำลองคาด โต๊ะที่ถือ equity (คือขาย protection บน equity) แล้ว hedge ด้วยการซื้อ protection บน mezzanine จึงขาดทุนทั้งสองขา ครั้งที่สองคือปี 2012 ตำแหน่งขนาดใหญ่ของ JPMorgan ในดัชนี CDX IG9 (ดัชนี CDS ของบริษัทอเมริกันเกรดดี รุ่นที่ 9) ซึ่งเรียกกันว่ากรณี London Whale ถูกสังเกตเห็นเพราะราคาดัชนีเพี้ยนจากราคาของสิ่งที่เกี่ยวข้อง

ทั้งสองกรณีบอกว่า ราคาที่ใช้ตีมูลค่า (mark) และการ hedge ของพอร์ตแบบนี้พึ่งแบบจำลองมากกว่าที่เห็น และส่วนต่างระหว่างราคาซื้อกับราคาขาย (bid-offer) ที่กว้าง ทำให้การปิดสถานะมีต้นทุนสูง

1. ใช้พอร์ต \$100 ล้านกับสามชั้นเดิมของขั้นแรก คือ 0%–3%, 3%–7% และ 7%–100% ถ้าปีนี้พอร์ตขาดทุน 8% หรือ \$8 ล้าน แต่ละชั้นเสียกี่ดอลลาร์?

เฉลย

ใช้ $\ell(L)=\min(\max(L-a,0),\ b-a)$ กับ $L=8$ หน่วยเป็นล้านดอลลาร์:

\[ \begin{aligned} \ell_{0,3}(8)&=\min(8-0,\ 3)=3,\\ \ell_{3,7}(8)&=\min(8-3,\ 4)=4,\\ \ell_{7,100}(8)&=\min(8-7,\ 93)=1. \end{aligned} \]

equity เสีย \$3 ล้าน (หมดชั้น) mezzanine เสีย \$4 ล้าน (หมดชั้น) senior เสีย \$1 ล้าน รวม $3+4+1=8$ เท่ากับขาดทุนของพอร์ต senior เริ่มเสียแล้วเพราะขาดทุนเกิน 7%

2. กลับไปที่ลูกหนี้สองราย รายละ \$50 แต่ละรายมีโอกาสผิดนัด 10% ชั้นบนรับส่วนที่เกิน \$50 คราวนี้สมมติว่าโอกาสที่ทั้งคู่ผิดนัดพร้อมกันเป็น 5.5% ซึ่งอยู่ระหว่างโลกอิสระ (1%) กับโลกพร้อมกันเสมอ (10%) ขาดทุนเฉลี่ยของพอร์ตและของชั้นบนเป็นเท่าไร?

เฉลย

ลูกหนี้รายแรกผิดนัด 10% ในนั้น 5.5% เป็นการผิดนัดพร้อมอีกราย จึงผิดนัดคนเดียว $0.10-0.055=0.045$ รายที่สองก็เหมือนกัน

\[ \begin{aligned} P(L=50)&=2(0.10-0.055)=0.09,\\ P(L=100)&=0.055,\\ P(L=0)&=1-0.055-0.09=0.855,\\ E[L]&=0.09(50)+0.055(100)\\ &=4.5+5.5=10,\\ E[\ell]&=0.055(50)=2.75. \end{aligned} \]

ขาดทุนเฉลี่ยของพอร์ตยังเป็น \$10 เท่าเดิม ชั้นบนเสียเฉลี่ย \$2.75 อยู่ระหว่าง \$0.50 กับ \$5.00 ตามโอกาสผิดนัดพร้อมกัน

const {sqrt, exp, log, log1p, abs, PI, min, max} = Math;
function num(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(`${name} must be a finite number`);
  return x;
}
const pdf = x => exp(-x * x / 2) / sqrt(2 * PI);
// Standard normal CDF: power series near 0, continued fraction in the tails.
function Phi(x) {
  if (abs(num('x', x)) < 3) {
    let term = x, sum = x;
    for (let n = 1; n < 200 && abs(term) > 1e-17 * abs(sum); n++) { term *= x * x / (2 * n + 1); sum += term; }
    return 0.5 + pdf(x) * sum;
  }
  const z = abs(x); let f = z;
  for (let k = 300; k >= 1; k--) f = z + k / f;
  return x > 0 ? 1 - pdf(z) / f : pdf(z) / f;
}
function PhiInv(p) {
  if (!(num('p', p) > 0 && p < 1)) throw new RangeError('p must be strictly between 0 and 1');
  let x = 0;
  for (let i = 0; i < 100; i++) { const dx = (Phi(x) - p) / pdf(x); x -= dx; if (abs(dx) < 1e-15) break; }
  return x;
}
// Tranche loss for portfolio loss L and tranche [a, b].
function trancheLoss(L, a, b) {
  if (!(num('a', a) >= 0 && num('b', b) > a)) throw new RangeError('need 0 <= a < b');
  return min(max(num('L', L) - a, 0), b - a);
}
// P(L = l), l = 0..N, in the one-factor Gaussian copula; trapezoid rule over the factor m.
function lossDistribution(N, q, rho, h = 0.01, lim = 10) {
  if (!Number.isInteger(N) || N < 1) throw new RangeError('N must be a positive whole number');
  if (!(num('rho', rho) >= 0 && rho < 1)) throw new RangeError('rho must be in [0, 1)');
  const c = PhiInv(q), logC = [0];
  for (let l = 1; l <= N; l++) logC.push(logC[l - 1] + log(N - l + 1) - log(l));
  const binom = p => logC.map((lc, l) => p <= 0 ? +(l === 0) : p >= 1 ? +(l === N) : exp(lc + l * log(p) + (N - l) * log1p(-p)));
  if (rho === 0) return binom(q);
  const out = new Array(N + 1).fill(0);
  for (let m = -lim; m <= lim + 1e-9; m += h) {
    const w = h * pdf(m), row = binom(Phi((c - sqrt(rho) * m) / sqrt(1 - rho)));
    for (let l = 0; l <= N; l++) out[l] += w * row[l];
  }
  return out;
}
const expectedTranche = (P, a, b) => P.reduce((s, p, l) => s + p * trancheLoss(l, a, b), 0);
// Two-period tranche: premium on the notional left at the start of each year, default leg on new losses.
function fairSpread(E1, E2, a, b, r) {
  const th = b - a, d1 = 1 / (1 + r), d2 = d1 * d1;
  const annuity = d1 * th + d2 * (th - E1), protection = d1 * E1 + d2 * (E2 - E1);
  return {annuity, protection, spread: protection / annuity, upfront5: (protection - 0.05 * annuity) / th};
}
// Number of defaults when each name has its own default probability (names independent).
function poissonBinomial(ps) {
  let d = [1];
  for (const p of ps) {
    if (!(num('p', p) >= 0 && p <= 1)) throw new RangeError('probabilities must be in [0, 1]');
    const nd = new Array(d.length + 1).fill(0);
    d.forEach((x, k) => { nd[k] += x * (1 - p); nd[k + 1] += x * p; });
    d = nd;
  }
  return d;
}

  • ขาดทุนของชั้น $[a,b]$ คือ $\ell(L)=\min(\max(L-a,0),\ b-a)$ เช่นพอร์ตเสีย 5% ชั้น 3%–7% เสีย $5-3=2$ จากความหนา 4 คือครึ่งชั้น

  • Gaussian copula ทำให้ทุกบริษัทอิสระกันเมื่อรู้ปัจจัยร่วม จึงนับด้วย binomial แล้วอินทิเกรตข้ามปัจจัย ปีที่เศรษฐกิจแย่ ($m=-2$ ที่ $\rho=0.5$) ดันโอกาสผิดนัดของทุกบริษัทจาก 2% เป็น 18.3% พร้อมกัน
  • ในพอร์ต 125 บริษัทที่ $q=2\%$ การขยับ $\rho$ จาก 0 เป็น 0.5 ย้ายขาดทุนเฉลี่ยของ super senior จาก 0.0183 เป็น 1.2354 ราย และของ equity จาก 2.0933 เป็น 0.8442 ราย
  • เบี้ยยุติธรรมของชั้นหาจากการตั้งขาเบี้ยให้เท่าขาชดเชย โดยคิดเบี้ยบนส่วนที่เหลือ ได้ 18.11% ต่อปีสำหรับชั้นกลางในสัญญา 2 ปี
  • correlation ตัวเดียวไม่บอก tail dependence normal กับ meta-Gumbel ที่ความสัมพันธ์ใกล้กัน มีโอกาสสุดขั้วพร้อมกันต่างกัน 2.4 เท่า
