2.2 ความผันผวนมาจากภายในกลุ่ม หรือจากค่าเฉลี่ยที่ต่างกัน?

ความแปรปรวนรวมเท่ากับการแกว่งภายในแต่ละกรณี บวกกับการที่ค่าเฉลี่ยของแต่ละกรณีอยู่ห่างกัน

พอร์ตหนึ่งมีวันสงบ 75% ของวัน วันสงบกำไรเฉลี่ย \$200 และ standard deviation (SD) \$400 อีก 25% เป็นวันตึงเครียด ขาดทุนเฉลี่ย \$500 และ SD \$1,000 (ตัวเลขสมมติ) รายงานความเสี่ยงฉบับร่างเขียนว่า SD ต่อวันของพอร์ตคือ $0.75(400)+0.25(1{,}000)=550$ ดอลลาร์ ผู้จัดการความเสี่ยงจะเซ็นผ่านได้ไหม ถ้าไม่ได้ ตัวเลขที่ถูกคือเท่าไร

ลองตอบก่อนเปิดเฉลย

เซ็นไม่ได้ SD ที่ถูกคือประมาณ \$679.61 ต่อวัน มากกว่าในร่าง 24% มาจากสองส่วนที่ต้องบวกกันในหน่วยกำลังสอง: การแกว่งภายในสภาวะ $0.75(400^2)+0.25(1{,}000^2)=370{,}000$ และการที่ค่าเฉลี่ย 200 กับ −500 อยู่ห่างกัน $91{,}875$ รวม variance $461{,}875$ แล้วจึงถอดราก การเฉลี่ย SD ตรง ๆ ผิดสองชั้น: ลืมส่วนที่สอง และเฉลี่ยรากแทนเฉลี่ยกำลังสอง

ภาพรวมก่อนลงสูตร

หน้าที่แล้ว tower property บอกว่าค่าเฉลี่ยรวมคือค่าเฉลี่ยของค่าเฉลี่ยรายกรณี ความแปรปรวนไม่ง่ายอย่างนั้น เพราะผลลัพธ์หนึ่งวันอยู่ห่างค่าเฉลี่ยรวมได้สองทาง: ห่างจากศูนย์กลางของกรณีตัวเอง และศูนย์กลางของกรณีนั้นเองก็ห่างจากค่าเฉลี่ยรวม

รูปด้านล่างวาดผลลัพธ์ทั้งหมดบนเส้นจำนวน ลูกศรเขียวคือระยะภายในกลุ่ม ลูกศรม่วงคือระยะระหว่างกลุ่ม law of total variance บอกว่า variance รวมเท่ากับค่าเฉลี่ยของระยะเขียวยกกำลังสอง บวกค่าเฉลี่ยของระยะม่วงยกกำลังสอง ไม่มีพจน์ไขว้ ชื่อเล่น EVVE มาจากลำดับตัวอักษรของสูตร $\operatorname{Var}(Y)=E[\operatorname{Var}(Y\mid X)]+\operatorname{Var}(E[Y\mid X])$

หน้านี้จะคำนวณสองส่วนทีละขั้น ตรวจกับการแจกแจงที่นับมือได้ พิสูจน์ว่าทำไมพจน์ไขว้หายไป แล้วใช้กฎนี้แยกความแม่นของค่าพยากรณ์ออกจากความเสี่ยงของพอร์ต และอธิบายว่าทำไมตลาดที่สลับสภาวะจึงมีหางหนา

ศัพท์ที่ใช้ในหัวข้อนี้
Conditional variance $\operatorname{Var}(Y\mid X)$
ความแปรปรวนของ $Y$ รอบค่าเฉลี่ยของกรณีตัวเอง เมื่อรู้ $X$ แล้ว มันเป็นตัวแปรสุ่มเพราะขึ้นกับว่า $X$ ออกกรณีไหน ใช้วัดว่ารู้สภาวะแล้วยังเหลือความไม่แน่นอนเท่าไร
ส่วนภายในกลุ่ม (within) $W$
$E[\operatorname{Var}(Y\mid X)]$ ค่าเฉลี่ยของ conditional variance ถ่วงด้วยโอกาสของแต่ละกรณี คือความเสี่ยงที่เหลือแม้รู้สภาวะ
ส่วนระหว่างกลุ่ม (between) $B$
$\operatorname{Var}(E[Y\mid X])$ ความแปรปรวนของค่าเฉลี่ยรายกรณีรอบค่าเฉลี่ยรวม คือส่วนที่ข้อมูล $X$ อธิบายได้
Law of total variance (EVVE)
$\operatorname{Var}(Y)=W+B$ ใช้แยกที่มาของความเสี่ยง และเป็นเครื่องมือหลักของ random sums ในหน้าถัดไป
Mean squared error (MSE)
ค่าเฉลี่ยของ (ผลจริง − ค่าพยากรณ์)² ใช้วัดความแม่นของค่าพยากรณ์ รากของมันเรียก RMSE
Mixture distribution
การแจกแจงที่เกิดจากสุ่มสภาวะก่อนแล้วสุ่มผลลัพธ์ในสภาวะนั้น เป็นแบบจำลองพื้นฐานของตลาดที่สลับระหว่างช่วงสงบกับช่วงผันผวน
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$p_x$โอกาสของสภาวะ $x$ไม่มีหน่วย
$m_x$, $\mu$ค่าเฉลี่ยในสภาวะ $x$ และค่าเฉลี่ยรวมดอลลาร์
$s_x$SD ภายในสภาวะ $x$ดอลลาร์
$W$, $B$ส่วนภายในกลุ่มและส่วนระหว่างกลุ่มของ varianceดอลลาร์²

ขั้นที่ 1 — หาศูนย์กลางรวมก่อน

ทั้งสองส่วนของความแปรปรวนวัดระยะจากค่าเฉลี่ยรวม จึงต้องหามันก่อน ด้วย tower property

โจทย์ให้อะไรมาบ้าง: $p_{\text{calm}}=0.75$, $m_{\text{calm}}=200$, $s_{\text{calm}}=400$ และ $p_{\text{stress}}=0.25$, $m_{\text{stress}}=-500$, $s_{\text{stress}}=1{,}000$ ดอลลาร์

\[ \begin{aligned} \mu=E[Y]&=0.75(200)+0.25(-500)\\ &=150-125=25. \end{aligned} \]

คำตอบ: กำไรเฉลี่ย \$25 ต่อวัน เล็กมากเมื่อเทียบกับการแกว่งหลายร้อยดอลลาร์ของแต่ละวัน

ขั้นที่ 2 — ส่วนภายในกลุ่ม: รู้สภาวะแล้วยังแกว่งเท่าไร

สมมติว่าเช้านี้เรารู้แล้วว่าเป็นวันแบบไหน กำไรจริงยังไม่แน่นอน มันแกว่งรอบค่าเฉลี่ยของวันแบบนั้นด้วย variance $s_x^2$ ส่วนภายในคือค่าเฉลี่ยของ variance เหล่านี้ ถ่วงด้วยความถี่ของวัน

\[ \begin{aligned} W&=E\big[\operatorname{Var}(Y\mid X)\big]=\sum_x p_x\,s_x^2\\ &=0.75(400^2)+0.25(1{,}000^2)\\ &=120{,}000+250{,}000\\ &=370{,}000. \end{aligned} \]

ต้องเฉลี่ย variance ไม่ใช่เฉลี่ย SD เพราะ variance คือค่าเฉลี่ยของระยะยกกำลังสอง และค่าเฉลี่ยของค่าเฉลี่ยยังเป็นค่าเฉลี่ยของสิ่งเดียวกัน ส่วน SD เป็นรากซึ่งเฉลี่ยข้ามกลุ่มตรง ๆ ไม่ได้ สังเกตว่าวันตึงเครียดเกิดแค่ 25% แต่ให้ส่วนภายในถึง 250,000 จาก 370,000 เพราะ SD ที่ใหญ่ขึ้นสองเท่าครึ่งกลายเป็นหกเท่าหนึ่งในสี่เมื่อยกกำลังสอง

ขั้นที่ 3 — ส่วนระหว่างกลุ่ม: ค่าเฉลี่ยของกรณีอยู่ห่างกันเท่าไร

คราวนี้ลบการแกว่งภายในทิ้งทั้งหมด แทนผลลัพธ์ทุกวันด้วยค่าเฉลี่ยของวันแบบนั้น แล้วถามว่าตัวเลขที่เหลือนี้ยังแกว่งรอบ 25 เท่าไร

\[ \begin{aligned} B&=\operatorname{Var}\big(E[Y\mid X]\big)=\sum_x p_x(m_x-\mu)^2\\ &=0.75(200-25)^2+0.25(-500-25)^2\\ &=0.75(175^2)+0.25(525^2)\\ &=22{,}968.75+68{,}906.25\\ &=91{,}875. \end{aligned} \]

$E[Y\mid X]$ เป็นตัวแปรสุ่มที่ได้ 200 ด้วยโอกาส 0.75 และ −500 ด้วยโอกาส 0.25 บรรทัดแรกจึงเป็นแค่ variance ของตัวแปรสุ่มสองค่าตามนิยามใน variance ระยะต้องวัดจากค่าเฉลี่ยรวม 25 ไม่ใช่จากศูนย์ ถ้าลืมลบ 25 จะได้ $0.75(200^2)+0.25(500^2)=92{,}500$ ซึ่งเกินไป $25^2=625$ พอดี

ขั้นที่ 4 — บวกในหน่วยกำลังสอง แล้วค่อยถอดราก

โจทย์ให้อะไรมาบ้าง: ส่วนภายใน $W=370{,}000$ และส่วนระหว่าง $B=91{,}875$ ดอลลาร์² ที่เพิ่งได้

\[ \begin{aligned} \operatorname{Var}(Y)&=W+B=461{,}875,\\ \operatorname{SD}(Y)&=\sqrt{461{,}875}\approx679.61,\\ \frac{W}{W+B}&\approx80.1\%,\quad\frac{B}{W+B}\approx19.9\%. \end{aligned} \]

คำตอบ: SD ประมาณ \$679.61 ต่อวัน ไม่ใช่ \$550 จากการเฉลี่ย SD และไม่ใช่ $\sqrt{370{,}000}\approx608.28$ จากการทิ้งส่วนระหว่างกลุ่ม ราว 80% ของ variance มาจากการแกว่งภายในสภาวะ อีก 20% มาจากการที่สองสภาวะมีค่าเฉลี่ยต่างกัน

ตรวจเองใน 10 วินาที: $680^2=462{,}400$ ใกล้ 461,875 และ $550^2=302{,}500$ ห่างไปมาก การเฉลี่ย SD จึงพลาด variance ไปมากกว่าหนึ่งในสาม

ขั้นที่ 5 — ตรวจกับการแจกแจงที่นับมือได้

สูตรใช้แค่ค่าเฉลี่ยและ SD ของแต่ละกรณี ขั้นนี้สร้างการแจกแจงจริงหนึ่งแบบที่มีตัวเลขเหล่านั้นพอดี แล้วคำนวณ variance ตรง ๆ โดยไม่ผ่านสูตร

โจทย์ให้อะไรมาบ้าง: แปดผลลัพธ์ที่มีโอกาสเท่ากันคนละ 1/8: วันสงบหกผลลัพธ์เป็น 600, −200, 600, −200, 600, −200 (อยู่ห่าง 200 เท่ากับ 400 ทุกตัว จึงมี SD 400) และวันตึงเครียดสองผลลัพธ์เป็น 500 และ −1,500 (อยู่ห่าง −500 เท่ากับ 1,000 จึงมี SD 1,000) สัดส่วน 6:2 คือ 75%:25% ตามโจทย์

\[ \begin{aligned} E[Y]&=\tfrac18\big(3(600)+3(-200)\\ &\qquad+500-1{,}500\big)=25,\\ E[Y^2]&=\tfrac18\big(3(600^2)+3(200^2)\\ &\qquad+500^2+1{,}500^2\big)\\ &=462{,}500,\\ \operatorname{Var}(Y)&=462{,}500-25^2\\ &=461{,}875. \end{aligned} \]

คำตอบ: ตรงกับ $W+B$ ทุกหลัก หารด้วย 8 เพราะนี่คือ variance ของการแจกแจงที่กำหนด ไม่ใช่การประมาณจากตัวอย่างข้อมูลซึ่งหารด้วย $n-1$ (estimators)

ขั้นที่ 6 — พิสูจน์ว่าทำไมบวกกันได้พอดี

ตัวอย่างตรงกันแล้ว ต้องการเหตุผลที่ใช้ได้ทุกกรณี ให้ $m=E[Y\mid X]$ และสมมติ $E[Y^2]\lt\infty$ ขั้นแรกหา second moment ภายในกรณีก่อน แล้วเฉลี่ยข้ามกรณีด้วย tower property

\[ \begin{aligned} \operatorname{Var}(Y\mid X)&=E[(Y-m)^2\mid X]\\ &=E[Y^2\mid X]-2m\,E[Y\mid X]+m^2\\ &=E[Y^2\mid X]-m^2,\\ \operatorname{Var}(Y)&=E[Y^2]-(E[Y])^2\\ &=E\big[E[Y^2\mid X]\big]-(E[m])^2\\ &=E\big[\operatorname{Var}(Y\mid X)\big]\\ &\quad+E[m^2]-(E[m])^2\\ &=E\big[\operatorname{Var}(Y\mid X)\big]+\operatorname{Var}(m). \end{aligned} \]

สามบรรทัดแรกกระจายกำลังสองภายในกรณี โดยดึง $m$ ออกนอกค่าเฉลี่ยเพราะรู้แล้วเมื่อรู้ $X$ (การดึงสิ่งที่รู้แล้วออก จาก tower property) ได้ $E[Y^2\mid X]=\operatorname{Var}(Y\mid X)+m^2$ ตัวอย่าง: วันสงบมี $E[Y^2\mid\text{calm}]=400^2+200^2=200{,}000$ ไม่ใช่ 160,000 เพราะ second moment วัดจากศูนย์

บรรทัดถัดมาใช้ tower property สองครั้ง กับ $Y^2$ และกับ $Y$ แล้วแทนผลข้างบน สองพจน์สุดท้าย $E[m^2]-(E[m])^2$ คือนิยามของ variance ของ $m$ เอง จึงได้ EVVE

อีกมุมหนึ่งที่เห็นภาพกว่า: เขียน $Y-\mu=(Y-m)+(m-\mu)$ แล้วยกกำลังสอง พจน์ไขว้ $2(Y-m)(m-\mu)$ มีค่าเฉลี่ยศูนย์ เพราะเมื่อรู้ $X$ ตัว $m-\mu$ เป็นค่าคงที่ ส่วน $Y-m$ เฉลี่ยศูนย์พอดี ระยะสองท่อนจึงตั้งฉากกันแบบทฤษฎีบทพีทาโกรัส: variance บวกกันได้ แต่ SD บวกกันไม่ได้

ขั้นที่ 7 — รู้สภาวะช่วยให้พยากรณ์แม่นขึ้น แต่พอร์ตไม่ได้เสี่ยงน้อยลงเอง

ถ้าเช้านี้รู้สภาวะ ค่าพยากรณ์ที่ดีที่สุดคือค่าเฉลี่ยของสภาวะนั้น ขั้นนี้วัดว่าความคลาดเคลื่อนของการพยากรณ์ลดลงเท่าไร และแยกมันออกจากความเสี่ยงของเงินจริง

\[ \begin{aligned} E\big[(Y-\mu)^2\big]&=\operatorname{Var}(Y)=461{,}875,\\ E\big[(Y-m(X))^2\big]&=E\big[\operatorname{Var}(Y\mid X)\big]\\ &=W=370{,}000,\\ \frac{B}{\operatorname{Var}(Y)}&\approx19.9\%. \end{aligned} \]

บรรทัดแรกคือ MSE ของการทายด้วยค่าเฉลี่ยรวม 25 ทุกวัน บรรทัดที่สองคือ MSE ของการทายด้วย 200 หรือ −500 ตามสภาวะ ส่วนต่างคือ $B$ พอดี ข้อมูลสภาวะจึงอธิบายความแปรปรวนได้ 19.9% แนวคิดเดียวกับ $R^2$ ของ OLS regression RMSE ลดจาก 679.61 เหลือ 608.28 ดอลลาร์

แต่ความแปรปรวนของ P&L พอร์ตยังเป็น 461,875 เท่าเดิม การรู้สภาวะไม่ได้เปลี่ยนเงินที่เข้าออกพอร์ต ความเสี่ยงลดลงก็ต่อเมื่อเราทำอะไรบางอย่าง เช่น ถ้า hedge ที่ลด variance ภายในทุกสภาวะลงครึ่งหนึ่งโดยไม่เปลี่ยนค่าเฉลี่ย จะได้ $185{,}000+91{,}875=276{,}875$ SD ลดเหลือ 526.19 ไม่ใช่ครึ่งหนึ่งของ 679.61 เพราะส่วนระหว่างไม่ได้ลด และการลด variance ครึ่งหนึ่งลด SD แค่เท่ากับคูณ $1/\sqrt2$

ขั้นที่ 8 — กลยุทธ์ momentum สามสภาวะรายเดือน

กฎใช้กับกี่กรณีก็ได้ ขั้นนี้ใช้สามสภาวะของกลยุทธ์ momentum สมมติตัวเดียวกับใน tower property ซึ่งมีผลตอบแทนเฉลี่ย 0.318% ต่อเดือน แล้วเพิ่ม SD ของแต่ละสภาวะ คำนวณเป็นจุดเปอร์เซ็นต์ตลอด

โจทย์ให้อะไรมาบ้าง: ความผันผวนต่ำ โอกาส 0.55 เฉลี่ย 0.9 SD 1.2 ปกติ โอกาส 0.32 เฉลี่ย 0.3 SD 2.4 วิกฤต โอกาส 0.13 เฉลี่ย −2.1 SD 6.5

\[ \begin{aligned} W&=0.55(1.2^2)+0.32(2.4^2)+0.13(6.5^2)\\ &=0.792+1.8432+5.4925\\ &=8.1277,\\ E[m^2]&=0.55(0.9^2)+0.32(0.3^2)\\ &\quad+0.13(2.1^2)=1.0476,\\ B&=1.0476-0.318^2=0.946476,\\ \operatorname{Var}(R)&=9.074176,\\ \operatorname{SD}(R)&\approx3.012. \end{aligned} \]

คำตอบ: SD ประมาณ 3.01% ต่อเดือน ส่วนภายในคิดเป็น 89.6% ของ variance วิกฤตเกิดแค่ 13% ของเดือน แต่ให้ส่วนภายใน 5.49 จาก 8.13 และให้ส่วนระหว่างส่วนใหญ่ด้วย เพราะ −2.1 อยู่ไกลจาก 0.318 ที่สุด

ถ้าแต่ละเดือนมีการแจกแจงเดิมและไม่สัมพันธ์กันข้ามเดือน variance ของผลรวม 12 เดือนคือ 12 เท่า SD จึงคูณ $\sqrt{12}$: $\sqrt{12}(3.012)\approx10.44\%$ ต่อปี และอัตราส่วนผลตอบแทนเฉลี่ยต่อ SD ต่อปี (อัตราปลอดความเสี่ยงศูนย์) คือ $12(0.318)/10.44\approx0.37$ ถ้าเดือนติดกันสัมพันธ์กันต้องบวก covariance เข้าไปด้วย

ตรวจเองใน 10 วินาที: เฉลี่ย SD ตรง ๆ ได้ $0.55(1.2)+0.32(2.4)+0.13(6.5)=2.273$ ต่ำกว่า 3.012 อยู่หนึ่งในสี่ ความผิดแบบเดียวกับร่างรายงานตอนต้นหน้า

ขั้นที่ 9 — สองสภาวะ Normal รวมกันได้หางหนา

ข้อมูลผลตอบแทนรายวันจริงมีวันที่ขยับเกินสาม SD บ่อยกว่าที่ Normal ทำนายมาก (stylized facts) ขั้นนี้แสดงว่าการสลับสภาวะอย่างเดียวก็สร้างหางหนาได้ ใช้ตลาดสมมติที่ 80% ของวันเป็น Normal ค่าเฉลี่ยศูนย์ SD 1% และ 20% เป็น Normal ค่าเฉลี่ยศูนย์ SD 3%

\[ \begin{aligned} \operatorname{Var}(R)&=0.8(1^2)+0.2(3^2)+0\\ &=2.6,\quad\operatorname{SD}(R)\approx1.612,\\ P(|R|\gt4.84)&=0.8\,P\big(|Z|\gt4.84\big)\\ &\quad+0.2\,P\big(|Z|\gt1.612\big)\\ &\approx0.000001+0.0214\\ &\approx2.14\%,\\ P\big(|Z|\gt3\big)&\approx0.27\%. \end{aligned} \]

บรรทัดแรกคือ EVVE ที่ส่วนระหว่างเป็นศูนย์ เพราะค่าเฉลี่ยของสองสภาวะเท่ากัน บรรทัดที่สองถามโอกาสที่ผลตอบแทนขยับเกินสาม SD รวม ($3\times1.612\approx4.84\%$) โอกาสคือค่าเฉลี่ยของตัวบ่งชี้ จึงใช้ tower property แยกตามสภาวะได้ ในวันสงบ 4.84% คือ 4.84 SD ของวันนั้น แทบเป็นไปไม่ได้ ในวันผันผวน 4.84% เป็นแค่ $4.84/3\approx1.61$ SD ของวันนั้น เกิดได้บ่อย ($Z$ คือ standard normal และค่าหางอ่านจาก CDF ใน Normal distribution)

Normal ที่มี SD 1.612 เท่ากันให้โอกาสเกินสาม SD แค่ 0.27% ตลาดที่สลับสภาวะจึงมีวันสาม SD บ่อยกว่าเกือบแปดเท่า ทั้งที่ variance เท่ากัน นี่คือเหตุผลหนึ่งที่แบบจำลองความผันผวนเปลี่ยนตามเวลา เช่น GARCH อธิบายหางหนาได้

ความผิดที่ทำให้รายงานความเสี่ยงต่ำเกินจริง

เฉลี่ย SD ตรง ๆ: ได้ 550 แทน 679.61 ดอลลาร์ต่อวัน และ 2.273% แทน 3.012% ต่อเดือน ต่ำไปราวหนึ่งในห้าถึงหนึ่งในสี่ทั้งสองตัวอย่าง

ทิ้งส่วนระหว่างกลุ่ม: รายงานแค่ $\sqrt{W}=608.28$ ซึ่งคือความเสี่ยงที่เหลือ หลังรู้สภาวะแล้ว ไม่ใช่ความเสี่ยงก่อนรู้ ส่วนนี้หายไปได้เฉพาะเมื่อค่าเฉลี่ยของทุกสภาวะเท่ากัน

วัดส่วนระหว่างจากศูนย์: $E[m^2]=92{,}500$ แทน $B=91{,}875$ ที่นี่ผิดแค่ 625 เพราะค่าเฉลี่ยรวม 25 เล็ก ถ้าค่าเฉลี่ยรวมเป็น 300 จะผิดถึง 90,000

สับสนความแม่นของค่าพยากรณ์กับความเสี่ยงพอร์ต: รู้สภาวะแล้ว RMSE ลดจาก 679.61 เหลือ 608.28 แต่ SD ของ P&L พอร์ตยังเป็น 679.61 จนกว่าจะปรับสถานะหรือ hedge

คิดว่าลด variance ครึ่งหนึ่งคือลด SD ครึ่งหนึ่ง: ลดส่วนภายในครึ่งหนึ่งได้ SD 526.19 ลดลงแค่ 22.6%

ใช้ทำอะไรบนโต๊ะจริง

ฝ่ายความเสี่ยงใช้การแยกนี้ตอบว่าความเสี่ยงของพอร์ตมาจากไหน ถ้าส่วนระหว่างใหญ่ แปลว่าค่าเฉลี่ยของพอร์ตเปลี่ยนมากตามสภาวะ การป้องกันที่ได้ผลคือลดความไวต่อสภาวะ ถ้าส่วนภายในใหญ่ แปลว่าแม้รู้สภาวะก็ยังแกว่งมาก ต้องลดขนาดสถานะหรือกระจายความเสี่ยง นักวิเคราะห์แบบจำลองปัจจัยใช้หลักเดียวกันแยก variance ของหุ้นเป็นส่วนที่ปัจจัยอธิบายได้กับส่วนเฉพาะตัว (risk decomposition) และหน้าถัดไปใช้มันหาความเสี่ยงของผลรวมที่จำนวนรายการเป็นตัวแปรสุ่ม

โจทย์ตรวจความเข้าใจ

1. สองสภาวะมีโอกาสครึ่งหนึ่งเท่ากัน ค่าเฉลี่ย 2 เท่ากันทั้งคู่ SD เป็น 1 และ 3 variance รวมเป็นเท่าไร ส่วนไหนเป็นศูนย์

เฉลย

ค่าเฉลี่ยรายสภาวะเท่ากัน $E[Y\mid X]=2$ คงที่ จึงได้ $B=0$ ส่วนภายในคือ $0.5(1^2)+0.5(3^2)=5$ variance รวม 5 และ SD $\sqrt5\approx2.236$ ไม่ใช่ SD เฉลี่ย $0.5(1)+0.5(3)=2$

2. ในตัวอย่างวันสงบกับวันตึงเครียด ถ้ากำไรทุกวันเท่ากับค่าเฉลี่ยของสภาวะพอดี (SD ภายในเป็นศูนย์) SD รวมเป็นเท่าไร

เฉลย

$W=0$ แต่ $B=91{,}875$ ยังอยู่ SD รวมคือ $\sqrt{91{,}875}\approx303.11$ ดอลลาร์ พอร์ตยังเสี่ยงเพราะไม่รู้ล่วงหน้าว่าจะได้ 200 หรือ −500

3. ถ้า $X$ บอกค่า $Y$ ได้แน่นอน หรือถ้า $X$ อิสระจาก $Y$ แต่ละกรณีเหลือส่วนไหน

เฉลย

ถ้า $X$ บอก $Y$ แน่นอน เมื่อรู้ $X$ ก็ไม่เหลือการแกว่ง $W=0$ และ $B=\operatorname{Var}(Y)$ ถ้าอิสระกัน $E[Y\mid X]=E[Y]$ คงที่ จึงได้ $B=0$ และ $W=\operatorname{Var}(Y)$ แต่ $B=0$ อย่างเดียวไม่พิสูจน์ว่าอิสระ ดูโจทย์ข้อแรกที่ค่าเฉลี่ยเท่ากันแต่ SD ต่างกัน

คำนวณซ้ำด้วย JavaScript

ฟังก์ชัน decompose รับโอกาส ค่าเฉลี่ย และ SD ของแต่ละสภาวะ แล้วคืนค่าเฉลี่ยรวม ส่วนภายใน ส่วนระหว่าง และ SD รวม โค้ดตรวจกับการแจกแจงแปดจุดและคำนวณหางของตลาดสองสภาวะด้วย

เปิดดูโค้ด 
const decompose = (p, m, sd) => {
  const mean = p.reduce((s, q, i) => s + q * m[i], 0);
  const within = p.reduce((s, q, i) => s + q * sd[i] ** 2, 0);
  const between = p.reduce((s, q, i) => s + q * (m[i] - mean) ** 2, 0);
  return {mean, within, between, variance: within + between,
    sd: Math.sqrt(within + between)};
};
const daily = decompose([0.75, 0.25], [200, -500], [400, 1000]);
// 25, 370000, 91875, 461875, 679.61

const y = [600, -200, 600, -200, 600, -200, 500, -1500];
const mu = y.reduce((s, a) => s + a, 0) / y.length;
const direct = y.reduce((s, a) => s + (a - mu) ** 2, 0) / y.length; // 461875

const monthly = decompose([0.55, 0.32, 0.13], [0.9, 0.3, -2.1], [1.2, 2.4, 6.5]);
const annualSD = Math.sqrt(12) * monthly.sd;     // 10.44

// tail of a two-regime market: 0.8 N(0,1) + 0.2 N(0,3^2)
const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
const tail = x => {               // P(|Z| > x) by Simpson's rule
  const n = 20000, h = x / n;
  let s = phi(0) + phi(x);
  for (let i = 1; i < n; i++) s += (i % 2 ? 4 : 2) * phi(i * h);
  return 1 - 2 * s * h / 3;
};
const sdMix = Math.sqrt(0.8 * 1 + 0.2 * 9);     // 1.612
const c = 3 * sdMix;
const mixTail = 0.8 * tail(c) + 0.2 * tail(c / 3); // 0.0214
console.log({daily, mu, direct, monthly, annualSD, sdMix, mixTail,
  normalTail: tail(3), hedged: daily.within / 2 + daily.between});

สิ่งที่ควรตอบได้หลังอ่าน

  • $\operatorname{Var}(Y)=E[\operatorname{Var}(Y\mid X)]+\operatorname{Var}(E[Y\mid X])$ เมื่อ $E[Y^2]\lt\infty$ โดยไม่ต้องให้ $X$ กับ $Y$ อิสระกัน
  • ส่วนภายในเฉลี่ย variance ไม่ใช่เฉลี่ย SD ส่วนระหว่างวัดระยะของค่าเฉลี่ยรายกรณีจากค่าเฉลี่ยรวม ตัวอย่างนี้ได้ 370,000 กับ 91,875
  • บวกในหน่วยกำลังสองก่อนถอดราก: SD รวม 679.61 ไม่ใช่ 550 สองส่วนตั้งฉากกันเพราะพจน์ไขว้เฉลี่ยศูนย์
  • ข้อมูลสภาวะลด MSE ของการพยากรณ์ลงเท่ากับส่วนระหว่าง แต่ไม่ได้ลดความเสี่ยงของพอร์ตจนกว่าจะลงมือปรับสถานะ
  • ตลาดที่สลับสภาวะความผันผวนมีวันสาม SD บ่อยกว่า Normal ที่ variance เท่ากันเกือบแปดเท่า

หน้าถัดไป random sums และ Wald's identity ให้ “กรณี” คือจำนวนรายการในหนึ่งวัน แล้วใช้ EVVE หาว่าจำนวนรายการที่ไม่แน่นอนเพิ่มความเสี่ยงของยอดรวมเท่าไร
