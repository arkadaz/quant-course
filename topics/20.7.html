20.7 Credit Default Swaps (CDS)

ผู้ซื้อ CDS จ่ายเบี้ยทุกไตรมาสตราบที่ผู้ออกหนี้ยังรอด แลกกับเงินชดเชยส่วนที่หายเมื่อผิดนัด และ par spread คืออัตราเบี้ยที่ทำให้สองขามีค่าเท่ากัน ซึ่งออกมาใกล้ hazard × (1 − recovery)

ลูกค้าถือ CDS อายุ 5 ปี บนหนี้ \$10,000,000 ในฝั่งผู้ซื้อความคุ้มครอง จ่ายเบี้ย 125 bp ต่อปีทุกไตรมาส วันนี้อัตราไร้ความเสี่ยง 4.5% hazard ของผู้ออกหนี้ 2.0% ต่อปี และ recovery 40% (ตัวเลขสมมติ) ตลาดตั้งเบี้ยยุติธรรมได้ราว 120 bp เพื่อนบอกว่าลูกค้าจ่ายเกินปีละ 5 bp ห้าปี สัญญาจึงติดลบ $0.0005(5)(10^7)=\$25{,}000$ ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก par spread คือ 119.99975 bp และสัญญามีค่า −\$21,225.22 สำหรับผู้ซื้อ ไม่ใช่ −\$25,000 เบี้ยจ่ายเฉพาะเมื่อผู้ออกหนี้ยังรอด และเงินปีหลังต้องคิดลด ส่วนต่างต่อปีจึงคูณด้วย risky annuity 4.2448 ปี ไม่ใช่ 5 ปี แบบเดียวกับการตีมูลค่า swap เก่าด้วย annuity ในหน้า swap rate

ภาพรวมก่อนลงสูตร

พันธบัตรเอกชนผสมความเสี่ยงอัตราดอกเบี้ยกับความเสี่ยงเครดิตไว้ในราคาเดียว CDS แยกความเสี่ยงเครดิตออกมาซื้อขายตรง ๆ ผู้ซื้อความคุ้มครอง (protection buyer) จ่ายเบี้ยเป็นงวด ผู้ขาย (protection seller) จ่ายส่วนที่หาย $(1-R)N$ เมื่อผู้ออกหนี้อ้างอิงผิดนัด โครงสร้างเหมือน swap: สองขา และตั้งอัตราให้มูลค่าเริ่มต้นเป็นศูนย์

ราคาใช้โอกาสรอดชุดเดียวกับพันธบัตรเอกชน: เบี้ยจ่ายเมื่อยังรอด จึงถ่วงด้วยโอกาสรอด เงินชดเชยจ่ายเมื่อผิดนัด จึงถ่วงด้วยโอกาสผิดนัดในงวดนั้น ผลลัพธ์ที่ต้องจำคือ par spread ≈ hazard × (1 − recovery) เพราะในแต่ละไตรมาส เบี้ยที่จ่ายต้องเท่ากับเงินชดเชยที่คาดว่าจะได้

หน้านี้จะไล่เงินของเส้นทางเดียวด้วยมือ สร้างสองขาทีละงวด หา par spread และสูตรประมาณ ตีมูลค่าสัญญาที่เบี้ยไม่เท่า par วัดความไว แกะ hazard จาก spread หลายอายุ และปิดด้วย CDS 2 ปีใน workbook ของคอร์ส รูปด้านล่างคือเงินของ CDS หนึ่งสัญญาในเส้นทางที่ผู้ออกหนี้ผิดนัดในเดือนที่ 16

ศัพท์ที่ใช้ในหัวข้อนี้
Credit default swap (CDS)
สัญญาที่ผู้ซื้อจ่ายเบี้ยเป็นงวดเพื่อรับเงินชดเชยเมื่อผู้ออกหนี้อ้างอิง (reference entity) เกิด credit event เช่นไม่จ่ายหนี้หรือล้มละลาย ใช้ป้องกันหรือรับความเสี่ยงเครดิตโดยไม่ต้องซื้อขายตัวหนี้
Premium leg และ protection leg
premium leg คือมูลค่าวันนี้ของเบี้ยที่ผู้ซื้อจ่ายตราบที่ยังรอด รวมเบี้ยค้างของงวดที่ผิดนัด protection leg (หรือ default leg) คือมูลค่าวันนี้ของเงินชดเชย $(1-R)N$ ที่ผู้ขายจ่ายเมื่อผิดนัด
Par spread
อัตราเบี้ยต่อปีที่ทำให้สองขามีค่าเท่ากัน สัญญาใหม่ที่อัตรานี้ไม่ต้องจ่ายเงินก้อนตอนเริ่ม เป็นตัวเลขที่ตลาดใช้พูดถึงความเสี่ยงเครดิตของบริษัทหรือประเทศ
Risky annuity
มูลค่าวันนี้ของการจ่าย 1 ต่อปีทุกงวดตราบที่ยังไม่ผิดนัด (รวมเบี้ยค้าง) มีหน่วยเป็นปี ใช้แปลงส่วนต่างของอัตราเบี้ยเป็นเงิน แบบ annuity ของ swap ที่เติมโอกาสรอดเข้าไป
Upfront และ standard coupon
ตั้งแต่ปี 2009 ตลาดใช้อัตราเบี้ยมาตรฐานไม่กี่ค่า แล้วชดเชยส่วนต่างกับ par spread ด้วยเงินก้อนวันเริ่มสัญญา (upfront)
Jump-to-default
มูลค่าที่เปลี่ยนทันทีเมื่อผิดนัด ซึ่งใหญ่กว่าความไวต่อ spread หนึ่ง bp หลายพันเท่า ต้องรายงานแยกจาก credit01

ขั้นที่ 1 — ใครจ่ายใคร และเงินของเส้นทางเดียว

เริ่มจากเงินที่ไหลจริงก่อนคิดค่าเฉลี่ยใด ๆ CDS 2 ปี notional \$1,000,000 เบี้ย 160 bp ต่อปีจ่ายทุกไตรมาส recovery 45% สมมติว่าผู้ออกหนี้ผิดนัดในเดือนที่ 16 ตามกติกาแบบง่าย สัญญาจบที่วันจ่ายถัดไป (เดือนที่ 18) และผู้ซื้อจ่ายเบี้ยค้างของช่วงที่ได้รับความคุ้มครองแล้วแต่ยังไม่ได้จ่าย คือตั้งแต่วันจ่ายล่าสุด $t_{k-1}$ ถึงวันผิดนัด $\tau$

\[ \begin{aligned} \delta sN&=\frac{0.016(10^6)}{4}=4{,}000,\\ (\tau-t_{k-1})\,sN&=\frac{0.016(10^6)}{12}\\ &=1{,}333.33,\\ (1-R)N&=0.55(10^6)=550{,}000,\\ X_{\rm buy}&=550{,}000-5(4{,}000)\\ &\quad-1{,}333.33\\ &=528{,}666.67. \end{aligned} \]

ผู้ซื้อจ่ายเบี้ย \$4,000 ในเดือนที่ 3, 6, 9, 12 และ 15 ผิดนัดในเดือนที่ 16 จึงค้างเบี้ยหนึ่งเดือน (เดือน 15 ถึง 16) จ่ายในเดือนที่ 18 พร้อมรับเงินชดเชย \$550,000 ช่วงค้างคือ $\tau-t_{k-1}$ ไม่ใช่ $t_k-\tau$ ซึ่งจะเป็นสองเดือนที่ยังไม่ได้รับความคุ้มครอง (บางเอกสารพิมพ์สลับ ตรวจได้ด้วยตัวอย่างนี้ที่ค้างหนึ่งเดือน)

นี่คือเงินของเส้นทางเดียว ยังไม่คิดลดและไม่ถ่วงโอกาส ผลออกมาสุดขั้ว: จ่าย \$21,333.33 ได้ \$550,000 ถ้าไม่ผิดนัดเลย ผู้ซื้อจ่ายแปดงวดรวม \$32,000 และไม่ได้อะไร ราคาที่ยุติธรรมมาจากการเฉลี่ยทุกเส้นทาง ซึ่งคือขั้นถัดไป

ขั้นที่ 2 — โอกาสรอดและโอกาสผิดนัดรายไตรมาส

ตั้งแต่ขั้นนี้ใช้ CDS 5 ปีของโจทย์เปิดหน้า: $N=\$10$ ล้าน $\delta=0.25$ $n=20$ $r=4.5\%$ $\lambda=2\%$ $R=40\%$ ต้องใช้สองตัวเลขต่องวด ตัวแรกคือโอกาสรอดถึงวันจ่าย ตัวที่สองคือโอกาสผิดนัดภายในงวดนั้นพอดี สองตัวนี้ใช้คนละที่ และการสลับกันคือบั๊กที่พบบ่อยที่สุดในโค้ด CDS

\[ \begin{aligned} Q_i&=e^{-\lambda T_i},\\ \Delta Q_i&=Q_{i-1}-Q_i,\\ Q_1&=e^{-0.005}=0.995012,\\ \Delta Q_1&=0.004988,\\ D_1&=e^{-0.01125}=0.988813. \end{aligned} \]

$Q_i$ ถ่วงเงินที่จ่ายเมื่อยังรอด (เบี้ย) $\Delta Q_i$ ถ่วงเงินที่จ่ายเมื่อผิดนัด (เงินชดเชยและเบี้ยค้าง) ไตรมาสแรกมีโอกาสผิดนัด 0.004988 ไม่ใช่ 0.995012 เลขชี้กำลังมาจากหนึ่งไตรมาส: $0.02(0.25)=0.005$ และ $0.045(0.25)=0.01125$ สมมติด้วยว่าการผิดนัดไม่เกี่ยวกับอัตราดอกเบี้ย ค่าเฉลี่ยของเงินที่คิดลดจึงเป็น $D_i$ คูณโอกาส

ขั้นที่ 3 — ขาเบี้ย: เบี้ยตามกำหนดบวกเบี้ยค้าง ยุบเป็นค่าเฉลี่ยแบบสี่เหลี่ยมคางหมู

เบี้ยงวดที่ $i$ คือ $\delta sN$ จ่ายเมื่อรอดถึง $T_i$ ถ้าผิดนัดกลางงวด ผู้ซื้อจ่ายเบี้ยค้าง สมมติว่าวันผิดนัดกระจายเท่ากันในงวด จึงค้างเฉลี่ยครึ่งงวด $\delta/2$ แล้วดึงตัวร่วมออก

\[ \begin{aligned} PV_{\rm prem}&=sN\sum_{i=1}^{n}\Big[\delta D_iQ_i\\ &\qquad+\frac{\delta}{2}D_i(Q_{i-1}-Q_i)\Big]\\ &=sN\,\frac{\delta}{2}\sum_{i=1}^{n}D_i\,(Q_{i-1}+Q_i)\\ &=sN\,A. \end{aligned} \]

ในวงเล็บ $2Q_i+Q_{i-1}-Q_i=Q_{i-1}+Q_i$ เบี้ยจึงถ่วงด้วยค่าเฉลี่ยของโอกาสรอดต้นงวดกับปลายงวด (สี่เหลี่ยมคางหมู) $A$ คือ risky annuity มีหน่วยเป็นปีและไม่ขึ้นกับ $s$ มันคือ annuity ของ swap ที่เติมโอกาสรอดเข้าไปในทุกงวด

ขั้นที่ 4 — ขาชดเชย และ par spread

เงินชดเชย $(1-R)N$ จ่ายเมื่อผิดนัด ในกติกาของหน้านี้จ่ายที่ปลายงวดที่ผิดนัด จึงถ่วงด้วย $\Delta Q_i$ คิดลดด้วย $D_i$ บวกทุกงวดได้เพราะผิดนัดได้ครั้งเดียว สัญญาใหม่ต้องมีค่าศูนย์ จึงตั้งสองขาเท่ากันแล้วตัด $N$ แบบเดียวกับการหา swap rate

\[ \begin{aligned} PV_{\rm prot}&=N(1-R)\sum_{i=1}^{n}D_i\,\Delta Q_i,\\ s^*&=\frac{(1-R)\sum_iD_i\,\Delta Q_i}{A},\\ \Delta Q_i&=h\,Q_{i-1},\\ s^*&=\frac{(1-R)\,h}{\delta(1-h/2)}\\ &\approx\lambda(1-R). \end{aligned} \]

แถวที่สามให้ $h$ คือโอกาสผิดนัดต่องวดคงที่ แล้ว $Q_i=(1-h)Q_{i-1}$ ทำให้ $Q_{i-1}+Q_i=(2-h)Q_{i-1}$ ผลบวก $\sum D_iQ_{i-1}$ อยู่ทั้งเศษและส่วนจึงตัดกันหมด เหลือแถวที่สี่ ซึ่งไม่ขึ้นกับอัตราดอกเบี้ยเลย ระวัง: $h$ เป็นโอกาสต่องวด จึงต้องหารด้วย $\delta$ ให้เป็นต่อปี (บางเอกสารเขียน $(1-R)h/(1-h/2)$ โดยไม่มี $\delta$ ซึ่งใช้ได้เฉพาะเมื่องวดยาวหนึ่งปี) เพราะ $h\approx\lambda\delta$ แถวสุดท้ายจึงตามมา

ตัวเลขของเรา $h=1-e^{-0.005}=0.004988$ ได้ $0.6(0.004988)/[0.25(0.997506)]=1.2000\%$ เกือบเท่า $\lambda(1-R)=0.02(0.6)=120$ bp พอดี ตัวหาร $1-h/2$ ชดเชยเบี้ยที่จ่ายไม่เต็มงวดเมื่อผิดนัด รูปด้านล่างแสดงว่าทำไมสูตรนี้ไม่ขึ้นกับอัตราดอกเบี้ย: ที่ par spread เงินสองขาเท่ากันทุกไตรมาส ไม่ใช่แค่ผลรวม

ขั้นที่ 5 — ตัวเลขของ CDS 5 ปี: annuity, ขาชดเชย และ par spread

โจทย์ให้อะไรมาบ้าง: เมื่อ $r$ และ $\lambda$ คงที่ $D_iQ_i=a^i$ โดย $a=e^{-(0.045+0.02)(0.25)}=e^{-0.01625}$ และ $D_i\Delta Q_i=(e^{0.005}-1)a^i$ ผลบวก 20 งวดจึงเป็นอนุกรมเรขาคณิต

\[ \begin{aligned} G&=\sum_{i=1}^{20}a^i=\frac{a(1-a^{20})}{1-a}\\ &=16.936879,\\ \Sigma_D&=(e^{0.005}-1)\,G\\ &=0.0848964603,\\ A&=0.25\,G+0.125\,\Sigma_D\\ &=4.2448318563,\\ PV_{\rm prot}&=10^7(0.6)(0.0848964603)\\ &=509{,}378.76,\\ s^*&=\frac{0.6(0.0848964603)}{4.2448318563}\\ &=119.99975\ \text{bp}. \end{aligned} \]

คำตอบ: ขาชดเชยมีค่า \$509,378.76 และที่ par spread 119.99975 bp ขาเบี้ยมีค่าเท่ากันพอดี สัญญาใหม่จึงไม่ต้องจ่ายเงินก้อนตอนเริ่ม ทั้งที่แต่ละขามีค่าเกินครึ่งล้านดอลลาร์ annuity 4.2448 ปีแยกเป็นเบี้ยตามกำหนด 4.2342 ปีกับเบี้ยค้าง 0.0106 ปี

ตรวจเองใน 10 วินาที: $0.6(0.0849)/4.245=0.0120$ เท่ากับ $0.6(0.02)$ ของสูตรลัด และ annuity ต้องต่ำกว่า 5 ปี เพราะเบี้ยถูกคิดลดและหยุดเมื่อผิดนัด

ขั้นที่ 6 — สัญญาที่เบี้ย 125 bp มีค่าเท่าไร และ upfront

สัญญาของลูกค้าจ่ายเบี้ย 125 bp แต่ par วันนี้คือ 119.99975 bp มูลค่าสำหรับผู้ซื้อคือขาชดเชยลบขาเบี้ยที่อัตราของสัญญา ซึ่งเท่ากับส่วนต่างของอัตราคูณ risky annuity

\[ \begin{aligned} PV_{\rm prem}&=10^7(0.0125)(4.2448318563)\\ &=530{,}603.98,\\ V_{\rm buy}&=509{,}378.76-530{,}603.98\\ &=-21{,}225.22,\\ V_{\rm buy}&=N(s^*-s)A. \end{aligned} \]

แถวสุดท้ายได้จากการแทน $PV_{\rm prot}=Ns^*A$ ซึ่งเป็นนิยามของ par spread ผู้ซื้อจ่ายเบี้ยสูงกว่าอัตรายุติธรรมราว 5 bp สัญญาจึงติดลบ \$21,225.22 ถ้าจะเปิดสัญญานี้ใหม่วันนี้ ผู้ขายต้องจ่าย upfront ให้ผู้ซื้อเท่านี้ คำตอบ \$25,000 ของโจทย์เปิดหน้าคูณด้วย 5 ปีแทน 4.2448 ปี

ตั้งแต่ ISDA ปรับกติกาในปี 2009 CDS ในสหรัฐฯ ซื้อขายที่เบี้ยมาตรฐาน 100 bp หรือ 500 bp และครบกำหนดตรงวันมาตรฐาน 20 มีนาคม มิถุนายน กันยายน และธันวาคม ส่วนต่างกับ par spread ชำระเป็น upfront ด้วยสูตรเดียวกับแถวสุดท้าย

ขั้นที่ 7 — credit01 และความเสี่ยงตอนผิดนัด

ขยับ hazard 1 bp (2.00% เป็น 2.01%) คิดทั้งสองขาใหม่ แล้วเทียบกับสิ่งที่เกิดถ้าผู้ออกหนี้ผิดนัดวันนี้: ผู้ซื้อได้ $(1-R)N$ ทันที และสัญญาซึ่งมีค่า $V_{\rm buy}$ หายไป

\[ \begin{aligned} V_{\rm buy}(2.01\%)&-V_{\rm buy}(2.00\%)\\ &=2{,}551.30,\\ \text{JTD}&=(1-R)N-V_{\rm buy}\\ &=6{,}000{,}000+21{,}225.22\\ &=6{,}021{,}225.22. \end{aligned} \]

hazard ขึ้น 1 bp ผู้ซื้อได้ \$2,551.30 ซึ่งใกล้ $NA(1-R)(0.0001)=\$2{,}547$ ของสูตรลัด แต่ถ้าผิดนัดจริงผู้ซื้อได้ราว \$6.02 ล้าน มากกว่า 2,360 เท่า ความเสี่ยงของ CDS จึงรายงานด้วยตัวเลขเดียวไม่ได้ ต้องมีทั้งความไวต่อ spread, jump-to-default, ความไวต่อ recovery และความเสี่ยงของคู่สัญญา ผู้ขายความคุ้มครองอยู่ฝั่งตรงข้ามทุกตัว

ขั้นที่ 8 — แกะ hazard จาก par spread หลายอายุ

ตลาด quote par spread หลายอายุ ไม่ได้ quote hazard โต๊ะจึงแกะ hazard เป็นช่วงจากสั้นไปยาว แบบเดียวกับ bootstrapping ของ zero rate: อายุสั้นที่สุดใช้ hazard ช่วงแรกตัวเดียว อายุถัดไปใช้ช่วงแรกที่ได้แล้ว แก้แค่ช่วงใหม่ ตัวอย่างสมมติ: CDS 1 ปี 100 bp และ 2 ปี 130 bp จ่ายรายไตรมาส $r=4.5\%$ $R=40\%$ hazard คงที่ในแต่ละปี

\[ \begin{aligned} \frac{0.6\,\Sigma_D(\lambda_1)}{A(\lambda_1)}&=0.0100,\\ \lambda_1&=1.6667\%,\\ \frac{0.6\,\Sigma_D(\lambda_1,\lambda_2)}{A(\lambda_1,\lambda_2)}&=0.0130,\\ \lambda_2&=2.7012\%,\\ Q(2)&=e^{-(\lambda_1+\lambda_2)}=0.957261. \end{aligned} \]

ปีแรกได้ $0.01/0.6=1.6667\%$ ตรงสูตรลัด เพราะ hazard คงที่ในปีนั้น ปีที่สองต้องสูงกว่าที่เดาด้วยค่าเฉลี่ย ($2(130/0.6)-166.67=266.67$ bp) เป็น 270.12 bp เพราะเงินปีที่สองถูกคิดลดและมีผู้รอดน้อยกว่า จึงมีน้ำหนักน้อยกว่าในสองขา ต้องดันให้สูงขึ้นอีกนิดจึงยก spread สองปีถึง 130 bp ได้ แต่ละขั้นแก้สมการตัวแปรเดียวด้วย bisection และตรวจด้วยการคิดราคากลับ: ทั้งสองสัญญาต้องมีค่าศูนย์ที่ spread ของตลาด

ขั้นที่ 9 — CDS 2 ปีใน workbook ของคอร์ส

โจทย์ให้อะไรมาบ้าง: workbook เดียวกับที่ใช้ตั้งราคาพันธบัตรห้าตัวในหน้าพันธบัตรที่ผิดนัดได้ ใช้ hazard ต่อครึ่งปีจาก Solver หารสองเป็นต่อไตรมาส: ปีแรก $0.0201406/2=0.0100703$ ปีที่สอง $0.0194431/2=0.0097216$ อัตรา 1% ทบรายไตรมาส $D_k=(1+0.01/4)^{-k}$ recovery 45% notional \$1,000,000 เบี้ยค้างครึ่งงวด แล้วให้ Solver หา spread ที่ทำให้สองขาเท่ากัน

\[ \begin{aligned} PV_{\rm prem}&=41{,}396.31+206.97\\ &=41{,}603.28,\\ PV_{\rm prot}&=41{,}603.28,\\ s^*&=218.8895\ \text{bp},\\ s^*_1&\approx\frac{0.55(0.010070)}{0.25(0.994965)}\\ &=222.67\ \text{bp},\\ s^*_2&\approx214.92\ \text{bp}. \end{aligned} \]

คำตอบ: เบี้ยตามกำหนด \$41,396.31 เบี้ยค้าง \$206.97 (เล็กเพราะโอกาสผิดนัดต่อไตรมาสราว 1% และค้างครึ่งไตรมาส) และขาชดเชย \$41,603.28 เท่ากันพอดีที่ 218.8895 bp ซึ่งคือค่าที่ workbook เก็บไว้ในช่อง Spread สูตรประมาณด้วย hazard ปีแรกได้ 222.67 bp ปีที่สองได้ 214.92 bp ค่าจริงอยู่ระหว่างกลาง

ตรวจเองใน 10 วินาที: $0.55(4)(1.007\%)=2.22\%$ ใกล้ 218.89 bp เพราะ spread ต่อปีคือ loss given default คูณ hazard ต่อปีโดยประมาณ (hazard ต่อไตรมาสคูณ 4)

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

คูณส่วนต่างของเบี้ยด้วยจำนวนปี: $0.0005(5)(10^7)=\$25{,}000$ แทน \$21,225.22 ต้องคูณ risky annuity 4.2448 ปี

ใช้โอกาสรอดแทนโอกาสผิดนัดในขาชดเชย: ไตรมาสแรกจะได้น้ำหนัก 0.995 แทน 0.005 ขาชดเชยใหญ่เกินจริงราวสองร้อยเท่า ตรวจได้ทันทีเพราะ par spread จะออกมาเป็นหลายสิบเปอร์เซ็นต์

ลืมเบี้ยค้าง: annuity เหลือ 4.2342 แทน 4.2448 par spread สูงไปเป็น 120.30 bp สำหรับ CDS 5 ปีนี้ ต่างแค่ 0.3 bp แต่สำหรับชื่อที่ hazard สูง ส่วนนี้โตตาม

ลืมหารด้วย $\delta$ ในสูตรประมาณ: ใช้ $(1-R)h/(1-h/2)$ กับ $h$ รายไตรมาส 0.004988 ได้ 30 bp แทน 120 bp ต่ำไปสี่เท่า

สลับเครื่องหมายผู้ซื้อกับผู้ขาย: −\$21,225.22 เป็นของผู้ซื้อ ผู้ขายได้ +\$21,225.22 ถ้าสลับ รายงานกำไรขาดทุนผิดไปสองเท่าของค่านี้

นับเบี้ยค้างผิดช่วง: ใช้ $t_k-\tau$ แทน $\tau-t_{k-1}$ ในเส้นทางที่ผิดนัดเดือน 16 ได้สองเดือน (\$2,666.67) แทนหนึ่งเดือน (\$1,333.33)

ใช้ hazard คงที่ตัวเดียวกับ spread หลายอายุ: hazard 2.1667% ที่ fit CDS 2 ปีตั้งราคา CDS 1 ปีได้ 130 bp แทน 100 bp ต้องแกะเป็นขั้นบันได

ใช้ทำอะไรบนโต๊ะจริง

CDS เริ่มในปี 1994 เมื่อ J.P. Morgan ต้องเปิดวงเงิน \$4.8 พันล้านให้ Exxon ซึ่งอาจต้องจ่ายค่าเสียหายจากเรือ Exxon Valdez ธนาคารอยากรักษาลูกค้าแต่ไม่อยากแบกความเสี่ยงก้อนใหญ่ จึงซื้อความคุ้มครองจาก European Bank for Reconstruction and Development ทุกวันนี้ธนาคารยังใช้ CDS แบบนี้: ลดความเสี่ยงที่กระจุกกับลูกค้ารายใหญ่โดยไม่ต้องขายเงินกู้ และ hedge บริษัทที่ไม่มีหุ้นกู้ซื้อขาย โต๊ะเครดิตแกะ hazard เป็นขั้นบันไดจาก par spread หลายอายุ คิดราคากลับทุก quote แล้วรายงานความไวแยกตามอายุ

CDS ไม่ใช่ประกัน: ซื้อได้แม้ไม่ได้ถือหนี้ (naked CDS) เขียนได้ง่าย และซื้อขายนอกตลาด การใช้งานจึงกลายเป็นการเก็งกำไรอย่างรวดเร็ว: รับความเสี่ยงเครดิตโดยไม่ต้องลงเงินก้อน แสดงมุมมองว่าเครดิตจะแย่ลงง่ายกว่าการชอร์ตหุ้นกู้ และเล่นส่วนต่างกับพันธบัตร spread ของ CDS ขยับเร็วกว่าอันดับเครดิตมาก ตลาดจึงใช้มันวัดความเสี่ยงของบริษัทและประเทศ (CDS 5 ปีของ Ford, GM และ AIG พุ่งไปหลายพัน bp ในปี 2008 และของกรีซในปี 2012)

par spread ของ CDS ใกล้แต่ไม่เท่ากับ spread ของพันธบัตร ส่วนต่าง (CDS–bond basis) มาจากต้นทุนการกู้เงินมาซื้อพันธบัตร สภาพคล่อง และรายละเอียดของสัญญา ใครตัดสินว่าเกิด credit event และ recovery เท่าไร อยู่ในเอกสารมาตรฐานของ ISDA (ออกปี 1999 แก้ปี 2003 และ 2009) ปัจจุบันคณะกรรมการตัดสินว่าเกิดเหตุหรือไม่ และ recovery มาจากการประมูลพันธบัตรของผู้ออก

บทเรียนจากปี 2008: ไม่มีใครเห็นฐานะ CDS ทั้งหมด AIG ใช้อันดับเครดิตสูงของตัวเองขาย CDS ราว \$500 พันล้าน แล้วกลายเป็นผู้ขายความคุ้มครองที่จ่ายไม่ไหวพอดีตอนที่ต้องจ่าย (wrong-way risk) ตลาดมี notional รวมราว \$62 ล้านล้านปลายปี 2007 หลังวิกฤต CDS ดัชนีมาตรฐานต้องผ่านสำนักหักบัญชีกลาง และสัญญาที่ซื้อขายกันเองต้องวางหลักประกันมากขึ้น

เปิดดูโค้ด

โค้ดนี้สร้างตารางโอกาสรอด คิดขาเบี้ย (แยกเบี้ยตามกำหนดกับเบี้ยค้าง) ขาชดเชย par spread สูตรประมาณ มูลค่าสัญญา 125 bp credit01 jump-to-default เงินของเส้นทางเดียว CDS 2 ปีใน workbook และแกะ hazard สองปีจาก spread 100 และ 130 bp แล้วพิมพ์ตัวเลขหลักหนึ่งบรรทัด

const {exp} = Math;

// CDS on a regular grid: survival Q, discount D, premium leg with half-period accrued premium, protection paid at period end.
function cds({N, R, delta, D, Q, s}) {
  if (!(N > 0 && delta > 0)) throw new RangeError('notional and period length must be positive');
  if (!(R >= 0 && R < 1)) throw new RangeError('recovery must be in [0, 1)');
  if (Q.length !== D.length + 1 || Q[0] !== 1) throw new RangeError('survival must start at 1 and have one more entry than discount factors');
  if (Q.some((q, i) => i && q > Q[i - 1])) throw new RangeError('survival cannot increase');
  const dQ = D.map((_, i) => Q[i] - Q[i + 1]);
  const scheduled = D.reduce((a, d, i) => a + delta * d * Q[i + 1], 0);
  const accrued = D.reduce((a, d, i) => a + delta / 2 * d * dQ[i], 0);
  const annuity = scheduled + accrued, defaultSum = D.reduce((a, d, i) => a + d * dQ[i], 0);
  const defaultLeg = N * (1 - R) * defaultSum, par = (1 - R) * defaultSum / annuity;
  const out = {scheduled, accrued, annuity, defaultSum, defaultLeg, par};
  if (s !== undefined) { out.premiumLeg = N * s * annuity; out.buyerValue = defaultLeg - out.premiumLeg; }
  return out;
}
// Constant rate and hazard (continuous), n periods of length delta.
function flat(r, lambda, delta, n) {
  return {D: Array.from({length: n}, (_, i) => exp(-r * (i + 1) * delta)), Q: Array.from({length: n + 1}, (_, i) => exp(-lambda * i * delta))};
}
// Hazard constant within each year (lams[0], lams[1], ...), quarterly CDS, rate 4.5%, recovery 40%.
function piecewise(lams, years) {
  const Q = [1], D = [];
  for (let i = 1; i <= 4 * years; i++) { Q.push(Q[i - 1] * exp(-lams[Math.ceil(i / 4) - 1] * 0.25)); D.push(exp(-0.045 * 0.25 * i)); }
  return cds({N: 1, R: 0.4, delta: 0.25, D, Q});
}
function bisect(f, lo, hi) {
  for (let k = 0; k < 200; k++) { const m = (lo + hi) / 2; if (f(m) > 0) hi = m; else lo = m; }
  return (lo + hi) / 2;
}

const base = {N: 1e7, R: 0.4, delta: 0.25};
const five = cds({...base, ...flat(0.045, 0.02, 0.25, 20), s: 0.0125});
const bumped = cds({...base, ...flat(0.045, 0.0201, 0.25, 20), s: 0.0125});
const a = exp(-0.01625), G = a * (1 - a ** 20) / (1 - a);
const h = 1 - exp(-0.005);
// Expected (undiscounted) cash per quarter of the two legs at the par spread.
const quarters = Array.from({length: 20}, (_, i) => {
  const Q0 = exp(-0.005 * i), Q1 = exp(-0.005 * (i + 1));
  return {protection: 6e6 * (Q0 - Q1), premium: 1e7 * five.par * (0.25 * Q1 + 0.125 * (Q0 - Q1))};
});
// Course example: 2-year CDS, 160 bp, default in month 16, recovery 45%.
const path = {premium: 0.016 * 1e6 / 4, accrued: 0.016 * 1e6 / 12, protection: 0.55 * 1e6};
// Course workbook: half-year hazards from its Solver, divided by two per quarter; rate 1% compounded quarterly.
const hq = [...Array(4).fill(0.02014057304019802 / 2), ...Array(4).fill(0.019443103338662979 / 2)];
const Qx = [1]; hq.forEach(x => Qx.push(Qx[Qx.length - 1] * (1 - x)));
const Dx = Array.from({length: 8}, (_, k) => (1 + 0.01 / 4) ** -(k + 1));
const file = cds({N: 1e6, R: 0.45, delta: 0.25, D: Dx, Q: Qx});

// Bootstrap: 1-year CDS at 100 bp, then 2-year at 130 bp.
const lam1 = bisect(l => piecewise([l], 1).par - 0.0100, 0, 1);
const lam2 = bisect(l => piecewise([lam1, l], 2).par - 0.0130, 0, 1);

สิ่งที่ควรตอบได้หลังอ่าน

  • ผู้ซื้อจ่ายเบี้ยตราบที่ยังรอด (ถ่วงด้วย $Q_i$) และรับ $(1-R)N$ เมื่อผิดนัด (ถ่วงด้วย $\Delta Q_i$) บวกเบี้ยค้างของช่วง $\tau-t_{k-1}$ เมื่อผิดนัด
  • par spread คือขาชดเชยหารด้วย risky annuity: 119.99975 bp จาก \$509,378.76 และ $A=4.2448$ ปี เมื่อ hazard คงที่ เงินสองขาเท่ากันทุกไตรมาส par spread จึงเป็น $(1-R)h/[\delta(1-h/2)]\approx\lambda(1-R)$
  • สัญญาที่เบี้ยไม่เท่า par มีค่า $N(s^*-s)A$: เบี้ย 125 bp ติดลบ \$21,225.22 ไม่ใช่ \$25,000 และตลาดจ่ายส่วนนี้เป็น upfront
  • credit01 ของผู้ซื้อคือ +\$2,551.30 ต่อ hazard 1 bp แต่ jump-to-default ราว \$6.02 ล้าน ใหญ่กว่าหลายพันเท่า
  • spread หลายอายุแกะเป็น hazard ขั้นบันไดได้ทีละช่วง: 100 bp และ 130 bp ให้ 1.6667% และ 2.7012% และ CDS 2 ปีใน workbook มี par spread 218.8895 bp
