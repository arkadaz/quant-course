27.5 Winsorization: Which Outliers to Keep

ค่าประหลาดมีสองชนิดที่หน้าตาเหมือนกัน ราคาผิดต้องแก้ที่ต้นทาง ข่าวจริงต้องเก็บไว้ เพราะ factor return คือผลตอบแทนของพอร์ตที่ถือหุ้นตัวนั้นจริง winsorization เป็นแค่ตาข่ายชั้นสุดท้าย และต้องวัดความประหลาดด้วยตัวหารที่ค่าประหลาดดันไม่ขึ้น

จักรวาล 600 ตัวของบทนี้ (หุ้นแปดตัวในตัวอย่างของ cross-sectional regression ซ้ำ 75 ชุด) เปิดการ winsorize ไว้ที่คะแนนความประหลาด 10 วันนี้มีสองเรื่องที่หุ้นธนาคารตัวที่ 5 สองชุด: เรื่อง A หุ้นลง 18% เพราะกำไรต่ำกว่าคาด เรื่อง B ข้อมูลบอกว่าหุ้นขึ้น 340% เพราะผู้ให้ข้อมูลยังไม่ปรับการรวมหุ้นห้าหุ้นเป็นหนึ่ง ระบบจะทำอะไรกับสองค่านี้ และผลที่ได้ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ทั้งคู่เกินเกณฑ์ (คะแนน 14.71 และ 109.83) จึงถูกดึงลงมาที่เกณฑ์ทั้งคู่ และผิดทั้งคู่ เรื่อง B ราคาที่รายงาน 4.40 เท่าคือการรวมหุ้น (คูณ 5) กับการลงจริง 12% พร้อมกัน ผลตอบแทนจริง −12% ควรขยับ momentum −3.64 bp แต่ค่าดิบดันมัน +101.00 bp หลัง winsorize เหลือ +4.22 bp ยังผิด 7.86 bp และผิดทิศ ทางที่ถูกคือปรับการรวมหุ้น ได้ −12% ที่คะแนน 9.48 ระบบไม่แตะ เรื่อง A ถูกตัดเหลือ −12.62% momentum ขยับ −3.83 bp แทน −5.43 bp ที่พอร์ตเจ็บจริง ข้อมูลจริงหายไป 29.5% และรายงานบอกผลตอบแทนของพอร์ตที่ไม่มีใครถือ

ภาพรวมก่อนลงสูตร

สามหน้าที่ผ่านมาสมมติว่าผลตอบแทนที่ป้อนเข้า cross-sectional regression สะอาด แต่ข้อมูลจริงมีค่าประหลาดเสมอ และค่าประหลาดหนึ่งค่าทำลายงานวิจัยได้ทั้งชิ้น มันมาจากสองแหล่ง แหล่งแรกคือข้อมูลผิด: ผู้ให้ข้อมูลไม่ปรับการแตกหุ้นหรือรวมหุ้น ข้อมูลไม่ได้เก็บพร้อมกัน ราคาหลุดจากการซื้อขายไม่กี่หุ้น แหล่งที่สองคือค่าประหลาดของจริง: หุ้นสภาพคล่องต่ำ หุ้นที่กำลังถูกถอดจากตลาดหรือล้มละลาย และข่าวใหญ่จริง ๆ เช่นกำไรผิดคาด การควบรวม อุบัติเหตุ ระบบที่ตัดทุกค่าที่ใหญ่เหมือนกันหมดจะผิดทั้งสองทาง

winsorization คือการดึงค่าที่ประหลาดเกินเกณฑ์กลับมาที่เกณฑ์พอดี รูปด้านล่างคือทั้งเรื่องในภาพเดียว: วันปกติของหุ้นหนึ่งตัวกองอยู่ตรงกลาง เพดานสองข้างอยู่ที่คะแนน ±10 ค่าที่อยู่นอกเพดานถูกดึงกลับ ไม่ว่ามันจะเป็นข่าวจริงหรือข้อมูลผิด ส่วนค่าจริงที่ซ่อนอยู่ในข้อมูลผิดอยู่ในเพดานและรอดไปได้

หน้านี้จะคิดว่าค่าหนึ่งตัวขยับ factor return เท่าไรด้วยพอร์ตเลียนแบบ factor ตั้งคะแนนความประหลาดที่ทนทาน ดูว่าการดึงลงมาที่เกณฑ์ช่วยเรื่องหนึ่งและทำร้ายอีกเรื่องเท่าไร แก้ที่ต้นทาง ดูว่าทำไมตัวหารต้องเป็น median เลือกเกณฑ์จากข้อมูลที่สะอาด และจบที่เหตุผลว่าทำไมข่าวจริงห้ามแตะ

ศัพท์ที่ใช้ในหัวข้อนี้
Outlier
ค่าที่ห่างจากปกติมาก เป็นคำกลางที่ยังไม่ตัดสินว่าเป็นข้อผิดพลาดหรือของจริง
Winsorization
ดึงค่าที่เกินเกณฑ์ให้กลับมาอยู่ที่เกณฑ์พอดีแทนการลบทิ้ง จำนวนข้อมูลจึงไม่หาย แต่ขนาดของค่านั้นหาย ใช้เป็นตาข่ายกันข้อมูลผิดที่หลุดมาถึง regression
Robust score
ขนาดของ log return วันนี้หารด้วย median ของขนาด log return ในอดีต ใช้แทน z-score เพราะตัวหารไม่ถูกค่าประหลาดดึงขึ้น
Corporate action
สิ่งที่บริษัททำกับหุ้นของตัวเอง เช่นแตกหุ้น รวมหุ้น จ่ายปันผลพิเศษ ราคาต่อหุ้นกระโดดโดยมูลค่าไม่เปลี่ยน ถ้าผู้ให้ข้อมูลไม่ปรับ ผลตอบแทนจะผิด
Estimation universe
ชุดหุ้นที่ใช้ประมาณแบบจำลอง ด่านแรกที่กรองหุ้นเล็กซื้อขายน้อยและหุ้นที่กำลังถูกถอดออกจากตลาด ก่อนจะถึงขั้นจัดการค่าประหลาด
Audit trail
บันทึกว่าข้อมูลตัวไหนถูกแก้ วันไหน ค่าเดิมกับค่าใหม่คืออะไร เพราะอะไร ต้องมีทุกครั้งที่แตะข้อมูล
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$r_{i,t}$ผลตอบแทนของหุ้น $i$ ในวัน $t$ทศนิยม
$s_i,\ d_{i,t}$median ของ $\lvert\ln(1+r)\rvert$ ในอดีต และคะแนนความประหลาดทศนิยม, ไม่มีหน่วย
$d_{\max}$เกณฑ์ที่เกินแล้วถูกดึงลงไม่มีหน่วย
$H_{ki}$น้ำหนักของหุ้น $i$ ในพอร์ตเลียนแบบ factor $k$ไม่มีหน่วย
$\Delta\hat f_k$การขยับของ factor return ที่ประมาณได้bp (0.01%)
$\mathrm{rms}_k$รากของค่าเฉลี่ยกำลังสองของหน้าต่าง เมื่อมีค่าประหลาดเก่า $k$ ตัวทศนิยม

ขั้นที่ 1 — ค่าหนึ่งตัวขยับ factor return เท่าไร

ก่อนตัดสินใจว่าจะทำอะไรกับค่าประหลาด ต้องรู้ว่ามันทำอะไรกับ factor return ในตัวอย่างหุ้นแปดตัว factor return คือ $\hat{\mathbf f}=\mathbf H\mathbf r$ ซึ่งเป็นเชิงเส้น เปลี่ยนผลตอบแทนหุ้นตัวเดียวจึงขยับ factor แต่ละตัวเท่ากับน้ำหนักของหุ้นนั้นในพอร์ตเลียนแบบ factor คูณขนาดที่เปลี่ยน ในวันปกติหุ้นตัวที่ 5 ทุกชุดได้ 0.25% และ factor return คือค่าของเงื่อนไขถ่วงมูลค่าตลาดเป๊ะ (momentum 0.4741%) เพราะข้อมูลที่ซ้ำ 75 ชุดให้คำตอบเดิม

\[ \begin{aligned} \Delta\hat f_k&=H_{ki}\,\Delta r_i,\\ H_{{\rm mom},5}&=\tfrac{0.22295}{75}=0.002973,\\ \text{A}&:\ \Delta r=-0.18-0.0025=-0.1825,\\ &\quad\Delta\hat f_{\rm mom}=-5.43\ \text{bp},\\ \text{B}&:\ \Delta r=3.40-0.0025=3.3975,\\ &\quad\Delta\hat f_{\rm mom}=+101.00\ \text{bp},\\ \text{B}^{*}&:\ \Delta r=-0.12-0.0025=-0.1225,\\ &\quad\Delta\hat f_{\rm mom}=-3.64\ \text{bp}. \end{aligned} \]

0.22295 คือน้ำหนักของหุ้นตัวที่ 5 ในพอร์ต momentum เมื่อหุ้นแบบนี้มี 75 ตัว แต่ละตัวถือหนึ่งใน 75 ของน้ำหนักนั้น เรื่อง A ขยับ momentum −5.43 bp และขยับ banks −11.69 bp (น้ำหนัก $0.4806/75$) ซึ่งเป็นการขยับที่ควรเกิด พอร์ตที่ถือหุ้นนั้นเจ็บจริง

B คือค่าดิบที่ผิด ส่วน B* คือผลตอบแทนจริงของเรื่องเดียวกัน หุ้นหนึ่งตัวจาก 600 ที่รายงานผิดดัน momentum จาก 0.4741% เป็น 1.4841% และ banks ขึ้น 217.70 bp ขณะที่ค่าที่ถูก (−12% ซึ่งจะหาได้ในขั้นที่ว่าด้วยการแก้ที่ต้นทาง) ควรขยับ momentum แค่ −3.64 bp ค่าผิดจึงทำให้ momentum คลาด $101.00-(-3.64)=104.64$ bp ในวันเดียว อัตราส่วนระหว่างค่าดิบของสองเรื่องคือ $3.3975/0.1825=18.62$ พอดี เพราะทุกอย่างเป็นเชิงเส้นในผลตอบแทนดิบ และน้ำหนักใน regression มาจากความผันผวนของเมื่อวาน ไม่ได้ขยับตามค่าประหลาดของวันนี้

ขั้นที่ 2 — คะแนนความประหลาดที่ทนทาน

ต้องมีตัวเลขที่บอกว่าค่าไหนประหลาดสำหรับหุ้นตัวนั้น นี่คือนิยามของคะแนน: ขนาดของ log return วันนี้หารด้วย median ของขนาด log return ในอดีต $T$ วัน (ไม่รวมวันนี้) สมมติว่าวันปกติของหุ้นตัวที่ 5 เป็น Normal ที่ความผันผวน 2.0% ต่อวัน median ของขนาดคือ 0.6745 เท่าของความผันผวน เพราะ $P(\lvert Z\rvert\le0.6745)=0.5$

\[ \begin{aligned} s_i&=\operatorname{median}_{s=1..T}\lvert\ln(1+r_{i,t-s})\rvert,\\ d_{i,t}&=\lvert\ln(1+r_{i,t})\rvert/s_i,\\ s_5&=0.6745\times2.0\%=1.349\%,\\ \text{A}&:\ \tfrac{\lvert\ln0.82\rvert}{0.01349}=\tfrac{0.19845}{0.01349}=14.71,\\ \text{B}&:\ \tfrac{\ln4.40}{0.01349}=\tfrac{1.48160}{0.01349}=109.83. \end{aligned} \]

ใช้ log เพราะความสมมาตร ผลตอบแทน −50% กับ +100% คือการเคลื่อนไหวขนาดเท่ากันคนละทิศ ใน log ทั้งคู่มีขนาด 0.6931 แต่ในผลตอบแทนดิบตัวหนึ่งเป็นสองเท่าของอีกตัว

ใช้ median ของอดีตเพราะค่าประหลาดเก่าดันมันไม่ขึ้น (ขั้นที่เทียบตัวหารสองแบบจะวัดให้ดู) และไม่รวมวันนี้ เพราะตัวหารที่รวมวันนี้จะโตตามค่าประหลาดของวันนี้เอง

ค่าปกติ 0.25% ได้คะแนน 0.19 ข่าวจริงได้ 14.71 ราคาผิดได้ 109.83 สองเรื่องต่างกันเกือบ 7.5 เท่า แต่เกณฑ์ที่ใช้กันในทางปฏิบัติ ซึ่งเลือกด้วยการลองผิดลองถูกในช่วง 5 ถึง 10 ตามตลาดและประเภทสินทรัพย์ ต่ำกว่าทั้งคู่

ขั้นที่ 3 — ดึงลงมาที่เกณฑ์: ช่วยเรื่องหนึ่ง ทำร้ายอีกเรื่อง

winsorize คือแทนค่าที่คะแนนเกิน $d_{\max}$ ด้วยผลตอบแทนที่คะแนนเท่ากับ $d_{\max}$ พอดี กลับ log แล้วได้เพดานสองข้าง จากนั้นใช้สูตรการขยับของ factor กับค่าที่ถูกดึงลง แล้วเทียบกับสิ่งที่ควรเกิดจริง (A: −5.43 bp, B: −3.64 bp)

\[ \begin{aligned} r^{+}&=e^{10(0.01349)}-1=14.44\%,\\ r^{-}&=e^{-10(0.01349)}-1=-12.62\%,\\ \text{B}&:\ +101.00\to+4.22\ \text{bp},\\ &\quad 4.22-(-3.64)=7.86\ \text{bp},\\ &\quad 1-\tfrac{7.86}{104.64}=92.5\%,\\ \text{A}&:\ -5.43\to-3.83\ \text{bp},\\ &\quad \tfrac{3.83}{5.43}=70.5\%. \end{aligned} \]

เกณฑ์ 10 ลบความคลาดของราคาผิดไป 92.5% (จาก 104.64 bp เหลือ 7.86 bp) แต่ momentum ยังขยับผิดทิศ (+4.22 แทน −3.64) และทิ้งข้อมูลจริงของข่าวไป 29.5% (เก็บไว้ 70.5%) เพราะมันไม่รู้ว่าค่าไหนจริงค่าไหนผิด มันรู้แค่ว่าค่าไหนใหญ่

ลดเกณฑ์เป็น 5 เพดานเป็น +6.98% กับ −6.52% ราคาผิดเหลือ +2.00 bp ซึ่งยังคลาด 5.64 bp (ลบไป 94.6%) แต่ข่าวจริงเหลือแค่ 37.1% เพราะเพดานบวกไม่มีทางต่ำกว่าศูนย์ ความคลาดของราคาผิดจึงไม่ลงต่ำกว่า 3.64 bp ไม่ว่าเกณฑ์เท่าไร ส่วนเกณฑ์ที่ข่าวจริงรอดไม่ถูกแตะต้องสูงกว่า 14.71 และถ้าเกณฑ์สูงกว่า 109.83 ราคาผิดรอดทั้งก้อน ไม่มีเกณฑ์ไหนถูกกับทั้งสองเรื่อง

ขั้นที่ 4 — แก้ที่ต้นทาง: ปรับการรวมหุ้นแล้วใช้ค่าจริง

โจทย์ให้อะไรมาบ้าง: เรื่อง B บริษัทรวมหุ้นห้าหุ้นเป็นหนึ่งหุ้น (reverse split 1 ต่อ 5) ราคาต่อหุ้นจึงควรคูณ 5 โดยมูลค่าไม่เปลี่ยน ผู้ให้ข้อมูลรายงานราคาปิดวันนี้เป็น 4.40 เท่าของเมื่อวานโดยไม่ปรับ ถ้าปรับให้ถูก ผลตอบแทนจริงคือเท่าไร และระบบจะทำอะไรกับมัน

\[ \begin{aligned} r&=4.40/5-1=-12.00\%,\\ d&=\tfrac{\lvert\ln0.88\rvert}{0.01349}=\tfrac{0.12783}{0.01349}=9.48,\\ \Delta r&=-0.12-0.0025=-0.1225,\\ \Delta\hat f&=0.002973(-0.1225)\\ &=-3.64\ \text{bp}. \end{aligned} \]

คำตอบ: ราคาผิดซ่อนข่าวจริงอยู่ข้างใน หุ้นลงจริง 12% ในวันเดียวกับที่รวมหุ้น คะแนน 9.48 ต่ำกว่าเกณฑ์ 10 ระบบจึงไม่แตะ และ momentum ขยับ −3.64 bp ตามที่พอร์ตเจ็บจริง ถ้าปล่อยให้ winsorization จัดการ ได้ +4.22 bp ซึ่งผิดทั้งขนาดและทิศ

ตรวจเองใน 10 วินาที: $5\times0.88=4.40$ ราคาที่รายงานคือผลของการรวมหุ้น (คูณ 5) กับการลง 12% พร้อมกัน

ค่าประหลาดส่วนใหญ่แก้ได้ที่ต้นทางแบบนี้ ราคาที่ยังไม่ปรับ corporate action แก้ด้วยการปรับ ราคาหลุดจากการซื้อขายไม่กี่หุ้นในหุ้นสภาพคล่องดี แก้ด้วยการดูราคาทั้งช่วงแทนราคาสุดท้ายของช่วง ตัวอย่างที่เกิดจริง: ฤดูร้อนปี 2000 หุ้น Enron ซื้อขายแถว \$86 ทั้งวัน แล้วราคาปิดจาก closing auction กระโดดเป็น \$90 วันรุ่งขึ้นก็กลับไปกลาง \$80 ราคาปิดแบบนี้เทรดตามไม่ได้จริง ส่วนหุ้นเล็กที่ซื้อขายน้อย หุ้นที่กำลังถูกถอดหรือล้มละลาย แก้ด้วยการไม่เอาเข้า estimation universe ตั้งแต่แรก เหลือแหล่งเดียวที่แก้ไม่ได้และไม่ควรแก้ คือข่าวจริงที่ใหญ่

ขั้นที่ 5 — ทำไมตัวหารต้องเป็น median ไม่ใช่ความผันผวน

ทางลัดที่ใช้บ่อยคือ z-score: หารด้วยความผันผวนของอดีต ลองกับหน้าต่าง 251 วันของหุ้นตัวที่ 5 ที่วันปกติผันผวน 2.0% แต่มีค่าประหลาดเก่าขนาด +50% ติดอยู่ $k$ วัน แล้วให้คะแนนค่าประหลาด +50% ตัวใหม่ของวันนี้ ($\ln1.5=0.4055$) ความผันผวนของหน้าต่างวัดรอบศูนย์แบบที่ risk model ใช้ (root mean square)

\[ \begin{aligned} \mathrm{rms}_k^2&=\tfrac{(251-k)(0.02)^2+k(0.4055)^2}{251},\\ z_k&=0.4055/\mathrm{rms}_k,\\ z_0,z_1&=20.27,\ 12.49,\\ z_2,z_3&=9.81,\ 8.35,\\ d_0,d_2&=30.06,\ 29.78. \end{aligned} \]

ค่าประหลาดเก่าหนึ่งตัวดันความผันผวนของหน้าต่างจาก 2.0% เป็น 3.25% สองตัวเป็น 4.13% แล้วค่าประหลาดใหม่ถูกหารด้วยตัวเลขที่พวกพ้องของมันดันขึ้นมา พอมีสองตัวในหน้าต่าง คะแนนตกเหลือ 9.81 ต่ำกว่าเกณฑ์ 10 และหลบรอดไปได้ ยิ่งหุ้นมีปัญหาข้อมูลบ่อย มันยิ่งมองไม่เห็นปัญหา

median ขยับแค่หนึ่งตำแหน่งต่อค่าประหลาดหนึ่งตัว ค่าประหลาดสองตัวใน 251 ค่าทำให้ median กลายเป็นค่าลำดับที่ 126 ของ 249 ค่าปกติแทน 251 ค่า สำหรับ Normal คือ 1.349% เป็น 1.362% คะแนนจึงเกือบเท่าเดิม 30.06 เป็น 29.78 นี่คือความหมายของคำว่าทนทาน: median ทนข้อมูลผิดได้เกือบครึ่งหน้าต่าง ส่วนความผันผวนทนไม่ได้แม้ค่าเดียว

ขั้นที่ 6 — เกณฑ์ควรอยู่ที่เท่าไร: ถามข้อมูลที่สะอาด

โจทย์ให้อะไรมาบ้าง: ถ้าข้อมูลสะอาดทั้งหมด เกณฑ์ $c$ จะแก้ข้อมูลดีไปกี่จุดต่อปีในจักรวาล 600 ตัว ปีละ 251 วัน (150,600 จุด) สองแบบ: ผลตอบแทนเป็น Normal และผลตอบแทนหางหนาแบบ Student t ที่ 4 degrees of freedom (สมมติ ตาม stylized facts ที่บอกว่าผลตอบแทนจริงหางหนากว่า Normal) ทั้งสองแบบปรับสเกลให้ median ของขนาดเท่ากัน median ของ $\lvert T_4\rvert$ คือ 0.7407

ตรวจเองใน 10 วินาที: ที่ $c=3$ แบบ Normal $0.6745\times3=2.02$ และโอกาสที่ Normal เกิน 2.02 ทั้งสองข้างราว 4.3% ตามตาราง Normal ที่คุ้นเคย $0.0430\times150{,}600=6{,}480$

ขั้นที่ 7 — ตัดข่าวจริงทิ้ง คือรายงานผลตอบแทนของพอร์ตที่ไม่มีอยู่จริง

ทำไมข่าวจริงห้ามแตะ แม้จะดูเหมือนแค่ปรับเล็กน้อย? factor return คือผลตอบแทนของ factor-mimicking portfolio ที่ซื้อได้จริง เทียบสิ่งที่พอร์ต momentum ได้จริงวันนั้นกับสิ่งที่รายงานหลัง winsorize เรื่อง A ที่เกณฑ์ 10

\[ \begin{aligned} f_{\rm port}&=0.47415-0.05425\\ &=0.41990\%,\\ f_{\rm rep}&=0.47415-0.03826\\ &=0.43589\%,\\ f_{\rm rep}-f_{\rm port}&=0.01599\%. \end{aligned} \]

$f_{\rm port}$ คือผลตอบแทนของพอร์ต momentum ที่ถือหุ้นตัวนั้นด้วยน้ำหนัก 0.002973 จริง ๆ และเจ็บเต็ม 18% ส่วน $f_{\rm rep}$ คือตัวเลขที่ระบบรายงานหลังดึง −18% ขึ้นมาเป็น −12.62% ซึ่งไม่มีพอร์ตไหนในโลกได้ regression บนข้อมูลที่ winsorize แล้วคือผลตอบแทนของพอร์ตบนข้อมูลที่ไม่เคยเกิด

ส่วนต่าง 1.6 bp ในวันเดียวดูเล็ก แต่มันเป็นระบบ: ทุกครั้งที่ตัด ข่าวจริงถูกทำให้เล็กลง factor ที่ถือหุ้นนั้นด้าน long ดูดีกว่าความจริงในวันข่าวร้าย และดูแย่กว่าความจริงในวันข่าวดี ผลรวมคือ factor return ที่รายงานเรียบกว่าความจริง ความผันผวนและหางของ factor ถูกรายงานต่ำไป idiosyncratic return ก็ผิดตาม และ การแยก PnL ไม่ตรงกับเงินในพอร์ต winsorization จึงเป็นตาข่ายสำหรับข้อมูลผิดที่หลุดมาเท่านั้น: ราคาผิดหนึ่งตัวดัน momentum คลาดได้ 104.64 bp ในวันเดียว ตาข่ายทำให้เหลือ 7.86 bp ระหว่างรอคนมาแก้ ถ้างานต้นทางดี ตาข่ายนี้แทบไม่ทำงาน ซึ่งเป็นสัญญาณว่าระบบสุขภาพดี

ความผิดที่ให้ตัวเลขผิดแบบเงียบ ๆ

แก้ข้อมูลโดยไม่บันทึกและไม่มีใครอ่าน: ที่เกณฑ์ 10 กับข้อมูลหางหนา ระบบแก้ข้อมูลที่ไม่ผิดราว 267 จุดต่อปี ปนกับราคาผิดจริง ถ้าไม่มีรายการให้คนอ่านทีละบรรทัด จะไม่มีทางรู้ว่าตัดข่าวจริงทิ้งไปเท่าไร

ใช้ความผันผวนเป็นตัวหาร: ค่าประหลาดเก่าสองตัวในหน้าต่างพอให้ค่าประหลาดใหม่ได้คะแนน 9.81 และหลบเกณฑ์ 10 หุ้นที่ข้อมูลแย่ที่สุดจึงถูกตรวจน้อยที่สุด

ลบค่าประหลาดทิ้งแทนการดึงลง: regression ต้องมีค่าให้ทุกหุ้นที่อยู่ในจักรวาลวันนั้น การลบจึงเปลี่ยนพอร์ตของ factor ในวันนั้นแทน ปัญหาเดียวกับการตัดข่าวจริง: ตัวเลขที่รายงานไม่ใช่ผลตอบแทนของพอร์ตที่ถืออยู่

ใช้เกณฑ์เดียวกับทุกตลาด: ตารางสัดส่วนข้อมูลสะอาดที่ถูกแก้ขึ้นกับความหนาของหาง ตลาดที่หางหนากว่าจะถูกแก้ข้อมูลจริงมากกว่ามากที่เกณฑ์เดียวกัน ต้องคิดตารางนั้นกับข้อมูลของแต่ละตลาดใหม่

ใช้ทำอะไรบนโต๊ะจริง

winsorization เป็นขั้นที่สามของสายงานแบบจำลอง ต่อจากรับข้อมูลและเลือก estimation universe และมาก่อนสร้าง loading กับ cross-sectional regression กฎสองข้อที่ทีม risk model ใช้: ข้อแรก รายงานทุกค่าที่ถูก winsorize ทั้งใน backtest และระบบจริง พร้อมชื่อหุ้น วันที่ ค่าเดิม ค่าใหม่ และคะแนน แล้วมีคนอ่านทีละบรรทัด ข้อสอง estimation universe มีแต่หุ้นที่สภาพคล่องพอและซื้อขายได้จริง ส่วนเกณฑ์เลือกจากตารางสัดส่วนข้อมูลสะอาดที่ถูกแก้ของข้อมูลตัวเอง ในช่วง 5 ถึง 10 ไม่ใช่ลอกตัวเลขมา

โจทย์ตรวจความเข้าใจ

1. หุ้นที่ median ของขนาด log return คือ 1.0% ลง 25% ในวันเดียว คะแนนเท่าไร และถ้า $d_{\max}=10$ ค่าที่ถูกดึงลงคือเท่าไร?

เฉลย

$\lvert\ln0.75\rvert=0.2877$ คะแนน $0.2877/0.01=28.77$ เกินเกณฑ์ ค่าที่ถูกดึงลงคือ $e^{-10(0.01)}-1=e^{-0.1}-1=-9.52\%$ ถ้าเป็นข่าวจริง ผลตอบแทนหายไปกว่าครึ่ง ($9.52/25=38\%$ ที่เหลือ)

2. ในจักรวาล 600 ตัวของหน้านี้ ถ้าหุ้นตัวที่ 1 ชุดหนึ่ง (น้ำหนักใน momentum 0.20034 ต่อแปดตัว ปกติได้ 1.20%) ถูกรายงานผิดเป็น +100% momentum ขยับเท่าไร?

เฉลย

น้ำหนักต่อชุด $0.20034/75=0.002671$ การเปลี่ยน $1.00-0.012=0.988$ momentum ขยับ $0.002671\times0.988=0.002639$ หรือ +26.39 bp จากค่าผิดตัวเดียว

3. ถ้าผลตอบแทนหางหนาแบบ $t_4$ เกณฑ์ 8 แก้ข้อมูลดีไปกี่จุดต่อวันในจักรวาล 600 ตัว?

เฉลย

$0.406\%\times150{,}600=612$ จุดต่อปี หารด้วย 251 วันได้ราว 2.44 จุดต่อวัน อ่านได้ทุกเช้า ถ้าเกณฑ์ 3 จะเป็น 13,615 จุดต่อปี หรือ 54 จุดต่อวัน ซึ่งไม่มีใครอ่านไหว

const {sqrt, abs, exp, log, PI} = Math;
const T = A => A[0].map((_, j) => A.map(row => row[j]));
const mul = (A, B) => A.map(row => B[0].map((_, j) => row.reduce((s, a, k) => s + a * B[k][j], 0)));
function inverse(A) {                                   // Gauss-Jordan with partial pivoting
  const n = A.length, M = A.map((row, i) => [...row, ...row.map((_, j) => (i === j ? 1 : 0))]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let i = c + 1; i < n; i++) if (abs(M[i][c]) > abs(M[p][c])) p = i;
    [M[c], M[p]] = [M[p], M[c]];
    const v = M[c][c];
    for (let j = 0; j < 2 * n; j++) M[c][j] /= v;
    for (let i = 0; i < n; i++) if (i !== c) { const g = M[i][c]; for (let j = 0; j < 2 * n; j++) M[i][j] -= g * M[c][j]; }
  }
  return M.map(row => row.slice(n));
}
// The eight-stock model, cap-weighted industry constraint: factor returns f = H r
const industry = [0, 0, 0, 1, 1, 2, 2, 2], momentum = [1.2, -0.4, 0.6, -1.4, 0.9, -0.7, 0.3, -0.5];
const B = industry.map((g, i) => [1, +(g === 0), +(g === 1), +(g === 2), momentum[i]]);
const sigma = [1.8, 2.2, 1.5, 2.6, 2.0, 2.4, 1.7, 2.1], cap = [300, 180, 220, 400, 150, 260, 340, 190];
const c = [0, ...[0, 1, 2].map(g => cap.filter((_, i) => industry[i] === g).reduce((a, b) => a + b, 0) / 2040), 0];
const BW = T(B).map(row => row.map((x, i) => x / (sigma[i] * sigma[i])));
const K = mul(BW, B).map((row, i) => [...row, c[i]]);
K.push([...c, 0]);
const H = mul(inverse(K).slice(0, 5).map(row => row.slice(0, 5)), BW);
const r = [1.20, 0.35, 0.90, -0.60, 0.25, -1.10, -0.40, -0.95].map(x => x / 100);
const fClean = H.map(row => row.reduce((s, h, i) => s + h * r[i], 0));
const copies = 75, stock = 4;                           // 600 stocks = 75 copies; stock 5 is a bank
// One copy of stock i moves from its clean return to newReturn: factor moves, in basis points
const move = (i, newReturn) => H.map(row => row[i] / copies * (newReturn - r[i]) * 1e4);
const mom = ret => move(stock, ret)[4];
// Robust score and winsorisation
const s5 = 0.6744897501960817 * 0.02;                   // median |log return| of a Normal day with vol 2%
const score = (ret, s) => abs(log(1 + ret)) / s;
const winsorise = (ret, dmax, s) => (score(ret, s) <= dmax ? ret : ret > 0 ? exp(dmax * s) - 1 : exp(-dmax * s) - 1);
const real = mom(-0.18), bad = mom(3.40), truthB = mom(4.40 / 5 - 1);
const atThreshold = d => {
  const b = mom(winsorise(3.40, d, s5)), a = mom(winsorise(-0.18, d, s5));
  return {d, badMove: b, badError: b - truthB, removed: 1 - (b - truthB) / (bad - truthB), realMove: a, kept: a / real};
};
// Volatility versus median as the denominator: a 251-day window holding k old +50% days
function normalCdf(x) {                                 // series below 1, continued fraction above
  if (x < 0) return 1 - normalCdf(-x);
  if (x < 1) { let term = x, sum = x; for (let k = 1; k < 60; k++) { term *= x * x / (2 * k + 1); sum += term; } return 0.5 + exp(-x * x / 2) / sqrt(2 * PI) * sum; }
  let f = x; for (let k = 60; k >= 1; k--) f = x + k / f;
  return 1 - exp(-x * x / 2) / sqrt(2 * PI) / f;
}
function quantile(p) { let lo = -10, hi = 10; for (let i = 0; i < 200; i++) { const m = (lo + hi) / 2; if (normalCdf(m) < p) lo = m; else hi = m; } return (lo + hi) / 2; }
const L50 = log(1.5);
const windowScores = k => {
  const rms = sqrt(((251 - k) * 0.02 ** 2 + k * L50 * L50) / 251);
  const median = quantile(0.5 + 0.5 * 125.5 / (251 - k)) * 0.02;   // the 126th value is still a clean one
  return {k, rms, z: L50 / rms, d: L50 / median};
};
// Share of clean points flagged at threshold c: Normal, and Student t with 4 degrees of freedom
const tTail4 = t => 1 - t * (t * t + 6) / (t * t + 4) ** 1.5;
let lo = 0, hi = 5;
for (let i = 0; i < 200; i++) { const m = (lo + hi) / 2; if (tTail4(m) > 0.5) lo = m; else hi = m; }
const m4 = (lo + hi) / 2, points = 600 * 251;
const flagged = cc => ({c: cc, normal: 2 * (1 - normalCdf(0.6744897501960817 * cc)) * points, t4: tTail4(m4 * cc) * points});

สิ่งที่ควรตอบได้หลังอ่าน

  • ค่าหนึ่งตัวขยับ factor ตามน้ำหนักของมันในพอร์ตเลียนแบบ factor: ราคาผิด +340% ดัน momentum +101.00 bp ทั้งที่ค่าจริง (−12%) ควรขยับ −3.64 bp ข่าวจริง −18% ขยับ −5.43 bp
  • คะแนนที่ทนทานคือ $\lvert\ln(1+r)\rvert$ หารด้วย median ของอดีต ข่าวจริงได้ 14.71 ราคาผิดได้ 109.83 ถ้าใช้ความผันผวนเป็นตัวหาร ค่าประหลาดเก่าสองตัวพอให้ตัวใหม่หลบเกณฑ์ 10 (9.81)
  • winsorize ที่ 10 ลดความคลาดของราคาผิดจาก 104.64 bp เหลือ 7.86 bp แต่ยังผิดทิศ และทิ้งข่าวจริง 29.5% ไม่มีเกณฑ์ไหนถูกกับทั้งสองเรื่อง
  • ทางแก้จริงอยู่ที่ต้นทาง: ปรับการรวมหุ้นแล้วได้ −12% ที่คะแนน 9.48 ไม่ถูกแตะ คัด estimation universe ให้มีแต่หุ้นที่ซื้อขายได้จริง และข่าวจริงต้องเก็บไว้ทั้งก้อน
  • เลือกเกณฑ์จากข้อมูลสะอาดของตัวเอง หางหนาแบบ $t_4$ ยังถูกแตะ 267 จุดต่อปีที่เกณฑ์ 10 จึงต้องบันทึกและอ่านทุกค่าที่ถูกแก้
