27.5 Winsorization: Which Outliers to Keep

ค่าประหลาดในข้อมูลมีสองชนิดที่หน้าตาเหมือนกัน ราคาผิดต้องแก้ที่ต้นทาง ข่าวจริงต้องเก็บไว้ทั้งก้อน เพราะ factor return คือผลตอบแทนของพอร์ตที่ถือหุ้นตัวนั้นจริง winsorization เป็นแค่ตาข่ายชั้นสุดท้าย และคะแนนความประหลาดต้องหารด้วย median ซึ่งค่าประหลาดดันไม่ขึ้น

ทีม risk model (ทีมที่สร้างแบบจำลองความเสี่ยงของพอร์ต) คำนวณ factor return ทุกเย็น factor return คือผลตอบแทนประจำวันของ “ปัจจัย” ที่ขับหุ้นหลายตัวพร้อมกัน เช่น momentum (หุ้นที่ราคาวิ่งดีมาก่อน) หรือกลุ่มธนาคาร ทีมได้ตัวเลขนี้จาก cross-sectional regression ซึ่งรับผลตอบแทนของหุ้นทุกตัวในวันนั้นเป็นข้อมูล

ผลตอบแทนที่ผู้ให้ข้อมูลส่งมามีค่าผิดปนมาเป็นครั้งคราว ทีมจึงตั้งตาข่ายอัตโนมัติไว้ ระบบให้ “คะแนนความประหลาด” กับผลตอบแทนทุกค่า คะแนนนี้บอกว่าวันนี้หุ้นขยับแรงกว่าวันธรรมดาของมันกี่เท่า ถ้าคะแนนเกินเกณฑ์ ระบบดึงค่านั้นกลับมาที่เกณฑ์พอดี วิธีนี้เรียกว่า winsorization

ของที่รู้:

  • จักรวาลหุ้น (ชุดหุ้นที่แบบจำลองใช้) มี 600 ตัว สร้างจากหุ้น 8 ตัวในตัวอย่างของหน้า cross-sectional regression โดยลอกซ้ำ 75 ชุด $8\times75=600$
  • เกณฑ์ของระบบคือคะแนน $d_{\max}=10$
  • หุ้นตัวที่ 5 เป็นหุ้นธนาคาร วันธรรมดาของมันได้ผลตอบแทน 0.25%

วันนี้หุ้นตัวที่ 5 สองชุด (สองในบรรดา 75 ชุด) มีค่าแปลก

  • เรื่อง A: หุ้นลงจริง 18% เพราะบริษัทประกาศกำไรต่ำกว่าที่ตลาดคาด
  • เรื่อง B: ข้อมูลบอกว่าหุ้นขึ้น 340% ที่จริงบริษัทรวมหุ้นห้าหุ้นเป็นหนึ่งหุ้น ราคาต่อหุ้นจึงกระโดดขึ้น แต่ผู้ให้ข้อมูลไม่ได้ปรับตัวเลขให้

ระบบจะทำอะไรกับสองค่านี้ และผลที่ได้ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ระบบดึงทั้งสองค่าลงมาที่เกณฑ์ และผิดทั้งคู่ ตัวเลขทุกตัวในเฉลยนี้ หน้านี้จะคำนวณให้ดูทีละขั้น

สองค่าได้คะแนน 14.71 และ 109.83 เกินเกณฑ์ 10 ทั้งคู่

เรื่อง B: ราคาที่รายงานคือ 4.40 เท่าของเมื่อวาน เพราะ $1+3.40=4.40$ ตัวเลขนี้คือการรวมหุ้น (ราคาคูณ 5) กับการลงจริง 12% ที่เกิดพร้อมกัน ตรวจได้จาก $5\times0.88=4.40$ ผลตอบแทนจริง −12% ควรขยับ momentum −3.64 bp (bp หรือ basis point คือหนึ่งในร้อยของ 1%) แต่ค่าดิบ +340% ดันมัน +101.00 bp หลัง winsorize เหลือ +4.22 bp ซึ่งยังห่างจากค่าที่ควรเป็น $4.22-(-3.64)=7.86$ bp และผิดทิศด้วย ทางที่ถูกคือปรับการรวมหุ้นก่อน จะได้ −12% ที่คะแนน 9.48 ซึ่งต่ำกว่าเกณฑ์ ระบบจึงไม่แตะ

เรื่อง A: ระบบตัด −18% เหลือ −12.62% momentum จึงขยับแค่ −3.83 bp แทนที่จะเป็น −5.43 bp ตามที่พอร์ตเจ็บจริง ข้อมูลจริงหายไป $1-3.83/5.43=29.5\%$ และตัวเลขที่รายงานกลายเป็นผลตอบแทนของพอร์ตที่ไม่มีใครถือ

ภาพรวมก่อนลงสูตร

สามหน้าที่ผ่านมาสมมติว่าผลตอบแทนที่ป้อนเข้า cross-sectional regression สะอาดทุกค่า ข้อมูลจริงไม่เป็นแบบนั้น มันมีค่าประหลาด (outlier คือค่าที่ห่างจากปกติมาก) ปนมาเสมอ และ regression ไวต่อค่าเหล่านี้มาก ค่าผิดค่าเดียวพลิกตัวเลขของทั้งวันได้

ค่าประหลาดมาจากสองแหล่งที่หน้าตาเหมือนกัน

  • ข้อมูลผิด: ผู้ให้ข้อมูลไม่ปรับราคาเมื่อบริษัทแตกหุ้น (แบ่งหนึ่งหุ้นเป็นหลายหุ้น) หรือรวมหุ้น (รวมหลายหุ้นเป็นหนึ่งหุ้น) ข้อมูลของหุ้นแต่ละตัวเก็บมาไม่พร้อมกัน หรือราคาปิดหลุดไปเพราะมีคนซื้อขายแค่ไม่กี่หุ้น
  • ค่าประหลาดของจริง: หุ้นที่ซื้อขายน้อย หุ้นที่กำลังถูกถอดจากตลาดหรือกำลังล้มละลาย และข่าวใหญ่จริง เช่น กำไรผิดคาด การควบรวมกิจการ อุบัติเหตุ

ระบบที่ตัดทุกค่าที่ใหญ่เหมือนกันหมดจึงผิดทั้งสองทาง มันตัดข่าวจริงที่ควรเก็บ และแก้ราคาผิดได้ไม่หมด

winsorization คือการดึงค่าที่ประหลาดเกินเกณฑ์กลับมาที่เกณฑ์พอดี รูปข้างล่างเล่าทั้งเรื่องในภาพเดียว วันธรรมดาของหุ้นตัวที่ 5 กองอยู่ตรงกลาง เพดานสองข้างอยู่ที่คะแนน −10 และ +10 ค่าที่อยู่นอกเพดานถูกดึงกลับ ไม่ว่ามันจะเป็นข่าวจริงหรือข้อมูลผิด ส่วนผลตอบแทนจริงที่ซ่อนอยู่ในข้อมูลผิดอยู่ในเพดาน จึงรอดไปได้

หน้านี้เดินเจ็ดขั้น ขั้นแรกวัดว่าค่าหนึ่งตัวขยับ factor return เท่าไร ขั้นต่อมาสร้างคะแนนความประหลาดที่ทนทาน แล้วดูว่าการดึงลงมาที่เกณฑ์ช่วยเรื่องหนึ่งและทำร้ายอีกเรื่องเท่าไร จากนั้นแก้ข้อมูลที่ต้นทาง ดูว่าทำไมตัวหารของคะแนนต้องเป็น median เลือกเกณฑ์จากข้อมูลที่สะอาด และจบที่เหตุผลว่าทำไมข่าวจริงห้ามแตะ

ศัพท์ที่ใช้ในหัวข้อนี้
Outlier (ค่าประหลาด)
ค่าที่ห่างจากปกติมาก เป็นคำกลางที่ยังไม่ตัดสินว่าเป็นข้อผิดพลาดหรือของจริง
Factor return
ผลตอบแทนประจำวันของปัจจัยหนึ่ง เช่น momentum หรือกลุ่มธนาคาร ได้จาก cross-sectional regression และเท่ากับผลตอบแทนของพอร์ตเลียนแบบ factor
พอร์ตเลียนแบบ factor (factor-mimicking portfolio)
พอร์ตหุ้นที่ซื้อได้จริง ซึ่งผลตอบแทนของมันเท่ากับ factor return พอดี น้ำหนักของหุ้นแต่ละตัวในพอร์ตนี้คือแถวหนึ่งของ matrix $\mathbf H$
bp (basis point)
หนึ่งในร้อยของ 1% คือ $1\ \text{bp}=0.01\%=0.0001$
Log return
$\ln(1+r)$ เมื่อ $r$ คือผลตอบแทนแบบทศนิยม ข้อดีคือการขึ้นกับการลงที่หักล้างกันพอดีมีขนาดเท่ากัน
Winsorization
ดึงค่าที่เกินเกณฑ์ให้กลับมาอยู่ที่เกณฑ์พอดีแทนการลบทิ้ง จำนวนข้อมูลจึงไม่หาย แต่ขนาดของค่านั้นหาย ใช้เป็นตาข่ายกันข้อมูลผิดที่หลุดมาถึง regression
Robust score (คะแนนความประหลาดที่ทนทาน)
ขนาดของ log return วันนี้ หารด้วย median ของขนาด log return ย้อนหลัง ใช้แทน z-score เพราะค่าประหลาดเก่าดันตัวหารนี้ไม่ขึ้น
Corporate action
สิ่งที่บริษัททำกับหุ้นของตัวเอง เช่น แตกหุ้น รวมหุ้น (reverse split) จ่ายปันผลพิเศษ ราคาต่อหุ้นกระโดดทั้งที่มูลค่ารวมไม่เปลี่ยน ถ้าผู้ให้ข้อมูลไม่ปรับ ผลตอบแทนจะผิด
Estimation universe
ชุดหุ้นที่ใช้ประมาณแบบจำลอง เป็นด่านแรกที่กรองหุ้นเล็กซื้อขายน้อยและหุ้นที่กำลังถูกถอดจากตลาดออกไป ก่อนจะถึงขั้นจัดการค่าประหลาด
Audit trail
บันทึกว่าข้อมูลตัวไหนถูกแก้ วันไหน ค่าเดิมกับค่าใหม่คืออะไร และเพราะอะไร ต้องมีทุกครั้งที่แตะข้อมูล
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$r_{i,t}$ผลตอบแทนของหุ้น $i$ ในวัน $t$ทศนิยม
$T$จำนวนวันย้อนหลังที่ใช้หา $s_i$วัน
$s_i$median ของ $\lvert\ln(1+r)\rvert$ ของหุ้น $i$ ย้อนหลัง $T$ วัน คือขนาดการขยับของวันธรรมดาทศนิยม
$d_{i,t}$คะแนนความประหลาด: วันนี้หุ้นขยับกี่เท่าของ $s_i$ไม่มีหน่วย
$d_{\max}$เกณฑ์ ถ้าคะแนนเกินค่านี้ ค่านั้นถูกดึงลงไม่มีหน่วย
$r^{+},\ r^{-}$เพดานด้านขึ้นและด้านลง คือผลตอบแทนที่คะแนนเท่ากับ $d_{\max}$ พอดีทศนิยม
$H_{ki}$น้ำหนักของหุ้น $i$ ในพอร์ตเลียนแบบ factor $k$ไม่มีหน่วย
$\Delta\hat f_k$การขยับของ factor return ที่ประมาณได้bp (0.01%)
$E_{\rm B}$ความคลาดของ momentum ในเรื่อง B: ค่าที่ระบบรายงาน ลบด้วยค่าที่ควรเป็นbp
$\mathrm{rms}_k$ความผันผวนของหน้าต่างข้อมูลย้อนหลัง วัดรอบศูนย์ (รากของค่าเฉลี่ยกำลังสอง) เมื่อมีค่าประหลาดเก่า $k$ ตัวทศนิยม

ขั้นที่ 1 — ค่าหนึ่งตัวขยับ factor return เท่าไร

ก่อนตัดสินใจว่าจะทำอะไรกับค่าประหลาด ต้องรู้ก่อนว่ามันทำอะไรกับ factor return ถ้าค่าผิดค่าเดียวแทบไม่ขยับอะไร ก็ไม่ต้องกังวล แต่ถ้ามันพลิกตัวเลขของทั้งวันได้ ก็ต้องจัดการ

หน้า cross-sectional regression แสดงว่า factor return เขียนได้เป็น $\hat{\mathbf f}=\mathbf H\mathbf r$ โดย $\mathbf r$ คือเวกเตอร์ผลตอบแทนของหุ้นทุกตัวในวันนั้น และ $\mathbf H$ คือ matrix ที่ regression สร้างขึ้น แถว $k$ ของ $\mathbf H$ คือน้ำหนักของหุ้นแต่ละตัวในพอร์ตเลียนแบบ factor $k$ (พอร์ตที่ซื้อได้จริง และได้ผลตอบแทนเท่ากับ factor return นั้นพอดี) สูตรนี้เป็นเชิงเส้น ถ้าผลตอบแทนของหุ้น $i$ ตัวเดียวเปลี่ยนไป $\Delta r_i$ factor $k$ จึงขยับ $H_{ki}\,\Delta r_i$

ของที่ต้องใช้:

  • ในตัวอย่างแปดตัว น้ำหนักของหุ้นตัวที่ 5 ในพอร์ต momentum คือ 0.22295 ค่านี้อ่านจาก $\mathbf H$ ของหน้า cross-sectional regression แบบที่บังคับให้ industry factor ถ่วงด้วยมูลค่าตลาดรวมกันเป็นศูนย์ ในจักรวาล 600 ตัว หุ้นตัวที่ 5 มี 75 ชุดที่เหมือนกันทุกอย่าง น้ำหนักนี้จึงถูกแบ่งเท่า ๆ กันให้ 75 ชุด
  • วันธรรมดา หุ้นตัวที่ 5 ทุกชุดได้ 0.25% เพราะข้อมูล 75 ชุดซ้ำกันหมด regression จึงให้ factor return ชุดเดิมของตัวอย่างแปดตัว เช่น momentum 0.4741%
  • ในการคำนวณ ผลตอบแทนเขียนเป็นทศนิยม เช่น −18% คือ −0.18 ส่วนการขยับของ factor วัดเป็น bp โดย $1\ \text{bp}=0.0001$

มีสามกรณีที่ต้องคิด คือ A (ข่าวจริง −18%) B (ค่าดิบที่ผิด +340%) และ B* (ผลตอบแทนจริงของเรื่อง B คือ −12% ขั้นแก้ที่ต้นทางจะหาตัวเลขนี้) แต่ละกรณีแทนค่า 0.25% ของวันธรรมดาด้วยค่าใหม่ $\Delta r$ จึงเท่ากับค่าใหม่ลบ 0.0025

\[ \begin{aligned} \Delta\hat f_k&=H_{ki}\,\Delta r_i,\\ H_{{\rm mom},5}&=0.22295/75=0.0029727,\\ \Delta r_{\rm A}&=-0.18-0.0025=-0.1825,\\ \Delta\hat f_{\rm A}&=0.0029727\times(-0.1825)\\ &=-0.000543=-5.43\ \text{bp},\\ \Delta r_{\rm B}&=3.40-0.0025=3.3975,\\ \Delta\hat f_{\rm B}&=0.0029727\times3.3975\\ &=0.010100=+101.00\ \text{bp},\\ \Delta r_{\rm B^*}&=-0.12-0.0025=-0.1225,\\ \Delta\hat f_{\rm B^*}&=0.0029727\times(-0.1225)\\ &=-0.000364=-3.64\ \text{bp}. \end{aligned} \]

การคำนวณง่ายขนาดนี้เพราะสองเหตุผล ข้อแรก $\hat{\mathbf f}=\mathbf H\mathbf r$ เป็นเชิงเส้น ผลตอบแทนเปลี่ยนเท่าไร factor ก็ขยับเป็นสัดส่วนเท่านั้น ข้อสอง $\mathbf H$ ไม่ขยับตามค่าประหลาดของวันนี้ เพราะน้ำหนักใน regression มาจากความผันผวนที่ประมาณได้ถึงเมื่อวาน ผลคือ ค่าดิบของ B ใหญ่กว่า A อยู่ $3.3975/0.1825=18.62$ เท่า การขยับของ momentum ก็ใหญ่กว่า 18.62 เท่าเช่นกัน

เรื่อง A คือการขยับที่ควรเกิด เพราะพอร์ตที่ถือหุ้นนั้นเจ็บจริง factor อื่นก็ขยับด้วยสูตรเดียวกัน เช่น banks ซึ่งน้ำหนักของหุ้นชุดนี้คือ $0.4806/75=0.0064077$ จึงขยับ $0.0064077\times(-0.1825)=-11.69$ bp

เรื่อง B คือค่าผิด หุ้นหนึ่งตัวจาก 600 ดัน momentum จาก 0.4741% เป็น $0.4741\%+1.0100\%=1.4841\%$ ดัน banks ขึ้น $0.0064077\times3.3975=+217.70$ bp และดัน market (น้ำหนัก $0.13765/75=0.0018353$) ขึ้น $0.0018353\times3.3975=+62.35$ bp ทั้งที่ค่าจริง B* ควรขยับ momentum แค่ −3.64 bp ค่าผิดจึงทำให้ momentum คลาดไป $101.00-(-3.64)=104.64$ bp ในวันเดียว

ขั้นที่ 2 — คะแนนความประหลาดที่ทนทาน

ระบบต้องตัดสินว่าค่าไหน “ใหญ่ผิดปกติ” แต่ใหญ่แค่ไหนถึงผิดปกติขึ้นกับหุ้นแต่ละตัว หุ้นธนาคารที่ปกติขยับวันละราว 1–2% ถ้าลง 18% คือเรื่องใหญ่มาก แต่หุ้นตัวเล็กที่ขยับวันละ 10% เป็นเรื่องปกติ จึงต้องวัดเทียบกับวันธรรมดาของหุ้นตัวนั้นเอง

คะแนนความประหลาด $d_{i,t}$ ของหุ้น $i$ ในวัน $t$ จึงนิยามว่า ขนาดของ log return วันนี้ หารด้วยขนาดการขยับของวันธรรมดา $s_i$ ส่วน $s_i$ คือ median ของขนาด log return ย้อนหลัง $T$ วัน ไม่รวมวันนี้ (log return คือ $\ln(1+r)$ และ median คือค่าตรงกลางเมื่อเรียงจากน้อยไปมาก)

เพื่อให้ได้ตัวเลขของหุ้นตัวที่ 5 หน้านี้สมมติว่าวันธรรมดาของมันเป็น Normal ที่ความผันผวน 2.0% ต่อวัน กรณีนี้ median ของขนาดคือ 0.6745 เท่าของความผันผวน เพราะ $P(\lvert Z\rvert\le0.6745)=0.5$ เมื่อ $Z$ คือตัวแปร Normal มาตรฐาน แปลว่าวันธรรมดาครึ่งหนึ่งขยับน้อยกว่า 0.6745 เท่าของความผันผวน อีกครึ่งขยับมากกว่า

\[ \begin{aligned} s_i&=\operatorname{median}_{j=1..T}\lvert\ln(1+r_{i,t-j})\rvert,\\ d_{i,t}&=\lvert\ln(1+r_{i,t})\rvert/s_i,\\ s_5&=0.6745\times2.0\%=1.349\%,\\ d_{\rm A}&=\tfrac{\lvert\ln0.82\rvert}{0.01349}=\tfrac{0.19845}{0.01349}=14.71,\\ d_{\rm B}&=\tfrac{\ln4.40}{0.01349}=\tfrac{1.48160}{0.01349}=109.83,\\ d_{\rm 0}&=\tfrac{\ln1.0025}{0.01349}=\tfrac{0.00250}{0.01349}=0.19. \end{aligned} \]

$d_{\rm A}$ ใช้ $1-0.18=0.82$ และ $d_{\rm B}$ ใช้ $1+3.40=4.40$ ส่วน $d_{\rm 0}$ คือคะแนนของวันธรรมดาที่ได้ 0.25% ไว้เทียบ

ทำไมใช้ log? เพราะมันสมมาตร หุ้นที่ลง 50% แล้วขึ้น 100% จะกลับมาที่ราคาเดิม สองการขยับนี้ใหญ่เท่ากันแต่คนละทิศ ใน log ทั้งคู่มีขนาดเท่ากัน $\lvert\ln0.5\rvert=\ln2=0.6931$ แต่ในผลตอบแทนดิบ ตัวหนึ่งใหญ่เป็นสองเท่าของอีกตัว

ทำไมใช้ median ของข้อมูลย้อนหลัง? เพราะค่าประหลาดเก่าดัน median ไม่ขึ้น ขั้นที่เทียบตัวหารสองแบบจะวัดให้ดู และทำไมไม่รวมวันนี้? เพราะถ้ารวม ตัวหารจะโตตามค่าประหลาดของวันนี้เอง คะแนนก็จะต่ำกว่าที่ควร

ผลคือวันธรรมดาได้คะแนน 0.19 ข่าวจริงได้ 14.71 ราคาผิดได้ 109.83 สองเรื่องต่างกัน $109.83/14.71=7.47$ เท่า แต่ทั้งคู่เกินเกณฑ์ที่คนทำงานใช้กัน ซึ่งอยู่ในช่วง 5 ถึง 10 เกณฑ์ในช่วงนี้เลือกด้วยการลองผิดลองถูกตามตลาดและประเภทสินทรัพย์

ขั้นที่ 3 — ดึงลงมาที่เกณฑ์: ช่วยเรื่องหนึ่ง ทำร้ายอีกเรื่อง

ตอนนี้รู้แล้วว่าทั้งสองค่าเกินเกณฑ์ ขั้นนี้ดูว่าเมื่อระบบดึงมันลงมาแล้ว factor return ที่ได้ใกล้ความจริงขึ้นแค่ไหน

winsorize คือแทนค่าที่คะแนนเกิน $d_{\max}$ ด้วยผลตอบแทนที่คะแนนเท่ากับ $d_{\max}$ พอดี ให้ $r^{+}$ คือเพดานด้านขึ้น และ $r^{-}$ คือเพดานด้านลง จากนิยามของคะแนน เพดานด้านขึ้นต้องทำให้ $\ln(1+r^{+})=d_{\max}\,s$ แก้สมการได้ $r^{+}=e^{d_{\max}s}-1$ ด้านลงก็เหมือนกันแต่เลขชี้กำลังติดลบ $r^{-}=e^{-d_{\max}s}-1$

จากนั้นใช้สูตรการขยับจากขั้นแรกกับค่าที่ถูกดึงลง แล้วเทียบกับสิ่งที่ควรเกิดจริง คือ A ควรขยับ −5.43 bp และ B ควรขยับ −3.64 bp (ค่าของ B*) ตัววัดของเรื่อง B คือความคลาด $E_{\rm B}$ = momentum ที่ระบบรายงาน ลบด้วยค่าที่ควรเป็น ก่อน winsorize ความคลาดนี้คือ 104.64 bp ตัววัดของเรื่อง A คือสัดส่วนของการขยับจริงที่ยังเหลืออยู่

\[ \begin{aligned} r^{+}&=e^{10\times0.01349}-1=14.44\%,\\ r^{-}&=e^{-10\times0.01349}-1=-12.62\%,\\ \Delta\hat f_{\rm B}&=0.0029727\times(0.1444-0.0025)\\ &=+4.22\ \text{bp},\\ E_{\rm B}&=4.22-(-3.64)=7.86\ \text{bp},\\ 1-E_{\rm B}/104.64&=1-7.86/104.64=92.5\%,\\ \Delta\hat f_{\rm A}&=0.0029727\times(-0.1262-0.0025)\\ &=-3.83\ \text{bp},\\ 3.83/5.43&=70.5\%. \end{aligned} \]

เกณฑ์ 10 ลบความคลาดของราคาผิดไปได้ 92.5% จาก 104.64 bp เหลือ 7.86 bp แต่ momentum ยังขยับผิดทิศ คือ +4.22 แทนที่จะเป็น −3.64 ส่วนเรื่อง A เหลือการขยับจริงแค่ 70.5% ข้อมูลจริงของข่าวจึงหายไป $100\%-70.5\%=29.5\%$ ต้นเหตุคือเพดานไม่รู้ว่าค่าไหนจริงค่าไหนผิด มันรู้แค่ว่าค่าไหนใหญ่

ลดเกณฑ์ลงเป็น 5 ช่วยได้ไหม? เพดานแคบลง แล้วคิดซ้ำด้วยสูตรเดิม

\[ \begin{aligned} r^{+}&=e^{5\times0.01349}-1=6.98\%,\\ r^{-}&=e^{-5\times0.01349}-1=-6.52\%,\\ \Delta\hat f_{\rm B}&=0.0029727\times(0.0698-0.0025)\\ &=+2.00\ \text{bp},\\ E_{\rm B}&=2.00-(-3.64)=5.64\ \text{bp},\\ \Delta\hat f_{\rm A}&=0.0029727\times(-0.0652-0.0025)\\ &=-2.01\ \text{bp},\\ 2.01/5.43&=37\%. \end{aligned} \]

ราคาผิดดีขึ้นนิดเดียว ความคลาดลดไป $1-5.64/104.64=94.6\%$ แทน 92.5% แต่ข่าวจริงเหลือแค่ราว 37% ของการขยับจริง

ลดเกณฑ์ต่อไปเรื่อย ๆ ก็ลบความคลาดของ B ไม่หมด เพราะเพดานด้านขึ้น $r^{+}=e^{d_{\max}s}-1$ ไม่มีทางต่ำกว่าศูนย์ เขียนความคลาดเป็นสูตรของ $r^{+}$ จะเห็นพื้นของมัน

\[ \begin{aligned} E_{\rm B}&=H_{{\rm mom},5}\bigl[(r^{+}-0.0025)-(-0.1225)\bigr]\\ &=H_{{\rm mom},5}\,(r^{+}+0.12)\\ &\ge0.0029727\times0.12\\ &=0.000357=3.57\ \text{bp}. \end{aligned} \]

อีกด้านหนึ่ง ข่าวจริงจะรอดโดยไม่ถูกแตะก็ต่อเมื่อเกณฑ์สูงกว่าคะแนนของมัน คือ 14.71 แต่ถ้าเกณฑ์สูงกว่า 109.83 ราคาผิดก็รอดทั้งก้อน ไม่มีเกณฑ์ไหนถูกกับทั้งสองเรื่อง

ขั้นที่ 4 — แก้ที่ต้นทาง: ปรับการรวมหุ้นแล้วใช้ค่าจริง

เรื่อง B ไม่ใช่ข่าว มันคือ corporate action (สิ่งที่บริษัททำกับหุ้นของตัวเอง) แบบหนึ่ง เรียกว่า reverse split หรือการรวมหุ้น บริษัทเอาหุ้นห้าหุ้นมารวมเป็นหนึ่งหุ้น คนที่เคยถือ 5 หุ้นจะเหลือ 1 หุ้น มูลค่ารวมเท่าเดิม ราคาต่อหุ้นจึงต้องคูณ 5 ถ้าผู้ให้ข้อมูลไม่ปรับ ผลตอบแทนที่คิดจากราคาจะพองขึ้นทั้งที่ไม่มีใครได้เงินเพิ่ม

โจทย์ให้อะไรมาบ้าง: ของที่รู้มีสามอย่าง

  • อัตรารวมหุ้น 5 หุ้นเดิมต่อ 1 หุ้นใหม่
  • ราคาปิดวันนี้ที่รายงานมาเป็น 4.40 เท่าของราคาปิดเมื่อวาน ตัวเลขนี้มาจากค่าดิบ +340% คือ $1+3.40=4.40$
  • ตัวหารของคะแนน $s_5=1.349\%$ และเกณฑ์ 10 เหมือนเดิม

ถ้าปรับการรวมหุ้นให้ถูก ผลตอบแทนจริงคือเท่าไร ระบบจะทำอะไรกับมัน และ momentum ขยับเท่าไร?

วิธีปรับคือหารราคาวันนี้ด้วย 5 ให้อยู่ในหน่วยเดียวกับราคาเมื่อวาน (ราคาของหุ้นเดิมหนึ่งหุ้น) แล้วคิดผลตอบแทน คะแนน และการขยับของ momentum ด้วยสูตรเดิม

\[ \begin{aligned} r&=4.40/5-1=-12.00\%,\\ d&=\tfrac{\lvert\ln0.88\rvert}{0.01349}=\tfrac{0.12783}{0.01349}=9.48,\\ \Delta r&=-0.12-0.0025=-0.1225,\\ \Delta\hat f&=0.0029727\times(-0.1225)\\ &=-3.64\ \text{bp}. \end{aligned} \]

คำตอบ: ราคาผิดซ่อนข่าวจริงไว้ข้างใน หุ้นลงจริง 12% ในวันเดียวกับที่รวมหุ้น คะแนน 9.48 ต่ำกว่าเกณฑ์ 10 ระบบจึงไม่แตะ และ momentum ขยับ −3.64 bp ตามที่พอร์ตเจ็บจริง ถ้าปล่อยให้ winsorization จัดการแทน จะได้ +4.22 bp ซึ่งผิดทั้งขนาดและทิศ

ตรวจเองใน 10 วินาที: $5\times0.88=4.40$ ราคาที่รายงานจึงเป็นผลของการรวมหุ้น (คูณ 5) กับการลง 12% ที่เกิดพร้อมกันจริง

ค่าประหลาดส่วนใหญ่แก้ได้ที่ต้นทางแบบนี้ แต่ละแหล่งมีวิธีแก้ของมัน

  • ราคาที่ยังไม่ปรับ corporate action: ปรับให้ถูก แบบที่เพิ่งทำ
  • ราคาหลุดเพราะมีคนซื้อขายไม่กี่หุ้น ในหุ้นที่ปกติซื้อขายคล่อง: ใช้ราคาที่สะท้อนการซื้อขายทั้งช่วง แทนราคาสุดท้ายของช่วง ตัวอย่างที่เกิดจริง ฤดูร้อนปี 2000 หุ้น Enron ซื้อขายแถว \$86 ทั้งวัน แต่ราคาปิดจาก closing auction (การจับคู่คำสั่งซื้อขายรอบสุดท้ายตอนตลาดปิด) กระโดดเป็น \$90 วันรุ่งขึ้นราคาก็กลับไปแถวกลาง \$80 ราคาปิดแบบนี้ไม่มีใครซื้อขายตามได้จริง
  • หุ้นเล็กที่ซื้อขายน้อย หุ้นที่กำลังถูกถอดจากตลาดหรือล้มละลาย: ไม่เอาเข้า estimation universe (ชุดหุ้นที่ใช้ประมาณแบบจำลอง) ตั้งแต่แรก

เหลือแหล่งเดียวที่แก้ไม่ได้และไม่ควรแก้ คือข่าวจริงที่ใหญ่

ขั้นที่ 5 — ทำไมตัวหารต้องเป็น median ไม่ใช่ความผันผวน

ขั้นคะแนนความประหลาดใช้ median เป็นตัวหาร ทางลัดที่คนใช้บ่อยกว่าคือ z-score ซึ่งหารด้วยความผันผวนของข้อมูลย้อนหลังแทน ขั้นนี้ทดลองดูว่าทางลัดนี้พังตรงไหน

ของที่ใช้ในการทดลอง:

  • หน้าต่างข้อมูลย้อนหลัง 251 วันทำการ ราวหนึ่งปีของการซื้อขาย (ตลาดหุ้นสหรัฐเปิดราว 251–252 วันต่อปี)
  • วันธรรมดาของหุ้นตัวที่ 5 ผันผวน 2.0% ต่อวัน เหมือนขั้นก่อน
  • ในหน้าต่างมีค่าประหลาดเก่าขนาด +50% ติดอยู่ $k$ วัน log return ของมันคือ $\ln1.5=0.40547$
  • วันนี้มีค่าประหลาด +50% ตัวใหม่เข้ามา ต้องให้คะแนนมัน

ความผันผวนของหน้าต่างวัดรอบศูนย์แบบที่ risk model ใช้ คือ rms (root mean square: ยกกำลังสองทุกค่า หาค่าเฉลี่ย แล้วถอดราก) หน้าต่างมีวันธรรมดา $251-k$ วัน ซึ่งกำลังสองเฉลี่ยคือ $(0.02)^2=0.0004$ และวันประหลาด $k$ วัน ซึ่งกำลังสองคือ $(0.40547)^2$ ส่วน z-score คือ log return ของวันนี้หารด้วย rms

\[ \begin{aligned} \mathrm{rms}_k^2&=\tfrac{(251-k)(0.0004)+k(0.40547)^2}{251},\\ z_k&=0.40547/\mathrm{rms}_k,\\ z_0&=0.40547/0.02=20.27,\\ \mathrm{rms}_1^2&=\tfrac{250(0.0004)+(0.40547)^2}{251}=0.0010534,\\ \mathrm{rms}_1&=\sqrt{0.0010534}=0.032456,\\ z_1&=0.40547/0.032456=12.49,\\ \mathrm{rms}_2^2&=\tfrac{249(0.0004)+2(0.40547)^2}{251}=0.0017068,\\ \mathrm{rms}_2&=\sqrt{0.0017068}=0.041314,\\ z_2&=0.40547/0.041314=9.81. \end{aligned} \]

ค่าประหลาดเก่าหนึ่งตัวดันความผันผวนของหน้าต่างจาก 2.0% เป็น 3.25% สองตัวดันเป็น 4.13% ค่าประหลาดตัวใหม่จึงถูกหารด้วยตัวเลขที่ค่าประหลาดรุ่นก่อนดันขึ้นมา พอมีสองตัวในหน้าต่าง คะแนนตกเหลือ 9.81 ต่ำกว่าเกณฑ์ 10 และหลบรอดไปได้ ผลคือ ยิ่งหุ้นมีปัญหาข้อมูลบ่อย ระบบยิ่งมองไม่เห็นปัญหาของมัน

median ไม่เป็นแบบนั้น เพราะมันดูแค่ลำดับ ไม่ดูขนาด median ของ 251 ค่าคือค่าลำดับที่ 126 เมื่อเรียงจากน้อยไปมาก ค่าประหลาดสองตัวไปอยู่ท้ายแถว ค่าลำดับที่ 126 จึงยังเป็นค่าธรรมดา แค่เปลี่ยนจากค่ากลางของวันธรรมดา 251 วัน เป็นค่าลำดับที่ 126 ของวันธรรมดา 249 วัน ซึ่งเลื่อนขึ้นไปนิดเดียว ค่าลำดับที่ 126 ของ 249 ค่าอยู่ที่สัดส่วน $(126-0.5)/249=0.5040$ ของข้อมูล สำหรับ Normal ที่ความผันผวน 2.0% ตัวหารและคะแนนจึงเป็นดังนี้ ($d_k$ คือคะแนนแบบ median เมื่อมีค่าประหลาดเก่า $k$ ตัว)

\[ \begin{aligned} d_0&=0.40547/0.01349=30.06,\\ P(\lvert Z\rvert\le q)&=0.5040\ \Rightarrow\ q=0.6808,\\ s&=0.6808\times2.0\%=1.3616\%,\\ d_2&=0.40547/0.013616=29.78. \end{aligned} \]

คะแนนแทบไม่เปลี่ยน จาก 30.06 เป็น 29.78 และแม้มีค่าประหลาดเก่าถึงแปดตัว ก็ยังได้ 28.94 นี่คือความหมายของคำว่าทนทาน median ทนข้อมูลผิดได้เกือบครึ่งหน้าต่าง ส่วนความผันผวนทนไม่ได้แม้แต่ค่าเดียว

ขั้นที่ 6 — เกณฑ์ควรอยู่ที่เท่าไร: ถามข้อมูลที่สะอาด

เกณฑ์ต่ำจับข้อมูลผิดได้มาก แต่ก็ไปแก้ข้อมูลดีด้วย ขั้นนี้วัดว่าแก้ข้อมูลดีไปเท่าไร วิธีวัดคือสมมติว่าข้อมูลสะอาดทั้งหมด แล้วนับว่าเกณฑ์ $c$ ดึงข้อมูลลงกี่จุด ทุกจุดที่ถูกดึงคือข้อมูลดีที่ถูกแก้โดยไม่จำเป็น

โจทย์ให้อะไรมาบ้าง: ของที่รู้มีดังนี้

  • จักรวาล 600 ตัว ปีละ 251 วันทำการ จึงมีข้อมูล $600\times251=150{,}600$ จุดต่อปี
  • แบบที่ 1: ผลตอบแทนวันธรรมดาเป็น Normal ซึ่งหางบาง คือวันที่ขยับแรงมาก ๆ เกิดยากมาก
  • แบบที่ 2: ผลตอบแทนเป็น Student t ที่ 4 degrees of freedom เขียนย่อว่า $t_4$ ซึ่งหางหนา คือวันที่ขยับแรงมาก ๆ เกิดบ่อยกว่า Normal มาก (สมมติ ตาม stylized facts ที่บอกว่าผลตอบแทนจริงหางหนากว่า Normal)
  • ทั้งสองแบบปรับสเกลให้ median ของขนาดเท่ากัน คะแนนจึงเทียบกันได้ตรง ๆ

ถ้าข้อมูลสะอาดทั้งหมด เกณฑ์ $c$ แต่ละค่าแก้ข้อมูลดีไปกี่จุดต่อปี?

คะแนนเกิน $c$ แปลว่าขนาดของ log return เกิน $c$ เท่าของ median ของขนาด สำหรับ Normal มาตรฐาน median ของ $\lvert Z\rvert$ คือ 0.6745 เงื่อนไขจึงเป็น $\lvert Z\rvert\gt0.6745c$ โดย $Q(x)$ คือโอกาสที่ Normal มาตรฐานเกิน $x$ ด้านเดียว สำหรับ $t_4$ median ของ $\lvert T_4\rvert$ คือ 0.7407 เงื่อนไขจึงเป็น $\lvert T_4\rvert\gt x$ เมื่อ $x=0.7407c$ CDF ของ $t_4$ เขียนเป็นรูปปิดได้ $F(x)=\tfrac12+\tfrac{x(x^2+6)}{2(x^2+4)^{3/2}}$ โอกาสเกินทั้งสองข้างคือ $2\bigl(1-F(x)\bigr)$ คูณโอกาสด้วย 150,600 ก็ได้จำนวนจุดต่อปี $N$

ขั้นที่ 7 — ตัดข่าวจริงทิ้ง คือรายงานผลตอบแทนของพอร์ตที่ไม่มีอยู่จริง

ทำไมห้ามแตะข่าวจริง ทั้งที่การดึง −18% ขึ้นมาเป็น −12.62% ดูเหมือนแค่ปรับเล็กน้อย? คำตอบอยู่ที่ความหมายของ factor return มันคือผลตอบแทนของ factor-mimicking portfolio (พอร์ตเลียนแบบ factor) ซึ่งเป็นพอร์ตที่ซื้อได้จริง ตัวเลขที่รายงานจึงควรเท่ากับเงินที่พอร์ตนั้นได้จริง ลองเทียบสองตัวเลขในเรื่อง A ที่เกณฑ์ 10

  • $f_{\rm port}$ คือผลตอบแทนที่พอร์ต momentum ได้จริงวันนั้น เท่ากับ momentum ของวันธรรมดา 0.47415% บวกการขยับจริง −5.425 bp หรือ −0.05425%
  • $f_{\rm rep}$ คือตัวเลขที่ระบบรายงานหลัง winsorize เท่ากับ 0.47415% บวกการขยับหลังตัด −3.826 bp หรือ −0.03826%

สองการขยับนี้คือ −5.43 bp และ −3.83 bp จากขั้นก่อน ๆ เขียนทศนิยมเพิ่มอีกหนึ่งตำแหน่งเพื่อให้ผลต่างไม่เพี้ยนจากการปัดเศษ

\[ \begin{aligned} f_{\rm port}&=0.47415-0.05425\\ &=0.41990\%,\\ f_{\rm rep}&=0.47415-0.03826\\ &=0.43589\%,\\ f_{\rm rep}-f_{\rm port}&=0.01599\%. \end{aligned} \]

$f_{\rm port}$ คือเงินที่พอร์ต momentum ได้จริง พอร์ตนี้ถือหุ้นชุดนั้นด้วยน้ำหนัก 0.0029727 และเจ็บเต็ม 18% ส่วน $f_{\rm rep}$ คือผลตอบแทนของพอร์ตเดียวกัน ในโลกที่หุ้นชุดนั้นลงแค่ 12.62% ซึ่งไม่ได้เกิดขึ้น ไม่มีพอร์ตไหนได้ตัวเลขนี้จริง regression บนข้อมูลที่ winsorize แล้วจึงรายงานผลตอบแทนของพอร์ตบนข้อมูลที่ไม่เคยเกิด

ส่วนต่าง $0.01599\%$ หรือราว 1.6 bp ในวันเดียวดูเล็ก แต่มันเอียงไปทางเดียวเสมอ ทุกครั้งที่ตัด ข่าวจริงถูกทำให้เล็กลง factor ที่ถือหุ้นนั้นฝั่ง long (ฝั่งซื้อ) จะดูดีกว่าความจริงในวันข่าวร้าย และดูแย่กว่าความจริงในวันข่าวดี ผลรวมคือ factor return ที่รายงานเรียบกว่าความจริง ความผันผวนและหางของ factor จึงถูกรายงานต่ำไป idiosyncratic return (ส่วนที่หุ้นขยับเองโดย factor อธิบายไม่ได้) ก็ผิดตาม และ การแยก PnL ไม่ตรงกับเงินในพอร์ต

winsorization จึงเป็นตาข่ายสำหรับข้อมูลผิดที่หลุดมาถึง regression เท่านั้น ราคาผิดหนึ่งตัวดัน momentum คลาดได้ 104.64 bp ในวันเดียว ตาข่ายลดเหลือ 7.86 bp ระหว่างรอคนมาแก้ที่ต้นทาง ถ้างานต้นทางดี ตาข่ายนี้แทบไม่ได้ทำงาน และนั่นคือสัญญาณว่าระบบสุขภาพดี

ความผิดที่ให้ตัวเลขผิดแบบเงียบ ๆ

แก้ข้อมูลโดยไม่บันทึกและไม่มีใครอ่าน: ระบบที่แก้เงียบ ๆ ซ่อนความเสียหายไว้ ที่เกณฑ์ 10 กับข้อมูลหางหนาแบบ $t_4$ ระบบแก้ข้อมูลที่ไม่ผิดไป $0.0017725\times150{,}600=267$ จุดต่อปี ปนอยู่กับราคาผิดจริง ถ้าไม่มีรายการให้คนอ่านทีละบรรทัด จะไม่มีทางรู้ว่าตัดข่าวจริงทิ้งไปเท่าไร

ใช้ความผันผวนเป็นตัวหาร: ค่าประหลาดเก่าดันตัวหารขึ้น ค่าใหม่จึงหลบเกณฑ์ ในหน้าต่างที่มีค่า +50% เก่าสองตัว แบบผิดให้คะแนนค่า +50% ตัวใหม่ $z_2=0.40547/0.041314=9.81$ ต่ำกว่าเกณฑ์ 10 จึงรอด แบบถูกให้ $d_2=0.40547/0.013616=29.78$ จึงถูกจับ ถ้าใช้แบบผิด หุ้นที่ข้อมูลแย่ที่สุดจะถูกตรวจน้อยที่สุด

ลบค่าประหลาดทิ้งแทนการดึงลง: regression ต้องมีผลตอบแทนของทุกหุ้นที่อยู่ในจักรวาลวันนั้น ถ้าลบหุ้นตัวหนึ่งออก พอร์ตเลียนแบบ factor ของวันนั้นจะไม่มีหุ้นตัวนั้นอยู่ ตัวเลขที่รายงานจึงเป็นผลตอบแทนของอีกพอร์ตหนึ่ง ไม่ใช่พอร์ตที่ถืออยู่ ปัญหาเดียวกับการตัดข่าวจริง

ใช้เกณฑ์เดียวกับทุกตลาด: จำนวนข้อมูลดีที่ถูกแก้ขึ้นกับความหนาของหาง ที่เกณฑ์ 5 เดียวกัน ตลาดที่หางบางแบบ Normal ถูกแก้ $0.000745\times150{,}600=112$ จุดต่อปี แต่ตลาดที่หางหนาแบบ $t_4$ ถูกแก้ $0.02077\times150{,}600=3{,}128$ จุดต่อปี มากกว่ากัน $3{,}128/112=27.9$ เท่า จึงต้องคิดตารางนี้ใหม่กับข้อมูลของแต่ละตลาด

ใช้ทำอะไรบนโต๊ะจริง

ทุกวัน ทีม risk model สร้างแบบจำลองตามลำดับเดิม ขั้นแรกรับข้อมูลจากผู้ให้ข้อมูล ขั้นที่สองเลือก estimation universe ขั้นที่สามคือ winsorization จากนั้นจึงสร้าง loading (ตัวเลขที่บอกว่าหุ้นแต่ละตัวมีลักษณะของ factor มากแค่ไหน เช่น คะแนน momentum) และรัน cross-sectional regression

ทีมใช้กฎสองข้อ

  • รายงานทุกค่าที่ถูก winsorize ทั้งใน backtest (การทดสอบกับข้อมูลย้อนหลัง) และในระบบจริง แต่ละบรรทัดมีชื่อหุ้น วันที่ ค่าเดิม ค่าใหม่ และคะแนน แล้วมีคนอ่านทีละบรรทัด บันทึกนี้คือ audit trail
  • estimation universe มีแต่หุ้นที่ซื้อขายคล่องพอ และซื้อขายได้จริง

ส่วนเกณฑ์ เลือกจากตารางจำนวนข้อมูลดีที่ถูกแก้ ซึ่งคิดจากข้อมูลของตัวเอง ภายในช่วง 5 ถึง 10 ไม่ใช่ลอกตัวเลขของคนอื่นมา

โจทย์ตรวจความเข้าใจ

1. หุ้นตัวหนึ่งปกติขยับไม่มาก median ของขนาด log return ย้อนหลังของมันคือ $s=1.0\%$ วันนี้หุ้นลง 25% ในวันเดียว ระบบใช้เกณฑ์ $d_{\max}=10$ คะแนนของวันนี้เท่าไร และถ้าถูกดึงลง ค่าใหม่คือเท่าไร?

เฉลย

หาคะแนนด้วยนิยามเดิม ใช้ $1-0.25=0.75$ แล้วหาเพดานด้านลงด้วย $r^{-}=e^{-d_{\max}s}-1$

\[ \begin{aligned} d&=\tfrac{\lvert\ln0.75\rvert}{0.01}=\tfrac{0.2877}{0.01}=28.77,\\ r^{-}&=e^{-10\times0.01}-1=e^{-0.1}-1=-9.52\%. \end{aligned} \]

คะแนน 28.77 เกินเกณฑ์ 10 ระบบจึงดึงลงเหลือ −9.52% ถ้านี่เป็นข่าวจริง ผลตอบแทนที่รายงานเหลือแค่ $9.52/25=38\%$ ของของจริง หายไปกว่าครึ่ง

2. ในจักรวาล 600 ตัวของหน้านี้ หุ้นตัวที่ 1 (หุ้น tech ในตัวอย่างแปดตัว) วันธรรมดาได้ 1.20% น้ำหนักของมันในพอร์ต momentum ของตัวอย่างแปดตัวคือ 0.20034 (อ่านจาก $\mathbf H$ แบบเดียวกับหุ้นตัวที่ 5) วันนี้ข้อมูลของหุ้นนี้ชุดหนึ่งถูกรายงานผิดเป็น +100% momentum ขยับเท่าไร?

เฉลย

ทำแบบขั้นแรก แบ่งน้ำหนักให้ 75 ชุด แล้วคูณกับการเปลี่ยนของผลตอบแทน

\[ \begin{aligned} H_{{\rm mom},1}&=0.20034/75=0.0026712,\\ \Delta r&=1.00-0.012=0.988,\\ \Delta\hat f&=0.0026712\times0.988\\ &=0.0026391=+26.39\ \text{bp}. \end{aligned} \]

ค่าผิดตัวเดียวจาก 600 ตัว ดัน momentum ขึ้น 26.39 bp

3. ทีมหนึ่งใช้เกณฑ์ 8 กับจักรวาล 600 ตัว และผลตอบแทนจริงหางหนาแบบ $t_4$ ข้อมูลดีจะถูกแก้กี่จุดต่อวัน และคนอ่านรายการไหวไหม?

เฉลย

อ่านโอกาสจากตาราง ($t_4$ ที่เกณฑ์ 8 คือ 0.406%) คูณจำนวนจุดต่อปี แล้วหารด้วยจำนวนวันทำการ

\[ \begin{aligned} N&=0.004064\times150{,}600=612,\\ 612/251&=2.44. \end{aligned} \]

ราววันละ 2.44 จุด อ่านได้ทุกเช้า ถ้าใช้เกณฑ์ 3 จะเป็น 13,615 จุดต่อปี หรือ $13{,}615/251=54$ จุดต่อวัน ซึ่งไม่มีใครอ่านไหว

const {sqrt, abs, exp, log, PI} = Math;
const T = A => A[0].map((_, j) => A.map(row => row[j]));
const mul = (A, B) => A.map(row => B[0].map((_, j) => row.reduce((s, a, k) => s + a * B[k][j], 0)));
function inverse(A) {                                   // Gauss-Jordan with partial pivoting
  const n = A.length, M = A.map((row, i) => [...row, ...row.map((_, j) => (i === j ? 1 : 0))]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let i = c + 1; i < n; i++) if (abs(M[i][c]) > abs(M[p][c])) p = i;
    [M[c], M[p]] = [M[p], M[c]];
    const v = M[c][c];
    for (let j = 0; j < 2 * n; j++) M[c][j] /= v;
    for (let i = 0; i < n; i++) if (i !== c) { const g = M[i][c]; for (let j = 0; j < 2 * n; j++) M[i][j] -= g * M[c][j]; }
  }
  return M.map(row => row.slice(n));
}
// The eight-stock model, cap-weighted industry constraint: factor returns f = H r

const winsorise = (ret, dmax, s) => (score(ret, s) <= dmax ? ret : ret > 0 ? exp(dmax * s) - 1 : exp(-dmax * s) - 1);

  return {d, badMove: b, badError: b - truthB, removed: 1 - (b - truthB) / (bad - truthB), realMove: a, kept: a / real};
};
// Volatility versus median as the denominator: a 251-day window holding k old +50% days
function normalCdf(x) {                                 // series below 1, continued fraction above
  if (x < 0) return 1 - normalCdf(-x);
  if (x < 1) { let term = x, sum = x; for (let k = 1; k < 60; k++) { term *= x * x / (2 * k + 1); sum += term; } return 0.5 + exp(-x * x / 2) / sqrt(2 * PI) * sum; }
  let f = x; for (let k = 60; k >= 1; k--) f = x + k / f;
  return 1 - exp(-x * x / 2) / sqrt(2 * PI) / f;
}
function quantile(p) { let lo = -10, hi = 10; for (let i = 0; i < 200; i++) { const m = (lo + hi) / 2; if (normalCdf(m) < p) lo = m; else hi = m; } return (lo + hi) / 2; }
const L50 = log(1.5);
const windowScores = k => {
  const rms = sqrt(((251 - k) * 0.02 ** 2 + k * L50 * L50) / 251);
  const median = quantile(0.5 + 0.5 * 125.5 / (251 - k)) * 0.02;   // the 126th value is still a clean one
  return {k, rms, z: L50 / rms, d: L50 / median};
};
// Share of clean points flagged at threshold c: Normal, and Student t with 4 degrees of freedom
const tTail4 = t => 1 - t * (t * t + 6) / (t * t + 4) ** 1.5;
let lo = 0, hi = 5;
for (let i = 0; i < 200; i++) { const m = (lo + hi) / 2; if (tTail4(m) > 0.5) lo = m; else hi = m; }
const m4 = (lo + hi) / 2, points = 600 * 251;
const flagged = cc => ({c: cc, normal: 2 * (1 - normalCdf(0.6744897501960817 * cc)) * points, t4: tTail4(m4 * cc) * points});
console.log({

  scores: [score(0.0025, s5), score(-0.18, s5), score(3.40, s5), score(-0.12, s5)], rawError: bad - truthB,
  caps10: [exp(10 * s5) - 1, exp(-10 * s5) - 1], thresholds: [2, 5, 10, 14.71].map(atThreshold),

  window: [0, 1, 2, 3].map(windowScores), flagged: [3, 5, 8, 10].map(flagged),

  • ค่าหนึ่งตัวขยับ factor เท่ากับน้ำหนักของมันในพอร์ตเลียนแบบ factor คูณการเปลี่ยนของผลตอบแทน ราคาผิด +340% ดัน momentum +101.00 bp ทั้งที่ค่าจริง −12% ควรขยับแค่ −3.64 bp ส่วนข่าวจริง −18% ขยับ −5.43 bp
  • คะแนนที่ทนทานคือ $\lvert\ln(1+r)\rvert$ หารด้วย median ของขนาดย้อนหลัง ข่าวจริงได้ 14.71 ราคาผิดได้ 109.83 ถ้าใช้ความผันผวนเป็นตัวหารแทน ค่าประหลาดเก่าแค่สองตัวก็พอให้ตัวใหม่ได้ 9.81 และหลบเกณฑ์ 10
  • winsorize ที่เกณฑ์ 10 ลดความคลาดของราคาผิดจาก 104.64 bp เหลือ 7.86 bp แต่ยังผิดทิศ และทิ้งข้อมูลจริงของข่าวไป 29.5% ไม่มีเกณฑ์ไหนถูกกับทั้งสองเรื่อง
  • ทางแก้จริงอยู่ที่ต้นทาง ปรับการรวมหุ้นแล้วได้ −12% ที่คะแนน 9.48 ซึ่งระบบไม่แตะ คัด estimation universe ให้มีแต่หุ้นที่ซื้อขายได้จริง และเก็บข่าวจริงไว้ทั้งก้อน
