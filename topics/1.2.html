1.2 Discrete Random Variables and the Probability Mass Function (PMF)

เมื่อผลลัพธ์ออกได้เป็นค่า ๆ PMF บอกโอกาสของแต่ละค่า และโอกาสของเงื่อนไขใดก็ตามคือผลบวกของโอกาสเฉพาะค่าที่เข้าเงื่อนไข

เทรดเดอร์คนหนึ่งจะซื้อหุ้น TSLA (หุ้นของบริษัท Tesla) แล้วถือไว้จนราคาแตะเส้นใดเส้นหนึ่งที่วางแผนไว้ ก่อนลงเงินจริง เขาอยากรู้ว่าแผนนี้คุ้มหรือไม่ จึงต้องเปลี่ยนแผนให้เป็นตัวเลขที่คิดโอกาสได้

แผนของเขามีแค่นี้:

  • ซื้อ 200 หุ้น ที่ราคาหุ้นละ \$200
  • จุดตัดขาดทุน (stop-loss) อยู่ที่ \$195 ถ้าราคาลงมาแตะ ระบบจะขายทิ้งทันที เพื่อไม่ให้ขาดทุนเกินที่ตั้งใจ
  • เป้าขายทำกำไร (take-profit) อยู่ที่ \$210 ถ้าราคาขึ้นไปแตะ ระบบจะขายเก็บกำไร
  • ถ้าราคาขึ้นไปได้สักพักแล้ว เขาจะเลื่อนจุดตัดขาดทุนขึ้นมาไว้ที่ราคาซื้อ \$200 ถ้าราคาย้อนกลับลงมา เขาจึงขายได้เท่าทุนพอดี

เขาลองใช้กฎเดียวกันนี้กับข้อมูลราคาย้อนหลัง แล้วนับว่าแต่ละครั้งจบแบบไหน วิธีนี้เรียกว่า backtest ผลที่ได้ (ตัวเลขสมมติ) คือ:

  • โดนตัดขาดทุน 55% ของจำนวนครั้ง
  • ขายเท่าทุน 15%
  • ถึงเป้ากำไร 30%

เขาถามสองข้อ ข้อแรก โอกาสที่การซื้อขายครั้งหนึ่ง “ไม่ขาดทุน” คือ 30% หรือ 45% ข้อสอง แผนนี้แพ้บ่อยกว่าชนะ (55% เทียบกับ 30%) แปลว่าแผนนี้เสียเปรียบแน่หรือเปล่า

ลองตอบก่อนเปิดเฉลย

ข้อแรก “ไม่ขาดทุน” มีสองกรณี คือขายเท่าทุนกับถึงเป้ากำไร จึงต้องบวกทั้งสอง: $0.15+0.30=0.45$ หรือ 45% ส่วน 30% คือโอกาส “ชนะ” ซึ่งเป็นคนละคำถาม

ข้อสอง แผนนี้ยังไม่เสียเปรียบ เพราะครั้งที่แพ้กับครั้งที่ชนะได้เสียเงินไม่เท่ากัน ให้ $L$ เป็นเงินที่เสียในครั้งที่โดนตัดขาดทุน และ $W$ เป็นเงินที่ได้ในครั้งที่ถึงเป้า:

\[\begin{aligned} L&=200\times(\$200-\$195)=\$1{,}000\\ W&=200\times(\$210-\$200)=\$2{,}000 \end{aligned}\]

ลองนึกถึงการซื้อขายแบบนี้ 100 ครั้ง จะชนะราว 30 ครั้ง แพ้ราว 55 ครั้ง และเท่าทุนราว 15 ครั้งซึ่งไม่ได้ไม่เสีย กำไรเฉลี่ยต่อครั้ง $m$ จึงเป็น

\[\begin{aligned} m&=\frac{30\times2{,}000-55\times1{,}000}{100}\\ &=\frac{60{,}000-55{,}000}{100}=\$50 \end{aligned}\]

แผนนี้ชนะน้อยครั้งกว่า แต่ชนะทีหนึ่งได้เป็นสองเท่าของที่เสียเวลาแพ้ จึงยังเหลือกำไรเฉลี่ยราว \$50 ต่อครั้ง (ก่อนหักค่าธรรมเนียมซื้อขาย) คำตอบทั้งสองข้อมาจากตารางเดียวกัน คือตารางที่บอกว่าผลลัพธ์แต่ละแบบมีโอกาสเท่าไร ตารางนี้ชื่อ PMF และหน้านี้จะสร้างมันทีละขั้น

ภาพรวมก่อนลงสูตร

การซื้อขายแต่ละครั้งในแผนนี้จบได้แค่สามแบบ แบบแรกโดนตัดขาดทุน เสีย $200\times(\$200-\$195)=\$1{,}000$ แบบที่สองขายเท่าทุน ไม่ได้ไม่เสีย แบบที่สามถึงเป้า ได้ $200\times(\$210-\$200)=\$2{,}000$ ก่อนซื้อเรายังไม่รู้ว่าจะจบแบบไหน แต่รู้ว่ามีแบบไหนบ้าง ตัวเลขที่ยังไม่รู้ค่าแบบนี้คือ random variable ที่เจอมาแล้วใน หน้า random variable และ CDF เราเขียนมันด้วยตัวใหญ่ $X$ และใช้ตัวเล็ก $x$ แทนค่าหนึ่งค่าที่เรากำลังถามถึง

ค่าที่ $X$ เป็นได้ในตัวอย่างนี้ไล่นับได้ทีละค่า random variable แบบนี้เรียกว่า discrete random variable อีกตัวอย่างหนึ่งคือจำนวนบริษัทลูกหนี้ของธนาคารที่ผิดนัดชำระหนี้ (จ่ายหนี้ไม่ได้ตามกำหนด) ในปีนี้ ซึ่งเป็นได้ 0, 1, 2, … ราย ตัวแปรแบบนี้บอกโอกาสได้ตรง ๆ ทีละค่า ฟังก์ชันที่รับค่า $x$ แล้วตอบว่า “โอกาสที่ $X$ ออกมาเท่ากับ $x$ พอดีคือเท่าไร” เรียกว่า probability mass function หรือ PMF

PMF มีกฎแค่สองข้อ ข้อแรก โอกาสห้ามติดลบ ข้อสอง โอกาสของทุกค่ารวมกันต้องได้หนึ่ง กฎง่ายแค่นี้แต่ใช้ได้กว้าง เพราะโอกาสของเงื่อนไขใดก็ตามหาได้ด้วยวิธีเดียวกัน เช่น “ไม่ขาดทุน” หรือ “ทอยลูกเต๋าสองลูกได้ผลรวมตั้งแต่ 8” วิธีนั้นคือเลือกค่าที่เข้าเงื่อนไข แล้วบวกโอกาสของค่าเหล่านั้น ถ้าวาด PMF เป็นกราฟแท่ง ก็คือเลือกแท่งแล้วบวกความสูงของแท่ง

CDF จากหน้าที่แล้วคือ $F(x)=P(X\le x)$ หมายถึงโอกาสที่ผลออกมาไม่เกิน $x$ หน้านี้จะเห็นว่า CDF ก็คือ PMF ที่บวกสะสมจากค่าน้อยไปค่ามากนั่นเอง

ลำดับของหน้านี้คือ แปลงแผนซื้อขายเป็นตัวเลข สร้าง PMF แล้วตรวจกฎสองข้อ ใช้ PMF ตอบคำถามของเทรดเดอร์ แปลงไปกลับระหว่าง PMF กับ CDF แล้วสร้าง PMF จากการนับช่องของลูกเต๋า สุดท้ายดูสองเรื่องที่ PMF ของการซื้อขายครั้งเดียวบอกไม่ได้ เรื่องแรกคือผลของหลายครั้งเกี่ยวกันหรือไม่ เรื่องที่สองคือผลลัพธ์ที่ตกหล่นไปจากตาราง

ศัพท์ที่ใช้ในหน้านี้
stop-loss (จุดตัดขาดทุน)
ราคาที่ตั้งไว้ล่วงหน้าว่าถ้าราคาลงมาถึง ให้ขายทิ้งทันที เพื่อจำกัดเงินที่เสียในการซื้อขายครั้งนั้น
take-profit (เป้าขายทำกำไร)
ราคาที่ตั้งไว้ล่วงหน้าว่าถ้าราคาขึ้นไปถึง ให้ขายเก็บกำไร
backtest
การลองใช้กฎซื้อขายชุดเดียวกันกับข้อมูลราคาย้อนหลัง แล้วนับว่าแต่ละครั้งจบแบบไหน ใช้ประเมินแผนก่อนลงเงินจริง
discrete random variable
random variable ที่ค่าที่เป็นไปได้ไล่นับทีละค่าได้ จำนวนค่าอาจมีจำกัด เช่น −1, 0, +2 หรือนับไปได้เรื่อย ๆ ไม่สิ้นสุด เช่น 0, 1, 2, … ใช้กับผลที่ออกเป็นค่า ๆ เช่น ผลการซื้อขายที่มีจุดขายตั้งไว้ หรือจำนวนครั้งที่เรื่องหนึ่งเกิดขึ้น
PMF (probability mass function)
ฟังก์ชัน $p(x)=P(X=x)$ บอกโอกาสที่ $X$ ออกมาเท่ากับ $x$ พอดี วาดเป็นกราฟแท่งได้ แท่งละค่า
CDF (cumulative distribution function)
ฟังก์ชัน $F(x)=P(X\le x)$ บอกโอกาสที่ $X$ ออกมาไม่เกิน $x$ ได้มาจากการบวกแท่ง PMF สะสมจากซ้าย
P&L (profit and loss)
กำไรหรือขาดทุนเป็นดอลลาร์ของการซื้อขายหนึ่งครั้ง บวกคือกำไร ลบคือขาดทุน
R-multiple
P&L หารด้วยเงินที่ตั้งใจยอมเสียต่อการซื้อขายหนึ่งครั้ง (เงินก้อนนี้เรียกว่า 1R) ทำให้การซื้อขายที่ใช้เงินต่างกันเทียบกันได้บนสเกลเดียว
เหตุการณ์ (event)
เงื่อนไขที่ผลลัพธ์อาจเข้าหรือไม่เข้า เช่น “ไม่ขาดทุน” โอกาสของเหตุการณ์คือผลบวกของ $p(x)$ เฉพาะค่า $x$ ที่เข้าเงื่อนไข
independence
การรู้ผลของครั้งหนึ่งไม่ทำให้โอกาสของอีกครั้งเปลี่ยน เมื่อเป็นอย่างนี้ โอกาสที่หลายครั้งออกตามที่กำหนดคือผลคูณของโอกาสแต่ละครั้ง
gap
ราคากระโดดข้ามระดับที่ตั้งไว้โดยไม่มีการซื้อขายระหว่างทาง เช่น ตลาดปิดที่ \$199 แล้วเช้าวันรุ่งขึ้นเปิดที่ \$175 คำสั่งตัดขาดทุนที่ \$195 จึงขายได้ราว \$175 แทน เป็นผลลัพธ์ที่ตาราง PMF แบบง่ายมักลืมใส่
สัญลักษณ์ ความหมาย และหน่วย
สัญลักษณ์ความหมายหน่วย
$L$, $W$เงินที่เสียเมื่อโดนตัดขาดทุน, เงินที่ได้เมื่อถึงเป้ากำไรดอลลาร์
$m$กำไรเฉลี่ยต่อการซื้อขายหนึ่งครั้งดอลลาร์

$X$ผลของการซื้อขายหนึ่งครั้ง ยังไม่รู้ค่าก่อนซื้อขายR
$x$, $t$ค่าหนึ่งที่กำลังถามถึง, ตัวที่ไล่ไปทีละค่าในผลบวกR

$s$, $c(s)$ค่าผลรวมของสองลูก, จำนวนคู่แต้มที่ให้ผลรวมเท่ากับ $s$แต้ม, คู่
$X_1,\ldots,X_5$ผลของการซื้อขายครั้งที่ 1 ถึงครั้งที่ 5R

ขั้นที่ 1 — แปลงแผนซื้อขายเป็นตัวเลขหน่วย R

ก่อนจะพูดถึงโอกาส ต้องตกลงกันก่อนว่าเราวัดอะไร เราไม่ได้วัดราคาหุ้น เราวัดว่าการซื้อขายครั้งหนึ่งได้หรือเสียเงินเท่าไร ตัวเลขนี้เรียกว่า P&L (profit and loss) และเพื่อให้ผลไม่ขึ้นกับจำนวนหุ้นที่ซื้อ เราวัด P&L เป็นจำนวนเท่าของเงินที่ตั้งใจยอมเสียต่อครั้ง เงินก้อนนี้เรียกว่า 1R

ในสูตรด้านล่าง $X_{\mathrm{stop}}$, $X_{\mathrm{flat}}$ และ $X_{\mathrm{target}}$ คือค่าของ $X$ เมื่อการซื้อขายจบที่จุดตัดขาดทุน \$195 ที่ราคาซื้อ \$200 และที่เป้ากำไร \$210 ตามลำดับ เศษของแต่ละตัวคือ P&L เป็นดอลลาร์ ได้จากจำนวนหุ้นคูณ (ราคาขาย − ราคาซื้อ)

\[\begin{aligned} 1R&=200\times(\$200-\$195)\\ &=\$1{,}000\\[4pt] X&=\frac{\mathrm{P\&L}}{1R}=\frac{\mathrm{P\&L}}{\$1{,}000}\\[4pt] X_{\mathrm{stop}}&=\frac{200\times(195-200)}{1{,}000}=-1\\ X_{\mathrm{flat}}&=\frac{200\times(200-200)}{1{,}000}=0\\ X_{\mathrm{target}}&=\frac{200\times(210-200)}{1{,}000}=+2 \end{aligned}\]

1R คือเงินที่เสียถ้าราคาลงไปแตะจุดตัดขาดทุน ทุกผลลัพธ์จึงถูกวัดเทียบกับเงินก้อนนี้ ทำไมต้องหารด้วย 1R เพราะจำนวนหุ้นจะตัดกันหายไป ลองให้ $n$ เป็นจำนวนหุ้นใด ๆ ผลของการถึงเป้าก็ยังเป็น $\dfrac{n\times(210-200)}{n\times(200-195)}=\dfrac{10}{5}=2$ เสมอ ไม่ว่าจะซื้อ 100 หุ้นหรือ 1,000 หุ้น ผลที่ได้จึงบอกคุณภาพของแผน ไม่ใช่ขนาดของเงินที่ลง

ตอนนี้ $X$ มีค่าที่เป็นไปได้สามค่า คือ −1, 0 และ +2 ค่าเหล่านี้ไล่นับได้ $X$ จึงเป็น discrete random variable ข้อควรจำคือ 1R เป็นแค่แผน ตลาดไม่ได้รับประกันว่าจะเสียไม่เกินนี้ ท้ายหน้าจะเห็นว่าเกิดอะไรขึ้นเมื่อราคากระโดดข้ามจุดตัดขาดทุน

ขั้นที่ 2 — PMF และกฎสองข้อของมัน

ตอนนี้รู้แล้วว่า $X$ ออกได้สามค่า ขั้นต่อไปคือแจกโอกาสให้แต่ละค่า โดยใช้ตัวเลขจาก backtest ตอนต้นหน้า คือ −1R ได้ 0.55 0R ได้ 0.15 และ +2R ได้ 0.30 แล้วตรวจว่าการแจกนี้ใช้ได้ การตรวจใช้กฎสองข้อ ซึ่งเป็นสิ่งเดียวที่คณิตศาสตร์บังคับ ส่วนตัวเลขจะตรงกับตลาดจริงหรือไม่เป็นอีกเรื่องหนึ่ง

ในสูตร เครื่องหมาย $\equiv$ แปลว่า “นิยามว่าเท่ากับ” ส่วน $\sum_x$ แปลว่าบวกทุกค่า $x$ ที่ $X$ เป็นได้ และ $a$, $b$ คือขอบล่างกับขอบบนของช่วงที่เราถาม

\[\begin{aligned} p(x)&\equiv P(X=x)\\ p(x)&\ge 0\\ \sum_{x}p(x)&=1\\[4pt] p(-1)+p(0)+p(2)&=0.55+0.15+0.30\\ &=1.00\\[4pt] P(a\le X\le b)&=\sum_{a\le x\le b}p(x) \end{aligned}\]

ทำไมโอกาสรวมต้องเป็นหนึ่ง เพราะการซื้อขายครั้งหนึ่งจบได้แบบเดียว −1R กับ +2R เกิดพร้อมกันไม่ได้ ค่าในตารางจึงไม่ซ้อนกัน และสามค่านี้ครอบคลุมทุกทางที่การซื้อขายจะจบ ทุกครั้งจึงตกอยู่ในค่าใดค่าหนึ่งพอดี รวมกันจึงเป็น 100% ของจำนวนครั้ง หรือโอกาสหนึ่ง ส่วนค่าที่ไม่อยู่ในตาราง เช่น +1R มีโอกาสเป็นศูนย์ เขียนว่า $p(1)=0$

สูตรของ $P(a\le X\le b)$ คือเครื่องมือที่ใช้งานจริง มันบอกว่าโอกาสที่ $X$ ตกอยู่ในช่วง $a$ ถึง $b$ คือผลบวกของ $p(x)$ เฉพาะค่า $x$ ที่อยู่ในช่วงนั้น ช่วงเป็นแค่เงื่อนไขแบบหนึ่ง เงื่อนไขจะเป็นอะไรก็ได้ เช่น “ไม่เท่ากับศูนย์” วิธีคิดยังเหมือนเดิม คือเลือกค่าที่เข้าเงื่อนไขแล้วบวกโอกาส ที่บวกกันได้ตรง ๆ ก็เพราะค่าต่าง ๆ ไม่ซ้อนกัน จึงไม่มีครั้งไหนถูกนับซ้ำ

ขั้นที่ 3 — โอกาสของเหตุการณ์คือผลรวมของแท่งที่เข้าเงื่อนไข

ตอนนี้ตอบข้อแรกของเทรดเดอร์ได้แล้ว งานที่สำคัญที่สุดเกิดก่อนการบวก คือเขียนให้ชัดว่าแต่ละคำถามนับค่าไหนบ้าง

  • “ชนะ” คือ $X\gt 0$ มีค่าเดียวคือ +2R
  • “ไม่ขาดทุน” คือ $X\ge 0$ มีสองค่าคือ 0R และ +2R
  • “ขาดทุน” คือ $X\lt 0$ มีค่าเดียวคือ −1R

จากนั้นจึงบวกโอกาสของค่าที่อยู่ในแต่ละรายการ

\[\begin{aligned} P(X\gt 0)&=p(2)=0.30\\ P(X\ge 0)&=p(0)+p(2)\\ &=0.15+0.30=0.45\\ P(X\lt 0)&=p(-1)=0.55\\[4pt] P(X\ge 0)+P(X\lt 0)&=0.45+0.55=1 \end{aligned}\]

คำตอบข้อแรกจึงเป็น 45% ไม่ใช่ 30% ส่วนผลบวก $P(X\ge 0)+P(X\lt 0)$ มีไว้ตรวจคำตอบ เพราะ “ไม่ขาดทุน” กับ “ขาดทุน” แบ่งทุกค่าออกเป็นสองกองพอดี ไม่มีค่าไหนอยู่ทั้งสองกอง และไม่มีค่าไหนตกหล่น โอกาสของสองกองจึงต้องรวมกันได้หนึ่ง ถ้าไม่ได้หนึ่งแปลว่านับผิด

ระวังคู่ “ชนะ” กับ “ขาดทุน” ซึ่งรวมกันได้แค่ $0.30+0.55=0.85$ เพราะค่า 0R ไม่อยู่ในกองไหนเลย อีกวิธีตรวจคือ กอง “ไม่ขาดทุน” มีค่า +2R ของกอง “ชนะ” อยู่แล้ว แล้วยังมี 0R เพิ่มอีก โอกาสไม่ขาดทุนจึงต้องมากกว่าโอกาสชนะ ถ้าได้เท่ากันที่ 0.30 แปลว่าลืมแถว 0R

ขั้นที่ 4 — PMF กับ CDF แปลงกลับไปมาได้

ใน หน้า random variable และ CDF เราสร้าง CDF ด้วยการนับสะสม ตอนนี้มี PMF แล้ว จึงเขียนความสัมพันธ์ของสองตัวนี้เป็นสูตรได้ทั้งขาไปและขากลับ รูปบันไดบนสุดของหน้าแสดงเรื่องนี้ไว้แล้ว ขั้นนี้แค่เขียนสิ่งที่เห็นในรูปให้เป็นสูตร

ในสูตร $t$ คือตัวที่ไล่ไปทีละค่าที่ $X$ เป็นได้ ส่วน $F(x^-)$ คือโอกาสที่ $X\lt x$ หมายถึงยอดสะสมของค่าที่น้อยกว่า $x$ โดยยังไม่รวม $x$ เอง

\[\begin{aligned} F(x)&=\sum_{t\le x}p(t)\\[4pt] F(-1)&=0.55\\ F(0)&=0.55+0.15=0.70\\ F(2)&=0.70+0.30=1\\[4pt] p(x)&=F(x)-F(x^-)\\ p(0)&=0.70-0.55=0.15 \end{aligned}\]

ขาไปคือการบวกสะสม $F(x)$ เก็บ $p(t)$ ของทุกค่า $t$ ที่ไม่เกิน $x$ แล้วบวกกัน ค่า $x$ ไม่จำเป็นต้องเป็นค่าที่ $X$ ออกได้ เช่น $F(1)=p(-1)+p(0)=0.55+0.15=0.70$ ซึ่งเท่ากับ $F(0)$ เพราะไม่มีผลลัพธ์ใดอยู่ระหว่าง 0R กับ +1R บันไดจึงแบนช่วงนั้น

ขากลับคือการวัดความสูงของขั้นบันได ยอด $F(x)$ กับยอด $F(x^-)$ ต่างกันแค่ค่า $x$ ค่าเดียว เอามาลบกันจึงเหลือ $p(x)$ พอดี PMF กับ CDF จึงเป็นข้อมูลชุดเดียวกันที่จัดเก็บสองแบบ PMF ตอบคำถาม “เท่ากับเท่าไรพอดี” ได้ทันที ส่วน CDF ตอบคำถาม “ไม่เกินเท่าไร” ได้ทันที

ขั้นที่ 5 — สร้าง PMF จากการนับช่องที่มีโอกาสเท่ากัน: ลูกเต๋าสองลูก

PMF ของเทรดเดอร์ได้มาจากการนับผล backtest แต่หลายครั้งไม่มีใครให้ PMF มาตรง ๆ เราต้องสร้างเองจากผลพื้นฐานที่มีโอกาสเท่ากัน ลูกเต๋าสองลูกเป็นตัวอย่างที่เล็กพอจะนับด้วยมือ และมีกับดักเดียวกับงานจริง คือผลพื้นฐานมีโอกาสเท่ากัน แต่ค่าที่เราสนใจไม่ได้มีโอกาสเท่ากัน

โจทย์ให้อะไรมาบ้าง:

  • ทอยลูกเต๋าที่ยุติธรรมสองลูกแยกกัน “ยุติธรรม” แปลว่าแต่ละหน้า 1 ถึง 6 มีโอกาสออกเท่ากัน
  • $Y_1$ และ $Y_2$ คือแต้มของลูกที่ 1 และลูกที่ 2
  • $X=Y_1+Y_2$ คือผลรวมของสองลูก เป็นได้ตั้งแต่ 2 ถึง 12
  • $c(s)$ คือจำนวนคู่ $(Y_1,Y_2)$ ที่ให้ผลรวมเท่ากับ $s$

โจทย์ต้องการ PMF ของ $X$ และโอกาสที่ผลรวมได้ตั้งแต่ 8 ขึ้นไป

ผลพื้นฐานคือคู่แต้ม $(Y_1,Y_2)$ ซึ่งมีทั้งหมด $6\times6=36$ คู่ และแต่ละคู่มีโอกาส $1/36$ เท่ากัน โอกาสของผลรวม $s$ จึงเท่ากับจำนวนคู่ที่ให้ $s$ หารด้วย 36 งานที่เหลือคือนับ $c(s)$ ถ้า $s\le 7$ ลูกแรกออกได้ตั้งแต่ 1 ถึง $s-1$ แล้วลูกที่สองต้องเป็น $s-Y_1$ ซึ่งอยู่ในช่วง 1 ถึง 6 เสมอ จึงมี $s-1$ คู่ ถ้า $s\ge 7$ ลูกแรกต้องออกอย่างน้อย $s-6$ เพื่อให้ลูกที่สองไม่เกิน 6 ลูกแรกจึงออกได้ $6-(s-6)+1=13-s$ แบบ สองกรณีนี้เขียนรวมเป็นสูตรเดียวได้

\[\begin{aligned} p(s)&=\frac{c(s)}{36},\quad s=2,\ldots,12\\[4pt] c(s)&=s-1\quad (s\le 7)\\ c(s)&=13-s\quad (s\ge 7)\\ c(s)&=6-|s-7|\\[4pt] p(7)&=\frac{6}{36},\qquad p(12)=\frac{1}{36}\\[4pt] P(X\ge 8)&=\frac{5+4+3+2+1}{36}\\ &=\frac{15}{36}\approx 41.67\% \end{aligned}\]

คำตอบ: สูตร $6-|s-7|$ ใช้ได้ทั้งสองกรณี เพราะเมื่อ $s\le 7$ จะได้ $6-(7-s)=s-1$ และเมื่อ $s\ge 7$ จะได้ $6-(s-7)=13-s$ ผลรวม 7 มีหกคู่ ซึ่งมากที่สุด จึงออกบ่อยที่สุดด้วยโอกาส $6/36$ ผลรวม 2 และ 12 มีคู่เดียว คือ (1,1) และ (6,6) ส่วนผลรวมตั้งแต่ 8 นับจาก $c(8)=5$ ลดลงทีละหนึ่งจนถึง $c(12)=1$ รวมได้ 15 คู่จาก 36 หรือประมาณ 41.67%

ตรวจเองใน 10 วินาที: PMF ต้องรวมได้หนึ่ง จำนวนคู่ของทุกผลรวมตั้งแต่ 2 ถึง 12 จึงต้องรวมได้ 36 พอดี: $1+2+3+4+5+6+5+4+3+2+1=36$ ถ้าคิดผิดว่าผลรวมทั้ง 11 ค่ามีโอกาสเท่ากัน ค่าละ $1/11$ จะได้ $P(X\ge8)=5/11\approx45.45\%$ ซึ่งผิด เพราะสิ่งที่มีโอกาสเท่ากันคือคู่แต้ม ไม่ใช่ค่าผลรวม

ขั้นที่ 6 — หลายครั้งต้องรู้ว่าผลแต่ละครั้งเกี่ยวกันหรือไม่

เทรดเดอร์ถามต่อว่า “ถ้าห้าครั้งถัดไปโดนตัดขาดทุนหมด จะเป็นไปได้แค่ไหน” เขาต้องรู้ เพราะแพ้ห้าครั้งติดคือเสีย $5\times\$1{,}000=\$5{,}000$ และเขาต้องมีเงินพอรับไหว PMF ของครั้งเดียวยังตอบไม่ได้ เพราะมันบอกแค่โอกาสของการซื้อขายครั้งเดียว

เราต้องรู้เพิ่มอีกข้อ คือผลของครั้งก่อนทำให้โอกาสของครั้งถัดไปเปลี่ยนหรือไม่ ถ้าไม่เปลี่ยน เราบอกว่าผลแต่ละครั้งเป็นอิสระต่อกัน (independence) เมื่อเป็นอย่างนั้น โอกาสที่หลายครั้งออกตามที่กำหนดคือผลคูณของโอกาสแต่ละครั้ง

ให้ $X_i$ เป็นผลของการซื้อขายครั้งที่ $i$ และ “แพ้” หมายถึง $X_i\lt 0$ ซึ่งมีโอกาส 0.55 ให้ $A_2$ คือเหตุการณ์ที่ครั้งที่ 1 และ 2 แพ้ทั้งคู่ และ $A_5$ คือเหตุการณ์ที่ครั้งที่ 1 ถึง 5 แพ้ทั้งหมด ส่วน $P'$ คือโอกาสที่คิดภายใต้อีกสมมติฐานหนึ่ง ซึ่งจะอธิบายหลังสูตร

\[\begin{aligned} P(A_2)&=0.55\times0.55=0.3025\\[4pt] P(A_5)&=0.55^5\\ &=0.3025^2\times0.55\\ &\approx 0.0503=5.03\%\\[4pt] P'(A_5)&=0.55\times0.70^4\\ &\approx 0.1321=13.21\% \end{aligned}\]

ทำไมคูณได้ ลองนึกถึงการซื้อขายจำนวนมาก ราว 55% แพ้ในครั้งแรก ถ้าผลครั้งที่สองไม่สนใจผลครั้งแรก กลุ่มที่แพ้ครั้งแรกนี้ก็จะแพ้ครั้งที่สองอีกราว 55% สัดส่วนที่แพ้ทั้งสองครั้งจึงเป็น 55% ของ 55% คือ $0.55\times0.55=0.3025$ ทำแบบเดียวกันต่อไปจนครบห้าชั้นได้ราว 5.03% หรือประมาณ 1 ใน 20 เพราะ $1/0.0503\approx 20$

ระวังว่าตัวเลขนี้คือโอกาสของห้าครั้งที่ระบุไว้ล่วงหน้า เช่น ห้าครั้งถัดไป มันไม่ใช่โอกาสที่จะเจอแพ้ห้าครั้งติดสักช่วงหนึ่งในการซื้อขาย 100 ครั้ง โอกาสแบบหลังสูงกว่ามาก เพราะใน 100 ครั้ง จุดเริ่มนับห้าครั้งติดมีได้ถึง $100-5+1=96$ ตำแหน่ง

แถวของ $P'$ แสดงว่าสมมติฐานเปลี่ยนคำตอบได้มาก สมมติว่าผลไม่เป็นอิสระต่อกัน หลังแพ้หนึ่งครั้ง โอกาสแพ้ครั้งถัดไปขึ้นเป็น 0.70 (ตัวเลขสมมติ) เช่น ในช่วงที่ตลาดไม่เข้าทางกลยุทธ์ ครั้งแรกยังใช้ 0.55 เพราะยังไม่มีผลก่อนหน้า อีกสี่ครั้งที่ตามมาเกิดหลังการแพ้ทั้งหมด จึงใช้ 0.70 ทุกครั้ง คำตอบสูงกว่าเดิม $0.1321/0.0503\approx 2.6$ เท่า ทั้งที่โอกาสแพ้ของครั้งแรกยังเป็น 0.55 เหมือนเดิม

ขั้นที่ 7 — ผลลัพธ์ที่ตกหล่นจากตาราง

ตาราง PMF ของเทรดเดอร์รวมได้หนึ่งและผ่านกฎทั้งสองข้อแล้ว แต่ตารางที่ผ่านกฎก็ยังลืมผลลัพธ์ที่เกิดได้จริงได้ จุดตัดขาดทุนที่ \$195 เป็นแค่คำสั่งว่า “ถ้าราคาถึง \$195 ให้ขาย” มันไม่ได้รับประกันว่าจะขายได้ที่ \$195

ลองนึกถึงกรณีนี้ ข่าวร้ายของบริษัทออกมาหลังตลาดปิด เช้าวันรุ่งขึ้นราคาเปิดที่ \$175 เลย โดยไม่มีการซื้อขายที่ราคาระหว่างทาง คำสั่งขายจึงได้ราคาราว \$175 การที่ราคากระโดดข้ามแบบนี้เรียกว่า gap ให้ $X_{\mathrm{gap}}$ เป็นผลของการซื้อขายครั้งนั้นในหน่วย R ซึ่งสูตรด้านล่างจะคำนวณได้ −5R คือเสียเป็นห้าเท่าของที่วางแผนไว้

สมมติว่า gap แบบนี้เกิด 1 ครั้งในทุก 100 ครั้งของการซื้อขาย (ตัวเลขสมมติเพื่อฝึกคิด ไม่ใช่ค่าประมาณของ TSLA) ครั้งเหล่านี้เคยถูกนับรวมอยู่ใน 55% ที่โดนตัดขาดทุน ตารางใหม่จึงต้องย้ายโอกาส 0.01 ออกจากแถว −1R ไปไว้ที่แถว −5R

จากนั้นเทียบกำไรเฉลี่ยต่อครั้งของสองตาราง กำไรเฉลี่ยคิดแบบเดียวกับ \$50 ตอนต้นหน้า คือคูณผลแต่ละค่าด้วยโอกาสของมันแล้วบวกกัน ต่างกันแค่ว่าคราวนี้ใช้โอกาสแทนจำนวนครั้งจาก 100 และวัดเป็น R ให้ $m_0$ เป็นกำไรเฉลี่ยของตารางเดิม และ $m_1$ เป็นของตารางใหม่ แถว 0R ไม่ต้องเขียน เพราะ $0\times0.15=0$

\[\begin{aligned} X_{\mathrm{gap}}&=\frac{200\times(175-200)}{1{,}000}=-5\\[4pt] p(-5)&=0.01,\qquad p(-1)=0.54\\ p(0)&=0.15,\qquad p(2)=0.30\\ \sum_x p(x)&=0.01+0.54+0.15+0.30\\ &=1\\[4pt] m_0&=(-1)(0.55)+2(0.30)\\ &=-0.55+0.60=0.05R\\[4pt] m_1&=(-5)(0.01)+(-1)(0.54)\\ &\quad+2(0.30)\\ &=-0.05-0.54+0.60\\ &=0.01R \end{aligned}\]

จุดที่ต้องระวังคือการเพิ่มแถวโดยไม่ปรับแถวอื่น ถ้าเติม $p(-5)=0.01$ แต่ปล่อย $p(-1)$ ไว้ที่ 0.55 ผลรวมจะเป็น $0.01+0.55+0.15+0.30=1.01$ ผิดกฎทันที เราจึงย้ายโอกาสแทนการเติม โอกาสแพ้รวมยังเป็น $0.01+0.54=0.55$ เท่าเดิม อัตราแพ้ชนะไม่เปลี่ยนเลย

แต่กำไรเฉลี่ยลดจาก 0.05R เหลือ 0.01R คิดเป็นดอลลาร์คือจาก $0.05\times\$1{,}000=\$50$ เหลือ $0.01\times\$1{,}000=\$10$ ต่อครั้ง หายไป $(0.05-0.01)/0.05=80\%$ ทำไมโอกาสแค่ 0.01 ทำได้ขนาดนี้ เพราะในค่าเฉลี่ย โอกาสแต่ละก้อนถูกคูณด้วยผลของมัน การย้าย 0.01 จาก −1R ไปไว้ที่ −5R ทำให้ค่าเฉลี่ยเปลี่ยน $0.01\times\big(-5-(-1)\big)=-0.04R$ และ $0.05-0.04=0.01R$ ตรงกับที่คำนวณไว้ การคูณผลด้วยโอกาสแล้วบวกกันแบบนี้คือ expected value ซึ่งเป็นเรื่องของ หน้า expected value ถัดไป

จุดที่พลาดแล้วได้คำตอบผิดโดยไม่รู้ตัว

ลืมแถวที่อยู่ตรงขอบเงื่อนไข: คำว่า “ไม่ขาดทุน” รวมแถว 0R ด้วย แต่คนมักนับแค่แถวที่กำไร ผิดคือ $P(X\ge 0)=p(2)=0.30$ ถูกคือ $P(X\ge 0)=p(0)+p(2)=0.15+0.30=0.45$ ก่อนบวกทุกครั้ง ให้เขียนรายชื่อค่าที่เข้าเงื่อนไขออกมาก่อน

คิดเองว่าค่าที่ต่างกันมีโอกาสเท่ากัน: ผลรวมลูกเต๋าสองลูกมี 11 ค่า แต่ไม่ได้มีโอกาสค่าละ $1/11$ ผิดคือ $P(X\ge 8)=5/11\approx 45.45\%$ ถูกคือ $P(X\ge 8)=15/36\approx 41.67\%$ ต้องหาก่อนว่าอะไรคือผลพื้นฐานที่มีโอกาสเท่ากันจริง (ที่นี่คือคู่แต้ม) แล้วค่อยนับ

คูณโอกาสโดยไม่ถามว่าผลแต่ละครั้งเป็นอิสระต่อกันหรือไม่: ถ้าแพ้แล้วมีแนวโน้มแพ้ต่อ การคูณ 0.55 ห้าครั้งจะให้ตัวเลขต่ำเกินจริง การคูณตรง ๆ ได้ $0.55^5\approx 5.03\%$ แต่ถ้าหลังแพ้ โอกาสแพ้ครั้งถัดไปขึ้นเป็น 0.70 คำตอบที่ถูกคือ $0.55\times0.70^4\approx 13.21\%$ ถ้าวางแผนเงินทุนจากตัวเลขแรก จะเตรียมเงินรับช่วงแพ้ติดกันน้อยเกินไป

เติมแถวใหม่โดยไม่ลดแถวเดิม: เมื่อแยกกรณี gap ออกมา ต้องย้ายโอกาสจากแถวเดิม ไม่ใช่เติมเพิ่ม ผิดคือ $0.01+0.55+0.15+0.30=1.01$ ซึ่งผิดกฎข้อสอง และทุกตัวเลขที่คำนวณต่อจากตารางนี้จะคลาดหมด ถูกคือ $0.01+0.54+0.15+0.30=1$ โดยบอกให้ชัดว่าโอกาส 0.01 ย้ายมาจากแถว −1R

ใช้ทำอะไรบนโต๊ะจริง

ในทีมเทรด (มักเรียกว่าโต๊ะ หรือ trading desk) PMF แบบในหน้านี้ได้มาจากการนับผล backtest คือนับว่าการซื้อขายย้อนหลังจบที่ผลแต่ละแบบกี่ครั้ง แล้วหารด้วยจำนวนครั้งทั้งหมด เหมือนการนับวันใน ECDF ตัวอย่างเช่น backtest มีการซื้อขาย 200 ครั้ง (ตัวเลขสมมติ) จบที่ตัดขาดทุน 110 ครั้ง เท่าทุน 30 ครั้ง และถึงเป้า 60 ครั้ง จะได้ PMF ชุดเดียวกับของเทรดเดอร์

\[\begin{aligned} p(-1)&=110/200=0.55\\ p(0)&=30/200=0.15\\ p(2)&=60/200=0.30 \end{aligned}\]

ตัวเลขเหล่านี้ไม่แน่นอนเต็มร้อย เพราะข้อมูลย้อนหลังมีจำกัด ถ้า backtest กับช่วงเวลาอื่นอาจได้ตัวเลขต่างไปบ้าง และควรแยกครั้งที่ขายได้แย่กว่าแผน เช่น gap ออกมาเป็นแถวของตัวเอง ไม่ปนไว้ในแถว −1R เพราะส่วนท้ายของหน้านี้แสดงแล้วว่าแถวเล็ก ๆ แบบนี้กินกำไรเฉลี่ยได้มาก

PMF ยังใช้ประเมินสัญญาที่จ่ายเงินเป็นก้อนได้ สมมติมีสัญญาที่จ่าย \$100 เฉพาะเมื่อการซื้อขายถึงเป้า +2R และไม่จ่ายเลยในกรณีอื่น สัญญานี้จ่ายเฉลี่ยต่อครั้ง $100\times0.30+0\times(0.55+0.15)=\$30$ แต่ราคาที่ควรซื้อขายสัญญานี้ไม่ใช่ \$30 พอดี เพราะต้องคิดเรื่องเวลาที่ต้องรอเงินและความเสี่ยงเพิ่ม เรื่องนี้คือการตั้งราคา derivative (สัญญาที่มูลค่าขึ้นกับราคาของสิ่งอื่น) ซึ่งจะมาในภายหลัง

โจทย์ตรวจความเข้าใจ

1. ร้านค้าให้ลูกค้าหยิบคูปองส่วนลดหนึ่งใบจากกล่อง โดยไม่ดูก่อน ทุกใบจึงมีโอกาสถูกหยิบเท่ากัน ในกล่องมีคูปองห้าใบ:

  • ส่วนลด \$1 สามใบ
  • ส่วนลด \$5 หนึ่งใบ
  • ส่วนลด \$10 หนึ่งใบ

ให้ $D$ เป็นส่วนลดที่ได้เป็นดอลลาร์ เขียน PMF ของ $D$ แล้วหาโอกาสที่ได้ส่วนลดอย่างน้อย \$5 ทำไมคำตอบจึงไม่ใช่ 2/3

เฉลย

สิ่งที่มีโอกาสเท่ากันคือคูปองแต่ละใบ ใบละ $1/5$ โอกาสของแต่ละค่าส่วนลดจึงเท่ากับจำนวนใบของค่านั้นหารด้วย 5

\[\begin{aligned} p(1)&=3/5\\ p(5)&=1/5,\qquad p(10)=1/5\\ \sum_d p(d)&=3/5+1/5+1/5=1\\ P(D\ge 5)&=p(5)+p(10)\\ &=1/5+1/5=2/5=40\% \end{aligned}\]

คำตอบ 2/3 มาจากการคิดว่าส่วนลดสามค่า คือ \$1, \$5 และ \$10 มีโอกาสค่าละ 1/3 แล้วนับสองค่าได้ $2\times1/3=2/3$ ซึ่งผิด เพราะค่า \$1 มีคูปองถึงสามใบ จึงมีโอกาสมากกว่าค่าอื่น

2. เทรดเดอร์อีกคนตั้งเป้ากำไรห่างจากราคาซื้อเท่ากับระยะตัดขาดทุน ผลของเขาจึงเป็น −1R, 0R หรือ +1R จาก backtest (ตัวเลขสมมติ) ได้โอกาสดังนี้ และผลแต่ละครั้งเป็นอิสระต่อกัน

  • $p(-1)=0.40$
  • $p(0)=0.20$
  • $p(1)=0.40$

ตรวจว่าตารางนี้เป็น PMF แล้วหาสามอย่าง คือโอกาสไม่ขาดทุน โอกาสที่ห้าครั้งที่ระบุไว้แพ้ทั้งหมด และกำไรเฉลี่ยต่อครั้ง

เฉลย

ทุกโอกาสไม่ติดลบ และรวมกันได้หนึ่ง จึงเป็น PMF ส่วนคำตอบอื่นคิดแบบเดียวกับแผน TSLA ให้ $A_5$ คือห้าครั้งที่ระบุไว้แพ้ทั้งหมด และ $m$ คือกำไรเฉลี่ยต่อครั้งในหน่วย R

\[\begin{aligned} \sum_x p(x)&=0.40+0.20+0.40=1\\ P(X\ge 0)&=0.20+0.40=0.60\\ P(A_5)&=0.40^5=0.01024\\ m&=(-1)(0.40)+0(0.20)+1(0.40)\\ &=-0.40+0.40=0R \end{aligned}\]

เทียบกับแผน TSLA แผนนี้ไม่ขาดทุนบ่อยกว่า (0.60 เทียบกับ 0.45) และแพ้ห้าครั้งรวดยากกว่า (1.024% เทียบกับ 5.03%) แต่กำไรเฉลี่ยเป็นศูนย์ ขณะที่แผน TSLA ได้ 0.05R การเทียบแผนจึงต้องดูทั้งขนาดของผลและโอกาส ไม่ใช่ดูแค่ว่าชนะบ่อยแค่ไหน

3. ในเกมลูกเต๋าเกมหนึ่ง ผู้เล่นชนะทันทีถ้าทอยลูกเต๋าที่ยุติธรรมสองลูกได้ผลรวม 7 หรือ 11 โอกาสชนะทันทีคือเท่าไร

เฉลย

ผลรวม 7 มีหกคู่ คือ (1,6), (2,5), (3,4), (4,3), (5,2), (6,1) ผลรวม 11 มีสองคู่ คือ (5,6) กับ (6,5) ผลรวมจะเป็น 7 และ 11 พร้อมกันไม่ได้ จึงบวกโอกาสกันได้ตรง ๆ: $p(7)+p(11)=6/36+2/36=8/36\approx 22.22\%$

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
const pmf = [[-1, 0.55], [0, 0.15], [2, 0.30]];
const total = pmf.reduce((s, [x, p]) => s + p, 0);
const prob = test =>
  pmf.filter(([x]) => test(x)).reduce((s, [x, p]) => s + p, 0);
console.log(total);                    // 1 (ตรวจกฎข้อสอง)
console.log(prob(x => x > 0));        // 0.30 ชนะ
console.log(prob(x => x >= 0));       // 0.45 ไม่ขาดทุน
console.log(prob(x => x <= 0));       // 0.70 = F(0)

// PMF ของผลรวมลูกเต๋าสองลูกจากการนับ 36 ช่อง
const dice = {};
for (let a = 1; a <= 6; a++)
  for (let b = 1; b <= 6; b++) dice[a + b] = (dice[a + b] || 0) + 1 / 36;
let atLeast8 = 0;
for (let s = 8; s <= 12; s++) atLeast8 += dice[s];
console.log(dice[7], atLeast8);        // 0.1667  0.4167

console.log(0.55 ** 5);                // 0.0503 (independence)
console.log(0.55 * 0.70 ** 4);         // 0.1321 (แพ้แล้วแพ้ต่อง่ายขึ้น)
console.log(-5 * 0.01 - 1 * 0.54 + 2 * 0.30); // 0.01 (มี gap)

สิ่งที่ควรตอบได้หลังอ่าน

  • PMF คือ $p(x)=P(X=x)$ โอกาสที่ผลออกมาเท่ากับ $x$ พอดี มันต้องไม่ติดลบ และรวมทุกค่าแล้วต้องได้หนึ่ง ค่าที่ไม่อยู่ในตารางมีโอกาสเป็นศูนย์
  • โอกาสของเงื่อนไขใดก็ตามคือผลบวกของ $p(x)$ เฉพาะค่าที่เข้าเงื่อนไข “ไม่ขาดทุน” ของแผน TSLA จึงเป็น $0.15+0.30=0.45$ ไม่ใช่ 0.30
  • CDF คือ PMF ที่บวกสะสมจากซ้าย และ PMF คือความสูงของแต่ละขั้นบันไดของ CDF ทั้งสองเป็นข้อมูลชุดเดียวกัน
  • หลายครั้ง PMF ต้องสร้างเองจากการนับผลพื้นฐานที่มีโอกาสเท่ากัน เช่น คู่แต้ม 36 คู่ของลูกเต๋าสองลูก ซึ่งให้ $P(X\ge8)=15/36$ ไม่ใช่ $5/11$
  • PMF ของครั้งเดียวไม่บอกว่าผลหลายครั้งเกี่ยวกันหรือไม่ แพ้ห้าครั้งรวดเป็น 5.03% ถ้าผลเป็นอิสระต่อกัน แต่เป็น 13.21% ถ้าแพ้แล้วมีแนวโน้มแพ้ต่อ
  • ตารางที่รวมได้หนึ่งก็ยังลืมผลลัพธ์สำคัญได้ การย้ายโอกาสแค่ 0.01 ไปไว้ที่กรณี gap −5R ทำให้กำไรเฉลี่ยลดจาก 0.05R เหลือ 0.01R

หน้านี้ใช้การ “คูณผลด้วยโอกาสแล้วบวกกัน” ไปสองครั้ง ตอนคิดกำไรเฉลี่ย \$50 และตอนเทียบผลของ gap หน้าถัดไป expected value จะทำให้การคิดแบบนี้เป็นเครื่องมือเต็มตัว และตอบว่ากำไรเฉลี่ยที่เป็นบวกบอกอะไรและไม่บอกอะไร
