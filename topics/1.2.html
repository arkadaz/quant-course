1.2 Discrete Random Variables and the Probability Mass Function (PMF)

สร้างแบบจำลองจากผลลัพธ์ทีละกรณี ก่อนนำโอกาสมารวมกัน

กลยุทธ์หนึ่งมีโอกาสขาดทุน 55% เท่าทุน 15% และกำไร 30% ถ้าถามว่า “มีโอกาสไม่ขาดทุนเท่าไร” คำตอบคือ 30% หรือ 45%? แล้วการแพ้บ่อยกว่าชนะบอกได้แล้วหรือยังว่ากลยุทธ์ไม่คุ้ม?

เราจะตอบด้วยตารางที่เก็บทั้งผลลัพธ์และโอกาสของแต่ละกรณี เรียกว่า Probability Mass Function (PMF) ตารางนี้เป็นข้อมูลชุดเดียวกับ CDF ในบทเรียนก่อน แต่แทนที่จะเก็บยอดสะสม เราเก็บน้ำหนักของแต่ละค่าแยกกัน

เริ่มให้ถูก: เรากำลังวัดราคา ผลตอบแทน หรือกำไรขาดทุน

ในบทเรียนนี้ เราวัดกำไรขาดทุนของการซื้อขายหนึ่งครั้ง ไม่ใช่ราคาหุ้นโดยตรง สมมติว่าซื้อ TSLA 200 หุ้นที่ราคา \$200 ตั้งระดับขายตัดขาดทุนไว้ที่ \$195 และตั้งเป้าขายทำกำไรที่ \$210 ยังไม่คิดค่าธรรมเนียมหรือความคลาดเคลื่อนของราคาที่ซื้อขายได้

เราจะใช้เงินที่วางแผนเสี่ยงเป็นหน่วยเปรียบเทียบ เรียกว่า 1R หากวางแผนเสี่ยง \$1,000 แล้วได้กำไร \$2,000 ผลลัพธ์คือ +2R วิธีนี้ทำให้เปรียบเทียบการซื้อขายที่มีขนาดเงินต่างกันได้ แต่ 1R ไม่ใช่เพดานขาดทุนที่ตลาดรับประกัน

ขั้นที่ 1 — แปลงแผนซื้อขายเป็นผลลัพธ์ในหน่วย R

ให้ $X$ เป็นกำไรขาดทุนหารด้วยเงินที่วางแผนเสี่ยง ผลลัพธ์ของ $X$ เป็นตัวเลขที่บอกว่าได้หรือเสียกี่เท่าของ 1R

\[ \begin{aligned} 1R&=200(\$200-\$195)=\$1{,}000\\ X&=\frac{\text{P\&L}}{\$1{,}000}\\ X_{\text{stop}}&=\frac{200(195-200)}{1{,}000}=-1\\ X_{\text{flat}}&=\frac{200(200-200)}{1{,}000}=0\\ X_{\text{target}}&=\frac{200(210-200)}{1{,}000}=2 \end{aligned} \]

ผลลัพธ์ที่ใช้ในแบบจำลองมีสามค่า: −1, 0 และ +2 ในหน่วย R ตัวแปรที่ค่าที่เป็นไปได้นับไล่เป็นค่า ๆ ได้เรียกว่า discrete random variable ไม่จำเป็นต้องมีค่าได้เพียงไม่กี่ค่า เช่น จำนวนเหตุการณ์ 0, 1, 2, … ก็เป็น discrete แม้จะไม่กำหนดค่าสูงสุด

โจทย์ให้โอกาสของทั้งสามผลลัพธ์

ผลลัพธ์ $x$กำไรขาดทุนโอกาส $p(x)$ความหมาย
−1R−\$1,0000.55ขายที่ระดับตัดขาดทุนตามแบบจำลอง
0R\$00.15ขายเท่าราคาซื้อ ก่อนคิดค่าใช้จ่าย
+2R+\$2,0000.30ขายถึงเป้ากำไรตามแบบจำลอง

โอกาสทั้งสามเป็นสมมติฐานสำหรับฝึกคำนวณ ไม่ใช่ผล backtest ที่ยืนยันแล้ว การใช้ตารางกับตลาดจริงต้องตรวจทั้งค่าที่อาจเกิดและโอกาสของแต่ละค่า

ขั้นที่ 2 — ตรวจว่าตารางเป็น PMF ที่ถูกต้องหรือไม่

นิยาม $p(x)=P(X=x)$ คือโอกาสที่ได้ผลลัพธ์ $x$ พอดี ผลลัพธ์ต่างค่ากันไม่เกิดพร้อมกันในการซื้อขายครั้งเดียว จึงบวกโอกาสของแต่ละแถวได้โดยไม่นับซ้ำ

\[ \begin{aligned} p(x)&\equiv P(X=x)\\ p(x)&\ge0\quad\text{for every }x\\ \sum_{\text{all }x}p(x)&=1\\[3pt] p(-1)+p(0)+p(2)&=0.55+0.15+0.30\\ &=1.00 \end{aligned} \]

เงื่อนไขแรกห้ามโอกาสติดลบ เงื่อนไขที่สองให้โอกาสของทุกผลลัพธ์รวมกันเป็นหนึ่ง ตารางจึงผ่านเงื่อนไขทางคณิตศาสตร์ สำหรับค่าที่ไม่อยู่ในแบบจำลอง เช่น +1R เรากำหนด $p(1)=0$

ถ้าผลรวมไม่เท่ากับหนึ่ง อาจเกิดจากตกหล่น นับซ้ำ ใส่ตัวเลขผิด หรือปัดเศษมากเกินไป ต้องหาสาเหตุก่อนใช้ แต่แม้รวมได้หนึ่ง ก็ยังไม่ได้พิสูจน์ว่าแบบจำลองครอบคลุมโลกจริง เราจะกลับมาดูข้อจำกัดนี้หลังคำนวณตัวอย่างหลัก

Worked Example — ชนะกับไม่ขาดทุนเป็นคนละเหตุการณ์

ของที่มี: PMF สามแถวข้างต้น

คำถาม: หาโอกาสชนะ โอกาสไม่ขาดทุน และโอกาสขาดทุน แล้วตรวจว่าคำตอบเข้ากันได้หรือไม่

ก่อนคำนวณ ให้เขียนแถวที่เข้าแต่ละเงื่อนไข: “ชนะ” มีเฉพาะ +2R ส่วน “ไม่ขาดทุน” รวม 0R ด้วย และ “ขาดทุน” มีเฉพาะ −1R

ขั้นที่ 3 — รวมเฉพาะแถวที่ตอบคำถาม

\[ \begin{aligned} P(X\gt0)&=p(2)=0.30\\ P(X\ge0)&=p(0)+p(2)\\ &=0.15+0.30=0.45\\ P(X\lt0)&=p(-1)=0.55\\[3pt] P(X\ge0)+P(X\lt0)&=0.45+0.55=1 \end{aligned} \]

คำตอบคือชนะ 30% ไม่ขาดทุน 45% และขาดทุน 55% สองเหตุการณ์หลังแบ่งผลลัพธ์ทุกแถวออกเป็นสองกลุ่มพอดี จึงตรวจกลับได้ว่าโอกาสรวมเป็นหนึ่ง ส่วน “ชนะ” กับ “ขาดทุน” รวมได้เพียง 85% เพราะยังไม่รวมแถวเท่าทุน

ตรวจคำตอบก่อนตีความว่ากลยุทธ์คุ้มหรือไม่

ตรวจเองใน 10 วินาที: โอกาสไม่ขาดทุนต้องไม่น้อยกว่าโอกาสชนะ เพราะกลุ่มแรกครอบคลุมกลุ่มหลัง หากคำนวณได้กลับกัน ให้ตรวจว่าเผลอตัดแถว 0R ทิ้งหรือไม่

แปลว่าอะไร: อัตราชนะอย่างเดียวตัดสินความคุ้มไม่ได้ ในตารางนี้ การชนะเพิ่มกำไรเฉลี่ย $2(0.30)=0.60R$ ส่วนการแพ้ลดลง $1(0.55)=0.55R$ จึงเหลือ $0.05R$ ก่อนหักค่าใช้จ่าย นี่คือ expected value ซึ่งจะพัฒนาเต็มในหัวข้อ 1.3 ไม่ใช่ผลกำไรที่รับประกันในครั้งถัดไป

เชื่อมกลับไปยัง CDF ที่เพิ่งเรียน

PMF กับ CDF ไม่ใช่แบบจำลองคู่แข่งกัน PMF แยกโอกาสทีละค่า ส่วน CDF รวมทุกค่าที่ไม่เกินเกณฑ์ เมื่อตั้งเกณฑ์ที่ 0R จึงต้องรวมทั้ง −1R และ 0R ไม่ใช่หยิบเฉพาะน้ำหนักของแถว 0R

ขั้นที่ 4 — สร้าง CDF จาก PMF

\[ \begin{aligned} F(-1)&=p(-1)=0.55\\ F(0)&=p(-1)+p(0)=0.70\\ F(2)&=p(-1)+p(0)+p(2)=1\\[3pt] F(x)&=\sum_{t\le x}p(t) \end{aligned} \]

ตัวอักษร $t$ ในผลรวมใช้ไล่ค่าที่เป็นไปได้ของ $X$ แล้วเลือกเฉพาะค่าที่ไม่เกิน $x$ เช่น ถ้าถาม $F(1)$ จะรวม −1R กับ 0R ได้ 0.70 เช่นเดียวกับ $F(0)$ เพราะในแบบจำลองไม่มีผลลัพธ์อยู่ระหว่าง 0R กับ +2R

ขั้นที่ 5 — ดึง PMF กลับจากขั้นกระโดดของ CDF

ให้ $F(x^-)$ เป็นยอดสะสมก่อนถึง $x$ ซึ่งยังไม่รวมค่านั้น เมื่อลบออกจากยอดที่รวม $x$ แล้ว จึงเหลือโอกาสของ $x$ เพียงค่าเดียว

\[ \begin{aligned} F(x)&=F(x^-)+P(X=x)\\ p(x)&=F(x)-F(x^-)\\[3pt] p(-1)&=0.55-0=0.55\\ p(0)&=0.70-0.55=0.15\\ p(2)&=1.00-0.70=0.30 \end{aligned} \]

ผลลัพธ์กลับมาตรงกับ PMF เดิมครบทุกค่า สำหรับข้อมูล discrete โอกาสที่จุดหนึ่งคือความสูงของขั้นกระโดด ไม่ใช่ความชันระหว่างขั้น ส่วนการเชื่อม CDF กับ density ของแบบ continuous เป็นอีกกรณีหนึ่งในหัวข้อ 1.8

จากครั้งเดียวไปหลายครั้ง: ยังขาดข้อมูลอีกอย่างหนึ่ง

การรู้ว่าโอกาสแพ้แต่ละครั้งเป็น 55% ยังไม่พอหาโอกาสแพ้ห้าครั้งติดกัน เราต้องรู้ด้วยว่าผลครั้งก่อนเปลี่ยนโอกาสครั้งต่อไปหรือไม่ หากผลเป็นอิสระต่อกัน หรือมี independence เราจึงใช้โอกาส 0.55 เดิมในทุกขั้นของการคูณได้

ตัวอย่างง่าย ๆ: หลังผ่านเงื่อนไขว่าแพ้ครั้งแรกแล้ว ภายใต้ independence โอกาสแพ้ครั้งที่สองยังเป็น 0.55 โอกาสแพ้ทั้งสองจึงเท่ากับ $0.55(0.55)$ ทำเช่นนี้ต่อจนครบห้าครั้ง

ขั้นที่ 6 — หาโอกาสแพ้ทั้งหมดในชุดห้าครั้งที่กำหนดไว้

\[ \begin{aligned} P(\text{5 losses})&=0.55^5\\ 0.55^2&=0.3025\\ 0.55^4&=0.3025^2=0.09150625\\ 0.55^5&=0.09150625(0.55)\\ &=0.0503284375\approx5.03\% \end{aligned} \]

สำหรับชุดห้าครั้งที่กำหนดไว้ล่วงหน้า แบบจำลองให้โอกาสแพ้ทั้งหมดประมาณ 5.03% ถ้าพิจารณาหลายชุดที่มีโอกาสเดียวกัน จะคาดว่าจะพบชุดแพ้ทั้งหมดประมาณห้าชุดต่อร้อยชุด แต่จำนวนจริงไม่จำเป็นต้องตรงนี้

ห้ามอ่านผลนี้ว่า “ในหนึ่งร้อยครั้ง มีโอกาสแพ้ห้าครั้งติดสักช่วงหนึ่งเพียง 5.03%” เพราะหนึ่งร้อยครั้งมีช่วงห้าครั้งให้เริ่มนับได้หลายตำแหน่ง นั่นเป็นเหตุการณ์อีกแบบที่ต้องคำนวณต่างออกไป

ถ้าความเป็นอิสระไม่จริง คำตอบเปลี่ยนอย่างไร

สมมติว่าโอกาสแพ้ครั้งแรกยังเป็น 0.55 แต่เมื่อแพ้มาแล้ว โอกาสแพ้ครั้งถัดไปภายใต้ประวัติที่แพ้ต่อเนื่องเพิ่มเป็น 0.70 ทั้งสี่ครั้งที่เหลือ โอกาสแพ้ทั้งหมดจึงเป็น $0.55(0.70)^4=0.132055$ หรือประมาณ 13.21%

ตัวเลขนี้สูงกว่า 5.03% เพราะสมมติฐานเปลี่ยน เราไม่ได้อ้างว่าผู้เทรดหรือตลาดมีพฤติกรรมเช่นนี้จริง จุดประสงค์คือแสดงว่า PMF ของครั้งเดียวไม่บอกความสัมพันธ์ระหว่างหลายครั้ง

ตรวจเองใน 10 วินาที: เมื่อเปลี่ยนตัวคูณสี่ตัวจาก 0.55 เป็น 0.70 โอกาสรวมต้องเพิ่มขึ้น ถ้าคำตอบลดลง แสดงว่าคำนวณหรือใส่เงื่อนไขผิด

PMF รวมได้หนึ่ง แต่ยังขาดเหตุการณ์สำคัญได้

ซื้อหุ้นที่ \$100 และวางระดับตัดขาดทุนที่ \$98 เท่ากับวางแผนเสี่ยงหุ้นละ \$2 แต่หากราคากระโดดลงและขายได้จริงที่ \$90 จะขาดทุนหุ้นละ \$10 หรือ $10/2=5R$ ผลลัพธ์ −5R ไม่อยู่ใน PMF เดิมที่ตั้งขาดทุนไว้เพียง −1R

stop-market order เปลี่ยนเป็นคำสั่งซื้อขายที่ราคาตลาดเมื่อถึงเงื่อนไข จึงไม่รับประกันราคาที่ได้ ส่วน stop-limit order จำกัดราคาที่รับได้ แต่คำสั่งอาจไม่สำเร็จหากตลาดผ่านราคานั้นไปแล้ว ทั้งสองแบบไม่ได้ทำให้ความเสี่ยงหายไป

เมื่อเพิ่มเหตุการณ์ gap ต้องจัดน้ำหนักใหม่ให้ทั้งตาราง ไม่ใช่เติมอีกหนึ่งแถวแล้วปล่อยให้โอกาสรวมเกินหนึ่ง และต้องมีข้อมูลหรือสมมติฐานรองรับว่าโอกาสของเหตุการณ์ใหม่มาจากไหน

ขั้นที่ 7 — ลองปรับแบบจำลองโดยไม่ทำให้โอกาสเกินหนึ่ง

เพื่อเห็นผลของแถวที่ตกหล่น สมมติใหม่ว่าในโอกาสขาดทุนเดิม 0.55 มีส่วน 0.01 ที่ขาดทุน −5R แทน −1R ส่วนโอกาสเท่าทุนและกำไรยังเท่าเดิม นี่เป็นตัวเลขสมมติ ไม่ใช่ค่าประมาณ gap ของ TSLA

\[ \begin{aligned} p(-5)&=0.01,\qquad p(-1)=0.54\\ p(0)&=0.15,\qquad p(2)=0.30\\ \sum_x p(x)&=0.01+0.54+0.15+0.30=1\\[3pt] \text{average P\&L} &=(-5)(0.01)+(-1)(0.54)+2(0.30)\\ &=-0.05-0.54+0.60=0.01R \end{aligned} \]

โอกาสแพ้รวมยังเป็น 55% เหมือนเดิม แต่กำไรเฉลี่ยลดจาก 0.05R เหลือ 0.01R เพราะขนาดขาดทุนบางกรณีเพิ่มขึ้น จึงเห็นว่าการดูอัตราชนะหรืออัตราแพ้อย่างเดียวอาจพลาดส่วนที่สำคัญต่อความคุ้มและความเสี่ยง

ลองทำเอง 1 — ค่าที่ต่างกันไม่จำเป็นต้องมีโอกาสเท่ากัน

ของที่มี: คูปองห้าใบ ได้แก่ส่วนลด \$1 สามใบ \$5 หนึ่งใบ และ \$10 หนึ่งใบ สุ่มหยิบหนึ่งใบโดยทุกใบมีโอกาสเท่ากัน

คำถาม: เขียน PMF ของส่วนลด แล้วหาโอกาสได้ส่วนลดอย่างน้อย \$5 ทำไมจึงไม่ใช่ 2/3?

เปิดคำตอบ

$p(1)=3/5$, $p(5)=1/5$ และ $p(10)=1/5$ จึงได้โอกาสส่วนลดอย่างน้อย \$5 เท่ากับ $1/5+1/5=2/5=40\%$

ส่วนลดมีสามค่าที่ต่างกัน แต่ไม่ได้มีน้ำหนักเท่ากัน หน่วยที่ถูกสุ่มอย่างเท่าเทียมคือคูปองแต่ละใบ ไม่ใช่ชื่อส่วนลดแต่ละค่า

ลองทำเอง 2 — ไม่แพ้บ่อยกว่า แปลว่าดีกว่าเสมอหรือไม่

ของที่มี: อีกกลยุทธ์ให้ −1R, 0R และ +1R ด้วยโอกาส 0.40, 0.20 และ 0.40 ตามลำดับ สมมติให้แต่ละครั้งเป็นอิสระ

คำถาม: ตรวจ PMF หาโอกาสไม่ขาดทุน โอกาสแพ้ทั้งหมดในชุดห้าครั้ง และกำไรเฉลี่ยก่อนหักค่าใช้จ่าย แล้วเปรียบเทียบกับแบบจำลองเดิม

เปิดวิธีคิดและคำตอบ

โอกาสรวม $0.40+0.20+0.40=1$ และไม่ติดลบ โอกาสไม่ขาดทุนคือ $0.20+0.40=0.60$ ส่วนโอกาสแพ้ทั้งหมดในชุดห้าครั้งคือ $0.40^5=0.01024$ หรือ 1.024%

กำไรเฉลี่ยคือ $(-1)(0.40)+0(0.20)+1(0.40)=0R$ แม้โอกาสไม่ขาดทุนสูงกว่าและแพ้ห้าครั้งติดยากกว่า ก็ยังไม่มีค่าเฉลี่ยบวกก่อนหักค่าใช้จ่าย การตัดสินกลยุทธ์จึงต้องดูทั้งจำนวนเงิน โอกาส และข้อจำกัดของแบบจำลอง

ตรวจเองใน 10 วินาที: โอกาสชนะกับแพ้เท่ากันและขนาดเงินเท่ากัน จึงต้องหักล้างกันในค่าเฉลี่ย ถ้าได้ค่าเฉลี่ยบวกหรือลบโดยยังไม่คิดค่าใช้จ่าย ให้ตรวจการแทนค่า

นำไปใช้จริงโดยไม่ลืมว่าตารางเป็นแบบจำลอง

ถ้าจะสร้าง PMF จาก backtest ให้แยกสองงาน: ตรวจว่าข้อมูลและวิธีจำลองการซื้อขายถูกต้อง แล้วจึงนับสัดส่วนของผลลัพธ์ ตัวเลขที่ได้ยังมีความไม่แน่นอนจากข้อมูลจำกัด และอาจเปลี่ยนเมื่อสภาพตลาดหรือกลยุทธ์เปลี่ยน

PMF ยังใช้หาเงินรับเฉลี่ยของสัญญาได้ เช่น สัญญาที่จ่าย \$100 เฉพาะกรณี +2R ให้เงินรับคาดหวัง $100(0.30)=\$30$ แต่การตั้งราคาสัญญาต้องพิจารณาเวลาและความเสี่ยงเพิ่มเติม อย่าเรียกเงินรับเฉลี่ยว่าราคายุติธรรมโดยไม่ระบุเงื่อนไข

คำสำคัญสำหรับทบทวน
PMF / CDF
PMF ให้โอกาสของแต่ละค่า ส่วน CDF บวกโอกาสสะสมจนถึงเกณฑ์ ค่าสองตัวนี้ไม่ใช่คำตอบเดียวกัน แต่แปลงกลับไปมาได้สำหรับแบบจำลอง discrete
R-multiple / P&L
R-multiple คือกำไรขาดทุนหารด้วยเงินที่วางแผนเสี่ยง P&L คือกำไรหรือขาดทุนที่ต้องระบุว่าหักค่าใช้จ่ายแล้วหรือยัง
breakeven / take-profit / stop-loss
ผลเท่าทุน เป้าหมายทำกำไร และระดับตัดขาดทุนตามลำดับ ระดับที่ตั้งไว้เป็นแผน ไม่ใช่ข้อรับประกันราคาที่ซื้อขายสำเร็จ
independence
การที่รู้ผลครั้งหนึ่งแล้วไม่เปลี่ยนโอกาสของอีกครั้ง เป็นเงื่อนไขที่ใช้คูณโอกาสเดิมซ้ำในตัวอย่างแพ้ห้าครั้ง
gap / regime
gap คือราคากระโดดผ่านช่วงหนึ่ง ส่วน regime หมายถึงสภาวะตลาดที่มีลักษณะบางอย่างต่อเนื่อง ทั้งสองเตือนให้ตรวจว่าแบบจำลองเดิมยังเหมาะสมหรือไม่
edge / expected value
expected value คือค่าเฉลี่ยที่ถ่วงด้วยโอกาส ส่วน edge คือความได้เปรียบที่ต้องประเมินหลังต้นทุนและภายใต้สมมติฐานที่น่าเชื่อถือ ค่าเฉลี่ยบวกไม่รับประกันกำไรทุกครั้ง
สัญลักษณ์ที่ใช้
สัญลักษณ์ความหมาย
$X$ / $x$ผลลัพธ์ที่ขึ้นอยู่กับผลสุ่ม / ค่าหนึ่งที่กำลังถาม โดยใช้ R เป็นหน่วยเปรียบเทียบ
$p(x)$โอกาสที่ผลลัพธ์เท่ากับ $x$ พอดี
$F(x)$ / $F(x^-)$ยอดสะสมถึง $x$ / ยอดก่อนถึง $x$ ที่ยังไม่รวมค่านั้น
$\sum_{t\le x}p(t)$รวมโอกาสของทุกค่าที่ไม่เกินเกณฑ์ $x$
ตรวจ PMF, CDF และโอกาสแพ้ต่อเนื่องด้วย JavaScript 
const pmf = [[-1, 0.55], [0, 0.15], [2, 0.30]];
const total = pmf.reduce((s, [x, p]) => s + p, 0);
const valid = pmf.every(([x, p]) => p >= 0)
  && Math.abs(total - 1) < 1e-12;
const probability = test =>
  pmf.filter(([x]) => test(x)).reduce((s, [x, p]) => s + p, 0);
console.log(valid);                         // true
console.log(probability(x => x >= 0));     // ประมาณ 0.45
console.log(probability(x => x <= 0));     // ประมาณ 0.70
console.log(0.55 ** 5);                     // 0.0503284375
console.log(0.55 * 0.70 ** 4);              // ประมาณ 0.132055
console.log(-5 * 0.01 - 0.54 + 2 * 0.30);   // ประมาณ 0.01

โค้ดตรวจตัวเลขตามสมมติฐานที่ให้ ไม่ได้พิสูจน์ว่าโอกาสหรือ independence เหล่านี้ตรงกับตลาดจริง

สรุป — ตรวจตารางก่อนคำนวณ และตรวจสมมติฐานก่อนเชื่อผล

  • PMF ระบุโอกาสของผลลัพธ์แต่ละค่า ต้องไม่มีน้ำหนักติดลบ และน้ำหนักรวมต้องเท่ากับหนึ่ง
  • การหาโอกาสของเหตุการณ์เริ่มจากเลือกแถวที่เข้าเงื่อนไขให้ถูก เช่น ไม่ขาดทุนต้องรวมแถวเท่าทุนด้วย
  • CDF คือผลรวมสะสมของ PMF ส่วน PMF คือความสูงของขั้นกระโดดใน CDF
  • โอกาสของครั้งเดียวไม่บอกความสัมพันธ์หลายครั้ง สูตร $0.55^5$ ต้องมีสมมติฐาน independence และกำหนดเหตุการณ์ให้ชัด
  • ตารางที่ถูกต้องทางคณิตศาสตร์ยังอาจขาดเหตุการณ์สำคัญในโลกจริง อัตราชนะเท่าเดิมก็มีค่าเฉลี่ยและความเสี่ยงต่างกันได้

ต่อไปเราจะนำผลลัพธ์แต่ละค่าคูณกับโอกาสอย่างเป็นระบบ เพื่อหาว่าค่าเฉลี่ยบอกอะไรเกี่ยวกับกลยุทธ์ และเหตุใดค่าเฉลี่ยบวกจึงไม่ใช่คำรับประกันกำไร
