11.1 Definition of Geometric Brownian Motion (GBM)

เปลี่ยนการเดินแบบบวกให้เป็นการเติบโตแบบคูณ

เงินออม 100 USD เพิ่ม 10% แล้วลด 10% วันถัดไป คุณคิดว่าจะกลับมา 100 USD หรือไม่?

เฉลย: มันเป็น 99 USD เพราะการเปลี่ยนแบบร้อยละคูณกับยอดปัจจุบัน ไม่ได้บวกจำนวนเงินคงที่

Geometric Brownian motion (GBM) ให้การเปลี่ยนเล็ก ๆ เป็นสัดส่วนของค่าปัจจุบันพร้อมส่วนสุ่มจาก Brownian motion เปอร์เซ็นต์เป็นบันไดเลื่อน ไม่ใช่บันไดปูน; งานจริงใช้ GBM เป็น baseline สำหรับตัวแปรบวกและ simulation ของผลตอบแทน

Geometric Brownian Motion (GBM)
stochastic process ที่ให้ราคาเป็นค่าเริ่มต้นคูณ exponential ของ trend และ shock สุ่ม ใช้สร้าง paths ที่เป็นบวกสำหรับ simulation และเป็นฐานของ option model
drift
อัตราเติบโตเฉลี่ยของราคาต่อหน่วยเวลาใน price process ใช้กำหนด expected future price ภายใต้ probability measure ที่ระบุ
volatility
ขนาดการกระจายของ percent return ต่อรากที่สองของเวลา ใช้วัดความไม่แน่นอนของราคาและสเกล shock ให้ถูกกับ horizon
log return
ค่า logarithm ของอัตราส่วนราคาปลายงวดต่อราคาเริ่มงวด ใช้เปลี่ยนการคูณของ returns ให้เป็นการบวกและทำให้ GBM เขียนง่าย
Monte Carlo
วิธีสร้าง random paths จำนวนมากแล้วเฉลี่ย payoff หรือ loss ใช้ประเมินราคาหรือความเสี่ยงเมื่อคำตอบปิดรูปหาได้ยาก
limited liability
กติกาที่ผู้ถือหุ้นขาดทุนได้ไม่เกินเงินที่จ่ายซื้อหุ้น ใช้อธิบายว่าราคาหุ้นควรมี lower bound ที่ศูนย์
stochastic process
ลำดับของ random variables ที่ถูกจัดตามเวลา ใช้แทนวิวัฒนาการของราคาและความเสี่ยงบนทุก horizon
stochastic differential equation (SDE)
สมการที่มีทั้ง deterministic time term และ Brownian random term ใช้ระบุ dynamics ต่อช่วงเวลาที่เล็กมากของราคา
Markov process
process ที่ conditional distribution ของอนาคตขึ้นกับ state ปัจจุบันโดยไม่ต้องเก็บอดีตทั้งหมด ใช้ลด memory ของ simulation engine
standard deviation
รากที่สองของ variance ซึ่งวัดขนาดการกระจายรอบค่าเฉลี่ย ใช้แปล volatility เป็น uncertainty ตาม horizon
variance
ค่าเฉลี่ยของ squared deviations รอบ mean ใช้วัดการกระจายของ random shock ก่อนแปลงเป็น standard deviation
payoff
เงินที่ contract หรือ position จ่ายเมื่อถึง state หรือวันกำหนด ใช้แปลง simulated price path เป็นมูลค่าที่ต้องประเมิน
slippage
ส่วนต่างระหว่างราคาที่คาดว่าจะได้กับราคาที่ execute จริง ใช้หัก execution cost ออกจาก model P&L

ลองทำ

worked example — scenario และ position P&L

ถือหุ้นสมมติ 20,000 shares ที่ราคา 100 USD จึงมี market value 2,000,000 USD. จาก draw บวก 0.80 ราคา scenario เป็น 101.54 USD และ one-day P&L เป็น 30,800 USD ก่อน fees และ slippage. Inputs เป็น annual convention; ถ้าขยายเป็นสิบวันต้องตั้ง horizon ใหม่เป็นสิบ trading days ไม่ใช่คูณ daily multiplier เดิมซ้ำด้วย draw เดิม.

ลองตอบก่อนราคา scenario USD 101.54 ทำให้ position 20,000 shares กำไรเท่าไรจากราคาเริ่ม USD 100?

ของที่โจทย์ให้20,000 shares, ราคาเริ่ม USD 100, ราคา scenario USD 101.54. ยังไม่หัก fee หรือ slippage.

1. คูณ 20,000 ด้วย USD 101.54 ได้ market value ใหม่ USD 2,030,800. เพราะต้อง mark หุ้นทุก share ด้วยราคาใหม่.

2. ลบมูลค่าเริ่ม USD 2,000,000 ออก ได้ P&L USD 30,800.

เฉลย: draw บวก 0.80 ให้กำไรหนึ่งวัน USD 30,800 ใน scenario นี้.

เช็ก 10 วินาที: ราคาเพิ่ม USD 1.54 ต่อ share; USD 1.54 × 20,000 = USD 30,800.

งานจริง: เปลี่ยน horizon ก่อน run หลายวัน เพราะ draw เดิมห้ามถูกนำไปคูณซ้ำแบบไม่เปลี่ยนเวลา.

กับดัก: อย่าเรียก scenario draw หนึ่งครั้งว่า expected return หรือปล่อยให้ fee กับ slippage หายไปจาก P&L.

ระวังตรงนี้

กับดัก: ใช้ Euler แบบราคาตรง ๆ แล้วคิดว่าเหมือน GBM

การอัปเดต เป็น approximation ที่ยังติดลบได้เมื่อ shock ต่ำพอ. สำหรับ GBM ใช้ exact exponential transition ข้างบน; จึงได้ positivity และ distribution ที่ถูกต้องในทุก step size.

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
ความผันผวนคงที่ความผันผวนไม่เปลี่ยนเปลี่ยนตลอดและเกาะกลุ่มราคา option ที่คำนวณได้ไม่ตรงตลาด เกิดเป็นรอยยิ้มในหัวข้อ 13.5
ไม่มีการกระโดดราคาเดินต่อเนื่องกระโดดตอนมีข่าวความเสี่ยงของเหตุการณ์เดียวถูกประเมินต่ำมาก
ผลตอบแทนเป็นระฆังคว่ำlog return เป็นระฆังคว่ำหางอ้วนกว่าชัดเจนวันที่แย่ที่สุดเกิดบ่อยกว่าที่แบบจำลองบอกหลายเท่า
สามแถวนี้เป็นที่มาของแบบจำลองขั้นสูงทั้งหมดในบทที่ 13

สรุปที่ใช้ได้จริง

  • GBM ทำให้ราคาบวกเสมอและ shocks เป็น percent moves
  • คือ price drift แต่ log drift เท่ากับ
  • exact transition ใช้ สำหรับ drift และ สำหรับ noise
  • ผล USD ต้องมาจาก simulated price คูณ position หลังล็อก units และ horizon
