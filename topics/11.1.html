11.1 Setting Up the Hedging Problem

ซื้อชุดหุ้นกับพันธบัตรที่ถูกที่สุดซึ่งรับประกันว่าจ่ายลูกค้าได้ครบไม่ว่าตลาดไปทางไหน โจทย์นี้คือ linear program ที่มีอสมการหนึ่งข้อต่อตลาดหนึ่งแบบ และคำตอบอยู่ที่มุมซึ่งพิสูจน์ตัวเองได้ด้วยน้ำหนักสองตัว

โต๊ะเทรด (ทีมในธนาคารที่ซื้อขายในตลาดและขายสัญญาให้ลูกค้า) เพิ่งขายสัญญาฉบับหนึ่ง สัญญานี้บอกว่าปีหน้าโต๊ะต้องจ่ายเงินให้ลูกค้า โดยจำนวนเงินขึ้นกับว่าตลาดหุ้นไปทางไหน เงินที่ต้องจ่ายนี้เรียกว่า “ภาระ” โต๊ะไม่อยากเดาทางตลาด จึงจะซื้อของชุดหนึ่งไว้วันนี้ ให้เงินที่ของชุดนั้นจ่ายปีหน้าพอจ่ายภาระได้ครบทุกกรณี ของชุดนี้เรียกว่า hedge

เพื่อให้คิดง่าย สมมติว่าปีหน้าตลาดเป็นได้แค่สามแบบ คือ ขึ้น ทรงตัว และลง (หน้านี้เรียกแต่ละแบบว่า “สภาวะ”) ของที่รู้ (ตัวเลขสมมติทั้งหมด):

  • ภาระปีหน้า $X$: \$120 ถ้าตลาดขึ้น \$90 ถ้าทรงตัว และ \$50 ถ้าลง
  • หุ้น: ราคาวันนี้ \$100 ปีหน้าเป็น \$130, \$100 หรือ \$70 ตามสภาวะ
  • พันธบัตร (สัญญากู้ที่ผู้ออกสัญญาว่าจะคืนเงินจำนวนแน่นอน): ราคาวันนี้ \$95 ปีหน้าคืน \$100 ทุกสภาวะ
  • ของทั้งสองอย่างซื้อได้ และ short ได้ การ short คือยืมของมาขายวันนี้เพื่อรับเงิน แล้วปีหน้าต้องคืนของนั้น หรือจ่ายเงินเท่ามูลค่าของมันในปีหน้า

เพื่อนร่วมโต๊ะเสนอว่า “ทำให้สองกรณีสุดขั้ว (ขึ้นกับลง) จ่ายพอดี กรณีกลางก็น่าจะรอดเอง” แผนของเพื่อนใช้เงินวันนี้ \$86.58 (หน้านี้จะคำนวณตัวเลขนี้ให้ดูในขั้นที่ 5) คำถามคือ แผนของเพื่อนจ่ายครบจริงไหม และวันนี้ต้องใช้เงินอย่างน้อยเท่าไรจึงจ่ายได้ครบทุกสภาวะ?

ลองตอบก่อนเปิดเฉลย

แผนของเพื่อนไม่ครบ และเงินขั้นต่ำคือ \$90.50 แผนของเพื่อนคือซื้อหุ้น $\tfrac76$ หุ้น และ short พันธบัตร $\tfrac{19}{60}$ หน่วย ปีหน้าแต่ละสภาวะได้เงินเท่านี้

\[\begin{aligned}\text{up}&=130\cdot\tfrac76-100\cdot\tfrac{19}{60}\\&=151.67-31.67=120,\\\text{flat}&=100\cdot\tfrac76-31.67\\&=116.67-31.67=85,\\\text{down}&=70\cdot\tfrac76-31.67\\&=81.67-31.67=50.\end{aligned}\]

กรณีทรงตัวได้ \$85 แต่ต้องจ่าย \$90 จึงขาด $90-85=\$5$ ต้นเหตุคือราคาหุ้นกรณีทรงตัว \$100 อยู่กึ่งกลางของ \$130 กับ \$70 พอดี และพันธบัตรจ่ายเท่ากันทุกสภาวะ เงินที่พอร์ตใด ๆ ได้ในกรณีทรงตัวจึงเท่ากับค่าเฉลี่ยของกรณีขึ้นกับกรณีลงเสมอ ได้ $\tfrac12(120+50)=85$

แผนที่ถูกที่สุดที่จ่ายครบคือซื้อหุ้น 1 หุ้น และ short พันธบัตร 0.1 หน่วย ปีหน้าหุ้นให้ \$130, \$100, \$70 แล้วหักค่าคืนพันธบัตร $0.1\times100=\$10$ เหลือ \$120, \$90, \$60 ซึ่งครบทุกสภาวะ เงินที่ใช้วันนี้คือ

\[\begin{aligned}\text{cost}&=1\times100-0.1\times95\\&=100-9.50=\$90.50.\end{aligned}\]

ภาพรวมก่อนลงสูตร

พอร์ต (ชุดของที่ถือ) หนึ่งพอร์ตในโจทย์นี้คือตัวเลขสองตัว $\theta_1$ คือจำนวนหุ้นที่ถือ และ $\theta_2$ คือจำนวนพันธบัตรที่ถือ ถ้าค่าใดติดลบ แปลว่า short ของชิ้นนั้น ให้ $s$ คือราคาหุ้นปีหน้า หุ้นหนึ่งหุ้นให้เงิน $s$ และพันธบัตรหนึ่งหน่วยให้ \$100 เงินที่พอร์ตได้ปีหน้า (เรียกว่า payoff) จึงเป็น

\[\text{payoff}=\theta_1 s+100\,\theta_2.\]

ถ้าวาด payoff เทียบกับ $s$ ทุกพอร์ตจะเป็นเส้นตรง ความชันของเส้นคือจำนวนหุ้น $\theta_1$ ส่วนความสูงของเส้นเลื่อนขึ้นลงตามพันธบัตร $100\,\theta_2$ ภาระของลูกค้าเป็นแค่จุดสามจุด (หนึ่งจุดต่อหนึ่งสภาวะ) โจทย์ทั้งหมดจึงพูดได้ในประโยคเดียว คือหาเส้นตรงที่ถูกที่สุดซึ่งอยู่บนหรือเหนือจุดทั้งสาม

รูปด้านล่างแสดงทั้งเรื่อง เส้นแดงคือแผนของเพื่อน มันผ่านจุดขึ้นกับจุดลงพอดี แต่จุดทรงตัวลอยอยู่เหนือเส้น ปัญหาคือสามจุดของภาระไม่อยู่บนเส้นตรงเดียวกัน จึงไม่มีเส้นไหนผ่านครบทั้งสามจุด ต้องยอมจ่ายเกินในสภาวะใดสภาวะหนึ่ง เส้นเขียวผ่านจุดขึ้นกับจุดทรงตัว และลอยเหนือจุดลง \$10 เส้นนี้คือ hedge ที่ถูกที่สุด

หน้านี้จะทำงานตามลำดับนี้

  1. เขียนโจทย์เป็น linear program (LP) คือโจทย์ที่หาค่าต่ำสุดของต้นทุนที่เป็นเส้นตรง ภายใต้อสมการเส้นตรงหนึ่งข้อต่อหนึ่งสภาวะ
  2. ตรวจว่าต้นทุนมีพื้น คือไม่มีทางได้เงินฟรีจนต้นทุนลดลงได้ไม่สิ้นสุด
  3. หาคำตอบที่มุมของพื้นที่ที่เลือกได้
  4. พิสูจน์ว่าคำตอบถูกที่สุดจริง ด้วยการเขียนต้นทุนใหม่บรรทัดเดียว

ครึ่งหลังของหน้าใช้โครงเดียวกันกับงานที่โต๊ะหุ้นเจอทุกวัน คือลด beta ของตะกร้าหุ้นภายใต้เพดานการ short (beta คือตัวเลขที่บอกว่าเมื่อตลาดขยับ 1% หุ้นกลุ่มนั้นขยับตามกี่ %)

ศัพท์ที่ใช้ในหัวข้อนี้
Hedge
ของที่ซื้อหรือ short ไว้เพื่อให้เงินที่ได้จากมันไปปิดภาระหรือความเสี่ยงที่มีอยู่ โต๊ะจะได้ไม่ต้องเดาทางตลาด
Short
ยืมของมาขายวันนี้เพื่อรับเงิน แล้วภายหลังต้องคืนของนั้น ผลคือได้เงินวันนี้ และต้องจ่ายเท่ามูลค่าของมันในอนาคต ในหน้านี้เขียนเป็นจำนวนที่ถือติดลบ
Payoff
เงินที่ของชิ้นหนึ่งหรือพอร์ตหนึ่งให้ ณ วันครบกำหนด (ในหน้านี้คือปีหน้า) แยกตามสภาวะ
สภาวะ (state)
ผลที่เป็นไปได้แบบหนึ่งของตลาดปีหน้า หน้านี้มีสามแบบ คือ ขึ้น ทรงตัว และลง
Superhedge
พอร์ตที่ payoff ไม่ต่ำกว่าภาระในทุกสภาวะ ใช้เมื่อผู้ขายสัญญาต้องจ่ายให้ได้ไม่ว่าตลาดไปทางไหน ต่างจาก replication ซึ่งต้องจ่ายเท่าภาระพอดีทุกสภาวะ
Linear program (LP)
โจทย์หาค่าต่ำสุดหรือสูงสุดของเป้าหมายที่เป็นเส้นตรง ภายใต้สมการและอสมการที่เป็นเส้นตรง ใช้ได้ที่นี่เพราะทั้งต้นทุนและ payoff ของพอร์ตคือผลรวมของราคาคูณจำนวนที่ถือ
Feasible region
แผนทั้งหมดที่ผ่านข้อจำกัดครบทุกข้อ คือพื้นที่ที่เราเลือกได้ ส่วนเป้าหมาย (เช่นต้นทุน) เป็นตัวตัดสินว่าจุดไหนในพื้นที่นั้นดีที่สุด
จุดมุม (vertex)
เมื่อมีสองตัวแปร มุมคือจุดที่ข้อจำกัดสองข้อเป็นสมการพอดีพร้อมกัน ถ้าเลื่อนเส้นต้นทุนไปทางถูกจนเกือบหลุดพื้นที่ จุดสุดท้ายที่แตะคือมุม มุมจึงเป็นตัวเลือกที่ต้องตรวจ
Arbitrage (free lunch)
พอร์ตที่ไม่มีทางเสียเงินในอนาคต แต่ได้เงินวันนี้ หรือพอร์ตที่ไม่ต้องจ่ายอะไรเลยแต่มีโอกาสได้เงิน ถ้าตลาดมีของแบบนี้ ต้นทุน hedge จะลดลงได้ไม่มีพื้น
Incomplete market
ตลาดที่มีสภาวะมากกว่าจำนวนสินทรัพย์ที่ใช้ผสมกันได้ payoff บางแบบจึงสร้างให้ตรงทุกสภาวะไม่ได้ ต้องยอมจ่ายเกินในบางสภาวะ
Beta
ตัวเลขที่บอกว่าเมื่อตลาดขยับ 1% หุ้นหรือตะกร้าหุ้นขยับตามกี่ % เช่น beta 1.10 คือตลาดขึ้น 1% ตะกร้าขึ้นราว 1.10%
Position และ notional
position คือของที่ถืออยู่หนึ่งรายการ notional คือขนาดของ position นั้นวัดเป็นดอลลาร์ เช่น short SPY \$6 ล้าน
Dollar beta
มูลค่า position คูณ beta บอกว่า position ขยับกี่ดอลลาร์เมื่อตลาดขยับ ใช้บวกลบความเสี่ยงตามตลาดของหลาย position ในหน่วยเดียวกันได้

ขั้นที่ 1 — ของที่โจทย์ให้: ราคาวันนี้ ตาราง payoff และภาระ

ก่อนคำนวณอะไร เราจัดของที่โจทย์ให้ลงเป็นเวกเตอร์และ matrix เพราะจะได้เขียนต้นทุนและ payoff ของทุกพอร์ตด้วยสูตรเดียว ทุกตัวเลขในขั้นนี้มาจากโจทย์ตรง ๆ ยังไม่มีการคำนวณ

  • $p$ คือราคาวันนี้ ตัวบนเป็นหุ้น (\$100) ตัวล่างเป็นพันธบัตร (\$95)
  • $X$ คือภาระปีหน้า เรียงจากบนลงล่างเป็น ขึ้น ทรงตัว ลง
  • $S$ คือตาราง payoff ปีหน้า แต่ละแถวคือหนึ่งสภาวะ แต่ละคอลัมน์คือสินทรัพย์หนึ่งตัว เราวางแบบนี้เพราะเดี๋ยวจะคูณ $S$ กับจำนวนที่ถือ $\theta$ แล้วได้ payoff ของทั้งพอร์ตทีละสภาวะ
\[ \begin{aligned} p&=\begin{bmatrix}100\\95\end{bmatrix},\qquad X=\begin{bmatrix}120\\90\\50\end{bmatrix},\\ S&=\begin{bmatrix}130&100\\100&100\\70&100\end{bmatrix},\qquad \theta=\begin{bmatrix}\theta_1\\\theta_2\end{bmatrix}. \end{aligned} \]

คอลัมน์แรกของ $S$ คือหุ้นหนึ่งหุ้น ซึ่งปีหน้าให้ \$130, \$100 หรือ \$70 คอลัมน์ที่สองคือพันธบัตรหนึ่งหน่วย ซึ่งให้ \$100 ทุกแถว สิ่งที่เราเลือกได้มีแค่ $\theta_1$ (จำนวนหุ้น) กับ $\theta_2$ (จำนวนพันธบัตร) และทั้งคู่ติดลบได้

$\theta_2$ ติดลบมีความหมายง่าย ๆ คือการกู้เงิน เพราะ short พันธบัตรหนึ่งหน่วยได้เงินวันนี้ \$95 แล้วปีหน้าต้องจ่ายคืน \$100

ตลาดอื่นก็เขียนแบบเดียวกัน ถ้ามีสินทรัพย์ $d$ ตัว และสภาวะ $m$ แบบ $S$ จะมี $m$ แถว $d$ คอลัมน์ ช่อง $S_{ij}$ คือราคาปีหน้าของสินทรัพย์ $j$ ในสภาวะ $i$ ตลาดของเรามี $m=3$ แต่ $d=2$ แปลว่ามีเงื่อนไขสามข้อ แต่มีปุ่มให้หมุนแค่สองปุ่ม จำคู่เลข 3 กับ 2 นี้ไว้ เพราะมันคือต้นเหตุของทุกเรื่องที่แปลกในหน้านี้

ขั้นที่ 2 — ต้นทุนวันนี้ payoff ปีหน้า และแผนแรกที่จ่ายครบแน่

ทุกแผนมีตัวเลขสองชุดที่เราต้องรู้ ชุดแรกคือเงินที่จ่ายวันนี้ (cost) ชุดที่สองคือเงินที่ได้ปีหน้าในแต่ละสภาวะ ($y$) ทั้งสองชุดคือผลรวมของ “ราคาคูณจำนวนที่ถือ” จึงเป็นเส้นตรงใน $\theta$ จากนั้นเราลองแผนที่ง่ายที่สุดซึ่งจ่ายครบแน่ ๆ ก่อน ชื่อ $\theta^{\rm b}$ (b มาจาก bond) เพื่อให้รู้ว่าคำตอบที่ดีที่สุดแพงได้ไม่เกินเท่าไร

\[ \begin{aligned} \text{cost}&=100\theta_1+95\theta_2=p^{\mathsf T}\theta,\\ y&=S\theta=\theta_1S_1+\theta_2S_2\\ &=\begin{bmatrix}130\theta_1+100\theta_2\\100\theta_1+100\theta_2\\70\theta_1+100\theta_2\end{bmatrix},\\ \theta^{\rm b}&=(0,\ 1.2),\\ S\theta^{\rm b}&=(120,\ 120,\ 120),\\ p^{\mathsf T}\theta^{\rm b}&=95(1.2)=114. \end{aligned} \]

$y=S\theta$ อ่านได้สองทาง ทางแรกคือคูณแต่ละแถวของ $S$ กับ $\theta$ ได้ payoff ทีละสภาวะ ทางที่สองคือมองเป็นการผสมคอลัมน์ payoff ของพอร์ตคือ $\theta_1$ เท่าของคอลัมน์หุ้น $S_1$ บวก $\theta_2$ เท่าของคอลัมน์พันธบัตร $S_2$ ทางที่สองสำคัญกว่า เพราะมันบอกว่า payoff ที่เราสร้างได้มีแค่ส่วนผสมของสองคอลัมน์นี้ ชุดของส่วนผสมทั้งหมดนี้เรียกว่า range ของ $S$ (ดูrank และ range ของ matrix)

แผน $\theta^{\rm b}$ คือถือพันธบัตรอย่างเดียว ภาระที่สูงที่สุดคือ \$120 และพันธบัตรหน่วยละ \$100 จึงต้องใช้ $120/100=1.2$ หน่วย แผนนี้จ่าย \$120 ทุกสภาวะจึงครบแน่ แต่จ่ายเกินในกรณีทรงตัว $120-90=\$30$ และในกรณีลง $120-50=\$70$ ราคา \$114 จึงเป็นเพดาน คำตอบที่ดีที่สุดต้องไม่แพงกว่านี้ งานที่เหลือคือหาว่าต้นทุนลดลงได้ต่ำแค่ไหน

ขั้นที่ 3 — ทำไมเป็น ≥ ไม่ใช่ = : กรณีทรงตัวถูกล็อกไว้ที่ค่าเฉลี่ย

ทางที่ตรงที่สุดคือหาพอร์ตที่ payoff เท่าภาระพอดีทุกสภาวะ แต่นั่นคือสมการสามข้อกับตัวแปรสองตัว การนับจำนวนอย่างเดียวยังไม่บอกว่าทำไมจึงไม่มีคำตอบ เราจึงต้องดูข้างในแถวของ $S$ ราคาหุ้นกรณีทรงตัว \$100 อยู่กึ่งกลางของ \$130 กับ \$70 พอดี และพันธบัตรจ่ายเท่ากันทุกแถว ข้อสังเกตสองข้อนี้ทำให้แถวกลางเขียนได้จากแถวบนกับแถวล่าง

\[ \begin{aligned} y_{\rm flat}&=100\theta_1+100\theta_2\\ &=\tfrac12(130\theta_1+100\theta_2)\\ &\quad+\tfrac12(70\theta_1+100\theta_2)\\ &=\tfrac12\,(y_{\rm up}+y_{\rm down}),\\ \tfrac12(X_{\rm up}+X_{\rm down})&=\tfrac12(120+50)=85,\\ X_{\rm flat}&=90\ne85,\\ \min_{\theta}\ p^{\mathsf T}\theta&\quad\text{s.t.}\quad S\theta\ge X. \end{aligned} \]

หัวใจของขั้นนี้คือ $y_{\rm flat}=\tfrac12(y_{\rm up}+y_{\rm down})$ แปลว่า payoff กรณีทรงตัวของพอร์ตใด ๆ เท่ากับค่าเฉลี่ยของกรณีขึ้นกับกรณีลงเสมอ การแยก $100\theta_1$ เป็นครึ่งหนึ่งของ $130\theta_1$ บวกครึ่งหนึ่งของ $70\theta_1$ ทำได้เพราะ $\tfrac12(130+70)=100$ ส่วน $100\theta_2$ แยกเป็นสองครึ่งได้เพราะพันธบัตรจ่าย \$100 ทุกแถว ในรูปเส้นตรงด้านบน นี่คือเหตุที่จุดกลางของทุกเส้นอยู่กึ่งกลางระหว่างปลายสองข้าง

ผลที่ตามมาคือ ถ้าพอร์ตจ่าย \$120 ในกรณีขึ้นและ \$50 ในกรณีลงพอดี กรณีทรงตัวจะได้ \$85 ไม่ใช่ \$90 จึงไม่มีพอร์ตไหนสร้างภาระนี้ได้ตรงทุกสภาวะ ตลาดที่สร้าง payoff บางแบบให้ตรงไม่ได้แบบนี้เรียกว่า incomplete market

นี่คือเหตุที่โจทย์ใช้ $\ge$ แทน $=$ ลูกค้าไม่ว่าอะไรถ้าได้เงินเกิน แต่ขาดไม่ได้แม้แต่สภาวะเดียว และเมื่อเราหาต้นทุนต่ำสุด การคำนวณจะตัดเงินเกินที่ไม่จำเป็นออกเอง สูตรสุดท้ายคือ LP ของเรา อ่านว่า “หา $\theta$ ที่ทำให้ $p^{\mathsf T}\theta$ ต่ำที่สุด ภายใต้เงื่อนไข (s.t. ย่อมาจาก subject to) ว่า $S\theta\ge X$ ทุกแถว” เราไม่ใส่เงื่อนไขว่า $\theta$ ต้องไม่ติดลบ เพราะ short ได้ทั้งหุ้นและพันธบัตร

LP ทุกตัวมีหน้าตาแบบเดียวกัน คือหาค่าต่ำสุดหรือสูงสุดของ $c^{\mathsf T}x$ ภายใต้สมการ $A_{\rm eq}x=b_{\rm eq}$ และอสมการ $A_{\rm in}x\le b_{\rm in}$ ของเรามีแต่อสมการแบบ “อย่างน้อย” ถ้าคูณ $-1$ ทั้งสองข้าง $S\theta\ge X$ จะกลายเป็น $-S\theta\le-X$ ซึ่งเป็นแบบ “ไม่เกิน” ตามรูปมาตรฐาน

ขั้นที่ 4 — ต้นทุนมีพื้นไหม: ตรวจว่าไม่มีเงินฟรี

ก่อนหาค่าต่ำสุด ต้องแน่ใจก่อนว่าค่าต่ำสุดมีอยู่จริง ลองนึกถึงพอร์ตเสริม $d$ ที่เอาไปบวกกับแผนเดิม (เรียก $d$ ว่า “ทิศ” เพราะมันคือทิศที่เราขยับ $\theta$ ไป และเป็นคนละตัวกับ $d$ ที่นับจำนวนสินทรัพย์ในขั้นที่ 1) ถ้า $d$ ไม่ลด payoff ในสภาวะใดเลย แต่ต้นทุนของ $d$ ติดลบ (คือได้เงินวันนี้) เราจะบวก $d$ เข้าไปซ้ำได้เรื่อย ๆ แผนยังจ่ายภาระครบ แต่ได้เงินเพิ่มทุกครั้ง ต้นทุนจึงลดลงได้ไม่มีพื้น ของแบบนี้คือเงินฟรี หรือ arbitrage

กติกาที่ใช้ตรวจคือหลักการไม่มี arbitrage ซึ่งมีสองระดับ

  • weak: สัญญาที่จ่ายไม่ติดลบทุกสภาวะ ต้องมีราคาไม่ติดลบ
  • strong: ถ้าสัญญานั้นจ่ายเป็นบวกจริงอย่างน้อยหนึ่งสภาวะด้วย ราคาต้องเป็นบวกจริง

ทิศมีได้ไม่จำกัด เราจึงตรวจผ่านทิศพิเศษสองทิศ แล้วเขียนทิศอื่นทั้งหมดเป็นส่วนผสมของสองทิศนี้ ทิศ $A$ คือซื้อหุ้น 1 หุ้นแล้ว short พันธบัตร $70/100=0.7$ หน่วย กรณีลงจึงได้ $70-70=0$ พอดี ทิศ $B$ คือ short หุ้น 1 หุ้นแล้วซื้อพันธบัตร $130/100=1.3$ หน่วย กรณีขึ้นจึงได้ $-130+130=0$ พอดี

\[ \begin{aligned} A&=(1,\ -0.7),\\ SA&=(60,\ 30,\ 0),\\ p^{\mathsf T}A&=100-66.5=33.5,\\ B&=(-1,\ 1.3),\\ SB&=(0,\ 30,\ 60),\\ p^{\mathsf T}B&=-100+123.5=23.5,\\ d&=aA+bB,\\ Sd&=(60a,\ 30a+30b,\ 60b),\\ p^{\mathsf T}d&=33.5a+23.5b. \end{aligned} \]

$A$ จ่าย $(60, 30, 0)$ ไม่ติดลบทุกสภาวะ และเป็นบวกจริงในสองสภาวะ ราคาของมัน \$33.50 เป็นบวก จึงผ่านกติกา strong $B$ จ่าย $(0, 30, 60)$ และราคา \$23.50 ก็ผ่านเช่นกัน

ทีนี้ดูทิศ $d$ ใด ๆ ที่ไม่ลด payoff สภาวะใดเลย เราแยก $d$ เป็น $aA+bB$ ได้เสมอ เพราะ $A$ กับ $B$ ไม่ชี้ไปทางเดียวกัน (ไม่มีตัวไหนเป็นจำนวนเท่าของอีกตัว) ตัวคูณ $a$ กับ $b$ อ่านได้จากช่องแรกและช่องสุดท้ายของ $Sd$ คือ $a=(Sd)_{\rm up}/60$ และ $b=(Sd)_{\rm down}/60$ เมื่อ $d$ ไม่ลด payoff สองช่องนี้ไม่ติดลบ จึงได้ $a\ge0$ และ $b\ge0$

ต้นทุนของ $d$ คือ $33.5a+23.5b$ เมื่อ $a$ กับ $b$ ไม่ติดลบ ต้นทุนนี้ก็ไม่ติดลบ และเป็นศูนย์ได้เฉพาะเมื่อ $a=b=0$ คือไม่ได้ขยับเลย ตลาดนี้จึงไม่มีเงินฟรี และต้นทุน hedge มีพื้น

ถ้าตลาดตั้งราคาผิด เช่นหุ้นราคา \$135 ทั้งที่ปีหน้าได้มากสุดแค่ \$130 ต้นทุนของ $B$ จะกลายเป็น $-135+95\times1.3=-135+123.5=-11.5$ คือได้เงินวันนี้ \$11.50 และ payoff $(0, 30, 60)$ ไม่มีทางติดลบ ทำซ้ำได้ไม่จำกัด โปรแกรมแก้ LP (solver) จะตอบว่า unbounded ซึ่งในภาษาการเงินคือเจอ arbitrage ในตลาดจริงที่มีผู้ซื้อผู้ขายมากพอและเห็นราคาเหมือนกัน คนจะแห่มาทำแบบนี้จนราคาถูกดันกลับและช่องปิดไป

เก็บตัวเลขสองตัวนี้ไว้ $33.5/60\approx0.5583$ กับ $23.5/60\approx0.3917$ มันคือต้นทุนของ $A$ และ $B$ หารด้วยเงิน \$60 ที่แต่ละทิศจ่าย สองตัวนี้จะกลับมาเป็นน้ำหนักในขั้นที่ 6 และหน้า LP duality จะแสดงว่ามันทำหน้าที่เป็นราคาวันนี้ของเงิน \$1 ในกรณีขึ้นและในกรณีลง

ขั้นที่ 5 — มุมสามมุม และมุมที่ถูกที่สุดกลับใช้ไม่ได้

รู้แล้วว่าต้นทุนมีพื้น ขั้นนี้หาว่าพื้นอยู่ตรงไหน วาดพอร์ตเป็นจุด $(\theta_1, \theta_2)$ บนระนาบ (รูปถัดจากขั้นนี้) แต่ละแถวของ $S\theta\ge X$ ตัดระนาบออกครึ่งหนึ่ง ส่วนที่เหลือหลังตัดครบสามแถวคือพื้นที่ของพอร์ตที่จ่ายครบ

พอร์ตที่ต้นทุนเท่ากัน $100\theta_1+95\theta_2=k$ เรียงเป็นเส้นตรง และเส้นของทุกค่า $k$ ขนานกัน นึกภาพเลื่อนเส้นนี้ไปทางที่ถูกลงจนเกือบหลุดพื้นที่ จุดสุดท้ายที่ยังแตะอยู่คือ “มุม” ของพื้นที่ ตรงมุมนั้น สองแถวจ่ายเท่าภาระพอดี (หน้านี้เรียกว่าสองแถว “ชนพอดี”) มีตัวแปรสองตัว สมการสองข้อจึงตรึงจุดได้หนึ่งจุด เลือกสองแถวจากสามแถวได้สามคู่ จึงมีมุมให้ตรวจสามมุม และทุกมุมต้องเอาไปตรวจกับแถวที่เหลือว่ายังจ่ายครบไหม

\[ \begin{aligned} \theta^{\rm uf}&=(1,\ -0.1),\\ p^{\mathsf T}\theta^{\rm uf}&=100-9.5=90.50,\\ y^{\rm uf}_{\rm down}&=70-10=60\ge50,\\ \theta^{\rm ud}&=(\tfrac76,\ -\tfrac{19}{60}),\\ p^{\mathsf T}\theta^{\rm ud}&=\tfrac{700}{6}-\tfrac{1805}{60}\approx86.58,\\ y^{\rm ud}_{\rm flat}&=\tfrac12(120+50)=85\lt90,\\ \theta^{\rm fd}&=(\tfrac43,\ -\tfrac{13}{30}),\\ p^{\mathsf T}\theta^{\rm fd}&=\tfrac{400}{3}-\tfrac{1235}{30}\approx92.17,\\ y^{\rm fd}_{\rm up}&=\tfrac{520}{3}-\tfrac{130}{3}=130\ge120. \end{aligned} \]

ตัวยกบอกว่าแถวไหนชนพอดี u คือแถวขึ้น (up) f คือแถวทรงตัว (flat) d คือแถวลง (down) เช่น $\theta^{\rm uf}$ คือมุมที่แถวขึ้นกับแถวทรงตัวชนพอดี

ทุกมุมแก้ได้ง่าย เพราะพันธบัตรจ่าย \$100 ในทุกแถว เมื่อลบสองแถวกัน พจน์ $100\theta_2$ จึงหักหาย เหลือหุ้นตัวเดียว หา $\theta_1$ ได้ แล้วแทนกลับในแถวใดแถวหนึ่งเพื่อหา $\theta_2$

  • $\theta^{\rm uf}$: $(130-100)\theta_1=120-90$ ได้ $\theta_1=1$ แทนในแถวทรงตัว $100+100\theta_2=90$ ได้ $\theta_2=-0.1$
  • $\theta^{\rm ud}$: $(130-70)\theta_1=120-50$ ได้ $\theta_1=70/60=\tfrac76$ แทนในแถวลง $100\theta_2=50-70\cdot\tfrac76=-31.67$ ได้ $\theta_2=-\tfrac{19}{60}$
  • $\theta^{\rm fd}$: $(100-70)\theta_1=90-50$ ได้ $\theta_1=40/30=\tfrac43$ แทนในแถวทรงตัว $100\theta_2=90-100\cdot\tfrac43=-43.33$ ได้ $\theta_2=-\tfrac{13}{30}$

มุมที่ถูกที่สุดคือ $\theta^{\rm ud}$ ราคา \$86.58 ซึ่งก็คือแผนของเพื่อนในโจทย์เปิด แต่มันตกแถวทรงตัว ได้แค่ \$85 ตามที่กฎค่าเฉลี่ยในขั้นที่ 3 ทำนายไว้ อีกสองมุมผ่านทุกแถว ราคา \$90.50 และ \$92.17 ถ้ารับมุม \$86.58 ไปโดยไม่ตรวจแถวที่เหลือ โต๊ะจะขาดเงิน \$5 ในปีที่ตลาดทรงตัว

ขั้นที่ 6 — พิสูจน์ว่า \$90.50 ต่ำสุดจริงด้วยบรรทัดเดียว

การเทียบสามมุมบอกว่ามุมไหนดีที่สุดในสามมุม แต่ยังไม่ได้พิสูจน์ว่าไม่มีพอร์ตอื่นในพื้นที่ที่ถูกกว่า วิธีพิสูจน์ที่สั้นที่สุดคือหาน้ำหนักสองตัว $w_1$ กับ $w_2$ ที่คูณแถวขึ้น $(130, 100)$ กับแถวทรงตัว $(100, 100)$ ของ $S$ แล้วรวมกันได้เวกเตอร์ราคา $p=(100, 95)$ พอดี สองแถวนี้คือแถวที่ชนพอดีที่มุมผู้ชนะ $(1, -0.1)$

\[ \begin{aligned} &130w_1+100w_2=100,\\ &100w_1+100w_2=95,\\ &30w_1=5,\qquad w_1=\tfrac16,\\ &w_2=0.95-\tfrac16=\tfrac{47}{60},\\ &p^{\mathsf T}\theta=\tfrac16\,y_{\rm up}+\tfrac{47}{60}\,y_{\rm flat}\\ &\qquad\ge\tfrac16(120)+\tfrac{47}{60}(90)\\ &\qquad=20+70.5=90.50. \end{aligned} \]

สมการคู่แรกคือเงื่อนไขที่เราต้องการ ในคอลัมน์หุ้น แถวขึ้นคูณ $w_1$ บวกแถวทรงตัวคูณ $w_2$ ต้องได้ราคาหุ้น \$100 ในคอลัมน์พันธบัตรต้องได้ราคาพันธบัตร \$95 เมื่อลบสมการทั้งสองกัน พจน์ $100w_2$ หักหาย เหลือ $30w_1=5$ จึงได้ $w_1=\tfrac16$ และ $w_2=\tfrac{47}{60}$

การเขียนต้นทุน $p^{\mathsf T}\theta$ เป็นผลรวมของ $y_{\rm up}$ กับ $y_{\rm flat}$ ไม่ใช่การประมาณ มันคือต้นทุนเดิมที่จัดรูปใหม่ ลองกระจายดู

\[\begin{aligned}&\tfrac16(130\theta_1+100\theta_2)+\tfrac{47}{60}(100\theta_1+100\theta_2)\\&\quad=(21.67+78.33)\theta_1+(16.67+78.33)\theta_2\\&\quad=100\theta_1+95\theta_2.\end{aligned}\]

ได้ต้นทุนเดิมพอดีทุกพอร์ต ไม่ว่า $\theta$ จะเป็นอะไร

จังหวะที่ทำให้พิสูจน์ได้คือเครื่องหมาย $\ge$ แผนที่จ่ายครบมี $y_{\rm up}\ge120$ และ $y_{\rm flat}\ge90$ และน้ำหนักทั้งสองเป็นบวก เราจึงแทน $y_{\rm up}$ กับ $y_{\rm flat}$ ด้วยค่าต่ำสุดของมันได้โดยอสมการไม่พลิก ผลคือทุกแผนที่จ่ายครบใช้เงินอย่างน้อย \$90.50 และใช้เท่านี้พอดีเฉพาะเมื่อสองแถวนั้นชนพอดี ซึ่งคือ $\theta=(1, -0.1)$ เท่านั้น

การพิสูจน์แบบนี้ต้องผ่านสองข้อพร้อมกัน ข้อแรกคือน้ำหนักไม่ติดลบ ข้อสองคือมุมนั้นจ่ายครบทุกแถว สองมุมที่เหลือตกคนละข้อ

  • มุม $(\tfrac43, -\tfrac{13}{30})$ ตกข้อแรก น้ำหนักบนแถวทรงตัวกับแถวลงต้องแก้จาก $100w_2+70w_3=100$ และ $100w_2+100w_3=95$ ลบกันได้ $30w_3=-5$ คือ $w_3=-\tfrac16$ ติดลบ แปลว่าเพิ่ม payoff กรณีลงแล้วต้นทุนกลับลดลง มุมนี้จึงยังไม่ใช่คำตอบ
  • มุมของเพื่อนตกข้อสอง น้ำหนักบนแถวขึ้นกับแถวลงเป็นบวกทั้งคู่ คือ $0.5583$ กับ $0.3917$ จากขั้นที่ 4 จึงได้ขอบล่าง $0.5583(120)+0.3917(50)=86.58$ ที่จริงสำหรับทุกแผน แต่ไม่มีแผนที่จ่ายครบแผนไหนลงไปถึงขอบนี้ได้ เพราะจุดเดียวที่แตะขอบคือมุมของเพื่อน ซึ่งตกแถวทรงตัว

สรุปคือ น้ำหนักที่ไม่ติดลบให้ขอบล่างของต้นทุนเสมอ แต่ขอบล่างนั้นจะเท่าต้นทุนจริง ก็เฉพาะที่มุมซึ่งจ่ายครบทุกแถว

ขั้นที่ 7 — อ่านคำตอบเป็นเงินสด และส่วนเกิน \$10 ที่ตัดทิ้งไม่ได้

คำตอบ $\theta^*=(1, -0.1)$ บอกเป็นจำนวนหน่วย คนบนโต๊ะต้องการรู้เป็นเงิน คือวันนี้จ่ายเท่าไร และปีหน้าแต่ละสภาวะเหลือเงินเกินภาระเท่าไร เราเรียกเงินเกินนี้ว่าส่วนเกิน $e=S\theta-X$ (ต้องไม่ติดลบทุกสภาวะ) จากนั้นถามต่อว่า ถ้าเปลี่ยนแผน ส่วนเกินนี้ลดลงได้อีกไหม

\[ \begin{aligned} p^{\mathsf T}\theta^*&=100(1)+95(-0.1)\\ &=90.50,\\ e(\theta^*)&=(120,\ 90,\ 60)-X\\ &=(0,\ 0,\ 10),\\ e_{\rm flat}&=\tfrac12(y_{\rm up}+y_{\rm down})-90\\ &=\tfrac12(120+e_{\rm up}+50+e_{\rm down})-90\\ &=\tfrac12(e_{\rm up}+e_{\rm down})-5,\\ e_{\rm up}+e_{\rm down}&=2e_{\rm flat}+10\ge10. \end{aligned} \]

อ่านเป็นเงินสดได้แบบนี้ ซื้อหุ้น 1 หุ้นจ่าย \$100 และ short พันธบัตร 0.1 หน่วยได้เงิน $0.1\times95=\$9.50$ การ short พันธบัตรนี้ก็คือกู้เงิน \$9.50 แล้วคืน $0.1\times100=\$10$ ปีหน้าทุกกรณี (ดอกเบี้ย $10/9.5-1\approx5.26\%$) ปีหน้าหุ้นให้ \$130, \$100 หรือ \$70 หักคืนเงินกู้ \$10 เหลือ \$120, \$90 หรือ \$60 กรณีขึ้นและทรงตัวจ่ายพอดี กรณีลงเหลือ \$10

ส่วนท้ายของสูตรตอบคำถามว่าตัดส่วนเกินนี้ได้ไหม เราเริ่มจากกฎค่าเฉลี่ยในขั้นที่ 3 แล้วแทน payoff ด้วย “ภาระบวกส่วนเกิน” คือ $y=X+e$ เลข $-5$ มาจาก $\tfrac12(120+50)-90=85-90$ และเพราะ $e_{\rm flat}\ge0$ ผลรวมส่วนเกินกรณีขึ้นกับกรณีลงจึงต้องไม่น้อยกว่า \$10 เสมอ ไม่ว่าจะเลือกแผนไหน

แผนที่ถูกที่สุดวางเงิน \$10 นั้นไว้ในกรณีลงทั้งก้อน หน้า LP duality จะอธิบายว่าทำไม คำตอบสั้น ๆ คือกรณีลงเป็นสภาวะที่เงินหนึ่งดอลลาร์มีราคาวันนี้ถูกที่สุดสำหรับโต๊ะนี้

ตัวอย่างที่สอง — ลด beta ด้วย QQQ และ SPY ภายใต้เพดานการ short

โครงเดียวกันใช้กับงานที่โต๊ะหุ้นเจอทุกวัน โต๊ะหนึ่งถือตะกร้าหุ้นบริษัทผลิตชิป (semiconductor) ไว้ ตะกร้านี้ขยับแรงกว่าตลาด ฝ่ายความเสี่ยงกลัวว่าถ้าตลาดทั้งตลาดตกแรง โต๊ะจะเสียหนัก จึงสั่งให้ลดการขยับตามตลาดลง โดยไม่ต้องขายหุ้นในตะกร้าทิ้ง วิธีที่ใช้คือ short กองทุนที่วิ่งตามตลาด ถ้าตลาดตก ฝั่ง short จะได้เงินมาชดเชย

ตัววัดการขยับตามตลาดคือ beta ถ้าตลาดขยับ 1% ของที่มี beta 1.10 จะขยับราว 1.10% ของที่รู้:

  • ตะกร้าหุ้นมูลค่า \$12 ล้าน มี beta 1.10
  • คำสั่งของฝ่ายความเสี่ยง: beta ที่เหลือหลัง hedge ต้องไม่เกิน 0.20
  • เครื่องมือที่ 1: short QQQ (กองทุนที่ซื้อขายเหมือนหุ้นและวิ่งตามดัชนี Nasdaq-100 ซึ่งเป็นหุ้นเทคโนโลยีใหญ่ 100 ตัว) beta 1.20 (สมมติ)
  • เครื่องมือที่ 2: short SPY (กองทุนที่วิ่งตามดัชนี S&P 500 ของหุ้นใหญ่ 500 ตัวในสหรัฐ) beta 1.00 พอดี เพราะเราใช้ SPY เป็นตัวแทน “ตลาด” เอง และของใดเทียบกับตัวเองย่อมมี beta 1
  • เพดานของโต๊ะ: short ได้ไม่เกินตัวละ \$6 ล้าน ตัวเลขนี้มาจากนโยบายเรื่องสภาพคล่อง (ซื้อขายก้อนใหญ่กว่านี้แล้วราคาจะขยับเพราะคำสั่งของเราเอง)
  • ต้นทุนซื้อขาย (สมมติ): QQQ \$180 และ SPY \$90 ต่อขนาด position (notional) \$1 ล้าน คิดเป็นสัดส่วน $180/1{,}000{,}000=0.018\%$ และ $90/1{,}000{,}000=0.009\%$ หรือ 1.8 และ 0.9 basis points (1 basis point คือ 0.01%)

beta ของแต่ละตัวมาจากการ regress ผลตอบแทนของมันกับผลตอบแทนของตลาด แบบเดียวกับในhedge ratio จากการแจกแจงแบบมีเงื่อนไข คำถามคือ ควร short QQQ และ SPY ตัวละเท่าไร จึงผ่านคำสั่งของฝ่ายความเสี่ยงด้วยต้นทุนต่ำที่สุด

ขั้นที่ 8 — แปลงคำสั่ง “beta ไม่เกิน 0.20” ให้เป็นอสมการ

คำสั่งมาเป็นประโยค เราต้องแปลงให้เป็นอสมการที่ตรวจได้ ตัวแปรคือ $x_Q$ ขนาด short QQQ และ $x_S$ ขนาด short SPY หน่วยล้านดอลลาร์ทั้งคู่

beta ของของต่างชิ้นบวกกันตรง ๆ ไม่ได้ เพราะแต่ละชิ้นมีขนาดไม่เท่ากัน เราจึงใช้ dollar beta (มูลค่าคูณ beta) ซึ่งบวกลบข้าม position ได้

  • ตะกร้า: $12\times1.10=13.2$ แปลว่าตลาดขึ้น 1% ตะกร้าขึ้นราว $13.2\times0.01=0.132$ ล้านดอลลาร์ หรือ \$132,000
  • short QQQ \$1 ล้าน หักออกได้ $1\times1.2=1.2$
  • short SPY \$1 ล้าน หักออกได้ $1\times1.0=1.0$

dollar beta ที่เหลือคือ $13.2-1.2x_Q-x_S$ หารด้วยมูลค่าตะกร้า \$12 ล้าน ก็กลับเป็น beta ของตะกร้าหลัง hedge ซึ่งเรียกว่า $R$

\[ \begin{aligned} &R=\frac{13.2-1.2x_Q-x_S}{12}\le0.20,\\ &13.2-1.2x_Q-x_S\le2.4,\\ &-1.2x_Q-x_S\le-10.8,\\ &1.2x_Q+x_S\ge10.8,\\ &0\le x_Q\le6,\qquad 0\le x_S\le6,\\ &C=180x_Q+90x_S. \end{aligned} \]

การแปลงทำแค่สามอย่าง คูณ 12 ทั้งสองข้าง ($12\times0.20=2.4$) ย้าย 13.2 ข้ามข้าง ($2.4-13.2=-10.8$) แล้วคูณทั้งสองข้างด้วย $-1$ จังหวะที่ต้องระวังคืออันสุดท้าย การคูณด้วยจำนวนติดลบทำให้อสมการพลิกจาก $\le$ เป็น $\ge$ ถ้าลืมพลิก โจทย์จะกลายเป็น “ลด beta ได้ไม่เกิน 10.8” และแผนที่ถูกที่สุดคือไม่ทำอะไรเลย

10.8 มีหน่วย beta คูณล้านดอลลาร์ อ่านว่า hedge ต้องหักการขยับตามตลาดออกอย่างน้อย $10.8\times0.01=0.108$ ล้านดอลลาร์ หรือ \$108,000 ทุกครั้งที่ตลาดขยับ 1% ขนาด short ต้องไม่ติดลบ เพราะเราเลือกไว้แล้วว่าจะ short ไม่ใช่ซื้อ ส่วนเพดาน 6 มาจากนโยบายสภาพคล่อง ไม่ได้คำนวณมา สุดท้าย $C$ คือต้นทุนซื้อขายรวม \$180 ต่อ QQQ \$1 ล้าน บวก \$90 ต่อ SPY \$1 ล้าน

ขั้นที่ 9 — ลองทีละตัว แล้วเรียงตามต้นทุนต่อ beta

โจทย์ให้อะไรมาบ้าง: อสมการ beta $1.2x_Q+x_S\ge10.8$ และเพดานตัวละ 6 ที่เพิ่งเขียน กับต้นทุน \$180 (QQQ) และ \$90 (SPY) ต่อ \$1 ล้าน

วิธีคิด: ลองแบบง่ายก่อน คือใช้เครื่องมือตัวเดียว ให้ $x^{(1)}$ คือขนาดที่ต้องใช้ถ้าใช้ตัวนั้นตัวเดียว ถ้าไม่พอ จึงค่อยผสม และเวลาผสม ให้เติมตัวที่ลด beta หนึ่งหน่วยได้ถูกกว่าก่อน ต้นทุนต่อ beta คือต้นทุนต่อ \$1 ล้าน หารด้วย beta ที่ \$1 ล้านนั้นหักได้

\[ \begin{aligned} x_Q^{(1)}&=10.8/1.2=9\gt6,\\ x_S^{(1)}&=10.8/1=10.8\gt6,\\ 180/1.2&=150,\qquad 90/1=90,\\ x_S&=6,\\ x_Q&=(10.8-6)/1.2=4,\\ C&=180(4)+90(6)\\ &=720+540=1{,}260. \end{aligned} \]

คำตอบ: ใช้ตัวเดียวไม่ได้ทั้งคู่ เพราะ QQQ ต้องใช้ \$9 ล้าน และ SPY ต้องใช้ \$10.8 ล้าน เกินเพดาน \$6 ล้านทั้งคู่ จึงต้องผสม SPY ลด beta หนึ่งหน่วยได้ถูกกว่า (\$90 เทียบกับ \$150 ของ QQQ) จึงใช้ SPY จนเต็ม \$6 ล้าน ซึ่งลดได้ 6 ยังขาดอีก $10.8-6=4.8$ ให้ QQQ เติม ต้องใช้ $4.8/1.2=4$ คือ \$4 ล้าน ยังอยู่ในเพดาน ต้นทุนรวม \$1,260

ตรวจเองใน 10 วินาที: beta ที่ลดได้คือ $1.2\times4+6=10.8$ พอดี และ beta ที่เหลือคือ $1.10-10.8/12=1.10-0.90=0.20$ พอดีเป้า ข้อที่ต้องจำคือให้เทียบต้นทุนต่อ beta ที่ลดได้ ไม่ใช่ต้นทุนต่อดอลลาร์ ในตัวอย่างนี้สองแบบให้ลำดับเดียวกัน แต่โจทย์ข้อ 3 ท้ายหน้าเป็นกรณีที่ลำดับกลับกัน

ขั้นที่ 10 — พิสูจน์ด้วยน้ำหนักสองตัว แล้วกระทบยอด beta

การเรียงตามต้นทุนต่อ beta ให้คำตอบมา แต่ยังไม่ใช่ข้อพิสูจน์ เราจึงใช้วิธีเดียวกับที่พิสูจน์ \$90.50 ในขั้นที่ 6 คือเขียนต้นทุนใหม่ด้วยสองเงื่อนไขที่ชนพอดีที่ $(4, 6)$ เงื่อนไขแรกคือเกณฑ์ beta $1.2x_Q+x_S\ge10.8$ (ลดได้ 10.8 พอดี) เงื่อนไขที่สองคือเพดาน SPY $x_S\le6$ (ใช้เต็ม 6 พอดี)

\[ \begin{aligned} 180x_Q+90x_S&=150(1.2x_Q+x_S)\\ &\quad-60x_S\\ &\ge150(10.8)-60(6)\\ &=1{,}620-360\\ &=1{,}260=C(4,\ 6). \end{aligned} \]

ส่วนแรกของสูตรเป็นแค่การจัดต้นทุนใหม่ ไม่ได้ประมาณอะไร ตรวจได้ว่า $150\times1.2=180$ (สัมประสิทธิ์ของ $x_Q$) และ $150-60=90$ (สัมประสิทธิ์ของ $x_S$)

จังหวะสำคัญคือตอนแทนสองเงื่อนไขที่ชนพอดี เกณฑ์ beta บอกว่า $1.2x_Q+x_S\ge10.8$ คูณด้วย 150 ซึ่งเป็นบวก อสมการจึงไม่พลิก ส่วน $x_S\le6$ คูณด้วย $-60$ ซึ่งติดลบ อสมการจึงพลิกเป็น $-60x_S\ge-360$ ทั้งสองข้อชี้ไปทาง $\ge$ เหมือนกัน จึงบวกกันได้ ผลคือทุกแผนที่ผ่านกฎใช้เงินอย่างน้อย \$1,260 และใช้เท่านี้พอดีเฉพาะเมื่อ beta ลดได้ 10.8 พอดีและ SPY เต็ม 6 พอดี

น้ำหนักสองตัวนี้มีความหมายเป็นเงิน 150 คือต้นทุนต่อ beta ของตัวที่เติมส่วนสุดท้าย (QQQ) ส่วน 60 คือเงินที่ประหยัดได้ถ้า SPY ได้เพดานเพิ่ม \$1 ล้าน เพราะ SPY เพิ่ม \$1 ล้านลด beta ได้ 1 ในราคา \$90 แทน QQQ ที่ลด beta 1 เท่ากันในราคา \$150 ประหยัด $150-90=\$60$ หน้า LP duality จะเรียกสองตัวนี้ว่า shadow price

ก่อนส่งคำสั่ง ให้กระทบยอด beta ตามรูปด้านล่าง ตัวเลขทั้งสี่ต้องลงตัว ถ้าไม่ลงตัว แปลว่าหน่วยหรือเครื่องหมายผิดที่ใดที่หนึ่ง

ความผิดที่ให้คำตอบผิดโดยไม่มี error

ห้าม short โดยไม่ตั้งใจ ($\theta\ge0$): solver หลายตัวตั้งค่าเริ่มต้นให้ตัวแปรห้ามติดลบ ถ้าลืมปิด พอร์ตจะ short พันธบัตรไม่ได้ คือกู้เงินไม่ได้ คำตอบจะย้ายไปซื้อหุ้นอย่างเดียวให้แถวขึ้นพอดี $130\theta_1=120$ ได้ $\theta_1=12/13\approx0.9231$ หุ้น ราคา $100\times12/13=\$92.31$ แทนที่จะเป็น \$90.50 แพงขึ้น $92.31-90.50=\$1.81$ โดยไม่มีคำเตือนใด ๆ เครื่องหมายของตัวแปรเป็นส่วนหนึ่งของโจทย์ ต้องเขียนเองทุกครั้ง

ลืมพลิกอสมการ beta: ถ้าเขียน $1.2x_Q+x_S\le10.8$ แผนที่ถูกที่สุดคือไม่ short อะไรเลย $(0, 0)$ ต้นทุน \$0 แต่ beta ยังเป็น 1.10 ไม่ใช่ 0.20 แผนที่ถูกคือ $(4, 6)$ ต้นทุน \$1,260 วิธีจับง่าย ๆ คือลองแผน “ไม่ทำอะไร” ทุกครั้ง ถ้าแผนนี้ผ่านกฎที่บังคับให้ hedge แปลว่ากฎกลับหัว

แก้สองแถวแล้วไม่ตรวจแถวที่สาม: มุม \$86.58 ดูถูกที่สุดในสามมุม แต่จ่ายกรณีทรงตัวได้แค่ $\tfrac12(120+50)=\$85$ ขาดไป \$5 คำตอบที่ถูกคือ \$90.50 ทุกครั้งที่หาคำตอบจากข้อจำกัดบางข้อ ต้องเอาคำตอบไปตรวจข้อที่เหลือทุกข้อก่อนเทียบราคา

ตั้งราคาจากค่าเฉลี่ยของภาระ: ถ้าเชื่อว่าสามสภาวะมีโอกาสเท่ากัน ค่าเฉลี่ยของภาระคือ $(120+90+50)/3=86.67$ แล้วแปลงเป็นเงินวันนี้ด้วย 0.95 (ราคาพันธบัตร \$95 ต่อ \$100 ปีหน้า แปลว่าเงิน \$1 ปีหน้ามีค่า \$0.95 วันนี้) ได้ $0.95\times86.67=\$82.33$ ถ้าขายสัญญาที่ราคานี้ เงินจะไม่พอซื้อ hedge ที่ต้องใช้ \$90.50 เพราะ superhedge ต้องจ่ายครบไม่ว่าสภาวะไหนเกิด ราคา \$90.50 ไม่ขึ้นกับโอกาสของแต่ละสภาวะเลย คนสองคนที่เห็นต่างกันเรื่องโอกาสก็ได้ตัวเลขนี้ตรงกัน

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะ structuring (ทีมที่ออกแบบและขายสัญญาซึ่งจ่ายเงินตามสภาวะตลาดให้ลูกค้า) ใช้โจทย์แรกตรง ๆ ต้นทุน superhedge \$90.50 คือราคาต่ำสุดที่ขายสัญญาได้โดยโต๊ะไม่ต้องรับความเสี่ยงเลย ส่วนที่บวกเพิ่มจากนี้คือกำไรของโต๊ะ ถ้าลูกค้าต่อรองให้ต่ำกว่า \$90.50 การรับงานแปลว่าโต๊ะเลือกรับความเสี่ยงในบางสภาวะ ไม่ใช่ว่าโต๊ะหา hedge ที่ถูกกว่าได้

โต๊ะที่ต้องลด beta ภายใต้เพดาน ใส่โจทย์ที่สองไว้ในระบบก่อนส่งคำสั่ง ข้อจำกัดแต่ละข้อเป็นอสมการที่ฝ่ายความเสี่ยงตรวจได้ทีละข้อ และคำตอบมาพร้อมน้ำหนัก 150 กับ 60 ซึ่งบอกว่าเพดานไหนกำลังทำให้โต๊ะเสียเงิน และเสียเท่าไร

แบบจำลองนี้สมมติสามอย่างที่ต้องจำไว้

  • ตลาดปีหน้ามีแค่สามแบบ แต่ของจริงราคาเป็นได้ทุกค่าในช่วงหนึ่ง
  • ซื้อและ short ได้ที่ราคาเดียวกัน แต่ของจริงราคาที่เราซื้อได้สูงกว่าราคาที่เราขายได้ (ส่วนต่างนี้เรียกว่า bid-ask spread) และกู้เงินแพงกว่าให้กู้
  • ตั้งพอร์ตครั้งเดียวแล้วถือจนครบปี ถ้าปรับพอร์ตระหว่างทางได้ hedge อาจถูกลง เรื่องนี้ต้องใช้การตั้งราคาบน binomial tree

โจทย์ตรวจความเข้าใจ

1. ลูกค้าอีกรายขอสัญญาแบบเดียวกัน ต่างกันแค่ภาระกรณีทรงตัวลดจาก \$90 เป็น \$85 ภาระจึงเป็น \$120, \$85, \$50 หุ้นและพันธบัตรเหมือนเดิมทุกอย่าง ต้นทุนต่ำสุดของ hedge คือเท่าไร และยังต้องเหลือเงินทิ้งในสภาวะใดไหม?

เฉลย

ภาระกรณีทรงตัวตอนนี้เท่ากับค่าเฉลี่ยของกรณีขึ้นกับกรณีลงพอดี คือ $\tfrac12(120+50)=85$ สามจุดของภาระจึงอยู่บนเส้นตรงเดียวกัน และสร้างได้ตรงทุกสภาวะ มุม $\theta=(\tfrac76, -\tfrac{19}{60})$ ที่เคยตกแถวทรงตัว ตอนนี้ชนพอดีทั้งสามแถว payoff เป็น $(120, 85, 50)$ ไม่เหลือเงินทิ้งเลย ต้นทุนคือ

\[\begin{aligned}\text{cost}&=100\cdot\tfrac76-95\cdot\tfrac{19}{60}\\&=116.67-30.08\approx\$86.58.\end{aligned}\]

น้ำหนักเดิม $(\tfrac16, \tfrac{47}{60})$ ยังใช้พิสูจน์ได้ เพราะมันขึ้นกับ $S$ กับ $p$ เท่านั้น ไม่ขึ้นกับภาระ ขอบล่างคือ $\tfrac16(120)+\tfrac{47}{60}(85)=20+66.58=86.58$ เท่ากับต้นทุนพอดี ภาระที่สร้างได้ตรงจึงมีราคาเดียว ถ้าใครขายถูกหรือแพงกว่านี้ จะมีคนทำเงินฟรีจากส่วนต่างได้

2. อีกตลาดหนึ่งมีของให้ใช้สองอย่าง หุ้นราคาวันนี้ \$100 ปีหน้าจ่าย \$120, \$100 หรือ \$70 และพันธบัตรราคาวันนี้ \$100 ปีหน้าจ่าย \$105 ทุกกรณี ภาระปีหน้าคือ \$110, \$100, \$80 มีคนเสนอแผนซื้อหุ้น 0.5 หุ้นและพันธบัตร $\tfrac{10}{21}$ หน่วย ใช้เงิน $100(0.5)+100(\tfrac{10}{21})=50+47.62=\$97.62$ แผนนี้เป็นตัวอย่างเดียวกับที่เคยเห็นในฟังก์ชันเชิงเส้นและข้อจำกัดเชิงเส้น แผนนี้ถูกที่สุดแล้วหรือยัง?

เฉลย

ถูกที่สุดแล้ว แผนนี้จ่ายครบทุกแถว เพราะ $105\times\tfrac{10}{21}=50$ จึงได้ $(60+50, 50+50, 35+50)=(110, 100, 85)$ ทีนี้หามุมทั้งสาม ลบสองแถวกันแล้วพจน์พันธบัตรหักหายเหมือนในขั้นที่ 5

\[\begin{aligned}\text{uf}:\ 20\theta_1&=10,\quad\theta=(0.5,\ 0.4762),\\\text{cost}&=50+47.62=97.62,\\\text{ud}:\ 50\theta_1&=30,\quad\theta=(0.6,\ 0.3619),\\\text{cost}&=60+36.19=96.19,\\\text{fd}:\ 30\theta_1&=20,\quad\theta=(0.6667,\ 0.3175),\\\text{cost}&=66.67+31.75=98.41.\end{aligned}\]

มุม ud ถูกที่สุดในสามมุม แต่แถวกลางได้ $100(0.6)+105(0.3619)=60+38=\$98$ ขาดไป \$2 จึงใช้ไม่ได้ มุม fd ผ่านทุกแถวแต่แพงกว่า เหลือมุม uf ซึ่งคือแผนที่เสนอมา

พิสูจน์ด้วยน้ำหนักบนแถวแรก $(120, 105)$ กับแถวกลาง $(100, 105)$ ที่รวมกันต้องได้ราคา $(100, 100)$

\[\begin{aligned}120w_1+100w_2&=100,\\105(w_1+w_2)&=100,\\20w_1&=100-100\cdot\tfrac{100}{105}=4.76,\\w_1&=\tfrac{5}{21},\quad w_2=\tfrac{20}{21}-\tfrac{5}{21}=\tfrac57.\end{aligned}\]

สมการที่สามได้จากการเขียน $120w_1+100w_2=20w_1+100(w_1+w_2)$ แล้วแทน $w_1+w_2=\tfrac{100}{105}$ น้ำหนักทั้งคู่เป็นบวก ทุกแผนที่จ่ายครบจึงใช้เงินอย่างน้อย $110(\tfrac{5}{21})+100(\tfrac57)=26.19+71.43=\$97.62$

3. กลับไปที่ตัวอย่างการลด beta สมมติว่าต้นทุนซื้อขาย SPY ขึ้นจาก \$90 เป็น \$160 ต่อ \$1 ล้าน ส่วน QQQ ยัง \$180 ทุกอย่างอื่นเหมือนเดิม ต่อ \$1 ล้าน SPY ยังถูกกว่า QQQ ควรใช้ SPY จนเต็มก่อนเหมือนเดิมไหม?

เฉลย

ไม่ควร ต้องเทียบต้นทุนต่อ beta ไม่ใช่ต่อดอลลาร์ QQQ ได้ $180/1.2=150$ ส่วน SPY ได้ $160/1=160$ ตอนนี้ QQQ ถูกกว่าต่อ beta จึงใช้ QQQ เต็ม \$6 ล้านก่อน แล้วให้ SPY เติมส่วนที่ขาด

\[\begin{aligned}1.2\times6&=7.2,\\x_S&=10.8-7.2=3.6,\\C(6,\ 3.6)&=180(6)+160(3.6)\\&=1{,}080+576=1{,}656,\\C(4,\ 6)&=180(4)+160(6)\\&=720+960=1{,}680.\end{aligned}\]

แผนเดิมที่ใช้ SPY ก่อนแพงกว่า $1{,}680-1{,}656=\$24$ พิสูจน์ด้วยวิธีเดียวกับขั้นที่ 10 แต่ตอนนี้เงื่อนไขที่ชนพอดีคือเกณฑ์ beta กับเพดาน QQQ

\[\begin{aligned}180x_Q+160x_S&=160(1.2x_Q+x_S)-12x_Q\\&\ge160(10.8)-12(6)\\&=1{,}728-72=1{,}656.\end{aligned}\]

การจัดรูปถูกเพราะ $160\times1.2-12=192-12=180$ และขั้น $\ge$ ใช้ได้เพราะ $x_Q\le6$ ทำให้ $-12x_Q\ge-72$

  1. จับแถวทีละคู่ แก้สมการสองข้อ ได้มุมหนึ่งมุมต่อหนึ่งคู่

// Linear programs with two decision variables: minimise c.x subject to every row A[k].x >= b[k].
function checkProblem(c, A, b) {
  const pair = v => Array.isArray(v) && v.length === 2 && v.every(Number.isFinite);
  if (!pair(c)) throw new TypeError('Cost must be two finite numbers');
  if (!Array.isArray(A) || A.length < 2 || !A.every(pair)) throw new TypeError('Need at least two rows of two finite numbers');
  if (!Array.isArray(b) || b.length !== A.length || !b.every(Number.isFinite)) throw new TypeError('Need one finite limit per row');
}
// Solve [[a, b], [c, d]] [x, y] = [e, f] by Cramer's rule; null when the two rows are parallel.
function solve2x2(a, b, c, d, e, f) {
  const det = a * d - b * c;
  if (Math.abs(det) < 1e-12 * (Math.abs(a * d) + Math.abs(b * c) + 1e-300)) return null;
  return [(e * d - b * f) / det, (a * f - e * c) / det];
}
const dot = (u, v) => u[0] * v[0] + u[1] * v[1];
function solveLP(c, A, b) {
  checkProblem(c, A, b);
  const corners = [];
  for (let i = 0; i < A.length; i++) for (let j = i + 1; j < A.length; j++) {
    const x = solve2x2(A[i][0], A[i][1], A[j][0], A[j][1], b[i], b[j]);
    if (!x) continue;
    const slack = A.map((row, k) => dot(row, x) - b[k]);
    const feasible = slack.every((s, k) => s >= -1e-9 * (1 + Math.abs(b[k])));
    // Weights on the two binding rows that rebuild the cost vector: w_i A[i] + w_j A[j] = c.
    const weights = solve2x2(A[i][0], A[j][0], A[i][1], A[j][1], c[0], c[1]);
    corners.push({rows: [i, j], x, cost: dot(c, x), feasible, slack, weights});
  }
  // A feasible corner whose weights are all >= 0 proves itself cheapest: cost >= w.b for every feasible x.
  const proven = corners.filter(k => k.feasible && k.weights.every(w => w >= -1e-12)).sort((p, q) => p.cost - q.cost);
  if (!proven.length) throw new RangeError('No corner proves itself cheapest: the rules clash or the cost has no floor');
  const best = proven[0];
  return {...best, bound: best.weights[0] * b[best.rows[0]] + best.weights[1] * b[best.rows[1]], corners};
}
// Superhedge: rows are the states up, flat, down; columns are one share and one bond.
const S = [[130, 100], [100, 100], [70, 100]], X = [120, 90, 50], p = [100, 95];
const payoff = t => S.map(row => dot(row, t));
const hedge = solveLP(p, S, X);
const noShort = solveLP(p, [...S, [1, 0], [0, 1]], [...X, 0, 0]);
const edgeA = [1, -0.7], edgeB = [-1, 1.3];
// Beta hedge: rows are the beta floor, the two caps written as -x >= -6, and the no-long rules x >= 0.
const betaRows = [[1.2, 1], [-1, 0], [0, -1], [1, 0], [0, 1]];
const need = 12 * (1.10 - 0.20);
const beta = solveLP([180, 90], betaRows, [need, -6, -6, 0, 0]);
const flipped = solveLP([180, 90], [[-1.2, -1], ...betaRows.slice(1)], [-need, -6, -6, 0, 0]);

สิ่งที่ควรตอบได้หลังอ่าน

  • hedge ที่ถูกที่สุดซึ่งจ่ายครบทุกสภาวะ (superhedge) คือ LP หาค่าต่ำสุดของต้นทุน $p^{\mathsf T}\theta$ ภายใต้ $S\theta\ge X$ ภาระ \$120, \$90, \$50 ใช้เงิน \$90.50 ที่ $\theta=(1, -0.1)$ ไม่ใช่ \$86.58 ตามแผนของเพื่อน
  • payoff ของพอร์ตใด ๆ เป็นส่วนผสมของคอลัมน์ของ $S$ ในตลาดนี้ payoff กรณีทรงตัวจึงเท่ากับค่าเฉลี่ยของกรณีขึ้นกับกรณีลงเสมอ ภาระที่ไม่เป็นแบบนั้นสร้างให้ตรงไม่ได้ และต้องเหลือเงินรวมอย่างน้อย \$10
  • ต้นทุนมีพื้นเมื่อไม่มีทางได้เงินฟรี ทิศ $A$ และ $B$ จ่ายไม่ติดลบทุกสภาวะ และมีราคาเป็นบวก \$33.50 กับ \$23.50 ตลาดนี้จึงผ่านหลักไม่มี arbitrage แบบ strong
  • มุมทุกมุมต้องตรวจกับทุกแถว และมุมที่ถูกที่สุดพิสูจน์ตัวเองได้ด้วยน้ำหนักไม่ติดลบ $(\tfrac16, \tfrac{47}{60})$ ซึ่งรวมสองแถวที่ชนพอดีให้ได้เวกเตอร์ราคาพอดี
  • คำสั่ง “beta ไม่เกิน 0.20” กลายเป็น $1.2x_Q+x_S\ge10.8$ หลังพลิกเครื่องหมาย คำตอบคือ short QQQ \$4 ล้านและ SPY \$6 ล้าน ราคา \$1,260 พิสูจน์ด้วยน้ำหนัก 150 และ 60
