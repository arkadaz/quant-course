11.1 Setting Up the Hedging Problem

คำสั่ง “จ่ายให้ครบทุกกรณีด้วยเงินน้อยที่สุด” เขียนเป็นอสมการหนึ่งข้อต่อหนึ่งสภาวะได้ และคำตอบอยู่ที่มุมที่พิสูจน์ตัวเองได้ด้วยน้ำหนักสองตัว

ปีหน้าโต๊ะต้องจ่ายลูกค้า \$120 ถ้าตลาดขึ้น \$90 ถ้าตลาดทรงตัว และ \$50 ถ้าตลาดลง วันนี้มีของให้ซื้อหรือ short ได้สองอย่าง คือหุ้นราคา \$100 ที่ปีหน้าเป็น \$130, \$100 หรือ \$70 และพันธบัตรราคา \$95 ที่คืน \$100 ทุกกรณี เพื่อนร่วมโต๊ะเสนอว่า “ปิดสองกรณีสุดขั้วให้พอดี กรณีกลางรอดเอง” ได้พอร์ตราคา \$86.58 วันนี้ต้องใช้เงินอย่างน้อยเท่าไรจึงจ่ายได้ครบทุกกรณี?

ลองตอบก่อนเปิดเฉลย

อย่างน้อย \$90.50 พอร์ตของเพื่อนคือหุ้น 7/6 หุ้นกับ short พันธบัตร 19/60 หน่วย ปีหน้าได้ \$120, \$85 และ \$50 กรณีทรงตัวขาด \$5 เพราะในตลาดนี้ payoff กรณีทรงตัวของทุกพอร์ตเท่ากับค่าเฉลี่ยของกรณีขึ้นกับกรณีลงเสมอ พอร์ตที่ถูกที่สุดที่จ่ายครบคือซื้อหุ้น 1 หุ้นและ short พันธบัตร 0.1 หน่วย ได้ \$120, \$90 และ \$60 จ่ายวันนี้ \$100 − \$9.50 = \$90.50

สิ่งที่เราจะสร้าง

7.4 จบที่ข้อสังเกตว่า “ผ่านทุกข้อจำกัด” กับ “ถูกที่สุด” เป็นคนละคำถาม เราเจอพอร์ตที่ถูกลงได้ แต่ยังพิสูจน์ไม่ได้ว่าถูกที่สุด หัวข้อนี้ตอบคำถามที่สองให้จบ: เขียนโจทย์เป็นตัวแปร เป้าหมาย และข้อจำกัด ตรวจว่าต้นทุนมีพื้น หาผู้สมัครที่มุม แล้วพิสูจน์ด้วยการจัดต้นทุนใหม่บรรทัดเดียวว่าไม่มีแผนไหนถูกกว่า

เราทำสองโจทย์ โจทย์แรกคือภาระข้างบน ซึ่งเป็นแม่แบบของการตั้งราคาสินค้าที่จ่ายตามสภาวะตลาด โจทย์ที่สองคือลด beta ของตะกร้าหุ้นด้วย QQQ กับ SPY ภายใต้เพดานสภาพคล่อง ทั้งสองจบด้วยตัวเลขคู่หนึ่งที่ใช้พิสูจน์คำตอบ และตัวเลขคู่นั้นจะกลายเป็นราคาของแต่ละสภาวะและราคาของแต่ละข้อจำกัดใน 11.3

ศัพท์ที่ใช้ในหัวข้อนี้
Superhedge
พอร์ตที่ payoff ไม่ต่ำกว่าภาระในทุกสภาวะ ใช้เมื่อผู้ขายต้องจ่ายให้ได้ไม่ว่าตลาดไปทางไหน ต่างจาก replication ที่ต้องเท่ากันพอดีทุกช่อง
Linear program (LP)
โจทย์หาค่าต่ำสุดหรือสูงสุดของเป้าหมายที่เป็นเส้นตรง ภายใต้ข้อจำกัดที่เป็นเส้นตรง ใช้ได้ที่นี่เพราะต้นทุนและ payoff ของพอร์ตเป็นผลรวมของราคาคูณจำนวนที่ถือ
Feasible region
ทุกแผนที่ผ่านข้อจำกัดครบทุกข้อ เป็นพื้นที่ที่เราเลือกได้ ส่วนเป้าหมายเป็นตัวตัดสินว่าจุดไหนในพื้นที่นั้นดีที่สุด
จุดมุม (vertex)
จุดในพื้นที่ที่ข้อจำกัดสองข้อชนพอดีเมื่อมีสองตัวแปร เส้นต้นทุนที่เลื่อนลงจนเกือบหลุดพื้นที่จะแตะที่มุม มุมจึงเป็นผู้สมัครที่ต้องตรวจ
Arbitrage
พอร์ตที่ไม่มีทางเสียเงินในอนาคต แต่ได้เงินวันนี้หรือไม่ต้องจ่ายอะไรเลย ถ้ามี ต้นทุน hedge จะลดลงได้ไม่มีพื้น
Incomplete market
ตลาดที่มีสภาวะมากกว่าจำนวนสินทรัพย์ที่ผสมกันได้ payoff บางแบบจึงสร้างให้ตรงทุกช่องไม่ได้ ต้องจ่ายเกินในบางสภาวะ
Dollar beta
มูลค่า position คูณ beta บอกว่า position ขยับกี่ดอลลาร์ต่อการขยับของตลาด ใช้บวกลบ exposure ของหลาย position ในหน่วยเดียวกันได้
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$\theta_1,\ \theta_2$จำนวนหุ้นและจำนวนพันธบัตรที่ถือ ติดลบคือ shortหน่วย
$p$ราคาวันนี้ของหุ้นและพันธบัตร $(100, 95)$USD ต่อหน่วย
$S$ตาราง payoff ปีหน้า แถวคือสภาวะ คอลัมน์คือสินทรัพย์USD ต่อหน่วย
$X,\ y$ภาระที่ต้องจ่าย และ payoff ของพอร์ต $y=S\theta$ ในแต่ละสภาวะUSD
$w_1,\ w_2$น้ำหนักที่คูณสองแถวที่ชนพอดีเพื่อพิสูจน์คำตอบUSD วันนี้ต่อ USD ปีหน้า
$x_Q,\ x_S$ขนาด short QQQ และ SPYล้าน USD

ขั้นที่ 1 — ของที่โจทย์ให้: สามสภาวะ สองสินทรัพย์

ทุกตัวเลขในขั้นนี้เป็นของที่โจทย์ให้ ยังไม่มีการคำนวณ เราวางแถวเป็นสภาวะและคอลัมน์เป็นสินทรัพย์ เพราะเดี๋ยวจะคูณตารางนี้กับจำนวนที่ถือ แล้วได้ payoff ของทั้งพอร์ตทีละสภาวะ

\[ \begin{aligned} p&=\begin{bmatrix}100\\95\end{bmatrix},\qquad X=\begin{bmatrix}120\\90\\50\end{bmatrix},\\ S&=\begin{bmatrix}130&100\\100&100\\70&100\end{bmatrix},\qquad \theta=\begin{bmatrix}\theta_1\\\theta_2\end{bmatrix}. \end{aligned} \]

คอลัมน์แรกของ $S$ คือหุ้นหนึ่งหุ้น ได้ \$130, \$100 หรือ \$70 คอลัมน์ที่สองคือพันธบัตรหนึ่งหน่วย ได้ \$100 ทุกแถว สิ่งที่เราเลือกคือ $\theta_1$ จำนวนหุ้น และ $\theta_2$ จำนวนพันธบัตร ทั้งคู่ติดลบได้ ถ้า $\theta_2\lt0$ คือขายพันธบัตรที่ยืมมา ได้เงิน \$95 ต่อหน่วยวันนี้แล้วคืน \$100 ปีหน้า ซึ่งก็คือการกู้เงิน

มีสามสภาวะแต่มีของให้ผสมแค่สองอย่าง จำคู่เลข 3 กับ 2 นี้ไว้ มันคือต้นเหตุของทุกเรื่องที่แปลกในหัวข้อนี้

ขั้นที่ 2 — ต้นทุนวันนี้ payoff ปีหน้า และแผนแรกที่จ่ายครบแน่

ก่อนหาแผนที่ดีที่สุด ต้องเขียนสองสิ่งที่ทุกแผนมี คือเงินที่จ่ายวันนี้ และเงินที่ได้ปีหน้าในแต่ละสภาวะ ทั้งสองเป็นผลรวมของราคาคูณจำนวน จึงเป็นเส้นตรงใน $\theta$ จากนั้นลองแผนที่ง่ายที่สุดที่จ่ายครบแน่ เพื่อให้รู้เพดานของคำตอบ

\[ \begin{aligned} \text{cost}&=100\theta_1+95\theta_2\\ &=p^{\mathsf T}\theta,\\ y&=S\theta\\ &=\begin{bmatrix}130\theta_1+100\theta_2\\100\theta_1+100\theta_2\\70\theta_1+100\theta_2\end{bmatrix},\\ \theta^{\rm b}&=(0,\ 1.2),\\ S\theta^{\rm b}&=(120,\ 120,\ 120),\\ p^{\mathsf T}\theta^{\rm b}&=95(1.2)=114. \end{aligned} \]

แผน $\theta^{\rm b}$ คือพันธบัตรล้วน 1.2 หน่วย จ่าย \$120 ทุกกรณี จึงผ่านแน่ แต่จ่ายเกิน \$30 ในกรณีทรงตัวและ \$70 ในกรณีลง ราคา \$114 จึงเป็นเพดาน คำตอบที่ดีที่สุดต้องไม่แพงกว่านี้ งานที่เหลือคือหาว่าลงได้ต่ำแค่ไหน

ขั้นที่ 3 — ทำไมเป็น ≥ ไม่ใช่ = : กรณีทรงตัวถูกล็อกไว้ที่ค่าเฉลี่ย

ถ้าอยากได้ payoff เท่าภาระพอดีทุกกรณี ก็คือสามสมการ แต่มีตัวแปรแค่สองตัว การนับอย่างเดียวยังไม่บอกว่าทำไมไม่มีคำตอบ ให้ดูแถวของ $S$: ราคาหุ้นกรณีทรงตัว \$100 อยู่กึ่งกลาง \$130 กับ \$70 พอดี และพันธบัตรจ่ายเท่ากันทุกแถว

\[ \begin{aligned} y_{\rm flat}&=100\theta_1+100\theta_2\\ &=\tfrac12(130\theta_1+100\theta_2)\\ &\quad+\tfrac12(70\theta_1+100\theta_2)\\ &=\tfrac12\,(y_{\rm up}+y_{\rm down}),\\ \tfrac12(X_{\rm up}+X_{\rm down})&=\tfrac12(120+50)=85,\\ X_{\rm flat}&=90\ne85,\\ \min_{\theta}\ p^{\mathsf T}\theta&\quad\text{s.t.}\quad S\theta\ge X. \end{aligned} \]

บรรทัดที่สี่คือหัวใจ: payoff กรณีทรงตัวของพอร์ตใด ๆ เท่ากับค่าเฉลี่ยของกรณีขึ้นกับกรณีลงเสมอ ถ้าพอร์ตจ่าย \$120 กับ \$50 ได้พอดี กรณีทรงตัวจะได้ \$85 ไม่ใช่ \$90 การสร้างภาระนี้ให้ตรงทุกช่องจึงเป็นไปไม่ได้ ตลาดแบบนี้เรียกว่า incomplete market

นี่คือเหตุที่โจทย์ใช้ $\ge$: ลูกค้าไม่ว่าอะไรถ้าได้เงินเกิน แต่ขาดไม่ได้แม้แต่สภาวะเดียว และเป้าหมายที่หาต้นทุนต่ำสุดจะรีดส่วนเกินที่ไม่จำเป็นออกเอง บรรทัดสุดท้ายคือ LP ของเรา ไม่มีเงื่อนไขเครื่องหมายบน $\theta$ เพราะ short ได้ทั้งคู่

ขั้นที่ 4 — ต้นทุนมีพื้นไหม: ตรวจว่าไม่มีเงินฟรี

ก่อนหาค่าต่ำสุด ต้องแน่ใจว่ามันมีอยู่ ถ้ามีทิศ $d$ ที่ไม่ลด payoff ในสภาวะใดเลยแต่ต้นทุนติดลบ เราจะเดินไปทางนั้นได้เรื่อย ๆ จ่ายภาระครบและรับเงินเพิ่มไม่สิ้นสุด วิธีตรวจคือเขียนทิศใด ๆ เป็นส่วนผสมของสองทิศพิเศษ ทิศ $A$ ทำให้กรณีลงไม่ขยับ ทิศ $B$ ทำให้กรณีขึ้นไม่ขยับ

\[ \begin{aligned} A&=(1,\ -0.7),\\ SA&=(60,\ 30,\ 0),\\ p^{\mathsf T}A&=100-66.5=33.5,\\ B&=(-1,\ 1.3),\\ SB&=(0,\ 30,\ 60),\\ p^{\mathsf T}B&=-100+123.5=23.5,\\ d&=aA+bB,\\ Sd&=(60a,\ 30a+30b,\ 60b),\\ p^{\mathsf T}d&=33.5a+23.5b. \end{aligned} \]

ทิศ $d$ ใด ๆ แยกเป็น $A$ กับ $B$ ได้เสมอ: เลือก $a$ ให้ payoff กรณีขึ้นเปลี่ยนเท่าที่ $d$ ทำ และเลือก $b$ ให้กรณีลงเปลี่ยนเท่าที่ $d$ ทำ สองค่านี้ตรึง $d$ ได้ตัวเดียว เพราะหุ้นกับพันธบัตรไม่ใช่ของซ้ำกัน

ถ้า $d$ ไม่ลด payoff สภาวะใดเลย ช่องแรกและช่องสุดท้ายของ $Sd$ บังคับให้ $a\ge0$ และ $b\ge0$ ต้นทุนของ $d$ จึงไม่ติดลบ และเป็นศูนย์ได้เฉพาะเมื่อ $d$ ไม่ขยับเลย ไม่มีเงินฟรี ต้นทุนจึงมีพื้น ตัวเลข $33.5/60\approx0.5583$ กับ $23.5/60\approx0.3917$ จะกลับมาใน 11.3

ขั้นที่ 5 — มุมสามมุม และมุมที่ถูกที่สุดตกรอบ

เส้นต้นทุนคงที่ $100\theta_1+95\theta_2=k$ ขนานกันทุกค่า $k$ นึกภาพเลื่อนเส้นนี้ไปทางที่ถูกลงจนเกือบหลุดพื้นที่ที่จ่ายครบ จุดสุดท้ายที่ยังแตะคือมุมที่สองแถวชนพอดี สองตัวแปรใช้สองสมการตรึงจุด เลือกสองแถวจากสามได้สามคู่ และทุกคู่ต้องเสียบกลับแถวที่เหลือ

\[ \begin{aligned} \theta^{\rm uf}&=(1,\ -0.1),\\ p^{\mathsf T}\theta^{\rm uf}&=100-9.5=90.50,\\ y^{\rm uf}_{\rm down}&=70-10=60\ge50,\\ \theta^{\rm ud}&=(\tfrac76,\ -\tfrac{19}{60}),\\ p^{\mathsf T}\theta^{\rm ud}&=\tfrac{700}{6}-\tfrac{1805}{60}\approx86.58,\\ y^{\rm ud}_{\rm flat}&=\tfrac12(120+50)=85\lt90,\\ \theta^{\rm fd}&=(\tfrac43,\ -\tfrac{13}{30}),\\ p^{\mathsf T}\theta^{\rm fd}&=\tfrac{400}{3}-\tfrac{1235}{30}\approx92.17,\\ y^{\rm fd}_{\rm up}&=\tfrac{520}{3}-\tfrac{130}{3}=130\ge120. \end{aligned} \]

ตัวยกบอกว่าแถวไหนชนพอดี เช่น $\theta^{\rm uf}$ คือมุมที่แถวขึ้น (up) กับแถวทรงตัว (flat) ชน ทุกคู่ลบสองแถวกันได้ทันที เพราะพันธบัตรจ่าย \$100 ในทุกแถว พจน์ $100\theta_2$ จึงหักหาย เหลือหุ้นตัวเดียว: $(130-100)\theta_1=120-90$ ได้ $\theta_1=1$ แล้วแทนในแถวทรงตัว $100\theta_2=90-100$ ได้ $\theta_2=-0.1$ อีกสองคู่ใช้ $60\theta_1=120-50$ และ $30\theta_1=90-50$

มุมที่ถูกที่สุด \$86.58 คือแผนของเพื่อนในโจทย์เปิด และมันตกแถวทรงตัวที่ \$85 ตามที่ขั้นที่ 3 ทำนายไว้ อีกสองมุมผ่านทุกแถว ราคา \$90.50 และ \$92.17 ถ้ารับมุมแรกไปโดยไม่เสียบกลับ โต๊ะจะขาดเงิน \$5 ในปีที่ตลาดทรงตัว

ขั้นที่ 6 — พิสูจน์ว่า \$90.50 ต่ำสุดจริงด้วยบรรทัดเดียว

ดูแค่สามมุมยังไม่พอ ต้องแน่ใจว่าไม่มีจุดอื่นในพื้นที่ที่ถูกกว่า วิธีที่สั้นที่สุดคือหาน้ำหนักสองตัวที่คูณแถวขึ้นกับแถวทรงตัว (สองแถวที่ชนพอดีที่มุมผู้ชนะ) แล้วรวมกันได้เวกเตอร์ราคา $p$ พอดี

\[ \begin{aligned} &130w_1+100w_2=100,\\ &100w_1+100w_2=95,\\ &30w_1=5,\qquad w_1=\tfrac16,\\ &w_2=0.95-\tfrac16=\tfrac{47}{60},\\ &p^{\mathsf T}\theta=\tfrac16\,y_{\rm up}+\tfrac{47}{60}\,y_{\rm flat}\\ &\qquad\ge\tfrac16(120)+\tfrac{47}{60}(90)\\ &\qquad=20+70.5=90.50. \end{aligned} \]

สองบรรทัดแรกคือเงื่อนไขที่ต้องการ: แถวขึ้นคูณ $w_1$ บวกแถวทรงตัวคูณ $w_2$ ต้องได้ราคาหุ้น \$100 ในคอลัมน์หุ้น และราคาพันธบัตร \$95 ในคอลัมน์พันธบัตร ลบบรรทัดที่สองออกจากบรรทัดแรก พจน์ $100w_2$ หักหาย เหลือ $30w_1=5$

บรรทัดที่เริ่มด้วย $p^{\mathsf T}\theta$ ไม่ใช่การประมาณ มันคือต้นทุนเดิมที่จัดใหม่: กระจาย $\tfrac16(130\theta_1+100\theta_2)+\tfrac{47}{60}(100\theta_1+100\theta_2)$ แล้วได้ $100\theta_1+95\theta_2$ พอดีทุกพอร์ต

จังหวะที่ทำให้พิสูจน์ได้คือเครื่องหมาย $\ge$ แผนที่จ่ายครบมี $y_{\rm up}\ge120$ และ $y_{\rm flat}\ge90$ และน้ำหนักทั้งสองเป็นบวก จึงแทนด้วยค่าต่ำสุดได้โดยอสมการไม่พลิก ทุกแผนที่จ่ายครบจึงใช้เงินอย่างน้อย \$90.50 และเท่าพอดีเมื่อสองแถวนั้นชนพอดี ซึ่งคือ $\theta=(1, -0.1)$ เท่านั้น

ถ้าน้ำหนักตัวใดติดลบ การพิสูจน์ใช้ไม่ได้ ที่มุม $(\tfrac43, -\tfrac{13}{30})$ น้ำหนักของแถวลงออกมาเป็น $-\tfrac16$ แปลว่าเพิ่ม payoff กรณีลงแล้วต้นทุนกลับลด มุมนั้นจึงยังไม่ใช่คำตอบ

ขั้นที่ 7 — อ่านคำตอบเป็นเงินสด และส่วนเกิน \$10 ที่ตัดทิ้งไม่ได้

คำตอบเป็นจำนวนหน่วย โต๊ะต้องแปลงกลับเป็นเงินที่ไหลวันนี้และปีหน้า แล้วดูว่าแต่ละสภาวะเหลือเท่าไร

\[ \begin{aligned} p^{\mathsf T}\theta^*&=100(1)+95(-0.1)\\ &=90.50,\\ e&:=S\theta-X\ge0,\\ e(\theta^*)&=(120,\ 90,\ 60)-X\\ &=(0,\ 0,\ 10),\\ e_{\rm flat}&=\tfrac12(y_{\rm up}+y_{\rm down})-90\\ &=\tfrac12(e_{\rm up}+e_{\rm down})-5,\\ e_{\rm up}+e_{\rm down}&=2e_{\rm flat}+10\ge10. \end{aligned} \]

ซื้อหุ้น 1 หุ้นจ่าย \$100 และ short พันธบัตร 0.1 หน่วยได้เงิน \$9.50 ซึ่งคือกู้ \$9.50 แล้วคืน \$10 ปีหน้าทุกกรณี (ดอกเบี้ย $10/9.5-1\approx5.26\%$) ปีหน้าหุ้นให้ \$130, \$100, \$70 หักคืนเงินกู้ \$10 เหลือ \$120, \$90, \$60 กรณีขึ้นและทรงตัวจ่ายพอดี กรณีลงเหลือ \$10

สามบรรทัดสุดท้ายบอกว่าส่วนเกินนี้ตัดไม่ได้ ไม่ว่าแผนไหน ให้ $e$ คือส่วนเกินของแต่ละสภาวะ แทน $y=X+e$ ในกฎค่าเฉลี่ยของขั้นที่ 3 แล้วเลข $-5$ มาจาก $\tfrac12(120+50)-90$ ผลคือส่วนเกินกรณีขึ้นบวกกรณีลงต้องไม่น้อยกว่า \$10 เสมอ แผนที่ถูกที่สุดวางเงิน \$10 นั้นไว้ในกรณีลงทั้งก้อน ซึ่ง 11.3 จะอธิบายว่าทำไมกรณีลงเป็นที่ที่ถูกที่สุดสำหรับเงินส่วนนี้

ตัวอย่างที่สอง — ลด beta ด้วย QQQ และ SPY ภายใต้เพดานสภาพคล่อง

โครงเดียวกันใช้กับงานที่พบทุกวันบนโต๊ะหุ้น ตะกร้าหุ้น semiconductor มูลค่า \$12 ล้าน มี beta 1.10 ฝ่ายความเสี่ยงสั่งให้ beta ที่เหลือไม่เกิน 0.20 เครื่องมือคือ short QQQ ซึ่งมี beta 1.20 และ short SPY ซึ่งมี beta 1.00 เพราะใช้เป็นตัวแทนตลาด เพดานสภาพคล่องของโต๊ะคือ short ได้ไม่เกิน \$6 ล้านต่อตัว และต้นทุนซื้อขาย (สมมติ) คือ \$180 และ \$90 ต่อ notional \$1 ล้าน หรือ 1.8 และ 0.9 basis points

ขั้นที่ 8 — แปลงคำสั่ง “beta ไม่เกิน 0.20” ให้เป็นอสมการ

คำสั่งมาเป็นประโยค ต้องแปลเป็นสมการที่ตรวจได้ เริ่มจาก dollar beta เพราะมันบวกลบข้าม position ได้: ตะกร้ามี $12(1.10)=13.2$ short QQQ \$1 ล้านหักได้ 1.2 และ short SPY \$1 ล้านหักได้ 1.0 แล้วหารด้วยขนาดตะกร้ากลับเป็น beta

\[ \begin{aligned} &R=\frac{13.2-1.2x_Q-x_S}{12}\le0.20,\\ &13.2-1.2x_Q-x_S\le2.4,\\ &-1.2x_Q-x_S\le-10.8,\\ &1.2x_Q+x_S\ge10.8,\\ &0\le x_Q\le6,\qquad 0\le x_S\le6,\\ &C=180x_Q+90x_S. \end{aligned} \]

บรรทัดที่สองคูณ 12 ทั้งสองข้าง ($12\times0.20=2.4$) บรรทัดที่สามย้าย 13.2 ข้ามข้าง ($2.4-13.2=-10.8$) จังหวะที่ต้องระวังคือบรรทัดที่สี่ คูณทั้งสองข้างด้วย $-1$ แล้วอสมการต้องพลิกจาก $\le$ เป็น $\ge$ ถ้าลืมพลิก โจทย์จะกลายเป็น “ลด beta ไม่เกิน 10.8” และแผนที่ถูกที่สุดคือไม่ทำอะไรเลย (ดูกับดักท้ายหน้า)

10.8 มีหน่วย beta-ล้าน USD อ่านว่า hedge ต้องหักการขยับตามตลาดออกอย่างน้อย \$108,000 ต่อการขยับของตลาด 1% ขนาด short ไม่ติดลบเพราะเราเลือกทิศ short ไว้แล้ว ส่วนเพดาน 6 มาจากนโยบายสภาพคล่อง ไม่ได้คำนวณมา

ขั้นที่ 9 — ลองทีละตัว แล้วเรียงตามต้นทุนต่อ beta

โจทย์ให้อะไรมาบ้าง: ข้อจำกัดจากขั้นที่ 8 และต้นทุน \$180 กับ \$90 ต่อ \$1 ล้าน ให้ $x^{(1)}$ คือขนาดที่ต้องใช้ถ้าใช้เครื่องมือตัวเดียว

\[ \begin{aligned} x_Q^{(1)}&=10.8/1.2=9\gt6,\\ x_S^{(1)}&=10.8/1=10.8\gt6,\\ 180/1.2&=150,\\ 90/1&=90,\\ x_S&=6,\\ x_Q&=(10.8-6)/1.2=4,\\ C&=180(4)+90(6)\\ &=720+540=1{,}260. \end{aligned} \]

คำตอบ: ใช้ตัวเดียวไม่ได้ทั้งคู่เพราะชนเพดาน 6 จึงต้องผสม SPY ลด beta หนึ่งหน่วยได้ถูกกว่า (\$90 เทียบ \$150) จึงใช้ SPY จนเต็ม \$6 ล้าน แล้วให้ QQQ เติมส่วนที่ขาด 4.8 ซึ่งต้องใช้ \$4 ล้าน ยังอยู่ในเพดาน ต้นทุนรวม \$1,260

ตรวจเองใน 10 วินาที: $1.2\times4+6=10.8$ ลด beta ได้พอดี และ beta ที่เหลือคือ $1.10-10.8/12=0.20$ พอดีเป้า สิ่งที่ต้องเทียบคือต้นทุนต่อ beta ที่ลดได้ ไม่ใช่ต่อดอลลาร์ ที่นี่สองวิธีให้ลำดับเดียวกัน แต่โจทย์ข้อ 3 ท้ายหน้าเป็นกรณีที่ลำดับกลับกัน

ขั้นที่ 10 — พิสูจน์ด้วยน้ำหนักสองตัว แบบเดียวกับขั้นที่ 6

การเรียงตามต้นทุนต่อ beta ให้คำตอบ แต่ยังไม่ใช่ข้อพิสูจน์ ใช้วิธีของขั้นที่ 6: เขียนต้นทุนใหม่ด้วยสองแถวที่ชนพอดีที่ $(4,6)$ คือแถว beta และเพดาน SPY

\[ \begin{aligned} 180x_Q+90x_S&=150(1.2x_Q+x_S)\\ &\quad-60x_S\\ &\ge150(10.8)-60(6)\\ &=1{,}620-360\\ &=1{,}260=C(4,\ 6). \end{aligned} \]

สองบรรทัดแรกเป็นการจัดต้นทุนใหม่ ตรวจได้ว่า $150\times1.2=180$ และ $150-60=90$ บรรทัดที่สามแทนสองแถวที่ชน: beta ที่ลดได้ไม่น้อยกว่า 10.8 คูณด้วย 150 ซึ่งเป็นบวก ส่วน $x_S\le6$ คูณด้วย $-60$ จึงได้ $-60x_S\ge-360$ ทุกแผนที่ผ่านกฎจึงใช้เงินอย่างน้อย \$1,260 และเท่าพอดีเฉพาะเมื่อ beta ลดพอดี 10.8 และ SPY เต็ม 6

สองน้ำหนักนี้มีความหมาย: 150 คือต้นทุนต่อ beta ของตัวที่เติมส่วนสุดท้าย (QQQ) ส่วน 60 คือเงินที่ประหยัดได้ถ้า SPY ได้เพดานเพิ่ม \$1 ล้าน เพราะเอา SPY \$90 ไปแทน QQQ ที่ลด beta เท่ากันในราคา \$150 11.3 จะเรียกสองตัวนี้ว่า shadow price

คำถามที่ควรถามออกมาดัง ๆ

ทำไมไม่ใช้ค่าคาดหวังของภาระ? โจทย์ไม่ได้ให้โอกาสของแต่ละสภาวะ และ superhedge ไม่ต้องใช้มัน เพราะต้องจ่ายครบไม่ว่าสภาวะไหนเกิด ราคา \$90.50 จึงไม่ขึ้นกับว่าใครเชื่อว่าตลาดมีโอกาสขึ้นเท่าไร ใครสองคนที่เห็นต่างเรื่องโอกาสก็ต้องได้ตัวเลขนี้ตรงกัน

ต้นทุนไม่มีพื้นหน้าตาเป็นอย่างไร? สมมติหุ้นราคา \$135 ทั้งที่ปีหน้าได้มากสุด \$130 ทิศ $B=(-1, 1.3)$ มีต้นทุน $-135+123.5=-11.5$ คือได้เงินวันนี้ \$11.50 และ payoff $(0, 30, 60)$ ไม่มีทางติดลบ เดินไปทางนั้นซ้ำได้ไม่จำกัด solver จะตอบว่า unbounded ซึ่งในภาษาการเงินคือเจอ arbitrage

ถ้ามี 500 สภาวะและ 20 สินทรัพย์ล่ะ? รูปเดิมทุกอย่าง แค่ $S$ ใหญ่ขึ้น แต่การไล่ทุกมุมใช้ไม่ได้แล้ว เพราะการเลือก 20 แถวจาก 500 มีราว $2.7\times10^{35}$ วิธี solver จึงเดินจากมุมไปมุมข้างเคียงที่ถูกลง (simplex) และต้องรับโจทย์ในรูปมาตรฐาน ซึ่งคือเรื่องของ 11.2

ความผิดที่ให้คำตอบผิดโดยไม่มี error

ใส่ $\theta\ge0$ เพราะเคยชิน: solver หลายตัวตั้งค่าเริ่มต้นให้ตัวแปรไม่ติดลบ ถ้าปล่อยไว้ คำตอบจะย้ายไปซื้อหุ้น $12/13\approx0.9231$ หุ้นโดยไม่มีพันธบัตร ราคา \$92.31 แพงขึ้น \$1.81 โดยไม่มีคำเตือนใด ๆ เครื่องหมายของตัวแปรเป็นข้อมูลของโจทย์ ต้องเขียนเองทุกครั้ง

ลืมพลิกอสมการ beta: ถ้าเขียน $1.2x_Q+x_S\le10.8$ แผนที่ถูกที่สุดคือ $(0,0)$ ต้นทุน \$0 และ beta ยังเป็น 1.10 วิธีจับคือทดสอบแผนไม่ทำอะไรทุกครั้ง ถ้ามันผ่านกฎขั้นต่ำของการ hedge แปลว่ากฎกลับหัว

แก้สองแถวแล้วไม่เสียบแถวที่สาม: มุม \$86.58 ดูถูกที่สุดในสามมุม แต่จ่ายกรณีทรงตัวได้แค่ \$85 ทุกครั้งที่แก้จากข้อจำกัดบางข้อ ต้องเอาคำตอบไปตรวจข้อที่เหลือทุกข้อก่อนเทียบราคา

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะ structuring ที่ขายสินค้าซึ่งจ่ายตามสภาวะตลาดใช้โจทย์แรกตรง ๆ ต้นทุน superhedge \$90.50 คือราคาต่ำสุดที่ขายได้โดยไม่ต้องรับความเสี่ยงเลย ส่วนที่บวกเพิ่มคือกำไรของโต๊ะ ถ้าลูกค้าต่อรองต่ำกว่านี้ การรับงานคือการเลือกรับความเสี่ยงในบางสภาวะ ไม่ใช่การ hedge ที่ประหยัดขึ้น

โต๊ะที่ต้องลด beta ภายใต้ limit ใช้โจทย์ที่สองในระบบก่อนส่งคำสั่ง ข้อจำกัดเป็นอสมการที่ฝ่ายความเสี่ยงตรวจได้ทีละแถว และคำตอบมาพร้อมน้ำหนัก 150 กับ 60 ที่บอกว่าเพดานไหนกำลังทำให้เสียเงิน

สามโจทย์ตรวจความเข้าใจ

1. ถ้าภาระกรณีทรงตัวลดจาก \$90 เป็น \$85 (ภาระ \$120, \$85, \$50) ต้นทุนต่ำสุดเท่าไร และยังต้องเหลือเงินทิ้งในสภาวะใดไหม?

เฉลย

$85=\tfrac12(120+50)$ พอดี ภาระนี้จึงสร้างได้ตรงทุกช่อง ทั้งสามแถวชนพอดีที่ $\theta=(\tfrac76, -\tfrac{19}{60})$ payoff $(120, 85, 50)$ ไม่เหลือเงินทิ้งเลย ต้นทุน $\tfrac{700}{6}-\tfrac{1805}{60}\approx\$86.58$ น้ำหนักเดิมพิสูจน์ได้: $\tfrac16(120)+\tfrac{47}{60}(85)=20+66.58=86.58$ ภาระที่สร้างได้ตรงมีราคาเดียว ถ้าขายถูกหรือแพงกว่านี้จะมีคนทำเงินฟรีจากส่วนต่าง

2. ในโจทย์ของ 7.4 หุ้นราคา \$100 จ่าย \$120, \$100, \$70 พันธบัตรราคา \$100 จ่าย \$105 ทุกกรณี และภาระคือ \$110, \$100, \$80 7.4 เจอแผน $(0.5, \tfrac{10}{21})$ ราคา \$97.62 แผนนี้ถูกที่สุดแล้วหรือยัง?

เฉลย

ถูกที่สุดแล้ว มุมสามมุมคือ $(0.5, \tfrac{10}{21})$ ราคา \$97.62 ผ่านทุกแถว, $(0.6, 0.3619)$ ราคา \$96.19 แต่แถวกลางได้ \$98 ขาด \$2 และ $(\tfrac23, 0.3175)$ ราคา \$98.41 พิสูจน์ด้วยน้ำหนักบนแถวแรกกับแถวกลาง: $120w_1+100w_2=100$ และ $105(w_1+w_2)=100$ ได้ $w_1=\tfrac{5}{21}$, $w_2=\tfrac57$ ทั้งคู่บวก จึงได้ต้นทุนอย่างน้อย $110(\tfrac{5}{21})+100(\tfrac57)=26.19+71.43=\$97.62$

3. ถ้าต้นทุน SPY ขึ้นเป็น \$160 ต่อ \$1 ล้าน (QQQ ยัง \$180) SPY ยังถูกกว่าต่อดอลลาร์ ควรใช้ SPY จนเต็มก่อนเหมือนเดิมไหม?

เฉลย

ไม่ ต่อ beta QQQ ถูกกว่า ($180/1.2=150$ เทียบ $160/1=160$) จึงใช้ QQQ เต็ม \$6 ล้าน ลดได้ 7.2 แล้วให้ SPY เติม 3.6 ต้นทุน $180(6)+160(3.6)=1{,}080+576=\$1{,}656$ แผนใช้ SPY ก่อน $(4, 6)$ ต้องจ่าย $720+960=\$1{,}680$ แพงกว่า \$24 พิสูจน์: $180x_Q+160x_S=160(1.2x_Q+x_S)-12x_Q\ge1{,}728-72=1{,}656$

คำนวณซ้ำด้วย JavaScript

รันใน Node.js ได้โดยไม่ติดตั้งแพ็กเกจ ฟังก์ชัน solveLP แก้ LP สองตัวแปรแบบเดียวกับที่ทำด้วยมือ: ตัดทุกคู่ของแถวเป็นมุม เสียบกลับทุกแถว หาน้ำหนักที่รวมสองแถวที่ชนเป็นเวกเตอร์ต้นทุน แล้วรับเฉพาะมุมที่ผ่านทุกแถวและน้ำหนักไม่ติดลบ ซึ่งพิสูจน์ตัวเองว่าถูกที่สุด ถ้าไม่มีมุมแบบนั้น โค้ดปฏิเสธแทนการเดา

// Linear programs with two decision variables: minimise c.x subject to every row A[k].x >= b[k].
function checkProblem(c, A, b) {
  const pair = v => Array.isArray(v) && v.length === 2 && v.every(Number.isFinite);
  if (!pair(c)) throw new TypeError('Cost must be two finite numbers');
  if (!Array.isArray(A) || A.length < 2 || !A.every(pair)) throw new TypeError('Need at least two rows of two finite numbers');
  if (!Array.isArray(b) || b.length !== A.length || !b.every(Number.isFinite)) throw new TypeError('Need one finite limit per row');
}
// Solve [[a, b], [c, d]] [x, y] = [e, f] by Cramer's rule; null when the two rows are parallel.
function solve2x2(a, b, c, d, e, f) {
  const det = a * d - b * c;
  if (Math.abs(det) < 1e-12 * (Math.abs(a * d) + Math.abs(b * c) + 1e-300)) return null;
  return [(e * d - b * f) / det, (a * f - e * c) / det];
}
const dot = (u, v) => u[0] * v[0] + u[1] * v[1];
function solveLP(c, A, b) {
  checkProblem(c, A, b);
  const corners = [];
  for (let i = 0; i < A.length; i++) for (let j = i + 1; j < A.length; j++) {
    const x = solve2x2(A[i][0], A[i][1], A[j][0], A[j][1], b[i], b[j]);
    if (!x) continue;
    const slack = A.map((row, k) => dot(row, x) - b[k]);
    const feasible = slack.every((s, k) => s >= -1e-9 * (1 + Math.abs(b[k])));
    // Weights on the two binding rows that rebuild the cost vector: w_i A[i] + w_j A[j] = c.
    const weights = solve2x2(A[i][0], A[j][0], A[i][1], A[j][1], c[0], c[1]);
    corners.push({rows: [i, j], x, cost: dot(c, x), feasible, slack, weights});
  }
  // A feasible corner whose weights are all >= 0 proves itself cheapest: cost >= w.b for every feasible x.
  const proven = corners.filter(k => k.feasible && k.weights.every(w => w >= -1e-12)).sort((p, q) => p.cost - q.cost);
  if (!proven.length) throw new RangeError('No corner proves itself cheapest: the rules clash or the cost has no floor');
  const best = proven[0];
  return {...best, bound: best.weights[0] * b[best.rows[0]] + best.weights[1] * b[best.rows[1]], corners};
}
// Superhedge: rows are the states up, flat, down; columns are one share and one bond.
const S = [[130, 100], [100, 100], [70, 100]], X = [120, 90, 50], p = [100, 95];
const payoff = t => S.map(row => dot(row, t));
const hedge = solveLP(p, S, X);
const noShort = solveLP(p, [...S, [1, 0], [0, 1]], [...X, 0, 0]);
const edgeA = [1, -0.7], edgeB = [-1, 1.3];
// Beta hedge: rows are the beta floor, the two caps written as -x >= -6, and the no-long rules x >= 0.
const betaRows = [[1.2, 1], [-1, 0], [0, -1], [1, 0], [0, 1]];
const need = 12 * (1.10 - 0.20);
const beta = solveLP([180, 90], betaRows, [need, -6, -6, 0, 0]);

สิ่งที่ควรตอบได้หลังอ่าน

  • superhedge คือ LP: หาค่าต่ำสุดของ $p^{\mathsf T}\theta$ ภายใต้ $S\theta\ge X$ ภาระ \$120/\$90/\$50 ใช้เงิน \$90.50 ที่ $\theta=(1, -0.1)$ ไม่ใช่ \$86.58
  • ในตลาดนี้ payoff กรณีทรงตัวเท่ากับค่าเฉลี่ยของขึ้นกับลงเสมอ ภาระที่กรณีทรงตัวไม่ใช่ค่าเฉลี่ยจึงสร้างตรงไม่ได้ และต้องเหลือเงิน \$10 ในกรณีลง
  • ต้นทุนมีพื้นเมื่อไม่มีทิศที่ได้ของฟรี ทิศ $A$ และ $B$ ใช้เงิน \$33.50 และ \$23.50 จึงไม่มี arbitrage
  • มุมต้องเสียบกลับทุกแถว และมุมที่ถูกที่สุดพิสูจน์ตัวเองได้ด้วยน้ำหนักไม่ติดลบ $(\tfrac16, \tfrac{47}{60})$ ที่รวมแถวที่ชนเป็นเวกเตอร์ราคา
