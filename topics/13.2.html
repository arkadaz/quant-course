13.2 The Black–Scholes Formula

แกะราคาสิทธิ์ซื้อหุ้นทีละส่วนจนเห็นที่มาของทุกตัวเลข

European call บนหุ้นราคา spot \$100 มี strike \$105 อายุ 0.25 ปี ดอกเบี้ยปลอดความเสี่ยง 4% ต่อปี ความผันผวน 20% ควรมีราคาเท่าไร และโอกาสทางทฤษฎีที่จะได้ใช้สิทธิ์เป็นกี่เปอร์เซ็นต์?

เฉลย: ราคา call คือ \$2.39 (put คือ \$6.35) โอกาสใช้สิทธิ์ตามแบบจำลองคือ 33.07% (จาก $d_2 = -0.4379$) ส่วนจำนวนหุ้นทำซ้ำหรือ Delta คือ 0.3677 (จาก $d_1 = -0.3379$)

ศัพท์ชุดแรก: สัญญาและกติกาที่ใช้ตั้งราคา
European call

คืออะไร: สิทธิ์ที่ให้ผู้ถือ *ซื้อ* หุ้นที่ราคาตกลงไว้ ใช้ได้เฉพาะวันหมดอายุวันเดียว

ใช้ทำอะไร: เป็นสัญญาที่สูตรในหัวข้อนี้ตั้งราคาให้เป็นตัวแรก ส่วนตัวอื่นได้มาจากตัวนี้เกือบทั้งหมด

ทำไมต้องเริ่มจากตัวนี้: เพราะเงินที่ได้รับตอนหมดอายุเขียนเป็นสูตรได้ในบรรทัดเดียว แต่ยังมีความไม่แน่นอนจริงให้ต้องคิด

European put

คืออะไร: สิทธิ์ที่ให้ผู้ถือ *ขาย* หุ้นที่ราคาตกลงไว้ ใช้ได้เฉพาะวันหมดอายุเช่นกัน

ใช้ทำอะไร: ใช้ป้องกันขาลง คนถือหุ้นซื้อตัวนี้ไว้เพื่อกำหนดราคาขายขั้นต่ำ

ทำไมต้องรู้คู่กัน: เพราะราคาของมันไม่ต้องพิสูจน์ใหม่ พอได้ราคา call แล้ว ความสัมพันธ์ในขั้นที่ 12 ให้ราคา put ทันที

risk-neutral measure

คืออะไร: กติกาถ่วงน้ำหนักโอกาสของเส้นทางราคาแบบใหม่ ที่เลือกมาให้ราคาหุ้นหลังหักดอกเบี้ยแล้วไม่มีทิศทางเฉลี่ยเหลืออยู่

ใช้ทำอะไร: ใช้เป็นกติกาเดียวที่เราคำนวณค่าเฉลี่ยของเงินรับปลายทางภายใต้มัน

ทำไมต้องใช้: เพราะถ้าใช้ความน่าจะเป็นจริงของโลก เราต้องรู้ว่าหุ้นจะโตเฉลี่ยเท่าไร ซึ่งไม่มีใครรู้ กติกานี้ตัดคำถามนั้นออกไปทั้งข้อ และยังให้ราคาที่ถูกต้อง เพราะราคาที่ได้มาจากต้นทุนของพอร์ตทำซ้ำในหัวข้อ 13.1 ไม่ได้มาจากการเดา

risk-neutral expectation

คืออะไร: ค่าเฉลี่ยที่คำนวณโดยใช้กติกาถ่วงน้ำหนักข้างต้น ไม่ใช่กติกาของโลกจริง

ใช้ทำอะไร: เป็นตัวเลขที่เราคำนวณจริงในขั้นที่ 3 ถึง 5 แล้วคิดลดกลับมาเป็นราคาวันนี้

ทำไมต้องแยกชื่อ: เพราะมันไม่ใช่การพยากรณ์ ตัวเลขนี้ไม่ได้บอกว่าเราคิดว่าหุ้นจะไปทางไหน การเผลออ่านว่าเป็นคำพยากรณ์คือความเข้าใจผิดที่พบบ่อยที่สุดของทั้งบท

martingale
martingale คือ process ที่ conditional expected value ของอนาคตเท่ากับค่าปัจจุบัน ในที่นี้ใช้กับราคาที่ discount แล้ว ไม่ได้หมายความว่าราคาหุ้นดิบไม่มี drift
lognormal distribution

คืออะไร: การกระจายของตัวเลขที่ติดลบไม่ได้ ซึ่ง log ของมันเป็นระฆังคว่ำ เรียนไปแล้วในหัวข้อ 1.10

ใช้ทำอะไร: เป็นรูปร่างของราคาหุ้นในวันหมดอายุตามที่แบบจำลองสมมติไว้

ทำไมต้องใช้: เพราะราคาหุ้นติดลบไม่ได้ ระฆังคว่ำธรรมดาจึงใช้กับราคาโดยตรงไม่ได้ แต่ใช้กับ log ของราคาได้

standard normal

คืออะไร: ระฆังคว่ำที่จัดให้กลางอยู่ที่ศูนย์และความผันผวนเท่ากับหนึ่ง

ใช้ทำอะไร: เป็นแหล่งความสุ่มตัวเดียวของทั้งสูตร เขียนแทนด้วย $Z$

ทำไมต้องใช้: เพราะเมื่อบีบความสุ่มทั้งหมดให้เหลือตัวเดียวที่มีตารางค่าสำเร็จ การหาค่าเฉลี่ยที่ดูเหมือนยากจึงกลายเป็นการเปิดตาราง

normal cumulative distribution function (CDF)

คืออะไร: function ที่ตอบว่าค่าสุ่มมาตรฐานจะออกมาต่ำกว่าเลขที่ถามกี่เปอร์เซ็นต์ เขียนแทนด้วย $\Phi$

ใช้ทำอะไร: เป็นตัวเลขสองตัวที่โผล่ในคำตอบสุดท้าย คือ $\Phi(d_1)$ กับ $\Phi(d_2)$

ทำไมต้องใช้: เพราะพื้นที่ใต้ระฆังคว่ำไม่มีสูตรปิด เราจึงตั้งชื่อให้มันแล้วเปิดค่าจากตารางหรือเครื่องคิดเลข

normal density

คืออะไร: ความสูงของเส้นระฆังคว่ำที่จุดหนึ่ง เขียนแทนด้วย $\phi$

ใช้ทำอะไร: ใช้ระหว่างการพิสูจน์ในขั้นที่ 5 ตอนเลื่อนโค้งไปหนึ่งช่วง

ทำไมต้องแยกจากตัวบน: เพราะตัวหนึ่งคือความสูง อีกตัวคือพื้นที่สะสม สลับกันเมื่อไรก็ได้คำตอบที่ผิดโดยไม่มีอะไรเตือน

หัวข้อนี้เลือกเส้นทางที่ตรงกว่าการแก้สมการ คือคำนวณค่าเฉลี่ยของเงินที่จะได้รับโดยตรง ภายใต้กติกาถ่วงน้ำหนักที่ได้จากบทที่ 12

สิ่งที่ทำให้คำนวณได้จริงคือการแยก payoff ออกเป็นสองก้อน คือได้หุ้นมาก้อนหนึ่ง จ่ายเงินสดออกไปก้อนหนึ่ง แล้วคิดแยกกัน ซึ่งเป็นที่มาของสองพจน์ในสูตรสุดท้าย

ข้อสังเกตสำคัญคือทุกวันนี้ตลาดไม่ได้ใช้สูตรนี้ทำนายราคา แต่ใช้มันแปลงราคาที่ซื้อขายกันจริง ให้เป็นตัวเลขความผันผวนที่เทียบข้ามสัญญาได้ ซึ่งเป็นการใช้งานคนละแบบกับที่ผู้เขียนตั้งใจ

ที่มาและประวัติศาสตร์: การเดินทางสู่สูตรที่ไม่ต้องเดาความกลัว

ก่อนปี 1973 การตั้งราคา option เป็นปริศนาที่ไม่มีใครแก้ตก ราว ๆ ปี 1900 Louis Bachelier เสนอให้ใช้ Brownian motion อธิบายราคาหุ้นบนกระดานปารีส แต่แบบจำลองของเขาทำให้ราคาหุ้นติดลบได้ ต่อมา Paul Samuelson (1965) แก้ด้วย geometric Brownian motion สำหรับตั้งราคา warrant ทว่าสูตรของ Samuelson ยังติดตัวแปร $\mu$ หรือผลตอบแทนเฉลี่ยที่คาดหวังของหุ้น ซึ่งไม่มีใครรู้ว่าควรเป็นเท่าไร เพราะขึ้นกับความพึงพอใจและความกลัวความเสี่ยงของแต่ละคนเหมือนปัญหา St. Petersburg paradox

Fischer Black, Myron Scholes และ Robert C. Merton (ราว ๆ 1973) ค้นพบจุดเปลี่ยนสำคัญ: หากผู้ลงทุนปรับสัดส่วนการถือหุ้นและกู้ยืมเงินสดอย่างต่อเนื่อง (delta hedging) ความเสี่ยงของพอร์ตจะหักล้างกันหมดจนไร้ความเสี่ยงในทุกขณะสั้น ๆ และตามหลัก no-arbitrage พอร์ตที่ไร้ความเสี่ยงต้องเติบโตด้วยอัตราดอกเบี้ย $r$ เท่านั้น ส่งผลให้ตัวแปร $\mu$ และระดับความกลัวความเสี่ยงหลุดหายไปจากสมการอย่างสิ้นเชิง ในเวลาไล่เลี่ยกัน Edward Thorp ก็ใช้แนวคิด delta hedging ทำกำไรจาก warrant ในตลาดจริงเช่นกัน

การค้นพบนี้เปลี่ยนโลกการเงินจากการเดาทิศทางราคา มาสู่เทคโนโลยีการผลิตเชิงวิศวกรรม: option ไม่ใช่การพนันที่ต้องอาศัยผู้ซื้อผู้ขายที่มีมุมมองต่างกัน แต่เป็นสัญญาทางการเงินที่สามารถสร้างเลียนแบบได้ด้วยหุ้นและพันธบัตร เมื่อตลาด options จดทะเบียนอย่าง Chicago Board Options Exchange เปิดทำการในปี 1973 สูตร Black–Scholes จึงกลายเป็นโครงสร้างพื้นฐานหลักที่ขับเคลื่อนตลาด derivative ทั่วโลกตั้งแต่นั้นมา

Worked Example — โจทย์และสิ่งที่ให้มา

โจทย์ให้อะไรมาบ้าง: ใช้หุ้นสหรัฐฯ ไม่มีเงินปันผล ราคาเริ่มต้น \$100, strike \$105, อายุ 0.25 ปี, อัตราดอกเบี้ย 0.04 ต่อปีแบบต่อเนื่อง และ volatility 0.20 ต่อรากปี ราคาเป็นต่อหุ้น; หากสัญญาแทน 100 หุ้นต้องคูณ 100 หลังคำนวณ ไม่ใส่ตัวคูณไว้กลางสูตร

สมมติฐานเหมือนหัวข้อ 13.1: volatility และอัตราดอกเบี้ยคงที่ เส้นทางต่อเนื่อง ซื้อขาย frictionless และใช้สิทธิ์ได้เฉพาะวันหมดอายุ สูตรจึงเป็น benchmark ที่ตรวจสอบได้ ไม่ใช่ market quote โดยตัวมันเอง

ขั้นที่ 1 — ลองด้วยมือ: ราคาปลายทางสามค่า แยก payoff เป็นสองบัญชี

ก่อนใช้ระฆังคว่ำ ลองโลกที่ราคาปลายทางมีได้แค่สามค่า จะเห็นกลไก “แยก payoff เป็นบัญชีหุ้นกับบัญชี strike” ที่ทั้งหัวข้อพึ่งพา

\[ \begin{aligned} K&=105\\ S_T&=90,\ 100,\ 120\\ \mathbb Q&=0.3,\ 0.4,\ 0.3\\ (S_T-K)^+&=0,\ 0,\ 15\\ \mathbb E^{\mathbb Q}[(S_T-K)^+]&=0.3(15)=4.5\\[4pt] \text{stock}&=\mathbb E^{\mathbb Q}[S_T\mathbf 1(S_T>K)]\\ &=0.3(120)=36\\ \text{strike}&=K\,\mathbb Q(S_T>K)\\ &=105(0.3)=31.5\\ 36-31.5&=4.5 \end{aligned} \]

call จ่ายเฉพาะทางที่หุ้นจบเหนือ 105 คือทางเดียว (120) น้ำหนัก 0.3 ค่าเฉลี่ยจึงเป็น 4.5 แยกเป็นสองบัญชี: “ได้หุ้น” เฉพาะทางนั้น (36) กับ “จ่าย strike” เฉพาะทางนั้น (31.5) ลบกันได้เท่าเดิม

สูตร Black–Scholes คือการทำแบบเดียวกันเมื่อ $S_T$ มีได้ทุกค่า: บัญชีหุ้นจะกลายเป็น $S_0e^{rT}\Phi(d_1)$ และบัญชี strike เป็น $K\Phi(d_2)$ (ขั้นที่ 6) แล้วคิดลดทั้งคู่

ตัวเลข 0.3 ในตัวอย่างนี้เล่นบท $\Phi(d_2)$ คือโอกาสได้ใช้สิทธิ์ ส่วน 36/0.3 = 120 คือค่าเฉลี่ยของหุ้น *เมื่อ* ได้ใช้สิทธิ์ ซึ่งสูงกว่าค่าเฉลี่ยรวม 103 นี่คือเหตุผลที่บัญชีหุ้นต้องมีตัวเลขของตัวเองที่ไม่ใช่โอกาสเฉย ๆ

ขั้นที่ 2 — แก้สมการหุ้นภายใต้ risk-neutral measure

เริ่มจากเขียนราคาหุ้นตอนหมดอายุให้อยู่ในรูปที่มีตัวสุ่มมาตรฐานตัวเดียว สี่บรรทัดนี้ประกอบผลจากสามหัวข้อก่อนหน้าเข้าด้วยกัน ไม่มีอะไรใหม่ และการมีก้อนสุ่มตัวเดียวคือสิ่งที่ทำให้ integral ข้างหน้าคำนวณได้ด้วยมือ

\[ \begin{aligned}S_T&=S_0e^{(\mu-\frac12\sigma^{2})T+\sigma W_T}\qquad\text{(topic 11.1)}\\ W_T&=\sqrt{T}\,Z,\qquad Z\sim\mathcal N(0,1)\qquad\text{(topic 10.1)}\\ \mathbb Q:\quad\mu&\to r\qquad\text{(topic 12.6)}\\ S_T&=S_0e^{(r-\frac12\sigma^{2})T+\sigma\sqrt{T}\,Z}\end{aligned} \]

ไม่ต้องแก้สมการใหม่ ยกคำตอบของสมการหุ้นจากหัวข้อ 11.1 มาใช้ได้เลย แล้วเขียน Brownian ที่เวลา $T$ ในรูปก้อนมาตรฐานคูณราก ตามสมบัติที่ 2 ของหัวข้อ 10.1

สิ่งเดียวที่เปลี่ยนคือบรรทัดสาม ภายใต้น้ำหนักชุดใหม่ของหัวข้อ 12.6 อัตราการโตจริงถูกแทนด้วยอัตราดอกเบี้ย ส่วนความผันผวนของแรงสุ่มไม่เปลี่ยน ซึ่งเข้ากันพอดีกับผลของหัวข้อ 13.1 ที่ $\mu$ หายไปจากสมการ

ตอนนี้เหลือก้อนสุ่มตัวเดียวคือ $Z$ ซึ่งเราคำนวณค่าเฉลี่ยของมันเป็นแล้วตั้งแต่บทที่ 1 โจทย์ตั้งราคาทั้งหมดจึงยุบเหลือ integral บนระฆังมาตรฐาน

ขั้นที่ 3 — แยก payoff เป็นสองบัญชี

payoff ของ call แยกได้เป็นสองก้อน คือได้หุ้นมาก้อนหนึ่ง กับจ่ายเงินสดออกไปอีกก้อนหนึ่ง สูตรข้างล่างอธิบายว่าทำไมสูตร Black–Scholes ถึงมีสองพจน์ และทำไมสองพจน์นั้น ถึงมีหน้าตาไม่เหมือนกัน คือก้อนหนึ่งถ่วงด้วยราคาหุ้น อีกก้อนไม่ถ่วง

\[ \begin{aligned} (S_T-K)^{+}&=\begin{cases}S_T-K,&S_T>K\\ 0,&S_T\le K\end{cases}\\ &=\big(S_T-K\big)\mathbf 1(S_T>K)\\ &=S_T\mathbf 1(S_T>K)-K\mathbf 1(S_T>K)\\ &\mathbb E^{\mathbb Q}\big[\mathbf 1(S_T>K)\big]=\mathbb Q(S_T>K)\\ C&=e^{-rT}\Big(\mathbb E^{\mathbb Q}\big[S_T\mathbf 1(S_T>K)\big]\\ &\qquad-K\,\mathbb Q(S_T>K)\Big) \end{aligned} \]

payoff ของ call มีสองกรณี ใช้สิทธิ์เมื่อราคาสูงกว่า strike ไม่ใช้เมื่อต่ำกว่า วิธีจัดการคือรวบสองกรณีเป็นบรรทัดเดียวด้วยตัวบ่งชี้ ซึ่งเป็นหนึ่งเมื่อเงื่อนไขจริงและศูนย์เมื่อไม่จริง

กระจายวงเล็บแล้วได้สองบัญชีที่ต่างกันโดยสิ้นเชิง คือบัญชีหุ้น กับบัญชีเงินสด แยกแบบนี้แล้วแต่ละก้อนคำนวณง่ายกว่ามาก

ค่าเฉลี่ยของตัวบ่งชี้คือความน่าจะเป็นของเหตุการณ์นั้นพอดี เพราะมันคูณหนึ่งด้วยโอกาสที่เกิด บวกศูนย์ด้วยโอกาสที่ไม่เกิด

ใส่สูตรตั้งราคาของหัวข้อ 12.6 กับสองก้อนที่แยกไว้ สองก้อนนี้จะกลายเป็นสองพจน์ในสูตรสุดท้าย นั่นคือเหตุผลที่ Black-Scholes มีสองพจน์ ไม่ใช่พจน์เดียว

ขั้นที่ 4 — เปลี่ยนเงื่อนไขใช้สิทธิ์เป็นเกณฑ์ของ Z

เงื่อนไขว่าราคาสูงกว่า strike แปลงเป็นเงื่อนไขบนตัวสุ่มมาตรฐานได้ ห้าบรรทัดนี้คือที่มาของ $d_2$ ทุกตัวอักษร มันไม่ใช่สัญลักษณ์ลึกลับ มันคือระยะจากเกณฑ์ใช้สิทธิ์ วัดเป็นจำนวนเท่าของความผันผวน เหมือน z-score ในหัวข้อ 1.9

\[ \begin{aligned}S_T>K\;&\Rightarrow\;\log S_0+\big(r-\tfrac12\sigma^{2}\big)T+\sigma\sqrt T\,Z>\log K\\ &\Rightarrow\;\sigma\sqrt T\,Z>\log\frac{K}{S_0}-\big(r-\tfrac12\sigma^{2}\big)T\\ &\Rightarrow\;Z>\frac{\log(K/S_0)-\big(r-\tfrac12\sigma^{2}\big)T}{\sigma\sqrt T}\\ d_2&:=\frac{\log(S_0/K)+\big(r-\tfrac12\sigma^{2}\big)T}{\sigma\sqrt T}\\ S_T>K&\quad\text{when}\quad Z>-d_2\end{aligned} \]

เงื่อนไขใช้สิทธิ์เขียนอยู่ในภาษาของราคา แต่ distribution ที่เรารู้อยู่ในภาษาของก้อนสุ่มมาตรฐาน จึงต้องขนอสมการข้ามไป ใส่ log ทั้งสองข้างได้โดยไม่พลิกเครื่องหมาย เพราะ log เพิ่มขึ้นเสมอและราคาเป็นบวกเสมอ

ย้ายทุกอย่างที่ไม่ใช่ก้อนสุ่มไปฝั่งขวา แล้วหารด้วย $\sigma\sqrt T$ ซึ่งเป็นบวก เครื่องหมายจึงไม่พลิก

ตั้งชื่อฝั่งขวาโดยกลับเครื่องหมายทั้งก้อน การกลับเครื่องหมายทำให้ $\log(K/S_0)$ กลายเป็น $\log(S_0/K)$ เพราะ log ของส่วนกลับคือค่าลบ

ตอนนี้เงื่อนไขใช้สิทธิ์เขียนใหม่ทั้งหมดในภาษาของก้อนสุ่มมาตรฐาน integral ที่ต้องคำนวณจึงมีขอบเป็นตัวเลขที่รู้ค่าแล้ว

ขั้นที่ 5 — เลื่อน normal density สำหรับขาหุ้น

ขาหุ้นมี exponential คูณอยู่หน้า density จึงต้องจัดกำลังสองใหม่ให้กลับมาเป็น density ปกติที่เลื่อนไป หกบรรทัดนี้ตอบคำถามที่คนเรียน Black–Scholes ถามบ่อยที่สุด คือ $d_1$ กับ $d_2$ ต่างกันตรงไหน คำตอบคือต่างกันด้วยระยะที่ density ถูกเลื่อน ไม่ใช่เพราะเป็นความน่าจะเป็นคนละอย่าง

\[ \begin{aligned}e^{\sigma\sqrt T\,z}\phi(z)&=\frac{1}{\sqrt{2\pi}}e^{\sigma\sqrt T\,z-\frac12z^{2}}\\ \sigma\sqrt T\,z-\tfrac12z^{2}&=-\tfrac12\big(z^{2}-2\sigma\sqrt T\,z\big)\\ &=-\tfrac12\Big[\big(z-\sigma\sqrt T\big)^{2}-\sigma^{2}T\Big]\\ &=-\tfrac12\big(z-\sigma\sqrt T\big)^{2}+\tfrac12\sigma^{2}T\\ e^{\sigma\sqrt T\,z}\phi(z)&=e^{\sigma^{2}T/2}\,\phi\big(z-\sigma\sqrt T\big)\\[4pt] d_1&:=d_2+\sigma\sqrt T\end{aligned} \]

ขาหุ้นมีราคาคูณอยู่ข้างใน integral ซึ่งเป็น exponential ทำให้ integral ไม่ใช่รูปมาตรฐาน กลเม็ดคือรวมเลขชี้กำลังสองก้อนเข้าด้วยกันแล้วจัดกำลังสองสมบูรณ์ วิธีเดียวกับหัวข้อ 1.10 ทุกประการ

ดึงลบครึ่งออกมาข้างหน้า แล้วเติมและลบ $\sigma^{2}T$ หนึ่งครั้ง เพื่อให้สองพจน์แรกกลายเป็นวงเล็บยกกำลังสอง ลองกระจายกลับเพื่อตรวจได้ทุกเมื่อ พอกระจายลบครึ่งเข้าไป ค่าที่ลบทิ้งก็กลับมาเป็นบวก

อ่านผลบรรทัดห้า การถ่วงด้วยราคาหุ้นไม่ได้ทำลายรูประฆัง มันแค่เลื่อนจุดกลางไป $\sigma\sqrt T$ แล้วทิ้งค่าคงที่ไว้ข้างหน้า

นี่คือเหตุผลเดียวที่ $d_1$ ต่างจาก $d_2$ ไม่มีอะไรลึกลับกว่านั้น มันคือระยะที่ density ถูกเลื่อน

ขั้นที่ 6 — ประเมิน integral สองส่วน

เมื่อทั้งสองก้อนกลายเป็น integral ของ density มาตรฐานแล้ว ก็อ่านค่าออกมาเป็น $\Phi$ ได้ทันที สูตรข้างล่างคือจุดที่ทุกอย่างมาบรรจบ และเครื่องมือที่ใช้มีแค่สองอย่าง คือการจัดกำลังสองสมบูรณ์ กับการเปลี่ยนตัวแปรใน integral

\[ \begin{aligned} &\mathbb Q(S_T>K)=\mathbb Q(Z>-d_2)\\ &=\mathbb Q(Z \lt d_2)=\Phi(d_2)\\[4pt] &\mathbb E^{\mathbb Q}\big[S_T\mathbf 1(S_T>K)\big]\\ &=\int_{-d_2}^{\infty}S_0e^{(r-\frac12\sigma^{2})T}e^{\sigma\sqrt T\,z}\phi(z)\,dz\\ &=S_0e^{(r-\frac12\sigma^{2})T}e^{\sigma^{2}T/2}\\ &\qquad\int_{-d_2}^{\infty}\phi\big(z-\sigma\sqrt T\big)\,dz\\ &=S_0e^{rT}\int_{-d_2-\sigma\sqrt T}^{\infty}\phi(u)\,du\\ &=S_0e^{rT}\,\Phi\big(d_2+\sigma\sqrt T\big)\\ &=S_0e^{rT}\,\Phi(d_1) \end{aligned} \]

ก้อนเงินสดง่ายที่สุด ใช้ความสมมาตรของระฆัง พื้นที่ทางขวาของค่าลบเท่ากับพื้นที่ทางซ้ายของค่าบวก จึงอ่านเป็น $\Phi(d_2)$ ได้ทันที

ก้อนหุ้นต้องใช้ผลของขั้นที่ 5 เขียนเป็น integral โดยแทนราคาจากขั้นที่ 2 และใช้ขอบจากขั้นที่ 4 แล้วแทน exponential คูณ density ด้วย density ที่เลื่อนแล้ว ค่าคงที่ทั้งหมดออกมาอยู่ข้างหน้า

เปลี่ยนตัวแปรให้ตามการเลื่อน ขอบล่างจึงเลื่อนตามไปด้วย และเลขชี้กำลังสองก้อนหน้ารวมกันได้ $rT$ พอดี เพราะลบครึ่งกับบวกครึ่งหักกัน

ข้อควรระวังที่คนพลาดบ่อยที่สุด $\Phi(d_1)$ ไม่ใช่ความน่าจะเป็นที่จะได้ใช้สิทธิ์ อันนั้นคือ $\Phi(d_2)$ ส่วนตัวแรกคือค่าเฉลี่ยของหุ้นที่ถ่วงด้วยราคาแล้ว

ขั้นที่ 7 — ได้สูตร call และ put

ประกอบสองก้อนกลับเข้าด้วยกันเป็นสูตร call แล้วใช้ความสัมพันธ์ระหว่างสองสัญญาได้สูตร put สูตรข้างล่างปิดงานทั้งหัวข้อ และจุดที่ควรจำคือฝั่ง put ไม่ได้ต้องทำงานใหม่เลย มันเป็นแค่พีชคณิตบนสูตรที่มีอยู่แล้ว

\[ \begin{aligned} C&=e^{-rT}\Big(S_0e^{rT}\Phi(d_1)-K\Phi(d_2)\Big)\\ &=S_0\Phi(d_1)-Ke^{-rT}\Phi(d_2)\\[4pt] &\text{parity}:\\ C-P&=S_0-Ke^{-rT}\\ P&=C-S_0+Ke^{-rT}\\ &=S_0\Phi(d_1)-Ke^{-rT}\Phi(d_2)\\ &\quad-S_0+Ke^{-rT}\\ &=Ke^{-rT}\big(1-\Phi(d_2)\big)\\ &\quad-S_0\big(1-\Phi(d_1)\big)\\ &=Ke^{-rT}\Phi(-d_2)-S_0\Phi(-d_1) \end{aligned} \]

แทนสองผลของขั้นที่ 6 ลงในรูปที่แยกไว้ในขั้นที่ 3 แล้วคูณตัวคิดลดเข้าไป พจน์แรกหักกันหมดเหลือราคาหุ้นวันนี้เปล่า ๆ ได้สูตร call ครบ

ฝั่ง put ไม่ต้องคำนวณ integral ใหม่เลยสักตัว ใช้ความสัมพันธ์ระหว่าง call กับ put ซึ่งหัวข้อ 13.4 พิสูจน์ด้วย payoff ทีละกรณี ย้ายข้างแล้วแทนสูตร call ที่เพิ่งได้

จัดกลุ่มใหม่โดยดึง $Ke^{-rT}$ และ $S_0$ ออกเป็นตัวร่วม แล้วใช้ความสมมาตรของระฆังอีกครั้ง คือหนึ่งลบพื้นที่ทางซ้าย เท่ากับพื้นที่ทางซ้ายของค่าที่กลับเครื่องหมาย

สูตร put จึงตกลงมาเองจากสูตร call งานหนักทั้งหมดทำครั้งเดียวก็พอ

ทำไม $\Phi(d_1)$ กับ $\Phi(d_2)$ ไม่ควรถูกเรียกเหมือนกัน

Phi ของ d2 ตอบว่าเส้นทางภายใต้ risk-neutral measure จบเหนือ strike เป็นสัดส่วนเท่าไร ขณะที่ Phi ของ d1 ให้น้ำหนักเส้นทางที่หุ้นสูงมากมากขึ้นเพราะอยู่ใน expectation ของราคาปลายทาง จึงเท่ากับ delta ในกรณีไม่มีเงินปันผล แต่ไม่ใช่ exercise probability การแยกสองความหมายนี้ช่วยกันการตีความพื้นที่ใต้โค้งผิด

ทำไมต้องใช้: เพราะมันจับความผิดพลาดหน่วยได้เร็วที่สุด เช่นการใส่ 20 แทน 0.20 มักดันราคาทะลุขอบบนทันที

คืออะไร: ขนาดการกระจายแบบยกกำลังสอง ในที่นี้คิดต่อหนึ่งหน่วยเวลา

ใช้ทำอะไร: เป็นตัวที่บวกกันได้ตามเวลา ความผันผวนตลอด $T$ ปีจึงเป็น $\sigma^{2}T$

ทำไมต้องใช้: เพราะเฉพาะตัวนี้เท่านั้นที่บวกกันได้ตรง ๆ ส่วนรากของมันบวกไม่ได้ กฎรากที่สองของเวลาทั้งหมดมาจากข้อเท็จจริงข้อนี้ข้อเดียว

volatility

คืออะไร: รากที่สองของ variance ต่อปี รายงานเป็นเปอร์เซ็นต์ต่อปี

ใช้ทำอะไร: เป็น input ตัวเดียวในสูตรที่มองไม่เห็นในตลาดโดยตรง

ทำไมต้องแยกชื่อ: เพราะคนพูดสองคำนี้สลับกันบ่อย แต่ใส่ผิดตัวลงในสูตร ราคาที่ได้จะผิดเป็นเท่าตัว

underlying

คืออะไร: สินทรัพย์ที่สัญญาอ้างอิงถึง ในที่นี้คือหุ้น

ใช้ทำอะไร: เป็นตัวที่ราคาของ option ทั้งหมดขึ้นอยู่กับมัน

ทำไมต้องมี: เพราะราคาที่พิสูจน์มาได้จากการซื้อขายตัวนี้จริง ถ้าซื้อขายมันไม่ได้ วิธีทั้งหมดในบทนี้ก็ใช้ไม่ได้

forward

คืออะไร: ราคาที่ตกลงกันวันนี้ว่าจะซื้อขายกันในอนาคต เท่ากับ $S_0e^{rT}$ ในโลกของบทนี้

ใช้ทำอะไร: ใช้เป็นจุดอ้างอิงกลางว่าค่าไหนคือ 'ตรงกลาง' ของราคาปลายทาง

ทำไมต้องใช้: เพราะเทียบ strike กับราคาวันนี้นั้นเทียบผิดจุด ตัวที่ควรเทียบคือราคาที่ตลาดตกลงกันแล้วสำหรับวันนั้น

moneyness

คืออะไร: ระยะห่างระหว่าง strike กับจุดอ้างอิง มักวัดเป็น log ของอัตราส่วน

ใช้ทำอะไร: ใช้บอกว่าสิทธิ์ใบนี้ใกล้ได้ใช้หรือไกลจากการได้ใช้

ทำไมต้องใช้: เพราะ strike 100 บนหุ้นราคา 100 กับบนหุ้นราคา 1000 เป็นสัญญาคนละแบบกันโดยสิ้นเชิง ตัวเลขดิบจึงเทียบข้ามหุ้นไม่ได้

payoff

คืออะไร: เงินที่ผู้ถือได้รับในวันหมดอายุ ขึ้นกับราคาหุ้นวันนั้นอย่างเดียว

ใช้ทำอะไร: เป็นจุดตั้งต้นของการพิสูจน์ในขั้นที่ 3

ทำไมต้องแยกจากราคา: เพราะ payoff คือสิ่งที่ได้ตอนจบ ส่วนราคาคือสิ่งที่จ่ายตอนเริ่ม ทั้งหัวข้อนี้คือการแปลงอันแรกให้เป็นอันหลัง

partial differential equation
partial differential equation คือสมการที่มี derivatives ตามหลายตัวแปร หัวข้อก่อน derive มันเพื่อเชื่อมวิธีพอร์ตทำซ้ำกับสูตรปิดในหัวข้อนี้

ขั้นที่ 8 — เตรียมตัวเศษและหารด้วยหน่วยเดียวกัน

เริ่มตัวอย่างด้วยตัวเลขจริง แยกชิ้นส่วนของ $d_1$ ออกมาคำนวณทีละชิ้นก่อน จะได้ไม่พลาด

\[ \log(100/105)=-0.048790164,\quad (0.04+0.20^2/2)(0.25)=0.015,\quad0.20\sqrt{0.25}=0.10 \]

ทีละชิ้น: 100/105 = 0.952381 แล้ว log ของมันคือ −0.048790 (ติดลบเพราะ strike สูงกว่า spot) ส่วน 0.20 กำลังสองคือ 0.04 ครึ่งหนึ่งคือ 0.02 บวก 0.04 ได้ 0.06 คูณ 0.25 ได้ 0.015 และรากของ 0.25 คือ 0.5 คูณ 0.20 ได้ 0.10

log moneyness และ drift adjustment ไม่มีหน่วย ส่วนความผันผวนคูณรากเวลามีหน่วยหักล้างกัน ตัวส่วน 0.10 จึงใช้ standardized numerator ได้

ขั้นที่ 9 — คำนวณ $d_1$ และ $d_2$

รวมสามชิ้นเข้าเป็น $d_1$ แล้ว $d_2$ ตามมาทันทีโดยลบออกไปพจน์เดียว

\[ d_1=\frac{-0.048790164+0.015}{0.10}=-0.337901642,\qquad d_2=-0.437901642 \]

ทั้งสองค่าเป็นลบเพราะ call ยัง out of the money และเวลาสั้น d_2 ต่ำกว่า d_1 อยู่ 0.10 ตาม identity

ขั้นที่ 10 — อ่านค่าจาก normal CDF และ discount

แปลงสองค่านั้นเป็นความน่าจะเป็น และเตรียมตัวคิดลดไว้ให้พร้อม

\[ \Phi(d_1)=0.367718655,\quad \Phi(d_2)=0.330728793,\quad e^{-0.04(0.25)}=0.990049834 \]

exercise probability ภายใต้แบบจำลองประมาณ 33.07 เปอร์เซ็นต์ ส่วน share-weighted quantity ประมาณ 36.77 เปอร์เซ็นต์ และเงิน \$1 วันหมดอายุมีมูลค่า \$0.99005 วันนี้

เปิดตาราง: $\Phi(-0.3379)=1-\Phi(0.3379)$ ตารางให้ $\Phi(0.33)=0.6293$ และ $\Phi(0.34)=0.6331$ ประมาณระหว่างกลางได้ 0.6323 จึง $\Phi(d_1)\approx0.3677$ เครื่องคิดเลขให้ 0.367718655

ขั้นที่ 11 — ประกอบราคาเป็น USD

เอาทุกชิ้นที่เตรียมไว้มาประกอบเป็นราคาเดียว

\[ \begin{aligned} C&=100(0.367718655)\\ &\quad-105(0.990049834)(0.330728793)\\ &=36.77186552-34.38098856\\ &=2.39087696\ \text{USD} \end{aligned} \]

ขาหุ้นมีมูลค่า \$36.7719 และขา strike มีมูลค่า \$34.3810 ผลต่างคือ call \$2.39087696 ต่อหุ้น

ขั้นที่ 12 — ใช้ parity และ bounds เป็น checks

ก่อนเชื่อตัวเลข ตรวจสองอย่างที่ทำได้ในสิบวินาที คือ parity และกรอบบนล่างที่ราคาต้องอยู่ข้างใน

\[ P=C-S_0+Ke^{-rT}=6.34610950,\qquad \max(S_0-Ke^{-rT},0)\le C\le S_0 \]

put ทีละชิ้น: $Ke^{-rT}=105(0.990049834)=103.955232544$ แล้ว $2.39087696-100+103.955232544=6.346109504$

put มีราคา \$6.34610950 และ call ต้องอยู่ระหว่างศูนย์กับ \$100 ค่า 2.39087696 ผ่านทั้ง parity และ no-arbitrage bounds

ขั้นที่ 13 — ขยายสู่หุ้นที่มีเงินปันผล: Merton (1973) continuous dividend yield

แบบจำลอง Black–Scholes ดั้งเดิมตั้งสมมติฐานว่าหุ้นไม่มีการจ่ายเงินปันผล แต่ในตลาดจริง หุ้นส่วนใหญ่และดัชนีหลักเช่น S&P 500 จ่ายเงินปันผลสม่ำเสมอ Robert C. Merton (1973) จึงขยายสูตรด้วยการสมมติให้อัตราเงินปันผลจ่ายออกต่อเนื่องด้วยอัตรา $c$

การจ่ายเงินปันผลทำให้ราคาหุ้นหลังวันขึ้นเครื่องหมายลดลง ผู้ถือ call เสียเปรียบเพราะไม่ได้เงินปันผลนี้ ขณะที่ผู้ถือ put ได้ประโยชน์เพราะราคาหุ้นลดลงเข้าใกล้ strike สูตรของ Merton จึงเป็นหัวใจสำคัญของการตั้งราคา index options และ currency options ในเวลาต่อมา

\[ \begin{aligned} dS_t&=(r-c)S_t\,dt+\sigma S_t\,dW_t^{\mathbb Q}\\ S_T&=S_0e^{(r-c-\frac12\sigma^{2})T+\sigma\sqrt T\,Z}\\[4pt] \text{stock}&=e^{-rT}\mathbb E^{\mathbb Q}\big[S_T\mathbf 1(S_T>K)\big]\\ &=e^{-rT}S_0e^{(r-c)T}\Phi(d_1)\\ &=S_0e^{-cT}\Phi(d_1)\\ \text{strike}&=Ke^{-rT}\Phi(d_2)\\[4pt] d_1&=\frac{\log(S_0/K)+(r-c+\frac12\sigma^2)T}{\sigma\sqrt T}\\ d_2&=d_1-\sigma\sqrt T\\[4pt] C&=S_0e^{-cT}\Phi(d_1)-Ke^{-rT}\Phi(d_2)\\ P&=C-S_0e^{-cT}+Ke^{-rT}\\ &=Ke^{-rT}\Phi(-d_2)-S_0e^{-cT}\Phi(-d_1)\\[4pt] c&=0.02\\ d_1&=-0.387901642,\quad d_2=-0.487901642\\ \Phi(d_1)&=0.349044412,\quad \Phi(d_2)=0.312809756\\[4pt] C&=100(0.995012479)(0.349044412)\\ &\quad-105(0.990049834)(0.312809756)\\ &=34.73035453-32.51821091\\ &=2.21214362\ \text{USD}\\ P&=2.21214362-99.50124785+103.95523254\\ &=6.66612831\ \text{USD} \end{aligned} \]

เมื่อหุ้นจ่ายเงินปันผลอย่างต่อเนื่องด้วยอัตรา $c$ เงินสดจะไหลออกจากหุ้นเข้ากระเป๋าผู้ถือหุ้น ทำให้ราคาหุ้นเติบโตช้าลงภายใต้ $\mathbb Q$ ด้วย drift ที่ลดเหลือ $r - c$ การถือหุ้น 1 หน่วยต้องซื้อล่วงหน้าเพียง $e^{-cT}$ หุ้นเพราะเงินปันผลที่นำไปซื้อหุ้นเพิ่มจะสะสมจนครบ 1 หุ้นพอดีที่เวลา $T$

ผลลัพธ์คือขาหุ้นจะถูกลดทอนด้วยตัวคูณ $e^{-cT}$ กลายเป็น $S_0e^{-cT}\Phi(d_1)$ ขณะที่ขา strike ยังคิดลดด้วยดอกเบี้ย $e^{-rT}$ เท่าเดิม ค่า $d_1$ และ $d_2$ จึงถูกลบด้วย $cT$ ในตัวเศษ

เมื่อใส่ตัวเลขเดิม $S_0=100, K=105, r=0.04, \sigma=0.20, T=0.25$ แต่เพิ่มเงินปันผล $c=0.02$ ราคา call ลดลงจาก 2.39 เหลือ \$2.21 เพราะผู้ถือ call เสียประโยชน์จากปันผล ส่วน put เพิ่มขึ้นจาก 6.35 เป็น \$6.67 สอดคล้องกับ put–call parity พอดี

ขั้นที่ 14 — ตัวอย่างจากต้นทาง: call อายุ 3 เดือน บนหุ้น \$35 กับชิ้นแรกของตัวเศษ

ต้นทางใช้อีกชุดตัวเลข หุ้นราคา \$35 call แบบยุโรป strike \$36 อายุ 3 เดือน ดอกเบี้ย 2% ต่อปี ความผันผวน 24% ต่อปี เดินสูตรเดิมทีละชิ้นอีกรอบ หัวข้อ 13.3 จะใช้ call ตัวนี้ต่อ

\[ \begin{aligned} S_0&=35,\quad K=36,\quad T=0.25\\ r&=0.02,\quad \sigma=0.24\\[4pt] S_0/K&=35/36=0.972222\\ \log(S_0/K)&=-0.028171\\ S_0/K-1&=-0.027778\\[4pt] \sigma^2&=0.24\times0.24=0.0576\\ \tfrac12\sigma^2&=0.0288\\ (r+\tfrac12\sigma^2)T&=0.0488(0.25)=0.012200\\[4pt] \text{numerator}&=-0.028171+0.012200\\ &=-0.015971 \end{aligned} \]

ตรวจเงื่อนไขก่อนใช้สูตร call ใช้สิทธิ์ได้วันหมดอายุเท่านั้น ราคาเดินแบบหัวข้อ 11.1 ด้วยความผันผวนคงที่ ไม่มีเงินปันผลระหว่างทาง กู้และฝากที่อัตราเดียวกัน ซื้อขายได้ต่อเนื่องไม่มีค่าธรรมเนียม

ห้าตัวเลขที่ใส่คือราคาหุ้น strike เวลา ดอกเบี้ย และความผันผวน ไม่มีผลตอบแทนคาดหวังของหุ้นเลย ตามเหตุผลของหัวข้อ 13.1

ชิ้นแรกวัดว่าหุ้นอยู่ห่าง strike แค่ไหนในหน่วย log ราคาต้องขึ้น 2.82% ใน log ถึงจะแตะ 36 พอดี ใกล้กับ 2.78% แบบเปอร์เซ็นต์ธรรมดาเพราะระยะสั้น ที่ต้องใช้ log เพราะสิ่งที่เป็นระฆังคว่ำคือ log ของราคาปลายทาง ไม่ใช่ตัวราคา

ชิ้นที่สองคือ drift สะสมของขาหุ้นตลอดอายุ 0.0122 บวกกันได้ตัวเศษ −0.015971 ครึ่งหนึ่งของ variance เป็นบวกตรงนี้ เพราะ $d_1$ คือตัวที่ถูกเลื่อนไปแล้วตามขั้นที่ 5

ขั้นที่ 15 — ตัวส่วน แล้วได้ $d_1$ กับ $d_2$ พร้อมทางตรวจ

หารด้วยความผันผวนของแรงสุ่มตลอดสามเดือน แล้วตรวจ $d_2$ อีกทางด้วย drift ของ log ภายใต้ risk-neutral measure

\[ \begin{aligned} \sqrt T&=\sqrt{0.25}=0.5\\ \sigma\sqrt T&=0.24(0.5)=0.12\\[4pt] d_1&=-0.015971/0.12=-0.133091\\ d_2&=-0.133091-0.12=-0.253091\\[4pt] (r-\tfrac12\sigma^2)T&=(0.02-0.0288)(0.25)=-0.0022\\ d_2&=\frac{-0.028171-0.0022}{0.12}\\ &=\frac{-0.030371}{0.12}=-0.253091 \end{aligned} \]

ตลอดสามเดือน log ของราคาแกว่งด้วย standard deviation (SD) 12% ไม่ใช่ 24% เพราะความผันผวนโตตามรากของเวลา $d_1$ กับ $d_2$ จึงเป็นระยะวัดเป็นจำนวนเท่าของ 12% เหมือน z-score ของหัวข้อ 1.9

ทางตรวจใช้สูตรของ $d_2$ ตรง ๆ ที่มีครึ่ง variance เป็นลบ ได้ −0.253091 ตรงกัน $d_2$ อยู่ในโลกของความน่าจะเป็น ส่วน $d_1$ ถูกเลื่อนขึ้นไปอีก 0.12 ตอนคิดขาหุ้น strike อยู่เหนือจุดกลางของ log ราคาปลายทาง 0.253 เท่าของ SD โอกาสไปถึงจึงต่ำกว่าครึ่งเล็กน้อย

ขั้นที่ 16 — เปิดตาราง คิดลด strike แล้วคูณทีละก้อน

สองค่าในตารางกับตัวคิดลดหนึ่งตัว แล้วคูณก้อนซ้ายกับก้อนขวาแยกกันก่อนลบ

\[ \begin{aligned} \Phi(d_1)&=\Phi(-0.133091)=0.44706\\ \Phi(d_2)&=\Phi(-0.253091)=0.40010\\[4pt] rT&=0.02(0.25)=0.005\\ e^{-0.005}&=0.9950125\\ Ke^{-rT}&=36(0.9950125)=35.82045\\[4pt] &35(0.44706)=15.64710\\ &35.82045(0.40010)=14.33176\\ C&=15.64710-14.33176=1.3153\\ C_{\text{exact}}&=1.31540\ \text{USD} \end{aligned} \]

ค่า z ติดลบนิดเดียว พื้นที่ทางซ้ายจึงต้องต่ำกว่าครึ่งนิดเดียว 0.447 กับ 0.400 ผ่านการตรวจด้วยตา หมุดที่ควรจำคือ Φ(0) = 0.5 Φ(−0.25) ราว 0.40 และ Φ(−0.5) ราว 0.31

คิดลดเฉพาะ strike เพราะ \$36 คือเงินที่จ่ายอีกสามเดือน ส่วน \$35 เป็นราคาวันนี้อยู่แล้ว ส่วนลด \$0.1796 คือดอกเบี้ยที่ยังไม่ต้องจ่าย ถ้าดอกเบี้ย 8% อายุ 5 ปี ส่วนลดจะเป็น \$11.87 ใหญ่กว่าตัว option เสียอีก

คูณด้วยมือได้ 1.3153 ใช้ค่า Φ ไม่ปัดได้ \$1.31540 ต่างกันแค่ 0.00006 ห้ามใช้ $\Phi(d_2)$ ทั้งสองก้อน เพราะจะได้ (35 − 35.8204)(0.40010) = −\$0.328 ราคาติดลบซึ่งไม่มีความหมาย

ขั้นที่ 17 — ตรวจด้วยขอบเขตที่ไม่ต้องใช้แบบจำลอง

ราคาต้องอยู่ในกรอบที่ no-arbitrage บังคับเสมอ และต้องขยับไปทางที่ถูกเมื่อความผันผวนวิ่งไปสุดทาง

\[ \begin{aligned} \text{lower}&=\max(35-35.8204,\ 0)=0\\ \text{upper}&=S_0=35\\ 0&\le1.3154\le35\\[4pt] \text{intrinsic}&=\max(35-36,\ 0)=0\\ \text{time value}&=1.3154-0=1.3154\\[4pt] \sigma\to0&:\ C\to0\\ \sigma=0.24&:\ C=1.3154\\ \sigma\to\infty&:\ C\to35 \end{aligned} \]

สิทธิ์ซื้อหุ้นต้องถูกกว่าตัวหุ้นเอง และไม่ต่ำกว่าส่วนต่างของหุ้นกับ strike ที่คิดลดแล้ว ซึ่งที่นี่ติดลบจึงเป็นศูนย์ ราคา 1.3154 อยู่ต้นกรอบ 0 ถึง 35 สมกับ call ที่ยังไม่มีกำไรและอายุสั้น

ราคาทั้งก้อนเป็นค่าเวลาล้วน เพราะวันนี้หุ้นต่ำกว่า strike \$1 แต่หนึ่ง SD ของสามเดือนคือ 12% ของ 35 หรือ \$4.2 ระยะ \$1 จึงแค่ 0.24 เท่าของ SD วิ่งข้ามได้สบาย ถ้าหุ้นไม่ขยับ ค่าเวลานี้ละลายหมดในสามเดือน หัวข้อ 13.3 จะวัดเป็นเงินต่อวัน

ขั้นที่ 18 — อ่าน $\Phi(d_1)$ กับ $\Phi(d_2)$ ให้ถูกความหมาย

สองตัวเลขจากตารางตอบคนละคำถาม และช่องว่างระหว่างมันมีที่มา

\[ \begin{aligned} \Delta&=\Phi(d_1)=0.4471\\ 10{,}000(0.4471)&=4{,}471\ \text{shares}\\[4pt] \mathbb Q(S_T>36)&=\Phi(d_2)=0.4001\\[4pt] d_1-d_2&=\sigma\sqrt T=0.12\\ \Phi(d_1)-\Phi(d_2)&=0.0470 \end{aligned} \]

หุ้นขึ้น \$1 call ขึ้นราว \$0.447 ถ้าขาย call 100 สัญญา สัญญาละ 100 หุ้น รวม 10,000 หุ้น ต้องซื้อหุ้นไว้ 4,471 หุ้นเพื่อ hedge ส่วนโอกาสที่หุ้นจะจบเหนือ \$36 ภายใต้ risk-neutral measure คือ 40.0%

$\Phi(d_2)$ นับว่าได้ใช้สิทธิ์บ่อยแค่ไหน $\Phi(d_1)$ ถ่วงแต่ละกรณีด้วยขนาดของหุ้นที่ได้ กรณีที่หุ้นขึ้นแรงจึงมีน้ำหนักมากกว่า ตัวแรกจึงสูงกว่าเสมอ ช่องว่าง 4.70 จุดกว้างขึ้นเมื่อความผันผวนสูงหรืออายุยาว เพราะทั้งคู่ทำให้ $\sigma\sqrt T$ ใหญ่ขึ้น

กับดักที่พบบ่อย ใส่อายุเป็น 3 แทน 0.25 ปี ราคาพุ่งเป็น \$6.24 แพงเกินจริง 4.7 เท่า ใส่ความผันผวนเป็น 24 แทน 0.24 ราคาจะวิ่งไปชนเพดาน \$35 ทันที

สูตรตั้งราคาที่ทั้งตลาดใช้ร่วมกัน เป็นภาษากลางมากกว่าจะเป็นคำทำนายราคา

ใช้แปลงราคาที่ซื้อขายกันจริง ให้กลายเป็นตัวเลขความผันผวนที่เทียบข้ามสัญญาได้ ซึ่งเป็นการใช้งานหลักจริง ๆ ของสูตรนี้

คำตอบ — ราคา Call และ Put ตามสูตร Black–Scholes

คำถาม: European call และ put บนหุ้น spot \$100 strike \$105 อายุ 0.25 ปี ดอกเบี้ย 4% ต่อปี ความผันผวน 20% ควรมีราคาเท่าไร และหากมีเงินปันผลต่อเนื่อง 2% ราคาเปลี่ยนเป็นเท่าไร?

ของที่มี (ขั้นที่ 1 ถึง 13): Spot \$100, Strike \$105, อายุ 0.25 ปี, ดอกเบี้ย 4% ต่อปี, Volatility 20%, ตัวคิดลดมีค่า 0.99005

1 กรณีไม่มีปันผล: ได้ d₁ เท่ากับ −0.337902 และ d₂ เท่ากับ −0.437902 ได้ราคา call เท่ากับ \$2.39087696 ต่อหุ้น (\$239.09 ต่อสัญญา 100 หุ้น) และราคา put เท่ากับ \$6.34610950 ต่อหุ้น (\$634.61 ต่อสัญญา)

2 สัดส่วนและโอกาส: โอกาสทางทฤษฎีที่จะได้ใช้สิทธิ์อยู่ที่ 33.07% (คำนวณจาก Φ ของ d₂) ส่วนสัดส่วนถือหุ้นเพื่อทำซ้ำอยู่ที่ 36.77% (คำนวณจาก Φ ของ d₁)

3 กรณีมีเงินปันผลต่อเนื่อง c เท่ากับ 0.02: ได้ d₁ เท่ากับ −0.387902 และ d₂ เท่ากับ −0.487902 ราคา call ลดเหลือ \$2.21214362 และราคา put เพิ่มขึ้นเป็น \$6.66612831

ตรวจเองใน 10 วินาที: ขาหุ้น 100 × 0.367719 คือ 36.7719 ลบขา strike 105 × 0.99005 × 0.330729 คือ 34.3810 ได้ \$2.3909 พอดี และตรวจ put ด้วย parity ได้ \$6.3461

แปลว่าอะไรบนโต๊ะเทรด: Black–Scholes แยกมูลค่า option ออกเป็นสองก้อนที่ซื้อขายได้จริง คือการซื้อหุ้นล่วงหน้าและการกู้ยืมเงินด้วยมูลค่าปัจจุบันของ strike สูตรนี้ไม่ได้พยายามเดาว่าหุ้นจะวิ่งไปทางไหน แต่บอกต้นทุนเป๊ะ ๆ ของการสังเคราะห์สิทธิ์นี้ในตลาด

คำตอบ — call 35 / \$36 จากต้นทาง

คำถาม: หุ้น \$35 call แบบยุโรป strike \$36 อายุ 3 เดือน ดอกเบี้ย 2% ความผันผวน 24% ได้ $d_1$ $d_2$ ราคา และจำนวนหุ้นที่ต้องถือเท่าไร?

ของที่มี: ขั้นที่ 14 ถึง 18

1. d₁ = −0.13309 และ d₂ = −0.25309 ได้จากเอา 0.12 ไปหารตัวเศษ −0.015971

2 ราคา call \$1.3154 เท่ากับ 35 × 0.44706 − 35.8204 × 0.40010 เป็นค่าเวลาล้วน

3. delta 0.4471 ขาย 100 สัญญาต้องถือหุ้น 4,471 หุ้น ส่วนโอกาสใช้สิทธิ์ภายใต้ risk-neutral measure คือ 40.0% ต่างกัน 4.70 จุด ห้ามใช้แทนกัน

ตรวจเองใน 10 วินาที: ln(35/36) ≈ −0.0282 บวก 0.0122 ได้ −0.016 หาร 0.12 ได้ −0.133 และราคาต้องอยู่ระหว่าง 0 กับ 35

แปลว่าอะไร: บนโต๊ะไม่มีใครใช้สูตรนี้หาราคา เพราะราคาอยู่บนจออยู่แล้ว ที่ทำจริงคือเดินย้อน ใส่ราคาตลาดแล้วแก้หาความผันผวนที่ทำให้สูตรตรงกับราคานั้น ได้ implied volatility ของหัวข้อ 13.4

import numpy as np
from scipy.stats import norm

S, K, T, r, sigma = 100.0, 105.0, 0.25, 0.04, 0.20
d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

c_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
p_price = K * np.exp(-r * T) * norm.cdf(-d2) - S * norm.cdf(-d1)

assert np.isclose(d1, -0.337901642, atol=1e-6)
assert np.isclose(d2, -0.437901642, atol=1e-6)
assert np.isclose(c_price, 2.39087696, atol=1e-6)
assert np.isclose(p_price, 6.34610950, atol=1e-6)
assert np.isclose(c_price - p_price, S - K * np.exp(-r * T), atol=1e-7)

c_div = 0.02
d1_div = (np.log(S / K) + (r - c_div + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
d2_div = d1_div - sigma * np.sqrt(T)
c_div_price = S * np.exp(-c_div * T) * norm.cdf(d1_div) - K * np.exp(-r * T) * norm.cdf(d2_div)
p_div_price = K * np.exp(-r * T) * norm.cdf(-d2_div) - S * np.exp(-c_div * T) * norm.cdf(-d1_div)

assert np.isclose(c_div_price, 2.21214362, atol=1e-6)
assert np.isclose(p_div_price, 6.66612831, atol=1e-6)
assert np.isclose(c_div_price - p_div_price, S * np.exp(-c_div * T) - K * np.exp(-r * T), atol=1e-7)
S2, K2, T2, r2, s2 = 35.0, 36.0, 0.25, 0.02, 0.24      # the source's call
num = np.log(S2 / K2) + (r2 + s2**2 / 2) * T2
assert abs(np.log(S2 / K2) + 0.028171) < 1e-6 and abs(num + 0.015971) < 1e-6
a1 = num / (s2 * np.sqrt(T2)); a2 = a1 - s2 * np.sqrt(T2)
assert abs(a1 + 0.133091) < 1e-6 and abs(a2 + 0.253091) < 1e-6
assert abs((np.log(S2 / K2) + (r2 - s2**2 / 2) * T2) / 0.12 - a2) < 1e-12
KD = K2 * np.exp(-r2 * T2)
assert abs(KD - 35.82045) < 1e-5
c2 = S2 * norm.cdf(a1) - KD * norm.cdf(a2)
assert abs(c2 - 1.31540) < 1e-5 and 0 <= c2 <= S2
assert abs(norm.cdf(a1) - 0.44706) < 1e-5 and abs(norm.cdf(a2) - 0.40010) < 1e-5
assert round(10_000 * norm.cdf(a1)) == 4471
assert abs((S2 - KD) * norm.cdf(a2) + 0.328) < 1e-3        # both legs with Phi(d2): negative
def bs(S, K, T, r, s):
    x1 = (np.log(S / K) + (r + s * s / 2) * T) / (s * np.sqrt(T))
    return S * norm.cdf(x1) - K * np.exp(-r * T) * norm.cdf(x1 - s * np.sqrt(T))
assert abs(bs(S2, K2, 3.0, r2, s2) - 6.2371) < 1e-4     # T typed as 3 months -> 3 years
assert bs(S2, K2, T2, r2, 1e-6) < 1e-9 and abs(bs(S2, K2, T2, r2, 50.0) - S2) < 1e-6
print("Assertions verified.")
