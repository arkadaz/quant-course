13.2 Itô's Lemma

เมื่อ $X$ ขยับด้วย drift $a$ และส่วนสุ่มขนาด $b$ ค่าของ $f(t,X)$ ได้ drift เพิ่ม $\tfrac12b^2f_{xx}$ ที่ chain rule ปกติไม่เห็น และพจน์นี้ทำให้ราคากลางของ SPY ปีหน้าต่ำกว่าค่าเฉลี่ย

SPY อยู่ที่ \$520 โต๊ะเขียนแบบจำลองเป็น SDE $dS_t=\mu S_t\,dt+\sigma S_t\,dW_t$ ด้วย drift 8% และความผันผวน 18% ต่อปี แปลว่าในก้าวสั้น ๆ เปอร์เซ็นต์ที่ราคาขยับมีค่าเฉลี่ย $\mu\,dt$ นักวิเคราะห์หารด้วย $S$ ได้ $dS/S=\mu\,dt+\sigma\,dW$ แล้วใช้ chain rule $d\ln S=dS/S$ สรุปว่า log ราคาโต 8% ต่อปี ราคากลางปีหน้า (median) คือ $520e^{0.08}=\$563.31$ และโอกาสจบปีต่ำกว่า \$520 คือ 32.8% รายงานความเสี่ยงควรใช้สองตัวเลขนี้ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ควร chain rule ทิ้งพจน์ความโค้งของ log ไป log ราคาจริงโต $0.08-\tfrac12(0.18)^2=0.0638$ ต่อปี median จึงเป็น \$554.26 ต่ำกว่าที่คิด \$9.05 และโอกาสจบปีต่ำกว่า \$520 คือ 36.2% ไม่ใช่ 32.8% ส่วน \$563.31 ไม่ได้ผิดทั้งหมด มันคือค่าเฉลี่ยของราคาปลายปีพอดี แค่ตอบคนละคำถาม

ภาพรวมก่อนลงสูตร

หน้าที่แล้ว ทำไม calculus ปกติใช้กับ Brownian motion ไม่ได้ พบว่าผลรวมกำลังสองของการขยับเท่ากับเวลาที่ผ่านไป chain rule สำหรับ $f(W)$ จึงต้องเติม $\tfrac12f''\,dt$ แต่ราคาจริงไม่ได้เป็น $W$ ตรง ๆ ราคามี drift และขนาดของส่วนสุ่มขึ้นกับราคาวันนั้น หน้านี้ทำ Taylor แบบเดียวกันกับ $f(t,X_t)$ เมื่อ $X$ ขยับตาม SDE ใด ๆ ได้กฎเต็มรูปที่เรียกว่า Itô's lemma

ใจความมีบรรทัดเดียว: drift ของ $f$ คือ drift ที่ chain rule ปกติให้ บวกครึ่งหนึ่งของความโค้ง $f_{xx}$ คูณ variance ต่อปีของการขยับ $b^2$ รูปด้านล่างแยก drift ของ $\ln S$ ของ SPY เป็นสองก้อนนี้: 8% ที่ chain rule เห็น กับ −1.62% ที่ความโค้งของ log กินไป เหลือ 6.38%

จากนั้นใช้กฎนี้กับ Geometric Brownian motion พิสูจน์ว่า SDE ของโต๊ะกับสูตร exponential คือ process เดียวกัน ตอบโจทย์ SPY ตรวจด้วยการเดิน SDE ทีละวันโดยไม่ใช้ผลของ Itô เลย และดูว่าความผันผวนกัดการโตของ median อย่างไร

ขั้นที่ 1 — SDE คือสูตรของก้าวเล็ก ๆ

ก่อนหาอนุพันธ์ของอะไร ต้องตกลงกันก่อนว่า $dX_t=a\,dt+b\,dW_t$ แปลว่าอะไร มันเป็นนิยาม: ซอยเวลาเป็นท่อน ท่อนละ $\Delta t$ อ่านค่า $a$ และ $b$ ที่ต้นท่อน แล้วขยับตามนี้ ลองอ่าน GBM ของ SPY ที่ท่อนละหนึ่งวันทำการ $\Delta t=1/252$ (ตลาดหุ้นสหรัฐเปิดราว 252 วันต่อปี)

\[ \begin{aligned} X_i-X_{i-1}&=a(t_{i-1},X_{i-1})\,\Delta t\\ &\quad+b(t_{i-1},X_{i-1})\,\Delta W_i,\\ \text{GBM}&:\ a=\mu S,\quad b=\sigma S,\\ a\,\Delta t&=520(0.08)/252=0.1651,\\ b\sqrt{\Delta t}&=520(0.18)/\sqrt{252}=5.896. \end{aligned} \]

$dX_t=a\,dt+b\,dW_t$ เป็นตัวย่อของบรรทัดแรกเมื่อ $\Delta t$ เล็กลงไม่สิ้นสุด หน้า Itô integral จะให้ความหมายแบบ integral ที่แม่นกว่านี้ จุดสำคัญคือ $a$ และ $b$ ใช้ค่าที่ต้นท่อน ซึ่งรู้แล้วก่อนก้าว แบบเดียวกับตัวคูณที่รู้ค่าก่อนก้าวซึ่งทำให้ $(dW)^2$ แทนด้วย $dt$ ได้

ในหนึ่งวัน drift ขยับ SPY ราว 16.5 เซนต์ ส่วนสุ่มมี SD \$5.90 ใหญ่กว่า 36 เท่า ส่วนสุ่มครองการขยับรายวัน ส่วน drift ค่อย ๆ สะสมตามเวลา

ขั้นที่ 2 — Taylor ของ f(t, X): ถามทีละพจน์ว่ารอดไหม

ให้ $f(t,x)$ มีอนุพันธ์ต่อเนื่องถึงอันดับสอง ในหนึ่งท่อน เวลาขยับ $\Delta t$ และตัวแปรขยับ $\Delta X$ Taylor สองตัวแปรถึงอันดับสองมีห้าพจน์ ใช้ตารางคูณของ Itô ($(dt)^2=0$, $dt\,dW=0$, $(dW)^2=dt$ เมื่อบวกทั้งช่วง) ตัดสินทีละพจน์

\[ \begin{aligned} \Delta f&=f_t\,\Delta t+f_x\,\Delta X+\tfrac12f_{xx}(\Delta X)^2\\ &\quad+f_{tx}\,\Delta t\,\Delta X+\tfrac12f_{tt}(\Delta t)^2+\cdots,\\ (\Delta X)^2&=a^2(\Delta t)^2+2ab\,\Delta t\,\Delta W\\ &\quad+b^2(\Delta W)^2,\\ (dX)^2&=0+0+b^2\,dt=b^2\,dt,\\ dt\,dX&=a\,(dt)^2+b\,dt\,dW=0,\\ (a\Delta t)^2&=0.1651^2=0.0273,\\ b^2\Delta t&=5.896^2=34.77. \end{aligned} \]

ใน $(\Delta X)^2$ กำลังสองของ drift และพจน์ไขว้มี $(\Delta t)^2$ กับ $\Delta t\,\Delta W$ ซึ่งบวกทั้งช่วงแล้วหายไป เหลือแค่ $b^2(\Delta W)^2$ ที่บวกแล้วได้เหมือน $b^2\Delta t$ พจน์ $f_{tx}$ และ $f_{tt}$ ก็หายด้วยเหตุผลเดียวกัน อันดับสองจึงเหลือพจน์ใหม่พจน์เดียว

ตัวเลขของ SPY บอกเหตุผลเป็นขนาด: ในหนึ่งวันกำลังสองของส่วนสุ่มเฉลี่ย 34.77 แต่กำลังสองของ drift แค่ 0.0273 ห่างกัน $\sigma^2/(\mu^2\Delta t)=1{,}276$ เท่า และห่างขึ้นอีกเมื่อก้าวสั้นลง

ขั้นที่ 3 — ประกอบเป็น Itô's lemma

เก็บพจน์ที่รอด แทน $dX$ ด้วยนิยามของ SDE และ $(dX)^2$ ด้วย $b^2\,dt$ ที่เพิ่งได้ แล้วจัดกลุ่มเป็นส่วนที่คาดได้กับส่วนสุ่ม

\[ \begin{aligned} df&=f_t\,dt+f_x\,dX+\tfrac12f_{xx}(dX)^2\\ &=f_t\,dt+f_x(a\,dt+b\,dW)+\tfrac12f_{xx}b^2\,dt\\ &=\big(f_t+a f_x+\tfrac12b^2f_{xx}\big)\,dt\\ &\quad+b f_x\,dW,\\ d\,\mathbb E[f]&=\mathbb E\big[f_t+a f_x+\tfrac12b^2f_{xx}\big]\,dt. \end{aligned} \]

chain rule ปกติให้ drift $f_t+af_x$ Itô เติม $\tfrac12b^2f_{xx}$ คือครึ่งหนึ่งของความโค้งคูณ variance ต่อปีของการขยับ ส่วนสุ่ม $bf_x\,dW$ เหมือนเดิม ความโค้งไม่เปลี่ยนความแรงของการสั่น แต่เปลี่ยนทิศที่ค่าเฉลี่ยเอียงไป

ที่แทน $(\Delta X)^2$ ด้วย $b^2\Delta t$ ได้แม้มีตัวคูณ เพราะ $\tfrac12f_{xx}b^2$ ใช้ค่าที่ต้นท่อน บรรทัดสุดท้ายได้จากการเอาค่าเฉลี่ยสองข้าง พจน์ $dW$ มีค่าเฉลี่ยศูนย์เพราะตัวคูณรู้ค่าก่อนก้าว ส่วนการขยับข้างหน้าเฉลี่ยศูนย์ไม่ว่าอดีตเป็นอย่างไร

ขั้นที่ 4 — ตรวจกับสามเรื่องที่รู้คำตอบแล้ว

โจทย์ให้อะไรมาบ้าง: กฎใหม่ต้องให้คำตอบเดิมในเรื่องที่ตอบได้ทางอื่น ลองสามเรื่อง: (a) ผลตอบแทนสะสม $R_t=\mu t+\sigma W_t$ กับ $f=x^2$ ได้ $a=\mu$, $b=\sigma$ (b) $f=x^2-t$ บน $W$ ได้ $a=0$, $b=1$ (c) $f=e^{\sigma x-\sigma^2t/2}$ บน $W$

\[ \begin{aligned} \text{(a)}\ d(R^2)&=(2\mu R+\sigma^2)\,dt+2\sigma R\,dW,\\ \tfrac{d}{dt}\mathbb E[R_t^2]&=2\mu(\mu t)+\sigma^2,\\ \mathbb E[R_1^2]&=\mu^2+\sigma^2=0.0388,\\ \text{(b)}\ \text{drift}&=-1+0+\tfrac12(1)(2)=0,\\ \text{(c)}\ \text{drift}&=-\tfrac12\sigma^2f+0+\tfrac12\sigma^2f=0,\\ \mathbb E\big[e^{0.18W_1}\big]&=e^{0.0162}=1.01633. \end{aligned} \]

คำตอบ: (a) ได้ 0.0388 ตรงกับสัญญา \$1 ล้าน คูณ $R^2$ ที่จ่ายเฉลี่ย \$38,800 ในหน้า quadratic variation (b) $W_t^2-t$ ไม่มี drift จึงมีค่าเฉลี่ยคงที่ที่ 0 ได้ $\mathbb E[W_t^2]=t$ ตรงกับ variance ของ Brownian motion มาตรฐาน (c) ไม่มี drift ค่าเฉลี่ยจึงคงที่ที่ $f(0,0)=1$ ย้าย $e^{-\sigma^2/2}$ ไปอีกข้างได้บรรทัดสุดท้าย ใน (b) และ (c) พจน์ $f_t$ ติดลบพอดีกับ Itô correction ที่เป็นบวก

ตรวจเองใน 10 วินาที: ใน (c) $f_t=-\tfrac12\sigma^2f$ เพราะอนุพันธ์ของเลขชี้กำลังตาม $t$ คือ $-\sigma^2/2$ และ $f_{xx}=\sigma^2f$ เพราะดึง $\sigma$ ออกมาสองครั้ง สองพจน์นี้หักกันพอดี บรรทัดสุดท้ายยังได้ทางอื่นด้วย: ถ้า $Y$ เป็น Normal ค่าเฉลี่ยศูนย์ variance $v$ ค่าเฉลี่ยของ $e^{Y}$ คือ $e^{v/2}$ (moment generating function ของ Normal) ที่นี่ $Y=0.18W_1$ มี $v=0.0324$ จึงได้ $e^{0.0162}$

ขั้นที่ 5 — GBM: หา drift ของ log ราคา

ตอนนี้กลับไปที่โจทย์ SPY GBM มี $S$ อยู่ทั้งสองพจน์ จึงแก้ตรง ๆ ไม่ได้ แต่ log เปลี่ยนการคูณเป็นการบวก ลอง $f(t,x)=\ln x$ ซึ่งไม่มีเวลาอยู่ในตัว แล้วแทนทีละช่องของ Itô's lemma ที่เพิ่งประกอบ

\[ \begin{aligned} f_t&=0,\quad f_x=\frac1S,\quad f_{xx}=-\frac1{S^2},\\ a f_x&=\mu S\cdot\frac1S=\mu,\\ \tfrac12b^2f_{xx}&=\tfrac12\sigma^2S^2\Big(-\frac1{S^2}\Big)=-\tfrac12\sigma^2,\\ d\ln S_t&=\big(\mu-\tfrac12\sigma^2\big)\,dt+\sigma\,dW_t,\\ \mu-\tfrac12\sigma^2&=0.08-\tfrac12(0.0324)\\ &=0.08-0.0162=0.0638. \end{aligned} \]

ทุกช่อง $S$ ตัดกันหมด เหลือค่าคงที่: log ราคาคือ Brownian motion ที่มี drift $0.0638$ และความผันผวน $0.18$ ไม่ว่าราคาจะอยู่ที่ \$520 หรือ \$100 นักวิเคราะห์ในโจทย์หยุดที่ช่องที่สองซึ่งให้ $\mu$

ช่องที่สามคือสิ่งที่หายไป log โค้งคว่ำ ($f_{xx}\lt0$) ขาลงจึงเสียมากกว่าขาขึ้นได้ รูปด้านล่างแสดงด้วยตัวเลข: ถ้า SPY ขึ้นหรือลง 18% ด้วยโอกาสเท่ากัน ราคาเฉลี่ยยังอยู่ที่ \$520 แต่ค่าเฉลี่ยของ log คือ $\tfrac12\big(\ln0.82+\ln1.18\big)=-0.0165$ ใกล้ $-\tfrac12\sigma^2=-0.0162$

ขั้นที่ 6 — SDE ของโต๊ะกับสูตร exponential คือ process เดียวกัน

ฝั่งขวาของ $d\ln S$ ไม่มี $S$ เหลือ จึงบวกทุกท่อนได้ตรง ๆ: ผลรวมของ $dt$ คือ $T$ และผลรวมของ $dW$ คือ $W_T-W_0=W_T$ แล้วตรวจย้อนทาง ใช้ Itô กับสูตรที่ได้บน $X=W$ ($a=0$, $b=1$) ต้องได้ SDE เดิมกลับมา

\[ \begin{aligned} \ln S_T-\ln S_0&=\big(\mu-\tfrac12\sigma^2\big)T+\sigma W_T,\\ S_T&=S_0\,e^{(\mu-\frac12\sigma^2)T+\sigma W_T},\\ g(t,w)&:=S_0\,e^{(\mu-\frac12\sigma^2)t+\sigma w},\\ g_t&=\big(\mu-\tfrac12\sigma^2\big)g,\quad g_w=\sigma g,\\ g_{ww}&=\sigma^2g,\\ dg&=\big(\mu-\tfrac12\sigma^2+\tfrac12\sigma^2\big)g\,dt+\sigma g\,dW\\ &=\mu g\,dt+\sigma g\,dW. \end{aligned} \]

บรรทัดที่สองคือนิยามของ GBM ในหน้า Geometric Brownian motion ทุกตัว ส่วนห้าบรรทัดล่างพิสูจน์ทางกลับ: Itô correction $+\tfrac12\sigma^2$ ของ exponential หักล้าง $-\tfrac12\sigma^2$ ที่ใส่ไว้ในเลขชี้กำลังพอดี นิยามของ GBM ต้องใส่ $\mu-\tfrac12\sigma^2$ ไว้ในเลขชี้กำลังเพื่อให้เปอร์เซ็นต์ที่ขยับเฉลี่ย $\mu\,dt$ และตอนนี้เห็นแล้วว่าเป็นเหตุผลเดียวกัน

ผลพลอยได้มีสามข้อ ราคาเป็น exponential จึงไม่ติดลบ (เจ้าของหุ้นเสียได้ไม่เกินเงินที่ลงไป) อัตราส่วน $S_{t+s}/S_t=e^{(\mu-\frac12\sigma^2)s+\sigma(W_{t+s}-W_t)}$ ขึ้นกับแค่ช่วงเวลา $s$ ไม่ขึ้นกับราคาวันนี้ และจำลองได้ตรงเป๊ะโดยไม่ต้องก้าวทีละวัน (การจำลอง SDE)

ขั้นที่ 7 — คำตอบของโจทย์ SPY: median, ค่าเฉลี่ย และโอกาสขาดทุน

โจทย์ให้อะไรมาบ้าง: $S_0=\$520$, $\mu=0.08$, $\sigma=0.18$, $T=1$ ปี และ $W_1=Z\sim\mathcal N(0,1)$ median ของ $Z$ คือ 0 และ exponential ไม่สลับลำดับของตัวเลข median ของราคาจึงได้จากการใส่ $Z=0$ ค่าเฉลี่ยได้จากค่าเฉลี่ยของ Itô's lemma กับ $f=x$ ซึ่งให้ $d\,\mathbb E[S]=\mu\,\mathbb E[S]\,dt$

\[ \begin{aligned} \operatorname{Med}(S_1)&=520\,e^{0.0638}=554.26,\\ \mathbb E[S_1]&=520\,e^{0.08}=563.31,\\ \ln(S_1/520)&=0.0638+0.18Z,\\ S_1\lt520&:\ Z\lt-0.0638/0.18=-0.3544,\\ P(S_1\lt520)&=\Phi(-0.3544)=0.3615,\\ \Phi(-0.08/0.18)&=\Phi(-0.4444)=0.3284. \end{aligned} \]

คำตอบ: ครึ่งหนึ่งของเส้นทางจบปีต่ำกว่า \$554.26 ค่าเฉลี่ยคือ \$563.31 ห่างกัน \$9.05 และโอกาสจบต่ำกว่า \$520 คือ 36.2% chain rule ปกติให้ median เท่ากับค่าเฉลี่ย และให้โอกาสขาดทุน 32.8% (บรรทัดสุดท้าย) ต่ำไป 3.3 จุด เพราะใช้จุดกลางของ log ที่ 0.08 แทน 0.0638

ตรวจเองใน 10 วินาที: ค่าเฉลี่ยได้อีกทางจาก moment generating function ของ Normal: $\mathbb E[e^{0.18Z}]=e^{0.0162}$ คูณ $520e^{0.0638}$ ได้ $520e^{0.08}$ พอดี และ $e^{0.0638}\approx1+0.0638+0.0638^2/2=1.0658$ คูณ 520 ได้ราว \$554.2

ขั้นที่ 8 — หุ้นที่ผันผวนกว่า: ช่องว่างโตตาม σ²

โจทย์ให้อะไรมาบ้าง: หุ้นสมมติราคา \$100 drift 12% และความผันผวน 28% ต่อปี ใช้สูตร drift ของ log, median, ค่าเฉลี่ย และโอกาสขาดทุนชุดเดิม เปลี่ยนแค่ตัวเลข

\[ \begin{aligned} \mu-\tfrac12\sigma^2&=0.12-\tfrac12(0.0784)=0.0808,\\ \operatorname{Med}(S_1)&=100\,e^{0.0808}=108.42,\\ \mathbb E[S_1]&=100\,e^{0.12}=112.75,\\ P(S_1\lt100)&=\Phi(-0.0808/0.28)\\ &=\Phi(-0.2886)=0.3865,\\ \Phi(-0.12/0.28)&=\Phi(-0.4286)=0.3341. \end{aligned} \]

คำตอบ: median \$108.42 ค่าเฉลี่ย \$112.75 ห่างกัน \$4.33 หรือ 4.3% ของราคา ขณะที่ SPY ห่าง $9.05/520=1.7\%$ โอกาสขาดทุนหนึ่งปีคือ 38.6% และ chain rule ปกติให้ 33.4% ต่ำไป 5.2 จุด ยิ่งผันผวน ความผิดของ chain rule ยิ่งใหญ่ เพราะพจน์ที่มันทิ้งคือ $\tfrac12\sigma^2$

ตรวจเองใน 10 วินาที: $0.28^2=0.0784$ ครึ่งหนึ่งคือ 0.0392 และ $e^{0.0808}\approx1+0.0808+0.0033=1.0841$

ขั้นที่ 9 — volatility drag: ความผันผวนกัดการโตของ median

หุ้นที่ผันผวนกว่ามีช่องว่างระหว่าง median กับค่าเฉลี่ยกว้างกว่า ลองตรึง drift ของราคาไว้ที่ 12% แล้วเปลี่ยนแค่ $\sigma$ ดูว่าอัตราโตของ median $g(\sigma)=\mu-\tfrac12\sigma^2$ ลดลงเท่าไร และถึงศูนย์ที่ไหน

\[ \begin{aligned} g(\sigma)&=0.12-\tfrac12\sigma^2,\\ \sigma=0.10,\ 0.18,\ 0.28&:\ 0.115,\ 0.1038,\ 0.0808,\\ \sigma=0.50,\ 0.60&:\ -0.005,\ -0.06,\\ g(\sigma)=0&:\ \sigma=\sqrt{2(0.12)}=0.490,\\ \mu=0.08&:\ \sigma=\sqrt{0.16}=0.40. \end{aligned} \]

ค่าเฉลี่ยของราคายังโต 12% ต่อปีทุกแถว เพราะ $\mathbb E[S_T]=S_0e^{\mu T}$ ไม่มี $\sigma$ อยู่เลย แต่ median โตช้าลงเรื่อย ๆ และที่ความผันผวน 49% median ไม่โตเลย ถ้า SPY ผันผวนถึง 40% ขณะที่ drift ยังเป็น 8% (บรรทัดสุดท้าย) median ของมันก็จะหยุดโตเช่นกัน

drag นี้ไม่ใช่เงินที่ใครหักไป มันคือความโค้งของ log: ขึ้น 10% แล้วลง 10% เหลือ $1.1\times0.9=0.99$ ความผันผวนยิ่งแรง การขึ้นลงสลับกันยิ่งกัดมาก

ขั้นที่ 10 — ตรวจด้วยการเดิน SDE ทีละวัน โดยไม่ใช้ผลของ Itô

โจทย์ให้อะไรมาบ้าง: โค้ดท้ายหน้าเดิน SDE ตรงตามนิยามก้าวเล็ก ๆ คือ $S_i=S_{i-1}(1+\mu\Delta t+\sigma\Delta W_i)$ วันละก้าว 252 ก้าว 20,000 เส้นทาง ด้วย seed 132 ในโค้ดส่วนนี้ไม่มี $\tfrac12\sigma^2$ หรือ log อยู่เลย แล้ววัดสี่ค่าเทียบกับทฤษฎีเป็นจำนวน SE

ตรวจเองใน 10 วินาที: SE ของค่าเฉลี่ย log คือ $0.18/\sqrt{20{,}000}=0.00127$ และ $(0.063807-0.08)/0.00127\approx-12.7$ ส่วน SE ของค่าเฉลี่ยราคาคือ SD ของราคาปลายปี \$102.22 (หาจาก $S^2$ ในขั้นถัดไป) หารด้วย 141.4 ได้ \$0.72

การเดินวันละก้าวไม่ใช่ GBM ตรงเป๊ะ ค่าเฉลี่ยของมันคือ $520(1+0.08/252)^{252}=\$563.302$ ต่างจาก \$563.309 แค่ 0.7 เซนต์ เล็กกว่า SE ร้อยเท่า ตัวเลขนี้คือดอกเบี้ยทบต้นรายวันเทียบกับทบต้นต่อเนื่อง $e^{0.08}$ นั่นเอง SE ของ median ใช้ $1/(2p\sqrt N)$ เมื่อ $p$ คือ density ที่ median ได้ \$0.88

ขั้นที่ 11 — ใช้กับ S²: chain rule ปกติบอกว่าราคาปลายปีไม่กระจายเลย

median และค่าเฉลี่ยยังไม่บอกว่าราคากระจายกว้างแค่ไหน ต้องใช้ $\mathbb E[S_1^2]$ ใช้ Itô กับ $f=x^2$ ซึ่งมี $f_x=2S$ และ $f_{xx}=2$ บน GBM แล้วเอาค่าเฉลี่ยสองข้าง

\[ \begin{aligned} d(S^2)&=\big(2\mu S^2+\sigma^2S^2\big)\,dt+2\sigma S^2\,dW,\\ \mathbb E[S_1^2]&=520^2e^{2(0.08)+0.0324}\\ &=327{,}766.8,\\ \operatorname{SD}(S_1)&=\sqrt{327{,}766.8-563.31^2}\\ &=102.22,\\ 520^2e^{0.16}&=317{,}317.3=563.31^2. \end{aligned} \]

บรรทัดแรกคือ $af_x=2\mu S^2$ บวก $\tfrac12b^2f_{xx}=\tfrac12\sigma^2S^2(2)$ drift เป็นสัดส่วนกับ $S^2$ ค่าเฉลี่ยจึงโตแบบ exponential ด้วยอัตรา $2\mu+\sigma^2=0.1924$ ต่อปี ราคาปลายปีมี SD \$102.22 หรือราว 18% ของค่าเฉลี่ย

chain rule ปกติได้อัตรา $2\mu$ (บรรทัดสุดท้าย) ซึ่งทำให้ $\mathbb E[S_1^2]=(\mathbb E[S_1])^2$ พอดี แปลว่า variance เป็นศูนย์ คือราคาปลายปีแน่นอน ทั้งที่แบบจำลองมีความผันผวน 18% พจน์ที่มันทิ้งคือความกว้างทั้งหมดของการกระจาย

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

เรียก $\mu-\tfrac12\sigma^2$ ว่า expected return: พอร์ต SPY \$10 ล้าน ค่าเฉลี่ยหนึ่งปีคือ $10^7e^{0.08}$ ถ้าตารางหนึ่งใช้ 6.38% เป็นผลตอบแทนคาดหวัง จะได้ $10^7e^{0.0638}$ ต่ำไป \$174,079 ทั้งที่ใช้แบบจำลองเดียวกัน ต้องเขียนกำกับทุกครั้งว่าตัวเลขนั้นคือ drift ของราคาหรือ drift ของ log

ใช้ $\mu$ เป็นจุดกลางของ log ตอนคิดโอกาสขาดทุน: SPY ได้ 32.8% แทน 36.2% และหุ้นผันผวน 28% ได้ 33.4% แทน 38.6% รายงานความเสี่ยงต่ำไป 3.3 และ 5.2 จุด โดยไม่มีตัวเลขไหนดูแปลก

คูณ drift ของ log ด้วย leverage: กองทุน 3 เท่ารายวันมี $dL/L=3\,dS/S$ คือ $a=3\mu L$, $b=3\sigma L$ ใช้สูตร drift ของ log ได้ $3\mu-\tfrac92\sigma^2=0.24-0.1458=0.0942$ ไม่ใช่ $3(0.0638)=0.1914$ median ของเงิน \$1 ล้านหลังหนึ่งปีคือ \$1,098,779 ไม่ใช่ \$1,210,944 (ยังไม่คิดค่าธรรมเนียมและดอกเบี้ย) ความผันผวนสามเท่าทำให้ drag โตเก้าเท่า

ใช้ทำอะไรบนโต๊ะจริง

ทุกครั้งที่โต๊ะแปลงราคาเป็น log return หรือแปลงกลับ มี Itô's lemma อยู่ข้างใน: VaR บน log return ใช้จุดกลาง $\mu-\tfrac12\sigma^2$ ส่วนการคาดการณ์มูลค่าพอร์ตเฉลี่ยใช้ $\mu$ เวลาตั้งราคา option โต๊ะเขียน GBM ด้วยอัตราดอกเบี้ย $r$ และ dividend yield $q$ แทน $\mu$ คือ $dS=(r-q)S\,dt+\sigma S\,dW$ Itô's lemma ให้ drift ของ log เป็น $r-q-\tfrac12\sigma^2$ ซึ่งเป็นตัวที่โผล่ใน $d_2$ ของ สูตร Black–Scholes และใน characteristic function ของ $\ln S_T$ ที่ใช้ตั้งราคาด้วย Fourier และ FFT

งานที่ใหญ่ที่สุดคือใช้ Itô's lemma กับมูลค่า option $V(t,S)$ ได้ $dV=(V_t+\mu SV_S+\tfrac12\sigma^2S^2V_{SS})\,dt+\sigma SV_S\,dW$ พจน์ $\tfrac12\sigma^2S^2V_{SS}$ คือผลของ gamma และเป็นแกนของ สมการ Black–Scholes ส่วน payoff หักมุมอย่าง $\max(S-K,0)$ ไม่มี $f_{xx}$ ที่ strike จึงใช้ Itô กับมูลค่าก่อนหมดอายุซึ่งเรียบ ไม่ใช่กับ payoff ในวันสุดท้าย

อย่าลืมว่า GBM เป็นแค่จุดเริ่ม log return จริงมีหางหนากว่า Normal และความผันผวนเปลี่ยนตลอด (stylized facts) Itô's lemma ยังใช้ได้กับแบบจำลองที่ความผันผวนเป็นตัวแปรสุ่มเอง เช่น Heston แค่ drift ของ log กลายเป็น $\mu-\tfrac12\sigma_t^2$ ที่เปลี่ยนตามเวลา

โจทย์ตรวจความเข้าใจ

1. หุ้นราคา \$100 จ่าย dividend yield 1% ดอกเบี้ย 5% ความผันผวน 30% ต่อปี โต๊ะ option เขียน $dS=(r-q)S\,dt+\sigma S\,dW$ หา drift ของ log, median และค่าเฉลี่ยของราคาในหนึ่งปีภายใต้แบบจำลองนี้ และโอกาสที่ call strike \$80 จบ in the money

เฉลย

drift ของ log คือ $0.05-0.01-\tfrac12(0.09)=-0.005$ ติดลบเล็กน้อย median คือ $100e^{-0.005}=\$99.50$ ค่าเฉลี่ยคือ $100e^{0.04}=\$104.08$ (คือราคา forward หนึ่งปี) call จบ in the money เมื่อ $\ln(S_1/100)\gt\ln0.8=-0.22314$ คือ $Z\gt(-0.22314+0.005)/0.30=-0.7271$ โอกาส $\Phi(0.7271)=76.6\%$ ตัวเลข $0.7271$ คือ $d_2$ ของ Black–Scholes และราคา call ที่ได้คือ \$25.61 ถ้าใช้ chain rule ปกติ ($0.04$ แทน $-0.005$) จะได้ 81.0% สูงไป 4.3 จุด

2. คุณจะซื้อ SPY มูลค่า \$1 ล้านในอีกหนึ่งปี ค่าเฉลี่ยของจำนวนหุ้นที่ได้คือเท่าไร? (ใช้ Itô กับ $f=1/x$)

เฉลย

$f_x=-1/S^2$ และ $f_{xx}=2/S^3$ drift คือ $\mu S(-1/S^2)+\tfrac12\sigma^2S^2(2/S^3)=(\sigma^2-\mu)/S$ จึงได้ $d(1/S)=(\sigma^2-\mu)(1/S)\,dt-\sigma(1/S)\,dW$ อัตราคือ $0.0324-0.08=-0.0476$ จำนวนหุ้นเฉลี่ยคือ $(10^6/520)e^{-0.0476}=1{,}923.08\times0.953515=1{,}833.68$ หุ้น มากกว่า $10^6/\mathbb E[S_1]=10^6/563.31=1{,}775.22$ เพราะ $1/x$ โค้งหงาย

3. ผู้ขายข้อมูลส่งแบบจำลองมาเป็น $S_T=S_0e^{0.05T+0.20W_T}$ drift $\mu$ ของ SDE คือเท่าไร และหุ้น \$100 มีค่าเฉลี่ยกับ median หลังหนึ่งปีเท่าไร?

เฉลย

เทียบกับสูตร exponential ของ GBM: $\mu-\tfrac12\sigma^2=0.05$ และ $\sigma=0.20$ จึงได้ $\mu=0.05+0.02=0.07$ ค่าเฉลี่ยคือ $100e^{0.07}=\$107.25$ median คือ $100e^{0.05}=\$105.13$ ถ้าเผลอเอา 5% เป็น drift ของราคา จะประมาณค่าเฉลี่ยต่ำไป \$2.12

รันใน Node.js ได้โดยไม่ต้องติดตั้งอะไร ฟังก์ชัน ito คือ Itô's lemma ใช้หา drift ของ $\ln S$, $S^2$, $1/S$ และกองทุน 3 เท่า จากนั้นเดิน SDE ทีละวันด้วยเครื่องสุ่มที่มี seed แล้วเทียบกับทฤษฎีเป็นจำนวน SE

// Standard Normal CDF: Simpson's rule on the bell curve from 0 to |x|.
function Phi(x) {
  if (!Number.isFinite(x) || Math.abs(x) > 8) throw new RangeError('Phi needs a finite score between -8 and 8');
  const n = 4000, h = Math.abs(x) / n, phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(x) * s * h / 3;
}
// Ito's lemma for dX = a dt + b dW: df = (f_t + a f_x + b^2 f_xx / 2) dt + b f_x dW.
function ito(d, a, b) {
  const {ft = 0, fx, fxx} = d;
  if (![ft, fx, fxx, a, b].every(Number.isFinite)) throw new TypeError('Derivatives and coefficients must be finite numbers');
  return {drift: ft + a * fx + 0.5 * b * b * fxx, noise: b * fx};
}
// GBM dS = mu S dt + sigma S dW. ln S has f_x = 1/S and f_xx = -1/S^2; S cancels, so any S gives the same drift.
function gbmStats(S0, mu, sigma, T, K = S0) {
  if (![S0, mu, sigma, T, K].every(Number.isFinite) || S0 <= 0 || sigma <= 0 || T <= 0 || K <= 0) throw new RangeError('Need S0, sigma, T, K > 0');
  const logDrift = ito({fx: 1 / S0, fxx: -1 / (S0 * S0)}, mu * S0, sigma * S0).drift;
  // E[S^2] from Ito on S^2: its drift is (2 mu + sigma^2) S^2.
  const rate2 = ito({fx: 2 * S0, fxx: 2}, mu * S0, sigma * S0).drift / (S0 * S0);
  const mean = S0 * Math.exp(mu * T), second = S0 * S0 * Math.exp(rate2 * T);
  const z = (Math.log(K / S0) - logDrift * T) / (sigma * Math.sqrt(T));
  const zNaive = (Math.log(K / S0) - mu * T) / (sigma * Math.sqrt(T));
  return {logDrift, median: S0 * Math.exp(logDrift * T), mean, sd: Math.sqrt(second - mean * mean),
    below: Phi(z), naiveBelow: Phi(zNaive)};
}
// mulberry32 + Box-Muller: seeded standard Normals, the same generator as the quadratic-variation page.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Step the SDE itself, S_i = S_(i-1) (1 + mu dt + sigma dW_i). No Ito result is used inside.
function simulateGBM(paths, steps, S0, mu, sigma, T, seed) {
  const z = normals(seed), dt = T / steps, sq = Math.sqrt(dt), ends = new Float64Array(paths);
  let logSum = 0, sum = 0, below = 0;
  for (let p = 0; p < paths; p++) {
    let S = S0;
    for (let k = 0; k < steps; k++) S *= 1 + mu * dt + sigma * sq * z();
    ends[p] = S; logSum += Math.log(S / S0); sum += S;
    if (S < S0) below++;
  }
  ends.sort();
  const median = paths % 2 ? ends[(paths - 1) / 2] : (ends[paths / 2 - 1] + ends[paths / 2]) / 2;
  return {meanLog: logSum / paths, median, mean: sum / paths, below: below / paths};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • $dX=a\,dt+b\,dW$ คือสูตรก้าวเล็ก ๆ ที่อ่าน $a$ และ $b$ ที่ต้นก้าว ใน $(dX)^2$ เหลือแค่ $b^2\,dt$
  • Itô's lemma: $df=(f_t+af_x+\tfrac12b^2f_{xx})\,dt+bf_x\,dW$ พจน์ใหม่ขึ้นกับความผันผวนและความโค้ง ไม่ขึ้นกับ drift
  • GBM: $d\ln S=(\mu-\tfrac12\sigma^2)\,dt+\sigma\,dW$ จึงได้ $S_T=S_0e^{(\mu-\frac12\sigma^2)T+\sigma W_T}$ ซึ่งคือนิยามของ GBM
  • SPY \$520 drift 8% ความผันผวน 18%: median ปีหน้า \$554.26 ค่าเฉลี่ย \$563.31 โอกาสจบต่ำกว่า \$520 คือ 36.2% ไม่ใช่ 32.8%
  • การเดิน SDE ทีละวันโดยไม่ใช้ Itô ให้ค่าเฉลี่ย log 0.063807 ห่าง 0.0638 แค่ 0.005 SE และห่าง 0.08 ถึง 12.7 SE

หน้าถัดไป Itô integral ถามว่า $\int b\,dW$ ที่ซ่อนอยู่ใน SDE ทุกตัวแปลว่าอะไรแน่ ทำไมต้องอ่านตัวคูณที่ต้นท่อน และถ้าอ่านที่ปลายท่อนจะได้กำไรปลอมเท่าไร
