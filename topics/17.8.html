17.8 Covariance Shrinkage (Ledoit-Wolf)

optimizer เทเงินไปที่ความคลาดเคลื่อนของค่าที่ประมาณ การดึงค่าเฉลี่ยและ covariance เข้าหาสิ่งที่เรียบง่ายยอมเบี้ยวนิดหนึ่งเพื่อแลกกับความนิ่งมาก และ Ledoit-Wolf เลือกว่าจะดึงแรงแค่ไหนจากข้อมูลเอง

ไฟล์ Assignment 2 ให้ผลตอบแทนรายเดือน 60 เดือนของสามสินทรัพย์ พอร์ต tangency ที่คำนวณจากค่าเฉลี่ยและ covariance ที่ประมาณได้สัญญา Sharpe ratio 0.864 สูงกว่าที่พอร์ตดีที่สุดของค่าจริงทำได้ (0.851) เสียอีก ถ้าค่าจริงคือค่าในแผ่นแรกของไฟล์ (ค่าเฉลี่ย 6%, 2% และ 4%) พอร์ตนี้ได้จริงเท่าไร และแก้อย่างไรที่ง่ายที่สุด?

ลองตอบก่อนเปิดเฉลย

ได้จริง 0.586 ต่ำกว่าที่ทำได้หนึ่งในสาม เพราะ optimizer เทเงิน 78% ไปที่ตัวที่ค่าเฉลี่ยถูกประมาณสูงเกินที่สุด ทางแก้ที่ง่ายที่สุดคือดึงค่าเฉลี่ยทั้งสามให้เท่ากันหมด ได้ Sharpe จริง 0.834 เกือบเท่าที่ดีที่สุด เพราะ optimizer เหลือแต่ covariance ซึ่งประมาณได้แม่นกว่ามาก

สิ่งที่เราจะสร้าง

17.3 เห็นแล้วว่าน้ำหนัก tangency ขยับราว 4.3 จุดต่อ 1 จุดของค่าเฉลี่ย และไฟล์แปดกลุ่มให้น้ำหนัก 568% ส่วน 17.4 เห็นว่า inverse ขยายทิศที่ eigenvalue เล็ก 56 เท่า หน้านี้แก้ปัญหานั้น: เมื่อตัวเลขที่ป้อนมีเสียงรบกวน ให้ดึงมันเข้าหาสิ่งที่นิ่งกว่า

เริ่มจากการทดลองในความคิดว่าทำไม optimizer เลือกข้างที่ผิดเสมอ วัดว่าค่าเฉลี่ยห้าปีคลาดได้แค่ไหน ดูไฟล์ Assignment 2 ดึงค่าเฉลี่ยเข้าหากัน แล้วทำแบบเดียวกันกับ covariance: ดูว่าการผสมกับ identity ทำอะไรกับ eigenvalue ลองกับสองสินทรัพย์ที่เกือบเป็นตัวเดียวกัน คิดความเข้มแบบ Ledoit-Wolf ด้วยมือจากข้อมูลสี่วัน และจบที่ข้อมูลที่เป็นเสียงรบกวนล้วน

ขั้นที่ 1 — ลองด้วยมือ: สองสินทรัพย์ที่เหมือนกันทุกอย่าง

สไลด์ของคอร์สให้การทดลองในความคิด: สองสินทรัพย์ค่าเฉลี่ยจริง 5% ความผันผวน 20% เท่ากัน ไม่สัมพันธ์กัน เงินสด 1% ค่าที่ประมาณได้ของตัวแรกสูงไป 1 จุด ตัวที่สองต่ำไป 1 จุด ความคลาดเฉลี่ยเป็นศูนย์ เมื่อ covariance เป็น $0.04I$ ทิศของ tangency คือส่วนเกินเงินสดตรง ๆ (17.3)

\[ \begin{aligned} \hat\mu&=(6\%,\ 4\%),\quad\mu=(5\%,\ 5\%),\\ w&\propto(\hat\mu-r_f)=(5,\ 3),\quad w=(0.625,\ 0.375),\\ \sigma_p&=0.20\sqrt{0.625^2+0.375^2}=14.58\%,\\ \text{promised}&:\ \frac{0.625(6)+0.375(4)-1}{14.58}\\ &=\frac{4.25}{14.58}=0.2915,\\ \text{delivered}&:\ \frac{5-1}{14.58}=0.2744,\\ \text{best}&:\ w=(\tfrac12,\ \tfrac12),\ \frac{4}{14.14}=0.2828. \end{aligned} \]

คำตอบที่ถูกคือแบ่งครึ่ง optimizer กลับเทเงินไปที่ตัวที่ถูกประมาณสูงเกิน ซึ่งผิดทางพอดี พอร์ตสัญญา 0.2915 แต่ได้จริง 0.2744 แย่กว่าการแบ่งครึ่งเฉย ๆ

ความคลาดที่เฉลี่ยเป็นศูนย์ไม่หักล้างกันในพอร์ต เพราะ optimizer ไม่ได้สุ่มเลือก มันเลือกข้างที่ความคลาดเป็นบวกเสมอ ตัวเลขที่ optimizer สัญญาจึงสูงเกินจริงเสมอ

ขั้นที่ 2 — ทำไมค่าเฉลี่ยประมาณยากกว่า covariance มาก

ค่าเฉลี่ยรายปีที่ได้จาก 60 เดือนคือ 12 เท่าของค่าเฉลี่ยรายเดือน ค่าเฉลี่ยของ 60 ตัวมี standard error เป็นความผันผวนหารด้วย $\sqrt{60}$ (3.3) ใช้ความผันผวนจริงจากแนวทแยงของ $V$

\[ \begin{aligned} \mathrm{SE}(\hat\mu_{\text{ann}})&=\frac{12\,\sigma_{\text{mon}}}{\sqrt{60}}=\frac{\sqrt{12}\,\sigma_{\text{ann}}}{\sqrt{60}}\\ &=\frac{\sigma_{\text{ann}}}{\sqrt5},\\ \sigma_{\text{ann}}&=\sqrt{0.008},\ \sqrt{0.002},\ \sqrt{0.008}\\ &=8.94\%,\ 4.47\%,\ 8.94\%,\\ \mathrm{SE}&=4.0\%,\ 2.0\%,\ 4.0\%,\\ \frac{d(d+1)}{2}&=6,\ 36,\ 125{,}250,\\ d&=3,\ 8,\ 500. \end{aligned} \]

ความผันผวนรายเดือนคือรายปีหารด้วย $\sqrt{12}$ จึงได้บรรทัดแรก ห้าปีของข้อมูลบอกค่าเฉลี่ยได้แค่บวกลบ 4 จุด ทั้งที่ค่าเฉลี่ยเองมีขนาดแค่ 2 ถึง 6% สิ่งที่ประมาณได้จึงเกือบเป็นเสียงรบกวนล้วน การเพิ่มความถี่ของข้อมูลไม่ช่วย เพราะ SE ขึ้นกับความยาวของช่วง ไม่ใช่จำนวนจุด

covariance ต่างออกไป: มันเฉลี่ยกำลังสองของการขยับ ข้อมูลที่ถี่ขึ้นช่วยได้ แต่จำนวนตัวที่ต้องประมาณโตเป็นกำลังสอง หุ้น 500 ตัวมี 125,250 ตัว ขณะที่ข้อมูลรายวันหนึ่งปี (250 วันทำการ) มีแค่ $250\times500=125{,}000$ ตัวเลข

ขั้นที่ 3 — ไฟล์ Assignment 2: พอร์ตจากค่าที่ประมาณ วัดด้วยค่าจริง

โจทย์ให้อะไรมาบ้าง: แผ่นที่สองของไฟล์คิดค่าเฉลี่ยต่อปี (AVERAGE คูณ 12) และ covariance ต่อปีจาก 60 เดือน แผ่นแรกให้ค่าจริง $\mu=(6,\ 2,\ 4)\%$ และ $V$ ของ Assignment 1 (17.3 ขั้นที่ 8) เงินสด 1% หาพอร์ต tangency จากค่าที่ประมาณ แล้ววัดด้วยค่าจริง

\[ \begin{aligned} \hat\mu&=(-0.52\%,\ 4.71\%,\ -0.70\%),\\ \hat V&=10^{-4}\begin{bmatrix}56&-20&37\\-20&22&-22\\37&-22&74\end{bmatrix},\\ \hat w&=\frac{\hat V^{-1}(\hat\mu-0.01\mathbf1)}{\mathbf1^{\mathsf T}\hat V^{-1}(\hat\mu-0.01\mathbf1)}\\ &=(0.1267,\ 0.7826,\ 0.0907),\\ \text{promised}&:\ \mathrm{SR}=0.864,\\ \text{delivered}&:\ \frac{2.688-1}{2.882}=0.586,\\ \text{best}&:\ 0.851. \end{aligned} \]

คำตอบ: covariance ที่ประมาณใกล้ของจริงพอควร (0.0056 เทียบ 0.008 และ −0.0020 เทียบ −0.002) แต่ค่าเฉลี่ยกลับเครื่องหมายสองตัว optimizer เทเงิน 78% ไปที่ตัวที่สองซึ่งดูดีที่สุดในข้อมูล วัดด้วยค่าจริงได้ผลตอบแทน 2.688% ความผันผวน 2.882% Sharpe 0.586 ต่ำกว่า 0.851 ของพอร์ตดีที่สุดจริง (17.3) หนึ่งในสาม

ค่าที่ประมาณของตัวแรกห่างจากค่าจริง $(-0.52-6)/4.0=-1.63$ เท่าของ SE เป็นความคลาดธรรมดาของข้อมูลห้าปี ไม่ใช่ข้อมูลเสีย

ตรวจเองใน 10 วินาที: $0.1267+0.7826+0.0907=1$ และ $(2.688-1)/2.882=0.586$

ขั้นที่ 4 — ดึงค่าเฉลี่ยเข้าหาค่าเฉลี่ยรวม

สไลด์เสนอสูตรแบบ James-Stein: ผสมค่าที่ประมาณของแต่ละตัวกับค่าเฉลี่ยของทุกตัว ด้วยน้ำหนัก $\alpha$ แล้วคิด tangency ใหม่ด้วย $\hat V$ เดิม และวัดด้วยค่าจริงเหมือนขั้นที่ 3

\[ \begin{aligned} \mu_i^{\text{sh}}&=\alpha\hat\mu_i+(1-\alpha)\bar{\hat\mu},\\ \bar{\hat\mu}&=\tfrac13\textstyle\sum_j\hat\mu_j=1.163\%,\\ \alpha=0.5&:\ \mu^{\text{sh}}=(0.32,\ 2.93,\ 0.23)\%,\\ &\quad\ \mathrm{SR}=0.615,\\ \alpha=0&:\ w=(0.2273,\ 0.6224,\ 0.1503),\\ &\quad\ \mathrm{SR}=0.834. \end{aligned} \]

ดึงครึ่งทางได้ Sharpe จริง 0.615 ดึงจนเท่ากันหมดได้ 0.834 เกือบถึง 0.851 เมื่อค่าเฉลี่ยเท่ากันทุกตัว optimizer ไม่มีอะไรให้ไล่ตาม จึงเลือกจาก covariance ล้วน ซึ่งประมาณได้ดีกว่ามาก ในไฟล์นี้การทิ้งข้อมูลค่าเฉลี่ยไปเลยชนะการเชื่อมัน

ขั้นต่อไปใช้ความคิดเดียวกันกับ covariance ซึ่งสไลด์เขียนเป็น $\alpha\hat V+(1-\alpha)mI$ ตรงกับ $\delta=1-\alpha$ ของหน้านี้

ขั้นที่ 5 — ผสม covariance กับ $mI$: eigenvector เดิม eigenvalue ถูกดึงเข้าหากัน

นิยามการผสม: $\widehat\Sigma_\delta=(1-\delta)S+\delta mI$ โดย $m$ คือค่าเฉลี่ยของ variance ทุกตัว target นี้ให้ variance เท่ากันและ covariance เป็นศูนย์ ถามว่าการผสมทำอะไรกับทิศและขนาดของ $S$ (17.4)

\[ \begin{aligned} Sq_i&=\lambda_iq_i,\\ \widehat\Sigma_\delta q_i&=(1-\delta)\lambda_iq_i+\delta m\,q_i,\\ \widehat\lambda_i&=(1-\delta)\lambda_i+\delta m,\\ \kappa(\widehat\Sigma_\delta)&=\frac{(1-\delta)\lambda_{\max}+\delta m}{(1-\delta)\lambda_{\min}+\delta m}. \end{aligned} \]

จังหวะสำคัญคือบรรทัดที่สอง: $Iq_i=q_i$ ทุกทิศ identity จึงไม่หมุนอะไรเลย ทิศเดิมยังเป็น eigenvector ค่าที่เปลี่ยนคือ eigenvalue ซึ่งถูกดึงเข้าหา $m$ เป็นเส้นตรง

ผลที่ตามมา: eigenvalue ที่เล็กมากถูกยกขึ้นมากเมื่อเทียบกับตัวเอง ตัวที่ใหญ่ถูกกดลงนิดเดียวเมื่อเทียบกับตัวเอง condition number จึงลดลง และถ้า $\delta\gt0$ ทุก eigenvalue เป็นบวก แม้ $S$ เดิมกลับด้านไม่ได้

ขั้นที่ 6 — สองสินทรัพย์ที่เกือบเป็นตัวเดียวกัน

ตัวอย่างรายปี: ความผันผวน 20% และ 10% covariance 0.019 คือ correlation $0.019/(0.20\times0.10)=0.95$ หาพอร์ตเสี่ยงต่ำสุดด้วยสูตรของ 17.3 ขั้นที่ 3 แล้วดู eigenvalue ด้วย trace และ determinant ของ matrix 2×2

\[ \begin{aligned} S&=\begin{bmatrix}0.04&0.019\\0.019&0.01\end{bmatrix},\\ w_1&=\frac{0.01-0.019}{0.04+0.01-2(0.019)}=\frac{-0.009}{0.012}=-0.75,\\ \lambda&=\frac{0.05\pm\sqrt{0.05^2-4(0.000039)}}{2}=\frac{0.05\pm0.048415}{2},\\ \lambda&=0.049207,\ 0.000793,\quad\kappa=62.1,\\ \frac{1}{\lambda}&=20.3,\ 1{,}261.7. \end{aligned} \]

พอร์ตเสี่ยงต่ำสุดสั่ง short ตัวแรก 75% และถือตัวที่สอง 175% เพราะสองตัวเกือบเป็นตัวเดียวกัน matrix จึงมีทิศ “ถือตัวหนึ่ง short อีกตัว” ที่ variance วัดได้แค่ 0.000793 (ความผันผวน 2.8% ต่อปี) determinant คือ $0.04(0.01)-0.019^2=0.000039$

การกลับ matrix เอา 1 หารด้วย eigenvalue ทิศนั้นจึงถูกขยาย 1,262 เท่า เทียบกับ 20 เท่าของอีกทิศ optimizer เห็นโอกาสลดความเสี่ยงมหาศาลในทิศนั้น ทั้งที่ 0.000793 คือตัวเลขที่ข้อมูลจำกัดวัดได้แย่ที่สุด

ขั้นที่ 7 — ผสมครึ่งหนึ่งแล้วคิดใหม่

โจทย์ให้อะไรมาบ้าง: $S$ ของขั้นที่ 6 $m=(0.04+0.01)/2=0.025$ และ $\delta=0.5$ (ค่าสาธิต ไม่ใช่ค่าที่ Ledoit-Wolf เลือก) ทุน \$10 ล้าน

\[ \begin{aligned} \widehat\Sigma_{0.5}&=0.5S+0.5(0.025)I=\begin{bmatrix}0.0325&0.0095\\0.0095&0.0175\end{bmatrix},\\ w_1&=\frac{0.0175-0.0095}{0.0325+0.0175-2(0.0095)}=\frac{0.0080}{0.0310}=\frac{8}{31},\\ \widehat\lambda&=0.5(0.049207)+0.0125=0.037104,\\ \widehat\lambda&=0.5(0.000793)+0.0125=0.012896,\quad\kappa=2.88. \end{aligned} \]

คำตอบ: น้ำหนักเปลี่ยนจาก −75% เป็น $8/31=25.81\%$ และตัวที่สอง 74.19% คือ \$2,580,645 กับ \$7,419,355 ไม่ต้อง short เงินรวมสองฝั่งลดจาก \$25 ล้าน (short 7.5 ถือ 17.5) เหลือ \$10 ล้าน eigenvalue เล็กถูกยกขึ้น 16 เท่า ตัวใหญ่ถูกกดลงแค่ 25% condition number จาก 62.1 เหลือ 2.88

ช่องนอกแนวทแยงหดครึ่งหนึ่งพอดี (0.019 เป็น 0.0095) เพราะ target ไม่มี covariance ช่องแนวทแยงขยับเข้าหากัน: shrinkage แตะทิศที่เชื่อไม่ได้แรงที่สุด และแตะทิศที่เชื่อได้เบาที่สุด

ตรวจเองใน 10 วินาที: $2{,}580{,}645+7{,}419{,}355=10{,}000{,}000$ และ $0.037104+0.012896=0.05$ เท่ากับ trace เดิม

ขั้นที่ 8 — Ledoit-Wolf: เลือกความเข้มจากข้อมูลเอง คิดด้วยมือสี่วัน

ควรผสมแรงแค่ไหน? ถ้า $S$ สั่นมากจากวันหนึ่งไปอีกวัน ควรดึงแรง ถ้า $S$ อยู่ไกลจาก target ต่อให้ดึงก็เบี้ยวมาก ควรดึงเบา Ledoit-Wolf วัดสองอย่างนี้ด้วยผลรวมกำลังสองของทุกช่อง (Frobenius) แล้วเอามาหารกัน ใช้ผลตอบแทนสี่วันของสองสินทรัพย์ (สมมติ หน่วย % ค่าเฉลี่ยศูนย์) $(1,2),\ (-2,-1),\ (3,1),\ (-1,-3)$

\[ \begin{aligned} S&=\frac1n\textstyle\sum_tx_tx_t^{\mathsf T}=\frac14\begin{bmatrix}15&10\\10&15\end{bmatrix}\\ &=\begin{bmatrix}3.75&2.5\\2.5&3.75\end{bmatrix},\\ m&=3.75,\quad d^2=\|S-mI\|^2=2(2.5)^2=12.5,\\ \bar b^2&=\frac1{n^2}\textstyle\sum_t\|x_tx_t^{\mathsf T}-S\|^2\\ &=\frac{8.125+8.125+35.625+35.625}{16}=5.46875,\\ \widehat\delta&=\frac{\min(\bar b^2,\ d^2)}{d^2}=\frac{5.46875}{12.5}=0.4375. \end{aligned} \]

$\bar b^2$ คือ variance ของค่าเฉลี่ยแบบ 3.3 ทำกับ matrix: แต่ละวันให้ “ตัวอย่าง” $x_tx_t^{\mathsf T}$ หนึ่งตัว ความห่างของมันจาก $S$ บอกว่าข้อมูลสั่นแค่ไหน หารด้วย $n$ ครั้งหนึ่งเป็นค่าเฉลี่ย และอีกครั้งเพราะค่าเฉลี่ยของ $n$ ตัวสั่นน้อยลง $n$ เท่า

เช่นวันที่ 3 ให้ $x_3x_3^{\mathsf T}-S$ มีช่อง 5.25, 0.5, 0.5 และ −2.75 กำลังสองรวม 35.625

$\min$ กันไม่ให้ $\widehat\delta$ เกิน 1 ข้อมูลสี่วันบอกให้ดึงเข้าหา target 43.75% covariance หดจาก 2.5 เป็น $0.5625(2.5)=1.406$ correlation จาก 0.667 เหลือ 0.375 ถ้า $d^2=0$ คือ $S$ เป็น target อยู่แล้ว ไม่มีอะไรให้ผสม ห้ามหารศูนย์

ขั้นที่ 9 — ข้อมูลที่ไม่มีโครงสร้างเลย ยังได้ eigenvalue ที่กระจาย

ทดลองในกรณีที่รู้คำตอบ: 100 สินทรัพย์อิสระกันสนิท variance 1 ทุกตัว ข้อมูล 250 วัน covariance จริงคือ $I$ ทุก eigenvalue ควรเป็น 1 ผลของ Marchenko-Pastur (ยกมา ไม่พิสูจน์ที่นี่) บอกว่าเมื่อจำนวนสินทรัพย์ $p$ กับจำนวนวัน $n$ โตไปพร้อมกัน eigenvalue ของ sample covariance กระจายอยู่ในช่วงที่ขึ้นกับ $q=p/n$ เท่านั้น

\[ \begin{aligned} q&=\frac{100}{250}=0.4,\quad\sqrt q=0.6325,\\ \lambda_{\min}&\approx(1-\sqrt q)^2=0.135,\quad\lambda_{\max}\approx(1+\sqrt q)^2=2.665,\\ \text{seed }178&:\ \lambda_{\min}=0.160,\ \lambda_{\max}=2.634,\ \bar\lambda=1.0005. \end{aligned} \]

บรรทัดสุดท้ายคือการจำลองจริงในโค้ดท้ายหน้า eigenvalue กระจายจาก 0.160 ถึง 2.634 ต่างกัน 16 เท่า ทั้งที่ความจริงไม่มีทิศไหนพิเศษเลย ค่าเฉลี่ยยังเป็น 1 เพราะ trace ประมาณได้ดี ที่คลาดคือการกระจายของมัน

โครงสร้างทั้งหมดนี้เป็นของปลอมจากข้อมูลไม่พอ และ optimizer จะทุ่มเงินไปที่ทิศที่ eigenvalue 0.16 ซึ่งดูปลอดภัยที่สุด คือทิศที่ประมาณผิดมากที่สุดพอดี การดึง eigenvalue เข้าหา 1 ในขั้นที่ 5 แก้ตรงนี้

คำถามที่ควรถามออกมาดัง ๆ

ถ้าผสมแล้วเบี้ยว ทำไมยังดีกว่า? ความคลาดรวมคือ bias กำลังสองบวก variance ของค่าประมาณ ข้อมูลน้อยเมื่อเทียบกับจำนวนตัวที่ต้องประมาณ variance ครองความคลาดรวม ยอมเบี้ยวนิดหนึ่งแลกกับ variance ที่ลดลงมากจึงคุ้ม เมื่อข้อมูลมากขึ้น $\bar b^2$ เล็กลง $\widehat\delta$ ก็ลดลงเอง

มีทางอื่นนอกจากผสมไหม? สไลด์ของคอร์สเสนอสองทาง: ใส่ข้อจำกัดน้ำหนัก เช่นห้าม short หรือจำกัดผลรวมขนาดน้ำหนักไม่เกิน 2 ซึ่งกันการถือยาวกับ short หักล้างกันก้อนใหญ่ (KKT ของ 12.6) และแบบ robust ที่ขอให้พอร์ตผ่านเป้าแม้ค่าเฉลี่ยจริงเป็นค่าที่แย่ที่สุดในวงรีความเชื่อมั่นรอบค่าที่ประมาณ

shrinkage แก้ค่าเฉลี่ยด้วยไหม? การผสม covariance ไม่แตะค่าเฉลี่ยเลย ขั้นที่ 3 แสดงว่าปัญหาใหญ่กว่าอยู่ที่ค่าเฉลี่ย 17.9 จึงเริ่มจากค่าเฉลี่ยที่ตลาดบอกเป็นนัยแทน

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

เชื่อ Sharpe ที่ optimizer สัญญา: 0.864 ที่สัญญาได้จริง 0.586 ตัวเลขที่ optimizer รายงานเป็นการดูกระจกของข้อมูลตัวเองเสมอ ต้องวัดนอกข้อมูลที่ใช้ประมาณ

ไม่บอก target: $mI$ กับ correlation เท่ากันทุกคู่ให้ matrix ต่างกันและพอร์ตต่างกัน ความเข้มจากสูตรหนึ่งใช้กับอีก target ไม่ได้

เลือก $\delta$ จากชุดทดสอบ: ไล่หา $\delta$ ที่ให้ Sharpe ทดสอบสูงสุดแล้วรายงานตัวเลขนั้น คือการใช้ชุดทดสอบเป็นชุดฝึก ผลจะดีเกินจริงแบบเดียวกับขั้นที่ 3

อ่านรูปกล่องแคบว่าแม่น: Figure 17.8f นิ่งรอบค่าที่เบี้ยว ความนิ่งไม่ใช่ความถูก

ใช้ทำอะไรบนโต๊ะจริง

แบบจำลองความเสี่ยงของพอร์ตหุ้นหลายร้อยตัวใช้ covariance ที่ผสมแล้ว หรือแบบจำลองปัจจัยของ 15.3 แทน sample covariance เสมอ เพราะจำนวนตัวที่ต้องประมาณเกินข้อมูล optimizer ของ desk ใส่ข้อจำกัดน้ำหนักเสมอ และใช้ค่าเฉลี่ยที่ดึงเข้าหาจุดอ้างอิงแทนค่าเฉลี่ยย้อนหลังดิบ

function num(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(`${name} must be a finite number`);
  return x;
}
const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);
const times = (M, v) => M.map(r => dot(r, v));
function solve(S, b) {                                    // Gaussian elimination with partial pivoting
  const n = S.length, M = S.map((r, i) => [...r, b[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (Math.abs(M[r][c]) > Math.abs(M[p][c])) p = r;
    if (Math.abs(M[p][c]) < 1e-15) throw new RangeError('matrix is singular');
    [M[c], M[p]] = [M[p], M[c]];
    for (let r = c + 1; r < n; r++) { const f = M[r][c] / M[c][c]; for (let k = c; k <= n; k++) M[r][k] -= f * M[c][k]; }
  }
  const x = new Array(n).fill(0);
  for (let r = n - 1; r >= 0; r--) x[r] = (M[r][n] - dot(M[r].slice(r + 1, n), x.slice(r + 1))) / M[r][r];
  return x;
}
const tangency = (mu, V, rf) => { const u = solve(V, mu.map(m => m - rf)), s = u.reduce((a, b) => a + b, 0); return u.map(x => x / s); };
const sharpe = (w, mu, V, rf) => (dot(w, mu) - rf) / Math.sqrt(dot(w, times(V, w)));
const minVarFirst = C => { const u = solve(C, C.map(() => 1)); return u[0] / u.reduce((a, b) => a + b, 0); };
// Blend with the scaled identity: (1 - delta) S + delta m I with m the average of the diagonal.
function shrink(S, delta) {
  if (!(num('delta', delta) >= 0 && delta <= 1)) throw new RangeError('delta must be in [0, 1]');
  const m = S.reduce((a, r, i) => a + r[i], 0) / S.length;
  return S.map((r, i) => r.map((x, j) => (1 - delta) * x + (i === j ? delta * m : 0)));
}
// Ledoit-Wolf intensity for the scaled-identity target with zero-mean data rows x_t.
function ledoitWolf(X) {
  if (!Array.isArray(X) || X.length < 2) throw new TypeError('need at least two observations');
  const n = X.length, p = X[0].length;
  const S = Array.from({length: p}, (_, i) => Array.from({length: p}, (_, j) => X.reduce((a, x) => a + x[i] * x[j], 0) / n));
  const m = S.reduce((a, r, i) => a + r[i], 0) / p;
  let d2 = 0, b2 = 0;
  for (let i = 0; i < p; i++) for (let j = 0; j < p; j++) d2 += (S[i][j] - (i === j ? m : 0)) ** 2;
  for (const x of X) for (let i = 0; i < p; i++) for (let j = 0; j < p; j++) b2 += (x[i] * x[j] - S[i][j]) ** 2;
  b2 /= n * n;
  return {S, m, d2, b2, delta: d2 === 0 ? 1 : Math.min(b2, d2) / d2};
}
// Eigenvalues of a symmetric matrix by Jacobi rotations.
function eigenvalues(S) {
  const n = S.length, A = S.map(r => [...r]);
  for (let sweep = 0; sweep < 60; sweep++) {
    let off = 0;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) off += A[p][q] ** 2;
    if (off < 1e-26) break;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) {
      if (Math.abs(A[p][q]) < 1e-300) continue;
      const theta = (A[q][q] - A[p][p]) / (2 * A[p][q]);
      const t = Math.sign(theta || 1) / (Math.abs(theta) + Math.sqrt(theta * theta + 1)), c = 1 / Math.sqrt(t * t + 1), s = t * c;
      for (let k = 0; k < n; k++) { const kp = A[k][p], kq = A[k][q]; A[k][p] = c * kp - s * kq; A[k][q] = s * kp + c * kq; }
      for (let k = 0; k < n; k++) { const pk = A[p][k], qk = A[q][k]; A[p][k] = c * pk - s * qk; A[q][k] = s * pk + c * qk; }
    }
  }
  return A.map((r, i) => r[i]).sort((a, b) => b - a);
}
function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}

  • optimizer เลือกข้างที่ความคลาดเป็นบวกเสมอ: พอร์ตสัญญา 0.864 ได้จริง 0.586 ขณะที่ทำได้ 0.851
  • ค่าเฉลี่ยห้าปีคลาดได้ ±4 จุด ($\sigma/\sqrt5$) ดึงค่าเฉลี่ยให้เท่ากันหมดได้ Sharpe จริง 0.834
  • ผสมกับ $mI$ ไม่เปลี่ยน eigenvector แต่ดึง eigenvalue เข้าหา $m$: สองสินทรัพย์ correlation 0.95 condition number จาก 62.1 เหลือ 2.88 น้ำหนักจาก −75% เป็น 25.81%
  • Ledoit-Wolf เลือก $\delta=\min(\bar b^2,d^2)/d^2$: ข้อมูลสี่วันให้ 0.4375
  • ข้อมูลที่ไม่มีโครงสร้างเลยยังให้ eigenvalue 0.16 ถึง 2.63 (Marchenko-Pastur 0.135 ถึง 2.665) และการผสมแลก variance กับ bias ไม่ได้ให้ความจริงฟรี
