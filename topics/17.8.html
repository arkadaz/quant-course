17.8 Covariance Shrinkage (Ledoit-Wolf)

ค่าเฉลี่ยและ covariance ที่ประมาณจากข้อมูลมีเสียงรบกวน และ optimizer ทุ่มเงินไปที่เสียงนั้น shrinkage ดึงค่าประมาณเข้าหาเป้าหมายที่เรียบง่าย ยอมเบี้ยวนิดหนึ่งเพื่อแลกกับการแกว่งที่ลดลงมาก

ข้อมูลผลตอบแทนรายเดือน 60 เดือนของสามสินทรัพย์ เมื่อเอาค่าเฉลี่ยและ covariance ที่ประมาณได้ไปหาพอร์ต tangency จะได้ Sharpe 0.864 ตามตัวเลขที่ประมาณ แต่โจทย์นี้เป็นโลกสมมติที่เรารู้พารามิเตอร์ที่ใช้สร้างข้อมูล: ค่าเฉลี่ย 6%, 2% และ 4% ต่อปี กับ covariance ที่รู้ค่า พอร์ตเดิมได้ Sharpe เท่าไรเมื่อวัดด้วยพารามิเตอร์ชุดนั้น และทำอะไรได้บ้างให้ดีขึ้น?

ลองตอบก่อนเปิดเฉลย

ได้ 0.586 ขณะที่พอร์ตที่ดีที่สุดภายใต้พารามิเตอร์ชุดนั้นได้ 0.851 optimizer ให้น้ำหนัก 78% กับสินทรัพย์ที่สองซึ่งค่าเฉลี่ยถูกประมาณเป็น 4.71% ทั้งที่ค่าจริงคือ 2% ถ้าดึงค่าเฉลี่ยที่ประมาณทั้งสามให้เท่ากันก่อนคำนวณ Sharpe ที่วัดด้วยพารามิเตอร์ชุดนั้นขึ้นเป็น 0.834 การทิ้งข้อมูลค่าเฉลี่ยไปเลยชนะการเชื่อมัน

ภาพรวมก่อนลงสูตร

น้ำหนักของ Markowitz มาจาก $\Sigma^{-1}(\mu-r_f\mathbf 1)$ ทั้ง $\mu$ และ $\Sigma$ เป็นค่าที่ประมาณจากข้อมูล ปัญหามีสองชั้น ชั้นแรก ค่าเฉลี่ยประมาณได้หยาบมาก ชั้นที่สอง inverse ของ covariance หารด้วย eigenvalue ทิศที่ eigenvalue เล็กจึงถูกขยาย และ eigenvalue เล็กคือตัวที่ประมาณพลาดง่ายที่สุด optimizer จึงทุ่มเงินไปที่ความคลาดพอดี จนมีคนเรียกมันว่า error maximizer

ทางแก้ชื่อ shrinkage: ผสมค่าที่ประมาณได้กับเป้าหมายที่เรียบง่าย รูปด้านล่างคือทั้งเรื่องในภาพเดียว ข้อมูลจำลอง 100 สินทรัพย์ที่อิสระกันสนิท ความผันผวนเท่ากัน 250 วัน ความจริงคือ eigenvalue ทุกตัวเท่ากับ 1 แต่ sample covariance ให้ eigenvalue กระจายตั้งแต่ 0.16 ถึง 2.63 ทั้งหมดเป็นของปลอมจากข้อมูลไม่พอ การผสมครึ่งหนึ่งดึงทุกตัวเข้าหา 1 ครึ่งทาง และสูตรของ Ledoit–Wolf ซึ่งเลือกความเข้มจากข้อมูลเอง ดึงไปเกือบสุดทาง

หน้านี้จะเริ่มจากเหตุที่ optimizer ขยายความคลาด วัดว่าค่าเฉลี่ยคลาดได้แค่ไหน ดูผลกับข้อมูล 60 เดือน แล้วผสมค่าเฉลี่ยก่อน จากนั้นจึงผสม covariance ดูว่ามันทำอะไรกับ eigenvalue และน้ำหนัก คิดความเข้มของ Ledoit–Wolf ด้วยมือ ดูว่าเสียงรบกวนล้วนสร้าง eigenvalue ปลอมได้แค่ไหน และจบที่วิธีตรวจว่าการผสมช่วยจริงหรือทำให้แย่ลง

ขั้นที่ 1 — สองสินทรัพย์ที่เหมือนกันทุกอย่าง แต่ค่าประมาณไม่เหมือน

เริ่มจากการทดลองในความคิดที่เล็กที่สุด สองสินทรัพย์มีค่าเฉลี่ยจริง 5% ความผันผวน 20% เท่ากัน ไม่สัมพันธ์กัน เงินสดให้ 1% ค่าที่ประมาณได้ของตัวแรกสูงไป 1 จุด ตัวที่สองต่ำไป 1 จุด ความคลาดเฉลี่ยเป็นศูนย์ ฟังดูเหมือนค่าประมาณที่ดี เมื่อ covariance เป็น $0.04I$ ทิศของพอร์ต tangency คือผลตอบแทนส่วนเกินตรง ๆ

\[ \begin{aligned} \hat\mu&=(6\%,\ 4\%),\quad\mu=(5\%,\ 5\%),\\ \hat\mu-r_f\mathbf1&=(5\%,\ 3\%),\\ w&=(0.625,\ 0.375),\\ \sigma_p&=0.20\sqrt{0.625^2+0.375^2}\\ &\approx14.58\%,\\ \mathrm{SR}_{\text{est}}&=\frac{0.0525-0.01}{0.1458}\approx0.2915,\\ \mathrm{SR}_{\text{true}}&=\frac{0.05-0.01}{0.1458}\approx0.2744,\\ \mathrm{SR}_{\text{best}}&=\frac{0.04}{0.20/\sqrt2}\approx0.2828. \end{aligned} \]

ความจริงคือแบ่งครึ่ง แต่ค่าประมาณสั่งให้ถือตัวแรกมากกว่า ($5/(5+3)=62.5\%$) ซึ่งเป็นตัวที่ถูกประมาณสูงไปพอดี พอร์ตนี้ “สัญญา” Sharpe 0.2915 แต่ให้จริง 0.2744 ต่ำกว่าการแบ่งครึ่งที่ไม่ต้องรู้อะไรเลย

ความคลาดของสองตัวเฉลี่ยกันได้ศูนย์ แต่ในพอร์ตไม่หักล้างกัน เพราะ optimizer ให้น้ำหนักมากกับตัวที่ดูดีเกินจริง และน้ำหนักน้อยกับตัวที่ดูแย่เกินจริง ความคลาดจึงถูกเลือกเข้าพอร์ตอย่างเป็นระบบ ยิ่งยอมให้ short ได้มาก ยิ่งไล่ความคลาดได้มาก

ขั้นที่ 2 — ค่าเฉลี่ยประมาณยากกว่า covariance มาก

ค่าเฉลี่ยรายปีจาก 60 เดือนคือ 12 เท่าของค่าเฉลี่ยรายเดือน และค่าเฉลี่ยของ 60 ตัวมี standard error เป็นความผันผวนหารด้วย $\sqrt{60}$ ใช้ความผันผวนจริงจากแนวทแยงของ $V$ ในโลกสมมติ (0.008, 0.002 และ 0.008 ต่อปี)

\[ \begin{aligned} \mathrm{SE}(\hat\mu_{\text{ann}})&=\frac{12\,\sigma_{\text{mon}}}{\sqrt{60}}=\frac{\sqrt{12}\,\sigma_{\text{ann}}}{\sqrt{60}}\\ &=\frac{\sigma_{\text{ann}}}{\sqrt5},\\ \sigma_{\text{ann}}&=8.94\%,\ 4.47\%,\ 8.94\%,\\ \mathrm{SE}&=4.0\%,\ 2.0\%,\ 4.0\%,\\ \frac{d(d+1)}{2}&=6,\ 36,\ 125{,}250\\ \text{for}\ d&=3,\ 8,\ 500. \end{aligned} \]

บรรทัดแรกใช้ $\sigma_{\text{mon}}=\sigma_{\text{ann}}/\sqrt{12}$ ซึ่งถูกเมื่อผลตอบแทนรายเดือนอิสระกัน ข้อมูลห้าปีจึงให้ SE ของค่าเฉลี่ย 4, 2 และ 4 จุดเปอร์เซ็นต์ ใหญ่พอจะสลับลำดับว่าตัวไหนน่าลงทุนที่สุด และ SE ขึ้นกับจำนวนปี ไม่ใช่จำนวนจุดข้อมูล การแบ่งห้าปีเป็นรายวันไม่ช่วยค่าเฉลี่ยเลย แต่ช่วย covariance ได้มาก นี่คือเหตุที่ covariance ประมาณได้ดีกว่าค่าเฉลี่ยมาก

แต่ covariance ก็มีปัญหาของมัน: หุ้น 500 ตัวมีสมาชิกที่ไม่ซ้ำกัน 125,250 ค่า ถ้ามีข้อมูลแค่ 250 วัน sample covariance หลังหักค่าเฉลี่ยมี rank ไม่เกิน 249 (rank ของผลรวมของ 250 matrix ที่ rank หนึ่ง ลบไปหนึ่งจากการหักค่าเฉลี่ย) จึงมี eigenvalue เป็นศูนย์อย่างน้อย 251 ตัว และกลับ matrix ไม่ได้เลย

ขั้นที่ 3 — 60 เดือนจริงจัง: พอร์ตจากค่าที่ประมาณ วัดด้วยพารามิเตอร์ของโลกสมมติ

โจทย์ให้อะไรมาบ้าง: ข้อมูล 60 เดือนชุดเดียวกับที่ใช้ตรวจ VaR ในVaR backtesting ค่าเฉลี่ยต่อปี (ค่าเฉลี่ยรายเดือนคูณ 12) และ covariance ต่อปีที่ประมาณได้อยู่ด้านล่าง โลกสมมติมี $\mu=(6,\ 2,\ 4)\%$ เงินสด 1% หาพอร์ต tangency จากค่าที่ประมาณ แล้ววัดด้วยพารามิเตอร์ของโลกสมมติ

\[ \begin{aligned} \hat\mu&=(-0.52\%,\ 4.71\%,\\ &\qquad-0.70\%),\\ \hat V&=10^{-4}\begin{bmatrix}56&-20&37\\-20&22&-22\\37&-22&74\end{bmatrix},\\ \hat w&\propto\hat V^{-1}(\hat\mu-0.01\mathbf1),\\ \hat w&=(0.1267,\ 0.7826,\ 0.0907),\\ \mathrm{SR}_{\text{est}}&\approx0.864,\\ \mathrm{SR}_{\text{true}}&\approx\frac{2.688-1}{2.882}\approx0.586,\\ \mathrm{SR}_{\text{best}}&\approx0.851,\\ \frac{0.586}{0.851}&\approx0.688. \end{aligned} \]

คำตอบ: covariance ที่ประมาณใกล้ของจริงพอควร (0.0056 เทียบ 0.008 และ −0.0020 เทียบ −0.002) แต่ค่าเฉลี่ยกลับเครื่องหมายไปสองตัว optimizer เทเงิน 78% ไปที่ตัวที่สองซึ่งดูดีที่สุดในข้อมูล วัดด้วยพารามิเตอร์ของโลกสมมติได้ผลตอบแทน 2.688% ความผันผวน 2.882% Sharpe 0.586 ได้แค่ 68.8% ของ 0.851 ที่ทำได้ดีที่สุด สัดส่วนนี้เรียกว่า Sharpe ratio efficiency และไม่มีวันเกิน 1 (เป็นผลของ Cauchy–Schwarz: พอร์ตที่ดีที่สุดคือพอร์ตที่ใช้พารามิเตอร์จริงเท่านั้น)

ค่าประมาณของตัวแรกห่างจากค่าจริง $(-0.52-6)/4.0\approx-1.63$ เท่าของ SE ความต่างระดับนี้เกิดจากการสุ่มได้ตามปกติ ข้อมูลไม่ได้ “เสีย” ข้อมูลแค่ไม่พอ

ตรวจเองใน 10 วินาที: $0.1267+0.7826+0.0907=1$ และ $(2.688-1)/2.882\approx0.586$

ขั้นที่ 4 — ดึงค่าเฉลี่ยเข้าหาค่าเฉลี่ยรวม

ค่าเฉลี่ยคลาดมากที่สุด จึงแก้ที่ค่าเฉลี่ยก่อน วิธีแบบ James–Stein: ผสมค่าที่ประมาณของแต่ละตัวกับค่าเฉลี่ยของทุกตัว ด้วยน้ำหนัก $\alpha$ แล้วคิด tangency ใหม่ด้วย $\hat V$ เดิม และวัดด้วยพารามิเตอร์ของโลกสมมติเหมือนขั้นที่ผ่านมา

\[ \begin{aligned} \mu_i^{\text{sh}}&=\alpha\hat\mu_i+(1-\alpha)\bar{\hat\mu},\\ \bar{\hat\mu}&=\tfrac13\textstyle\sum_j\hat\mu_j\approx1.163\%,\\ \alpha=1&:\ \mathrm{SR}_{\text{true}}\approx0.586,\\ \alpha=0.5&:\ \mathrm{SR}_{\text{true}}\approx0.615,\\ \alpha=0.25&:\ \mathrm{SR}_{\text{true}}\approx0.660,\\ \alpha=0&:\ w\approx(0.227,\ 0.622,\ 0.150),\\ &\quad\ \mathrm{SR}_{\text{true}}\approx0.834. \end{aligned} \]

ดึงครึ่งทางช่วยนิดเดียว ดึงจนเท่ากันหมดได้ 0.834 เกือบถึง 0.851 เมื่อค่าเฉลี่ยเท่ากันทุกตัว optimizer ไม่มีอะไรให้ไล่ตาม จึงเลือกจาก covariance ล้วน ซึ่งประมาณได้ดีกว่ามาก น้ำหนัก $(0.227,\ 0.622,\ 0.150)$ ใกล้พอร์ตที่ดีที่สุดจริง $(0.292,\ 0.583,\ 0.125)$ ในโลกสมมตินี้ การทิ้งข้อมูลค่าเฉลี่ยไปเลยชนะการเชื่อมัน

ทำไมการดึงเข้าหาจุดร่วมจึงช่วยได้ทั้งที่จุดร่วมผิด? Charles Stein แสดงว่าเมื่อประมาณค่าเฉลี่ยของข้อมูล Normal ตั้งแต่สามตัวขึ้นไปพร้อมกัน การดึงทุกตัวเข้าหาจุดร่วมด้วยความแรงที่คำนวณจากข้อมูล ให้ความคลาดกำลังสองรวมต่ำกว่าการใช้ค่าเฉลี่ยของแต่ละตัวตรง ๆ ไม่ว่าค่าจริงจะเป็นเท่าไร (ถ้าจุดร่วมคือค่าเฉลี่ยรวมที่คำนวณจากข้อมูลเอง ต้องมีตั้งแต่สี่ตัว) ความคิดเดียวกันนี้คือสิ่งที่ขั้นต่อไปทำกับ covariance

ขั้นที่ 5 — ทำไม inverse ขยายความคลาด: สองสินทรัพย์ที่เกือบเป็นตัวเดียวกัน

optimizer ใช้ inverse ของ covariance และ inverse ทำงานผ่าน eigenvalue: เขียน matrix เป็นผลรวมของทิศ $q_i$ ที่มีขนาด $\lambda_i$ แล้ว inverse คือผลรวมเดิมที่ขนาดกลับเป็น $1/\lambda_i$ ลองกับตัวอย่างรายปี: ความผันผวน 20% และ 10% covariance 0.019 คือ correlation $0.019/(0.20\times0.10)=0.95$

\[ \begin{aligned} S&=\textstyle\sum_i\lambda_i\,q_iq_i^{\mathsf T},\\ S^{-1}&=\textstyle\sum_i\frac{1}{\lambda_i}\,q_iq_i^{\mathsf T},\\ S&=\begin{bmatrix}0.04&0.019\\0.019&0.01\end{bmatrix},\\ \lambda&=\frac{0.05\pm\sqrt{0.05^2-4(0.000039)}}{2}\\ &\approx0.049207,\ 0.000793,\\ \frac{1}{\lambda}&\approx20.3,\ 1{,}261.7,\quad\kappa\approx62.1,\\ w_1^{\min}&=\frac{0.01-0.019}{0.04+0.01-2(0.019)}\\ &=\frac{-0.009}{0.012}=-0.75. \end{aligned} \]

eigenvalue ของ matrix 2×2 ได้จาก trace (0.05) กับ determinant ($0.04\times0.01-0.019^2=0.000039$) สองตัวต่างกัน 62 เท่า ทิศใหญ่คือ “ถือทั้งคู่” ซึ่งแกว่งมาก ทิศเล็กคือ “ถือตัวหนึ่ง short อีกตัว” ซึ่ง variance วัดได้แค่ 0.000793 (ความผันผวน 2.8% ต่อปี) inverse คูณทิศเล็กด้วย 1,262 แต่ทิศใหญ่แค่ 20 ถ้า eigenvalue เล็กคลาดไปนิดเดียว ผลต่อน้ำหนักจะถูกขยายมาก ความเสียหายจากค่าเฉลี่ยที่คลาดก็ถูกขยายด้วยตัวคูณระดับเดียวกับ condition number

บรรทัดสุดท้ายคือพอร์ตเสี่ยงต่ำสุดของสองสินทรัพย์ (ตั้งอนุพันธ์ของ variance เทียบ $w_1$ ให้เป็นศูนย์ แบบในMarkowitz portfolio theory) มันสั่ง short ตัวแรก 75% และถือตัวที่สอง 175% คือเดิมพันเต็มที่กับทิศเล็กที่ดูปลอดภัยที่สุด

ขั้นที่ 6 — ผสม covariance กับ $mI$: ทิศเดิม ขนาดถูกดึงเข้าหากัน

นิยามการผสม: $\widehat\Sigma_\delta=(1-\delta)S+\delta mI$ โดย $m$ คือค่าเฉลี่ยของ variance ทุกตัว เป้าหมายนี้บอกว่าทุกตัวแกว่งเท่ากันและไม่สัมพันธ์กัน ถามว่าการผสมทำอะไรกับทิศและขนาดของ $S$ แล้วลองผสมครึ่งหนึ่งกับตัวอย่างที่เพิ่งคิด ($m=(0.04+0.01)/2=0.025$)

\[ \begin{aligned} \widehat\Sigma_\delta q_i&=(1-\delta)\lambda_iq_i+\delta m\,q_i,\\ \widehat\lambda_i&=(1-\delta)\lambda_i+\delta m,\\ \widehat\Sigma_{0.5}&=\begin{bmatrix}0.0325&0.0095\\0.0095&0.0175\end{bmatrix},\\ \widehat\lambda&\approx0.037104,\ 0.012896,\\ \kappa&\approx2.88,\\ w_1&=\frac{0.0175-0.0095}{0.0325+0.0175-0.019}\\ &=\frac{0.008}{0.031}\approx25.81\%. \end{aligned} \]

จังหวะสำคัญคือบรรทัดแรก: $Iq_i=q_i$ ทุกทิศ identity จึงไม่หมุนอะไรเลย ทิศเดิมยังเป็น eigenvector ค่าที่เปลี่ยนคือ eigenvalue ซึ่งถูกดึงเข้าหา $m$ เป็นเส้นตรง ตัวเล็กถูกยกขึ้น 16 เท่า ตัวใหญ่ถูกกดลงแค่ 25% condition number จาก 62.1 เหลือ 2.88 และเมื่อ $\delta\gt0$ ทุก eigenvalue เป็นบวก matrix ที่เคยกลับไม่ได้ก็กลับได้

น้ำหนักเปลี่ยนจาก −75% เป็น 25.81% และตัวที่สอง 74.19% ไม่ต้อง short เงินรวมสองฝั่งของทุน \$10 ล้านลดจาก \$25 ล้าน (short 7.5 ถือ 17.5) เหลือ \$10 ล้าน ช่องนอกแนวทแยงหดครึ่งหนึ่งพอดี (0.019 เป็น 0.0095) เพราะเป้าหมายไม่มี covariance

อีกมุมหนึ่งของสูตรเดียวกัน: $(1-\delta)S+\delta mI=(1-\delta)(S+kI)$ เมื่อ $k=\delta m/(1-\delta)=0.025$ การหาพอร์ตเสี่ยงต่ำสุดด้วย $S+kI$ คือการลด $w^{\mathsf T}Sw+k\,w^{\mathsf T}w$ คือลงโทษน้ำหนักที่ใหญ่ หรือมองว่าแต่ละสินทรัพย์มีความไม่แน่นอนอิสระเพิ่มอีก variance $k$ ที่ข้อมูลไม่เห็น การผสมกับ identity จึงเป็นทั้งการแก้ค่าประมาณและการเผื่อความไม่รู้ในตัว

ขั้นที่ 7 — Ledoit–Wolf: เลือกความเข้มจากข้อมูลเอง คิดด้วยมือสี่วัน

ควรผสมแรงแค่ไหน? ความคิดของ Ledoit กับ Wolf: ผสมแรงเมื่อ $S$ สั่นมากเทียบกับระยะที่มันห่างจากเป้าหมาย และผสมเบาเมื่อ $S$ นิ่งและห่างเป้าหมายมาก (คือข้อมูลมีโครงสร้างจริงที่เป้าหมายไม่มี) ทั้งสองขนาดวัดด้วยผลรวมกำลังสองของทุกช่อง ลองกับผลตอบแทนสมมติสี่วัน หน่วย %: $(1,2),\ (-2,-1),\ (3,1),\ (-1,-3)$ โดยสมมติว่ารู้ว่าค่าเฉลี่ยจริงเป็นศูนย์

\[ \begin{aligned} S&=\frac1n\textstyle\sum_tx_tx_t^{\mathsf T}=\frac14\begin{bmatrix}15&10\\10&15\end{bmatrix}\\ &=\begin{bmatrix}3.75&2.5\\2.5&3.75\end{bmatrix},\quad m=3.75,\\ d^2&=\|S-mI\|^2=2(2.5)^2=12.5,\\ \bar b^2&=\frac1{n^2}\textstyle\sum_t\|x_tx_t^{\mathsf T}-S\|^2\\ &=\frac{2(8.125)+2(35.625)}{16}\\ &=5.46875,\\ \widehat\delta&=\frac{\min(\bar b^2,\ d^2)}{d^2}=\frac{5.46875}{12.5}\\ &=0.4375. \end{aligned} \]

$\bar b^2$ คือ variance ของค่าเฉลี่ยแบบเดียวกับ standard error ของค่าเฉลี่ย แต่ทำกับ matrix: แต่ละวันให้ “ตัวอย่าง” $x_tx_t^{\mathsf T}$ หนึ่งตัว ความห่างของมันจาก $S$ บอกว่าข้อมูลสั่นแค่ไหน หารด้วย $n$ ครั้งหนึ่งเพื่อเป็นค่าเฉลี่ย และอีกครั้งเพราะค่าเฉลี่ยของ $n$ ตัวสั่นน้อยลง $n$ เท่า ตัวอย่าง: วันที่ 3 ให้ $x_3x_3^{\mathsf T}=[9,3;3,1]$ ลบ $S$ ได้ช่อง 5.25, 0.5, 0.5 และ −2.75 กำลังสองรวม 35.625

ข้อมูลสี่วันบอกให้ดึงเข้าหาเป้าหมาย 43.75% covariance หดจาก 2.5 เป็น $0.5625(2.5)\approx1.406$ correlation จาก 0.667 เหลือ 0.375 $\min$ กันไม่ให้ $\widehat\delta$ เกิน 1 และถ้า $d^2=0$ คือ $S$ เป็นเป้าหมายอยู่แล้ว ไม่มีอะไรให้ผสม ห้ามหารศูนย์ ในเชิงเรขาคณิต สูตรนี้หาจุดบนเส้นตรงระหว่าง $S$ กับ $mI$ ที่คาดว่าใกล้ covariance จริงที่สุด เมื่อวัดระยะด้วยผลรวมกำลังสองของทุกช่อง

ขั้นที่ 8 — เสียงรบกวนล้วนก็สร้าง eigenvalue กระจายได้ และปัจจัยจริงโผล่อย่างไร

กลับไปที่รูปแรก: 100 สินทรัพย์อิสระ variance 1 ข้อมูล 250 วัน covariance จริงคือ $I$ แต่ eigenvalue ที่เห็นกระจาย ทฤษฎี Marchenko–Pastur (ยกผลมา ไม่พิสูจน์ที่นี่) บอกว่าเมื่อจำนวนสินทรัพย์ $p$ กับจำนวนวัน $n$ โตไปพร้อมกัน ช่วงที่ eigenvalue จากเสียงล้วนกระจายขึ้นกับ $\gamma=p/n$ เท่านั้น และถ้ามีปัจจัยจริงหนึ่งตัวที่ eigenvalue จริง $\lambda$ (หน่วยเดียวกับ variance เฉพาะตัว) ทฤษฎีเดียวกันบอกว่ามันจะโผล่พ้นกองเสียงเมื่อใหญ่พอ

\[ \begin{aligned} \gamma&=\frac{100}{250}=0.4,\quad\sqrt\gamma\approx0.632,\\ \lambda_{\pm}&\approx(1\pm\sqrt\gamma)^2=0.135,\ 2.665,\\ \text{simulated}&:\ 0.160\ \text{to}\ 2.634,\\ \lambda&\gt1+\sqrt\gamma\approx1.632:\\ \hat\lambda&\approx\lambda\Big(1+\frac{\gamma}{\lambda-1}\Big),\\ \lambda=5&:\ \hat\lambda\approx5.5. \end{aligned} \]

eigenvalue กระจาย 16 เท่าทั้งที่ความจริงไม่มีทิศไหนพิเศษเลย ค่าเฉลี่ยของมันยังเป็น 1.0005 เพราะผลรวมของ eigenvalue คือ trace ซึ่งประมาณได้ดี สิ่งที่คลาดคือการกระจาย optimizer จะทุ่มเงินไปที่ทิศที่ eigenvalue 0.16 ซึ่งดูปลอดภัยที่สุด ทั้งที่เป็นทิศที่ประมาณผิดมากที่สุดพอดี สูตร Ledoit–Wolf เห็นว่า $S$ สั่นเกือบเท่ากับระยะที่ห่างจากเป้าหมาย ($\bar b^2=40.11$ เทียบ $d^2=40.79$) จึงเลือก $\delta\approx0.98$ และดึงกลับเกือบถึงความจริง

ปัจจัยจริงต่างออกไป: ถ้า $\lambda$ เกิน $1+\sqrt\gamma$ มันจะโผล่พ้นขอบบน แต่ค่าที่เห็นจะสูงเกินจริงราว $\lambda\gamma/(\lambda-1)$ เช่นปัจจัย 5 เท่าจะเห็นเป็น 5.5 ถ้าต่ำกว่าเกณฑ์ มันจะจมในกองเสียง และ eigenvector ที่เห็นแทบไม่บอกอะไรเกี่ยวกับทิศจริง ปัญหาคือเป้าหมาย $mI$ ไม่รู้จักปัจจัย มันกดปัจจัยจริงลงไปพร้อมกับเสียง (รูปด้านล่าง) นี่คือความเบี้ยวที่ยอมจ่าย และเป็นเหตุที่งานจริงมักใช้เป้าหมายที่มีปัจจัยร่วมอยู่ในตัว

ขั้นที่ 9 — ตรวจว่าผสมแล้วดีขึ้นจริงไหม: วัดความเสี่ยงจริงของพอร์ตเสี่ยงต่ำสุด

โจทย์ให้อะไรมาบ้าง: เกณฑ์ตัดสินที่ยุติธรรม: สร้างพอร์ตเสี่ยงต่ำสุดจาก matrix ที่ประมาณ แล้ววัดความเสี่ยงของพอร์ตนั้นด้วย covariance จริง พอร์ตที่สร้างจาก matrix จริงเสี่ยงต่ำสุดเสมอ matrix ไหนพาไปใกล้ค่านั้นกว่าคือ matrix ที่ดีกว่าสำหรับงานพอร์ต ลองสองโลก: โลก A คือ 100 สินทรัพย์อิสระ 250 วันของรูปแรก โลก B คือสองสินทรัพย์ correlation 0.95 ที่ใช้ดูว่า inverse ขยายความคลาด สุ่มข้อมูลชุดละ 24 วัน 2,000 ชุด (เครื่องสุ่ม seed 1788)

\[ \begin{aligned} w^{\mathsf T}\Sigma w&\ge w_{\min}^{\mathsf T}\Sigma\,w_{\min},\\ \text{A}:\ \frac{\sigma_{\text{sample}}}{\sigma_{\min}}&\approx1.24,\\ \frac{\sigma_{\text{LW}}}{\sigma_{\min}}&\approx1.00,\\ \text{promised}&:\ 0.75,\\ \text{B}:\ \sigma_{\min}&=5.70\%,\\ \sigma_{\text{sample}}&\approx5.83\%,\\ \sigma_{\text{LW}}&\approx8.31\%,\\ \sigma_{\delta=0.5}&\approx12.44\%. \end{aligned} \]

คำตอบ: ในโลก A พอร์ตจาก sample covariance เชื่อว่าความผันผวนของตัวเองเป็นแค่ 0.75 เท่าของค่าที่ดีที่สุด แต่ได้จริง 1.24 เท่า มันวางเงินในทิศที่ดูปลอดภัยเพราะเสียงรบกวน พอร์ตจาก Ledoit–Wolf ได้ 1.00 เท่า แทบเท่าพอร์ตที่รู้ความจริง ในโลก B ทุกอย่างกลับด้าน: sample ได้ 5.83% ใกล้ 5.70% ที่ดีที่สุด แต่ Ledoit–Wolf (ความเข้มเฉลี่ย 0.16) ได้ 8.31% และผสมครึ่งได้ 12.44% เพราะเป้าหมาย $mI$ บอกว่า correlation เป็นศูนย์ ทั้งที่ความจริงคือ 0.95 การผสมจึงทำลายโครงสร้างจริงที่ข้อมูลเห็นชัดอยู่แล้ว

น้ำหนักบอกเรื่องเดียวกัน: ในโลก B น้ำหนักตัวแรกจาก sample เฉลี่ย −75.1% แกว่ง ±10.9 จุด ส่วนผสมครึ่งเฉลี่ย 25.9% แกว่งแค่ ±1.2 จุด นิ่งกว่ามาก แต่นิ่งรอบค่าที่ผิด shrinkage คุ้มเมื่อ $p/n$ ใหญ่และเป้าหมายใกล้ความจริง และไม่คุ้มเมื่อข้อมูลพอแล้วและเป้าหมายลบโครงสร้างจริงทิ้ง

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ใช้ Sharpe ในชุดฝึกแทน Sharpe ข้างหน้า: พอร์ตของ 60 เดือนสัญญา 0.864 แต่ให้ 0.586 ในโลกจริงเราไม่รู้พารามิเตอร์ จึงต้องประเมินด้วยข้อมูลที่ไม่ได้ใช้เลือกพอร์ต

ไม่บอกเป้าหมาย: $mI$ กับ correlation เท่ากันทุกคู่ให้ matrix ต่างกันและพอร์ตต่างกัน ความเข้มที่คำนวณสำหรับเป้าหมายหนึ่งใช้กับอีกเป้าหมายไม่ได้

เป้าหมายลบโครงสร้างจริง: สองสินทรัพย์ correlation 0.95 ที่ผสมกับ $mI$ ได้ความเสี่ยงจริง 8.31% แทน 5.83% ของ sample ถ้าสินทรัพย์มีปัจจัยร่วมแรง ให้ใช้เป้าหมายที่เก็บปัจจัยไว้

เลือก $\delta$ จากชุดทดสอบ: ไล่หา $\delta$ ที่ให้ผลทดสอบดีที่สุดแล้วรายงานตัวเลขนั้น คือการใช้ชุดทดสอบเป็นชุดฝึก ผลจะดีเกินจริงแบบเดียวกับพอร์ต 60 เดือน

อ่านความนิ่งว่าแม่น: น้ำหนักที่ผสมครึ่งแกว่งแค่ ±1.2 จุดรอบ 25.9% ทั้งที่คำตอบจริงคือ −75% ความนิ่งไม่ใช่ความถูก

ใช้ทำอะไรบนโต๊ะจริง

เมื่อสินทรัพย์มีจำนวนมากเทียบกับข้อมูล งานจริงมักไม่ใช้ sample covariance ตรง ๆ ทางเลือกหลักคือผสมกับเป้าหมาย หรือใช้ covariance จากแบบจำลองหลายปัจจัย ซึ่งลดจำนวนค่าที่ต้องประมาณจากหลายหมื่นเหลือไม่กี่ร้อย อีกสองทางที่ใช้คู่กันได้คือใส่ข้อจำกัดน้ำหนัก เช่นห้าม short หรือให้ผลรวมขนาดน้ำหนักไม่เกิน 2 (ซึ่งกันการถือกับ short หักล้างกันก้อนใหญ่ เงื่อนไขของKKT บอกว่าข้อจำกัดเหล่านี้ทำงานเหมือนการผสม) และแบบ robust ที่ขอให้พอร์ตผ่านเป้าแม้ค่าเฉลี่ยจริงจะเป็นค่าที่แย่ที่สุดในวงรีความเชื่อมั่นรอบค่าที่ประมาณ ส่วนปัญหาที่ใหญ่กว่า คือค่าเฉลี่ย การผสม covariance ไม่ได้แตะเลย

$0.16/\sqrt{10}\approx5.06\%$ คือ SE ประมาณ 5 จุดเปอร์เซ็นต์ ข้อมูลรายวันไม่ช่วย เพราะค่าเฉลี่ยรายปีขึ้นกับราคาต้นทางกับปลายทาง SE จึงขึ้นกับจำนวนปี ไม่ใช่จำนวนจุด

3. ข้อมูลสามวันของสองสินทรัพย์ โดยสมมติว่ารู้ค่าเฉลี่ยเป็นศูนย์: $(1,1),\ (-1,-1),\ (2,-2)$ หาความเข้มของ Ledoit–Wolf

เฉลย

$S=\tfrac13[6,-2;-2,6]\approx[2,-0.667;-0.667,2]$ $m=2$ และ $d^2=2(0.667)^2\approx0.889$ ส่วน $x_tx_t^{\mathsf T}-S$ สามวันมีผลรวมกำลังสอง 7.556, 7.556 และ 30.222 รวม 45.333 หารด้วย $3^2=9$ ได้ $\bar b^2\approx5.037$ เกิน $d^2$ จึงได้ $\widehat\delta=\min(5.037,\,0.889)/0.889=1$ สามวันสั่นมากเกินจะเชื่อโครงสร้างใด ๆ สูตรจึงเลือกเป้าหมายล้วน

const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);
const times = (M, v) => M.map(r => dot(r, v));
function solve(S, b) {                                    // Gaussian elimination with partial pivoting
  const n = S.length, M = S.map((r, i) => [...r, b[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (Math.abs(M[r][c]) > Math.abs(M[p][c])) p = r;
    [M[c], M[p]] = [M[p], M[c]];
    for (let r = c + 1; r < n; r++) { const f = M[r][c] / M[c][c]; for (let k = c; k <= n; k++) M[r][k] -= f * M[c][k]; }
  }
  const x = new Array(n).fill(0);
  for (let r = n - 1; r >= 0; r--) { let s = M[r][n]; for (let k = r + 1; k < n; k++) s -= M[r][k] * x[k]; x[r] = s / M[r][r]; }
  return x;
}

// Blend with the scaled identity: (1 - delta) S + delta m I, m = average variance.
function shrink(S, delta) {
  const m = S.reduce((a, r, i) => a + r[i], 0) / S.length;
  return S.map((r, i) => r.map((x, j) => (1 - delta) * x + (i === j ? delta * m : 0)));
}
// Ledoit-Wolf intensity for the scaled-identity target, zero-mean rows x_t.
function ledoitWolf(X) {
  const n = X.length, p = X[0].length;
  const S = Array.from({length: p}, (_, i) => Array.from({length: p}, (_, j) => X.reduce((a, x) => a + x[i] * x[j], 0) / n));
  const m = S.reduce((a, r, i) => a + r[i], 0) / p;
  let d2 = 0, b2 = 0;
  for (let i = 0; i < p; i++) for (let j = 0; j < p; j++) d2 += (S[i][j] - (i === j ? m : 0)) ** 2;
  for (const x of X) for (let i = 0; i < p; i++) for (let j = 0; j < p; j++) b2 += (x[i] * x[j] - S[i][j]) ** 2;
  b2 /= n * n;
  return {S, m, d2, b2, delta: d2 === 0 ? 1 : Math.min(b2, d2) / d2};
}
function mulberry32(seed) {
  return () => { seed |= 0; seed = seed + 0x6D2B79F5 | 0; let t = Math.imul(seed ^ seed >>> 15, 1 | seed);

}

สิ่งที่ควรตอบได้หลังอ่าน

  • optimizer เลือกค่าที่บังเอิญดูดีเข้าพอร์ต: พอร์ต 60 เดือนสัญญา Sharpe 0.864 แต่ให้ 0.586 จาก 0.851 ที่ทำได้ดีที่สุด
  • ค่าเฉลี่ยรายปีจากห้าปีมี SE ราว $\sigma/\sqrt5$ (4 จุด) การดึงค่าเฉลี่ยทั้งหมดให้เท่ากันยก Sharpe ที่ได้จริงเป็น 0.834
  • inverse คูณทิศที่ eigenvalue เล็กด้วย $1/\lambda$ ผสมกับ $mI$ ไม่เปลี่ยน eigenvector แต่ดึง eigenvalue เข้าหา $m$: condition number 62.1 เหลือ 2.88 น้ำหนัก −75% เป็น 25.81%
  • Ledoit–Wolf เลือก $\delta=\min(\bar b^2,d^2)/d^2$: ข้อมูลสี่วันได้ 0.4375 เสียงล้วน 100 สินทรัพย์ได้ 0.98 และดึง eigenvalue 0.16 ถึง 2.63 กลับมาใกล้ 1
  • ตัดสินด้วยความเสี่ยงจริงของพอร์ตเสี่ยงต่ำสุด: การผสมช่วยมากเมื่อเป้าหมายใกล้ความจริง (1.24 เป็น 1.00 เท่า) และทำร้ายเมื่อเป้าหมายลบโครงสร้างจริง (5.83% เป็น 8.31%)
