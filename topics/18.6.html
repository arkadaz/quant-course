18.6 Almgren-Chriss Optimal Execution

ขายเร็ว ราคาถูกกดลงเพราะคำสั่งของเราเอง ขายช้า เสี่ยงที่ราคาจะลงเองระหว่างรอ พอรวมสองอย่างเป็นคะแนนเดียว แผนที่ดีที่สุดออกมาเป็นเส้นโค้ง sinh ซึ่งชันแค่ไหนขึ้นกับความกลัวความเสี่ยงที่โต๊ะเลือกเอง

โต๊ะเทรด (trading desk) คือทีมในธนาคารหรือกองทุนที่ส่งคำสั่งซื้อขายหุ้นแทนลูกค้า วันนี้ลูกค้าสั่งให้โต๊ะขายหุ้นตัวหนึ่ง 100,000 หุ้นให้หมดภายในห้าวัน โต๊ะขายได้วันละครั้ง จึงต้องเลือกว่าแต่ละวันจะขายกี่หุ้น

ปัญหามีสองด้าน ถ้าขายก้อนใหญ่ในวันเดียว คนที่รับซื้อในราคาดีมีไม่พอ ราคาที่ได้จึงต่ำลง ความเสียหายนี้เรียกว่า market impact แต่ถ้าเก็บหุ้นไว้ขายวันหลัง ราคาตลาดอาจลงเองระหว่างรอ เงินที่จะได้จึงไม่แน่นอน

ของที่รู้ (ตัวเลขสมมติทั้งหมด):

  • หุ้นที่ต้องขาย $X=100{,}000$ หุ้น ขายห้าครั้ง วันละครั้ง
  • ถ้าขายครั้งละ $n$ หุ้น ราคาที่ได้จะต่ำกว่าราคาตลาด $\eta n$ ดอลลาร์ต่อหุ้น โดย $\eta=10^{-5}$ เช่นขาย 20,000 หุ้น ราคาต่ำลง $10^{-5}\times20{,}000=\$0.20$ ต่อหุ้น
  • เงินที่เสียไปกับ impact ในครั้งนั้นคือราคาที่หายต่อหุ้นคูณจำนวนหุ้น $\eta n\times n=\eta n^2$ เช่น $10^{-5}\times20{,}000^2=\$4{,}000$
  • หุ้นที่ยังขายไม่ออก $x$ หุ้นต้องถือค้างไปถึงวันถัดไป และขาดทุนได้ถ้าราคาลง โต๊ะแปลงความเสี่ยงนี้เป็น “ค่าปรับ” $c\,x^2$ ดอลลาร์ทุกครั้งที่ถือค้างข้ามวัน ตลาดไม่ได้กำหนด $c$ ให้ โต๊ะเลือกเองตามว่ากลัวแค่ไหน ยิ่งกลัว $c$ ยิ่งใหญ่ (ทำไมต้องเป็น $x^2$ ขั้นบัญชีเงินที่ได้ด้านล่างจะแสดงให้ดู)
  • คะแนนของแผน $J$ คือเงินที่เสียกับ impact ทั้งห้าครั้ง บวกค่าปรับของทุกวันที่ยังถือหุ้นค้าง คะแนนยิ่งต่ำยิ่งดี

เทรดเดอร์สองคนเสนอแผนต่างกัน คนแรกขายเท่ากันวันละ 20,000 หุ้น คนที่สองเร่งขายช่วงต้น: 40,000, 30,000, 20,000, 10,000 และ 0 หุ้น

ถ้า $c=10^{-6}$ แผนไหนคะแนนต่ำกว่า และถ้าโต๊ะกลัวมากขึ้นเป็น $c=3\times10^{-6}$ ล่ะ

ลองตอบก่อนเปิดเฉลย

คะแนนของสองแผนเขียนเป็นฟังก์ชันของ $c$ ได้ดังนี้ ขั้นให้คะแนนด้วยมือด้านล่างจะคำนวณตัวเลขทุกตัวให้ดูทีละบรรทัด

\[\begin{aligned}J_{\rm eq}&=20{,}000+c\,(12{,}000\times10^6),\\J_{\rm fr}&=30{,}000+c\,(4{,}600\times10^6).\end{aligned}\]

ที่ $c=10^{-6}$ ค่าปรับของแผนเท่ากันคือ $10^{-6}\times12{,}000\times10^6=\$12{,}000$ จึงได้ $J_{\rm eq}=20{,}000+12{,}000=\$32{,}000$ ส่วนแผนเร่งได้ $J_{\rm fr}=30{,}000+4{,}600=\$34{,}600$ แผนขายเท่ากันชนะ

ที่ $c=3\times10^{-6}$ ค่าปรับทั้งสองแผนโตสามเท่า เป็น $3\times12{,}000=36{,}000$ และ $3\times4{,}600=13{,}800$ จึงได้ $J_{\rm eq}=20{,}000+36{,}000=\$56{,}000$ และ $J_{\rm fr}=30{,}000+13{,}800=\$43{,}800$ คราวนี้แผนเร่งชนะ

ตลาดไม่ได้เปลี่ยนอะไรเลย เปลี่ยนแค่ตัวเลขความกลัวที่โต๊ะเลือกเอง และทั้งสองแผนยังแพ้แผนที่ดีที่สุด ซึ่งหน้านี้จะหาให้ทีละขั้น: คะแนน \$29,885 ที่ $c=10^{-6}$ และ \$42,299 ที่ $c=3\times10^{-6}$

ภาพรวมก่อนลงสูตร

ทำไมขายก้อนใหญ่แล้วได้ราคาแย่ เพราะในตลาด คนที่รอรับซื้อแต่ละคนตั้งราคาและจำนวนของตัวเองไว้ คนที่ให้ราคาดีที่สุดรับได้แค่ส่วนหนึ่ง ที่เหลือต้องขายให้คนที่ให้ราคาต่ำลงไปเรื่อย ๆ ยิ่งก้อนใหญ่ ราคาเฉลี่ยที่ได้ยิ่งต่ำ ราคาที่ขยับเพราะคำสั่งของเราเองนี้คือ market impact ซึ่งหน้า market microstructure วัดไว้แล้ว

ทางแก้คือแบ่งขายทีละน้อย แต่ระหว่างที่ทยอยขาย หุ้นที่ยังถืออยู่ก็ขึ้นลงตามตลาด เงินที่จะได้จึงไม่แน่นอน ดังนั้นสองทางเลือกมีข้อเสียคนละแบบ ขายเร็วเสีย impact มากแต่เสี่ยงน้อย ขายช้าเสีย impact น้อยแต่เสี่ยงมาก

Almgren กับ Chriss เสนอให้ชั่งสองอย่างนี้ด้วยตัวเลขเดียว คือต้นทุนที่คาดว่าจะเสีย บวก $\lambda$ คูณความแปรปรวน (variance) ของเงินที่จะได้ ตัว $\lambda$ คือความกลัวความเสี่ยงที่โต๊ะเลือกเอง รูปนี้เหมือน mean-variance ของ Markowitz portfolio theory ต่างกันแค่ของที่เราเลือก ที่นี่เลือกจำนวนหุ้นที่ขายแต่ละวัน ไม่ใช่น้ำหนักของหุ้นแต่ละตัวในพอร์ต

หน้านี้เดินตามลำดับนี้:

  • ตั้งกติกาว่าการขายกดราคาอย่างไร แล้วทำบัญชีเงินที่ได้ จะเห็นว่าความเสี่ยงมาจากหุ้นที่ยังถืออยู่
  • ให้คะแนนสองแผนของโจทย์เปิดหน้าด้วยมือ
  • หาแผนที่ดีที่สุดด้วยแคลคูลัส (ตั้งอนุพันธ์เป็นศูนย์) ได้สูตร sinh
  • วาดเส้น frontier ของต้นทุนกับความเสี่ยง และดูว่าถ้ามีเวลามาก ๆ แผนกลายเป็นการขายแบบ exponential
  • ปิดด้วยเพดานปริมาณที่โต๊ะขายได้ต่อวัน และไฟล์ Excel ของคอร์สที่ใช้ impact แบบไม่เป็นเส้นตรง

รูปด้านล่างคือคำตอบของทั้งหน้าในภาพเดียว

ศัพท์ที่ใช้ในหัวข้อนี้
Market impact
ราคาที่ขยับเพราะคำสั่งของเราเอง ขายก้อนใหญ่ต้องขายให้คนที่ให้ราคาต่ำลงเรื่อย ๆ ราคาเฉลี่ยที่ได้จึงต่ำกว่าราคาตลาดก่อนขาย
Optimal execution
การเลือกว่าจะซื้อหรือขายครั้งละเท่าไรจนครบคำสั่ง ให้ต้นทุนที่คาดบวกค่าปรับความเสี่ยงต่ำที่สุด ผลที่ได้คือตารางว่าวันไหนขายกี่หุ้น ซึ่งตรวจย้อนหลังได้ว่าทำตามหรือไม่
Temporary impact และ permanent impact
temporary impact คือส่วนที่กดราคาเฉพาะคำสั่งนั้น พอขายเสร็จราคาก็ฟื้นกลับ permanent impact คือรอยกดที่ค้างอยู่ และทำให้ทุกหุ้นที่ขายหลังจากนั้นได้ราคาต่ำลงด้วย
Inventory risk
ความเสี่ยงของหุ้นที่ยังขายไม่หมด ถ้าราคาลงระหว่างรอ หุ้นที่เหลือจะขายได้เงินน้อยลง ยิ่งถือมากและนานยิ่งเสี่ยง นี่เป็นเหตุผลเดียวที่บอกให้รีบขาย
ความแปรปรวน (variance) และ SD
ความแปรปรวนวัดว่าตัวเลขสุ่มกระจายห่างจากค่าเฉลี่ยแค่ไหน มีหน่วยเป็นดอลลาร์กำลังสอง SD (standard deviation) คือรากที่สองของมัน จึงมีหน่วยเป็นดอลลาร์และอ่านง่ายกว่า
Risk aversion ($\lambda$)
ความกลัวความเสี่ยง คือจำนวนดอลลาร์ที่โต๊ะยอมจ่ายเพื่อลดความแปรปรวนของเงินที่จะได้ลงหนึ่งหน่วย ตลาดไม่ได้กำหนดให้ โต๊ะเลือกเองตามว่าลูกค้าเร่งแค่ไหน และตัวเลขนี้ตัดสินว่าแผนจะเร่งขายแค่ไหน
Execution frontier
นำแผนที่ดีที่สุดของ $\lambda$ แต่ละค่ามาวางเป็นจุดบนกราฟ แกนหนึ่งคือความเสี่ยง อีกแกนคือต้นทุนที่คาด แล้วลากเส้นผ่าน แผนใดอยู่เหนือเส้น แปลว่ามีแผนอื่นที่เสี่ยงเท่ากันแต่ถูกกว่า
Participation rate
คำสั่งของเราคิดเป็นกี่เปอร์เซ็นต์ของจำนวนหุ้นที่ซื้อขายกันทั้งตลาดในช่วงเดียวกัน โต๊ะตั้งเพดานไว้ เพื่อไม่ให้คำสั่งของตัวเองใหญ่จนกดราคาแรง

$J$คะแนนของแผน: ต้นทุน impact บวกค่าปรับความเสี่ยง ยิ่งต่ำยิ่งดีดอลลาร์

ขั้นที่ 1 — แบบจำลองราคา: impact สองแบบ

ก่อนจะให้คะแนนแผนได้ ต้องมีกติกาว่าการขายแต่ละครั้งเปลี่ยนราคาอย่างไร แบบจำลองนี้บอกว่ามีสามอย่างเกิดกับราคา

  • ตอนขายครั้งที่ $k$ จำนวน $n_k$ หุ้น ราคาที่ได้จริง $\hat S_k$ ต่ำกว่าราคาตลาด $S_k$ อยู่ $h(n_k)$ ดอลลาร์ต่อหุ้น นี่คือ temporary impact
  • หลังขาย ราคาตลาดถูกกดลงถาวร $g(n_k)$ ดอลลาร์ต่อหุ้น นี่คือ permanent impact
  • ระหว่างการขายสองครั้ง ราคาตลาดขยับขึ้นหรือลงแบบสุ่ม $\sigma z_k$ โดย $z_k$ เป็นตัวสุ่ม Normal มาตรฐาน (ค่าเฉลี่ย 0, SD 1) ที่อิสระกันทุกช่วง

หน้านี้ใช้รูปที่ง่ายที่สุดคือเส้นตรง $h(n)=\eta n$ และ $g(n)=\gamma n$ เขียนกติกาทั้งหมดเป็นสมการได้ดังนี้

\[ \begin{aligned} \hat S_k&=S_k-h(n_k),\\ S_{k+1}&=S_k+\sigma z_k-g(n_k),\\ h(n)&=\eta n,\qquad g(n)=\gamma n. \end{aligned} \]

สมการแรกบอกว่าเราขายได้ต่ำกว่าราคาตลาด เพราะคำสั่งต้องไล่ขายให้คนที่ให้ราคาต่ำลงเรื่อย ๆ ส่วนนี้เกิดเฉพาะตอนขาย พอขายเสร็จ คนรับซื้อรายใหม่เข้ามา ราคาก็ฟื้น สมการที่สองบอกว่าราคาตลาดของครั้งถัดไปเปลี่ยนจากสองเหตุ เหตุแรกคือตลาดขยับเอง $\sigma z_k$ เหตุที่สองคือรอยกดถาวร $g(n_k)$ ซึ่งเกิดเพราะคนในตลาดเห็นคนขายก้อนใหญ่ แล้วเดาว่าผู้ขายอาจรู้ข่าวร้าย จึงปรับราคาลงและไม่ปรับกลับ

รูปเส้นตรงของ $h$ และ $g$ เป็นตัวเลือกที่ง่ายที่สุด ไม่ใช่กฎธรรมชาติ ต้นทุนการซื้อขายจริงมักแยกเป็นสามก้อน คือ spread (ส่วนต่างระหว่างราคาที่คนเสนอซื้อกับราคาที่คนเสนอขาย) temporary impact และ permanent impact เวลาวางแผนแบ่งคำสั่ง สองก้อนแรกใหญ่กว่าก้อนสุดท้ายมาก ไฟล์ Excel ในขั้นสุดท้ายของหน้านี้ใช้ $h$ แบบไม่เป็นเส้นตรงของ Kissel–Glantz ซึ่ง impact โตเร็วกว่าเส้นตรงเมื่อคำสั่งใหญ่ขึ้น

ขั้นที่ 2 — บัญชีเงินที่ได้: ความเสี่ยงมาจากหุ้นที่ยังถือ

ราคาขยับแบบสุ่ม เงินที่ได้รวม $R$ จึงเป็นตัวสุ่มด้วย เราอยากรู้สองอย่างของมัน คือค่าเฉลี่ย (เงินที่คาดว่าจะได้) และความแปรปรวน (ความไม่แน่นอน) โดยเขียนทั้งสองอย่างเป็นสูตรของแผน วิธีคือรวมเงินที่ได้จากการขายทุกครั้ง แล้วจัดใหม่ให้เห็นว่าการขยับแบบสุ่มของแต่ละวันไปคูณกับอะไร

\[ \begin{aligned} S_k&=S_1+\sum_{j\lt k}\big(\sigma z_j-g(n_j)\big),\\ R&=\sum_{k=1}^{T}\hat S_kn_k\\ &=S_1X+\sigma\sum_{j=1}^{T}z_jx_j\\ &\quad-\sum_j g(n_j)x_j-\sum_k h(n_k)n_k,\\ C&=\sum_j g(n_j)x_j+\sum_k h(n_k)n_k,\\ \mathbb E[R]&=S_1X-C,\\ \mathrm{Var}(R)&=\sigma^2\sum_{k=1}^{T-1}x_k^2. \end{aligned} \]

แถวแรกได้จากการใช้สมการราคาของขั้นก่อนซ้ำ ๆ ย้อนไปถึง $S_1$ ราคาก่อนขายครั้งที่ $k$ จึงเท่ากับราคาเริ่มต้น บวกการขยับสุ่มทุกวันก่อนหน้า และหักรอยกดถาวรของทุกครั้งก่อนหน้า พอแทนลงใน $R=\sum\hat S_kn_k$ จะได้ผลบวกซ้อน $\sum_k\sum_{j\lt k}z_jn_k$ ซึ่งยังอ่านไม่ออก

กลที่ใช้คือสลับลำดับการนับ แทนที่จะถามว่าการขายครั้งที่ $k$ โดนการขยับของวันไหนบ้าง ให้ถามว่าการขยับของวันที่ $j$ โดนการขายครั้งไหนบ้าง คำตอบคือทุกครั้งหลังวันที่ $j$ ซึ่งรวมกันได้ $n_{j+1}+\dots+n_T=x_j$ คือหุ้นที่ยังถืออยู่หลังขายครั้งที่ $j$ พอดี ดูตัวอย่างที่ $T=3$: $z_1$ เกิดหลังขายครั้งแรก จึงกระทบการขายครั้งที่ 2 และ 3 และคูณกับ $n_2+n_3=x_1$ ส่วน $z_2$ กระทบเฉพาะครั้งที่ 3 จึงคูณกับ $n_3=x_2$ ก้อน $g$ สลับแบบเดียวกัน ได้ $\sum_j g(n_j)x_j$

ต่อมาหาค่าเฉลี่ย เพราะ $z_j$ มีค่าเฉลี่ยศูนย์ เงินที่คาดว่าจะได้จึงเป็นมูลค่าตั้งต้น $S_1X$ ลบต้นทุน $C$ ส่วนความแปรปรวนใช้สองกฎ คือ $\mathrm{Var}(az)=a^2\mathrm{Var}(z)$ และความแปรปรวนของผลบวกของตัวสุ่มที่อิสระกันเท่ากับผลบวกของความแปรปรวน เพราะ $\mathrm{Var}(z_j)=1$ จึงได้ $\sigma^2\sum x_j^2$ ผลบวกหยุดที่ $T-1$ เพราะ $x_T=0$

ความหมายคือ ทุกหุ้นที่ยังถือข้ามช่วงหนึ่ง โดนการขยับของราคาช่วงนั้นเต็ม ๆ ขายเร็วทำให้ $x_k$ เล็ก จึงเสี่ยงน้อย แต่ต้องขายก้อนใหญ่และเสีย impact มาก ขายช้าก็ตรงกันข้าม นี่คือที่มาของค่าปรับ $c\,x^2$ ในโจทย์เปิดหน้า ค่าปรับคือ $\lambda$ คูณความแปรปรวนนี้ ซึ่งขั้นถัดไปจะรวมเป็น $c=\lambda\sigma^2$

ขั้นที่ 3 — impact ถาวรแบบเส้นตรงไม่เปลี่ยนรูปของปัญหา และคะแนนที่ใช้ทั้งหน้า

ในบัญชีเงิน ต้นทุนถาวรคือ $\sum_j g(n_j)x_j=\gamma\sum_k n_kx_k$ ซึ่งดูเหมือนขึ้นกับแผน ถ้ามันทำให้ปัญหายากขึ้น เราต้องแบกมันไปทุกขั้น ขั้นนี้จะแสดงว่ามันแค่บวกค่าคงที่และทำให้ $\eta$ เล็กลงนิดหนึ่ง วิธีคือเขียนมันด้วยผลบวกกำลังสองของจำนวนที่ขายแต่ละครั้ง แล้วจึงตั้งคะแนน $J$ ที่ใช้ทั้งหน้า

\[ \begin{aligned} X^2&=\Big(\sum_k n_k\Big)^2\\ &=\sum_k n_k^2+2\sum_{k\lt j}n_kn_j,\\ \sum_k n_kx_k&=\sum_{k\lt j}n_kn_j\\ &=\tfrac12\Big(X^2-\sum_k n_k^2\Big),\\ C&=\gamma\sum_k n_kx_k+\eta\sum_k n_k^2\\ &=\tfrac12\gamma X^2\\ &\quad+\big(\eta-\tfrac12\gamma\big)\sum_k n_k^2,\\ J&=\eta\sum_{k=1}^{T}n_k^2+c\sum_{k=1}^{T-1}x_k^2. \end{aligned} \]

แถวแรกคือการกระจาย $(n_1+\dots+n_T)^2$ ได้กำลังสองของแต่ละตัว บวกผลคูณไขว้ของทุกคู่สองครั้ง แถวที่สองใช้ $x_k=n_{k+1}+\dots+n_T$ ดังนั้น $n_kx_k$ คือผลคูณของการขายครั้งที่ $k$ กับทุกครั้งที่ตามมา พอรวมทุก $k$ ก็ได้ผลคูณไขว้ทุกคู่ครั้งเดียว ซึ่งเป็นครึ่งหนึ่งของผลคูณไขว้ใน $X^2$ ลองที่ $T=2$: $X^2=n_1^2+n_2^2+2n_1n_2$ และ $\sum n_kx_k=n_1x_1=n_1n_2$ ตรงกัน

แทนลงในต้นทุน $C$ (ใส่ $h(n)=\eta n$ และ $g(n)=\gamma n$ ลงในบัญชีเงิน) ได้สองก้อน ก้อนแรก $\tfrac12\gamma X^2$ เป็นค่าคงที่ที่ทุกแผนจ่ายเท่ากัน เพราะ $X$ ถูกกำหนดไว้แล้ว ก้อนที่สองมีรูปเดียวกับ impact ชั่วคราวทุกอย่าง แค่ใช้ $\eta-\tfrac12\gamma$ แทน $\eta$ ดังนั้นถ้ามี $\gamma$ ก็แค่ใส่ $\eta-\tfrac12\gamma$ แทน $\eta$ ในทุกสูตรที่ตามมา หน้านี้จึงตั้ง $\gamma=0$ เพื่อให้สูตรสั้น

แถวสุดท้ายเป็นนิยามของคะแนน ไม่ใช่ผลที่พิสูจน์ คะแนนคือต้นทุนที่คาด $\eta\sum n_k^2$ บวก $\lambda$ คูณความแปรปรวน $\sigma^2\sum x_k^2$ แล้วรวม $\lambda\sigma^2$ เป็นตัวเดียวคือ $c=\lambda\sigma^2$ ต้นทุนเป็นดอลลาร์ ความแปรปรวนเป็นดอลลาร์กำลังสอง $\lambda$ จึงต้องมีหน่วยต่อดอลลาร์ เพื่อให้สองก้อนบวกกันได้ นี่คือปัญหาแบบเดียวกับ mean-variance กับต้นทุนการซื้อขาย ต่างกันที่ของที่เลือกคือจังหวะเวลาของการขาย ไม่ใช่น้ำหนักพอร์ต

ขั้นที่ 4 — ถ้าไม่กลัวความเสี่ยงเลย ขายเท่ากันทุกครั้ง และยิ่งช้ายิ่งถูก

ก่อนแก้ปัญหาเต็ม ดูกรณีสุดขั้วก่อน ถ้าโต๊ะไม่กลัวความเสี่ยงเลย ($c=0$) คะแนนเหลือแค่ $\eta\sum n_k^2$ และต้องขายให้ครบ $\sum n_k=X$ คำถามคือแผนไหนถูกที่สุด

เขียนการขายแต่ละครั้งเป็นค่าเฉลี่ยบวกส่วนเบี่ยง $n_k=X/T+d_k$ โดย $d_k$ คือจำนวนที่ขายมากหรือน้อยกว่าค่าเฉลี่ย เพราะยอดรวมต้องเป็น $X$ ส่วนเบี่ยงจึงรวมกันได้ศูนย์ $\sum d_k=0$ แล้วกระจายกำลังสอง

\[ \begin{aligned} \sum_k n_k^2&=\sum_k\Big(\frac XT+d_k\Big)^2\\ &=\frac{X^2}{T}+\frac{2X}{T}\sum_k d_k\\ &\quad+\sum_k d_k^2\\ &=\frac{X^2}{T}+\sum_k d_k^2,\\ I(T)&=\eta\frac{X^2}{T}=\frac{10^{-5}(10^5)^2}{T}\\ &=\frac{100{,}000}{T},\\ I(1)&=100{,}000,\quad I(5)=20{,}000,\\ I(10)&=10{,}000. \end{aligned} \]

ก้อน $\tfrac{X^2}{T}$ มาจากการบวก $(X/T)^2$ ทั้งหมด $T$ ครั้ง ก้อนกลางหายไปเพราะ $\sum d_k=0$ ก้อนสุดท้าย $\sum d_k^2$ เป็นผลบวกของกำลังสอง จึงไม่ติดลบ และเป็นศูนย์เฉพาะเมื่อ $d_k=0$ ทุกตัว คือขายเท่ากันทุกครั้ง ดังนั้นการเบี่ยงจากค่าเฉลี่ยทุกแบบทำให้แพงขึ้น เหตุผลคือ impact เป็นกำลังสอง วันที่ขายเกินค่าเฉลี่ยเสียเพิ่มมากกว่าที่วันที่ขายน้อยประหยัดได้ ผลคือขายห้าครั้งเท่ากันเสีย $I(5)=\$20{,}000$ แต่ขายทีเดียวหมดเสีย $I(1)=\$100{,}000$

ต้นทุนต่อหุ้นคือ $I(T)/X=\eta X/T$ เช่นที่ $T=5$ ได้ $10^{-5}\times100{,}000/5=\$0.20$ ต่อหุ้น ตัวเลขนี้ลดลงเมื่อใช้เวลาขายนานขึ้น ถ้าไม่มีความเสี่ยง ทางที่ดีที่สุดจึงเป็นการยืดการขายออกไปให้นานที่สุด ดังนั้นความเสี่ยงของหุ้นที่ถือค้างเป็นแรงเดียวที่บอกให้รีบ และ $c$ คือตัวบอกว่ารีบแค่ไหน

ขั้นที่ 5 — ให้คะแนนสองแผนของโจทย์เปิดหน้าด้วยมือ

ตอนนี้มีคะแนน $J$ แล้ว จึงตอบโจทย์เปิดหน้าได้ด้วยมือ เพื่อให้สั้น เขียน $I=\eta\sum n_k^2$ แทนต้นทุน impact และ $Q=\sum x_k^2$ แทนผลบวกกำลังสองของหุ้นที่ยังถือ คะแนนจึงเป็น $J=I+cQ$

โจทย์ให้อะไรมาบ้าง:

  • ตัวคูณ impact $\eta=10^{-5}$
  • แผนเท่ากัน (eq) ขายครั้งละ 20,000 หุ้น หลังขายแต่ละครั้งเหลือ 80, 60, 40, 20 พันหุ้น
  • แผนเร่ง (fr) ขาย 40, 30, 20, 10, 0 พันหุ้น หลังขายแต่ละครั้งเหลือ 60, 30, 10, 0 พันหุ้น
\[ \begin{aligned} I_{\rm eq}&=5\times10^{-5}\times(20{,}000)^2\\ &=20{,}000,\\ I_{\rm fr}&=10^{-5}(40^2+30^2+20^2\\ &\qquad+10^2)\times10^6\\ &=10^{-5}\times3{,}000\times10^6\\ &=30{,}000,\\ Q_{\rm eq}&=(80^2+60^2+40^2\\ &\qquad+20^2)\times10^6\\ &=12{,}000\times10^6,\\ Q_{\rm fr}&=(60^2+30^2+10^2)\times10^6\\ &=4{,}600\times10^6. \end{aligned} \]

คำตอบ: ที่ $c=10^{-6}$ ค่าปรับ $cQ$ ของแผนเท่ากันคือ $10^{-6}\times12{,}000\times10^6=12{,}000$ ของแผนเร่งคือ $10^{-6}\times4{,}600\times10^6=4{,}600$ จึงได้

\[ \begin{aligned} J_{\rm eq}&=20{,}000+12{,}000=\$32{,}000,\\ J_{\rm fr}&=30{,}000+4{,}600=\$34{,}600. \end{aligned} \]

แผนเท่ากันชนะ ที่ $c=3\times10^{-6}$ ค่าปรับโตสามเท่า เป็น $3\times12{,}000=36{,}000$ และ $3\times4{,}600=13{,}800$

\[ \begin{aligned} J_{\rm eq}&=20{,}000+36{,}000=\$56{,}000,\\ J_{\rm fr}&=30{,}000+13{,}800=\$43{,}800. \end{aligned} \]

คราวนี้แผนเร่งชนะ

ตรวจเองใน 10 วินาที: แผนเร่งจ่าย impact มากกว่า $30{,}000-20{,}000=\$10{,}000$ แต่ลด $Q$ ลง $(12{,}000-4{,}600)\times10^6=7.4\times10^9$ แผนเร่งจึงคุ้มเมื่อค่าปรับที่ลดได้มากกว่า \$10,000 คือ $c\times7.4\times10^9\gt10{,}000$ หรือ $c\gt10{,}000/(7.4\times10^9)=1.35\times10^{-6}$ ค่านี้อยู่ระหว่างสองค่าที่ลอง ผู้ชนะจึงพลิกพอดี

ขั้นที่ 6 — แผนที่ดีที่สุดจากเงื่อนไขอันดับหนึ่ง: สูตรปิดแบบ sinh

ลองทีละแผนไม่มีวันจบ ทางที่ดีกว่าคือใช้แคลคูลัสหาแผนที่ทำให้ $J$ ต่ำสุด ตาม gradient และเงื่อนไขอันดับหนึ่ง: ที่จุดต่ำสุด อนุพันธ์เทียบตัวแปรทุกตัวเป็นศูนย์

เลือกตัวแปรเป็นหุ้นที่ถือ $x_1,\dots,x_{T-1}$ แทนจำนวนที่ขาย เพราะสองปลาย $x_0=X$ และ $x_T=0$ ถูกตรึงไว้ เงื่อนไขขายให้ครบจึงเป็นจริงเองโดยไม่ต้องบังคับ ส่วนจำนวนที่ขายหาได้จาก $n_k=x_{k-1}-x_k$ ตัว $x_k$ โผล่ใน $J$ สามที่ คือในการขายครั้งที่ $k$ ($n_k=x_{k-1}-x_k$) ในการขายครั้งที่ $k+1$ ($n_{k+1}=x_k-x_{k+1}$) และในค่าปรับ $cx_k^2$ อนุพันธ์จึงมีสามพจน์

\[ \begin{aligned} \frac{\partial J}{\partial x_k}&=-2\eta(x_{k-1}-x_k)\\ &\quad+2\eta(x_k-x_{k+1})\\ &\quad+2cx_k=0,\\ x_{k+1}-2x_k+x_{k-1}&=\kappa^2x_k,\\ \kappa^2&=c/\eta,\\ e^{\tilde\kappa}-2+e^{-\tilde\kappa}&=\kappa^2,\\ 2\cosh\tilde\kappa&=2+\kappa^2,\\ x_k&=X\,\frac{\sinh(\tilde\kappa(T-k))}{\sinh(\tilde\kappa T)}. \end{aligned} \]

หารสมการแรกด้วย $2\eta$ แล้วย้ายข้าง ได้สมการผลต่าง (difference equation) ในแถวที่สอง ด้านซ้าย $x_{k+1}-2x_k+x_{k-1}$ คือ “ความโค้ง” ของเส้นหุ้นที่ถือ เป็นอนุพันธ์อันดับสองแบบนับทีละขั้น สมการจึงบอกว่าเส้นทางที่ดีที่สุดโค้งหงายมากตรงที่ยังถือมาก และเกือบตรงตรงที่ถือน้อย

แก้แบบเดียวกับสมการเชิงอนุพันธ์ $x''=\kappa^2x$ คือเดาคำตอบรูป $x_k=e^{\tilde\kappa k}$ แทนลงไปแล้วหารด้วย $e^{\tilde\kappa k}$ ได้ $e^{\tilde\kappa}-2+e^{-\tilde\kappa}=\kappa^2$ และเพราะ $\cosh a=(e^a+e^{-a})/2$ จึงเขียนเป็น $2\cosh\tilde\kappa=2+\kappa^2$ ได้ รูป $e^{-\tilde\kappa k}$ ก็ใช้ได้ด้วยเหตุผลเดียวกัน ตัว $\tilde\kappa$ (มีหมวก) เป็นคนละตัวกับ $\kappa$ เพราะสองตัวนี้ไม่เท่ากันพอดี

คำตอบทั่วไปจึงเป็น $Ae^{\tilde\kappa k}+Be^{-\tilde\kappa k}$ แล้วเลือก $A$ กับ $B$ ให้ตรงสองปลาย $x_0=X$ และ $x_T=0$ ฟังก์ชัน $\sinh a=(e^a-e^{-a})/2$ เป็นผลรวมแบบนี้พอดี และเป็นศูนย์ที่ $a=0$ ดังนั้น $\sinh(\tilde\kappa(T-k))$ เป็นศูนย์ที่ $k=T$ เอง เมื่อหารด้วย $\sinh(\tilde\kappa T)$ ก็ได้ $X$ ที่ $k=0$ นี่คือแถวสุดท้าย

ทำไมจุดที่อนุพันธ์เป็นศูนย์คือจุดต่ำสุดจริง เพราะ $J$ เป็นผลบวกของกำลังสองล้วน จึงเป็นชามหงายที่มีก้นเดียว ลองกรณีสุดขั้วด้วย ถ้า $c\to0$ จะได้ $\tilde\kappa\to0$ และ $\sinh a\approx a$ อัตราส่วน sinh จึงเข้าใกล้ $(T-k)/T$ ซึ่งเป็นเส้นตรง คือขายเท่ากัน ตรงกับกรณีไม่กลัวความเสี่ยง

ขั้นที่ 7 — แผนที่ดีที่สุดของโจทย์เปิดหน้า

ตอนนี้ใส่ตัวเลขของโจทย์เปิดหน้าลงในสูตร sinh เพื่อดูว่าแผนที่ดีที่สุดหน้าตาเป็นอย่างไร และดีกว่าสองแผนของเทรดเดอร์แค่ไหน

โจทย์ให้อะไรมาบ้าง: หุ้นที่ต้องขาย $X=100{,}000$ ขาย $T=5$ ครั้ง ตัวคูณ impact $\eta=10^{-5}$ และ $c=10^{-6}$

\[ \begin{aligned} \kappa^2&=c/\eta=10^{-6}/10^{-5}=0.1,\\ \cosh\tilde\kappa&=1+\kappa^2/2=1.05,\\ \tilde\kappa&=\cosh^{-1}1.05=0.314925,\\ x_1&=10^5\frac{\sinh(4\tilde\kappa)}{\sinh(5\tilde\kappa)}\\ &=10^5\times\frac{1.62031}{2.31092}\\ &=70{,}115.40,\\ x_{1..4}&=70{,}115,\ 47{,}242,\\ &\qquad29{,}094,\ 13{,}854,\\ n_k&=x_{k-1}-x_k\\ &=29{,}885,\ 22{,}873,\ 18{,}149,\\ &\qquad15{,}239,\ 13{,}854,\\ I&=\eta\sum n_k^2=21{,}698.22,\\ Q&=\sum x_k^2=8{,}186.38\times10^6,\\ J^*&=I+cQ\\ &=21{,}698.22+8{,}186.38\\ &=29{,}884.60. \end{aligned} \]

คำตอบ: แผนที่ดีที่สุดขายครั้งแรกเกือบ 30,000 หุ้น แล้วขายน้อยลงทุกครั้ง คะแนน \$29,884.60 ต่ำกว่าทั้งสองแผนของเทรดเดอร์ (\$32,000 และ \$34,600) เทียบกับแผนเท่ากัน มันจ่าย impact มากกว่า $21{,}698-20{,}000=\$1{,}698$ แต่ลดค่าปรับความเสี่ยงได้ $12{,}000-8{,}186=\$3{,}814$ จึงคุ้ม

ทำแบบเดียวกันที่ค่า $c$ อื่น ที่ $c=3\times10^{-6}$ ได้ $\kappa^2=0.3$ ครั้งแรกขาย 42,298.75 หุ้น คะแนน \$42,298.75 ที่ $c=10^{-5}$ ได้ $\kappa^2=1$ ครั้งแรกขาย 61,818.18 หุ้น คะแนนกับจำนวนหุ้นครั้งแรกเป็นเลขเดียวกันไม่ใช่เรื่องบังเอิญ ช่องตรวจด้านล่างอธิบายว่าทำไม

ตรวจเองใน 10 วินาที: คะแนนที่ดีที่สุดเท่ากับ $\eta Xn_1$ เสมอ เหตุผลคือ $J$ เป็นกำลังสองล้วนของ $(X,x_1,\dots,x_{T-1})$ ฟังก์ชันแบบนี้มีสมบัติว่า ผลบวกของ “ตัวแปรคูณอนุพันธ์เทียบตัวนั้น” เท่ากับ $2J$ ที่จุดต่ำสุด อนุพันธ์เทียบ $x_k$ ทุกตัวเป็นศูนย์ จึงเหลือแค่พจน์ของ $X$ ซึ่งโผล่ใน $n_1=X-x_1$ ที่เดียว ส่วนสมการผลต่างที่ $k=1$ ตรวจได้ว่า $x_2+x_0=(2+\kappa^2)x_1$

\[ \begin{aligned} 2J^*&=X\cdot\frac{\partial J}{\partial X}=X\cdot2\eta n_1,\\ J^*&=\eta Xn_1=10^{-5}(10^5)(29{,}884.60)\\ &=29{,}884.60,\\ x_2+x_0&=47{,}242.35+100{,}000\\ &=147{,}242.35=2.1\times70{,}115.40. \end{aligned} \]

ที่นี่ $\eta X=10^{-5}\times10^5=1$ คะแนนเป็นดอลลาร์จึงเท่ากับจำนวนหุ้นที่ขายครั้งแรกพอดี

ขั้นที่ 8 — execution frontier: แผนเร่งของเทรดเดอร์เป็นแผนที่เปลือง

คะแนน $J$ ผสมต้นทุนกับความเสี่ยงไว้ด้วยกันตามค่า $c$ ที่เลือก ขั้นนี้แยกสองอย่างออกจากกัน เพื่อถามว่าแผนเร่งของเทรดเดอร์ “เปลือง” ไหม คือมีแผนอื่นที่เสี่ยงเท่ากันแต่ถูกกว่าหรือเปล่า

ก่อนอื่นต้องอ่านความเสี่ยงเป็นเงินให้ได้ จึงต้องรู้ขนาดการขยับของราคา สมมติหุ้นราคา \$100 และขยับวันละ 2% (หนึ่ง SD) จะได้ $\sigma=0.02\times100=\$2$ ต่อหุ้นต่อวัน SD ของเงินที่ได้คือรากที่สองของความแปรปรวน $\sigma^2Q$ คือ $\sigma\sqrt Q$

แต่ละค่า $c$ ให้แผนที่ดีที่สุดหนึ่งแผน ซึ่งเป็นหนึ่งจุดบนกราฟ (SD, ต้นทุนที่คาด) เส้นที่ลากผ่านจุดเหล่านี้คือ execution frontier วิธีตรวจแผนเร่งคือหาแผนบนเส้นที่มี $Q$ เท่ากับแผนเร่งพอดี ($4{,}600\times10^6$) โดยแบ่งครึ่งช่วงของ $c$ ไปเรื่อย ๆ (bisection: ถ้า $Q$ ยังใหญ่ไปให้เพิ่ม $c$ ถ้าเล็กไปให้ลด $c$) แล้วเทียบต้นทุน impact ของสองแผน

\[ \begin{aligned} \mathrm{SD}_{\rm eq}&=2\sqrt{12{,}000\times10^6}\\ &=219{,}089,\\ \mathrm{SD}_{\rm fr}&=2\sqrt{4{,}600\times10^6}\\ &=135{,}647,\\ c&=3.1613\times10^{-6},\\ n&=43{,}054,\ 25{,}052,\ 14{,}969,\\ &\qquad9{,}618,\ 7{,}308,\\ I&=\eta\sum n_k^2=28{,}511.94,\\ 30{,}000-I&=1{,}488.06. \end{aligned} \]

bisection หยุดที่ $c=3.1613\times10^{-6}$ ซึ่งให้แผนบนเส้นที่เสี่ยงเท่าแผนเร่งทุกหลัก แผนนี้จ่าย impact น้อยกว่าแผนเร่งของเทรดเดอร์ \$1,488.06 แผนเร่งจึงอยู่เหนือเส้น และไม่มีค่า $c$ ไหนที่ทำให้มันเป็นแผนที่ดีที่สุด สาเหตุคือแผนเร่งลดลงเป็นเส้นตรงจนครั้งสุดท้ายขายศูนย์ ส่วนแผนบนเส้นเร่งช่วงต้นแรงกว่า (43,054 หุ้น) แล้วเก็บหางยาวกว่า (7,308 หุ้นในครั้งสุดท้าย) เพราะ impact เป็นกำลังสอง การเกลี่ยการขายช่วงท้ายให้หลายครั้งจึงถูกกว่า

สังเกตขนาดด้วย SD ของเงินที่ได้อยู่ระหว่าง \$136,000 ถึง \$219,000 ใหญ่กว่าต้นทุน impact ที่คาด \$20,000 ถึง \$30,000 หลายเท่า ผลของคำสั่งเดียวจึงขึ้นกับโชคเป็นหลัก ตัวเลข $c$ แปลงกลับเป็นความกลัวความเสี่ยงได้ $\lambda=c/\sigma^2=10^{-6}/2^2=2.5\times10^{-7}$ ต่อดอลลาร์ ความหมายคือ ความเสี่ยงขนาด SD \$200,000 โต๊ะคิดเป็นค่าปรับ $\lambda(200{,}000)^2=2.5\times10^{-7}\times4\times10^{10}=\$10{,}000$

ขั้นที่ 9 — ถ้าไม่มีเส้นตาย: ขายเป็นสัดส่วนคงที่ของที่เหลือ

สูตร sinh มีเส้นตาย $T$ ฝังอยู่ เพราะต้องบังคับให้ $x_T=0$ คำถามคือรูปโค้งของแผนมาจากเส้นตาย หรือมาจากความกลัวความเสี่ยงเอง วิธีดูคือเขียน sinh กลับเป็น exponential แล้วดูว่าเกิดอะไรเมื่อเส้นตายอยู่ไกลมาก

\[ \begin{aligned} \frac{x_k}{X}&=\frac{\sinh(\tilde\kappa(T-k))}{\sinh(\tilde\kappa T)}\\ &=\frac{e^{-\tilde\kappa k}-e^{-\tilde\kappa(2T-k)}}{1-e^{-2\tilde\kappa T}}\\ &\to e^{-\tilde\kappa k},\\ 1-e^{-\tilde\kappa}&=1-0.7298=0.2702,\\ t_{1/2}&=\frac{\ln2}{\tilde\kappa}=\frac{0.6931}{0.3149}\\ &=2.20,\\ \kappa&=\sqrt{c/\eta}=\sqrt{\lambda\sigma^2/\eta}\\ &=\sqrt{0.1}=0.3162. \end{aligned} \]

แถวที่สองได้จากนิยาม $\sinh a=(e^a-e^{-a})/2$ แล้วคูณทั้งเศษและส่วนด้วย $2e^{-\tilde\kappa T}$ เมื่อ $T$ โตมาก พจน์ $e^{-\tilde\kappa(2T-k)}$ และ $e^{-2\tilde\kappa T}$ เข้าใกล้ศูนย์ เหลือ $e^{-\tilde\kappa k}$ แปลว่าทุกครั้ง หุ้นที่ถือถูกคูณด้วย $e^{-\tilde\kappa}=0.7298$ คือขาย 27.02% ของที่ยังเหลือ

ครึ่งชีวิต $t_{1/2}$ คือเวลาที่หุ้นที่ถือลดเหลือครึ่งหนึ่ง แก้ $e^{-\tilde\kappa t}=1/2$ ได้ $t=\ln2/\tilde\kappa=2.20$ วัน แผนที่ไม่มีเส้นตายจึงเป็นการระบายหุ้นออกแบบ exponential ถ้าขายได้ตลอดเวลาแทนวันละครั้ง จะเขียนได้ว่า $\dot x=-\kappa x$ ซึ่ง $\kappa=0.3162$ ใกล้ $\tilde\kappa=0.3149$ มาก เพราะเมื่อ $\tilde\kappa$ เล็ก $\cosh\tilde\kappa\approx1+\tilde\kappa^2/2$ เทียบกับ $\cosh\tilde\kappa=1+\kappa^2/2$ จึงได้ $\tilde\kappa\approx\kappa$

แถวสุดท้ายบอกทิศของทุกอย่างในสูตรเดียว ยิ่งกลัวความเสี่ยง ($\lambda$ ใหญ่) หรือหุ้นยิ่งผันผวน ($\sigma$ ใหญ่) ยิ่งระบายเร็ว ยิ่ง impact แพง ($\eta$ ใหญ่) ยิ่งระบายช้า เส้นตายจะเปลี่ยนแผนก็ต่อเมื่อมันสั้นเมื่อเทียบกับครึ่งชีวิต 2.2 วัน เส้นตาย 5 วันจึงงอปลายเส้นให้ลงถึงศูนย์ แต่เส้นตาย 20 วันแทบไม่มีผล

ขั้นที่ 10 — แผนสวยแต่ส่งจริงได้ไหม: เพดานปริมาณของโต๊ะ

แผนจากสูตร sinh ยังไม่ได้ดูข้อจำกัดของโลกจริง โต๊ะส่วนใหญ่มีกฎว่าวันหนึ่งห้ามขายเกินสัดส่วนหนึ่งของจำนวนหุ้นที่ซื้อขายกันทั้งตลาดในวันนั้น (participation rate) เพื่อไม่ให้คำสั่งของตัวเองกดราคาแรงเกินไป ขั้นนี้ดูว่ากฎนี้เปลี่ยนแผนอย่างไร และทำให้เสียเพิ่มเท่าไร

โจทย์ให้อะไรมาบ้าง:

  • เพดานของโต๊ะคือ 15% ของปริมาณซื้อขายต่อวัน (สมมติ)
  • หุ้นนี้ซื้อขายกันวันละ 200,000 หุ้น (สมมติ) โต๊ะจึงขายได้ไม่เกิน $0.15\times200{,}000=30{,}000$ หุ้นต่อวัน
  • โต๊ะใช้ $c=3\times10^{-6}$ ซึ่งแผนจากสูตร sinh ขายครั้งแรก 42,299 หุ้น เกินเพดาน

ลองแก้แบบตรงไปตรงมาก่อน ตัดครั้งแรกเหลือ 30,000 หุ้น แล้วใช้สูตร sinh คิดสี่ครั้งที่เหลือใหม่จาก $100{,}000-30{,}000=70{,}000$ หุ้น ครั้งที่สองจะออกมา 30,315 หุ้น ซึ่งเกินเพดานอีก จึงต้องให้เพดานบังคับทั้งสองครั้งแรก แล้วคิดสามครั้งที่เหลือใหม่จาก $100{,}000-60{,}000=40{,}000$ หุ้น ด้วยสูตร sinh เดิม ที่ $T=3$ และ $\kappa^2=3\times10^{-6}/10^{-5}=0.3$ (นับ $k=0$ ที่หลังขายครั้งที่สอง)

\[ \begin{aligned} n_1&=n_2=30{,}000,\\ x_k&=40{,}000\,\frac{\sinh(\tilde\kappa(3-k))}{\sinh(3\tilde\kappa)},\\ n_{3..5}&=18{,}555,\ 12{,}121,\ 9{,}324,\\ J_{\rm cap}&=I+cQ\\ &=23{,}781.41+21{,}140.50\\ &=44{,}921.91,\\ J_{\rm cap}-J^*&=44{,}921.91-42{,}298.75\\ &=2{,}623.16. \end{aligned} \]

คำตอบ: แผนใหม่ขายเต็มเพดานสองวันแรก แล้วระบายที่เหลือแบบ sinh คะแนนแย่ลงจากแผนที่ไม่มีเพดาน (\$42,298.75 จากขั้นแผนที่ดีที่สุด) อยู่ \$2,623.16 นี่คือราคาของการทำตามกฎ

ตรวจเองใน 10 วินาที: $30{,}000+30{,}000+18{,}555+12{,}121+9{,}324=100{,}000$ และไม่มีครั้งไหนเกิน 30,000

ขั้นที่ 11 — ไฟล์ Excel ของคอร์ส: ขาย 1,000 หุ้นใน 10 ครั้งด้วย impact แบบ Kissel–Glantz

คอร์สมีไฟล์ Excel ที่ทำโจทย์แบบเดียวกัน แต่ใช้ impact ที่สมจริงกว่าเส้นตรง และให้ Solver (เครื่องมือหาค่าต่ำสุดที่มากับ Excel) หาแผนแทนสูตร sinh ขั้นนี้อ่านไฟล์นั้นด้วยภาษาของหน้านี้

โจทย์ให้อะไรมาบ้าง:

  • ขาย 1,000 หุ้นใน 10 ครั้ง
  • impact ถาวรเป็นเส้นตรง $g(n)=0.001n$
  • impact ชั่วคราวแบบ Kissel–Glantz จากหน้า market microstructure ต้นทุนต่อครั้งคือ $h(n)n=\alpha n+\delta n^{1.65}$ ก้อน $\alpha n$ โตเป็นเส้นตรง ก้อน $\delta n^{1.65}$ โตเร็วกว่าเส้นตรงเมื่อขายก้อนใหญ่
  • ค่าคงที่ของสูตรเป็นชุดเดียวกับหน้านั้น: $a_1=0.0035$, $\beta=0.65$ (เลขชี้กำลัง 1.65 คือ $1+\beta$), $a_2=0.3$ และ $a_3=0.0015$
  • ไฟล์ใช้หุ้นตัวที่ 1 ซึ่งมีความผันผวนต่อช่วง $\sigma=0.051449$ (5.1449%) และปริมาณซื้อขายต่อวัน $V=10$
  • คะแนนคือต้นทุนชั่วคราว บวกต้นทุนถาวร บวก $\rho$ คูณความแปรปรวน $\sigma^2\sum x_k^2$ โดยน้ำหนักความเสี่ยง $\rho=1$ และ $x_k$ คือหุ้นที่ถือหลังขายแต่ละครั้ง แบบเดียวกับบัญชีเงินที่ได้ด้านบน

เริ่มจากหาค่าคงที่สองตัวของต้นทุนชั่วคราว แล้วเทียบคะแนนของคำตอบจาก Solver กับการขายเท่ากันครั้งละ 100 หุ้น

\[ \begin{aligned} \alpha&=a_2\sigma+a_3\\ &=0.3(0.051449)+0.0015\\ &=0.016935,\\ \delta&=a_1(100/V)^{\beta}\\ &=0.0035(100/10)^{0.65}\\ &=0.0035\times4.4668=0.015634,\\ J_{\rm file}&=1{,}120.73+132.93+66.10\\ &=1{,}319.77,\\ I_{\rm equal}&=10(\alpha\cdot100+\delta\cdot100^{1.65})\\ &=10(1.6935+31.1938)\\ &=328.87,\\ J_{\rm equal}&=328.87+450.00+7{,}543.95\\ &=8{,}322.82. \end{aligned} \]

คำตอบ: Solver ขายครั้งแรก 849.84 หุ้น (85% ของ 1,000) ครั้งที่สอง 104.60 หุ้น แล้วที่เหลือเป็นเศษเล็ก ๆ คะแนนของไฟล์แยกเป็นต้นทุนชั่วคราว 1,120.73 ต้นทุนถาวร 132.93 และความเสี่ยง 66.10 ถ้าขายเท่ากันครั้งละ 100 หุ้น ต้นทุนชั่วคราวน้อยกว่ามาก (328.87) แต่ความเสี่ยงพุ่งเป็น 7,543.95 คะแนนรวมจึงแย่กว่า $8{,}322.82/1{,}319.77=6.3$ เท่า

ทำไมไฟล์เร่งขายมากขนาดนี้ เพราะความเสี่ยงต่อช่วงสูงมาก (5% ต่อช่วง) เมื่อเทียบกับต้นทุนการขาย การถือหุ้นค้างไว้จึงแพงกว่าการขายเร็ว

Solver ของ Excel อาจหยุดก่อนถึงจุดต่ำสุดจริง จึงแก้ซ้ำด้วยอีกวิธี คือเริ่มจากแผนเท่ากัน แล้วย้ายหุ้นระหว่างสองครั้งทีละคู่ไปเรื่อย ๆ ตราบใดที่คะแนนยังลด ได้คะแนน 1,319.71 และครั้งแรก 850.42 หุ้น ใกล้คำตอบของ Solver มาก คำตอบของไฟล์จึงอยู่ใกล้จุดต่ำสุดจริง

ตรวจเองใน 10 วินาที: แผนเท่ากันถือหุ้นหลังขายแต่ละครั้ง 900, 800, …, 100, 0 หุ้น ต้นทุนถาวร $P=\sum g(n_k)x_k$ และความเสี่ยง $W=\sigma^2\sum x_k^2$ คิดได้ในสองสามบรรทัด

\[ \begin{aligned} P&=0.001(100)(900+\dots+0)\\ &=0.1(4{,}500)=450,\\ W&=0.051449^2(900^2+\dots+100^2)\\ &=0.002647(2{,}850{,}000)\\ &=7{,}544. \end{aligned} \]

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

เทียบคะแนนข้ามค่า $c$: คะแนนที่ $c$ ต่างกันวัดด้วยไม้บรรทัดคนละอัน จึงเทียบกันไม่ได้ เช่นแผนเท่ากันที่ $c=10^{-6}$ ได้ \$32,000 ต่ำกว่าแผนเร่งที่ $c=3\times10^{-6}$ (\$43,800) แต่ไม่ได้แปลว่าแผนเท่ากันดีกว่า ถ้าเทียบที่ $c=3\times10^{-6}$ เดียวกัน แผนเท่ากันได้ $20{,}000+3\times10^{-6}\times12{,}000\times10^6=\$56{,}000$ และแพ้แผนเร่ง

ใช้ $\sigma$ รายปีแทนรายช่วง: $c=\lambda\sigma^2$ ต้องใช้ $\sigma$ ของช่วงเดียวกับการขาย ซึ่งที่นี่คือหนึ่งวัน ปีหนึ่งมีวันทำการราว 252 วัน (365 วัน หักเสาร์อาทิตย์ 104 วัน และวันหยุดตลาดราว 9 วัน) ความแปรปรวนของการขยับรายวันที่อิสระกันบวกกันได้ ความแปรปรวนรายปีจึงเป็น $252\sigma^2$ ถ้าใส่ค่ารายปีโดยไม่ตั้งใจ $c$ จะกลายเป็น $252\times10^{-6}$ และ $\kappa^2=252\times10^{-6}/10^{-5}=25.2$ แผนจะขายครั้งแรก 96,319 หุ้น เกือบหมดในวันเดียว ทั้งที่ค่าที่ถูก $c=10^{-6}$ ให้ครั้งแรกแค่ 29,885 หุ้น

ส่งแผนที่ดีที่สุดโดยไม่ตรวจเพดาน: สูตร sinh ไม่รู้จักกฎของโต๊ะ ที่ $c=3\times10^{-6}$ ครั้งแรก 42,299 หุ้นเกินเพดาน 30,000 และถ้าตัดแค่ครั้งแรก ครั้งที่สองจะเกินต่อ (30,315) แผนที่ถูกต้องให้เพดานบังคับสองวันแรก แล้วคิดที่เหลือใหม่ ได้ 30,000, 30,000, 18,555, 12,121, 9,324

อ่านคะแนนเป็นสัญญาว่าจะได้ราคานี้: ที่ $c=10^{-6}$ ต้นทุน impact ที่คาดคือ \$21,698 แต่ SD ของเงินที่ได้คือ $2\sqrt{8{,}186.38\times10^6}=\$180{,}957$ ใหญ่กว่า $180{,}957/21{,}698=8.3$ เท่า ผลของคำสั่งเดียวจึงบอกอะไรเกี่ยวกับฝีมือได้น้อยมาก ต้องวัดคุณภาพการส่งคำสั่งจากค่าเฉลี่ยของหลายคำสั่ง อีกเรื่องคือแบบจำลองใช้พารามิเตอร์คงที่ ถ้ามีข่าวหรือตลาดหยุดซื้อขายระหว่างทาง ต้องมีกฎปรับแผน

ลืมว่า $\lambda$ เป็นสิ่งที่เราเลือก: ค่านี้ค่าเดียวพลิกผู้ชนะในโจทย์เปิดหน้าได้ ที่ $c=10^{-6}$ แผนเท่ากันชนะ \$32,000 ต่อ \$34,600 แต่ที่ $c=3\times10^{-6}$ แผนเร่งชนะ \$43,800 ต่อ \$56,000 จึงต้องบันทึกไว้ก่อนส่งคำสั่งว่าเลือกค่าไหนเพราะอะไร ไม่อย่างนั้นจะมีคนเลือกค่าย้อนหลังให้แผนที่ใช้ไปแล้วดูดีเสมอ

ใช้ทำอะไรบนโต๊ะจริง

ระบบส่งคำสั่งของกองทุนใหญ่ใช้กรอบคิดนี้ตัดสินว่าคำสั่งใหญ่ควรเสร็จในกี่ชั่วโมงหรือกี่วัน ขั้นตอนคร่าว ๆ คือตั้ง $\lambda$ ตามว่าลูกค้าเร่งแค่ไหน แล้วใส่ข้อจำกัดก่อนหาคำตอบ เช่นเพดาน participation ช่วงประมูลตอนเปิดและปิดตลาด (ช่วงที่ตลาดรวบรวมคำสั่งทั้งหมดแล้วจับคู่ที่ราคาเดียว) และช่วงที่ห้ามซื้อขาย

หลังส่งคำสั่งเสร็จ โต๊ะวัดผลด้วย implementation shortfall คือส่วนต่างระหว่างราคาตอนตัดสินใจขายกับราคาเฉลี่ยที่ขายได้จริง และดูค่าเฉลี่ยจากหลายคำสั่ง เพราะคำสั่งเดียวขึ้นกับโชคมากเกินไป

การย้ายทั้งพอร์ต คือซื้อขายหุ้นหลายตัวพร้อมกัน ยากกว่าหุ้นตัวเดียวหลายเรื่อง

  • จำนวนช่วง $T$ เองก็ต้องเลือก ไม่ได้ถูกกำหนดมาให้
  • คำสั่งในหุ้นตัวหนึ่งกระทบราคาหุ้นตัวอื่น เพราะคนตั้งราคาเดามูลค่าของหุ้นตัวหนึ่งจากคำสั่งในหุ้นที่เกี่ยวข้อง หลักฐานที่พบคือผลข้ามหุ้นนี้มักเป็นลบ เล็กลงเมื่อมีผู้เก็งกำไรมาก และใหญ่ขึ้นเมื่อความเห็นในตลาดแตกต่างกันมาก
  • ต้องเลือกระหว่าง market order (ซื้อขายทันทีที่ราคาตลาด) กับ limit order (ตั้งราคาไว้แล้วรอคนมาจับคู่) ซึ่งหน้า order book และ queue position ชั่งให้ดู
  • ต้องตัดสินว่าจะใช้ dark pool ไหม ซึ่งคือที่ซื้อขายที่ไม่แสดงคำสั่งให้คนอื่นเห็นล่วงหน้า
  • ต้องรักษาพอร์ตให้สมดุลระหว่างทาง เช่นขายหุ้นที่ถือไปพร้อมกับซื้อคืนหุ้นที่ชอร์ตไว้ (ยืมมาขายก่อน) ไม่ให้พอร์ตที่ทำไปครึ่งเดียวกลายเป็นเดิมพันด้านเดียว

โจทย์ตรวจความเข้าใจ

1. โต๊ะได้คำสั่งที่เล็กลง: ขาย 60,000 หุ้นในสามวัน วันละครั้ง ตัวคูณ impact เท่าเดิม $\eta=10^{-5}$ และลูกค้าไม่รีบเลย โต๊ะจึงไม่คิดค่าปรับความเสี่ยง ($c=0$) ควรขายอย่างไร และเสียกับ impact เท่าไร ถ้าเทรดเดอร์อยากขาย 30,000, 20,000 และ 10,000 หุ้นแทน จะเสียเพิ่มเท่าไร

เฉลย

กรณีไม่กลัวความเสี่ยงบอกว่าขายเท่ากัน คือครั้งละ $60{,}000/3=20{,}000$ หุ้น แผนอื่นเสียเพิ่ม $\eta\sum d_k^2$ โดยแผน 30, 20, 10 พันหุ้นเบี่ยงจากค่าเฉลี่ย $d_k=+10{,}000,\ 0,\ -10{,}000$

\[\begin{aligned}I&=\eta X^2/T=10^{-5}(6\times10^4)^2/3\\&=10^{-5}\times3.6\times10^9/3=\$12{,}000,\\I_{\rm alt}&=10^{-5}(9+4+1)\times10^8=\$14{,}000,\\\eta\sum d_k^2&=10^{-5}\times2\times10^8=\$2{,}000.\end{aligned}\]

แผนของเทรดเดอร์เสียเพิ่ม $14{,}000-12{,}000=\$2{,}000$ ตรงกับ $\eta\sum d_k^2$ พอดี

2. สมมติหุ้นของโจทย์เปิดหน้าซื้อขายกันน้อยลง จนขายแล้วกดราคาแรงเป็นสองเท่า ($\eta=2\times10^{-5}$) และพร้อมกันนั้นโต๊ะก็คิดค่าปรับความเสี่ยงเป็นสองเท่า ($c=2\times10^{-6}$) แผนที่ดีที่สุดและคะแนนเปลี่ยนอย่างไร

เฉลย

แผนขึ้นกับ $\kappa^2=c/\eta$ เท่านั้น และ $\kappa^2=2\times10^{-6}/(2\times10^{-5})=0.1$ เท่าเดิม แผนจึงเหมือนเดิมทุกหุ้น ครั้งแรกขาย 29,884.60 หุ้น ส่วนคะแนน ทั้งสองก้อนของ $J$ โตสองเท่า คะแนนจึงเป็นสองเท่า ตรวจด้วยสูตร $J^*=\eta Xn_1=2\times10^{-5}(10^5)(29{,}884.60)=\$59{,}769.19$

3. ถ้าคิด impact ถาวร $\gamma=10^{-6}$ ด้วย (ราคาตลาดถูกกดลง $\gamma n$ ค้างไว้หลังขายแต่ละครั้ง) ต้นทุนถาวรของแผนเท่ากันและแผนเร่งของโจทย์เปิดหน้าเป็นเท่าไร และผลต่างนี้ทำให้ผู้ชนะที่ $c=10^{-6}$ และ $c=3\times10^{-6}$ เปลี่ยนไหม

เฉลย

ใช้ $\gamma\sum n_kx_k=\tfrac12\gamma(X^2-\sum n_k^2)$ จากขั้น impact ถาวร โดย $X^2=10^{10}$ แผนเท่ากันมี $\sum n_k^2=5\times(2\times10^4)^2=2\times10^9$ แผนเร่งมี $\sum n_k^2=(1.6+0.9+0.4+0.1)\times10^9=3\times10^9$

\[\begin{aligned}P_{\rm eq}&=0.5(10^{-6})(10^{10}-2\times10^9)\\&=\$4{,}000,\\P_{\rm fr}&=0.5(10^{-6})(10^{10}-3\times10^9)\\&=\$3{,}500.\end{aligned}\]

แผนเร่งจ่ายต้นทุนถาวรน้อยกว่า \$500 ซึ่งคือ $\tfrac12\gamma$ คูณผลต่างของ $\sum n_k^2$ พอดี: $0.5\times10^{-6}\times10^9=500$ ผลคือ impact ส่วนเกินของแผนเร่งลดจาก \$10,000 เหลือ $10{,}000-500=\$9{,}500$ เท่ากับใช้ $\eta-\tfrac12\gamma=0.95\times10^{-5}$ แทน $\eta$ คือย่อ $\eta$ ลง 5% จุดที่ผู้ชนะพลิกจึงเลื่อนจาก $1.35\times10^{-6}$ ไปเป็น $9{,}500/(7.4\times10^9)=1.28\times10^{-6}$ ซึ่งยังอยู่ระหว่าง $10^{-6}$ กับ $3\times10^{-6}$ ผู้ชนะทั้งสองกรณีจึงไม่เปลี่ยน

const {sinh, acosh, abs, pow, sqrt, log, max} = Math;

// Score of a sell schedule n (shares per sale): temporary impact eta n^2, plus c times
// the squared holdings left after each sale (x_1 ... x_{T-1}); c = lambda sigma^2.
function score(n, eta, c) {
  if (!Array.isArray(n) || n.length === 0) throw new TypeError('schedule must be a non-empty array');
  const X = n.reduce((a, b) => a + b, 0);
  let held = X, impact = 0, risk = 0;
  for (const k of n) { impact += eta * k * k; held -= k; risk += held * held; }
  return {impact, risk, J: impact + c * risk};
}
// Optimal schedule in closed form: x_k = X sinh(kt (T - k)) / sinh(kt T) with cosh kt = 1 + c / (2 eta).
function optimal(X, T, eta, c) {
  if (!(eta > 0) || !(c >= 0)) throw new RangeError('eta must be positive and c must not be negative');
  if (!Number.isInteger(T) || T < 1) throw new RangeError('T must be a positive integer');
  const kt = acosh(1 + c / (2 * eta));
  const x = [...Array(T + 1)].map((_, k) => c === 0 ? X * (T - k) / T : X * sinh(kt * (T - k)) / sinh(kt * T));
  return x.slice(1).map((h, i) => x[i] - h);
}
// Check the first-order conditions directly: x_{k+1} + x_{k-1} = (2 + c / eta) x_k for every inside k.
function focResidual(n, eta, c) {
  const x = [n.reduce((a, b) => a + b, 0)];
  for (const k of n) x.push(x[x.length - 1] - k);
  let worst = 0;
  for (let k = 1; k < x.length - 1; k++) worst = max(worst, abs(x[k + 1] + x[k - 1] - (2 + c / eta) * x[k]));
  return worst;
}

const sig = 0.051449003877626245, alpha = 0.3 * sig + 0.0015, delta = 0.0035 * pow(100 / 10, 0.65), gamma = 0.001, rho = 1;
function course(n) {
  let x = 1000, temp = 0, perm = 0, risk = 0;
  for (const k of n) { x -= k; temp += alpha * abs(k) + delta * pow(abs(k), 1.65); perm += gamma * k * x; risk += sig * sig * x * x; }
  return {temp, perm, risk, J: temp + perm + rho * risk};
}

function resolve(n) {
  n = n.slice();
  const g = (sqrt(5) - 1) / 2;
  for (let sweep = 0; sweep < 400; sweep++) {
    let gain = 0;
    for (let i = 0; i < n.length; i++) for (let j = 0; j < n.length; j++) {
      if (i === j || n[i] <= 0) continue;
      const f = t => { const z = n.slice(); z[i] -= t; z[j] += t; return course(z).J; };

    if (gain < 1e-10) break;
  }
  return n;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ความแปรปรวนของเงินที่ได้จากการทยอยขายคือ $\sigma^2\sum x_k^2$ เพราะทุกหุ้นที่ยังถือข้ามช่วงหนึ่งรับการขยับของราคาช่วงนั้นเต็ม ๆ ส่วน impact ถาวรแบบเส้นตรงแค่บวกค่าคงที่ และย่อ $\eta$ เป็น $\eta-\tfrac12\gamma$
  • ถ้าไม่กลัวความเสี่ยง ให้ขายเท่ากัน (เสีย \$20,000 ในโจทย์เปิดหน้า) เพราะต้นทุนต่อหุ้น $\eta X/T$ ลดลงเมื่อใช้เวลานานขึ้น และค่า $c$ ค่าเดียวพลิกผู้ชนะได้: \$32,000 ต่อ \$34,600 ที่ $c=10^{-6}$ กลายเป็น \$56,000 ต่อ \$43,800 ที่ $c=3\times10^{-6}$
  • แผนที่ดีที่สุดคือ $x_k=X\sinh(\tilde\kappa(T-k))/\sinh(\tilde\kappa T)$ โดย $\cosh\tilde\kappa=1+c/(2\eta)$ ที่ $c=10^{-6}$ ครั้งแรกขาย 29,885 หุ้น และคะแนนเท่ากับ $\eta Xn_1$
  • แผนเร่งของเทรดเดอร์เปลืองกว่าแผนบน frontier ที่ความเสี่ยงเท่ากัน \$1,488 เพดาน 15% ของปริมาณซื้อขายทำให้คะแนนแย่ลง \$2,623 และถ้าไม่มีเส้นตาย แผนคือการระบายแบบ exponential ที่หุ้นลดเหลือครึ่งทุก $\ln2/\tilde\kappa=2.2$ วัน
  • ไฟล์ของคอร์สที่ใช้ impact แบบ Kissel–Glantz ขาย 85% ในครั้งแรก ได้คะแนน 1,319.77 เทียบกับ 8,322.82 ของการขายเท่ากัน
