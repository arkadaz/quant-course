27.1 Cross-Sectional Regression and Rank-Deficient Loadings

factor return ไม่มีให้ดาวน์โหลด ต้องหาเองทุกวันจาก regression ที่วิ่งข้ามหุ้นทุกตัวในวันเดียว และถ้ามี market กับ industry อยู่ด้วยกัน สมการจะมีคำตอบที่ดีเท่ากันนับไม่ถ้วน จนกว่าเราจะเลือกเงื่อนไขเอง

แบบจำลองความเสี่ยงของหุ้น 8 ตัวมีห้า factor: market ที่หุ้นทุกตัวมี loading 1, industry สามกลุ่ม (tech, banks, energy) ที่หุ้นแต่ละตัวอยู่กลุ่มเดียว และ momentum นักพัฒนาสั่งไลบรารีหา factor return ของวันนี้ ได้ตัวเลขออกมาโดยไม่มีคำเตือน แล้วรายงานว่า “market วันนี้ −0.03% tech +0.64% ใช้ได้เลย” เชื่อตัวเลขนี้ได้ไหม?

ลองตอบก่อนเปิดเฉลย

ยังไม่ได้ คอลัมน์ market เท่ากับผลรวมของสามคอลัมน์ industry พอดี ห้าคอลัมน์จึงเป็นอิสระกันแค่สี่ สมการมีคำตอบที่ดีเท่ากันนับไม่ถ้วน และไลบรารีเลือกให้หนึ่งคำตอบเงียบ ๆ (คำตอบที่เวกเตอร์สั้นที่สุด: market −0.0324% tech +0.6366%) ถ้าลบคอลัมน์ energy ทิ้งจะได้ −0.6466% กับ +1.2508% ถ้าตั้งเงื่อนไขถ่วงมูลค่าตลาดได้ −0.0666% กับ +0.6708% ทั้งสามชุดทำนายผลตอบแทนหุ้นทุกตัวได้เท่ากันเป๊ะ และให้ momentum 0.4741% เท่ากัน ต่างกันแค่การแบ่งเครดิตระหว่าง market กับ industry ซึ่งต้องเลือกเองอย่างรู้ตัว

ภาพรวมก่อนลงสูตร

ตอนตั้ง สมการ factor model เราใช้ factor return $\mathbf f_t$ ราวกับมีอยู่ในข้อมูล แต่ข้อมูลจริงมีแค่สองอย่าง คือผลตอบแทนของหุ้นทุกตัวในวันนั้น กับคุณสมบัติของบริษัทที่รู้ตั้งแต่เมื่อวาน (loading เช่นอยู่ industry ไหน momentum สูงแค่ไหน) factor return ต้องหาเองจากสองอย่างนี้ ทุกวัน แบบจำลองแบบนี้เรียกว่า fundamental factor model

วิธีหาเห็นได้ในรูปเดียว เอาหุ้นทั้ง 8 ตัวของวันนี้มาวาง แกนนอนคือ momentum loading แกนตั้งคือผลตอบแทนวันนี้ แล้วลากเส้นที่เข้ากับจุดดีที่สุด ความชันของเส้นคือ momentum factor return ของวันนี้ เพราะมันบอกว่าหุ้นที่ momentum มากกว่าหนึ่งหน่วยได้ผลตอบแทนมากกว่ากี่เปอร์เซ็นต์ เพราะหุ้นแต่ละกลุ่มมี industry ของตัวเอง เส้นจึงมีสามเส้นขนานกัน ความสูงของแต่ละเส้นคือ market บวก industry ของกลุ่มนั้น regression นี้วิ่ง “ข้ามหุ้น” ในวันเดียว จึงเรียกว่า cross-sectional regression และทำซ้ำทุกวันจนได้ factor return เป็นอนุกรมเวลา

รูปนี้ซ่อนปัญหาไว้หนึ่งข้อ ข้อมูลบอกความสูงของเส้นได้สามค่า แต่ความสูงแต่ละค่าเป็นผลรวมของสองตัว (market + industry) รวมเป็นตัวไม่รู้สี่ตัว สามสมการสี่ตัวไม่รู้จึงมีคำตอบนับไม่ถ้วน หน้านี้จะตั้งสมการ อธิบายน้ำหนักของแต่ละหุ้น หาทิศที่ข้อมูลมองไม่เห็น เทียบสามทางแก้ด้วยตัวเลข ดูว่า factor return แต่ละตัวคือพอร์ตที่ซื้อได้จริง วัดว่ามันคลาดได้แค่ไหน และแก้ปัญหาไก่กับไข่ของน้ำหนัก

ศัพท์ที่ใช้ในหัวข้อนี้
Cross-sectional regression
regression ที่ข้อมูลแต่ละแถวคือหุ้นหนึ่งตัวในวันเดียวกัน ทำซ้ำทุกวัน ใช้หา factor return ของวันนั้นจากผลตอบแทนของหุ้นทุกตัว
Fundamental factor model
แบบจำลองที่ loading มาจากคุณสมบัติของบริษัท (industry, momentum, ขนาด) ซึ่งรู้ล่วงหน้า ส่วน factor return ต้องประมาณจากข้อมูล ใช้ในแบบจำลองความเสี่ยงเชิงพาณิชย์และงานหา alpha
WLS (weighted least squares)
หาค่าที่ทำให้ผลรวมของความคลาดกำลังสองที่ถ่วงน้ำหนักแล้วน้อยที่สุด ใช้เมื่อข้อมูลแต่ละแถวน่าเชื่อถือไม่เท่ากัน OLS คือกรณีที่น้ำหนักเท่ากันหมด
Rank-deficient
loadings matrix ที่จำนวนคอลัมน์ที่เป็นอิสระกันจริง (rank) น้อยกว่าจำนวนคอลัมน์ ทำให้ regression มีคำตอบที่ดีเท่ากันนับไม่ถ้วน
Null direction
ทิศ $\mathbf v$ ที่ $\mathbf B\mathbf v=\mathbf 0$ บวกเข้าไปในคำตอบกี่เท่าก็ได้โดยคำทำนายของหุ้นทุกตัวไม่เปลี่ยน ใช้บอกว่าข้อมูล “มองไม่เห็น” อะไร
Factor-mimicking portfolio (FMP)
พอร์ตหุ้นที่ผลตอบแทนเท่ากับ factor return ที่ประมาณได้พอดี มี exposure 1 ต่อ factor ของมันและ 0 ต่อ factor อื่น ใช้ซื้อขาย factor ได้จริงและใช้ตรวจว่าตัวเลขแต่ละตัวหมายถึงอะไร
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$\mathbf r$ผลตอบแทนส่วนเกินของหุ้น $n$ ตัวในวันหนึ่ง% ต่อวัน
$\mathbf B$loadings matrix $n\times m$ ที่รู้ตั้งแต่สิ้นวันก่อนหน้าไม่มีหน่วย
$\mathbf f,\ \boldsymbol\epsilon$factor return ที่ต้องหา และ idiosyncratic return% ต่อวัน
$\sigma_i,\ w_i$ความผันผวนเฉพาะตัวของหุ้น $i$ และน้ำหนัก $w_i=1/\sigma_i^2$% ต่อวัน, ต่อ %²
$\mathbf W$matrix แนวทแยงที่มี $w_i$ อยู่บนแนวทแยงต่อ %²
$\mathbf H$matrix ที่แปลงผลตอบแทนหุ้นเป็น factor return ($\hat{\mathbf f}=\mathbf H\mathbf r$) แต่ละแถวคือน้ำหนักของ FMPไม่มีหน่วย
$\mathbf v,\ \mathbf c$null direction และเวกเตอร์ของเงื่อนไขที่เติมไม่มีหน่วย

ขั้นที่ 1 — ข้อมูลของวันนี้ และสมการหนึ่งบรรทัดต่อหุ้นหนึ่งตัว

โจทย์ให้อะไรมาบ้าง: หุ้น 8 ตัว ผลตอบแทนวันนี้ $r$ momentum loading ความผันผวนเฉพาะตัว $\sigma$ (ประมาณไว้ถึงเมื่อวาน) และมูลค่าตลาด ตัวเลขทั้งหมดเป็นข้อมูลสมมติ คอลัมน์ของ $\mathbf B$ เรียงเป็น market (1 ทุกตัว), tech (หุ้น 1–3), banks (หุ้น 4–5), energy (หุ้น 6–8) และ momentum

คำตอบ: หุ้นแต่ละตัวให้สมการหนึ่งบรรทัด แปดบรรทัด ตัวไม่รู้คือ factor return ห้าตัว บวกส่วนเฉพาะตัวแปดตัว เราไม่ได้ “แก้” สมการให้ลงตัว แต่เลือก $\mathbf f$ ที่ทำให้ส่วนที่อธิบายไม่ได้ $\boldsymbol\epsilon$ เล็กที่สุด ซึ่งคือ regression ที่มีหุ้นเป็นแถว loading เป็นคอลัมน์ และ factor return เป็นสัมประสิทธิ์

loading ต้องเป็นข้อมูลที่รู้ ณ สิ้นวันก่อนหน้า ไม่ใช่ของวันนี้ ข้อมูลจากผู้ขายหลายรายประทับวันที่ $t$ ให้ข้อมูลที่รู้ตอนสิ้นวัน $t$ ถ้าเอาไปจับคู่กับผลตอบแทนของวัน $t$ ตรง ๆ ก็คือใช้ข้อมูลที่ยังไม่รู้ตอนต้นวัน ต้องเลื่อนหนึ่งวันเสมอ

ตรวจเองใน 10 วินาที: ทุกแถวของสามคอลัมน์ industry มีเลข 1 ตัวเดียว ผลรวมสามคอลัมน์จึงเป็น 1 ทุกแถว เท่ากับคอลัมน์ market ปัญหาที่จะเจอในขั้นที่ว่าด้วยทิศที่ข้อมูลมองไม่เห็นจึงมองออกได้ก่อนคำนวณ

ขั้นที่ 2 — WLS: หุ้นที่เหวี่ยงน้อยมีเสียงดังกว่า

หุ้นแต่ละตัวมีเสียงรบกวนเฉพาะตัวไม่เท่ากัน หุ้นที่ $\sigma_i$ ใหญ่บอกเรื่อง factor ได้น้อยกว่า วิธีที่ตรงไปตรงมาคือหารสมการของหุ้นแต่ละตัวด้วย $\sigma_i$ ก่อน ให้เสียงรบกวนทุกแถวมีขนาดเท่ากัน แล้วทำ OLS ตามปกติ การหารแบบนี้เท่ากับถ่วงความคลาดกำลังสองด้วย $w_i=1/\sigma_i^2$

\[ \begin{aligned} \frac{r_i}{\sigma_i}&=\frac{(\mathbf B\mathbf f)_i}{\sigma_i}+\frac{\epsilon_i}{\sigma_i},\\ S(\mathbf f)&=\sum_i w_i\big(r_i-(\mathbf B\mathbf f)_i\big)^2,\\ \nabla S&=-2\,\mathbf B^{\mathsf T}\mathbf W(\mathbf r-\mathbf B\mathbf f)=\mathbf 0,\\ \mathbf B^{\mathsf T}\mathbf W\mathbf B\,\hat{\mathbf f}&=\mathbf B^{\mathsf T}\mathbf W\mathbf r,\\ \hat{\mathbf f}&=\mathbf H\mathbf r,\\ \mathbf H&=(\mathbf B^{\mathsf T}\mathbf W\mathbf B)^{-1}\mathbf B^{\mathsf T}\mathbf W. \end{aligned} \]

บรรทัดแรกคือหัวใจ: หลังหารด้วย $\sigma_i$ ส่วนเฉพาะตัวของทุกหุ้นมีความผันผวน 1 เท่ากันหมด ซึ่งเป็นเงื่อนไขที่ OLS ให้ค่าประมาณที่ไม่เอนและผันผวนน้อยที่สุดในบรรดาวิธีเชิงเส้น (Gauss–Markov) การหารทั้งสองข้างของสมการด้วยเลขบวกตัวเดียวกันไม่เปลี่ยนว่า $\mathbf f$ ตัวไหนเป็นคำตอบจริง จึงทำได้เสมอ ผลรวมกำลังสองของสมการที่หารแล้วคือ $S(\mathbf f)$ ในบรรทัดที่สอง

บรรทัดที่สามถึงสี่ได้จากตั้ง gradient ให้เป็นศูนย์ เหมือน normal equations ของ OLS แต่มี $\mathbf W$ คั่นกลาง เพราะค่าประมาณไม่เอน ค่าที่ได้จึงไม่มีความคลาดสะสมเมื่อเอาไปบวกกันหลายร้อยวันใน การแยก PnL เป็นส่วนของ factor กับส่วนเฉพาะตัว ความเอนนิดเดียวต่อวันจะกลายเป็นรายงานที่บิดทั้งปี

บรรทัดสุดท้ายสำคัญกว่าที่เห็น: factor return แต่ละตัวคือผลรวมถ่วงน้ำหนักของผลตอบแทนหุ้น จึงเป็นผลตอบแทนของพอร์ตหนึ่งที่ซื้อได้จริง ขั้นที่ว่าด้วยพอร์ตเลียนแบบ factor จะกางพอร์ตนี้ออกมาดู สูตรนี้ใช้ได้ก็ต่อเมื่อ $\mathbf B^{\mathsf T}\mathbf W\mathbf B$ ผกผันได้ ซึ่งวันนี้มันผกผันไม่ได้

ขั้นที่ 3 — คอลัมน์ที่บวกกันได้อีกคอลัมน์: dummy variable trap

industry เป็นคอลัมน์ 0 กับ 1 (dummy) หุ้นทุกตัวอยู่หนึ่ง industry พอดี บวกสามคอลัมน์จึงได้ 1 ทุกแถว ซึ่งคือคอลัมน์ market ข้อมูลจึงแยกไม่ออกว่าผลตอบแทนส่วนหนึ่งมาจาก market หรือมาจาก industry ทุกกลุ่มพร้อมกัน ขั้นนี้เขียนความซ้ำนั้นเป็นทิศหนึ่งทิศ

\[ \begin{aligned} \mathbf b_{\text{tech}}+\mathbf b_{\text{banks}}+\mathbf b_{\text{energy}}&=\mathbf b_{\text{mkt}},\\ \mathbf v&=(1,\ -1,\ -1,\ -1,\ 0),\\ \mathbf B\mathbf v&=\mathbf 0,\\ \operatorname{rank}(\mathbf B)&=4\lt 5,\\ \mathbf B(\hat{\mathbf f}+s\,\mathbf v)&=\mathbf B\hat{\mathbf f}+s\,\mathbf B\mathbf v\\ &=\mathbf B\hat{\mathbf f}. \end{aligned} \]

อ่าน $\mathbf v$ เป็นภาษาคนว่า “เพิ่ม market หนึ่งหน่วย แล้วลดทุก industry หนึ่งหน่วย” หุ้นทุกตัวได้ market มาหนึ่งและเสีย industry ของตัวเองไปหนึ่ง ผลรวมเป็นศูนย์ ตำแหน่งสุดท้ายเป็นศูนย์ momentum จึงไม่เกี่ยวกับความกำกวมนี้เลย

บรรทัดสุดท้ายบอกผลที่ตามมา: ถ้า $\hat{\mathbf f}$ เป็นคำตอบที่ดีที่สุด $\hat{\mathbf f}+s\mathbf v$ ก็ดีที่สุดเท่ากันทุกค่า $s$ เพราะคำทำนายของหุ้นทุกตัวเหมือนเดิม และ $\mathbf B^{\mathsf T}\mathbf W\mathbf B\,\mathbf v=\mathbf 0$ ด้วย matrix นี้จึงผกผันไม่ได้ บางไลบรารีหยุดและเตือน บางไลบรารีคืนตัวเลขมาเงียบ ๆ อย่างหลังอันตรายกว่า เพราะไม่มีใครรู้ว่ามันเลือก $s$ ไปเท่าไร

ปัญหาเดียวกันเกิดกับกลุ่มคอลัมน์ใด ๆ ที่รวมกันเป็นคอลัมน์อื่นได้ เช่น factor ประเทศที่หุ้นแต่ละตัวอยู่ประเทศเดียว บวกกับ factor โลก (1 ทุกตัว) หรือ industry กับประเทศอยู่ด้วยกันในแบบจำลองหลายประเทศ

ขั้นที่ 4 — ข้อมูลกำหนดอะไรได้ และอะไรที่ยังลอยอยู่

ก่อนเลือกทางแก้ ควรรู้ว่าทุกคำตอบที่ดีที่สุดตกลงกันเรื่องอะไรบ้าง ถ้าดูรูปภาพรวม ข้อมูลกำหนดความชันและความสูงของสามเส้นได้ชัดเจน ความสูงแต่ละค่าคือผลรวมของ market กับ industry หนึ่งตัว ค่าเหล่านี้หาได้โดยลบคอลัมน์ energy ทิ้งชั่วคราวแล้วแก้ WLS ตามปกติ (ทำครบในขั้นที่ให้ตัวเลขจากสามทาง)

\[ \begin{aligned} f_{\text{mkt}}+f_{\text{tech}}&=0.6042\%,\\ f_{\text{mkt}}+f_{\text{banks}}&=-0.0873\%,\\ f_{\text{mkt}}+f_{\text{energy}}&=-0.6466\%,\\ f_{\text{mom}}&=0.4741\%. \end{aligned} \]

สี่สมการ ห้าตัวไม่รู้ เหลือปุ่มหมุนอิสระหนึ่งปุ่ม คือ $f_{\text{mkt}}$ จะเลือก $f_{\text{mkt}}$ เท่าไรก็ได้ แล้ว industry ทั้งสามจะปรับตามให้ผลรวมยังเท่าเดิม ปุ่มนี้คือการเลื่อนไปตามทิศ $\mathbf v$ ที่เพิ่งหาได้นั่นเอง

ส่วนที่ไม่ลอยคือ momentum กับคำทำนายของหุ้นทุกตัว ดังนั้นความเสี่ยงของพอร์ตใด ๆ และ idiosyncratic return ของหุ้นทุกตัวไม่ขึ้นกับการเลือกนี้ สิ่งที่ขึ้นกับการเลือกคือ “เรื่องเล่า” ว่าวันนี้ market ขึ้นหรือลง และ industry ไหนชนะ ซึ่งเป็นสิ่งที่ผู้จัดการพอร์ตอ่านทุกเช้า

ขั้นที่ 5 — สามทางแก้ ต่างกันที่ข้อมูลชิ้นที่เติม

ทุกทางแก้เติมข้อมูลหนึ่งชิ้นเพื่อปักหมุดหนึ่งจุดบนเส้นของคำตอบที่ดีเท่ากัน ชิ้นนั้นอาจเป็นการทิ้งคอลัมน์ การลงโทษคำตอบที่ยาว หรือเงื่อนไขที่มีความหมายทางธุรกิจ

\[ \begin{aligned} \text{A}&:\ f_{\text{energy}}=0,\\ \text{B}&:\ \hat{\mathbf f}_\delta=(\mathbf B^{\mathsf T}\mathbf W\mathbf B+\delta\mathbf I)^{-1}\mathbf B^{\mathsf T}\mathbf W\mathbf r,\\ &\quad \delta\to0:\ \hat{\mathbf f}=(\mathbf B^{\mathsf T}\mathbf W\mathbf B)^{+}\,\mathbf B^{\mathsf T}\mathbf W\mathbf r,\\ \text{C}&:\ \mathbf c^{\mathsf T}\mathbf f=0,\\ c_{\text{tech}}&=700/2040=0.3431,\\ c_{\text{banks}}&=550/2040=0.2696,\\ c_{\text{energy}}&=790/2040=0.3873. \end{aligned} \]

ทาง A ลบคอลัมน์หนึ่งทิ้ง แล้วใช้สูตร WLS เดิมได้เลย ง่ายที่สุด แต่ industry ที่เหลือกลายเป็น “เทียบกับ energy” และ industry ที่ถูกลบไม่มีตัวเลขของตัวเอง ลองนึกถึงผู้จัดการพอร์ตที่ดูแลหุ้น energy แล้วถูกบอกว่า industry ของเขาไม่มีในแบบจำลอง

ทาง B บวกบทลงโทษเล็ก ๆ $\delta\lVert\mathbf f\rVert^2$ เข้าไป (ridge) matrix จึงผกผันได้ แต่ค่าที่ได้เอนเล็กน้อย พอ $\delta$ เข้าใกล้ศูนย์ คำตอบเข้าหาคำตอบของ pseudo-inverse ($^{+}$) ซึ่งเลือกเวกเตอร์ที่สั้นที่สุดในบรรดาคำตอบที่ดีที่สุดทั้งหมด ไลบรารีหลายตัวทำแบบนี้เงียบ ๆ ฟังดูเป็นกลาง แต่ “ความยาวของเวกเตอร์” ไม่มีความหมายทางธุรกิจ และเปลี่ยนไปเมื่อจำนวน industry เปลี่ยน

ทาง C ตั้งเงื่อนไขว่าผลตอบแทนของ industry ถ่วงด้วยสัดส่วนมูลค่าตลาดรวมเป็นศูนย์ $\mathbf c$ มีค่าเฉพาะสามช่องของ industry คือสัดส่วนมูลค่าของ tech (\$700 ล้าน), banks (\$550 ล้าน) และ energy (\$790 ล้าน) จากทั้งหมด \$2,040 ล้าน ความหมายคือพอร์ตทั้งตลาดตามมูลค่าไม่ได้หรือเสียอะไรจาก industry ทุกอย่างของมันมาจาก market market factor จึงเป็นผลตอบแทนของตลาดจริง แก้ได้ด้วย ตัวคูณ Lagrange หนึ่งตัว: เติมเงื่อนไขเป็นแถวและคอลัมน์ใหม่ของ normal equations

ขั้นที่ 7 — factor return คือพอร์ตที่ซื้อได้: กางน้ำหนักออกมาดู

สูตร WLS บอกว่า $\hat{\mathbf f}=\mathbf H\mathbf r$ แถวที่ $k$ ของ $\mathbf H$ จึงเป็นน้ำหนักของพอร์ตหุ้นที่ผลตอบแทนเท่ากับ factor return ตัวที่ $k$ พอดี เรียกว่า factor-mimicking portfolio ขั้นนี้กางแถวเหล่านั้นออกมา แล้วใช้มันเปิดโปงว่าทาง A กับทาง C ต่างกันที่ไหนจริง ๆ

\[ \begin{aligned} \mathbf H\mathbf B&=(\mathbf B^{\mathsf T}\mathbf W\mathbf B)^{-1}\mathbf B^{\mathsf T}\mathbf W\mathbf B=\mathbf I,\\ \textstyle\sum_i h_{\text{mom},i}&=0,\\ \textstyle\sum_i h_{\text{mom},i}\,\text{mom}_i&=1,\\ \textstyle\sum_i h_{\text{mom},i}\,r_i&=0.4741\%. \end{aligned} \]

บรรทัดแรกคือเหตุที่พอร์ตเหล่านี้ “บริสุทธิ์”: $\mathbf H\mathbf B=\mathbf I$ แปลว่าพอร์ตของ factor ที่ $k$ มี exposure 1 ต่อ factor ของตัวเอง และ 0 ต่อ factor อื่นทั้งหมด ในบรรดาพอร์ตที่มี exposure แบบนี้ พอร์ตนี้มีความเสี่ยงเฉพาะตัวต่ำที่สุด เพราะสร้างจากน้ำหนัก $1/\sigma_i^2$ เดียวกัน

พอร์ตของ momentum ซื้อหุ้นที่ momentum สูง ขายหุ้นที่ momentum ต่ำ ใช้เงินสุทธิศูนย์ (exposure ต่อ market เป็นศูนย์) และได้ 0.4741% พอดีวันนี้ คอลัมน์นี้เหมือนกันทั้งทาง A และทาง C เพราะ momentum ไม่ลอย

สองคอลัมน์ทางขวาคือเรื่องสำคัญ: พอร์ตของ “market” ในทาง A ลงเงินเกือบทั้งหมดในหุ้น energy สามตัว ($0.216+0.494+0.290=1.000$) ส่วนในทาง C เป็นพอร์ตซื้ออย่างเดียวที่กระจายทั่วทั้งแปดตัว ใกล้เคียงการถือทั้งตลาด ใครอ่านรายงานทาง A ว่า market ลง 0.65% จะเข้าใจผิดทั้งห้อง เพราะสิ่งที่ลงคือหุ้น energy

ขั้นที่ 8 — ตัวเลขที่ได้คลาดได้แค่ไหน และทำไม WLS คลาดน้อยกว่า OLS

factor return ที่ได้เป็นค่าประมาณจากหุ้นไม่กี่ตัวในวันเดียว จึงมีความคลาดของมันเอง ถ้า $w_i$ คือหนึ่งส่วนความแปรปรวนเฉพาะตัวที่ถูกต้อง สูตร covariance ของค่าประมาณสั้นมาก และขนาดของมันคือสิ่งที่ การประมาณ factor covariance matrix ต้องหักออกในหน้าถัดไป (เขียนบนทาง A ซึ่ง matrix ผกผันได้)

\[ \begin{aligned} \operatorname{var}(\hat{\mathbf f})&=(\mathbf B^{\mathsf T}\mathbf W\mathbf B)^{-1},\\ \operatorname{SE}(\hat f_{\text{mom}})&=1.02\%,\\ \operatorname{SE}^{\text{OLS}}(\hat f_{\text{mom}})&=1.03\%,\\ \operatorname{SE}^{\text{OLS}}(\hat f_{\text{banks}})&=2.04\%\ \text{vs}\ 1.98\%. \end{aligned} \]

บรรทัดแรกมาจากแทน $\mathbf r=\mathbf B\mathbf f+\boldsymbol\epsilon$ ลงใน $\hat{\mathbf f}=\mathbf H\mathbf r$: ได้ $\hat{\mathbf f}=\mathbf f+\mathbf H\boldsymbol\epsilon$ เพราะ $\mathbf H\mathbf B=\mathbf I$ ส่วนที่คลาดคือ $\mathbf H\boldsymbol\epsilon$ ซึ่งมี covariance $\mathbf H\,\mathbf W^{-1}\mathbf H^{\mathsf T}$ คูณออกมาแล้วเหลือ $(\mathbf B^{\mathsf T}\mathbf W\mathbf B)^{-1}$ ถ้ามีหุ้นมาก ทุกช่องของ $\mathbf B^{\mathsf T}\mathbf W\mathbf B$ ใหญ่ขึ้นตามจำนวนหุ้น ความคลาดจึงหดลง

บรรทัดที่สองคือข่าวร้ายของโจทย์เล็ก: ด้วยหุ้นแปดตัว momentum 0.47% มีความคลาดมาตรฐาน 1.02% ใหญ่กว่าตัวมันเอง แยกจากศูนย์ไม่ได้เลย ในตลาดจริงที่มีราว 3,000 ตัวและ loading กระจายพอ ๆ กัน ความคลาดหดราว $\sqrt{3000/8}\approx19.4$ เท่า เหลือประมาณ 0.05% ต่อวัน (เป็นการประมาณคร่าว ๆ ที่สมมติว่าตลาดใหญ่หน้าตาเหมือนแปดตัวนี้ซ้ำหลายรอบ)

สองบรรทัดหลังเทียบกับ OLS ที่ไม่ถ่วง OLS ไม่ได้เอน แต่คลาดมากกว่า ความแปรปรวนของมันสูงกว่า WLS 3% ถึง 9% ในโจทย์นี้ ซึ่งความผันผวนเฉพาะตัวห่างกันแค่ 1.5% ถึง 2.6% ในตลาดจริงที่หุ้นใหญ่เงียบ 1% แต่หุ้นเล็กเหวี่ยง 5% น้ำหนักต่างกันถึง 25 เท่า และ OLS จะปล่อยให้หุ้นเล็กที่มีเสียงรบกวนมากครอบงำค่าประมาณ ตัวเลขรายวันของสองวิธีห่างกันมากที่สุด 0.06 จุดที่ banks ซึ่งมีหุ้นแค่สองตัว และหนึ่งในนั้นเหวี่ยงที่สุด

ขั้นที่ 9 — ไก่กับไข่: น้ำหนักมาจากผลลัพธ์ของตัวเอง

WLS ต้องใช้ $\sigma_i$ แต่ $\sigma_i$ คือความผันผวนของ idiosyncratic return ซึ่งจะมีได้ก็ต่อเมื่อหา factor return เสร็จแล้ว ทางออกมีสองแบบ แบบแรกยืมความผันผวนเฉพาะตัวจากแบบจำลองสำเร็จรูปของผู้ขายมาใช้ แบบที่สองวนสองรอบในช่วงเริ่มต้น แล้วใช้ค่าของเมื่อวานตลอดไป

\[ \begin{aligned} \text{pass 1}&:\ w_i=1,\\ &\quad \hat{\mathbf f}^{(1)}\to\hat{\boldsymbol\epsilon}^{(1)}\to\hat\sigma_i^{(1)},\\ \text{pass 2}&:\ w_i=1/\big(\hat\sigma_i^{(1)}\big)^2,\\ &\quad \hat{\mathbf f}^{(2)}\to\hat\sigma_i^{(2)},\\ \text{day }t&:\ w_{i,t}=1/\hat\sigma_{i,t-1}^2. \end{aligned} \]

รอบแรกไม่ถ่วงเลย (OLS) เพื่อให้ได้ idiosyncratic return ชุดแรกตลอดช่วงเริ่มต้น เช่นปีแรก 252 วันทำการ แล้วใช้มันคำนวณความผันผวนเฉพาะตัวของแต่ละหุ้น (idiosyncratic covariance สอนวิธีคำนวณให้ดี) รอบที่สองใช้ความผันผวนนั้นเป็นน้ำหนัก ค่าประมาณที่ได้แม้ไม่ใช่ความผันผวนที่ดีที่สุด ก็ยังดีกว่าการถ่วงเท่ากันซึ่งคือ OLS หลังจากช่วงเริ่ม ทุกวันใช้ค่าที่ประมาณได้ถึงเมื่อวาน เพราะความผันผวนเฉพาะตัวเปลี่ยนช้า

คำว่า “ถึงเมื่อวาน” สำคัญ ถ้าเผลอใช้ความผันผวนที่รวมวันนี้ หุ้นที่บังเอิญเหวี่ยงแรงวันนี้จะได้น้ำหนักต่ำ แบบจำลองก็เหมือนรู้ล่วงหน้าว่าใครจะเหวี่ยง idiosyncratic return ที่ได้จะเล็กเกินจริง และความเสี่ยงที่รายงานก็ต่ำเกินจริงตาม

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ปล่อยให้ไลบรารีเลือกเอง: ได้ทาง B โดยไม่รู้ตัว market −0.0324% ที่ไม่มีใครอธิบายได้ว่ามาจากเงื่อนไขอะไร และวันที่จำนวน industry เปลี่ยน คำตอบสั้นที่สุดก็เปลี่ยนนิยามไปด้วย

เปลี่ยนเงื่อนไขกลางประวัติข้อมูล: ถ้าเคยใช้ทาง A แล้วเปลี่ยนเป็นทาง C ทุก factor ยกเว้น momentum จะกระโดด 0.58 จุดในวันที่เปลี่ยน ทั้งที่ไม่มีอะไรเกิดในตลาด การทดสอบย้อนหลังที่คร่อมวันนั้นจะเห็นเหตุการณ์ปลอม

ใช้ข้อมูลของวันนี้ทำน้ำหนักหรือ loading ของวันนี้: idiosyncratic return เล็กเกินจริง ความเสี่ยงที่รายงานต่ำเกินจริงตาม และ backtest ได้ข้อมูลที่ยังไม่รู้ ณ เวลานั้น ตรวจทุกครั้งว่าข้อมูลที่ประทับวันที่ $t$ ของผู้ขายหมายถึงรู้ตอนต้นหรือตอนสิ้นวัน

industry ที่เหลือหุ้นตัวเดียว: factor ของ industry นั้นจะดูดผลตอบแทนของหุ้นตัวนั้นไปหมด idiosyncratic return ของมันเป็นศูนย์ทุกวัน ความผันผวนเฉพาะตัวที่ประมาณได้เข้าหาศูนย์ และน้ำหนัก $1/\sigma^2$ ของวันถัดไปพุ่งไม่มีขอบเขต ต้องรวม industry เล็กเข้ากับกลุ่มใกล้เคียง

ใช้ทำอะไรบนโต๊ะจริง

ทีมแบบจำลองความเสี่ยงรัน regression นี้ทุกคืนบนหุ้นหลายพันตัว ในสายงานหกขั้น: รับข้อมูลและตรวจความถูกต้อง เลือกจักรวาลหุ้นที่สภาพคล่องพอให้ราคาเชื่อถือได้และซื้อขายได้จริง (เพราะ FMP ถือหุ้นทุกตัวในจักรวาล) จัดการค่าผิดปกติด้วย winsorization สร้าง loading ทำ cross-sectional regression รายวัน แล้วประมาณ factor covariance กับ idiosyncratic covariance จากอนุกรมเวลาที่ได้ ทีมเลือกทาง C ครั้งเดียวแล้วไม่เปลี่ยน ใช้น้ำหนักจากความผันผวนเฉพาะตัวของเมื่อวาน และตรวจ rank ของ $\mathbf B$ ทุกวัน เพราะหุ้นที่เข้าออกจากกลุ่มอาจสร้างคอลัมน์ซ้ำใหม่ได้

โจทย์ตรวจความเข้าใจ

1. ถ้าลบคอลัมน์ tech ทิ้งแทน energy ค่า market, banks และ energy จะเป็นเท่าไร (ใช้ความจริงที่ว่าทุกคำตอบต่างกันแค่ในทิศ $\mathbf v$)?

เฉลย

เริ่มจากทาง C แล้วบวก $s\mathbf v$ จน tech เป็นศูนย์: $0.6708-s=0$ จึง $s=0.6708$ market $=-0.0666+0.6708=0.6042\%$ banks $=-0.0207-0.6708=-0.6915\%$ energy $=-0.5800-0.6708=-1.2508\%$ momentum ยังเป็น 0.4741% ตรวจด้วยความสูงของเส้น: market + banks $=0.6042-0.6915=-0.0873$ และ market + energy $=0.6042-1.2508=-0.6466$ ตรงกับที่ข้อมูลกำหนด ทางนี้ทำให้ “market” กลายเป็นหุ้น tech ที่ momentum เป็นศูนย์

2. แบบจำลองหลายประเทศมี industry 10 ตัวและประเทศ 4 ประเทศ หุ้นทุกตัวอยู่หนึ่ง industry และหนึ่งประเทศ ไม่มี market factor ยังมี null direction ไหม ถ้ามีคืออะไร และถ้าเพิ่ม market factor เข้าไปอีกจะต้องเติมเงื่อนไขกี่ข้อ?

เฉลย

มี ผลรวมคอลัมน์ industry เป็น 1 ทุกแถว และผลรวมคอลัมน์ประเทศก็เป็น 1 ทุกแถว ทิศ $\mathbf v$ ที่ใส่ +1 ทุก industry และ −1 ทุกประเทศจึงให้ $\mathbf B\mathbf v=\mathbf 0$ (หุ้นทุกตัวได้ +1 จาก industry ของตัวเองและ −1 จากประเทศของตัวเอง) ต้องเติมหนึ่งเงื่อนไข ถ้าเพิ่ม market เข้าไปจะมี null direction สองทิศ: (market +1, ทุก industry −1) และ (market +1, ทุกประเทศ −1) rank ขาดสอง ต้องเติมสองเงื่อนไข เช่นให้ industry ถ่วงมูลค่ารวมเป็นศูนย์ และประเทศถ่วงมูลค่ารวมเป็นศูนย์

3. ถ้าความผันผวนเฉพาะตัวของหุ้นในตลาดอยู่ระหว่าง 1% ถึง 4% ต่อวัน หุ้นที่เงียบที่สุดได้น้ำหนักกี่เท่าของตัวที่เหวี่ยงที่สุด และถ้าจำนวนหุ้นเพิ่มจาก 8 เป็น 800 ตัวโดยหน้าตาข้อมูลเหมือนเดิม ความคลาดมาตรฐานของ momentum จะเหลือเท่าไร?

เฉลย

น้ำหนักห่างกัน $(4/1)^2=16$ เท่า (ถ้ากว้าง 1% ถึง 5% เป็น 25 เท่า) การถ่วงจึงสำคัญกว่าในโจทย์แปดตัวที่ห่างกันแค่ 3 เท่ามาก ส่วนความคลาด: ทุกช่องของ $\mathbf B^{\mathsf T}\mathbf W\mathbf B$ ใหญ่ขึ้น 100 เท่า covariance ของค่าประมาณจึงเล็กลง 100 เท่า ความคลาดมาตรฐานเล็กลง $\sqrt{100}=10$ เท่า จาก 1.02% เหลือประมาณ 0.10%

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
// One day, 8 stocks; loadings = market, tech, banks, energy, momentum (made-up data)
const industry = [0, 0, 0, 1, 1, 2, 2, 2];
const mom = [1.2, -0.4, 0.6, -1.4, 0.9, -0.7, 0.3, -0.5];
const r = [1.20, 0.35, 0.90, -0.60, 0.25, -1.10, -0.40, -0.95];   // percent
const sig = [1.8, 2.2, 1.5, 2.6, 2.0, 2.4, 1.7, 2.1];             // idio vol, percent
const cap = [300, 180, 220, 400, 150, 260, 340, 190];             // $ million
const w = sig.map(s => 1 / s ** 2);
const B = industry.map((g, i) => [1, +(g === 0), +(g === 1), +(g === 2), mom[i]]);

const T = A => A[0].map((_, j) => A.map(row => row[j]));
const mul = (A, C) => A.map(row => C[0].map((_, j) => row.reduce((s, a, k) => s + a * C[k][j], 0)));
function solve(A, b) {                       // Gaussian elimination, refuses a singular A
  const n = A.length, M = A.map((row, i) => [...row, b[i]]);
  for (let k = 0; k < n; k++) {
    let p = k;
    for (let i = k + 1; i < n; i++) if (Math.abs(M[i][k]) > Math.abs(M[p][k])) p = i;
    if (Math.abs(M[p][k]) < 1e-12) throw new RangeError('singular: factors not identified');
    [M[k], M[p]] = [M[p], M[k]];
    for (let i = k + 1; i < n; i++) { const f = M[i][k] / M[k][k]; for (let j = k; j <= n; j++) M[i][j] -= f * M[k][j]; }
  }
  const x = new Array(n).fill(0);
  for (let i = n - 1; i >= 0; i--) x[i] = (M[i][n] - M[i].slice(i + 1, n).reduce((s, a, j) => s + a * x[i + 1 + j], 0)) / M[i][i];
  return x;
}
const inv = A => T(A.map((_, i) => solve(A, A.map((_, j) => +(i === j)))));
const normal = (X, wt, y) => {               // B'WB and B'Wy
  const XW = T(X).map(row => row.map((x, i) => x * wt[i]));
  return [mul(XW, X), XW.map(row => row.reduce((s, x, i) => s + x * y[i], 0))];
};

// A: drop the energy column
const BA = B.map(b => [b[0], b[1], b[2], b[4]]);
const [GA, gA] = normal(BA, w, r);
const fA = solve(GA, gA);
// C: cap-weighted industry returns sum to zero, one Lagrange multiplier
const total = cap.reduce((a, b) => a + b);
const c = [0, ...[0, 1, 2].map(g => cap.filter((_, i) => industry[i] === g).reduce((a, b) => a + b) / total), 0];
const [G] = normal(B, w, r);
const K = G.map((row, i) => [...row, c[i]]).concat([[...c, 0]]);
const fit = y => solve(K, [...normal(B, w, y)[1], 0]).slice(0, 5);
const fC = fit(r);
// B: slide C along v to the shortest vector
const v = [1, -1, -1, -1, 0];
const s = -fC.reduce((t, x, j) => t + x * v[j], 0) / 4;
const fB = fC.map((x, j) => x + s * v[j]);
// FMPs: rows of H; market FMP under C from unit returns
const HA = mul(inv(GA), T(BA).map(row => row.map((x, i) => x * w[i])));
const mktC = r.map((_, i) => fit(r.map((_, k) => +(k === i)))[0]);
// precision: WLS standard errors, and OLS for comparison
const seWLS = inv(GA).map((row, k) => Math.sqrt(row[k]));
const [GO, gO] = normal(BA, w.map(() => 1), r);
const fOLS = solve(GO, gO);
const round = a => a.map(x => +x.toFixed(4));
console.log({ fA: round(fA), fC: round(fC), fB: round(fB), momFMP: round(HA[3]),
  mktFMP_A: round(HA[0]), mktFMP_C: round(mktC), seWLS: round(seWLS), fOLS: round(fOLS) });

สิ่งที่ควรตอบได้หลังอ่าน

  • factor return หาจาก WLS ข้ามหุ้นทุกวัน: ในรูป scatter มันคือความชันของเส้น ถ่วงด้วย $1/\sigma_i^2$ เพราะหารสมการด้วย $\sigma_i$ ทำให้เสียงรบกวนทุกแถวเท่ากัน
  • market บวก industry ที่รวมเป็นหนึ่งทำให้ rank ขาดหนึ่งเสมอ ทิศที่หายคือ “เพิ่ม market ลดทุก industry” ข้อมูลกำหนดได้แค่ผลรวม market + industry ของแต่ละกลุ่ม
  • ทุกทางแก้ต่างกันแค่ในทิศนั้น: momentum คำทำนาย ความเสี่ยงและ idiosyncratic return เท่ากันเป๊ะ ต่างแค่การแบ่งเครดิต จึงต้องเลือกครั้งเดียวแล้วไม่เปลี่ยน
  • แต่ละ factor return คือผลตอบแทนของพอร์ตที่ซื้อได้ ($\mathbf H\mathbf B=\mathbf I$) ทาง A ทำให้พอร์ต market เป็นพอร์ต energy ทาง C ทำให้มันใกล้พอร์ตทั้งตลาด
  • ค่าประมาณมีความคลาด $(\mathbf B^{\mathsf T}\mathbf W\mathbf B)^{-1}$ ซึ่งหดตามจำนวนหุ้น และน้ำหนักต้องมาจากความผันผวนเฉพาะตัวถึงเมื่อวาน: วนสองรอบตอนเริ่ม แล้ววันละรอบ

ตอนนี้เรามี factor return วันละชุด หน้าถัดไป การประมาณ factor covariance matrix เอาอนุกรมนี้มาสร้าง covariance ซึ่งฟังดูเป็นแค่ค่าเฉลี่ยของผลคูณ แต่ต้องหักความคลาดที่เพิ่งวัดได้ออก ให้น้ำหนักข้อมูลใหม่มากกว่าเก่า และแก้ autocorrelation ก่อน
