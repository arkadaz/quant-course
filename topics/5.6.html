5.6 Conditional Independence and the Gaussian Copula

ลูกหนี้หลายรายอาจอิสระกันเมื่อรู้ภาวะเศรษฐกิจแล้ว แต่เพราะทุกรายเผชิญภาวะเดียวกัน การผิดนัดจึงกองรวมกันเมื่อมองข้ามทุกภาวะ และ Gaussian copula คือวิธีเขียนความคิดนี้เป็นแบบจำลอง

desk เครดิตถือหุ้นกู้ของสองบริษัทที่ไม่ได้ค้าขายกันเลย ทีมเศรษฐศาสตร์ (สมมติ) บอกว่าปีหน้าเศรษฐกิจดีด้วยโอกาส 70% และแย่ 30% ถ้าเศรษฐกิจดี แต่ละบริษัทผิดนัดด้วยโอกาส 2% ถ้าแย่ โอกาสนี้เป็น 20% และเมื่อรู้ภาวะแล้ว ชะตาของสองบริษัทไม่เกี่ยวกัน หัวหน้า desk ถามว่าโอกาสที่ทั้งสองบริษัทผิดนัดในปีหน้าเป็นเท่าไร นักวิเคราะห์คนหนึ่งคำนวณโอกาสผิดนัดรายตัวก่อน ได้ 7.4% แล้วยกกำลังสอง ได้ 0.548%

ลองตอบก่อนเปิดเฉลย

คำตอบคือ 1.228% สูงกว่า 0.548% ถึง 2.24 เท่า ต้องคูณภายในแต่ละภาวะก่อน: ภาวะดีได้ $0.02\times0.02=0.04\%$ ภาวะแย่ได้ $0.20\times0.20=4\%$ แล้วจึงเฉลี่ยข้ามภาวะ: $0.7(0.04\%)+0.3(4\%)=1.228\%$ การยกกำลังสอง 7.4% คือการทำกลับลำดับ (เฉลี่ยก่อนแล้วค่อยคูณ) ซึ่งทิ้งข้อเท็จจริงที่สำคัญที่สุดไป: เมื่อบริษัทหนึ่งเจอภาวะแย่ อีกบริษัทก็เจอภาวะแย่ด้วย

ภาพรวมก่อนลงสูตร

independence แบบไม่มีเงื่อนไขแทบไม่เคยจริงในเครดิต แต่ conditional independence มักใกล้ความจริงกว่ามาก: ถ้ารู้แล้วว่าเศรษฐกิจเป็นอย่างไร สิ่งที่เหลือ เช่นผู้บริหารพลาดหรือโรงงานไฟไหม้ เป็นเรื่องเฉพาะบริษัทที่ไม่เกี่ยวกัน ท่าคำนวณจึงเป็นสองชั้นแบบเดียวกับ tower property: ตรึงภาวะเศรษฐกิจ คูณโอกาสรายตัวภายในภาวะนั้น แล้วเฉลี่ยข้ามภาวะ

รูปด้านล่างแสดงสองชั้นนี้ ชั้นบนคือต้นไม้ของภาวะเศรษฐกิจ แต่ละกิ่งมีแท่งยาวเท่ากับโอกาสผิดนัดพร้อมกันในภาวะนั้น ชั้นล่างเทียบคำตอบที่ได้จากการเฉลี่ยข้ามภาวะกับคำตอบจากการคูณโอกาสรายตัวเฉลี่ย ภาวะแย่ที่เกิดแค่ 30% คือผู้กำหนดคำตอบ

หน้านี้จะนิยาม conditional independence แล้วขยายจากสองภาวะเป็นภาวะต่อเนื่องด้วย Gaussian copula แบบจำลองนี้ตรึงโอกาสผิดนัดรายตัวไว้ตามข้อมูลตลาด แล้วใช้ตัวเลขเดียว $\rho$ ควบคุมว่าการผิดนัดกองรวมกันมากแค่ไหน จากนั้นจะนับจำนวนผิดนัดในพอร์ตหุ้นกู้ 125 ตัว ดูว่าใครรับความเสียหายใน tranche แต่ละชั้น และแยกสามปริมาณที่ชื่อคล้ายกันแต่คนละเรื่อง คือ latent correlation, default correlation และ tail dependence

ศัพท์ที่ใช้ในหัวข้อนี้
Conditional independence
สองตัวแปรอิสระกันเมื่อรู้ค่าของตัวแปรที่สาม (ปัจจัยร่วม) แล้ว แต่ก่อนรู้ปัจจัยนั้นอาจพึ่งพากันได้มาก ใช้แตกโอกาสร่วมของหลายตัวให้เป็นผลคูณที่คำนวณง่ายภายในแต่ละภาวะ
PD (probability of default)
โอกาสผิดนัดชำระหนี้ภายในช่วงเวลาหนึ่ง เช่นหนึ่งปี ในตลาดจริงประมาณจาก spread ของ CDS หรือราคาหุ้นกู้
Copula
การแจกแจงร่วมของ “ตำแหน่งเปอร์เซ็นไทล์” ของหลายตัวแปร ใช้แยกรูปแบบการเกิดร่วมออกจากการแจกแจงรายตัว ทำให้ตรึง PD รายตัวตามตลาดแล้วปรับเฉพาะการกองรวมได้
Latent variable (ตัวแปรแฝง)
คะแนน “สุขภาพ” ของบริษัทที่แบบจำลองสร้างขึ้น มองไม่เห็นโดยตรง บริษัทผิดนัดเมื่อคะแนนนี้ต่ำกว่าเกณฑ์ ใช้เป็นตัวกลางที่ทำให้ Gaussian copula ใช้กับเหตุการณ์ผิดนัดแบบ 0/1 ได้
Tranche
ชั้นของการรับความเสียหายในพอร์ตสินเชื่อ ชั้น equity รับความเสียหายก้อนแรก ชั้น senior รับเป็นลำดับท้าย ใช้แบ่งความเสี่ยงก้อนเดียวให้นักลงทุนหลายกลุ่ม
Tail dependence
ลิมิตของโอกาสที่ตัวที่สองอยู่ในหางสุด เมื่อรู้ว่าตัวแรกอยู่ในหางสุด ใช้แยกแบบจำลองที่ “วิกฤตพร้อมกัน” ได้จริงในสุดหาง ออกจากแบบจำลองที่ความสัมพันธ์จางหายไปในสุดหาง

ขั้นที่ 1 — คูณภายในภาวะ แล้วเฉลี่ยข้ามภาวะ

โจทย์ให้อะไรมาบ้าง: $Z$ เป็นภาวะดีด้วยโอกาส 0.7 และแย่ด้วยโอกาส 0.3 ให้ $p(Z)$ เป็น PD ของแต่ละบริษัทในภาวะนั้น: $p(\text{good})=0.02$, $p(\text{bad})=0.20$ เมื่อรู้ $Z$ แล้ว $D_A$ กับ $D_B$ อิสระกัน

\[\begin{aligned} P(D_A=1)&=0.7(0.02)+0.3(0.20)=0.074,\\ P(D_A=1,\,D_B=1)&=0.7(0.02^2)+0.3(0.20^2)\\ &=0.00028+0.012=0.01228,\\ P(D_A=1)\,P(D_B=1)&=0.074^2=0.005476,\\ 0.01228-0.005476&=0.006804. \end{aligned}\]

คำตอบ: โอกาสผิดนัดทั้งคู่ 1.228% บรรทัดแรกเฉลี่ย PD ข้ามภาวะตาม tower property บรรทัดที่สองคูณภายในภาวะ (ใช้ conditional independence) แล้วเฉลี่ย ภาวะแย่ให้ 0.012 จาก 0.01228 ทั้งหมด หรือ 98% ของคำตอบ

ตรวจเองใน 10 วินาที: ผลต่าง 0.006804 คือ variance ของ $p(Z)$: $E[p(Z)^2]-(E[p(Z)])^2$ ซึ่งไม่ติดลบเสมอ ตรวจ: $p(Z)$ ห่างจากค่าเฉลี่ย 0.074 อยู่ $-0.054$ หรือ $+0.126$ จึงได้ $0.7(0.054^2)+0.3(0.126^2)=0.002041+0.004763=0.006804$ ถ้า PD ไม่ขึ้นกับภาวะเลย variance นี้เป็นศูนย์ และเราได้กรณีอิสระแท้

ขั้นที่ 2 — นิยาม conditional independence

ตัวอย่างสองภาวะใช้สมมติฐานหนึ่งโดยไม่ได้ตั้งชื่อ ขั้นนี้เขียนมันให้ชัด แล้วขยายจากสองบริษัทเป็นพอร์ต

\[\begin{aligned} E[f(X)\,g(Y)\mid Z]&=E[f(X)\mid Z]\;E[g(Y)\mid Z],\\ P(D_1=1,\ldots,D_n=1\mid Z)&=\prod_{i=1}^{n}P(D_i=1\mid Z),\\ P(D_A=1,\,D_B=1)&=E\big[p_A(Z)\,p_B(Z)\big],\\ &\ne E[p_A(Z)]\;E[p_B(Z)]\ \text{in general}. \end{aligned}\]

บรรทัดแรกคือนิยาม: สูตรผลคูณของค่าเฉลี่ยจาก ผลที่ตามมาของความเป็นอิสระ ใช้ได้ภายในแต่ละค่าของ $Z$ ทุกคู่ฟังก์ชัน $f,g$ เลือก $f,g$ เป็น indicator ของการผิดนัดก็ได้บรรทัดที่สอง ซึ่งขยายไปกี่บริษัทก็ได้ นี่คือเหตุผลที่ desk ชอบสมมติฐานนี้: ภายในภาวะหนึ่ง โอกาสร่วมของหุ้นกู้ร้อยตัวเป็นแค่ผลคูณ คำนวณง่าย

บรรทัดที่สามใช้ tower property: เฉลี่ยโอกาสร่วมตามเงื่อนไขข้ามการแจกแจงของ $Z$ บรรทัดสุดท้ายเตือนว่าค่าเฉลี่ยของผลคูณไม่เท่ากับผลคูณของค่าเฉลี่ย ผลต่างคือ $\operatorname{Cov}(p_A(Z),p_B(Z))$ ถ้าทั้งสองบริษัทแย่ลงในภาวะเดียวกัน covariance เป็นบวก และโอกาสผิดนัดร่วมสูงกว่าผลคูณ ถ้าบริษัทหนึ่งได้ประโยชน์จากภาวะที่ทำร้ายอีกบริษัท (เช่นผู้ผลิตน้ำมันกับสายการบิน) covariance อาจติดลบได้

การใส่ปัจจัยร่วมไม่ได้รับรอง conditional independence เอง มันเป็นสมมติฐาน ถ้าบริษัท A เป็นลูกค้ารายใหญ่ของ B การผิดนัดของ A ทำร้าย B โดยตรงแม้รู้ภาวะเศรษฐกิจแล้ว สมมติฐานนี้ก็ผิด

ขั้นที่ 3 — การผิดนัดของรายหนึ่งคือข่าวเรื่องเศรษฐกิจ

ถ้าสองบริษัทอิสระกันเมื่อรู้ภาวะ ทำไมข่าวว่า A ผิดนัดจึงทำให้ราคาหุ้นกู้ของ B ตก ขั้นนี้ตอบด้วย Bayes

โจทย์ให้อะไรมาบ้าง: แบบจำลองสองภาวะเดิม เพิ่งรู้ว่าบริษัท A ผิดนัด แต่ยังไม่รู้ว่าเศรษฐกิจเป็นภาวะไหน

\[\begin{aligned} P(\text{bad}\mid D_A=1)&=\frac{0.3(0.20)}{0.074}=\frac{0.06}{0.074}=0.811,\\ P(D_B=1\mid D_A=1)&=\frac{0.01228}{0.074}=0.166. \end{aligned}\]

คำตอบ: หลังรู้ว่า A ผิดนัด โอกาสที่เศรษฐกิจอยู่ในภาวะแย่กระโดดจาก 30% เป็น 81% และ PD ของ B จาก 7.4% เป็น 16.6% บรรทัดแรกคือ Bayes' theorem: ใน 7.4% ของโลกที่ A ผิดนัด 6 จุดเปอร์เซ็นต์มาจากภาวะแย่ บรรทัดที่สองคือนิยามโอกาสตามเงื่อนไขจาก conditional distribution A ไม่ได้ทำให้ B ผิดนัด แต่การผิดนัดของ A เป็นหลักฐานว่าภาวะที่ทั้งสองบริษัทเผชิญอยู่แย่

ตรวจเองใน 10 วินาที: ถ้ารู้ภาวะอยู่แล้ว ข่าวนี้ไม่เปลี่ยนอะไร: ในภาวะแย่ PD ของ B ยังคง 20% ไม่ว่า A จะผิดนัดหรือไม่ ซึ่งตรงกับนิยาม conditional independence และ 16.6% คือค่าเฉลี่ย $0.811(20\%)+0.189(2\%)=16.6\%$

ขั้นที่ 4 — Copula: แยกการแจกแจงรายตัวออกจากรูปแบบการเกิดร่วม

สองภาวะหยาบเกินไปสำหรับพอร์ตจริง และ desk ต้องการให้ PD รายตัวตรงกับราคาในตลาดเป๊ะ ขณะที่ปรับระดับการกองรวมได้อิสระ copula ทำให้แยกสองเรื่องนี้ได้

\[\begin{aligned} U&=F_X(X),\qquad V=F_Y(Y),\\ F_{X,Y}(x,y)&=C\big(F_X(x),\,F_Y(y)\big),\\ C_\rho(u,v)&=\Phi_\rho\big(\Phi^{-1}(u),\,\Phi^{-1}(v)\big). \end{aligned}\]

บรรทัดแรกแปลงแต่ละตัวแปรเป็นตำแหน่งเปอร์เซ็นไทล์ของมันเอง เช่น $U=0.10$ แปลว่า $X$ อยู่ที่ 10% ล่างสุดของการแจกแจงตัวเอง ถ้า $F_X$ ต่อเนื่อง $U$ จะเป็น uniform บนช่วง 0 ถึง 1 เสมอ ไม่ว่า $X$ มาจากการแจกแจงอะไร ตัวอย่าง: ถ้า $X$ เป็น uniform ระหว่าง −10% กับ 10% ค่า $X=-8\%$ อยู่สูงกว่าขอบล่าง 2 จุดจากความกว้าง 20 จุด จึงได้ $U=0.10$ แล้ว $\Phi^{-1}(0.10)=-1.2816$ คือคะแนน normal ที่อยู่ตำแหน่งเดียวกัน

บรรทัดที่สองคือทฤษฎีบทของ Sklar: joint CDF ใดก็ตามเขียนเป็นฟังก์ชัน $C$ ของ marginal CDF ได้ $C$ คือ joint CDF ของเปอร์เซ็นไทล์ $(U,V)$ ซึ่งเก็บรูปแบบการเกิดร่วมไว้ทั้งหมด และไม่สนว่า marginal เป็นอะไร ถ้า marginal ต่อเนื่อง $C$ มีได้แบบเดียว

บรรทัดสุดท้ายคือทางเลือกหนึ่งของ $C$: แปลงเปอร์เซ็นไทล์ทั้งสองเป็นคะแนน normal แล้วสมมติว่าคู่คะแนนเป็น Gaussian ร่วมที่ correlation $\rho$ ($\Phi_\rho$ คือ bivariate normal CDF) การแปลง marginal ให้เป็น normal ไม่ได้ทำให้คู่เป็น Gaussian ร่วมเอง นั่นคือสมมติฐานที่เติมเข้าไป และเป็นจุดอ่อนหลักของแบบจำลอง

ความเข้าใจผิดที่พบบ่อยคือ marginal กับ correlation matrix พอจะกำหนด joint distribution ไม่จริง correlation วัดแค่ความสัมพันธ์เชิงเส้น สองการแจกแจงที่มี marginal เป็น normal มาตรฐานและ correlation 0.7 เท่ากัน อาจต่างกันมากในโอกาสที่ทั้งคู่ขยับแรงพร้อมกัน ขึ้นกับ copula ที่ใช้ (ดูเรื่อง tail dependence ท้ายหน้า)

ขั้นที่ 5 — ปัจจัยร่วมหนึ่งตัว: สร้าง Gaussian copula ให้คำนวณได้

Gaussian copula ของหุ้นกู้หลายร้อยตัวต้องการ correlation หลายหมื่นคู่ แบบจำลองที่ใช้กันจริงลดเหลือพารามิเตอร์เดียวด้วยปัจจัยร่วม ซึ่งทำให้กลับมาเป็นโครงสร้างของตัวอย่างสองภาวะอีกครั้ง

\[\begin{aligned} G_i&=\sqrt\rho\,Z+\sqrt{1-\rho}\,\varepsilon_i,\\ \operatorname{Corr}(G_i,G_j)&=\rho,\qquad i\ne j,\\ D_i=1\ &\text{when}\ G_i\le c=\Phi^{-1}(p),\\ p(z)&=P\Big(\varepsilon_i\le\tfrac{c-\sqrt\rho\,z}{\sqrt{1-\rho}}\Big)\\ &=\Phi\Big(\tfrac{\Phi^{-1}(p)-\sqrt\rho\,z}{\sqrt{1-\rho}}\Big). \end{aligned}\]

บรรทัดแรก: $Z,\varepsilon_1,\varepsilon_2,\ldots$ เป็น normal มาตรฐานอิสระร่วมกัน $Z$ คือสุขภาพเศรษฐกิจที่ทุกบริษัทใช้ร่วมกัน $\varepsilon_i$ คือข่าวเฉพาะบริษัท $G_i$ มี variance $\rho+(1-\rho)=1$ และสองบริษัทมี covariance $\sqrt\rho\sqrt\rho=\rho$ ผ่าน $Z$ ตัวเดียว นี่จึงเป็น Gaussian copula ที่ correlation ทุกคู่เท่ากับ $\rho$ แบบทั่วไปให้แต่ละบริษัทมีน้ำหนักบนปัจจัยของตัวเอง $a_i$: $G_i=a_iZ+\sqrt{1-a_i^2}\,\varepsilon_i$ แล้ว correlation ของคู่ $i,j$ คือ $a_ia_j$

บรรทัดที่สาม: เลือกเกณฑ์ $c=\Phi^{-1}(p)$ เพราะ $G_i$ เป็น normal มาตรฐาน โอกาส $G_i\le c$ จึงเป็น $p$ พอดี PD รายตัวตรงกับตลาดไม่ว่า $\rho$ เป็นเท่าไร ถ้าใช้ PD ตามเวลา $q_i(t)$ จาก CDS เกณฑ์ $\Phi^{-1}(q_i(t))$ ให้การแจกแจงร่วมของเวลาผิดนัดทั้งพอร์ตเป็น Gaussian copula ของ $q_i(t)$

สองบรรทัดสุดท้ายคือหัวใจ: เมื่อรู้ $Z=z$ ส่วนที่ยังสุ่มคือ $\varepsilon_i$ ซึ่งอิสระกันข้ามบริษัท การผิดนัดจึงอิสระกันเมื่อรู้ $Z$ ย้ายข้างอสมการ $\sqrt\rho z+\sqrt{1-\rho}\,\varepsilon_i\le c$ ได้เงื่อนไขของ $\varepsilon_i$ ซึ่งมีโอกาส $\Phi(\cdot)$ ตรวจเครื่องหมาย: $z$ ต่ำลง ตัวเศษเพิ่มขึ้น PD จึงสูงขึ้น ที่ $\rho=0$ ได้ $p(z)=p$ ทุกภาวะ ส่วน $\rho=1$ ทำให้ตัวหารเป็นศูนย์ ต้องแยกพิจารณา

ขั้นที่ 7 — นับจำนวนผิดนัดในพอร์ตหุ้นกู้ 125 ตัว

ภายในภาวะหนึ่ง การผิดนัดของแต่ละตัวอิสระกันและมี PD เท่ากัน จำนวนผิดนัดจึงเป็น binomial ภายในภาวะ แล้วเฉลี่ยข้ามภาวะ เหมือนตัวอย่างสองภาวะทุกประการ แค่ภาวะต่อเนื่อง

โจทย์ให้อะไรมาบ้าง: พอร์ตสมมติ 125 หุ้นกู้ PD หนึ่งปี 2% เท่ากันทุกตัว ใช้แบบจำลองปัจจัยเดียวด้านบน ให้ $N$ เป็นจำนวนที่ผิดนัดในหนึ่งปี

\[\begin{aligned} N\mid Z=z&\sim\text{Binomial}\big(125,\ p(z)\big),\\ P(N=k)&=\int\binom{125}{k}p(z)^k\big(1-p(z)\big)^{125-k}\varphi(z)\,dz,\\ E[N]&=\int 125\,p(z)\,\varphi(z)\,dz=125(0.02)=2.5. \end{aligned}\]

ขั้นที่ 9 — latent correlation ไม่ใช่ default correlation

$\rho$ ในแบบจำลองคือ correlation ของคะแนนสุขภาพแฝง ไม่ใช่ของเหตุการณ์ผิดนัด ถ้าเอาสองค่านี้ไปใช้สลับกัน ตัวเลขทั้งพอร์ตจะเพี้ยน

\[\begin{aligned} P(D_i=1,\,D_j=1)&=\int p(z)^2\,\varphi(z)\,dz,\\ \operatorname{Corr}(D_i,D_j)&=\frac{E[p(Z)^2]-p^2}{p(1-p)},\\ \rho=0.15:\quad&\frac{0.000877-0.0004}{0.0196}=0.0243,\\ \rho=0.30:\quad&\frac{0.001664-0.0004}{0.0196}=0.0645. \end{aligned}\]

บรรทัดแรกคือการคูณภายในภาวะแล้วเฉลี่ยของตัวอย่างสองภาวะ แต่ภาวะต่อเนื่อง บรรทัดที่สองคือ correlation ของตัวแปร 0/1 สองตัว: covariance คือโอกาสร่วมลบผลคูณ ($E[D_iD_j]-p^2$) และ variance ของตัวแปร 0/1 ที่มีโอกาส $p$ คือ $p(1-p)$

latent correlation 0.15 ให้ default correlation แค่ 0.0243 เล็กกว่าหกเท่า เหตุผล: เหตุการณ์ผิดนัดเกิดเฉพาะในหางล่าง 2% ของคะแนน ส่วนใหญ่ของ correlation ระหว่างคะแนนเกิดในช่วงกลางที่ไม่มีใครผิดนัด แต่อย่าเห็นตัวเลขเล็กแล้วคิดว่าไม่สำคัญ default correlation 0.0243 นี้คือสิ่งที่ดันโอกาสผิดนัด 10 ตัวขึ้นไปจาก 0.022% เป็น 3.85% ในพอร์ต 125 ตัว

ขั้นที่ 10 — tail dependence: ถามถึงสุดหาง ไม่ใช่หางที่ใช้จริง

คำวิจารณ์ที่ดังที่สุดต่อ Gaussian copula คือมัน “ไม่มี tail dependence” ขั้นนี้ดูว่าข้อความนี้แปลว่าอะไร และไม่ได้แปลว่าอะไร

\[\begin{aligned} \lambda_L&=\lim_{q\to0}P(V\le q\mid U\le q),\\ \text{Gaussian},\ \rho=0.6:&\quad 0.496,\ 0.310,\ 0.188,\ 0.049\\ &\quad\text{at } q=0.2,\ 0.05,\ 0.01,\ 0.0001,\\ \lambda_L^{\text{Gauss}}&=0,\\ \lambda_L^{t}&=2\,T_{\nu+1}\Big(-\sqrt{\tfrac{(\nu+1)(1-\rho)}{1+\rho}}\Big)\\ &=2\,T_5(-1.118)=0.314\quad(\nu=4,\ \rho=0.6). \end{aligned}\]

บรรทัดแรก: ถ้ารู้ว่าตัวแรกอยู่ในหางล่าง $q$ ของตัวเอง ตัวที่สองอยู่ในหางล่าง $q$ ด้วยโอกาสเท่าไร แล้วให้ $q$ เล็กลงเรื่อย ๆ ตัวเลขสี่ตัวของ Gaussian copula ได้จากการหาร bivariate normal CDF ด้วย $q$ เช่นที่ $q=0.05$ คือ $0.0155/0.05=0.310$ ซึ่งตรงกับตัวเลขหางร่วมที่เห็นใน independence ค่าเหล่านี้ลดลงช้า ๆ แต่ลดลงถึงศูนย์ในลิมิต

ข้อความ “tail dependence เป็นศูนย์” จึงไม่ได้แปลว่าไม่มีการผิดนัดพร้อมกัน ที่ระดับ 5% ที่ใช้จริง โอกาสตามเงื่อนไขยังสูงถึง 31% เทียบกับ 5% ถ้าอิสระ มันแปลว่าในวิกฤตที่ลึกขึ้นเรื่อย ๆ ความสัมพันธ์ในแบบจำลองจางลงจนหายไป ซึ่งตรงข้ามกับที่ตลาดจริงมักทำ

Student-t copula ใช้ correlation $\rho$ บนชั้นแฝงเหมือนกัน แต่เพิ่ม degrees of freedom $\nu$ ที่ทำให้หางหนา บรรทัดสุดท้ายเป็นผลที่รู้กันของ t copula ($T_{\nu+1}$ คือ CDF ของ Student-t ที่ $\nu+1$ degrees of freedom และ $\sqrt{5(0.4)/1.6}=1.118$) ลิมิตของมันคือ 0.314 ไม่ใช่ศูนย์: ในสุดหาง เมื่อตัวหนึ่งพัง อีกตัวพังตามด้วยโอกาสราวหนึ่งในสามเสมอ

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

คูณ PD เฉลี่ยแทนการเฉลี่ยผลคูณ: $0.074^2=0.548\%$ เทียบกับ 1.228% ต่ำไป 2.24 เท่า ลำดับที่ถูกคือคูณภายในภาวะก่อน แล้วจึงเฉลี่ย

ใส่ latent correlation ในสูตรของ default correlation: ถ้าใส่ 0.15 แทน 0.0243 ลงในสูตร $E[D_iD_j]=p^2+\operatorname{Corr}\cdot p(1-p)$ จะได้โอกาสผิดนัดร่วม $0.0004+0.15(0.0196)=0.334\%$ แทนที่จะเป็น 0.0877% สูงไปเกือบสี่เท่า

คิดว่า PD ในภาวะกลางคือ PD เฉลี่ย: ที่ $z=0$ และ $\rho=0.3$ PD คือ 0.71% ไม่ใช่ 2% ถ้าใช้ภาวะกลางเป็น “ฉากทัศน์พื้นฐาน” จะประเมินความเสียหายคาดหมายต่ำไปเกือบสามเท่า

ใช้ $\rho$ ตัวเดียวกับทุก tranche: ในตลาดจริง เมื่อหา $\rho$ ที่ทำให้ราคาจากแบบจำลองตรงกับราคาตลาดของแต่ละชั้น (implied correlation) ได้ค่าไม่เท่ากันในแต่ละชั้น และบางชั้นหาค่าที่ตรงไม่ได้เลย เพราะ mezzanine แทบไม่ไวต่อ $\rho$ (0.389 ถึง 0.549 ในตาราง tranche) นี่คือสัญญาณว่าแบบจำลองปัจจัยเดียวผิดรูป ไม่ใช่แค่ผิดพารามิเตอร์

ตีความ tail dependence ศูนย์ว่าไม่มีวิกฤตพร้อมกัน: Gaussian copula ที่ $\rho=0.6$ ยังให้โอกาสตามเงื่อนไข 31% ที่หาง 5% ตัวเลขศูนย์เป็นเรื่องของลิมิตเท่านั้น

ส่ง $\rho=1$ เข้าสูตร $p(z)$: ตัวหาร $\sqrt{1-\rho}$ เป็นศูนย์ ทุกบริษัทผิดนัดพร้อมกันเมื่อ $Z\le c$ ต้องจัดการเป็นกรณีพิเศษ

ใช้ทำอะไรบนโต๊ะจริง

แบบจำลองปัจจัยเดียวนี้เคยเป็นมาตรฐานตลาดในการตั้งราคา CDO เพราะคำนวณเร็ว: ภายในภาวะใช้ binomial (หรือการวนเพิ่มทีละบริษัทเมื่อ PD ไม่เท่ากัน) แล้วอินทิเกรตหนึ่งมิติ รายละเอียดการตั้งราคา premium leg และ default leg อยู่ใน CDOs and the Gaussian copula โครงสร้างการแบ่งชั้นแบบเดียวกันใช้กับสินเชื่อบ้านใน CMO tranche waterfalls นอกจากเครดิต ความคิด “อิสระเมื่อรู้ปัจจัย” คือรากของ factor model ของผลตอบแทนหุ้นด้วย

บทความของ David X. Li ในปี 2000 เป็นงานสำคัญที่นำ copula มาใช้กับการผิดนัดร่วม (ตัวทฤษฎีบทของ Sklar มีตั้งแต่ปี 1959) ในวิกฤตปี 2007–2008 แบบจำลองนี้ถูกวิจารณ์หนัก ส่วนใหญ่ถูกต้อง แต่จุดอ่อนเหล่านั้น เช่น $\rho$ ตัวเดียว recovery คงที่ (ในความจริงสุ่มและต่ำในภาวะแย่) และหางที่บางเกินไป เป็นที่รู้กันก่อนวิกฤตแล้ว ปัญหาใหญ่กว่าคือการเชื่อตัวเลขจากแบบจำลองโดยไม่ทดสอบสถานการณ์เลวร้าย รายละเอียดอยู่ใน สิ่งที่วิกฤต 2007–2008 ทำให้พัง

1. ในภาวะที่รู้แล้ว บริษัท A ผิดนัด 10% และ B ผิดนัด 20% และอิสระกันเมื่อรู้ภาวะ โอกาสผิดนัดทั้งคู่ในภาวะนี้เป็นเท่าไร ใช้ตัวเลขนี้เป็นโอกาสทั้งปีได้เลยไหม

เฉลย

ในภาวะนี้ $0.10\times0.20=2\%$ ใช้เป็นโอกาสทั้งปีไม่ได้ จนกว่าจะเฉลี่ยข้ามทุกภาวะที่อาจเกิด ถ่วงด้วยโอกาสของแต่ละภาวะ (หรือรู้แน่ว่าภาวะนี้จะเกิด)

2. แบบจำลองสองภาวะของหน้านี้ ถ้ารู้ว่า A ไม่ผิดนัด โอกาสที่เศรษฐกิจแย่และ PD ของ B เป็นเท่าไร

เฉลย

$P(\text{bad}\mid D_A=0)=0.3(0.8)/(1-0.074)=0.24/0.926=0.259$ ลดลงจาก 0.30 นิดหน่อย PD ของ B $=0.259(0.20)+0.741(0.02)=0.0518+0.0148=6.66\%$ ลดลงจาก 7.4% ข่าวดีให้ข้อมูลน้อยกว่าข่าวร้าย เพราะการไม่ผิดนัดเกิดบ่อยในทั้งสองภาวะ

3. แบบจำลองปัจจัยเดียว PD 2% และ $\rho=0.30$ จงหา PD ในภาวะ $z=-2$ แล้วบอกว่าในภาวะนั้น พอร์ต 125 ตัวผิดนัดเฉลี่ยกี่ตัว

เฉลย

$p(-2)=\Phi\big((-2.054+\sqrt{0.3}(2))/\sqrt{0.7}\big)=\Phi\big((-2.054+1.095)/0.837\big)=\Phi(-1.146)=12.6\%$ ในภาวะนั้นจำนวนผิดนัดเป็น binomial ค่าเฉลี่ย $125\times0.126=15.8$ ตัว ซึ่งกินชั้น equity และ mezzanine หมด และกินชั้น senior ไปเกือบ 10 หน่วย

// normal CDF by series (fine for |x| < 7), quantile by bisection, Simpson rule
function Phi(x) {
  const a = Math.abs(x); if (a > 7) return x < 0 ? 0 : 1;
  let t = a, s = a;
  for (let k = 1; k < 400; k++) { t *= a * a / (2 * k + 1); s += t; if (t < s * 1e-16) break; }
  const half = Math.exp(-a * a / 2) / Math.sqrt(2 * Math.PI) * s;
  return x < 0 ? .5 - half : .5 + half;
}
const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
function quantile(p) { let lo = -8, hi = 8;
  for (let i = 0; i < 100; i++) { const m = (lo + hi) / 2; if (Phi(m) < p) lo = m; else hi = m; }
  return (lo + hi) / 2; }
function simpson(f, a, b, n = 2400) { const h = (b - a) / n; let s = f(a) + f(b);
  for (let i = 1; i < n; i++) s += (i % 2 ? 4 : 2) * f(a + i * h); return s * h / 3; }

// 1) two-state economy
const pdState = [[.7, .02], [.3, .20]];
const pA = pdState.reduce((s, [w, q]) => s + w * q, 0);          // 0.074
const both = pdState.reduce((s, [w, q]) => s + w * q * q, 0);     // 0.01228
console.log({ pA, both, product: pA * pA, badGivenA: .3 * .2 / pA, BgivenA: both / pA });

// 2) one-factor Gaussian copula, PD 2%
const p = .02, c = quantile(p);                                    // -2.054
const pd = (z, rho) => Phi((c - Math.sqrt(rho) * z) / Math.sqrt(1 - rho));
for (const rho of [.15, .3]) {
  const joint = simpson(z => pd(z, rho) ** 2 * phi(z), -8, 8);
  console.log({ rho, z0: pd(0, rho), zm2: pd(-2, rho), zm3: pd(-3, rho),
    mean: simpson(z => pd(z, rho) * phi(z), -8, 8), joint,
    defaultCorr: (joint - p * p) / (p * (1 - p)) });               // 0.0243, 0.0645
}

// 3) 125 bonds: distribution of defaults and tranche expected losses
function binom(n, q) { const out = []; let lc = 0;
  for (let k = 0; k <= n; k++) { if (k > 0) lc += Math.log((n - k + 1) / k);
    out.push(q <= 0 ? +(k === 0) : Math.exp(lc + k * Math.log(q) + (n - k) * Math.log1p(-q))); }
  return out; }
function lossDist(rho, n = 125) {
  if (rho === 0) return binom(n, p);
  const acc = new Array(n + 1).fill(0), a = -8, b = 8, m = 1600, h = (b - a) / m;
  for (let i = 0; i <= m; i++) { const z = a + i * h, w = (i === 0 || i === m) ? 1 : (i % 2 ? 4 : 2);
    binom(n, pd(z, rho)).forEach((v, k) => { acc[k] += w * v * phi(z) * h / 3; }); }
  return acc; }
const tranche = (d, L, U) => d.reduce((s, q, k) => s + q * Math.max(Math.min(k, U) - L, 0), 0);
for (const rho of [0, .15, .3, .5]) {
  const d = lossDist(rho);
  console.log({ rho, P0: d[0], tail10: d.slice(10).reduce((s, q) => s + q, 0),
    equity: tranche(d, 0, 3), mezz: tranche(d, 3, 6), senior: tranche(d, 6, 125) });
}

สิ่งที่ควรตอบได้หลังอ่าน

  • conditional independence: คูณภายในภาวะก่อน แล้วเฉลี่ยข้ามภาวะ ได้ 1.228% ไม่ใช่ $7.4\%^2=0.548\%$ ผลต่างคือ variance ของ PD ข้ามภาวะ
  • การผิดนัดของรายหนึ่งเป็นข่าวเรื่องภาวะร่วม: PD ของอีกรายกระโดดจาก 7.4% เป็น 16.6% ทั้งที่ไม่มีความเชื่อมโยงทางธุรกิจ
  • copula แยก marginal ออกจากรูปแบบการเกิดร่วม Gaussian copula แบบปัจจัยเดียวตรึง PD รายตัวที่ $c=\Phi^{-1}(p)$ และใช้ $\rho$ ตัวเดียวควบคุมการกองรวม
  • $\rho$ ไม่เปลี่ยนค่าเฉลี่ยของจำนวนผิดนัด (2.5 จาก 125 ตัว) แต่ดันโอกาสผิดนัด 10 ตัวขึ้นไปจาก 0.022% เป็น 6.43% และย้ายความเสียหายจาก equity ไป senior
  • latent correlation (0.15), default correlation (0.0243) และ tail dependence (0 สำหรับ Gaussian, 0.314 สำหรับ t ที่ $\nu=4,\ \rho=0.6$) เป็นคนละปริมาณ ต้องบอกให้ชัดก่อนใส่ตัวเลขในสูตร

บทนี้จบที่การแจกแจงร่วมของสองถึงหลายตัวแปรด้วยตาราง density และปัจจัยร่วม เมื่อจำนวนตัวแปรเป็นหลักร้อย เราต้องการภาษาที่กระชับกว่านี้ บทถัดไป เริ่มที่ row และ column vector ซึ่งเป็นเครื่องมือที่ทำให้ค่าเฉลี่ย covariance และน้ำหนักพอร์ตของหุ้นร้อยตัวเขียนได้ในบรรทัดเดียว
