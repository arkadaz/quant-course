2.1 เฉลี่ยทีละสภาวะ แล้วเฉลี่ยกลับทั้งระบบ

ค่าเฉลี่ยรวมเท่ากับค่าเฉลี่ยของแต่ละกรณี ถ่วงด้วยโอกาสที่กรณีนั้นจะเกิด

ทีมเทรดทีมหนึ่งในธนาคาร (คนในวงการเรียกทีมแบบนี้ว่า desk) ใช้กลยุทธ์ซื้อขายอยู่หนึ่งแบบ กลยุทธ์คือกติกาที่บอกว่าวันไหนจะซื้ออะไรและขายอะไร ทุกเย็นทีมนับว่าวันนั้นได้กำไรหรือขาดทุนกี่ดอลลาร์ ตัวเลขนี้เรียกว่า P&L (profit and loss) วันที่ได้กำไร P&L เป็นบวก วันที่ขาดทุน P&L เป็นลบ

จากข้อมูลย้อนหลัง ทีมแบ่งวันซื้อขายเป็นสองแบบ วันสงบคือวันที่ไม่มีข่าวใหญ่ ราคาขยับตามปกติ วันข่าวแรงคือวันที่มีข่าวใหญ่จนราคากระโดด ตัวเลขด้านล่างเป็นตัวเลขสมมติ

  • วันสงบเกิด 80% ของวันซื้อขาย ในวันแบบนี้กลยุทธ์ได้กำไรเฉลี่ย \$100
  • วันข่าวแรงเกิด 20% ของวันซื้อขาย ในวันแบบนี้กลยุทธ์ขาดทุนเฉลี่ย \$600

ตอนนี้ยังไม่มีใครรู้ว่าพรุ่งนี้จะเป็นวันแบบไหน หัวหน้าทีมถามสองข้อ ข้อแรก P&L ของพรุ่งนี้ควรคาดไว้ที่เท่าไรโดยเฉลี่ย ข้อสอง วันข่าวแรงต้องเกิดบ่อยแค่ไหน กลยุทธ์นี้จึงเริ่มขาดทุนโดยเฉลี่ย

ลองตอบก่อนเปิดเฉลย

ข้อแรก วันสงบเกิดบ่อยกว่าวันข่าวแรง จึงต้องได้น้ำหนักมากกว่า เราคูณ P&L เฉลี่ยของวันแต่ละแบบด้วยโอกาสที่วันแบบนั้นเกิด แล้วบวกกัน

\[\begin{aligned}0.8\times100+0.2\times(-600)&=80-120\\&=-40\end{aligned}\]

กลยุทธ์ขาดทุนเฉลี่ย \$40 ต่อวัน ทั้งที่วันส่วนใหญ่ได้กำไร คำตอบไม่ใช่ค่าที่ได้จากการบวกสองค่าแล้วหารสอง

\[\frac{100+(-600)}{2}=-250\]

เพราะการหารสองให้น้ำหนักวันสองแบบเท่ากัน ทั้งที่สองแบบเกิดบ่อยไม่เท่ากัน

ข้อสอง กลยุทธ์คุ้มทุนพอดีเมื่อวันข่าวแรงเกิด $1/7\approx14.29\%$ ของวัน ขั้นที่ 8 ของหน้านี้จะหาตัวเลขนี้ให้ดูทีละขั้น ตอนนี้วันข่าวแรงเกิด 20% ซึ่งเกินจุดคุ้มทุนไปแล้ว

ภาพรวมก่อนลงสูตร

คำถามข้อแรกของหัวหน้าทีมคิดเป็นสองชั้น ชั้นในถามว่า ถ้ารู้แล้วว่าพรุ่งนี้เป็นวันแบบไหน P&L เฉลี่ยเป็นเท่าไร คำตอบชั้นในมีสองค่า คือ \$100 สำหรับวันสงบ และ −\$600 สำหรับวันข่าวแรง ชั้นนอกถามว่า วันแต่ละแบบเกิดบ่อยแค่ไหน แล้วเอาความถี่นั้นเป็นน้ำหนักถ่วงคำตอบชั้นใน

แต่การคิดสองชั้นได้ค่าเดียวกับการเอา P&L ของทุกวันมาเฉลี่ยตรง ๆ จริงหรือ กฎที่ตอบว่า “ได้เท่ากันเสมอ” ชื่อ law of iterated expectations หรือเรียกสั้น ๆ ว่า tower property ก่อนเขียนกฎเป็นสูตร ขอตั้งชื่อให้ของสามอย่าง

  • $Y$ คือ P&L ของหนึ่งวัน หน่วยเป็นดอลลาร์
  • $X$ คือสภาวะของตลาดในวันนั้น หมายถึงวันนั้นเป็นวันแบบไหน มีสองค่า คือ calm (วันสงบ) กับ stress (วันข่าวแรง)
  • $E[Y]$ คือค่าเฉลี่ยของ $Y$ แบบถ่วงด้วยโอกาส เรียกว่า expected value (ดู expected value) ส่วน $E[Y\mid X]$ คือค่าเฉลี่ยของ $Y$ เมื่อรู้ค่าของ $X$ แล้ว ขีดตั้ง $\mid$ อ่านว่า “เมื่อรู้”

กฎนี้เขียนเป็นสูตรได้ว่า $E[Y]=E\big[E[Y\mid X]\big]$ ให้อ่านจากข้างในออกมา ข้างในหาค่าเฉลี่ยของ $Y$ ในวันแต่ละแบบ ข้างนอกเฉลี่ยคำตอบเหล่านั้นอีกชั้นด้วยโอกาสของวันแต่ละแบบ ผลที่ได้เท่ากับค่าเฉลี่ยของ $Y$ ทั้งหมด

รูปด้านล่างวาดการคิดสองชั้นเป็นพื้นที่ แท่งหนึ่งแท่งแทนวันหนึ่งแบบ ความกว้างของแท่งคือสัดส่วนของวันแบบนั้น ความสูงคือ P&L เฉลี่ยของวันแบบนั้น พื้นที่ของแท่งคือกว้างคูณสูง ซึ่งก็คือพจน์หนึ่งตัวในผลถ่วงน้ำหนัก พื้นที่เหนือเส้นศูนย์นับเป็นบวก พื้นที่ใต้เส้นศูนย์นับเป็นลบ

ความกว้างของสองแท่งรวมกันได้ 1 พอดี ผลรวมพื้นที่จึงเท่ากับค่าเฉลี่ยรวม แท่งแดงแคบแต่ลึก มันจึงหักแท่งน้ำเงินที่กว้างแต่ตื้นจนผลรวมติดลบ

หน้านี้เดินตามลำดับนี้ เริ่มจากแยกให้ออกว่า ค่าเฉลี่ยเมื่อรู้สภาวะเป็นตัวเลขหรือเป็นตัวแปรสุ่ม จากนั้นพิสูจน์ว่าการเฉลี่ยสองชั้นได้ค่าเดิมเสมอ แล้วใช้กฎนี้ในสามงานที่เจอจริง คือ ดึงสิ่งที่รู้แล้วออกนอกค่าเฉลี่ย เฉลี่ยย้อนกลับบนต้นไม้ราคาทีละงวด และวัดว่าค่าเฉลี่ยรวมเปลี่ยนเท่าไรเมื่อความถี่ของวันข่าวแรงเปลี่ยน

ศัพท์ที่ใช้ในหัวข้อนี้
Conditional expectation $E[Y\mid X=x]$
ค่าเฉลี่ยของ $Y$ เมื่อรู้แล้วว่า $X$ มีค่า $x$ คิดเหมือนค่าเฉลี่ยธรรมดา แต่ใช้เฉพาะกรณีที่ $X=x$ ใช้ตอบคำถามว่า “ถ้าวันนี้เป็นแบบนี้ ควรคาดว่าจะได้เท่าไร” เช่น $E[Y\mid X=\text{calm}]=100$ คือ P&L เฉลี่ยของวันสงบ
$E[Y\mid X]$ เป็นตัวแปรสุ่ม
เมื่อไม่ระบุค่าของ $X$ สัญลักษณ์นี้หมายถึงกติกาว่า “รู้ $X$ เมื่อไร ให้ใช้ค่าเฉลี่ยของกรณีนั้น” ก่อนรู้ $X$ เรายังไม่รู้ว่าจะได้ค่าเฉลี่ยของกรณีไหน มันจึงเป็นตัวแปรสุ่มที่ค่าขึ้นกับ $X$ ใช้เป็นค่าพยากรณ์ที่ปรับตามข้อมูลที่จะได้เห็น
Tower property (law of iterated expectations)
กฎ $E\big[E[Y\mid X]\big]=E[Y]$ หาค่าเฉลี่ยในแต่ละกรณีก่อน แล้วเฉลี่ยคำตอบเหล่านั้นอีกชั้นด้วยโอกาสของแต่ละกรณี จะได้ค่าเฉลี่ยรวมเดิม ใช้แตกโจทย์ยากเป็นกรณีย่อยที่คิดง่ายกว่า
Taking out what is known
ของที่คำนวณได้จากข้อมูลที่รู้แล้ว ทำตัวเหมือนค่าคงที่ จึงดึงออกมานอก conditional expectation ได้ ท่านี้ใช้ทุกครั้งที่คำนวณกับ martingale (กระบวนการสุ่มที่ค่าเฉลี่ยของอนาคต เมื่อรู้ทุกอย่างถึงวันนี้ เท่ากับค่าวันนี้) และ Brownian motion (การเดินสุ่มที่ก้าวเล็กและถี่จนเวลาต่อเนื่อง ใช้เป็นแบบจำลองของราคา)
การแบ่งกรณี (partition)
การแบ่งวันทั้งหมดเป็นกลุ่ม โดยทุกวันอยู่ในกลุ่มเดียวพอดี ไม่มีวันไหนอยู่สองกลุ่ม และไม่มีวันไหนตกหล่น โอกาสของทุกกลุ่มจึงรวมกันได้ 1 พอดี ถ้าแบ่งไม่ได้แบบนี้ การถ่วงน้ำหนักจะผิด
Information set และ filtration
Information set คือข้อมูลทั้งหมดที่รู้ ณ เวลาหนึ่ง เขียนเป็น $\mathcal F_n$ สำหรับเวลา $n$ ข้อมูลมีแต่เพิ่มขึ้นตามเวลา ไม่มีวันลืม ลำดับของ information set ที่โตขึ้นเรื่อย ๆ นี้เรียกว่า filtration เราเขียน $E_n[\,\cdot\,]$ แทน “ค่าเฉลี่ยเมื่อรู้ข้อมูลถึงเวลา $n$” รายละเอียดอยู่ใน filtration และ martingale
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$X$สภาวะของตลาดในวันนั้น: calm (วันสงบ) หรือ stress (วันข่าวแรง)ไม่มีหน่วย
$Y$กำไรขาดทุน (P&L) ของหนึ่งวันดอลลาร์
$P(X=x)$โอกาสที่วันหนึ่งอยู่ในสภาวะ $x$ไม่มีหน่วย
$p$โอกาสที่วันหนึ่งเป็นวันข่าวแรง เมื่อปล่อยให้เปลี่ยนได้ (ขั้นที่ 8)ไม่มีหน่วย
$m(x)$$E[Y\mid X=x]$ P&L เฉลี่ยของวันแบบ $x$ดอลลาร์
$g(X)$ปริมาณใด ๆ ที่คำนวณได้จาก $X$ เช่นขนาดสถานะ (ขั้นที่ 5)แล้วแต่ปริมาณ
$S_n$ตำแหน่งของ random walk หลังก้าวที่ $n$ (ขั้นที่ 6) หรือราคา ณ งวด $n$ (ขั้นที่ 7)ก้าว หรือดอลลาร์
$\mathcal F_n$ข้อมูลทั้งหมดที่รู้ ณ เวลา $n$ไม่มีหน่วย
$E_n[\,\cdot\,]$ค่าเฉลี่ยเมื่อรู้ข้อมูลถึงเวลา $n$หน่วยเดียวกับสิ่งที่เฉลี่ย

ขั้นที่ 1 — รู้สภาวะแล้วเป็นตัวเลข ยังไม่รู้เป็นตัวแปรสุ่ม

ชั้นในของโจทย์คือค่าเฉลี่ยของ $Y$ ในวันแบบเดียวกัน ก่อนเอาค่าเหล่านี้ไปเฉลี่ยอีกชั้น ต้องแยกให้ออกว่าตอนไหนมันเป็นตัวเลขที่รู้แล้ว และตอนไหนมันยังสุ่มอยู่ เพราะชั้นนอกจะเฉลี่ยของที่ยังสุ่ม

เราตั้งชื่อ P&L เฉลี่ยของวันแบบ $x$ ว่า $m(x)$ ถ้า $Y$ มีค่าที่เป็นไปได้ไม่กี่ค่า ค่าเฉลี่ยคือผลรวมของ “ค่าคูณโอกาสของค่านั้น” ต่างจากค่าเฉลี่ยธรรมดาตรงที่โอกาสในที่นี้คือ $P(Y=y\mid X=x)$ หมายถึงโอกาสที่ $Y=y$ เมื่อรู้ว่าวันนั้นอยู่ในสภาวะ $x$ (conditional probability)

\[ \begin{aligned} m(x)&=E[Y\mid X=x]\\ &=\sum_y y\,P(Y=y\mid X=x),\\ m(X)&=\begin{cases}100, & X=\text{calm}\\ -600, & X=\text{stress}\end{cases} \end{aligned} \]

$m(x)$ คือค่าเฉลี่ยธรรมดาแบบใน expected value แต่ใช้โอกาสของวันแบบ $x$ เท่านั้น ใส่ $x$ เข้าไปหนึ่งค่า ได้ตัวเลขออกมาหนึ่งตัว คือ $m(\text{calm})=100$ และ $m(\text{stress})=-600$

จุดที่คนสับสนคือ $m(X)$ ที่เขียนด้วย $X$ ตัวใหญ่ ตัวใหญ่หมายถึงสภาวะของพรุ่งนี้ที่ยังไม่รู้ ตอนนี้เราจึงยังไม่รู้ว่าจะได้ 100 หรือ −600 ดังนั้น $m(X)=E[Y\mid X]$ เป็นตัวแปรสุ่ม มันได้ 100 ด้วยโอกาส 0.8 และได้ −600 ด้วยโอกาส 0.2

แต่ $m(X)$ ไม่ใช่ $Y$ วันสงบจริงวันหนึ่งอาจกำไร \$300 หรือขาดทุน \$200 ก็ได้ ค่า 100 เป็นแค่ค่าเฉลี่ยของวันแบบนั้น ไม่ใช่ P&L ของวันใดวันหนึ่ง

ขั้นที่ 2 — เฉลี่ยตัวแปรสุ่ม $m(X)$ อีกชั้น

ขั้นที่ 1 ได้ $m(X)$ ซึ่งยังสุ่มตามสภาวะของพรุ่งนี้ ชั้นนอกคือหาค่าเฉลี่ยของมัน ตัวแปรสุ่มที่มีสองค่ามีค่าเฉลี่ยเท่ากับ ค่าแต่ละค่าคูณโอกาสของมัน แล้วบวกกัน

โจทย์ให้อะไรมาบ้าง:

  • โอกาสของวันสงบ $P(X=\text{calm})=0.8$
  • โอกาสของวันข่าวแรง $P(X=\text{stress})=0.2$
  • P&L เฉลี่ยของวันสงบ $m(\text{calm})=\$100$
  • P&L เฉลี่ยของวันข่าวแรง $m(\text{stress})=-\$600$

โอกาสสองค่านี้รวมกันได้ $0.8+0.2=1$ พอดี แปลว่าทุกวันถูกนับครั้งเดียว ไม่มีวันไหนอยู่ทั้งสองแบบ และไม่มีวันไหนตกหล่น จึงใช้เป็นน้ำหนักได้

\[ \begin{aligned} E\big[m(X)\big]&=0.8(100)+0.2(-600)\\ &=80-120\\ &=-40 \end{aligned} \]

คำตอบ: กลยุทธ์ขาดทุนเฉลี่ย \$40 ต่อวัน ส่วนบวก \$80 มาจากวันสงบ ส่วนลบ \$120 มาจากวันข่าวแรง ทำไมส่วนลบชนะ เพราะวันข่าวแรงเกิดน้อยกว่าวันสงบ $0.8/0.2=4$ เท่า แต่ขาดทุนต่อวันลึกกว่ากำไรต่อวันของวันสงบ $600/100=6$ เท่า หกเท่ามากกว่าสี่เท่า ส่วนลบจึงใหญ่กว่า

ตรวจเองใน 10 วินาที: นึกถึงวันซื้อขาย 100 วัน ในนั้นเป็นวันสงบ 80 วัน และวันข่าวแรง 20 วัน ผลรวม P&L ของกลุ่มหนึ่งเท่ากับจำนวนวันในกลุ่มคูณค่าเฉลี่ยของกลุ่ม ไม่ว่าแต่ละวันในกลุ่มจะได้เท่าไร

\[\begin{aligned}80\times100&=\$8{,}000\\20\times(-600)&=-\$12{,}000\\\frac{8{,}000-12{,}000}{100}&=-\$40\end{aligned}\]

ผลรวมทั้งหมดหารด้วย 100 วันได้ −\$40 ต่อวัน เท่ากับทางคิดสองชั้น

ขั้นที่ 3 — พิสูจน์ว่าเฉลี่ยสองชั้นได้ค่าเฉลี่ยเดิม

ตัวอย่างเดียวยังไม่ใช่เหตุผล เพราะตัวเลขอาจบังเอิญตรงกันก็ได้ ขั้นนี้จึงพิสูจน์ว่าการเฉลี่ยสองชั้นได้ $E[Y]$ เสมอ บทพิสูจน์ใช้แค่นิยามของโอกาสแบบมีเงื่อนไข (conditional probability) คือโอกาสของเหตุการณ์หนึ่ง เมื่อรู้แล้วว่าอีกเหตุการณ์หนึ่งเกิดขึ้น

บทพิสูจน์ไม่ต้องสมมติว่า $X$ กับ $Y$ อิสระกัน (independent หมายถึงรู้ค่าตัวหนึ่งแล้วไม่ช่วยทายอีกตัว) ข้อนี้สำคัญ เพราะในตัวอย่างของเรา สภาวะของวันกับ P&L เกี่ยวกันชัด ๆ อีกสัญลักษณ์ที่ต้องใช้คือ $P(X=x,\,Y=y)$ เรียกว่าโอกาสร่วม (joint probability) คือโอกาสที่ $X=x$ และ $Y=y$ เกิดพร้อมกัน

\[ \begin{aligned} E\big[E[Y\mid X]\big] &=\sum_x P(X=x)\sum_y y\,P(Y=y\mid X=x)\\ &=\sum_x\sum_y y\,P(X=x,\,Y=y)\\ &=\sum_y y\sum_x P(X=x,\,Y=y)\\ &=\sum_y y\,P(Y=y)\\ &=E[Y] \end{aligned} \]

บทพิสูจน์เริ่มจากเขียนสองชั้นตรงตามคำพูด ข้างในเฉลี่ย $Y$ ในกรณี $x$ ข้างนอกถ่วงด้วยโอกาสของกรณีนั้น จากนั้นใช้สองท่า

ท่าแรกคือเอาโอกาสของกรณีคูณเข้าไปในโอกาสแบบมีเงื่อนไข ตามนิยามจาก Bayes' theorem ที่ว่า $P(Y=y\mid X=x)\,P(X=x)=P(X=x,Y=y)$ เมื่อ $P(X=x)\gt0$ ความหมายคือ โอกาสที่วันนั้นเป็นกรณี $x$ คูณโอกาสที่ได้ $y$ ในกรณีนั้น เท่ากับโอกาสที่ทั้งสองอย่างเกิดพร้อมกัน หลังท่านี้ เราได้ผลรวมของ “$y$ คูณโอกาสร่วม” ครบทุกคู่ $(x,y)$

ท่าที่สองคือท่าที่ต้องหยุดดู คือสลับลำดับการบวก จากเดิมที่รวมทีละกรณี $x$ เปลี่ยนเป็นรวมทีละค่า $y$ ทำได้เพราะเป็นการบวกตัวเลขชุดเดิม แค่เปลี่ยนลำดับ ถ้ามีพจน์ไม่จำกัดจำนวน ต้องมีเงื่อนไข $E[|Y|]\lt\infty$ (ค่าเฉลี่ยของขนาดของ $Y$ ไม่เป็นอนันต์) ผลรวมจึงไม่ขึ้นกับลำดับ

เมื่อรวมโอกาสร่วมข้ามทุก $x$ ก็ได้โอกาสของ $y$ เอง ตามนิยามของ marginal distribution ผลจึงกลับมาเป็นค่าเฉลี่ยธรรมดาของ $Y$

ตัวแปรต่อเนื่อง: ใช้ density แทนผลรวม

ถ้า $X$ และ $Y$ เป็นตัวแปรต่อเนื่อง (มีค่าเป็นจำนวนจริงได้ทุกค่าในช่วงหนึ่ง) เราใช้ density แทนโอกาสของแต่ละค่า joint density $f_{X,Y}(x,y)$ บอกว่าโอกาสหนาแน่นแค่ไหนรอบจุด $(x,y)$ ส่วน conditional density คือ $f_{Y\mid X}(y\mid x)=f_{X,Y}(x,y)/f_X(x)$ ในจุดที่ $f_X(x)\gt0$ ตาม conditional distribution

ขั้นตอนเหมือนกรณีนับได้ทุกขั้น แค่เปลี่ยนผลรวมเป็นอินทิกรัล และการสลับลำดับอินทิกรัลก็อาศัยเงื่อนไข $E[|Y|]\lt\infty$ เหมือนกัน

\[ \begin{aligned} E\big[E[Y\mid X]\big] &=\int f_X(x)\int y\,f_{Y\mid X}(y\mid x)\,dy\,dx\\ &=\iint y\,f_{X,Y}(x,y)\,dy\,dx\\ &=\int y\,f_Y(y)\,dy\\ &=E[Y] \end{aligned} \]

ถ้า $E[|Y|]$ เป็นอนันต์ ค่าเฉลี่ยของ $Y$ ไม่มีอยู่ตั้งแต่ต้น กฎนี้จึงไม่มีอะไรให้พูดถึง ตัวอย่างคือ Cauchy distribution ซึ่งหน้าตาเป็นระฆังสมมาตรรอบศูนย์ แต่หางหนามากจน $E[|Y|]$ เป็นอนันต์ กราฟสมมาตรจึงไม่ได้แปลว่าค่าเฉลี่ยเป็นศูนย์

ขั้นที่ 4 — เห็นการสลับลำดับการบวกบนตารางจริง

ตัวอย่างวันสงบกับวันข่าวแรงให้มาแค่ค่าเฉลี่ยของแต่ละกรณี เราไม่เห็นว่าข้างในแต่ละกรณีมีค่าอะไรบ้าง ขั้นนี้จึงใช้ตารางโอกาสร่วมเล็ก ๆ ที่เห็นครบทุกช่อง เพื่อดูการสลับลำดับการบวกในบทพิสูจน์ด้วยตา ตัวเลขในตารางเป็นตัวเลขสมมติ เลือกให้เล็กพอจะคิดในใจได้

โจทย์ให้อะไรมาบ้าง: $X$ มีค่าได้ 1 หรือ 2 และ $Y$ มีค่าได้ −2 หรือ 5 ตารางแบ่งคอลัมน์ตามค่า $X$ และแบ่งแถวตามค่า $Y$ ช่องในตารางคือโอกาสร่วม เช่น $P(X=1,\,Y=-2)=0.1$ ทั้งสี่ช่องรวมกันได้ $0.1+0.2+0.3+0.4=1$

ทางแรกคือ tower property ก่อนอื่นต้องรู้โอกาสของ $X$ แต่ละค่า ซึ่งได้จากการรวมคอลัมน์ของมัน $P(X=1)=0.1+0.2=0.3$ และ $P(X=2)=0.3+0.4=0.7$ โอกาสแบบมีเงื่อนไขในคอลัมน์หนึ่ง คือโอกาสร่วมหารด้วยโอกาสของคอลัมน์นั้น เช่น $P(Y=5\mid X=1)=0.2/0.3=2/3$ ค่าเฉลี่ยในแต่ละคอลัมน์จึงหารด้วยโอกาสของคอลัมน์ แล้วค่อยถ่วงด้วยโอกาสของคอลัมน์อีกที

\[ \begin{aligned} E[Y\mid X=1]&=\frac{0.1(-2)+0.2(5)}{0.3}\\ &=\frac{0.8}{0.3}\approx2.67,\\ E[Y\mid X=2]&=\frac{0.3(-2)+0.4(5)}{0.7}\\ &=\frac{1.4}{0.7}=2,\\ E\big[E[Y\mid X]\big]&=0.3\cdot\tfrac{0.8}{0.3}+0.7(2)\\ &=0.8+1.4=2.2 \end{aligned} \]

ทางที่สองคือเฉลี่ยตรง ๆ เริ่มจากรวมโอกาสของค่า $Y$ เดียวกันข้ามทุกคอลัมน์ (ตามนิยามของ marginal distribution) ได้ $P(Y=-2)=0.1+0.3=0.4$ และ $P(Y=5)=0.2+0.4=0.6$ แล้วจึงเฉลี่ย

\[E[Y]=0.4(-2)+0.6(5)=-0.8+3=2.2\]

คำตอบ: ทั้งสองทางได้ 2.2 ทางแรกเฉลี่ยในแต่ละคอลัมน์ก่อน แล้วถ่วงด้วยโอกาสของคอลัมน์ ทางที่สองรวมค่า $Y$ เดียวกันข้ามคอลัมน์ก่อน แล้วจึงเฉลี่ย สองทางบวกตัวเลขสี่ช่องชุดเดียวกัน ต่างกันแค่ลำดับ

ตรวจเองใน 10 วินาที: ในทางแรก $0.3\times\frac{0.8}{0.3}=0.8$ ตัวหาร 0.3 ถูกตัดทิ้งพอดี เหลือ $0.8=0.1(-2)+0.2(5)$ ซึ่งคือผลรวมของ “ค่า $Y$ คูณโอกาสร่วม” ในคอลัมน์แรก การตัดตัวหารทิ้งแบบนี้คือท่าแรกในบทพิสูจน์ ที่เปลี่ยนโอกาสแบบมีเงื่อนไขกลับเป็นโอกาสร่วม

ขั้นที่ 5 — ดึงสิ่งที่รู้แล้วออกนอกค่าเฉลี่ย

เทรดเดอร์ตัดสินใจตอนเช้าว่าจะถือหุ้นกี่หุ้น โดยดูจากข้อมูลที่มีถึงเช้านี้ จำนวนหุ้นที่ถือเรียกว่าขนาดสถานะ (position) กำไรของวันนั้นคือขนาดสถานะคูณการเปลี่ยนแปลงของราคาวันนั้น ตอนเช้าขนาดสถานะรู้แล้ว แต่การเปลี่ยนแปลงของราคายังสุ่ม โจทย์แบบนี้จึงต้องหาค่าเฉลี่ยของผลคูณ ระหว่างของที่รู้แล้วกับของที่ยังสุ่ม

ในสัญลักษณ์ ให้ $X$ คือข้อมูลที่รู้แล้ว ให้ $g(X)$ คือปริมาณใด ๆ ที่คำนวณได้จาก $X$ (เช่นขนาดสถานะ) และให้ $Y$ คือของที่ยังสุ่ม (เช่นการเปลี่ยนแปลงของราคา) เราอยากรู้ $E[g(X)\,Y]$ และอยากแยกส่วนที่รู้แล้วออกจากส่วนที่ยังสุ่ม

\[ \begin{aligned} E[g(X)\,Y\mid X=x]&=\sum_y g(x)\,y\,P(Y=y\mid X=x)\\ &=g(x)\,E[Y\mid X=x],\\ E[g(X)\,Y\mid X]&=g(X)\,E[Y\mid X],\\ E[g(X)\,Y]&=E\big[g(X)\,E[Y\mid X]\big] \end{aligned} \]

เมื่อรู้แล้วว่า $X=x$ ค่า $g(x)$ เป็นตัวเลขตัวเดียวกันในทุกพจน์ของผลรวม จึงยกออกมานอกผลรวมได้ เหมือนดึงค่าคงที่ออกจาก $\sum$ ท่านี้ชื่อ taking out what is known ผลนี้จริงทุกค่า $x$ จึงเขียนด้วย $X$ ตัวใหญ่ได้ แล้วเอา tower property มาเฉลี่ยทั้งสองข้างอีกชั้น ด้านซ้ายจึงกลายเป็น $E[g(X)\,Y]$ เงื่อนไขที่ต้องมีคือ $E[|g(X)\,Y|]\lt\infty$ แบบเดียวกับในบทพิสูจน์

กับดักคือการแทน $g(X)$ ด้วย $E[g(X)]$ แล้วคูณ $E[Y]$ วิธีนี้ถูกเมื่อ $X$ กับ $Y$ อิสระกัน แต่ผิดได้เมื่อไม่อิสระ สิ่งที่ถูกเสมอคือคูณ $g(X)$ กับค่าเฉลี่ยของ $Y$ ในกรณีเดียวกัน แล้วจึงเฉลี่ย หัวข้อความผิดท้ายหน้ามีตัวอย่างตัวเลข

ขั้นที่ 6 — Random walk สามก้าว: หา $E[S_1S_3]$

Random walk คือตำแหน่งที่เดินสุ่มทีละก้าว ทุกก้าวโยนเหรียญหนึ่งครั้ง ออกหัวเดินขึ้นหนึ่ง ออกก้อยเดินลงหนึ่ง ในบทหลัง ๆ แบบจำลองราคาหุ้นสร้างจาก Brownian motion ซึ่งก็คือ random walk ที่ก้าวเล็กและถี่จนเวลาต่อเนื่อง ตัวอย่างนี้จึงเป็นต้นแบบของการคำนวณกับ Brownian motion ทุกครั้ง คือแยกอนาคตเป็นส่วนที่รู้แล้วบวกส่วนที่ยังไม่รู้ แล้วดึงส่วนที่รู้แล้วออกมา

คำถามคือ ตำแหน่งหลังก้าวแรกกับตำแหน่งหลังก้าวที่สามเคลื่อนไปด้วยกันแค่ไหน ค่าที่ใช้วัดคือค่าเฉลี่ยของผลคูณ $E[S_1S_3]$ ถ้าสองตำแหน่งมักเป็นบวกพร้อมกันหรือลบพร้อมกัน ผลคูณจะเป็นบวกบ่อย ค่าเฉลี่ยของผลคูณจึงเป็นบวก

โจทย์ให้อะไรมาบ้าง:

  • $X_1,X_2,X_3$ คือผลของการโยนเหรียญสามครั้งที่อิสระกัน แต่ละครั้งเป็น $+1$ หรือ $-1$ ด้วยโอกาสเท่ากันคือ $\tfrac12$ ค่าเฉลี่ยของแต่ละก้าวจึงเป็น $\tfrac12(+1)+\tfrac12(-1)=0$
  • ตำแหน่งเริ่มที่ 0 ตำแหน่งหลังก้าวแรกคือ $S_1=X_1$
  • ตำแหน่งหลังก้าวที่สามคือ $S_3=X_1+X_2+X_3$

ทางลัดคือแยก $S_3$ เป็นส่วนที่รู้แล้วเมื่อรู้ก้าวแรก ($X_1$) บวกส่วนที่ยังไม่รู้ ($X_2+X_3$) หาค่าเฉลี่ยของ $S_3$ เมื่อรู้ก้าวแรกก่อน แล้วใช้ taking out what is known กับ $g(X_1)=S_1$

\[ \begin{aligned} E[S_3\mid X_1]&=X_1+E[X_2+X_3]\\ &=X_1+0=S_1,\\ E[S_1S_3]&=E\big[S_1\,E[S_3\mid X_1]\big]\\ &=E[S_1^2]=E[X_1^2]\\ &=1 \end{aligned} \]

คำตอบ: $E[S_1S_3]=1$ ค่าเฉลี่ยของ $S_3$ เมื่อรู้ก้าวแรก คือ $X_1$ บวกค่าเฉลี่ยของสองก้าวที่เหลือ สองก้าวนั้นอิสระจาก $X_1$ การรู้ก้าวแรกจึงไม่เปลี่ยนค่าเฉลี่ยของมัน ซึ่งยังเป็นศูนย์ จากนั้นดึง $S_1$ ออกมา เพราะรู้แล้วเมื่อรู้ $X_1$ เหลือ $E[S_1^2]$ และเพราะ $X_1$ เป็น $+1$ หรือ $-1$ เสมอ $X_1^2=1$ ทุกครั้ง ค่าเฉลี่ยจึงเป็น 1

ตรวจเองใน 10 วินาที: ไล่ครบแปดเส้นทาง ถ้าก้าวแรกเป็น +1 สี่เส้นทางจบที่ $S_3=3,1,1,-1$ ถ้าก้าวแรกเป็น −1 สี่เส้นทางจบที่ $S_3=1,-1,-1,-3$ ค่าเฉลี่ยของ $S_3$ ในแต่ละกลุ่มคือ

\[\begin{aligned}\frac{3+1+1-1}{4}&=1\\\frac{1-1-1-3}{4}&=-1\end{aligned}\]

กลุ่มแรกมี $S_1=+1$ ผลคูณ $S_1S_3$ จึงเฉลี่ย $(+1)(1)=1$ กลุ่มที่สองมี $S_1=-1$ ผลคูณจึงเฉลี่ย $(-1)(-1)=1$ สองกลุ่มโอกาสเท่ากัน ค่าเฉลี่ยรวมคือ $\tfrac12(1)+\tfrac12(1)=1$ ตรงกับทางลัด

ในเวลาต่อเนื่องทำแบบเดียวกัน ให้ $W_t$ คือตำแหน่งของ Brownian motion ณ เวลา $t$ ให้ $E_s$ คือค่าเฉลี่ยเมื่อรู้ข้อมูลถึงเวลา $s$ และ $E_0$ คือค่าเฉลี่ยเมื่อรู้แค่ข้อมูลวันนี้ นิยามของ Brownian motion ให้ของสามอย่างที่ต้องใช้

  • เริ่มที่ $W_0=0$
  • ส่วนที่เดินเพิ่มหลังเวลา $s$ คือ $W_{t+s}-W_s$ ไม่ขึ้นกับอดีต และเฉลี่ยเป็นศูนย์
  • variance ของ $W_s$ เท่ากับ $s$

เราแยก $W_{t+s}$ เป็นส่วนที่รู้แล้ว ณ เวลา $s$ บวกส่วนที่ยังไม่รู้ จากนั้นใช้ tower property เฉลี่ยผ่านเวลา $s$ ก่อน แล้วดึง $W_s$ ที่รู้แล้วออกมา

\[ \begin{aligned} E_s[W_{t+s}]&=W_s+E_s[W_{t+s}-W_s]\\ &=W_s+0,\\ E_0[W_{t+s}W_s]&=E_0\big[W_s\,E_s[W_{t+s}]\big]\\ &=E_0[W_s^2]=s \end{aligned} \]

ค่า $s$ ตัวสุดท้ายมาจากข้อที่ว่า $E_0[W_s^2]$ คือ variance ของ $W_s$ บวกค่าเฉลี่ยยกกำลังสอง ซึ่งเท่ากับ $s+0^2=s$ หน้า ตัวอย่างคำนวณ $E_0[W_{t+s}W_s]$ ทำเรื่องนี้อย่างละเอียด

ขั้นที่ 7 — ข้อมูลซ้อนกัน: เฉลี่ยย้อนทีละงวดบนต้นไม้ราคา

ในตลาด ข้อมูลเพิ่มขึ้นทุกวัน วันนี้เรารู้ราคาวันนี้ พรุ่งนี้เราจะรู้ราคาพรุ่งนี้เพิ่ม ถ้าวันนี้อยากรู้ค่าเฉลี่ยของราคาในอีกสองงวด ทำได้สองทาง ทางแรกเฉลี่ยทุกปลายทางตรง ๆ ทางที่สองยืนที่งวดหน้าก่อน หาค่าเฉลี่ยของงวดถัดไปจากจุดนั้น แล้วเฉลี่ยย้อนกลับมาที่วันนี้ ทางที่สองคือวิธีที่ใช้ตั้งราคา option บนต้นไม้ราคา (option คือสัญญาที่ให้สิทธิซื้อหรือขายหุ้นในราคาที่ตกลงไว้ล่วงหน้า)

กฎที่รับรองว่าสองทางได้ผลเดียวกัน คือ tower property แบบข้อมูลซ้อน ในสูตรนี้ $E[Y\mid\mathcal F_n]$ คือค่าพยากรณ์ของ $Y$ เมื่อรู้ข้อมูลถึงงวด $n$

\[E\big[E[Y\mid\mathcal F_{n+1}]\mid\mathcal F_n\big]=E[Y\mid\mathcal F_n]\]

สูตรนี้บอกว่า ถ้าเอาค่าพยากรณ์ที่ใช้ข้อมูลมากกว่า (รู้ถึงงวด $n+1$) มาเฉลี่ยด้วยข้อมูลที่น้อยกว่า (รู้ถึงงวด $n$) จะได้ค่าพยากรณ์ของข้อมูลที่น้อยกว่า จำง่าย ๆ ว่า “ข้อมูลน้อยชนะ” เพราะวันนี้เรายังไม่รู้ว่าพรุ่งนี้จะรู้อะไรเพิ่ม การเฉลี่ยจึงลบข้อมูลส่วนเกินนั้นทิ้ง เงื่อนไขคือข้อมูลต้องสะสม หมายถึงทุกอย่างที่รู้ ณ งวด $n$ ยังรู้อยู่ ณ งวด $n+1$

ลองใช้กับต้นไม้ราคาสมมติ

  • ราคาวันนี้ $S_0=\$100$
  • แต่ละงวด ราคาขึ้น 10% (คูณ 1.1) ด้วยโอกาส 0.6 หรือลง 10% (คูณ 0.9) ด้วยโอกาส 0.4
  • การขึ้นลงของแต่ละงวดอิสระกัน
  • $S_n$ คือราคา ณ งวด $n$ และ $E_n[\,\cdot\,]$ คือค่าเฉลี่ยเมื่อรู้ราคาถึงงวด $n$

เริ่มจากยืนที่งวด 1 ราคา $S_1$ รู้แล้ว จึงดึงออกมาได้ เหลือค่าเฉลี่ยของตัวคูณหนึ่งงวด จากนั้นเฉลี่ยย้อนกลับมาที่วันนี้

\[ \begin{aligned} E_1[S_2]&=S_1\,(0.6\times1.1+0.4\times0.9)\\ &=S_1\,(0.66+0.36)=1.02\,S_1,\\ E_0[S_1]&=1.02\times100=102,\\ E_0[S_2]&=E_0\big[E_1[S_2]\big]=1.02\,E_0[S_1]\\ &=1.02\times102=104.04 \end{aligned} \]

ค่าเฉลี่ยของราคาโตงวดละ 1.02 เท่า ไม่ว่าจะยืนอยู่ที่จุดไหน เพราะตัวคูณของแต่ละงวดอิสระจากอดีต การเฉลี่ยย้อนสองงวดจึงได้ $100\times1.02\times1.02=104.04$ ท่าที่ต้องหยุดดูคือ $E_0\big[E_1[S_2]\big]=E_0[S_2]$ ซึ่งก็คือกฎ “ข้อมูลน้อยชนะ” ด้านบน โดยใช้ $n=0$

ตรวจด้วยทางตรง ราคางวด 2 มีสามค่า ราคา 121 ต้องขึ้นสองครั้ง โอกาส $0.6\times0.6=0.36$ ราคา 99 ได้จากขึ้นแล้วลง หรือลงแล้วขึ้น ($100\times1.1\times0.9=99$) โอกาส $2\times0.6\times0.4=0.48$ ราคา 81 ต้องลงสองครั้ง โอกาส $0.4\times0.4=0.16$

\[\begin{aligned}E_0[S_2]&=0.36(121)+0.48(99)+0.16(81)\\&=43.56+47.52+12.96\\&=104.04\end{aligned}\]

ท่าเดียวกันนี้ใช้ยืด martingale จากหนึ่งงวดเป็นหลายงวด martingale คือกระบวนการ $M_n$ ที่ค่าเฉลี่ยของงวดหน้า เมื่อรู้ข้อมูลถึงวันนี้ เท่ากับค่าวันนี้ คือ $E_n[M_{n+1}]=M_n$ ทุก $n$ (ดู filtration และ martingale) ใช้กฎข้อมูลน้อยชนะแล้วได้

\[\begin{aligned}E_n[M_{n+2}]&=E_n\big[E_{n+1}[M_{n+2}]\big]\\&=E_n[M_{n+1}]\\&=M_n\end{aligned}\]

ท่านี้ยังใช้หาค่าเฉลี่ยของราคาใน GBM ที่มี drift μ ด้วย GBM (geometric Brownian motion) คือแบบจำลองราคาที่ค่าเฉลี่ยโตในอัตรา $\mu$ ต่อปี อัตรานี้เรียกว่า drift ส่วนราคาจริงแกว่งสุ่มรอบแนวโน้มนั้น บนต้นไม้ของเรา ค่าเฉลี่ยโตงวดละ 1.02 เท่า ใน GBM ค่าเฉลี่ยโตแบบต่อเนื่อง หน้านั้นจะแสดงว่าในช่วงเวลา $s$ ปี ค่าเฉลี่ยโต $e^{\mu s}$ เท่า คือ $E_t[S_{t+s}]=e^{\mu s}S_t$

ขั้นที่ 8 — ค่าเฉลี่ยรวมไวต่อความถี่ของสภาวะแค่ไหน

ตัวเลข 20% มาจากข้อมูลย้อนหลัง แต่ความถี่ของวันข่าวแรงไม่คงที่ บางปีข่าวน้อย บางปีมีวิกฤตต่อเนื่อง หัวหน้าทีมจึงถามข้อสองว่า วันข่าวแรงต้องเกิดบ่อยแค่ไหน กลยุทธ์จึงเริ่มขาดทุนโดยเฉลี่ย ขั้นนี้ตรึง P&L เฉลี่ยของสองสภาวะไว้ที่ค่าเดิม แล้วปล่อยให้โอกาสของวันข่าวแรงเป็นตัวแปร

โจทย์ให้อะไรมาบ้าง:

  • P&L เฉลี่ยของวันสงบ $m(\text{calm})=\$100$
  • P&L เฉลี่ยของวันข่าวแรง $m(\text{stress})=-\$600$
  • โอกาสของวันข่าวแรง $P(X=\text{stress})=p$ ซึ่งยังไม่กำหนดค่า โอกาสที่เหลือ $1-p$ จึงเป็นของวันสงบ

เขียนค่าเฉลี่ยรวมเป็นฟังก์ชันของ $p$ ด้วย tower property แล้วหาค่า $p$ ที่ทำให้ค่าเฉลี่ยรวมเป็นศูนย์พอดี

\[ \begin{aligned} E[Y]&=(1-p)(100)+p(-600)\\ &=100-100p-600p\\ &=100-700p,\\ 100-700p&=0\\ p&=\tfrac{100}{700}=\tfrac17\approx14.29\% \end{aligned} \]

คำตอบ: ถ้าวันข่าวแรงเกิดบ่อยกว่า 1 ใน 7 ของวัน ค่าเฉลี่ยติดลบ ความชันของเส้นคือ $-700$ ซึ่งก็คือส่วนต่างของค่าเฉลี่ยสองสภาวะ $-600-100=-700$ ความชันนี้บอกว่า ถ้า $p$ ผิดไป 1 จุด (เช่นจาก 20% เป็น 21%) ค่าเฉลี่ยรวมจะผิดไป $700\times0.01=\$7$ ต่อวัน

ตรวจเองใน 10 วินาที: แทน $p=0.2$ ได้ $100-700\times0.2=100-140=-40$ ตรงกับค่าเฉลี่ยรวมในขั้นที่ 2 แทน $p=0$ ได้ 100 ซึ่งคือกรณีที่มีแต่วันสงบ

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

หารสองแทนการถ่วงน้ำหนัก: การบวกค่าเฉลี่ยของสองสภาวะแล้วหารสอง ให้วันข่าวแรงหนักเท่าวันสงบ ทั้งที่วันข่าวแรงเกิดแค่ 20% ของวัน ทางผิดได้

\[\frac{100+(-600)}{2}=-250\]

ทางถูกถ่วงด้วยโอกาสของแต่ละสภาวะ

\[0.8(100)+0.2(-600)=-40\]

สองคำตอบต่างกัน $-40-(-250)=\$210$ ต่อวัน

แบ่งกรณีทับกัน: ถ้าแบ่งวันด้วยสองเกณฑ์ที่ต่างกัน กลุ่มอาจทับกัน เช่นกลุ่ม “วันความผันผวนต่ำ” มี 85% ของวัน เฉลี่ย +\$100 และกลุ่ม “วันมีข่าว” มี 20% ของวัน เฉลี่ย −\$600 โดยมี 5% ของวันที่อยู่ทั้งสองกลุ่ม ถ้าถ่วงตรง ๆ จะได้

\[0.85(100)+0.2(-600)=-35\]

−35 ดูสมเหตุสมผล แต่น้ำหนักรวม $0.85+0.2=1.05$ เกิน 1 แปลว่าวันที่ทับกัน 5% ถูกนับสองครั้ง ทางที่ถูกคือแบ่งใหม่ให้ไม่ทับกัน เป็นสามกลุ่ม

\[\begin{aligned}0.85-0.05&=0.80\\0.20-0.05&=0.15\\0.80+0.15+0.05&=1\end{aligned}\]

กลุ่มแรกคือวันความผันผวนต่ำที่ไม่มีข่าว 0.80 กลุ่มที่สองคือวันมีข่าวที่ความผันผวนไม่ต่ำ 0.15 กลุ่มที่สามคือวันที่เข้าทั้งสองเกณฑ์ 0.05 แล้วหา P&L เฉลี่ยของแต่ละกลุ่มใหม่ก่อนถ่วง ตรวจทุกครั้งว่าโอกาสรวมเป็น 1 พอดี

ใช้ข้อมูลที่ยังไม่รู้ตอนตัดสินใจ: backtest คือการทดสอบกลยุทธ์กับข้อมูลย้อนหลัง สมมติ backtest กติกา “เทรดเฉพาะวันสงบ วันข่าวแรงไม่เทรด” วันที่ไม่เทรดได้ P&L ศูนย์ ผลเฉลี่ยจึงดูดี

\[0.8(100)+0.2(0)=+80\]

แต่ป้าย “วันสงบ” หรือ “วันข่าวแรง” ติดได้หลังตลาดปิดเท่านั้น ตอนเช้าเรายังไม่รู้ว่าวันนี้เป็นวันแบบไหน จึงต้องเทรดทุกวัน ผลจริงคือ

\[0.8(100)+0.2(-600)=-40\]

ค่าเฉลี่ยแบบมีเงื่อนไขต้องใช้เฉพาะข้อมูลที่มีอยู่จริง ณ เวลาตัดสินใจ

แยกค่าเฉลี่ยของผลคูณ: สมมติ $E[Y\mid X]=3X$, $E[X]=2$ และ $\operatorname{Var}(X)=1$ จาก tower property $E[Y]=E[3X]=3\times2=6$ ทางผิดคูณค่าเฉลี่ยสองตัวตรง ๆ ได้ $E[X]\,E[Y]=2\times6=12$ ทางถูกดึง $X$ ออกในกรณีเดียวกันก่อน แล้วใช้ $E[X^2]=\operatorname{Var}(X)+(E[X])^2$ จาก variance

\[\begin{aligned}E[XY]&=E\big[X\,E[Y\mid X]\big]=3E[X^2]\\&=3(1+2^2)=15\end{aligned}\]

การคูณค่าเฉลี่ยสองตัวตรง ๆ ใช้ได้เมื่อ $X$ กับ $Y$ อิสระกัน ที่นี่ค่าเฉลี่ยของ $Y$ ขึ้นกับ $X$ ชัด ๆ จึงใช้ไม่ได้

ใช้ทำอะไรบนโต๊ะจริง

ทีมเทรดใช้กฎนี้ทุกครั้งที่คิดเป็นฉากทัศน์ (scenario) คือแบ่งอนาคตเป็นไม่กี่สภาวะ เช่น เศรษฐกิจโต ทรงตัว หรือถดถอย แล้วกำหนดโอกาสของแต่ละสภาวะ หา P&L เฉลี่ยในแต่ละสภาวะ แล้วถ่วงกลับด้วยโอกาส แบบเดียวกับวันสงบกับวันข่าวแรงในหน้านี้

ฝ่ายเครดิตของธนาคารใช้กฎนี้หาจำนวนลูกหนี้ที่ผิดนัดชำระหนี้ (default) โดยเฉลี่ยในพอร์ตสินเชื่อ ปัญหาคือลูกหนี้ไม่อิสระกัน พอเศรษฐกิจแย่ ทุกคนก็ลำบากพร้อมกัน วิธีแก้คือ condition บนปัจจัยเศรษฐกิจร่วมก่อน หมายถึงคิดแยกทีละค่าของปัจจัยนั้น เมื่อรู้ปัจจัยนั้นแล้ว ลูกหนี้แต่ละรายแทบอิสระกัน จึงคิดง่าย จากนั้นค่อยเฉลี่ยข้ามทุกค่าของปัจจัยด้วย tower property แนวคิดนี้คือหัวใจของ Gaussian copula และการตั้งราคา CDO (หลักทรัพย์ที่รวมหนี้หลายก้อนเข้าด้วยกัน แล้วแบ่งขายเป็นชั้นตามลำดับการรับความเสียหาย)

การตั้งราคา option บนต้นไม้ราคาก็คือการเฉลี่ยย้อนทีละงวด แบบในรูปต้นไม้ด้านบน ต่างกันตรงที่ใช้โอกาสชุดพิเศษที่ตั้งขึ้นเพื่อการตั้งราคา ไม่ใช่โอกาสที่ใครคิดว่าหุ้นจะขึ้น หน้า binomial tree จะอธิบายเหตุผล

โจทย์ตรวจความเข้าใจ

1. ปีนี้ตลาดเงียบกว่าเดิม ทีมประเมินว่าวันข่าวแรงจะเกิดแค่ 10% ของวัน ส่วน P&L เฉลี่ยของวันแต่ละแบบยังเท่าเดิม (+\$100 และ −\$600) ค่าเฉลี่ยรวมต่อวันเป็นเท่าไร และต่างจากค่าเฉลี่ยที่ควรใช้เมื่อรู้แน่ว่าพรุ่งนี้เป็นวันสงบอย่างไร

เฉลย

ถ่วงด้วยโอกาสใหม่ วันสงบ $1-0.1=0.9$ และวันข่าวแรง 0.1

\[\begin{aligned}0.9(100)+0.1(-600)&=90-60\\&=\$30\end{aligned}\]

ใช้เส้นตรงจากขั้นที่ 8 ก็ได้ผลเดียวกัน $100-700\times0.1=\$30$ ต่อวัน แต่ถ้ารู้แน่ว่าพรุ่งนี้เป็นวันสงบ ค่าเฉลี่ยที่ควรใช้คือ $E[Y\mid X=\text{calm}]=\$100$ คำตอบต่างกันเพราะข้อมูลที่รู้ต่างกัน ไม่ใช่เพราะกลยุทธ์เปลี่ยน

2. ทีมวิจัยดูสัญญาณตัวหนึ่งตอนเช้า เรียกค่าของสัญญาณว่า $X$ และให้ $Y$ คือ P&L ของวันนั้น ทีมพบว่า เมื่อรู้สัญญาณแล้ว P&L เฉลี่ยเป็นสามเท่าของสัญญาณ คือ $E[Y\mid X]=3X$ สัญญาณมีค่าเฉลี่ย $E[X]=2$ และ variance $\operatorname{Var}(X)=1$ (variance คือค่าเฉลี่ยของระยะห่างจากค่าเฉลี่ยยกกำลังสอง) จงหา $E[Y]$ และ $E[XY]$ (ตัวเลขสมมติ)

เฉลย

$E[Y]$ ใช้ tower property เฉลี่ย $E[Y\mid X]$ อีกชั้น ส่วน $E[XY]$ ใช้ taking out what is known ดึง $X$ ออกมาก่อน แล้วใช้สูตร $E[X^2]=\operatorname{Var}(X)+(E[X])^2$ จาก variance

\[\begin{aligned}E[Y]&=E[3X]=3\times2=6,\\E[X^2]&=1+2^2=5,\\E[XY]&=E\big[X\,E[Y\mid X]\big]\\&=E[3X^2]=3\times5=15\end{aligned}\]

คำตอบไม่ใช่ $E[X]E[Y]=2\times6=12$ ส่วนต่าง $15-12=3$ คือ covariance (ค่าที่วัดว่าสองตัวแปรขึ้นลงไปด้วยกันแค่ไหน) $\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]=3$ ตัวเลขนี้เท่ากับ $3\operatorname{Var}(X)$ พอดี เพราะ

\[\begin{aligned}E[XY]-E[X]E[Y]&=3E[X^2]-3(E[X])^2\\&=3\operatorname{Var}(X)=3\times1\end{aligned}\]

3. กลยุทธ์ momentum คือกลยุทธ์ที่ซื้อของที่ราคาขึ้นมาในช่วงก่อนหน้า และขายของที่ราคาลงมา กลยุทธ์ momentum ตัวหนึ่ง (ตัวเลขสมมติ) ให้ผลตอบแทนต่างกันตามสภาวะของตลาดในเดือนนั้น

  • เดือนความผันผวนต่ำ เกิดด้วยโอกาส 0.55 ผลตอบแทนเฉลี่ย 0.9% ต่อเดือน
  • เดือนปกติ เกิดด้วยโอกาส 0.32 ผลตอบแทนเฉลี่ย 0.3% ต่อเดือน
  • เดือนวิกฤต เกิดด้วยโอกาส 0.13 ผลตอบแทนเฉลี่ย −2.1% ต่อเดือน

จงหาผลตอบแทนเฉลี่ยต่อเดือน และหาว่าส่วนติดลบจากเดือนวิกฤต หักส่วนบวกจากอีกสองสภาวะไปกี่เปอร์เซ็นต์

เฉลย

ตรวจก่อนว่าสามสภาวะครอบคลุมทุกเดือนพอดี $0.55+0.32+0.13=1$ แล้วหาส่วนที่แต่ละสภาวะมีต่อค่าเฉลี่ย คือโอกาสคูณผลตอบแทนเฉลี่ย (หน่วยเป็น %)

\[\begin{aligned}0.55\times0.9&=0.495\\0.32\times0.3&=0.096\\0.13\times(-2.1)&=-0.273\\0.495+0.096-0.273&=0.318\end{aligned}\]

ผลตอบแทนเฉลี่ยคือ 0.318% ต่อเดือน ส่วนบวกจากสองสภาวะแรกรวมกันได้ $0.495+0.096=0.591$ เดือนวิกฤตหักไป

\[\frac{0.273}{0.591}\approx0.462=46.2\%\]

เดือนวิกฤตเกิดแค่ 13% ของเดือน แต่หักส่วนบวกไปเกือบครึ่ง

คำนวณซ้ำด้วย JavaScript

โค้ดนี้คำนวณตัวเลขหลักของหน้าซ้ำ ได้แก่ −40 จากการถ่วงน้ำหนัก เทียบกับ −250 จากการหารสอง จุดคุ้มทุน 1/7 ตารางโอกาสร่วมทั้งสองทาง แปดเส้นทางของ random walk ต้นไม้ราคาทั้งทางย้อนกลับและทางตรง และโจทย์ momentum

เปิดดูโค้ด 
const p = [0.8, 0.2], m = [100, -600];
const tower = p[0] * m[0] + p[1] * m[1];          // -40
const naive = (m[0] + m[1]) / 2;                  // -250 (wrong)
const breakEven = 1 / 7;                          // 0.142857

// joint table: rows X = 1, 2 ; columns Y = -2, 5
const joint = [[0.1, 0.2], [0.3, 0.4]], y = [-2, 5];
let viaRows = 0, direct = 0;
for (const row of joint) {
  const px = row[0] + row[1];
  const mx = (row[0] * y[0] + row[1] * y[1]) / px; // E[Y | X]
  viaRows += px * mx;
}
for (let j = 0; j < 2; j++) direct += (joint[0][j] + joint[1][j]) * y[j];

// random walk: E[S1 * S3] over 8 equally likely paths
let s1s3 = 0;
for (const a of [1, -1]) for (const b of [1, -1]) for (const c of [1, -1])
  s1s3 += a * (a + b + c) / 8;                    // 1

// two-period tree: x1.1 with prob 0.6, x0.9 with prob 0.4
const g = 0.6 * 1.1 + 0.4 * 0.9;                  // 1.02
const backward = 100 * g * g;                     // 104.04
const straight = 0.36 * 121 + 0.48 * 99 + 0.16 * 81;

const momentum = 0.55 * 0.9 + 0.32 * 0.3 + 0.13 * -2.1; // 0.318
console.log({tower, naive, breakEven, viaRows, direct, s1s3,
  backward, straight, momentum});

สิ่งที่ควรตอบได้หลังอ่าน

  • $E[Y\mid X=x]$ เป็นตัวเลขหนึ่งตัว แต่ $E[Y\mid X]$ เป็นตัวแปรสุ่มที่ค่าขึ้นกับ $X$ และมันไม่ใช่ $Y$
  • $E[Y]=E\big[E[Y\mid X]\big]$ ใช้ได้เมื่อ $E[|Y|]\lt\infty$ โดยไม่ต้องให้ $X$ กับ $Y$ อิสระกัน วันสงบ 80% กับวันข่าวแรง 20% ให้ $0.8(100)+0.2(-600)=-40$ ไม่ใช่ −250 จากการหารสอง
  • ของที่รู้แล้วดึงออกนอกค่าเฉลี่ยได้ $E[g(X)Y]=E\big[g(X)E[Y\mid X]\big]$ ท่านี้ให้ $E[S_1S_3]=1$ ใน random walk
  • เมื่อข้อมูลซ้อนกัน การเฉลี่ยย้อนทีละงวดได้ผลเดียวกับการเฉลี่ยตรง ๆ เช่น 104.04 บนต้นไม้ราคา
  • ถ้าโอกาสของวันข่าวแรงเปลี่ยน 1 จุด ค่าเฉลี่ยรวมเปลี่ยนเท่ากับส่วนต่างของค่าเฉลี่ยสองสภาวะคูณ 0.01 คือ $(-600-100)\times0.01=-\$7$ ต่อวัน

หน้าถัดไป law of total variance ใช้กฎเดียวกันกับ $Y^2$ แล้วแยก variance รวมเป็นสองส่วน ส่วนแรกคือการแกว่งภายในแต่ละสภาวะ ส่วนที่สองคือการที่ค่าเฉลี่ยของแต่ละสภาวะอยู่ห่างกัน
