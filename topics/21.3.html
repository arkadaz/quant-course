21.3 Fourier and FFT Pricing

แบบจำลองที่ไม่มีสูตรของ density มักมีสูตรของ characteristic function หน่วงราคา call ให้แปลง Fourier ได้ แล้วกลับเป็นราคาด้วยผลรวมเดียว ซึ่ง FFT คำนวณให้ทุก strike พร้อมกัน

calibration ของ 21.2 ต้องการราคา call ของ Heston หลาย strike ทุกครั้งที่อัลกอริทึมขยับ วิธีของ 14.7 ใช้ characteristic function 6,002 ครั้งต่อ strike (สองอินทิกรัล อินทิกรัลละ 3,001 จุด) smile เจ็ด strike จึงใช้ 42,014 ครั้ง เพื่อนเขียนเครื่องตั้งราคาแบบ Fourier ที่ได้ทุก strike พร้อมกัน แล้วทดสอบกับ call ที่รู้คำตอบ (หุ้น \$100 strike \$80 อายุ 1 ปี ดอกเบี้ย 5% ปันผล 1% ความผันผวน 30% ราคา Black–Scholes \$25.6146) ตั้งค่าหน่วง $\alpha=0.01$ ได้ 372.11 ตั้ง $\alpha=10$ บนกริด 64 จุดได้ 9.06 เขาสรุปว่าวิธีนี้ใช้ไม่ได้ ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก ผิดที่ค่าที่ตั้ง ไม่ใช่วิธี $\alpha=0.01$ สร้างยอดสูง 10,273 ที่แคบราว 0.01 ตรงความถี่ศูนย์ ซึ่งกริดที่ห่าง 0.25 มองไม่เห็นรูป ส่วน $\alpha=10$ บนกริด 64 จุดที่ห่าง 0.1 ตัดอินทิกรัลที่ความถี่ 6.3 ขณะที่ integrand ยังมีขนาด 12% ของยอด ที่ $\alpha=1.5$ ระยะความถี่ 0.25 และ 4,096 จุด ได้ \$25.6146 ตรงสูตร และ FFT ครั้งเดียวให้ 4,096 strike จาก characteristic function 4,096 ครั้ง smile ของ 14.7 ออกมาตรงทุกตัว ใช้งานน้อยกว่า 42,014 ครั้งราวสิบเท่า

สิ่งที่เราจะสร้าง

14.2 ตั้งราคา call เป็นค่าเฉลี่ยคิดลดของ payoff ถ่วงด้วย density ของราคาปลายทาง วิธีนี้ใช้ได้เมื่อเขียน density ได้ แต่ Heston ของ 14.7 เขียนไม่ได้ สิ่งที่ Heston ให้คือ characteristic function ซึ่ง 14.7 แปลงกลับเป็นราคาทีละ strike ด้วยสองอินทิกรัล หน้านี้สร้างทางที่เร็วกว่า

ลำดับคือ ตั้งราคาด้วย density ตรง ๆ ก่อนเพื่อมีคำตอบไว้เทียบ นิยาม characteristic function หาของ Black–Scholes ดูว่าทำไมต้องหน่วงราคา call ก่อนแปลง Fourier สร้าง transform ของ Carr–Madan กลับเป็นราคาด้วยผลรวมเดียว เปลี่ยนผลรวมเป็น FFT ที่ให้ทุก strike อธิบายตารางค่าที่ตั้งและ aliasing แล้วใช้โค้ดเดียวกันกับ Heston และ Variance Gamma จบที่ smile ของ 14.7 จาก FFT ครั้งเดียว

ขั้นที่ 1 — ราคาคือพื้นที่ใต้ payoff คูณ density แล้วคิดลด

เริ่มจากวิธีที่รู้อยู่แล้วเพื่อมีคำตอบไว้เทียบ ภายใต้ $\mathbb Q$ ของ 14.2 ราคา call คือค่าเฉลี่ยคิดลดของ payoff: คูณ payoff กับ density ของราคาปลายทาง แล้วหาพื้นที่ สำหรับ Black–Scholes density คือ lognormal ของ 1.10 ใช้กรณีทดสอบของหน้านี้ ($S_0=100$, $K=80$, $T=1$, $r=5\%$, $q=1\%$, $\sigma=30\%$) และแท่งสี่เหลี่ยมคางหมูกว้าง 0.2 จำนวน 4,096 แท่งเริ่มที่ strike

\[ \begin{aligned} C&=e^{-rT}\int_K^{\infty}(s-K)f(s)\,ds,\\ f(s)&=\frac{e^{-z^2/2}}{s\,\sigma\sqrt{2\pi T}},\\ z&=\frac{\ln s-\mu}{\sigma\sqrt T},\\ \mu&=\ln S_0+(r-q-\tfrac12\sigma^2)T\\ &=4.605170-0.005,\\ C_{\rm bars}&=25.61458,\\ C_{\rm BS}&=25.61462. \end{aligned} \]

payoff เป็นศูนย์เมื่อหุ้นจบต่ำกว่า strike อินทิกรัลจึงเริ่มที่ $K$ ค่า $-0.005$ มาจาก $0.05-0.01-\tfrac12(0.09)$ แท่งแรกอยู่ที่ strike พอดีจึงนับครึ่งแท่งตามกฎสี่เหลี่ยมคางหมู แท่งสุดท้ายอยู่ที่ราว \$899 ซึ่ง density แทบเป็นศูนย์ ผลต่างจากสูตรของ 14.2 ($d_1=1.027145$, $d_2=0.727145$) คือ 0.00004 ซึ่งมาจากความกว้างของแท่ง

วิธีนี้ตรงไปตรงมาและแม่น ปัญหาเดียวคือต้องมีสูตรของ $f$ Heston ของ 14.7 ไม่มี ขั้นต่อไปจึงย้ายไปใช้ของที่ Heston มี

ขั้นที่ 2 — characteristic function: ค่าเฉลี่ยของจุดบนวงกลม

ลองของเล่นที่แยกจากแบบจำลองราคาหุ้นก่อน: สุ่มได้ $X=0$ หรือ $X=1$ อย่างละครึ่ง ที่ความถี่ $u=0$ ทั้งสองผลชี้ไปทางขวาของวงกลม; ที่ $u=\pi$ ผล 0 ชี้ขวา แต่ผล 1 ชี้ซ้าย น้ำหนักบวกเท่ากันจึงหักล้างกันได้ จากนั้นค่อยใช้ characteristic function ของ $x_T=\ln S_T$ กับ Black–Scholes โดยจัดกำลังสองสมบูรณ์แบบเดียวกับ 8.5

ความถี่ผล $X=0$ (โอกาส 1/2)ผล $X=1$ (โอกาส 1/2)ค่าเฉลี่ยถ่วงน้ำหนัก
$u=0$$+1$$+1$$\tfrac12(+1)+\tfrac12(+1)=1$
$u=\pi$$+1$$-1$$\tfrac12(+1)+\tfrac12(-1)=0$
\[ \begin{aligned} \varphi(u)&=\mathbb E^{\mathbb Q}\big[e^{iux_T}\big],\\ \varphi_{01}(u)&=\tfrac12e^{iu\cdot0}+\tfrac12e^{iu\cdot1},\\ \varphi_{01}(0)&=1,\quad \varphi_{01}(\pi)=0,\\ x_T&=\mu+\sigma\sqrt T\,Z,\\ \varphi(u)&=e^{iu\mu}\,\mathbb E\big[e^{(iu\sigma\sqrt T)Z}\big]\\ &=e^{iu\mu-\frac12\sigma^2Tu^2},\\ \varphi(-i)&=e^{\mu+\frac12\sigma^2T}\\ &=S_0e^{(r-q)T}=104.0811. \end{aligned} \]

ทั้งสองผลยังมีโอกาส $1/2$ เท่าเดิม แม้ค่าเฉลี่ยที่ $u=\pi$ เป็นศูนย์: ศูนย์หมายถึงทิศทางเชิงซ้อนหักล้างกัน ไม่ใช่โอกาสเป็นศูนย์ เมื่อ $u=0$ ไม่มีการหมุนเลยจึงรวมได้ 1

นี่คือภาพของ $\varphi_{01}(0)=1$ และ $\varphi_{01}(\pi)=0$ ก่อนเรียกค่าเฉลี่ยของ $e^{iuX}$ ว่า characteristic function ขนาดของค่าเฉลี่ยจุดบนวงกลมจึงไม่เกินหนึ่ง ต่างจาก moment generating function ที่บางการแจกแจงไม่มีค่า

ค่าที่ทุก $u$ ร่วมกันบอกการแจกแจงได้ครบ แต่ตารางนี้เป็นเพียงตัวแปร 0/1 ไม่ใช่ราคา Black–Scholes หรือ Heston

บรรทัดที่ห้าใช้ผลของ 8.5 ว่า $\mathbb E[e^{tZ}]=e^{t^2/2}$ กับ $t=iu\sigma\sqrt T$ ซึ่งการจัดกำลังสองยังใช้ได้กับ $t$ เชิงซ้อน ได้ $t^2=-u^2\sigma^2T$ ส่วนจริงที่ติดลบคือตัวที่ทำให้คลื่นเล็กลงเมื่อความถี่สูง การตรวจที่ใช้ได้กับทุกแบบจำลองคือ $\varphi(0)=1$ และ $\varphi(-i)=\mathbb E[S_T]$ ซึ่งต้องเท่ากับ forward $100e^{0.04}=104.0811$

ขั้นที่ 3 — ทำไมต้องหน่วงราคา call ก่อนแปลง

อยากเขียนราคา call เป็นฟังก์ชันของ log-strike $k$ แล้วแปลง Fourier ทั้งเส้น แต่การแปลงต้องการให้ฟังก์ชันลดเป็นศูนย์ทั้งสองปลาย ราคา call ลดเป็นศูนย์เมื่อ strike สูงมาก แต่เมื่อ strike เข้าใกล้ศูนย์ ($k\to-\infty$) ราคาเข้าหา $S_0e^{-qT}$ ไม่ใช่ศูนย์ ทางแก้คือคูณด้วย $e^{\alpha k}$ ซึ่งเล็กลงเร็วเมื่อ $k$ ติดลบ

\[ \begin{aligned} C(k)&\to S_0e^{-qT}=99.005,\\ C(\ln1)&=98.054,\\ c(k)&=e^{\alpha k}\,C(k),\quad \alpha\gt0,\\ c(-5)&=e^{-7.5}\,C(-5)=0.0548,\\ \mathbb E\big[S_T^{\alpha+1}\big]&\lt\infty. \end{aligned} \]

ที่ strike \$1 call ยังมีค่า 98.054 เกือบเท่าหุ้น ถ้าไม่หน่วง พื้นที่ใต้ $C(k)$ ทางซ้ายยาวไม่สิ้นสุด ที่ $\alpha=1.5$ และ $k=-5$ (strike \$0.0067) ค่าที่หน่วงแล้วเหลือ 0.0548 และหดต่อตาม $e^{1.5k}$

ทางขวา $e^{\alpha k}$ โตขึ้น จึงต้องให้ $C(k)$ ลดเร็วกว่า เงื่อนไขนั้นคือบรรทัดสุดท้าย: moment ลำดับ $\alpha+1$ ของหุ้นต้องมีค่า แบบจำลองที่หางอ้วนมีขีดจำกัดของ $\alpha$ ส่วน Black–Scholes ไม่มี

ขั้นที่ 4 — transform ของ Carr–Madan: สลับลำดับอินทิกรัลแล้วคิดข้างในได้เอง

หา Fourier transform ของ $c(k)$ โดยแทนราคา call ด้วยนิยามของขั้นที่ 1 ในรูปของ $x=\ln s$ แล้วสลับว่าจะอินทิเกรตตาม $k$ หรือตาม $x$ ก่อน ตรึงราคาปลายทาง $x$ ไว้ call จ่ายเฉพาะ strike ที่ต่ำกว่า $e^x$ อินทิกรัลข้างในจึงวิ่งจาก $-\infty$ ถึง $x$ และมีคำตอบปิด

\[ \begin{aligned} \psi(u)&=\int_{-\infty}^{\infty}e^{iuk}c(k)\,dk,\\ z&=\alpha+iu,\\ I(x)&=\int_{-\infty}^{x}e^{zk}e^{x}\,dk\\ &\quad-\int_{-\infty}^{x}e^{(z+1)k}\,dk\\ &=\frac{e^{(z+1)x}}{z}-\frac{e^{(z+1)x}}{z+1}\\ &=\frac{e^{(z+1)x}}{z(z+1)},\\ \psi(u)&=\frac{e^{-rT}\,\mathbb E\big[e^{(z+1)x_T}\big]}{z(z+1)}\\ &=\frac{e^{-rT}\varphi\big(u-(\alpha+1)i\big)}{z(z+1)},\\ z(z+1)&=(\alpha+iu)(\alpha+1+iu). \end{aligned} \]

$I(x)$ คือส่วนที่เหลือของ $\psi$ เมื่อตรึงราคาปลายทางไว้ที่ $x$ มันคืออินทิกรัลของ exponential สองตัว: $\int e^{zk}e^x\,dk=e^xe^{zk}/z$ และ $\int e^{(z+1)k}dk=e^{(z+1)k}/(z+1)$ ปลายล่างหายไปเพราะ $\alpha\gt0$ ทำให้ $e^{zk}\to0$ เมื่อ $k\to-\infty$ นี่คือหน้าที่ของการหน่วงในภาษาของสูตร รวมสองก้อนได้ $1/z-1/(z+1)=1/(z(z+1))$

บรรทัดสุดท้ายคือกลเม็ดหลัก: $e^{(z+1)x}=e^{i(u-(\alpha+1)i)x}$ ค่าเฉลี่ยของมันจึงคือ characteristic function ที่ความถี่เลื่อนลงไปในแกนจินตภาพ $\alpha+1$ หน่วย ถ้ารู้ $\varphi$ ก็รู้ $\psi$ ทุกความถี่ ไม่ต้องรู้ density เลย สลับลำดับอินทิกรัลได้เพราะ moment ของขั้นที่ 3 มีค่า

ขั้นที่ 5 — กลับเป็นราคา: ครึ่งแกนบวก และผลรวมสี่เหลี่ยมคางหมู

ตอนนี้มี $\psi$ แล้ว ต้องแปลงกลับเป็น $c(k)$ แล้วหารการหน่วงออก เพราะ $c(k)$ เป็นจำนวนจริง ค่าที่ความถี่ $-u$ คือ conjugate ของค่าที่ $u$ อินทิกรัลทั้งเส้นจึงเหลือสองเท่าของส่วนจริงบนครึ่งแกนบวก แล้วแทนอินทิกรัลด้วยผลรวมบนกริด $u_j=j\eta$

\[ \begin{aligned} F(u)&=e^{-iuk}\psi(u),\\ F(-u)&=\overline{F(u)},\\ C(k)&=\frac{e^{-\alpha k}}{2\pi}\int_{-\infty}^{\infty}F\,du\\ &=\frac{e^{-\alpha k}}{\pi}\int_0^{\infty}\operatorname{Re}F\,du\\ &\approx\frac{e^{-\alpha k}}{\pi}\sum_{j=0}^{N-1}w_j\operatorname{Re}F(u_j),\\ u_j&=j\eta,\quad w_0=\eta/2,\\ w_j&=\eta\quad(j\ge1),\\ \alpha&=1.5,\ \eta=0.25,\ N=1{,}024,\\ C(\ln80)&=25.614621. \end{aligned} \]

$F$ คือสิ่งที่ต้องอินทิเกรต สองบรรทัดแรกบอกว่าค่าที่ $-u$ คือ conjugate ของค่าที่ $u$ เพราะ $c(k)$ เป็นจำนวนจริง บรรทัดที่สามคือการแปลงกลับของ Fourier ตามนิยามที่มี $1/(2\pi)$ อยู่ข้างหน้า บรรทัดที่สี่รวมครึ่งซ้ายกับครึ่งขวา: จำนวนเชิงซ้อนบวก conjugate ของมันได้สองเท่าของส่วนจริง สองตัดกับ $2\pi$ เหลือ $\pi$

จุดแรก $u_0=0$ ได้น้ำหนักครึ่งหนึ่งเพราะเป็นขอบของช่วงตามกฎสี่เหลี่ยมคางหมู

กรณีทดสอบได้ 25.614621 เท่ากับสูตรของ Black–Scholes ทุกหลักที่พิมพ์ และแม่นกว่าแท่ง density ของขั้นที่ 1 โดยใช้ characteristic function เพียง 1,024 ครั้ง ความถี่ไปถึง $1{,}023(0.25)=255.75$ ไกลเกินที่คลื่นยังมีขนาด

ขั้นที่ 6 — จากหนึ่ง strike เป็นทั้งแถว: เลือกกริดให้ผลรวมกลายเป็น FFT

ถ้าต้องการหลาย strike ผลรวมของขั้นที่ 5 ต้องทำใหม่ทุก strike ถ้าวาง log-strike เป็นกริด $k_m=k_0+m\lambda$ และเลือก $\lambda\eta=2\pi/N$ ตัวคูณ $e^{-iu_jk_m}$ จะแยกเป็นส่วนที่ขึ้นกับ $j$ อย่างเดียวคูณกับ $e^{-2\pi ijm/N}$ ซึ่งเป็นรูปของ discrete Fourier transform ที่ FFT คำนวณให้ทุก $m$ พร้อมกัน

\[ \begin{aligned} u_jk_m&=j\eta k_0+jm\,\eta\lambda\\ &=j\eta k_0+2\pi jm/N,\\ x_j&=w_j\,e^{-iu_jk_0}\,\psi(u_j),\\ C(k_m)&\approx\frac{e^{-\alpha k_m}}{\pi}\operatorname{Re}\sum_{j=0}^{N-1}x_j\,e^{-2\pi ijm/N},\\ N&=4{,}096,\ \eta=0.25,\\ \lambda&=\frac{2\pi}{4{,}096(0.25)}=0.006136,\\ N\log_2N&=49{,}152. \end{aligned} \]

บรรทัดแรกคือจุดที่ต้องเลือก: ถ้า $\eta\lambda=2\pi/N$ พจน์ที่สองเป็นมุมของ DFT พอดี ผลคือราคา 4,096 strike จาก characteristic function 4,096 ครั้งกับ FFT หนึ่งครั้ง ซึ่งใช้การคูณบวกราว $N\log_2N=49{,}152$ ครั้ง เทียบกับ $N^2=16.8$ ล้านครั้งถ้าบวกตรง ๆ

ราคาที่ต้องจ่ายคือสองกริดผูกกัน: อยากได้ความถี่ละเอียด ($\eta$ เล็ก) strike จะห่าง ที่นี่ $\lambda=0.006136$ คือ strike ห่างกันราว 0.61% กริดทั้งแถวกว้าง $N\lambda=25.1$ ในหน่วย log-strike

วางกริดได้สองแบบ: ให้ strike วันนี้อยู่กลางแถว ($k_0=\ln100-N\lambda/2=\ln100-12.566$ จุดที่ 2,048 จึงเป็น strike 100 พอดี) หรือให้ strike ที่สนใจเป็นตัวแรก ($k_0=\ln80$ ตัวถัดไปคือ $80e^{\lambda}=80.49$) แบบแรกกับ Black–Scholes $\sigma=20\%$ ($S_0=100$, $r=5\%$, $q=0$) ได้ 10.450584 ที่จุด 2,048 เท่ากับสูตร ($d_1=0.35$, $d_2=0.15$) strike ที่ไม่อยู่บนกริดใช้ interpolation แบบลูกบาศก์ใน $k$ จากสี่จุดรอบ ๆ ที่ strike 70, 85, 115, 130 และ 150 พลาดจากสูตรไม่เกิน $10^{-7}$

// Fourier pricing: direct integration against a density, characteristic functions, the Carr-Madan
// damped transform, one strike by the trapezoid rule, all strikes by one FFT, the alpha/eta/N table,
// aliasing, Heston and Variance Gamma through the same code, and the checks before calibration.
// Local names for the Math functions: shorter to read, and fast in any sandbox.
const { abs, exp, log, log2, sqrt, sin, cos, atan2, hypot, max, floor, PI, round } = Math;
// Complex numbers as {re, im}.
const cx = (re, im = 0) => ({re, im});
const add = (a, b) => cx(a.re + b.re, a.im + b.im), sub = (a, b) => cx(a.re - b.re, a.im - b.im);
const mul = (a, b) => cx(a.re * b.re - a.im * b.im, a.re * b.im + a.im * b.re), scale = (k, a) => cx(k * a.re, k * a.im);
const div = (a, b) => { const d = b.re * b.re + b.im * b.im; return cx((a.re * b.re + a.im * b.im) / d, (a.im * b.re - a.re * b.im) / d); };
const cexp = a => { const m = exp(a.re); return cx(m * cos(a.im), m * sin(a.im)); };
const clog = a => cx(log(hypot(a.re, a.im)), atan2(a.im, a.re));
function csqrt(a) { // principal root, imaginary part as Im(a) / (2 Re) to avoid cancellation (as in 14.7)
  const r = hypot(a.re, a.im);
  if (a.re >= 0) { const re = sqrt((r + a.re) / 2); return cx(re, re === 0 ? 0 : a.im / (2 * re)); }
  const im = (a.im < 0 ? -1 : 1) * sqrt((r - a.re) / 2); return cx(a.im / (2 * im), im);
}
function checkMarket(m) {
  if (m === null || typeof m !== 'object') throw new TypeError('Market must be an object');
  for (const k of ['S', 'T']) if (!(Number.isFinite(m[k]) && m[k] > 0)) throw new RangeError(`${k} must be a positive number`);
  if (!Number.isFinite(m.r) || !Number.isFinite(m.q)) throw new RangeError('r and q must be finite numbers');
  return m;
}
// Characteristic functions of x = ln S_T under Q, u complex.
const bsCF = (m, sigma) => u => cexp(add(scale(log(m.S) + (m.r - m.q - 0.5 * sigma * sigma) * m.T, mul(cx(0, 1), u)), scale(-0.5 * sigma * sigma * m.T, mul(u, u))));
function hestonCF(m, p) { // stable form of 14.7 step 8
  if (!(p.kappa > 0 && p.theta > 0 && p.xi > 0 && p.v0 > 0 && p.rho > -1 && p.rho < 1)) throw new RangeError('Heston needs kappa, theta, xi, v0 > 0 and -1 < rho < 1');
  return u => {
    const iu = mul(cx(0, 1), u), b = sub(cx(p.kappa), scale(p.rho * p.xi, iu));
    const d = csqrt(add(mul(b, b), scale(p.xi * p.xi, add(iu, mul(u, u))))), g = div(sub(b, d), add(b, d)), e = cexp(scale(-m.T, d));
    const B = mul(scale(1 / (p.xi * p.xi), sub(b, d)), div(sub(cx(1), e), sub(cx(1), mul(g, e))));
    const A = add(scale((m.r - m.q) * m.T, iu), scale(p.kappa * p.theta / (p.xi * p.xi), sub(scale(m.T, sub(b, d)), scale(2, clog(div(sub(cx(1), mul(g, e)), sub(cx(1), g)))))));
    return cexp(add(add(A, scale(p.v0, B)), scale(log(m.S), iu)));
  };
}
function vgCF(m, sigma, nu, th) { // Variance Gamma: Brownian motion with drift th run on a gamma clock of variance rate nu
  const base = 1 - th * nu - 0.5 * sigma * sigma * nu;
  if (!(base > 0)) throw new RangeError('Variance Gamma parameters give no finite forward');
  const omega = log(base) / nu;
  return u => { const iu = mul(cx(0, 1), u), z = add(sub(cx(1), scale(th * nu, iu)), scale(0.5 * sigma * sigma * nu, mul(u, u)));
    return div(cexp(scale(log(m.S) + (m.r - m.q + omega) * m.T, iu)), cexp(scale(m.T / nu, clog(z)))); };
}
// Normal CDF (as in 14.1) and Black-Scholes with a dividend yield (14.2): the benchmark.
const npdf = x => exp(-0.5 * x * x) / sqrt(2 * PI);
function ncdf(x) {
  const a = abs(x);
  if (a <= 3) { let t = a, s = a; for (let n = 1; n < 200 && t > 1e-17 * s; n++) { t *= a * a / (2 * n + 1); s += t; } return x >= 0 ? 0.5 + npdf(a) * s : 0.5 - npdf(a) * s; }
  let f = a; for (let k = 120; k >= 1; k--) f = a + k / f; return x >= 0 ? 1 - npdf(a) / f : npdf(a) / f;
}
function bsCall(m, K, sigma) {
  const v = sigma * sqrt(m.T), d1 = (log(m.S / K) + (m.r - m.q + 0.5 * sigma * sigma) * m.T) / v, d2 = d1 - v;
  return {call: m.S * exp(-m.q * m.T) * ncdf(d1) - K * exp(-m.r * m.T) * ncdf(d2), d1, d2};
}
// Step 1: price = discounted payoff times the lognormal density, trapezoid bars of width h from the strike up.
function densityPrice(m, K, sigma, h, n) {
  const mu = log(m.S) + (m.r - m.q - 0.5 * sigma * sigma) * m.T, v = sigma * sqrt(m.T);
  let s = 0;
  for (let j = 0; j < n; j++) { const x = K + j * h, f = exp(-0.5 * ((log(x) - mu) / v) ** 2) / (x * v * sqrt(2 * PI)); s += (j === 0 ? h / 2 : h) * (x - K) * f; }
  return exp(-m.r * m.T) * s;
}
// Step 4: the Carr-Madan transform of the damped call price.
const psi = (m, phi, alpha, u) => div(scale(exp(-m.r * m.T), phi(cx(u, -(alpha + 1)))), mul(cx(alpha, u), cx(alpha + 1, u)));
function checkGrid(alpha, eta, N) {
  if (!(alpha > 0)) throw new RangeError('Damping alpha must be positive');
  if (!(eta > 0)) throw new RangeError('Frequency step eta must be positive');
  if (!(Number.isInteger(N) && N >= 2 && (N & (N - 1)) === 0)) throw new RangeError('N must be a power of two');
}
// Step 5: one strike, trapezoid on u_j = j eta, j = 0..N-1 (first weight eta / 2).
function carrMadan(m, phi, K, alpha, eta, N) {
  checkMarket(m); checkGrid(alpha, eta, N);
  const k = log(K); let s = 0;
  for (let j = 0; j < N; j++) { const u = j * eta; s += (j === 0 ? eta / 2 : eta) * mul(cexp(cx(0, -u * k)), psi(m, phi, alpha, u)).re; }
  return exp(-alpha * k) / PI * s;
}
// Step 6: radix-2 FFT, X_m = sum_j x_j exp(-2 pi i j m / N).
function fft(x) {
  const N = x.length; if (N === 1) return [x[0]];
  const even = fft(x.filter((_, i) => i % 2 === 0)), odd = fft(x.filter((_, i) => i % 2 === 1)), out = new Array(N);
  for (let m = 0; m < N / 2; m++) { const t = mul(cexp(cx(0, -2 * PI * m / N)), odd[m]); out[m] = add(even[m], t); out[m + N / 2] = sub(even[m], t); }
  return out;
}
// Step 6: all strikes at once. Log-strikes k_m = start + m lambda with lambda eta = 2 pi / N.
function carrMadanFFT(m, phi, alpha, eta, N, start) {
  checkMarket(m); checkGrid(alpha, eta, N);
  const lambda = 2 * PI / (N * eta), x = [];
  for (let j = 0; j < N; j++) { const u = j * eta; x.push(scale((j === 0 ? eta / 2 : eta), mul(cexp(cx(0, -u * start)), psi(m, phi, alpha, u)))); }
  const X = fft(x);
  return X.map((z, i) => { const k = start + i * lambda; return {K: exp(k), k, call: exp(-alpha * k) / PI * z.re}; });
}
// Black-Scholes implied volatility by bisection (to read the Heston smile).
function impliedVol(m, K, price) {
  const lo0 = max(m.S * exp(-m.q * m.T) - K * exp(-m.r * m.T), 0);
  if (!(price > lo0 && price < m.S * exp(-m.q * m.T))) throw new RangeError('Price is outside the no-arbitrage range for a call');
  let lo = 1e-4, hi = 4; for (let i = 0; i < 100; i++) { const mid = (lo + hi) / 2; if (bsCall(m, K, mid).call > price) hi = mid; else lo = mid; }
  return (lo + hi) / 2;
}
// Cubic (four-point Lagrange) interpolation in log-strike on the FFT ladder.
function interpolate(ladder, K) {
  const k = log(K), step = ladder[1].k - ladder[0].k, i = floor((k - ladder[0].k) / step) - 1;
  if (i < 0 || i + 3 >= ladder.length) throw new RangeError('Strike is outside the FFT ladder');
  const pts = ladder.slice(i, i + 4);
  return pts.reduce((s, p, a) => s + p.call * pts.reduce((w, q, b) => (a === b ? w : w * (k - q.k) / (p.k - q.k)), 1), 0);
}

ที่มาที่ไป

Heston (1993) ตั้งราคา option ด้วยการแปลงกลับของ characteristic function ทีละ strike ในรูปสองความน่าจะเป็นแบบที่ 14.7 ใช้ Peter Carr กับ Dilip Madan (1999) หน่วงราคา call ด้วย $e^{\alpha k}$ ให้แปลง Fourier ได้ทั้งเส้น แล้วใช้ FFT ของ Cooley กับ Tukey (1965) คำนวณทุก strike พร้อมกัน หลังจากนั้นมีวิธีที่ต่อยอดอีกหลายแบบ เช่นอินทิกรัลเดียวของ Lewis (2001) และวิธี COS ของ Fang กับ Oosterlee (2008) ที่ใช้อนุกรม cosine แทน

สิ่งที่ควรตอบได้หลังอ่าน

  • ราคาคือพื้นที่ใต้ payoff คูณ density (25.6146 จากแท่ง 4,096 แท่ง) แต่แบบจำลองอย่าง Heston ไม่มี density ให้ มีแต่ characteristic function ที่ต้องผ่าน $\varphi(0)=1$ และ $\varphi(-i)=$ forward
  • ราคา call ต้องหน่วงด้วย $e^{\alpha k}$ ก่อนแปลง แล้ว transform ของ Carr–Madan คือ $e^{-rT}\varphi(u-(\alpha+1)i)/((\alpha+iu)(\alpha+1+iu))$ ซึ่งได้จากการสลับลำดับอินทิกรัล
  • เลือก $\lambda\eta=2\pi/N$ แล้วผลรวมกลายเป็น FFT: 4,096 strike จาก characteristic function 4,096 ครั้ง ราว 49,152 การคูณบวก smile ของ 14.7 ออกมาตรงทุกตัว
  • $\alpha$ เล็กเกินให้ยอดที่กริดมองไม่เห็น (372.11) $\alpha$ ใหญ่บนกริดสั้นตัดอินทิกรัล (9.06) และ $\eta$ ใหญ่ทำให้หน้าต่าง strike สั้นจนหางวนทับ (0.18 ที่ $\eta=1.5$)
  • ตาราง Heston ที่ใช้สอนกรณีนี้ (25.2428) รันด้วยปันผลศูนย์ ค่าที่ถูกเมื่อปันผล 1% คือ 24.3325
