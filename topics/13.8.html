13.8 Simulating Stochastic Differential Equations — Euler, Milstein, and Exact Schemes

ราคาที่ได้จากการจำลอง SDE มีความคลาดสองก้อน คือก้อนจากจำนวนเส้นทางที่หดเมื่อสุ่มมากขึ้น กับก้อนจากความยาวก้าวที่สุ่มเท่าไรก็ไม่หาย และหน้านี้วัดก้อนที่สองให้เห็นเป็นตัวเลข

หุ้นสมมติ \$100 drift 12% ความผันผวน 28% ต่อปี ทีมหนึ่งจำลองหนึ่งปีด้วยสูตร Euler แค่ 4 ก้าว เส้นทางหนึ่งได้ \$116.08 ขณะที่สูตรจริงบนเลขสุ่มชุดเดียวกันได้ \$114.66 หัวหน้าบอกว่าไม่เป็นไร สุ่ม 1,000,000 เส้นทางแล้วเฉลี่ย ความคลาดจะหักล้างกันหมด และช่วงความเชื่อมั่น 95% จะแคบราว ±\$0.06 ช่วงนั้นจะครอบค่าเฉลี่ยจริง \$112.75 ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ครอบ ความคลาดรายเส้นส่วนใหญ่หักล้างกันจริง แต่เหลือ bias ที่คิดได้ตรง ๆ: ค่าเฉลี่ยของ Euler 4 ก้าวคือ $100(1.03)^4=\$112.55$ ต่ำกว่าค่าจริง \$0.20 หรือ 6.4 เท่าของ SE (\$0.031) ช่วงความเชื่อมั่นจึงแคบรอบตัวเลขที่ผิด เพิ่มเส้นทางเท่าไรก็ไม่ช่วย ต้องซอยก้าว (ที่ 252 ก้าว bias เหลือ \$0.0032) หรือใช้สูตรจริงซึ่งไม่มี bias เลย

ภาพรวมก่อนลงสูตร

ทั้งบทนี้ใช้การสุ่มตรวจผลมาหลายครั้ง ทั้งตอนตรวจ Itô's lemma, กฎผลคูณของสองราคา และ Feynman–Kac หน้านี้หันมาตรวจตัวเครื่องสุ่มเอง ตอนนิยาม SDE เราเขียนมันเป็นสูตรก้าวเล็ก ๆ: ขยับด้วย drift คูณเวลา บวกตัวคูณคูณการขยับของ Brownian motion สูตรนั้นคือ Euler ถ้าก้าวยาวจริงในโค้ด สูตรนี้คลาดเท่าไร

มีสามทางให้เลือก Euler อ่านค่าที่ต้นก้าวแล้วตรึงไว้ทั้งก้าว Milstein เติมพจน์แก้หนึ่งพจน์ที่ได้จาก Itô integral ส่วนสูตรจริงสุ่มจากการกระจายที่แท้จริงของแบบจำลอง เช่นของ GBM ที่ $S_{t+\Delta t}=S_te^{(\mu-\frac12\sigma^2)\Delta t+\sigma\Delta W}$ ซึ่งใช้ได้ทุกความยาวก้าว รูปด้านล่างวางสามทางบนเส้นทาง Brownian เส้นเดียวกัน: เส้นเขียวบางคือเส้นทางจริงที่ละเอียด จุดเขียวคือสูตรจริงที่สี่จุดของตาราง ส่วนเส้นน้ำเงินและแดงคือ Milstein และ Euler ที่เดินสี่ก้าว

หน้านี้สร้างสามสูตร เดินสี่ก้าวด้วยมือ อธิบายว่าทำไม Euler สูงไปในเส้นทางนี้ นิยามความแม่นสองแบบ วัดอัตราที่ความคลาดหดจากการสุ่ม 20,000 เส้นทาง คิด bias ของค่าเฉลี่ยแบบตรงเป๊ะเพื่อตอบโจทย์เปิดเรื่อง แล้วจบที่ราคาติดลบและการเลือกสูตรบนโต๊ะ

ศัพท์ที่ใช้ในหัวข้อนี้
Euler–Maruyama scheme
สูตรเดินก้าวที่อ่าน drift และตัวคูณของ $dW$ ที่ต้นก้าวแล้วถือว่าคงที่ทั้งก้าว คือนิยามของ SDE ในรูปก้าวเล็ก ใช้ได้กับทุก SDE ด้วยโค้ดที่ง่ายที่สุด
Milstein scheme
Euler บวกพจน์แก้ $\tfrac12bb'\big((\Delta W)^2-\Delta t\big)$ ที่คิดว่าตัวคูณของ $dW$ เปลี่ยนไปตามค่าที่ขยับระหว่างก้าว ใช้ลดความคลาดของเส้นทางเดี่ยว
Exact scheme
สุ่มจากการกระจายจริงของแบบจำลองในแต่ละก้าว เช่นสูตร exponential ของ GBM หรือ Normal ของ Vasicek ไม่มีความคลาดจากความยาวก้าวเลย
Strong error และ weak error
strong error วัดว่าเส้นทางที่จำลองห่างจากเส้นทางจริงบนเลขสุ่มชุดเดียวกันเท่าไร weak error วัดแค่ว่าค่าเฉลี่ยของสิ่งที่สนใจเพี้ยนเท่าไร การตั้งราคาต้องการแบบหลัง การหา delta ด้วยการขยับราคาต้องการแบบแรก
Discretization bias
ความคลาดเชิงระบบจากการใช้ก้าวยาวจำกัด ไม่หายเมื่อเพิ่มจำนวนเส้นทาง ต้องตรวจด้วยการซอยก้าวถี่ขึ้น
Common random numbers
ใช้เลขสุ่มชุดเดียวกันกับทุกสูตรที่เทียบกัน ความต่างที่เห็นจึงมาจากสูตร ไม่ใช่จากโชค
Brownian bridge
เส้นทาง Brownian ที่ถูกตรึงค่าที่สองจุดเวลา ใช้เติมเส้นทางระหว่างจุดของตาราง หรือคิดโอกาสที่เส้นทางแตะ barrier ระหว่างสองวันที่สังเกต

ขั้นที่ 1 — สร้างการขยับ แล้วเดินแบบ Euler

ทุกสูตรเริ่มจากการสร้าง $\Delta W$ การขยับของ Brownian motion มาตรฐาน ในเวลา $\Delta t$ มี variance เท่ากับ $\Delta t$ จึงต้องคูณเลขสุ่มมาตรฐานด้วย $\sqrt{\Delta t}$ แล้ว Euler คือนิยามของ SDE ตรง ๆ: อ่าน $a$ และ $b$ ที่ต้นก้าวแล้วตรึงไว้ทั้งก้าว ใช้หนึ่งปีสี่ก้าวกับเลขสุ่มสี่ตัวที่จะใช้ร่วมกันทุกสูตรในหน้านี้

\[ \begin{aligned} \Delta W_k&=\sqrt{\Delta t}\,Z_k,\quad \Delta t=0.25,\\ Z&=(0.5,\ -1.2,\ 0.8,\ 0.3),\\ \Delta W&=0.5\,Z\\ &=(0.25,\ -0.60,\ 0.40,\ 0.15),\\ X_{k+1}&=X_k+a(X_k)\,\Delta t\\ &\quad+b(X_k)\,\Delta W_k. \end{aligned} \]

ถ้าเผลอคูณด้วย $\Delta t$ แทน $\sqrt{\Delta t}$ ก้าวรายวันจะให้ความผันผวนต่อปีแค่ $0.28/\sqrt{252}=1.76\%$ แทน 28% เล็กไป 16 เท่า ทั้งที่กราฟเส้นทางยังดูสมเหตุสมผล (252 คือจำนวนวันทำการต่อปีของตลาดหุ้นสหรัฐ) Euler ทิ้งข้อเท็จจริงหนึ่งข้อ: ระหว่างก้าว $X$ ขยับไปแล้ว ตัวคูณ $b(X)$ จึงไม่คงที่จริง

ขั้นที่ 2 — พจน์แก้ของ Milstein มาจาก Itô integral ในหนึ่งก้าว

Milstein เก็บผลที่ $b$ เปลี่ยนระหว่างก้าว ด้วย Taylor หนึ่งพจน์ของ $b$ และแทนการขยับของ $X$ ด้วยส่วนสุ่มของมัน แล้วต้องหา integral ของการขยับที่สะสมระหว่างก้าว ซึ่งคือ $\int W\,dW=\tfrac12(W^2-T)$ ของหน้า Itô integral ที่ใช้กับก้าวเดียว

\[ \begin{aligned} b(X_s)&\approx b(X_k)+b'(X_k)\,b(X_k)\\ &\quad\times(W_s-W_k),\\ \int_{t_k}^{t_{k+1}}(W_s-W_k)\,dW_s&=\tfrac12\big[(\Delta W_k)^2-\Delta t\big],\\ \text{Milstein}&=\text{Euler}\\ &\quad+\tfrac12\,b\,b'\big[(\Delta W_k)^2-\Delta t\big]. \end{aligned} \]

บรรทัดแรกใช้ $X_s-X_k\approx b\,(W_s-W_k)$ ส่วน drift ของการขยับเล็กกว่าอีกขั้นจึงทิ้งได้ บรรทัดที่สองไม่ใช่ $\tfrac12(\Delta W)^2$ อย่างที่ calculus ปกติให้ ต้องหัก $\Delta t$ ออกตาม Itô การหักนี้ทำให้พจน์แก้เฉลี่ยศูนย์ Milstein จึงดัดเส้นทางให้ตรงขึ้นโดยไม่ย้ายค่าเฉลี่ย

ขั้นที่ 3 — สามสูตรของ GBM คือ Taylor ของสูตรจริงที่ตัดคนละที่

GBM มี $b=\sigma S$ จึงได้ $b'=\sigma$ และพจน์แก้ $\tfrac12\sigma^2S\big((\Delta W)^2-\Delta t\big)$ สูตรจริงของหนึ่งก้าวคือรูปที่การแก้ SDE ของ GBMให้ ให้ $u$ เป็นเลขชี้กำลังของมัน แล้วกระจาย $e^u$ ถึงอันดับสอง โดย $u^2=\sigma^2(\Delta W)^2$ บวกพจน์ขนาด $\Delta t^{3/2}$ ที่ทิ้งได้

\[ \begin{aligned} S^X_{k+1}&=S_k\,e^{u},\\ u&=(\mu-\tfrac12\sigma^2)\Delta t+\sigma\Delta W_k,\\ e^u&\approx1+u+\tfrac12\sigma^2(\Delta W_k)^2\\ &=1+\mu\Delta t+\sigma\Delta W_k\\ &\quad+\tfrac12\sigma^2\big[(\Delta W_k)^2-\Delta t\big],\\ \frac{S^M_{k+1}}{S_k}&=1+\mu\Delta t+\sigma\Delta W_k\\ &\quad+\tfrac12\sigma^2\big[(\Delta W_k)^2-\Delta t\big],\\ \frac{S^E_{k+1}}{S_k}&=1+\mu\Delta t+\sigma\Delta W_k. \end{aligned} \]

$-\tfrac12\sigma^2\Delta t$ จาก drift ของ log รวมกับ $+\tfrac12\sigma^2(\Delta W)^2$ จากกำลังสอง ได้พจน์แก้ของ Milstein พอดี Milstein จึงคือสูตรจริงที่ตัดที่อันดับสอง ส่วน Euler ตัดเร็วกว่าหนึ่งขั้น ในรูปของตัวคูณต่อก้าว: สูตรจริงเป็น exponential ของเลขสุ่ม Milstein เป็นพาราโบลา Euler เป็นเส้นตรง รูปด้านล่างวาดสามตัวคูณนี้ในกรณีที่ก้าวยาวและหุ้นผันผวนสูง เพื่อให้เห็นช่องว่างชัด

ขั้นที่ 4 — เดินสี่ก้าวด้วยมือ: เลขสุ่มชุดเดียว สามสูตร

โจทย์ให้อะไรมาบ้าง: $S_0=\$100$, $\mu=0.12$, $\sigma=0.28$, $\Delta t=0.25$ จึงได้ $\mu\Delta t=0.03$ และ $\tfrac12\sigma^2=0.0392$ ใช้การขยับสี่ตัวที่สร้างไว้ ก้าวแรกของแต่ละสูตรคิดได้ด้วยมือ แล้วเดินต่อจนครบสี่ก้าว

\[ \begin{aligned} S^E_1&=100(1+0.03+0.07)=110,\\ S^M_1&=110+100(0.0392)(0.0625-0.25)\\ &=109.265,\\ S^X_1&=100\,e^{0.0202+0.07}=109.4393. \end{aligned} \]

ตรวจเองใน 10 วินาที: ก้าวแรกของ Milstein หัก $0.0392\times0.1875\times100=0.735$ ออกจาก Euler เพราะ $(\Delta W)^2=0.0625$ น้อยกว่า $\Delta t=0.25$ และสูตรจริงปลายทางคือ $100e^{0.0808+0.28(0.2)}=100e^{0.1368}=114.66$ ใช้แค่ผลรวม $\sum\Delta W=0.2$

ขั้นที่ 5 — ทำไม Euler สูงไป: เส้นทางนี้มีผลรวมกำลังสองน้อยกว่าหนึ่งปี

เทียบ log ของผลคูณตัวคูณ Euler กับ log ของสูตรจริง แล้วใช้ $\ln(1+x)\approx x-\tfrac12x^2$ ดูว่าส่วนต่างมาจากไหน ตัวคูณของ Euler สี่ก้าวคือ 1.100, 0.862, 1.142 และ 1.072

\[ \begin{aligned} \textstyle\sum\ln(\text{Euler})&=0.09531-0.14850\\ &\quad+0.13278+0.06953\\ &=0.14912,\\ \ln(S^X_4/100)&=0.0808+0.28(0.2)\\ &=0.1368,\\ \text{gap}&=0.01232,\quad e^{0.01232}=1.0124,\\ \tfrac12\sigma^2\big(T-\textstyle\sum(\Delta W_k)^2\big)&=0.0392(1-0.605)\\ &=0.0155. \end{aligned} \]

ถ้าใช้แค่อันดับสอง log ของตัวคูณ Euler หัก $\tfrac12\sigma^2$ คูณผลรวมกำลังสองของการขยับที่เกิดจริง แต่สูตรจริงหัก $\tfrac12\sigma^2$ คูณเวลาเต็มหนึ่งปี เส้นทางนี้มี $\sum(\Delta W)^2=0.605$ น้อยกว่าหนึ่งปี Euler จึงหักน้อยไป ค่าประมาณอันดับสองให้ 0.0155 พจน์อันดับสูงกว่าหักลงเหลือ 0.0123 ที่เห็นจริง

นี่คือบทเรียนของผลรวมกำลังสองของการขยับในอีกรูป: ผลรวมนั้นเท่ากับเวลาเมื่อซอยละเอียด แต่สี่ก้าวยังแกว่งได้มาก (SD ของผลรวมสี่ก้าวคือ $\sqrt{2/4}=0.707$) Euler ผูกความคลาดของตัวเองไว้กับการแกว่งนี้

ขั้นที่ 6 — ความแม่นสองแบบ และทำไม Euler ได้ค่าเฉลี่ยดีกว่าได้เส้นทาง

สองนิยามข้างล่างวัดคนละอย่าง strong error ดูเส้นทางเทียบเส้นทางบนเลขสุ่มชุดเดียวกัน weak error ดูแค่ค่าเฉลี่ยของสิ่งที่สนใจ $\varphi$ ตัวเลขชี้กำลัง $p$ บอกว่าความคลาดหดเร็วแค่ไหนเมื่อซอยก้าว จากนั้นดูพจน์ $\epsilon_k$ ที่ Euler ทิ้งไปว่ามันสะสมอย่างไร

\[ \begin{aligned} \mathbb E\big|X_T-X_T^{\Delta t}\big|&\propto\Delta t^{\,p_s},\\ \big|\mathbb E[\varphi(X_T)]-\mathbb E[\varphi(X_T^{\Delta t})]\big|&\propto\Delta t^{\,p_w},\\ \epsilon_k&=\tfrac12bb'\big[(\Delta W_k)^2-\Delta t\big],\\ \mathbb E_k[\epsilon_k]&=\tfrac12bb'(\Delta t-\Delta t)=0,\\ \operatorname{SD}(\epsilon_k)&=\tfrac12|bb'|\sqrt2\,\Delta t,\\ \operatorname{SD}\Big(\textstyle\sum_{k=1}^{n}\epsilon_k\Big)&\propto\sqrt n\,\Delta t=\sqrt{T\,\Delta t}. \end{aligned} \]

พจน์ที่ทิ้งเฉลี่ยศูนย์ทุกก้าว เมื่อเฉลี่ยหลายเส้นทางจึงหักล้างกัน แต่บนเส้นทางเดียวมันสะสมแบบรากของจำนวนก้าว เพราะเป็นผลรวมของก้อนที่อิสระกัน ได้ขนาด $\Delta t^{1/2}$ Euler จึงมี $p_s=\tfrac12$ ส่วน weak error มาจากพจน์ที่เล็กกว่า ได้ $p_w=1$

Milstein เก็บ $\epsilon_k$ ไว้จึงได้ $p_s=1$ ส่วน $p_w$ ยังเป็น 1 เท่า Euler ตัวเลขอันดับเหล่านี้เป็นผลมาตรฐานสำหรับ SDE ที่ $a$ และ $b$ เรียบ (ยกมาใช้) ขั้นถัดไปวัดมันจริง

ขั้นที่ 7 — วัด strong error จริง: 20,000 เส้นทาง ห้าขนาดก้าว

โจทย์ให้อะไรมาบ้าง: โค้ดท้ายหน้าสร้างเส้นทาง Brownian ละเอียด 64 ก้าวต่อปี 20,000 เส้นด้วย seed 138 แล้วรวมก้าวเล็กเป็นก้าวใหญ่ให้ได้ 4, 8, 16, 32 และ 64 ก้าว ทุกสูตรใช้การขยับชุดเดียวกัน และสูตรจริงใช้ปลายทาง $W_1$ เดียวกัน วัดค่าเฉลี่ยของ $|S-S^X|$ เป็นดอลลาร์

ขั้นที่ 8 — คำตอบของโจทย์เปิดเรื่อง: bias ของค่าเฉลี่ยแบบตรงเป๊ะ

โจทย์ให้อะไรมาบ้าง: ค่าเฉลี่ยของ Euler คิดได้โดยไม่ต้องสุ่ม ทุกก้าวคูณด้วย $1+\mu\Delta t+\sigma\Delta W$ ซึ่งเฉลี่ย $1+\mu\Delta t$ และแต่ละก้าวอิสระกัน ค่าเฉลี่ยของผลคูณจึงเป็นผลคูณของค่าเฉลี่ย พจน์แก้ของ Milstein เฉลี่ยศูนย์ จึงได้ค่าเฉลี่ยเดียวกัน ค่าจริงคือ $S_0e^{\mu}$ (ราคาคาดหวังของ GBM) ส่วน SD ของ Euler 4 ก้าวได้จากค่าเฉลี่ยของกำลังสองของตัวคูณ $1.03^2+0.28^2(0.25)$

\[ \begin{aligned} \mathbb E[S^E_1]&=100(1+0.12/n)^n,\\ \text{bias}&=100e^{0.12}-100(1+0.12/n)^n,\\ n=4,\ 8,\ 16&:\ 0.1988,\ 0.1004,\ 0.0505,\\ n=252&:\ 0.0032,\\ \operatorname{SD}(S^E_1)&=\sqrt{10^4(1.03^2+0.0196)^4-112.5509^2}\\ &=31.02. \end{aligned} \]

คำตอบ: Euler 4 ก้าวเฉลี่ย \$112.5509 ต่ำกว่าค่าจริง \$112.7497 อยู่ \$0.1988 ที่ 1,000,000 เส้นทาง standard error คือ $31.02/1{,}000=\$0.031$ ช่วง 95% คือ $112.55\pm0.061$ ซึ่งไม่ครอบ \$112.75 bias เท่ากับ 6.4 SE และคงที่ไม่ว่าสุ่มกี่เส้น ทุกครั้งที่ก้าวสั้นลงครึ่งหนึ่ง bias หารด้วยราว 2 ตาม $p_w=1$ ที่ 252 ก้าวเหลือ \$0.0032

ตรวจเองใน 10 วินาที: $1.03^4=1.12551$ และ $e^{0.12}=1.12750$ ต่างกัน 0.00199 คูณ 100 ได้ราว \$0.20

ขั้นที่ 9 — เมื่อไร Euler ให้ราคาติดลบ

ตัวคูณของ Euler เป็นเส้นตรงของ $Z$ จึงติดลบได้เมื่อ $Z$ ลบมากพอ (ตามรูปตัวคูณด้านบน) แก้หาเกณฑ์ ($\sigma\sqrt{\Delta t}\gt0$ จึงหารได้โดยไม่กลับทิศ) แล้วลองสามกรณี: หุ้นของโจทย์ หุ้นผันผวน 80% ก้าวละหนึ่งปี และตัวเดียวกันก้าวละเดือน

\[ \begin{aligned} 1+\mu\Delta t+\sigma\sqrt{\Delta t}\,Z&\lt0,\\ Z&\lt-\frac{1+\mu\Delta t}{\sigma\sqrt{\Delta t}},\\ \sigma=0.28,\ \Delta t=0.25&:\ Z\lt-7.36,\\ \sigma=0.80,\ \Delta t=1&:\ Z\lt-1.40,\\ &\quad\Phi(-1.40)=8.08\%,\\ \sigma=0.80,\ \Delta t=\tfrac1{12}&:\ Z\lt-4.373,\\ &\quad\Phi(-4.373)=0.00061\%. \end{aligned} \]

ในโจทย์หลักต้องได้เลขสุ่มต่ำกว่า −7.36 ซึ่งแทบไม่เกิด แต่หุ้นที่ผันผวน 80% จำลองก้าวละปี ราวหนึ่งในสิบสองเส้นทางได้ราคาติดลบ แล้ว log ของราคาและรากของราคาพังทั้งชุด ซอยเป็นรายเดือนเหลือโอกาสราว 0.0073% ต่อปี (12 ก้าว) ทางที่ดีกว่าคือไม่ใช้ Euler กับราคาดิบเลย ใช้สูตรจริงหรือเดิน Euler บน log ราคา ส่วน Milstein ของ GBM ไม่ติดลบในกรณีนี้ (ต่ำสุด 0.30) เพราะพาราโบลาของมันไม่ตัดศูนย์ตราบที่ $\sigma^2\Delta t\lt1+2\mu\Delta t$

ขั้นที่ 10 — สูตรจริงของ Vasicek และเมื่อ Milstein เท่ากับ Euler

การแก้ SDE ของ Vasicekให้การกระจายของดอกเบี้ยที่เวลาใดก็ได้: Normal ที่ค่าเฉลี่ยถูกดึงหา $\theta$ และ variance $\sigma_V^2(1-e^{-2\kappa t})/(2\kappa)$ ใช้มันเป็นสูตรก้าวที่ตรงเป๊ะ โดยเริ่มจาก $r_k$ แล้วใส่เวลา $\Delta t$ ส่วน Milstein ของ Vasicek มี $b=\sigma_V$ คงที่ จึงได้ $b'=0$ ใช้ $\kappa=0.8$, $\theta=3\%$ และ $\sigma_V=1.2\%$

\[ \begin{aligned} r_{k+1}&=\theta+(r_k-\theta)e^{-\kappa\Delta t}\\ &\quad+\sigma_V\sqrt{\frac{1-e^{-2\kappa\Delta t}}{2\kappa}}\,Z_k,\\ \Delta t=\tfrac1{252}&:\ e^{-0.8/252}=0.996830,\\ \operatorname{SD}&=0.00075473,\\ \text{Euler SD}&=0.012\sqrt{1/252}\\ &=0.00075593,\\ b'=0&:\ \text{Milstein}=\text{Euler}. \end{aligned} \]

ก้าวรายวันของ Euler กับของสูตรจริงต่างกันน้อยมาก (SD ต่างกัน 0.16%) แต่สูตรจริงใช้ก้าวยาวเท่าไรก็ได้ สำหรับพันธบัตรห้าปี ก้าวเดียวห้าปีก็ตรงเป๊ะ Milstein ไม่ช่วย Vasicek เลย และการที่ Milstein ตรงกับ Euler ก็ไม่ได้แปลว่าทั้งคู่ตรงกับคำตอบจริง

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

คูณเลขสุ่มด้วย $\Delta t$ แทน $\sqrt{\Delta t}$: ก้าวรายวันให้ความผันผวนต่อปี 1.76% แทน 28% ราคา option ทุกตัวถูกตีต่ำไปมาก ตรวจได้ทันทีด้วย realized variance ของเส้นทางที่จำลอง (ผลรวมกำลังสองของผลตอบแทน) ซึ่งต้องใกล้ $\sigma^2T$

เชื่อช่วงความเชื่อมั่นเรื่อง bias ของก้าว: Euler 4 ก้าวกับ 1,000,000 เส้นทางให้ $112.55\pm0.06$ ที่ไม่ครอบค่าจริง \$112.75 ช่วงความเชื่อมั่นวัดได้แค่ความคลาดจากการสุ่ม ต้องรายงาน bias จากการซอยก้าวแยกอีกก้อน

เทียบสูตรด้วยเลขสุ่มคนละชุด: ถ้าสุ่ม Euler กับสูตรจริงแยกกันคนละ 20,000 เส้น ผลต่างของค่าเฉลี่ยจะแกว่งด้วย SE ราว $\sqrt2\times31/141=0.31$ ดอลลาร์ ใหญ่กว่า bias \$0.20 ที่อยากวัด ต้องใช้ common random numbers เสมอ

ใช้ Euler บนราคาดิบเมื่อผันผวนสูงและก้าวยาว: หุ้นผันผวน 80% ก้าวละปีได้ราคาติดลบใน 8.08% ของก้าว ค่าเฉลี่ยของ log ราคาหรือรากของราคาจะเป็นตัวเลขที่ไม่มีความหมาย

รู้ได้อย่างไรว่าก้าวสั้นพอ? รันสองขนาดก้าว เช่น $n$ กับ $2n$ ด้วยเลขสุ่มชุดเดิม ถ้า $p_w=1$ bias ของ $n$ ก้าวประมาณได้เป็นสองเท่าของผลต่างระหว่างสองรัน ในหุ้นของหน้านี้ ผลต่างระหว่าง 8 กับ 16 ก้าวคือ $0.1004-0.0505=0.0499$ จึงประมาณ bias ของ 16 ก้าวได้ราว 0.050 ตรงกับ 0.0505 ที่คิดตรง ๆ ต้นไม้ binomial ก็เป็นการซอยเวลาแบบหนึ่ง ราคาจากต้นไม้เข้าหา Black–Scholes เมื่อจำนวนงวดเพิ่ม และควรตรวจด้วยหลักเดียวกัน งบความคลาดของทุกราคาจาก Monte Carlo จึงมีสองบรรทัดเสมอ: SE จากจำนวนเส้นทาง และ bias จากขนาดก้าว (Monte Carlo และ bootstrap ดูการสรุปผลจากการสุ่มอย่างเป็นระบบ)

3. หุ้นที่ผันผวน 80% จำลองด้วย Euler ก้าวละเดือน โอกาสที่เส้นทางหนึ่งจะมีราคาติดลบภายในปีคือเท่าไร?

// Standard Normal CDF: Simpson's rule on the bell curve from 0 to |x|.
function Phi(x) {
  if (!Number.isFinite(x) || Math.abs(x) > 8) throw new RangeError('Phi needs a finite score between -8 and 8');
  const n = 4000, h = Math.abs(x) / n, phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(x) * s * h / 3;
}
function checkModel(m) {
  if (![m.S0, m.mu, m.sigma].every(Number.isFinite) || m.S0 <= 0 || m.sigma <= 0) throw new RangeError('Need S0 > 0, sigma > 0 and a finite mu');
}
// One step of each GBM scheme from S with step dt and Brownian increment dW.
const schemes = {
  euler: (m, S, dt, dW) => S * (1 + m.mu * dt + m.sigma * dW),
  milstein: (m, S, dt, dW) => S * (1 + m.mu * dt + m.sigma * dW + 0.5 * m.sigma * m.sigma * (dW * dW - dt)),
  exact: (m, S, dt, dW) => S * Math.exp((m.mu - 0.5 * m.sigma * m.sigma) * dt + m.sigma * dW)
};
// Walk all three schemes on the same shocks z (common random numbers), dW = sqrt(dt) z.
function walk(m, z, T) {
  checkModel(m);
  if (!Array.isArray(z) || z.length === 0 || !z.every(Number.isFinite)) throw new TypeError('Need a nonempty list of finite shocks');
  const dt = T / z.length, rows = [{euler: m.S0, milstein: m.S0, exact: m.S0}];
  for (const x of z) {
    const dW = Math.sqrt(dt) * x, prev = rows[rows.length - 1], next = {};
    for (const k of Object.keys(schemes)) next[k] = schemes[k](m, prev[k], dt, dW);
    rows.push(next);
  }
  return {dt, dW: z.map(x => Math.sqrt(dt) * x), rows};
}
// mulberry32 + Box-Muller: seeded standard Normals, the same generator on every page of this chapter.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Strong error E|S_scheme - S_exact| at T = 1 on the same Brownian path, for several step counts.
function strongErrors(m, stepList, paths, seed) {
  checkModel(m);
  const maxN = Math.max(...stepList);
  if (!stepList.every(n => Number.isInteger(n) && n >= 1 && maxN % n === 0)) throw new RangeError('Step counts must be whole and divide the finest grid');
  const z = normals(seed), out = stepList.map(n => ({n, euler: 0, milstein: 0}));
  for (let p = 0; p < paths; p++) {
    const fine = Array.from({length: maxN}, () => z() * Math.sqrt(1 / maxN));
    stepList.forEach((n, j) => {
      const r = maxN / n, dt = 1 / n;
      let E = m.S0, M = m.S0, W = 0;
      for (let k = 0; k < n; k++) {
        let dW = 0;
        for (let i = 0; i < r; i++) dW += fine[k * r + i];
        E = schemes.euler(m, E, dt, dW); M = schemes.milstein(m, M, dt, dW); W += dW;
      }
      const X = m.S0 * Math.exp((m.mu - 0.5 * m.sigma * m.sigma) + m.sigma * W);
      out[j].euler += Math.abs(E - X) / paths; out[j].milstein += Math.abs(M - X) / paths;
    });
  }
  return out;
}
// Weak bias of the mean, exactly: E[S_Euler] = S0 (1 + mu dt)^n (the Milstein term has mean zero too).
function meanBias(m, n) {
  checkModel(m);
  return m.S0 * Math.exp(m.mu) - m.S0 * (1 + m.mu / n) ** n;
}
// Chance that one Euler step makes the price negative: Z below -(1 + mu dt) / (sigma sqrt(dt)).
function negativeStep(m, dt) {
  checkModel(m);
  const z = -(1 + m.mu * dt) / (m.sigma * Math.sqrt(dt));
  return {z, p: z < -8 ? 0 : Phi(z)};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • $\Delta W=\sqrt{\Delta t}\,Z$ เสมอ คูณด้วย $\Delta t$ ทำให้ความผันผวนรายวันรวมทั้งปีเหลือ 1.76% แทน 28%
  • Euler คือนิยาม SDE บนตาราง Milstein เติม $\tfrac12bb'\big((\Delta W)^2-\Delta t\big)$ จาก Itô integral ในหนึ่งก้าว และทั้งคู่คือ Taylor ของสูตรจริงของ GBM ที่ตัดคนละที่ (เส้นตรง พาราโบลา exponential)
  • สี่ก้าวของหุ้น \$100: สูตรจริง \$114.66 Euler +1.24% Milstein −0.08% เพราะเส้นทางนี้มี $\sum(\Delta W)^2=0.605$ ไม่ใช่ 1
  • วัดจริง: strong error ของ Euler หารด้วย 1.41 และของ Milstein หารด้วย 1.99 ทุกครั้งที่ก้าวสั้นลงครึ่งหนึ่ง
  • bias ของค่าเฉลี่ยไม่หายด้วยการเพิ่มเส้นทาง: Euler 4 ก้าวต่ำไป \$0.20 หรือ 6.4 SE ที่ 1,000,000 เส้นทาง ต้องซอยก้าวหรือใช้สูตรจริง
