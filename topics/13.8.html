13.8 Simulating Stochastic Differential Equations — Euler, Milstein, and Exact Schemes

ราคาที่ได้จากการจำลอง SDE คลาดได้สองทาง ทางแรกมาจากจำนวนเส้นทางที่สุ่ม และหดลงเมื่อสุ่มมากขึ้น ทางที่สองมาจากความยาวของก้าวเวลา และสุ่มมากเท่าไรก็ไม่หาย หน้านี้วัดทางที่สองให้เห็นเป็นตัวเลข

ทีม quant ของธนาคารมักหาราคาเฉลี่ยของหุ้นในอนาคตด้วยการจำลองบนคอมพิวเตอร์ เรียกว่า Monte Carlo: สุ่มเส้นทางราคาที่เป็นไปได้จำนวนมาก แล้วเฉลี่ยราคาปลายทาง แต่คอมพิวเตอร์เดินเวลาแบบต่อเนื่องไม่ได้ มันต้องเดินเป็นก้าว ก้าวละช่วงเวลาสั้น ๆ คำถามของหน้านี้คือ การเดินเป็นก้าวทำให้คำตอบเพี้ยนไปเท่าไร

ของที่รู้ (ตัวเลขสมมติ):

  • ราคาหุ้นวันนี้ $S_0=\$100$
  • drift $\mu=12\%$ ต่อปี คืออัตราที่ราคาโตโดยเฉลี่ย
  • ความผันผวน $\sigma=28\%$ ต่อปี คือขนาดการแกว่งของราคา วัดเป็น SD (standard deviation) ของผลตอบแทนในหนึ่งปี
  • จำลองหนึ่งปี แบ่งเป็น 4 ก้าว ก้าวละไตรมาส ความยาวก้าวจึงเป็น $\Delta t=1/4=0.25$ ปี

ทีมใช้สูตรเดินก้าวที่ง่ายที่สุด ชื่อ Euler ทุกก้าว ราคาโตตาม drift แล้วบวกการแกว่งสุ่มหนึ่งครั้ง ลองเดินเส้นทางหนึ่งด้วย Euler ได้ราคาปลายปี \$116.08 แต่ยังมีอีกสูตรหนึ่งที่เราเรียกว่า “สูตรจริง” สูตรนี้ไม่มีความคลาดจากการเดินเป็นก้าวเลย ถ้าป้อนเลขสุ่มชุดเดียวกันให้สูตรจริง เส้นทางเดียวกันจบที่ \$114.66 สองตัวเลขนี้หน้านี้จะคำนวณให้ดูทีละก้าวในขั้นที่ 4

หัวหน้าทีมบอกว่าไม่เป็นไร เส้นทางเดียวคลาดได้ แต่ถ้าสุ่ม $N=1{,}000{,}000$ เส้นทางแล้วเฉลี่ย ความคลาดจะหักล้างกันเอง เขาจะรายงานผลเป็นช่วงความเชื่อมั่น 95% คือค่าเฉลี่ยที่ได้ บวกลบ 1.96 เท่าของ SE

  • SE (standard error) คือขนาดที่ค่าเฉลี่ยจากการสุ่มแกว่ง คิดจาก SD ของราคาปลายทาง หารด้วย $\sqrt N$
  • SD ของราคาปลายทางของ Euler คือ \$31.02 ตัวเลขนี้หน้านี้จะคำนวณให้ดูในขั้นที่ 8
  • 1.96 คือระยะ (นับเป็นจำนวน SD) ที่ครอบ 95% ของรูประฆัง Normal

ช่วงของหัวหน้าจึงกว้างข้างละ

\[\begin{aligned}\text{SE}&=\frac{31.02}{\sqrt{1{,}000{,}000}}=\$0.031,\\1.96\,\text{SE}&=1.96\times0.031=\$0.061.\end{aligned}\]

ราคาเฉลี่ยที่ถูกต้องของหุ้นตัวนี้ในอีกหนึ่งปีรู้อยู่แล้ว คือ $S_0e^{\mu}=100e^{0.12}=\$112.75$ (สูตรจากหน้า ราคาคาดหวังของ GBM) คำถามคือ ช่วงแคบ ±\$0.061 ของหัวหน้าจะครอบ \$112.75 ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ครอบ ความคลาดของแต่ละเส้นส่วนใหญ่หักล้างกันจริง แต่เหลือส่วนหนึ่งที่เอียงไปทางเดียวกันทุกเส้น ส่วนนี้เรียกว่า bias และสำหรับหุ้นตัวนี้ bias คิดได้ตรง ๆ โดยไม่ต้องสุ่ม ทุกก้าวของ Euler คูณราคาด้วยตัวคูณ $1+\mu\Delta t+\sigma\Delta W$ ส่วนสุ่ม $\sigma\Delta W$ เฉลี่ยเป็นศูนย์ ตัวคูณจึงเฉลี่ยได้ $1+\mu\Delta t=1+0.12\times0.25=1.03$ ให้ $\mathbb E[S^E_4]$ คือราคาเฉลี่ยของ Euler หลังสี่ก้าว สี่ก้าวจึงได้

\[\begin{aligned}\mathbb E[S^E_4]&=100(1.03)^4=\$112.5509,\\\text{bias}&=112.7497-112.5509\\&=\$0.1988,\\\frac{\text{bias}}{\text{SE}}&=\frac{0.1988}{0.031}=6.4.\end{aligned}\]

ค่าเฉลี่ยที่หัวหน้าได้จะอยู่แถว \$112.55 ช่วงของเขาคือ $112.55\pm0.061=[112.49,\ 112.61]$ ช่วงนี้แคบ แต่แคบรอบตัวเลขที่ผิด เพราะ bias ใหญ่กว่า SE ถึง 6.4 เท่า เพิ่มเส้นทางเท่าไรก็ไม่ช่วย เพราะ bias ไม่ขึ้นกับจำนวนเส้นทาง ทางแก้มีสองทาง ทางแรกคือซอยก้าวให้สั้นลง เช่นที่ 252 ก้าว (ก้าวละวันทำการ) bias เหลือ \$0.0032 ซึ่งขั้นที่ 8 คิดให้ดู ทางที่สองคือใช้สูตรจริงซึ่งไม่มี bias เลย

ภาพรวมก่อนลงสูตร

SDE (stochastic differential equation) คือสมการที่บอกว่า ค่าหนึ่ง เช่นราคาหุ้น $X$ ขยับอย่างไรในเวลาสั้น ๆ $dt$

\[dX=a(X)\,dt+b(X)\,dW.\]

ส่วนแรก $a\,dt$ คือการขยับที่แน่นอน เรียกว่า drift ส่วนที่สอง $b\,dW$ คือการขยับสุ่ม $dW$ คือการขยับเล็ก ๆ ของ Brownian motion (การเดินสุ่มแบบต่อเนื่อง) และ $b$ คือตัวคูณที่บอกว่าการสุ่มนั้นแรงแค่ไหน ทั้ง $a$ และ $b$ ขึ้นกับค่า $X$ ณ ตอนนั้น

ทั้งบทนี้เราสุ่มเส้นทางจาก SDE เพื่อตรวจผลมาหลายครั้ง ทั้งตอนตรวจ Itô's lemma, กฎผลคูณของสองราคา และ Feynman–Kac หน้านี้หันมาตรวจตัวเครื่องสุ่มเอง ปัญหาคือ ในโค้ด $dt$ เล็กจนเป็นศูนย์ไม่ได้ คอมพิวเตอร์ต้องใช้ก้าวยาว $\Delta t$ ที่มีขนาดจริง เช่นหนึ่งวันหรือหนึ่งไตรมาส คำถามของหน้าคือ ก้าวที่ยาวจริงทำให้คำตอบคลาดเท่าไร

สูตรเดินก้าวที่หน้านี้เทียบกันมีสามแบบ:

  • Euler อ่านค่า $a$ และ $b$ ที่ต้นก้าว แล้วถือว่าคงที่ทั้งก้าว
  • Milstein เพิ่มพจน์แก้หนึ่งพจน์ เพราะระหว่างก้าว $X$ ขยับไปแล้ว $b(X)$ จึงขยับตาม พจน์นี้ได้มาจาก Itô integral
  • สูตรจริง (exact scheme) สุ่มค่าปลายก้าวจากการกระจายที่แท้จริงของแบบจำลอง ตัวอย่างคือ GBM (geometric Brownian motion แบบจำลองราคาหุ้นที่ขยับเป็นสัดส่วนของราคาตัวเอง) ซึ่งมีสูตรจริง $S_{t+\Delta t}=S_te^{(\mu-\frac12\sigma^2)\Delta t+\sigma\Delta W}$ ใช้ได้กับก้าวยาวเท่าไรก็ได้

รูปด้านล่างใช้หุ้นของโจทย์เปิดเรื่อง และป้อนเส้นทาง Brownian เส้นเดียวกันให้ทั้งสามสูตร เส้นเขียวบางคือเส้นทางจริงที่ละเอียด จุดเขียวคือค่าจากสูตรจริงที่ปลายแต่ละก้าว เส้นน้ำเงินคือ Milstein และเส้นแดงคือ Euler ซึ่งเดินสี่ก้าวเท่ากัน

ลำดับของหน้า: สร้างสามสูตร เดินสี่ก้าวด้วยมือ อธิบายว่าทำไม Euler สูงไปในเส้นทางนี้ นิยามความแม่นสองแบบ วัดว่าความคลาดหดเร็วแค่ไหนจากการสุ่ม 20,000 เส้นทาง คิด bias ของค่าเฉลี่ยแบบตรงเป๊ะเพื่อตอบโจทย์เปิดเรื่อง แล้วจบที่ราคาติดลบ และการเลือกสูตรในงานจริง

ศัพท์ที่ใช้ในหัวข้อนี้
Euler–Maruyama scheme
สูตรเดินก้าวที่ง่ายที่สุด อ่าน drift $a$ และตัวคูณ $b$ ของ $dW$ ที่ต้นก้าว แล้วถือว่าคงที่ทั้งก้าว คือการเขียน SDE เป็นก้าวยาว $\Delta t$ ตรง ๆ ใช้ได้กับทุก SDE
Milstein scheme
Euler บวกพจน์แก้ $\tfrac12bb'\big((\Delta W)^2-\Delta t\big)$ โดย $b'$ คืออัตราที่ตัวคูณ $b$ เปลี่ยนเมื่อ $X$ ขยับ พจน์นี้คิดผลที่ $b$ เปลี่ยนไประหว่างก้าว จึงช่วยให้แต่ละเส้นทางแม่นขึ้น
Exact scheme (สูตรจริง)
สุ่มค่าปลายก้าวจากการกระจายที่แท้จริงของแบบจำลอง เช่นสูตร exponential ของ GBM หรือการกระจาย Normal ของ Vasicek จึงไม่มีความคลาดจากความยาวก้าวเลย
Strong error และ weak error
strong error วัดว่าเส้นทางที่จำลองอยู่ห่างจากเส้นทางจริงเท่าไร เมื่อใช้เลขสุ่มชุดเดียวกัน weak error วัดแค่ว่าค่าเฉลี่ยของสิ่งที่สนใจ เช่นเงินที่สัญญาจ่าย เพี้ยนไปเท่าไร การตั้งราคาสัญญาสนใจแบบหลัง เพราะราคาคือค่าเฉลี่ย งานที่ต้องให้ทุกเส้นทางถูกสนใจแบบแรก ตัวอย่างคือการหา delta (ราคาสัญญาเปลี่ยนเท่าไรเมื่อราคาหุ้นขยับ \$1) ด้วยการขยับราคาตั้งต้นแล้วจำลองซ้ำ
Discretization bias
ความคลาดที่เอียงไปทางเดียว เกิดจากการใช้ก้าวที่ยาวจริง เพิ่มจำนวนเส้นทางแล้วไม่หาย ต้องตรวจด้วยการซอยก้าวให้ถี่ขึ้น
Common random numbers
ใช้เลขสุ่มชุดเดียวกันกับทุกสูตรที่เทียบกัน ความต่างที่เห็นจึงมาจากตัวสูตร ไม่ใช่จากโชค
Brownian bridge
เส้นทาง Brownian ที่ถูกตรึงค่าไว้ที่สองจุดเวลา ใช้เติมเส้นทางระหว่างสองจุดของตาราง หรือคิดโอกาสที่ราคาแตะ barrier (ระดับราคาที่ถ้าแตะแล้วเงื่อนไขของสัญญาเปลี่ยน) ระหว่างสองวันที่สังเกตราคา
สัญลักษณ์และหน่วย

$X_k,\ a(X_k),\ b(X_k)$ค่าที่ก้าวที่ $k$, drift และตัวคูณของ $dW$ ที่ต้นก้าวหน่วยของตัวแปร, ต่อปี, ต่อ $\sqrt{\text{yr}}$

$\Delta W_k,\ Z_k$การขยับของ Brownian motion ในก้าวที่ $k$ และเลขสุ่ม $\mathcal N(0,1)$ ที่สร้างมัน$\sqrt{\text{yr}}$, ไม่มีหน่วย

ขั้นที่ 1 — สร้างการขยับ แล้วเดินแบบ Euler

ทุกสูตรในหน้านี้ต้องใช้ของชิ้นเดียวกันก่อน คือการขยับสุ่ม $\Delta W_k$ ของ Brownian motion ในก้าวที่ $k$ หน้า Brownian motion มาตรฐาน บอกว่า การขยับในช่วงเวลา $\Delta t$ เป็น Normal ที่มีค่าเฉลี่ย 0 และ variance $\Delta t$ ดังนั้น SD ของมันคือ $\sqrt{\Delta t}$ เราจึงสร้างมันได้ง่าย ๆ ให้สุ่มเลข Normal มาตรฐาน $Z_k$ (ค่าเฉลี่ย 0 และ SD 1) แล้วคูณด้วย $\sqrt{\Delta t}$

หน้านี้เดินหนึ่งปีเป็นสี่ก้าว และใช้เลขสุ่ม $Z$ สี่ตัวด้านล่างร่วมกันทุกสูตร เลขชุดนี้เลือกมาให้คิดด้วยมือง่าย ไม่ได้สุ่มจากเครื่อง เมื่อได้ $\Delta W_k$ แล้ว Euler ก็คือการเขียน SDE $dX=a(X)\,dt+b(X)\,dW$ เป็นก้าวยาว $\Delta t$ ตรง ๆ คืออ่าน $a$ และ $b$ ที่ต้นก้าว แล้วถือว่าคงที่ทั้งก้าว

\[ \begin{aligned} \Delta t&=1/4=0.25,\quad \sqrt{\Delta t}=0.5,\\ \Delta W_k&=\sqrt{\Delta t}\,Z_k,\\ Z&=(0.5,\ -1.2,\ 0.8,\ 0.3),\\ \Delta W&=0.5\,Z\\ &=(0.25,\ -0.60,\ 0.40,\ 0.15),\\ X_{k+1}&=X_k+a(X_k)\,\Delta t\\ &\quad+b(X_k)\,\Delta W_k. \end{aligned} \]

ใจความคือ การขยับสุ่มโตตามรากของเวลา ไม่ใช่ตามเวลา จุดที่พลาดง่ายจึงเป็น $\sqrt{\Delta t}$ ไม่ใช่ $\Delta t$ ถ้าเผลอคูณเลขสุ่มด้วย $\Delta t$ ความผันผวนจะหายไปเกือบหมด แต่กราฟเส้นทางยังดูปกติ จึงไม่มีใครเห็น ลองคิดกับก้าวรายวัน $\Delta t=1/252$ (252 คือจำนวนวันทำการต่อปีของตลาดหุ้นสหรัฐ) ถ้าคูณผิด แต่ละก้าวจะแกว่งด้วย SD $\sigma\Delta t$ variance ของ 252 ก้าวที่อิสระกันบวกกันได้ ความผันผวนต่อปีที่ได้จึงเป็น

\[ \begin{aligned} \sqrt{252\,(\sigma\Delta t)^2}&=\frac{\sigma}{\sqrt{252}}\\ &=\frac{0.28}{15.87}=1.76\%, \end{aligned} \]

แทนที่จะเป็น 28% เล็กไป $28/1.76\approx16$ เท่า

ส่วน Euler เองก็ทิ้งข้อเท็จจริงไปหนึ่งข้อ: ระหว่างก้าว $X$ ขยับไปแล้ว ตัวคูณ $b(X)$ จึงไม่ได้คงที่จริง ขั้นถัดไปเก็บผลนี้กลับเข้ามา

ขั้นที่ 2 — พจน์แก้ของ Milstein มาจาก Itô integral ในหนึ่งก้าว

Euler ใช้ $b$ ค่าเดียวทั้งก้าว แต่ในความจริง $X$ ขยับไปเรื่อย ๆ ภายในก้าว $b(X)$ จึงขยับตาม ส่วนสุ่มที่แท้จริงของก้าวจึงเป็น integral $\int b(X_s)\,dW_s$ โดย $X_s$ คือค่าที่เวลา $s$ ระหว่างต้นก้าว $t_k$ กับปลายก้าว $t_{k+1}$ ขั้นนี้หาว่า Euler ทิ้งอะไรไป โดยทำสามอย่าง

  • ประมาณ $b(X_s)$ ด้วย Taylor หนึ่งพจน์รอบค่าต้นก้าว $X_k$ ให้ $b$ และ $b'$ แทน $b(X_k)$ และ $b'(X_k)$ คือค่าที่ต้นก้าว
  • แทนการขยับ $X_s-X_k$ ด้วยส่วนสุ่มของมัน $b\,(W_s-W_k)$ ทิ้งส่วน drift ได้ เพราะส่วน drift มีขนาดราว $\Delta t$ ส่วนสุ่มมีขนาดราว $\sqrt{\Delta t}$ และเมื่อก้าวสั้น $\sqrt{\Delta t}$ ใหญ่กว่า $\Delta t$ มาก เช่น $\sqrt{0.01}=0.1$ ใหญ่กว่า $0.01$ สิบเท่า
  • หา integral ที่เหลือ $\int(W_s-W_k)\,dW_s$ ภายในก้าวเดียว integral นี้คือสูตร $\int_0^T W\,dW=\tfrac12(W_T^2-T)$ จากหน้า Itô integral เพียงเริ่มนับเวลาใหม่ที่ต้นก้าว ให้ $T$ เป็น $\Delta t$ และ $W_T$ เป็น $\Delta W_k$
\[ \begin{aligned} X_s-X_k&\approx b\,(W_s-W_k),\\ b(X_s)&\approx b+b'\,(X_s-X_k)\\ &\approx b+b'b\,(W_s-W_k),\\ \int_{t_k}^{t_{k+1}}b(X_s)\,dW_s&\approx b\,\Delta W_k\\ &\quad+bb'\!\int_{t_k}^{t_{k+1}}(W_s-W_k)\,dW_s,\\ \int_{t_k}^{t_{k+1}}(W_s-W_k)\,dW_s&=\tfrac12\big[(\Delta W_k)^2-\Delta t\big],\\ \text{Milstein}&=\text{Euler}\\ &\quad+\tfrac12\,b\,b'\big[(\Delta W_k)^2-\Delta t\big]. \end{aligned} \]

ใจความคือ ส่วนสุ่มของก้าวไม่ได้มีแค่ $b\,\Delta W$ แบบ Euler แต่มีพจน์เพิ่มอีกหนึ่งพจน์ เพราะ $b$ ขยับตาม $W$ ภายในก้าว จุดที่ต้องระวังคือ integral ตัวสุดท้าย calculus ปกติจะให้ $\tfrac12(\Delta W)^2$ แต่ Itô integral ต้องหัก $\Delta t$ ออก เหตุผลคือ ผลรวมกำลังสองของการขยับเล็ก ๆ ภายในก้าวไม่หายไปเมื่อซอยละเอียด มันรวมได้เวลา $\Delta t$ พอดี

การหัก $\Delta t$ นี้ทำให้พจน์แก้มีค่าเฉลี่ยเป็นศูนย์ เพราะ $\mathbb E[(\Delta W)^2]=\Delta t$ ดังนั้น Milstein ดัดแต่ละเส้นทางให้เข้าใกล้เส้นทางจริง แต่ไม่ย้ายค่าเฉลี่ยของทั้งกลุ่ม

ขั้นที่ 3 — สามสูตรของ GBM คือ Taylor ของสูตรจริงที่ตัดคนละที่

ตอนนี้กลับมาที่หุ้น เราจะใช้ Milstein กับหุ้น แล้ววางเทียบกับสูตรจริง เพื่อดูว่าสามสูตรเกี่ยวกันอย่างไร หุ้นในหน้านี้ใช้แบบจำลอง GBM ซึ่งเป็น SDE

\[dS=\mu S\,dt+\sigma S\,dW.\]

เทียบกับรูป $dX=a\,dt+b\,dW$ จะได้ $a=\mu S$ และ $b=\sigma S$ อนุพันธ์ของ $b$ เทียบ $S$ คือ $b'=\sigma$ จึงได้ $bb'=\sigma S\times\sigma=\sigma^2S$ พจน์แก้ของ Milstein จึงเป็น $\tfrac12\sigma^2S\big((\Delta W)^2-\Delta t\big)$

สูตรจริงของหนึ่งก้าวมาจากหน้า การแก้ SDE ของ GBM คือ $S_{k+1}=S_ke^u$ โดย $u$ คือเลขชี้กำลังในแถวที่สองด้านล่าง สูตรนี้มี exponential ส่วนอีกสองสูตรเป็นพหุนาม จะเทียบกันได้ต้องกระจาย $e^u$ เป็นอนุกรม Taylor ถึงอันดับสอง $e^u\approx1+u+\tfrac12u^2$ ใน $u^2$ เราเก็บไว้แค่ $\sigma^2(\Delta W)^2$ ซึ่งมีขนาดราว $\Delta t$ พจน์อื่นของ $u^2$ เช่น $2\sigma(\mu-\tfrac12\sigma^2)\,\Delta t\,\Delta W$ มีขนาดราว $\Delta t\times\sqrt{\Delta t}=\Delta t^{3/2}$ หรือเล็กกว่า จึงทิ้งได้

\[ \begin{aligned} S^X_{k+1}&=S_k\,e^{u},\\ u&=(\mu-\tfrac12\sigma^2)\Delta t+\sigma\Delta W_k,\\ e^u&\approx1+u+\tfrac12\sigma^2(\Delta W_k)^2\\ &=1+\mu\Delta t+\sigma\Delta W_k\\ &\quad+\tfrac12\sigma^2\big[(\Delta W_k)^2-\Delta t\big],\\ \frac{S^M_{k+1}}{S_k}&=1+\mu\Delta t+\sigma\Delta W_k\\ &\quad+\tfrac12\sigma^2\big[(\Delta W_k)^2-\Delta t\big],\\ \frac{S^E_{k+1}}{S_k}&=1+\mu\Delta t+\sigma\Delta W_k. \end{aligned} \]

ใจความคือ สามสูตรเป็นสูตรเดียวกันที่ตัดอนุกรมคนละที่ จุดที่น่าสนใจคือสองพจน์ที่รวมกัน พจน์แรกคือ $-\tfrac12\sigma^2\Delta t$ ซึ่งอยู่ในเลขชี้กำลังของสูตรจริง พจน์ที่สองคือ $+\tfrac12\sigma^2(\Delta W)^2$ ซึ่งมาจาก $\tfrac12u^2$ สองพจน์นี้รวมกันได้พจน์แก้ของ Milstein พอดี ดังนั้น Milstein คือสูตรจริงที่ตัดอนุกรมที่อันดับสอง ส่วน Euler ตัดเร็วกว่านั้นหนึ่งขั้น

ให้ “ตัวคูณของราคา” ในหนึ่งก้าวคือราคาใหม่หารด้วยราคาเก่า ถ้ามองตัวคูณนี้เป็นฟังก์ชันของเลขสุ่ม $Z$ จะได้ภาพง่าย ๆ สูตรจริงเป็น exponential, Milstein เป็นพาราโบลา และ Euler เป็นเส้นตรง รูปด้านล่างวาดสามตัวคูณนี้ในกรณีที่ก้าวยาวและหุ้นผันผวนสูง เพื่อให้เห็นช่องว่างชัด

ขั้นที่ 4 — เดินสี่ก้าวด้วยมือ: เลขสุ่มชุดเดียว สามสูตร

ถึงตอนนี้เรามีสามสูตรแล้ว ขั้นนี้ใส่ตัวเลขจริงเพื่อดูว่ามันห่างกันแค่ไหนบนเส้นทางเดียวกัน

โจทย์ให้อะไรมาบ้าง: หุ้นของโจทย์เปิดเรื่อง

  • ราคาวันนี้ $S_0=\$100$
  • drift $\mu=0.12$ และความผันผวน $\sigma=0.28$ ต่อปี
  • ความยาวก้าว $\Delta t=0.25$ ปี สี่ก้าว
  • การขยับ $\Delta W=(0.25,\ -0.60,\ 0.40,\ 0.15)$ จากขั้นที่ 1

ก่อนเดิน คิดค่าคงที่ที่ใช้ทุกก้าว และค่าของก้าวแรกไว้ก่อน

\[ \begin{aligned} \mu\Delta t&=0.12\times0.25=0.03,\\ \tfrac12\sigma^2&=\tfrac12(0.28)^2=0.0392,\\ (\mu-\tfrac12\sigma^2)\Delta t&=(0.12-0.0392)(0.25)\\ &=0.0202,\\ \sigma\Delta W_1&=0.28\times0.25=0.07,\\ (\Delta W_1)^2&=0.25^2=0.0625. \end{aligned} \]

ก้าวแรกของแต่ละสูตรคิดด้วยมือได้ดังนี้ ($S^E$, $S^M$, $S^X$ คือราคาจาก Euler, Milstein และสูตรจริง)

\[ \begin{aligned} S^E_1&=100(1+0.03+0.07)=\$110,\\ S^M_1&=110+100(0.0392)(0.0625-0.25)\\ &=110-0.735=\$109.265,\\ S^X_1&=100\,e^{0.0202+0.07}=\$109.4393. \end{aligned} \]

ตรวจเองใน 10 วินาที: ก้าวแรก $(\Delta W_1)^2=0.0625$ น้อยกว่า $\Delta t=0.25$ อยู่ $0.25-0.0625=0.1875$ พจน์แก้ของ Milstein จึงติดลบ และหักออกจาก Euler $100\times0.0392\times0.1875=0.735$ ส่วนสูตรจริงไม่ต้องเดินทีละก้าวก็ได้ เพราะเมื่อคูณ $e^{u_1}e^{u_2}e^{u_3}e^{u_4}$ เลขชี้กำลังของสี่ก้าวบวกกัน จึงใช้แค่ผลรวมของการขยับ $W_1=\sum\Delta W=0.25-0.60+0.40+0.15=0.2$ ($W_1$ คือค่าของ Brownian motion ที่เวลาหนึ่งปี)

\[ \begin{aligned} S^X_4&=100\,e^{(\mu-\frac12\sigma^2)(1)+\sigma W_1}\\ &=100\,e^{(0.12-0.0392)+0.28(0.2)}\\ &=100\,e^{0.0808+0.056}\\ &=100\,e^{0.1368}=\$114.66. \end{aligned} \]

ขั้นที่ 5 — ทำไม Euler สูงไป: เส้นทางนี้มีผลรวมกำลังสองน้อยกว่าหนึ่งปี

Euler คลาดไป 1.24% บนเส้นทางนี้ และคลาดไปทางสูง ขั้นนี้หาว่าความคลาดมาจากไหน วิธีคือเทียบ log ของราคาปลายทาง เพราะราคาปลายทางคือราคาตั้งต้นคูณตัวคูณสี่ตัว และ log เปลี่ยนผลคูณให้เป็นผลบวก ซึ่งเทียบกันง่ายกว่า

  • ให้ $x_k=\mu\Delta t+\sigma\Delta W_k$ คือส่วนที่ Euler บวกเข้าไปในก้าวที่ $k$ ตัวคูณของก้าวนั้นจึงเป็น $1+x_k$
  • ใช้อนุกรม Taylor ถึงอันดับสอง $\ln(1+x)\approx x-\tfrac12x^2$
  • ใน $x_k^2$ เก็บไว้แค่ $\sigma^2(\Delta W_k)^2$ เพราะพจน์อื่นเล็กกว่า ด้วยเหตุผลเดียวกับในขั้นที่ 3
  • ให้ $T$ คือเวลาทั้งหมด (ที่นี่ $T=1$ ปี) และ $W_T=\sum_k\Delta W_k$ คือผลรวมของการขยับ ผลรวมของ $\mu\Delta t$ ทุกก้าวจึงเป็น $\mu T$
\[ \begin{aligned} \ln(1+x_k)&\approx x_k-\tfrac12x_k^2\\ &\approx x_k-\tfrac12\sigma^2(\Delta W_k)^2,\\ \textstyle\sum_k\ln(1+x_k)&\approx\mu T+\sigma W_T\\ &\quad-\tfrac12\sigma^2\textstyle\sum_k(\Delta W_k)^2,\\ \ln(S^X_n/S_0)&=\mu T+\sigma W_T-\tfrac12\sigma^2T,\\ \text{gap}&\approx\tfrac12\sigma^2\big(T-\textstyle\sum_k(\Delta W_k)^2\big). \end{aligned} \]

“gap” คือส่วนที่ log ของ Euler สูงกว่า log ของสูตรจริง ได้จากการเอาผลรวม log ของ Euler ลบด้วย log ของสูตรจริง พจน์ $\mu T+\sigma W_T$ ตัดกันหมด เหลือแค่ส่วนที่ทั้งสองหักไม่เท่ากัน ตอนนี้ใส่ตัวเลขของเส้นทางนี้ เริ่มจากตัวคูณของ Euler ทั้งสี่ก้าว $1+x_k=1.03+0.28\,\Delta W_k$ และผลรวมกำลังสองของการขยับ

\[ \begin{aligned} 1.03+0.28(0.25)&=1.100,\\ 1.03+0.28(-0.60)&=0.862,\\ 1.03+0.28(0.40)&=1.142,\\ 1.03+0.28(0.15)&=1.072,\\ \textstyle\sum(\Delta W_k)^2&=0.0625+0.36\\ &\quad+0.16+0.0225=0.605. \end{aligned} \]

จากนั้นเทียบ log ของสองสูตรตรง ๆ แล้วเทียบกับค่าประมาณอันดับสองในแถวสุดท้ายของสูตรด้านบน

\[ \begin{aligned} \textstyle\sum\ln(1+x_k)&=0.09531-0.14850\\ &\quad+0.13278+0.06953\\ &=0.14912,\\ \ln(S^X_4/100)&=0.0808+0.28(0.2)\\ &=0.1368,\\ \text{gap}&=0.14912-0.1368=0.01232,\\ e^{0.01232}&=1.0124,\\ \tfrac12\sigma^2\big(1-0.605\big)&=0.0392\times0.395\\ &=0.0155. \end{aligned} \]

ใจความคือ ทั้งสองสูตรหัก $\tfrac12\sigma^2$ ออกจาก log แต่หักคูณกับคนละอย่าง Euler หัก $\tfrac12\sigma^2$ คูณผลรวมกำลังสองของการขยับที่เกิดขึ้นจริงในเส้นทางนั้น สูตรจริงหัก $\tfrac12\sigma^2$ คูณเวลาเต็ม $T$ เส้นทางนี้มี $\sum(\Delta W)^2=0.605$ น้อยกว่าหนึ่งปี Euler จึงหักน้อยไป และจบสูงเกินไป

ช่องว่างจริงใน log คือ 0.01232 และ $e^{0.01232}=1.0124$ คือ Euler สูงกว่า 1.24% ตรงกับที่เห็นในขั้นที่ 4 ค่าประมาณอันดับสองให้ 0.0155 ซึ่งใหญ่กว่าเล็กน้อย เพราะพจน์อันดับสามขึ้นไปที่เราทิ้งไปดึงค่ากลับลงมา

นี่คือบทเรียนของหน้า ผลรวมกำลังสองของการขยับ ในอีกรูป ผลรวมนั้นเข้าหาเวลา $T$ เมื่อซอยก้าวละเอียด แต่ถ้ามีแค่สี่ก้าว มันยังแกว่งได้มาก แกว่งแค่ไหนคิดได้ แต่ละก้าว $(\Delta W_k)^2=\Delta t\,Z_k^2$ และ $Z^2$ ของ Normal มาตรฐานมี variance $\mathbb E[Z^4]-(\mathbb E[Z^2])^2=3-1=2$ แต่ละก้าวจึงมี variance $2\Delta t^2$ สี่ก้าวอิสระกัน variance จึงบวกกันได้

\[\operatorname{SD}\Big(\textstyle\sum_{k=1}^4(\Delta W_k)^2\Big)=\sqrt{4\times2\times0.25^2}=\sqrt{0.5}=0.707.\]

ผลรวมที่ควรเป็น 1 จึงแกว่งได้ราว ±0.7 จากเส้นทางหนึ่งไปอีกเส้นทางหนึ่ง และความคลาดของ Euler บนแต่ละเส้นทางก็แกว่งตาม

ขั้นที่ 6 — ความแม่นสองแบบ และทำไม Euler ได้ค่าเฉลี่ยดีกว่าได้เส้นทาง

ขั้นที่ 5 ดูแค่เส้นทางเดียว แต่ในงานจริงเราถามได้สองคำถาม คำถามแรก: แต่ละเส้นทางที่จำลองใกล้เส้นทางจริงแค่ไหน คำถามที่สอง: ค่าเฉลี่ยของทุกเส้นทางใกล้ค่าเฉลี่ยจริงแค่ไหน สองคำถามนี้มีคำตอบต่างกัน จึงมีนิยามความคลาดสองแบบ

  • strong error เทียบเส้นทางกับเส้นทาง บนเลขสุ่มชุดเดียวกัน: ค่าเฉลี่ยของ $|X_T-X_T^{\Delta t}|$ โดย $X_T$ คือค่าจริงที่เวลาจบ $T$ และ $X_T^{\Delta t}$ คือค่าที่จำลองด้วยก้าวยาว $\Delta t$
  • weak error เทียบแค่ค่าเฉลี่ยของสิ่งที่สนใจ $\varphi(X_T)$ เช่นเงินที่สัญญาจ่ายตอนจบ

เครื่องหมาย $\propto\Delta t^{\,p}$ แปลว่าความคลาดหดตาม $\Delta t^{\,p}$ เมื่อซอยก้าว ตัวเลขชี้กำลัง $p$ เรียกว่าอันดับ (order) ยิ่ง $p$ ใหญ่ ความคลาดยิ่งหดเร็ว จากนั้นเราดูพจน์ $\epsilon_k$ ที่ Euler ทิ้งไปในก้าวที่ $k$ ว่ามันสะสมอย่างไร ($\mathbb E_k$ คือค่าเฉลี่ยเมื่อรู้ค่าที่ต้นก้าวแล้ว)

\[ \begin{aligned} \mathbb E\big|X_T-X_T^{\Delta t}\big|&\propto\Delta t^{\,p_s},\\ \big|\mathbb E[\varphi(X_T)]-\mathbb E[\varphi(X_T^{\Delta t})]\big|&\propto\Delta t^{\,p_w},\\ \epsilon_k&=\tfrac12bb'\big[(\Delta W_k)^2-\Delta t\big],\\ \mathbb E_k[\epsilon_k]&=\tfrac12bb'(\Delta t-\Delta t)=0,\\ \operatorname{Var}\big((\Delta W_k)^2\big)&=2\Delta t^2,\\ \operatorname{SD}(\epsilon_k)&=\tfrac12|bb'|\sqrt2\,\Delta t,\\ \operatorname{SD}\Big(\textstyle\sum_{k=1}^{n}\epsilon_k\Big)&\propto\sqrt n\,\Delta t\\ &=\sqrt{T/\Delta t}\,\Delta t=\sqrt{T\,\Delta t}. \end{aligned} \]

ใจความคือ พจน์ที่ Euler ทิ้งไปหักล้างกันในค่าเฉลี่ย แต่ไม่หักล้างบนเส้นทางเดียว พจน์ $\epsilon_k$ มีค่าเฉลี่ยศูนย์ทุกก้าว เพราะ $\mathbb E[(\Delta W)^2]=\Delta t$ เมื่อเฉลี่ยหลายเส้นทาง มันจึงหักล้างกันเอง แต่บนเส้นทางเดียว มันไม่หาย แต่ละก้อนมีขนาดราว $\Delta t$ เพราะ $(\Delta W)^2=\Delta t\,Z^2$ มี variance $2\Delta t^2$ ตามที่คิดในขั้นที่ 5

จุดที่ต้องคิดให้ดีคือการรวมก้อน หนึ่งปีมี $n=T/\Delta t$ ก้อนที่อิสระกัน ผลรวมของก้อนอิสระโตตามรากของจำนวนก้อน ไม่ใช่ตามจำนวนก้อน เพราะสิ่งที่บวกกันได้คือ variance ไม่ใช่ SD ผลรวมจึงมีขนาดราว $\sqrt n\,\Delta t=\sqrt{T\Delta t}$ ซึ่งหดตาม $\Delta t^{1/2}$ Euler จึงมีอันดับ strong $p_s=\tfrac12$ ส่วน weak error ของ Euler มาจากพจน์ที่เล็กกว่านี้ และได้อันดับ $p_w=1$

Milstein เก็บ $\epsilon_k$ ไว้ จึงได้ $p_s=1$ ส่วน $p_w$ ยังเป็น 1 เท่ากับ Euler อันดับเหล่านี้เป็นผลมาตรฐานสำหรับ SDE ที่ $a$ และ $b$ เรียบ หน้านี้ยกมาใช้โดยไม่พิสูจน์ส่วนที่เหลือ ขั้นถัดไปจึงวัดมันจริงด้วยการจำลองแทน

ขั้นที่ 7 — วัด strong error จริง: 20,000 เส้นทาง ห้าขนาดก้าว

ขั้นที่ 6 บอกว่า strong error หดตาม $\Delta t^{\,p_s}$ ถ้าก้าวสั้นลงครึ่งหนึ่ง ความคลาดจะเปลี่ยนจาก $\Delta t^{\,p_s}$ เป็น $(\Delta t/2)^{p_s}=\Delta t^{\,p_s}/2^{p_s}$ คือหารด้วย $2^{p_s}$ ดังนั้น Euler ($p_s=\tfrac12$) ควรหารด้วย $2^{1/2}=\sqrt2=1.414$ และ Milstein ($p_s=1$) ควรหารด้วย $2^1=2$ ขั้นนี้ลองวัดจริงกับหุ้นตัวเดิม

ขั้นที่ 8 — คำตอบของโจทย์เปิดเรื่อง: bias ของค่าเฉลี่ยแบบตรงเป๊ะ

กลับมาที่คำถามของหัวหน้าทีม: สุ่มล้านเส้นทางแล้วค่าเฉลี่ยจะถูกไหม ขั้นที่ 6 บอกว่า weak error ของ Euler ไม่เป็นศูนย์ ขั้นนี้คิดมันให้เห็นเป็นดอลลาร์ โชคดีที่สำหรับ GBM ค่าเฉลี่ยของ Euler คิดได้ตรงเป๊ะโดยไม่ต้องสุ่มเลย

โจทย์ให้อะไรมาบ้าง: หุ้นของโจทย์เปิดเรื่อง จำลองหนึ่งปี ($T=1$) ด้วย $n$ ก้าว ก้าวละ $\Delta t=1/n$ ปี เหตุผลที่คิดค่าเฉลี่ยได้ตรง ๆ มีสามข้อ

  • ทุกก้าว Euler คูณราคาด้วย $1+\mu\Delta t+\sigma\Delta W$ และเพราะ $\mathbb E[\Delta W]=0$ ตัวคูณนี้จึงเฉลี่ย $1+\mu\Delta t$
  • การขยับของแต่ละก้าวอิสระกัน ค่าเฉลี่ยของผลคูณจึงเท่ากับผลคูณของค่าเฉลี่ย
  • พจน์แก้ของ Milstein เฉลี่ยศูนย์ Milstein จึงมีค่าเฉลี่ยเท่ากับ Euler

ขั้นที่ 9 — เมื่อไร Euler ให้ราคาติดลบ

ราคาหุ้นจริงติดลบไม่ได้ แต่ Euler ทำให้ติดลบได้ เหตุผลคือ ตัวคูณของ Euler $1+\mu\Delta t+\sigma\sqrt{\Delta t}\,Z$ เป็นเส้นตรงของ $Z$ ถ้า $Z$ ลบมากพอ ตัวคูณก็ติดลบ ดูพื้นที่แดงในรูปตัวคูณด้านบน ขั้นนี้หาว่าต้องได้ $Z$ ต่ำแค่ไหน และเรื่องนี้เกิดบ่อยแค่ไหน

วิธีคือแก้อสมการ “ตัวคูณติดลบ” หา $Z$ ตอนแก้ เราหารด้วย $\sigma\sqrt{\Delta t}$ ซึ่งเป็นบวก ทิศของอสมการจึงไม่กลับ แล้วลองสามกรณี

  • หุ้นของโจทย์เปิดเรื่อง $\sigma=0.28$ ก้าวละไตรมาส $\Delta t=0.25$
  • หุ้นผันผวน 80% ที่เดินก้าวละหนึ่งปี $\Delta t=1$ (กรณีในรูปตัวคูณ)
  • หุ้นผันผวน 80% ตัวเดียวกัน แต่เดินก้าวละเดือน $\Delta t=1/12$ จึงได้ $\sqrt{1/12}=0.2887$ และ $\mu\Delta t=0.12/12=0.01$

$\Phi(z)$ คือโอกาสที่เลขสุ่ม Normal มาตรฐานออกต่ำกว่า $z$

\[ \begin{aligned} 1+\mu\Delta t+\sigma\sqrt{\Delta t}\,Z&\lt0,\\ Z&\lt-\frac{1+\mu\Delta t}{\sigma\sqrt{\Delta t}},\\ \sigma=0.28,\ \Delta t=0.25&:\ -\tfrac{1.03}{0.28\times0.5}=-7.36,\\ \sigma=0.80,\ \Delta t=1&:\ -\tfrac{1.12}{0.80}=-1.40,\\ &\quad\Phi(-1.40)=8.08\%,\\ \sigma=0.80,\ \Delta t=\tfrac1{12}&:\ -\tfrac{1.01}{0.80\times0.2887}=-4.373,\\ &\quad\Phi(-4.373)=0.00061\%. \end{aligned} \]

ส่วน Milstein ของ GBM ต่างออกไป ตัวคูณของมันเป็นพาราโบลาของ $Z$ ที่หงายขึ้น เขียนเป็น $AZ^2+BZ+C$ ได้ พาราโบลาหงายจะไม่ติดลบเลยถ้ามันไม่ตัดแกนศูนย์ ซึ่งเกิดเมื่อ discriminant $B^2-4AC$ ติดลบ หา $A$, $B$, $C$ ได้จากการแทน $\Delta W=\sqrt{\Delta t}\,Z$ ลงในตัวคูณของ Milstein แล้วจัดกลุ่มตามกำลังของ $Z$ จากนั้นแทนลงใน $B^2\lt4AC$ และหารทั้งสองข้างด้วย $\sigma^2\Delta t$ ซึ่งเป็นบวก

\[ \begin{aligned} A&=\tfrac12\sigma^2\Delta t,\quad B=\sigma\sqrt{\Delta t},\\ C&=1+\mu\Delta t-\tfrac12\sigma^2\Delta t,\\ B^2&\lt4AC,\\ 1&\lt2\big(1+\mu\Delta t-\tfrac12\sigma^2\Delta t\big),\\ \sigma^2\Delta t&\lt1+2\mu\Delta t,\\ \sigma=0.80,\ \Delta t=1&:\ 0.64\lt1.24. \end{aligned} \]

ใจความคือ Euler ติดลบเมื่อการแกว่งของหนึ่งก้าว $\sigma\sqrt{\Delta t}$ ใหญ่เทียบกับ 1 หุ้นในโจทย์หลักต้องได้เลขสุ่มต่ำกว่า −7.36 ซึ่งแทบไม่เกิด แต่หุ้นที่ผันผวน 80% และจำลองก้าวละปี ได้ราคาติดลบใน 8.08% ของเส้นทาง หรือราว 1 ใน 12 เส้น ($1/0.0808=12.4$) พอราคาติดลบ การคำนวณที่ต้องใช้ log ของราคาหรือรากของราคาจะพังทั้งชุด

ถ้าซอยเป็นรายเดือน แต่ละก้าวติดลบยากขึ้นมาก ทั้งปี (12 ก้าว) เหลือโอกาสราว 0.0073% ซึ่งคิดให้ดูในโจทย์ข้อ 3 ท้ายหน้า แต่ทางที่ดีกว่าการซอยก้าวคือไม่ใช้ Euler กับราคาดิบเลย ให้ใช้สูตรจริง หรือเดิน Euler บน log ของราคาแทน ส่วน Milstein ของ GBM ไม่ติดลบในกรณีทดสอบนี้ เพราะ $0.64\lt1.24$ ตรงกับในรูปที่พาราโบลาต่ำสุดที่ 0.30 ซึ่งยังเป็นบวก

ขั้นที่ 10 — สูตรจริงของ Vasicek และเมื่อ Milstein เท่ากับ Euler

สูตรจริงไม่ได้มีแค่กับหุ้น ธนาคารต้องจำลองอัตราดอกเบี้ยด้วย เช่นเพื่อคิดราคาพันธบัตร (bond: ตราสารหนี้ที่จ่ายเงินคืนตามกำหนด) แบบจำลองดอกเบี้ยที่ง่ายที่สุดตัวหนึ่งคือ Vasicek ให้ $r$ คืออัตราดอกเบี้ยระยะสั้น SDE ของมันคือ

\[dr=\kappa(\theta-r)\,dt+\sigma_V\,dW.\]

ส่วน drift $\kappa(\theta-r)$ ดึงดอกเบี้ยกลับหาระดับระยะยาว $\theta$ ถ้า $r$ สูงกว่า $\theta$ drift ติดลบ ถ้าต่ำกว่า drift เป็นบวก $\kappa$ บอกว่าดึงกลับเร็วแค่ไหน ส่วนสุ่มแกว่งด้วยขนาดคงที่ $\sigma_V$ ตัวเลขที่ใช้ (สมมติ)

  • ความเร็วที่ดึงกลับ $\kappa=0.8$ ต่อปี
  • ระดับระยะยาว $\theta=3\%$
  • ความผันผวนของดอกเบี้ย $\sigma_V=1.2\%$ ต่อ $\sqrt{\text{yr}}$
  • ก้าวรายวัน $\Delta t=1/252$ ปี

หน้า การแก้ SDE ของ Vasicek ให้การกระจายของดอกเบี้ยหลังเวลา $t$ ใดก็ได้ มันเป็น Normal ที่ค่าเฉลี่ยถูกดึงจากค่าตั้งต้นเข้าหา $\theta$ และมี variance $\sigma_V^2(1-e^{-2\kappa t})/(2\kappa)$ ถ้าเริ่มจาก $r_k$ แล้วใส่เวลา $t=\Delta t$ ก็ได้สูตรก้าวที่ตรงเป๊ะ (แถวแรกด้านล่าง) ส่วน Euler ใช้ SD ของก้าวเป็น $\sigma_V\sqrt{\Delta t}$ เพื่อดูว่าสองสูตรต่างกันแค่ไหน เราเทียบ SD ของก้าวรายวัน ให้ $\text{SD}_X$ คือ SD ของสูตรจริง และ $\text{SD}_E$ คือ SD ของ Euler

\[ \begin{aligned} r_{k+1}&=\theta+(r_k-\theta)e^{-\kappa\Delta t}\\ &\quad+\sigma_V\sqrt{\frac{1-e^{-2\kappa\Delta t}}{2\kappa}}\,Z_k,\\ e^{-\kappa\Delta t}&=e^{-0.8/252}=0.996830,\\ 2\kappa\Delta t&=1.6/252=0.006349,\\ \text{SD}_X&=0.012\sqrt{\frac{1-e^{-0.006349}}{1.6}}\\ &=0.00075473,\\ \text{SD}_E&=0.012\sqrt{1/252}=0.00075593,\\ \frac{\text{SD}_E}{\text{SD}_X}-1&=0.16\%. \end{aligned} \]

Milstein ของ Vasicek ก็คิดง่าย ตัวคูณของ $dW$ คือ $b=\sigma_V$ ซึ่งคงที่ จึงได้ $b'=0$ และพจน์แก้ $\tfrac12bb'\big((\Delta W)^2-\Delta t\big)$ เป็นศูนย์ Milstein จึงเท่ากับ Euler ทุกก้าว

ใจความคือ ในก้าวรายวัน Euler กับสูตรจริงต่างกันน้อยมาก SD ต่างกันแค่ 0.16% ข้อดีของสูตรจริงอยู่ที่ก้าวยาว ใช้ก้าวยาวเท่าไรก็ยังตรง เช่นถ้าต้องการดอกเบี้ยในอีกห้าปี เพื่อคิดราคาพันธบัตรอายุห้าปี ก้าวเดียวยาวห้าปีก็ตรงเป๊ะ

Milstein ไม่ช่วย Vasicek เลย เพราะ $b$ คงที่ และอย่าเข้าใจผิดว่าการที่ Milstein ให้ผลตรงกับ Euler แปลว่าทั้งคู่ถูก ทั้งคู่ยังคลาดจากสูตรจริงเท่ากัน

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

คูณเลขสุ่มด้วย $\Delta t$ แทน $\sqrt{\Delta t}$: ความผิดนี้ทำให้ความผันผวนหายไปเกือบหมด แต่เส้นทางยังดูปกติ กับก้าวรายวัน ความผันผวนต่อปีที่ได้คือ $0.28/\sqrt{252}=1.76\%$ แทนที่จะเป็น $\sigma=28\%$ (ที่มาของ 1.76% อยู่ในขั้นที่ 1) ราคา option ทุกตัวจึงถูกตีต่ำไปมาก option คือสัญญาที่ให้สิทธิ์ซื้อหรือขายหุ้นในราคาที่ตกลงไว้ และมีค่ามากขึ้นเมื่อหุ้นแกว่งแรง วิธีตรวจคือดู realized variance ของเส้นทางที่จำลอง ซึ่งก็คือผลรวมกำลังสองของผลตอบแทนรายก้าว ค่าที่ถูกต้องต้องใกล้ $\sigma^2T=0.28^2\times1=0.0784$ ถ้าคูณผิดจะได้ราว $0.0176^2=0.00031$ เล็กไปสองร้อยกว่าเท่า

เชื่อว่าช่วงความเชื่อมั่นครอบความคลาดจากก้าวด้วย: ช่วงความเชื่อมั่นวัดได้แค่ความคลาดจากการสุ่ม (SE) ไม่เห็น bias จากความยาวก้าวเลย Euler 4 ก้าวกับ 1,000,000 เส้นทางให้ช่วง $112.55\pm0.061$ แต่ค่าจริงคือ $100e^{0.12}=\$112.75$ อยู่นอกช่วง เพราะ bias \$0.20 ใหญ่กว่าครึ่งความกว้าง \$0.061 ต้องรายงาน bias จากการซอยก้าวแยกอีกบรรทัด

เทียบสองสูตรด้วยเลขสุ่มคนละชุด: ถ้าสุ่มแยกกัน เสียงรบกวนจากการสุ่มจะกลบความต่างที่อยากวัด สมมติสุ่ม Euler กับสูตรจริงแยกกัน สูตรละ $N=20{,}000$ เส้น ความต่างของค่าเฉลี่ยทั้งสองจะแกว่งด้วย SE ของผลต่าง ซึ่งคิดจาก SD ราว \$31 ของแต่ละฝั่ง

\[ \begin{aligned} \text{SE}_{\text{diff}}&\approx\sqrt2\times\frac{31}{\sqrt{20{,}000}}\\ &=\sqrt2\times\frac{31}{141}=\$0.31, \end{aligned} \]

ใหญ่กว่า bias \$0.20 ที่อยากวัด ($\sqrt2$ มาจาก variance ของสองฝั่งที่อิสระกันบวกกัน) ต้องใช้ common random numbers คือเลขสุ่มชุดเดียวกันทั้งสองสูตรเสมอ

ใช้ Euler กับราคาดิบเมื่อผันผวนสูงและก้าวยาว: ความผิดนี้ทำให้ได้ราคาติดลบ ซึ่งหุ้นจริงเป็นไม่ได้ หุ้นผันผวน 80% ที่เดินก้าวละปี ติดลบเมื่อ $Z\lt-1.12/0.80=-1.40$ คือใน $\Phi(-1.40)=8.08\%$ ของก้าว (ขั้นที่ 9) ส่วนสูตรจริง $e^{-0.2+0.8Z}$ ติดลบใน 0% ของก้าว เพราะ exponential เป็นบวกเสมอ พอมีราคาติดลบ ค่าเฉลี่ยของ log ของราคาหรือรากของราคาจะกลายเป็นตัวเลขที่ไม่มีความหมาย ให้ใช้สูตรจริง หรือเดิน Euler บน log ของราคาแทน

ทำไมสัญญาที่ขึ้นกับทั้งเส้นทางต้องเดินทีละวันที่สังเกตราคา? สัญญาที่จ่ายตามราคาวันเดียว เช่น European option (option ที่ใช้สิทธิ์ได้แค่วันครบกำหนด) ต้องการแค่การกระจายของราคาวันนั้น ก้าวเดียวจึงพอ แต่สัญญาที่ขึ้นกับหลายวันต้องรู้ด้วยว่าราคาแต่ละวันเกี่ยวกันอย่างไร ตัวอย่างคือ knock-in ซึ่งเป็น option ที่จะเริ่มมีผลก็ต่อเมื่อราคาแตะระดับที่กำหนดไว้ก่อน เช่นแตะระดับนั้นในวันสังเกตครึ่งปี

ลองนึกถึงหุ้นสองตัว การกระจายของราคาในแต่ละวันเหมือนกันทุกวัน แต่ราคาวันแรกกับวันหลังเกี่ยวกันไม่เท่ากัน European option ของสองตัวนี้จะราคาเท่ากัน เพราะดูแค่วันเดียว แต่ knock-in จะราคาต่างกัน เพราะขึ้นกับว่าราคาเดินผ่านระดับนั้นหรือเปล่า เครื่องจำลองจึงต้องเดินทีละวันที่สังเกต โดยแต่ละก้าวต่อจากราคาของก้าวก่อน ด้วยการขยับที่อิสระกันตามแบบจำลอง ไม่ใช่สุ่มราคาของแต่ละวันแยกกัน

รู้ได้อย่างไรว่าก้าวสั้นพอ? ถ้าไม่มีสูตรจริงให้เทียบ อันดับ $p_w=1$ ช่วยได้ วิธีคือรันสองขนาดก้าว เช่น $n$ กับ $2n$ ก้าว ด้วยเลขสุ่มชุดเดิม

  • bias หดตาม $\Delta t=1/n$ จึงเขียนได้ว่า $\text{bias}_n\approx c/n$ โดย $c$ เป็นค่าคงที่ที่เราไม่รู้
  • ให้ $\bar S_n$ คือค่าเฉลี่ยราคาปลายทางจากรัน $n$ ก้าว ซึ่งเท่ากับค่าจริงลบ $\text{bias}_n$

ลบค่าเฉลี่ยของสองรัน ค่าจริงที่ไม่รู้จะตัดกันหายไป เหลือผลต่างที่บอก bias ของรันที่ละเอียดกว่า จากนั้นลองกับ bias จริงของ 8 และ 16 ก้าวจากขั้นที่ 8

\[ \begin{aligned} \bar S_{2n}-\bar S_n&=\text{bias}_n-\text{bias}_{2n}\\ &\approx\frac{c}{n}-\frac{c}{2n}=\frac{c}{2n}\\ &\approx\text{bias}_{2n},\\ \text{bias}_8-\text{bias}_{16}&=0.1004-0.0505\\ &=0.0499\approx\text{bias}_{16}. \end{aligned} \]

ผลต่าง 0.0499 นี้หาได้จากสองรันโดยไม่ต้องรู้ค่าจริง และใกล้ bias จริงของ 16 ก้าว (0.0505) มาก หลักเดียวกันใช้ตรวจต้นไม้ binomial ได้ด้วย ต้นไม้ binomial คือแบบจำลองที่ให้ราคาขึ้นหรือลงได้สองทางในแต่ละงวด มันก็เป็นการซอยเวลาแบบหนึ่ง ราคาจากต้นไม้เข้าหาราคาจากสูตร Black–Scholes (สูตรราคา option ของ GBM) เมื่อจำนวนงวดเพิ่ม

สรุปคือ ทุกราคาที่ได้จาก Monte Carlo ควรรายงานความคลาดสองบรรทัดเสมอ บรรทัดแรกคือ SE จากจำนวนเส้นทาง บรรทัดที่สองคือ bias จากขนาดก้าว (หน้า Monte Carlo และ bootstrap สรุปผลจากการสุ่มอย่างเป็นระบบ)

โจทย์ตรวจความเข้าใจ

1. ขั้นที่ 4 คิดก้าวแรกให้ดูด้วยมือ แต่ก้าวที่เหลือให้ไว้แค่ในตาราง ลองคิดก้าวที่สองของ Milstein เอง ราคาต้นก้าวคือ $S^M_1=\$109.265$ การขยับของก้าวนี้คือ $\Delta W_2=-0.60$ และค่าคงที่ยังเป็น $\mu\Delta t=0.03$, $\sigma=0.28$, $\tfrac12\sigma^2=0.0392$, $\Delta t=0.25$ ราคาปลายก้าวคือเท่าไร?

เฉลย

ให้ $M_2$ คือตัวคูณของ Milstein ในก้าวที่สอง $M_2=1+\mu\Delta t+\sigma\Delta W_2+\tfrac12\sigma^2\big((\Delta W_2)^2-\Delta t\big)$ แทนตัวเลข

\[ \begin{aligned} (\Delta W_2)^2&=(-0.60)^2=0.36,\\ \sigma\Delta W_2&=0.28(-0.60)=-0.168,\\ \tfrac12\sigma^2(0.36-0.25)&=0.0392\times0.11\\ &=0.004312,\\ M_2&=1+0.03-0.168+0.004312\\ &=0.866312,\\ S^M_2&=109.265\times0.866312\\ &=\$94.6576. \end{aligned} \]

ตรงกับตาราง ก้าวนี้ $(\Delta W)^2=0.36$ มากกว่า $\Delta t=0.25$ พจน์แก้จึงเป็นบวก ต่างจากก้าวแรกที่พจน์แก้ติดลบ

2. ทีมในโจทย์เปิดเรื่องอยากรู้ว่า ถ้าเดิน Euler เดือนละก้าว (12 ก้าวต่อปี) แทนไตรมาสละก้าว bias ของค่าเฉลี่ยราคาปลายปีจะเหลือเท่าไร หุ้นยังเป็นตัวเดิม $S_0=\$100$ และ $\mu=12\%$

เฉลย

ใช้สูตร $\text{bias}_n=100e^{0.12}-100(1+0.12/n)^n$ จากขั้นที่ 8 กับ $n=12$

\[ \begin{aligned} 1+0.12/12&=1.01,\\ 100(1.01)^{12}&=\$112.6825,\\ \text{bias}_{12}&=112.7497-112.6825\\ &=\$0.0672. \end{aligned} \]

ค่านี้อยู่ระหว่าง 0.1004 ของ 8 ก้าวกับ 0.0505 ของ 16 ก้าว ตามที่ควรเป็น ตรวจด้วยอันดับ $p_w=1$ ได้ด้วย ถ้า $\text{bias}_n\approx c/n$ แล้ว $\text{bias}_{12}\approx\text{bias}_4\times4/12=0.1988\times4/12=0.066$ ใกล้ค่าจริง 0.0672

3. กลับไปที่หุ้นผันผวน 80% ($\mu=12\%$) ในขั้นที่ 9 ถ้าจำลองด้วย Euler เดือนละก้าว (12 ก้าว) โอกาสที่เส้นทางหนึ่งจะมีราคาติดลบอย่างน้อยหนึ่งครั้งภายในปีคือเท่าไร?

เฉลย

แต่ละก้าวติดลบเมื่อ $Z$ ต่ำกว่าเกณฑ์ในขั้นที่ 9 ให้ $p$ คือโอกาสที่ก้าวหนึ่งติดลบ สิบสองก้าวอิสระกัน โอกาสที่ไม่ติดลบเลยคือ $(1-p)^{12}$ โอกาสที่ติดลบอย่างน้อยหนึ่งครั้งจึงเป็น $1-(1-p)^{12}$

\[ \begin{aligned} Z&\lt-\frac{1+0.01}{0.80\sqrt{1/12}}=-\frac{1.01}{0.23094}\\ &=-4.373,\\ p&=\Phi(-4.373)=0.0000061,\\ 1-(1-p)^{12}&=0.000073=0.0073\%. \end{aligned} \]

ลดจาก 8.08% ของก้าวละปีกว่าพันเท่า ($8.08/0.0073\approx1{,}100$)

// Standard Normal CDF: Simpson's rule on the bell curve from 0 to |x|.
function Phi(x) {
  if (!Number.isFinite(x) || Math.abs(x) > 8) throw new RangeError('Phi needs a finite score between -8 and 8');
  const n = 4000, h = Math.abs(x) / n, phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(x) * s * h / 3;
}
function checkModel(m) {
  if (![m.S0, m.mu, m.sigma].every(Number.isFinite) || m.S0 <= 0 || m.sigma <= 0) throw new RangeError('Need S0 > 0, sigma > 0 and a finite mu');
}
// One step of each GBM scheme from S with step dt and Brownian increment dW.
const schemes = {
  euler: (m, S, dt, dW) => S * (1 + m.mu * dt + m.sigma * dW),
  milstein: (m, S, dt, dW) => S * (1 + m.mu * dt + m.sigma * dW + 0.5 * m.sigma * m.sigma * (dW * dW - dt)),
  exact: (m, S, dt, dW) => S * Math.exp((m.mu - 0.5 * m.sigma * m.sigma) * dt + m.sigma * dW)
};
// Walk all three schemes on the same shocks z (common random numbers), dW = sqrt(dt) z.
function walk(m, z, T) {
  checkModel(m);
  if (!Array.isArray(z) || z.length === 0 || !z.every(Number.isFinite)) throw new TypeError('Need a nonempty list of finite shocks');
  const dt = T / z.length, rows = [{euler: m.S0, milstein: m.S0, exact: m.S0}];
  for (const x of z) {
    const dW = Math.sqrt(dt) * x, prev = rows[rows.length - 1], next = {};
    for (const k of Object.keys(schemes)) next[k] = schemes[k](m, prev[k], dt, dW);
    rows.push(next);
  }
  return {dt, dW: z.map(x => Math.sqrt(dt) * x), rows};
}
// mulberry32 + Box-Muller: seeded standard Normals, the same generator on every page of this chapter.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Strong error E|S_scheme - S_exact| at T = 1 on the same Brownian path, for several step counts.
function strongErrors(m, stepList, paths, seed) {
  checkModel(m);
  const maxN = Math.max(...stepList);
  if (!stepList.every(n => Number.isInteger(n) && n >= 1 && maxN % n === 0)) throw new RangeError('Step counts must be whole and divide the finest grid');
  const z = normals(seed), out = stepList.map(n => ({n, euler: 0, milstein: 0}));
  for (let p = 0; p < paths; p++) {
    const fine = Array.from({length: maxN}, () => z() * Math.sqrt(1 / maxN));
    stepList.forEach((n, j) => {
      const r = maxN / n, dt = 1 / n;
      let E = m.S0, M = m.S0, W = 0;
      for (let k = 0; k < n; k++) {
        let dW = 0;
        for (let i = 0; i < r; i++) dW += fine[k * r + i];
        E = schemes.euler(m, E, dt, dW); M = schemes.milstein(m, M, dt, dW); W += dW;
      }
      const X = m.S0 * Math.exp((m.mu - 0.5 * m.sigma * m.sigma) + m.sigma * W);
      out[j].euler += Math.abs(E - X) / paths; out[j].milstein += Math.abs(M - X) / paths;
    });
  }
  return out;
}
// Weak bias of the mean, exactly: E[S_Euler] = S0 (1 + mu dt)^n (the Milstein term has mean zero too).
function meanBias(m, n) {
  checkModel(m);
  return m.S0 * Math.exp(m.mu) - m.S0 * (1 + m.mu / n) ** n;
}
// Chance that one Euler step makes the price negative: Z below -(1 + mu dt) / (sigma sqrt(dt)).
function negativeStep(m, dt) {
  checkModel(m);
  const z = -(1 + m.mu * dt) / (m.sigma * Math.sqrt(dt));
  return {z, p: z < -8 ? 0 : Phi(z)};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • การขยับสุ่มของหนึ่งก้าวคือ $\Delta W=\sqrt{\Delta t}\,Z$ เสมอ ถ้าเผลอคูณด้วย $\Delta t$ ก้าวรายวันจะให้ความผันผวนทั้งปีแค่ $0.28/\sqrt{252}=1.76\%$ แทน 28%
  • Euler คือการเขียน SDE เป็นก้าวยาว $\Delta t$ ตรง ๆ Milstein เติมพจน์แก้ $\tfrac12bb'\big((\Delta W)^2-\Delta t\big)$ ที่ได้จาก Itô integral ในหนึ่งก้าว สำหรับ GBM ทั้งคู่คือ Taylor ของสูตรจริงที่ตัดคนละที่ ตัวคูณของราคาจึงเป็นเส้นตรง พาราโบลา และ exponential ตามลำดับ
  • สี่ก้าวของหุ้น \$100 บนเลขสุ่มชุดเดียวกัน สูตรจริงได้ \$114.66 Euler สูงไป 1.24% Milstein ต่ำไป 0.08% Euler สูงไปเพราะเส้นทางนี้มี $\sum(\Delta W)^2=0.605$ ไม่ใช่ 1 ปี
  • วัดจริงด้วย 20,000 เส้นทาง ทุกครั้งที่ก้าวสั้นลงครึ่งหนึ่ง strong error ของ Euler หารด้วยราว 1.41 ($\sqrt2$) และของ Milstein หารด้วยราว 1.99 (เกือบ 2)
  • bias ของค่าเฉลี่ยไม่หายด้วยการเพิ่มเส้นทาง Euler 4 ก้าวต่ำไป \$0.20 ซึ่งเท่ากับ 6.4 เท่าของ SE ที่ 1,000,000 เส้นทาง ทางแก้คือซอยก้าวหรือใช้สูตรจริง และรายงานทั้ง SE และ bias เสมอ
