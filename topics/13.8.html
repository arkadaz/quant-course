13.8 Variance Swaps and Log-Contract Replication

เปลี่ยน option strip ทั้งแถวเป็น fair variance แล้วตามรอยความคลาดเคลื่อนทุกชั้น

desk ต้องเสนอ fair strike ของ variance swap อายุ 30 วันบนดัชนีสหรัฐฯ เมื่อ SPX forward อยู่ 5,000 จุด แต่หน้าจอมี option หลายสิบ strike ไม่ได้มีสัญญาที่จ่าย variance ตรง ๆ ให้ซื้อ เราจะพิสูจน์ว่าทำไม put ฝั่งต่ำและ call ฝั่งสูงที่ถ่วงด้วย K^{2}$$ จึงรวมเป็นราคา variance ได้ แล้วคำนวณกำไรขาดทุนเป็น USD โดยไม่สลับ volatility กับ variance

ศัพท์การเงินที่เพิ่งโผล่มา

variance swap / fair variance strike
variance swap คือสัญญาที่แลก annualized realized variance กับระดับที่ตกลงไว้ ส่วน fair variance strike คือระดับที่ทำให้มูลค่าเริ่มต้นเป็นศูนย์ ใช้ซื้อหรือขายความแกว่งโดยไม่เลือกทิศทางราคาปลายทาง
realized variance (RV) / realized volatility / log return / observation schedule
realized variance (RV) คือผลรวมกำลังสองของ log return ที่ annualize แล้ว realized volatility คือรากของค่านั้น log return คือ log ของอัตราส่วนราคาติดกัน และ observation schedule คือชุดวันกับราคาที่สัญญาระบุ ใช้คำนวณขาชำระจริงแบบตรวจซ้ำได้
variance notional / vega notional / variance point
variance notional คือจำนวน USD ต่อหนึ่งหน่วย annualized variance ส่วน vega notional คือจำนวน USD ต่อการเปลี่ยน volatility 1 จุดเปอร์เซ็นต์ และ variance point คือ 01^{2} ใช้แปลงส่วนต่าง variance ให้เป็นเงินโดยไม่ผิดตัวคูณ
forward / discount factor / risk-neutral
forward คือราคาตกลงส่งมอบในอนาคต discount factor คือเงินวันนี้ที่โตเป็นหนึ่งหน่วยในวันนั้น และ risk-neutral คือกติกาถ่วงน้ำหนักที่ทำให้ราคาหลังหักดอกเบี้ยสอดคล้องกัน ใช้ย้ายจากเงินรับ option ไปหา fair strike
log contract / static replication / dynamic hedge
log contract คือเงินรับที่เป็นลบของ log ราคาปลายทางเทียบ forward static replication คือชุด option ที่ไม่ต้องปรับขาระหว่างทาง และ dynamic hedge คือจำนวน underlying ที่ต้องปรับตามราคา ใช้แยกขาเชิงเส้นออกจากความโค้งที่ option strip สร้าง
out-of-the-money (OTM) option / option strip / quadrature
out-of-the-money (OTM) option คือสิทธิ์ที่ไม่มี intrinsic value ณ ราคาอ้างอิง option strip คือแถวสิทธิ์หลาย strike และ quadrature คือการแทนอินทิกรัลด้วยผลรวมบนกริด ใช้ประมาณ log contract จาก put ต่ำกว่า forward และ call สูงกว่า forward
Cboe Volatility Index (VIX) / constant maturity
Cboe Volatility Index (VIX) คือดัชนีที่สรุป expected volatility 30 วันจากราคา SPX options ส่วน constant maturity คือ horizon คงที่ที่ได้จากการเชื่อมสอง expiry ใช้รายงานค่ารากของ variance ในหน่วย volatility points ไม่ใช่ราคา variance swap ที่ส่งมอบได้โดยตรง
futures
สัญญามาตรฐานที่ตกลงราคาซื้อขายสำหรับวันข้างหน้าและปรับกำไรขาดทุนผ่านตลาดตามกติกา ใช้รับความเสี่ยงของตัวอ้างอิง เช่น VIX โดยไม่ใช่รายการเดียวกับ variance swap
expected value
expected value คือค่าเฉลี่ยถ่วงด้วยความน่าจะเป็นภายใต้ measure ที่กำหนด ใช้เชื่อมเงินรับอนาคตกับราคาหรือ fair strike วันนี้
bid / ask / midquote / tail truncation
bid คือราคาที่ขายได้ ask คือราคาที่ซื้อได้ midquote คือกึ่งกลางสองราคา และ tail truncation คือการตัด strike ปีกไกลเพราะไม่มี quote ที่ใช้ได้ ใช้ระบุว่าผลรวมจากหน้าจอเป็นค่าประมาณและยังมีต้นทุนทำซ้ำ
jump / discrete sampling / replication error
jump คือการเปลี่ยนราคาข้ามช่วงทันที discrete sampling คือการวัดราคาเป็นวันหรือช่วงจำกัด และ replication error คือส่วนต่างระหว่างเงินรับสัญญากับชุดทำซ้ำ ใช้กำหนด model risk เมื่อสมมติฐานเส้นทางต่อเนื่องและกริด strike ไม่เป็นจริง

กำหนด desk problem และ convention

ให้ forward ของ SPX ที่ expiry 30 วันเท่ากับ 5,000 จุด อัตราดอกเบี้ยต่อเนื่อง 4% ต่อปี และ option midquotes สังเคราะห์มาจากสูตร 13.2 ด้วย volatility แบน 20% ต่อรากปี ใช้ strike 3,000 ถึง 7,000 ทุก 50 จุด ตัวเลขทั้งหมดเป็นแบบฝึกคำนวณ ไม่ใช่ snapshot ตลาดจริง

สัญญา variance swap สมมติวัด log return ตอนปิด 10 ครั้ง ใช้ observations ต่อปี ไม่หัก sample mean และมี variance notional 1,000,000 USD ต่อ annualized variance หนึ่งหน่วย ต้องล็อกสาม convention นี้ก่อนคำนวณ เพราะสัญญาจริงอาจมีวันหยุด ราคา disruption และกติกาปรับข้อมูลต่างกัน [FE4 M3 L9–L10]

กลับไปตอบ desk problem

บนชุด midquotes สังเคราะห์ fair variance strike แบบกริดคือ 0.04020277 ต่อปี หรือ 20.0506% ต่อรากปี ผู้ซื้อ variance notional 1,000,000 USD ที่เจอ path ตัวอย่าง 10 observations จ่ายรับ 7,677.23 USD ส่วนค่าที่สร้าง constant 30 วันจากสอง expiry เป็นขั้นเพิ่มของดัชนี VIX ไม่ใช่การอ้างว่า variance swap กับสัญญาที่อ้างอิง VIX เป็นรายการเดียวกัน

กับดัก: สูตร exact เจอตลาดที่มีกริดและ jump

replication แบบอินทิกรัลต้องการทุก strike แต่หน้าจอมี strike จำกัด ใช้ midquote ที่อาจซื้อขายไม่ได้ และปีกไกลอาจไม่มี bid การลด spacing ช่วย discretization แต่ไม่รับรองว่าการเติม quote ปีกถูกต้อง ต้องคำนวณ sensitivity ต่อ strike cutoff, bid–ask และ forward ที่ใช้

สูตร pathwise มาจาก diffusion ต่อเนื่อง ขณะที่สัญญาวัด log return เป็นช่วงและตลาดมี jump จึงเกิด replication error; corporate action, market disruption และ observation ที่หายต้องใช้เอกสารสัญญาจริง VIX ก็เป็นดัชนี constant-maturity ที่มี selection rule ของตัวเอง ไม่ใช่ variance swap ที่กดซื้อบนหน้าจอได้เหมือนหุ้น

ชุด option ปีกกว้างไม่ได้ทำให้ tail risk หายไป มันแค่ส่งใบแจ้งหนี้ช้ากว่า — หัวข้อ 21.3 จะเปลี่ยนอินทิกรัลเป็นเครื่องคำนวณที่เร็วขึ้น แต่ไม่เปลี่ยนสมมติฐานเศรษฐศาสตร์ข้างใต้

สรุปที่ใช้ได้จริง

  • คำนวณ realized variance ตาม observation schedule และ annualization ที่สัญญาระบุก่อนแปลงเป็น USD
  • fair variance strike มาจาก OTM put ใต้ forward และ OTM call เหนือ forward ที่ถ่วงด้วย K^{2}$$
  • ผลรวมแบบ VIX-style มี discretization, tail truncation และ quote conventions; constant 30 วันเชื่อม total variance
  • variance swap เป็นเส้นตรงใน variance ไม่ใช่ใน volatility และ jump ทำให้ static replication เหลือ basis risk
