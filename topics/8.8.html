8.8 Linear Combinations

ผลตอบแทนของพอร์ตคือผลรวมถ่วงน้ำหนักของผลตอบแทนแต่ละสินทรัพย์ ค่าเฉลี่ยกับ SD ของผลรวมนี้หาจาก covariance ได้เสมอ แต่จะบอกได้ว่าปีแย่ ๆ แย่แค่ไหน (VaR และ expected shortfall) จากสองตัวเลขนี้ ก็ต่อเมื่อผลตอบแทนเป็น MVN (Normal หลายตัวแปร) เท่านั้น

กองทุนหนึ่งแบ่งเงินลงหุ้น พันธบัตร และทองคำ ทีมความเสี่ยงต้องรายงานตัวเลขชื่อ “VaR 99%” ทุกปี VaR 99% คือระดับขาดทุนที่พอร์ตจะขาดทุนเกินได้แค่ราว 1 ปีใน 100 ปี ผู้ลงทุนใช้ตัวเลขนี้ดูว่ากองทุนอาจเสียเงินได้แค่ไหนในปีที่แย่มาก

ของที่รู้ (พอร์ตสมมติ):

  • มูลค่าพอร์ต $V=\$100$ ล้าน
  • ค่าเฉลี่ยของผลตอบแทนต่อปี $\mu_p=6.4\%$
  • SD ของผลตอบแทนต่อปี $\sigma_p=9.6\%$ คือขนาดที่ผลตอบแทนแต่ละปีแกว่งห่างจากค่าเฉลี่ย

สองตัวเลขหลังมาจากการรวมสามสินทรัพย์ หน้านี้จะคำนวณให้ดูทีละขั้นในขั้นที่ 3

นักวิเคราะห์คนแรกใช้สูตรสำเร็จของ Normal ในสูตรนี้ 2.3263 คือจำนวน SD ที่ต้องเดินลงจากค่าเฉลี่ย จนพื้นที่ใต้ระฆัง Normal ทางซ้ายเหลือแค่ 1% (ขั้นที่ 4 จะหาที่มาของสูตรให้ดู) คิดเป็นหน่วย \$ ล้าน ($V=100$) ได้

\[ \begin{aligned} \text{VaR}&=V\,(2.3263\,\sigma_p-\mu_p)\\ &=100\,(2.3263\times0.096-0.064)\\ &=100\,(0.2233-0.064)\approx15.93. \end{aligned} \]

เขาจึงรายงาน VaR 99% \$15.93 ล้าน นักวิเคราะห์คนที่สองบอกว่า จากสองตัวเลขนี้ยังตอบไม่ได้ ใครถูก และสองคนนี้เถียงกันเรื่องสูตร หรือเรื่องสมมติฐาน

ลองตอบก่อนเปิดเฉลย

ทั้งคู่ถูกคนละส่วน ค่าเฉลี่ย 6.4% กับ SD 9.6% หาได้จากค่าเฉลี่ยกับ covariance ของสามสินทรัพย์เสมอ ไม่ต้องสมมติอะไร แต่ VaR 99% ถามถึงรูปทรงของหางซ้าย คือผลตอบแทนต่ำกว่าระดับไหนได้แค่ 1% ของเวลา สองตัวเลขนี้ไม่ได้บอกเรื่องนั้น

คนแรกเพิ่มสมมติฐานเงียบ ๆ ว่าผลตอบแทนของสามสินทรัพย์เป็น joint Normal (Normal หลายตัวแปรร่วมกัน) พอร์ตจึงเป็น Normal และสูตรข้างบนใช้ได้ แต่ถ้าผลตอบแทนมาจากสองภาวะตลาด (ปีสงบกับปีตึงเครียด) ที่ปรับให้ค่าเฉลี่ยและ SD เท่าเดิมทุกตัว VaR 99% จะเป็น \$18.99 ล้าน กับดักท้ายหน้าจะคำนวณตัวเลขนี้ให้ดู ดังนั้นสองคนนี้เถียงกันเรื่องสมมติฐาน ไม่ใช่เรื่องสูตร

ภาพรวมก่อนลงสูตร

เริ่มจากตัวอย่างเล็ก ๆ นักลงทุนแบ่งเงิน 60% ไว้ใน SPX (ดัชนี S&P 500 คือหุ้นใหญ่ 500 ตัวของสหรัฐ) และ 40% ไว้ใน QQQ (กองทุนที่วิ่งตามดัชนี Nasdaq-100 ซึ่งเป็นหุ้นเทคโนโลยีเป็นหลัก) ถ้าวันนี้ SPX ขึ้น 1% และ QQQ ลง 2% พอร์ตได้ $0.6\times1\%+0.4\times(-2\%)=-0.2\%$ ผลตอบแทนของพอร์ตจึงเป็นแค่ผลรวมถ่วงน้ำหนัก

เขียนเป็นสูตรทั่วไปได้ว่า $L=a^{\mathsf T}R$ โดย $R$ คือ vector ผลตอบแทนของแต่ละสินทรัพย์ และ $a$ คือ vector ตัวคูณ (ในตัวอย่างนี้ $a=(0.6,\ 0.4)$) คำถามของหน้านี้คือ ถ้ารู้ distribution ของ $R$ แล้ว จะรู้ distribution ของ $L$ ได้แค่ไหน คำตอบมีสองชั้น

  • ชั้นที่ได้ฟรีเสมอ: ค่าเฉลี่ย $a^{\mathsf T}\mu$ และ variance $a^{\mathsf T}\Sigma a$ ของ $L$ โดย $\mu$ คือ vector ค่าเฉลี่ยของแต่ละสินทรัพย์ และ $\Sigma$ คือ covariance matrix ชั้นนี้ไม่ต้องสมมติอะไรเลย นอกจาก variance มีค่าจำกัด เป็นสูตรเดียวกับในการแปลงเชิงเส้นและความเสี่ยงของพอร์ต
  • ชั้นที่ต้องสมมติเพิ่ม: รูปทรงทั้งก้อนของ distribution ของ $L$ ซึ่ง VaR ต้องใช้ ชั้นนี้ต้องรู้มากกว่า covariance

รูปข้างล่างช่วยให้เห็นภาพ แกนนอนคือผลตอบแทน SPX แกนตั้งคือผลตอบแทน QQQ ของวันหนึ่ง ถ้าวาดผลตอบแทนของหลาย ๆ วันเป็นจุด จะได้ “เมฆ” ที่หนาแน่นตรงกลาง ให้ $x$ และ $y$ เป็นผลตอบแทน SPX และ QQQ (หน่วยเปอร์เซ็นต์) ทุกจุดที่ทำให้พอร์ต 60/40 ได้ −2% เท่ากันจะเรียงอยู่บนเส้นตรงเส้นเดียว เพราะ $0.6x+0.4y=-2$ คือสมการเส้นตรง เส้นของค่าอื่น ๆ ขนานกับเส้นนี้หมด

ดังนั้นโอกาสที่พอร์ตได้ระหว่าง −4% ถึง −2% คือมวลของเมฆที่ตกอยู่ระหว่างสองเส้นนั้น ถ้าเมฆเป็น MVN (Normal หลายตัวแปร) มวลระหว่างเส้นขนานจะเรียงกันเป็นรูประฆัง Normal เสมอ ไม่ว่าเส้นจะเอียงไปทางไหน สมบัตินี้เรียกว่า Gaussian closure

หน้านี้เดินทีละขั้น ขั้นที่ 1 หาสูตรค่าเฉลี่ยและ variance ของผลรวม ขั้นที่ 2 ใช้ MGF พิสูจน์ว่าผลรวมของ MVN เป็น Normal ขั้นที่ 3 และ 4 ใช้กับพอร์ตหุ้น/พันธบัตร/ทอง 50/30/20 จนได้ VaR และ expected shortfall ขั้นที่ 5 แบ่งความเสี่ยงให้แต่ละสินทรัพย์ ขั้นที่ 6 ดูพอร์ตรายวัน 60/40 ขั้นที่ 7 แปลงแบบจำลองรายปีเป็นรายวัน แล้วปิดด้วยกับดัก ข้อที่สำคัญที่สุดคือ distribution สองแบบที่ค่าเฉลี่ยและ covariance เท่ากันทุกตัว ยังให้ VaR ต่างกันได้ถึง 19% กับดักท้ายหน้าจะคำนวณให้ดู

ขั้นที่ 1 — ค่าเฉลี่ยและ variance ของผลรวม โดยยังไม่สมมติ Normal

ก่อนสมมติอะไรเรื่องรูปทรงของ distribution มาดูก่อนว่าได้อะไรมาฟรี เงื่อนไขเดียวคือทุกสินทรัพย์มี variance จำกัด ค่าเฉลี่ยของผลรวมคือผลรวมของค่าเฉลี่ย เพราะ expected value เป็นเชิงเส้น ส่วน variance คือค่าเฉลี่ยของระยะห่างจากค่าเฉลี่ยยกกำลังสอง เราจึงหักค่าเฉลี่ยออกก่อน แล้วยกกำลังสองผลรวมที่เหลือ ในสูตรข้างล่าง $\Sigma_{ij}$ คือ covariance ของสินทรัพย์ $i$ กับ $j$ ซึ่งนิยามว่า $\Sigma_{ij}=\mathbb E[(R_i-\mu_i)(R_j-\mu_j)]$

\[ \begin{aligned} L&:=a^{\mathsf T}R=\sum_i a_iR_i,\\ \mathbb E[L]&=\sum_i a_i\mu_i=a^{\mathsf T}\mu,\\ L-\mathbb E[L]&=\sum_i a_i(R_i-\mu_i),\\ \operatorname{Var}(L)&=\mathbb E\Big[\Big(\sum_i a_i(R_i-\mu_i)\Big)^2\Big]\\ &=\sum_i\sum_j a_ia_j\,\Sigma_{ij}\\ &=a^{\mathsf T}\Sigma a. \end{aligned} \]

จังหวะที่ต้องคิดคือการกระจายกำลังสองของผลรวม $\big(\sum_ix_i\big)^2=\sum_i\sum_jx_ix_j$ ซึ่งได้ทุกคู่ $(i,j)$ จากนั้นค่าเฉลี่ยของ $(R_i-\mu_i)(R_j-\mu_j)$ ก็คือ $\Sigma_{ij}$ ตามนิยาม คู่ที่ $i=j$ คือ variance ของสินทรัพย์ตัวนั้นเอง คู่ที่ $i\ne j$ คือ covariance ระหว่างสองตัว ซึ่งเป็นที่มาของ “พจน์ไขว้”

ไม่มีบรรทัดไหนใช้ Normal หรือความอิสระเลย สองตัวเลขนี้จึงถูกกับทุก distribution ที่ variance จำกัด แต่มันเป็นแค่สองตัวเลข รู้ค่าเฉลี่ยกับ variance แล้ว ยังไม่รู้ว่าหางซ้ายหนาแค่ไหน (หางซ้ายคือโอกาสที่ผลตอบแทนติดลบมาก ๆ) ขั้นถัดไปจะเติมช่องว่างนี้

ขั้นที่ 2 — ใช้ MGF พิสูจน์ว่าผลรวมของ MVN ยังเป็น Normal

ถ้าอยากรู้มากกว่าสองตัวเลข ต้องสมมติเพิ่ม สมมติว่า $R\sim\mathcal N_n(\mu,\Sigma)$ คือผลตอบแทน $n$ ตัวเป็น MVN ที่มี vector ค่าเฉลี่ย $\mu$ และ covariance $\Sigma$ เครื่องมือที่เหมาะคือ moment generating function (MGF) คือฟังก์ชัน $M_X(t)=\mathbb E[e^{tX}]$ ซึ่งระบุ distribution ได้ครบ หน้านั้นหา MGF ของ MVN ไว้แล้ว คือ $M_R(s)=\exp\big(s^{\mathsf T}\mu+\tfrac12s^{\mathsf T}\Sigma s\big)$

ทำไม MGF ถึงเหมาะ เพราะ $e^{tL}=e^{t\,a^{\mathsf T}R}=e^{(ta)^{\mathsf T}R}$ แปลว่า MGF ของ $L$ ก็คือ MGF ของ $R$ ที่แทนค่าตรงจุด $s=ta$ ไม่ต้อง integrate อะไรใหม่

\[ \begin{aligned} M_L(t)&=\mathbb E\big[e^{t\,a^{\mathsf T}R}\big]=M_R(ta)\\ &=\exp\!\big(t\,a^{\mathsf T}\mu+\tfrac12t^2a^{\mathsf T}\Sigma a\big),\\ L&\sim\mathcal N\big(a^{\mathsf T}\mu,\ a^{\mathsf T}\Sigma a\big). \end{aligned} \]

บรรทัดที่สองได้จากการแทน $s=ta$ ลงใน MGF ของ MVN ผลออกมามีรูป $\exp(tm+\tfrac12t^2v)$ โดย $m=a^{\mathsf T}\mu$ และ $v=a^{\mathsf T}\Sigma a$ รูปนี้คือ MGF ของ Normal ตัวเดียวที่มีค่าเฉลี่ย $m$ และ variance $v$ พอดี เหตุผลที่สรุปได้คือ MGF ที่มีค่าจำกัดรอบ $t=0$ ระบุ distribution ได้แบบเดียว ดังนั้น $L$ เป็น Normal จริง ๆ ไม่ใช่แค่มีค่าเฉลี่ยกับ variance เหมือน Normal

กรณีพิเศษ ถ้า $a^{\mathsf T}\Sigma a=0$ สูตรยังใช้ได้ แต่ $L$ เป็นค่าคงที่ ไม่มีระฆังให้วาด เราจึงไม่ต้องขอให้ $\Sigma$ invert ได้

ขยายเป็นหลาย output พร้อมกัน

บางครั้งต้องการหลายผลรวมพร้อมกัน เช่นดูพอร์ตสามแบบในคราวเดียว ให้แต่ละแถวของ matrix $A$ เป็นตัวคูณของผลรวมหนึ่งตัว และ $c$ เป็น vector ค่าคงที่ที่บวกเข้าไป แล้วทำแบบเดียวกัน โดยให้ $s$ เป็น vector

\[ \begin{aligned} Y&:=AR+c,\\ M_Y(s)&=e^{s^{\mathsf T}c}\,M_R(A^{\mathsf T}s)\\ &=\exp\!\big(s^{\mathsf T}(A\mu+c)\\ &\qquad+\tfrac12s^{\mathsf T}A\Sigma A^{\mathsf T}s\big),\\ Y&\sim\mathcal N\big(A\mu+c,\ A\Sigma A^{\mathsf T}\big). \end{aligned} \]

ค่าคงที่ $c$ เลื่อนค่าเฉลี่ย แต่ไม่เปลี่ยน covariance การเลือกดูเฉพาะบางสินทรัพย์ (marginal ของ MVN) คือกรณีที่ $A$ เป็น selection matrix ซึ่งแต่ละแถวมีเลข 1 ตัวเดียวตรงสินทรัพย์ที่เลือก ส่วนการดูหลายพอร์ตพร้อมกันคือกรณีที่แต่ละแถวของ $A$ เป็นน้ำหนักของพอร์ตหนึ่ง ถ้าสองแถวของ $A$ เหมือนกัน $A\Sigma A^{\mathsf T}$ จะ singular (invert ไม่ได้) แต่ $Y$ ยังเป็น Gaussian เพียงแต่ไม่มี density เต็มมิติ

ทางกลับกันก็จริง นิยามหนึ่งของ MVN คือ “ทุก linear combination เป็น Normal” (นับค่าคงที่เป็น Normal ที่ variance ศูนย์) คำว่า “ทุก” สำคัญมาก ตรวจว่าแต่ละสินทรัพย์ดูเป็น Normal หรือลองพอร์ตไม่กี่แบบ ยังไม่พอ กับดักท้ายหน้าจะแสดงว่าพังได้อย่างไร

ขั้นที่ 3 — พอร์ต 50/30/20: ไล่จากข้อมูลตั้งต้นไปถึง distribution

โจทย์ให้อะไรมาบ้าง: นี่คือพอร์ตในคำถามเปิด กองทุนแบ่งเงิน \$100 ล้าน ลงสามสินทรัพย์ คือหุ้นสหรัฐ 50% พันธบัตรรัฐบาลสหรัฐ 30% และทองคำ 20% เราอยากรู้ค่าเฉลี่ยและ SD ของผลตอบแทนทั้งพอร์ตในหนึ่งปี ตัวเลขในตารางเป็นค่าสมมติของแบบจำลอง และขอสมมติเพิ่มว่าผลตอบแทนรายปีของสามตัวเป็น joint Normal (MVN) ข้อนี้เป็นสมมติฐาน ไม่ใช่หลักฐานว่าตลาดจริงเป็น Normal

สินทรัพย์ค่าเฉลี่ยต่อปีSD ต่อปีน้ำหนัก
หุ้นสหรัฐ9%18%0.50
พันธบัตรสหรัฐ3%6%0.30
ทองคำ5%15%0.20

นอกจากค่าเฉลี่ยกับ SD ยังต้องรู้ว่าสินทรัพย์แต่ละคู่ขยับไปทางเดียวกันแค่ไหน ตัววัดนี้คือ correlation $\rho$ ซึ่งอยู่ระหว่าง −1 ถึง 1 ค่าสมมติคือ

  • หุ้นกับพันธบัตร $\rho_{12}=-0.20$ (ปีที่หุ้นแย่ พันธบัตรมักดีขึ้นเล็กน้อย)
  • หุ้นกับทอง $\rho_{13}=0.05$
  • พันธบัตรกับทอง $\rho_{23}=0.25$

สูตรของขั้นที่ 1 ใช้ covariance ไม่ใช่ correlation จึงต้องแปลงก่อนด้วย $\Sigma_{ij}=\rho_{ij}\sigma_i\sigma_j$ เช่นหุ้นกับพันธบัตรได้ $\Sigma_{12}=-0.20\times0.18\times0.06=-0.00216$ ส่วนช่องทแยงคือ variance ของตัวเอง เช่น $\Sigma_{11}=0.18^2=0.0324$ จากนั้นใช้สูตรของขั้นที่ 1 โดยตัวคูณคือน้ำหนัก $a=w=(0.5,\ 0.3,\ 0.2)$ เราคำนวณ $u=\Sigma w$ แยกไว้ก่อน เพราะขั้นที่ 5 จะใช้ซ้ำ

\[ \begin{aligned} \Sigma&=\begin{bmatrix} 0.0324&-0.00216&0.00135\\ -0.00216&0.0036&0.00225\\ 0.00135&0.00225&0.0225 \end{bmatrix},\\ \mu_p&=0.5(0.09)+0.3(0.03)+0.2(0.05)\\ &=0.064,\\ u_1&=0.5(0.0324)+0.3(-0.00216)\\ &\quad+0.2(0.00135)=0.015822,\\ u&:=\Sigma w\\ &=(0.015822,\ 0.000450,\ 0.005850)^{\mathsf T},\\ v_p&=w^{\mathsf T}u=0.5(0.015822)\\ &\quad+0.3(0.000450)+0.2(0.005850)\\ &=0.009216,\\ \sigma_p&=\sqrt{0.009216}=0.096,\\ R_p&\sim\mathcal N(0.064,\ 0.009216). \end{aligned} \]

$u_2$ และ $u_3$ คำนวณแบบเดียวกับ $u_1$ คือเอาแถวที่ 2 และแถวที่ 3 ของ $\Sigma$ คูณกับ $w$

คำตอบ: ค่าเฉลี่ย 6.4% และ SD 9.6% ต่อปี บรรทัดสุดท้าย (พอร์ตเป็น Normal) เขียนได้เพราะเราสมมติ joint Normal ไว้ ถ้าเอาสมมติฐานนี้ออก ค่าเฉลี่ยกับ SD ยังถูกทุกหลัก แต่จะไม่รู้รูปทรงทั้งก้อนของ distribution

ตรวจเองใน 10 วินาที: แยก variance เป็นสองกอง กอง $D$ คือพจน์ทแยง (แต่ละสินทรัพย์ลำพัง) กอง $K$ คือพจน์ไขว้ (คู่ที่ต่างกัน นับสองครั้ง) ตัวคูณข้างหน้าคือ $w_i^2$ และ $w_iw_j$ เช่น $0.25=0.5^2$ และ $0.15=0.5\times0.3$

\[ \begin{aligned} D&=0.25(0.0324)+0.09(0.0036)\\ &\quad+0.04(0.0225)=0.009324,\\ K&=2\big[0.15(-0.00216)+0.10(0.00135)\\ &\quad+0.06(0.00225)\big]=-0.000108,\\ D+K&=0.009216. \end{aligned} \]

ได้ตรงกับ $v_p$ พจน์ไขว้ของพอร์ตนี้แทบหักล้างกันหมด เพราะ covariance ของหุ้นกับพันธบัตรติดลบ แต่นี่เป็นเรื่องของชุดตัวเลขนี้เท่านั้น ไม่ได้แปลว่า covariance ไม่สำคัญ ในขั้นที่ 6 จะเห็นพอร์ตที่พจน์ไขว้ทำให้ SD เปลี่ยนไปมาก

ขั้นที่ 4 — VaR และ expected shortfall จากค่าเฉลี่ยกับ SD

ตอนนี้รู้แล้วว่าผลตอบแทนพอร์ต $R_p$ เป็น Normal ที่มีค่าเฉลี่ย $\mu_p$ และ SD $\sigma_p$ รูปทรงของ Normal ตายตัว พอรู้สองค่านี้ หางซ้ายทั้งหางก็ถูกกำหนดแล้ว เราจึงคำนวณ VaR กับ ES ได้ ตั้งชื่อของที่ต้องใช้ก่อน

  • $V$ คือมูลค่าพอร์ตตอนต้นปี ขาดทุนเป็นดอลลาร์คือ $-VR_p$ (ผลตอบแทนติดลบ แปลว่าขาดทุนเป็นบวก)
  • VaR ระดับ $p$ (เช่น $p=0.99$) คือขาดทุนที่ถูกเกินได้แค่สัดส่วน $1-p$ ของเวลา
  • ES ระดับ $p$ คือค่าเฉลี่ยของขาดทุน นับเฉพาะเมื่อขาดทุนเกิน VaR แล้ว
  • เขียน $R_p=\mu_p+\sigma_pZ$ โดย $Z$ เป็น Normal มาตรฐาน (ค่าเฉลี่ย 0 SD 1) ที่มี density $\varphi$ และ quantile $z_p$
\[ \begin{aligned} \operatorname{VaR}_p&=V\,(z_p\,\sigma_p-\mu_p),\\ \mathbb E[Z\mid Z\gt z]&=\frac{1}{1-p}\int_{z}^{\infty}t\,\varphi(t)\,dt\\ &=\frac{\varphi(z)}{1-p},\\ \operatorname{ES}_p&=V\Big(\sigma_p\frac{\varphi(z_p)}{1-p}-\mu_p\Big). \end{aligned} \]

บรรทัด VaR ได้จากการกลับเครื่องหมาย เพราะ Normal สมมาตร $Z$ จึงต่ำกว่า $-z_p$ ได้แค่ $1-p$ ของเวลา แปลว่าผลตอบแทนต่ำกว่า $\mu_p-z_p\sigma_p$ ได้แค่ $1-p$ ของเวลา คูณด้วย $-V$ แล้ว ขาดทุนจึงเกิน $V(z_p\sigma_p-\mu_p)$ ได้แค่เท่านั้น

บรรทัด ES ต้องใช้ค่าเฉลี่ยของ $Z$ ในหางขวาเหนือ $z$ ซึ่งเท่ากับค่าเฉลี่ยของ $-Z$ ในหางซ้าย เพราะ Normal สมมาตร ส่วน integral ทำได้ในบรรทัดเดียว เพราะ $\varphi(t)=e^{-t^2/2}/\sqrt{2\pi}$ มีอนุพันธ์ $\varphi'(t)=-t\varphi(t)$ ดังนั้น $\int_z^\infty t\varphi(t)\,dt=\big[-\varphi(t)\big]_z^\infty=\varphi(z)$ สังเกตว่าทั้งสองสูตรมีแค่ $\mu_p$ กับ $\sigma_p$ ใน Normal จึงไม่มีข้อมูลหางอะไรนอกเหนือจากสองตัวเลขนี้

แทนตัวเลขของพอร์ต 50/30/20 คิดเป็นหน่วย \$ ล้าน ($V=100$) โดย $\mu_p=0.064$ และ $\sigma_p=0.096$ ค่า $z_{0.99}$ อ่านจากตาราง Normal และ $\varphi(z_{0.99})$ ได้จากการแทนค่าในสูตรของ $\varphi$

\[ \begin{aligned} z_{0.99}&\approx2.3263,\\ \varphi(z_{0.99})&\approx0.026652,\\ \frac{\varphi(z_{0.99})}{1-0.99}&=\frac{0.026652}{0.01}=2.6652,\\ \operatorname{VaR}_{0.99}&=100\,(2.3263\times0.096-0.064)\\ &=100\times0.15933\approx15.933,\\ \operatorname{ES}_{0.99}&=100\,(0.096\times2.6652-0.064)\\ &=100\times0.19186\approx19.186. \end{aligned} \]

ได้ VaR 99% ราว \$15.93 ล้าน และ ES 99% ราว \$19.19 ล้าน อ่านว่า ประมาณ 1 ปีใน 100 ปี พอร์ตจะขาดทุนเกิน \$15.93 ล้าน และในปีแย่กลุ่มนั้น ขาดทุนเฉลี่ย \$19.19 ล้าน มากกว่า VaR อีก $19.186-15.933\approx\$3.25$ ล้าน ทั้งสองเป็นตัวเลขของแบบจำลอง ไม่ใช่ขาดทุนสูงสุดที่เป็นไปได้ และไม่ได้รับประกันว่าทุก 100 ปีจะเจอปีแบบนี้หนึ่งครั้งพอดี

เทียบกับการลงหุ้นล้วน (ค่าเฉลี่ย 9% SD 18%) ใช้สูตรเดิม $100\,(2.3263\times0.18-0.09)\approx32.87$ คือ VaR 99% \$32.87 ล้าน เกือบสองเท่าของพอร์ตผสม ทั้งที่ค่าเฉลี่ยสูงกว่า

ขั้นที่ 5 — เงินครึ่งพอร์ตไม่ได้แปลว่ารับความเสี่ยงครึ่งหนึ่ง

ทีมความเสี่ยงมักถามต่อว่า SD 9.6% นี้มาจากสินทรัพย์ไหน เงินครึ่งหนึ่งอยู่ในหุ้น หุ้นจึงรับความเสี่ยงครึ่งหนึ่งหรือเปล่า วิธีตอบคือแบ่ง variance ของพอร์ตเป็นก้อน ก้อนละหนึ่งสินทรัพย์ ก้อนของสินทรัพย์ $i$ คือ $C_i=w_i(\Sigma w)_i=w_iu_i$ โดยใช้ $u=\Sigma w$ จากขั้นที่ 3 เมื่อรวมทุกก้อนจะได้ $\sum_iC_i=w^{\mathsf T}u=w^{\mathsf T}\Sigma w=v_p$ พอดี นี่เป็นการแบ่งบัญชีของ variance ไม่ใช่การแบ่งโอกาสขาดทุน

\[ \begin{aligned} C_1&=0.5(0.015822)=0.007911,\\ C_2&=0.3(0.000450)=0.000135,\\ C_3&=0.2(0.005850)=0.001170,\\ \textstyle\sum_i C_i&=0.009216,\\ C_1/v_p&=0.007911/0.009216\approx85.84\%. \end{aligned} \]

หารก้อนที่เหลือด้วย $v_p=0.009216$ แบบเดียวกัน ได้พันธบัตร $0.000135/0.009216\approx1.46\%$ และทอง $0.001170/0.009216\approx12.70\%$

ทำไมหุ้นใช้เงิน 50% แต่กิน variance ถึง 85.84% เพราะ $C_i$ ไม่ได้คูณน้ำหนักกับ variance ของตัวเองอย่างเดียว มันคูณกับ $(\Sigma w)_i$ ซึ่งคือ covariance ของสินทรัพย์ $i$ กับทั้งพอร์ต ($(\Sigma w)_i=\operatorname{Cov}(R_i,R_p)$) หุ้นมี SD สูงสุด (18%) และเป็นก้อนใหญ่ที่สุดของพอร์ตเอง พอร์ตจึงขยับตามหุ้นมากที่สุด

พันธบัตรได้แค่ 1.46% เพราะ correlation ติดลบกับหุ้นหักล้างความผันผวนของพันธบัตรเองเกือบหมด ถ้าพอร์ตมีสินทรัพย์ที่ถือไว้เพื่อหักล้างความเสี่ยง (hedge) ก้อนของมันติดลบได้ ดูโจทย์ข้อ 2 ท้ายหน้า

เชื่อม contribution กับอนุพันธ์ของความเสี่ยง

ทำไมแบ่งแบบนี้ถึงสมเหตุผล ดูจากอนุพันธ์ของ variance $v=w^{\mathsf T}\Sigma w$ และของ SD $\sigma=\sqrt v$ เทียบกับน้ำหนักแต่ละตัว อนุพันธ์นี้บอกว่า ถ้าเพิ่มน้ำหนักสินทรัพย์ $i$ นิดหนึ่ง ความเสี่ยงของพอร์ตจะเปลี่ยนเร็วแค่ไหน

\[ \begin{aligned} \frac{\partial v}{\partial w_i}&=2(\Sigma w)_i,\\ \frac{\partial\sigma}{\partial w_i}&=\frac{(\Sigma w)_i}{\sigma}\quad(\sigma\gt0),\\ \sum_i w_i\frac{\partial\sigma}{\partial w_i}&=\frac{w^{\mathsf T}\Sigma w}{\sigma}=\sigma. \end{aligned} \]

บรรทัดสุดท้ายบอกว่า ถ้าเอาน้ำหนักแต่ละตัวคูณกับอัตราที่ SD เปลี่ยน แล้วรวมกัน จะได้ SD ทั้งพอร์ตพอดี เหตุผลคือถ้าคูณทุกน้ำหนักด้วย $k$ SD ก็คูณด้วย $k$ ตาม ($\sigma$ เป็นฟังก์ชัน homogeneous ดีกรี 1) นี่คือเหตุที่ contribution รวมกันได้ความเสี่ยงทั้งพอร์ตพอดี

ลองใช้ ย้ายน้ำหนัก 0.01 จากหุ้นไปพันธบัตร คือ $\Delta w_1=-0.01$ และ $\Delta w_2=+0.01$ SD จะเปลี่ยนประมาณ $\sum_i\frac{\partial\sigma}{\partial w_i}\Delta w_i=0.01\,(u_2-u_1)/\sigma$

\[ \begin{aligned} \frac{u_2-u_1}{\sigma}&=\frac{0.000450-0.015822}{0.096}\\ &\approx-0.1601,\\ \sigma_{\text{new}}&\approx0.096+0.01\times(-0.1601)\\ &\approx0.09440. \end{aligned} \]

SD ใหม่จึงประมาณ 9.440% ถ้าคำนวณตรงด้วยสูตรของขั้นที่ 1 ที่น้ำหนัก $(0.49,\ 0.31,\ 0.20)$ ได้ 9.4407% ใกล้กันเพราะขยับน้ำหนักน้อย

ถ้าอยากให้ทั้งสามสินทรัพย์รับ variance เท่ากันคนละหนึ่งในสาม (เรียกว่า risk parity) ต้องแก้สมการ $C_1=C_2=C_3$ ด้วยวิธีเชิงตัวเลข เพราะไม่มีสูตรปิด ได้น้ำหนักราว $(0.2115,\ 0.5869,\ 0.2016)$ ซึ่งให้ SD $\sqrt{w^{\mathsf T}\Sigma w}\approx6.095\%$ แต่ค่าเฉลี่ยตกเหลือ $0.2115(9\%)+0.5869(3\%)+0.2016(5\%)\approx4.672\%$

ขั้นที่ 6 — อีกช่วงเวลา: พอร์ตรายวัน 60/40 ของ SPX กับ QQQ

โจทย์ให้อะไรมาบ้าง: กลับมาที่พอร์ตในรูปเส้นขนานด้านบน นักลงทุนแบ่งเงิน 60% ใน SPX และ 40% ใน QQQ เขาอยากรู้ว่าในหนึ่งวัน พอร์ตจะลง 2% ถึง 4% บ่อยแค่ไหน ระวังชื่อ “60/40” ตรงนี้หมายถึงหุ้นสองกอง ไม่ใช่พอร์ตหุ้น 60% พันธบัตร 40% ที่คนในวงการมักหมายถึง แบบจำลองรายวัน (สมมติ) คิดผลตอบแทนเป็นหน่วยเปอร์เซ็นต์ variance จึงเป็นหน่วยเปอร์เซ็นต์ยกกำลังสอง

  • SPX ค่าเฉลี่ย 0.04% SD 2% ต่อวัน จึงมี variance $2^2=4$
  • QQQ ค่าเฉลี่ย 0.03% SD 3% ต่อวัน จึงมี variance $3^2=9$
  • correlation 0.4 จึงได้ covariance $0.4\times2\times3=2.4$
  • น้ำหนัก $w=(0.6,\ 0.4)$ และขอสมมติว่าทั้งคู่เป็น joint Normal

ขั้นแรกใช้สูตรของขั้นที่ 1 แบบสองสินทรัพย์ $v_L=w_1^2\sigma_1^2+w_2^2\sigma_2^2+2w_1w_2\Sigma_{12}$ จากนั้นใช้ Gaussian closure พอร์ตเป็น Normal จึงหาโอกาสได้จากพื้นที่ใต้ระฆังด้วย $\Phi$ หลังแปลงขอบทั้งสองเป็นจำนวน SD ที่ห่างจากค่าเฉลี่ย

\[ \begin{aligned} \mu_L&=0.6(0.04)+0.4(0.03)=0.036,\\ v_L&=0.36(4)+0.16(9)+2(0.24)(2.4)\\ &=1.44+1.44+1.152=4.032,\\ \sigma_L&=\sqrt{4.032}\approx2.008,\\ \frac{-2-0.036}{2.008}&\approx-1.014,\\ \frac{-4-0.036}{2.008}&\approx-2.010,\\ P(-4\lt L\lt-2)&=\Phi(-1.014)-\Phi(-2.010)\\ &\approx15.53\%-2.22\%=13.31\%. \end{aligned} \]

คำตอบ: ค่าเฉลี่ย 0.036% SD 2.008% ต่อวัน และโอกาสที่พอร์ตลงระหว่าง 2% ถึง 4% ในหนึ่งวันคือ 13.31% หรือราว 13 วันใน 100 วัน ตัวเลขนี้คือพื้นที่แดงในรูปเส้นขนาน

covariance ทำอะไรกับ SD ของพอร์ต ลองเทียบสามกรณี ถ้าสองตัวไม่ขยับร่วมกันเลย (correlation 0) พจน์ไขว้ 1.152 หายไป ถ้าขยับตามกันเป๊ะ (correlation 1) variance เป็น $(w_1\sigma_1+w_2\sigma_2)^2$ SD จึงเท่ากับค่าเฉลี่ยถ่วงน้ำหนักของ SD

\[ \begin{aligned} \text{SD}_{\rho=0}&=\sqrt{1.44+1.44}\approx1.697\%,\\ \text{SD}_{\rho=0.4}&=\sqrt{4.032}\approx2.008\%,\\ \text{SD}_{\rho=1}&=0.6(2)+0.4(3)=2.4\%. \end{aligned} \]

ของจริงอยู่ระหว่างกลาง

ตรวจเองใน 10 วินาที: spread SPX − QQQ (ซื้อ SPX แล้วขาย QQQ มูลค่าเท่ากัน) ใช้ตัวคูณ $a=(1,\ -1)$ ได้ค่าเฉลี่ย $0.04-0.03=0.01\%$ และ variance $4+9-2(2.4)=8.2$ คราวนี้ covariance ถูกหักออก เพราะพจน์ไขว้มีตัวคูณ $2a_1a_2=2(1)(-1)=-2$ ซึ่งติดลบ spread ก็ยังเป็น Normal แม้สองตัวไม่อิสระกัน เพราะ Gaussian closure ใช้ได้กับทุกตัวคูณ

ขั้นที่ 7 — เปลี่ยนช่วงเวลา (horizon) ต้องเพิ่มแบบจำลองตามเวลา

หัวหน้าขอ VaR รายวัน ของพอร์ต 50/30/20 แต่แบบจำลองที่มีอยู่เป็นรายปี จะแปลงอย่างไร ต้องสมมติเพิ่มสามข้อ

  • ผลตอบแทนรายปีคือผลรวมของผลตอบแทนรายวัน $T=252$ วัน เพราะตลาดหุ้นสหรัฐเปิดราว 252 วันต่อปี คือ 365 วัน หักเสาร์อาทิตย์ราว 104 วัน และวันหยุดตลาดราว 9 วัน ($365-104-9=252$)
  • ทุกวันมีค่าเฉลี่ย $\mu_d$ และ variance $\sigma_d^2$ เท่ากัน
  • ผลตอบแทนของวันต่างกันไม่มี covariance ต่อกัน (วันนี้ไม่บอกอะไรเกี่ยวกับพรุ่งนี้)

จากนั้นใช้สูตรของขั้นที่ 1 กับผลรวมของ 252 วัน แล้วแก้กลับหาค่ารายวัน ค่า $q_{0.01,d}$ คือผลตอบแทนรายวันที่ต่ำกว่านี้ได้แค่ 1% ของวัน

\[ \begin{aligned} S_T&:=\sum_{t=1}^T R_t,\\ \mathbb E[S_T]&=T\mu_d,\qquad\operatorname{Var}(S_T)=T\sigma_d^2,\\ \mu_d&=\mu_p/T=0.064/252\approx0.000254,\\ \sigma_d&=\sigma_p/\sqrt T=0.096/\sqrt{252}\\ &\approx0.006047,\\ q_{0.01,d}&=\mu_d-z_{0.99}\,\sigma_d\\ &=0.000254-2.3263(0.006047)\\ &\approx-0.01381,\\ \operatorname{VaR}_{0.99,d}&=100\times0.01381\approx1.38. \end{aligned} \]

บรรทัด variance คือสูตรของขั้นที่ 1 อีกครั้ง โดยมองแต่ละวันเป็น “สินทรัพย์” หนึ่งตัวที่ตัวคูณ 1 เมื่อ covariance ข้ามวันเป็นศูนย์ พจน์ไขว้หายหมด variance จึงโตตาม $T$ และ SD โตตาม $\sqrt T$ นี่คือที่มาของการหารด้วย $\sqrt{252}$ ไม่ใช่หารด้วย 252

quantile ในบรรทัดถัดมาใช้สมมติฐานอีกชั้น คือผลตอบแทนรายวันเป็น Normal ด้วย จึงได้ VaR 99% รายวันราว 1.38% ของพอร์ต หรือ \$1.38 ล้าน (บรรทัดสุดท้ายคิดเป็นหน่วย \$ ล้าน) ถ้าผลตอบแทนวันนี้สัมพันธ์กับเมื่อวาน พจน์ไขว้ข้ามวันจะกลับมา และการหารด้วย $\sqrt{252}$ จะผิด

ยังมีอีกเงื่อนไขที่ซ่อนอยู่ในทุกขั้นของหน้านี้ คือน้ำหนัก $w$ วัดตอนต้นช่วง สูตร $w^{\mathsf T}R$ ถูกพอดี ถ้าซื้อจำนวนหน่วยคงที่ตอนต้นช่วงแล้วถือจนจบ โดยไม่มีเงินเข้าออก ตัวอย่าง ลง \$60 ใน SPX และ \$40 ใน QQQ (รวม \$100) แล้ว SPX ขึ้น 10% และ QQQ ลง 5%

\[ \begin{aligned} 60(1.10)+40(0.95)&=66+38=104,\\ \frac{104-100}{100}&=4\%,\\ 0.6(10\%)+0.4(-5\%)&=4\%. \end{aligned} \]

สองวิธีได้ 4% เท่ากัน แต่ถ้าซื้อขายปรับน้ำหนักกลับ (rebalance) ระหว่างช่วง หรือพอร์ตมี option (สัญญาที่ให้สิทธิ์ซื้อหรือขายในราคาที่ตกลงไว้ ซึ่ง payoff ไม่เป็นเส้นตรงกับราคา) ผลปลายทางจะไม่ใช่ linear combination ของผลตอบแทนอีกต่อไป Gaussian closure จึงใช้ไม่ได้ ต้องใช้การจำลองแบบในการจำลอง MVN ด้วย Cholesky

Gaussian เป็นสมมติฐาน ไม่ใช่ผลที่ตรวจได้จากค่าเฉลี่ยกับ covariance

marginal เป็น Normal ทุกตัวยังไม่พอ ความผิดพลาดคือ ตรวจแล้วว่าสินทรัพย์แต่ละตัวมีผลตอบแทนเป็น Normal (marginal คือ distribution ของตัวแปรทีละตัว) และ covariance เป็นศูนย์ แล้วสรุปว่าพอร์ตต้องเป็น Normal ตัวอย่างที่สร้างขึ้นให้เห็นว่าผิด

  • ผลตอบแทนตัวแรก $X\sim\mathcal N(0,1)$
  • $W$ เป็น $+1$ หรือ $-1$ อย่างละครึ่ง โดยอิสระจาก $X$ (เหมือนโยนเหรียญ)
  • ผลตอบแทนตัวที่สอง $Y=WX$

$Y$ เป็น Normal มาตรฐานเหมือน $X$ เพราะ Normal สมมาตร การกลับเครื่องหมายแบบสุ่มจึงไม่เปลี่ยน distribution และ $\operatorname{Cov}(X,Y)=\mathbb E[WX^2]=\mathbb E[W]\,\mathbb E[X^2]=0$ ทีนี้ดูพอร์ตครึ่งต่อครึ่ง $L=(X+Y)/2$

\[ \begin{aligned} L&=\tfrac12X(1+W),\\ W=-1\ \Rightarrow\ L&=0,\\ W=+1\ \Rightarrow\ L&=X,\\ \operatorname{Var}(L)&=\tfrac12(0)+\tfrac12\mathbb E[X^2]=0.5,\\ a^{\mathsf T}\Sigma a&=\tfrac14(1+1)=0.5. \end{aligned} \]

ค่าเฉลี่ยของ $L$ คือ 0 และ variance 0.5 ตรงกับสูตร แต่ $L$ ไม่ใช่ Normal เพราะครึ่งหนึ่งของเวลามันเป็นศูนย์พอดี ซึ่ง Normal ทำไม่ได้

ค่าเฉลี่ยและ covariance เท่ากันทุกตัว VaR ยังต่างได้ ความผิดพลาดคือ คิดว่าถ้าค่าเฉลี่ยกับ SD ของพอร์ตถูกแล้ว VaR ที่ได้จากสูตร Normal ก็ต้องถูก ลองใช้พอร์ต 50/30/20 เดิม แต่สมมติว่าตลาดมีสองภาวะ

  • ภาวะสงบ 75% ของเวลา ผลตอบแทนพอร์ตเป็น Normal ค่าเฉลี่ย 6.4% SD 7.312%
  • ภาวะตึงเครียด 25% ของเวลา ผลตอบแทนพอร์ตเป็น Normal ค่าเฉลี่ย 6.4% SD 14.431%

SD สองค่านี้เป็นค่าสมมติ เลือกให้ภาวะตึงเครียดแกว่งแรงเกือบสองเท่าของภาวะสงบ แล้วปรับขนาดให้ variance รวมเท่ากับของเดิมพอดี เมื่อสองภาวะมีค่าเฉลี่ยเท่ากัน variance รวมคือค่าเฉลี่ยถ่วงน้ำหนักของ variance ทั้งสอง (หน่วยเปอร์เซ็นต์ยกกำลังสอง)

\[ \begin{aligned} &0.75(7.312^2)+0.25(14.431^2)\\ &\quad\approx40.10+52.06=92.16=9.6^2. \end{aligned} \]

ค่าเฉลี่ยกับ SD ของพอร์ตจึงเท่ากับแบบ Normal เดิมทุกตัว แต่แบบสองภาวะไม่มีสูตรปิดของ quantile ต้องหาด้วยวิธีเชิงตัวเลข (โค้ด JavaScript ท้ายหน้าทำให้ดู) ส่วนแบบ Normal ที่ระดับ 95% ใช้สูตรของขั้นที่ 4 โดย $z_{0.95}\approx1.6449$ และ $\varphi(z_{0.95})\approx0.10314$ (หน่วย \$ ล้าน)

\[ \begin{aligned} \operatorname{VaR}_{0.95}&=100\,(1.6449\times0.096-0.064)\\ &\approx9.39,\\ \operatorname{ES}_{0.95}&=100\,\Big(0.096\times\frac{0.10314}{0.05}-0.064\Big)\\ &\approx13.40. \end{aligned} \]

ระบบความเสี่ยงของธนาคารมีวิธีคิด VaR แบบเร็วที่สุดชื่อ VaR แบบ parametric (หรือ delta-normal) คือคิดจากสูตร ไม่ได้จำลอง คำนวณเสร็จในเสี้ยววินาที และวิธีนี้ก็คือขั้นที่ 3 กับ 4 ของหน้านี้ ระบบเอาน้ำหนักกับ covariance คำนวณ SD ของพอร์ต $\sigma_p=\sqrt{w^{\mathsf T}\Sigma w}$ แล้วใช้ $\operatorname{VaR}=V(z_p\sigma_p-\mu_p)$

วิธีนี้เร็วและอธิบายง่าย แต่ยืนอยู่บนสองสมมติฐาน คือผลตอบแทนเป็น joint Normal และ payoff เป็นเส้นตรง Markowitz portfolio selection ซึ่งเลือกพอร์ตจากค่าเฉลี่ยกับ variance อย่างเดียว ก็ยืนอยู่บนเหตุผลเดียวกัน คือเมื่อพอร์ตเป็น Normal สองตัวเลขนี้บอกทุกอย่าง พอร์ตที่มี option หรือมีผลตอบแทนหางหนา (ขาดทุนหนัก ๆ เกิดบ่อยกว่าที่ Normal บอก) ต้องใช้การจำลองแทน

โจทย์ตรวจความเข้าใจ

1. ผู้จัดการกองทุนอยากได้ผลตอบแทนมากขึ้น จึงกู้เงินมาอีก \$100 ล้าน (เท่ากับมูลค่าพอร์ตเดิม) ดอกเบี้ยแน่นอน 2% ต่อปี แล้วลงพอร์ต 50/30/20 เดิมทั้งหมด \$200 ล้าน คิดผลตอบแทนบนเงินของกองทุนเอง \$100 ล้าน ค่าเฉลี่ย SD และ VaR 99% เป็นเท่าไร

เฉลย

กำไรของพอร์ต \$200 ล้าน คือ $200R_p$ (\$ ล้าน) หักดอกเบี้ย $100\times0.02=2$ แล้วหารด้วยเงินของกองทุนเอง 100 ได้ผลตอบแทน $(200R_p-2)/100=2R_p-0.02$ นี่คือ affine transformation ของ Normal จึงยังเป็น Normal variance คูณด้วย $2^2$ เพราะ $\operatorname{Var}(2R_p)=2^2\operatorname{Var}(R_p)$ (หน่วย \$ ล้านในบรรทัดสุดท้าย)

\[ \begin{aligned} \mu&=2(0.064)-0.02=0.108,\\ \sigma^2&=2^2(0.009216)=0.036864,\\ \sigma&=\sqrt{0.036864}=0.192,\\ \operatorname{VaR}_{0.99}&=100\,(2.3263\times0.192-0.108)\\ &\approx33.87. \end{aligned} \]

ได้ค่าเฉลี่ย 10.8% SD 19.2% และ VaR 99% ราว \$33.87 ล้าน สองเท่าของ VaR เดิมคือ $2\times15.933\approx\$31.87$ ล้าน VaR ใหม่จึงมากกว่าสองเท่าของเดิมอีก $33.87-31.87=\$2$ ล้าน ซึ่งก็คือดอกเบี้ยที่ต้องจ่ายแน่นอน ค่าคงที่ไม่เปลี่ยน SD แต่เลื่อนทั้ง distribution

2. พอร์ตสมมติมีสองสินทรัพย์ ตัวแรกแกว่งแรงและมักขยับสวนทางกับตัวที่สอง (covariance ติดลบ) ของที่รู้คือ covariance matrix $\Sigma=\begin{bmatrix}0.04&-0.015\\-0.015&0.01\end{bmatrix}$ และน้ำหนัก $w=(0.2,\ 0.8)$ ก้อน variance (risk contribution) ของสินทรัพย์แรกติดลบได้หรือไม่ ถ้าได้ แปลว่าอะไร

เฉลย

ใช้ $C_i=w_i(\Sigma w)_i$ จากขั้นที่ 5

\[ \begin{aligned} (\Sigma w)_1&=0.04(0.2)-0.015(0.8)=-0.004,\\ (\Sigma w)_2&=-0.015(0.2)+0.01(0.8)=0.005,\\ C_1&=0.2(-0.004)=-0.0008,\\ C_2&=0.8(0.005)=0.004,\\ v&=C_1+C_2=0.0032. \end{aligned} \]

สัดส่วนจึงเป็น $-0.0008/0.0032=-25\%$ และ $0.004/0.0032=125\%$ ติดลบได้ แปลว่าสินทรัพย์แรกเคลื่อนสวนทางกับพอร์ต (covariance กับพอร์ตติดลบ) การถือเพิ่มเล็กน้อยจึงลดความเสี่ยงของพอร์ต ไม่ได้แปลว่ามีโอกาสหรือ variance ติดลบ

3. พอร์ตสมมติมีสองสินทรัพย์ ผลตอบแทนคิดเป็นเปอร์เซ็นต์ variance จึงเป็นเปอร์เซ็นต์ยกกำลังสอง ของที่รู้คือ

  • สินทรัพย์ A ค่าเฉลี่ย 1% variance 0.1 เขียนว่า $\mathcal N(1,\ 0.1)$
  • สินทรัพย์ B ค่าเฉลี่ย 2% variance 0.5 เขียนว่า $\mathcal N(2,\ 0.5)$
  • correlation −0.25 และทั้งคู่เป็น joint Normal

พอร์ต A 70% B 30% มี distribution อะไร โอกาสที่พอร์ตได้ต่ำกว่า 1% เป็นเท่าไร และน้ำหนักไหนให้ variance ต่ำสุด

เฉลย

แปลง correlation เป็น covariance $c$ ก่อน แล้วใช้สูตรของขั้นที่ 1 แบบสองสินทรัพย์ ($0.49=0.7^2$, $0.09=0.3^2$, $0.21=0.7\times0.3$)

\[ \begin{aligned} c&=-0.25\sqrt{0.1\times0.5}\approx-0.0559,\\ \mu_L&=0.7(1)+0.3(2)=1.3,\\ v_L&=0.49(0.1)+0.09(0.5)\\ &\quad+2(0.21)(-0.0559)\\ &=0.049+0.045-0.02348\\ &=0.07052,\\ \sigma_L&=\sqrt{0.07052}\approx0.2656. \end{aligned} \]

พอร์ตจึงเป็น $\mathcal N(1.3,\ 0.07052)$ แปลงผลตอบแทน 1% เป็นจำนวน SD ที่ห่างจากค่าเฉลี่ย แล้วอ่าน $\Phi$ ได้ $P(L\lt1)=\Phi\big((1-1.3)/0.2656\big)=\Phi(-1.130)\approx12.9\%$

ส่วนน้ำหนักที่ให้ variance ต่ำสุด ให้ $x$ เป็นน้ำหนักใน A (B ได้ $1-x$) แล้วตั้งอนุพันธ์ของ variance เป็นศูนย์

\[ \begin{aligned} v(x)&=0.1x^2+0.5(1-x)^2\\ &\quad-0.1118\,x(1-x),\\ v'(x)&=0.2x-(1-x)-0.1118(1-2x)\\ &=1.4236x-1.1118=0,\\ x^*&=1.1118/1.4236\approx0.781. \end{aligned} \]

ที่ $x^*=0.781$ ได้ SD $\sqrt{v(0.781)}\approx0.2566$ และค่าเฉลี่ย $0.781(1)+0.219(2)\approx1.219$ SD นี้ต่ำกว่า SD ของแต่ละตัวทั้งคู่ ($\sqrt{0.1}\approx0.316$ และ $\sqrt{0.5}\approx0.707$) นี่คือผลของ correlation ติดลบ

// Portfolio moments (any distribution) and Gaussian VaR / ES (needs joint Normal).
const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);
function project(mu, S, a, shift = 0) {
  const u = S.map(row => dot(row, a)), variance = dot(a, u);
  return {mean: dot(a, mu) + shift, variance, sd: Math.sqrt(variance), u,
    shares: a.map((x, i) => x * u[i] / variance)};
}
const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
function Phi(x) { // Simpson's rule
  const n = 20000, h = Math.abs(x) / n; let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(x) * s * h / 3;
}
const z99 = 2.3263478740408408, z95 = 1.6448536269514722;
const gaussVaR = (p, V, z) => V * (z * p.sd - p.mean);
const gaussES = (p, V, z, tail) => V * (p.sd * phi(z) / tail - p.mean);

const mu = [0.09, 0.03, 0.05], w = [0.5, 0.3, 0.2], V = 1e8;
const S = [[0.0324, -0.00216, 0.00135], [-0.00216, 0.0036, 0.00225], [0.00135, 0.00225, 0.0225]];
const p = project(mu, S, w);

// Two-regime mixture with the same mean and the same variance as p
const k = Math.sqrt(0.75 * 0.76 ** 2 + 0.25 * 1.5 ** 2), a1 = 0.76 / k, a2 = 1.5 / k;
const mixCDF = z => 0.75 * Phi(z / a1) + 0.25 * Phi(z / a2);
function mixQuantile(q) { let lo = -20, hi = 20;
  for (let i = 0; i < 200; i++) { const m = (lo + hi) / 2; if (mixCDF(m) < q) lo = m; else hi = m; }
  return (lo + hi) / 2; }
function mixRisk(tail) {
  const z = mixQuantile(tail);
  const es = (0.75 * a1 * phi(z / a1) + 0.25 * a2 * phi(z / a2)) / tail; // mean of -Z below z
  return {VaR: V * (-z * p.sd - p.mean), ES: V * (es * p.sd - p.mean)};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ค่าเฉลี่ย $a^{\mathsf T}\mu$ และ variance $a^{\mathsf T}\Sigma a$ ของผลรวมถ่วงน้ำหนัก ถูกกับทุก distribution ที่ variance จำกัด ไม่ต้องอิสระ และไม่ต้องเป็น Normal
  • ถ้า $R$ เป็น MVN ผลรวมถ่วงน้ำหนักบวกค่าคงที่ทุกแบบเป็น Normal พิสูจน์ด้วย MGF ในบรรทัดเดียว และกลับทางได้ด้วย คือ MVN ก็คือ vector ที่ทุก linear combination เป็น Normal
  • เมื่อพอร์ตเป็น Normal ทั้ง VaR $=V(z_p\sigma_p-\mu_p)$ และ ES $=V\big(\sigma_p\varphi(z_p)/(1-p)-\mu_p\big)$ ขึ้นกับค่าเฉลี่ยกับ SD ของพอร์ตเท่านั้น
  • risk contribution $w_i(\Sigma w)_i$ แบ่ง variance ตามว่าสินทรัพย์ขยับไปกับทั้งพอร์ตแค่ไหน เงิน 50% อาจเป็นความเสี่ยง 86%
  • ค่าเฉลี่ยและ covariance เท่ากัน ไม่ได้แปลว่าหางเท่ากัน marginal เป็น Normal ทุกตัวก็ยังไม่พอ Gaussian closure จึงเป็นสมมติฐานที่ต้องบอกให้ชัด
