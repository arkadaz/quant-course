8.8 Linear Combinations

Mean กับ covariance บอก SD ของพอร์ตได้เสมอ แต่จะบอกโอกาสขาดทุนได้ ต้องรู้ว่าพอร์ตมี distribution แบบไหน

พอร์ตสมมติ \$100 ล้าน มี annual mean return 6.4% และ SD 9.6% คนหนึ่งใช้สองเลขนี้คำนวณ loss VaR 99% ได้ \$15.93 ล้าน อีกคนบอกว่ายังตอบไม่ได้ ทั้งคู่กำลังขัดแย้งกันเรื่องสูตร หรือกำลังใช้สมมติฐานไม่เหมือนกัน?

ลองตอบก่อนอ่านต่อ

ทั้งคู่ถูกคนละส่วน 6.4% กับ 9.6% คำนวณได้จาก mean vector กับ covariance เสมอ แต่ VaR 99% ถามว่า return ต่ำกว่าระดับไหนได้เพียง 1% ของเวลา ซึ่งสองเลขนี้ไม่ได้บอก คนแรกเพิ่มสมมติฐานว่า returns ของสินทรัพย์เป็น joint Gaussian ไว้แล้ว พอร์ตจึงเป็น Normal และได้ \$15.93 ล้าน ความขัดแย้งอยู่ที่สมมติฐาน ไม่ได้อยู่ที่สูตร

บทนี้เพิ่มอะไรจากสูตรใน 8.2

8.2 สอนว่า mean และ covariance เปลี่ยนอย่างไรเมื่อเราถ่วงน้ำหนักหรือบวกค่าคงที่ สูตรนั้นใช้ได้กับทุก distribution ที่มี variance จำกัด แต่ได้คำตอบแค่สองเลข หัวข้อนี้เพิ่มเงื่อนไขเดียวคือ joint Gaussian แล้วได้คำตอบทั้งรูปร่างของ distribution พอร์ต ซึ่งเป็นสิ่งที่ VaR ต้องใช้

ตลอดหน้า น้ำหนักเป็นค่าคงที่ที่ตัดสินใจก่อนผลตอบแทนของช่วงนั้นเกิด เราใช้สองโมเดลที่แยกกัน: พอร์ตหุ้น/bond/ทองคำรายปี และคู่ SPX/QQQ รายวัน อย่านำ covariance ของคนละช่วงเวลาหรือคนละลำดับสินทรัพย์มาปนกัน

ขั้นที่ 1 — คำนวณ moments โดยยังไม่สมมติ Normal

เริ่มจากสิ่งที่ได้มาฟรี ขอแค่ทุกสินทรัพย์มี variance จำกัด Mean ของผลรวมคือผลรวมของ means เพราะค่าคาดหวังเป็นเชิงเส้น ส่วน variance ต้องลบ mean ออกก่อน แล้วยกกำลังสองผลรวมที่เหลือ

\[ \begin{aligned} L&:=a^{\mathsf T}R,\\ \mathbb E[L]&=\sum_i a_i\mathbb E[R_i]=a^{\mathsf T}\mu,\\ L-\mathbb E[L]&=\sum_i a_i(R_i-\mu_i),\\ \operatorname{Var}(L)&=\mathbb E\Big[\Big(\sum_i a_i(R_i-\mu_i)\Big)^2\Big]\\ &=\sum_i\sum_j a_i a_j\,\mathbb E[(R_i-\mu_i)(R_j-\mu_j)]\\ &=\sum_i\sum_j a_i a_j\Sigma_{ij}\\ &=a^{\mathsf T}\Sigma a. \end{aligned} \]

จังหวะสำคัญคือการกระจายกำลังสองของผลรวม: ได้ทุกคู่ $(i,j)$ คู่ที่ $i=j$ คือ variance ของสินทรัพย์เอง คู่ที่ $i\ne j$ คือ covariance ซึ่งเป็นที่มาของพจน์ไขว้ ตลอดทางไม่มีบรรทัดไหนใช้ Normal หรือ independence สองเลขนี้จึงถูกกับทุก distribution ที่มี variance จำกัด

แต่ก็เป็นแค่สองเลข รู้ mean กับ variance แล้วยังไม่รู้ว่าหางซ้ายหนาแค่ไหน นั่นคือช่องว่างที่ขั้นถัดไปต้องเติม

ขั้นที่ 2 — ใช้ MGF เพื่อพิสูจน์ว่า distribution ยัง Gaussian

ถ้าอยากได้มากกว่าสองเลข ต้องเพิ่มสมมติฐาน: ให้ $R\sim\mathcal N_n(\mu,\Sigma)$ โดย $\Sigma$ เป็น PSD เครื่องมือที่เหมาะคือ MGF จาก 8.5 เพราะ $e^{tL}=e^{(ta)^{\mathsf T}R}$ แปลว่า MGF ของ $L$ ก็คือ MGF ของ $R$ ที่ประเมินตรงจุด $s=ta$ ไม่ต้อง integrate อะไรใหม่เลย

\[ \begin{aligned} M_L(t)&=\mathbb E[e^{t a^{\mathsf T}R}]\\ &=M_R(ta)\\ &=\exp\!\left(t a^{\mathsf T}\mu+\tfrac12 t^2a^{\mathsf T}\Sigma a\right),\\ L&\sim\mathcal N(a^{\mathsf T}\mu,a^{\mathsf T}\Sigma a). \end{aligned} \]

บรรทัดที่สามมีรูป $\exp(tm+\tfrac12t^2v)$ โดย $m=a^{\mathsf T}\mu$ และ $v=a^{\mathsf T}\Sigma a$ ซึ่งเป็น MGF ของ Normal ตัวเดียวพอดี และ MGF ที่มีค่าจำกัดรอบ $t=0$ ระบุ distribution ได้เพียงแบบเดียว $L$ จึงเป็น Normal จริง ไม่ใช่แค่มี mean กับ variance เหมือน Normal

ถ้า $a^{\mathsf T}\Sigma a=0$ สูตรเดิมยังใช้ได้ แต่ $L$ กลายเป็นค่าคงที่ ไม่มี bell curve ให้วาด เราจึงไม่ต้องขอให้ $\Sigma$ invertible ก่อน

ขยายเป็นหลาย outputs พร้อมกัน
\[ \begin{aligned} Y&:=AR+c,\\ M_Y(s)&=e^{s^{\mathsf T}c}M_R(A^{\mathsf T}s)\\ &=\exp\!\left(s^{\mathsf T}(A\mu+c)\right)\\ &\quad\times\exp\!\left(\tfrac12 s^{\mathsf T}A\Sigma A^{\mathsf T}s\right),\\ Y&\sim\mathcal N(A\mu+c,A\Sigma A^{\mathsf T}). \end{aligned} \]

ค่าคงที่ $c$ ขยับ mean แต่ไม่แตะ covariance ถ้า outputs บางตัวซ้ำกัน เช่นสองบรรทัดของ $A$ เหมือนกัน $A\Sigma A^{\mathsf T}$ จะ singular ทั้งที่คูณ matrix ถูกมิติ ผลลัพธ์ยังเป็น Gaussian แต่เป็นแบบที่ไม่มี density เต็มมิติ

ทางกลับกันก็จริง: นิยามหนึ่งของ MVN คือ “ทุก linear combination เป็น Normal” (นับค่าคงที่เป็น Normal ที่ variance ศูนย์) คำว่า ทุก สำคัญมาก การตรวจว่าแต่ละสินทรัพย์ดู Normal หรือลองพอร์ตไม่กี่แบบยังไม่พอ ตัวอย่างใน pitfall ท้ายหน้าแสดงว่าพังได้อย่างไร

โจทย์ให้อะไรมาบ้าง: สมมติ annual simple returns ของ US stocks, US bonds และ gold ใน USD เป็น joint Gaussian ใช้ weights 0.50,0.30,0.20 ตามลำดับ ตัวเลขนี้เป็น model inputs ไม่ใช่การยืนยันว่าตลาดจริงเป็น Normal

Correlations คือ stock–bond −0.20, stock–gold 0.05, bond–gold 0.25 ใช้ $\Sigma_{ij}=\rho_{ij}\sigma_i\sigma_j$ แปลงเป็น covariance ก่อน ไม่ใช่นำ correlation matrix มาคูณ weights แล้วเรียกผลว่า return variance

\[ \begin{aligned} \mu&=(0.09,0.03,0.05)^{\mathsf T},\\ \Sigma&=\begin{bmatrix} 0.0324&-0.00216&0.00135\\ -0.00216&0.0036&0.00225\\ 0.00135&0.00225&0.0225 \end{bmatrix},\\ w&=(0.5,0.3,0.2)^{\mathsf T},\\ \mu_p&=0.5(0.09)+0.3(0.03)+0.2(0.05)\\ &=0.064,\\ u&:=\Sigma w=(0.015822,0.000450,0.005850)^{\mathsf T},\\ v_p&=0.5(0.015822)+0.3(0.000450)\\ &\quad+0.2(0.005850)\\ &=0.009216,\\ \sigma_p&=\sqrt{0.009216}=0.096,\\ R_p&\sim\mathcal N(0.064,0.009216). \end{aligned} \]

คำตอบ: mean 6.4%, SD 9.6% ต่อช่วงหนึ่งปี ภายใต้ joint Gaussian assumption จึงระบุ law บรรทัดสุดท้ายได้ ถ้าเอาสมมติฐานนี้ออก สอง moments ยังถูกแต่ไม่รู้ทั้ง distribution

ตรวจเองใน 10 วินาที: diagonal terms รวม 0.009324, cross terms รวม −0.000108 จึงได้ 0.009216 หากละ covariance จะได้ SD ประมาณ 9.6561% ในชุดนี้ผลสุทธิของ cross terms เล็ก แต่ไม่ได้แปลว่า covariance ไม่มีความสำคัญในทุกพอร์ต

ขั้นที่ 4 — เงินครึ่งพอร์ตไม่ได้แปลว่ารับความเสี่ยงครึ่งหนึ่ง

แบ่ง variance เป็น $C_i=w_i(\Sigma w)_i$ แล้วรวมกลับได้ variance ทั้งหมด นี่เป็น accounting identity ของ quadratic form ไม่ใช่ probability decomposition

\[ \begin{aligned} C_1&=0.5(0.015822)=0.007911,\\ C_2&=0.3(0.000450)=0.000135,\\ C_3&=0.2(0.005850)=0.001170,\\ \sum_i C_i&=0.009216,\\ (C_1,C_2,C_3)/v_p &\approx(85.8398\%,1.4648\%,12.6953\%). \end{aligned} \]

ทำไมหุ้นใช้เงิน 50% แต่กิน variance ถึง 85.84%? เพราะ contribution ไม่ได้คูณน้ำหนักกับ variance ของตัวเองอย่างเดียว มันคูณกับ $(\Sigma w)_i$ ซึ่งวัดว่าสินทรัพย์นั้นเคลื่อนไปกับทั้งพอร์ตแค่ไหน หุ้นมี SD 18% และเป็นก้อนใหญ่ที่สุดของพอร์ตเอง จึงเคลื่อนไปกับพอร์ตมากที่สุด

อย่าอ่าน 85.84% เป็นโอกาสที่หุ้นจะทำให้ขาดทุน มันเป็นการแบ่งบัญชีของ variance เท่านั้น และในพอร์ตที่มี hedge บาง contribution ติดลบได้ (โจทย์ข้อ 2 ท้ายหน้า)

เชื่อม contribution กับอนุพันธ์ของความเสี่ยง

ให้ $e_i$ เป็น unit vector ที่มี 1 อยู่ช่อง $i$ การเพิ่มน้ำหนักตัวเดียวโดยตรึงตัวอื่นไว้ ต่างจากการย้ายเงินจากตัวหนึ่งไปอีกตัว เพราะแบบแรกทำให้ขนาดพอร์ตเปลี่ยนด้วย

\[ \begin{aligned} v(w+h e_i)&=v(w)+2h(\Sigma w)_i+h^2\Sigma_{ii},\\ \frac{\partial v}{\partial w_i}&=2(\Sigma w)_i,\\ \frac{\partial\sigma}{\partial w_i}&=\frac{(\Sigma w)_i}{\sigma}\quad(\sigma\gt0),\\ \sum_i w_i\frac{\partial\sigma}{\partial w_i}&=\frac{v}{\sigma}=\sigma. \end{aligned} \]

บรรทัดที่สองบอกว่า $u=\Sigma w$ เป็นอนุพันธ์ของ variance (หารสอง) ถ้าอยากได้อนุพันธ์ของ SD ต้องหารด้วย $\sigma$ อีกที ส่วนบรรทัดสุดท้ายคือเหตุผลที่ contributions รวมกันได้ SD ทั้งพอร์ตพอดี

ลองใช้: ย้ายน้ำหนัก 0.01 จากหุ้นไป bond อัตราเปลี่ยนของ SD คือ $(u_2-u_1)/\sigma=(0.000450-0.015822)/0.096=-0.160125$ จึงประมาณ SD ใหม่ได้ $9.6\%-0.01(16.0125\%)=9.439875\%$ เทียบกับคำนวณตรงที่น้ำหนัก $(0.49, 0.31, 0.20)$ ได้ 9.440653% ใกล้กันเพราะขยับน้อย

ถ้าอยากให้ทุกสินทรัพย์รับความเสี่ยงเท่ากัน ต้องเปลี่ยนน้ำหนักตามโจทย์ risk budgeting ใน 7.3 และ mean จะเปลี่ยนตามไปด้วย ในโมเดลนี้ risk-parity weights ประมาณ $(0.2115, 0.5869, 0.2016)$ ให้ mean 4.6720% และ SD 6.0950% คือลด SD ได้จริง แต่ต้องยอมเสีย mean จาก 6.4% ไม่ได้ของฟรี

ขั้นที่ 5 — ตอบ opening question ด้วย loss quantile

โจทย์ให้อะไรมาบ้าง: V=\$100 ล้าน, annual $R_p\sim\mathcal N(0.064,0.009216)$ และ $z_{0.99}\approx2.326347874$ ใช้ quantile 1% ของ return แล้วเปลี่ยนเครื่องหมายเป็น quantile 99% ของ loss

\[ \begin{aligned} q_{0.01}&=\mu_p-z_{0.99}\sigma_p\\ &=0.064-(2.326347874)(0.096)\\ &\approx-0.159329396,\\ \operatorname{VaR}_{0.99}&=-Vq_{0.01}\\ &\approx15{,}932{,}940\ \mathrm{USD}. \end{aligned} \]

คำตอบ: loss VaR ราว \$15.93 ล้าน ของ horizon หนึ่งปีตามโมเดล ไม่ใช่ขาดทุนสูงสุด และไม่ใช่คำรับรองว่าทุก 100 ปีจะเจอหนึ่งปีที่ขาดทุนเท่านี้พอดี หาก parameters เป็นเพียง estimates, tail calibration ก็มี uncertainty เพิ่ม

ตรวจเองใน 10 วินาที: ลงหุ้นล้วนตามโมเดล mean 9%, SD 18% ได้ loss VaR ราว \$32.8743 ล้าน คือ $\$100\text{M}\times(2.326347874\times0.18-0.09)$ เกือบสองเท่าของพอร์ตผสม แม้ mean ของหุ้นล้วนจะสูงกว่า (9% เทียบ 6.4%) เพราะ SD 18% เทียบ 9.6% กินผลของ mean ที่ต่างกันจนหมด

ขั้นที่ 6 — อีก horizon: daily 60/40 SPX/QQQ

โจทย์ให้อะไรมาบ้าง: เปลี่ยนไปใช้ daily Gaussian model ที่ Figure 8.8a–d วาด: SPX มี mean 0.0004 และ variance 0.0004 (SD 2%) QQQ มี mean 0.0003 และ variance 0.0009 (SD 3%) covariance 0.00024 น้ำหนัก 0.6 กับ 0.4 ระวังชื่อ “60/40” ตรงนี้เป็นหุ้นสองกองทุน ไม่ใช่พอร์ตหุ้น/bond 60/40 ที่คนมักหมายถึง

\[ \begin{aligned} \mu_L&=0.6(0.0004)+0.4(0.0003)=0.00036,\\ v_L&=0.6^2(0.0004)+0.4^2(0.0009)\\ &\quad+2(0.6)(0.4)(0.00024)\\ &=0.0004032,\\ \sigma_L&=\sqrt{0.0004032}\approx0.02007984,\\ L&\sim\mathcal N(0.00036,0.0004032). \end{aligned} \]

คำตอบ: daily mean 0.036% และ SD ประมาณ 2.008% วางสามตัวเลขเรียงกันจะเห็นว่า covariance ทำอะไร: ถ้าสองตัวไม่ขยับร่วมกันเลยจะได้ $\sqrt{0.000288}\approx1.697\%$ ถ้าขยับตามกันเป๊ะจะได้ค่าเฉลี่ยถ่วงน้ำหนัก $0.6(2\%)+0.4(3\%)=2.4\%$ ของจริงอยู่ระหว่างกลาง เพราะ correlation $0.00024/(0.02\times0.03)=0.4$ ไม่ใช่ 0 และไม่ใช่ 1

ตรวจเองใน 10 วินาที: spread $X-Y$ ใช้ coefficients $(1, -1)$ ได้ mean 0.0001 และ variance $0.0004+0.0009-2(0.00024)=0.00082$ ครั้งนี้ covariance ถูกลบออก เพราะ $2a_1a_2$ ติดลบ spread ก็ยังเป็น Normal แม้สองตัวไม่ independent

ขั้นที่ 7 — น้ำหนักคงที่ หมายถึงน้ำหนักตอนเริ่ม ไม่ใช่ rebalance ทุกวัน

คำถามที่คนมักถาม: ถ้าราคาขยับ น้ำหนักจริงในพอร์ตก็ drift ไปแล้ว สูตร $w^{\mathsf T}R$ ยังใช้ได้หรือ? ใช้ได้ ถ้าซื้อจำนวนหุ้นคงที่แล้วถือจนจบช่วงโดยไม่มีเงินเข้าออก เช่น ลง \$60 ใน SPX กับ \$40 ใน QQQ ถ้า SPX ขึ้น 10% และ QQQ ลง 5% มูลค่าปลายทางคือ $60(1.10)+40(0.95)=104$ ผลตอบแทน 4% เท่ากับ $0.6(10\%)+0.4(-5\%)$ พอดี ค่าที่ใช้คือน้ำหนักตอนเริ่ม ไม่ใช่น้ำหนักระหว่างทาง

ถ้า rebalance ระหว่างช่วง ผลปลายทางจะขึ้นกับเส้นทางราคาทั้งเส้น ไม่ใช่ผลรวมถ่วงน้ำหนักของผลตอบแทนทั้งช่วงอีกต่อไป Options ก็เช่นกัน payoff ไม่เป็นเส้นตรง วิธี delta-normal จึงเป็นแค่การประมาณ ไม่ใช่ Gaussian closure ของ option จริง

อีกกรณีคือเลือกน้ำหนักตามสภาพตลาดก่อนเทรด ภายใต้ข้อมูลนั้นพอร์ตอาจเป็น Normal แต่ถ้าน้ำหนัก means หรือ covariance เปลี่ยนตาม state distribution ที่เฉลี่ยทุก state จะเป็น mixture ซึ่งหางหนากว่า Normal ได้ แม้แต่ละ state จะเป็น Normal ก็ตาม

ขั้นที่ 8 — เปลี่ยน horizon ต้องเพิ่มโมเดลตามเวลา

ถ้าหัวหน้าขอ VaR รายวันของพอร์ต 50/30/20 เรามีแต่โมเดลรายปี จะแปลงอย่างไร? ต้องสมมติเพิ่มว่าผลรายปีเป็นผลรวมของผลรายวัน $T=252$ วันซื้อขาย (1.1 อธิบายที่มาของ 252) แต่ละวันมี mean และ variance เท่ากัน และวันต่าง ๆ ไม่มี covariance ต่อกัน สมมติฐานนี้ไม่ได้มาจากโมเดลรายปี เราเติมเข้าไปเอง

\[ \begin{aligned} S_T&:=\sum_{t=1}^T R_t,\\ \mathbb E[S_T]&=T\mu_d,\\ \operatorname{Var}(S_T)&=T\sigma_d^2,\\ \mu_d&=0.064/252\approx0.000253968,\\ \sigma_d&=0.096/\sqrt{252}\approx0.006047432,\\ q_{0.01,d}&=\mu_d-z_{0.99}\sigma_d\\ &\approx-0.01381446. \end{aligned} \]

บรรทัด variance คือสูตรขั้นที่ 1 อีกครั้ง โดยมองแต่ละวันเป็น “สินทรัพย์” หนึ่งตัวที่น้ำหนัก 1 เมื่อ covariance ข้ามวันเป็นศูนย์ พจน์ไขว้หายหมด variance จึงโตตาม $T$ และ SD โตตาม $\sqrt T$ นี่คือที่มาของการหารด้วย $\sqrt{252}$

บรรทัด quantile ใช้สมมติฐานอีกชั้น คือผลรายวันเป็น Normal ด้วย จึงได้ประมาณ −1.38145% ต่อวัน ระวังว่าผลตอบแทน simple จริงทบต้นเป็น $\prod_t(1+R_t)-1$ ไม่ใช่ผลรวม สูตรนี้จึงเป็นการประมาณที่ใช้ได้ดีเมื่อผลรายวันเล็ก

ถ้าผลตอบแทนวันนี้สัมพันธ์กับเมื่อวาน (autocovariance ไม่เป็นศูนย์) พจน์ไขว้ข้ามวันจะกลับมา และการหารด้วย $\sqrt{252}$ จะผิด ต้องตรวจช่วงเวลา การทบต้น และความสัมพันธ์ข้ามวันก่อนใช้

Gaussian เป็น model statement ไม่ใช่ผลตรวจจาก mean กับ covariance

ให้ $X\sim N(0,1)$ และ W เป็น independent fair sign แล้วกำหนด Y=WX Marginals X, Y เป็น standard Normal, covariance ศูนย์ แต่ $L=(X+Y)/2$ เท่ากับศูนย์ครึ่งหนึ่งของเวลา และเท่ากับ X อีกครึ่งหนึ่ง จึงมี atom ที่ศูนย์ ไม่ใช่ $N(0,1/2)$ แม้ mean 0 กับ variance 1/2 จะตรงกัน

ในตัวอย่างนี้ $P(L\lt-2)=\tfrac12\Phi(-2)\approx1.1375\%$ แต่การใส่ Normal law จาก moments อย่างเดียวให้ประมาณ 0.2339% นี่เป็น counterexample ไม่ใช่ theorem ว่า Normal จะประเมิน tail ต่ำเกินไปในทุกกรณี

Non-Gaussian models อาจมี analytic distributions, convolution หรือวิธี numerical อื่นได้ ไม่จำเป็นต้อง Monte Carlo เสมอ แต่สำหรับ payoff ไม่เชิงเส้นหรือ distribution ซับซ้อน ต้องประเมินวิธีให้ตรงโมเดลแทนยืม quantile Normal โดยไม่มีเหตุผล

สามโจทย์ตรวจหน่วยและขอบเขตของ theorem

1. เพิ่ม annual risky weights ทั้งสามเป็นสองเท่า โดยยืมเงินเท่ากับ NAV เดิมที่ต้นทุนแน่นอน 2% ของช่วงนั้น Mean, variance และ loss VaR บน NAV \$100 ล้าน เป็นเท่าไร?

เฉลย

Payoff $2R_p-0.02$ ยัง Gaussian เพราะเป็น affine map Mean $2(0.064)-0.02=0.108$, variance $4(0.009216)=0.036864$, SD 19.2%, loss VaR ประมาณ \$33.8659 ล้าน ซึ่งมากกว่าสองเท่าของเดิมอีก \$2 ล้าน จาก cost ไม่ใช่รับ mean 12.8% โดยลืม borrowing

2. ถ้า covariance เป็น $\begin{bmatrix}0.04&-0.015\\-0.015&0.01\end{bmatrix}$ และ weights (0.2,0.8) variance contributions จะติดลบได้หรือไม่?

เฉลย

Sigma w=(−0.004,0.005), contributions=(−0.0008,0.004), รวมเป็น variance 0.0032 สัดส่วนจึงเป็น −25% และ 125% ตัวแรกลดความเสี่ยงผ่าน covariance ของพอร์ต ไม่ใช่มี negative probability

3. Joint Gaussian ที่มี $R=(Z,Z)$ และ $Z\sim N(0,1)$ ถ้าเลือก spread (1, −1) ต้องใช้ Normal density ที่ variance เท่าไร?

เฉลย

Spread เป็นศูนย์แน่นอน มี variance 0 จึงไม่มี ordinary Normal density ที่หารด้วย SD ได้ ใช้ point mass ที่ศูนย์ นี่เป็น degenerate Gaussian ที่ theorem อนุญาต ไม่ใช่ error ว่า closure ใช้กับ singular covariance ไม่ได้

คำนวณ moments และ Gaussian quantiles คนละขั้น

JavaScript นี้ตรวจ dimensions, symmetry และ variance ของ directions ที่ขอ แต่ไม่แทนการตรวจ PSD ทุกทิศหรือทดสอบ Gaussianity ของข้อมูล ต้องรับ covariance model ที่ผ่านการตรวจแล้วตาม 7.6 สูตร risk shares ใช้เมื่อ variance บวก; กรณี point mass คืน shares เป็น null แทนหารด้วยศูนย์

function finiteVector(v, n) {
  if (!Array.isArray(v) || v.length !== n || ![...v].every(Number.isFinite)) throw new TypeError('Need a matching finite vector');
}
function finite(x) {
  if (!Number.isFinite(x)) throw new RangeError('Arithmetic overflow');
  return x;
}
function dot(a, b) {
  if (!Array.isArray(a) || a.length === 0) throw new TypeError('Need a nonempty vector');
  finiteVector(a, a.length); finiteVector(b, a.length);
  return finite(a.reduce((s, x, i) => s + x * b[i], 0));
}
function project(mu, S, a, shift = 0) {
  if (!Array.isArray(mu) || mu.length === 0 || !Number.isFinite(shift)) throw new TypeError('Invalid projection inputs');
  const n = mu.length; finiteVector(mu, n); finiteVector(a, n);
  if (!Array.isArray(S) || S.length !== n) throw new TypeError('Need a square covariance');
  for (const row of [...S]) finiteVector(row, n);
  for (let i = 0; i < n; i++) for (let j = 0; j < n; j++) {
    if (S[i][j] !== S[j][i]) throw new RangeError('Covariance must be symmetric');
  }
  const u = S.map(row => dot(row, a)), mean = finite(dot(a, mu) + shift);
  const variance = dot(a, u);
  if (variance < 0) throw new RangeError('Negative projected variance');
  const sd = Math.sqrt(variance), contributions = a.map((x, i) => finite(x * u[i]));
  return {mean, variance, sd, u, contributions,
    shares: variance === 0 ? null : contributions.map(x => x / variance),
    marginalSD: sd === 0 ? null : u.map(x => x / sd)};
}
function normalLogMGF(t, mean, variance) {
  if (![t, mean, variance].every(Number.isFinite) || variance < 0) throw new RangeError('Invalid Gaussian MGF arguments');
  return finite(t * mean + .5 * t * (t * variance)); // t*(t*v): t*t alone can underflow or overflow first
}
function gaussianRisk(p, V) {
  if (!Number.isFinite(V) || V < 0) throw new RangeError('Invalid NAV');
  if (!p || ![p.mean, p.sd].every(Number.isFinite) || p.sd < 0) throw new RangeError('Invalid portfolio moments');
  const returnQuantile = finite(p.mean - 2.3263478740408408 * p.sd);
  return {returnQuantile, lossVaR99: finite(-V * returnQuantile)};
}
function Phi(x) {
  if (!Number.isFinite(x) || Math.abs(x) > 6) throw new RangeError('CDF demo requires finite scores within 6');
  const n = 12000, h = Math.abs(x) / n;
  const phi = z => Math.exp(-.5 * z * z) / Math.sqrt(2 * Math.PI);
  let sum = 0, correction = 0;
  for (let i = 0; i <= n; i++) {
    const term = (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h) - correction;
    const next = sum + term; correction = (next - sum) - term; sum = next;
  }
  return .5 + Math.sign(x) * sum * h / 3;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • Finite moments ให้ $\mathbb E[a^{\mathsf T}R]=a^{\mathsf T}\mu$ และ variance $a^{\mathsf T}\Sigma a$ โดยไม่ต้อง independent หรือ Normal
  • Joint Gaussianity เพิ่มคำตอบว่า affine combinations ยัง Gaussian รวม degenerate cases; Normal marginals อย่างเดียวไม่พอ
  • Portfolio SD ไม่ใช่ weighted average ของ SDs และ risk contribution ไม่ใช่ loss probability
  • Loss quantile ต้องประกาศ distribution, horizon, หน่วย และฐานเงิน; model VaR ไม่ใช่ maximum loss หรือ guarantee
  • Weights เริ่มต้นของ buy-and-hold ใช้ได้แม้ระหว่างทาง drift แต่ rebalancing, nonlinear payoffs และเปลี่ยน horizon ต้องเพิ่มสมมติฐาน
