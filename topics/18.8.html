18.8 Order Book Depth, Queue Position, Maker-Taker

วางคำสั่งซื้อรอไว้ (limit order) ถูกกว่าซื้อทันที แต่ต้องต่อคิวและอาจไม่ได้ของ ถ้าไม่ได้ ต้องกลับไปไล่ซื้อที่ราคาหนีขึ้นไปแล้ว การรอจึงคุ้มเฉพาะเมื่อคิวข้างหน้าสั้นพอที่เราจะได้ของส่วนใหญ่

โต๊ะเทรด (ทีมที่ส่งคำสั่งซื้อขายให้กองทุน) ได้รับงานให้ซื้อหุ้นตัวหนึ่ง 10,000 หุ้น ในตลาดหุ้น ราคาที่ซื้อได้ทันทีแพงกว่าราคาที่ขายได้ทันทีเสมอ คนซื้อจึงมีสองทาง ทางแรกคือ “เคาะ” ซื้อทันทีจากคนที่ตั้งขายรอไว้ ทางที่สองคือวางคำสั่งซื้อที่ราคาถูกกว่าแล้วต่อคิวรอ จนกว่าจะมีคนขายเข้ามาเอง ทางที่สองถูกกว่าถ้าได้ของ แต่ก็อาจไม่ได้ คำถามของหน้านี้คือ เมื่อไรการรอคุ้ม

ของที่เห็นบนจอตอนนี้ (ตัวเลขสมมติ):

  • ราคาสูงสุดที่มีคนรอซื้อ เรียกว่า bid คือ \$100.00 ราคาต่ำสุดที่มีคนรอขาย เรียกว่า ask คือ \$100.02 ช่องว่างระหว่างสองราคานี้เรียกว่า spread: $s=100.02-100.00=\$0.02$ หรือ 2 เซนต์ต่อหุ้น
  • ราคากลาง (mid) อยู่ตรงกลาง spread: $(100.00+100.02)/2=\$100.01$ หน้านี้วัดต้นทุนทุกอย่างเทียบกับราคากลาง
  • ที่ราคา bid \$100.00 มีคำสั่งซื้อของคนอื่นรออยู่ก่อนเราแล้ว $q_0=40{,}000$ หุ้น ถ้าเราวางรอ เราต้องต่อท้ายคิวนี้
  • ตลาดเก็บค่าธรรมเนียมจากคนที่เคาะ $f_t=0.3$ เซนต์ต่อหุ้น และจ่ายเงินคืนที่เรียกว่า rebate ให้คนที่วางรอแล้วได้ของ $r_m=0.2$ เซนต์ต่อหุ้น
  • ถ้ารอแล้วไม่ได้ของ ราคามักหนีขึ้นไปแล้ว เราต้องกลับมาเคาะที่ราคาแพงขึ้นอีก $D=5$ เซนต์ต่อหุ้น
  • แรงขาย คือจำนวนหุ้นที่คนขายส่งเข้ามาขายที่ราคา bid ระหว่างที่เรารอ ตัวเลขนี้เดาล่วงหน้าไม่ได้ รู้แค่ค่าเฉลี่ย $\mu=50{,}000$ หุ้น

ซื้อที่ ask แพงกว่าราคากลาง $100.02-100.01=\$0.01$ หรือ 1 เซนต์ ซึ่งก็คือครึ่ง spread ส่วนซื้อที่ bid ถูกกว่าราคากลาง 1 เซนต์เท่ากัน ให้ $C_T$ คือต้นทุนต่อหุ้นของการเคาะ และ $C_{M|F}$ คือต้นทุนต่อหุ้นของการรอแล้วได้ของ ทั้งคู่วัดเป็นเซนต์เทียบราคากลาง ค่าติดลบแปลว่าได้ของถูกกว่าราคากลาง

\[ \begin{aligned} C_T&=1+0.3=1.3,\\ C_{M|F}&=-1-0.2=-1.2,\\ C_T-C_{M|F}&=1.3-(-1.2)=2.5. \end{aligned} \]

เพื่อนร่วมโต๊ะเห็นส่วนต่าง 2.5 เซนต์ต่อหุ้นนี้ จึงบอกว่า “รอสิ ได้ส่วนต่างตั้ง 2.5 เซนต์” ควรรอหรือเคาะ

ลองตอบก่อนเปิดเฉลย

ควรเคาะ ส่วนต่าง 2.5 เซนต์ได้เฉพาะหุ้นที่ได้ของ ต่อท้ายคิว 40,000 หุ้น เราได้ของเฉลี่ยแค่ 40.7% ของคำสั่ง (หน้านี้จะคำนวณตัวเลขนี้ให้ดูทีละขั้น) อีก $100\%-40.7\%=59.3\%$ ต้องกลับไปเคาะที่ราคาแพงขึ้น จึงเสีย $1.3+5=6.3$ เซนต์ต่อหุ้น ต้นทุนเฉลี่ยของการรอ (เซนต์ต่อหุ้น) จึงเป็น

\[ \begin{aligned} &0.407\times(-1.2)+0.593\times6.3\\ &=-0.49+3.73=3.25 \end{aligned} \]

ซึ่งแพงกว่าเคาะทันทีที่เสีย 1.3 เซนต์ การรอจะคุ้มก็ต่อเมื่อได้ของอย่างน้อยสองในสามของคำสั่ง และต้องมีคิวข้างหน้าไม่เกินราว 15,400 หุ้น หน้านี้จะพิสูจน์ทั้งสองตัวเลขนี้ในขั้นท้าย ๆ

ภาพรวมก่อนลงสูตร

ตลาดหุ้นจับคู่คนซื้อกับคนขายผ่านสมุดคำสั่งที่เรียกว่า limit order book มันคือรายการคำสั่งซื้อ (ฝั่ง bid) และคำสั่งขาย (ฝั่ง ask) ที่วางรอไว้ แต่ละคำสั่งบอกว่า “ซื้อ (หรือขาย) กี่หุ้น ที่ราคาเท่าไร” ระบบเรียงคำสั่งตามราคาก่อน ราคาที่ดีกว่าได้ก่อน ถ้าราคาเท่ากัน ใครมาก่อนได้ก่อน เหมือนคิวหน้าร้าน

คนในตลาดจึงมีสองบทบาท คนที่วางคำสั่งรอเรียกว่า maker เพราะเขาสร้างของไว้ให้คนอื่นซื้อขาย คนที่เข้ามาชนคำสั่งที่รออยู่เพื่อได้ของทันทีเรียกว่า taker หน้า market microstructure มองจากฝั่ง taker ซึ่งได้ของทันที แต่ซื้อแพงและขายถูก หน้านี้มองจากฝั่ง maker ซึ่งได้ราคาดีกว่าและได้ rebate แต่ไม่รู้ว่าจะได้ของเมื่อไร หรือจะได้หรือไม่

การวางรอมีต้นทุนสองก้อนที่ไม่เห็นบนจอ:

  • ต้นทุนของโอกาส: ถ้าราคาวิ่งหนีขึ้นไปก่อนเราได้ของ เราต้องกลับมาไล่ซื้อที่ราคาแพงกว่า
  • adverse selection (การถูกคนที่รู้มากกว่าเลือกเทรดกับเรา): คนที่ยอมขายให้เราทันทีบางคนรู้ว่าราคากำลังจะลง เราจึงมักได้ของตอนที่ราคากำลังจะวิ่งสวนทางเรา

สิ่งที่ตัดสินว่าควรรอหรือเคาะมีสามอย่าง คือเรารีบแค่ไหน ความผันผวนของราคาสูงแค่ไหน และตลาดให้ส่วนลดกับคนวางรอเท่าไร หน้านี้แปลงทั้งสามอย่างเป็นตัวเลข

หน้านี้เดินตามลำดับนี้:

  1. กติกาคิว: ถ้ารู้แรงขาย เราได้กี่หุ้น
  2. แรงขายที่สุ่ม: โอกาสได้ของ และสัดส่วนที่ได้โดยเฉลี่ย
  3. บัญชีต้นทุนต่อหุ้นของ maker กับ taker
  4. ราคาวิ่งสวนได้มากที่สุดเท่าไรก่อนการรอจะแพ้
  5. จุดตัดสองในสาม: ต้องได้ของอย่างน้อยเท่าไร
  6. ตอบโจทย์เปิดหน้า
  7. คิวที่ลึกที่สุดที่ยังรอได้

รูปด้านล่างคือ order book ของโจทย์เปิดหน้า

ศัพท์ที่ใช้ในหัวข้อนี้
Bid, ask, spread และราคากลาง (mid)
bid คือราคาสูงสุดที่มีคนรอซื้อ ask คือราคาต่ำสุดที่มีคนรอขาย spread คือ ask ลบ bid ราคากลางคือค่าเฉลี่ยของ bid กับ ask คนที่ซื้อทันทีจ่าย ask จึงแพงกว่าราคากลางครึ่ง spread
Limit order book และ price-time priority
limit order คือคำสั่งที่บอกราคาไว้ เช่น “ซื้อ 10,000 หุ้นที่ \$100.00 ไม่แพงกว่านี้” ถ้ายังไม่มีคนขายที่ราคานั้น คำสั่งจะรออยู่ใน limit order book กติกาจับคู่เรียกว่า price-time priority: ราคาที่ดีกว่าได้ก่อน ถ้าราคาเท่ากัน คำสั่งที่มาก่อนได้ก่อน ตำแหน่งในคิวจึงมีค่า
Maker, taker และ rebate
maker คือคนที่วางคำสั่งรอ ทำให้ตลาดมีของให้ซื้อขาย taker คือคนที่เข้ามาชนคำสั่งที่รออยู่เพื่อได้ของทันที ในหน้านี้เรียกการทำแบบนี้ว่า “เคาะ” ตลาดหลายแห่งเก็บค่าธรรมเนียมจาก taker แล้วจ่ายเงินคืนส่วนหนึ่งให้ maker เงินคืนนี้เรียกว่า rebate ใช้ดึงคนมาวางคำสั่งรอ
แรงขาย
จำนวนหุ้นที่คนขายส่งเข้ามาขายที่ราคา bid ในช่วงที่เรารอ แรงขายกินคิวจากหัวคิวไปท้ายคิว
Fill probability และ fill fraction
fill probability คือโอกาสที่คำสั่งที่วางรอจะได้จับคู่บ้างภายในเวลาที่กำหนด fill fraction คือสัดส่วนของคำสั่งที่ได้โดยเฉลี่ย คำสั่งอาจได้แค่บางส่วน การตัดสินใจจึงต้องใช้ตัวหลัง
Markout และ adverse selection
markout คือระยะที่ราคาเคลื่อนไปหลังเราได้ของ วัดที่เวลาสั้น ๆ เช่น 1 วินาทีหรือ 1 นาที ถ้าคำสั่งรอของเรามักได้ของตอนที่ราคากำลังวิ่งสวน markout จะเป็นต้นทุน ปรากฏการณ์นี้เรียกว่า adverse selection ของ maker: คนที่รู้มากกว่าเลือกเทรดกับเราตอนที่มันดีกับเขา
Realized spread
ครึ่ง spread ที่คนวางรอได้จริงหลังหัก markout มักน้อยกว่าครึ่ง spread ที่เห็นบนจอ และเป็นรายได้จริงของผู้ดูแลสภาพคล่อง (market maker คือคนที่วางทั้งคำสั่งซื้อและขายรอไว้ตลอดเวลา)
Lit pool และ dark pool
lit คือตลาดที่แสดงคำสั่งให้ทุกคนเห็นก่อนซื้อขาย dark คือที่ซื้อขายก้อนใหญ่ได้โดยไม่เปิดขนาดหรือตัวตนจนกว่าจะซื้อขายเสร็จ ช่วยลด impact (ราคาขยับเพราะคำสั่งของเราเอง) แต่ไม่รู้ว่าจะได้ของเท่าไร
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$q_0,\ Q$หุ้นที่รออยู่หน้าเรา และขนาดคำสั่งของเราหุ้น
$M,\ \mu$แรงขายที่เข้ามาชน bid ระหว่างที่รอ และค่าเฉลี่ยของมันหุ้น
$R$แรงขายที่เหลือหลังกินคิวหน้าเราหมดหุ้น
$F$จำนวนหุ้นที่เราได้หุ้น
$s,\ f_t,\ r_m$spread, ค่าธรรมเนียมที่ taker จ่าย และ rebate ที่ maker ได้ดอลลาร์ต่อหุ้น
$D$ราคาที่หนีขึ้นไปแล้ว เมื่อต้องกลับไปไล่ซื้อส่วนที่ไม่ได้ดอลลาร์ต่อหุ้น

$C_{\rm rest}$ต้นทุนเฉลี่ยของการวางรอ รวมส่วนที่พลาดแล้วต้องไล่ซื้อดอลลาร์ต่อหุ้น

ขั้นที่ 1 — กติกาคิว: ได้ของเมื่อแรงขายกินคิวหน้าหมดแล้ว

ก่อนจะคิดเรื่องโอกาส ต้องตอบคำถามที่ง่ายกว่าก่อน: ถ้ารู้แน่ว่าแรงขายมา $M$ หุ้น เราจะได้กี่หุ้น ให้ $q_0=40{,}000$ คือหุ้นที่รอหน้าเรา $Q=10{,}000$ คือขนาดคำสั่งของเรา และ $F$ คือจำนวนหุ้นที่เราได้ หุ้นที่คนขายส่งเข้ามาจะถูกจับคู่กับคิวหน้าเราจนครบก่อน ที่เหลือจึงมาถึงเรา และเราได้ไม่เกินที่สั่งไว้ ขั้นนี้เป็นกติกาล้วน ๆ ยังไม่มีการสุ่ม (สมมติว่าไม่มีใครข้างหน้ายกเลิกคำสั่ง)

\[ \begin{aligned} R&=\max(0,\ M-q_0),\\ F(M)&=\min\{Q,\ R\}. \end{aligned} \]

$R$ คือแรงขายที่เหลือหลังกินคิวหน้าเราหมด ถ้า $M-q_0$ ติดลบ แปลว่าแรงขายหมดก่อนถึงเรา $\max$ กับศูนย์จึงกันไว้ไม่ให้เรา “ได้ติดลบ” ส่วน $\min$ กับ $Q$ กันไว้ไม่ให้เราได้เกินที่สั่ง แรงขายส่วนที่เกินจะไปกินคำสั่งที่ราคาถัดลงไป

ประเด็นสำคัญคือ ทุกคนในคิววางราคาเดียวกัน แต่โอกาสได้ของไม่เท่ากัน คนที่มาก่อนได้ก่อนเสมอ

ลองแทนแรงขายสามขนาด คือ 25,000, 45,000 และ 60,000 หุ้น ลบคิวหน้าเรา 40,000 หุ้นออกก่อน จะได้ $R=\max(0,\,-15{,}000)=0$, $\ R=\max(0,\,5{,}000)=5{,}000$ และ $R=\max(0,\,20{,}000)=20{,}000$ ตามลำดับ จากนั้นตัดไม่ให้เกิน $Q$:

\[ \begin{aligned} F(25{,}000)&=\min\{10{,}000,\ 0\}=0,\\ F(45{,}000)&=\min\{10{,}000,\ 5{,}000\}\\ &=5{,}000,\\ F(60{,}000)&=\min\{10{,}000,\ 20{,}000\}\\ &=10{,}000. \end{aligned} \]

แรงขายไม่ถึง 40,000 หุ้นไม่ให้อะไรเราเลย ระหว่าง 40,000 ถึง $40{,}000+10{,}000=50{,}000$ หุ้น เราได้เพิ่มขึ้นหุ้นต่อหุ้นเป็นเส้นตรง เกิน 50,000 หุ้นเราได้ครบ

ขั้นที่ 2 — แรงขายสุ่ม: โอกาสได้ของ และสัดส่วนที่ได้โดยเฉลี่ย

ในความจริงเราไม่รู้ว่าแรงขายจะมากี่หุ้น จึงต้องถามเป็นโอกาส หน้านี้สมมติแบบจำลองที่ง่ายที่สุดสำหรับจำนวนบวกที่เดาไม่ได้ คือ $M$ มีการแจกแจงแบบ exponential ที่มีค่าเฉลี่ย $\mu=50{,}000$ หุ้น (ทำความรู้จักการแจกแจงนี้ได้ที่ สวนสัตว์ของการแจกแจง) สิ่งเดียวที่เราต้องใช้จากมันคือ โอกาสที่แรงขายจะมากกว่า $m$ หุ้น ลดลงแบบ exponential ตาม $m$:

\[ P(M\gt m)=e^{-m/\mu}. \]

เราอยากรู้สามอย่าง: โอกาสที่ได้ของบ้าง โอกาสที่ได้ครบ และโดยเฉลี่ยได้กี่หุ้น สองข้อแรกอ่านจากกติกาคิวได้ตรง ๆ ได้บ้างเมื่อ $M\gt q_0$ และได้ครบเมื่อ $M\gt q_0+Q$ เลขชี้กำลังที่ต้องใช้คือ $q_0/\mu=40{,}000/50{,}000=0.8$ และ $(q_0+Q)/\mu=50{,}000/50{,}000=1$

\[ \begin{aligned} P(F\gt0)&=P(M\gt q_0)\\ &=e^{-0.8}=0.4493,\\ P(F=Q)&=P(M\gt q_0+Q)\\ &=e^{-1}=0.3679. \end{aligned} \]

ข้อที่สามต้องคิดอีกแบบ เพราะคำสั่งอาจได้แค่บางส่วน ให้นับทีละหุ้น หุ้นที่อยู่ตำแหน่ง $m$ ในคิว (โดย $m$ อยู่ระหว่าง $q_0$ กับ $q_0+Q$) จะได้จับคู่ก็ต่อเมื่อแรงขายมาถึงตำแหน่งนั้น คือ $M\gt m$ จำนวนหุ้นที่เราได้จึงเท่ากับจำนวนตำแหน่งในช่วงของเราที่แรงขายมาถึง

\[ \begin{aligned} \mathbb E[F]&=\int_{q_0}^{q_0+Q}P(M\gt m)\,dm\\ &=\Big[-\mu e^{-m/\mu}\Big]_{q_0}^{q_0+Q}\\ &=\mu\big(e^{-0.8}-e^{-1}\big)\\ &=50{,}000\times0.08145\\ &=4{,}072.5,\\ \varphi&=\frac{\mathbb E[F]}{Q}=\frac{4{,}072.5}{10{,}000}\\ &=0.4072. \end{aligned} \]

ทำไมค่าเฉลี่ยของจำนวนหุ้นที่ได้กลายเป็นอินทิกรัลของโอกาส ลองคิดว่าแต่ละตำแหน่ง $m$ ในช่วงของเรามีตัวนับที่เป็น 1 ถ้าได้ และเป็น 0 ถ้าไม่ได้ จำนวนหุ้นที่ได้คือผลรวมของตัวนับทุกตัว ค่าเฉลี่ยของผลรวมเท่ากับผลรวมของค่าเฉลี่ย และค่าเฉลี่ยของตัวนับ 0 หรือ 1 ก็คือโอกาสที่มันเป็น 1 นั่นคือ $P(M\gt m)$ เมื่อตำแหน่งเรียงต่อกันเป็นช่วง ผลรวมจึงกลายเป็นอินทิกรัล ส่วนแถวที่ใส่วงเล็บเหลี่ยมใช้ความจริงว่า $-\mu e^{-m/\mu}$ มีอนุพันธ์เท่ากับ $e^{-m/\mu}$ แล้วแทนขอบบนลบขอบล่าง

ผลคือ ต่อท้ายคิว 40,000 หุ้น โอกาสได้บ้างคือ 44.93% โอกาสได้ครบคือ 36.79% และได้เฉลี่ย 40.72% ของคำสั่ง ตัวเลขสุดท้ายต่ำกว่าตัวแรก เพราะหลายครั้งเราได้แค่บางส่วน ตัวที่ใช้ตัดสินใจคือ $\varphi$ เพราะต้นทุนคิดเป็นรายหุ้น

เทียบกับการอยู่หัวคิว ($q_0=0$): ได้บ้างแน่นอนเพราะ $e^{0}=1$ ได้ครบด้วยโอกาส $e^{-10{,}000/50{,}000}=e^{-0.2}=81.87\%$ และได้เฉลี่ย $\varphi=5\times(1-0.8187)=90.63\%$ (เลข 5 มาจาก $\mu/Q=50{,}000/10{,}000$) ความลึกของคิวจึงลดโอกาสแบบ exponential ไม่ใช่แบบเส้นตรง

โค้ดท้ายหน้าตรวจสูตรด้วยการสุ่มแรงขาย 400,000 ครั้ง ได้ 44.88%, 36.78% และ 40.68% ใกล้กับ 44.93%, 36.79% และ 40.72% จากสูตร

ขั้นที่ 3 — บัญชีต่อหุ้นของ maker และ taker

จะเทียบการรอกับการเคาะได้ ต้องวัดต้นทุนของทั้งสองทางด้วยไม้บรรทัดเดียวกัน หน้านี้วัดทุกอย่างเป็นดอลลาร์ต่อหุ้นเทียบราคากลาง \$100.01 ให้ค่าบวกคือเสียเงิน (1 เซนต์ $=\$0.01$) มีสามกรณี:

  • เคาะ: ซื้อที่ ask แพงกว่าราคากลางครึ่ง spread $s/2$ แล้วจ่ายค่าธรรมเนียม $f_t$ อีก
  • รอแล้วได้ของ: ซื้อที่ bid ถูกกว่าราคากลางครึ่ง spread และได้ rebate $r_m$ คืน แต่ถ้าหลังได้ของ ราคาวิ่งสวนทางเรา (ลงไป) อีก $\Delta P$ ส่วนนั้นเป็นต้นทุน เพราะของที่เพิ่งซื้อมามีค่าน้อยลงทันที
  • รอแล้วไม่ได้: ต้องกลับไปเคาะ เสีย $C_T$ เหมือนเคาะ บวกราคาที่หนีขึ้นไปแล้ว $D$
\[ \begin{aligned} C_T&=\tfrac s2+f_t\\ &=0.01+0.003=0.013,\\ C_{M|F}&=-\tfrac s2-r_m+\Delta P\\ &=-0.012+\Delta P,\\ C_{\rm rest}&=\varphi\,C_{M|F}\\ &\quad+(1-\varphi)(C_T+D). \end{aligned} \]

$C_{\rm rest}$ คือต้นทุนเฉลี่ยของการวางรอ มันเป็นค่าเฉลี่ยถ่วงน้ำหนัก เพราะหุ้นส่วน $\varphi$ ของคำสั่งได้ของในฐานะ maker และส่วนที่เหลือ $1-\varphi$ พลาด แล้วต้องไปเคาะที่ราคาแย่ลง ในสูตรนี้มีต้นทุนที่ไม่เห็นบนจออยู่สองตัว $D$ คือต้นทุนของโอกาส และ $\Delta P$ คือต้นทุนของ adverse selection

rebate เกิดเฉพาะหุ้นที่ได้ และเล็กมาก แค่ 0.2 เซนต์ ส่วน $\Delta P$ ใหญ่กว่านั้นได้ง่าย ถ้าได้ของแล้วราคาวิ่งสวน 1 เซนต์ ต้นทุนต่อหุ้นที่ได้จะเป็น $C_{M|F}=-0.012+0.010=-\$0.002$ คือเหลือกำไรแค่ rebate

มืออาชีพแยกส่วนที่ได้จาก spread หลังหัก markout ออกมาดูเป็นตัวเดียว เรียกว่า realized spread:

\[ s_{\rm real}=\tfrac s2-\Delta P. \]

ในตัวอย่างเมื่อกี้ $s_{\rm real}=0.01-0.01=0$ ครึ่ง spread ที่เห็นบนจอหายไปทั้งหมด ผู้ดูแลสภาพคล่องมืออาชีพ (market maker) จึงหาเงินจาก realized spread ไม่ใช่ spread บนจอ นี่คือเหตุที่พวกเขายอมจ่ายเงินให้โบรกเกอร์เพื่อขอรับคำสั่งของนักลงทุนรายย่อย เรียกว่า payment for order flow เพราะคำสั่งรายย่อยโดยเฉลี่ยไม่ได้รู้อะไรล่วงหน้า markout จึงต่ำ และ realized spread ใกล้ครึ่ง spread เต็ม

ขั้นที่ 4 — markout มากที่สุดที่การรอยังเสมอกับการเคาะ

markout $\Delta P$ ไม่ได้อยู่บนจอ ต้องวัดเอาจากประวัติการเทรดของเราเอง ก่อนไปวัด เราอยากรู้ว่าต้องกลัวมันแค่ไหน คำถามคือ หลังได้ของแล้ว ราคาวิ่งสวนได้มากที่สุดกี่เซนต์ การรอจึงยังไม่แพ้การเคาะ วิธีหาคือตั้งต้นทุนเฉลี่ยของการรอให้เท่ากับการเคาะพอดี แล้วแก้สมการหา $\Delta P$ เรียกค่านั้นว่า $\Delta P^*$

\[ \begin{aligned} C_T&=\varphi\,C_{M|F}\\ &\quad+(1-\varphi)(C_T+D),\\ \varphi\,C_{M|F}&=\varphi\,C_T-(1-\varphi)D,\\ C_{M|F}&=C_T-\tfrac{1-\varphi}{\varphi}D,\\ \Delta P^*&=s+f_t+r_m-\tfrac{1-\varphi}{\varphi}D. \end{aligned} \]

ขั้นแรกให้ $\varphi C_{M|F}$ อยู่ข้างเดียว แล้วย้ายที่เหลือไปอีกข้าง ตรงนี้ $C_T$ กับ $-(1-\varphi)C_T$ มาอยู่ด้วยกัน และรวมกันได้ $C_T-(1-\varphi)C_T=\varphi C_T$ จากนั้นหารด้วย $\varphi$ ทั้งสองข้าง ขั้นสุดท้ายแทน $C_{M|F}=-\tfrac s2-r_m+\Delta P$ และ $C_T=\tfrac s2+f_t$ ลงไป แล้วย้ายข้างให้เหลือ $\Delta P$ ตัวเดียว ครึ่ง spread สองก้อนรวมกันเป็น $s$ เต็ม

สูตรนี้อ่านได้เป็นสองก้อน ก้อนแรก $s+f_t+r_m=0.02+0.003+0.002=\$0.025$ คือทุกอย่างที่การรอประหยัดได้ต่อหุ้นที่ได้ ซึ่งก็คือส่วนต่าง 2.5 เซนต์ของเพื่อนในโจทย์เปิดหน้า ก้อนที่สอง $\tfrac{1-\varphi}{\varphi}D$ คือค่าไล่ราคาของส่วนที่พลาด เฉลี่ยออกมาเป็นต่อหุ้นที่ได้ ถ้าได้ของแน่นอน ($\varphi=1$) ก้อนที่สองเป็นศูนย์ ราคาวิ่งสวนได้ถึง 2.5 เซนต์

ตัวอย่าง: ต่อท้ายคิว 40,000 หุ้น ($\varphi=0.4072$ จากขั้นแรงขายสุ่ม) แต่ไม่รีบ ถ้าพลาด ราคาหนีไปแค่ $D=\$0.01$ (ตัวเลขสมมติ):

\[ \begin{aligned} \tfrac{1-\varphi}{\varphi}&=\tfrac{0.5928}{0.4072}=1.4555,\\ \Delta P^*&=0.025-1.4555\times0.01\\ &=\$0.0104. \end{aligned} \]

แปลว่า ถ้า markout ที่วัดได้จริงต่ำกว่า 1.04 เซนต์ต่อหุ้น การรอคุ้ม ถ้าสูงกว่านั้น ควรเคาะ

ขั้นที่ 5 — โอกาสได้ของขั้นต่ำ: จุดตัดสองในสาม

ลองมองกรณีที่ดีที่สุดสำหรับการรอ คือไม่มี adverse selection เลย ราคาไม่วิ่งสวนหลังได้ของ ($\Delta P=0$) ถึงอย่างนั้น การรอก็ยังแพ้ได้ ถ้าเราได้ของน้อยเกินไป เพราะส่วนที่พลาดต้องไปไล่ซื้อแพง คำถามคือ ต้องได้ของอย่างน้อยกี่เปอร์เซ็นต์ ให้ $\varphi^*$ คือสัดส่วนขั้นต่ำนั้น หาได้จากการตั้ง $\Delta P^*=0$ ในสูตรของขั้นที่แล้ว แล้วแก้หา $\varphi$:

\[ \begin{aligned} s+f_t+r_m&=\tfrac{1-\varphi}{\varphi}D,\\ \varphi(s+f_t+r_m)&=(1-\varphi)D,\\ \varphi^*&=\frac{D}{D+s+f_t+r_m}. \end{aligned} \]

คูณ $\varphi$ ทั้งสองข้างเพื่อเอาเศษส่วนออก แล้วกระจายฝั่งขวาเป็น $D-\varphi D$ ย้าย $\varphi D$ มาฝั่งซ้าย จะได้ $\varphi(D+s+f_t+r_m)=D$ จากนั้นหารด้วยวงเล็บ สูตรสุดท้ายอ่านง่าย: จุดตัดคือค่าไล่ราคา $D$ หารด้วยค่าไล่ราคารวมกับทุกอย่างที่การรอประหยัดได้ ยิ่งรีบ $D$ ยิ่งใหญ่ จุดตัดยิ่งเข้าใกล้หนึ่ง คือต้องได้ของเกือบทั้งหมด การรอจึงจะคุ้ม

แทนตัวเลขของโจทย์เปิดหน้า $D=\$0.05$ และ $s+f_t+r_m=\$0.025$ แล้วดูด้วยว่า $\Delta P^*=0.025-\tfrac{1-\varphi}{\varphi}\times0.05$ เปลี่ยนไปอย่างไรเมื่อ $\varphi$ ลดลงจาก 1 ไป 0.5:

\[ \begin{aligned} \varphi^*&=\frac{0.05}{0.05+0.025}\\ &=\frac{0.05}{0.075}=\tfrac23,\\ \Delta P^*(1)&=0.025-0\times0.05=0.025,\\ \Delta P^*(0.8)&=0.025-0.25\times0.05\\ &=0.0125,\\ \Delta P^*(\tfrac23)&=0.025-0.5\times0.05=0,\\ \Delta P^*(0.5)&=0.025-1\times0.05\\ &=-0.025. \end{aligned} \]

ตัวคูณหน้า 0.05 คือ $\tfrac{1-\varphi}{\varphi}$ เช่นที่ $\varphi=0.8$ ได้ $0.2/0.8=0.25$ และที่ $\varphi=\tfrac23$ ได้ $\tfrac13/\tfrac23=0.5$ เมื่อ $\varphi$ ต่ำกว่าสองในสาม $\Delta P^*$ ติดลบ แปลว่าการรอจะคุ้มก็ต่อเมื่อราคาต้องวิ่งมาทางที่ดีกับเราหลังได้ของ ซึ่งมักไม่เกิด เพราะคำสั่งรอมักได้ของตอนที่ราคากำลังวิ่งสวน

ขั้นที่ 6 — ตอบโจทย์เปิดหน้า: รอหรือเคาะ

ตอนนี้มีเครื่องมือครบแล้ว กลับไปที่โต๊ะเทรดในโจทย์เปิดหน้า ซึ่งต้องเลือกระหว่างเคาะซื้อ 10,000 หุ้นทันที กับต่อท้ายคิว 40,000 หุ้นที่ bid

โจทย์ให้อะไรมาบ้าง (ดอลลาร์ต่อหุ้น):

  • spread $s=0.02$ ค่าธรรมเนียมของคนเคาะ $f_t=0.003$ และ rebate ของคนวางรอ $r_m=0.002$
  • ราคาที่หนีไปถ้าพลาด $D=0.05$
  • สัดส่วนที่ได้โดยเฉลี่ย $\varphi=0.4072$ ซึ่งคำนวณไว้แล้วในขั้นแรงขายสุ่ม
  • สมมติว่าไม่มี markout ($\Delta P=0$) ซึ่งเป็นกรณีที่ดีที่สุดสำหรับการรอ

ต้นทุนของการเคาะคือ $C_T=0.01+0.003=0.013$ หุ้นที่รอแล้วได้เสีย $C_{M|F}=-0.01-0.002=-0.012$ หุ้นที่พลาดเสีย $C_T+D=0.013+0.05=0.063$ และส่วนที่พลาดคือ $1-\varphi=1-0.4072=0.5928$ เอาทั้งหมดใส่สูตรต้นทุนเฉลี่ยของการรอ:

\[ \begin{aligned} C_{\rm rest}&=0.4072\times(-0.012)\\ &\quad+0.5928\times0.063\\ &=-0.0049+0.0373\\ &=0.0325. \end{aligned} \]

คำตอบ: ควรเคาะ เคาะทันทีเสีย 1.30 เซนต์ต่อหุ้น รอเสียเฉลี่ย 3.25 เซนต์ คิดเป็น $0.0325/0.013=2.5$ เท่าของการเคาะ ทั้งที่ยังไม่นับ markout เลย สาเหตุคือ $\varphi=40.7\%$ ต่ำกว่าจุดตัด $66.7\%$ มาก “ส่วนต่าง 2.5 เซนต์” ที่เพื่อนเห็นนั้นได้เฉพาะหุ้นที่ได้ของ ซึ่งมีแค่ราว 4 ใน 10 อีกราว 6 ใน 10 ต้องจ่าย 6.3 เซนต์

ตรวจเองใน 10 วินาที (คิดเป็นเซนต์): $0.4072\times(-1.2)+0.5928\times6.3=-0.49+3.73=3.25$

ขั้นที่ 7 — ตำแหน่งในคิวมีราคา: คิวลึกได้แค่ไหนจึงยังรอได้

เรามีสองข้อเท็จจริงแล้ว ข้อแรก จุดตัดบอกว่าต้องได้ของอย่างน้อยสองในสาม ข้อสอง สัดส่วนที่ได้ขึ้นกับจำนวนหุ้นที่รอหน้าเรา เอาสองข้อมารวมกันจะตอบคำถามที่ใช้บนโต๊ะได้ทันที: คิวข้างหน้ายาวได้มากที่สุดกี่หุ้น การรอจึงยังคุ้ม ให้ $q$ คือจำนวนหุ้นที่รอหน้าเรา และ $q^*$ คือค่า $q$ ที่ลึกที่สุดที่ยังได้ $\varphi=2/3$ สูตรของ $\varphi$ มาจากขั้นแรงขายสุ่ม แค่เปลี่ยน $q_0$ เป็น $q$ ทั่วไป:

\[ \begin{aligned} \varphi(q)&=\frac{\mu}{Q}\big(e^{-q/\mu}-e^{-(q+Q)/\mu}\big)\\ &=\frac{\mu}{Q}\,e^{-q/\mu}\big(1-e^{-Q/\mu}\big). \end{aligned} \]

รูปที่สองของสูตรดึง $e^{-q/\mu}$ ออกมาเป็นตัวร่วม เพราะ $e^{-(q+Q)/\mu}=e^{-q/\mu}e^{-Q/\mu}$ ตอนนี้เห็นชัดว่าความลึก $q$ อยู่ในตัวคูณ $e^{-q/\mu}$ ตัวเดียว ทุก ๆ 50,000 หุ้นที่คิวลึกขึ้น สัดส่วนที่ได้จึงหดเหลือ $e^{-1}=36.8\%$ ของเดิม

ตั้ง $\varphi(q^*)=\tfrac23$ แล้วแก้หา $q^*$ ตัวเลขที่ใช้คือ $Q/\mu=10{,}000/50{,}000=0.2$ และ $1-e^{-0.2}=1-0.81873=0.18127$:

\[ \begin{aligned} e^{-q^*/\mu}&=\frac{(2/3)\times0.2}{1-e^{-0.2}}\\ &=\frac{0.13333}{0.18127}=0.73555,\\ q^*&=-\mu\ln0.73555\\ &=50{,}000\times0.30713\\ &=15{,}357. \end{aligned} \]

ขั้นแรกย้าย $\mu/Q$ และ $1-e^{-Q/\mu}$ ไปอีกข้าง ($\mu/Q$ กลับหัวเป็น $Q/\mu=0.2$) ขั้นที่สองใส่ $\ln$ ทั้งสองข้างเพื่อถอดเลขชี้กำลัง ได้ $q^*/\mu=-\ln0.73555=0.30713$

ความหมายคือ ถ้ามีหุ้นรอข้างหน้าไม่เกินราว 15,400 หุ้น การรอชนะการเคาะ (เมื่อไม่มี markout) ถ้าลึกกว่านั้นให้เคาะ นี่คือเหตุที่ระบบส่งคำสั่งพยายามรักษาตำแหน่งในคิวไว้ ถ้ายกเลิกคำสั่งแล้วส่งใหม่เพื่อแก้ราคาเล็กน้อย คำสั่งจะไปต่อท้ายคิว และอาจย้ายจากฝั่งที่การรอคุ้มไปฝั่งที่ไม่คุ้ม

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

นับ rebate เป็นกำไรเพิ่ม: คนมักคิดว่าวางรอแล้วได้ทั้งครึ่ง spread และ rebate คือ $0.010+0.002=\$0.012$ ต่อหุ้น แต่ถ้าราคาวิ่งสวน 1 เซนต์หลังได้ของ เงินที่ประหยัดได้จริงคือ $0.012-0.010=\$0.002$ เหลือแค่ rebate ตัวเดียว และ rebate ก็ได้เฉพาะหุ้นที่ได้ของ ต่อท้ายคิว 40,000 หุ้น เฉลี่ยต่อหุ้นของคำสั่งจึงเหลือ $0.4072\times0.2=0.08$ เซนต์

ใช้โอกาสได้บ้างแทนสัดส่วนที่ได้: โอกาสได้บ้าง 0.4493 สูงกว่าสัดส่วนที่ได้จริง 0.4072 เพราะหลายครั้งได้แค่บางส่วน ในกรณี $D=\$0.01$ ถ้าใช้ตัวผิด markout ที่เสมอตัวจะสูงเกินจริง การรอจึงดูดีเกินจริง ตัวเลขผิดคือ $0.025-\tfrac{0.5507}{0.4493}\times0.01=\$0.0127$ ตัวเลขถูกคือ $0.025-\tfrac{0.5928}{0.4072}\times0.01=\$0.0104$

ลืมค่าไล่ราคาของส่วนที่ไม่ได้: เพื่อนในโจทย์เปิดหน้าดูแค่หุ้นที่ได้ ซึ่งเสีย $-1.2$ เซนต์ จึงคิดว่ารอถูกกว่าเคาะ 2.5 เซนต์ แต่ต้นทุนเฉลี่ยจริงของการรอคือ $0.4072\times(-1.2)+0.5928\times6.3=3.25$ เซนต์ แพงกว่า 1.30 เซนต์ของการเคาะ

เชื่อว่าคิวที่เห็นคือคิวจริง: ตลาดมีคำสั่งซ่อนที่ไม่แสดงบนจอ มีคนยกเลิกคำสั่ง และกติกาต่างกันไปตามตลาด คนข้างหน้าที่ยกเลิกทำให้เราเลื่อนขึ้น ฟังดูดี แต่คนมักยกเลิกตอนที่เห็นว่าราคากำลังจะวิ่งสวน ซึ่งเป็นตอนที่เราไม่อยากได้ของที่สุด จึงต้องวัดอัตราการได้ของจริง แยกตามตลาดและฝั่งซื้อขาย

ใช้ทำอะไรบนโต๊ะจริง

คำสั่งใหญ่ เช่น 10,000 หุ้นในโจทย์เปิดหน้า มักถูกโปรแกรมหั่นเป็นคำสั่งย่อยแล้วส่งทีละก้อน โปรแกรมนี้เรียกว่าระบบส่งคำสั่ง มันตัดสินทุกคำสั่งย่อยว่าจะวางรอหรือเคาะ ด้วยตรรกะเดียวกับหน้านี้ คือเทียบ markout ที่วัดได้กับ $\Delta P^*$ และเทียบสัดส่วนที่ได้กับจุดตัด $\varphi^*$ ตัวเลขที่ใส่ไม่ใช่ตัวเลขสมมติ แต่วัดจากการเทรดของตัวเอง ได้แก่

  • สัดส่วนที่ได้จริง แยกตามความลึกของคิว
  • markout หลังได้ของ วัดที่ 1 วินาที 10 วินาที และ 1 นาที
  • ราคาที่หนีไปเมื่อพลาด ($D$)

ถ้าต้องปิดความเสี่ยงให้ทันก่อนตลาดปิด การพลาดแพงมาก $D$ จึงใหญ่ จุดตัดเข้าใกล้หนึ่ง และควรเคาะ ถ้าไม่รีบและความผันผวนต่ำ ราคาไม่ค่อยหนี $D$ จึงเล็ก การรอคุ้มแม้อยู่ลึกในคิว

อีกทางเลือกหนึ่งคือ dark pool ที่นี่ไม่แสดงขนาดคำสั่งและตัวตนของคนส่งจนกว่าจะซื้อขายเสร็จ คำสั่งใหญ่จึงไม่ดันราคาก่อน แต่ก็ไม่รู้ว่าจะได้ของเท่าไร ส่วนแบ่งของ dark pool มีหลายประมาณการ ประมาณการหนึ่งให้ราว 11 ถึง 12% ของปริมาณซื้อขายในหุ้นบางตัว อีกประมาณการให้ราว 16% ของปริมาณหุ้นสหรัฐฯ ทั้งหมดในปี 2024

dark pool มีข้อกังวลสองข้อ ข้อแรก เมื่อคำสั่งย้ายไปซ่อนมากขึ้น ราคาในตลาดเปิดก็สะท้อนมูลค่าได้แย่ลง ข้อสอง คนที่ได้ซื้อก้อนใหญ่ใน dark pool เจอ winner's curse คือยิ่งได้ของง่าย ยิ่งน่าสงสัยว่าเราให้ราคาดีเกินไป ในกรณีนี้ การได้ของครบมักแปลว่าอีกฝั่งรู้ว่าควรขาย ซึ่งเป็นรูปแบบเดียวกับ adverse selection ในหน้านี้ ปี 2009 SEC (หน่วยงานกำกับตลาดทุนสหรัฐฯ) เสนอมาตรการให้ dark pool โปร่งใสขึ้น

โจทย์ตรวจความเข้าใจ

1. โต๊ะเทรดเดิมต้องซื้อ 10,000 หุ้นเหมือนโจทย์เปิดหน้า แต่วันนี้คิวที่ bid สั้นกว่า มีหุ้นรอหน้าเราแค่ $q_0=20{,}000$ หุ้น ส่วนตัวเลขอื่นเท่าเดิม ($\mu=50{,}000$, $D=\$0.05$, ไม่มี markout) โอกาสได้บ้าง โอกาสได้ครบ และสัดส่วนที่ได้เฉลี่ยเป็นเท่าไร ควรรอไหม

เฉลย

เลขชี้กำลังคือ $q_0/\mu=20{,}000/50{,}000=0.4$ และ $(q_0+Q)/\mu=30{,}000/50{,}000=0.6$ ส่วนตัวคูณหน้าสูตรของ $\varphi$ คือ $\mu/Q=50{,}000/10{,}000=5$ จึงได้

\[ \begin{aligned} P(F\gt0)&=e^{-0.4}=67.03\%,\\ P(F=Q)&=e^{-0.6}=54.88\%,\\ \varphi&=5\times(0.6703-0.5488)\\ &=60.75\%. \end{aligned} \]

$\varphi=60.75\%$ ยังต่ำกว่าจุดตัด 66.7% จึงควรเคาะ ซึ่งตรงกับคิวลึกที่สุดที่ยังรอได้ราว 15,400 หุ้น เพราะ 20,000 หุ้นลึกกว่านั้น ตรวจด้วยต้นทุนก็ได้ผลเดียวกัน ส่วนที่พลาดคือ $1-0.6075=0.3925$ และแต่ละหุ้นที่พลาดเสีย $0.013+0.05=0.063$:

\[ \begin{aligned} C_{\rm rest}&=0.6075\times(-0.012)\\ &\quad+0.3925\times0.063\\ &=\$0.0174, \end{aligned} \]

ยังแพงกว่า \$0.013 ของการเคาะ

2. วันนี้ตลาดเงียบ และโต๊ะไม่รีบ ต่อท้ายคิว 40,000 หุ้นเหมือนเดิม ($\varphi=0.4072$) แต่ถ้าพลาด ราคาจะหนีไปแค่ $D=\$0.01$ จุดตัดคือเท่าไร และถ้าไม่มี markout ควรรอไหม

เฉลย

จุดตัดคือ

\[ \varphi^*=\frac{0.01}{0.01+0.025}=28.57\%. \]

$\varphi=40.72\%$ สูงกว่าจุดตัด จึงรอได้ ตรวจด้วยต้นทุน หุ้นที่พลาดเสีย $C_T+D=0.013+0.01=0.023$ ดังนั้น

\[ \begin{aligned} C_{\rm rest}&=0.4072\times(-0.012)\\ &\quad+0.5928\times0.023\\ &=\$0.0087, \end{aligned} \]

ต่ำกว่า \$0.013 ของการเคาะ แต่ต้องตรวจด้วยว่า markout จริงต่ำกว่า $\Delta P^*=\$0.0104$ ซึ่งคำนวณไว้ในขั้น markout ที่เสมอตัว

3. ตลาดหุ้นแห่งหนึ่งหาเงินจากส่วนต่างค่าธรรมเนียม มันเก็บค่าธรรมเนียมจาก taker 0.30 เซนต์ต่อหุ้น และจ่าย rebate ให้ maker 0.20 เซนต์ต่อหุ้น (0.30 เซนต์คือเพดานที่กฎ Regulation NMS ของสหรัฐฯ ใช้มาตั้งแต่ปี 2005 และปี 2024 SEC ลงมติลดเพดานนี้เหลือ 0.10 เซนต์สำหรับหุ้นราคาตั้งแต่ \$1) ถ้าวันหนึ่งมีการจับคู่ 1,000,000 หุ้น ใครจ่ายและใครได้เงินเท่าไร

เฉลย

ทุกหุ้นที่จับคู่มี taker หนึ่งฝั่งและ maker หนึ่งฝั่ง ให้ $T$ คือเงินที่ taker จ่ายรวม $K$ คือ rebate ที่ maker ได้รวม และ $V$ คือที่ตลาดเก็บไว้ (0.30 เซนต์ $=\$0.003$ และ 0.20 เซนต์ $=\$0.002$):

\[ \begin{aligned} T&=10^6\times0.003=\$3{,}000,\\ K&=10^6\times0.002=\$2{,}000,\\ V&=T-K=\$1{,}000. \end{aligned} \]

taker จ่าย \$3,000 maker ได้คืน \$2,000 และตลาดเก็บส่วนต่าง \$1,000 ตลาดยอมจ่าย rebate เพราะคำสั่งที่วางรอทำให้มีของให้ซื้อขาย และนั่นดึง taker เข้ามา ถ้าตารางค่าธรรมเนียมเปลี่ยน กลยุทธ์ที่คุ้มเพราะ rebate อาจเลิกคุ้มทันที

const {exp, log, min, max} = Math;

function shares(name, v) {
  if (!(typeof v === 'number' && Number.isFinite(v) && v >= 0)) throw new RangeError(`${name} must be a non-negative number`);
  return v;
}
// Price-time priority: incoming sell flow M first fills the q0 shares ahead of us, then our Q shares.
const fillShares = (Q, M, q0) => min(shares('Q', Q), max(0, shares('M', M) - shares('q0', q0)));
// Sell flow M exponential with mean mu: chance of any fill, of a full fill, and the expected filled fraction.
function queue(Q, q0, mu) {
  if (!(mu > 0)) throw new RangeError('mu must be positive');
  const a = exp(-q0 / mu), b = exp(-(q0 + Q) / mu);
  return {any: a, full: b, fraction: mu * (a - b) / Q};   // each share level m in [q0, q0 + Q] fills when M > m
}
// Costs per share measured from the mid: take now, or rest and (if not filled) take later after the price moved D.
function restOrTake({s, fee, rebate, D, phi, markout = 0}) {
  if (!(phi > 0 && phi <= 1)) throw new RangeError('fill fraction must be in (0, 1]');
  const take = s / 2 + fee, filled = -s / 2 - rebate + markout;
  return {take, filled, realizedSpread: s / 2 - markout, rest: phi * filled + (1 - phi) * (take + D),
    breakevenMarkout: s + fee + rebate - (1 - phi) / phi * D, cutoff: D / (D + s + fee + rebate)};
}
function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}

const q = queue(10000, 40000, 50000);
const fees = {s: 0.02, fee: 0.003, rebate: 0.002};
// Simulate 400,000 random sell flows to check the closed forms.
const rnd = mulberry32(11);
let any = 0, full = 0, filled = 0;
for (let i = 0; i < 400000; i++) {
  const M = -50000 * log(1 - rnd()), f = fillShares(10000, M, 40000);
  if (f > 0) any++; if (f === 10000) full++; filled += f;
}
// Deepest queue at which resting still breaks even with zero markout (fill fraction = 2/3): closed form and bisection.
const maxQueue = -50000 * log((2 / 3) * (10000 / 50000) / (1 - exp(-10000 / 50000)));
let lo = 0, hi = 200000;
for (let k = 0; k < 200; k++) { const m = (lo + hi) / 2; if (queue(10000, m, 50000).fraction > 2 / 3) lo = m; else hi = m; }

  anyAsPhi: restOrTake({...fees, D: 0.01, phi: q.any}).breakevenMarkout,

สิ่งที่ควรตอบได้หลังอ่าน

  • ที่ราคาเดียวกัน คำสั่งของเราได้ของเมื่อแรงขายกินคิวหน้าเราหมดแล้วเท่านั้น: $F=\min\{Q,\max(0,M-q_0)\}$ ใครมาก่อนได้ก่อนเสมอ
  • ถ้าแรงขายเป็นแบบ exponential ค่าเฉลี่ย 50,000 หุ้น การต่อท้ายคิว 40,000 หุ้นมีโอกาสได้บ้าง 44.93% ได้ครบ 36.79% และได้เฉลี่ย 40.72% ของคำสั่ง ตัวสุดท้ายนี้คือตัวที่ใช้ตัดสินใจ เพราะคำสั่งได้บางส่วนได้
  • การวางรอมีต้นทุนที่ไม่เห็นบนจอสองก้อน คือต้นทุนของโอกาส ($D$) และ adverse selection ($\Delta P$) markout มากที่สุดที่การรอยังเสมอตัวคือ $\Delta P^*=s+f_t+r_m-\frac{1-\varphi}{\varphi}D$ ถ้าไม่มี markout การรอคุ้มเมื่อ $\varphi\ge D/(D+s+f_t+r_m)$ ซึ่งในโจทย์คือ 2/3
  • โจทย์เปิดหน้า: รอเสียเฉลี่ย 3.25 เซนต์ต่อหุ้น เคาะเสีย 1.30 เซนต์ จึงควรเคาะ การรอจะคุ้มเฉพาะเมื่อคิวข้างหน้าไม่เกินราว 15,400 หุ้น

หน้าถัดไป ETF creation-redemption arbitrage เอาต้นทุนการซื้อขายทั้งหมดที่สะสมมา ตั้งแต่ spread, impact จนถึงคิว ไปใช้กับ arbitrage ที่เห็นบ่อยที่สุดในตลาด ETF คือกองทุนที่ซื้อขายเหมือนหุ้นและถือตะกร้าหุ้นไว้ข้างใน บางครั้งราคา ETF ห่างจากมูลค่าของตะกร้าหุ้นที่มันถือ คำถามคือ ต้องห่างแค่ไหนจึงคุ้มที่จะซื้อฝั่งหนึ่งแล้วขายอีกฝั่ง
