12.1 Global vs Local Minima

โปรแกรมหาค่าต่ำสุดมองเห็นแค่พื้นรอบตัว จึงรับประกันได้แค่ก้นหลุมที่ใกล้ที่สุด ยกเว้นเมื่อกราฟเป็นชามใบเดียว (convex) และ variance ของพอร์ตก็เป็นชามแบบนั้นพอดี

ทีม quant คือทีมที่สร้างกลยุทธ์ซื้อขายจากคณิตศาสตร์และข้อมูล ทีมนี้มีกลยุทธ์หนึ่งที่อ่าน “สัญญาณ” ตัวหนึ่ง แล้วตัดสินใจว่าจะซื้อหรือขาย ปุ่มปรับของกลยุทธ์มีปุ่มเดียว คือน้ำหนักสัญญาณ $w$ ถ้า $w$ เป็นบวก กลยุทธ์เล่นตามสัญญาณ ถ้า $w$ ติดลบ กลยุทธ์เล่นสวนสัญญาณ ทีมอยากได้ $w$ ที่ทำให้ขาดทุนน้อยที่สุด

ทีมวัดผลด้วย backtest คือเอากลยุทธ์ไปรันกับราคาในอดีต แล้วดูว่าจะขาดทุนเท่าไร สมมติว่าผลขาดทุนย้อนหลัง หน่วยล้านดอลลาร์ ออกมาเป็นสูตรนี้ (ค่าติดลบแปลว่ากำไร)

\[f(w)=3w^4-4w^3-36w^2\]

ทีมให้คอมพิวเตอร์หา $w$ ด้วย gradient descent วิธีนี้เริ่มจาก $w$ ค่าหนึ่ง แล้วขยับ $w$ ไปทางที่ขาดทุนลดลงทีละก้าว จนพื้นราบ คือความชันเป็นศูนย์ ทีมรันโค้ดเดิมกับข้อมูลเดิมสองรอบ

  • รอบแรกเริ่มที่ $w=-1$
  • รอบสองเริ่มที่ $w=+1$

ทั้งสองรอบรายงานว่า “converged, slope = 0” แปลว่าหยุดแล้วเพราะความชันเป็นศูนย์ เพื่อนร่วมทีมบอกว่าเลือกรอบไหนก็ได้ เพราะโปรแกรมยืนยันแล้วทั้งคู่ จริงไหม?

ลองตอบก่อนเปิดเฉลย

ไม่จริง สองรอบหยุดคนละที่ หน้านี้จะคำนวณตัวเลขเหล่านี้ให้ดูทีละขั้น

  • รอบแรกหยุดที่ $w=-2$ ซึ่ง $f(-2)=-64$ คือกำไร \$64 ล้าน
  • รอบสองหยุดที่ $w=3$ ซึ่ง $f(3)=-189$ คือกำไร \$189 ล้าน

สองรอบต่างกัน $189-64=125$ คือ \$125 ล้าน และต่างกันเพราะจุดเริ่มอย่างเดียว ทั้งสองจุดมีความชันศูนย์ และกราฟหงายขึ้นรอบตัวทั้งคู่ จึงผ่านทุกการตรวจที่ดูแค่รอบตัว แต่มีแค่ $w=3$ ที่ต่ำที่สุดทั้งเส้น

ท้ายหน้าจะเจอโจทย์ที่ไม่มีปัญหานี้ คือจัดพอร์ตหุ้นกับพันธบัตรให้แกว่งน้อยที่สุด โจทย์นั้นเริ่มที่หุ้น 0% หรือหุ้น 100% ก็จบที่คำตอบเดียวกัน คือหุ้น 10.53% (หน้านี้จะคำนวณให้ดู) เพราะกราฟของโจทย์นั้นเป็นชามใบเดียว

ภาพรวมก่อนลงสูตร

optimizer คือโปรแกรมที่หาค่าตัวแปรที่ทำให้ค่าหนึ่งต่ำที่สุด gradient descent ในโจทย์เปิดเรื่องก็เป็น optimizer แบบหนึ่ง optimizer ทุกตัวทำงานเหมือนคนเดินลงเขาตอนหมอกลง มันเห็นแค่พื้นใต้เท้า คือรู้ความชันและความโค้งตรงจุดที่ยืน แล้วก้าวไปทางที่ต่ำลง พอพื้นราบทุกทิศ มันก็หยุด

จุดที่หยุดจึงรับประกันได้แค่ว่า “รอบ ๆ ตัวไม่มีที่ต่ำกว่า” จุดแบบนี้เรียกว่า local minimum แต่สิ่งที่เราต้องการจริงคือ “ทั้งแผนที่ไม่มีที่ต่ำกว่า” จุดแบบนี้เรียกว่า global minimum

รูปด้านล่างคือกราฟผลขาดทุน $f(w)$ ของโจทย์เปิดเรื่อง กราฟมีสองหุบ คั่นด้วยสันเขาที่ $w=0$ ถ้ามองแค่ในกรอบสีส้มรอบ $w=-2$ จุด $w=-2$ ต่ำที่สุดแน่นอน แต่นอกกรอบไปทางขวามีหุบที่ $w=3$ ซึ่งลึกกว่า $189-64=125$ ล้านดอลลาร์ การตรวจที่ดูแค่รอบตัวมองไม่เห็นหุบนั้นเลย

หน้านี้เดินตามลำดับนี้

  1. หาจุดที่พื้นราบด้วยมือ แล้วดูว่าจุดไหนเป็นก้นหุบ จุดไหนเป็นยอดเนิน
  2. นิยามคำว่า local กับ global ให้ชัด
  3. ปล่อย gradient descent สองรอบ ให้เห็นว่าจุดเริ่มเป็นตัวเลือกหุบ
  4. หาเงื่อนไขที่ทำให้ปัญหานี้หายไป เงื่อนไขนั้นชื่อ convexity แปลว่ากราฟเป็นชามใบเดียว ถ้าเป็นชามใบเดียว ก้นหลุมใกล้ตัวทุกหลุมคือก้นหลุมต่ำสุด และความชันศูนย์ก็พอยืนยันคำตอบ
  5. พิสูจน์ว่า variance ของพอร์ตเป็นชามแบบนั้น และใช้นิยามเดียวกันจับได้ว่ากราฟ backtest ไม่ใช่

Optimizer

วิธีหาค่าต่ำสุดที่ก้าวสวนความชันทีละก้าว ก้าวยาวเท่ากับขนาดก้าว $\eta$ คูณความชัน แล้วหยุดเมื่อความชันเป็นศูนย์

Local minimum
จุดที่ไม่มีจุดใกล้ ๆ ตัวไหนต่ำกว่า algorithm ที่มองแค่รอบตัวรับประกันได้แค่จุดแบบนี้ และจุดนี้อาจไม่ใช่ global

จุดที่ความชันเป็นศูนย์ เราใช้มันเป็นรายชื่อผู้สมัคร เพราะจุดต่ำสุดที่อยู่กลางกราฟเรียบต้องมีความชันศูนย์ แต่ยอดเนินก็มีความชันศูนย์ จึงอยู่ในรายชื่อด้วย
Convex function
function ที่กราฟไม่เคยโผล่ขึ้นเหนือเส้นตรงที่เชื่อมสองจุดใด ๆ บนกราฟ กราฟแบบนี้เป็นชามใบเดียว จึงรับประกันว่าหลุมใกล้ตัวคือหลุมต่ำสุดของทั้งโจทย์
Basin of attraction
กลุ่มจุดเริ่มที่ algorithm ไหลไปจบที่หลุมเดียวกัน กลุ่มนี้ขึ้นกับทั้งรูปร่างกราฟและขนาดก้าวที่ใช้
Multi-start
การรัน optimizer ซ้ำจากหลายจุดเริ่ม แล้วเก็บผลที่ดีที่สุด ช่วยลดโอกาสพลาดหุบลึก แต่ไม่ใช่การพิสูจน์

ขั้นที่ 1 — หาจุดที่พื้นราบของ backtest

ก่อนจะถามว่าจุดไหนต่ำสุด เราต้องมีรายชื่อผู้สมัครก่อน ลองคิดดู ถ้าความชันที่จุดหนึ่งไม่เป็นศูนย์ ก้าวสวนความชันนิดเดียวก็ได้ค่าต่ำลง จุดนั้นจึงไม่ใช่จุดต่ำสุด ดังนั้นจุดต่ำสุดที่อยู่กลางกราฟเรียบต้องมีความชันศูนย์ เราจึงหา derivative $f'(w)$ ซึ่งคือความชัน แล้วหาว่ามันเป็นศูนย์ที่ไหน

\[ \begin{aligned} f'(w)&=12w^3-12w^2-72w\\ &=12w\,(w^2-w-6)\\ &=12w\,(w-3)(w+2),\\ f'(w)=0:&\quad w=-2,\ 0,\ 3. \end{aligned} \]

ความชันเป็นสมการกำลังสาม ซึ่งแก้ตรง ๆ ยาก แต่ทุกพจน์มี $12w$ เป็นตัวร่วม จึงดึงออกมาได้ วงเล็บที่เหลือเป็นกำลังสอง เราหาสองจำนวนที่คูณกันได้ −6 และบวกกันได้ −1 ซึ่งคือ −3 กับ +2 ผลคูณจะเป็นศูนย์เมื่อตัวใดตัวหนึ่งเป็นศูนย์ เราจึงได้ผู้สมัครสามตัว คือ −2, 0 และ 3

ตัวเลข 3, −4, −36 ในสูตร $f$ ถูกเลือกมาให้รากลงตัว เพื่อให้คิดด้วยมือได้ กราฟของกลยุทธ์จริงไม่มีสูตรแบบนี้ มันคือผล backtest ทีละค่า แต่มีหลายหุบได้แบบเดียวกัน

ขั้นที่ 2 — จัดประเภทสามจุด และพิสูจน์ว่าไม่มีอะไรต่ำกว่า −189

ความชันศูนย์เกิดได้ทั้งที่ก้นหุบและบนยอดเนิน เราจึงต้องแยกสองแบบนี้ออกจากกัน ตัวแยกคือความโค้ง $f''(w)$ ซึ่งคือ derivative ของความชัน ถ้า $f''$ เป็นบวก กราฟหงายขึ้น จุดนั้นเป็นก้นหุบ ถ้า $f''$ เป็นลบ กราฟคว่ำลง จุดนั้นเป็นยอดเนิน (เหตุผลเต็มอยู่ในหน้า Hessian และเงื่อนไขอันดับสอง) จากนั้นเราแทนค่ากลับเข้า $f$ เพื่อดูว่าแต่ละจุดลึกแค่ไหน

\[ \begin{aligned} f''(w)&=36w^2-24w-72,\\ f''(-2)&=144+48-72=120,\\ f''(0)&=-72,\\ f''(3)&=324-72-72=180,\\ f(-2)&=48+32-144=-64,\\ f(0)&=0,\\ f(3)&=243-108-324=-189. \end{aligned} \]

ความโค้งที่ $w=-2$ และ $w=3$ เป็นบวกทั้งคู่ สองจุดนี้จึงเป็นก้นหุบ ความโค้งที่ $w=0$ เป็นลบ จุดนี้จึงเป็นยอดเนินที่คั่นกลาง สองก้นหุบผ่านการตรวจเหมือนกันทุกข้อ คือความชันศูนย์และความโค้งบวก แต่หุบหนึ่งลึก −64 อีกหุบลึก −189 การตรวจที่ดูแค่รอบตัวจึงบอกไม่ได้ว่าหุบไหนดีกว่า

ยังเหลือคำถามหนึ่ง เรารู้ได้อย่างไรว่าไม่มีจุดที่ต่ำกว่า −189 ซ่อนอยู่ไกลออกไป วิธีคือดึง $w^2$ ออกมาเป็นตัวร่วม เพราะ $w^2$ ไม่เคยติดลบ เครื่องหมายของ $f$ จึงขึ้นกับวงเล็บที่เหลืออย่างเดียว แล้วเราดูวงเล็บนั้นที่ $w=\pm5$

\[ \begin{aligned} f(w)&=w^2\,(3w^2-4w-36),\\ w=5:&\quad 75-20-36=19\gt0,\\ w=-5:&\quad 75+20-36=59\gt0. \end{aligned} \]

วงเล็บ $3w^2-4w-36$ มีความชัน $6w-4$ ความชันนี้เป็นบวกเมื่อ $w\ge5$ และเป็นลบเมื่อ $w\le-5$ แปลว่าวงเล็บโตขึ้นเรื่อย ๆ เมื่อเดินออกไปทั้งสองฝั่ง ที่ $w=\pm5$ วงเล็บเป็นบวกแล้ว นอกช่วง −5 ถึง 5 วงเล็บจึงบวกตลอด และ $f$ ก็บวกตลอด ค่าบวกสู้ −189 ไม่ได้

ส่วนในช่วง −5 ถึง 5 จุดต่ำสุดต้องเป็นจุดราบ หรือไม่ก็ปลายช่วง ปลายช่วงให้ $f(5)=5^2\times19=475$ และ $f(-5)=5^2\times59=1{,}475$ ซึ่งสูงกว่า −189 มาก global minimum จึงเป็น $w=3$ แน่นอน

นี่คือใบรับรอง global แบบหนึ่ง หาจุดราบให้ครบ แล้วแสดงว่ากราฟเชิดขึ้นเมื่อออกไปไกล วิธีนี้ใช้ได้ที่นี่เพราะมีตัวแปรเดียวและมีสูตร กลยุทธ์จริงที่มี 20 parameter และไม่มีสูตร ทำแบบนี้ไม่ได้

ขั้นที่ 3 — นิยามคำว่าต่ำสุดสองระดับ

ตอนนี้เรามีตัวอย่างครบทั้งสองแบบแล้ว คือ $w=-2$ ที่ต่ำแค่รอบตัว และ $w=3$ ที่ต่ำที่สุดทั้งเส้น เราจึงเขียนนิยามให้ชัดได้ ให้ $x^\star$ คือจุดที่กำลังตรวจ และ $y$ คือจุดอื่นที่เอามาเทียบ นิยามทั้งสองต่างกันแค่ว่าเอา $x^\star$ ไปเทียบกับ $y$ ตัวไหนบ้าง

\[ \begin{aligned} \text{global}:&\quad f(y)\ge f(x^\star)\\ &\quad(\text{every allowed } y),\\ \text{local}:&\quad f(y)\ge f(x^\star)\\ &\quad(\text{allowed } y,\ \lVert y-x^\star\rVert\le r). \end{aligned} \]

global เทียบ $x^\star$ กับทุกจุดที่โจทย์อนุญาต local เทียบเฉพาะจุดที่ห่างจาก $x^\star$ ไม่เกินรัศมี $r$ โดย $r$ เป็นค่าบวกค่าหนึ่ง จะเล็กแค่ไหนก็ได้ พูดแบบชาวบ้าน local แปลว่าคลำรอบเท้าแล้วไม่มีอะไรต่ำกว่า global แปลว่าต่ำที่สุดในแผนที่ทั้งใบ

ลองใช้นิยามกับ $w=-2$ โดยให้ $r=1$ ซึ่งคือกรอบสีส้มในรูปแรก ช่วงที่ต้องตรวจคือ −3 ถึง −1 ในช่วงนี้มีจุดราบแค่ −2 จุดเดียว ส่วนปลายช่วงให้ $f(-3)=243+108-324=27$ และ $f(-1)=3+4-36=-29$ ซึ่งสูงกว่า −64 ทั้งคู่ $w=-2$ จึงเป็น local minimum

global ทุกจุดเป็น local ด้วย เพราะถ้าต่ำกว่าทุกจุด ก็ต่ำกว่าจุดใกล้ตัวแน่นอน แต่กลับกันไม่จริง $w=-2$ คือตัวอย่าง

ขั้นที่ 4 — ปล่อย gradient descent จากสองจุดเริ่ม

ตอนนี้เรารู้แล้วว่ามีสองหุบ คำถามต่อไปคือ ถ้าปล่อยให้คอมพิวเตอร์เดินเอง มันจะลงหุบไหน เราจะเดินตามมันทีละก้าวด้วยมือ

โจทย์ให้อะไรมาบ้าง:

  • กฎของ gradient descent คือ $w_{k+1}=w_k-\eta f'(w_k)$ โดย $w_k$ คือตำแหน่งหลังก้าวที่ $k$ กฎนี้ก้าวสวนความชัน ความชันบวกจึงพาไปทางซ้าย ความชันลบพาไปทางขวา
  • ขนาดก้าว $\eta=0.005$ (สมมติ) ใช้เท่ากันทั้งสองรอบ ก้าวจึงยาว $\eta$ คูณความชัน
  • รอบที่เริ่ม $w_0=-1$ เรียกว่ารอบ $a$ และรอบที่เริ่ม $w_0=+1$ เรียกว่ารอบ $b$
  • ความชัน $f'(w)=12w(w-3)(w+2)$ ที่แยกตัวประกอบไว้แล้วในขั้นที่ 1

ก้าวแรกของสองรอบเป็นแบบนี้

\[ \begin{aligned} f'(-1)&=12(-1)(-4)(1)=48,\\ a_1&=-1-0.005(48)=-1.24,\\ f'(1)&=12(1)(-2)(3)=-72,\\ b_1&=1-0.005(-72)=1.36. \end{aligned} \]

คำตอบ: ดูเครื่องหมายของความชันทีละช่วง

  • ระหว่าง −2 กับ 0 ตัวประกอบ $12w$ ลบ, $w-3$ ลบ และ $w+2$ บวก ผลคูณจึงบวกตลอด รอบ $a$ ถูกดันไปทางซ้ายทุกก้าว จึงไหลไปหา −2
  • ระหว่าง 0 กับ 3 ตัวประกอบ $12w$ บวก, $w-3$ ลบ และ $w+2$ บวก ผลคูณจึงลบตลอด รอบ $b$ ถูกดันไปทางขวาทุกก้าว จึงไหลไปหา 3

สันเขาที่ $w=0$ จึงเป็นเส้นแบ่ง ฝั่งไหนเริ่ม ก็ลงหุบฝั่งนั้น ตารางข้างล่างคือแปดก้าวแรก และก้าวที่ 40 ซึ่งคำนวณด้วยโค้ดท้ายหน้า

ใกล้ก้นหุบ ความชันเหลือน้อย ก้าวจึงสั้นลงเองโดยไม่ต้องสั่ง รอบ $b$ เข้าใกล้ก้นหุบเร็วกว่า เพราะหุบขวาโค้งแรงกว่า (ความโค้ง 180 เทียบกับ 120) เหตุผลคือ ใกล้ก้นหุบ $w^\star$ ความชันประมาณเท่ากับความโค้งคูณระยะห่างจากก้นหุบ แทนลงในกฎการเดิน ระยะห่างจึงถูกคูณด้วย $1-\eta f''$ ทุกก้าว

ขั้นที่ 5 — convexity: เส้นเชื่อมต้องไม่ต่ำกว่ากราฟ แล้วพื้นผิว backtest ก็สอบตก

ขั้นที่ 4 แสดงว่าถ้ากราฟมีหลายหุบ จุดเริ่มจะเป็นตัวเลือกหุบ และเราไม่มีทางรู้จากรอบตัวว่าได้หุบที่ดีที่สุดหรือยัง ปัญหานี้จะหายไปถ้ากราฟเป็นชามใบเดียว เราจึงต้องมีวิธีตรวจว่ากราฟเป็นชามใบเดียวไหม วิธีนั้นชื่อ convexity

ไอเดียคือ เลือกสองจุด $x$ กับ $y$ บนแกนนอน แล้วลากเส้นตรงเชื่อมจุด $(x, f(x))$ กับ $(y, f(y))$ บนกราฟ เส้นนี้เรียกว่า chord ตัวเลข $\alpha$ ระหว่าง 0 ถึง 1 บอกตำแหน่งระหว่างสองจุด $\alpha=1$ คือที่ $x$ และ $\alpha=0$ คือที่ $y$ function เรียกว่า convex เมื่อค่าจริงของกราฟ (ฝั่งซ้ายของอสมการข้างล่าง) ไม่เคยสูงกว่าค่าบน chord (ฝั่งขวา) ไม่ว่าเลือก $x$, $y$ และ $\alpha$ อะไร

ลองใช้นิยามนี้กับสองก้นหุบของกราฟ backtest ทันที ให้ $x=-2$, $y=3$ และ $\alpha=0.5$ จุดกึ่งกลางคือ $0.5(-2)+0.5(3)=0.5$

\[ \begin{aligned} &f\big(\alpha x+(1-\alpha)y\big)\\ &\quad\le\alpha f(x)+(1-\alpha)f(y),\\ \text{chord}&=0.5(-64)+0.5(-189)=-126.5,\\ f(0.5)&=3(0.0625)-4(0.125)-36(0.25)\\ &=0.1875-0.5-9=-9.3125,\\ f(0.5)-\text{chord}&=117.1875\gt0. \end{aligned} \]

ค่าบน chord ที่กึ่งกลางคือค่าเฉลี่ยของสองก้นหุบ ได้ −126.5 แต่กราฟจริงที่ $w=0.5$ อยู่ที่ −9.3125 ซึ่งสูงกว่า chord ถึง 117.1875 กราฟโผล่ขึ้นเหนือเส้นตรง เพราะระหว่างสองหุบมีสันเขาคั่นอยู่

คำว่า “ไม่ว่าเลือกคู่ไหน” ทำให้การยืนยันว่า convex ยาก เพราะต้องพิสูจน์ทุกคู่ แต่การหักล้างง่าย เจอคู่เดียวที่ไม่ผ่านก็พอ กราฟ backtest จึงไม่ convex อีกทางลัดหนึ่งคือ $f''(0)=-72$ ติดลบ กราฟที่คว่ำลงตรงไหนสักแห่งเป็น convex ไม่ได้

ขั้นที่ 6 — พิสูจน์: ถ้า convex หลุมใกล้ตัวทุกหลุมคือหลุมต่ำสุด และความชันศูนย์ก็พอ

ตอนนี้เรารู้วิธีตรวจว่ากราฟไม่ convex แล้ว แต่ทำไมเราอยากได้ convex นัก ขั้นนี้ตอบคำถามนั้น ถ้า function เป็น convex ก้นหลุมใกล้ตัวทุกหลุมคือก้นหลุมต่ำสุดของทั้งโจทย์ เราพิสูจน์ด้วยการสมมติตรงข้าม แล้วดูว่าขัดแย้ง

สมมติว่า $x^\star$ เป็น local minimum แต่มีจุด $y$ ที่โจทย์อนุญาตและต่ำกว่า คือ $f(y)\lt f(x^\star)$ เราเดินจาก $x^\star$ ไปหา $y$ ตามเส้นตรง ให้ $z(\alpha)$ คือจุดบนทางเดิน เมื่อ $\alpha=0$ อยู่ที่ $x^\star$ และเมื่อ $\alpha=1$ อยู่ที่ $y$ แล้วใช้นิยามของ convex ดูว่าค่าบนทางเดินเป็นอย่างไร

\[ \begin{aligned} z(\alpha)&=(1-\alpha)x^\star+\alpha y,\\ f\big(z(\alpha)\big)&\le(1-\alpha)f(x^\star)+\alpha f(y)\\ &=f(x^\star)+\alpha\big(f(y)-f(x^\star)\big)\\ &\lt f(x^\star)\quad(0\lt\alpha\le1),\\ \lVert z(\alpha)-x^\star\rVert&=\alpha\lVert y-x^\star\rVert. \end{aligned} \]

convex บอกว่าค่าบนทางเดินไม่สูงกว่า chord และ chord นี้เริ่มที่ $f(x^\star)$ แล้วลาดลงไปหา $f(y)$ ที่ต่ำกว่า ผลต่าง $f(y)-f(x^\star)$ ติดลบ ค่าบนทางเดินจึงต่ำกว่า $f(x^\star)$ ทันทีที่ก้าวออกมา ไม่ว่าก้าวสั้นแค่ไหน

อีกด้านหนึ่ง ระยะจาก $x^\star$ ถึง $z(\alpha)$ คือ $\alpha$ คูณระยะเต็ม ถ้าเลือก $\alpha$ เล็กพอ จุด $z(\alpha)$ ก็อยู่ในรัศมี $r$ จุดนั้นจึงทั้งใกล้ $x^\star$ และต่ำกว่า $x^\star$ ซึ่งขัดกับที่ว่า $x^\star$ ต่ำสุดรอบตัว ดังนั้นสมมติฐานว่ามี $y$ ที่ต่ำกว่าจึงผิด

การพิสูจน์นี้มีเงื่อนไขซ่อนอยู่ ทางเดินต้องอยู่ในเขตที่โจทย์อนุญาตตลอดทาง เขตแบบ “ลงเงินครบ 100%” ผ่าน เพราะผสมสองพอร์ตที่ลงเงินครบ ก็ยังได้พอร์ตที่ลงเงินครบ แต่เขตแบบ “ถือหุ้นไม่เกิน 30 ตัว” ไม่ผ่าน เพราะผสมสองพอร์ตที่ถือหุ้นคนละชุด อาจได้พอร์ตที่ถือเกิน 30 ตัว

ผลที่สองใช้บ่อยกว่า ถ้า function เป็น convex และเรียบ ความชันศูนย์อย่างเดียวก็ยืนยันว่าเป็น global ได้ ไม่ต้องดูความโค้ง ไม่ต้องดูที่ไกล ๆ เราได้ผลนี้จากนิยามเดิม โดยย้ายข้าง หารด้วย $\alpha$ แล้วให้ $\alpha$ เล็กลงจนเป็นศูนย์

\[ \begin{aligned} \frac{f\big(x+\alpha(y-x)\big)-f(x)}{\alpha}&\le f(y)-f(x),\\ \alpha\to0:\quad f'(x)\,(y-x)&\le f(y)-f(x),\\ f'(x^\star)=0:\quad f(y)&\ge f(x^\star). \end{aligned} \]

เศษส่วนทางซ้ายคือการขยับของค่า $f$ หารด้วยระยะที่ขยับ คือความชันจาก $x$ ไปทาง $y$ เมื่อ $\alpha$ หดเข้าหาศูนย์ เศษส่วนนี้กลายเป็น derivative จังหวะนี้ทำได้เพราะ $f$ เรียบ ผลที่ได้บอกว่าเส้นสัมผัสที่จุดใดก็ตามอยู่ใต้กราฟทั้งเส้น

ถ้าเส้นสัมผัสที่ $x^\star$ แบนราบ คือ $f'(x^\star)=0$ กราฟทั้งเส้นก็อยู่เหนือระดับ $f(x^\star)$ จุดนั้นจึงเป็น global ถ้ามีหลายตัวแปร $f'(x)(y-x)$ จะกลายเป็น $\nabla f(x)^{\mathsf T}(y-x)$ ซึ่งหน้า gradient และเงื่อนไขอันดับหนึ่ง จะสร้างให้

ขั้นที่ 7 — ทดสอบกับพอร์ตหุ้นและพันธบัตร: 0.0155 อยู่ใต้ 0.0250

ตอนนี้เปลี่ยนโจทย์ ผู้จัดการกองทุนมีเงินก้อนหนึ่ง จะแบ่งลงหุ้นกับพันธบัตร และอยากให้มูลค่าพอร์ตแกว่งน้อยที่สุด ตัววัดการแกว่งคือ variance ของผลตอบแทนพอร์ต (กำลังสองของความผันผวน) คำถามแรกคือ variance ของพอร์ตเป็นชามใบเดียวไหม ถ้าใช่ ทุกอย่างที่พิสูจน์ในขั้นที่ 6 ใช้ได้ทันที

โจทย์ให้อะไรมาบ้าง: แบบจำลองรายปีสมมติที่ใช้ทั้งบทนี้

  • ความผันผวนของหุ้น $\sigma_1=20\%$ ต่อปี
  • ความผันผวนของพันธบัตร $\sigma_2=10\%$ ต่อปี
  • correlation ของหุ้นกับพันธบัตร $\rho=0.30$ คือสองตัวมักขยับทางเดียวกันบ้าง แต่ไม่มาก (1 คือขยับตามกันเป๊ะ 0 คือไม่เกี่ยวกันเลย)
  • น้ำหนักพอร์ต $p=(p_1, p_2)$ คือสัดส่วนเงินในหุ้นและในพันธบัตร

สามตัวเลขแรกรวมกันเป็น covariance matrix $V$ ช่องทแยงคือ variance ของแต่ละตัว ช่องนอกทแยงคือ covariance $\rho\sigma_1\sigma_2$ ซึ่งวัดว่าสองตัวขยับไปด้วยกันแค่ไหน variance ของพอร์ตคือ $f(p)=p^{\mathsf T}Vp$ (ที่มาอยู่ในหน้า ความเสี่ยงของพอร์ต) เราทดสอบนิยาม convex ด้วยพอร์ตสุดขั้วสองพอร์ต คือหุ้นล้วน $x=(1, 0)$ กับพันธบัตรล้วน $y=(0, 1)$ ที่ $\alpha=0.5$ ซึ่งก็คือพอร์ตครึ่งต่อครึ่ง

\[ \begin{aligned} V_{11}&=0.20^2=0.04,\\ V_{22}&=0.10^2=0.01,\\ V_{12}&=0.30(0.20)(0.10)=0.006,\\ f(p)&=0.04p_1^2+0.012p_1p_2+0.01p_2^2,\\ f(1, 0)&=0.04,\quad f(0, 1)=0.01,\\ \text{chord}&=0.5(0.04)+0.5(0.01)=0.025,\\ f(0.5, 0.5)&=0.25\,(0.04+0.012+0.01)\\ &=0.0155. \end{aligned} \]

สูตร $f(p)$ ได้จากการกาง $p^{\mathsf T}Vp$ ออกเป็นสี่ช่องของ matrix ส่วน $f(0.5, 0.5)$ มีตัวคูณ $0.25$ เพราะทุกพจน์มีน้ำหนักคูณกันสองตัว และ $0.5\times0.5=0.25$

คำตอบ: ค่าจริงที่กึ่งกลางคือ 0.0155 อยู่ใต้ chord ที่ 0.025 นิยามจึงผ่านสำหรับคู่นี้ ถ้าแปลงกลับเป็นความผันผวน พอร์ตครึ่งต่อครึ่งมี $\sqrt{0.0155}\approx12.45\%$ แต่ chord ให้ $\sqrt{0.025}\approx15.81\%$ ช่องว่าง $0.025-0.0155=0.0095$ คือ variance ที่ลดได้จากการผสมสองสินทรัพย์ที่ไม่ได้ขยับไปด้วยกันเต็มที่

ตรวจเองใน 10 วินาที: พจน์กลางคือ $0.012=2\times0.006$ เพราะช่อง $V_{12}$ กับ $V_{21}$ เท่ากัน และถูกนับสองครั้ง ถ้าลืมคูณสองจะได้ $0.25\,(0.04+0.006+0.01)=0.0140$ แทน 0.0155

ขั้นที่ 8 — ช่องว่างมีสูตรปิด และไม่ติดลบกับทุกคู่

ขั้นที่ 7 ทดสอบได้แค่คู่เดียว แต่นิยาม convex ต้องผ่านทุกคู่ และทดสอบทีละคู่ไม่มีวันครบ โชคดีที่ $f(p)=p^{\mathsf T}Vp$ เป็นสูตรกำลังสอง เราจึงคำนวณช่องว่างระหว่าง chord กับกราฟเป็นสูตรทั่วไปได้ สำหรับพอร์ต $x$ และ $y$ ใด ๆ วิธีคือกางค่า $f$ ที่จุดผสม $z$ แล้วเอาไปลบออกจากค่าบน chord

\[ \begin{aligned} z&=\alpha x+(1-\alpha)y,\\ f(z)&=\alpha^2x^{\mathsf T}Vx+(1-\alpha)^2y^{\mathsf T}Vy\\ &\quad+2\alpha(1-\alpha)\,x^{\mathsf T}Vy,\\ \text{gap}&=\alpha f(x)+(1-\alpha)f(y)-f(z)\\ &=\alpha(1-\alpha)\big(x^{\mathsf T}Vx+y^{\mathsf T}Vy\big)\\ &\quad-2\alpha(1-\alpha)\,x^{\mathsf T}Vy\\ &=\alpha(1-\alpha)\,(x-y)^{\mathsf T}V(x-y). \end{aligned} \]

จังหวะสำคัญคือการลบ $f(z)$ ออกจาก chord ก้อนของ $x^{\mathsf T}Vx$ เหลือ $\alpha-\alpha^2=\alpha(1-\alpha)$ และก้อนของ $y^{\mathsf T}Vy$ เหลือ $(1-\alpha)-(1-\alpha)^2=\alpha(1-\alpha)$ เหมือนกันพอดี ทุกก้อนจึงมีตัวคูณร่วม $\alpha(1-\alpha)$ แล้วสามก้อนที่เหลือรวบเป็นรูปกำลังสองของผลต่าง $x-y$ ได้ เหมือน $u^2+v^2-2uv=(u-v)^2$

ตรวจกับพอร์ตครึ่งต่อครึ่งในขั้นที่ 7 ผลต่างคือ $x-y=(1, -1)$ จึงได้ $(x-y)^{\mathsf T}V(x-y)=0.04-0.012+0.01=0.038$ และช่องว่างคือ $0.25\times0.038=0.0095$ ตรงกับที่คำนวณไว้พอดี

ทำไมช่องว่างนี้ไม่ติดลบ $x-y$ ก็เป็นพอร์ตได้ คือพอร์ต long–short ที่ซื้อตามน้ำหนักของ $x$ และ short (ขายของที่ยืมมา) ตามน้ำหนักของ $y$ ค่า $(x-y)^{\mathsf T}V(x-y)$ คือ variance ของพอร์ตนั้น และ variance ไม่มีวันติดลบ ช่องว่างจึงไม่ติดลบกับทุกคู่และทุก $\alpha$ นี่คือการพิสูจน์ว่า variance ของพอร์ตเป็น convex ครบทุกคู่ ไม่ใช่แค่คู่ที่ลอง

ถ้าอยากได้มากกว่า “ไม่ติดลบ” เราใช้ eigenvalues ของ $V$ ได้ matrix ขนาด 2×2 มี eigenvalue สองค่า ผลบวกของสองค่านี้เท่ากับ trace (ผลรวมช่องทแยง) และผลคูณเท่ากับ determinant

\[ \begin{aligned} \lambda_1+\lambda_2&=0.04+0.01=0.05,\\ \lambda_1\lambda_2&=0.04(0.01)-0.006^2\\ &=0.000364. \end{aligned} \]

สองจำนวนที่รู้ผลบวกและผลคูณ คือรากของสมการกำลังสอง $\lambda^2-(\lambda_1+\lambda_2)\lambda+\lambda_1\lambda_2=0$ (กางวงเล็บ $(\lambda-\lambda_1)(\lambda-\lambda_2)$ ดูได้) เราจึงแก้ด้วยสูตรกำลังสองได้

\[ \begin{aligned} &\lambda^2-0.05\lambda+0.000364=0,\\ \lambda&=\frac{0.05\pm\sqrt{0.0025-0.001456}}{2}\\ &=\frac{0.05\pm0.0323110}{2},\\ \lambda_1&\approx0.0411555,\quad\lambda_2\approx0.0088445. \end{aligned} \]

eigenvalue ที่เล็กที่สุดเป็นเหมือนพื้นที่ variance ทะลุลงไปไม่ได้ variance ของพอร์ตใด ๆ ไม่ต่ำกว่า $\lambda_2$ คูณความยาวกำลังสองของน้ำหนัก คือ $p^{\mathsf T}Vp\ge\lambda_2\lVert p\rVert^2$ ในที่นี้ $\lambda_2\approx0.0088$ เป็นบวก ช่องว่างจึงเป็นบวกจริงทุกครั้งที่ $x\ne y$ ไม่ใช่แค่ไม่ติดลบ function แบบนี้เรียกว่า strictly convex ผลที่ได้คือ ถ้ามีจุดต่ำสุด จะมีจุดเดียว

ตรวจกับพอร์ต $(1, -1)$ ความยาวกำลังสองคือ $1^2+(-1)^2=2$ ขอบล่างจึงเป็น $0.0088445\times2=0.0177$ และ variance จริงของพอร์ตนี้คือ 0.038 ซึ่งไม่ต่ำกว่าขอบล่างจริง

ขั้นที่ 9 — ลงเงินครบ 100%: เริ่มที่ไหนก็จบที่หุ้น 10.53%

ตอนนี้เรารู้แล้วว่า variance ของพอร์ตเป็นชามใบเดียว ขั้นนี้หาก้นชามจริง ๆ และดูว่า gradient descent จากสองปลายจบที่เดียวกันจริงไหม

โจทย์ให้อะไรมาบ้าง:

  • ถ้าไม่มีข้อจำกัด variance ต่ำสุดคือไม่ถืออะไรเลย $p=(0, 0)$ ซึ่งไม่มีใครต้องการ โจทย์จึงบังคับให้ลงเงินครบ คือเงินทั้งก้อนต้องอยู่ในหุ้นหรือพันธบัตร ไม่เหลือเป็นเงินสด
  • ให้หุ้นได้น้ำหนัก $a$ และพันธบัตรได้ $1-a$ เขตที่อนุญาตจึงเป็นเส้นตรงเส้นเดียว ทางเดินในการพิสูจน์ของขั้นที่ 6 จึงอยู่ในเขตตลอด
  • gradient descent ใช้ขนาดก้าว $\eta=10$ (สมมติ) เริ่มสองรอบ จากหุ้น 100% ($a_0=1$) และจากหุ้น 0% ($a_0=0$)

เราแทน $p=(a, 1-a)$ ลงใน $f(p)$ จะได้ variance เป็น function ของ $a$ ตัวเดียว เรียกว่า $g(a)$ แล้วหาจุดที่ความชันเป็นศูนย์

\[ \begin{aligned} g(a)&=0.04a^2+0.012a(1-a)\\ &\quad+0.01(1-a)^2\\ &=0.038a^2-0.008a+0.01,\\ g'(a)&=0.076a-0.008=0,\\ a^\star&=\frac{0.008}{0.076}=\frac{2}{19}\approx0.105263,\\ g(a^\star)&=0.038(0.105263)^2\\ &\quad-0.008(0.105263)+0.01\\ &=0.000421-0.000842+0.01\\ &\approx0.0095789,\\ a_{k+1}&=a_k-10\,(0.076a_k-0.008)\\ &=0.24\,a_k+0.08,\\ a_{k+1}-a^\star&=0.24\,(a_k-a^\star). \end{aligned} \]

สมการของระยะห่าง $a_k-a^\star$ ได้จากการเอากฎการเดินลบด้วย $a^\star=0.24\,a^\star+0.08$ ซึ่งจริง เพราะ $0.24\times0.105263+0.08=0.105263$ คือก้นชามเป็นจุดที่เดินแล้วไม่ขยับ

คำตอบ: ก้นชามอยู่ที่หุ้น $a^\star=2/19\approx10.53\%$ และพันธบัตร $1-0.1053=89.47\%$ variance ต่ำสุดคือ 0.0095789 แปลงเป็นความผันผวนได้ $\sqrt{0.0095789}\approx9.787\%$ ซึ่งต่ำกว่าพันธบัตรล้วนที่ 10% เหตุผลคือหุ้นก้อนเล็ก ๆ ที่ correlation กับพันธบัตรแค่ 0.30 ช่วยกระจายความเสี่ยง

gradient descent จากสองปลายเดินแบบนี้

\[ \begin{aligned} a_0=1:&\quad0.24(1)+0.08=0.32,\\ &\quad0.24(0.32)+0.08=0.1568,\\ &\quad0.1176,\ \ldots\\ a_0=0:&\quad0.24(0)+0.08=0.08,\\ &\quad0.24(0.08)+0.08=0.0992,\\ &\quad0.1038,\ \ldots \end{aligned} \]

ทั้งสองรอบเข้าหา 0.105263 เพราะระยะห่างจากคำตอบถูกคูณด้วย 0.24 ทุกก้าว คือเหลือ 24% ของก้าวก่อน ไม่ว่าเริ่มที่ไหน

ตรวจเองใน 10 วินาที: ความโค้ง $g''=0.076$ เป็นบวก และ $0.076=2\times0.038$ คือสองเท่าของ variance ของพอร์ต long–short $(1, -1)$ จากสูตรช่องว่างในขั้นที่ 8 ค่า $\eta=10$ ดูใหญ่ แต่ต้องอ่านคู่กับความโค้ง ตัวคูณระยะห่างคือ $1-\eta g''=1-10\times0.076=0.24$ หน้า gradient descent และ Newton's method จะแสดงว่า $\eta g''$ ต้องน้อยกว่า 2 การเดินจึงไม่ระเบิด ที่นี่ $\eta g''=0.76$ จึงปลอดภัย

กับดัก: “converged” แปลว่ากฎการหยุดผ่าน ไม่ได้แปลว่าชนะทั้งแผนที่

ความผิดพลาดหลักคือเชื่อว่าโปรแกรมที่รายงาน “converged” ได้คำตอบที่ดีที่สุดแล้ว รอบ $a$ รายงานความชัน 0.00 ที่ $w=-2$ ถูกต้องทุกหลัก แต่ได้กำไรน้อยกว่าคำตอบจริงมาก

\[ \begin{aligned} \text{run }a:&\quad f(-2)=-64,\\ \text{best}:&\quad f(3)=-189,\\ \text{missed}:&\quad189-64=125. \end{aligned} \]

รอบ $a$ จึงพลาดกำไรไป \$125 ล้าน การตรวจว่า $f''\gt0$ ที่จุดที่ได้ก็พิสูจน์ได้แค่ local เหมือนกัน หุบซ้ายโค้งหงาย 120 การตรวจรอบตัวเห็นมันไม่ต่างจากหุบขวาเลย

ความผิดพลาดที่สองคือคิดว่าเริ่มฝั่งไหนก็ลงหุบฝั่งนั้นเสมอ จริง ๆ แล้วขนาดก้าวก็เลือกหุบได้ ถ้าเริ่มที่ $w=5.5$ ซึ่งอยู่ฝั่งขวาของสันเขา ก้าวแรกยาวจนข้ามสันไปฝั่งซ้าย

\[ \begin{aligned} f'(5.5)&=12(5.5)(2.5)(7.5)=1{,}237.5,\\ \eta f'(5.5)&=0.005\times1{,}237.5=6.1875,\\ w_1&=5.5-6.1875=-0.6875. \end{aligned} \]

$w_1$ อยู่ฝั่งซ้ายของสันแล้ว รอบนี้จึงไปจบที่ −2 ทั้งที่เริ่มฝั่งขวา แอ่งของ algorithm จึงไม่ใช่แอ่งของกราฟเสมอไป

ความผิดพลาดที่สามคือคิดว่า multi-start (รันซ้ำจากหลายจุดเริ่มแล้วเก็บผลดีที่สุด) เป็นใบรับรอง มันช่วยได้ แต่ไม่ได้พิสูจน์อะไร ลองสุ่มจุดเริ่มแบบสม่ำเสมอในช่วง −4 ถึง 5 ช่วงนี้ยาว 9 หน่วย ฝั่งลบยาว 4 หน่วย ถ้าใช้ function descend ในโค้ดท้ายหน้ารันที่ $\eta=0.005$ จะเห็นว่าจุดเริ่มฝั่งบวกทุกจุดในช่วงนี้ไหลไปหา 3 และฝั่งลบทุกจุดไหลไปหา −2 แต่ละครั้งจึงพลาดหุบขวาด้วยโอกาส 4/9 ถ้าสุ่มห้าครั้ง โอกาสที่ทั้งห้าครั้งตกฝั่งลบและพลาดหุบขวาคือ

\[\Big(\frac{4}{9}\Big)^5\approx0.0173=1.73\%.\]

แต่ในโจทย์จริงไม่มีใครรู้สัดส่วน 4/9 นี้ อีกทั้งการเลือกผลที่ดีที่สุดจากหลายรอบคือปัญหา multiple testing คือลองหลายครั้งแล้วเก็บแต่ผลที่สวย ผลที่ได้จึงสวยเกินจริง (overfitting)

ความผิดพลาดที่สี่คือเช็กแต่ objective แล้วลืมเช็กเขตที่อนุญาต variance เป็น convex ก็จริง แต่ถ้าเพิ่มกฎ “ถือหุ้นไม่เกิน 30 ตัว” แล้วผสมสองพอร์ตที่ถือ 30 ตัวคนละชุด อาจได้พอร์ตที่ถือ 60 ตัว ทางเดินในการพิสูจน์หลุดออกนอกเขต และหลายหุบก็กลับมา

ข้อสุดท้าย convex แต่ไม่ strictly convex ไม่รับประกันว่ามีคำตอบเดียว ถ้าสองสินทรัพย์มีความผันผวนเท่ากันและ correlation เป็น 1 ทุกส่วนผสมมี variance เท่ากันหมด พื้นจึงเป็นร่องแบน ค่าต่ำสุดมีค่าเดียว แต่ตำแหน่งที่ให้ค่านั้นมีไม่จำกัด

ใบรับรองว่าไม่มีอะไรต่ำกว่านี้ไกลออกไป: $h=w^2(3w^2-8w-18)$ ที่ $w=5$ วงเล็บเป็น $75-40-18=17$ ที่ $w=-5$ เป็น $75+40-18=97$ และวงเล็บโตต่อเมื่อออกไปทั้งสองฝั่ง global จึงเป็น $w=3$ ส่วน $w=-1$ เป็นแค่ local ที่ตื้นกว่า $135-7=128$ ล้านดอลลาร์

2. สมมติว่าหุ้นกับพันธบัตรเริ่มขยับตามกันแรงขึ้น correlation จึงเป็น $\rho=0.80$ แทน 0.30 ส่วนความผันผวนยังเท่าเดิม ($\sigma_1=20\%$, $\sigma_2=10\%$) พอร์ตที่ลงเงินครบและมี variance ต่ำสุดถือหุ้นเท่าไร?

เฉลย

ทำแบบขั้นที่ 9 แต่เปลี่ยน covariance ก่อน

\[ \begin{aligned} V_{12}&=0.8(0.2)(0.1)=0.016,\\ g(a)&=0.04a^2+0.032a(1-a)\\ &\quad+0.01(1-a)^2\\ &=0.018a^2+0.012a+0.01,\\ g'(a)&=0.036a+0.012=0,\\ a^\star&=-\frac{0.012}{0.036}=-\frac{1}{3},\\ g(a^\star)&=\frac{0.018}{9}-0.004+0.01\\ &=0.008. \end{aligned} \]

$a^\star=-1/3$ แปลว่า short หุ้น 33.3% แล้วเอาเงินนั้นไปถือพันธบัตร $1-(-1/3)=133.3\%$ variance 0.008 แปลงเป็นความผันผวนได้ $\sqrt{0.008}\approx8.944\%$ ซึ่งต่ำกว่าพันธบัตรล้วนที่ 10% เหตุผลคือ เมื่อสองตัวขยับตามกันแรง การ short ตัวที่แกว่งแรงกว่าช่วยหักล้างการแกว่งของอีกตัว โจทย์ยังเป็นชามใบเดียว เพราะความโค้ง $g''=0.036\gt0$

3. กลับไปที่กับดัก multi-start ทีมสุ่มจุดเริ่มแบบสม่ำเสมอในช่วง −4 ถึง 5 แต่ละครั้งพลาดหุบขวาด้วยโอกาส 4/9 ต้องสุ่มอย่างน้อยกี่จุด โอกาสที่จะพลาดหุบ $w=3$ ทุกครั้งจึงจะไม่เกิน 0.1%?

เฉลย

ให้ $n$ คือจำนวนจุดเริ่ม เราต้องการ $(4/9)^n\le0.001$ ใส่ log ทั้งสองข้าง แล้วหารด้วย $\ln(4/9)$ ซึ่งติดลบ เครื่องหมายอสมการจึงกลับข้าง

\[ \begin{aligned} n\ln\tfrac{4}{9}&\le\ln0.001,\\ n&\ge\frac{\ln0.001}{\ln(4/9)}=\frac{-6.9078}{-0.8109}\\ &\approx8.52. \end{aligned} \]

$n$ ต้องเป็นจำนวนเต็ม จึงต้อง 9 จุด ตรวจ: $(4/9)^9\approx0.00068$ ไม่เกิน 0.001 แต่ $(4/9)^8\approx0.00152$ ยังเกิน คำตอบนี้ใช้ได้เพราะเรารู้ว่าแอ่งขวากินสัดส่วน 5/9 ของช่วง ในโจทย์จริงไม่มีใครบอกสัดส่วนนี้

const loss = w => 3 * w ** 4 - 4 * w ** 3 - 36 * w ** 2;
const slope = w => 12 * w ** 3 - 12 * w ** 2 - 72 * w; // = 12w(w-3)(w+2)
const curvature = w => 36 * w * w - 24 * w - 72;
function descend(grad, start, eta, steps) {
  if (!(eta > 0)) throw new RangeError('Step size must be positive');
  const path = [start];
  for (let k = 0; k < steps; k++) {
    const next = path[k] - eta * grad(path[k]);
    if (!Number.isFinite(next)) throw new RangeError(`Diverged at step ${k + 1}`);
    path.push(next);
  }
  return path;
}
// Covariance of stocks (SD 20%) and bonds (SD 10%), correlation 0.30.

const quad = p => V[0][0] * p[0] ** 2 + 2 * V[0][1] * p[0] * p[1] + V[1][1] * p[1] ** 2;
// Chord minus curve at alpha*x + (1-alpha)*y; convexity needs this to be >= 0.
function chordGap(fn, x, y, alpha) {
  const z = Array.isArray(x) ? x.map((xi, i) => alpha * xi + (1 - alpha) * y[i]) : alpha * x + (1 - alpha) * y;
  return alpha * fn(x) + (1 - alpha) * fn(y) - fn(z);
}

สิ่งที่ควรตอบได้หลังอ่าน

  • local เทียบแค่จุดใกล้ตัว global เทียบทุกจุดที่โจทย์อนุญาต algorithm ที่ดูแค่ความชันรับประกันได้แค่ local ในหน้านี้ backtest เดียวกันได้กำไร \$64 ล้าน หรือ \$189 ล้าน ขึ้นกับจุดเริ่ม
  • ความชันศูนย์ให้รายชื่อผู้สมัคร ความโค้งแยกก้นหุบกับยอดเนิน แต่ไม่มีการตรวจรอบตัวแบบไหนบอกได้ว่าหุบไหนลึกที่สุด
  • convex แปลว่ากราฟไม่เคยโผล่ขึ้นเหนือ chord ไม่ว่าเลือกคู่ไหน ถ้าเขตที่อนุญาตก็ convex ด้วย ทุก local คือ global และความชันศูนย์ก็พอยืนยันคำตอบ
  • variance ของพอร์ตเป็น convex เพราะช่องว่างระหว่าง chord กับกราฟเท่ากับ $\alpha(1-\alpha)$ คูณ variance ของพอร์ต $x-y$ ซึ่งไม่ติดลบ พอร์ตหุ้นกับพันธบัตรที่ลงเงินครบจึงมีคำตอบเดียว คือหุ้น $2/19\approx10.53\%$
  • หักล้างว่าไม่ convex ใช้คู่เดียวก็พอ เช่นกึ่งกลางของกราฟ backtest ที่สูงกว่า chord 117.1875 แต่การยืนยันว่า convex ต้องพิสูจน์ทุกคู่
