12.1 Global vs Local Minima

optimizer มองเห็นแค่พื้นรอบเท้า จึงรับประกันได้แค่ก้นหลุมที่ใกล้ที่สุด ยกเว้นเมื่อโจทย์เป็นชามใบเดียวแบบ convex ซึ่ง variance ของพอร์ตเป็นแบบนั้นพอดี

ทีม quant ปรับน้ำหนักสัญญาณ $w$ ของกลยุทธ์หนึ่งด้วย gradient descent บนผลขาดทุนย้อนหลังสมมติ $f(w)=3w^4-4w^3-36w^2$ หน่วยล้านดอลลาร์ (ค่าติดลบคือกำไร) รันโค้ดเดิมกับข้อมูลเดิมสองรอบ รอบแรกเริ่มที่ $w=-1$ รอบสองเริ่มที่ $w=+1$ ทั้งสองรอบรายงานว่า “converged, slope = 0” เพื่อนร่วมทีมบอกว่าเลือกรอบไหนก็ได้ เพราะ optimizer ยืนยันแล้วทั้งคู่ จริงไหม?

ลองตอบก่อนเปิดเฉลย

ไม่จริง รอบแรกหยุดที่ $w=-2$ กำไร \$64 ล้าน รอบสองหยุดที่ $w=3$ กำไร \$189 ล้าน ต่างกัน \$125 ล้าน จากจุดเริ่มอย่างเดียว ทั้งสองจุดมีความชันศูนย์และโค้งหงาย คือผ่านทุกการตรวจที่ทำได้รอบตัว แต่มีแค่ $w=3$ ที่ต่ำสุดทั้งเส้น ตรงข้ามกับโจทย์ลด variance ของพอร์ตหุ้นกับพันธบัตรที่ลงเงินครบในหน้านี้ ซึ่งเริ่มที่หุ้น 0% หรือ 100% ก็จบที่หุ้น 10.53% เหมือนกัน เพราะมันเป็นชามใบเดียว

ภาพรวมก่อนลงสูตร

optimizer ทุกตัวทำงานเหมือนคนเดินลงเขาตอนหมอกลง มันวัดได้แค่ความชันและความโค้งใต้เท้า แล้วก้าวไปทางที่ต่ำลง พอพื้นราบทุกทิศมันก็หยุด จุดที่หยุดจึงรับประกันได้แค่ว่า “รอบ ๆ ตัวไม่มีที่ต่ำกว่า” ซึ่งเรียกว่า local minimum ส่วนสิ่งที่เราต้องการจริงคือ “ทั้งแผนที่ไม่มีที่ต่ำกว่า” ซึ่งเรียกว่า global minimum

รูปด้านล่างคือพื้นผิว backtest ของโจทย์เปิดเรื่อง มีสองหุบคั่นด้วยสันเขาที่ $w=0$ ถ้ามองแค่ในกรอบสีส้มรอบ $w=-2$ จุดนั้นต่ำที่สุดแน่นอน แต่ออกนอกกรอบไปทางขวามีหุบที่ลึกกว่าอีก 125 และไม่มีการตรวจรอบตัวแบบไหนมองเห็นหุบนั้นได้

หน้านี้หาจุดราบด้วยมือ ปล่อย gradient descent ให้เห็นว่าจุดเริ่มเป็นตัวเลือกหุบ นิยามสองคำนี้ให้เป๊ะ แล้วหาเงื่อนไขที่ทำให้ปัญหาหายไปทั้งหมด คือ convexity: ถ้าพื้นผิวเป็นชามใบเดียว หลุมใกล้ตัวทุกหลุมคือหลุมต่ำสุด และความชันศูนย์ก็พอจะยืนยันคำตอบ เราจะพิสูจน์ว่า variance ของพอร์ตเป็นชามแบบนั้น และใช้นิยามเดียวกันจับได้ว่าพื้นผิว backtest ไม่ใช่

ขั้นที่ 1 — หาจุดที่พื้นราบของ backtest

ก่อนจะถามว่าจุดไหนต่ำสุด ต้องมีรายชื่อผู้สมัครก่อน ถ้าความชันที่จุดหนึ่งไม่เป็นศูนย์ ก้าวสวนความชันนิดเดียวก็ได้ค่าต่ำลง จุดต่ำสุดที่อยู่กลางพื้นผิวเรียบจึงต้องมีความชันศูนย์ เราหา derivative แล้วแยกตัวประกอบ

\[ \begin{aligned} f'(w)&=12w^3-12w^2-72w\\ &=12w\,(w^2-w-6)\\ &=12w\,(w-3)(w+2),\\ f'(w)=0:&\quad w=-2,\ 0,\ 3. \end{aligned} \]

ทุกพจน์ของ $f'$ มี $w$ อย่างน้อยหนึ่งตัว จึงดึง $12w$ ออกมาได้ วงเล็บที่เหลือต้องการสองจำนวนที่คูณกันได้ −6 และบวกกันได้ −1 คือ −3 กับ +2 ผลคูณเป็นศูนย์เมื่อตัวใดตัวหนึ่งเป็นศูนย์ จึงได้ผู้สมัครสามตัวโดยไม่ต้องแก้สมการกำลังสามตรง ๆ

ตัวเลข 3, −4, −36 ถูกเลือกให้รากลงตัวจนคิดมือได้ พื้นผิวของกลยุทธ์จริงไม่มีสูตร มันคือผล backtest ทีละค่า แต่มีหลายหุบได้แบบเดียวกัน

ขั้นที่ 2 — จัดประเภทสามจุด และพิสูจน์ว่าไม่มีอะไรต่ำกว่า −189

ความชันศูนย์เกิดได้ทั้งที่ก้นหุบและบนยอดเนิน ตัวแยกคือความโค้ง $f''$: บวกแปลว่ากราฟหงายเป็นก้นหุบ ลบแปลว่ากราฟคว่ำเป็นยอดเนิน (เหตุผลเต็มอยู่ในหน้า Hessian และเงื่อนไขอันดับสอง) จากนั้นแทนค่ากลับเข้า $f$ เพื่อวัดความลึก

\[ \begin{aligned} f''(w)&=36w^2-24w-72,\\ f''(-2)&=144+48-72=120,\\ f''(0)&=-72,\\ f''(3)&=324-72-72=180,\\ f(-2)&=48+32-144=-64,\\ f(0)&=0,\\ f(3)&=243-108-324=-189. \end{aligned} \]

$w=-2$ กับ $w=3$ เป็นก้นหุบทั้งคู่ ส่วน $w=0$ เป็นยอดเนินที่คั่นกลาง สองก้นหุบผ่านเงื่อนไขความชันและความโค้งเหมือนกันทุกประการ แต่ลึก −64 กับ −189 นี่คือเหตุที่การตรวจรอบตัวแยกสองหุบไม่ออก

แต่จะรู้ได้อย่างไรว่าไม่มีจุดที่ต่ำกว่า −189 ซ่อนอยู่ไกลออกไป ดึง $w^2$ ออกเป็นตัวร่วมแล้วดูเครื่องหมายของวงเล็บที่เหลือ

\[ \begin{aligned} f(w)&=w^2\,(3w^2-4w-36),\\ w=5:&\quad 75-20-36=19\gt0,\\ w=-5:&\quad 75+20-36=59\gt0. \end{aligned} \]

วงเล็บมีความชัน $6w-4$ ซึ่งบวกเมื่อ $w\ge5$ และลบเมื่อ $w\le-5$ วงเล็บจึงโตขึ้นเรื่อย ๆ เมื่อเดินออกไปทั้งสองฝั่ง นอกช่วง −5 ถึง 5 ทุกค่าของ $f$ จึงเป็นบวก สู้ −189 ไม่ได้ ในช่วงนั้นจุดต่ำสุดต้องเป็นจุดราบหรือปลายช่วง และปลายช่วงให้ $f(5)=475$ กับ $f(-5)=1{,}475$ คำตอบ global จึงเป็น $w=3$ แน่นอน

นี่คือใบรับรอง global แบบหนึ่ง: หาจุดราบให้ครบ แล้วแสดงว่าพื้นผิวเชิดขึ้นเมื่อออกไปไกล ใช้ได้ที่นี่เพราะมีตัวแปรเดียวและมีสูตร โจทย์ 20 parameter ที่ไม่มีสูตรทำแบบนี้ไม่ได้

ขั้นที่ 3 — นิยามคำว่าต่ำสุดสองระดับ

ตอนนี้เรามีตัวอย่างครบทั้งสองแบบแล้ว จึงเขียนนิยามให้เป๊ะได้ สองบรรทัดนี้เป็นนิยาม ต่างกันแค่ว่าเอา $x^\star$ ไปเทียบกับจุดไหนบ้าง

\[ \begin{aligned} \text{global}:&\quad f(y)\ge f(x^\star)\\ &\quad(\text{every allowed } y),\\ \text{local}:&\quad f(y)\ge f(x^\star)\\ &\quad(\text{allowed } y,\ \lVert y-x^\star\rVert\le r). \end{aligned} \]

global เทียบกับทุกจุดที่โจทย์อนุญาต local เทียบเฉพาะจุดที่ห่างจาก $x^\star$ ไม่เกินรัศมี $r$ ซึ่งเป็นบวกค่าหนึ่ง เล็กแค่ไหนก็ได้ ภาษาชาวบ้านคือ local แปลว่าคลำรอบเท้าแล้วไม่มีอะไรต่ำกว่า global แปลว่าต่ำที่สุดในแผนที่ทั้งใบ

$w=-2$ เป็น local ด้วย $r=1$ ซึ่งคือกรอบสีส้มในรูปภาพรวม: ในช่วง −3 ถึง −1 จุดราบมีแค่ −2 และปลายช่วงให้ $f(-3)=27$ กับ $f(-1)=-29$ สูงกว่า −64 ทั้งคู่ ทุก global เป็น local ด้วย แต่กลับกันไม่จริง

ขั้นที่ 4 — ปล่อย gradient descent จากสองจุดเริ่ม

โจทย์ให้อะไรมาบ้าง: กฎของ gradient descent คือก้าวสวนความชัน $w_{k+1}=w_k-\eta f'(w_k)$ ใช้ $\eta=0.005$ เท่ากันทั้งสองรอบ เรียกรอบที่เริ่ม −1 ว่า $a$ และรอบที่เริ่ม +1 ว่า $b$ ใช้ $f'(w)=12w(w-3)(w+2)$ ที่แยกตัวประกอบไว้แล้ว

\[ \begin{aligned} f'(-1)&=12(-1)(-4)(1)=48,\\ a_1&=-1-0.005(48)=-1.24,\\ f'(1)&=12(1)(-2)(3)=-72,\\ b_1&=1-0.005(-72)=1.36. \end{aligned} \]

คำตอบ: ความชันบวกสั่งให้ถอยซ้าย ความชันลบสั่งให้เดินขวา ระหว่าง −2 กับ 0 ความชันเป็นบวกตลอด (ตัวประกอบ $12w$ ลบ, $w-3$ ลบ, $w+2$ บวก) รอบ $a$ จึงไหลซ้ายไปหา −2 ระหว่าง 0 กับ 3 ความชันเป็นลบตลอด รอบ $b$ จึงไหลขวาไปหา 3 สันเขาที่ $w=0$ คือเส้นแบ่ง ตารางคือแปดก้าวแรก

ขั้นที่ 5 — convexity: เส้นเชื่อมต้องไม่ต่ำกว่ากราฟ แล้วพื้นผิว backtest ก็สอบตก

ปัญหาหลายหุบจะหายไปถ้าพื้นผิวผ่านเงื่อนไขหนึ่ง บรรทัดแรกเป็นนิยามของเงื่อนไขนั้น แล้วลองใช้กับสองก้นหุบของพื้นผิว backtest ทันที คือ $x=-2$, $y=3$ ที่ $\alpha=0.5$ ซึ่งให้จุดกึ่งกลาง $0.5(-2)+0.5(3)=0.5$

\[ \begin{aligned} &f\big(\alpha x+(1-\alpha)y\big)\\ &\quad\le\alpha f(x)+(1-\alpha)f(y),\\ \text{chord}&=0.5(-64)+0.5(-189)=-126.5,\\ f(0.5)&=0.1875-0.5-9=-9.3125,\\ f(0.5)-\text{chord}&=117.1875\gt0. \end{aligned} \]

เลือกสองจุดบนกราฟ ลากเส้นตรงเชื่อมกัน (chord) $\alpha$ บอกตำแหน่งบนเส้น: $\alpha=1$ อยู่ที่ $x$, $\alpha=0$ อยู่ที่ $y$ ฝั่งซ้ายของนิยามคือค่าจริงของ function ฝั่งขวาคือค่าบนเส้นตรง function จะ convex ก็ต่อเมื่อกราฟไม่โผล่ขึ้นเหนือเส้นตรง ไม่ว่าเลือกคู่ไหนและ $\alpha$ เท่าไร

คำว่า “ทุกคู่” ทำให้พิสูจน์ยาก แต่หักล้างง่าย คู่เดียวก็พอ พื้นผิว backtest ที่กึ่งกลางสูงกว่าเส้นเชื่อมถึง 117.1875 จึงไม่ convex ทางลัดอีกทางคือ $f''(0)=-72$ ติดลบ กราฟที่คว่ำลงตรงไหนสักแห่งเป็น convex ไม่ได้

ขั้นที่ 6 — พิสูจน์: ถ้า convex หลุมใกล้ตัวทุกหลุมคือหลุมต่ำสุด และความชันศูนย์ก็พอ

สมมติว่า $x^\star$ เป็น local minimum แต่มีจุด $y$ ที่อนุญาตและต่ำกว่า เดินจาก $x^\star$ ไปหา $y$ ตามเส้นตรง แล้วใช้นิยามของ convex ดูว่าค่าบนทางเดินเป็นอย่างไร

\[ \begin{aligned} z(\alpha)&=(1-\alpha)x^\star+\alpha y,\\ f\big(z(\alpha)\big)&\le(1-\alpha)f(x^\star)+\alpha f(y)\\ &=f(x^\star)+\alpha\big(f(y)-f(x^\star)\big)\\ &\lt f(x^\star)\quad(0\lt\alpha\le1),\\ \lVert z(\alpha)-x^\star\rVert&=\alpha\lVert y-x^\star\rVert. \end{aligned} \]

บรรทัดที่สามจัดรูปให้เห็นว่าค่าบนทางเดินคือค่าที่ $x^\star$ บวก $\alpha$ คูณผลต่าง ซึ่งผลต่างติดลบเพราะ $y$ ต่ำกว่า ค่าจึงลดลงทันทีที่ก้าวออกจาก $x^\star$ บรรทัดสุดท้ายบอกว่าเลือก $\alpha$ เล็กพอ จุดบนทางเดินก็อยู่ในรัศมี $r$ ได้ จุดนั้นทั้งใกล้และต่ำกว่า $x^\star$ ขัดกับที่ว่า $x^\star$ ต่ำสุดรอบตัว สมมติฐานว่ามี $y$ ที่ต่ำกว่าจึงผิด

เงื่อนไขที่ซ่อนอยู่คือทางเดินต้องอยู่ในเขตที่อนุญาตตลอด เขตแบบ “ลงเงินครบ 100%” ผ่าน เพราะจุดผสมของสองพอร์ตที่ลงเงินครบก็ลงเงินครบ แต่เขตแบบ “ถือไม่เกิน 30 ตัว” ไม่ผ่าน

ผลที่สองใช้บ่อยกว่า: สำหรับ function convex ที่เรียบ ความชันศูนย์อย่างเดียวก็ยืนยัน global ได้ ย้ายข้างนิยามเดิม หารด้วย $\alpha$ แล้วให้ $\alpha$ เล็กลงจนเป็นศูนย์

\[ \begin{aligned} \frac{f\big(x+\alpha(y-x)\big)-f(x)}{\alpha}&\le f(y)-f(x),\\ \alpha\to0:\quad f'(x)\,(y-x)&\le f(y)-f(x),\\ f'(x^\star)=0:\quad f(y)&\ge f(x^\star). \end{aligned} \]

ฝั่งซ้ายของบรรทัดแรกคือความชันของเส้นตัดจาก $x$ ไปทาง $y$ เมื่อ $\alpha$ หดลง มันกลายเป็น derivative บรรทัดที่สองจึงบอกว่าเส้นสัมผัสที่จุดใดก็ตามอยู่ใต้กราฟทั้งเส้น ถ้าเส้นสัมผัสที่ $x^\star$ แบนราบ กราฟทั้งเส้นก็อยู่เหนือระดับ $f(x^\star)$ ในหลายตัวแปร $f'(x)(y-x)$ กลายเป็น $\nabla f(x)^{\mathsf T}(y-x)$ ซึ่งหน้า gradient และเงื่อนไขอันดับหนึ่ง จะสร้าง

ขั้นที่ 7 — ทดสอบกับพอร์ตหุ้นและพันธบัตร: 0.0155 อยู่ใต้ 0.0250

โจทย์ให้อะไรมาบ้าง: แบบจำลองรายปีสมมติที่ใช้ทั้งบทนี้ หุ้นมีความผันผวน 20% พันธบัตร 10% correlation 0.30 objective คือ variance ของพอร์ต $f(p)=p^{\mathsf T}Vp$ (ความเสี่ยงของพอร์ต: variance ของผลรวมถ่วงน้ำหนักคือ $p^{\mathsf T}Vp$) ทดสอบนิยามด้วยพอร์ตสุดขั้วสองพอร์ต คือหุ้นล้วน $x=(1, 0)$ กับพันธบัตรล้วน $y=(0, 1)$ ที่ $\alpha=0.5$

\[ \begin{aligned} V_{11}&=0.20^2=0.04,\\ V_{22}&=0.10^2=0.01,\\ V_{12}&=0.30(0.20)(0.10)=0.006,\\ f(p)&=0.04p_1^2+0.012p_1p_2+0.01p_2^2,\\ \text{chord}&=0.5(0.04)+0.5(0.01)=0.025,\\ f(0.5, 0.5)&=0.25\,(0.04+0.012+0.01)\\ &=0.0155. \end{aligned} \]

คำตอบ: ค่าจริงที่กึ่งกลาง 0.0155 อยู่ใต้เส้นตรง 0.0250 นิยามผ่านสำหรับคู่นี้ ในหน่วยความผันผวน พอร์ตครึ่งต่อครึ่งมี $\sqrt{0.0155}\approx12.45\%$ ขณะที่เส้นตรงให้ $\sqrt{0.025}\approx15.81\%$ ส่วนต่าง 0.0095 คือ variance ที่ลดได้จากการผสมสองสินทรัพย์ที่ไม่ขยับไปด้วยกันเต็มที่

ตรวจเองใน 10 วินาที: พจน์กลาง $0.012=2\times0.006$ เพราะช่อง $V_{12}$ กับ $V_{21}$ เท่ากันและถูกนับสองครั้ง ถ้าลืมคูณสองจะได้ 0.0140 แทน 0.0155

ขั้นที่ 8 — ช่องว่างมีสูตรปิด และไม่ติดลบกับทุกคู่

ทดสอบทีละคู่ไม่มีวันครบ แต่ objective กำลังสอง $f(p)=p^{\mathsf T}Vp$ ให้เราคำนวณช่องว่างเป็นสูตรทั่วไปได้ กางค่าที่จุดผสม $z$ แล้วลบออกจากค่าบนเส้นตรง

\[ \begin{aligned} z&=\alpha x+(1-\alpha)y,\\ f(z)&=\alpha^2x^{\mathsf T}Vx+(1-\alpha)^2y^{\mathsf T}Vy\\ &\quad+2\alpha(1-\alpha)\,x^{\mathsf T}Vy,\\ \text{gap}&=\alpha f(x)+(1-\alpha)f(y)-f(z)\\ &=\alpha(1-\alpha)\big(x^{\mathsf T}Vx+y^{\mathsf T}Vy\big)\\ &\quad-2\alpha(1-\alpha)\,x^{\mathsf T}Vy\\ &=\alpha(1-\alpha)\,(x-y)^{\mathsf T}V(x-y). \end{aligned} \]

จังหวะสำคัญคือ $\alpha-\alpha^2=\alpha(1-\alpha)$ และ $(1-\alpha)-(1-\alpha)^2=\alpha(1-\alpha)$ ทุกก้อนจึงมีตัวคูณร่วม แล้วสามก้อนในวงเล็บรวบเป็นกำลังสองของผลต่าง ตรวจกับพอร์ตครึ่งต่อครึ่งที่เพิ่งคำนวณ: $x-y=(1, -1)$ ให้ $0.04-0.012+0.01=0.038$ คูณ $0.25$ ได้ 0.0095 พอดี

$(x-y)^{\mathsf T}V(x-y)$ คือ variance ของพอร์ต long–short $x-y$ ซึ่งติดลบไม่ได้ ช่องว่างจึงไม่ติดลบกับทุกคู่และทุก $\alpha$ นี่คือการพิสูจน์ว่า variance ของพอร์ตเป็น convex ครบทุกคู่ ไม่ใช่แค่คู่ที่ลอง

ถ้าอยากได้มากกว่า “ไม่ติดลบ” ใช้ eigenvalues ของ $V$: ผลบวกของสอง eigenvalues คือ trace $0.04+0.01=0.05$ ผลคูณคือ determinant $0.04(0.01)-0.006^2=0.000364$ สองค่านี้จึงเป็นรากของสมการกำลังสอง

\[ \begin{aligned} &\lambda^2-0.05\lambda+0.000364=0,\\ \lambda&=\frac{0.05\pm\sqrt{0.0025-0.001456}}{2}\\ &=\frac{0.05\pm0.0323110}{2},\\ \lambda_1&\approx0.0411555,\quad\lambda_2\approx0.0088445. \end{aligned} \]

eigenvalue ที่เล็กที่สุดบอกว่า variance ของพอร์ตใด ๆ ไม่ต่ำกว่า $\lambda_2$ คูณความยาวกำลังสองของน้ำหนัก เมื่อ $\lambda_2\gt0$ ช่องว่างเป็นบวกจริงทุกครั้งที่ $x\ne y$ เรียกว่า strictly convex ผลที่ได้คือถ้ามีจุดต่ำสุด จะมีจุดเดียว ตรวจ: $(1, -1)$ ยาวกำลังสอง 2 และ $0.0088445\times2=0.0177$ ไม่เกิน 0.038 จริง

ขั้นที่ 9 — ลงเงินครบ 100%: เริ่มที่ไหนก็จบที่หุ้น 10.53%

โจทย์ให้อะไรมาบ้าง: ถ้าไม่มีข้อจำกัด variance ต่ำสุดคือไม่ถืออะไรเลย $p=(0, 0)$ ซึ่งไม่ใช่คำตอบที่ใครต้องการ จึงบังคับให้ลงเงินครบ ให้หุ้น $a$ และพันธบัตร $1-a$ เขตที่อนุญาตเป็นเส้นตรง ทางเดินในการพิสูจน์ว่า local คือ global จึงอยู่ในเขตตลอด แล้วปล่อย gradient descent บนเส้นนี้ด้วย $\eta=10$ จากหุ้น 100% และหุ้น 0%

\[ \begin{aligned} g(a)&=0.04a^2+0.012a(1-a)\\ &\quad+0.01(1-a)^2\\ &=0.038a^2-0.008a+0.01,\\ g'(a)&=0.076a-0.008=0,\\ a^\star&=\frac{0.008}{0.076}=\frac{2}{19}\approx0.105263,\\ g(a^\star)&\approx0.0095789,\\ a_{k+1}&=a_k-10\,g'(a_k)=0.24\,a_k+0.08,\\ a_{k+1}-a^\star&=0.24\,(a_k-a^\star). \end{aligned} \]

คำตอบ: หุ้น 10.53% พันธบัตร 89.47% variance 0.0095789 หรือความผันผวน $\sqrt{0.0095789}\approx9.787\%$ ต่ำกว่าพันธบัตรล้วนที่ 10% เพราะหุ้นก้อนเล็กที่ correlation แค่ 0.30 ช่วยกระจาย รอบที่เริ่มหุ้น 100% เดิน 0.32, 0.1568, 0.1176, … รอบที่เริ่มหุ้น 0% เดิน 0.08, 0.0992, 0.1038, … ทั้งสองเข้าหา 0.105263 เพราะระยะห่างจากคำตอบหดเหลือ 24% ทุกก้าว ไม่ว่าเริ่มที่ไหน

ตรวจเองใน 10 วินาที: $g''=0.076$ เป็นบวก และเท่ากับ $2\times0.038$ คือสองเท่าของ variance ของพอร์ต long–short $(1, -1)$ จากสูตรช่องว่าง ส่วน $0.24\times0.105263+0.08=0.105263$ คือจุดนิ่งของกฎการเดิน ค่า $\eta=10$ ดูใหญ่แต่ต้องอ่านคู่กับความโค้ง: $10\times0.076=0.76$ ซึ่งหน้า gradient descent และ Newton's method จะแสดงว่าต้องน้อยกว่า 2 จึงไม่ระเบิด

กับดัก: “converged” แปลว่ากฎการหยุดผ่าน ไม่ได้แปลว่าชนะทั้งแผนที่

รอบ $a$ รายงานความชัน 0.00 ที่ $w=-2$ ถูกต้องทุกหลัก แต่แย่กว่าคำตอบจริง \$125 ล้าน การเห็น $f''\gt0$ ที่จุดที่ได้ก็พิสูจน์แค่ local เช่นกัน หุบซ้ายโค้งหงาย 120 ไม่ต่างจากหุบขวาเลยในสายตาของการตรวจรอบตัว

แอ่งของ algorithm ไม่ใช่แอ่งของพื้นผิวเสมอไป ถ้าเริ่มที่ $w=5.5$ ซึ่งอยู่ฝั่งขวาของสันเขา ความชันคือ 1,237.5 ก้าวแรกยาว $0.005\times1{,}237.5=6.1875$ พาไปที่ −0.6875 ข้ามสันไปฝั่งซ้าย แล้วจบที่ −2 ขนาดก้าวก็เลือกหุบได้

multi-start ช่วยได้แต่ไม่ใช่ใบรับรอง ถ้าสุ่มจุดเริ่มสม่ำเสมอในช่วง −4 ถึง 5 จุดเริ่มฝั่งบวกทุกจุดไหลไปหา 3 (ตรวจด้วยโค้ดท้ายหน้าที่ $\eta=0.005$) โอกาสพลาดหุบขวาทั้งห้าครั้งคือ $(4/9)^5\approx1.73\%$ แต่ในโจทย์จริงไม่มีใครรู้สัดส่วน 4/9 นี้ และการเลือกผลที่ดีที่สุดจากหลายรอบคือปัญหา multiple testing ที่ทำให้ backtest สวยเกินจริง (overfitting)

เช็กแต่ objective แล้วลืมเช็กเขตที่อนุญาตก็พังได้ variance เป็น convex ก็จริง แต่ถ้าเพิ่มกฎ “ถือไม่เกิน 30 ตัว” จุดผสมของสองพอร์ตที่ถือ 30 ตัวคนละชุดอาจถือ 60 ตัว ทางเดินในการพิสูจน์หลุดเขต และหลายหุบกลับมา สุดท้าย convex แต่ไม่ strictly convex ก็ไม่รับประกันคำตอบเดียว: ถ้าสองสินทรัพย์มีความผันผวนเท่ากันและ correlation 1 ทุกส่วนผสมมี variance เท่ากันหมด พื้นเป็นร่องแบน ค่าต่ำสุดมีค่าเดียวแต่ตำแหน่งมีไม่จำกัด

  for (let k = 0; k < steps; k++) {
    const next = path[k] - eta * grad(path[k]);
    if (!Number.isFinite(next)) throw new RangeError(`Diverged at step ${k + 1}`);
    path.push(next);
  }
  return path;
}
// Covariance of stocks (SD 20%) and bonds (SD 10%), correlation 0.30.
const V = [[0.04, 0.006], [0.006, 0.01]];
const quad = p => V[0][0] * p[0] ** 2 + 2 * V[0][1] * p[0] * p[1] + V[1][1] * p[1] ** 2;
// Chord minus curve at alpha*x + (1-alpha)*y; convexity needs this to be >= 0.
function chordGap(fn, x, y, alpha) {
  const z = Array.isArray(x) ? x.map((xi, i) => alpha * xi + (1 - alpha) * y[i]) : alpha * x + (1 - alpha) * y;
  return alpha * fn(x) + (1 - alpha) * fn(y) - fn(z);
}
const half = (V[0][0] + V[1][1]) / 2, r = Math.hypot((V[0][0] - V[1][1]) / 2, V[0][1]);
const bend = V[0][0] + V[1][1] - 2 * V[0][1];       // variance of (stock - bond)
const aStar = (V[1][1] - V[0][1]) / bend;           // 2/19
const budgetSlope = a => 2 * bend * a - 2 * (V[1][1] - V[0][1]);
const runA = descend(slope, -1, 0.005, 40), runB = descend(slope, 1, 0.005, 40);

สิ่งที่ควรตอบได้หลังอ่าน

  • local เทียบแค่จุดใกล้ตัว global เทียบทุกจุดที่อนุญาต algorithm ที่ดูแค่ความชันรับประกันได้แค่ local: backtest เดียวกันได้ \$64 ล้าน หรือ \$189 ล้าน ตามจุดเริ่ม
  • ความชันศูนย์ให้ผู้สมัคร ความโค้งแยกหุบกับยอด แต่ไม่มีการตรวจรอบตัวแบบไหนบอกได้ว่าหุบไหนลึกที่สุด
  • convex แปลว่าเส้นเชื่อมไม่ต่ำกว่ากราฟทุกคู่ ถ้าเขตที่อนุญาตก็ convex ด้วย ทุก local คือ global และความชันศูนย์ก็พอยืนยันคำตอบ
  • variance ของพอร์ตเป็น convex เพราะช่องว่างเท่ากับ $\alpha(1-\alpha)$ คูณ variance ของพอร์ต $x-y$ ซึ่งไม่ติดลบ พอร์ตหุ้นกับพันธบัตรที่ลงเงินครบจึงมีคำตอบเดียวคือหุ้น 2/19 หรือ 10.53%
  • หักล้าง convex ใช้คู่เดียว เช่นกึ่งกลางของพื้นผิว backtest ที่สูงกว่าเส้นเชื่อม 117.1875 ส่วนการยืนยันต้องพิสูจน์ทุกคู่

หน้าถัดไป gradient และเงื่อนไขอันดับหนึ่ง จะเปลี่ยนความชันของตัวแปรเดียวให้เป็น vector ของหลายตัวแปร แล้วใช้มันตอบคำถามแรกของเทรดเดอร์: เพิ่มหุ้น 1% ในพอร์ต 60/40 ความเสี่ยงขึ้นเท่าไร
