16.1 Stationarity and the Autocorrelation Function

Autocorrelation วัดว่าค่าวันนี้ยังจำค่าเมื่อ $k$ วันก่อนได้แค่ไหน และตัวเลขนี้มีความหมายก็ต่อเมื่อกฎของข้อมูลไม่เปลี่ยนตามวันที่ ซึ่งผลตอบแทนผ่าน แต่ราคาไม่ผ่าน

ทีมวิจัยสรุปผลตอบแทนรายวันของดัชนีหุ้นสหรัฐ 1,000 วันมาสองตัวเลข: autocorrelation ระหว่างผลตอบแทนเมื่อวานกับวันนี้คือ +0.031 และของขนาดการขยับ $|r_t|$ คือ +0.284 เทรดเดอร์คนหนึ่งบอกว่า “บวกทั้งคู่ วันขึ้นมักตามด้วยวันขึ้น ซื้อตามได้เลย” ตัวเลขไหนเป็นสัญญาณจริง และมันบอกเรื่องทิศทางหรือเรื่องความเสี่ยง?

ลองตอบก่อนเปิดเฉลย

+0.031 ยังแยกจากศูนย์ไม่ได้ ข้อมูลที่ไม่มีความจำเลยให้ค่าอยู่ในช่วง ±0.062 ได้ 95% ของเวลา ค่า t จึงแค่ 0.98 และถ้าค่าจริงเป็น 0.031 พอดี ต้องใช้ข้อมูลราว 3,998 วัน หรือเกือบ 16 ปี ค่าขนาดนี้จึงจะแตะเส้นเกณฑ์ ส่วน +0.284 มีค่า t 8.98 และ Ljung–Box สาม lag ได้ 184.8 เทียบเกณฑ์ 7.815 วันแรงบอกว่าพรุ่งนี้น่าจะแรง แต่ไม่ได้บอกว่าขึ้นหรือลง ความเสี่ยงพยากรณ์ได้ ทิศทางไม่ได้

ภาพรวมก่อนลงสูตร

หน้าก่อน ๆ ส่วนใหญ่ถือว่าข้อมูลแต่ละวันอิสระต่อกัน หน้านี้ถามกลับ: ค่าวันนี้ยังจำค่าเมื่อวานได้แค่ไหน เครื่องมือคือ autocorrelation function (ACF) ซึ่งคือ correlation ของอนุกรมกับตัวมันเองที่เลื่อนไป $k$ วัน จับคู่ “วันนี้กับเมื่อวาน” ทุกคู่ในข้อมูล แล้วดูว่าคู่ส่วนใหญ่ไปทางเดียวกันหรือสวนกัน

การเอาคู่จากทุกช่วงเวลามาเฉลี่ยรวมเป็นตัวเลขเดียวมีความหมายก็ต่อเมื่อทุกคู่มาจากกฎเดียวกัน เงื่อนไขนี้ชื่อ stationarity รูปด้านล่างแสดงว่าทำไมนักวิเคราะห์จึงทำงานกับผลตอบแทน ไม่ใช่ราคา: ราคาเดินไปแล้วไม่กลับ ความกว้างที่เป็นไปได้โตตามเวลา ส่วนผลตอบแทนแกว่งรอบศูนย์ในแถบเดิมทุกวัน

ผลตอบแทนรายวันของหุ้นจริงมีลักษณะที่พบซ้ำทุกตลาด (stylized facts) สี่ข้อ: ACF ของผลตอบแทนแทบเป็นศูนย์ ยกเว้นข้อมูลระหว่างวันที่การเด้งของราคาซื้อขายเข้ามาปน, ACF ของ $|r_t|$ และ $r_t^2$ เป็นบวกชัดและอยู่นาน โดย $|r_t|$ ชัดกว่า, หางหนากว่า Normal มาก (ผลตอบแทนรายวันปี 2001–2017 ของ SPY มี kurtosis ราว 11.4 ของ IBM ราว 7.1 เทียบกับ 3 ของ Normal) และยิ่งรวมเป็นรายสัปดาห์หรือรายเดือน การแจกแจงยิ่งเข้าใกล้ Normal หน้านี้สร้างเครื่องมือที่ใช้เห็นสองข้อแรก: นับ ACF ด้วยมือ เขียนเป็นสูตร หาว่าความบังเอิญสร้างค่าได้กว้างแค่ไหน รวมหลาย lag เป็นตัวเลขเดียว แล้วดูว่าความจำจางแบบไหนและเปลี่ยนการคูณรากของเวลาอย่างไร

ศัพท์ที่ใช้ในหัวข้อนี้
Time series
ข้อมูลที่เรียงตามเวลา ลำดับมีความหมาย สลับวันกันแล้วได้ข้อมูลคนละชุด เช่นราคาปิดรายวันหรือสเปรดรายเดือน
Lag
ระยะห่างเป็นจำนวนช่วงเวลาระหว่างสองค่าที่จับคู่กัน ในข้อมูลรายวัน lag 1 คือคู่เมื่อวานกับวันนี้ lag 20 คือคู่ที่ห่างกันราวหนึ่งเดือนทำการ
Autocorrelation function (ACF)
ชุดของ correlation ระหว่างอนุกรมกับตัวมันเองที่เลื่อนไป $k$ ช่วง สำหรับ $k=1, 2, \ldots$ ใช้ดูว่าความจำยาวแค่ไหนและจางแบบไหน ก่อนเลือกแบบจำลอง
Weak stationarity
สมบัติที่ค่าเฉลี่ย, variance และ covariance ของคู่ที่ห่างกัน $k$ วันไม่ขึ้นกับวันที่ มีไว้เพื่อให้การเอาคู่จากทุกช่วงเวลามาเฉลี่ยรวมเป็นตัวเลขเดียวมีความหมาย
White noise
อนุกรมที่ค่าเฉลี่ยคงที่และ ACF เป็นศูนย์ทุก lag ใช้เป็นเส้นฐานของ “ไม่มีความจำเชิงเส้น” และเป็นสิ่งที่ residual ของแบบจำลองที่ดีควรเป็น
Volatility clustering
วันที่ขยับแรงมักอยู่ติดกัน วันเงียบก็อยู่ติดกัน เห็นเป็น ACF บวกของ $|r_t|$ ทั้งที่ ACF ของ $r_t$ แทบเป็นศูนย์ ใช้เป็นเหตุผลให้สร้างแบบจำลองของความผันผวน
Ljung–Box test
สถิติที่รวม ACF กำลังสองหลาย lag เป็นตัวเลขเดียวแล้วเทียบกับ chi-square ใช้แทนการไล่ดูทีละ lag ซึ่งให้สัญญาณหลอกได้ง่าย
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$r_t$ผลตอบแทนของวันที่ $t$ทศนิยมต่อวัน
$|r_t|$ขนาดของการขยับ ไม่สนทิศทศนิยมต่อวัน
$P_t$ราคาปิดของวันที่ $t$ดอลลาร์
$n,\ k$จำนวนวันในข้อมูล และ lagวัน
$\gamma_k$autocovariance ที่ lag $k$; $\gamma_0$ คือ varianceทศนิยม²
$\rho_k,\ \hat\rho_k$ACF ของแบบจำลอง และค่าที่ประมาณจากข้อมูลไม่มีหน่วย
$h,\ Q(h)$จำนวน lag ที่รวม (หรือจำนวนวันที่รวมผลตอบแทน) และค่า Ljung–Boxจำนวน และไม่มีหน่วย

ขั้นที่ 1 — หกวันด้วยมือ: เลื่อนอนุกรมหนึ่งวันแล้วจับคู่

คำถาม “เมื่อวานบอกอะไรเกี่ยวกับวันนี้” แปลเป็นการคำนวณได้ตรง ๆ: จับคู่ทุกวันกับวันก่อนหน้า หักค่าเฉลี่ยออก แล้วดูว่าผลคูณของคู่เป็นบวกหรือลบโดยรวม ให้ $N_1$ เป็นผลรวมผลคูณของคู่ที่ห่างกันหนึ่งวัน และ $D$ เป็นผลรวมกำลังสองของทุกวัน ข้อมูลหกวันนี้ใช้หน่วย %

\[ \begin{aligned} r&=(2,\ 3,\ -3,\ -2,\ 1,\ -1),\\ \bar r&=0,\\ N_1&=(3)(2)+(-3)(3)+(-2)(-3)\\ &\quad+(1)(-2)+(-1)(1)\\ &=6-9+6-2-1=0,\\ D&=4+9+9+4+1+1=28,\\ \hat\rho_1(r)&=0/28=0. \end{aligned} \]

ใช้ตัวเลขชุดเดิม แต่ทิ้งเครื่องหมาย ให้ $x=|r|$ เหลือแค่ขนาดของการขยับ แล้วนับแบบเดียวกัน

\[ \begin{aligned} x&=(2,\ 3,\ 3,\ 2,\ 1,\ 1),\\ \bar x&=12/6=2,\\ x-\bar x&=(0,\ 1,\ 1,\ 0,\ -1,\ -1),\\ N_1&=(1)(0)+(1)(1)+(0)(1)\\ &\quad+(-1)(0)+(-1)(-1)=2,\\ D&=0+1+1+0+1+1=4,\\ \hat\rho_1(x)&=2/4=0.5. \end{aligned} \]

ชุดแรกดูทิศทาง: +3 ตามหลัง +2 ได้ผลคูณ +6 แต่ −3 ตามหลัง +3 ได้ −9 คู่ที่ไปทางเดียวกันกับคู่ที่สวนกันหักกันพอดี เหลือศูนย์ ทิศเมื่อวานจึงไม่บอกทิศวันนี้เลย

ชุดที่สองดูขนาด: วันแรง (3, 3) อยู่ติดกัน วันเบา (1, 1) ก็อยู่ติดกัน ผลคูณของการเบี่ยงจึงเป็นบวกและได้ 0.5 นี่คือ volatility clustering ในหกตัวเลข และเป็นตัวอย่างว่า correlation เป็นศูนย์ไม่ได้แปลว่าอิสระกัน: ขนาดของวันนี้ยังขึ้นกับขนาดของเมื่อวาน

ขั้นที่ 2 — เขียนการนับเป็นสูตร

การนับหกวันทำกับ lag 1 เท่านั้น ถ้าจับคู่ที่ห่างกัน $k$ วันก็ได้ lag $k$ นิยามของแบบจำลองใช้ค่าเฉลี่ยจริง $\mu$ ส่วนตัวประมาณจากข้อมูลใช้ $\bar r$ แทน สองบรรทัดแรกเป็นนิยาม บรรทัดสามคือสิ่งที่นับมือไปแล้ว

\[ \begin{aligned} \gamma_k&:=\mathbb E\big[(r_t-\mu)(r_{t-k}-\mu)\big],\\ \rho_k&:=\gamma_k/\gamma_0,\\ \hat\rho_k&=\frac{\sum_{t=k+1}^{n}(r_t-\bar r)(r_{t-k}-\bar r)}{\sum_{t=1}^{n}(r_t-\bar r)^2},\\ \hat\rho_2(r)&=\frac{(-6)+(-6)+(-3)+2}{28}\\ &=-\frac{13}{28}\approx-0.464. \end{aligned} \]

$\gamma_k$ คือค่าเฉลี่ยของผลคูณการเบี่ยงของคู่ที่ห่างกัน $k$ วัน หารด้วย $\gamma_0$ ซึ่งคือ variance แล้วหน่วยตัดกันหมด ตัวเลขจึงเทียบข้ามสินทรัพย์และข้าม lag ได้ ตัวอย่างหกวันที่ lag 2 เหลือแค่สี่คู่: $(-3)(2)$, $(-2)(3)$, $(1)(-3)$ และ $(-1)(-2)$

ตัวประมาณใช้ตัวส่วนเดียวกันทุก lag คือกำลังสองของทั้ง $n$ วัน แม้ตัวเศษมีแค่ $n-k$ คู่ ผลคือ $|\hat\rho_k|\le1$ เสมอตาม Cauchy–Schwarz (ขนาดของinner product ไม่เกินผลคูณของความยาว) แลกกับการที่ lag ไกล ๆ ถูกดึงเข้าหาศูนย์เล็กน้อย ค่า −0.464 จากสี่คู่ดูใหญ่ แถบความบังเอิญที่จะหาด้านล่างจะบอกว่าใหญ่พอหรือยัง

ขั้นที่ 3 — ตัวเลขนี้มีความหมายเมื่อกฎไม่ขึ้นกับวันที่

สูตร ACF เอาคู่จากทุกวันมาเฉลี่ยรวมเป็นตัวเลขเดียว การทำแบบนั้นมีความหมายก็ต่อเมื่อทุกคู่มาจากกฎเดียวกัน ถ้าปีแรกกับปีหลังมีค่าเฉลี่ยคนละระดับ ค่าเฉลี่ยรวมก็ไม่ใช่ของปีไหนเลย เงื่อนไขนี้คือ weak stationarity เป็นนิยามที่เลือกใช้ ไม่ใช่ผลที่พิสูจน์: สามบรรทัดแรกต้องจริงทุก $t$ จากนั้นลองตรวจราคา

\[ \begin{aligned} \mathbb E[r_t]&=\mu,\\ \operatorname{Var}(r_t)&=\gamma_0,\\ \operatorname{Cov}(r_t,r_{t-k})&=\gamma_k,\\ \ln P_t&=\ln P_0+\sum_{j=1}^{t}r_j,\\ \operatorname{Var}(\ln P_t)&=t\sigma^2,\\ \sigma=0.012:&\quad\sqrt1\,\sigma=1.2\%,\\ &\quad\sqrt{1000}\,\sigma=37.9\%. \end{aligned} \]

log ราคาวันนี้คือ log ราคาวันแรกบวกผลตอบแทน log ทุกวันที่ผ่านมา ถ้าผลตอบแทนอิสระกันและมี variance $\sigma^2$ เท่ากันทุกวัน variance ของผลรวม $t$ ก้อนคือ $t\sigma^2$ ซึ่งโตไม่หยุด เงื่อนไขข้อสองจึงไม่ผ่านสำหรับ log ราคา นี่คือกรวยที่กว้างขึ้นในรูปแรกของหน้า

ตรงกับgeometric Brownian motion: $\ln(P_{t+s}/P_t)$ เป็น Normal ที่ค่าเฉลี่ย $(\mu-\tfrac12\sigma^2)s$ และ variance $\sigma^2s$ ซึ่งขึ้นกับความยาวช่วง $s$ เท่านั้น ไม่ขึ้นกับว่าเริ่มวันไหน ผลตอบแทนของช่วงยาวเท่ากันจึงมีกฎเดียวกันทุกช่วง ส่วนระดับราคาไม่มี

volatility clustering เกิดได้แม้ผลตอบแทนยัง stationary: variance ที่เฉลี่ยทุกวันคงที่ได้ ขณะที่ variance เมื่อรู้ข้อมูลถึงวันนี้แล้วขยับขึ้นลง GARCH จะทำให้เห็นด้วยตัวเลข

ลองให้โค้ดท้ายหน้าสร้างราคาแบบ random walk 1,000 วันที่ SD 1.2% ต่อวัน แล้วคำนวณ ACF ของระดับราคาตรง ๆ ได้ 0.9955 ที่ lag 1 และยัง 0.9156 ที่ lag 20 ส่วน ACF ของผลตอบแทนชุดเดียวกันได้ −0.025 ตัวเลข 0.99 ไม่ได้บอกว่าพยากรณ์ราคาได้ มันบอกแค่ว่าราคาวันนี้อยู่ใกล้ราคาเมื่อวาน

ขั้นที่ 4 — ถ้าไม่มีความจำเลย ค่าที่ได้จะแกว่งแค่ไหน

กลับมาที่โจทย์เปิด: 0.031 ใหญ่พอไหม วิธีตอบคือหาว่าถ้าผลตอบแทนไม่มีความจำเลย $\hat\rho_k$ จะแกว่งรอบศูนย์กว้างเท่าไร สมมติให้ $r_t$ อิสระกันทุกวัน ค่าเฉลี่ยศูนย์ variance $\sigma^2$ แล้วดูตัวเศษของ $\hat\rho_k$ ทีละก้อน

\[ \begin{aligned} \mathbb E[r_tr_{t-k}]&=\mathbb E[r_t]\,\mathbb E[r_{t-k}]\\ &=0,\\ \operatorname{Var}(r_tr_{t-k})&=\mathbb E[r_t^2]\,\mathbb E[r_{t-k}^2]\\ &=\sigma^4,\\ \operatorname{Cov}(r_tr_{t-k},\,r_sr_{s-k})&=0\quad(t\ne s),\\ \hat\gamma_k&=\frac1n\sum_{t=k+1}^{n}r_tr_{t-k},\\ \operatorname{Var}(\hat\gamma_k)&=\frac{n-k}{n^2}\,\sigma^4\\ &\approx\frac{\sigma^4}{n},\\ \hat\rho_k&\approx\hat\gamma_k/\sigma^2,\\ \operatorname{Var}(\hat\rho_k)&\approx\frac{\sigma^4/n}{\sigma^4}=\frac1n,\\ n&=1000:\\ \mathrm{SE}&\approx1/\sqrt{1000}\\ &\approx0.0316,\\ 1.96\,\mathrm{SE}&\approx0.0620. \end{aligned} \]

บรรทัดแรกใช้ความอิสระ: ค่าเฉลี่ยของผลคูณแยกเป็นผลคูณของค่าเฉลี่ยซึ่งเป็นศูนย์ บรรทัดที่สามคือจุดที่คนสะดุด ทำไมผลคูณของสองคู่คนละวันไม่มี covariance? ในสี่ตัวที่คูณกัน ตัวที่มีวันที่ล่าสุดปรากฏครั้งเดียวและอิสระจากอีกสามตัว ค่าเฉลี่ยของทั้งก้อนจึงเป็นศูนย์ variance ของผลรวม $n-k$ ก้อนจึงบวกกันตรง ๆ

หารด้วย $\sigma^2$ แล้ว $\sigma^4$ บนล่างตัดกัน ผลไม่ขึ้นกับว่าข้อมูลผันผวนแค่ไหน แถบ 95% คือ $\pm1.96/\sqrt n$ ซึ่งคนทำงานมักปัดเป็น $\pm2/\sqrt n$ โดย 1.96 คือจุดที่หางสองข้างของNormalรวมกันเหลือ 5% ที่ 1,000 วันได้ ±0.062 ส่วนข้อมูลหกวันใช้ฝึกคำนวณเท่านั้น แม้แทนสูตรได้ $\pm1.96/\sqrt6\approx\pm0.80$ แต่ตัวอย่างเล็กเกินกว่าจะเชื่อแถบ Normal นี้

ที่มาของแถบนี้ใช้ “อิสระ” ไม่ใช่แค่ “correlation เป็นศูนย์” ถ้าผลตอบแทนกำลังสองมี covariance บวกแบบ volatility clustering ค่าเฉลี่ยของ $r_t^2r_{t-k}^2$ จะมากกว่า $\sigma^4$ แถบที่ถูกต้องจะกว้างกว่า ±0.062 ซอฟต์แวร์สถิติที่ดีมีแถบแบบ robust ที่ปรับเรื่องนี้ให้เลือกใช้

ขั้นที่ 5 — ดู 20 แท่งพร้อมกัน แล้วเลือกแท่งที่หลุด คือการหลอกตัวเอง

กราฟ ACF ปกติแสดง 20 แท่งพร้อมกัน แต่ละแท่งมีโอกาส 5% ที่จะหลุดแถบโดยบังเอิญ ไล่ดูทั้ง 20 แท่งแล้วหยิบแท่งที่หลุดมาเล่า ก็คือการทดสอบ 20 ครั้งแล้วรายงานครั้งที่ชนะ (multiple testing) ให้ $A$ เป็นจำนวนแท่งที่หลุดเมื่อข้อมูลเป็น noise ล้วน โดยถือว่า 20 แท่งเกือบอิสระกัน ซึ่งจริงโดยประมาณเมื่อไม่มีความจำ

\[ \begin{aligned} P(A=0)&=0.95^{20}=0.3585,\\ P(A\ge1)&=1-0.3585=0.6415,\\ \mathbb E[A]&=20(0.05)=1. \end{aligned} \]

ข้อมูล noise ล้วนราวสองในสามชุดจะมีแท่งหลุดอย่างน้อยหนึ่งแท่ง และโดยเฉลี่ยประมาณหนึ่งแท่ง แท่งที่หลุดแท่งเดียวในกราฟ 20 แท่งจึงเป็นสิ่งที่ควรคาดไว้ ไม่ใช่การค้นพบ

โค้ดท้ายหน้าลองจริง: สร้าง noise ล้วน 1,000 ชุด ชุดละ 1,000 วัน ได้ 61.7% ของชุดที่มีแท่งหลุด และเฉลี่ย 0.949 แท่งต่อชุด ต่างจากสูตร 2.5 จุด ซึ่งอยู่ในระดับที่การสุ่ม 1,000 ชุดคลาดได้ (SE ราว 1.5 จุด)

ขั้นที่ 6 — รวมหลาย lag เป็นตัวเลขเดียว: Ljung–Box

ทางแก้ของการเลือกแท่งคือรวมทุก lag เป็นตัวเลขเดียวแล้วเทียบกับเกณฑ์เดียว ทำให้แต่ละ $\hat\rho_k$ เป็นเลขมาตรฐานก่อนโดยหารด้วย SE ของมัน สำหรับข้อมูลอิสระที่มีการแจกแจงเหมือนกัน เมื่อจำนวนข้อมูลมากและเลือก $h$ คงที่ แต่ละ $Z_k$ เป็น Normal มาตรฐานโดยประมาณตามcentral limit theorem และเกือบอิสระกัน ผลรวมกำลังสองของ Normal มาตรฐานอิสระ $h$ ตัวมีการแจกแจงชื่อ chi-square $h$ องศาอิสระ

\[ \begin{aligned} Z_k&:=\hat\rho_k\big/\sqrt{\operatorname{Var}(\hat\rho_k)},\\ Z_1^2+\cdots+Z_h^2&\approx\chi^2_h,\\ \operatorname{Var}(\hat\rho_k)\approx\tfrac1n:&\quad Q_{\rm BP}=n\sum_{k=1}^{h}\hat\rho_k^2,\\ \operatorname{Var}(\hat\rho_k)&\approx\frac{n-k}{n(n+2)},\\ Q(h)&=n(n+2)\sum_{k=1}^{h}\frac{\hat\rho_k^2}{n-k}. \end{aligned} \]

บรรทัดที่สามใช้ SE $1/\sqrt n$ ที่เพิ่งได้ตรง ๆ เรียกว่า Box–Pierce บรรทัดสุดท้ายคือ Ljung–Box ซึ่งใช้ variance ที่ละเอียดกว่า ตัวหาร $n-k$ มาจากจำนวนคู่ที่เหลือจริงที่ lag $k$ แบบเดียวกับ $(n-k)/n^2$ ในการหาแถบ ส่วน $n+2$ แทน $n$ มาจากการคำนวณ variance แบบละเอียดของข้อมูล Normal ขนาดจำกัด เรารับส่วนนี้มาเป็นของที่ให้

แทนค่าของโจทย์เปิด $n=1000$ และ ACF สาม lag แรกของทั้งสองอนุกรม (ทิศทาง 0.031, −0.018, 0.009 ขนาด 0.284, 0.241, 0.213) เกณฑ์ 7.815 คือจุดที่พื้นที่หางขวาของ chi-square 3 องศาอิสระเหลือ 5% โค้ดท้ายหน้าหามันด้วยการอินทิเกรต density

\[ \begin{aligned} n(n+2)&=1000(1002)=1{,}002{,}000,\\ Q_r(3)&\approx1{,}002{,}000\times10^{-7}\\ &\quad\times(9.620+3.246+0.812)\\ &\approx1.371,\\ Q_{|r|}(3)&\approx1{,}002{,}000\times10^{-6}\\ &\quad\times(80.74+58.20+45.51)\\ &\approx184.8,\\ \chi^2_3(0.95)&=7.815. \end{aligned} \]

ก้อนในวงเล็บคือ $\hat\rho_k^2/(n-k)$ ทีละ lag เช่น $0.031^2/999=9.620\times10^{-7}$ ทิศทางได้ 1.371 ต่ำกว่าเกณฑ์มาก ไม่มีหลักฐานของความจำ ขนาดได้ 184.8 สูงกว่าเกณฑ์ราว 24 เท่า

ที่ 1,000 วันการปรับของ Ljung–Box แทบไม่มีผล Box–Pierce ได้ 1.366 เทียบ 1.371 แต่ที่ 50 วัน ตัวคูณของ lag 1 คือ $52/49=1.061$ และของ lag 3 คือ $52/47=1.106$ ต่างจาก Box–Pierce 6% ถึง 11%

ถ้าทดสอบ residual ของ ARMA($p,q$) ที่ฟิตมาแล้ว มักใช้ $h-p-q$ องศาอิสระเมื่อ $h\gt p+q$ และถ้า variance เปลี่ยนตามอดีต ต้องใช้รุ่นที่รองรับความผันผวนเปลี่ยนได้ ผลที่ไม่ปฏิเสธคือ “ยังไม่เห็นความจำเชิงเส้น” ไม่ใช่ “พิสูจน์แล้วว่าไม่มีความสัมพันธ์ใด ๆ”

ขั้นที่ 7 — ตัดสินโจทย์เปิด: ทิศทางหรือความเสี่ยง

โจทย์ให้อะไรมาบ้าง: $n=1000$ วัน ACF ของ $r_t$ ที่ lag 1–3 คือ 0.031, −0.018, 0.009 ของ $|r_t|$ คือ 0.284, 0.241, 0.213 และ $|r_t|$ ที่ lag 20 คือ 0.118 แถบ ±0.062 และ $Q(3)$ ได้จากสองขั้นก่อนหน้า

\[ \begin{aligned} t_r&=0.031\sqrt{1000}\\ &\approx0.98,\\ 0.031\pm0.062&\to(-0.031,\ 0.093),\\ n_{\rm need}&=(1.96/0.031)^2\\ &\approx3{,}998,\\ t_{|r|}&=0.284\sqrt{1000}\\ &\approx8.98,\\ t_{|r|,20}&=0.118\sqrt{1000}\\ &\approx3.73,\\ R^2_r&=0.031^2=0.096\%,\\ R^2_{|r|}&=0.284^2=8.07\%. \end{aligned} \]

คำตอบ: ทิศทางไม่มีหลักฐาน ช่วง 95% ครอบทั้งศูนย์และค่าติดลบ ข้อมูล 1,000 วันจึงบอกไม่ได้แม้แต่เครื่องหมายของความจำ ถ้าค่าจริงคือ 0.031 พอดี ต้องใช้ราว 3,998 วัน หรือ 15.9 ปีที่ปีละ 252 วันทำการ (365 วันลบเสาร์อาทิตย์ 104 วัน และวันหยุดตลาดสหรัฐราว 9 วัน) ค่าขนาดนี้จึงจะแตะเส้น 1.96 SE และแม้ถึงตอนนั้นก็ยังพลาดได้ราวครึ่งหนึ่ง ส่วนขนาดอยู่ห่างศูนย์ 8.98 SE ที่ lag 1 และยังเกิน 3.7 SE ที่ lag 20 ตัวเลขชุดนี้จึงสนับสนุนให้สร้างแบบจำลองขนาดการขยับ มากกว่าสรุปว่าซื้อตามวันขึ้นแล้วจะได้กำไร

$R^2$ บอกขนาดของประโยชน์ เพราะregression เส้นตรงตัวแปรเดียวที่มี intercept มี $R^2$ เท่ากับ correlation ยกกำลังสอง: ใช้ $r_{t-1}$ ทำนาย $r_t$ อธิบาย variance ได้ 0.096% ส่วน $|r_{t-1}|$ ทำนาย $|r_t|$ ได้ 8.07% มากกว่า 84 เท่า

ตรวจเองใน 10 วินาที: $\sqrt{1000}\approx31.62$ ดังนั้น $1.96/31.62\approx0.062$ และ $0.284\times31.62\approx8.98$ ส่วน $3{,}998/252\approx15.9$ ปี

ขั้นที่ 8 — ความจำของขนาดจางแบบไหน

รู้แล้วว่าขนาดมีความจำ คำถามถัดไปคือมันจางเร็วแค่ไหนและจางแบบไหน เพราะรูปร่างนี้บอกว่าควรใช้แบบจำลองใด ลองสองรูปร่าง แบบแรก geometric ลดด้วยอัตราคงที่ทุก lag ฟิตจาก lag 1 กับ 2 แบบที่สอง power law ลดตาม $k^{-d}$ ฟิตจาก lag 1 กับ 20

\[ \begin{aligned} \rho_k&=\rho_1\phi^{k-1},\\ \phi&=0.241/0.284=0.8486,\\ \rho_{10}&=0.284(0.8486^{9})=0.0648,\\ \rho_{20}&=0.284(0.8486^{19})=0.0125,\\ \rho_k&=\rho_1k^{-d},\\ 20^{-d}&=0.118/0.284=0.4155,\\ d&=\frac{\ln(0.284/0.118)}{\ln20}\\ &\approx\frac{0.8783}{2.9957}\\ &\approx0.2932,\\ \rho_{10}&=0.284(10^{-0.2932})=0.1446. \end{aligned} \]

ค่าที่วัดได้ที่ lag 10 และ 20 คือ 0.152 และ 0.118 เส้น geometric ทำนายต่ำกว่าจริง 2.3 เท่าที่ lag 10 และ 9.4 เท่าที่ lag 20 ส่วน power law ทำนาย 0.1446 ที่ lag 10 ใกล้ของจริง

การเทียบนี้ลำเอียงให้ power law เพราะมันถูกบังคับให้ผ่าน lag 20 พอดี ถ้าฟิตทั้งสองแบบด้วย least squares บน log ของทั้ง 20 lag เส้น geometric ที่ดีที่สุดยังคลาดได้ถึง 19% ส่วน power law คลาดไม่เกิน 4.6% ความจำของขนาดจึงลดเร็วช่วงแรกแล้วลากหางยาว

แบบจำลองที่มีอัตราความจำตัวเดียวอย่าง AR(1) สร้างรูปนี้ไม่ได้ GARCH เข้าใกล้กว่าด้วยการตอบสนองแรงในวันแรกแล้วจางช้า แต่ 20 lag จากข้อมูลชุดเดียวยังไม่พอพิสูจน์ความจำยาว มันเป็นเบาะแสในการเลือกแบบจำลอง

ขั้นที่ 9 — ความจำเปลี่ยนกฎ “คูณรากของเวลา”

คนบนโต๊ะแปลงความผันผวนรายวันเป็นรายสัปดาห์หรือรายปีด้วย $\sqrt h$ เสมอ กฎนี้ใช้ได้เพราะสมมติว่าผลตอบแทนแต่ละวันไม่มี autocorrelation ถ้ามี ต้องนับ covariance ระหว่างวันด้วย variance ของผลรวม $h$ วันคือผลรวมของทุกช่องในตาราง $h\times h$ ของ covariance: ช่องทแยง $h$ ช่องเป็น $\gamma_0$ และช่องที่ห่างจากทแยง $k$ มีทั้งหมด $2(h-k)$ ช่อง แต่ละช่องเป็น $\gamma_k$

\[ \begin{aligned} \operatorname{Var}\Big(\sum_{t=1}^{h}r_t\Big)&=h\gamma_0+2\sum_{k=1}^{h-1}(h-k)\gamma_k\\ &=h\gamma_0\Big[1+2\sum_{k=1}^{h-1}\big(1-\tfrac kh\big)\rho_k\Big],\\ h=5,\ \rho_1=0.1:&\quad1+2(0.8)(0.1)=1.16,\\ h=5,\ \rho_1=-0.05:&\quad1+2(0.8)(-0.05)=0.92,\\ 1.2\%\sqrt5&=2.683\%,\\ 2.683\%\sqrt{1.16}&=2.890\%,\\ 2.683\%\sqrt{0.92}&=2.574\%. \end{aligned} \]

ก้อนในวงเล็บเหลี่ยมคือตัวปรับของกฎรากของเวลา ถ้า ACF เป็นศูนย์ทุก lag ก้อนนี้เป็น 1 และได้ $h\gamma_0$ แบบเดิม ACF บวก (วันขึ้นตามด้วยวันขึ้น) ทำให้ผลรวมแกว่งกว้างกว่าที่คูณรากของเวลา ACF ลบ (วันขึ้นตามด้วยวันลง) ทำให้แกว่งแคบกว่า ตัวคูณ $1-k/h$ มาจากการที่คู่ซึ่งห่างกัน $k$ วันมีอยู่แค่ $h-k$ คู่ในหน้าต่าง $h$ วัน

ทั้งปี 252 วันทำการกับ SD รายวัน 1.2%: ไม่มีความจำได้ $1.2\%\sqrt{252}=19.05\%$ ถ้า $\rho_1=0.1$ ได้ 20.86% ถ้า $\rho_1=-0.05$ ได้ 18.08% ACF ขนาดที่ดูเล็กเปลี่ยนตัวเลขความเสี่ยงรายปีได้เกือบสองจุด แบบจำลองความเสี่ยงที่ประมาณ covariance จากข้อมูลรายวันจึงมักใส่ตัวปรับแบบนี้ (ตัวประมาณของ Newey–West ใช้น้ำหนัก $1-k/(1+L)$ ที่ลดลงตาม lag) และการเด้งระหว่าง bid กับ askคือกรณีที่ ACF ลบแรงมากในข้อมูลรายนาที

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

หา ACF ของระดับราคา: random walk ในรูปเทียบราคากับผลตอบแทนได้ 0.9955 ที่ lag 1 ทั้งที่ผลตอบแทนไม่มีความจำเลย ตัวเลขใกล้ 1 แบบนี้เกิดเมื่อระดับราคาค่อย ๆ เปลี่ยนและไม่มีค่าเฉลี่ยคงที่ และเป็นต้นเหตุของspurious regression ระหว่างสองอนุกรมที่ไม่เกี่ยวกัน

หยิบแท่งที่หลุดแท่งเดียว: noise ล้วนมีโอกาสประมาณ 64% ที่จะมีแท่งหลุดอย่างน้อยหนึ่งแท่งใน 20 แท่ง แท่ง lag 13 ที่ได้ 0.086 ในรูป noise ล้วนคือตัวอย่าง รายงานเฉพาะ lag ที่ “ชนะ” โดยไม่รวมทั้งหมดด้วย Ljung–Box คือการค้นหาจนเจอ ไม่ใช่การพบสัญญาณ

ลืมว่าราคามาจากไหน: ราคาปิดของหุ้นที่ซื้อขายน้อยอาจค้างที่ราคาเก่า ทำให้เกิด ACF บวกปลอม ส่วนราคาที่เด้งระหว่าง bid กับ ask สร้าง ACF ติดลบปลอม ข้อมูลที่สลับ +1% กับ −1% ทุกวันได้ $\hat\rho_1=-0.833$ (โจทย์ข้อ 3 ด้านล่าง) สองผลนี้หักล้างกันจนดูเหมือนไม่มีอะไรได้ หน้า MA, ARMA และ ARIMA จะแยกผลของการเด้งออกมา

อ่าน ACF เป็นศูนย์ว่าอิสระ หรือว่าทำนายไม่ได้: ข้อมูลหกวันมี ACF ของทิศทางเป็นศูนย์พอดี แต่ขนาดยังจำกันที่ 0.5 ACF วัดได้แค่ความจำเชิงเส้นของอนุกรมกับตัวเอง ผลตอบแทนอาจยังทำนายได้จากตัวแปรอื่นที่ไม่ใช่อดีตของตัวมันเอง

คูณรากของเวลาโดยไม่ดู ACF: ที่ $\rho_1=0.1$ ความผันผวนรายปีจริงคือ 20.86% ไม่ใช่ 19.05% ความเสี่ยงต่ำไปเกือบ 9% ของตัวเลขโดยไม่มีอะไรเตือน

ก่อนฟิตแบบจำลองใดกับอนุกรมใหม่ คนทำงานดู ACF สองชุดเสมอ: ของผลตอบแทนเพื่อหาความจำของทิศทาง และของ $|r_t|$ หรือ $r_t^2$ เพื่อหาความจำของความเสี่ยง ผลบอกว่าควรใช้แบบจำลองของค่าเฉลี่ยแบบ AR หรือ MA และ ARMA แบบจำลองของความผันผวนแบบ GARCH หรือทั้งสอง

หลังฟิตเสร็จ ACF และ Ljung–Box ของ residual คือการตรวจงาน residual ที่ยังมีความจำแปลว่าแบบจำลองยังจับไม่หมด ส่วนงานหาสัญญาณเทรด คำถาม “ต้องใช้ข้อมูลกี่ปีจึงจะเชื่อได้” ซึ่งตอบด้วย $n=(1.96/\rho)^2$ มักตัดสินงานวิจัยได้ก่อนเขียนโค้ดบรรทัดแรก และงานวัดความเสี่ยงใช้ ACF ปรับกฎรากของเวลาเมื่อแปลงความผันผวนรายวันเป็นช่วงยาว

โจทย์ตรวจความเข้าใจ

1. มีข้อมูลรายวันหนึ่งปี 252 วัน วัด $\hat\rho_1=0.10$ ได้ ผ่านแถบ 95% ไหม และถ้าค่าจริงคือ 0.10 ต้องใช้กี่วันจึงผ่าน?

เฉลย

แถบคือ $1.96/\sqrt{252}=1.96/15.87\approx0.1235$ ค่า 0.10 ยังอยู่ในแถบ ไม่ผ่าน ค่าขนาดนี้จะแตะเส้นเกณฑ์เมื่อ $n\ge(1.96/0.10)^2=384.2$ คือ 385 วัน หรือราวปีครึ่ง ความจำที่ใหญ่กว่าโจทย์เปิดสามเท่าต้องใช้ข้อมูลน้อยกว่าเก้าเท่า เพราะ $n$ ขึ้นกับกำลังสองของ $1/\rho$

2. ข้อมูล 100 วันให้ $\hat\rho_1=0.15$ และ $\hat\rho_2=0.10$ จงหา $Q(2)$ และเทียบกับเกณฑ์ 95% ของ chi-square 2 องศาอิสระ

เฉลย

$Q(2)=100(102)\big(0.0225/99+0.01/98\big)=10{,}200(0.00032931)\approx3.359$ chi-square 2 องศาอิสระมี CDF $1-e^{-x/2}$ เกณฑ์จึงหาได้ด้วยมือจาก $e^{-x/2}=0.05$ คือ $x=-2\ln0.05\approx5.991$ ค่า 3.359 ต่ำกว่าเกณฑ์ ยังไม่มีหลักฐานของความจำ แม้แท่งแรก 0.15 จะดูใหญ่ เพราะแถบของ 100 วันกว้างถึง ±0.196

3. ผลตอบแทนหกวันคือ $(1, -1, 1, -1, 1, -1)\%$ จงหา $\hat\rho_1$ ของ $r_t$ และของ $|r_t|$ แล้วหา SD ของผลรวมสองวันถ้า ACF ของประชากรเป็น $\rho_1=-0.5$ และ SD รายวัน 1%

เฉลย

ค่าเฉลี่ยเป็นศูนย์ ผลคูณของห้าคู่ติดกันเป็น −1 ทุกคู่ รวม −5 ตัวส่วนคือ 6 จึงได้ $\hat\rho_1=-5/6\approx-0.833$ ส่วน $|r_t|$ เป็น 1 ทุกวัน หักค่าเฉลี่ยแล้วเป็นศูนย์หมด ได้ $0/0$ ซึ่งนิยามไม่ได้ ไม่ใช่ศูนย์ โค้ดท้ายหน้าจึงปฏิเสธอนุกรมคงที่แทนที่จะตอบตัวเลข สำหรับผลรวมสองวัน ตัวปรับคือ $1+2(1-\tfrac12)(-0.5)=0.5$ variance จึงเป็น $2(1\%)^2(0.5)=1\%^2$ ได้ SD 1% เท่ากับวันเดียว ไม่ใช่ $\sqrt2\times1\%=1.41\%$ การเด้งขึ้นลงหักล้างกันเอง

เปิดดูโค้ด

รันใน Node.js ได้โดยไม่ติดตั้งแพ็กเกจ โค้ดคำนวณ ACF จากข้อมูลดิบ ปฏิเสธอนุกรมคงที่และ lag ที่เกินข้อมูล หาเกณฑ์ chi-square ด้วยการอินทิเกรต density แบบ Simpson สร้าง random walk และ noise ล้วนด้วยเครื่องสุ่มแบบมี seed เพื่อให้ทุกคนได้ตัวเลขชุดเดียวกับในหน้า แล้วพิมพ์ทุกตัวเลขเป็น JSON บรรทัดเดียว

function series(x) {
  if (!Array.isArray(x) || x.length < 3 || ![...x].every(Number.isFinite)) {
    throw new TypeError('Need an array of at least three finite numbers');
  }
  return x.length;
}
// Sample ACF: pairs k apart over the same denominator for every lag, so |rho_k| <= 1.
function acf(x, maxLag) {
  const n = series(x);
  if (!Number.isInteger(maxLag) || maxLag < 1 || maxLag >= n) throw new RangeError('Lag must be an integer from 1 to n - 1');
  const mean = x.reduce((s, v) => s + v, 0) / n, d = x.map(v => v - mean);
  const bottom = d.reduce((s, v) => s + v * v, 0);
  if (!(bottom > 0)) throw new RangeError('Constant series: the ACF is 0/0, undefined');
  return Array.from({length: maxLag}, (_, j) => {
    let top = 0;
    for (let t = j + 1; t < n; t++) top += d[t] * d[t - j - 1];
    return top / bottom;
  });
}
function checkRhos(rhos, n) {
  if (!Array.isArray(rhos) || !rhos.length || ![...rhos].every(r => Number.isFinite(r) && Math.abs(r) <= 1)) {
    throw new TypeError('Need autocorrelations between -1 and 1');
  }
  if (!Number.isInteger(n) || n <= rhos.length + 1) throw new RangeError('Need an integer n larger than the number of lags + 1');
}
const band = (n, z = 1.96) => z / Math.sqrt(n);
function ljungBox(rhos, n) {
  checkRhos(rhos, n);
  return n * (n + 2) * rhos.reduce((s, r, i) => s + r * r / (n - i - 1), 0);
}
function boxPierce(rhos, n) {
  checkRhos(rhos, n);
  return n * rhos.reduce((s, r) => s + r * r, 0);
}
// Chi-square density with h degrees of freedom, integrated by Simpson's rule on a fine grid.
function chiSquareCdf(x, h) {
  if (!Number.isInteger(h) || h < 2 || h > 40 || !(x >= 0)) throw new RangeError('Need 2 <= h <= 40 and x >= 0');
  let logGamma = h % 2 ? Math.log(Math.sqrt(Math.PI)) : 0;
  for (let a = h % 2 ? 0.5 : 1; a < h / 2; a++) logGamma += Math.log(a);
  const f = t => t > 0 ? Math.exp((h / 2 - 1) * Math.log(t) - t / 2 - (h / 2) * Math.log(2) - logGamma) : (h === 2 ? 0.5 : 0);
  const steps = 20000, w = x / steps;
  let s = f(0) + f(x);
  for (let i = 1; i < steps; i++) s += (i % 2 ? 4 : 2) * f(i * w);
  return s * w / 3;
}
function chiSquareCritical(h, p = 0.95) {
  let lo = 0, hi = 200;
  for (let i = 0; i < 60; i++) { const m = (lo + hi) / 2; if (chiSquareCdf(m, h) < p) lo = m; else hi = m; }
  return (lo + hi) / 2;
}
// mulberry32 + Box-Muller: seeded, so every reader gets the same numbers.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const radius = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = radius * Math.sin(angle);
    return radius * Math.cos(angle);
  };
}
function randomWalk(n, sigma, seed) {
  if (!Number.isInteger(n) || n < 3 || !(sigma > 0)) throw new RangeError('Need n >= 3 steps and sigma > 0');
  const z = normals(seed), returns = [], prices = [];
  let logPrice = Math.log(500);
  for (let t = 0; t < n; t++) { const r = sigma * z(); returns.push(r); logPrice += r; prices.push(Math.exp(logPrice)); }
  return {returns, prices};
}
// Pure noise, 20 lags per series: how often does at least one bar leave the band?
function falseAlarms(count, n, lags, seed) {
  const z = normals(seed), limit = band(n);
  let anyOutside = 0, barsOutside = 0, first = null;
  for (let s = 0; s < count; s++) {
    const r = acf(Array.from({length: n}, z), lags);
    if (first === null) first = r;
    const out = r.filter(v => Math.abs(v) > limit).length;
    barsOutside += out;
    if (out > 0) anyOutside++;
  }
  return {share: anyOutside / count, barsPerSeries: barsOutside / count, firstSeriesLag13: first[12]};
}
// Fit both decay shapes to all lags at once: a straight line through log(rho) against k or log(k).
function decayFit(rhos) {
  if (!Array.isArray(rhos) || rhos.length < 3 || ![...rhos].every(r => r > 0 && r <= 1)) {
    throw new RangeError('Need at least three positive autocorrelations');
  }
  const line = xs => {
    const m = xs.length, y = rhos.map(Math.log);
    const mx = xs.reduce((s, v) => s + v, 0) / m, my = y.reduce((s, v) => s + v, 0) / m;
    let sxy = 0, sxx = 0;
    for (let i = 0; i < m; i++) { sxy += (xs[i] - mx) * (y[i] - my); sxx += (xs[i] - mx) ** 2; }
    const slope = sxy / sxx, fit = xs.map(v => Math.exp(my + slope * (v - mx)));
    return {slope, fit, maxError: Math.max(...fit.map((f, i) => Math.abs(f / rhos[i] - 1)))};
  };
  const k = rhos.map((_, i) => i + 1), geo = line(k), pow = line(k.map(Math.log));
  return {rate: Math.exp(geo.slope), geometricMaxError: geo.maxError, d: -pow.slope, powerMaxError: pow.maxError};
}
// Variance of an h-day sum relative to h * gamma0: 1 + 2 * sum over k of (1 - k/h) rho_k.
function varianceRatio(rhos, h) {
  if (!Number.isInteger(h) || h < 1) throw new RangeError('Horizon must be a whole number of days');
  return 1 + 2 * rhos.reduce((s, r, i) => s + (i + 1 < h ? (1 - (i + 1) / h) * r : 0), 0);
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ACF คือ correlation ของอนุกรมกับตัวเองที่เลื่อนไป $k$ วัน นับมือได้จากผลรวมผลคูณของคู่หารด้วยผลรวมกำลังสอง
  • ตัวเลขนี้มีความหมายเมื่อข้อมูล stationary ราคาไม่ผ่านเพราะ variance โตตามเวลา (ACF ของราคาได้ 0.9955 ทั้งที่ไม่มีความจำ) จึงวิเคราะห์ผลตอบแทน และ volatility clustering ไม่ได้ขัดกับ stationarity
  • ถ้าไม่มีความจำ $\hat\rho_k$ แกว่งด้วย SE ราว $1/\sqrt n$: ที่ 1,000 วันแถบ 95% คือ ±0.062 และ +0.031 มีค่า t แค่ 0.98
  • ดู 20 แท่งพร้อมกัน noise ล้วนมีแท่งหลุดอย่างน้อยหนึ่งแท่ง 64% ของเวลา จึงรวมเป็น Ljung–Box: ทิศทางได้ 1.37 ขนาดได้ 184.8 เทียบเกณฑ์ 7.815
  • ผลตอบแทนแทบไม่จำทิศทาง แต่จำขนาดได้นาน ความจำของขนาดลดเร็วช่วงแรกแล้วลากหางยาว
  • ACF ที่ไม่เป็นศูนย์เปลี่ยนกฎรากของเวลา: variance $h$ วันคือ $h\gamma_0[1+2\sum(1-k/h)\rho_k]$

หน้าถัดไป Autoregressive processes (AR) เริ่มสร้างแบบจำลองของความจำ แบบที่ง่ายที่สุดคือให้ค่าวันนี้เป็นส่วนหนึ่งของค่าเมื่อวานบวกข่าวใหม่ แล้วดูว่า ACF ของมันออกมาเป็นรูปร่างแบบไหน
