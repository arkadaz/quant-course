16.1 Stationarity and the Autocorrelation Function

ดูว่าข้อมูลจำอดีตนานเท่าไร และรูปแบบยังคงเดิมหรือไม่

ผลลัพธ์เมื่อวานเป็นลบ; นั่นบังคับให้วันพรุ่งนี้ลบตามหรือเพียงบอกว่าการแกว่งอาจแรงขึ้น?

เฉลย: ไม่ได้บังคับให้ลบตาม—sign มักไม่มี memory ที่ใช้ได้ แต่ขนาดการแกว่งอาจมี. ทายว่าเหรียญจะออกหัวมักแพ้ แต่ทายว่ามันกำลังถูกโยนแรงอาจชนะ; จากนั้นจึงตั้งชื่อ stationarity และ autocorrelation function (ACF) ให้สิ่งที่เราตรวจ.

weak stationarity
สมบัติที่ mean และ variance คงเดิม และ covariance ขึ้นกับ lag ไม่ใช่วันที่ ใช้ทำให้กฎสถิติที่ประมาณจากอดีตนำไปใช้กับอนาคตได้
autocorrelation function (ACF)
correlation ระหว่างอนุกรมกับสำเนาของตัวเองที่เลื่อนไป k ช่วงเวลา ใช้ตรวจว่าความจำเชิงเส้นอยู่ที่ horizon ใด
volatility clustering
ช่วงที่ผลตอบแทนขนาดใหญ่ติดกันและช่วงเล็กติดกัน ใช้เป็นหลักฐานว่า variance หรือขนาดการแกว่งกำลังสองโดยเฉลี่ยมี dynamics แม้ signed return จะดูไม่มีความจำ
white noise
สัญญาณที่มี mean คงที่และไม่มี autocorrelation ที่ lag บวก ใช้เป็น null model ของ residual ที่เหลือหลัง fit
Ljung–Box test
การรวม squared ACF หลาย lag เป็นสถิติเดียว ใช้ตรวจ joint hypothesis ว่าไม่มี serial correlation แทนการไล่ดูทีละแท่ง
moving-average process (MA)
แบบจำลองที่ใช้ข่าวใหม่หรือ shock ปัจจุบันกับอดีตจำนวนจำกัด ใช้อธิบายผลกระทบที่ค่อย ๆ หมดอายุ
autoregressive process (AR)
แบบจำลองที่ใช้ค่าก่อนหน้าของอนุกรมมาช่วยอธิบายค่าปัจจุบัน ใช้วัดว่าความจำของระดับหรือผลตอบแทนสลายเร็วเพียงใด
generalized autoregressive conditional heteroskedasticity (GARCH)
variance model ที่ให้ความผันผวนวันนี้ขึ้นกับ shock และความผันผวนในอดีต ใช้จับ volatility clustering
HAC
heteroskedasticity and autocorrelation consistent (HAC) standard error ใช้ปรับ uncertainty เมื่อ residual มี variance ไม่คงที่หรือพึ่งพากันตามเวลา

กับดักข้อมูลและคำประกาศเกินจริง

ราคา close ของหุ้นสภาพคล่องต่ำอาจ stale ทำให้เกิด positive autocorrelation; bid–ask bounce ทำให้เกิด negative lag-1 autocorrelation และสองผลอาจหักล้างกันพอดี ต้องรู้ว่าใช้ trade price, mid price หรือ adjusted close และจัดการ corporate action ก่อนคำนวณ นอกจากนี้ rho = 0 แปลเพียงไม่พบ linear dependence ไม่ได้แปลว่า independent

›โค้ดตรวจทุกเลขของตัวอย่างเปิดโค้ด
import numpy as np
r=np.array([2,3,-3,-2,1,-1.],dtype=float)
def acf1(x):
    z=x-x.mean()
    return z[1:]@z[:-1]/(z@z)
assert abs(acf1(r)-0.0)<1e-12
assert abs(acf1(abs(r))-0.5)<1e-12
n=1000
assert abs(1.96/np.sqrt(n)-0.0619806)<1e-6
assert abs(.031**2-.000961)<1e-12
ใช้ NumPy ตรวจ toy ACF, null band และ R-squared; ใน production ต้องใช้ heteroskedasticity and autocorrelation consistent (HAC) หรือ bootstrap band เมื่อ residual ไม่ใช่ white noise

ก่อนไปต่อ — หัวข้อถัดไป

เมื่อ ACF บอกว่าความจำอยู่ใน mean หรือ variance แล้ว ขั้นต่อไปคือตั้งสมการที่สร้างความจำอย่าง explicit: AR จะจำค่าของอนุกรมเอง ส่วน MA จะจำ shock ที่สังเกตไม่ได้ และ GARCH จะจำ conditional variance

สรุปที่ใช้ได้จริง

  • ตรวจ stationarity และเลือก return ก่อน fit model; ราคาไม่ใช่ default input ที่ปลอดภัย
  • ACF ของ signed return และ |return| ตอบคำถามคนละเรื่อง: ทิศทางอาจไม่มี memory แต่ volatility clustering อาจชัด
  • ใช้ Ljung–Box เพื่อตรวจหลาย lag พร้อมกัน และแยก statistical significance ออกจากกำไร USD
  • band แบบ ±1.96/√n เป็นเพียง null approximation; microstructure, regime change และ nonlinear dependence ทำให้ตีความตรง ๆ ไม่ได้
