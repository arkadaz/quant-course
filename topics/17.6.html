17.6 Drawdown, Calmar, and De-risking Rules

drawdown วัดว่าทุนวันนี้ต่ำกว่ายอดสูงสุดที่เคยทำได้กี่เปอร์เซ็นต์ หลุมยิ่งลึกยิ่งต้องฟื้นมากกว่าที่เสีย และกฎลดขนาดเมื่อหลุมลึกช่วยให้หลุมตื้นขึ้นโดยแลกกับกำไรตอนตลาดฟื้น

บัญชี \$1,000,000 ขึ้นไปถึงยอด \$1,100,000 แล้วลดเหลือ \$880,000 ผู้จัดการบอกนักลงทุนว่า “เราลงไปแค่ 12% จากเงินต้น ทำกำไรอีก 12% ก็กลับมาแล้ว” ประโยคนี้ผิดตรงไหน? และถ้าบัญชีมีกฎ “ลงจากยอดถึง 10% ให้ลดขนาดเหลือครึ่ง” กฎนี้ช่วยได้เท่าไร และต้องจ่ายอะไร?

ลองตอบก่อนเปิดเฉลย

ความเจ็บวัดจากยอด \$1.1 ล้าน ไม่ใช่จากเงินต้น บัญชีลงจากยอด 20% และต้องกำไร $0.20/0.80=25\%$ จึงกลับถึงยอด กำไร 12% พาไปได้แค่ $880{,}000\times1.12=\$985{,}600$ ส่วนกฎลดขนาด บนเส้นทางสมมติ 12 วันในหน้านี้ หลุมที่ลึกที่สุดตื้นขึ้นจาก 21.13% เหลือ 16.03% แต่บัญชีจบที่ \$1,011,463 แทน \$1,035,914 เพราะช่วงที่ตลาดเด้งกลับ กฎถือแค่ครึ่งขนาด

ภาพรวมก่อนลงสูตร

VaR และ Expected Shortfall ถามว่าวันเดียวเสียได้เท่าไร แต่คนที่ฝากเงินไว้ไม่ได้เจ็บทีละวัน เขาเจ็บจากยอดเงินที่เคยเห็นแล้วหายไป drawdown วัดความเจ็บแบบนั้น: ทุนวันนี้ต่ำกว่ายอดสูงสุดที่เคยทำได้กี่เปอร์เซ็นต์ ตัวเลขนี้ขึ้นกับลำดับของผลตอบแทน ไม่ใช่แค่ค่าเฉลี่ยกับความผันผวน Sharpe ratio จึงมองไม่เห็นมัน

รูปด้านล่างคือทั้งเรื่องในภาพเดียว เส้นน้ำเงินคือทุนของเส้นทางสมมติ 12 วัน เส้นประคือยอดสูงสุดสะสม ซึ่งขึ้นได้อย่างเดียว ไม่เคยลงตามทุน พื้นที่แดงระหว่างสองเส้นคือ drawdown และแท่งแดงด้านล่างคือความลึกของหลุมรายวัน หลุมลึกสุด 21.13% ในวันที่ 5 แล้วใช้อีกห้าวันจึงกลับถึงยอดเดิม

หน้านี้จะนับหลุมด้วยมือ หาว่าหลุมลึกเท่าไรต้องฟื้นเท่าไร แยกเงินฝากถอนออกจากผลงาน สร้าง Calmar ratio แล้วเขียนกฎลดขนาดสองแบบ คือแบบขั้นบันไดกับแบบต่อเนื่องของ Grossman–Zhou ลองทั้งสองบนเส้นทางเดียวกัน และจบที่ราคาที่กฎทุกแบบต้องจ่าย

ศัพท์ที่ใช้ในหัวข้อนี้
Drawdown
สัดส่วนที่ทุนตอนนี้ต่ำกว่ายอดสูงสุดที่เคยทำได้ ใช้วัดความเสียหายที่เจ้าของเงินรู้สึกจริงระหว่างทาง
High-water mark (ยอดสูงสุดสะสม)
ยอดทุนสูงสุดตั้งแต่เริ่มจนถึงวันนี้ ไม่มีวันลดลง ใช้เป็นฐานของ drawdown และเป็นฐานคิดค่าธรรมเนียมผลงานของกองทุนจำนวนมาก
Maximum drawdown
drawdown ที่ลึกที่สุดในช่วงที่วัด ใช้สรุปหลุมที่หนักที่สุดที่เคยต้องทน
Time under water
ระยะเวลาที่ทุนยังไม่กลับถึงยอดเดิม ต้องบอกว่านับจำนวนวันที่ปิดต่ำกว่ายอด หรือนับจากวันทำยอดถึงวันฟื้น เพราะสองแบบต่างกันหนึ่งวัน
Time-weighted return
ผลตอบแทนที่ตัดผลของเงินฝากถอนออก โดยต่อผลตอบแทนรายงวดเป็นมูลค่าต่อหน่วย ใช้วัดผลงานของผู้จัดการ ไม่ใช่ผลของจังหวะที่ลูกค้าเติมหรือถอนเงิน
Calmar ratio
อัตราโตทบต้นต่อปี (CAGR) หารด้วย maximum drawdown ในหน้าต่างเดียวกัน ใช้ถามว่าได้เท่าไรต่อความเจ็บที่ลึกที่สุดหนึ่งหน่วย ชื่อมาจากจดหมายข่าว California Managed Accounts Reports ที่เสนอตัววัดนี้ในปี 1991
De-risking rule (stop-out)
กฎที่ลดขนาดความเสี่ยงอัตโนมัติเมื่อ drawdown ถึงจุดที่ตั้งไว้ ใช้จำกัดความเสียหายต่อ แต่ต้องมีกฎกลับเข้า และมีต้นทุน
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$W_t$ทุน ณ สิ้นวันที่ $t$ดอลลาร์
$H_t$ยอดสูงสุดสะสมถึงวันที่ $t$ดอลลาร์
$D_t$drawdown $1-W_t/H_t$สัดส่วน
$D_{\max}$drawdown ที่ลึกที่สุดในช่วงสัดส่วน
$R$ผลตอบแทนที่ต้องทำเพื่อกลับยอดสัดส่วน
$Q_t,\ U_t$เงินฝากสุทธิของวันที่ $t$ (ถอนเป็นลบ) และมูลค่าต่อหน่วยดอลลาร์ และไม่มีหน่วย
$g,\ T$CAGR และความยาวของช่วงข้อมูลต่อปี และปี
$r_t,\ a_t$ผลตอบแทนของกลยุทธ์ที่ขนาดเต็มในวันที่ $t$ และขนาดที่ถือ (1 คือเต็ม)สัดส่วน
$c$ต้นทุนต่อการเปลี่ยนขนาดหนึ่งหน่วยสัดส่วนของทุน
$D^{*},\ F_t,\ C_t$หลุมที่ยอมได้มากที่สุด พื้น $(1-D^{*})H_t$ และ cushion $W_t-F_t$สัดส่วน และดอลลาร์
$m,\ E_t$ตัวคูณ cushion และเงินที่ลงในกลยุทธ์เท่า และดอลลาร์

ขั้นที่ 1 — นับหลุมด้วยมือ: หกวันของทุน ยอดสูงสุด และ drawdown

เริ่มจากตัวเลขของโจทย์ ทุนหกวัน (ล้านดอลลาร์) คือ 1.000, 1.100, 0.880, 0.968, 1.0648 และ 1.120 ไม่มีเงินฝากถอน ความเจ็บวัดจากยอดที่เคยเห็น ไม่ใช่จากเงินต้น จึงต้องเดินหายอดสูงสุดสะสมก่อน แล้วค่อยเทียบทุนกับมัน

\[ \begin{aligned} H_t&=\max(W_0,\ W_1,\ \dots,\ W_t),\\ D_t&=1-\frac{W_t}{H_t},\\ H&=(1.000,\ 1.100,\ 1.100,\\ &\qquad1.100,\ 1.100,\ 1.120),\\ D_2&=1-\frac{0.880}{1.100}=0.20,\\ D_3&=1-\frac{0.968}{1.100}=0.12,\\ D_4&=1-\frac{1.0648}{1.100}=0.032,\\ D_{\max}&=0.20. \end{aligned} \]

วันที่ 2 ทุนตกเหลือ 0.88 แต่ยอดสะสมยังเป็น 1.1 เพราะมันจำค่าสูงสุดไว้และไม่ลดตามทุน วันที่ 3 กำไร 10% เป็น 0.968 แต่ยังต่ำกว่ายอด 12% วันที่ 4 กำไรอีก 10% ยังต่ำกว่ายอด 3.2% วันที่ 5 ทำยอดใหม่ 1.12 หลุมจึงกลับเป็นศูนย์

กำไร 10% สองวันรวมกันได้ $1.1^2-1=21\%$ จริง แต่ทุนขึ้นจาก 0.88 เป็นแค่ $0.88\times1.21=1.0648$ ยังไม่ถึง 1.1 นี่คือสัญญาณแรกว่าการฟื้นต้องใช้เปอร์เซ็นต์มากกว่าที่เสีย ขั้นถัดไปจะหาว่ามากกว่าเท่าไรพอดี

เรื่องระยะเวลา: มีสามวันติดกันที่ปิดต่ำกว่ายอด (วันที่ 2–4) แต่จากวันทำยอด (วันที่ 1) ถึงวันฟื้น (วันที่ 5) ผ่านไปสี่วัน รายงานต้องบอกว่าใช้นิยามไหน

ขั้นที่ 2 — ตก 20% ต้องฟื้นเท่าไร

กลับไปวันที่บัญชีเหลือ \$880,000 ทุนที่เหลือต้องโตอีก $R$ จนกลับถึงยอด เขียนเงื่อนไข “โตแล้วถึงยอดพอดี” เป็นสมการ แล้วแก้หา $R$

\[ \begin{aligned} W_t(1+R)&=H_t,\\ (1-D_t)(1+R)&=1,\\ R&=\frac{1}{1-D_t}-1=\frac{D_t}{1-D_t},\\ D=0.10&:\ R\approx11.11\%,\\ D=0.20&:\ R=25\%,\\ D=0.35&:\ R\approx53.85\%,\\ D=0.50&:\ R=100\%. \end{aligned} \]

บรรทัดที่สองมาจากการแทน $W_t=H_t(1-D_t)$ แล้วหารทั้งสองข้างด้วย $H_t$ ยอดสูงสุดตัดกันหมด เหลือแค่สัดส่วน คำตอบจึงใช้ได้กับบัญชีทุกขนาด ตรวจ: $880{,}000\times1.25=1{,}100{,}000$

ทำไมต้องฟื้นมากกว่าที่เสีย? เงิน \$220,000 ที่หายไปเท่ากับ 20% ของฐาน \$1.1 ล้าน แต่การหาเงินจำนวนเดิมกลับมาต้องทำจากฐานที่เหลือ \$880,000 ซึ่งเล็กกว่า จึงเป็น 25% ของฐานใหม่ ส่วนเกินโตเร็วขึ้นเรื่อย ๆ: หลุม 10% ต้องฟื้น 11.11% แต่หลุม 50% ต้องฟื้น 100% เปอร์เซ็นต์ที่ลงกับที่ขึ้นจึงหักล้างกันตรง ๆ ไม่ได้ เพราะคิดจากฐานคนละจำนวน

ขั้นที่ 3 — เงินฝากถอนไม่ใช่กำไรขาดทุน: วัดหลุมบนมูลค่าต่อหน่วย

สูตรของขั้นที่ผ่านมาใช้ทุน $W_t$ ตรง ๆ ซึ่งถูกเฉพาะเมื่อไม่มีเงินเข้าออก ถ้าลูกค้าถอน \$200,000 ในวันที่ตลาดนิ่ง ทุนลดทั้งที่ไม่มีใครขาดทุน วิธีแก้คือแยกผลตอบแทนของแต่ละวันออกจากเงินที่เข้าออก แล้วต่อผลตอบแทนเป็นมูลค่าต่อหน่วย ซึ่งเป็นสิ่งที่กองทุนรวมรายงานเป็น NAV ต่อหน่วย

\[ \begin{aligned} W_t&=W_{t-1}(1+r_t)+Q_t,\\ r_t&=\frac{W_t-Q_t}{W_{t-1}}-1,\\ U_t&=U_{t-1}(1+r_t),\quad U_0=1,\\ W&:\ 1.1\ \to\ 0.9,\quad Q=-0.2,\\ r&=\frac{0.9-(-0.2)}{1.1}-1=0,\\ 1-\frac{0.9}{1.1}&\approx18.18\%,\\ 1-\frac{U_t}{\max U}&=0. \end{aligned} \]

บรรทัดแรกบอกลำดับเหตุการณ์ที่สมมติ: เงินโตตามตลาดก่อน แล้วเงินฝากถอนเข้าออกตอนปิดวัน บรรทัดที่สองแก้หา $r_t$ โดยบวกเงินที่ถอนกลับเข้าไปก่อนเทียบกับเมื่อวาน วันที่ถอน \$200,000 ตอนตลาดนิ่งจึงได้ $r=0$ หลุมที่ถูกต้องคือศูนย์ ถ้าใช้ทุนตรง ๆ จะได้หลุมปลอม 18.18%

มูลค่าต่อหน่วยตอบว่า “ผู้จัดการทำผลงานอย่างไร” แต่เงินของลูกค้ารวมกันอาจเจออีกเรื่อง ตัวอย่าง: ปีแรกกองทุนบริหารเงิน \$1 ล้านได้ +20% ลูกค้าเห็นผลงานดีจึงเติมจนเป็น \$10 ล้าน ปีที่สองได้ −10% ค่าเฉลี่ยรายปีคือ $(20\%-10\%)/2=5\%$ มูลค่าต่อหน่วยจบที่ $1.2\times0.9=1.08$ แต่ลูกค้ารวมกันได้ \$200,000 ในปีแรกและเสีย \$1,000,000 ในปีที่สอง ขาดทุนสุทธิ \$800,000 หรือ $(1\times20\%-10\times10\%)/11\approx-7.27\%$ ต่อดอลลาร์ต่อปี drawdown กับ Calmar ในหน้านี้คิดบนมูลค่าต่อหน่วย ส่วนประสบการณ์ของเงินลูกค้าต้องดูแยก

ขั้นที่ 4 — CAGR และ Calmar ต้องมาจากหน้าต่างเดียวกัน

Calmar ratio เอาผลตอบแทนหารด้วยความเจ็บ ผลตอบแทนในที่นี้คืออัตราโตทบต้นคงที่ที่พาทุนต้นทางไปถึงทุนปลายทางพอดี (บรรทัดแรกคือนิยาม) แล้วถอดรากเพื่อแกะอัตราออกมา จากนั้นลองกับทุนสิ้นปี 0 ถึง 3 ที่เป็น 1.00, 1.20, 0.90 และ 1.10 ล้านดอลลาร์

\[ \begin{aligned} \frac{W_T}{W_0}&=(1+g)^{T},\\ g&=\Big(\frac{W_T}{W_0}\Big)^{1/T}-1,\\ \mathrm{Calmar}&=\frac{g}{D_{\max}},\\ D_{\max}&=1-\frac{0.90}{1.20}=0.25,\\ g&=1.10^{1/3}-1\approx0.03228,\\ \mathrm{Calmar}&\approx\frac{0.03228}{0.25}\approx0.129,\\ \bar r&=\frac{0.20-0.25+0.2222}{3}\\ &\approx5.74\%. \end{aligned} \]

หลุมลึกสุดคือปีที่ 2 ที่ลงจาก 1.20 เหลือ 0.90 ทบต้นได้แค่ปีละ 3.228% ตรวจ: $1.03228^3\approx1.100$ Calmar 0.129 คือได้ราว 0.13 ส่วนต่อความเจ็บหนึ่งส่วน

ค่าเฉลี่ยเลขคณิตของผลตอบแทนรายปี (+20%, −25%, +22.22%) คือ 5.74% สูงกว่าอัตราทบต้นเกือบสองเท่า เพราะการตก 25% ต้องฟื้น 33.3% ตามสูตรของขั้นที่ 2 ช่องว่างระหว่างสองตัวเลขนี้คือ volatility drag ที่เห็นในKelly criterion (ค่าเฉลี่ยของ log ต่ำกว่า log ของค่าเฉลี่ย) Calmar จึงต้องใช้ $g$ ไม่ใช่ $\bar r$

เงื่อนไขสำคัญกว่าสูตร: $g$ กับ $D_{\max}$ ต้องมาจากช่วงเดียวกันและความถี่เดียวกัน หลุมที่วัดรายวันลึกเท่ากับหรือมากกว่าที่วัดรายเดือนเสมอ เพราะจุดรายเดือนเป็นส่วนหนึ่งของจุดรายวัน และช่วงข้อมูลยาวเจอหลุมลึกเท่ากับหรือมากกว่าช่วงสั้นที่อยู่ข้างใน ธรรมเนียมเดิมของ Calmar ใช้ 36 เดือนย้อนหลัง

ขั้นที่ 5 — ผลตอบแทนชุดเดียวกัน สลับลำดับ หลุมต่างกันเกือบเท่าตัว

โจทย์ให้อะไรมาบ้าง: กลยุทธ์ A ได้ +10%, +10%, −10%, −10% กลยุทธ์ B ได้ +10%, −10%, +10%, −10% เป็นผลตอบแทนสี่ตัวชุดเดียวกัน แค่สลับลำดับ หา Sharpe, CAGR และ maximum drawdown ของทั้งสอง

\[ \begin{aligned} W^{A}&=1,\ 1.1,\ 1.21,\\ &\qquad1.089,\ 0.9801,\\ W^{B}&=1,\ 1.1,\ 0.99,\\ &\qquad1.089,\ 0.9801,\\ D^{A}_{\max}&=1-\frac{0.9801}{1.21}=19\%,\\ D^{B}_{\max}&=1-\frac{0.9801}{1.1}\approx10.9\%. \end{aligned} \]

คำตอบ: ค่าเฉลี่ยและความผันผวนคิดจากตัวเลขสี่ตัว +10, +10, −10 และ −10 ซึ่งเป็นสี่ตัวเดียวกันทั้งสองกลยุทธ์ Sharpe จึงเท่ากันทุกตำแหน่งทศนิยม ทุนปลายทางก็เท่ากัน (0.9801) เพราะการคูณ $(1.1)(1.1)(0.9)(0.9)$ สลับลำดับได้ CAGR จึงเท่ากันด้วย สิ่งเดียวที่ต่างคือหลุม: A ขึ้นไปยอด 1.21 แล้วร่วงสองวันติด ลึก 19% ส่วน B ไม่เคยขึ้นสูงกว่า 1.1 และตกไม่เคยเกินทีละวัน ลึกแค่ 10.9% Calmar ของสองกลยุทธ์จึงต่างกันเกือบเท่าตัว ทั้งที่ Sharpe เหมือนกัน

ตรวจเองใน 10 วินาที: $1.21\times0.9\times0.9=0.9801$ และ $1.1\times0.9\times1.1\times0.9=0.9801$

ขั้นที่ 6 — เขียนกฎลดขนาดแบบขั้นบันไดให้ใช้ได้จริง

รู้วิธีวัดหลุมแล้ว คำถามต่อไปคือทำอะไรกับมัน กฎตัวอย่าง: หลังปิดวัน ถ้าหลุมต่ำกว่า 10% ใช้ขนาดเต็ม ตั้งแต่ 10% แต่ต่ำกว่า 20% ใช้ครึ่งขนาด ตั้งแต่ 20% พักความเสี่ยง ขนาดที่ตัดสินใช้กับวันถัดไปเท่านั้น เพราะหลุมของวันนี้รู้ตอนปิด และทุกครั้งที่เปลี่ยนขนาดเสียต้นทุน $c$ ต่อหนึ่งหน่วยของการเปลี่ยน

\[ \begin{aligned} a_{t+1}&=\begin{cases}1,&D_t\lt0.10,\\0.5,&0.10\le D_t\lt0.20,\\0,&D_t\ge0.20,\end{cases}\\ W_{t+1}&=W_t\big(1-c\,|a_{t+1}-a_t|\big)\\ &\quad\times\big(1+a_{t+1}r_{t+1}\big),\\ c&=0.001,\\ \text{cost}&=1{,}000{,}000(0.001)(0.5)\\ &=500. \end{aligned} \]

ตัวห้อย $t+1$ กับ $t$ คือหัวใจของกฎ: ใช้ข้อมูลถึงเมื่อวานตัดสินขนาดของวันนี้ ถ้าเผลอใช้หลุมของวันเดียวกับผลตอบแทน การทดสอบย้อนหลังจะลดขนาดก่อนวันร้ายได้อย่างวิเศษ ซึ่งทำจริงไม่ได้

ต้นทุนหักจากทุนก่อนรับผลตอบแทน บัญชี \$1 ล้านที่ลดจากเต็มเป็นครึ่งเสีย \$500 เงินสดส่วนที่ไม่ได้ลงทุนสมมติว่าไม่ได้ดอกเบี้ย ตัวเลข 10% กับ 20% เป็นค่าที่เลือกมาสาธิต ไม่ใช่มาตรฐาน

ขั้นที่ 8 — กฎแบบต่อเนื่องของ Grossman–Zhou: ลงทุนตามเบาะที่เหลือเหนือพื้น

กฎขั้นบันไดมีสองจุดอ่อน: ขนาดกระโดดทีละขั้น และเพดาน 20% เป็นแค่คำสัญญา Grossman กับ Zhou (1993) เสนอกฎที่ต่อเนื่องกว่า: ตั้งพื้นไว้ที่ $1-D^{*}$ ของยอด เช่น 80% ของยอดถ้ายอมหลุมได้ $D^{*}=20\%$ ส่วนของทุนที่อยู่เหนือพื้นเรียกว่า cushion แล้วลงทุนเป็นจำนวนเท่าของ cushion

\[ \begin{aligned} F_t&=(1-D^{*})H_t,\\ C_t&=W_t-F_t,\\ E_t&=m\,C_t,\\ C_{t+1}&=C_t+E_t\,r_{t+1}\\ &=C_t\,(1+m\,r_{t+1}),\\ \frac{E_t}{W_t}&=m\Big(1-\frac{1-D^{*}}{1-D_t}\Big). \end{aligned} \]

บรรทัดที่สี่คือเหตุผลทั้งหมด: ระหว่างที่ยังไม่ทำยอดใหม่ พื้น $F_t$ อยู่กับที่ กำไรขาดทุนของวันจึงตกกับ cushion ทั้งก้อน และเพราะเงินที่ลงทุนเป็น $m$ เท่าของ cushion การเปลี่ยนของ cushion จึงเป็นสัดส่วนกับตัวมันเอง cushion ถูกคูณด้วย $(1+m\,r)$ ทุกวัน ตัวคูณนี้ติดลบได้ก็ต่อเมื่อวันเดียวขาดทุนเกิน $1/m$ ถ้าปรับขนาดถี่จนแต่ละช่วงขยับนิดเดียว cushion จะหดเข้าหาศูนย์ได้แต่ไม่ทะลุ ทุนจึงไม่ต่ำกว่าพื้น หลุมไม่เกิน $D^{*}$

บรรทัดสุดท้ายได้จากการหาร $E_t=m(W_t-F_t)$ ด้วย $W_t$ แล้วแทน $W_t=H_t(1-D_t)$ ขนาดจึงลดลงอย่างต่อเนื่องตามหลุม แทนที่จะกระโดดเป็นขั้น ในงานต้นฉบับ $m$ คือขนาด Kelly $\mu/\sigma^2$ ของKelly criterion ที่ยอดจึงถือ $D^{*}$ เท่าของ Kelly เช่นกองทุน 60/40 ของบทนี้ที่ Kelly สั่ง 2.5 เท่า กับ $D^{*}=20\%$ จะถือ 0.5 เท่าที่ยอด เพื่อเทียบกับกฎขั้นบันไดอย่างยุติธรรม หน้านี้เลือก $m=1/D^{*}=5$ ให้ถือเต็มขนาดที่ยอดเท่ากัน

ขั้นที่ 9 — เทียบสองกฎ: ขนาดตามหลุม วันกระโดด และเส้นทาง 12 วัน

โจทย์ให้อะไรมาบ้าง: กฎ Grossman–Zhou กับ $D^{*}=0.20$ และ $m=5$ หาขนาดที่หลุม 0%, 10% และ 15% หาหลุมหลังวันที่กลยุทธ์ขนาดเต็มร่วง 25% โดยเริ่มจากหลุม 5% แล้วลองกับเส้นทาง 12 วันเดิม (ต้นทุน $c=0.001$)

\[ \begin{aligned} D=0&:\ 5(1-0.8)=1,\\ D=0.10&:\ 5\big(1-\tfrac{0.8}{0.9}\big)\approx0.556,\\ D=0.15&:\ 5\big(1-\tfrac{0.8}{0.85}\big)\approx0.294,\\ \text{step}&:\ 1-0.95(0.75)=28.75\%,\\ E&=5(0.95-0.80)H=0.75H,\\ W&=0.95H-0.25(0.75H)\\ &=0.7625H,\\ \text{GZ}&:\ 1-0.7625=23.75\%. \end{aligned} \]

คำตอบ: ขนาดลดจาก 1 เป็น 0.556 ที่หลุม 10% และ 0.294 ที่หลุม 15% เกือบเป็นเส้นตรงไปถึงศูนย์ที่ 20% วันที่ร่วง 25% จากหลุม 5% กฎขั้นบันไดยังถือเต็มจึงทะลุไปถึง 28.75% กฎ Grossman–Zhou ถือแค่ 0.789 ของทุนจึงไปถึง 23.75% ทั้งสองทะลุพื้น 20% เพราะ 25% เกิน $1/m=20\%$ ซึ่งเป็นวันที่ขาดทุนเกินกว่าที่สมมติฐาน “ปรับขนาดได้ทันก่อนราคาขยับมาก” รองรับ

ขั้นที่ 10 — ราคาที่กฎทุกแบบต้องจ่าย: Sharpe ลดเมื่อขนาดแกว่ง

นอกจากพลาดช่วงเด้ง ยังมีต้นทุนที่ลึกกว่า ถ้าการเปลี่ยนขนาดไม่ได้รู้อะไรเกี่ยวกับผลตอบแทนข้างหน้า การปล่อยให้ขนาดแกว่งจะลด Sharpe เสมอ ให้กลยุทธ์ที่ขนาดเต็มมีผลตอบแทนเฉลี่ย $s\sigma$ ความผันผวน $\sigma$ ต่อวัน (Sharpe $s$) และขนาด $a_t$ ไม่เกี่ยวกับผลตอบแทนของวันนั้น

\[ \begin{aligned} \mathbb E[a_t r_t]&=\bar a\,s\sigma,\\ \operatorname{Var}(a_t r_t)&\approx\overline{a^2}\,\sigma^2,\\ \mathrm{SR}&\approx s\,\frac{\bar a}{\sqrt{\overline{a^2}}},\\ \overline{a^2}-\bar a^{2}&\ge0,\\ a=(0.5,\ 1.5)&:\ \frac{1}{\sqrt{1.25}}\approx0.894,\\ \text{12 days}&:\ \frac{0.7917}{\sqrt{0.6875}}\approx0.955. \end{aligned} \]

บรรทัดแรกใช้ว่า $a_t$ ไม่เกี่ยวกับ $r_t$ ค่าเฉลี่ยของผลคูณจึงเป็นผลคูณของค่าเฉลี่ย บรรทัดที่สองประมาณ variance ด้วย $\overline{a^2}\sigma^2$ ซึ่งแม่นเมื่อ Sharpe รายวันเล็ก (ส่วนที่ทิ้งคือก้อน $s^2\sigma^2$) บรรทัดที่สี่คือ variance ของ $a$ ที่ไม่ติดลบ จึงได้ $\bar a\le\sqrt{\overline{a^2}}$ และ Sharpe ไม่มีวันสูงกว่า $s$ เท่ากันได้เฉพาะเมื่อขนาดคงที่

ตัวอย่าง: ถือครึ่งขนาดครึ่งปี แล้ว 1.5 เท่าอีกครึ่งปี ค่าเฉลี่ยขนาดยังเป็น 1 แต่ Sharpe เหลือ 89.4% ของเดิม ขนาดของกฎขั้นบันไดใน 12 วัน (เต็ม 7 วัน ครึ่ง 5 วัน) เสีย Sharpe 4.5% ถ้าการลดขนาดไม่ได้จับจังหวะอะไรได้จริง กฎลดขนาดจึงเหมือนซื้อ put option ของกลยุทธ์ตัวเอง: จ่ายเบี้ยประกันเป็นผลตอบแทนที่หายไปทุกครั้งที่ลดขนาดแล้วตลาดเด้ง เพื่อแลกกับหลุมที่ตื้นขึ้น จะคุ้มหรือไม่ขึ้นกับว่าความเจ็บจากหลุมลึกแพงแค่ไหนสำหรับเจ้าของเงิน

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

วัดหลุมจากเงินต้น: บัญชีในโจทย์ลงแค่ 12% จากเงินต้น แต่ลง 20% จากยอด และต้องฟื้น 25% ไม่ใช่ 12%

นับเงินถอนเป็นขาดทุน: ลูกค้าถอน \$200,000 จากยอด \$1.1 ล้านในวันที่ตลาดนิ่ง ถ้าคิดบนทุนตรง ๆ จะได้หลุมปลอม 18.18% ต้องคิดบนมูลค่าต่อหน่วย

ใช้ข้อมูลอนาคตตัดสินขนาด: การใช้ $D_{t+1}$ ตัดสิน $a_{t+1}$ ใช้ข้อมูลที่ตอนตัดสินใจยังไม่รู้ ผลทดสอบจะดูดีกว่าที่ทำได้จริง

พักแล้วไม่มีทางกลับ: เมื่อกฎขั้นบันไดพักความเสี่ยง ทุนไม่ขยับ หลุมจึงค้างที่เดิมตลอดไป กฎไม่มีวันสั่งกลับเข้าเอง ต้องเขียนกฎกลับเข้าแยก เช่นประเมินใหม่หลังพัก 20 วันทำการ หรือรีเซ็ตยอดตามกฎที่ประกาศไว้ล่วงหน้า

เทียบ Calmar ต่างหน้าต่างหรือต่างความถี่: กองทุนที่มีข้อมูล 3 ปีดู Calmar ดีกว่ากองที่มี 15 ปีได้ เพียงเพราะหน้าต่างสั้นยังไม่เจอหลุมใหญ่ และหลุมรายเดือนตื้นกว่าหลุมรายวันเสมอ

เลือกจุดตัดจากเส้นทางเดียว: ไล่หาจุดตัดที่ให้ผลดีที่สุดบนเส้นทางทดสอบเส้นเดียวแล้วเรียกว่าผลนอกตัวอย่าง คือการใช้ข้อมูลทดสอบเป็นข้อมูลฝึก

ใช้ทำอะไรบนโต๊ะจริง

ผู้จัดสรรเงินให้กองทุนดู maximum drawdown และเวลาใต้น้ำคู่กับ Sharpe เพราะลูกค้ามักถอนเงินตอนหลุมลึก ไม่ใช่ตอน Sharpe ต่ำ กองทุนที่มีผู้จัดการหลายทีมเขียนกฎ stop-out ไว้ในสัญญาของแต่ละทีม: ลงจากยอดถึงระดับหนึ่งให้ลดขนาด ถึงอีกระดับให้ปิดสถานะ ส่วนฝ่ายบริหารความเสี่ยงทดสอบกฎแบบนี้กับเส้นทางจำนวนมาก เช่นเส้นทางจาก block bootstrap ในMonte Carlo และ bootstrap และรวมต้นทุนการซื้อขายจริงเข้าไปด้วย เพราะกฎแบบต่อเนื่องอย่าง Grossman–Zhou ปรับขนาดบ่อยและแรงที่สุดตอนตลาดป่วน

เฉลย

cushion คือ $0.85H-0.80H=0.05H$ เงินที่ลงทุน $5\times0.05H=0.25H$ คิดเป็น $0.25/0.85\approx29.4\%$ ของทุน บัญชีถึงพื้นเมื่อเสียเท่ากับ cushion: $0.25H\times x=0.05H$ ได้ $x=20\%=1/m$ ค่านี้ไม่ขึ้นกับว่าตอนนี้หลุมลึกแค่ไหน เพราะ cushion ถูกคูณด้วย $(1+m\,r)$ เสมอ

// Running peak, drawdown and the deepest hole of a wealth (or unit-value) path.
function drawdowns(W) {
  let H = -Infinity, maxD = 0;
  const dd = W.map(w => { H = Math.max(H, w); const d = 1 - w / H; maxD = Math.max(maxD, d); return d; });
  return {dd, maxD};
}
const recovery = D => D / (1 - D);                         // W(1 + R) = H with W = H(1 - D)
const cagr = (W0, WT, years) => (WT / W0) ** (1 / years) - 1;
// Unit value: strip deposits Q (withdrawals negative) that arrive at the close.
function unitValue(W, Q) {
  const U = [1];
  for (let t = 1; t < W.length; t++) U.push(U[t - 1] * (W[t] - Q[t]) / W[t - 1]);
  return U;
}
// Run a sizing rule on full-size daily returns; size is decided from yesterday's close.
function run(returns, size, c = 0.001) {
  let W = 1, H = 1, prev = 1, maxD = 0, costs = 0;
  const sizes = [];
  for (const r of returns) {
    const a = size(W, H);
    const cost = c * Math.abs(a - prev) * W;
    W = (W - cost) * (1 + a * r);
    costs += cost; prev = a; sizes.push(a);
    H = Math.max(H, W); maxD = Math.max(maxD, 1 - W / H);
  }
  return {W, maxD, costs, sizes};
}
const hold = () => 1;
const stairs = (W, H) => { const D = 1 - W / H; return D < 0.10 - 1e-12 ? 1 : D < 0.20 - 1e-12 ? 0.5 : 0; };
const gz = (m, Dstar) => (W, H) => Math.max(0, m * (W - (1 - Dstar) * H)) / W;   // m times the cushion

const r12 = [0.02, -0.06, -0.05, -0.04, -0.08, 0.06, 0.07, 0.05, 0.04, 0.03, -0.02, 0.03];
const a = run(r12, hold), b = run(r12, stairs), g = run(r12, gz(5, 0.2));
const mean = x => x.reduce((s, v) => s + v, 0) / x.length;
console.log({
  six: drawdowns([1, 1.1, 0.88, 0.968, 1.0648, 1.12]).maxD,               // 0.20
  recover: [0.10, 0.20, 0.35, 0.50].map(recovery),                       // 0.1111, 0.25, 0.5385, 1
  withdrawal: drawdowns(unitValue([1.1, 0.9], [0, -0.2])).maxD,          // 0, not 0.1818
  perDollar: (1 * 0.20 - 10 * 0.10) / 11,                                // -0.0727
  calmar3: cagr(1, 1.1, 3) / drawdowns([1, 1.2, 0.9, 1.1]).maxD,         // 0.129
  orderA: drawdowns([1, 1.1, 1.21, 1.089, 0.9801]).maxD,                 // 0.19

  gapStairs: 1 - 0.95 * 0.75,                                           // 0.2875

สิ่งที่ควรตอบได้หลังอ่าน

  • drawdown วัดจากยอดสูงสุดสะสมซึ่งไม่มีวันลดลง: จาก \$1.1 ล้านเหลือ \$880,000 คือหลุม 20% ไม่ใช่ 12%
  • หลุม $D$ ต้องฟื้น $D/(1-D)$ เพราะเงินก้อนเดิมต้องหาจากฐานที่เล็กลง: 20% ต้อง 25% และ 50% ต้อง 100%
  • หลุมต้องคิดบนมูลค่าต่อหน่วยที่ตัดเงินฝากถอนออก และ Calmar คือ CAGR หารด้วยหลุมลึกสุดในหน้าต่างเดียวกัน: 3.228%/25% ≈ 0.129
  • Sharpe มองไม่เห็นลำดับ: ผลตอบแทนชุดเดียวกันให้หลุม 19% หรือ 10.9% ได้ ขึ้นกับว่ามาเรียงอย่างไร
  • กฎลดขนาดทำให้หลุมตื้นขึ้น (21.13% เป็น 16.03% หรือ 14.99%) แต่จ่ายด้วยกำไรตอนเด้ง และ Sharpe ที่ลดเมื่อขนาดแกว่ง ส่วนวันที่ร่วงเกิน $1/m$ พาหลุมทะลุเพดานได้ทุกกฎ

กฎลดขนาดหลายแบบใช้ VaR เป็นสัญญาณเตือน แต่ VaR ที่ประกาศไว้เชื่อได้แค่ไหน หน้าถัดไป VaR backtesting: Kupiec และ Christoffersen นับวันที่ขาดทุนเกิน VaR แล้วถามว่ามีมากเกินไปไหม และมาติดกันเกินไปไหม
