17.6 Drawdown, Calmar, and De-risking Rules

drawdown วัดว่าทุนวันนี้ต่ำกว่ายอดสูงสุดที่เคยทำได้กี่เปอร์เซ็นต์ หลุมยิ่งลึกยิ่งต้องฟื้นมากกว่าที่เสีย และกฎลดขนาดเมื่อหลุมลึกช่วยให้หลุมตื้นขึ้นโดยแลกกับกำไรตอนตลาดฟื้น

ผู้จัดการกองทุนคนหนึ่งรับเงินจากนักลงทุนมาลงทุนให้ เงินในบัญชีขึ้นลงทุกวันตามผลการลงทุน นักลงทุนจำได้ว่าเงินของตัวเองเคยขึ้นไปสูงสุดเท่าไร และเจ็บเมื่อเห็นเงินส่วนนั้นหายไป

บัญชีนี้มีตัวเลขสมมติดังนี้:

  • เงินต้นตอนเริ่ม \$1,000,000
  • ต่อมาเงินขึ้นไปถึงยอดสูงสุด \$1,100,000
  • วันนี้เงินลดลงเหลือ \$880,000

ผู้จัดการเทียบกับเงินต้น ได้ $1-\dfrac{880{,}000}{1{,}000{,}000}=12\%$ แล้วบอกนักลงทุนว่า “เราลงไปแค่ 12% ทำกำไรอีก 12% ก็กลับมาแล้ว” ประโยคนี้ผิดตรงไหน?

คำถามที่สองเป็นเรื่องกฎ บัญชีนี้ตั้งกฎไว้ว่า “ถ้าเงินลดลงจากยอดสูงสุดถึง 10% ให้ลดเงินที่ลงทุนเหลือครึ่งเดียว อีกครึ่งถือเป็นเงินสด” กฎนี้ช่วยได้เท่าไร และต้องจ่ายอะไรแลก?

ลองตอบก่อนเปิดเฉลย

ความเจ็บต้องวัดจากยอด \$1,100,000 ไม่ใช่จากเงินต้น สัดส่วนที่เงินลดลงจากยอดสูงสุดเรียกว่า drawdown ส่วนกำไร $R$ ที่ต้องทำเพื่อกลับถึงยอด ต้องคิดจากเงินที่เหลือ \$880,000:

\[\begin{aligned}\text{drawdown}&=1-\frac{880{,}000}{1{,}100{,}000}=20\%,\\R&=\frac{1{,}100{,}000}{880{,}000}-1=25\%,\\880{,}000\times1.12&=\$985{,}600.\end{aligned}\]

บัญชีจึงลงจากยอด 20% ไม่ใช่ 12% และต้องกำไร 25% จึงกลับถึงยอด ถ้ากำไรแค่ 12% เงินจะไปได้แค่ \$985,600 ซึ่งยังต่ำกว่ายอด

ส่วนกฎลดเงินลงทุน หน้านี้จะลองกับเส้นทางสมมติ 12 วันและคำนวณให้ดูทีละขั้น ผลคือ drawdown ที่ลึกที่สุดตื้นขึ้นจาก 21.13% เหลือ 16.03% แต่บัญชีจบที่ \$1,011,463 แทนที่จะเป็น \$1,035,914 เพราะตอนที่ตลาดเด้งกลับ กฎยังลงทุนแค่ครึ่งเดียว

ภาพรวมก่อนลงสูตร

หน้า VaR และ Expected Shortfall ถามว่าในวันเดียวบัญชีอาจเสียเงินได้เท่าไร แต่เจ้าของเงินไม่ได้เจ็บทีละวัน เขาเจ็บเมื่อเงินที่เคยเห็นในบัญชีหายไป และเจ็บต่อไปจนกว่าจะได้คืน drawdown วัดความเจ็บแบบนี้ มันคือสัดส่วนที่เงินในบัญชีวันนี้ต่ำกว่ายอดสูงสุดที่เคยทำได้ หน้านี้จะเรียกช่องว่างนี้สั้น ๆ ว่า “หลุม”

ความลึกของหลุมขึ้นกับลำดับของผลตอบแทน ไม่ใช่แค่ค่าเฉลี่ยกับความผันผวน ตัววัดยอดนิยมอย่าง Sharpe ratio (ผลตอบแทนเฉลี่ยหารด้วยความผันผวน) ไม่สนว่าวันดีกับวันร้ายมาเรียงกันอย่างไร จึงมองไม่เห็นหลุม

รูปด้านล่างเล่าเรื่องทั้งหน้าในภาพเดียว เป็นเส้นทางสมมติ 12 วันของบัญชี \$1 ล้าน:

  • เส้นน้ำเงินคือเงินในบัญชีแต่ละวัน
  • เส้นประคือยอดสูงสุดสะสม คือเงินที่สูงที่สุดเท่าที่เคยเห็นมา เส้นนี้ขึ้นได้อย่างเดียว ไม่ลงตามเงินในบัญชี
  • พื้นที่แดงระหว่างสองเส้นคือหลุม แท่งแดงด้านล่างคือความลึกของหลุมในแต่ละวัน

หลุมลึกที่สุดคือ 21.13% ในวันที่ 5 แล้วต้องใช้อีกห้าวัน (ถึงวันที่ 10) เงินจึงกลับถึงยอดเดิม ตัวเลข 21.13% นี้หน้านี้จะคำนวณให้ดูในขั้นที่ 7

ลำดับของหน้า: นับหลุมด้วยมือ หาว่าหลุมลึกเท่าไรต้องฟื้นเท่าไร แยกเงินที่ลูกค้าฝากหรือถอนออกจากผลงานจริง สร้าง Calmar ratio (ผลตอบแทนต่อปีหารด้วยหลุมที่ลึกที่สุด) แล้วเขียนกฎลดเงินลงทุนสองแบบ คือแบบขั้นบันได กับแบบต่อเนื่องของ Grossman–Zhou ลองทั้งสองกฎกับเส้นทางเดียวกัน และจบที่ราคาที่กฎทุกแบบต้องจ่าย

ศัพท์ที่ใช้ในหัวข้อนี้
Drawdown (หลุม)
สัดส่วนที่เงินในบัญชีตอนนี้ต่ำกว่ายอดสูงสุดที่เคยทำได้ เช่นยอดเคยเป็น \$100 ตอนนี้เหลือ \$90 หลุมคือ $1-90/100=10\%$ ตัวนี้วัดความเสียหายที่เจ้าของเงินรู้สึกจริงระหว่างทาง
High-water mark (ยอดสูงสุดสะสม)
เงินในบัญชีที่สูงที่สุดตั้งแต่เริ่มจนถึงวันนี้ ค่านี้ไม่มีวันลดลง ใช้เป็นฐานของ drawdown กองทุนจำนวนมากยังใช้มันเป็นฐานคิดค่าธรรมเนียมผลงาน คือเก็บค่าธรรมเนียมได้เฉพาะกำไรที่อยู่เหนือยอดเดิม
Maximum drawdown
หลุมที่ลึกที่สุดในช่วงเวลาที่วัด บอกว่าในช่วงนั้นเจ้าของเงินต้องทนความเจ็บหนักที่สุดเท่าไร
Time under water (เวลาใต้น้ำ)
ระยะเวลาที่เงินยังไม่กลับถึงยอดเดิม นับได้สองแบบ คือนับจำนวนวันที่ปิดต่ำกว่ายอด หรือนับจากวันที่ทำยอดถึงวันที่ฟื้น สองแบบนี้ต่างกันหนึ่งวัน รายงานจึงต้องบอกว่าใช้แบบไหน
Time-weighted return
ผลตอบแทนที่ตัดผลของเงินที่ลูกค้าฝากหรือถอนออก วิธีคือคิดผลตอบแทนของแต่ละวันแยกจากเงินเข้าออก แล้วคูณต่อกันเป็นมูลค่าต่อหน่วย (แบบเดียวกับ NAV ต่อหน่วยของกองทุนรวม) ตัวนี้วัดฝีมือผู้จัดการ ไม่ใช่จังหวะที่ลูกค้าเติมหรือถอนเงิน
Sharpe ratio
ผลตอบแทนเฉลี่ยหารด้วยความผันผวน บอกว่าได้ผลตอบแทนเท่าไรต่อการแกว่งหนึ่งหน่วย มันคิดจากค่าเฉลี่ยกับความผันผวนเท่านั้น จึงไม่รู้ว่าวันดีกับวันร้ายมาเรียงกันอย่างไร อ่านเต็มที่หน้า Sharpe ratio
CAGR (compound annual growth rate)
อัตราโตต่อปีแบบทบต้นที่คงที่ ซึ่งพาเงินต้นไปถึงเงินปลายทางได้พอดี เช่นเงินโตจาก 1 เป็น 1.21 ในสองปี คือ CAGR 10% เพราะ $1.1^2=1.21$
Calmar ratio
CAGR หารด้วย maximum drawdown ในช่วงเวลาเดียวกัน ถามว่าได้ผลตอบแทนต่อปีเท่าไร ต่อความเจ็บที่ลึกที่สุดหนึ่งหน่วย ชื่อมาจากจดหมายข่าว California Managed Accounts Reports ที่เสนอตัววัดนี้ในปี 1991
ขนาด (position size)
สัดส่วนของเงินในบัญชีที่ลงไปในกลยุทธ์ 1 คือลงเต็มตามแผนปกติ 0.5 คือลงครึ่งเดียวและถือเงินสดอีกครึ่ง 0 คือหยุดลงทุน
De-risking rule (stop-out)
กฎที่ลดขนาดลงเองเมื่อหลุมลึกถึงระดับที่ตั้งไว้ ใช้จำกัดความเสียหาย แต่ต้องมีกฎว่าจะกลับมาลงทุนเมื่อไร และการลดขนาดแต่ละครั้งมีต้นทุน
Cushion (เบาะ)
เงินส่วนที่อยู่เหนือ “พื้น” ที่ตั้งไว้ เช่นยอดเคยเป็น \$100 ตั้งพื้นไว้ที่ \$80 ถ้าตอนนี้มี \$95 เบาะคือ $95-80=\$15$ กฎ Grossman–Zhou ลงทุนตามขนาดของเบาะนี้
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$W_t$เงินในบัญชี (ทุน) ตอนปิดวันที่ $t$ดอลลาร์
$H_t$ยอดสูงสุดสะสม คือ $W$ ที่สูงที่สุดตั้งแต่วันที่ 0 ถึงวันที่ $t$ดอลลาร์
$D_t$หลุม (drawdown) $1-W_t/H_t$สัดส่วน
$D_{\max}$หลุมที่ลึกที่สุดในช่วงที่วัดสัดส่วน
$R$กำไรที่ต้องทำต่อจากวันนี้เพื่อกลับถึงยอดสัดส่วน
$Q_t,\ U_t$เงินที่ลูกค้าฝากสุทธิในวันที่ $t$ (ถอนเป็นลบ) และมูลค่าต่อหน่วยดอลลาร์ และไม่มีหน่วย
$g,\ T$CAGR และความยาวของช่วงข้อมูลต่อปี และปี
$r_t,\ a_t$ผลตอบแทนของกลยุทธ์ในวันที่ $t$ ถ้าลงเต็ม และขนาดที่ถือจริง (1 คือเต็ม)สัดส่วน
$c$ต้นทุนการซื้อขายต่อเงินที่ปรับหนึ่งดอลลาร์สัดส่วนของทุน
$D^{*},\ F_t,\ C_t$เพดานหลุมที่ยอมได้ พื้น $(1-D^{*})H_t$ และเบาะ (cushion) $W_t-F_t$สัดส่วน และดอลลาร์
$m,\ E_t$ตัวคูณของเบาะ และเงินที่ลงในกลยุทธ์เท่า และดอลลาร์
$s,\ \sigma$Sharpe ratio รายวัน และความผันผวนรายวันของกลยุทธ์ที่ลงเต็มไม่มีหน่วย และสัดส่วนต่อวัน
$\bar a,\ \overline{a^2}$ค่าเฉลี่ยของขนาด และค่าเฉลี่ยของขนาดยกกำลังสองไม่มีหน่วย

ขั้นที่ 1 — นับหลุมด้วยมือ: หกวันของทุน ยอดสูงสุด และ drawdown

ก่อนจะคุยเรื่องกฎ ต้องนับหลุมให้เป็นก่อน ใช้บัญชีจากโจทย์ต้นหน้า และสมมติว่าไม่มีใครฝากหรือถอนเงินระหว่างทาง เงินในบัญชีตอนปิดวันที่ 0 ถึง 5 (ล้านดอลลาร์ สมมติ) คือ:

  • วันที่ 0: $W_0=1.000$ (เงินต้น) และวันที่ 1: $W_1=1.100$ (ยอดสูงสุด)
  • วันที่ 2: $W_2=0.880$
  • วันที่ 3: กำไร 10% ได้ $W_3=0.88\times1.1=0.968$
  • วันที่ 4: กำไรอีก 10% ได้ $W_4=0.968\times1.1=1.0648$
  • วันที่ 5: $W_5=1.120$

หลุมวัดจากยอดที่เคยเห็น ไม่ใช่จากเงินต้น จึงต้องรู้ยอดสูงสุดสะสม $H_t$ ของทุกวันก่อน $H_t$ คือ $W$ ที่มากที่สุดตั้งแต่วันที่ 0 ถึงวันที่ $t$ จากนั้นหลุม $D_t$ คือสัดส่วนที่ $W_t$ ต่ำกว่า $H_t$

\[ \begin{aligned} H_t&=\max(W_0,\ W_1,\ \dots,\ W_t),\\ D_t&=1-\frac{W_t}{H_t},\\ H&=(1.000,\ 1.100,\ 1.100,\\ &\qquad1.100,\ 1.100,\ 1.120),\\ D_2&=1-\frac{0.880}{1.100}=0.20,\\ D_3&=1-\frac{0.968}{1.100}=0.12,\\ D_4&=1-\frac{1.0648}{1.100}=0.032,\\ D_{\max}&=0.20. \end{aligned} \]

$H$ ทำตัวเหมือนตัวจำค่าสูงสุด วันที่ 2 เงินตกเหลือ 0.88 แต่ $H$ ยังเป็น 1.1 เพราะมันไม่ลดตามเงิน วันที่ 3 และ 4 เงินขึ้นทั้งสองวัน แต่ยังต่ำกว่ายอด หลุมจึงเหลือ 12% และ 3.2% วันที่ 5 เงินขึ้นไป 1.12 ซึ่งสูงกว่ายอดเดิม $H$ จึงขยับขึ้นตาม และหลุมกลับเป็นศูนย์

สังเกตว่ากำไร 10% สองวันติดรวมกันได้เกิน 20%: $1.1^2-1=21\%$ แต่ยังพาเงินจาก 0.88 ไปได้แค่ $0.88\times1.21=1.0648$ ไม่ถึง 1.1 นี่คือสัญญาณแรกว่าการฟื้นต้องใช้เปอร์เซ็นต์มากกว่าที่เสีย ขั้นถัดไปจะหาว่ามากกว่าเท่าไรพอดี

เรื่องเวลาใต้น้ำ: เงินปิดต่ำกว่ายอดสามวันติด (วันที่ 2 ถึง 4) แต่ถ้านับจากวันที่ทำยอด (วันที่ 1) ถึงวันที่ฟื้น (วันที่ 5) จะได้ $5-1=4$ วัน รายงานจึงต้องบอกว่าใช้นิยามไหน

ขั้นที่ 2 — ตก 20% ต้องฟื้นเท่าไร

ผู้จัดการในโจทย์คิดว่าเสียเท่าไรก็ทำคืนเท่านั้น แต่ขั้นที่ 1 เพิ่งเห็นว่ากำไรรวม 21% ยังไม่พอถมหลุม 20% ขั้นนี้จึงหาว่าต้องฟื้นกี่เปอร์เซ็นต์พอดี ให้ $R$ คือกำไรที่ต้องทำต่อจากวันนี้ เงื่อนไขคือเงินวันนี้ $W_t$ โตขึ้น $R$ แล้วเท่ากับยอด $H_t$ พอดี เขียนเงื่อนไขนี้เป็นสมการ แล้วแก้หา $R$

\[ \begin{aligned} W_t(1+R)&=H_t,\\ (1-D_t)(1+R)&=1,\\ R&=\frac{1}{1-D_t}-1=\frac{D_t}{1-D_t},\\ D=0.10&:\ R=\tfrac{0.10}{0.90}\approx11.11\%,\\ D=0.20&:\ R=\tfrac{0.20}{0.80}=25\%,\\ D=0.35&:\ R=\tfrac{0.35}{0.65}\approx53.85\%,\\ D=0.50&:\ R=\tfrac{0.50}{0.50}=100\%. \end{aligned} \]

ก้าวสำคัญคือการเปลี่ยนจากเงินเป็นสัดส่วน นิยามของหลุมเขียนกลับด้านได้เป็น $W_t=H_t(1-D_t)$ แทนค่านี้ลงในเงื่อนไข แล้วหารทั้งสองข้างด้วย $H_t$ ยอดสูงสุดจะตัดกันหมด เหลือแค่ $D_t$ คำตอบจึงใช้ได้กับบัญชีทุกขนาด ตรวจกับโจทย์: $880{,}000\times1.25=1{,}100{,}000$

ทำไมต้องฟื้นมากกว่าที่เสีย? เพราะสองเปอร์เซ็นต์นี้หารด้วยฐานคนละตัว เงินที่หายไปคือ $1{,}100{,}000-880{,}000=\$220{,}000$ ตอนเสีย เงินก้อนนี้เทียบกับฐาน \$1.1 ล้าน ได้ $220{,}000/1{,}100{,}000=20\%$ ตอนหาคืน ต้องหาเงินก้อนเดิมจากฐานที่เหลือ \$880,000 ซึ่งเล็กกว่า จึงได้ $220{,}000/880{,}000=25\%$ ยิ่งหลุมลึก ฐานที่เหลือยิ่งเล็ก ส่วนต่างจึงโตเร็วขึ้นเรื่อย ๆ หลุม 10% ต้องฟื้น 11.11% แต่หลุม 50% ต้องฟื้นถึง 100%

ขั้นที่ 3 — เงินฝากถอนไม่ใช่กำไรขาดทุน: วัดหลุมบนมูลค่าต่อหน่วย

ขั้นที่ผ่านมาคิดหลุมจากเงินในบัญชี $W_t$ ตรง ๆ วิธีนี้ถูกเฉพาะเมื่อไม่มีเงินเข้าออก แต่กองทุนจริงมีลูกค้าฝากและถอนเงินอยู่ตลอด ตัวอย่าง: เงินอยู่ที่ยอด \$1.1 ล้าน แล้วลูกค้าถอน \$200,000 ในวันที่ตลาดนิ่ง เงินในบัญชีเหลือ \$900,000 ทั้งที่ไม่มีใครขาดทุนเลย ถ้าเอา \$900,000 ไปเทียบกับยอด จะเห็นหลุมปลอม

วิธีแก้คือแยกสองเรื่องออกจากกัน ให้ $Q_t$ คือเงินที่ลูกค้าฝากสุทธิในวันที่ $t$ (ถอนเป็นลบ) และ $r_t$ คือผลตอบแทนจากการลงทุนของวันนั้น เราหา $r_t$ ก่อน แล้วคูณผลตอบแทนต่อกันเป็นมูลค่าต่อหน่วย $U_t$ ซึ่งก็คือ NAV ต่อหน่วย (มูลค่าทรัพย์สินสุทธิต่อหน่วย) ที่กองทุนรวมรายงาน ในตัวอย่างนี้ (ล้านดอลลาร์) $W_{t-1}=1.1$, $W_t=0.9$ และ $Q_t=-0.2$ ให้ $D_U$ คือหลุมที่คิดบนมูลค่าต่อหน่วย และ $D_W$ คือหลุมที่คิดบนเงินในบัญชีตรง ๆ

\[ \begin{aligned} W_t&=W_{t-1}(1+r_t)+Q_t,\\ r_t&=\frac{W_t-Q_t}{W_{t-1}}-1,\\ U_t&=U_{t-1}(1+r_t),\quad U_0=1,\\ r_t&=\frac{0.9-(-0.2)}{1.1}-1=0,\\ D_U&=1-\frac{U_t}{\max U}=0,\\ D_W&=1-\frac{0.9}{1.1}\approx18.18\%. \end{aligned} \]

สมการแรกบอกลำดับเหตุการณ์ที่เราสมมติ: เงินโตตามตลาดก่อน แล้วเงินฝากถอนจึงเข้าออกตอนปิดวัน พอแก้หา $r_t$ ก็คือการบวกเงินที่ถอนกลับเข้าไป (หรือหักเงินที่ฝากออก) ก่อนเทียบกับเมื่อวาน วันที่ถอน \$200,000 ตอนตลาดนิ่งจึงได้ $r_t=0$ มูลค่าต่อหน่วยไม่ขยับ หลุมที่ถูกคือศูนย์ ส่วน 18.18% เป็นหลุมปลอมที่เกิดจากเงินถอนล้วน ๆ

มูลค่าต่อหน่วยตอบคำถามว่า “ผู้จัดการทำผลงานอย่างไร” แต่เงินของลูกค้ารวมกันอาจเจออีกเรื่องหนึ่ง ตัวอย่างสมมติ:

  • ปีที่ 1 กองทุนดูแลเงิน \$1 ล้าน ได้ผลตอบแทน +20%
  • ลูกค้าเห็นผลงานดี จึงเติมเงินจนกองทุนมี \$10 ล้าน
  • ปีที่ 2 ได้ผลตอบแทน −10%

ให้ $\bar r$ คือค่าเฉลี่ยของผลตอบแทนรายปี และ $G$ คือกำไรรวมของลูกค้าทุกคน (ล้านดอลลาร์) เงินที่ลงทุนรวมกันสองปีคือ $1+10=11$ ล้านดอลลาร์-ปี (\$1 ล้านลงทุนหนึ่งปี บวก \$10 ล้านลงทุนอีกหนึ่งปี)

\[ \begin{aligned} \bar r&=\frac{20\%+(-10\%)}{2}=5\%,\\ U_2&=1.2\times0.9=1.08,\\ G&=1(0.20)+10(-0.10)\\ &=0.2-1.0=-0.8,\\ \frac{G}{11}&=\frac{-0.8}{11}\approx-7.27\%. \end{aligned} \]

มูลค่าต่อหน่วยโต 8% แต่ลูกค้ารวมกันขาดทุน \$800,000 หรือเฉลี่ยราว 7.27% ต่อดอลลาร์ต่อปี เพราะเงินก้อนใหญ่เข้ามาก่อนปีที่แย่ หน้านี้คิด drawdown กับ Calmar บนมูลค่าต่อหน่วย เพราะต้องการวัดฝีมือผู้จัดการ ส่วนประสบการณ์ของเงินลูกค้าต้องดูแยกอีกตัวหนึ่ง

ขั้นที่ 4 — CAGR และ Calmar ต้องมาจากหน้าต่างเดียวกัน

ตอนนี้วัดหลุมได้ถูกแล้ว ขั้นนี้เอาหลุมไปเทียบกับผลตอบแทน เพื่อดูว่าความเจ็บที่ต้องทนแลกมากับผลตอบแทนเท่าไร ตัววัดนี้คือ Calmar ratio คือผลตอบแทนต่อปีหารด้วยหลุมที่ลึกที่สุด ผลตอบแทนต่อปีที่ใช้คือ CAGR ซึ่งเขียนแทนด้วย $g$ มันคืออัตราโตต่อปีแบบทบต้นที่คงที่ ซึ่งพาเงินต้น $W_0$ ไปถึงเงินปลายทาง $W_T$ ใน $T$ ปีได้พอดี เราเขียนนิยามนี้เป็นสมการ แล้วถอดราก $T$ เพื่อแกะ $g$ ออกมา

ตัวอย่างสมมติ: มูลค่าต่อหน่วยตอนสิ้นปีที่ 0 ถึง 3 คือ 1.00, 1.20, 0.90 และ 1.10 ผลตอบแทนรายปี $r_1,r_2,r_3$ คิดจากปีต่อปี และ $\bar r$ คือค่าเฉลี่ยธรรมดาของสามตัวนี้ ซึ่งจะเอามาเทียบกับ $g$

\[ \begin{aligned} \frac{W_T}{W_0}&=(1+g)^{T},\\ g&=\Big(\frac{W_T}{W_0}\Big)^{1/T}-1,\\ \mathrm{Calmar}&=\frac{g}{D_{\max}},\\ g&=\Big(\frac{1.10}{1.00}\Big)^{1/3}-1\approx0.03228,\\ D_{\max}&=1-\frac{0.90}{1.20}=0.25,\\ \mathrm{Calmar}&\approx\frac{0.03228}{0.25}\approx0.129,\\ r_1&=\tfrac{1.20}{1.00}-1=+20\%,\\ r_2&=\tfrac{0.90}{1.20}-1=-25\%,\\ r_3&=\tfrac{1.10}{0.90}-1\approx+22.22\%,\\ \bar r&=\frac{0.20-0.25+0.2222}{3}\\ &\approx5.74\%. \end{aligned} \]

หลุมลึกสุดอยู่ในปีที่ 2 ที่ลงจาก 1.20 เหลือ 0.90 ส่วนเงินโตทบต้นได้แค่ปีละ 3.228% ตรวจ: $1.03228^3\approx1.100$ Calmar 0.129 แปลว่าได้ผลตอบแทนต่อปีราว 0.13 ส่วน ต่อความเจ็บที่ลึกที่สุดหนึ่งส่วน

ทำไมไม่ใช้ค่าเฉลี่ยธรรมดา $\bar r=5.74\%$? เพราะมันสูงกว่าอัตราทบต้นเกือบสองเท่า ($5.74/3.228\approx1.78$) ทั้งที่เงินจริงไม่ได้โตปีละ 5.74% สาเหตุคือปีที่ตก 25% ต้องฟื้น $0.25/0.75\approx33.3\%$ ตามสูตรของขั้นที่ 2 แต่ปีถัดมาฟื้นแค่ 22.22% ค่าเฉลี่ยธรรมดานับ −25% กับ +22.22% เหมือนเกือบหักล้างกันได้ ซึ่งไม่จริง ช่องว่างนี้เรียกว่า volatility drag ซึ่งเห็นแล้วในหน้า Kelly criterion (ค่าเฉลี่ยของ log ต่ำกว่า log ของค่าเฉลี่ย) Calmar จึงต้องใช้ $g$ ไม่ใช่ $\bar r$

เงื่อนไขที่สำคัญกว่าสูตร: $g$ กับ $D_{\max}$ ต้องมาจากช่วงเวลาเดียวกัน และวัดด้วยความถี่เดียวกัน เพราะสองเรื่องนี้เปลี่ยนความลึกของหลุมได้

  • หลุมที่วัดจากข้อมูลรายวันลึกเท่ากับหรือมากกว่าหลุมที่วัดรายเดือนเสมอ เพราะราคาสิ้นเดือนเป็นส่วนหนึ่งของราคารายวัน ข้อมูลรายวันจึงเห็นจุดต่ำกลางเดือนที่ข้อมูลรายเดือนมองข้าม
  • ข้อมูลช่วงยาวเจอหลุมลึกเท่ากับหรือมากกว่าช่วงสั้นที่อยู่ข้างใน เพราะช่วงยาวมีช่วงสั้นอยู่ในตัว

ธรรมเนียมดั้งเดิมของ Calmar ใช้ข้อมูลย้อนหลัง 36 เดือน (สามปี)

ขั้นที่ 5 — ผลตอบแทนชุดเดียวกัน สลับลำดับ หลุมต่างกันเกือบเท่าตัว

ขั้นนี้ดูว่าทำไม Sharpe ratio ถึงมองไม่เห็นหลุม

โจทย์ให้อะไรมาบ้าง: กลยุทธ์สมมติสองตัว แต่ละตัวมีผลตอบแทนสี่งวด

  • กลยุทธ์ A: +10%, +10%, −10%, −10%
  • กลยุทธ์ B: +10%, −10%, +10%, −10%

ทั้งสองเป็นตัวเลขสี่ตัวชุดเดียวกัน แค่เรียงคนละลำดับ คำถามคือ Sharpe, CAGR และ maximum drawdown ของสองกลยุทธ์ต่างกันไหม เริ่มจากเดินเงินทีละงวด โดยเริ่มที่ 1 แล้วคูณด้วย 1.1 หรือ 0.9 ตามผลตอบแทนของงวดนั้น

\[ \begin{aligned} W^{A}&=1,\ 1.1,\ 1.21,\\ &\qquad1.089,\ 0.9801,\\ W^{B}&=1,\ 1.1,\ 0.99,\\ &\qquad1.089,\ 0.9801,\\ D^{A}_{\max}&=1-\frac{0.9801}{1.21}=19\%,\\ D^{B}_{\max}&=1-\frac{0.9801}{1.1}\approx10.9\%. \end{aligned} \]

คำตอบ: Sharpe คิดจากค่าเฉลี่ยกับความผันผวนของตัวเลขสี่ตัว +10, +10, −10 และ −10 ซึ่งเป็นสี่ตัวเดียวกันทั้งสองกลยุทธ์ Sharpe จึงเท่ากันทุกตำแหน่งทศนิยม เงินปลายทางก็เท่ากันที่ 0.9801 เพราะการคูณ $1.1\times1.1\times0.9\times0.9$ สลับลำดับได้ CAGR จึงเท่ากันด้วย

สิ่งเดียวที่ต่างคือหลุม A ขึ้นไปถึงยอด 1.21 ก่อน แล้วร่วงสองงวดติด หลุมจึงลึก 19% ส่วน B ไม่เคยขึ้นเกิน 1.1 และไม่เคยตกสองงวดติด หลุมจึงลึกแค่ 10.9% Calmar หารด้วยหลุม ขนาดของ Calmar สองกลยุทธ์จึงต่างกัน $19/10.9\approx1.74$ เท่า ทั้งที่ Sharpe เหมือนกัน

ตรวจเองใน 10 วินาที: $1.21\times0.9\times0.9=0.9801$ และ $1.1\times0.9\times1.1\times0.9=0.9801$

ขั้นที่ 6 — เขียนกฎลดขนาดแบบขั้นบันไดให้ใช้ได้จริง

ตอนนี้วัดหลุมได้แล้ว คำถามต่อไปคือจะทำอะไรกับมัน วิธีที่ใช้กันมากคือลดขนาด (สัดส่วนเงินที่ลงในกลยุทธ์) เมื่อหลุมลึก ให้ $a_t$ คือขนาดที่ถือในวันที่ $t$ ($a=1$ คือลงเต็ม $a=0.5$ คือลงครึ่งเดียวและถือเงินสดอีกครึ่ง) และ $r_t$ คือผลตอบแทนของกลยุทธ์ในวันนั้นถ้าลงเต็ม กฎตัวอย่างแบบขั้นบันไดตัดสินหลังปิดตลาดทุกวัน:

  • หลุมต่ำกว่า 10%: วันถัดไปลงเต็ม
  • หลุมตั้งแต่ 10% แต่ต่ำกว่า 20%: วันถัดไปลงครึ่งเดียว
  • หลุมตั้งแต่ 20% ขึ้นไป: หยุดลงทุน

ต้องระวังสองเรื่อง เรื่องแรก หลุมของวันนี้รู้ตอนปิดตลาด ขนาดที่ตัดสินจึงใช้ได้กับวันพรุ่งนี้เท่านั้น เรื่องที่สอง การเปลี่ยนขนาดต้องซื้อขาย ซึ่งมีค่าใช้จ่าย ให้ $c$ คือต้นทุนต่อเงินที่ซื้อขายหนึ่งดอลลาร์ หน้านี้สมมติ $c=0.001$ หรือ 0.1% ตัวเลข 10% กับ 20% ของกฎก็เป็นค่าที่เลือกมาสาธิต ไม่ใช่มาตรฐาน

\[ \begin{aligned} a_{t+1}&=\begin{cases}1,&D_t\lt0.10,\\0.5,&0.10\le D_t\lt0.20,\\0,&D_t\ge0.20,\end{cases}\\ W_{t+1}&=W_t\big(1-c\,|a_{t+1}-a_t|\big)\\ &\quad\times\big(1+a_{t+1}r_{t+1}\big),\\ \text{cost}&=c\,W_t\,|a_{t+1}-a_t|\\ &=0.001(1{,}000{,}000)(0.5)\\ &=\$500. \end{aligned} \]

สูตรการเดินเงินบอกลำดับของหนึ่งวัน: เช้าวันใหม่ปรับขนาดก่อน จึงเสียต้นทุนเป็นสัดส่วน $c\,|a_{t+1}-a_t|$ ของเงิน แล้วเงินที่เหลือจึงได้ผลตอบแทน $a_{t+1}r_{t+1}$ เงินสดส่วนที่ไม่ได้ลงทุนสมมติว่าไม่ได้ดอกเบี้ย ตัวอย่าง: บัญชี \$1 ล้านที่ลดจากลงเต็มเป็นลงครึ่ง เปลี่ยนขนาดไป 0.5 จึงเสีย \$500

จุดที่ต้องระวังที่สุดคือตัวห้อย $a_{t+1}$ ตัดสินจาก $D_t$ คือใช้ข้อมูลถึงเมื่อวานตัดสินขนาดของวันนี้ ถ้าเผลอใช้หลุมของวันเดียวกับผลตอบแทน การทดสอบย้อนหลังจะลดขนาดได้ก่อนวันร้ายทุกครั้งอย่างน่าอัศจรรย์ ซึ่งในชีวิตจริงทำไม่ได้

ขั้นที่ 7 — ลองกฎกับเส้นทาง 12 วัน

ขั้นนี้ลองกฎขั้นบันไดกับเส้นทาง 12 วันในรูปแรกของหน้า แล้วเทียบกับการลงเต็มตลอด

โจทย์ให้อะไรมาบ้าง:

  • บัญชีเริ่มที่ \$1,000,000 ค่า $W$ ด้านล่างเขียนเป็นล้านดอลลาร์
  • ผลตอบแทนรายวันถ้าลงเต็ม (สมมติ) คือ 2, −6, −5, −4, −8, 6, 7, 5, 4, 3, −2 และ 3 เปอร์เซ็นต์
  • ต้นทุนการเปลี่ยนขนาด $c=0.001$

ช่วงขาลง: สามวันแรกหลุมยังไม่ถึง 10% กฎจึงลงเต็ม สองบัญชีเดินเหมือนกัน ยอดคือ 1.02 จากวันที่ 1 พอปิดวันที่ 3 หลุมเกิน 10% กฎจึงลดเหลือครึ่งตั้งแต่วันที่ 4 และเสียต้นทุน 0.05% ของเงิน ($c\times0.5=0.0005$) วันที่ 4 และ 5 ตลาดลง 4% กับ 8% บัญชีที่ใช้กฎลงแค่ครึ่งหนึ่งของนั้น คือ 2% กับ 4%

\[ \begin{aligned} W_3&=1.02(0.94)(0.95)=0.91086,\\ D_3&=1-\frac{0.91086}{1.02}\approx10.70\%,\\ \text{cost}_4&=0.0005(910{,}860)\approx\$455,\\ W_5^{\text{rule}}&=0.91086(0.9995)(0.98)(0.96)\\ &\approx0.85651,\\ D_5^{\text{rule}}&=1-\frac{0.85651}{1.02}\approx16.03\%,\\ W_5^{\text{hold}}&=0.91086(0.96)(0.92)\approx0.80447,\\ D_5^{\text{hold}}&=1-\frac{0.80447}{1.02}\approx21.13\%. \end{aligned} \]

ช่วงเด้ง: วันที่ 6 ถึง 8 ตลาดขึ้น 6%, 7% และ 5% แต่กฎยังลงครึ่งเดียว จึงได้แค่ 3%, 3.5% และ 2.5% ปิดวันที่ 8 หลุมต่ำกว่า 10% กฎจึงกลับไปลงเต็มตั้งแต่วันที่ 9 และเสียต้นทุนอีกครั้ง

\[ \begin{aligned} W_8^{\text{rule}}&=0.85651(1.03)(1.035)(1.025)\\ &\approx0.93591,\\ D_8^{\text{rule}}&=1-\frac{0.93591}{1.02}\approx8.24\%,\\ \text{cost}_9&=0.0005(935{,}910)\approx\$468,\\ W_{12}^{\text{rule}}&=0.93591(0.9995)(1.04)\\ &\quad\times(1.03)(0.98)(1.03)\\ &\approx1.01146,\\ W_{12}^{\text{hold}}&=0.80447(1.06)(1.07)(1.05)\\ &\quad\times(1.04)(1.03)(0.98)(1.03)\\ &\approx1.03591. \end{aligned} \]

วันที่ 9 ถึง 12 สองบัญชีลงเต็มเหมือนกัน ต่างกันแค่จุดเริ่ม และบัญชีที่ใช้กฎเสียต้นทุนอีก 0.05% (ตัวคูณ 0.9995) โค้ด JavaScript ท้ายหน้าคำนวณซ้ำให้ทั้งเส้นทาง

คำตอบ: หลุมลึกสุดของบัญชีที่ใช้กฎคือ 16.03% แทน 21.13% ต้นทุนการปรับขนาดรวม $455+468=\$923$ แต่ช่วงวันที่ 6 ถึง 8 ที่ตลาดเด้งแรง กฎถือแค่ครึ่ง บัญชีจึงจบที่ \$1,011,463 ขณะที่การลงเต็มตลอดจบที่ \$1,035,914

สรุปเป็นราคา: บนเส้นทางนี้ กฎทำให้หลุมตื้นขึ้น $21.13-16.03=5.10$ จุด โดยแลกกับเงิน $1{,}035{,}914-1{,}011{,}463=\$24{,}451$ แต่ถ้าหลังวันที่ 5 ตลาดลงต่อแทนที่จะเด้ง กฎจะเป็นฝ่ายชนะ การตัดสินว่ากฎดีไหมจึงต้องลองกับหลายเส้นทาง ไม่ใช่เส้นเดียว

ตรวจเองใน 10 วินาที: $1.02\times0.94\times0.95=0.91086$ และ $0.91086/1.02\approx0.893$ คือต่ำกว่ายอด 10.7%

ขั้นที่ 8 — กฎแบบต่อเนื่องของ Grossman–Zhou: ลงทุนตามเบาะที่เหลือเหนือพื้น

กฎขั้นบันไดมีจุดอ่อนสองข้อ ข้อแรก ขนาดกระโดดทีละขั้น จาก 1 เป็น 0.5 ทันทีที่หลุมข้าม 10% ข้อที่สอง ตัวเลข 20% เป็นแค่จุดที่กฎหยุดลงทุน ไม่ได้รับประกันว่าหลุมจะไม่ลึกเกิน 20% Grossman กับ Zhou (1993) เสนอกฎที่ปรับขนาดอย่างต่อเนื่อง และออกแบบให้หลุมไม่เกินเพดานที่ตั้งไว้ กฎมีสามส่วน:

  • ตั้งเพดานหลุมที่ยอมได้ $D^{*}$ เช่น 20%
  • คำนวณ “พื้น” $F_t=(1-D^{*})H_t$ คือระดับเงินที่ห้ามต่ำกว่า ถ้า $D^{*}=20\%$ พื้นคือ 80% ของยอด
  • เงินส่วนที่อยู่เหนือพื้นเรียกว่า cushion (เบาะ) $C_t=W_t-F_t$ แล้วลงทุนเป็น $m$ เท่าของเบาะ ให้ $E_t$ คือเงินที่ลงในกลยุทธ์

ขั้นนี้จะดูว่าทำไมกฎนี้กันหลุมไม่ให้เกิน $D^{*}$ และขนาดเปลี่ยนตามหลุมอย่างไร

\[ \begin{aligned} F_t&=(1-D^{*})H_t,\\ C_t&=W_t-F_t,\\ E_t&=m\,C_t,\\ C_{t+1}&=C_t+E_t\,r_{t+1}\\ &=C_t\,(1+m\,r_{t+1}),\\ \frac{E_t}{W_t}&=m\Big(1-\frac{1-D^{*}}{1-D_t}\Big). \end{aligned} \]

ทำไมเบาะไม่ทะลุศูนย์? ระหว่างที่ยังไม่ทำยอดใหม่ ยอด $H_t$ อยู่กับที่ พื้น $F_t$ จึงอยู่กับที่ด้วย กำไรหรือขาดทุนของวันจึงไปตกที่เบาะทั้งก้อน และเพราะเงินที่ลงทุนเป็น $m$ เท่าของเบาะ เบาะจึงถูกคูณด้วย $(1+m\,r_{t+1})$ ทุกวัน ตัวคูณนี้ติดลบได้ก็ต่อเมื่อวันเดียวขาดทุนเกิน $1/m$ เช่น $m=5$ ต้องขาดทุนเกิน $1/5=20\%$ ในวันเดียว ถ้าปรับขนาดถี่พอจนแต่ละช่วงราคาขยับนิดเดียว เบาะจะหดเข้าหาศูนย์ได้ แต่ไม่ทะลุ เงินจึงไม่ต่ำกว่าพื้น และหลุมไม่เกิน $D^{*}$

สมการสุดท้ายบอกขนาดเป็นสัดส่วนของเงิน ได้จากการหาร $E_t=m(W_t-F_t)$ ด้วย $W_t$ แล้วแทน $W_t=H_t(1-D_t)$ และ $F_t=(1-D^{*})H_t$ ยอด $H_t$ ตัดกันหมด ขนาดจึงลดลงอย่างต่อเนื่องเมื่อหลุมลึกขึ้น และเป็นศูนย์พอดีเมื่อ $D_t=D^{*}$ แทนที่จะกระโดดเป็นขั้น

เลือก $m$ อย่างไร? ที่ยอด ($D_t=0$) ขนาดคือ $m\big(1-(1-D^{*})\big)=mD^{*}$ งานต้นฉบับใช้ $m$ เท่ากับขนาด Kelly $a^{*}=(\mu-r)/\sigma^2$ จากหน้า Kelly criterion ที่ยอดจึงถือ $D^{*}$ เท่าของขนาด Kelly เช่นหุ้นในหน้านั้นที่ Kelly สั่งถือ 2.16 เท่าของทุน ถ้า $D^{*}=20\%$ ที่ยอดจะถือ $0.2\times2.16\approx0.43$ เท่า หน้านี้ต้องการเทียบกับกฎขั้นบันไดอย่างยุติธรรม จึงเลือก $m=1/D^{*}=5$ ให้ที่ยอดถือเต็มขนาดเท่ากัน: $5\times0.2=1$

ขั้นที่ 9 — เทียบสองกฎ: ขนาดตามหลุม วันกระโดด และเส้นทาง 12 วัน

ขั้นนี้เทียบสองกฎด้วยตัวเลข

โจทย์ให้อะไรมาบ้าง: กฎ Grossman–Zhou ที่ $D^{*}=0.20$ และ $m=5$ ถามสามเรื่อง

  • ที่หลุม 0%, 10% และ 15% กฎนี้ถือขนาดเท่าไร (แทนค่าในสูตรขนาดของขั้นที่ 8)
  • บัญชีอยู่ที่หลุม 5% แล้วเกิดวันร้ายที่กลยุทธ์ขนาดเต็มร่วง 25% ในวันเดียว เช่นราคากระโดดลงข้ามคืนจากข่าวร้าย หลุมของแต่ละกฎจะไปอยู่ที่เท่าไร
  • บนเส้นทาง 12 วันเดิม (ต้นทุน $c=0.001$) แต่ละกฎจบอย่างไร

เริ่มจากขนาดที่หลุมต่าง ๆ แทน $m=5$ และ $1-D^{*}=0.8$:

\[ \begin{aligned} D=0&:\ 5(1-0.8)=1,\\ D=0.10&:\ 5\big(1-\tfrac{0.8}{0.9}\big)\approx0.556,\\ D=0.15&:\ 5\big(1-\tfrac{0.8}{0.85}\big)\approx0.294. \end{aligned} \]

ต่อไปคือวันร่วง 25% ที่หลุม 5% เงินคือ $W=0.95H$ กฎขั้นบันไดยังถือเต็ม (หลุมยังไม่ถึง 10%) จึงเสีย 25% ของเงินทั้งหมด ส่วน Grossman–Zhou ลงทุนแค่ 5 เท่าของเบาะ $0.95H-0.80H$ และเสีย 25% ของเงินก้อนนั้น

\[ \begin{aligned} \text{stairs}:\ W&=0.95H(1-0.25)=0.7125H,\\ D&=1-0.7125=28.75\%,\\ \text{GZ}:\ E&=5(0.95-0.80)H=0.75H,\\ W&=0.95H-0.25(0.75H)=0.7625H,\\ D&=1-0.7625=23.75\%. \end{aligned} \]

คำตอบ: ขนาดของ Grossman–Zhou ลดจาก 1 ที่ยอด เหลือ 0.556 ที่หลุม 10% และ 0.294 ที่หลุม 15% เกือบเป็นเส้นตรงลงไปถึงศูนย์ที่หลุม 20%

ในวันร่วง 25% ทั้งสองกฎทะลุเพดาน 20% กฎขั้นบันไดยังถือเต็ม หลุมจึงไปถึง 28.75% ส่วน Grossman–Zhou ถือแค่ $0.75/0.95\approx0.789$ ของเงิน หลุมจึงไปถึง 23.75% Grossman–Zhou ทะลุเพราะวันเดียวร่วง 25% เกิน $1/m=20\%$ ซึ่งเป็นวันที่สมมติฐาน “ปรับขนาดได้ทันก่อนราคาขยับมาก” ใช้ไม่ได้ กฎขั้นบันไดทะลุง่ายกว่านั้นอีก ที่หลุม 5% และถือเต็ม แค่วันเดียวร่วงเกิน $1-0.80/0.95\approx15.8\%$ ก็ทะลุแล้ว

ขั้นที่ 10 — ราคาที่กฎทุกแบบต้องจ่าย: Sharpe ลดเมื่อขนาดแกว่ง

นอกจากพลาดช่วงตลาดเด้ง กฎลดขนาดยังมีต้นทุนที่ซ่อนอยู่ลึกกว่า คือ Sharpe ratio ลดลง ถ้าการเปลี่ยนขนาดไม่ได้ช่วยทายผลตอบแทนข้างหน้า แค่ปล่อยให้ขนาดแกว่งก็ทำให้ Sharpe ต่ำลงเสมอ ขั้นนี้แสดงว่าทำไม

ให้กลยุทธ์ที่ลงเต็มมีความผันผวนรายวัน $\sigma$ และ Sharpe รายวัน $s$ เพราะ Sharpe คือค่าเฉลี่ยหารด้วยความผันผวน ผลตอบแทนเฉลี่ยต่อวันจึงเป็น $s\sigma$ ให้ขนาด $a_t$ ไม่เกี่ยวกับผลตอบแทนของวันนั้น เขียน $\bar a$ แทนค่าเฉลี่ยของขนาด และ $\overline{a^2}$ แทนค่าเฉลี่ยของขนาดยกกำลังสอง

\[ \begin{aligned} \mathbb E[a_t r_t]&=\bar a\,s\sigma,\\ \operatorname{Var}(a_t r_t)&\approx\overline{a^2}\,\sigma^2,\\ \mathrm{SR}&\approx s\,\frac{\bar a}{\sqrt{\overline{a^2}}},\\ \overline{a^2}-\bar a^{2}&\ge0. \end{aligned} \]

ค่าเฉลี่ยใช้ข้อที่ว่า $a_t$ ไม่เกี่ยวกับ $r_t$ ค่าเฉลี่ยของผลคูณจึงเท่ากับผลคูณของค่าเฉลี่ย variance เป็นค่าประมาณ ค่าจริงคือ $\overline{a^2}(\sigma^2+s^2\sigma^2)-\bar a^2s^2\sigma^2$ แต่ Sharpe รายวันเล็กมาก เช่น Sharpe ต่อปี 1 คิดเป็นรายวันแค่ $1/\sqrt{252}\approx0.063$ (252 คือจำนวนวันทำการในหนึ่งปี) ก้อนที่มี $s^2$ จึงทิ้งได้ เอาค่าเฉลี่ยหารด้วยรากของ variance ก็ได้ Sharpe ใหม่

หัวใจอยู่ที่ variance ของขนาดเอง $\overline{a^2}-\bar a^2$ ซึ่งไม่มีวันติดลบ จึงได้ $\bar a\le\sqrt{\overline{a^2}}$ ตัวคูณ $\bar a/\sqrt{\overline{a^2}}$ จึงไม่เกิน 1 Sharpe ใหม่ไม่มีวันสูงกว่า $s$ และเท่ากันได้เฉพาะเมื่อขนาดคงที่

ลองสองตัวอย่าง ตัวอย่างแรก ถือครึ่งขนาดครึ่งปี แล้วถือ 1.5 เท่าอีกครึ่งปี ตัวอย่างที่สองคือกฎขั้นบันไดบนเส้นทาง 12 วัน ซึ่งถือเต็ม 7 วันและครึ่งเดียว 5 วัน

\[ \begin{aligned} (0.5,\ 1.5):\ \bar a&=\tfrac{0.5+1.5}{2}=1,\\ \overline{a^2}&=\tfrac{0.25+2.25}{2}=1.25,\\ \tfrac{\bar a}{\sqrt{\overline{a^2}}}&=\tfrac{1}{\sqrt{1.25}}\approx0.894,\\ \text{12 days}:\ \bar a&=\tfrac{7(1)+5(0.5)}{12}\approx0.7917,\\ \overline{a^2}&=\tfrac{7(1)+5(0.25)}{12}=0.6875,\\ \tfrac{\bar a}{\sqrt{\overline{a^2}}}&=\tfrac{0.7917}{\sqrt{0.6875}}\approx0.955. \end{aligned} \]

ตัวอย่างแรก ขนาดเฉลี่ยยังเป็น 1 แต่ Sharpe เหลือ 89.4% ของเดิม ตัวอย่างที่สอง Sharpe เหลือ 95.5% คือเสียไป 4.5% ถ้าการลดขนาดไม่ได้จับจังหวะตลาดได้จริง กฎลดขนาดก็เหมือนซื้อประกันให้กลยุทธ์ของตัวเอง คล้าย put option ซึ่งเป็นสัญญาที่จ่ายชดเชยเมื่อราคาตกต่ำกว่าระดับที่ตกลงไว้ (อ่านเพิ่มที่หน้า Put–Call Parity) เบี้ยประกันคือผลตอบแทนที่หายไปทุกครั้งที่ลดขนาดแล้วตลาดเด้ง สิ่งที่ได้คืนคือหลุมที่ตื้นขึ้น จะคุ้มหรือไม่ขึ้นกับว่าหลุมลึกทำให้เจ้าของเงินเจ็บแค่ไหน เช่นลูกค้าจะถอนเงินหนีหรือไม่

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

วัดหลุมจากเงินต้น: หลุมต้องวัดจากยอดสูงสุด ไม่ใช่จากเงินต้น บัญชีในโจทย์ถ้าเทียบเงินต้นได้ $1-0.88/1.00=12\%$ ซึ่งผิด ที่ถูกคือ $1-0.88/1.10=20\%$ และต้องฟื้น $0.20/0.80=25\%$ ไม่ใช่ 12%

นับเงินถอนเป็นขาดทุน: เงินที่ลูกค้าถอนไม่ใช่การขาดทุน ลูกค้าถอน \$200,000 จากยอด \$1.1 ล้านในวันที่ตลาดนิ่ง ถ้าคิดบนเงินในบัญชีตรง ๆ จะได้หลุมปลอม $1-0.9/1.1\approx18.18\%$ ที่ถูกคือคิดบนมูลค่าต่อหน่วย: $r=(0.9+0.2)/1.1-1=0$ หลุมจึงเป็นศูนย์

ใช้ข้อมูลอนาคตตัดสินขนาด: ขนาดของพรุ่งนี้ $a_{t+1}$ ต้องตัดสินจากหลุมของวันนี้ $D_t$ ถ้าใช้ $D_{t+1}$ ก็คือใช้ราคาปิดของวันที่ยังไม่เกิด ผลทดสอบย้อนหลังจะดูดีกว่าที่ทำได้จริง

หยุดลงทุนแล้วไม่มีทางกลับ: กฎขั้นบันไดที่ไม่มีกฎกลับเข้าจะหยุดตลอดไป เมื่อกฎสั่ง $a=0$ เงินไม่ขยับเลย: $W_{t+1}=W_t(1+0\cdot r_{t+1})=W_t$ หลุมจึงค้างที่ 20% ขึ้นไป และกฎก็สั่ง $a=0$ ต่อไปเรื่อย ๆ ต้องเขียนกฎกลับเข้าแยกต่างหาก เช่นประเมินใหม่หลังหยุด 20 วันทำการ หรือรีเซ็ตยอดตามกฎที่ประกาศไว้ล่วงหน้า

เทียบ Calmar ต่างช่วงเวลาหรือต่างความถี่: กองทุนที่มีข้อมูล 3 ปีอาจดู Calmar ดีกว่ากองที่มีข้อมูล 15 ปี เพียงเพราะช่วงสั้นยังไม่เจอหลุมใหญ่ และหลุมที่วัดรายเดือนไม่มีทางลึกกว่าหลุมที่วัดรายวัน การเทียบจึงต้องใช้ช่วงเวลาและความถี่เดียวกัน

เลือกจุดตัดจากเส้นทางเดียว: ถ้าไล่หาระดับหลุมที่ให้ผลดีที่สุด (เช่นจะใช้ 10% หรือ 12%) บนเส้นทางทดสอบเส้นเดียว แล้วเรียกผลนั้นว่าผลนอกตัวอย่าง (ผลบนข้อมูลที่ไม่ได้ใช้ตอนออกแบบกฎ) ก็คือการใช้ข้อมูลทดสอบเป็นข้อมูลฝึก ผลที่รายงานจะดีเกินจริง

ใช้ทำอะไรบนโต๊ะจริง

คนที่เลือกว่าจะฝากเงินไว้กับกองทุนไหนดู maximum drawdown และเวลาใต้น้ำคู่กับ Sharpe เพราะลูกค้ามักถอนเงินตอนหลุมลึก ไม่ใช่ตอน Sharpe ต่ำ

กองทุนที่มีผู้จัดการหลายทีมเขียนกฎ stop-out ไว้ในข้อตกลงของแต่ละทีม เช่น ลงจากยอดถึงระดับหนึ่งให้ลดขนาด ถึงอีกระดับให้ปิดสถานะทั้งหมด (ขายทุกอย่างที่ถืออยู่)

ฝ่ายบริหารความเสี่ยงทดสอบกฎแบบนี้กับเส้นทางจำนวนมาก ไม่ใช่เส้นเดียว เช่นเส้นทางที่สร้างด้วย block bootstrap (สุ่มหยิบข้อมูลจริงมาต่อกันเป็นท่อน ๆ) ในหน้า Monte Carlo และ bootstrap และต้องรวมต้นทุนการซื้อขายจริงเข้าไปด้วย เพราะกฎแบบต่อเนื่องอย่าง Grossman–Zhou ปรับขนาดบ่อยและแรงที่สุดตอนตลาดป่วน ซึ่งมักเป็นตอนที่ต้นทุนซื้อขายสูง

โจทย์ตรวจความเข้าใจ

1. กองทุนแห่งหนึ่งเคยทำยอดสูงสุดไว้ วันนี้เงินลดลงจากยอดนั้น 35% ผู้จัดการต้องทำกำไรอีกกี่เปอร์เซ็นต์ เงินจึงจะกลับถึงยอด?

เฉลย

ใช้สูตรจากขั้นที่ 2 กับ $D=0.35$: $R=D/(1-D)=0.35/0.65\approx53.85\%$ มากกว่าที่เสียไป $53.85-35=18.85$ จุด ตรวจ: เงินที่เหลือคือ 65% ของยอด โตขึ้น 53.85% ได้ $0.65\times1.5385\approx1.000$ คือกลับถึงยอดพอดี

2. กองทุนหนึ่งรายงานมูลค่าต่อหน่วยที่โตจาก 1.0 เป็น 1.5 ในเวลา 5 ปี ในช่วง 5 ปีนั้น หลุมที่ลึกที่สุด (maximum drawdown) คือ 30% หา CAGR และ Calmar ratio

เฉลย

ใช้สูตร $g$ จากขั้นที่ 4 กับ $T=5$ การถอดรากที่ 5 ทำด้วย log ได้ง่าย: ยกกำลัง $1/5$ เท่ากับหาร log ด้วย 5 แล้วยก $e$ กลับ

\[ \begin{aligned} g&=\Big(\frac{1.5}{1.0}\Big)^{1/5}-1,\\ \ln1.5&=0.40547,\\ \tfrac{0.40547}{5}&=0.081093,\\ e^{0.081093}&\approx1.08447,\\ g&\approx8.447\%,\\ \mathrm{Calmar}&=\frac{0.08447}{0.30}\approx0.2816. \end{aligned} \]

3. บัญชีใช้กฎ Grossman–Zhou ที่ $D^{*}=20\%$ และ $m=5$ ตอนปิดวันนี้ เงินอยู่ต่ำกว่ายอด 15% คือ $W=0.85H$ พรุ่งนี้ควรลงทุนกี่เปอร์เซ็นต์ของเงิน และถ้ากลยุทธ์ขนาดเต็มร่วงในวันเดียว ต้องร่วงกี่เปอร์เซ็นต์ บัญชีจึงจะลงไปแตะพื้นพอดี?

เฉลย

หาเบาะก่อน แล้วลงทุน 5 เท่าของเบาะ บัญชีแตะพื้นเมื่อขาดทุนเท่ากับเบาะพอดี ให้ $x$ คือขนาดของวันร่วง

\[ \begin{aligned} C&=0.85H-0.80H=0.05H,\\ E&=5(0.05H)=0.25H,\\ \frac{E}{W}&=\frac{0.25H}{0.85H}\approx29.4\%,\\ 0.25H\times x&=0.05H,\\ x&=\frac{0.05}{0.25}=20\%=\frac1m. \end{aligned} \]

พรุ่งนี้ลงทุนราว 29.4% ของเงิน และต้องร่วง 20% ในวันเดียวจึงแตะพื้น ค่า 20% นี้ไม่ขึ้นกับว่าตอนนี้หลุมลึกแค่ไหน เพราะเบาะถูกคูณด้วย $(1+m\,r)$ เสมอ และตัวคูณนี้เป็นศูนย์เมื่อ $r=-1/m$

// Running peak, drawdown and the deepest hole of a wealth (or unit-value) path.
function drawdowns(W) {
  let H = -Infinity, maxD = 0;
  const dd = W.map(w => { H = Math.max(H, w); const d = 1 - w / H; maxD = Math.max(maxD, d); return d; });
  return {dd, maxD};
}
const recovery = D => D / (1 - D);                         // W(1 + R) = H with W = H(1 - D)
const cagr = (W0, WT, years) => (WT / W0) ** (1 / years) - 1;
// Unit value: strip deposits Q (withdrawals negative) that arrive at the close.
function unitValue(W, Q) {
  const U = [1];
  for (let t = 1; t < W.length; t++) U.push(U[t - 1] * (W[t] - Q[t]) / W[t - 1]);
  return U;
}
// Run a sizing rule on full-size daily returns; size is decided from yesterday's close.
function run(returns, size, c = 0.001) {
  let W = 1, H = 1, prev = 1, maxD = 0, costs = 0;
  const sizes = [];
  for (const r of returns) {
    const a = size(W, H);
    const cost = c * Math.abs(a - prev) * W;
    W = (W - cost) * (1 + a * r);
    costs += cost; prev = a; sizes.push(a);
    H = Math.max(H, W); maxD = Math.max(maxD, 1 - W / H);
  }
  return {W, maxD, costs, sizes};
}
const hold = () => 1;
const stairs = (W, H) => { const D = 1 - W / H; return D < 0.10 - 1e-12 ? 1 : D < 0.20 - 1e-12 ? 0.5 : 0; };
const gz = (m, Dstar) => (W, H) => Math.max(0, m * (W - (1 - Dstar) * H)) / W;   // m times the cushion

const r12 = [0.02, -0.06, -0.05, -0.04, -0.08, 0.06, 0.07, 0.05, 0.04, 0.03, -0.02, 0.03];
const a = run(r12, hold), b = run(r12, stairs), g = run(r12, gz(5, 0.2));
const mean = x => x.reduce((s, v) => s + v, 0) / x.length;
console.log({
  six: drawdowns([1, 1.1, 0.88, 0.968, 1.0648, 1.12]).maxD,               // 0.20

  withdrawal: drawdowns(unitValue([1.1, 0.9], [0, -0.2])).maxD,          // 0, not 0.1818
  perDollar: (1 * 0.20 - 10 * 0.10) / 11,                                // -0.0727
  calmar3: cagr(1, 1.1, 3) / drawdowns([1, 1.2, 0.9, 1.1]).maxD,         // 0.129
  orderA: drawdowns([1, 1.1, 1.21, 1.089, 0.9801]).maxD,                 // 0.19

  gapStairs: 1 - 0.95 * 0.75,                                           // 0.2875

สิ่งที่ควรตอบได้หลังอ่าน

  • drawdown วัดจากยอดสูงสุดสะสมซึ่งไม่มีวันลดลง จาก \$1.1 ล้านเหลือ \$880,000 คือหลุม $1-0.88/1.1=20\%$ ไม่ใช่ 12%
  • หลุม $D$ ต้องฟื้น $D/(1-D)$ เพราะเงินก้อนเดิมต้องหาจากฐานที่เล็กลง หลุม 20% ต้องฟื้น 25% หลุม 50% ต้องฟื้น 100%
  • หลุมต้องคิดบนมูลค่าต่อหน่วยที่ตัดเงินฝากถอนออก Calmar คือ CAGR หารด้วยหลุมลึกสุดในช่วงเวลาเดียวกัน เช่น $3.228\%/25\%\approx0.129$
  • Sharpe มองไม่เห็นลำดับ ผลตอบแทนชุดเดียวกันให้หลุม 19% หรือ 10.9% ก็ได้ ขึ้นกับว่าเรียงกันอย่างไร
  • กฎลดขนาดทำให้หลุมตื้นขึ้น (จาก 21.13% เป็น 16.03% หรือ 14.99%) แต่จ่ายด้วยกำไรที่หายไปตอนตลาดเด้ง และด้วย Sharpe ที่ลดลงเมื่อขนาดแกว่ง วันที่ร่วงแรงในวันเดียว (เกิน $1/m$ สำหรับ Grossman–Zhou) พาหลุมทะลุเพดานได้ทุกกฎ

กฎลดขนาดหลายแบบใช้ VaR (ตัวเลขขาดทุนต่อวันที่ไม่ควรถูกทะลุบ่อย) เป็นสัญญาณเตือน แต่ VaR ที่ประกาศไว้เชื่อได้แค่ไหน หน้าถัดไป VaR backtesting: Kupiec และ Christoffersen นับวันที่ขาดทุนเกิน VaR แล้วถามว่ามีมากเกินไปไหม และมาติดกันเกินไปไหม
