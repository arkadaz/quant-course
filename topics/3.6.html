3.6 The Multiple Testing Problem

เมื่อลองหลายแบบแล้วเลือกตัวที่ดีที่สุด ผู้ชนะจะดูดีแม้ไม่มีตัวไหนมี edge เลย หลักฐานจึงต้องคิดรวมทุกแบบที่เคยลอง

ทีมวิจัยลอง 200 กลยุทธ์บนข้อมูลห้าปี แล้วส่งมาเฉพาะตัวที่ผ่านการทดสอบที่เกณฑ์ 5% ตัวที่ดีที่สุดมี Sharpe รายปีราว 1.2 ถ้าความจริงทั้ง 200 ตัวไม่มี edge เลย จะมีตัวที่ผ่านเกณฑ์กี่ตัว และ Sharpe 1.2 ของผู้ชนะน่าตื่นเต้นแค่ไหน

ลองตอบก่อนเปิดเฉลย

คาดว่าจะผ่านราว $200\times5\%=10$ ตัว ถ้าการทดสอบอิสระกัน โอกาสที่จะมีอย่างน้อยหนึ่งตัวผ่านคือ $1-0.95^{200}\approx99.9965\%$ เกือบแน่นอน และ Sharpe ของตัวที่ดีที่สุดใน 200 ตัวที่ไม่มี edge เฉลี่ยราว 1.23 พอดีกับที่เห็น ผู้ชนะ Sharpe 1.2 จึงเป็นสิ่งที่ noise ล้วน ๆ ผลิตได้ตามปกติ ต้องผ่านเกณฑ์ที่เข้มกว่ามาก เช่น Sharpe ราว 1.64 ตามเกณฑ์ Bonferroni

ภาพรวมก่อนลงสูตร

หน้า การทดสอบสมมติฐาน คุมการปฏิเสธผิดไว้ที่ 5% ต่อการทดสอบหนึ่งครั้ง ถ้าทดสอบ 200 ครั้งแล้วเก็บเฉพาะตัวที่ผ่าน 5% ของ 200 คือสิบตัวที่ผ่านทั้งที่ไม่มีอะไรเลย ผู้ชนะที่ถูกคัดมาจึงไม่ได้เป็นหลักฐานแบบเดียวกับการทดสอบที่ตั้งไว้ก่อนครั้งเดียว ปัญหานี้เกิดทุกที่ที่มีการค้นหา: เลือก lookback ที่ดีที่สุด เลือกหุ้นที่ดีที่สุด เลือกผู้จัดการที่ดีที่สุด

ทางแก้มีสามระดับ ระดับแรกคือนับให้ครบว่าลองไปกี่แบบ ระดับที่สองคือปรับเกณฑ์ให้เข้มขึ้นตามจำนวนที่ลอง ซึ่งมีสองแบบให้เลือกตามเป้าหมาย คือคุมโอกาสที่จะมีของปลอมแม้แต่ตัวเดียว (Bonferroni) หรือคุมสัดส่วนของปลอมในรายชื่อที่ผ่าน (Benjamini–Hochberg) ระดับที่สามคือออกแบบกระบวนการวิจัยให้มีข้อมูลที่ไม่เคยถูกใช้ตัดสินใจเหลือไว้ตรวจ

หน้านี้เริ่มจากการหลอกที่ไม่ต้องใช้ฝีมือเลย นับจำนวนผู้ผ่านปลอม หาว่าผู้ชนะจาก noise ดูดีได้แค่ไหน ดูผลของความสัมพันธ์ระหว่างกลยุทธ์ แล้วจบที่ Bonferroni, BH, base rate และขั้นตอนวิจัยที่ใช้จริง

ขั้นที่ 1 — ประวัติสมบูรณ์แบบผลิตได้โดยไม่ต้องรู้อะไรเลย

โจทย์ให้อะไรมาบ้าง: ทุกวันพุธติดกันสิบสัปดาห์ คุณได้จดหมายทายผลฟุตบอลนัดใหญ่วันอาทิตย์ และทายถูกทุกครั้ง สัปดาห์ที่สิบเอ็ดจดหมายขอเงิน \$10,000 ก่อนจะบอกผลนัดถัดไป วิธีที่ผู้ส่งใช้: เริ่มส่งถึง 10,240 คน ครึ่งหนึ่งทายทีม A อีกครึ่งทายทีม B สัปดาห์ถัดไปส่งต่อเฉพาะกลุ่มที่ได้คำทายถูก แล้วแบ่งครึ่งอีก

\[\begin{aligned} \frac{10{,}240}{2^{10}}&=10,\\ 10{,}240\sum_{k=0}^{9}2^{-k}&=10{,}240\Big(2-\frac{1}{512}\Big)\\ &=20{,}460. \end{aligned}\]

คำตอบ: บรรทัดแรกคือจำนวนคนที่เหลือหลังแบ่งครึ่งสิบครั้ง บรรทัดที่สองคือจำนวนจดหมายทั้งหมด ผู้รับสิบคนเห็นประวัติทายถูกสิบครั้งติด ทั้งที่ผู้ส่งไม่รู้ผลล่วงหน้าเลย ค่าส่งฉบับละ \$0.75 รวม \$15,345 ถ้าทั้งสิบคนจ่าย รายรับคือ \$100,000 คุณคือผู้รอดของการคัดเลือก ประวัติที่คุณเห็นถูกต้องทุกบรรทัด สิ่งที่หายไปคือจดหมายอีก 20,450 ฉบับที่ทายผิดและคุณไม่เคยเห็น บรรทัดที่สองคืออนุกรมเรขาคณิต: สัปดาห์ $k$ ส่ง $10{,}240/2^k$ ฉบับ

ไม่ต้องมีคนโกงก็เกิดได้ ถ้าผู้จัดการกองทุน 10,240 คนไม่มีฝีมือ แต่ละปีชนะตลาดด้วยโอกาสครึ่งหนึ่ง และคนที่แพ้ถูกปิดกองทุน หลังสิบปีจะเหลือราวสิบคนที่ชนะรวด ฐานข้อมูลที่เก็บแต่กองทุนที่ยังเปิดอยู่จะเห็นแต่คนเหล่านี้ (survivorship bias)

ขั้นที่ 2 — นับผู้ผ่านปลอม: ค่าคาดหวังกับโอกาสมีอย่างน้อยหนึ่งตัว

ให้ $M$ เป็นจำนวนการทดสอบใน family ทุกตัวไม่มี edge และแต่ละตัวปฏิเสธผิดด้วยโอกาส $\alpha=5\%$ ให้ $I_i=1$ เมื่อตัวที่ $i$ ผ่านเกณฑ์โดยไม่สมควร และ $V=\sum_iI_i$ คือจำนวนผู้ผ่านปลอม

\[\begin{aligned} \mathbb E[V]&=\sum_{i=1}^{M}\mathbb E[I_i]=M\alpha=200(0.05)=10,\\ P(V\ge1)&=1-(1-\alpha)^M=1-0.95^{200}\\ &\approx99.9965\%,\\ 1-0.95^M\gt0.5&\ \Rightarrow\ M\gt\frac{\ln0.5}{\ln0.95}\approx13.5. \end{aligned}\]

สองตัวเลขนี้ตอบคนละคำถามและต้องการข้อสมมติต่างกัน บรรทัดแรกคือค่าเฉลี่ยของผลรวม ซึ่งบวกกันได้เสมอไม่ว่าการทดสอบจะสัมพันธ์กันแค่ไหน บรรทัดที่สองคือ family-wise error rate (FWER) ใช้การคูณโอกาสที่ “ไม่พลาดเลย” ซึ่งทำได้เฉพาะเมื่อการทดสอบอิสระกัน ถ้า 200 การทดสอบเป็นสำเนาเดียวกันหมด FWER จะเหลือ 5% แต่ $\mathbb E[V]$ ยังเป็น 10: ส่วนใหญ่ไม่มีใครผ่าน แต่ 5% ของครั้งผ่านพร้อมกันทั้ง 200 บรรทัดสุดท้ายหารด้วย $\ln0.95$ ซึ่งติดลบ ทิศอสมการจึงกลับ ผลคือการลองเพียง 14 แบบก็มีโอกาสเกินครึ่งที่จะเจอของปลอม (45 แบบเกิน 90%) ปัญหาเริ่มตั้งแต่ grid เล็ก ๆ ตัวอย่างที่แหลมที่สุด: ผู้จัดการที่ชนะตลาดเก้าในสิบปีมี p 1.07% ใน การทดสอบสมมติฐาน แต่ถ้าเขาเป็นคนที่ดีที่สุดจากผู้จัดการไร้ฝีมือ 20 คน โอกาสที่อย่างน้อยหนึ่งคนจะมีประวัติแบบนี้คือ $1-(1-0.0107)^{20}\approx19.4\%$ ไม่หายากเลย

ขั้นที่ 3 — ผู้ชนะจาก noise ดูดีได้แค่ไหน

ทีมไม่ได้ส่งมาทุกตัวที่ผ่าน มักส่งตัวที่ดีที่สุด ให้สถิติของแต่ละกลยุทธ์ภายใต้ “ไม่มี edge” เป็น normal มาตรฐานอิสระ $Z_1,\ldots,Z_M$ แล้วหาการแจกแจงของผู้ชนะ $Z_{\max}$ ค่าสูงสุดไม่เกิน $z$ ก็ต่อเมื่อทุกตัวไม่เกิน $z$

\[\begin{aligned} P(Z_{\max}\le z)&=\Phi(z)^M,\\ f_{\max}(z)&=M\,\phi(z)\,\Phi(z)^{M-1},\\ \mathbb E[Z_{\max}]&=\int_{-\infty}^{\infty}z\,f_{\max}(z)\,dz\approx2.746,\\ \widehat{\mathrm{SR}}_{\max}&\approx\frac{2.746}{\sqrt5}\approx1.23,\\ \mathbb E[Z_{\max}]&\le\sqrt{2\ln M}\approx3.255. \end{aligned}\]

ผู้ชนะของ 200 ตัวที่ไม่มีอะไรเลยมีสถิติเฉลี่ยราว 2.75 สูงกว่าเกณฑ์ 1.96 ของการทดสอบเดี่ยวสบาย ๆ บรรทัดที่สองได้จากอนุพันธ์ของบรรทัดแรก ($\phi$ คือความหนาแน่นของ normal มาตรฐาน) บรรทัดที่สามอินทิเกรตเชิงตัวเลข แปลงเป็น Sharpe รายปีด้วย $\widehat{\mathrm{SR}}=Z/\sqrt T$ จาก การทดสอบสมมติฐาน ที่ $T=5$ ได้ราว 1.23 ซึ่งเท่ากับผู้ชนะในโจทย์พอดี บรรทัดสุดท้ายคือขอบบนมาตรฐานที่โตตาม $\sqrt{\ln M}$ ให้ Sharpe ไม่เกิน $\sqrt{2\ln200/5}\approx1.46$ มันเป็นขอบบน ไม่ใช่ค่าเฉลี่ย การโตแบบราก log หมายความว่าลองเพิ่มจาก 200 เป็น 20,000 แบบ ผู้ชนะปลอมจะดูดีขึ้นเพียงราว 1.4 เท่า แต่จะดีขึ้นเสมอ และผลนี้หดตาม $1/\sqrt T$ ข้อมูลยี่สิบปีลดขอบบนเหลือ 0.73

ขั้นที่ 4 — กลยุทธ์ที่คล้ายกันนับเป็นการทดสอบน้อยกว่าจำนวนจริง

200 กลยุทธ์ใน grid จริงไม่อิสระกัน lookback 20 วันกับ 21 วันให้ผลแทบเหมือนกัน แบบจำลองง่ายที่สุดคือทุกคู่มี correlation เท่ากัน $\rho$ เขียนแต่ละสถิติเป็นส่วนร่วม $F$ บวกส่วนเฉพาะตัว $e_i$ ซึ่งเป็น normal มาตรฐานอิสระทั้งหมด

\[\begin{aligned} Z_i&=\sqrt\rho\,F+\sqrt{1-\rho}\,e_i,\\ \max_iZ_i&=\sqrt\rho\,F+\sqrt{1-\rho}\,\max_ie_i,\\ \mathbb E[Z_{\max}]&=\sqrt{1-\rho}\times2.746,\\ \rho=0.5:\ 1.94,&\qquad \rho=0.9:\ 0.87. \end{aligned}\]

ส่วนร่วมไม่ช่วยใครชนะใคร มีแต่ส่วนเฉพาะตัวที่ทำให้มีผู้ชนะ ความสัมพันธ์จึงลดการได้เปรียบของการค้นหาตาม $\sqrt{1-\rho}$ บรรทัดแรกทำให้ $Z_i$ มี variance $\rho+(1-\rho)=1$ และ covariance ของคู่ใด ๆ เท่ากับ $\rho$ บรรทัดสองดึง $\sqrt\rho F$ ออกนอก max ได้เพราะมันเท่ากันทุกตัว บรรทัดสามใช้ $\mathbb E[F]=0$ และค่าเฉลี่ย 2.746 ของผู้ชนะจาก 200 ตัวอิสระที่เพิ่งหาได้ ที่ $\rho=0.5$ ผู้ชนะปลอมมี Sharpe ห้าปีเฉลี่ยราว 0.87 ที่ $\rho=0.9$ ราว 0.39 แนวคิดเดียวกันนี้คือ Rademacher complexity ที่ใช้ในการ backtest ระดับมืออาชีพ: วัดว่าชุดกลยุทธ์ “ไล่ตาม” ลำดับ +1/−1 แบบสุ่มได้ดีแค่ไหน ถ้าทุกตัวเป็นสำเนาเดียวกัน ชุดนี้ไล่ตามอะไรไม่ได้มากกว่าตัวเดียว ถ้าทุกตัวไม่สัมพันธ์กัน มันไล่ตาม noise ได้ดีที่สุด แล้วนำค่านั้นไปหักออกจาก Sharpe ที่เห็นเป็น “haircut” ขอบบนของมันในกรณีอิสระคือ $\sqrt{2\ln M/T}$ ตัวเดียวกับขอบบนของผู้ชนะปลอมข้างบน ข้อควรระวัง: ห้ามเลือก “จำนวนการทดสอบอิสระเทียบเท่า” ตามใจเพื่อให้ผ่าน ต้องวัดจากความสัมพันธ์จริงของกลยุทธ์

ขั้นที่ 5 — Bonferroni: แบ่งงบความผิดพลาดให้ทุกการทดสอบ

ถ้าอยากให้โอกาสมีของปลอมแม้แต่ตัวเดียวทั้ง family ไม่เกิน $\alpha=5\%$ วิธีที่ง่ายที่สุดคือแบ่งงบ 5% ให้ทุกการทดสอบเท่ากัน ใช้เกณฑ์ต่อตัว $\alpha/M$ ให้ $M_0$ เป็นจำนวนการทดสอบที่ $H_0$ จริง และเรียงลำดับให้ตัวที่ 1 ถึง $M_0$ เป็นตัวเหล่านั้น

\[\begin{aligned} P(V\ge1)&\le\sum_{i=1}^{M_0}P\Big(p_i\le\frac{\alpha}{M}\Big)\\ &=M_0\frac{\alpha}{M}\le\alpha,\\ \frac{0.05}{200}&=0.00025,\\ z_{1-0.000125}&\approx3.662,\\ \widehat{\mathrm{SR}}&\ge\frac{3.662}{\sqrt5}\approx1.638. \end{aligned}\]

โอกาสที่เหตุการณ์ใดเหตุการณ์หนึ่งเกิด ไม่เกินผลบวกของโอกาสแต่ละเหตุการณ์ (union bound) อสมการนี้ไม่ต้องสมมติความอิสระเลย Bonferroni จึงใช้ได้แม้กลยุทธ์สัมพันธ์กัน ขอเพียง p-value ของแต่ละตัวถูกต้อง และนับ family ครบ บรรทัดสองใช้ว่า p-value ของตัวที่ $H_0$ จริงต่ำกว่า $c$ ด้วยโอกาส $c$ และ $M_0\le M$ สำหรับ 200 กลยุทธ์ เกณฑ์ต่อตัวคือ 0.00025 สองด้าน ค่า $z$ คือ 3.662 Sharpe ห้าปีต้องถึง 1.64 ผู้ชนะ 1.2 ในโจทย์จึงไม่ผ่าน ถ้าการทดสอบอิสระกันจริง FWER หลังปรับคือ $1-(1-0.00025)^{200}\approx4.88\%$ ข้อเสียคือเข้มเกินไปเมื่อกลยุทธ์สัมพันธ์กันมาก ดังรูปเส้นประด้านบน และมันไม่ซ่อม p-value ที่ผิดตั้งแต่ต้นจาก leakage

ขั้นที่ 6 — Benjamini–Hochberg: คุมสัดส่วนของปลอมในรายชื่อ

บางงานไม่ต้องการศูนย์ของปลอม แค่ต้องการรายชื่อผู้สมัครที่ส่วนใหญ่เป็นของจริงเพื่อไปตรวจต่อ ให้ $R$ เป็นจำนวนที่ประกาศว่าผ่าน สัดส่วนของปลอม $V/R$ (นิยามเป็นศูนย์เมื่อ $R=0$) และค่าเฉลี่ยของมันคือ false discovery rate BH ทำแบบนี้: เรียง p-value จากน้อยไปมาก $p_{(1)}\le\cdots\le p_{(M)}$ หาอันดับสุดท้ายที่อยู่ใต้เส้นที่ชันขึ้นตามอันดับ แล้วเก็บทุกอันดับจนถึงตรงนั้น

\[\begin{aligned} \mathrm{FDR}&=\mathbb E\Big[\frac{V}{\max(R,1)}\Big],\\ p_{(k)}&\le\frac{k\,q}{M},\qquad p_{(i)}\gt\frac{i\,q}{M}\ \ (i\gt k),\\ M=200,\ q=0.10:\quad\frac{iq}{M}&=0.0005\,i. \end{aligned}\]

บรรทัดที่สองนิยาม $k$ เป็นอันดับสุดท้ายที่ p อยู่ใต้เส้น ทุกอันดับหลังจากนั้นอยู่เหนือเส้น แล้วเก็บอันดับ 1 ถึง $k$ ทั้งหมด (ถ้าไม่มีอันดับใดอยู่ใต้เส้น $k=0$) อันดับแรกต้องผ่านเกณฑ์เข้มเท่า Bonferroni แต่อันดับหลัง ๆ ได้เกณฑ์หลวมขึ้น เพราะถ้ามีหลายตัวผ่านแล้ว ของปลอมหนึ่งตัวเป็นสัดส่วนที่เล็กลง ตัวอย่าง: สี่อันดับแรกมี p เป็น 0.0002, 0.0009, 0.0020, 0.0040 และอีก 196 ตัวเป็น 0.50 ทั้งหมด เส้นของอันดับ 1 ถึง 4 คือ 0.0005, 0.0010, 0.0015, 0.0020 อันดับ 1 และ 2 อยู่ใต้เส้น อันดับ 3 กับ 4 อยู่เหนือ และ 0.50 ไม่ผ่านอันดับใดเลย จึงได้ $k=2$ เก็บสองตัว Bonferroni ที่ FWER 5% (เกณฑ์ 0.00025) เก็บตัวเดียว สองวิธีนี้คุมคนละเป้าหมายด้วยคนละงบ ไม่ใช่วิธีหนึ่งดีกว่าอีกวิธี ต้องตรวจทุกอันดับ ไม่หยุดที่อันดับแรกที่เกินเส้น เพราะเส้นชันขึ้นเรื่อย ๆ อันดับหลังอาจกลับมาอยู่ใต้เส้นได้ BH คุม FDR เมื่อการทดสอบอิสระกันหรือสัมพันธ์กันในทางบวกแบบที่ทฤษฎีรองรับ ถ้าโครงสร้างความสัมพันธ์ไม่รู้ ใช้ Benjamini–Yekutieli ซึ่งหาร $q$ ด้วย $1+\tfrac12+\cdots+\tfrac1M$

ขั้นที่ 7 — ผู้ผ่านไม่ได้มีโอกาสเป็นของจริง 95% โดยอัตโนมัติ

โจทย์ให้อะไรมาบ้าง: ไอเดียกลยุทธ์ 1,000 ไอเดีย สมมติว่ามีเพียง 2% ที่มี edge จริง การทดสอบมี power 50% เมื่อ edge มีจริง และปฏิเสธผิด 5% เมื่อไม่มี ถามว่าไอเดียที่ผ่านการทดสอบมีโอกาสเป็นของจริงเท่าไร ให้ $D$ คือ “ไอเดียมี edge จริง” และ $W$ คือ “ไอเดียผ่านการทดสอบ” บรรทัดแรกข้างล่างนับไอเดียดีที่ผ่าน บรรทัดที่สองนับไอเดียไม่ดีที่ผ่าน

\[\begin{aligned} 1{,}000(0.02)(0.50)&=10,\\ 1{,}000(0.98)(0.05)&=49,\\ P(D\mid W)&=\frac{0.02(0.50)}{0.02(0.50)+0.98(0.05)}\\ &=\frac{10}{59}\approx16.9\%. \end{aligned}\]

คำตอบ: ราว 17% เท่านั้น ห้าในหกของผู้ผ่านเป็นของปลอม ทั้งที่การทดสอบแต่ละครั้งคุมความผิดไว้ 5% นี่คือ Bayes’ theorem ที่ใช้กับสัดส่วนไอเดียดีตั้งต้น (base rate) เมื่อไอเดียดีหายาก ของปลอมจำนวนมากจากกองไอเดียไม่ดีที่ใหญ่มากจะท่วมของจริง และ power ต่ำทำให้ของจริงหลุดไปครึ่งหนึ่ง ทางแก้คือเพิ่ม power (ข้อมูลยาวขึ้น) ลดเกณฑ์ (เช่น Bonferroni) หรือเพิ่ม base rate ด้วยการเลือกไอเดียที่มีเหตุผลเชิงกลไกรองรับตั้งแต่ต้น

ตรวจเองใน 10 วินาที: ผู้ผ่านทั้งหมด $10+49=59$ ตัว ของจริง 10 ตัว ได้ $10/59$

ขั้นที่ 8 — เปลี่ยนสูตรเป็นกระบวนการวิจัย

สูตรทุกตัวข้างบนต้องการสองอย่างที่ไม่มีสูตรไหนให้ได้: จำนวนการทดสอบที่ซื่อสัตย์ และ p-value ที่ไม่ปนเปื้อน ทั้งสองเป็นเรื่องของกระบวนการ

นับ family ให้ครบ: 20 lookback × 5 รอบปรับพอร์ต × 4 กฎออก คือ 400 แบบแล้ว รวมถึงการตัดสินใจนอกโค้ด เช่นเปลี่ยน universe หลังเห็นผล ถ้าไม่รู้ว่าลองไปกี่แบบ อย่าตั้ง $M=1$ เพียงเพราะเหลือผู้ชนะตัวเดียว

กัน leakage: ใช้แต่ข้อมูลที่รู้จริง ณ วันนั้น ตัวอย่างที่พบบ่อยคือ (ก) backtest หุ้น 20 ตัวที่ใหญ่ที่สุดใน S&P 500 วันนี้ ย้อนหลัง 20 ปี ซึ่งเลือกจากผู้ที่รอดและเติบโตแล้ว (ข) ใช้งบการเงินตั้งแต่วันสิ้นไตรมาสแทนวันประกาศ หรือใช้ตัวเลขที่ถูกแก้ย้อนหลัง (ค) ทำ normalize ข้อมูลทั้งชุดให้ค่าเฉลี่ยศูนย์และ variance หนึ่งก่อนแบ่ง training กับ test ข้อมูลอัตราแลกเปลี่ยนสี่ปีที่แบ่ง 75% สร้างกลยุทธ์ 25% ทดสอบจะดูดีมากใน test แต่ล้มเหลวเมื่อใช้จริง เพราะค่าเฉลี่ยและ variance ของช่วง test รั่วเข้าไปในข้อมูลที่ใช้สร้างกลยุทธ์แล้ว

แยกข้อมูลสร้างกับข้อมูลตรวจ: cross-validation แบบสุ่มแบ่งก้อนใช้กับอนุกรมเวลาได้ไม่ดี เพราะก้อนติดกันสัมพันธ์กัน และตัวแปรอย่าง momentum ที่ใช้ผลตอบแทนในอดีตอาจดึงข้อมูลจากก้อนทดสอบเข้ามา walk-forward (รูปด้านล่าง) ใกล้กับการใช้งานจริงกว่า: สร้างด้วยข้อมูลถึงวันนี้ ทดสอบกับช่วงถัดไป แล้วเลื่อนไป ราคาที่จ่ายคือใช้ข้อมูลสร้างน้อยลง ส่วน holdout ต้องใช้ครั้งเดียว ถ้าเปิดดูแล้วแก้แล้วเปิดดูใหม่ holdout ก็กลายเป็นอีกตัวแปรที่ถูก optimize

ความผิดที่ทำให้ตัวเลขดูน่าเชื่อแต่ผิด

รายงาน p ของผู้ชนะเหมือนทดสอบครั้งเดียว: ผู้ชนะจาก 200 แบบที่ไม่มี edge ผ่านเกณฑ์ 1.96 ได้ 99.4% ของครั้ง p ของมันจึงไม่มีความหมายหากไม่บอกว่าคัดมาจากเท่าไร

ใช้สูตร FWER แบบอิสระกับ grid ที่สัมพันธ์กัน: 200 แบบที่เป็นสำเนาเดียวกันมี FWER 5% ไม่ใช่ 99.9965% สูตรที่ใช้ได้เสมอคือ $\mathbb E[V]=M\alpha$ และขอบเขต Bonferroni

หยุดตรวจ BH ที่อันดับแรกที่เกินเส้น: p สองตัว 0.020 และ 0.021 ที่ $q=0.03$ เส้นคือ 0.015 และ 0.030 อันดับแรกเกินเส้น แต่อันดับสองอยู่ใต้เส้น จึงเก็บทั้งสองตัว

จูน holdout แล้วยังเรียกว่า holdout: เปิดดูห้ารอบแล้วแก้ทุกรอบเท่ากับเพิ่มการทดสอบอีกห้าครั้งบนข้อมูลชุดเดียวกัน

ใช้ฐานข้อมูลที่เหลือแต่ผู้รอด: กองทุนที่ปิดตัวหายไปจากฐานข้อมูล ค่าเฉลี่ยของกองทุนที่เหลือจึงสูงเกินจริง และทุกการทดสอบบนฐานข้อมูลนั้นเอียงไปทางเดียวกัน

โจทย์ตรวจความเข้าใจ

1. มี p-value สองตัวคือ 0.020 และ 0.021 ใช้ BH ที่ $q=0.03$ ควรเก็บกี่ตัว และ Bonferroni ที่ $\alpha=0.03$ เก็บกี่ตัว

เฉลย

BH: $M=2$ เส้นคือ $1\times0.03/2=0.015$ และ $2\times0.03/2=0.030$ อันดับแรก 0.020 เกิน 0.015 แต่อันดับสอง 0.021 ไม่เกิน 0.030 อันดับสุดท้ายที่อยู่ใต้เส้นคืออันดับ 2 จึงเก็บทั้งสองตัว Bonferroni: เกณฑ์ $0.03/2=0.015$ ไม่มีตัวไหนผ่าน เก็บศูนย์ตัว

2. ทีมลอง 50 กลยุทธ์อิสระที่ไม่มี edge บนข้อมูลสิบปี ใช้เกณฑ์ 5% คาดว่ามีผู้ผ่านปลอมกี่ตัว โอกาสมีอย่างน้อยหนึ่งตัวเท่าไร และ Sharpe ต้องถึงเท่าไรตาม Bonferroni

เฉลย

$\mathbb E[V]=50(0.05)=2.5$ ตัว $P(V\ge1)=1-0.95^{50}\approx92.3\%$ เกณฑ์ต่อตัวคือ $0.05/50=0.001$ สองด้าน $z_{0.9995}\approx3.29$ Sharpe ต้องถึง $3.29/\sqrt{10}\approx1.04$

3. ถ้าสัดส่วนไอเดียดีเพิ่มจาก 2% เป็น 10% (power 50% และเกณฑ์ 5% เท่าเดิม) ผู้ผ่านมีโอกาสเป็นของจริงเท่าไร

เฉลย

ของจริงที่ผ่าน $1{,}000(0.10)(0.50)=50$ ของปลอมที่ผ่าน $1{,}000(0.90)(0.05)=45$ โอกาสคือ $50/95\approx52.6\%$ base rate ที่ดีขึ้นห้าเท่าทำให้ผู้ผ่านน่าเชื่อขึ้นจาก 17% เป็นราวครึ่งหนึ่ง การเลือกไอเดียที่มีเหตุผลรองรับมีค่ามากกว่าการปรับสูตรทดสอบ

function integrate(f, a, b, steps = 8000) {
  const h = (b - a) / steps;
  let s = f(a) + f(b);
  for (let i = 1; i < steps; i++) s += (i % 2 ? 4 : 2) * f(a + i * h);
  return s * h / 3;
}
function Phi(x) {
  const ax = Math.abs(x), d = Math.exp(-ax * ax / 2) / Math.sqrt(2 * Math.PI);
  if (ax < 3) {
    let term = ax, sum = ax;
    for (let k = 1; term > 1e-17 * sum; k++) { term *= ax * ax / (2 * k + 1); sum += term; }
    return x < 0 ? 0.5 - d * sum : 0.5 + d * sum;
  }
  let f = 0;
  for (let k = 300; k >= 1; k--) f = k / (ax + f);
  return x < 0 ? d / (ax + f) : 1 - d / (ax + f);
}
const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
function quantile(p) {
  let lo = -10, hi = 10;
  for (let i = 0; i < 100; i++) { const m = (lo + hi) / 2; if (Phi(m) < p) lo = m; else hi = m; }
  return (lo + hi) / 2;
}
// Benjamini-Hochberg: largest rank whose sorted p-value sits under the line i q / M.
function bh(values, q) {
  const p = [...values].sort((a, b) => a - b);
  let k = 0;
  p.forEach((v, i) => { if (v <= (i + 1) * q / p.length) k = i + 1; });
  return k;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • 200 กลยุทธ์ที่ไม่มี edge ให้ผู้ผ่านปลอมคาดหวัง 10 ตัวเสมอ และถ้าอิสระกัน โอกาสมีอย่างน้อยหนึ่งตัวคือ 99.9965%
  • ผู้ชนะจาก 200 ตัวที่เป็น noise มีสถิติเฉลี่ย 2.75 หรือ Sharpe ห้าปีราว 1.23 และความสัมพันธ์ระหว่างกลยุทธ์ลดค่านี้ตาม $\sqrt{1-\rho}$
  • Bonferroni ใช้เกณฑ์ $\alpha/M$ คุม FWER โดยไม่ต้องอิสระ สำหรับ 200 แบบห้าปี Sharpe ต้องถึงราว 1.64
  • BH คุมสัดส่วนของปลอมในรายชื่อ ต้องตรวจทุกอันดับ และในตัวอย่างเก็บสองตัวขณะที่ Bonferroni เก็บหนึ่ง
  • เมื่อไอเดียดีมีแค่ 2% ผู้ผ่านเป็นของจริงเพียงราว 17% และไม่มีสูตรใดแทนการนับทุกแบบที่ลอง การกัน leakage และ holdout ที่ใช้ครั้งเดียวได้

บทนี้จบด้วยคำถามว่าข้อมูลที่มี ณ เวลาหนึ่งบอกอะไรได้บ้าง ซึ่งเป็นแนวคิดตั้งต้นของบทถัดไป filtration และ martingale ที่ทำให้คำว่า “รู้อะไร ณ วันนั้น” กลายเป็นคณิตศาสตร์ และใช้มันอธิบายว่าทำไมไม่มีระบบเดิมพันใดชนะเกมที่ยุติธรรมได้
