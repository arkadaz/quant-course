11.3 Linear Programming Duality

ถามกลับด้านว่าแต่ละข้อจำกัดมีราคาเท่าไร แล้วได้ขอบล่างที่ชนต้นทุน hedge จริงพอดี ราคาชุดนั้นใช้ตั้งราคาสัญญาใหม่และใช้ต่อรองเพดาน

ลูกค้าขอซื้อ call บนหุ้นตัวเดียวกับใน โจทย์ hedge ภาระ \$120/\$90/\$50 (หุ้นราคา \$100 ปีหน้าเป็น \$130, \$100 หรือ \$70 พันธบัตรราคา \$95 คืน \$100) call strike \$100 อายุหนึ่งปีจ่าย \$30 ถ้าตลาดขึ้น และ \$0 ในอีกสองกรณี น้องในโต๊ะหยิบน้ำหนัก 1/6 ที่ใช้พิสูจน์ต้นทุน \$90.50 มาคูณ แล้วบอกว่า “ราคาที่ถูกต้องคือ $30\times\tfrac16=\$5.00$” โต๊ะควรขาย call นี้ที่ \$5.00 ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ควร \$5.00 เป็นแค่ปลายล่าง น้ำหนัก 1/6 เป็นราคาชุดหนึ่งในหลายชุดที่อธิบายราคาหุ้นและพันธบัตรได้ครบเท่ากัน ชุดอื่นให้ call แพงได้ถึง \$16.75 ถ้าขายที่ \$5.00 โต๊ะจะ hedge ให้จ่ายครบทุกกรณีไม่ได้ เพราะพอร์ตที่ถูกที่สุดที่จ่ายไม่น้อยกว่า \$30, \$0, \$0 คือหุ้น 0.5 หุ้นกับ short พันธบัตร 0.35 หน่วย ราคา \$16.75 ราคาที่ไม่เปิดช่อง arbitrage อยู่ระหว่าง \$5.00 กับ \$16.75

ภาพรวมก่อนลงสูตร

ตอนหา hedge ที่ถูกที่สุด เราพิสูจน์ต้นทุน \$90.50 ด้วยน้ำหนัก $\tfrac16$ กับ $\tfrac{47}{60}$ แต่ยังไม่ได้บอกว่าน้ำหนักพวกนั้นหามาจากไหน และหมายถึงอะไร หน้านี้สร้างมันจากคำถามกลับด้าน: แทนที่จะถามว่าต้องซื้ออะไร ให้ถามว่าเงิน \$1 ที่ได้ในแต่ละสภาวะควรมีราคาวันนี้เท่าไร คำถามนั้นเป็น LP อีกตัวหนึ่ง เรียกว่า dual ส่วนโจทย์ hedge เดิมเรียกว่า primal

รูปด้านล่างคือหัวใจของหน้านี้ แผนที่จ่ายครบทุกแผนมีต้นทุนอยู่ข้างบน ราคาสภาวะที่ใช้ได้ทุกชุดให้ขอบล่างอยู่ข้างล่าง ไม่มีขอบล่างตัวไหนเกินต้นทุนของแผนไหน เพราะฉะนั้นถ้าเจอคู่ที่เท่ากันพอดี ทั้งสองต้องเป็นคำตอบที่ดีที่สุดทั้งคู่ ที่นี่คู่นั้นพบกันที่ \$90.50

หน้านี้จะสร้างขอบล่าง เห็นขอบล่างที่ดีที่สุดชนต้นทุนจริง ดูว่าทำไมสภาวะที่มีเงินเหลือมีราคาศูนย์ แล้วใช้ราคาชุดนี้สองแบบ: เป็นราคาของเงินในแต่ละสภาวะเพื่อตั้งราคา call และเป็นราคาของแต่ละข้อจำกัดเพื่อรู้ว่าเพดาน SPY มีค่า \$60 ต่อ \$1 ล้าน

ศัพท์ที่ใช้ในหัวข้อนี้
Dual LP
LP คู่ที่ให้ราคากับแต่ละข้อจำกัดของโจทย์เดิม (primal) ใช้สร้างขอบล่างของต้นทุน ค่าของมันไม่เกินต้นทุนของแผนใด ๆ ที่ใช้ได้
Weak duality
ค่าของ dual ทุกชุดที่ใช้ได้ไม่เกินต้นทุนของ primal ทุกแผนที่ใช้ได้ ใช้บีบคำตอบจากสองข้างโดยยังไม่ต้องแก้จนจบ
Strong duality
ถ้าฝั่งใดฝั่งหนึ่งมีค่าที่ดีที่สุดเป็นตัวเลขจำกัด ค่าที่ดีที่สุดของทั้งสองฝั่งเท่ากันพอดี ใช้เป็นใบรับรองว่าคำตอบดีที่สุดจริง และเป็น checksum ของแบบจำลอง
Complementary slackness
ทุกข้อจำกัด ส่วนเหลือคูณราคาต้องเป็นศูนย์ที่คำตอบ ข้อที่ยังมีที่ว่างมีราคาศูนย์ ข้อที่มีราคาบวกต้องชนพอดี
State price
ราคาวันนี้ของสัญญาที่จ่าย \$1 ถ้าสภาวะหนึ่งเกิดและ \$0 ถ้าไม่เกิด (เรียกอีกชื่อว่า Arrow–Debreu price) ใช้ตั้งราคาอะไรก็ได้ที่เขียน payoff เป็นรายสภาวะ
Shadow price
ต้นทุนที่ดีที่สุดเปลี่ยนไปเท่าไรเมื่อขยับข้อจำกัดข้อหนึ่งหนึ่งหน่วย ใช้ได้ในช่วงที่ชุดของข้อจำกัดที่ชนยังเป็นชุดเดิม
Risk-neutral probability
state price หารด้วยผลรวมของมัน ใช้เป็นน้ำหนักเฉลี่ย payoff แล้วคิดลดด้วยดอกเบี้ย ไม่ใช่โอกาสจริงที่สภาวะจะเกิด
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$u=(u_1,u_2,u_3)$ราคาของเงิน \$1 ในกรณีขึ้น ทรงตัว และลงดอลลาร์วันนี้ต่อดอลลาร์ปีหน้า
$t$ตัวแปรเดียวที่เหลืออิสระในราคาชุดที่ใช้ได้เหมือน $u$
$P,\ D$ต้นทุนที่ดีที่สุดของ primal และค่าที่ดีที่สุดของ dualดอลลาร์
$e$เงินเหลือของแผนในแต่ละสภาวะ $e=S\theta-X$ดอลลาร์
$h$payoff ของสัญญาใหม่ เช่น call $(30,0,0)$ดอลลาร์
$q,\ r$risk-neutral probability และดอกเบี้ยไร้ความเสี่ยงหนึ่งปีไม่มีหน่วย
$y,\ u_Q,\ u_S$ราคาของเกณฑ์ beta ของเพดาน QQQ และของเพดาน SPYดอลลาร์ต่อหน่วยของแถวนั้น
$U_S,\ B$เพดาน SPY และเกณฑ์ beta ที่ต้องลด เมื่อลองขยับล้านดอลลาร์ และ beta คูณล้านดอลลาร์

ขั้นที่ 1 — ถามกลับด้าน: ถ่วงแต่ละสภาวะด้วยราคา แล้วได้ขอบล่าง

เราต้องการตัวเลขที่พิสูจน์ว่าไม่มี hedge ไหนถูกกว่า ทำแบบเดียวกับตอนพิสูจน์ \$90.50 แต่ยังไม่เลือกน้ำหนัก: คูณแถวของสภาวะที่ $i$ ด้วย $u_i\ge0$ ซึ่งไม่พลิกเครื่องหมายอสมการเพราะคูณด้วยค่าไม่ติดลบ แล้วบวกทั้งสามแถว จัดกลุ่มตาม $\theta_1$ กับ $\theta_2$

\[ \begin{aligned} &u_1y_1+u_2y_2+u_3y_3\ge X^{\mathsf T}u,\\ &(130u_1+100u_2+70u_3)\,\theta_1\\ &\quad+100(u_1+u_2+u_3)\,\theta_2\ge X^{\mathsf T}u,\\ &130u_1+100u_2+70u_3=100,\\ &100(u_1+u_2+u_3)=95,\\ &p^{\mathsf T}\theta\ge X^{\mathsf T}u,\\ &D=\max_u\ X^{\mathsf T}u,\\ &\text{s.t.}\ S^{\mathsf T}u=p,\ u\ge0. \end{aligned} \]

สองบรรทัดแรกเป็นพีชคณิตล้วน ถ้าสองบรรทัดกลางเป็นจริง ด้านซ้ายก็คือต้นทุน $100\theta_1+95\theta_2$ พอดี ทุกแผนที่จ่ายครบจึงแพงอย่างน้อย $X^{\mathsf T}u$ อยากได้ขอบล่างที่คมที่สุดก็เลือก $u$ ให้ $X^{\mathsf T}u$ มากที่สุด ได้ LP ใหม่ในสองบรรทัดสุดท้าย

ทำไมต้องเท่ากันเป๊ะ ไม่ใช่แค่ไม่เกิน? เพราะ $\theta$ ติดลบได้ ถ้าตัวคูณของ $\theta_1$ เป็น 101 แทน 100 ด้านซ้ายจะต่างจากต้นทุนไป $\theta_1$ ซึ่งเป็นบวกหรือลบก็ได้ ขอบล่างของด้านซ้ายจึงไม่ใช่ขอบล่างของต้นทุนอีกต่อไป

รูปทั่วไปของคู่นี้คือ primal $P=\min_x c^{\mathsf T}x$ ภายใต้ $Ax\ge b$ กับ dual $D=\max_u b^{\mathsf T}u$ ภายใต้ $A^{\mathsf T}u=c$ และ $u\ge0$ ของเราคือ $A=S$, $b=X$, $c=p$ แถวของ primal กลายเป็นตัวแปรของ dual และตัวแปรของ primal กลายเป็นแถวของ dual

ขั้นที่ 2 — แก้ข้อจำกัดของ dual: ราคาที่ใช้ได้เป็นเส้น ไม่ใช่จุด

ข้อจำกัด $S^{\mathsf T}u=p$ อ่านทีละคอลัมน์ของ $S$ คือทีละสินทรัพย์: ราคาชุดนี้ต้องให้ราคาหุ้น \$100 และราคาพันธบัตร \$95 ถูกต้อง มีสองสมการแต่สามตัวแปร จึงเหลืออิสระหนึ่งตัว

\[ \begin{aligned} &130u_1+100u_2+70u_3=100,\\ &100u_1+100u_2+100u_3=95,\\ &30u_1-30u_3=5,\\ &u_3=t,\qquad u_1=\tfrac16+t,\\ &u_2=0.95-u_1-u_3=\tfrac{47}{60}-2t,\\ &0\le t\le\tfrac{47}{120}\approx0.3917. \end{aligned} \]

ลบบรรทัดที่สองออกจากบรรทัดแรก $u_2$ หักหาย เหลือ $30u_1-30u_3=5$ ตั้ง $u_3=t$ แล้วเขียนอีกสองตัวด้วย $t$ เงื่อนไข $u\ge0$ บังคับให้ $t\ge0$ และ $u_2\ge0$ คือ $t\le\tfrac{47}{120}$

ราคาที่ใช้ได้จึงเป็นส่วนของเส้นตรง ไม่ใช่จุดเดียว เพราะมีสามสภาวะแต่มีสินทรัพย์แค่สองตัวไว้ตรึงราคา ปลาย $t=0$ คือ $(\tfrac16, \tfrac{47}{60}, 0)$ น้ำหนักที่พิสูจน์ \$90.50 ปลาย $t=\tfrac{47}{120}$ คือ $(0.5583, 0, 0.3917)$ ซึ่งคือ $33.5/60$ กับ $23.5/60$ จากสองทิศพิเศษที่ใช้ตรวจว่าไม่มีเงินฟรีในโจทย์ hedge

จุดกลางเส้น เช่น $t=0.2$ ให้ราคาทุกสภาวะเป็นบวกจริง นี่คือหลักฐานว่าตลาดนี้ไม่มี arbitrage: ถ้ามีราคาที่เป็นบวกทุกสภาวะและอธิบายราคาตลาดได้ครบ พอร์ตที่จ่ายไม่ติดลบทุกสภาวะและเป็นบวกบางสภาวะจะมีราคาเป็นบวกเสมอ ซึ่งคือหลัก no-arbitrage แบบ strong พอดี

ขั้นที่ 3 — weak duality ด้วยตัวเลข: บีบคำตอบจากสองข้าง

โจทย์ให้อะไรมาบ้าง: แผนที่จ่ายครบแผนหนึ่งคือมุม $\theta=(\tfrac43, -\tfrac{13}{30})$ ราคา \$92.17 และราคาชุดหนึ่งบนเส้นที่ $t=0.2$ ทั้งคู่ไม่ใช่ตัวที่ดีที่สุด

\[ \begin{aligned} &u(0.2)=(0.3667,\ 0.3833,\ 0.2),\\ &\text{stock}:\ 47.67+38.33+14=100,\\ &\text{bond}:\ 36.67+38.33+20=95,\\ &X^{\mathsf T}u=44+34.5+10=88.50,\\ &88.50\le P\le92.17. \end{aligned} \]

คำตอบ: ยังไม่ได้แก้ LP ให้จบ แต่รู้แล้วว่าต้นทุน hedge ที่ดีที่สุดอยู่ระหว่าง \$88.50 กับ \$92.17 ใครอ้างว่า hedge ได้ที่ \$85 ถูกหักล้างได้ทันทีด้วยราคาชุดนี้ ใน LP ที่มีตัวแปรเป็นแสน ขอบล่างแบบนี้คือสิ่งที่บอกว่าคำตอบที่มีอยู่ห่างจากดีที่สุดไม่เกินเท่าไร

ตรวจเองใน 10 วินาที: ช่องว่าง $92.17-88.50=3.67$ เท่ากับ $0.3667\times10$ เพราะแผนนี้เหลือเงิน \$10 ในกรณีขึ้น และราคาของกรณีขึ้นคือ 0.3667 อีกไม่กี่บรรทัดจะเห็นว่าช่องว่างคือผลรวมของ “เงินเหลือคูณราคา” เสมอ

ขั้นที่ 4 — ขอบล่างที่ดีที่สุดชนต้นทุนจริงพอดี

ราคาทั้งเส้นใช้ได้หมด ชุดไหนให้ขอบล่างสูงที่สุด? แทน $u(t)$ ลงใน $X^{\mathsf T}u$ แล้วกางทีละก้อน

\[ \begin{aligned} &X^{\mathsf T}u(t)=120(\tfrac16+t)\\ &\qquad+90(\tfrac{47}{60}-2t)+50t\\ &\qquad=90.5-10t,\\ &t^*=0,\quad u^*=(\tfrac16,\ \tfrac{47}{60},\ 0),\\ &D=90.50=P,\\ &S^{\mathsf T}(1,\ -2,\ 1)^{\mathsf T}=(0,\ 0). \end{aligned} \]

ตัวคูณของ $t$ ติดลบ ยิ่ง $t$ ใหญ่ขอบล่างยิ่งต่ำ จึงเลือก $t=0$ ได้ \$90.50 เท่ากับต้นทุน hedge ที่ดีที่สุดพอดี ช่วง \$88.50 ถึง \$92.17 ยุบเหลือจุดเดียว นี่คือ strong duality และมันไม่ใช่เรื่องบังเอิญของตัวอย่างนี้ ทฤษฎีบททั่วไปมีสามชั้น: ทุกแผน $x$ และทุกราคา $u$ ที่ใช้ได้ให้ $c^{\mathsf T}x\ge P\ge D\ge b^{\mathsf T}u$ (weak) ถ้า $P$ หรือ $D$ เป็นตัวเลขจำกัด แล้ว $P=D$ (strong) และ dual ของ dual คือ primal เดิม (การพิสูจน์ทั่วไปใช้ Farkas lemma ซึ่งไม่ทำในหน้านี้)

เลข $-10$ มาจากไหน: เพิ่ม $t$ หนึ่งหน่วยคือขยับราคาไปทิศ $(1, -2, 1)$ บรรทัดสุดท้ายบอกว่าทิศนี้ไม่เปลี่ยนราคาหุ้นหรือพันธบัตรเลย ($130-200+70=0$ และ $100-200+100=0$) มันคือกฎ “กรณีทรงตัวเท่ากับค่าเฉลี่ยของขึ้นกับลง” ที่มองจากฝั่งราคา ผลต่อภาระคือ $120-180+50=-10$ ภาระที่กรณีทรงตัวสูงกว่าค่าเฉลี่ยทำให้ราคาที่ย้ายออกจากกรณีทรงตัวเสียมูลค่า

ขั้นที่ 5 — ช่องว่างคือเงินเหลือคูณราคา

เห็นช่องว่าง \$3.67 ที่ $t=0.2$ และช่องว่างศูนย์ที่ $t=0$ ต้องการสูตรที่บอกช่องว่างของทุกคู่แผนกับราคา แทน $p$ ด้วย $S^{\mathsf T}u$ ในต้นทุน แล้วย้ายวงเล็บ

\[ \begin{aligned} &p^{\mathsf T}\theta-X^{\mathsf T}u=(S^{\mathsf T}u)^{\mathsf T}\theta-X^{\mathsf T}u\\ &\qquad=u^{\mathsf T}(S\theta-X)=u^{\mathsf T}e\ge0,\\ &u^{*\mathsf T}e(\theta^*)=\tfrac16(0)+\tfrac{47}{60}(0)\\ &\qquad+0(10)=0,\\ &u(0.2)^{\mathsf T}e(\tfrac43,\ -\tfrac{13}{30})=0.3667(10)\\ &\qquad=3.67. \end{aligned} \]

บรรทัดที่สองคือ weak duality ในบรรทัดเดียว: ต้นทุนของแผนลบขอบล่างของราคา เท่ากับผลรวมของ “เงินเหลือในสภาวะนั้นคูณราคาของสภาวะนั้น” ทุกตัวไม่ติดลบ ช่องว่างจึงไม่ติดลบ

ช่องว่างเป็นศูนย์ได้ก็ต่อเมื่อทุกสภาวะมีตัวใดตัวหนึ่งเป็นศูนย์ คือเงินเหลือหรือราคา เงื่อนไขนี้ชื่อ complementary slackness สภาวะที่ hedge จ่ายพอดี (ขึ้นและทรงตัว) มีราคาบวกได้ สภาวะที่มีเงินเหลือ \$10 (ลง) ต้องมีราคาศูนย์

เหตุผลทางเงิน: กรณีลงมีเงินเหลืออยู่แล้ว เงินเพิ่มอีก \$1 ในกรณีนั้นไม่ช่วยให้จ่ายภาระได้ดีขึ้น จึงไม่มีค่าสำหรับโต๊ะนี้ ราคาศูนย์ไม่ได้แปลว่าตลาดลงไม่ได้ มันบอกคุณค่าของเงินเพิ่มสำหรับ hedge นี้ ไม่ได้บอกโอกาส นี่ตอบคำถามที่ค้างไว้ว่าทำไม hedge ที่ถูกที่สุดวางเงิน \$10 ไว้ที่กรณีลง: มันคือสภาวะที่ราคาถูกที่สุด

ขั้นที่ 6 — อ่าน $u$ เป็น shadow price: เพิ่มภาระ \$1 แล้วแก้ใหม่

ถ้า $u^*$ เป็นราคาจริง การเพิ่มภาระของสภาวะหนึ่งขึ้น \$1 ต้องทำให้ต้นทุน hedge เพิ่มเท่ากับราคาของสภาวะนั้น ลองแก้ LP ใหม่ทีละสภาวะด้วยวิธีหามุมเดิม

\[ \begin{aligned} &X_1=121:\ \theta=(\tfrac{31}{30},\ -\tfrac{2}{15}),\\ &\qquad P=90.6667=90.50+0.1667,\\ &X_2=91:\ \theta=(\tfrac{29}{30},\ -\tfrac{17}{300}),\\ &\qquad P=91.2833=90.50+0.7833,\\ &X_3=51:\ \theta=(1,\ -0.1),\\ &\qquad P=90.50+0,\\ &X_3=60\to61:\ \Delta P=0.3917. \end{aligned} \]

สามส่วนต่างตรงกับ $u^*$ ทุกตัว: 0.1667, 0.7833 และ 0 เหตุผลคือ $P=D=X^{\mathsf T}u^*$ และเมื่อขยับ $X$ นิดเดียว $u^*$ ยังเป็นราคาชุดที่ดีที่สุด อัตราที่ต้นทุนเปลี่ยนต่อภาระในสภาวะ $i$ จึงเป็น $u_i^*$ ตัวแปร dual จึงเรียกว่าราคาได้อย่างชอบธรรม

ราคาเงาใช้ได้ในช่วงหนึ่งเท่านั้น ภาระกรณีลงเพิ่มได้ฟรีจนถึง \$60 ซึ่งคือ payoff ที่ hedge จ่ายอยู่แล้ว เกินจากนั้นทุก \$1 แพงขึ้น \$0.3917 เพราะราคาชุดที่ดีที่สุดกระโดดไปอีกปลายของเส้น $(0.5583, 0, 0.3917)$

ขั้นที่ 7 — อ่าน $u$ เป็น state price: ราคา ดอกเบี้ย และโอกาสแบบ risk-neutral

$u_i^*$ คือราคาวันนี้ของสัญญาที่จ่าย \$1 ถ้าสภาวะ $i$ เกิด ตรวจก่อนว่ามันให้ราคาของที่มีในตลาดถูก แล้วอ่านสิ่งที่มันบอกเพิ่ม

\[ \begin{aligned} &\text{stock}:\ 130(\tfrac16)+100(\tfrac{47}{60})+0=100,\\ &\text{bond}:\ 100(\tfrac16+\tfrac{47}{60}+0)=95,\\ &u_1+u_2+u_3=0.95,\\ &r=1/0.95-1\approx5.26\%,\\ &q=u^*/0.95=(0.1754,\ 0.8246,\ 0),\\ &0.95\,[0.1754(130)+0.8246(100)]=100. \end{aligned} \]

สองบรรทัดแรกคือ $S^{\mathsf T}u=p$ นั่นเอง dual บังคับแค่ว่าราคาของแต่ละสภาวะต้องอธิบายราคาตลาดที่มีอยู่ได้ ผลรวมของ $u$ คือราคาวันนี้ของ \$1 ที่จ่ายแน่นอน (ได้ทุกสภาวะ) จึงเป็นตัวคิดลด 0.95 และดอกเบี้ยหนึ่งปี 5.26%

ทำไมพันธบัตรที่คืน \$100 ต้องราคา \$100/(1+r) พอดี ถ้ากู้และให้กู้ได้ที่ดอกเบี้ย $r$ เดียวกัน: ซื้อพันธบัตรที่ราคา $p$ แล้วกู้ $100/(1+r)$ ปีหน้าได้ \$100 คืนหนี้ \$100 เหลือศูนย์ทุกกรณี หลัก no-arbitrage แบบ weak บอกว่าพอร์ตที่จ่ายไม่ติดลบต้องมีราคาไม่ติดลบ จึงได้ $p\ge100/(1+r)$ กลับข้างคือขายพันธบัตรแล้วให้กู้ ได้ $p\le100/(1+r)$ สองข้างบีบให้เท่ากันพอดี

หาร $u$ ด้วย 0.95 ได้ $q$ ที่รวมกันได้ 1 เอาไปเฉลี่ย payoff หุ้นแล้วคิดลดได้ \$100 พอดี ตัวเลขนี้มาจากราคาล้วน ไม่เคยถามเลยว่าโอกาสขาขึ้นจริงเท่าไร และ $q_3=0$ ไม่ได้แปลว่าตลาดลงไม่ได้ มันเป็นผลของการเลือกปลาย $t=0$ ราคาชุดอื่นบนเส้นให้ $q_3$ เป็นบวก วิธีอ่านแบบนี้จะกลับมาเต็มรูปใน การตั้งราคาบน binomial tree ซึ่งมีสองสภาวะต่อสองสินทรัพย์ ราคาจึงเป็นจุดเดียว

ขั้นที่ 8 — ราคา call ในตลาดไม่สมบูรณ์: ช่วง ไม่ใช่เลขเดียว

กลับไปที่โจทย์เปิด ราคาทุกชุดบนเส้นอธิบายหุ้นและพันธบัตรได้ครบเท่ากัน ตลาดจึงไม่ได้บอกว่าชุดไหนถูก คิดราคา call จากทุกชุด แล้วตรวจปลายทั้งสองด้วยพอร์ตจริง

\[ \begin{aligned} &h=(30,\ 0,\ 0),\\ &h^{\mathsf T}u(t)=30(\tfrac16+t),\\ &5.00\le h^{\mathsf T}u(t)\le16.75,\\ &\theta^{\rm sub}=(1,\ -1),\\ &S\theta^{\rm sub}=(30,\ 0,\ -30)\le h,\\ &p^{\mathsf T}\theta^{\rm sub}=100-95=5.00,\\ &\theta^{\rm sup}=(0.5,\ -0.35),\\ &S\theta^{\rm sup}=(30,\ 15,\ 0)\ge h,\\ &p^{\mathsf T}\theta^{\rm sup}=50-33.25=16.75. \end{aligned} \]

บรรทัดที่สามใช้ $0\le t\le\tfrac{47}{120}$: ปลายล่าง $30\times\tfrac16=5.00$ ปลายบน $30\times(\tfrac16+\tfrac{47}{120})=30\times0.5583=16.75$ พอร์ต sub จ่ายไม่เกิน call ทุกสภาวะ พอร์ต sup จ่ายไม่น้อยกว่า call ทุกสภาวะ ราคาของมันตรงกับสองปลายพอดี ปลายบนคือ LP superhedge ของ call เอง และ strong duality บอกว่ามันเท่ากับราคาสูงสุดบนเส้น

ใครขาย call ต่ำกว่า \$5.00 เราซื้อ call แล้วขายพอร์ต sub ได้เงินวันนี้และปีหน้าไม่มีทางติดลบ ใครซื้อสูงกว่า \$16.75 เราขาย call แล้วถือพอร์ต sup แม้แต่ที่ปลายพอดีก็ยังมีช่อง: ซื้อ call ที่ \$5.00 แล้วขายพอร์ต sub ไม่ต้องจ่ายอะไร แต่ได้ \$30 ในกรณีลง ราคาที่ไม่เปิดช่อง arbitrage แบบ strong จึงอยู่ระหว่าง \$5.00 กับ \$16.75 โดยไม่รวมปลาย

ภาระ \$120/\$90/\$50 ก็มีช่วงแบบเดียวกัน: $90.5-10t$ ตั้งแต่ \$86.58 ถึง \$90.50 ปลายล่างคือพอร์ตของเพื่อนในโจทย์ hedge ซึ่งจ่าย \$120, \$85, \$50 ไม่เกินภาระทุกกรณี

ตัวอย่างที่สอง — dual ของการลด beta ด้วย QQQ และ SPY

ย้อนไปโจทย์ลด beta ของตะกร้า \$12 ล้าน: short QQQ $x_Q$ และ SPY $x_S$ (ล้านดอลลาร์) ต้นทุน \$180 และ \$90 ต่อ \$1 ล้าน ต้องให้ $1.2x_Q+x_S\ge10.8$ และแต่ละตัวไม่เกิน 6 คำตอบคือ $(4,6)$ ราคา \$1,260 คราวนี้ตัวแปรห้ามติดลบ ($x_Q, x_S\ge0$) เราจะเห็นอีกครึ่งของกฎการสร้าง dual ก่อนอื่นเขียนทุกแถวเป็นแบบ “อย่างน้อย” โดยคูณเพดานด้วย $-1$: $-x_Q\ge-6$ และ $-x_S\ge-6$ แล้วให้ราคาแต่ละแถวเป็น $y$, $u_Q$ และ $u_S$ ซึ่งไม่ติดลบทั้งหมด

ขั้นที่ 9 — ราคาต่อแถว: dual ของการลด beta

ทำเหมือนตอนถ่วงสามสภาวะ: คูณแต่ละแถวด้วยราคาของมัน แล้วบวก จัดกลุ่มตาม $x_Q$ กับ $x_S$ แต่เงื่อนไขของตัวคูณจะต่างไป เพราะตัวแปรห้ามติดลบ

\[ \begin{aligned} &y(1.2x_Q+x_S)\ge10.8y,\\ &u_Q(-x_Q)\ge-6u_Q,\\ &u_S(-x_S)\ge-6u_S,\\ &(1.2y-u_Q)x_Q+(y-u_S)x_S\\ &\qquad\ge10.8y-6u_Q-6u_S,\\ &1.2y-u_Q\le180,\qquad y-u_S\le90,\\ &D=\max\ 10.8y-6u_Q-6u_S. \end{aligned} \]

เพราะ $x_Q, x_S\ge0$ ถ้าตัวคูณของ $x_Q$ ไม่เกิน 180 ก็ได้ $180x_Q\ge(1.2y-u_Q)x_Q$ ทันที ไม่ต้องเท่ากันเป๊ะเหมือนตอน $\theta$ ติดลบได้ ต้นทุนจึงไม่ต่ำกว่า $10.8y-6u_Q-6u_S$ สำหรับราคาชุดใดก็ได้ที่ผ่านสองเงื่อนไขนี้

อ่านเป็นเงิน: short QQQ \$1 ล้านสร้าง beta 1.2 หน่วยซึ่งมีค่า $1.2y$ แต่กินเพดาน QQQ ไป \$1 ล้านซึ่งมีค่า $u_Q$ มูลค่าสุทธินี้ต้องไม่เกินต้นทุน \$180 ถ้าเกิน แปลว่าเราตั้งราคา beta สูงเกินจริง

รวมสองตัวอย่างได้กฎสี่ข้อของการสร้าง dual ของโจทย์ min:

ฝั่ง primalฝั่ง dualเห็นที่ไหน
แถว “อย่างน้อย” $\ge$ราคาแถวนั้นไม่ติดลบทุกสภาวะ และเกณฑ์ beta
แถวที่เป็นสมการ $=$ราคาแถวนั้นติดลบได้งบของกองทุนที่ต้องรวมได้ 1
ตัวแปรติดลบได้แถว dual เป็นสมการ$\theta$ ของ superhedge
ตัวแปรห้ามติดลบแถว dual เป็น “ไม่เกิน”$x_Q, x_S$ ของการลด beta

ไม่ต้องท่องตาราง: Lagrangian relaxation สร้างทั้งสี่ข้อออกมาเองแบบกลไก

ขั้นที่ 10 — ลองราคาสามชุด: ขอบล่างขยับ แต่ไม่เคยเกินต้นทุนจริง

โจทย์ให้อะไรมาบ้าง: dual ที่เพิ่งได้ และคำตอบ primal $(4,6)$ ราคา \$1,260 ที่มีเงินเหลือ $s_B=0$, $s_Q=2$, $s_S=0$ ตามที่อ่านได้จาก รูปมาตรฐาน ลองราคา $(y, u_Q, u_S)$ สามชุด

\[ \begin{aligned} &(90,\ 0,\ 0):\ 108\le180,\ 90\le90,\\ &\qquad D=10.8(90)=972,\\ &(150,\ 0,\ 60):\ 180\le180,\ 90\le90,\\ &\qquad D=1{,}620-360=1{,}260,\\ &(160,\ 0,\ 70):\ 192\gt180,\\ &150(0)+0(2)+60(0)=0. \end{aligned} \]

คำตอบ: ชุดแรกใช้ได้แต่บอกแค่ว่า “ไม่มีทางถูกกว่า \$972” จริงแต่ไม่คม ชุดที่สองดันขอบล่างถึง \$1,260 เท่ากับต้นทุนของ $(4,6)$ พอดี จึงเป็นคำตอบของ dual และพิสูจน์ว่า $(4,6)$ ดีที่สุด ชุดที่สามผิดกติกา ถ้าฝืนใช้จะได้ “ขอบล่าง” $1{,}728-420=\$1{,}308$ ซึ่งเกินต้นทุนจริง แสดงว่ากติกาของ dual จำเป็นจริง

ตรวจเองใน 10 วินาที: บรรทัดสุดท้ายคือ complementary slackness: เกณฑ์ beta และเพดาน SPY ชนพอดี (เหลือศูนย์) จึงมีราคาบวก 150 และ 60 ส่วนเพดาน QQQ เหลือ \$2 ล้าน จึงมีราคาศูนย์ ราคาชุดนี้คือ 150 กับ 60 ที่ใช้พิสูจน์ \$1,260 ตั้งแต่แรก

ขั้นที่ 11 — ราคาเงาของเพดาน SPY และช่วงที่ใช้ได้

$u_S^*=60$ บอกว่าเพดาน SPY เพิ่ม \$1 ล้าน ต้นทุนลด \$60 ตรวจด้วยการเขียนต้นทุนที่ดีที่สุดเป็นฟังก์ชันของเพดาน $U_S$ แล้วดูว่าสูตรใช้ได้ถึงไหน

\[ \begin{aligned} &C(U_S)=90U_S+150(10.8-U_S)\\ &\qquad=1{,}620-60U_S,\\ &0\le(10.8-U_S)/1.2\le6,\\ &3.6\le U_S\le10.8,\\ &C(7)=1{,}620-420=1{,}200,\\ &C(B)=540+150(B-6),\\ &6\le B\le13.2,\quad C(10.2)=1{,}170. \end{aligned} \]

SPY ใช้เต็มเพดาน $U_S$ แล้ว QQQ เติม beta ที่เหลือ $(10.8-U_S)/1.2$ ในราคา \$180 ต่อ \$1 ล้าน หรือ \$150 ต่อ beta ต้นทุนจึงลด \$60 ทุก \$1 ล้านของเพดาน SPY ที่เพิ่ม (SPY \$90 เข้าแทน QQQ \$150) แต่สูตรนี้ใช้ได้เฉพาะเมื่อ QQQ อยู่ระหว่าง 0 ถึง 6 คือเพดาน SPY ระหว่าง \$3.6 ล้าน ถึง \$10.8 ล้าน ต่ำกว่านั้นไม่มีแผนที่ผ่านกฎ สูงกว่านั้น SPY ตัวเดียวพอ เพดานไม่ชนอีก ราคาเงากลายเป็นศูนย์

$y^*=150$ อ่านแบบเดียวกัน: เกณฑ์ $B$ เพิ่ม 1 ต้นทุนเพิ่ม \$150 ถ้าฝ่ายความเสี่ยงยอม beta 0.25 แทน 0.20 เกณฑ์ลดเป็น $12(1.10-0.25)=10.2$ ประหยัด $150\times0.6=\$90$ เหลือ \$1,170 (ตรวจตรง: SPY 6 QQQ $4.2/1.2=3.5$ ต้นทุน $630+540$) ใช้ได้ตั้งแต่เกณฑ์ 6 (QQQ เป็นศูนย์) ถึง 13.2 (QQQ เต็ม) ส่วน $u_Q^*=0$ เพราะ QQQ ยังเหลือเพดาน ผ่อนไปก็ไม่ได้อะไร

ความผิดที่ทำให้เสียเงินจริง

เรียกปลายของช่วงว่า “ราคาที่ถูกต้อง”: ขาย call ที่ \$5.00 แล้ว hedge ที่จ่ายครบทุกกรณีต้องใช้ \$16.75 โต๊ะขาดเงิน hedge \$11.75 หรือต้องยอมรับความเสี่ยงในกรณีทรงตัวแทน ในตลาดไม่สมบูรณ์ ราคาเดียวต้องมาจากการเลือกเพิ่ม เช่นแบบจำลองหรือความชอบเสี่ยง ไม่ได้มาจากการไม่มี arbitrage อย่างเดียว

ใช้ราคาเงานอกช่วง: ขยายเพดาน SPY จาก \$6 ล้านเป็น \$12 ล้าน แล้วคาดว่าประหยัด $6\times60=\$360$ ต้นทุนเหลือ \$900 ของจริงเหลือ \$972 เพราะเพดานที่เกิน \$10.8 ล้านไม่ได้ใช้ ประมาณผิดไป \$72

เทียบราคาเงาข้ามหน่วย: $y^*=150$ คือดอลลาร์ต่อหนึ่งหน่วยของ beta คูณล้านดอลลาร์ ส่วน $u_S^*=60$ คือดอลลาร์ต่อ \$1 ล้านของเพดาน ตัวเลขที่ใหญ่กว่าไม่ได้แปลว่าข้อนั้นสำคัญกว่า ต้องเทียบราคาเงาของแต่ละข้อกับต้นทุนของการได้ทรัพยากรนั้นเพิ่มหนึ่งหน่วย

เชื่อเครื่องหมายของ solver: solver ส่วนใหญ่รายงาน dual values หรือ marginals มาด้วย แต่เครื่องหมายขึ้นกับว่ามันใช้ min หรือ max และเขียนแถวเป็น $\le$ หรือ $\ge$ วิธีกันพลาดคือแก้ใหม่หลังขยับข้อจำกัดหนึ่งหน่วยแบบที่ทำกับภาระ \$121 แล้วดูว่าต้นทุนขยับทางเดียวกับที่ราคาบอก

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะ pricing ใช้คู่ primal–dual ตั้งกรอบราคาของสินค้าที่ hedge ไม่ได้พอดี ต้นทุน superhedge เป็นเพดานของราคาที่ขายได้โดยไม่รับความเสี่ยง และต้นทุน sub-hedge เป็นพื้นของราคาที่ซื้อได้ ส่วนที่เหลือระหว่างสองค่าคือพื้นที่ที่ต้องใช้แบบจำลองหรือการตัดสินใจเรื่องความเสี่ยง

ฝ่ายบริหารความเสี่ยงใช้ shadow price ตัดสินว่าควรลงทุนขยายเพดานข้อไหน ถ้าการขอเพิ่มเพดาน SPY \$1 ล้านมีต้นทุนจริง (เช่นค่าสภาพคล่องหรือค่าทุน) ต่ำกว่า \$60 ก็คุ้ม ถ้าแพงกว่าก็ไม่คุ้ม และความเท่ากันของ primal กับ dual ใช้เป็น checksum ทุกครั้งที่แก้แบบจำลอง: ถ้าสองตัวเลขไม่เท่ากัน แปลว่าเครื่องหมายของแถว หน่วย หรือคำตอบผิดที่ใดที่หนึ่ง

แบบจำลองนี้มีสามสภาวะที่รู้ payoff แน่นอน ช่วงราคาจึงขึ้นกับว่าเลือกสภาวะอย่างไร และเมื่อคำตอบ primal มีข้อจำกัดชนเกินจำเป็น ราคาเงาอาจมีหลายชุด ตัวที่ solver รายงานเป็นแค่ชุดหนึ่ง ต้องตรวจด้วยการแก้ใหม่ทั้งทางขึ้นและทางลง

โจทย์ตรวจความเข้าใจ

1. put strike \$100 จ่าย \$0, \$0, \$30 ในสามสภาวะ ราคาที่ไม่เปิดช่อง arbitrage อยู่ในช่วงไหน และพอร์ต superhedge คืออะไร?

เฉลย

ราคาจากเส้นคือ $30u_3=30t$ ตั้งแต่ 0 ถึง $30\times\tfrac{47}{120}=11.75$ ไม่รวมปลาย พอร์ต superhedge คือ $(-0.5, 0.65)$ จ่าย $(-65+65, -50+65, -35+65)=(0, 15, 30)$ ราคา $-50+61.75=\$11.75$ สังเกตว่า call ลบ put ได้ $30(\tfrac16+t)-30t=5$ ทุก $t$ เท่ากับหุ้น \$100 ลบพันธบัตร \$95 เพราะ payoff ของ call ลบ put คือ $(30, 0, -30)$ ซึ่งเป็นหุ้นลบพันธบัตรพอดี

2. ถ้าโต๊ะจะเป็นฝ่ายรับภาระ \$120/\$90/\$50 จากคนอื่น (ได้รับเงินนั้นปีหน้า) ควรจ่ายวันนี้ได้มากสุดเท่าไรโดยยังล็อกกำไรได้?

เฉลย

ใช้ปลายล่างของช่วง: $90.5-10\times\tfrac{47}{120}=90.5-3.9167=\$86.58$ ที่ราคานี้โต๊ะ short พอร์ต $(\tfrac76, -\tfrac{19}{60})$ ได้เงิน \$86.58 และพอร์ตนั้นต้องจ่าย \$120, \$85, \$50 ซึ่งไม่เกินเงินที่ได้รับทุกกรณี (เหลือ \$5 ในกรณีทรงตัว) จ่ายถูกกว่านี้ได้กำไรแน่นอน จ่ายแพงกว่านี้ต้องรับความเสี่ยง

3. ถ้าโต๊ะกู้เงินได้ที่ดอกเบี้ย 6% ต่อปี แต่ให้กู้ได้แค่ 5% พันธบัตรที่คืน \$100 ในหนึ่งปีต้องมีราคาเท่าไรจึงไม่เปิดช่อง arbitrage?

เฉลย

ใช้สองพอร์ตเหมือนตอนอ่านดอกเบี้ยจากราคาสภาวะ ซื้อพันธบัตรแล้วกู้ $100/1.06=\$94.34$ ปีหน้าเหลือศูนย์ทุกกรณี พอร์ตนี้จึงต้องมีราคาไม่ติดลบ $p-94.34\ge0$ ได้ $p\ge\$94.34$ ขายพันธบัตรแล้วให้กู้ $100/1.05=\$95.24$ ได้ $95.24-p\ge0$ คือ $p\le\$95.24$ ราคาเป็นช่วง \$94.34 ถึง \$95.24 ไม่ใช่ค่าเดียว ส่วนต่างดอกเบี้ยกู้กับให้กู้ทำหน้าที่เหมือนสภาวะที่ขาดหายไป ช่องว่างของราคาจึงเปิดออก

รันใน Node.js ได้โดยไม่ติดตั้งแพ็กเกจ ฟังก์ชัน lp แก้ LP เล็ก ๆ ด้วยการไล่คำตอบพื้นฐานทุกแบบ แล้วรับคำตอบก็ต่อเมื่อมีราคาแถวชุดหนึ่งที่พิสูจน์ว่าไม่มีคอลัมน์ไหนถูกกว่าราคาของมัน โค้ดแก้ primal กับ dual แยกกันแล้วเทียบค่า คำนวณ “เงินเหลือคูณราคา” หาราคาเงาด้วยการแก้ใหม่ทีละหน่วย หาช่วงราคา call และ put จากราคาชุดที่ใช้ได้ทั้งหมด และขยับเพดาน SPY กับเกณฑ์ beta

// Tiny exact LP: minimise c.x subject to rows[k].x >= rhs[k]; x[j] >= 0 unless j is listed in free.
// It lists every basic solution of the standard form, so it only suits a handful of variables.
function solveSquare(M, v) {
  const n = M.length, T = M.map((r, i) => [...r, v[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (Math.abs(T[r][c]) > Math.abs(T[p][c])) p = r;
    if (Math.abs(T[p][c]) < 1e-12) return null;
    [T[c], T[p]] = [T[p], T[c]];
    for (let r = 0; r < n; r++) if (r !== c) {
      const f = T[r][c] / T[c][c];
      for (let k = c; k <= n; k++) T[r][k] -= f * T[c][k];
    }
  }
  return T.map((r, i) => r[n] / r[i]);
}
function choose(n, k) {
  const out = [], pick = [];
  (function walk(s) {
    if (pick.length === k) { out.push([...pick]); return; }
    for (let i = s; i < n; i++) { pick.push(i); walk(i + 1); pick.pop(); }
  })(0);
  return out;
}
function lp(c, rows, rhs, free = []) {
  const n = c.length, m = rows.length;
  if (!c.every(Number.isFinite) || !m || !rows.every(r => Array.isArray(r) && r.length === n && r.every(Number.isFinite))) {
    throw new TypeError('Need a finite cost and rows of matching length');
  }
  if (!Array.isArray(rhs) || rhs.length !== m || !rhs.every(Number.isFinite)) throw new TypeError('Need one finite limit per row');
  // Standard form columns: x+ for every variable, x- for free ones, then one surplus per row.
  const cols = [];
  for (let j = 0; j < n; j++) {
    cols.push({j, sign: 1});
    if (free.includes(j)) cols.push({j, sign: -1});
  }
  for (let k = 0; k < m; k++) cols.push({row: k});
  const A = rows.map((r, k) => cols.map(col => (col.row === undefined ? col.sign * r[col.j] : (col.row === k ? -1 : 0))));
  const cost = cols.map(col => (col.row === undefined ? col.sign * c[col.j] : 0));
  const corners = [];
  for (const basis of choose(cols.length, m)) {
    const part = solveSquare(A.map(r => basis.map(i => r[i])), rhs);
    if (!part || part.some(v => v < -1e-9)) continue;
    const z = new Array(cols.length).fill(0);
    basis.forEach((i, k) => { z[i] = part[k]; });
    corners.push({basis, z, value: z.reduce((s, v, i) => s + v * cost[i], 0)});
  }
  if (!corners.length) throw new RangeError('No feasible corner: the rules clash');
  const low = Math.min(...corners.map(k => k.value));
  // Proof of optimality: row prices y with B^T y = c_B and no column cheaper than its price (reduced cost >= 0).
  let proof = null;
  for (const k of corners.filter(k => k.value <= low + 1e-9)) {
    const y = solveSquare(k.basis.map(i => A.map(r => r[i])), k.basis.map(i => cost[i]));
    if (y && cols.every((_, i) => cost[i] - A.reduce((s, r, q) => s + y[q] * r[i], 0) >= -1e-9)) { proof = {...k, y}; break; }
  }
  if (!proof) throw new RangeError('No corner proves itself cheapest: the cost has no floor');
  const x = new Array(n).fill(0);
  cols.forEach((col, i) => { if (col.row === undefined) x[col.j] += col.sign * proof.z[i]; });
  const surplus = rows.map((r, k) => r.reduce((s, a, j) => s + a * x[j], 0) - rhs[k]);
  return {x, value: proof.value, surplus, rowPrices: proof.y};
}
const dot = (a, b) => a.reduce((s, v, i) => s + v * b[i], 0);
const T = M => M[0].map((_, j) => M.map(r => r[j]));
// Primal: cheapest superhedge. Dual: best state prices u >= 0 with S^T u = p, written as two >= rows.
const S = [[130, 100], [100, 100], [70, 100]], X = [120, 90, 50], p = [100, 95];
const primal = X => lp(p, S, X, [0, 1]);
const dualRows = [...T(S), ...T(S).map(r => r.map(v => -v))], dualRhs = [...p, ...p.map(v => -v)];
const priceRange = h => [lp(h, dualRows, dualRhs).value, -lp(h.map(v => -v), dualRows, dualRhs).value];
const P = primal(X), dual = lp(X.map(v => -v), dualRows, dualRhs), u = dual.x;
const segment = t => [1 / 6 + t, 47 / 60 - 2 * t, t], tMax = 47 / 120;
const call = [30, 0, 0], put = [0, 0, 30];
// Beta hedge: caps written as -x >= -6. Its dual: max 10.8y - 6uQ - 6uS with 1.2y - uQ <= 180, y - uS <= 90.
const betaRows = [[1.2, 1], [-1, 0], [0, -1]];
const beta = (need = 10.8, capS = 6) => lp([180, 90], betaRows, [need, -6, -capS]);

สิ่งที่ควรตอบได้หลังอ่าน

  • dual ของ superhedge คือหาค่าสูงสุดของ $X^{\mathsf T}u$ ภายใต้ $S^{\mathsf T}u=p$ และ $u\ge0$ ตัวแปรที่ติดลบได้ทำให้เป็นสมการ ตัวแปรที่ห้ามติดลบทำให้เป็นข้อ “ไม่เกิน”
  • ช่องว่าง $p^{\mathsf T}\theta-X^{\mathsf T}u=u^{\mathsf T}e\ge0$ คือ weak duality ที่ดีที่สุดทั้งสองฝั่งเท่ากันที่ \$90.50 และ \$1,260 คือ strong duality
  • ส่วนเหลือคูณราคาเป็นศูนย์ทุกข้อ: กรณีลงเหลือ \$10 จึงมีราคาศูนย์ เพดาน QQQ เหลือ \$2 ล้านจึงมีราคาศูนย์
  • $u^*=(\tfrac16, \tfrac{47}{60}, 0)$ เป็นทั้ง shadow price (ภาระกรณีทรงตัวเพิ่ม \$1 ต้นทุนเพิ่ม \$0.7833) และ state price (ให้ราคาหุ้น \$100 พันธบัตร \$95 ดอกเบี้ย 5.26%)
  • ตลาดไม่สมบูรณ์ให้ราคาเป็นช่วง: call อยู่ระหว่าง \$5.00 กับ \$16.75 และเพดาน SPY มีราคา \$60 ต่อ \$1 ล้านเฉพาะช่วง \$3.6 ล้าน ถึง \$10.8 ล้าน

หน้าถัดไป Lagrangian relaxation จะสร้าง dual ชุดเดิมจากอีกทาง: แทนที่จะห้ามฝ่าข้อจำกัด ให้ติดค่าปรับต่อหน่วยที่ฝ่า แล้วถามว่าค่าปรับเท่าไรทำให้ไม่มีใครอยากฝ่า วิธีนี้คือ Lagrangian ที่ใช้ต่อในโจทย์ไม่เชิงเส้นทั้งหมด
