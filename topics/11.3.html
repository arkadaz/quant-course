11.3 Linear Programming Duality

แทนที่จะถามว่าต้องซื้ออะไร ให้ถามว่าเงิน \$1 ในแต่ละกรณีมีราคาเท่าไร คำถามกลับด้านนี้ให้ขอบล่างที่ชนต้นทุน hedge จริงพอดี และให้ราคาที่ใช้ตั้งราคาสัญญาใหม่กับวัดค่าของเพดาน

ลูกค้ารายหนึ่งขอซื้อสัญญาใหม่บนหุ้นตัวหนึ่งจากโต๊ะเทรด โต๊ะต้องตั้งราคาขาย ถ้าตั้งต่ำไป เงินที่ได้จะไม่พอซื้อพอร์ตที่ใช้ปิดความเสี่ยงของสัญญานี้

ตลาดในโจทย์นี้ง่ายที่สุดเท่าที่เป็นไปได้ มีแค่หนึ่งปี และปีหน้าเกิดได้สามกรณี คือตลาดขึ้น ทรงตัว หรือลง ของที่ซื้อขายได้วันนี้มีสองอย่าง:

  • หุ้น ราคาวันนี้ \$100 ปีหน้าเป็น \$130, \$100 หรือ \$70 ตามกรณี
  • พันธบัตร ราคาวันนี้ \$95 ปีหน้าคืน \$100 ทุกกรณี

สัญญาที่ลูกค้าขอคือ call strike \$100 อายุหนึ่งปี call คือสิทธิ์ซื้อหุ้นปีหน้าในราคาที่ตกลงไว้วันนี้ ราคานั้นเรียกว่า strike ถ้าหุ้นขึ้นเป็น \$130 ลูกค้าใช้สิทธิ์ซื้อที่ \$100 ได้ส่วนต่าง $130-100=\$30$ ถ้าหุ้นอยู่ที่ \$100 หรือ \$70 สิทธิ์นี้ไม่มีค่า สรุปคือ call จ่าย \$30, \$0, \$0 ในกรณีขึ้น ทรงตัว และลง

โต๊ะนี้เคยเจอโจทย์คล้ายกันใน โจทย์ hedge ภาระ \$120/\$90/\$50 ครั้งนั้นโต๊ะมีภาระต้องจ่ายลูกค้าปีหน้า \$120, \$90 หรือ \$50 ตามกรณี จึงต้องซื้อ hedge ไว้วันนี้ hedge คือพอร์ตหุ้นกับพันธบัตรที่ปีหน้าให้เงินพอจ่ายภาระครบ ไม่ว่าเกิดกรณีไหน hedge ที่ถูกที่สุดราคา \$90.50

ตอนพิสูจน์ว่า \$90.50 ถูกที่สุด เราใช้ตัวเลขช่วยสองตัว คือ $\tfrac16$ คู่กับกรณีขึ้น และ $\tfrac{47}{60}$ คู่กับกรณีทรงตัว น้องในโต๊ะเดาว่า $\tfrac16$ คือราคาวันนี้ของเงิน \$1 ที่จ่ายเฉพาะกรณีขึ้น call จ่าย \$30 ในกรณีนั้น น้องจึงคูณ:

\[30\times\tfrac16=\$5.00\]

โต๊ะควรขาย call นี้ที่ \$5.00 ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ควร \$5.00 เป็นแค่ราคาต่ำสุดที่เป็นไปได้ ไม่ใช่ราคาที่ถูกต้อง ตัวเลข $\tfrac16$ มาจากราคาต่อกรณีชุดหนึ่ง แต่ยังมีอีกหลายชุดที่ให้ราคาหุ้น \$100 และราคาพันธบัตร \$95 ตรงตลาดเหมือนกัน ชุดอื่นให้ราคา call สูงได้ถึง \$16.75

ถ้าขายที่ \$5.00 โต๊ะจะมีเงินไม่พอ hedge พอร์ตที่ถูกที่สุดที่ปีหน้าจ่ายไม่น้อยกว่า \$30, \$0, \$0 คือซื้อหุ้น 0.5 หุ้น และ short พันธบัตร 0.35 หน่วย (short คือยืมของมาขายวันนี้ ได้เงินวันนี้ แล้วปีหน้าต้องคืน) ราคาวันนี้ของพอร์ตนี้คือ

\[\begin{aligned}0.5(100)-0.35(95)&=50-33.25\\&=\$16.75\end{aligned}\]

ราคา call ที่ไม่เปิดช่องให้ใครทำเงินฟรีแบบไม่มีความเสี่ยง (arbitrage) อยู่ระหว่าง \$5.00 กับ \$16.75 หน้านี้จะหาตัวเลขทั้งสองทีละขั้น

ภาพรวมก่อนลงสูตร

ตอนหา hedge ที่ถูกที่สุด เราพิสูจน์ต้นทุน \$90.50 ด้วยตัวเลขช่วย $\tfrac16$ กับ $\tfrac{47}{60}$ แต่ยังไม่ได้บอกว่าตัวเลขพวกนี้มาจากไหน และหมายถึงอะไร หน้านี้ตอบเรื่องนั้นด้วยการถามกลับด้าน

คำถามเดิมคือ “ต้องซื้อหุ้นกับพันธบัตรเท่าไร hedge จึงถูกที่สุด” โจทย์แบบนี้เป็น linear program (LP) คือหาค่าต่ำสุดของต้นทุนที่เป็นเส้นตรง ภายใต้ข้อจำกัดที่เป็นอสมการเชิงเส้น เราเรียกโจทย์เดิมนี้ว่า primal

คำถามกลับด้านคือ “เงิน \$1 ที่จะได้ปีหน้าเฉพาะในกรณีหนึ่ง ควรมีราคาวันนี้เท่าไร” คำถามนี้ก็เป็น LP อีกตัวหนึ่ง เรียกว่า dual คำตอบของมันคือราคาต่อกรณีหนึ่งชุด และราคาชุดนั้นให้ตัวเลขที่รับประกันว่าไม่มี hedge ไหนถูกกว่า เราเรียกตัวเลขแบบนี้ว่า ขอบล่าง

รูปด้านล่างคือหัวใจของหน้านี้ แถวบนคือต้นทุนของแผน hedge ต่าง ๆ ที่จ่ายภาระครบ แถวล่างคือขอบล่างจากราคาต่อกรณีแต่ละชุด ขอบล่างไม่เคยเกินต้นทุนของแผนไหนเลย ดังนั้นถ้าเจอแผนกับขอบล่างที่เท่ากันพอดี แผนนั้นถูกที่สุดแน่นอน และขอบล่างนั้นสูงที่สุดแน่นอน ในโจทย์นี้ทั้งสองพบกันที่ \$90.50

ลำดับของหน้านี้คือ สร้างขอบล่าง ดูขอบล่างที่ดีที่สุดชนต้นทุนจริง ดูว่าทำไมกรณีที่ hedge มีเงินเหลือจึงได้ราคาศูนย์ แล้วใช้ราคาชุดนี้สองแบบ แบบแรกเป็นราคาของเงินในแต่ละกรณี ใช้ตั้งราคา call แบบที่สองเป็นราคาของแต่ละข้อจำกัด ใช้ตอบคำถามแบบ “ถ้าขยายเพดานการ short กองทุน SPY อีก \$1 ล้าน ต้นทุน hedge ลดลงเท่าไร” (SPY คือกองทุนที่ซื้อขายเหมือนหุ้นและวิ่งตามดัชนี S&P 500) ครึ่งหลังของหน้าจะคำนวณว่าคำตอบคือ \$60

ศัพท์ที่ใช้ในหัวข้อนี้
Call, put และ strike
call คือสิทธิ์ซื้อหุ้นในอนาคตที่ราคาซึ่งตกลงไว้วันนี้ ราคานั้นเรียกว่า strike ถ้าหุ้นสูงกว่า strike ผู้ถือได้ส่วนต่าง ถ้าไม่สูงกว่า ได้ศูนย์ put คือสิทธิ์ขาย ได้ส่วนต่างเมื่อหุ้นต่ำกว่า strike
Short
ยืมของมาขายวันนี้ ได้เงินวันนี้ แล้วต้องหาของนั้นมาคืนในอนาคต ในสูตรเขียนเป็นจำนวนที่ติดลบ
Payoff
เงินที่สัญญาหรือพอร์ตจ่ายปีหน้า แยกตามกรณี เช่น call จ่าย \$30, \$0, \$0
Arbitrage
วิธีทำเงินที่ไม่มีทางขาดทุนในกรณีไหนเลย แบบ weak คือได้เงินวันนี้โดยปีหน้าไม่ติดลบ แบบ strong รวมถึงกรณีที่วันนี้จ่ายศูนย์ แต่ปีหน้าได้เงินอย่างน้อยหนึ่งกรณี ราคาที่ “ไม่เปิดช่อง arbitrage” คือราคาที่ไม่มีวิธีแบบนี้
Primal
โจทย์เดิม ในหน้านี้คือหา hedge ที่ถูกที่สุดที่จ่ายภาระครบทุกกรณี
Dual LP
LP คู่ของ primal ที่ตั้งราคาให้แต่ละข้อจำกัด (ในตัวอย่างแรกคือแต่ละกรณีของตลาด) แล้วหาราคาชุดที่ให้ขอบล่างของต้นทุนสูงที่สุด ค่าของ dual ไม่เคยเกินต้นทุนของแผนใด ๆ ที่จ่ายครบ
Weak duality
ขอบล่างจากราคาทุกชุดที่ผ่านกติกาของ dual ไม่เกินต้นทุนของทุกแผนที่ผ่านกติกาของ primal ใช้บีบคำตอบจากสองข้าง โดยยังไม่ต้องแก้โจทย์จนจบ
Strong duality
ถ้าฝั่งใดฝั่งหนึ่งมีค่าที่ดีที่สุดเป็นตัวเลขจำกัด ค่าที่ดีที่สุดของสองฝั่งเท่ากันพอดี ใช้เป็นใบรับรองว่าคำตอบดีที่สุดจริง และใช้ตรวจว่าแบบจำลองไม่ผิด
Complementary slackness
ที่คำตอบที่ดีที่สุด ทุกข้อจำกัดต้องมี “ส่วนเหลือคูณราคา” เท่ากับศูนย์ ข้อที่ยังมีที่ว่างจึงมีราคาศูนย์ ข้อที่มีราคาเป็นบวกต้องชนพอดี
State price
ราคาวันนี้ของสัญญาที่จ่าย \$1 ถ้ากรณีหนึ่งเกิด และ \$0 ถ้าไม่เกิด (อีกชื่อคือ Arrow–Debreu price) ใช้ตั้งราคาอะไรก็ได้ที่เขียน payoff แยกตามกรณีได้
Shadow price (ราคาเงา)
ต้นทุนที่ดีที่สุดเปลี่ยนไปเท่าไร เมื่อผ่อนหรือเพิ่มข้อจำกัดข้อหนึ่งหนึ่งหน่วย ใช้ได้เฉพาะช่วงที่ชุดของข้อจำกัดที่ชนพอดียังเป็นชุดเดิม
Risk-neutral probability
state price หารด้วยผลรวมของ state price ทุกกรณี ได้ตัวเลขที่รวมกันได้ 1 ใช้เฉลี่ย payoff แล้วคิดลดด้วยดอกเบี้ยได้ราคาวันนี้ แต่มันไม่ใช่โอกาสจริงที่กรณีนั้นจะเกิด
ตลาดไม่สมบูรณ์ (incomplete market)
ตลาดที่มีจำนวนกรณีมากกว่าจำนวนสินทรัพย์ที่ใช้ตรึงราคา ราคาต่อกรณีจึงมีได้หลายชุด และสัญญาใหม่มีราคาเป็นช่วง ไม่ใช่เลขเดียว
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย

$S$ตาราง payoff ขนาด 3×2 แถวคือกรณีขึ้น ทรงตัว ลง คอลัมน์คือหุ้นกับพันธบัตรดอลลาร์ปีหน้า

ขั้นที่ 1 — ถามกลับด้าน: ถ่วงแต่ละกรณีด้วยราคา แล้วได้ขอบล่าง

เราต้องการตัวเลขที่พิสูจน์ว่าไม่มี hedge ไหนถูกกว่า โดยไม่ต้องไล่ลองทุกแผน ก่อนอื่นทวนโจทย์ hedge แผนหนึ่งคือคู่ตัวเลข $\theta=(\theta_1,\theta_2)$ โดย $\theta_1$ คือจำนวนหุ้น และ $\theta_2$ คือจำนวนพันธบัตร ทั้งสองติดลบได้ ติดลบแปลว่า short ต้นทุนวันนี้ของแผนคือ $100\theta_1+95\theta_2$ และเงินที่แผนจ่ายปีหน้าต้องไม่น้อยกว่าภาระในทุกกรณี เงื่อนไขนี้เขียนเป็นอสมการได้สามข้อ ข้อละหนึ่งกรณี

เขียนย่อด้วย matrix ได้ว่า หาค่าต่ำสุดของ $p^{\mathsf T}\theta$ ภายใต้ $S\theta\ge X$ โดย $S$ คือตาราง payoff (แถวคือกรณี คอลัมน์คือหุ้นกับพันธบัตร) $X=(120, 90, 50)$ คือภาระ และ $p=(100, 95)$ คือราคาวันนี้

วิธีพิสูจน์ \$90.50 เดิมคือคูณอสมการด้วยน้ำหนักแล้วบวกกัน คราวนี้ทำแบบเดียวกัน แต่ยังไม่เลือกค่าของน้ำหนัก ให้ $u_1, u_2, u_3$ เป็นน้ำหนักของกรณีขึ้น ทรงตัว และลง ทุกตัวต้องไม่ติดลบ เพราะการคูณอสมการด้วยค่าติดลบจะพลิกทิศของมัน คูณแล้วบวกทั้งสามข้อ จัดกลุ่มตาม $\theta_1$ กับ $\theta_2$:

\[ \begin{aligned} &130\theta_1+100\theta_2\ge120\quad(\times u_1),\\ &100\theta_1+100\theta_2\ge90\quad(\times u_2),\\ &70\theta_1+100\theta_2\ge50\quad(\times u_3),\\ &(130u_1+100u_2+70u_3)\,\theta_1\\ &\quad+100(u_1+u_2+u_3)\,\theta_2\\ &\quad\ge120u_1+90u_2+50u_3=X^{\mathsf T}u,\\ &130u_1+100u_2+70u_3=100,\\ &100(u_1+u_2+u_3)=95,\\ &100\theta_1+95\theta_2\ge X^{\mathsf T}u,\\ &D=\max_u\ X^{\mathsf T}u\\ &\quad\text{s.t.}\ S^{\mathsf T}u=p,\ u\ge0. \end{aligned} \]

ความคิดหลักคือ อสมการที่จริงสำหรับทุกแผน เมื่อคูณด้วยน้ำหนักที่ไม่ติดลบแล้วบวกกัน ก็ยังจริงสำหรับทุกแผน ถ้าเลือกน้ำหนักให้ตัวคูณของ $\theta_1$ เท่ากับ 100 และตัวคูณของ $\theta_2$ เท่ากับ 95 ด้านซ้ายจะกลายเป็นต้นทุน $100\theta_1+95\theta_2$ ของแผนพอดี ดังนั้นทุกแผนที่จ่ายครบมีต้นทุนอย่างน้อย $X^{\mathsf T}u$ อยากได้ขอบล่างที่สูงที่สุด ก็เลือก $u$ ให้ $X^{\mathsf T}u$ มากที่สุด นี่คือ LP ใหม่ชื่อ dual และเรียกค่าที่ดีที่สุดของมันว่า $D$

สองเงื่อนไขของน้ำหนักมีความหมายทางเงิน ถ้าอ่าน $u_i$ เป็นราคาของเงิน \$1 ในกรณี $i$ เงื่อนไขแรกบอกว่าราคาชุดนี้ต้องให้ราคาหุ้น \$100 ตรงตลาด เงื่อนไขที่สองบอกว่าต้องให้ราคาพันธบัตร \$95 ตรงตลาด เขียนรวมเป็น $S^{\mathsf T}u=p$

จุดที่ต้องระวังคือ ทำไมตัวคูณต้องเท่ากับราคาพอดี ไม่ใช่แค่ไม่เกิน เพราะ $\theta$ ติดลบได้ สมมติตัวคูณของ $\theta_1$ เป็น 101 แทน 100 ด้านซ้ายจะเป็น $101\theta_1+95\theta_2=(100\theta_1+95\theta_2)+\theta_1$ คือต้นทุนบวก $\theta_1$ ถ้าแผนมี $\theta_1$ เป็นบวก ด้านซ้ายจะสูงกว่าต้นทุน การรู้ว่าด้านซ้ายไม่ต่ำกว่า $X^{\mathsf T}u$ จึงไม่บอกอะไรเกี่ยวกับต้นทุน ถ้าใช้ 99 ปัญหาเดียวกันเกิดเมื่อ $\theta_1$ ติดลบ แผนเลือกเครื่องหมายของ $\theta_1$ ได้ทั้งสองทาง ทางเดียวที่ปลอดภัยคือให้เท่ากันพอดี

รูปทั่วไปของคู่นี้คือ primal หาค่าต่ำสุด $P=\min_x c^{\mathsf T}x$ ภายใต้ $Ax\ge b$ โดย $x$ ติดลบได้ และ dual หาค่าสูงสุด $D=\max_u b^{\mathsf T}u$ ภายใต้ $A^{\mathsf T}u=c$ และ $u\ge0$ ของเราคือ $A=S$, $b=X$, $c=p$ สังเกตว่าแต่ละข้อจำกัดของ primal (แต่ละกรณี) กลายเป็นตัวแปรหนึ่งตัวของ dual และแต่ละตัวแปรของ primal (หุ้น พันธบัตร) กลายเป็นสมการหนึ่งข้อของ dual

ขั้นที่ 2 — แก้ข้อจำกัดของ dual: ราคาที่ใช้ได้เป็นเส้น ไม่ใช่จุด

ขั้นที่แล้วได้ dual มา ก่อนหาค่าสูงสุด ต้องรู้ก่อนว่าราคา $u$ แบบไหนบ้างที่ผ่านกติกา กติกา $S^{\mathsf T}u=p$ มีสองสมการ สมการแรกมาจากหุ้น: ราคาชุดนี้ต้องให้ราคาหุ้น \$100 สมการที่สองมาจากพันธบัตร: ต้องให้ราคาพันธบัตร \$95 มีสองสมการแต่มีสามตัวแปร จึงเหลือตัวแปรที่เลือกได้อิสระหนึ่งตัว เราเรียกมันว่า $t$

\[ \begin{aligned} &130u_1+100u_2+70u_3=100,\\ &100u_1+100u_2+100u_3=95,\\ &30u_1-30u_3=5,\\ &u_3=t,\qquad u_1=\tfrac16+t,\\ &u_2=0.95-u_1-u_3=\tfrac{47}{60}-2t,\\ &0\le t\le\tfrac{47}{120}\approx0.3917. \end{aligned} \]

ลบสมการพันธบัตรออกจากสมการหุ้น พจน์ $100u_2$ หักกันหาย เหลือ $30u_1-30u_3=5$ หรือ $u_1=\tfrac16+u_3$ ตั้งชื่อ $u_3=t$ แล้วเขียนอีกสองตัวด้วย $t$ เงื่อนไขว่าราคาห้ามติดลบให้ขอบสองข้าง: $u_3\ge0$ ให้ $t\ge0$ และ $u_2\ge0$ ให้ $\tfrac{47}{60}-2t\ge0$ คือ $t\le\tfrac{47}{120}$

ราคาที่ใช้ได้จึงเป็นส่วนของเส้นตรง ไม่ใช่จุดเดียว สาเหตุคือมีสามกรณี แต่มีสินทรัพย์แค่สองตัวไว้ตรึงราคา ปลาย $t=0$ คือ $u=(\tfrac16, \tfrac{47}{60}, 0)$ ซึ่งคือน้ำหนักที่พิสูจน์ \$90.50 ปลาย $t=\tfrac{47}{120}$ คือ $u=(\tfrac{67}{120}, 0, \tfrac{47}{120})=(0.5583, 0, 0.3917)$ สองตัวนี้เท่ากับ $33.5/60$ กับ $23.5/60$ ซึ่งเคยเห็นแล้วตอนตรวจว่าโจทย์ hedge ไม่มีเงินฟรี

จุดกลางเส้น เช่น $t=0.2$ ให้ราคาเป็นบวกทุกกรณี จุดนี้เป็นหลักฐานว่าตลาดนี้ไม่มี arbitrage เหตุผลคือ ราคาวันนี้ของพอร์ตใด ๆ เท่ากับผลรวมของ “เงินที่พอร์ตจ่ายในแต่ละกรณี คูณราคาของกรณีนั้น” ($p^{\mathsf T}\theta=u^{\mathsf T}S\theta$ เพราะ $p=S^{\mathsf T}u$) ถ้าพอร์ตจ่ายไม่ติดลบทุกกรณี และจ่ายเป็นบวกอย่างน้อยหนึ่งกรณี ผลรวมนี้ต้องเป็นบวก ไม่มีใครได้พอร์ตแบบนั้นไปฟรี นี่คือหลัก no-arbitrage แบบ strong

ขั้นที่ 3 — weak duality ด้วยตัวเลข: บีบคำตอบจากสองข้าง

ใน LP จริงที่มีตัวแปรเป็นแสนตัว เรามักแก้ไม่จบในเวลาที่มี แต่ยังอยากรู้ว่าแผนที่มีอยู่ดีพอหรือยัง ขั้นนี้แสดงว่าแผนที่ยังไม่ดีที่สุดหนึ่งแผน กับราคาที่ยังไม่ดีที่สุดหนึ่งชุด ก็บีบคำตอบได้แล้ว

โจทย์ให้อะไรมาบ้าง:

  • แผน hedge แผนหนึ่งที่จ่ายภาระครบ: ซื้อหุ้น $\theta_1=\tfrac43$ หุ้น และ short พันธบัตร $\tfrac{13}{30}$ หน่วย คือ $\theta_2=-\tfrac{13}{30}$ แผนนี้คือมุมหนึ่งของพื้นที่แผนที่ใช้ได้ในโจทย์ hedge
  • ราคาต่อกรณีชุดหนึ่งบนเส้นของขั้นที่ 2 ที่ $t=0.2$: $u=(\tfrac16+0.2,\ \tfrac{47}{60}-0.4,\ 0.2)=(0.3667, 0.3833, 0.2)$

คำถามคือ โดยยังไม่แก้ LP ให้จบ บอกได้ไหมว่าต้นทุน hedge ที่ถูกที่สุด $P$ อยู่ช่วงไหน

\[ \begin{aligned} &p^{\mathsf T}\theta=100(\tfrac43)-95(\tfrac{13}{30})\\ &\quad=133.33-41.17=92.17,\\ &130u_1+100u_2+70u_3\\ &\quad=47.67+38.33+14=100,\\ &100(u_1+u_2+u_3)\\ &\quad=36.67+38.33+20=95,\\ &X^{\mathsf T}u=120u_1+90u_2+50u_3\\ &\quad=44+34.5+10=88.50,\\ &88.50\le P\le92.17. \end{aligned} \]

คำตอบ: แผนนี้มีต้นทุน \$92.17 ราคาชุดนี้ให้ราคาหุ้น \$100 และพันธบัตร \$95 ตรงตลาด จึงผ่านกติกาของ dual และให้ขอบล่าง \$88.50 ต้นทุนที่ดีที่สุดจึงไม่ต่ำกว่า \$88.50 (เพราะเป็นขอบล่าง) และไม่สูงกว่า \$92.17 (เพราะมีแผนที่ทำได้ที่ราคานี้อยู่แล้ว) ถ้ามีคนอ้างว่า hedge ได้ที่ \$85 ราคาชุดนี้หักล้างได้ทันที เพราะ \$85 ต่ำกว่าขอบล่าง \$88.50 ใน LP ขนาดใหญ่ ขอบล่างแบบนี้บอกว่าคำตอบที่มีอยู่ห่างจากดีที่สุดได้ไม่เกินเท่าไร

ตรวจเองใน 10 วินาที: ช่องว่างคือ $92.17-88.50=3.67$ ลองดูว่าแผนนี้จ่ายเท่าไรปีหน้า ในกรณีขึ้นแผนจ่าย

\[ \begin{aligned} 130(\tfrac43)-100(\tfrac{13}{30})&=173.33-43.33\\ &=130, \end{aligned} \]

เกินภาระ \$120 ไป \$10 ส่วนกรณีทรงตัวและลงแผนจ่าย \$90 กับ \$50 พอดีภาระ ช่องว่างจึงเท่ากับ $0.3667\times10=3.67$ คือเงินเหลือ \$10 คูณราคาของกรณีขึ้น ขั้นที่ 5 จะพิสูจน์ว่าช่องว่างเป็นผลรวมของ “เงินเหลือคูณราคา” เสมอ

ขั้นที่ 4 — ขอบล่างที่ดีที่สุดชนต้นทุนจริงพอดี

ทุกจุดบนเส้นราคาให้ขอบล่างที่ถูกต้อง แต่เราอยากได้ขอบล่างที่สูงที่สุด เพราะมันบีบคำตอบได้แน่นที่สุด จึงแทน $u(t)$ จากขั้นที่ 2 ลงใน $X^{\mathsf T}u$ แล้วกางวงเล็บ ขอบล่างจะออกมาเป็นเส้นตรงของ $t$

\[ \begin{aligned} &X^{\mathsf T}u(t)=120(\tfrac16+t)\\ &\quad+90(\tfrac{47}{60}-2t)+50t\\ &\quad=(20+70.5)+(120-180+50)t\\ &\quad=90.5-10t,\\ &t^*=0,\quad u^*=(\tfrac16,\ \tfrac{47}{60},\ 0),\\ &D=90.5-10(0)=90.50=P,\\ &S^{\mathsf T}(1,\ -2,\ 1)^{\mathsf T}=(0,\ 0). \end{aligned} \]

ตัวคูณของ $t$ ติดลบ ยิ่ง $t$ ใหญ่ ขอบล่างยิ่งต่ำ จึงเลือก $t=0$ ได้ขอบล่าง \$90.50 ซึ่งเท่ากับต้นทุน hedge ที่ถูกที่สุดพอดี ช่วง \$88.50 ถึง \$92.17 จากขั้นที่ 3 ยุบเหลือจุดเดียว ข้อเท็จจริงที่ว่าขอบล่างที่ดีที่สุดเท่ากับต้นทุนที่ดีที่สุดพอดี เรียกว่า strong duality

เรื่องนี้ไม่ใช่ความบังเอิญของตัวอย่างนี้ ทฤษฎีบทของ LP บอกสามข้อ ข้อแรกคือ weak duality: ทุกแผน $x$ และทุกราคา $u$ ที่ผ่านกติกาให้ $c^{\mathsf T}x\ge P\ge D\ge b^{\mathsf T}u$ ข้อสองคือ strong duality: ถ้า $P$ หรือ $D$ เป็นตัวเลขจำกัด แล้ว $P=D$ ข้อสามคือ dual ของ dual คือ primal เดิม การพิสูจน์ข้อสองในกรณีทั่วไปใช้ Farkas lemma ซึ่งหน้านี้ไม่ทำ

เลข $-10$ มาจากไหน การเพิ่ม $t$ หนึ่งหน่วยคือการขยับราคาไปในทิศ $(1, -2, 1)$ แถวสุดท้ายของสูตรบอกว่าทิศนี้ไม่เปลี่ยนราคาหุ้น เพราะ $130-200+70=0$ และไม่เปลี่ยนราคาพันธบัตร เพราะ $100-200+100=0$ ราคาจึงยังผ่านกติกา ทิศนี้คือกฎ “payoff กรณีทรงตัวเท่ากับค่าเฉลี่ยของกรณีขึ้นกับกรณีลง” ที่มองจากฝั่งราคา แต่ทิศนี้เปลี่ยนค่าของภาระไป $120-180+50=-10$ ค่าติดลบเพราะภาระกรณีทรงตัว \$90 สูงกว่าค่าเฉลี่ยของกรณีขึ้นกับลง $\tfrac{120+50}{2}=\$85$ การย้ายราคาออกจากกรณีทรงตัวจึงทำให้ภาระดูถูกลง

ขั้นที่ 5 — ช่องว่างคือเงินเหลือคูณราคา

ขั้นที่ 3 เห็นช่องว่าง \$3.67 ที่ $t=0.2$ ขั้นที่ 4 เห็นช่องว่างศูนย์ที่ $t=0$ ตอนนี้อยากได้สูตรที่บอกช่องว่างของแผนใดก็ได้กับราคาชุดใดก็ได้ ให้ $e=S\theta-X$ คือเงินเหลือของแผนในแต่ละกรณี (เงินที่แผนจ่ายลบภาระ) แผนที่จ่ายครบมี $e\ge0$ ทุกกรณี วิธีหาสูตรคือแทนราคาตลาด $p$ ในต้นทุนด้วย $S^{\mathsf T}u$ ซึ่งเท่ากันตามกติกาของ dual แล้วจัดวงเล็บใหม่

\[ \begin{aligned} &p^{\mathsf T}\theta-X^{\mathsf T}u\\ &\quad=(S^{\mathsf T}u)^{\mathsf T}\theta-X^{\mathsf T}u\\ &\quad=u^{\mathsf T}(S\theta-X)=u^{\mathsf T}e\ge0,\\ &u^{*\mathsf T}e(\theta^*)=\tfrac16(0)+\tfrac{47}{60}(0)+0(10)\\ &\quad=0,\\ &u(0.2)^{\mathsf T}e(\tfrac43,\ -\tfrac{13}{30})\\ &\quad=0.3667(10)+0.3833(0)+0.2(0)\\ &\quad=3.67. \end{aligned} \]

สูตรนี้บอกว่า ต้นทุนของแผนลบขอบล่างของราคา เท่ากับผลรวมของ “เงินเหลือในกรณีนั้น คูณราคาของกรณีนั้น” จังหวะสำคัญคือการแทน $p$ ด้วย $S^{\mathsf T}u$ ซึ่งทำได้เพราะราคาที่ผ่านกติกาของ dual ให้ราคาหุ้นกับพันธบัตรตรงตลาดพอดี หลังแทนแล้ว $(S^{\mathsf T}u)^{\mathsf T}\theta=u^{\mathsf T}S\theta$ เป็นแค่การสลับลำดับการคูณ เงินเหลือไม่ติดลบ ราคาก็ไม่ติดลบ ช่องว่างจึงไม่ติดลบ นี่คือ weak duality ที่พิสูจน์ได้ในบรรทัดเดียว

ช่องว่างเป็นศูนย์ได้ก็ต่อเมื่อทุกกรณีมีตัวใดตัวหนึ่งเป็นศูนย์ คือเงินเหลือเป็นศูนย์ หรือราคาเป็นศูนย์ เงื่อนไขนี้ชื่อ complementary slackness ใน hedge ที่ถูกที่สุด $\theta^*=(1, -0.1)$ ซึ่งปีหน้าจ่าย \$120, \$90, \$60 กรณีขึ้นกับกรณีทรงตัวจ่ายพอดีภาระ ราคาของสองกรณีนี้จึงเป็นบวกได้ กรณีลงมีเงินเหลือ $60-50=\$10$ ราคาของกรณีลงจึงต้องเป็นศูนย์

เหตุผลทางเงิน: ในกรณีลง hedge มีเงินเหลืออยู่แล้ว ได้เงินเพิ่มอีก \$1 ในกรณีนั้นก็ไม่ช่วยให้จ่ายภาระได้ดีขึ้น เงินก้อนนั้นจึงไม่มีค่าสำหรับโต๊ะนี้ ราคาศูนย์ไม่ได้แปลว่าตลาดลงไม่ได้ มันบอกค่าของเงินเพิ่มสำหรับ hedge นี้ ไม่ได้บอกโอกาส และมันตอบคำถามที่ค้างไว้ว่า ทำไม hedge ที่ถูกที่สุดจึงเหลือเงิน \$10 ไว้ในกรณีลง คำตอบคือ กรณีลงเป็นกรณีที่ราคาถูกที่สุด

ขั้นที่ 6 — อ่าน $u$ เป็น shadow price: เพิ่มภาระ \$1 แล้วแก้ใหม่

ถ้า $u^*$ เป็น “ราคา” จริง การเพิ่มภาระในกรณีหนึ่งอีก \$1 ควรทำให้ต้นทุน hedge ที่ดีที่สุดเพิ่มขึ้นเท่ากับราคาของกรณีนั้นพอดี ทดสอบด้วยการแก้ LP ใหม่ทีละกรณี เมื่อขยับภาระนิดเดียว hedge ที่ดีที่สุดยังจ่ายพอดีในกรณีขึ้นกับกรณีทรงตัว จึงหา $\theta$ ได้จากสองสมการ $130\theta_1+100\theta_2=X_1$ และ $100\theta_1+100\theta_2=X_2$ ลบกันได้ $30\theta_1=X_1-X_2$ แล้วคิดต้นทุน $P=100\theta_1+95\theta_2$

\[ \begin{aligned} &\theta_1=\tfrac{X_1-X_2}{30},\quad\theta_2=\tfrac{X_2}{100}-\theta_1,\\ &X_1=121:\ \theta=(\tfrac{31}{30},\ -\tfrac{2}{15}),\\ &\quad P=103.3333-12.6667\\ &\quad\phantom{P}=90.50+0.1667,\\ &X_2=91:\ \theta=(\tfrac{29}{30},\ -\tfrac{17}{300}),\\ &\quad P=96.6667-5.3833\\ &\quad\phantom{P}=90.50+0.7833,\\ &X_3=51:\ \theta=(1,\ -0.1),\ P=90.50+0,\\ &X_3\gt60:\\ &\quad P=\max(90.5,\ 67+\tfrac{47}{120}X_3),\\ &X_3=61:\ P=67+23.8917\\ &\quad\phantom{X_3=61:\ P}=90.50+0.3917. \end{aligned} \]

ส่วนต่างสามตัวแรก 0.1667, 0.7833 และ 0 ตรงกับ $u^*=(\tfrac16, \tfrac{47}{60}, 0)$ ทุกตัว เหตุผลคือ ต้นทุนที่ดีที่สุดเท่ากับขอบล่างที่ดีที่สุด $P=D=X^{\mathsf T}u^*$ เมื่อขยับ $X$ เพียงเล็กน้อย ราคาชุด $u^*$ ยังเป็นชุดที่ดีที่สุด ต้นทุนจึงเปลี่ยนไป $u_i^*$ ต่อภาระ \$1 ที่เพิ่มในกรณี $i$ นี่คือเหตุที่เรียกตัวแปรของ dual ว่า “ราคา” ได้ ในบทบาทนี้เรียกว่า shadow price หรือราคาเงา

กรณีลงต่างออกไป ภาระกรณีลง \$51 ยังไม่ต้องเปลี่ยนแผน เพราะ hedge เดิมจ่าย \$60 ในกรณีลงอยู่แล้ว ต้นทุนจึงไม่เพิ่มเลย ตรงกับราคาศูนย์

แต่ราคาเงาใช้ได้ในช่วงหนึ่งเท่านั้น ภาระกรณีลงเพิ่มได้ฟรีจนถึง \$60 เกินจากนั้นต้องคิดใหม่ วิธีที่สั้นที่สุดคือใช้ strong duality: $P=D$ คือค่าสูงสุดของขอบล่าง $X^{\mathsf T}u(t)$ บนเส้นราคา ขอบล่างเป็นเส้นตรงของ $t$ ค่าสูงสุดจึงอยู่ที่ปลายใดปลายหนึ่ง ปลาย $t=0$ ให้ \$90.50 ปลาย $t=\tfrac{47}{120}$ ให้ $120(\tfrac{67}{120})+90(0)+X_3(\tfrac{47}{120})=67+\tfrac{47}{120}X_3$ ที่ $X_3=60$ สองปลายเท่ากันพอดี เพราะ $67+23.5=90.5$ เมื่อ $X_3$ เกิน 60 ปลายขวาชนะ ราคาชุดที่ดีที่สุดจึงกระโดดไปเป็น $(0.5583, 0, 0.3917)$ และภาระกรณีลงทุก \$1 ทำให้ต้นทุนเพิ่ม \$0.3917

ขั้นที่ 7 — อ่าน $u$ เป็น state price: ราคา ดอกเบี้ย และโอกาสแบบ risk-neutral

บทบาทที่สองของ $u^*$ คือราคาของเงินในแต่ละกรณี $u_i^*$ คือราคาวันนี้ของสัญญาที่จ่าย \$1 ปีหน้าถ้ากรณี $i$ เกิด และจ่าย \$0 ถ้าไม่เกิด ราคาแบบนี้เรียกว่า state price ขั้นนี้ตรวจก่อนว่ามันให้ราคาหุ้นกับพันธบัตรตรงตลาด แล้วอ่านสิ่งที่มันบอกเพิ่ม คือดอกเบี้ย และตัวเลขที่หน้าตาเหมือนโอกาส

\[ \begin{aligned} &\text{stock}:\ 130(\tfrac16)+100(\tfrac{47}{60})+0=100,\\ &\text{bond}:\ 100(\tfrac16+\tfrac{47}{60}+0)=95,\\ &u_1+u_2+u_3=0.95,\\ &r=1/0.95-1\approx5.26\%,\\ &q=u^*/0.95=(0.1754,\ 0.8246,\ 0),\\ &0.95\,[0.1754(130)+0.8246(100)]=100. \end{aligned} \]

ราคาวันนี้ของหุ้นคือผลรวมของ “เงินที่หุ้นจ่ายในแต่ละกรณี คูณราคาของกรณีนั้น” พันธบัตรก็คิดแบบเดียวกัน ทั้งสองตรงตลาด เพราะนี่คือกติกา $S^{\mathsf T}u=p$ ของ dual นั่นเอง dual บังคับแค่ว่าราคาต่อกรณีต้องอธิบายราคาของที่มีขายในตลาดได้

ถ้ารวมราคาของทั้งสามกรณี จะได้ราคาวันนี้ของสัญญาที่จ่าย \$1 ทุกกรณี คือเงิน \$1 ที่ได้แน่นอนปีหน้า ราคานี้คือ 0.95 ส่วนลดนี้มาจากดอกเบี้ย ถ้าดอกเบี้ยหนึ่งปีคือ $r$ เงิน $\tfrac{1}{1+r}$ วันนี้จะโตเป็น \$1 ปีหน้า จึงได้ $\tfrac{1}{1+r}=0.95$ และ $r=\tfrac{1}{0.95}-1\approx5.26\%$

ทำไมพันธบัตรที่คืน \$100 ต้องราคา $\tfrac{100}{1+r}$ พอดี สมมติกู้และให้กู้ได้ที่ดอกเบี้ย $r$ เดียวกัน ให้ $p_2$ คือราคาพันธบัตร พอร์ตแรก: ซื้อพันธบัตร และกู้เงิน $\tfrac{100}{1+r}$ วันนี้ ปีหน้าได้ \$100 จากพันธบัตร เอาไปคืนหนี้ \$100 พอดี เหลือศูนย์ทุกกรณี หลัก no-arbitrage แบบ weak บอกว่าพอร์ตที่จ่ายไม่ติดลบต้องมีราคาไม่ติดลบ ราคาวันนี้ของพอร์ตนี้คือ $p_2-\tfrac{100}{1+r}$ จึงได้ $p_2\ge\tfrac{100}{1+r}$ พอร์ตกลับข้างคือขายพันธบัตรแล้วเอาเงินไปให้กู้ ได้ $p_2\le\tfrac{100}{1+r}$ สองข้างบีบให้เท่ากันพอดี

หาร $u^*$ ด้วย 0.95 ได้ $q$ ซึ่งรวมกันได้ 1 พอดี หน้าตาเหมือนโอกาส จึงเรียกว่า risk-neutral probability เอา $q$ ไปเฉลี่ย payoff ของหุ้นแล้วคิดลดด้วย 0.95 ได้ราคาหุ้น \$100 พอดี แต่ $q$ มาจากราคาล้วน ไม่เคยถามเลยว่าโอกาสที่ตลาดจะขึ้นจริงเท่าไร และ $q_3=0$ ไม่ได้แปลว่าตลาดลงไม่ได้ มันเป็นผลของการเลือกปลาย $t=0$ ราคาชุดอื่นบนเส้นให้ $q_3$ เป็นบวก วิธีอ่านแบบนี้จะกลับมาเต็มรูปใน การตั้งราคาบน binomial tree ซึ่งมีสองกรณีต่อสินทรัพย์สองตัว ราคาต่อกรณีจึงมีชุดเดียว

ขั้นที่ 8 — ราคา call ในตลาดไม่สมบูรณ์: ช่วง ไม่ใช่เลขเดียว

กลับไปที่ call ในโจทย์เปิด ราคาทุกชุดบนเส้นให้ราคาหุ้นกับพันธบัตรตรงตลาดเท่ากัน ตลาดจึงไม่ได้บอกว่าชุดไหนถูก เราจึงคิดราคา call จากทุกชุดบนเส้น ซึ่งจะได้เป็นช่วง แล้วตรวจปลายทั้งสองด้วยพอร์ตที่ซื้อขายได้จริง ให้ $h=(30, 0, 0)$ คือ payoff ของ call ในสามกรณี พอร์ตที่ใช้ตรวจมีสองแบบ แบบ sub คือพอร์ตที่จ่ายไม่เกิน call ในทุกกรณี แบบ sup (superhedge) คือพอร์ตที่จ่ายไม่น้อยกว่า call ในทุกกรณี

\[ \begin{aligned} &h^{\mathsf T}u(t)=30u_1=30(\tfrac16+t),\\ &t=0:\ 30(\tfrac16)=5.00,\\ &t=\tfrac{47}{120}:\ 30(\tfrac16+\tfrac{47}{120})\\ &\quad=30(0.5583)=16.75,\\ &\theta^{\rm sub}=(1,\ -1),\\ &S\theta^{\rm sub}=(130,\ 100,\ 70)-100\\ &\quad=(30,\ 0,\ -30)\le h,\\ &p^{\mathsf T}\theta^{\rm sub}=100-95=5.00,\\ &\theta^{\rm sup}=(0.5,\ -0.35),\\ &S\theta^{\rm sup}=0.5(130,\ 100,\ 70)-35\\ &\quad=(30,\ 15,\ 0)\ge h,\\ &p^{\mathsf T}\theta^{\rm sup}=50-33.25=16.75. \end{aligned} \]

ราคา call จากราคาต่อกรณีคือ $30u_1$ เพราะ call จ่ายเฉพาะกรณีขึ้น ค่านี้เพิ่มขึ้นตาม $t$ และ $t$ อยู่ในช่วง $0\le t\le\tfrac{47}{120}$ จากขั้นที่ 2 ราคา call จึงอยู่ระหว่าง \$5.00 กับ \$16.75 ปลายทั้งสองมีพอร์ตจริงรองรับ พอร์ต sub คือซื้อหุ้น 1 หุ้น และ short พันธบัตร 1 หน่วย พอร์ต sup คือซื้อหุ้น 0.5 หุ้น และ short พันธบัตร 0.35 หน่วย ราคาวันนี้ของสองพอร์ตตรงกับสองปลายพอดี ไม่ใช่ความบังเอิญ ปลายบนคือคำตอบของ LP superhedge ของ call และ strong duality บอกว่ามันต้องเท่ากับราคาสูงสุดบนเส้น

ทำไมราคานอกช่วงจึงเปิดช่องทำเงินฟรี ถ้าใครขาย call ต่ำกว่า \$5.00 เราซื้อ call จากเขาแล้วขายพอร์ต sub ได้เงินวันนี้ ปีหน้าไม่มีทางติดลบ เพราะ call จ่ายไม่น้อยกว่าที่พอร์ต sub ต้องจ่ายคืน ถ้าใครซื้อ call สูงกว่า \$16.75 เราขาย call ให้เขาแล้วซื้อพอร์ต sup ไว้ ซึ่งจ่ายครบทุกกรณี

แม้แต่ที่ปลายพอดีก็ยังมีช่อง ซื้อ call ที่ \$5.00 แล้วขายพอร์ต sub วันนี้ไม่ต้องจ่ายอะไรเลย แต่ปีหน้าได้เงินสุทธิ $h-S\theta^{\rm sub}=(30, 0, 0)-(30, 0, -30)=(0, 0, 30)$ คือได้ \$30 ในกรณีลง ราคาที่ไม่เปิดช่อง arbitrage แบบ strong จึงอยู่ระหว่าง \$5.00 กับ \$16.75 โดยไม่รวมปลาย

ภาระ \$120/\$90/\$50 ก็มีช่วงแบบเดียวกัน คือ $90.5-10t$ ตั้งแต่ \$86.58 (ที่ $t=\tfrac{47}{120}$) ถึง \$90.50 (ที่ $t=0$) ปลายล่างคือราคาของพอร์ตที่เพื่อนเสนอในโจทย์ hedge ซึ่งจ่าย \$120, \$85, \$50 ไม่เกินภาระทุกกรณี

ตัวอย่างที่สอง — dual ของการลด beta ด้วย QQQ และ SPY

ตัวอย่างที่สองมาจากงานประจำวันของโต๊ะ ซึ่งอยู่ในครึ่งหลังของ โจทย์ hedge โต๊ะถือตะกร้าหุ้นมูลค่า \$12 ล้าน ตะกร้านี้ขยับแรงกว่าตลาด ตัววัดการขยับตามตลาดคือ beta ถ้าตลาดขยับ 1% ของที่มี beta 1.10 จะขยับราว 1.10% ฝ่ายความเสี่ยงสั่งให้ลด beta ของตะกร้าลงเหลือไม่เกิน 0.20 วิธีลดคือ short กองทุนที่วิ่งตามดัชนี เพราะฝั่ง short ได้กำไรเมื่อตลาดลง จึงหักล้างการขยับของตะกร้า ของที่รู้:

  • QQQ คือกองทุนที่วิ่งตามดัชนี Nasdaq-100 มี beta 1.2 (สมมติ) short \$1 ล้านจึงลด dollar beta (มูลค่าเป็นล้านดอลลาร์คูณ beta) ได้ $1\times1.2=1.2$ ต้นทุนซื้อขาย \$180 ต่อ \$1 ล้าน (สมมติ)
  • SPY มี beta 1.0 พอดี เพราะใช้ SPY เป็นตัวแทน “ตลาด” เอง short \$1 ล้านลด dollar beta ได้ 1.0 ต้นทุน \$90 ต่อ \$1 ล้าน (สมมติ)
  • เพดานการ short ของโต๊ะ: แต่ละตัวไม่เกิน \$6 ล้าน

ให้ $x_Q$ กับ $x_S$ คือขนาดที่ short QQQ กับ SPY หน่วยล้านดอลลาร์ ตะกร้ามี dollar beta $12\times1.10=13.2$ และยอมให้เหลือได้ $12\times0.20=2.4$ จึงต้องลดอย่างน้อย $13.2-2.4=10.8$ ได้ข้อจำกัด $1.2x_Q+x_S\ge10.8$ แผนที่ถูกที่สุดซึ่งหาได้ในหน้านั้นคือ $(x_Q, x_S)=(4, 6)$ ต้นทุน

\[ \begin{aligned} 180(4)+90(6)&=720+540\\ &=\$1{,}260 \end{aligned} \]

สิ่งที่ต่างจากตัวอย่างแรกคือ ตัวแปรห้ามติดลบ ($x_Q, x_S\ge0$ เพราะเป็นขนาดของการ short) ตัวอย่างนี้จึงแสดงอีกครึ่งของกฎการสร้าง dual ก่อนอื่นเขียนทุกข้อจำกัดให้เป็นแบบ “อย่างน้อย” ($\ge$) เหมือนกัน โดยคูณเพดานด้วย $-1$: $x_Q\le6$ กลายเป็น $-x_Q\ge-6$ และ $x_S\le6$ กลายเป็น $-x_S\ge-6$ แล้วตั้งราคาของสามข้อเป็น $y$ (เกณฑ์ beta), $u_Q$ (เพดาน QQQ) และ $u_S$ (เพดาน SPY) ทุกตัวไม่ติดลบ

ขั้นที่ 9 — ราคาต่อข้อจำกัด: dual ของการลด beta

เราอยากได้ขอบล่างของต้นทุน $180x_Q+90x_S$ แบบเดียวกับตัวอย่างแรก จึงทำแบบเดียวกับตอนถ่วงสามกรณี: คูณแต่ละข้อจำกัดด้วยราคาของมัน บวกกัน แล้วจัดกลุ่มตาม $x_Q$ กับ $x_S$ สิ่งที่จะต่างไปคือเงื่อนไขของตัวคูณ เพราะคราวนี้ตัวแปรห้ามติดลบ

\[ \begin{aligned} &y(1.2x_Q+x_S)\ge10.8y,\\ &u_Q(-x_Q)\ge-6u_Q,\\ &u_S(-x_S)\ge-6u_S,\\ &(1.2y-u_Q)x_Q+(y-u_S)x_S\\ &\qquad\ge10.8y-6u_Q-6u_S,\\ &1.2y-u_Q\le180,\qquad y-u_S\le90,\\ &D=\max\ 10.8y-6u_Q-6u_S. \end{aligned} \]

จังหวะสำคัญอยู่ที่ตัวคูณ เพราะ $x_Q\ge0$ ถ้าตัวคูณของ $x_Q$ ไม่เกิน 180 ก็ได้ $180x_Q\ge(1.2y-u_Q)x_Q$ ทันที ไม่ต้องเท่ากันพอดีแบบตอนที่ $\theta$ ติดลบได้ ตัวคูณของ $x_S$ ที่ไม่เกิน 90 ก็ให้ผลแบบเดียวกัน รวมกันได้ว่าต้นทุน $180x_Q+90x_S$ ไม่ต่ำกว่าด้านซ้าย และด้านซ้ายไม่ต่ำกว่า $10.8y-6u_Q-6u_S$ ข้อนี้จริงสำหรับราคาทุกชุดที่ผ่านสองเงื่อนไข dual จึงคือหาค่าสูงสุดของ $10.8y-6u_Q-6u_S$

อ่านเงื่อนไขเป็นเงิน: short QQQ \$1 ล้านลด beta ได้ 1.2 หน่วย ซึ่งมีค่า $1.2y$ แต่ก็กินเพดาน QQQ ไป \$1 ล้าน ซึ่งมีค่า $u_Q$ มูลค่าสุทธิ $1.2y-u_Q$ ต้องไม่เกินต้นทุนจริง \$180 ถ้าเกิน แปลว่าเราตั้งราคา beta สูงเกินจริง เพราะซื้อ beta จากตลาดได้ถูกกว่าราคาที่ตั้งไว้

รวมสองตัวอย่างได้กฎสี่ข้อของการสร้าง dual ของโจทย์หาค่าต่ำสุด:

ขั้นที่ 10 — ลองราคาสามชุด: ขอบล่างขยับ แต่ไม่เคยเกินต้นทุนจริง

ขั้นนี้ลองใช้ dual ที่เพิ่งได้กับตัวเลขจริง เพื่อดูว่าราคาแบบไหนให้ขอบล่างที่ดี และราคาที่ผิดกติกาทำให้พังอย่างไร

โจทย์ให้อะไรมาบ้าง: แผนที่ถูกที่สุด $(4, 6)$ ราคา \$1,260 และราคา $(y, u_Q, u_S)$ สามชุดที่จะลอง แต่ละชุดต้องตรวจสองเงื่อนไข $1.2y-u_Q\le180$ กับ $y-u_S\le90$ ก่อน แล้วจึงคิดขอบล่าง $D=10.8y-6u_Q-6u_S$ นอกจากนี้ให้ $s_B, s_Q, s_S$ คือส่วนเหลือ (slack) ของเกณฑ์ beta เพดาน QQQ และเพดาน SPY ที่แผน $(4, 6)$ คือข้อจำกัดนั้นยังเหลือที่ว่างเท่าไร (วิธีอ่านส่วนเหลืออยู่ใน รูปมาตรฐาน)

\[ \begin{aligned} &s_B=1.2(4)+6-10.8=0,\\ &s_Q=6-4=2,\quad s_S=6-6=0,\\ &(90,\ 0,\ 0):\ 108\le180,\ 90\le90,\\ &\quad D=10.8(90)=972,\\ &(150,\ 0,\ 60):\ 180\le180,\ 90\le90,\\ &\quad D=1{,}620-360=1{,}260,\\ &(160,\ 0,\ 70):\ 192\gt180,\\ &\quad 10.8(160)-6(70)=1{,}308,\\ &150(0)+0(2)+60(0)=0. \end{aligned} \]

คำตอบ: ชุดแรกผ่านกติกา แต่บอกได้แค่ว่า “ไม่มีแผนไหนถูกกว่า \$972” ซึ่งจริงแต่ไม่แน่นพอ ชุดที่สองดันขอบล่างขึ้นถึง $10.8(150)-6(60)=\$1{,}260$ เท่ากับต้นทุนของ $(4, 6)$ พอดี ชุดนี้จึงเป็นคำตอบของ dual และพิสูจน์ว่า $(4, 6)$ ถูกที่สุด ชุดที่สามผิดกติกา เพราะ $1.2(160)=192$ เกิน 180 ถ้าฝืนใช้จะได้ “ขอบล่าง” \$1,308 ซึ่งสูงกว่าต้นทุนของแผนที่ทำได้จริง \$1,260 ตัวเลขนี้จึงเชื่อไม่ได้ และแสดงว่ากติกาของ dual จำเป็นจริง

ตรวจเองใน 10 วินาที: แถวสุดท้ายของสูตรคือ complementary slackness ส่วนเหลือคูณราคาเป็นศูนย์ทุกข้อ เกณฑ์ beta และเพดาน SPY ชนพอดี (ส่วนเหลือศูนย์) จึงมีราคาเป็นบวกได้ คือ 150 และ 60 ส่วนเพดาน QQQ ยังเหลือ \$2 ล้าน จึงมีราคาศูนย์ 150 กับ 60 คือน้ำหนักสองตัวที่ใช้พิสูจน์ \$1,260 ในโจทย์ hedge ตั้งแต่แรก

ขั้นที่ 11 — ราคาเงาของเพดาน SPY และช่วงที่ใช้ได้

ฝ่ายความเสี่ยงอยากรู้ว่า ถ้าไปขอขยายเพดาน SPY จะคุ้มไหม ราคา $u_S^*=60$ ตอบได้ว่า เพดาน SPY เพิ่ม \$1 ล้าน ต้นทุนที่ดีที่สุดลด \$60 แต่ต้องตรวจก่อนว่าตัวเลขนี้ใช้ได้ถึงไหน วิธีตรวจคือเขียนต้นทุนที่ดีที่สุดเป็นฟังก์ชันของเพดาน SPY ซึ่งเรียกว่า $U_S$ (ล้านดอลลาร์) แผนที่ดีที่สุดยังเป็นแบบเดิม: SPY ถูกกว่าต่อ beta จึงใช้เต็มเพดาน $x_S=U_S$ แล้วให้ QQQ เติม beta ที่ขาด $x_Q=(10.8-U_S)/1.2$ ซึ่ง QQQ คิดเป็น $180/1.2=\$150$ ต่อ beta หนึ่งหน่วย

\[ \begin{aligned} &C(U_S)=90U_S+150(10.8-U_S)\\ &\quad=1{,}620-60U_S,\\ &0\le(10.8-U_S)/1.2\le6,\\ &3.6\le U_S\le10.8,\\ &C(7)=1{,}620-60(7)=1{,}200,\\ &C(B)=90(6)+150(B-6)\\ &\quad=540+150(B-6),\\ &6\le B\le13.2,\\ &B=12(1.10-0.25)=10.2,\\ &C(10.2)=540+150(4.2)=1{,}170. \end{aligned} \]

สูตร $C(U_S)=1{,}620-60U_S$ บอกว่าเพดาน SPY เพิ่มทุก \$1 ล้าน ต้นทุนลด \$60 ตรงกับ $u_S^*$ พอดี เหตุผลทางเงินคือ SPY \$1 ล้านที่เพิ่มเข้ามาลด beta ได้ 1 หน่วยในราคา \$90 และเข้าไปแทน QQQ ที่ลด beta หน่วยเดียวกันในราคา \$150 จึงประหยัด $150-90=\$60$ ตัวอย่าง: ขยายเพดานจาก \$6 ล้านเป็น \$7 ล้าน ต้นทุนลดจาก \$1,260 เหลือ \$1,200

แต่สูตรนี้ใช้ได้เฉพาะเมื่อขนาด QQQ อยู่ระหว่าง 0 ถึง 6 แก้อสมการนี้ได้ว่าเพดาน SPY ต้องอยู่ระหว่าง \$3.6 ล้าน ถึง \$10.8 ล้าน ถ้าเพดานต่ำกว่า \$3.6 ล้าน QQQ เต็มเพดานแล้วก็ยังลด beta ไม่พอ ไม่มีแผนที่ผ่านกฎ ถ้าเพดานสูงกว่า \$10.8 ล้าน SPY ตัวเดียวก็ลด beta ได้ครบ เพดานไม่ชนอีก ราคาเงาจึงกลายเป็นศูนย์

$y^*=150$ อ่านแบบเดียวกัน ให้ $B$ คือ dollar beta ที่ต้องลด (เดิม 10.8) ถ้า $B$ เพิ่ม 1 หน่วย ต้นทุนเพิ่ม \$150 ตัวอย่าง: ถ้าฝ่ายความเสี่ยงยอมให้ beta เหลือ 0.25 แทน 0.20 เกณฑ์จะลดเป็น 10.2 ลดลง $10.8-10.2=0.6$ หน่วย ประหยัด $150\times0.6=\$90$ ต้นทุนเหลือ \$1,170 ตรวจตรง ๆ ได้ด้วย: SPY 6 กับ QQQ $4.2/1.2=3.5$ ต้นทุน $90(6)+180(3.5)=540+630=\$1{,}170$ สูตรนี้ใช้ได้ตั้งแต่เกณฑ์ 6 (QQQ เป็นศูนย์) ถึง 13.2 (QQQ เต็มเพดาน) ส่วน $u_Q^*=0$ เพราะ QQQ ยังเหลือเพดาน \$2 ล้าน ผ่อนเพดาน QQQ ไปก็ไม่ได้อะไร

ความผิดที่ทำให้เสียเงินจริง

เรียกปลายของช่วงว่า “ราคาที่ถูกต้อง”: ถ้าขาย call ที่ \$5.00 โต๊ะต้องใช้ \$16.75 ซื้อพอร์ต sup ที่จ่ายครบทุกกรณี เงินขาด $16.75-5.00=\$11.75$ ถ้าไม่ซื้อพอร์ตนั้น ก็ต้องยอมรับความเสี่ยงในบางกรณีเอง ในตลาดไม่สมบูรณ์ หลัก no-arbitrage อย่างเดียวให้ได้แค่ช่วง ราคาเลขเดียวต้องมาจากการตัดสินใจเพิ่ม เช่นเลือกแบบจำลอง หรือเลือกว่ายอมรับความเสี่ยงได้แค่ไหน

ใช้ราคาเงานอกช่วง: ขยายเพดาน SPY จาก \$6 ล้านเป็น \$12 ล้าน แล้วคาดว่าประหยัด $60\times6=\$360$ ต้นทุนเหลือ $1{,}260-360=\$900$ ของจริงเหลือ $90\times10.8=\$972$ เพราะ SPY \$10.8 ล้านตัวเดียวก็ลด beta ได้ครบ เพดานส่วนที่เกิน \$10.8 ล้านจึงไม่ได้ใช้ ประมาณผิดไป $972-900=\$72$

เทียบราคาเงาข้ามหน่วย: $y^*=150$ มีหน่วยเป็นดอลลาร์ต่อ dollar beta หนึ่งหน่วย ส่วน $u_S^*=60$ มีหน่วยเป็นดอลลาร์ต่อเพดาน \$1 ล้าน ตัวเลขที่ใหญ่กว่าไม่ได้แปลว่าข้อนั้นสำคัญกว่า สิ่งที่ต้องเทียบคือราคาเงาของแต่ละข้อ กับต้นทุนของการได้ข้อนั้นเพิ่มหนึ่งหน่วย

เชื่อเครื่องหมายของ solver: โปรแกรมแก้ LP (solver) ส่วนใหญ่รายงานราคาของแต่ละข้อจำกัดมาด้วย ในชื่อ dual values หรือ marginals แต่เครื่องหมายขึ้นกับว่ามันตั้งโจทย์เป็น min หรือ max และเขียนข้อจำกัดเป็น $\le$ หรือ $\ge$ วิธีกันพลาดคือแก้ใหม่หลังขยับข้อจำกัดหนึ่งหน่วย แบบที่ทำกับภาระ \$121 ในขั้นที่ 6 แล้วดูว่าต้นทุนขยับไปทางเดียวกับที่ราคาบอก

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะตั้งราคา (pricing) ใช้คู่ primal กับ dual ตั้งกรอบราคาของสินค้าที่ hedge ให้พอดีไม่ได้ ต้นทุน superhedge คือราคาต่ำสุดที่โต๊ะขายได้โดยไม่ต้องรับความเสี่ยงเลย ต้นทุน sub-hedge คือราคาสูงสุดที่โต๊ะซื้อได้โดยไม่ต้องรับความเสี่ยงเลย ราคาที่อยู่ระหว่างสองค่านี้ต้องใช้แบบจำลอง หรือการตัดสินใจเรื่องความเสี่ยงช่วยเลือก

ฝ่ายบริหารความเสี่ยงใช้ shadow price ตัดสินว่าควรขอขยายเพดานข้อไหน ถ้าการขยายเพดาน SPY \$1 ล้านมีต้นทุนจริงต่ำกว่า \$60 (เช่นค่าสภาพคล่อง หรือเงินทุนที่ต้องกันไว้) ก็คุ้ม ถ้าแพงกว่าก็ไม่คุ้ม

ความเท่ากันของค่าที่ดีที่สุดของ primal กับ dual ใช้ตรวจทุกครั้งที่แก้แบบจำลอง ถ้าสองตัวเลขไม่เท่ากัน แปลว่าเครื่องหมายของข้อจำกัด หน่วย หรือคำตอบผิดที่ใดที่หนึ่ง

ข้อจำกัดของวิธีนี้: แบบจำลองนี้มีแค่สามกรณีที่รู้ payoff แน่นอน ช่วงราคาจึงขึ้นกับว่าเลือกกรณีอย่างไร และเมื่อคำตอบของ primal มีข้อจำกัดที่ชนพอดีมากเกินจำเป็น ราคาเงาอาจมีหลายชุด ตัวที่ solver รายงานเป็นแค่ชุดหนึ่ง ต้องตรวจด้วยการแก้ใหม่ทั้งทางเพิ่มและทางลด

โจทย์ตรวจความเข้าใจ

1. ลูกค้าอีกรายขอซื้อ put strike \$100 อายุหนึ่งปีบนหุ้นตัวเดียวกัน put คือสิทธิ์ขายหุ้นปีหน้าที่ราคา strike ถ้าหุ้นลงเป็น \$70 ผู้ถือขายได้ที่ \$100 จึงได้ $100-70=\$30$ ในกรณีอื่นสิทธิ์นี้ไม่มีค่า put จึงจ่าย \$0, \$0, \$30 ในกรณีขึ้น ทรงตัว และลง ราคา put ที่ไม่เปิดช่อง arbitrage อยู่ในช่วงไหน และพอร์ต superhedge ที่ถูกที่สุดคืออะไร?

เฉลย

ราคา put จากราคาต่อกรณีคือ $30u_3=30t$ เพราะ put จ่ายเฉพาะกรณีลง ราคาที่ให้ put แพงที่สุดคือปลาย $t=\tfrac{47}{120}$ ราคาชุดนั้นเป็นบวกในกรณีขึ้นกับกรณีลง complementary slackness จึงบอกว่าพอร์ต superhedge ต้องจ่ายพอดีในสองกรณีนั้น ได้สองสมการ ลบกันแล้วหา $\theta$ ได้:

\[ \begin{aligned} &0\lt30t\lt30(\tfrac{47}{120})=11.75,\\ &130\theta_1+100\theta_2=0,\\ &70\theta_1+100\theta_2=30,\\ &60\theta_1=-30,\quad\theta=(-0.5,\ 0.65),\\ &S\theta=-0.5(130,\ 100,\ 70)+65\\ &\quad=(0,\ 15,\ 30)\ge(0,\ 0,\ 30),\\ &p^{\mathsf T}\theta=-50+0.65(95)=11.75. \end{aligned} \]

ราคา put จึงอยู่ระหว่าง \$0 กับ \$11.75 ไม่รวมปลาย พอร์ต superhedge คือ short หุ้น 0.5 หุ้น และซื้อพันธบัตร 0.65 หน่วย ราคา \$11.75 สังเกตว่าราคา call ลบราคา put คือ $30(\tfrac16+t)-30t=5$ ทุก $t$ ซึ่งเท่ากับหุ้น \$100 ลบพันธบัตร \$95 เหตุผลคือ payoff ของ call ลบ put คือ $(30, 0, -30)$ ซึ่งเท่ากับ payoff ของหุ้นหนึ่งหุ้นลบพันธบัตรหนึ่งหน่วยพอดี

2. คราวนี้กลับข้าง: มีคนเสนอขายสิทธิ์รับเงินให้โต๊ะ ปีหน้าโต๊ะจะได้รับ \$120, \$90 หรือ \$50 ตามกรณี โต๊ะต้องจ่ายค่าสิทธิ์วันนี้ โต๊ะควรจ่ายได้มากสุดเท่าไร โดยยังล็อกได้ว่าไม่ขาดทุนในกรณีไหนเลย?

เฉลย

ใช้ปลายล่างของช่วงราคาภาระจากขั้นที่ 8 ปลายนั้นคือราคาของพอร์ต $\theta=(\tfrac76, -\tfrac{19}{60})$ ที่เพื่อนเสนอในโจทย์ hedge โต๊ะ short พอร์ตนี้ คือ short หุ้น $\tfrac76$ หุ้น และซื้อพันธบัตร $\tfrac{19}{60}$ หน่วย ได้เงินวันนี้มาจ่ายค่าสิทธิ์ ปีหน้าต้องคืนเท่ากับที่พอร์ตนี้จ่าย:

\[ \begin{aligned} &90.5-10(\tfrac{47}{120})=90.5-3.9167=86.58,\\ &\theta=(\tfrac76,\ -\tfrac{19}{60}),\\ &p^{\mathsf T}\theta=116.67-30.08=86.58,\\ &S\theta=(120,\ 85,\ 50)\le(120,\ 90,\ 50). \end{aligned} \]

โต๊ะจ่ายได้มากสุด \$86.58 เงินที่ได้จากการ short พอร์ตพอดีค่าสิทธิ์ ปีหน้าเงินที่ต้องคืน \$120, \$85, \$50 ไม่เกินเงินที่ได้รับในทุกกรณี และเหลือ \$5 ในกรณีทรงตัว ถ้าจ่ายถูกกว่านี้ โต๊ะได้กำไรแน่นอน ถ้าจ่ายแพงกว่านี้ โต๊ะต้องรับความเสี่ยง

3. ในโลกจริง ดอกเบี้ยเงินกู้มักสูงกว่าดอกเบี้ยที่ได้จากการให้กู้ สมมติโต๊ะกู้เงินได้ที่ดอกเบี้ย 6% ต่อปี แต่ให้กู้ได้แค่ 5% ต่อปี พันธบัตรที่คืน \$100 ในหนึ่งปีต้องมีราคาเท่าไร จึงไม่เปิดช่อง arbitrage?

เฉลย

ใช้สองพอร์ตแบบเดียวกับตอนอ่านดอกเบี้ยจากราคาต่อกรณีในขั้นที่ 7 ให้ $p_2$ คือราคาพันธบัตร พอร์ตแรกซื้อพันธบัตรแล้วกู้เงิน $100/1.06=\$94.34$ ปีหน้าได้ \$100 พอดีคืนหนี้ เหลือศูนย์ทุกกรณี พอร์ตนี้จึงต้องมีราคาไม่ติดลบ: $p_2-94.34\ge0$ ได้ $p_2\ge\$94.34$ พอร์ตที่สองขายพันธบัตรแล้วเอาเงิน $100/1.05=\$95.24$ ไปให้กู้ ได้ $95.24-p_2\ge0$ คือ $p_2\le\$95.24$ ราคาจึงเป็นช่วง \$94.34 ถึง \$95.24 ไม่ใช่ค่าเดียว ส่วนต่างระหว่างดอกเบี้ยกู้กับดอกเบี้ยให้กู้ทำให้ตรึงราคาได้ไม่ครบ เหมือนตลาดที่มีสินทรัพย์ไม่พอ ช่องว่างของราคาจึงเปิดออก

// Tiny exact LP: minimise c.x subject to rows[k].x >= rhs[k]; x[j] >= 0 unless j is listed in free.
// It lists every basic solution of the standard form, so it only suits a handful of variables.
function solveSquare(M, v) {
  const n = M.length, T = M.map((r, i) => [...r, v[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (Math.abs(T[r][c]) > Math.abs(T[p][c])) p = r;
    if (Math.abs(T[p][c]) < 1e-12) return null;
    [T[c], T[p]] = [T[p], T[c]];
    for (let r = 0; r < n; r++) if (r !== c) {
      const f = T[r][c] / T[c][c];
      for (let k = c; k <= n; k++) T[r][k] -= f * T[c][k];
    }
  }
  return T.map((r, i) => r[n] / r[i]);
}
function choose(n, k) {
  const out = [], pick = [];
  (function walk(s) {
    if (pick.length === k) { out.push([...pick]); return; }
    for (let i = s; i < n; i++) { pick.push(i); walk(i + 1); pick.pop(); }
  })(0);
  return out;
}
function lp(c, rows, rhs, free = []) {
  const n = c.length, m = rows.length;
  if (!c.every(Number.isFinite) || !m || !rows.every(r => Array.isArray(r) && r.length === n && r.every(Number.isFinite))) {
    throw new TypeError('Need a finite cost and rows of matching length');
  }
  if (!Array.isArray(rhs) || rhs.length !== m || !rhs.every(Number.isFinite)) throw new TypeError('Need one finite limit per row');
  // Standard form columns: x+ for every variable, x- for free ones, then one surplus per row.
  const cols = [];
  for (let j = 0; j < n; j++) {
    cols.push({j, sign: 1});
    if (free.includes(j)) cols.push({j, sign: -1});
  }
  for (let k = 0; k < m; k++) cols.push({row: k});
  const A = rows.map((r, k) => cols.map(col => (col.row === undefined ? col.sign * r[col.j] : (col.row === k ? -1 : 0))));
  const cost = cols.map(col => (col.row === undefined ? col.sign * c[col.j] : 0));
  const corners = [];
  for (const basis of choose(cols.length, m)) {
    const part = solveSquare(A.map(r => basis.map(i => r[i])), rhs);
    if (!part || part.some(v => v < -1e-9)) continue;
    const z = new Array(cols.length).fill(0);
    basis.forEach((i, k) => { z[i] = part[k]; });
    corners.push({basis, z, value: z.reduce((s, v, i) => s + v * cost[i], 0)});
  }
  if (!corners.length) throw new RangeError('No feasible corner: the rules clash');
  const low = Math.min(...corners.map(k => k.value));
  // Proof of optimality: row prices y with B^T y = c_B and no column cheaper than its price (reduced cost >= 0).
  let proof = null;
  for (const k of corners.filter(k => k.value <= low + 1e-9)) {
    const y = solveSquare(k.basis.map(i => A.map(r => r[i])), k.basis.map(i => cost[i]));
    if (y && cols.every((_, i) => cost[i] - A.reduce((s, r, q) => s + y[q] * r[i], 0) >= -1e-9)) { proof = {...k, y}; break; }
  }
  if (!proof) throw new RangeError('No corner proves itself cheapest: the cost has no floor');
  const x = new Array(n).fill(0);
  cols.forEach((col, i) => { if (col.row === undefined) x[col.j] += col.sign * proof.z[i]; });
  const surplus = rows.map((r, k) => r.reduce((s, a, j) => s + a * x[j], 0) - rhs[k]);
  return {x, value: proof.value, surplus, rowPrices: proof.y};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • dual ของโจทย์ superhedge คือหาค่าสูงสุดของ $X^{\mathsf T}u$ ภายใต้ $S^{\mathsf T}u=p$ และ $u\ge0$ ในคำพูด: หาราคาต่อกรณีที่ให้ราคาตลาดถูก และให้ภาระดูแพงที่สุด ตัวแปรที่ติดลบได้ทำให้แถวของ dual เป็นสมการ ตัวแปรที่ห้ามติดลบทำให้เป็นข้อ “ไม่เกิน”
  • ช่องว่าง $p^{\mathsf T}\theta-X^{\mathsf T}u=u^{\mathsf T}e\ge0$ คือ weak duality ค่าที่ดีที่สุดของสองฝั่งเท่ากัน (\$90.50 ในตัวอย่างแรก \$1,260 ในตัวอย่างที่สอง) คือ strong duality
  • ที่คำตอบ ส่วนเหลือคูณราคาเป็นศูนย์ทุกข้อ: กรณีลงเหลือเงิน \$10 จึงมีราคาศูนย์ เพดาน QQQ เหลือ \$2 ล้าน จึงมีราคาศูนย์
  • $u^*=(\tfrac16, \tfrac{47}{60}, 0)$ อ่านได้สองแบบ แบบ shadow price: ภาระกรณีทรงตัวเพิ่ม \$1 ต้นทุนเพิ่ม \$0.7833 แบบ state price: ให้ราคาหุ้น \$100 พันธบัตร \$95 และดอกเบี้ย 5.26%
  • ตลาดไม่สมบูรณ์ให้ราคาเป็นช่วง: call อยู่ระหว่าง \$5.00 กับ \$16.75 และราคาเงาก็ใช้ได้เป็นช่วง: เพดาน SPY มีค่า \$60 ต่อ \$1 ล้าน เฉพาะเมื่อเพดานอยู่ระหว่าง \$3.6 ล้าน ถึง \$10.8 ล้าน
