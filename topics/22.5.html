22.5 What 2007–2008 Actually Broke

วิกฤตปี 2007–2008 ไม่ได้เกิดจากสูตรผิดสูตรเดียว ทุกขั้นของการปล่อยกู้ ขายต่อ และห่อซ้ำ ผูกกับราคาบ้านทั้งประเทศตัวเดียวกัน พอราคาบ้านลด ทุกขั้นจึงพังพร้อมกัน

ก่อนวิกฤตปี 2007–2008 ธนาคารใหญ่หลายแห่งถือตราสารที่ได้อันดับเครดิต AAA ไว้มาก AAA คืออันดับสูงสุดที่บริษัทจัดอันดับให้ได้ แปลว่าแทบไม่มีทางเสียเงิน แต่ตราสารเหล่านี้ทำมาจากสินเชื่อบ้านของผู้กู้เครดิตอ่อนในสหรัฐฯ เรียกว่าสินเชื่อ subprime พอราคาบ้านลด ของที่ได้ AAA ก็ขาดทุนหนัก หน้านี้ใช้ตัวอย่างสมมติตัวอย่างเดียวเพื่อดูว่ามันเสียได้อย่างไร

ตราสารในตัวอย่างถูกสร้างเป็นสองรอบ:

  • รอบแรก: รวมสินเชื่อบ้านหลายพันสัญญาเป็นกองเดียว เรียกว่า pool แล้วแบ่งการรับขาดทุนของ pool เป็นชั้น (tranche) ชั้นล่างรับขาดทุนก่อน ชั้นบนรับทีหลัง ชั้นกลางที่เรียกว่า mezzanine 3%–7% ไม่เสียอะไรเลยถ้า pool ขาดทุนไม่เกิน 3% ของหนี้ทั้งกอง และเสียหมดเมื่อ pool ขาดทุนถึง 7% ชั้นนี้จึงหนา $7\%-3\%=4\%$ ของ pool
  • รอบสอง: นำชั้น mezzanine ของ 100 pool มารวมเป็นกองใหม่ แล้วแบ่งชั้นอีกครั้ง ตราสารที่ได้เรียกว่า CDO² (CDO ที่ทำจากชั้นของ CDO อื่น) ชั้นบนสุดของกองใหม่เริ่มเสียก็ต่อเมื่อชั้น mezzanine ทั้ง 100 ตัวขาดทุนเฉลี่ยเกิน 30% ของความหนา ชั้นบนสุดนี้ได้ AAA และเป็นของที่ธนาคารถือ

ของที่รู้ของแต่ละ pool (ตัวเลขสมมติ):

  • โอกาสผิดนัดตลอดอายุสินเชื่อ $\mathrm{PD}=4\%$ ผิดนัดคือผู้กู้หยุดผ่อนก่อนหนี้หมด
  • เมื่อผิดนัด ผู้ให้กู้เสีย $\mathrm{LGD}=40\%$ ของหนี้ ส่วนที่เหลือได้คืนจากการยึดบ้านไปขาย

ทีมที่ออกตราสารคำนวณว่าชั้น mezzanine แต่ละตัวมีโอกาสเริ่มเสียราว 11% และเฉลี่ยแล้วเสียราว 3% ของความหนา (หน้านี้จะคำนวณสองตัวเลขนี้ให้ดูทีละขั้น) แล้วสรุปว่า “พอเฉลี่ย 100 ตัว ขาดทุนเฉลี่ยจะนิ่งอยู่แถว 3% ชั้นบนสุดที่เริ่มเสียที่ 30% จึงไม่มีทางเสีย”

ถ้าทุก pool ขึ้นกับราคาบ้านทั้งประเทศตัวเดียวกัน โอกาสที่ชั้นบนสุดเริ่มเสียคือเท่าไร?

ลองตอบก่อนเปิดเฉลย

ราว 3.79% ไม่ใช่ศูนย์ ทีมคำนวณถูกเฉพาะกรณีที่ 100 pool ไม่เกี่ยวกันเลย กรณีนั้นขาดทุนเฉลี่ยของ 100 ชั้นนิ่งอยู่ใกล้ 3.02% จริง และโอกาสที่มันแตะ 30% ต่ำกว่า $10^{-33}$

แต่ถ้าราคาบ้านทั้งประเทศขับทุก pool ชั้น mezzanine ทั้ง 100 ตัวจะเสียเท่ากันในปีเดียวกัน การเฉลี่ย 100 ตัวจึงไม่ช่วยอะไร ชั้นบนสุดเสียทันทีที่ชั้น mezzanine ตัวหนึ่งเสียเกิน 30% ของความหนา 4% คือเมื่อ pool ขาดทุนเกิน

\[3\%+0.3\times4\%=4.2\%\]

หน้านี้จะคำนวณให้ดูว่าเหตุการณ์นี้มีโอกาส 3.79% ส่วนโอกาสที่ชั้น mezzanine เองเริ่มเสียคือ 11.17% เทียบกันได้ $3.79/11.17=0.34$ ชั้น “AAA” นี้จึงเสี่ยงราวหนึ่งในสามของวัตถุดิบที่มันทำมา

ภาพรวมก่อนลงสูตร

สินเชื่อบ้านหนึ่งสัญญาต้องผ่านหลายมือกว่าจะกลายเป็นชั้น AAA ในมือธนาคาร สี่หน้าที่ผ่านมาสร้างแต่ละชิ้นไว้แล้ว: ค่างวดและหนี้ของสินเชื่อบ้าน การคืนก่อนกำหนดผ่านการกู้ใหม่ กติกาแบ่งเงินเป็นชั้น และการแบ่งขาดทุนที่ขึ้นกับการผิดนัดพร้อมกัน หน้านี้ต่อชิ้นเหล่านั้นเป็นโซ่เส้นเดียว แล้วไล่ดูด้วยตัวเลขว่าโซ่ขาดตรงไหน ทีละข้อต่อ

โซ่เริ่มที่ผู้กู้ subprime คือผู้กู้ที่ประวัติเครดิตอ่อน หลายคนได้สินเชื่อที่ดอกเบี้ยต่ำแค่ช่วงแรก อัตราช่วงแรกนี้เรียกว่าอัตราโปรโมชันหรือ teaser rate พออัตราโปรโมชันหมด ค่างวดจะขึ้น แผนของผู้กู้คือกู้ก้อนใหม่มาปิดก้อนเดิมก่อนถึงวันนั้น แผนนี้ใช้ได้ตราบที่ราคาบ้านยังขึ้น

ผู้ปล่อยกู้ไม่ได้เก็บสินเชื่อไว้เอง แต่ขายต่อให้คนที่รวมสินเชื่อเป็น pool แล้วแบ่งชั้น ชั้นกลางของหลาย pool ถูกรวมแล้วแบ่งชั้นซ้ำเป็น CDO² ชั้นบนสุดของมันได้ AAA และคนซื้อมักใช้เงินกู้ระยะสั้นมาซื้อ

ทุกข้อต่อคำนวณถูกภายใต้สมมติฐานของตัวเอง สิ่งที่พังคือสมมติฐานว่าข้อต่อเหล่านี้ไม่เกี่ยวกัน ความจริงคือทุกข้อต่อผูกกับราคาบ้านทั้งประเทศตัวเดียวกัน พอราคาบ้านลด ทุกข้อจึงพังพร้อมกัน รูปด้านล่างคือโซ่ทั้งเส้น และบอกว่าใครถือความเสี่ยงส่วนไหน

หน้านี้เดินโซ่ตามลำดับนี้:

  • อัตราโปรโมชันหมด ค่างวดกระโดด
  • ราคาบ้านลดจนหนี้มากกว่าบ้าน ผู้กู้จึงกู้ใหม่ไม่ได้
  • โอกาสผิดนัดกับขาดทุนต่อหลังขึ้นพร้อมกัน ขาดทุนเฉลี่ยจึงสูงกว่าการคูณค่าเฉลี่ย
  • ขาดทุนของ pool และของชั้น mezzanine เขียนเป็นฟังก์ชันของราคาบ้าน
  • CDO² จาก 100 pool ปลอดภัยแค่ไหน ขึ้นกับว่า pool เกี่ยวกันแค่ไหน
  • เงินกู้ระยะสั้นเปลี่ยนขาดทุนบนกระดาษเป็นการบังคับขาย
  • การขายพร้อมกันกดราคา แล้วราคาที่ลดก็บังคับให้ขายอีก
ศัพท์ที่ใช้ในหัวข้อนี้
Pool, tranche และ mezzanine
Pool คือกองสินเชื่อหลายพันสัญญาที่ถูกรวมกัน เงินผ่อนของทุกสัญญาไหลเข้ากองเดียว tranche หรือชั้น คือส่วนแบ่งของกองที่รับขาดทุนเป็นลำดับ ชั้นล่างเสียก่อน ชั้นบนเสียทีหลัง mezzanine คือชั้นกลาง เช่นชั้น 3%–7% ที่เริ่มเสียเมื่อกองขาดทุนเกิน 3% และเสียหมดที่ 7%
อันดับเครดิต AAA
เกรดที่บริษัทจัดอันดับให้ตราสารหนี้ AAA คือเกรดสูงสุด แปลว่าโอกาสเสียเงินต่ำมาก ผู้ออกตราสารเป็นคนจ่ายค่าจ้างให้บริษัทจัดอันดับ
Subprime และ teaser rate
Subprime คือสินเชื่อให้ผู้กู้ที่ประวัติเครดิตอ่อน จำนวนมากเป็นสินเชื่ออัตราลอยตัว (adjustable-rate mortgage) ที่ช่วงแรกดอกเบี้ยต่ำ เรียกว่า teaser rate แล้วปรับขึ้นทีหลัง ผู้กู้มักวางแผนกู้ใหม่ก่อนอัตราปรับ
Loan-to-value (LTV) และ negative equity
LTV คือหนี้หารด้วยราคาบ้าน ถ้า LTV เกิน 100% หนี้มากกว่าบ้าน เรียกว่า negative equity ผู้กู้กู้ใหม่ไม่ได้ และขายบ้านแล้วก็ยังปิดหนี้ไม่หมด
PD, LGD และ expected loss
PD คือโอกาสผิดนัด LGD คือสัดส่วนของหนี้ที่เสียเมื่อผิดนัด expected loss คือขาดทุนเฉลี่ย ถ้า PD กับ LGD ขึ้นลงพร้อมกัน ขาดทุนเฉลี่ยต้องคิดจากค่าเฉลี่ยของผลคูณ ไม่ใช่ผลคูณของค่าเฉลี่ย
MBS, ABS CDO และ CDO²
MBS คือตราสารที่จ่ายเงินจากค่างวดของ pool สินเชื่อบ้าน ABS CDO คือ CDO ที่หลักประกันเป็นชั้นของตราสาร securitization อื่น (ตราสารที่ทำจากกองสินเชื่อ) เช่นชั้น mezzanine ของ MBS หลายตัว CDO² คือการแบ่งชั้นซ้ำจากชั้นที่แบ่งมาแล้ว และยังมี CDO³ ต่อจากนั้นอีก
Repo และ haircut
Repo คือการกู้ระยะสั้นโดยวางหลักทรัพย์ค้ำ haircut คือส่วนของมูลค่าหลักประกันที่ผู้ให้กู้ไม่ยอมให้กู้ เช่น haircut 5% ของหลักประกัน \$100 ให้กู้ได้แค่ \$95 ถ้า haircut ขึ้นหรือราคาหลักประกันลด ผู้กู้ต้องหาเงินมาเพิ่มหรือขายของ
Fire sale
การที่หลายรายต้องขายของแบบเดียวกันพร้อมกันอย่างเร่งด่วน จนราคาต่ำกว่ามูลค่า ราคาที่ลดทำให้คนอื่นต้องขายตาม ความเสี่ยงนี้ตลาดสร้างขึ้นเอง (market endogeneity) ไม่ได้มาจากตัวสินทรัพย์

สัญลักษณ์ความหมายหน่วย
$A_1,\ A_2,\ r$ค่างวดก่อนและหลังอัตราปรับ และดอกเบี้ยต่อเดือน (อัตราต่อปีหารด้วย 12)ดอลลาร์ต่อเดือน, สัดส่วน
$e_0,\ d$เงินดาวน์เป็นสัดส่วนของราคาบ้าน และสัดส่วนที่ราคาบ้านลดสัดส่วน
$B_t,\ H_t$หนี้ค้าง และราคาบ้านดอลลาร์

$Y,\ \rho,\ c$ตัวแปรราคาบ้านของ pool หนึ่ง (normal มาตรฐาน ต่ำคือแย่) สัดส่วนของ variance ของผู้กู้แต่ละคนที่มาจาก $Y$ และเกณฑ์ผิดนัด $c=\Phi^{-1}(\mathrm{PD})$ไม่มีหน่วย

ขั้นที่ 1 — อัตราโปรโมชันหมด: ค่างวดกระโดด

ข้อต่อแรกคือตัวสินเชื่อ สินเชื่อ subprime จำนวนมากเป็นแบบ 2/28 คือดอกเบี้ยต่ำคงที่ 2 ปีแรก แล้วเปลี่ยนเป็นอัตราลอยตัวที่สูงกว่าอีก 28 ปี ขั้นนี้ถามว่าพออัตราโปรโมชันหมด ค่างวดต่อเดือนขึ้นเท่าไร

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ):

  • ยอดกู้ $B_0=\$200{,}000$ ผ่อนรายเดือน 30 ปี คือ $30\times12=360$ งวด
  • 24 เดือนแรก ดอกเบี้ย 7% ต่อปี คิดเป็นต่อเดือน $r_1=0.07/12$
  • ตั้งแต่เดือนที่ 25 ดอกเบี้ยปรับเป็น 10% ต่อปี คือ $r_2=0.10/12$ ธนาคารคิดค่างวดใหม่จากหนี้ที่เหลือ $B_{24}$ กับงวดที่เหลือ $360-24=336$ งวด

ค่างวดทั้งสองช่วงมาจากสูตรค่างวด $A=\dfrac{Br}{1-(1+r)^{-n}}$ คือค่างวดคงที่ที่ผ่อน $n$ งวดแล้วหนี้ $B$ หมดพอดี ส่วนหนี้ที่เหลือหลัง 24 งวดคือหนี้ตั้งต้นที่โตด้วยดอกเบี้ย 24 เดือน ลบด้วยค่างวดทุกงวดที่จ่ายไปแล้ว ซึ่งก็โตด้วยดอกเบี้ยเช่นกัน:

\[ \begin{aligned} A_1&=\frac{200{,}000(0.07/12)}{1-(1+0.07/12)^{-360}}\\ &=\frac{1{,}166.67}{0.87679}=1{,}330.60,\\ B_{24}&=B_0(1+r_1)^{24}-A_1\frac{(1+r_1)^{24}-1}{r_1}\\ &=229{,}961.20-34{,}171.31\\ &=195{,}789.89,\\ A_2&=\frac{195{,}789.89(0.10/12)}{1-(1+0.10/12)^{-336}}\\ &=\frac{1{,}631.58}{0.93848}=1{,}738.54. \end{aligned} \]

คำตอบ: ค่างวดขึ้นจาก \$1,330.60 เป็น \$1,738.54 ทั้งที่ผ่อนมาสองปีแล้ว หนี้ก็ลดไปนิดเดียว:

\[ \begin{aligned} \frac{1{,}738.54}{1{,}330.60}-1&=30.7\%,\\ 200{,}000-195{,}789.89&=\$4{,}210.11. \end{aligned} \]

หนี้ลดน้อยเพราะค่างวดช่วงแรกเกือบทั้งหมดเป็นดอกเบี้ย สมมติว่าผู้กู้คนนี้ใช้รายได้ 38% ผ่อนค่างวดเดิม ค่างวดใหม่จะกินรายได้ $0.38\times1{,}738.54/1{,}330.60\approx49.6\%$ เกือบครึ่งของรายได้ ผู้กู้แบบนี้จึงวางแผนกู้ใหม่ก่อนอัตราปรับ แต่ธนาคารใหม่จะให้กู้ก็ต่อเมื่อบ้านยังมีมูลค่าเกินหนี้พอสมควร

ตรวจเองใน 10 วินาที: ถ้าอัตราไม่ปรับ ลองคิดค่างวดใหม่ที่ 7% จากหนี้ที่เหลือกับ 336 งวด:

\[\frac{195{,}789.89(0.07/12)}{1-(1+0.07/12)^{-336}}=1{,}330.60\]

ได้เท่าเดิมพอดี เหตุผลคือหนี้ที่เหลือก็คือมูลค่าวันนี้ของค่างวดที่เหลือทั้งหมด คิดลดด้วยอัตราเดิม แปลงกลับด้วยอัตราเดิมจึงได้ค่างวดเดิม ส่วนที่ขึ้น 30.7% จึงมาจากอัตราดอกเบี้ยทั้งหมด

ขั้นที่ 2 — ราคาบ้านลด: หนี้มากกว่าบ้าน

ขั้นที่แล้วบอกว่าทางหนีของผู้กู้คือกู้ใหม่ ธนาคารใหม่จะให้กู้ก็ต่อเมื่อบ้านมีมูลค่ามากกว่าหนี้ ขั้นนี้จึงถามว่าราคาบ้านต้องลดเท่าไร หนี้จึงเกินมูลค่าบ้าน ตัววัดที่ธนาคารใช้คือ LTV (loan-to-value) คือหนี้หารด้วยราคาบ้าน ตัวแปรที่ใช้มีดังนี้:

  • ราคาบ้านวันซื้อ $H_0$ และหนี้ตั้งต้น $B_0$
  • เงินดาวน์เป็นสัดส่วนของราคาบ้าน $e_0$ ผู้กู้จ่ายเอง $e_0H_0$ และกู้ส่วนที่เหลือ $B_0=(1-e_0)H_0$
  • ราคาบ้านลดลงเป็นสัดส่วน $d$ ราคาใหม่จึงเป็น $H_0(1-d)$

ช่วงปีแรก ๆ หนี้แทบไม่ลด ขั้นที่แล้วผ่อนสองปีตัดเงินต้นได้แค่ $4{,}210.11/200{,}000=2.1\%$ ขั้นนี้จึงประมาณว่าหนี้ยังเท่ายอดกู้ $B_0$ แล้วเขียน LTV ก่อนและหลังราคาลด:

\[ \begin{aligned} \mathrm{LTV}_0&=\frac{B_0}{H_0}=1-e_0,\\ \mathrm{LTV}_t&\approx\frac{B_0}{H_0(1-d)}=\frac{1-e_0}{1-d},\\ \mathrm{LTV}_t-1&=\frac{1-e_0-(1-d)}{1-d}\\ &=\frac{d-e_0}{1-d}. \end{aligned} \]

ตัวอย่าง: ผู้กู้ดาวน์ $e_0=5\%$ และราคาบ้านลด $d=20\%$

\[\mathrm{LTV}_t=\frac{1-0.05}{1-0.20}=\frac{0.95}{0.80}=118.75\%\]

$\mathrm{LTV}_t-1$ บอกว่าหนี้เกินบ้านกี่เปอร์เซ็นต์ ตัวส่วน $1-d$ เป็นบวกเสมอ เครื่องหมายจึงขึ้นกับตัวเศษ $d-e_0$ อย่างเดียว ข้อสรุปคือหนี้เกินบ้านทันทีที่ราคาลดมากกว่าเงินดาวน์ ผู้กู้ที่ดาวน์ 5% จึงติดลบตั้งแต่ราคาลดเกิน 5% และที่ราคาลด 20% หนี้เกินบ้าน 18.75% ภาวะนี้เรียกว่า negative equity

ผู้กู้คนนี้กู้ใหม่ไม่ได้ เพราะไม่มีธนาคารไหนให้กู้เกินมูลค่าบ้าน ขายบ้านก็ได้เงินไม่พอปิดหนี้ ถ้าค่างวดกระโดดด้วย ทางที่เหลือคือหยุดผ่อน

ราคาที่ลดยังทำให้ผู้ให้กู้เสียมากขึ้นเมื่อผู้กู้ผิดนัด ตัวอย่าง (ตัวเลขสมมติ): บ้านราคา \$500,000 ดาวน์ 5% จึงกู้ \$475,000 ผ่อนจนหนี้เหลือ \$465,000 แล้วราคาบ้านลดเหลือ \$400,000 ผู้กู้หยุดผ่อน ผู้ให้กู้ยึดบ้านไปขายได้ \$400,000 แต่เสียค่ายึดและค่าขาย \$20,000 จึงได้สุทธิ \$380,000 ผู้ให้กู้เสียเท่าไร?

\[ \begin{aligned} \mathrm{LTV}&=\frac{465{,}000}{400{,}000}=116.25\%,\\ 465{,}000-380{,}000&=\$85{,}000,\\ \mathrm{LGD}&=\frac{85{,}000}{465{,}000}=18.28\%. \end{aligned} \]

ผู้ให้กู้เสีย \$85,000 หรือ 18.28% ของหนี้ ถ้าราคาบ้านไม่ลด บ้าน \$500,000 หักค่าขายแล้วยังได้เงินเกินหนี้ \$465,000 ขาดทุนจึงเป็นศูนย์ ราคาบ้านที่ลดจึงทำร้ายสองทาง: ผู้กู้ผิดนัดมากขึ้น และแต่ละรายที่ผิดนัดก็ทำให้เสียมากขึ้น

ขั้นที่ 3 — โอกาสผิดนัดกับขาดทุนต่อหลังขึ้นพร้อมกัน

ขั้นที่แล้วเห็นว่าราคาบ้านที่ลดทำสองอย่างพร้อมกัน: ผู้กู้ผิดนัดมากขึ้น (PD สูงขึ้น) และแต่ละรายที่ผิดนัดก็เสียมากขึ้น (LGD สูงขึ้น) ขาดทุนต่อหนี้ \$1 คือ PD คูณ LGD คำถามคือ ถ้ารู้ค่าเฉลี่ยของ PD และค่าเฉลี่ยของ LGD เอามาคูณกันได้ไหม

ขั้นนี้ใช้สองสถานการณ์สมมติ:

สถานการณ์โอกาสเกิดPDLGD
ปกติ90%1%15%
วิกฤต (ราคาบ้านลดแรง)10%15%60%

เขียน $p$ แทน PD และ $g$ แทน LGD ให้สั้น ทั้งสองตัวเปลี่ยนไปตามสถานการณ์ $E[\cdot]$ คือค่าเฉลี่ยที่ถ่วงด้วยโอกาสเกิดของแต่ละสถานการณ์ เครื่องมือที่ต้องใช้คือนิยามของ covariance $\mathrm{Cov}(p,g)=E[pg]-E[p]\,E[g]$ ย้ายข้างแล้วได้:

\[E[pg]=E[p]\,E[g]+\mathrm{Cov}(p,g)\]

สูตรนี้บอกว่าค่าเฉลี่ยของผลคูณเท่ากับผลคูณของค่าเฉลี่ยเฉพาะเมื่อ covariance เป็นศูนย์ ที่นี่ PD กับ LGD ขึ้นพร้อมกันในปีวิกฤต covariance จึงเป็นบวก ลองคิดทั้งสองแบบ:

\[ \begin{aligned} E[p]&=0.9(1\%)+0.1(15\%)=2.4\%,\\ E[g]&=0.9(15\%)+0.1(60\%)=19.5\%,\\ E[p]\,E[g]&=2.4\%\times19.5\%=0.468\%,\\ E[pg]&=0.9(1\%)(15\%)\\ &\quad+0.1(15\%)(60\%)\\ &=0.135\%+0.900\%=1.035\%,\\ \mathrm{Cov}(p,g)&=1.035\%-0.468\%=0.567\%. \end{aligned} \]

สองตัวเลขต่างกันเพราะ PD กับ LGD สูงในปีเดียวกัน ปีวิกฤตมีผู้กู้ผิดนัดมาก และแต่ละรายที่ผิดนัดก็เสียมาก ผลคูณของปีนั้นจึงใหญ่เป็นพิเศษ การคูณค่าเฉลี่ยแยกกันเท่ากับสมมติว่า PD กับ LGD สุ่มแยกกัน PD สูงของปีวิกฤตจึงถูกจับคู่กับ LGD ต่ำของปีปกติเกือบตลอด ผลคูณใหญ่นั้นจึงหายไป

ขาดทุนเฉลี่ยจริงคือ $1.035/0.468=2.21$ เท่าของการคูณค่าเฉลี่ย และส่วนของสถานการณ์วิกฤตคือ $0.900/1.035=87\%$ ของขาดทุนเฉลี่ยทั้งหมด ทั้งที่สถานการณ์นี้เกิดแค่ 10% ของเวลา

ขั้นที่ 4 — ขาดทุนของ pool เป็นฟังก์ชันของราคาบ้าน

ตอนนี้ขยับจากบ้านหลังเดียวเป็นทั้ง pool ซึ่งมีสินเชื่อหลายพันสัญญา เราอยากรู้ว่า pool ขาดทุนเท่าไร และชั้น mezzanine 3%–7% เสียเมื่อไร เครื่องมือคือแบบจำลองปัจจัยเดียว ซึ่งทำงานแบบนี้ (ตัวเลขสมมติ):

  • ผู้กู้แต่ละคนมีคะแนน “สุขภาพการเงิน” ที่สุ่มได้ เป็น normal มาตรฐาน ถ้าคะแนนต่ำกว่าเกณฑ์ $c$ ผู้กู้ผิดนัด เกณฑ์ถูกตั้งให้โอกาสผิดนัดเท่า $\mathrm{PD}=4\%$ คือ $\Phi(c)=4\%$ โดย $\Phi$ คือ CDF ของ normal มาตรฐาน (โอกาสที่ค่าสุ่มต่ำกว่าตัวเลขที่ใส่) ส่วน $\Phi^{-1}$ ทำย้อนกลับ คือรับโอกาสแล้วคืนตัวเลข จึงได้ $c=\Phi^{-1}(4\%)$
  • คะแนนนี้มีสองส่วน ส่วนแรกคือตัวแปรราคาบ้านของ pool $Y$ ซึ่งทุกคนใน pool ใช้ร่วมกัน $Y$ ต่ำคือราคาบ้านแย่ ส่วนที่สองคือโชคของผู้กู้เอง $\varepsilon$ ที่ไม่เกี่ยวกับคนอื่น คะแนนคือ $\sqrt\rho\,Y+\sqrt{1-\rho}\,\varepsilon$
  • $\rho=0.1$ คือสัดส่วนของ variance ของคะแนนที่มาจากราคาบ้าน
  • LGD เท่าเดิมคือ 40%

ถ้ารู้ $Y$ ผู้กู้คนหนึ่งผิดนัดเมื่อ $\varepsilon\lt(c-\sqrt\rho\,Y)/\sqrt{1-\rho}$ ซึ่งมีโอกาส $\Phi\big((c-\sqrt\rho\,Y)/\sqrt{1-\rho}\big)$ pool มีผู้กู้หลายพันคน และเมื่อรู้ $Y$ แล้ว โชคของแต่ละคนไม่เกี่ยวกัน กฎของจำนวนมากจึงบอกว่าสัดส่วนที่ผิดนัดจริงเท่ากับโอกาสนี้ คูณด้วย LGD ได้ขาดทุนของ pool เป็นฟังก์ชันของ $Y$ ตัวเดียว:

\[ \begin{aligned} L(Y)&=0.4\,\Phi\Big(\frac{c-\sqrt{0.1}\,Y}{\sqrt{0.9}}\Big),\\ c&=\Phi^{-1}(4\%)=-1.7507,\\ L(0)&=0.4\,\Phi\Big(\frac{-1.7507}{0.9487}\Big)\\ &=0.4\,\Phi(-1.8454)=1.30\%,\\ L(-2)&=0.4\,\Phi\Big(\frac{-1.7507+0.6325}{0.9487}\Big)\\ &=0.4\,\Phi(-1.1787)=4.77\%. \end{aligned} \]

ตัวเลขที่ใช้คือ $\sqrt{0.9}=0.9487$ และ $\sqrt{0.1}\times2=0.6325$ ปีที่ราคาบ้านธรรมดา ($Y=0$) pool เสีย 1.30% ปีที่ราคาบ้านแย่ ($Y$ ต่ำกว่าค่าเฉลี่ย 2 SD) pool เสีย 4.77% เกือบสี่เท่า ถ้าเฉลี่ยทุกปีรวมกัน ขาดทุนของ pool คือ $4\%\times40\%=1.6\%$ แต่ pool หนึ่งจะเสียจริงเท่าไรขึ้นกับว่าราคาบ้านของมันแย่แค่ไหน

ชั้น mezzanine สนใจแค่ว่า $L$ ข้าม 3% และ 7% ตอนไหน $L(Y)$ ลดลงเสมอเมื่อ $Y$ เพิ่ม เพราะ $\Phi$ เป็นฟังก์ชันเพิ่ม และ $Y$ อยู่ในตัวเศษด้วยเครื่องหมายลบ เราจึงแก้สมการย้อนหา $Y$ ได้: หารสองข้างด้วย 0.4 ใส่ $\Phi^{-1}$ แล้วย้ายข้าง ให้ $Y_x$ คือค่า $Y$ ที่ทำให้ pool ขาดทุน $x$ พอดี

\[ \begin{aligned} Y_x&=\frac{c-\sqrt{0.9}\,\Phi^{-1}(x/0.4)}{\sqrt{0.1}},\\ Y_{3\%}&=\frac{-1.7507-0.9487\,\Phi^{-1}(0.075)}{0.3162}\\ &=\frac{-1.7507+0.9487(1.4395)}{0.3162}\\ &=\frac{-0.3850}{0.3162}=-1.2176,\\ Y_{7\%}&=-2.7324. \end{aligned} \]

ที่ $x=3\%$ ค่าในวงเล็บคือ $3\%/0.4=0.075$ และ $\Phi^{-1}(0.075)=-1.4395$ ส่วน $\sqrt{0.1}=0.3162$ ค่า $Y_{7\%}$ ได้จากสูตรเดียวกันโดยใส่ $x=7\%$ ต่อไปแปลงขาดทุนของ pool เป็นขาดทุนของชั้น mezzanine $\ell(Y)$ วัดเป็นสัดส่วนของความหนา 4% ของชั้น แล้วหาโอกาสที่ชั้นเริ่มเสียและเสียหมด:

\[ \begin{aligned} u&=L(Y)-3\%,\\ \ell(Y)&=\frac{\min\big(\max(u,0),\,4\%\big)}{4\%},\\ P(\ell\gt0)&=P(Y\lt-1.2176)\\ &=\Phi(-1.2176)=11.17\%,\\ P(\ell=1)&=\Phi(-2.7324)=0.314\%,\\ E[\ell(Y)]&=\int\ell(y)\,\varphi(y)\,dy=3.02\%. \end{aligned} \]

$u$ คือส่วนที่ pool เสียเกิน 3% สูตรของ $\ell$ หนีบ $u$ ไว้ระหว่าง 0 ถึง 4% แล้วหารด้วย 4% เช่น ถ้า pool เสีย 5% ชั้นนี้เสีย $(5\%-3\%)/4\%=50\%$ ของความหนา ชั้นจึงเริ่มเสียเมื่อ $Y$ ต่ำกว่า −1.2176 ซึ่งมีโอกาส 11.17% และเสียหมดเมื่อ $Y$ ต่ำกว่า −2.7324 ซึ่งมีโอกาส 0.314%

ขาดทุนเฉลี่ย $E[\ell]$ คือค่าเฉลี่ยของ $\ell(y)$ ถ่วงด้วย density ของ normal มาตรฐาน $\varphi(y)$ อินทิกรัลนี้ไม่มีสูตรปิด จึงคำนวณเชิงตัวเลขด้วยโค้ดท้ายหน้า ได้ 3.02% ของความหนา และ SD 11.93% SD ใหญ่กว่าค่าเฉลี่ยมากเพราะชั้นนี้ส่วนใหญ่ไม่เสียเลย แต่บางปีเสียหนัก ตัวเลขทั้งหมดนี้เป็นของชั้นเดียว ยังไม่ได้บอกว่าชั้นหลายตัวเสียพร้อมกันแค่ไหน ซึ่งเป็นเรื่องของขั้นถัดไป

ขั้นที่ 5 — CDO² จากชั้น mezzanine 100 ตัว: ความเป็นอิสระคือสมมติฐานทั้งหมด

ตอนนี้กลับมาที่คำถามของหน้า CDO² รวมชั้น mezzanine ของ 100 pool ในสัดส่วนเท่า ๆ กัน ให้ $\bar\ell$ คือขาดทุนเฉลี่ยของ 100 ชั้นนี้ ชั้นบนสุดของ CDO² เสียเมื่อ $\bar\ell\ge30\%$ คำตอบทั้งหมดขึ้นกับว่าราคาบ้านของ 100 pool ขยับไปด้วยกันแค่ไหน

โจทย์ให้อะไรมาบ้าง: ตัวแปรราคาบ้านของ pool ที่ $j$ มีสองส่วน คือส่วนของทั้งประเทศ $M$ ที่ทุก pool ใช้ร่วมกัน และส่วนของภูมิภาค $Z_j$ ที่เป็นของ pool นั้นเอง:

\[Y_j=\sqrt\beta\,M+\sqrt{1-\beta}\,Z_j\]

$M$ และ $Z_1,\dots,Z_{100}$ เป็น normal มาตรฐานที่ไม่เกี่ยวกัน variance ของ $Y_j$ จึงเป็น $\beta+(1-\beta)=1$ แต่ละ pool ยังใช้แบบจำลองเดิมของขั้นที่แล้วได้ทุกอย่าง $\beta$ คือสัดส่วนของ variance ที่มาจากราคาบ้านทั้งประเทศ $\beta=0$ แปลว่า 100 pool ไม่เกี่ยวกันเลย หรือเป็นอิสระกัน ส่วน $\beta=1$ แปลว่าทุก pool ใช้ราคาบ้านตัวเดียวกัน

เมื่อรู้ $M$ แล้ว ส่วนที่เหลือของแต่ละ pool ไม่เกี่ยวกัน ค่าเฉลี่ยของ 100 ชั้นจึงเข้าใกล้ค่าเฉลี่ยแบบมีเงื่อนไข $E[\ell(Y_j)\mid M]$ ค่านี้ลดลงเมื่อ $M$ เพิ่ม ชั้นบนสุดจึงเสียเมื่อ $M$ ต่ำกว่าจุดตัด $M^*$ ที่ทำให้ค่านี้เท่ากับ 30% พอดี และโอกาสที่ชั้นบนสุดเสียคือ $P=\Phi(M^*)$

เริ่มจากกรณีที่คิดด้วยมือได้ คือ $\beta=1$ ทุก pool มี $Y_j=M$ ชั้น mezzanine ทุกตัวจึงเสียเท่ากัน และ $\bar\ell=\ell(M)$ จุดตัดคือจุดที่ pool ขาดทุนพอให้ชั้น mezzanine เสีย 30% ของความหนา ใช้สูตร $Y_x$ ของขั้นที่แล้วกับ $x=4.2\%$:

\[ \begin{aligned} L(M^*)&=3\%+0.3\times4\%=4.2\%,\\ M^*&=\frac{-1.7507-0.9487\,\Phi^{-1}(0.105)}{0.3162}\\ &=\frac{-1.7507+0.9487(1.2536)}{0.3162}\\ &=\frac{-0.5614}{0.3162}=-1.7755,\\ P&=\Phi(-1.7755)=3.79\%. \end{aligned} \]

ในวงเล็บคือ $4.2\%/0.4=0.105$ และ $\Phi^{-1}(0.105)=-1.2536$ กรณี $\beta=0.25$ และ $0.5$ ต้องเฉลี่ย $\ell$ ข้ามส่วนภูมิภาค $Z_j$ ก่อนหาจุดตัด ซึ่งไม่มีสูตรปิด โค้ดท้ายหน้าคำนวณให้ ส่วนกรณี $\beta=0$ ชั้น 100 ตัวไม่เกี่ยวกันเลย $\bar\ell$ คือค่าเฉลี่ยของ 100 ตัวที่แต่ละตัวมีค่าเฉลี่ย 3.02% และ SD 11.93% (จากขั้นที่แล้ว) SD ของค่าเฉลี่ยของ $n$ ตัวที่ไม่เกี่ยวกันคือ SD ของตัวเดียวหารด้วย $\sqrt n$:

\[ \begin{aligned} \beta=0.5&:\ M^*=-2.2815,\ P=1.13\%,\\ \beta=0.25&:\ M^*=-3.0829,\ P=0.10\%,\\ \beta=0&:\ \mathrm{SD}(\bar\ell)=\frac{11.93\%}{\sqrt{100}}=1.19\%,\\ &\quad\ \frac{30\%-3.02\%}{1.19\%}\approx23,\\ &\quad\ P(\bar\ell\ge30\%)\lt10^{-33}. \end{aligned} \]

คำตอบ: ถ้าทุก pool ผูกกับราคาบ้านทั้งประเทศตัวเดียว ($\beta=1$) ชั้น mezzanine ทั้ง 100 ตัวเสียเท่ากันพร้อมกัน เหมือนมีตัวเดียว ชั้นบนสุดเสียเมื่อ pool ขาดทุนเกิน 4.2% ซึ่งมีโอกาส 3.79% เทียบกับโอกาสที่ชั้น mezzanine เองเริ่มเสีย 11.17% ได้ $3.79/11.17=0.34$ ชั้นที่ได้ AAA จึงเสี่ยงราวหนึ่งในสามของวัตถุดิบของมัน ไม่ใช่แทบศูนย์

ตัวเลข $10^{-33}$ ของกรณี $\beta=0$ มาจากไหน จุด 30% อยู่ห่างค่าเฉลี่ยราว 23 SD ซึ่งไกลมาก แต่ใช้รูประฆัง normal ประมาณโอกาสตรงนี้ไม่ได้ เพราะ $\ell$ ของแต่ละชั้นเบี้ยวมาก ส่วนใหญ่เป็นศูนย์ บางครั้งเป็นหนึ่ง จึงใช้ขอบเขต Chernoff แทน ขอบเขตนี้เป็นเพดานของโอกาสที่ค่าเฉลี่ยของ $n$ ตัวที่ไม่เกี่ยวกันจะขึ้นไปถึงระดับ $k$:

\[ \begin{aligned} P(\bar\ell\ge k)&\le\exp\big(-n\,I(k)\big),\\ I(k)&=\max_{t}\Big[tk-\log E\big[e^{t\ell}\big]\Big]. \end{aligned} \]

ใส่ $n=100$ และ $k=30\%$ โค้ดท้ายหน้าได้เพดาน $10^{-33.02}$ ซึ่งต่ำกว่า $10^{-33}$ นี่คือตัวเลขที่ทีมออกตราสารเชื่อ

ตรวจเองใน 10 วินาที: ที่ $\beta=1$ จุดตัด $M^*=-1.7755$ ต้องอยู่ระหว่างจุดที่ชั้นเริ่มเสีย $-1.2176$ กับจุดที่ชั้นเสียหมด $-2.7324$ เพราะ 30% อยู่ระหว่างเสีย 0% กับเสีย 100% ของความหนา มันอยู่ในช่วงนั้นจริง โอกาส 3.79% จึงต้องอยู่ระหว่าง 0.314% กับ 11.17% ซึ่งก็จริง

ตัวเลขระหว่างกลางสำคัญที่สุด แค่ราคาบ้านทั้งประเทศมีส่วนครึ่งหนึ่งของ variance ($\beta=0.5$) โอกาสก็ขึ้นจากแทบศูนย์เป็น 1.13% เหตุผลคือการกระจายไป 100 pool ตัดได้เฉพาะส่วนที่แต่ละ pool ไม่ใช้ร่วมกัน ($Z_j$) ส่วนราคาบ้านทั้งประเทศ ($M$) ทุก pool ใช้ร่วมกัน เฉลี่ยกี่ pool ก็ไม่หาย ในโลกจริงยังแย่กว่านี้ เพราะสินเชื่อก้อนเดียวกันมักถูกใส่ซ้ำใน pool ของหลายดีล ชั้น mezzanine ของ CDO หลายตัวจึงอ้างอิงสินเชื่อชุดเดียวกัน

ขั้นที่ 6 — เงินกู้ระยะสั้น: ขาดทุนบนกระดาษกลายเป็นการขาย

ธนาคารส่วนใหญ่ไม่ได้ซื้อชั้น AAA ด้วยเงินของตัวเอง แต่กู้ระยะสั้นผ่าน repo คือวางชั้น AAA เป็นหลักประกันแล้วกู้เงินมาซื้อ ผู้ให้กู้ไม่ให้กู้เต็มมูลค่าหลักประกัน แต่หักส่วนหนึ่งไว้กันราคาลด ส่วนที่หักเรียกว่า haircut $h$ กติกาคือหนี้ $D$ ต้องไม่เกิน $(1-h)$ เท่าของมูลค่าหลักประกัน $V$ ขั้นนี้ถามว่าถ้าราคาลดนิดเดียว ธนาคารต้องขายของเท่าไร

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ):

  • ธนาคารถือชั้น AAA มูลค่า $V=\$100$ ล้าน
  • haircut $h=5\%$ จึงกู้ได้สูงสุด $0.95\times100=\$95$ ล้าน ธนาคารกู้เต็มวงเงิน $D=\$95$ ล้าน และใช้เงินตัวเองแค่ $100-95=\$5$ ล้าน
  • ราคาชั้น AAA ลด 3% มูลค่าเหลือ $V=\$97$ ล้าน วงเงินใหม่เหลือ $0.95\times97=\$92.15$ ล้าน หนี้ \$95 ล้านจึงเกินวงเงิน

ธนาคารต้องขายหลักประกันมูลค่า $x$ แล้วเอาเงินไปคืนหนี้ จนหนี้กลับมาอยู่ในวงเงิน การขายลดทั้งสองข้าง หลังขาย หนี้เหลือ $D-x$ และหลักประกันเหลือ $V-x$ เงื่อนไขจึงเป็น:

\[ \begin{aligned} D-x&\le(1-h)(V-x),\\ D-x&\le(1-h)V-x+hx,\\ hx&\ge D-(1-h)V,\\ x&=\frac{D-(1-h)V}{h}. \end{aligned} \]

$x$ ในแถวสุดท้ายคือยอดขายที่น้อยที่สุดที่ทำให้เงื่อนไขเป็นจริง แทนตัวเลข ($D=95,\ V=97$) ทั้งที่ haircut เดิม และที่ผู้ให้กู้ขึ้น haircut เป็น 15%:

\[ \begin{aligned} h=5\%&:\ x=\frac{95-0.95(97)}{0.05}\\ &\qquad=\frac{2.85}{0.05}=57,\\ h=15\%&:\ x=\frac{95-0.85(97)}{0.15}\\ &\qquad=\frac{12.55}{0.15}=83.67. \end{aligned} \]

จุดที่คนส่วนใหญ่พลาดคือคิดว่าขาย \$1 แล้วช่องว่างหาย \$1 ความจริงการขาย \$1 ลดหนี้ \$1 แต่ก็ลดวงเงินกู้ไป $(1-h)$ ดอลลาร์ด้วย ช่องว่างระหว่างหนี้กับวงเงิน $D-(1-h)V$ จึงแคบลงแค่ $h$ ดอลลาร์ต่อการขาย \$1 ช่องว่างทุก \$1 จึงต้องขาย $1/h$ ดอลลาร์ ที่ $h=5\%$ คือ $1/0.05=20$ ดอลลาร์

ผลคือราคาลดแค่ 3% ธนาคารต้องขาย \$57 ล้านจาก \$97 ล้าน ถ้าผู้ให้กู้กลัวแล้วขึ้น haircut เป็น 15% พร้อมกัน ต้องขาย \$83.67 ล้าน หรือ $83.67/97=86.3\%$ ของที่ถือ ในปี 2007–2008 haircut ของหลักประกันที่เป็นตราสาร securitization ขึ้นจากเกือบศูนย์เป็นหลายสิบเปอร์เซ็นต์ และบางประเภทผู้ให้กู้ไม่รับเป็นหลักประกันเลย

สูตรเดียวกันนี้ใช้กับกองทุนที่ซื้อหุ้นด้วยเงินกู้ (margin) ในฟองสบู่ วิกฤต และการกำกับดูแล ถ้าเขียนเงินของเจ้าของเป็น $E=V-D$ ช่องว่างจะเท่ากับ $D-(1-h)V=hV-E$ คือเงินที่ผู้ให้กู้อยากให้เจ้าของใส่ไว้ ($hV$) ลบด้วยเงินที่เจ้าของมีอยู่จริง ($E$)

ขั้นที่ 7 — การขายกดราคา แล้วราคาก็บังคับให้ขายอีก

สูตรขายบังคับของขั้นที่แล้วสมมติว่าขายได้ที่ราคาเดิม แต่ถ้าผู้ถือหลายรายต้องขายของแบบเดียวกันพร้อมกัน ผู้ซื้อมีน้อย ราคาจึงลด ราคาที่ลดทำให้ช่องว่างกว้างขึ้นอีก และต้องขายอีก ขั้นนี้ใช้แบบจำลองย่อที่หยาบโดยตั้งใจ เพื่อให้เห็นว่าวงจรนี้มีอยู่จริง ไม่ได้ใช้พยากรณ์ ทุกรอบ $t$ ทำสามอย่าง:

  • วัดแรงกดดันให้ขาย $s_t$ คือช่องว่างหารด้วยมูลค่าหลักประกัน
  • หนีบแรงกดดันให้อยู่ระหว่าง 0 ถึง 1 ได้ $q_t$ เพราะไม่มีช่องว่างก็ไม่มีแรงกด และขายได้ไม่เกินของที่ถือ
  • ราคาลดเป็นสัดส่วน $\alpha q_t$ โดย $\alpha$ (สมมติ) บอกว่าตลาดไวต่อการขายแค่ไหน $\alpha=0$ คือขายเท่าไรราคาก็ไม่ขยับ

หนี้ $D=95$ และ haircut $h=15\%$ คงที่ตลอด เริ่มที่ $V_0=97$ และใช้ $\alpha=0.5$ เมื่อ $s_t$ อยู่ระหว่าง 0 ถึง 1 สูตรราคาย่อได้ เพราะ $V_t\times s_t$ คือช่องว่างพอดี:

\[ \begin{aligned} s_t&=\frac{D-(1-h)V_t}{V_t},\\ q_t&=\min\big(\max(s_t,0),1\big),\\ V_{t+1}&=V_t(1-\alpha q_t)\\ &=V_t-\alpha\big[D-(1-h)V_t\big]. \end{aligned} \]

แถวสุดท้ายบอกว่าแต่ละรอบราคาลดเป็นดอลลาร์เท่ากับ $\alpha$ คูณช่องว่าง เดินสี่รอบแรก โดยช่องว่างของแต่ละรอบคือ $95-0.85V_t$:

\[ \begin{aligned} V_1&=97-0.5(12.55)=90.725,\\ V_2&=90.725-0.5(17.884)=81.783,\\ V_3&=81.783-0.5(25.484)=69.041,\\ V_4&=69.041-0.5(36.315)=50.883. \end{aligned} \]

ทำไมยิ่งขายยิ่งต้องขาย หนี้ในแบบจำลองนี้คงที่ ราคาที่ลดจึงทำให้ช่องว่างกว้างขึ้นทุกรอบ จาก 12.55 เป็น 17.88, 25.48 และ 36.32 ราคาจึงลดเร็วขึ้นทุกรอบ ใน 4 รอบมูลค่าเหลือ $50.88/97=52\%$ ราวครึ่งเดียว

แบบจำลองนี้ไม่ได้ลดหนี้ตามเงินที่ได้จากการขาย จึงเกินจริงด้านร้าย แต่ทิศถูก: ราคาที่ลดสร้างการขาย และการขายสร้างราคาที่ลด ความเสี่ยงแบบนี้ไม่ได้มาจากบ้านหลังไหนเลย มันมาจากผู้ถือที่ต้องขายพร้อมกัน ซึ่งเรียกว่า fire sale

แบบจำลองของ pool และ CDO² ในหน้านี้คือ Gaussian copula แบบเดียวกับในหน้า CDO และ Gaussian copula แบบจำลองนี้ไม่ได้ “ผิด” ในแบบที่สูตรคำนวณพลาด สูตรข้างบนถูกภายใต้สมมติฐานของมัน และข้อจำกัดของมันเป็นที่รู้กันก่อนวิกฤต สิ่งที่ผิดมีสองอย่าง อย่างแรกคือตัวเลขที่ใส่ คือ $\beta$ และ $\rho$ ที่ประมาณจากช่วงที่ราคาบ้านขึ้นทุกปี อย่างที่สองคือไม่มีใครถามว่า ถ้าตัวเลขนั้นผิด ชั้นไหนเจ็บ หน้านี้เห็นแล้วว่าแค่เปลี่ยน $\beta$ ตัวเดียว คำตอบก็เปลี่ยนจากแทบศูนย์เป็น 3.79%

สาเหตุที่ไม่ใช่คณิตศาสตร์ก็หนักพอกัน นายหน้า ผู้ปล่อยกู้ ผู้จัดตั้งตราสาร และบริษัทจัดอันดับ ได้เงินตอนสินเชื่อถูกปล่อยและขายต่อ ไม่ใช่ตอนที่ผู้กู้ผ่อนจนหมด จึงไม่มีใครต้องรับผลถ้าสินเชื่อเสีย ปัญหานี้เรียกว่า moral hazard นอกจากนั้น การกำกับดูแลและการบริหารความเสี่ยงตามไม่ทัน และตราสารก็ซับซ้อนเกินกว่าจะสร้างแบบจำลองให้ดีได้

บนโต๊ะจริง วิธีที่ใช้แทนการเชื่อตัวเลขเดียวคือทดสอบด้วยสถานการณ์ของปัจจัยร่วม เช่นสมมติว่าราคาบ้านทั้งประเทศลด 20% แล้วเดินผลผ่านทุกข้อต่อ: ความเร็วของการคืนก่อนกำหนด การผิดนัดและ LGD ที่ขึ้นพร้อมกัน waterfall (กติกาส่งเงินลงทีละชั้น) ของแต่ละชั้น และเงินกู้ที่ใช้ถือ แล้วรายงานผลเป็นช่วงตามค่า $\beta$ หลายค่า ไม่ใช่ค่าเดียว ต้องนับความเสี่ยงด้านสภาพคล่องด้วย เพราะในวันแย่หาคนซื้อยาก และส่วนต่างระหว่างราคาเสนอซื้อกับเสนอขาย (bid-offer) กว้าง

หลังวิกฤต กฎหมาย Dodd–Frank ของสหรัฐฯ กำหนดให้ผู้ทำ securitization ถือความเสี่ยงของตราสารที่ตัวเองออกไว้อย่างน้อย 5% คนที่ส่งต่อความเสี่ยงจึงต้องรับผลส่วนหนึ่งเอง

ลำดับเหตุการณ์สั้น ๆ: ราคาบ้านในสหรัฐฯ ขึ้นต่อเนื่องจนถึงราวปี 2006 แล้วเริ่มลด ปี 2007 การผิดนัดของสินเชื่อ subprime เพิ่มเร็ว ตามด้วยการลดอันดับชั้นของ MBS และ CDO จำนวนมาก มีนาคม 2008 Bear Stearns ถูกขายให้ JPMorgan โดยมีธนาคารกลางสหรัฐฯ ช่วย กันยายน 2008 รัฐเข้าควบคุม Fannie Mae และ Freddie Mac และ Lehman Brothers ล้มละลายในวันที่ 15 กันยายน

โจทย์ตรวจความเข้าใจ

1. ผู้กู้คนหนึ่งจ่ายเงินดาวน์ $e_0=10\%$ ของราคาบ้าน และกู้ส่วนที่เหลือ ต่อมาราคาบ้านลด $d=25\%$ ประมาณว่าหนี้ยังเท่ายอดกู้ LTV ตอนนี้เป็นเท่าไร และราคาบ้านต้องลดเท่าไร หนี้จึงเท่ากับมูลค่าบ้านพอดี?

เฉลย

ใช้สูตร LTV ของขั้นราคาบ้านลด:

\[ \begin{aligned} \mathrm{LTV}_t&=\frac{1-0.10}{1-0.25}=\frac{0.90}{0.75}=120\%,\\ \mathrm{LTV}_t-1&=\frac{d-e_0}{1-d}. \end{aligned} \]

หนี้เกินบ้าน 20% ส่วน $\mathrm{LTV}_t-1$ เป็นศูนย์เมื่อตัวเศษ $d-e_0$ เป็นศูนย์ คือ $d=e_0$ หนี้จึงเท่ากับบ้านพอดีเมื่อราคาลดเท่าเงินดาวน์ คือลด 10%

2. ทีมความเสี่ยงอีกทีมใช้สองสถานการณ์สมมติ: ปกติ มีโอกาสเกิด 80% PD 2% LGD 20% และวิกฤต มีโอกาสเกิด 20% PD 10% LGD 50% ขาดทุนเฉลี่ยจริงต่างจากการคูณค่าเฉลี่ยเท่าไร?

เฉลย

คิดค่าเฉลี่ยแต่ละตัว คูณกัน แล้วเทียบกับค่าเฉลี่ยของผลคูณ:

\[ \begin{aligned} E[p]&=0.8(2\%)+0.2(10\%)=3.6\%,\\ E[g]&=0.8(20\%)+0.2(50\%)=26\%,\\ E[p]\,E[g]&=3.6\%\times26\%=0.936\%,\\ E[pg]&=0.8(2\%)(20\%)\\ &\quad+0.2(10\%)(50\%)\\ &=0.32\%+1.00\%=1.32\%,\\ \mathrm{Cov}(p,g)&=1.32\%-0.936\%=0.384\%. \end{aligned} \]

ขาดทุนจริงคือ $1.32/0.936=1.41$ เท่าของการคูณค่าเฉลี่ย หรือสูงกว่า 41% ส่วนต่างทั้งหมดคือ covariance 0.384%

3. ธนาคารถือหลักประกัน \$100 ล้าน และกู้ repo \$90 ล้าน ซึ่งเต็มวงเงินที่ haircut 10% พอดี ($0.9\times100=90$) ต่อมาราคาหลักประกันลด 5% และผู้ให้กู้ขึ้น haircut เป็น 20% พร้อมกัน ธนาคารต้องขายเท่าไร?

เฉลย

มูลค่าใหม่คือ $V=100\times0.95=95$ ใส่สูตรขายบังคับ:

\[ \begin{aligned} x&=\frac{D-(1-h)V}{h}=\frac{90-0.8(95)}{0.2}\\ &=\frac{14}{0.2}=70. \end{aligned} \]

ธนาคารต้องขาย \$70 ล้าน ตรวจ: หลังขาย หนี้เหลือ $90-70=20$ หลักประกันเหลือ $95-70=25$ วงเงินคือ $0.8\times25=20$ เท่าหนี้พอดี

const {sqrt, exp, log, abs, PI, min, max} = Math;
function num(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(`${name} must be a finite number`);
  return x;
}
const pdf = x => exp(-x * x / 2) / sqrt(2 * PI);
function Phi(x) {
  if (abs(num('x', x)) < 3) {
    let term = x, sum = x;
    for (let n = 1; n < 200 && abs(term) > 1e-17 * abs(sum); n++) { term *= x * x / (2 * n + 1); sum += term; }
    return 0.5 + pdf(x) * sum;
  }
  const z = abs(x); let f = z;
  for (let k = 300; k >= 1; k--) f = z + k / f;
  return x > 0 ? 1 - pdf(z) / f : pdf(z) / f;
}
function PhiInv(p) {
  if (!(num('p', p) > 0 && p < 1)) throw new RangeError('p must be strictly between 0 and 1');
  let x = 0;
  for (let i = 0; i < 100; i++) { const dx = (Phi(x) - p) / pdf(x); x -= dx; if (abs(dx) < 1e-15) break; }
  return x;
}
const payment = (B, c, n) => B * (c / 12) / (1 - (1 + c / 12) ** -n);

// Large pool: loss fraction given the house-price factor y, and the mezzanine tranche [a, b] as a share of its thickness.
function poolModel(pd, lgd, rho, a = 0.03, b = 0.07) {
  if (!(num('rho', rho) > 0 && rho < 1)) throw new RangeError('rho must be strictly between 0 and 1');
  if (!(num('lgd', lgd) > 0 && lgd <= 1)) throw new RangeError('lgd must be in (0, 1]');
  const c = PhiInv(pd);
  const loss = y => lgd * Phi((c - sqrt(rho) * y) / sqrt(1 - rho));
  const tranche = y => min(max(loss(y) - a, 0), b - a) / (b - a);
  const yAt = x => (c - sqrt(1 - rho) * PhiInv(x / lgd)) / sqrt(rho);     // loss(yAt(x)) = x
  return {c, loss, tranche, yAt};
}
const expectNormal = (f, h = 0.002, lim = 10) => { let s = 0; for (let y = -lim; y <= lim; y += h) s += h * pdf(y) * f(y); return s; };
// P(average mezzanine loss of many pools exceeds k) when pools share a national factor with weight beta.
function seniorHit(model, beta, k) {
  if (!(num('beta', beta) > 0 && beta <= 1)) throw new RangeError('beta must be in (0, 1]');
  const g = M => beta === 1 ? model.tranche(M) : expectNormal(z => model.tranche(sqrt(beta) * M + sqrt(1 - beta) * z), 0.01, 9);
  let lo = -12, hi = 12;                                 // g falls as M rises: find g(M*) = k
  for (let i = 0; i < 70; i++) { const mid = (lo + hi) / 2; if (g(mid) > k) lo = mid; else hi = mid; }
  return Phi(lo);
}
// Chernoff bound on P(average of n independent tranche losses >= k): exp(-n sup_t [t k - log E e^(t l)]).
function chernoffLog10(model, n, k) {
  const rate = t => t * k - log(expectNormal(y => exp(t * model.tranche(y))));
  let lo = 0, hi = 60;
  for (let i = 0; i < 60; i++) { const m1 = lo + (hi - lo) / 3, m2 = hi - (hi - lo) / 3; if (rate(m1) < rate(m2)) lo = m1; else hi = m2; }
  return -n * rate((lo + hi) / 2) / Math.LN10;
}
// Repo: assets that must be sold (proceeds repay debt) to bring debt back under (1 - h) of collateral.
function forcedSale(V, D, h) {
  if (!(num('h', h) > 0 && h < 1)) throw new RangeError('haircut must be strictly between 0 and 1');
  return min(max(num('D', D) - (1 - h) * num('V', V), 0) / h, V);
}
function fireSale(alpha, V = 97, D = 95, h = 0.15, rounds = 10) {
  const path = [V];
  for (let i = 0; i < rounds; i++) {
    const v = path[i], q = v > 0 ? min(max((D - (1 - h) * v) / v, 0), 1) : 0;
    path.push(v * (1 - alpha * q));
  }
  return path;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ทำไมผู้กู้ subprime ต้องกู้ใหม่: พออัตราโปรโมชันหมด ค่างวดกระโดด (+30.7% ในตัวอย่าง) และการกู้ใหม่ทำได้เฉพาะเมื่อบ้านยังมีมูลค่าเกินหนี้
  • ราคาบ้านลดเท่าไรหนี้จึงเกินบ้าน: ทันทีที่ราคาลดเกินเงินดาวน์ เพราะ $\mathrm{LTV}_t-1=(d-e_0)/(1-d)$ ดาวน์ 5% ราคาลด 20% ได้ LTV 118.75% และขาดทุนต่อหลังก็แย่ลงพร้อมกัน
  • ทำไมคูณค่าเฉลี่ยของ PD กับ LGD ไม่ได้: เพราะสองตัวขึ้นพร้อมกัน ขาดทุนเฉลี่ยคือค่าเฉลี่ยของผลคูณ 1.035% ไม่ใช่ 0.468%
  • ชั้น AAA ของ CDO² ปลอดภัยแค่ไหน: ปลอดภัยเฉพาะเมื่อ pool ไม่เกี่ยวกัน ถ้าทุก pool ผูกกับราคาบ้านตัวเดียว โอกาสเสียคือ 3.79% ไม่ใช่ต่ำกว่า $10^{-33}$ และแค่ $\beta=0.5$ ก็ได้ 1.13%
  • ทำไมราคาลดนิดเดียวจึงบังคับขายมาก: ของที่ถือด้วย repo ต้องขาย $1/h$ ดอลลาร์ต่อช่องว่างทุก \$1 และการขายพร้อมกันก็กดราคาต่อ

บทถัดไป real options และ derivatives ของพลังงาน เปลี่ยนเรื่องไปที่สิทธิ์ในโลกจริง เริ่มจากreal options กับ dynamic programming ซึ่งตั้งราคาสิทธิ์ที่จะรอ ด้วยการคิดย้อนจากปลายทาง แบบเดียวกับสิทธิ์ปิดหนี้ก่อนกำหนดของผู้กู้บ้านในบทนี้ ส่วนวงจรเงินกู้กับการขายบังคับของหน้านี้ ฟองสบู่ วิกฤต และการกำกับดูแลจะกลับมาขยายเป็นภาพของทั้งตลาด
