22.5 What 2007–2008 Actually Broke

ไม่ได้พังเพราะสูตรเดียว แต่เพราะทุกข้อต่อของโซ่ผูกกับราคาบ้านตัวเดียวกัน: ผู้กู้ที่กู้ใหม่ไม่ได้ pool ที่เสียพร้อมกัน ชั้น AAA ที่ทำจากชั้นกลาง และเงินกู้ระยะสั้นที่บังคับให้ขาย

ธนาคารลงทุนถือชั้นบนสุดของ CDO² ซึ่งได้อันดับ AAA และรับขาดทุนเกิน 30% ของหลักประกัน หลักประกันคือชั้น mezzanine 3%–7% ของ pool สินเชื่อ subprime 100 pool แต่ละ pool มีโอกาสผิดนัดตลอดอายุ 4% และเสีย 40% ของหนี้เมื่อผิดนัด ทีมที่ออกตราสารบอกว่า “ชั้น mezzanine แต่ละตัวมีโอกาสเริ่มเสียราว 11% และขาดทุนเฉลี่ยราว 3% ของชั้น พอรวม 100 ตัว ค่าเฉลี่ยจะนิ่ง ชั้นที่เริ่มเสียที่ 30% จึงไม่มีทางเสีย” ถ้าทุก pool ผูกกับราคาบ้านของทั้งประเทศตัวเดียวกัน โอกาสที่ชั้นนี้เริ่มเสียคือเท่าไร?

ลองตอบก่อนเปิดเฉลย

3.79% ถ้า 100 pool ไม่เกี่ยวกันจริง ขาดทุนเฉลี่ยของ 100 ชั้นจะนิ่งใกล้ 3.02% และโอกาสแตะ 30% ต่ำกว่า $10^{-33}$ ตามที่ทีมบอก แต่ถ้าทุก pool ขึ้นกับตัวแปรราคาบ้านตัวเดียว ชั้น mezzanine ทุกตัวเสียพร้อมกันเหมือนเป็นตัวเดียว ชั้นบนสุดจะเสียทันทีที่แต่ละ pool ขาดทุนเกิน 4.2% ซึ่งมีโอกาส 3.79% ชั้น “AAA” นี้จึงเสี่ยงราวหนึ่งในสามของชั้น mezzanine ที่มันทำมาจาก

ภาพรวมก่อนลงสูตร

สี่หน้าที่ผ่านมาสร้างโซ่ครบแล้ว: ค่างวดและหนี้ของสินเชื่อบ้าน การคืนก่อนกำหนดผ่านการกู้ใหม่ กติกาแบ่งเงินเป็นชั้น และการแบ่งขาดทุนที่ขึ้นกับการผิดนัดพร้อมกัน หน้านี้เดินโซ่นั้นในทิศที่มันพัง ทีละข้อต่อ ด้วยตัวเลข

สินเชื่อ subprime คือสินเชื่อให้ผู้กู้ที่ประวัติเครดิตอ่อน คุณภาพจริงของผู้กู้มักถูกซ่อน และจำนวนมากเป็นสินเชื่ออัตราลอยตัวที่เริ่มด้วยอัตราโปรโมชันต่ำ (teaser) แผนของผู้กู้คือกู้ใหม่ก่อนอัตราปรับ ซึ่งทำได้ตราบที่ราคาบ้านขึ้น สินเชื่อถูกขายต่อเข้า pool แบ่งเป็นชั้น ชั้นกลางของหลาย pool ถูกรวมเป็น CDO อีกชั้น (ABS CDO หรือ CDO²) ชั้นบนของมันได้ AAA และถูกถือด้วยเงินกู้ระยะสั้น

ทุกข้อต่อคำนวณถูกภายใต้สมมติฐานของตัวเอง สิ่งที่พังคือสมมติฐานว่าข้อต่อเหล่านี้ไม่เกี่ยวกัน เพราะทุกข้อต่อผูกกับราคาบ้านของทั้งประเทศตัวเดียวกัน รูปด้านล่างคือโซ่ทั้งเส้น และใครถือความเสี่ยงส่วนไหน

ศัพท์ที่ใช้ในหัวข้อนี้
Subprime และ teaser rate
สินเชื่อให้ผู้กู้ที่ประวัติเครดิตอ่อน จำนวนมากเป็น adjustable-rate mortgage ที่เริ่มด้วยอัตราต่ำช่วงแรก (teaser) แล้วปรับขึ้น ผู้กู้มักวางแผนกู้ใหม่ก่อนอัตราปรับ
Loan-to-value (LTV) และ negative equity
LTV คือหนี้หารด้วยราคาบ้าน เมื่อ LTV เกิน 100% หนี้มากกว่าบ้าน (negative equity) ผู้กู้กู้ใหม่ไม่ได้ และขายบ้านแล้วก็ยังปิดหนี้ไม่หมด
PD, LGD และ expected loss
โอกาสผิดนัด สัดส่วนที่เสียเมื่อผิดนัด และค่าเฉลี่ยของขาดทุน ขาดทุนเฉลี่ยคือค่าเฉลี่ยของผลคูณ ไม่ใช่ผลคูณของค่าเฉลี่ย เมื่อสองตัวขยับพร้อมกัน
ABS CDO และ CDO²
CDO ที่หลักประกันคือชั้นของตราสาร securitization อื่น เช่นชั้น mezzanine ของ pool สินเชื่อบ้าน CDO² คือการแบ่งชั้นซ้ำจากชั้นที่แบ่งมาแล้ว และยังมี CDO³ ต่อจากนั้นอีก
Repo และ haircut
Repo คือการกู้ระยะสั้นโดยวางหลักทรัพย์ค้ำ haircut คือส่วนของมูลค่าหลักประกันที่ผู้ให้กู้ไม่ให้กู้ ถ้า haircut ขึ้นหรือราคาหลักประกันลด ผู้กู้ต้องหาเงินหรือขายของ
Fire sale
การขายเร่งด่วนหลายรายพร้อมกันจนราคาต่ำกว่ามูลค่า ราคาที่ลดทำให้คนอื่นต้องขายต่อ เป็นความเสี่ยงที่ตลาดสร้างขึ้นเอง (market endogeneity)

สัญลักษณ์ความหมายหน่วย
$e_0,\ d$เงินดาวน์เป็นสัดส่วนของราคาบ้าน และสัดส่วนที่ราคาบ้านลดสัดส่วน
$B_t,\ H_t$หนี้ค้าง และราคาบ้านดอลลาร์
$\mathrm{PD},\ \mathrm{LGD}$โอกาสผิดนัด และสัดส่วนที่เสียเมื่อผิดนัดสัดส่วน
$Y,\ \beta$ตัวแปรราคาบ้านของ pool หนึ่ง (normal มาตรฐาน ต่ำคือแย่) และสัดส่วนของ variance ที่มาจากราคาบ้านทั้งประเทศไม่มีหน่วย

ขั้นที่ 1 — อัตราโปรโมชันหมด: ค่างวดกระโดด

ข้อต่อแรกอยู่ที่ตัวสินเชื่อ สินเชื่อ subprime จำนวนมากเป็นแบบ 2/28: อัตราต่ำคงที่ 2 ปีแรกแล้วลอยตัวอีก 28 ปี ใช้สูตรค่างวดคิดทั้งสองช่วง

โจทย์ให้อะไรมาบ้าง: สินเชื่อสมมติ \$200,000 ผ่อนแบบ 30 ปี อัตรา 7% ช่วง 24 เดือนแรก แล้วอัตราปรับเป็น 10% คิดค่างวดใหม่จากหนี้ที่เหลือกับ 336 งวดที่เหลือ

\[ \begin{aligned} A_1&=\frac{200{,}000(0.07/12)}{1-(1+0.07/12)^{-360}}\\ &=1{,}330.60,\\ B_{24}&=195{,}789.89,\\ A_2&=\frac{195{,}789.89(0.10/12)}{1-(1+0.10/12)^{-336}}\\ &=1{,}738.54. \end{aligned} \]

คำตอบ: ค่างวดขึ้นจาก \$1,330.60 เป็น \$1,738.54 หรือ +30.7% ทั้งที่หนี้ลดไปแค่ \$4,210.11 ใน 2 ปี ถ้าค่างวดเดิมกิน 38% ของรายได้ (สมมติ) ค่างวดใหม่จะกิน 49.6% ผู้กู้แบบนี้วางแผนกู้ใหม่ก่อนอัตราปรับ ซึ่งทำได้ก็ต่อเมื่อบ้านยังมีส่วนของเจ้าของเหลือพอให้ธนาคารใหม่ปล่อยกู้

ตรวจเองใน 10 วินาที: ถ้าอัตราไม่ปรับ คิดค่างวดใหม่ที่ 7% จาก \$195,789.89 กับ 336 งวดจะได้ \$1,330.60 เท่าเดิม เพราะหนี้ค้างคือมูลค่าวันนี้ของค่างวดที่เหลือ ส่วนที่ขึ้นทั้งหมดจึงมาจากอัตรา

ขั้นที่ 2 — ราคาบ้านลด: หนี้มากกว่าบ้าน

ช่วงแรกของการผ่อน หนี้แทบไม่ลด (ผ่อนสองปีตัดเงินต้นได้ไม่ถึง 2%) ถ้าราคาบ้านลด อัตราส่วนหนี้ต่อราคาบ้านจึงพุ่ง ขั้นนี้หาว่าราคาลดเท่าไรหนี้จึงเกินบ้าน โดยประมาณว่าหนี้ยังเท่ายอดกู้

\[ \begin{aligned} \mathrm{LTV}_0&=\frac{B_0}{H_0}=1-e_0,\\ \mathrm{LTV}_t&\approx\frac{B_0}{H_0(1-d)}\\ &=\frac{1-e_0}{1-d},\\ \mathrm{LTV}_t-1&=\frac{d-e_0}{1-d},\\ \frac{0.95}{0.80}&=118.75\%. \end{aligned} \]

บรรทัดที่สามบอกว่าหนี้เกินบ้านทันทีที่ราคาลดมากกว่าเงินดาวน์ ผู้กู้ที่ดาวน์ 5% จึงติดลบตั้งแต่ราคาลดเกิน 5% และที่ราคาลด 20% (บรรทัดสุดท้าย $e_0=5\%,\ d=20\%$) หนี้เกินบ้าน 18.75% ผู้กู้คนนี้กู้ใหม่ไม่ได้ ขายบ้านก็ปิดหนี้ไม่หมด ถ้าค่างวดกระโดดด้วย ทางออกที่เหลือคือหยุดจ่าย

บ้านที่ถูกยึดขายได้ไม่ครบหนี้ ตัวอย่าง: บ้าน \$500,000 กู้ \$475,000 ผ่อนจนหนี้เหลือ \$465,000 ราคาบ้านลดเป็น \$400,000 (LTV 116.25%) ขายได้สุทธิหลังค่าใช้จ่าย \$380,000 ผู้ให้กู้เสีย \$85,000 หรือ LGD 18.28% ถ้าราคาไม่ลด ขาดทุนนี้แทบเป็นศูนย์

ขั้นที่ 3 — โอกาสผิดนัดกับขาดทุนต่อหลังขึ้นพร้อมกัน

ราคาบ้านที่ลดทำให้ทั้งโอกาสผิดนัดสูงขึ้นและขาดทุนต่อหลังสูงขึ้น ขาดทุนเฉลี่ยของ pool จึงคิดโดยคูณค่าเฉลี่ยสองตัวแยกกันไม่ได้ เพราะค่าเฉลี่ยของผลคูณเท่ากับผลคูณของค่าเฉลี่ยเฉพาะเมื่อ covariance เป็นศูนย์ ขั้นนี้ใช้สองสถานการณ์สมมติ: ปกติ (โอกาส 90%) PD 1% LGD 15% และวิกฤต (โอกาส 10%) PD 15% LGD 60%

\[ \begin{aligned} E[pg]&=E[p]\,E[g]\\ &\quad+\mathrm{Cov}(p,g),\\ E[p]&=0.9(1\%)+0.1(15\%)\\ &=2.4\%,\\ E[g]&=0.9(15\%)+0.1(60\%)\\ &=19.5\%,\\ E[p]\,E[g]&=0.468\%,\\ E[pg]&=0.135\%+0.900\%\\ &=1.035\%. \end{aligned} \]

เขียน $p$ แทน PD และ $g$ แทน LGD ให้สั้น บรรทัดแรกคือนิยามของ covariance เขียนกลับด้าน บรรทัดสุดท้ายเฉลี่ยผลคูณของแต่ละสถานการณ์: $0.9(1\%)(15\%)=0.135\%$ และ $0.1(15\%)(60\%)=0.900\%$ ผลต่าง 0.567% คือ covariance ขาดทุนเฉลี่ยจริงเป็น 2.21 เท่าของการคูณค่าเฉลี่ย และเก้าในสิบของมันมาจากสถานการณ์วิกฤตที่เกิดแค่ 10%

ขั้นที่ 4 — ขาดทุนของ pool เป็นฟังก์ชันของราคาบ้าน

ตอนนี้ขยับจากบ้านหลังเดียวเป็น pool ใช้แบบจำลองปัจจัยเดียวโดยให้ปัจจัยของ pool คือตัวแปรราคาบ้าน $Y$ ถ้า pool มีสินเชื่อหลายพันหลัง เมื่อรู้ $Y$ แล้ว สัดส่วนที่ผิดนัดจะเท่ากับโอกาสผิดนัดแบบมีเงื่อนไขพอดี (กฎของจำนวนมาก) ขาดทุนของ pool จึงเป็นฟังก์ชันของ $Y$ ตัวเดียว ตัวเลขสมมติ: PD ตลอดอายุ 4% LGD 40% และ $\rho=0.1$

\[ \begin{aligned} L(Y)&=0.4\,\Phi\Big(\frac{c-\sqrt{0.1}\,Y}{\sqrt{0.9}}\Big),\\ c&=\Phi^{-1}(4\%)=-1.7507,\\ L(0)&=1.30\%,\\ L(-2)&=4.77\%,\\ L(Y)=3\%&:\ Y=-1.2176,\\ L(Y)=7\%&:\ Y=-2.7324,\\ u&=L(Y)-3\%,\\ \ell(Y)&=\min(\max(u,0),4\%)\\ &\quad\div4\%. \end{aligned} \]

ขาดทุนเฉลี่ยของ pool คือ $4\%\times40\%=1.6\%$ แต่ขาดทุนของ pool หนึ่ง ๆ ขึ้นกับว่าราคาบ้านของมันแย่แค่ไหน $L(Y)$ ลดลงเมื่อ $Y$ ดีขึ้นเสมอ เพราะ $\Phi$ เป็นฟังก์ชันเพิ่มและ $Y$ อยู่ในตัวเศษด้วยเครื่องหมายลบ จึงแก้ย้อนหา $Y$ ที่ให้ขาดทุนเท่าที่ต้องการได้ ชั้น mezzanine 3%–7% เริ่มเสียเมื่อ $Y\lt-1.2176$ ซึ่งมีโอกาส $\Phi(-1.2176)=11.17\%$ และเสียหมดเมื่อ $Y\lt-2.7324$ ซึ่งมีโอกาส 0.314% ขาดทุนเฉลี่ยของชั้น $E[\ell(Y)]=3.02\%$ ของความหนา ส่วนเบี่ยงเบนมาตรฐาน 11.93% ตัวเลขเหล่านี้เป็นของชั้นเดียว ยังไม่ได้บอกว่าชั้นหลายตัวเสียพร้อมกันแค่ไหน

ขั้นที่ 5 — CDO² จากชั้น mezzanine 100 ตัว: ความเป็นอิสระคือสมมติฐานทั้งหมด

CDO² ของโจทย์รวมชั้น mezzanine ของ 100 pool เท่า ๆ กัน ชั้นบนสุดเสียเมื่อขาดทุนเฉลี่ยของ 100 ชั้นเกิน 30% ของความหนา คำถามคือ 100 pool เกี่ยวกันแค่ไหน ให้ตัวแปรราคาบ้านของ pool ที่ $j$ มีส่วนร่วมระดับประเทศ $M$ และส่วนของภูมิภาค $Z_j$

โจทย์ให้อะไรมาบ้าง: $Y_j=\sqrt\beta\,M+\sqrt{1-\beta}\,Z_j$ ทุกตัวเป็น normal มาตรฐานอิสระกัน pool และชั้นตามแบบจำลองขาดทุนของ pool ข้างบน เมื่อรู้ $M$ ชั้น 100 ตัวอิสระกัน ขาดทุนเฉลี่ยของ 100 ชั้น $\bar\ell$ จึงเข้าใกล้ $E[\ell(Y_j)\mid M]$ ชั้นบนสุดเสียเมื่อ $\bar\ell\ge30\%$

\[ \begin{aligned} \beta=0&:\ \bar\ell\approx3.02\%\pm1.19\%,\\ &\quad\ P(\bar\ell\ge30\%)\lt10^{-33},\\ \beta=0.25&:\ P=0.10\%,\\ \beta=0.5&:\ P=1.13\%,\\ \beta=1&:\ P=P\big(L(M)\gt4.2\%\big)\\ &=\Phi(-1.7755)\\ &=3.79\%. \end{aligned} \]

คำตอบ: ถ้าทุก pool ผูกกับราคาบ้านทั้งประเทศตัวเดียว ($\beta=1$) ชั้น mezzanine ทั้ง 100 ตัวเสียพร้อมกันเป็นตัวเดียว ชั้นบนสุดเสียเมื่อชั้น mezzanine เสียเกิน 30% ของความหนา คือเมื่อ pool ขาดทุนเกิน $3\%+0.3(4\%)=4.2\%$ ซึ่งมีโอกาส 3.79% เทียบกับโอกาสเริ่มเสียของชั้น mezzanine เอง 11.17% ชั้นที่ได้ AAA จึงเสี่ยงราวหนึ่งในสามของวัตถุดิบ

ตรวจเองใน 10 วินาที: ที่ $\beta=0$ ส่วนเบี่ยงเบนมาตรฐานของชั้นเดียวคือ 11.93% หารด้วย $\sqrt{100}$ ได้ 1.19% จุด 30% อยู่ห่างค่าเฉลี่ย 3.02% ราว 23 เท่าของส่วนเบี่ยงเบน ส่วน $10^{-33}$ มาจากขอบเขตแบบ Chernoff ของค่าเฉลี่ย 100 ตัวที่อิสระกัน

ตัวเลขระหว่างกลางสำคัญที่สุด: แค่ให้ราคาบ้านทั้งประเทศมีส่วนครึ่งหนึ่งของ variance ($\beta=0.5$) โอกาสก็ขึ้นจากแทบศูนย์เป็น 1.13% การกระจาย 100 pool ช่วยได้เฉพาะส่วนที่ไม่ร่วมกัน และราคาบ้านทั้งประเทศที่ลดพร้อมกันคือส่วนที่ร่วมกัน ในโลกจริงยังแย่กว่านี้ เพราะสินเชื่อก้อนเดียวกันโผล่ซ้ำใน pool ของหลาย deal ชั้น mezzanine ของหลาย CDO จึงอ้างอิงของชุดเดียวกัน

ขั้นที่ 6 — เงินกู้ระยะสั้น: ขาดทุนบนกระดาษกลายเป็นการขาย

ชั้น AAA ส่วนใหญ่ไม่ได้ถือด้วยเงินของตัวเอง แต่ถือด้วย repo ระยะสั้น ถ้าธนาคารถือชั้น AAA มูลค่า \$100 ล้าน กู้ repo \$95 ล้านที่ haircut 5% หนี้ต้องไม่เกิน $(1-h)$ เท่าของมูลค่าหลักประกัน ถ้าเกิน ต้องขายของไปคืนหนี้ และการขาย \$1 ลดทั้งหนี้และหลักประกัน

\[ \begin{aligned} D-x&\le(1-h)(V-x),\\ hx&\ge D-(1-h)V,\\ x&=\frac{D-(1-h)V}{h},\\ V=97,\ h=5\%&:\ x=\frac{2.85}{0.05}=57,\\ V=97,\ h=15\%&:\ x=\frac{12.55}{0.15}\\ &\qquad\quad=83.67. \end{aligned} \]

บรรทัดที่สองได้จากกระจายวงเล็บแล้วย้าย $x$ ไปข้างเดียว การขาย \$1 ลดหนี้ \$1 แต่ลดวงเงินกู้ $(1-h)$ ดอลลาร์ ช่องว่างจึงแคบลงแค่ $h$ ดอลลาร์ต่อการขาย \$1 ทุกดอลลาร์ของช่องว่างจึงต้องขาย $1/h$ ดอลลาร์ สูตรเดียวกันนี้ใช้กับกองทุนที่ซื้อด้วย margin ในฟองสบู่ วิกฤต และการกำกับดูแล เพราะ $D-(1-h)V=hV-E$ เมื่อ $E=V-D$ คือเงินของเจ้าของ

ราคา AAA ลดแค่ 3% ธนาคารต้องขาย \$57 ล้านจาก \$97 ล้าน และถ้าผู้ให้กู้ขึ้น haircut เป็น 15% พร้อมกัน ต้องขาย \$83.67 ล้าน หรือ 86.3% ของที่ถือ ในปี 2007–2008 haircut ของหลักประกันที่เป็นตราสาร securitization ขึ้นจากเกือบศูนย์เป็นหลายสิบเปอร์เซ็นต์ และบางประเภทผู้ให้กู้ไม่รับเลย

ขั้นที่ 7 — การขายกดราคา แล้วราคาก็บังคับให้ขายอีก

สูตรขายบังคับสมมติว่าขายได้ที่ราคาเดิม แต่ถ้าผู้ถือหลายรายต้องขายของแบบเดียวกันพร้อมกัน ราคาจะลดลง ขั้นนี้ใช้แบบจำลองย่อที่หยาบโดยตั้งใจ เพื่อแสดงว่าวงจรนี้มีอยู่ ไม่ใช่เพื่อพยากรณ์: ให้แรงกดดันแต่ละรอบเป็นช่องว่างเทียบกับมูลค่า แล้วให้ราคาลดตามแรงกดดันคูณ $\alpha$

\[ \begin{aligned} s_t&=\frac{D-(1-h)V_t}{V_t},\\ q_t&=\min\big(\max(s_t,0),1\big),\\ V_{t+1}&=V_t(1-\alpha q_t),\\ \alpha=0.5&:\ V=97,\ 90.72,\ 81.78,\\ &\qquad\ \ 69.04,\ 50.88. \end{aligned} \]

เริ่มที่ $V=97$ หนี้ 95 haircut 15% แรงกดดันรอบแรกคือ $12.55/97=12.94\%$ ราคาลดครึ่งหนึ่งของนั้น แล้วช่องว่างก็กว้างขึ้นเพราะหนี้ยังเท่าเดิม ใน 4 รอบมูลค่าเหลือราวครึ่ง แบบจำลองนี้ไม่ได้ลดหนี้ตามการขาย จึงเกินจริงด้านร้าย แต่ทิศถูก: ราคาที่ลดสร้างการขาย และการขายสร้างราคาที่ลด ความเสี่ยงแบบนี้ไม่ได้มาจากบ้านหลังไหนเลย มันมาจากผู้ถือที่ต้องขายพร้อมกัน

ใช้ทำอะไรบนโต๊ะจริง

Gaussian copula ไม่ได้ “ผิด” ในแบบที่สูตรคำนวณพลาด สูตรของ pool และ CDO² ข้างบนถูกภายใต้สมมติฐานของมัน และข้อจำกัดของมันเป็นที่รู้กันก่อนวิกฤต สิ่งที่ผิดคือตัวเลขที่ใส่ ($\beta$ และ $\rho$ ที่ปรับจากช่วงที่ราคาบ้านขึ้นทุกปี) และการไม่ถามว่าถ้าตัวเลขนั้นผิด ชั้นไหนเจ็บ คำตอบเปลี่ยนจากแทบศูนย์เป็น 3.79% ด้วยตัวเลขตัวเดียว ส่วนสาเหตุอื่นที่ไม่ใช่คณิตศาสตร์ก็หนักพอกัน: นายหน้า ผู้ปล่อยกู้ ผู้จัดตั้ง และบริษัทจัดอันดับได้เงินตอนสินเชื่อถูกปล่อยและขายต่อ ไม่ใช่ตอนที่มันถูกจ่ายคืน (moral hazard) การกำกับดูแลและการบริหารความเสี่ยงตามไม่ทัน และตราสารซับซ้อนเกินกว่าจะสร้างแบบจำลองให้ดีได้

วิธีที่ใช้แทนคือทดสอบด้วยปัจจัยร่วมที่ตั้งเป็นสถานการณ์ เช่นราคาบ้านทั้งประเทศลด 20% แล้วเดินผลผ่านทุกข้อต่อ: ความเร็วการคืนก่อน การผิดนัดและ LGD ที่ขึ้นพร้อมกัน waterfall ของแต่ละชั้น และเงินกู้ที่ใช้ถือ แล้วรายงานผลตามช่วงของ $\beta$ ไม่ใช่ค่าเดียว ต้องนับความเสี่ยงด้านสภาพคล่องด้วย เพราะในวันแย่ราคาหายากและ bid-offer กว้าง หลังวิกฤต Dodd–Frank กำหนดให้ผู้ทำ securitization ถือความเสี่ยงของตราสารที่ตัวเองออกไว้อย่างน้อย 5% เพื่อให้ผู้ส่งต่อความเสี่ยงต้องรับผลส่วนหนึ่งเอง

ลำดับเหตุการณ์สั้น ๆ: ราคาบ้านในสหรัฐฯ ขึ้นต่อเนื่องจนถึงราวปี 2006 แล้วเริ่มลด การผิดนัดของสินเชื่อ subprime เพิ่มเร็วในปี 2007 ตามด้วยการลดอันดับชั้นของ MBS และ CDO จำนวนมาก มีนาคม 2008 Bear Stearns ถูกขายให้ JPMorgan โดยมีธนาคารกลางช่วย กันยายน 2008 Fannie Mae และ Freddie Mac ถูกรัฐเข้าควบคุม และ Lehman Brothers ล้มละลายในวันที่ 15 กันยายน

const {sqrt, exp, log, abs, PI, min, max} = Math;
function num(name, x) {
  if (typeof x !== 'number' || !Number.isFinite(x)) throw new TypeError(`${name} must be a finite number`);
  return x;
}
const pdf = x => exp(-x * x / 2) / sqrt(2 * PI);
function Phi(x) {
  if (abs(num('x', x)) < 3) {
    let term = x, sum = x;
    for (let n = 1; n < 200 && abs(term) > 1e-17 * abs(sum); n++) { term *= x * x / (2 * n + 1); sum += term; }
    return 0.5 + pdf(x) * sum;
  }
  const z = abs(x); let f = z;
  for (let k = 300; k >= 1; k--) f = z + k / f;
  return x > 0 ? 1 - pdf(z) / f : pdf(z) / f;
}
function PhiInv(p) {
  if (!(num('p', p) > 0 && p < 1)) throw new RangeError('p must be strictly between 0 and 1');
  let x = 0;
  for (let i = 0; i < 100; i++) { const dx = (Phi(x) - p) / pdf(x); x -= dx; if (abs(dx) < 1e-15) break; }
  return x;
}
const payment = (B, c, n) => B * (c / 12) / (1 - (1 + c / 12) ** -n);

// Large pool: loss fraction given the house-price factor y, and the mezzanine tranche [a, b] as a share of its thickness.
function poolModel(pd, lgd, rho, a = 0.03, b = 0.07) {
  if (!(num('rho', rho) > 0 && rho < 1)) throw new RangeError('rho must be strictly between 0 and 1');
  if (!(num('lgd', lgd) > 0 && lgd <= 1)) throw new RangeError('lgd must be in (0, 1]');
  const c = PhiInv(pd);
  const loss = y => lgd * Phi((c - sqrt(rho) * y) / sqrt(1 - rho));
  const tranche = y => min(max(loss(y) - a, 0), b - a) / (b - a);
  const yAt = x => (c - sqrt(1 - rho) * PhiInv(x / lgd)) / sqrt(rho);     // loss(yAt(x)) = x
  return {c, loss, tranche, yAt};
}
const expectNormal = (f, h = 0.002, lim = 10) => { let s = 0; for (let y = -lim; y <= lim; y += h) s += h * pdf(y) * f(y); return s; };
// P(average mezzanine loss of many pools exceeds k) when pools share a national factor with weight beta.
function seniorHit(model, beta, k) {
  if (!(num('beta', beta) > 0 && beta <= 1)) throw new RangeError('beta must be in (0, 1]');
  const g = M => beta === 1 ? model.tranche(M) : expectNormal(z => model.tranche(sqrt(beta) * M + sqrt(1 - beta) * z), 0.01, 9);
  let lo = -12, hi = 12;                                 // g falls as M rises: find g(M*) = k
  for (let i = 0; i < 70; i++) { const mid = (lo + hi) / 2; if (g(mid) > k) lo = mid; else hi = mid; }
  return Phi(lo);
}
// Chernoff bound on P(average of n independent tranche losses >= k): exp(-n sup_t [t k - log E e^(t l)]).
function chernoffLog10(model, n, k) {
  const rate = t => t * k - log(expectNormal(y => exp(t * model.tranche(y))));
  let lo = 0, hi = 60;
  for (let i = 0; i < 60; i++) { const m1 = lo + (hi - lo) / 3, m2 = hi - (hi - lo) / 3; if (rate(m1) < rate(m2)) lo = m1; else hi = m2; }
  return -n * rate((lo + hi) / 2) / Math.LN10;
}
// Repo: assets that must be sold (proceeds repay debt) to bring debt back under (1 - h) of collateral.
function forcedSale(V, D, h) {
  if (!(num('h', h) > 0 && h < 1)) throw new RangeError('haircut must be strictly between 0 and 1');
  return min(max(num('D', D) - (1 - h) * num('V', V), 0) / h, V);
}
function fireSale(alpha, V = 97, D = 95, h = 0.15, rounds = 10) {
  const path = [V];
  for (let i = 0; i < rounds; i++) {
    const v = path[i], q = v > 0 ? min(max((D - (1 - h) * v) / v, 0), 1) : 0;
    path.push(v * (1 - alpha * q));
  }
  return path;
}

  • อัตราโปรโมชันที่หมดทำให้ค่างวดกระโดด (+30.7% ในตัวอย่าง) และทางหนีคือกู้ใหม่ ซึ่งต้องมีส่วนของเจ้าของในบ้าน

  • ขาดทุนบนกระดาษของของที่ถือด้วย repo กลายเป็นการขาย $1/h$ เท่าของช่องว่าง และการขายพร้อมกันกดราคาต่อ
