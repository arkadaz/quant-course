1.6 The Poisson Distribution

Poisson ใช้นับว่าเหตุการณ์หนึ่งเกิดกี่ครั้งในช่วงเวลาหนึ่ง เมื่อเหตุการณ์เกิดได้จากหลายจุด แต่ละจุดเกิดยาก และตัวเลขเดียวที่ต้องรู้คือจำนวนครั้งเฉลี่ย $\lambda$

พอร์ตลงทุนหนึ่งถือหุ้นกู้ของบริษัท 200 แห่ง หุ้นกู้ (bond) คือการให้บริษัทกู้เงิน บริษัทสัญญาว่าจะจ่ายดอกเบี้ยและคืนเงินต้นตามกำหนด แต่บางบริษัทอาจจ่ายไม่ได้ เรียกว่าผิดนัดชำระ (default) เมื่อบริษัทผิดนัด เจ้าของหุ้นกู้มักได้เงินคืนแค่บางส่วน

ฝ่ายความเสี่ยงต้องกันเงินไว้ก้อนหนึ่ง เป็นงบรองรับความเสียหายของปีหน้า ถ้างบน้อยไป ปีที่มีหลายบริษัทผิดนัดจะเกิดเงินขาด

ของที่รู้ (ตัวเลขสมมติเพื่อฝึกคิด):

  • จำนวนบริษัท $n=200$ ราย ลงเงินรายละ \$5 ล้าน
  • แต่ละรายมีโอกาสผิดนัดภายในหนึ่งปี $p=1.5\%$ และรายหนึ่งผิดนัดหรือไม่ ไม่เกี่ยวกับรายอื่น
  • ถ้าผิดนัด จะได้เงินคืน 40% ของเงินที่ลงไป ส่วนนี้เรียกว่า recovery จึงเสียไป 60%

ฝ่ายความเสี่ยงคิดความเสียหายเฉลี่ยต่อปีแบบนี้ ให้ $\lambda$ เป็นจำนวนรายที่ผิดนัดเฉลี่ยต่อปี และ $L$ เป็นเงินที่เสียเมื่อหนึ่งรายผิดนัด ความเสียหายเฉลี่ยคือสองตัวนี้คูณกัน

\[\begin{aligned} \lambda&=np=200\times0.015=3\\ L&=\$5{,}000{,}000\times(1-0.40)\\ &=\$3{,}000{,}000\\ \lambda L&=3\times\$3{,}000{,}000\\ &=\$9{,}000{,}000 \end{aligned}\]

ฝ่ายความเสี่ยงจึงเสนอให้ตั้งงบไว้ \$9 ล้านพอดี หัวหน้าถามว่า งบเท่าค่าเฉลี่ยนี้จะไม่พอบ่อยแค่ไหน

ลองตอบก่อนเปิดเฉลย

ไม่พอบ่อยกว่าหนึ่งปีในสามปี งบ \$9 ล้านรับความเสียหายได้แค่ 3 ราย เพราะ $3\times\$3$ ล้าน $=\$9$ ล้าน ปีไหนที่ผิดนัดตั้งแต่ 4 รายขึ้นไป งบก็ไม่พอ สูตร Poisson ที่หน้านี้จะสร้างให้โอกาสนั้นเป็น

\[\begin{aligned} P(X\ge4)&=1-P(X\le3)\\ &=1-e^{-3}\big(1+3+4.5+4.5\big)\\ &=1-13e^{-3}\approx35.3\% \end{aligned}\]

โดย $X$ คือจำนวนรายที่ผิดนัดในปีนั้น และ $1, 3, 4.5, 4.5$ คือ $3^r/r!$ ของ $r=0, 1, 2, 3$ ส่วนปีที่เสียตั้งแต่ \$15 ล้าน (ผิดนัด 5 รายขึ้นไป) มีโอกาสราว 18.5% ซึ่งหน้านี้จะคำนวณให้ดูทีละขั้น ค่าเฉลี่ยจึงไม่ใช่ระดับที่ควรใช้เป็นงบ

ภาพรวมก่อนลงสูตร

จำนวนรายที่ผิดนัดจาก 200 ราย คิดด้วย binomial ได้ตามหน้า binomial distribution binomial นับว่าใน $n$ ครั้งที่ไม่เกี่ยวกัน มีกี่ครั้งที่ “เกิด” เมื่อแต่ละครั้งเกิดด้วยโอกาส $p$ แต่โจทย์นี้มีลักษณะพิเศษสามข้อ:

  • จุดที่เหตุการณ์อาจเกิดมีมาก ($n=200$ ราย)
  • แต่ละจุดเกิดยาก ($p=1.5\%$)
  • ตัวเลขที่เรามั่นใจที่สุดคือจำนวนครั้งเฉลี่ยต่อช่วง (3 รายต่อปี)

ลักษณะแบบนี้พบบ่อยในตลาด เช่น จำนวนคำสั่งซื้อขายที่ส่งเข้ามาในหนึ่งวินาที จำนวนครั้งที่ระบบล่มในหนึ่งเดือน หรือจำนวนวันที่ราคากระโดดแรงในหนึ่งปี ในกรณีเหล่านี้ เรานับไม่ได้ว่ามี “จุดที่อาจเกิด” กี่จุด แต่รู้ว่าเฉลี่ยแล้วเกิดกี่ครั้ง

ลองแบ่งช่วงเวลาให้ละเอียดขึ้นเรื่อย ๆ โดยคงจำนวนครั้งเฉลี่ยไว้เท่าเดิม binomial จะเข้าใกล้ distribution ตัวหนึ่งที่ใช้ตัวเลขตัวเดียว คือจำนวนครั้งเฉลี่ย $\lambda$ (อ่านว่า แลมบ์ดา) ตัวนี้ชื่อ Poisson distribution

สูตรของมันคือ $P(X=r)=\lambda^r e^{-\lambda}/r!$ หน้านี้จะสร้างสูตรนี้ขึ้นจาก binomial ทีละขั้น สมบัติเด่นของมันคือค่าเฉลี่ยกับ variance เท่ากับ $\lambda$ ทั้งคู่

ลำดับของหน้านี้:

  1. หา $\lambda$ จากข้อมูลที่มี
  2. หาโอกาสที่ไม่มีเหตุการณ์เลย แล้วดูว่า $e$ มาจากไหน
  3. สร้างสูตรเต็ม ตรวจว่าโอกาสรวมได้ 1 และพิสูจน์ค่าเฉลี่ยกับ variance
  4. กลับมาที่พอร์ตหุ้นกู้: งบเท่าค่าเฉลี่ยไม่พอบ่อยแค่ไหน และควรตั้งงบเท่าไรให้พอใน 99 ปีจาก 100 ปี
  5. ดูว่าคำตอบเปลี่ยนแค่ไหน ถ้าบริษัทผิดนัดพร้อมกันเป็นกลุ่ม

ขั้นที่ 1 — λ คือจำนวนเฉลี่ยในช่วงที่ถาม

สูตร Poisson ต้องการตัวเลขเดียว คือ $\lambda$ จำนวนครั้งเฉลี่ยในช่วงเวลาที่ถาม จึงต้องหา $\lambda$ ให้ถูกก่อน ข้อมูลที่มีมักมาในสองแบบ

  • รู้จำนวนจุดที่อาจเกิด $n$ กับโอกาสต่อจุด $p$: ใช้ $\lambda=np$
  • รู้อัตราเฉลี่ย $a$ ครั้งต่อหน่วยเวลา และความยาวช่วงที่ถาม $t$ ในหน่วยเวลาเดียวกัน: ใช้ $\lambda=a\,t$

ลองสามตัวอย่าง ตัวแรกคือพอร์ตหุ้นกู้ $n=200$ ราย $p=0.015$ ตัวที่สองคือคำสั่งซื้อขายที่ส่งเข้าระบบเฉลี่ย $a=20$ รายการต่อวินาที และถามช่วงสั้น ๆ $t=0.1$ วินาที ตัวที่สามคือ alarm ของระบบเทรด (เสียงเตือนเมื่อมีอะไรผิดปกติ) ที่ดังเฉลี่ย $a=2$ ครั้งต่อชั่วโมง และถามช่วงครึ่งชั่วโมง $t=0.5$ ชั่วโมง

\[\begin{aligned} \lambda_{\mathrm{bonds}}&=np=200\times0.015=3\\[4pt] \lambda_{\mathrm{orders}}&=a\,t=20\times0.1=2\\[4pt] \lambda_{\mathrm{alarm}}&=a\,t=2\times0.5=1 \end{aligned}\]

$\lambda$ คือจำนวนครั้งเฉลี่ย ไม่ใช่โอกาส จึงเป็น 3 หรือ 20 ก็ได้ จุดที่พลาดบ่อยที่สุดคือหน่วยเวลาไม่ตรงกัน alarm ที่ดังเฉลี่ย 2 ครั้งต่อชั่วโมง ถ้าถามครึ่งชั่วโมง ต้องใช้ $\lambda=1$ ไม่ใช่ 2 เพราะครึ่งชั่วโมงควรดังได้ครึ่งหนึ่งของหนึ่งชั่วโมง

การคูณ $a\,t$ ถูกต้องเมื่ออัตราคงที่ตลอดช่วง แต่คำสั่งซื้อขายจริงเข้ามาหนาตอนตลาดเปิด และบางลงตอนเที่ยง ถ้าถามช่วงตลาดเปิด ต้องใช้อัตราเฉลี่ยของช่วงนั้นจริง ๆ ไม่ใช่ค่าเฉลี่ยทั้งวัน

ขั้นที่ 2 — โอกาสที่ไม่มีเหตุการณ์เลย และที่มาของ e

ก่อนจะหาโอกาสของ 3 ราย หรือ 5 ราย เริ่มจากคำถามที่ง่ายที่สุดก่อน: ปีหนึ่งไม่มีรายไหนผิดนัดเลย มีโอกาสเท่าไร คำตอบของข้อนี้จะบอกด้วยว่าค่าคงที่ $e$ ในสูตร Poisson มาจากไหน

แบ่งหนึ่งปีเป็น $n$ ช่วงย่อยเท่า ๆ กัน (หรือมองเป็น $n$ ราย ก็ได้) แต่ละช่วงเกิดเหตุการณ์ได้ด้วยโอกาส $\lambda/n$ และแต่ละช่วงไม่เกี่ยวกัน จำนวนครั้งเฉลี่ยทั้งปีจึงเป็น $n\times\lambda/n=\lambda$ เสมอ ไม่ว่า $n$ เท่าไร

ให้ $X_n$ เป็นจำนวนครั้งที่เกิดเมื่อแบ่งเป็น $n$ ช่วง ปีที่ไม่มีเหตุการณ์เลยคือปีที่ทุกช่วงเงียบ แต่ละช่วงเงียบด้วยโอกาส $1-\lambda/n$ จึงคูณกัน $n$ ครั้ง ลองดูว่าเมื่อ $n$ โตขึ้น โดย $\lambda=3$ คงที่ คำตอบเป็นอย่างไร

\[\begin{aligned} P(X_n=0)&=\Big(1-\frac{\lambda}{n}\Big)^n\\[4pt] n=12&:\ (1-0.25)^{12}\approx 0.0317\\ n=200&:\ (1-0.015)^{200}\approx 0.0487\\ n=10{,}000&:\ (1-0.0003)^{10{,}000}\approx 0.0498\\[4pt] \ln P(X_n=0)&=n\ln\Big(1-\frac{\lambda}{n}\Big)\\ &\approx n\Big(-\frac{\lambda}{n}\Big)=-\lambda\\[4pt] P(X_n=0)&\longrightarrow e^{-\lambda}=e^{-3}\approx 0.0498 \end{aligned}\]

เมื่อ $n$ โตขึ้น ตัวเลขไต่ขึ้นแล้วหยุดนิ่งที่ราว 0.0498 ทำไมนิ่งตรงนั้น: ใส่ $\ln$ เพื่อให้กำลัง $n$ ลงมาเป็นตัวคูณ แล้วแทน $\ln(1-u)$ ด้วย $-u$ เมื่อ $u$ เล็ก ขั้นนี้คือขั้นที่ต้องดู มันทำได้เพราะความชันของ $\ln x$ ที่ $x=1$ คือ $1/x=1$ ใกล้ ๆ จุดนั้นกราฟจึงเกือบเป็นเส้นตรง $\ln(1-u)\approx-u$ และเมื่อ $n$ โตขึ้น $u=\lambda/n$ ยิ่งเล็กลง การประมาณจึงยิ่งแม่น สุดท้ายถอด $\ln$ กลับด้วย $e$ ยกกำลัง ได้ $e^{-\lambda}$

ความหมายคือ เมื่อจุดที่อาจเกิดมีมากขึ้น แต่ค่าเฉลี่ยคงที่ คำตอบจะหยุดเปลี่ยนและนิ่งที่ $e^{-\lambda}$ พอร์ตจริงของเรามี $n=200$ ได้ 0.0487 ใกล้ค่าปลายทาง 0.0498 แล้ว ปีที่ไม่มีใครผิดนัดเลยจึงเกิดราว 1 ปีใน 20 ปี เพราะ $1/0.0498\approx20$

ขั้นที่ 3 — จากศูนย์ครั้งไปสู่ r ครั้ง

ตอนนี้รู้โอกาสของศูนย์ครั้งแล้ว ขั้นนี้หาโอกาสที่เกิดพอดี $r$ ครั้ง เช่น พอดี 3 ราย วิธีเหมือนเดิม: เริ่มจากสูตร binomial ที่มี $n$ ช่วง ช่วงละโอกาส $\lambda/n$ แยกสูตรออกเป็นตัวคูณหลายตัว แล้วดูว่าแต่ละตัวเข้าใกล้อะไรเมื่อ $n$ โตขึ้น โดย $r$ คงที่ การแยกใช้สองข้อเท็จจริง คือ $\binom nr=\frac{n(n-1)\cdots(n-r+1)}{r!}$ และ $(1-\lambda/n)^{n-r}=(1-\lambda/n)^{n}(1-\lambda/n)^{-r}$

\[\begin{aligned} P(X_n=r)&=\binom nr\Big(\frac{\lambda}{n}\Big)^r\Big(1-\frac{\lambda}{n}\Big)^{n-r}\\ &=\frac{n(n-1)\cdots(n-r+1)}{r!}\cdot\frac{\lambda^r}{n^r}\\ &\quad\times\Big(1-\frac{\lambda}{n}\Big)^{n}\Big(1-\frac{\lambda}{n}\Big)^{-r}\\ &=\frac{\lambda^r}{r!}\cdot A_n\cdot B_n\cdot C_n\\[4pt] A_n&=\frac{n(n-1)\cdots(n-r+1)}{n^r}\to 1\\ B_n&=\Big(1-\frac{\lambda}{n}\Big)^{n}\to e^{-\lambda}\\ C_n&=\Big(1-\frac{\lambda}{n}\Big)^{-r}\to 1\\[4pt] P(X=r)&=\boxed{\frac{\lambda^r e^{-\lambda}}{r!}},\quad r=0,1,2,\ldots\\[4pt] P(X=3)&=\frac{3^3e^{-3}}{3!}=4.5\times0.0498\approx0.224 \end{aligned}\]

สูตรนี้บอกว่า โอกาสที่เกิดพอดี $r$ ครั้ง เท่ากับ $\lambda^r/r!$ คูณโอกาสเงียบทั้งปี $e^{-\lambda}$

ขั้นที่ต้องดูคือสามตัวคูณที่ยังมี $n$ อยู่ $A_n$ คือ $\frac nn\cdot\frac{n-1}{n}\cdots\frac{n-r+1}{n}$ แต่ละตัวเข้าใกล้ 1 เมื่อ $n$ ใหญ่ และมีแค่ $r$ ตัวซึ่งเป็นจำนวนคงที่ ผลคูณจึงเข้าใกล้ 1 ด้วย ข้อนี้ใช้ได้เพราะ $r$ คงที่ ถ้า $r$ โตตาม $n$ จะสรุปแบบนี้ไม่ได้ $B_n$ คือโอกาสเงียบทั้งปีที่หาไว้ในขั้นที่แล้ว จึงเข้าใกล้ $e^{-\lambda}$ ส่วน $C_n$ มีวงเล็บที่เข้าใกล้ 1 ยกกำลัง $-r$ ซึ่งคงที่ จึงเข้าใกล้ 1

สูตรนี้เรียกว่า PMF (probability mass function) ของ Poisson คือตารางโอกาสของแต่ละค่า ลองใช้กับพอร์ตหุ้นกู้ที่ $\lambda=3$ โดย $3^3/3!=27/6=4.5$ โอกาสที่ผิดนัดพอดี 3 รายจึงเป็น 0.224 ตรงกับแท่งสีแดงในรูปแรก

สังเกตว่า $n$ กับ $p$ หายไปจากสูตร เหลือแค่ $\lambda=np$ ตัวเดียว นี่คือข้อดีหลักของ Poisson: เราไม่ต้องรู้ว่าปีหนึ่งมี “จุดที่อาจผิดนัด” กี่จุด รู้แค่ค่าเฉลี่ยก็พอ

ขั้นที่ 4 — ตรวจว่ารวมได้หนึ่ง และคำนวณแท่งถัดไปจากแท่งก่อน

$X$ เป็นได้ทุกค่า 0, 1, 2, … ไม่มีที่สิ้นสุด โอกาสของทุกค่ารวมกันต้องได้ 1 พอดี ไม่อย่างนั้นสูตรนี้ใช้เป็น distribution ไม่ได้ จึงต้องตรวจ เครื่องมือที่ใช้คืออนุกรมของ exponential (Taylor series ของ $e^a$)

\[e^{a}=\sum_{r=0}^{\infty}\frac{a^r}{r!}=1+a+\frac{a^2}{2!}+\frac{a^3}{3!}+\cdots\]

อนุกรมเดียวกันยังให้วิธีคิดแท่งถัดไปจากแท่งก่อนหน้า ซึ่งกดเครื่องคิดเลขง่ายกว่าแทนสูตรเต็มทีละแท่ง ตัวเลขข้างล่างใช้ $\lambda=3$ ของพอร์ตหุ้นกู้ และเก็บทศนิยมไว้ห้าหกตำแหน่ง เพื่อให้การปัดไม่สะสมจนตัวเลขเพี้ยน

\[\begin{aligned} \sum_{r=0}^{\infty}\frac{\lambda^re^{-\lambda}}{r!}&=e^{-\lambda}\sum_{r=0}^{\infty}\frac{\lambda^r}{r!}\\ &=e^{-\lambda}e^{\lambda}=1\\[4pt] \frac{P(X=r)}{P(X=r-1)}&=\frac{\lambda^r/r!}{\lambda^{r-1}/(r-1)!}=\frac{\lambda}{r}\\[4pt] P(X=0)&=e^{-3}\approx0.049787\\ P(X=1)&=0.049787\times\tfrac31\approx0.14936\\ P(X=2)&=0.14936\times\tfrac32\approx0.22404\\ P(X=3)&=0.22404\times\tfrac33\approx0.22404\\ P(X=4)&=0.22404\times\tfrac34\approx0.16803\\ P(X=5)&=0.16803\times\tfrac35\approx0.10082 \end{aligned}\]

การตรวจผลรวมใช้ได้เพราะ $e^{-\lambda}$ ไม่ขึ้นกับ $r$ จึงดึงออกมานอกผลรวมได้ ผลรวมที่เหลือคืออนุกรมของ $e^{\lambda}$ พอดี คูณกันจึงได้ 1

อัตราส่วนของแท่งติดกันคือ $\lambda/r$ ถ้า $r\lt\lambda$ อัตราส่วนมากกว่า 1 แท่งจึงสูงขึ้น ถ้า $r=\lambda$ อัตราส่วนเท่ากับ 1 แท่งจึงเท่ากัน ถ้า $r\gt\lambda$ แท่งเตี้ยลง เมื่อ $\lambda=3$ แท่ง 2 กับแท่ง 3 จึงสูงเท่ากันพอดีที่ 0.2240 ค่าที่มีโอกาสมากที่สุดจึงมีสองค่า คือ 2 กับ 3 ราย และไม่มีค่าไหนมีโอกาสเกิน 1 ใน 4 ตัวเลขชุดนี้คือความสูงของแท่งในรูปแรก (ปัดเหลือสามตำแหน่ง)

ขั้นที่ 5 — ค่าเฉลี่ยและ variance เท่ากับ λ ทั้งคู่

เราตั้ง $\lambda$ ให้เป็นจำนวนครั้งเฉลี่ยตั้งแต่แรก จึงควรตรวจว่าสูตรที่สร้างมาให้ค่าเฉลี่ย $\lambda$ จริง จากนั้นหา variance ด้วยวิธีเดียวกัน variance คือค่าเฉลี่ยของระยะห่างจากค่าเฉลี่ยยกกำลังสอง ใช้วัดว่าจำนวนรายแกว่งไปจากค่าเฉลี่ยมากแค่ไหน วิธีคือให้ตัวคูณ $r$ ไปตัดกับ $r!$ ที่ตัวส่วน

\[\begin{aligned} \mathbb E[X]&=\sum_{r=1}^{\infty}r\,\frac{\lambda^re^{-\lambda}}{r!}\\ &=\lambda\sum_{r=1}^{\infty}\frac{\lambda^{r-1}e^{-\lambda}}{(r-1)!}\\ &=\lambda\sum_{j=0}^{\infty}\frac{\lambda^{j}e^{-\lambda}}{j!}=\lambda\\[4pt] \mathbb E[X(X-1)]&=\sum_{r=2}^{\infty}r(r-1)\frac{\lambda^re^{-\lambda}}{r!}\\ &=\lambda^2\sum_{r=2}^{\infty}\frac{\lambda^{r-2}e^{-\lambda}}{(r-2)!}\\ &=\lambda^2\sum_{j=0}^{\infty}\frac{\lambda^{j}e^{-\lambda}}{j!}=\lambda^2\\[4pt] \mathrm{Var}(X)&=\mathbb E[X^2]-(\mathbb E[X])^2\\ &=\mathbb E[X(X-1)]+\mathbb E[X]-\lambda^2\\ &=\lambda^2+\lambda-\lambda^2=\lambda \end{aligned}\]

ผลคือค่าเฉลี่ยกับ variance ของ Poisson เท่ากับ $\lambda$ ทั้งคู่ ความคิดหลักคือทำให้ตัวคูณ $r$ หายไป เพราะ $r/r!=1/(r-1)!$ เมื่อตัดกันแล้ว ดึง $\lambda$ ออกมาได้หนึ่งตัว และเปลี่ยนตัวนับเป็น $j=r-1$ ผลรวมที่เหลือก็คือโอกาสของทุกค่ารวมกัน ซึ่งขั้นที่แล้วตรวจไว้ว่าได้ 1 พจน์ $r=0$ ตัดทิ้งได้ตั้งแต่ต้น เพราะคูณด้วยศูนย์

ตอนหา variance เราไม่คิด $X^2$ ตรง ๆ เพราะ $r^2$ ตัดกับ $r!$ ไม่ลงตัว แต่ $r(r-1)$ ตัดกับ $r!$ ได้สองชั้นพอดี จึงคิด $\mathbb E[X(X-1)]$ ก่อน แล้วค่อยเปลี่ยนกลับด้วย $X^2=X(X-1)+X$

standard deviation (SD) คือรากที่สองของ variance จึงเท่ากับ $\sqrt\lambda$ ที่ $\lambda=3$ ได้ $\sqrt3\approx1.73$ ราย ขนาดการแกว่งเทียบกับค่าเฉลี่ยคือ $\sqrt\lambda/\lambda=1/\sqrt\lambda$ ซึ่งเล็กลงเมื่อ $\lambda$ โต พอร์ตที่คาดว่าผิดนัด 100 ราย แกว่งราว $1/\sqrt{100}=10\%$ ของค่าเฉลี่ย แต่พอร์ตของเราที่คาดว่าผิดนัด 3 ราย แกว่งถึง $1/\sqrt3\approx58\%$

การที่ค่าเฉลี่ยเท่ากับ variance ยังใช้ตรวจข้อมูลจริงได้ด้วย ถ้านับเหตุการณ์จริงหลายปีแล้วพบว่า variance สูงกว่าค่าเฉลี่ยมาก แปลว่า Poisson อาจไม่เหมาะกับข้อมูลนั้น

ขั้นที่ 6 — แปลงจำนวนรายเป็นเงิน แล้วตอบคำถามเรื่องงบ

ตอนนี้มีสูตรครบแล้ว กลับมาตอบคำถามของหัวหน้า ก่อนอื่นต้องแปลงจำนวนรายเป็นเงิน ให้ $L$ เป็นเงินที่เสียเมื่อหนึ่งรายผิดนัด และสมมติว่าทุกรายเสียเท่ากัน ความเสียหายรวมทั้งปีคือ $S=LX$ เพราะ $L$ เป็นค่าคงที่ ค่าเฉลี่ยจึงคูณด้วย $L$ ได้ตรง ๆ คือ $\mathbb E[LX]=L\,\mathbb E[X]$ ส่วน variance คูณด้วย $L^2$ คือ $\mathrm{Var}(LX)=L^2\,\mathrm{Var}(X)$ SD จึงคูณด้วย $L$

ความเสียหายมาเป็นก้อนละ $L=\$3$ ล้าน ค่าที่ $S$ เป็นได้จึงมีแค่ \$0, \$3 ล้าน, \$6 ล้าน, \$9 ล้าน, \$12 ล้าน, … ความเสียหายจะเกิน \$9 ล้านก็ต่อเมื่อผิดนัดตั้งแต่ 4 รายขึ้นไป เราจึงเปลี่ยนคำถามเรื่องเงินเป็นคำถามเรื่องจำนวนราย แล้วคิดจากด้านตรงข้าม คือ 1 ลบโอกาสของ 0 ถึง 3 ราย โดย $\lambda^r/r!$ ของ $r=0,1,2,3$ คือ $1, 3, 4.5, 4.5$ และของ $r=4$ คือ $3^4/4!=81/24=3.375$

\[\begin{aligned} L&=\$5{,}000{,}000\times(1-0.40)\\ &=\$3{,}000{,}000\\[4pt] \mathbb E[S]&=L\,\lambda=\$3{,}000{,}000\times3\\ &=\$9{,}000{,}000\\ \mathrm{SD}(S)&=L\sqrt\lambda=\$3{,}000{,}000\times\sqrt3\\ &\approx\$5{,}196{,}152\\[4pt] P(S\gt\$9{,}000{,}000)&=P(X\ge4)\\ &=1-P(X\le3)\\ &=1-e^{-3}\big(1+3+4.5+4.5\big)\\ &=1-13e^{-3}\approx 35.28\%\\[4pt] P(S\ge\$15{,}000{,}000)&=P(X\ge5)\\ &=1-P(X\le4)\\ &=1-e^{-3}\big(13+3.375\big)\\ &=1-16.375e^{-3}\approx 18.47\% \end{aligned}\]

งบที่ตั้งเท่าค่าเฉลี่ย \$9 ล้าน จึงไม่พอราว 35 ปีใน 100 ปี หรือเกินหนึ่งในสามของปี และราว 18 ปีใน 100 ปี ความเสียหายจะสูงถึง \$15 ล้านขึ้นไป ขั้นที่ต้องดูคือการเปลี่ยน $S\gt\$9$ ล้าน เป็น $X\ge4$ ซึ่งทำได้เพราะ $S$ ขยับทีละก้อน \$3 ล้าน จึงไม่มีค่าระหว่าง \$9 ล้านกับ \$12 ล้าน

ทำไมค่าเฉลี่ยถึงต่ำไปสำหรับเป็นงบ เพราะ distribution นี้เบ้ขวา คือหางยาวไปทางขวา ฝั่งซ้ายของค่าเฉลี่ยถูกกั้นไว้ที่ศูนย์ราย ปีที่ดีที่สุดจึงเสียน้อยกว่าค่าเฉลี่ยได้ไม่เกิน \$9 ล้าน แต่ปีที่แย่เสียเกินค่าเฉลี่ยได้หลายเท่า

สมมติฐานว่า recovery คงที่ 40% ทำให้คิดง่าย แต่ในความจริง recovery มักต่ำลงในปีที่ผิดนัดกันมาก ความเสียหายในปีแย่จึงหนักกว่าที่คำนวณนี้อีก

ขั้นที่ 7 — ระดับความเสียหายที่ครอบคลุม 99% ของปี

งบเท่าค่าเฉลี่ยไม่พอบ่อยเกินไป แล้วควรตั้งเท่าไร ฝ่ายความเสี่ยงมักตั้งคำถามแบบนี้: “ระดับความเสียหายไหนที่ปีส่วนใหญ่ไม่เกิน คือไม่เกินราว 99 ปีจาก 100 ปี” ระดับนี้เรียกว่า quantile 99% ของความเสียหาย หาด้วยกติกาเดียวกับหน้า CDF: หาจำนวนรายที่น้อยที่สุด $k$ ที่โอกาสสะสม $P(X\le k)$ (โอกาสที่ผิดนัดไม่เกิน $k$ ราย) ถึง 0.99 แล้วคูณ $k$ ด้วย $L$

เริ่มจาก $P(X\le4)=16.375e^{-3}\approx0.81526$ ที่ได้ในขั้นที่แล้ว แล้วบวกแท่งถัดไปทีละแท่ง แท่ง 5 ราย $P(X=5)\approx0.10082$ มีอยู่แล้วจากขั้นที่ 4 แท่งที่เหลือคิดด้วยกฎเดียวกัน คือแท่งถัดไปเท่ากับแท่งก่อนคูณ $\lambda/r$

\[\begin{aligned} P(X=6)&=0.10082\times\tfrac36\approx0.05041\\ P(X=7)&=0.05041\times\tfrac37\approx0.02160\\ P(X=8)&=0.02160\times\tfrac38\approx0.00810\\[4pt] P(X\le 5)&=0.81526+0.10082=0.91608\\ P(X\le 6)&=0.91608+0.05041=0.96649\\ P(X\le 7)&=0.96649+0.02160=0.98809\\ P(X\le 8)&=0.98809+0.00810=0.99619\\[4pt] 0.98809&\lt0.99\le0.99619\\ k&=8\\ k\,L&=8\times\$3{,}000{,}000\\ &=\boxed{\$24{,}000{,}000} \end{aligned}\]

โอกาสสะสมถึง 7 รายได้ราว 0.9881 ยังไม่ถึง 0.99 พอนับถึง 8 รายได้ราว 0.9962 เกิน 0.99 แล้ว $k$ จึงเป็น 8 และระดับ 99% คือ \$24 ล้าน หรือ $24/9\approx2.7$ เท่าของค่าเฉลี่ย จำนวนรายขึ้นทีละหนึ่ง เราจึงหาระดับที่ให้ 99% พอดีไม่ได้ ต้องเลือกขั้นแรกที่ถึงหรือเกิน

ระดับนี้ไม่ใช่ความเสียหายสูงสุด ยังเหลือโอกาส $1-0.9962=0.38\%$ ที่จะผิดนัดเกิน 8 ราย และตัวเลขทั้งหมดนี้ถูกต้องเฉพาะเมื่อสมมติฐาน “แต่ละรายผิดนัดอิสระกัน” เป็นจริง

ขั้นที่ 8 — ตรวจกับ binomial จริง แล้วดูว่าเมื่อไร Poisson ใช้ไม่ได้

ขั้นนี้มีสองคำถาม คำถามแรก: ภายใต้สมมติฐานของโจทย์ คำตอบที่ตรงที่สุดคือ binomial ที่ $n=200$ และ $p=0.015$ เขียนย่อว่า $\mathrm{Bin}(200,0.015)$ Poisson ที่ใช้แทนมันพลาดไปเท่าไร ตัวเลขฝั่ง binomial ข้างล่างคิดด้วยสูตรจากหน้า binomial distribution คำถามที่สองสำคัญกว่า: ถ้าบริษัทไม่ได้ผิดนัดอิสระกันจริงล่ะ

ในโลกจริง เศรษฐกิจตัวเดียวกันกระทบทุกบริษัทพร้อมกัน ลองแบบจำลองง่าย ๆ ที่ปีหน้าเศรษฐกิจเป็นได้สองสภาพ (ตัวเลขสมมติ):

  • ปีปกติ เกิดด้วยโอกาส 60% ในปีแบบนี้ จำนวนรายผิดนัดเป็น Poisson ที่ค่าเฉลี่ย 1.5 ราย
  • ปีเศรษฐกิจถดถอย เกิดด้วยโอกาส 40% จำนวนรายผิดนัดเป็น Poisson ที่ค่าเฉลี่ย 5.25 ราย

ตัวเลข 5.25 เลือกมาให้ค่าเฉลี่ยรวมยังเป็น 3 เท่าเดิม คือ $0.6\times1.5+0.4\times5.25=0.9+2.1=3$ ความต่างจึงไม่ได้อยู่ที่ค่าเฉลี่ย แต่อยู่ที่การแกว่ง

variance ของแบบนี้คิดด้วย law of total variance: variance เฉลี่ยภายในแต่ละสภาพ บวกกับ variance ของค่าเฉลี่ยของสองสภาพรอบค่าเฉลี่ยรวม 3 ภายในแต่ละสภาพเป็น Poisson จึงมี variance เท่ากับค่าเฉลี่ยของสภาพนั้น

ส่วนโอกาสที่ผิดนัดตั้งแต่ 5 ราย ให้คิดแยกทีละสภาพด้วยสูตร Poisson เดิม ได้ราว 0.0186 เมื่อ $\lambda=1.5$ และราว 0.6022 เมื่อ $\lambda=5.25$ แล้วถ่วงด้วยโอกาสของแต่ละสภาพ

\[\begin{aligned} \mathrm{Bin}&:\ P(X=0)=0.985^{200}\approx4.87\%\\ &\quad\ P(X\ge5)\approx18.35\%\\ \mathrm{Poisson}&:\ P(X=0)=e^{-3}\approx4.98\%\\ &\quad\ P(X\ge5)\approx18.47\%\\[4pt] \mathrm{Var}(X)&=0.6(1.5)+0.4(5.25)\\ &\quad+0.6(1.5-3)^2+0.4(5.25-3)^2\\ &=3+1.35+2.025=6.375\\[4pt] P(X\ge5)&=0.6(0.0186)+0.4(0.6022)\\ &\approx25.20\% \end{aligned}\]

binomial กับ Poisson ต่างกันไม่ถึง 0.2 จุดเปอร์เซ็นต์ ($18.47-18.35=0.12$) การประมาณจึงไม่ใช่ปัญหา ปัญหาจริงอยู่ที่ independence ในแบบสองสภาพ เมื่อรู้แล้วว่าปีหน้าเป็นสภาพไหน การผิดนัดยังอิสระกัน เรียกว่า conditional independence แต่ตอนนี้เราไม่รู้ ปีที่แย่จึงมีหลายรายผิดนัดพร้อมกัน

ผลคือ variance ขึ้นจาก 3 เป็น 6.375 ทั้งที่ค่าเฉลี่ยเท่าเดิม 6.375 แยกได้เป็นสองส่วน: 3 มาจากการแกว่งภายในแต่ละสภาพ และ $1.35+2.025=3.375$ มาจากการที่ค่าเฉลี่ยของสองสภาพต่างกัน

หางขวาจึงหนักขึ้น โอกาสเสียตั้งแต่ \$15 ล้านขึ้นจาก 18.47% เป็น 25.20% ถ้าคิดโอกาสสะสมแบบเดียวกับขั้นที่ 7 จะได้ $P(X\le9)\approx0.9833$ ยังไม่ถึง 0.99 และ $P(X\le10)\approx0.9925$ ถึงแล้ว ระดับ 99% จึงขยับจาก 8 รายเป็น 10 ราย หรือ $10\times\$3$ ล้าน $=\$30$ ล้าน

แนวคิด “อิสระกันเมื่อรู้ปัจจัยร่วม” คือแกนของ conditional independence และ Gaussian copula ซึ่งเป็นแบบจำลองที่ตลาดใช้ตั้งราคาพอร์ตสินเชื่อมาจนถึงวิกฤตปี 2008

จุดที่พลาดแล้วได้คำตอบผิดโดยไม่รู้ตัว

ใช้ค่าเฉลี่ยเป็นงบ: งบที่เท่ากับ expected loss ไม่พอบ่อยเกินไป เพราะ distribution ของการนับที่ค่าเฉลี่ยเล็กเบ้ขวาเสมอ ผิด: งบ $=\lambda L=3\times\$3$ ล้าน $=\$9$ ล้าน ซึ่งไม่พอด้วยโอกาส $P(X\ge4)=1-13e^{-3}\approx35.3\%$ ถูก: ถ้าต้องการงบที่พอราว 99 ปีจาก 100 ปี ให้ใช้ quantile 99% คือ $k\,L=8\times\$3$ ล้าน $=\$24$ ล้าน

ใช้อัตราผิดช่วงเวลา: เอาอัตราต่อชั่วโมงมาใช้กับช่วงครึ่งชั่วโมงตรง ๆ alarm ดังเฉลี่ย 2 ครั้งต่อชั่วโมง ถามโอกาสที่ไม่ดังเลยตลอดครึ่งชั่วโมง ผิด: ใช้ $\lambda=2$ ได้ $e^{-2}\approx13.53\%$ ถูก: $\lambda=2\times0.5=1$ ได้ $e^{-1}\approx36.79\%$ ต่างกัน $e^{-1}/e^{-2}=e\approx2.7$ เท่า

อ่านแท่งเดียวแทนหาง: โอกาสของ “ตั้งแต่ 5 ราย” ต้องรวมทุกแท่งตั้งแต่ 5 รายขึ้นไป ไม่ใช่แท่ง 5 รายแท่งเดียว ผิด: $P(X=5)\approx10.08\%$ ถูก: $P(X\ge5)=1-P(X\le4)\approx1-0.8153=18.47\%$

เชื่อ independence ในจุดที่ไม่มี: Poisson และ binomial ต่างสมมติว่าแต่ละเหตุการณ์ไม่เกี่ยวกัน แต่การผิดนัด ระบบหลายตัวที่ล่มเพราะใช้โครงสร้างพื้นฐานเดียวกัน และคำสั่งขายตอนตลาดตื่นตระหนก ล้วนเกิดเป็นกลุ่ม ในแบบสองสภาพเศรษฐกิจข้างบน โอกาสเสียตั้งแต่ \$15 ล้านขึ้นจาก 18.47% (อิสระกัน) เป็น 25.20% (เกาะกลุ่ม) ทั้งที่ค่าเฉลี่ยเท่าเดิม ถ้าข้อมูลจริงมี variance สูงกว่าค่าเฉลี่ยมาก ให้สงสัยไว้ก่อนจะใช้หางของ Poisson

ใช้ทำอะไรบนโต๊ะจริง

ทีมที่ดูแลระบบซื้อขายต้องตัดสินใจว่าระบบควรรับคำสั่งได้กี่รายการต่อวินาที (วางแผนความจุ) สมมติว่าคำสั่งเข้ามาเฉลี่ย 20 รายการต่อวินาที และระบบรับได้ 25 รายการต่อวินาที ค่าเฉลี่ยต่ำกว่าความจุ แต่ก็ยังมีวินาทีที่คำสั่งล้น โอกาสนั้นคือ

\[\begin{aligned} P(X\gt25)&=1-\sum_{r=0}^{25}\frac{20^re^{-20}}{r!}\\ &\approx11.2\% \end{aligned}\]

ผลรวมนี้ยาว จึงให้คอมพิวเตอร์คิด (ดูโค้ดท้ายหน้า) ผลคือราว 1 วินาทีในทุก 9 วินาที ระบบจะรับไม่ทัน เพราะ $1/0.112\approx9$

ถ้าแต่ละคำสั่งถูกจับคู่ซื้อขายสำเร็จด้วยโอกาส 30% โดยไม่เกี่ยวกัน จำนวนคำสั่งที่สำเร็จต่อวินาทีก็เป็น Poisson เช่นกัน มีค่าเฉลี่ย $20\times0.3=6$ ผลนี้ได้จากการให้ indicator (ตัวแปรที่เป็น 1 เมื่อสำเร็จ และ 0 เมื่อไม่สำเร็จ) กับแต่ละคำสั่ง ดูPoisson thinning

ในด้านสินเชื่อ แนวคิด “อัตราการผิดนัดต่อหน่วยเวลา” ถูกพัฒนาต่อเป็น hazard rate (โอกาสผิดนัดต่อหน่วยเวลา ณ แต่ละช่วง) ซึ่งใช้ตั้งราคาหุ้นกู้และ CDS (credit default swap: สัญญาที่จ่ายชดเชยเมื่อบริษัทผิดนัด คล้ายประกัน) ดูdefaultable bonds และ hazard rates

ข้อ (ข) ถามหนึ่งชั่วโมง และคิดจากด้านตรงข้าม คือ 1 ลบโอกาสของ 0 ถึง 3 ครั้ง โดย $2^r/r!$ ของ $r=0,1,2,3$ คือ $1, 2, 2, \tfrac43$

\[\begin{aligned} \lambda&=2\times1=2\\ P(X\le3)&=e^{-2}\big(1+2+2+\tfrac43\big)\\ &=6.333e^{-2}\approx0.8571\\ P(X\ge4)&=1-0.8571\approx14.29\% \end{aligned}\]

2. พอร์ตหุ้นกู้เดิม 200 ราย แต่สมมติว่าถ้าบริษัทผิดนัด จะได้เงินคืนแค่ 20% แทน 40% สมมติฐานอื่นเท่าเดิมทั้งหมด expected loss โอกาสผิดนัดตั้งแต่ 5 ราย และระดับความเสียหาย 99% เปลี่ยนไปอย่างไร

\[\begin{aligned} L&=\$5{,}000{,}000\times(1-0.20)\\ &=\$4{,}000{,}000\\ \lambda L&=3\times\$4{,}000{,}000\\ &=\$12{,}000{,}000\\[4pt] P(X\ge5)&\approx18.47\%\\ 5L&=5\times\$4{,}000{,}000\\ &=\$20{,}000{,}000\\[4pt] k\,L&=8\times\$4{,}000{,}000\\ &=\$32{,}000{,}000 \end{aligned}\]

จำนวนคำสั่งที่สำเร็จเป็น Poisson เช่นกัน (Poisson thinning) ค่าเฉลี่ยหาได้ด้วย indicator: ถ้าวินาทีนั้นมีคำสั่ง $N$ รายการ จำนวนที่สำเร็จเฉลี่ยคือ $0.3N$ แล้วเฉลี่ยข้ามทุกค่าของ $N$

\[\begin{aligned} \lambda&=0.3\times20=6\\ P(X=0)&=e^{-6}\approx0.25\%\\ 1/e^{-6}&=e^{6}\approx403 \end{aligned}\]

ค่าเฉลี่ยคือ 6 รายการต่อวินาที และวินาทีที่ไม่มีคำสั่งไหนสำเร็จเลยเกิดราว 1 วินาทีในทุก 400 วินาที

เปิดดูโค้ด 
// PMF ของ Poisson ด้วยสูตรแท่งถัดไป = แท่งก่อน × λ / r
function poisson(lambda, last) {
  const p = [Math.exp(-lambda)];
  for (let r = 1; r <= last; r++) p.push(p[r - 1] * lambda / r);
  return p;
}
const p = poisson(3, 60);
const cdf = k => p.slice(0, k + 1).reduce((a, b) => a + b, 0);
console.log(p[0], p[3]);                 // 0.0498 0.2240
console.log(1 - cdf(3), 1 - cdf(4));     // 0.3528 0.1847
console.log(cdf(7), cdf(8));             // 0.9881 0.9962 → 8 ราย
const mean = p.reduce((s, v, r) => s + r * v, 0);
const varX = p.reduce((s, v, r) => s + r * r * v, 0) - mean ** 2;
console.log(mean, varX);                 // 3 3

console.log((1 - 3 / 200) ** 200, Math.exp(-3)); // 0.0487 0.0498

// แบบจำลองสองสภาพเศรษฐกิจ (สมมติ)
const good = poisson(1.5, 60), bad = poisson(5.25, 60);
const tail = (q, k) => 1 - q.slice(0, k).reduce((a, b) => a + b, 0);
console.log(0.6 * tail(good, 5) + 0.4 * tail(bad, 5)); // 0.2520

const orders = poisson(20, 80);
console.log(1 - orders.slice(0, 26).reduce((a, b) => a + b, 0)); // 0.1122

สิ่งที่ควรตอบได้หลังอ่าน

  • Poisson คือปลายทางของ binomial เมื่อจุดที่อาจเกิดมีมาก แต่ละจุดเกิดยาก และค่าเฉลี่ย $\lambda=np$ คงที่ สูตรคือ $P(X=r)=\lambda^re^{-\lambda}/r!$ ส่วน $\lambda$ ต้องเป็นจำนวนครั้งเฉลี่ยของช่วงเวลาที่ถามจริง
  • ค่าเฉลี่ยและ variance ของ Poisson เท่ากับ $\lambda$ ทั้งคู่ การแกว่งเทียบกับค่าเฉลี่ยจึงเป็น $\sqrt\lambda/\lambda=1/\sqrt\lambda$ ยิ่ง $\lambda$ เล็ก ยิ่งแกว่งมากเมื่อเทียบกับค่าเฉลี่ย
  • พอร์ตหุ้นกู้ตัวอย่างมี expected loss \$9 ล้าน แต่งบเท่านั้นไม่พอราว 35 ปีใน 100 ปี ($1-13e^{-3}\approx35.3\%$) ส่วนงบที่พอราว 99 ปีใน 100 ปีคือ \$24 ล้าน
  • ในตัวอย่างนี้ Poisson ต่างจาก binomial ไม่ถึง 0.2 จุดเปอร์เซ็นต์ ความเสี่ยงที่ใหญ่กว่าคือการที่บริษัทผิดนัดพร้อมกันเป็นกลุ่ม ซึ่งเพิ่ม variance และโอกาสของปีแย่ได้มาก ทั้งที่ค่าเฉลี่ยไม่เปลี่ยน

หน้าถัดไป Bayes' theorem กลับทิศคำถาม จากเดิมที่ถามว่า “ถ้ารู้แบบจำลอง ข้อมูลนี้เกิดได้บ่อยแค่ไหน” เป็น “เมื่อเห็นข้อมูลแล้ว ควรเชื่อแบบจำลองไหนมากขึ้นเท่าไร” นี่คือคำถามที่ค้างไว้ในหน้า binomial distribution ตอนประเมินผู้จัดการกองทุนที่ชนะตลาด 8 ปีจาก 10 ปี
