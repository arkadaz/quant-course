1.6 The Poisson Distribution

จากอัตราการเกิดเหตุการณ์ สู่โอกาสของจำนวนครั้งและจำนวนเงินที่เสีย

ระบบรับคำสั่งซื้อขายได้ 25 รายการต่อวินาที ส่วนคำสั่งเข้าเฉลี่ย 20 รายการต่อวินาที แค่นี้พอจะบอกได้ไหมว่าระบบรับไหว?

ยังไม่ได้ ค่าเฉลี่ยไม่บอกว่าคำสั่งเข้ากระจายสม่ำเสมอหรือมาเป็นชุด หากจำนวนคำสั่งในหนึ่งวินาทีเป็น Poisson ที่มีค่าเฉลี่ย 20 โอกาสที่จะเข้าเกิน 25 รายการอยู่ที่ประมาณ 11.22% แต่ถ้ารูปแบบการมาถึงต่างออกไป โอกาสนี้ก็เปลี่ยนได้

หัวข้อนี้จะสร้าง Poisson จาก Binomial ก่อน แล้วนำไปคำนวณการผิดนัดของพอร์ตหุ้นกู้ เราจะแยกให้ชัดระหว่าง “ขาดทุนเฉลี่ยเท่าไร” กับ “มีโอกาสขาดทุนเกินระดับที่กำหนดเท่าไร”

ต่างจาก Binomial ตรงไหน

Binomial เริ่มจากจำนวนครั้งทดลองที่กำหนดไว้ เช่นผู้กู้ 200 ราย แต่ละรายผิดนัดหรือไม่ผิดนัด ส่วน Poisson ใช้แบบจำลองของจำนวนเหตุการณ์ในช่วงที่กำหนด เช่นจำนวนคำสั่งในหนึ่งวินาที ซึ่งไม่มีจำนวนครั้งทดลองปรากฏอยู่ในสูตร

เขียน $X\sim\mathrm{Poisson}(\lambda)$ โดย $X$ เป็นจำนวนเหตุการณ์ และ $\lambda$ เป็นจำนวนเฉลี่ยในช่วงที่กำลังศึกษา ไม่ใช่ความน่าจะเป็น ดังนั้น $\lambda$ อาจมากกว่าหนึ่งได้ แต่ $X$ ต้องเป็นจำนวนเต็มไม่ติดลบ

การรู้ค่าเฉลี่ยเพียงอย่างเดียวไม่ได้พิสูจน์ว่า $X$ เป็น Poisson แบบจำลองการมาถึงที่เราจะใช้ยังต้องมีอัตราคงที่ จำนวนเหตุการณ์ในช่วงที่ไม่ทับกันเป็นอิสระ และโอกาสเกิดหลายเหตุการณ์ในช่วงสั้นมากต้องเล็กเมื่อเทียบกับความยาวช่วงนั้น

แยกอัตราต่อเวลาออกจากจำนวนเฉลี่ยในช่วง

อัตราที่กำหนดช่วงที่ถามค่า $\lambda$ ที่ต้องใส่ในสูตร
กริ่งเฉลี่ย 2 ครั้งต่อชั่วโมง1 ชั่วโมง$2\times1=2$
กริ่งเฉลี่ย 2 ครั้งต่อชั่วโมงครึ่งชั่วโมง$2\times0.5=1$
คำสั่งเฉลี่ย 20 รายการต่อวินาที0.1 วินาที$20\times0.1=2$

เมื่ออัตราคงที่ ใช้ $\lambda=\text{อัตรา}\times\text{ความยาวช่วง}$ โดยหน่วยเวลาต้องตรงกัน หากอัตราเปลี่ยนตามเวลา ต้องคำนวณจำนวนเฉลี่ยของช่วงนั้นให้เหมาะสมก่อน ไม่ใช้ค่าเฉลี่ยทั้งวันแทนทุกวินาทีโดยอัตโนมัติ

สร้างสูตรจากคำถามเล็ก: ทำไมบางชั่วโมงกริ่งจึงไม่ดังเลย

สมมติว่ากริ่งมีอัตรา 2 ครั้งต่อชั่วโมงตามเงื่อนไขข้างต้น แบ่งหนึ่งชั่วโมงเป็น $n$ ช่วงย่อย แล้วใช้แบบจำลองชั่วคราวที่แต่ละช่วงมีเหตุการณ์ได้ไม่เกินหนึ่งครั้ง ด้วยโอกาส $2/n$ อย่างเป็นอิสระ จำนวนครั้งรวมจึงเป็น Binomial ที่มีค่าเฉลี่ย 2

เมื่อแบ่งละเอียดขึ้น ข้อจำกัดไม่เกินหนึ่งครั้งต่อช่วงรบกวนแบบจำลองน้อยลง เราจะดูผลเมื่อ $n$ โตโดยคงจำนวนเฉลี่ยไว้ ไม่ใช่เพิ่มทั้งจำนวนช่วงและจำนวนเหตุการณ์เฉลี่ยไปพร้อมกัน

ขั้นที่ 1 — โอกาสไม่มีเหตุการณ์ในทุกช่วงย่อย

\[ \begin{aligned} P(X_n=0)&=\left(1-\frac{2}{n}\right)^n\\ n=60&:\quad P(X_n=0)\approx0.130799\\ n=3600&:\quad P(X_n=0)\approx0.135260\\ n\to\infty&:\quad P(X_n=0)\to e^{-2}\\ &\hspace{38pt}\approx0.135335 \end{aligned} \]

ผลลัพธ์เข้าใกล้ 13.53% ภายใต้แบบจำลองนี้ จึงมีชั่วโมงที่เงียบได้แม้ค่าเฉลี่ยเป็นสองครั้ง การเงียบหนึ่งชั่วโมงไม่พิสูจน์ว่ากริ่งเสีย แต่ก็ไม่ใช่หลักฐานยืนยันว่ากริ่งยังทำงาน ต้องแยกคำถามทางสถิติออกจากการตรวจอุปกรณ์

ขั้นที่ 2 — อธิบายเลข $e$ ที่ปรากฏในคำตอบ

Exponential มีสมบัติ $e^a=\lim_{n\to\infty}(1+a/n)^n$ ซึ่งใช้เป็นนิยามได้ เมื่อแทน $a=-\lambda$ จะได้ขีดจำกัดในขั้นแรก อีกทางหนึ่งใช้ natural logarithm และสมบัติความชันของ $\ln$ ใกล้ 1 ดังนี้

\[ \begin{aligned} \lim_{u\to0}\frac{\ln(1-u)}{u}&=-1\\ n\ln\left(1-\frac{\lambda}{n}\right) &=\lambda\frac{\ln(1-\lambda/n)}{\lambda/n}\\ &\longrightarrow-\lambda\\ \left(1-\frac{\lambda}{n}\right)^n&\longrightarrow e^{-\lambda} \end{aligned} \]

บรรทัดแรกใช้ความชันของ logarithm ที่จุด 1 และเครื่องหมายลบจาก $1-u$ ถ้ายังไม่เรียนอนุพันธ์ ให้ใช้ค่านิยามขีดจำกัดและตารางในขั้นแรกก่อน ส่วนนี้อธิบายที่มาของสูตร ไม่จำเป็นต้องคำนวณขีดจำกัดใหม่ทุกครั้งที่ใช้ Poisson

ขั้นที่ 3 — จากศูนย์ครั้ง ไปสู่โอกาสเกิดพอดี $r$ ครั้ง

เริ่มจาก $X_n\sim\mathrm{Binomial}(n,\lambda/n)$ แล้วตรึง $r$ ไว้ขณะเพิ่ม $n$ แยกตัวประกอบเพื่อดูขีดจำกัดทีละส่วน

\[ \begin{aligned} P(X_n=r)&=\binom nr\left(\frac{\lambda}{n}\right)^r \left(1-\frac{\lambda}{n}\right)^{n-r}\\ &=\frac{\lambda^r}{r!}\,A_nB_nC_n\\ A_n&=\prod_{j=0}^{r-1}\left(1-\frac jn\right)\longrightarrow1\\ B_n&=\left(1-\frac{\lambda}{n}\right)^n\longrightarrow e^{-\lambda}\\ C_n&=\left(1-\frac{\lambda}{n}\right)^{-r}\longrightarrow1\\ P(X=r)&=\boxed{\frac{\lambda^r e^{-\lambda}}{r!}},\quad r=0,1,2,\ldots \end{aligned} \]

$A_n$ มาจากการกาง $\binom nr$ แล้วหารด้วย $n^r$ ส่วน $B_n$ คือโอกาสศูนย์ครั้งที่หาแล้ว และ $C_n$ ชดเชยกำลัง $n-r$ ให้ตรงกับสูตรเดิม เมื่อ $r$ คงที่ แต่ละตัวประกอบใน $A_n$ และ $C_n$ เข้าใกล้หนึ่ง

สูตรนี้คือ Poisson PMF สำหรับ $\lambda\gt0$ ถ้า $\lambda=0$ แบบจำลองเป็นกรณีแน่นอนว่า $X=0$ ด้วยโอกาสหนึ่ง ไม่มีเหตุการณ์เกิดขึ้น จึงไม่ต้องจัดการนิพจน์ $0^0$ เอง

ขั้นที่ 4 — ตรวจว่า PMF รวมได้หนึ่ง และคำนวณแท่งถัดไป

อนุกรมของ exponential คือ $e^a=\sum_{r=0}^{\infty}a^r/r!$ จึงใช้ตรวจผลรวมของ PMF ได้ ส่วนการคำนวณหลายแท่งติดกันไม่ต้องเริ่มยกกำลังและหา factorial ใหม่ทุกแท่ง

\[ \begin{aligned} \sum_{r=0}^{\infty}P(X=r) &=e^{-\lambda}\sum_{r=0}^{\infty}\frac{\lambda^r}{r!}\\ &=e^{-\lambda}e^\lambda=1\\[3pt] \frac{P(X=r)}{P(X=r-1)}&=\frac{\lambda}{r},\quad r\ge1\\ P(X=0)&=e^{-\lambda}\\ P(X=r)&=P(X=r-1)\frac{\lambda}{r} \end{aligned} \]

เมื่อ $\lambda=3$ เริ่มจาก $e^{-3}\approx0.049787$ แล้วคูณด้วย 3, 3/2, 3/3, 3/4 ตามลำดับ จึงได้แท่งที่ 1, 2, 3, 4 วิธีนี้ช่วยทั้งคำนวณและตรวจคำตอบด้วยเครื่องคิดเลข

ลองใช้สูตรกับกริ่งก่อนเข้าสู่พอร์ตหุ้นกู้

โจทย์ให้อะไรมาบ้าง: จำนวนครั้งในหนึ่งชั่วโมงเป็น Poisson ที่ $\lambda=2$ ต้องการโอกาสดังพอดีสองครั้ง และอย่างน้อยสี่ครั้ง

พอดีสองครั้ง: $P(X=2)=2^2e^{-2}/2!=2e^{-2}\approx27.07\%$

อย่างน้อยสี่ครั้ง: รวมแท่งศูนย์ถึงสามก่อน ได้ $e^{-2}(1+2+2+4/3)\approx0.857123$ แล้วลบจากหนึ่ง จึงได้ประมาณ 14.29%

ตรวจเองใน 10 วินาที: ค่าเฉลี่ยสองครั้งไม่ได้แปลว่าส่วนใหญ่ต้องดังพอดีสองครั้ง และ 14.29% ไม่เท่ากับโอกาสเงียบ 13.53% แม้ทั้งสองค่าจะใกล้กัน

โจทย์หลัก: พอร์ตผิดนัดน้อยราย แต่แต่ละรายเสียเงินมาก

พอร์ตตัวอย่างถือหุ้นกู้ของบริษัทต่างกัน 200 ราย สมมติว่ารายหนึ่งมีโอกาสผิดนัดในหนึ่งปี 1.5% เท่ากันทุกรายและเป็นอิสระกัน แต่ละรายมีเงินต้นที่เสี่ยง \$5 ล้าน หากผิดนัดจะได้เงินคืน 40% แบบคงที่ ตัวเลขนี้เป็นสมมติฐานเพื่อฝึกคำนวณ ไม่ใช่ค่าประเมินเครดิตจริง

จำนวนรายผิดนัดตามสมมติฐานเป็น Binomial(200, 0.015) เราจะลองประมาณด้วย Poisson โดยใช้ค่าเฉลี่ยเดียวกัน แล้วตรวจความคลาดเคลื่อนกับ Binomial ภายหลัง

ขั้นที่ 5 — เตรียมจำนวนเฉลี่ยและความเสียหายต่อราย

ให้ $L$ เป็นจำนวนเงินที่เสียต่อหนึ่งราย และ $S=LX$ เป็นความเสียหายรวม ในที่นี้ LGD หมายถึงสัดส่วนที่เสียหลังหัก recovery ไม่ใช่จำนวนเงิน $L$

\[ \begin{aligned} \lambda&=np=200(0.015)=3\\ \mathrm{LGD}&=1-0.40=0.60\\ L&=\$5{,}000{,}000(0.60)=\$3{,}000{,}000\\ S&=LX=\$3{,}000{,}000\,X \end{aligned} \]

สามรายเป็นจำนวนเฉลี่ยในหนึ่งปี ส่วนสามล้านดอลลาร์เป็นความเสียหายต่อราย ห้ามนำสองเลขนี้มาใช้สลับกัน เราสมมติเงินที่เสี่ยงและ recovery คงที่ หากสองส่วนนี้สุ่มด้วย ต้องเพิ่มแบบจำลองความเสียหาย ไม่ใช่นับจำนวนรายอย่างเดียว

ขั้นที่ 6 — ตอบโอกาสศูนย์ราย สามราย และตั้งแต่ห้าราย

\[ \begin{aligned} P(X=0)&=e^{-3}\approx4.9787\%\\ P(X=3)&=\frac{3^3e^{-3}}{3!}\approx22.4042\%\\[3pt] P(X\le4)&=e^{-3}\left(1+3+\frac92+\frac{27}{6}+\frac{81}{24}\right)\\ &=16.375e^{-3}\approx0.815263\\ P(X\ge5)&=1-P(X\le4)\\ &\approx\boxed{18.4737\%} \end{aligned} \]

ห้ารายขึ้นไปทำให้เสียตั้งแต่ \$15 ล้านขึ้นไป ดังนั้นภายใต้ค่าประมาณนี้ โอกาสขาดทุนถึงระดับนั้นอยู่ที่ 18.47% ต่อปี ไม่ได้หมายความว่าจะเกิดตรงทุกห้าปี และไม่ใช่โอกาสผิดนัดของบริษัทหนึ่งซึ่งโจทย์ให้ไว้ที่ 1.5%

ขั้นที่ 7 — พิสูจน์ว่าค่าเฉลี่ยของ Poisson เท่ากับ $\lambda$

ใช้ค่าเฉลี่ยแบบถ่วงน้ำหนักจากหัวข้อ 1.3 ตัวคูณ $r$ ตัดกับ factorial ได้หนึ่งชั้น ส่วนพจน์ศูนย์ไม่ส่งผลต่อค่าเฉลี่ย

\[ \begin{aligned} \mathbb E[X]&=\sum_{r=1}^{\infty}r\frac{\lambda^re^{-\lambda}}{r!}\\ &=\lambda e^{-\lambda}\sum_{r=1}^{\infty}\frac{\lambda^{r-1}}{(r-1)!}\\ &=\lambda e^{-\lambda}\sum_{k=0}^{\infty}\frac{\lambda^k}{k!}\\ &=\lambda e^{-\lambda}e^\lambda=\lambda \end{aligned} \]

เปลี่ยนตัวนับจาก $r$ เป็น $k=r-1$ เพื่อให้เห็นอนุกรมเดิมจากขั้นที่ 4 ชัดขึ้น ไม่ได้เปลี่ยนค่าในผลรวม เมื่อใช้ $\lambda=3$ จึงได้จำนวนรายเฉลี่ยสามรายตามที่ตั้งแบบจำลองไว้

ขั้นที่ 8 — พิสูจน์ variance โดยเริ่มจาก $X(X-1)$

$r(r-1)$ ตัดกับ factorial ได้สองชั้น จากนั้นใช้ $X^2=X(X-1)+X$ เพื่อกลับไปหาค่าเฉลี่ยกำลังสอง

\[ \begin{aligned} \mathbb E[X(X-1)]&=\sum_{r=2}^{\infty}\frac{\lambda^re^{-\lambda}}{(r-2)!}\\ &=\lambda^2e^{-\lambda}\sum_{k=0}^{\infty}\frac{\lambda^k}{k!}=\lambda^2\\ \mathbb E[X^2]&=\lambda^2+\lambda\\ \mathrm{Var}(X)&=(\lambda^2+\lambda)-\lambda^2=\lambda\\ \mathrm{SD}(X)&=\sqrt\lambda\\ \lambda=3&:\quad\mathrm{SD}(X)=\sqrt3\approx1.7321 \end{aligned} \]

Poisson มีค่าเฉลี่ยและ variance เท่ากันในเชิงตัวเลข แต่มีหน่วยต่างกัน ค่าเฉลี่ยเป็นจำนวนครั้ง ส่วน variance เป็นครั้ง² และ standard deviation กลับมาเป็นจำนวนครั้งเหมือนเดิม

ขั้นที่ 9 — เปลี่ยนจำนวนรายเป็นความเสียหายเฉลี่ยและความผันผวน

\[ \begin{aligned} \mathbb E[S]&=L\mathbb E[X]\\ &=\$3{,}000{,}000(3)=\boxed{\$9{,}000{,}000}\\ \mathrm{Var}(S)&=L^2\mathrm{Var}(X)\\ \mathrm{SD}(S)&=L\sqrt\lambda\\ &=\$3{,}000{,}000\sqrt3\\ &\approx\$5{,}196{,}152 \end{aligned} \]

เงินเก้าล้านดอลลาร์คือ expected loss ตามสมมติฐาน ไม่ใช่ขาดทุนสูงสุด และ standard deviation ประมาณ 5.20 ล้านไม่ใช่ขอบเขตที่รับรองว่าความเสียหายต้องอยู่ภายใน แบบจำลองนี้ไม่ใช่ Normal จึงไม่ควรนำกฎช่วง 68–95–99.7% มาใช้ทันที

Expected loss ไม่ใช่คำสั่งให้ตั้งสำรองหรือกันเงินสดเท่าตัวเลขนี้

Provision เป็นรายการทางบัญชีที่ต้องพิจารณามาตรฐานและวิธีประเมินที่ใช้ ส่วนเงินกองทุนและสภาพคล่องมีวัตถุประสงค์และเกณฑ์ของตนเอง คำว่า reserve ก็อาจมีความหมายต่างกันในแต่ละบริบท จึงไม่ควรสรุปจากโจทย์นี้ว่าต้องกันเงินสดเก้าล้านดอลลาร์ตามกฎจริง

สิ่งที่คำนวณได้แน่นอนภายใต้สมมติฐานคือ expected loss เก้าล้านดอลลาร์ และ distribution ของความเสียหายตามแบบจำลอง หากต้องการระดับรองรับความเสียหาย ต้องระบุโอกาสเป้าหมายและช่วงเวลาด้วย

Worked Example — หาระดับความเสียหายที่ครอบคลุมอย่างน้อย 99%

ของที่มี: $X\sim\mathrm{Poisson}(3)$ และเสีย \$3 ล้านต่อราย ต้องการจำนวนเต็มที่น้อยที่สุด $k$ ซึ่งทำให้ $P(X\le k)\ge0.99$ นี่คือ quantile ไม่ใช่ค่าเฉลี่ย

รวม PMF ตั้งแต่ศูนย์ถึงเจ็ดได้ $P(X\le7)\approx0.988095$ ซึ่งยังไม่ถึงเป้า เมื่อเพิ่มแท่งแปดได้ $P(X\le8)\approx0.996197$ จึงได้คำตอบ $k=8$

ระดับความเสียหายที่ตรงกันคือ $8\times\$3$ ล้าน = \$24 ล้าน ครอบคลุมประมาณ 99.62% ไม่ใช่ 99% พอดี เพราะจำนวนรายเพิ่มทีละจำนวนเต็ม

ตรวจเองใน 10 วินาที: หากตอบ \$21 ล้าน จะรองรับเพียงเจ็ดรายซึ่งยังไม่ถึง 99% และ \$24 ล้านก็ไม่ใช่ขาดทุนสูงสุด Poisson ยังให้โอกาสผิดนัดเกินแปดราย

ตรวจค่าประมาณกับ Binomial ที่ตรงสมมติฐานพอร์ต

ใช้ $P(X=r)=\binom{200}{r}(0.015)^r(0.985)^{200-r}$ สำหรับคอลัมน์ Binomial กรณีศูนย์ราย Poisson สูงกว่าโดยประมาณ 0.112 จุดเปอร์เซ็นต์ หรือ 2.30% เมื่อเทียบกับค่า Binomial ต้องบอกให้ชัดว่ารายงานความต่างแบบไหน

ตรงกับสมมติฐาน ไม่ได้แปลว่าตรงกับโลกจริง

Binomial เป็นคำตอบตรงภายใต้จำนวนราย โอกาสรายละเท่ากัน และ independence ที่กำหนดไว้ ไม่ใช่ “ค่าจริงของตลาด” ส่วน Poisson เป็นค่าประมาณอีกชั้นหนึ่ง แม้โอกาสหลายข้อจะใกล้กัน ก็ยังต้องตรวจสมมติฐานร่วมของทั้งสองแบบ

อีกความต่างคือ Binomial ให้ผิดนัดได้ไม่เกิน 200 ราย ขณะที่ Poisson ไม่มีเพดานจำนวนครั้ง แม้โอกาสเกิน 200 จะเล็กมากในตัวอย่างนี้ แต่ข้อจำกัดทางกายภาพยังอยู่ การประมาณไม่ได้ลบข้อจำกัดนั้นออกจากโจทย์จริง

เมื่อข้อมูลไม่เหมือน Poisson ให้ตรวจอะไรต่อ

สิ่งที่เห็นคำถามที่ควรตรวจ
ช่วงเปิดตลาดมีคำสั่งมากกว่าช่วงกลางวันนำช่วงที่มีอัตราต่างกันมารวมเป็นค่าเฉลี่ยเดียวหรือไม่?
เหตุการณ์ตามกันมาเป็นชุดมีปัจจัยร่วม เหตุการณ์หนึ่งกระตุ้นอีกเหตุการณ์ หรือการส่งเป็นกลุ่มหรือไม่?
Variance ของตัวอย่างสูงกว่าค่าเฉลี่ยมากเกิดจากอัตราเปลี่ยน ข้อมูลปะปน dependence หรือความคลาดเคลื่อนจากตัวอย่างขนาดเล็ก?
ค่าเฉลี่ยกับ variance ใกล้กันPMF และโอกาสหางเข้ากันด้วยหรือไม่? ความใกล้กันของสอง moment ยังพิสูจน์ distribution ไม่ได้

การเปรียบเทียบ variance กับค่าเฉลี่ยเป็นสัญญาณให้ตรวจต่อ ไม่ใช่การทดสอบที่ชี้ขาดทันที และ variance สูงไม่ได้แปลว่าโอกาสเกินทุกเกณฑ์ต้องสูงขึ้นเสมอ

ทำไม Poisson(3) มีแท่งสูงสุดสองแท่ง

จากอัตราส่วน $P(X=r)/P(X=r-1)=\lambda/r$ แท่งจะสูงขึ้นเมื่อ $r\lt\lambda$ เท่ากันเมื่อ $r=\lambda$ และลดลงเมื่อ $r\gt\lambda$ ที่ $\lambda=3$ แท่งสองกับสามจึงสูงเท่ากันประมาณ 22.40% ทั้งคู่เป็น mode

โดยทั่วไป ถ้า $\lambda$ ไม่เป็นจำนวนเต็ม mode คือจำนวนเต็มที่ปัด $\lambda$ ลง หาก $\lambda$ เป็นจำนวนเต็มบวกจะมีสอง mode คือ $\lambda-1$ กับ $\lambda$ ส่วนกรณี $\lambda=0$ มีเพียงศูนย์

ส่วนต่อยอด: เก็บ moment หลายลำดับไว้ใน function เดียว

ส่วนนี้ใช้อนุพันธ์ หากยังไม่เรียนสามารถกลับมาอ่านภายหลังได้ วิธีหาค่าเฉลี่ยและ variance ข้างต้นยังสมบูรณ์ด้วยตัวเอง Moment Generating Function หรือ MGF นิยามว่า $M_X(t)=\mathbb E[e^{tX}]$ เมื่อ expectation นี้มีค่าจำกัดในช่วงรอบศูนย์

เหตุผลที่อนุพันธ์ดึง moment ออกมาได้คืออนุพันธ์ลำดับที่ $k$ ของ $e^{tX}$ เท่ากับ $X^ke^{tX}$ เมื่อแทน $t=0$ จึงเหลือ $X^k$ สำหรับ Poisson สามารถสลับการหาอนุพันธ์กับ expectation ได้ และ MGF มีค่าจำกัดสำหรับ $t$ จริงทุกค่า

ขั้นที่ 10 — สร้าง MGF แล้วตรวจ moment เดิม

\[ \begin{aligned} M_X(t)&=e^{-\lambda}\sum_{r=0}^{\infty}\frac{(\lambda e^t)^r}{r!}\\ &=e^{-\lambda}e^{\lambda e^t}=e^{\lambda(e^t-1)}\\ M'_X(t)&=\lambda e^tM_X(t)\\ M''_X(t)&=[\lambda e^t+(\lambda e^t)^2]M_X(t)\\ M'''_X(t)&=[\lambda e^t+3(\lambda e^t)^2+(\lambda e^t)^3]M_X(t)\\[3pt] M'_X(0)&=\lambda\\ M''_X(0)&=\lambda+\lambda^2\\ M'''_X(0)&=\lambda+3\lambda^2+\lambda^3\\ \lambda=3&:\quad\mathbb E[X^3]=3+27+27=57 \end{aligned} \]

แถว MGF ใช้อนุกรม exponential เดิมโดยเปลี่ยนจาก $\lambda$ เป็น $\lambda e^t$ ส่วนแถวอนุพันธ์ใช้ product rule และ chain rule ผลสองลำดับแรกตรงกับการบวก PMF ที่พิสูจน์แล้ว ลำดับสามเป็น raw moment ไม่ใช่ skewness โดยตรง

ลองทำเอง — เปลี่ยนช่วงเวลาและเปลี่ยน recovery

ข้อแรก: กริ่งมีอัตราคงที่สองครั้งต่อชั่วโมงตามแบบจำลองเดิม โอกาสเงียบตลอดครึ่งชั่วโมงเป็นเท่าไร? ข้อสอง: พอร์ตเดิมได้ recovery 20% แทน 40% โดยคงสมมติฐานอื่น โอกาสผิดนัดอย่างน้อยห้ารายและ expected loss เปลี่ยนอย่างไร?

เปิดคำตอบพร้อมเหตุผล

ครึ่งชั่วโมงใช้ $\lambda=2(0.5)=1$ จึงมีโอกาสศูนย์ครั้ง $e^{-1}\approx36.79\%$ ห้ามใส่สองเพียงเพราะอัตราที่ให้มาคือสองต่อชั่วโมง

Recovery ใหม่ทำให้ $L=(1-0.20)\$5$ ล้าน = \$4 ล้าน expected loss จึงเป็น \$12 ล้าน ส่วนโอกาสผิดนัดอย่างน้อยห้ารายยังประมาณ 18.47% เท่าเดิม เพราะ distribution ของจำนวนรายไม่เปลี่ยน แต่เหตุการณ์นั้นทำให้เสียตั้งแต่ \$20 ล้านแทน \$15 ล้าน

ตรวจ PMF, CDF และโจทย์พอร์ตด้วย JavaScript 
function poisson(lambda, last) {
  const p = [Math.exp(-lambda)];
  for (let r = 1; r <= last; r++) p.push(p[r - 1] * lambda / r);
  return p;
}
const p = poisson(3, 80);
const cdf = k => p.slice(0, k + 1).reduce((a, b) => a + b, 0);
const mean = p.reduce((s, v, r) => s + r * v, 0);
const second = p.reduce((s, v, r) => s + r * r * v, 0);
console.log(p[0]);                          // 0.049787068...
console.log(p[3]);                          // 0.224041808...
console.log(1 - cdf(4));                    // 0.184736755...
console.log([mean, second - mean ** 2]);     // ประมาณ [3, 3]
console.log([cdf(7), cdf(8)]);               // [0.988095496..., 0.996197008...]
console.log(3_000_000 * mean);               // ประมาณ 9000000
const orders = poisson(20, 25);
console.log(1 - orders.reduce((a, b) => a + b, 0)); // 0.112184973...

การบวกถึง 80 เป็นการตัดอนุกรมเพื่อคำนวณ ไม่ใช่การพิสูจน์ผลรวมอนันต์ พอเพียงสำหรับความแม่นยำที่แสดงเมื่อ $\lambda=3$ แต่โค้ดนี้ไม่ใช่ตัวคำนวณสำหรับทุกพารามิเตอร์ โดยเฉพาะค่าเฉลี่ยใหญ่มากหรือหางเล็กมากที่ต้องใช้วิธีรักษาเสถียรภาพเชิงตัวเลข

สรุป — นับเหตุการณ์ก่อน แล้วค่อยแปลงเป็นผลกระทบ

  • Poisson เป็นแบบจำลอง ไม่ได้ตามมาจากการรู้ค่าเฉลี่ยอย่างเดียว ต้องตรวจเงื่อนไขการเกิดเหตุการณ์และช่วงเวลาที่ใช้
  • สูตร $P(X=r)=\lambda^re^{-\lambda}/r!$ มาจาก Binomial เมื่อเพิ่มจำนวนครั้ง ลดโอกาสต่อครั้ง และคง $np=\lambda$ ไว้
  • ค่าเฉลี่ยและ variance เท่ากับ $\lambda$ ส่วน standard deviation เท่ากับ $\sqrt\lambda$ ทั้งสามคำมีความหมายและหน่วยต่างกัน
  • พอร์ตตัวอย่างมี expected loss \$9 ล้าน แต่ Poisson approximation ให้โอกาสเสียตั้งแต่ \$15 ล้านประมาณ 18.47% ค่าเฉลี่ยจึงไม่ใช่ระดับรองรับปีที่แย่
  • ระดับขาดทุน 99% ตามแบบจำลองนี้เท่ากับ \$24 ล้าน ไม่ใช่ข้อกำหนดเงินสำรองจริง และไม่คุ้มครองความผิดพลาดของสมมติฐาน

หัวข้อถัดไปเปลี่ยนทิศทางคำถาม จาก “เมื่อรู้แบบจำลองแล้ว ข้อมูลนี้เกิดได้แค่ไหน” เป็น “เมื่อเห็นข้อมูลแล้ว ควรปรับความเชื่อเรื่องแบบจำลองอย่างไร” ด้วย Bayes' theorem
