7.6 Eigenvalues and Positive Definiteness

eigenvector คือทิศที่ matrix ไม่หมุน แค่ยืดด้วยตัวคูณ eigenvalue และ covariance matrix ใช้ได้จริงก็ต่อเมื่อตัวยืดทุกตัวไม่ติดลบ ซึ่งคือ positive semidefinite

นักลงทุนคนหนึ่งไม่อยากถือหุ้นตัวเดียว เพราะกลัวราคาแกว่งแรง เขาจึงแบ่งเงินเท่า ๆ กันซื้อหุ้นธนาคารสหรัฐสามตัว คือ JPM (JPMorgan), BAC (Bank of America) และ WFC (Wells Fargo) เขาหวังว่าพอร์ต (เงินลงทุนทั้งก้อนที่แบ่งไว้ในหลายตัว) จะแกว่งน้อยกว่าหุ้นตัวเดียวมาก

ของที่รู้ (ตัวเลขสมมติ):

  • ความผันผวนของหุ้นแต่ละตัว $\sigma=25\%$ ต่อปี ความผันผวนคือ SD (standard deviation) ของผลตอบแทน บอกว่าผลตอบแทนรายปีมักแกว่งห่างจากค่าเฉลี่ยราวกี่เปอร์เซ็นต์ (ดู Variance and Standard Deviation)
  • correlation ของทุกคู่ $\rho=0.7$ correlation วัดว่าสองตัวขึ้นลงพร้อมกันแค่ไหน มีค่าตั้งแต่ −1 ถึง 1 ค่า 0.7 แปลว่าส่วนใหญ่ขึ้นลงไปทางเดียวกัน (ดู Inner Product, Angle, and Correlation)
  • น้ำหนักของแต่ละตัว $w=\tfrac13$ คือลงเงินตัวละหนึ่งในสามของเงินทั้งหมด

เพื่อนคนหนึ่งจำสูตรมาว่า ถ้าแบ่งเงินเท่ากันใน $n$ ตัว ความผันผวนจะหารด้วย $\sqrt n$ จึงคิดว่าพอร์ตนี้ผันผวน $\sigma/\sqrt3=25\%/1.732\approx14.43\%$ ต่อปี

ตัวเลข 14.43% ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก สูตรหารด้วย $\sqrt n$ ใช้ได้เฉพาะเมื่อหุ้นไม่เกี่ยวกันเลย ($\rho=0$) ที่นี่ต้องคิด variance ของพอร์ตตรง ๆ variance คือความผันผวนยกกำลังสอง $\sigma^2=0.25^2=0.0625$ และ covariance ของแต่ละคู่คือ $\rho\sigma^2$ พอร์ตมีสามพจน์ที่หุ้นจับคู่กับตัวเอง และหกพจน์ที่จับคู่กับตัวอื่น (สามคู่ นับสองรอบ) ทุกพจน์คูณน้ำหนัก $w\times w=\tfrac19$

\[\begin{aligned} \operatorname{Var}&=\tfrac19\big(3\sigma^2+6\rho\sigma^2\big)=\frac{\sigma^2(1+2\rho)}{3}\\ &=\frac{0.0625(1+1.4)}{3}=\frac{0.15}{3}=0.05,\\ \sigma_p&=\sqrt{0.05}\approx22.36\%. \end{aligned}\]

ความผันผวนของพอร์ต $\sigma_p$ ลดจาก 25% เหลือ 22.36% เท่านั้น ไม่ใช่ 14.43% ทำไมแบ่งเงินแล้วลดได้น้อยแบบนี้ หน้านี้จะตอบด้วยภาพ หุ้นสามตัวนี้มี “ทิศ” หนึ่งที่ทั้งสามขึ้นลงพร้อมกัน ทิศนี้แบก variance ไว้มาก และพอร์ตเงินเท่ากันวางตัวอยู่บนทิศนั้นพอดี การแบ่งเงินจึงหนีความเสี่ยงที่ทั้งสามมีร่วมกันไม่ได้เลย ขั้นสามธนาคารท้ายหน้าจะคำนวณขนาดของทิศนี้ให้ดู

ภาพรวมก่อนลงสูตร

ความเสี่ยงของหุ้นหลายตัวเก็บอยู่ในตารางเดียว เรียกว่า covariance matrix ช่องแนวทแยงคือ variance ของแต่ละตัว ช่องอื่นคือ covariance ของแต่ละคู่ (ตัวเลขที่บอกว่าสองตัวขึ้นลงด้วยกันแค่ไหน) ตารางนี้สมมาตร เพราะ covariance ของ A กับ B เท่ากับของ B กับ A คำถามใน hook จึงกลายเป็นคำถามเรื่อง matrix ว่า matrix นี้ “ยืด” ทิศไหนมากที่สุด

ลองนึกภาพ matrix $2\times2$ หนึ่งตัว เอามันคูณลูกศรยาวหนึ่งหน่วยทุกทิศรอบวงกลม ลูกศรส่วนใหญ่ถูกทั้งยืดและหมุน แต่มีบางทิศที่ลูกศรไม่หมุนเลย แค่ยาวขึ้นหรือสั้นลง ทิศพิเศษนี้เรียกว่า eigenvector และตัวคูณความยาวเรียกว่า eigenvalue ถ้า matrix สมมาตร ทิศพิเศษเหล่านี้ตั้งฉากกันเสมอ และเป็นแกนยาวกับแกนสั้นของวงรีที่วงกลมถูกยืดไปเป็น ดังรูปด้านล่าง

กับ covariance ภาพนี้มีความหมายเรื่องเงินตรง ๆ eigenvector คือพอร์ตแบบหนึ่ง และ eigenvalue คือ variance ของพอร์ตนั้น พอร์ตจากทิศต่างกันขึ้นลงไม่เกี่ยวกันเลย (covariance เป็นศูนย์) ทิศที่ eigenvalue ใหญ่คือความเสี่ยงร่วมที่แบ่งเงินแล้วก็ไม่หาย ทิศที่ eigenvalue เล็กมากคือที่ที่ optimizer (โปรแกรมที่หาน้ำหนักพอร์ตที่ “ดีที่สุด” ให้อัตโนมัติ) ชอบทุ่มเงินลงไป และถ้ามี eigenvalue ติดลบ ตารางนั้นใช้เป็น covariance ไม่ได้ เพราะจะมีพอร์ตที่ variance ติดลบ ซึ่งเป็นไปไม่ได้

ลำดับของหน้านี้ เริ่มจากหา eigenvalue ด้วยสมการ แล้วแสดงว่า matrix สมมาตรแยกเป็น “หมุน ยืด หมุนกลับ” ได้เสมอ ใช้ภาพนี้คิด variance ของพอร์ตใหม่ จากนั้นนิยาม positive definite กับ positive semidefinite ด้วยภาพเส้นระดับ และตรวจด้วยมือด้วย Sylvester's criterion แล้วกลับมาตอบ hook ปิดท้ายด้วย covariance จริงของสินทรัพย์แปดกลุ่ม

ศัพท์ที่ใช้ในหัวข้อนี้
Eigenvector และ eigenvalue
eigenvector คือ vector $\mathbf u$ ที่ไม่ใช่ศูนย์ ซึ่ง matrix $A$ คูณแล้วได้ทิศเดิม แค่ยาวขึ้นหรือสั้นลง เขียนเป็น $A\mathbf u=\lambda\mathbf u$ ตัวคูณความยาว $\lambda$ คือ eigenvalue ใช้หาทิศหลักของความเสี่ยง
Covariance matrix
ตารางที่ช่องแนวทแยงคือ variance ของสินทรัพย์แต่ละตัว และช่องอื่นคือ covariance ของแต่ละคู่ ตารางนี้สมมาตรเสมอ
Quadratic form
ตัวเลข $\mathbf x^{\mathsf T}A\mathbf x$ ถ้า $A$ เป็น covariance และ $\mathbf x$ เป็นน้ำหนักพอร์ต ตัวเลขนี้คือ variance ของพอร์ต
Spectral decomposition
การเขียน matrix สมมาตรเป็น $Q\Lambda Q^{\mathsf T}$ อ่านว่าหมุน ยืดตามแกน แล้วหมุนกลับ ใช้คำนวณ inverse และรากที่สองของ covariance
Positive semidefinite (PSD)
matrix สมมาตรที่ $\mathbf x^{\mathsf T}A\mathbf x\ge0$ ทุก $\mathbf x$ ซึ่งเท่ากับว่า eigenvalues ไม่ติดลบสักตัว covariance ทุกตัวต้องผ่านเงื่อนไขนี้
Positive definite (PD)
matrix สมมาตรที่ $\mathbf x^{\mathsf T}A\mathbf x\gt0$ ทุก $\mathbf x\ne\mathbf 0$ ซึ่งเท่ากับว่า eigenvalues เป็นบวกทุกตัว covariance แบบนี้ไม่มีพอร์ตไหนที่ความเสี่ยงเป็นศูนย์ และหา inverse ได้
Indefinite
matrix ที่มีทั้งทิศที่ $\mathbf x^{\mathsf T}A\mathbf x$ เป็นบวกและทิศที่เป็นลบ ถ้าเป็น Hessian ที่จุดราบ จุดนั้นคือจุดอานม้า ไม่ใช่จุดต่ำสุด
Trace
ผลรวมของช่องแนวทแยง $\operatorname{tr}A$ ของ covariance คือผลรวม variance ของทุกตัว
Condition number
eigenvalue ใหญ่สุดหารด้วยเล็กสุด ยิ่งใหญ่ inverse ยิ่งขยาย error ในข้อมูล (ดู Rank, Range, and Invertibility)
Principal component (PCA)
eigenvector ของ covariance เรียงจาก eigenvalue มากไปน้อย ใช้สรุปว่าการขยับของสินทรัพย์จำนวนมากมาจากไม่กี่ทิศ

ขั้นที่ 1 — eigenvector: ทิศที่คูณแล้วยังอยู่บนเส้นเดิม

ก่อนจะหา eigenvector ด้วยสูตร ลองดูด้วยตาก่อนว่ามันคืออะไร เอา $M$ จากรูปข้างบนมาคูณสามทิศ แล้วดูว่าผลลัพธ์ยังอยู่บนเส้นเดิมไหม “อยู่บนเส้นเดิม” แปลว่าผลลัพธ์เป็น input เดิมคูณตัวเลขตัวหนึ่ง

\[\begin{aligned} M\begin{bmatrix}1\\1\end{bmatrix}&=\begin{bmatrix}3+1\\1+3\end{bmatrix}=4\begin{bmatrix}1\\1\end{bmatrix},\\ M\begin{bmatrix}1\\-1\end{bmatrix}&=\begin{bmatrix}3-1\\1-3\end{bmatrix}=2\begin{bmatrix}1\\-1\end{bmatrix},\\ M\begin{bmatrix}1\\0\end{bmatrix}&=\begin{bmatrix}3\\1\end{bmatrix}\ne c\begin{bmatrix}1\\0\end{bmatrix}. \end{aligned}\]

ทิศ $(1,1)$ กับ $(1,-1)$ ออกมาเป็นตัวเดิมคูณ 4 และคูณ 2 จึงเป็น eigenvectors และ 4 กับ 2 คือ eigenvalues ของมัน เขียนเป็นนิยามทั่วไปได้ว่า vector $\mathbf u\ne\mathbf 0$ เป็น eigenvector ของ $A$ ถ้า $A\mathbf u=\lambda\mathbf u$ สำหรับตัวเลข $\lambda$ บางตัว ส่วนทิศ $(1,0)$ ออกมาเป็น $(3,1)$ ซึ่งไม่มีตัวเลข $c$ ไหนทำให้ $c\times(1,0)=(3,1)$ ได้ เพราะ $c\times0$ เป็นศูนย์เสมอ แต่พิกัดที่สองของผลลัพธ์คือ 1 ลูกศรนี้จึงถูกหมุน

eigenvector มีความยาวได้ทุกแบบ ถ้า $\mathbf u$ เป็น eigenvector แล้ว $2\mathbf u$ หรือ $-\mathbf u$ ก็เป็นด้วย เพราะ $A(c\mathbf u)=c\lambda\mathbf u=\lambda(c\mathbf u)$ เราจึงมักย่อให้ยาวหนึ่งหน่วย $\|\mathbf u\|=1$ เพื่อเทียบกันง่าย แต่เครื่องหมายยังเลือกได้สองทาง โปรแกรมสองตัวอาจตอบ $\mathbf u$ กับ $-\mathbf u$ ซึ่งชี้แนวเดียวกัน ไม่มีตัวไหนผิด และถ้า eigenvalue เป็นศูนย์ แปลว่า matrix ส่งทิศนั้นไปที่ศูนย์ ทิศนั้นจึงอยู่ใน null space

ขั้นที่ 2 — หา eigenvalue: เมื่อไร $A-\lambda I$ บี้ทิศหนึ่งทิ้ง

กับ $M$ เราเดาทิศได้เพราะเลือกเลขง่าย แต่ covariance จริงเดาไม่ได้ จึงต้องมีวิธีที่ใช้ได้ทุกครั้ง เริ่มจากย้ายข้างนิยาม $A\mathbf u=\lambda\mathbf u$ เป็น $(A-\lambda I)\mathbf u=\mathbf 0$ โดย $I$ คือ identity matrix ถ้า $A-\lambda I$ หา inverse ได้ คูณ inverse ทั้งสองข้างจะได้ $\mathbf u=\mathbf 0$ เท่านั้น ซึ่งไม่นับเป็น eigenvector ดังนั้น $\lambda$ ที่เราต้องการคือค่าที่ทำให้ $A-\lambda I$ หา inverse ไม่ได้ คือ determinant เป็นศูนย์ (determinant ศูนย์แปลว่า matrix บี้ระนาบจนแบน ดู Rank, Range, and Invertibility)

ลองกับ covariance ของผลตอบแทนรายวันของดัชนีหุ้นสองตัว (ดัชนีคือตัวเลขที่สรุปราคาหุ้นทั้งกลุ่ม เช่น S&P 500) ตัวเลขสมมติ:

  • ความผันผวนรายวันของดัชนีแรก $\sigma_1=2\%$ และของดัชนีที่สอง $\sigma_2=3\%$
  • correlation ของสองดัชนี $\rho=0.4$

เขียนทุกช่องในหน่วย %² (เปอร์เซ็นต์ยกกำลังสอง) ช่องแนวทแยงคือ variance $\sigma_1^2=2^2=4$ และ $\sigma_2^2=3^2=9$ ช่องนอกแนวทแยงคือ covariance $\rho\sigma_1\sigma_2=0.4\times2\times3=2.4$ แล้วตั้ง determinant ให้เป็นศูนย์

\[\begin{aligned} \Sigma&=\begin{bmatrix}4&2.4\\2.4&9\end{bmatrix},\\ \det(\Sigma-\lambda I)&=(4-\lambda)(9-\lambda)-2.4^2\\ &=\lambda^2-13\lambda+36-5.76\\ &=\lambda^2-13\lambda+30.24=0,\\ \lambda&=\frac{13\pm\sqrt{13^2-4(30.24)}}{2}\\ &=\frac{13\pm\sqrt{48.04}}{2}=\frac{13\pm6.93109}{2},\\ \lambda_1&\approx9.96554,\quad\lambda_2\approx3.03446. \end{aligned}\]

ปัญหา “หาทิศที่ไม่หมุน” กลายเป็นสมการกำลังสองธรรมดา เรียกว่า characteristic equation แล้วแก้ด้วยสูตรรากของสมการกำลังสอง มีวิธีตรวจคำตอบเร็ว ๆ ด้วย สมการที่มีราก $\lambda_1,\lambda_2$ เขียนได้เป็น $(\lambda-\lambda_1)(\lambda-\lambda_2)=\lambda^2-(\lambda_1+\lambda_2)\lambda+\lambda_1\lambda_2$ เทียบกับสมการข้างบน ผลรวมของ eigenvalues จึงต้องเท่ากับ $4+9=13$ ซึ่งคือผลรวมแนวทแยง (trace) และผลคูณต้องเท่ากับ $30.24$ ซึ่งคือ determinant ลองดู $9.96554+3.03446=13$ และ $9.96554\times3.03446\approx30.24$ ตรงทั้งคู่ ส่วนที่เหลือของหน้าจะปัดเป็น $\lambda_1\approx9.9655$ และ $\lambda_2\approx3.0345$

ระวังหน่วย eigenvalues ทั้งสองเป็น variance หน่วย %² ไม่ใช่ความผันผวน ถ้าเขียนเป็นเศษส่วนแทนเปอร์เซ็นต์ ต้องคูณ $(0.01)^2$ ได้ $9.9655\times0.0001=0.00099655$ และ $3.0345\times0.0001=0.00030345$

ได้ eigenvalue แล้ว ต่อไปหาทิศของมัน แทน $\lambda_1$ ลงใน $(\Sigma-\lambda_1I)\mathbf u=\mathbf 0$ ให้ $\mathbf u=(x,y)$ แถวแรกของสมการพอให้หาอัตราส่วน $y/x$ ได้ แล้วหารด้วยความยาวให้เหลือยาวหนึ่งหน่วย

\[\begin{aligned} (4-\lambda_1)x+2.4y&=0,\\ \frac yx=\frac{\lambda_1-4}{2.4}&=\frac{5.96554}{2.4}\approx2.48564,\\ \sqrt{1+2.48564^2}&\approx2.67926,\\ \mathbf u_1&\approx\Big(\frac{1}{2.67926},\ \frac{2.48564}{2.67926}\Big)\\ &\approx(0.37324,\ 0.92774),\\ \mathbf u_2&\approx(-0.92774,\ 0.37324). \end{aligned}\]

ทิศ $\mathbf u_1$ ขึ้นไปทางดัชนีที่สองมากกว่าดัชนีแรก เพราะดัชนีที่สองแกว่งแรงกว่า ส่วน $\mathbf u_2$ ได้จากการสลับพิกัดของ $\mathbf u_1$ แล้วกลับเครื่องหมายตัวหนึ่ง ซึ่งคือ $\mathbf u_1$ หมุน 90° ทางลัดนี้ใช้ได้เพราะ eigenvectors ของ matrix สมมาตรตั้งฉากกันเสมอ (ขั้นถัดไปจะพิสูจน์) ตรวจว่าใช้ได้จริงด้วยการแทนกลับ แถวแรกของ $(\Sigma-\lambda_2I)\mathbf u_2$ คือ $(4-3.03446)(-0.92774)+2.4(0.37324)\approx0$

อัตราส่วน 2.48564 คือความชันของแกนยาวของกลุ่มข้อมูล อย่าสับสนกับ regression slope ซึ่งคือความชันของเส้นที่ใช้ทำนายดัชนีที่สองจากดัชนีแรก ตัวนั้นเท่ากับ covariance หารด้วย variance ของดัชนีแรก $2.4/4=0.6$ สองเส้นต่างกันเพราะตอบคนละคำถาม แกนยาวคือทิศที่ข้อมูลแผ่ออกมากที่สุด regression คือเส้นที่ทำนายแกนตั้งจากแกนนอนได้ดีที่สุด

ขั้นที่ 3 — matrix สมมาตร = หมุน แล้วยืด แล้วหมุนกลับ

ในตัวอย่างดัชนีสองตัว $\mathbf u_1$ กับ $\mathbf u_2$ ตั้งฉากกันพอดี เช็กได้จาก inner product $0.37324(-0.92774)+0.92774(0.37324)=0$ คำถามคือ นี่เป็นโชคหรือเกิดเสมอ ถ้าเกิดเสมอ เราจะใช้ eigenvectors เป็นแกนพิกัดชุดใหม่ได้ ซึ่งเป็นหัวใจของหน้านี้ วิธีพิสูจน์คือคิดตัวเลข $\mathbf u_i^{\mathsf T}\Sigma\mathbf u_j$ สองทาง โดย $\mathbf u_i,\mathbf u_j$ คือ eigenvectors สองตัวที่มี eigenvalues $\lambda_i\ne\lambda_j$

\[\begin{aligned} \mathbf u_i^{\mathsf T}\Sigma\mathbf u_j&=\lambda_j\,\mathbf u_i^{\mathsf T}\mathbf u_j,\\ \mathbf u_i^{\mathsf T}\Sigma\mathbf u_j&=(\Sigma\mathbf u_i)^{\mathsf T}\mathbf u_j=\lambda_i\,\mathbf u_i^{\mathsf T}\mathbf u_j,\\ (\lambda_i-\lambda_j)\,\mathbf u_i^{\mathsf T}\mathbf u_j&=0 \ \Longrightarrow\ \mathbf u_i^{\mathsf T}\mathbf u_j=0. \end{aligned}\]

ทางแรกให้ $\Sigma$ คูณ $\mathbf u_j$ ที่อยู่ทางขวาก่อน ได้ $\lambda_j\mathbf u_j$ ทางที่สองให้ $\Sigma$ ไปคูณ $\mathbf u_i$ ทางซ้ายแทน จุดที่ต้องระวังอยู่ตรงนี้ ปกติ $\mathbf u_i^{\mathsf T}\Sigma=(\Sigma^{\mathsf T}\mathbf u_i)^{\mathsf T}$ เพราะ transpose ของผลคูณกลับลำดับ แต่ $\Sigma$ สมมาตร $\Sigma^{\mathsf T}=\Sigma$ (ดู Transpose) จึงเขียนเป็น $(\Sigma\mathbf u_i)^{\mathsf T}$ ได้ และได้ $\lambda_i$ ออกมา

ตัวเลขเดียวกันคิดได้สองทาง ผลจึงต้องเท่ากัน ลบกันได้ $(\lambda_i-\lambda_j)\,\mathbf u_i^{\mathsf T}\mathbf u_j=0$ เมื่อ eigenvalues ต่างกัน วงเล็บแรกไม่ใช่ศูนย์ inner product จึงต้องเป็นศูนย์ คือสองทิศตั้งฉากกัน (inner product ศูนย์คือมุม 90° ดู Inner Product, Angle, and Correlation) ทฤษฎีที่ใหญ่กว่านี้ ชื่อ spectral theorem รับประกันต่อว่า matrix สมมาตรทุกตัวมี eigenvalues เป็นจำนวนจริง และมี eigenvectors ตั้งฉากกันครบทุกมิติ แม้ eigenvalues บางตัวจะซ้ำกันก็ตาม

เมื่อ eigenvectors ตั้งฉากกันและยาวหนึ่งหน่วย ก็จัดมันเป็นแกนพิกัดชุดใหม่ได้ วาง eigenvectors เป็นคอลัมน์ของ matrix $Q$ และวาง eigenvalues บนแนวทแยงของ matrix $\Lambda$ ซึ่งช่องอื่นเป็นศูนย์ ในตัวอย่างดัชนีสองตัว $Q=\begin{bmatrix}0.37324&-0.92774\\0.92774&0.37324\end{bmatrix}$ และ $\Lambda=\begin{bmatrix}9.9655&0\\0&3.0345\end{bmatrix}$ แล้วจะได้การแยก matrix ที่ใช้ทั้งเล่ม

\[\begin{aligned} \Sigma Q&=Q\Lambda,\quad Q^{\mathsf T}Q=I,\\ \Sigma&=Q\Lambda Q^{\mathsf T},\\ \Sigma^{-1}&=Q\Lambda^{-1}Q^{\mathsf T},\\ \operatorname{tr}\Sigma&=\sum_i\lambda_i,\quad\det\Sigma=\prod_i\lambda_i. \end{aligned}\]

$\Sigma Q=Q\Lambda$ คือสมการ $\Sigma\mathbf u_i=\lambda_i\mathbf u_i$ ของทุกคอลัมน์เขียนรวมกันทีเดียว ส่วน $Q^{\mathsf T}Q=I$ มาจากที่ช่อง $(i,j)$ ของ $Q^{\mathsf T}Q$ คือ $\mathbf u_i^{\mathsf T}\mathbf u_j$ ซึ่งเป็น 1 เมื่อ $i=j$ (ยาวหนึ่ง) และเป็น 0 เมื่อ $i\ne j$ (ตั้งฉาก) ดังนั้น inverse ของ $Q$ ก็คือ $Q^{\mathsf T}$ นั่นเอง เอา $Q^{\mathsf T}$ คูณทางขวาของ $\Sigma Q=Q\Lambda$ ทั้งสองข้าง จึงได้ $\Sigma=Q\Lambda Q^{\mathsf T}$

อ่านสูตรนี้จากขวาไปซ้าย $Q^{\mathsf T}$ หมุนระนาบจน eigenvectors มาอยู่บนแกน $\Lambda$ ยืดแต่ละแกนด้วย eigenvalue ของแกนนั้น แล้ว $Q$ หมุนกลับ ดังรูปด้านล่าง การหมุนไม่เปลี่ยนความยาวและไม่เปลี่ยนพื้นที่ ทุกอย่างที่ matrix ทำกับขนาดจึงอยู่ใน $\Lambda$ หมด determinant คือตัวคูณพื้นที่ (หรือปริมาตร) จึงเท่ากับผลคูณของตัวยืดบนแนวทแยงของ $\Lambda$ ส่วน trace ใช้กฎที่ว่าสลับลำดับการคูณแล้ว trace เท่าเดิม $\operatorname{tr}(Q\Lambda Q^{\mathsf T})=\operatorname{tr}(\Lambda Q^{\mathsf T}Q)=\operatorname{tr}\Lambda$ จึงเท่ากับผลรวม eigenvalues กรณี $2\times2$ เราเห็นสองข้อนี้แล้วจากสมการกำลังสองในขั้นที่ 2

inverse ก็ได้มาฟรี ๆ ถ้า $\Sigma$ ยืดแกนหนึ่งด้วย $\lambda_i$ การย้อนกลับคือคูณแกนนั้นด้วย $1/\lambda_i$ แทน ทิศที่ eigenvalue เล็กจึงถูก inverse ขยายมากที่สุด ในตัวอย่างนี้ $1/\lambda_2=1/3.0345\approx0.3295$ แต่ $1/\lambda_1=1/9.9655\approx0.1003$ ทิศ $\mathbf u_2$ จึงถูกขยายมากกว่า $\lambda_1/\lambda_2=9.9655/3.0345\approx3.28$ เท่า เรื่องนี้จะกลับมาเป็นปัญหาใหญ่ในขั้นสินทรัพย์แปดกลุ่ม

ขั้นที่ 4 — variance ของพอร์ตในพิกัดของ eigenvectors

ทีนี้ใช้แกนชุดใหม่ตอบคำถามเรื่องเงิน พอร์ตหนึ่งพอร์ตเขียนเป็นน้ำหนัก $\mathbf w=(w_1,w_2)$ คือสัดส่วนของเงินที่ลงในแต่ละดัชนี variance ของพอร์ตคือ $\mathbf w^{\mathsf T}\Sigma\mathbf w$ (ที่มาอยู่ใน Transpose) เราอยากรู้ว่าความเสี่ยงนี้มาจากทิศไหนเท่าไร จึงเขียน $\mathbf w$ ในพิกัดของ eigenvectors ให้ $\mathbf c=Q^{\mathsf T}\mathbf w$ คือ $c_i=\mathbf u_i^{\mathsf T}\mathbf w$ ตัวเลข $c_i$ บอกว่าพอร์ตนี้ชี้ไปตามทิศ $\mathbf u_i$ มากแค่ไหน แล้วแทน $\Sigma=Q\Lambda Q^{\mathsf T}$

\[\begin{aligned} \mathbf w^{\mathsf T}\Sigma\mathbf w&=\mathbf w^{\mathsf T}Q\Lambda Q^{\mathsf T}\mathbf w =\mathbf c^{\mathsf T}\Lambda\mathbf c=\sum_i\lambda_ic_i^2,\\ \|\mathbf w\|^2&=\sum_ic_i^2,\\ \|\mathbf w\|=1:\ \ \lambda_{\min}&\le\mathbf w^{\mathsf T}\Sigma\mathbf w\le\lambda_{\max}. \end{aligned}\]

ก้าวที่ทำให้สูตรนี้ใช้ได้คือ $\mathbf w^{\mathsf T}Q=(Q^{\mathsf T}\mathbf w)^{\mathsf T}=\mathbf c^{\mathsf T}$ เพราะ transpose ของผลคูณกลับลำดับ ในพิกัดเดิม variance มีพจน์ไขว้ $2w_1w_2\Sigma_{12}$ ปนอยู่ ($\Sigma_{12}$ คือช่องนอกแนวทแยง) ในพิกัดใหม่พจน์ไขว้หายไปหมด เพราะ $\Lambda$ มีแค่แนวทแยง variance ของพอร์ตจึงเป็นแค่ผลรวมของ “eigenvalue คูณกำลังสองของส่วนที่พอร์ตชี้ไปทางนั้น” แต่ละทิศแบกความเสี่ยงของตัวเองแยกกัน ไม่มีใครหักล้างใคร และถ้า eigenvalues ไม่ติดลบ ทุกพจน์ก็ไม่ติดลบ

ความยาวของ $\mathbf w$ เท่าเดิมในพิกัดใหม่ เพราะ $Q^{\mathsf T}$ แค่หมุน ไม่ยืด จึงได้ $\|\mathbf w\|^2=\sum_ic_i^2$ ถ้าเลือกพอร์ตที่ยาวหนึ่งหน่วย $\|\mathbf w\|=\sqrt{w_1^2+w_2^2}=1$ (ความยาวแบบ L2 ไม่ใช่ผลรวมน้ำหนักเท่ากับหนึ่ง) ค่า $c_i^2$ จะรวมกันได้ 1 variance จึงเป็นค่าเฉลี่ยถ่วงน้ำหนักของ eigenvalues และค่าเฉลี่ยย่อมอยู่ระหว่างค่าน้อยสุดกับมากสุดเสมอ รูปด้านล่างหมุน $\mathbf w$ รอบวงกลมให้เห็นข้อนี้

ลองกับพอร์ตที่ลงเงิน 60% ในดัชนีแรกและ 40% ในดัชนีที่สอง $\mathbf w=(0.6,\ 0.4)$ ใช้ $\mathbf u_1=(0.37324,\ 0.92774)$ และ $\mathbf u_2=(-0.92774,\ 0.37324)$ จากขั้นที่ 2

\[\begin{aligned} c_1&=0.6(0.37324)+0.4(0.92774)\approx0.59504,\\ c_2&=-0.6(0.92774)+0.4(0.37324)\approx-0.40735,\\ \lambda_1c_1^2&=9.96554(0.59504)^2\approx3.5285,\\ \lambda_2c_2^2&=3.03446(0.40735)^2\approx0.5035,\\ \mathbf w^{\mathsf T}\Sigma\mathbf w&\approx3.5285+0.5035=4.032. \end{aligned}\]

ตรวจกับสูตรเดิมที่มีพจน์ไขว้ $0.6^2(4)+2(0.6)(0.4)(2.4)+0.4^2(9)=1.44+1.152+1.44=4.032$ ตรงกัน variance ของพอร์ตคือ 4.032 %² ความผันผวนคือ $\sqrt{4.032}\approx2.008\%$ ต่อวัน

ข้อมูลใหม่ที่ได้คือส่วนแบ่ง ทิศแรกแบก $3.5285/4.032\approx87.51\%$ ของ variance พอร์ตนี้ อย่าสับสนกับอีกตัวเลขที่ดูคล้ายกัน $\lambda_1/\operatorname{tr}\Sigma=9.9655/13\approx76.66\%$ ตัวนี้คือสัดส่วนของ variance รวมของทั้งสองดัชนี ที่ทิศแรกอธิบายได้ ซึ่งเป็นเกณฑ์ที่ PCA ใช้ 87.51% ตอบว่า “ความเสี่ยงของพอร์ตนี้มาจากไหน” ส่วน 76.66% ตอบว่า “ตลาดสองดัชนีนี้ขยับตามทิศแรกแค่ไหน” เป็นคนละคำถาม

ขั้นที่ 5 — PSD, PD และ indefinite ดูได้จากเส้นระดับ

ทำไมต้องสนใจเครื่องหมายของ eigenvalue เพราะ variance คือค่าเฉลี่ยของกำลังสอง จึงติดลบไม่ได้ ตาราง $\Sigma$ ที่ใช้เป็น covariance ได้จริงต้องให้ variance ไม่ติดลบกับทุกพอร์ต เขียนเป็น $\mathbf w^{\mathsf T}\Sigma\mathbf w=\operatorname{Var}(\mathbf w^{\mathsf T}\mathbf R)\ge0$ ทุก $\mathbf w$ โดย $\mathbf R$ คือ vector ของผลตอบแทนของสินทรัพย์แต่ละตัว และ $\mathbf w^{\mathsf T}\mathbf R$ คือผลตอบแทนของพอร์ต เงื่อนไขนี้มีชื่อว่า positive semidefinite (PSD) สูตรจากขั้นก่อนแปลมันเป็นเงื่อนไขของ eigenvalues ได้ทันที ในที่นี้เขียน matrix สมมาตรทั่วไปเป็น $A$ และ vector เป็น $\mathbf x$

\[\begin{aligned} \mathbf x^{\mathsf T}A\mathbf x&=\sum_i\lambda_ic_i^2,\\ \text{PSD}&:\ \lambda_1,\dots,\lambda_n\ge0,\\ \text{PD}&:\ \lambda_1,\dots,\lambda_n\gt0,\\ \mathbf x=\mathbf u_k&\Rightarrow\mathbf x^{\mathsf T}A\mathbf x=\lambda_k. \end{aligned}\]

ทำไม “eigenvalues ไม่ติดลบ” กับ “$\mathbf x^{\mathsf T}A\mathbf x$ ไม่ติดลบทุก $\mathbf x$” จึงเป็นเรื่องเดียวกัน ทางหนึ่ง ถ้า eigenvalues ไม่ติดลบสักตัว ผลรวม $\sum\lambda_ic_i^2$ ก็มีแต่พจน์ที่ไม่ติดลบ จึงติดลบไม่ได้ อีกทาง ถ้ามี $\lambda_k\lt0$ สักตัว ให้เลือก $\mathbf x$ เป็น eigenvector ตัวนั้นเอง จะได้ $c_k=1$ และ $c$ ตัวอื่นเป็นศูนย์ ผลจึงเท่ากับ $\lambda_k$ ซึ่งติดลบทันที

positive definite (PD) เข้มกว่า PSD ตรงที่ห้ามมีทิศที่ได้ศูนย์ด้วย คือทุก eigenvalue ต้องเป็นบวก matrix ที่เป็น PSD แต่ไม่ใช่ PD จึงมี eigenvalue ศูนย์อย่างน้อยหนึ่งตัว determinant ซึ่งเป็นผลคูณของ eigenvalues จึงเป็นศูนย์ และหา inverse ไม่ได้ ตัวอย่างคือ sample covariance ของ “พอร์ตผี” ที่ข้อมูลบอกว่าไม่มีความเสี่ยงเลย ใน Rank, Range, and Invertibility

เงื่อนไขเดียวกันนี้ใช้กับอีกงานหนึ่งด้วย คือบอกว่าจุดที่ฟังก์ชันราบ (gradient เป็นศูนย์) เป็นก้นหลุม ยอดเขา หรือจุดอานม้า เครื่องมือคือ Hessian ซึ่งเป็น matrix ของอนุพันธ์อันดับสอง บอกความโค้งของฟังก์ชันในแต่ละทิศ (ดู The Hessian and Second-Order Conditions) ลองกับฟังก์ชัน $f(\mathbf x)=x_1^2+3x_1x_2+x_2^3$ ซึ่งรูปด้านล่างใช้วาด

\[\begin{aligned} \nabla f&=\begin{bmatrix}2x_1+3x_2\\3x_1+3x_2^2\end{bmatrix},\\ H&=\begin{bmatrix}2&3\\3&6x_2\end{bmatrix},\\ x_1&=-\tfrac32x_2,\quad x_2\big(3x_2-\tfrac92\big)=0,\\ H_0&=\begin{bmatrix}2&3\\3&0\end{bmatrix},\quad H_*=\begin{bmatrix}2&3\\3&9\end{bmatrix},\\ \lambda(H_0)&=1\pm\sqrt{10}\approx4.16,\ -2.16,\\ \lambda(H_*)&=\tfrac12\big(11\pm\sqrt{85}\big)\approx10.11,\ 0.89. \end{aligned}\]

gradient $\nabla f$ คืออนุพันธ์ย่อยของ $f$ เทียบ $x_1$ และเทียบ $x_2$ ส่วน $H$ ได้จากการหาอนุพันธ์ย่อยของ gradient อีกรอบ เช่น ช่องมุมขวาล่างคืออนุพันธ์ของ $3x_1+3x_2^2$ เทียบ $x_2$ ซึ่งคือ $6x_2$ จุดราบหาได้จาก $\nabla f=\mathbf 0$ แถวแรกให้ $x_1=-\tfrac32x_2$ แทนลงแถวที่สองได้ $-\tfrac92x_2+3x_2^2=0$ ซึ่งแยกตัวประกอบเป็น $x_2(3x_2-\tfrac92)=0$ จึงมีจุดราบสองจุด คือ $\mathbf x=\mathbf 0$ กับ $\mathbf x=(-\tfrac94,\ \tfrac32)$ เรียก Hessian ที่สองจุดนี้ว่า $H_0$ และ $H_*$ ตามลำดับ (แทน $x_2=\tfrac32$ ได้ $6x_2=9$)

eigenvalues ของแต่ละตัวหาจาก trace กับ determinant เหมือนขั้นที่ 2 $H_0$ มี trace $2+0=2$ และ determinant $2(0)-3^2=-9$ จึงได้ $\lambda^2-2\lambda-9=0$ ส่วน $H_*$ มี trace $2+9=11$ และ determinant $2(9)-3^2=9$ จึงได้ $\lambda^2-11\lambda+9=0$ แล้วแก้ด้วยสูตรรากของสมการกำลังสอง

$H_0$ มี eigenvalue บวกหนึ่งตัวและลบหนึ่งตัว จึงเป็น indefinite ฟังก์ชันโค้งขึ้นทิศหนึ่งและโค้งลงอีกทิศ จุด $\mathbf 0$ จึงเป็นจุดอานม้า ไม่ใช่ก้นหลุม ส่วน $H_*$ มี eigenvalues บวกทั้งคู่ จึงเป็น PD ทุกทิศโค้งขึ้น จุด $(-\tfrac94,\ \tfrac32)$ จึงเป็นก้นหลุมเฉพาะที่

มีข้อควรระวังหนึ่งข้อ เกณฑ์ eigenvalue ใช้ได้กับ matrix สมมาตรเท่านั้น ลอง $A=\begin{bmatrix}1&4\\0&1\end{bmatrix}$ ซึ่งไม่สมมาตร eigenvalues ของมันคือ 1 กับ 1 เพราะ $\det(A-\lambda I)=(1-\lambda)(1-\lambda)-4(0)=(1-\lambda)^2$ ทั้งคู่บวก แต่ที่ $\mathbf x=(1,-1)$ ได้ $\mathbf x^{\mathsf T}A\mathbf x=1(1)^2+4(1)(-1)+1(-1)^2=-2$ ติดลบ เหตุผลคือ $\mathbf x^{\mathsf T}A\mathbf x$ เป็นตัวเลขตัวเดียว จึงเท่ากับ transpose ของตัวเอง $\mathbf x^{\mathsf T}A^{\mathsf T}\mathbf x$ quadratic form จึงเห็นแค่ค่าเฉลี่ย $\tfrac12(A+A^{\mathsf T})=\begin{bmatrix}1&2\\2&1\end{bmatrix}$ ซึ่งสมมาตร มี trace 2 และ determinant $1-4=-3$ จึงได้ $\lambda^2-2\lambda-3=(\lambda-3)(\lambda+1)=0$ eigenvalues คือ 3 กับ $-1$ ตัวหลังติดลบ ต้องดู eigenvalues ของส่วนสมมาตรนี้แทน

ขั้นที่ 6 — Sylvester's criterion: ตรวจ PD โดยไม่ต้องหา eigenvalues

การหา eigenvalues ต้องแก้สมการ ซึ่งยากขึ้นเรื่อย ๆ เมื่อ matrix ใหญ่ขึ้น ถ้าอยากรู้แค่ว่า matrix เป็น PD หรือไม่ มีทางลัดที่ไม่ต้องหา eigenvalues เลย ดูกรณี $2\times2$ ก่อน เขียน matrix สมมาตรเป็นตัวอักษร แล้วจัดกำลังสองสมบูรณ์ (สมมติ $a\gt0$ เพื่อให้หารด้วย $a$ ได้)

\[\begin{aligned} A&=\begin{bmatrix}a&b\\b&d\end{bmatrix},\\ \mathbf x^{\mathsf T}A\mathbf x&=ax_1^2+2bx_1x_2+dx_2^2\\ &=a\Big(x_1+\frac ba x_2\Big)^2+\frac{ad-b^2}{a}x_2^2. \end{aligned}\]

การจัดกำลังสองสมบูรณ์ทำให้พจน์ไขว้ $2bx_1x_2$ ไปซ่อนอยู่ในวงเล็บ (กระจายวงเล็บกลับก็ได้ $ax_1^2+2bx_1x_2+\tfrac{b^2}{a}x_2^2$ ส่วนเกิน $\tfrac{b^2}{a}x_2^2$ ถูกหักคืนในพจน์ที่สอง) เหลือสองพจน์ที่เป็นกำลังสองคูณสัมประสิทธิ์ ผลรวมจึงเป็นบวกทุก $\mathbf x\ne\mathbf 0$ ก็ต่อเมื่อสัมประสิทธิ์ทั้งสอง $a$ กับ $\tfrac{ad-b^2}{a}$ เป็นบวก คือ $a\gt0$ และ $ad-b^2\gt0$ ทิศกลับก็จริง ถ้า $a\le0$ เลือก $\mathbf x=(1,0)$ จะได้ค่า $a$ ซึ่งไม่บวก ถ้า $ad-b^2\le0$ เลือก $x_2=1$ กับ $x_1=-b/a$ วงเล็บเป็นศูนย์ เหลือ $\tfrac{ad-b^2}{a}$ ซึ่งไม่บวก

ตัวเลข $a$ คือ determinant ของบล็อกมุมบนซ้ายขนาด $1\times1$ และ $ad-b^2$ คือ determinant ของบล็อกมุมบนซ้ายขนาด $2\times2$ determinant ของบล็อกมุมบนซ้ายเหล่านี้เรียกว่า leading principal minors กฎทั่วไปสำหรับ matrix ทุกขนาดชื่อ Sylvester's criterion คือ matrix สมมาตรเป็น PD ก็ต่อเมื่อ leading principal minors ทุกขนาดเป็นบวก

ลองตรวจสาม matrix ที่เจอมาแล้ว covariance ของดัชนีสองตัว $\Sigma$ และ Hessian สองตัว $H_*$ กับ $H_0$

\[\begin{aligned} \Sigma&:\ \ 4\gt0,\quad 4(9)-2.4^2=30.24\gt0,\\ H_*&:\ \ 2\gt0,\quad 2(9)-3^2=9\gt0,\\ H_0&:\ \ 2\gt0,\quad 2(0)-3^2=-9\lt0. \end{aligned}\]

$\Sigma$ และ $H_*$ ผ่านทั้งสองข้อ จึงเป็น PD ตรงกับ eigenvalues ที่หาไว้ ส่วน $H_0$ ตกข้อที่สอง จึงไม่ใช่ PD ตรงกับที่มี eigenvalue ติดลบ

มีกับดักที่คนพลาดบ่อย คือเปลี่ยนคำว่า “บวก” เป็น “ไม่ติดลบ” แล้วคิดว่าได้เกณฑ์ตรวจ PSD วิธีนี้ใช้ไม่ได้ ลอง $\begin{bmatrix}0&0\\0&-1\end{bmatrix}$ leading principal minors คือ $0$ กับ $0(-1)-0^2=0$ ไม่ติดลบทั้งคู่ แต่ที่ $\mathbf x=(0,1)$ ได้ $\mathbf x^{\mathsf T}A\mathbf x=-1$ การตรวจ PSD ต้องดู principal minors ทุกตัว ไม่ใช่แค่บล็อกมุมบนซ้าย ซึ่งรวมช่องแนวทแยงทุกช่องด้วย (ช่อง $-1$ จับความผิดนี้ได้ทันที) หรือไม่ก็ดู eigenvalues ตรง ๆ

ขั้นที่ 7 — สามธนาคาร: ทิศร่วมหนึ่งทิศ และระนาบ spread สองมิติ

ตอนนี้มีเครื่องมือพอจะตอบ hook แล้ว หุ้นธนาคารสามตัวมีความผันผวนเท่ากัน $\sigma=0.25$ จึงมี variance $\sigma^2=0.0625$ เท่ากันทุกตัว และ correlation ทุกคู่เท่ากันคือ $\rho$ ตาราง covariance ขนาด $3\times3$ จึงมีแค่สองค่า ช่องแนวทแยงเป็น $\sigma^2$ ช่องอื่นเป็น $\rho\sigma^2$ เขียนให้สั้นได้ด้วย vector $\mathbf 1=(1,1,1)$ เพราะ $\mathbf 1\mathbf 1^{\mathsf T}$ คือ matrix $3\times3$ ที่เป็นเลข 1 ทุกช่อง ตารางที่สมมาตรขนาดนี้เดา eigenvectors ได้จากรูปร่างของมันเลย

\[\begin{aligned} \Sigma&=\sigma^2\big((1-\rho)I+\rho\,\mathbf 1\mathbf 1^{\mathsf T}\big),\\ \Sigma\,\mathbf 1&=\sigma^2\big((1-\rho)+3\rho\big)\mathbf 1\\ &=\sigma^2(1+2\rho)\,\mathbf 1,\\ \mathbf 1^{\mathsf T}\mathbf v=0:\ \ \Sigma\mathbf v&=\sigma^2(1-\rho)\,\mathbf v,\\ \rho=0.7:\ \ \lambda_{\text{common}}&=0.0625(1+1.4)=0.15,\\ \lambda_{\text{spread}}&=0.0625(1-0.7)=0.01875. \end{aligned}\]

ทิศแรกที่ลองคือ $\mathbf 1$ คือ “ถือทุกตัวเท่ากัน” จุดสำคัญคือ $\mathbf 1\mathbf 1^{\mathsf T}\mathbf 1=\mathbf 1(\mathbf 1^{\mathsf T}\mathbf 1)=3\,\mathbf 1$ เพราะ $\mathbf 1^{\mathsf T}\mathbf 1=1+1+1=3$ ผลจึงเป็น $\mathbf 1$ คูณตัวเลข ทิศนี้คือ eigenvector เรียกว่าทิศร่วม (common) eigenvalue ของมันคือ $\sigma^2(1+2\rho)$

ทิศที่สองคือ vector $\mathbf v$ ใดก็ได้ที่ผลรวมพิกัดเป็นศูนย์ $\mathbf 1^{\mathsf T}\mathbf v=0$ เช่น $(1,-1,0)$ เรียกว่าพอร์ต spread คือซื้อบางตัว (long ได้กำไรเมื่อราคาขึ้น) และขายบางตัว (short คือยืมหุ้นมาขาย ได้กำไรเมื่อราคาลง) ในขนาดที่หักล้างกันพอดี สำหรับ $\mathbf v$ แบบนี้ $\mathbf 1\mathbf 1^{\mathsf T}\mathbf v=\mathbf 1(\mathbf 1^{\mathsf T}\mathbf v)=\mathbf 0$ พจน์ที่มี $\rho$ หายไป เหลือ $\sigma^2(1-\rho)$ vector ที่ผลรวมเป็นศูนย์มีทั้งระนาบ (สองมิติ) eigenvalue นี้จึงซ้ำสองครั้ง ตรวจด้วย trace ได้ $0.15+2(0.01875)=0.1875$ เท่ากับผลรวมแนวทแยง $3(0.0625)=0.1875$

ตอบ hook พอร์ตเงินเท่ากันคือ $\mathbf w=\tfrac13\mathbf 1$ ซึ่งชี้ไปตามทิศร่วมทั้งหมด ไม่มีส่วนไหนอยู่ในระนาบ spread เลย variance ของมันจึงมาจาก $\lambda_{\text{common}}$ ตัวเดียว คูณกำลังสองของความยาว

\[\begin{aligned} \|\mathbf w\|^2&=3\big(\tfrac13\big)^2=\tfrac13,\\ \mathbf w^{\mathsf T}\Sigma\mathbf w&=\lambda_{\text{common}}\|\mathbf w\|^2=\frac{0.15}{3}=0.05,\\ \sigma_p&=\sqrt{0.05}\approx22.36\%. \end{aligned}\]

ได้ 22.36% ตรงกับที่คิดตรง ๆ ใน hook แต่ตอนนี้เห็นเหตุผลแล้ว สูตรหารด้วย $\sqrt3$ จะได้ผลก็ต่อเมื่อทุกทิศมี eigenvalue เท่ากัน ซึ่งเกิดเมื่อ $\rho=0$ ที่ $\rho=0.7$ ทิศร่วมใหญ่กว่าทิศ spread ถึง $0.15/0.01875=8$ เท่า และพอร์ตเงินเท่ากันวางอยู่บนทิศใหญ่นั้นพอดี ทิศที่ความเสี่ยงต่ำอยู่ในระนาบ spread ซึ่งต้อง short บางตัว ไม่ใช่การแบ่งเงินซื้ออย่างเดียว เช่น long JPM และ short BAC ขนาดยาวหนึ่งหน่วย $(1,-1,0)/\sqrt2$ ความผันผวนของพอร์ตนี้คือ $\sqrt{0.01875}\approx13.69\%$

เพราะ eigenvalue ของ spread ซ้ำสองครั้ง ทุกทิศในระนาบผลรวมศูนย์เป็น eigenvector ได้หมด จะเลือกคู่ไหนที่ตั้งฉากกันก็ได้ โปรแกรมสองตัวจึงอาจรายงาน eigenvectors ของระนาบนี้ต่างกัน โดยที่ไม่มีตัวไหนผิด

สูตรเดียวกันยังบอกด้วยว่า correlation ที่เท่ากันทุกคู่ต่ำได้แค่ไหน ลองนึกถึงคนในทีมที่พิมพ์ correlation เองทีละคู่ เพื่อจำลองวิกฤตที่หุ้นสวนทางกันหมด ตารางที่เขาพิมพ์ต้องมี eigenvalues ไม่ติดลบ คือ $1+2\rho\ge0$ และ $1-\rho\ge0$ ซึ่งรวมกันได้ $-\tfrac12\le\rho\le1$ สำหรับสามตัว ถ้าเขาใส่ $\rho=-0.6$ ทุกคู่ดูปกติดี ค่าอยู่ระหว่าง −1 กับ 1 และ correlation matrix ของแต่ละคู่ $\begin{bmatrix}1&-0.6\\-0.6&1\end{bmatrix}$ มี determinant $1-0.36=0.64\gt0$ แต่ทั้งตารางใช้ไม่ได้

\[\begin{aligned} \lambda_{\text{common}}&=0.0625\big(1+2(-0.6)\big)\\ &=0.0625(-0.2)=-0.0125,\\ \mathbf w^{\mathsf T}\Sigma\mathbf w&=\frac{-0.0125}{3}\approx-0.0042. \end{aligned}\]

พอร์ตเงินเท่ากันจะมี “variance” ติดลบ ซึ่งเป็นไปไม่ได้ ตารางนี้จึงไม่ใช่ covariance ของหุ้นสามตัวใด ๆ เลย เหตุผลเชิงภาพคือ ถ้า A สวนทาง B แรง และ B สวนทาง C แรง A กับ C ก็ต้องขยับไปทางเดียวกัน จะให้ทั้งสามสวนทางกันแรงพร้อมกันทุกคู่ไม่ได้ การตรวจทีละคู่จึงมองไม่เห็นปัญหานี้

ขั้นที่ 8 — covariance จริงของ asset class แปดกลุ่ม

ตัวอย่างที่ผ่านมาใช้ตัวเลขสมมติ ขั้นนี้ลองกับตารางจริง กองทุนขนาดใหญ่มักแบ่งเงินเป็น asset class คือกลุ่มสินทรัพย์ประเภทเดียวกัน เช่น พันธบัตร (ตราสารที่รัฐบาลกู้เงินแล้วจ่ายดอกเบี้ย ราคาแกว่งน้อย) หุ้นใหญ่ หุ้นเล็ก หุ้นต่างประเทศ คำถามคือ ความเสี่ยงของแปดกลุ่มนี้มาจากกี่ทิศจริง ๆ และตารางนี้ปลอดภัยพอจะเอาไปหา inverse ในสูตรจัดพอร์ตไหม

โจทย์ให้อะไรมาบ้าง: covariance ของผลตอบแทนรายปีของแปดกลุ่ม ประมาณจากข้อมูลย้อนหลัง ชุดเดียวกับใน Matrix Multiplication ตาราง $8\times8$ เต็มอยู่ในโค้ดท้ายหน้า ตารางข้างล่างดึงมาเฉพาะช่องแนวทแยง ซึ่งคือ variance ของแต่ละกลุ่ม ความผันผวนคือรากที่สองของมัน เช่น พันธบัตรสหรัฐ $\sqrt{0.001005}\approx0.0317=3.17\%$

(growth คือหุ้นบริษัทที่ตลาดคาดว่าจะโตเร็ว value คือหุ้นบริษัทที่ราคาถูกเมื่อเทียบกับกำไรหรือทรัพย์สิน) trace คือผลรวมของคอลัมน์ variance ทั้งแปดช่อง $\operatorname{tr}\Sigma=0.001005+0.007277+\dots+0.079958=0.3406$

คำตอบ: ตาราง $8\times8$ แก้สมการ determinant ด้วยมือไม่ไหว จึงหา eigenvalues ด้วยโปรแกรม โค้ดท้ายหน้าใช้วิธี Jacobi ซึ่งหมุนแกนทีละคู่จนช่องนอกแนวทแยงเป็นศูนย์หมด ได้ eigenvalues แปดค่า เป็นบวกทุกค่า ตารางนี้จึงเป็น PD ค่าที่น่าสนใจคือตัวใหญ่สุดกับตัวเล็กสุด

\[\begin{aligned} \lambda_1&\approx0.25453,\\ \frac{\lambda_1}{\operatorname{tr}\Sigma}&=\frac{0.25453}{0.3406}\approx74.73\%,\\ \lambda_8&\approx0.000632,\\ \frac{\lambda_8}{\operatorname{tr}\Sigma}&=\frac{0.000632}{0.3406}\approx0.19\%,\\ \kappa&=\frac{\lambda_1}{\lambda_8}=\frac{0.25453}{0.000632}\approx403. \end{aligned}\]

ทิศแรกแบก variance รวมเกือบสามในสี่ eigenvector ของมันมีน้ำหนักบวกในหุ้นทั้งหกกลุ่ม ตั้งแต่ 0.24 ถึง 0.59 และแทบเป็นศูนย์ในพันธบัตรสองกลุ่ม ทิศนี้จึงคือ “หุ้นทุกตลาดขึ้นลงพร้อมกัน” เป็นทิศร่วมแบบเดียวกับสามธนาคาร แต่ใหญ่กว่า ส่วนทิศสุดท้ายแทบไม่มี variance เลย eigenvector ของมันเกือบทั้งหมดอยู่ในพันธบัตรสหรัฐ (น้ำหนัก 0.96) ตัวเลข $\kappa$ คือ condition number คือ eigenvalue ใหญ่สุดหารด้วยเล็กสุด

ความหมายสำหรับคนจัดพอร์ต สูตรจัดพอร์ตแบบ mean–variance คือ $\mathbf w^*=\tfrac{1}{2\tau}\Sigma^{-1}\boldsymbol\mu$ (ดู Rank, Range, and Invertibility) โดย $\boldsymbol\mu$ คือผลตอบแทนที่คาดว่าจะได้ของแต่ละกลุ่ม และ $\tau$ คือระดับที่นักลงทุนกลัวความเสี่ยง ขั้นที่ 3 แสดงแล้วว่า $\Sigma^{-1}$ ยืดแต่ละทิศด้วย $1/\lambda_i$ ทิศเล็กสุดจึงถูกยืดมากกว่าทิศใหญ่สุด 403 เท่า แต่ $\boldsymbol\mu$ ประมาณจากข้อมูลย้อนหลัง จึงคลาดจากค่าจริงเสมอ ความคลาดเล็ก ๆ ที่บังเอิญชี้ไปตามทิศเล็ก ๆ จะถูกขยายเป็นน้ำหนักก้อนใหญ่ นี่คือเหตุผลเชิง matrix ที่ทำให้ mean–variance optimizer ถูกเรียกว่า “ตัวขยาย error”

ปัญหายังซ้อนอีกชั้น eigenvalue ตัวบนสุดที่ประมาณจากข้อมูลมักสูงกว่าค่าจริง และตัวล่างสุดมักต่ำกว่าค่าจริง condition number ที่เห็นจึงมักใหญ่เกินจริง วิธีแก้ที่นิยมคือ shrink ซึ่งดึง eigenvalues เข้าหากัน (ดู Covariance Shrinkage (Ledoit-Wolf)) ส่วนการตัด eigenvalues เล็กทิ้งเป็นศูนย์ไม่ใช่ทางออก เพราะจะได้ covariance ที่ determinant เป็นศูนย์ หา inverse ไม่ได้

ขั้นที่ 9 — PD กับ optimizer: ชามที่มีก้นเดียว

ขั้นสุดท้ายตอบว่าทำไม optimizer ถึงต้องการ covariance ที่เป็น PD optimizer ด้านพอร์ตมักหาน้ำหนัก $\mathbf w$ ที่ทำให้คะแนน $f(\mathbf w)=\tfrac12\mathbf w^{\mathsf T}\Sigma\mathbf w-\boldsymbol\mu^{\mathsf T}\mathbf w$ ต่ำที่สุด พจน์แรกคือครึ่งหนึ่งของ variance (ความเสี่ยงที่อยากให้น้อย) พจน์ที่สองคือผลตอบแทนที่คาดว่าจะได้ (ซึ่งอยากให้มาก จึงใส่เครื่องหมายลบ) ตัว $\tfrac12$ ใส่ไว้ให้อนุพันธ์ออกมาสวย เพื่อดูรูปร่างของ $f$ ให้ลองขยับ $\mathbf w$ ไปตามทิศ $\mathbf z$ เป็นระยะ $t$ แล้วกระจายวงเล็บ

\[\begin{aligned} f(\mathbf w+t\mathbf z)&=\tfrac12(\mathbf w+t\mathbf z)^{\mathsf T}\Sigma(\mathbf w+t\mathbf z)\\ &\quad-\boldsymbol\mu^{\mathsf T}(\mathbf w+t\mathbf z)\\ &=f(\mathbf w)+t\,\mathbf z^{\mathsf T}(\Sigma\mathbf w-\boldsymbol\mu)\\ &\quad+\tfrac{t^2}{2}\,\mathbf z^{\mathsf T}\Sigma\mathbf z. \end{aligned}\]

ตอนกระจายจะได้พจน์ไขว้สองตัว $\tfrac t2\mathbf w^{\mathsf T}\Sigma\mathbf z$ กับ $\tfrac t2\mathbf z^{\mathsf T}\Sigma\mathbf w$ สองตัวนี้เท่ากันเพราะ $\Sigma$ สมมาตร จึงรวมเป็น $t\,\mathbf z^{\mathsf T}\Sigma\mathbf w$ ได้ ผลที่ได้คือ $f$ ตามแนวเส้นตรงใด ๆ เป็นพาราโบลาในตัวแปร $t$ ความโค้งของพาราโบลานี้คือ $\mathbf z^{\mathsf T}\Sigma\mathbf z$ ซึ่งแปลว่า $\Sigma$ เองคือ Hessian ของ $f$

ถ้า $\Sigma$ เป็น PD ทุกทิศโค้งขึ้น $f$ เป็นชามที่มีก้นเดียว ก้นชามคือจุดที่พจน์ $t$ หายไปทุกทิศ คือ $\Sigma\mathbf w=\boldsymbol\mu$ และมีคำตอบเดียวเพราะ $\Sigma$ หา inverse ได้ ถ้า $\Sigma$ เป็นแค่ PSD จะมีทิศราง $\mathbf z$ ที่ $\Sigma\mathbf z=\mathbf 0$ ตามทิศนี้ $f$ เหลือแค่ $f(\mathbf w)-t\,\boldsymbol\mu^{\mathsf T}\mathbf z$ ถ้า $\boldsymbol\mu^{\mathsf T}\mathbf z\gt0$ ($\mathbf z$ ให้ผลตอบแทน) ยิ่ง $t$ ใหญ่ $f$ ยิ่งลด ไม่มีที่สิ้นสุด optimizer จะเพิ่มขนาดพอร์ตไปเรื่อย ๆ และถ้า $\Sigma$ เป็น indefinite ก็ไม่มีก้นชามเลย ถ้า optimizer หยุดได้บน matrix แบบนั้น ก็เพราะชนข้อจำกัด (constraint) เช่น “น้ำหนักแต่ละตัวห้ามเกิน 100%” ไม่ได้แปลว่าคำตอบมีความหมาย

รูปร่างของชามยังบอกด้วยว่าหาก้นยากแค่ไหน ถ้า eigenvalue มากสุดกับน้อยสุดต่างกันมาก (condition number ใหญ่) ชามจะเป็นหุบแคบยาว วิธีที่เดินตาม gradient จะวิ่งซิกแซกไปมาระหว่างผนังหุบ เรื่องนี้อยู่ใน gradient descent และ Newton's method covariance รายวันของดัชนีสองตัวมี condition number $9.9655/3.0345\approx3.28$ ชามจึงค่อนข้างกลม ส่วนของแปด asset class คือ 403 หุบแคบกว่ามาก

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

อ่าน eigenvalue เป็นความผันผวน: eigenvalue คือ variance ไม่ใช่ความผันผวน ของดัชนีสองตัว $\lambda_1\approx9.97$ มีหน่วย %² ถ้าอ่านว่า “ทิศแรกผันผวน 9.97% ต่อวัน” ค่าที่ถูกคือ $\sqrt{\lambda_1}=\sqrt{9.97}\approx3.16\%$ ต่อวัน ตัวเลขที่อ่านผิดจึงใหญ่เกินไป $9.97/3.16\approx3.2$ เท่า

เทียบพอร์ตยาวหนึ่งหน่วยกับพอร์ตที่ลงเงินครบ: eigenvector ยาวหนึ่งหน่วยแบบ L2 แต่เงินรวมไม่ใช่ 100% ทิศร่วมของสามธนาคาร $\mathbf u_1=(1,1,1)/\sqrt3$ ลงเงินรวม $3/\sqrt3=\sqrt3\approx173\%$ ความผันผวนของมันคือ $\sqrt{0.15}\approx38.73\%$ ถ้าเอาไปเทียบตรง ๆ กับพอร์ตเงินเท่ากัน 22.36% จะสรุปผิดว่าทิศร่วมเสี่ยงกว่ามาก ที่จริงย่อให้ลงเงิน 100% ก่อนก็ได้ค่าเดียวกัน $38.73\%/\sqrt3\approx22.36\%$

สับสนส่วนแบ่งสองแบบ: “ทิศแรกอธิบายตลาดได้แค่ไหน” กับ “ทิศแรกแบกความเสี่ยงของพอร์ตเราเท่าไร” เป็นคนละตัวเลข ของดัชนีสองตัว ตัวแรกคือ $\lambda_1/\operatorname{tr}\Sigma=9.9655/13\approx76.66\%$ ตัวหลังสำหรับพอร์ต $(0.6,\ 0.4)$ คือ $\lambda_1c_1^2/\mathbf w^{\mathsf T}\Sigma\mathbf w=3.5285/4.032\approx87.51\%$ ถ้าใช้ตัวแรกแทนตัวหลัง จะประเมินว่าต้องป้องกันความเสี่ยงทิศแรกน้อยเกินไป

เชื่อ correlation ที่ตรวจทีละคู่: ผ่านทีละคู่ไม่ได้แปลว่าผ่านทั้งตาราง สามหุ้นที่ correlation $-0.6$ ทุกคู่ผ่านการตรวจทีละคู่ เพราะ $1-0.6^2=0.64\gt0$ แต่ทิศร่วมมี eigenvalue $0.0625(1-1.2)=-0.0125$ ถ้าใส่ตารางนี้ใน optimizer มันจะเจอพอร์ตที่ “ความเสี่ยงติดลบ” แล้วทุ่มเงินเข้าไป

ใช้เกณฑ์ eigenvalue กับ matrix ไม่สมมาตร: eigenvalues บวกทั้งหมดไม่ได้รับประกันว่า $\mathbf x^{\mathsf T}A\mathbf x\gt0$ ถ้า $A$ ไม่สมมาตร $A=\begin{bmatrix}1&4\\0&1\end{bmatrix}$ มี eigenvalues 1 กับ 1 แต่ที่ $\mathbf x=(1,-1)$ ได้ $1-4+1=-2$ ต้องดู eigenvalues ของ $\tfrac12(A+A^{\mathsf T})$ ซึ่งคือ 3 กับ $-1$

ตัดทิศเล็กทิ้งหมด: การเก็บแค่ eigenvalues ใหญ่ ๆ แล้วตั้งตัวที่เหลือเป็นศูนย์ทำให้ covariance หา inverse ไม่ได้ทันที เพราะ determinant คือผลคูณของ eigenvalues ซึ่งกลายเป็นศูนย์ ในตารางแปดกลุ่ม ถ้าตั้ง $\lambda_8=0$ optimizer จะเห็นพอร์ตตามทิศที่ 8 (เกือบทั้งหมดเป็นพันธบัตรสหรัฐ) ว่าไม่มีความเสี่ยงเลย ทั้งที่ความผันผวนจริงตามทิศนั้นคือ $\sqrt{0.000632}\approx2.5\%$

function jacobi(A0) {                       // symmetric matrices only
  const n = A0.length, A = A0.map(r => r.slice());
  const V = A.map((r, i) => r.map((_, j) => (i === j ? 1 : 0)));
  for (let sweep = 0; sweep < 100; sweep++) {
    let off = 0;
    for (let i = 0; i < n; i++) for (let j = i + 1; j < n; j++) off += A[i][j] ** 2;
    if (off < 1e-30) break;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) {
      if (A[p][q] === 0) continue;
      const th = (A[q][q] - A[p][p]) / (2 * A[p][q]);
      const t = Math.sign(th || 1) / (Math.abs(th) + Math.sqrt(th * th + 1));
      const c = 1 / Math.sqrt(t * t + 1), s = t * c;
      for (let k = 0; k < n; k++) { const a = A[k][p], b = A[k][q]; A[k][p] = c * a - s * b; A[k][q] = s * a + c * b; }
      for (let k = 0; k < n; k++) { const a = A[p][k], b = A[q][k]; A[p][k] = c * a - s * b; A[q][k] = s * a + c * b; }
      for (let k = 0; k < n; k++) { const a = V[k][p], b = V[k][q]; V[k][p] = c * a - s * b; V[k][q] = s * a + c * b; }
    }
  }
  const order = A.map((_, i) => i).sort((i, j) => A[j][j] - A[i][i]);
  return { values: order.map(i => A[i][i]), vectors: order.map(i => V.map(r => r[i])) };
}
const quad = (A, x) => x.reduce((s, xi, i) => s + xi * A[i].reduce((t, a, j) => t + a * x[j], 0), 0);

สิ่งที่ควรตอบได้หลังอ่าน

  • eigenvector คือทิศที่ matrix คูณแล้วไม่หมุน แค่ยืดหรือหด และ eigenvalue คือตัวยืดนั้น หาได้จาก $\det(A-\lambda I)=0$ แล้วตรวจคำตอบได้ทันที ผลรวมของ eigenvalues ต้องเท่ากับ trace และผลคูณต้องเท่ากับ determinant
  • matrix สมมาตรมี eigenvectors ตั้งฉากกันเสมอ จึงแยกเป็น $Q\Lambda Q^{\mathsf T}$ ได้ อ่านว่าหมุน ยืด หมุนกลับ ในพิกัดของ eigenvectors variance ของพอร์ตเหลือแค่ $\sum\lambda_ic_i^2$ ไม่มีพจน์ไขว้
  • covariance ทุกตัวต้องเป็น PSD คือ eigenvalues ไม่ติดลบ ถ้าเป็น PD ด้วย (eigenvalues บวกทุกตัว) ก็ไม่มีพอร์ตไหนที่ความเสี่ยงเป็นศูนย์ และหา inverse ได้ matrix $2\times2$ ตรวจด้วยมือได้ด้วย Sylvester's criterion
  • หุ้นสามตัวที่ correlation 0.7 ทุกคู่มีทิศร่วมที่ eigenvalue 0.15 ใหญ่กว่าทิศ spread 8 เท่า พอร์ตเงินเท่ากันจึงผันผวน 22.36% ไม่ใช่ 14.43% และถ้าทุกคู่ correlation เท่ากัน ค่านั้นต้องไม่ต่ำกว่า −0.5
  • covariance จริงของแปดกลุ่มมีทิศแรกแบก 74.73% ของ trace และ condition number ราว 403 แปลว่า $\Sigma^{-1}$ ในสูตรจัดพอร์ตจะขยาย error ของการประมาณมาก
