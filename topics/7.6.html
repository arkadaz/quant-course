7.6 Eigenvalues and Positive Definiteness

เปลี่ยนแกนให้เห็นทิศของความเสี่ยง แล้วตรวจว่า covariance เป็นไปได้จริงหรือไม่

สมมติ JPM, BAC และ WFC แต่ละตัวมี SD 25% ต่อปี ถือตัวละหนึ่งในสามของ NAV จะได้ SD $25\%/\sqrt3\approx14.43\%$ หรือไม่ ถ้า correlation ทุกคู่เท่ากับ 0.7?

ดูคำตอบ

ไม่ได้ สูตรหารด้วย $\sqrt3$ นั้นใช้กรณี covariance ระหว่างคู่เป็นศูนย์ ภายใต้สมมติฐานนี้ variance พอร์ตเท่ากับ $0.25^2(1+2\times0.7)/3=0.05$ จึงมี SD ประมาณ 22.36% หุ้นสามชื่อยังมีทิศร่วมที่กระจายออกได้ไม่มาก

เราจะค่อย ๆ หาแกนร่วมนี้ด้วย eigenvectors และดูว่า eigenvalues ทำหน้าที่เป็น variance ของพอร์ตแบบใด ตัวเลขทั้งหมดในหน้านี้เป็นตัวอย่างสมมติ ไม่ใช่ค่าที่อ้างว่าเก็บจากตลาดปัจจุบัน

1. Eigenvector: ทิศที่ matrix ไม่ส่งออกไปนอกเส้นเดิม

สำหรับ square matrix $A$ เราเรียก $u\ne0$ ว่า eigenvector หาก $Au=\lambda u$ ค่า $\lambda$ คือ eigenvalue คูณด้วยค่าบวกจะยืด/หด ค่าลบกลับทิศ และศูนย์ส่ง vector ไปศูนย์ ตามความหมายของ null space ใน 7.5

\[ \begin{aligned} A&=\begin{bmatrix}2&0\\0&1\end{bmatrix},\\ A\begin{bmatrix}1\\0\end{bmatrix}&=2\begin{bmatrix}1\\0\end{bmatrix},\qquad A\begin{bmatrix}0\\1\end{bmatrix}=1\begin{bmatrix}0\\1\end{bmatrix},\\ A\begin{bmatrix}1\\1\end{bmatrix}&=\begin{bmatrix}2\\1\end{bmatrix}. \end{aligned} \]

สองแกนแรกเป็น eigenvectors ส่วน $(1,1)$ ไม่ใช่ เพราะ output ไม่เป็น scalar เท่าเดียวคูณทุกพิกัด ถ้า $u$ เป็น eigenvector แล้ว $cu$ สำหรับ $c\ne0$ ก็เป็นด้วย จึงมักกำหนด $\|u\|_2=1$ เพื่อให้เทียบสเกลได้

คำว่า eigenvalue ยังไม่ได้แปลว่า variance สำหรับ matrix ทั่วไป ความหมายทางความเสี่ยงจะตามมาเมื่อ $A$ เป็น covariance และเราระบุหน่วยของข้อมูลกับ normalization ของ vector แล้ว

2. หา eigenvalues โดยถามว่าเมื่อไรระบบมีคำตอบที่ไม่เป็นศูนย์

จัดรูป $Au=\lambda u$ เป็น $(A-\lambda I)u=0$ ถ้า $A-\lambda I$ กลับด้านได้ คำตอบมีเพียง $u=0$ ซึ่งไม่ใช่ eigenvector ดังนั้นค่าที่ต้องการทำให้ determinant เป็นศูนย์ นี่คือ characteristic equation

เริ่มจากข้อมูลสองชุดที่รูปเรียกว่า SPX และ QQQ ให้ $R$ เป็น daily returns ที่หัก mean แล้ว ใช้หน่วยเศษส่วน และกำหนด covariance ดังนี้:

\[ \Sigma=\begin{bmatrix}0.0004&0.00024\\0.00024&0.0009\end{bmatrix},\qquad \sigma_1=2\%,\quad\sigma_2=3\%. \]

Covariance นอกแนวทแยงมาจาก $0.4(0.02)(0.03)=0.00024$ จึงเป็นสมมติฐาน correlation 0.4 ทุกช่องอยู่ที่ horizon หนึ่งวันเหมือนกัน ไม่ได้ผสม daily variance กับ annual covariance

\[ \begin{aligned} \det(\Sigma-\lambda I)&=(0.0004-\lambda)(0.0009-\lambda)\\ &\quad-0.00024^2\\ &=\lambda^2-0.0013\lambda+0.0000003024,\\ 0&=\lambda^2-0.0013\lambda+0.0000003024,\\ \lambda_{1,2}&=\frac{0.0013\pm\sqrt{0.0000004804}}{2},\\ \lambda_1&\approx0.000996554469,\\ \lambda_2&\approx0.000303445531. \end{aligned} \]

ทั้งคู่เป็น variance ในหน่วย return เศษส่วนยกกำลังสอง ยังไม่ใช่ SD และยังไม่ใช่ risk ของพอร์ตที่ใส่เงิน 100% โดยอัตโนมัติ

หาทิศของค่าตัวแรกจากสมการแถวหนึ่ง แล้ว normalize:

\[ \begin{aligned} (0.0004-\lambda_1)x+0.00024y&=0,\\ y/x&=(\lambda_1-0.0004)/0.00024\\ &\approx2.485643621,\\ u_1&=\frac{(1,2.485643621)^{\mathsf T}}{\sqrt{1+2.485643621^2}}\\ &\approx(0.373237645,0.927735771)^{\mathsf T},\\ u_2&\approx(0.927735771,-0.373237645)^{\mathsf T}. \end{aligned} \]

แทนกลับจะได้ $\Sigma u_i\approx\lambda_i u_i$ และ $u_1^{\mathsf T}u_2\approx0$ การกลับเครื่องหมาย eigenvector ทั้งตัวไม่เปลี่ยน eigenvalue เลข 2.4856 คือ slope ของแกนหลัก ไม่ใช่ regression slope หรือคำทำนายว่า QQQ ต้องเคลื่อนไหวเท่านี้เมื่อ SPX เปลี่ยน 1%

3. เหตุใด covariance จึงเลือกแกนที่ตั้งฉากกันได้?

Covariance เป็น real symmetric matrix เพราะ $\operatorname{Cov}(R_i,R_j)=\operatorname{Cov}(R_j,R_i)$ สำหรับ matrix ประเภทนี้ spectral theorem รับประกัน eigenvalues จริงและ orthonormal eigenbasis ครบจำนวนมิติ

ส่วนที่พิสูจน์สั้น ๆ ได้คือ eigenvectors ของค่าที่ต่างกันต้องตั้งฉาก: ใช้ความสมมาตรย้าย $A$ ไปอีกฝั่งของ inner product

\[ \begin{aligned} u_i^{\mathsf T}Au_j&=\lambda_j u_i^{\mathsf T}u_j,\\ u_i^{\mathsf T}Au_j&=(Au_i)^{\mathsf T}u_j=\lambda_i u_i^{\mathsf T}u_j,\\ (\lambda_i-\lambda_j)u_i^{\mathsf T}u_j&=0,\\ \lambda_i\ne\lambda_j&\ \Longrightarrow\ u_i^{\mathsf T}u_j=0. \end{aligned} \]

เมื่อ eigenvalue ซ้ำ สามารถเลือก basis ที่ orthonormal ภายใน eigenspace นั้นได้ แต่ eigenvectors สองตัวที่หยิบมาเองไม่จำเป็นต้องตั้งฉาก และทิศที่โปรแกรมรายงานอาจต่างกันทั้งที่ subspace เดิม

เก็บ unit eigenvectors เป็นคอลัมน์ของ $Q$ และ eigenvalues ไว้บน diagonal ของ $\Lambda$ จะได้:

\[ \begin{aligned} AQ&=Q\Lambda,\qquad Q^{\mathsf T}Q=QQ^{\mathsf T}=I,\\ A&=Q\Lambda Q^{\mathsf T},\\ A^{-1}&=Q\Lambda^{-1}Q^{\mathsf T}\quad(\lambda_i\ne0\ \forall i). \end{aligned} \]

ที่นี่ $Q^{-1}=Q^{\mathsf T}$ เพราะคอลัมน์ orthonormal ไม่ใช่เพราะ inverse เท่ากับ transpose สำหรับทุก basis ตามที่เตือนไว้ในบท 6 และ 7.2 ผลของเปลี่ยนแกนอาจรวมการกลับเครื่องหมายแกนด้วย

รูปนี้ยังให้วิธีตรวจผล: trace เท่ากับผลรวม eigenvalues และ determinant เท่ากับผลคูณ เพราะ:

\[ \begin{aligned} \operatorname{tr}A&=\sum_i\sum_j\lambda_j q_{ij}^2=\sum_j\lambda_j,\\ \det A&=(\det Q)^2\prod_j\lambda_j=\prod_j\lambda_j. \end{aligned} \]

สำหรับตัวอย่างสองมิติ ผลรวมต้องได้ 0.0013 และผลคูณ $3.024\times10^{-7}$ ถ้า normalize vectors หรือเรียง eigenvalues ผิดคู่ การแทนกลับ $Q\Lambda Q^{\mathsf T}$ จะตรวจพบได้ดีกว่ามองตัวเลขทีละตัว

4. เปลี่ยนพิกัดของ returns กับเปลี่ยนพิกัดของพอร์ต

ให้ $Y=Q^{\mathsf T}R$ เป็น returns ในแกนใหม่ จาก linearity ของ covariance:

\[ \operatorname{Cov}(Y)=Q^{\mathsf T}\Sigma Q=\Lambda. \]

จึงมี $\operatorname{Var}(u_i^{\mathsf T}R)=\lambda_i$ และ SD เท่ากับ $\sqrt{\lambda_i}$ สำหรับ unit eigenvector ส่วน portfolio weights $w$ มีพิกัดอีกชุดคือ $c=Q^{\mathsf T}w$ โดย $w=Qc$ ทำให้:

\[ \begin{aligned} w^{\mathsf T}R&=c^{\mathsf T}Y,\\ w^{\mathsf T}\Sigma w&=c^{\mathsf T}\Lambda c=\sum_i\lambda_i c_i^2,\\ \|w\|_2^2&=\sum_i c_i^2. \end{aligned} \]

ถ้า normalize $\|w\|_2=1$ จะได้ variance เป็น weighted average ของ eigenvalues โดย weights คือ $c_i^2$ จึงอยู่ระหว่าง $\lambda_{\min}$ และ $\lambda_{\max}$ และแตะขอบได้ที่ eigenvectors นั้น ๆ แต่เงื่อนไขนี้ไม่ใช่ $\sum w_i=1$ หรือ gross exposure เท่ากัน

สำหรับพอร์ต $w=(0.6,0.4)$ คำนวณได้ $c\approx(0.595036895,0.407346405)$ จึงมี:

\[ \begin{aligned} V&=0.6^2(0.0004)+2(0.6)(0.4)(0.00024)\\ &\quad+0.4^2(0.0009)=0.0004032,\\ \lambda_1c_1^2&\approx0.000352848951,\\ \lambda_2c_2^2&\approx0.000050351049,\\ \sqrt V&\approx0.020079841=2.0079841\%. \end{aligned} \]

แกนแรกจึงรับประมาณ 87.51% ของ variance พอร์ตนี้ แต่ $\lambda_1/\operatorname{tr}\Sigma\approx76.66\%$ คือส่วนของ total coordinate variance ที่แกนแรกอธิบายตามเกณฑ์ PCA ทั้งสองจำนวนตอบคนละคำถาม

ส่วนแบ่งแบบ eigenbasis ไม่ติดลบเมื่อ covariance เป็น PSD ต่างจาก asset-level contributions ใน 7.3 ที่อาจติดลบเมื่อบาง asset ช่วย hedge และส่วนแบ่ง trace ยังขึ้นกับหน่วย/การ standardize ของข้อมูลด้วย

5. Positive semidefinite กับ positive definite ต่างกันตรงศูนย์

Covariance ที่มี finite second moments ต้องให้ $w^{\mathsf T}\Sigma w=\operatorname{Var}(w^{\mathsf T}R)\ge0$ สำหรับทุก $w$ นี่คือ positive semidefinite (PSD) ส่วน positive definite (PD) กำหนดให้เป็นบวกอย่างเคร่งครัดเมื่อ $w\ne0$

Real symmetric matrixQuadratic formEigenvalues
PSDไม่ติดลบทุกทิศ; บางทิศอาจเป็นศูนย์ทุกค่า $\ge0$
PDเป็นบวกทุกทิศที่ไม่เป็นศูนย์ทุกค่า $\gt0$
Indefiniteมีทั้งทิศบวกและทิศลบมีทั้งค่าบวกและค่าลบ

เหตุผลอยู่ใน $w^{\mathsf T}Aw=\sum_i\lambda_i c_i^2$: ถ้าทุกค่าไม่ลบผลรวมไม่ลบ และถ้ามีค่าลบ เลือก $w=u_i$ จะได้ค่าลบนั้นทันที ดังนั้น covariance จริงเป็น PSD แต่อาจ singular ได้ เช่นผลตอบแทนบางตัวซ้ำกันพอดี

การมี eigenvalues ไม่เป็นศูนย์ทั้งหมดรับรอง invertibility แต่ไม่รับรอง PD เช่น $\operatorname{diag}(1,-1)$ กลับด้านได้และยังให้ quadratic form ติดลบในบางทิศ

ทำไมต้องย้ำคำว่า symmetric?

$A=\begin{bmatrix}1&4\\0&1\end{bmatrix}$ มี eigenvalues ทั้งสองเท่ากับ 1 แต่ที่ $x=(1,-1)$ กลับได้ $x^{\mathsf T}Ax=-2$ เกณฑ์ “eigenvalues บวกแล้ว quadratic form บวก” ที่ใช้ข้างต้นอาศัย real symmetry อย่านำไปใช้กับ matrix ทั่วไปโดยข้ามเงื่อนไขนี้

Sylvester’s criterion: ตรวจ PD โดยไม่หา eigenvalues ทุกตัว

สำหรับ real symmetric matrix ขนาด 2×2 ที่ $a\gt0$ ใช้การจัดกำลังสอง:

\[ \begin{aligned} A&=\begin{bmatrix}a&b\\b&d\end{bmatrix},\\ x^{\mathsf T}Ax&=a\left(x_1+\frac ba x_2\right)^2 +\frac{ad-b^2}{a}x_2^2. \end{aligned} \]

จึงเป็น PD ก็ต่อเมื่อ $a\gt0$ และ $ad-b^2\gt0$ ตัวอย่างรายวันผ่านเพราะ $a=0.0004$ และ determinant $3.024\times10^{-7}$ เป็นบวกทั้งคู่

สำหรับขนาดทั่วไป Sylvester’s criterion บอกว่า PD ก็ต่อเมื่อ leading principal minors หรือ determinants ของบล็อกบนซ้ายขนาด 1,2,…,n เป็นบวกทั้งหมด มองได้เป็นการจัดกำลังสองต่อเนื่องที่ได้ coefficients $D_k/D_{k-1}$ โดย $D_0=1$

ถ้าจะตรวจ PSD ห้ามเปลี่ยนเพียง “บวก” เป็น “ไม่ลบ” ในเกณฑ์ leading minors เช่น $\operatorname{diag}(0,-1)$ มี leading minors 0,0 แต่ quadratic form ที่ $(0,1)$ เท่ากับ −1 เกณฑ์ PSD ต้องตรวจ ทุก principal minor ไม่ใช่เฉพาะบล็อกบนซ้าย หรือใช้ eigenvalues ของ matrix สมมาตร

6. สามธนาคาร: ทิศร่วมหนึ่งทิศ และ spread plane สองมิติ

กลับไป JPM/BAC/WFC สมมติให้ SD ต่อปีเท่ากัน $\sigma=0.25$ และ correlation ทุกคู่เท่ากับ $\rho$ เขียน covariance ด้วย $\mathbf1=(1,1,1)^{\mathsf T}$ ได้ว่า:

\[ \begin{aligned} \Sigma&=\sigma^2\begin{bmatrix}1&\rho&\rho\\\rho&1&\rho\\\rho&\rho&1\end{bmatrix}\\ &=\sigma^2\{(1-\rho)I+\rho\mathbf1\mathbf1^{\mathsf T}\}. \end{aligned} \]

สำหรับทิศร่วม $u_1=\mathbf1/\sqrt3$ ผลคูณ $\mathbf1\mathbf1^{\mathsf T}u_1=3u_1$ ส่วนทิศที่ sum coordinates เป็นศูนย์จะถูกพจน์นี้ส่งไปศูนย์ จึงหา eigenvalues ได้ทันทีโดยไม่ต้องเริ่มจาก cubic equation:

\[ \begin{aligned} \Sigma u_1&=\sigma^2(1+2\rho)u_1,\\ u_2&=\frac{(1,-1,0)^{\mathsf T}}{\sqrt2},\qquad u_3=\frac{(1,1,-2)^{\mathsf T}}{\sqrt6},\\ \Sigma u_2&=\sigma^2(1-\rho)u_2,\\ \Sigma u_3&=\sigma^2(1-\rho)u_3. \end{aligned} \]

ทั้งสาม vectors เป็น orthonormal เราเลือก $u_2,u_3$ เป็น basis ของ zero-sum plane แต่เปลี่ยนเป็น orthonormal basis อื่นในระนาบนั้นก็ได้ เนื่องจาก eigenvalue ซ้ำ จึงไม่ควรตีความการสลับแกนที่โปรแกรมรายงานว่าเศรษฐกิจเปลี่ยนทิศเสมอไป

\[ \begin{aligned} \rho=0.7:\quad\lambda_{\rm common}&=0.0625(2.4)=0.15,\\ \lambda_{\rm spread}&=0.0625(0.3)=0.01875\quad\text{(twice)},\\ \operatorname{tr}\Sigma&=0.15+2(0.01875)=0.1875,\\ \det\Sigma&=0.15(0.01875)^2=0.000052734375. \end{aligned} \]

ทิศร่วมอธิบาย 80% ของ trace ส่วนอีกสองแกนคนละ 10% สำหรับสมมติฐานนี้ ไม่ใช่หลักฐานว่าปัจจัยตลาดจริงรับความเสี่ยง 80% ในพอร์ตธนาคารทุกแบบ และเมื่อ $\rho\lt0$ ทิศร่วมอาจมี eigenvalue เล็กกว่า spread ไม่ควรเรียกทิศร่วมว่า “ทิศใหญ่” โดยไม่ดูค่า

ตรวจคำตอบอีกทางด้วย characteristic polynomial

แยกสเกล $\Sigma=\sigma^2C$ ให้ $k=\lambda/\sigma^2$ และ $u=1-k$ เมื่อขยาย determinant ของ $C-kI$ ได้:

\[ \begin{aligned} 0&=u^3-3\rho^2u+2\rho^3\\ &=(u+2\rho)(u-\rho)^2,\\ k&=1+2\rho,\quad1-\rho,\quad1-\rho. \end{aligned} \]

ที่ $\rho=0.7$ polynomial คือ $u^3-1.47u+0.686$ มีราก $-1.4,0.7,0.7$ จึงให้ $k=2.4,0.3,0.3$ ตรงกับวิธีทิศร่วม ส่วน leading minors ของ correlation matrix คือ $1,0.51,0.216$ ซึ่งเป็นบวกทั้งหมด

7. แปลเป็นพอร์ต: L2 หนึ่ง กับลงทุนเงินครบหนึ่ง ไม่ใช่ข้อกำหนดเดียวกัน

$u_2=(1,-1,0)/\sqrt2$L2 = 1; net = 0, gross = $\sqrt2$$\sqrt{0.01875}\approx13.69\%$

สองแถวแรกเทียบที่ L2 เท่ากัน ไม่ได้ใช้เงินสดหรือ gross exposure เท่ากัน พอร์ตเท่ากันทุกชื่อในแถวสามคือ $u_1/\sqrt3$ จึงมี variance $\lambda_{\rm common}/3$ ซึ่งปิดคำถามต้นหน้า

$u_2$ ตัดทิศร่วมออกได้ในโมเดลที่ loadings เหมือนกันนี้ แต่ dollar-neutral ไม่ได้แปลว่า beta-neutral ในตลาดจริง หรือปลอดภัยจาก basis risk, liquidity, borrow costs และ jump risk การเห็น SD ต่ำลงจึงไม่พอให้สรุปว่าเพิ่ม leverage แล้วปลอดภัยเท่าเดิม

ถ้าเพิ่ม $\rho$ เป็น 0.9 โดย ตรึง individual SD ที่ 25% spread eigenvalue ลดเป็น 0.00625 และ SD ลดเป็นประมาณ 7.91% แต่ถ้า individual SD เพิ่มเป็น 50% พร้อมกัน spread SD จะเป็น $0.50\sqrt{0.1}\approx15.81\%$ สูงกว่าจุดเริ่ม 13.69%

นี่เป็นผลของโมเดลที่กำหนด ไม่ใช่กฎว่าพอร์ต long–short ได้ประโยชน์จากวิกฤตหรือจาก correlation ที่เพิ่มเสมอ

8. Pairwise correlations ดูถูกต้องทั้งหมด ยังรวมเป็น covariance ที่ผิดได้

จาก eigenvalues ของสามตัวข้างต้น หาก $\sigma\gt0$ จะเป็น PSD ก็ต่อเมื่อทั้ง $1+2\rho\ge0$ และ $1-\rho\ge0$ จึงได้:

\[ \begin{aligned} \Sigma\text{ is PSD}&\ \Longleftrightarrow\ -\tfrac12\le\rho\le1,\\ \Sigma\text{ is PD}&\ \Longleftrightarrow\ -\tfrac12\lt\rho\lt1. \end{aligned} \]

ที่ $\rho=-0.5$ ทิศร่วมเป็นศูนย์แต่สอง spread directions ยังเป็นบวก จึง rank 2 ที่ $\rho=1$ เหลือทิศร่วมอย่างเดียวจึง rank 1 ทั้งสองเป็น covariance ที่เป็นไปได้ แต่ไม่มี inverse

ลองตั้งทุกคู่เป็น −0.6 แต่ละคู่ยังอยู่ระหว่าง −1 กับ 1 และทุก 2×2 correlation block มี determinant $1-0.6^2=0.64$ เป็นบวก ทว่า:

\[ \begin{aligned} \lambda_{\rm common}&=0.0625(1-1.2)=-0.0125,\\ w=(1,1,1)^{\mathsf T}/3:\quad w^{\mathsf T}\Sigma w&=-0.0125/3\\ &\approx-0.004166667,\\ \det C&=(1.6)^2(-0.2)=-0.512. \end{aligned} \]

Variance ติดลบเป็นไปไม่ได้ จึงต้องปฏิเสธ matrix นี้ในฐานะ covariance ไม่ใช่ตีความว่าเป็นพอร์ตที่ hedge ได้ดีกว่าศูนย์

9. เชื่อมกับ optimizer และการตรวจ covariance ก่อนใช้

พิจารณา objective ที่ต้องการ minimize คือ $f(w)=\frac12w^{\mathsf T}\Sigma w-\mu^{\mathsf T}w$ เมื่อขยับ $w$ ตามทิศ $z$ ด้วยขนาด $t$ จะได้:

\[ \begin{aligned} f(w+tz)&=f(w)+t z^{\mathsf T}(\Sigma w-\mu)\\ &\quad+\frac{t^2}{2}z^{\mathsf T}\Sigma z. \end{aligned} \]

พจน์ $t^2$ บอก curvature ตามทิศนั้น ในภาษาอนุพันธ์ Hessian ของ $f$ คือ $\Sigma$ ถ้า PD จะเป็น strictly convex quadratic บน $\mathbb R^n$ และมี minimizer เดียว ส่วนกรณี maximize utility ใน 7.5 เปลี่ยนเครื่องหมายเป็น strictly concave

PSD ที่ singular อาจยังมี optimum เดียวเมื่อ constraints ปิด null directions ออก ดังตัวอย่าง sum weights ใน 7.5 แต่ถ้ามี linear gain ตาม null direction ที่ constraints ไม่จำกัด objective อาจไร้ขอบเขต ส่วน PD อย่างเดียวไม่ได้รับรองว่าทุก algorithm หรือทุก step size จะลู่เข้า

Eigenvalue เล็กที่ยังบวกทำให้ inverse ขยายพิกัดนั้นด้วย $1/\lambda_i$ สำหรับ SPD matrix condition number ใน 2-norm คือ $\lambda_{\max}/\lambda_{\min}$ เพราะการคูณยืดแต่ละ orthonormal direction ตาม eigenvalue ตัวอย่างรายวันมีค่าประมาณ 3.2841 แต่เมื่อค่าต่ำสุดเข้าใกล้ศูนย์ คำตอบอาจไวต่อ estimation error มาก

สิ่งที่พบควรถามต่อก่อนแก้
Covariance ไม่สมมาตรคู่ข้อมูล ลำดับ assets และหน่วยตรงกันหรือไม่? การเฉลี่ยกับ transpose แก้ symmetry ไม่ได้รับรอง PSD
Eigenvalue ติดลบชัดเจนใช้ pairwise estimates คนละวัน หรือประกอบ entries จากสมมติฐานที่ขัดกันหรือไม่?
Eigenvalue ติดลบเล็กมากเทียบกับ matrix scale และ numerical error ก่อนแยกจากค่าที่ควรเป็นศูนย์ ห้ามใช้ cutoff เดียวทุกหน่วย
Eigenvalue ศูนย์หรือเล็กข้อมูลซ้ำทิศ วันน้อย หรือ risk model ขาด residual directions? Shrinkage/factor model ต้องมีเหตุผลและทดสอบเพิ่ม

Centered sample covariance จากข้อมูลครบชุดเดียวมีรูป $R^{\mathsf T}R/(T-1)$ จึงเป็น PSD ใน exact arithmetic แม้ assets มากกว่าวันก็ทำให้ rank ลด ไม่ได้สร้าง variance ติดลบอย่างแท้จริง การซ่อม matrix ให้ PSD จึงเป็นการเปลี่ยนโมเดลที่ต้องเปิดเผย ไม่ใช่สร้างข้อมูลใหม่

หากมี eigenvalue ลบ optimizer ที่ถูก constraints จำกัดก็ยังอาจคืนคำตอบหรือมี optimum ได้ ดังนั้น “โปรแกรม converge” ไม่ใช่หลักฐานว่าคำตอบนั้นเป็นความเสี่ยงที่ตีความได้

สูตร eigenvalues 2×2 นี้ใช้กับตัวอย่างขนาดเล็กที่มีสเกลเหมาะสม ไม่ใช่ eigensolver ทั่วไปสำหรับระบบ ill-conditioned เราคืน unit vectors เป็นคอลัมน์ของ $Q$ และเก็บ eigenvalues เรียงให้ตรงกัน

function shape(A) {
  if (!Array.isArray(A) || !A.length || !Array.isArray(A[0]) || !A[0].length) throw new TypeError('Need a rectangular matrix');
  const n = A[0].length;
  if ([...A].some(row => !Array.isArray(row) || row.length !== n || ![...row].every(Number.isFinite))) throw new TypeError('Need a finite rectangular matrix');
  return [A.length, n];
}
function dot(a, b) {
  if (!Array.isArray(a) || !Array.isArray(b) || !a.length || a.length !== b.length || ![...a, ...b].every(Number.isFinite)) throw new TypeError('Need matching finite vectors');
  const result = a.reduce((s, x, i) => s + x * b[i], 0);
  if (!Number.isFinite(result)) throw new RangeError('Arithmetic overflow');
  return result;
}
function transpose(A) { const [, n] = shape(A); return Array.from({length: n}, (_, j) => A.map(row => row[j])); }
function multiply(A, B) { shape(A); const Bt = transpose(B); return A.map(row => Bt.map(col => dot(row, col))); }
function matvec(A, x) { shape(A); return A.map(row => dot(row, x)); }
const quadratic = (A, x) => dot(x, matvec(A, x));
function diagonal(values) {
  dot(values, values.map(() => 0));
  return values.map((x, i) => values.map((_, j) => i === j ? x : 0));
}
function spectral2(A) {
  const [m, n] = shape(A);
  if (m !== 2 || n !== 2) throw new RangeError('Need a 2 by 2 matrix');
  if (A[0][1] !== A[1][0]) throw new RangeError('Need a symmetric matrix');
  const a = A[0][0], b = A[0][1], d = A[1][1];
  const radius = Math.hypot(a - d, 2 * b), angle = .5 * Math.atan2(2 * b, a - d);
  const c = Math.cos(angle), s = Math.sin(angle), values = [(a + d + radius) / 2, (a + d - radius) / 2];
  if (![...values, c, s].every(Number.isFinite)) throw new RangeError('Arithmetic overflow');
  return {values, Q: [[c, s], [s, -c]]};
}
function equicovariance(rho, sigma = .25) {
  if (!Number.isFinite(rho) || Math.abs(rho) > 1 || !Number.isFinite(sigma) || sigma <= 0) throw new RangeError('Invalid correlation or standard deviation');
  const variance = sigma * sigma;
  if (!Number.isFinite(variance) || variance === 0) throw new RangeError('Variance outside working range');
  // Pairwise admissibility is not a PSD certificate: rho=-.6 is intentional below.
  return Array.from({length: 3}, (_, i) => Array.from({length: 3}, (_, j) => variance * (i === j ? 1 : rho)));
}
const Sigma = [[.0004, .00024], [.00024, .0009]], eig = spectral2(Sigma), Qt = transpose(eig.Q);
const w = [.6, .4], coords = matvec(Qt, w), terms = coords.map((c, i) => eig.values[i] * c * c);
const V = quadratic(Sigma, w), inverse = multiply(multiply(eig.Q, diagonal(eig.values.map(x => 1 / x))), Qt);

const u2 = [1, -1, 0].map(x => x / Math.sqrt(2));
const u3 = [1, 1, -2].map(x => x / Math.sqrt(6));
const Q3 = transpose([u1, u2, u3]), bank = equicovariance(.7), equal = [1/3, 1/3, 1/3];
const states = [-1, 0, 1].map(x => [x, x*x - 2/3]);
