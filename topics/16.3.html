16.3 MA, ARMA, and ARIMA

แบบจำลอง MA จำ “ข่าว” ของเมื่อวาน ไม่ได้จำ “ค่า” ของเมื่อวาน ความจำของมันจึงหมดหลังไม่กี่งวด ราคาซื้อขายที่เด้งไปมาระหว่าง bid กับ ask คือ MA(1) แบบหนึ่ง และใช้ถอดได้ทั้งต้นทุนการซื้อขาย (spread) และความผันผวนจริง

ฝ่ายความเสี่ยงของธนาคารต้องรู้ว่าหุ้นตัวหนึ่งแกว่งแรงแค่ไหนในหนึ่งปี เพราะตัวเลขนี้ใช้ตั้งวงเงินขาดทุนของโต๊ะเทรด วงเงินนี้มักตั้งด้วย VaR (Value at Risk) ซึ่งเป็นยอดขาดทุนที่ไม่ควรเกินในวันปกติ เช่นเกินได้แค่ 1 วันใน 100 วัน ข้อมูลที่มีคือราคาซื้อขายทุกนาที จุดข้อมูลเยอะมาก จึงดูเหมือนจะวัดได้แม่น

ในตลาดหุ้น มีคนตั้งราคารอซื้อและรอขายไว้ตลอด ราคาสูงสุดที่มีคนรอซื้อเรียกว่า bid ราคาต่ำสุดที่มีคนรอขายเรียกว่า ask ช่องว่างระหว่างสองราคานี้คือ bid–ask spread ใครซื้อแล้วขายทันทีจะเสียเงินเท่าช่องว่างนี้ ข้อมูลของเราไม่มี bid และ ask มีแค่ราคาที่ซื้อขายกันจริง

ของที่วัดได้ (ตัวเลขสมมติ):

  • ราคาหุ้นประมาณ \$42
  • ผลตอบแทนรายนาที $X_t$ คือราคาเปลี่ยนไปกี่เปอร์เซ็นต์ในนาทีที่ $t$ วัดได้ SD $=0.10\%$ ต่อนาที
  • autocorrelation ที่ lag 1 คือ correlation ระหว่างผลตอบแทนนาทีนี้กับนาทีก่อน วัดได้ $\hat\rho_1=-0.345$ ค่าติดลบแปลว่านาทีที่ราคาขึ้นมักตามด้วยนาทีที่ราคาลง
  • ตลาดเปิดวันละ 300 นาที (สมมติของโจทย์) และปีหนึ่งมี 252 วันทำการ

ระบบความเสี่ยงถือว่าแต่ละนาทีอิสระกัน ถ้าอิสระกัน variance ของแต่ละนาทีบวกกันได้ SD จึงโตตามรากของจำนวนนาที ระบบจึงขยายจากนาทีเป็นปีแบบนี้

\[ \begin{aligned} n&=300\times252=75{,}600,\\ \sqrt n&=274.95,\\ \sigma_{\rm naive}&=0.10\%\times274.95=27.5\%. \end{aligned} \]

แล้วนำ 27.5% ต่อปีไปคิด VaR คำถามมีสองข้อ ตัวเลข 27.5% เชื่อได้ไหม และ bid–ask spread ของหุ้นตัวนี้กว้างกี่เซนต์?

ลองตอบก่อนเปิดเฉลย

หน้านี้จะคำนวณทุกตัวเลขให้ดูทีละขั้น โดยสมมติว่าราคาเป็นไปตามแบบจำลองของ Roll คือราคาที่เห็นเท่ากับมูลค่าจริงที่ขยับตามข่าว บวกการเด้งไปมาระหว่าง bid กับ ask ผลคือ spread ประมาณ 0.1174% ของราคา หรือ $0.1174\%\times\$42=\$0.0493$ ราว 4.93 เซนต์ต่อหุ้น

เมื่อหักการเด้งออก ราคาจริงแกว่งแค่ 0.0557% ต่อนาที หรือ $0.0557\%\times274.95=15.3\%$ ต่อปี ตัวเลข 27.5% จึงสูงเกินจริง $0.10/0.0557=1.8$ เท่า สาเหตุคือ 69% ของ variance รายนาทีมาจากการเด้ง ไม่ได้มาจากข่าว และการเด้งไม่สะสมไปตามเวลาเหมือนข่าว

ภาพรวมก่อนลงสูตร

หน้า AR processes สร้างแบบจำลองที่จำค่าของงวดก่อน ตัวอย่างในหน้านั้นคือสเปรดหุ้นกู้ ซึ่งเดือนนี้เก็บ 88% ของค่าเดือนก่อนไว้ แล้วส่งต่อไปเดือนถัดไปอีก ข่าวหนึ่งก้อนจึงค่อย ๆ จาง แต่ไม่เคยหายหมด

หน้านี้สร้างความจำอีกแบบ คือจำข่าว “ข่าว” ในที่นี้คือส่วนที่คาดไม่ถึงของแต่ละงวด เขียนเป็น $\epsilon_t$ ค่าวันนี้มีเศษของข่าวเมื่อวานติดมาด้วย แล้วเศษนั้นหายหมดในวันถัดไป แบบจำลองนี้ชื่อ moving-average process หรือ MA ตัวอย่างที่ชัดที่สุดในตลาดคือราคาซื้อขายที่เด้งไปมาระหว่าง bid กับ ask

รูปด้านล่างแสดงความต่างในภาพเดียว เราใส่ข่าวขนาด 1 เข้าไปหนึ่งก้อน แล้วดูว่ามันยังค้างอยู่เท่าไรในงวดต่อ ๆ ไป MA(1) ค้างงวดเดียวแล้วเป็นศูนย์พอดี AR(1) ลดลงครึ่งหนึ่งทุกงวดแต่ไม่ถึงศูนย์ ARMA ผสมทั้งสองแบบ ความต่างนี้ทิ้งรูปแบบเฉพาะตัว (หน้านี้เรียกว่า “ลายเซ็น”) ไว้ใน ACF ซึ่งคือ correlation ของอนุกรมกับตัวมันเองเมื่อย้อนไป $k$ งวด (ดูหน้า ACF) เราจึงใช้ ACF แยกสองแบบออกจากกันได้จากข้อมูล

ลำดับของหน้านี้ เริ่มจากนับการเด้งด้วยมือ แล้วเขียนเป็น MA(1) ดูลายเซ็นของมันใน ACF และ PACF แล้วหาเพดานของมัน จากนั้นใช้มันถอด spread และความผันผวนจริงตามวิธีของ Roll และดูว่าความถี่ของข้อมูลเปลี่ยนภาพอย่างไร ต่อด้วยการรวมสองความจำเป็น ARMA แล้วปิดด้วย ARIMA ซึ่งพยากรณ์ราคาด้วยค่าเฉลี่ยถ่วงที่กรองการเด้งออกได้ ตัวเลขของหุ้น \$42 เป็นตัวอย่างสมมติ

ศัพท์ที่ใช้ในหัวข้อนี้
MA(q)
moving-average process: ค่าวันนี้เท่ากับข่าววันนี้ บวกข่าวของ $q$ งวดก่อนหน้าคูณน้ำหนัก ความจำจึงหมดหลัง $q$ งวดพอดี ระวัง ชื่อนี้ไม่เกี่ยวกับเส้นค่าเฉลี่ยเคลื่อนที่ที่วาดบนกราฟราคา
ARMA(p, q)
แบบจำลองที่จำทั้งค่าย้อนหลัง $p$ งวด (ส่วน AR) และข่าวย้อนหลัง $q$ งวด (ส่วน MA) ใช้เมื่อมีสองกลไกพร้อมกัน และมักใช้ parameter น้อยกว่า AR หรือ MA ล้วน ๆ ที่อธิบายข้อมูลได้เท่ากัน
ARIMA(p, d, q)
ARMA ที่ใช้กับผลต่างของอนุกรม (ค่าวันนี้ลบค่าเมื่อวาน) โดยหาผลต่าง $d$ ครั้ง ใช้กับอนุกรมที่ไม่ stationary คืออนุกรมที่ค่าเฉลี่ยหรือความผันผวนเปลี่ยนไปตามเวลา เช่นราคา ราคาลอยไปเรื่อย ๆ แต่การเปลี่ยนแปลงของราคา stationary
Autocovariance
covariance ของอนุกรมกับตัวมันเองเมื่อย้อนไป $k$ งวด เขียนเป็น $\gamma_k$ ที่ $k=0$ คือ variance หาร $\gamma_k$ ด้วย $\gamma_0$ ได้ ACF $\rho_k$
PACF
partial autocorrelation ที่ lag $k$: ถ้าทำนายค่าวันนี้ด้วยค่าย้อนหลัง $k$ งวดล่าสุดพร้อมกัน PACF คือสัมประสิทธิ์ของงวดที่ไกลที่สุด มันวัดว่างวดนั้นยังช่วยทำนายได้อีกเท่าไร หลังจากงวดที่ใกล้กว่าช่วยไปแล้ว ใช้คู่กับ ACF เพื่อเลือกระหว่าง AR กับ MA
Invertibility
เงื่อนไข $|\theta|\lt1$ ของ MA ที่ทำให้ย้อนคำนวณข่าวจากข้อมูลได้ โดยข้อมูลที่เก่ากว่าได้น้ำหนักที่จางลง มีไว้เลือกหนึ่งค่าจาก $\theta$ สองค่าที่ให้ ACF เดียวกัน
Bid–ask spread
ask ลบ bid คือต้นทุนของคนที่ซื้อแล้วขายทันที หน้านี้เขียนเป็น $S$ และวัดเป็นสัดส่วนของราคา
Bid–ask bounce
คนที่อยากซื้อทันทีต้องจ่ายที่ ask คนที่อยากขายทันทีได้ที่ bid คำสั่งที่ซื้อขายทันทีแบบนี้เรียกว่า market order ราคาซื้อขายที่บันทึกไว้จึงกระโดดไปมาระหว่าง bid กับ ask ตามว่าฝ่ายไหนส่งคำสั่งเข้ามา แม้มูลค่าตรงกลางไม่ขยับเลย การกระโดดนี้เป็น microstructure noise คือความคลาดที่เกิดจากกลไกการซื้อขาย มันทำให้ความผันผวนที่วัดจากข้อมูลถี่ ๆ ดูใหญ่เกินจริง
Roll estimator
วิธีของ Richard Roll (1984) ที่ถอด bid–ask spread ออกจาก autocovariance ที่ lag 1 ซึ่งติดลบ ใช้แค่ราคาซื้อขาย ไม่ต้องเห็นสมุดคำสั่ง (รายการคำสั่งซื้อและขายที่รออยู่)
EWMA
exponentially weighted moving average: ค่าเฉลี่ยถ่วงที่ให้ข้อมูลล่าสุดได้น้ำหนักมากที่สุด แล้วน้ำหนักของข้อมูลที่เก่ากว่าลดลงด้วยอัตราคงที่ทีละงวด
Kalman filter
วิธีประมาณค่าที่มองไม่เห็นจากการวัดที่มีความคลาด โดยผสมค่าที่ทำนายไว้กับค่าที่วัดใหม่ ตามสัดส่วนความไม่แน่นอนของแต่ละฝั่ง
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$X_t$ผลตอบแทนที่วัดจากราคาซื้อขายในนาทีที่ $t$ (ในขั้น ARIMA หมายถึงตัวราคาเอง)ทศนิยมต่อนาที
$\epsilon_t,\ \sigma$ข่าว (ส่วนที่คาดไม่ถึง) ของงวด $t$ ในแบบจำลอง MA และ SD ของมันทศนิยมต่อนาที
$\theta,\ \phi$น้ำหนักของข่าวเมื่อวาน (MA) และของค่าเมื่อวาน (AR)ไม่มีหน่วย

ขั้นที่ 1 — ราคาที่เด้งระหว่าง bid กับ ask นับด้วยมือ

ก่อนเขียนสูตรทั่วไป ลองดูการเด้งในตลาดที่เล็กที่สุดก่อน ตลาดนี้ไม่มีข่าวเลย ทุกการขยับของราคาที่เห็นจึงมาจากการเด้งล้วน ๆ ของที่กำหนด (สมมติ):

  • มูลค่าตรงกลาง คือราคาที่ยุติธรรมของหุ้นซึ่งอยู่กึ่งกลางระหว่าง bid กับ ask อยู่ที่ \$100 ตลอด
  • bid \$99.90 และ ask \$100.10 จึงได้ spread $S=100.10-99.90=\$0.20$ และครึ่ง spread \$0.10
  • ทุกนาทีมีคนส่ง market order หนึ่งครั้ง เป็นผู้ซื้อ (จ่ายที่ ask) หรือผู้ขาย (ได้ที่ bid) โอกาสอย่างละครึ่ง และไม่ขึ้นกับนาทีก่อน
  • $q_t$ คือทิศของการ “เคาะ” (ส่งคำสั่งที่จับคู่กับราคาที่รออยู่ทันที) ในนาทีที่ $t$: $q_t=+1$ เมื่อผู้ซื้อเคาะที่ ask และ $q_t=-1$ เมื่อผู้ขายเคาะที่ bid

ราคาที่เห็น $P_t$ คือมูลค่าตรงกลางบวกหรือลบครึ่ง spread สิ่งที่เราวัดคือการเปลี่ยนราคา $\Delta P_t=P_t-P_{t-1}$ เราจะหา variance ของมัน ($\gamma_0$) และ covariance กับนาทีก่อน ($\gamma_1$) และกับสองนาทีก่อน ($\gamma_2$) ข้อเท็จจริงที่ใช้มีสองข้อ $q_t^2=1$ เสมอ จึงได้ $\mathbb E[q_t^2]=1$ และ $q$ ของคนละนาทีอิสระกันและมีค่าเฉลี่ยศูนย์ จึงได้ $\mathbb E[q_tq_s]=0$ เมื่อ $t\ne s$

\[ \begin{aligned} P_t&=100+0.10\,q_t,\\ \Delta P_t&=0.10\,(q_t-q_{t-1}),\\ \gamma_0&=0.10^2\operatorname{Var}(q_t-q_{t-1})\\ &=0.01(1+1)=0.02,\\ \gamma_1&=0.01\,\mathbb E\big[(q_t-q_{t-1})(q_{t-1}-q_{t-2})\big]\\ &=0.01(0-0-1+0)=-0.01,\\ \gamma_2&=0.01\,\mathbb E[(q_t-q_{t-1})\\ &\qquad\cdot(q_{t-2}-q_{t-3})]\\ &=0,\\ \rho_1&=-0.01/0.02=-0.5,\\ S&=2\sqrt{-\gamma_1}=2\sqrt{0.01}=0.20. \end{aligned} \]

มูลค่าตรงกลางไม่ขยับเลย แต่ราคาที่บันทึกไว้ขยับ เพราะแต่ละนาทีราคาเกิดที่ \$99.90 หรือ \$100.10 ตามว่าใครเคาะ การเปลี่ยนราคาจึงมีได้แค่สามค่า คือ −\$0.20 (จาก ask ลงมา bid), \$0 (ฝั่งเดิมซ้ำ) และ +\$0.20 (จาก bid ขึ้นไป ask)

จุดสำคัญอยู่ที่ $\gamma_1$ กระจายวงเล็บได้สี่พจน์ มีพจน์เดียวที่เป็นทิศของนาทีเดียวกันคูณกัน คือ $-q_{t-1}^2$ ซึ่งมีค่าเฉลี่ย $-1$ อีกสามพจน์เป็นการเคาะคนละนาทีที่อิสระกัน ค่าเฉลี่ยจึงเป็นศูนย์ ที่ lag 2 สองวงเล็บไม่มีนาทีซ้ำกันเลย จึงได้ศูนย์พอดี

ความหมายคือ ราคาที่ขึ้นมักตามด้วยราคาที่ลง เพราะถ้านาทีนี้มีคนเคาะที่ ask ราคาอยู่ด้านบนแล้ว นาทีหน้าจึงมีแต่ทางอยู่ที่เดิมหรือลงไป bid

สมการสุดท้ายใช้ย้อนกลับได้ $\gamma_1=-(0.10)^2$ คือลบของครึ่ง spread ยกกำลังสอง ถ้าวัด $\gamma_1$ จากข้อมูลได้ ก็ถอด spread กลับมาได้ด้วย $S=2\sqrt{-\gamma_1}$ นี่คือความคิดของ Roll ซึ่งขั้นที่ 5 จะใช้กับตลาดที่มูลค่าตรงกลางขยับตามข่าวด้วย

ขั้นที่ 2 — MA(1): ความจำของข่าวแค่หนึ่งงวด

ขั้นที่แล้วได้ $\Delta P_t=0.10q_t-0.10q_{t-1}$ ถ้ามอง $0.10q_t$ เป็น “ข่าว” ของนาทีนี้ (ส่วนที่คาดล่วงหน้าไม่ได้) การเปลี่ยนราคาก็คือข่าวของนาทีนี้ บวกข่าวของนาทีก่อนคูณ −1 รูปแบบนี้มีชื่อว่า MA(1) เราจะเขียนแบบทั่วไป แล้วหา autocovariance ด้วยวิธีเดียวกับที่นับมือ

นิยามของ MA(1): ค่าวันนี้ $X_t$ เท่ากับค่าเฉลี่ย $\mu$ บวกข่าววันนี้ $\epsilon_t$ บวกข่าวเมื่อวาน $\epsilon_{t-1}$ คูณน้ำหนัก $\theta$ ข่าวแต่ละวันอิสระกัน มีค่าเฉลี่ยศูนย์ และมี variance $\sigma^2$

\[ \begin{aligned} X_t&=\mu+\epsilon_t+\theta\epsilon_{t-1},\\ \gamma_0&=\mathbb E[(\epsilon_t+\theta\epsilon_{t-1})^2]\\ &=\sigma^2(1+\theta^2),\\ \gamma_1&=\mathbb E[(\epsilon_t+\theta\epsilon_{t-1})\\ &\qquad\cdot(\epsilon_{t-1}+\theta\epsilon_{t-2})]\\ &=\theta\,\mathbb E[\epsilon_{t-1}^2]=\theta\sigma^2,\\ \gamma_k&=0\quad(k\ge2),\\ \rho_1&=\frac{\theta\sigma^2}{\sigma^2(1+\theta^2)}=\frac{\theta}{1+\theta^2},\\ \theta=-1:&\quad\rho_1=\frac{-1}{1+1}=-\frac12,\\ \theta=-0.4:&\quad\rho_1=\frac{-0.4}{1+0.16}\\ &\quad\approx-0.3448. \end{aligned} \]

ใน $\gamma_0$ เมื่อกางกำลังสอง พจน์ไขว้ $2\theta\epsilon_t\epsilon_{t-1}$ หายไป เพราะข่าวคนละวันอิสระกัน ค่าเฉลี่ยของผลคูณจึงเป็นศูนย์ เหลือ variance สองก้อน คือ $\sigma^2$ กับ $\theta^2\sigma^2$ ใน $\gamma_1$ ใช้เหตุผลเดียวกับการนับมือ จากสี่พจน์ มีแค่ $\epsilon_{t-1}$ ที่อยู่ในทั้งสองวงเล็บ ที่ lag 2 ไม่มีข่าวไหนอยู่ในทั้งสองวงเล็บเลย จึงได้ศูนย์พอดี

นี่คือลายเซ็นของ MA(1): ACF มีค่าที่ lag 1 แล้วตัดขาดเป็นศูนย์ ต่างจาก AR(1) ที่ ACF เป็น $\phi^k$ ซึ่งจางลงทุก lag แต่ไม่ถึงศูนย์ MA($q$) ทั่วไปตัดขาดหลัง lag $q$ ด้วยเหตุผลเดียวกัน สองค่าที่ห่างกันเกิน $q$ งวดไม่มีข่าวร่วมกันเลย

การเด้งล้วน ๆ ในขั้นที่ 1 คือกรณี $\theta=-1$ ซึ่งให้ $\rho_1=-0.5$ ตรงกับที่นับมือได้ ส่วนหุ้น \$42 วัด $\hat\rho_1$ ได้ −0.345 ค่า $\theta$ ที่ทำให้ $\theta/(1+\theta^2)=-0.345$ คือ $\theta=-0.4$ ตามที่แทนค่าให้ดูในแถวสุดท้าย ขั้นที่ 4 จะแสดงว่ายังมีอีกค่าหนึ่งที่ให้ผลเท่ากัน และทำไมเราเลือก −0.4

ขั้นที่ 3 — ลายเซ็นใน ACF และ PACF: แยก MA ออกจาก AR

ข้อมูลที่ ACF มีแท่งใหญ่แค่ที่ lag 1 อาจเป็น MA(1) ก็ได้ หรือเป็น AR(1) ที่ $\phi$ เล็กก็ได้ เพราะ AR(1) แบบนั้นมี ACF ที่ lag 2 เท่ากับ $\phi^2$ ซึ่งเล็กมากจนมองข้ามง่าย เราจึงต้องมีเครื่องมืออีกตัวที่แยกสองแบบออกจากกันได้ชัด

คำถามของเครื่องมือนั้นคือ ถ้าใช้ค่าเมื่อวานทำนายวันนี้อยู่แล้ว การเพิ่มค่าเมื่อวานซืนเข้าไปช่วยอีกไหม? PACF ที่ lag 2 เขียนเป็น $\phi_{22}$ คือสัมประสิทธิ์ของเมื่อวานซืน ในสมการทำนายที่ใส่ทั้งเมื่อวานและเมื่อวานซืน ต่างจาก ACF ที่ lag 2 ซึ่งเทียบวันนี้กับเมื่อวานซืนตรง ๆ โดยไม่หักส่วนที่เมื่อวานอธิบายไปแล้ว

ลองเทียบสองแบบจำลองที่มี $\rho_1=-0.3448$ เท่ากัน คือ MA(1) ที่ $\theta=-0.4$ ซึ่งมี $\rho_2=0$ และ AR(1) ที่ $\phi=-0.4/1.16=-0.3448$ ซึ่งมี $\rho_2=\phi^2=\rho_1^2$ ตัวเลขทั้งหมดเป็นค่าตามทฤษฎีของแบบจำลอง ไม่ใช่ค่าที่ประมาณจากข้อมูล สูตรของ $\phi_{22}$ พิสูจน์ไว้ในกล่องท้ายขั้นนี้

\[ \begin{aligned} \rho_1^2&=(-0.3448)^2\approx0.1189,\\ 1-\rho_1^2&=0.8811,\\ \phi_{22}&=\frac{\rho_2-\rho_1^2}{1-\rho_1^2},\\ \text{MA(1)}:&\quad\frac{0-0.1189}{0.8811}\approx-0.1350,\\ \text{AR(1)}:&\quad\frac{0.1189-0.1189}{0.8811}=0. \end{aligned} \]

ใน AR(1) ตัวเศษเป็นศูนย์ เพราะ $\rho_2=\phi^2=\rho_1^2$ พอดี ความหมายคือ เมื่อรู้ค่าเมื่อวานแล้ว ค่าเมื่อวานซืนไม่ช่วยทำนาย (แบบเชิงเส้น) เพิ่มเลย ทุกอย่างที่เมื่อวานซืนรู้ ถูกส่งต่อมาทางค่าเมื่อวานหมดแล้ว

ใน MA(1) ค่าเมื่อวานซืนยังช่วยได้ เพราะค่าเมื่อวาน $X_{t-1}=\epsilon_{t-1}+\theta\epsilon_{t-2}$ มีข่าวของเมื่อวานซืนปนอยู่ การรู้ $X_{t-2}$ ช่วยแยกส่วน $\epsilon_{t-2}$ นั้นออก จึงเห็นข่าวเมื่อวาน $\epsilon_{t-1}$ ชัดขึ้น และข่าวเมื่อวานคือสิ่งที่ใช้ทำนายวันนี้ได้ PACF ของ MA(1) จึงไม่เป็นศูนย์ที่ lag 2, 3, … แต่จางลงเรื่อย ๆ

กฎจำง่าย: MA ตัด ACF แต่ PACF จาง ส่วน AR ตัด PACF แต่ ACF จาง

ที่มาของสูตร PACF lag 2

เขียนสมการทำนายที่ใช้สอง lag $\hat X_t=a_1X_{t-1}+a_2X_{t-2}$ เงื่อนไขของ OLS regression คือ residual $X_t-\hat X_t$ ต้องไม่มี covariance กับตัวแปรต้นแต่ละตัว คือ $X_{t-1}$ และ $X_{t-2}$ เขียนสองเงื่อนไขนี้ออกมาแล้วหารด้วย $\gamma_0$ ได้สองสมการแรกข้างล่าง จากสมการแรกได้ $a_1=\rho_1-a_2\rho_1$ แทนลงสมการที่สองแล้วแก้หา $a_2$

\[ \begin{aligned} \rho_1&=a_1+a_2\rho_1,\\ \rho_2&=a_1\rho_1+a_2,\\ \rho_2&=(\rho_1-a_2\rho_1)\rho_1+a_2,\\ a_2(1-\rho_1^2)&=\rho_2-\rho_1^2,\\ \phi_{22}:=a_2&=\frac{\rho_2-\rho_1^2}{1-\rho_1^2}. \end{aligned} \]

ขั้นที่ 4 — เพดานของ MA(1) และ θ สองค่าที่ให้ ACF เดียวกัน

ใน MA(1) ค่า $\rho_1=\theta/(1+\theta^2)$ มีเพดาน ถ้าข้อมูลมี ACF ที่ lag 1 ใหญ่เกินเพดานนี้ MA(1) ก็อธิบายข้อมูลไม่ได้ เราพิสูจน์เพดานจากความจริงง่าย ๆ ว่ากำลังสองไม่ติดลบ ระหว่างทางต้องแยกให้ดีระหว่างค่าตามทฤษฎีของแบบจำลอง $\rho_1$ กับค่าที่ประมาณจากข้อมูล $\hat\rho_1$ ซึ่งคลาดได้

\[ \begin{aligned} (1-|\theta|)^2&\ge0,\\ 1+\theta^2&\ge2|\theta|,\\ |\rho_1|=\frac{|\theta|}{1+\theta^2}&\le\frac12,\\ \theta=-2.5:&\quad\frac{-2.5}{1+6.25}=-0.3448. \end{aligned} \]

เพดานมาจากกำลังสองที่ไม่ติดลบ กาง $(1-|\theta|)^2$ ได้ $1-2|\theta|+\theta^2\ge0$ ย้าย $2|\theta|$ ไปอีกข้าง แล้วหารทั้งสองข้างด้วย $2(1+\theta^2)$ ซึ่งเป็นบวกเสมอ จึงได้ $|\rho_1|\le1/2$ และเท่ากันพอดีเมื่อ $|\theta|=1$

ผลที่ใช้ได้จริงคือ $\rho_1=-0.6$ เป็น ACF ตามทฤษฎีของ MA(1) ไม่ได้ แต่ข้อมูลชุดสั้น ๆ อาจให้ $\hat\rho_1=-0.6$ ได้ เพราะค่าประมาณคลาดจากการสุ่ม ก่อนตัด MA(1) ทิ้ง จึงต้องดูก่อนว่าค่าประมาณคลาดได้แค่ไหน

แถวสุดท้ายเผยปัญหาใหม่ คือ $\theta=-2.5$ ให้ $\rho_1$ เท่ากับ $\theta=-0.4$ พอดี เหตุผลคือถ้าแทน $\theta$ ด้วย $1/\theta$ ค่า $\rho_1$ ไม่เปลี่ยน: $\dfrac{1/\theta}{1+1/\theta^2}=\dfrac{\theta}{\theta^2+1}$ (คูณทั้งเศษและส่วนด้วย $\theta^2$) และ $1/(-0.4)=-2.5$ ดู ACF อย่างเดียวจึงแยกสองค่านี้ไม่ออก ต้องมีเกณฑ์เลือก

เกณฑ์นั้นมาจากงานที่ต้องทำจริง ข่าว $\epsilon_t$ มองไม่เห็นตรง ๆ เราเห็นแค่ $X_t$ จึงต้องย้อนคำนวณข่าวจากข้อมูล วิธีคือย้ายข้างสมการ MA(1) ให้ $\epsilon_t$ อยู่ซ้าย แล้วแทน $\epsilon_{t-1}$ ด้วยสมการเดียวกันซ้ำไปเรื่อย ๆ

\[ \begin{aligned} \epsilon_t&=(X_t-\mu)-\theta\epsilon_{t-1}\\ &=(X_t-\mu)-\theta(X_{t-1}-\mu)\\ &\quad+\theta^2\epsilon_{t-2}\\ &=\sum_{j=0}^{k-1}(-\theta)^j(X_{t-j}-\mu)\\ &\quad+(-\theta)^k\epsilon_{t-k},\\ 0.4^{10}&\approx0.0001,\\ 2.5^{10}&\approx9{,}537. \end{aligned} \]

ข่าววันนี้เท่ากับผลรวมของข้อมูลย้อนหลังคูณน้ำหนัก $(-\theta)^j$ บวกก้อนท้าย $(-\theta)^k\epsilon_{t-k}$ ที่เราไม่รู้ค่า ที่ $\theta=-0.4$ น้ำหนักคือ $0.4^j$ ซึ่งจางเร็ว ข้อมูลเมื่อ 10 นาทีก่อนได้น้ำหนักแค่ $0.4^{10}\approx0.0001$ ก้อนท้ายที่ไม่รู้ค่าจึงหายไปเอง

ที่ $\theta=-2.5$ น้ำหนักกลับโตขึ้น ข้อมูลเมื่อ 10 นาทีก่อนได้น้ำหนัก $2.5^{10}\approx9{,}537$ ข่าวที่ย้อนคำนวณได้จึงขึ้นกับข้อมูลที่เก่าที่สุดมากที่สุด ซึ่งไม่มีความหมาย

เงื่อนไข $|\theta|\lt1$ นี้เรียกว่า invertibility (ย้อนกลับได้) และเป็นเหตุที่เราเลือก $\theta=-0.4$ ไม่ใช่ −2.5 มันคือเงื่อนไขเดียวกับ $|\phi|\lt1$ ของ AR แต่ใช้กับการย้อนไปหาข่าว

ขั้นที่ 5 — แบบจำลองของ Roll: แยกการเด้งออกจากข่าวจริง

ในตลาดจริง ราคาไม่ได้แค่เด้ง มูลค่าตรงกลางเองก็ขยับเมื่อมีข่าว แบบจำลองของ Roll (Roll model) รวมสองอย่างนี้ด้วยสมมติฐานสามข้อ

  • มูลค่าตรงกลางเดินแบบ random walk คือทุกนาทีขยับด้วยผลตอบแทนจากข่าวจริง $e_t$ ซึ่งอิสระกันทุกนาทีและมี variance $\sigma_e^2$
  • ราคาที่เห็นคือมูลค่าตรงกลางบวกหรือลบครึ่ง spread ตามทิศการเคาะ $q_t$ เหมือนขั้นที่ 1 โดยวัด spread $S$ เป็นสัดส่วนของราคา
  • ทิศการเคาะไม่เกี่ยวกับข่าว

ข้อสุดท้ายทำให้ variance และ covariance ของสองส่วนบวกกันได้ตรง ๆ ส่วนการเด้งใช้ผลการนับมือในขั้นที่ 1 ได้เลย โดยเปลี่ยน \$0.10 เป็นครึ่ง spread $S/2$

\[ \begin{aligned} X_t&=e_t+\tfrac S2(q_t-q_{t-1}),\\ \gamma_0&=\sigma_e^2+\tfrac{S^2}{4}(2)=\sigma_e^2+\tfrac{S^2}{2},\\ \gamma_1&=\tfrac{S^2}{4}(-1)=-\tfrac{S^2}{4},\qquad\gamma_2=0,\\ S&=2\sqrt{-\gamma_1},\\ \sigma_e^2&=\gamma_0-\tfrac{S^2}{2}=\gamma_0+2\gamma_1. \end{aligned} \]

ข่าวจริงอิสระกันทุกนาที จึงเพิ่มแค่ $\gamma_0$ ไม่ไปเพิ่ม $\gamma_1$ ส่วนการเด้งให้ $2(S/2)^2$ ใน $\gamma_0$ และ $-(S/2)^2$ ใน $\gamma_1$ ตามการนับมือ ผลคือ ACF ตัดขาดหลัง lag 1 ข้อมูลแบบนี้จึงหน้าตาเหมือน MA(1) ทุกอย่างในสายตาของสถิติ ทั้งที่ข้างในมีสองกลไก

สองแถวล่างแก้หาของที่มองไม่เห็นจากของที่วัดได้ คือ $\gamma_1$ บอก spread และ $\gamma_0+2\gamma_1$ บอก variance ของข่าวจริง

$\gamma_0+2\gamma_1$ มีอีกความหมายหนึ่ง ถ้ามองข้อมูลเป็น MA(1) จะได้ $\gamma_0+2\gamma_1=\sigma^2(1+\theta^2)+2\theta\sigma^2=\sigma^2(1+\theta)^2$ นี่คือ variance ต่อนาทีเมื่อรวมผลตอบแทนเป็นช่วงยาวมาก เพราะในช่วงยาว การเด้งตรงกลางหักล้างกันหมด เหลือแค่ต้นกับปลาย ซึ่งมีสัดส่วนเล็กลงเรื่อย ๆ (ขั้นที่ 7 จะแสดงให้ดู) ถ้า ACF ที่ lag 2 ขึ้นไปไม่เป็นศูนย์ชัด แปลว่ามูลค่าตรงกลางเองมีความจำ แบบจำลองนี้ก็ไม่พอแล้ว

ขั้นที่ 6 — ตอบโจทย์เปิด: spread และความผันผวนจริงของหุ้น \$42

ตอนนี้มีเครื่องมือครบแล้ว กลับไปตอบโจทย์เปิด ของที่รู้:

  • SD ของผลตอบแทนรายนาทีที่วัดได้ $0.10\%=0.001$ ดังนั้น $\gamma_0=0.001^2=10^{-6}$
  • MA(1) ที่ฟิตได้ $\theta=-0.4$ ซึ่งให้ $\rho_1=-0.4/1.16=-0.3448$ (ขั้นที่ 2) และ $\gamma_1=\rho_1\gamma_0$
  • ราคาหุ้น \$42
  • ตลาดเปิดวันละ 300 นาที เป็นสมมติฐานของโจทย์ (ตลาดจริงดูหลังคำตอบ)
  • ปีหนึ่งมี 252 วันทำการ มาจาก $365-104-9=252$ คือหักเสาร์อาทิตย์ 104 วัน และวันหยุดตลาดหุ้นสหรัฐราว 9 วัน

ลำดับการคำนวณ หา $\gamma_1$ ก่อน แล้วถอด spread $S$ ตามด้วย variance ของข่าวจริง $\sigma_e^2$ จากนั้นขยายจากนาทีเป็นวันและปีด้วยรากของจำนวนนาที ($\sqrt{300}$ สำหรับวัน และ $\sqrt{300\times252}$ สำหรับปี)

\[ \begin{aligned} \gamma_1&=\frac{-0.4}{1.16}\times10^{-6}\\ &\approx-3.448\times10^{-7},\\ S&=2\sqrt{-\gamma_1}\\ &\approx2(5.872\times10^{-4})\\ &\approx0.1174\%,\\ S\times\$42&\approx\$0.0493,\\ \sigma_e^2&=\gamma_0+2\gamma_1\\ &=10^{-6}-6.897\times10^{-7}\\ &\approx3.103\times10^{-7},\\ \sigma_e&\approx0.0557\%\ \text{per minute},\\ \sqrt{300}&\approx17.32,\\ \sqrt{300\times252}&\approx274.95,\\ \sigma_{\rm day}&\approx0.0557\%(17.32)\\ &\approx0.965\%,\\ \sigma_{\rm year}&\approx0.0557\%(274.95)\\ &\approx15.3\%,\\ \sigma_{\rm naive}&\approx0.10\%(274.95)\\ &\approx27.5\%. \end{aligned} \]

คำตอบ: spread คือ 0.1174% ของราคา หรือราว 4.93 เซนต์ต่อหุ้น การเด้งกินส่วนแบ่งของ variance รายนาที $\dfrac{S^2/2}{\gamma_0}=\dfrac{6.897\times10^{-7}}{10^{-6}}=69\%$ ภายใต้สมมติฐานของ Roll ราคาจริงแกว่ง 0.0557% ต่อนาที 0.965% ต่อวัน และ 15.3% ต่อปี

ตัวเลข 27.5% ของระบบความเสี่ยงจึงสูงกว่าความผันผวนของข่าวจริง $\dfrac{0.10\%}{0.0557\%}=1.8$ เท่า ถ้าใช้มันเป็น volatility ใน VaR ความเสี่ยงที่คำนวณได้จะสูงเกินจริงเกือบเท่าตัว

ตัวเลข 300 นาทีต่อวันเป็นสมมติของโจทย์ ตลาดหุ้นสหรัฐเปิดจริง 9:30 ถึง 16:00 ตามเวลานิวยอร์ก คือ 6.5 ชั่วโมง หรือ $6.5\times60=390$ นาที ถ้าใช้ 390 ทุกตัวเลขรายวันและรายปีโตขึ้น $\sqrt{390/300}=1.140$ เท่า

\[ \begin{aligned} \sqrt{390\times252}&=\sqrt{98{,}280}=313.5,\\ \sigma_{\rm naive}&\approx0.10\%\times313.5=31.35\%,\\ \sigma_{\rm year}&\approx0.0557\%\times313.5=17.5\%. \end{aligned} \]

แต่ spread, $\rho_1$ และอัตราส่วน 1.8 เท่าไม่เปลี่ยน เพราะคำนวณจากข้อมูลรายนาทีล้วน ๆ

ตรวจเองใน 10 วินาที: ถ้ามองข้อมูลเป็น MA(1) ค่า $\sigma(1+\theta)$ ต้องเท่ากับ $\sigma_e$ (ขั้นที่ 5) จาก $\gamma_0=\sigma^2(1+\theta^2)$ ได้ $\sigma=\sqrt{10^{-6}/1.16}=0.0928\%$ แล้ว $\sigma(1+\theta)=0.0928\%\times0.6=0.0557\%$ ตรงกับ $\sigma_e$ ส่วน spread เป็นเงินตรวจได้จาก $0.1174\%\times\$42=\$0.0493$

ขั้นที่ 7 — ความถี่ของข้อมูล: ข่าวสะสม แต่การเด้งไม่สะสม

ปัญหาในขั้นที่ 6 มาจากการใช้ข้อมูลรายนาที ถ้าวัดผลตอบแทนทุก $m$ นาทีแทน จะเกิดอะไรขึ้น? ข่าวจริงอิสระกันทุกนาที จึงบวกกันได้ $m$ ก้อน variance โตเป็น $m\sigma_e^2$ แต่การเด้งรวม $m$ นาทีหักล้างกันเป็นทอด ๆ เหลือแค่ต้นกับปลาย $(q_1-q_0)+(q_2-q_1)+\cdots+(q_m-q_{m-1})=q_m-q_0$ ส่วนการเด้งจึงมี variance $\tfrac{S^2}{4}\operatorname{Var}(q_m-q_0)=\tfrac{S^2}{4}\times2=\tfrac{S^2}{2}$ เท่าเดิม ไม่ว่า $m$ เท่าไร

ขั้นนี้ตอบว่าควรวัดความผันผวนจากข้อมูลถี่แค่ไหน แถวสุดท้ายคือความผันผวนต่อปีที่ระบบความเสี่ยงจะได้ ถ้าใช้ข้อมูลช่วง $m$ นาทีแล้วขยายด้วยรากของเวลาแบบในโจทย์เปิด (หนึ่งปีมี 75,600 นาที)

\[ \begin{aligned} \operatorname{Var}(X_1+\cdots+X_m)&=m\sigma_e^2+\tfrac{S^2}{2},\\ \text{bounce share}&=\frac{S^2/2}{m\sigma_e^2+S^2/2},\\ \sigma_{\rm naive}(m)&=\sqrt{\frac{m\sigma_e^2+S^2/2}{m}\times75{,}600}. \end{aligned} \]

ตัวอย่างแถว $m=5$ ใช้ $\sigma_e^2=3.103\times10^{-7}$ และ $S^2/2=6.897\times10^{-7}$ จากขั้นที่ 6

\[ \begin{aligned} \operatorname{Var}_5&=5(3.103\times10^{-7})\\ &\quad+6.897\times10^{-7}\\ &=2.241\times10^{-6},\\ \text{bounce share}&=\frac{6.897\times10^{-7}}{2.241\times10^{-6}}\\ &=30.8\%,\\ \sigma_{\rm naive}(5)&=\sqrt{\frac{2.241\times10^{-6}}{5}\times75{,}600}\\ &=18.4\%. \end{aligned} \]

แต่ช่วงยาวแลกกับจุดข้อมูลที่น้อยลง ช่วง 25 นาทีเหลือข้อมูลวันละ $300/25=12$ จุด แทนที่จะเป็น 300 จุด ค่าประมาณจึงคลาดมากขึ้น ทางสายกลางที่ใช้กันคือ realized volatility จากข้อมูลทุก 5 นาที งานของ Liu, Patton และ Sheppard (2015) เทียบตัวประมาณเกือบ 400 แบบกับสินทรัพย์ 31 ตัวในห้ากลุ่ม และหาวิธีที่ชนะแบบ 5 นาทีอย่างชัดเจนได้ยาก อีกทางคือใช้ข้อมูลถี่ แล้วหักการเด้งออกแบบของ Roll

ตารางนี้คือกรณีสุดโต่งของกฎในหน้า ACF ที่ว่า variance ของผลรวม $h$ ช่วงคือ $h\gamma_0[1+2\sum_k(1-k/h)\rho_k]$ ใส่ $\rho_1=-0.345$ ให้ $\rho$ ที่ lag อื่นเป็นศูนย์ และให้ $h=m$ ก็ได้ $m\sigma_e^2+S^2/2$ เท่ากับสูตรข้างบน

ขั้นที่ 8 — ARMA(1,1): จำทั้งค่าและข่าว

บางอนุกรมมีทั้งสองกลไก ตัวอย่างคือสเปรดหุ้นกู้ในหน้า AR processes ที่ค่อย ๆ กลับหาค่าเฉลี่ยแบบ AR แต่ถ้าราคาที่ใช้วัดถูกกวนด้วยการเด้ง ค่าที่วัดได้ก็มีร่องรอยของข่าวแบบ MA ปนอยู่ แบบจำลองที่รวมสองอย่างคือ ARMA(1,1) ค่าวันนี้เท่ากับ $\phi$ เท่าของค่าเมื่อวาน บวกข่าววันนี้ บวก $\theta$ เท่าของข่าวเมื่อวาน

เราจะหาสามอย่าง คือน้ำหนักของข่าวย้อนหลัง variance และ ACF โดยสมมติ $|\phi|\lt1$ (อนุกรมไม่ระเบิด) และค่าเฉลี่ยศูนย์ แล้วแทนตัวเลข $\phi=0.7$ และ $\theta=-0.4$ ให้ดู

\[ \begin{aligned} X_t&=\phi X_{t-1}+\epsilon_t+\theta\epsilon_{t-1},\\ X_t&=\epsilon_t\\ &\quad+(\phi+\theta)\sum_{j=1}^{\infty}\phi^{j-1}\epsilon_{t-j},\\ \gamma_0&=\sigma^2\left[1+\frac{(\phi+\theta)^2}{1-\phi^2}\right]\\ &=\sigma^2\,\frac{1+2\phi\theta+\theta^2}{1-\phi^2},\\ \gamma_1&=\phi\gamma_0+\theta\sigma^2,\\ \rho_1&=\frac{(1+\phi\theta)(\phi+\theta)}{1+2\phi\theta+\theta^2},\\ \rho_k&=\phi\rho_{k-1}\quad(k\ge2),\\ \phi&=0.7,\quad\theta=-0.4:\\ \gamma_0&=\frac{1-0.56+0.16}{1-0.49}\sigma^2\\ &=\frac{0.60}{0.51}\sigma^2\approx1.176\sigma^2,\\ \rho_1&=\frac{(1-0.28)(0.7-0.4)}{0.60}\\ &=\frac{0.72(0.3)}{0.60}=0.36,\\ \rho_2&=0.7(0.36)=0.252. \end{aligned} \]

น้ำหนักของข่าวย้อนหลังได้จากการแทนสมการตัวเองซ้ำ แบบที่ทำกับ AR(1) ข่าวเมื่อวานได้น้ำหนัก $\phi+\theta$ ทันที ส่วน $\phi$ มาจากค่าเมื่อวานที่ส่งต่อมา ส่วน $\theta$ มาจากความจำข่าวโดยตรง จากนั้นน้ำหนักจางลงทีละ $\phi$ เท่าต่องวด ตรงกับแท่งม่วงในรูปแรกของหน้า

variance คือ $\sigma^2$ คูณผลรวมกำลังสองของน้ำหนักเหล่านี้ $1+(\phi+\theta)^2(1+\phi^2+\phi^4+\cdots)$ วงเล็บหลังเป็นอนุกรมเรขาคณิตที่รวมได้ $1/(1-\phi^2)$ จึงได้สูตร $\gamma_0$

หา $\gamma_1$ โดยคูณสมการด้วย $X_{t-1}$ แล้วหาค่าเฉลี่ย พจน์ AR ให้ $\phi\gamma_0$ ข่าววันนี้ไม่เกี่ยวกับ $X_{t-1}$ จึงหายไป ส่วนข่าวเมื่อวานอยู่ใน $X_{t-1}$ ด้วยน้ำหนัก 1 จึงเหลือ $\theta\sigma^2$ หารด้วย $\gamma_0$ แล้วจัดรูปได้สูตร $\rho_1$ ตั้งแต่ lag 2 ข่าวไม่มีส่วนร่วมแล้ว เหลือแต่ความจำแบบ AR จึงได้ $\rho_k=\phi\rho_{k-1}$

ลายเซ็นของ ARMA(1,1) คือ lag 1 ถูกน้ำหนักข่าว $\theta$ ที่ติดลบดึงลงจาก 0.7 (ค่าที่ AR(1) ล้วน ๆ จะให้) เหลือ 0.36 จากนั้นจางด้วยอัตรา 0.7 แบบ AR(1) ทุกประการ ทั้ง ACF และ PACF จึงจางทั้งคู่ ไม่มีตัวไหนตัดขาด ถ้า $\theta=0$ สูตรกลับเป็น AR(1) ถ้า $\phi=0$ กลับเป็น MA(1) และหน้า GARCH จะพบว่า GARCH คือ ARMA(1,1) ของข่าวกำลังสอง

กับดักของ ARMA: ถ้า $\phi=-\theta$ เช่น $\phi=0.4$ และ $\theta=-0.4$ น้ำหนัก $\phi+\theta=0.4-0.4=0$ ข่าวเก่าทุกก้อนได้น้ำหนักศูนย์ อนุกรมจึงเป็นข่าววันนี้ล้วน ๆ คือ white noise (อนุกรมที่ไม่มีความจำเลย) ความจำสองแบบหักล้างกันหมด ข้อมูลจึงเข้ากับคู่ $\phi$ กับ $\theta$ คู่ไหนก็ได้ที่บวกกันเป็นศูนย์ ซอฟต์แวร์จะคืนค่าที่ดูมั่นใจแต่ไม่มีความหมาย จึงควรลองแบบจำลองที่เล็กกว่าก่อนเสมอ

ขั้นที่ 9 — ARIMA: หาผลต่างก่อน แล้วคำทำนายกลายเป็นค่าเฉลี่ยถ่วงแบบเรขาคณิต

ตัวราคาเองไม่ stationary มันลอยไปเรื่อย ๆ ไม่มีค่าเฉลี่ยให้กลับ แต่ผลต่างของราคา (ราคาครั้งนี้ลบราคาครั้งก่อน) ในแบบจำลองของ Roll เป็น MA(1) แบบจำลองของราคาที่ผลต่างเป็น MA(1) เรียกว่า ARIMA(0,1,1) ตัวเลขสามตัวคือ AR 0 งวด หาผลต่าง 1 ครั้ง และ MA 1 งวด

ในขั้นนี้ $X_t$ คือตัวราคา ไม่ใช่ผลตอบแทน และ $\hat X_{t+1|t}$ คือคำทำนายราคาครั้งที่ $t+1$ โดยใช้ข้อมูลถึงครั้งที่ $t$ คำถามที่ใช้งานจริงคือ เห็นราคาซื้อขายล่าสุดแล้ว มูลค่าจริงตอนนี้ควรประมาณเท่าไร? ข่าวของครั้งหน้ายังไม่เกิด ค่าเฉลี่ยของมันเป็นศูนย์ สิ่งที่เหลือให้ใช้มีแค่ราคาล่าสุดกับเศษของข่าวล่าสุด และข่าวล่าสุดก็คือส่วนที่คำทำนายครั้งก่อนพลาด

\[ \begin{aligned} X_t-X_{t-1}&=\epsilon_t+\theta\epsilon_{t-1},\\ \hat X_{t+1|t}&=X_t+\theta\epsilon_t,\\ \epsilon_t&=X_t-\hat X_{t|t-1},\\ \hat X_{t+1|t}&=(1+\theta)X_t\\ &\quad-\theta\hat X_{t|t-1},\\ \theta&=-0.4:\\ \hat X_{t+1|t}&=0.6X_t+0.4\hat X_{t|t-1},\\ \hat X_{1|0}&=0.6(42.05)+0.4(42.00)\\ &=42.03,\\ \hat X_{2|1}&=0.6(41.99)+0.4(42.03)\\ &=42.006. \end{aligned} \]

สมการคำทำนายบอกว่า คำทำนายใหม่คือค่าเฉลี่ยถ่วงของราคาล่าสุดกับคำทำนายเก่า ราคาล่าสุดได้น้ำหนัก $K=1+\theta=1-0.4=0.6$ คำทำนายเก่าได้ $-\theta=0.4$ เมื่อ $-1\lt\theta\lt0$ น้ำหนักทั้งสองเป็นบวกและรวมกันได้ 1 การเฉลี่ยแบบนี้เรียกว่า exponential smoothing หรือ EWMA เพราะถ้าแทนคำทำนายเก่าด้วยสมการเดียวกันซ้ำ ๆ ราคาย้อนหลัง $j$ ครั้งจะได้น้ำหนัก $0.6(0.4)^j$ ซึ่งลดลงแบบเรขาคณิต

ลองใช้กับราคาสมมติสองครั้ง คำทำนายเก่าคือ \$42.00 แล้วมีคนเคาะที่ ask \$42.05 คำทำนายขยับขึ้นไปแค่ \$42.03 คือ 60% ของการขึ้น \$0.05 เพราะส่วนที่เหลืออาจเป็นการเด้งที่จะกลับลงมา ครั้งต่อมามีคนเคาะที่ bid \$41.99 คำทำนายลงมาแค่ \$42.006 สมการบรรทัดเดียวนี้จึงกรองการเด้งออกได้ส่วนหนึ่ง

ทำไมต้องเป็น 0.6 พอดี? ลองมองแบบจำลองของ Roll เป็นปัญหากรองสัญญาณแบบที่วิศวกรคุ้นเคย

  • สถานะที่มองไม่เห็นคือมูลค่าตรงกลาง มันเดินแบบ random walk ด้วย variance $\sigma_e^2$ ต่อนาที
  • สิ่งที่วัดได้คือราคาซื้อขาย เท่ากับมูลค่าตรงกลางบวกความคลาดจากการเด้ง ความคลาดนี้คือ $\pm S/2$ จึงมี variance $(S/2)^2=S^2/4$

ตัวกรองที่ดีที่สุดสำหรับปัญหาแบบนี้คือ Kalman filter (EWMA, Kalman, GARCH) เมื่อทำงานไปนานจนนิ่ง มันกลายเป็น EWMA ที่มีน้ำหนักคงที่ $K$ เรียกว่า Kalman gain ซึ่งหาได้จากอัตราส่วนของสอง variance นี้

\[ \begin{aligned} \frac{S^2/4}{\sigma_e^2}&=\frac{0.4\sigma^2}{0.36\sigma^2}=\frac{10}{9},\\ P&=\sigma_e^2\,\frac{1+\sqrt{4(10/9)+1}}{2}\\ &=0.36\sigma^2\cdot\frac{1+7/3}{2}=0.6\sigma^2,\\ K&=\frac{P}{P+S^2/4}=\frac{0.6}{0.6+0.4}\\ &=0.6=1+\theta. \end{aligned} \]

อัตราส่วนแรกใช้สิ่งที่ถอดได้แล้วในขั้นที่ 5 แต่เขียนด้วย $\sigma^2$ ซึ่งคือ variance ของข่าวใน MA(1) ความคลาดจากการเด้งคือ $S^2/4=-\gamma_1=-\theta\sigma^2=0.4\sigma^2$ และข่าวจริงคือ $\sigma_e^2=\sigma^2(1+\theta)^2=0.6^2\sigma^2=0.36\sigma^2$

$P$ คือความไม่แน่นอน (variance) ของมูลค่าจริงก่อนเห็นราคาใหม่ เมื่อตัวกรองนิ่งแล้ว ที่มาของสูตรอยู่ในกล่องข้างล่าง ส่วน $K=P/(P+S^2/4)$ คือสัดส่วนที่ควรเชื่อราคาใหม่ คือความไม่แน่นอนของเรา หารด้วยความไม่แน่นอนรวมของเราและของการวัด

ผลคือ $K=0.6$ ตรงกับน้ำหนัก $1+\theta$ ของ ARIMA พอดี สองมุมมองให้คำตอบเดียวกัน และให้บทเรียนเดียวกัน ยิ่งการเด้งใหญ่เมื่อเทียบกับข่าว ยิ่งควรเชื่อราคาล่าสุดน้อยลง

ที่มาของสูตร $P$ และ $K$

ให้ $Q=\sigma_e^2$ คือ variance ที่มูลค่าจริงเดินในหนึ่งนาที และ $R=S^2/4$ คือ variance ของความคลาดจากการเด้ง ก่อนเห็นราคาใหม่ ความไม่แน่นอนของเราคือ $P$ เมื่อผสมค่าเดิมกับราคาใหม่ด้วยน้ำหนัก $K$ ความคลาดของค่าผสมมี variance $(1-K)^2P+K^2R$ หาอนุพันธ์เทียบ $K$ แล้วตั้งเป็นศูนย์ ได้น้ำหนักที่ดีที่สุด $K=P/(P+R)$ และ variance หลังผสมลดเหลือ $(1-K)P=PR/(P+R)$

จากนั้นมูลค่าจริงเดินอีกหนึ่งนาที ความไม่แน่นอนจึงเพิ่มอีก $Q$ ในสภาวะนิ่ง วงจรนี้ต้องกลับมาที่ $P$ เดิม จึงได้สมการกำลังสอง เลือกรากบวกเพราะ variance ติดลบไม่ได้

\[ \begin{aligned} P&=\frac{PR}{P+R}+Q,\\ P(P+R)&=PR+Q(P+R),\\ P^2-QP-QR&=0,\\ P&=\frac{Q+\sqrt{Q^2+4QR}}{2}\\ &=Q\,\frac{1+\sqrt{4R/Q+1}}{2}. \end{aligned} \]

ตัวเลข $d$ ใน ARIMA($p$, $d$, $q$) ต้องเลือกให้พอดี ถ้าหาผลต่างมากเกินไปจะได้ของปลอม สมมติอนุกรมเป็น white noise อยู่แล้ว ผลต่างของมันคือ $\epsilon_t-\epsilon_{t-1}$ ซึ่งเป็น MA(1) ที่ $\theta=-1$ และให้ $\rho_1=-1/(1+1)=-0.5$ พอดี หน้าตาเหมือนการเด้งทุกอย่าง ทั้งที่ข้อมูลเดิมไม่มีความจำเลย

ขั้นที่ 10 — เลือก p กับ q: ระบุ ประมาณ ตรวจ

ตอนนี้มีแบบจำลองให้เลือกหลายแบบ ข้อมูลจริงชุดหนึ่งควรใช้ AR, MA หรือ ARMA และกี่ lag? ขั้นตอนมาตรฐานของ Box และ Jenkins มีสามจังหวะ

  • ระบุ: ดูลายเซ็นของ ACF และ PACF เพื่อเดาว่าเป็นแบบไหน
  • ประมาณ: หา parameter ด้วย maximum likelihood คือเลือก parameter ที่ทำให้ข้อมูลที่เห็นมีโอกาสเกิดมากที่สุด
  • ตรวจ: ดูว่า residual (ส่วนที่แบบจำลองอธิบายไม่ได้) เป็น white noise หรือไม่ ด้วย Ljung–Box

เมื่อลายเซ็นไม่ชัด ให้ฟิตหลายแบบแล้วเทียบด้วยเกณฑ์ที่ให้คะแนนความเข้ากับข้อมูล แต่หักคะแนนตามจำนวน parameter $k$ สองเกณฑ์ที่ใช้มากคือ AIC และ BIC ทั้งสองใช้ log-likelihood $\ln L$ คือ log ของโอกาสที่แบบจำลองให้กับข้อมูลชุดนี้ ยิ่งสูงยิ่งเข้ากับข้อมูล

ตัวอย่างสมมติ ฟิตสองแบบกับข้อมูล $n=1{,}000$ จุด โดยกำหนดค่าเฉลี่ยเป็นศูนย์

  • AR(1) ได้ $\ln L=5{,}000.0$ มี $k=2$ คือ $\phi$ และ variance ของข่าว
  • ARMA(1,1) ได้ $\ln L=5{,}001.5$ มี $k=3$ เพราะเพิ่ม $\theta$
\[ \begin{aligned} \mathrm{AIC}&=-2\ln L+2k,\\ \mathrm{BIC}&=-2\ln L+k\ln n,\\ \mathrm{AIC}_{\rm AR}&=-10{,}000+2(2)=-9{,}996,\\ \mathrm{AIC}_{\rm ARMA}&=-10{,}003+2(3)=-9{,}997,\\ \ln1{,}000&=6.908,\\ \mathrm{BIC}_{\rm AR}&=-10{,}000+2(6.908)\\ &=-9{,}986.2,\\ \mathrm{BIC}_{\rm ARMA}&=-10{,}003+3(6.908)\\ &=-9{,}982.3. \end{aligned} \]

ทั้งสองเกณฑ์เริ่มจาก $-2\ln L$ ซึ่งยิ่งต่ำยิ่งเข้ากับข้อมูล แล้วบวกค่าปรับตามจำนวน parameter ค่ารวมที่ต่ำกว่าชนะ AIC ปรับตัวละ 2 จึงเลือก ARMA เพราะ −9,997 ต่ำกว่า −9,996 BIC ปรับตัวละ $\ln n=6.908$ จึงเลือก AR เพราะ −9,986.2 ต่ำกว่า −9,982.3

สรุปคือ parameter ที่เพิ่มมาหนึ่งตัวทำให้ $\ln L$ เพิ่ม 1.5 หรือทำให้ $-2\ln L$ ลดลง 3 ซึ่งมากกว่าค่าปรับ 2 ของ AIC แต่น้อยกว่าค่าปรับ 6.908 ของ BIC สองเกณฑ์จึงขัดกันได้ เมื่อข้อมูลเยอะ BIC จะชอบแบบจำลองที่เล็กกว่า ซึ่งมักปลอดภัยกว่าเมื่อพยากรณ์ข้อมูลที่ไม่ได้ใช้ฟิต

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

เรียกขนาดข่าว $\sigma$ ของ MA(1) ว่าความผันผวนจริง คนที่ฟิต MA(1) จะได้ $\sigma$ มาด้วย และอาจคิดว่านี่คือความผันผวนที่หักการเด้งออกแล้ว การคิดที่ผิดเป็นแบบนี้

\[ \begin{aligned} \sigma&=\frac{0.10\%}{\sqrt{1.16}}=\frac{0.10\%}{1.077}=0.0928\%,\\ \sigma\sqrt{75{,}600}&=0.0928\%\times274.95=25.5\%. \end{aligned} \]

แล้วสรุปว่า 27.5% วัดเกินแค่ $1.077-1=7.7\%$ ข้อสรุปนี้ผิด เพราะ $\sigma$ ของ MA(1) ยังรวมการเด้งอยู่ ตัวเลขที่ถูกคือราคาจริงแกว่ง $\sigma(1+\theta)=0.0928\%\times0.6=0.0557\%$ ต่อนาที หรือ 15.3% ต่อปี ส่วนที่วัดเกินจึงเกือบเท่าตัว ($0.10/0.0557=1.8$ เท่า) ไม่ใช่ 7.7%

เห็น ACF ติดลบแล้วคิดว่าเป็น mean reversion ที่ทำกำไรได้ (mean reversion คือราคาที่ขึ้นแล้วมักกลับลง) ราคาที่เด้งกลับคือราคาของอีกฝั่งของ spread ไม่ใช่มูลค่าที่เปลี่ยนจริง คนที่เก็บกำไรนี้ได้ต้องซื้อที่ bid และขายที่ ask ซึ่งคืองานของ market maker คือคนที่ตั้งราคารอซื้อและรอขายไว้ทั้งสองฝั่ง ถ้าเราส่งคำสั่งข้าม spread เอง (ซื้อที่ ask แล้วขายที่ bid) จะเสียเงินราว 4.93 เซนต์ต่อหุ้นทุกรอบ ตามที่คำนวณในขั้นที่ 6 ก่อนทดสอบกลยุทธ์ ให้ใช้ราคากลาง หรือหัก spread ออกก่อนเสมอ

เห็นแท่ง ACF แท่งเดียวที่ lag 1 แล้วฟิต AR(1) AR(1) ที่ $\phi=-0.345$ ทำนายว่า ACF ที่ lag 2 คือ $\phi^2=(-0.345)^2=+0.119$ สมมติข้อมูล 10,000 นาทีให้ ACF ที่ lag 2 แค่ 0.003 ซึ่งอยู่ในแถบความบังเอิญ $\pm2/\sqrt{10{,}000}=\pm0.02$ ข้อมูลกำลังบอกว่า lag 2 เป็นศูนย์ คือเป็น MA ไม่ใช่ AR จึงต้องดู PACF ประกอบเสมอ

ผสมหน่วย ป้อน SD เป็น 0.10 (ตัวเลขในหน่วย %) แทน 0.001 (ทศนิยม) ตัวเลขใหญ่ไป $0.10/0.001=100$ เท่า variance จึงเพี้ยน $100^2=10{,}000$ เท่า และ spread ที่ถอดได้จาก $S=2\sqrt{-\gamma_1}$ เพี้ยน $\sqrt{10{,}000}=100$ เท่า แปลงทุกตัวเป็นทศนิยมก่อนแทนสูตร

ใช้ทำอะไรบนโต๊ะจริง

Roll estimator ใช้ประมาณต้นทุนการซื้อขาย (spread) จากราคาซื้อขายอย่างเดียว จึงเหมาะกับข้อมูลเก่า หรือตลาดที่ไม่มีสมุดคำสั่งให้ดู ใช้ตรวจได้ด้วยว่าการเด้งทำให้ความผันผวนจากข้อมูลถี่ดูใหญ่เกินจริงแค่ไหน ก่อนส่งตัวเลขเข้าระบบ VaR

การเด้งไม่ใช่ความคลาดแหล่งเดียว ราคาจากหลายตลาดที่ไม่ตรงกัน เวลาที่บันทึกคลาดเคลื่อน และหุ้นที่ซื้อขายห่างกันเกิน 5 นาทีต่อครั้ง ก็ทำให้ราคาที่เห็นคลาดจากมูลค่าจริงได้ ถ้าต้องการราคาปิดที่สะอาด ค่าเฉลี่ยถ่วงของราคาช่วงท้ายวันมักดีกว่าราคาซื้อขายครั้งสุดท้ายเพียงครั้งเดียว ด้วยเหตุผลเดียวกับรูป EWMA

ARMA และ ARIMA ใช้พยากรณ์อนุกรมที่มีทั้งแรงดึงกลับและร่องรอยของข่าว เช่นสเปรดหุ้นกู้ และ volume (ปริมาณการซื้อขาย) ขั้นตอนมาตรฐานคือ ดูลายเซ็นของ ACF และ PACF ฟิตแบบจำลองเล็ก ๆ ไม่กี่แบบ เทียบด้วย AIC หรือ BIC แล้วตรวจ ACF ของ residual ด้วย Ljung–Box ระวังว่าการทดสอบที่ไม่ปฏิเสธ ไม่ได้พิสูจน์ว่า residual อิสระกัน มันแค่บอกว่ายังไม่พบหลักฐานว่ามีความจำเหลืออยู่

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด

รันใน Node.js ได้โดยไม่ต้องติดตั้งแพ็กเกจ โค้ดคำนวณตัวเลขทุกตัวในหน้านี้ซ้ำ และปฏิเสธการใช้ Roll ในสองกรณี คือเมื่อ $\gamma_1$ ไม่ติดลบ และเมื่อ $\rho_1$ ต่ำกว่า −1/2 เพราะกรณีหลังทำให้ $\sigma_e^2=\gamma_0+2\gamma_1$ ติดลบ การเด้งอย่างเดียวอธิบายไม่ได้ PACF คำนวณด้วย Durbin–Levinson ซึ่งคือการแก้สมการปกติทีละ lag โค้ดยังหาน้ำหนัก Kalman ของแบบจำลอง Roll และสร้างตลาดแบบ Roll ด้วยเครื่องสุ่มที่กำหนด seed ไว้ เพื่อตรวจว่าวิธีถอด spread คืนค่าที่ใส่ไว้ได้จริง และน้ำหนัก 0.6 ให้ความคลาดต่ำสุดจริง

function finite(...xs) {
  if (!xs.every(Number.isFinite)) throw new TypeError('Inputs must be finite numbers');
}
// MA(1): X = mu + e_t + theta e_(t-1). Memory of exactly one period of news.
function ma1(theta, sigma) {
  finite(theta, sigma);
  if (!(sigma > 0)) throw new RangeError('Need sigma > 0');
  const s2 = sigma * sigma;
  return {gamma0: s2 * (1 + theta * theta), gamma1: theta * s2, rho1: theta / (1 + theta * theta), longRunSD: sigma * Math.abs(1 + theta)};
}
// Roll: gamma0 = sigma_e^2 + S^2/2 and gamma1 = -S^2/4, solved for the spread and the efficient variance.
function roll(gamma0, gamma1) {
  finite(gamma0, gamma1);
  if (!(gamma0 > 0)) throw new RangeError('Variance must be positive');
  if (!(gamma1 < 0)) throw new RangeError('Roll needs a negative lag-1 autocovariance');
  const efficientVar = gamma0 + 2 * gamma1;
  if (!(efficientVar > 0)) throw new RangeError('rho1 below -1/2: bounce alone cannot explain it');
  return {spread: 2 * Math.sqrt(-gamma1), efficientVar, efficientSD: Math.sqrt(efficientVar), bounceShare: -2 * gamma1 / gamma0};
}
// Steady-state Kalman gain for "random walk seen through noise": state variance q, noise variance r.
function kalmanGain(q, r) {
  if (!(q > 0) || !(r > 0)) throw new RangeError('Need positive variances');
  const p = q * (1 + Math.sqrt(4 * r / q + 1)) / 2;
  return p / (p + r);
}
function annualize(sdPerMinute, minutesPerDay, daysPerYear = 252) {
  finite(sdPerMinute, minutesPerDay, daysPerYear);
  if (!(sdPerMinute >= 0) || !(minutesPerDay > 0) || !(daysPerYear > 0)) throw new RangeError('Need sd >= 0 and positive day counts');
  return {day: sdPerMinute * Math.sqrt(minutesPerDay), year: sdPerMinute * Math.sqrt(minutesPerDay * daysPerYear)};
}
// Returns over m minutes: efficient moves add up (m sigma_e^2); the bounce telescopes to its two endpoints (S^2/2).
function aggregate(m, efficientVar, spread, minutesPerDay = 300) {
  if (!Number.isInteger(m) || m < 1) throw new RangeError('Window must be a whole number of minutes');
  const variance = m * efficientVar + spread * spread / 2;
  return {bounceShare: spread * spread / 2 / variance, naiveAnnual: Math.sqrt(variance / m * minutesPerDay * 252)};
}
// PACF by the Durbin-Levinson recursion: the last coefficient of the best k-lag linear predictor.
function pacf(rho, K) {
  if (!Array.isArray(rho) || rho[0] !== 1 || rho.length <= K || !Number.isInteger(K) || K < 1) throw new RangeError('Need rho[0] = 1 and lags up to K');
  let prev = [];
  const out = [];
  for (let k = 1; k <= K; k++) {
    let num = rho[k], den = 1;
    for (let j = 1; j < k; j++) { num -= prev[j - 1] * rho[k - j]; den -= prev[j - 1] * rho[j]; }
    const last = num / den, next = [];
    for (let j = 1; j < k; j++) next.push(prev[j - 1] - last * prev[k - j - 1]);
    next.push(last); prev = next; out.push(last);
  }
  return out;
}
// ARMA(1,1): weights psi_0 = 1, psi_j = (phi + theta) phi^(j-1); ACF decays at phi after lag 1.
function arma11(phi, theta, lags = 4) {
  finite(phi, theta);
  if (!(Math.abs(phi) < 1) || !(Math.abs(theta) < 1)) throw new RangeError('Need |phi| < 1 and |theta| < 1');
  const gamma0 = (1 + 2 * phi * theta + theta * theta) / (1 - phi * phi);
  const rho = [1, (1 + phi * theta) * (phi + theta) / (1 + 2 * phi * theta + theta * theta)];
  for (let k = 2; k <= lags; k++) rho.push(phi * rho[k - 1]);
  return {gamma0, gamma1: phi * gamma0 + theta, rho, psi: [1, 2, 3].map(j => (phi + theta) * phi ** (j - 1))};
}
// ARIMA(0,1,1) one-step forecast = exponential smoothing with weight 1 + theta on the newest price.
function smooth(prices, start, theta) {
  finite(start, theta);
  if (!Array.isArray(prices) || !prices.length || ![...prices].every(Number.isFinite)) throw new TypeError('Need finite prices');
  if (!(Math.abs(theta) < 1)) throw new RangeError('Need |theta| < 1');
  const out = [];
  let f = start;
  for (const p of prices) { f = (1 + theta) * p - theta * f; out.push(f); }
  return out;
}
function generator(seed) {
  let a = seed >>> 0, spare = null;
  const uniform = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  const normal = () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const radius = Math.sqrt(-2 * Math.log(uniform())), angle = 2 * Math.PI * uniform();
    spare = radius * Math.sin(angle);
    return radius * Math.cos(angle);
  };
  return {uniform, normal};
}
// A Roll market: efficient return e_t plus half a spread times the change in trade direction.
function simulateRoll(minutes, efficientSD, spread, seed) {
  if (!Number.isInteger(minutes) || minutes < 3) throw new RangeError('Need at least three minutes');
  finite(efficientSD, spread);
  const g = generator(seed), x = [];
  let q = g.uniform() < 0.5 ? -1 : 1;
  for (let t = 0; t < minutes; t++) {
    const next = g.uniform() < 0.5 ? -1 : 1;
    x.push(efficientSD * g.normal() + spread / 2 * (next - q));
    q = next;
  }
  const mean = x.reduce((s, v) => s + v, 0) / minutes;
  let g0 = 0, g1 = 0;
  for (let t = 0; t < minutes; t++) { g0 += (x[t] - mean) ** 2; if (t) g1 += (x[t] - mean) * (x[t - 1] - mean); }
  g0 /= minutes; g1 /= minutes;
  return {gamma0: g0, gamma1: g1, rho1: g1 / g0, estimate: roll(g0, g1)};
}
// Dollar prices of the $42 stock: how close does an EWMA with weight K stay to the true mid value?
function filterError(K, trades, stepSD, halfSpread, seed) {
  const g = generator(seed);
  let m = 42, f = 42, s = 0;
  for (let t = 0; t < trades; t++) {
    m += stepSD * g.normal();
    const p = m + (g.uniform() < 0.5 ? -1 : 1) * halfSpread;
    f = K * p + (1 - K) * f;
    s += (f - m) ** 2;
  }
  return Math.sqrt(s / trades);
}

สิ่งที่ควรตอบได้หลังอ่าน

  • MA(1) มี ACF ที่ lag 1 เท่ากับ $\theta/(1+\theta^2)$ ซึ่งมีขนาดไม่เกิน 1/2 และเป็นศูนย์ตั้งแต่ lag 2 ส่วน PACF ค่อย ๆ จาง กลับด้านกับ AR(1)
  • ค่า $\theta$ กับ $1/\theta$ ให้ ACF เดียวกัน เราเลือกค่าที่ $|\theta|\lt1$ (invertible) เพราะย้อนคำนวณข่าวได้ด้วยน้ำหนักที่จางลง
  • ในแบบจำลองของ Roll ผลตอบแทนที่มีการเด้งเป็น MA(1) spread คือ $S=2\sqrt{-\gamma_1}$ และ variance ของข่าวจริงคือ $\gamma_0+2\gamma_1$ หุ้น \$42 ในตัวอย่างมี spread 4.93 เซนต์ และความผันผวนจริง 15.3% ต่อปี ไม่ใช่ 27.5%
  • ข่าวสะสมตามเวลา แต่การเด้งไม่สะสม ข้อมูลที่ห่างขึ้นจึงลดส่วนของการเด้ง แลกกับจุดข้อมูลที่น้อยลง
  • ARMA(1,1) มี ACF ที่ lag 1 ซึ่งถูกความจำข่าวดึง แล้วจางด้วยอัตรา $\phi$ ระวังกรณี $\phi=-\theta$ ที่ความจำสองแบบหักล้างกันหมด และเลือกแบบจำลองด้วย AIC หรือ BIC
  • ARIMA(0,1,1) ให้คำทำนายเป็น EWMA ที่น้ำหนัก $1+\theta$ ซึ่งเท่ากับ Kalman gain ของแบบจำลอง Roll (0.6 ในตัวอย่าง) การหาผลต่างของ white noise โดยไม่จำเป็น สร้าง $\rho_1=-0.5$ ปลอมขึ้นมาได้

ทั้ง AR และ MA สร้างความจำให้ค่าเฉลี่ยของพรุ่งนี้ แต่หน้า ACF พบว่าความจำที่แรงที่สุดของผลตอบแทนอยู่ที่ขนาดของการขยับ ไม่ใช่ทิศ หน้าถัดไป ARCH และ GARCH จึงใช้ความคิดเดียวกันกับ variance ให้ความเสี่ยงวันนี้จำข่าวกำลังสองของเมื่อวาน
