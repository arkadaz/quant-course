16.3 MA, ARMA, and ARIMA

MA จำข่าวของเมื่อวาน ไม่ได้จำค่าของเมื่อวาน ACF ของมันจึงตัดเป็นศูนย์หลังไม่กี่ lag และราคาที่เด้งระหว่าง bid กับ ask คือ MA(1) ที่บอกได้ทั้ง spread และความผันผวนจริง

ผลตอบแทนรายนาทีของหุ้นราคา \$42 มี SD 0.10% ต่อนาที และ autocorrelation ที่ lag 1 เท่ากับ −0.345 ระบบความเสี่ยงคูณด้วยรากของจำนวนนาทีต่อปี (300 นาทีต่อวัน × 252 วัน) ได้ความผันผวน 27.5% ต่อปี แล้วเอาไปคิด VaR ตัวเลขนี้เชื่อได้ไหม และ bid–ask spread ของหุ้นตัวนี้กว้างกี่เซนต์?

ลองตอบก่อนเปิดเฉลย

ถ้าสมมติว่าราคาเป็นไปตามแบบจำลอง Roll ซึ่งมีข่าวใหม่กับการเด้งระหว่าง bid และ ask จะคำนวณได้ spread 0.1174% ของราคา หรือ 4.93 เซนต์ต่อหุ้น หักส่วนเด้งออกแล้วราคาจริงแกว่งแค่ 0.0557% ต่อนาที หรือ 15.3% ต่อปี ตัวเลข 27.5% สูงกว่าความผันผวนของข่าวจริง 1.8 เท่า เพราะ 69% ของ variance รายนาทีคือการเด้ง ไม่ใช่ข่าว

ภาพรวมก่อนลงสูตร

หน้า AR processes สร้างความจำของค่า: เดือนนี้เก็บ 88% ของสเปรดเดือนก่อน แล้วค่านั้นก็ส่งต่อไปเดือนถัดไปอีก ข่าวหนึ่งก้อนจึงจางแต่ไม่เคยหายหมด หน้านี้สร้างความจำอีกแบบ คือความจำของข่าว: ค่าวันนี้มีเศษของข่าวเมื่อวานติดมาด้วย แล้วเศษนั้นหายไปหมดในวันถัดไป แบบจำลองนี้ชื่อ moving-average process หรือ MA ตัวอย่างที่ชัดที่สุดในตลาดคือราคาซื้อขายที่เด้งระหว่าง bid กับ ask

รูปด้านล่างคือความต่างทั้งหมดในภาพเดียว: ส่งข่าวขนาด 1 เข้าไปหนึ่งก้อนแล้วดูว่ามันค้างอยู่เท่าไรในงวดต่อ ๆ ไป MA(1) ค้างงวดเดียวแล้วเป็นศูนย์พอดี AR(1) จางลงครึ่งหนึ่งทุกงวดไม่มีวันถึงศูนย์ ARMA ผสมทั้งสอง ความต่างนี้ทิ้งลายเซ็นไว้ใน ACF ที่เราใช้แยกสองแบบออกจากกันจากข้อมูล

เราจะนับการเด้งด้วยมือก่อน แล้วเขียนเป็น MA(1) หาลายเซ็นใน ACF และ PACF หาเพดานของมัน ใช้มันถอด spread และความผันผวนจริงแบบของ Roll ดูว่าความถี่ของข้อมูลเปลี่ยนภาพอย่างไร รวมสองความจำเป็น ARMA แล้วปิดด้วย ARIMA ซึ่งเป็นแบบจำลองของราคาที่ต้องหาผลต่างก่อน และให้คำทำนายเป็นค่าเฉลี่ยถ่วงแบบเรขาคณิตที่กรองการเด้งออกได้ ตัวเลขของหุ้น \$42 เป็นตัวอย่างสมมติ

ศัพท์ที่ใช้ในหัวข้อนี้
MA(q)
moving-average process: ค่าวันนี้คือข่าววันนี้บวกข่าวของ $q$ งวดก่อนถ่วงน้ำหนัก ความจำจึงหมดหลัง $q$ งวดพอดี ชื่อนี้ไม่ใช่เส้นค่าเฉลี่ยเคลื่อนที่ของราคาบนกราฟ
ARMA(p, q)
แบบจำลองที่มีทั้งความจำของค่า $p$ งวด (AR) และความจำของข่าว $q$ งวด (MA) ใช้เมื่อสองกลไกเกิดพร้อมกัน ด้วย parameter น้อยกว่าการใช้อย่างใดอย่างหนึ่งล้วน ๆ
ARIMA(p, d, q)
ARMA ที่ใช้กับผลต่างของอนุกรม $d$ ครั้ง ใช้กับระดับที่ไม่ stationary เช่นราคา ซึ่งหาผลต่างหนึ่งครั้งแล้วได้การเปลี่ยนแปลงที่ stationary
PACF
partial autocorrelation: สัมประสิทธิ์ของ lag $k$ ในสมการทำนายที่ใช้ $k$ lag ล่าสุดพร้อมกัน คือความสัมพันธ์ที่เหลือหลังหักส่วนที่ lag ใกล้กว่าอธิบายไปแล้ว ใช้คู่กับ ACF เพื่อเลือกระหว่าง AR กับ MA
Invertibility
เงื่อนไข $|\theta|\lt1$ ของ MA ที่ทำให้ถอยกลับไปหาข่าวจากข้อมูลได้ด้วยน้ำหนักที่จางลง มีไว้เลือกหนึ่งคำตอบจากสองค่าของ $\theta$ ที่ให้ ACF เดียวกัน
Bid–ask bounce
การที่ราคาซื้อขายกระโดดระหว่างราคาเสนอซื้อ (bid) กับราคาเสนอขาย (ask) ตามว่าฝ่ายไหนส่งคำสั่งแบบ market order เข้ามา ทั้งที่มูลค่าตรงกลางไม่ขยับ เป็น microstructure noise ที่ทำให้ความผันผวนความถี่สูงดูใหญ่เกินจริง
Roll estimator
วิธีของ Richard Roll ที่ถอด bid–ask spread ออกจาก autocovariance lag 1 ที่ติดลบ โดยใช้แค่ราคาซื้อขาย ไม่ต้องเห็นสมุดคำสั่ง
สัญลักษณ์และหน่วย

$X_t$ผลตอบแทนที่วัดจากราคาซื้อขายในนาทีที่ $t$ทศนิยมต่อนาที

ขั้นที่ 1 — ราคาที่เด้งระหว่าง bid กับ ask นับด้วยมือ

เริ่มจากตลาดที่ไม่มีข่าวเลย มูลค่าตรงกลางอยู่ที่ \$100 ตลอด bid คือ \$99.90 ask คือ \$100.10 spread $S=\$0.20$ ทุกนาทีมีคนส่ง market order หนึ่งครั้ง ผู้ซื้อ (ซึ่งต้องจ่ายที่ ask) หรือผู้ขาย (ซึ่งได้ที่ bid) อย่างละครึ่ง และไม่เกี่ยวกับนาทีก่อน ให้ $q_t=\pm1$ เป็นทิศของการเคาะ ราคาที่เห็นจึงเป็นครึ่ง spread บวกหรือลบจากตรงกลาง แล้วนับ variance และ covariance ของการเปลี่ยนราคา

\[ \begin{aligned} P_t&=100+0.10\,q_t,\\ \Delta P_t&=0.10\,(q_t-q_{t-1}),\\ \gamma_0&=0.10^2\operatorname{Var}(q_t-q_{t-1})\\ &=0.01(2)=0.02,\\ \gamma_1&=0.01\,\mathbb E\big[(q_t-q_{t-1})(q_{t-1}-q_{t-2})\big]\\ &=0.01(0-0-1+0)=-0.01,\\ \gamma_2&=0.01\,\mathbb E[(q_t-q_{t-1})\\ &\qquad\cdot(q_{t-2}-q_{t-3})]\\ &=0,\\ \rho_1&=-0.01/0.02=-0.5,\\ S&=2\sqrt{-\gamma_1}=2\sqrt{0.01}=0.20. \end{aligned} \]

มูลค่าตรงกลางไม่ขยับเลย แต่ราคาที่เห็นเด้ง เพราะแต่ละนาทีจะเกิดที่ \$99.90 หรือ \$100.10 ตามว่าใครเคาะ การเปลี่ยนราคาจึงมีสามค่า: −0.20 (จาก ask ลง bid), 0 (ฝั่งเดิม) และ +0.20

จุดที่ต้องดูคือบรรทัด $\gamma_1$ กระจายวงเล็บได้สี่พจน์ พจน์เดียวที่มีทิศของนาทีเดียวกันคูณกันคือ $-q_{t-1}^2=-1$ อีกสามพจน์เป็นการเคาะคนละนาทีซึ่งเฉลี่ยเป็นศูนย์ ที่ lag 2 ไม่มีนาทีไหนซ้ำกันเลย จึงได้ศูนย์พอดี ราคาขึ้นมักตามด้วยราคาลง เพราะการเคาะที่ ask ครั้งนี้ทำให้ครั้งหน้ามีโอกาสลงไป bid

บรรทัดสุดท้ายอ่านย้อนกลับ: วัด $\gamma_1$ ได้ ก็ถอด spread ได้ นี่คือความคิดของ Roll ที่จะใช้กับข้อมูลที่ราคาจริงขยับด้วยในอีกไม่กี่ขั้น

ขั้นที่ 2 — MA(1): ความจำของข่าวแค่หนึ่งงวด

ดูการเด้งอีกครั้ง: $\Delta P_t=0.10q_t-0.10q_{t-1}$ คือข่าวของนาทีนี้บวกข่าวของนาทีก่อนคูณ −1 เขียนแบบทั่วไปเป็น MA(1) ซึ่งเป็นนิยาม: ค่าวันนี้คือค่าเฉลี่ย บวกข่าววันนี้ บวกข่าวเมื่อวานถ่วงด้วย $\theta$ โดยข่าวแต่ละวันอิสระกัน ค่าเฉลี่ยศูนย์ variance $\sigma^2$ แล้วหา autocovariance แบบเดียวกับการนับมือ

\[ \begin{aligned} X_t&=\mu+\epsilon_t+\theta\epsilon_{t-1},\\ \gamma_0&=\mathbb E[(\epsilon_t+\theta\epsilon_{t-1})^2]\\ &=\sigma^2(1+\theta^2),\\ \gamma_1&=\mathbb E[(\epsilon_t+\theta\epsilon_{t-1})\\ &\qquad\cdot(\epsilon_{t-1}+\theta\epsilon_{t-2})]\\ &=\theta\,\mathbb E[\epsilon_{t-1}^2]=\theta\sigma^2,\\ \gamma_k&=0\quad(k\ge2),\\ \rho_1&=\frac{\theta\sigma^2}{\sigma^2(1+\theta^2)}=\frac{\theta}{1+\theta^2},\\ \theta=-1:&\quad\rho_1=-1/2,\\ \theta=-0.4:&\quad\rho_1=-0.4/1.16\\ &\quad\approx-0.3448. \end{aligned} \]

กางกำลังสองของบรรทัดที่สองแล้วพจน์ไขว้หายเพราะข่าวคนละวันอิสระกัน เหลือ variance สองก้อน ใน $\gamma_1$ ก็เหมือนการนับมือ: ในสี่พจน์ มีแค่ $\epsilon_{t-1}$ ที่ปรากฏทั้งสองวงเล็บ ที่ lag 2 ไม่มีข่าวไหนซ้ำ จึงเป็นศูนย์พอดี

นี่คือลายเซ็นของ MA(1): ACF มีค่าที่ lag 1 แล้วตัดขาดเป็นศูนย์ ต่างจาก AR(1) ที่ ACF คูณด้วย $\phi$ ทุก lag และไม่ตัดเป็นศูนย์ MA($q$) ทั่วไปทำแบบเดียวกันที่ lag $q$: สองค่าที่ห่างกันเกิน $q$ งวดไม่มีข่าวร่วมกันเลย การเด้งล้วน ๆ คือกรณี $\theta=-1$ และตัวอย่างหุ้น \$42 ฟิตได้ $\theta=-0.4$ ซึ่งให้ $\rho_1=-0.3448$

ขั้นที่ 3 — ลายเซ็นใน ACF และ PACF: แยก MA ออกจาก AR

สมมติใช้ข้อมูลเมื่อวานทำนายวันนี้อยู่แล้ว ถ้าเพิ่มข้อมูลเมื่อวานซืน จะช่วยอีกไหม? PACF ที่ lag 2 คือสัมประสิทธิ์ของเมื่อวานซืนในสมการทำนายที่ใส่ทั้งสองวัน ต่างจาก ACF ที่เทียบวันนี้กับเมื่อวานซืนโดยไม่ได้ใส่เมื่อวานเข้ามาด้วย ลองเทียบสองแบบจำลองที่มี ACF lag 1 เท่ากัน: MA(1) ใช้ $\theta=-0.4$ ส่วน AR(1) ใช้ $\phi=-0.4/1.16$ ค่าทั้งหมดเป็นค่าของแบบจำลอง ไม่ใช่ค่าประมาณจากข้อมูลสั้น ๆ

\[ \begin{aligned} \rho_1^2&\approx0.1189,\\ \phi_{22}&=\frac{\rho_2-\rho_1^2}{1-\rho_1^2},\\ \text{MA(1)}:&\quad\frac{0-0.1189}{0.8811}\approx-0.1350,\\ \text{AR(1)}:&\quad\frac{0.1189-0.1189}{0.8811}=0. \end{aligned} \]

ใน AR(1) ได้ $\rho_2=\rho_1^2$ ตัวเศษจึงเป็นศูนย์: เมื่อใช้เมื่อวานแล้ว เมื่อวานซืนไม่ช่วยทำนายเชิงเส้นเพิ่ม เพราะทุกอย่างที่เมื่อวานซืนรู้ ถูกส่งผ่านค่าเมื่อวานมาหมดแล้ว สำหรับ MA(1) ค่าเมื่อวานซืนยังช่วยแยกข่าวที่ซ่อนอยู่ในค่าของเมื่อวาน จึงเหลือ PACF ที่ lag 2, 3, … ที่จางลง กฎจำง่าย: MA ตัด ACF แต่จาง PACF ส่วน AR ตัด PACF แต่จาง ACF

ที่มาของสูตร PACF lag 2

เขียนสมการทำนายด้วยสอง lag $\hat X_t=a_1X_{t-1}+a_2X_{t-2}$ แล้วใช้สมการปกติของ OLS regression (residual ต้องไม่มี covariance กับตัวแปรต้นแต่ละตัว) หารด้วย $\gamma_0$ จะได้สองสมการนี้ แทน $a_1=\rho_1-a_2\rho_1$ ลงสมการที่สองแล้วแก้หา $a_2$

\[ \begin{aligned} \rho_1&=a_1+a_2\rho_1,\\ \rho_2&=a_1\rho_1+a_2,\\ a_2(1-\rho_1^2)&=\rho_2-\rho_1^2,\\ \phi_{22}:=a_2&=\frac{\rho_2-\rho_1^2}{1-\rho_1^2}. \end{aligned} \]

ขั้นที่ 4 — เพดานของ MA(1) และ θ สองค่าที่ให้ ACF เดียวกัน

ค่า ACF ของ MA(1) ในประชากรมีขนาดไม่เกิน 0.5 เราพิสูจน์ได้จากกำลังสองไม่ติดลบ แต่ต้องแยกค่าประชากร $\rho_1$ ออกจากค่าที่ประมาณจากข้อมูล $\hat\rho_1$

\[ \begin{aligned} (1-|\theta|)^2&\ge0,\\ 1+\theta^2&\ge2|\theta|,\\ |\rho_1|=\frac{|\theta|}{1+\theta^2}&\le\frac12,\\ \theta=-2.5:&\quad\frac{-2.5}{1+6.25}=-0.3448. \end{aligned} \]

ขยายกำลังสองในบรรทัดแรกแล้วย้ายข้างได้บรรทัดที่สอง หารทั้งสองข้างด้วย $2(1+\theta^2)$ ได้เพดาน 1/2 ซึ่งเกิดที่ $|\theta|=1$ พอดี ค่า $\rho_1=-0.6$ จึงเป็น ACF ประชากรของ MA(1) ไม่ได้ แต่ตัวอย่างสั้น ๆ อาจให้ $\hat\rho_1=-0.6$ เพราะความคลาดของการสุ่ม ต้องประเมินความคลาดก่อนตัดแบบจำลองทิ้ง

บรรทัดสุดท้ายคือปัญหาใหม่: $\theta=-2.5$ ให้ ACF เท่ากับ $\theta=-0.4$ ทุกตำแหน่ง เพราะ $1/\theta$ ให้ $\rho_1$ เดิมเสมอ ดู ACF อย่างเดียวจึงแยกสองค่านี้ไม่ได้ เราเลือกค่าที่ถอดข่าวย้อนหลังได้อย่างเสถียร

เหตุผลนั้นคือเราต้องถอยกลับไปหาข่าวจากข้อมูล เพราะข่าวสังเกตตรง ๆ ไม่ได้ ย้ายข้างสมการ MA(1) แล้วแทนตัวเองซ้ำ

\[ \begin{aligned} \epsilon_t&=(X_t-\mu)-\theta\epsilon_{t-1}\\ &=(X_t-\mu)-\theta(X_{t-1}-\mu)\\ &\quad+\theta^2\epsilon_{t-2}\\ &=\sum_{j=0}^{k-1}(-\theta)^j(X_{t-j}-\mu)\\ &\quad+(-\theta)^k\epsilon_{t-k},\\ 0.4^{10}&\approx0.0001,\\ 2.5^{10}&\approx9{,}537. \end{aligned} \]

ที่ $\theta=-0.4$ น้ำหนักของข้อมูลย้อนหลังคือ $0.4^j$ จางลงจนข้อมูล 10 นาทีก่อนแทบไม่มีผล และก้อนท้ายที่ไม่รู้ค่าหายไป ที่ $\theta=-2.5$ น้ำหนักระเบิดเป็นหลักพันภายใน 10 นาที ข่าวที่ถอดได้จึงไม่มีความหมาย เงื่อนไข $|\theta|\lt1$ นี้เรียกว่า invertibility และเป็นเหตุที่เลือก −0.4 ไม่ใช่ −2.5 มันคือเงื่อนไขเดียวกับ $|\phi|\lt1$ ของ AR แต่ใช้กับการถอยกลับไปหาข่าว

ขั้นที่ 5 — แบบจำลองของ Roll: แยกการเด้งออกจากข่าวจริง

ตลาดจริงมีทั้งข่าวที่ขยับมูลค่าตรงกลาง และการเด้ง แบบจำลองของ Roll (Roll model) บอกว่ามูลค่าตรงกลางเดินแบบ random walk และราคาที่เห็นคือมูลค่านั้นบวกความคลาดในการวัดที่เป็นครึ่ง spread ใส่ข่าวจริง $e_t$ ที่อิสระกันทุกนาที variance $\sigma_e^2$ เข้าไปในกลไกการเด้ง โดยวัด spread $S$ เป็นสัดส่วนของราคา การเคาะไม่เกี่ยวกับข่าว variance และ covariance จึงบวกกันเป็นก้อน ๆ

\[ \begin{aligned} X_t&=e_t+\tfrac S2(q_t-q_{t-1}),\\ \gamma_0&=\sigma_e^2+\tfrac{S^2}{4}(2)=\sigma_e^2+\tfrac{S^2}{2},\\ \gamma_1&=\tfrac{S^2}{4}(-1)=-\tfrac{S^2}{4},\qquad\gamma_2=0,\\ S&=2\sqrt{-\gamma_1},\\ \sigma_e^2&=\gamma_0-\tfrac{S^2}{2}=\gamma_0+2\gamma_1. \end{aligned} \]

ข่าวจริงอิสระกันทุกนาที จึงเพิ่มแค่ใน $\gamma_0$ ไม่เพิ่มใน $\gamma_1$ ส่วนการเด้งให้ $2(S/2)^2$ กับ $-(S/2)^2$ ตามการนับมือ ACF ตัดขาดหลัง lag 1 ข้อมูลแบบนี้จึงเป็น MA(1) ในสายตาของสถิติ ทั้งที่ข้างในมีสองกลไก

สองบรรทัดล่างแก้หาของที่ไม่เห็น: $\gamma_1$ บอก spread และ $\gamma_0+2\gamma_1$ บอก variance ของข่าวจริง ตัวหลังมีอีกความหมาย: มันเท่ากับ $\sigma^2(1+\theta^2)+2\theta\sigma^2=\sigma^2(1+\theta)^2$ ของ MA(1) ซึ่งคือ variance ต่อนาทีเมื่อรวมช่วงที่ยาวมาก การเด้งตรงกลางหักล้างกัน เหลือเฉพาะหัวกับท้ายซึ่งมีสัดส่วนเล็กลง ถ้า ACF lag 2 ขึ้นไปไม่เป็นศูนย์ชัด แปลว่ามูลค่าตรงกลางเองมีความจำ แบบจำลองนี้ไม่พอแล้ว

ขั้นที่ 6 — ตอบโจทย์เปิด: spread และความผันผวนจริงของหุ้น \$42

โจทย์ให้อะไรมาบ้าง: SD ที่วัดได้ 0.10% ต่อนาที จึงได้ $\gamma_0=10^{-6}$ MA(1) ที่ฟิตได้ $\theta=-0.4$ จึงได้ $\rho_1=-0.3448$ และ $\gamma_1=\rho_1\gamma_0$ ราคาหุ้น \$42 ตัวเลข 300 นาทีต่อวันเป็นสมมติฐานของโจทย์ และ 252 วันทำการต่อปีมาจาก 365 วันลบเสาร์อาทิตย์ 104 วันและวันหยุดตลาดราว 9 วัน

\[ \begin{aligned} \gamma_1&=\frac{-0.4}{1.16}\times10^{-6}\\ &\approx-3.448\times10^{-7},\\ S&=2\sqrt{-\gamma_1}\\ &\approx2(5.872\times10^{-4})\\ &\approx0.1174\%,\\ S\times\$42&\approx\$0.0493,\\ \sigma_e^2&=10^{-6}+2\gamma_1\\ &\approx3.103\times10^{-7},\\ \sigma_e&\approx0.0557\%\ \text{per minute},\\ \sqrt{300}&\approx17.32,\\ \sqrt{300\times252}&\approx274.95,\\ \sigma_{\rm day}&\approx0.0557\%(17.32)\\ &\approx0.965\%,\\ \sigma_{\rm year}&\approx0.0557\%(274.95)\\ &\approx15.3\%,\\ \sigma_{\rm naive}&\approx0.10\%(274.95)\\ &\approx27.5\%. \end{aligned} \]

คำตอบ: spread คือ 0.1174% ของราคา หรือ 4.93 เซนต์ต่อหุ้น การเด้งกิน $6.897\times10^{-7}/10^{-6}=69\%$ ของ variance รายนาที ราคาจริงแกว่ง 0.0557% ต่อนาที 0.965% ต่อวัน และ 15.3% ต่อปี ภายใต้สมมติฐานของ Roll ตัวเลข 27.5% สูงกว่าความผันผวนของข่าวจริงประมาณ $0.10/0.0557=1.8$ เท่า การใช้มันเป็น volatility ใน VaR จึงทำให้ความเสี่ยงสูงเกินไปเกือบเท่าตัว

ตลาดหุ้นสหรัฐเปิดจริง 9:30 ถึง 16:00 คือ 390 นาที ไม่ใช่ 300 ถ้าใช้ 390 ตัวเลขรายวันและรายปีทุกตัวโตขึ้น $\sqrt{390/300}=1.140$ เท่า: แบบผิดได้ 31.3% แบบถูกได้ 17.5% ต่อปี แต่ spread, $\rho_1$ และอัตราส่วน 1.8 เท่าไม่เปลี่ยน เพราะคำนวณจากข้อมูลรายนาทีล้วน

ตรวจเองใน 10 วินาที: $\sigma(1+\theta)$ ของ MA(1) ต้องได้ $\sigma_e$ เดียวกัน: $\sigma=\sqrt{10^{-6}/1.16}=0.0928\%$ คูณ $0.6$ ได้ 0.0557% และ $0.1174\%\times42=\$0.0493$

ขั้นที่ 7 — ความถี่ของข้อมูล: ข่าวสะสม แต่การเด้งไม่สะสม

ถ้าวัดผลตอบแทนทุก $m$ นาทีแทนทุกนาที ข่าวจริงบวกกัน $m$ ก้อน ส่วนการเด้งรวม $m$ นาทีเหลือแค่หัวกับท้าย เพราะ $(q_1-q_0)+(q_2-q_1)+\cdots=q_m-q_0$ หักล้างกันเป็นทอด ๆ ขั้นนี้บอกว่าควรวัดความผันผวนจากข้อมูลถี่แค่ไหน

ขั้นที่ 8 — ARMA(1,1): จำทั้งค่าและข่าว

บางอนุกรมมีทั้งแรงดึงกลับแบบ AR และร่องรอยของข่าวแบบ MA เช่นสเปรดที่ค่อย ๆ กลับหาค่าเฉลี่ยแต่ถูกกวนด้วยการเด้ง รวมสองอย่างเป็น ARMA(1,1) สูตรต่อไปใช้ $|\phi|\lt1$ และค่าเฉลี่ยศูนย์ เพื่อหาน้ำหนักข่าวย้อนหลัง variance และ ACF

\[ \begin{aligned} X_t&=\phi X_{t-1}+\epsilon_t+\theta\epsilon_{t-1},\\ X_t&=\epsilon_t\\ &\quad+(\phi+\theta)\sum_{j=1}^{\infty}\phi^{j-1}\epsilon_{t-j},\\ \gamma_0&=\sigma^2\left[1+\frac{(\phi+\theta)^2}{1-\phi^2}\right]\\ &=\sigma^2\,\frac{1+2\phi\theta+\theta^2}{1-\phi^2},\\ \gamma_1&=\phi\gamma_0+\theta\sigma^2,\\ \rho_1&=\frac{(1+\phi\theta)(\phi+\theta)}{1+2\phi\theta+\theta^2},\\ \rho_k&=\phi\rho_{k-1}\quad(k\ge2),\\ \phi&=0.7,\quad\theta=-0.4:\\ \gamma_0&=\frac{0.60}{0.51}\sigma^2\approx1.176\sigma^2,\\ \rho_1&=\frac{0.72(0.3)}{0.60}=0.36,\\ \rho_2&=0.252. \end{aligned} \]

บรรทัดที่สองได้จากการแทนสมการตัวเองซ้ำแบบที่ทำกับ AR(1): ข่าวเมื่อวานได้น้ำหนัก $\phi+\theta$ ทันที แล้วจางลงทีละ $\phi$ ตรงกับแท่งม่วงในรูปแรกของหน้า variance คือผลรวมกำลังสองของน้ำหนัก ซึ่งเป็นอนุกรมเรขาคณิต

$\gamma_1$ ได้จากการคูณสมการด้วย $X_{t-1}$ แล้วหาค่าเฉลี่ย: ข่าววันนี้ไม่เกี่ยวกับเมื่อวานจึงหาย ส่วนข่าวเมื่อวานอยู่ใน $X_{t-1}$ ด้วยน้ำหนัก 1 จึงเหลือ $\theta\sigma^2$ หารด้วย $\gamma_0$ แล้วจัดรูปได้สูตร $\rho_1$

ลายเซ็นคือ lag 1 ถูกดึงลงจาก 0.7 เหลือ 0.36 ด้วยข่าวติดลบ จากนั้นจางด้วยอัตรา 0.7 แบบ AR(1) ทุกประการ ทั้ง ACF และ PACF จึงจางทั้งคู่ ไม่มีตัวไหนตัดขาด ถ้า $\theta=0$ สูตรกลับเป็น AR(1) ถ้า $\phi=0$ กลับเป็น MA(1) และ GARCH จะกลายเป็น ARMA(1,1) ของข่าวกำลังสอง

กับดักของ ARMA: ถ้า $\phi=-\theta$ เช่น $\phi=0.4,\ \theta=-0.4$ น้ำหนัก $\phi+\theta$ เป็นศูนย์ อนุกรมคือข่าววันนี้ล้วน ๆ เป็น white noise ความจำสองแบบหักล้างกันหมด ข้อมูลจึงให้ค่า $\phi$ กับ $\theta$ คู่ไหนก็ได้ที่ผลรวมเป็นศูนย์ ซอฟต์แวร์จะคืนค่าที่ดูมั่นใจแต่ไม่มีความหมาย ลองแบบจำลองที่เล็กกว่าก่อนเสมอ

ขั้นที่ 9 — ARIMA: หาผลต่างก่อน แล้วคำทำนายกลายเป็นค่าเฉลี่ยถ่วงแบบเรขาคณิต

ระดับราคาไม่ stationary แต่ผลต่างราคาในแบบจำลองของ Roll ทำตาม MA(1) เราเรียกแบบจำลองของระดับราคานี้ว่า ARIMA(0,1,1) ตัวเลขตรงกลางคือจำนวนครั้งที่หาผลต่าง ถามว่ามูลค่าจริงตอนนี้ควรประมาณเท่าไร ข่าวของครั้งหน้ายังไม่เกิด เหลือแค่ราคาล่าสุดกับเศษของข่าวล่าสุด และข่าวล่าสุดคือส่วนที่คำทำนายครั้งก่อนพลาด

\[ \begin{aligned} X_t-X_{t-1}&=\epsilon_t+\theta\epsilon_{t-1},\\ \hat X_{t+1|t}&=X_t+\theta\epsilon_t,\\ \epsilon_t&=X_t-\hat X_{t|t-1},\\ \hat X_{t+1|t}&=(1+\theta)X_t\\ &\quad-\theta\hat X_{t|t-1},\\ \theta&=-0.4:\\ \hat X_{t+1|t}&=0.6X_t+0.4\hat X_{t|t-1},\\ \hat X_{1|0}&=0.6(42.05)+0.4(42.00)\\ &=42.03,\\ \hat X_{2|1}&=0.6(41.99)+0.4(42.03)\\ &=42.006. \end{aligned} \]

เมื่อ $-1\lt\theta\lt0$ สมการคำทำนายนี้คือ exponential smoothing หรือ EWMA: คำทำนายใหม่คือค่าเฉลี่ยถ่วงของราคาล่าสุดกับคำทำนายเก่า น้ำหนักของราคาล่าสุดคือ $K=1+\theta=0.6$ กางต่อไปได้น้ำหนัก $0.6(0.4)^j$ บนราคาย้อนหลัง $j$ ครั้ง

ตัวอย่างการอัปเดตสองครั้ง: คำทำนายเก่า \$42.00 ราคาถัดมาเคาะที่ ask \$42.05 คำทำนายขยับแค่ไป \$42.03 คือ 60% ของการขึ้น เพราะส่วนที่เหลืออาจเป็นการเด้งที่จะกลับไป ครั้งต่อมาเคาะที่ bid \$41.99 คำทำนายลงมาแค่ \$42.006 นี่คือการกรองการเด้งออกด้วยสมการบรรทัดเดียว

ทำไมต้อง 0.6 พอดี? มองแบบจำลองของ Roll เป็นปัญหากรองสัญญาณ: สถานะที่ไม่เห็นคือมูลค่าตรงกลางซึ่งเดินด้วย variance $\sigma_e^2$ ต่อนาที สิ่งที่เห็นคือมูลค่านั้นบวกความคลาดที่มี variance $S^2/4$ ตัวกรองที่ดีที่สุดสำหรับปัญหาแบบนี้คือ Kalman filter (EWMA, Kalman, GARCH) ซึ่งในสภาวะนิ่งกลายเป็น EWMA ด้วยน้ำหนัก $K$ ที่หาได้จากอัตราส่วนของสอง variance

\[ \begin{aligned} \frac{S^2/4}{\sigma_e^2}&=\frac{0.4\sigma^2}{0.36\sigma^2}=\frac{10}{9},\\ P&=\sigma_e^2\,\frac{1+\sqrt{4(10/9)+1}}{2}\\ &=0.36\sigma^2\cdot\frac{1+7/3}{2}=0.6\sigma^2,\\ K&=\frac{P}{P+S^2/4}=\frac{0.6}{0.6+0.4}\\ &=0.6=1+\theta. \end{aligned} \]

บรรทัดแรกใช้สิ่งที่ถอดได้แล้ว: ความคลาดจากการเด้งคือ $-\gamma_1=0.4\sigma^2$ และข่าวจริงคือ $\sigma^2(1+\theta)^2=0.36\sigma^2$ โดย $\sigma^2$ คือ variance ของข่าวใน MA(1) $P$ คือความไม่แน่นอนของมูลค่าจริงก่อนเห็นราคาใหม่ในสภาวะนิ่ง (สูตรนี้รับมาจากการแก้สมการ Kalman แบบหนึ่งตัวแปร) และ $K$ คือสัดส่วนที่ควรเชื่อราคาใหม่ ได้ 0.6 ตรงกับ ARIMA ทุกตำแหน่ง สองมุมมองให้คำตอบเดียวกัน: ยิ่งการเด้งใหญ่เทียบกับข่าว ยิ่งควรเชื่อราคาล่าสุดน้อยลง

ตัวเลข $d$ ใน ARIMA($p$, $d$, $q$) ต้องเลือกให้พอดี หาผลต่างเกินก็เกิดของปลอม: ถ้าอนุกรมเป็น white noise อยู่แล้ว ผลต่างของมันคือ $\epsilon_t-\epsilon_{t-1}$ ซึ่งเป็น MA(1) ที่ $\theta=-1$ และได้ $\rho_1=-0.5$ พอดี หน้าตาเหมือนการเด้งทุกอย่าง ทั้งที่ข้อมูลเดิมไม่มีความจำเลย

ขั้นที่ 10 — เลือก p กับ q: ระบุ ประมาณ ตรวจ

ขั้นตอนมาตรฐานของ Box และ Jenkins มีสามจังหวะ: ระบุแบบจำลองจากลายเซ็น ACF และ PACF, ประมาณ parameter ด้วย maximum likelihood แล้วตรวจว่า residual เป็น white noise ด้วย Ljung–Box เมื่อลายเซ็นคลุมเครือ ให้ฟิตหลายแบบแล้วเทียบด้วยเกณฑ์ที่ลงโทษจำนวน parameter $k$ สมมติฟิต AR(1) และ ARMA(1,1) กับข้อมูล 1,000 จุด ได้ log-likelihood 5,000.0 และ 5,001.5 โดยกำหนดค่าเฉลี่ยเป็นศูนย์ จึงนับ $k=2$ (AR กับ variance ข่าว) และ $k=3$ (เพิ่ม MA)

\[ \begin{aligned} \mathrm{AIC}&=-2\ln L+2k,\\ \mathrm{BIC}&=-2\ln L+k\ln n,\\ \mathrm{AIC}_{\rm AR}&=-10{,}000+4=-9{,}996,\\ \mathrm{AIC}_{\rm ARMA}&=-10{,}003+6=-9{,}997,\\ \ln1000&=6.908,\\ \mathrm{BIC}_{\rm AR}&=-10{,}000+13.82=-9{,}986.2,\\ \mathrm{BIC}_{\rm ARMA}&=-10{,}003+20.72=-9{,}982.3. \end{aligned} \]

ทั้งสองเกณฑ์เริ่มจาก $-2\ln L$ ซึ่งยิ่งต่ำยิ่งเข้ากับข้อมูล แล้วบวกค่าปรับต่อ parameter ค่าที่ต่ำกว่าชนะ AIC ปรับตัวละ 2 จึงเลือก ARMA (−9,997 ต่ำกว่า −9,996) BIC ปรับตัวละ $\ln n=6.91$ จึงเลือก AR (−9,986.2 ต่ำกว่า −9,982.3) log-likelihood ที่เพิ่ม 1.5 จากการเพิ่มหนึ่ง parameter พอสำหรับ AIC แต่ไม่พอสำหรับ BIC สองเกณฑ์ขัดกันได้ BIC ชอบแบบจำลองเล็กกว่าเมื่อข้อมูลเยอะ ซึ่งมักปลอดภัยกว่าสำหรับการพยากรณ์นอกข้อมูลที่ฟิต

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

เรียกขนาดข่าวของ MA ว่าความผันผวนจริง: หาร 0.10% ด้วย $\sqrt{1.16}=1.077$ ได้ $\sigma=0.0928\%$ แล้วสรุปว่า “วัดเกินแค่ 7.7%” หรือ 25.5% ต่อปีแทน 27.5% ผิดทิศ $\sigma$ ของ MA ยังรวมการเด้งอยู่ ราคาจริงแกว่ง $\sigma(1+\theta)=0.0557\%$ ต่อนาที หรือ 15.3% ต่อปี ส่วนที่วัดเกินจึงเกือบเท่าตัว ไม่ใช่ 7.7%

เห็น ACF ติดลบแล้วเรียกว่า mean reversion ที่ทำกำไรได้: ราคาที่เด้งกลับคือราคาเดิมของอีกฝั่ง จะเก็บมันได้ต้องซื้อที่ bid ขายที่ ask ซึ่งคืองานของ market maker ถ้าส่งคำสั่งข้าม spread เอง เสียราว 4.93 เซนต์ต่อหุ้นทันทีทุกรอบ ทดสอบกลยุทธ์บนราคากลางหรือหัก spread ก่อนเสมอ

เห็นแท่ง ACF แท่งเดียวที่ lag 1 แล้วฟิต AR(1): AR(1) ที่ $\phi=-0.345$ จะทำนายว่า ACF lag 2 เป็น +0.119 ถ้าข้อมูล 10,000 นาทีให้ lag 2 แค่ 0.003 (แถบความบังเอิญคือ ±0.02) ข้อมูลกำลังบอกว่าเป็น MA ไม่ใช่ AR ดู PACF ด้วยเสมอ

ผสมหน่วย: ป้อน 0.10 (หน่วย %) แทน 0.001 variance เพี้ยน $100^2=10{,}000$ เท่า และ spread ที่ถอดได้เพี้ยน 100 เท่า ตรวจว่าทุกตัวเป็นทศนิยมก่อนแทนสูตร

ใช้ทำอะไรบนโต๊ะจริง

Roll estimator ใช้ประมาณต้นทุนสภาพคล่องจากราคาซื้อขายอย่างเดียว เหมาะกับข้อมูลเก่าหรือตลาดที่ไม่มีสมุดคำสั่งให้ดู และใช้ตรวจว่าความผันผวนความถี่สูงถูกการเด้งทำให้ดูใหญ่แค่ไหนก่อนส่งเข้าระบบ VaR การเด้งไม่ใช่ความคลาดแหล่งเดียว ราคาจากหลายตลาด การประทับเวลา และหุ้นที่ซื้อขายไม่ถึงครั้งละ 5 นาทีก็ทำให้ราคาที่เห็นคลาดจากมูลค่าจริงได้ ถ้าต้องการราคาปิดที่สะอาด ค่าเฉลี่ยถ่วงของราคาช่วงท้ายวันมักดีกว่าราคาซื้อขายครั้งสุดท้ายครั้งเดียว ด้วยเหตุผลเดียวกับรูป EWMA

ARMA และ ARIMA ใช้พยากรณ์อนุกรมที่มีทั้งแรงดึงกลับและร่องรอยข่าว เช่นสเปรดและ volume ขั้นตอนมาตรฐานคือ: ดูลายเซ็น ACF/PACF, ฟิตแบบจำลองเล็ก ๆ ไม่กี่แบบ, เทียบด้วย AIC หรือ BIC แล้วตรวจ ACF ของ residual ด้วย Ljung–Box โดยการไม่ปฏิเสธสมมติฐานไม่ใช่การพิสูจน์ว่า residual อิสระกัน

โจทย์ตรวจความเข้าใจ

1. MA(1) ที่ $\theta=0.5$ และ $\sigma=1$ มี $\gamma_0$, $\rho_1$ และ $\rho_2$ เท่าไร?

เฉลย

$\gamma_0=1+0.25=1.25$, $\gamma_1=0.5$ จึงได้ $\rho_1=0.5/1.25=0.4$ และ $\rho_2=0$ เพราะสองค่าที่ห่างกันสองงวดไม่มีข่าวร่วมกัน $\theta$ บวกให้ ACF บวก ข่าวดีเมื่อวานยังดันวันนี้ขึ้นอีกครึ่งหนึ่ง ตรงกับแท่งน้ำเงินในรูปแรกของหน้า

2. หุ้นราคา \$20 มี SD ผลตอบแทนรายนาที 0.20% และ $\hat\rho_1=-0.3$ จงหา spread เป็นเซนต์ SD ของข่าวจริงต่อนาที และน้ำหนัก EWMA ที่ดีที่สุดสำหรับประมาณมูลค่าจริง

เฉลย

$\gamma_0=0.002^2=4\times10^{-6}$ และ $\gamma_1=-0.3\gamma_0=-1.2\times10^{-6}$ ได้ $S=2\sqrt{1.2\times10^{-6}}=0.2191\%$ คูณ \$20 ได้ 4.38 เซนต์ ส่วน $\sigma_e^2=4\times10^{-6}-2.4\times10^{-6}=1.6\times10^{-6}$ จึงได้ $\sigma_e=0.1265\%$ ต่อนาที การเด้งกิน 60% ของ variance สำหรับน้ำหนัก: อัตราส่วน $(S^2/4)/\sigma_e^2=1.2/1.6=0.75$ ได้ $P=1.6\times10^{-6}(1+\sqrt{4(0.75)+1})/2=1.6\times10^{-6}(1+2)/2=2.4\times10^{-6}$ และ $K=2.4/(2.4+1.2)=0.667$ ตรวจด้วย MA(1): $\theta/(1+\theta^2)=-0.3$ ให้ $\theta=-0.333$ (รากที่ invertible) และ $1+\theta=0.667$ ตรงกัน

3. ARMA(1,1) ที่ $\phi=0.5$ และ $\theta=0.5$ มี $\gamma_0/\sigma^2$, $\rho_1$ และ $\rho_2$ เท่าไร?

เฉลย

$\gamma_0/\sigma^2=(1+0.5+0.25)/(1-0.25)=1.75/0.75=2.333$ และ $\rho_1=(1+0.25)(1.0)/1.75=0.714$ แล้ว $\rho_2=0.5(0.714)=0.357$ น้ำหนักของข่าวย้อนหลังคือ 1, 1, 0.5, 0.25 ตรงกับแท่งม่วงในรูปแรก: ข่าวเมื่อวานได้น้ำหนักเต็มหนึ่งเท่า เพราะทั้งความจำของค่าและของข่าวไปทางเดียวกัน ตรวจ: $1^2+1^2+0.5^2+0.25^2+\cdots=1+1/(1-0.25)=2.333$

รันใน Node.js ได้โดยไม่ติดตั้งแพ็กเกจ โค้ดปฏิเสธ Roll เมื่อ $\gamma_1$ ไม่ติดลบ หรือเมื่อ $\rho_1$ ต่ำกว่า −1/2 ซึ่งการเด้งอธิบายไม่ได้ คำนวณ PACF ด้วย Durbin–Levinson ซึ่งเป็นการแก้สมการปกติทีละ lag หาน้ำหนัก Kalman ของแบบจำลอง Roll และสร้างตลาดแบบ Roll ด้วยเครื่องสุ่มแบบมี seed เพื่อดูว่าวิธีถอด spread คืนค่าที่ใส่ไว้ได้จริง และน้ำหนัก 0.6 ให้ความคลาดต่ำสุดจริง

function finite(...xs) {
  if (!xs.every(Number.isFinite)) throw new TypeError('Inputs must be finite numbers');
}
// MA(1): X = mu + e_t + theta e_(t-1). Memory of exactly one period of news.
function ma1(theta, sigma) {
  finite(theta, sigma);
  if (!(sigma > 0)) throw new RangeError('Need sigma > 0');
  const s2 = sigma * sigma;
  return {gamma0: s2 * (1 + theta * theta), gamma1: theta * s2, rho1: theta / (1 + theta * theta), longRunSD: sigma * Math.abs(1 + theta)};
}
// Roll: gamma0 = sigma_e^2 + S^2/2 and gamma1 = -S^2/4, solved for the spread and the efficient variance.
function roll(gamma0, gamma1) {
  finite(gamma0, gamma1);
  if (!(gamma0 > 0)) throw new RangeError('Variance must be positive');
  if (!(gamma1 < 0)) throw new RangeError('Roll needs a negative lag-1 autocovariance');
  const efficientVar = gamma0 + 2 * gamma1;
  if (!(efficientVar > 0)) throw new RangeError('rho1 below -1/2: bounce alone cannot explain it');
  return {spread: 2 * Math.sqrt(-gamma1), efficientVar, efficientSD: Math.sqrt(efficientVar), bounceShare: -2 * gamma1 / gamma0};
}
// Steady-state Kalman gain for "random walk seen through noise": state variance q, noise variance r.
function kalmanGain(q, r) {
  if (!(q > 0) || !(r > 0)) throw new RangeError('Need positive variances');
  const p = q * (1 + Math.sqrt(4 * r / q + 1)) / 2;
  return p / (p + r);
}
function annualize(sdPerMinute, minutesPerDay, daysPerYear = 252) {
  finite(sdPerMinute, minutesPerDay, daysPerYear);
  if (!(sdPerMinute >= 0) || !(minutesPerDay > 0) || !(daysPerYear > 0)) throw new RangeError('Need sd >= 0 and positive day counts');
  return {day: sdPerMinute * Math.sqrt(minutesPerDay), year: sdPerMinute * Math.sqrt(minutesPerDay * daysPerYear)};
}
// Returns over m minutes: efficient moves add up (m sigma_e^2); the bounce telescopes to its two endpoints (S^2/2).
function aggregate(m, efficientVar, spread, minutesPerDay = 300) {
  if (!Number.isInteger(m) || m < 1) throw new RangeError('Window must be a whole number of minutes');
  const variance = m * efficientVar + spread * spread / 2;
  return {bounceShare: spread * spread / 2 / variance, naiveAnnual: Math.sqrt(variance / m * minutesPerDay * 252)};
}
// PACF by the Durbin-Levinson recursion: the last coefficient of the best k-lag linear predictor.
function pacf(rho, K) {
  if (!Array.isArray(rho) || rho[0] !== 1 || rho.length <= K || !Number.isInteger(K) || K < 1) throw new RangeError('Need rho[0] = 1 and lags up to K');
  let prev = [];
  const out = [];
  for (let k = 1; k <= K; k++) {
    let num = rho[k], den = 1;
    for (let j = 1; j < k; j++) { num -= prev[j - 1] * rho[k - j]; den -= prev[j - 1] * rho[j]; }
    const last = num / den, next = [];
    for (let j = 1; j < k; j++) next.push(prev[j - 1] - last * prev[k - j - 1]);
    next.push(last); prev = next; out.push(last);
  }
  return out;
}
// ARMA(1,1): weights psi_0 = 1, psi_j = (phi + theta) phi^(j-1); ACF decays at phi after lag 1.
function arma11(phi, theta, lags = 4) {
  finite(phi, theta);
  if (!(Math.abs(phi) < 1) || !(Math.abs(theta) < 1)) throw new RangeError('Need |phi| < 1 and |theta| < 1');
  const gamma0 = (1 + 2 * phi * theta + theta * theta) / (1 - phi * phi);
  const rho = [1, (1 + phi * theta) * (phi + theta) / (1 + 2 * phi * theta + theta * theta)];
  for (let k = 2; k <= lags; k++) rho.push(phi * rho[k - 1]);
  return {gamma0, gamma1: phi * gamma0 + theta, rho, psi: [1, 2, 3].map(j => (phi + theta) * phi ** (j - 1))};
}
// ARIMA(0,1,1) one-step forecast = exponential smoothing with weight 1 + theta on the newest price.
function smooth(prices, start, theta) {
  finite(start, theta);
  if (!Array.isArray(prices) || !prices.length || ![...prices].every(Number.isFinite)) throw new TypeError('Need finite prices');
  if (!(Math.abs(theta) < 1)) throw new RangeError('Need |theta| < 1');
  const out = [];
  let f = start;
  for (const p of prices) { f = (1 + theta) * p - theta * f; out.push(f); }
  return out;
}
function generator(seed) {
  let a = seed >>> 0, spare = null;
  const uniform = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  const normal = () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const radius = Math.sqrt(-2 * Math.log(uniform())), angle = 2 * Math.PI * uniform();
    spare = radius * Math.sin(angle);
    return radius * Math.cos(angle);
  };
  return {uniform, normal};
}
// A Roll market: efficient return e_t plus half a spread times the change in trade direction.
function simulateRoll(minutes, efficientSD, spread, seed) {
  if (!Number.isInteger(minutes) || minutes < 3) throw new RangeError('Need at least three minutes');
  finite(efficientSD, spread);
  const g = generator(seed), x = [];
  let q = g.uniform() < 0.5 ? -1 : 1;
  for (let t = 0; t < minutes; t++) {
    const next = g.uniform() < 0.5 ? -1 : 1;
    x.push(efficientSD * g.normal() + spread / 2 * (next - q));
    q = next;
  }
  const mean = x.reduce((s, v) => s + v, 0) / minutes;
  let g0 = 0, g1 = 0;
  for (let t = 0; t < minutes; t++) { g0 += (x[t] - mean) ** 2; if (t) g1 += (x[t] - mean) * (x[t - 1] - mean); }
  g0 /= minutes; g1 /= minutes;
  return {gamma0: g0, gamma1: g1, rho1: g1 / g0, estimate: roll(g0, g1)};
}
// Dollar prices of the $42 stock: how close does an EWMA with weight K stay to the true mid value?
function filterError(K, trades, stepSD, halfSpread, seed) {
  const g = generator(seed);
  let m = 42, f = 42, s = 0;
  for (let t = 0; t < trades; t++) {
    m += stepSD * g.normal();
    const p = m + (g.uniform() < 0.5 ? -1 : 1) * halfSpread;
    f = K * p + (1 - K) * f;
    s += (f - m) ** 2;
  }
  return Math.sqrt(s / trades);
}

สิ่งที่ควรตอบได้หลังอ่าน

  • MA(1) มี ACF ที่ lag 1 เท่ากับ $\theta/(1+\theta^2)$ มีขนาดไม่เกิน 1/2 และเป็นศูนย์หลังจากนั้น ส่วน PACF จางลงช้า ๆ กลับด้านกับ AR(1)
  • เมื่อ $\theta\ne0$ ค่า $\theta$ กับ $1/\theta$ ให้ ACF เดียวกัน เราเลือก $|\theta|\lt1$ เพื่อถอดข่าวย้อนหลังด้วยน้ำหนักที่จางลง
  • ภายใต้แบบจำลองของ Roll ผลต่างราคาที่มีการเด้งเป็น MA(1): $S=2\sqrt{-\gamma_1}$ และ variance ของข่าวจริงคือ $\gamma_0+2\gamma_1$ ตัวอย่างได้ spread 4.93 เซนต์ และความผันผวน 15.3% ไม่ใช่ 27.5%
  • ARMA(1,1) ให้ lag 1 ที่ถูกข่าวดึง แล้วจางด้วย $\phi$ ระวังกรณี $\phi=-\theta$ ที่ความจำหักล้างกันหมด และเลือกแบบจำลองด้วย AIC หรือ BIC
  • ARIMA(0,1,1) ให้คำทำนายเป็น EWMA ที่น้ำหนัก $1+\theta$ ซึ่งเท่ากับ Kalman gain ของแบบจำลอง Roll (0.6 ในตัวอย่าง) การหาผลต่างของ white noise โดยไม่จำเป็นสร้าง $\rho_1=-0.5$ ปลอมได้

ทั้ง AR และ MA สร้างความจำให้ค่าเฉลี่ยของพรุ่งนี้ แต่หน้า ACF พบว่าความจำที่แรงที่สุดของผลตอบแทนอยู่ในขนาดของการขยับ หน้าถัดไป ARCH และ GARCH จึงใช้ความคิดเดียวกันกับ variance: ให้ความเสี่ยงวันนี้จำข่าวกำลังสองของเมื่อวาน
