14.5 The Volatility Surface and Term Structure

implied volatility ของทุก strike และทุกอายุต่อกันเป็นผืนเดียว ต้องเชื่อมข้ามอายุบน total variance ที่บวกกันได้ตามเวลา และผืนต้องผ่านกฎสองข้อจึงไม่มีเงินฟรี

SPX อยู่ที่ 5,000 จุด ดอกเบี้ย 4% อัตราปันผล 1.5% ต่อปี option อายุ 1 เดือนซื้อขายที่ implied volatility 30% และอายุ 3 เดือนที่ 24% (ทั้งคู่ที่ strike เท่ากับ forward) ลูกค้าขอราคา call อายุ 2 เดือนซึ่งไม่มีในตลาด เทรดเดอร์ฝึกหัดเฉลี่ยตรง ๆ ได้ 27% เพราะ 2 เดือนอยู่กึ่งกลาง ถูกไหม และถ้าผิด ผิดเป็นเงินเท่าไรต่อสัญญาที่ตัวคูณ \$100 ต่อจุด?

ลองตอบก่อนเปิดเฉลย

ผิด สิ่งที่บวกกันได้ตามเวลาคือ variance คูณเวลา ไม่ใช่ความผันผวน $0.30^2(1/12)=0.0075$ กับ $0.24^2(3/12)=0.0144$ กึ่งกลางคือ 0.01095 แปลงกลับได้ 25.63% ไม่ใช่ 27% ที่ 27% call อายุ 2 เดือนราคา 219.21 จุดแทน 208.11 จุด แพงไป 11.10 จุด หรือ \$1,110 ต่อสัญญา และถ้าอายุ 3 เดือนเป็น 18% การเฉลี่ยตรง ๆ แบบเดียวกันจะให้ราคาที่เปิดช่องเงินฟรีให้คู่ค้าเลย

ภาพรวมก่อนลงสูตร

ตลาดไม่ได้ซื้อขาย option ด้วยความผันผวนตัวเดียว ทุกคู่ strike กับอายุมีราคาของตัวเอง ถ้าแปลงแต่ละราคาเป็นความผันผวนที่ใส่ในสูตร Black–Scholes แล้วได้ราคานั้นพอดี (implied volatility) จะได้ตัวเลขหนึ่งตัวต่อหนึ่งคู่ วางเรียงกันตาม strike และอายุเป็นผืนที่เรียกว่า volatility surface ถ้าแบบจำลอง Black–Scholes ถูก ผืนนี้ต้องแบนราบและไม่ขยับตามเวลา ของจริงไม่แบนและขยับทุกวัน strike ต่ำมีความผันผวนสูงกว่า (skew) และเอียงชันที่สุดที่อายุสั้น ส่วนตามแกนอายุ ความผันผวนขึ้นหรือลงก็ได้แล้วค่อย ๆ เข้าหาค่าคงที่เมื่ออายุยาวมาก วันที่ตลาดเครียด อายุสั้นแพงกว่าอายุยาวมากจนเส้นหัวกลับ

ทุกโต๊ะยังคำนวณผืนนี้และ Greeks ด้วยสูตร Black–Scholes ทั้งที่รู้ว่าแบบจำลองผิด คนในตลาดเรียกว่า “ใส่ตัวเลขผิดลงในสูตรผิดเพื่อให้ได้ราคาที่ถูก” สูตรทำหน้าที่แค่แปลงราคาเป็นหน่วยเดียวกันที่เทียบข้าม strike และอายุได้

หน้านี้สร้างสามอย่าง: วิธีเชื่อมค่าระหว่างอายุให้ถูก กฎสองข้อที่ผืนต้องผ่านจึงไม่มีเงินฟรี และขอบเขตของสิ่งที่ผืนตั้งราคาได้ รูปแรกหั่นผืนสมมติของหน้านี้เป็นชิ้นตามอายุ แต่ละชิ้นคือ smile ของอายุนั้น รูปที่สองหั่นตาม strike แต่ละเส้นคือ term structure ของ strike นั้น

ศัพท์ที่ใช้ในหัวข้อนี้
Implied volatility
ความผันผวนที่ใส่ในสูตร Black–Scholes แล้วได้ราคาตลาดพอดี นิยามโดยอ้อมผ่านสมการ ราคาตลาด = ราคาจากสูตร ใช้แปลงราคา option เป็นหน่วยที่เทียบกันได้ข้าม strike และอายุ
Volatility surface และ skew
ตาราง implied volatility เรียงตาม strike และอายุ skew (หรือ smile) คือรูปตามแกน strike ที่อายุเดียว หุ้นและดัชนีมักเอียงให้ strike ต่ำแพงกว่า ใช้อ่านราคาของสัญญาที่ไม่มีคนซื้อขาย
Term structure
implied volatility ที่ strike เดียวเทียบอายุ ตลาดปกติมักเพิ่มตามอายุ วันตลาดเครียดอายุสั้นแพงกว่าจนเส้นหัวกลับ ใช้อ่านว่าตลาดคาดความผันผวนช่วงไหนสูง
Total variance และ forward variance
total variance $w=\sigma_{\rm imp}^2T$ คือ variance ของ log ราคาตลอดอายุ บวกกันได้ตามเวลา จึงเป็นแกนที่ใช้เชื่อมข้ามอายุ forward variance คือความชันของ $w$ ตามอายุ หรือ variance ต่อปีของช่วงระหว่างสองอายุ ติดลบไม่ได้
Calendar และ butterfly arbitrage
calendar คือ option อายุยาวถูกกว่าอายุสั้นที่ moneyness เดียวกัน butterfly คือสาม strike เรียงกันแล้วพอร์ต butterfly มีต้นทุนติดลบ ทั้งสองเป็นเงินฟรีที่ล็อกได้โดยซื้อแล้วถือไว้เฉย ๆ (static arbitrage)
Exotic option
สัญญาที่จ่ายตามเส้นทางของราคาหรือเงื่อนไขพิเศษ เช่น knock-in put ที่มีผลเฉพาะเมื่อราคาแตะระดับที่ตกลงไว้ก่อน ผืนความผันผวนตั้งราคาสัญญาแบบนี้ได้ไม่ครบ ต้องมีแบบจำลองของเส้นทางเพิ่ม

ขั้นที่ 1 — implied volatility คือคำตอบเดียวของสมการราคา

ผืนประกอบจากจุด ก่อนต่อผืนต้องรู้ว่าแต่ละจุดได้มาอย่างไร และทำไมมีคำตอบเดียว นิยามคือ $C_{\rm mkt}(K,T)=C_{\rm BS}\big(K,T,\sigma_{\rm imp}(K,T)\big)$ แก้หา $\sigma_{\rm imp}$ ทีละจุด

โจทย์ให้อะไรมาบ้าง: call บน SPX strike 5,000 อายุ 3 เดือน ($T=0.25$) ราคาตลาด 250 จุด $S_0=5{,}000$, $r=4\%$, $q=1.5\%$ หาความผันผวนที่สูตรให้ 250 พอดี ด้วยการแบ่งครึ่งช่วง (ถ้าสูตรให้แพงไป ลดความผันผวน ถ้าถูกไป เพิ่ม)

\[ \begin{aligned} \sigma\to0:\ C_{\rm BS}&\to\big(S_0e^{-qT}-Ke^{-rT}\big)^+=31.04,\\ \sigma\to\infty:\ C_{\rm BS}&\to S_0e^{-qT}=4{,}981.29,\\ C_{\rm BS}(25\%)&=263.30\gt250,\\ C_{\rm BS}(22.5\%)&=238.61\lt250,\\ C_{\rm BS}(23.75\%)&=250.96\gt250,\\ C_{\rm BS}(23.125\%)&=244.78\lt250,\\ \sigma_{\rm imp}&=23.653\%. \end{aligned} \]

คำตอบ: implied volatility คือ 23.65% ราคาจากสูตรเพิ่มขึ้นตามความผันผวนเสมอ เพราะ vega เป็นบวก (Greeks) จาก 31.04 จุดเมื่อความผันผวนเป็นศูนย์ ไปจนถึงราคาหุ้นที่หักปันผล 4,981.29 จุดเมื่อความผันผวนโตไม่จำกัด เส้นที่ขึ้นตลอดตัดเส้นราคาตลาดได้ครั้งเดียว ราคาตลาดใดที่อยู่ระหว่างสองขอบนี้จึงมี implied volatility หนึ่งค่าพอดี ถ้าราคาหลุดขอบ แปลว่าราคานั้นเปิดช่องเงินฟรีอยู่แล้ว

ตรวจเองใน 10 วินาที: vega ที่ 25% คือ 987.35 จุดต่อความผันผวน 1.00 ก้าวแบบ Newton หนึ่งก้าว $0.25-(263.30-250)/987.35=0.23653$ ตกที่คำตอบเลย เพราะราคา ATM แทบเป็นเส้นตรงในความผันผวน

ขั้นที่ 2 — ลองด้วยมือ: variance บวกกันได้ ความผันผวนบวกไม่ได้

โจทย์ให้อะไรมาบ้าง: สมมติเดือนแรกดัชนีแกว่งด้วยความผันผวน 30% ต่อปี และสองเดือนถัดไปแกว่งด้วยค่าคงที่ $\sigma_f$ ที่ยังไม่รู้ ตลาดบอกว่าทั้ง 3 เดือนมีความผันผวน 24% ต่อปี หา $\sigma_f$ ให้ $\operatorname{Var}_{a\to b}$ คือ variance ของ log ราคาจากสิ้นเดือนที่ $a$ ถึงสิ้นเดือนที่ $b$ ก้อนสุ่มของช่วงที่ไม่ทับกันอิสระกัน (สามสมบัติของ Brownian motion) variance ของผลรวมจึงเท่ากับผลรวมของ variance

\[ \begin{aligned} \operatorname{Var}_{0\to3}&=\operatorname{Var}_{0\to1}+\operatorname{Var}_{1\to3},\\ 0.24^2\Big(\frac{3}{12}\Big)&=0.30^2\Big(\frac{1}{12}\Big)+\sigma_f^2\Big(\frac{2}{12}\Big),\\ 0.0144&=0.0075+\sigma_f^2(0.166667),\\ \sigma_f^2&=\frac{0.0069}{0.166667}=0.0414,\\ \sigma_f&=20.35\%. \end{aligned} \]

คำตอบ: สองเดือนหลังต้องแกว่งแค่ 20.35% ต่อปี ถ้าลองเฉลี่ยความผันผวนถ่วงเวลา $\tfrac13(30\%)+\tfrac23(20.35\%)\approx23.56\%$ ไม่ใช่ 24% การเฉลี่ยความผันผวนจึงใช้ไม่ได้ สิ่งที่รวมกันได้ตรง ๆ คือ variance คูณเวลา

ตรวจเองใน 10 วินาที: $0.0075+0.0414(2/12)=0.0075+0.0069=0.0144=0.24^2/4$ และ 20.35% ต่ำกว่า 24% มาก เพราะเดือนแรกที่แกว่ง 30% กิน variance ไปเกินครึ่ง (0.0075 จาก 0.0144)

ขั้นที่ 3 — แกนที่ถูกต้อง: forward, log-moneyness และ total variance

ตัวอย่างมือบอกว่าการเชื่อมข้ามอายุต้องทำบนปริมาณที่บวกกันได้ ขั้นนี้ตั้งแกนของผืนให้ตรงกับเรื่องนี้ ส่วนแกน strike วัดเทียบกับ forward ของอายุนั้น เพราะดอกเบี้ยและปันผลเลื่อนจุดกลางของแต่ละอายุไปคนละที่ สามบรรทัดแรกเป็นนิยาม บรรทัดที่เหลือคือตัวอย่างมือในรูปทั่วไป

\[ \begin{aligned} F(T)&:=S_0e^{(r-q)T},\\ k&:=\ln\frac{K}{F(T)},\\ w(k,T)&:=\sigma_{\rm imp}(k,T)^2\,T,\\ w(T_2)&=w(T_1)+v_{12}\,(T_2-T_1),\\ v_{12}&=\frac{w(T_2)-w(T_1)}{T_2-T_1}\ge0. \end{aligned} \]

variance ทั้งหมดถึง $T_2$ เท่ากับ variance ถึง $T_1$ บวกส่วนของช่วงถัดไป ส่วนนั้นเขียนเป็นอัตราต่อปี $v_{12}$ คูณความยาวช่วง $v_{12}$ เรียกว่า forward variance มันเป็น variance จึงติดลบไม่ได้ ผลคือ total variance ต้องไม่ลดลงเมื่ออายุยาวขึ้น แม้ความผันผวนต่อปีจะลดลงได้ ถ้าความผันผวนลดช้าพอ $w=\sigma^2T$ ยังโตเพราะ $T$ โต

ทำไมเทียบ strike กับ forward ไม่ใช่กับราคาวันนี้: strike 5,000 วันนี้เท่ากับราคาปัจจุบัน แต่ที่อายุ 1 ปี forward คือ $5{,}000e^{0.025}=5{,}126.6$ strike เดียวกันจึงอยู่ที่ $k=-0.025$ ไม่ใช่ศูนย์ การวางทุกอายุบน $k$ ทำให้ $k=0$ ของทุกอายุหมายถึง strike เท่ากับ forward เหมือนกัน

ขั้นที่ 4 — เชื่อมอายุ 2 เดือนบน total variance

โจทย์ให้อะไรมาบ้าง: $w_1=0.0075$ ที่ 1 เดือน และ $w_3=0.0144$ ที่ 3 เดือน จากตัวอย่างมือ เชื่อมเส้นตรงบน $w$ ตามเวลาแล้วแปลงกลับเป็นความผันผวน จากนั้นคิดราคา call SPX อายุ 2 เดือนที่ strike เท่ากับ forward ด้วยคำตอบที่ถูกและด้วย 27%

\[ \begin{aligned} w\Big(\frac{2}{12}\Big)&=0.0075+\frac{1/12}{2/12}(0.0069)\\ &=0.0075+0.00345=0.01095,\\ \sigma_{\rm imp}&=\sqrt{0.01095\times6}=25.632\%,\\ 27\%&:\ w=0.27^2/6=0.01215,\\ F&=5{,}000e^{0.025/6}=5{,}020.88,\\ C(25.632\%)&=208.11,\\ C(27\%)&=219.21. \end{aligned} \]

คำตอบ: ควรเสนอ 25.63% ไม่ใช่ 27% ที่ 27% ราคาแพงไป 11.10 จุด หรือ \$1,110 ต่อสัญญา ใกล้กับ vega 811 จุดต่อความผันผวน 1.00 คูณส่วนต่าง 0.0137 ลูกค้าที่รู้เรื่องจะไม่ซื้อ และถ้าโต๊ะซื้อที่ 27% ก็จ่ายแพงไปเท่านั้น

ตรวจเองใน 10 วินาที: $0.01095\times6=0.0657$ รากคือ 0.2563 และ 25.63% อยู่ใกล้ 24% มากกว่า 30% เพราะอายุ 3 เดือนมี variance เกือบสองเท่าของอายุ 1 เดือน น้ำหนักจึงเอียงไปทางนั้น

ขั้นที่ 5 — เชื่อมบนความผันผวนตรง ๆ แล้วเกิดเงินฟรี

โจทย์ให้อะไรมาบ้าง: เปลี่ยนอายุ 3 เดือนเป็น 18% ส่วน 1 เดือนยังเป็น 30% เทรดเดอร์เฉลี่ยตรง ๆ ได้ 24% ที่ 2 เดือน ตรวจด้วย forward variance และด้วยราคา call ที่ strike เท่ากับ forward หารด้วย $DF$ ซึ่งเมื่อตั้ง $K=F$ ในสูตร Black–Scholes จะได้ $d_{1,2}=\pm\sqrt w/2$ และ $c=2\Phi(\sqrt w/2)-1$

\[ \begin{aligned} w(3/12)&=0.18^2(0.25)=0.0081,\\ w(2/12)&=0.24^2(2/12)=0.0096,\\ v_{23}&=\frac{0.0081-0.0096}{1/12}=-0.018\lt0,\\ c(2/12)&=2\Phi(0.04899)-1=0.03907,\\ c(3/12)&=2\Phi(0.04500)-1=0.03589,\\ w(2/12)&=0.0075+0.5(0.0006)=0.0078\\ &\Rightarrow\ \sigma_{\rm imp}=21.63\%. \end{aligned} \]

คำตอบ: 24% ที่ 2 เดือนทำให้ total variance ลดจาก 0.0096 เหลือ 0.0081 ในเดือนสุดท้าย forward variance −0.018 ต่อปีซึ่งเป็นไปไม่ได้ ในหน่วยราคา call อายุ 2 เดือน (0.03907 ต่อหน่วย forward) แพงกว่า call อายุ 3 เดือน (0.03589) ทั้งที่ตัวอายุยาวให้สิทธิ์ครอบคลุมกว่า ขายตัวสั้นซื้อตัวยาวจึงได้เงินสดวันนี้และไม่มีทางขาดทุน การเชื่อมบน $w$ ให้ 21.63% และ forward variance 0.0036 ต่อปีทั้งสองช่วง ปลอดภัย

ตรวจเองใน 10 วินาที: ตัวเลข 24% ฟังดูสมเหตุสมผล ไม่มีอะไรเตือนเลย ระบบจึงต้องตรวจ $w$ ที่ทุก $k$ ทุกอายุโดยอัตโนมัติ ไม่ใช่ดูด้วยตา

ขั้นที่ 6 — กฎตามแกนเวลา: ราคาที่หารหน่วยแล้วต้องไม่ลดตามอายุ

ตัวอย่างที่แล้วเห็นเงินฟรีจากตัวเลข ขั้นนี้พิสูจน์ว่ากฎทั่วไปคืออะไร หาร call ด้วยมูลค่าวันนี้ของ forward ($DF$) แล้วเทียบที่ $x=K/F$ เดียวกัน เมื่อดอกเบี้ยและปันผลรู้ค่า $M_T=S_T/F(T)$ มีค่าเฉลี่ยภายใต้ risk-neutral measure เท่ากับ 1 ทุกอายุ และเป็น martingale: ค่าเฉลี่ยของอนาคตเมื่อรู้ข้อมูลถึงวันนี้คือค่าวันนี้ (ตามที่ Girsanov และ risk-neutral measure สร้างไว้)

\[ \begin{aligned} c(x,T)&:=\frac{C(K,T)}{D(T)F(T)}\\ &=\mathbb E^{\mathbb Q}\big[(M_T-x)^+\big],\\ &\mathbb E^{\mathbb Q}\big[(M_{T_2}-x)^+\big]\\ &\ge\mathbb E^{\mathbb Q}\big[(\mathbb E[M_{T_2}\mid T_1]-x)^+\big]\\ &=\mathbb E^{\mathbb Q}\big[(M_{T_1}-x)^+\big],\\ c(x,T)&=\Phi\Big(\frac{-\ln x+w/2}{\sqrt w}\Big)\\ &\quad-x\,\Phi\Big(\frac{-\ln x-w/2}{\sqrt w}\Big),\\ \frac{\partial w(k,T)}{\partial T}&\ge0. \end{aligned} \]

บรรทัดที่สี่ใช้ว่า $(m-x)^+$ เป็นฟังก์ชันโค้งหงาย ค่าเฉลี่ยของฟังก์ชันโค้งหงายไม่น้อยกว่าฟังก์ชันของค่าเฉลี่ย (Jensen) ใช้กับค่าเฉลี่ยแบบมีเงื่อนไข ณ $T_1$ จากนั้นบรรทัดที่ห้าใช้ martingale: ค่าเฉลี่ยของ $M_{T_2}$ เมื่อรู้ข้อมูลถึง $T_1$ คือ $M_{T_1}$ ความหมายคือ option อายุยาวมีทุกอย่างที่อายุสั้นมี บวกเวลาแกว่งเพิ่ม (โดยที่ $T_2\gt T_1$)

บรรทัดที่หกและเจ็ดคือสูตร Black–Scholes ที่หารหน่วยแล้ว เวลาเข้าสูตรผ่าน $w$ ตัวเดียว และ $c$ เพิ่มตาม $w$ (vega บวก) กฎจึงกลายเป็นบรรทัดสุดท้าย: ที่ log-moneyness เดียวกัน total variance ต้องไม่ลดตามอายุ ไม่ใช่แค่ที่ strike เท่ากับ forward แต่ทุก $k$

ขั้นที่ 7 — กฎตามแกน strike: ความชันจำกัด และต้องโค้งหงาย

ที่อายุเดียว ราคา call เป็นฟังก์ชันของ strike หาอนุพันธ์ของ payoff ทีละครั้ง: $(S_T-K)^+$ ลดลง 1 ต่อ strike ที่เพิ่ม 1 เมื่อ $S_T\gt K$ และคงที่เมื่อ $S_T\lt K$ แล้วเอาค่าเฉลี่ยที่คิดลด สองบรรทัดแรกจึงได้ อนุพันธ์ครั้งที่สองทำให้ขั้นบันไดนั้นกลายเป็น density ตลาดจริงมี strike ห่างกันเป็นช่วง $h$ อนุพันธ์ครั้งที่สองจึงกลายเป็นพอร์ต butterfly: ซื้อ call ปีกสองข้าง ขาย call กลางสองใบ

\[ \begin{aligned} C_K&=-e^{-rT}\,\mathbb Q(S_T\gt K),\\ C_{KK}&=e^{-rT}f^{\mathbb Q}(K)\ge0,\\ -e^{-rT}&\le C_K\le0,\\ B_0&:=C(K-h)-2C(K)+C(K+h)\ge0,\\ \Pi_T(K)&=h,\ \ \Pi_T(K\pm h)=0,\\ \int_{K-h}^{K+h}\Pi_T(s)\,ds&=\tfrac12(2h)(h)=h^2,\\ B_0&\approx e^{-rT}f^{\mathbb Q}(K)\,h^2. \end{aligned} \]

บรรทัดที่สามมาจากว่าโอกาสอยู่ระหว่าง 0 ถึง 1: ราคา call ต้องลดลงตาม strike แต่ลดเร็วไม่เกิน $e^{-rT}$ ต่อ strike 1 จุด ถ้าลดเร็วกว่านั้น call spread (ซื้อ $K$ ขาย $K+h$) จะแพงกว่าเงินสูงสุดที่มันจ่ายได้คือ $h$ คิดลด กฎข้อนี้คือ “skew ห้ามชันเกินไป” ในภาษาราคา

บรรทัดที่สี่ถึงหกคือ payoff ของ butterfly ในวันหมดอายุ: กระโจมสามเหลี่ยมยอดสูง $h$ ที่ $K$ และเป็นศูนย์นอกช่วง $K\pm h$ payoff ไม่ติดลบเลย ราคาวันนี้จึงติดลบไม่ได้ บรรทัดสุดท้ายได้เมื่อ $h$ เล็กจน density แทบคงที่บนฐานกระโจม ราคา butterfly คูณ $e^{rT}$ หารด้วย $h^2$ จึงคือ density ของราคาปลายทาง ผลนี้เรียกว่า Breeden–Litzenberger

ขั้นที่ 8 — ตรวจด้วยตัวเลข: butterfly ราคาติดลบ และ skew ที่ชันเกิน

โจทย์ให้อะไรมาบ้าง: (ก) call SPX อายุเดียวกันสาม strike ราคากลาง: 4,900 → 112 จุด, 5,000 → 80 จุด, 5,100 → 47 จุด ($h=100$) เส้นดูเกือบตรง (ข) หุ้น \$100 อายุ 1 ปี ดอกเบี้ยศูนย์ ความผันผวน ATM 25% skew ชันได้แค่ไหน ใช้กฎความชันที่เพิ่งได้: digital call ที่จ่าย \$1 เมื่อ $S_T\gt K$ ราคา $-\partial C_{\rm mkt}/\partial K$ ต้องอยู่ระหว่าง 0 ถึง $e^{-rT}=1$ และเพราะ $C_{\rm mkt}=C_{\rm BS}(K,\sigma(K))$ กฎลูกโซ่ให้สองก้อน

\[ \begin{aligned} B_0&=112-2(80)+47=-1,\\ \tfrac12(112+47)&=79.5\lt80,\\ \text{dig}&=-\frac{\partial C_{\rm BS}}{\partial K}-\nu\,\frac{\partial\sigma}{\partial K},\\ -\frac{\partial C_{\rm BS}}{\partial K}&=\Phi(d_2)=\Phi(-0.125)=0.4503,\\ \nu&=100\,\phi(0.125)=39.584,\\ 0.4503-39.584\,\frac{\partial\sigma}{\partial K}&\le1\\ \Rightarrow\ \frac{\partial\sigma}{\partial K}&\ge-0.01389. \end{aligned} \]

คำตอบ: (ก) butterfly มีต้นทุน −1 จุด คือได้เงิน 1 จุดวันนี้ และถือสิทธิ์ที่จ่ายได้ถึง 100 จุดถ้าดัชนีจบที่ 5,000 โดยไม่มีทางติดลบ นี่คือ static arbitrage ก่อนหักต้นทุน ราคากลาง 80 ต้องไม่เกิน 79.5 ซึ่งเป็นค่าเฉลี่ยของปีกทั้งสอง (ข) skew ลาดลงได้ไม่เกิน 0.01389 ต่อ strike \$1 หรือ 13.9 จุดความผันผวนต่อ strike ที่ขยับ 10% ของราคา ชันกว่านั้นเมื่อไร digital ราคาเกิน \$1 ทั้งที่จ่ายได้ไม่เกิน \$1 และ put spread หรือ call spread ข้าง ๆ ATM ก็ผิดขอบเดียวกัน

ตรวจเองใน 10 วินาที: (ก) ต่ำกว่า 4,900 ทั้งสามใบไม่จ่าย สูงกว่า 5,100 ได้ศูนย์ทุกจุด ระหว่างนั้นเป็นบวก จึงไม่มีทางติดลบจริง (ข) อีกขอบหนึ่งคือ digital ต้องไม่ติดลบ: $0.4503/39.584=0.01137$ skew จึงลาดขึ้นได้ไม่เกิน 11.4 จุดต่อ strike 10%

ขั้นที่ 9 — ตรวจผืนทั้งผืน แล้วอ่าน distribution ที่ซ่อนอยู่

โจทย์ให้อะไรมาบ้าง: ผืนสมมติสำหรับฝึก (ไม่ใช่ข้อมูลตลาด) ที่วาดในสองรูปแรก $\sigma_{\rm imp}(k,T)=0.20+0.06e^{-2T}-0.06\,k/\sqrt T+0.02\,k^2/T$ ที่ $-0.28\le k\le0.24$ และอายุ 1 เดือนถึง 1.5 ปี ระดับ ATM ลดตามอายุ ส่วน $-0.06k/\sqrt T$ คือ skew ที่ชันขึ้นเมื่ออายุสั้น และ $0.02k^2/T$ คือความโค้ง ตรวจกฎแกนเวลาบนกริด $k$ ห่าง 0.01 กับอายุห่าง 0.001 ปี ตรวจกฎแกน strike ด้วยราคาที่หารหน่วยแล้วบนกริด strike ห่าง 0.25% ของ forward แล้วอ่าน density ของ $M=S_T/F$ ที่อายุ 3 เดือนจากความโค้งของราคา

\[ \begin{aligned} \sigma_{\rm imp}(0,\tfrac1{12})&=25.08\%,\ \ w=0.00524,\\ \sigma_{\rm imp}(0,0.25)&=23.64\%,\ \ w=0.01397,\\ \sigma_{\rm imp}(0,1)&=20.81\%,\ \ w=0.04331,\\ \min\ \Delta w&=3.4\times10^{-5}\gt0,\\ \min\ B_0&=1.7\times10^{-8}\gt0,\\ \mathbb Q(M\lt0.85)&=10.17\%\ \ (\text{flat}:\ 9.41\%),\\ \mathbb Q(M\gt1.15)&=10.17\%\ \ (\text{flat}:\ 10.72\%). \end{aligned} \]

คำตอบ: ผืนนี้ผ่านทั้งสองกฎในช่วงที่วาด total variance เพิ่มตามอายุทุก $k$ ทั้งที่ความผันผวน ATM ลดจาก 25.08% เหลือ 20.81% และ butterfly ทุกตัวบนกริดเป็นบวก (ตัวที่เฉียดที่สุดอยู่ปีกขวาของอายุ 1 เดือน) ผืนนี้จึงบอก distribution ภายใต้ risk-neutral measure ของราคาปลายทางได้ทีละอายุ: เทียบกับ lognormal ที่ใช้ความผันผวน ATM ตัวเดียว (23.64%) ผืนที่มี skew ให้โอกาสร่วงต่ำกว่า 85% ของ forward มากกว่า (10.17% กับ 9.41%) และให้โอกาสพุ่งเกิน 115% น้อยกว่า (10.17% กับ 10.72%) หางซ้ายหนา หางขวาบาง

ตรวจเองใน 10 วินาที: density ที่อ่านได้รวมพื้นที่ได้ 1.0000 บนช่วง 0.4 ถึง 1.8 ของ forward และ $w$ ที่ $k=0$ คือ $0.2508^2/12=0.00524$, $0.2364^2/4=0.01397$ และ $0.2081^2=0.04331$ เพิ่มขึ้นทั้งที่ความผันผวนลดลง แบบเดียวกับตัวอย่าง 2 เดือนข้างบน

ขั้นที่ 10 — ทำไม skew ของหุ้นเอียงซ้าย: leverage effect และความกลัว

ทั้งสองรูปแรกและตลาดจริงให้ strike ต่ำมีความผันผวนสูง ก่อนตลาดหุ้นสหรัฐฯ ร่วงในเดือนตุลาคม 1987 แทบไม่มี skew เลย คำอธิบายมีสองกลุ่ม กลุ่มแรกมาจากงบดุล: มูลค่าบริษัท $V$ คือหนี้ $D_{\rm debt}$ บวกหุ้น $E$ มูลค่าบริษัทเหมาะจะเดินแบบ GBM มากกว่าหุ้น ถ้ามันแกว่งด้วยความผันผวนคงที่ $\sigma_V$ และหนี้แทบไม่ขยับ การแกว่งทั้งหมดตกอยู่กับหุ้น

\[ \begin{aligned} V&=D_{\rm debt}+E,\quad \Delta D_{\rm debt}\approx0,\\ \Delta E&\approx\Delta V=V\,\frac{\Delta V}{V},\\ \frac{\Delta E}{E}&\approx\frac{V}{E}\,\frac{\Delta V}{V},\\ \sigma_E&\approx\frac{V}{E}\,\sigma_V=\Big(1+\frac{D_{\rm debt}}{E}\Big)\sigma_V,\\ V=100,\ E=50&:\ \ \sigma_E=2(20\%)=40\%,\\ V=90,\ E=40&:\ \ \sigma_E=2.25(20\%)=45\%. \end{aligned} \]

บรรทัดที่สามหารบรรทัดที่สองด้วย $E$ แล้ววัดขนาดการแกว่ง บริษัทมูลค่า 100 หนี้ 50 ที่แกว่ง 20% ทำให้หุ้นแกว่ง 40% ถ้ามูลค่าบริษัทลด 10% เหลือ 90 หุ้นลดจาก 50 เหลือ 40 (ลง 20%) และแกว่ง 45% หุ้นยิ่งลงยิ่งแกว่งแรง put ที่ strike ต่ำจ่ายเงินในโลกที่หุ้นลงไปแล้ว จึงควรมีความผันผวนสูงกว่า มุมมองนี้มาจาก Merton ที่มองหุ้นเป็น call บนมูลค่าบริษัท strike เท่ากับหนี้ เพราะเจ้าหนี้ได้เงินก่อนผู้ถือหุ้น

กลุ่มที่สองคือความไม่ชอบความเสี่ยง: ราคากระโดดลงแรงและบ่อยกว่ากระโดดขึ้น ตลาดลงแล้วคนกลัว ความผันผวนจึงพุ่ง และนักลงทุนซื้อ put นอกเงินป้องกันพอร์ตตลอดเวลา อุปสงค์ของ strike ต่ำจึงสูง แบบจำลอง Heston จะสร้าง skew ขึ้นเองจาก correlation ติดลบระหว่างราคากับความผันผวน

ขั้นที่ 11 — สิ่งที่ผืนตั้งราคาได้: digital และ range accrual

ผืนให้ distribution ของราคาปลายทางทีละอายุ สัญญาใดที่จ่ายตามราคา ณ วันเดียวจึงตั้งราคาได้จากผืนล้วน ๆ: ราคาคือ $\mathbb E^{\mathbb Q}[e^{-rT}g(S_T)]$

โจทย์ให้อะไรมาบ้าง: (ก) digital call จ่าย \$1 ถ้าหุ้น \$100 จบเหนือ \$100 ในหนึ่งปี ดอกเบี้ยศูนย์ ความผันผวน ATM 25% และ skew ลดลง 2.5 จุดต่อ strike ที่สูงขึ้น 10% ของราคา คือ $\partial\sigma/\partial K=-0.025/10=-0.0025$ ต่อ \$1 ใช้สูตรกฎลูกโซ่จากขั้นตรวจ skew (ข) สัญญา 3 เดือน notional \$10 ล้าน บนดัชนีที่อยู่ 1,525 จุด จ่ายตามสัดส่วนของวันทำการที่ดัชนีปิดในช่วง 1,500 ถึง 1,550 ($0.25\times252=63$ วันทำการ) ลองด้วยความผันผวนคงที่ 20% ดอกเบี้ยศูนย์

\[ \begin{aligned} \text{dig}&=\Phi(d_2)-\nu\,\frac{\partial\sigma}{\partial K}\\ &=0.4503+39.584(0.0025)=0.5492,\\ \text{range}&=\frac{10^7}{63}\sum_{i=1}^{63}p_i,\\ p_i&=\mathbb Q\big(1{,}500\le S_{t_i}\le1{,}550\big),\\ p_1&=0.807,\ \ p_{63}=0.130,\\ \tfrac1{63}\textstyle\sum p_i&=0.2289,\\ \text{range}&=\$2{,}288{,}678. \end{aligned} \]

คำตอบ: (ก) ถ้าไม่นับ skew digital ราคา 45 เซนต์ต่อ \$1 นับ skew แล้ว 55 เซนต์ ต่างกัน 10% ของ notional เพราะ skew บอกว่า call ที่ strike สูงถูกลงเร็วกว่าที่ความผันผวนคงที่บอก ราคาจึงลาดชันกว่าตาม strike (ข) เงื่อนไขของแต่ละวันคือ digital ที่ 1,500 ลบ digital ที่ 1,550 ของวันนั้น สัญญาทั้งก้อนจึงคือ digital 63 คู่ ที่ความผันผวนคงที่ราคา \$2.29 ล้าน ของจริงต้องอ่าน digital ของแต่ละวันจากผืนพร้อม skew ของอายุนั้น

ตรวจเองใน 10 วินาที: วันแรกดัชนีอยู่กลางช่วงกว้าง 50 จุด และแกว่งวันละราว $20\%/\sqrt{252}\approx1.26\%$ หรือ 19 จุด จึงอยู่ในช่วงราว 81% แต่หลัง 63 วัน SD เป็น $20\%\sqrt{0.25}=10\%$ หรือ 152 จุด ช่วง 50 จุดจับได้แค่ราว 13%

ขั้นที่ 12 — สิ่งที่ผืนตั้งราคาไม่ได้: knock-in put ของสองหุ้นที่ผืนเหมือนกัน

โจทย์ให้อะไรมาบ้าง: หุ้นสองตัวราคาเริ่มที่ 1 ความผันผวน 30% ดอกเบี้ยศูนย์ ราคาที่เวลา $T$ คือ $e^{-\sigma^2T/2+\sigma\sqrt T\,Z}$ ราคาครึ่งปีใช้ก้อนสุ่ม $Z_a$ ราคาหนึ่งปีใช้ $Z_b=\rho Z_a+\sqrt{1-\rho^2}\,Z_c$ โดย $Z_a$ กับ $Z_c$ เป็น standard Normal อิสระ หุ้นสองตัวต่างกันแค่ $\rho$: ค่าบวกคือ momentum (วิ่งต่อ) ค่าลบคือ mean reversion (กลับตัว) สัญญาจ่าย put strike 1 ที่หนึ่งปี เฉพาะเมื่อราคาครึ่งปีถึง 1.2 คำนวณด้วย integral ตาม $Z_a$ ส่วนค่าเฉลี่ยตาม $Z_c$ ใช้สูตร put ของ Black–Scholes

\[ \begin{aligned} \operatorname{Var}(Z_b)&=\rho^2+(1-\rho^2)=1,\\ \text{put}_{\rm Eur}&=0.1192\ \ \text{every }\rho,\\ S_{0.5}\ge1.2\ &\Rightarrow\ Z_a\ge\frac{\ln1.2+0.0225}{0.30\sqrt{0.5}}=0.9655,\\ \rho=-0.5&:\ 0.0390,\\ \rho=0&:\ 0.0199,\\ \rho=0.5&:\ 0.0059,\\ \rho=\sqrt{0.5}&:\ 0.0020. \end{aligned} \]

คำตอบ: บรรทัดแรกบอกว่าราคาของแต่ละวันหมดอายุมี distribution เดียวกันทุก $\rho$ call และ put ธรรมดาทุก strike ทุกวันหมดอายุจึงราคาเท่ากัน ผืนความผันผวนของสองหุ้นเหมือนกันเป๊ะ แต่ knock-in put ต้องการให้ราคาขึ้นไปถึง 1.2 ที่ครึ่งปีแล้วกลับลงต่ำกว่า 1 หุ้นที่ชอบกลับตัว ($\rho=-0.5$) ทำแบบนั้นง่าย ราคา 0.0390 หุ้นที่วิ่งต่อ ($\rho=0.5$) ราคา 0.0059 ต่างกัน 6.6 เท่า

ตรวจเองใน 10 วินาที: ถ้าหุ้นเดินแบบ GBM จริง ก้อนสุ่มครึ่งปีกับทั้งปีมี correlation $\sqrt{0.5/1}=0.707$ เพราะ covariance ของ Brownian motion คือเวลาที่ทับกัน ได้ราคา 0.0020 ผืนเห็นแค่ distribution ทีละวันหมดอายุ ไม่เห็นว่าสองวันผูกกันอย่างไร

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

เชื่อมบนความผันผวน: ตัวอย่าง 2 เดือนแพงไป \$1,110 ต่อสัญญา และตัวอย่าง 18% สร้างเงินฟรีให้คู่ค้า ทั้งสองกรณีตัวเลขดูสมเหตุสมผล เชื่อมบน $w$ ที่ $k$ เดียวกันเสมอ

อ่าน smile ด้วย strike ดิบ: บนผืนสมมติที่อายุ 1 ปี strike 5,000 อยู่ที่ $k=-0.025$ ความผันผวนที่นั่นสูงกว่าที่ forward 0.15 จุด ถ้าอ่านเป็นค่าที่ forward จะใส่ความผันผวนผิด 0.15 จุด คูณ vega ของ call SPX 1 ปีที่ strike นี้ 1,916 จุดต่อ 1.00 ได้ราคาผิด 2.90 จุดดัชนี หรือ \$290 ต่อสัญญา

เส้นเรียบจึงคิดว่าปลอดภัย: spline ผ่านทุกจุดได้สวยแต่ซ่อน density ติดลบหรือ forward variance ติดลบได้ (รูปเส้นเรียบที่ซ่อน forward variance ติดลบ และรูปราคาที่เรียงเกือบตรง) ต้องตรวจกฎในรูปราคาทุกจุดบนกริดละเอียด ทั้งหลังการเชื่อมและหลังการต่อปีก

stress ผืนทีละส่วน: รายงานความเสี่ยงชอบขยับผืนเป็น scenario เช่น “อายุ 3 เดือนลง 8 จุด” จากโจทย์เปิดเรื่องที่อายุ 1 เดือน 30% อายุ 3 เดือนจะเหลือ 16% ได้ $w=0.0064$ ต่ำกว่า 0.0075 ของอายุ 1 เดือน forward variance −0.0066 ต่อปี scenario นั้นเป็นโลกที่มีเงินฟรี P&L ที่คำนวณได้จึงไม่มีความหมาย ต้องตรวจกฎกับผืนที่ stress แล้วด้วย

ใช้ผืนตั้งราคาสัญญาที่ขึ้นกับเส้นทาง: ผืนเดียวกันให้ราคา knock-in ได้ตั้งแต่ 0.0001 ถึง 0.059 ขึ้นกับแบบจำลองของเส้นทาง ราคาจากผืนอย่างเดียวจึงไม่มีความหมาย

ใช้ทำอะไรบนโต๊ะจริง

ทุกวันโต๊ะดึง quote ทุก strike ทุกอายุ ตัดราคาค้าง หา forward และ discount จาก put–call parity แก้ implied volatility ทีละจุด แปลงเป็น $(k,w)$ แล้ว fit ผืนโดยบังคับกฎแกนเวลาและแกน strike จากนั้นคำนวณราคากลับเทียบกับ bid–ask ทุกจุด ผืนนี้ใช้เสนอราคาอายุที่ไม่มีในตลาด ตั้งราคา digital และ range accrual และแบ่ง vega ตามอายุในรายงานความเสี่ยง

ราคา option ที่ซื้อขายคล่องมาจากอุปสงค์อุปทาน ไม่ได้มาจากแบบจำลอง แบบจำลองยังจำเป็นสองงาน: ตั้งราคาสัญญาที่ไม่มีในตลาด เช่น knock-in โดยปรับให้ตรงกับราคาของตัวที่ซื้อขายคล่อง และคำนวณ Greeks กับ scenario เพื่อ hedge แบบจำลองทุกตัวเป็นแค่การประมาณ ต้องปรับค่าใหม่บ่อย ซึ่งตัวมันเองบอกว่าประมาณได้ไม่ดีนัก

ดัชนี VIX ของ Cboe ใช้การเชื่อมแบบอายุ 2 เดือนข้างบน: วัดความผันผวน 30 วันของ S&P 500 โดยเชื่อม variance ของสองอายุที่คร่อม 30 วันบนแกน total variance แล้วแปลงกลับเป็นต่อปี หน้าของ variance swap และ log contract จะแสดงว่า variance ของแต่ละอายุคำนวณจากราคา option ทุก strike อย่างไร

โจทย์ตรวจความเข้าใจ

1. implied volatility อายุ 1 เดือน 22% และ 6 เดือน 20% หาค่าอายุ 3 เดือนด้วยการเชื่อมบน total variance เทียบกับการเชื่อมตรง ๆ บนความผันผวน และหา forward volatility ระหว่าง 1 ถึง 6 เดือน

เฉลย

$w_1=0.22^2/12=0.0040333$ และ $w_6=0.20^2(0.5)=0.02$ น้ำหนักที่ 3 เดือนคือ $(3-1)/(6-1)=0.4$ จึง $w=0.0040333+0.4(0.0159667)=0.0104200$ และ $\sigma=\sqrt{0.01042/0.25}=20.416\%$ การเชื่อมตรง ๆ ให้ $22-0.4(2)=21.2\%$ สูงไป 0.78 จุด forward volatility คือ $\sqrt{0.0159667/(5/12)}=19.575\%$ ซึ่งเป็นบวก จึงไม่มี calendar arbitrage

2. call SPX อายุ 0.5 ปี ดอกเบี้ย 4% ราคา 112, 78 และ 47 จุดที่ strike 4,900, 5,000 และ 5,100 ผ่านกฎ butterfly ไหม และ density ที่ 5,000 ประมาณเท่าไร?

เฉลย

$B_0=112-2(78)+47=3\ge0$ ผ่าน density ประมาณ $e^{0.02}(3)/100^2=0.000306$ ต่อจุด คูณความกว้าง 100 จุดได้โอกาสราว 3.06% ที่ดัชนีจบในช่วง 4,950 ถึง 5,050 ภายใต้ risk-neutral measure ตรวจกฎความชันด้วย: $(112-78)/100=0.34$ และ $(78-47)/100=0.31$ อยู่ระหว่าง 0 กับ $e^{-0.02}=0.98$ ผ่าน

3. ในตัวอย่าง leverage effect ถ้ามูลค่าบริษัทเพิ่ม 10% เป็น 110 ความผันผวนของหุ้นเป็นเท่าไร และบอกอะไรเกี่ยวกับ call ที่ strike สูง?

เฉลย

หุ้นเป็น $110-50=60$ จึง $\sigma_E=(110/60)(20\%)=36.67\%$ ลดจาก 40% หุ้นยิ่งขึ้นยิ่งแกว่งน้อย call ที่ strike สูงจ่ายเงินในโลกที่หุ้นขึ้นไปแล้วซึ่งแกว่งน้อยกว่า จึงควรมีความผันผวนต่ำกว่า smile จึงลาดลงไปทางขวาแบบรูปผืนหั่นตามอายุ

// The volatility surface: implied vol, total-variance interpolation, the no-arbitrage rules, and what a surface can price.
const { abs, exp, log, sqrt, min, max, PI } = Math;
const phi = x => exp(-0.5 * x * x) / sqrt(2 * PI);
// Normal CDF: Taylor series near the centre, continued fraction in the tails.
function Phi(x) {
  const a = abs(x);
  if (a <= 3) {
    let term = a, sum = a;
    for (let n = 1; n < 200 && term > 1e-17 * sum; n++) { term *= a * a / (2 * n + 1); sum += term; }
    return x >= 0 ? 0.5 + phi(a) * sum : 0.5 - phi(a) * sum;
  }
  let f = a;
  for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - phi(a) / f : phi(a) / f;
}
function bs(S, K, T, r, sigma, q = 0) {
  if (![S, K, T, sigma].every(x => Number.isFinite(x) && x > 0)) throw new RangeError('S, K, T and sigma must be positive');
  const A = S * exp(-q * T), B = K * exp(-r * T), v = sigma * sqrt(T), d1 = (log(A / B) + v * v / 2) / v, d2 = d1 - v;
  return {d2, call: A * Phi(d1) - B * Phi(d2), vega: A * phi(d1) * sqrt(T)};
}
// Implied vol by bisection: the price rises with sigma, so one answer exists inside the price bounds.
function impliedVol(price, S, K, T, r, q) {
  const low = max(S * exp(-q * T) - K * exp(-r * T), 0), high = S * exp(-q * T);
  if (!(price > low && price < high)) throw new RangeError('Price is outside the no-arbitrage bounds');
  let lo = 1e-4, hi = 5;
  for (let i = 0; i < 100; i++) { const m = (lo + hi) / 2; if (bs(S, K, T, r, m, q).call > price) hi = m; else lo = m; }
  return (lo + hi) / 2;
}
// Total variance, forward variance, and interpolation that refuses a calendar arbitrage.
const totalVariance = (sigma, T) => sigma * sigma * T;
function forwardVariance(s1, T1, s2, T2) {
  if (!(T2 > T1)) throw new RangeError('Need T2 > T1');
  const v = (totalVariance(s2, T2) - totalVariance(s1, T1)) / (T2 - T1);
  if (v < 0) throw new RangeError(`Calendar arbitrage: forward variance ${v.toFixed(4)} is negative`);
  return v;
}
function interpolateVol(T, T1, s1, T2, s2) {
  forwardVariance(s1, T1, s2, T2);
  const w = totalVariance(s1, T1) + (T - T1) / (T2 - T1) * (totalVariance(s2, T2) - totalVariance(s1, T1));
  return {w, sigma: sqrt(w / T)};
}
// Call divided by D*F as a function of x = K/F and total variance w.
const normCall = (x, w) => Phi((-log(x) + w / 2) / sqrt(w)) - x * Phi((-log(x) - w / 2) / sqrt(w));
// The training surface used on this page (made up): skew steeper at short maturities.
const surface = (k, T) => 0.20 + 0.06 * exp(-2 * T) - 0.06 * k / sqrt(T) + 0.02 * k * k / T;
function checkSurface() {
  let minDw = Infinity, minFly = Infinity;
  for (let i = 0; i <= 52; i++) { const k = -0.28 + 0.01 * i;
    for (let j = 0; j < 1420; j++) { const T = 0.08 + 0.001 * j;
      minDw = min(minDw, surface(k, T + 0.001) ** 2 * (T + 0.001) - surface(k, T) ** 2 * T); } }
  for (const T of [0.08, 0.25, 0.5, 1, 1.5]) {
    const xs = []; for (let x = exp(-0.28); x <= exp(0.24); x += 0.0025) xs.push(x);
    const c = xs.map(x => normCall(x, surface(log(x), T) ** 2 * T));
    for (let i = 1; i + 1 < c.length; i++) minFly = min(minFly, c[i - 1] - 2 * c[i] + c[i + 1]);
  }
  return {minDw, minFly};
}
// Risk-neutral probability that S_T / F ends below x, read from the surface: 1 + dc/dx.
function cdfFromSurface(x, T, h = 1e-4) {
  const c = y => normCall(y, surface(log(y), T) ** 2 * T);
  return 1 + (c(x + h) - c(x - h)) / (2 * h);
}
// Knock-in put: pays (1 - S_1)+ only if S_0.5 >= 1.2. Inner expectation in closed form, outer by Simpson.
function knockIn(rho, sigma = 0.3, T1 = 0.5, T2 = 1, barrier = 1.2) {
  if (!(abs(rho) < 1)) throw new RangeError('Correlation must lie strictly between -1 and 1');
  const zb = (log(barrier) + sigma * sigma * T1 / 2) / (sigma * sqrt(T1)), b = sigma * sqrt(T2 * (1 - rho * rho));
  const inner = z => { const A = exp(-sigma * sigma * T2 / 2 + sigma * sqrt(T2) * rho * z), z0 = -log(A) / b;
    return Phi(z0) - A * exp(b * b / 2) * Phi(z0 - b); };
  const n = 4000, h = (9 - zb) / n; let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * inner(zb + i * h) * phi(zb + i * h);
  return s * h / 3;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • implied volatility มีค่าเดียวเพราะราคาจากสูตรขึ้นตามความผันผวนตลอด: call 3 เดือนราคา 250 จุดให้ 23.65% และผืนคือจุดแบบนี้ทุก strike ทุกอายุ
  • variance บวกกันตามเวลา ความผันผวนไม่บวก จึงเชื่อมอายุบน $w=\sigma_{\rm imp}^2T$ ที่ $k=\ln(K/F)$ เดียวกัน: 30% กับ 24% ให้อายุ 2 เดือน 25.63% ไม่ใช่ 27% ซึ่งแพงไป \$1,110 ต่อสัญญา
  • forward variance ต้องไม่ติดลบ: ความผันผวนลดตามอายุได้ แต่ total variance ลดไม่ได้ ตามแกน strike ราคา call ต้องลดลงไม่เร็วเกิน $e^{-rT}$ และโค้งหงาย butterfly 112/80/47 ราคา −1 คือเงินฟรี และ skew ATM 25% ลาดลงได้ไม่เกิน 13.9 จุดต่อ strike 10%
  • ความโค้งของราคาตาม strike คือ density ของราคาปลายทาง ผืนที่มี skew ให้หางซ้ายหนากว่า lognormal และ skew ส่วนหนึ่งมาจาก leverage: หนี้ 50 บริษัท 100 แกว่ง 20% ทำให้หุ้นแกว่ง 40% และ 45% เมื่อบริษัทลดเหลือ 90
  • ผืนตั้งราคาสัญญาที่ขึ้นกับราคาวันเดียวได้ (digital 0.45 เป็น 0.55 เมื่อนับ skew, range accrual \$2.29 ล้าน) แต่ตั้งราคาสัญญาที่ขึ้นกับเส้นทางไม่ได้ (knock-in 0.0020 ถึง 0.0390 บนผืนเดียวกัน)

หน้าถัดไป โครงสร้างสำหรับเทรดความผันผวน ใช้ผืนนี้เป็นสนามเทรด: straddle, strangle, risk reversal, butterfly และ calendar แต่ละตัวซื้อขายส่วนไหนของผืน และได้เสียอย่างไรเมื่อผืนขยับ
