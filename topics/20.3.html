20.3 Rate Lattices: Ho-Lee and Black-Derman-Toy

ต้นไม้สองกิ่งของอัตราดอกเบี้ยระยะสั้นให้ราคาของเงินที่จ่ายเฉพาะบางสถานการณ์ ปรับทีละชั้นให้ราคาพันธบัตรตรง curve วันนี้ แล้วใช้ตั้งราคา option บนพันธบัตร forward และ futures

นักลงทุนถือ call แบบยุโรปอายุ 1 ปี บน zero-coupon bond ที่ครบกำหนดในปีที่ 1.5 หน้าตั๋ว \$1,000,000 strike 0.975 ต่อ \$1 short rate วันนี้คือ 5% ต่อปี (ทบต่อเนื่อง) อีกครึ่งปีจะเป็น 6% หรือ 4% และที่ปีที่ 1 จะเป็น 7%, 5% หรือ 3% ครึ่งต่อครึ่งทุกกิ่ง (ตัวเลขสมมติ) เพื่อนใช้อัตรากลาง 5% ที่ปีที่ 1: พันธบัตรตอนนั้นราคา 0.975310 ได้ payoff \$309.91 คิดลดกลับมาได้ \$294.80 ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก ราคาที่ถูกคือ \$2,564.15 เกือบเก้าเท่า option จ่ายแบบไม่สมมาตร ถ้าอัตราปีที่ 1 ลงเป็น 3% พันธบัตรราคา 0.985112 และ payoff เป็น \$10,111.94 ถ้าขึ้นเป็น 7% payoff เป็นศูนย์ ไม่ติดลบ ค่าเฉลี่ยของอัตรามองไม่เห็นก้อนนี้ ต้องมีต้นไม้ของอัตราทั้งต้น

สิ่งที่เราจะสร้าง

20.1 และ 20.2 ตั้งราคาเงินที่ล็อกได้ด้วย discount factor ของวันนี้อย่างเดียว สัญญาที่มีทางเลือกไม่เป็นแบบนั้น มันจ่ายเฉพาะบางสถานการณ์ จึงต้องรู้ว่าอัตราในอนาคตกระจายอย่างไร หน้านี้ใช้ต้นไม้สองกิ่งแบบ 18.3 แต่สิ่งที่แตกกิ่งคืออัตราดอกเบี้ยระยะสั้น ไม่ใช่ราคาหุ้น

เริ่มจากต้นไม้เล็กที่ตั้งด้วยมือ ตั้งราคาพันธบัตรด้วยการเดินย้อน หา state price ด้วยการเดินหน้า ตั้งราคา option ของโจทย์เปิดหน้า แล้วบังคับต้นไม้ให้ตรง curve ของตลาดด้วย Ho-Lee และ BDT จากนั้นใช้ต้นไม้ของคอร์สตั้งราคา zero, option อเมริกัน, forward และ futures แล้วดูว่าทำไมการ fit curve อย่างเดียวไม่พอ

ศัพท์ที่ใช้ในหัวข้อนี้
Short rate
อัตราดอกเบี้ยของงวดถัดไปหนึ่งงวด ซึ่งรู้ค่าตอนต้นงวด เป็นตัวแปรเดียวที่ต้นไม้เก็บ ราคาพันธบัตรทุกอายุคำนวณจากมัน
Recombining lattice
ต้นไม้ที่ขึ้นแล้วลงกับลงแล้วขึ้นมาถึงจุดเดียวกัน จำนวนจุดจึงโตตามจำนวนงวดแบบเส้นตรง ไม่ใช่เท่าตัวทุกงวด
Risk-neutral probability $q$
น้ำหนักของกิ่งขึ้นที่ใช้ตั้งราคา ไม่ใช่โอกาสจริง short rate ซื้อขายไม่ได้ จึงกำหนด $q$ เองตรง ๆ (หน้านี้ใช้ครึ่งต่อครึ่ง) แล้วไปปรับอัตราแทน
State price (Arrow–Debreu)
ราคาวันนี้ของเงิน \$1 ที่จ่ายเฉพาะจุดเดียวของต้นไม้ รวมทั้งน้ำหนัก $q$ และการคิดลดไว้แล้ว หาครั้งเดียวแล้วใช้ตั้งราคาได้ทุกสัญญา
Calibration
การเลือกค่าในต้นไม้ให้ราคาที่ต้นไม้คำนวณตรงกับราคาตลาดของตราสารที่ซื้อขายคล่อง ก่อนนำไปตั้งราคาของที่ไม่มีราคาตลาด
Ho-Lee และ Black–Derman–Toy (BDT)
สองวิธีวางอัตราในแต่ละชั้น Ho-Lee วางให้ห่างกันเป็นจำนวนจุดเท่ากัน (อัตราติดลบได้) BDT วางให้ห่างกันเป็นสัดส่วนเท่ากัน (อัตราเป็นบวกเสมอ)
Cash account
บัญชีที่เริ่มที่ \$1 แล้วทบด้วย short rate ทีละงวด ปลอดภัยทีละงวดแต่ไม่ปลอดภัยเมื่อมองหลายงวด ใช้เป็นตัวหารของราคาทุกตัว

ขั้นที่ 1 — ต้นไม้ของ short rate: ทุกจุดรู้อัตราของงวดหน้า

ต้นไม้เก็บ short rate ของแต่ละจุด คืออัตราที่ใช้กับงวดถัดไปหนึ่งงวด ที่แต่ละจุด มูลค่าคือค่าเฉลี่ยถ่วงของสองจุดลูก คิดลดหนึ่งงวดด้วยอัตราของจุดนั้นเอง ไม่ใช่อัตราเดียวทั้งต้น นี่คือกฎเดียวที่ใช้ซ้ำทั้งหน้า ต้นไม้ของโจทย์เปิดหน้ามีสามชั้น

\[ \begin{aligned} V_{n,j}&=e^{-r_{n,j}\Delta t}\big[q\,V_{\rm up}\\ &\qquad+(1-q)\,V_{\rm down}\big],\\ q&=\tfrac12,\quad\Delta t=0.5,\\ r_0&=5\%,\\ r_{0.5}&=6\%,\ 4\%,\\ r_1&=7\%,\ 5\%,\ 3\%. \end{aligned} \]

ต้นไม้หุ้นใน 18.3 ได้ $q$ มาจากการเลียนแบบ เพราะหุ้นซื้อขายได้ short rate ซื้อขายไม่ได้ จึงกำหนด $q$ เองตรง ๆ ค่าใดก็ได้ระหว่าง 0 กับ 1 ราคาที่ได้ไม่เปิดช่องเงินฟรี เพราะทุกราคาคำนวณจากระบบเดียวกันที่มีราคาเป็นบวกทุกจุด งานยากจึงย้ายไปที่การปรับอัตราให้ตรงตลาด (ขั้นที่ 5)

ต้นไม้นี้ recombine: ขึ้นแล้วลงกับลงแล้วขึ้นมาถึง 5% เดียวกัน ชั้นที่ $n$ จึงมีแค่ $n+1$ จุด ไม่ใช่ $2^n$

ขั้นที่ 2 — ราคาพันธบัตรบนต้นไม้: เดินย้อนจากวันครบกำหนด

ลองกับของที่ง่ายที่สุด zero ที่จ่าย \$1 ในปีที่ 1 ที่จุดครึ่งปีมันเหลืออีกงวดเดียว ราคาคือ $e^{-r\Delta t}$ ของจุดนั้น แล้วถอยมาวันนี้อีกงวดด้วยกฎของขั้นที่ 1

\[ \begin{aligned} Z_{\rm up}&=e^{-0.06(0.5)}=0.970446,\\ Z_{\rm down}&=e^{-0.04(0.5)}=0.980199,\\ Z_0&=e^{-0.05(0.5)}\\ &\quad\times\tfrac12(0.970446+0.980199)\\ &=0.975310(0.975322)\\ &=0.951241. \end{aligned} \]

ต้นไม้บอกว่า \$1 ในปีที่ 1 มีค่าวันนี้ 0.951241 ถ้าตลาดบอกตัวเลขอื่น ต้นไม้นี้ใช้ตั้งราคาไม่ได้ ต้องปรับจนตรง (ขั้นที่ 5)

สังเกตว่าค่าเฉลี่ยของสอง discount factor คือ 0.975322 สูงกว่า discount factor ของอัตรากลาง 5% ซึ่งคือ 0.975310 เล็กน้อย เพราะ $e^{-x}$ โค้งหงาย ค่าเฉลี่ยของมันจึงมากกว่าค่าที่จุดเฉลี่ย ความต่างเล็ก ๆ นี้จะกลับมาในขั้นที่ 5

ขั้นที่ 3 — state price: ราคาของ \$1 ที่จ่ายเฉพาะจุดเดียว

เดินย้อนทีละสัญญาใช้ได้ แต่ถ้าต้องตั้งราคาหลายสัญญามีทางลัด: หาราคาวันนี้ของเงิน \$1 ที่จ่ายเฉพาะจุด $(n,j)$ จุดเดียว เรียกว่า state price $Q_{n,j}$ เงินก้อนนั้นที่ชั้นก่อนหน้ามีค่าไม่เป็นศูนย์แค่ที่พ่อแม่สองจุด จุดละ $\tfrac12e^{-r\Delta t}$ ให้ $j$ นับจากบนลงล่าง จุด $(n+1,s)$ มาจาก $(n,s)$ ด้วยการลง และจาก $(n,s-1)$ ด้วยการขึ้น

\[ \begin{aligned} Q_{n+1,s}&=\tfrac12Q_{n,s-1}e^{-r_{n,s-1}\Delta t}\\ &\quad+\tfrac12Q_{n,s}e^{-r_{n,s}\Delta t},\\ Q_{1,\cdot}&=\tfrac12(0.975310)=0.487655,\\ Q_{2,0}&=0.487655(\tfrac12)(0.970446)\\ &=0.236621,\\ Q_{2,2}&=0.487655(\tfrac12)(0.980199)\\ &=0.238999,\\ Q_{2,1}&=0.236621+0.238999\\ &=0.475621,\\ \textstyle\sum_sQ_{2,s}&=0.951241. \end{aligned} \]

แถวแรกคือเงิน \$1 ที่จุด $(n+1,s)$ ตีราคากลับไปที่พ่อแม่ แล้วคูณ state price ของพ่อแม่ ($Q_{0,0}=1$) จุดกลางมาได้สองทาง แต่ละทางราคาต่างกันเพราะคิดลดด้วยอัตราของพ่อแม่คนละจุด (6% หรือ 4%) ต้องบวกทั้งสองทาง

state price รวม $q$ และการคิดลดไว้แล้ว จึงไม่ใช่โอกาส (รวมกันได้ 0.951241 ไม่ใช่ 1) ผลบวกของชั้นปีที่ 1 ตรงกับราคา zero ของขั้นที่ 2 ทุกหลัก สองวิธีคนละทิศได้ตัวเลขเดียวกัน นี่คือการตรวจที่สำคัญที่สุดของต้นไม้

ขั้นที่ 4 — คำตอบของโจทย์เปิดหน้า: call บน zero-coupon bond

โจทย์ให้อะไรมาบ้าง: call หมดอายุปีที่ 1 บน zero ที่ครบกำหนดปีที่ 1.5 หน้าตั๋ว \$1,000,000 strike 0.975 ต่อ \$1 ที่วันใช้สิทธิ์พันธบัตรเหลือครึ่งปี และอัตราของครึ่งปีนั้นรู้แล้ว ราคาพันธบัตรจึงเป็น $e^{-r(0.5)}$ ของแต่ละจุด state price จากขั้นที่ 3

\[ \begin{aligned} P_{2,0}&=0.965605,\\ P_{2,1}&=0.975310,\\ P_{2,2}&=0.985112,\\ N(P-0.975)^+&=0,\ 309.91,\\ &\qquad10{,}111.94,\\ V_0&=0.475621(309.91)\\ &\quad+0.238999\\ &\qquad\times10{,}111.94\\ &=147.40+2{,}416.75\\ &=2{,}564.15. \end{aligned} \]

คำตอบ: \$2,564.15 payoff เป็นเงินที่ปีที่ 1 และ state price ย้ายมันมาวันนี้ในขั้นเดียว ไม่ต้องคิดลดซ้ำ ถ้าคูณ discount factor ปีที่ 1 อีกครั้งจะคิดลดสองรอบ ส่วนวิธีอัตรากลางตัวเดียวได้ $309.91(0.951241)=\$294.80$ ต่ำไปเกือบเก้าเท่า เพราะมูลค่าเกือบทั้งหมด (\$2,416.75) มาจากจุดอัตรา 3% ซึ่งค่าเฉลี่ยมองไม่เห็น

ตรวจเองใน 10 วินาที: $(0.985112-0.975)(1{,}000{,}000)=10{,}111.94$ คูณ state price ราว 0.24 ได้ราว \$2,400 เป็นก้อนใหญ่ของคำตอบ

ขั้นที่ 5 — Ho-Lee: ปรับระดับทีละชั้นให้ตรง curve ของตลาด

ต้นไม้ของขั้นที่ 1 ตั้งด้วยมือ ต้นไม้จริงต้องให้ราคา zero ตรงกับ curve ของตลาดทุกอายุ Ho-Lee วางอัตราแบบบวก: ทุกจุดในชั้นเดียวกันห่างกันเท่ากัน $2\sigma\sqrt{\Delta t}$ และเลื่อนทั้งชั้นด้วยระดับ $\alpha_n$ ซึ่งเป็นตัวไม่รู้ตัวเดียวต่อชั้น ใช้เงื่อนไขของขั้นที่ 3: ผลบวกของ state price ชั้นถัดไปต้องเท่ากับ discount factor ของตลาด

\[ \begin{aligned} r_{n,j}&=\alpha_n+x_{n,j},\\ x_{n,j}&=(n-2j)\,\sigma\sqrt{\Delta t},\\ D(0,t_{n+1})&=\sum_jQ_{n,j}e^{-r_{n,j}\Delta t}\\ &=e^{-\alpha_n\Delta t}H_n,\\ H_n&=\sum_jQ_{n,j}e^{-x_{n,j}\Delta t},\\ \alpha_n&=-\frac{1}{\Delta t}\ln\frac{D(0,t_{n+1})}{H_n}. \end{aligned} \]

$\alpha_n$ เลื่อนทุกจุดในชั้นเท่ากัน $e^{-\alpha_n\Delta t}$ จึงดึงออกนอกผลบวกได้ เหลือสมการเดียวตัวไม่รู้เดียวต่อชั้น แก้จากชั้นแรกไปชั้นหลังแบบ bootstrapping ของ 20.1 ต้นไม้ของขั้นที่ 1 คือ Ho-Lee ที่ $\alpha_n=5\%$ ทุกชั้นและ $\sigma\sqrt{0.5}=1\%$ หรือ $\sigma=1.4142\%$ ต่อ √ปี

ลอง calibrate กับ curve ของ 20.1 (0.9755, 0.9505, 0.931421875, 0.9059165) ด้วย $\sigma=1\%$ ได้ $\alpha$ = 4.9610, 5.1936, 4.0602 และ 5.5643% ถ้า $\sigma=0$ ได้ 4.9610, 5.1924, 4.0552 และ 5.5530% คือ forward ของ 20.1 พอดี ความผันผวนดัน $\alpha$ สูงกว่า forward 0.1, 0.5 และ 1.1 bp ด้วยเหตุผลโค้งหงายของขั้นที่ 2

ขั้นที่ 6 — BDT: วางอัตราแบบคูณ อัตราจึงเป็นบวกเสมอ

Ho-Lee ห่างกันเป็นจำนวนจุด ถ้าอัตราต่ำ จุดล่างติดลบได้ BDT วาง log ของอัตราแบบบวกแทน ตัวอัตราจึงคูณกัน แบบที่คอร์สใช้คือ $r_{i,j}=a_ie^{bj}$ ทบต่องวด งวดละปี $b$ คือความผันผวนของ log อัตรา แล้วแก้ $a_i$ ทีละชั้นให้ตรงกับ spot rate $s_{i+1}$ ของตลาด

\[ \begin{aligned} r_{i,j}&=a_ie^{bj},\quad a_i\gt 0,\\ \frac{1}{(1+s_{i+1})^{i+1}}&=\sum_j\frac{Q_{i,j}}{1+a_ie^{bj}},\\ Q_{1,\cdot}&=\frac{1}{2(1.073)}\\ &=0.465983,\\ \frac{1}{1.0762^2}&=0.465983\Big[\frac{1}{1+a_1}\\ &\qquad+\frac{1}{1+a_1e^{0.005}}\Big],\\ a_1&=7.9211\%. \end{aligned} \]

เส้น spot ทบรายปีของตัวอย่างคือ 7.30, 7.62, 8.10, 8.45, 9.20, 9.64, 10.12, 10.45, 10.75 และ 11.22% ตรึง $b=0.005$ งวดแรกมีจุดเดียว $a_0=7.30\%$ state price ของสองจุดปีที่ 1 คือ 0.465983 แก้สมการได้ $a_1=7.9211\%$ ต่อไปได้ $a_2$ ถึง $a_4$ = 9.0212, 9.4357 และ 12.1302%

ฝั่งขวาลดลงเมื่อ $a_i$ เพิ่ม (อัตราสูง คิดลดมาก) จาก $\sum_jQ_{i,j}$ ที่ $a_i=0$ ลงไปหาศูนย์ จึงมีคำตอบบวกเดียวเสมอเมื่อ curve ไม่บังคับให้อัตราติดลบ และหาได้ด้วย bisection ไม่ต้องแก้ทุกชั้นพร้อมกัน

ขั้นที่ 7 — ต้นไม้ของคอร์ส: เริ่ม 6% ขึ้นคูณ 1.25 ลงคูณ 0.9

ต้นไม้สอนของคอร์สทบต่องวด (คิดลดด้วย $1+r$) short rate เริ่ม 6% แต่ละงวดคูณ 1.25 หรือ 0.9 ครึ่งต่อครึ่ง ให้ $j$ นับจำนวนครั้งที่ขึ้น ตั้งราคา zero หน้าตั๋ว 100 ที่ครบกำหนดงวดที่ 4 ด้วยการเดินย้อน

\[ \begin{aligned} r_{i,j}&=0.06(1.25)^j(0.9)^{i-j},\\ Z_{i,j}&=\frac{\tfrac12Z_{i+1,j}+\tfrac12Z_{i+1,j+1}}{1+r_{i,j}},\\ Z_{2,2}&=\frac{\tfrac12(92.22)+\tfrac12(89.51)}{1.0938}\\ &=83.08,\\ Z_{0,0}&=\frac{\tfrac12(84.43)+\tfrac12(79.27)}{1.06}\\ &=77.22,\\ s_4&=(100/77.22)^{1/4}-1\\ &=6.68\%. \end{aligned} \]

ต้นไม้ recombine เพราะ $1.25(0.9)=0.9(1.25)$ state price ทบต่องวดใช้สมการเดินหน้าเดิมโดยแทน $e^{-r\Delta t}$ ด้วย $1/(1+r)$ ชั้นที่ 4 ได้ 0.0511, 0.1992, 0.2901, 0.1868 และ 0.0449 (อัตราต่ำไปสูง) คูณ 100 แล้วบวกได้ 77.22 ตรงกับการเดินย้อน

ทำแบบนี้ทุกอายุได้ spot 6.00, 6.22, 6.45, 6.68 และ 6.91% short rate ตัวเดียวจึงให้ทั้งเส้น ต้นไม้แบบคูณนี้ไม่มีแรงดึงกลับ อัตราบนสุดที่งวดที่ 5 ลอยไปถึง 18.31% ใช้สอนวิธีคิด ไม่ใช่ใช้งานจริง

ราคาที่หารด้วย cash account $B_t=(1+r_0)\cdots(1+r_{t-1})$ เป็นค่าเฉลี่ยของงวดหน้าที่หารแบบเดียวกัน บัญชีนี้ปลอดภัยทีละงวดแต่ไม่ปลอดภัยสองงวด: $B_2$ เป็น 1.1395 หรือ 1.11724 ตามว่างวดแรกขึ้นหรือลง

ขั้นที่ 8 — option บนพันธบัตรของต้นไม้คอร์ส: call แบบยุโรป และ put แบบอเมริกัน

โจทย์ให้อะไรมาบ้าง: zero ของขั้นที่ 7 ราคาที่งวดที่ 2 คือ 90.64, 87.35 และ 83.08 และที่งวดที่ 3 คือ 95.81, 94.27, 92.22 และ 89.51 (อัตราต่ำไปสูง) call strike 84 หมดอายุงวดที่ 2 และ put แบบอเมริกัน strike 88 หมดอายุงวดที่ 3 ใช้สิทธิ์ได้ทุกงวด ที่แต่ละจุดเลือกค่ามากกว่าระหว่างใช้สิทธิ์ทันทีกับถือต่อ $H$

\[ \begin{aligned} C_{2,\cdot}&=(Z_{2,\cdot}-84)^+\\ &=6.64,\ 3.35,\ 0,\\ C_{1,\cdot}&=4.74,\ 1.56,\\ C_0&=\frac{\tfrac12(4.74+1.56)}{1.06}\\ &=2.97,\\ P_{t,j}&=\max(88-Z_{t,j},\ H_{t,j}),\\ P_{0}&=\max(10.78,\ 5.80)\\ &=10.78. \end{aligned} \]

คำตอบ: call ราคา 2.97 มีค่าเฉพาะจุดที่อัตราต่ำ เพราะพันธบัตรแพง put อเมริกันราคา 10.78 และควรใช้สิทธิ์ทันทีวันนี้ เพราะ $88-77.22=10.78$ มากกว่าค่าของการถือต่อ 5.80 ที่งวดที่ 3 พันธบัตรราคาเกิน 88 ทุกจุด put แบบยุโรปที่ strike เดียวกันจึงมีค่าศูนย์ ราคา 10.78 ทั้งก้อนมาจากสิทธิ์ใช้ก่อนกำหนด ตัวเลขนี้มาจากค่าที่เลือกสอน ไม่ใช่พฤติกรรมที่พบบ่อยในตลาด

ตรวจเองใน 10 วินาที: จุดบนสุดของงวดที่ 1 (อัตรา 7.5%): $\tfrac12(0+3.35)/1.075=1.56$ ตรงกับแถวที่สาม

ขั้นที่ 9 — forward กับ futures บนพันธบัตรเดียวกันไม่เท่ากัน

พันธบัตรคูปอง 10% ต่องวด ครบกำหนดงวดที่ 6 ส่งมอบที่งวดที่ 4 หลังจ่ายคูปองงวดที่ 4 แล้ว ราคาพันธบัตรตอนส่งมอบ $S_4$ คือ 111.16, 108.00, 103.83, 98.44 และ 91.66 (อัตราต่ำไปสูง) forward มีค่าศูนย์วันเซ็นและจ่ายครั้งเดียวตอนส่งมอบ futures ปรับกำไรขาดทุนทุกงวดและเข้าสัญญาได้ฟรีทุกงวด

\[ \begin{aligned} 0&=\mathbb E^{\mathbb Q}_0\Big[\frac{S_4-G_0}{B_4}\Big],\\ G_0&=\frac{\mathbb E^{\mathbb Q}_0[S_4/B_4]}{\mathbb E^{\mathbb Q}_0[1/B_4]}\\ &=\frac{79.83}{0.7722}=103.38,\\ 0&=\mathbb E^{\mathbb Q}_k\Big[\frac{F_{k+1}-F_k}{B_{k+1}}\Big],\\ F_k&=\mathbb E^{\mathbb Q}_k[F_{k+1}],\quad F_4=S_4,\\ F_0&=\tfrac12(105.64+100.81)\\ &=103.22. \end{aligned} \]

forward: $G_0$ รู้วันนี้จึงดึงออกจากค่าเฉลี่ยได้ ตัวบนคือพันธบัตรคิดลดด้วยต้นไม้ (79.83) ตัวล่างคือราคา zero งวดที่ 4 (0.7722) futures: $B_{k+1}$ รู้ตั้งแต่งวด $k$ จึงตัดทิ้งได้ ราคา futures จึงเป็นค่าเฉลี่ยธรรมดาของสองลูก ไม่คิดลด ถอยจาก $F_4=S_4$ ทีละชั้น

สองราคาต่างกัน 0.16 เพราะอัตรากับราคาพันธบัตรเดินสวนกัน วันที่พันธบัตรขึ้นคือวันที่อัตราลง กำไรจาก futures จึงถูกนำไปฝากตอนอัตราต่ำ ถ้าอัตราไม่สุ่ม สองราคานี้จะเท่ากัน แบบที่ 19.1 สมมติไว้

const {exp, log, sqrt, max} = Math;

// A recombining lattice is a list of layers; layer n holds n + 1 short rates.
function checkLattice(rates) {
  if (!Array.isArray(rates) || rates.length === 0) throw new TypeError('rates must be a non-empty array of layers');
  rates.forEach((layer, n) => {
    if (!Array.isArray(layer) || layer.length !== n + 1) throw new RangeError(`layer ${n} must hold ${n + 1} rates`);
    if (layer.some(x => !Number.isFinite(x) || x <= -1)) throw new RangeError('every rate must be a number above -100%');
  });
  return rates;
}
// One-period discount at a node: continuous e^(-r dt), or per-period 1 / (1 + r) when dt is null.
const disc = (r, dt) => dt === null ? 1 / (1 + r) : exp(-r * dt);
// Forward equations for state prices with q = 1/2: node j of layer n + 1 has parents j - 1 and j.
function statePrices(rates, dt) {
  checkLattice(rates);
  const Q = [[1]];
  rates.forEach((layer, n) => {
    const next = Array(n + 2).fill(0);
    layer.forEach((r, j) => { const v = Q[n][j] * 0.5 * disc(r, dt); next[j] += v; next[j + 1] += v; });
    Q.push(next);
  });
  return Q;
}
// Backward induction from layer `from` to 0, keeping every layer; `early(n, j, hold)` may replace the holding value.
function backward(rates, dt, terminal, from, early = (n, j, h) => h) {
  checkLattice(rates.slice(0, from));
  if (terminal.length !== from + 1) throw new RangeError('terminal layer must hold from + 1 values');
  const layers = [terminal];
  for (let n = from - 1; n >= 0; n--) {
    const V = layers[0];
    layers.unshift(rates[n].map((r, j) => early(n, j, disc(r, dt) * 0.5 * (V[j] + V[j + 1]))));
  }
  return layers;
}
// Ho-Lee: r = alpha_n + (n - 2j) sigma sqrt(dt); alpha_n solved so layer n reprices D(0, t_{n+1}).
function hoLee(D, sigma, dt) {
  if (!(sigma >= 0)) throw new RangeError('sigma must be at least 0');
  let Q = [1]; const alpha = [], rates = [];
  D.forEach((target, n) => {
    const x = Q.map((_, j) => (n - 2 * j) * sigma * sqrt(dt));
    const H = Q.reduce((s, q, j) => s + q * exp(-x[j] * dt), 0);
    const a = -log(target / H) / dt;
    alpha.push(a); rates.push(x.map(v => a + v));
    Q = statePrices(rates, dt)[n + 1];
  });
  return {alpha, rates, check: Q.reduce((s, q) => s + q, 0)};
}
// BDT with per-period compounding: r = a_i e^(b j); a_i by bisection so layer i reprices the spot curve.
function bdt(spot, b) {
  let Q = [1]; const a = [];
  spot.forEach((s, i) => {
    const target = 1 / (1 + s) ** (i + 1);
    const f = ai => Q.reduce((sum, q, j) => sum + q / (1 + ai * exp(b * j)), 0) - target;
    if (!(f(0) > 0)) throw new RangeError('spot curve needs a negative rate level');
    let lo = 0, hi = 1;
    for (let k = 0; k < 200; k++) { const m = (lo + hi) / 2; if (f(m) > 0) lo = m; else hi = m; }
    const ai = (lo + hi) / 2; a.push(ai);
    const next = Array(i + 2).fill(0);
    Q.forEach((q, j) => { const v = q / (2 * (1 + ai * exp(b * j))); next[j] += v; next[j + 1] += v; });
    Q = next;
  });
  return a;
}

const oneYear = Qt[2].reduce((s, q) => s + q, 0);

แบบจำลองอัตราดอกเบี้ยรุ่นแรก เช่น Vasicek (1977) และ Cox–Ingersoll–Ross (1985) มีพารามิเตอร์คงที่ไม่กี่ตัว จึงตั้งราคาพันธบัตรทุกอายุให้ตรงตลาดพร้อมกันไม่ได้ Thomas Ho และ Sang Bin Lee เสนอในปี 1986 ให้ระดับของแต่ละช่วงเวลาเป็นตัวปรับอิสระ แล้วเลือกให้ราคาตรง curve พอดี Fischer Black, Emanuel Derman และ William Toy เสนอในปี 1990 ให้ทำงานบน log ของอัตราเพื่อไม่ให้อัตราติดลบ แนวคิด “ตรงตลาดก่อน แล้วค่อยตั้งราคาของที่ซับซ้อน” ยังเป็นหลักของงานอนุพันธ์อัตราดอกเบี้ยทุกวันนี้
