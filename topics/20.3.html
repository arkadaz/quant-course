20.3 Rate Lattices: Ho-Lee and Black-Derman-Toy

วาดอัตราดอกเบี้ยในอนาคตเป็นต้นไม้สองกิ่ง ปรับต้นไม้ทีละชั้นให้ราคาพันธบัตรตรงกับตลาดวันนี้ แล้วใช้ต้นไม้ตั้งราคาสัญญาที่จ่ายเงินเฉพาะบางสถานการณ์ เช่น option บนพันธบัตร

ราคาพันธบัตรเดินสวนกับอัตราดอกเบี้ย เพราะเงินที่พันธบัตรจะจ่ายเป็นจำนวนตายตัว ถ้าอัตราดอกเบี้ยขึ้น เงินก้อนนั้นคิดลดมาเป็นเงินวันนี้ได้น้อยลง พันธบัตรจึงถูกลง ถ้าอัตราลง พันธบัตรก็แพงขึ้น ดังนั้นสัญญาที่จ่ายเงินตามราคาพันธบัตรในอนาคตจะมีค่าเท่าไร ขึ้นกับว่าอัตราดอกเบี้ยจะไปทางไหน หน้านี้สร้างเครื่องมือสำหรับตั้งราคาสัญญาแบบนี้

ตัวอย่าง นักลงทุนคนหนึ่งถือ call option บนพันธบัตร call option คือสิทธิ์ (ไม่ใช่ข้อผูกมัด) ที่จะซื้อของในราคาที่ตกลงไว้ล่วงหน้า ราคาที่ตกลงนี้เรียกว่า strike ถ้าวันใช้สิทธิ์ของแพงกว่า strike ผู้ถือจะใช้สิทธิ์และได้ส่วนต่าง ถ้าของถูกกว่า ผู้ถือจะปล่อยสิทธิ์ทิ้งและได้ศูนย์

ของที่รู้:

  • พันธบัตรเป็นแบบ zero-coupon คือไม่จ่ายดอกเบี้ยระหว่างทาง จ่ายเงินก้อนเดียวตอนครบกำหนดในปีที่ 1.5 (ต่อไปจะเรียกพันธบัตรแบบนี้สั้น ๆ ว่า zero) เงินก้อนนี้เรียกว่าหน้าตั๋ว $N=\$1{,}000{,}000$
  • สิทธิ์ใช้ได้วันเดียวคือปีที่ 1 (เรียกว่า call แบบยุโรป) strike คือ $K=0.975$ ต่อหน้าตั๋ว \$1 ทั้งก้อนจึงเป็น $0.975\times1{,}000{,}000=\$975{,}000$
  • อัตราดอกเบี้ยของครึ่งปีถัดไปเรียกว่า short rate วันนี้ $r_0=5\%$ ต่อปี แบบทบต่อเนื่อง คือเงิน \$1 ที่จะได้ในอีก $t$ ปี มีค่าวันนี้ $e^{-rt}$
  • อีกครึ่งปี short rate จะเป็น 6% หรือ 4% ที่ปีที่ 1 จะเป็น 7%, 5% หรือ 3% ทุกทางแยกขึ้นหรือลงครึ่งต่อครึ่ง (ตัวเลขสมมติ วาดเป็นต้นไม้ไว้ในรูปแรกของหน้า)

เพื่อนคนหนึ่งคิดว่าใช้อัตรากลางตัวเดียวก็พอ ที่ปีที่ 1 อัตรากลางคือ 5% และพันธบัตรเหลืออายุอีกครึ่งปี เขาจึงหาราคาพันธบัตร $P$ หาเงินที่สิทธิ์จ่าย $X$ แล้วคิดลดมาเป็นเงินวันนี้ $V_0$ ตัวคูณ 0.951241 คือราคาวันนี้ของ \$1 ที่จ่ายในปีที่ 1 ซึ่งหน้านี้จะคำนวณให้ดูในขั้นที่ 2

\[\begin{aligned}P&=e^{-0.05\times0.5}=0.97530991,\\X&=N(P-K)\\&=10^6(0.97530991-0.975)\\&=\$309.91,\\V_0&=309.91\times0.951241\\&=\$294.80.\end{aligned}\]

\$294.80 คือราคาที่ถูกของสิทธิ์นี้ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ถูก ราคาที่ถูกคือ \$2,564.15 (คำนวณในขั้นที่ 4) สูงกว่าคำตอบของเพื่อนเกือบเก้าเท่า เพราะ $2{,}564.15/294.80=8.7$ ต้นเหตุคือ call จ่ายเงินไม่สมมาตร ถ้าอัตราปีที่ 1 ลงเป็น 3% พันธบัตรจะแพงขึ้น และสิทธิ์จ่ายก้อนใหญ่:

\[\begin{aligned}P&=e^{-0.03\times0.5}=0.98511194,\\X&=10^6(0.98511194-0.975)\\&=\$10{,}111.94.\end{aligned}\]

ถ้าอัตราขึ้นเป็น 7% พันธบัตรราคา $e^{-0.07\times0.5}=0.96560542$ ต่ำกว่า strike ผู้ถือจึงไม่ใช้สิทธิ์ และได้ศูนย์ ไม่ใช่ติดลบ ก้อนใหญ่ฝั่ง 3% จึงไม่มีอะไรมาหักล้าง อัตรากลางตัวเดียวมองไม่เห็นก้อนนี้ เราจึงต้องรู้อัตราทุกทางที่เป็นไปได้ ซึ่งก็คือต้นไม้ทั้งต้น

ภาพรวมก่อนลงสูตร

ในหน้า zero rate และ forward กับหน้า swap เงินทุกก้อนในสัญญาเป็นตัวเลขตายตัว หรือล็อกให้ตายตัวได้ตั้งแต่วันนี้ จึงคิดลดด้วย discount factor ของวันนี้ได้เลย (discount factor คือราคาวันนี้ของ \$1 ที่จ่ายแน่นอนในวันหนึ่งข้างหน้า) option ไม่เป็นแบบนั้น option จ่ายเงินเฉพาะเมื่ออัตราไปทางหนึ่ง เราจึงต้องรู้ว่าอัตราในอนาคตเป็นไปได้กี่แบบ และแต่ละแบบมีน้ำหนักเท่าไร

เครื่องมือที่ง่ายที่สุดคือต้นไม้สองกิ่ง แบบเดียวกับ binomial tree ของหุ้น ต่างกันที่สิ่งที่แตกกิ่งไม่ใช่ราคาหุ้น แต่เป็น short rate คืออัตราดอกเบี้ยของงวดถัดไปหนึ่งงวด แต่ละจุดบนต้นไม้คือสถานการณ์หนึ่งที่อาจเกิด และแต่ละจุดรู้อัตราของตัวเอง

รูปด้านล่างคือต้นไม้ของโจทย์เปิดหน้า ตัวเลขสีน้ำเงินเหนือจุดคือ short rate ตัวเลขสีส้มใต้จุดคือราคาของ zero ที่จ่าย \$1 ในปีที่ 1 ราคาสีส้มเติมจากขวาไปซ้าย ที่ปีที่ 1 พันธบัตรครบกำหนดและจ่าย \$1 ราคาจึงเป็น 1 ทุกจุด ถอยมาหนึ่งชั้น เอาราคาของสองจุดลูกมาเฉลี่ย แล้วคิดลดด้วยอัตราของจุดนั้นเอง กลไกมีแค่นี้ ส่วนที่เหลือของหน้าคือการปรับต้นไม้ให้ตรงกับราคาในตลาด

ศัพท์ที่ใช้ในหัวข้อนี้
Short rate
อัตราดอกเบี้ยของงวดถัดไปหนึ่งงวด รู้ค่าตั้งแต่ต้นงวด เหมือนอัตราเงินฝากที่ล็อกไว้หนึ่งงวด เป็นตัวแปรเดียวที่ต้นไม้เก็บ ราคาพันธบัตรทุกอายุคำนวณจากมัน
Zero-coupon bond (zero)
พันธบัตรที่ไม่จ่ายดอกเบี้ยระหว่างทาง จ่ายเงินก้อนเดียวตอนครบกำหนด เงินก้อนนั้นเรียกว่าหน้าตั๋ว
Discount factor และ curve
discount factor คือราคาวันนี้ของ \$1 ที่จ่ายแน่นอนในวันหนึ่งข้างหน้า curve ของตลาดคือชุดของ discount factor ทุกอายุ ซึ่งแกะได้จากราคาพันธบัตรที่ซื้อขายวันนี้
Call, put และ strike
call คือสิทธิ์ซื้อ put คือสิทธิ์ขาย ในราคาที่ตกลงไว้ล่วงหน้า (strike) แบบยุโรปใช้สิทธิ์ได้วันหมดอายุวันเดียว แบบอเมริกันใช้สิทธิ์ได้ทุกงวดจนถึงวันหมดอายุ
Recombining lattice
ต้นไม้ที่ขึ้นแล้วลงกับลงแล้วขึ้นจบที่จุดเดียวกัน จำนวนจุดในแต่ละชั้นจึงเพิ่มทีละหนึ่ง ไม่ใช่เพิ่มเท่าตัวทุกงวด
Risk-neutral probability $q$
น้ำหนักของกิ่งขึ้นที่ใช้ตั้งราคา ไม่ใช่โอกาสที่เกิดจริง short rate ซื้อขายไม่ได้ เราจึงกำหนด $q$ เอง (หน้านี้ใช้ครึ่งต่อครึ่ง) แล้วไปปรับอัตราให้ราคาตรงตลาดแทน
State price (Arrow–Debreu, elementary price)
ราคาวันนี้ของตั๋วที่จ่าย \$1 ถ้าต้นไม้ไปถึงจุดหนึ่งจุดเดียว และจ่ายศูนย์ถ้าไปที่อื่น ราคานี้รวมน้ำหนัก $q$ และการคิดลดไว้แล้ว หาครั้งเดียวแล้วใช้ตั้งราคาได้ทุกสัญญา
Calibration
การเลือกค่าในต้นไม้ให้ราคาที่ต้นไม้คำนวณได้ตรงกับราคาตลาดของตราสารที่ซื้อขายคล่อง ก่อนเอาต้นไม้ไปตั้งราคาของที่ไม่มีราคาตลาด
Ho–Lee และ Black–Derman–Toy (BDT)
สองวิธีวางอัตราในแต่ละชั้น Ho–Lee ให้จุดติดกันห่างกันเป็นจำนวนจุดเท่ากัน (อัตราติดลบได้) BDT ให้จุดติดกันห่างกันเป็นสัดส่วนเท่ากัน (อัตราเป็นบวกเสมอ)
Cash account
บัญชีที่เริ่มด้วย \$1 แล้วทบด้วย short rate ทีละงวด ปลอดภัยทีละงวด เพราะรู้อัตราของงวดนั้นตั้งแต่ต้นงวด แต่ไม่ปลอดภัยเมื่อมองหลายงวด ใช้เป็นตัวหารของราคาทุกตัว
Basis point (bp)
หนึ่งในร้อยของ 1 จุด คือ 0.01% หรือ 0.0001
Forward และ futures
สัญญาซื้อของในอนาคตในราคาที่ตกลงวันนี้ forward จ่ายเงินครั้งเดียวตอนส่งมอบ futures เคลียร์กำไรขาดทุนเป็นเงินสดทุกงวด

ขั้นที่ 1 — กฎเดียวของต้นไม้: เฉลี่ยสองลูก คิดลดด้วยอัตราของจุดนั้น

ก่อนตั้งราคาอะไรได้ ต้องมีกฎว่ามูลค่าที่จุดหนึ่งมาจากไหน เราเรียกจุดบนต้นไม้ด้วยสองตัวเลข $n$ คือชั้น นับงวดจากวันนี้ (วันนี้คือชั้น 0) และ $j$ คือตำแหน่งในชั้น นับจากบนลงล่าง จุดบนสุดคือ $j=0$ ซึ่งมีอัตราสูงสุด

กฎคือ มูลค่าที่จุดหนึ่งเท่ากับค่าเฉลี่ยของมูลค่าที่สองจุดลูก คิดลดกลับมาหนึ่งงวดด้วยอัตราของจุดนั้นเอง ไม่ใช่อัตราเดียวทั้งต้น ทำไมต้องใช้อัตราของจุดนั้น เพราะอัตรานั้นรู้ตั้งแต่ต้นงวด และใช้กับงวดถัดไปพอดี เหมือนเงินฝากที่ล็อกอัตราไว้หนึ่งงวด ถ้าสัญญาจ่ายเงิน $C$ ที่จุดลูกด้วย ก็บวกเงินนั้นเข้าไปก่อนเฉลี่ย ในสูตร $V$ คือมูลค่าของสัญญา $q$ คือน้ำหนักของกิ่งขึ้น และ $\Delta t$ คือความยาวหนึ่งงวดเป็นปี สี่แถวล่างคือค่าของต้นไม้ในโจทย์เปิดหน้า โดย $r_0$, $r_{0.5}$ และ $r_1$ คืออัตราของจุดวันนี้ จุดครึ่งปี และจุดปีที่ 1 กฎนี้คือกฎเดียวที่ใช้ซ้ำทั้งหน้า

\[ \begin{aligned} V_{n,j}&=e^{-r_{n,j}\Delta t}\big[q\,(V_{\rm up}+C_{\rm up})\\ &\qquad+(1-q)\,(V_{\rm down}+C_{\rm down})\big],\\ q&=\tfrac12,\quad\Delta t=0.5,\\ r_0&=5\%,\\ r_{0.5}&=6\%,\ 4\%,\\ r_1&=7\%,\ 5\%,\ 3\%. \end{aligned} \]

$q$ มาจากไหน ใน binomial tree ของหุ้น $q$ ได้มาจากการสร้างพอร์ตหุ้นกับเงินฝากที่จ่ายเงินเหมือน option ทุกกิ่ง แต่ short rate ไม่ใช่ของที่ซื้อขายได้ จึงสร้างพอร์ตแบบนั้นไม่ได้ เราจึงกำหนด $q$ เอง จะเป็นค่าไหนระหว่าง 0 กับ 1 ก็ได้ หน้านี้ใช้ $q=\tfrac12$

เลือก $q$ เองแบบนี้แล้วจะเปิดช่องให้ได้เงินฟรีไหม (arbitrage คือพอร์ตที่ได้เงินวันนี้ แล้วไม่ต้องจ่ายคืนในสถานการณ์ไหนเลย) คำตอบคือไม่ เพราะทุกราคาคำนวณจากระบบเดียวกัน และในระบบนี้ราคาของ \$1 ที่จ่ายที่จุดใดก็ตามเป็นบวกเสมอ พอร์ตที่จ่ายเงินไม่ติดลบทุกจุดจึงมีราคาไม่ติดลบ งานยากจึงย้ายไปอยู่ที่การเลือกอัตราในแต่ละจุดให้ราคาตรงกับตลาด ซึ่งเรียกว่า calibration (ขั้นที่ 5 และ 6)

มองกฎเดียวกันอีกมุมได้ด้วย cash account $B_t$ คือบัญชีที่เริ่มด้วย \$1 แล้วทบด้วย short rate ทุกงวด งวดถัดไปบัญชีจึงเป็น $B_{t+1}=B_te^{r\Delta t}$ ซึ่งรู้ค่าตั้งแต่ตอนนี้ เอากฎของขั้นนี้ (กรณีไม่มี $C$) หารด้วย $B_t$ ทั้งสองข้าง ตัว $e^{-r\Delta t}/B_t$ จะรวมเป็น $1/B_{t+1}$ ได้ $\tfrac{V_t}{B_t}=q\tfrac{V_{\rm up}}{B_{t+1}}+(1-q)\tfrac{V_{\rm down}}{B_{t+1}}$ แปลว่าราคาที่หารด้วยบัญชีนี้ เท่ากับค่าเฉลี่ยของตัวมันเองในงวดถัดไป ของที่มีสมบัติแบบนี้เรียกว่า martingale เป็นเรื่องเดียวกับ risk-neutral measure ของหุ้น

ขั้นที่ 2 — ราคาพันธบัตรบนต้นไม้: เดินย้อนจากวันครบกำหนด

ลองใช้กฎกับของที่ง่ายที่สุดก่อน คือ zero ที่จ่าย \$1 ในปีที่ 1 ที่ปีที่ 1 มันจ่าย \$1 ทุกจุด ที่จุดครึ่งปีมันเหลืออีกงวดเดียว ค่าเฉลี่ยของสองลูกคือ 1 ราคาจึงเป็น $e^{-r\Delta t}$ ของจุดนั้น จากนั้นถอยมาวันนี้อีกงวดด้วยกฎเดิม ในสูตร $Z_{\rm up}$ คือราคาที่จุดบนของครึ่งปี (อัตรา 6%) และ $Z_{\rm down}$ คือราคาที่จุดล่าง (อัตรา 4%) ตัวเลขทั้งหมดคือสีส้มในรูปแรก

\[ \begin{aligned} Z_{\rm up}&=e^{-0.06\times0.5}=0.970446,\\ Z_{\rm down}&=e^{-0.04\times0.5}=0.980199,\\ Z_0&=e^{-0.05\times0.5}\\ &\quad\times\tfrac12(0.970446+0.980199)\\ &=0.975310\times0.975322\\ &=0.951241. \end{aligned} \]

ต้นไม้นี้บอกว่า \$1 ที่จ่ายในปีที่ 1 มีค่าวันนี้ 0.951241 ถ้าตลาดซื้อขายของชิ้นนี้ที่ราคาอื่น ต้นไม้นี้ยังเอาไปตั้งราคาอะไรไม่ได้ ต้องปรับจนราคาตรงกันก่อน

มีเรื่องเล็ก ๆ ซ่อนอยู่ในตัวคูณ 0.975322 มันคือค่าเฉลี่ยของ discount factor สองตัว คือ $e^{-0.06\times0.5}=e^{-0.03}$ ของจุด 6% และ $e^{-0.04\times0.5}=e^{-0.02}$ ของจุด 4% ค่าเฉลี่ยนี้สูงกว่า discount factor ของอัตราเฉลี่ย 5% เล็กน้อย: $\tfrac12(e^{-0.03}+e^{-0.02})=0.975322\gt e^{-0.025}=0.975310$ เหตุผลคือกราฟของ $e^{-x}$ โค้งหงาย ค่าเฉลี่ยของฟังก์ชันโค้งหงายจึงมากกว่าค่าของฟังก์ชันที่จุดเฉลี่ยเสมอ (Jensen's inequality) ความต่างนี้จะกลับมาตอน calibrate ยิ่งอัตรากระจายกว้าง discount factor เฉลี่ยยิ่งสูง ระดับของอัตราในต้นไม้จึงต้องขยับขึ้นเล็กน้อยเพื่อให้ราคาเท่าเดิม

ขั้นที่ 3 — state price: ราคาของ \$1 ที่จ่ายเฉพาะจุดเดียว

การเดินย้อนต้องทำใหม่ทุกครั้งที่เปลี่ยนสัญญา ถ้าต้องตั้งราคาหลายสัญญาบนต้นไม้เดียวกัน มีทางลัด คือหาราคาวันนี้ของตั๋วใบหนึ่งที่จ่าย \$1 ถ้าต้นไม้ไปถึงจุด $(n,j)$ และจ่ายศูนย์ถ้าไปที่อื่น ราคานี้เรียกว่า state price เขียนว่า $Q_{n,j}$ วันนี้ $Q_{0,0}=1$ เพราะ \$1 วันนี้มีค่า \$1

หา $Q$ ของชั้นถัดไปจากชั้นนี้ได้อย่างไร ตั๋วที่จ่ายที่จุด $(n+1,s)$ มีค่าที่ชั้น $n$ เฉพาะที่จุดพ่อแม่สองจุดที่มีกิ่งมาถึงมัน ที่พ่อแม่จุดหนึ่งซึ่งมีอัตรา $r$ ตั๋วนี้มีค่า $\tfrac12e^{-r\Delta t}$ คือน้ำหนักครึ่งหนึ่งของกิ่งนั้น คูณการคิดลดหนึ่งงวด แล้วคูณ state price ของพ่อแม่ และบวกทั้งสองพ่อแม่ เพราะ $j$ นับจากบนลงล่าง จุด $(n+1,s)$ จึงมาจาก $(n,s)$ ด้วยการลง และมาจาก $(n,s-1)$ ด้วยการขึ้น ส่วน $Q_{1,\cdot}$ แปลว่าทั้งสองจุดของชั้น 1 ซึ่งมีค่าเท่ากัน

\[ \begin{aligned} Q_{n+1,s}&=\tfrac12Q_{n,s-1}e^{-r_{n,s-1}\Delta t}\\ &\quad+\tfrac12Q_{n,s}e^{-r_{n,s}\Delta t},\\ Q_{1,\cdot}&=\tfrac12\times1\times e^{-0.05\times0.5}\\ &=0.487655,\\ Q_{2,0}&=\tfrac12(0.487655)\\ &\quad\times e^{-0.06\times0.5}\\ &=0.236621,\\ Q_{2,2}&=\tfrac12(0.487655)\\ &\quad\times e^{-0.04\times0.5}\\ &=0.238999,\\ Q_{2,1}&=0.236621+0.238999\\ &=0.475621,\\ \textstyle\sum_sQ_{2,s}&=0.951241. \end{aligned} \]

จุดกลางของปีที่ 1 มาได้สองทาง คือขึ้นแล้วลง หรือลงแล้วขึ้น สองทางมีค่าไม่เท่ากัน เพราะคิดลดด้วยอัตราของพ่อแม่คนละจุด (6% หรือ 4%) จึงต้องบวกทั้งสองทาง ทางที่ผ่านพ่อแม่บนมีค่าเท่ากับ $Q_{2,0}$ พอดี เพราะพ่อแม่บนส่งค่าให้ลูกสองจุดเท่ากัน ทางที่ผ่านพ่อแม่ล่างก็เท่ากับ $Q_{2,2}$ ด้วยเหตุผลเดียวกัน สูตรนี้คำนวณจากซ้ายไปขวา คือจากวันนี้ไปอนาคต จึงเรียกว่า forward equations

state price รวมทั้งน้ำหนัก $q$ และการคิดลดไว้ในตัวแล้ว จึงไม่ใช่โอกาส ผลบวกของชั้นปีที่ 1 คือ 0.951241 ไม่ใช่ 1 ผลบวกนี้มีความหมาย ถ้าถือตั๋วครบทั้งสามใบ ก็ได้ \$1 แน่นอนในปีที่ 1 ซึ่งก็คือ zero ปีที่ 1 และตัวเลขนี้ตรงกับขั้นที่ 2 ทุกหลัก สองวิธีเดินคนละทิศแต่ได้ตัวเลขเดียวกัน นี่คือการตรวจที่สำคัญที่สุดของต้นไม้ เมื่อมี state price แล้ว สัญญาที่จ่ายเงิน $X_j$ ที่จุด $j$ ของชั้น $n$ มีราคาวันนี้ $V_0=\sum_jQ_{n,j}X_j$

ขั้นที่ 4 — คำตอบของโจทย์เปิดหน้า: call บน zero-coupon bond

ตอนนี้มีเครื่องมือครบแล้ว กลับไปตอบนักลงทุนในโจทย์เปิดหน้า

โจทย์ให้อะไรมาบ้าง:

  • call หมดอายุปีที่ 1 บน zero ที่ครบกำหนดปีที่ 1.5 หน้าตั๋ว $N=\$1{,}000{,}000$ strike $K=0.975$ ต่อ \$1
  • ที่ปีที่ 1 พันธบัตรเหลืออายุครึ่งปี และอัตราของครึ่งปีนั้นรู้แล้วที่แต่ละจุด ราคาพันธบัตรที่จุด $j$ จึงเป็น $P_{2,j}=e^{-r_{2,j}\times0.5}$
  • state price ของสามจุดปีที่ 1 ได้จากขั้นที่ 3 คือ 0.236621, 0.475621 และ 0.238999

คำนวณสามอย่างตามลำดับ อย่างแรกคือราคาพันธบัตรที่แต่ละจุด อย่างที่สองคือเงินที่สิทธิ์จ่าย $X_{2,j}=N(P_{2,j}-K)^+$ เครื่องหมาย $(x)^+$ แปลว่า $\max(x,0)$ คือถ้าติดลบให้เป็นศูนย์ เพราะผู้ถือจะไม่ใช้สิทธิ์ อย่างที่สามคือคูณ state price แล้วบวก ราคาพันธบัตรใช้ทศนิยม 8 ตำแหน่ง เพราะพอคูณ $10^6$ ทศนิยมหลักที่ 7 และ 8 จะกลายเป็นหลักเซนต์

\[ \begin{aligned} P_{2,0}&=e^{-0.07\times0.5}=0.96560542,\\ P_{2,1}&=e^{-0.05\times0.5}=0.97530991,\\ P_{2,2}&=e^{-0.03\times0.5}=0.98511194,\\ X_{2,0}&=10^6(0.96560542-0.975)^+\\ &=0,\\ X_{2,1}&=10^6(0.97530991-0.975)^+\\ &=309.91,\\ X_{2,2}&=10^6(0.98511194-0.975)^+\\ &=10{,}111.94,\\ V_0&=\textstyle\sum_jQ_{2,j}X_{2,j}\\ &=0.236621\times0\\ &\quad+0.475621\times309.91\\ &\quad+0.238999\times10{,}111.94\\ &=147.40+2{,}416.75\\ &=2{,}564.15. \end{aligned} \]

คำตอบ: สิทธิ์นี้ราคา \$2,564.15 เงิน $X$ เป็นเงินที่จ่ายในปีที่ 1 และ state price ย้ายมันมาเป็นเงินวันนี้ในขั้นเดียว ไม่ต้องคิดลดซ้ำอีก วิธีอัตรากลางตัวเดียวของเพื่อนได้ $309.91\times0.951241=\$294.80$ ต่ำไปเกือบเก้าเท่า เพราะมูลค่าเกือบทั้งหมด (\$2,416.75) มาจากจุดอัตรา 3% ซึ่งอัตรากลางมองไม่เห็น

ตรวจเองใน 10 วินาที: ก้อนใหญ่มาจากจุด 3% เงินที่จ่ายที่นั่นราว $10^6(0.9851-0.975)\approx10{,}100$ ดอลลาร์ คูณ state price ราว 0.24 ได้ $10{,}100\times0.24\approx\$2{,}400$ ใกล้กับ \$2,416.75

ขั้นที่ 5 — Ho–Lee: ปรับระดับทีละชั้นให้ตรง curve ของตลาด

ต้นไม้ที่ผ่านมาเราตั้งอัตราเอง ราคา zero ที่ได้จึงเป็นตัวเลขตามใจเรา ต้นไม้ที่ใช้งานจริงต้องให้ราคา zero ตรงกับตลาดทุกอายุ ราคาของตลาดคือ discount factor $D(0,t)$ ซึ่งแกะได้จากราคาพันธบัตรวันนี้ และชุดของมันทุกอายุเรียกว่า curve

Ho–Lee วางอัตราในชั้น $n$ ด้วยสองส่วน ส่วนแรกคือระดับ $\alpha_n$ ที่เลื่อนทั้งชั้นขึ้นลงพร้อมกัน ส่วนที่สองคือระยะ $x_{n,j}$ ที่ทำให้จุดติดกันในชั้นเดียวกันห่างกันเท่ากัน คือ $2\sigma\sqrt{\Delta t}$ โดย $\sigma$ คือความผันผวนของอัตราที่ตั้งไว้ก่อน ตัวที่ไม่รู้จึงมีแค่ $\alpha_n$ ชั้นละหนึ่งตัว

เงื่อนไขที่ใช้หา $\alpha_n$ มาจาก state price zero ที่ครบกำหนดชั้น $n+1$ จ่าย \$1 ทุกจุดของชั้นนั้น ที่จุด $j$ ของชั้น $n$ มันจึงมีค่า $e^{-r_{n,j}\Delta t}$ คูณด้วย state price แล้วบวกทุกจุด ได้ราคาวันนี้ ซึ่งต้องเท่ากับ $D(0,t_{n+1})$ ของตลาด

\[ \begin{aligned} r_{n,j}&=\alpha_n+x_{n,j},\\ x_{n,j}&=(n-2j)\,\sigma\sqrt{\Delta t},\\ D(0,t_{n+1})&=\sum_jQ_{n,j}e^{-r_{n,j}\Delta t}\\ &=e^{-\alpha_n\Delta t}H_n,\\ H_n&=\sum_jQ_{n,j}e^{-x_{n,j}\Delta t},\\ \alpha_n&=-\frac{1}{\Delta t}\ln\frac{D(0,t_{n+1})}{H_n}. \end{aligned} \]

ทำไมแก้ได้ง่าย เพราะ $\alpha_n$ เลื่อนทุกจุดในชั้นเท่ากัน ตัวคูณ $e^{-\alpha_n\Delta t}$ จึงเหมือนกันทุกพจน์ และดึงออกนอกผลบวกได้ ส่วนที่เหลือในผลบวกเรียกว่า $H_n$ ซึ่งรู้ค่าแล้ว จึงเหลือสมการเดียว ตัวไม่รู้เดียว แก้ด้วย log ได้ตรง ๆ แต่ละชั้นต้องใช้ state price ของชั้นก่อน จึงแก้จากชั้นแรกไปชั้นหลังทีละชั้น แบบเดียวกับ bootstrapping ของ curve

ต้นไม้ของโจทย์เปิดหน้าก็คือ Ho–Lee ที่ $\alpha_n=5\%$ ทุกชั้น และ $\sigma\sqrt{0.5}=1\%$ หรือ $\sigma=0.01/\sqrt{0.5}=1.4142\%$ ต่อ √ปี ตรวจได้: ชั้นที่ 2 มี $x_{2,j}=(2-2j)\times1\%$ คือ $+2\%,\ 0,\ -2\%$ บวก 5% ได้ 7%, 5% และ 3% ตรงกับรูปแรก

หนังสือบางเล่มเขียน Ho–Lee อีกแบบ คือ $r_{i,j}=a_i+b_ij$ โดยให้ $j$ นับจำนวนครั้งที่ขึ้น แบบนี้มีพารามิเตอร์ $a_i$ และ $b_i$ ชั้นละสองตัว รวม $2n$ ตัวสำหรับ $n$ ชั้น มองจากจุดพ่อแม่ อัตราที่ชั้น $i$ มีสองค่าห่างกัน $b_i$ แต่ละค่ามีน้ำหนักครึ่งหนึ่ง SD (standard deviation) ของอัตรางวดเดียวจึงเป็น $b_i/2$

ลองกับ curve จริงกว่านี้ curve นี้คือ discount factor ของ 0.5, 1, 1.5 และ 2 ปี ที่แกะจากราคา note ในหน้า zero rate, forward และ bootstrapping ตารางเทียบ $\alpha_n$ ที่ได้เมื่อไม่มีความผันผวน ($\sigma=0$) กับเมื่อ $\sigma=1\%$ ต่อ √ปี:

เมื่อ $\sigma=0$ ทุกจุดในชั้นเดียวกันมีอัตราเท่ากัน เพราะ $x=0$ ทุกจุด $H_n$ จึงเป็นแค่ผลบวกของ state price ชั้น $n$ ซึ่งเท่ากับ $D(0,t_n)$ สูตรจึงเหลือ $\alpha_n=-\ln\big(D(0,t_{n+1})/D(0,t_n)\big)/\Delta t$ ซึ่งก็คือ forward rate ครึ่งปีของ curve เช่น $\alpha_1=-\ln(0.9505/0.9755)/0.5=5.1924\%$ ต้นไม้ที่ไม่มีการกระจายจึงเป็นแค่ forward rate เรียงกัน

เมื่อใส่ความผันผวน $\alpha_n$ สูงกว่า forward 0.1, 0.5 และ 1.1 bp (1 bp คือ 0.01 จุด) ยิ่งชั้นไกล อัตรายิ่งกระจายกว้าง ส่วนต่างจึงยิ่งโต เหตุผลคือเรื่องโค้งหงายในขั้นที่ 2 อัตราที่กระจายทำให้ discount factor เฉลี่ยสูงขึ้น ระดับจึงต้องขยับขึ้นมาชดเชยให้ราคาเท่าเดิม

ขั้นที่ 6 — BDT: วางอัตราแบบคูณ อัตราจึงเป็นบวกเสมอ

Ho–Lee ให้จุดติดกันห่างกันเป็นจำนวนจุดคงที่ ถ้าอัตราต่ำอยู่แล้ว จุดล่างก็ติดลบได้ เช่น 0.5% ลบ 1 จุดได้ −0.5% Black–Derman–Toy (BDT) แก้ปัญหานี้ด้วยการให้ log ของอัตราห่างกันคงที่แทน ตัวอัตราจึงห่างกันเป็นสัดส่วน (คูณกัน) และเป็นบวกเสมอ

ตัวอย่าง BDT ในขั้นนี้ใช้งวดละ 1 ปี และคิดดอกเบี้ยทบงวดละครั้ง คือ \$1 ที่จ่ายปลายงวดมีค่าต้นงวด $1/(1+r)$ ตั้งแต่ขั้นนี้ไป ให้ $j$ นับจำนวนครั้งที่ขึ้น ($j=0$ คืออัตราต่ำสุด ต่างจากขั้นก่อน) อัตราที่จุด $(i,j)$ คือ $r_{i,j}=a_ie^{bj}$ โดย $a_i$ คืออัตราต่ำสุดของชั้น $i$ และ $b$ คือระยะห่างของ log อัตราระหว่างจุดติดกัน จุดติดกันจึงมีอัตราต่างกัน $e^b$ เท่า

เป้าหมายคือหา $a_i$ ทีละชั้น ให้ราคา zero ตรงกับ spot rate ของตลาด spot rate $s_{i+1}$ คืออัตราทบปีละครั้งที่ตลาดให้กับเงินที่ฝากไว้ $i+1$ ปี ดังนั้น \$1 ในปีที่ $i+1$ มีค่าวันนี้ $1/(1+s_{i+1})^{i+1}$ ของที่รู้:

  • เส้น spot ของตัวอย่าง (สมมติ) สำหรับ 1 ถึง 10 ปี คือ 7.30, 7.62, 8.10, 8.45, 9.20, 9.64, 10.12, 10.45, 10.75 และ 11.22%
  • ตั้ง $b=0.005$ ไว้ก่อน
  • ชั้น 0 มีจุดเดียว อัตราของมันจึงต้องเท่ากับ spot 1 ปีพอดี $a_0=s_1=7.30\%$

สูตรด้านล่างคือเงื่อนไขทั่วไป ตามด้วยการแก้หา $a_1$ เป็นตัวอย่าง $Q_{1,\cdot}$ คือ state price ของแต่ละจุดในปีที่ 1 คือน้ำหนักครึ่งหนึ่ง คูณการคิดลดหนึ่งปีด้วย 7.30%

\[ \begin{aligned} r_{i,j}&=a_ie^{bj},\quad a_i\gt 0,\\ \frac{1}{(1+s_{i+1})^{i+1}}&=\sum_j\frac{Q_{i,j}}{1+a_ie^{bj}},\\ Q_{1,\cdot}&=\frac{1}{2\times1.073}\\ &=0.465983,\\ \frac{1}{1.0762^2}&=0.465983\Big[\frac{1}{1+a_1}\\ &\qquad+\frac{1}{1+a_1e^{0.005}}\Big],\\ a_1&=7.9211\%. \end{aligned} \]

ฝั่งซ้ายของสมการ $a_1$ คือราคาตลาดของ \$1 ในปีที่ 2 คือ $1/1.0762^2=0.863404$ ฝั่งขวาคือราคาเดียวกันที่ต้นไม้คำนวณ แก้ได้ $a_1=7.9211\%$ จุดบนของชั้นนี้จึงเป็น $7.9211\%\times e^{0.005}=7.9608\%$ ทำต่อแบบเดียวกันทีละชั้นได้ $a_2=9.0212\%$, $a_3=9.4357\%$ และ $a_4=12.1302\%$

ทำไมมีคำตอบเดียวเสมอ ฝั่งขวาลดลงเมื่อ $a_i$ เพิ่ม เพราะอัตราสูงขึ้น การคิดลดก็มากขึ้น ที่ $a_i=0$ ฝั่งขวาเท่ากับ $\sum_jQ_{i,j}$ ซึ่งคือราคา zero ที่ครบกำหนดชั้น $i$ และเมื่อ $a_i$ โตมาก ฝั่งขวาลงไปหาศูนย์ ถ้าราคาตลาดอยู่ระหว่างสองค่านี้ คือ zero ที่ไกลกว่าถูกกว่า zero ที่ใกล้กว่า ก็มีคำตอบบวกตัวเดียว หาได้ด้วย bisection (แบ่งครึ่งช่วงคำตอบซ้ำ ๆ) หรือ Solver ใน Excel ทีละชั้น ไม่ต้องแก้ทุกชั้นพร้อมกัน

ขั้นที่ 7 — ต้นไม้ตัวอย่างมาตรฐาน: เริ่ม 6% ขึ้นคูณ 1.25 ลงคูณ 0.9

ขั้นที่ 7 ถึง 9 ใช้ต้นไม้ตัวอย่างที่สอนกันแพร่หลาย (จากสไลด์เรื่อง term structure lattice ของ Haugh และ Iyengar ที่ Columbia) เพื่อตั้งราคาสัญญาหลายแบบบนต้นไม้เดียวกัน ตัวเลขเป็นตัวเลขฝึก ไม่ได้ calibrate กับตลาด ของที่กำหนด:

  • short rate วันนี้ $r_{0,0}=6\%$ ต่องวด คิดลดแบบทบงวดละครั้ง คือหารด้วย $1+r$
  • ทุกงวด อัตราคูณ 1.25 (ขึ้น) หรือคูณ 0.9 (ลง) น้ำหนักครึ่งต่อครึ่ง
  • $j$ นับจำนวนครั้งที่ขึ้น จุด $(i,j)$ คือขึ้น $j$ ครั้งและลง $i-j$ ครั้ง

งานแรกคือตั้งราคา zero หน้าตั๋ว \$100 ที่ครบกำหนดงวดที่ 4 ด้วยการเดินย้อน สองรูปถัดไปแสดงอัตราและราคาของทุกจุด สูตรด้านล่างแสดงสองจุดเป็นตัวอย่าง คือจุด $(2,2)$ ซึ่งขึ้นสองครั้ง และจุดวันนี้ ตัวเลข 92.22, 89.51, 84.43 และ 79.27 คือราคาของจุดลูก อ่านได้จากรูปราคา zero

\[ \begin{aligned} r_{i,j}&=0.06(1.25)^j(0.9)^{i-j},\\ Z_{i,j}&=\frac{\tfrac12Z_{i+1,j}+\tfrac12Z_{i+1,j+1}}{1+r_{i,j}},\\ r_{2,2}&=0.06(1.25)^2=0.09375,\\ Z_{2,2}&=\frac{\tfrac12(92.22)+\tfrac12(89.51)}{1.09375}\\ &=83.08,\\ Z_{0,0}&=\frac{\tfrac12(84.43)+\tfrac12(79.27)}{1.06}\\ &=77.22,\\ s_4&=(100/77.22)^{1/4}-1\\ &=6.68\%. \end{aligned} \]

ต้นไม้นี้ recombine เพราะขึ้นแล้วลงกับลงแล้วขึ้นให้อัตราเท่ากัน: $1.25\times0.9=0.9\times1.25$ ราคา 77.22 บอกว่าเงิน \$77.22 วันนี้โตเป็น \$100 ในสี่งวด อัตราทบต่องวดที่ทำแบบนั้นได้คือ spot rate $s_4$ ซึ่งแก้จาก $100/(1+s_4)^4=77.22$ ได้ 6.68%

ตรวจด้วย state price ได้เหมือนขั้นที่ 3 แค่เปลี่ยนตัวคิดลด $e^{-r\Delta t}$ เป็น $1/(1+r)$ state price ของชั้นที่ 4 (อัตราต่ำไปสูง) คือ 0.051113, 0.199247, 0.290089, 0.186842 และ 0.044887 ผลบวกคือ 0.772178 คูณ 100 ได้ 77.22 ตรงกับการเดินย้อน

ทำแบบเดียวกันทุกอายุ ได้ spot ของ 1 ถึง 5 งวดเป็น 6.00, 6.22, 6.45, 6.68 และ 6.91% short rate ตัวเดียวจึงให้ทั้งเส้น ถ้าพรุ่งนี้อัตราย้ายไปอยู่จุดใหม่ ราคา zero ชุดใหม่ก็ให้เส้นใหม่ แบบจำลองของ short rate จึงเป็นแบบจำลองของ term structure ทั้งเส้น (term structure คือ spot rate ของทุกอายุ)

ต้นไม้แบบคูณนี้ไม่มี mean reversion คือไม่มีแรงที่ดึงอัตราสูงให้ลงและดึงอัตราต่ำให้ขึ้น อัตราจึงลอยไปได้ไกล จุดบนสุดของงวดที่ 5 คือ $6\%\times1.25^5=18.31\%$ ต้นไม้นี้จึงใช้ฝึกวิธีคิด ไม่ใช่ใช้งานจริง

ต้นไม้นี้ยังแสดงว่า cash account ปลอดภัยแค่ทีละงวด บัญชีที่ฝาก \$1 แล้วทบด้วย short rate คือ $B_t=(1+r_0)(1+r_1)\cdots(1+r_{t-1})$ ที่งวดที่ 2 บัญชีเป็น $1.06\times1.075=1.1395$ ถ้างวดแรกขึ้น หรือ $1.06\times1.054=1.11724$ ถ้างวดแรกลง ตอนต้นงวดเรารู้ว่างวดนั้นจะได้เท่าไร แต่มองไกลสองงวดยังไม่รู้

ขั้นที่ 8 — option บนพันธบัตร: call แบบยุโรป และ put แบบอเมริกัน

มีต้นไม้และราคา zero ครบแล้ว ต่อไปคือ option บน zero ตัวนี้ ซึ่งต้องเดินย้อนบนต้นไม้เหมือนกัน

โจทย์ให้อะไรมาบ้าง: ของที่สิทธิ์อ้างอิงคือ zero 4 งวดในรูปด้านบน มีสองสัญญา:

  • call แบบยุโรป strike 84 หมดอายุงวดที่ 2 ราคา zero ที่งวดที่ 2 คือ 90.64, 87.35 และ 83.08 (อัตราต่ำไปสูง)
  • put แบบอเมริกัน strike 88 หมดอายุงวดที่ 3 put คือสิทธิ์ขายในราคา strike แบบอเมริกันใช้สิทธิ์ได้ทุกงวดจนถึงวันหมดอายุ ราคา zero ที่งวดที่ 3 คือ 95.81, 94.27, 92.22 และ 89.51
  • short rate ที่ใช้คิดลด: งวดที่ 0 คือ 6% งวดที่ 1 คือ $6\%\times0.9=5.4\%$ และ $6\%\times1.25=7.5\%$

call ใช้การเดินย้อนตามปกติ ส่วน put ต้องตัดสินใจที่ทุกจุดว่าจะใช้สิทธิ์เลยหรือถือต่อ ใช้สิทธิ์เลยได้ $88-Z_{t,j}$ ถือต่อได้ $H_{t,j}$ ซึ่งคือมูลค่าจากการเดินย้อนหนึ่งงวด ผู้ถือเลือกทางที่ได้มากกว่า ค่าในสูตรเรียงจากอัตราต่ำไปสูง

\[ \begin{aligned} C_{2,\cdot}&=(Z_{2,\cdot}-84)^+\\ &=6.64,\ 3.35,\ 0,\\ C_{1,0}&=\tfrac12(6.64+3.35)/1.054\\ &=4.74,\\ C_{1,1}&=\tfrac12(3.35+0)/1.075\\ &=1.56,\\ C_0&=\tfrac12(4.74+1.56)/1.06\\ &=2.97,\\ P_{t,j}&=\max(88-Z_{t,j},\ H_{t,j}),\\ P_{3,\cdot}&=0,\ 0,\ 0,\ 0,\\ P_{2,\cdot}&=0,\ 0.65,\ 4.92,\\ P_{1,\cdot}&=3.57,\ 8.73,\\ P_{0}&=\max(88-77.22,\ 5.80)\\ &=10.78. \end{aligned} \]

คำตอบ: call ราคา 2.97 มูลค่ามาจากจุดอัตราต่ำ เพราะที่นั่นพันธบัตรแพงกว่า strike put อเมริกันราคา 10.78 และควรใช้สิทธิ์ทันทีวันนี้ เพราะใช้เลยได้ $88-77.22=10.78$ ส่วนถือต่อได้แค่ $\tfrac12(3.57+8.73)/1.06=5.80$

ทำไม put ควรใช้สิทธิ์เร็วขนาดนี้ ดูงวดที่ 3: zero ทุกจุดราคาเกิน 88 put ที่รอถึงงวดที่ 3 จึงได้ศูนย์ทุกจุด put แบบยุโรป (ใช้สิทธิ์ได้แค่งวดที่ 3) ที่ strike เดียวกันจึงมีค่าศูนย์ ราคา 10.78 ทั้งก้อนมาจากสิทธิ์ใช้ก่อนกำหนด ที่จุดอัตรา 9.375% ของงวดที่ 2 ก็ใช้สิทธิ์เหมือนกัน เพราะ $88-83.08=4.92$ มากกว่าการถือต่อซึ่งได้ศูนย์ ผลแบบนี้มาจากตัวเลขที่เลือกมาให้ฝึก ไม่ใช่สิ่งที่พบบ่อยในตลาด

ตรวจเองใน 10 วินาที: ที่จุดอัตรา 7.5% ของงวดที่ 1 ถ้าถือ put ต่อได้ $\tfrac12(0.65+4.92)/1.075=2.59$ น้อยกว่าใช้สิทธิ์เลย $88-79.27=8.73$ จึงใช้สิทธิ์ ตรงกับ $P_{1,1}=8.73$

ขั้นที่ 9 — forward กับ futures บนพันธบัตรเดียวกันไม่เท่ากัน

forward และ futures เป็นสัญญาซื้อของในอนาคตในราคาที่ตกลงวันนี้ทั้งคู่ ต่างกันที่วิธีจ่ายเงิน

  • forward: ตกลงราคา $G_0$ วันนี้ วันเซ็นไม่มีใครจ่ายอะไร ผู้ซื้อจ่าย $G_0$ และรับของครั้งเดียวตอนส่งมอบ
  • futures: ราคา $F_k$ ถูกประกาศใหม่ทุกงวด ทุกปลายงวดผู้ซื้อได้รับเงินสด $F_{k+1}-F_k$ (ถ้าติดลบก็ต้องจ่าย) และเข้าสัญญาได้ฟรีทุกงวด

ของที่ส่งมอบคือพันธบัตรคูปองบนต้นไม้ 6% เดิม พันธบัตรนี้หน้าตั๋ว 100 จ่ายคูปอง (ดอกเบี้ยรายงวด) 10 ทุกงวด และครบกำหนดงวดที่ 6 การส่งมอบเกิดที่งวดที่ 4 หลังจ่ายคูปองงวดที่ 4 ไปแล้ว ราคาพันธบัตรตอนส่งมอบ $S_4$ หาได้จากการเดินย้อนจากงวดที่ 6 (งวดที่ 6 จ่าย $100+10=110$) ได้ห้าค่า 111.16, 108.00, 103.83, 98.44 และ 91.66 (อัตราต่ำไปสูง)

ราคาที่ยุติธรรมของทั้งสองสัญญาคือราคาที่ทำให้สัญญามีค่าศูนย์ตอนเข้า แต่เงื่อนไข “มีค่าศูนย์” ของสองสัญญาต่างกัน จึงได้สองสูตร ในสูตร $\mathbb E^{\mathbb Q}_k[\cdot]$ คือค่าเฉลี่ยถ่วงด้วยน้ำหนัก $q$ บนต้นไม้เมื่อมองจากงวด $k$ และการหารด้วย cash account $B$ คือการคิดลดตามเส้นทางที่อัตราเดินจริง

\[ \begin{aligned} 0&=\mathbb E^{\mathbb Q}_0\Big[\frac{S_4-G_0}{B_4}\Big],\\ G_0&=\frac{\mathbb E^{\mathbb Q}_0[S_4/B_4]}{\mathbb E^{\mathbb Q}_0[1/B_4]}\\ &=\frac{79.83}{0.7722}=103.38,\\ 0&=\mathbb E^{\mathbb Q}_k\Big[\frac{F_{k+1}-F_k}{B_{k+1}}\Big],\\ F_k&=\mathbb E^{\mathbb Q}_k[F_{k+1}],\quad F_4=S_4,\\ F_0&=\tfrac12(105.64+100.81)\\ &=103.22. \end{aligned} \]

forward: $G_0$ รู้ตั้งแต่วันนี้ จึงดึงออกจากค่าเฉลี่ยแล้วย้ายข้างได้ ตัวบนคือราคาวันนี้ของการได้รับ $S_4$ ที่งวดที่ 4 หาได้ด้วยการเดินย้อน $S_4$ บนต้นไม้ ได้ 79.83 ตัวล่างคือราคาวันนี้ของ \$1 ที่งวดที่ 4 ซึ่งก็คือ zero 4 งวดหารด้วยหน้าตั๋ว $77.22/100=0.7722$

futures: $B_{k+1}$ รู้ตั้งแต่งวด $k$ เพราะอัตราของงวดนั้นรู้ตั้งแต่ต้นงวด จึงคูณออกได้ เหลือ $F_k$ เท่ากับค่าเฉลี่ยธรรมดาของสองลูก ไม่มีการคิดลด เริ่มจาก $F_4=S_4$ แล้วเฉลี่ยถอยทีละชั้น เช่น $\tfrac12(111.16+108.00)=109.58$ ได้งวดที่ 3 เป็น 109.58, 105.91, 101.14, 95.05 งวดที่ 2 เป็น 107.75, 103.52, 98.09 และงวดที่ 1 เป็น 105.64, 100.81

การเฉลี่ยซ้อนกันสี่ชั้นแบบนี้ เท่ากับการเฉลี่ยครั้งเดียวด้วยน้ำหนักของทุกเส้นทาง (tower property: ค่าเฉลี่ยของค่าเฉลี่ยแบบมีเงื่อนไขคือค่าเฉลี่ยเดิม) จึงได้ $F_0=\mathbb E^{\mathbb Q}_0[S_4]$ ตรวจทางตรงได้ จุดที่ขึ้น $j$ ครั้งจากสี่งวดมี $\binom4j$ เส้นทาง น้ำหนักจึงเป็น 1, 4, 6, 4 และ 1 ส่วน 16:

\[\begin{aligned}F_0&=\tfrac1{16}\big[111.16+4(108.00)\\&\quad+6(103.83)+4(98.44)\\&\quad+91.66\big]\\&=1{,}651.56/16=103.22.\end{aligned}\]

สองราคาต่างกัน $103.38-103.22=0.16$ เพราะอัตรากับราคาพันธบัตรเดินสวนกัน วันที่พันธบัตรขึ้นคือวันที่อัตราลง ผู้ซื้อ futures ได้กำไรในวันนั้น แต่เอากำไรไปฝากได้ดอกเบี้ยต่ำ วันที่พันธบัตรลงคือวันที่อัตราขึ้น ผู้ซื้อต้องหาเงินมาจ่ายขาดทุนตอนที่เงินกู้แพง ผู้ซื้อ futures จึงเสียเปรียบเล็กน้อย ราคา futures ที่ยุติธรรมจึงต้องต่ำกว่า forward ถ้าอัตราไม่สุ่ม สองราคานี้จะเท่ากัน ซึ่งเป็นสิ่งที่หน้า mark-to-market ของ futures สมมติไว้

ขั้นที่ 10 — fit curve ได้พอดี ยังไม่ได้บอกอะไรเรื่องความผันผวน

ขั้นที่ 5 และ 6 ตั้ง $\sigma$ หรือ $b$ ไว้ก่อน แล้วแก้หาระดับของแต่ละชั้น คำถามที่เหลือคือ $\sigma$ หรือ $b$ ควรเป็นเท่าไร ราคา zero ช่วยตอบได้ไหม ลองทำ BDT กับเส้น spot เดิมของขั้นที่ 6 สองครั้ง ครั้งแรก $b=0.005$ ครั้งที่สอง $b=0.01$ แล้วเทียบระดับที่ได้ แถวสุดท้ายคือเงื่อนไขที่ทั้งสองต้นไม้ทำให้จริงทุกชั้น คือผลบวกของ state price ชั้น $i+1$ เท่ากับราคาตลาดของ \$1 ในปีที่ $i+1$

\[ \begin{aligned} b=0.005&:\ a_1=7.9211\%,\\ &\quad\ a_2=9.0212\%,\\ b=0.01&:\ a_1=7.9013\%,\\ &\quad\ a_2=8.9760\%,\\ \textstyle\sum_jQ_{i+1,j}&=(1+s_{i+1})^{-(i+1)}. \end{aligned} \]

ทั้งสองต้นไม้ให้ราคา zero ทั้งสิบอายุตรงตลาดทุกตัว เพราะระดับ $a_i$ ปรับตามจนราคาตรงทุกครั้ง สิ่งที่ต่างคือความกว้างของการกระจาย $a_i$ คืออัตราของจุดล่างสุด เมื่อ $b=0.01$ อัตรากระจายกว้างกว่า จุดล่างสุดจึงต่ำกว่า ราคา zero จึงไม่บอกอะไรเลยเรื่องความผันผวน แต่ราคา option ไวต่อความผันผวนมาก ในหน้า swaption ของต้นไม้ BDT สองต้นนี้ให้ราคา swaption (สิทธิ์ที่จะเข้าทำ swap ในอนาคต) \$1,339 กับ \$1,962 ห่างกัน $1{,}962/1{,}339=1.47$ เท่า

งานจริงจึงต้อง calibrate กับราคา option ด้วย ให้ $\theta$ คือชุดพารามิเตอร์ทั้งหมด (ระดับและความผันผวนของทุกชั้น) แล้วเลือก $\theta$ ที่ทำให้ราคาจากแบบจำลองห่างจากราคาตลาดน้อยที่สุด:

\[\begin{aligned}\min_\theta\ &\textstyle\sum_kw_k\big(V_k(\theta)-V_k^{\rm mkt}\big)^2\\&+\lambda\lVert\theta-\theta_{\rm prev}\rVert^2.\end{aligned}\]

$V_k(\theta)$ คือราคาของตราสารตัวที่ $k$ จากแบบจำลอง $V_k^{\rm mkt}$ คือราคาตลาดของมัน และ $w_k$ คือน้ำหนักที่บอกว่าตราสารไหนสำคัญ พจน์สุดท้ายคือโทษที่ไม่ให้ $\theta$ กระโดดไปไกลจากค่าของเมื่อวาน $\theta_{\rm prev}$ โดย $\lambda$ คุมว่าลงโทษแรงแค่ไหน ตราสารที่ใช้ต้องมี option ที่ซื้อขายคล่อง เช่น cap (สัญญาที่จ่ายเงินเมื่ออัตราสูงกว่าเพดาน) และ swaption และควรคล้ายกับของที่จะตั้งราคา

ปัญหานี้ไม่ใช่ convex จึงมีจุดต่ำสุดเฉพาะที่หลายจุด และต้อง calibrate ใหม่หลายครั้งต่อวัน ถ้าแบบจำลองถูกจริง calibrate ครั้งเดียวก็พอ การที่ต้องทำซ้ำบอกว่าไม่มีแบบจำลองไหนถูก งานตั้งราคาอนุพันธ์จึงเป็นการเดาราคาที่มองไม่เห็นจากราคาที่เห็น (interpolate และ extrapolate) โดยไม่เปิดช่องให้ได้เงินฟรี (ดู สูตร calibration ที่ใช้งานจริง)

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ใช้อัตรากลางตัวเดียวตั้งราคา option: option จ่ายเงินแบบหักมุม จึงต้องใช้ทุกจุดของต้นไม้ ไม่ใช่แค่จุดกลาง ในโจทย์เปิดหน้า วิธีผิดได้ $309.91\times0.951241=\$294.80$ วิธีถูกได้ $\sum_jQ_{2,j}X_{2,j}=\$2{,}564.15$

ลืมเส้นทางที่สองของจุดกลาง: จุดกลางต้องรับค่าจากพ่อแม่ทั้งสอง ถ้านับแค่ทางจากพ่อแม่บน จะได้ $Q_{2,1}=0.236621$ แทนที่จะเป็น $0.236621+0.238999=0.475621$ ผลบวกของชั้นเหลือ $0.236621+0.236621+0.238999=0.712241$ แทน 0.951241 และราคา call เหลือ $0.236621\times309.91+2{,}416.75=\$2{,}490.08$ แทน \$2,564.15

คิดลดซ้ำหลังคูณ state price: state price เป็นราคาวันนี้อยู่แล้ว คิดลดอีกรอบจะได้ $2{,}564.15\times0.951241=\$2{,}439.12$ ต่ำไป $2{,}564.15-2{,}439.12\approx\$125$

อ่าน state price เป็นโอกาส: ผลบวกของชั้นปีที่ 1 คือราคา zero 0.951241 ไม่ใช่ 1 ถ้าหารด้วยผลบวกนี้เพื่อให้เป็นโอกาส จะได้ 0.24875, 0.5 และ 0.25125 ค่าเฉลี่ยของเงินที่จ่ายด้วยน้ำหนักนี้คือ $0.5\times309.91+0.25125\times10{,}111.94=\$2{,}695.58$ ซึ่งเป็นเงินปีที่ 1 ถ้าตอบตัวเลขนี้ก็ผิด ต้องคูณ discount factor กลับเข้าไป $2{,}695.58\times0.951241=\$2{,}564.15$

เชื่อว่า fit curve ได้แล้วราคา option จะถูก: ราคา zero ไม่บอกความผันผวน ต้นไม้ BDT ที่ $b=0.005$ และ $b=0.01$ ให้ราคา zero ตรงตลาดเท่ากันทุกอายุ แต่ให้ราคา swaption \$1,339 กับ \$1,962

ใช้ Ho–Lee ตอนอัตราต่ำโดยไม่ตรวจ: ระยะห่างคงที่ทำให้จุดล่างติดลบได้ ที่อัตรา 0.5% กับระยะ 1 จุด จุดล่างคือ $0.5-1=-0.5\%$ ส่วน BDT ให้ $0.5\times e^{-0.2}=0.409\%$ ถ้าสัญญาขึ้นกับอัตราใกล้ศูนย์ ต้องดูว่าอัตราติดลบเป็นไปได้จริงในตลาดนั้นหรือไม่

2. สมมติว่านักลงทุนในโจทย์เปิดหน้าถือ put (สิทธิ์ขาย) แทน call โดย strike ยังเป็น 0.975 ต่อ \$1 และหน้าตั๋วยังเป็น \$1,000,000 put ราคาเท่าไร? และตรวจคำตอบด้วย put–call parity (ความสัมพันธ์ระหว่างราคา call กับ put ที่ strike เดียวกัน) อย่างไร?

เฉลย

put จ่ายเงินเมื่อพันธบัตรถูกกว่า strike ซึ่งเกิดแค่ที่จุดอัตรา 7%:

\[\begin{aligned}X^{\rm put}&=10^6(0.975-0.96560542)\\&=9{,}394.58,\\V_0^{\rm put}&=0.236621\times9{,}394.58\\&=\$2{,}222.96.\end{aligned}\]

ตรวจด้วย parity ที่ทุกจุด call ลบ put จ่าย $N(P-K)$ พอดี เพราะถ้า $P\gt K$ call จ่ายส่วนต่างและ put จ่ายศูนย์ ถ้า $P\lt K$ กลับกัน มูลค่าวันนี้ของ $N\cdot P$ คือ $N$ คูณราคา zero 1.5 ปี (0.92780147 จากข้อ 1) และมูลค่าวันนี้ของ $N\cdot K$ คือ $NK$ คูณราคา zero 1 ปี (0.95124131):

\[\begin{aligned}V^{\rm call}-V^{\rm put}&=10^6(0.92780147)\\&\quad-0.975(10^6)(0.95124131)\\&=927{,}801.47-927{,}460.28\\&=341.19,\\2{,}564.15-2{,}222.96&=341.19.\end{aligned}\]

สองทางได้ \$341.19 ตรงกัน

const {exp, log, sqrt, max} = Math;

// One-period discount at a node: continuous e^(-r dt), or per-period 1 / (1 + r) when dt is null.
const disc = (r, dt) => dt === null ? 1 / (1 + r) : exp(-r * dt);
// Forward equations for state prices with q = 1/2: node j of layer n + 1 has parents j - 1 and j.
function statePrices(rates, dt) {
  const Q = [[1]];
  rates.forEach((layer, n) => {
    const next = Array(n + 2).fill(0);
    layer.forEach((r, j) => { const v = Q[n][j] * 0.5 * disc(r, dt); next[j] += v; next[j + 1] += v; });
    Q.push(next);
  });
  return Q;
}
// Backward induction from layer `from` to 0, keeping every layer; `early(n, j, hold)` may replace the holding value.
function backward(rates, dt, terminal, from, early = (n, j, h) => h) {
  const layers = [terminal];
  for (let n = from - 1; n >= 0; n--) {
    const V = layers[0];
    layers.unshift(rates[n].map((r, j) => early(n, j, disc(r, dt) * 0.5 * (V[j] + V[j + 1]))));
  }
  return layers;
}
// Ho-Lee: r = alpha_n + (n - 2j) sigma sqrt(dt); alpha_n solved so layer n reprices D(0, t_{n+1}).
function hoLee(D, sigma, dt) {
  let Q = [1]; const alpha = [], rates = [];
  D.forEach((target, n) => {
    const x = Q.map((_, j) => (n - 2 * j) * sigma * sqrt(dt));
    const H = Q.reduce((s, q, j) => s + q * exp(-x[j] * dt), 0);
    const a = -log(target / H) / dt;
    alpha.push(a); rates.push(x.map(v => a + v));
    Q = statePrices(rates, dt)[n + 1];
  });
  return alpha;
}
// BDT with per-period compounding: r = a_i e^(b j); a_i by bisection so layer i reprices the spot curve.
function bdt(spot, b) {
  let Q = [1]; const a = [];
  spot.forEach((s, i) => {
    const target = 1 / (1 + s) ** (i + 1);
    const f = ai => Q.reduce((sum, q, j) => sum + q / (1 + ai * exp(b * j)), 0) - target;
    let lo = 0, hi = 1;
    for (let k = 0; k < 200; k++) { const m = (lo + hi) / 2; if (f(m) > 0) lo = m; else hi = m; }
    const ai = (lo + hi) / 2; a.push(ai);
    const next = Array(i + 2).fill(0);
    Q.forEach((q, j) => { const v = q / (2 * (1 + ai * exp(b * j))); next[j] += v; next[j + 1] += v; });
    Q = next;
  });
  return a;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ต้นไม้ของ short rate คิดลดทีละงวดด้วยอัตราของแต่ละจุด ราคาหาได้สองทาง คือเดินย้อนจากวันครบกำหนด หรือคูณ state price แล้วบวก สองทางต้องได้ตัวเลขเดียวกัน เช่น zero ปีที่ 1 ได้ 0.951241 ทั้งคู่
  • state price คือราคาวันนี้ของ \$1 ที่จ่ายเฉพาะจุดเดียว รวมน้ำหนักและการคิดลดไว้แล้ว จึงไม่ใช่โอกาส ผลบวกของแต่ละชั้นคือราคา zero และจุดกลางต้องรวมค่าจากทุกเส้นทาง
  • option บนพันธบัตรต้องใช้อัตราทุกทางที่เป็นไปได้ ในโจทย์เปิดหน้าราคาที่ถูกคือ \$2,564.15 ส่วนอัตรากลางตัวเดียวได้แค่ \$294.80
  • Ho–Lee และ BDT ปรับระดับของแต่ละชั้นให้ราคา zero ตรงตลาด ชั้นละหนึ่งสมการ หนึ่งตัวไม่รู้ ถ้าไม่มีความผันผวน ระดับของ Ho–Lee คือ forward rate ของ curve พอดี Ho–Lee ให้อัตราติดลบได้ BDT ไม่ได้
  • บนต้นไม้ 6%: zero 4 งวดราคา 77.22, call ราคา 2.97, put อเมริกันราคา 10.78 และควรใช้สิทธิ์ทันที, forward 103.38 สูงกว่า futures 103.22 เพราะอัตราสุ่มและเดินสวนกับราคาพันธบัตร
  • การทำให้ราคา zero ตรงตลาดไม่ได้กำหนดความผันผวน ต้อง calibrate กับราคา option ด้วย
