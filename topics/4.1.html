4.1 What a Matrix Is

ตารางตัวเลขทำหน้าที่เป็นเครื่องแปลงข้อมูล

เครื่องผสมสีรับสีแดง 2 หน่วยกับน้ำเงิน 3 หน่วย ตารางตัวเลข 2 × 2 จะบอกสูตรผสมของ output ทั้งสองช่องได้อย่างไร?

เฉลย: อ่านทีละแถว แต่ละแถวบอกว่า output ช่องนั้นหยิบ input แต่ละสีมาเท่าไร ตารางนี้จึงเป็นกติกาแปลงของเข้าเป็นของออก ไม่ใช่กล่องเก็บเลข

กติกาแบบนี้เรียกว่า matrix ใช้แปลง vector หนึ่งเป็นอีก vector หนึ่ง และรวมหลายสมการไว้ให้ตรวจพร้อมกัน

matrix คือเครื่องปั่น ไม่ใช่ตู้เก็บเลข—ก่อนกดต้องรู้ว่าใส่อะไรและแต่ละปุ่มทำอะไร งาน quant ใช้มันรวม exposure กับข้อมูล risk หลายตัว

row
แนวนอนหนึ่งแถวของ matrix ใช้แทน observation, asset หรือ output ชุดหนึ่งตามความหมายของ model
column
แนวตั้งหนึ่งคอลัมน์ของ matrix ใช้แทน feature, factor หรือ position dimension หนึ่งชุด
element
ตัวเลขหนึ่งช่องที่อยู่ตรงจุดตัดของ row กับ column ใช้เป็น factor loading เฉพาะคู่ที่กำลังอ่าน
exposure
จำนวน sensitivity หรือ notional ที่ portfolio มีต่อ asset หรือ factor ใช้รวม risk และคำนวณ hedge
notional
มูลค่าอ้างอิงของ position ซึ่งไม่จำเป็นต้องเท่ากับเงินสดที่จ่าย ใช้กำหนดขนาด trade และคำนวณ exposure
hedge
position ที่ตั้งใจให้หักล้าง risk ของ position อื่น ใช้ลด exposure ที่ desk ไม่ต้องการถือ
factor
ตัวแปรร่วมที่ขับเคลื่อน returns ของหลาย assets เช่น market หรือ quality ใช้สรุป risk ที่ position หลายตัวรับร่วมกัน

USD

คำตอบ — factor exposure 2.25 กับ 0.95

คำตอบmarket exposure เท่ากับ 2.25 USD million และ quality exposure เท่ากับ 0.95 USD million จาก matrix ที่มี assets 3 rows กับ factors 2 columns

ตรวจเองใน 10 วินาทีคูณ แยกทีละ factor แล้วต้องได้ vector สองค่า 2.25 และ 0.95 USD million; ถ้าได้สามค่า แปลว่าวาง matrix ผิดด้าน

ใช้ตัดสินใจ: ส่ง factor report ได้เมื่อ asset order ของ matrix ตรงกับ position vector ทุกแถว ถ้า engineer เปลี่ยนลำดับ rows แต่ไม่เปลี่ยน ให้ reject แม้โปรแกรมจะไม่ขึ้น error

ระวังตรงนี้

กับดัก: มอง matrix เป็นถุงตัวเลข

อย่าทิ้งชื่อ row, ชื่อ column หรือหน่วยไว้ใน metadata เพราะตัวเลข 1.2 USD million กับ 1.2 shares ไม่ใช่ quantity เดียวกัน ก่อนคูณให้เช็ก shape และ label alignment เสมอ

สรุปที่ใช้ได้จริง

  • matrix คือ table ที่เก็บความสัมพันธ์ของ rows กับ columns ไม่ใช่ list แบน ๆ
  • shape บอกจำนวน rows และ columns และช่วยป้องกัน dimension error
  • row aggregation กับ column aggregation ตอบคำถามคนละแบบ
  • ใน risk engine ต้องเก็บ labels และ units คู่กับ numbers
