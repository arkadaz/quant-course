4.1 Filtrations and the Definition of a Martingale

Martingale คือกระบวนการที่ค่าเฉลี่ยของอนาคต เมื่อรู้ทุกอย่างถึงวันนี้แล้ว เท่ากับค่าของวันนี้พอดี

ทีมที่ตั้งราคาสัญญาบนหุ้นต้องตอบคำถามเดียวกันทุกวัน: รู้ราคาย้อนหลังถึงวันนี้แล้ว ค่าเฉลี่ยของราคาในอนาคตอยู่ตรงไหน ก่อนจะไปถึงหุ้น ลองตอบคำถามนี้กับเกมที่ง่ายที่สุดก่อน คือเกมโยนเหรียญ (สมมติ)

กติกาของเกม:

  • เริ่มด้วยเงิน \$100
  • โยนเหรียญรอบละครั้ง ออกหัวได้ \$10 ออกก้อยเสีย \$10
  • เหรียญยุติธรรม หัวกับก้อยมีโอกาสอย่างละครึ่ง และผลแต่ละรอบไม่ขึ้นกับรอบก่อน

เล่นไปแล้วสามรอบ ออก หัว หัว ก้อย ยอดเงินจึงเดินเป็น \$100 → \$110 → \$120 → \$110 ตอนนี้มีเงิน \$110

ถ้าเล่นต่ออีกสี่รอบ ควรคาดยอดเงินตอนจบไว้ที่ \$100 ซึ่งเป็นทุนตั้งต้น หรือ \$110 ซึ่งมีอยู่ตอนนี้ และยอดจริงอาจไปได้ไกลแค่ไหน

ลองตอบก่อนเปิดเฉลย

คาดไว้ที่ \$110 ไม่ใช่ \$100 เพราะสามรอบที่ผ่านไปเกิดขึ้นแล้ว มันเป็นข้อเท็จจริง ไม่ใช่สิ่งที่ต้องเดา ส่วนแต่ละรอบข้างหน้าได้หรือเสียเฉลี่ยเป็นศูนย์

\[\tfrac12(+10)+\tfrac12(-10)=0\]

สี่รอบข้างหน้าจึงไม่ขยับค่าเฉลี่ยเลย แต่ยอดจริงขยับได้มาก ถ้าออกก้อยหมดหรือออกหัวหมด ยอดจะเป็น

\[\begin{aligned}110-4\times10&=\$70\\110+4\times10&=\$150\end{aligned}\]

ยอดจะกลับมาที่ \$110 พอดีก็ต่อเมื่อออกหัวสองครั้งจากสี่ครั้ง ซึ่งเกิดได้ 6 แบบจากทั้งหมด $2^4=16$ แบบ โอกาสจึงเป็น $6/16=37.5\%$ ด้านล่างจะนับให้ดูครบทุกแบบ ค่าเฉลี่ยที่ไม่ขยับจึงไม่ได้แปลว่าเงินไม่ขยับ

ภาพรวมก่อนลงสูตร

คำตอบ \$110 มาจากความคิดสองข้อ

ข้อแรกคือข้อมูลสะสม หลังรอบที่ 3 เรารู้ผลสามรอบแรกแล้ว และจะไม่ลืมมัน แต่ยังไม่รู้ผลรอบที่ 4 ข้อมูลที่โตขึ้นทุกรอบและไม่เคยหายแบบนี้มีชื่อเรียกว่า filtration

ข้อสองคือค่าเฉลี่ยแบบมีเงื่อนไข (conditional expectation) เราเฉลี่ยเฉพาะส่วนที่ยังไม่รู้ ส่วนที่รู้แล้วถือเป็นตัวเลขธรรมดา ในเกมนี้ \$110 คือส่วนที่รู้แล้ว สี่รอบข้างหน้าคือส่วนที่ต้องเฉลี่ย

ถ้าค่าเฉลี่ยของก้าวถัดไปเท่ากับค่าวันนี้เสมอ ไม่ว่าจะยืนอยู่วันไหนและประวัติเป็นแบบไหน เราเรียกกระบวนการนั้นว่า martingale มันคือ “เกมยุติธรรม” ในภาษาคณิตศาสตร์ ถ้าค่าเฉลี่ยของก้าวถัดไปสูงกว่าค่าวันนี้ เรียกว่า submartingale ถ้าต่ำกว่า เรียกว่า supermartingale

รูปด้านล่างสรุปทั้งหน้าในภาพเดียว ฝั่งซ้ายคืออดีตที่รู้แล้ว มีเส้นเดียว ฝั่งขวาคืออนาคตที่ยังเป็นไปได้ 16 เส้นทาง หน้านี้เดินตามลำดับนี้

  • ตกลงให้ชัดว่า ณ แต่ละรอบรู้อะไรแล้ว (filtration)
  • ตรวจทีละก้าวว่าเกมเหรียญเป็น martingale แล้วต่อหนึ่งก้าวเป็นหลายก้าวด้วย tower property (กฎที่ว่าเฉลี่ยซ้อนสองชั้นได้ผลเท่ากับเฉลี่ยชั้นเดียว)
  • ตรวจต้นไม้ราคาหุ้น (แบบจำลองที่ราคาแตกเป็นสองทางทุกงวด) ทุกจุดแยก
  • จบที่เหตุผลว่าทำไมการตั้งราคา option (สัญญาที่ให้สิทธิ์ซื้อหรือขายหุ้นในราคาที่ตกลงไว้) ต้องเลือกโอกาสชุดพิเศษ ชุดที่ทำให้ราคาหุ้นหลังคิดลดเป็น martingale คิดลดคือหารด้วยดอกเบี้ยที่เงินจะงอกขึ้นในช่วงนั้น เพื่อแปลงเงินในอนาคตกลับเป็นเงินวันนี้
ศัพท์ที่ใช้ในหัวข้อนี้
Filtration $(\mathcal F_n)$
ข้อมูลทั้งหมดที่รู้ ณ เวลา $n$ ข้อมูลนี้โตขึ้นตามเวลาและไม่เคยหาย ใช้ตอบให้ชัดว่า ตอนตัดสินใจ เรารู้อะไรแล้วบ้าง
Adapted
ค่า $X_n$ คำนวณได้จากข้อมูลถึงเวลา $n$ เท่านั้น ไม่แอบใช้ข้อมูลอนาคต ใช้ตรวจว่า backtest (การลองกลยุทธ์กับข้อมูลย้อนหลัง) ไม่มี look-ahead คือไม่ได้ใช้ข้อมูลที่ตอนนั้นยังไม่มีใครรู้
Conditional expectation $\mathbb E_n[Y]$
ค่าเฉลี่ยของ $Y$ เมื่อรู้ข้อมูลถึงเวลา $n$ แล้ว คำตอบขึ้นกับว่าประวัติจริงเป็นแบบไหน ก่อนเห็นประวัติ คำตอบจึงยังเป็นตัวแปรสุ่ม มันคือคำพยากรณ์ที่ดีที่สุด ในความหมายว่าค่าเฉลี่ยของความคลาดเคลื่อนยกกำลังสองต่ำที่สุด
Integrable
$\mathbb E\big[|X_n|\big]$ มีค่าจำกัด แปลว่าขนาดเฉลี่ยของค่านี้ไม่ใหญ่ไม่สิ้นสุด ต้องมีข้อนี้ก่อน ค่าเฉลี่ยจึงมีความหมาย
Martingale
กระบวนการที่ adapted, integrable และค่าเฉลี่ยของก้าวถัดไป เมื่อรู้ข้อมูลถึงวันนี้ เท่ากับค่าวันนี้ ใช้เป็นแบบจำลองของเกมยุติธรรม และของราคาหุ้นหลังหักผลของดอกเบี้ยเวลาตั้งราคาอนุพันธ์
Drift
ทิศและขนาดที่ค่าเฉลี่ยขยับในแต่ละก้าว martingale ไม่มี drift ส่วนหุ้นที่คาดว่าจะขึ้นวันละ 60 เซนต์มี drift ขึ้น
Submartingale และ supermartingale
ค่าเฉลี่ยของก้าวถัดไปไม่ต่ำกว่า (sub) หรือไม่สูงกว่า (super) ค่าวันนี้ บอกว่า drift ชี้ขึ้นหรือชี้ลง เช่นเกมที่โดนเก็บค่าธรรมเนียมทุกรอบเป็น supermartingale
อนุพันธ์ (derivative) และ payoff
อนุพันธ์คือสัญญาที่มูลค่าขึ้นกับราคาของอย่างอื่น เช่น option บนหุ้น payoff คือเงินที่สัญญาจ่ายตอนครบกำหนด
คิดลด (discount)
แปลงเงินในอนาคตกลับเป็นมูลค่าวันนี้ โดยหารด้วยตัวคูณดอกเบี้ย เช่น \$1.0002 พรุ่งนี้มีค่าเท่ากับ $1.0002/1.0002=\$1$ วันนี้ เมื่อดอกเบี้ยวันละ 0.02%
Arbitrage
ช่องทางได้กำไรแน่นอนโดยไม่ต้องใช้เงินตัวเองและไม่มีทางขาดทุน ตลาดที่ทำงานปกติไม่ควรมีช่องแบบนี้ค้างอยู่
Risk-neutral probability $Q$
ชุดโอกาสที่ใช้ตั้งราคา ไม่ใช่โอกาสจริง เราเลือกมันให้ราคาหุ้นหลังคิดลดเป็น martingale แล้วใช้หาราคาอนุพันธ์ว่าเท่ากับค่าเฉลี่ยของ payoff หลังคิดลด

ขั้นที่ 1 — ตกลงก่อนว่า ณ เวลา $n$ รู้อะไร

ในเฉลยของคำถามเปิด เราถือว่า “หัว หัว ก้อย” เป็นของที่รู้แล้ว คำว่า “ค่าเฉลี่ยของอนาคต” จะมีความหมายก็ต่อเมื่อบอกให้ชัดว่าตอนนี้รู้อะไรแล้ว ขั้นนี้จึงตั้งชื่อให้ของที่รู้

  • $C_i$ คือผลเหรียญรอบที่ $i$ ให้ $C_i=+1$ เมื่อออกหัว และ $C_i=-1$ เมื่อออกก้อย
  • $\mathcal F_n$ คือข้อมูลที่รู้หลังจบรอบที่ $n$ ในเกมนี้คือผล $C_1,\ldots,C_n$ ครบทุกตัว
  • $X_n$ คือยอดเงินหลังจบรอบที่ $n$ เริ่มที่ \$100 แล้วบวก \$10 คูณผลเหรียญทุกรอบที่ผ่านมา
\[ \begin{aligned} X_n&=100+10\sum_{i=1}^{n}C_i\\ X_3&=100+10(1+1-1)=110\\ \mathbb E_n[Y]&=\mathbb E[Y\mid\mathcal F_n] \end{aligned} \]

สูตรยอดเงินใช้ผลเหรียญแค่ถึงรอบที่ $n$ ไม่มี $C_{n+1}$ อยู่ในสูตรเลย ดังนั้นพอจบรอบที่ $n$ เราก็รู้ $X_n$ ได้ทันที ไม่ต้องรออนาคต สมบัตินี้มีชื่อว่า adapted ถ้าแทนเส้นทางจริง หัว หัว ก้อย ($C_1=C_2=+1$, $C_3=-1$) ก็ได้ \$110 ตรงกับคำถามเปิด

ส่วน $\mathbb E_n[Y]$ เป็นแค่ชื่อย่อของ “ค่าเฉลี่ยของ $Y$ เมื่อรู้ข้อมูลถึงรอบที่ $n$” โดย $Y$ คืออะไรก็ได้ที่ยังสุ่มอยู่ เช่นยอดเงินในรอบหน้า ชื่อย่อนี้จะใช้ตลอดหน้านี้

ทำไมเรียกว่า filtration (แปลตรงตัวคือการกรอง) รูปด้านล่างตอบได้ เหรียญสามรอบมีเส้นทางที่เป็นไปได้ $2^3=8$ แบบ ก่อนโยน เราแยกแปดแบบนี้ไม่ออกเลย ทุกครั้งที่เห็นเหรียญหนึ่งรอบ กลุ่มเส้นทางที่ยังเป็นไปได้ถูกกรองให้เล็กลง ข้อมูลจึงโตขึ้นและไม่เคยหาย สิ่งที่รู้ ณ รอบที่ 2 ยังรู้อยู่ ณ รอบที่ 3 เสมอ แนวคิดเดียวกันใช้กับเวลาที่ไหลต่อเนื่องในหน้า filtration ในเวลาต่อเนื่อง ซึ่งเขียนเป็น $\mathcal F_t$

ขั้นที่ 2 — ค่าเฉลี่ยหนึ่งก้าว: แยกสิ่งที่รู้ออกจากสิ่งที่ยังสุ่ม

คำถามเปิดถามล่วงหน้าสี่รอบ ซึ่งยากเกินไปสำหรับก้าวแรก เราจึงถามแค่หนึ่งรอบก่อน: ยืนอยู่หลังรอบที่ $n$ ค่าเฉลี่ยของยอดเงินรอบหน้าเป็นเท่าไร ยอดรอบหน้าแยกได้เป็นสองส่วน คือยอดตอนนี้ $X_n$ ซึ่งรู้แล้ว บวกผลของเหรียญที่ยังไม่โยน $10\,C_{n+1}$ ซึ่งยังสุ่มอยู่

\[ \begin{aligned} X_{n+1}&=X_n+10\,C_{n+1}\\ \mathbb E_n[X_{n+1}]&=X_n+10\,\mathbb E_n[C_{n+1}]\\ &=X_n+10\,\mathbb E[C_{n+1}]\\ &=X_n+10\big(\tfrac12-\tfrac12\big)\\ &=X_n \end{aligned} \]

ความคิดทั้งหมดคือ ค่าเฉลี่ยของยอดรอบหน้า เท่ากับยอดตอนนี้ บวกค่าเฉลี่ยของสิ่งที่ยังสุ่ม และสิ่งที่ยังสุ่มเฉลี่ยเป็นศูนย์ เราดึง $X_n$ ออกมานอกค่าเฉลี่ยได้ตรง ๆ เพราะหลังรอบที่ $n$ มันเป็นตัวเลขที่รู้แล้ว การเฉลี่ยตัวเลขที่รู้แล้วได้ตัวมันเอง ท่านี้ชื่อ taking out what is known (ดึงสิ่งที่รู้แล้วออกมา) จากหน้า tower property

จุดที่ต้องหยุดดูคือการเปลี่ยน $\mathbb E_n[C_{n+1}]$ เป็น $\mathbb E[C_{n+1}]$ ซึ่งแปลว่า “รู้ประวัติแล้วก็ไม่ช่วยเดาเหรียญรอบหน้า” ข้อนี้จริงเพราะกติกาบอกว่าเหรียญแต่ละรอบไม่ขึ้นกับรอบก่อน ถ้าเกมมี momentum (ผลล่าสุดมีแนวโน้มเกิดซ้ำ) เช่นออกหัวแล้วรอบหน้ามีโอกาสหัว 60% ขั้นนี้จะพังทันที เพราะหลังออกหัว ค่าเฉลี่ยของเหรียญรอบหน้าจะเป็น $0.6(+1)+0.4(-1)=0.2$ ไม่ใช่ศูนย์

ลองตรวจด้วยตัวเลขที่ยอด \$110 รอบหน้าเป็น \$120 หรือ \$100 อย่างละครึ่ง ค่าเฉลี่ยคือ $\tfrac12(120)+\tfrac12(100)=110$ ยอดจริงไม่มีทางเป็น 110 ในรอบหน้า แต่จุดสมดุลของสองค่านี้คือ 110

ขั้นที่ 3 — นิยาม martingale ให้ครบสามข้อ

ผลหนึ่งก้าวที่เพิ่งได้คือหัวใจของ martingale แต่นิยามเต็มมีอีกสองเงื่อนไขที่คนมักลืม เราจึงเขียนให้ครบตรงนี้ กระบวนการ $(X_n)$ เป็น martingale เทียบกับข้อมูล $(\mathcal F_n)$ และชุดโอกาส $P$ เมื่อผ่านครบสามข้อ

  • $X_n$ adapted คือรู้ค่าได้จากข้อมูลถึงรอบที่ $n$ ข้อนี้เป็นเรื่องของข้อมูล จึงเขียนเป็นคำ ไม่มีสูตร
  • $X_n$ integrable คือขนาดเฉลี่ยมีค่าจำกัด (สูตรแถวบน)
  • ค่าเฉลี่ยของก้าวถัดไปเท่ากับค่าวันนี้ ในทุกรอบ $n$ (สูตรแถวล่าง)
\[ \begin{aligned} \mathbb E\big[|X_n|\big]&\lt\infty\\ \mathbb E_n[X_{n+1}]&=X_n \end{aligned} \]

แต่ละข้อกันความผิดคนละแบบ ข้อ adapted ห้ามแอบใช้อนาคต ข้อ integrable กันไม่ให้ค่าเฉลี่ยใหญ่ไม่สิ้นสุด ถ้าไม่มีข้อนี้ ค่าเฉลี่ยแบบมีเงื่อนไขอาจไม่มีอยู่จริง ส่วนข้อสุดท้ายบอกว่าเมื่อรู้ข้อมูลถึงวันนี้ ค่าเฉลี่ยไม่มี drift คือไม่ขยับไปทางไหนเลย

ทำไมต้องบอกชุดโอกาส $P$ ด้วย เพราะกระบวนการเดียวกันอาจเป็น martingale ใต้ชุดโอกาสหนึ่ง แต่ไม่เป็นใต้อีกชุด เรื่องนี้คือแก่นของการตั้งราคาในขั้นสุดท้ายของหน้านี้

เกมเหรียญผ่านครบสามข้อ $X_n$ เป็นสูตรของ $C_1,\ldots,C_n$ จึง adapted ยอดเงินขยับได้รอบละไม่เกิน \$10 จึงได้ $|X_n|\le100+10n$ ขนาดจึงจำกัดแน่นอน ส่วนข้อสุดท้ายคือการคำนวณหนึ่งก้าวที่เพิ่งทำ

ถ้าเปลี่ยนเครื่องหมายเท่ากับในแถวล่างเป็น $\ge$ จะได้ submartingale ถ้าเป็น $\le$ จะได้ supermartingale ส่วน martingale ก็คือกระบวนการที่เป็นทั้งสองแบบพร้อมกัน บางตำราเขียนข้อสุดท้ายเป็น $\mathbb E_n[X_{n+m}]=X_n$ สำหรับทุก $n$ และทุก $m\ge0$ ขั้นถัดไปจะแสดงว่าสองแบบนี้คือนิยามเดียวกัน

ทำไมต้อง integrable: กราฟสมมาตรยังไม่พอ

ข้อ integrable ดูเหมือนเป็นข้อเล็ก ตัวอย่างนี้แสดงว่ามันพังได้จริง ให้ $Y$ เป็นตัวแปรสุ่มที่มี density (ฟังก์ชันที่บอกว่าค่าแต่ละช่วงเกิดบ่อยแค่ไหน) แบบ Cauchy คือ $f(y)=1/\big(\pi(1+y^2)\big)$ กราฟนี้สมมาตรรอบศูนย์ เราจึงอยากตอบว่าค่าเฉลี่ยเป็นศูนย์ แต่ลองคำนวณขนาดเฉลี่ย $\mathbb E|Y|$ ดู ครึ่งซ้ายกับครึ่งขวาเท่ากัน จึงคิดแค่ครึ่งขวาแล้วคูณสอง

\[ \begin{aligned} \mathbb E|Y|&=\frac2\pi\int_0^\infty\frac{y}{1+y^2}\,dy\\ &=\frac1\pi\Big[\log(1+y^2)\Big]_0^\infty\\ &=\infty \end{aligned} \]

อินทิกรัลของ $y/(1+y^2)$ คือ $\tfrac12\log(1+y^2)$ (ลองหาอนุพันธ์กลับดูจะได้ตัวเดิม) เลข $\tfrac12$ นี้หักกับเลข 2 ข้างหน้า ทำไมได้อนันต์ เพราะ $\log(1+y^2)$ โตไปเรื่อย ๆ ไม่หยุดเมื่อ $y$ ใหญ่ขึ้น หางของ Cauchy บางลงช้าเกินไป ค่าใหญ่ ๆ จึงมาบ่อยพอที่จะดึงขนาดเฉลี่ยให้ใหญ่ไม่สิ้นสุด

ผลที่ตามมาคือ ครึ่งขวาของ $\mathbb E[Y]$ เป็น $+\infty$ และครึ่งซ้ายเป็น $-\infty$ อนันต์สองก้อนนี้หักกันเป็นศูนย์ไม่ได้ ถ้าตัดหางซ้ายกับขวาให้ยาวเท่ากันก็ได้ศูนย์ แต่ถ้าตัดไม่เท่ากันก็ได้ค่าอื่น ศูนย์จึงเป็นแค่ผลของวิธีตัด ไม่ใช่ค่าเฉลี่ย ดังนั้นผลรวมของก้าวแบบ Cauchy จะพิสูจน์ว่าเป็น martingale ด้วยเหตุผล “แต่ละก้าวเฉลี่ยศูนย์” ไม่ได้ (การแจกแจงหางหนาแบบนี้อยู่ในหน้า สวนสัตว์ของการแจกแจง)

ขั้นที่ 4 — จากหนึ่งก้าวเป็นหลายก้าวด้วย tower property

ตอนนี้เรารู้แค่ค่าเฉลี่ยของรอบถัดไป แต่คำถามเปิดถามล่วงหน้าสี่รอบ เราจะต่อหนึ่งก้าวเป็นหลายก้าวด้วยการเฉลี่ยซ้อนสองชั้น ชั้นในเฉลี่ยโดยแกล้งทำเป็นรู้ข้อมูลมากขึ้นอีกหนึ่งรอบ ชั้นนอกเฉลี่ยผลนั้นอีกทีด้วยข้อมูลที่มีจริงตอนนี้

\[ \begin{aligned} \mathbb E_n[X_{n+2}]&=\mathbb E_n\big[\mathbb E_{n+1}[X_{n+2}]\big]\\ &=\mathbb E_n[X_{n+1}]\\ &=X_n\\ \mathbb E_n[X_{n+m}]&=X_n\\ \mathbb E[X_n]&=\mathbb E[X_0] \end{aligned} \]

ท่าที่ต้องหยุดดูคือการแทรกค่าเฉลี่ยชั้นใน $\mathbb E_{n+1}$ เข้าไปใน $\mathbb E_n$ กฎ tower property บอกว่า ถ้าเอาคำพยากรณ์ที่ใช้ข้อมูลมากกว่า มาเฉลี่ยด้วยข้อมูลที่น้อยกว่า จะได้คำพยากรณ์ของข้อมูลที่น้อยกว่า ท่านี้ใช้ได้ก็เพราะ filtration ไม่เคยลืม ทุกอย่างที่รู้หลังรอบ $n$ ยังรู้อยู่หลังรอบ $n+1$ ข้อมูลชั้นนอกจึงเป็นส่วนหนึ่งของข้อมูลชั้นในเสมอ

พอแทรกแล้ว ที่เหลือคือใช้ผลหนึ่งก้าวสองครั้ง ครั้งแรกที่รอบ $n+1$ ได้ $\mathbb E_{n+1}[X_{n+2}]=X_{n+1}$ ครั้งที่สองที่รอบ $n$ ได้ $\mathbb E_n[X_{n+1}]=X_n$ ทำซ้ำแบบเดียวกัน $m$ ครั้งก็ได้ $\mathbb E_n[X_{n+m}]=X_n$ คำถามเปิดจึงตอบได้ทันทีด้วย $n=3$ และ $m=4$ คือ $\mathbb E_3[X_7]=X_3=110$

แถวสุดท้ายได้จากการยืนที่รอบ 0 แล้วมองไปข้างหน้า $n$ รอบ จะได้ $\mathbb E_0[X_n]=X_0$ จากนั้นเฉลี่ยทั้งสองข้างอีกชั้นหนึ่ง ข้างซ้ายกลายเป็น $\mathbb E[X_n]$ ด้วย tower property ความหมายคือ ค่าเฉลี่ยที่คิดก่อนเห็นอะไรเลย คงที่ทุกเวลา

แต่ทิศกลับไม่จริง ค่าเฉลี่ยรวมคงที่ทุกเวลา ยังไม่พอจะเป็น martingale ตัวอย่างเช่น ให้ $Z$ เป็น $+1$ หรือ $-1$ อย่างละครึ่ง แล้วตั้ง $X_0=0$, $X_1=Z$, $X_2=-Z$ ทุกเวลามีค่าเฉลี่ยศูนย์ เพราะ $\mathbb E[Z]=\tfrac12(+1)+\tfrac12(-1)=0$ แต่เมื่อเห็น $X_1=+1$ แล้ว เรารู้แน่ว่า $X_2=-1$ จึงได้ $\mathbb E_1[X_2]=-X_1$ ไม่ใช่ $X_1$ รูปด้านล่างวาดตัวอย่างนี้

ขั้นที่ 5 — ตรวจด้วยการนับทั้ง 16 เส้นทาง

tower property บอกว่า $\mathbb E_3[X_7]=110$ ขั้นนี้ไม่ใช้กฎใดเลย แต่นับทุกเส้นทางตรง ๆ เพื่อให้เห็นว่าไม่มีอะไรซ่อนอยู่ และได้เห็นด้วยว่ายอดจริงกระจายไปได้แค่ไหน

โจทย์ให้อะไรมาบ้าง:

  • ยอดตอนนี้ $X_3=110$ และเหลืออีกสี่รอบ
  • สี่รอบมีเส้นทางที่เป็นไปได้ $2^4=16$ เส้น แต่ละเส้นมีโอกาส $(\tfrac12)^4=\tfrac1{16}$
  • ถ้าออกหัว $k$ ครั้งจากสี่ครั้ง ก็ออกก้อย $4-k$ ครั้ง ยอดตอนจบคือ $110+10k-10(4-k)=70+20k$ ดังนั้น $k=0,1,2,3,4$ ให้ยอด 70, 90, 110, 130, 150
  • จำนวนเส้นทางที่ออกหัว $k$ ครั้ง คือจำนวนวิธีเลือก $k$ รอบจากสี่รอบ $\binom4k$ ได้ 1, 4, 6, 4, 1 ตาม binomial distribution
\[ \begin{aligned} \mathbb E_3[X_7]&=\tfrac{1}{16}\big[1(70)+4(90)+6(110)\\ &\qquad+4(130)+1(150)\big]\\ &=\tfrac{1}{16}(70+360+660\\ &\qquad+520+150)\\ &=\tfrac{1}{16}(1{,}760)=110\\ P_3(X_7=110)&=\tfrac{6}{16}=37.5\% \end{aligned} \]

แถวล่างของสูตรคือโอกาสที่ยอดจบที่ \$110 พอดี โดย $P_3$ อ่านว่า “โอกาสเมื่อรู้ข้อมูลถึงรอบที่ 3” เส้นทางที่จบที่ 110 มี 6 เส้นจาก 16 เส้น

คำตอบ: ค่าเฉลี่ยได้ \$110 ตรงกับที่ tower property บอก แต่ยอดจริงจบได้ตั้งแต่ \$70 ถึง \$150 และโอกาสที่ยอดจะไม่ใช่ \$110 คือ $1-0.375=62.5\%$ ค่าเฉลี่ยบอกจุดสมดุล ไม่ได้บอกว่าเงินจะอยู่ตรงนั้น

ตรวจเองใน 10 วินาที: ปลายทางเรียงสมมาตรรอบ 110 คือ 70 คู่กับ 150 และ 90 คู่กับ 130 แต่ละคู่มีน้ำหนักเท่ากัน ค่าเฉลี่ยของการแจกแจงที่สมมาตรคือจุดกึ่งกลางเสมอ เช่น $\tfrac12(70+150)=110$

ขั้นที่ 6 — เก็บค่าธรรมเนียมแล้วกลายเป็น supermartingale

เกมจริงไม่ค่อยยุติธรรม เพราะเจ้ามือต้องได้ส่วนแบ่ง สมมติเจ้ามือเก็บค่าธรรมเนียม \$1 ทุกรอบ หลัง $n$ รอบเราจ่ายไปแล้ว $1\times n=n$ ดอลลาร์ ยอดสุทธิจึงเป็น $Y_n=X_n-n$ คำถามเดิมต้องถามใหม่ ค่าเฉลี่ยของยอดสุทธิรอบหน้าอยู่ตรงไหน

\[ \begin{aligned} Y_{n+1}&=Y_n+10\,C_{n+1}-1\\ \mathbb E_n[Y_{n+1}]&=Y_n+0-1\\ &=Y_n-1\lt Y_n \end{aligned} \]

ยอดรอบหน้าคือยอดตอนนี้ บวกผลเหรียญ แล้วหักค่าธรรมเนียม ผลเหรียญยังเฉลี่ยศูนย์เหมือนเดิม จึงเหลือแค่ค่าธรรมเนียมที่หักแน่นอน ทุกก้าวจึงคาดว่ายอดจะลดลง \$1 จากที่ยืนอยู่ $Y_n$ จึงเป็น supermartingale

ชื่ออาจดูกลับด้าน วิธีจำคือดูว่าค่าวันนี้อยู่ตรงไหนเทียบกับค่าเฉลี่ยของพรุ่งนี้ supermartingale คือค่าวันนี้อยู่ “เหนือ” ($Y_n\ge\mathbb E_n[Y_{n+1}]$) ส่วน submartingale คือค่าวันนี้อยู่ “ใต้”

ระวังอย่างหนึ่ง “คาดว่าจะลด” ไม่ได้แปลว่าลดทุกเส้นทาง รอบที่ออกหัวยังได้สุทธิ $10-1=+\$9$ การจัดประเภทดูที่ทิศของค่าเฉลี่ยเมื่อรู้ข้อมูล ไม่ได้ดูว่าเส้นทางเส้นหนึ่งจบสูงหรือต่ำ รูปถัดไปแสดงเรื่องนี้ด้วยเส้นทางสุ่มจำนวนมาก

ขั้นที่ 7 — ต้นไม้ราคาสองงวด: ต้องผ่านทุกโหนด

ทีนี้เปลี่ยนจากเหรียญมาเป็นราคาหุ้น แบบจำลองราคาที่ง่ายที่สุดคือต้นไม้ราคา (binomial tree) ทุกงวดราคามีสองทาง ขึ้นหรือลง จุดแยกแต่ละจุดเรียกว่าโหนด (node) ในต้นไม้ “ทุกประวัติที่อาจเกิด” ก็คือทุกโหนด นิยาม martingale จึงต้องผ่านที่ทุกโหนด ผ่านแค่โหนดแรกยังไม่พอ

โจทย์ให้อะไรมาบ้าง: (ตัวเลขสมมติ)

  • ราคาเริ่มต้น $S_0=\$100$
  • แต่ละงวดราคาคูณด้วย $u=1.10$ (ขึ้น 10%) หรือ $d=0.95$ (ลง 5%)
  • ดอกเบี้ยเป็นศูนย์ ขั้นนี้จึงยังไม่ต้องคิดลด ขั้นถัดไปจะใส่ดอกเบี้ยเข้ามา
  • โอกาสขึ้น $p$ เท่ากันทุกโหนด ยังไม่รู้ค่า ต้องหาเอง

ราคาสองงวดได้จากการคูณต่อกัน งวดแรกได้ $100\times1.10=110$ หรือ $100\times0.95=95$ งวดที่สองได้

\[\begin{aligned}110\times1.10&=121\\110\times0.95&=104.5=95\times1.10\\95\times0.95&=90.25\end{aligned}\]

เงื่อนไข martingale ที่โหนดราคา $S$ คือ $p\,(uS)+(1-p)\,(dS)=S$ หารทั้งสองข้างด้วย $S$ จะเหลือ $pu+(1-p)d=1$ แปลว่าตัวคูณเฉลี่ยต้องเท่ากับ 1 กระจายวงเล็บแล้วจัดใหม่ได้ $p(u-d)=1-d$ จึงได้ $p=(1-d)/(u-d)$ สูตรด้านล่างแทนตัวเลขลงไป แล้วตรวจทั้งสามโหนด

\[ \begin{aligned} p(1.10)+(1-p)(0.95)&=1\\ p=\frac{1-0.95}{1.10-0.95}&=\frac13\\ \tfrac13(110)+\tfrac23(95)&=100\\ \tfrac13(121)+\tfrac23(104.5)&=110\\ \tfrac13(104.5)+\tfrac23(90.25)&=95 \end{aligned} \]

คำตอบ: $p=1/3$ ผ่านครบสามโหนด เพราะตัวคูณเฉลี่ยเป็น 1 ทุกโหนด ค่าเฉลี่ยของงวดหน้าจึงเท่ากับราคาที่ยืนอยู่เสมอ

ทีนี้ลองให้แต่ละโหนดใช้ตัวคูณไม่เหมือนกัน เปลี่ยนเฉพาะโหนดบน (ราคา 110) ให้คูณ 1.05 หรือ 0.95 ราคางวดที่สองจากโหนดนี้จะเป็น $110\times1.05=115.5$ หรือ $110\times0.95=104.5$ ถ้ายังใช้ $p=1/3$ เดิม

\[\begin{aligned}\tfrac13(115.5)+\tfrac23(104.5)&=38.5+69.67\\&\approx108.17\ne110\end{aligned}\]

โหนดแรก (100) กับโหนดล่าง (95) ยังผ่าน แต่โหนดบนไม่ผ่าน ทั้งต้นไม้จึงไม่เป็น martingale ถ้าจะให้โหนดบนผ่าน ต้องแก้ $pu+(1-p)d=1$ ใหม่ด้วยตัวคูณของโหนดนั้น ได้ $p=(1-0.95)/(1.05-0.95)=1/2$ โอกาสจึงต้องต่างกันไปตามโหนด

กลับกัน ถ้าต้นไม้เดิมใช้ $p=1/2$ ที่โหนดบน จะได้ $\tfrac12(121)+\tfrac12(104.5)=112.75\gt110$ ค่าเฉลี่ยสูงกว่าราคาที่ยืนอยู่ โหนดนั้นจึงมี drift ขึ้น

ตรวจเองใน 10 วินาที: ถ้าตัวคูณเฉลี่ย $pu+(1-p)d$ เท่ากับ 1 ค่าเฉลี่ยของงวดหน้าคือราคาวันนี้คูณ 1 ไม่ว่าราคาวันนี้เป็นเท่าไร

ขั้นที่ 8 — ราคาหุ้นไม่ใช่ martingale ใต้โอกาสจริง แต่ราคาที่คิดลดแล้วเป็นใต้ $Q$

ทำไมตลาดการเงินสนใจ martingale ขนาดนี้ เพราะการตั้งราคาอนุพันธ์ (สัญญาที่มูลค่าขึ้นกับราคาของอย่างอื่น เช่น option บนหุ้น) ทั้งหมดยืนอยู่บนมัน ขั้นนี้ใช้ต้นไม้หนึ่งวันของ SPY ซึ่งเป็นกองทุนที่ซื้อขายเหมือนหุ้นและวิ่งตามดัชนี S&P 500 (ดัชนีของหุ้นใหญ่ 500 ตัวในสหรัฐ)

ของที่รู้: (ตัวเลขสมมติ)

  • ราคาวันนี้ $S_0=\$570$
  • พรุ่งนี้ราคา $S_1$ ขึ้นไป \$576 หรือลงไป \$564
  • นักวิเคราะห์ประเมินว่าโอกาสขึ้นจริงคือ 0.55 โอกาสลงจึงเป็น $1-0.55=0.45$ ชุดโอกาสจริงนี้เรียกว่า $P$
  • ดอกเบี้ยเงินฝากราว 5% ต่อปี ปีหนึ่งมี 252 วันทำการ (วันที่ตลาดหุ้นสหรัฐเปิด) ดอกเบี้ยต่อวันจึงราว $0.05/252=0.000198\approx0.0002$ ตัวคูณดอกเบี้ยต่อวันคือ $R=1.0002$ แปลว่าเงิน \$1 วันนี้โตเป็น \$1.0002 พรุ่งนี้

เราจะถามสองข้อ ข้อแรก ใต้โอกาสจริง ราคา SPY เป็น martingale ไหม ข้อสอง ถ้าไม่เป็น มีชุดโอกาส $q$ ชุดอื่นไหมที่ทำให้ราคาพรุ่งนี้หลังคิดลด (หารด้วย $R$ เพื่อแปลงกลับเป็นเงินวันนี้) มีค่าเฉลี่ยเท่ากับราคาวันนี้ เงื่อนไขของข้อสองคือ $\big[q(576)+(1-q)(564)\big]/R=570$ คูณทั้งสองข้างด้วย $R$ แล้วแก้หา $q$

\[ \begin{aligned} \mathbb E^P[S_1]&=0.55(576)+0.45(564)\\ &=570.60\gt570\\ 570R&=q(576)+(1-q)(564)\\ q&=\frac{570R-564}{576-564}\\ &=\frac{570.114-564}{12}=0.5095\\ \mathbb E^Q\Big[\frac{S_1}{R}\Big]&=\frac{0.5095(576)+0.4905(564)}{1.0002}\\ &=\frac{570.114}{1.0002}=570 \end{aligned} \]

ข้อแรกตอบว่าไม่เป็น ใต้โอกาสจริง $P$ ค่าเฉลี่ยของราคาพรุ่งนี้สูงกว่าวันนี้ $570.60-570=\$0.60$ ราคาจึงมี drift ขึ้นวันละ 60 เซนต์ และเป็น submartingale ใต้ $P$ ซึ่งสมเหตุสมผล คนถือหุ้นรับความเสี่ยงว่าราคาอาจลง จึงต้องได้ผลตอบแทนเฉลี่ยมากกว่าเงินฝากเป็นค่าชดเชย

ข้อสองคือท่าหลักของการตั้งราคา เราไม่ได้ถามว่าโอกาสจริงคือเท่าไร แต่ถามกลับว่า ต้องใช้โอกาสเท่าไร ราคาหลังคิดลดจึงจะไม่มี drift เงินวันนี้ \$570 ถ้าฝากไว้หนึ่งวันจะโตเป็น $570\times1.0002=\$570.114$ แทนค่านี้ในสูตรของ $q$ ได้ $q=0.5095$ โอกาสลงจึงเป็น $1-0.5095=0.4905$ ถ้าดอกเบี้ยเป็นศูนย์ ($R=1$) จะได้ $q=(570-564)/12=0.5$ พอดี

ใต้ $q$ ค่าเฉลี่ยของราคาพรุ่งนี้คือ \$570.114 ซึ่งเท่ากับเงินฝากหนึ่งวันพอดี พอหารด้วย $R$ ก็กลับมาเป็น \$570 ชุดโอกาสนี้คือ $Q$ ราคาหลังคิดลด $S_n/R^n$ จึงเป็น martingale ใต้ $Q$ ส่วนราคาที่ไม่คิดลด $S_n$ ไม่เป็น สังเกตด้วยว่า $q$ อยู่ระหว่าง 0 กับ 1 ได้ก็เพราะ \$570.114 อยู่ระหว่าง \$564 กับ \$576

ผลที่ได้คือสูตรราคาของทุกอย่างในต้นไม้ ราคาหุ้นวันนี้คือ $S_0=\mathbb E^Q\big[S_n/R^n\big]$ และอนุพันธ์ที่จ่ายเงิน $C_n$ ตอนครบกำหนด มีราคาวันนี้ $C_0=\mathbb E^Q[C_n]/R^n$ หน้า การตั้งราคาบน binomial tree ใช้สูตรนี้ตั้งราคาจริง

$Q$ แบบนี้มีอยู่เสมอหรือ ทฤษฎีบทพื้นฐานของการตั้งราคา (fundamental theorem of asset pricing) ตอบว่า $Q$ ที่ทุกโอกาสเป็นบวกมีอยู่ ก็ต่อเมื่อตลาดไม่มี arbitrage (ช่องทางได้กำไรแน่นอนโดยไม่ต้องใช้เงินตัวเอง) ตัวอย่างเช่น ถ้าทางขึ้นของหุ้นไปถึงแค่ \$570.10 ซึ่งต่ำกว่าเงินฝาก \$570.114 ก็จะไม่มี $q$ ที่อยู่ระหว่าง 0 กับ 1 และทุกคนทำแบบนี้ได้ ยืมหุ้นมาขายวันนี้ได้ \$570 เอาเงินไปฝาก พรุ่งนี้ได้ \$570.114 แล้วซื้อหุ้นคืนในราคาไม่เกิน \$570.10 ได้กำไรอย่างน้อย $570.114-570.10=\$0.014$ ต่อหุ้นแน่นอน

มีสองกรณีที่สูตรต้องปรับ ถ้าหุ้นจ่ายปันผล ต้องบวกปันผลหลังคิดลดเข้าไปด้วย (หน้า ปันผลในสูตรราคา) ส่วนราคา futures (สัญญาซื้อขายล่วงหน้า) เป็น martingale ใต้ $Q$ โดยไม่ต้องคิดลด เพราะตอนเข้าสัญญาไม่ต้องจ่ายเงิน (หน้า mark-to-market และ margin)

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

คิดว่า martingale แปลว่าเสี่ยงน้อย: ค่าเฉลี่ยที่ไม่ขยับไม่ได้แปลว่าเงินไม่ขยับ ในเกมเหรียญ $\mathbb E_3[X_7]=110$ แต่ยอดจริงจบได้ตั้งแต่ $110-4\times10=70$ ถึง $110+4\times10=150$ ถ้าเริ่มใหม่จาก \$100 แล้วเล่นสิบรอบ ช่วงจะกว้างเป็น $100-10\times10=0$ ถึง $100+10\times10=200$ ค่าเฉลี่ยยังเป็น 100 เท่าเดิม ความกว้างจึงต้องคำนวณแยก ซึ่งหน้าถัดไปจะทำ

ตรวจแค่ค่าเฉลี่ยรวม: ค่าเฉลี่ยรวมคงที่ไม่ได้พิสูจน์ว่าเป็น martingale ตัวอย่าง $X_1=Z$, $X_2=-Z$ ผ่านการตรวจแบบผิด เพราะ $\mathbb E[X_1]=\mathbb E[X_2]=0$ แต่การตรวจที่ถูกให้ $\mathbb E_1[X_2]=-X_1$ ซึ่งห่างจาก $X_1$ อยู่ $|{-X_1}-X_1|=2$ หน่วยในทุกเส้นทาง ต้องตรวจที่ทุกโหนด

แอบใช้ข้อมูลอนาคต: กระบวนการที่ค่าวันนี้ต้องรอรู้พรุ่งนี้ ไม่ใช่ martingale ตั้ง $Y_n=C_{n+1}$ คือเหรียญของรอบหน้า ทุกเวลามี $\mathbb E[Y_n]=0$ แต่หลังรอบที่ $n$ เรายังไม่รู้ค่า $Y_n$ มันจึงไม่ adapted ใน backtest ความผิดแบบเดียวกันเกิดเมื่อใช้ตัวเลขเศรษฐกิจฉบับที่แก้ไขภายหลัง (เช่น GDP ที่ประกาศครั้งแรกแล้วถูกปรับทีหลัง) แทนฉบับที่ประกาศจริง ณ วันตัดสินใจ ผลตอบแทนที่ได้จะดีเกินจริง และดูจากตัวเลขผลตอบแทนอย่างเดียวจะหาไม่เจอ

ลืมว่า martingale ใต้ชุดโอกาสไหน: ค่าเฉลี่ยใต้ $Q$ ใช้ตั้งราคา ไม่ใช่ใช้พยากรณ์ ใน SPY ค่าเฉลี่ยของราคาพรุ่งนี้ใต้ $P$ คือ $0.55(576)+0.45(564)=570.60$ ส่วนใต้ $Q$ หลังคิดลดได้ 570 ถ้าเอาค่าใต้ $Q$ ไปพยากรณ์ราคาจริง จะทิ้ง drift $570.60-570=\$0.60$ ต่อวันไปทั้งหมด กลับกัน ถ้าเอาโอกาสจริง $P$ ไปตั้งราคา option จะได้ราคาที่คนอื่นทำ arbitrage ได้

ใช้ทำอะไรบนโต๊ะจริง

ทีมเทรดอนุพันธ์ (ในวงการเรียกว่า desk) ใช้ martingale ทุกวัน ราคาของ option คือค่าเฉลี่ยของ payoff หลังคิดลด ใต้ $Q$ สูตรนี้ใช้ได้เพราะราคาหลังคิดลดของทุกสินทรัพย์ในตลาดต้องเป็น martingale ใต้ $Q$

ทีมวิจัยกลยุทธ์ใช้ martingale เป็นสมมติฐานตั้งต้นที่ต้องหักล้างให้ได้ ผลตอบแทนส่วนเกินคือผลตอบแทนที่ได้เกินดอกเบี้ยเงินฝาก ถ้ามันเฉลี่ยเป็นศูนย์เมื่อรู้ข้อมูลวันนี้ (คนในวงการเรียกว่า martingale difference) สัญญาณซื้อขายที่สร้างจากข้อมูลวันนี้ก็ทำกำไรเฉลี่ยไม่ได้ (ดูหน้า ความมีประสิทธิภาพของตลาด) กลยุทธ์ใหม่จึงต้องแสดงให้เห็นก่อนว่าข้อนี้ไม่จริง

ฝั่ง backtest ถือคำว่า adapted เป็นกฎเหล็ก ทุกสัญญาณต้องคำนวณได้จากข้อมูลที่มีอยู่จริง ณ เวลานั้น

โจทย์ตรวจความเข้าใจ

1. เล่นเกมเหรียญเดิม (เริ่ม \$100 หัวได้ \$10 ก้อยเสีย \$10) ไปแล้วหกรอบ ตอนนี้มียอด $X_6=\$80$ ถ้าเล่นต่อจนจบรอบที่ 10 ควรคาดยอดตอนจบไว้เท่าไร และถ้าเจ้ามือเก็บค่าธรรมเนียมรอบละ \$1 ในสี่รอบข้างหน้า คำตอบเปลี่ยนเป็นเท่าไร

เฉลย

ถ้าไม่มีค่าธรรมเนียม ยอดเงินเป็น martingale และ tower property ต่อหนึ่งก้าวเป็นสี่ก้าวได้ จึงคาด $\mathbb E_6[X_{10}]=X_6=\$80$ ถ้ามีค่าธรรมเนียม แต่ละรอบคาดว่าลด \$1 สี่รอบจึงคาด $80-4\times1=\$76$ ยอดสุทธิเป็น supermartingale

2. ในเกมเหรียญเดิม ใช้ข้อมูล $\mathcal F_n$ เดิม แต่ตั้งกระบวนการใหม่ $Y_n=C_{n+1}$ คือผลเหรียญของรอบถัดไป ทุกเวลามี $\mathbb E[Y_n]=\tfrac12(+1)+\tfrac12(-1)=0$ ค่าเฉลี่ยรวมจึงคงที่ ทำไม $Y_n$ ไม่ใช่ martingale

เฉลย

เพราะ $Y_n$ ไม่ adapted หลังรอบที่ $n$ เรายังไม่รู้ผลเหรียญรอบ $n+1$ จึงยังไม่รู้ $Y_n$ เงื่อนไขข้อแรกของนิยามจึงพังตั้งแต่ต้น ค่าเฉลี่ยรวมที่คงที่ไม่ช่วยอะไร เพราะมันเป็นแค่ผลที่ตามมาของ martingale ไม่ใช่นิยาม

3. หุ้นตัวหนึ่ง (สมมติ) ราคาวันนี้ \$100 พรุ่งนี้ราคาจะขึ้นไป \$120 หรือลงไป \$90 ดอกเบี้ยเป็นศูนย์ ต้องใช้โอกาสขึ้น $p$ เท่าไร ราคาจึงเป็น martingale ที่โหนดแรก ถ้างวดถัดไปจากโหนด \$120 ราคาเป็น \$144 หรือ \$108 ด้วยโอกาสขึ้น $p$ เดิม โหนดนั้นผ่านไหม

เฉลย

ที่โหนดแรก ค่าเฉลี่ยของราคาพรุ่งนี้ต้องเท่ากับ 100

\[\begin{aligned}120p+90(1-p)&=100\\30p+90&=100\\p&=10/30=1/3\end{aligned}\]

ที่โหนด \$120 ใช้ $p=1/3$ เดิม

\[\tfrac13(144)+\tfrac23(108)=48+72=120\]

ผ่าน เพราะโหนดนี้ใช้ตัวคูณ $144/120=1.2$ กับ $108/120=0.9$ เหมือนงวดแรก ตัวคูณเฉลี่ยคือ $\tfrac13(1.2)+\tfrac23(0.9)=0.4+0.6=1$ จึงผ่านทุกโหนดที่ใช้ตัวคูณคู่นี้

  if (Math.abs(a - b) > eps) throw new Error(`${a} != ${b}`);
};
// coin game: X3 = 110, enumerate the 16 futures
let sum = 0, at110 = 0, lo = Infinity, hi = -Infinity;
for (let mask = 0; mask < 16; mask++) {
  let x = 110;
  for (let k = 0; k < 4; k++) x += (mask & (1 << k)) ? 10 : -10;
  sum += x; if (x === 110) at110++;
  lo = Math.min(lo, x); hi = Math.max(hi, x);
}
near(sum / 16, 110); near(at110 / 16, 0.375);
console.log({mean: sum / 16, lo, hi, pAt110: at110 / 16});
// two-period tree u = 1.10, d = 0.95, zero rate
const p = (1 - 0.95) / (1.10 - 0.95);              // 1/3
for (const s of [100, 110, 95]) near(p * 1.10 * s + (1 - p) * 0.95 * s, s);
console.log('upper node, 1.05/0.95:', p * 115.5 + (1 - p) * 104.5); // 108.17
console.log('p = 1/2 on original tree:', 0.5 * 121 + 0.5 * 104.5);  // 112.75
// SPY one-day tree
const R = 1.0002, q = (570 * R - 564) / (576 - 564);
console.log({meanP: 0.55 * 576 + 0.45 * 564, q,

สิ่งที่ควรตอบได้หลังอ่าน

  • บอกได้ว่า ณ เวลา $n$ เรารู้อะไรแล้ว (filtration) และค่าของกระบวนการคำนวณได้จากข้อมูลนั้นหรือไม่ (adapted)
  • Martingale ต้องผ่านสามข้อ คือ adapted, integrable และ $\mathbb E_n[X_{n+1}]=X_n$ ในทุกโหนด ค่าเฉลี่ยรวมคงที่อย่างเดียวไม่พอ
  • tower property ต่อหนึ่งก้าวเป็นหลายก้าว จึงได้ $\mathbb E_3[X_7]=110$ ทั้งที่ยอดจริงจบได้ตั้งแต่ 70 ถึง 150
  • เกมที่เก็บค่าธรรมเนียมทุกรอบเป็น supermartingale ส่วนต้นไม้ราคาเป็น martingale เมื่อตัวคูณเฉลี่ย $pu+(1-p)d$ เท่ากับ 1 ทุกโหนด
  • ราคาหุ้นมี drift ใต้โอกาสจริง $P$ แต่ราคาหลังคิดลดเป็น martingale ใต้ $Q$ ราคาอนุพันธ์จึงเท่ากับค่าเฉลี่ยใต้ $Q$ ของ payoff หลังคิดลด

หน้าถัดไป สร้าง martingale จาก random walk ทำกลับด้านกับหน้านี้ หน้านี้ตรวจว่าอะไรเป็น martingale หน้าถัดไปเริ่มจากกำไรสะสมที่มี drift แล้วหักส่วนที่คาดได้ออก จนเหลือ martingale จากนั้นวัดว่าส่วนที่เหลือแกว่งได้มากแค่ไหน เมื่อเทียบกับความผันผวน
