14.2 The Black–Scholes Formula

ราคา call คือค่าเฉลี่ยของ payoff ในโลกที่หุ้นโตเท่าดอกเบี้ย คิดลดกลับมาวันนี้ แยกเป็นขาหุ้นกับขา strike จึงได้สูตรสองพจน์

นักศึกษาฝึกงานที่โต๊ะ option ได้รับคำขอให้เสนอราคาขาย call หนึ่งตัว call คือสัญญาที่ให้สิทธิ์ผู้ถือซื้อหุ้นหนึ่งหุ้นในราคาที่ตกลงไว้ เมื่อสัญญาหมดอายุ ราคาที่ตกลงไว้นี้เรียกว่า strike

ถ้าวันหมดอายุหุ้นแพงกว่า strike ผู้ถือจะใช้สิทธิ์ และได้ส่วนต่างเป็นกำไร ถ้าหุ้นถูกกว่า ผู้ถือก็ทิ้งสิทธิ์และได้ศูนย์ เงินที่ผู้ถือได้ในวันหมดอายุเรียกว่า payoff คำถามคือ สิทธิ์แบบนี้วันนี้ควรขายเท่าไร

ของที่รู้:

  • ราคาหุ้นวันนี้ $S_0=\$100$
  • strike $K=\$105$
  • อายุสัญญา 3 เดือน คิดเป็นปีได้ $T=3/12=0.25$ ปี
  • ดอกเบี้ยต่อปี $r=4\%$ คิดแบบทบต้นต่อเนื่อง คือเงิน \$1 ฝากไว้ $T$ ปีจะโตเป็น $e^{rT}$ ดอลลาร์
  • ความผันผวนต่อปี $\sigma=20\%$ คือขนาดการแกว่งของราคาหุ้นในหนึ่งปี วัดเป็น SD (standard deviation) ของผลตอบแทน

ถ้าวันหมดอายุหุ้นมีราคา $S_T$ payoff ของ call คือ $(S_T-K)^+$ เครื่องหมาย $(x)^+$ หมายถึง $\max(x,0)$ คือเอา $x$ ถ้าเป็นบวก และเอาศูนย์ถ้าติดลบ

นักศึกษาคิดแบบนี้ ในโลกที่ใช้ตั้งราคา option หุ้นโตเฉลี่ยเท่าดอกเบี้ย (เหตุผลอยู่ในภาพรวมด้านล่าง) ราคาเฉลี่ยวันหมดอายุจึงเป็น

\[\begin{aligned}S_0e^{rT}&=100e^{0.04\times0.25}\\&=100e^{0.01}=\$101.01\end{aligned}\]

ค่าเฉลี่ยนี้ต่ำกว่า strike ถ้าหุ้นจบที่ค่าเฉลี่ยพอดี payoff คือ $(101.01-105)^+=0$ เขาจึงสรุปว่า call นี้ “เฉลี่ยแล้วไม่มีค่า” และยอมขายที่ \$0.10

แต่หน้า Black–Scholes PDE คำนวณราคาของ call ตัวเดียวกันด้วยการแก้สมการบนกริดได้ \$2.3909 ใครถูก และเงิน \$2.39 มาจากไหน

ลองตอบก่อนเปิดเฉลย

กริดถูก นักศึกษาเอาราคาเฉลี่ยใส่ลงใน payoff ซึ่งเท่ากับคิดว่าหุ้นไม่แกว่งเลย แต่หุ้นแกว่ง และ payoff ของ call ไม่เคยติดลบ เส้นทางที่หุ้นจบต่ำกว่า \$105 ให้ศูนย์ ไม่มีเงินติดลบมาหักล้าง ส่วนเส้นทางที่จบสูงกว่าให้เงินจริง ค่าเฉลี่ยของ payoff จึงมากกว่า payoff ของค่าเฉลี่ย

หน้านี้จะคำนวณตัวเลขสามตัวต่อไปนี้ให้ดูทีละขั้น:

  • 33.07% ของเส้นทางราคาจบเหนือ \$105 (นับด้วยน้ำหนักที่ใช้ตั้งราคา)
  • ในเส้นทางกลุ่มนั้น หุ้นจบเฉลี่ยที่ \$112.30 จึงจ่ายเฉลี่ย $112.30-105=\$7.30$
  • เงิน \$1 ที่ได้ในอีก 3 เดือน มีค่าวันนี้ $e^{-0.01}=\$0.99005$ เพราะเงินวันนี้เอาไปฝากแล้วได้ดอกเบี้ย

ราคา call ซึ่งเขียนว่า $C$ คือโอกาสใช้สิทธิ์ คูณเงินที่ได้เฉลี่ยเมื่อใช้สิทธิ์ แล้วแปลงเป็นเงินวันนี้

\[\begin{aligned}C&\approx0.99005\times(0.3307\times7.302)\\&\approx0.99005\times2.415\\&\approx\$2.39\end{aligned}\]

ตัวเลขละเอียด \$2.3909 ได้ในขั้นที่ 8 การขายที่ \$0.10 จึงเท่ากับแจกเงิน $2.39-0.10=\$2.29$ ต่อหุ้น

ภาพรวมก่อนลงสูตร

หน้า Black–Scholes PDE หาราคา option ด้วยการแก้สมการเชิงอนุพันธ์ย่อย (PDE) บนกริด วิธีนั้นให้ตัวเลข แต่ไม่ให้สูตร หน้านี้หาสูตรปิดที่กดเครื่องคิดเลขได้

ทางลัดมาจากผลของ Feynman–Kac ซึ่งบอกว่าคำตอบของ PDE แบบนี้เท่ากับค่าเฉลี่ยของ payoff แล้วคิดลดกลับมาวันนี้ “คิดลด” คือแปลงเงินในอนาคตเป็นเงินวันนี้ โดยคูณด้วย $e^{-rT}$ แต่ค่าเฉลี่ยนี้ต้องคิดในโลกสมมติที่หุ้นโตเฉลี่ยในอัตราดอกเบี้ย $r$ ไม่ใช่อัตราที่หุ้นโตจริง ซึ่งเรียก $\mu$ การถ่วงน้ำหนักเส้นทางราคาแบบนี้เรียกว่า risk-neutral เขียนแทนด้วย $\mathbb Q$

ทำไมเปลี่ยน $\mu$ เป็น $r$ ได้ หน้า PDE แสดงแล้วว่าผู้ขาย option สร้างพอร์ตเลียนแบบได้ คือพอร์ตหุ้นกับเงินกู้ที่ให้เงินเท่า payoff ทุกกรณี และต้นทุนของพอร์ตนี้ไม่มี $\mu$ อยู่เลย ดังนั้นจะสมมติให้หุ้นโตเท่าไรก็ได้ราคาเดียวกัน เราจึงเลือก $\mu=r$ ซึ่งคำนวณง่ายที่สุด

รูปด้านล่างแสดงว่าในโลกนั้น ราคาหุ้นวันหมดอายุกระจายตัวอย่างไร ราคา call มาจากพื้นที่สีส้มทางขวาของ strike: ขนาดของพื้นที่ (โอกาสได้ใช้สิทธิ์) คูณระยะที่หุ้นเลย strike ไปโดยเฉลี่ย แล้วคิดลดกลับมา

ตอนใช้สิทธิ์ ผู้ถือ call ได้หุ้นหนึ่งหุ้น และจ่ายเงินเท่า strike หน้านี้จึงแยกงานเป็นสองบัญชี บัญชี “ได้หุ้น” กับบัญชี “จ่าย strike” คำนวณแต่ละบัญชีด้วยตาราง Normal จนได้สูตร แล้วตรวจสูตรด้วยขอบเขตราคา ต้นไม้ binomial และการสุ่ม สุดท้ายขยายไปถึงหุ้นที่จ่ายปันผล

ศัพท์ที่ใช้ในหัวข้อนี้
Call และ put
call คือสิทธิ์ซื้อหุ้นที่ราคา strike ส่วน put คือสิทธิ์ขายหุ้นที่ราคา strike ผู้ถือไม่มีข้อผูกมัด จึงใช้สิทธิ์เฉพาะเมื่อได้กำไร แบบ European ใช้สิทธิ์ได้เฉพาะวันหมดอายุ แบบ American ใช้สิทธิ์ได้ทุกวันจนหมดอายุ
Strike ($K$) และ payoff
strike คือราคาที่ตกลงไว้ในสัญญา payoff คือเงินที่ผู้ถือได้ในวันหมดอายุ call ได้ $(S_T-K)^+=\max(S_T-K,0)$ และ put ได้ $(K-S_T)^+$
Risk-neutral weights ($\mathbb Q$)
วิธีถ่วงน้ำหนักเส้นทางราคาที่ทำให้หุ้นโตเฉลี่ยเท่าดอกเบี้ย ใช้เขียนราคา option เป็นค่าเฉลี่ยแล้วคิดลด วิธีนี้ใช้ได้เพราะต้นทุนของพอร์ตเลียนแบบไม่ขึ้นกับอัตราโตจริง $\mu$ มันเป็นเครื่องมือคำนวณ ไม่ใช่คำทำนายว่าหุ้นจะไปทางไหน
Forward price
$F=S_0e^{rT}$ คือราคาที่ตกลงกันวันนี้ เพื่อซื้อหุ้นในวันหมดอายุ คิดจากต้นทุนของการกู้เงินมาซื้อหุ้นวันนี้แล้วถือไว้ (ดู ต้นทุนการถือ) และเท่ากับค่าเฉลี่ยของ $S_T$ ภายใต้ $\mathbb Q$ ในโจทย์นี้ $F=100e^{0.01}=\$101.01$ strike ควรเทียบกับ forward ไม่ใช่กับราคาหุ้นวันนี้
Discount factor
$e^{-rT}$ คือตัวคูณที่แปลงเงินวันหมดอายุเป็นเงินวันนี้ ที่ดอกเบี้ย 4% ต่อปีนาน 0.25 ปี ได้ $e^{-0.04\times0.25}=e^{-0.01}=0.99005$ คือเงิน \$1 วันหมดอายุมีค่า \$0.99005 วันนี้ การคูณด้วยตัวนี้เรียกว่า “คิดลด”
Indicator
$\mathbf 1(S_T\gt K)$ มีค่า 1 เมื่อหุ้นจบเหนือ strike และมีค่า 0 เมื่อไม่ใช่ ใช้เขียน payoff สองกรณีเป็นบรรทัดเดียว แล้วแยกเป็นสองบัญชี ค่าเฉลี่ยของมันคือโอกาสที่เหตุการณ์นั้นเกิด
$\Phi$ กับ $\phi$
$\Phi(x)$ คือ CDF ของ standard Normal คือพื้นที่ใต้ระฆังทางซ้ายของ $x$ ส่วน $\phi(x)=e^{-x^2/2}/\sqrt{2\pi}$ คือความสูงของระฆังที่ $x$ ตัวแรกอยู่ในคำตอบ ตัวหลังใช้ระหว่างพิสูจน์ ถ้าสลับกันจะได้ตัวเลขผิดโดยไม่มีอะไรเตือน
$d_1$ และ $d_2$
ระยะสองตัว วัดเป็นจำนวน SD ของ log ราคาปลายทาง $d_2$ บอกว่าความบังเอิญต้องแรงแค่ไหน หุ้นจึงจะจบเหนือ strike ส่วน $d_1=d_2+\sigma\sqrt T$ คือ $d_2$ ที่ถูกเลื่อน เมื่อนับเส้นทางหนักตามราคาหุ้น
Dividend yield ($q$)
อัตราปันผลต่อปี โดยสมมติว่าปันผลไหลออกจากหุ้นอย่างต่อเนื่อง ผู้ถือ call ไม่ได้ปันผลนี้ จึงต้องหักออกจากการโตของหุ้น เหมาะกับดัชนีที่มีหุ้นหลายร้อยตัวจ่ายปันผลกระจายทั้งปี
Hedge
การถือหุ้นและเงินกู้ไว้หักล้างความเสี่ยงของ option ที่ขายไป ถ้าทำครบ กำไรขาดทุนของสองฝั่งจะหักกันพอดี

ขั้นที่ 1 — ลองด้วยมือ: หุ้นปลายทางมีแค่สามราคา

ก่อนจะเจอ integral ลองโลกเล็ก ๆ ที่นับด้วยมือได้ก่อน ในโลกนี้หุ้นวันหมดอายุมีได้แค่สามราคา ทุกอย่างที่หน้านี้จะทำกับระฆัง Normal จะเห็นครบในตัวอย่างนี้

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติทั้งหมด):

  • หุ้นวันนี้ $S_0=\$100$
  • วันหมดอายุหุ้นเป็นได้ \$90, \$100 หรือ \$120 โดยมีน้ำหนักที่ใช้ตั้งราคา 0.3, 0.4 และ 0.3 ตามลำดับ
  • เงิน \$1 วันนี้โตเป็น \$1.03 ในวันหมดอายุ
  • call มี strike $K=\$105$

ราคา call วันนี้เท่าไร และถ้าแยก payoff เป็นบัญชี “ได้หุ้น” กับบัญชี “จ่าย strike” แต่ละบัญชีมีค่าเท่าไร

เริ่มจากเช็กว่าน้ำหนักชุดนี้ใช้ตั้งราคาได้จริง คือหุ้นต้องโตเฉลี่ยเท่าเงินฝาก ค่าเฉลี่ยของหุ้นวันหมดอายุเรียกว่า forward เขียนว่า $F$ จากนั้นหาค่าเฉลี่ยของ payoff แล้วคิดลดด้วยการหารด้วย 1.03

\[ \begin{aligned} F&=0.3(90)+0.4(100)+0.3(120)\\ &=27+40+36=103,\\ 100(1.03)&=103,\\ (S_T-K)^+&=0,\ 0,\ 15,\\ \mathbb E\big[(S_T-K)^+\big]&=0.3(15)=4.5,\\ C&=\frac{4.5}{1.03}=4.3689. \end{aligned} \]

ต่อไปแยกเป็นสองบัญชี ในโลกนี้ใช้สิทธิ์เฉพาะเส้นทางที่หุ้นจบที่ \$120 ให้ $A$ คือค่าเฉลี่ยของหุ้นที่ได้รับ และ $B$ คือค่าเฉลี่ยของเงิน strike ที่จ่าย โดยนับเฉพาะเส้นทางที่ใช้สิทธิ์

\[ \begin{aligned} A&=0.3(120)=36,\\ B&=0.3(105)=31.5,\\ A-B&=36-31.5=4.5. \end{aligned} \]

คำตอบ: call ราคา \$4.3689 น้ำหนักชุดนี้ใช้ตั้งราคาได้ เพราะค่าเฉลี่ยของหุ้นคือ \$103 เท่ากับเงิน \$100 ที่ฝากไว้ หุ้นจึงโตเฉลี่ยเท่าดอกเบี้ยพอดี บัญชีได้หุ้นมีค่า 36 บัญชีจ่าย strike มีค่า 31.5 ลบกันได้ 4.5 เท่ากับค่าเฉลี่ยของ payoff

มีตัวเลขสองตัวที่ต้องจำไว้ เพราะจะกลับมาในสูตรจริง:

  • โอกาสได้ใช้สิทธิ์ภายใต้น้ำหนักนี้คือ 0.3 ตัวนี้จะกลายเป็น $\Phi(d_2)$
  • สัดส่วนของค่าเฉลี่ยหุ้นที่มาจากเส้นทางใช้สิทธิ์คือ $A/F=36/103=0.3495$ ตัวนี้จะกลายเป็น $\Phi(d_1)$

ตัวที่สองสูงกว่าตัวแรก เพราะเส้นทางที่ใช้สิทธิ์คือเส้นทางที่หุ้นราคาสูง ถ้าถ่วงทุกเส้นทางด้วยราคาหุ้นของมัน น้ำหนักจะไหลไปทางราคาสูง ดังรูปด้านล่าง

ตรวจเองใน 10 วินาที: สองวิธีให้ผลเดียวกัน $0.3(15)=4.5=36-31.5$ และถ้าเอาค่าเฉลี่ย 103 ใส่ใน payoff จะได้ $(103-105)^+=0$ คือราคาศูนย์แบบที่นักศึกษาในโจทย์เปิดเรื่องคิด ทั้งที่ราคาจริงคือ \$4.37

ขั้นที่ 2 — หุ้นปลายทางเขียนด้วยก้อนสุ่มก้อนเดียว

ในโลกจริง หุ้นวันหมดอายุมีได้ทุกราคา ไม่ใช่แค่สามราคา เราจึงต้องมีสูตรที่บอกว่า $S_T$ เป็นเท่าไร เมื่อเกิดความบังเอิญขนาดหนึ่ง สูตรนี้สร้างจากของสามอย่างที่มีแล้ว:

  • แบบจำลอง GBM (geometric Brownian motion) ซึ่งให้ log ของราคาหุ้นเดินสุ่ม และมีคำตอบเป็นสูตรปิด
  • การขยับของ Brownian motion ตลอดช่วงเวลา $T$ เป็น Normal ที่มีค่าเฉลี่ย 0 และ SD $\sqrt T$ จึงเขียนเป็น $\sqrt T\,Z$ ได้ เมื่อ $Z$ คือก้อนสุ่ม standard Normal (ค่าเฉลี่ย 0 และ SD 1)
  • ภายใต้น้ำหนักตั้งราคา อัตราโตเฉลี่ยของหุ้น (drift) เปลี่ยนจาก $\mu$ เป็น $r$

จากนั้นตรวจว่าสูตรนี้ให้ค่าเฉลี่ยของ $S_T$ เท่ากับ forward จริง โดยใช้สูตร $\mathbb E[e^{aZ}]=e^{a^2/2}$ ของ lognormal แล้วแทนตัวเลขของโจทย์เปิดเรื่อง

\[ \begin{aligned} S_T&=S_0e^{(r-\frac12\sigma^2)T+\sigma\sqrt T\,Z},\\ Z&\sim\mathcal N(0,1),\\ \mathbb E^{\mathbb Q}[S_T]&=S_0e^{(r-\frac12\sigma^2)T}\,\mathbb E\big[e^{\sigma\sqrt T\,Z}\big]\\ &=S_0e^{(r-\frac12\sigma^2)T}e^{\frac12\sigma^2T}\\ &=S_0e^{rT}=F,\\ F&=100e^{0.04(0.25)}=100e^{0.01}\\ &=101.0050,\\ \tfrac12\sigma^2&=\tfrac12(0.20)^2=0.02,\\ (r-\tfrac12\sigma^2)T&=(0.04-0.02)(0.25)\\ &=0.005,\\ S_0e^{0.005}&=100.5013. \end{aligned} \]

สูตรนี้มีก้อนสุ่ม $Z$ ก้อนเดียว ทุกคำถามเรื่อง $S_T$ จึงแปลงเป็นคำถามเรื่อง $Z$ ได้ และ $Z$ มีตาราง Normal ให้เปิด

ตัวที่ดูแปลกคือ $-\tfrac12\sigma^2T$ ในเลขชี้กำลัง มันมีไว้ชดเชย เพราะ exponential โค้งงอขึ้น (convex) ค่าเฉลี่ยของ $e^{\sigma\sqrt T Z}$ จึงไม่ใช่ $e^0=1$ แต่เป็น $e^{\sigma^2T/2}$ ซึ่งมากกว่า 1 สองตัวนี้หักกันพอดี ค่าเฉลี่ยของ $S_T$ จึงออกมาเป็น $F$

ถ้าแทน $Z=0$ ซึ่งเป็นค่ากลางของ $Z$ จะได้ $S_0e^{0.005}=\$100.50$ ตัวนี้คือ median ของ $S_T$ คือราคาที่ครึ่งหนึ่งของเส้นทางจบต่ำกว่า median ต่ำกว่าค่าเฉลี่ย \$101.01 เพราะการกระจายแบบ lognormal เบ้ขวา เส้นทางที่ขึ้นแรงดึงค่าเฉลี่ยขึ้นไป ดูได้จากรูประฆังแรกที่หางขวายาวกว่าหางซ้าย

ขั้นที่ 3 — ราคาคือค่าเฉลี่ยคิดลด แล้วแยก payoff เป็นสองบัญชี

ตอนนี้มีสูตรของ $S_T$ แล้ว ขั้นต่อไปคือเขียนราคา call ให้อยู่ในรูปที่คำนวณได้ ผลของ Feynman–Kac บอกว่าราคาวันนี้คือค่าเฉลี่ยของ payoff ภายใต้ $\mathbb Q$ คูณ discount factor $e^{-rT}$ ค่าเฉลี่ยนี้เขียนเป็น integral กับ density ได้ตรง ๆ

จากนั้นแยก payoff เป็นสองบัญชี แบบที่ทำด้วยมือในโลกสามราคา เครื่องมือที่ใช้แยกคือ indicator $\mathbf 1(S_T\gt K)$ ซึ่งมีค่า 1 เมื่อหุ้นจบเหนือ strike และมีค่า 0 เมื่อไม่ใช่

\[ \begin{aligned} C&=e^{-rT}\,\mathbb E^{\mathbb Q}\big[(S_T-K)^+\big]\\ &=e^{-rT}\int_K^{\infty}(s-K)\,f(s)\,ds,\\ (S_T-K)^+&=S_T\mathbf 1(S_T\gt K)-K\,\mathbf 1(S_T\gt K),\\ \mathbb E^{\mathbb Q}\big[\mathbf 1(S_T\gt K)\big]&=\mathbb Q(S_T\gt K),\\ C&=e^{-rT}\Big(\mathbb E^{\mathbb Q}\big[S_T\mathbf 1(S_T\gt K)\big]\\ &\qquad-K\,\mathbb Q(S_T\gt K)\Big). \end{aligned} \]

$f(s)$ คือ density ของ $S_T$ และ integral เริ่มที่ $K$ เพราะทางซ้ายของ strike payoff เป็นศูนย์ integral นี้คือพื้นที่สีส้มในรูปแรก ถ้ามีสูตรของ density ก็คำนวณ integral ด้วยตัวเลขได้ เช่นใช้ trapezoid rule ซึ่งซอยช่วงเป็นชิ้นเล็ก ๆ แล้วรวมพื้นที่สี่เหลี่ยมคางหมู แต่ทางที่ได้สูตรปิดคือแยกเป็นสองบัญชี

การแยกใช้ได้เพราะ indicator เปิดปิดทั้งสองบัญชีพร้อมกัน เมื่อใช้สิทธิ์ indicator เป็น 1 จึงเหลือ $S_T-K$ เมื่อไม่ใช้ indicator เป็น 0 จึงเหลือ 0 ตรงกับ payoff ทั้งสองกรณี ส่วนค่าเฉลี่ยของ indicator คือ 1 คูณโอกาสที่เกิด บวก 0 คูณโอกาสที่ไม่เกิด จึงเท่ากับโอกาสที่หุ้นจบเหนือ strike

สองบัญชีต้องคำนวณคนละแบบ บัญชีจ่าย strike คูณด้วย $K$ ซึ่งคงที่ จึงเหลือแค่โอกาสใช้สิทธิ์ แต่บัญชีได้หุ้นมี $S_T$ สุ่มอยู่ข้างใน เส้นทางที่หุ้นจบสูงจึงถูกนับหนักกว่า เหมือนแท่งส้มในโลกสามราคา

ขั้นที่ 4 — ขา strike: เงื่อนไขใช้สิทธิ์กลายเป็นเกณฑ์ของ Z

เริ่มจากบัญชีจ่าย strike เพราะง่ายกว่า สิ่งที่ต้องหาคือโอกาส $\mathbb Q(S_T\gt K)$ เรารู้การกระจายของ $Z$ แต่เงื่อนไข $S_T\gt K$ เขียนด้วยราคาหุ้น จึงต้องแปลงอสมการให้เป็นเงื่อนไขของ $Z$ การแปลงมีสองขั้น และทั้งสองขั้นไม่ทำให้เครื่องหมายพลิก:

  • ใส่ log ทั้งสองข้าง ใช้ได้เพราะราคาเป็นบวก และ log เป็นฟังก์ชันเพิ่ม
  • หารด้วย $\sigma\sqrt T$ ใช้ได้เพราะ $\sigma\sqrt T$ เป็นบวก

ตัวเลขใช้โจทย์เปิดเรื่อง โดย $(r-\tfrac12\sigma^2)T=0.005$ มาจากขั้นที่ 2

\[ \begin{aligned} \ln S_T&=\ln S_0+(r-\tfrac12\sigma^2)T+\sigma\sqrt T\,Z,\\ \ln S_T\gt\ln K\ &\Rightarrow\ Z\gt z^*,\\ z^*&=\frac{\ln(K/S_0)-(r-\frac12\sigma^2)T}{\sigma\sqrt T},\\ d_2&:=-z^*=\frac{\ln(S_0/K)+(r-\frac12\sigma^2)T}{\sigma\sqrt T},\\ \mathbb Q(S_T\gt K)&=\mathbb Q(Z\gt-d_2)=\Phi(d_2),\\ \sigma\sqrt T&=0.20\sqrt{0.25}=0.10,\\ z^*&=\frac{\ln(105/100)-0.005}{0.10}\\ &=\frac{0.048790-0.005}{0.10}=0.4379,\\ \Phi(d_2)&=\Phi(-0.4379)=0.3307. \end{aligned} \]

$z^*$ คือจำนวน SD ที่ $Z$ ต้องขึ้นไปให้ถึง หุ้นจึงจะจบเหนือ strike อ่านเป็นเรื่องได้แบบนี้ log ของหุ้นต้องขึ้นจาก $\ln100$ ไปถึง $\ln105$ คือขึ้น 0.048790 แต่ log ของหุ้นขึ้นเองโดยเฉลี่ยแค่ 0.005 ส่วนที่ขาด $0.048790-0.005=0.043790$ ต้องมาจากความบังเอิญ ความบังเอิญตลอด 3 เดือนมีขนาด SD $=0.10$ ส่วนที่ขาดจึงเท่ากับ $0.043790/0.10=0.4379$ SD เหมือน z-score ของ Normal distribution

ท่าที่ต้องระวังคือการกลับเครื่องหมาย พื้นที่ทางขวาของ $-d_2$ เท่ากับพื้นที่ทางซ้ายของ $d_2$ เพราะระฆัง Normal สมมาตรรอบศูนย์ เราตั้งชื่อ $d_2$ ให้เป็นค่าลบของเกณฑ์ ก็เพื่อให้คำตอบเขียนสั้น ๆ เป็น $\Phi(d_2)$ ได้

ขั้นที่ 5 — ขาหุ้น: จัดกำลังสองสมบูรณ์ แล้ว d₁ ก็โผล่มา

ต่อไปคือบัญชีได้หุ้น $\mathbb E^{\mathbb Q}[S_T\mathbf 1(S_T\gt K)]$ บัญชีนี้ยากกว่า เพราะมี $S_T$ คูณอยู่ข้างใน เมื่อแทนสูตร $S_T$ จากขั้นที่ 2 ลงใน integral จะมีตัว $e^{\sigma\sqrt T z}$ คูณกับความสูงของระฆัง $\phi(z)=e^{-z^2/2}/\sqrt{2\pi}$

ผลคูณนี้ไม่ใช่ระฆังมาตรฐาน จึงเปิดตารางตรง ๆ ไม่ได้ วิธีแก้คือรวมเลขชี้กำลังสองก้อนเข้าด้วยกัน แล้วจัดกำลังสองสมบูรณ์ ซึ่งเป็นวิธีเดียวกับที่ใช้หาค่าเฉลี่ยของ lognormal ขอบล่างของ integral คือเกณฑ์ $-d_2$ จากขั้นที่ 4

\[ \begin{aligned} \sigma\sqrt T z-\tfrac12z^2&=-\tfrac12\big(z-\sigma\sqrt T\big)^2\\ &\quad+\tfrac12\sigma^2T,\\ e^{\sigma\sqrt T z}\phi(z)&=e^{\frac12\sigma^2T}\phi\big(z-\sigma\sqrt T\big),\\ &\mathbb E^{\mathbb Q}\big[S_T\mathbf 1(S_T\gt K)\big]\\ &=S_0e^{(r-\frac12\sigma^2)T}\\ &\quad\times\int_{-d_2}^{\infty}e^{\sigma\sqrt T z}\phi(z)\,dz\\ &=S_0e^{rT}\int_{-d_2}^{\infty}\phi\big(z-\sigma\sqrt T\big)\,dz\\ &=F\int_{-d_2-\sigma\sqrt T}^{\infty}\phi(u)\,du\\ &=F\,\Phi\big(d_2+\sigma\sqrt T\big)=F\,\Phi(d_1),\\ d_1&:=d_2+\sigma\sqrt T. \end{aligned} \]

ท่าสำคัญคือการจัดกำลังสองสมบูรณ์ ตรวจได้ด้วยการกระจายกลับ: $-\tfrac12(z^2-2\sigma\sqrt T z+\sigma^2T)+\tfrac12\sigma^2T$ เหลือ $\sigma\sqrt T z-\tfrac12z^2$ พอดี ผลที่ได้บอกว่า การถ่วงด้วยราคาหุ้นไม่ทำลายรูประฆัง มันแค่เลื่อนจุดกลางของระฆังไปทางขวา $\sigma\sqrt T$ และทิ้งตัวคูณ $e^{\sigma^2T/2}$ ไว้ข้างนอก ตัวคูณนี้รวมกับ $e^{(r-\sigma^2/2)T}$ ได้ $e^{rT}$ พอดี หน้า integral จึงเหลือ $S_0e^{rT}=F$

จากนั้นเปลี่ยนตัวแปรเป็น $u=z-\sigma\sqrt T$ ขอบล่างจึงเลื่อนจาก $-d_2$ เป็น $-d_2-\sigma\sqrt T$ แล้วใช้ความสมมาตรของระฆังแบบเดียวกับขั้นที่ 4 ลองตรวจสมการเลื่อนระฆัง $e^{\sigma\sqrt T z}\phi(z)=e^{\sigma^2T/2}\phi(z-\sigma\sqrt T)$ ด้วยตัวเลข ที่ $z=0.7$ และ $\sigma\sqrt T=0.1$ ตัวคูณข้างนอกคือ $e^{0.1^2/2}=e^{0.005}$ สองข้างได้ $e^{0.07}\phi(0.7)=1.072508\times0.312254=0.334895$ และ $e^{0.005}\phi(0.6)=1.005013\times0.333225=0.334895$ เท่ากัน

นี่คือที่มาเดียวของ $d_1$ มันคือ $d_2$ ที่ถูกเลื่อนไป $\sigma\sqrt T$ เพราะเส้นทางถูกนับหนักตามราคาหุ้น เหมือนแท่งส้มในโลกสามราคาที่เอียงไปทางราคาสูง

ขั้นที่ 6 — ประกอบเป็นสูตร call และ put

ตอนนี้ได้ทั้งสองบัญชีแล้ว บัญชีจ่าย strike คือ $K\,\Phi(d_2)$ และบัญชีได้หุ้นคือ $F\,\Phi(d_1)$ แทนลงในสูตรของขั้นที่ 3 ก็ได้ราคา call

put คือสิทธิ์ขายหุ้นที่ราคา strike ผู้ถือจึงใช้สิทธิ์เมื่อหุ้นจบต่ำกว่า strike และได้ $(K-S_T)^+$ payoff นี้แยกเป็นสองบัญชีได้เหมือนกัน: $(K-S_T)^+=K\,\mathbf 1(S_T\lt K)-S_T\mathbf 1(S_T\lt K)$ เหตุการณ์ $S_T\lt K$ คือพื้นที่อีกฝั่งของเกณฑ์เดิม จึงได้ $\Phi(-d)$ แทน $\Phi(d)$ โดยไม่ต้องคำนวณ integral ใหม่

\[ \begin{aligned} C&=e^{-rT}\big(F\,\Phi(d_1)-K\,\Phi(d_2)\big)\\ &=S_0\Phi(d_1)-Ke^{-rT}\Phi(d_2),\\ P&=Ke^{-rT}\Phi(-d_2)-S_0\Phi(-d_1),\\ C-P&=S_0\big[\Phi(d_1)+\Phi(-d_1)\big]\\ &\quad-Ke^{-rT}\big[\Phi(d_2)+\Phi(-d_2)\big]\\ &=S_0-Ke^{-rT}. \end{aligned} \]

ขาหุ้นเปลี่ยนจาก $e^{-rT}F$ เป็น $S_0$ เพราะ $F=S_0e^{rT}$ ส่วนขา strike ยังมี $e^{-rT}$ อยู่ เพราะเงิน strike จ่ายในวันหมดอายุ ไม่ใช่วันนี้

สูตรนี้อ่านเป็นพอร์ตได้ทันที: ถือหุ้น $\Phi(d_1)$ หุ้น และกู้เงิน $Ke^{-rT}\Phi(d_2)$ ดอลลาร์ นี่คือ พอร์ตเลียนแบบ ตัวเดิม หน้า the Greeks จะพิสูจน์ว่าความชันของราคา call เทียบราคาหุ้นเท่ากับ $\Phi(d_1)$ ทุกจุด สังเกตว่าในสูตรไม่มี $\mu$ เลย เหมือนที่การตั้งราคาบนต้นไม้ไม่ใช้โอกาสจริง

ผลต่าง $C-P$ ใช้ความจริงว่า $\Phi(x)+\Phi(-x)=1$ คือพื้นที่ทางซ้ายบวกพื้นที่ทางขวาของจุดเดียวกันได้ทั้งระฆัง ผลคือ put–call parity $C-P=S_0-Ke^{-rT}$ ที่นี่ได้มาจากสูตร แต่หน้า put–call parity จะพิสูจน์ใหม่โดยไม่ใช้แบบจำลองเลย ความสัมพันธ์นี้จึงใช้ตรวจราคาจากตลาดได้

ขั้นที่ 7 — แทนตัวเลขของ call \$105

ถึงเวลาแทนตัวเลขของโจทย์เปิดเรื่อง เพื่อดูว่าสูตรให้ \$2.3909 เท่ากับกริดจริงไหม

โจทย์ให้อะไรมาบ้าง: $S_0=100$, $K=105$, $T=0.25$, $r=0.04$ และ $\sigma=0.20$ ไม่มีปันผล

ทำตามลำดับของการพิสูจน์: หา $d_2$ ก่อน แล้วหา $d_1$ แล้วคำนวณสองบัญชี ค่า $\Phi$ เปิดจากตาราง Normal หรือคำนวณด้วยโค้ดท้ายหน้า ส่วน put ใช้ $\Phi(-x)=1-\Phi(x)$

\[ \begin{aligned} \ln(100/105)&=-0.0487902,\\ (r-\tfrac12\sigma^2)T&=(0.04-0.02)(0.25)\\ &=0.005,\\ \sigma\sqrt T&=0.20(0.5)=0.10,\\ d_2&=\frac{-0.0487902+0.005}{0.10}\\ &=-0.4379016,\\ d_1&=-0.4379016+0.10=-0.3379016,\\ \Phi(d_1)&=0.3677187,\ \ \Phi(d_2)=0.3307288,\\ \Phi(-d_1)&=1-0.3677187=0.6322813,\\ \Phi(-d_2)&=1-0.3307288=0.6692712,\\ Ke^{-rT}&=105e^{-0.01}=103.955233,\\ C&=100(0.3677187)\\ &\quad-103.955233(0.3307288)\\ &=36.771866-34.380989\\ &=2.390877,\\ P&=103.955233(0.6692712)\\ &\quad-100(0.6322813)\\ &=69.574244-63.228134\\ &=6.346110. \end{aligned} \]

คำตอบ: call ราคา \$2.390877 ต่อหุ้น กริดของ PDE (ระยะกริด \$0.25) ให้ 2.390636 ห่างกันแค่ $2.390877-2.390636=0.000241$ สองบัญชีคือ \$36.7719 กับ \$34.3810 ตรงกับขาหุ้นและเงินกู้ของพอร์ตเลียนแบบพอดี put ราคา \$6.346110 ต่อหุ้น

option ในตลาดหนึ่งสัญญาครอบหุ้น 100 หุ้น ราคาต่อสัญญาจึงเป็น call $100\times2.390877=\$239.09$ และ put $100\times6.346110=\$634.61$

ตรวจเองใน 10 วินาที: ตาราง Normal ส่วนใหญ่ให้แต่ค่าบวก จึงหา $\Phi(0.3379)$ ก่อน แล้วใช้ $\Phi(-x)=1-\Phi(x)$ ตารางให้ $\Phi(0.33)=0.6293$ และ $\Phi(0.34)=0.6331$ ต่างกัน $0.6331-0.6293=0.0038$ ประมาณเชิงเส้นระหว่างสองค่านี้ แล้วตรวจ parity:

\[ \begin{aligned} \Phi(0.3379)&\approx0.6293+\tfrac{0.3379-0.33}{0.01}(0.0038)\\ &=0.6293+0.79(0.0038)=0.6323,\\ \Phi(d_1)&=1-0.6323=0.3677,\\ C-P&=2.3909-6.3461=-3.9552,\\ S_0-Ke^{-rT}&=100-103.9552=-3.9552. \end{aligned} \]

ค่า $\Phi(d_1)$ จากตารางตรงกับสูตร และ $C-P$ เท่ากับ $S_0-Ke^{-rT}$ parity จึงผ่าน

ขั้นที่ 8 — อ่าน Φ(d₂) และ Φ(d₁) ให้ถูก แล้วตอบโจทย์เปิดเรื่อง

สูตรมีตัวเลขสองตัวที่คนอ่านผิดบ่อยที่สุด คือ $\Phi(d_2)$ กับ $\Phi(d_1)$ ขั้นนี้แปลความหมายของทั้งสองตัว แล้วใช้มันตอบโจทย์เปิดเรื่องให้ครบ

โจทย์ให้อะไรมาบ้าง:

  • ค่าจากขั้นที่ 7: $\Phi(d_2)=0.330729$, $\Phi(d_1)=0.367719$ และ $e^{-rT}=e^{-0.01}=0.9900498$
  • forward $F=101.0050$ จากขั้นที่ 2
  • อัตราโตจริงของหุ้น $\mu=12\%$ ต่อปี (สมมติ) ใช้เทียบกับโลกจริง

คำถามมีสามข้อ ในโลกตั้งราคา เมื่อได้ใช้สิทธิ์ หุ้นจบเฉลี่ยที่เท่าไร payoff เฉลี่ยเท่าไร และในโลกจริงที่หุ้นโต 12% ต่อปี โอกาสจบเหนือ strike เป็นเท่าไร

ค่าเฉลี่ยของหุ้นเฉพาะเส้นทางที่ใช้สิทธิ์ หาได้จากบัญชีได้หุ้นก่อนคิดลด $F\,\Phi(d_1)$ หารด้วยโอกาสใช้สิทธิ์ เหมือนหาค่าเฉลี่ยของกลุ่มย่อย ด้วยการเอาผลรวมของกลุ่มหารด้วยขนาดกลุ่ม ส่วนโอกาสจริงคำนวณด้วยสูตร $d_2$ เดิม แต่ใช้ $\mu$ แทน $r$ เรียกผลว่า $d_2^{\rm real}$

\[ \begin{aligned} \mathbb Q(S_T\gt K)&=\Phi(d_2)=0.330729,\\ \mathbb E^{\mathbb Q}[S_T\mid S_T\gt K]&=\frac{F\,\Phi(d_1)}{\Phi(d_2)}\\ &=\frac{101.0050(0.367719)}{0.330729}\\ &=112.3018,\\ 112.3018-105&=7.3018,\\ 0.330729(7.3018)&=2.414906,\\ 0.9900498(2.414906)&=2.390877,\\ \mu-\tfrac12\sigma^2&=0.12-0.02=0.10,\\ d_2^{\rm real}&=\frac{-0.0487902+0.10(0.25)}{0.10}\\ &=-0.2379,\\ \Phi(-0.2379)&=0.4060. \end{aligned} \]

คำตอบ: ภายใต้ $\mathbb Q$ เส้นทาง 33.07% จบเหนือ \$105 ในกลุ่มนั้นหุ้นจบเฉลี่ยที่ \$112.30 จึงจ่ายเฉลี่ย \$7.30 คูณกันได้ค่าเฉลี่ยของ payoff \$2.4149 คิดลดแล้วได้ \$2.3909 นี่คือคำตอบของโจทย์เปิดเรื่องครบทุกตัวเลข

$\Phi(d_1)=36.77\%$ ไม่ใช่โอกาส มันคือสัดส่วนของ forward ที่มาจากเส้นทางที่ใช้สิทธิ์: $F\,\Phi(d_1)=101.005\times0.3677=37.14$ จาก $F=101.005$ เหมือน $36/103$ ในโลกสามราคา นอกจากนี้ $\Phi(d_1)=0.3677$ ยังเป็นจำนวนหุ้นที่ผู้ขาย call ต้องถือไว้ hedge ต่อ call หนึ่งตัว

สิ่งที่ต้องไม่สับสน: ถ้าหุ้นโตจริง 12% ต่อปี โอกาสจริงที่หุ้นจะจบเหนือ \$105 คือ 40.60% ไม่ใช่ 33.07% แต่ราคา call ไม่ขยับตาม 40.60% เพราะต้นทุน hedge ไม่ขึ้นกับ $\mu$ ดังนั้น $\Phi(d_2)$ คือน้ำหนักที่ใช้ตั้งราคา ไม่ใช่คำทำนาย

ขั้นที่ 9 — ตรวจโดยไม่ต้องเชื่อสูตร: ขอบเขต และความผันผวนที่ปลายสุด

สูตรยาวขนาดนี้พิมพ์ผิดได้ง่าย ก่อนใช้ราคาใด ๆ จึงควรตรวจกับขอบเขตที่จริงเสมอ โดยไม่ต้องพึ่งแบบจำลอง ขอบเขตมีสองข้าง:

  • เพดาน: payoff ของ call คือ $(S_T-K)^+$ ซึ่งไม่เกิน $S_T$ เสมอ ราคา call วันนี้จึงไม่เกินราคาหุ้นวันนี้ $S_0$
  • พื้น: payoff ไม่ต่ำกว่าศูนย์ และไม่ต่ำกว่า $S_T-K$ สัญญาที่จ่าย $S_T-K$ ในวันหมดอายุมีค่าวันนี้ $S_0-Ke^{-rT}$ (หุ้นหนึ่งหุ้น ลบมูลค่าวันนี้ของเงิน $K$) ราคา call จึงไม่ต่ำกว่าตัวที่มากกว่าในสองตัวนี้

จากนั้นดูว่าสูตรวิ่งไปที่ไหน เมื่อความผันผวนเข้าใกล้ศูนย์ และเมื่อโตไม่จำกัด ราคาที่ความผันผวนอื่น ๆ คำนวณด้วยสูตรเดิม (ดูโค้ดท้ายหน้า)

\[ \begin{aligned} \max(S_0-Ke^{-rT},0)&\le C\le S_0,\\ S_0-Ke^{-rT}&=100-103.955=-3.955,\\ \max(-3.955,0)=0&\le2.3909\le100,\\ \sigma\to0:\ C&\to e^{-rT}\max(F-K,0)=0,\\ \sigma=0.10:\ C&=0.6393,\\ \sigma=0.20:\ C&=2.3909,\\ \sigma=0.40:\ C&=6.2973,\\ \sigma=1.20:\ C&=22.12,\\ \sigma=4:\ C&=67.65,\\ \sigma\to\infty:\ C&\to S_0=100. \end{aligned} \]

เมื่อ $\sigma\to0$ หุ้นไม่แกว่ง และจะจบที่ forward \$101.005 แน่นอน ซึ่งต่ำกว่า strike \$105 ทั้ง $d_1$ และ $d_2$ จึงวิ่งไป $-\infty$ และสองบัญชีหายหมด ราคาศูนย์นี้คือสิ่งที่นักศึกษาในโจทย์เปิดเรื่องคำนวณ การเอาค่าเฉลี่ยใส่ payoff จึงเท่ากับตั้งราคาในโลกที่ไม่มีความผันผวน ทุกเซนต์ของราคา call ที่เหนือศูนย์จึงเป็นราคาของความผันผวน

เมื่อ $\sigma\to\infty$ จะได้ $d_1\to+\infty$ และ $d_2\to-\infty$ บัญชีได้หุ้นเข้าหา $S_0$ ส่วนบัญชีจ่าย strike เข้าหาศูนย์ ราคาจึงเข้าหาหุ้นทั้งตัว แต่ช้ามาก ที่ความผันผวน 400% ราคายังเป็นแค่ \$67.65

ช่วงกลางราคาเพิ่มเกือบเป็นเส้นตรง จาก 20% ไป 40% ราคาขึ้น $(6.2973-2.3909)/2=\$1.95$ ต่อความผันผวน 10 จุด ความไวของราคาต่อความผันผวนนี้ชื่อ vega ซึ่งเป็นหนึ่งใน the Greeks และเพราะราคาเพิ่มตามความผันผวนเสมอ ราคาตลาดแต่ละราคาจึงย้อนกลับไปหาความผันผวนได้ค่าเดียว ค่านั้นเรียกว่า implied volatility

ขั้นที่ 10 — ตรวจด้วยสองวิธีที่ไม่ใช้พีชคณิต: ต้นไม้ binomial และการสุ่ม

การพิสูจน์ในขั้นที่ 3 ถึง 6 ใช้พีชคณิตหลายขั้น ถ้าพลาดตรงไหนสักจุด สูตรจะผิดทั้งสูตร ขั้นนี้จึงตรวจสูตรด้วยสองวิธีที่ไม่ใช้พีชคณิตนั้นเลย

วิธีแรก ต้นไม้ binomial: แบ่งอายุ $T$ เป็น $n$ งวด ทุกงวดหุ้นขึ้นเป็น $u$ เท่า หรือลงเป็น $d$ เท่า แล้วไล่ราคาถอยหลังจากวันหมดอายุด้วยพอร์ตเลียนแบบ ค่าที่ใช้:

  • $u=e^{\sigma\sqrt{T/n}}$ และ $d=1/u$ คือขนาดการขึ้นลงต่องวด ตั้งให้ความผันผวนตรงกับ $\sigma$
  • $R=e^{rT/n}$ คือตัวคูณที่เงิน \$1 โตในหนึ่งงวด
  • $w=(R-d)/(u-d)$ คือน้ำหนักตั้งราคาของการขึ้น ซึ่งทำให้หุ้นโตเฉลี่ย $R$ เท่าต่องวด
  • $\eta$ คือจำนวนครั้งขึ้นน้อยที่สุด ที่ทำให้หุ้นจบเหนือ strike

ราคาจากต้นไม้เขียนเป็นผลรวมได้ และแยกเป็นบัญชีได้หุ้นกับบัญชีจ่าย strike ได้แบบเดียวกับสูตร

วิธีที่สอง การสุ่ม: สุ่ม $Z$ 200,000 ค่า โดยใช้ตัวสร้างเลขสุ่มชื่อ mulberry32 เริ่มที่ seed 2024 แล้วแปลงเป็น Normal ด้วยวิธี Box–Muller แต่ละค่าสร้าง $S_T$ ด้วยสูตรของขั้นที่ 2 แล้วเฉลี่ย payoff และคิดลด ผลเฉลี่ยเรียกว่า $\hat C$ ความคลาดของมันวัดด้วย standard error (SE) คือ SD ของ payoff ที่คิดลดแล้ว หารด้วย $\sqrt{200{,}000}$ ส่วน $\hat p$ คือสัดส่วนเส้นทางที่จบเหนือ \$105

\[ \begin{aligned} C_n&=\frac{S_0}{R^n}\sum_{j=\eta}^{n}\binom nj w^j(1-w)^{n-j}u^jd^{n-j}\\ &\quad-\frac{K}{R^n}\sum_{j=\eta}^{n}\binom nj w^j(1-w)^{n-j},\\ C_{10}&=2.4238,\ \ C_{100}=2.3988,\\ C_{1000}&=2.3914,\\ \hat C&=2.3773,\ \ \operatorname{SE}=0.0109,\\ \frac{\hat C-C}{\operatorname{SE}}&=\frac{2.3773-2.3909}{0.0109}=-1.25,\\ \hat p&=\frac{65{,}811}{200{,}000}=0.329055. \end{aligned} \]

คำตอบ: ต้นไม้เข้าหา \$2.3909 เมื่อจำนวนงวดเพิ่ม ระยะห่างคือ $2.4238-2.3909=0.0329$ ที่ 10 งวด, $2.3988-2.3909=0.0079$ ที่ 100 งวด และ $2.3914-2.3909=0.0005$ ที่ 1,000 งวด ผลรวมตัวที่สอง $\sum_{j\ge\eta}\binom nj w^j(1-w)^{n-j}$ คือโอกาสใช้สิทธิ์ในต้นไม้ และเข้าหา $\Phi(d_2)$

การสุ่มห่างจากสูตร 1.25 SE ส่วนสัดส่วนเส้นทางที่ใช้สิทธิ์ $\hat p=0.329055$ เทียบกับ $\Phi(d_2)=0.330729$ ต้องใช้ SE ของสัดส่วน:

\[ \begin{aligned} \operatorname{SE}_p&=\sqrt{\frac{0.3307(0.6693)}{200{,}000}}=0.00105,\\ \frac{\hat p-\Phi(d_2)}{\operatorname{SE}_p}&=\frac{0.329055-0.330729}{0.00105}\\ &=-1.59. \end{aligned} \]

ทั้งสองวิธีห่างจากสูตรไม่ถึง 2 SE ซึ่งเป็นระยะคลาดปกติของการสุ่ม สูตรจึงผ่านการตรวจที่ไม่ได้ใช้พีชคณิตของสองบัญชีเลย

ตรวจเองใน 10 วินาที: การสุ่ม 200,000 เส้นทางให้ความแม่นแค่ราว ±0.011 ขณะที่สูตรให้ 2.390877 ทันที SE ลดลงตาม $1/\sqrt n$ ถ้าอยากได้ SE 0.001 ต้องใช้ $(0.0109/0.001)^2\times200{,}000=23{,}762{,}000$ หรือราว 24 ล้านเส้นทาง การสุ่มจึงเก็บไว้ใช้กับสัญญาที่ไม่มีสูตรปิด (ดู Monte Carlo) ส่วนต้นไม้เก็บไว้ใช้กับ option ที่ใช้สิทธิ์ก่อนวันหมดอายุได้

ขั้นที่ 11 — หุ้นที่จ่ายปันผล: หักปันผลออกจากการโตของหุ้น

ทุกอย่างที่ผ่านมาสมมติว่าหุ้นไม่จ่ายปันผล แต่ option จำนวนมากเขียนบนดัชนี เช่น S&P 500 ซึ่งเป็นดัชนีของหุ้นใหญ่ 500 ตัวในสหรัฐ หุ้นหลายร้อยตัวในดัชนีจ่ายปันผลกระจายกันตลอดปี ผู้ถือ call ไม่ได้ปันผลนั้น เพราะยังไม่ได้ถือหุ้นจริง

เพื่อให้คำนวณง่าย สมมติว่าปันผลไหลออกจากหุ้นอย่างต่อเนื่องในอัตรา $q$ ต่อปี เรียกว่า dividend yield ภายใต้ $\mathbb Q$ ผลตอบแทนรวมของหุ้นยังต้องเท่าดอกเบี้ย $r$ แต่ส่วนหนึ่งขนาด $q$ ออกมาเป็นเงินปันผล ราคาหุ้นจึงโตแค่ $r-q$

ทุกขั้นที่ผ่านมาใช้ได้เหมือนเดิม แค่เปลี่ยนอัตราโตของหุ้นจาก $r$ เป็น $r-q$ ส่วนการคิดลดยังใช้ $r$ (ปันผลที่จ่ายเป็นก้อนอยู่ในหน้า ปันผลในสูตรราคา) ตัวอย่างใช้ call ตัวเดิม แต่ให้หุ้นจ่ายปันผล $q=2\%$ ต่อปี

\[ \begin{aligned} S_T&=S_0e^{(r-q-\frac12\sigma^2)T+\sigma\sqrt T\,Z},\\ F&=S_0e^{(r-q)T},\\ d_2&=\frac{\ln(S_0/K)+(r-q-\frac12\sigma^2)T}{\sigma\sqrt T},\\ d_1&=d_2+\sigma\sqrt T,\\ C&=S_0e^{-qT}\Phi(d_1)-Ke^{-rT}\Phi(d_2),\\ P+S_0e^{-qT}&=C+Ke^{-rT},\\ (r-q-\tfrac12\sigma^2)T&=(0.04-0.02-0.02)(0.25)\\ &=0,\\ d_2&=\frac{-0.0487902+0}{0.10}=-0.4879016,\\ d_1&=-0.4879016+0.10=-0.3879016,\\ e^{-qT}&=e^{-0.02(0.25)}=0.9950125,\\ C&=100(0.9950125)(0.3490444)\\ &\quad-103.955233(0.3128098)\\ &=34.730355-32.518211\\ &=2.212144,\\ P&=2.212144-99.501248+103.955233\\ &=6.666128. \end{aligned} \]

ที่ $q=2\%$ อัตราโตลบครึ่งของ $\sigma^2$ เป็นศูนย์พอดี ตัวเศษของ $d_2$ จึงเหลือแค่ $\ln(S_0/K)$ ค่า $\Phi(d_1)=0.3490444$ และ $\Phi(d_2)=0.3128098$ เปิดจากตารางแบบขั้นที่ 7 ส่วน put ใช้ parity ที่มีปันผล โดย $S_0e^{-qT}=100(0.9950125)=99.501248$

$e^{-qT}$ หน้าบัญชีได้หุ้นมีความหมายตรง ๆ ถ้าซื้อหุ้นวันนี้แค่ $e^{-0.005}=0.9950$ หุ้น แล้วเอาปันผลที่ได้ซื้อหุ้นเพิ่มไปเรื่อย ๆ วันหมดอายุจะมีหุ้นครบหนึ่งหุ้นพอดี ผู้ถือ call ได้หุ้นหนึ่งหุ้นตอนใช้สิทธิ์ แต่ไม่ได้ปันผลระหว่างทาง บัญชีได้หุ้นจึงมีค่าลดลงตามสัดส่วนนี้

ปันผลทำให้ forward ลดลง จาก $100e^{0.01}=101.005$ เหลือ $100e^{0.005}=100.501$ หุ้นจึงมีโอกาสจบเหนือ strike น้อยลง call ถูกลง $2.390877-2.212144=\$0.1787$ และ put แพงขึ้น $6.666128-6.346110=\$0.3200$ บรรทัด parity ที่มีปันผลได้มาจากการประกอบสูตรแบบเดิม แค่ $S_0$ กลายเป็น $S_0e^{-qT}$

อีกตัวอย่างหนึ่ง เพื่อเทียบกับการคำนวณ integral ตรง ๆ ใช้ตัวเลขสมมติ: หุ้น \$100, strike \$80, อายุ 1 ปี, ดอกเบี้ย 5%, ปันผล 1% และความผันผวน 30% (ครึ่งของ $\sigma^2$ คือ $0.09/2=0.045$)

\[ \begin{aligned} d_2&=\frac{\ln(100/80)+(0.05-0.01-0.045)(1)}{0.30}\\ &=\frac{0.223144-0.005}{0.30}=0.7271,\\ d_1&=0.7271+0.30=1.0271,\\ C&=100e^{-0.01}\Phi(1.0271)\\ &\quad-80e^{-0.05}\Phi(0.7271)\\ &=99.0050(0.847824)\\ &\quad-76.0984(0.766431)\\ &=83.9388-58.3242=25.6146. \end{aligned} \]

ถ้าคำนวณ integral ของขั้นที่ 3 ด้วย trapezoid rule ช่องละ \$0.20 จำนวน 4,096 ช่อง (ตั้งแต่ \$80 ถึง $80+4{,}096\times0.20=\$899.20$) ก็ได้ 25.6146 เช่นกัน

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

ใช้ $\Phi(d_2)$ ทั้งสองบัญชี: ความผิดนี้ลืมว่าบัญชีได้หุ้นนับเส้นทางหนักตามราคาหุ้น ผลที่ได้คือ $(S_0-Ke^{-rT})\Phi(d_2)=(100-103.9552)(0.3307)=-1.3081$ ราคาติดลบ ซึ่งเป็นไปไม่ได้ เพราะ payoff ไม่เคยติดลบ ที่ถูกคือ $S_0\Phi(d_1)-Ke^{-rT}\Phi(d_2)=36.7719-34.3810=\$2.3909$

ใส่หน่วยผิด: สูตรต้องการอายุเป็นปี และความผันผวนเป็นทศนิยม ลองใช้ call ของโจทย์ข้อ 1 ด้านล่าง (หุ้น \$35 strike \$36 อายุ 3 เดือน ความผันผวน 24%) ราคาที่ถูกคือ \$1.3154

  • ใส่อายุ $T=3$ (นึกว่าเป็นเดือน) แทน 0.25 จะได้ \$6.2371 แพงเกินจริง $6.2371/1.3154=4.74$ เท่า
  • ใส่ความผันผวน 24 แทน 0.24 ราคาจะชนเพดาน คือเกือบ \$35 เต็ม
  • ใส่อายุ 90 (วัน) แทน 0.25 ปีใน call \$105 ของโจทย์เปิดเรื่อง จะได้ \$97.40 แทน \$2.3909

สูตรไม่ร้องเตือนเอง โค้ดท้ายหน้าจึงปฏิเสธความผันผวนที่เกิน 5 (500%) และอายุที่เกิน 30 ปี

ลืมปันผล: ตั้งราคา call บนดัชนีที่จ่ายปันผล 2% ต่อปี แต่ใส่ $q=0$ จะได้ \$2.3909 แทน \$2.2121 แพงเกิน $(2.3909-2.2121)/2.2121=8.1\%$ และ put ถูกเกิน $6.6661-6.3461=\$0.32$ ทั้งสองราคาผ่านการตรวจขอบเขตได้สบาย ความผิดนี้จึงหลุดไปถึงใบเสนอราคาลูกค้าได้

เชื่อว่า GBM คือหุ้นจริง: สูตรสมมติสามอย่าง คือหุ้นไม่กระโดด หางของผลตอบแทนบางแบบ Normal และความผันผวนคงที่ หุ้นจริงไม่เป็นแบบนั้น และทุกโต๊ะรู้ดี ถ้าใช้ความผันผวนค่าเดียวกับทุก strike ราคา put ที่ strike ต่ำจะถูกเกินไป เพราะหุ้นจริงร่วงแรงบ่อยกว่าที่ Normal บอก ตลาดแก้ด้วยการใส่ความผันผวนคนละค่าให้แต่ละ strike ภาพของความผันผวนที่เปลี่ยนตาม strike นี้เรียกว่า volatility smile

ใช้ทำอะไรบนโต๊ะจริง

บนโต๊ะเทรดจริง ไม่มีใครใช้สูตรนี้ทำนายว่าราคา option ควรเป็นเท่าไร เพราะราคามีให้เห็นบนจออยู่แล้ว ที่ใช้จริงคือเดินย้อน: ใส่ราคาตลาดเข้าไป แล้วแก้หาความผันผวนที่ทำให้สูตรให้ราคานั้นพอดี ค่าที่ได้เรียกว่า implied volatility

ทำไมต้องย้อน เพราะราคาเป็นดอลลาร์เทียบข้ามสัญญาไม่ได้ call อายุ 1 เดือนกับ call อายุ 1 ปีราคาต่างกันมาก ด้วยเหตุผลเรื่องเวลาล้วน ๆ แต่ implied volatility เป็นหน่วย “ต่อปี” เดียวกันหมด จึงเทียบข้าม strike ข้ามอายุ และข้ามหุ้นได้ เทรดเดอร์จึงเสนอราคากันเป็น “vol” ไม่ใช่เป็นดอลลาร์ คนในวงการพูดถึงการใช้แบบนี้ว่า “ใส่ตัวเลขผิดลงในสูตรผิด เพื่อให้ได้ราคาที่ถูก”

สูตรยังเป็นใบสั่งงานของโต๊ะ hedge ด้วย: ต่อ call ที่ขายไปหนึ่งตัว ให้ถือหุ้น $\Phi(d_1)$ หุ้น และกู้เงิน $Ke^{-rT}\Phi(d_2)$ ดอลลาร์ ตัวคูณสัญญา 100 หุ้นให้คูณตอนท้ายเสมอ ไม่ใส่ไว้กลางสูตร call \$2.3909 ต่อหุ้นจึงเป็น $100\times2.3909=\$239.09$ ต่อสัญญา

// Black-Scholes from its two legs: toy, formula, bounds, limits, binomial tree, simulation, dividends.
const { abs, exp, log, sqrt, max, sin, cos, imul, PI } = Math;
function checkInputs(S, K, T, r, sigma, q = 0) {
  if (![S, K, T, r, sigma, q].every(Number.isFinite)) throw new TypeError('Inputs must be finite numbers');
  if (S <= 0 || K <= 0) throw new RangeError('Spot and strike must be positive');
  if (T <= 0 || T > 30) throw new RangeError('Time to expiry must be in years, above 0 and at most 30 (0.25 = 3 months)');
  if (sigma <= 0 || sigma > 5) throw new RangeError('Volatility must be per year, above 0 and at most 5 (0.20 = 20%)');
}
const phi = x => exp(-0.5 * x * x) / sqrt(2 * PI);
function Phi(x) { // normal CDF: series near the centre, continued fraction in the tails
  const a = abs(x);
  if (a <= 3) { let t = a, s = a; for (let n = 1; n < 200 && t > 1e-17 * s; n++) { t *= a * a / (2 * n + 1); s += t; }
    return x >= 0 ? 0.5 + phi(a) * s : 0.5 - phi(a) * s; }
  let f = a; for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - phi(a) / f : phi(a) / f;
}
function blackScholes(S, K, T, r, sigma, q = 0) { // d2 first: it is the exercise threshold
  checkInputs(S, K, T, r, sigma, q);
  const sT = sigma * sqrt(T), D = exp(-r * T), Dq = exp(-q * T);
  const d2 = (log(S / K) + (r - q - 0.5 * sigma * sigma) * T) / sT, d1 = d2 + sT;
  const stockLeg = S * Dq * Phi(d1), strikeLeg = K * D * Phi(d2);
  return { d1, d2, Nd1: Phi(d1), Nd2: Phi(d2), stockLeg, strikeLeg, call: stockLeg - strikeLeg,
    put: K * D * Phi(-d2) - S * Dq * Phi(-d1) };
}
function toy(prices, weights, K, growth) { // three prices at expiry: two accounts
  const avg = f => prices.reduce((a, s, i) => a + weights[i] * f(s), 0);
  const forward = avg(s => s), stock = avg(s => (s > K ? s : 0)), exercise = avg(s => (s > K ? 1 : 0));
  return { forward, stock, strike: K * exercise, exercise, share: stock / forward, price: (stock - K * exercise) / growth };
}
function binomial(S, K, T, r, sigma, n) { // u = e^(sigma sqrt(T/n)), d = 1/u, march backwards
  const h = T / n, u = exp(sigma * sqrt(h)), d = 1 / u, R = exp(r * h), q = (R - d) / (u - d);
  let V = Array.from({ length: n + 1 }, (_, j) => max(S * u ** j * d ** (n - j) - K, 0));
  for (let t = n - 1; t >= 0; t--) for (let j = 0; j <= t; j++) V[j] = (q * V[j + 1] + (1 - q) * V[j]) / R;
  return V[0];
}
function trapezoid(S, K, T, r, sigma, q, eta, N) { // integrate (s - K) f(s) ds from K to K + N eta
  const m = log(S) + (r - q - 0.5 * sigma * sigma) * T, v = sigma * sqrt(T);
  const f = s => phi((log(s) - m) / v) / (s * v);
  let sum = 0;
  for (let j = 0; j <= N; j++) { const s = K + j * eta, w = (j === 0 || j === N) ? eta / 2 : eta; sum += (s - K) * f(s) * w; }
  return exp(-r * T) * sum;
}
function normals(seed) { // mulberry32 + Box-Muller
  let a = seed >>> 0, spare = null;
  const u = () => { a = (a + 0x6D2B79F5) >>> 0; let t = imul(a ^ (a >>> 15), a | 1);
    t ^= t + imul(t ^ (t >>> 7), t | 61); return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296; };
  return () => { if (spare !== null) { const z = spare; spare = null; return z; }
    const rad = sqrt(-2 * log(u())), ang = 2 * PI * u(); spare = rad * sin(ang); return rad * cos(ang); };
}
function monteCarlo(S, K, T, r, sigma, n, seed) {
  const z = normals(seed), drift = (r - 0.5 * sigma * sigma) * T, sT = sigma * sqrt(T), D = exp(-r * T);
  let sum = 0, sum2 = 0, hits = 0, sumS = 0;
  for (let i = 0; i < n; i++) { const ST = S * exp(drift + sT * z()), pay = max(ST - K, 0);
    sum += pay; sum2 += pay * pay; sumS += ST; if (ST > K) hits++; }
  const mean = sum / n, sd = sqrt((sum2 - n * mean * mean) / (n - 1));
  return { n, price: D * mean, se: D * sd / sqrt(n), exercised: hits / n, meanST: sumS / n };
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ราคา call คือค่าเฉลี่ยของ payoff ภายใต้ $\mathbb Q$ แล้วคิดลด: $C=e^{-rT}\mathbb E^{\mathbb Q}[(S_T-K)^+]$ แยกเป็นบัญชีได้หุ้นกับบัญชีจ่าย strike ได้ $C=S_0\Phi(d_1)-Ke^{-rT}\Phi(d_2)$ ส่วน put ได้จากพื้นที่อีกฝั่งของเกณฑ์เดียวกัน
  • $d_2$ มาจากการแปลงเงื่อนไข $S_T\gt K$ เป็น $Z\gt-d_2$ ส่วน $d_1=d_2+\sigma\sqrt T$ มาจากการจัดกำลังสองสมบูรณ์ เมื่อนับเส้นทางหนักตามราคาหุ้น
  • call strike \$105 บนหุ้น \$100 อายุ 3 เดือน ราคา \$2.3909 และ put ราคา \$6.3461 ตรงกับกริดของ PDE ต้นไม้ 1,000 งวด และการสุ่ม 200,000 เส้นทาง
  • $\Phi(d_2)=33.07\%$ คือโอกาสใช้สิทธิ์ภายใต้ $\mathbb Q$ ไม่ใช่โอกาสจริง (โอกาสจริงคือ 40.60% ถ้าหุ้นโต 12% ต่อปี) ส่วน $\Phi(d_1)=36.77\%$ คือจำนวนหุ้นที่ต้องถือไว้ hedge
