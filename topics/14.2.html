14.2 The Black–Scholes Formula

ราคา call คือค่าเฉลี่ยของ payoff ในโลกที่หุ้นโตเท่าดอกเบี้ย คิดลดกลับมาวันนี้ แยกเป็นขาหุ้นกับขา strike จึงได้สูตรสองพจน์

หุ้นราคา \$100 มี call strike \$105 อายุ 3 เดือน (0.25 ปี) ดอกเบี้ย 4% ต่อปี ความผันผวน 20% ต่อปี นักศึกษาฝึกงานคิดว่า ในโลกที่ใช้ตั้งราคา หุ้นโตเท่าดอกเบี้ย ราคาเฉลี่ยวันหมดอายุจึงเป็น $100e^{0.04\times0.25}\approx\$101.01$ ต่ำกว่า strike ราว \$4 call นี้ “เฉลี่ยแล้วไม่มีค่า” เขาจึงยอมขายที่ \$0.10 แต่ 14.1 แก้ PDE ได้ \$2.3909 ใครถูก และเงิน \$2.39 มาจากไหน?

ลองตอบก่อนเปิดเฉลย

14.1 ถูก นักศึกษาเอาราคาเฉลี่ยใส่ลงใน payoff ซึ่งเท่ากับคิดว่าหุ้นไม่แกว่งเลย แต่ payoff ของ call ไม่เคยติดลบ เส้นทางที่จบต่ำกว่า \$105 ให้ศูนย์ ส่วนเส้นทางที่จบสูงกว่าให้เงินจริง หน้านี้จะคำนวณว่า 33.07% ของเส้นทาง (ภายใต้น้ำหนักที่ใช้ตั้งราคา) จบเหนือ \$105 และเมื่อจบเหนือ หุ้นอยู่ที่เฉลี่ย \$112.30 จ่ายเฉลี่ย \$7.30 ค่าเฉลี่ยของ payoff จึงเป็น $0.3307\times7.302\approx\$2.415$ คิดลดกลับมาวันนี้ได้ \$2.3909 การขายที่ \$0.10 คือแจกเงินราว \$2.29 ต่อหุ้น

สิ่งที่เราจะสร้าง

14.1 ได้ราคา \$2.3909 จากการแก้ PDE บนกริด ซึ่งเป็นตัวเลขจากคอมพิวเตอร์ ไม่ใช่สูตร 13.7 (Feynman–Kac) บอกว่าคำตอบของ PDE แบบนี้คือค่าเฉลี่ยของ payoff ที่คิดลดแล้ว เมื่อให้หุ้นโตในอัตรา $r$ แทน $\mu$ ซึ่งคือน้ำหนักแบบ risk-neutral ของ 13.6 หัวข้อนี้คำนวณค่าเฉลี่ยนั้นออกมาเป็นสูตรที่กดเครื่องคิดเลขได้

เราจะทำโลกที่หุ้นปลายทางมีแค่สามราคาด้วยมือก่อน เพื่อเห็นว่า payoff แยกเป็นขาหุ้นกับขา strike ได้อย่างไร แล้วทำแบบต่อเนื่อง: เขียนหุ้นปลายทางด้วยก้อนสุ่มก้อนเดียว แปลงเงื่อนไขใช้สิทธิ์เป็นเกณฑ์ของก้อนสุ่ม (ได้ $d_2$) จัดกำลังสองสมบูรณ์ให้ขาหุ้น (ได้ $d_1$) ประกอบเป็นสูตร แทนตัวเลข ตรวจด้วยขอบเขตและการสุ่ม แล้วขยายไปหุ้นที่จ่ายปันผล กับตัวอย่างที่สองที่ 14.3 จะใช้ต่อ

ขั้นที่ 1 — ลองด้วยมือ: หุ้นปลายทางมีแค่สามราคา

โจทย์ให้อะไรมาบ้าง: หุ้นวันนี้ \$100 วันหมดอายุเป็นได้ \$90, \$100 หรือ \$120 น้ำหนักที่ใช้ตั้งราคาคือ 0.3, 0.4 และ 0.3 เงิน \$1 วันนี้โตเป็น \$1.03 ตอนหมดอายุ หาราคา call strike \$105 และแยกเป็นสองบัญชี

\[ \begin{aligned} F&=0.3(90)+0.4(100)+0.3(120)\\ &=103=100(1.03),\\ (S_T-K)^+&=0,\ 0,\ 15,\\ \text{stock}&=0.3(120)=36,\\ \text{strike}&=105(0.3)=31.5,\\ C&=\frac{36-31.5}{1.03}=\frac{4.5}{1.03}\\ &\approx4.3689. \end{aligned} \]

คำตอบ: call ราคา \$4.3689 น้ำหนักชุดนี้ใช้ตั้งราคาได้เพราะค่าเฉลี่ยของหุ้นคือ 103 เท่ากับเงิน \$100 ที่ฝากไว้ หุ้นจึงโตเฉลี่ยเท่าดอกเบี้ยพอดี แบบเดียวกับน้ำหนัก 0.5 ในขั้นที่ 1 ของ 14.1 บัญชี “ได้หุ้น” มีเฉพาะเส้นทาง \$120 (36) และบัญชี “จ่าย strike” มีเฉพาะเส้นทางเดียวกัน (31.5) ลบกันได้ 4.5 เท่ากับค่าเฉลี่ยของ payoff

ตัวเลขสองตัวที่ต้องจำไว้: 0.3 คือโอกาสได้ใช้สิทธิ์ภายใต้น้ำหนักนี้ ซึ่งจะกลายเป็น $\Phi(d_2)$ และ $36/103\approx0.3495$ คือสัดส่วนของค่าเฉลี่ยหุ้นที่มาจากเส้นทางที่ใช้สิทธิ์ ซึ่งจะกลายเป็น $\Phi(d_1)$ ตัวหลังสูงกว่าเพราะเส้นทางที่ใช้สิทธิ์คือเส้นทางที่หุ้นราคาสูง

ตรวจเองใน 10 วินาที: $0.3(15)=4.5=36-31.5$ และถ้าเอาค่าเฉลี่ย 103 ใส่ payoff จะได้ $(103-105)^+=0$ ราคาศูนย์แบบที่นักศึกษาในโจทย์เปิดเรื่องคิด ทั้งที่ของจริงคือ \$4.37

ขั้นที่ 2 — ของที่ให้มา: หุ้นปลายทางเขียนด้วยก้อนสุ่มก้อนเดียว

ในโลกจริงหุ้นปลายทางมีได้ทุกค่า เราจึงต้องมีสูตรของ $S_T$ ก่อน ใช้ของที่พิสูจน์แล้วสามอย่าง: คำตอบของ GBM (10.1), $W_T=\sqrt T\,Z$ (9.1) และภายใต้น้ำหนักตั้งราคา drift $\mu$ กลายเป็น $r$ (13.6) บรรทัดที่เหลือตรวจว่าค่าเฉลี่ยของ $S_T$ เป็น forward จริง ด้วย $\mathbb E[e^{aZ}]=e^{a^2/2}$ ของ 1.10

\[ \begin{aligned} S_T&=S_0e^{(r-\frac12\sigma^2)T+\sigma\sqrt T\,Z},\\ Z&\sim\mathcal N(0,1),\\ \mathbb E^{\mathbb Q}[S_T]&=S_0e^{(r-\frac12\sigma^2)T}\,\mathbb E\big[e^{\sigma\sqrt T\,Z}\big]\\ &=S_0e^{(r-\frac12\sigma^2)T}e^{\frac12\sigma^2T}\\ &=S_0e^{rT}=F,\\ F&=100e^{0.01}\approx101.0050,\\ S_0e^{(r-\frac12\sigma^2)T}&=100e^{0.005}\approx100.5013. \end{aligned} \]

มีก้อนสุ่ม $Z$ ก้อนเดียว ทุกคำถามเรื่อง $S_T$ จึงกลายเป็นคำถามเรื่อง $Z$ ซึ่งมีตาราง ส่วน $-\tfrac12\sigma^2T$ ในเลขชี้กำลังมีไว้ชดเชย: exponential ของก้อนสุ่มดันค่าเฉลี่ยขึ้น $e^{\sigma^2T/2}$ เท่า (ความนูนของ exponential) สองตัวนี้หักกันพอดี ค่าเฉลี่ยจึงออกมาเป็น $F$

บรรทัดสุดท้ายคือค่ากลางของ $S_T$ (ตอน $Z=0$) ซึ่งเป็น median \$100.50 ต่ำกว่าค่าเฉลี่ย \$101.01 เพราะ lognormal เบ้ขวา ครึ่งหนึ่งของเส้นทางจบต่ำกว่า \$100.50 แต่เส้นทางที่ขึ้นแรงดึงค่าเฉลี่ยขึ้นไป

ขั้นที่ 3 — ราคาคือค่าเฉลี่ยคิดลด แล้วแยก payoff เป็นสองบัญชี

13.7 บอกว่าคำตอบของ PDE ใน 14.1 ที่มีเงื่อนไขปลายทางเป็น payoff คือค่าเฉลี่ยของ payoff ภายใต้ $\mathbb Q$ คูณ discount factor ขั้นนี้ใช้ indicator รวม payoff สองกรณีเป็นบรรทัดเดียวแล้วกระจาย แบบที่ทำด้วยมือในขั้นที่ 1

\[ \begin{aligned} C&=e^{-rT}\,\mathbb E^{\mathbb Q}\big[(S_T-K)^+\big],\\ (S_T-K)^+&=(S_T-K)\,\mathbf 1(S_T\gt K)\\ &=S_T\mathbf 1(S_T\gt K)-K\,\mathbf 1(S_T\gt K),\\ \mathbb E^{\mathbb Q}\big[\mathbf 1(S_T\gt K)\big]&=\mathbb Q(S_T\gt K),\\ C&=e^{-rT}\Big(\mathbb E^{\mathbb Q}\big[S_T\mathbf 1(S_T\gt K)\big]\\ &\qquad-K\,\mathbb Q(S_T\gt K)\Big). \end{aligned} \]

บรรทัดที่สองใช้ว่า indicator เป็น 1 เมื่อใช้สิทธิ์และเป็น 0 เมื่อไม่ใช้ คูณแล้วจึงได้ $S_T-K$ หรือ 0 ตรงกับ payoff ทั้งสองกรณี บรรทัดที่สี่ใช้ว่าค่าเฉลี่ยของ indicator คือ 1 คูณโอกาสที่เกิด บวก 0 คูณโอกาสที่ไม่เกิด

สองบัญชีหน้าตาไม่เหมือนกัน ขา strike คูณด้วย $K$ ที่คงที่ จึงเหลือแค่โอกาส ส่วนขาหุ้นมี $S_T$ ที่สุ่มอยู่ข้างใน เส้นทางที่หุ้นสูงจึงนับหนักกว่า ขาหุ้นต้องใช้ขั้นที่ 5 นี่คือเหตุผลที่สูตรสุดท้ายมีสองพจน์ และมีตัวเลข $d$ สองตัว

ขั้นที่ 4 — ขา strike: เงื่อนไขใช้สิทธิ์กลายเป็นเกณฑ์ของ Z

เรารู้ distribution ของ $Z$ แต่เงื่อนไข $S_T\gt K$ เขียนอยู่ในภาษาของราคา จึงต้องแปลงอสมการข้ามไป ใส่ log สองข้างได้โดยเครื่องหมายไม่พลิก เพราะ log เพิ่มขึ้นเสมอและราคาเป็นบวก แล้วหารด้วย $\sigma\sqrt T$ ที่เป็นบวก ตัวเลขใช้โจทย์เปิดเรื่อง

\[ \begin{aligned} \ln S_T&=\ln S_0+(r-\tfrac12\sigma^2)T+\sigma\sqrt T\,Z,\\ \ln S_T\gt\ln K\ &\Rightarrow\ Z\gt z^*,\\ z^*&=\frac{\ln(K/S_0)-(r-\frac12\sigma^2)T}{\sigma\sqrt T},\\ d_2&:=-z^*=\frac{\ln(S_0/K)+(r-\frac12\sigma^2)T}{\sigma\sqrt T},\\ \mathbb Q(S_T\gt K)&=\mathbb Q(Z\gt-d_2)=\Phi(d_2),\\ z^*&=\frac{0.048790-0.005}{0.10}=0.4379,\\ \Phi(d_2)&=\Phi(-0.4379)\approx0.3307. \end{aligned} \]

$z^*$ อ่านได้ตรง ๆ: log ของหุ้นต้องขึ้นจาก $\ln100$ ถึง $\ln105$ คือ 0.048790 แต่ค่ากลางของมันขึ้นแค่ $(0.04-0.02)(0.25)=0.005$ ส่วนที่ขาด 0.043790 หารด้วย SD ของ log ตลอด 3 เดือน $0.20\sqrt{0.25}=0.10$ ได้ 0.4379 SD เหมือน z-score ของ 1.9

บรรทัดที่ห้าใช้ความสมมาตรของระฆัง: พื้นที่ทางขวาของ $-d_2$ เท่ากับพื้นที่ทางซ้ายของ $d_2$ เราตั้งชื่อ $d_2$ ให้เป็นค่าลบของเกณฑ์ ก็เพื่อให้คำตอบเขียนเป็น $\Phi(d_2)$ ได้สั้น ๆ

ขั้นที่ 5 — ขาหุ้น: จัดกำลังสองสมบูรณ์ แล้ว d₁ ก็โผล่มา

ขาหุ้นมี $S_T$ คูณอยู่ใน integral ทำให้ข้างในเป็น $e^{\sigma\sqrt T z}\phi(z)$ ซึ่งไม่ใช่ density มาตรฐาน กลเม็ดคือรวมเลขชี้กำลังสองก้อนแล้วจัดกำลังสองสมบูรณ์ วิธีเดียวกับที่ 1.10 ใช้หาค่าเฉลี่ยของ lognormal ขอบล่างของ integral คือ $-d_2$ จากขั้นที่ 4

\[ \begin{aligned} \sigma\sqrt T z-\tfrac12z^2&=-\tfrac12\big(z-\sigma\sqrt T\big)^2\\ &\quad+\tfrac12\sigma^2T,\\ e^{\sigma\sqrt T z}\phi(z)&=e^{\frac12\sigma^2T}\phi\big(z-\sigma\sqrt T\big),\\ &\mathbb E^{\mathbb Q}\big[S_T\mathbf 1(S_T\gt K)\big]\\ &=S_0e^{(r-\frac12\sigma^2)T}\\ &\quad\times\int_{-d_2}^{\infty}e^{\sigma\sqrt T z}\phi(z)\,dz\\ &=S_0e^{rT}\int_{-d_2}^{\infty}\phi\big(z-\sigma\sqrt T\big)\,dz\\ &=F\int_{-d_2-\sigma\sqrt T}^{\infty}\phi(u)\,du\\ &=F\,\Phi\big(d_2+\sigma\sqrt T\big)=F\,\Phi(d_1),\\ d_1&:=d_2+\sigma\sqrt T. \end{aligned} \]

สองบรรทัดแรกตรวจได้ด้วยการกระจายกลับ: $-\tfrac12(z^2-2\sigma\sqrt T z+\sigma^2T)+\tfrac12\sigma^2T$ เหลือ $\sigma\sqrt T z-\tfrac12z^2$ บรรทัดที่สามจึงบอกว่าการถ่วงด้วยราคาหุ้นไม่ทำลายรูประฆัง แค่เลื่อนจุดกลางไป $\sigma\sqrt T$ แล้วทิ้งตัวคูณ $e^{\sigma^2T/2}$ ไว้ ซึ่งรวมกับ $e^{(r-\sigma^2/2)T}$ ได้ $e^{rT}$ พอดี

บรรทัดที่แปดเปลี่ยนตัวแปรเป็น $u=z-\sigma\sqrt T$ ขอบล่างจึงเลื่อนตาม บรรทัดที่เก้าใช้ความสมมาตรแบบขั้นที่ 4 ตัวเลขตรวจได้: ที่ $z=0.7$ และ $\sigma\sqrt T=0.1$ สองข้างของบรรทัดที่สามเท่ากันที่ 0.334895 นี่คือที่มาเดียวของ $d_1$ มันคือ $d_2$ ที่ถูกเลื่อนเพราะนับเส้นทางหนักตามราคาหุ้น

ขั้นที่ 6 — ประกอบเป็นสูตร call และ put

แทนผลของขั้นที่ 4 และ 5 ลงในสองบัญชีของขั้นที่ 3 แล้วทำซ้ำกับ put ซึ่ง payoff คือ $(K-S_T)^+=K\,\mathbf 1(S_T\lt K)-S_T\mathbf 1(S_T\lt K)$ เหตุการณ์ตรงข้ามคือพื้นที่อีกฝั่งของเกณฑ์เดิม จึงได้ $\Phi(-d)$ แทน $\Phi(d)$ โดยไม่ต้องคำนวณ integral ใหม่

\[ \begin{aligned} C&=e^{-rT}\big(F\,\Phi(d_1)-K\,\Phi(d_2)\big)\\ &=S_0\Phi(d_1)-Ke^{-rT}\Phi(d_2),\\ P&=Ke^{-rT}\Phi(-d_2)-S_0\Phi(-d_1),\\ C-P&=S_0\big[\Phi(d_1)+\Phi(-d_1)\big]\\ &\quad-Ke^{-rT}\big[\Phi(d_2)+\Phi(-d_2)\big]\\ &=S_0-Ke^{-rT}. \end{aligned} \]

บรรทัดที่สองใช้ $Fe^{-rT}=S_0$ ขาหุ้นจึงกลายเป็นราคาหุ้นวันนี้ ส่วนขา strike ยังคิดลดอยู่เพราะ strike จ่ายตอนหมดอายุ อ่านสูตรเป็นพอร์ตได้ทันที: ถือหุ้น $\Phi(d_1)$ หุ้น และกู้ $Ke^{-rT}\Phi(d_2)$ ซึ่งคือพอร์ตเลียนแบบของ 14.1 ขั้นที่ 7 จะเห็นเป็นตัวเลขว่าตรงกัน ส่วน 14.3 จะพิสูจน์ว่าความชัน $C_S$ เท่ากับ $\Phi(d_1)$ ทุกจุด

สองบรรทัดสุดท้ายใช้ $\Phi(x)+\Phi(-x)=1$ ผลคือ put–call parity ที่นี่ได้มาจากสูตร 14.4 จะพิสูจน์ใหม่โดยไม่ใช้แบบจำลองเลย จึงใช้ตรวจราคาจากตลาดได้

ขั้นที่ 7 — แทนตัวเลขของ call \$105

โจทย์ให้อะไรมาบ้าง: $S_0=100$, $K=105$, $T=0.25$, $r=0.04$, $\sigma=0.20$ ไม่มีปันผล ทำตามลำดับของการพิสูจน์: $d_2$ ก่อน แล้ว $d_1$ แล้วสองขา

\[ \begin{aligned} \ln(100/105)&=-0.0487902,\\ (r-\tfrac12\sigma^2)T&=0.02(0.25)=0.005,\\ \sigma\sqrt T&=0.20(0.5)=0.10,\\ d_2&=\frac{-0.0487902+0.005}{0.10}\\ &=-0.4379016,\\ d_1&=-0.4379016+0.10=-0.3379016,\\ \Phi(d_1)&=0.3677187,\ \ \Phi(d_2)=0.3307288,\\ Ke^{-rT}&=105e^{-0.01}=103.955233,\\ C&=100(0.3677187)\\ &\quad-103.955233(0.3307288)\\ &=36.771866-34.380989\\ &=2.390877,\\ P&=103.955233(0.6692712)\\ &\quad-100(0.6322813)\\ &=69.574244-63.228134\\ &=6.346110. \end{aligned} \]

คำตอบ: call \$2.390877 ต่อหุ้น ตรงกับกริดของ 14.1 (2.390636 ที่ระยะกริด \$0.25 ห่างกัน 0.000241) และสองขาคือ \$36.7719 กับ \$34.3810 ซึ่งเป็นขาหุ้นและเงินกู้ใน Figure 14.1a พอดี put \$6.346110 ต่อสัญญา 100 หุ้น call เป็น \$239.09 และ put เป็น \$634.61

ตรวจเองใน 10 วินาที: ตาราง Normal ให้ $\Phi(0.33)=0.6293$ และ $\Phi(0.34)=0.6331$ ประมาณเชิงเส้นที่ 0.3379 ได้ $0.6293+0.79(0.0038)\approx0.6323$ จึงได้ $\Phi(d_1)=1-0.6323=0.3677$ และ $C-P=2.3909-6.3461=-3.9552=100-103.9552$

ขั้นที่ 8 — อ่าน Φ(d₂) และ Φ(d₁) ให้ถูก แล้วตอบโจทย์เปิดเรื่อง

โจทย์ให้อะไรมาบ้าง: ค่าจากขั้นที่ 7 และ forward $F=101.0050$ จากขั้นที่ 2 หารสองบัญชีด้วยโอกาสใช้สิทธิ์ เพื่อได้ค่าเฉลี่ยเฉพาะเส้นทางที่ใช้สิทธิ์ แล้วเทียบกับโอกาสในโลกจริงที่หุ้นโต $\mu=12\%$ ต่อปีแบบ 10.1

\[ \begin{aligned} \mathbb Q(S_T\gt K)&=\Phi(d_2)=0.330729,\\ \mathbb E^{\mathbb Q}[S_T\mid S_T\gt K]&=\frac{F\,\Phi(d_1)}{\Phi(d_2)}\\ &=\frac{101.0050(0.367719)}{0.330729}\\ &=112.3018,\\ 112.3018-105&=7.3018,\\ 0.330729(7.3018)&=2.414906,\\ 0.9900498(2.414906)&=2.390877,\\ d_2^{\rm real}&=\frac{-0.0487902+0.10(0.25)}{0.10}\\ &=-0.2379,\ \ \Phi(-0.2379)=0.4060. \end{aligned} \]

คำตอบ: ภายใต้ $\mathbb Q$ 33.07% ของเส้นทางจบเหนือ \$105 เมื่อจบเหนือ หุ้นอยู่เฉลี่ย \$112.30 จ่ายเฉลี่ย \$7.30 คูณกันได้ค่าเฉลี่ยของ payoff \$2.4149 คิดลดได้ \$2.3909 ตอบโจทย์เปิดเรื่องครบ ส่วน $\Phi(d_1)=36.77\%$ ไม่ใช่โอกาส มันคือสัดส่วนของ forward ที่มาจากเส้นทางที่ใช้สิทธิ์ ($101.005\times0.3677=37.14$ จาก 101.005) เหมือน $36/103$ ในขั้นที่ 1 และคือจำนวนหุ้นที่ hedge ใน 14.1

ตรวจเองใน 10 วินาที: ถ้าหุ้นโตจริง 12% ต่อปี โอกาสจริงที่จะจบเหนือ \$105 คือ 40.60% ไม่ใช่ 33.07% ตัวเลข $\Phi(d_2)$ จึงเป็นน้ำหนักสำหรับตั้งราคา ไม่ใช่คำทำนาย และราคาไม่เปลี่ยนตาม 40.60% เพราะ 14.1 แสดงแล้วว่าต้นทุน hedge ไม่ขึ้นกับ $\mu$

ขั้นที่ 9 — ตรวจโดยไม่ต้องเชื่อสูตร: ขอบเขต และความผันผวนที่ปลายสุด

ก่อนใช้ราคาใด ๆ ให้ตรวจสองอย่างที่ไม่ขึ้นกับแบบจำลอง: payoff ของ call ไม่เกิน $S_T$ ราคาจึงไม่เกินหุ้น และ payoff ไม่ต่ำกว่า $S_T-K$ ซึ่งวันนี้มีค่า $S_0-Ke^{-rT}$ และไม่ต่ำกว่าศูนย์ จากนั้นดูว่าสูตรไปที่ไหนเมื่อความผันผวนเข้าใกล้ศูนย์และโตไม่จำกัด

\[ \begin{aligned} \max(S_0-Ke^{-rT},0)&\le C\le S_0,\\ \max(-3.955,0)=0&\le2.3909\le100,\\ \sigma\to0:\ C&\to e^{-rT}\max(F-K,0)=0,\\ \sigma=0.10:\ C&=0.6393,\\ \sigma=0.20:\ C&=2.3909,\\ \sigma=0.40:\ C&=6.2973,\\ \sigma=1.20:\ C&=22.12,\\ \sigma=4:\ C&=67.65,\\ \sigma\to\infty:\ C&\to S_0=100. \end{aligned} \]

เมื่อ $\sigma\to0$ ทั้ง $d_1$ และ $d_2$ วิ่งไป $-\infty$ เพราะ $F=101.005$ ต่ำกว่า $K=105$ สองขาจึงหายหมด ราคาศูนย์นี้คือสิ่งที่นักศึกษาในโจทย์เปิดเรื่องคำนวณ การเอาค่าเฉลี่ยใส่ payoff คือการตั้งราคาในโลกที่ไม่มีความผันผวน ราคา call ทุกเซนต์ที่เหนือศูนย์จึงเป็นราคาของความผันผวน

เมื่อ $\sigma\to\infty$ ได้ $d_1\to+\infty$ และ $d_2\to-\infty$ ราคาเข้าหาหุ้นทั้งตัว แต่ช้ามาก ที่ 400% ยังได้แค่ \$67.65 ระหว่าง 20% ถึง 40% ราคาขึ้นราว \$1.9 ต่อความผันผวน 10 จุด ความไวนี้คือ vega ที่ 14.3 จะคำนวณ

ขั้นที่ 10 — ตรวจด้วยการสุ่ม 200,000 เส้นทาง

โจทย์ให้อะไรมาบ้าง: สุ่ม $Z$ 200,000 ตัวด้วยเครื่องสุ่ม mulberry32 seed 2024 กับ Box–Muller แบบเดียวกับ 8.9 และ 14.1 สร้าง $S_T$ ด้วยสูตรขั้นที่ 2 แล้วเฉลี่ย payoff คิดลด SE คือ SD ของตัวอย่างหารด้วย $\sqrt n$ ตาม 3.3 ให้ $\hat p$ คือสัดส่วนเส้นทางที่จบเหนือ $K$ และ $\overline{S_T}$ คือค่าเฉลี่ยของหุ้นปลายทางที่สุ่มได้

\[ \begin{aligned} \hat C&=e^{-rT}\frac1n\sum_{i=1}^{n}\big(S_T^{(i)}-K\big)^+\\ &=2.3773,\ \ \operatorname{SE}=0.0109,\\ \frac{2.3773-2.3909}{0.0109}&\approx-1.25,\\ \hat p&=\frac{65{,}811}{200{,}000}=0.329055,\\ \sqrt{\frac{0.3307(0.6693)}{200{,}000}}&=0.00105,\\ \frac{0.329055-0.330729}{0.00105}&\approx-1.59,\\ \overline{S_T}&=101.0027. \end{aligned} \]

คำตอบ: ราคาจากการสุ่มห่างสูตร 1.25 SE สัดส่วนที่จบเหนือ \$105 ห่าง $\Phi(d_2)$ 1.59 SE และค่าเฉลี่ยของ $S_T$ คือ 101.0027 เทียบ $F=101.0050$ ทั้งสามตัวอยู่ในระยะที่การสุ่มคลาดได้ตามปกติ สูตรจึงผ่านการตรวจที่ไม่ได้ใช้พีชคณิตของขั้นที่ 4 ถึง 6 เลย

ตรวจเองใน 10 วินาที: การสุ่ม 200,000 เส้นทางให้ความแม่นแค่ ±0.011 ขณะที่สูตรให้ 2.390877 ทันที การสุ่มจึงมีไว้สำหรับสัญญาที่ไม่มีสูตรปิด (17.5) และถ้าอยากได้ SE 0.001 ต้องใช้ราว $(0.0109/0.001)^2\times200{,}000\approx24$ ล้านเส้นทาง

ขั้นที่ 11 — หุ้นที่จ่ายปันผล: หักปันผลออกจากการโตของหุ้น

ดัชนีอย่าง S&P 500 จ่ายปันผลตลอดปี ผู้ถือ call ไม่ได้ปันผลนั้น Merton (1973) สมมติให้ปันผลไหลออกต่อเนื่องอัตรา $q$ ต่อปี ผลตอบแทนรวมของหุ้นภายใต้ $\mathbb Q$ ยังเท่าดอกเบี้ย $r$ แต่ส่วนหนึ่ง $q$ ออกมาเป็นเงินปันผล ราคาหุ้นจึงโตแค่ $r-q$ ทุกขั้นที่ผ่านมาใช้ได้เหมือนเดิม แค่เปลี่ยนการโตของหุ้น ส่วนการคิดลดยังใช้ $r$

\[ \begin{aligned} S_T&=S_0e^{(r-q-\frac12\sigma^2)T+\sigma\sqrt T\,Z},\\ F&=S_0e^{(r-q)T},\\ d_2&=\frac{\ln(S_0/K)+(r-q-\frac12\sigma^2)T}{\sigma\sqrt T},\\ d_1&=d_2+\sigma\sqrt T,\\ C&=e^{-rT}\big(F\,\Phi(d_1)-K\,\Phi(d_2)\big)\\ &=S_0e^{-qT}\Phi(d_1)-Ke^{-rT}\Phi(d_2),\\ q=0.02:\ d_2&=\frac{-0.0487902+0}{0.10}=-0.4879016,\\ d_1&=-0.3879016,\\ C&=100(0.9950125)(0.3490444)\\ &\quad-103.955233(0.3128098)\\ &=34.730355-32.518211=2.212144,\\ P&=2.212144-99.501248+103.955233\\ &=6.666128. \end{aligned} \]

ที่ $q=2\%$ ส่วน $(r-q-\tfrac12\sigma^2)T$ เป็น $(0.04-0.02-0.02)(0.25)=0$ พอดี ตัวเศษของ $d_2$ จึงเหลือแค่ log moneyness ส่วน $e^{-qT}$ หน้าขาหุ้นมีความหมายตรง ๆ: ซื้อหุ้นวันนี้แค่ $e^{-0.005}=0.9950$ หุ้น แล้วเอาปันผลซื้อหุ้นเพิ่มไปเรื่อย ๆ จะมีครบหนึ่งหุ้นพอดีในวันหมดอายุ

บรรทัด put ใช้ parity แบบมีปันผล $C-P=S_0e^{-qT}-Ke^{-rT}$ ซึ่งได้จากขั้นที่ 6 เหมือนเดิม ปันผล 2% ทำให้ forward ลดจาก 101.005 เหลือ 100.501 call จึงถูกลง \$0.1787 และ put แพงขึ้น \$0.3200

ขั้นที่ 12 — ตัวอย่างที่สอง: call \$36 บนหุ้น \$35 ที่ 14.3 จะใช้ต่อ

โจทย์ให้อะไรมาบ้าง: หุ้น \$35, strike \$36, อายุ 3 เดือน, ดอกเบี้ย 2% ต่อปี, ความผันผวน 24% ต่อปี ไม่มีปันผล เป็นชุดตัวเลขแบบที่ตำราใช้กันมาก เดินสูตรทีละชิ้นอีกรอบ

\[ \begin{aligned} \ln(35/36)&=-0.0281709,\\ (r-\tfrac12\sigma^2)T&=(0.02-0.0288)(0.25)\\ &=-0.0022,\\ \sigma\sqrt T&=0.24(0.5)=0.12,\\ d_2&=\frac{-0.0281709-0.0022}{0.12}\\ &=-0.2530906,\\ d_1&=-0.2530906+0.12=-0.1330906,\\ \Phi(d_1)&=0.4470608,\ \ \Phi(d_2)=0.4000991,\\ Ke^{-rT}&=36e^{-0.005}=35.820449,\\ C&=35(0.4470608)\\ &\quad-35.820449(0.4000991)\\ &=15.647130-14.331729\\ &=1.315401. \end{aligned} \]

คำตอบ: call ราคา \$1.3154 ต่อหุ้น ทั้งหมดเป็นค่าเวลา เพราะวันนี้หุ้นต่ำกว่า strike \$1 แต่ SD ของ log ราคาตลอด 3 เดือนคือ 12% หรือราว \$4.20 บนหุ้น \$35 ระยะ \$1 จึงวิ่งข้ามได้ไม่ยาก ถ้าขาย 100 สัญญา (10,000 หุ้นอ้างอิง) ต้องถือหุ้นราว $10{,}000(0.4471)=4{,}471$ หุ้น ส่วนโอกาสใช้สิทธิ์ภายใต้ $\mathbb Q$ คือ 40.01%

ตรวจเองใน 10 วินาที: $\ln(35/36)\approx-1/35.5\approx-0.0282$ และราคาต้องอยู่ระหว่าง $\max(35-35.82, 0)=0$ กับ 35 ค่า 1.3154 อยู่ต้นช่วง สมกับ call ที่ยังไม่มีกำไรและอายุสั้น

คำถามที่ควรถามออกมาดัง ๆ

ไม่มีใครเชื่อว่าหุ้นโตแค่เท่าดอกเบี้ย แล้วทำไมคำนวณแบบนั้นได้? เพราะ 14.1 พิสูจน์ว่าต้นทุนของพอร์ตเลียนแบบไม่ขึ้นกับ $\mu$ เลือก $\mu$ เท่าไรก็ได้ราคาเดียวกัน เราจึงเลือกค่าที่ทำให้ราคาเขียนเป็นค่าเฉลี่ยคิดลดได้ง่ายที่สุด คือ $\mu=r$ (13.6) สิ่งที่บังคับราคาคือการ hedge ไม่ใช่ความเชื่อ ขั้นที่ 8 แสดงว่าโอกาสจริง 40.60% ไม่ได้ทำให้ราคาเปลี่ยน

ทำไม call มีค่าทั้งที่หุ้นต่ำกว่า strike? เพราะ payoff ไม่มีขาลง เส้นทางที่จบต่ำกว่า strike ให้ศูนย์ ไม่ได้ให้ติดลบ ค่าเฉลี่ยของ payoff จึงมากกว่า payoff ของค่าเฉลี่ยเสมอ ขั้นที่ 9 แสดงว่าส่วนต่างทั้งหมดหายไปเมื่อ $\sigma\to0$

$d_1$ กับ $d_2$ ต่างกันแค่ $\sigma\sqrt T$ ทำไมต้องมีสองตัว? $d_2$ นับว่าเส้นทางไหนใช้สิทธิ์ ทุกเส้นนับเท่ากัน ส่วน $d_1$ นับแต่ละเส้นหนักตามราคาหุ้นที่ได้ เส้นที่หุ้นขึ้นแรงจึงนับหนักกว่า ถ้าใช้ตัวเดียวกันทั้งสองขาจะได้ราคาติดลบ (ดูกับดักข้างล่าง)

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

ใช้ $\Phi(d_2)$ ทั้งสองขา: จะได้ $(S_0-Ke^{-rT})\Phi(d_2)=(100-103.9552)(0.3307)=-1.3081$ ราคาติดลบซึ่งเป็นไปไม่ได้ ตัวอย่างที่สองได้ $(35-35.8204)(0.4001)=-0.3283$ ขาหุ้นต้องใช้ $\Phi(d_1)$ เพราะนับเส้นทางหนักตามราคาหุ้น

ใส่หน่วยผิด: อายุ 3 เดือนต้องเป็น 0.25 ปี ถ้าใส่ 3 call \$36 บนหุ้น \$35 จะมีราคา \$6.2371 แพงเกินจริง 4.74 เท่า ถ้าใส่ความผันผวน 24 แทน 0.24 ราคาจะชนเพดานเกือบ \$35 เต็ม และถ้าใส่อายุ 90 (วัน) แทน 0.25 ปี call \$105 จะมีราคา \$97.40 สูตรไม่ร้องเตือนเอง โค้ดท้ายหน้าจึงปฏิเสธความผันผวนเกิน 5 (500%) และอายุเกิน 30 ปี

ลืมปันผล: ตั้งราคา call บนดัชนีที่จ่ายปันผล 2% โดยใส่ $q=0$ จะได้ \$2.3909 แทน \$2.2121 แพงเกินไป 8.1% และ put ถูกเกินไป \$0.32 ทั้งคู่ผ่าน bounds ได้สบาย ความผิดนี้จึงหลุดไปถึงใบเสนอราคาได้

ใช้ทำอะไรบนโต๊ะจริง

บนโต๊ะไม่มีใครใช้สูตรนี้ทำนายว่าราคา option ควรเป็นเท่าไร เพราะราคาอยู่บนจออยู่แล้ว ที่ใช้จริงคือเดินย้อน: ใส่ราคาตลาดแล้วแก้หาความผันผวนที่ทำให้สูตรตรงกับราคานั้น ได้ implied volatility ของ 14.4 ซึ่งเทียบข้าม strike ข้ามอายุ และข้ามหุ้นได้ ขณะที่ราคาดิบเทียบกันไม่ได้ เทรดเดอร์จึงเสนอราคากันเป็น “vol” ไม่ใช่เป็นดอลลาร์

สูตรยังเป็นใบสั่งงานของโต๊ะ hedge: ถือ $\Phi(d_1)$ หุ้นต่อ call และกู้ $Ke^{-rT}\Phi(d_2)$ ส่วนการคูณตัวคูณสัญญา 100 หุ้นทำตอนท้ายเสมอ ไม่ใส่ไว้กลางสูตร call \$2.3909 ต่อหุ้นจึงเป็น \$239.09 ต่อสัญญา

สามโจทย์ตรวจความเข้าใจ

1. ตั้ง strike เท่ากับ forward พอดี $K=F=101.005$ ในโจทย์เปิดเรื่อง หา $d_1$, $d_2$ และราคา call แล้วเทียบกับสูตรลัด $C\approx0.4\,S_0\sigma\sqrt T$

เฉลย

$\ln(S_0/F)=-rT$ หักกับ $rT$ ในตัวเศษ จึงเหลือ $d_1=\tfrac12\sigma\sqrt T=0.05$ และ $d_2=-0.05$ ราคา $=S_0\Phi(0.05)-Fe^{-rT}\Phi(-0.05)=100[\Phi(0.05)-\Phi(-0.05)]=100(0.039878)=\$3.9878$ สูตรลัดให้ $0.4(100)(0.10)=\$4.00$ ใกล้มาก เพราะเมื่อ $d$ เล็ก $\Phi(x)-\Phi(-x)\approx2x\phi(0)$ และ $\phi(0)=1/\sqrt{2\pi}\approx0.3989$

2. สัญญาหนึ่งจ่าย \$1 ถ้าหุ้นในโจทย์เปิดเรื่องจบเหนือ \$105 (digital call) อีกสัญญาจ่ายหุ้นหนึ่งหุ้นถ้าจบเหนือ \$105 แต่ละสัญญาราคาเท่าไร และประกอบเป็น call ได้อย่างไร?

เฉลย

digital call คือขา strike หารด้วย $K$: $e^{-rT}\Phi(d_2)=0.9900498(0.3307288)=\$0.327438$ สัญญาที่จ่ายหุ้นคือขาหุ้น $S_0\Phi(d_1)=\$36.7719$ call คือสัญญาที่จ่ายหุ้น ลบ digital 105 ใบ: $36.7719-105(0.327438)=36.7719-34.3810=\$2.3909$ ตรงกับขั้นที่ 7

3. หาราคา put strike \$36 ของตัวอย่างที่สอง ทั้งด้วยสูตรตรงและด้วย parity

เฉลย

สูตรตรง: $\Phi(-d_2)=0.5999009$ และ $\Phi(-d_1)=0.5529392$ ได้ $35.820449(0.5999009)-35(0.5529392)=21.488720-19.352871=\$2.135850$ ส่วน parity: $1.315401-35+35.820449=\$2.135850$ ตรงกัน put แพงกว่า call เพราะวันนี้หุ้นต่ำกว่า strike อยู่แล้ว

// Black-Scholes from its two legs: toy, formula, bounds, limits, simulation, dividends.
// Local names for the Math functions: shorter to read, and fast in any sandbox.
const { abs, exp, log, sqrt, max, sin, cos, imul, PI } = Math;
function checkInputs(S, K, T, r, sigma, q = 0) {
  if (![S, K, T, r, sigma, q].every(Number.isFinite)) throw new TypeError('Inputs must be finite numbers');
  if (S <= 0 || K <= 0) throw new RangeError('Spot and strike must be positive');
  if (T <= 0 || T > 30) throw new RangeError('Time to expiry must be in years, above 0 and at most 30 (0.25 = 3 months)');
  if (sigma <= 0 || sigma > 5) throw new RangeError('Volatility must be per year, above 0 and at most 5 (0.20 = 20%)');
}
const phi = x => exp(-0.5 * x * x) / sqrt(2 * PI);
// Normal CDF: Taylor series near the centre, continued fraction in the tails.
function Phi(x) {
  if (!Number.isFinite(x)) throw new TypeError('Phi needs a finite number');
  const a = abs(x);
  if (a <= 3) {
    let term = a, sum = a;
    for (let n = 1; n < 200 && term > 1e-17 * sum; n++) { term *= a * a / (2 * n + 1); sum += term; }
    return x >= 0 ? 0.5 + phi(a) * sum : 0.5 - phi(a) * sum;
  }
  let f = a;
  for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - phi(a) / f : phi(a) / f;
}
// Price per share. q is a continuous dividend yield (0 = none). d2 first: it is the exercise threshold.
function blackScholes(S, K, T, r, sigma, q = 0) {
  checkInputs(S, K, T, r, sigma, q);
  const sT = sigma * sqrt(T), D = exp(-r * T), Dq = exp(-q * T);
  const d2 = (log(S / K) + (r - q - 0.5 * sigma * sigma) * T) / sT, d1 = d2 + sT;
  const stockLeg = S * Dq * Phi(d1), strikeLeg = K * D * Phi(d2);
  return {d1, d2, Nd1: Phi(d1), Nd2: Phi(d2), stockLeg, strikeLeg, call: stockLeg - strikeLeg,
    put: K * D * Phi(-d2) - S * Dq * Phi(-d1)};
}
// Three prices at expiry with given pricing weights: split the payoff into two accounts.
function toy(prices, weights, K, growth) {
  if (prices.length !== weights.length || weights.some(w => !(w >= 0))) throw new RangeError('Need one non-negative weight per price');
  if (abs(weights.reduce((a, w) => a + w, 0) - 1) > 1e-12) throw new RangeError('Weights must sum to 1');
  const avg = f => prices.reduce((a, s, i) => a + weights[i] * f(s), 0);
  const forward = avg(s => s), stock = avg(s => (s > K ? s : 0)), exercise = avg(s => (s > K ? 1 : 0));
  return {forward, stock, strike: K * exercise, exercise, share: stock / forward, price: (stock - K * exercise) / growth};
}
// Seeded uniforms (mulberry32) and Box-Muller normals: the same generator as 8.9 and 14.1.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => { a = (a + 0x6D2B79F5) >>> 0; let t = imul(a ^ (a >>> 15), a | 1);
    t ^= t + imul(t ^ (t >>> 7), t | 61); return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296; };
  return () => { if (spare !== null) { const z = spare; spare = null; return z; }
    const rad = sqrt(-2 * log(u())), ang = 2 * PI * u(); spare = rad * sin(ang); return rad * cos(ang); };
}
function monteCarlo(S, K, T, r, sigma, n, seed) {
  checkInputs(S, K, T, r, sigma);
  if (!Number.isInteger(n) || n < 2) throw new RangeError('Need a whole number of paths, at least 2');
  const z = normals(seed), drift = (r - 0.5 * sigma * sigma) * T, sT = sigma * sqrt(T), D = exp(-r * T);
  let sum = 0, sum2 = 0, hits = 0, sumS = 0;
  for (let i = 0; i < n; i++) {
    const ST = S * exp(drift + sT * z()), pay = max(ST - K, 0);
    sum += pay; sum2 += pay * pay; sumS += ST; if (ST > K) hits++;
  }
  const mean = sum / n, sd = sqrt((sum2 - n * mean * mean) / (n - 1));
  return {n, price: D * mean, se: D * sd / sqrt(n), exercised: hits / n, meanST: sumS / n};
}
function refusal(f) { try { f(); return null; } catch (error) { return error.message; } }
const S = 100, K = 105, T = 0.25, r = 0.04, sigma = 0.2;
const main = blackScholes(S, K, T, r, sigma), F = S * exp(r * T), D = exp(-r * T);
const mc = monteCarlo(S, K, T, r, sigma, 200000, 2024);
const second = blackScholes(35, 36, 0.25, 0.02, 0.24), atmf = blackScholes(S, F, T, r, sigma);
console.log(JSON.stringify({

  realWorld: Phi((log(S / K) + (0.12 - 0.5 * sigma * sigma) * T) / (sigma * sqrt(T))),

  lowVolLimit: D * max(F - K, 0), bounds: [max(S - K * D, 0), S],

สิ่งที่ควรตอบได้หลังอ่าน

  • ราคา call คือ $e^{-rT}\mathbb E^{\mathbb Q}[(S_T-K)^+]$ แยกเป็นขาหุ้นกับขา strike ได้ $C=S_0\Phi(d_1)-Ke^{-rT}\Phi(d_2)$ และ put ได้จากพื้นที่อีกฝั่งของเกณฑ์เดียวกัน
  • $d_2$ มาจากการแปลงเงื่อนไข $S_T\gt K$ เป็น $Z\gt-d_2$ ส่วน $d_1=d_2+\sigma\sqrt T$ มาจากการจัดกำลังสองสมบูรณ์เมื่อถ่วงด้วยราคาหุ้น
  • call \$105 บนหุ้น \$100 อายุ 3 เดือน: \$2.3909 และ put \$6.3461 ตรงกับกริดของ 14.1 และการสุ่ม 200,000 เส้นทาง
  • $\Phi(d_2)=33.07\%$ คือโอกาสใช้สิทธิ์ภายใต้ $\mathbb Q$ ไม่ใช่โอกาสจริง (40.60% ถ้าหุ้นโต 12%) ส่วน $\Phi(d_1)=36.77\%$ คือจำนวนหุ้นที่ hedge
  • ตรวจทุกราคาด้วย bounds, parity และหน่วย: ปี ไม่ใช่เดือนหรือวัน และความผันผวน 0.20 ไม่ใช่ 20
