20.2 Swap Rates and the Swap Curve

swap คือสัญญาแลกดอกเบี้ยคงที่กับดอกเบี้ยลอยตัว หน้านี้แสดงว่าดอกเบี้ยลอยตัวที่ยังไม่มีใครรู้อัตรา กลับมีราคาวันนี้แน่นอน จึงหาอัตราคงที่ที่ทำให้สองฝั่งเท่ากัน (swap rate) ได้ และใช้ swap rate ที่ตลาดประกาศ แกะ discount factor กลับมาได้

interest rate swap คือสัญญาที่สองฝ่ายตกลงจ่ายดอกเบี้ยให้กันทุกงวด ฝ่ายหนึ่งจ่ายดอกเบี้ยอัตราคงที่ (fixed) ที่ตกลงกันไว้วันเซ็น อีกฝ่ายจ่ายดอกเบี้ยอัตราลอยตัว (floating) ซึ่งขึ้นลงตามอัตราตลาดของแต่ละงวด ดอกเบี้ยทั้งสองฝั่งคิดบนเงินต้นก้อนเดียวกัน เรียกว่า notional แต่ไม่มีใครจ่ายเงินต้นก้อนนี้จริง มันมีไว้คูณกับอัตราเท่านั้น

ลูกค้าของธนาคารรายหนึ่งทำ swap ไว้ตั้งแต่หลายปีก่อน ลูกค้ารับดอกเบี้ยคงที่และจ่ายดอกเบี้ยลอยตัว วันนี้อัตราในตลาดไม่เหมือนวันเซ็นแล้ว ลูกค้าจึงอยากรู้ว่าสัญญาที่ถืออยู่มีค่าเท่าไร

ของที่รู้ (ตัวเลขสมมติทั้งหมด):

  • notional $N=\$50$ ล้าน
  • อัตราคงที่ในสัญญา $K=5.25\%$ ต่อปี ลูกค้าจึงได้รับปีละ $NK=50{,}000{,}000\times0.0525=\$2{,}625{,}000$
  • สัญญาเหลืออีก 5 ปี จ่ายกันปีละครั้ง ดอกเบี้ยลอยตัวของแต่ละปีใช้อัตราตลาดที่จะประกาศตอนต้นปีนั้น อัตราของปีข้างหน้าจึงยังไม่มีใครรู้
  • discount factor ของปีที่ 1 ถึง 5 คือ $D_1,\dots,D_5=0.9512,\ 0.9048,\ 0.8600,\ 0.8170,\ 0.7760$ โดย $D_i$ คือราคาวันนี้ของเงิน \$1 ที่จะได้ตอนสิ้นปีที่ $i$ เช่น \$1 ในอีกหนึ่งปีมีค่าวันนี้ \$0.9512 ตัวเลขชุดนี้แกะได้จากราคาพันธบัตรในตลาด แบบในหน้า bootstrapping

คำถามมีสองข้อ ข้อแรก ถ้าวันนี้ทำ swap ใหม่อายุ 5 ปี อัตราคงที่ที่ยุติธรรมคือเท่าไร ข้อสอง สัญญาเก่าของลูกค้ามีค่าเท่าไร

เพื่อนร่วมโต๊ะหาอัตราของ swap ใหม่ได้ $S_5=5.198422\%$ (หน้านี้จะคำนวณตัวเลขนี้ให้ดูทีละขั้น) แล้วให้เหตุผลว่า สัญญาเก่าได้ดอกเบี้ยสูงกว่าสัญญาใหม่ปีละ $K-S_5$ จึงคิดเงินส่วนเกินต่อปีแล้วคูณ 5 ปี (bp หรือ basis point คือ 0.01%):

\[\begin{aligned}K-S_5&=0.0525-0.051984219\\&=0.000515781\\&\approx5.16\text{ bp},\\N(K-S_5)&=5\times10^7\times0.000515781\\&\approx\$25{,}789.05,\\5\times25{,}789.05&\approx\$128{,}945.23.\end{aligned}\]

คำตอบของเพื่อนถูกไหม?

ลองตอบก่อนเปิดเฉลย

ข้อแรก อัตราของ swap ใหม่ได้จากสูตรด้านล่าง ตัวส่วนคือผลบวกของ discount factor ทั้งห้าตัว $0.9512+0.9048+0.8600+0.8170+0.7760=4.3090$

\[\begin{aligned}S_5&=\frac{1-D_5}{D_1+D_2+\dots+D_5}\\&=\frac{1-0.7760}{4.3090}\\&=\frac{0.224}{4.309}=5.198422\%.\end{aligned}\]

ที่มาของสูตรนี้ ขั้นด้านล่างจะสร้างให้ดูทีละขั้น ข้อสอง เพื่อนพลาด สัญญาเก่ามีค่า \$111,125.00 ไม่ใช่ \$128,945.23 เงินส่วนเกินปีละ \$25,789.05 มาคนละปี เงินที่มาปีหลังมีค่าวันนี้น้อยกว่า จึงต้องคูณเงินแต่ละปีด้วย discount factor ของปีนั้นก่อนบวก ผลบวกของ discount factor คือ 4.309 ไม่ใช่ 5:

\[\begin{aligned}V&=25{,}789.05\times(D_1+\dots+D_5)\\&=25{,}789.05\times4.309\\&\approx\$111{,}125.\end{aligned}\]

เรื่องที่น่าสนใจกว่าคือ ดอกเบี้ยลอยตัวที่ยังไม่มีใครรู้อัตราสักปี กลับมีราคาวันนี้แน่นอน $N(1-D_5)=50{,}000{,}000\times0.224=\$11{,}200{,}000$

ภาพรวมก่อนลงสูตร

ทำไมถึงมีสัญญาแบบนี้ ลองนึกถึงบริษัทที่กู้เงินดอกเบี้ยลอยตัว ทุกครั้งที่อัตราตลาดขึ้น บริษัทต้องจ่ายดอกเบี้ยมากขึ้น ถ้าบริษัททำ swap ที่รับลอยตัวและจ่ายคงที่ ดอกเบี้ยลอยตัวที่ได้จาก swap จะนำไปจ่ายหนี้ได้พอดี เหลือแค่ดอกเบี้ยคงที่ที่จ่ายออก ต้นทุนของบริษัทจึงคงที่ ทั้งที่หนี้เดิมยังเป็นลอยตัว swap แบบนี้เป็นสัญญาที่ใหญ่ที่สุดในตลาดดอกเบี้ย

เงินต้นไม่ต้องแลกกัน เพราะสองฝั่งเท่ากันและเป็นเงินสกุลเดียวกัน แลกไปก็ได้คืนเท่าเดิม แต่ละงวดจึงจ่ายกันแค่ส่วนต่างของดอกเบี้ยสองฝั่ง เราเรียกเงินของแต่ละฝั่งว่า “ขา” (leg) คือขาคงที่ (fixed leg) และขาลอยตัว (floating leg)

มูลค่าของ swap คือราคาวันนี้ของขาที่รับ ลบราคาวันนี้ของขาที่จ่าย ขาคงที่คิดง่าย เพราะรู้เงินทุกงวดแล้ว จึงคูณด้วย discount factor แล้วบวกได้ทันที ขาลอยตัวดูเหมือนคิดไม่ได้ เพราะยังไม่รู้อัตรา แต่อัตราของทุกงวดล็อกได้ตั้งแต่วันนี้ด้วย FRA (forward rate agreement คือสัญญาที่ตกลงวันนี้ว่าดอกเบี้ยของช่วงเวลาหนึ่งในอนาคตจะเป็นอัตราเท่าไร) อัตราที่ล็อกได้นี้เรียกว่า forward rate ขาลอยตัวทั้งขาจึงมีราคาแน่นอนวันนี้

รูปด้านล่างวาดเงินของสองขาจากมุมของลูกค้าที่รับคงที่ ดอกเบี้ยลอยตัววาดที่ระดับ forward rate ของวันนี้ หลังจากนั้นหน้านี้จะทำทีละเรื่อง:

  • ตีราคาขาคงที่ แล้วตีราคาขาลอยตัว
  • หา par swap rate คืออัตราคงที่ที่ทำให้สองขาราคาเท่ากัน
  • ตีราคาสัญญาเก่าของลูกค้า และวัดว่ามูลค่าไวต่ออัตราแค่ไหน (DV01)
  • เดินกลับทาง แกะ discount factor ออกจาก swap rate ที่ตลาดประกาศ
  • ดูกติกาจริงของตลาด และเหตุผลที่บริษัทอยากทำ swap
  • ดูข้อมูลจริงว่า swap แต่ละอายุขยับไปด้วยกันแค่ไหน แล้ว fit เส้นตรงด้วย gradient descent
ศัพท์ที่ใช้ในหัวข้อนี้
Interest rate swap และ notional
สัญญาที่สองฝ่ายจ่ายดอกเบี้ยให้กัน ฝ่ายหนึ่งจ่ายอัตราคงที่ อีกฝ่ายจ่ายอัตราลอยตัว ทั้งสองฝั่งคิดบนเงินต้นก้อนเดียวกันที่เรียกว่า notional เงินต้นก้อนนี้ไม่ถูกแลกจริง เพราะเท่ากันสองฝั่ง บริษัทใช้ swap เปลี่ยนหนี้ดอกเบี้ยลอยตัวให้กลายเป็นดอกเบี้ยคงที่ หรือกลับกัน
Fixed leg และ floating leg
เงินของแต่ละฝั่งเรียกว่าขา (leg) ขาคงที่ (fixed leg) จ่ายอัตราที่ตกลงไว้วันเซ็นทุกงวด ขาลอยตัว (floating leg) จ่ายอัตราอ้างอิงของตลาด อัตรานี้ประกาศตอนต้นงวด (เรียกว่าวัน reset) แล้วจ่ายเงินตอนปลายงวด
Discount factor และ bp
discount factor $D_i$ คือราคาวันนี้ของเงิน \$1 ที่จะได้ในวันที่ $T_i$ เงินที่มาช้ามีค่าวันนี้น้อยกว่า $D_i$ จึงต่ำกว่า 1 และลดลงเมื่อ $T_i$ ไกลขึ้น bp (basis point) คือ 0.01% หรือ 0.0001
Forward rate และ FRA
FRA (forward rate agreement) คือสัญญาที่ตกลงวันนี้ว่าดอกเบี้ยของช่วงเวลาหนึ่งในอนาคตจะเป็นอัตราเท่าไร ทำได้โดยไม่ต้องจ่ายเงินวันนี้ อัตราที่ล็อกได้นี้คือ forward rate ซึ่งอ่านได้จาก discount factor สองตัว
SOFR และ LIBOR
อัตราอ้างอิงของขาลอยตัว LIBOR คืออัตราเฉลี่ยที่ธนาคารใหญ่แจ้งว่าพร้อมให้กันกู้ มีหลายอายุตั้งแต่ข้ามคืนถึง 12 เดือน ตลาดดอลลาร์ใช้จนถึงปี 2023 SOFR คืออัตราดอกเบี้ยข้ามคืนของการกู้ที่มีพันธบัตรรัฐบาลสหรัฐฯ เป็นหลักประกัน (repo) นำอัตรารายวันมาทบกันทั้งงวด แล้วใช้แทน LIBOR ในตลาดดอลลาร์
Par swap rate และ swap curve
par swap rate คืออัตราคงที่ที่ทำให้ swap ใหม่มีค่าศูนย์วันเซ็น จึงไม่มีใครต้องจ่ายใครล่วงหน้า ตลาดประกาศ (quote) ตัวเลขนี้สำหรับแต่ละอายุ เส้นที่ลากผ่าน swap rate ของทุกอายุเรียกว่า swap curve
Annuity
ผลบวกของ discount factor คูณความยาวงวดของขาคงที่ คือราคาวันนี้ของการได้ \$1 ต่อปีไปทุกงวด ใช้แปลงส่วนต่างของอัตราต่อปีให้เป็นเงินวันนี้
Receive-fixed, pay-fixed, DV01 และ hedge
ฝั่งรับคงที่ (receive-fixed) ได้ประโยชน์เมื่อ swap rate ของตลาดลง ฝั่งจ่ายคงที่ (pay-fixed) ได้ประโยชน์เมื่อ swap rate ขึ้น DV01 คือจำนวนเงินที่มูลค่าเปลี่ยนเมื่ออัตราขยับ 1 bp hedge คือการทำสัญญาอีกตัวมาหักล้างความเสี่ยง โต๊ะใช้ DV01 กำหนดขนาด hedge และเพดานความเสี่ยง

ขั้นที่ 1 — ขาคงที่: เงินเท่ากันทุกงวด และ annuity

จะรู้มูลค่าของ swap ต้องรู้ราคาของสองขาก่อน เริ่มจากขาที่ง่ายกว่า ขาคงที่จ่ายดอกเบี้ยงวดละ $NK\delta_i$ คือ notional $N$ คูณอัตราคงที่ $K$ คูณความยาวงวด $\delta_i$ (เป็นปี) swap ในโจทย์จ่ายปีละครั้ง จึงมี $\delta_i=1$ เงินทุกงวดรู้ล่วงหน้าหมด ราคาวันนี้จึงคิดเหมือน ราคาพันธบัตร: คูณเงินงวดที่ $i$ ด้วย discount factor $D_i$ ของวันจ่าย แล้วบวกทุกงวด $NK$ เท่ากันทุกงวด จึงดึงออกมาไว้หน้าผลบวกได้ ก้อนที่เหลือเราตั้งชื่อว่า annuity $A_n$

\[ \begin{aligned} PV_{\rm fix}&=\sum_{i=1}^{n}NK\delta_iD_i\\ &=NK\,A_n,\\ A_5&=0.9512+0.9048\\ &\quad+0.8600+0.8170\\ &\quad+0.7760=4.3090,\\ NK&=5\times10^7\times0.0525\\ &=2{,}625{,}000,\\ PV_{\rm fix}&=2{,}625{,}000\times4.309\\ &=11{,}311{,}125. \end{aligned} \]

$A_n$ คือราคาวันนี้ของการได้ \$1 ทุกปีไป $n$ ปี เพราะถ้าเงินทุกงวดเป็น \$1 ผลบวกก็เหลือ $A_n$ พอดี หน่วยของมันจึงเป็นปี (ดอลลาร์วันนี้ต่อ \$1 ต่อปี) และมันไม่ขึ้นกับ $K$ คิดครั้งเดียวจึงใช้ได้กับทุกอัตรา ถ้าอยากรู้ว่าอัตราที่ต่างกันปีละ 1% มีค่าวันนี้เท่าไร ก็คูณด้วย $A_n$ ได้เลย

ลูกค้าได้ \$2,625,000 ทุกปี ห้าปี ถ้าบวกตรง ๆ จะได้ $5\times2{,}625{,}000=\$13{,}125{,}000$ แต่ราคาวันนี้คือ \$11,311,125 เพราะเงินที่มาช้ากว่ามีค่าวันนี้น้อยกว่า discount factor ที่ต่ำกว่า 1 คือตัวหักส่วนนี้ออก

ขั้นที่ 2 — ขาลอยตัว: ล็อกทุกงวดด้วย FRA แล้วพจน์กลางหักกันหมด

ขาลอยตัวจ่ายงวดละ $N\delta_iL_i$ โดย $L_i$ คืออัตราที่ตลาดจะประกาศตอนต้นงวด $i$ วันนี้ยังไม่มีใครรู้ $L_i$ แล้วจะตีราคาเงินที่ยังไม่รู้จำนวนได้อย่างไร

ทางออกคือ FRA สมมติว่าเราถือเงินลอยตัวงวดนี้ไว้ แล้วทำ FRA ที่จ่าย $L_i$ และรับ $F_i$ ในงวดเดียวกัน ส่วนที่เป็น $L_i$ จะหักกันหมด เหลือเงินแน่นอน $N\delta_iF_i$ ที่ $T_i$ FRA ทำได้โดยไม่ต้องจ่ายเงินวันนี้ ดังนั้นเงินลอยตัวงวดนี้มีราคาวันนี้เท่ากับเงินแน่นอน $N\delta_iF_i$ ที่วันเดียวกัน

แล้ว $F_i$ เท่าไร? อ่านได้จาก discount factor สองตัว เงิน \$1 ที่ $T_{i-1}$ มีราคาวันนี้ $D_{i-1}$ ถ้าล็อกให้มันโตต่ออีกหนึ่งงวดที่อัตรา $F_i$ จะได้ $1+\delta_iF_i$ ดอลลาร์ที่ $T_i$ ซึ่งมีราคาวันนี้ $(1+\delta_iF_i)D_i$ ทั้งสองแบบคือเงินก้อนเดียวกัน ราคาวันนี้จึงต้องเท่ากัน: $D_{i-1}=(1+\delta_iF_i)D_i$ หรือ $1+\delta_iF_i=D_{i-1}/D_i$ (หน้า forward rate และ FRA อธิบายเรื่องนี้ละเอียด) ให้ $V_i=N\delta_iF_iD_i$ คือราคาวันนี้ของดอกเบี้ยลอยตัวงวด $i$ แทน $\delta_iF_i$ ลงไป แล้วลองสองงวดแรกด้วยมือ

\[ \begin{aligned} V_i&=N\Big(\frac{D_{i-1}}{D_i}-1\Big)D_i\\ &=N(D_{i-1}-D_i),\\ \frac{V_1}{N}&=1-0.9512=0.0488,\\ \frac{V_2}{N}&=0.9512-0.9048\\ &=0.0464,\\ PV_{\rm flt}&=N\sum_{i=1}^{n}(D_{i-1}-D_i)\\ &=N(1-D_n)\\ &=5\times10^7\times0.224\\ &=11{,}200{,}000. \end{aligned} \]

จังหวะสำคัญอยู่ที่แถวแรก เมื่อคูณ $\delta_iF_i=D_{i-1}/D_i-1$ ด้วย $D_i$ ตัวส่วน $D_i$ ตัดกันพอดี เหลือแค่ $D_{i-1}-D_i$ คือผลต่างของ discount factor สองตัวที่ติดกัน พอบวกทุกงวด $D_1$ ที่ถูกลบในงวดแรกจะถูกบวกคืนในงวดที่สอง $D_2$ ก็เป็นแบบเดียวกัน พจน์กลางจึงหักกันหมด (เรียกว่า telescoping) เหลือ $D_0=1$ ลบตัวสุดท้าย $D_n$ รูปขั้นบันไดด้านล่างแสดงเรื่องนี้ให้เห็นด้วยตา

งวดที่ 3 ถึง 5 คิดแบบเดียวกัน: $0.9048-0.8600=0.0448$, $0.8600-0.8170=0.0430$ และ $0.8170-0.7760=0.0410$ คูณ $N=\$50$ ล้าน ห้างวดมีราคาวันนี้ (ล้านดอลลาร์)

\[\begin{aligned}&50\times(0.0488,\ 0.0464,\ 0.0448,\ 0.0430,\ 0.0410)\\&=(2.44,\ 2.32,\ 2.24,\ 2.15,\ 2.05),\\&2.44+2.32+2.24+2.15+2.05=11.20.\end{aligned}\]

ตรงกับสูตรสั้น $N(1-D_5)$ สูตรสั้นนี้ใช้ได้เมื่อ forward กับการคิดลดมาจาก curve เดียวกัน ตลาดปัจจุบันใช้สองเส้น คือคิดลดด้วยเส้น OIS (curve ที่สร้างจากอัตราดอกเบี้ยข้ามคืน ใช้กับสัญญาที่วางหลักประกัน) แต่หา forward จากเส้นของอัตราอ้างอิงที่ swap ใช้ ถ้าสองเส้นต่างกัน ตัวส่วนในแถวแรกไม่ตัดกันพอดี ต้องบวกทีละงวดแทน

ขั้นที่ 3 — อีกมุม: floating rate note ราคาเท่าหน้าตั๋วทุกวัน reset

ผลของขั้นก่อนฟังดูแปลก ขาลอยตัวมีราคา $N(1-D_n)$ ไม่ว่าอัตราในอนาคตจะออกมาเท่าไร ขั้นนี้ดูเรื่องเดียวกันจากอีกมุม เพื่อให้เห็นว่าทำไมมันจริง

คิดถึง floating rate note คือพันธบัตรที่จ่ายคูปองตามอัตราตลาดของแต่ละงวด แล้วคืนเงินต้น $N$ ตอนครบอายุ ให้ $r_k$ คืออัตราต่องวดที่ประกาศตอนต้นงวด $k$ อัตรานี้ใช้ทั้งคิดคูปองของงวดนั้น และคิดลดเงินของงวดนั้นกลับมา เพราะเป็นอัตราตลาดของช่วงเวลาเดียวกัน ให้ $V_k$ คือราคาของ note ที่วัน $T_k$ หลังจ่ายคูปองของวันนั้นแล้ว เราคิดย้อนจากวัน reset สุดท้ายทีละงวด เหมือนการคิดย้อนบน ต้นไม้ binomial

\[ \begin{aligned} V_{n-1}&=\frac{Nr_n+N}{1+r_n}=N,\\ V_{k-1}&=\frac{Nr_k+V_k}{1+r_k}\\ &=\frac{Nr_k+N}{1+r_k}=N,\\ V_0&=PV_{\rm flt}+N\,D_n=N,\\ PV_{\rm flt}&=N(1-D_n). \end{aligned} \]

ที่วัน reset สุดท้าย $T_{n-1}$ note เหลือเงินก้อนเดียว คือคูปองบวกเงินต้น $N(1+r_n)$ ที่ $T_n$ คิดลดด้วย $r_n$ ตัวเดียวกันจึงได้ $N$ พอดี ถอยไปอีกงวด เงินที่รออยู่คือคูปอง $Nr_k$ บวกราคา note ซึ่งเพิ่งได้ว่าเท่ากับ $N$ จึงได้ $N$ อีก ทุกวัน reset จึงมีราคา $N$ ไม่ว่าอัตราในอนาคตจะเป็นเท่าไร เหตุผลคือคูปองโตด้วยอัตราเดียวกับที่ใช้คิดลดพอดี สองอย่างจึงหักกันเอง

แถวที่สามแยกราคาวันนี้ของ note ออกเป็นสองก้อน คือคูปองทั้งหมด (ซึ่งก็คือขาลอยตัวของ swap) กับเงินต้นที่ $T_n$ ซึ่งมีราคาวันนี้ $ND_n$ ขาลอยตัวคือ note ที่ไม่มีเงินต้นคืน ราคาของมันจึงเป็น $N-ND_n=N(1-D_n)$ ตรงกับขั้นก่อน

ลองด้วยตัวเลข note \$1,000,000 อายุสี่งวด ถ้าทุกงวดอัตราเป็น 3% คูปองงวดละ $1{,}000{,}000\times0.03=\$30{,}000$ คิดลดคูปองทีละงวด แล้วคิดลดเงินต้น:

\[\begin{aligned}\sum_{k=1}^{4}\frac{30{,}000}{1.03^k}&=29{,}126.21+28{,}277.88\\&\quad+27{,}454.25+26{,}654.61\\&=111{,}512.95,\\\frac{1{,}000{,}000}{1.03^4}&=888{,}487.05,\\111{,}512.95+888{,}487.05&=1{,}000{,}000.\end{aligned}\]

ถ้าอัตราสี่งวดเป็น 2%, 5%, 3.5% และ 4% คิดย้อนด้วยสูตรด้านบนก็ยังได้ \$1,000,000 ทุกวัน reset เช่นงวดสุดท้าย $V_3=\dfrac{40{,}000+1{,}000{,}000}{1.04}=1{,}000{,}000$ ข้อแม้คือผู้ออก note ต้องไม่มีโอกาสผิดนัด ถ้ามี ตลาดจะคิดลดด้วยอัตราที่สูงกว่าคูปอง แล้วราคาจะต่ำกว่า $N$

มุมนี้ให้อีกข้อสรุปหนึ่ง ถ้าเติมเงินต้น $N$ ที่ปลายทั้งสองขาของ swap มูลค่าสุทธิไม่เปลี่ยน เพราะรับ $N$ และจ่าย $N$ ในวันเดียวกันหักกันหมด หลังเติมแล้ว ขาคงที่กลายเป็นพันธบัตรคูปอง $K$ และขาลอยตัวกลายเป็น floating rate note ฝั่งรับคงที่จึงเหมือนถือพันธบัตรคูปอง $K$ และติดค้าง floating rate note หนึ่งฉบับ (เรียกว่าชอร์ต คือถือแบบติดลบ) note นี้มีราคา $N$ ทุกวัน reset จึงแทบไม่ขยับตามอัตรา ความเสี่ยงด้านอัตราของ swap จึงเท่ากับของพันธบัตรคูปองทั้งก้อน

ขั้นที่ 4 — par swap rate: อัตราคงที่ที่ทำให้สองขาเท่ากัน

ตอนนี้รู้ราคาของสองขาแล้ว คำถามถัดไปคือ swap ใหม่ควรใช้อัตราคงที่เท่าไร วันเซ็นไม่มีใครจ่ายเงินให้ใคร swap ใหม่จึงต้องมีค่าศูนย์ คือสองขาราคาเท่ากัน อัตราคงที่ที่ทำแบบนั้นได้เรียกว่า par swap rate $S_n$ เราจึงตั้งขาคงที่ $NS_nA_n$ ให้เท่ากับขาลอยตัว $N(1-D_n)$ แล้วหารด้วย $N$ ทั้งสองข้าง $N$ หายไป อัตรา swap จึงไม่ขึ้นกับขนาดสัญญา

แถวสุดท้ายเป็นอีกหน้าตาหนึ่งของสูตรเดียวกัน ได้จากการใช้ขาลอยตัวแบบบวกทีละงวด $N\sum_i\delta_iF_iD_i$ แทนแบบสั้น (ในที่นี้ $\delta_i=1$) แล้วหารด้วย $NA_n$

\[ \begin{aligned} NS_nA_n&=N(1-D_n),\\ S_n&=\frac{1-D_n}{A_n},\\ S_5&=\frac{1-0.7760}{4.309}=\frac{0.224}{4.309}\\ &=5.198422\%,\\ S_n&=\sum_{i=1}^{n}\frac{D_i}{A_n}\,F_i. \end{aligned} \]

แถวสุดท้ายบอกความหมายของ swap rate: มันคือค่าเฉลี่ยถ่วงน้ำหนักของ forward ทุกปี โดยปีที่ $i$ ได้น้ำหนัก $D_i/A_n$ ลองคิดด้วยตัวเลข forward ของแต่ละปีได้จาก $F_i=D_{i-1}/D_i-1$:

\[\begin{aligned}F_1&=\tfrac{1}{0.9512}-1=5.1304\%,\\F_2&=\tfrac{0.9512}{0.9048}-1=5.1282\%,\\F_3&=\tfrac{0.9048}{0.8600}-1=5.2093\%,\\F_4&=\tfrac{0.8600}{0.8170}-1=5.2632\%,\\F_5&=\tfrac{0.8170}{0.7760}-1=5.2835\%.\end{aligned}\]

น้ำหนักของแต่ละปีคือ $D_i/A_5$ เช่นปีแรก $0.9512/4.309=0.2207$ ห้าปีได้ 0.2207, 0.2100, 0.1996, 0.1896 และ 0.1801 รวมกันได้ 1 เพราะ $A_5$ คือผลบวกของ $D_i$ ทั้งห้าตัวเอง ปีใกล้ได้น้ำหนักมากกว่า เพราะ discount factor ของปีใกล้สูงกว่า

ค่าเฉลี่ยธรรมดาให้ทุกปีหนักเท่ากัน ได้ $(5.1304+5.1282+5.2093+5.2632+5.2835)/5=5.2029\%$ ซึ่งสูงกว่า swap rate 5.1984% เพราะปีไกลซึ่ง forward สูง ได้น้ำหนักมากเกินจริง

สูตร $S_n=(1-D_n)/A_n$ หน้าตาเดียวกับ par yield ของพันธบัตร (อัตราคูปองที่ทำให้พันธบัตรขายได้ที่ราคาหน้าตั๋วพอดี) เพราะตามมุมของขั้นก่อน swap คือพันธบัตรคูปอง $S_n$ ลบ floating rate note ที่ราคาหน้าตั๋ว ตำราและตลาดมักเขียนเป็นเปอร์เซ็นต์ และให้ทุกงวดยาว $\Delta$ ปีเท่ากัน: $s(t,T)=100\,[1-P(t,T)]/[\Delta\sum_{j}P(t,T_j)]$ โดย $P(t,T)$ คือราคาที่เวลา $t$ ของ \$1 ที่ $T$ ซึ่งก็คือ discount factor

swap rate จึงไม่ใช่คำทำนายว่าอัตราจะเป็นเท่าไร มันคืออัตราที่ไม่เปิดช่องให้ใครได้กำไรฟรี ถ้าตลาด quote อัตราอื่น คนจะทำ swap คู่กับ FRA ทีละงวด แล้วเก็บส่วนต่างไปโดยไม่เสี่ยง

ขั้นที่ 5 — สัญญาเก่าที่ 5.25% มีค่าเท่าไร และ DV01

โจทย์ให้อะไรมาบ้าง: กลับมาที่สัญญาเก่าในโจทย์เปิดหน้า ลูกค้ารับคงที่ $K=5.25\%$ และจ่ายลอยตัว บน $N=\$50$ ล้าน เหลืออายุห้าปี ขั้นก่อน ๆ คำนวณไว้แล้วว่า

  • ขาคงที่ที่ลูกค้ารับ มีราคา $PV_{\rm fix}=\$11{,}311{,}125$
  • ขาลอยตัวที่ลูกค้าจ่าย มีราคา $PV_{\rm flt}=\$11{,}200{,}000$
  • annuity $A_5=4.309$ และ swap rate ของตลาดวันนี้ $S_5=5.198422\%$

มูลค่าของลูกค้าคือขาที่รับ ลบขาที่จ่าย อีกวิธีหนึ่งคือเขียนขาลอยตัวเป็น $NS_5A_5$ ซึ่งเท่ากันตามนิยามของ $S_5$ วิธีนี้บอกเหตุผลด้วย ส่วน DV01 คือมูลค่าเปลี่ยนไปเท่าไรเมื่อ swap rate ของตลาดขยับ 1 bp (0.0001)

\[ \begin{aligned} V_{\rm rec}&=PV_{\rm fix}-PV_{\rm flt}\\ &=11{,}311{,}125-11{,}200{,}000\\ &=111{,}125,\\ V_{\rm rec}&=NKA_5-NS_5A_5\\ &=N(K-S_5)A_5\\ &\approx25{,}789.05\times4.309\\ &\approx111{,}125,\\ \mathrm{DV01}&=NA_5\times0.0001\\ &=5\times10^7\times4.309\times0.0001\\ &=21{,}545. \end{aligned} \]

คำตอบ: สัญญาเก่ามีค่า +\$111,125.00 สำหรับลูกค้าที่รับคงที่ และ −\$111,125.00 สำหรับธนาคารที่เป็นคู่สัญญาฝั่งจ่ายคงที่ วิธีที่สองบอกว่าเงินนี้มาจากไหน ลูกค้าได้อัตราสูงกว่าตลาดปีละ $K-S_5=0.051578\%$ หรือ 5.1578 bp คิดเป็นเงินปีละ $N(K-S_5)\approx\$25{,}789.05$ แต่เงินแต่ละปีต้องคิดลดก่อนบวก จึงคูณด้วย $A_5=4.309$ ไม่ใช่ 5 คำตอบ \$128,945.23 ของเพื่อนลืมขั้นนี้

DV01 มาจากสูตร $V_{\rm rec}=N(K-S_5)A_5$ เอง ถ้า $S_5$ ขึ้น 1 bp และ $A_5$ ไม่เปลี่ยน มูลค่าจะลดลง $NA_5\times0.0001=\$21{,}545$ ตัวเลขนี้ใช้ตรวจคำตอบได้ด้วย สัญญาเก่าห่างจากตลาด 5.1578 bp จึงมีค่า $5.1578\times21{,}545\approx\$111{,}125$

ตรวจเองใน 10 วินาที: ต่อ notional \$1 ขาคงที่มีราคา $KA_5$ และขาลอยตัวมีราคา $1-D_5$ ดังนั้น $0.0525\times4.309-0.224=0.2262225-0.224=0.0022225$ คูณ \$50 ล้านได้ $0.0022225\times50{,}000{,}000=\$111{,}125$ พอดี

ขั้นที่ 6 — เดินกลับทาง: แกะ discount factor จาก swap rate

ทุกขั้นที่ผ่านมาเริ่มจาก discount factor แต่ในตลาดจริงไม่มีใครประกาศ discount factor ให้ สิ่งที่ตลาด quote คือ swap rate ของแต่ละอายุ เพราะในหลายช่วงอายุ swap ซื้อขายคล่องกว่าพันธบัตร ถ้าจะตีราคาสัญญาอื่น จึงต้องแกะ discount factor ออกจาก swap rate ก่อน

วิธีคือเดินกลับทาง สมมติว่ารู้ $S_n$ และรู้ discount factor ของทุกอายุที่สั้นกว่าแล้ว ให้ $B_{n-1}=D_1+\dots+D_{n-1}$ คือผลบวกของตัวที่รู้แล้ว ดังนั้น $A_n=B_{n-1}+D_n$ และเหลือ $D_n$ ตัวเดียวที่ยังไม่รู้ แทนลงในสูตร par swap rate $S_nA_n=1-D_n$ แล้วแก้หา $D_n$ ตัวอย่างใช้อายุ 3 ปี ซึ่งมี $S_3=5.15464\%$ และ $B_2=0.9512+0.9048=1.856$

\[ \begin{aligned} S_n(B_{n-1}+D_n)&=1-D_n,\\ D_n(1+S_n)&=1-S_nB_{n-1},\\ D_n&=\frac{1-S_nB_{n-1}}{1+S_n},\\ D_3&=\frac{1-0.0515464\times1.856}{1.0515464}\\ &=\frac{0.9043299}{1.0515464}=0.8600. \end{aligned} \]

แถวที่สองย้ายทุกพจน์ที่มี $D_n$ ไปไว้ข้างซ้าย แล้วหาร วิธีนี้เหมือนการแกะ note ตอน bootstrapping จากพันธบัตร ทุกประการ เพราะ swap คือพันธบัตรคูปอง $S_n$ ที่ขายได้ที่ราคาหน้าตั๋วพอดี (ขาลอยตัวบวกเงินต้นมีค่า $N$) ต้องไล่จากอายุสั้นไปยาวด้วยเหตุผลเดียวกัน คือแต่ละ quote เพิ่ม discount factor ที่ไม่รู้เข้ามาแค่ตัวเดียว

quote ทั้งห้าอายุของเส้นในหน้านี้ได้จากสูตร $S_n=(1-D_n)/A_n$ เช่น $S_2=\dfrac{1-0.9048}{0.9512+0.9048}=\dfrac{0.0952}{1.856}=5.1293\%$ ห้าอายุคือ 5.1304, 5.1293, 5.1546, 5.1797 และ 5.1984% เกือบแบน ทั้งที่ forward ไต่จาก 5.13% ไป 5.28% เพราะ swap rate เป็นค่าเฉลี่ยของ forward ตั้งแต่ปีแรก แกะกลับด้วยสูตรนี้ได้ discount factor ทั้งห้าตัวเดิม

ต้องใช้ quote เต็มความละเอียด ตัวอย่างข้างบนจึงใช้ $S_3=5.15464\%$ ถ้าใช้ quote ที่ปัดแล้ว discount factor จะเพี้ยน โจทย์ตรวจความเข้าใจข้อ 2 ท้ายหน้าให้ลองดูว่าเพี้ยนแค่ไหน

ขั้นที่ 7 — กติกาจริง: swap 2 ปี notional \$1,000,000

ตัวอย่างข้างบนจ่ายปีละครั้งเพื่อให้เลขง่าย swap จริงมีกติกาละเอียดกว่านั้น ดูกติกาของ swap ดอลลาร์มาตรฐานในช่วงที่ยังใช้ LIBOR เป็นอัตราลอยตัว:

  • อายุที่ซื้อขายกันมากคือ 2, 5, 10 และ 30 ปี
  • ขาคงที่จ่ายทุกครึ่งปี งวดหนึ่งจึงยาว $\delta=\tfrac12$ ปี
  • ขาลอยตัวจ่ายทุกไตรมาส ($\delta=\tfrac14$ ปี) ตาม 3M LIBOR คือ LIBOR อายุ 3 เดือน อัตรากำหนดตอนต้นงวด แล้วจ่ายเงินตอนปลายงวด

ตัวอย่างจากสไลด์ของคอร์ส: swap 2 ปี notional \$1,000,000 อัตราคงที่ 2.9894% ต่อปี LIBOR ที่ประกาศสำหรับสองงวดแรกคือ 2.4012% และ 2.7293% ต่อปี เงินแต่ละงวดคือ notional คูณความยาวงวด คูณอัตรา

\[ \begin{aligned} p_{\rm fix}&=10^6\times\tfrac12\times0.029894\\ &=14{,}947,\\ p_{\rm flt,1}&=10^6\times\tfrac14\times0.024012\\ &=6{,}003,\\ p_{\rm flt,2}&=10^6\times\tfrac14\times0.027293\\ &=6{,}823.25. \end{aligned} \]

ขาคงที่รู้เงินทุกงวดตั้งแต่วันแรก คือสี่งวด งวดละ \$14,947 ขาลอยตัวมีแปดงวด วันนี้รู้แค่งวดแรก \$6,003 เพราะอัตรางวดแรกประกาศวันนี้ งวดที่สอง \$6,823.25 จะรู้เมื่อถึงเดือนที่ 3 ซึ่งเป็นวัน reset ของงวดนั้น (ตัวอย่างใส่อัตราให้ดูล่วงหน้า) สองขาจ่ายคนละความถี่ จึงหักกลบกันได้เฉพาะวันที่จ่ายตรงกัน คือทุกครึ่งปี

LIBOR เป็นอัตราแบบ simple (ไม่ทบ) ผูกกับราคาของ zero-coupon bond (พันธบัตรที่จ่ายเงินก้อนเดียวตอนครบอายุ) ด้วย $L(t,T)=100\,[1/P(t,T)-1]/(T-t)$ โดย $P(t,T)$ คือราคาที่เวลา $t$ ของ \$1 ที่ $T$ เหตุผลคือ เงิน $P$ ที่ฝากวันนี้โตเป็น \$1 ที่ $T$ จึงโตขึ้น $1/P-1$ เท่าตลอดช่วง หารด้วยความยาวช่วงให้เป็นอัตราต่อปี แล้วคูณ 100 ให้เป็นเปอร์เซ็นต์

ของจริงยังต้องนับวันด้วย LIBOR นับความยาวงวดเป็นจำนวนวันจริงหารด้วย 360 (กติกา actual/360) และเริ่มนับสองวันทำการหลังวันตกลง ตัวอย่างนี้ใช้ครึ่งปีกับไตรมาสเท่ากันทุกงวดเพื่อให้เลขง่าย ถ้าขาคงที่นับแบบ actual/360 และครึ่งปีนั้นมี 182 วันจริง เงินงวดนั้นจะเป็น $10^6\times0.029894\times\tfrac{182}{360}=\$15{,}113.08$ ไม่ใช่ \$14,947

ขั้นที่ 8 — ทำไมบริษัททำ swap: comparative advantage

ทำไมบริษัทถึงอยากทำ swap แทนที่จะกู้แบบที่ต้องการตรง ๆ ดูตัวอย่างสมมติ บริษัท A กับบริษัท B อยากกู้คนละ \$1 ล้าน A อยากจ่ายดอกเบี้ยลอยตัว B อยากจ่ายดอกเบี้ยคงที่ ผู้ให้กู้เสนออัตราต่อปีดังนี้ ($L$ คืออัตราลอยตัวอ้างอิง เช่น LIBOR และ $L+0.3\%$ คือ $L$ บวกเพิ่มอีก 0.3%):

  • A กู้คงที่ได้ 4.0% หรือกู้ลอยตัวได้ $L+0.3\%$
  • B กู้คงที่ได้ 5.2% หรือกู้ลอยตัวได้ $L+1.0\%$

B ต้องจ่ายแพงกว่า A ทั้งสองแบบ เพราะผู้ให้กู้มองว่า B มีโอกาสผิดนัดมากกว่า แล้ว A จะได้อะไรจากการร่วมมือกับ B? ให้ดูว่า B แพงกว่า A มากน้อยต่างกันในสองตลาด ผลต่างของสองส่วนต่างนี้เรียกว่า $G$ คือเงินที่สองบริษัทแบ่งกันได้ ถ้า A กู้ในตลาดที่ A ถูกกว่า B มากที่สุด และ B กู้ในตลาดที่ B แพงกว่า A น้อยที่สุด แล้วแลกดอกเบี้ยกันด้วย swap สมมติว่าตกลงกันว่า B จ่ายคงที่ 3.95% ให้ A และ A จ่าย $L$ ให้ B

\[ \begin{aligned} \Delta_{\rm fix}&=5.2\%-4.0\%=1.2\%,\\ \Delta_{\rm flt}&=1.0\%-0.3\%=0.7\%,\\ G&=1.2\%-0.7\%=0.5\%,\\ A&:\ 4.0\%-3.95\%+L\\ &\quad=L+0.05\%,\\ B&:\ L+1.0\%-L+3.95\%\\ &\quad=4.95\%. \end{aligned} \]

สองแถวแรกบอกว่า B แพงกว่า A 1.2% ในตลาดคงที่ แต่แพงกว่าแค่ 0.7% ในตลาดลอยตัว B จึงเสียเปรียบน้อยกว่าในตลาดลอยตัว เรียกว่า B ได้เปรียบเชิงเปรียบเทียบ (comparative advantage) ฝั่งลอยตัว ส่วน A ได้เปรียบเชิงเปรียบเทียบฝั่งคงที่ ดังนั้นให้ A กู้คงที่ 4.0% และให้ B กู้ลอยตัว $L+1.0\%$ ทั้งที่แต่ละคนอยากได้อีกแบบ แล้วใช้ swap แลกดอกเบี้ยกัน เงินต้น \$1 ล้านของสองฝั่งเท่ากัน จึงไม่ต้องแลก

สองแถวล่างคือดอกเบี้ยสุทธิของแต่ละบริษัท A จ่าย 4.0% ให้ผู้ให้กู้ ได้ 3.95% จาก B แล้วจ่าย $L$ ให้ B ส่วน B จ่าย $L+1.0\%$ ให้ผู้ให้กู้ ได้ $L$ จาก A แล้วจ่าย 3.95% ให้ A ตัว $L$ ที่รับและจ่ายของ B หักกันเอง ผลคือ

\[\begin{aligned}(L+0.3\%)-(L+0.05\%)&=0.25\%,\\5.2\%-4.95\%&=0.25\%,\\0.25\%+0.25\%&=0.5\%=G.\end{aligned}\]

A ได้ดอกเบี้ยลอยตัวที่ถูกลง 0.25% และ B ได้ดอกเบี้ยคงที่ที่ถูกลง 0.25% คิดเป็นเงิน $1{,}000{,}000\times0.0025=\$2{,}500$ ต่อปีต่อบริษัท อัตรา 3.95% ถูกเลือกให้แบ่ง $G$ เท่ากันคนละครึ่ง ถ้าตกลงอัตราอื่น ส่วนแบ่งจะเปลี่ยน แต่รวมกันยังเป็น $G$

ในทางปฏิบัติ สองบริษัทมักทำ swap ผ่าน dealer (ธนาคารที่เป็นตัวกลาง) ซึ่งเก็บส่วนหนึ่งของ $G$ เป็นค่าธรรมเนียม และส่วนต่างเหล่านี้บางส่วนคือค่าความเสี่ยงผิดนัดที่ต่างกันของสองบริษัท ความเสี่ยงนั้นยังอยู่ใน swap ถ้า B ผิดนัด A จะไม่ได้ 3.95% จาก B อีก กำไรนี้จึงไม่ใช่เงินฟรีทั้งหมด

ขั้นที่ 9 — ข้อมูลจริง: อัตราแต่ละอายุเดินด้วยกันแค่ไหน

สมมติว่าธนาคารถือ swap อายุ 5 ปี แล้วอยากลดความเสี่ยงด้วย swap อายุ 2 ปีซึ่งซื้อขายง่ายกว่า (การ hedge) วิธีนี้ได้ผลก็ต่อเมื่อ swap rate สองอายุนี้ขยับไปด้วยกัน ขั้นนี้จึงดูข้อมูลจริงว่ามันขยับไปด้วยกันแค่ไหน

ข้อมูลคือ swap rate และ LIBOR ดอลลาร์รายวัน ตั้งแต่ 2 มกราคม 2014 ถึง 11 ตุลาคม 2018 จากสไลด์ของคอร์ส แบ่งเป็นสองช่วง ช่วงแรกถึง 24 พฤษภาคม 2016 ช่วงสองเริ่ม 25 พฤษภาคม 2016 เครื่องมือมีสองอย่าง อย่างแรกคือ correlation ตัวเลขระหว่าง −1 ถึง 1 ที่บอกว่าสองชุดข้อมูลขึ้นลงด้วยกันแค่ไหน (1 คือขึ้นลงพร้อมกันเป็นเส้นตรงพอดี) อย่างที่สองคือทาย swap อายุหนึ่งด้วยเส้นตรงของอีกอายุ แบบ OLS regression แล้ววัดว่าเส้นตรงพอดีแค่ไหนด้วย $R^2$

\[ \begin{aligned} \hat y_t&=a_0+a_1x_t,\\ R^2&=\frac{\sum_t(\hat y_t-\bar y)^2}{\sum_t(y_t-\bar y)^2}. \end{aligned} \]

$y_t$ คือ swap rate วันที่ $t$ ของอายุที่อยากทาย $x_t$ คือ swap rate วันเดียวกันของอายุที่ใช้ทาย $\hat y_t$ คือค่าที่เส้นตรงทาย และ $\bar y$ คือค่าเฉลี่ยของ $y$ ตัวส่วนของ $R^2$ วัดว่า $y$ แกว่งรอบค่าเฉลี่ยมากแค่ไหน ตัวเศษวัดว่าเส้นตรงตามการแกว่งนั้นได้แค่ไหน $R^2$ จึงเป็นสัดส่วนของการแกว่งที่เส้นตรงอธิบายได้ 100% คือทายได้พอดี 0% คือเส้นตรงไม่ช่วยอะไรเลย

ตารางแรกด้านล่างเป็น correlation ของ LIBOR อายุ 1, 2, 3, 6 และ 12 เดือน ตารางที่สองเป็นของ swap อายุ 2, 3, 5, 7, 10, 15 และ 30 ปี แต่ละช่องเขียนเป็น “ช่วงแรก / ช่วงสอง”

swap ทุกคู่มี correlation อย่างน้อย 0.64 และสูงขึ้นในช่วงสอง ส่วน LIBOR ต่ำได้ถึง 0.29 และส่วนใหญ่ต่ำลงในช่วงสอง เหตุผลหนึ่งอยู่ในสูตร swap rate ซึ่งเป็นค่าเฉลี่ยของ forward ตั้งแต่ปีแรก swap 5 ปีกับ 7 ปีจึงใช้ forward ห้าปีแรกร่วมกัน และขยับไปด้วยกันแทบเลี่ยงไม่ได้

ข้อควรระวัง ตัวเลขเหล่านี้คิดจากระดับของอัตรา ซึ่งมักมีแนวโน้มขึ้นหรือลงยาว ๆ ร่วมกัน correlation จึงดูสูงกว่า correlation ของการเปลี่ยนแปลงรายวัน แต่การ hedge สนใจว่าวันพรุ่งนี้อัตราจะขยับไปด้วยกันไหม จึงควรคิดจากการเปลี่ยนแปลง

ขั้นที่ 10 — fit เส้นตรงด้วย gradient descent และทำไม learning rate ใหญ่ไปถึงระเบิด

เส้นตรงในขั้นก่อนหาได้ด้วยสูตรตรงของ least squares แต่แบบจำลองส่วนใหญ่ที่ต้อง fit กับราคาตลาด เช่น การ calibrate Vasicek และ CIR ไม่มีสูตรตรง ต้องค้นหาตัวเลขที่ทำให้ loss (ตัววัดว่าแบบจำลองทายผิดมากแค่ไหน) ต่ำที่สุด วิธีพื้นฐานคือ gradient descent: ที่จุดปัจจุบัน หาทิศที่ loss ชันขึ้นมากที่สุด (gradient) แล้วก้าวสวนทางไปนิดหนึ่ง ทำซ้ำไปเรื่อย ๆ ขนาดก้าวคุมด้วยตัวเลขที่เรียกว่า learning rate $\gamma$

ขั้นนี้ลองกับข้อมูลเล็ก ๆ ที่รู้คำตอบอยู่แล้ว เพื่อดูว่าถ้าเลือก $\gamma$ ผิดจะเกิดอะไร:

  • ข้อมูลสามจุด ($m=3$) $x=(1,\ 2,\ 3)$ และ $y=(1.5,\ 2.0,\ 2.5)$ ทั้งสามจุดอยู่บนเส้น $y=1+0.5x$ พอดี คำตอบที่ถูกจึงเป็น $a_0=1$, $a_1=0.5$
  • ความคลาดที่จุด $t$ คือ $e_t=a_0+a_1x_t-y_t$ และ loss $J$ คือครึ่งหนึ่งของค่าเฉลี่ยของ $e_t^2$ (ตัว $\tfrac12$ ใส่ไว้ให้อนุพันธ์ไม่มีเลข 2 ติดมา)
  • เริ่มที่ $\theta_0=(a_0,a_1)=(0,0)$ แล้วก้าวหนึ่งก้าว $\theta_1=\theta_0-\gamma\nabla J(\theta_0)$ เทียบ $\gamma=0.1$ กับ $\gamma=0.5$
\[ \begin{aligned} J&=\frac{1}{2m}\sum_{t=1}^{m}e_t^2,\\ \frac{\partial J}{\partial a_0}&=\frac1m\sum_t e_t,\\ \frac{\partial J}{\partial a_1}&=\frac1m\sum_t e_tx_t,\\ \nabla J(0,0)&=(-2,\ -4.3333),\\ \theta_1&=\theta_0-\gamma\,\nabla J(\theta_0),\\ \gamma=0.1&:\ \theta_1=(0.2,\ 0.4333),\\ \gamma=0.5&:\ \theta_1=(1.0,\ 2.1667). \end{aligned} \]

อนุพันธ์มาจาก chain rule: $\partial(e_t^2)/\partial a_0=2e_t$ และ $\partial(e_t^2)/\partial a_1=2e_tx_t$ เพราะ $a_1$ อยู่ใน $e_t$ ในรูป $a_1x_t$ เลข 2 ตัดกับ $\tfrac12$ พอดี ที่ $(0,0)$ เส้นตรงทาย 0 ทุกจุด ความคลาดจึงเป็น $e=(-1.5,\ -2.0,\ -2.5)$:

\[\begin{aligned}\frac{\partial J}{\partial a_0}&=\frac{-1.5-2.0-2.5}{3}=-2,\\\frac{\partial J}{\partial a_1}&=\frac{-1.5(1)-2.0(2)-2.5(3)}{3}\\&=-\frac{13}{3}=-4.3333,\\J(0,0)&=\frac{1.5^2+2.0^2+2.5^2}{6}=2.0833.\end{aligned}\]

gradient ติดลบทั้งคู่ แปลว่าถ้าเพิ่ม $a_0$ และ $a_1$ loss จะลด การก้าวสวนทาง gradient จึงเพิ่มทั้งคู่ เช่นที่ $\gamma=0.1$ ได้ $\theta_1=(0,0)-0.1\times(-2,\,-4.3333)=(0.2,\ 0.4333)$ ลองคิด loss ของสองก้าวที่ได้:

\[\begin{aligned}\gamma=0.1&:\ e=(-0.8667,\ -0.9333,\ -1.0),\\J&=\tfrac{0.7511+0.8711+1.0}{6}=0.4370,\\\gamma=0.5&:\ e=(1.6667,\ 3.3333,\ 5.0),\\J&=\tfrac{2.7778+11.1111+25}{6}=6.4815.\end{aligned}\]

ก้าวเล็ก loss ลดจาก 2.0833 เหลือ 0.4370 ส่วนก้าวใหญ่ loss กลับโตเป็น 6.4815 เพราะก้าวข้ามก้นหลุมไปไกลจนสูงกว่าจุดเริ่ม

ทำไมก้าวใหญ่ถึงระเบิด เพราะข้อมูลอยู่บนเส้นคำตอบ $\theta^*=(1,\ 0.5)$ พอดี loss จึงเป็นกำลังสองของระยะห่างจากคำตอบ และ gradient เป็นเส้นตรงของระยะนั้น: $\nabla J(\theta)=H(\theta-\theta^*)$ โดย $H$ คือ Hessian (matrix ของอนุพันธ์อันดับสอง) ช่องของ $H$ คือค่าเฉลี่ยของ $1$, $x$ และ $x^2$ ได้ $\bar x=(1+2+3)/3=2$ และ $\overline{x^2}=(1+4+9)/3=14/3$ แทนลงในสูตรก้าว ความคลาดจากคำตอบถูกคูณด้วย matrix เดิมทุกก้าว:

\[\begin{aligned}\theta_{k+1}-\theta^*&=(I-\gamma H)(\theta_k-\theta^*),\\H&=\begin{bmatrix}1&2\\2&14/3\end{bmatrix},\\\lambda^2-\tfrac{17}{3}\lambda+\tfrac23&=0,\\\lambda&=5.5465,\ 0.1202,\\\gamma&\lt\frac{2}{5.5465}=0.3606.\end{aligned}\]

ตามทิศของ eigenvector แต่ละตัวของ $H$ ความคลาดถูกคูณด้วย $1-\gamma\lambda$ ทุกก้าว eigenvalue $\lambda$ สองตัวเป็นรากของสมการในแถวที่สาม ซึ่งใช้ trace $1+\tfrac{14}{3}=\tfrac{17}{3}$ และ determinant $\tfrac{14}{3}-4=\tfrac23$ ถ้า $|1-\gamma\lambda|\gt1$ ความคลาดโตทุกก้าว ทิศที่ชันที่สุด ($\lambda=5.5465$) จึงบังคับให้ $\gamma\lt0.3606$ ที่ $\gamma=0.5$ ทิศนี้ถูกคูณด้วย $1-0.5\times5.5465=-1.77$ คือกลับด้านและโตขึ้น 1.77 เท่าทุกก้าว

ทิศที่ราบมี $\lambda=0.1202$ ที่ $\gamma=0.1$ ความคลาดในทิศนี้ถูกคูณด้วย $1-0.1\times0.1202=0.988$ ทุกก้าว คือหดแค่ 1.2% ต่อก้าว โค้ดท้ายหน้านับได้ว่าต้องเดิน 1,115 ก้าว จึงเข้าใกล้คำตอบภายในระยะ $10^{-6}$ นี่คือราคาของ learning rate ที่ปลอดภัย มันต้องเล็กพอสำหรับทิศที่ชันที่สุด แล้วทิศที่ราบก็คืบไปช้ามาก

ข้อมูล swap จริงในสไลด์ของคอร์สให้ภาพเดียวกัน (ทาย 5 ปีด้วย 2 ปี ข้อมูลทั้งช่วง เริ่มที่ $(a_0,a_1)=(-100,\ -100)$) ที่ $\gamma=0.005$ เดิน 300 ก้าวยังไปได้แค่ $(-14.82,\ 10.69)$ ที่ $\gamma=0.1$, 0.2 และ 0.3 ถึงคำตอบ $(1.036,\ 0.628)$ ใน 264, 140 และ 95 ก้าว แต่ที่ $\gamma=0.33$ ระเบิด เพดานของข้อมูลชุดนั้นจึงอยู่ระหว่าง 0.3 กับ 0.33 ส่วนวิธี Nelder–Mead ซึ่งค้นหาโดยไม่ใช้ gradient ได้ $(1.03876,\ 0.62619)$ ตรงกับ least squares ในตาราง

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ลืมคิดลดส่วนต่าง: ส่วนต่างของอัตราต้องคูณด้วย annuity ไม่ใช่จำนวนปี ค่าที่ผิดคือ $5\times25{,}789.05\approx\$128{,}945.23$ ค่าที่ถูกคือ $4.309\times25{,}789.05\approx\$111{,}125.00$ เกินไป $128{,}945.23-111{,}125.00=\$17{,}820.23$

ใช้ค่าเฉลี่ยธรรมดาของ forward เป็น swap rate: ค่าเฉลี่ยธรรมดาให้ปีไกลหนักเกินไป ได้ $\bar F=5.2029\%$ แทน $S_5=5.198422\%$ swap ใหม่ \$50 ล้านที่ตั้งอัตรานี้จึงไม่ได้มีค่าศูนย์ แต่เพี้ยนไป $N(\bar F-S_5)A_5=50{,}000{,}000\times0.0000448452\times4.309\approx\$9{,}661.90$

เอา swap rate ไปคิดลดเงินก้อนเดียว: swap rate เป็นค่าเฉลี่ยของหลายวันจ่าย แบบเดียวกับ par yield มันไม่ใช่อัตราคิดลดของวันใดวันหนึ่ง ถ้าเอา \$50 ล้านในปีที่ 5 ไปหาร จะได้ $50{,}000{,}000/1.051984219^5\approx\$38{,}808{,}233.93$ แต่ค่าที่ถูกคือ $50{,}000{,}000\times0.776=\$38{,}800{,}000$ เกินไป \$8,233.93

ลืมกติกานับวัน: ถ้าขาคงที่นับแบบ actual/360 และครึ่งปีนั้นมี 182 วัน เงินงวดนั้นคือ $10^6\times0.029894\times\tfrac{182}{360}=\$15{,}113.08$ ไม่ใช่ $10^6\times0.029894\times\tfrac12=\$14{,}947$ ต่างกัน $15{,}113.08-14{,}947=\$166.08$ ต่องวด ต่อ \$1 ล้าน

เชื่อ hedge ที่ fit จากช่วงเดียว: ความสัมพันธ์ระหว่างอายุเปลี่ยนได้ตามช่วงเวลา 5 ปีบน 2 ปีมี $R^2$ 4% และความชัน −0.248 ในช่วงแรก แต่มี $R^2$ 97% และความชัน 0.9032 ในช่วงสอง hedge ที่ fit จากช่วงแรกจึงผิดทั้งขนาดและเครื่องหมายในช่วงสอง

ใช้ทำอะไรบนโต๊ะจริง

บริษัทที่กู้ลอยตัวใช้ swap ล็อกต้นทุนให้เป็นอัตราคงที่ บริษัทที่ออกพันธบัตรดอกเบี้ยคงที่ใช้ swap แปลงกลับเป็นลอยตัว ธนาคารใช้ swap rate สร้าง curve ช่วงอายุยาว เพราะ swap ซื้อขายคล่องกว่าพันธบัตร และรายงาน DV01 แยกตามอายุทุกวัน มูลค่าสัญญาเก่าคิดด้วย $N(K-S)A$ โดยไม่ต้องจำลองอัตราลอยตัวในอนาคตเลย เพราะเงินทุกก้อนล็อกได้ด้วย FRA ซึ่งเป็นสัญญาที่จ่ายเป็นเส้นตรงของอัตรา

ตลาดเปลี่ยนไปหลายอย่างหลังวิกฤตปี 2008 swap ที่วางหลักประกัน (collateral) คิดลดด้วยเส้น OIS ซึ่งในดอลลาร์ปัจจุบันคือเส้น SOFR swap มาตรฐานส่วนใหญ่ต้องผ่านสำนักหักบัญชีกลาง (clearing house คือตัวกลางที่รับประกันว่าทั้งสองฝ่ายจะได้เงิน) และตั้งแต่ปี 2023 อ้างอิง SOFR แทน LIBOR โดย SOFR ทบรายวันตลอดงวด แล้วจ่ายช้ากว่าวันสิ้นงวดเล็กน้อย สูตรของหน้านี้ยังใช้ได้ แต่ต้องบอกทุกครั้งว่าเส้นไหนใช้คิดลด และเส้นไหนใช้หา forward ถ้าคู่สัญญาอาจผิดนัด ต้องปรับมูลค่าตาม ความเสี่ยงผิดนัด ด้วย

โจทย์ตรวจความเข้าใจ

1. ลูกค้าอีกรายถือ swap ที่รับคงที่ 5.25% และจ่ายลอยตัว บน notional \$50,000,000 เหมือนลูกค้าในโจทย์เปิดหน้า แต่สัญญาเหลืออายุแค่ 3 ปี จ่ายปีละครั้ง ใช้ discount factor ชุดเดียวกัน ($D_1=0.9512$, $D_2=0.9048$, $D_3=0.8600$) swap ใหม่อายุ 3 ปีควรมีอัตราคงที่เท่าไร สัญญาของลูกค้ารายนี้มีค่าเท่าไร และ DV01 เท่าไร

เฉลย

หา annuity และ par swap rate อายุ 3 ปีก่อน แล้วใช้ “ขาคงที่ลบขาลอยตัว” ต่อ notional \$1:

\[\begin{aligned}A_3&=0.9512+0.9048+0.8600=2.716,\\S_3&=\frac{1-0.86}{2.716}=\frac{0.14}{2.716}=5.1546\%,\\KA_3&=0.0525\times2.716=0.14259,\\V&=N\big(KA_3-(1-D_3)\big)\\&=5\times10^7\times(0.14259-0.14)\\&=5\times10^7\times0.00259=\$129{,}500,\\\mathrm{DV01}&=5\times10^7\times2.716\times0.0001\\&=\$13{,}580.\end{aligned}\]

สัญญานี้มีค่ามากกว่าสัญญา 5 ปี (\$111,125) ทั้งที่อายุสั้นกว่า เพราะอัตรา 3 ปีของตลาดต่ำกว่า ส่วนต่างจึงกว้างกว่า: $5.25\%-5.1546\%=0.0954\%$ หรือ 9.54 bp เทียบกับ 5.16 bp ของสัญญา 5 ปี

2. ระบบของธนาคารเก็บ swap rate ที่ตลาด quote ไว้แค่สี่ตำแหน่ง swap 4 ปีจึงถูกบันทึกเป็น 5.1797% แทนค่าเต็ม ถ้ารู้ discount factor สามปีแรกแล้ว ($B_3=D_1+D_2+D_3$) แกะ $D_4$ ด้วย quote ที่ปัดนี้ได้เท่าไร ต่างจากค่าจริง 0.8170 เท่าไร

เฉลย

ใช้สูตรแกะ curve ด้วย $S_4=0.051797$ และ $B_3=2.716$:

\[\begin{aligned}D_4&=\frac{1-S_4B_3}{1+S_4}\\&=\frac{1-0.051797\times2.716}{1.051797}\\&=\frac{0.859319348}{1.051797}=0.8170011.\end{aligned}\]

ต่างจาก 0.8170 ราว $0.8170011-0.8170=1.1\times10^{-6}$ บนเงิน \$50 ล้านที่ปีที่ 4 คิดเป็น $50{,}000{,}000\times1.14\times10^{-6}\approx\$57$ quote ที่ปัดเล็กน้อยทำให้ discount factor เพี้ยนเล็กน้อย แต่ forward ซึ่งหารด้วยช่วงเวลาสั้นจะขยายความเพี้ยนนี้ให้ใหญ่ขึ้น

3. บริษัท A และ B อยากกู้คนละ \$1 ล้าน A อยากจ่ายลอยตัว B อยากจ่ายคงที่ A กู้คงที่ได้ 6.0% หรือลอยตัว $L+0.5\%$ B กู้คงที่ได้ 7.5% หรือลอยตัว $L+1.2\%$ ทั้งสองทำ swap ผ่าน dealer ที่เก็บค่าธรรมเนียม 0.2% ต่อปี แล้วแบ่งส่วนที่เหลือเท่ากัน สุดท้ายแต่ละบริษัทจ่ายดอกเบี้ยเท่าไร

เฉลย

หาเงินที่แบ่งกันได้ $G$ ก่อน แล้วหักค่าธรรมเนียม:

\[\begin{aligned}G&=(7.5\%-6.0\%)-(1.2\%-0.5\%)\\&=1.5\%-0.7\%=0.8\%,\\0.8\%-0.2\%&=0.6\%,\quad 0.6\%/2=0.3\%,\\A&:\ L+0.5\%-0.3\%=L+0.2\%,\\B&:\ 7.5\%-0.3\%=7.2\%.\end{aligned}\]

แต่ละบริษัทประหยัด 0.3% ต่อปี คิดเป็น $1{,}000{,}000\times0.003=\$3{,}000$ ต่อปี

const {sqrt, hypot} = Math;

// Swap on annual periods (delta = 1): annuity, legs, par rate, value to the fixed receiver.
function swap(D, N, K) {
  const n = D.length, A = D.reduce((s, d) => s + d, 0);
  const prev = [1, ...D.slice(0, -1)];
  const forwards = D.map((d, i) => prev[i] / d - 1);             // simple forward of each year
  const floatPV = forwards.map((F, i) => N * F * D[i]);          // FRA-locked value of each floating payment
  const S = (1 - D[n - 1]) / A;
  return {A, S, forwards, weights: D.map(d => d / A), floatPV, fixPV: N * K * A,
    floatLeg: floatPV.reduce((s, x) => s + x, 0), value: N * (K - S) * A, dv01: N * A * 1e-4};
}
// Bootstrap discount factors back from annual par swap quotes, shortest first.
function fromQuotes(S) {
  const D = []; let B = 0;
  for (const s of S) { const d = (1 - s * B) / (1 + s); D.push(d); B += d; }
  return D;
}
// Floating-rate note valued backwards from the last reset; rates[k] is set at the start of period k + 1.
function frn(N, rates) {
  let V = N;
  for (let k = rates.length - 1; k >= 0; k--) V = (N * rates[k] + V) / (1 + rates[k]);
  return V;
}
// Gradient descent on J(a0, a1) = sum (a0 + a1 x - y)^2 / (2m).
function descend(x, y, lr, steps, start = [0, 0]) {
  const m = x.length, J = a => x.reduce((s, xi, i) => s + (a[0] + a[1] * xi - y[i]) ** 2, 0) / (2 * m);
  let a = start;
  for (let k = 0; k < steps; k++) {
    const e = x.map((xi, i) => a[0] + a[1] * xi - y[i]);
    a = [a[0] - lr * e.reduce((s, v) => s + v, 0) / m, a[1] - lr * e.reduce((s, v, i) => s + v * x[i], 0) / m];
  }
  return {a, J: J(a)};
}

  • ขาคงที่มีราคา $NKA_n$ และขาลอยตัวมีราคา $N(1-D_n)$ แม้ยังไม่รู้อัตรา เหตุผลแรกคือแต่ละงวดล็อกได้ด้วย FRA แล้วพจน์กลางหักกันหมด เหตุผลที่สองคือ floating rate note มีราคาเท่าหน้าตั๋วทุกวัน reset
  • par swap rate คือ $S_n=(1-D_n)/A_n$ ซึ่งเป็นค่าเฉลี่ยถ่วงน้ำหนักของ forward ที่ปีใกล้หนักกว่า ในตัวอย่างได้ 5.198422% ไม่ใช่ค่าเฉลี่ยธรรมดา 5.2029%
  • สัญญาเก่ามีค่า $N(K-S)A$ คือส่วนต่างของอัตราต่อปีคูณ annuity ในตัวอย่างได้ \$111,125 ไม่ใช่ \$128,945.23 และ DV01 คือ $NA\times0.0001=\$21{,}545$ ต่อ bp ซึ่งกระจายไปตามวันจ่าย
  • แกะ discount factor จาก swap rate ได้ทีละอายุ จากสั้นไปยาว ด้วย $D_n=(1-S_nB_{n-1})/(1+S_n)$ แบบเดียวกับการแกะจากพันธบัตร
  • swap ช่วยให้สองบริษัทกู้ในตลาดที่ตัวเองได้เปรียบเชิงเปรียบเทียบ แล้วแลกดอกเบี้ยกัน ในข้อมูลจริง swap ทุกคู่อายุมี correlation อย่างน้อย 0.64 แต่ความสัมพันธ์เปลี่ยนตามช่วงเวลา hedge ที่ fit จากช่วงเดียวจึงเชื่อไม่ได้

ทุกอย่างในหน้านี้ใช้แค่ discount factor ของวันนี้ เพราะเงินทุกก้อนล็อกได้ด้วย FRA ซึ่งจ่ายเป็นเส้นตรงของอัตรา แต่สัญญาบางแบบจ่ายเงินเฉพาะเมื่ออัตราข้ามระดับหนึ่ง เช่น cap และ floor (สัญญาที่จ่ายเมื่ออัตราขึ้นเกินหรือลงต่ำกว่าระดับที่ตกลง) และ swaption (สิทธิ์ที่จะเข้าทำ swap ในอนาคต) สัญญาแบบนี้ต้องรู้ว่าอัตราในอนาคตอาจเป็นได้แค่ไหน หน้าถัดไป lattice ของ Ho–Lee และ BDT สร้างต้นไม้ของอัตราที่อาจเกิดในอนาคต โดยยังให้ราคา zero-coupon bond วันนี้ตรงกับ curve เดิม
