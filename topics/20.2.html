20.2 Swap Rates and the Swap Curve

swap แลกดอกเบี้ยคงที่กับดอกเบี้ยลอยตัว ขาลอยตัวที่ยังไม่รู้อัตรามีค่าวันนี้แน่นอนเท่ากับ $N(1-D_n)$ swap rate จึงเป็นอัตราคงที่ที่ทำให้สองขาเท่ากัน และใช้แกะ curve กลับได้

ลูกค้าถือ swap อายุ 5 ปี notional \$50,000,000 ที่รับดอกเบี้ยคงที่ 5.25% ต่อปีและจ่ายดอกเบี้ยลอยตัว จ่ายกันปีละครั้ง วันนี้ discount factor ปีที่ 1 ถึง 5 คือ 0.9512, 0.9048, 0.8600, 0.8170 และ 0.7760 (ตัวเลขสมมติ) swap ใหม่อายุเท่ากันควรมีอัตราคงที่เท่าไร และสัญญาเก่ามีค่าเท่าไร? เพื่อนร่วมโต๊ะคิดว่าสัญญาเก่าได้เปรียบตลาดราว 5.16 bp ต่อปี ห้าปีคิดเป็น \$128,945.23 ถูกไหม?

ลองตอบก่อนเปิดเฉลย

อัตรา swap วันนี้คือ $(1-0.7760)/4.3090=5.198422\%$ สัญญาเก่ามีค่า \$111,125.00 ไม่ใช่ \$128,945.23 ส่วนต่างปีละ \$25,789.05 ต้องคิดลดทีละปี จึงคูณด้วยผลบวกของ discount factor 4.3090 ไม่ใช่ 5 และที่น่าสนใจกว่าคือขาลอยตัวที่ยังไม่รู้อัตราสักงวด มีค่าวันนี้แน่นอน \$11,200,000

ภาพรวมก่อนลงสูตร

interest rate swap คือสัญญาที่สองฝ่ายแลกกระแสดอกเบี้ยกันบนเงินต้นสมมติ (notional) ก้อนเดียวกัน ฝั่งหนึ่งจ่ายอัตราคงที่ที่ตกลงวันเซ็น อีกฝั่งจ่ายอัตราลอยตัวที่จะรู้ค่าตอนต้นแต่ละงวด เงินต้นไม่ถูกแลกจริง เพราะเท่ากันสองฝั่งและเป็นสกุลเดียวกัน แต่ละงวดจึงจ่ายกันแค่ส่วนต่าง นี่คือสัญญาที่ใหญ่ที่สุดในตลาดดอกเบี้ย

ขาคงที่คิดราคาได้ทันทีด้วย discount factor ที่แกะไว้ตอน bootstrapping ขาลอยตัวดูเหมือนคิดไม่ได้เพราะยังไม่รู้อัตรา แต่ทุกงวดล็อกได้ด้วย FRA (สัญญาล็อกอัตราของช่วงอนาคตที่สร้างได้จาก zero สองตัว) ขาลอยตัวทั้งขาจึงมีราคาแน่นอนวันนี้ รูปด้านล่างวาดเงินของทั้งสองขาจากมุมฝั่งรับคงที่ โดยวาดขาลอยตัวที่ระดับ forward ของวันนี้

หน้านี้จะคิดสองขา หา par swap rate ตีราคาสัญญาเก่าและ DV01 เดินกลับทางเพื่อแกะ curve จาก swap rate ดูกติกาจริงของตลาด เหตุผลที่บริษัททำ swap แล้วจบด้วยข้อมูลจริงว่าแต่ละอายุเดินด้วยกันแค่ไหน และวิธี fit เส้นตรงด้วย gradient descent

ศัพท์ที่ใช้ในหัวข้อนี้
Interest rate swap และ notional
สัญญาแลกกระแสดอกเบี้ยสองชุดบนเงินต้นสมมติ (notional) ก้อนเดียวกัน เงินต้นไม่ถูกแลกจริงเพราะเท่ากันสองฝั่ง ใช้เปลี่ยนหนี้อัตราลอยตัวเป็นอัตราคงที่หรือกลับกัน
Fixed leg และ floating leg
fixed leg จ่ายอัตราคงที่ที่ตกลงวันเซ็นทุกงวด floating leg จ่ายอัตราอ้างอิงที่รู้ค่าตอนต้นแต่ละงวด (reset) แล้วจ่ายตอนปลายงวด (in arrears)
SOFR และ LIBOR
อัตราอ้างอิงของขาลอยตัว LIBOR คืออัตราเฉลี่ยที่ธนาคารใหญ่แจ้งว่าพร้อมให้กันกู้ มีหลายอายุตั้งแต่ข้ามคืนถึง 12 เดือน ใช้จนถึงปี 2023 SOFR คืออัตราข้ามคืนของ repo ที่มีพันธบัตรรัฐบาลสหรัฐฯ ค้ำ ทบกันทั้งงวดแล้วใช้แทน LIBOR ในตลาดดอลลาร์
Par swap rate
อัตราคงที่ที่ทำให้ swap ใหม่มีค่าศูนย์วันเซ็น ไม่มีใครต้องจ่ายใครล่วงหน้า เป็นตัวเลขที่ตลาด quote สำหรับแต่ละอายุ เส้นของมันคือ swap curve
Annuity
ผลบวกของ discount factor คูณความยาวงวดของขาคงที่ คือมูลค่าวันนี้ของการได้ \$1 ต่อปีทุกงวด ใช้แปลงส่วนต่างของอัตราต่อปีเป็นเงินวันนี้
Receive-fixed, pay-fixed และ DV01
ฝั่งรับอัตราคงที่ได้ประโยชน์เมื่อ swap rate ตลาดลง ฝั่งจ่ายอัตราคงที่ได้ประโยชน์เมื่อขึ้น DV01 คือเงินที่มูลค่าเปลี่ยนเมื่ออัตราขยับ 1 bp ใช้กำหนดขนาด hedge และเพดานความเสี่ยงของโต๊ะ

ขั้นที่ 1 — ขาคงที่: เงินเท่ากันทุกงวด และ annuity

เริ่มจากขาที่ง่าย ขาคงที่จ่าย $NK\delta_i$ ทุกงวด เป็นเงินที่รู้ล่วงหน้าทั้งหมด จึงคิดลดทีละก้อนแล้วบวกแบบ ราคาพันธบัตร ได้ทันที เทคนิคเดียวคือดึง $NK$ ซึ่งเหมือนกันทุกงวดออกมาข้างหน้า แล้วตั้งชื่อก้อนที่เหลือ

\[ \begin{aligned} PV_{\rm fix}&=\sum_{i=1}^{n}NK\delta_iD_i\\ &=NK\,A_n,\\ A_5&=0.9512+0.9048\\ &\quad+0.8600+0.8170\\ &\quad+0.7760=4.3090,\\ NK&=2{,}625{,}000,\\ PV_{\rm fix}&=2{,}625{,}000(4.309)\\ &=11{,}311{,}125. \end{aligned} \]

$A_n$ คือมูลค่าวันนี้ของการได้ \$1 ต่อปีทุกงวด มีหน่วยเป็นปีและไม่ขึ้นกับ $K$ จึงคิดครั้งเดียวใช้กับทุกอัตรา swap รายปีมี $\delta_i=1$ annuity จึงเป็นผลบวกของ discount factor ตรง ๆ

ลูกค้าได้ \$2,625,000 ต่อปีห้างวด มีค่าวันนี้ \$11,311,125 ไม่ใช่ \$13,125,000 เพราะเงินปีหลังมีค่าน้อยกว่า

ขั้นที่ 2 — ขาลอยตัว: ล็อกทุกงวดด้วย FRA แล้วพจน์กลางหักกันหมด

ขาลอยตัวจ่าย $N\delta_iL_i$ โดย $L_i$ รู้ค่าตอนต้นงวด วันนี้ยังไม่รู้ แต่ FRA ล็อกเงินก้อนนี้ได้ที่อัตรา $F_i$ โดยไม่เสียเงินวันนี้ และอัตรานั้นอ่านจาก discount factor สองตัว: $1+\delta_iF_i=D_{i-1}/D_i$ เงินสุ่มก้อนนั้นจึงมีค่าเท่ากับเงินแน่นอน $N\delta_iF_i$ ที่ $T_i$ แทนแล้วลองสองงวดแรกด้วยมือ

\[ \begin{aligned} N\delta_iF_iD_i&=N\Big(\frac{D_{i-1}}{D_i}-1\Big)D_i\\ &=N(D_{i-1}-D_i),\\ \frac{V_1}{N}&=1-0.9512=0.0488,\\ \frac{V_2}{N}&=0.9512-0.9048\\ &=0.0464,\\ PV_{\rm flt}&=N\sum_{i=1}^{n}(D_{i-1}-D_i)\\ &=N(1-D_n)\\ &=5\times10^7(0.224)\\ &=11{,}200{,}000. \end{aligned} \]

คูณ forward ด้วย discount factor ของงวดเดียวกัน ตัวส่วนตัดกันพอดี เหลือผลต่างของ discount factor สองตัวที่ติดกัน พอบวกทุกงวด $D_1$ ที่ถูกลบในงวดแรกถูกบวกคืนในงวดสอง พจน์กลางหักกันหมดแบบ telescoping เหลือ $D_0=1$ ลบตัวสุดท้าย รูปขั้นบันไดด้านล่างแสดงเรื่องนี้ด้วยตา

ห้างวดมีค่า \$2.44, \$2.32, \$2.24, \$2.15 และ \$2.05 ล้าน รวม \$11.2 ล้าน สูตรสั้นนี้ใช้ได้เมื่อ forward กับการคิดลดมาจากเส้นเดียวกัน ถ้าใช้สองเส้น (คิดลดด้วยเส้น OIS ทาย forward ด้วยเส้นของ index) ต้องบวกทีละงวดตามแถวแรก

ขั้นที่ 3 — อีกมุม: floating rate note ราคาเท่าหน้าตั๋วทุกวัน reset

ทำไม $N(1-D_n)$ สมเหตุสมผล คิดถึง floating rate note ที่จ่ายคูปองตามอัตราตลาดทุกงวดแล้วคืนเงินต้น $N$ ให้ $r_k$ คืออัตราต่องวดที่รู้ตอนต้นงวด $k$ ซึ่งเป็นอัตราเดียวกับที่ใช้คิดลดงวดนั้น ย้อนจากวัน reset สุดท้ายทีละงวด เหมือนการคิดย้อนบน ต้นไม้ binomial

\[ \begin{aligned} V_{n-1}&=\frac{Nr_n+N}{1+r_n}=N,\\ V_{k-1}&=\frac{Nr_k+V_k}{1+r_k}\\ &=\frac{Nr_k+N}{1+r_k}=N,\\ V_0&=PV_{\rm flt}+N\,D_n=N,\\ PV_{\rm flt}&=N(1-D_n). \end{aligned} \]

ที่วัน reset สุดท้าย เงินที่เหลือคือ $N(1+r_n)$ คิดลดด้วย $r_n$ ตัวเดียวกันจึงได้ $N$ พอดี ถอยทีละงวด ทุกวัน reset มีค่า $N$ ไม่ว่าอัตราในอนาคตจะเป็นเท่าไร เพราะคูปองจ่ายเท่าอัตราที่ใช้คิดลดพอดี ขาลอยตัวของ swap คือ note นี้ที่ไม่มีเงินต้นคืน จึงเท่ากับ $N$ ลบมูลค่าวันนี้ของเงินต้น

ตัวอย่าง: note \$1,000,000 สี่งวด ถ้าทุกงวดเป็น 3% คูปอง \$30,000 มีค่าวันนี้ 29,126.21, 28,277.88, 27,454.25 และ 26,654.61 รวม \$111,512.95 เงินต้นมีค่า \$888,487.05 รวมเป็น \$1,000,000 พอดี ถ้าอัตราสี่งวดเป็น 2%, 5%, 3.5% และ 4% ก็ยังได้ \$1,000,000 ที่ทุกวัน reset ข้อแม้คือผู้ออก note ต้องไม่มีความเสี่ยงผิดนัด

มุมนี้ให้อีกข้อสรุป: เติมเงินต้น $N$ ที่ปลายทั้งสองขาได้โดยไม่เปลี่ยนมูลค่าสุทธิ ฝั่งรับคงที่จึงเท่ากับถือพันธบัตรคูปอง $K$ แล้วชอร์ต floating rate note ซึ่งมีค่า $N$ ทุกวัน reset และแทบไม่ไวต่ออัตรา ความเสี่ยงอัตราของ swap จึงเป็นความเสี่ยงของพันธบัตรคูปองทั้งก้อน

ขั้นที่ 4 — par swap rate: อัตราคงที่ที่ทำให้สองขาเท่ากัน

swap ใหม่ต้องมีค่าศูนย์วันเซ็น เพราะไม่มีใครจ่ายใครล่วงหน้า ตั้งสองขาเท่ากันแล้วตัด $N$ ทิ้ง อัตรา swap จึงไม่ขึ้นกับขนาดสัญญา แถวสุดท้ายได้จากการใส่ผลบวกทีละงวดของขาลอยตัวแทนสูตรย่อ

\[ \begin{aligned} NS_nA_n&=N(1-D_n),\\ S_n&=\frac{1-D_n}{A_n},\\ S_5&=\frac{0.224}{4.309}\\ &=5.198422\%,\\ S_n&=\sum_{i=1}^{n}\frac{D_i}{A_n}\,F_i. \end{aligned} \]

forward ห้าปีคือ 5.1304, 5.1282, 5.2093, 5.2632 และ 5.2835% น้ำหนัก $D_i/A_n$ คือ 0.2207, 0.2100, 0.1996, 0.1896 และ 0.1801 รวมเป็น 1 swap rate จึงเป็นค่าเฉลี่ยถ่วงของ forward ที่ปีใกล้หนักกว่า ค่าเฉลี่ยธรรมดา 5.2029% สูงไปเพราะให้ปีไกลที่ forward สูงหนักเท่าปีใกล้

สูตรนี้หน้าตาเดียวกับ par yield ของพันธบัตร เพราะ swap คือพันธบัตรคูปอง $S_n$ ลบ floating rate note ที่ราคาหน้าตั๋ว ถ้าเขียนแบบที่ตลาดใช้ คือคูณ 100 ให้เป็นเปอร์เซ็นต์และให้งวดยาว $\Delta$ ปี ได้ $s(t,T)=100\,[1-P(t,T)]/[\Delta\sum_{j}P(t,T_j)]$ swap rate จึงไม่ใช่คำทำนายอัตรา ถ้าตลาด quote อัตราอื่น คนจะทำ swap คู่กับ FRA ทีละงวดแล้วเก็บส่วนต่าง

ขั้นที่ 5 — สัญญาเก่าที่ 5.25% มีค่าเท่าไร และ DV01

โจทย์ให้อะไรมาบ้าง: ลูกค้ารับคงที่ 5.25% จ่ายลอยตัว บน \$50,000,000 เหลือห้าปี ตลาดวันนี้ให้ $S_5=5.198422\%$ และ $A_5=4.309$ ตามที่เพิ่งคิด

\[ \begin{aligned} V_{\rm rec}&=PV_{\rm fix}-PV_{\rm flt}\\ &=11{,}311{,}125\\ &\quad-11{,}200{,}000\\ &=111{,}125,\\ V_{\rm rec}&=N(K-S_5)A_5\\ &=25{,}789.05(4.309),\\ \mathrm{DV01}&=NA_5(0.0001)\\ &=21{,}545. \end{aligned} \]

คำตอบ: สัญญาเก่ามีค่า +\$111,125.00 สำหรับฝั่งรับคงที่ (และ −\$111,125.00 สำหรับคู่สัญญาที่จ่ายคงที่) ส่วนต่าง 5.1578 bp ต่อปีเป็นเงิน \$25,789.05 ต่อปี แต่ละปีต้องคิดลด จึงคูณด้วย 4.309 ไม่ใช่ 5 คำตอบ \$128,945.23 ของเพื่อนลืมคิดลด DV01 \$21,545 คือมูลค่าที่เปลี่ยนเมื่อ swap rate ตลาดขยับ 1 bp และ $5.1578(21{,}545)=111{,}125$

ตรวจเองใน 10 วินาที: $0.0525(4.309)=0.2262225$ ลบ $0.224$ ได้ $0.0022225$ คูณ \$50 ล้านได้ \$111,125 พอดี

ขั้นที่ 6 — เดินกลับทาง: แกะ discount factor จาก swap rate

ตลาดไม่ได้ให้ discount factor ตลาด quote swap rate ของแต่ละอายุ เพราะ swap ซื้อขายคล่องกว่าพันธบัตรในหลายช่วงอายุ จึงเดินกลับทาง: รู้ $S_n$ และ discount factor ของอายุที่สั้นกว่า ให้ $B_{n-1}$ คือผลบวกของตัวที่รู้แล้ว แยกพจน์สุดท้ายที่ยังไม่รู้ออกมา

\[ \begin{aligned} S_n(B_{n-1}+D_n)&=1-D_n,\\ D_n(1+S_n)&=1-S_nB_{n-1},\\ D_n&=\frac{1-S_nB_{n-1}}{1+S_n},\\ D_3&=\frac{1-0.0515464(1.856)}{1.0515464}\\ &=0.8600. \end{aligned} \]

ย้ายทุกพจน์ที่มี $D_n$ ไปฝั่งเดียวแล้วหาร เหมือนการแกะ note ตอน bootstrapping จากพันธบัตร ทุกประการ เพราะ swap คือพันธบัตรคูปอง $S_n$ ที่ราคา par: ขาลอยตัวบวกเงินต้นมีค่า $N$ พอดี ต้องไล่จากอายุสั้นไปยาวด้วยเหตุผลเดียวกัน แต่ละ quote เพิ่ม discount factor ที่ไม่รู้แค่ตัวเดียว

par quote ห้าอายุของเส้นนี้คือ 5.1304, 5.1293, 5.1546, 5.1797 และ 5.1984% เกือบแบน ทั้งที่ forward ไต่จาก 5.13 ไป 5.28% เพราะ swap rate เป็นค่าเฉลี่ย แกะกลับได้ discount factor ทั้งห้าตัวเดิม ใช้ quote เต็มความละเอียด เพราะ quote ที่ปัดทำให้ discount factor เพี้ยน (ลองดูในโจทย์ตรวจความเข้าใจท้ายหน้า)

ขั้นที่ 7 — กติกาจริง: swap 2 ปี notional \$1,000,000

swap มาตรฐานของตลาดดอลลาร์ช่วงที่ยังใช้ LIBOR มีอายุนิยม 2, 5, 10 และ 30 ปี ขาคงที่จ่ายทุกครึ่งปี ขาลอยตัวจ่าย 3M LIBOR ทุกไตรมาส อัตรากำหนดตอนต้นงวดแล้วจ่ายตอนปลาย ลอง swap 2 ปีอัตราคงที่ 2.9894% ที่ LIBOR สองงวดแรกเป็น 2.4012% และ 2.7293%

\[ \begin{aligned} p_{\rm fix}&=10^6\Big(\frac12\Big)(0.029894)\\ &=14{,}947,\\ p_{\rm flt,1}&=10^6\Big(\frac14\Big)(0.024012)\\ &=6{,}003,\\ p_{\rm flt,2}&=10^6\Big(\frac14\Big)(0.027293)\\ &=6{,}823.25. \end{aligned} \]

ขาคงที่รู้ทุกงวดตั้งแต่วันแรก สี่งวดละ \$14,947 ขาลอยตัวมีแปดงวด วันนี้รู้แค่งวดแรก \$6,003 งวดที่สองรู้ค่าเมื่อถึงเดือนที่ 3 ทั้งสองขาจ่ายคนละความถี่ จึงหักกลบกันเฉพาะวันที่จ่ายตรงกัน

LIBOR เป็นอัตรา simple ที่ผูกกับราคา zero ด้วย $L(t,T)=100\,[1/P(t,T)-1]/(T-t)$ นับวันแบบ actual/360 และเริ่มนับสองวันทำการหลังวันตกลง ตัวอย่างนี้ใช้ครึ่งปีกับไตรมาสเท่ากันทุกงวดเพื่อให้เลขง่าย ของจริงใช้วันจ่ายจริง: ครึ่งปีที่มี 182 วันให้ขาคงที่ $10^6(0.029894)(182/360)=\$15{,}113.08$ ไม่ใช่ \$14,947

ขั้นที่ 8 — ทำไมบริษัททำ swap: comparative advantage

บริษัท A ต้องการกู้ลอยตัว \$1 ล้าน บริษัท B ต้องการกู้คงที่ \$1 ล้าน อัตราสมมติ: A กู้คงที่ได้ 4.0% หรือลอยตัว $L+0.3\%$ ส่วน B กู้คงที่ได้ 5.2% หรือลอยตัว $L+1.0\%$ B แพงกว่าทั้งสองตลาด แล้วทำไมยังมีเหตุให้ร่วมมือกัน? ดูส่วนต่างของส่วนต่าง แล้วลองให้แต่ละคนกู้ฝั่งที่ได้เปรียบแล้วแลกดอกเบี้ยกัน

\[ \begin{aligned} \Delta_{\rm fix}&=5.2\%-4.0\%=1.2\%,\\ \Delta_{\rm flt}&=1.0\%-0.3\%=0.7\%,\\ G&=1.2\%-0.7\%=0.5\%,\\ A&:\ 4.0\%-3.95\%+L\\ &\quad=L+0.05\%,\\ B&:\ L+1.0\%-L+3.95\%\\ &\quad=4.95\%. \end{aligned} \]

B แพงกว่า A น้อยกว่าในตลาดลอยตัว (0.7% เทียบ 1.2%) จึงได้เปรียบเชิงเปรียบเทียบฝั่งลอยตัว A ได้เปรียบฝั่งคงที่ A กู้คงที่ 4.0% B กู้ลอยตัว $L+1.0\%$ แล้วทำ swap: B จ่ายคงที่ 3.95% ให้ A และ A จ่าย $L$ ให้ B เงินต้น \$1 ล้านของสองฝั่งเท่ากัน จึงไม่ต้องแลก

A จ่ายสุทธิ $L+0.05\%$ แทน $L+0.3\%$ B จ่าย 4.95% แทน 5.2% ประหยัดคนละ 0.25% หรือ \$2,500 ต่อปีบน \$1 ล้าน รวมเท่ากับ $G$ ถ้าผ่าน dealer ส่วนหนึ่งของ $G$ เป็นค่าธรรมเนียม ส่วนต่างเหล่านี้บางส่วนคือค่าความเสี่ยงเครดิตที่ต่างกัน จึงไม่ใช่เงินฟรีทั้งหมด

ขั้นที่ 9 — ข้อมูลจริง: อัตราแต่ละอายุเดินด้วยกันแค่ไหน

ถ้าจะ hedge swap อายุหนึ่งด้วยอีกอายุ ต้องรู้ว่ามันเดินด้วยกันแค่ไหน ข้อมูลรายวันของตลาดดอลลาร์ 2 มกราคม 2014 ถึง 11 ตุลาคม 2018 แบ่งสองช่วงที่ 24/25 พฤษภาคม 2016 ให้ correlation ในสองตารางข้างล่าง และลองทาย swap อายุหนึ่งด้วยเส้นตรงของอีกอายุแบบ OLS regression วัดความพอดีด้วย $R^2$

\[ \begin{aligned} \hat y_t&=a_0+a_1x_t,\\ R^2&=\frac{\sum_t(\hat y_t-\bar y)^2}{\sum_t(y_t-\bar y)^2}. \end{aligned} \]

$y_t$ คือ swap rate อายุที่อยากทาย $x_t$ คืออายุที่ใช้ทาย $R^2$ คือสัดส่วนความแปรผันของ $y$ ที่เส้นตรงอธิบายได้ ตารางแรกเป็น LIBOR 1, 2, 3, 6 และ 12 เดือน ตารางที่สองเป็น swap 2, 3, 5, 7, 10, 15 และ 30 ปี แต่ละช่องคือช่วงแรก / ช่วงสอง

swap ทุกคู่สูงกว่า 0.64 และสูงขึ้นในช่วงสอง LIBOR ต่ำถึง 0.29 และส่วนใหญ่ต่ำลง เหตุผลหนึ่งอยู่ที่สูตร swap rate: มันคือค่าเฉลี่ยของ forward swap 5 ปีกับ 7 ปีใช้ forward ห้าปีแรกร่วมกัน จึงเดินด้วยกันแทบเลี่ยงไม่ได้ ข้อควรระวัง: ตัวเลขเหล่านี้คิดจากระดับอัตราซึ่งมีแนวโน้มร่วมกัน correlation จึงดูสูงกว่าของการเปลี่ยนแปลงรายวัน การ hedge ต้องใช้การเปลี่ยนแปลง

ขั้นที่ 10 — fit เส้นตรงด้วย gradient descent และทำไม learning rate ใหญ่ไปถึงระเบิด

least squares มีสูตรตรง แต่แบบจำลองส่วนใหญ่ที่ต้อง fit กับตลาด เช่น การ calibrate Vasicek และ CIR ไม่มี ต้องหาจุดต่ำสุดของ loss ด้วยการเดินทีละขั้นสวนทาง gradient แบบ gradient descent ลองกับข้อมูลสามจุด $x=(1,2,3)$ $y=(1.5,2.0,2.5)$ ซึ่งคำตอบคือ $a_0=1$ $a_1=0.5$ เริ่มที่ศูนย์ ให้ $e_t=a_0+a_1x_t-y_t$

\[ \begin{aligned} J&=\frac{1}{2m}\sum_{t=1}^{m}e_t^2,\\ \frac{\partial J}{\partial a_0}&=\frac1m\sum_t e_t,\\ \frac{\partial J}{\partial a_1}&=\frac1m\sum_t e_tx_t,\\ \nabla J(0,0)&=(-2,\ -4.3333),\\ \theta_1&=\theta_0-\gamma\,\nabla J,\\ \gamma=0.1&:\ (0.2,\ 0.4333),\\ \gamma=0.5&:\ (1.0,\ 2.1667),\\ \lambda&=5.5465,\ 0.1202,\\ \gamma&\lt\frac{2}{5.5465}=0.3606. \end{aligned} \]

ที่ศูนย์ แบบจำลองทายศูนย์ทุกจุด $e_t$ คือ −1.5, −2.0 และ −2.5 ค่าเฉลี่ย −2 และค่าเฉลี่ยของ $e_tx_t$ คือ $-13/3$ ก้าวด้วย $\gamma=0.1$ loss ลดจาก 2.0833 เหลือ 0.4370 ก้าวด้วย $\gamma=0.5$ loss กลับโตเป็น 6.4815

ทำไม: loss เป็นกำลังสอง ความคลาดจากคำตอบถูกคูณด้วย $I-\gamma H$ ทุกก้าว เมื่อ $H$ คือ Hessian ที่มีสมาชิก 1, 2, 2 และ 14/3 (ค่าเฉลี่ยของ $1$, $x$ และ $x^2$) trace 17/3 และ determinant 2/3 ให้ค่า eigenvalue $\lambda$ สองตัวในแถวรองสุดท้าย (รากของ $\lambda^2-\tfrac{17}{3}\lambda+\tfrac23=0$) ถ้า $|1-\gamma\lambda|\gt 1$ ความคลาดโตทุกก้าว จึงต้องมี $\gamma\lt 0.3606$

ทิศที่ราบมี $\lambda=0.1202$ ที่ $\gamma=0.1$ ความคลาดหดแค่ 1.2% ต่อก้าว ต้องเดิน 1,115 ก้าวจึงเข้าใกล้คำตอบภายใน $10^{-6}$ บนข้อมูล swap จริง (5 ปีบน 2 ปี ทั้งช่วง เริ่มที่ (−100, −100)) $\gamma=0.005$ เดิน 300 ก้าวยังไปได้แค่ (−14.82, 10.69) $\gamma=0.1$, 0.2 และ 0.3 ถึงคำตอบ (1.036, 0.628) ใน 264, 140 และ 95 ก้าว แต่ 0.33 ระเบิด เพดานของข้อมูลชุดนั้นจึงอยู่ระหว่าง 0.3 กับ 0.33 วิธี Nelder–Mead ที่ไม่ใช้ gradient ได้คำตอบเดียวกับ least squares ทุกหลัก (1.03876, 0.62619)

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

ลืมคิดลดส่วนต่าง: $5(25{,}789.05)=\$128{,}945.23$ เกินมูลค่าจริง \$111,125.00 ไป \$17,820.23 ส่วนต่างของอัตราต้องคูณ annuity ไม่ใช่จำนวนปี

ใช้ค่าเฉลี่ยธรรมดาของ forward เป็น swap rate: ได้ 5.2029% แทน 5.198422% swap ใหม่ \$50 ล้านที่อัตรานี้ไม่ได้มีค่าศูนย์ แต่เพี้ยนไป \$9,661.90

เอา swap rate ไปคิดลดเงินก้อนเดียว: \$50 ล้านในปีที่ 5 หารด้วย $1.051984^5$ ได้ \$38,808,233.93 แต่ของจริงคือ $50{,}000{,}000(0.776)=\$38{,}800{,}000$ เกินไป \$8,233.93 swap rate เป็นค่าเฉลี่ยของหลายวันจ่ายแบบเดียวกับ par yield

ลืมกติกานับวัน: ครึ่งปีที่มี 182 วันแบบ actual/360 ให้ขาคงที่ \$15,113.08 ไม่ใช่ \$14,947 ต่างงวดละ \$166.08 ต่อ \$1 ล้าน

เชื่อ hedge ที่ fit จากช่วงเดียว: 5 ปีบน 2 ปีมี $R^2$ 4% และความชัน −0.248 ในช่วงแรก แต่ 97% และ 0.9032 ในช่วงสอง

ใช้ทำอะไรบนโต๊ะจริง

บริษัทที่กู้ลอยตัวใช้ swap ล็อกต้นทุนเป็นอัตราคงที่ ผู้ออกพันธบัตรคงที่ใช้ swap แปลงกลับเป็นลอยตัว ธนาคารใช้ swap rate สร้าง curve ช่วงยาวเพราะซื้อขายคล่องกว่าพันธบัตร และรายงาน DV01 แยกตามอายุทุกวัน มูลค่าสัญญาเก่าคิดแบบ $N(K-S)A$ โดยไม่ต้องจำลองอัตราลอยตัวในอนาคตเลย เพราะเงินทุกก้อนล็อกได้ด้วยสัญญาเชิงเส้น

ตั้งแต่หลังปี 2008 swap ที่มีหลักประกันคิดลดด้วยเส้น OIS (ในดอลลาร์ปัจจุบันคือเส้น SOFR) swap มาตรฐานส่วนใหญ่ต้องผ่านสำนักหักบัญชีกลาง และอ้างอิง SOFR แทน LIBOR ตั้งแต่ปี 2023 SOFR ทบรายวันแล้วจ่ายช้ากว่าวันสิ้นงวดเล็กน้อย สูตรของหน้านี้ยังใช้ได้ แต่ต้องประกาศทุกครั้งว่าเส้นไหนใช้คิดลด เส้นไหนใช้ทาย forward และถ้าคู่สัญญาอาจผิดนัด ต้องปรับมูลค่าด้วย ความเสี่ยงผิดนัด

โจทย์ตรวจความเข้าใจ

1. จาก discount factor ชุดเดียวกัน swap 3 ปีควรมีอัตราเท่าไร และ swap 3 ปีที่รับคงที่ 5.25% บน \$50,000,000 มีค่าเท่าไร?

เฉลย

$A_3=0.9512+0.9048+0.86=2.716$ $S_3=0.14/2.716=5.1546\%$ มูลค่า $50{,}000{,}000(0.0525(2.716)-0.14)=50{,}000{,}000(0.00259)=\$129{,}500$ มากกว่าสัญญา 5 ปี ทั้งที่อายุสั้นกว่า เพราะส่วนต่างกว้างกว่า (9.54 bp เทียบ 5.16 bp) DV01 คือ \$13,580

2. ถ้าตลาด quote swap 4 ปีเป็น 5.1797% (ปัดสี่ตำแหน่ง) และรู้ discount factor สามปีแรก $D_4$ เป็นเท่าไร ต่างจาก 0.8170 เท่าไร?

เฉลย

$B_3=2.716$ $D_4=(1-0.051797(2.716))/1.051797=0.859319348/1.051797=0.8170011$ ต่างจาก 0.8170 ราว $1.1\times10^{-6}$ หรือ \$57 บนเงิน \$50 ล้านที่ปีที่ 4 quote ที่ปัดเล็กน้อยให้ discount factor เพี้ยนเล็กน้อย แต่ forward ที่หารด้วยช่วงสั้นจะขยายความเพี้ยนนี้

3. A กู้คงที่ได้ 6.0% หรือลอยตัว $L+0.5\%$ B กู้คงที่ได้ 7.5% หรือลอยตัว $L+1.2\%$ ถ้า dealer เก็บ 0.2% และแบ่งที่เหลือเท่ากัน แต่ละฝ่ายจ่ายเท่าไร?

เฉลย

$G=(7.5\%-6.0\%)-(1.2\%-0.5\%)=1.5\%-0.7\%=0.8\%$ หัก dealer 0.2% เหลือ 0.6% แบ่งคนละ 0.3% A จ่าย $L+0.5\%-0.3\%=L+0.2\%$ B จ่าย $7.5\%-0.3\%=7.2\%$ ประหยัดคนละ \$3,000 ต่อปีบน \$1 ล้าน

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
const {sqrt, hypot} = Math;

// Swap on annual periods (delta = 1): annuity, legs, par rate, value to the fixed receiver.
function swap(D, N, K) {
  const n = D.length, A = D.reduce((s, d) => s + d, 0);
  const prev = [1, ...D.slice(0, -1)];
  const forwards = D.map((d, i) => prev[i] / d - 1);             // simple forward of each year
  const floatPV = forwards.map((F, i) => N * F * D[i]);          // FRA-locked value of each floating payment
  const S = (1 - D[n - 1]) / A;
  return {A, S, forwards, weights: D.map(d => d / A), floatPV, fixPV: N * K * A,
    floatLeg: floatPV.reduce((s, x) => s + x, 0), value: N * (K - S) * A, dv01: N * A * 1e-4};
}
// Bootstrap discount factors back from annual par swap quotes, shortest first.
function fromQuotes(S) {
  const D = []; let B = 0;
  for (const s of S) { const d = (1 - s * B) / (1 + s); D.push(d); B += d; }
  return D;
}
// Floating-rate note valued backwards from the last reset; rates[k] is set at the start of period k + 1.
function frn(N, rates) {
  let V = N;
  for (let k = rates.length - 1; k >= 0; k--) V = (N * rates[k] + V) / (1 + rates[k]);
  return V;
}
// Gradient descent on J(a0, a1) = sum (a0 + a1 x - y)^2 / (2m).
function descend(x, y, lr, steps, start = [0, 0]) {
  const m = x.length, J = a => x.reduce((s, xi, i) => s + (a[0] + a[1] * xi - y[i]) ** 2, 0) / (2 * m);
  let a = start;
  for (let k = 0; k < steps; k++) {
    const e = x.map((xi, i) => a[0] + a[1] * xi - y[i]);
    a = [a[0] - lr * e.reduce((s, v) => s + v, 0) / m, a[1] - lr * e.reduce((s, v, i) => s + v * x[i], 0) / m];
  }
  return {a, J: J(a)};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ขาคงที่มีค่า $NKA_n$ และขาลอยตัวมีค่า $N(1-D_n)$ เพราะแต่ละงวดล็อกได้ด้วย FRA แล้วพจน์กลางหักกันหมด หรือเพราะ floating rate note ราคาเท่าหน้าตั๋วทุกวัน reset
  • par swap rate คือ $(1-D_n)/A_n$ ซึ่งเป็นค่าเฉลี่ยถ่วงของ forward: 5.198422% ในตัวอย่าง ไม่ใช่ค่าเฉลี่ยธรรมดา 5.2029%
  • สัญญาเก่ามีค่า $N(K-S)A$: \$111,125 ไม่ใช่ \$128,945.23 และ DV01 คือ \$21,545 ต่อ bp กระจายตามวันจ่าย
  • แกะ discount factor จาก swap rate ได้ทีละอายุด้วย $D_n=(1-S_nB_{n-1})/(1+S_n)$ แบบเดียวกับการแกะจากพันธบัตร
  • swap ช่วยให้สองบริษัทกู้ฝั่งที่ตัวเองได้เปรียบแล้วแลกดอกเบี้ยกัน และ swap แต่ละอายุ correlation สูงกว่า 0.64 ทุกคู่ แต่ความสัมพันธ์เปลี่ยนตามช่วงเวลา
