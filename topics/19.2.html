19.2 Marking-to-Market, Margin, and Basis Risk

futures ให้กำไรขาดทุนรวมเท่ากับ forward แต่จ่ายเป็นเงินสดทุกเย็น ความต่างข้อนี้ทำให้ต้องมีเงินสดสำรอง และถ้า hedge ด้วยของที่ไม่ตรงกับสัญญา จะยังเหลือส่วนต่างที่เรียกว่า basis

คุณคาดว่าหุ้นอเมริกาทั้งตลาดจะขึ้น จึงซื้อ ES หนึ่งสัญญา ES คือสัญญา futures บนดัชนี S&P 500 (ดัชนีที่รวมราคาหุ้นใหญ่ 500 ตัวของสหรัฐ) ส่วน futures คือสัญญาซื้อขายในวันข้างหน้าที่ตกลงราคากันวันนี้ และซื้อขายในตลาดกลาง ทุกจุดที่ดัชนีขยับ สัญญาหนึ่งสัญญาได้หรือเสีย \$50

ตอนซื้อ คุณไม่ต้องจ่ายราคาเต็ม แต่ต้องวางเงินประกันไว้ในบัญชีที่เรียกว่าบัญชี margin ทุกเย็นตลาดประกาศ “ราคาชำระ” (settlement price) คือราคาที่ตลาดใช้คิดเงินของวันนั้น แล้วหักหรือเติมเงินในบัญชีตามที่ราคาขยับ ถ้ายอดบัญชีต่ำกว่าเกณฑ์ขั้นต่ำ โบรกเกอร์จะเรียกให้คุณโอนเงินเพิ่ม

ของที่รู้ (ตัวเลขสมมติเพื่อฝึกลงบัญชี ไม่ใช่อัตราจริงของตลาด):

  • ราคาที่ซื้อ 5,000 จุด
  • เงินประกันเริ่มต้น \$12,000 วางตอนซื้อ
  • เกณฑ์ขั้นต่ำ \$9,000 ยอดบัญชีหลังโอนเงินแต่ละเย็นต้องไม่ต่ำกว่านี้
  • ราคาชำระเย็นนี้ 4,988 จุด และเย็นพรุ่งนี้ 4,938 จุด

เย็นนี้เงินออกจากบัญชีเท่าไร เย็นพรุ่งนี้ต้องโอนเงินเข้าเท่าไร เพื่อนบอกว่า “เติมแค่ \$100 ให้บัญชีกลับไปถึง \$9,000 ก็พอ” ถูกไหม?

ลองตอบก่อนเปิดเฉลย

ให้ $\Delta\Pi_t$ คือเงินที่โอนเข้าบัญชี (บวก) หรือออกจากบัญชี (ลบ) ในเย็นวันที่ $t$ และ $V_t$ คือยอดบัญชีหลังโอน เย็นนี้คือ $t=1$ ราคาลง 12 จุด เย็นพรุ่งนี้คือ $t=2$ ราคาลงอีก 50 จุด แต่ละจุดมีค่า \$50:

\[\begin{aligned}\Delta\Pi_1&=50\times(4{,}988-5{,}000)=-\$600,\\V_1&=12{,}000-600=\$11{,}400,\\\Delta\Pi_2&=50\times(4{,}938-4{,}988)=-\$2{,}500,\\V_2&=11{,}400-2{,}500=\$8{,}900.\end{aligned}\]

ยอด \$8,900 ต่ำกว่าเกณฑ์ \$9,000 กติกาของตลาดคือต้องเติมกลับถึงเงินประกันเริ่มต้น ไม่ใช่แค่ถึงเกณฑ์ จึงต้องโอน $12{,}000-8{,}900=\$3{,}100$ ไม่ใช่ $9{,}000-8{,}900=\$100$

สังเกตว่าคุณยังไม่ได้ขายอะไรเลย แต่ต้องหาเงินสด \$3,100 แล้ว เพราะ futures คิดกำไรขาดทุนเป็นเงินสดทุกเย็น ไม่รอวันหมดอายุ

ภาพรวมก่อนลงสูตร

ในหน้า ราคา forward จาก cost of carry เราดูสัญญา forward คือสัญญาซื้อขายในวันข้างหน้าที่ตกลงราคาไว้วันนี้ ระหว่างทางมูลค่าของสัญญาขึ้นลงไปเรื่อย ๆ แต่ไม่มีใครจ่ายเงินกัน เงินทั้งหมดจ่ายก้อนเดียวในวันหมดอายุ ปัญหาคือ ถ้าฝั่งหนึ่งขาดทุนหนักระหว่างทาง เขาอาจหนีไปก่อนถึงวันจ่าย

futures คือสัญญาแบบเดียวกันที่ซื้อขายในตลาดกลาง และแก้ปัญหานี้ด้วยกติกาง่าย ๆ ทุกเย็นตลาดประกาศราคาชำระ แล้วโอนส่วนที่ราคาเปลี่ยนจากเมื่อวานเป็นเงินสดทันที คนที่ขาดทุนจ่าย คนที่กำไรรับ กติกานี้เรียกว่า mark-to-market หนี้ระหว่างสองฝั่งจึงไม่เคยค้างเกินหนึ่งวัน นอกจากนี้ยังมี clearinghouse (สำนักหักบัญชี) ยืนเป็นคู่สัญญาให้ทุกคน เราจึงไม่ต้องกังวลว่าอีกฝั่งตัวจริงคือใคร

ความปลอดภัยนี้มีราคา คือเงินสด เราต้องวางเงินประกัน และต้องเติมเงินทุกครั้งที่บัญชีต่ำกว่าเกณฑ์ แม้พอร์ตทั้งก้อนจะไม่ได้ขาดทุนเลย หน้านี้ทำสี่เรื่อง:

  • ลงบัญชีเงินรายวันทีละวัน แล้วหาว่าราคาลงได้แค่ไหนก่อนถูกเรียกเงิน
  • พิสูจน์ว่าเงินรายวันทุกก้อนรวมกันได้เท่ากับเงินก้อนเดียวของ forward
  • ดูว่าตัวเลขที่เรียกว่า “ราคา futures” คืออะไรกันแน่ และเมื่อไรที่มันไม่เท่ากับราคา forward
  • เรื่อง hedge คือการถือของไว้แล้วขาย futures เพื่อให้กำไรขาดทุนสองขาหักล้างกัน ส่วนต่างระหว่างราคาของที่ถือกับราคา futures เรียกว่า basis และเป็นส่วนที่ hedge เอาออกไม่ได้

รูปด้านล่างวาดโจทย์เปิดเรื่องทั้งหมด: ยอดบัญชี margin สองเย็น และจุดที่ถูกเรียกเงิน

ศัพท์ที่ใช้ในหัวข้อนี้
Forward และ futures
สัญญาซื้อขายในวันข้างหน้าที่ตกลงราคาไว้วันนี้ forward ตกลงกันเองสองฝ่าย และจ่ายเงินก้อนเดียวตอนจบ futures ซื้อขายในตลาดกลาง และจ่ายกำไรขาดทุนเป็นเงินสดทุกเย็น
ES (E-mini S&P 500)
สัญญา futures บนดัชนี S&P 500 ดัชนีขยับหนึ่งจุด สัญญาหนึ่งสัญญาได้หรือเสีย \$50 วันหมดอายุชำระเป็นเงินสด ไม่มีการส่งหุ้นจริง
ฝั่งซื้อและฝั่งขาย (long และ short)
ฝั่งซื้อได้เงินเมื่อราคาขึ้นและเสียเมื่อราคาลง ฝั่งขายกลับกัน ในสูตรของหน้านี้ จำนวนสัญญา $N$ ติดลบแปลว่าเป็นฝั่งขาย
Mark-to-market
กติกาที่ทุกเย็นตลาดตีราคาทุกสัญญาด้วยราคาชำระของวันนั้น แล้วโอนส่วนที่เปลี่ยนจากเมื่อวานเป็นเงินสด คนขาดทุนจ่าย คนกำไรรับ เหมือนปิดสัญญาเก่าแล้วเปิดสัญญาใหม่ทุกวัน มีไว้เพื่อไม่ให้หนี้ระหว่างสองฝั่งสะสมจนใครคิดหนี
Settlement price (ราคาชำระ)
ราคาที่ตลาดประกาศทุกเย็นเพื่อใช้คิดเงินรายวัน มักอิงราคาซื้อขายช่วงท้ายวัน จึงไม่จำเป็นต้องเท่ากับราคาที่เราซื้อขายจริง ในวันหมดอายุ ราคาชำระถูกกำหนดให้เท่ากับระดับดัชนี
Initial margin (เงินประกันเริ่มต้น)
เงินประกันที่ต้องวางตอนเปิดสัญญา เป็นกันชนรับขาดทุนรายวัน ไม่ใช่ราคาของสัญญา และไม่ใช่ขาดทุนสูงสุด
Maintenance margin (เกณฑ์ขั้นต่ำ) และ margin call (การเรียกเงิน)
maintenance margin คือยอดต่ำสุดที่บัญชียอมให้มี ถ้ายอดต่ำกว่านี้หลังโอนเงินรายวัน โบรกเกอร์จะเรียกให้เติมเงินกลับถึง initial margin ภายในเวลาที่กำหนด การเรียกนี้คือ margin call ถ้าไม่เติม สัญญาจะถูกปิด
Clearinghouse (สำนักหักบัญชี)
ตัวกลางที่เป็นผู้ซื้อให้ผู้ขายทุกคน และเป็นผู้ขายให้ผู้ซื้อทุกคน เราจึงไม่ต้องกังวลว่าอีกฝั่งจะหนี clearinghouse เป็นผู้เก็บ margin ของทั้งตลาดด้วย
Hedge
การเปิดสถานะที่กำไรขาดทุนสวนทางกับของที่ถืออยู่ เพื่อให้สองขาหักล้างกัน เช่นถือหุ้นแล้วขาย ES ถ้าหุ้นลง ES ฝั่งขายจะได้เงินชดเชย
Basis
ราคาของที่ถือ ลบด้วยราคา futures ที่ใช้ hedge ถ้าของที่ถือคือของที่สัญญาอ้างอิงพอดี basis ต้องเป็นศูนย์ในวันหมดอายุ
Basis risk
ความเสี่ยงที่ basis ขยับระหว่างที่ hedge อยู่ ส่วนนี้ไม่หายไม่ว่าจะเลือกจำนวนสัญญาเท่าไร จึงต้องประเมินก่อนว่า hedge จะป้องกันได้แค่ไหน

ขั้นที่ 1 — ลองด้วยมือ: สามวันของบัญชี margin

ก่อนเขียนสูตร ลองลงบัญชีด้วยมือสามเย็น จะได้เห็นกติกาทั้งหมดในตัวเลขจริง

โจทย์ให้อะไรมาบ้าง:

  • ซื้อ ES หนึ่งสัญญาที่ราคา $F_0=5{,}000$ จุด จุดละ \$50
  • ยอดบัญชี margin เริ่มต้น $V_0=\$12{,}000$ และเกณฑ์ขั้นต่ำ \$9,000 เหมือนโจทย์เปิดเรื่อง
  • ราคาชำระสามเย็นถัดมา $F_1=4{,}988$, $F_2=5{,}003$ และ $F_3=4{,}990$

กติกาของแต่ละเย็นมีสองข้อ ข้อแรก เงินที่โอนคือราคาชำระวันนี้ลบของเมื่อวาน คูณ \$50 คือ $\Delta\Pi_t=50(F_t-F_{t-1})$ ข้อสอง ยอดบัญชีใหม่คือยอดเมื่อวานบวกเงินที่โอน คือ $V_t=V_{t-1}+\Delta\Pi_t$

\[ \begin{aligned} \Delta\Pi_1&=50(4{,}988-5{,}000)=-600,\\ V_1&=12{,}000-600=11{,}400,\\ \Delta\Pi_2&=50(5{,}003-4{,}988)=+750,\\ V_2&=11{,}400+750=12{,}150,\\ \Delta\Pi_3&=50(4{,}990-5{,}003)=-650,\\ V_3&=12{,}150-650=11{,}500. \end{aligned} \]

ราคาที่เราซื้อ 5,000 ถูกใช้แค่ในเย็นแรก หลังจากนั้นทุกเย็นเทียบกับราคาชำระของเมื่อวาน ไม่ใช่ราคาที่ซื้อ เพราะการขยับก่อนหน้านั้นจ่ายกันไปแล้ว ถ้าเทียบกับ 5,000 ทุกวัน เราจะนับการขยับเดิมซ้ำ เงินจึงย้ายทีละก้อนเล็ก ๆ ทุกเย็น ยอดต่ำสุดคือ \$11,400 ยังสูงกว่าเกณฑ์ \$9,000 จึงยังไม่มีใครเรียกเงินเพิ่ม

คำตอบ: เงินจ่ายเป็นสามก้อน −\$600, +\$750 และ −\$650 รวมเป็นขาดทุน $-600+750-650=-\$500$ บัญชีจบที่ \$11,500

ตรวจเองใน 10 วินาที: ราคาจบที่ 4,990 ต่ำกว่าราคาซื้อ 10 จุด จึงขาดทุน $10\times50=\$500$ และ $12{,}000-500=11{,}500$ ตรงกับยอด $V_3$

ขั้นที่ 2 — กติกาเป็นสมการ และราคาที่ทำให้ถูกเรียกเงิน

การไล่ทีละวันใช้ได้ แต่โต๊ะเทรดอยากตอบสองคำถามโดยไม่ต้องไล่: ราคาลงได้อีกแค่ไหนก่อนถูกเรียกเงิน และถูกเรียกแล้วต้องเติมเท่าไร เราจึงเขียนกติกาเป็นสมการ โดยเพิ่มสัญลักษณ์ต่อไปนี้:

  • $N$ คือจำนวนสัญญา ติดลบแปลว่าฝั่งขาย
  • $M$ คือเงินต่อการขยับหนึ่งจุด สำหรับ ES คือ \$50
  • $V_{\text{init}}$ คือเงินประกันเริ่มต้น และ $V_{\text{mnt}}$ คือเกณฑ์ขั้นต่ำ
  • $C_t$ คือเงินที่ถูกเรียกให้เติมในวันที่ $t$
\[ \begin{aligned} \Delta\Pi_t&=NM(F_t-F_{t-1}),\\ V_t&=V_{t-1}+\Delta\Pi_t,\\ C_t&=V_{\text{init}}-V_t\quad(V_t\lt V_{\text{mnt}}). \end{aligned} \]

สองสมการแรกคือกติกาเดียวกับที่ใช้ลงบัญชีด้วยมือ แค่เขียนให้ใช้ได้กับกี่สัญญาก็ได้ สมการของ $C_t$ คือจุดที่เพื่อนพลาด เมื่อยอดต่ำกว่าเกณฑ์ ต้องเติมกลับถึงเงินประกันเริ่มต้น ไม่ใช่แค่ถึงเกณฑ์ ตลาดทำแบบนี้เพื่อให้กันชนกลับมาเต็ม เพราะถ้าเติมแค่ถึง \$9,000 ราคาลงอีกนิดเดียวก็ถูกเรียกอีก

ใส่ตัวเลขของโจทย์เปิดเรื่อง ($N=1$, $M=50$) ยอดหลังเย็นแรกคือ $V_1=\$11{,}400$ จากเฉลย แล้วดูเย็นที่สอง:

\[ \begin{aligned} V_2&=11{,}400+50(4{,}938-4{,}988)\\ &=8{,}900\lt9{,}000,\\ C_2&=12{,}000-8{,}900=3{,}100. \end{aligned} \]

คำถามที่สองคือ ราคาต่ำแค่ไหนจึงเริ่มถูกเรียก ก่อนมีการเติมเงิน ยอดบัญชีเมื่อราคาชำระเป็น $F$ คือ $12{,}000+50(F-5{,}000)$ ให้ $F^{*}$ คือราคาที่ทำให้ยอดนี้เท่ากับเกณฑ์พอดี แล้วแก้หา $F^{*}$:

\[ \begin{aligned} 12{,}000+50(F^{*}-5{,}000)&=9{,}000,\\ 50(F^{*}-5{,}000)&=9{,}000-12{,}000=-3{,}000,\\ F^{*}-5{,}000&=-\frac{3{,}000}{50}=-60,\\ F^{*}&=4{,}940. \end{aligned} \]

ถ้าราคาชำระต่ำกว่า 4,940 บัญชีจะต่ำกว่าเกณฑ์ ระยะนี้ห่างจากราคาซื้อแค่ 60 จุด คิดเป็น $60/5{,}000=1.2\%$ ของดัชนี ทำไมแค่นี้ก็พอให้ถูกเรียกเงิน? เพราะสัญญาหนึ่งคุมดัชนีมูลค่า $5{,}000\times50=\$250{,}000$ แต่วางเงินประกันแค่ \$12,000 คือ $250{,}000/12{,}000=20.8$ เท่า การใช้เงินน้อยคุมของมูลค่ามากแบบนี้เรียกว่า leverage ข้อดีคือใช้เงินน้อย ข้อเสียคือดัชนีขยับแค่ 1.2% ก็กินกันชน \$3,000 จนหมด

ขั้นที่ 3 — เงินรายวันรวมกันได้เท่ากับ forward

futures จ่ายทีละก้อนเล็ก ๆ ทุกเย็น ส่วน forward จ่ายก้อนเดียวตอนจบ ก่อนจะใช้ futures แทน forward ได้ ต้องรู้ก่อนว่ายอดรวมของสองแบบเท่ากันไหม วิธีตรวจคือบวกเงินรายวันทุกก้อนเข้าด้วยกัน ให้ $n$ คือจำนวนวันจนถึงวันหมดอายุ และ $S_n$ คือระดับดัชนีในวันนั้น

\[ \begin{aligned} \sum_{t=1}^{n}\Delta\Pi_t&=NM\big[(F_1-F_0)+(F_2-F_1)\\ &\qquad+\cdots+(F_n-F_{n-1})\big]\\ &=NM(F_n-F_0),\\ F_n&=S_n,\\ \sum_{t=1}^{n}\Delta\Pi_t&=NM(S_n-F_0). \end{aligned} \]

ผลรวมนี้ยุบตัวเอง ในวงเล็บ $F_1$ ถูกบวกครั้งหนึ่งแล้วลบครั้งหนึ่ง $F_2$ ก็เช่นกัน ทุกตัวกลางหักล้างกันเป็นคู่ เหลือแค่ตัวสุดท้ายลบตัวแรก

ขั้นที่ต้องมีเหตุผลคือ $F_n=S_n$ ในวันหมดอายุ ราคา futures ต้องเท่ากับดัชนี เพราะสัญญาที่ชำระวันนี้ก็คือของวันนี้ ถ้าสองราคาไม่เท่ากัน ใครก็ซื้อตัวที่ถูกกว่า ขายตัวที่แพงกว่า แล้วเก็บส่วนต่างได้ทันทีโดยไม่เสี่ยง ยอดรวมจึงเท่ากับเงินก้อนเดียวของ forward ที่ตกลงราคา $F_0$ ไว้ คือ $NM(S_n-F_0)$ พอดี

ตรวจกับสามเย็นของขั้นที่ 1 ($N=1$, $M=50$, ราคาจบที่ $F_3=4{,}990$):

\[ \begin{aligned} -600+750-650&=-500,\\ 50(4{,}990-5{,}000)&=-500. \end{aligned} \]

ยอดรวมตรงกัน แต่มีข้อแม้ เรายังไม่ได้นับดอกเบี้ย เงิน \$600 ของเย็นแรกออกจากกระเป๋าตั้งแต่เย็นแรก ไม่ใช่ตอนจบ ถ้าเงินก้อนนั้นยังอยู่กับเรา เราเอาไปฝากได้ดอกเบี้ยระหว่างทาง ความต่างระหว่าง futures กับ forward จึงเหลือเรื่องเดียว คือจังหวะเวลาของเงิน ขั้นที่ 4 และ 5 ดูเรื่องนี้ต่อ

ขั้นที่ 4 — “ราคา” futures บนต้นไม้คืออะไร และทำไมเท่ากับ forward เมื่อดอกเบี้ยคงที่

ตอนนี้ถึงคำถามที่ดูง่ายแต่คนสับสนบ่อย: ตัวเลข $F_t$ ที่เรียกว่า “ราคา futures” เป็นราคาของอะไร มันไม่ใช่เงินที่ต้องจ่ายเพื่อซื้อสัญญา เพราะการเข้าสัญญา futures ไม่ต้องจ่ายอะไรเลย (เงินประกันยังเป็นของเรา แค่ฝากไว้) $F_t$ เป็นแค่ตัวเลขที่ใช้คิดเงินรายวัน ดังนั้นมองได้ว่า futures เป็นของที่มีมูลค่าศูนย์ทุกเวลา และจ่ายเงิน $F_{t+1}-F_t$ ให้คนถือทุกงวด คล้ายปันผลที่บวกก็ได้ลบก็ได้

เราจะหา $F_t$ ด้วย binomial tree คือต้นไม้ราคาที่ทุกงวดราคาขึ้นหรือลงได้สองทาง ในต้นไม้นี้ มูลค่าวันนี้ของเงินที่จะได้งวดหน้า คือค่าเฉลี่ยของเงินนั้นที่ถ่วงด้วยน้ำหนัก $q$ (โอกาสตั้งราคา) แล้วหารด้วยตัวคูณเงินฝาก $R$ เขียนค่าเฉลี่ยแบบนี้ว่า $\mathbb E^{\mathbb Q}_t[\,\cdot\,]$ โดย $t$ บอกว่าเรารู้ข้อมูลถึงงวด $t$ แล้ว เงื่อนไขของเราคือ มูลค่าวันนี้ของเงินงวดหน้าของ futures ต้องเป็นศูนย์

\[ \begin{aligned} 0&=\mathbb E^{\mathbb Q}_t\Big[\frac{F_{t+1}-F_t}{R}\Big]\\ &=\frac{\mathbb E^{\mathbb Q}_t[F_{t+1}]-F_t}{R},\\ F_t&=\mathbb E^{\mathbb Q}_t[F_{t+1}]\\ &=\mathbb E^{\mathbb Q}_t\big[\mathbb E^{\mathbb Q}_{t+1}[F_{t+2}]\big]\\ &=\mathbb E^{\mathbb Q}_t[F_n]=\mathbb E^{\mathbb Q}_t[S_n]. \end{aligned} \]

ความคิดหลักคือ futures เข้าฟรี มูลค่าของมันจึงเป็นศูนย์เสมอ $F_t$ รู้ค่าแล้ว ณ งวด $t$ จึงดึงออกมานอกค่าเฉลี่ยได้ และ $R$ เป็นค่าคงที่ จึงดึงออกมาได้เหมือนกัน ตรงนี้คือจุดที่น่าสนใจ: เศษส่วนเท่ากับศูนย์ ตัวเศษก็ต้องเป็นศูนย์ $R$ จึงหายไปเลย ราคา futures วันนี้จึงเป็นค่าเฉลี่ยธรรมดาของราคางวดหน้า โดยไม่ต้องคิดลดด้วยดอกเบี้ย

จากนั้นทำซ้ำทีละงวดด้วย tower property (ค่าเฉลี่ยของค่าเฉลี่ยแบบมีเงื่อนไข คือค่าเฉลี่ยเดิม) จนถึงวันหมดอายุ ซึ่ง $F_n=S_n$ จากขั้นที่ 3 ได้ $F_t=\mathbb E^{\mathbb Q}_t[S_n]$ ของที่ค่าวันนี้เท่ากับค่าเฉลี่ยของค่าในอนาคตเสมอแบบนี้เรียกว่า martingale ราคา futures จึงเป็น martingale ภายใต้น้ำหนัก $q$

ลองกับตัวเลข ของที่รู้ (สมมติ):

  • หุ้นวันนี้ $S_0=\$100$
  • งวดหน้าราคาขึ้นเป็น 110 หรือลงเป็น 90 จึงได้ $u=110/100=1.1$ และ $d=90/100=0.9$
  • เงินฝากโตงวดละ 2% คือ $R=1.02$ และหุ้นไม่จ่ายปันผล
  • futures หมดอายุในสองงวด ($n=2$)

ขั้นแรกหาน้ำหนัก $q$ ด้วยสูตรของ binomial tree แล้วหาราคาหุ้นที่ปลายทางทั้งสามจุด:

\[ \begin{aligned} q&=\frac{R-d}{u-d}=\frac{1.02-0.90}{1.10-0.90}\\ &=\frac{0.12}{0.20}=0.6,\\ S_2^{uu}&=100(1.1)^2=121,\\ S_2^{ud}&=100(1.1)(0.9)=99,\\ S_2^{dd}&=100(0.9)^2=81. \end{aligned} \]

ที่ปลายทาง ราคา futures เท่ากับราคาหุ้น จากนั้นย้อนกลับทีละงวดด้วยค่าเฉลี่ยถ่วง $q=0.6$ กับ $1-q=0.4$ โดยไม่หารด้วย $R$:

\[ \begin{aligned} F_1^{u}&=0.6(121)+0.4(99)=112.2,\\ F_1^{d}&=0.6(99)+0.4(81)=91.8,\\ F_0&=0.6(112.2)+0.4(91.8)\\ &=104.04=100(1.02)^2. \end{aligned} \]

สังเกตว่า $112.2=110\times1.02$ และ $91.8=90\times1.02$ ทุกจุดก่อนหมดอายุ ราคา futures คือราคาหุ้นคูณ $1.02$ ยกกำลังจำนวนงวดที่เหลือ ซึ่งคือราคา forward จาก cost of carry เมื่อไม่มีปันผล $G_0=S_0R^n=100(1.02)^2$ พอดี ดังนั้นเมื่อดอกเบี้ยคงที่ futures กับ forward มีราคาเดียวกันทุกจุดของต้นไม้

ถ้าหุ้นจ่ายปันผล สูตร $F_0=\mathbb E^{\mathbb Q}_0[S_n]$ ยังใช้ได้ ปันผลเข้ามาเปลี่ยนแค่ $q$ หน้า ปันผลในสูตรราคา ทำให้ดู

ขั้นที่ 5 — เมื่อดอกเบี้ยขยับไปพร้อมราคา futures ไม่เท่ากับ forward

ขั้นที่ 4 ได้ futures เท่ากับ forward เพราะเราให้ดอกเบี้ย $R$ คงที่ ในโลกจริงดอกเบี้ยขยับ และบางช่วงขยับไปทางเดียวกับราคา ตัวอย่างนี้แสดงว่า เมื่อเป็นแบบนั้น จังหวะของเงินรายวันเริ่มมีค่าเป็นเงิน

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ):

  • ถือ futures ฝั่งซื้อหนึ่งหน่วย ได้เงินเมื่อราคาขึ้น เสียเงินเมื่อราคาลง
  • วันแรกราคาขึ้น 10 จุด หรือลง 10 จุด โอกาสเท่ากัน หลังจากนั้นราคาไม่ขยับอีก
  • ถ้าราคาขึ้น ดอกเบี้ยขึ้นเป็น 6% ต่อปี ถ้าราคาลง ดอกเบี้ยลงเป็น 2% ต่อปี
  • เหลือเวลา 1 ปีถึงวันหมดอายุ ดอกเบี้ยคิดแบบทบต้นต่อเนื่อง คือเงิน $x$ ฝากหนึ่งปีที่อัตรา $r$ โตเป็น $xe^{r}$
  • เทียบกับ forward ที่ได้ +10 หรือ −10 จุดก้อนเดียวในวันหมดอายุ

futures จ่ายเงินตั้งแต่วันแรก เงินก้อนนั้นจึงโตด้วยดอกเบี้ยไปอีกหนึ่งปี ส่วน forward ไม่มีเงินระหว่างทาง คำนวณเงินที่มีในวันหมดอายุของแต่ละกรณี แล้วเฉลี่ย:

\[ \begin{aligned} \text{up}:\ \ +10e^{0.06}&=+10.6184,\\ \text{down}:\ \ -10e^{0.02}&=-10.2020,\\ \tfrac12(10.6184-10.2020)&=0.2082,\\ \tfrac12(10-10)&=0. \end{aligned} \]

กรณีราคาขึ้น ขา futures ได้ +10 เป็นเงินสดตั้งแต่วันแรก แล้วเอาไปฝากได้ดอกเบี้ยสูง 6% กรณีราคาลง ต้องหาเงิน 10 มาจ่ายตั้งแต่วันแรก แต่ตอนนั้นดอกเบี้ยถูกแค่ 2% ภาระจึงโตช้า สรุปคือ ได้เงินตอนดอกเบี้ยสูง เสียเงินตอนดอกเบี้ยต่ำ เฉลี่ยสองกรณีได้เปรียบ 0.2082 จุด ส่วน forward ได้ +10 หรือ −10 ตอนจบ เฉลี่ยเป็นศูนย์

ทั้งสองสัญญาเข้าได้ฟรี ถ้าฝั่งซื้อ futures ได้เปรียบแบบนี้ ตลาดต้องตั้งราคา futures ให้สูงกว่า forward เล็กน้อย เพื่อลบความได้เปรียบนั้นออก ถ้าดอกเบี้ยขยับสวนทางกับราคา ทุกอย่างกลับด้าน ต้นไม้ในขั้นที่ 4 ให้สองราคาเท่ากันเพราะ $R$ คงที่ ซึ่งเป็นข้อสมมติ ไม่ใช่ความจริงทั่วไป กับ ES อายุไม่กี่เดือน ความต่างนี้เล็กมาก แต่กับ futures ของอัตราดอกเบี้ยอายุยาว (ดู zero rate และ forward rate) มันใหญ่พอที่โต๊ะต้องปรับ

คำตอบ: ในตัวอย่างนี้ฝั่งซื้อ futures ได้เปรียบ forward เฉลี่ย 0.21 จุด ราคา futures จึงต้องสูงกว่าราคา forward เล็กน้อย

ตรวจเองใน 10 วินาที: กรณีขึ้นได้ดอกเบี้ยราว $10\times6\%=0.6$ จุด กรณีลงเสียดอกเบี้ยราว $10\times2\%=0.2$ จุด เฉลี่ยได้ราว $\tfrac12(0.6-0.2)=0.2$ จุด ใกล้ 0.2082

ขั้นที่ 6 — basis ของดัชนีเดียวกันหดเป็นศูนย์ แต่ของที่ใช้แทนไม่ต้องหด

คนที่ hedge ถือของจริงอยู่ (เช่นหุ้นทั้งตะกร้า) และขาย futures ไว้ ถ้าสองราคาขยับเท่ากันทุกจุด กำไรขาดทุนจะหักล้างกันหมด ส่วนที่ขยับไม่เท่ากันคือส่วนที่ hedge เอาออกไม่ได้ เราจึงต้องรู้ก่อนว่าส่วนต่างนี้เดินอย่างไร ส่วนต่างนี้คือ basis $B_t=S_t-F_t$

เริ่มจากกรณีง่ายที่สุด ของที่ถือคือดัชนี S&P 500 เอง และ hedge ด้วย ES ราคา ES ที่ยุติธรรม (fair value จากหน้า ราคา forward จาก cost of carry) คือ $F_t=S_te^{r\tau}$ โดย $\tau=T-t$ คือเวลาที่เหลือถึงวันหมดอายุ ของที่รู้ (สมมติ):

  • ดัชนี $S_t=5{,}000$ จุด ให้คงที่ เพื่อดูผลของเวลาอย่างเดียว
  • ดอกเบี้ย $r=5\%$ ต่อปี และหุ้นในดัชนีไม่จ่ายปันผล
  • ดู basis เมื่อเวลาเหลือ $\tau=0.5$, $0.25$ และ $0$ ปี ซึ่งให้ $r\tau=0.05\times0.5=0.025$, $0.05\times0.25=0.0125$ และ $0$
\[ \begin{aligned} B_t&=S_t-S_te^{r\tau}=S_t\big(1-e^{r\tau}\big),\\ \tau=0.5:\ \ B&=5{,}000\big(1-e^{0.025}\big)\\ &=5{,}000(1-1.025315)\\ &=-126.58,\\ \tau=0.25:\ \ B&=5{,}000\big(1-e^{0.0125}\big)\\ &=5{,}000(1-1.012578)\\ &=-62.89,\\ \tau=0:\ \ B&=5{,}000(1-1)=0. \end{aligned} \]

basis ติดลบเพราะ futures แพงกว่าดัชนีเท่ากับดอกเบี้ยของเวลาที่เหลือ เมื่อเวลาเหลือน้อยลง ดอกเบี้ยส่วนนี้ก็หดลง จนเป็นศูนย์ในวันหมดอายุ การหดนี้รู้ล่วงหน้าทั้งเส้น จึงไม่ใช่ความเสี่ยง มันคือดอกเบี้ยที่คนขาย futures ได้รับทีละน้อย (ถ้าปันผลมากกว่าดอกเบี้ย basis จะเป็นบวกแทน)

ความเสี่ยงจริงมาจากสองแหล่ง แหล่งแรก ราคา futures ในตลาดเบี่ยงจาก fair value ไปบ้างในระยะสั้น แหล่งที่สอง ของที่ถือไม่ใช่ดัชนี เช่นกองทุนหุ้นเทคโนโลยีที่ hedge ด้วย ES ในกรณีหลัง ไม่มีอะไรบังคับให้ basis เป็นศูนย์ในวันหมดอายุ เพราะ ES ชำระที่ระดับดัชนี ไม่ใช่ที่ราคากองทุน

ขั้นที่ 7 — แยกกำไรขาดทุนหลัง hedge: ส่วนที่ขนาดแก้ได้ กับส่วนที่แก้ไม่ได้

ขั้นที่แล้วบอกว่า basis ของของที่ใช้แทนไม่หายเอง ขั้นนี้วัดว่ามันกินเงินเท่าไรในหนึ่งวัน และแยกให้เห็นว่ากำไรขาดทุนหลัง hedge ส่วนไหนแก้ได้ด้วยการเลือกจำนวนสัญญา ส่วนไหนแก้ไม่ได้

สถานการณ์ (ตัวเลขสมมติ):

  • ถือกองทุนมูลค่า \$250,000 ที่ขึ้นลงตามดัชนีโดยประมาณ ดัชนีอยู่ที่ 5,000 จุด กองทุนจึงได้หรือเสีย $Q=250{,}000/5{,}000=\$50$ ต่อจุดของดัชนี
  • ขาย ES หนึ่งสัญญาไว้ hedge คือ $N=-1$ และ $M=\$50$
  • วันหนึ่ง ES ลง 40 จุด ($\Delta F=-40$) แต่กองทุนลงเท่ากับ 42 จุดของดัชนี ($\Delta S=-42$)

เขียนกำไรขาดทุนรวมของสองขา แล้วแยกการขยับของกองทุนเป็นสองส่วน คือส่วนที่ futures ขยับ กับส่วนที่ basis ขยับ $\Delta S=\Delta B+\Delta F$ ซึ่งเป็นแค่นิยาม $B=S-F$ ที่ย้ายข้าง:

\[ \begin{aligned} \Pi&=Q\,\Delta S+NM\,\Delta F,\\ \Delta S&=\Delta B+\Delta F,\\ \Pi&=Q\,\Delta B+(Q+NM)\,\Delta F. \end{aligned} \]

หัวใจของขั้นนี้คือการจัดกลุ่มใหม่ ก้อน $(Q+NM)\,\Delta F$ คือส่วนที่ขึ้นกับการขยับของ futures ถ้าเลือกจำนวนสัญญาให้ $NM=-Q$ ก้อนนี้หายหมด (การเลือกจำนวนสัญญาเมื่อพอร์ตไม่ได้ขยับเท่าดัชนี คืองานของหน้า การ hedge ด้วย ES) ส่วนก้อน $Q\,\Delta B$ ไม่มี $N$ อยู่เลย จะขายกี่สัญญาก็ไม่หาย ก้อนนี้คือ basis risk

ใส่ตัวเลข เทียบกับกรณีที่ไม่ hedge:

\[ \begin{aligned} \Delta B&=\Delta S-\Delta F=-42-(-40)=-2,\\ Q+NM&=50+(-1)(50)=0,\\ \Pi&=50(-2)+0(-40)=-100,\\ \Pi_{\text{unhedged}}&=Q\,\Delta S=50(-42)=-2{,}100. \end{aligned} \]

ขนาด hedge พอดีแล้ว เพราะ $Q+NM=0$ ถ้าไม่ hedge กองทุนเสีย \$2,100 เมื่อ hedge แล้วเหลือเสียแค่ \$100 ซึ่งคือ basis ที่ขยับ 2 จุด คูณ \$50

ขั้นที่ 8 — hedge ถูกทิศ แต่เงินสดหมดก่อน

hedge ที่ถูกทิศก็ยังทำให้เดือดร้อนได้ เพราะสองขาจ่ายเงินไม่เหมือนกัน ขาหุ้นมีกำไรขาดทุนบนกระดาษ จนกว่าจะขายหุ้น ส่วนขา futures ต้องจ่ายเป็นเงินสดทุกเย็น ตัวอย่างนี้ดูกรณีที่ตลาดวิ่งขึ้นติดกันหลายวัน ซึ่งฝั่งขาย ES เสียเงินทุกเย็น

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ):

  • ถือหุ้น \$250,000 ที่ขึ้นลงตามดัชนี และขาย ES หนึ่งสัญญาที่ 5,000 ไว้ hedge ($N=-1$, $M=\$50$)
  • บัญชี margin เริ่มที่ \$12,000 เกณฑ์ขั้นต่ำ \$9,000
  • ดัชนีขึ้นวันละ 25 จุด ติดกัน 20 วัน จาก 5,000 ไปถึง $5{,}000+20\times25=5{,}500$

คำถามคือ ระหว่าง 20 วันนี้ต้องหาเงินสดมาเติมเท่าไร เริ่มจากเงินที่ออกทุกเย็น แล้วดูว่าบัญชีหลุดเกณฑ์วันไหน:

\[ \begin{aligned} \Delta\Pi_t&=(-1)(50)(25)=-1{,}250,\\ V_2&=12{,}000-2(1{,}250)=9{,}500,\\ V_3&=12{,}000-3(1{,}250)=8{,}250,\\ C_3&=12{,}000-8{,}250=3{,}750,\\ C_3+C_6+\cdots+C_{18}&=6(3{,}750)\\ &=22{,}500,\\ V_{20}&=12{,}000-2(1{,}250)=9{,}500. \end{aligned} \]

หลังสองวันบัญชีเหลือ \$9,500 ยังไม่ต่ำกว่าเกณฑ์ วันที่สามลดลงไปที่ \$8,250 ต่ำกว่าเกณฑ์ จึงถูกเรียกให้เติม \$3,750 กลับถึง \$12,000 แล้ววงจรเดิมเริ่มใหม่ การเรียกเงินจึงเกิดทุกสามวัน คือวันที่ 3, 6, 9, 12, 15 และ 18 รวมหกครั้ง หลังวันที่ 18 เหลืออีกสองวัน บัญชีจึงจบที่ \$9,500 เหมือนหลังสองวันแรก

เงินที่ออกจากกระเป๋าทั้งหมด คือเงินประกันก้อนแรก บวกเงินที่เติม ลบยอดที่ยังเหลือในบัญชี เทียบกับขาดทุนของ ES ที่ราคาขึ้น $5{,}500-5{,}000=500$ จุด:

\[ \begin{aligned} 12{,}000+22{,}500-9{,}500&=25{,}000,\\ 500\times50&=25{,}000. \end{aligned} \]

ยอดตรงกัน เงินที่ออกไปทั้งหมดคือขาดทุนของ ES พอดี และเท่ากับกำไรของหุ้น $Q\times500=50\times500=\$25{,}000$ พอร์ตรวมจึงไม่ได้ขาดทุน ปัญหาคือกำไรของหุ้นเป็นแค่ตัวเลขบนกระดาษ ส่วนเงินที่ต้องเติมต้องเป็นเงินสดภายในวัน ถ้าหาไม่ทัน โบรกเกอร์จะปิด ES ให้ hedge หายไปตรงยอดของการวิ่งขึ้น และความเสี่ยงที่ตั้งใจปิดก็กลับมาทั้งก้อน

คำตอบ: ต้องหาเงินสดเพิ่ม \$22,500 ใน 20 วัน ทั้งที่พอร์ตรวมไม่ได้ขาดทุนเลย

ตรวจเองใน 10 วินาที: ขาดทุนของ ES คือ $500\times50=25{,}000$ บัญชีรับส่วนหนึ่งไว้เองโดยไม่ต้องเติม คือ $12{,}000-9{,}500=2{,}500$ ที่เหลือ $25{,}000-2{,}500=22{,}500$ ต้องเติมจากข้างนอก

ขั้นที่ 9 — ต่อยอด: option บน futures ใช้ต้นไม้ราคา futures ได้ทันที

option คือสิทธิ (ไม่ใช่หน้าที่) ที่จะซื้อหรือขายของในราคาที่ตกลงไว้ ราคาที่ตกลงไว้เรียกว่า strike put คือสิทธิขาย จึงมีค่าเมื่อราคาตลาดต่ำกว่า strike แบบยุโรป (European) แปลว่าใช้สิทธิได้เฉพาะวันหมดอายุ option ที่ซื้อขายมากที่สุดหลายตัวในโลก เช่นบนดัชนี S&P 500, Eurostoxx 50, FTSE 100 และ Nikkei 225 อ้างอิง futures ไม่ใช่ดัชนีโดยตรง ข่าวดีคือต้นไม้ราคา futures แบบในขั้นที่ 4 ใช้ตั้งราคา option เหล่านี้ได้ทันที

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ): หาราคา put แบบยุโรปบน futures

  • ดัชนีวันนี้ $S_0=100$
  • ดอกเบี้ย $r=2\%$ ต่อปี และหุ้นในดัชนีจ่ายปันผลต่อเนื่องในอัตรา $c=1\%$ ต่อปี
  • ความผันผวน $\sigma=20\%$ ต่อปี คือขนาดการแกว่งของผลตอบแทนในหนึ่งปี วัดเป็น SD (standard deviation)
  • futures กับ put หมดอายุพร้อมกันที่ $T=0.5$ ปี และ strike $K=100$
  • ใช้ต้นไม้ $n=10$ งวด แต่ละงวดยาว $\Delta t=T/n=0.5/10=0.05$ ปี

ขั้นแรกสร้างต้นไม้ ตามวิธีของ Cox, Ross และ Rubinstein ในหน้า binomial tree ราคาคูณ $u=e^{\sigma\sqrt{\Delta t}}$ เมื่อขึ้น และคูณ $d=1/u$ เมื่อลง เพื่อให้ต้นไม้แกว่งเท่าความผันผวน $\sigma$ สูตรของ $q$ ใช้ $e^{(r-c)\Delta t}$ แทน $R$ เพราะหุ้นที่จ่ายปันผลในอัตรา $c$ โตในต้นไม้แค่ $r-c$ (ส่วนหนึ่งของผลตอบแทนจ่ายออกไปเป็นปันผล):

\[ \begin{aligned} \sigma\sqrt{\Delta t}&=0.2\sqrt{0.05}=0.044721,\\ u&=e^{0.044721}=1.045736,\\ d&=1/u=0.956264,\\ e^{(r-c)\Delta t}&=e^{0.01\times0.05}=1.000500,\\ q&=\frac{1.000500-0.956264}{1.045736-0.956264}\\ &=\frac{0.044236}{0.089472}=0.49441. \end{aligned} \]

งานมีสองรอบ รอบแรกคือต้นไม้ราคา futures ทำแบบเดียวกับขั้นที่ 4 ที่ปลายทาง $F_n=S_n$ แล้วย้อนด้วยค่าเฉลี่ยถ่วง $q$ โดยไม่หารด้วยดอกเบี้ย ผลที่ได้ต้องตรงกับค่าเฉลี่ยของราคาปลายทาง:

\[ \begin{aligned} F_0&=\mathbb E^{\mathbb Q}_0[S_n]=S_0e^{(r-c)T}\\ &=100e^{(0.02-0.01)(0.5)}\\ &=100e^{0.005}=100.50. \end{aligned} \]

รอบสองคือต้นไม้ราคา put ที่ปลายทาง put มีค่า $\max(K-F_n,0)$ แล้วย้อนด้วย $q$ เหมือนเดิม แต่คราวนี้หารด้วยดอกเบี้ย $e^{r\Delta t}=e^{0.02\times0.05}=1.0010$ ทุกงวด:

\[ \begin{aligned} P_n&=\max(K-F_n,\,0),\\ P_t&=\frac{q\,P_{t+1}^{u}+(1-q)\,P_{t+1}^{d}}{e^{r\Delta t}},\\ P_0&=5.21. \end{aligned} \]

ทำไมรอบแรกไม่หารด้วยดอกเบี้ย แต่รอบสองหาร? เพราะ futures เข้าฟรี ราคาของมันจึงเป็นค่าเฉลี่ยธรรมดาตามขั้นที่ 4 แต่ put ต้องจ่ายเงินซื้อวันนี้ และได้เงินคืนวันหน้า เงินวันหน้าจึงต้องหารด้วยดอกเบี้ยให้เป็นเงินวันนี้ ตัวเลข $P_0=5.21$ ได้จากการย้อนต้นไม้ 10 งวด ซึ่งมีจุดมากเกินกว่าจะทำด้วยมือ โค้ดท้ายหน้าทำทั้งสองรอบให้ดู

ปันผล $c$ เข้ามาทาง $q$ อย่างเดียว ตรงกับที่ต้นไม้สองงวดในขั้นที่ 4 บอก ในทางปฏิบัติ option ที่ซื้อขายกันมากไม่ต้องใช้ model ตั้งราคา เพราะตลาดบอกราคามาเอง ซึ่งเท่ากับบอกความผันผวน $\sigma$ ที่ซ่อนอยู่ในราคานั้น model จำเป็นตอน hedge และตอนตั้งราคาของที่ไม่มีใครซื้อขาย

คำตอบ: ราคา futures วันนี้ 100.50 และ put strike 100 บน futures มีค่า 5.21

ตรวจเองใน 10 วินาที: $q$ ต้องอยู่ระหว่าง 0 กับ 1 และใกล้ 0.5 เมื่อ $\Delta t$ เล็ก ได้ 0.494 ผ่าน และ $F_0$ ต้องสูงกว่า 100 เพราะดอกเบี้ย 2% มากกว่าปันผล 1% ได้ 100.50 ผ่าน

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

เติมเงินแค่ถึงเกณฑ์: เมื่อถูกเรียกเงิน ต้องเติมกลับถึงเงินประกันเริ่มต้น ไม่ใช่แค่ถึงเกณฑ์ ในโจทย์เปิดเรื่อง คำตอบผิดคือ $9{,}000-8{,}900=\$100$ คำตอบถูกคือ $12{,}000-8{,}900=\$3{,}100$ ถ้าเตรียมเงินไว้แค่ \$100 ก็เติมไม่ครบตามที่ถูกเรียก และสัญญาจะถูกปิดตั้งแต่วันแรกที่ถูกเรียก

คิดว่า margin คือขาดทุนสูงสุด: เงินประกันเป็นแค่กันชน ไม่ใช่เพดานขาดทุน ถ้าดัชนีลง 5% คือ $0.05\times5{,}000=250$ จุด สัญญาเดียวเสีย $250\times50=\$12{,}500$ มากกว่าเงินประกันทั้งก้อน \$12,000 ส่วนที่เกินต้องจ่ายเพิ่มจากกระเป๋า

เทียบกับราคาที่ซื้อทุกวัน: เงินรายวันต้องเทียบกับราคาชำระของเมื่อวาน ถ้าเทียบกับ 5,000 ทุกวันในสามเย็นของขั้นที่ 1 จะนับการขยับของวันก่อนซ้ำ

\[ \begin{aligned} \text{wrong}&=50(4{,}988-5{,}000)\\ &\quad+50(5{,}003-5{,}000)\\ &\quad+50(4{,}990-5{,}000)\\ &=-600+150-500=-950,\\ \text{right}&=-600+750-650=-500. \end{aligned} \]

คิดว่าราคา futures คือเงินที่ต้องจ่าย: ES ที่ 5,000 ไม่ได้แปลว่าต้องจ่าย $5{,}000\times50=\$250{,}000$ เพื่อเข้าสัญญา การเข้าสัญญาฟรี เงินที่ต้องมีคือเงินประกัน \$12,000 กับเงินรายวัน และเพราะเข้าฟรี ห้ามหารด้วยดอกเบี้ยตอนย้อนต้นไม้ราคา futures บนต้นไม้หนึ่งงวดของหุ้น 100 ที่ไป 110 หรือ 90 ราคา futures ที่ถูกคือ $0.6(110)+0.4(90)=102$ ถ้าเผลอหารด้วย $R=1.02$ จะได้ $102/1.02=100$ ซึ่งคือราคาหุ้นวันนี้ ไม่ใช่ราคา futures

นับกำไรบนกระดาษเป็นเงินสด: ในขั้นที่ 8 หุ้นได้กำไร $50\times500=\$25{,}000$ ซึ่งเท่ากับขาดทุนของ ES พอดี แต่กำไรนั้นยังไม่ใช่เงินสด ขณะที่ ES ต้องเติมเงินสดจริง $6\times3{,}750=\$22{,}500$ ภายใน 20 วัน

hedge ด้วยของที่ใช้แทนแล้วคาดว่า basis จะหายเอง: basis หดเป็นศูนย์เฉพาะเมื่อของที่ถือคือของที่สัญญาอ้างอิงพอดี ในรูป basis ของที่ใช้แทน เส้นส้มจบที่ −13.3 จุด (ค่าสมมติ) ไม่ใช่ศูนย์ ส่วนนั้นเป็นกำไรหรือขาดทุนของเราเอง

ใช้ทำอะไรบนโต๊ะจริง

โต๊ะที่ใช้ futures hedge มีคนดูแลเงินสดโดยเฉพาะ ทุกเช้าเขาคำนวณว่า ถ้าราคาขยับแรงเท่าวันที่แย่ที่สุดในอดีต โต๊ะจะถูกเรียกเงินเท่าไร แล้วกันเงินสดหรือวงเงินกู้ไว้ก่อน กองทุนที่ถือหุ้นแต่ hedge ด้วย futures จึงถือเงินสดส่วนหนึ่งไว้เสมอ อีกเรื่องที่ต้องระวังคือ clearinghouse มักขึ้นเงินประกันในช่วงที่ตลาดแกว่งแรง ซึ่งเป็นจังหวะที่หาเงินยากที่สุด

ตัวอย่างที่ถูกยกบ่อยคือ Metallgesellschaft บริษัทใหญ่ด้านโลหะและพลังงานของเยอรมนี บริษัททำสัญญาขายน้ำมันให้ลูกค้าในราคาคงที่ล่วงหน้าหลายปี สัญญานี้ขาดทุนถ้าน้ำมันขึ้น บริษัทจึง hedge ด้วยการซื้อ futures น้ำมันอายุสั้น ในปี 1993 ราคาน้ำมันลง ขา futures ขาดทุนและถูกเรียกเงินสดทันที ส่วนสัญญาขายให้ลูกค้ามีกำไร แต่กำไรนั้นจะเป็นเงินสดก็ต่อเมื่อส่งน้ำมันในอีกหลายปี สุดท้ายบริษัทต้องปิดสถานะและบันทึกขาดทุนราว \$1.3 พันล้าน นี่คือฟันเลื่อยแบบเดียวกับรูปของขั้นที่ 8 ในขนาดที่ใหญ่กว่ามาก

ก่อนเปิด hedge ด้วยของที่ไม่ตรงกับดัชนี โต๊ะวัดก่อนว่า basis ในอดีตขยับได้แค่ไหน แล้วบอกเจ้าของเงินล่วงหน้าว่า hedge นี้จะเหลือความเสี่ยงประมาณเท่าไร ไม่ใช่สัญญาว่าความเสี่ยงจะเป็นศูนย์

โจทย์ตรวจความเข้าใจ

1. คุณคาดว่าตลาดจะลง จึงขาย ES สองสัญญาที่ 5,000 ฝั่งขายได้เงินเมื่อราคาลง และเสียเงินเมื่อราคาขึ้น ของที่รู้ (สมมติ): เงินประกันเริ่มต้น \$24,000 เกณฑ์ขั้นต่ำ \$18,000 และราคาชำระสองเย็นถัดมาคือ 5,030 กับ 5,070 แต่ละเย็นเงินออกเท่าไร ถูกเรียกเงินไหม และราคาชำระเท่าไรที่เริ่มทำให้ถูกเรียก?

เฉลย

ใช้ $\Delta\Pi_t=NM(F_t-F_{t-1})$ โดย $N=-2$ และ $M=50$:

\[ \begin{aligned} \Delta\Pi_1&=(-2)(50)(5{,}030-5{,}000)=-3{,}000,\\ V_1&=24{,}000-3{,}000=21{,}000,\\ \Delta\Pi_2&=(-2)(50)(5{,}070-5{,}030)=-4{,}000,\\ V_2&=21{,}000-4{,}000=17{,}000\lt18{,}000,\\ C_2&=24{,}000-17{,}000=7{,}000. \end{aligned} \]

เย็นที่สองถูกเรียกเงิน \$7,000 ราคาที่เริ่มถูกเรียกคือราคา $F^{*}$ ที่ทำให้ยอดบัญชีเท่ากับเกณฑ์พอดี สองสัญญาเสีย $2\times50=\$100$ ต่อจุดที่ราคาขึ้น:

\[ \begin{aligned} 24{,}000-100(F^{*}-5{,}000)&=18{,}000,\\ F^{*}-5{,}000&=\frac{24{,}000-18{,}000}{100}=60,\\ F^{*}&=5{,}060. \end{aligned} \]

ถ้าราคาชำระสูงกว่า 5,060 บัญชีจะต่ำกว่าเกณฑ์และถูกเรียกเงิน

2. คุณซื้อ ES สามสัญญา ราคาชำระของวันที่ 0 ถึง 4 เป็น 5,000 → 5,020 → 4,970 → 5,010 → 5,045 เงินรายวันแต่ละวันเป็นเท่าไร และรวมได้เท่าไร ตรวจผลรวมด้วยการหักล้างของขั้นที่ 3

เฉลย

สามสัญญาได้หรือเสีย $NM=3\times50=\$150$ ต่อจุด:

\[ \begin{aligned} \Delta\Pi_1&=150(5{,}020-5{,}000)=+3{,}000,\\ \Delta\Pi_2&=150(4{,}970-5{,}020)=-7{,}500,\\ \Delta\Pi_3&=150(5{,}010-4{,}970)=+6{,}000,\\ \Delta\Pi_4&=150(5{,}045-5{,}010)=+5{,}250,\\ \textstyle\sum\Delta\Pi_t&=3{,}000-7{,}500+6{,}000+5{,}250\\ &=6{,}750,\\ 150(5{,}045-5{,}000)&=150\times45=6{,}750. \end{aligned} \]

ผลรวมตรงกับสูตรหักล้าง $NM(F_4-F_0)$ แต่ระหว่างทาง วันที่สองต้องจ่ายเงินสด \$7,500 ทั้งที่จบด้วยกำไร

3. คุณถือกองทุน \$500,000 ที่ขึ้นลงตามดัชนี กองทุนได้หรือเสีย $Q=\$100$ ต่อจุดของดัชนี และขาย ES สองสัญญาไว้ hedge วันหนึ่ง ES ลง 30 จุด แต่กองทุนลงเท่ากับ 33 จุด กำไรขาดทุนก่อนและหลัง hedge เป็นเท่าไร?

เฉลย

ใช้ $Q=100$, $N=-2$, $M=50$, $\Delta S=-33$ และ $\Delta F=-30$:

\[ \begin{aligned} \Pi_{\text{unhedged}}&=100(-33)=-3{,}300,\\ NM\,\Delta F&=(-2)(50)(-30)=+3{,}000,\\ \Pi&=-3{,}300+3{,}000=-300. \end{aligned} \]

ตรวจด้วยสูตรแยกของขั้นที่ 7 ขนาด hedge พอดี จึงเหลือแค่ก้อน basis:

\[ \begin{aligned} Q+NM&=100+(-2)(50)=0,\\ \Delta B&=-33-(-30)=-3,\\ Q\,\Delta B&=100(-3)=-300. \end{aligned} \]

4. บนต้นไม้หนึ่งงวด หุ้นวันนี้ราคา 50 งวดหน้าขึ้นเป็น 60 หรือลงเป็น 45 เงินฝากโต $R=1.04$ ต่องวด และหุ้นไม่จ่ายปันผล ราคา futures ที่หมดอายุงวดหน้าเป็นเท่าไร?

เฉลย

หา $u$, $d$ และ $q$ ก่อน แล้วเฉลี่ยราคาปลายทางด้วย $q$ โดยไม่หารด้วย $R$ เพราะ futures เข้าฟรี:

\[ \begin{aligned} u&=60/50=1.2,\quad d=45/50=0.9,\\ q&=\frac{1.04-0.9}{1.2-0.9}=\frac{0.14}{0.30}=0.4667,\\ F_0&=0.4667(60)+0.5333(45)\\ &=28+24=52,\\ G_0&=50(1.04)=52. \end{aligned} \]

เปิดดูโค้ด 
const {exp, sqrt, max} = Math;

// Daily settlement of N contracts (N < 0 = short); below maintenance, top up to initial.
function settle(prices, N, M, initial, maintenance) {
  let balance = initial, paidIn = 0, calls = 0;
  for (let t = 1; t < prices.length; t++) {
    balance += N * M * (prices[t] - prices[t - 1]);
    if (balance < maintenance) { paidIn += initial - balance; balance = initial; calls++; }
  }
  return {balance, paidIn, calls};
}

// Futures lattice: F_n = S_n, then F_t = q F_up + (1 - q) F_down, no discounting.
function futuresLattice(S0, u, d, q, n) {
  let F = [];
  for (let j = 0; j <= n; j++) F.push(S0 * u ** j * d ** (n - j));
  const last = F.slice();
  for (let t = n - 1; t >= 0; t--) F = F.slice(1).map((up, j) => q * up + (1 - q) * F[j]);
  return {F0: F[0], last};
}

// European put on futures: payoff at n, step back with q AND discount by R each step.
function putOnFutures(S0, n, r, c, sigma, T, K) {
  const dt = T / n, u = exp(sigma * sqrt(dt)), d = 1 / u, R = exp(r * dt);
  const q = (exp((r - c) * dt) - d) / (u - d);
  const {F0, last} = futuresLattice(S0, u, d, q, n);
  let P = last.map(f => max(K - f, 0));
  for (let t = n - 1; t >= 0; t--) P = P.slice(1).map((up, j) => (q * up + (1 - q) * P[j]) / R);
  return {u, d, q, F0, put: P[0]};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • futures โอนเงิน $NM(F_t-F_{t-1})$ เป็นเงินสดทุกเย็น โดยเทียบกับราคาชำระของเมื่อวาน ไม่ใช่ราคาที่ซื้อ
  • เมื่อบัญชีต่ำกว่าเกณฑ์ ต้องเติมกลับถึง initial margin ในโจทย์เปิดเรื่องคือ \$3,100 ไม่ใช่ \$100 และ ES ลงแค่ 60 จุด (1.2% ของดัชนี) ก็ถูกเรียกเงิน เพราะเงินประกัน \$12,000 คุมดัชนีมูลค่า \$250,000
  • เงินรายวันรวมกันได้ $NM(S_n-F_0)$ เท่ากับ forward เพราะพจน์กลางหักล้างกันเป็นคู่ และ $F_n=S_n$ ในวันหมดอายุ สองสัญญาต่างกันแค่จังหวะเวลาของเงิน
  • futures เข้าฟรีเสมอ ราคาของมันจึงเป็นค่าเฉลี่ยโดยไม่คิดลด $F_t=\mathbb E^{\mathbb Q}_t[S_n]$ (เป็น martingale) เท่ากับ forward เมื่อดอกเบี้ยคงที่ (104.04 บนต้นไม้สองงวด) และแพงกว่า forward เล็กน้อยเมื่อดอกเบี้ยขยับไปทางเดียวกับราคา
  • หลัง hedge กำไรขาดทุนเหลือ $Q\,\Delta B+(Q+NM)\,\Delta F$ การเลือกจำนวนสัญญาลบได้แค่ก้อนหลัง ก้อน basis ยังอยู่ และ hedge ที่ถูกทิศก็ยังต้องใช้เงินสด (\$22,500 ใน 20 วันที่ตลาดวิ่งขึ้น)

หน้าถัดไป การ hedge ด้วย ES futures ใช้สูตรแยกกำไรขาดทุนนี้กับพอร์ตหุ้นจริงที่ไม่ได้ขยับเท่าดัชนี: ต้องขาย ES กี่สัญญาเมื่อพอร์ตมี beta ไม่เท่ากับหนึ่ง (beta คือพอร์ตขยับกี่เท่าของดัชนี) และความเสี่ยงที่เหลือใหญ่แค่ไหน
