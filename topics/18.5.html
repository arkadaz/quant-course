18.5 Market Microstructure

ราคาที่เห็นบนจอไม่ใช่ราคาที่ซื้อได้จริง การซื้อหรือขายแต่ละครั้งเสียต้นทุนสามก้อน คือครึ่งหนึ่งของส่วนต่างราคาซื้อกับราคาขาย (spread) ค่าธรรมเนียม และ impact ซึ่งคือราคาที่คำสั่งของเราดันเอง ก้อนสุดท้ายมักใหญ่ที่สุด และโตตามขนาดคำสั่ง

ทีมวิจัยทีมหนึ่งเจอกลยุทธ์ซื้อหุ้นที่ดูดีมาก เขาทดสอบมันด้วย backtest คือรันกลยุทธ์บนข้อมูลราคาย้อนหลัง เพื่อดูว่าถ้าทำจริงในอดีตจะได้เท่าไร กลยุทธ์นี้ซื้อหุ้นตัวหนึ่ง ถือไว้ 5 วันทำการ แล้วขายออก จากนั้นเริ่มรอบใหม่ คำถามของหน้านี้คือ ถ้าเอาเงินจริงไปทำ จะได้อย่างที่ backtest บอกไหม

ของที่รู้:

  • เงินที่ใช้ต่อรอบ \$200 ล้าน หุ้นตัวนี้ราคาหุ้นละ \$50
  • backtest บอกว่าแต่ละรอบได้กำไร 0.42% ของเงินที่ลง โดยยังไม่หักต้นทุนใด ๆ
  • ปีหนึ่งมีวันทำการราว 250 วัน (ตลาดหุ้นสหรัฐฯ เปิดปีละราว 252 วัน) รอบละ 5 วันจึงได้ $250/5=50$ รอบต่อปี กำไรบนกระดาษจึงเป็น $50\times0.42\%=21\%$ ต่อปี
  • หุ้นตัวนี้มีคนซื้อขายรวมกันวันละ \$800 ล้าน
  • ราคาหุ้นตัวนี้ขยับวันละราว 1.8% เรียกว่าความผันผวนรายวัน คือ SD (standard deviation) ของผลตอบแทนรายวัน
  • บนจอ คนที่รอซื้อให้ราคาสูงสุด \$49.925 เรียกว่า bid และคนที่รอขายเสนอราคาต่ำสุด \$50.075 เรียกว่า ask ใครอยากซื้อทันทีต้องจ่าย ask ใครอยากขายทันทีได้แค่ bid
  • ค่าธรรมเนียมโบรกเกอร์ 0.08% ต่อการซื้อหนึ่งครั้งหรือการขายหนึ่งครั้ง การซื้อหรือขายหนึ่งครั้งเรียกว่าหนึ่ง “ขา” ซื้อแล้วขายคืนครบหนึ่งรอบเรียกว่า “ไปกลับ”

ทีมคิดว่าต้นทุนมีแค่ค่าธรรมเนียม ไปกลับเสีย $2\times0.08\%=0.16\%$ ต่อรอบ จึงยังเหลือกำไร $0.42\%-0.16\%=0.26\%$ ต่อรอบ ผลตอบแทนจริงต่อปีคือเท่าไร

ลองตอบก่อนเปิดเฉลย

ติดลบราว 74% ต่อปี หน่วยที่ใช้นับต้นทุนคือ bp (basis point) ซึ่ง 1 bp เท่ากับ 0.01% ขาเดียวเสียสามก้อน

  • ครึ่ง spread: ราคากลาง (midpoint) คือค่าเฉลี่ยของ bid กับ ask $(49.925+50.075)/2=\$50.00$ แต่เราซื้อที่ ask \$50.075 จึงจ่ายเกินราคากลาง $(50.075-50.00)/50.00=0.15\%=15$ bp
  • ค่าธรรมเนียม 0.08% หรือ 8 bp
  • impact 72 bp คือราคาที่คำสั่งของเราดันขึ้นเอง เพราะคำสั่ง \$200 ล้านเป็นหนึ่งในสี่ของการซื้อขายทั้งวัน หน้านี้จะคำนวณตัวเลขนี้ให้ดูทีละขั้นด้านล่าง
\[\begin{aligned}c_{\rm leg}&=15+8+72=95\ \text{bp},\\c_{\rm rt}&=2\times95=190\ \text{bp}\\&=1.90\%,\\C&=1.90\%\times200\ \text{M}=3.8\ \text{M},\\G&=0.42\%\times200\ \text{M}=0.84\ \text{M},\\R&=50(0.42\%-1.90\%)=-74\%.\end{aligned}\]

$c_{\rm leg}$ คือต้นทุนขาเดียว $c_{\rm rt}$ คือต้นทุนไปกลับ $C$ คือต้นทุนต่อรอบเป็นดอลลาร์ $G$ คือกำไรก่อนต้นทุนต่อรอบ และ $R$ คือผลทั้งปี 50 รอบ แต่ละรอบขาดทุน $3.8-0.84=\$2.96$ ล้าน ค่าธรรมเนียมที่ทีมนับเป็นก้อนที่เล็กที่สุดในสามก้อน

ภาพรวมก่อนลงสูตร

หัวข้อก่อน ๆ ในเล่มสมมติว่าเราซื้อขายได้ที่ราคาเดียว และซื้อได้มากเท่าไรก็ได้ หน้ากำไรขาดทุนของการ delta hedge ก็คิดต้นทุนแค่ค่าธรรมเนียม 10 bp (0.10%) ความจริงไม่ได้ง่ายแบบนั้น หน้านี้จะดูว่าคำสั่งซื้อจริงเดินผ่านตลาดอย่างไร และต้นทุนแยกเป็นกี่ก้อน

ตลาดหุ้นจับคู่คนซื้อกับคนขายด้วยรายการที่เรียกว่า order book มันคือบันไดของคำสั่งที่รออยู่ ฝั่งคนรอขายเรียงจากราคาถูกขึ้นไปหาแพง ฝั่งคนรอซื้อเรียงจากราคาสูงลงมา ระหว่างสองฝั่งมีช่องว่างที่เรียกว่า spread คือราคาขายต่ำสุดลบราคาซื้อสูงสุด

ถ้าเราอยากซื้อทันที เราต้องข้ามช่องว่างนั้นไปซื้อจากคนที่รอขาย แต่ละขั้นของบันไดมีหุ้นจำกัด ถ้าสั่งมาก เราก็ต้องไต่ขึ้นไปซื้อขั้นที่แพงกว่า ราคาเฉลี่ยที่จ่ายจึงแพงขึ้น และหลังคำสั่งจบ ราคากลางของตลาดก็ขยับขึ้นตามไปด้วย ต้นทุนจึงมีสามก้อน

  • ครึ่ง spread คือราคาที่จ่ายเกินราคากลาง เพราะต้องซื้อจากฝั่งขาย
  • ค่าธรรมเนียมที่จ่ายให้โบรกเกอร์และตลาด
  • impact คือราคาที่คำสั่งของเราดันเอง ก้อนนี้โตตามขนาดคำสั่ง

ลำดับของหน้า: เริ่มจากซื้อหุ้นบน order book ด้วยมือ แล้ววัดว่าหุ้นซื้อขายง่ายแค่ไหน จากนั้นแยกต้นทุนของคำสั่งหนึ่งออกเป็นชิ้น ต่อด้วยวิธีของ Roll ที่เดา spread จากราคาที่ซื้อขายจริงอย่างเดียว แล้วประมาณ impact ด้วยสองสูตรที่ใช้กันจริง คือกฎรากที่สอง และสูตรต้นทุนของ Kissel กับ Glantz จากนั้นตอบโจทย์เปิดหน้า ลองหาทางแก้ และจบที่การคิดต้นทุนตั้งแต่ตอนเลือกพอร์ต

ศัพท์ที่ใช้ในหัวข้อนี้
Backtest
การรันกลยุทธ์บนข้อมูลราคาย้อนหลัง เพื่อดูว่าถ้าทำจริงในอดีตจะได้เท่าไร ตัวเลขที่ได้ดีแค่ไหนขึ้นกับว่าคิดต้นทุนครบหรือเปล่า
bp (basis point)
หนึ่งในร้อยของ 1% คือ 1 bp = 0.01% หน่วยนี้ใช้นับต้นทุนการซื้อขาย เพราะตัวเลขมักเล็กกว่า 1%
ขา และไปกลับ
การซื้อหนึ่งครั้งหรือการขายหนึ่งครั้งเรียกว่าหนึ่งขา ซื้อเข้าแล้วขายออกครบหนึ่งรอบเรียกว่าไปกลับ ต้นทุนไปกลับจึงเท่ากับต้นทุนขาเดียวสองครั้ง
Order book, bid และ ask
order book คือรายการคำสั่งที่รอจับคู่ เรียงตามราคา ถ้าราคาเท่ากัน คำสั่งที่มาก่อนได้จับคู่ก่อน (price-time priority) bid คือราคาสูงสุดที่มีคนรอซื้อ ask คือราคาต่ำสุดที่มีคนรอขาย แต่ละราคามีหุ้นรออยู่จำนวนจำกัด
Spread และ midpoint
spread คือ ask ลบ bid midpoint คือราคากลางของสองราคานี้ คือ (bid + ask) หารด้วย 2 เราใช้ midpoint เป็นเส้นวัดว่าจ่ายแพงไปเท่าไร แต่ไม่มีใครซื้อขายที่ midpoint ได้จริง
Market order และ limit order
market order คือคำสั่งที่ยอมจ่ายข้าม spread เพื่อได้ของทันที limit order คือคำสั่งที่วางราคาไว้ในบันไดแล้วรอ ได้ราคาดีกว่า แต่ไม่รู้ว่าจะได้ของเมื่อไร หรือจะได้เลยไหม
สภาพคล่อง (liquidity)
ความง่ายในการซื้อขาย หุ้นที่สภาพคล่องสูงซื้อขายได้เร็ว ราคาขยับน้อยตอนเราซื้อขาย และรับคำสั่งก้อนใหญ่ได้
Price impact
ราคาที่ขยับเพราะคำสั่งของเราเอง ถ้าคำสั่งใหญ่เมื่อเทียบกับการซื้อขายทั้งวัน มันจะดันราคาแรง สำหรับคำสั่งใหญ่ ก้อนนี้คือต้นทุนก้อนใหญ่ที่สุด
Effective, realized half-spread และ adverse selection
effective คือราคาที่เราจ่ายห่างจาก midpoint ตอนส่งคำสั่ง realized คือราคาที่เราจ่ายห่างจาก midpoint หลังคำสั่งจบ ถ้า realized ติดลบ แปลว่าคนที่ขายให้เราขาดทุน เพราะราคาวิ่งขึ้นหลังเขาขาย ผลแบบนี้เรียกว่า adverse selection คือคนตั้งราคาไปเจอคู่ค้าที่รู้ทางมากกว่า
VWAP และ TWAP
VWAP คือราคาเฉลี่ยของวันที่ถ่วงด้วยปริมาณซื้อขาย TWAP คือราคาเฉลี่ยที่ให้ทุกช่วงเวลามีน้ำหนักเท่ากัน ทั้งสองใช้เป็นเป้าตอนทยอยส่งคำสั่ง และใช้เทียบว่าเราซื้อได้แพงหรือถูก
Dark pool
ตลาดที่ไม่แสดงขนาดคำสั่งและตัวตนของคนส่งจนกว่าจะจับคู่ได้ ใช้ซื้อขายก้อนใหญ่โดยไม่ดันราคาบนจอ แต่ไม่รู้ล่วงหน้าว่าจะได้ของเท่าไร
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$b,\ a,\ m$bid, ask และ midpoint $m=(a+b)/2$ดอลลาร์ต่อหุ้น
$Q,\ V$ขนาดคำสั่ง และปริมาณซื้อขายทั้งวัน (สองตัวต้องใช้หน่วยเดียวกัน)หุ้น หรือดอลลาร์
$\bar P$ราคาเฉลี่ยที่จ่ายจริงดอลลาร์ต่อหุ้น
$C$ต้นทุนเป็นเงินดอลลาร์
$\sigma$ความผันผวนรายวัน คือ SD ของผลตอบแทนรายวันต่อวัน
$I,\ Y$impact เป็นสัดส่วนของราคา และตัวคูณที่ต้องประมาณจากข้อมูลสัดส่วน, ไม่มีหน่วย
$s,\ q_t$ครึ่ง spread และเครื่องหมายของการซื้อขายครั้งที่ $t$ (+1 ซื้อ, −1 ขาย)ดอลลาร์, ไม่มีหน่วย
$\gamma_1$covariance ของการขยับราคาสองครั้งติดกันดอลลาร์ยกกำลังสอง
$x_i,\ y_i,\ \Delta w_i$น้ำหนักใหม่ น้ำหนักเดิม และน้ำหนักที่ย้ายของหุ้นตัวที่ $i$จุด (ทั้งพอร์ตรวมเป็น 100)
$\lambda,\ \eta$ตัวคูณโทษของความเสี่ยง และน้ำหนักของต้นทุนในเป้าหมายของพอร์ตไม่มีหน่วย

ขั้นที่ 1 — กิน order book ด้วยมือ

จอบอกว่าราคาขายต่ำสุดคือ \$100.04 คนใหม่มักคิดว่าซื้อ 40,000 หุ้นก็จ่ายหุ้นละ \$100.04 ขั้นนี้จะลองซื้อจริงบน order book ในรูปด้านบน เพื่อดูว่าทำไมไม่ใช่ (ตัวเลขสมมติทั้งหมด)

  • ฝั่งขายมีสามขั้น: 10,000 หุ้นที่ \$100.04, 16,000 หุ้นที่ \$100.06 และ 22,000 หุ้นที่ \$100.08
  • ฝั่งซื้อสูงสุด (bid) คือ \$100.00
  • เราซื้อ $Q=40{,}000$ หุ้นด้วย market order คือยอมซื้อทันทีที่ราคาเท่าไรก็ได้

คำสั่งจึงต้องไต่บันไดขึ้นไปทีละขั้นจนได้ครบ ในแต่ละขั้น คนที่มาวางขายก่อนได้ขายก่อน ให้ $m$ คือราคากลาง $D$ คือเงินที่จ่ายทั้งหมด $\bar P$ คือราคาเฉลี่ยต่อหุ้น และ $C$ คือเงินที่จ่ายเกินราคากลาง

\[ \begin{aligned} m&=\frac{100.00+100.04}{2}=100.02,\\ D&=10{,}000(100.04)\\ &\quad+16{,}000(100.06)\\ &\quad+14{,}000(100.08)\\ &=4{,}002{,}480,\\ \bar P&=\frac{D}{Q}=\frac{4{,}002{,}480}{40{,}000}\\ &=100.062,\\ C&=(\bar P-m)Q\\ &=0.042(40{,}000)=1{,}680. \end{aligned} \]

ขั้นแรกมีของแค่ 10,000 หุ้น ขั้นที่สองอีก 16,000 หุ้น ส่วนที่เหลือ $40{,}000-26{,}000=14{,}000$ หุ้นต้องซื้อที่ \$100.08 ราคาเฉลี่ยจึงเป็น \$100.062 ไม่ใช่ \$100.04 ที่เห็นบนจอ

เงินที่จ่ายเกินราคากลาง \$1,680 มาจากสองที่ ที่แรกคือครึ่ง spread $C_s$ ซึ่งต้องจ่ายแน่ ๆ แม้ซื้อหุ้นเดียว ที่สองคือการไต่ขึ้นไปซื้อขั้นที่แพงกว่า ก้อนที่สองนี้แหละที่โตตามขนาดคำสั่ง ลองเทียบกับการซื้อแค่ 20,000 หุ้น ซึ่งได้ครึ่งหนึ่งที่ \$100.04 และอีกครึ่งที่ \$100.06 ให้ราคาเฉลี่ยเป็น $\bar P_{20}$

\[ \begin{aligned} C_s&=(100.04-100.02)(40{,}000)\\ &=800,\\ C-C_s&=1{,}680-800=880,\\ \bar P_{20}&=\frac{100.04+100.06}{2}=100.05,\\ \bar P_{20}-m&=100.05-100.02=0.03. \end{aligned} \]

ซื้อ 20,000 หุ้นจ่ายเกินราคากลางหุ้นละ 3 เซนต์ แต่ซื้อ 40,000 หุ้นจ่ายเกินหุ้นละ 4.2 เซนต์ ยิ่งสั่งมาก ต้นทุนต่อหุ้นยิ่งสูง

ถ้าสั่ง 50,000 หุ้น ของที่แสดงทั้งสามขั้นมีแค่ $10{,}000+16{,}000+22{,}000=48{,}000$ หุ้น อีก 2,000 หุ้นต้องรอคนมาวางขายใหม่ ซึ่งมักมาที่ราคาสูงขึ้น ส่วนคนที่วาง limit order ต้องรอคิวในขั้นราคาของตัวเอง ใครมาก่อนได้ก่อน เรื่องคิวนี้มีต่อในหน้าorder book, คิว และ maker-taker

ขั้นที่ 2 — วัดสภาพคล่องสองแบบ: นับปริมาณ หรือคิดเป็นต้นทุน

ก่อนซื้อหุ้นตัวไหน คนส่งคำสั่งอยากรู้ว่าหุ้นตัวนั้นซื้อขายง่ายแค่ไหน ความง่ายนี้เรียกว่าสภาพคล่อง (liquidity) หุ้นที่สภาพคล่องสูงมีสามอย่าง คือซื้อขายได้เร็ว ราคาขยับน้อยตอนเราซื้อขาย และรับคำสั่งก้อนใหญ่ได้เพราะบันไดลึก

วัดสภาพคล่องได้สองแบบ แบบแรกนับปริมาณ เช่น turnover คือจำนวนหุ้นที่ซื้อขายต่อวัน หารด้วยจำนวนหุ้นทั้งหมดของบริษัท แบบที่สองคิดเป็นต้นทุน เช่น spread คิดเป็นสัดส่วนของราคากลาง ลองวัดหุ้นตัวเดิมจากขั้นก่อน โดยสมมติเพิ่มสองตัวเลข

  • หุ้นตัวนี้ซื้อขายกันวันละ 2,000,000 หุ้น (สมมติ)
  • บริษัทมีหุ้นทั้งหมด 500,000,000 หุ้น (สมมติ)
\[ \begin{aligned} \text{turnover}&=\frac{2{,}000{,}000}{500{,}000{,}000}\\ &=0.4\%,\\ \frac{a-b}{m}&=\frac{0.04}{100.02}\\ &=0.0004=4\ \text{bp},\\ \frac{\bar P-m}{m}&=\frac{0.042}{100.02}\\ &=0.00042=4.2\ \text{bp}. \end{aligned} \]

turnover 0.4% บอกว่าแต่ละวันหุ้นเปลี่ยนมือราว 0.4% ของทั้งบริษัท จึงหาคู่ค้าได้ไม่ยาก แต่มันไม่บอกว่าคำสั่งของเราจะเสียเงินเท่าไร แบบคิดเป็นต้นทุนตอบตรงกว่า spread 4 bp แปลว่าคำสั่งเล็กที่สุดเสียครึ่งหนึ่ง คือ 2 bp เพราะจ่ายเกินราคากลางแค่ครึ่ง spread

คำสั่ง 40,000 หุ้นเป็น $40{,}000/2{,}000{,}000=2\%$ ของการซื้อขายทั้งวัน มันเสีย 4.2 bp ซึ่งมากกว่าคำสั่งเล็กสุดสองเท่า เพราะต้องไต่บันไดขึ้นไปซื้อขั้นที่แพงกว่า

ในทางปฏิบัติ มีเครื่องมือแบบคิดเป็นต้นทุนอีกสามตัว ตัวแรกคือ VWAP ราคาเฉลี่ยของวันที่ใช้เทียบว่าเราซื้อได้แพงหรือถูก ตัวที่สองคือตารางของ Loeb ที่บอกต้นทุนตามขนาดคำสั่ง ตัวที่สามคือสูตรต้นทุนของ Kissel กับ Glantz ซึ่งหน้านี้จะใช้ด้านล่าง

ขั้นที่ 3 — แยกต้นทุนหนึ่งคำสั่ง: effective, impact และ realized

หลังคำสั่งจบ โต๊ะเทรดอยากรู้ว่าเงินที่เสียไปไปอยู่ที่ไหน เสียให้คนขายตรง ๆ หรือเสียเพราะคำสั่งเราดันราคาเอง ขั้นนี้แยกต้นทุนออกเป็นสามระยะบนเส้นราคาเดียวกัน โดยใช้หุ้นของโจทย์เปิดหน้า

โจทย์ให้อะไรมาบ้าง:

  • ราคากลางก่อนส่งคำสั่ง $m_0=(49.925+50.075)/2=\$50.00$
  • ดูการซื้อครั้งแรกของคำสั่งนี้ ซึ่งได้ที่ ask คือ $P=\$50.075$
  • หลังคำสั่งทั้งก้อนจบ ราคากลางขึ้นไปอยู่ที่ $m_1=\$50.36$ ตัวเลขนี้มาจาก impact 72 bp ที่หน้านี้จะคำนวณด้านล่าง

ทุกระยะหารด้วยราคากลางก่อนส่งคำสั่ง $m_0$ เพื่อให้เป็นสัดส่วนของราคา $h_{\rm eff}$ คือราคาที่จ่ายห่างจากราคากลางตอนส่งคำสั่ง (effective) $I$ คือระยะที่ราคากลางถูกดันไป (impact) และ $h_{\rm real}$ คือราคาที่จ่ายห่างจากราคากลางใหม่ (realized)

\[ \begin{aligned} h_{\rm eff}&=\frac{P-m_0}{m_0}\\ &=\frac{50.075-50.00}{50.00}=15\ \text{bp},\\ I&=\frac{m_1-m_0}{m_0}\\ &=\frac{50.36-50.00}{50.00}=72\ \text{bp},\\ h_{\rm real}&=\frac{P-m_1}{m_0}\\ &=\frac{50.075-50.36}{50.00}=-57\ \text{bp},\\ h_{\rm eff}&=h_{\rm real}+I. \end{aligned} \]

คำตอบ: ตอนซื้อ เราจ่ายเกินราคากลาง 15 bp คำสั่งทั้งก้อนดันราคากลางขึ้น 72 bp เมื่อเทียบกับราคากลางใหม่ \$50.36 คนที่ขายให้เราที่ \$50.075 ขายถูกไป 57 bp เขาจึงขาดทุน realized ที่ติดลบแบบนี้คือร่องรอยของ adverse selection คนที่ตั้งราคาขายไปเจอคู่ค้าที่รู้ทางมากกว่า และขายของให้ก่อนราคาจะวิ่ง

ตรวจเองใน 10 วินาที: $-57+72=15$ ตรงกับแถวสุดท้าย เพราะระยะจาก $m_0$ ไป $P$ แยกได้เป็นสองท่อน คือจาก $m_1$ ไป $P$ บวกจาก $m_0$ ไป $m_1$: $50.075-50.00=(50.075-50.36)+(50.36-50.00)$

ขั้นที่ 4 — อ่าน spread จากราคาซื้อขายอย่างเดียว: แบบจำลองของ Roll

ข้อมูลเก่าหลายชุดมีแค่ราคาที่ซื้อขายกันจริง ไม่มี bid และ ask เก็บไว้ ถ้าอยากรู้ spread ของหุ้นในอดีต จะทำอย่างไร Richard Roll สังเกตว่าการซื้อขายแต่ละครั้งเกิดที่ ask (ถ้าคนซื้อเป็นฝ่ายรีบ) หรือที่ bid (ถ้าคนขายเป็นฝ่ายรีบ) ราคาที่บันทึกไว้จึงเด้งขึ้นลงรอบราคากลาง และขนาดของการเด้งบอก spread

Roll เขียนความคิดนี้เป็นแบบจำลองด้วยของสี่อย่าง

  • $P_t$ คือราคาของการซื้อขายครั้งที่ $t$
  • $m_t$ คือราคากลางตอนนั้น มันเดินสุ่มทีละก้าว $u_t$ ซึ่งเป็นค่าสุ่มที่ค่าเฉลี่ยศูนย์ ไม่เกี่ยวกับก้าวก่อน ๆ และไม่เกี่ยวกับว่าใครซื้อใครขาย
  • $s$ คือครึ่ง spread
  • $q_t$ คือ $+1$ ถ้าครั้งนั้นเป็นการซื้อ และ $-1$ ถ้าเป็นการขาย สุ่มแบบโยนเหรียญแยกกันทุกครั้ง จึงมีค่าเฉลี่ยศูนย์ ส่วน $q_t^2=1$ เสมอ และ $\mathbb E[q_tq_{t-1}]=0$ เพราะสองครั้งไม่เกี่ยวกัน

เราไม่เห็น $s$ ตรง ๆ แต่เห็นการขยับของราคา $\Delta P_t=P_t-P_{t-1}$ จึงลองหา covariance ของการขยับสองครั้งติดกัน แล้วดูว่า $s$ โผล่ออกมาไหม

\[ \begin{aligned} P_t&=m_t+s\,q_t,\\ m_t&=m_{t-1}+u_t,\\ \Delta P_t&=u_t+s(q_t-q_{t-1}),\\ \gamma_1&=\mathrm{Cov}(\Delta P_t,\Delta P_{t-1})\\ &=s^2\,\mathbb E\big[(q_t-q_{t-1})\\ &\qquad\times(q_{t-1}-q_{t-2})\big]\\ &=s^2(0-0-1+0)=-s^2,\\ 2s&=2\sqrt{-\gamma_1}. \end{aligned} \]

จุดที่ต้องคิดคือบรรทัดของ $\gamma_1$ ทำไมพจน์ $u$ หายไปหมด เพราะ $u_t$ เป็นการเดินของราคากลางที่ไม่เกี่ยวกับการซื้อหรือขาย และไม่เกี่ยวกับ $u$ ตัวก่อน ๆ ผลคูณที่มี $u$ จึงมีค่าเฉลี่ยศูนย์ทั้งหมด เหลือแค่ส่วนของ $q$ พอกางวงเล็บได้สี่พจน์ $q_tq_{t-1}$, $-q_tq_{t-2}$, $-q_{t-1}^2$ และ $q_{t-1}q_{t-2}$ สามพจน์เป็นผลคูณของ $q$ คนละครั้ง ซึ่งค่าเฉลี่ยเป็นศูนย์ เหลือ $-q_{t-1}^2=-1$ ตัวเดียว

ความหมายคือ ถ้าครั้งนี้เป็นการซื้อที่ ask ครั้งถัดไปมีโอกาสครึ่งหนึ่งเป็นการขายที่ bid ราคาจึงเด้งกลับ การขยับขึ้นมักตามด้วยการขยับลง covariance ของการขยับติดกันจึงติดลบ และขนาดของมันคือ $s^2$ พอดี เราจึงถอดรากของ $-\gamma_1$ เพื่อได้ $s$

ตัวอย่าง ถ้าวัดจากข้อมูลได้ $\gamma_1=-0.0004$ ดอลลาร์ยกกำลังสอง จะได้ $s=\sqrt{0.0004}=0.02$ และ spread $2s=\$0.04$ หรือ 4 เซนต์ ตรงกับ order book ด้านบน โค้ดท้ายหน้าจำลองการซื้อขาย 20,000 ครั้งที่ครึ่ง spread 0.02 แล้วใช้สูตรนี้อ่านกลับ ได้ spread 0.0403 ใกล้ของจริงมาก การใช้แบบจำลองนี้กับข้อมูลความถี่สูงจริงอยู่ในหน้าRoll model

ขั้นที่ 5 — กฎรากที่สองของ impact: แบบจำลองที่ต้องประมาณ ไม่ใช่กฎธรรมชาติ

การไต่บันไดด้วยมือใช้ได้กับคำสั่งเล็ก แต่ order book จริงเปลี่ยนทุกเสี้ยววินาที และคำสั่งใหญ่ไม่ได้ซื้อทีเดียวจบ ก่อนส่งคำสั่ง โต๊ะเทรดจึงต้องมีสูตรหยาบไว้เดาว่าคำสั่งจะดันราคาไปเท่าไร

สูตรที่ใช้กันมากเรียกว่ากฎรากที่สอง มันบอกว่า impact $I$ (เป็นสัดส่วนของราคา) เท่ากับตัวคูณ $Y$ คูณความผันผวนรายวัน $\sigma$ คูณรากที่สองของ $Q/V$ ซึ่งคือขนาดคำสั่งเทียบกับการซื้อขายทั้งวัน สูตรนี้เป็นนิยามของแบบจำลอง ไม่ได้พิสูจน์มาจากอะไร คนเลือกรูปรากที่สองเพราะมันเข้ากับข้อมูลของหลายตลาดได้พอสมควร ส่วน $Y$ ต้องประมาณจากข้อมูลของตลาดนั้นเอง ค่าที่พบบ่อยอยู่ระหว่าง 0.5 ถึง 1

ลองใช้กับคำสั่งเดิมจากขั้นแรก คือซื้อ 40,000 หุ้นที่ราคากลาง \$100.02 โดยสมมติตัวเลขกลม ๆ ให้คิดง่าย (ขนาดคำสั่ง 1% นี้ต่างจาก 2% ในขั้นวัดสภาพคล่อง เพราะเป็นตัวอย่างสมมติแยกกัน)

  • ตัวคูณ $Y=1$
  • ความผันผวนรายวัน $\sigma=2\%$
  • คำสั่งเป็น 1% ของการซื้อขายทั้งวัน $Q/V=0.01$

เราจะหา impact เป็นเงิน $C_I$ แล้วเทียบกับต้นทุนครึ่ง spread $C_s$ (2 เซนต์ต่อหุ้น) จากนั้นถามกลับว่าคำสั่งต้องเล็กแค่ไหน impact จึงจะเล็กเท่าครึ่ง spread ซึ่งคือ $0.02/100.02=2$ bp

\[ \begin{aligned} I&=Y\sigma\sqrt{Q/V},\\ I&=1(0.02)\sqrt{0.01}\\ &=0.002=20\ \text{bp},\\ C_I&=0.002(40{,}000\times100.02)\\ &=0.002(4{,}000{,}800)=8{,}001.60,\\ C_s&=0.02(40{,}000)=800,\\ \sqrt{Q/V}&=\frac{0.0002}{1\times0.02}=0.01,\\ Q/V&=0.01^2=0.0001=0.01\%. \end{aligned} \]

impact 20 bp บนเงิน \$4,000,800 คือราว \$8,000 มากกว่าต้นทุนครึ่ง spread \$800 ถึง $8{,}001.60/800\approx10$ เท่า สองแถวล่างตั้ง $I$ ให้เท่ากับ 2 bp หรือ 0.0002 แล้วแก้หา $Q/V$ ได้แค่ 0.01% ของการซื้อขายทั้งวัน คำสั่งที่ใหญ่กว่านี้มี impact แพงกว่าครึ่ง spread แล้ว ดังนั้นคำสั่งเกือบทุกขนาดที่กองทุนส่ง จะมี impact เป็นต้นทุนก้อนหลัก

ทำไมต้องเป็นรากที่สอง ไม่ใช่เส้นตรง ลองขยายคำสั่งสี่เท่า สูตรบอกว่าต้นทุนต่อหุ้นโตแค่ $\sqrt4=2$ เท่า เหตุผลที่คนเชื่อกันคือ คำสั่งใหญ่มักถูกซอยเป็นชิ้นเล็กแล้วส่งนานขึ้น ตลาดจึงมีเวลาเติมของเข้ามาใหม่ แต่ต้นทุนเป็นเงินยังโต $4\times2=8$ เท่า เพราะจำนวนหุ้นก็โตสี่เท่าด้วย

ขั้นที่ 6 — ฟังก์ชันต้นทุน Kissel–Glantz

กฎรากที่สองมีรูปตายตัวแบบเดียว โต๊ะเทรดที่มีประวัติคำสั่งของตัวเองเยอะ ๆ มักอยากได้สูตรที่ยืดหยุ่นกว่า แล้วปรับให้เข้ากับข้อมูลของตัวเอง สูตรที่ใช้กันมากคือของ Kissel กับ Glantz มันคิดต้นทุนทีละหุ้น และไม่นับว่าการซื้อหุ้นตัวหนึ่งไปดันราคาหุ้นตัวอื่น

สูตรนี้บอกว่าต้นทุนเป็นสัดส่วนของเงินที่ซื้อขาย $|PQ|$ ($P$ คือราคา $Q$ คือจำนวนหุ้น) สัดส่วนนั้นมีสามก้อน

  • ก้อน impact $a_1(100|Q|/V)^{\beta}$ โตตามขนาดคำสั่งเป็นเปอร์เซ็นต์ของการซื้อขายทั้งวัน ยกกำลัง $\beta$ (กฎรากที่สองคือกรณี $\beta=0.5$)
  • ก้อน $a_2\sigma$ โตตามความผันผวน เพราะหุ้นที่แกว่งแรงมี spread กว้าง
  • ก้อนคงที่ $a_3$ เช่นค่าธรรมเนียม

ค่า $a_1, a_2, a_3, \beta$ ได้จาก regression คือเอาต้นทุนที่เกิดจริงของคำสั่งในอดีต หารด้วยเงินที่ซื้อขาย แล้วหาค่าที่ทำให้สูตรใกล้ข้อมูลที่สุด ($\epsilon$ คือส่วนที่สูตรอธิบายไม่ได้) สูตรนี้เป็นนิยามของแบบจำลองเช่นกัน ไม่ได้พิสูจน์มา

ในขั้นสุดท้ายของหน้า เราจะใช้สูตรนี้ตอนเลือกพอร์ต ซึ่งคิดเป็นน้ำหนัก ไม่ใช่จำนวนหุ้น จึงต้องเขียนใหม่ด้วยน้ำหนัก ให้ $\Delta w_i$ คือน้ำหนักของหุ้นตัวที่ $i$ ที่ย้าย นับเป็นจุด (ทั้งพอร์ตรวมเป็น 100 จุด) และให้ $V_i$ คือการซื้อขายต่อวันในหน่วยเดียวกัน ทั้งจำนวนที่ซื้อขาย $|Q|$ และเงินที่ซื้อขาย $|PQ|$ จึงกลายเป็น $|\Delta w_i|$ แล้วยุบ $|\Delta w_i|^{\beta}\times|\Delta w_i|=|\Delta w_i|^{1+\beta}$

\[ \begin{aligned} c(Q)&=\Big[a_1\Big(\frac{100|Q|}{V}\Big)^{\beta}\\ &\qquad+a_2\sigma+a_3\Big]|PQ|,\\ \frac{c(Q_t)}{|P_tQ_t|}&=a_1\Big(\frac{100|Q_t|}{V_t}\Big)^{\beta}\\ &\qquad+a_2\sigma_t+a_3+\epsilon,\\ C_i&=a_1\Big(\frac{100}{V_i}\Big)^{\beta}|\Delta w_i|^{1+\beta}\\ &\quad+(a_2\sigma_i+a_3)|\Delta w_i|. \end{aligned} \]

ก้อน impact เป็นตัวที่โตเร็ว เพราะยกกำลัง $1+\beta$ ซึ่งมากกว่า 1 ย้ายน้ำหนักสองเท่า ก้อนนี้โตเกินสองเท่า ส่วนก้อน $(a_2\sigma_i+a_3)|\Delta w_i|$ โตเป็นเส้นตรง

ลองคิดกับหุ้นสมมติที่จะใช้ในการเลือกพอร์ตด้านล่าง ค่าพารามิเตอร์ (สมมติ) คือ $a_1=0.0035$, $\beta=0.65$, $a_2=0.3$ และ $a_3=0.0015$ หุ้นตัวที่ 1 มีการซื้อขายต่อวัน $V_1=10$ และความผันผวน $\sigma_1=\sqrt{0.002647}=0.051449$ (รากที่สองของความแปรปรวนในตารางของโค้ดท้ายหน้า) เราย้ายน้ำหนักมัน $\Delta w_1=10$ จุด

\[ \begin{aligned} C_1&=0.0035\Big(\frac{100}{10}\Big)^{0.65}(10)^{1.65}\\ &\quad+(0.3(0.051449)+0.0015)(10)\\ &=0.0035(4.4668)(44.668)\\ &\quad+(0.016935)(10)\\ &=0.69834+0.16935=0.86769. \end{aligned} \]

หุ้นตัวที่ 1 ซื้อขายง่าย จึงเสียแค่ 0.86769 หน่วย (หน่วยเดียวกับเป้าหมายของพอร์ตด้านล่าง) ทีนี้ลองหุ้นตัวที่ 4 ที่ซื้อขายต่อวันแค่ $V_4=0.1$ ถ้าย้ายน้ำหนัก 17.25 จุด สูตรเดียวกันให้ 34.5466 แพงกว่ามาก ด้วยสองเหตุผล ข้อแรก $(100/0.1)^{0.65}=89.1$ ขณะที่ $(100/10)^{0.65}=4.47$ ตัวคูณจึงโตราว $89.1/4.47=20$ เท่า ข้อสอง $17.25^{1.65}=109.8$ ขณะที่ $10^{1.65}=44.7$ เพราะกำลัง 1.65 โตเร็วกว่าเส้นตรง

ขั้นที่ 7 — โจทย์เปิดหน้า: หนึ่งรอบของคำสั่ง \$200 ล้าน

ตอนนี้มีเครื่องมือครบแล้ว กลับไปที่ทีมวิจัยในโจทย์เปิดหน้า เขาจะซื้อหุ้น \$200 ล้านแล้วขายคืนใน 5 วัน ขั้นนี้คิดต้นทุนจริงของหนึ่งรอบด้วยกฎรากที่สอง

โจทย์ให้อะไรมาบ้าง:

  • คำสั่ง \$200 ล้าน ที่ราคา \$50 คือ $200{,}000{,}000/50=4{,}000{,}000$ หุ้น
  • การซื้อขายทั้งวัน $V=\$800$ ล้าน
  • ความผันผวนรายวัน $\sigma=1.8\%$
  • ตัวคูณ $Y=0.8$ เป็นค่าที่ต้องประมาณจากข้อมูล ที่นี่สมมติค่านี้
  • ครึ่ง spread $(50.075-50.00)/50.00=15$ bp และค่าธรรมเนียม 8 bp ต่อขา
  • กำไรก่อนต้นทุน 0.42% ต่อรอบ

ให้ $c_1$ คือต้นทุนขาเดียว $c_2$ คือต้นทุนไปกลับ $C$ คือต้นทุนต่อรอบเป็นดอลลาร์ และ $G$ คือกำไรก่อนต้นทุนต่อรอบเป็นดอลลาร์

\[ \begin{aligned} \frac QV&=\frac{200}{800}=0.25,\\ I&=0.8(1.8\%)\sqrt{0.25}=0.72\%,\\ m_1&=50.00(1.0072)=50.36,\\ c_1&=15+72+8=95\ \text{bp},\\ c_2&=2c_1=190\ \text{bp},\\ C&=0.019(200\ \text{M})=3{,}800{,}000,\\ G&=0.0042(200\ \text{M})=840{,}000,\\ G-C&=-2{,}960{,}000. \end{aligned} \]

คำตอบ: คำสั่งนี้ใหญ่ถึงหนึ่งในสี่ของการซื้อขายทั้งวัน impact จึงเป็น 72 bp มันดันราคากลางจาก \$50.00 ไป \$50.36 ซึ่งคือตัวเลขที่ใช้แยกต้นทุนในขั้นก่อน ขาเดียวเสีย 95 bp ไปกลับเสีย 190 bp ทำไมต้องคูณสอง เพราะตอนขายออก เราก็ต้องขายที่ bid เสียครึ่ง spread เสียค่าธรรมเนียม และการขายก้อนใหญ่ก็ดันราคาลง เหมือนตอนซื้อที่ดันขึ้น ราคาที่ขึ้นไปตอนซื้อจึงไม่ใช่กำไรที่เก็บได้จริง สรุปคือขาดทุนรอบละ \$2.96 ล้าน

ตรวจเองใน 10 วินาที: $0.8\times1.8\%\times0.5=0.72\%$ และ $2(0.15\%+0.72\%+0.08\%)=1.90\%$ ส่วนค่าธรรมเนียมไปกลับ $2\times8=16$ bp เป็นแค่ $16/190=8\%$ ของต้นทุนทั้งหมด

ขั้นที่ 8 — ทั้งปี: บนกระดาษ +21% ของจริง −74%

หนึ่งรอบขาดทุนแล้ว แต่ทีมสัญญาผลทั้งปี จึงต้องดูทั้งปีด้วย ขั้นนี้ต่อผลของหนึ่งรอบให้ครบ 50 รอบ โดยคิดแบบไม่ทบต้น คือลงเงิน \$200 ล้านเท่าเดิมทุกรอบ เหมือนที่ backtest คิด แล้วตรวจกลับอีกทางด้วยเงินที่ซื้อขายทั้งปี

ให้ $G_{\rm yr}$ คือกำไรก่อนต้นทุนทั้งปี $C_{\rm yr}$ คือต้นทุนทั้งปี ทั้งสองเป็นเปอร์เซ็นต์ของเงิน \$200 ล้าน ให้ $V_{\rm tr}$ คือเงินที่ซื้อขายทั้งปี และ $c$ คือต้นทุนทั้งปีหารด้วยเงินที่ซื้อขาย

\[ \begin{aligned} G_{\rm yr}&=50(0.42\%)=21.0\%,\\ C_{\rm yr}&=50(1.90\%)=95.0\%,\\ G_{\rm yr}-C_{\rm yr}&=-74.0\%,\\ V_{\rm tr}&=100(200\ \text{M})\\ &=20{,}000\ \text{M},\\ c&=\frac{190\ \text{M}}{20{,}000\ \text{M}}=0.95\%. \end{aligned} \]

ต้นทุนทั้งปีเท่ากับ 95% ของเงินที่ลง คือ $0.95\times200=\$190$ ล้าน ขณะที่กำไรก่อนต้นทุนได้แค่ 21% ขาดทุนสุทธิ $0.74\times200=\$148$ ล้าน

ตรวจกลับอีกทาง ไปกลับ 50 รอบคือซื้อขาย $2\times50=100$ ขา ขาละ \$200 ล้าน รวมเป็นเงินที่ซื้อขาย \$20,000 ล้าน เอาต้นทุน \$190 ล้านหารด้วยเงินก้อนนี้ ได้ 0.95% ซึ่งเท่ากับต้นทุนขาเดียว 95 bp พอดี สองทางให้คำตอบตรงกัน

จากตรงนี้ได้วิธีตรวจ backtest ในสามวินาที ถามว่าแต่ละปีซื้อขายเป็นเงินกี่เท่าของพอร์ต คูณด้วยต้นทุนขาเดียว แล้วเทียบกับผลตอบแทนที่อ้าง ที่นี่คือ $100\times0.95\%=95\%$ เทียบกับ 21% ที่อ้าง ซึ่งไม่มีทางรอด

ขั้นที่ 9 — ทางแก้ และพื้นที่ที่แก้ไม่ได้

ทีมยังไม่อยากทิ้งกลยุทธ์ ขั้นนี้ลองแก้ทีละทาง แล้วดูว่าทางไหนช่วยได้จริง

  • ทางที่หนึ่ง ลดขนาดคำสั่งเหลือ \$40 ล้าน ซึ่งเป็น $40/800=5\%$ ของการซื้อขายทั้งวัน ให้ $I_{40}$ คือ impact และ $c_{40}$ คือต้นทุนไปกลับของคำสั่งขนาดนี้
  • ทางที่สอง ใช้ขนาดเดิม แต่ถือนานขึ้นเป็นรอบละ 25 วัน ปีหนึ่งจึงได้ $250/25=10$ รอบ สมมติว่ากำไรสะสมตามวันที่ถือ กำไรต่อรอบ $g_{25}$ จึงโต $25/5=5$ เท่า ให้ $R_{25}$ คือผลทั้งปี
  • ทางที่สาม ถามว่าถ้าคำสั่งเล็กจนไม่มี impact เลย ต้นทุนไปกลับจะเหลือ $c_{\min}$ เท่าไร
  • สุดท้าย หาว่าต้องถือนานกี่วัน $H^*$ กำไรจึงพอจ่ายต้นทุนไปกลับ 1.90% ของขนาดเดิม

ตัวคูณ $0.8\times1.8\%=1.44\%$ มาจากกฎรากที่สองของหุ้นตัวนี้

\[ \begin{aligned} I_{40}&=1.44\%\sqrt{0.05}\\ &=32.2\ \text{bp},\\ c_{40}&=2(15+32.2+8)\\ &=110.4\ \text{bp},\\ g_{25}&=5(0.42\%)=2.10\%,\\ R_{25}&=10(2.10\%-1.90\%)\\ &=2.0\%,\\ c_{\min}&=2(15+8)=46\ \text{bp},\\ H^*&=\frac{1.90\%}{0.42\%/5}=\frac{1.90\%}{0.084\%}\\ &=22.6. \end{aligned} \]

ลดขนาดช่วยได้บ้าง ต้นทุนไปกลับลดจาก 190 เหลือ 110.4 bp แต่ยังเกินกำไร 42 bp ต่อรอบ ผลทั้งปียังติดลบ $50(0.42\%-1.104\%)=-34.2\%$ ดีขึ้นจาก −74% ราวครึ่งหนึ่ง แต่ยังขาดทุน

ถือ 25 วันได้ผลทั้งปี +2% รอดแต่บางมาก เพราะต้นทุนกินกำไรไป $1.90/2.10=90\%$

$c_{\min}$ คือพื้นที่แก้ไม่ได้ ต่อให้ไม่มี impact เลย ครึ่ง spread กับค่าธรรมเนียมไปกลับก็ 46 bp แล้ว มากกว่ากำไร 42 bp ต่อรอบ กลยุทธ์ที่ถือ 5 วันนี้จึงแพ้ตั้งแต่ก่อนเริ่ม ไม่ว่าจะลดขนาดแค่ไหน ส่วน $H^*$ บอกว่าที่ขนาดเดิม ต้องถืออย่างน้อย 22.6 วันจึงเสมอตัว เพราะกำไรได้วันละ $0.42\%/5=0.084\%$

ทางอื่นที่ใช้กันจริงก็มีราคาของมัน ทางแรกคือทยอยส่งคำสั่งตลอดวันตามเป้า VWAP หรือ TWAP วิธีนี้ลด impact ได้ แต่ระหว่างรอ ราคาอาจวิ่งหนีไป หน้าAlmgren–Chriss หาจุดสมดุลของสองเรื่องนี้

ทางที่สองคือใช้ limit order วางราคารอแทนการซื้อทันที วิธีนี้ประหยัดครึ่ง spread ได้ จะวางหรือไม่ และวางที่ราคาไหน ขึ้นกับสามอย่าง คือเรารอได้ไหม หุ้นผันผวนแค่ไหน (ผันผวนมาก รอแล้วราคาอาจวิ่งหนี) และตลาดให้ส่วนลดกับคนวางของรอเท่าไร (maker rebate) ข้อเสียคือ คำสั่งที่ได้จับคู่มักเป็นตอนที่ราคากำลังวิ่งสวนทางเรา

ทางที่สามคือ dark pool ซึ่งในหุ้นบางตัว บางช่วงมีสัดส่วนราว 11–12% ของการซื้อขาย มันลด impact ได้เพราะไม่แสดงขนาดคำสั่ง แต่ไม่รู้ว่าจะได้ของเท่าไร และมีกับดักที่เรียกว่า winner's curse คือถ้าได้ก้อนใหญ่มาง่าย ๆ อาจเป็นเพราะอีกฝั่งรู้อะไรบางอย่างที่เราไม่รู้

ขั้นที่ 10 — ใส่ต้นทุนเข้าไปในการเลือกพอร์ตตั้งแต่ต้น

จนถึงตอนนี้ เราเลือกว่าจะซื้ออะไรก่อน แล้วค่อยมาเจอต้นทุนทีหลัง ผู้จัดการพอร์ตมีสองทาง ทางแรกคือเลือกพอร์ตก่อน แล้วส่งคำสั่งให้ประหยัดที่สุด ทางที่สองคือคิดต้นทุนเข้าไปตั้งแต่ตอนเลือกพอร์ต ในทางปฏิบัติควรทำทั้งสองอย่าง ขั้นนี้ลองทางที่สองกับหุ้นสมมติ 10 ตัว

  • ตอนนี้ถือหุ้นตัวละ $y_i=10$ จุด รวม 100 จุด
  • เราหาน้ำหนักใหม่ $x_i\ge0$ (ห้ามชอร์ต) ที่รวมกันได้ 100 จุดเหมือนเดิม
  • $\mu$ คือผลตอบแทนคาดของหุ้นแต่ละตัว เป็นเปอร์เซ็นต์ และ $\Sigma$ คือ covariance matrix ของหุ้นทั้ง 10 ตัว ตัวเลขอยู่ในโค้ดท้ายหน้า
  • $\lambda=10$ คือโทษต่อความแปรปรวนหนึ่งหน่วย คูณกับความแปรปรวนเต็มตัว ไม่มีการหารด้วย 2
  • $C(x,y)$ คือต้นทุน Kissel–Glantz รวมทุกตัว โดยย้ายน้ำหนัก $\Delta w_i=x_i-y_i$ และ $\eta=0.1$ คือน้ำหนักของต้นทุนในเป้าหมาย

เป้าหมาย $U$ คือเป้าหมายแบบMarkowitz (ผลตอบแทนคาด ลบโทษความเสี่ยง) แล้วลบต้นทุนการย้ายน้ำหนักเพิ่มเข้าไป เราอยากได้ $x$ ที่ทำให้ $U$ สูงสุด ลองเทียบสองคำตอบ คำตอบแรก $U_{\rm solver}$ มาจาก Solver ของ Excel คำตอบที่สอง $U_{\rm resolve}$ มาจากการแก้ใหม่ด้วยโค้ดท้ายหน้า

\[ \begin{aligned} U&=\mu^\top x-\lambda\,x^\top\Sigma x-\eta\,C(x,y),\\ U_{\rm solver}&=645.2575-10(3.64213)\\ &\quad-0.1(67.4336)\\ &=645.2575-36.4213-6.7434\\ &=602.0928,\\ U_{\rm resolve}&=649.5479-10(3.85849)\\ &\quad-0.1(78.3045)\\ &=649.5479-38.5849-7.8305\\ &=603.1325. \end{aligned} \]

ในแต่ละแถว ตัวเลขสามตัวคือผลตอบแทนคาด $\mu^\top x$ ความแปรปรวน $x^\top\Sigma x$ และต้นทุนรวม $C$ ของพอร์ตนั้น Solver ของ Excel หาคำตอบโดยเดินตามความชันของ $U$ คำตอบที่ได้ขายหุ้นตัวที่ 2, 8 และ 10 ทิ้งหมด และซื้อตัวที่ 4 ซึ่งมีผลตอบแทนคาดสูงสุด 7.17% เพิ่มเป็น 27.25 จุด หุ้นตัวนี้ซื้อขายยาก การย้ายมัน $27.25-10=17.25$ จุด ตัวเดียวก็เสียต้นทุน 34.55 แล้ว (ค่าที่คิดไว้ในขั้นของ Kissel–Glantz) คิดเป็น $34.55/67.43=51\%$ ของต้นทุนรวม ส่วนตัวที่ 1 และ 5 ค้างอยู่ที่ 10 จุดพอดี

เมื่อแก้โจทย์เดียวกันใหม่ด้วยการย้ายน้ำหนักทีละคู่ (โค้ดท้ายหน้า) ได้ $U=603.1325$ ซึ่งสูงกว่า ที่น้ำหนัก 11.21, 0, 14.37, 28.71, 6.45, 17.49, 18.66, 0, 3.10, 0 จุด แล้วทำไม Solver ติดอยู่ที่ 10 จุดของตัวที่ 1 และ 5 เพราะต้นทุนมีพจน์ $|x_i-y_i|$ กราฟของมันหักมุมที่ $x_i=10$ ความชันซ้ายกับขวาของมุมไม่เท่ากัน วิธีที่เดินตามความชันจึงเห็นว่าขยับไปทางไหนก็เสียต้นทุนทันที เลยหยุดอยู่ตรงนั้น ต้นทุนที่มีมุมแบบนี้ต้องใช้ตัวแก้ที่รับมือกับมุมได้

อีกทางหนึ่งของ Lo, Petrov และ Wierzbicki ไม่ใส่ต้นทุนในเป้าหมาย แต่ให้คะแนนสภาพคล่องของหุ้นแต่ละตัว $l_i$ อยู่ระหว่าง 0 ถึง 1 แล้วบังคับให้ค่าเฉลี่ยถ่วงน้ำหนัก $\sum_i l_i|x_i|/\sum_j|x_j|$ ไม่ต่ำกว่าเกณฑ์ ที่ใช้ค่าสัมบูรณ์ก็เพื่อไม่ให้การชอร์ตหุ้นสภาพคล่องต่ำตัวหนึ่งไปหักล้างกับการถือหุ้นสภาพคล่องต่ำอีกตัว

นับแค่ค่าธรรมเนียม: ทีมในโจทย์เปิดหน้านับต้นทุนไปกลับแค่ $2\times8=16$ bp จึงคิดว่าได้ $50(0.42\%-0.16\%)=+13\%$ ต่อปี แต่ต้นทุนจริงคือ $2(15+72+8)=190$ bp ผลจริงคือ $50(0.42\%-1.90\%)=-74\%$

เชื่อว่าของที่แสดงคือของที่ได้: order book ด้านบนแสดงของขายรวม $10{,}000+16{,}000+22{,}000=48{,}000$ หุ้น คำสั่ง 50,000 หุ้นจึงไม่มีทางได้ครบที่ราคาที่เห็น และในตลาดจริง ของที่แสดงอาจหายไปก่อนเราซื้อถึงด้วยซ้ำ

ใช้ต้นทุนของวันปกติในวันที่ตลาดตึงเครียด: วันที่ตลาดตื่นตระหนกมักเป็นวันที่ต้องขายที่สุด แต่ต้นทุนก็แพงที่สุดด้วย สมมติวันนั้น spread กว้างขึ้น 5 เท่า และการซื้อขายทั้งวันเหลือหนึ่งในห้า ครึ่ง spread จึงเป็น $5\times15=75$ bp ส่วนคำสั่ง \$200 ล้านเท่าเดิมกลายเป็นสัดส่วนที่ใหญ่ขึ้น $Q/V$ โตจาก 0.25 เป็น $5\times0.25=1.25$ impact ซึ่งโตตามรากที่สองของ $Q/V$ จึงโต $\sqrt5=2.24$ เท่า

\[ \begin{aligned} I&=72\sqrt5=161\ \text{bp},\\ c_{\rm leg}&=75+161+8=244\ \text{bp},\\ \frac{244}{95}&=2.6. \end{aligned} \]

ถ้าใช้ตัวเลขวันปกติ จะคิดว่าเสียขาละ 95 bp แต่ของจริงเสีย 244 bp แพงกว่า 2.6 เท่า

นับ impact ขาเดียว: ราคาที่ดันขึ้นตอนซื้อดูเหมือนกำไรบนจอ แต่ตอนขายก้อนเดียวกัน ราคาจะถูกดันลงเท่ากัน ถ้านับ impact แค่ขาซื้อ จะได้ต้นทุนไปกลับ $2(15+8)+72=118$ bp ซึ่งผิด ต้องนับทั้งสองขา $2(15+72+8)=190$ bp

เชื่อคำตอบของตัวแก้โจทย์โดยไม่ตรวจ: Solver ที่เดินตามความชันหยุดที่ $U=602.09$ แต่คำตอบที่ดีกว่าได้ 603.13 ต่างกัน $603.1325-602.0928=1.04$ หน่วยของเป้าหมาย สาเหตุคือต้นทุนมีมุมหักที่น้ำหนักเดิม

อ่าน Roll spread เมื่อ covariance เป็นบวก: สูตร $s=\sqrt{-\gamma_1}$ ใช้ได้เมื่อ $\gamma_1$ ติดลบเท่านั้น ถ้าราคาวิ่งเป็นแนวโน้มแรงกว่าการเด้งระหว่าง bid กับ ask การขยับติดกันจะไปทางเดียวกัน $\gamma_1$ จึงเป็นบวก เช่น $\gamma_1=+0.0004$ ทำให้ $\sqrt{-0.0004}$ ไม่มีคำตอบ อย่ากลับเครื่องหมายเองเพื่อให้ได้ spread \$0.04 ออกมา ข้อมูลชุดนั้นใช้สูตรนี้ไม่ได้

ใช้ทำอะไรบนโต๊ะจริง

ก่อนรับกลยุทธ์ใหม่ ทีมความเสี่ยงทำการตรวจสามวินาทีแบบในขั้นทั้งปีด้านบน คือเอาเงินที่ซื้อขายต่อปีคูณด้วยต้นทุนขาเดียวตามขนาดคำสั่งจริง แล้วเทียบกับผลตอบแทนที่ทีมอ้าง

ระหว่างส่งคำสั่ง โต๊ะเทรดวัด effective, impact และ realized แยกตามโบรกเกอร์และช่องทาง เพื่อดูว่าเงินรั่วไปที่ไหน หลังจบวัน โต๊ะเทียบราคาที่ได้กับ VWAP หรือกับราคาตอนตัดสินใจซื้อ (ดูหน้าตลาด โบรกเกอร์ และการซื้อขายจริง) ส่วนผู้จัดการพอร์ตคิดต้นทุนเข้าไปตั้งแต่ตอนเลือกพอร์ต เพื่อไม่ให้เงินไหลไปหาหุ้นที่ดูดีบนกระดาษแต่ซื้อจริงไม่ได้

ข้อจำกัดที่ต้องรู้: สูตรต้นทุนทั้งหมดในหน้านี้คิดทีละหุ้น แต่ของจริงมีหลักฐานว่าคำสั่งในหุ้นตัวหนึ่งดันราคาหุ้นที่เกี่ยวข้องด้วย เพราะคนตั้งราคาพยายามเดามูลค่าของหุ้นตัวหนึ่งจากคำสั่งในหุ้นที่คล้ายกัน ผลข้ามหุ้นนี้มักเป็นลบ มันเล็กลงเมื่อตลาดมีผู้เล่นมาก และใหญ่ขึ้นเมื่อความเห็นในตลาดต่างกันมาก ต้นทุนของการย้ายทั้งพอร์ตจึงไม่เท่ากับผลรวมของต้นทุนทีละตัว และเรื่องนี้ยังเข้าใจกันไม่ครบ

โจทย์ตรวจความเข้าใจ

1. คุณต้องซื้อหุ้นตัวในรูป order book ด้านบน (ask \$100.04 มี 10,000 หุ้น, \$100.06 มี 16,000 หุ้น, ราคากลาง \$100.02) จำนวน 20,000 หุ้น และต้องได้ทันที จึงใช้ market order ราคาเฉลี่ยที่จ่ายเป็นเท่าไร และจ่ายเกินราคากลางรวมกี่ดอลลาร์

เฉลย

ขั้นแรกให้ 10,000 หุ้นที่ \$100.04 ที่เหลือ $20{,}000-10{,}000=10{,}000$ หุ้นมาจากขั้น \$100.06

\[\begin{aligned}\bar P&=\frac{10{,}000(100.04)+10{,}000(100.06)}{20{,}000}\\&=100.05,\\C&=(100.05-100.02)(20{,}000)=600.\end{aligned}\]

จ่ายเกินราคากลาง \$600 ครึ่ง spread อธิบายได้ $0.02\times20{,}000=\$400$ อีก $600-400=\$200$ มาจากการไต่ไปซื้อขั้นที่สอง

2. คุณมีแค่ข้อมูลราคาที่ซื้อขายกันจริงของหุ้นตัวหนึ่ง ไม่มี bid และ ask เมื่อวัด covariance ของการขยับราคาสองครั้งติดกัน ได้ $\gamma_1=-0.0009$ ดอลลาร์ยกกำลังสอง spread ตามแบบจำลองของ Roll คือเท่าไร

เฉลย

ครึ่ง spread $s=\sqrt{-\gamma_1}=\sqrt{0.0009}=0.03$ ดังนั้น spread $=2s=2\times0.03=\$0.06$ หรือ 6 เซนต์ ถ้า covariance ออกมาเป็นบวก สูตรนี้ใช้ไม่ได้ เพราะถอดรากของค่าลบไม่ได้ ซึ่งเกิดบ่อยเมื่อราคาวิ่งเป็นแนวโน้มแรงกว่าการเด้ง

3. ทีมในโจทย์เปิดหน้าเสนอให้ลดคำสั่งจาก \$200 ล้านเหลือ \$100 ล้านต่อรอบ ตัวเลขอื่นเหมือนเดิม: การซื้อขายทั้งวัน \$800 ล้าน ความผันผวนรายวัน 1.8% ตัวคูณ $Y=0.8$ ครึ่ง spread 15 bp ค่าธรรมเนียม 8 bp ต่อขา และกำไรก่อนต้นทุน 42 bp ต่อรอบ ต้นทุนไปกลับเป็นเท่าไร และกลยุทธ์รอดไหม

เฉลย
\[\begin{aligned}\frac QV&=\frac{100}{800}=0.125,\\I&=0.8(1.8\%)\sqrt{0.125}\\&=0.509\%=50.9\ \text{bp},\\c_2&=2(15+50.9+8)=147.8\ \text{bp},\\R&=50(0.42\%-1.478\%)\\&=-52.9\%.\end{aligned}\]

// Buy q shares against displayed ask levels [[price, size], ...] sorted from the best ask upward.
function walkBook(asks, q) {
  let left = q, paid = 0;
  for (const [price, size] of asks) {
    const take = Math.min(left, size);
    paid += take * price; left -= take;
    if (left === 0) return {paid, average: paid / q};
  }
  throw new RangeError(`only ${q - left} shares are displayed`);
}

// Roll: trades bounce between bid and ask, so Cov(dP_t, dP_t-1) = -s^2 and the spread is 2s.
function rollSpread(prices) {
  const d = prices.slice(1).map((p, i) => p - prices[i]);
  const m = d.reduce((a, b) => a + b, 0) / d.length;
  let c = 0;
  for (let i = 1; i < d.length; i++) c += (d[i] - m) * (d[i - 1] - m);
  c /= d.length - 1;
  if (c >= 0) throw new RangeError('autocovariance is not negative, Roll spread undefined');
  return {cov: c, spread: 2 * sqrt(-c)};
}

function resolve(x, eta = 0.1) {
  x = x.slice();
  const g = (sqrt(5) - 1) / 2;
  for (let sweep = 0; sweep < 400; sweep++) {

สิ่งที่ควรตอบได้หลังอ่าน

  • คำสั่งใหญ่ต้องไต่บันไดของ order book ขึ้นไปซื้อขั้นที่แพงกว่า คำสั่ง 40,000 หุ้นในตัวอย่างจ่ายเกินราคากลาง \$1,680 ไม่ใช่แค่ \$800 ของครึ่ง spread
  • ต้นทุนของการซื้อหนึ่งครั้งแยกได้เป็น effective = realized + impact ในตัวอย่างคือ $15=-57+72$ bp ถ้า realized ติดลบ แปลว่าคนที่ขายให้เราขาดทุน ซึ่งเป็นร่องรอยของ adverse selection
  • Roll อ่าน spread จากราคาที่ซื้อขายจริงได้ เพราะราคาเด้งระหว่าง bid กับ ask ทำให้ covariance ของการขยับติดกันเท่ากับ $-s^2$ จึงได้ spread $2s=2\sqrt{-\gamma_1}$
  • กฎรากที่สอง $I=Y\sigma\sqrt{Q/V}$ เป็นแบบจำลองที่ต้องประมาณ $Y$ จากข้อมูล ใช้กับโจทย์เปิดหน้าแล้ว คำสั่ง \$200 ล้านเสียไปกลับ 190 bp และ backtest ที่บอก +21% กลายเป็น −74% ต่อปี
  • ต่อให้ไม่มี impact ครึ่ง spread กับค่าธรรมเนียมไปกลับก็ 46 bp เกินกำไร 42 bp ต่อรอบแล้ว ส่วนการคิดต้นทุนตั้งแต่ตอนเลือกพอร์ตทำให้หุ้นที่ซื้อขายยากขยับน้อยลง และคำตอบของตัวแก้โจทย์ต้องตรวจเสมอ เพราะ Solver หยุดที่ 602.09 ขณะที่ทำได้ถึง 603.13
