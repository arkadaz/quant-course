18.5 Market Microstructure

ราคากลางบนจอไม่ใช่ราคาที่ซื้อขายได้ คำสั่งจริงเสียครึ่ง spread ค่าธรรมเนียม และ impact ที่ตัวเองดันราคา ซึ่งมักใหญ่ที่สุดและโตตามขนาดคำสั่ง

backtest ของกลยุทธ์หนึ่งบอกว่าได้ 0.42% ต่อรอบ ถือรอบละ 5 วัน ปีละ 50 รอบ รวม +21% ต่อปี พอร์ต \$200 ล้านซื้อหุ้นราคา \$50 ที่ซื้อขายกันวันละ \$800 ล้าน ความผันผวนรายวัน 1.8% bid \$49.925 ask \$50.075 ค่าธรรมเนียมขาละ 0.08% ทีมบอกว่า “ต้นทุนมีแค่ค่าธรรมเนียม ไปกลับ 0.16% ยังเหลือ 0.26% ต่อรอบ” ผลตอบแทนจริงต่อปีคือเท่าไร

ลองตอบก่อนเปิดเฉลย

ติดลบราว 74% ต่อปี ขาเดียวเสียครึ่ง spread 15 bp ค่าธรรมเนียม 8 bp และ impact ที่คำสั่งขนาดหนึ่งในสี่ของปริมาณทั้งวันดันราคาเองอีก 72 bp รวม 95 bp ไปกลับ 190 bp หรือ \$3.8 ล้านต่อรอบ เทียบกำไรก่อนต้นทุน \$840,000 ขาดทุนรอบละ \$2.96 ล้าน ทั้งปี 50 รอบคือ $50(0.42\%-1.90\%)=-74\%$ ค่าธรรมเนียมที่ทีมนับเป็นก้อนที่เล็กที่สุด

ภาพรวมก่อนลงสูตร

ทุกหัวข้อก่อนหน้าสมมติว่าซื้อขายได้ที่ราคาเดียวไม่จำกัดจำนวน กำไรขาดทุนของการ delta hedge แตะต้นทุนด้วยค่าธรรมเนียม 10 bp เท่านั้น หน้านี้เปิดดูว่าคำสั่งจริงเดินผ่าน order book อย่างไร และต้นทุนแยกเป็นกี่ก้อน

order book คือบันไดของคำสั่งที่รอจับคู่ ฝั่งขายเรียงจากราคาต่ำขึ้นไป ฝั่งซื้อเรียงจากราคาสูงลงมา ช่องว่างระหว่างสองฝั่งคือ spread คำสั่งซื้อที่ต้องการของทันทีต้องข้าม spread แล้วกินบันไดขึ้นไปทีละขั้น ยิ่งสั่งมากยิ่งกินลึก ราคาเฉลี่ยยิ่งแพง และหลังคำสั่งจบ ราคากลางเองก็ขยับตามไปด้วย ต้นทุนจึงมีสามก้อน ครึ่ง spread ค่าธรรมเนียม และ impact ซึ่งเป็นก้อนที่โตตามขนาดคำสั่ง

หน้านี้จะกิน order book ด้วยมือ วัดสภาพคล่อง แยกต้นทุนหนึ่งคำสั่ง อ่าน spread จากราคาซื้อขายอย่างเดียวด้วยแบบจำลองของ Roll ประมาณ impact ด้วยกฎรากที่สองและฟังก์ชัน Kissel–Glantz แล้วตอบโจทย์เปิดหน้า หาทางแก้ และจบที่การใส่ต้นทุนเข้าไปในการเลือกพอร์ตตั้งแต่ต้น

ศัพท์ที่ใช้ในหัวข้อนี้
Order book, bid และ ask
รายการคำสั่งที่รอจับคู่ เรียงตามราคา และในราคาเดียวกันเรียงตามเวลาที่มาก่อน (price-time priority) bid คือราคาสูงสุดที่มีคนรอซื้อ ask คือราคาต่ำสุดที่มีคนรอขาย แต่ละราคามีจำนวนหุ้นจำกัด
Spread และ midpoint
spread คือ ask ลบ bid midpoint คือค่ากลางของสองราคา ใช้เป็นเกณฑ์วัดต้นทุน แต่ไม่มีใครซื้อขายที่ midpoint ได้จริง
Market order และ limit order
market order ยอมข้าม spread เพื่อได้ของทันที limit order วางราคาไว้ในบันไดแล้วรอ ได้ราคาดีกว่าแต่ไม่รู้ว่าจะได้ของเมื่อไร หรือได้เลยไหม
Price impact
ราคาที่ขยับเพราะคำสั่งของเราเอง คำสั่งยิ่งใหญ่เทียบปริมาณทั้งวันยิ่งดันแรง และเป็นต้นทุนก้อนใหญ่ที่สุดของคำสั่งใหญ่
Effective, realized half-spread และ adverse selection
effective คือราคาที่ได้ห่างจาก midpoint ตอนส่งคำสั่ง realized คือห่างจาก midpoint หลังคำสั่งจบ ถ้า realized ติดลบ คนที่ขายให้เราขาดทุน เพราะคำสั่งเรามีข้อมูล ซึ่งเรียกว่า adverse selection
VWAP และ TWAP
ราคาเฉลี่ยของวันถ่วงด้วยปริมาณ และราคาเฉลี่ยถ่วงเวลาเท่ากัน ใช้เป็นเป้าของการทยอยส่งคำสั่ง และเป็นเกณฑ์เทียบว่าซื้อได้แพงหรือถูก
Dark pool
ตลาดที่ไม่แสดงขนาดคำสั่งและตัวตนผู้ส่งจนกว่าจะจับคู่ได้ ใช้ซื้อขายก้อนใหญ่โดยไม่ดันราคาบนจอ แต่ไม่รู้ว่าจะได้ของเท่าไร
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$b,\ a,\ m$bid, ask และ midpoint $m=(a+b)/2$ดอลลาร์ต่อหุ้น
$Q,\ V$ขนาดคำสั่ง และปริมาณซื้อขายทั้งวันหุ้น หรือดอลลาร์
$\bar P$ราคาเฉลี่ยที่ได้จริงดอลลาร์ต่อหุ้น
$\sigma$ความผันผวนรายวันต่อวัน
$I,\ Y$impact เป็นสัดส่วนของราคา และตัวคูณที่ต้องประมาณจากข้อมูลสัดส่วน, ไม่มีหน่วย
$s,\ q_t$ครึ่ง spread และเครื่องหมายคำสั่ง (+1 ซื้อ, −1 ขาย)ดอลลาร์, ไม่มีหน่วย

ขั้นที่ 1 — กิน order book ด้วยมือ

order book ในรูปด้านบนมีหุ้นวางขายสามขั้น 10,000 หุ้นที่ \$100.04, 16,000 หุ้นที่ \$100.06 และ 22,000 หุ้นที่ \$100.08 ฝั่งซื้อสูงสุดคือ \$100.00 ซื้อ 40,000 หุ้นด้วย market order ต้องกินขึ้นไปทีละขั้นจนครบ ในแต่ละขั้น คำสั่งที่มาวางก่อนได้จับคู่ก่อน

\[ \begin{aligned} m&=\frac{100.00+100.04}{2}=100.02,\\ \text{paid}&=10{,}000(100.04)\\ &\quad+16{,}000(100.06)\\ &\quad+14{,}000(100.08)\\ &=4{,}002{,}480,\\ \bar P&=\frac{4{,}002{,}480}{40{,}000}=100.062,\\ C&=(\bar P-m)Q\\ &=0.042(40{,}000)=1{,}680. \end{aligned} \]

ป้ายบอก \$100.04 แต่มีของแค่ 10,000 หุ้นที่ราคานั้น ราคาเฉลี่ยจริงคือ \$100.062 $C$ คือเงินที่จ่ายเกิน midpoint คือ \$1,680 ครึ่ง spread (2 เซนต์ต่อหุ้น) อธิบายได้ \$800 อีก \$880 มาจากการกินลึกลงไปในขั้นที่แพงกว่า ถ้าซื้อแค่ 20,000 หุ้นจะเฉลี่ย \$100.05 ต้นทุนต่อหุ้นโตตามขนาดคำสั่ง

ถ้าสั่ง 50,000 หุ้น ของที่แสดงทั้งสามขั้นมีแค่ 48,000 อีก 2,000 หุ้นต้องรอคนมาวางขายใหม่ ซึ่งมักมาที่ราคาสูงขึ้น ส่วนคนที่วาง limit order ต้องรอคิวในขั้นราคาของตัวเอง ใครมาก่อนได้ก่อน เรื่องคิวนี้มีรายละเอียดต่อในorder book, คิว และ maker-taker

ขั้นที่ 2 — วัดสภาพคล่องสองแบบ: นับปริมาณ หรือคิดเป็นต้นทุน

หุ้นที่มีสภาพคล่องคือหุ้นที่มีสามอย่าง ซื้อขายได้เร็ว ราคาขยับน้อยตอนเราซื้อขาย และซื้อขายก้อนใหญ่ได้เพราะบันไดลึก วัดได้สองแบบ แบบนับปริมาณ เช่น turnover คือปริมาณต่อวันหารด้วยจำนวนหุ้นทั้งหมด และแบบคิดเป็นต้นทุน เช่น spread เป็นเปอร์เซ็นต์ของราคา สมมติหุ้นตัวนี้ซื้อขายวันละ 2 ล้านหุ้น จากทั้งหมด 500 ล้านหุ้น

\[ \begin{aligned} \text{turnover}&=\frac{2{,}000{,}000}{500{,}000{,}000}\\ &=0.4\%,\\ \frac{a-b}{m}&=\frac{0.04}{100.02}=4\ \text{bp},\\ \frac{\bar P-m}{m}&=\frac{0.042}{100.02}=4.2\ \text{bp}. \end{aligned} \]

turnover บอกว่าหาคู่ค้าง่ายแค่ไหน แต่ไม่บอกว่าคำสั่งของเราจะเสียเท่าไร แบบคิดเป็นต้นทุนตอบตรงกว่า spread 4 bp แปลว่าคำสั่งเล็กที่สุดเสียครึ่งหนึ่งคือ 2 bp แต่คำสั่ง 40,000 หุ้น (2% ของปริมาณทั้งวัน) เสีย 4.2 bp มากกว่าสองเท่า

เครื่องมือแบบต้นทุนที่ใช้กันมีอีกสามตัว VWAP เป็นเกณฑ์เทียบราคาที่ได้ ตารางต้นทุนตามขนาดคำสั่งของ Loeb และฟังก์ชันต้นทุนของ Kissel กับ Glantz ที่จะใช้ด้านล่าง

ขั้นที่ 3 — แยกต้นทุนหนึ่งคำสั่ง: effective, impact และ realized

โจทย์ให้อะไรมาบ้าง: หุ้นของโจทย์เปิดหน้า midpoint ก่อนส่งคำสั่ง \$50.00 ซื้อได้ที่ \$50.075 (ask) หลังคำสั่งจบ midpoint ขึ้นไปอยู่ที่ \$50.36 ทุกตัววัดเทียบ midpoint ก่อนส่งคำสั่ง

\[ \begin{aligned} h_{\rm eff}&=\frac{50.075-50.00}{50.00}=15\ \text{bp},\\ I&=\frac{50.36-50.00}{50.00}=72\ \text{bp},\\ h_{\rm real}&=\frac{50.075-50.36}{50.00}\\ &=-57\ \text{bp},\\ h_{\rm eff}&=h_{\rm real}+I. \end{aligned} \]

คำตอบ: เราจ่ายเกิน midpoint 15 bp ตอนซื้อ คำสั่งเราดัน midpoint ขึ้น 72 bp และคนที่ขายให้เราที่ 50.075 ขาดทุน 57 bp เมื่อเทียบกับ midpoint ใหม่ realized ที่ติดลบคือหลักฐานของ adverse selection คนตั้งราคาขายของให้คำสั่งที่รู้ทางมากกว่า

ตรวจเองใน 10 วินาที: $-57+72=15$ ตรงกับแถวสุดท้าย เพราะแยก $50.075-50.00$ เป็น $(50.075-50.36)+(50.36-50.00)$

ขั้นที่ 4 — อ่าน spread จากราคาซื้อขายอย่างเดียว: แบบจำลองของ Roll

ถ้ามีแค่ราคาที่ซื้อขายจริง ไม่มี order book จะรู้ spread ได้ไหม Roll สมมติว่าราคาซื้อขาย $P_t$ คือ midpoint $m_t$ ที่เดินสุ่ม บวกหรือลบครึ่ง spread $s$ ตามว่าคำสั่งนั้นเป็นซื้อ ($q_t=+1$) หรือขาย ($-1$) โดย $q_t$ สุ่มอิสระ ค่าเฉลี่ยศูนย์ และ $q_t^2=1$ แล้วหา covariance ของการขยับสองครั้งติดกัน

\[ \begin{aligned} P_t&=m_t+s\,q_t,\quad m_t=m_{t-1}+u_t,\\ \Delta P_t&=u_t+s(q_t-q_{t-1}),\\ \gamma_1&=\mathrm{Cov}(\Delta P_t,\Delta P_{t-1})\\ &=s^2\,\mathbb E\big[(q_t-q_{t-1})\\ &\qquad\times(q_{t-1}-q_{t-2})\big]\\ &=-s^2\,\mathbb E[q_{t-1}^2]=-s^2,\\ 2s&=2\sqrt{-\gamma_1}. \end{aligned} \]

กางวงเล็บได้สี่พจน์ สามพจน์เป็นผลคูณของ $q$ คนละเวลาซึ่งค่าเฉลี่ยเป็นศูนย์ เหลือ $-q_{t-1}^2$ ส่วน $u_t$ ไม่เกี่ยวกับ $q$ และไม่สัมพันธ์กันข้ามเวลาจึงหายไป ความหมายคือ ซื้อที่ ask แล้วมักตามด้วยขายที่ bid ราคาจึงเด้งกลับ การขยับติดกันจึงสัมพันธ์เป็นลบ

ถ้าวัดได้ $\gamma_1=-0.0004$ จะได้ $s=0.02$ และ spread 4 เซนต์ ตรงกับ order book ด้านบน โค้ดท้ายหน้าจำลองการซื้อขาย 20,000 ครั้งที่ครึ่ง spread 0.02 แล้วอ่านกลับได้ spread 0.0403 การใช้แบบจำลองนี้กับข้อมูลความถี่สูงจริงอยู่ในหน้าRoll model

ขั้นที่ 5 — กฎรากที่สองของ impact: แบบจำลองที่ต้องประมาณ ไม่ใช่กฎธรรมชาติ

order book จริงเปลี่ยนตลอด จึงต้องมีสูตรหยาบไว้ประมาณ impact ก่อนส่งคำสั่ง สูตรที่ใช้กันมากกำหนดให้ impact เป็นสัดส่วนของราคา เท่ากับตัวคูณ $Y$ คูณความผันผวนรายวัน คูณรากที่สองของสัดส่วนคำสั่งต่อปริมาณทั้งวัน นี่คือนิยามของแบบจำลอง ไม่ได้พิสูจน์จากอะไร รูปรากที่สองถูกเลือกเพราะเข้ากับข้อมูลหลายตลาดพอสมควร และ $Y$ ต้องประมาณจากข้อมูลของตลาดนั้น (ช่วงที่พบบ่อยคือ 0.5 ถึง 1)

\[ \begin{aligned} I&=Y\sigma\sqrt{Q/V},\\ I&=1(0.02)\sqrt{0.01}=0.002=20\ \text{bp},\\ C_I&=0.002(4{,}000{,}800)=8{,}001.60,\\ C_s&=0.02(40{,}000)=800,\\ I^*&=2\ \text{bp}\ :\ \frac QV=\Big(\frac{0.0002}{0.02}\Big)^2\\ &=0.01\%. \end{aligned} \]

ตัวอย่างสมมติ คำสั่ง 1% ของปริมาณทั้งวัน ความผันผวนรายวัน 2% ได้ impact 20 bp บนมูลค่า 40,000 หุ้นที่ \$100.02 คือราว \$8,000 สิบเท่าของครึ่ง spread สองแถวล่างหาขนาดที่ impact เท่าครึ่ง spread (2 bp) ได้แค่ 0.01% ของปริมาณทั้งวัน คำสั่งแทบทุกขนาดที่สถาบันส่งจึงมี impact เป็นก้อนหลัก

ทำไมเป็นรากที่สอง คำสั่งใหญ่สี่เท่าจ่ายต่อหุ้นแพงขึ้นแค่สองเท่า เพราะคำสั่งใหญ่มักถูกซอยส่งนานขึ้น ตลาดมีเวลาเติมของ แต่ต้นทุนเป็นเงินยังโต $4\times2=8$ เท่า

ขั้นที่ 6 — ฟังก์ชันต้นทุน Kissel–Glantz

อีกฟังก์ชันที่ใช้มากแยกต้นทุนได้ทีละหุ้น (ไม่นับว่าการซื้อหุ้นตัวหนึ่งดันราคาตัวอื่น) ต้นทุนเป็นสัดส่วนของมูลค่าที่ซื้อขาย $|PQ|$ ก้อน impact โตตามขนาดเทียบปริมาณต่อวันยกกำลัง $\beta$ บวกก้อนที่เป็นเส้นตรงตามความผันผวนและค่าคงที่ พารามิเตอร์ได้จาก regression ของต้นทุนที่เกิดจริงต่อมูลค่าของคำสั่งในอดีต นี่คือนิยามของแบบจำลอง ถ้าเขียนด้วยน้ำหนักพอร์ต (จุด) จะได้แถวที่สี่

\[ \begin{aligned} c(Q)&=\Big[a_1\Big(\frac{100|Q|}{V}\Big)^{\beta}\\ &\qquad+a_2\sigma+a_3\Big]|PQ|,\\ \frac{c(Q_t)}{|P_tQ_t|}&=a_1\Big(\frac{100|Q_t|}{V_t}\Big)^{\beta}+a_2\sigma_t+a_3+\epsilon,\\ C_i&=a_1\Big(\frac{100}{V_i}\Big)^{\beta}|\Delta w_i|^{1+\beta}\\ &\quad+(a_2\sigma_i+a_3)|\Delta w_i|,\\ C_1&=0.0035(10)^{0.65}(10)^{1.65}\\ &\quad+(0.3(0.051449)+0.0015)(10)\\ &=0.69834+0.16935=0.86769. \end{aligned} \]

ตัวอย่างหุ้นสมมติ 10 ตัว ใช้ $a_1=0.0035$, $\beta=0.65$, $a_2=0.3$, $a_3=0.0015$ หุ้นตัวที่ 1 ความผันผวน 5.1449% ปริมาณต่อวัน 10 หน่วย ถ้าย้ายน้ำหนัก 10 จุด เสีย impact 0.69834 และก้อนเส้นตรง 0.16935 หุ้นตัวที่ 4 ปริมาณแค่ 0.1 หน่วย ถ้าย้าย 17.25 จุด เสีย 34.5466 เพราะ $(100/0.1)^{0.65}=89.1$ เท่าของ $(100/10)^{0.65}=4.47$ และ $|\Delta w|^{1.65}$ โตเร็วกว่าเส้นตรง

ขั้นที่ 7 — โจทย์เปิดหน้า: หนึ่งรอบของคำสั่ง \$200 ล้าน

โจทย์ให้อะไรมาบ้าง: คำสั่ง \$200 ล้านที่ \$50 คือ 4 ล้านหุ้น ปริมาณต่อวัน \$800 ล้าน ความผันผวนรายวัน 1.8% ตัวคูณ $Y=0.8$ (ค่าที่ต้องประมาณ ใช้ค่านี้เป็นสมมติฐาน) ครึ่ง spread $(50.075-50)/50=15$ bp ค่าธรรมเนียม 8 bp กำไรก่อนต้นทุน 0.42% ต่อรอบ

\[ \begin{aligned} \frac QV&=\frac{200}{800}=0.25,\\ I&=0.8(1.8\%)\sqrt{0.25}=0.72\%,\\ m_1&=50.00(1.0072)=50.36,\\ c_1&=15+72+8=95\ \text{bp},\\ c_2&=2c_1=190\ \text{bp},\\ C&=0.019(200\ \text{M})=3{,}800{,}000,\\ G&=0.0042(200\ \text{M})=840{,}000,\\ G-C&=-2{,}960{,}000. \end{aligned} \]

คำตอบ: impact 72 bp ดัน midpoint จาก 50.00 ไป 50.36 ซึ่งคือตัวเลขที่ใช้แยกต้นทุนด้านบน ขาเดียวเสีย 95 bp ไปกลับ 190 bp เพราะตอนขายออกก็ต้องจ่ายทุกก้อนซ้ำ และการขายก้อนใหญ่ดันราคาลงเหมือนที่ตอนซื้อดันขึ้น ราคาที่ขึ้นไปตอนซื้อจึงไม่ใช่กำไรที่เก็บได้ ขาดทุนรอบละ \$2.96 ล้าน

ตรวจเองใน 10 วินาที: $0.8\times1.8\%\times0.5=0.72\%$ และ $2(0.15\%+0.72\%+0.08\%)=1.90\%$ ส่วนค่าธรรมเนียมไปกลับ 16 bp เป็นแค่ 8% ของ 190 bp

ขั้นที่ 8 — ทั้งปี: บนกระดาษ +21% ของจริง −74%

ต่อผลของหนึ่งรอบให้ครบ 50 รอบ คิดแบบไม่ทบต้นบนเงิน \$200 ล้านเท่าเดิมทุกรอบเหมือนที่ backtest คิด แล้วตรวจกลับด้วยมูลค่าที่ซื้อขายทั้งปี

\[ \begin{aligned} G_{\rm yr}&=50(0.42\%)=21.0\%,\\ C_{\rm yr}&=50(1.90\%)=95.0\%,\\ G_{\rm yr}-C_{\rm yr}&=-74.0\%,\\ V_{\rm tr}&=100(200\ \text{M})\\ &=20{,}000\ \text{M},\\ c&=\frac{190\ \text{M}}{20{,}000\ \text{M}}=0.95\%. \end{aligned} \]

$G_{\rm yr}$ คือกำไรก่อนต้นทุนทั้งปี $C_{\rm yr}$ คือต้นทุนทั้งปี ซึ่งเท่ากับ 95% ของพอร์ต ขาดทุนสุทธิ \$148 ล้าน ตรวจกลับ ไปกลับ 50 รอบคือซื้อขาย 100 ขา ขาละ \$200 ล้าน รวม \$20,000 ล้าน ต้นทุน \$190 ล้านหารแล้วได้ 0.95% เท่ากับต้นทุนขาเดียวพอดี

วิธีตรวจ backtest ในสามวินาที เอามูลค่าที่ซื้อขายต่อปีเป็นกี่เท่าของพอร์ต คูณต้นทุนขาเดียว แล้วเทียบกับผลตอบแทนที่อ้าง ที่นี่คือ $100\times0.95\%=95\%$ เทียบ 21%

ขั้นที่ 9 — ทางแก้ และพื้นที่ที่แก้ไม่ได้

ลองแก้ทีละทาง ลดขนาดคำสั่งเหลือ \$40 ล้าน (5% ของปริมาณทั้งวัน) ถือนานขึ้นเป็น 25 วัน (ปีละ 10 รอบ กำไรต่อรอบโตห้าเท่า) และถามว่าถ้าคำสั่งเล็กจนไม่มี impact เลยจะเหลือต้นทุนเท่าไร

\[ \begin{aligned} I_{40}&=1.44\%\sqrt{0.05}\\ &=32.2\ \text{bp},\\ c_{40}&=2(15+32.2+8)\\ &=110.4\ \text{bp},\\ g_{25}&=5(0.42\%)=2.10\%,\\ R_{25}&=10(2.10\%-1.90\%)\\ &=2.0\%,\\ c_{\min}&=2(15+8)=46\ \text{bp},\\ H^*&=\frac{1.90\%}{0.084\%}=22.6. \end{aligned} \]

ลดขนาดช่วยได้ครึ่งหนึ่ง แต่ $c_{40}=110.4$ bp ยังเกิน 42 bp ถือ 25 วัน ($g_{25}$ คือกำไรต่อรอบ $R_{25}$ คือผลทั้งปี 10 รอบ) เหลือ +2% ต่อปี รอดแต่บาง ต้นทุนกินกำไรไป 90%

$c_{\min}$ คือพื้นที่แก้ไม่ได้ ต่อให้ไม่มี impact ครึ่ง spread กับค่าธรรมเนียมไปกลับก็ 46 bp มากกว่า 42 กลยุทธ์ 5 วันนี้ตายตั้งแต่ต้น $H^*$ บอกว่าที่ขนาดเดิมต้องถืออย่างน้อย 22.6 วันจึงเสมอตัว เพราะกำไรวันละ $0.42\%/5=0.084\%$

ทางอื่นที่ใช้จริงมีราคาของมันเอง ทยอยส่งตลอดวันตามเป้า VWAP หรือ TWAP ลด impact ได้แต่รับความเสี่ยงที่ราคาวิ่งหนีระหว่างรอ (Almgren–Chriss หาจุดสมดุลนี้) ใช้ limit order ประหยัดครึ่ง spread ได้ แต่จะวางหรือไม่และวางที่ราคาไหนขึ้นกับสามอย่าง ความใจเย็นว่าต้องได้ของทันทีไหม ความผันผวนของหุ้น (ผันผวนมาก รอแล้วราคาอาจวิ่งหนี) และส่วนลดที่ตลาดให้คนวางของ (maker rebate) และคำสั่งที่ได้จับคู่มักเป็นตอนที่ราคากำลังวิ่งสวน ส่วน dark pool ซึ่งบางช่วงมีสัดส่วนราว 11–12% ของปริมาณในหุ้นบางตัว ลด impact ได้เพราะไม่แสดงขนาด แต่ไม่รู้ว่าจะได้ของเท่าไร และมี winner's curse ถ้าได้ก้อนใหญ่ง่าย ๆ อาจเป็นเพราะอีกฝั่งรู้อะไรบางอย่าง

ขั้นที่ 10 — ใส่ต้นทุนเข้าไปในการเลือกพอร์ตตั้งแต่ต้น

มีสองทาง เลือกพอร์ตก่อนแล้วค่อยส่งคำสั่งให้ถูก หรือใส่สภาพคล่องเข้าไปในการเลือกพอร์ตเลย ในทางปฏิบัติควรทำทั้งสองอย่าง ลองแบบที่สองกับหุ้นสมมติ 10 ตัว เริ่มจากถือตัวละ 10 จุด ($y$) หาพอร์ตใหม่ $x\ge0$ ที่รวมกันได้ 100 ให้เป้าหมายแบบMarkowitz ลบต้นทุน Kissel–Glantz สูงสุด โดยใช้ $\lambda=10$ กับความแปรปรวนเต็มตัว และน้ำหนักต้นทุน $\eta=0.1$

\[ \begin{aligned} U&=\mu^\top x-\lambda\,x^\top Vx-\eta\,C(x,y),\\ U_{\rm solver}&=645.2575-10(3.6421)\\ &\quad-0.1(67.4336)=602.0928,\\ U_{\rm resolve}&=649.5479-10(3.8585)\\ &\quad-0.1(78.3045)=603.1325. \end{aligned} \]

ถ้าแก้ด้วย Solver ของ Excel ซึ่งเดินตามความชัน จะได้คำตอบที่ขายหุ้นตัวที่ 2, 8 และ 10 ทิ้งหมด ซื้อตัวที่ 4 ที่ผลตอบแทนคาดสูงสุด 7.17% เพิ่มเป็น 27.25 จุด ยอมเสียต้นทุน 34.55 กับหุ้นตัวนี้ตัวเดียว เกินครึ่งของต้นทุนรวม 67.43 ส่วนตัวที่ 1 และ 5 ค้างอยู่ที่ 10 จุดพอดี

เมื่อแก้โจทย์เดียวกันใหม่ด้วยการย้ายน้ำหนักทีละคู่ (โค้ดท้ายหน้า) ได้ $U=603.1325$ สูงกว่า ที่น้ำหนัก 11.21, 0, 14.37, 28.71, 6.45, 17.49, 18.66, 0, 3.10, 0 จุด Solver ติดอยู่ที่ตัวที่ 1 และ 5 เพราะต้นทุน $|x_i-y_i|$ หักมุมที่ $x_i=10$ วิธีที่เดินตามความชันจึงเห็นว่าขยับไปทางไหนก็แย่ลงในทันที ต้นทุนที่ไม่เรียบต้องใช้ตัวแก้ที่รับมือกับมุมได้

อีกทางของ Lo, Petrov และ Wierzbicki แปลงสภาพคล่องของหุ้นแต่ละตัวให้อยู่ระหว่าง 0 ถึง 1 แล้วบังคับให้ค่าเฉลี่ยถ่วง $\sum_i l_i|x_i|/\sum_j|x_j|$ ไม่ต่ำกว่าเกณฑ์ ที่ใช้ค่าสัมบูรณ์เพราะไม่ให้การชอร์ตหุ้นสภาพคล่องต่ำตัวหนึ่งไปหักล้างกับการถืออีกตัว

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

นับแค่ค่าธรรมเนียม: โจทย์เปิดหน้าเห็น 16 bp แต่ของจริง 190 bp ผลต่อปีจาก +21% เหลือ −74%

เชื่อว่าของที่แสดงคือของที่ได้: order book ด้านบนแสดงของขายรวม 48,000 หุ้น คำสั่ง 50,000 หุ้นไม่มีทางได้ครบที่ราคาที่เห็น

ใช้ต้นทุนของวันปกติในวันที่ตลาดตึงเครียด: ถ้า spread กว้างขึ้น 5 เท่าและปริมาณเหลือหนึ่งในห้า ครึ่ง spread 15 เป็น 75 bp impact โต $\sqrt5=2.24$ เท่าจาก 72 เป็น 161 bp ขาเดียวรวมค่าธรรมเนียมเป็น 244 bp แพงกว่าวันปกติ 2.6 เท่า ในวันที่มักต้องขายที่สุด

นับ impact ขาเดียว: ราคาที่ดันขึ้นตอนซื้อดูเหมือนกำไรบนจอ แต่ตอนขายก้อนเดียวกันจะดันลงเท่ากัน ต้องคิดไปกลับเสมอ

เชื่อคำตอบของตัวแก้โจทย์โดยไม่ตรวจ: Solver ที่เดินตามความชันหยุดที่ 602.09 ต่ำกว่าที่ทำได้ 1.04 หน่วยของเป้าหมาย เพราะต้นทุนหักมุม

อ่าน Roll spread เมื่อ covariance เป็นบวก: สูตรต้องถอดรากของ $-\gamma_1$ ถ้าราคามีแนวโน้มแรงกว่าการเด้ง $\gamma_1$ เป็นบวกและสูตรไม่มีคำตอบ อย่าเติมเครื่องหมายเองเพื่อให้ได้ตัวเลข

ใช้ทำอะไรบนโต๊ะจริง

ก่อนรับกลยุทธ์ใหม่ ทีมความเสี่ยงคูณมูลค่าที่ซื้อขายต่อปีด้วยต้นทุนไปกลับตามขนาดจริงแบบการคิดทั้งปีด้านบน ระหว่างส่งคำสั่ง โต๊ะวัด effective, impact และ realized แยกตามโบรกเกอร์และช่องทาง และหลังจบวันเทียบราคาที่ได้กับ VWAP หรือราคาตอนตัดสินใจ (ตลาด โบรกเกอร์ และการซื้อขายจริง) ผู้จัดการพอร์ตใส่ต้นทุนเข้าไปในการเลือกพอร์ตเพื่อไม่ให้เงินไหลไปหาหุ้นที่ดูดีบนกระดาษแต่ซื้อจริงไม่ได้

ฟังก์ชันต้นทุนทั้งหมดในหน้านี้คิดทีละหุ้น ของจริงมีหลักฐานว่าคำสั่งในหุ้นตัวหนึ่งดันราคาหุ้นที่เกี่ยวข้องด้วย เพราะคนตั้งราคาพยายามเดามูลค่าของหุ้นตัวหนึ่งจากคำสั่งในหุ้นที่คล้ายกัน ผลข้ามหุ้นนี้มักเป็นลบ เล็กลงเมื่อมีผู้เล่นมาก และใหญ่ขึ้นเมื่อความเห็นในตลาดแตกต่างกันมาก ต้นทุนของการย้ายทั้งพอร์ตจึงต่างจากผลรวมทีละตัว และยังเป็นเรื่องที่เข้าใจไม่ครบ

โจทย์ตรวจความเข้าใจ

1. บน order book ด้านบน ซื้อ 20,000 หุ้นด้วย market order ราคาเฉลี่ยเท่าไร และเสียเทียบ midpoint เท่าไร

เฉลย

10,000 หุ้นที่ 100.04 และ 10,000 หุ้นที่ 100.06 เฉลี่ย \$100.05 เสีย $0.03(20{,}000)=\$600$ ครึ่ง spread อธิบาย \$400 อีก \$200 มาจากขั้นที่สอง

2. ราคาซื้อขายของหุ้นตัวหนึ่งมี covariance ของการขยับติดกัน $\gamma_1=-0.0009$ spread ตามแบบจำลองของ Roll คือเท่าไร

เฉลย

$s=\sqrt{0.0009}=0.03$ spread $=2s=\$0.06$ ถ้า covariance ออกมาเป็นบวก สูตรนี้ใช้ไม่ได้ (ถอดรากของค่าลบไม่ได้) ซึ่งเกิดบ่อยเมื่อราคามีแนวโน้มแรงกว่าการเด้ง

3. ในโจทย์เปิดหน้า ถ้าลดคำสั่งเหลือ \$100 ล้าน ต้นทุนไปกลับเป็นเท่าไร และกลยุทธ์ 42 bp รอดไหม

เฉลย

$Q/V=0.125$ impact $0.8(1.8\%)\sqrt{0.125}=0.5091\%$ ไปกลับ $2(15+50.9+8)=147.8$ bp ยังเกิน 42 bp มาก ไม่รอด และพื้นที่ที่แก้ไม่ได้บอกแล้วว่าต่อให้ impact เป็นศูนย์ ครึ่ง spread กับค่าธรรมเนียมไปกลับ 46 bp ก็ยังเกิน 42 bp

// Buy q shares against displayed ask levels [[price, size], ...] sorted from the best ask upward.
function walkBook(asks, q) {
  let left = q, paid = 0;
  for (const [price, size] of asks) {
    const take = Math.min(left, size);
    paid += take * price; left -= take;
    if (left === 0) return {paid, average: paid / q};
  }
  throw new RangeError(`only ${q - left} shares are displayed`);
}
// Square-root impact model (a fitted rule, not a law): fraction of price = Y sigma sqrt(Q/V).
const impact = (Y, sigma, participation) => Y * sigma * sqrt(participation);
// Roll: trades bounce between bid and ask, so Cov(dP_t, dP_t-1) = -s^2 and the spread is 2s.
function rollSpread(prices) {
  const d = prices.slice(1).map((p, i) => p - prices[i]);
  const m = d.reduce((a, b) => a + b, 0) / d.length;
  let c = 0;
  for (let i = 1; i < d.length; i++) c += (d[i] - m) * (d[i - 1] - m);
  c /= d.length - 1;
  if (c >= 0) throw new RangeError('autocovariance is not negative, Roll spread undefined');
  return {cov: c, spread: 2 * sqrt(-c)};
}
function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}

// Maximise over x >= 0 with sum 100 by moving weight between pairs (golden-section line search).
function resolve(x, eta = 0.1) {
  x = x.slice();
  const g = (sqrt(5) - 1) / 2;
  for (let sweep = 0; sweep < 400; sweep++) {
    let gain = 0;
    for (let i = 0; i < 10; i++) for (let j = 0; j < 10; j++) {
      if (i === j || x[i] <= 0) continue;
      const f = t => { const z = x.slice(); z[i] -= t; z[j] += t; return parts(z, eta).objective; };
      let a = 0, b = x[i], c1 = b - g * b, c2 = g * b, f1 = f(c1), f2 = f(c2);
      for (let k = 0; k < 50; k++) {
        if (f1 < f2) { a = c1; c1 = c2; f1 = f2; c2 = a + g * (b - a); f2 = f(c2); }
        else { b = c2; c2 = c1; f2 = f1; c1 = b - g * (b - a); f1 = f(c1); }
      }
      const t = (a + b) / 2, before = parts(x, eta).objective, after = f(t);
      if (after > before + 1e-12) { x[i] -= t; x[j] += t; gain += after - before; }
    }
    if (gain < 1e-10) break;
  }
  return x;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • คำสั่งใหญ่กินลึกลงไปใน order book 40,000 หุ้นเสีย \$1,680 เทียบ midpoint ไม่ใช่ \$800 ของครึ่ง spread
  • ต้นทุนหนึ่งคำสั่งแยกเป็น effective = realized + impact (15 = −57 + 72 bp) และ realized ติดลบคือ adverse selection
  • Roll อ่าน spread จากราคาซื้อขายได้เพราะการเด้งระหว่าง bid กับ ask ทำให้ covariance ของการขยับติดกันคือ $-s^2$
  • กฎรากที่สองเป็นแบบจำลองที่ต้องประมาณ ใช้แล้วคำสั่ง \$200 ล้านเสีย 190 bp ไปกลับ และ backtest +21% กลายเป็น −74%
