25.5 EWMA, the Kalman Filter, and GARCH as EWMA with an Offset

ระบบความเสี่ยงประมาณความผันผวนของหุ้นทุกวันด้วย EWMA หน้านี้แสดงว่า EWMA คือสูตรที่ดีที่สุดเมื่อ variance เดินสุ่มไปเรื่อย ๆ และเมื่อ variance ถูกดึงกลับหาระดับปกติ สูตรที่ดีที่สุดกลายเป็น GARCH(1,1) ซึ่งคือ EWMA ที่บวกค่าคงที่เพิ่มหนึ่งตัว

ทุกเช้า ธนาคารต้องรู้ว่าหุ้นแต่ละตัวในพอร์ตจะแกว่งแรงแค่ไหนในวันนี้ เพราะตัวเลขนี้บอกว่าพอร์ตอาจขาดทุนได้เท่าไร ตัวเลขนั้นคือความผันผวน: SD ของผลตอบแทนรายวัน ส่วน variance คือความผันผวนยกกำลังสอง ปัญหาคือความผันผวนมองไม่เห็นตรง ๆ เราเห็นแค่ผลตอบแทนของแต่ละวัน

ระบบความเสี่ยงของธนาคารจึงประมาณ variance ด้วย EWMA วิธีนี้เอาผลตอบแทนยกกำลังสองของหลายวันย้อนหลังมาเฉลี่ย วันล่าสุดได้น้ำหนักมากที่สุด และทุกวันที่ย้อนไป น้ำหนักลดลงเป็นสัดส่วนเท่าเดิม (ทำไมต้องยกกำลังสอง ภาพรวมด้านล่างจะอธิบาย)

ของที่รู้:

  • ระบบใช้ decay factor $\lambda=0.94$ กับทุกหุ้น $\lambda$ คือสัดส่วนที่น้ำหนักเหลือ เมื่อข้อมูลเก่าลงหนึ่งวัน ด้วยค่านี้ น้ำหนักของข้อมูลหนึ่งวันจะหดเหลือครึ่งหลังผ่านไป 11.2 วัน ตัวเลขนี้เรียกว่า half-life (ขั้นแรกด้านล่างคำนวณให้ดู)
  • ทีมวิจัยพบว่า variance ของผลตอบแทนรายวันไม่ได้ลอยไปไหนก็ได้ มันถูกดึงกลับหาระดับปกติ $V=9\times10^{-5}$ เสมอ (ตัวเลขสมมติ) คิดเป็นความผันผวน $\sqrt V=\sqrt{0.00009}=0.949\%$ ต่อวัน
  • แรงดึงกลับวัดด้วย $a=0.98$ (สมมติ): ถ้าวันนี้ variance สูงกว่า $V$ อยู่เท่าไร พรุ่งนี้ส่วนที่เกินนั้นจะเหลือ 98% นิสัยนี้เรียกว่า mean reversion

เพื่อนร่วมทีมอ่านเจอว่า “mean reversion ทำให้ข้อมูลเก่ามีค่ามากขึ้น” เขาจึงเสนอให้ยืด half-life จาก 11.2 วันเป็น 15.2 วัน (หน้านี้จะแสดงว่า 15.2 มาจากไหน) ข้อเสนอนี้ถูกไหม และสูตรที่ดีที่สุดคืออะไร?

ลองตอบก่อนเปิดเฉลย

ข้อเสนอดีขึ้นนิดเดียว และเหตุผลของมันกลับทิศ

เราวัดว่าสูตรไหนดีกว่าด้วย “ความผิดของการติดตาม” ทำแบบนี้: ทุกวัน เอาค่าที่พยากรณ์ลบ variance จริง แล้วยกกำลังสอง เฉลี่ยทุกวัน แล้วถอดราก สุดท้ายเขียนเป็น % ของ $V$ ยิ่งต่ำยิ่งดี หน้านี้จะคำนวณตัวเลขเหล่านี้ให้ดูทีละขั้น

  • EWMA เดิม ($\lambda=0.94$): 33.54%
  • ข้อเสนอ (half-life 15.2 วัน): 32.82%
  • EWMA ที่ดีที่สุด ไม่ว่าจะเลือก $\lambda$ เท่าไร: 32.78%
  • GARCH(1,1) ที่ $\omega=1.8\times10^{-6}$, $\alpha=0.0436$, $\beta=0.9364$: 30.51%

GARCH(1,1) คือ EWMA ที่บวกค่าคงที่ $\omega$ เข้าไป:

\[\hat\sigma_{t+1}^2=\omega+\alpha r_t^2+\beta\hat\sigma_t^2\]

ในสูตรนี้ $\hat\sigma_{t+1}^2$ คือ variance ของพรุ่งนี้ที่พยากรณ์ $r_t$ คือผลตอบแทนวันนี้ และ $\hat\sigma_t^2$ คือ variance ของวันนี้ที่พยากรณ์ไว้เมื่อวาน

ในสูตรที่ดีที่สุดนี้ น้ำหนักของข้อมูลเก่าหดเหลือครึ่งทุก 10.55 วัน (ขั้นที่ 7 คำนวณให้ดู) สั้นกว่า 11.2 วันเดิม ไม่ได้ยาวขึ้น สิ่งที่ mean reversion บอกเพิ่มคือ “variance อยู่ไม่ไกลจาก $V$” ความรู้นี้เข้ามาทางค่าคงที่ $\omega$ ซึ่งดึงคำตอบกลับหา $V$ ทุกวัน มันไม่ได้เข้ามาทางข้อมูลเก่า

ภาพรวมก่อนลงสูตร

เริ่มจากคำถามว่า ทำไมต้องเฉลี่ยหลายวัน เขียนผลตอบแทนของวัน $t$ ว่า $r_t$ และ variance ของวันนั้นว่า $\sigma_t^2$ ความผันผวนของวันนี้คือ SD ของผลตอบแทนวันนี้ แต่วันหนึ่งมีผลตอบแทนแค่ค่าเดียว เราจึงเห็น $r_t$ แต่ไม่เห็น SD ของมัน

ทางที่ใช้ได้คือยกกำลังสอง เพราะผลตอบแทนรายวันมีค่าเฉลี่ยเกือบศูนย์ ($\mathbb E[r_t]\approx0$) นิยามของ variance จึงเหลือแค่ค่าเฉลี่ยของ $r_t^2$:

\[\begin{aligned}\sigma_t^2&=\mathbb E[r_t^2]-(\mathbb E[r_t])^2\\&\approx\mathbb E[r_t^2].\end{aligned}\]

แต่ $r_t^2$ ของวันเดียวแกว่งแรงมาก ลองเขียน $r_t=\sigma_t\xi_t$ โดย $\xi_t$ เป็น Normal มาตรฐาน (ค่าเฉลี่ย 0, SD 1) จะได้ $r_t^2=\sigma_t^2\xi_t^2$ บางวัน $\xi_t$ ใกล้ศูนย์ $r_t^2$ ก็เกือบศูนย์ บางวัน $\xi_t=2$ $r_t^2$ ก็เป็นสี่เท่าของ variance

การแกว่งนี้ใหญ่แค่ไหน? ใช้สมบัติสองข้อของ Normal มาตรฐาน: $\mathbb E[\xi_t^2]=1$ (เพราะ SD เป็น 1) และ $\mathbb E[\xi_t^4]=3$ (ได้จากการอินทิเกรต density ของ Normal)

\[\begin{aligned}\operatorname{Var}(\xi_t^2)&=\mathbb E[\xi_t^4]-(\mathbb E[\xi_t^2])^2\\&=3-1^2=2,\\\operatorname{SD}(r_t^2)&=\sigma_t^2\operatorname{SD}(\xi_t^2)\\&=\sqrt2\,\sigma_t^2.\end{aligned}\]

SD ของ $r_t^2$ คือ $\sqrt2=1.41$ เท่าของ variance ที่อยากรู้ เสียงรบกวนจึงใหญ่กว่าตัวสัญญาณเอง ข้อมูลวันเดียวใช้ไม่ได้ ต้องเฉลี่ยหลายวัน

วิธีมาตรฐานของอุตสาหกรรมคือ EWMA (exponentially weighted moving average) มันเฉลี่ย $r^2$ ย้อนหลัง โดยน้ำหนักลดลงเหลือ $\lambda$ เท่าทุกวันที่ย้อนไป บริษัทที่ขายแบบจำลองความเสี่ยง (risk model) ให้ธนาคารและกองทุน เช่น RiskMetrics, Barra และ Axioma ใช้วิธีนี้ เหตุผลมีสามข้อ: มี parameter ตัวเดียว ใช้ค่าเดียวกันได้กับทุกหุ้น และอธิบายลูกค้าง่าย

ส่วนงานวิชาการนิยม GARCH มากกว่า GARCH พยากรณ์ variance ของพรุ่งนี้จากสามก้อน: ค่าคงที่ $r^2$ ของวันนี้ และ variance ที่พยากรณ์ไว้ของวันนี้ มันจึงมี parameter สามตัวต่อหุ้น และมีระดับปกติให้ variance กลับไปหา

หน้านี้ตอบว่าสองสูตรต่างกันจริงแค่ไหน และแต่ละสูตรเหมาะกับโลกแบบไหน ลำดับเป็นแบบนี้:

  • คลี่สูตร GARCH ออกมา แล้วจะเห็นว่ามันคือ EWMA บวกค่าคงที่
  • เขียนแบบจำลองสองบรรทัด แบบเดียวกับ แบบจำลองของ Roll: บรรทัดแรกคือค่าจริงที่มองไม่เห็น บรรทัดที่สองคือข้อมูลที่เห็น ซึ่งเท่ากับค่าจริงบวกเสียงรบกวน ที่นี่ค่าจริงคือ variance ของวันนั้น และข้อมูลคือ $r_t^2$
  • หาตัวกรองที่ดีที่สุดของแบบจำลองนี้ ซึ่งเรียกว่า Kalman filter ถ้า variance เดินสุ่มไปเรื่อย ๆ (random walk) Kalman filter ออกมาเป็น EWMA พอดี ถ้า variance ถูกดึงกลับหาระดับปกติ Kalman filter ออกมาเป็น GARCH(1,1)
  • สุดท้าย วัดว่าสูตรไหนติดตาม variance จริงได้ใกล้กว่ากันเท่าไร

ก่อนลงสูตร ดูของจริงก่อน รูปด้านล่างจำลองหุ้นที่ความผันผวนกระโดดขึ้นแล้วกลับลง แล้วดูว่า EWMA ที่ $\lambda=0.94$ ไล่ตามทันแค่ไหน

ศัพท์ที่ใช้ในหัวข้อนี้
EWMA และ decay factor
ค่าเฉลี่ยของ $r^2$ ย้อนหลัง โดยแต่ละวันได้น้ำหนัก $\lambda$ เท่าของวันที่ใหม่กว่าหนึ่งวัน เช่นที่ $\lambda=0.94$ วันนี้ได้น้ำหนัก $1-0.94=0.06$ และเมื่อวานได้ $0.06\times0.94=0.0564$ ตัว $\lambda$ เรียกว่า decay factor ชื่อเต็มของ EWMA คือ exponentially weighted moving average เป็นสูตรมาตรฐานของ risk model เชิงพาณิชย์ เพราะมี parameter ตัวเดียว
Half-life
จำนวนวันที่น้ำหนักของข้อมูลหนึ่งวันหดเหลือครึ่ง หาจาก $\lambda^h=\tfrac12$ จึงได้ $h=\ln0.5/\ln\lambda$ คนในวงการใช้ตัวเลขนี้บอกว่าสูตรลืมข้อมูลเก่าเร็วแค่ไหน โดยไม่ต้องพูดถึง $\lambda$
Mean reversion
นิสัยของ variance ที่ถูกดึงกลับหาระดับปกติ $V$ ถ้าวันนี้สูงกว่า $V$ พรุ่งนี้มักลดลงมาใกล้ $V$ ถ้าวันนี้ต่ำกว่า พรุ่งนี้มักสูงขึ้น
Persistence
ค่า $a$ ที่บอกว่าส่วนเกิน (variance ลบ $V$) ของวันนี้เหลือกี่ส่วนในวันพรุ่งนี้ $a=0.98$ คือเหลือ 98% ในภาษาของ GARCH มันคือ $\alpha+\beta$ ส่วนเกินหดเหลือครึ่งใน $\ln0.5/\ln a$ วัน ที่ $a=0.98$ คือ $\ln0.5/\ln0.98=34.3$ วัน
State-space model
แบบจำลองที่มีสองบรรทัด บรรทัดแรกบอกว่าสถานะ (state) ที่มองไม่เห็นเปลี่ยนอย่างไรจากวันหนึ่งไปอีกวัน บรรทัดที่สองบอกว่าข้อมูลที่เห็นเท่ากับสถานะบวกเสียงรบกวน เหมือนราคาจริงกับราคาที่บันทึกใน แบบจำลองของ Roll ที่นี่สถานะคือ variance จริง และข้อมูลคือ $r_t^2$ ข้อดีคือเราเขียนแบบจำลองก่อน แล้วค่อยหาตัวกรองที่ดีที่สุดจากมัน ไม่ต้องเดาสูตร
Kalman filter และ Kalman gain
Kalman filter คือสูตรที่ผสมค่าประมาณเดิมกับข้อมูลใหม่ ด้วยน้ำหนักที่ทำให้ความผิดเล็กที่สุด น้ำหนัก $K$ ที่ให้ข้อมูลใหม่เรียกว่า Kalman gain สำหรับ EWMA มันคือ $1-\lambda$
Integrated GARCH (IGARCH)
GARCH ที่ $\alpha+\beta=1$ และ $\omega=0$ จึงไม่มีระดับปกติให้กลับไปหา EWMA คือ IGARCH ในอีกชื่อหนึ่ง

ขั้นที่ 1 — EWMA และ half-life

ทุกการเปรียบเทียบในหน้านี้ถามเรื่องเดียว: ข้อมูลของแต่ละวันในอดีตได้น้ำหนักเท่าไร จึงเริ่มจากนิยามของ EWMA

ให้ $\hat\sigma_{t+1}^2$ คือ variance ของพรุ่งนี้ที่พยากรณ์ (หมวกบนหัวแปลว่า “ค่าประมาณ”) EWMA สร้างมันจากสองอย่าง: $r_t^2$ ของวันนี้ ได้น้ำหนัก $1-\lambda$ และค่าพยากรณ์ของวันนี้ที่ทำไว้เมื่อวาน $\hat\sigma_t^2$ ได้น้ำหนัก $\lambda$ ค่าพยากรณ์เมื่อวานก็สร้างจากสูตรเดียวกัน ถ้าแทนมันลงไปซ้ำ ๆ น้ำหนักของทุกวันจะโผล่ออกมา จากนั้นหา half-life โดยถามว่าต้องผ่านไปกี่วัน $h$ น้ำหนักจึงหดเหลือครึ่ง

\[ \begin{aligned} \hat\sigma_{t+1}^2&=(1-\lambda)r_t^2+\lambda\hat\sigma_t^2\\ &=(1-\lambda)r_t^2+\lambda(1-\lambda)r_{t-1}^2\\ &\quad+\lambda^2\hat\sigma_{t-1}^2\\ &=(1-\lambda)\sum_{i=0}^{\infty}\lambda^{i}r_{t-i}^2,\\ (1-\lambda)\sum_{i\ge0}\lambda^i&=\frac{1-\lambda}{1-\lambda}=1,\\ \lambda^h=\tfrac12\ \Rightarrow\ h\ln\lambda&=\ln0.5,\\ h&=\frac{\ln0.5}{\ln0.94}=\frac{-0.6931}{-0.0619}\\ &=11.20\ \text{days}. \end{aligned} \]

ผลรวมบอกน้ำหนักของทุกวันตรง ๆ: ข้อมูลของวันนี้ได้ $1-\lambda=0.06$ และข้อมูลของ $i$ วันก่อนได้ $0.06\times0.94^i$ น้ำหนักลดลงเรื่อย ๆ แต่ไม่มีวันไหนหลุดออกทันที ต่างจากค่าเฉลี่ย 20 วัน ที่ข้อมูลวันที่ 21 หายไปทั้งก้อน

น้ำหนักรวมเป็น 1 พอดี เพราะ $\sum\lambda^i$ เป็นอนุกรมเรขาคณิตที่รวมได้ $1/(1-\lambda)$ เรื่องนี้สำคัญ ถ้าน้ำหนักรวมไม่เป็น 1 ค่าเฉลี่ยจะสูงหรือต่ำกว่า variance จริงเสมอ

12 วันล่าสุดได้น้ำหนักรวมเท่าไร? ใช้อนุกรมเรขาคณิตแบบนับพจน์จำกัด:

\[\begin{aligned}(1-\lambda)\sum_{i=0}^{11}\lambda^i&=1-\lambda^{12}\\&=1-0.94^{12}=52.4\%.\end{aligned}\]

น้ำหนักราวครึ่งหนึ่งจึงอยู่ใน 12 วันล่าสุด ซึ่งเข้ากับ half-life 11.2 วัน อีกข้อดีหนึ่ง: สูตรนี้เก็บแค่ตัวเลขเดียวต่อหุ้น คือค่าพยากรณ์ของเมื่อวาน ระบบจึงคิดกับหุ้นหลายพันตัวได้ทุกวัน โดยไม่ต้องเก็บข้อมูลย้อนหลังเลย

half-life 11.2 วันสื่อสารง่ายกว่า $\lambda=0.94$ แต่ต้องระวัง เมื่อ $\lambda$ ใกล้ 1 การขยับ $\lambda$ นิดเดียวทำให้ half-life ขยับมาก เหตุผลคือ เมื่อ $\lambda$ ใกล้ 1 จะได้ $\ln\lambda\approx-(1-\lambda)$ ดังนั้น

\[\begin{aligned}h&\approx\frac{0.693}{1-\lambda},\\\lambda=0.94:\ h&\approx\frac{0.693}{0.06}=11.55.\end{aligned}\]

ค่าประมาณ 11.55 ใกล้ค่าจริง 11.20 สูตรประมาณนี้บอกว่า ถ้าระยะห่างจาก 1 หดครึ่ง half-life ก็ยาวขึ้นราวสองเท่า ค่าจริงคือ $\ln0.5/\ln0.97=22.76$ วัน และ $\ln0.5/\ln0.99=68.97$ วัน

ขั้นที่ 2 — คำพยากรณ์หลายวันของ EWMA แบนตลอดไป

งานบางอย่างต้องรู้ความผันผวนของหลายวันข้างหน้า เช่นการตั้งราคา option (สัญญาที่ราคาขึ้นกับความผันผวนจนถึงวันหมดอายุ) ที่หมดอายุในอีกสามเดือน ให้ $f_h$ คือ variance ที่พยากรณ์ไว้วันนี้ สำหรับวันที่ $h$ ข้างหน้า ($f_1$ คือพรุ่งนี้)

ปัญหาคือ สูตร EWMA ของวันที่ $h+1$ ต้องใช้ $r^2$ ของวันที่ $h$ ซึ่งยังไม่เกิด ค่าที่ดีที่สุดที่ใส่แทนได้คือค่าเฉลี่ยของมัน ค่าเฉลี่ยของ $r^2$ คือ variance ของวันนั้น (ภาพรวมด้านบน) ซึ่งก็คือ $f_h$ เอง

ใช้ตัวอย่างนี้ตลอดขั้นนี้:

  • เมื่อวานพยากรณ์ความผันผวนของวันนี้ไว้ 1% จึงได้ $\hat\sigma_t^2=0.01^2=0.0001$
  • วันนี้ตลาดร่วง 4% จึงได้ $r_t=-0.04$ และ $r_t^2=0.0016$
\[ \begin{aligned} f_{h+1}&=(1-\lambda)f_h+\lambda f_h=f_h,\\ \hat\sigma_{t+1}^2&=0.06(0.0016)+0.94(0.0001)\\ &=0.000096+0.000094\\ &=0.00019,\\ \hat\sigma_{t+1}&=\sqrt{0.00019}=1.378\%. \end{aligned} \]

หัวใจอยู่ที่น้ำหนักสองก้อนของ EWMA ซึ่งรวมกันเป็น 1 พอดี เมื่อใส่ค่าเดียวกัน $f_h$ ลงทั้งสองช่อง ผลก็ได้ $f_h$ เท่าเดิม คำพยากรณ์ของวันถัดไปจึงเท่ากับวันนี้ และเท่าเดิมไปทุกวัน หลังวันร่วง 4% EWMA ตอบ 1.378% ทั้งสำหรับพรุ่งนี้ และสำหรับอีกหกสิบวันข้างหน้า

GARCH(1,1) ทำต่างออกไป ใช้ตัวอย่างในหน้า ARCH/GARCH ที่ $\omega=1.8\times10^{-6}$, $\alpha=0.09$, $\beta=0.89$ ระดับปกติ $V$ ของมันคือค่าที่ใส่เข้าไปแล้วได้ค่าเดิมออกมา (ใส่ $V$ แทนทั้ง $r^2$ และ variance เดิม):

\[\begin{aligned}V&=\omega+(\alpha+\beta)V,\\V&=\frac{\omega}{1-\alpha-\beta}=\frac{1.8\times10^{-6}}{0.02}\\&=9\times10^{-5}.\end{aligned}\]

ค่านี้ตรงกับความผันผวน 0.949% ในโจทย์เปิดหน้า ทีนี้ใส่ข่าววันร่วง 4% เดียวกัน คำตอบของพรุ่งนี้คือ

\[\begin{aligned}f_1&=\omega+\alpha r_t^2+\beta\hat\sigma_t^2\\&=0.0000018+0.09(0.0016)\\&\quad+0.89(0.0001)\\&=0.0000018+0.000144+0.000089\\&=0.0002348,\\\sqrt{f_1}&=\sqrt{0.0002348}=1.532\%.\end{aligned}\]

วันถัด ๆ ไป GARCH ใส่ $f_h$ แทน $r^2$ ที่ยังไม่เกิด เหมือน EWMA แต่น้ำหนักรวม $\alpha+\beta=0.98$ ไม่ถึง 1 ถ้าแทน $\omega=(1-0.98)V$ แล้วย้าย $V$ ไปฝั่งซ้าย จะเห็นว่าส่วนเกินเหนือ $V$ เหลือ 98% ทุกวัน คำตอบจึงเดินกลับหาระดับปกติ:

\[\begin{aligned}f_{h+1}&=\omega+(\alpha+\beta)f_h,\\f_{h+1}-V&=0.98\,(f_h-V),\\f_{61}&=V+0.98^{60}(f_1-V),\\0.98^{60}&=0.2976,\\f_1-V&=0.0002348-0.00009\\&=0.0001448,\\f_{61}&=0.00009+0.2976(0.0001448)\\&=0.0001331,\\\sqrt{f_{61}}&=1.154\%.\end{aligned}\]

ส่วนเกินถูกคูณ 0.98 วันละครั้ง ผ่านไป 60 วันจึงคูณ $0.98^{60}$ อีก 60 วันหลังจากพรุ่งนี้ GARCH จึงตอบ 1.154% ใกล้ระดับปกติ 0.949% แล้ว ส่วน EWMA ยังค้างที่ 1.378%

ขั้นที่ 3 — คลี่ GARCH: EWMA บวกค่าคงที่

ขั้นที่แล้วเห็นว่าสองสูตรพยากรณ์อนาคตต่างกันมาก ตอนนี้วางสองสูตรข้างกัน เพื่อดูว่าต่างกันตรงไหนกันแน่ GARCH(1,1) เขียนว่า $\hat\sigma_{t+1}^2=\omega+\alpha r_t^2+\beta\hat\sigma_t^2$ คือค่าคงที่ $\omega$ บวกน้ำหนัก $\alpha$ บน $r^2$ ของวันนี้ บวกน้ำหนัก $\beta$ บนค่าพยากรณ์เดิม

คลี่มันแบบเดียวกับที่คลี่ EWMA ในขั้นแรก คือแทนค่าของเมื่อวานลงไปซ้ำ ๆ ทุกครั้งที่แทน จะได้ $\omega$ เพิ่มอีกหนึ่งก้อน ซึ่งถูกคูณ $\beta$ เพิ่มอีกหนึ่งชั้น ก้อน $\omega$ ทั้งหมดรวมกันเป็นอนุกรมเรขาคณิต $\omega(1+\beta+\beta^2+\cdots)=\omega/(1-\beta)$

\[ \begin{aligned} \text{GARCH}:&\quad\hat\sigma_{t+1}^2=\omega(1+\beta+\beta^2+\cdots)\\ &\qquad+\alpha\sum_{i\ge0}\beta^{i}r_{t-i}^2\\ &\quad=\frac{\omega}{1-\beta}+\alpha\sum_{i\ge0}\beta^{i}r_{t-i}^2,\\ \text{EWMA}:&\quad\hat\sigma_{t+1}^2=(1-\lambda)\sum_{i\ge0}\lambda^{i}r_{t-i}^2,\\ \text{same}:&\quad\omega=0,\ \alpha=1-\lambda,\ \beta=\lambda. \end{aligned} \]

สองสูตรหน้าตาเหมือนกัน ต่างกันแค่ก้อนคงที่ $\omega/(1-\beta)$ ข้างหน้า ถ้าตั้ง $\omega=0$, $\alpha=1-\lambda$ และ $\beta=\lambda$ GARCH จะกลายเป็น EWMA ทุกตัวอักษร EWMA จึงคือ GARCH ที่ไม่มีค่าคงที่

ทำไมเมื่อไม่มีค่าคงที่ น้ำหนักบนข้อมูลต้องรวมเป็น 1? สมมติ variance คงที่ที่ $\sigma^2$ ค่าเฉลี่ยของทุก $r^2$ ก็คือ $\sigma^2$ แล้วดูว่าสูตรตอบเท่าไรโดยเฉลี่ย:

\[\begin{aligned}\alpha(1+\beta+\beta^2+\cdots)&=\frac{\alpha}{1-\beta},\\\mathbb E[\hat\sigma_{t+1}^2]&=\frac{\alpha}{1-\beta}\,\sigma^2.\end{aligned}\]

ถ้าน้ำหนักรวม $\alpha/(1-\beta)$ น้อยกว่า 1 คำตอบจะต่ำกว่าความจริงเสมอ ถ้ามากกว่า 1 ก็สูงเกินเสมอ จึงต้องมี $\alpha/(1-\beta)=1$ หรือเขียนอีกแบบว่า $\alpha+\beta=1$ GARCH ที่มีเงื่อนไขนี้เรียกว่า IGARCH

มองกลับด้าน GARCH คือ EWMA ที่น้ำหนักรวมบนข้อมูลน้อยกว่า 1 แล้วเติมส่วนที่ขาดด้วยค่าคงที่ ถ้า GARCH ทำได้มากกว่า ทำไมอุตสาหกรรมยังใช้ EWMA? เหตุผลไม่ใช่ทฤษฎี แต่เป็นงานจริง EWMA มี parameter ตัวเดียวที่ใช้ร่วมกันได้ทุกหุ้น จึงไม่ต้องประมาณสามค่าต่อหุ้นจากข้อมูลที่มีเสียงรบกวน และอธิบายลูกค้าง่าย ขั้นที่เติม mean reversion ด้านล่างจะแสดงว่าค่าคงที่ของ GARCH มีความหมายของมันเอง ไม่ได้เป็นแค่ก้อนที่เติมให้ครบ

ขั้นที่ 4 — EWMA คือ Kalman filter ของ variance ที่เดินแบบ random walk

EWMA สะดวก แต่สะดวกไม่ได้แปลว่าถูก คำถามตอนนี้คือ มีโลกแบบไหนที่ EWMA เป็นคำตอบที่ดีที่สุดจริง ๆ? วิธีตอบคือเขียนแบบจำลองของโลกก่อน แล้วหาตัวกรองที่ดีที่สุดจากมัน ใช้แบบจำลองสองบรรทัดแบบเดียวกับราคาจริงและราคาที่บันทึกใน แบบจำลองของ Roll เปลี่ยนแค่ความหมายของตัวแปร:

  • บรรทัดแรก: สถานะที่มองไม่เห็น $x_t$ คือ variance จริงของวัน $t$ สมมติว่ามันเดินสุ่ม (random walk) คือทุกวันขยับขึ้นหรือลงแบบสุ่ม ขนาด SD $\tau_\epsilon$ เขียนเป็น $\tau_\epsilon\epsilon_t$ โดย $\epsilon_t$ เป็นตัวสุ่มที่มีค่าเฉลี่ย 0 และ SD 1
  • บรรทัดที่สอง: ข้อมูลที่เห็น $y_t=r_t^2$ มีค่าเฉลี่ยเท่ากับ $x_t$ แต่มีเสียงรบกวนขนาด SD $\tau_\eta$ เขียนเป็น $\tau_\eta\eta_t$ โดย $\eta_t$ มีค่าเฉลี่ย 0 และ SD 1 เช่นกัน

แบบจำลองนี้มีชื่อว่าแบบจำลองของ Muth เราไม่ต้องเดาสูตร เพราะหน้าเรื่อง Roll หาตัวกรองที่ดีที่สุดของแบบจำลองแบบนี้ไว้แล้ว มันทำสองจังหวะทุกวัน:

  • ผสม: ค่าประมาณเดิมมีความผิดที่มี variance $P$ ข้อมูลใหม่มีเสียงรบกวนที่มี variance $\kappa^2$ สองแหล่งนี้อิสระกัน วิธีผสมที่ดีที่สุดให้น้ำหนัก $K=P/(P+\kappa^2)$ กับข้อมูลใหม่ และความผิดที่เหลือมี variance $P\kappa^2/(P+\kappa^2)$ (รูปเดียวกับตัวต้านทานสองตัวต่อขนาน ซึ่งได้ค่าเล็กกว่าทั้งสองตัว)
  • เดินหน้าหนึ่งวัน: variance จริงขยับแบบสุ่มอีกหนึ่งก้อน ความผิดจึงโตขึ้น $\tau_\epsilon^2$

เพื่อให้เหลือตัวแปรตัวเดียว เราวัด variance ทุกตัวเป็นจำนวนเท่าของ $\tau_\epsilon^2$ จังหวะเดินหน้าจึงบวก 1 และเสียงรบกวนมี variance $\kappa^2$ โดย $\kappa=\tau_\eta/\tau_\epsilon$ บอกว่าเสียงรบกวนดังกว่าการขยับจริงกี่เท่า เมื่อทำซ้ำไปหลายวัน $P$ จะนิ่ง คือ $P$ ของพรุ่งนี้เท่ากับของวันนี้ สมการที่บอกจุดนิ่งนี้เรียกว่าสมการ Riccati เราแก้มัน แล้วต่อ $K$ เข้ากับ $\lambda$ ของ EWMA:

\[ \begin{aligned} x_{t+1}&=x_t+\tau_\epsilon\,\epsilon_{t+1},\\ y_t&=x_t+\tau_\eta\,\eta_t,\\ P&=\frac{P\kappa^2}{P+\kappa^2}+1,\\ P^2+P\kappa^2&=P\kappa^2+P+\kappa^2,\\ P^2&=P+\kappa^2,\\ K&=\frac{P}{P+\kappa^2}=\frac{P}{P^2}=\frac1P,\\ \kappa^2&=P^2-P=\frac{1-K}{K^2},\\ \kappa&=\frac{\sqrt{1-K}}{K}=\frac{\sqrt\lambda}{1-\lambda},\\ \kappa&=\frac{\sqrt{0.94}}{0.06}=\frac{0.9695}{0.06}=16.16. \end{aligned} \]

จังหวะที่ต้องดูคือการได้ $P^2=P+\kappa^2$ เราคูณ $P+\kappa^2$ ทั้งสองข้างของสมการ Riccati แล้วตัด $P\kappa^2$ ที่อยู่ทั้งสองฝั่งทิ้ง ผลคือตัวส่วนของ $K$ เท่ากับ $P^2$ พอดี จึงได้ $K=1/P$

ทีนี้เทียบกับ EWMA ค่าประมาณของพรุ่งนี้คือ $\hat x_{t+1|t}=(1-K)\hat x_{t|t-1}+Ky_t$ (ตัวห้อย $t+1|t$ อ่านว่า ค่าของวัน $t+1$ เมื่อรู้ข้อมูลถึงวัน $t$) ค่าที่ผสมแล้วใช้เป็นค่าของพรุ่งนี้ได้เลย เพราะการขยับแบบสุ่มของ random walk มีค่าเฉลี่ยศูนย์ ส่วน EWMA คือ $\hat\sigma_{t+1}^2=\lambda\hat\sigma_t^2+(1-\lambda)r_t^2$ สองสูตรเป็นสูตรเดียวกันเมื่อ $K=1-\lambda$ แทนค่านี้ลงในสูตรของ $\kappa$ ก็ได้ $\kappa$ จาก $\lambda$

ตรวจด้วยสูตรประมาณจากหน้า แบบจำลองของ Roll: เมื่อ $\kappa$ ใหญ่ $K\approx1/(1+\kappa)=1/17.16=0.058$ ใกล้ค่าจริง 0.06

แปลความหมาย: เลือก $\lambda=0.94$ ก็คือเชื่อว่าเสียงรบกวนของ $r^2$ ดังกว่าการขยับจริงของ variance ในหนึ่งวัน 16.16 เท่า ตัวเลขนี้ฟังขึ้นไหม? ภาพรวมด้านบนหาไว้แล้วว่า ถ้าผลตอบแทนเป็น Normal เสียงรบกวนของ $r^2$ มี SD $\sqrt2$ เท่าของ variance ใส่ระดับ $V=9\times10^{-5}$ จะได้

\[\begin{aligned}\tau_\eta&=\sqrt2\,V=1.27\times10^{-4},\\\frac{\tau_\epsilon}{V}&=\frac{\tau_\eta/\kappa}{V}=\frac{\sqrt2}{\kappa}\\&=\frac{1.4142}{16.16}=8.75\%.\end{aligned}\]

variance จริงจึงขยับวันละราว 8.75% ของระดับปกติ คิดเป็น $0.0875\times9\times10^{-5}=7.9\times10^{-6}$ ในหนึ่งเดือนมันขยับได้มากกว่านั้น หนึ่งเดือนมีราว 21 วันทำการ (ปีละ 252 วันทำการ หารด้วย 12 เดือน) การขยับ 21 ครั้งที่อิสระกันมี variance รวม 21 เท่า SD จึงโต $\sqrt{21}=4.58$ เท่า:

\[8.75\%\times\sqrt{21}=8.75\%\times4.58=40\%\]

ในหนึ่งเดือน variance จริงจึงขยับได้ราว 40% ของระดับปกติ ซึ่งฟังขึ้น: ช้าพอที่ไม่กระโดดทุกวัน แต่เร็วพอที่เปลี่ยนชัดในหนึ่งเดือน

ตรรกะของ EWMA อ่านได้จาก $\kappa$ ตรง ๆ ถ้า variance จริงแทบไม่ขยับ ($\kappa$ ใหญ่) ข้อมูลเก่าทุกวันยังบอกเรื่องเดียวกับวันนี้ จึงควรเฉลี่ยยาว ๆ ($\lambda$ ใกล้ 1) ถ้า variance ขยับเร็ว ($\kappa$ เล็ก) ข้อมูลเก่าล้าสมัยเร็ว จึงควรลืมมันเร็ว

ขั้นที่ 5 — เติม mean reversion: Riccati ที่มี a

แบบจำลอง random walk ข้างบนปล่อยให้ variance เดินไปไหนก็ได้ ติดลบก็ได้ และกระจายกว้างขึ้นเรื่อย ๆ ตามรากที่สองของเวลา แต่ข้อมูลจริงบอกว่าความผันผวนกลับหาระดับปกติเสมอ เราจึงเปลี่ยนบรรทัดแรกเป็น AR(1) รอบ $V$: ส่วนเกินเหนือ $V$ ของพรุ่งนี้เท่ากับ $a$ คูณส่วนเกินของวันนี้ บวกก้อนสุ่ม

จังหวะผสมยังเหมือนเดิม จังหวะเดินหน้าเปลี่ยนไป: ความผิดของค่าประมาณถูกคูณด้วย $a$ เหมือนส่วนเกิน variance ของความผิดจึงคูณ $a^2$ ก่อนบวกก้อนสุ่ม 1 (ในหน่วยของ $\tau_\epsilon^2$) สมการ Riccati จึงมี $a^2$ เพิ่มเข้ามา แก้แบบเดิม คือคูณ $P+\kappa^2$ ทั้งสองข้างแล้วย้ายข้าง จะได้สมการกำลังสองของ $P$ ซึ่งเราเก็บรากบวก

\[ \begin{aligned} x_{t+1}&=V+a(x_t-V)\\ &\quad+\tau_\epsilon\epsilon_{t+1},\\ P&=a^2\frac{P\kappa^2}{P+\kappa^2}+1,\\ P^2+P\kappa^2&=a^2P\kappa^2+P+\kappa^2,\\ 0&=P^2+cP-\kappa^2,\\ c&=(1-a^2)\kappa^2-1,\\ P&=\tfrac12\big(\sqrt{c^2+4\kappa^2}-c\big). \end{aligned} \]

ใส่ตัวเลขของหน้านี้: $a=0.98$ และ $\kappa=16.16$ จากขั้นที่แล้ว จึงได้ $\kappa^2=261.1$

\[ \begin{aligned} c&=(1-0.98^2)(261.1)-1\\ &=0.0396\times261.1-1=9.34,\\ P&=\tfrac12\big(\sqrt{9.34^2+4(261.1)}-9.34\big)\\ &=\tfrac12(\sqrt{1131.7}-9.34)\\ &=\tfrac12(33.64-9.34)=12.150,\\ K&=\frac{P}{P+\kappa^2}=\frac{12.150}{273.26}\\ &=0.04446. \end{aligned} \]

ตรวจว่าสูตรใหม่ครอบสูตรเก่า: เมื่อ $a=1$ จะได้ $c=-1$ สมการกลายเป็น $P^2=P+\kappa^2$ ของ random walk ซึ่งให้ $P=16.667$ และ $K=1/P=0.06$

ที่ $\kappa$ เท่าเดิม mean reversion ทำให้ $K$ ลดจาก 0.06 เป็น 0.04446 เหตุผลคือ variance จริงอยู่ไม่ไกลจาก $V$ ค่าประมาณเดิมจึงน่าเชื่อกว่า และข้อมูลใหม่ได้น้ำหนักน้อยลง ข้อสังเกตนี้คือสิ่งที่ทำให้หลายคนสรุปว่าควรมองย้อนหลังนานขึ้น แต่ระวัง: $K$ คือน้ำหนักในจังหวะผสม ยังไม่ใช่สูตรที่ใช้พยากรณ์ ขั้นถัดไปแสดงว่าสูตรพยากรณ์มี $a$ คูณอยู่ด้วย

ขั้นที่ 6 — สูตรที่ดีที่สุดคือ GARCH(1,1)

ขั้นที่แล้วได้น้ำหนัก $K$ ของจังหวะผสม ขั้นนี้ต่อจังหวะเดินหน้าเข้าไป เพื่อให้ได้สูตรพยากรณ์ของพรุ่งนี้จริง ๆ ให้ $\hat x_{t|t}$ คือค่าประมาณของวันนี้หลังผสมข้อมูลวันนี้แล้ว ค่าที่ดีที่สุดของพรุ่งนี้คือค่าเฉลี่ยของ $x_{t+1}$ เมื่อรู้ข้อมูลถึงวันนี้ ตามบรรทัดแรกของแบบจำลอง AR(1) มันคือ $V+a(\hat x_{t|t}-V)$ เพราะก้อนสุ่มของพรุ่งนี้มีค่าเฉลี่ยศูนย์ แทนจังหวะผสมลงไป แล้วจัดกลุ่มใหม่

\[ \begin{aligned} \hat x_{t|t}&=(1-K)\hat x_{t|t-1}+Ky_t,\\ \hat x_{t+1|t}&=V+a(\hat x_{t|t}-V)\\ &=(1-a)V+aK\,y_t\\ &\quad+a(1-K)\,\hat x_{t|t-1},\\ \omega&=(1-a)V\\ &=0.02\times9\times10^{-5}=1.8\times10^{-6},\\ \alpha&=aK=0.98\times0.04446\\ &=0.04357,\\ \beta&=a(1-K)=0.98\times0.95554\\ &=0.93643. \end{aligned} \]

สูตรที่จัดกลุ่มแล้วคือ GARCH(1,1) ทุกตัวอักษร: ค่าคงที่ $\omega$ บวก $\alpha$ คูณ $r_t^2$ (คือ $y_t$) บวก $\beta$ คูณ variance ที่พยากรณ์ไว้เมื่อวาน (คือ $\hat x_{t|t-1}$) ผลรวม $\alpha+\beta=aK+a(1-K)=a=0.98$ และระดับปกติ $\omega/(1-\alpha-\beta)=(1-a)V/(1-a)=V$ พอดี GARCH จึงไม่ใช่ EWMA ที่เติมค่าคงที่ตามใจ มันคือ Kalman filter ของ variance ที่ดึงกลับหาระดับปกติ

เมื่อ $a=1$ ค่าคงที่หายไป และได้ EWMA คืนมา ทีนี้ดูว่าข้อเสนอในโจทย์เปิดหน้ามาจากไหน ถ้าลืมตัวคูณ $a$ แล้วใช้จังหวะผสม $(1-K)\hat x+Ky$ เป็นสูตรพยากรณ์ตรง ๆ จะได้ EWMA ที่

\[\begin{aligned}\lambda&=1-K=1-0.04446=0.95554,\\h&=\frac{\ln0.5}{\ln0.95554}=15.24\ \text{days}.\end{aligned}\]

นี่คือ half-life 15.2 วันที่เพื่อนร่วมทีมเสนอ

ขั้นที่ 7 — ข้อมูลเก่าหดเร็วขึ้น ไม่ใช่ช้าลง

โจทย์ให้อะไรมาบ้าง: ตอนนี้ตอบคำถามเปิดหน้าได้แล้ว: mean reversion ทำให้ข้อมูลเก่าอยู่นานขึ้นหรือสั้นลง? ขั้นที่ 3 คลี่ GARCH ไว้แล้ว น้ำหนักของ $r^2$ เมื่อ $j$ วันก่อนคือ $\alpha\beta^j$ ทุกวันที่ย้อนไปจึงคูณ $\beta$ อีกหนึ่งครั้ง half-life ของน้ำหนักบนข้อมูลจึงคือ $\ln0.5/\ln\beta$ แยกจากกัน half-life ของการกลับหาระดับปกติคือ $\ln0.5/\ln a$ เพราะส่วนเกินคูณ $a$ ทุกวัน ตารางเทียบทั้งสองตัว โดยใช้ $\kappa=16.16$ เท่ากันทุกแถว และหา $K$ ของแต่ละแถวด้วยสมการ Riccati ที่มี $a$ แบบในขั้นที่ 5

half-life ของข้อมูลจึงสั้นลงจาก 11.20 เป็น 10.55 วัน แล้ว mean reversion ให้อะไรเพิ่ม? มันให้ความรู้ว่า variance อยู่ไม่ไกลจาก $V$ ความรู้นั้นเข้ามาทางค่าคงที่ $\omega=(1-a)V$ ซึ่งทุกวันเอา $V$ มาแทนที่ $1-a=2\%$ ของค่าประมาณ คอลัมน์ “ถ้าลืม $a$” ใช้ $\ln0.5/\ln(1-K)$ แบบข้อเสนอในโจทย์ มันให้คำตอบกลับทิศ: ยิ่ง mean reversion แรง half-life ยิ่งยาว

ขั้นที่ 8 — ได้ดีกว่าเท่าไร: ความผิดของการติดตาม variance จริง

โจทย์ให้อะไรมาบ้าง: รู้แล้วว่า GARCH ที่ได้จาก Kalman ดีที่สุด แต่ดีกว่าเท่าไร? เราวัดในโลกที่สร้างตามแบบจำลอง AR(1) ของหน้านี้:

  • ระดับปกติ $V=9\times10^{-5}$ และแรงดึงกลับ $a=0.98$ (จากโจทย์เปิดหน้า)
  • เสียงรบกวนของ $r^2$: $\tau_\eta=\sqrt2\,V$ (จากภาพรวม)
  • $\kappa=16.16$ ซึ่งคือค่าที่ทำให้ EWMA 0.94 ดีที่สุดในโลก random walk (ขั้นที่ 4) ดังนั้น $\tau_\epsilon=\tau_\eta/\kappa$

ตัวติดตามทุกตัวในตารางเขียนได้รูปเดียวกัน: $f_{t+1}=c+bf_t+gy_t$ โดย $f_{t+1}$ คือค่าพยากรณ์ของพรุ่งนี้ $g$ คือน้ำหนักบนข้อมูลวันนี้ $b$ คือน้ำหนักบนค่าพยากรณ์เดิม และ $c$ คือค่าคงที่ EWMA มี $c=0$, $g=1-\lambda$, $b=\lambda$ ส่วน GARCH มี $c=\omega$, $g=\alpha$, $b=\beta$

ความผิดคือ $f_{t+1}-x_{t+1}$ เราอยากได้ค่าเฉลี่ยของความผิดยกกำลังสอง (MSE) ซึ่งแยกได้เป็นสามก้อน: variance ของค่าพยากรณ์ บวก variance ของค่าจริง ลบสองเท่าของ covariance ระหว่างกัน ทุกก้อนต้องรู้ว่า $x$ ของสองวันเกี่ยวกันแค่ไหน ใน AR(1) ความเกี่ยวนี้หดลง $a$ เท่าทุกวันที่ห่างกัน:

\[ \begin{aligned} s^2&=a^2s^2+\tau_\epsilon^2\ \Rightarrow\ s^2=\frac{\tau_\epsilon^2}{1-a^2},\\ \operatorname{Cov}(x_t,x_{t-k})&=s^2a^k,\\ f_{t+1}&=\text{const}+g\sum_{j\ge0}b^j y_{t-j},\\ \operatorname{Cov}(f_{t+1},x_{t+1})&=g\sum_{j\ge0}b^js^2a^{j+1}\\ &=\frac{gs^2a}{1-ab},\\ \text{MSE}&=g^2A+s^2-\frac{2gs^2a}{1-ab},\\ A&=\frac{\tau_\eta^2}{1-b^2}\\ &\quad+\frac{s^2(1+ab)}{(1-b^2)(1-ab)}. \end{aligned} \]

variance จริง $x$ เองก็แกว่งไปมา $s^2$ คือ variance ของการแกว่งนั้น บรรทัดแรกของ AR(1) บอกว่า $\operatorname{Var}(x_{t+1})=a^2\operatorname{Var}(x_t)+\tau_\epsilon^2$ เมื่อนิ่งแล้วสองวันต้องเท่ากัน จึงได้แถวแรก ค่าพยากรณ์ $f$ คือผลรวมของข้อมูลเก่าที่ถ่วงด้วย $b^j$ (คลี่แบบเดียวกับขั้นที่ 1) covariance กับค่าจริงจึงเป็นอนุกรมเรขาคณิตที่อัตราส่วน $ab$ ส่วน $g^2A$ คือ variance ของ $f$ เอง มันมีสองส่วน: เสียงรบกวนของ $y$ ซึ่งอิสระกันทุกวัน รวมได้ $\tau_\eta^2/(1-b^2)$ และส่วนของ $x$ ซึ่งเป็นอนุกรมเรขาคณิตสองชั้น (ผลรวมของ $b^{j}b^{k}a^{|j-k|}$ ทุกคู่ $j,k$) รวมได้ก้อนที่สอง

ตรวจเองใน 10 วินาที: ทุกตัวต่ำกว่า 43.98% ของการใช้ $V$ ตรง ๆ และ GARCH ต่ำที่สุด เพราะมันคือ Kalman filter ซึ่งเป็นวิธีผสมสองแหล่งข้อมูลที่ดีที่สุดในบรรดาสูตรเชิงเส้นทั้งหมด

ขั้นที่ 9 — อ่าน GARCH ใด ๆ ในภาษาของ Kalman

ในงานจริง หลายโต๊ะ fit GARCH จากข้อมูล คือหาค่า $\omega$, $\alpha$, $\beta$ ที่เข้ากับข้อมูลที่สุด ขั้นนี้แสดงวิธีอ่านว่า GARCH ที่ได้มาเชื่ออะไรเกี่ยวกับโลก โดยกลับทางสูตรของขั้นที่ 6 จาก $\alpha=aK$, $\beta=a(1-K)$ และ $\omega=(1-a)V$ เราอ่าน $a$, $K$ และ $V$ ได้ทันที ลองกับ GARCH ในหน้า ARCH/GARCH ที่ $\omega=1.8\times10^{-6}$, $\alpha=0.09$, $\beta=0.89$

\[ \begin{aligned} a&=\alpha+\beta=0.09+0.89=0.98,\\ K&=\alpha/a=0.09/0.98=0.09184,\\ V&=\frac{\omega}{1-a}=\frac{1.8\times10^{-6}}{0.02}\\ &=9\times10^{-5}. \end{aligned} \]

ตัวที่เหลือคือ $\kappa$ ซึ่งกลับสูตรตรง ๆ ไม่ได้ เราจึงลองค่า $\kappa$ ไปเรื่อย ๆ จนสมการ Riccati ที่มี $a$ ให้ $K=0.09184$ (โค้ดท้ายหน้าใช้วิธีแบ่งครึ่งช่วง หรือ bisection) ได้ $\kappa=8.80$ ตรวจโดยใส่กลับลงในสูตรของขั้นที่ 5 ด้วย $\kappa^2=8.80^2=77.44$:

\[ \begin{aligned} c&=(1-0.98^2)(77.44)-1\\ &=0.0396\times77.44-1=2.067,\\ P&=\tfrac12\big(\sqrt{2.067^2+4(77.44)}-2.067\big)\\ &=\tfrac12(17.72-2.067)=7.827,\\ K&=\frac{7.827}{7.827+77.44}=0.0918. \end{aligned} \]

GARCH ตัวนี้คือ Kalman filter ของโลกที่ variance ดึงกลับด้วย $a=0.98$ เหมือนกัน แต่มันเชื่อว่าเสียงรบกวนของ $r^2$ ดังกว่าการเปลี่ยนจริงแค่ 8.80 เท่า ไม่ใช่ 16.16 เท่า มันจึงให้น้ำหนักข่าวใหม่มากกว่า ($K=0.0918$ เทียบกับ 0.0445)

ผลเห็นได้จากวันร่วง 4% ในขั้นที่ 2 (เมื่อวานพยากรณ์ไว้ 1%) ขั้นนั้นคิดไว้แล้วว่าพรุ่งนี้ GARCH ตัวนี้ตอบ 1.532% และ EWMA ตอบ 1.378% ส่วนตัวกรองที่ $\kappa=16.16$ ใช้ $\omega$, $\alpha$, $\beta$ ของขั้นที่ 6 กับสูตรเดียวกัน:

\[\begin{aligned}f_1&=0.0000018+0.04357(0.0016)\\&\quad+0.93643(0.0001)\\&=0.0001652,\\\sqrt{f_1}&=1.285\%,\\f_{61}&=0.00009+0.2976(0.0000752)\\&=0.0001124,\\\sqrt{f_{61}}&=1.060\%.\end{aligned}\]

อีก 60 วันหลังจากพรุ่งนี้ GARCH ตัวนี้เหลือ 1.154% ตัวกรองที่ $\kappa=16.16$ เหลือ 1.060% ส่วน EWMA ยัง 1.378%

แล้วตัวไหนดีกว่า? ในโลกที่ $\kappa=16.16$ จริง ใส่ $g=0.09$, $b=0.89$ ลงในสูตร MSE ของขั้นที่ 8 จะได้ความผิด 33.88% แย่กว่า EWMA เดิม (33.54%) ข้อสรุปคือ GARCH ไม่ได้ดีกว่าโดยอัตโนมัติ ค่าของมันต้องตรงกับเสียงรบกวนของข้อมูล

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

ใช้ EWMA ตอบคำถามระยะยาว: คำพยากรณ์หลายวันของ EWMA แบนตลอดไป จึงไม่เคยกลับหาระดับปกติ หลังวันร่วง 4% ในขั้นที่ 2 สองสูตรตอบความผันผวนของอีก 60 วันหลังพรุ่งนี้ต่างกัน:

\[\begin{aligned}\text{EWMA: }\sqrt{f_{61}}&=\sqrt{f_1}=1.378\%,\\\text{GARCH: }\sqrt{f_{61}}&=\sqrt{V+0.98^{60}(f_1-V)}\\&=1.154\%.\end{aligned}\]

งานตั้งราคา option ระยะยาวและการวางแผนเงินทุนจึงต้องใช้แบบจำลองที่มีระดับปกติ

ยืด half-life เพราะ mean reversion: ความคิดนี้ลืมตัวคูณ $a$ ในสูตรพยากรณ์ ผลคือได้ตัวเลขผิดทิศ:

\[\begin{aligned}\text{wrong: }\lambda&=1-K=0.9555,\ h=15.24,\\\text{right: }\beta&=a(1-K)=0.9364,\ h=10.55.\end{aligned}\]

สูตรที่ถูกให้ข้อมูลเก่าหดเร็วขึ้น แล้วเติมค่าคงที่ $\omega$ ความผิดของการติดตามจึงเป็น 30.51% ส่วนการยืดเป็น 15.24 วันได้ 32.82%

ใช้ $\lambda$ เดียวกันกับทุกสินทรัพย์: $\lambda$ ที่ดีที่สุดคือ $1-K$ และ $K$ มาจาก $\kappa$ ของสินทรัพย์นั้น สินทรัพย์ที่ variance เปลี่ยนเร็วเมื่อเทียบกับเสียงรบกวนของ $r^2$ ($\kappa$ เล็ก) ควรใช้ $\lambda$ เล็กกว่า เช่นที่ $\kappa=5$ ไม่มี mean reversion (คิดละเอียดในโจทย์ข้อ 3):

\[\begin{aligned}P&=\tfrac12\big(1+\sqrt{1+4\kappa^2}\big)=5.525,\\\lambda&=1-\frac1P=0.819,\\h&=\frac{\ln0.5}{\ln0.819}=3.47\ \text{days}.\end{aligned}\]

ถ้าใช้ 0.94 ตามหุ้นอื่น half-life จะเป็น 11.20 วัน ยาวกว่าที่ควร $11.20/3.47=3.2$ เท่า

ปรับ $\lambda$ จนกว่า backtest จะสวย: backtest คือการลองสูตรกับข้อมูลในอดีต ถ้าจูน $\lambda$ จนผลในอดีตดูดี เรากำลัง fit เสียงรบกวนของอดีต แบบจำลองบอกว่า $\lambda$ ควรมาจากสมบัติของข้อมูล คือ $\kappa$ และ $a$ เช่นในโลกของหน้านี้ ($a=0.98$, $\kappa=16.16$) EWMA ที่ดีที่สุดคือ $\lambda=0.9592$

เชื่อ GARCH ที่ fit มาโดยไม่อ่าน $\kappa$ ของมัน: GARCH ไม่ได้ดีกว่า EWMA เสมอ ในโลกที่ $\kappa=16.16$ GARCH ที่ $\alpha=0.09$, $\beta=0.89$ (ซึ่งเชื่อ $\kappa=8.80$) ได้ความผิด 33.88% แย่กว่า EWMA 0.94 ที่ได้ 33.54% ส่วน GARCH ที่ตรงกับโลก ($\alpha=0.04357$, $\beta=0.93643$) ได้ 30.51%

ใช้ทำอะไรบนโต๊ะจริง

risk model เชิงพาณิชย์ใช้ EWMA กับหุ้นทุกตัวที่ครอบคลุม ด้วย half-life ที่เลือกจากการทดสอบ และบอกลูกค้าเป็น half-life แทน $\lambda$ ส่วนโต๊ะที่ต้องการคำพยากรณ์หลายวัน เช่นการตั้งราคา option หรือการกันเงินทุนสำรอง ใช้ GARCH ที่ $\alpha+\beta\lt1$ เพราะมันมีระดับปกติให้กลับไปหา

GARCH ที่ fit มามีเหตุผลไหม? ตรวจได้โดยอ่าน $\kappa$ และ $a$ ของมันแบบขั้นที่ 9 แล้วเทียบกับเสียงรบกวนของ $r^2$ ที่วัดได้จริง

อีกทางหนึ่งคือเปลี่ยนข้อมูล realized variance (variance ที่คิดจากราคาระหว่างวันทีละไม่กี่นาที) ใช้แทน $r^2$ ได้ มันมีเสียงรบกวนน้อยกว่ามาก $\tau_\eta$ จึงเล็กลง $\kappa=\tau_\eta/\tau_\epsilon$ ก็เล็กลง และตัวกรองตามความผันผวนได้เร็วขึ้น หน้า การปรับความผันผวนระยะสั้น ของ factor model ต่อยอดเรื่องนี้

แบบจำลองสองบรรทัดมีจุดอ่อนสองข้อ ข้อแรก variance ในแบบจำลองติดลบได้ ข้อสอง เสียงรบกวนของ $r^2$ ไม่ใช่ Normal และขนาดของมันโตตาม variance เอง แบบจำลองของ Harvey และ Shephard แก้ทั้งสองข้อโดยใช้ $\ln r_t^2$ เป็นข้อมูล ถ้า $r_t=\sigma_t\xi_t$ กับ $\xi_t$ เป็น Normal มาตรฐาน log จะเปลี่ยนการคูณเป็นการบวก:

\[\begin{aligned}\ln r_t^2&=\ln\sigma_t^2+\ln\xi_t^2,\\\mathbb E[\ln\xi_t^2]&=-\gamma-\ln2\\&=-0.5772-0.6931=-1.27,\\\operatorname{SD}(\ln\xi_t^2)&=\sqrt{\pi^2/2}=2.22.\end{aligned}\]

$\gamma=0.5772$ คือค่าคงที่ของ Euler ทั้งสองค่าเป็นสมบัติของ Normal ที่หาได้จากการอินทิเกรต ตอนนี้เสียงรบกวน $\ln\xi_t^2$ มีขนาดคงที่ ไม่ขึ้นกับ $\sigma_t$ หักค่าเฉลี่ย −1.27 ออก แล้วใช้ Kalman filter แบบเดียวกันกับ $\ln\sigma^2$ ที่เดินแบบ AR(1) ความผันผวนที่ได้ $e^{\hat x/2}$ เป็นบวกเสมอ

โจทย์ตรวจความเข้าใจ

1. ทีมความเสี่ยงอีกทีมหนึ่งใช้ EWMA ที่ $\lambda=0.97$ (สมมติ) ซึ่งลืมข้อมูลเก่าช้ากว่า 0.94 หัวหน้าทีมอยากรู้สามเรื่อง: half-life กี่วัน การเลือกนี้เท่ากับเชื่อว่า $\kappa$ เป็นเท่าไร และ 20 วันล่าสุดได้น้ำหนักรวมเท่าไร?

เฉลย

ใช้สูตร half-life ของขั้นที่ 1 สูตร $\kappa$ ของขั้นที่ 4 และน้ำหนักรวมของ $n$ วันล่าสุด $1-\lambda^n$:

\[\begin{aligned}h&=\frac{\ln0.5}{\ln0.97}=\frac{-0.6931}{-0.03046}\\&=22.76\ \text{days},\\\kappa&=\frac{\sqrt{0.97}}{0.03}=\frac{0.9849}{0.03}=32.83,\\1-0.97^{20}&=1-0.5438=45.6\%.\end{aligned}\]

$\kappa$ ของทีมนี้คือ $32.83/16.16=2.03$ เท่าของกรณี 0.94 แปลว่าเขาเชื่อว่าเสียงรบกวนดังกว่าการขยับจริงมากกว่าราวสองเท่า และ 20 วันล่าสุดได้น้ำหนักไม่ถึงครึ่ง

2. โต๊ะ option fit GARCH กับหุ้นตัวหนึ่ง ได้ $\omega=2\times10^{-6}$, $\alpha=0.05$, $\beta=0.90$ (สมมติ) อ่านในภาษาของ Kalman ได้ $a$, $K$, $V$ เท่าไร และ half-life ของน้ำหนักบนข้อมูลกับของการกลับหาระดับปกติคือกี่วัน?

เฉลย

อ่านแบบขั้นที่ 9:

\[\begin{aligned}a&=\alpha+\beta=0.05+0.90=0.95,\\K&=\alpha/a=0.05/0.95=0.05263,\\V&=\frac{\omega}{1-a}=\frac{2\times10^{-6}}{0.05}=4\times10^{-5},\\h_{\text{data}}&=\frac{\ln0.5}{\ln0.90}=\frac{-0.6931}{-0.1054}=6.58,\\h_{\text{revert}}&=\frac{\ln0.5}{\ln0.95}=\frac{-0.6931}{-0.0513}=13.51.\end{aligned}\]

ระดับปกติคิดเป็นความผันผวน $\sqrt{0.00004}=0.632\%$ ต่อวัน น้ำหนักบนข้อมูลหดครึ่งทุก 6.58 วัน ส่วนเกินเหนือ $V$ หดครึ่งทุก 13.51 วัน ส่วน $\kappa$ หาโดยลองค่าจนสมการ Riccati ที่มี $a$ ให้ $K=0.05263$ ได้ $\kappa=11.14$ ตรวจโดยใส่กลับด้วย $\kappa^2=124.1$:

\[\begin{aligned}c&=(1-0.95^2)(124.1)-1=11.10,\\P&=\tfrac12\big(\sqrt{11.10^2+4(124.1)}-11.10\big)\\&=\tfrac12(24.89-11.10)=6.90,\\K&=\frac{6.90}{6.90+124.1}=0.0527.\end{aligned}\]

3. หุ้นตัวหนึ่งมี variance ที่เปลี่ยนเร็วมากเมื่อเทียบกับเสียงรบกวนของ $r^2$: วัดได้ $\kappa=5$ (สมมติ) และสมมติว่าไม่มี mean reversion EWMA ที่ดีที่สุดสำหรับหุ้นนี้มี $\lambda$ และ half-life เท่าไร? ตรวจคำตอบด้วยสูตร $\kappa=\sqrt\lambda/(1-\lambda)$

เฉลย

ไม่มี mean reversion จึงใช้สมการ Riccati ของ random walk $P^2=P+\kappa^2$ จากขั้นที่ 4 แล้วเก็บรากบวก:

\[\begin{aligned}P&=\tfrac12\big(1+\sqrt{1+4(25)}\big)\\&=\tfrac12(1+\sqrt{101})=5.5249,\\K&=1/P=0.1810,\\\lambda&=1-K=0.8190,\\h&=\frac{\ln0.5}{\ln0.819}=\frac{-0.6931}{-0.1997}\\&=3.47\ \text{days},\\\text{check: }\kappa&=\frac{\sqrt{0.819}}{0.181}=\frac{0.9050}{0.181}=5.00.\end{aligned}\]

คำนวณซ้ำด้วย JavaScript

โค้ดนี้รันใน Node.js ได้โดยไม่ต้องติดตั้งแพ็กเกจ มันคำนวณตัวเลขทุกตัวในหน้านี้ซ้ำ:

  • half-life และการแปลง $\lambda$ เป็น $\kappa$
  • สมการ Riccati ที่มี $a$ ทั้งด้วยสูตรปิดและด้วยการวนซ้ำ ซึ่งต้องได้คำตอบเดียวกัน
  • การแปลง Kalman เป็น GARCH และกลับ (หา $\kappa$ ด้วย bisection)
  • ความผิดของการติดตามจากสูตร MSE และการลอง $\lambda$ ทุกค่าเพื่อหา EWMA ที่ดีที่สุด
  • การยืนยันว่า EWMA กับ GARCH ที่ $\omega=0$ ให้ผลเท่ากันทุกบิต
  • การจำลองโลก AR(1) 200,000 วัน

const {sqrt, log, cos, sin, PI} = Math;

const halfLife = lambda => log(0.5) / log(lambda);
// random-walk variance: P = 1/K in units of tau_e^2, so kappa = sqrt(lambda) / (1 - lambda)
const kappaFromLambda = lambda => sqrt(lambda) / (1 - lambda);
// P = a^2 P k^2 / (P + k^2) + 1  gives  P^2 + c P - k^2 = 0 with c = (1 - a^2) k^2 - 1
function steadyGain(kappa, a = 1) {
  const R = kappa * kappa, c = (1 - a * a) * R - 1, P = 0.5 * (sqrt(c * c + 4 * R) - c);
  return {c, P, K: P / (P + R)};
}
function iteratedGain(kappa, a = 1, steps = 5000) {
  const R = kappa * kappa;
  let P = 1;
  for (let i = 0; i < steps; i++) P = a * a * P * R / (P + R) + 1;
  return P / (P + R);
}
// the steady Kalman filter written as GARCH(1,1)
function kalmanToGarch({kappa, a, V}) {
  const {K, P} = steadyGain(kappa, a);
  return {K, P, omega: (1 - a) * V, alpha: a * K, beta: a * (1 - K)};
}
// read a GARCH(1,1) back as a Kalman filter; kappa by bisection on the gain (K falls as kappa grows)
function garchToKalman({omega, alpha, beta}) {
  const a = alpha + beta;
  if (!(a < 1)) throw new RangeError('alpha + beta must be below 1 for a long-run level');
  const K = alpha / a;
  let lo = 1e-6, hi = 1e6;
  for (let i = 0; i < 300; i++) { const mid = sqrt(lo * hi); if (steadyGain(mid, a).K > K) lo = mid; else hi = mid; }
  return {a, K, V: omega / (1 - a), kappa: sqrt(lo * hi)};
}
// steady MSE of a tracker f(t+1) = c + b f(t) + g y(t) when x is AR(1) around V
function trackingMse({g, b}, {a, tauE, tauH}) {
  const s2 = tauE * tauE / (1 - a * a);
  return g * g * (tauH * tauH / (1 - b * b) + s2 * (1 + a * b) / ((1 - b * b) * (1 - a * b))) + s2 - 2 * g * s2 * a / (1 - a * b);
}
function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}
function normals(rnd) {
  let spare = null;
  return () => {
    if (spare !== null) { const s = spare; spare = null; return s; }
    let u = 0;
    while (u === 0) u = rnd();
    const v = rnd(), R = sqrt(-2 * log(u));
    spare = R * sin(2 * PI * v);
    return R * cos(2 * PI * v);
  };
}
// simulate the AR(1) variance world and run several trackers on the same data
function simulateTracking(n, seed, world, trackers) {
  const z = normals(mulberry32(seed)), x = new Float64Array(n + 1), y = new Float64Array(n);
  const f = trackers.map(() => new Float64Array(n + 1).fill(world.V));
  x[0] = world.V;
  for (let t = 0; t < n; t++) {
    y[t] = x[t] + world.tauH * z();
    trackers.forEach((k, i) => { f[i][t + 1] = k.c + k.b * f[i][t] + k.g * y[t]; });
    x[t + 1] = world.V + world.a * (x[t] - world.V) + world.tauE * z();
  }
  const rmse = f.map(fi => { let s = 0; for (let t = 1001; t <= n; t++) s += (fi[t] - x[t]) ** 2; return sqrt(s / (n - 1000)) / world.V; });
  return {y, rmse};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • EWMA ให้น้ำหนัก $(1-\lambda)\lambda^i$ กับข้อมูลของ $i$ วันก่อน และน้ำหนักรวมเป็น 1 ที่ $\lambda=0.94$ half-life คือ $\ln0.5/\ln0.94=11.20$ วัน คำพยากรณ์หลายวันของ EWMA แบนตลอดไป
  • GARCH ที่คลี่แล้วคือ EWMA บวกค่าคงที่ ทั้งสองเท่ากันเมื่อ $\omega=0$, $\alpha=1-\lambda$, $\beta=\lambda$
  • EWMA คือ Kalman filter ของ variance ที่เดินแบบ random walk โดย $\kappa=\sqrt\lambda/(1-\lambda)$ เลือก 0.94 ก็คือเชื่อว่าเสียงรบกวนของ $r^2$ ดังกว่าการเปลี่ยนจริง 16.16 เท่า
  • เมื่อ variance ถูกดึงกลับด้วย $a$ สูตรที่ดีที่สุดคือ GARCH ที่ $\omega=(1-a)V$, $\alpha=aK$, $\beta=a(1-K)$ ที่ $a=0.98$ ได้ $\alpha=0.04357$ และ $\beta=0.93643$ ข้อมูลเก่าจึงหดเร็วขึ้น (10.55 วัน) ไม่ใช่ช้าลง
  • ในโลกตัวอย่าง ความผิดของการติดตามคือ 30.51% สำหรับ GARCH จาก Kalman และ 32.78% สำหรับ EWMA ที่ดีที่สุด GARCH ที่ $\alpha=0.09$, $\beta=0.89$ อ่านได้ว่าเชื่อ $\kappa=8.80$ จึงแย่กว่า EWMA ในโลกนี้ (33.88%)

บทนี้จบที่หุ้นทีละตัว: ผลตอบแทนที่สะอาด นิสัยของมัน ราคาที่วัดผิด ความผันผวนที่วัดได้ และการเดินมันไปข้างหน้า บทถัดไปเริ่มจากหุ้นหลายพันตัวพร้อมกัน ซึ่งสิ่งที่สำคัญที่สุดคือการที่พวกมันขยับไปด้วยกัน อ่านต่อที่ สมการของ factor model
