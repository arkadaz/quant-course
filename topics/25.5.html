25.5 EWMA, the Kalman Filter, and GARCH as EWMA with an Offset

EWMA คือค่าประมาณที่ดีที่สุดของ variance ที่เดินแบบ random walk เมื่อมองผ่าน $r^2$ ที่มีเสียงรบกวน และเมื่อ variance ดึงกลับหาระดับปกติ สูตรที่ดีที่สุดกลายเป็น GARCH(1,1) ซึ่งคือ EWMA ที่มีค่าคงที่เพิ่มหนึ่งตัว

ระบบความเสี่ยงของธนาคารใช้ EWMA ที่ $\lambda=0.94$ กับทุกหุ้น ทีมวิจัยพบว่า variance จริงของหุ้นดึงกลับหาระดับปกติ $9\times10^{-5}$ (ความผันผวน 0.949% ต่อวัน) ด้วยความจำ 0.98 ต่อวัน เพื่อนร่วมทีมอ่านเจอว่า “mean reversion ทำให้ข้อมูลเก่ามีค่ามากขึ้น” จึงเสนอให้ยืด half-life จาก 11.2 วันเป็น 15.2 วัน ข้อเสนอนี้ถูกไหม และสูตรที่ดีที่สุดคืออะไร?

ลองตอบก่อนเปิดเฉลย

ยืดแล้วดีขึ้นนิดเดียว ความผิดของการติดตาม variance จริงลดจาก 33.54% เป็น 32.82% ของระดับปกติ และไม่มี EWMA ตัวไหนดีกว่า 32.78% สูตรที่ดีที่สุดคือ GARCH(1,1) ที่ $\omega=1.8\times10^{-6}$, $\alpha=0.0436$, $\beta=0.9364$ ได้ 30.51% และในสูตรนั้นน้ำหนักของข้อมูลเก่าหดครึ่งทุก 10.55 วัน สั้นกว่าเดิม ข้อมูลที่ mean reversion ให้เพิ่มไม่ได้ไปอยู่ในข้อมูลเก่า แต่ไปอยู่ในค่าคงที่ที่ดึงคำตอบกลับหาระดับปกติ

ภาพรวมก่อนลงสูตร

ความผันผวนของวันนี้มองไม่เห็นตรง ๆ สิ่งที่เห็นคือผลตอบแทนของวัน และ $r_t^2$ ของวันเดียวเป็นค่าประมาณ variance ที่แกว่งแรงมาก: โดยเฉลี่ยเท่ากับ variance แต่บางวันเกือบศูนย์ บางวันหลายเท่า วิธีมาตรฐานของอุตสาหกรรมคือเฉลี่ย $r^2$ ย้อนหลังด้วยน้ำหนักที่ลดลงแบบ exponential เรียกว่า EWMA ผู้ให้บริการ risk model เชิงพาณิชย์อย่าง RiskMetrics, Barra และ Axioma ใช้มัน เพราะมี parameter ตัวเดียวที่ใช้ร่วมกันได้ทุกหุ้นและอธิบายลูกค้าง่าย ส่วนงานวิชาการชอบ GARCH มากกว่า

หน้านี้ตอบว่าสองสูตรต่างกันจริงแค่ไหน และมาจากไหน: คลี่ GARCH แล้วจะเห็นว่ามันคือ EWMA บวกค่าคงที่ จากนั้นใช้แบบจำลองสองบรรทัดเดียวกับราคาที่วัดผิดใน แบบจำลองของ Roll เปลี่ยนแค่ความหมาย: สถานะคือ variance จริง ข้อมูลคือ $r_t^2$ ถ้า variance เดินแบบ random walk ค่าประมาณที่ดีที่สุดคือ EWMA ถ้ามันดึงกลับหาระดับปกติ ค่าประมาณที่ดีที่สุดคือ GARCH(1,1) แล้ววัดว่าได้ดีกว่ากันเท่าไร

รูปด้านล่างคือ EWMA ที่ $\lambda=0.94$ ไล่ตามความผันผวนที่กระโดดขึ้นแล้วลง

ขั้นที่ 1 — EWMA และ half-life

นี่คือนิยามของ EWMA: variance ของพรุ่งนี้คือส่วนผสมของ $r_t^2$ ของวันนี้กับค่าประมาณเดิม แทนสมการของเมื่อวานลงไปซ้ำ ๆ จะเห็นน้ำหนักที่ข่าวของแต่ละวันได้

\[ \begin{aligned} \hat\sigma_{t+1}^2&=(1-\lambda)r_t^2+\lambda\hat\sigma_t^2\\ &=(1-\lambda)\sum_{i=0}^{\infty}\lambda^{i}r_{t-i}^2,\\ (1-\lambda)\sum_{i\ge0}\lambda^i&=1,\\ \lambda^h=\tfrac12:&\quad h=\frac{\ln0.5}{\ln0.94}\\ &\quad=11.20\ \text{days}. \end{aligned} \]

ข่าวของวันนี้ได้น้ำหนัก $1-\lambda=0.06$ ข่าวเมื่อ $i$ วันก่อนได้ $0.06(0.94)^i$ ไม่มีวันไหนหลุดออกทันที ต่างจากหน้าต่าง 20 วันที่ข่าววันที่ 21 หายทั้งก้อน น้ำหนักรวมเป็น 1 พอดี (ผลบวกของอนุกรมเรขาคณิต) และ 12 วันล่าสุดได้น้ำหนักรวม $1-0.94^{12}=52.4\%$ สูตรนี้ใช้หน่วยความจำแค่ตัวเลขเดียวต่อหุ้น จึงคิดกับหุ้นหลายพันตัวได้ทุกวัน

half-life 11.2 วันสื่อสารง่ายกว่า $\lambda=0.94$ แต่ต้องระวัง: ใกล้ 1 ตัวเลขเล็ก ๆ ของ $\lambda$ ขยับ half-life มาก 0.97 ให้ 22.76 วัน และ 0.99 ให้ 68.97 วัน

ขั้นที่ 2 — คำพยากรณ์หลายวันของ EWMA แบนตลอดไป

พยากรณ์หลายวันข้างหน้าต้องใส่ $r^2$ ของวันที่ยังไม่มาถึง ค่าที่ดีที่สุดที่ใส่ได้คือค่าเฉลี่ยของมัน ซึ่งคือ variance ที่พยากรณ์ไว้เอง แทนลงในสูตรของ EWMA ตัวอย่าง: เมื่อวานพยากรณ์ความผันผวน 1% วันนี้ตลาดร่วง 4%

\[ \begin{aligned} f_{h+1}&=(1-\lambda)f_h+\lambda f_h=f_h,\\ -4\%:&\quad0.06(0.0016)+0.94(0.0001)\\ &\quad=0.00019,\\ &\quad\sqrt{0.00019}=1.378\%. \end{aligned} \]

เพราะน้ำหนักรวมเป็น 1 พอดี คำพยากรณ์ของวันถัดไปจึงเท่ากับของวันนี้ และเท่าเดิมไปทุกวัน หลังวันร่วง 4% EWMA ตอบ 1.378% ทั้งสำหรับพรุ่งนี้และอีกหกสิบวัน GARCH(1,1) ที่ $\omega=1.8\times10^{-6}$, $\alpha=0.09$, $\beta=0.89$ (ตัวอย่างในหน้า ARCH/GARCH) ตอบ $\sqrt{1.8\times10^{-6}+0.09(0.0016)+0.89(0.0001)}=1.532\%$ สำหรับพรุ่งนี้ แล้วเดินกลับหาระดับปกติ 0.949% เหลือ 1.154% อีก 60 วันหลังจากพรุ่งนี้

ขั้นที่ 3 — คลี่ GARCH: EWMA บวกค่าคงที่

วางสองสูตรข้างกัน คลี่ GARCH(1,1) $\hat\sigma_{t+1}^2=\omega+\alpha r_t^2+\beta\hat\sigma_t^2$ ด้วยการแทนค่าของเมื่อวานลงไปซ้ำ ๆ ก้อน $\omega$ สะสมเป็นอนุกรมเรขาคณิต $\omega(1+\beta+\beta^2+\cdots)$ ส่วน EWMA คลี่ไว้แล้วข้างบน ความเหมือนจะเห็นทันที

\[ \begin{aligned} \text{GARCH}:&\quad\hat\sigma_{t+1}^2=\frac{\omega}{1-\beta}\\ &\qquad+\alpha\sum_{i\ge0}\beta^{i}r_{t-i}^2,\\ \text{EWMA}:&\quad\hat\sigma_{t+1}^2=(1-\lambda)\sum_{i\ge0}\lambda^{i}r_{t-i}^2,\\ \text{same}:&\quad\omega=0,\ \alpha=1-\lambda,\ \beta=\lambda. \end{aligned} \]

สองสูตรต่างกันแค่ก้อนคงที่ข้างหน้า EWMA จึงคือ GARCH ที่ไม่มีค่าคงที่ และเมื่อไม่มีค่าคงที่ น้ำหนักรวม $\alpha/(1-\beta)$ ต้องเป็น 1 พอดี ไม่อย่างนั้นค่าประมาณจะไหลไปหาศูนย์หรือโตไม่หยุด นั่นคือ $\alpha+\beta=1$ หรือ IGARCH

ในทางกลับกัน GARCH คือ EWMA ที่น้ำหนักรวมบนข้อมูลน้อยกว่า 1 แล้วเติมส่วนที่ขาดด้วยค่าคงที่ ถ้าใช้ GARCH ได้ทำไมอุตสาหกรรมยังใช้ EWMA? ไม่มีเหตุผลเชิงหลักการ มีแต่เหตุผลเชิงปฏิบัติ: parameter ตัวเดียวที่ใช้ร่วมกันได้ทุกหุ้น ไม่ต้องประมาณสามค่าต่อหุ้น และอธิบายลูกค้าง่าย ส่วนที่เติม mean reversion ด้านล่างจะแสดงว่าค่าคงที่ของ GARCH มีความหมาย ไม่ได้เป็นแค่ก้อนที่เติมให้ครบ

ขั้นที่ 4 — EWMA คือ Kalman filter ของ variance ที่เดินแบบ random walk

ถามว่ามีแบบจำลองไหนที่ EWMA เป็นคำตอบที่ถูกต้อง ไม่ใช่แค่สะดวก ใช้สองบรรทัดเดียวกับราคาจริงและราคาที่บันทึก เปลี่ยนแค่ความหมาย: สถานะคือ variance จริง $x_t$ ข้อมูลคือ $y_t=r_t^2$ ซึ่งค่าเฉลี่ยเท่ากับ $x_t$ แต่แกว่งแรง นี่คือนิยามของแบบจำลอง (แบบจำลองของ Muth) ส่วนสมการ Riccati ของน้ำหนักที่นิ่งมาจากการ “ผสมแล้วเดินต่อ” แบบเดียวกับตัวกรองราคา โดยวัด $P$ เป็นหน่วย $\tau_\epsilon^2$

\[ \begin{aligned} x_{t+1}&=x_t+\tau_\epsilon\,\epsilon_{t+1},\\ y_t&=x_t+\tau_\eta\,\eta_t,\\ P^2&=P+\kappa^2,\quad K=\frac{P}{P+\kappa^2},\\ K&=\frac{P}{P^2}=\frac1P,\\ \kappa^2&=P^2-P=\frac{1-K}{K^2},\\ \kappa&=\frac{\sqrt\lambda}{1-\lambda}=\frac{\sqrt{0.94}}{0.06}\\ &=16.16. \end{aligned} \]

บรรทัดที่สามคือสมการ Riccati ของตัวกรองราคาที่เขียนในหน่วย $\tau_\epsilon^2$ ตัวส่วน $P+\kappa^2$ เท่ากับ $P^2$ พอดี $K$ จึงเป็น $1/P$ แล้วกลับสูตรได้ $\kappa$ จาก $\lambda=1-K$ ค่าประมาณที่ได้คือ $\hat x_{t+1|t}=(1-K)\hat x_{t|t-1}+Ky_t$ ซึ่งคือ EWMA ทุกตัวอักษร เมื่อ $\kappa$ ใหญ่ $K$ ใกล้ $1/(1+\kappa)$: ที่ $\kappa=16.16$ สูตรประมาณให้ 0.058 เทียบค่าจริง 0.06

$\lambda=0.94$ จึงแปลว่าเสียงรบกวนของ $r^2$ ดังกว่าการเปลี่ยนจริงของ variance ต่อวัน 16.16 เท่า ถ้าผลตอบแทนเป็น Normal เสียงรบกวนของ $r^2$ คือ $\sqrt2V=1.27\times10^{-4}$ ที่ $V=9\times10^{-5}$ variance จริงจึงเปลี่ยนวันละราว $7.9\times10^{-6}$ หรือ 8.75% ของระดับปกติ ซึ่งฟังขึ้น ตรรกะของ EWMA อ่านได้ตรง ๆ: ถ้าสถานะไม่เปลี่ยนเลย ทุกข้อมูลในอดีตมีค่าเท่ากัน ควรใช้ให้หมด (half-life ยาว) ถ้าสถานะเปลี่ยนเร็ว ($\kappa$ เล็ก) ควรลืมอดีตเร็ว

ขั้นที่ 5 — เติม mean reversion: Riccati ที่มี a

แบบจำลองข้างบนปล่อยให้ variance เดินไปไหนก็ได้ ติดลบก็ได้ และกระจายกว้างขึ้นตามรากที่สองของเวลา ซึ่งขัดกับข้อมูลที่ความผันผวนกลับหาระดับปกติเสมอ เปลี่ยนบรรทัดแรกเป็น AR(1) รอบ $V$ ขั้นตอนผสมยังเหมือนเดิม แต่ตอนเดินหน้าหนึ่งวัน ความผิดถูกคูณด้วย $a$ variance ของมันจึงคูณ $a^2$ ก่อนบวก $\tau_\epsilon^2$

\[ \begin{aligned} x_{t+1}&=V+a(x_t-V)\\ &\quad+\tau_\epsilon\epsilon_{t+1},\\ P&=a^2\frac{P\kappa^2}{P+\kappa^2}+1,\\ c&=(1-a^2)\kappa^2-1,\\ P&=\tfrac12\big(\sqrt{c^2+4\kappa^2}-c\big),\\ a=0.98:&\quad c=9.34,\\ &\quad P=12.150,\\ &\quad K=0.04446. \end{aligned} \]

คูณ $P+\kappa^2$ ทั้งสองข้างของบรรทัดที่สองแล้วย้ายข้าง จะได้ $P^2+cP-\kappa^2=0$ รากบวกคือบรรทัดที่สี่ เมื่อ $a=1$ จะได้ $c=-1$ และกลับไปเป็นกรณี random walk ที่ $P=16.667$ และ $K=0.06$

ที่ $\kappa$ เท่าเดิม mean reversion ทำให้ $K$ ลดจาก 0.06 เป็น 0.04446 เพราะ variance จริงอยู่ไม่ไกลจาก $V$ ค่าประมาณเดิมจึงน่าเชื่อกว่า นี่คือข้อสังเกตที่ทำให้หลายคนสรุปว่าควรมองย้อนหลังนานขึ้น แต่ $K$ คือน้ำหนักในขั้นผสม ยังไม่ใช่สูตรที่ใช้พยากรณ์ ขั้นถัดไปแสดงว่าสูตรพยากรณ์มี $a$ คูณอยู่ด้วย

ขั้นที่ 6 — สูตรที่ดีที่สุดคือ GARCH(1,1)

หลังผสมข้อมูลวันนี้แล้ว ค่าที่ดีที่สุดของพรุ่งนี้คือค่าเฉลี่ยของ $x_{t+1}$ เมื่อรู้ข้อมูลถึงวันนี้ ตามบรรทัดแรกของแบบจำลอง AR(1) มันคือ $V+a(\hat x_{t|t}-V)$ เพราะก้อนสุ่มของพรุ่งนี้มีค่าเฉลี่ยศูนย์ แทนขั้นผสมลงไปแล้วจัดกลุ่มใหม่

\[ \begin{aligned} \hat x_{t|t}&=(1-K)\hat x_{t|t-1}+Ky_t,\\ \hat x_{t+1|t}&=V+a(\hat x_{t|t}-V)\\ &=(1-a)V+aK\,y_t\\ &\quad+a(1-K)\,\hat x_{t|t-1},\\ \omega&=(1-a)V=1.8\times10^{-6},\\ \alpha&=aK=0.04357,\\ \beta&=a(1-K)=0.93643. \end{aligned} \]

บรรทัดที่สามและสี่คือ GARCH(1,1) ทุกตัวอักษร: ค่าคงที่ $\omega$ บวก $\alpha$ คูณ $r_t^2$ บวก $\beta$ คูณ variance ที่พยากรณ์ไว้เมื่อวาน โดย $\alpha+\beta=a=0.98$ และระดับปกติ $\omega/(1-\alpha-\beta)=V$ พอดี GARCH จึงไม่ใช่ EWMA ที่เติมค่าคงที่ตามใจ มันคือ Kalman filter ของ variance ที่ดึงกลับหาระดับปกติ

เมื่อ $a=1$ ค่าคงที่หายไปและได้ EWMA คืนมา ถ้าลืมตัวคูณ $a$ แล้วใช้ $(1-K)\hat x+Ky$ ตรง ๆ จะได้ EWMA ที่ $\lambda=0.9555$ ซึ่งคือ half-life 15.24 วันของข้อเสนอในโจทย์เปิดหน้า

ขั้นที่ 7 — ข้อมูลเก่าหดเร็วขึ้น ไม่ใช่ช้าลง

โจทย์ให้อะไรมาบ้าง: น้ำหนักของ $r^2$ เมื่อ $j$ วันก่อนใน GARCH คือ $\alpha\beta^j$ half-life ของน้ำหนักนั้นจึงคือ $\ln0.5/\ln\beta$ ส่วน half-life ของการกลับหาระดับปกติคือ $\ln0.5/\ln a$ เทียบทั้งสองตัวที่ $\kappa=16.16$ เท่ากันทุกแถว

ขั้นที่ 9 — อ่าน GARCH ใด ๆ ในภาษาของ Kalman

กลับทางสูตร GARCH จาก Kalman: จาก GARCH ใด ๆ อ่าน $a=\alpha+\beta$, $K=\alpha/a$ และ $V=\omega/(1-a)$ ได้ทันที แล้วหา $\kappa$ ที่ทำให้สมการ Riccati ที่มี $a$ ให้ $K$ นั้น ลองกับ GARCH ในหน้า ARCH/GARCH ที่ $\omega=1.8\times10^{-6}$, $\alpha=0.09$, $\beta=0.89$

\[ \begin{aligned} a&=0.09+0.89=0.98,\\ K&=0.09/0.98=0.09184,\\ V&=1.8\times10^{-6}/0.02=9\times10^{-5},\\ \kappa&=8.80,\\ -4\%:&\quad1.532\%,\ 1.285\%,\ 1.378\%. \end{aligned} \]

GARCH ตัวนี้คือ Kalman filter ของโลกเดียวกันที่เชื่อว่าเสียงรบกวนของ $r^2$ ดังกว่าการเปลี่ยนจริงแค่ 8.80 เท่า มันจึงให้น้ำหนักข่าวใหม่มากกว่า

หลังวันร่วง 4% จากความผันผวน 1% GARCH ตัวนี้ตอบ 1.532% ตัวกรองที่ $\kappa=16.16$ ตอบ 1.285% และ EWMA ตอบ 1.378% อีก 60 วันหลังจากพรุ่งนี้สองตัวแรกเหลือ 1.154% และ 1.060% ส่วน EWMA ยัง 1.378% ในโลกที่ $\kappa=16.16$ จริง GARCH ตัวนี้ติดตามได้ความผิด 33.88% แย่กว่า EWMA เดิม GARCH ไม่ได้ดีกว่าโดยอัตโนมัติ ค่าของมันต้องตรงกับเสียงรบกวนของข้อมูล

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

ใช้ EWMA ตอบคำถามระยะยาว: คำพยากรณ์หลายวันของ EWMA แบนตลอดไป หลังวันร่วงมันบอกว่าความผันผวน 1.378% จะอยู่ไปทุกวัน ขณะที่ GARCH บอก 1.154% อีก 60 วันถัดไป งานตั้งราคา option ระยะยาวและการวางแผนทุนต้องใช้แบบจำลองที่มีระดับปกติ

ยืด half-life เพราะ mean reversion: สูตรที่ดีที่สุดให้ข้อมูลเก่าหดเร็วขึ้น (10.55 วัน) แล้วเติมค่าคงที่ การยืด EWMA เป็น 15.24 วันคือผลของการลืม $a$ และได้ความผิด 32.82% แทน 30.51%

ใช้ $\lambda$ เดียวกันกับทุกสินทรัพย์: $\lambda=1-K$ มาจาก $\kappa$ ของแต่ละสินทรัพย์ สินทรัพย์ที่ variance เปลี่ยนเร็วเมื่อเทียบกับเสียงรบกวนของ $r^2$ ($\kappa$ เล็ก) ควรใช้ $\lambda$ เล็กกว่า ที่ $\kappa=5$ ได้ $\lambda=0.819$ และ half-life 3.47 วัน

ปรับ $\lambda$ จนกว่า backtest จะสวย: แบบจำลองให้ $\lambda$ จากสมบัติของข้อมูล คือ $\kappa$ และ $a$ การจูนตามผลลัพธ์ที่อยากเห็นคือการ fit เสียงรบกวน

เชื่อ GARCH ที่ fit มาโดยไม่อ่าน $\kappa$ ของมัน: GARCH ที่ $\alpha=0.09$ ในโลกที่ $\kappa=16.16$ ได้ความผิด 33.88% แย่กว่า EWMA ที่ไม่ต้องประมาณอะไรเลย

ใช้ทำอะไรบนโต๊ะจริง

risk model เชิงพาณิชย์ใช้ EWMA กับหุ้นทั้งจักรวาลด้วย half-life ที่เลือกจากการทดสอบ และสื่อสารด้วย half-life แทน $\lambda$ โต๊ะที่ต้องการคำพยากรณ์หลายวัน เช่นตั้งราคา option หรือกันทุน ใช้ GARCH ที่ $\alpha+\beta\lt1$ วิธีตรวจว่า GARCH ที่ fit มามีเหตุผลไหมคืออ่าน $\kappa$ และ $a$ ของมันแล้วเทียบกับเสียงรบกวนของ $r^2$ ที่วัดได้ และ realized variance ใช้แทน $r^2$ เป็นข้อมูลได้ ซึ่งลด $\tau_\eta$ ลงมาก $\kappa$ เล็กลง ตัวกรองจึงตามความผันผวนได้เร็วขึ้น การปรับความผันผวนระยะสั้น ของ factor model ต่อยอดเรื่องนี้

แบบจำลองสองบรรทัดมีจุดอ่อนสองข้อ: variance ในแบบจำลองติดลบได้ และเสียงรบกวนของ $r^2$ ไม่ใช่ Normal ขนาดของมันโตตาม variance เอง แบบจำลองของ Harvey และ Shephard แก้โดยใช้ $\ln r_t^2$ เป็นข้อมูล ถ้า $r_t=\sigma_t\xi_t$ กับ $\xi_t$ Normal จะได้ $\ln r_t^2=\ln\sigma_t^2+\ln\xi_t^2$ ซึ่ง $\ln\xi_t^2$ มีค่าเฉลี่ย −1.27 และ SD 2.22 (สมบัติของ Normal) หักค่าเฉลี่ยออกแล้วใช้ Kalman filter แบบเดียวกันกับ $\ln\sigma^2$ ที่เดินแบบ AR(1) ความผันผวนที่ได้ $e^{\hat x/2}$ เป็นบวกเสมอ

คำนวณซ้ำด้วย JavaScript

รันใน Node.js ได้โดยไม่ติดตั้งแพ็กเกจ โค้ดคิด half-life แปลง $\lambda$ เป็น $\kappa$ แก้สมการ Riccati ที่มี $a$ ทั้งด้วยสูตรปิดและการวนซ้ำ แปลง Kalman เป็น GARCH และกลับ คิดความผิดของการติดตามแบบปิด ยืนยันว่า EWMA กับ GARCH ที่ $\omega=0$ ให้ผลเท่ากันทุกบิต และจำลอง 200,000 วันของโลก AR(1) แล้วพิมพ์ตัวเลขหลักหนึ่งบรรทัด

const {sqrt, log, cos, sin, PI} = Math;

const halfLife = lambda => log(0.5) / log(lambda);
// random-walk variance: P = 1/K in units of tau_e^2, so kappa = sqrt(lambda) / (1 - lambda)
const kappaFromLambda = lambda => sqrt(lambda) / (1 - lambda);
// P = a^2 P k^2 / (P + k^2) + 1  gives  P^2 + c P - k^2 = 0 with c = (1 - a^2) k^2 - 1
function steadyGain(kappa, a = 1) {
  const R = kappa * kappa, c = (1 - a * a) * R - 1, P = 0.5 * (sqrt(c * c + 4 * R) - c);
  return {c, P, K: P / (P + R)};
}
function iteratedGain(kappa, a = 1, steps = 5000) {
  const R = kappa * kappa;
  let P = 1;
  for (let i = 0; i < steps; i++) P = a * a * P * R / (P + R) + 1;
  return P / (P + R);
}
// the steady Kalman filter written as GARCH(1,1)
function kalmanToGarch({kappa, a, V}) {
  const {K, P} = steadyGain(kappa, a);
  return {K, P, omega: (1 - a) * V, alpha: a * K, beta: a * (1 - K)};
}
// read a GARCH(1,1) back as a Kalman filter; kappa by bisection on the gain (K falls as kappa grows)
function garchToKalman({omega, alpha, beta}) {
  const a = alpha + beta;
  if (!(a < 1)) throw new RangeError('alpha + beta must be below 1 for a long-run level');
  const K = alpha / a;
  let lo = 1e-6, hi = 1e6;
  for (let i = 0; i < 300; i++) { const mid = sqrt(lo * hi); if (steadyGain(mid, a).K > K) lo = mid; else hi = mid; }
  return {a, K, V: omega / (1 - a), kappa: sqrt(lo * hi)};
}
// steady MSE of a tracker f(t+1) = c + b f(t) + g y(t) when x is AR(1) around V
function trackingMse({g, b}, {a, tauE, tauH}) {
  const s2 = tauE * tauE / (1 - a * a);
  return g * g * (tauH * tauH / (1 - b * b) + s2 * (1 + a * b) / ((1 - b * b) * (1 - a * b))) + s2 - 2 * g * s2 * a / (1 - a * b);
}
function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}
function normals(rnd) {
  let spare = null;
  return () => {
    if (spare !== null) { const s = spare; spare = null; return s; }
    let u = 0;
    while (u === 0) u = rnd();
    const v = rnd(), R = sqrt(-2 * log(u));
    spare = R * sin(2 * PI * v);
    return R * cos(2 * PI * v);
  };
}
// simulate the AR(1) variance world and run several trackers on the same data
function simulateTracking(n, seed, world, trackers) {
  const z = normals(mulberry32(seed)), x = new Float64Array(n + 1), y = new Float64Array(n);
  const f = trackers.map(() => new Float64Array(n + 1).fill(world.V));
  x[0] = world.V;
  for (let t = 0; t < n; t++) {
    y[t] = x[t] + world.tauH * z();
    trackers.forEach((k, i) => { f[i][t + 1] = k.c + k.b * f[i][t] + k.g * y[t]; });
    x[t + 1] = world.V + world.a * (x[t] - world.V) + world.tauE * z();
  }
  const rmse = f.map(fi => { let s = 0; for (let t = 1001; t <= n; t++) s += (fi[t] - x[t]) ** 2; return sqrt(s / (n - 1000)) / world.V; });
  return {y, rmse};
}

const V = 9e-5, a = 0.98, kappa = kappaFromLambda(0.94), tauH = sqrt(2) * V, tauE = tauH / kappa;
const world = {V, a, tauE, tauH}, g = kalmanToGarch({kappa, a, V});
const trackers = [{c: g.omega, b: g.beta, g: g.alpha}, {c: 0, b: 0.94, g: 0.06}, {c: 0, b: 1 - g.K, g: g.K}];

สิ่งที่ควรตอบได้หลังอ่าน

  • EWMA ให้น้ำหนัก $(1-\lambda)\lambda^i$ ซึ่งรวมกันได้ 1 half-life ที่ $\lambda=0.94$ คือ 11.20 วัน และคำพยากรณ์หลายวันของมันแบนตลอดไป
  • GARCH ที่คลี่แล้วคือ EWMA บวกค่าคงที่ ทั้งสองเท่ากันเมื่อ $\omega=0$, $\alpha=1-\lambda$, $\beta=\lambda$
  • EWMA คือ Kalman filter ของ variance ที่เดินแบบ random walk และ $\kappa=\sqrt\lambda/(1-\lambda)$: 0.94 แปลว่าเสียงรบกวนของ $r^2$ ดังกว่าการเปลี่ยนจริง 16.16 เท่า
  • เมื่อ variance ดึงกลับด้วย $a$ สูตรที่ดีที่สุดคือ GARCH ที่ $\omega=(1-a)V$, $\alpha=aK$, $\beta=a(1-K)$: ที่ $a=0.98$ ได้ 0.04357 และ 0.93643 ข้อมูลเก่าหดเร็วขึ้น (10.55 วัน) ไม่ใช่ช้าลง
  • ความผิดของการติดตามคือ 30.51% สำหรับ GARCH นั้น 32.78% สำหรับ EWMA ที่ดีที่สุด และ GARCH ที่ $\alpha=0.09$, $\beta=0.89$ อ่านได้ว่าเชื่อ $\kappa=8.80$

บทนี้จบที่หุ้นทีละตัว: ผลตอบแทนที่สะอาด นิสัยของมัน ราคาที่วัดผิด ความผันผวนที่วัดได้ และการเดินมันไปข้างหน้า บทถัดไปเริ่มจากหุ้นหลายพันตัวพร้อมกัน ซึ่งสิ่งที่สำคัญที่สุดคือการที่พวกมันขยับไปด้วยกัน อ่านต่อที่ สมการของ factor model
