1.11 A Zoo of Distributions

distribution แต่ละตัวคือเรื่องเล่าว่าข้อมูลเกิดขึ้นอย่างไร เลือกจากกลไกและหาง ไม่ใช่จากการจับค่าเฉลี่ยกับ SD ให้ตรง

ทีม execution วัดเวลารอจนมีคำสั่งซื้อขายเข้ามาครั้งถัดไปในหุ้นตัวหนึ่ง ได้ค่าเฉลี่ย 5 วินาทีและ SD 5 วินาที นักวิเคราะห์ใส่ Normal ที่มีค่าเฉลี่ยและ SD ตรงกันลงในระบบจำลอง แล้วบอกว่า “แบบจำลองตรงกับข้อมูลแล้ว” จริงไหม

ลองตอบก่อนเปิดเฉลย

ไม่จริง Normal นี้ให้โอกาสเวลารอติดลบ $\Phi\big(\tfrac{0-5}{5}\big)=\Phi(-1)\approx15.9\%$ ซึ่งเป็นไปไม่ได้ การจับค่าเฉลี่ยและ SD ให้ตรงไม่ได้แปลว่าจับรูปทรงได้ ตัวที่เหมาะคือ Exponential ซึ่งเกิดจากกลไกที่คำสั่งเข้ามาแบบสุ่มด้วยอัตราคงที่ และมีค่าเฉลี่ยเท่ากับ SD พอดีโดยธรรมชาติ

ภาพรวมก่อนลงสูตร

distribution แต่ละตัวเป็นคำตอบของกลไกหนึ่ง: นับความสำเร็จจากการทดลองอิสระ (Binomial) นับเหตุการณ์หายากในช่วงเวลา (Poisson) ผลรวมของผลเล็ก ๆ จำนวนมาก (Normal) ผลคูณของผลเล็ก ๆ จำนวนมาก (Lognormal) หน้านี้เพิ่มอีกสี่ตัวที่งานการเงินใช้บ่อย: Exponential สำหรับเวลารอ Student-t สำหรับกรณีที่ความผันผวนเองไม่แน่นอน Normal ผสมสำหรับตลาดที่สลับระหว่างช่วงสงบกับช่วงปั่นป่วน และ Pareto สำหรับขนาดที่บางครั้งใหญ่ผิดปกติ

เกณฑ์เลือกมีสี่ข้อ: ตัวแปรมีค่าได้ช่วงไหน (support) กลไกที่สร้างข้อมูลคืออะไร คำถามสนใจส่วนกลางหรือหาง และ moment ที่จะใช้มีอยู่จริงหรือไม่ สอง distribution ที่มีค่าเฉลี่ยและ SD เท่ากันอาจให้คำตอบเรื่องหางต่างกันหลายเท่า ดังที่จะคำนวณให้เห็นทั้งหน้า

ระหว่างทางจะได้เครื่องมือหนึ่งที่ใช้กับทุก distribution คือการสร้างตัวเลขสุ่มจาก CDF ซึ่งเป็นพื้นฐานของการจำลอง Monte Carlo

ศัพท์ที่ใช้ในหน้านี้
support
ช่วงค่าที่ตัวแปรเป็นไปได้ เช่นเวลารอไม่ติดลบ ราคาเป็นบวก ผลตอบแทนเป็นได้ทั้งบวกและลบ ใช้ตัดตัวเลือก distribution ก่อนดูอย่างอื่น
survival function
$P(X\gt x)=1-F(x)$ โอกาสที่ค่าเกินเกณฑ์ ใช้อ่านหางขวา และใช้เปรียบเทียบความหนาของหางบนกราฟ log
memoryless และ hazard rate
memoryless คือเวลารอที่เหลือไม่ขึ้นกับว่ารอมาแล้วนานเท่าไร hazard rate คืออัตราที่เหตุการณ์จะเกิดในชั่วขณะถัดไปเมื่อยังไม่เกิด Exponential มี hazard rate คงที่ ใช้กับเวลาผิดนัดชำระหนี้ได้
inverse transform sampling
การสร้างตัวเลขสุ่มจาก distribution ใดก็ได้โดยใส่เลขสุ่ม Uniform ลงใน inverse ของ CDF ใช้เป็นฐานของการจำลอง Monte Carlo
degrees of freedom ($\nu$)
พารามิเตอร์ของ Student-t ยิ่ง $\nu$ น้อยหางยิ่งหนา เมื่อ $\nu$ ใหญ่มาก t เข้าใกล้ Normal สำหรับ t-statistic จากข้อมูล $n$ ค่า ใช้ $\nu=n-1$
tail index ($\alpha$)
เลขชี้กำลังของหางแบบ power law $P(X\gt x)\propto x^{-\alpha}$ ยิ่ง $\alpha$ น้อยหางยิ่งหนา moment ลำดับ $k$ มีค่าจำกัดเฉพาะเมื่อ $k\lt\alpha$
skewness และ kurtosis
moment มาตรฐานลำดับสามและสี่ skewness ติดลบบอกว่าหางซ้ายยาว kurtosis เกิน 3 บอกว่าค่าสุดโต่งบ่อยกว่า Normal

$X,\ N(t)$เวลารอ, จำนวนเหตุการณ์ในช่วงยาว $t$วินาที, ครั้ง
$U$เลขสุ่ม Uniform ระหว่าง 0 ถึง 1ไม่มีหน่วย

ขั้นที่ 1 — Exponential: เวลารอระหว่างเหตุการณ์ Poisson

ถ้าคำสั่งเข้ามาแบบสุ่มอิสระด้วยอัตราคงที่ $\lambda=0.2$ ครั้งต่อวินาที (12 ครั้งต่อนาที) จำนวนคำสั่งในช่วงยาว $t$ วินาทีเป็น Poisson ค่าเฉลี่ย $\lambda t$ เคล็ดลับคือมองว่า “ยังต้องรอเกิน $t$ วินาที” เป็นเหตุการณ์เดียวกับ “ไม่มีคำสั่งเข้ามาเลยในช่วง $t$ วินาที”

\[ \begin{aligned} P(X\gt t)&=P(N(t)=0)=e^{-\lambda t}\\ F(t)&=1-e^{-\lambda t},\quad t\ge0\\ f(t)&=F'(t)=\lambda e^{-\lambda t}\\ P(X\gt10)&=e^{-0.2\times10}=e^{-2}\approx13.5\% \end{aligned} \]

บรรทัดแรกใช้สูตร Poisson ที่ $k=0$: $\frac{(\lambda t)^0e^{-\lambda t}}{0!}=e^{-\lambda t}$ จากนั้น CDF คือหนึ่งลบ survival และ PDF คือความชันของ CDF ตาม ตัวแปรต่อเนื่องและ PDF distribution นี้ชื่อ Exponential ($\lambda$) density สูงสุดที่ศูนย์ แปลว่าช่วงรอสั้น ๆ เกิดบ่อยที่สุด ระวังสับสน: $\lambda$ คืออัตราต่อวินาที ส่วนจำนวนเฉลี่ยในช่วง $t$ คือ $\lambda t$

ขั้นที่ 2 — ค่าเฉลี่ย SD และ quantile ของเวลารอ

สำหรับตัวแปรไม่ติดลบ ค่าเฉลี่ยเท่ากับพื้นที่ใต้ survival function (บวกชิ้นบาง ๆ “ยังรออยู่ไหม” ทุกวินาที) วิธีนี้สั้นกว่าการ integrate $t\,f(t)$ ตรง ๆ

\[ \begin{aligned} \mathbb E[X]&=\int_0^\infty P(X\gt t)\,dt\\ &=\int_0^\infty e^{-\lambda t}dt=\frac1\lambda\\ \mathbb E[X^2]&=2\int_0^\infty t\,e^{-\lambda t}dt=\frac{2}{\lambda^2}\\ \operatorname{Var}(X)&=\frac{2}{\lambda^2}-\frac{1}{\lambda^2}=\frac{1}{\lambda^2}\\ \lambda=0.2&:\quad\mathbb E[X]=5\ \text{s},\ \operatorname{SD}=5\ \text{s}\\ q_p&=-\frac{\ln(1-p)}{\lambda}\\ q_{0.5}&=\frac{\ln2}{0.2}\approx3.47\ \text{s},\quad q_{0.95}\approx14.98\ \text{s} \end{aligned} \]

บรรทัดที่สองใช้ integration by parts ซึ่งได้ $\int_0^\infty te^{-\lambda t}dt=1/\lambda^2$ ค่าเฉลี่ยเท่ากับ SD เป็นลายเซ็นของ Exponential นี่คือเหตุผลที่ข้อมูลในโจทย์เปิด (เฉลี่ย 5 SD 5) ชี้ไปที่ Exponential สูตร quantile ได้จากการแก้ $1-e^{-\lambda q}=p$ ครึ่งหนึ่งของเวลารอสั้นกว่า 3.47 วินาที ไม่ใช่ 5 วินาที และ $P(X\le5)=1-e^{-1}\approx63\%$ หางขวาดึงค่าเฉลี่ยขึ้นสูงกว่าค่ากลาง ถ้าระบบต้องรองรับ 95% ของกรณี ต้องเผื่อเวลาเกือบ 15 วินาที

ขั้นที่ 3 — memoryless: รอมานานแล้วไม่ได้ทำให้ใกล้ถึงคิว

รอมาแล้ว 10 วินาทียังไม่มีคำสั่ง เทรดเดอร์รู้สึกว่า “น่าจะมาเร็ว ๆ นี้” ลองคำนวณด้วย conditional probability จาก Bayes' theorem: หดกลุ่มเหลือเฉพาะกรณีที่รอเกิน 10 วินาที แล้วถามสัดส่วนที่รอเกินอีก 5 วินาที

\[ \begin{aligned} P(X\gt a+b\mid X\gt a)&=\frac{P(X\gt a+b)}{P(X\gt a)}\\ &=\frac{e^{-\lambda(a+b)}}{e^{-\lambda a}}=e^{-\lambda b}\\ a=10,\ b=5&:\quad\frac{e^{-3}}{e^{-2}}=e^{-1}\approx36.8\%\\ \mathbb E[X\mid X\gt10]&=10+\frac{1}{\lambda}=15\ \text{s} \end{aligned} \]

เวลาที่รอมาแล้ว $a$ หักล้างกันหมด โอกาสรอต่ออีก 5 วินาทีคือ 36.8% เท่ากับตอนเริ่มรอใหม่ ๆ พอดี คุณสมบัตินี้ชื่อ memoryless และ Exponential เป็น distribution ต่อเนื่องตัวเดียวที่มีคุณสมบัตินี้ ในงานเครดิต ถ้าบริษัทมีอัตราผิดนัดต่อปีคงที่ (hazard rate คงที่) เวลาผิดนัดก็เป็น Exponential และบริษัทที่รอดมาสิบปีก็ไม่ได้ปลอดภัยขึ้นหรืออันตรายขึ้น ซึ่งเป็นสมมติฐานตั้งต้นของ hazard rate และพันธบัตรที่ผิดนัดได้ ถ้าข้อมูลจริงไม่ memoryless แสดงว่าอัตราไม่คงที่

ขั้นที่ 4 — สร้างตัวเลขสุ่มจาก distribution ใดก็ได้ด้วย inverse CDF

คอมพิวเตอร์สุ่มได้แค่ $U$ ที่กระจายเท่า ๆ กันระหว่าง 0 ถึง 1 ถ้าอยากจำลองเวลารอ ต้องแปลง $U$ เป็นเวลา วิธีคือมองว่า $U$ เป็น “ระดับโอกาส” แล้วถาม CDF กลับทิศว่าเวลาไหนมีโอกาสสะสมเท่านั้น

\[ \begin{aligned} X&=F^{-1}(U)\\ P(X\le x)&=P(F^{-1}(U)\le x)=P(U\le F(x))=F(x)\\ \text{Exponential}&:\quad X=-\frac{\ln(1-U)}{\lambda}\\ U=0.63&:\quad X=-\frac{\ln0.37}{0.2}\approx4.97\ \text{s}\\ \text{Box–Muller}&:\quad Z=\sqrt{-2\ln U_1}\,\cos(2\pi U_2) \end{aligned} \]

บรรทัดที่สองคือเหตุผลที่วิธีนี้ถูก: $F$ เป็น function เพิ่ม จึงย้ายข้างอสมการได้โดยทิศไม่เปลี่ยน และโอกาสที่ $U$ ไม่เกิน $F(x)$ ก็คือ $F(x)$ เพราะ $U$ กระจายเท่า ๆ กัน ผลคือ $X$ มี CDF เท่ากับ $F$ พอดี สำหรับ Normal ซึ่ง inverse CDF ไม่มีสูตรปิด มีทางลัด Box–Muller ที่แปลง Uniform อิสระสองตัวเป็น Normal มาตรฐานอิสระ เช่น $U_1=0.25$, $U_2=0.60$ ให้ $Z\approx1.665\cos(216^\circ)\approx-1.347$ วิธีนี้มาจากการที่ Normal สองมิติสมมาตรรอบจุดกำเนิด มุมจึงสุ่มเท่า ๆ กัน และรัศมียกกำลังสองหารสองเป็น Exponential

ขั้นที่ 5 — Student-t: เมื่อตัวหารก็ต้องประมาณจากข้อมูล

นักวิเคราะห์ได้ผลตอบแทนรายเดือนของกลยุทธ์ใหม่เพียงสามเดือน: 0.5%, 0.6%, 0.7% ค่าเฉลี่ย 0.6% SD ตัวอย่าง 0.1% อยากรู้ว่าค่าเฉลี่ยต่างจากศูนย์จริงหรือแค่บังเอิญ ถ้ารู้ SD จริงจะได้ z-score ที่เป็น Normal แต่ที่นี่ SD ก็ประมาณจากข้อมูลสามค่าเดียวกัน ตัวหารจึงสุ่มด้วย

\[ \begin{aligned} t&=\frac{\bar x}{s/\sqrt n}=\frac{0.6}{0.1/\sqrt3}\approx10.39\\ P(|t_2|\gt c)&=1-\frac{c}{\sqrt{c^2+2}}\\ P(|t_2|\gt1.96)&\approx18.9\%\\ 1-\frac{c}{\sqrt{c^2+2}}=0.05&\quad\Rightarrow\quad c\approx4.30 \end{aligned} \]

ถ้าผลตอบแทนเป็น Normal อิสระและค่าเฉลี่ยจริงเป็นศูนย์ ค่า $t$ นี้มี Student-t distribution ที่ $\nu=n-1=2$ degrees of freedom (บรรทัดที่สองคือ CDF ของ $t_2$ ซึ่งมีสูตรปิด) เกณฑ์สองด้าน 5% จึงเป็น ±4.30 ไม่ใช่ ±1.96 ถ้าใช้ 1.96 จะตัดสินผิดว่า “มีผล” ถึง 18.9% ของเวลาแทนที่จะเป็น 5% ในตัวอย่างนี้ 10.39 ยังเกิน 4.30 แต่ข้อมูลสามเดือนมีปัญหาอื่นที่ใหญ่กว่า เช่นเลือกช่วงเวลาที่สวย เรื่องนี้จะต่อยอดใน การทดสอบสมมติฐานและ Sharpe ratio

ขั้นที่ 6 — ทำไม t จึงหางหนา และหนากว่าที่ไหน

นิยาม Student-t ด้วยกลไกที่เห็นในขั้นที่แล้ว: Normal หารด้วยตัวปรับ scale ที่สุ่มได้ ให้ $Z, Z_1,\ldots,Z_\nu$ เป็น Normal มาตรฐานอิสระ และ $V=\sum Z_i^2$ (chi-square ที่มี $\nu$ degrees of freedom มีค่าเฉลี่ย $\nu$)

\[ \begin{aligned} \tau&=\frac{Z}{\sqrt{V/\nu}}\\ f_{\tau\mid V}(x\mid v)&=\sqrt{\tfrac{v}{2\pi\nu}}\,e^{-vx^2/(2\nu)}\\ f_\tau(x)&=\int_0^\infty f_{\tau\mid V}(x\mid v)\,f_V(v)\,dv\\ &=\frac{\Gamma\big(\tfrac{\nu+1}{2}\big)}{\sqrt{\nu\pi}\,\Gamma\big(\tfrac{\nu}{2}\big)}\Big(1+\frac{x^2}{\nu}\Big)^{-(\nu+1)/2}\\ \operatorname{Var}(\tau)&=\frac{\nu}{\nu-2},\quad\nu\gt2\\ Y&=\tau_3/\sqrt3:\quad P(Y\lt-4)\approx0.308\%\\ \text{Normal}&:\quad P(Z\lt-4)\approx0.0032\% \end{aligned} \]

บรรทัดที่สองอ่านว่า: เมื่อรู้ $V=v$ แล้ว $\tau$ เป็น Normal ที่มี variance $\nu/v$ ถ้า $V$ บังเอิญเล็ก ตัวหารเล็ก $\tau$ จึงกระจายกว้าง บรรทัดที่สามเฉลี่ย Normal หลายความกว้างเข้าด้วยกันโดยถ่วงด้วย density ของ $V$ integral นี้หาค่าได้ด้วย Gamma function $\Gamma(a)=\int_0^\infty u^{a-1}e^{-u}du$ และให้สูตรบรรทัดที่สี่ หางของมันลดแบบกำลังของ $|x|$ คือ $|x|^{-(\nu+1)}$ ไม่ใช่ $e^{-x^2/2}$ จึงหนากว่า Normal มาก ผลข้างเคียงคือ moment ลำดับ $k$ มีค่าจำกัดเฉพาะเมื่อ $k\lt\nu$: $t_1$ ไม่มีค่าเฉลี่ย $t_2$ ไม่มี variance จำกัด และ kurtosis มีค่าเมื่อ $\nu\gt4$ เท่ากับ $3(\nu-2)/(\nu-4)$

ก่อนเทียบกับ Normal ต้องปรับให้ variance เท่ากันก่อน $t_3$ มี variance 3 จึงหารด้วย $\sqrt3$ ได้ $Y$ (CDF ของ $Y$ คือ $\tfrac12+\tfrac1\pi\big(\arctan y+\tfrac{y}{1+y^2}\big)$) ที่ −4σ หางของ $Y$ หนากว่า Normal 97 เท่า แต่ที่ −1.85σ (ขาดทุนเกิน 2% ของพอร์ต \$50 ล้านใน Normal distribution) $Y$ ให้ 2.44% น้อยกว่า Normal ที่ 3.18% สองเส้นตัดกันที่ราว 2.1σ เพราะเมื่อ variance เท่ากัน ถ้าหางกินพื้นที่มากขึ้น ไหล่ต้องบางลงชดเชย

ขั้นที่ 7 — Normal ผสม: ตลาดที่สลับระหว่างช่วงสงบกับช่วงปั่นป่วน

หางหนาในข้อมูลจริงส่วนใหญ่ไม่ได้มาจากวันที่บ้าคลั่งแบบไม่มีเหตุผล แต่มาจากความผันผวนที่ไม่คงที่ ลองแบบจำลองง่ายที่สุด: 75% ของวันเป็นวันสงบที่ผลตอบแทนเป็น Normal SD 0.76 (หน่วย σ ของพอร์ต) อีก 25% เป็นวันปั่นป่วนที่ SD 1.5 ค่าเฉลี่ยศูนย์ทั้งคู่ ตัวเลขชุดนี้เลือกมาให้ variance รวมใกล้ 1 เพื่อเทียบกับ Normal SD 1 และ t ที่ $\nu=12$ ซึ่งปรับให้ variance เป็น 1 อย่างยุติธรรม

\[ \begin{aligned} \operatorname{Var}&=0.75(0.76)^2+0.25(1.5)^2\\ &=0.4332+0.5625=0.9957\\ \mathbb E[X^4]&=3\big[0.75(0.76)^4+0.25(1.5)^4\big]=4.547\\ \text{kurtosis}&=\frac{4.547}{0.9957^2}\approx4.59\\ P(X\lt-3)&=0.75\,\Phi\!\big(\tfrac{-3}{0.76}\big)\\ &\quad+0.25\,\Phi\!\big(\tfrac{-3}{1.5}\big)\\ &=0.00003+0.00569\approx0.572\% \end{aligned} \]

variance ของส่วนผสมคือค่าเฉลี่ยถ่วงของ variance แต่ละสภาวะ (เมื่อค่าเฉลี่ยเท่ากัน) moment ลำดับสี่ก็ถ่วงแบบเดียวกัน โดย Normal แต่ละตัวมี $\mathbb E[X^4]=3\sigma^4$ ผลคือ kurtosis 4.59 ทั้งที่ทุกวันเป็น Normal แค่ความกว้างไม่เท่ากัน บรรทัดสุดท้ายบอกว่าโอกาสขาดทุนเกิน 3σ คือ 0.572% สูงกว่า Normal (0.135%) 4.2 เท่า และเกือบทั้งหมด (0.569%) มาจากวันปั่นป่วน นี่คือแนวคิดของ GARCH: ภายในแต่ละวันผลตอบแทนอาจเป็น Normal แต่เมื่อรวมทุกวันแล้วหางหนา

ตารางนี้คำนวณขาดทุนในหน่วย σ VaR คือ quantile ของขาดทุน ส่วน ES (expected shortfall หรือ CVaR) คือขาดทุนเฉลี่ยในวันที่เกิน VaR ที่ระดับ 95% แบบจำลองหางหนาให้ VaR ต่ำกว่า Normal ด้วยซ้ำ แต่ ES สูงกว่าทุกตัว เพราะ VaR ดูแค่ตำแหน่งขอบ ไม่ได้ดูว่าเลยขอบไปไกลแค่ไหน ที่ระดับ 99% ทั้ง VaR และ ES ของ Normal ผสมสูงกว่า Normal 13% และ 21% ตามลำดับ

ขั้นที่ 8 — Pareto: หางแบบ power law ที่ไม่มี variance

ขนาดคำสั่งซื้อขาย ขนาดบริษัท และความเสียหายจากภัยพิบัติมีลักษณะร่วมกัน: ส่วนใหญ่เล็ก แต่บางครั้งใหญ่กว่าปกติหลายร้อยเท่า สมมติขนาดคำสั่งอย่างน้อย $x_m=100$ หุ้น และหางลดแบบ power law ด้วย tail index $\alpha=1.5$

\[ \begin{aligned} P(X\gt x)&=\Big(\frac{x_m}{x}\Big)^{\alpha},\quad x\ge x_m\\ f(x)&=\alpha\,x_m^{\alpha}\,x^{-\alpha-1}\\ \mathbb E[X^k]&=\alpha x_m^{\alpha}\int_{x_m}^\infty x^{k-\alpha-1}dx\\ &=\frac{\alpha\,x_m^k}{\alpha-k},\quad k\lt\alpha\\ \mathbb E[X]&=\frac{1.5\times100}{0.5}=300\ \text{shares}\\ P(X\gt10{,}000)&=(0.01)^{1.5}=0.1\%\\ \text{Exponential, mean 300}&:\quad e^{-10{,}000/300}\approx3\times10^{-15} \end{aligned} \]

integral ในบรรทัดที่สามลู่เข้าเฉพาะเมื่อเลขชี้กำลัง $k-\alpha-1$ น้อยกว่า −1 คือ $k\lt\alpha$ ที่ $\alpha=1.5$ ค่าเฉลี่ยมีค่า (300 หุ้น) แต่ $\mathbb E[X^2]$ เป็นอนันต์ จึงไม่มี variance จำกัด SD ตัวอย่างคำนวณได้เสมอ แต่ไม่ลู่เข้าค่าใด ยิ่งเก็บข้อมูลมากยิ่งเจอคำสั่งยักษ์ที่ดัน SD ขึ้นอีก ถ้าใช้ Exponential ที่ค่าเฉลี่ย 300 เท่ากัน โอกาสคำสั่ง 10,000 หุ้นจะเล็กลงหนึ่งล้านล้านเท่า สำหรับผลตอบแทนหุ้น หางรายวันดูเหมือน power law ที่ $\alpha$ ราว 4: variance มีค่า แต่ moment ลำดับสี่อยู่ตรงขอบพอดี นี่คือเหตุผลที่ kurtosis ตัวอย่างของหุ้นกระโดดไปมามากในแต่ละช่วงข้อมูล

ขั้นที่ 9 — กลยุทธ์ที่ชนะเกือบทุกครั้ง: ค่าเฉลี่ยกับ SD ซ่อนอะไรไว้

โจทย์ให้อะไรมาบ้าง: กลยุทธ์ขาย option ที่ไกลจากราคาปัจจุบันได้กำไร 0.2% ด้วยโอกาส 99% และขาดทุน 15% ด้วยโอกาส 1% ต่อครั้ง (ตัวเลขสมมติ) หาค่าเฉลี่ย SD skewness kurtosis และโอกาสที่ 100 ครั้งแรกไม่เจอขาดทุนเลย

\[ \begin{aligned} \mu&=0.99(0.2\%)+0.01(-15\%)=0.048\%\\ \sigma&=\sqrt{0.99(0.152\%)^2+0.01(15.048\%)^2}\approx1.51\%\\ \text{skewness}&=\frac{\mathbb E[(X-\mu)^3]}{\sigma^3}\approx-9.85\\ \text{kurtosis}&=\frac{\mathbb E[(X-\mu)^4]}{\sigma^4}\approx98.0\\ P(\text{no loss in 100})&=0.99^{100}\approx36.6\% \end{aligned} \]

คำตอบ: ค่าเฉลี่ยเป็นบวกเล็กน้อย 0.048% ต่อครั้ง แต่ skewness −9.85 บอกว่าความเสี่ยงทั้งหมดกองอยู่ในหางซ้าย และ kurtosis 98 คือหางหนากว่า Normal หลายสิบเท่า ที่อันตรายที่สุดคือบรรทัดสุดท้าย: มีโอกาส 36.6% ที่ track record 100 ครั้งแรกจะเป็นกำไร 0.2% ทุกครั้ง SD ตัวอย่างจึงเป็นศูนย์ และ Sharpe ratio ที่คำนวณได้เป็นอนันต์ ทั้งที่ความเสี่ยงจริงยังอยู่ครบ

ตรวจเองใน 10 วินาที: ค่าเฉลี่ยและ SD เป็นแค่สองตัวเลขแรกของรูปทรง ถ้า distribution เบ้มาก ต้องรายงาน skewness, ขาดทุนสูงสุดที่เป็นไปได้ หรือ ES ด้วยเสมอ

เลือก distribution จากกลไก แล้วตรวจสมมติฐาน

distributionกลไกที่สร้างมันใช้กับอะไรบนโต๊ะต้องตรวจอะไร
Binomialนับความสำเร็จใน $n$ ครั้งที่อิสระจำนวนปีที่ชนะตลาด, จำนวนผิดนัดในพอร์ตเล็กอิสระจริงไหม โอกาสคงที่ไหม
Poissonนับเหตุการณ์หายากในช่วงเวลาจำนวนคำสั่งต่อวินาที, จำนวนวันขาดทุนหนักค่าเฉลี่ยเท่ากับ variance ไหม
Exponentialเวลารอเมื่ออัตราคงที่เวลารอคำสั่ง, เวลาผิดนัดเมื่อ hazard คงที่ค่าเฉลี่ยเท่ากับ SD ไหม memoryless ไหม
Normalผลรวมของผลเล็ก ๆ จำนวนมากผลตอบแทนพอร์ตระยะยาว, ความคลาดเคลื่อนของค่าประมาณQQ plot, kurtosis, หาง
Lognormalผลคูณของผลเล็ก ๆ จำนวนมากราคาสินทรัพย์ปลายช่วงlog return เป็น Normal ไหม ราคาเป็นศูนย์ได้ไหม
Student-tNormal หารด้วย scale ที่สุ่มt-statistic, ผลตอบแทนหางหนาใช้ variance เท่ากันตอนเทียบไหม ค่า $\nu$ เท่าไร
Normal ผสมหลายสภาวะที่ความผันผวนต่างกันVaR และ ES ที่มีช่วงวิกฤติมีกี่สภาวะ สัดส่วนเท่าไร
Paretoหางแบบ power lawขนาดคำสั่ง, ความเสียหายรุนแรงtail index เท่าไร moment ที่ใช้มีอยู่ไหม
Uniformทุกจุดในช่วงมีโอกาสเท่ากันเลขสุ่มพื้นฐานของการจำลองขอบเขตช่วงรู้จริงไหม

ความผิดพลาดที่ให้คำตอบผิดแบบเงียบ ๆ

จับค่าเฉลี่ยกับ SD ให้ตรงแล้วจบ: Normal(5, 5²) ให้เวลารอติดลบ 15.9% และ Exponential กับ Pareto ที่ค่าเฉลี่ย 300 หุ้นเท่ากันให้โอกาสคำสั่ง 10,000 หุ้นต่างกัน $10^{12}$ เท่า

เทียบ t ดิบกับ Normal: $t_3$ ดิบมี variance 3 ถ้าเทียบที่เกณฑ์ตัวเลขเดียวกันจะปนเรื่อง scale กับเรื่องหาง ต้องหาร $\sqrt{\nu/(\nu-2)}$ ก่อน

เชื่อ VaR เพียงตัวเดียว: ที่ระดับ 95% Normal ผสมให้ VaR ต่ำกว่า Normal (1.588 กับ 1.645) แต่ ES สูงกว่า (2.222 กับ 2.063) VaR ไม่เห็นสิ่งที่อยู่เลยขอบ

เชื่อ SD ตัวอย่างของข้อมูลหางหนา: ใน Pareto ที่ $\alpha=1.5$ ไม่มี variance จริงให้ประมาณ และ track record ที่ไม่เคยขาดทุนให้ SD ศูนย์ ทั้งสองกรณี SD ตัวอย่างดูแม่นยำแต่ไม่มีความหมาย

ลืมว่า memoryless เป็นสมมติฐาน: ถ้าอัตราคำสั่งช่วงเปิดตลาดสูงกว่าช่วงบ่าย การใช้ Exponential อัตราเดียวทั้งวันจะให้เวลารอผิดทั้งสองช่วง

ใช้ทำอะไรบนโต๊ะจริง

งาน Monte Carlo ทุกชิ้นเริ่มจาก inverse CDF หรือ Box–Muller ในขั้นที่ 4 แล้วเลือก distribution ของปัจจัยเสี่ยงแต่ละตัว ฝ่ายความเสี่ยงที่ดีจะรัน VaR และ ES ด้วยหลาย distribution คู่กัน (Normal, t, Normal ผสม, ข้อมูลจริง) แล้วรายงานความไวต่อการเลือก ไม่ใช่รายงานตัวเลขเดียว เรื่องนี้ต่อยอดใน VaR และ expected shortfall และ Monte Carlo และ bootstrap ส่วนทีม execution ใช้ Exponential และ Poisson จำลองการไหลของคำสั่งใน order book และคิว

โจทย์ตรวจความเข้าใจ

1. รอคำสั่งมาแล้ว 10 วินาทีภายใต้ Exponential อัตรา 0.2 ครั้งต่อวินาที เวลารอทั้งหมดเฉลี่ยเป็นเท่าไร และโอกาสที่ต้องรอรวมเกิน 20 วินาทีเป็นเท่าไร

เฉลย

จาก memoryless เวลาที่ยังต้องรอเฉลี่ย $1/\lambda=5$ วินาที เวลารวมจึงเฉลี่ย $10+5=15$ วินาที รอรวมเกิน 20 วินาทีคือรอต่ออีกเกิน 10 วินาที: $P(X\gt20\mid X\gt10)=e^{-0.2\times10}=e^{-2}\approx13.5\%$ เท่ากับโอกาสรอเกิน 10 วินาทีตั้งแต่เริ่ม

2. ใช้ Normal ผสม 75% (SD 0.76) กับ 25% (SD 1.5) หาโอกาสขาดทุนเกิน 2σ แล้วเทียบกับ Normal

เฉลย

$0.75\,\Phi(-2/0.76)+0.25\,\Phi(-2/1.5)=0.75\,\Phi(-2.632)+0.25\,\Phi(-1.333)\approx0.75(0.00425)+0.25(0.0912)=0.0032+0.0228\approx2.60\%$ ส่วน Normal คือ $\Phi(-2)\approx2.28\%$ ที่ 2σ ต่างกันแค่ 1.14 เท่า แต่ที่ 3σ ต่างกัน 4.2 เท่า (0.572% กับ 0.135%) ยิ่งไกลยิ่งห่าง และส่วนใหญ่ของหางมาจากวันปั่นป่วนเสมอ

3. สร้างเวลารอสามค่าจากเลขสุ่ม $U=0.10,\ 0.50,\ 0.99$ ด้วยอัตรา 0.2 ครั้งต่อวินาที แล้วอธิบายว่าทำไมค่าสุดท้ายห่างจากค่าอื่นมาก

เฉลย

$X=-\ln(1-U)/0.2$: $U=0.10$ ให้ $-\ln0.9/0.2\approx0.53$ วินาที $U=0.50$ ให้ $\ln2/0.2\approx3.47$ วินาที (median) $U=0.99$ ให้ $-\ln0.01/0.2\approx23.03$ วินาที เลขสุ่มที่ใกล้ 1 ตกในส่วนที่ CDF แบนมาก ขยับ $U$ นิดเดียวเวลาก็กระโดดไกล นี่คือหางขวาของ Exponential ที่เห็นผ่านการจำลอง

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
const phi = z => Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
function Phi(z) {
  const n = 10000, h = Math.abs(z) / n;
  let s = 0;
  for (let i = 0; i <= n; i++) s += (i === 0 || i === n ? 1 : i % 2 ? 4 : 2) * phi(i * h);
  return 0.5 + Math.sign(z) * h * s / 3;
}
// Exponential waiting time, rate 0.2 per second
const lambda = 0.2;
console.log(Phi(-1));                                     // 0.159 negative waits under Normal(5, 5^2)
console.log(Math.exp(-2), Math.log(2) / lambda, -Math.log(0.05) / lambda); // 0.135 3.47 14.98
console.log(Math.exp(-3) / Math.exp(-2));                 // 0.368 memoryless
console.log([0.10, 0.50, 0.63, 0.99].map(u => -Math.log(1 - u) / lambda)); // inverse CDF
const r = Math.sqrt(-2 * Math.log(0.25)), th = 2 * Math.PI * 0.60;
console.log(r * Math.cos(th), r * Math.sin(th));           // Box-Muller -1.347 -0.979

// t with 2 degrees of freedom: t-statistic and 5% critical value
console.log(0.6 / (0.1 / Math.sqrt(3)), 1 - 1.96 / Math.sqrt(1.96 ** 2 + 2));
console.log(Math.sqrt(2 * 0.95 ** 2 / (1 - 0.95 ** 2)));  // 4.303
// t3 scaled to unit variance vs Normal
const FY = y => 0.5 + (Math.atan(y) + y / (1 + y * y)) / Math.PI;
console.log(FY(-4), Phi(-4), FY(-4) / Phi(-4));           // 0.00308 0.0000317 97.3
console.log(FY(-1.854545), Phi(-1.854545));              // 0.0244 0.0318

// two-regime Normal mixture
const v = 0.75 * 0.76 ** 2 + 0.25 * 1.5 ** 2;
const m4 = 3 * (0.75 * 0.76 ** 4 + 0.25 * 1.5 ** 4);
console.log(v, m4 / v ** 2);                              // 0.9957 4.59
const mixTail = x => 0.75 * Phi(-x / 0.76) + 0.25 * Phi(-x / 1.5);
console.log(mixTail(3), Phi(-3), mixTail(2), Phi(-2));    // 0.00572 0.00135 0.0260 0.0228

// Pareto vs Exponential with the same mean of 300 shares
console.log(1.5 * 100 / 0.5, (100 / 10000) ** 1.5, Math.exp(-10000 / 300));

// short-option strategy
const p = [0.99, 0.01], x = [0.002, -0.15];
const mu = p[0] * x[0] + p[1] * x[1];
const mom = k => p[0] * (x[0] - mu) ** k + p[1] * (x[1] - mu) ** k;
console.log(mu, Math.sqrt(mom(2)), mom(3) / mom(2) ** 1.5, mom(4) / mom(2) ** 2, 0.99 ** 100);

สิ่งที่ควรตอบได้หลังอ่าน

  • เลือก distribution จาก support กลไก และหาง ไม่ใช่จากการจับค่าเฉลี่ยกับ SD: Normal(5, 5²) ให้เวลารอติดลบ 15.9%
  • Exponential คือเวลารอของ Poisson: อัตรา 0.2 ให้ค่าเฉลี่ย 5 วินาที median 3.47 วินาที และ memoryless
  • inverse CDF แปลงเลขสุ่ม Uniform เป็น distribution ใดก็ได้ เช่น $U=0.63$ เป็นเวลารอ 4.97 วินาที
  • Student-t คือ Normal ที่ scale สุ่ม หางลดแบบ power law เมื่อปรับ variance เท่ากัน หาง t₃ หนากว่า Normal 97 เท่าที่ 4σ แต่บางกว่าก่อน 2.1σ
  • ส่วนผสมของสภาวะสงบกับปั่นป่วนให้ kurtosis 4.59 และ ES 99% สูงกว่า Normal 21% แม้ทุกวันเป็น Normal
  • moment ไม่ได้มีเสมอ: Pareto ที่ α = 1.5 มีค่าเฉลี่ยแต่ไม่มี variance และ track record ที่ไม่เคยขาดทุนอาจซ่อน skewness −9.85
