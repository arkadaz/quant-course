6.2 Linear Independence and Linear Combinations

กองทุนชื่อใหม่เพิ่มทิศทางใหม่จริงหรือเป็นส่วนผสมที่ทำเองได้?

มีกองทุน A ที่ถือกลุ่มธนาคาร/พลังงาน/เทคโนโลยี 60/40/0 และกองทุน B ที่ถือ 20/0/80 โบรกเกอร์เสนอ C ที่ถือ 40/20/40 ถ้าเราซื้อ A และ B ได้อยู่แล้ว C เพิ่มทางเลือกในการจัดสัดส่วนสามกลุ่มนี้หรือไม่?

ลองผสมก่อนดูคำตอบ

ไม่เพิ่มในโมเดลสามกลุ่มนี้: ลงทุนครึ่งหนึ่งใน A และอีกครึ่งใน B จะได้ $0.5(60,40,0)+0.5(20,0,80)=(40,20,40)$ เหมือน C แต่ยังสรุปไม่ได้ว่าถือหุ้นรายตัวเหมือนกัน มีค่าธรรมเนียมเท่ากัน หรือให้ผลตอบแทนจริงเท่ากัน

คำว่า “ซ้ำ” ต้องบอกด้วยว่าซ้ำในข้อมูลระดับไหน บทนี้จะใช้สมการตรวจการซ้ำเชิงเส้น แยกจากความเป็นอิสระทางสถิติที่เรียนในบท 5 และแยกจากคำโฆษณาว่าการเพิ่มจำนวนกองทุนช่วยกระจายความเสี่ยงเสมอ

1. กำหนดช่องของ vector ก่อนพูดถึงความซ้ำ

ตัวอย่างนี้เป็นกองทุนสมมติของหุ้นสหรัฐ ลำดับพิกัดคือธนาคาร พลังงาน เทคโนโลยี ตัวเลขเป็นน้ำหนักต่อ NAV ไม่ใช่จำนวนหุ้นของกองทุน น้ำหนักแต่ละกองรวมเป็นหนึ่ง:

\[ \mathbf A=\begin{bmatrix}0.6\\0.4\\0\end{bmatrix},\qquad \mathbf B=\begin{bmatrix}0.2\\0\\0.8\end{bmatrix},\qquad \mathbf C=\begin{bmatrix}0.4\\0.2\\0.4\end{bmatrix}. \]

Linear combination คือการคูณแต่ละ vector ด้วย scalar แล้วบวก เช่น $a\mathbf A+b\mathbf B$ สำหรับเงินลงทุนที่แบ่งครึ่งสองกอง เราใช้ $a=b=0.5$ ค่าสัมประสิทธิ์นี้เป็นสัดส่วนเงิน ไม่ใช่ข้ออ้างว่าจำนวนหน่วยลงทุนของสองกองต้องเท่ากัน

2. แก้จากช่องที่ง่าย แล้วตรวจทุกช่องที่เหลือ

หาก C สร้างจาก A และ B ได้ ต้องมี $a,b$ ชุดเดียวกันที่ทำให้ทุกพิกัดตรงกัน ไม่ใช่เลือก $a,b$ ใหม่ในแต่ละแถว:

\[ \begin{aligned} a\mathbf A+b\mathbf B=\mathbf C &\Longleftrightarrow \begin{cases} 0.6a+0.2b=0.4&\text{bank},\\ 0.4a=0.2&\text{energy},\\ 0.8b=0.4&\text{tech}. \end{cases}\\ a&=0.5,\qquad b=0.5,\\ 0.6(0.5)+0.2(0.5)&=0.4. \end{aligned} \]

เราใช้แถวพลังงานกับเทคโนโลยีหาสัมประสิทธิ์ แล้วใช้แถวธนาคารตรวจคำตอบ จึงสรุปได้ว่า $\mathbf C=0.5\mathbf A+0.5\mathbf B$ จริง หากซื้อ A, B, C อย่างละหนึ่งในสาม พอร์ตสามชื่อก็ยังให้ exposure เท่ากับถือ A และ B อย่างละครึ่ง

\[ \begin{aligned} \frac13\mathbf A+\frac13\mathbf B+\frac13\mathbf C &=\left(\frac13+\frac16\right)\mathbf A +\left(\frac13+\frac16\right)\mathbf B\\ &=\frac12\mathbf A+\frac12\mathbf B=\mathbf C. \end{aligned} \]

ลองเปลี่ยนกองที่สามเป็น $\mathbf D=(0.45,0.15,0.40)^{\mathsf T}$ ซึ่งยังรวมเป็นหนึ่ง แถวพลังงานและเทคโนโลยีให้ $a=0.375,b=0.5$ แต่ธนาคารที่ผสมได้มีเพียง $0.6(0.375)+0.2(0.5)=0.325$ ไม่ใช่ 0.45 จึงสร้าง D จาก A และ B ไม่ได้

3. การซ้ำเชิงเส้นตอบเรื่อง exposure ไม่ได้ตอบเรื่องราคาแทนเรา

สมมติ expense ratio ของ A เท่ากับ 0.30% ต่อปี, B เท่ากับ 0.60% และ C เท่ากับ 0.25% หากใช้ NAV คงที่ 10 ล้าน USD เป็นฐานประมาณการ ค่าธรรมเนียมต่างกันดังนี้:

\[ \begin{aligned} f_{AB}&=0.5(0.30\%)+0.5(0.60\%)=0.45\%,\\ \text{Fee}_{AB}&=10{,}000{,}000(0.0045)=45{,}000,\\ \text{Fee}_{C}&=10{,}000{,}000(0.0025)=25{,}000,\\ \text{difference}&=20{,}000\ \text{USD/year}. \end{aligned} \]

C อาจเป็นวิธีซื้อ exposure สามกลุ่มเดิมที่ถูกกว่าในแง่ค่าบริหาร ดังนั้น “ไม่เพิ่มทิศทาง” ไม่ได้แปลว่า “ไม่มีประโยชน์” ตัวเลขนี้ยังไม่รวม NAV ที่เปลี่ยนระหว่างปี ค่าซื้อขาย ภาษี หรือความต่างของหุ้นที่แต่ละกองถือภายในกลุ่มเดียวกัน

อย่าเรียกส่วนต่างค่าธรรมเนียมนี้ว่า arbitrage ที่ทำได้ทันที การ long C แล้ว short ส่วนผสม A/B ยังต้องตรวจ cash flow จริง หุ้นที่ถือ ค่า borrow ข้อจำกัด short และราคาเข้าออก การเท่ากันเพียงสามพิกัดยังไม่ใช่การเท่ากันของ payoff ทุกสถานการณ์

4. นิยาม independence: ห้ามมีส่วนผสมที่ไม่ว่างแล้วหักล้างเป็นศูนย์

Vectors $\mathbf v_1,\ldots,\mathbf v_k$ เป็น linearly independent เมื่อสมการต่อไปนี้มีคำตอบได้เพียงสัมประสิทธิ์ศูนย์ทั้งหมด:

\[ \sum_{i=1}^k a_i\mathbf v_i=\mathbf0 \quad\Longrightarrow\quad a_1=\cdots=a_k=0. \]

ถ้ามีคำตอบที่อย่างน้อยหนึ่งสัมประสิทธิ์ไม่เป็นศูนย์ จะเรียกว่า linearly dependent เหตุผลที่นิยามนี้ตรวจ “สร้างจากตัวอื่นได้” คือเมื่อ $a_j\ne0$ เราจัดสมการได้ว่า

\[ \begin{aligned} a_j\mathbf v_j&=-\sum_{i\ne j}a_i\mathbf v_i,\\ \mathbf v_j&=-\sum_{i\ne j}\frac{a_i}{a_j}\mathbf v_i. \end{aligned} \]

สำหรับกองทุนเดิม ความสัมพันธ์ $0.5\mathbf A+0.5\mathbf B-\mathbf C=\mathbf0$ มีสัมประสิทธิ์ไม่เป็นศูนย์ จึงพิสูจน์ว่า ชุดสามตัว dependent แม้ A กับ B ไม่ขนานกันก็ตาม คำว่า dependent ไม่ได้บังคับว่าต้องมีคู่หนึ่งเป็นแค่การขยายอีกคู่เสมอไป

ส่วน A กับ B เป็นอิสระ: หาก $a\mathbf A+b\mathbf B=\mathbf0$ แถวพลังงานบังคับให้ $0.4a=0$ จึงได้ $a=0$ และแถวเทคโนโลยีบังคับให้ $0.8b=0$ จึงได้ $b=0$ นี่เป็นการตรวจตามนิยามโดยตรง

ชุดที่มี zero vector จะ dependent ทันที เพราะคูณ zero vector ด้วย 1 และคูณตัวอื่นด้วย 0 ก็ได้ผลรวมศูนย์ ส่วนชุดหลายตัวอาจมีทุกคู่ independent แต่ทั้งชุด dependent เช่น $(1,0),(0,1),(1,1)$

5. Span บอกว่าทำอะไรได้ และทำอะไรไม่ได้

Span คือเซตของผลลัพธ์จาก linear combination ทุกชุด โดยนิยามทางคณิตศาสตร์อนุญาตสัมประสิทธิ์จริงทั้งบวก ลบ และศูนย์:

\[ \operatorname{span}\{\mathbf A,\mathbf B\} =\{a\mathbf A+b\mathbf B:a,b\in\mathbb R\}. \]

เขียนสมาชิกทั่วไปเป็น $(x,y,z)^{\mathsf T}$ เราจะเห็นข้อจำกัดของพอร์ตที่สองกองนี้สร้างได้:

\[ \begin{aligned} x&=0.6a+0.2b,\qquad y=0.4a,\qquad z=0.8b,\\ a&=2.5y,\qquad b=1.25z,\\ x&=1.5y+0.25z. \end{aligned} \]

จึงเป็นระนาบหนึ่งในสามมิติ ไม่ใช่ทั้ง $\mathbb R^3$ ถ้าต้องการ pure tech $(0,0,1)^{\mathsf T}$ เราจำเป็นต้องใช้ $a=0,b=1.25$ แต่จะติดธนาคาร 0.25 มาด้วย จึงไม่สามารถสร้างเป้าหมายนี้จาก A, B หรือเพิ่ม C เข้าไปช่วยได้

ในตัวอย่างทั่วไปอีกชุด $(2,6,4)^{\mathsf T}=2(1,1,0)^{\mathsf T}+4(0,1,1)^{\mathsf T}$ เพราะพิกัดกลางเป็นผลรวมของพิกัดแรกกับพิกัดสุดท้าย เงื่อนไขแบบนี้เป็นวิธีตรวจว่าจุดอยู่ใน span โดยไม่ต้องเดาสัมประสิทธิ์ไปเรื่อย ๆ

ข้อกำหนดเซตที่ทำได้จาก A และ B
$a,b$ เป็นจำนวนจริงใด ๆทั้ง span ซึ่งเป็นระนาบ อาจต้อง short หรือใช้ leverage
$a+b=1$เส้นตรงผ่าน A และ B ไม่ใช่ทั้งระนาบ
$a,b\ge0$ และ $a+b=1$ส่วนของเส้นตรงระหว่าง A กับ B: แบ่งเงินลงทุนโดยไม่ short
มีเพดานสถานะและต้นทุนเพิ่มเติมต้องตรวจข้อจำกัดอีกชั้น แม้เป้าหมายอยู่ใน span

อย่าใช้คำว่า span กับ “พอร์ตที่อนุญาตให้ซื้อจริง” แทนกันโดยไม่บอกข้อจำกัด และอย่าเหมารวมว่าชุด dependent ให้คำตอบอนันต์เสมอ หากเป้าหมายอยู่นอก span จะไม่มีคำตอบ หากอยู่ใน span และมีทิศซ้ำ จึงสามารถเปลี่ยนสัมประสิทธิ์ตามความสัมพันธ์ศูนย์โดยยังได้เป้าหมายเดิม

6. สามทิศทางที่เติมเต็มสามมิติ

พิจารณา exposure เชิงนามธรรมสามตัว ไม่ใช่น้ำหนักกองทุนที่ต้องรวมเป็นหนึ่ง: $\mathbf u=(1,0,1)^{\mathsf T}$, $\mathbf v=(0,1,1)^{\mathsf T}$ และ $\mathbf w=(1,1,0)^{\mathsf T}$ หาก $a\mathbf u+b\mathbf v+c\mathbf w=\mathbf0$ จะได้

\[ \begin{aligned} a+c&=0,\qquad b+c=0,\qquad a+b=0,\\ a&=-c,\qquad b=-c,\\ -2c&=0\ \Longrightarrow\ c=0\ \Longrightarrow\ a=b=0. \end{aligned} \]

จึง independent ทั้งชุด มีสามทิศทางอิสระในสามมิติและสร้างได้ทั้ง $\mathbb R^3$ ต่างจาก A, B, C ซึ่งมีเพียงสองทิศทาง แม้มีจำนวน vector เท่ากัน Rank ใช้นับจำนวนทิศทางอิสระเหล่านี้ ไม่ใช่นับจำนวนชื่อสินทรัพย์

ตรวจอีกทางด้วย determinant

สำหรับ matrix จัตุรัส คอลัมน์ independent ก็ต่อเมื่อ determinant ไม่เป็นศูนย์ บท matrix จะอธิบายคุณสมบัตินี้ต่อไป ที่นี่เราได้พิสูจน์ด้วยสมการแล้ว จึงใช้ determinant เป็นการตรวจซ้ำ:

\[ \begin{aligned} \det[\mathbf A\ \mathbf B\ \mathbf C] &=0.6(0-0.16)-0.2(0.16-0)+0.4(0.32-0)\\ &=-0.096-0.032+0.128=0,\\ \det[\mathbf u\ \mathbf v\ \mathbf w] &=1(0-1)+1(0-1)=-2. \end{aligned} \]

สำหรับ matrix ที่ไม่จัตุรัส ไม่มี determinant ให้ใช้ตรง ๆ และสำหรับข้อมูลประมาณ การเห็น determinant เล็กไม่ควรถูกตีความทันทีว่า dependent แบบ exact ค่ามีผลจากการปรับหน่วยด้วย งานเชิงตัวเลขจึงมักตรวจ singular values กับ tolerance ที่เหมาะสม

7. Replicate payoff ในตลาดสองสถานะ

สมมติซื้อแล้วถือถึงวันสิ้นงวดได้สองสินทรัพย์ หุ้นหนึ่งหน่วยจ่ายตามราคาสุดท้าย 120 หรือ 80 USD และ bond หนึ่งหน่วยจ่าย 105 USD ทั้งสองสถานะ Call ที่ strike 100 จึงมี payoff 20 หรือ 0 USD เราต้องการจำนวนหุ้น $a$ และ bond $b$ ที่จ่ายเท่ากับ call ทุกสถานะในโมเดลนี้:

\[ \begin{aligned} 120a+105b&=20,\\ 80a+105b&=0,\\ 40a&=20\ \Longrightarrow\ a=0.5,\\ b&=-\frac{40}{105}=-\frac8{21}. \end{aligned} \]

ตรวจกลับ: สถานะขึ้นจ่าย $60-40=20$ และสถานะลงจ่าย $40-40=0$ ส่วน bond ติดลบหมายถึงการกู้หรือ short ตามข้อกำหนดของโมเดล Payoff สองคอลัมน์เป็นอิสระ เพราะ $120(105)-80(105)=4{,}200\ne0$ จึงมีคำตอบเพียงชุดเดียว

ถ้าซื้อขายแบ่งหน่วยได้ ทำ short/กู้ได้ ไม่มีต้นทุน และโมเดลครอบคลุม cash flow ทุกสถานการณ์ หลัก no-arbitrage บอกว่าราคา call ต้องเท่ากับต้นทุนพอร์ตที่จ่ายเหมือนกัน:

\[ C_0=0.5S_0-\frac8{21}B_0. \]

เหตุผลคือถ้าราคาต่างกัน เราสามารถขายสิ่งที่แพงกว่าและซื้อสิ่งที่ถูกกว่า รับส่วนต่างวันนี้ แต่ cash flow ในอนาคตหักล้างกัน ทั้งนี้เงื่อนไขซื้อขายต้องทำได้จริง หากเปลี่ยนชุดสถานะหรือเพิ่มข้อจำกัด ข้อสรุปอาจใช้ไม่ได้

ในตลาดสถานะจำกัด การมี payoff vectors ที่ span ครบทุกสถานะเรียกว่า complete market สินทรัพย์เพิ่มเติมอาจซ้ำซ้อนได้ ไม่จำเป็นว่าทุกตราสารในตลาดต้อง independent เพียงแต่ต้องเลือกชุดที่ครอบคลุม payoff space ได้

8. Independent ไม่ได้แปลว่า hedge ได้ดีหรือถูก

ให้ $\mathbf u=(1,0)^{\mathsf T}$ และ $\mathbf v=(1,\varepsilon)^{\mathsf T}$ เมื่อ $\varepsilon\ne0$ ทั้งคู่ independent แต่ถ้าจะสร้าง $(0,1)^{\mathsf T}$ ต้องใช้สัมประสิทธิ์

\[ \begin{aligned} a+b&=0,\qquad \varepsilon b=1,\\ b&=\frac1\varepsilon,\qquad a=-\frac1\varepsilon,\\ \varepsilon=0.001&\ \Longrightarrow\ (a,b)=(-1000,1000). \end{aligned} \]

ได้คำตอบทางพีชคณิต แต่ต้องใช้สถานะใหญ่หักล้างกัน หาก exposure ช่องที่สองของ $\mathbf u$ จริง ๆ เป็น 0.0001 แทนศูนย์ เป้าหมายช่องนั้นจะเหลือ $-1000(0.0001)+1000(0.001)=0.9$ แทน 1 การเกือบซ้ำจึงทำให้ข้อผิดพลาดเล็กต่อหน่วยถูกขยาย

$1.25\mathbf B-0.25\mathbf H=(0,0,1)^{\mathsf T}$ ในโมเดลสามกลุ่มนี้ แต่ต้อง short H 25% ของเงินฐาน และการหัก exposure ระดับกลุ่มไม่ยืนยันว่าความเสี่ยงรายหุ้นทั้งหมดถูกหักล้าง

JavaScript: ตรวจ residual ไม่ใช่แค่หาสัมประสิทธิ์

โค้ดนี้ใช้โครงสร้างเฉพาะของ A และ B เพื่อแก้จากพิกัดพลังงานกับเทคโนโลยี แล้วตรวจทั้งสามพิกัด ความคลาดเคลื่อนต่ำกว่า $10^{-12}$ ถือว่าเท่ากันสำหรับตัวอย่างที่ปรับหน่วยไว้แล้ว ไม่ใช่ tolerance สากลสำหรับข้อมูลทุกชนิด

const A = [.6, .4, 0], B = [.2, 0, .8], C = [.4, .2, .4];
function mix(a, b) { return A.map((x, i) => a * x + b * B[i]); }
function fitAB(target) {
  if (!Array.isArray(target) || target.length !== 3 || !target.every(Number.isFinite)) {
    throw new TypeError('Need three finite coordinates');
  }
  const a = target[1] / A[1], b = target[2] / B[2];
  const replica = mix(a, b);
  const residual = target.map((x, i) => x - replica[i]);
  const maxError = Math.max(...residual.map(Math.abs));
  const fits = maxError < 1e-12;
  return {a, b, replica, residual, fits,
    longOnlyBudget: fits && a >= 0 && b >= 0 && Math.abs(a + b - 1) < 1e-12};
}
function det3(a, b, c) {
  return a[0] * (b[1] * c[2] - b[2] * c[1])
    - b[0] * (a[1] * c[2] - a[2] * c[1])
    + c[0] * (a[1] * b[2] - a[2] * b[1]);
}
const D = [.45, .15, .40];
const delta = (20 - 0) / (120 - 80), bond = -80 * delta / 105;
const equalBook = A.map((x, i) => (x + B[i] + C[i]) / 3);
const epsilon = .001;
console.log(JSON.stringify({
  C: fitAB(C), D: fitAB(D), pureTech: fitAB([0, 0, 1]),
  equalBook, zeroRelation: mix(.5, .5).map((x, i) => x - C[i]),
  detABC: det3(A, B, C), detABD: det3(A, B, D),
  detIndependent: det3([1, 0, 1], [0, 1, 1], [1, 1, 0]),
  fees: [1e7 * (.003 + .006) / 2, 1e7 * .0025],
  feeSaving: 1e7 * ((.003 + .006) / 2 - .0025),
  delta, bond, up: 120 * delta + 105 * bond,
  down: 80 * delta + 105 * bond, middle: 100 * delta + 105 * bond,
  callPrice: 100 * delta + 100 * bond,
  nearCoefficients: [-1 / epsilon, 1 / epsilon],
  perturbedExposure: -1 / epsilon * .0001 + 1 / epsilon * epsilon
}));

สำหรับระบบทั่วไปควรใช้เครื่องมือเชิงตัวเลขที่ตรวจ rank และ conditioning ได้ ไม่ควรขยายวิธีเลือกสองแถวนี้ไปใช้กับ matrix ใด ๆ โดยไม่ตรวจว่าแถวที่เลือกแก้ได้จริงหรือไม่ การคำนวณ residual หลังแก้ยังจำเป็นเสมอ

ศัพท์ที่ต้องแยกจากกัน
Linear combination
ผลรวมของ vectors ที่คูณด้วยสัมประสิทธิ์ โดยค่าบวก ลบ หรือข้อจำกัดงบประมาณต้องระบุให้ชัด
Linear independence / dependence
ตรวจว่าผลรวมศูนย์บังคับให้สัมประสิทธิ์ทุกตัวเป็นศูนย์หรือไม่ เป็นเรื่องของทั้งชุด ไม่ใช่ดูเพียงแต่ละคู่
Span / rank
Span คือเซตที่สร้างจากส่วนผสมทั้งหมด ส่วน rank นับจำนวนทิศทางอิสระที่ใช้สร้างเซตนั้น
Residual
เป้าหมายลบผลที่สร้างได้ ต้องตรวจทุกพิกัด รวมทั้งพิกัดที่ไม่ได้ใช้หาคำตอบ
Replication / no-arbitrage
Replication ต้องจ่ายตรงกันทุกสถานการณ์ในโมเดล การผูกกับราคาต้องมีเงื่อนไขซื้อขายที่ทำได้จริงและเทียบ cash flow ครบ
ที่มาของแนวคิด

งานของ Grassmann ในปี 1844 และ Peano ในปี 1888 ช่วยพัฒนาภาษาของมิติและ vector spaces ในการเงิน แนวคิดสินทรัพย์ตามสถานะของ Arrow–Debreu ทำให้คำถาม “payoff นี้สร้างจากอะไรได้บ้าง” เป็นเครื่องมือวิเคราะห์ตลาด โดยต้องไม่ลืมว่าพิกัดและสถานะที่เลือกเป็นส่วนหนึ่งของแบบจำลอง

ก่อนบอกว่าพอร์ตซ้ำหรือ hedge ได้ ให้ตรวจตามนี้

  • ระบุพิกัดและหน่วยก่อน ความเท่ากันของ sector weights ไม่ใช่ความเท่ากันของหุ้นหรือ payoff ทั้งหมด
  • หาสัมประสิทธิ์แล้วตรวจทุกพิกัด ใช้ความสัมพันธ์ศูนย์เป็นหลักฐานของ dependence
  • เพิ่มชื่อที่อยู่ใน span เดิมไม่เพิ่มมิติ แต่อาจเปลี่ยนต้นทุนหรือความสะดวกในการซื้อ exposure
  • อยู่ใน span ไม่ได้แปลว่าผ่านข้อจำกัด short, leverage, liquidity หรือทนต่อข้อมูลคลาดเคลื่อนได้
  • ถ้าเลือกชุดที่ independent และ span ครบพื้นที่ที่สนใจได้ เราจะมี basis สำหรับเขียนพอร์ตด้วยพิกัดที่ไม่กำกวม นี่คือหัวข้อ 6.3
