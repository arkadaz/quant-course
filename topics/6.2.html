6.2 Linear Independence and Linear Combinations

สินทรัพย์ตัวใหม่เพิ่มทางเลือกจริงก็ต่อเมื่อมันผสมจากของที่มีอยู่แล้วไม่ได้ และการตรวจเรื่องนี้ทำได้ด้วยการแก้สมการเชิงเส้นธรรมดา

กองทุนรวม (fund) คือก้อนเงินที่ผู้จัดการกองทุนนำไปซื้อหุ้นหลายตัวแทนเรา ทุกกองทุนบอกว่าแบ่งเงินลงหุ้นแต่ละกลุ่มกี่เปอร์เซ็นต์ หน้านี้ใช้หุ้นแค่สามกลุ่ม คือ ธนาคาร พลังงาน และเทคโนโลยี

เราซื้อกองทุน A กับกองทุน B ได้อยู่แล้ว และแบ่งเงินระหว่างสองกองนี้ได้ตามใจ วันนี้โบรกเกอร์ (คนกลางที่ซื้อขายหลักทรัพย์แทนเรา) เสนอกองทุน C มาพร้อมคำโฆษณาว่า “C เพิ่มทางเลือกให้พอร์ต” พอร์ตคือชุดของทุกอย่างที่เราถืออยู่ ทุกกองทุนในหน้านี้เป็นกองทุนสมมติ:

กองทุนธนาคารพลังงานเทคโนโลยี
A (มีอยู่แล้ว)60%40%0%
B (มีอยู่แล้ว)20%0%80%
C (ที่เสนอมา)40%20%40%
D (อีกกองหนึ่ง)45%15%40%

“เพิ่มทางเลือก” ในที่นี้แปลว่า C ให้สัดส่วนสามกลุ่มที่เราแบ่งเงินระหว่าง A กับ B เองแล้วทำไม่ได้ คำโฆษณานี้จริงไหม แล้วกองทุน D ล่ะ

ลองตอบก่อนเปิดเฉลย

C ไม่เพิ่มอะไรเลย ลองใส่เงินครึ่งหนึ่งใน A และอีกครึ่งใน B แต่ละกลุ่มจะได้ครึ่งหนึ่งของ A บวกครึ่งหนึ่งของ B:

\[\begin{aligned} &0.5(60,40,0)+0.5(20,0,80)\\ &=(30,20,0)+(10,0,40)\\ &=(40,20,40). \end{aligned}\]

ผลตรงกับ C ทุกช่อง C จึงเป็นของที่เราทำเองได้อยู่แล้ว

D เพิ่มทางเลือกจริง ให้ $a$ คือสัดส่วนเงินที่ใส่ใน A และ $b$ คือสัดส่วนที่ใส่ใน B พลังงานมาจาก A อย่างเดียว และเทคโนโลยีมาจาก B อย่างเดียว ถ้าอยากได้พลังงาน 15 กับเทคโนโลยี 40 แบบ D สองช่องนี้บังคับ $a$ กับ $b$ ทันที แล้วช่องธนาคารก็ถูกบังคับตามไปด้วย:

\[\begin{aligned} 40a&=15,\quad a=0.375,\\ 80b&=40,\quad b=0.5,\\ 60a+20b&=60(0.375)+20(0.5)\\ &=22.5+10=32.5. \end{aligned}\]

ส่วนผสมได้ธนาคาร 32.5 แต่ D มี 45 จึงไม่มี $a,b$ คู่ไหนทำให้ตรงครบสามช่อง

อย่างไรก็ดี “ไม่เพิ่มทางเลือก” ไม่ได้แปลว่าไร้ประโยชน์ ถ้าค่าธรรมเนียมของ C ถูกกว่าการถือ A คู่กับ B การซื้อ C ก็เป็นทางที่ถูกกว่าในการได้สัดส่วนเดิม

ภาพรวมก่อนลงสูตร

กองทุนแต่ละกองในโจทย์เขียนเป็น vector ได้ คือตัวเลขสามตัวเรียงกัน ช่องละหนึ่งกลุ่มหุ้น เช่น A คือ $(0.6,0.4,0)$ (ทบทวนได้ที่ row vectors และ column vectors) การแบ่งเงินลงหลายกองทุนจึงเป็นการคูณ vector แต่ละตัวด้วยสัดส่วนเงิน แล้วบวกกันทีละช่อง ผลรวมแบบนี้เรียกว่า linear combination ตัวเลขที่ใช้คูณเรียกว่าสัมประสิทธิ์ (coefficient)

ทุกอย่างที่ผสมได้จากชุด vector หนึ่ง รวมกันเรียกว่า span ของชุดนั้น ถ้า vector ตัวไหนผสมได้จากตัวอื่นอยู่แล้ว เหมือน C ที่ผสมจาก A กับ B ได้ มันไม่ได้พาเราไปทิศทางใหม่ ชุดแบบนี้เรียกว่า linearly dependent (มีตัวซ้ำ) ถ้าไม่มีตัวไหนผสมจากตัวอื่นได้เลย ชุดนั้นเรียกว่า linearly independent (ไม่มีตัวซ้ำ)

คำถาม “ของใหม่ผสมจากของเก่าได้ไหม” โผล่บ่อยในงานการเงิน:

  • กองทุนใหม่ให้ exposure ใหม่ไหม exposure คือเงินที่เราเสี่ยงอยู่กับแต่ละกลุ่มหุ้นหรือแต่ละปัจจัย
  • option สร้างจากหุ้นกับ bond ได้ไหม option คือสัญญาที่จ่ายเงินตามราคาหุ้นในอนาคต ส่วน bond คือตราสารที่จ่ายเงินจำนวนแน่นอน ถ้าสร้างได้ ราคาของ option ก็ถูกบังคับด้วยราคาหุ้นกับ bond
  • ทำไมทฤษฎีพอร์ตจึงบอกว่านักลงทุนต้องการกองทุนแค่สองกอง

รูปด้านล่างแสดงสามกรณีในระนาบสองมิติที่ต้องแยกให้ออก จากนั้นหน้านี้จะไปทีละขั้น: หาสัมประสิทธิ์ของการผสมแล้วตรวจทุกช่อง เขียนนิยาม independence เป็นสมการที่ตรวจได้ วัดขนาดของ span ด้วย rank (จำนวนทิศทางที่ไม่ซ้ำ) ใช้หุ้นกับ bond สร้าง call option และดูว่าข้อห้าม short ตัด span ให้เหลือแค่ส่วนเล็ก ๆ (short คือยืมของมาขายก่อนแล้วซื้อคืนทีหลัง ในส่วนผสมมันคือสัมประสิทธิ์ที่ติดลบ)

ศัพท์ที่ใช้ในหัวข้อนี้
Linear combination
ผลรวมของ vector หลายตัวที่แต่ละตัวคูณด้วยตัวเลขหนึ่งตัว ตัวเลขนี้เรียกว่าสัมประสิทธิ์ เช่น $a\mathbf A+b\mathbf B$ ใช้บรรยายการแบ่งเงินลงหลายกองทุน หรือการถือหลายสินทรัพย์พร้อมกัน
Span
ทุก vector ที่ได้จาก linear combination ทุกแบบ โดยสัมประสิทธิ์เป็นจำนวนจริงอะไรก็ได้ รวมถึงค่าติดลบ ใช้ตอบว่าจากเครื่องมือที่มี เราสร้างพอร์ตหรือ payoff แบบไหนได้บ้าง
Linear independence และ dependence
ชุด vector เป็น independent ถ้าทางเดียวที่ผสมแล้วได้ vector ศูนย์คือให้สัมประสิทธิ์ทุกตัวเป็นศูนย์ ถ้ามีทางอื่น ชุดนั้น dependent คือมีตัวหนึ่งที่ผสมจากตัวอื่นได้ ใช้ตรวจว่าเครื่องมือใหม่เพิ่มทิศทางจริงไหม
Rank
จำนวนทิศทางที่ไม่ซ้ำกันในชุด vector หรือในคอลัมน์ของ matrix ใช้วัดขนาดของ span เป็นจำนวนมิติ ไม่ใช่จำนวนชื่อสินทรัพย์
Range
ทุกผลลัพธ์ $M\mathbf x$ ที่ matrix $M$ สร้างได้เมื่อเปลี่ยน $\mathbf x$ ไปทุกแบบ $M\mathbf x$ คือการคูณแต่ละคอลัมน์ของ $M$ ด้วยตัวเลขใน $\mathbf x$ แล้วบวกกัน range จึงเท่ากับ span ของคอลัมน์ของ $M$
NAV และ exposure
NAV (net asset value) คือมูลค่ารวมของทรัพย์สินในกองทุน exposure คือเงินที่เราเสี่ยงอยู่กับแต่ละกลุ่มหรือแต่ละปัจจัย หน้านี้วัดเป็นสัดส่วนของ NAV เช่น ธนาคาร 0.6 แปลว่าเงิน 60% ของกองทุนอยู่ในหุ้นธนาคาร
Short
การยืมสินทรัพย์มาขายก่อน แล้วซื้อคืนทีหลัง ในส่วนผสมมันคือสัมประสิทธิ์ที่ติดลบ การกู้เงินก็คือการ short bond
Payoff, call option และ put option
payoff คือเงินที่สินทรัพย์จ่ายในแต่ละสถานการณ์ในอนาคต call option ให้สิทธิ์ซื้อหุ้นที่ราคาที่ตกลงไว้ เรียกว่า strike $K$ จึงจ่าย $\max(S_1-K,0)$ เมื่อ $S_1$ คือราคาหุ้นตอนนั้น put option ให้สิทธิ์ขายที่ strike จึงจ่าย $\max(K-S_1,0)$
Replication และ complete market
Replication คือการสร้างพอร์ตที่จ่ายเท่ากับตราสารเป้าหมายในทุกสถานการณ์ ตลาดที่ทำแบบนี้ได้กับทุก payoff เรียกว่า complete market ใช้กำหนดราคา option จากราคาหุ้นกับ bond
Arbitrage และ no-arbitrage
arbitrage คือกำไรที่ได้แน่นอนโดยไม่ต้องรับความเสี่ยงเลย ราคาที่ไม่เปิดช่องให้ทำแบบนี้เรียกว่าราคา no-arbitrage
Two-fund theorem
ผลจากทฤษฎีพอร์ตแบบ mean-variance ว่าพอร์ต efficient ทุกพอร์ตเป็น linear combination ของพอร์ต efficient สองพอร์ต พอร์ต efficient คือพอร์ตที่ความผันผวนต่ำสุดเมื่อกำหนดผลตอบแทนคาดหวังไว้ ผลนี้อธิบายว่าทำไมนักลงทุนต้องการกองทุนแค่สองกอง

ขั้นที่ 1 — ผสมพอร์ต: คูณทั้ง vector แล้วบวกทีละช่อง

ก่อนจะถามว่ากองไหนซ้ำ ต้องเขียนการผสมกองทุนเป็นตัวเลขให้ได้ก่อน เราเขียนแต่ละกองทุนเป็น vector สามช่อง เรียงเป็น ธนาคาร พลังงาน เทคโนโลยี แต่ละช่องคือน้ำหนัก คือเงินในกลุ่มนั้นหารด้วย NAV (มูลค่ารวมของกองทุน) เช่น 60% เขียนเป็น 0.6 จากนั้นให้ $a$ คือสัดส่วนเงินของเราที่ใส่ใน A และ $b$ คือสัดส่วนที่ใส่ใน B

\[ \begin{aligned} \mathbf A&=\begin{bmatrix}0.6\\0.4\\0\end{bmatrix},\ \mathbf B=\begin{bmatrix}0.2\\0\\0.8\end{bmatrix},\ \mathbf C=\begin{bmatrix}0.4\\0.2\\0.4\end{bmatrix},\\ a\mathbf A+b\mathbf B&=\begin{bmatrix}0.6a+0.2b\\0.4a\\0.8b\end{bmatrix},\\ 0.5\mathbf A+0.5\mathbf B&=\begin{bmatrix}0.3+0.1\\0.2+0\\0+0.4\end{bmatrix}=\mathbf C. \end{aligned} \]

ทำไมคูณทั้ง vector ด้วยสัดส่วนเงินแล้วบวกทีละช่อง จึงได้ exposure ของพอร์ตผสมจริง ลองนับเงินดู เงินทุก \$1 ใน A มีหุ้นธนาคารอยู่ \$0.6 ถ้าเราใส่ \$0.5 ใน A จะได้หุ้นธนาคาร $0.5\times0.6=\$0.3$ อีก \$0.5 ที่ใส่ใน B ให้หุ้นธนาคาร $0.5\times0.2=\$0.1$ รวมเป็น $0.3+0.1=\$0.4$ ต่อเงินของเรา \$1 ซึ่งตรงกับช่องธนาคารของ C

ช่องอื่นนับแบบเดียวกัน แต่ละช่องจึงเป็น dot product ของสัดส่วนเงิน $(a,b)$ กับน้ำหนักของกลุ่มนั้นในสองกองทุน เช่น ช่องธนาคารคือ $(a,b)\cdot(0.6,0.2)=0.6a+0.2b$ แบบเดียวกับใน row vectors และ column vectors

ขั้นที่ 2 — หาสัมประสิทธิ์จากช่องที่ง่าย แล้วใช้ช่องที่เหลือตรวจ

ตอนนี้เราอยากรู้ว่ากองทุนเป้าหมายผสมจาก A กับ B ได้ไหม คือมี $a,b$ ที่ทำให้ $a\mathbf A+b\mathbf B$ เท่ากับเป้าหมายหรือเปล่า ข้อสำคัญคือ $a,b$ ต้องเป็นคู่เดียวกันใน ทุก ช่อง เพราะเราแบ่งเงินได้ครั้งเดียว จะเลือก $a,b$ ใหม่ให้แต่ละช่องไม่ได้

ช่องพลังงานมีแค่ $a$ (คือ $0.4a$) และช่องเทคโนโลยีมีแค่ $b$ (คือ $0.8b$) สองช่องนี้จึงให้ค่า $a$ กับ $b$ ทันที ส่วนช่องธนาคารเก็บไว้ตรวจ

\[ \begin{aligned} \mathbf C:\quad 0.4a&=0.2,\ a=0.5,\\ 0.8b&=0.4,\ b=0.5,\\ 0.6(0.5)+0.2(0.5)&=0.4,\\ \mathbf D:\quad 0.4a&=0.15,\ a=0.375,\\ 0.8b&=0.40,\ b=0.5,\\ 0.6(0.375)+0.2(0.5)&=0.325\ne0.45. \end{aligned} \]

C ผ่านการตรวจ ช่องธนาคารของส่วนผสมได้ 0.4 เท่ากับของ C จึงสรุปได้ว่า $\mathbf C=0.5\mathbf A+0.5\mathbf B$ ครบทุกช่อง

D ไม่ผ่าน ช่องพลังงานกับช่องเทคโนโลยีบังคับ $a=0.375$ กับ $b=0.5$ จนไม่เหลือตัวไหนให้ปรับ แล้วช่องธนาคารออกมา 0.325 แต่ D ต้องการ 0.45 ขาดไป $0.45-0.325=0.125$ จึงไม่มี $a,b$ คู่ไหนสร้าง D ได้ จุดที่คนพลาดบ่อยคือหยุดทันทีที่หา $a,b$ ได้ ถ้าไม่ตรวจช่องที่เหลือ เราจะสรุปผิดว่า D ก็ซ้ำ

เพิ่ม C เข้าพอร์ตก็ไม่ได้ทิศทางใหม่ ลองซื้อ A, B, C อย่างละหนึ่งในสาม แล้วแทน C ด้วย $\tfrac12\mathbf A+\tfrac12\mathbf B$ ส่วน $\tfrac13\mathbf C$ จึงเท่ากับ $\tfrac16\mathbf A+\tfrac16\mathbf B$:

\[ \begin{aligned} &\tfrac13\mathbf A+\tfrac13\mathbf B+\tfrac13\mathbf C\\ &=(\tfrac13+\tfrac16)\mathbf A+(\tfrac13+\tfrac16)\mathbf B\\ &=\tfrac12\mathbf A+\tfrac12\mathbf B=\mathbf C. \end{aligned} \]

พอร์ตมีสามชื่อ แต่สัดส่วนสามกลุ่มยังเท่ากับ C เดิม: สามชื่อ แต่มีแค่สองทิศทาง

ขั้นที่ 3 — นิยาม independence: ผสมได้ศูนย์ทางเดียวคือไม่ใส่อะไรเลย

ถ้ามีกองทุนหลายกอง การไล่ถามทีละกองว่า “กองนี้สร้างจากกองอื่นได้ไหม” จะยุ่งมาก นิยามที่ใช้จริงจึงรวมทุกตัวไว้ในคำถามเดียว: มีวิธีผสมที่สัมประสิทธิ์ไม่เป็นศูนย์ทั้งหมด แล้วได้ vector ศูนย์ไหม

ให้ชุดที่ตรวจมี $k$ ตัว คือ $\mathbf v_1,\dots,\mathbf v_k$ และให้ $a_1,\dots,a_k$ เป็นสัมประสิทธิ์ของแต่ละตัว ชุดนี้เป็น linearly independent เมื่อเงื่อนไขแถวบนสุดข้างล่างเป็นจริง:

\[ \begin{aligned} \sum_{i=1}^{k}a_i\mathbf v_i=\mathbf 0 &\ \Rightarrow\ a_1=\cdots=a_k=0,\\ a_j\ne0:\quad \mathbf v_j&=-\sum_{i\ne j}\frac{a_i}{a_j}\,\mathbf v_i,\\ 0.5\mathbf A+0.5\mathbf B-\mathbf C&=\mathbf 0. \end{aligned} \]

นิยามบอกว่า ถ้าผสมแล้วได้ศูนย์ สัมประสิทธิ์ต้องเป็นศูนย์ทุกตัว ทำไมเงื่อนไขนี้จับ “ตัวซ้ำ” ได้ สมมติมีวิธีผสมได้ศูนย์ที่ $a_j$ ไม่เป็นศูนย์ ย้ายพจน์ $a_j\mathbf v_j$ ไปอีกข้างของสมการ แล้วหารด้วย $a_j$ จะได้ $\mathbf v_j$ เป็นส่วนผสมของตัวอื่น จังหวะที่ต้องระวังคือการหาร ซึ่งทำได้ก็เพราะ $a_j\ne0$

ทางกลับก็จริง ถ้า $\mathbf v_j=\sum_{i\ne j}c_i\mathbf v_i$ อยู่แล้ว ให้ $a_j=-1$ และ $a_i=c_i$ ก็ผสมได้ศูนย์ โดยมีสัมประสิทธิ์ตัวหนึ่งเป็น $-1$ ดังนั้น “มีตัวซ้ำ” กับ “ผสมได้ศูนย์แบบไม่ใช่ศูนย์ล้วน” จึงเป็นคำถามเดียวกัน

ชุด A, B, C ผสมได้ศูนย์ด้วยสัมประสิทธิ์ $0.5$, $0.5$, $-1$ ตามแถวล่างสุด จึงเป็น dependent แม้ไม่มีคู่ไหนขนานกันเลย ส่วน A กับ B สองตัวเป็น independent เพราะถ้า $a\mathbf A+b\mathbf B=\mathbf 0$ ช่องพลังงานบังคับ $0.4a=0$ จึงได้ $a=0$ และช่องเทคโนโลยีบังคับ $0.8b=0$ จึงได้ $b=0$

มีสองกรณีที่คนมักพลาด กรณีแรก ชุดที่มี vector ศูนย์อยู่ด้วยเป็น dependent เสมอ เพราะให้สัมประสิทธิ์ของ vector ศูนย์เป็น 1 และของตัวอื่นเป็น 0 ก็ได้ศูนย์แล้ว กรณีที่สอง การตรวจทีละคู่ไม่พอ $(1,0)$, $(0,1)$, $(1,1)$ ไม่มีคู่ไหนขนานกัน แต่ $(1,0)+(0,1)-(1,1)=(0,0)$ ทั้งชุดจึงวนกลับศูนย์ได้ ตามแผงขวาของรูปสามแผงด้านบน

ขั้นที่ 4 — span มีขนาดเท่าไร: rank นับทิศทางที่ไม่ซ้ำ

รู้แล้วว่า A กับ B เป็นสองทิศทางที่ไม่ซ้ำกัน คำถามถัดไปคือ สองทิศทางนี้พาเราไปถึงพอร์ตแบบไหนได้บ้าง ให้ $(x,y,z)$ เป็นพอร์ตใดก็ได้ที่ผสมจาก A กับ B โดย $x$ คือน้ำหนักธนาคาร $y$ คือพลังงาน และ $z$ คือเทคโนโลยี เราจะใช้สองช่องที่ง่ายแก้หา $a$ กับ $b$ แล้วแทนลงช่องธนาคาร เพื่อให้เหลือเงื่อนไขที่มีแค่ $x,y,z$

\[ \begin{aligned} y&=0.4a,\quad a=2.5y,\\ z&=0.8b,\quad b=1.25z,\\ x&=0.6a+0.2b\\ &=0.6(2.5y)+0.2(1.25z)\\ &=1.5y+0.25z. \end{aligned} \]

ผลคือกฎข้อเดียว: ทุกพอร์ตที่ผสมจาก A กับ B ต้องมีน้ำหนักธนาคาร $x=1.5y+0.25z$ สมการเชิงเส้นข้อเดียวในสามตัวแปรที่ไม่มีค่าคงที่ คือสมการของระนาบที่ผ่านจุดกำเนิด span ของ A กับ B จึงเป็นระนาบหนึ่งในพื้นที่สามมิติ ไม่ใช่ทั้งพื้นที่

ลองพอร์ตเทคโนโลยีล้วน $(0,0,1)$ กฎบอกว่ามันต้องมีธนาคาร $1.5(0)+0.25(1)=0.25$ แต่มันมี 0 จึงสร้างไม่ได้ การเพิ่ม C เข้ามาก็ไม่ช่วย เพราะ C ผ่านกฎนี้ ($1.5(0.2)+0.25(0.4)=0.4$) จึงอยู่ในระนาบเดิม จำนวนทิศทางที่ไม่ซ้ำกันเรียกว่า rank ชุด A, B, C จึงมี rank 2: สามชื่อ แต่สองทิศทาง

ในงานจริง เรามักเก็บสินทรัพย์ไว้เป็นคอลัมน์ของ matrix จึงต้องอ่าน rank จาก matrix ให้เป็นด้วย ให้ $\mathbf x=(x_1,x_2,x_3)$ เป็นสัมประสิทธิ์ ผลคูณ $M\mathbf x$ คือการคูณคอลัมน์ที่ 1, 2, 3 ด้วย $x_1,x_2,x_3$ แล้วบวกกัน ผลทั้งหมดที่ได้เมื่อเปลี่ยน $\mathbf x$ ไปทุกแบบเรียกว่า range ของ $M$ ตัวอย่างนี้เป็นกรณีที่ span เล็กที่สุดที่ไม่ใช่จุดศูนย์จุดเดียว คือทุกคอลัมน์ชี้ทางเดียวกัน

\[ \begin{aligned} M&=\begin{bmatrix}1&2&3\\2&4&6\end{bmatrix},\\ \begin{bmatrix}2\\4\end{bmatrix}&=2\begin{bmatrix}1\\2\end{bmatrix},\quad \begin{bmatrix}3\\6\end{bmatrix}=3\begin{bmatrix}1\\2\end{bmatrix},\\ M\mathbf x&=x_1\begin{bmatrix}1\\2\end{bmatrix}+x_2\begin{bmatrix}2\\4\end{bmatrix}\\ &\quad+x_3\begin{bmatrix}3\\6\end{bmatrix}\\ &=(x_1+2x_2+3x_3)\begin{bmatrix}1\\2\end{bmatrix}. \end{aligned} \]

ทั้งสามคอลัมน์เป็นผลคูณของ $(1,2)$ พอแทนเข้าไป ทุกพจน์จึงรวบเป็นตัวเลขตัวเดียวคูณ $(1,2)$ ไม่ว่าเลือก $\mathbf x$ อย่างไร $M\mathbf x$ ก็อยู่บนเส้นตรงที่ผ่าน $(1,2)$ เท่านั้น เหมือนแผงกลางของรูปสามแผงด้านบน range ของ $M$ คือเส้นนั้น และ rank เท่ากับ 1

นับจากแถวก็ได้ผลเท่ากัน แถวที่สอง $(2,4,6)$ คือสองเท่าของแถวแรก $(1,2,3)$ จึงมีแถวที่ไม่ซ้ำแค่แถวเดียว ความจริงข้อนี้ใช้ได้เสมอ: จำนวนแถวที่ไม่ซ้ำเท่ากับจำนวนคอลัมน์ที่ไม่ซ้ำ rank จึงไม่เกินจำนวนแถว และไม่เกินจำนวนคอลัมน์ เหตุผลอยู่ใน rank, range และ invertibility

ขั้นที่ 5 — สามทิศทางที่เติมเต็มสามมิติ

ชุด A, B, C มีสามชื่อแต่ให้แค่สองทิศทาง ทีนี้ลองดูชุดสามตัวที่ไม่มีตัวซ้ำเลย เพื่อดูว่าสามทิศทางเติมเต็มพื้นที่สามมิติได้อย่างไร ให้ $\mathbf u=(1,0,1)$, $\mathbf v=(0,1,1)$, $\mathbf w=(1,1,0)$ แล้วตรวจตามนิยาม คือตั้งส่วนผสมด้วยสัมประสิทธิ์ $a,b,c$ ให้เท่ากับศูนย์ แล้วดูว่า $a,b,c$ ถูกบังคับให้เป็นศูนย์หมดหรือไม่

\[ \begin{aligned} a\mathbf u+b\mathbf v+c\mathbf w&=\mathbf 0,\\ a+c=0,\ b+c&=0,\ a+b=0,\\ a=-c,\ b&=-c,\\ a+b=-2c&=0,\\ c=0,\ a&=b=0. \end{aligned} \]

เขียนทีละช่องได้สามสมการ สองสมการแรกบอกว่า $a$ กับ $b$ ต่างก็เท่ากับ $-c$ พอแทนลงสมการที่สามจะได้ $-2c=0$ จึงได้ $c=0$ แล้ว $a$ กับ $b$ ก็เป็นศูนย์ตาม ทางเดียวที่ผสมได้ศูนย์คือไม่ใส่อะไรเลย ชุดนี้จึง independent

สามทิศทางที่ไม่ซ้ำในพื้นที่สามมิติ span ได้ทั้งพื้นที่ ไม่ว่าเป้าหมายเป็น vector ไหน จะมีสัมประสิทธิ์ชุดเดียวเท่านั้นที่ไปถึง ทำไมชุดเดียว เพราะถ้ามีสองชุดที่ไปถึงเป้าหมายเดียวกัน นำสองชุดมาลบกันจะได้วิธีผสมได้ศูนย์ที่ไม่ใช่ศูนย์ล้วน ซึ่งขัดกับที่เพิ่งพิสูจน์

ตรวจซ้ำด้วย determinant

determinant คือตัวเลขหนึ่งตัวที่คำนวณจาก matrix จัตุรัส (จำนวนแถวเท่ากับจำนวนคอลัมน์) ความจริงที่ใช้ตรงนี้คือ คอลัมน์ของ matrix จัตุรัสเป็น independent ก็ต่อเมื่อ determinant ไม่เป็นศูนย์ เหตุผลอยู่ใน rank, range และ invertibility ที่นี่ใช้มันตรวจซ้ำสิ่งที่พิสูจน์ด้วยสมการแล้ว

วิธีคำนวณคือวาง vector สามตัวเป็นสามคอลัมน์ แล้วกระจายตามแถวแรก: คูณแต่ละตัวในแถวแรกด้วย determinant ขนาด 2×2 ของช่องที่เหลือเมื่อตัดแถวและคอลัมน์ของตัวนั้นออก แล้วบวก ลบ บวก สลับกัน

\[ \begin{aligned} \det[\mathbf A\ \mathbf B\ \mathbf C] &=\det\begin{bmatrix}0.6&0.2&0.4\\0.4&0&0.2\\0&0.8&0.4\end{bmatrix}\\ &=0.6(0-0.16)-0.2(0.16-0)\\ &\quad+0.4(0.32-0)\\ &=-0.096-0.032+0.128=0,\\ \det[\mathbf A\ \mathbf B\ \mathbf D] &=0.6(0-0.12)-0.2(0.16-0)\\ &\quad+0.45(0.32-0)\\ &=-0.072-0.032+0.144=0.04,\\ \det[\mathbf u\ \mathbf v\ \mathbf w] &=1(0-1)-0(0-1)+1(0-1)\\ &=-2. \end{aligned} \]

A, B, C ได้ศูนย์ ตรงกับที่พบว่ามีตัวซ้ำ A, B, D ได้ 0.04 ซึ่งไม่เป็นศูนย์ แปลว่า D เพิ่มทิศทางใหม่ ตรงกับที่เราหา $a,b$ ให้ D ไม่ได้ ส่วน $\mathbf u,\mathbf v,\mathbf w$ ได้ $-2$ จึง independent ตามที่พิสูจน์ไว้

ข้อควรระวังกับข้อมูลจริง: determinant ที่เล็กไม่ได้แปลว่าเกือบซ้ำเสมอไป เพราะมันเปลี่ยนตามหน่วย ถ้าเขียนน้ำหนักเป็นเปอร์เซ็นต์แทนทศนิยม ทุกช่องจะคูณ 100 การคูณคอลัมน์หนึ่งด้วย 100 ทำให้ determinant คูณ 100 สามคอลัมน์จึงคูณ $100^3$ ได้ $0.04\times100^3=40{,}000$ ทั้งที่เป็นกองทุนชุดเดิมทุกอย่าง งานเชิงตัวเลขจึงไม่ตัดสินจากขนาดของ determinant แต่ใช้วิธีที่ไม่เปลี่ยนตามหน่วย

ขั้นที่ 6 — สร้าง call option จากคอลัมน์ payoff ของหุ้นกับ bond

เครื่องมือเดียวกันใช้กับ option ได้ด้วย call option คือสัญญาที่ให้สิทธิ์ซื้อหุ้นในอนาคตที่ราคาซึ่งตกลงไว้ล่วงหน้า ราคานี้เรียกว่า strike ถ้าปีหน้าหุ้นขึ้นไปสูงกว่า strike ผู้ถือ call ได้ส่วนต่าง ถ้าไม่สูงกว่า ได้ศูนย์ ธนาคารที่ขาย call ให้ลูกค้าต้องจ่ายส่วนต่างนี้ จึงอยากรู้ว่าสร้างเงินก้อนเดียวกันจากหุ้นกับ bond ได้ไหม ถ้าได้ ต้นทุนของการสร้างก็คือราคาที่ call ควรมี

เงินที่สินทรัพย์จ่ายในแต่ละสถานการณ์เรียกว่า payoff ตาราง payoff เขียนเป็น matrix $S$ ได้ โดยแถวคือสถานการณ์และคอลัมน์คือสินทรัพย์ เหมือนใน row vectors และ column vectors ถ้าถือหุ้น $a$ หน่วยและ bond $b$ หน่วย คือ $\boldsymbol\theta=(a,b)$ พอร์ตจะจ่าย $S\boldsymbol\theta$ ซึ่งคือการผสมคอลัมน์ของ $S$ คำถามว่า payoff ของ call สร้างได้ไหม จึงเป็นคำถามว่ามันอยู่ใน range ของ $S$ หรือเปล่า

โจทย์ให้อะไรมาบ้าง (ตลาดสมมติ):

  • ปีหน้ามีแค่สองสถานการณ์: ราคาขึ้น หรือราคาลง
  • หุ้น: วันนี้ราคา \$100 ปีหน้ามีค่า \$120 ถ้าขึ้น หรือ \$80 ถ้าลง
  • bond: วันนี้ราคา \$100 ปีหน้าจ่าย \$105 ทั้งสองกรณี
  • call strike \$100: จ่าย $\max(S_1-100,0)$ เมื่อ $S_1$ คือราคาหุ้นปีหน้า กรณีขึ้นได้ $\max(120-100,0)=\$20$ กรณีลงได้ $\max(80-100,0)=\$0$

เราต้องหา $a$ กับ $b$ ที่ทำให้พอร์ตจ่ายเท่ากับ call ในทั้งสองสถานการณ์ แต่ละสถานการณ์ให้สมการหนึ่งข้อ ส่วนราคา call วันนี้ $C_0$ ก็คือต้นทุนของพอร์ตนี้วันนี้ ซึ่งคิดได้ง่ายเพราะหุ้นกับ bond ราคาวันนี้ตัวละ \$100:

\[ \begin{aligned} 120a+105b&=20,\\ 80a+105b&=0,\\ (120-80)a&=20-0,\quad a=0.5,\\ 105b&=-80(0.5)=-40,\\ b&=-\tfrac{40}{105}=-\tfrac{8}{21},\\ C_0&=100a+100b\\ &=0.5(100)-\tfrac{8}{21}(100)\\ &=\tfrac{250}{21}\approx11.90. \end{aligned} \]

ทำไมการลบสมการได้ผล เพราะ bond จ่ายเท่ากันทั้งสองกรณี พอลบสมการที่สองออกจากสมการแรก $b$ จึงหายไป เหลือแค่ส่วนต่างของหุ้น $120-80=40$ ที่ต้องสร้างส่วนต่างของ call $20-0=20$ จึงต้องถือหุ้น $20/40=0.5$ หน่วย

คำตอบ: ซื้อหุ้นครึ่งหน่วย และ short bond $8/21\approx0.381$ หน่วย การ short bond ก็คือการกู้เงิน วันนี้ได้เงิน $\tfrac{8}{21}\times100\approx\$38.10$ แล้วปีหน้าคืน $\tfrac{8}{21}\times105=\$40$ พอร์ตนี้มีต้นทุนวันนี้ \$11.90 ตรวจกลับ: ถ้าราคาขึ้น พอร์ตจ่าย $0.5(120)-40=\$20$ ถ้าราคาลง พอร์ตจ่าย $0.5(80)-40=\$0$ ตรงกับ call ทั้งสองกรณี

ราคา \$11.90 นี้ถูกบังคับ ไม่ใช่แค่ค่าประมาณ สมมติมีคนยอมซื้อ call จากเราที่ \$13 เราขาย call ให้เขา แล้วใช้เงิน \$11.90 สร้างพอร์ตจำลอง จะได้เงินทันที $13-11.90=\$1.10$ ปีหน้าพอร์ตจ่ายเท่ากับที่เราต้องจ่ายให้ผู้ถือ call พอดีทั้งสองกรณี กำไรนี้จึงไม่มีความเสี่ยงเลย เรียกว่า arbitrage ถ้าราคาต่ำกว่า \$11.90 ก็ทำกลับข้างได้ คือซื้อ call แล้ว short พอร์ตจำลอง ราคาเดียวที่ไม่เปิดช่องแบบนี้ (ราคา no-arbitrage) จึงเป็น \$11.90 ภายใต้แบบจำลองสองสถานการณ์นี้ ซึ่งเป็นจุดตั้งต้นของ binomial tree pricing

ตรวจเองใน 10 วินาที: ทำไมตลาดนี้สร้าง payoff ได้ทุกแบบ ให้ดูว่าคอลัมน์หุ้น $(120,80)$ กับคอลัมน์ bond $(105,105)$ ขนานกันไหม สอง vector $(p,q)$ กับ $(r,s)$ ขนานกันเมื่อสัดส่วนเท่ากัน คือ $ps-qr=0$ ที่นี่ได้ $120(105)-80(105)=4{,}200\ne0$ จึงไม่ขนาน สองคอลัมน์ที่ไม่ซ้ำในสองมิติ span ได้ทั้งระนาบ payoff ใด ๆ ในตลาดสองสถานการณ์นี้จึงสร้างได้ ตลาดแบบนี้เรียกว่า complete market

ขั้นที่ 7 — กองทุนสองกองพอ: two-fund theorem และข้อจำกัดที่ตัด span

กลับมาที่กองทุน คำถามสุดท้ายคือ นักลงทุนต้องมีกองทุนกี่กอง ทฤษฎีพอร์ตแบบ mean-variance เลือกพอร์ตโดยชั่งผลตอบแทนคาดหวัง (mean) กับความผันผวน (วัดด้วย variance) พอร์ตที่ความผันผวนต่ำสุดเมื่อกำหนดผลตอบแทนคาดหวังไว้ เรียกว่าพอร์ต efficient ทฤษฎีนี้มีผลที่เรียกว่า two-fund theorem: ถ้ามีพอร์ต efficient สองพอร์ตที่ผลตอบแทนคาดหวังไม่เท่ากัน พอร์ต efficient ทุกพอร์ตเป็นส่วนผสมของสองพอร์ตนี้ ขั้นนี้ดูเฉพาะส่วนที่เป็นพีชคณิตเชิงเส้นของผลนั้น

สัญลักษณ์ที่ใช้:

  • $\mathbf x^{(1)}$ กับ $\mathbf x^{(2)}$ คือ vector น้ำหนักของพอร์ต efficient สองพอร์ต ที่มีผลตอบแทนคาดหวัง $r_1$ และ $r_2$ โดย $r_1\ne r_2$
  • $\boldsymbol\mu$ คือ vector ผลตอบแทนคาดหวังของสินทรัพย์แต่ละตัว และ $\mathbf 1$ คือ vector ที่ทุกช่องเป็น 1
  • $\beta$ คือสัดส่วนเงินที่ใส่ในพอร์ตที่สอง ส่วนที่เหลือ $1-\beta$ ใส่ในพอร์ตแรก ($\beta$ ตรงนี้เป็นแค่ชื่อสัมประสิทธิ์ ไม่ใช่ beta ของหุ้น) และ $\mathbf y$ คือพอร์ตที่ผสมได้
  • $r$ คือผลตอบแทนคาดหวังที่เราต้องการ
\[ \begin{aligned} \mathbf y&=(1-\beta)\mathbf x^{(1)}+\beta\mathbf x^{(2)},\\ \mathbf 1^{\mathsf T}\mathbf y&=(1-\beta)(1)+\beta(1)=1,\\ \boldsymbol\mu^{\mathsf T}\mathbf y&=(1-\beta)r_1+\beta r_2,\\ r&=r_1+\beta(r_2-r_1),\\ \beta&=\frac{r-r_1}{r_2-r_1}. \end{aligned} \]

ผลรวมน้ำหนัก $\mathbf 1^{\mathsf T}\mathbf y$ และผลตอบแทนคาดหวัง $\boldsymbol\mu^{\mathsf T}\mathbf y$ เป็น dot product ซึ่งเป็นเชิงเส้น คือผลของส่วนผสมเท่ากับส่วนผสมของผล น้ำหนักของสองพอร์ตต่างก็รวมเป็น 1 ส่วนผสมจึงยังใช้เงินครบพอดี และผลตอบแทนคาดหวังก็ผสมด้วยสัดส่วนเดียวกัน ตั้งให้เท่ากับเป้า $r$ แล้วจัดรูปเป็น $r=r_1+\beta(r_2-r_1)$ ก็แก้หา $\beta$ ได้ การหารด้วย $r_2-r_1$ ทำได้เพราะ $r_1\ne r_2$

ส่วนคำถามว่าทำไมส่วนผสมนี้ efficient ด้วย คำตอบมาจากเงื่อนไขของคำตอบที่ดีที่สุด ซึ่งเป็นเชิงเส้นเช่นกัน (ดู Markowitz portfolio selection) ผลคือ กองทุนแค่สองกองก็พอสร้างพอร์ต efficient ได้ทุกพอร์ต

ตัวอย่าง (สมมติ): ให้ A กับ B เป็นพอร์ต efficient ที่ผลตอบแทนคาดหวัง $r_1=4\%$ และ $r_2=8\%$ ถ้าเป้าคือ 6% จะได้ $\beta=\dfrac{6-4}{8-4}=0.5$ ซึ่งก็คือ C ถ้าเป้าคือ 10% จะได้ $\beta=\dfrac{10-4}{8-4}=1.5$ และพอร์ตคือ

\[ \begin{aligned} &-0.5\mathbf A+1.5\mathbf B\\ &=-0.5(0.6,0.4,0)+1.5(0.2,0,0.8)\\ &=(-0.3,-0.2,0)+(0.3,0,1.2)\\ &=(0,-0.2,1.2). \end{aligned} \]

ช่องพลังงานติดลบ แปลว่าต้อง short หุ้นพลังงาน 20% ของ NAV ซึ่งเกิดจากการ short กองทุน A ครึ่งหนึ่งของเงินเรา และถือเทคโนโลยี 120% นี่คือจุด E นอกสามเหลี่ยมในรูปสามเหลี่ยมด้านบน

สิ่งที่ผสมได้จริงขึ้นกับว่าเรายอมให้สัมประสิทธิ์เป็นอะไรได้บ้าง ยิ่งมีข้อจำกัดมาก ส่วนที่ไปถึงได้ยิ่งเล็ก:

ข้อกำหนดของสัมประสิทธิ์สิ่งที่ผสมได้จาก A และ B
$a,b$ เป็นจำนวนจริงอะไรก็ได้ทั้งระนาบ $x=1.5y+0.25z$ (span) อาจต้อง short หรือกู้เงิน
$a+b=1$เส้นตรงผ่าน A และ B (เส้นเขียวรวมเส้นประในรูปสามเหลี่ยม)
$a+b=1$ และ $a,b\ge0$แค่ส่วนเขียวระหว่าง A กับ B คือแบ่งเงินโดยไม่ short
มีเพดานขนาดสถานะ (position limit) ค่าธรรมเนียม ภาษีเล็กลงอีก แม้เป้าหมายอยู่ใน span ก็อาจทำจริงไม่ได้

ความผิดที่ทำให้สรุปผิดว่า “สร้างได้” หรือ “ปลอดภัย”

เกือบซ้ำแต่ไม่ซ้ำ: ความผิดคือเชื่อว่าชุดที่ independent ใช้สร้างทุกอย่างได้อย่างปลอดภัย ให้ $\mathbf u=(1,0)$ กับ $\mathbf v=(1,0.2)$ สองตัวนี้ independent แต่เกือบชี้ทางเดียวกัน จะสร้างเป้าหมาย $(0,1)$ ต้องแก้ $a\mathbf u+b\mathbf v=(0,1)$ ทีละช่อง:

\[ \begin{aligned} a+b&=0,\quad 0.2b=1,\\ b&=5,\quad a=-5. \end{aligned} \]

ต้องถือสองขาขนาด 5 เท่าที่หักล้างกัน เพื่อได้ของขนาดแค่ 1 ถ้าช่องที่สองของ $\mathbf v$ เล็กลงเป็น 0.001 จะได้ $b=1/0.001=1{,}000$ และ $a=-1{,}000$

ขาที่ใหญ่ขยายความผิดเล็ก ๆ ในข้อมูล สมมติช่องที่สองของ $\mathbf u$ ที่จริงไม่ใช่ 0 แต่เป็น 0.02 ในกรณีแรก หรือ 0.0001 ในกรณีที่สอง ส่วนผสมเดิมจะให้ช่องที่สองเป็น:

\[ \begin{aligned} -5(0.02)+5(0.2)&=0.9,\\ -1{,}000(0.0001)+1{,}000(0.001)&=0.9. \end{aligned} \]

เราคิดว่าจะได้ 1 แต่ได้จริง 0.9 พลาด 10% ของเป้าหมายทั้งสองกรณี กรณีที่สองใช้ความผิดแค่ 0.0001 ซึ่งเล็กกว่ากรณีแรก $0.02/0.0001=200$ เท่า ยิ่งสองทิศใกล้กัน ความผิดที่เล็กกว่าเดิมมากก็พาไปพลาดได้มากเท่าเดิม

น้ำหนักกลุ่มเท่ากัน ไม่ได้แปลว่า payoff เท่ากัน: ความผิดคือคิดว่าสัดส่วนสามกลุ่มเท่ากันแล้วผลตอบแทนจะเท่ากัน C กับครึ่ง A ครึ่ง B มีน้ำหนักสามกลุ่ม $(0.4,0.2,0.4)$ เท่ากัน แต่หุ้นรายตัวข้างในอาจต่างกัน เช่น C อาจถือธนาคารคนละแห่งกับ A ผลตอบแทนจริงจึงต่างกันได้ การซื้อ C แล้ว short ส่วนผสม A/B เพื่อเก็บส่วนต่างค่าธรรมเนียมจึงยังมีความเสี่ยง ไม่ใช่ arbitrage

independence มีสองความหมาย: ความผิดคือเอา linear independence ไปแปลว่าผลตอบแทนไม่เกี่ยวกัน linear independence เป็นเรื่องของ vector ที่รู้ค่าแน่นอน ว่าตัวหนึ่งผสมจากตัวอื่นได้ไหม ส่วน independence ของตัวแปรสุ่ม ถามว่ารู้ค่าตัวหนึ่งแล้ว การแจกแจงของอีกตัวเปลี่ยนไหม A กับ B independent ในความหมายแรก เพราะ exposure ไม่ซ้ำกัน แต่ถ้าหุ้นธนาคารกับหุ้นเทคโนโลยีขึ้นลงพร้อมกันบ่อย ผลตอบแทนของสองกองก็เคลื่อนไหวไปด้วยกันมาก ซึ่งวัดด้วย correlation

ตรวจไม่ครบทุกสถานการณ์: ความผิดคือตรวจพอร์ตจำลองเฉพาะสถานการณ์ที่ใช้ตั้งสมการ สมมติตลาดจริงมีสถานการณ์ที่สามที่หุ้นจบที่ \$100 พอร์ตจำลอง call (หุ้น 0.5 หน่วย กับหนี้ที่ต้องคืน \$40) จะจ่าย $0.5(100)-40=\$10$ แต่ call จ่าย $\max(100-100,0)=\$0$ พลาดไป \$10 เหตุผลคือ เมื่อมีสามสถานการณ์ payoff เป็น vector สามช่อง สองคอลัมน์ (หุ้นกับ bond) span ได้แค่ระนาบหนึ่งในพื้นที่สามมิตินี้ และ payoff ของ call อยู่นอกระนาบนั้น

ใช้ทำอะไรบนโต๊ะจริง

ของที่ไม่เพิ่มทิศทางใหม่ยังมีประโยชน์ได้ ถ้ามันถูกกว่า กองทุนเก็บค่าธรรมเนียมรายปีเป็นเปอร์เซ็นต์ของเงินที่เราลงไว้ เรียกว่า expense ratio ลองเทียบสองทางที่ได้สัดส่วนสามกลุ่มเท่ากัน คือถือครึ่ง A ครึ่ง B กับถือ C อย่างเดียว ตัวเลขสมมติ:

  • เงินที่ลงทุน \$10 ล้าน
  • expense ratio ต่อปีของ A คือ 0.30% ของ B คือ 0.60% และของ C คือ 0.25%

ให้ $f_{AB}$ คืออัตราค่าธรรมเนียมเฉลี่ยของทางครึ่ง A ครึ่ง B และให้ $F_{AB}$ กับ $F_C$ คือค่าธรรมเนียมต่อปีเป็นดอลลาร์ของแต่ละทาง:

\[ \begin{aligned} f_{AB}&=0.5(0.30\%)+0.5(0.60\%)=0.45\%,\\ F_{AB}&=0.45\%\times\$10{,}000{,}000=\$45{,}000,\\ F_C&=0.25\%\times\$10{,}000{,}000=\$25{,}000,\\ F_{AB}-F_C&=\$20{,}000. \end{aligned} \]

ถือ C ประหยัดได้ \$20,000 ต่อปี สำหรับ exposure สามกลุ่มเดิม ตัวเลขนี้ยังไม่นับภาษี ค่าซื้อขาย และความต่างของหุ้นข้างใน

คำถามเดียวกันโผล่อีกครั้งในงาน factor model ซึ่งอธิบายผลตอบแทนของหุ้นจำนวนมากด้วยปัจจัยร่วมไม่กี่ตัว (factor) เมื่อมีคนเสนอ factor ใหม่ คำถามแรกคือ มันอยู่ใน span ของ factor เดิมหรือเปล่า ถ้าอยู่ มันไม่ได้อธิบายอะไรเพิ่ม (ดู alpha spanned และ orthogonal)

โจทย์ตรวจความเข้าใจ

1. เราอยากได้พอร์ตเทคโนโลยีล้วน $(0,0,1)$ ซึ่ง A กับ B สร้างไม่ได้ สมมติโบรกเกอร์มีกองทุนธนาคารล้วน $\mathbf H=(1,0,0)$ ให้ซื้อด้วย จะสร้างพอร์ตเทคโนโลยีล้วนจาก B กับ H อย่างไร

เฉลย

ให้ $b$ คือสัดส่วนเงินใน B และ $h$ คือสัดส่วนเงินใน H ช่องเทคโนโลยีมีแต่ B จึงใช้หา $b$ ก่อน แต่ B พาหุ้นธนาคารมาด้วย จึงต้องใช้ H หักออกให้ช่องธนาคารเป็นศูนย์:

\[ \begin{aligned} 0.8b&=1,\quad b=1.25,\\ 0.2(1.25)+h&=0,\quad h=-0.25,\\ 1.25\mathbf B-0.25\mathbf H&=(0.25-0.25,\,0,\,1)\\ &=(0,0,1). \end{aligned} \]

ช่องพลังงานเป็นศูนย์ทั้งในสองกองอยู่แล้วจึงตรง คำตอบคือใส่เงิน 125% ใน B และ short H 25% สร้างได้ในระดับกลุ่ม แต่ต้อง short ได้จริง

2. ใช้ตลาดสองสถานการณ์เดิม: หุ้นวันนี้ \$100 ปีหน้า \$120 หรือ \$80 และ bond วันนี้ \$100 จ่าย \$105 ทั้งสองกรณี put option strike \$100 คือสิทธิ์ขายหุ้นที่ \$100 จึงจ่าย $\max(100-S_1,0)$ กรณีขึ้นได้ $\max(100-120,0)=\$0$ กรณีลงได้ $\max(100-80,0)=\$20$ จงหาพอร์ตหุ้นกับ bond ที่จ่ายเท่ากับ put และหาราคา put วันนี้ $P_0$

เฉลย

ตั้งสมการทีละสถานการณ์เหมือนตอนสร้าง call แล้วลบสมการเพื่อกำจัด $b$:

\[ \begin{aligned} 120a+105b&=0,\\ 80a+105b&=20,\\ 40a&=-20,\quad a=-0.5,\\ 105b&=-120(-0.5)=60,\\ b&=\tfrac{60}{105}=\tfrac47\approx0.571,\\ P_0&=100a+100b\\ &=-50+\tfrac{400}{7}=\tfrac{50}{7}\approx7.14. \end{aligned} \]

คือ short หุ้นครึ่งหน่วย และซื้อ bond $4/7$ หน่วย ราคา put \$7.14 ตรวจกับความสัมพันธ์ระหว่าง call กับ put:

\[ \begin{aligned} C_0-P_0&=11.90-7.14=4.76,\\ 100-\tfrac{100}{1.05}&=100-95.24=4.76. \end{aligned} \]

แถวบนคือราคา call ลบราคา put แถวล่างคือราคาหุ้นวันนี้ลบมูลค่าวันนี้ของ strike โดย strike \$100 ที่จ่ายปีหน้ามีค่าวันนี้ $100/1.05$ เพราะเงินใน bond โตจาก \$100 เป็น \$105 สองข้างเท่ากัน ตรงกับ put–call parity

3. มีสามกองทุนที่แบ่งเงินลงสองกลุ่ม กลุ่มละครึ่ง กองแรกถือธนาคารกับพลังงาน $(0.5,0.5,0)$ กองที่สองถือพลังงานกับเทคโนโลยี $(0,0.5,0.5)$ กองที่สามถือธนาคารกับเทคโนโลยี $(0.5,0,0.5)$ ชุดนี้ independent ไหม

เฉลย

ให้สัมประสิทธิ์ของสามกองเป็น $a,b,c$ ตั้งส่วนผสมให้เท่ากับศูนย์ แล้วเขียนทีละช่อง (ธนาคาร พลังงาน เทคโนโลยี):

\[ \begin{aligned} 0.5a+0.5c&=0,\quad c=-a,\\ 0.5a+0.5b&=0,\quad b=-a,\\ 0.5b+0.5c&=0.5(-a)+0.5(-a)\\ &=-a=0. \end{aligned} \]

จึงได้ $a=0$ แล้ว $b=c=0$ ตาม ทางเดียวที่ผสมได้ศูนย์คือศูนย์ทุกตัว ชุดนี้ independent อีกวิธีตรวจ: สามกองนี้คือครึ่งหนึ่งของ $\mathbf w,\mathbf v,\mathbf u$ ชุดสามทิศทางที่เติมเต็มสามมิติด้านบน การคูณด้วย 0.5 ไม่เปลี่ยนทิศทาง สามกองนี้จึงผสมได้ทุกสัดส่วนของสามกลุ่ม ถ้า short ได้

const A = [0.6, 0.4, 0], B = [0.2, 0, 0.8], C = [0.4, 0.2, 0.4], D = [0.45, 0.15, 0.40];
const mix = (a, b) => A.map((x, i) => a * x + b * B[i]);
function fitAB(target) {
  const a = target[1] / A[1], b = target[2] / B[2];   // energy row, tech row
  const residual = target.map((x, i) => x - mix(a, b)[i]);
  return {a, b, residual, fits: Math.max(...residual.map(Math.abs)) < 1e-12};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • หาสัมประสิทธิ์จากช่องที่แก้ง่าย แล้วตรวจช่องที่เหลือทุกช่อง: C $=0.5\mathbf A+0.5\mathbf B$ ผ่าน แต่ D ขาดน้ำหนักธนาคาร $0.45-0.325=0.125$
  • ชุด vector เป็น independent เมื่อทางเดียวที่ผสมได้ศูนย์คือให้สัมประสิทธิ์เป็นศูนย์ทุกตัว ถ้ามีทางอื่น ตัวหนึ่งเขียนเป็นส่วนผสมของตัวอื่นได้ และการตรวจทีละคู่ไม่พอ
  • rank นับทิศทางที่ไม่ซ้ำ ไม่ใช่จำนวนชื่อ: A, B, C มี rank 2 และ matrix ที่ทุกคอลัมน์เป็นผลคูณของ $(1,2)$ มี rank 1
  • payoff ที่อยู่ใน range ของตาราง payoff สร้างได้จากสินทรัพย์ที่มี และราคาของมันถูกบังคับด้วย no-arbitrage: call ในตัวอย่างราคา \$11.90
  • span ยอมให้สัมประสิทธิ์ติดลบ ข้อห้าม short ตัดเหลือแค่ส่วนเขียว และทิศที่เกือบขนานต้องใช้สถานะใหญ่ที่ไวต่อความผิดพลาด

หน้าถัดไป basis เลือกชุดที่ independent และ span ได้ครบพอดี แล้วใช้ชุดนั้นเป็นแกนใหม่ในการบรรยายพอร์ตเดิม โดยเงินไม่หายไปสักดอลลาร์
