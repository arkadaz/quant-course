14.6 Volatility Trading Structures: the Desk Playbook

straddle, strangle, risk reversal, butterfly และ calendar คือ option หลายขาที่ประกอบให้เหลือเฉพาะความเสี่ยงที่อยากถือ และ option ที่ hedge delta แล้วคือเดิมพันว่าความผันผวนที่เกิดจริงจะสูงหรือต่ำกว่า implied

หุ้นราคา \$100 ความผันผวน 20% ต่อปี ดอกเบี้ยศูนย์ คุณซื้อ straddle strike 100 อายุ 3 เดือน (call กับ put strike 100 อย่างละหนึ่ง) จำนวน 1,000 หน่วย เพื่อนบอกว่า “straddle ได้เงินเมื่อหุ้นขยับ ทางไหนก็ได้” ถ้าวันหมดอายุหุ้นจบที่ \$105 คุณได้หรือเสียเท่าไร และต้องจบนอกช่วงไหนจึงเริ่มได้กำไร?

ลองตอบก่อนเปิดเฉลย

เสีย \$2,975.52 straddle ราคา \$7.9755 ต่อหน่วย จบที่ \$105 ได้คืนแค่ \$5 ต่อหน่วย ต้องจบต่ำกว่า \$92.02 หรือสูงกว่า \$107.98 จึงเริ่มได้กำไร จบที่ \$115 ได้ \$7,024.48 ราคา \$7.98 ไม่ได้ตั้งขึ้นลอย ๆ มันเท่ากับขนาดการขยับเฉลี่ยของหุ้นตลอด 3 เดือนที่ความผันผวน 20% คือราว 0.8 เท่าของ SD \$10 straddle จึงได้กำไรเมื่อหุ้นขยับมากกว่าที่ราคาคิดไว้ ไม่ใช่แค่ขยับ

ภาพรวมก่อนลงสูตร

option ตัวเดียวให้ความเสี่ยงหลายอย่างพร้อมกัน: ทิศทาง (delta) ขนาดการแกว่ง (gamma และ vega) และเวลา (theta) ตามหน้าของ Greeks คนที่อยากเดิมพันแค่ “หุ้นจะแกว่งแรง” แต่ไม่รู้ทิศ ถ้าซื้อ call ตัวเดียวก็ได้ทิศทางติดมาด้วย โต๊ะจึงประกอบหลายขาเข้าด้วยกันให้เหลือเฉพาะสิ่งที่ต้องการ แล้ว hedge delta ที่เหลือด้วยหุ้น ราคาของ option ที่ซื้อขายคล่องมาจากอุปสงค์อุปทาน ความผันผวนจึงกลายเป็นสินค้าที่ซื้อขายได้เองเหมือนหุ้นหรือพันธบัตร

หน้านี้ใช้หุ้น \$100 ความผันผวนแบน 20% ดอกเบี้ยศูนย์ ไม่มีปันผล อายุแรก 0.25 ปีและอายุที่สอง 0.5 ปี ราคาทุกขามาจากสูตร Black–Scholes รูปสี่ช่องด้านล่างคือภาพรวมทั้งหน้า: กำไรขาดทุนวันหมดอายุของสี่โครงสร้างอายุเดียว แต่ละรูปทรงบอกว่าโครงสร้างนั้นได้เงินเมื่อไร

ลำดับคือ ราคา straddle ด้วยมือและเหตุผลว่าทำไมมันเท่ากับขนาดการขยับเฉลี่ย เขียนห้าโครงสร้างเป็นขาที่มีเครื่องหมาย หาจุดคุ้มทุน ตีราคา calendar รวม Greeks ตามขา แล้วดูหัวใจของการเทรดความผันผวน: option ที่ hedge delta แล้วได้เสียตาม gamma คูณ (การขยับจริงกำลังสอง ลบ การขยับที่ราคาคิดไว้) ตามด้วยตัวอย่างเส้นทางจริง 50 ช่วง ตาราง scenario ว่าแต่ละโครงสร้างซื้อส่วนไหนของผืนความผันผวน และจบที่ dispersion ซึ่งซื้อขาย correlation ระหว่างหุ้นในดัชนี

ศัพท์ที่ใช้ในหัวข้อนี้
Straddle และ strangle
straddle คือซื้อ call กับ put ที่ strike เดียวกัน strangle คือซื้อ put strike ต่ำกับ call strike สูง ทั้งสองได้เงินเมื่อหุ้นขยับไกลทางไหนก็ได้ strangle ถูกกว่าแต่ต้องขยับไกลกว่าจึงเริ่มจ่าย
Risk reversal
ซื้อ call strike สูงและขาย put strike ต่ำ (หรือกลับกัน) มีทิศทางชัด ราคาขึ้นกับว่า put ต่ำแพงกว่า call สูงแค่ไหน จึงใช้ซื้อขาย skew ของผืนความผันผวน
Butterfly
ซื้อ call สอง strike ปีก และขาย call strike กลางสองใบ payoff เป็นกระโจมที่สูงสุดตรงกลาง จำกัดทั้งกำไรและขาดทุน ใช้เดิมพันว่าหุ้นจะจบใกล้ strike กลาง หรือซื้อความโค้งของ smile
Calendar spread
ขาย option อายุสั้นและซื้อ option strike เดียวกันอายุยาว ใช้ซื้อขายความต่างระหว่างอายุบนผืนความผันผวน สองขาหมดอายุคนละวัน จึงต้องตีราคาขายาวในวันที่ขาสั้นหมด
Payoff, P&L และจุดคุ้มทุน
payoff คือเงินที่สัญญาจ่ายวันหมดอายุ P&L คือ payoff ลบเงินที่จ่ายตอนเปิด จุดคุ้มทุนคือราคาหุ้นที่ทำให้ P&L เป็นศูนย์ payoff ของคนซื้อ option ไม่เคยติดลบ แต่ P&L ติดลบได้
Delta-hedged option และ realized volatility
option ที่ถือคู่กับหุ้นจำนวน delta และปรับทุกช่วง ทิศทางหายไป เหลือกำไรขาดทุนจากขนาดการขยับ realized volatility คือความผันผวนที่หุ้นแกว่งจริงระหว่างทาง ใช้เทียบกับ implied volatility ที่จ่ายไปตอนซื้อ
Dispersion และ implied correlation
dispersion คือขายความผันผวนของดัชนีแล้วซื้อความผันผวนของหุ้นรายตัวในดัชนี กำไรเมื่อหุ้นเดินแยกกันมากกว่าที่ราคาคิด implied correlation คือค่า correlation ที่ทำให้ความผันผวนของดัชนีตรงกับของหุ้นรายตัว
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$S_0,\ S_T$ราคาหุ้นวันนี้ และวันหมดอายุดอลลาร์
$C(K,T),\ P(K,T)$ราคา call และ put ที่ strike $K$ อายุ $T$ดอลลาร์ต่อหุ้น
$T_1,\ T_2$อายุ 0.25 และ 0.5 ปีปี
$n_i$จำนวนหน่วยของขาที่ $i$ ซื้อเป็นบวก ขายเป็นลบหน่วย
$H(S_T),\ V_0$payoff รวมของชุด และเงินสุทธิที่จ่ายตอนเปิดดอลลาร์ต่อหน่วย
$\Delta,\ \Gamma,\ \nu,\ \Theta$delta, gamma, vega และ theta รวมตามขาต่อหุ้น, ต่อดอลลาร์, ต่อจุดความผันผวน, ต่อวัน
$\delta t,\ R$ช่วงเวลาระหว่างการปรับ hedge และผลตอบแทนของหุ้นในช่วงนั้นปี, ไม่มีหน่วย
$w_i,\ \sigma_i,\ \rho,\ \sigma_I$น้ำหนัก ความผันผวน และ correlation ของหุ้นในดัชนี และความผันผวนของดัชนีไม่มีหน่วย, ต่อรากที่สองของปี

ขั้นที่ 1 — ลองด้วยมือ: straddle ราคาเท่าไร และทำไม

โจทย์ให้อะไรมาบ้าง: $S_0=K=100$, $r=0$, $\sigma=0.20$, $T=0.25$ ในสูตร Black–Scholes เมื่อ $S_0=K$ และ $r=0$ ตัวเศษของ $d_1$ เหลือแค่ $\tfrac12\sigma^2T$ แล้วเทียบกับขนาดการขยับเฉลี่ย $S_0\sigma\sqrt T\,\mathbb E|Z|$

\[ \begin{aligned} d_1&=\frac{\tfrac12(0.04)(0.25)}{0.20(0.5)}=\frac{0.005}{0.10}=0.05,\\ C&=100\big[\Phi(0.05)-\Phi(-0.05)\big]\\ &=100(0.519939-0.480061)=3.987761,\\ P&=C-S_0+K=3.987761,\\ V_0&=C+P=7.975522,\\ \mathbb E|Z|&=2\int_0^\infty z\,\phi(z)\,dz=2\phi(0)=\sqrt{2/\pi},\\ S_0\sigma\sqrt T\,\mathbb E|Z|&=100(0.10)(0.797885)=7.978846. \end{aligned} \]

คำตอบ: straddle ราคา \$7.9755 ต่อหน่วย put เท่ากับ call พอดีเพราะ put–call parity ที่ $r=0$ และ $S_0=K$ ให้ $C-P=S_0-K=0$ บรรทัดสุดท้ายอธิบายตัวเลข: ที่ $r=0$ ราคา straddle คือค่าเฉลี่ยของ $|S_T-K|$ ภายใต้ risk-neutral measure และเมื่อ $\sigma\sqrt T$ เล็ก $S_T-S_0\approx S_0\sigma\sqrt T\,Z$ ค่าเฉลี่ยของขนาดการขยับจึงเป็น 0.8 เท่าของ SD \$10 ใกล้ 7.9755 มาก

ตรวจเองใน 10 วินาที: อินทิกรัล $\int_0^\infty z\phi(z)\,dz$ คือ $\big[-\phi(z)\big]_0^\infty=\phi(0)=0.3989$ สูตรในหัวของโต๊ะ “straddle ATM ≈ $0.8\,S\sigma\sqrt T$” มาจากบรรทัดนี้ ที่ 20% สามเดือนคือ $0.8(100)(0.2)(0.5)=8.0$

ขั้นที่ 2 — ห้าโครงสร้างเป็นขาที่มีเครื่องหมาย

ชื่อกลยุทธ์ไม่บอกเครื่องหมาย สองโต๊ะอาจหมายถึงทิศตรงข้ามด้วยชื่อเดียวกัน ขั้นนี้นิยามแต่ละตัวเป็นขาที่มีจำนวนและเครื่องหมาย แล้วเขียน payoff วันหมดอายุ บรรทัดของ straddle ใช้สองกรณี: ถ้า $S_T\ge K$ call จ่าย $S_T-K$ put ไม่จ่าย ถ้า $S_T\lt K$ put จ่าย $K-S_T$ call ไม่จ่าย ทั้งสองกรณีคือ $|S_T-K|$

\[ \begin{aligned} H_{\rm straddle}&=(S_T-100)^++(100-S_T)^+\\ &=|S_T-100|,\\ H_{\rm strangle}&=(90-S_T)^++(S_T-110)^+,\\ H_{\rm RR}&=(S_T-110)^+-(90-S_T)^+,\\ H_{\rm fly}&=(S_T-90)^+-2(S_T-100)^+\\ &\quad+(S_T-110)^+,\\ H_{\rm fly}&=\big[(S_T-90)^+-(S_T-100)^+\big]\\ &\quad-\big[(S_T-100)^+-(S_T-110)^+\big]. \end{aligned} \]

บรรทัดสุดท้ายอ่าน butterfly เป็น bull spread 90/100 ลบ bear spread 100/110 ก้อนแรกขึ้นจาก 0 ถึง 10 ระหว่าง 90 กับ 100 ก้อนหลังขึ้นจาก 0 ถึง 10 ระหว่าง 100 กับ 110 ลบกันจึงได้กระโจม: 0 ที่ 90, 10 ที่ 100, 0 ที่ 110 และ 0 นอกช่วง ตัวคูณ −2 ที่ strike 100 มาจากการที่ strike นี้ถูกใช้ในทั้งสอง spread

ขั้นที่ 3 — payoff ไม่ใช่กำไร: จุดคุ้มทุนของโครงสร้างอายุเดียว

โจทย์ให้อะไรมาบ้าง: payoff และราคาจากตารางขา P&L ต่อหน่วยคือ $H(S_T)-V_0$ (ดอกเบี้ยศูนย์ จึงลบตรงได้) จุดคุ้มทุนคือ $H(S_T)=V_0$ ซึ่งสำหรับ straddle คือ $|S_T-100|=7.975522$ มีสองคำตอบ แล้วคิด P&L ของ 1,000 หน่วยในโจทย์เปิดเรื่อง

\[ \begin{aligned} \text{straddle}:\ S_T&=100\pm7.975522\\ &=92.0245,\ 107.9755,\\ \text{strangle}:\ S_T&=90-1.6663,\ 110+1.6663\\ &=88.3337,\ 111.6663,\\ \text{fly}:\ S_T&=90+3.6908,\ 110-3.6908\\ &=93.6908,\ 106.3092,\\ 1{,}000(5-7.975522)&=-2{,}975.52,\\ 1{,}000(15-7.975522)&=+7{,}024.48. \end{aligned} \]

คำตอบ: straddle ต้องจบนอก 92.02 ถึง 107.98 ช่องขาดทุนกว้าง $2V_0=15.95$ strangle ถูกกว่าเกือบห้าเท่าแต่ต้องจบนอก 88.33 ถึง 111.67 butterfly กำไรเฉพาะเมื่อจบระหว่าง 93.69 ถึง 106.31 และได้สูงสุด $10-3.6908=6.3092$ ที่ 100 ส่วน risk reversal จ่าย 0.2416 แล้วได้กำไรเมื่อจบเหนือ 110.24 แต่ขาดทุนไม่จำกัดขาลง เพราะขาย put ไว้ (จุดดำในรูปสี่ช่องด้านบน)

ตรวจเองใน 10 วินาที: butterfly 3.6908 หารด้วยระยะ strike ยกกำลังสอง $10^2$ ได้ 0.0369 ใกล้ density ของ $S_T$ ที่ 100 ภายใต้ risk-neutral measure คือ $\phi(-0.05)/(100\times0.1)=0.0398$ ตามผล “ราคา butterfly ต่อ $h^2$ คือ density” ของผืนความผันผวน (ห่าง 7% เพราะระยะ 10 ยังไม่เล็กพอ)

ขั้นที่ 4 — calendar: ตีราคาขายาวในวันที่ขาสั้นหมดอายุ

calendar ขาย call อายุ 0.25 ปีและซื้อ call อายุ 0.5 ปี strike เดียวกัน วันที่ขาสั้นหมดอายุ ขายาวยังเหลืออายุ 0.25 ปี จึงยังมีค่าเวลา ต้องตีราคามันด้วยสูตร Black–Scholes ที่ราคาหุ้นวันนั้น ไม่ใช่ใช้ payoff ของมัน บรรทัดแรกเป็นนิยามของมูลค่าในวันนั้น (ความผันผวนยัง 20%)

\[ \begin{aligned} V_{T_1}&=C\big(S_{T_1},100,0.25\big)-(S_{T_1}-100)^+,\\ S_{T_1}=100:\ V_{T_1}&=3.9878-0=3.9878,\\ S_{T_1}=110:\ V_{T_1}&=10.9539-10=0.9539,\\ S_{T_1}=90:\ V_{T_1}&=0.7124,\\ V_{T_1}&=1.649437\ \Rightarrow\ S_{T_1}=94.22,\ 106.53. \end{aligned} \]

calendar ได้มากที่สุดเมื่อหุ้นอยู่ที่ strike ในวันที่ขาสั้นหมด: ขาสั้นหมดค่า ขายาวยังมีค่าเวลาเต็ม กำไร $3.9878-1.6494=2.3383$ ต่อหน่วย ถ้าหุ้นหนีไปไกลทางไหนก็ตาม ค่าเวลาของขายาวหาย และส่วนที่ขาสั้นต้องจ่ายหักกับส่วนในเงินของขายาว มูลค่าจึงเข้าหาศูนย์ จุดคุ้มทุนหาด้วยการแก้สมการบรรทัดสุดท้ายเชิงตัวเลข

ที่ \$110 ขายาวมีค่า 10.9539 คือเงินในตัว \$10 บวกค่าเวลา 0.9539 ขาสั้นจ่าย \$10 จึงเหลือแค่ค่าเวลา ที่ \$90 ขาสั้นไม่จ่าย แต่ขายาวอยู่นอกเงินและเหลือค่าเวลาแค่ 0.7124 ค่าเวลาของ option สูงสุดที่ strike และลดลงทั้งสองฝั่ง calendar จึงคือการถือค่าเวลาของขายาวไว้ขาย ณ วันที่ขาสั้นหมด

ขั้นที่ 5 — Greeks ของชุดคือผลรวมของขาที่มีเครื่องหมาย

มูลค่าของชุดคือผลรวมถ่วงด้วยจำนวนหน่วย อนุพันธ์ของผลรวมคือผลรวมของอนุพันธ์ และจำนวนหน่วยเป็นค่าคงที่ที่เราเลือก Greeks ทุกตัวจึงบวกกันตามขาได้ตรง ๆ เงื่อนไขเดียวคือทุกขาต้องคำนวณที่ราคาหุ้น เวลา และผืนความผันผวนชุดเดียวกัน

\[ \begin{aligned} V_{\rm set}&=\sum_i n_iV_i,\\ \Delta_{\rm set}&=\frac{\partial V_{\rm set}}{\partial S}=\sum_i n_i\Delta_i,\\ \Gamma_{\rm set}&=\sum_i n_i\Gamma_i,\quad\nu_{\rm set}=\sum_i n_i\nu_i,\\ \Theta_{\rm set}&=\sum_i n_i\Theta_i. \end{aligned} \]

เหตุผลนี้ไม่ได้ใช้อะไรเกี่ยวกับ option เลย ใช้แค่ว่าการหาอนุพันธ์กระจายเข้าไปในผลบวกได้ ข้อควรระวังอยู่ที่เครื่องหมาย: ขาที่ขายมี $n_i$ ติดลบ butterfly จึงมี $n=-2$ ที่ strike 100 และ calendar มี $n=-1$ ที่ขาสั้น

ขั้นที่ 6 — Greeks ของ straddle ด้วยมือ แล้วครบห้าโครงสร้าง

โจทย์ให้อะไรมาบ้าง: สูตร Greeks ที่ $S=100$, $r=0$, $d_1=0.05$, $\phi(0.05)=0.398444$ delta ของ put คือ delta ของ call ลบ 1 (หาอนุพันธ์ของ parity) ส่วน gamma และ vega ของ put เท่ากับของ call vega รายงานต่อความผันผวน 1 จุด theta ต่อวันปฏิทิน (365 วันต่อปี)

\[ \begin{aligned} \Delta&=\Phi(0.05)+\big(\Phi(0.05)-1\big)\\ &=2(0.519939)-1=0.039878,\\ \Gamma&=2\,\frac{0.398444}{100(0.2)(0.5)}=0.079689,\\ 0.01\,\nu&=2(0.01)(100)(0.398444)(0.5)\\ &=0.398444,\\ \Theta/365&=-2\,\frac{100(0.398444)(0.2)}{2(0.5)(365)}\\ &=-0.043665. \end{aligned} \]

คำตอบ: straddle ATM แทบไม่มีทิศ (delta 0.04) แต่มี gamma สองเท่าของ call ตัวเดียว ได้ \$0.40 ต่อความผันผวน 1 จุด และเสียค่าเวลา \$0.0437 ต่อวัน ตารางข้างล่างทำแบบเดียวกันครบทุกโครงสร้าง ต่อหน่วย ที่ $S=100$

ขั้นที่ 7 — option ที่ hedge delta แล้ว ได้เสียตามการขยับจริงเทียบกับที่ราคาคิด

straddle แทบไม่มี delta แต่ “แทบ” ไม่ใช่ศูนย์ และ delta เปลี่ยนทุกครั้งที่หุ้นขยับ โต๊ะจึงถือ option คู่กับหุ้นจำนวน delta แล้วปรับทุกช่วง $\delta t$ คำถามคือพอร์ตนี้ได้เสียจากอะไร ใช้ Taylor สองชั้นกับราคา option บวกค่าเวลา ลบขาหุ้นและดอกเบี้ยของเงินที่ยืม แล้วแทน theta ด้วย PDE ของ Black–Scholes ($\Theta+rS\Delta+\tfrac12\sigma^2S^2\Gamma=rC$ จากพอร์ตทำซ้ำ)

\[ \begin{aligned} \delta\Pi&=\delta C-\Delta\,\delta S-r(C-\Delta S)\,\delta t,\\ \delta C&\approx\Theta\,\delta t+\Delta\,\delta S+\tfrac12\Gamma(\delta S)^2,\\ \Theta&=rC-rS\Delta-\tfrac12\sigma^2S^2\Gamma,\\ \delta\Pi&\approx\tfrac12\Gamma S^2\Big[R^2-\sigma^2\delta t\Big],\\ R&=\frac{\delta S}{S},\qquad |R|^*=\sigma\sqrt{\delta t}. \end{aligned} \]

แทนบรรทัดที่สองและสามลงในบรรทัดแรก พจน์ $\Delta\,\delta S$ หักกับขาหุ้น พจน์ดอกเบี้ยทุกตัวหักกันหมด เหลือบรรทัดที่สี่: ในแต่ละช่วง ผู้ถือ option ที่ hedge แล้วได้ gamma คูณผลต่างระหว่างผลตอบแทนจริงกำลังสองกับ $\sigma^2\delta t$ ที่ราคา option คิดไว้ ทิศไม่มีผลเลย เพราะ $R$ ถูกยกกำลังสอง

จุดคุ้มทุนต่อช่วงคือ $|R|=\sigma\sqrt{\delta t}$ ขยับน้อยกว่านั้นเสียค่าเวลา ขยับมากกว่านั้นได้จาก gamma รวมทุกช่วงแล้ว ผู้ซื้อได้เงินถ้าความผันผวนที่เกิดจริง (realized) สูงกว่า implied ที่จ่ายไป ผู้ขายได้ถ้าต่ำกว่า และน้ำหนักของแต่ละช่วงคือ $\Gamma S^2$ ในช่วงนั้น ช่วงที่หุ้นอยู่ใกล้ strike ตอนใกล้หมดอายุมีน้ำหนักมากที่สุด

ขั้นที่ 8 — เส้นทางเดียว 50 ช่วง: ขาย call ที่ 30% แล้วหุ้นแกว่งแค่ 24.9%

โจทย์ให้อะไรมาบ้าง: โต๊ะขาย call 100,000 ตัว หุ้น \$50 strike \$50 อายุ 3 เดือน implied volatility 30% ดอกเบี้ย 2% รับเงิน \$310,815 แล้วทำพอร์ตทำซ้ำ: ถือหุ้นจำนวน delta และปรับ 50 ครั้ง (ทุก $\delta t=0.005$ ปี หรือราว 1.26 วันทำการ) บนเส้นทางราคาสมมติหนึ่งเส้นที่จบที่ \$54.41 log return ทั้ง 50 ช่วงมี SD คิดเป็นต่อปี 24.9% วันหมดอายุเทียบมูลค่าพอร์ตกับเงินที่ต้องจ่ายให้ผู้ซื้อ แล้วเทียบกับผลรวมของสูตรต่อช่วงที่เพิ่งได้ (เครื่องหมายกลับ เพราะโต๊ะเป็นผู้ขาย)

\[ \begin{aligned} |R|^*&=0.30\sqrt{0.005}=2.12\%\ \ (\$1.06),\\ \text{payoff}&=100{,}000(54.41-50)=\$440{,}790,\\ \text{portfolio}&=\$496{,}182,\\ \text{P\&L}&=496{,}182-440{,}790=+\$55{,}392,\\ \text{sum}&=\sum_i\tfrac12N\Gamma_iS_i^2\big[\sigma^2\delta t-R_i^2\big]\\ &\approx+\$46{,}584. \end{aligned} \]

คำตอบ: ผู้ขายที่ hedge ครบได้ \$55,392 หรือ 18% ของเบี้ยที่รับมา ไม่ใช่เพราะเดาทิศถูก (หุ้นขึ้น 8.8% และ call จบในเงิน) แต่เพราะหุ้นแกว่งแค่ 24.9% ต่ำกว่า 30% ที่ขายไป สูตรต่อช่วงอธิบายได้ \$46,584 ส่วนที่เหลือมาจากการที่ปรับ hedge เป็นช่วงห่าง และ Taylor สองชั้นไม่แม่นเมื่อ gamma เปลี่ยนเร็ว

ตรวจเองใน 10 วินาที: ดูรูปข้างล่าง กำไรสะสมขึ้นถึง \$77,334 ก่อนหมดอายุสองช่วง แล้วหุ้นกระโดด +4.2% จาก \$51.43 เป็น \$53.57 ตอนอยู่ใกล้ strike และเหลืออายุแค่ 0.01 ปี gamma ช่วงนั้นสูงมาก ช่วงเดียวกินกำไรไป \$21,919 ความผันผวนเฉลี่ยทั้งเส้นจึงไม่พอ ต้องดูว่าการขยับใหญ่เกิดตอนไหน

ขั้นที่ 9 — แต่ละโครงสร้างซื้อส่วนไหนของผืนความผันผวน

ตรวจเองใน 10 วินาที: คอลัมน์ขนานเกือบเท่า vega ในตาราง Greeks (ต่างกันเล็กน้อยเพราะ vega เองเปลี่ยนเมื่อความผันผวนขยับ) คอลัมน์ skew ของ straddle เป็นศูนย์เพราะไม่มีขาที่ 90 หรือ 110 และ straddle ได้ทั้งหุ้นขึ้นและลง แต่ขึ้นได้มากกว่าเพราะ delta +0.04

ขั้นที่ 10 — dispersion: variance ของดัชนีแยกเป็นส่วนเดี่ยวกับส่วนร่วม

ถ้าอยากซื้อขาย correlation ระหว่างหุ้นในดัชนี ต้องรู้ก่อนว่ามันอยู่ตรงไหนในความผันผวนของดัชนี ผลตอบแทนดัชนีคือผลรวมถ่วงน้ำหนักของหุ้น ใช้สูตร variance ของผลรวมเชิงเส้น แล้วแยกคู่ที่เป็นตัวเดียวกันออกจากคู่ที่ต่างกัน ตัวอย่างใช้หุ้นสองตัวน้ำหนักเท่ากัน ความผันผวน 20% และ 30% correlation 0.4 (สมมติ)

\[ \begin{aligned} r_I&=\sum_i w_ir_i,\\ \sigma_I^2&=\sum_i w_i^2\sigma_i^2+2\sum_{i\lt j}w_iw_j\sigma_i\sigma_j\rho_{ij},\\ \text{own}&=0.25(0.04)+0.25(0.09)=0.0325,\\ \text{cross}&=2(0.5)(0.5)(0.2)(0.3)\rho=0.03\rho,\\ \rho=0.4:\ \sigma_I^2&=0.0325+0.012=0.0445,\\ \sigma_I&=\sqrt{0.0445}=21.10\%. \end{aligned} \]

บรรทัดที่สองคือ variance ของผลรวม = ผลรวมของทุกคู่ $w_iw_j\operatorname{Cov}(r_i,r_j)$ คู่ $ij$ กับ $ji$ ให้ค่าเท่ากันจึงรวมเป็นสองเท่า และ covariance เขียนเป็น $\sigma_i\sigma_j\rho_{ij}$ ก้อนแรกเห็นได้จาก option ของหุ้นรายตัว ก้อนที่สองขึ้นกับ correlation อย่างเดียว

ดัชนีแกว่ง 21.10% ต่ำกว่าความผันผวนเฉลี่ยของหุ้น 25% ส่วนต่างคือการกระจายความเสี่ยง ถ้า $\rho=1$ ดัชนีจะแกว่ง 25% เต็ม ถ้า $\rho=0$ เหลือ 18.03%

ขั้นที่ 11 — dispersion ได้เงินเมื่อหุ้นเดินแยกกันมากกว่าที่ราคาคิด

โจทย์ให้อะไรมาบ้าง: ขาย variance ของดัชนีที่ระดับ 0.0445 (correlation 0.4) notional \$1,000,000 ต่อ variance 1.00 และซื้อ variance ของหุ้นรายตัวในขนาดที่หักกับส่วนเดี่ยวพอดี (ด้วย variance swap) ถ้าหุ้นแต่ละตัวแกว่งเท่าที่ราคาคิดไว้ แต่ correlation ที่เกิดจริงคือ 0.2 ได้เสียเท่าไร และถ้าตลาดขาย option ดัชนีที่ 22% correlation ที่ราคาบอกคือเท่าไร

\[ \begin{aligned} \rho=0.2:\ \sigma_I^2&=0.0325+0.006=0.0385,\\ \text{P\&L}&=1{,}000{,}000(0.0445-0.0385)\\ &=\$6{,}000,\\ \rho_{\rm impl}&=\frac{0.22^2-0.0325}{0.03}\\ &=\frac{0.0484-0.0325}{0.03}=0.53. \end{aligned} \]

คำตอบ: ส่วนเดี่ยว 0.0325 ไม่เปลี่ยน ขาหุ้นรายตัวจึงเสมอตัว ส่วนร่วมลดจาก 0.012 เหลือ 0.006 variance ของดัชนีจึงลด 0.006 คนที่ขายไว้ได้ \$6,000 เงินทั้งก้อนมาจาก correlation ไม่ใช่จากความผันผวนของหุ้นรายตัว ถ้าดัชนีซื้อขายที่ 22% ราคากำลังบอกว่า correlation เฉลี่ยคือ 0.53 ใครเชื่อว่าหุ้นจะเดินแยกกันมากกว่านั้นก็ทำ dispersion

ตรวจเองใน 10 วินาที: P&L เป็นเส้นตรงใน $\rho$ ด้วยความชัน 0.03 ต่อ correlation 1.00 correlation ลด 0.2 ได้ $0.2(0.03)(1{,}000{,}000)=\$6{,}000$ แต่ในวันตลาดตื่นตระหนก correlation มักพุ่งพร้อมกับความผันผวนของหุ้นรายตัว ตัวเลขนี้จึงเป็นแค่กรณีที่แยกผลของ correlation ออกมาให้เห็น

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

อ่าน payoff เป็นกำไร: กราฟ payoff ของ straddle ไม่เคยติดลบ แต่ที่ \$105 เสีย \$2,975.52 ต่อ 1,000 หน่วย จุดที่ P&L ตัดศูนย์ไม่ใช่ strike

พิมพ์อัตราส่วนผิด: butterfly ที่ขาย call 100 แค่ใบเดียว $C(90)-C(100)+C(110)$ ราคา 7.6786 และจ่าย 0, 10, 10 และ 30 ที่ \$80, \$100, \$110 และ \$130 คือ bull spread บวก call ที่ได้ไม่จำกัด ไม่ใช่กระโจมที่จำกัดความเสี่ยงอีกต่อไป

ตีราคา calendar ด้วย payoff ของสองวัน: ลบ payoff ของขาสั้นกับขายาวบนเส้นทางเดียวกันเหมือนหมดอายุวันเดียวกันไม่ได้ ในวันที่ขาสั้นหมด ขายาวยังมีค่าเวลาถึง 3.99 ที่ strike

เทียบ realized กับ implied แล้วคิดว่ารู้ผล: realized 24.9% ต่ำกว่า 30% ไป 5.1 จุด แต่ผลจริงขึ้นกับว่าการขยับใหญ่เกิดตอน gamma สูงหรือต่ำ ในตัวอย่าง 50 ช่วง การกระโดดครั้งเดียวใกล้หมดอายุกินกำไรไป \$21,919 จาก \$77,334 ถ้าอยากได้เงินตาม variance โดยไม่ขึ้นกับว่าหุ้นอยู่ตรงไหน ต้องใช้ variance swap

ลืมต้นทุนของหลายขา: butterfly มีสี่หน่วย option ถ้าแต่ละหน่วยห่างราคากลาง \$0.05 (สมมติ) เปิดและปิดครบหนึ่งรอบเสีย $8(0.05)=\$0.40$ ต่อหน่วย หรือ 11% ของราคา 3.69 ก่อนเริ่มได้อะไร

โต๊ะแปลงมุมมองเป็นโครงสร้างด้วยตาราง scenario: คิดว่าความผันผวน ATM ถูกเกินไปก็ซื้อ straddle แล้ว hedge delta ทุกวัน (gamma scalping) คิดว่า put strike ต่ำแพงเกินไปเมื่อเทียบกับ call strike สูงก็ขาย skew ด้วย risk reversal แล้ว hedge delta 0.32 คิดว่าช่วงก่อนประกาศงบอายุสั้นแพงเกินไปก็ขายอายุสั้นซื้ออายุยาวด้วย calendar และคิดว่า correlation ที่ราคาบอกสูงเกินไปก็ทำ dispersion

ทุกโครงสร้างต้องบันทึกเป็นขาที่มีเครื่องหมาย strike อายุ ประเภท จำนวน และตัวคูณ แล้วรายงาน Greeks และตาราง scenario ของทั้งชุด สำหรับการขยับเล็ก การประมาณด้วย delta, gamma และ vega ใช้ได้และเร็ว สำหรับการขยับใหญ่ต้องคำนวณใหม่ทั้งสูตร และต้องเลือกปัจจัยเสี่ยงกับขนาด stress อย่างระวัง ชื่อเดียวกันมีความเสี่ยงต่างกันตามราคาหุ้นและเวลา (รูป gamma เทียบราคาหุ้น)

โจทย์ตรวจความเข้าใจ

1. ขาย strangle 90/110 จำนวน 1,000 หน่วย ได้เงินเท่าไร จุดคุ้มทุนอยู่ไหน และถ้าหุ้นจบที่ \$80 ได้เสียเท่าไร?

เฉลย

รับ $1{,}000(1.666328)=\$1{,}666.33$ จุดคุ้มทุน $90-1.666328=88.33$ และ $110+1.666328=111.67$ ที่ \$80 put 90 จ่าย 10 ต่อหน่วย P&L $=1{,}000(1.666328-10)=-\$8{,}333.67$ ผู้ขาย strangle ได้เงินน้อยแน่นอน แลกกับขาดทุนที่ไม่มีเพดานทั้งสองฝั่ง

2. ใช้ตาราง scenario: ถ้าคิดว่า skew จะชันขึ้น 1 จุดแต่ไม่อยากถือทิศทาง ต้องทำอะไร ได้เท่าไรต่อหน่วย และต้อง hedge หุ้นกี่หุ้น?

เฉลย

ทำ risk reversal กลับด้าน: ซื้อ put 90 ขาย call 110 ได้ +0.241 ต่อหน่วยเมื่อ skew ชันขึ้นตามโจทย์ ชุดนี้มี delta −0.3181 จึงซื้อหุ้น 0.3181 หุ้นต่อหน่วย (318 หุ้นต่อ 1,000 หน่วย) ให้ delta รวมเป็นศูนย์ แล้วต้องปรับ hedge เมื่อราคาหุ้นเปลี่ยน

3. straddle ATM ของหน้านี้ hedge delta แล้ว ถ้าพรุ่งนี้หุ้นขยับ \$1.50 ได้เสียเท่าไรต่อ 1,000 หน่วย และต้องขยับเท่าไรจึงเสมอตัว?

เฉลย

ต่อหน่วย $\tfrac12(0.0797)(1.5^2-1.0959)=\tfrac12(0.0797)(1.1541)=0.0460$ คูณ 1,000 ได้ +\$46.0 จุดเสมอตัวคือ $\sqrt{1.0959}=\$1.047$ ทางไหนก็ได้ ซึ่งคือ $\sigma S/\sqrt{365}=20/19.10$

// Multi-leg option structures: prices, breakevens, Greeks by legs, the delta-hedged P&L, surface scenarios and dispersion.
const { abs, exp, log, sqrt, max, PI } = Math;
const phi = x => exp(-0.5 * x * x) / sqrt(2 * PI);
// Normal CDF: Taylor series near the centre, continued fraction in the tails.
function Phi(x) {
  const a = abs(x);
  if (a <= 3) {
    let term = a, sum = a;
    for (let n = 1; n < 200 && term > 1e-17 * sum; n++) { term *= a * a / (2 * n + 1); sum += term; }
    return x >= 0 ? 0.5 + phi(a) * sum : 0.5 - phi(a) * sum;
  }
  let f = a;
  for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - phi(a) / f : phi(a) / f;
}
// One option per share with rate r (0 on most of this page). Theta per calendar day, vega per vol point.
function option(type, S, K, T, sigma, r = 0) {
  if (type !== 'call' && type !== 'put') throw new TypeError("Option type must be 'call' or 'put'");
  if (![S, K, sigma].every(x => Number.isFinite(x) && x > 0) || !(T >= 0)) throw new RangeError('Spot, strike and volatility must be positive, time not negative');
  if (T === 0) { const call = type === 'call'; return {price: max(call ? S - K : K - S, 0), delta: call ? +(S > K) : -(S < K), gamma: 0, vega: 0, theta: 0}; }
  const sT = sigma * sqrt(T), d1 = (log(S / K) + (r + sigma * sigma / 2) * T) / sT, d2 = d1 - sT, call = type === 'call', D = exp(-r * T);
  return {price: call ? S * Phi(d1) - K * D * Phi(d2) : K * D * Phi(-d2) - S * Phi(-d1), delta: call ? Phi(d1) : Phi(d1) - 1,
    gamma: phi(d1) / (S * sT), vega: 0.01 * S * phi(d1) * sqrt(T), theta: -S * phi(d1) * sigma / (2 * sqrt(T)) / 365};
}
// A structure is a list of signed legs [units, type, strike, years]; volOf lets each strike and expiry have its own vol.
function value(legs, S, volOf = () => 0.2) {
  if (!Array.isArray(legs) || legs.length === 0) throw new RangeError('A structure needs at least one leg');
  const out = {price: 0, delta: 0, gamma: 0, vega: 0, theta: 0};
  for (const [n, type, K, T] of legs) {
    if (!Number.isFinite(n) || n === 0) throw new RangeError('Each leg needs a non-zero number of units');
    const o = option(type, S, K, T, volOf(K, T));
    for (const key of Object.keys(out)) out[key] += n * o[key];
  }
  return out;
}

const sets = {
  straddle: [[1, 'put', 100, T1], [1, 'call', 100, T1]], strangle: [[1, 'put', 90, T1], [1, 'call', 110, T1]],
  riskReversal: [[-1, 'put', 90, T1], [1, 'call', 110, T1]], butterfly: [[1, 'call', 90, T1], [-2, 'call', 100, T1], [1, 'call', 110, T1]],
  calendar: [[-1, 'call', 100, T1], [1, 'call', 100, T2]]
};
// Bisection for a breakeven: f must change sign on [lo, hi].
function root(f, lo, hi) {
  if (f(lo) * f(hi) > 0) throw new RangeError('No sign change: the interval does not bracket a breakeven');
  for (let i = 0; i < 200; i++) { const m = (lo + hi) / 2; if (f(lo) * f(m) <= 0) hi = m; else lo = m; }
  return (lo + hi) / 2;
}
const at100 = Object.fromEntries(Object.entries(sets).map(([k, legs]) => [k, value(legs, 100)]));
const V0 = k => at100[k].price;
const calendarAt = S => option('call', S, 100, 0.25, 0.2).price - max(S - 100, 0);

function hedgeShortCall(S, K, T, sigma, r, N) {
  const n = S.length - 1, dt = T / n;
  let account = N * option('call', S[0], K, T, sigma, r).price, gammaPnl = 0;
  for (let i = 0; i < n; i++) {
    const o = option('call', S[i], K, T - i * dt, sigma, r), shares = N * o.delta, cash = account - shares * S[i];
    account = shares * S[i + 1] + cash * exp(r * dt);
    const R = S[i + 1] / S[i] - 1;
    gammaPnl += 0.5 * N * o.gamma * S[i] * S[i] * (sigma * sigma * dt - R * R);
  }
  const logs = S.slice(1).map((s, i) => log(s / S[i])), m = logs.reduce((a, x) => a + x, 0) / n;
  const realized = sqrt(logs.reduce((a, x) => a + (x - m) ** 2, 0) / (n - 1) / dt);
  return {premium: N * option('call', S[0], K, T, sigma, r).price, pnl: account - N * max(S[n] - K, 0), gammaPnl, realized};
}
function indexVariance(w, sigma, rho) {
  if (!(rho >= -1 && rho <= 1)) throw new RangeError('Correlation must lie between -1 and 1');
  return w[0] ** 2 * sigma[0] ** 2 + w[1] ** 2 * sigma[1] ** 2 + 2 * w[0] * w[1] * sigma[0] * sigma[1] * rho;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • straddle ATM ราคาเท่าขนาดการขยับเฉลี่ย $S\sigma\sqrt T\sqrt{2/\pi}\approx0.8\,S\sigma\sqrt T$: \$7.98 ที่ 20% สามเดือน และ payoff ไม่ใช่ P&L: ต้องจบนอก 92.02 ถึง 107.98 ที่ \$105 ยังเสีย \$2,975.52 ต่อ 1,000 หน่วย
  • calendar ต้องตีราคาขายาวในวันที่ขาสั้นหมด: ได้มากที่สุด 2.34 ที่ strike และขาดทุนเมื่อหุ้นหนีไปนอก 94.22 ถึง 106.53
  • Greeks บวกตามขาที่มีเครื่องหมาย ชื่อ long ไม่ได้แปลว่าทุกตัวบวก: long butterfly มี gamma และ vega ติดลบที่กลาง
  • option ที่ hedge delta แล้วได้ $\tfrac12\Gamma S^2(R^2-\sigma^2\delta t)$ ต่อช่วง จึงเป็นเดิมพัน realized เทียบกับ implied ที่ถ่วงด้วย gamma: ขาย call ที่ 30% แล้วหุ้นแกว่ง 24.9% ได้ \$55,392 แต่การกระโดดครั้งเดียวใกล้ strike ตอนใกล้หมดอายุกินไป \$21,919
  • straddle ซื้อระดับ ATM strangle ซื้อปีก risk reversal ซื้อขาย skew butterfly ซื้อความโค้ง calendar ซื้อ term structure และ dispersion ซื้อขาย correlation (\$6,000 ต่อ \$1 ล้าน notional เมื่อ correlation ลดจาก 0.4 เป็น 0.2)

ทุกโครงสร้างในหน้านี้ใช้ความผันผวนแบน 20% แต่ตาราง scenario แสดงว่ากำไรมาจากการที่ผืนขยับ หน้าถัดไป stochastic volatility และแบบจำลอง Heston ให้ความผันผวนเองเป็นตัวแปรสุ่ม แล้วดูว่า smile และ term structure เกิดขึ้นเองได้อย่างไร
