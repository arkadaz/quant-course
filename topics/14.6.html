14.6 Volatility Trading Structures: the Desk Playbook

straddle, strangle, risk reversal, butterfly และ calendar คือชุด option หลายตัวที่ประกอบกันให้เหลือแค่ความเสี่ยงที่อยากถือ เมื่อหักทิศทางออกด้วยหุ้น (hedge delta) แล้ว option จะกลายเป็นเดิมพันว่าหุ้นจะแกว่งจริงแรงกว่าหรือเบากว่าที่ราคา option คิดไว้ (implied volatility)

คุณคิดว่าหุ้นตัวหนึ่งกำลังจะขยับแรง เช่นช่วงก่อนประกาศงบ แต่ไม่รู้ว่าจะขึ้นหรือลง เพื่อนแนะนำให้ซื้อ straddle แล้วบอกว่า “straddle ได้เงินเมื่อหุ้นขยับ ทางไหนก็ได้”

straddle คือการซื้อ option สองตัวคู่กัน ตัวแรกคือ call ซึ่งเป็นสิทธิซื้อหุ้นที่ราคาตกลง ตัวที่สองคือ put ซึ่งเป็นสิทธิขายหุ้นที่ราคาตกลง ราคาตกลงนี้เรียกว่า strike และทั้งสองตัวใช้ strike เดียวกัน

ของที่รู้:

  • ราคาหุ้นวันนี้ $S_0=\$100$
  • strike ของทั้งสองตัว $K=\$100$ และอายุ $T=3$ เดือน คือ $0.25$ ปี
  • ความผันผวนต่อปี $\sigma=20\%$ คือ SD (standard deviation) ของผลตอบแทนหุ้นในหนึ่งปี
  • ดอกเบี้ย $r=0$ (สมมติ เพื่อให้เลขง่าย)
  • คุณซื้อ 1,000 หน่วย หนึ่งหน่วยคือ call หนึ่งตัวกับ put หนึ่งตัว แต่ละตัวอ้างอิงหุ้นหนึ่งหุ้น
  • ราคา straddle ต่อหน่วยคือ $V_0=\$7.9755$ หน้านี้จะคำนวณตัวเลขนี้ให้ดูในขั้นแรก

ถ้าวันหมดอายุหุ้นจบที่ \$105 คุณได้หรือเสียเท่าไร และหุ้นต้องจบนอกช่วงไหนจึงเริ่มได้กำไร?

ลองตอบก่อนเปิดเฉลย

ที่ $S_T=\$105$ call จ่าย $105-100=\$5$ ต่อหน่วย ส่วน put ไม่จ่าย เพราะไม่มีใครใช้สิทธิขายที่ \$100 ในเมื่อตลาดให้ \$105 คุณได้คืน \$5 แต่จ่ายไป \$7.9755 จึงเสีย:

\[\begin{aligned}\text{P\&L}&=1{,}000\times(5-7.975522)\\&=-\$2{,}975.52\end{aligned}\]

straddle จ่าย $|S_T-100|$ เสมอ คุณจะได้คืนพอดีกับที่จ่ายเมื่อ $|S_T-100|=7.9755$ คือ $S_T=100-7.9755=\$92.02$ หรือ $S_T=100+7.9755=\$107.98$ หุ้นต้องจบต่ำกว่า \$92.02 หรือสูงกว่า \$107.98 จึงเริ่มได้กำไร เช่นถ้าจบที่ \$115 ได้ $1{,}000\times(15-7.975522)=+\$7{,}024.48$

ราคา \$7.98 ไม่ได้ตั้งขึ้นลอย ๆ SD ของราคาหุ้นใน 3 เดือนคือ $S_0\sigma\sqrt T=100\times0.20\times0.5=\$10$ และระยะที่หุ้นขยับโดยเฉลี่ย (ไม่สนทิศ) คือราว 0.8 เท่าของ SD คือ $0.8\times10=\$8$ (ขั้นแรกจะแสดงว่าเลข 0.8 มาจากไหน) ราคา straddle จึงเท่ากับระยะขยับเฉลี่ยที่ตลาดคาดไว้แล้ว straddle ได้กำไรเมื่อหุ้นขยับมากกว่าที่ราคาคิดไว้ ไม่ใช่แค่ขยับ

ภาพรวมก่อนลงสูตร

option ตัวเดียวพาความเสี่ยงหลายอย่างมาพร้อมกัน หน้าของ Greeks ตั้งชื่อให้แต่ละอย่าง:

  • delta: ราคา option เปลี่ยนเท่าไรเมื่อหุ้นขยับ \$1 คือความเสี่ยงด้านทิศทาง
  • gamma: delta เองเปลี่ยนเท่าไรเมื่อหุ้นขยับ \$1 คือความไวต่อขนาดการแกว่ง
  • vega: ราคา option เปลี่ยนเท่าไรเมื่อความผันผวนขึ้น 1 จุด (เช่นจาก 20% เป็น 21%)
  • theta: ราคา option ลดลงเท่าไรเมื่อเวลาผ่านไปหนึ่งวัน

สมมติคุณอยากเดิมพันแค่ว่า “หุ้นจะแกว่งแรง” แต่ไม่รู้ทิศ ถ้าซื้อ call ตัวเดียว คุณได้ทิศทางติดมาด้วย เพราะ call ได้เงินเฉพาะตอนหุ้นขึ้น ทีมเทรด option ในธนาคาร (เรียกสั้น ๆ ว่า “โต๊ะ”) จึงซื้อหรือขาย option หลายตัวพร้อมกันเป็นชุด option แต่ละตัวในชุดเรียกว่า “ขา” ชุดที่ประกอบดีจะหักความเสี่ยงที่ไม่ต้องการออก เหลือแค่ส่วนที่อยากถือ ส่วน delta ที่ยังเหลือ โต๊ะหักออกด้วยการซื้อหรือขายหุ้นจริง เรียกว่า hedge delta

ราคาของ option ในตลาดมาจากคนซื้อและคนขาย ความผันผวนที่ซ่อนอยู่ในราคานั้นเรียกว่า implied volatility และค่านี้ต่างกันไปในแต่ละ strike และแต่ละอายุ ภาพรวมของมันเรียกว่าผืนความผันผวน เมื่อถือชุด option ที่ hedge delta แล้ว คุณกำลังซื้อหรือขายความผันผวนนี้โดยตรง ความผันผวนจึงกลายเป็นของที่ซื้อขายได้เอง เหมือนหุ้นหรือพันธบัตร

ทั้งหน้าใช้ตลาดสมมติชุดเดียว:

  • ราคาหุ้นวันนี้ $S_0=\$100$ ไม่มีปันผล
  • ความผันผวน $\sigma=20\%$ ต่อปี เท่ากันทุก strike และทุกอายุ เรียกว่าผืนความผันผวน “แบน”
  • ดอกเบี้ย $r=0$
  • option มีสองอายุ คือ $T_1=0.25$ ปี (3 เดือน) และ $T_2=0.5$ ปี (6 เดือน)

ราคาทุกขามาจากสูตร Black–Scholes รูปสี่ช่องด้านล่างคือภาพรวมทั้งหน้า แต่ละช่องคือกำไรขาดทุนวันหมดอายุของโครงสร้างหนึ่งแบบ รูปทรงของเส้นบอกว่าโครงสร้างนั้นได้เงินเมื่อหุ้นจบตรงไหน

หน้านี้เดินตามลำดับนี้:

  1. คิดราคา straddle ด้วยมือ และดูว่าทำไมมันเท่ากับระยะที่หุ้นขยับโดยเฉลี่ย
  2. เขียนห้าโครงสร้างเป็นรายการขา พร้อมเครื่องหมาย ซื้อเป็นบวก ขายเป็นลบ
  3. หาจุดคุ้มทุน แล้วตีราคา calendar ซึ่งมีสองขาที่หมดอายุคนละวัน
  4. รวม Greeks ของทั้งชุดจาก Greeks ของแต่ละขา
  5. หัวใจของการเทรดความผันผวน: option ที่ hedge delta แล้วได้เสียตาม gamma คูณ (การขยับจริงยกกำลังสอง ลบ การขยับที่ราคา option คิดไว้) แล้วดูตัวอย่างบนเส้นทางราคา 50 ช่วง
  6. ตาราง scenario: แต่ละโครงสร้างได้เสียเมื่อผืนความผันผวนขยับแบบไหน
  7. dispersion: การซื้อขาย correlation ระหว่างหุ้นในดัชนี
ศัพท์ที่ใช้ในหัวข้อนี้
Call, put, strike และ ATM
call คือสิทธิ (ไม่ใช่หน้าที่) ซื้อหุ้นที่ราคา strike ในวันหมดอายุ put คือสิทธิขายหุ้นที่ราคา strike option ที่ strike เท่ากับราคาหุ้นวันนี้เรียกว่า ATM (at-the-money) ในหน้านี้ ATM คือ strike \$100
Straddle และ strangle
straddle คือซื้อ call และ put ที่ strike เดียวกัน strangle คือซื้อ put ที่ strike ต่ำกว่าราคาหุ้น กับ call ที่ strike สูงกว่า ทั้งสองแบบได้เงินเมื่อหุ้นขยับไกล ไม่ว่าทางไหน strangle ถูกกว่า แต่หุ้นต้องขยับไกลกว่าจึงเริ่มได้เงิน
Risk reversal และ skew
risk reversal คือซื้อ call strike สูงและขาย put strike ต่ำ (หรือกลับกัน) ชุดนี้มีทิศทางชัด ราคาของมันขึ้นกับว่า put strike ต่ำแพงกว่า call strike สูงแค่ไหน ความต่างของ implied volatility ระหว่าง strike ต่ำกับ strike สูงนี้เรียกว่า skew โต๊ะจึงใช้ risk reversal ซื้อขาย skew
Butterfly และ smile
butterfly คือซื้อ call สองตัวที่ strike ริม (เรียกว่า “ปีก”) และขาย call สองตัวที่ strike กลาง payoff เป็นรูปกระโจม สูงสุดตรงกลาง กำไรและขาดทุนมีเพดานทั้งคู่ ใช้เดิมพันว่าหุ้นจะจบใกล้ strike กลาง หรือใช้ซื้อความโค้งของ smile (เส้น implied volatility เทียบ strike ที่โค้งขึ้นทางปีกทั้งสองข้าง)
Calendar spread และ term structure
calendar คือขาย option อายุสั้นและซื้อ option อายุยาวที่ strike เดียวกัน ใช้ซื้อขายความต่างของ implied volatility ระหว่างอายุสั้นกับอายุยาว ความต่างตามอายุนี้เรียกว่า term structure สองขาหมดอายุคนละวัน จึงต้องตีราคาขายาวในวันที่ขาสั้นหมด
Payoff, P&L และจุดคุ้มทุน
payoff คือเงินที่สัญญาจ่ายในวันหมดอายุ P&L (profit and loss) คือกำไรขาดทุน เท่ากับ payoff ลบเงินที่จ่ายตอนเปิด จุดคุ้มทุนคือราคาหุ้นที่ทำให้ P&L เป็นศูนย์ payoff ของคนซื้อ option ไม่เคยติดลบ แต่ P&L ติดลบได้
Delta-hedged option และ realized volatility
delta-hedged option คือ option ที่ถือคู่กับการขายหุ้นจำนวน delta หุ้น และปรับจำนวนหุ้นทุกช่วงเวลา ทิศทางจึงหักกันหมด เหลือแค่กำไรขาดทุนจากขนาดการขยับ realized volatility คือความผันผวนที่หุ้นแกว่งจริงระหว่างทาง ใช้เทียบกับ implied volatility ที่จ่ายไปตอนซื้อ option
Dispersion และ implied correlation
dispersion คือขายความผันผวนของดัชนี แล้วซื้อความผันผวนของหุ้นรายตัวในดัชนี ได้กำไรเมื่อหุ้นเดินแยกทางกันมากกว่าที่ราคาคิด implied correlation คือค่า correlation ที่ทำให้ความผันผวนของดัชนีตามราคา option ตรงกับความผันผวนของหุ้นรายตัว

ขั้นที่ 1 — ลองด้วยมือ: straddle ราคาเท่าไร และทำไม

ก่อนจะประกอบชุดใหญ่ ต้องรู้ราคาของชิ้นพื้นฐานที่สุดก่อน คือ straddle ATM ของเปิดเรื่อง และอยากรู้ด้วยว่าทำไมราคาออกมาราว \$8

โจทย์ให้อะไรมาบ้าง:

  • ราคาหุ้นและ strike $S_0=K=100$ ดอกเบี้ย $r=0$
  • ความผันผวน $\sigma=0.20$ อายุ $T=0.25$ ปี จึงได้ $\sigma\sqrt T=0.20\times0.5=0.10$

สูตร Black–Scholes ของ call คือ $C=S_0\Phi(d_1)-Ke^{-rT}\Phi(d_2)$ โดย $d_1=\dfrac{\ln(S_0/K)+(r+\tfrac12\sigma^2)T}{\sigma\sqrt T}$ และ $d_2=d_1-\sigma\sqrt T$ เมื่อ $S_0=K$ จะได้ $\ln(S_0/K)=\ln1=0$ และเมื่อ $r=0$ ตัวเศษของ $d_1$ เหลือแค่ $\tfrac12\sigma^2T$ ส่วน put หาจาก put–call parity ซึ่งที่ $r=0$ คือ $C-P=S_0-K$

จากนั้นจะเทียบราคากับระยะที่หุ้นขยับโดยเฉลี่ย ถ้าเขียนการขยับใน 3 เดือนเป็น $S_T-S_0\approx S_0\sigma\sqrt T\,Z$ โดย $Z$ เป็น Normal มาตรฐาน ระยะเฉลี่ยแบบไม่สนเครื่องหมายคือ $S_0\sigma\sqrt T\,\mathbb E|Z|$

\[ \begin{aligned} d_1&=\frac{\tfrac12(0.04)(0.25)}{0.20(0.5)}=\frac{0.005}{0.10}=0.05,\\ d_2&=d_1-\sigma\sqrt T=0.05-0.10=-0.05,\\ C&=100\big[\Phi(0.05)-\Phi(-0.05)\big]\\ &=100(0.519939-0.480061)=3.987761,\\ P&=C-S_0+K=3.987761,\\ V_0&=C+P=7.975522,\\ \mathbb E|Z|&=2\int_0^\infty z\,\phi(z)\,dz=2\phi(0)=\sqrt{2/\pi},\\ S_0\sigma\sqrt T\,\mathbb E|Z|&=100(0.10)(0.797885)=7.978846. \end{aligned} \]

คำตอบ: straddle ราคา \$7.9755 ต่อหน่วย put ราคาเท่ากับ call พอดี เพราะ parity บอกว่า $C-P=S_0-K$ และที่ $S_0=K$ ผลต่างนี้เป็นศูนย์

ทำไมราคาใกล้ \$7.98 นัก? ที่ $r=0$ ราคา straddle คือค่าเฉลี่ยของ payoff $|S_T-K|$ ภายใต้ risk-neutral measure (โลกสมมติที่ใช้ตั้งราคา option ตามสูตร Black–Scholes) เพราะ $\sigma\sqrt T=0.10$ เล็ก การขยับของหุ้นจึงใกล้ Normal ที่มี SD $S_0\sigma\sqrt T=\$10$ ระยะขยับเฉลี่ยคือ $0.798\times10=\$7.98$ ห่างจากราคาจริงแค่ $7.9788-7.9755=\$0.003$

ตรวจเองใน 10 วินาที: ทำไม $\mathbb E|Z|=2\phi(0)$? เพราะ $|Z|$ สมมาตร จึงคิดแค่ครึ่งบวกแล้วคูณสอง และอนุพันธ์ของ $\phi(z)$ คือ $-z\phi(z)$ อินทิกรัลจึงเป็น $\int_0^\infty z\phi(z)\,dz=\big[-\phi(z)\big]_0^\infty=\phi(0)=0.3989$ โต๊ะจำสูตรลัดว่า “straddle ATM ≈ $0.8\,S\sigma\sqrt T$” เพราะ $\sqrt{2/\pi}=0.798\approx0.8$ ที่ความผันผวน 20% อายุสามเดือน ได้ $0.8\times100\times0.2\times0.5=\$8.0$

ขั้นที่ 2 — ห้าโครงสร้างเป็นขาที่มีเครื่องหมาย

ชื่อกลยุทธ์ไม่ได้บอกว่าซื้อหรือขาย สองโต๊ะอาจพูดชื่อเดียวกันแต่หมายถึงทิศตรงข้าม ขั้นนี้จึงเขียนแต่ละโครงสร้างเป็นรายการขา แต่ละขามีจำนวนและเครื่องหมาย ซื้อเป็นบวก ขายเป็นลบ แล้วเขียน payoff วันหมดอายุ $H(S_T)$ ของทั้งชุด

สัญลักษณ์ $(x)^+$ แปลว่า $\max(x,0)$ คือ $x$ ถ้า $x$ เป็นบวก และ 0 ถ้า $x$ ติดลบ call strike $K$ จึงจ่าย $(S_T-K)^+$ และ put จ่าย $(K-S_T)^+$ strangle และ risk reversal ใช้ strike 90 กับ 110 ห่างจากราคาหุ้นข้างละ \$10 ส่วน butterfly ใช้ 90, 100 และ 110

straddle มีสองกรณี ถ้า $S_T\ge K$ call จ่าย $S_T-K$ และ put ไม่จ่าย ถ้า $S_T\lt K$ put จ่าย $K-S_T$ และ call ไม่จ่าย ทั้งสองกรณีรวมกันเขียนได้เป็น $|S_T-K|$

\[ \begin{aligned} H_{\rm straddle}&=(S_T-100)^++(100-S_T)^+\\ &=|S_T-100|,\\ H_{\rm strangle}&=(90-S_T)^++(S_T-110)^+,\\ H_{\rm RR}&=(S_T-110)^+-(90-S_T)^+,\\ H_{\rm fly}&=(S_T-90)^+-2(S_T-100)^+\\ &\quad+(S_T-110)^+,\\ H_{\rm fly}&=\big[(S_T-90)^+-(S_T-100)^+\big]\\ &\quad-\big[(S_T-100)^+-(S_T-110)^+\big]. \end{aligned} \]

ทำไม butterfly ถึงเป็นกระโจม? ให้มองเป็นสองก้อน แต่ละก้อนคือ call spread (ซื้อ call strike ต่ำ ขาย call strike สูง) ก้อนแรกคือ call spread 90/100 จ่ายเพิ่มจาก 0 ถึง 10 เมื่อหุ้นขึ้นจาก 90 ถึง 100 แล้วคงที่ที่ 10 ก้อนหลังคือ call spread 100/110 ทำแบบเดียวกันแต่เริ่มที่ 100 เอาก้อนแรกลบก้อนหลัง ต่ำกว่า 90 ทั้งคู่เป็น 0 ระหว่าง 90 กับ 100 ก้อนแรกขึ้นแต่ก้อนหลังยังเป็น 0 เส้นจึงขึ้น ระหว่าง 100 กับ 110 ก้อนแรกคงที่ที่ 10 แต่ก้อนหลังขึ้น เส้นจึงลง เหนือ 110 ทั้งคู่เป็น 10 หักกันเหลือ 0 ยอดกระโจมจึงสูง 10 ที่ strike 100 ตัวคูณ −2 ที่ strike 100 มาจากการที่ strike นี้อยู่ในทั้งสองก้อน

ตารางนี้ตั้งราคาแต่ละขาด้วยสูตร Black–Scholes ที่ความผันผวน 20% แล้วรวมตามเครื่องหมาย ตัวอย่างหนึ่งขาที่คิดด้วยมือ: put strike 90 อายุ 0.25 ปี มี

\[\begin{aligned}d_1&=\frac{\ln(100/90)+0.005}{0.10}=1.1036,\\d_2&=1.1036-0.10=1.0036,\\P(90)&=90\,\Phi(-1.0036)-100\,\Phi(-1.1036)\\&=90(0.157784)-100(0.134882)\\&=0.7124.\end{aligned}\]

call 110 คิดแบบเดียวกันได้ 0.953947 call 90 หาจาก put 90 ผ่าน parity $C(90)=P(90)+S_0-K=0.712381+100-90=10.712381$ ขายาวของ calendar คือ call 100 อายุ $T_2=0.5$ ปี มี $d_1=\tfrac12(0.2)\sqrt{0.5}=0.0707$ จึงได้ $C=100\big[2\Phi(0.0707)-1\big]=5.637198$ (ใช้ $d_2=-d_1$ ซึ่งจริงเมื่อ $S_0=K$ และ $r=0$)

ขั้นที่ 3 — payoff ไม่ใช่กำไร: จุดคุ้มทุนของโครงสร้างอายุเดียว

กราฟ payoff ของคนซื้อ option ไม่เคยต่ำกว่าศูนย์ แต่นั่นยังไม่ใช่กำไร เพราะต้องจ่ายราคา $V_0$ ไปก่อนตอนเปิด ขั้นนี้หักราคานั้นออก แล้วหาราคาหุ้นที่ทำให้ได้เงินคืนพอดี

โจทย์ให้อะไรมาบ้าง: payoff $H(S_T)$ และราคา $V_0$ จากตารางขา

  • P&L ต่อหน่วยคือ $H(S_T)-V_0$ ลบกันตรง ๆ ได้ เพราะดอกเบี้ยเป็นศูนย์ เงินที่จ่ายวันนี้กับเงินที่ได้วันหมดอายุจึงมีค่าเท่ากัน
  • จุดคุ้มทุนคือ $S_T$ ที่ทำให้ $H(S_T)=V_0$
  • straddle: $|S_T-100|=7.975522$ มีสองคำตอบ ฝั่งละหนึ่ง
  • strangle: ใต้ 90 put จ่าย $90-S_T$ เหนือ 110 call จ่าย $S_T-110$ ตั้งแต่ละฝั่งให้เท่ากับ 1.6663
  • butterfly: ระหว่าง 90 กับ 100 payoff คือ $S_T-90$ ระหว่าง 100 กับ 110 คือ $110-S_T$ ตั้งแต่ละฝั่งให้เท่ากับ 3.6908
  • สองแถวท้ายคือ P&L ของ straddle 1,000 หน่วยในโจทย์เปิดเรื่อง เมื่อหุ้นจบที่ \$105 (payoff 5) และ \$115 (payoff 15)
\[ \begin{aligned} \text{straddle}:\ S_T&=100\pm7.975522\\ &=92.0245,\ 107.9755,\\ \text{strangle}:\ S_T&=90-1.6663,\ 110+1.6663\\ &=88.3337,\ 111.6663,\\ \text{fly}:\ S_T&=90+3.6908,\ 110-3.6908\\ &=93.6908,\ 106.3092,\\ 1{,}000(5-7.975522)&=-2{,}975.52,\\ 1{,}000(15-7.975522)&=+7{,}024.48. \end{aligned} \]

คำตอบ: straddle ได้กำไรเมื่อหุ้นจบนอกช่วง \$92.02 ถึง \$107.98 ช่วงที่ขาดทุนกว้าง $2V_0=2\times7.9755=\$15.95$

strangle ถูกกว่า straddle เกือบห้าเท่า ($7.9755/1.6663=4.8$) แต่หุ้นต้องจบนอกช่วง \$88.33 ถึง \$111.67 ซึ่งกว้างกว่า

butterfly กลับด้าน มันได้กำไรเฉพาะเมื่อหุ้นจบในช่วง \$93.69 ถึง \$106.31 กำไรสูงสุดอยู่ที่ \$100 คือยอดกระโจม 10 ลบราคา: $10-3.6908=\$6.3092$

risk reversal จ่าย \$0.2416 ตอนเปิด ได้กำไรเมื่อหุ้นจบเหนือ $110+0.2416=\$110.24$ แต่ขาดทุนหนักเมื่อหุ้นลง เพราะขาย put 90 ไว้ ต่ำกว่า \$90 หุ้นลงทุก \$1 เสียเพิ่ม \$1 (ดูจุดดำในรูปสี่ช่องด้านบน)

ตรวจเองใน 10 วินาที: ราคา butterfly บอก density ของราคาหุ้นวันหมดอายุได้ ตามผลในผืนความผันผวน: ราคา butterfly หารด้วยระยะห่าง strike ยกกำลังสอง $h^2$ ประมาณ density ของ $S_T$ ที่ strike กลาง (ภายใต้ risk-neutral measure) ลองดู ที่นี่ $h=10$:

\[\begin{aligned}\frac{3.6908}{10^2}&=0.0369,\\\frac{\phi(d_2)}{K\sigma\sqrt T}&=\frac{\phi(-0.05)}{100\times0.10}=0.0398.\end{aligned}\]

สองค่าห่างกันราว 7% เพราะระยะ $h=10$ ยังไม่เล็กพอ ถ้า $h$ เล็กลง สองค่าจะเข้าหากัน

ขั้นที่ 4 — calendar: ตีราคาขายาวในวันที่ขาสั้นหมดอายุ

calendar ต่างจากสี่ตัวก่อนหน้า เพราะสองขาหมดอายุคนละวัน ขาสั้นคือ call อายุ $T_1=0.25$ ปีที่ขายไป ขายาวคือ call อายุ $T_2=0.5$ ปีที่ซื้อไว้ ทั้งคู่ strike \$100 โต๊ะจ่ายสุทธิ $V_0=1.649437$ ตอนเปิด (จากตารางขา)

ในวันที่ขาสั้นหมดอายุ ขายาวยังเหลืออายุ $0.5-0.25=0.25$ ปี มันจึงยังมีค่าเวลา คือส่วนของราคาที่เกินเงินที่ได้ถ้าใช้สิทธิทันที เพราะยังมีเวลาให้หุ้นขยับ ดังนั้นจะใช้ payoff แทนมูลค่าของขายาวไม่ได้ ต้องตีราคามันด้วยสูตร Black–Scholes ที่ราคาหุ้นวันนั้น $S_{T_1}$ (ถือว่าความผันผวนยังเป็น 20%) มูลค่าของ calendar ในวันนั้น $V_{T_1}$ คือราคาขายาว ลบเงินที่ขาสั้นต้องจ่าย:

\[ \begin{aligned} V_{T_1}&=C\big(S_{T_1},100,0.25\big)-(S_{T_1}-100)^+,\\ S_{T_1}=100:\ V_{T_1}&=3.9878-0=3.9878,\\ S_{T_1}=110:\ V_{T_1}&=10.9539-10=0.9539,\\ S_{T_1}=90:\ V_{T_1}&=0.7124-0=0.7124,\\ V_{T_1}&=1.649437\ \Rightarrow\ S_{T_1}=94.22,\ 106.53. \end{aligned} \]

calendar ได้มากที่สุดเมื่อหุ้นอยู่ที่ strike พอดีในวันที่ขาสั้นหมด เพราะขาสั้นหมดค่า แต่ขายาวยังมีค่าเวลาเต็มที่ กำไรเทียบกับเงินที่จ่ายตอนเปิดคือ $3.987761-1.649437=\$2.3383$ ต่อหน่วย ถ้าหุ้นหนีไปไกล ไม่ว่าทางไหน ค่าเวลาของขายาวก็หายไป มูลค่าจึงเข้าหาศูนย์

ดูสองฝั่ง ที่ \$110 ขายาวมีค่า 10.9539 คือเงินในตัว $110-100=\$10$ บวกค่าเวลา 0.9539 แต่ขาสั้นต้องจ่าย \$10 ซึ่งหักกับเงินในตัวพอดี จึงเหลือแค่ค่าเวลา ที่ \$90 ขาสั้นไม่ต้องจ่าย แต่ขายาวอยู่ต่ำกว่า strike และเหลือค่าเวลาแค่ 0.7124 ค่าเวลาของ option สูงสุดที่ strike และลดลงทั้งสองฝั่ง calendar จึงเป็นการถือค่าเวลาของขายาวไว้ขายในวันที่ขาสั้นหมด

จุดคุ้มทุน \$94.22 และ \$106.53 คือราคาหุ้นที่ทำให้ $V_{T_1}$ เท่ากับเงินที่จ่ายไป 1.649437 สมการนี้ไม่มีสูตรปิด ต้องแก้เชิงตัวเลข เช่นแบ่งครึ่งช่วงไปเรื่อย ๆ แบบที่โค้ดท้ายหน้าทำ

ขั้นที่ 5 — Greeks ของชุดคือผลรวมของขาที่มีเครื่องหมาย

ตอนนี้รู้ราคาของแต่ละชุดแล้ว ต่อไปต้องรู้ความเสี่ยงของทั้งชุด คือ Greeks ข่าวดีคือไม่ต้องคิดใหม่ทั้งชุด มูลค่าของชุด $V_{\rm set}$ คือมูลค่าของแต่ละขา $V_i$ คูณจำนวนหน่วย $n_i$ (ซื้อเป็นบวก ขายเป็นลบ) แล้วบวกกัน Greeks คืออนุพันธ์ของมูลค่า เช่น delta คืออนุพันธ์เทียบราคาหุ้น $S$ และ $\nu$ (vega) คืออนุพันธ์เทียบความผันผวน อนุพันธ์ของผลบวกคือผลบวกของอนุพันธ์ ส่วน $n_i$ เป็นค่าคงที่ที่เราเลือกเอง จึงดึงออกมานอกอนุพันธ์ได้

\[ \begin{aligned} V_{\rm set}&=\sum_i n_iV_i,\\ \Delta_{\rm set}&=\frac{\partial V_{\rm set}}{\partial S}=\sum_i n_i\Delta_i,\\ \Gamma_{\rm set}&=\sum_i n_i\Gamma_i,\quad\nu_{\rm set}=\sum_i n_i\nu_i,\\ \Theta_{\rm set}&=\sum_i n_i\Theta_i. \end{aligned} \]

Greeks ของชุดคือ Greeks ของแต่ละขาคูณจำนวนหน่วยแล้วบวกกัน เหตุผลนี้ไม่ได้ใช้คุณสมบัติอะไรของ option เลย ใช้แค่ว่าอนุพันธ์กระจายเข้าไปในผลบวกได้ เงื่อนไขเดียวคือทุกขาต้องคำนวณที่ราคาหุ้น เวลา และผืนความผันผวนชุดเดียวกัน จุดที่พลาดง่ายคือเครื่องหมาย ขาที่ขายมี $n_i$ ติดลบ butterfly จึงมี $n=-2$ ที่ strike 100 และ calendar มี $n=-1$ ที่ขาสั้น

ขั้นที่ 6 — Greeks ของ straddle ด้วยมือ แล้วครบห้าโครงสร้าง

ลองใช้กฎนี้กับ straddle ด้วยมือก่อน แล้วค่อยดูตารางของทั้งห้าโครงสร้าง

โจทย์ให้อะไรมาบ้าง:

  • $S=100$, $r=0$, $\sigma=0.2$, $\sqrt T=0.5$ และ $d_1=0.05$ จากขั้นแรก
  • density ของ Normal มาตรฐานที่ $d_1$ คือ $\phi(0.05)=e^{-0.05^2/2}/\sqrt{2\pi}=0.398444$
  • สูตรของ call หนึ่งตัวจากหน้าของ Greeks: $\Delta=\Phi(d_1)$, $\Gamma=\dfrac{\phi(d_1)}{S\sigma\sqrt T}$, $\nu=S\phi(d_1)\sqrt T$ และ $\Theta=-\dfrac{S\phi(d_1)\sigma}{2\sqrt T}$ ต่อปี
  • vega รายงานต่อความผันผวน 1 จุด คือ 0.01 จึงคูณ $\nu$ ด้วย 0.01
  • theta รายงานต่อวันปฏิทิน จึงหารด้วย 365 เพราะหน้านี้นับอายุ $T$ เป็นปีปฏิทิน 365 วัน

put ต่างจาก call แค่ delta หาอนุพันธ์ของ parity $C-P=S-K$ เทียบ $S$ ได้ $\Delta_C-\Delta_P=1$ delta ของ put จึงเท่ากับ $\Phi(d_1)-1$ ส่วน gamma, vega และ theta ของ put เท่ากับของ call เพราะ $S-K$ ไม่มีความโค้งในราคาหุ้น และไม่ขึ้นกับความผันผวนหรือเวลา (ที่ $r=0$) straddle มี call และ put อย่างละตัว ตัวที่เท่ากันจึงคูณสอง

\[ \begin{aligned} \Delta&=\Phi(0.05)+\big(\Phi(0.05)-1\big)\\ &=2(0.519939)-1=0.039878,\\ \Gamma&=2\,\frac{0.398444}{100(0.2)(0.5)}=0.079689,\\ 0.01\,\nu&=2(0.01)(100)(0.398444)(0.5)\\ &=0.398444,\\ \Theta/365&=-2\,\frac{100(0.398444)(0.2)}{2(0.5)(365)}\\ &=-0.043665. \end{aligned} \]

คำตอบ: straddle ATM แทบไม่มีทิศ delta แค่ 0.04 คือหุ้นขึ้น \$1 straddle ได้ราว \$0.04 แต่ gamma เป็นสองเท่าของ call ตัวเดียว ถ้าความผันผวนขึ้น 1 จุด straddle ได้ \$0.40 และทุกวันที่ผ่านไปเสียค่าเวลา \$0.0437

ตรวจเองใน 10 วินาที: butterfly ที่ซื้อ (“long butterfly”) เมื่อหุ้นอยู่ตรงกลาง มี gamma และ vega ติดลบ และได้ค่าเวลา (theta บวก) เพราะมันขาย call ATM สองตัว ซึ่งมี gamma และ vega มากกว่าปีกสองตัวที่ซื้อ คำว่า long บอกแค่ว่าจ่ายเงินตอนเปิด ไม่ได้บอกว่า Greeks ทุกตัวเป็นบวก calendar ก็เช่นกัน vega บวกแต่ gamma ลบ เพราะ gamma ของขาสั้นอายุ 3 เดือน (0.0398) สูงกว่าของขายาวอายุ 6 เดือน (0.0281)

ขั้นที่ 7 — option ที่ hedge delta แล้ว ได้เสียตามการขยับจริงเทียบกับที่ราคาคิด

straddle แทบไม่มี delta แต่ “แทบ” ไม่ใช่ศูนย์ และ delta เปลี่ยนทุกครั้งที่หุ้นขยับ (นั่นคือ gamma) ถ้าอยากได้เงินจากการแกว่งอย่างเดียว โต๊ะต้องหักทิศทางออกตลอดเวลา วิธีคือถือ option หนึ่งตัว ขายหุ้น $\Delta$ หุ้น แล้วปรับจำนวนหุ้นทุกช่วงเวลา $\delta t$ เช่นทุกวัน คำถามของขั้นนี้คือ พอร์ตนี้ได้เสียจากอะไร

ตั้งชื่อของก่อน:

  • $\Pi=C-\Delta S$ คือมูลค่าพอร์ต: option หนึ่งตัว ลบหุ้นที่ขายไป $\Delta$ หุ้น
  • $\delta S$ คือระยะที่หุ้นขยับในช่วง $\delta t$ และ $R=\delta S/S$ คือผลตอบแทนของหุ้นในช่วงนั้น
  • $\sigma$ คือ implied volatility ที่ใช้ตั้งราคา option และใช้คำนวณ $\Delta$, $\Gamma$, $\Theta$

พอร์ตเปลี่ยนจากสามส่วน คือ option เปลี่ยน ($\delta C$) หุ้นที่ขายไว้เปลี่ยน ($\Delta\,\delta S$) และดอกเบี้ย เงินที่ผูกอยู่ในพอร์ตคือ $C-\Delta S$ ถ้ายืมเงินก้อนนี้มา ต้องจ่ายดอกเบี้ย $r(C-\Delta S)\,\delta t$ ส่วน $\delta C$ ประมาณด้วย Taylor สองชั้นของราคา option เราเก็บพจน์ $(\delta S)^2$ ไว้ แต่ทิ้ง $(\delta t)^2$ เพราะหุ้นขยับราว $\sigma S\sqrt{\delta t}$ ทำให้ $(\delta S)^2$ ใหญ่ระดับเดียวกับ $\delta t$ สุดท้ายแทน $\Theta$ ด้วย PDE ของ Black–Scholes $\Theta+rS\Delta+\tfrac12\sigma^2S^2\Gamma=rC$ จากพอร์ตทำซ้ำ

\[ \begin{aligned} \delta\Pi&=\delta C-\Delta\,\delta S-r(C-\Delta S)\,\delta t,\\ \delta C&\approx\Theta\,\delta t+\Delta\,\delta S+\tfrac12\Gamma(\delta S)^2,\\ \Theta&=rC-rS\Delta-\tfrac12\sigma^2S^2\Gamma,\\ \delta\Pi&\approx\tfrac12\Gamma(\delta S)^2-\tfrac12\sigma^2S^2\Gamma\,\delta t\\ &=\tfrac12\Gamma S^2\Big[R^2-\sigma^2\delta t\Big],\\ R&=\frac{\delta S}{S},\qquad |R|^*=\sigma\sqrt{\delta t}. \end{aligned} \]

เมื่อแทนการเปลี่ยนของ option และ theta ลงไป มีสองคู่ที่หักกันหมด คู่แรกคือ $\Delta\,\delta S$ ของ option หักกับหุ้นที่ขายไว้ นี่คือเหตุผลที่ hedge คู่ที่สองคือพจน์ดอกเบี้ย $rC\,\delta t$ และ $rS\Delta\,\delta t$ ใน theta หักกับดอกเบี้ยของเงินที่ยืม สิ่งที่เหลือคือ gamma คูณผลต่างระหว่างการขยับจริงยกกำลังสอง $R^2$ กับ $\sigma^2\delta t$ ค่าหลังนี้คือ variance ของผลตอบแทนในช่วง $\delta t$ ที่ราคา option คิดไว้ ทิศไม่มีผลเลย เพราะ $R$ ถูกยกกำลังสอง

จุดคุ้มทุนต่อช่วงคือ $|R|^*=\sigma\sqrt{\delta t}$ คือหุ้นขยับ 1 SD ของช่วงนั้นพอดี ถ้าขยับน้อยกว่านี้ ค่าเวลาที่เสียมากกว่าที่ได้จาก gamma ถ้าขยับมากกว่านี้ ได้จาก gamma มากกว่าค่าเวลา เมื่อรวมทุกช่วง ผู้ซื้อ option ได้เงินถ้าความผันผวนที่เกิดจริง (realized) สูงกว่า implied ที่จ่ายไป ผู้ขายได้ถ้าต่ำกว่า แต่แต่ละช่วงมีน้ำหนักไม่เท่ากัน น้ำหนักคือ $\Gamma S^2$ ของช่วงนั้น ซึ่งสูงที่สุดเมื่อหุ้นอยู่ใกล้ strike และ option ใกล้หมดอายุ

ขั้นที่ 8 — เส้นทางเดียว 50 ช่วง: ขาย call ที่ 30% แล้วหุ้นแกว่งแค่ 24.9%

ตอนนี้ลองดูสูตรนี้ทำงานบนเส้นทางราคาหนึ่งเส้น จากมุมของผู้ขาย โต๊ะขาย call ให้ลูกค้า แต่ไม่อยากเสี่ยงทิศทาง จึงซื้อหุ้นจำนวน delta มาถือไว้และปรับเป็นระยะ หุ้นกับเงินสดชุดนี้เรียกว่าพอร์ตทำซ้ำ เพราะมันเลียนแบบมูลค่าของ call ที่ขายไป

โจทย์ให้อะไรมาบ้าง:

  • โต๊ะขาย call $N=100{,}000$ ตัว แต่ละตัวอ้างอิงหุ้นหนึ่งหุ้น
  • ราคาหุ้นวันนี้ $S_0=\$50$ strike $K=\$50$ อายุ $T=0.25$ ปี
  • implied volatility ที่ขาย $\sigma=30\%$ และดอกเบี้ย $r=2\%$ ต่อปี
  • เงินที่รับคือราคา Black–Scholes ต่อตัว \$3.1082 คูณ 100,000 ได้ \$310,815
  • ปรับ hedge 50 ครั้ง ห่างกัน $\delta t=0.25/50=0.005$ ปี หรือราว $0.005\times252=1.26$ วันทำการ (ปีหนึ่งมีราว 252 วันที่ตลาดเปิด)
  • เส้นทางราคาสมมติ 51 จุด จบที่ \$54.4079 ทุกจุดอยู่ในโค้ดท้ายหน้า
  • realized volatility ของเส้นทางนี้คือ SD ของ log return ทั้ง 50 ช่วง หารด้วย $\sqrt{\delta t}$ เพื่อแปลงเป็นต่อปี ได้ 24.9%

วันหมดอายุ โต๊ะได้หรือเสียเท่าไร? วิธีคิดคือเทียบมูลค่าพอร์ตทำซ้ำ กับเงินที่ต้องจ่ายให้ผู้ซื้อ call แล้วเทียบกับผลรวมของสูตรต่อช่วงที่เพิ่งได้มา สูตรต้องกลับเครื่องหมาย เพราะโต๊ะเป็นผู้ขาย ผู้ขายได้ $\tfrac12\Gamma S^2\big[\sigma^2\delta t-R^2\big]$ ต่อตัวต่อช่วง มูลค่าพอร์ตตอนจบ \$496,182 มาจากการจำลองทีละช่วงในโค้ด

\[ \begin{aligned} |R|^*&=0.30\sqrt{0.005}=2.12\%,\\ |R|^*S_0&=0.0212\times50=\$1.06,\\ \text{payoff}&=100{,}000(54.4079-50)\\ &=\$440{,}790,\\ \text{portfolio}&=\$496{,}182,\\ \text{P\&L}&=496{,}182-440{,}790=+\$55{,}392,\\ \text{sum}&=\sum_i\tfrac12N\Gamma_iS_i^2\big[\sigma^2\delta t-R_i^2\big]\\ &\approx+\$46{,}584. \end{aligned} \]

คำตอบ: ผู้ขายที่ hedge ครบได้กำไร \$55,392 คิดเป็น $55{,}392/310{,}815=18\%$ ของเงินที่รับมา กำไรนี้ไม่ได้มาจากการเดาทิศถูก หุ้นขึ้น $54.4079/50-1=8.8\%$ และ call จบในเงิน ซึ่งเป็นทิศที่ไม่ดีกับผู้ขายด้วยซ้ำ กำไรมาจากการที่หุ้นแกว่งจริงแค่ 24.9% ต่ำกว่า 30% ที่ขายไป

สูตรต่อช่วงอธิบายได้ \$46,584 ส่วนที่เหลือ $55{,}392-46{,}584=\$8{,}808$ มาจากสองเรื่อง เรื่องแรก โต๊ะปรับ hedge เป็นช่วงห่าง ไม่ได้ปรับต่อเนื่อง เรื่องที่สอง Taylor สองชั้นไม่แม่นเมื่อ gamma เปลี่ยนเร็ว

ตรวจเองใน 10 วินาที: ดูรูปข้างล่าง กำไรสะสมขึ้นถึง \$77,334 ตอนเหลืออีกสองช่วงก่อนหมดอายุ แล้วหุ้นกระโดดจาก \$51.43 เป็น \$53.57 ในช่วงเดียว คือ $53.57/51.43-1=+4.2\%$ ตอนนั้นหุ้นอยู่ใกล้ strike และ option เหลืออายุแค่ $0.25-48\times0.005=0.01$ ปี gamma จึงสูงมาก กำไรสะสมลดจาก \$77,334 เหลือ \$55,415 คือเสีย $77{,}334-55{,}415=\$21{,}919$ ในช่วงเดียว ช่วงสุดท้ายแทบไม่เปลี่ยนอะไร จบที่ \$55,392 ความผันผวนเฉลี่ยทั้งเส้นจึงบอกผลไม่ครบ ต้องดูด้วยว่าการขยับใหญ่เกิดตอนไหน

ขั้นที่ 9 — แต่ละโครงสร้างซื้อส่วนไหนของผืนความผันผวน

vega วัดแค่การที่ทั้งผืนขึ้นลงพร้อมกัน แต่ผืนความผันผวนในตลาดจริงขยับได้หลายแบบ บางวัน put strike ต่ำแพงขึ้นแต่ call strike สูงถูกลง บางวันแค่อายุสั้นแพงขึ้น ขั้นนี้จึงคำนวณราคาใหม่ทั้งสูตรทุกขาภายใต้การขยับหลายแบบ แล้วดูว่าแต่ละโครงสร้างได้เสียกับแบบไหน ตารางแบบนี้เรียกว่าตาราง scenario

โจทย์ให้อะไรมาบ้าง: ราคาหุ้นเริ่มที่ \$100 และ implied volatility เริ่มที่ 20% ทุกขา การขยับมีหกแบบ:

  • (ก) ขนาน: ทุก strike ทุกอายุขึ้น 1 จุด จาก 20% เป็น 21%
  • (ข) skew ชันขึ้น: strike 90 ขึ้น 1 จุด strike 110 ลง 1 จุด strike 100 เท่าเดิม
  • (ค) ปีกยกขึ้น: strike 90 และ 110 ขึ้น 1 จุด strike 100 เท่าเดิม
  • (ง) อายุสั้น: เฉพาะอายุ 0.25 ปีขึ้น 1 จุด อายุ 0.5 ปีเท่าเดิม
  • หุ้น +5 และหุ้น −5: หุ้นขยับทันทีเป็น \$105 หรือ \$95 ความผันผวนเท่าเดิม

ทำไมต้องคำนวณใหม่ทั้งสูตร ไม่ใช้ Greeks ประมาณเอา? ลองเทียบกับ straddle การประมาณด้วย Greeks คือ Taylor แบบเดียวกับในขั้นที่ hedge delta โดย $\delta\sigma$ คือความผันผวนที่ขยับ ในสองกรณีนี้ความผันผวนไม่ขยับ $\delta\sigma=0$ เหลือแค่พจน์ delta กับ gamma ค่า “exact” คือมูลค่าที่คำนวณใหม่ทั้งสูตร:

\[ \begin{aligned} \text{P\&L}&\approx\Delta\,\delta S+\tfrac12\Gamma(\delta S)^2+\nu\,\delta\sigma,\\ \delta S=5:\ \text{P\&L}&\approx0.0399(5)+\tfrac12(0.0797)(25)\\ &=1.196\ \ (\text{exact }1.153),\\ \delta S=15:\ \text{P\&L}&\approx0.0399(15)+\tfrac12(0.0797)(225)\\ &=9.563\ \ (\text{exact }7.814). \end{aligned} \]

คำตอบ: แต่ละแถวบอกว่าโครงสร้างนั้นซื้ออะไรจริง

  • straddle ได้ +0.398 เมื่อทั้งผืนขึ้น และไม่สนแบบ (ข) กับ (ค) เลย มันจึงซื้อระดับความผันผวน ATM ล้วน ๆ
  • strangle ได้ +0.247 ทั้งจากแบบขนานและแบบปีก มันจึงซื้อระดับความผันผวนของปีก
  • risk reversal แทบไม่สนระดับ (+0.024) แต่เสีย 0.241 เมื่อ skew ชันขึ้น มันจึงเป็นเครื่องมือขาย skew และมีทิศทางติดมาด้วย (delta 0.32)
  • butterfly เสีย 0.151 เมื่อทั้งผืนขึ้น แต่ได้ +0.247 เมื่อปีกแพงขึ้นเทียบกับกลาง มันจึงซื้อความโค้งของ smile และขายระดับ ATM
  • calendar ได้ +0.082 เมื่อทั้งผืนขึ้น แต่เสีย 0.199 เมื่ออายุสั้นขึ้นตัวเดียว มันจึงซื้อ term structure คือได้เมื่ออายุยาวแพงขึ้นเทียบกับอายุสั้น

การประมาณด้วย Greeks แม่นเมื่อหุ้นขยับ \$5 ผิดแค่ $(1.196-1.153)/1.153=4\%$ แต่เมื่อหุ้นขยับ \$15 ผิดถึง $(9.563-7.814)/7.814=22\%$ เพราะ gamma เองเปลี่ยนเมื่อราคาหุ้นเปลี่ยน (ดูรูป gamma เทียบราคาหุ้น) Taylor ที่หยุดแค่ชั้นสองจึงพลาดเมื่อการขยับใหญ่

ตรวจเองใน 10 วินาที: คอลัมน์ขนานเกือบเท่า vega ในตาราง Greeks เช่น straddle 0.398 กับ 0.3984 และ butterfly −0.151 กับ −0.1573 ต่างกันเล็กน้อยเพราะ vega เองเปลี่ยนเมื่อความผันผวนขยับจาก 20% เป็น 21% คอลัมน์ skew ของ straddle เป็นศูนย์ เพราะ straddle ไม่มีขาที่ strike 90 หรือ 110 สุดท้าย straddle ได้ทั้งตอนหุ้นขึ้นและลง แต่ตอนขึ้นได้มากกว่า (1.153 กับ 0.801) เพราะ delta เป็นบวก 0.04

ขั้นที่ 10 — dispersion: variance ของดัชนีแยกเป็นส่วนเดี่ยวกับส่วนร่วม

ความผันผวนไม่ได้มีแค่ของหุ้นตัวเดียว ดัชนี เช่น S&P 500 คือตะกร้าหุ้นหลายตัวที่ถ่วงน้ำหนักไว้ และมี option ของดัชนีซื้อขายด้วย ดัชนีแกว่งแรงแค่ไหนขึ้นกับสองเรื่อง คือหุ้นแต่ละตัวแกว่งแรงแค่ไหน และหุ้นเดินไปทางเดียวกันแค่ไหน เรื่องหลังวัดด้วย correlation ถ้าอยากซื้อขาย correlation ต้องรู้ก่อนว่ามันซ่อนอยู่ตรงไหนในความผันผวนของดัชนี

ผลตอบแทนของดัชนี $r_I$ คือผลตอบแทนของหุ้นแต่ละตัว $r_i$ คูณน้ำหนัก $w_i$ แล้วบวกกัน จึงใช้สูตร variance ของผลรวมเชิงเส้นได้ แล้วแยกคู่ที่เป็นหุ้นตัวเดียวกัน (ส่วนเดี่ยว “own”) ออกจากคู่ที่เป็นหุ้นต่างตัว (ส่วนร่วม “cross”) ตัวอย่างใช้ดัชนีสมมติที่มีหุ้นสองตัว:

  • น้ำหนักเท่ากัน $w_1=w_2=0.5$ จึงได้ $w_i^2=0.25$
  • ความผันผวน $\sigma_1=20\%$ และ $\sigma_2=30\%$ จึงได้ $\sigma_1^2=0.04$ และ $\sigma_2^2=0.09$
  • correlation $\rho=0.4$
\[ \begin{aligned} r_I&=\sum_i w_ir_i,\\ \sigma_I^2&=\sum_i w_i^2\sigma_i^2+2\sum_{i\lt j}w_iw_j\sigma_i\sigma_j\rho_{ij},\\ \text{own}&=0.25(0.04)+0.25(0.09)=0.0325,\\ \text{cross}&=2(0.5)(0.5)(0.2)(0.3)\rho=0.03\rho,\\ \rho=0.4:\ \sigma_I^2&=0.0325+0.012=0.0445,\\ \sigma_I&=\sqrt{0.0445}=21.10\%. \end{aligned} \]

variance ของผลรวม คือผลรวมของ $w_iw_j\operatorname{Cov}(r_i,r_j)$ ทุกคู่ คู่ $(i,j)$ กับ $(j,i)$ ให้ค่าเท่ากัน จึงรวมเป็นสองเท่า และ covariance เขียนได้เป็น $\sigma_i\sigma_j\rho_{ij}$ ส่วนเดี่ยวรู้ได้จากราคา option ของหุ้นรายตัว ส่วนร่วมเป็นที่เดียวที่ correlation โผล่มา และมันเป็นเส้นตรงใน $\rho$

ดัชนีแกว่ง 21.10% ต่ำกว่าค่าเฉลี่ยของหุ้นสองตัว $(20\%+30\%)/2=25\%$ ส่วนต่างนี้คือผลของการกระจายความเสี่ยง หุ้นสองตัวไม่ได้เดินไปทางเดียวกันเสมอ จึงหักกันบางส่วน ถ้า $\rho=1$ จะได้ $\sigma_I^2=0.0325+0.03=0.0625$ คือ $\sigma_I=25\%$ เต็ม ถ้า $\rho=0$ จะเหลือ $\sigma_I=\sqrt{0.0325}=18.03\%$

ขั้นที่ 11 — dispersion ได้เงินเมื่อหุ้นเดินแยกกันมากกว่าที่ราคาคิด

สมมติโต๊ะเชื่อว่าหุ้นในดัชนีจะเดินแยกทางกันมากกว่าที่ตลาดคิด คือ correlation ที่เกิดจริงจะต่ำกว่าที่ราคาบอก โต๊ะอยากเดิมพันเรื่องนี้เรื่องเดียว โดยไม่เดิมพันว่าหุ้นแต่ละตัวจะแกว่งแรงแค่ไหน วิธีคือ dispersion: ขาย variance ของดัชนี แล้วซื้อ variance ของหุ้นรายตัวในขนาดที่ส่วนเดี่ยวหักกันพอดี เครื่องมือที่ใช้คือ variance swap สัญญาที่จ่ายเงินตามผลต่างระหว่าง variance ที่เกิดจริงกับระดับที่ตกลงไว้ คูณด้วยขนาดสัญญาที่เรียกว่า notional

โจทย์ให้อะไรมาบ้าง:

  • ขาย variance ของดัชนีที่ระดับ 0.0445 คือระดับที่ correlation 0.4 จากขั้นก่อน
  • notional \$1,000,000 ต่อ variance 1.00 คือถ้า variance จริงต่างจากระดับที่ตกลง 0.001 เงินจะเปลี่ยน $1{,}000{,}000\times0.001=\$1{,}000$
  • ซื้อ variance ของหุ้นรายตัวในขนาดที่หักกับส่วนเดี่ยว 0.0325 พอดี
  • หุ้นแต่ละตัวแกว่งเท่าที่ราคาคิดไว้ (20% และ 30%) แต่ correlation ที่เกิดจริงคือ 0.2

ได้เสียเท่าไร? และถ้าตลาดซื้อขาย option ดัชนีที่ implied volatility 22% correlation ที่ราคาบอก (implied correlation) คือเท่าไร?

ผู้ขาย variance ของดัชนีได้เงิน $1{,}000{,}000\times(0.0445-\sigma_I^2)$ โดย $\sigma_I^2$ คือ variance ของดัชนีที่เกิดจริง ส่วน implied correlation หาจากการแก้สมการ $0.22^2=0.0325+0.03\rho$ หาค่า $\rho$

\[ \begin{aligned} \rho=0.2:\ \sigma_I^2&=0.0325+0.006=0.0385,\\ \text{P\&L}&=1{,}000{,}000(0.0445-0.0385)\\ &=\$6{,}000,\\ \rho_{\rm impl}&=\frac{0.22^2-0.0325}{0.03}\\ &=\frac{0.0484-0.0325}{0.03}=0.53. \end{aligned} \]

คำตอบ: ส่วนเดี่ยว 0.0325 ไม่เปลี่ยน เพราะหุ้นแต่ละตัวแกว่งเท่าที่ราคาคิด ขาหุ้นรายตัวจึงเสมอตัว ส่วนร่วมลดจาก $0.03\times0.4=0.012$ เหลือ $0.03\times0.2=0.006$ variance ของดัชนีจึงลด 0.006 คนที่ขายไว้ได้ \$6,000 เงินทั้งก้อนมาจาก correlation ไม่ใช่จากความผันผวนของหุ้นรายตัว

ถ้าดัชนีซื้อขายที่ 22% ราคากำลังบอกว่า correlation เฉลี่ยคือ 0.53 ใครเชื่อว่าหุ้นจะเดินแยกกันมากกว่านั้น คือ correlation จริงจะต่ำกว่า 0.53 ก็ทำ dispersion

ตรวจเองใน 10 วินาที: variance ของดัชนีเปลี่ยน 0.03 ต่อ correlation ที่เปลี่ยน 1.00 P&L จึงเป็นเส้นตรงใน $\rho$ correlation ลด 0.2 ได้ $0.2\times0.03\times1{,}000{,}000=\$6{,}000$ ตรงกับข้างบน แต่ระวัง ในวันที่ตลาดตื่นตระหนก correlation มักพุ่งขึ้นพร้อมความผันผวนของหุ้นรายตัว ตัวเลขนี้จึงเป็นแค่กรณีที่แยกผลของ correlation ออกมาให้เห็นตัวเดียว

ความผิดที่ให้ตัวเลขผิดโดยไม่มีอะไรเตือน

อ่าน payoff เป็นกำไร: ความผิดคือดูกราฟ payoff ของ straddle ซึ่งไม่เคยติดลบ แล้วคิดว่าหุ้นขยับทางไหนก็ได้เงิน ที่ \$105 payoff คือ $|105-100|=\$5$ ต่อหน่วย ดูเหมือนได้ แต่ P&L จริงคือ $1{,}000\times(5-7.975522)=-\$2{,}975.52$ จุดที่ P&L ตัดศูนย์คือ \$92.02 และ \$107.98 ไม่ใช่ strike \$100

พิมพ์อัตราส่วนผิด: ความผิดคือขาย call 100 แค่ตัวเดียวแทนสองตัว ชุดที่ได้คือ $C(90)-C(100)+C(110)$ ราคา $10.712381-3.987761+0.953947=7.6786$ แทนที่จะเป็น 3.6908 payoff ที่ \$80, \$100, \$110 และ \$130 คือ 0, 10, 10 และ 30 เช่นที่ \$130 ได้ $(130-90)-(130-100)+(130-110)=30$ ชุดนี้คือ call spread 90/100 บวก call 110 ที่ได้ไม่จำกัด ไม่ใช่กระโจมที่จำกัดความเสี่ยงแล้ว

ตีราคา calendar ด้วย payoff ของสองวัน: ความผิดคือลบ payoff ของสองขาเหมือนหมดอายุวันเดียวกัน ถ้าทำอย่างนั้น ที่ $S_{T_1}=\$100$ ขายาวมีค่า $(100-100)^+=0$ calendar ดูเหมือนไม่มีค่าเลย แต่จริง ๆ ขายาวยังเหลืออายุ 0.25 ปี และมีค่าเวลา \$3.99 ที่ strike calendar จึงมีค่า 3.99 ไม่ใช่ 0

เทียบ realized กับ implied แล้วคิดว่ารู้ผล: ความผิดคือคิดว่า realized ต่ำกว่า implied แปลว่าผู้ขายได้เงินตามสัดส่วนแน่นอน ในตัวอย่าง 50 ช่วง realized ต่ำกว่า implied ไป $30-24.9=5.1$ จุด แต่ผลจริงขึ้นกับว่าการขยับใหญ่เกิดตอน gamma สูงหรือต่ำ การกระโดดครั้งเดียวใกล้หมดอายุกินกำไรไป \$21,919 จาก \$77,334 ถ้าอยากได้เงินตาม variance ตรง ๆ โดยไม่ขึ้นกับว่าหุ้นอยู่ตรงไหน ต้องใช้ variance swap

ลืมต้นทุนของหลายขา: ความผิดคือคิดกำไรจากราคากลางโดยไม่หักต้นทุนการซื้อขาย butterfly มี option สี่ตัว (call 90 หนึ่งตัว, call 100 สองตัว, call 110 หนึ่งตัว) ตลาดจริงให้ซื้อแพงกว่าราคากลางนิดหนึ่ง และขายถูกกว่านิดหนึ่ง สมมติแต่ละตัวห่างราคากลาง \$0.05 เปิดและปิดครบหนึ่งรอบคือซื้อขาย 8 ครั้ง เสีย $8\times0.05=\$0.40$ ต่อหน่วย คิดเป็น $0.40/3.69=11\%$ ของราคา butterfly ก่อนจะได้อะไรเลย

const { abs, exp, log, sqrt, max, PI } = Math;
const phi = x => exp(-0.5 * x * x) / sqrt(2 * PI);
// Normal CDF: Taylor series near the centre, continued fraction in the tails.
function Phi(x) {
  const a = abs(x);
  if (a <= 3) {
    let term = a, sum = a;
    for (let n = 1; n < 200 && term > 1e-17 * sum; n++) { term *= a * a / (2 * n + 1); sum += term; }
    return x >= 0 ? 0.5 + phi(a) * sum : 0.5 - phi(a) * sum;
  }
  let f = a;
  for (let k = 120; k >= 1; k--) f = a + k / f;
  return x >= 0 ? 1 - phi(a) / f : phi(a) / f;
}
// One option per share with rate r (0 on most of this page). Theta per calendar day, vega per vol point.
function option(type, S, K, T, sigma, r = 0) {
  if (type !== 'call' && type !== 'put') throw new TypeError("Option type must be 'call' or 'put'");
  if (![S, K, sigma].every(x => Number.isFinite(x) && x > 0) || !(T >= 0)) throw new RangeError('Spot, strike and volatility must be positive, time not negative');
  if (T === 0) { const call = type === 'call'; return {price: max(call ? S - K : K - S, 0), delta: call ? +(S > K) : -(S < K), gamma: 0, vega: 0, theta: 0}; }
  const sT = sigma * sqrt(T), d1 = (log(S / K) + (r + sigma * sigma / 2) * T) / sT, d2 = d1 - sT, call = type === 'call', D = exp(-r * T);
  return {price: call ? S * Phi(d1) - K * D * Phi(d2) : K * D * Phi(-d2) - S * Phi(-d1), delta: call ? Phi(d1) : Phi(d1) - 1,
    gamma: phi(d1) / (S * sT), vega: 0.01 * S * phi(d1) * sqrt(T), theta: -S * phi(d1) * sigma / (2 * sqrt(T)) / 365};
}
// A structure is a list of signed legs [units, type, strike, years]; volOf lets each strike and expiry have its own vol.
function value(legs, S, volOf = () => 0.2) {
  if (!Array.isArray(legs) || legs.length === 0) throw new RangeError('A structure needs at least one leg');
  const out = {price: 0, delta: 0, gamma: 0, vega: 0, theta: 0};

    for (const key of Object.keys(out)) out[key] += n * o[key];
  }
  return out;
}

function hedgeShortCall(S, K, T, sigma, r, N) {
  const n = S.length - 1, dt = T / n;
  let account = N * option('call', S[0], K, T, sigma, r).price, gammaPnl = 0;
  for (let i = 0; i < n; i++) {
    const o = option('call', S[i], K, T - i * dt, sigma, r), shares = N * o.delta, cash = account - shares * S[i];
    account = shares * S[i + 1] + cash * exp(r * dt);
    const R = S[i + 1] / S[i] - 1;
    gammaPnl += 0.5 * N * o.gamma * S[i] * S[i] * (sigma * sigma * dt - R * R);
  }
  const logs = S.slice(1).map((s, i) => log(s / S[i])), m = logs.reduce((a, x) => a + x, 0) / n;
  const realized = sqrt(logs.reduce((a, x) => a + (x - m) ** 2, 0) / (n - 1) / dt);
  return {premium: N * option('call', S[0], K, T, sigma, r).price, pnl: account - N * max(S[n] - K, 0), gammaPnl, realized};
}
function indexVariance(w, sigma, rho) {
  if (!(rho >= -1 && rho <= 1)) throw new RangeError('Correlation must lie between -1 and 1');
  return w[0] ** 2 * sigma[0] ** 2 + w[1] ** 2 * sigma[1] ** 2 + 2 * w[0] * w[1] * sigma[0] * sigma[1] * rho;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • straddle ATM ราคาเท่ากับระยะที่หุ้นขยับโดยเฉลี่ย $S\sigma\sqrt T\sqrt{2/\pi}\approx0.8\,S\sigma\sqrt T$ ที่ความผันผวน 20% อายุสามเดือนคือ \$7.98 และ payoff ไม่ใช่ P&L หุ้นต้องจบนอก \$92.02 ถึง \$107.98 จึงได้กำไร ที่ \$105 ยังเสีย \$2,975.52 ต่อ 1,000 หน่วย
  • calendar ต้องตีราคาขายาวด้วยสูตรในวันที่ขาสั้นหมดอายุ ไม่ใช่ด้วย payoff มันได้มากที่สุด \$2.34 ต่อหน่วยเมื่อหุ้นอยู่ที่ strike และขาดทุนเมื่อหุ้นหนีออกนอก \$94.22 ถึง \$106.53
  • Greeks ของชุดคือ Greeks ของแต่ละขาคูณจำนวนที่มีเครื่องหมายแล้วบวกกัน คำว่า long ไม่ได้แปลว่าทุกตัวเป็นบวก long butterfly มี gamma และ vega ติดลบเมื่อหุ้นอยู่ตรงกลาง
  • option ที่ hedge delta แล้วได้ $\tfrac12\Gamma S^2(R^2-\sigma^2\delta t)$ ต่อช่วง มันจึงเป็นเดิมพันว่า realized จะสูงหรือต่ำกว่า implied โดยถ่วงด้วย gamma ตัวอย่าง: ขาย call ที่ 30% แล้วหุ้นแกว่งจริง 24.9% ได้ \$55,392 แต่การกระโดดครั้งเดียวใกล้ strike ตอนใกล้หมดอายุกินไป \$21,919
  • แต่ละโครงสร้างซื้อคนละส่วนของผืนความผันผวน straddle ซื้อระดับ ATM strangle ซื้อปีก risk reversal ซื้อขาย skew butterfly ซื้อความโค้ง calendar ซื้อ term structure และ dispersion ซื้อขาย correlation (ได้ \$6,000 ต่อ notional \$1 ล้าน เมื่อ correlation ลดจาก 0.4 เป็น 0.2)
