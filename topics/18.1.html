18.1 The Time Value of Money

เงินคนละวันเอามาบวกหรือเทียบกันตรง ๆ ไม่ได้ ต้องย้ายทุกก้อนมาอยู่วันนี้ด้วยอัตราดอกเบี้ยก่อน และคำตอบว่าทางไหนคุ้มกว่าก็เปลี่ยนไปตามอัตรานั้น

พนักงานคนหนึ่งกำลังจะเกษียณ บริษัทให้เขาเลือกรับเงินบำนาญแบบใดแบบหนึ่งจากสามแบบ (ตัวเลขสมมติ):

  • ทาง A: รับเงินก้อนเดียว \$1,000,000 วันนี้
  • ทาง B: รับ \$120,000 ทุกสิ้นปี 12 ปี แล้วจบ
  • ทาง C: รับ \$45,000 ตอนสิ้นปีแรก แล้วเงินเพิ่มขึ้นปีละ 1% ไปตลอดกาล ไม่มีวันหยุดจ่าย

หลายคนตอบทันทีว่าเลือก B เพราะบวกแล้วได้ $12\times120{,}000=\$1{,}440{,}000$ มากกว่า A บางคนเลือก C เพราะจ่ายไม่มีวันหมด

แต่เงินที่ยังไม่ได้รับไม่ได้อยู่เฉย ๆ ถ้าได้เงินวันนี้ เอาไปฝากธนาคารแบบที่ไม่มีความเสี่ยง (ได้เงินคืนแน่นอนพร้อมดอกเบี้ย) ก็ได้ดอกเบี้ยทุกปี คำถามคือ ถ้าเงินฝากแบบนี้ให้ดอกเบี้ย 5% ต่อปี ควรเลือกทางไหน และถ้าให้ 8% ล่ะ

ลองตอบก่อนเปิดเฉลย

ต้องเทียบทั้งสามทางด้วย “มูลค่าวันนี้” คือเงินก้อนเดียวที่ได้วันนี้แล้วมีค่าเท่ากับเงินชุดนั้น หน้านี้จะคำนวณตัวเลขเหล่านี้ให้ดูทีละขั้นในขั้นที่ 8:

  • ดอกเบี้ย 5%: C มีค่า \$1,125,000 B มีค่า \$1,063,590.20 และ A มีค่า \$1,000,000 ทาง C ชนะ
  • ดอกเบี้ย 8%: A ยังมีค่า \$1,000,000 B เหลือ \$904,329.36 และ C เหลือ \$642,857.14 อันดับกลับกันหมด ทาง A ชนะ

ยอด \$1,440,000 ของ B ไม่มีความหมาย เพราะเงินแต่ละก้อนมาคนละปี \$1 ที่ได้วันนี้ฝากได้ $1\times1.05=\$1.05$ ปีหน้า \$1 วันนี้จึงมีค่ามากกว่า \$1 ปีหน้า ส่วน C ที่จ่ายตลอดกาลก็มีค่าจำกัด เพราะเงินยิ่งมาช้า ยิ่งมีค่าวันนี้น้อย

ภาพรวมก่อนลงสูตร

เงิน \$100 วันนี้กับเงิน \$100 ปีหน้าไม่เท่ากัน เพราะ \$100 วันนี้เอาไปฝากที่ 5% ได้ $100\times1.05=\$105$ ปีหน้า กลับกัน เงิน \$105 ที่จะได้ปีหน้าก็มีค่าวันนี้แค่ $105/1.05=\$100$ เงินคนละวันจึงเอามาบวกหรือเทียบกันตรง ๆ ไม่ได้ ต้องย้ายมาอยู่วันเดียวกันก่อน วันที่สะดวกที่สุดคือวันนี้ การย้ายเงินอนาคตมาวันนี้เรียกว่าการคิดลด (discounting) และอัตรา $r$ ที่ใช้ย้ายเรียกว่าอัตราคิดลด

ราคาเกือบทุกตัวที่เหลือในเล่มเริ่มจากคำถามนี้ คือเงินที่จะได้ในวันข้างหน้ามีค่าเท่าไรวันนี้ ตัวอย่างเช่น

  • สูตร Black–Scholes คูณ strike (ราคาที่ option ให้สิทธิ์ซื้อ ซึ่งจ่ายในวันหมดอายุ) ด้วย $e^{-rT}$ เพื่อย้ายมาวันนี้
  • ต้นไม้ binomial หารด้วย $1+r$ ทุกครั้งที่ถอยกลับหนึ่งงวด
  • ราคาพันธบัตรคือผลบวกของเงินหลายก้อนหลังย้ายแต่ละก้อนมาวันนี้แล้ว

วิธีคิดมีแค่สองจังหวะ จังหวะแรก ย้ายเงินแต่ละก้อนมาวันนี้ โดยหารด้วย $(1+r)^T$ เมื่อ $T$ คือจำนวนปีที่ต้องรอ จังหวะที่สอง บวกทุกก้อนเข้าด้วยกัน หน้านี้จะเดินตามลำดับนี้:

  • ฝากเงินด้วยมือ เพื่อหาว่าดอกเบี้ยทบต้นคืออะไร แล้วเดินกลับทิศเพื่อหาราคาวันนี้
  • เหตุผลว่าทำไมราคาต้องเท่ากับค่านี้พอดี (ถ้าไม่เท่า จะมีคนทำเงินฟรีได้)
  • สูตรลัดสำหรับเงินงวดเท่ากัน (annuity) และเงินงวดที่จ่ายไม่มีวันจบ (perpetuity)
  • หาอัตราที่ทำให้คำตอบ “ทางไหนดีกว่า” พลิก
  • ซอยงวดทบต้นให้ถี่ขึ้นเรื่อย ๆ จนได้ $e^{rT}$ ที่แบบจำลองเวลาต่อเนื่องใช้ทั้งเล่ม

รูปด้านล่างคือเงินของทาง B ทั้ง 12 งวด กรอบเส้นประคือเงินที่ได้จริงงวดละ \$120,000 แท่งทึบคือมูลค่าวันนี้ของเงินก้อนนั้นเมื่อใช้อัตรา 5% เงินยิ่งมาช้า แท่งยิ่งเตี้ย

ศัพท์ที่ใช้ในหัวข้อนี้
Present value (PV) และ future value (FV)
PV คือมูลค่าวันนี้ของเงินที่จะได้ในอนาคต FV คือยอดที่เงินวันนี้จะโตไปถึงในวันหนึ่งข้างหน้า ทั้งสองมีไว้ย้ายเงินข้ามเวลา เพื่อให้เงินคนละวันเทียบกันได้
Discounting และอัตราคิดลด
discounting (การคิดลด) คือการย้ายเงินอนาคตมาเป็นมูลค่าวันนี้ อัตราคิดลด $r$ คืออัตราที่ใช้ย้าย ปกติคือผลตอบแทนที่เงินก้อนเดียวกันหาได้จากทางอื่นที่เสี่ยงเท่ากัน
Discount factor และ zero-coupon bond
discount factor คือตัวคูณที่เปลี่ยนเงิน \$1 ในวันที่ $T$ ให้เป็นเงินวันนี้ ตัวคูณนี้ก็คือราคาวันนี้ของ zero-coupon bond ซึ่งเป็นสัญญาที่จ่าย \$1 ครั้งเดียวในวันที่ $T$ ถ้าดอกเบี้ยเป็นบวกและ $T$ อยู่ในอนาคต ตัวคูณนี้น้อยกว่า 1 เสมอ ถ้า $T$ คือวันนี้ ตัวคูณเท่ากับ 1 พอดี
Simple interest และ compound interest
simple interest (ดอกเบี้ยไม่ทบต้น) คิดดอกเบี้ยจากเงินต้นอย่างเดียวทุกงวด compound interest (ดอกเบี้ยทบต้น) คิดจากยอดทั้งก้อนที่รวมดอกเบี้ยงวดก่อน ๆ แล้ว ถ้าซอยงวดให้ถี่ขึ้นไม่สิ้นสุด เรียกว่า continuous compounding (ทบต้นต่อเนื่อง) ได้ตัวคูณ $e^{rT}$
Coupon ของพันธบัตร
พันธบัตรคือสัญญากู้เงินที่ซื้อขายได้ ผู้ซื้อจ่ายเงินวันนี้ แล้วได้ดอกเบี้ยเป็นงวด ๆ ที่เรียกว่าคูปอง (coupon) และได้เงินต้นคืนในวันครบกำหนด
No-arbitrage
หลักที่ว่าตลาดไม่ปล่อยให้มีเงินฟรี คือไม่มีพอร์ต (ชุดของการซื้อ ขาย กู้ และฝากที่ทำพร้อมกัน) ที่ได้เงินวันนี้โดยไม่ต้องจ่ายอะไรเลยในอนาคต หลักนี้บังคับว่าราคาของเงินชุดหนึ่งต้องเท่ากับ PV ของมัน
Annuity และ perpetuity
annuity คือเงินงวดเท่ากันจำนวนงวดจำกัด เช่น ค่าผ่อนบ้าน หรือคูปองพันธบัตร perpetuity คือเงินงวดที่จ่ายไม่มีวันจบ ทั้งสองแบบมีสูตรปิดจากอนุกรมเรขาคณิต จึงไม่ต้องบวกทีละงวด
NPV และ IRR
NPV (net present value) คือ PV ของเงินเข้าทั้งหมด ลบด้วย PV ของเงินออกทั้งหมด ถ้าเป็นบวกแปลว่าคุ้ม IRR (internal rate of return) คืออัตราที่ทำให้ NPV เป็นศูนย์ คนนิยมใช้สรุปโครงการเป็นตัวเลขเดียว แต่ตัวเลขนี้หลอกได้ง่าย
Effective annual rate (EAR)
ผลตอบแทนต่อปีที่ได้จริงหลังนับดอกเบี้ยที่ทบต้นระหว่างปีแล้ว ใช้เทียบอัตราที่ประกาศด้วยความถี่ทบต้นต่างกัน

ขั้นที่ 1 — ฝาก \$100 ด้วยมือ แล้วหาดอกเบี้ยของดอกเบี้ย

ก่อนจะย้ายเงินกลับมาวันนี้ได้ ต้องรู้ก่อนว่าเงินวันนี้โตไปข้างหน้าอย่างไร ลองฝากเงินด้วยมือทีละปี ของที่ใช้มีสามตัว:

  • เงินฝากวันนี้ $PV=\$100$
  • อัตราดอกเบี้ยต่อปี $r=5\%=0.05$
  • ยอดในบัญชีหลังฝากไป $n$ ปี เรียกว่า $FV_n$ (ในสูตรทั่วไปจะเขียนจำนวนปีเป็น $T$ และเรียกยอดว่า $FV_T$)

ธนาคารคิดดอกเบี้ยได้สองแบบ แบบแรกคือ simple interest (ดอกเบี้ยไม่ทบต้น) ธนาคารคิด 5% จากเงินต้น \$100 เท่านั้น ทุกปีจึงได้ดอกเบี้ยเท่ากัน $100\times0.05=\$5$ หลัง $n$ ปีได้ดอกเบี้ย $n$ ก้อน:

\[ \begin{aligned} FV_n&=PV(1+nr),\\ n=2&:\ 100(1+2\times0.05)=110,\\ n=10&:\ 100(1+10\times0.05)=150. \end{aligned} \]

แบบที่สองคือ compound interest (ดอกเบี้ยทบต้น) ธนาคารคิด 5% จากยอดที่อยู่ในบัญชีตอนนั้น ซึ่งรวมดอกเบี้ยที่ได้ไปแล้วด้วย ทุกปีจึงเอายอดทั้งก้อนคูณ 1.05:

\[ \begin{aligned} n=1&:\ 100\times1.05=105,\\ n=2&:\ 105\times1.05=110.25,\\ &\quad 110.25-110=0.25,\\ &\quad 0.25=5\times0.05,\\ FV_T&=PV(1+r)\cdots(1+r)\\ &=PV(1+r)^T,\\ n=10&:\ 100\times1.05^{10}=162.89,\\ &\quad 162.89-150=12.89. \end{aligned} \]

ปีที่สอง ดอกเบี้ย 5% คิดจากยอด \$105 ทั้งก้อน ไม่ใช่จากเงินต้น \$100 จึงได้มากกว่าแบบไม่ทบต้นอยู่ \$0.25 ส่วนเกินนี้มาจากดอกเบี้ย \$5 ของปีแรก ซึ่งไปงอกดอกเบี้ยอีก 5% ได้ $5\times0.05=\$0.25$ เราเรียกส่วนนี้ว่าดอกเบี้ยของดอกเบี้ย

ทุกปีทำเหมือนกัน คือคูณยอดทั้งก้อนด้วย $1+r$ ผ่านไป $T$ ปีจึงคูณ $T$ ครั้ง เขียนรวบเป็นยกกำลัง $T$ ได้ ช่วงแรกสองแบบแทบไม่ต่างกัน แต่พอถึงปีที่ 10 แบบทบต้นได้ \$162.89 แบบไม่ทบต้นได้ \$150 ส่วนต่าง \$12.89 คือดอกเบี้ยของดอกเบี้ยที่สะสมมาสิบปี และส่วนนี้โตเร็วขึ้นเรื่อย ๆ ตามเวลา

ขั้นที่ 2 — เดินกลับทิศ: discount factor คือราคาของ \$1 ในอนาคต

ในตลาด คำถามมักมาในทิศกลับ มีคนเสนอสัญญาว่าจะจ่ายเงินให้เรา \$105 ในอีกหนึ่งปี วันนี้เราควรจ่ายเท่าไรเพื่อซื้อสัญญานี้ ขั้นที่แล้วให้ $FV=PV(1+r)^T$ ตอนนี้รู้ $FV$ แต่ไม่รู้ $PV$ จึงแก้สมการหา $PV$ แล้วตั้งชื่อให้ตัวคูณที่ได้ว่า $D(0,T)$ (อ่านว่า discount factor จากวันที่ $T$ มาวันที่ 0 คือวันนี้)

\[ \begin{aligned} PV&=\frac{FV}{(1+r)^T}\\ &=FV\times D(0,T),\\ D(0,T)&=\frac{1}{(1+r)^T},\\ D(0,0)&=\frac{1}{1.05^0}=1,\\ D(0,1)&=\frac{1}{1.05}=0.952381,\\ D(0,2)&=\frac{1}{1.05^2}=0.907029,\\ D(0,10)&=\frac{1}{1.05^{10}}=0.613913,\\ 105\times D(0,1)&=105\times0.952381=100. \end{aligned} \]

$D(0,T)$ คือราคาวันนี้ของสัญญาที่จ่าย \$1 ในวันที่ $T$ ตลาดเรียกสัญญาแบบนี้ว่า zero-coupon bond เพราะจ่ายครั้งเดียวตอนจบ ไม่มีคูปองระหว่างทาง ยิ่งรอนาน ราคายิ่งถูก ส่วนเงิน \$1 ที่ได้วันนี้ก็มีค่า \$1 พอดี

ทำไมสัญญาที่จ่าย \$105 ปีหน้าต้องราคา \$100 พอดี ลองดูสองกรณี

  • ถ้าผู้ขายตั้งราคา \$101 จะไม่มีใครซื้อ เพราะเอา \$100 ไปฝากเองก็ได้ \$105 ปีหน้าเหมือนกัน และยังเหลือเงิน \$1
  • ถ้าผู้ขายตั้งราคา \$98 ทุกคนจะแห่ซื้อแทนการฝาก เพราะถ้าฝาก \$98 จะได้แค่ $98\times1.05=\$102.90$ ไม่ถึง \$105

ราคาเดียวที่ไม่มีฝ่ายไหนได้เปรียบจึงเป็น $FV\times D(0,T)$ เหตุผลเดียวกันใช้กับสัญญาทุกแบบ เช่น สัญญาที่จ่าย \$103 ปีหน้ามีค่าวันนี้ $103/1.05=\$98.10$

ขั้นที่ 3 — เงินหลายก้อน: ย้ายทีละก้อนแล้วค่อยบวก และทำไมราคาต้องเท่านี้

เงินส่วนใหญ่ในตลาดไม่ได้มาก้อนเดียว พันธบัตรเป็นตัวอย่างที่ดี พันธบัตรคือสัญญากู้เงินที่ซื้อขายได้ ผู้ซื้อจ่ายเงินวันนี้ แล้วได้ดอกเบี้ยรายปีที่เรียกว่าคูปอง (coupon) และได้เงินต้นคืนในปีสุดท้าย ลองดูพันธบัตรสมมติอายุสองปี:

  • เงินต้น \$100 คูปอง 4% ต่อปี คือ $100\times0.04=\$4$ ต่อปี
  • ปลายปีที่ 1 ได้คูปอง $c_1=\$4$
  • ปลายปีที่ 2 ได้คูปองกับเงินต้น $c_2=4+100=\$104$
  • อัตราดอกเบี้ยในตลาด $r=5\%$ ต่อปี

เงินสองก้อนนี้รอไม่เท่ากัน จึงต้องใช้ discount factor คนละตัว ย้ายแต่ละก้อนมาวันนี้ก่อน พอทุกก้อนอยู่วันเดียวกันแล้วจึงบวกกันได้ จากนั้นถามต่อว่า ถ้ามีคนขายพันธบัตรนี้ที่ราคา $p=\$97$ จะเกิดอะไรขึ้น

\[ \begin{aligned} PV&=\sum_{k=1}^{n}\frac{c_k}{(1+r)^k},\\ \frac{4}{1.05}&=3.809524,\\ \frac{104}{1.05^2}&=94.331066,\\ PV&=3.809524+94.331066\\ &=98.140590,\\ p&=97\lt PV,\\ PV-p&=98.140590-97=1.140590. \end{aligned} \]

เงินที่ได้รวม $4+104=\$108$ แต่มีค่าวันนี้แค่ \$98.14 ซึ่งต่ำกว่าเงินต้น \$100 ด้วย เหตุผลคือคูปอง 4% ต่ำกว่าดอกเบี้ย 5% ที่เงินหาได้เองในตลาด ผู้ซื้อจึงยอมจ่ายต่ำกว่า \$100 เพื่อชดเชยดอกเบี้ยที่ขาดไป

ทำไมราคาต้องเป็น \$98.14 พอดี สมมติมีคนขายที่ \$97 เราทำสามอย่างพร้อมกันวันนี้:

  • ซื้อพันธบัตร จ่าย \$97
  • กู้เงินก้อนแรก $4/1.05=\$3.81$ ปีหน้าต้องคืน \$4 พอดี
  • กู้เงินก้อนที่สอง $104/1.05^2=\$94.33$ ปีที่ 2 ต้องคืน \$104 พอดี

คูปองของพันธบัตรใช้หนี้ทั้งสองก้อนได้พอดี ในอนาคตจึงไม่มีเงินเข้าหรือออกเลย แต่วันนี้เราได้เงินกู้ $3.81+94.33=\$98.14$ จ่ายค่าพันธบัตรไป \$97 เหลือ $98.14-97=\$1.14$ ฟรี ๆ ถ้าราคาสูงกว่า \$98.14 ก็ทำกลับทิศ คือขายพันธบัตร (ถ้าไม่มี ก็ยืมมาขาย) แล้วฝากเงินสองก้อนไว้จ่ายคูปองแทน ทุกคนแห่ทำแบบนี้ ราคาจึงถูกดันกลับมาที่ PV เสมอ เหตุผลแบบนี้ชื่อ no-arbitrage (ไม่มีเงินฟรี) และจะเป็นเครื่องมือหลักของต้นไม้ binomial

ขั้นที่ 4 — ถ้าดอกเบี้ยกู้กับดอกเบี้ยฝากไม่เท่ากัน ราคากลายเป็นช่วง

เหตุผลในขั้นที่แล้วแอบสมมติว่าเรากู้และฝากได้ที่อัตราเดียวกัน ของจริงไม่ใช่ ธนาคารคิดดอกเบี้ยเงินกู้แพงกว่าดอกเบี้ยเงินฝากเสมอ ลองดูว่าเหตุผลเรื่องเงินฟรียังใช้ได้แค่ไหน ของที่ใช้ (ตัวเลขสมมติ):

  • ดอกเบี้ยเงินฝาก $r_L=5\%$ ต่อปี (L มาจาก lend คือเราให้ธนาคารยืม)
  • ดอกเบี้ยเงินกู้ $r_B=7\%$ ต่อปี (B มาจาก borrow คือเรายืมจากธนาคาร)
  • สัญญาที่จ่าย $c=\$105$ ในอีกหนึ่งปี ขายในตลาดที่ราคา $p$

เราทำพอร์ตสองทิศเหมือนเดิม ทิศแรกซื้อสัญญาแล้วกู้เงิน จึงใช้อัตรากู้ $r_B$ ทิศที่สองขายสัญญาแล้วฝากเงิน จึงใช้อัตราฝาก $r_L$ ให้ $PV(c;\,r)$ หมายถึงมูลค่าวันนี้ของเงิน $c$ เมื่อคิดด้วยอัตรา $r$:

\[ \begin{aligned} p&\ge PV(c;\,r_B)=\frac{105}{1.07}=98.13,\\ p&\le PV(c;\,r_L)=\frac{105}{1.05}=100,\\ PV(c;\,r_B)&\le p\le PV(c;\,r_L). \end{aligned} \]

ขอบล่างมาจากทิศซื้อ ถ้าสัญญาขายต่ำกว่า \$98.13 เช่น \$97 ให้ซื้อสัญญา แล้วกู้ $105/1.07=\$98.13$ ที่ 7% ปีหน้าต้องคืน \$105 ซึ่งเงินจากสัญญาจ่ายได้พอดี วันนี้เหลือ $98.13-97=\$1.13$ ฟรี

ขอบบนมาจากทิศขาย ถ้าสัญญาขายสูงกว่า \$100 เช่น \$101 ให้ขายสัญญา (รับปากว่าจะจ่าย \$105 ปีหน้า) แล้วฝาก \$100 ที่ 5% ปีหน้าได้ $100\times1.05=\$105$ ไว้จ่ายพอดี วันนี้เหลือ $101-100=\$1$ ฟรี

ระหว่าง \$98.13 ถึง \$100 ทั้งสองทิศทำเงินฟรีไม่ได้ ราคาที่ไม่มีใครได้ฟรีจึงไม่ใช่ค่าเดียว แต่เป็นช่วง ราคาจริงจะอยู่ตรงไหนในช่วง ขึ้นกับว่าฝั่งอยากซื้อหรือฝั่งอยากขายมีมากกว่า ในตลาดที่ผู้เล่นรายใหญ่กู้ได้ถูกจนเกือบเท่าอัตราฝาก ช่วงนี้จึงแคบจนแทบเป็นจุดเดียว

ขั้นที่ 5 — ห้างวดรายเดือนที่ไม่เท่ากันในตารางคำนวณ

เงินในชีวิตจริงไม่ได้มาเท่ากันทุกงวด เช่น ค่าเช่าที่บางเดือนเก็บได้ไม่ครบ งานแบบนี้มักทำในตารางคำนวณอย่าง Excel วิธีคิดยังเหมือนเดิม คือย้ายทีละก้อนแล้วบวก

โจทย์ให้อะไรมาบ้าง (ตัวเลขสมมติ):

  • เงินที่จะได้ปลายเดือนที่ 1 ถึง 5 คือ \$55.34, \$55.34, \$63.46, \$32.47 และ \$110.19
  • อัตราคิดลด 4.5% ต่อปี ทบต้นรายเดือน อัตราต่อเดือนจึงเป็น $0.045/12=0.00375$ หรือ 0.375%
\[ \begin{aligned} \frac{55.34}{1.00375}&=55.13,\\ \frac{55.34}{1.00375^2}&=54.93,\\ \frac{63.46}{1.00375^3}&=62.75,\\ \frac{32.47}{1.00375^4}&=31.99,\\ \frac{110.19}{1.00375^5}&=108.15,\\ PV&=55.13+54.93+62.75\\ &\quad+31.99+108.15\\ &=312.95. \end{aligned} \]

คำตอบ: \$312.95 (ถ้าไม่ปัดเศษระหว่างทาง ได้ 312.9464) สมมติวางตารางแบบนี้: ช่อง C1 ถึง G1 ใส่เลขเดือน 1 ถึง 5 ช่อง C2 ถึง G2 ใส่เงินแต่ละเดือน ช่อง C6 ใส่อัตรารายเดือน 0.00375 ใน Excel ทำได้สองทาง

  • ทางแรก พิมพ์ =NPV(C6, C2:G2) ได้คำตอบในช่องเดียว
  • ทางที่สอง คิดทีละเดือนด้วย =C2/((1+C6)^C1) ตรึงช่อง C6 ไว้ตอนลากสูตรไปทางขวา แล้วบวกห้าช่อง ทางนี้ใช้ตรวจทางแรกได้ในตัว

ข้อควรระวังสองข้อ ฟังก์ชัน PV ของ Excel ใช้ไม่ได้ เพราะรับเงินงวดได้ค่าเดียว และ NPV ของ Excel ถือว่าช่องแรกได้เงินปลายงวดแรก ถ้ามีเงินเข้าหรือออกวันนี้ ต้องบวกนอกสูตรเอง

ตรวจเองใน 10 วินาที: ถ้าไม่คิดลดเลย เงินรวมเป็นเท่าไร การคิดลดตัดไปกี่เปอร์เซ็นต์ แล้วเทียบกับค่าประมาณ “เวลารอเฉลี่ย × อัตราต่อเดือน” เวลารอเฉลี่ย $\bar t$ คือเลขเดือนถ่วงด้วยเงินของเดือนนั้น:

\[ \begin{aligned} \text{sum}&=55.34+55.34+63.46\\ &\quad+32.47+110.19=316.80,\\ \text{cut}&=\frac{316.80-312.95}{316.80}=1.2\%,\\ \bar t&=\frac{1(55.34)+2(55.34)+3(63.46)}{316.80}\\ &\quad+\frac{4(32.47)+5(110.19)}{316.80}\\ &=3.27\ \text{months},\\ \bar t\times\tfrac{0.045}{12}&=3.27\times0.375\%=1.2\%. \end{aligned} \]

สองค่าตรงกัน การคิดลดเดือนละ 0.375% เป็นเวลาเฉลี่ย 3.27 เดือน จึงตัดเงินไปราว 1.2% ตามที่ควร เวลารอเฉลี่ยยาวกว่ากลางช่วง (เดือนที่ 3) เพราะเงินก้อนใหญ่ที่สุดอยู่เดือนสุดท้าย

ขั้นที่ 6 — เงินงวดเท่ากัน: annuity และ perpetuity จากอนุกรมเรขาคณิต

ทาง B จ่ายเงินเท่ากัน 12 งวด งวดละ $c=\$120{,}000$ จะย้ายทีละงวดแล้วบวกเหมือนขั้นที่แล้วก็ได้ แต่ถ้ามี 360 งวด (ผ่อนบ้านรายเดือน 30 ปี คือ $30\times12=360$ งวด) จะเหนื่อยมาก ลองดูรูปแบบของพจน์ก่อน ให้ $v=1/(1+r)$ เป็นตัวคูณที่ย้ายเงินกลับมาหนึ่งงวด เงิน \$1 งวดที่ $k$ จึงมีค่าวันนี้ $v^k$ ทุกพจน์คือพจน์ก่อนหน้าคูณ $v$ ผลบวกนี้จึงเป็นอนุกรมเรขาคณิต ให้ $S_n$ คือผลบวกของ $n$ งวด งวดละ \$1 เราหาผลบวกแบบปิดได้ด้วยกล “คูณแล้วลบ”

\[ \begin{aligned} S_n&=v+v^2+\dots+v^n,\\ vS_n&=v^2+\dots+v^n+v^{n+1},\\ S_n-vS_n&=v-v^{n+1},\\ S_n&=\frac{v}{1-v}\,(1-v^n),\\ \frac{v}{1-v}&=\frac{1/(1+r)}{r/(1+r)}=\frac1r,\\ PV_{\text{ann}}&=c\,\frac{1-(1+r)^{-n}}{r},\\ PV_{\text{perp}}&=\lim_{n\to\infty}PV_{\text{ann}}=\frac cr. \end{aligned} \]

ท่าสำคัญคือคูณทั้งแถวด้วย $v$ แถวใหม่จึงเลื่อนไปหนึ่งพจน์ พอเอาสองแถวมาลบกัน พจน์กลางทุกตัวหักล้างกันหมด เหลือแค่หัว $v$ กับท้าย $v^{n+1}$ กลนี้ทำให้ 12 พจน์ หรือ 360 พจน์ของเงินกู้บ้าน คิดได้ในบรรทัดเดียว คูณผลบวกด้วยเงินต่องวด $c$ ก็ได้ PV ของ annuity

ถ้าจ่ายไม่มีวันจบ $v^n$ จะเข้าใกล้ศูนย์ เพราะ $v$ อยู่ระหว่าง 0 กับ 1 สูตรจึงเหลือ $c/r$ ตรวจด้วยเหตุผลได้ ถ้าฝากเงิน $c/r$ ไว้ จะได้ดอกเบี้ยปีละ $r\times c/r=c$ พอดี จึงจ่าย $c$ ได้ทุกปีตลอดไปโดยเงินต้นไม่ลดเลย

อีกทางที่ได้สูตรเดียวกันโดยไม่ต้องใช้พีชคณิต (ดูรูปด้านล่าง) annuity $n$ งวด เท่ากับ perpetuity ที่เริ่มจ่ายปีหน้า ลบด้วย perpetuity แบบเดียวกันที่เริ่มจ่ายปีที่ $n+1$ ตัวหลังคือ perpetuity ธรรมดาที่เลื่อนออกไป $n$ ปี จึงมีค่าวันนี้ $(1+r)^{-n}\,c/r$ ผลต่างจึงเป็น

\[\frac cr-(1+r)^{-n}\frac cr=\frac cr\big(1-(1+r)^{-n}\big)\]

ซึ่งตรงกับสูตร annuity ข้างบน

ขั้นที่ 7 — เงินงวดที่โตทุกปี: ทำไมต้องมี $g\lt r$

ทาง C ต่างจาก B สองอย่าง คือเงินโตขึ้นทุกปี และจ่ายไม่มีวันจบ สูตรของขั้นที่แล้วจึงใช้ตรง ๆ ไม่ได้ ให้ $c$ คือเงินปลายปีแรก และ $g$ คืออัตราที่เงินโตต่อปี ทาง C มี $c=\$45{,}000$ และ $g=1\%$ เงินปีที่ 2 จึงเป็น $45{,}000\times1.01=\$45{,}450$ และโดยทั่วไปเงินงวดที่ $k$ คือ $c(1+g)^{k-1}$ ถ้าดึง $c/(1+r)$ ออกมานอกผลบวก สิ่งที่เหลือก็เป็นอนุกรมเรขาคณิตอีก โดยมีอัตราส่วน $q$ (ในแถวที่สองเปลี่ยนตัวนับเป็น $j=k-1$ เพื่อให้เริ่มที่ศูนย์)

\[ \begin{aligned} PV&=\sum_{k=1}^{\infty}\frac{c(1+g)^{k-1}}{(1+r)^k}\\ &=\frac{c}{1+r}\sum_{j=0}^{\infty}q^j,\quad q=\frac{1+g}{1+r},\\ &=\frac{c}{1+r}\cdot\frac{1}{1-q}\\ &=\frac{c}{(1+r)-(1+g)}=\frac{c}{r-g}. \end{aligned} \]

ท่าที่ต้องระวังคือตอนใช้สูตรผลบวกอนุกรมเรขาคณิต ผลบวก $1+q+q^2+\dots$ เท่ากับ $1/(1-q)$ ได้ก็ต่อเมื่อ $q\lt 1$ ซึ่งแปลว่าเงินงวดโตช้ากว่าอัตราคิดลด ($g\lt r$) เมื่อเป็นแบบนั้น มูลค่าวันนี้ของงวดไกล ๆ จะเล็กลงเรื่อย ๆ จนผลบวกมีค่าจำกัด ถ้า $g\ge r$ งวดไกล ๆ ไม่เล็กลงเลย ผลบวกจึงเป็นอนันต์ ถ้าฝืนแทนตัวเลขลงสูตรจะได้ค่าติดลบที่ไม่มีความหมาย

สังเกตตัวส่วน $r-g$ ถ้า $r$ กับ $g$ ใกล้กัน ตัวส่วนจะเล็ก มูลค่าจึงไวต่อ $r$ มาก ทาง C มี $g=0.01$ ลองเปลี่ยน $r$ จาก 5% เป็น 8%:

\[ \begin{aligned} r=0.05&:\ r-g=0.05-0.01=0.04,\\ r=0.08&:\ r-g=0.08-0.01=0.07,\\ \frac{c/0.07}{c/0.04}&=\frac{0.04}{0.07}=0.571. \end{aligned} \]

มูลค่าที่ 8% เหลือแค่ 57.1% ของมูลค่าที่ 5% คือหายไปเกือบครึ่ง ขั้นถัดไปจะเห็นผลนี้กับตัวเลขจริง

  • คิดที่อัตรา $r=0.05$ ก่อน แล้วคิดซ้ำที่ $r=0.08$ ตัวห้อยของ $PV$ บอกอัตราเป็นเปอร์เซ็นต์

จากนั้นจะดูว่าทำไม C ร่วงแรงกว่า B มาก วิธีวัดคือหาว่าเงิน 12 ปีแรกของ C มีค่าเท่าไร เงินตั้งแต่ปีที่ 13 เป็นต้นไปหน้าตาเหมือนสาย C ทั้งสายทุกอย่าง ต่างกันแค่ทุกงวดโตไปแล้ว $(1+g)^{12}$ เท่า และมาช้ากว่า 12 ปี จึงต้องหารด้วย $(1+r)^{12}$ ส่วนหางนี้จึงมีค่า $(1+g)^{12}/(1+r)^{12}=q^{12}$ เท่าของทั้งสาย ส่วน 12 ปีแรกคือทั้งสายลบหาง

\[ \begin{aligned} PV_5(B)&=120{,}000\times\frac{1-1.05^{-12}}{0.05}\\ &=120{,}000\times8.863252\\ &=1{,}063{,}590.20,\\ PV_8(B)&=120{,}000\times\frac{1-1.08^{-12}}{0.08}\\ &=120{,}000\times7.536078\\ &=904{,}329.36,\\ PV_5(C)&=\frac{45{,}000}{0.05-0.01}=1{,}125{,}000,\\ PV_8(C)&=\frac{45{,}000}{0.08-0.01}=642{,}857.14,\\ \frac{PV_8(B)}{PV_5(B)}&=0.850\quad(-15.0\%),\\ \frac{PV_8(C)}{PV_5(C)}&=0.571\quad(-42.9\%),\\ q^{12}&=\Big(\frac{1.01}{1.05}\Big)^{12}=0.627458,\\ C_{1..12}&=\frac{c}{r-g}\big(1-q^{12}\big)\\ &=1{,}125{,}000(1-0.627458)\\ &=419{,}109.37,\\ \frac{C_{1..12}}{PV_5(C)}&=\frac{419{,}109.37}{1{,}125{,}000}=37.3\%. \end{aligned} \]

คำตอบ: ที่ 5% C ชนะ ตามด้วย B แล้วจึงเป็น A ทาง C ชนะทั้งที่เงินงวดแรกน้อยกว่า B ถึง $120{,}000/45{,}000=2.7$ เท่า เพราะ C จ่ายไปเรื่อย ๆ และโตทุกปี

ที่ 8% ทาง A ไม่ขยับ เพราะเป็นเงินวันนี้ ไม่ต้องคิดลด ทาง B เสียมูลค่า 15.0% แต่ทาง C เสียถึง 42.9% อันดับจึงกลับเป็น A, B, C

ทำไม C เสียมากขนาดนั้น ที่ 5% มูลค่าของ C มาจาก 12 ปีแรกแค่ 37.3% อีก $1-0.373=62.7\%$ มาจากเงินหลังปีที่ 12 เงินส่วนนี้ถูกคิดลดหลายสิบปี อัตราที่ขึ้นนิดเดียวจึงกัดส่วนนี้หนักมาก

ตรวจเองใน 10 วินาที: ถ้าไม่คิดลดเลย เงินของ B รวมกันได้ $12\times120{,}000=\$1{,}440{,}000$ การคิดลดตัดออกไป $1{,}440{,}000-1{,}063{,}590.20=\$376{,}409.80$ คิดเป็น $376{,}409.80/1{,}440{,}000=26\%$ ค่านี้สมเหตุผล เพราะเงินงวดกลาง ๆ ของ B รอราว 6 ปี และ $1-1.05^{-6}=1-0.746=25\%$ ใกล้กัน

ความไวต่ออัตราแบบนี้มีชื่อเฉพาะว่า duration คือเวลารอเฉลี่ยของเงิน โดยถ่วงแต่ละงวดด้วย PV ของงวดนั้น หน้านั้นจะสร้างสูตรให้ดู ตอนนี้ขอใช้ผลก่อน:

\[ \begin{aligned} \text{duration}&=\frac{\sum_k k\,PV_k}{PV},\\ B&:\ 5.9\ \text{years},\\ C&:\ \frac{1+r}{r-g}=\frac{1.05}{0.04}=26.25\ \text{years}. \end{aligned} \]

ยิ่ง duration ยาว มูลค่ายิ่งร่วงแรงเมื่ออัตราขึ้น C รอเฉลี่ยนานกว่า B ถึง $26.25/5.9=4.4$ เท่า จึงร่วงแรงกว่ามาก

ขั้นที่ 9 — อันดับพลิกที่อัตราไหน

คำตอบเปลี่ยนตามอัตรา แต่พนักงานไม่รู้แน่ว่าอัตราในอนาคตจะเป็นเท่าไร สิ่งที่เขาควรรู้จึงเป็นอัตราที่ทำให้อันดับพลิก พอรู้จุดพลิกแล้ว เขาก็ถามตัวเองได้ง่าย ๆ ว่าเชื่อไหมว่าเงินของตัวเองจะหาผลตอบแทนได้เกินอัตรานั้น

จุดที่ C เท่ากับ A แก้สมการตรง ๆ ได้ แต่จุดที่ B เท่ากับทางอื่นแก้ด้วยมือไม่ได้ เพราะ PV ของ annuity 12 งวดเป็นพหุนามกำลัง 12 ของ $v$ ไม่มีสูตรปิด จึงต้องหาเป็นตัวเลข โค้ดท้ายหน้าใช้การแบ่งครึ่งช่วง (bisection) คือเริ่มจากช่วงอัตราที่ผลต่างของสองทางเปลี่ยนเครื่องหมาย แล้วตัดช่วงครึ่งหนึ่งทิ้งไปเรื่อย ๆ โดยเก็บครึ่งที่ยังเปลี่ยนเครื่องหมายไว้ ให้ $r_{CA}$ คืออัตราที่ C เท่ากับ A และตั้งชื่อตัวอื่นแบบเดียวกัน

\[ \begin{aligned} C=A&:\ \frac{45{,}000}{r-0.01}=10^6,\\ r-0.01&=\frac{45{,}000}{10^6}=0.045,\\ r_{CA}&=0.01+0.045=5.50\%,\\ B=C&:\ r_{BC}=5.3037\%,\\ B=A&:\ r_{BA}=6.1104\%. \end{aligned} \]

จุดพลิกสามจุดแบ่งอัตราออกเป็นสี่ช่วง อันดับจากดีที่สุดไปแย่ที่สุดเป็นดังนี้

  • อัตราต่ำกว่า 5.30%: C, B, A
  • อัตรา 5.30% ถึง 5.50%: B, C, A
  • อัตรา 5.50% ถึง 6.11%: B, A, C
  • อัตราสูงกว่า 6.11%: A, B, C

แค่อัตราขยับจาก 5% ไป 8% อันดับก็พลิกถึงสามครั้ง คำถาม “ทางไหนดีกว่า” จึงไม่มีคำตอบ ถ้าไม่บอกอัตรา

ตรวจจุดที่ B เท่ากับ A ด้วยการแทนค่าสองข้าง ที่ 6% B มีค่า \$1,006,061.27 มากกว่า A ที่ 6.2% B มีค่า \$995,121.25 น้อยกว่า A จุดตัดจึงอยู่ระหว่าง 6% กับ 6.2% ตรงกับ 6.1104% ที่หาได้

ตัวเลข 6.1104% นี้คือ IRR ของการสละ A เพื่อรับ B คิดแบบนี้ได้ ถ้าเลือก B ก็เหมือนยอมทิ้งเงิน \$1,000,000 วันนี้ เพื่อแลกกับเงิน \$120,000 ทุกปี 12 ปี “การลงทุน” นี้ให้ผลตอบแทน 6.11% ต่อปี ถ้าเงินของเราหาผลตอบแทนที่เสี่ยงเท่ากันได้ต่ำกว่านี้ B คุ้มกว่า ถ้าหาได้สูงกว่า A คุ้มกว่า

ขั้นที่ 10 — ซอยงวดทบต้นจนต่อเนื่อง: ที่มาของ $e^{rT}$

ธนาคารมักประกาศอัตราเป็น “ต่อปี” แต่ทบต้นถี่กว่าปีละครั้ง เช่น ประกาศ 5% ต่อปี แต่ทบต้นทุกเดือน ทุกวัน หรือในแบบจำลองก็ทบต้นทุกขณะ เราต้องรู้ว่าการทบถี่ขึ้นทำให้เงินโตเท่าไร และถ้าทบถี่ไม่สิ้นสุดจะได้อะไร

ให้ $m$ คือจำนวนครั้งที่ทบต้นต่อปี เช่น $m=12$ คือรายเดือน แต่ละงวดได้ดอกเบี้ย $r/m$ เช่น $0.05/12=0.4167\%$ ต่อเดือน และ $T$ ปีมีทั้งหมด $mT$ งวด เราอยากรู้ว่าเกิดอะไรขึ้นเมื่อ $m$ โตไม่สิ้นสุด เคล็ดคือตั้งตัวแปรใหม่ $u=m/r$ แล้วรูปจะกลายเป็นนิยามของเลข $e$ อีกทางหนึ่งคือมองเป็นสมการเชิงอนุพันธ์ ให้ $M(t)$ คือเงินในบัญชีที่เวลา $t$ ในช่วงเวลาสั้น ๆ $dt$ เงิน $M$ งอกดอกเบี้ย $rM\,dt$

\[ \begin{aligned} FV_m&=PV\Big(1+\frac rm\Big)^{mT},\\ u&=\frac mr,\quad mT=u\,rT,\\ \Big(1+\frac rm\Big)^{mT}&=\Big[\Big(1+\frac1u\Big)^{u}\Big]^{rT}\\ &\to e^{rT},\\ \frac{dM}{dt}&=rM,\quad \frac{dM}{M}=r\,dt,\\ \ln M(t)&=rt+\ln M(0),\\ M(t)&=M(0)\,e^{rt},\\ D(0,T)&=\frac{1}{e^{rT}}=e^{-rT}. \end{aligned} \]

ท่าสำคัญคือการแยกเลขชี้กำลัง เพราะ $r/m=1/u$ และ $mT=u\times rT$ เราจึงเขียนการยกกำลัง $mT$ เป็นการยกกำลัง $u$ ก่อน แล้วค่อยยกกำลัง $rT$ ได้ ของในวงเล็บ $[\ ]$ คือ $(1+1/u)^u$ ซึ่งเข้าใกล้ $e\approx2.71828$ เมื่อ $u$ โตขึ้นเรื่อย ๆ และ $u$ โตตาม $m$ เสมอ เพราะ $r$ คงที่ ถ้าใส่ $r=1$ (ดอกเบี้ย 100% ต่อปี) กับ $T=1$ จะเห็นว่า $e$ ก็คือยอดที่ \$1 โตไปถึงในหนึ่งปี เมื่อทบต้นถี่ไม่สิ้นสุด

ทางสมการเชิงอนุพันธ์บอกเรื่องเดียวกันจากอีกมุม เงินโตเร็วตามยอดที่มีอยู่ ยิ่งมีมาก ดอกเบี้ยยิ่งงอกมาก แยกตัวแปรแล้วอินทิเกรตสองข้าง จะได้ $\ln M$ เป็นเส้นตรงในเวลา เงินจึงโตแบบ $e^{rt}$ กลับทิศเพื่อหาราคาวันนี้ก็ได้ discount factor $e^{-rT}$ นี่คือเหตุที่แบบจำลองเวลาต่อเนื่องทั้งเล่ม ตั้งแต่ geometric Brownian motion จนถึงสูตร Black–Scholes คิดลดด้วย $e^{-rT}$

ขั้นที่ 11 — \$1,000,000 ในอีก 12 ปี ที่ “5%” หกแบบ

คำว่า “5% ต่อปี” ฟังดูชัด แต่ถ้าไม่บอกว่าทบต้นถี่แค่ไหน ราคาวันนี้ก็ต่างกันได้หลายพันดอลลาร์ ลองเอาเงินก้อนเดียวกันมาคิดลดด้วย “5%” หกแบบ

โจทย์ให้อะไรมาบ้าง:

  • เงิน \$1,000,000 ที่จะได้ในอีก $T=12$ ปี
  • อัตราที่ประกาศ $r=5\%$ ต่อปี
  • ทบต้นปีละ $m$ ครั้ง: $m=1$ (รายปี), 2 (ครึ่งปี), 4 (รายไตรมาส), 12 (รายเดือน), 365 (รายวัน ตามจำนวนวันในปีปฏิทิน) และแบบต่อเนื่อง

แต่ละแบบใช้ discount factor $(1+r/m)^{-mT}$ ส่วนแบบต่อเนื่องใช้ $e^{-rT}$ โดย $rT=0.05\times12=0.6$ จากนั้นหาว่าอัตราต่อเนื่อง $r_c$ เท่าไร จึงให้ผลเท่ากับ 5% รายปีพอดี ตัวช่วยเทียบคือ EAR ซึ่งคือผลตอบแทนจริงในหนึ่งปีหลังทบต้นครบแล้ว

\[ \begin{aligned} m=1&:\ 1.05^{-12}=0.556837,\\ m=2&:\ 1.025^{-24}=0.552875,\\ m=4&:\ 1.0125^{-48}=0.550856,\\ m=12&:\ \big(1+\tfrac{0.05}{12}\big)^{-144}\\ &\quad=0.549496,\\ m=365&:\ \big(1+\tfrac{0.05}{365}\big)^{-4380}\\ &\quad=0.548834,\\ m\to\infty&:\ e^{-0.6}=0.548812,\\ \mathrm{EAR}_m&=\Big(1+\frac rm\Big)^m-1,\\ \mathrm{EAR}_{\infty}&=e^{r}-1,\\ e^{r_c}&=1.05,\\ r_c&=\ln 1.05=4.8790\%. \end{aligned} \]

คำตอบ: คูณ discount factor แต่ละแถวด้วย \$1,000,000 ได้มูลค่าวันนี้

  • รายปี \$556,837.42
  • ครึ่งปี \$552,875.35
  • รายไตรมาส \$550,856.49
  • รายเดือน \$549,496.18
  • รายวัน \$548,834.19
  • ต่อเนื่อง \$548,811.64

รายปีกับต่อเนื่องต่างกัน $556{,}837.42-548{,}811.64=\$8{,}025.78$ ทั้งที่ “อัตรา” เท่ากัน EAR บอกเหตุผล:

\[ \begin{aligned} \mathrm{EAR}_{12}&=\big(1+\tfrac{0.05}{12}\big)^{12}-1=5.1162\%,\\ \mathrm{EAR}_{\infty}&=e^{0.05}-1=5.1271\%. \end{aligned} \]

แบบรายเดือนและแบบต่อเนื่องให้ผลตอบแทนจริงเกิน 5% เพราะดอกเบี้ยไปงอกต่อระหว่างปี ถ้าอยากได้ผลเท่ากับ 5% รายปีพอดี ต้องใช้อัตราต่อเนื่อง $r_c=4.8790\%$ เพราะ $e^{r_c}=1.05$ ทำให้ $e^{-r_c k}=1.05^{-k}$ ทุกงวด $k$ ถ้าใช้ $r_c$ นี้คิดทาง B จึงได้ PV เท่าเดิม \$1,063,590.20 ทุกหลัก

ตรวจเองใน 10 วินาที: ทบต้นถี่ขึ้น เงินโตเร็วขึ้น มูลค่าวันนี้จึงต้องลดลงทุกแถว และแถว $m=365$ ต้องใกล้แถวต่อเนื่องมาก ทั้งสองข้อเป็นจริงในตาราง

ขั้นที่ 12 — ลองวนในคอมพิวเตอร์: เข้าใกล้ $e$ จากด้านล่าง แล้วพังเมื่อ $n$ ใหญ่เกิน

ขั้นที่ 10 บอกว่า $(1+1/n)^n$ เข้าใกล้ $e$ เมื่อ $n$ โต ลองให้คอมพิวเตอร์คิดดูจริง ๆ ว่าเข้าใกล้อย่างไร และเข้าใกล้จากฝั่งไหน ให้ $e_n=(1+1/n)^n$ คือยอดที่ \$1 โตไปถึงในหนึ่งปีที่ดอกเบี้ย 100% เมื่อทบต้น $n$ ครั้ง ลองใช้ $n$ ตามความถี่จริงก่อน:

  • $n=1, 2, 4$ คือรายปี ครึ่งปี และรายไตรมาส
  • $n=52$ คือรายสัปดาห์ และ $n=365$ คือรายวัน
  • $n=8{,}760$ คือรายชั่วโมง เพราะ $365\times24=8{,}760$
  • จากนั้นคูณสองไปเรื่อย ๆ 13 ครั้ง จนถึง $8{,}760\times2^{13}=71{,}761{,}920$

ทุกค่าที่ได้ต่ำกว่า $e$ เหตุผลพิสูจน์ได้ในไม่กี่บรรทัดด้วยฟังก์ชันช่วย $h(x)=x-\ln(1+x)$ จากนั้นลองให้ $n$ ใหญ่ขึ้นอีกมาก แล้วดูว่าคอมพิวเตอร์พังตรงไหน

\[ \begin{aligned} e_n&=\big(1+\tfrac1n\big)^n,\\ e_1&=2,\quad e_2=2.25,\\ e_4&=2.441406,\\ e_{52}&=2.692597,\\ e_{365}&=2.714567,\\ e_{8{,}760}&=2.718127,\\ e_{71{,}761{,}920}&=2.718282,\\ h(x)&=x-\ln(1+x),\\ h(0)&=0,\\ h'(x)&=1-\frac{1}{1+x}\\ &=\frac{x}{1+x}\gt 0,\\ \ln e_n&=n\ln\big(1+\tfrac1n\big)\\ &\lt n\cdot\tfrac1n=1,\\ e_{10^{12}}&=2.718523,\\ e_{10^{15}}&=3.035035,\\ e_{10^{16}}&=1. \end{aligned} \]

ทำไมทุกค่าต่ำกว่า $e$ ฟังก์ชัน $h$ เริ่มที่ศูนย์ และอนุพันธ์เป็นบวกตลอดเมื่อ $x\gt 0$ จึงเพิ่มขึ้นตลอด $h(x)$ จึงเป็นบวก แปลว่า $\ln(1+x)\lt x$ แทน $x=1/n$ แล้วคูณ $n$ ทั้งสองข้าง ได้ว่า $\ln e_n\lt 1$ ค่า $e_n$ จึงต่ำกว่า $e^1=e$ ทุก $n$ ที่ $n=1$ ได้แค่ 2 เพราะทบปีละครั้ง ไม่มีดอกเบี้ยของดอกเบี้ยระหว่างปีเลย

ค่าที่ต่ำกว่า $e$ นี้มีผลกับเงินแค่ไหน ลองคิดเงิน \$1 ที่ 5% หนึ่งปี:

\[ \begin{aligned} \big[e_1\big]^{0.05}&=2^{0.05}=1.035265,\\ e^{0.05}&=1.051271,\\ \big(1+\tfrac{0.05}{365}\big)^{365}&=1.051267,\\ 100(1.051271-1.051267)&=0.00036. \end{aligned} \]

ถ้าใช้ $e_1=2$ แทน $e$ จะได้ต่ำกว่าของจริงมาก แต่การทบรายวันตรง ๆ ต่างจากแบบต่อเนื่องแค่ \$0.00036 ต่อเงิน \$100 รายวันจึงใกล้ต่อเนื่องมากพอสำหรับงานจริง

สามค่าสุดท้ายผิด ทั้งที่สูตรถูก ต้นเหตุคือวิธีที่คอมพิวเตอร์เก็บตัวเลข ตัวเลขทศนิยมมาตรฐานเรียกว่า double เก็บเลขหลังจุดได้ 52 หลักในฐานสอง ตัวเลขที่ใกล้ 1 ที่สุดซึ่งเก็บได้จึงห่างจาก 1 อยู่ $2^{-52}=2.22\times10^{-16}$ ตัวเลขที่อยู่ระหว่างนั้นถูกปัดไปหาค่าที่เก็บได้ที่ใกล้ที่สุด:

\[ \begin{aligned} \frac{10^{-15}}{2^{-52}}&=4.504\to5,\\ 1+10^{-15}&\to1+5\times2^{-52}\\ &=1+1.110223\times10^{-15},\\ e_{10^{15}}&\approx e^{10^{15}\times1.110223\times10^{-15}}\\ &=e^{1.110223}=3.035,\\ 10^{-16}&\lt\tfrac12\times2^{-52}=1.11\times10^{-16},\\ 1+10^{-16}&\to1,\quad e_{10^{16}}=1^{n}=1. \end{aligned} \]

ที่ $n=10^{15}$ การปัดทำให้ดอกเบี้ยต่องวดใหญ่ขึ้นราว 11% ผลจึงพุ่งไป 3.035 ที่ $n=10^{16}$ ดอกเบี้ยต่องวดเล็กกว่าครึ่งช่องจึงถูกปัดทิ้งหมด เหลือ 1 ซึ่งยกกำลังอะไรก็เป็น 1

ค่าที่ $n=10^{12}$ ก็ผิดแล้ว แต่ผิดแบบเนียน ๆ เพราะ $10^{-12}/2^{-52}=4{,}503.6$ ถูกปัดเป็น 4,504 ช่อง ดอกเบี้ยต่องวดจึงใหญ่ไป $4{,}504/4{,}503.6-1=0.009\%$ ผลจึงเป็น $e^{1.000089}=2.718523$ ซึ่งเกิน $e$ ไปแล้ว ทั้งที่พิสูจน์ไว้ว่าต้องต่ำกว่า $e$ เสมอ ความต่างนี้เล็กเกินกว่าจะเห็นในรูปด้านล่าง บทเรียนคือ สูตรถูกไม่ได้แปลว่าตัวเลขที่คำนวณออกมาจะถูก

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

บวกเงินคนละวันตรง ๆ: เงินที่มาคนละปีมีค่าไม่เท่ากัน จึงบวกกันตรง ๆ ไม่ได้ ถ้าบวกตรง ๆ B ดูเหมือนมีค่า $12\times120{,}000=\$1{,}440{,}000$ แต่ที่ 5% มีค่าวันนี้จริงแค่ \$1,063,590.20 ส่วนต่าง $1{,}440{,}000-1{,}063{,}590.20=\$376{,}409.80$ คือราคาของการรอ

เลือกโครงการด้วย IRR เมื่อเงินสลับเข้าออกหลายครั้ง: ถ้าเงินออก เข้า แล้วออกอีก IRR อาจมีหลายค่า และบอกไม่ได้ว่าโครงการดีไหม ตัวอย่างสมมติ โครงการลงทุน \$100 วันนี้ ได้ \$230 ปีหน้า แต่ปีที่ 2 ต้องจ่ายอีก \$132 (เช่น ค่าปิดเหมืองและฟื้นฟูพื้นที่) ให้ $x=1/(1+r)$ แล้วหาอัตราที่ทำให้ NPV เป็นศูนย์:

\[ \begin{aligned} \text{NPV}&=-100+230x-132x^2=0,\\ x&=\frac{230\pm\sqrt{230^2-4(132)(100)}}{2(132)}\\ &=\frac{230\pm10}{264},\\ x=0.909091&:\ r=\tfrac1x-1=10\%,\\ x=0.833333&:\ r=\tfrac1x-1=20\%,\\ r=15\%&:\ -100+\tfrac{230}{1.15}-\tfrac{132}{1.15^2}=+0.19,\\ r=5\%&:\ -100+\tfrac{230}{1.05}-\tfrac{132}{1.05^2}=-0.68. \end{aligned} \]

IRR มีสองค่าคือ 10% และ 20% และ NPV เป็นบวกเฉพาะอัตราระหว่างสองค่านี้ ตัวเลข IRR ตัวเดียวจึงบอกไม่ได้ว่าโครงการคุ้มไหม ส่วนทาง C ซึ่งไม่มีเงินออกเลย ก็ไม่มี IRR ให้หาด้วยซ้ำ ทางที่ตรงกว่าคือคิด NPV ที่อัตราที่ใช้จริง

ลืมดูว่าจ่ายต้นงวดหรือปลายงวด: สูตรในหน้านี้ถือว่าจ่ายปลายงวด ถ้า B จ่ายต้นปีแทน เงินทุกงวดมาเร็วขึ้นหนึ่งปี จึงต้องคูณ PV ด้วย $1.05$:

\[ \begin{aligned} 1{,}063{,}590.20\times1.05&=1{,}116{,}769.71,\\ 1{,}116{,}769.71-1{,}063{,}590.20&=53{,}179.51,\\ 1{,}125{,}000-1{,}116{,}769.71&=8{,}230.29. \end{aligned} \]

มูลค่าเพิ่มขึ้น \$53,179.51 ซึ่งใหญ่พอจะเปลี่ยนการตัดสินใจได้ในหลายกรณี แม้ในกรณีนี้ที่ 5% B ก็ยังต่ำกว่า C อยู่ \$8,230.29

ใส่ $g\ge r$ ในสูตร perpetuity ที่โต: สูตร $c/(r-g)$ ใช้ได้เฉพาะเมื่อ $g\lt r$ ถ้า C โต 6% ต่อปีที่อัตรา 5% สูตรจะให้ $45{,}000/(0.05-0.06)=-\$4.5$ ล้าน ทั้งที่ผลบวกจริงเป็นอนันต์ ตัวเลขติดลบนี้ไม่มีความหมายเลย

พูด “5%” โดยไม่บอกความถี่ทบต้น: คำเดียวกันให้ราคาต่างกันได้หลายพันดอลลาร์ สำหรับเงิน \$1 ล้านในอีก 12 ปี 5% รายเดือนให้มูลค่าวันนี้ $10^6\times0.549496=\$549{,}496.18$ แต่ 5% รายปีให้ $10^6\times0.556837=\$556{,}837.42$ ต่างกัน $556{,}837.42-549{,}496.18=\$7{,}341.24$

ใช้ทำอะไรบนโต๊ะจริง

ราคาของพันธบัตร เงินกู้ และ swap (สัญญาที่สองฝ่ายตกลงแลกกระแสเงินกัน เช่น ฝ่ายหนึ่งจ่ายดอกเบี้ยคงที่ อีกฝ่ายจ่ายดอกเบี้ยลอยตัว) ล้วนคิดแบบพันธบัตรสองปีข้างบน คือเอาเงินแต่ละก้อนคูณ discount factor ของวันนั้นแล้วบวกกัน

ฝ่ายการเงินของบริษัทใช้ NPV ตัดสินว่าจะลงทุนโครงการไหม และมักทำกราฟแบบทาง A, B, C เพื่อบอกผู้บริหารว่าคำตอบพลิกที่อัตราไหน ทีมที่ซื้อขาย option ก็คิดลดเงินที่คาดว่าจะได้ในวันหมดอายุด้วย $e^{-rT}$ ส่วนสัญญาการเงินทุกฉบับต้องเขียนไว้ชัด ๆ ว่านับวันอย่างไรและทบต้นถี่แค่ไหน เพราะ “5%” คำเดียวแปลได้หลายค่า

แล้วควรใช้อัตราคิดลดเท่าไร คำตอบคือผลตอบแทนที่เงินก้อนเดียวกันหาได้จากทางเลือกอื่นที่ดีที่สุด ซึ่งเสี่ยงเท่ากัน ถ้าเงินที่จะได้แน่นอนเหมือนพันธบัตรรัฐบาล ก็ใช้อัตราของพันธบัตรรัฐบาลที่ครบกำหนดวันเดียวกัน อัตรานี้ต่างกันไปตามระยะเวลาที่รอ จึงต้องใช้ discount factor คนละค่าตามเส้น zero rate ถ้าผู้จ่ายอาจผิดนัดไม่จ่าย ต้องบวกส่วนชดเชยความเสี่ยงเข้าไปในอัตรา หรือคิดโอกาสผิดนัดตรง ๆ แบบพันธบัตรที่ผิดนัดได้

โจทย์ตรวจความเข้าใจ

1. คุณฝากเงิน \$2,000 ไว้กับธนาคาร 3 ปี ธนาคารประกาศดอกเบี้ย 6% ต่อปี แต่ทบต้นทุกเดือน ครบ 3 ปีจะได้เงินเท่าไร และผลตอบแทนจริงต่อปี (EAR) เป็นเท่าไร

เฉลย

ดอกเบี้ยต่อเดือนคือ 6% หารด้วย 12 และ 3 ปีมี 36 เดือน:

\[ \begin{aligned} r/m&=0.06/12=0.005,\\ mT&=12\times3=36,\\ FV&=2{,}000\times1.005^{36}=\$2{,}393.36,\\ \mathrm{EAR}&=1.005^{12}-1=6.1678\%. \end{aligned} \]

EAR สูงกว่า 6% ที่ประกาศ เพราะดอกเบี้ยของแต่ละเดือนไปงอกดอกเบี้ยต่อในเดือนถัด ๆ ไปของปีเดียวกัน

2. บริษัทหนึ่งแบ่งกำไรเป็นเงินสดให้ผู้ถือหุ้นทุกปี เงินนี้เรียกว่าปันผล คาดว่าปีหน้าจะจ่าย \$3 ต่อหุ้น แล้วโต 2% ต่อปีไปตลอด นักลงทุนต้องการผลตอบแทน 7% ต่อปีจากหุ้นที่เสี่ยงระดับนี้ (ใช้เป็นอัตราคิดลด) หุ้นนี้ควรมีค่าเท่าไร และถ้าผลตอบแทนที่ต้องการขึ้นเป็น 8% ล่ะ

เฉลย

ปันผลที่โตตลอดไปคือ perpetuity ที่โต ใช้สูตร $c/(r-g)$ จากขั้นที่ 7:

\[ \begin{aligned} r=7\%&:\ \frac{3}{0.07-0.02}=\$60,\\ r=8\%&:\ \frac{3}{0.08-0.02}=\$50,\\ 1-\frac{50}{60}&=16.7\%. \end{aligned} \]

อัตราขึ้นแค่ 1 จุด แต่ราคาหุ้นลดลง 16.7% เพราะมูลค่าส่วนใหญ่ของหุ้นแบบนี้อยู่ไกลเหมือนทาง C

3. บริษัทกำลังคิดว่าจะลงทุนโครงการหนึ่งไหม โครงการนี้ต้องจ่าย \$1,000 วันนี้ แล้วจะได้เงิน \$600 ปลายปีที่ 1 และอีก \$600 ปลายปีที่ 2 ถ้าใช้อัตราคิดลด 10% NPV เท่าไร IRR เท่าไร และถ้ามีคนเสนอซื้อสิทธิ์รับเงินสองก้อนนี้ที่ราคา \$1,100 ควรขายไหม

เฉลย

NPV คือ PV ของเงินเข้า ลบเงินที่จ่ายวันนี้:

\[ \begin{aligned} \text{NPV}&=-1{,}000+\frac{600}{1.1}+\frac{600}{1.1^2}\\ &=-1{,}000+545.45+495.87\\ &=\$41.32. \end{aligned} \]

NPV เป็นบวก โครงการจึงคุ้ม หา IRR โดยให้ $x=1/(1+r)$ แล้วตั้ง NPV เป็นศูนย์ หารทั้งสมการด้วย 600 ก่อนแก้:

\[ \begin{aligned} 600x^2+600x-1{,}000&=0,\\ x^2+x-\tfrac53&=0,\\ x&=\frac{-1+\sqrt{1+20/3}}{2}=0.884437,\\ r&=\frac1x-1=13.07\%. \end{aligned} \]

IRR 13.07% สูงกว่า 10% ตรงกับที่ NPV เป็นบวก (เลือกรากบวก เพราะ $x$ ต้องเป็นบวก) ส่วนข้อเสนอซื้อ สิทธิ์รับเงินสองก้อนมีค่าวันนี้ $545.45+495.87=\$1{,}041.32$ ที่อัตรา 10% ข้อเสนอ \$1,100 สูงกว่า จึงควรขาย ได้มากกว่าการถือไว้ $1{,}100-1{,}041.32=\$58.68$ ในมูลค่าวันนี้

const {pow, exp, log} = Math;

// Present value of flows[k] paid at the end of period k + 1, at rate r per period.
const pv = (flows, r) => flows.reduce((s, c, k) => s + c / pow(1 + r, k + 1), 0);
// Level annuity and growing perpetuity (first payment after one period).
const annuity = (c, r, n) => r === 0 ? c * n : c * (1 - pow(1 + r, -n)) / r;
const growing = (c, r, g) => {
  if (!(g < r)) throw new RangeError('g must be below r');
  return c / (r - g);
};
// Discount factor for T years at annual rate r, m times a year (Infinity = continuous).
const discount = (r, T, m) => m === Infinity ? exp(-r * T) : pow(1 + r / m, -m * T);
// Root of f on [lo, hi] by bisection; f must change sign.
function bisect(f, lo, hi) {
  let flo = f(lo);
  for (let k = 0; k < 200; k++) {
    const mid = (lo + hi) / 2, fm = f(mid);
    if (flo * fm <= 0) hi = mid; else { lo = mid; flo = fm; }
  }
  return (lo + hi) / 2;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ย้ายเงินในวันที่ $T$ มาวันนี้ด้วย $D(0,T)=(1+r)^{-T}$ ซึ่งก็คือราคาของ zero-coupon bond และเงินหลายก้อนต้องย้ายมาวันนี้ทีละก้อนก่อนบวก
  • อธิบายได้ว่าทำไมราคาต้องเท่ากับ PV: พันธบัตรที่มีค่า \$98.14 ถ้ามีคนขายที่ \$97 เราซื้อแล้วกู้เงินสองก้อนที่คูปองใช้คืนได้พอดี จะได้ $98.14-97=\$1.14$ ฟรี และถ้าอัตรากู้กับอัตราฝากต่างกัน ราคาที่ไม่มีเงินฟรีจะกลายเป็นช่วง
  • สร้างสูตร annuity, perpetuity และ perpetuity ที่โตได้จากอนุกรมเรขาคณิต และบอกได้ว่าทำไมต้องมี $g\lt r$
  • ที่ 5% ทาง C ชนะด้วยมูลค่า \$1,125,000 ที่ 8% ทาง A ชนะ อันดับพลิกที่ 5.30%, 5.50% และ 6.11% และเงินที่มาช้าไวต่ออัตรามากกว่า (C เสีย 42.9% ขณะที่ B เสีย 15.0%)
  • “5%” ต้องมาพร้อมความถี่ทบต้น สำหรับเงิน \$1 ล้านในอีก 12 ปี รายปีกับต่อเนื่องให้มูลค่าวันนี้ต่างกัน \$8,025.78 และ $e^{-rT}$ มาจากการซอยงวดทบต้นจนต่อเนื่อง
