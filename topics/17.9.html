17.9 The Black-Litterman Model

Black–Litterman ไม่ประมาณค่าเฉลี่ยจากอดีต แต่ย้อนหาค่าเฉลี่ยที่ทำให้พอร์ตอ้างอิงเป็นคำตอบที่ดีที่สุด แล้วผสมมุมมองของเราเข้าไปตามความมั่นใจ น้ำหนักจึงเบนจากพอร์ตอ้างอิงเฉพาะในทิศของมุมมอง

กองทุน \$10 ล้านถือหุ้น 60% พันธบัตร 40% ทีมวิจัยบอกว่า “หุ้นจะชนะพันธบัตร 3 จุดเปอร์เซ็นต์ต่อปี” แต่ไม่มั่นใจเต็มร้อย ผู้จัดการคนหนึ่งจะเพิ่มหุ้นทันที เพราะมุมมองบอกว่าหุ้นดีกว่า ควรเพิ่มหรือลดหุ้น และเท่าไร?

ลองตอบก่อนเปิดเฉลย

ควรลด ภายใต้ความเสี่ยงและความมั่นใจที่หน้านี้กำหนด หุ้นลดเหลือ 51.43% ย้าย \$857,143 ไปพันธบัตร เพราะพอร์ต 60/40 เองบอกเป็นนัยว่าหุ้นชนะพันธบัตร 4.8 จุด มุมมอง 3 จุดจึงเป็นข่าวร้ายสำหรับหุ้น ไม่ใช่ข่าวดี เมื่อให้ความเชื่อสองฝั่งเท่ากัน ส่วนต่างหลังผสมคือ 3.9 จุด

ภาพรวมก่อนลงสูตร

หน้า Ledoit–Wolf shrinkage แสดงว่าค่าเฉลี่ยคือตัวเลขที่ประมาณได้แย่ที่สุด และ optimizer ไวต่อมันที่สุด Fischer Black กับ Robert Litterman จึงกลับด้านคำถาม: แทนที่จะประมาณค่าเฉลี่ยจากอดีต ให้เริ่มจากพอร์ตที่ถืออยู่แล้ว (เช่นพอร์ตตลาดหรือ benchmark) แล้วถามว่าค่าเฉลี่ยแบบไหนทำให้พอร์ตนี้ดีที่สุดพอดี ค่าเฉลี่ยชุดนั้นคือจุดตั้งต้น เรียกว่า prior จากนั้นใส่เฉพาะเรื่องที่เรามีความเห็น เรียกว่า view พร้อมบอกว่ามั่นใจแค่ไหน แล้วผสมสองอย่างตามกฎของ Bayes ได้ posterior

รูปด้านล่างคือทั้งเรื่องในภาพเดียว ตัวเลขที่สนใจคือส่วนต่างผลตอบแทนหุ้นลบพันธบัตร prior บอก 4.8 จุด view บอก 3.0 จุด สองฝั่งไม่แน่นอนเท่ากัน (กว้างเท่ากัน) posterior จึงอยู่กึ่งกลางที่ 3.9 จุด และแคบกว่าทั้งสองฝั่ง เพราะมีข้อมูลสองแหล่งช่วยกัน

หน้านี้จะย้อนหาค่าเฉลี่ยจากน้ำหนัก 60/40 ดูว่ามันคือ CAPM เขียนมุมมองเป็นสมการพร้อมความไม่แน่นอน ผสมด้วยสูตรค่าเฉลี่ยแบบมีเงื่อนไขของ Normal หลายตัวแปร แปลงเป็นน้ำหนัก แล้วดูปุ่มความมั่นใจ กับดักของการนับมุมมองเดียวกันสองครั้ง และความไม่แน่นอนที่ยังเหลือ

ขั้นที่ 1 — ย้อนจากน้ำหนักไปหาค่าเฉลี่ย

หุ้นมีความผันผวน 20% พันธบัตร 10% correlation 0.2 (covariance $0.2\times0.2\times0.1=0.004$) ทุกผลตอบแทนเป็นส่วนเกินเงินสด นักลงทุนแบบ Markowitz เลือก $w$ ให้ $U(w)$ ข้างล่างสูงสุด ปกติเรารู้ค่าเฉลี่ยแล้วหาน้ำหนัก ครั้งนี้กลับด้าน: รู้น้ำหนัก 60/40 แล้วหาค่าเฉลี่ยที่ทำให้มันเป็นจุดสูงสุดพอดี

\[ \begin{aligned} U(w)&=w^{\mathsf T}\Pi-\frac{\delta}{2}w^{\mathsf T}\Sigma w,\\ \nabla U&=\Pi-\delta\Sigma w=0,\\ \Pi&=\delta\Sigma w_m,\\ (\Sigma w_m)_1&=0.04(0.6)+0.004(0.4)\\ &=0.0256,\\ (\Sigma w_m)_2&=0.004(0.6)+0.01(0.4)\\ &=0.0064,\\ \Pi&=2.5\begin{bmatrix}0.0256\\0.0064\end{bmatrix}=\begin{bmatrix}0.064\\0.016\end{bmatrix}. \end{aligned} \]

บรรทัดที่สองคือเงื่อนไขอันดับหนึ่ง (gradient เป็นศูนย์ที่จุดสูงสุด) ปกติเราแก้หา $w$ แต่ถ้ากำหนดให้ $w_m$ เป็นคำตอบ สมการเดียวกันก็แก้หา $\Pi$ ได้ทันที ไม่ต้อง invert อะไรเลย ได้ผลตอบแทนส่วนเกินหุ้น 6.4% พันธบัตร 1.6% ต่อปี ส่วนต่าง 4.8 จุด

ตัวเลขนี้ขึ้นกับ $\Sigma$ และ $\delta$ ที่เลือก ไม่ใช่สิ่งที่ราคาตลาดบอกเองลำพัง ถ้าเปลี่ยน $\delta$ ค่าเฉลี่ยทั้งชุดเปลี่ยนตามสัดส่วน ขั้นถัดไปจะดูว่า $\delta$ ควรเป็นเท่าไร และ $\Pi$ มีความหมายทางเศรษฐศาสตร์อย่างไร

ขั้นที่ 2 — ค่าเฉลี่ยที่ย้อนได้คือ CAPM

ถ้าทุกคนในตลาดลงทุนแบบ mean-variance และเชื่อตัวเลขชุดเดียวกัน ทุกคนจะถือพอร์ต tangency เดียวกันผสมกับเงินสด เมื่อรวมทุกคน พอร์ตที่ถือรวมกันก็คือพอร์ตตลาด พอร์ตตลาดจึงเป็นพอร์ต tangency และค่าเฉลี่ยที่ทำให้มันดีที่สุดคือสิ่งที่ CAPM ทำนาย คูณ $w_m^{\mathsf T}$ เข้ากับ $\Pi=\delta\Sigma w_m$ เพื่อหา $\delta$ แล้วแทนกลับ

\[ \begin{aligned} w_m^{\mathsf T}\Pi&=\delta\,w_m^{\mathsf T}\Sigma w_m,\\ \delta&=\frac{\mu_m}{\sigma_m^2}=\frac{0.0448}{0.01792}=2.5,\\ \Pi_i&=\frac{(\Sigma w_m)_i}{\sigma_m^2}\,\mu_m=\beta_i\,\mu_m,\\ \beta&=\frac{0.0256}{0.01792},\ \frac{0.0064}{0.01792}\\ &\approx1.429,\ 0.357,\\ \Pi&\approx1.429(4.48\%),\ 0.357(4.48\%)\\ &=6.4\%,\ 1.6\%. \end{aligned} \]

$w_m^{\mathsf T}\Pi$ คือผลตอบแทนส่วนเกินของพอร์ตอ้างอิง $\mu_m=0.6(6.4\%)+0.4(1.6\%)=4.48\%$ และ $w_m^{\mathsf T}\Sigma w_m$ คือ variance ของมัน 0.01792 (ความผันผวน 13.39%) ดังนั้น $\delta$ คือ “ผลตอบแทนส่วนเกินต่อหนึ่งหน่วย variance ของตลาด” เท่ากับ Sharpe ของตลาด (0.335) หารด้วยความผันผวนของตลาด ในงานจริงจึงเลือก $\delta$ จากความเชื่อเรื่อง Sharpe ของตลาด ไม่ได้เลือกลอย ๆ

บรรทัดที่สามคือ CAPM: $(\Sigma w_m)_i$ คือ covariance ของสินทรัพย์ $i$ กับพอร์ตอ้างอิง หารด้วย variance ของพอร์ตอ้างอิงคือ beta ของมัน ผลตอบแทนส่วนเกินที่ย้อนได้จึงเท่ากับ beta คูณผลตอบแทนส่วนเกินของตลาด หุ้นได้ 6.4% เพราะ beta 1.43 ไม่ใช่เพราะใครเดาว่าหุ้นดี prior ของ Black–Litterman จึงมีเหตุผลรองรับ: มันคือค่าเฉลี่ยที่ตลาดในภาวะสมดุลต้องการ

ขั้นที่ 3 — เขียนมุมมองและความไม่แน่นอนของสองฝั่ง

มุมมอง “หุ้นชนะพันธบัตร 3 จุด” พูดถึงส่วนต่าง จึงเขียนด้วยแถว $P=[1,\ -1]$ และ $q=0.03$ ก่อนผสม ต้องบอกว่าเชื่อแต่ละฝั่งแค่ไหน แบบจำลองนิยามว่า prior บอกค่าเฉลี่ยจริงอยู่รอบ $\Pi$ ด้วยความไม่แน่นอน $\tau\Sigma$ (ใช้ $\tau=0.05$) และมุมมองมีความคลาด $\epsilon$ ที่มี variance $\Omega$

\[ \begin{aligned} \mu&\sim N(\Pi,\ \tau\Sigma),\\ q&=P\mu+\epsilon,\quad\epsilon\sim N(0,\ \Omega),\\ \tau\Sigma&=\begin{bmatrix}0.0020&0.0002\\0.0002&0.0005\end{bmatrix},\\ \tau\Sigma P^{\mathsf T}&=\begin{bmatrix}0.0018\\-0.0003\end{bmatrix},\\ P\tau\Sigma P^{\mathsf T}&=0.0018+0.0003=0.0021,\\ \Omega&=0.0021,\\ P\Pi&=0.064-0.016=0.048,\\ q-P\Pi&=-0.018. \end{aligned} \]

คูณด้วย $P^{\mathsf T}=(1,-1)$ คือเอาคอลัมน์แรกลบคอลัมน์ที่สอง $P\tau\Sigma P^{\mathsf T}=0.0021$ คือ variance ของส่วนต่างตาม prior (standard deviation 4.6 จุด) ในตัวอย่างนี้ตั้ง $\Omega$ เท่ากันพอดี คือเชื่อมุมมองเท่ากับเชื่อ prior ตัวเลขนี้ไม่ใช่โอกาสที่ทีมวิจัยจะทายถูก แต่เป็นความกว้างของความคลาดที่ยอมรับ

บรรทัดสุดท้ายคือหัวใจของคำตอบในโจทย์: prior บอก 4.8 จุด มุมมองบอก 3 จุด มุมมองจึงต่ำกว่าจุดตั้งต้น 1.8 จุด แม้จะยังบอกว่าหุ้นดีกว่าพันธบัตรก็ตาม สิ่งที่ขยับพอร์ตคือความประหลาดใจ ไม่ใช่เครื่องหมายของมุมมอง

ขั้นที่ 4 — ผสมด้วยค่าเฉลี่ยแบบมีเงื่อนไขของ Normal

ถ้า $\mu$ กับ $q$ เป็น Normal ร่วมกัน ค่าเฉลี่ยของ $\mu$ เมื่อรู้ $q$ คือสูตรเดียวกับ hedge ratio ของ Normal หลายตัวแปร: ค่าเฉลี่ยเดิม บวก covariance คูณ inverse ของ variance คูณความประหลาดใจ ต้องหาสามก้อนก่อน โดยใช้ว่า $\epsilon$ อิสระจาก $\mu$

\[ \begin{aligned} \mathbb E[q]&=P\Pi,\\ \operatorname{Cov}(\mu,q)&=\operatorname{Cov}(\mu,P\mu)=\tau\Sigma P^{\mathsf T},\\ \operatorname{Var}(q)&=P\tau\Sigma P^{\mathsf T}+\Omega,\\ \mu_{\text{post}}&=\Pi+\tau\Sigma P^{\mathsf T}\\ &\quad\times\big(P\tau\Sigma P^{\mathsf T}+\Omega\big)^{-1}\\ &\quad\times(q-P\Pi). \end{aligned} \]

อ่านจากขวาไปซ้าย: $(q-P\Pi)$ คือความประหลาดใจ ถ้ามุมมองตรงกับ prior ก้อนนี้เป็นศูนย์และไม่มีอะไรขยับ ก้อนกลางคือการชั่งความเชื่อ ถ้า $\Omega$ ใหญ่มาก ก้อนนี้เข้าหาศูนย์และคำตอบกลับไปที่ $\Pi$ ก้อนซ้ายแปลงผลกลับเป็นภาษาของสินทรัพย์ทุกตัว ผ่าน covariance ที่เชื่อมมันกับมุมมอง

เมื่อมองเฉพาะส่วนต่าง สูตรนี้ยุบเป็นค่าเฉลี่ยถ่วงด้วยความแม่น (ส่วนกลับของ variance) แบบ Bayes ของ Normal: $\frac{4.8/0.0021+3.0/0.0021}{1/0.0021+1/0.0021}=3.9$ และ variance หลังผสมคือ $1/(1/0.0021+1/0.0021)=0.00105$ ตรงกับเส้นเขียวในรูปแรก matrix ที่ต้องกลับมีขนาดเท่าจำนวนมุมมอง ไม่ใช่จำนวนสินทรัพย์ มุมมองมักมีไม่กี่ข้อ สูตรนี้จึงใช้ได้กับพอร์ตหลายร้อยตัว

ขั้นที่ 5 — ค่าเฉลี่ยหลังผสม

โจทย์ให้อะไรมาบ้าง: ก้อนต่าง ๆ ที่หาไว้ตอนเขียนมุมมอง แทนลงในสูตรค่าเฉลี่ยแบบมีเงื่อนไข ตัว inverse เป็นตัวเลขเดียว $1/0.0042$ เพราะมีมุมมองข้อเดียว

\[ \begin{aligned} h&=\frac{q-P\Pi}{P\tau\Sigma P^{\mathsf T}+\Omega}=\frac{-0.018}{0.0042}\\ &\approx-4.285714,\\ \mu_{\text{post},1}&=0.064+0.0018h\\ &\approx0.064-0.007714=0.056286,\\ \mu_{\text{post},2}&=0.016-0.0003h\\ &\approx0.016+0.001286=0.017286,\\ \text{gap}&=4.8+(3.0-4.8)\frac{0.0021}{0.0042}=3.9. \end{aligned} \]

คำตอบ: หุ้น 5.6286% พันธบัตร 1.7286% ส่วนต่าง 3.9 จุด ทั้งสองตัวขยับทั้งที่มุมมองพูดถึงแค่ส่วนต่าง เพราะ covariance เชื่อมสองตัวเข้าด้วยกัน หุ้นซึ่งแกว่งมากกว่าและมีความไม่แน่นอนของค่าเฉลี่ยมากกว่ารับการปรับส่วนใหญ่ (−0.77 จุด เทียบกับพันธบัตร +0.13 จุด)

บรรทัดสุดท้ายคือน้ำหนักของมุมมอง: $0.0021/0.0042=0.5$ ถ้า $\Omega$ ใหญ่กว่านี้สิบเท่า น้ำหนักเหลือ $0.0021/0.0231=1/11\approx0.09$ และส่วนต่างขยับแค่ 0.16 จุด

ตรวจเองใน 10 วินาที: $0.056286-0.017286=0.039$ และ $4.8-0.9=3.9$

ขั้นที่ 6 — จากค่าเฉลี่ยเป็นน้ำหนัก: พอร์ตอ้างอิงบวก tilt

แปลงค่าเฉลี่ยกลับเป็นน้ำหนักด้วยเงื่อนไขอันดับหนึ่งเดิม $w^*=\Sigma^{-1}\mu_{\text{post}}/\delta$ กลับ $\Sigma$ ด้วยสูตร 2×2 ($\det\Sigma=0.0004-0.000016=0.000384$) แล้วดูว่าน้ำหนักแยกเป็นสองส่วนอย่างไร

\[ \begin{aligned} \Sigma^{-1}&\approx\begin{bmatrix}26.0417&-10.4167\\-10.4167&104.1667\end{bmatrix},\\ 2.5\,w_1^*&=26.0417(0.056286)\\ &\quad-10.4167(0.017286)\\ &\approx1.2857,\quad w_1^*\approx0.5143,\\ w^*&=\frac1\delta\Sigma^{-1}\big(\Pi+\tau\Sigma P^{\mathsf T}h\big)\\ &=w_m+\frac\tau\delta P^{\mathsf T}h,\\ \frac\tau\delta h&=0.02(-4.285714)\approx-0.085714,\\ w^*&\approx\begin{bmatrix}0.6-0.085714\\0.4+0.085714\end{bmatrix}=\begin{bmatrix}0.514286\\0.485714\end{bmatrix}. \end{aligned} \]

จังหวะสำคัญอยู่ที่บรรทัดที่สี่: $\Sigma^{-1}\Pi/\delta=w_m$ เพราะนั่นคือวิธีที่เราสร้าง $\Pi$ และ $\Sigma^{-1}\tau\Sigma=\tau I$ ตัดกันเหลือแค่ $P^{\mathsf T}$ น้ำหนักสุดท้ายจึงเป็นพอร์ตอ้างอิงบวก tilt ในทิศของมุมมองเท่านั้น ไม่มีทิศที่สามให้ optimizer เอาไปขยายความคลาดแบบที่เห็นในหน้า shrinkage

มุมมองเป็นส่วนต่าง $P^{\mathsf T}=(1,-1)$ tilt จึงรวมเป็นศูนย์ ทุนยังเต็ม 100% หุ้นเหลือ \$5,142,857 พันธบัตร \$4,857,143 ย้าย \$857,143 ตรวจด้วยเศษส่วน: $w_1^*=18/35$

ขั้นที่ 7 — ปุ่มความมั่นใจ

ตัวเลขที่ยากที่สุดในทางปฏิบัติคือ $\Omega$ ลองตั้ง $\Omega=k\,P\tau\Sigma P^{\mathsf T}$ ($k=1$ คือเชื่อมุมมองเท่ากับ prior) แล้วดูว่าน้ำหนักหุ้นเปลี่ยนตาม $k$ อย่างไร แทนลงในสูตรน้ำหนักของขั้นก่อน ตัวส่วนกลายเป็น $0.0021+k(0.0021)=0.0021(1+k)$

\[ \begin{aligned} w_1^*(k)&=0.6+0.02\,\frac{-0.018}{0.0021(1+k)}\\ &=0.6-\frac{0.171429}{1+k},\\ k=0.1&:\ 44.42\%,\\ k=1&:\ 51.43\%,\\ k=3&:\ 55.71\%,\\ k=10&:\ 58.44\%,\\ k=100&:\ 59.83\%. \end{aligned} \]

ไม่มั่นใจ ($k$ ใหญ่) น้ำหนักกลับหา 60% เอง มั่นใจมาก ($k$ เข้าหาศูนย์) น้ำหนักเข้าหา $0.6-0.171429=42.86\%$ ของแท่งกลางในรูปน้ำหนัก พฤติกรรมนี้คือสิ่งที่ต้องการ: พอร์ตเบนจากจุดอ้างอิงเท่าที่ความมั่นใจรองรับ แต่ก็แปลว่าผลลัพธ์ไวต่อตัวเลขที่คนใส่เอง ซึ่งคนมักประเมินความมั่นใจของตัวเองสูงเกิน

สังเกตว่าเมื่อผูก $\Omega$ กับ $P\tau\Sigma P^{\mathsf T}$ แบบนี้ $\tau$ ตัดกันในสูตรน้ำหนัก เหลือแค่อัตราส่วน $k$ ที่สำคัญ การถกเถียงว่า $\tau$ ควรเป็น 0.025 หรือ 0.05 จึงไม่เปลี่ยนน้ำหนัก ถ้าตั้งความมั่นใจของมุมมองเทียบกับ prior

ขั้นที่ 8 — มุมมองเดียวกันสองครั้งไม่ใช่หลักฐานสองชิ้น

สมมติสองทีมส่งมุมมองเดียวกัน “หุ้นชนะพันธบัตร 3 จุด” แต่ทั้งสองทีมอ่านรายงานชุดเดียวกัน ถ้าใส่เป็นสองบรรทัดโดยให้ความคลาดอิสระกัน สูตรจะนับเป็นหลักฐานสองชิ้น ลองเทียบกับกรณีที่ความคลาดของสองบรรทัดมี correlation $\rho=0.9$ ใช้ $P$ สองแถวเหมือนกันและ $\Omega$ ขนาด 2×2

\[ \begin{aligned} \Omega_\rho&=0.0021\begin{bmatrix}1&\rho\\\rho&1\end{bmatrix},\\ \text{shift}&=1.8\times\frac{2}{3+\rho},\\ \rho=0&:\ 4.8-1.8\Big(\frac23\Big)=3.60,\\ \rho=0.9&:\ 4.8-1.8\Big(\frac{2}{3.9}\Big)\approx3.88. \end{aligned} \]

ที่มาของ $2/(3+\rho)$: ก้อนกลางของสูตรผสมเป็น $0.0021\begin{bmatrix}2&1+\rho\\1+\rho&2\end{bmatrix}$ เพราะทุกช่องได้ $P\tau\Sigma P^{\mathsf T}=0.0021$ จาก prior บวกช่องของ $\Omega_\rho$ ความประหลาดใจเป็น $-0.018$ ทั้งสองแถว ผลรวมของตัวคูณสองตัวจึงเป็น $2(-0.018)/(0.0021(3+\rho))$ คูณกลับด้วย 0.0021 ได้ส่วนต่างขยับ $1.8\times2/(3+\rho)$ จุด

ความคลาดอิสระขยับ 1.2 จุด เหมือนมุมมองที่มั่นใจขึ้นเท่าตัว ความคลาดที่ correlation 0.9 ขยับ 0.92 จุด ใกล้กับมุมมองข้อเดียว (0.9 จุด) ช่องนอกแนวทแยงของ $\Omega$ จึงเป็นข้อมูลทางเศรษฐกิจว่ามุมมองมาจากแหล่งเดียวกันไหม ไม่ใช่รายละเอียดตกแต่ง

ขั้นที่ 9 — ความไม่แน่นอนที่เหลือในค่าเฉลี่ย

นอกจากค่าเฉลี่ย สูตรเดียวกันของ Normal หลายตัวแปรให้ variance แบบมีเงื่อนไขด้วย: variance เดิมลบส่วนที่มุมมองอธิบายได้ ใช้ดูว่ามุมมองลดความไม่รู้ไปแค่ไหน

\[ \begin{aligned} M&=\tau\Sigma-\frac{(\tau\Sigma P^{\mathsf T})(P\tau\Sigma)}{0.0042},\\ M_{11}&=0.0020-0.000771=0.001229,\\ M_{12}&=0.0002+0.000129=0.000329,\\ M_{22}&=0.0005-0.000021=0.000479. \end{aligned} \]

ส่วนที่ลบคือ $(0.0018,\ -0.0003)$ คูณตัวเอง หารด้วย 0.0042 แนวทแยงลดลง (หุ้นจาก 0.0020 เป็น 0.001229) เพราะมุมมองให้ข้อมูลเพิ่ม covariance นอกแนวทแยงเพิ่มขึ้น เพราะข้อมูลเกี่ยวกับส่วนต่างผูกค่าเฉลี่ยสองตัวเข้าด้วยกัน: ถ้ารู้ว่าหุ้นสูงกว่าที่คิด พันธบัตรก็น่าจะสูงกว่าที่คิดด้วย

ถ้าให้ผลตอบแทนปีหน้าเท่ากับค่าเฉลี่ยที่ยังไม่รู้บวกช็อกที่มี covariance $\Sigma$ ความไม่แน่นอนรวมของผลตอบแทนจะเป็น $\Sigma+M$ การคำนวณน้ำหนักในหน้านี้ใช้ $\Sigma$ เดิมตามสูตรดั้งเดิม บางสูตรใช้ $\Sigma+M$ ซึ่งให้น้ำหนักเล็กลงเล็กน้อย ต้องบอกว่าใช้แบบไหน

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

เทียบมุมมองกับศูนย์: “หุ้นดีกว่า 3 จุด” ยังต่ำกว่าจุดตั้งต้น 4.8 จุด จึงลดหุ้น ต้องเทียบกับ $P\Pi$ ไม่ใช่ดูว่ามุมมองเป็นบวกหรือไม่

นับมุมมองซ้ำ: สองทีมที่ใช้ข้อมูลเดียวกันใส่เป็นสองบรรทัดอิสระ ส่วนต่างขยับ 1.2 จุดแทน 0.9 เหมือนมั่นใจขึ้นเท่าตัวโดยไม่มีหลักฐานใหม่

เชื่อ $\Omega$ ที่ใส่เอง: ความมั่นใจเป็นตัวเลขที่เดาทั้งหมด และน้ำหนักหุ้นขยับได้ตั้งแต่ 42.86% ถึง 60% ตามมัน ต้องลองหลายค่าแล้วรายงานช่วง

สลับบทบาทของ covariance: $\Sigma$ คือการแกว่งของผลตอบแทนรอบค่าเฉลี่ย $\tau\Sigma$ และ $M$ คือความไม่แน่นอนของค่าเฉลี่ยก่อนและหลังรับมุมมอง และ $\Omega$ คือความคลาดของมุมมอง ใส่ผิดช่องแล้วน้ำหนักผิดโดยไม่มี error เตือน

ลืมว่า prior ขึ้นกับ $\delta$ และ $\Sigma$: ใช้ $\delta=3$ แทน 2.5 ค่าเฉลี่ยทั้งชุดขยาย 20% (หุ้น 7.68% พันธบัตร 1.92% ส่วนต่าง 5.76 จุด) มุมมอง 3 จุดเดิมจึงกลายเป็นข่าวร้ายที่หนักขึ้น

ใช้ทำอะไรบนโต๊ะจริง

ผู้จัดการกองทุนหลายสินทรัพย์ใช้ Black–Litterman แปลงมุมมองของทีมวิจัยเป็นน้ำหนัก โดยเริ่มจาก benchmark ของกองทุน คณะกรรมการลงทุนอ่านได้ทีละบรรทัดว่าพอร์ตเบนจาก benchmark เพราะมุมมองข้อไหน ด้วยความมั่นใจเท่าไร และเมื่อไม่มีมุมมองเลย พอร์ตก็กลับไปที่ benchmark เอง ซึ่งเป็นจุดที่ optimizer แบบเดิมทำไม่ได้ ในมุมของshrinkage นี่คือการดึงค่าเฉลี่ยเข้าหาเป้าหมายที่มาจากตลาดแทนที่จะเป็นค่าเฉลี่ยรวม น้ำหนักที่ได้ยังต้องผ่านเพดาน turnover และต้นทุนการซื้อขายก่อนกลายเป็นคำสั่งจริง

เฉลย

ความประหลาดใจ $q-P\Pi=0.06-0.048=0.012$ ตัวคูณ $h=0.012/0.0042\approx2.857$ ส่วนต่าง $4.8+1.2(0.5)=5.4$ จุด น้ำหนักหุ้น $0.6+0.02(2.857)\approx65.71\%$ มุมมองที่สูงกว่าจุดตั้งต้นจึงเพิ่มหุ้น

2. มุมมอง 3 จุดเดิม แต่ความไม่มั่นใจเป็นสามเท่าของ prior ($k=3$) ได้อะไร?

เฉลย

น้ำหนักของมุมมอง $1/(1+3)=0.25$ ส่วนต่าง $4.8-1.8(0.25)=4.35$ จุด น้ำหนักหุ้น $0.6-0.171429/4\approx55.71\%$

3. มุมมองแบบค่าเดียว: พันธบัตรได้ส่วนเกิน 2.5% ด้วย $\Omega=\tau\Sigma_{22}=0.0005$ หาค่าเฉลี่ยหลังผสมและน้ำหนัก

เฉลย

$P=[0,1]$ ได้ $P\tau\Sigma P^{\mathsf T}=0.0005$ ความประหลาดใจ $0.025-0.016=0.009$ ตัวคูณ $h=0.009/(0.0005+0.0005)=9$ และ $\tau\Sigma P^{\mathsf T}=(0.0002,\ 0.0005)$ ค่าเฉลี่ยใหม่ $(0.064+0.0018,\ 0.016+0.0045)=(0.0658,\ 0.0205)$ น้ำหนัก $w_m+0.02(9)(0,1)=(0.60,\ 0.58)$ รวม 118% คือกู้เงินสดมา 18% เพราะมุมมองค่าเดียวไม่ใช่ส่วนต่าง tilt จึงไม่หักล้างกัน

const dot = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0);
const times = (M, v) => M.map(r => dot(r, v));
const T = M => M[0].map((_, j) => M.map(r => r[j]));
const mm = (A, B) => A.map(r => T(B).map(c => dot(r, c)));
function solve(S, b) {                                    // Gaussian elimination with partial pivoting
  const n = S.length, M = S.map((r, i) => [...r, b[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (Math.abs(M[r][c]) > Math.abs(M[p][c])) p = r;
    [M[c], M[p]] = [M[p], M[c]];
    for (let r = c + 1; r < n; r++) { const f = M[r][c] / M[c][c]; for (let k = c; k <= n; k++) M[r][k] -= f * M[c][k]; }
  }
  const x = new Array(n).fill(0);
  for (let r = n - 1; r >= 0; r--) { let s = M[r][n]; for (let k = r + 1; k < n; k++) s -= M[r][k] * x[k]; x[r] = s / M[r][r]; }
  return x;
}
// Black-Litterman: prior mu ~ N(Pi, tau Sigma) with Pi = delta Sigma w_m; views q = P mu + e, e ~ N(0, Omega).
function blackLitterman({Sigma, wm, delta, tau, P, q, Omega}) {
  const Pi = times(Sigma, wm).map(x => delta * x);
  const A = Sigma.map(r => r.map(x => tau * x));                       // uncertainty of the mean
  const AP = mm(A, T(P));                                              // tau Sigma P'
  const inner = mm(P, AP).map((r, i) => r.map((x, j) => x + Omega[i][j]));   // P tau Sigma P' + Omega
  const h = solve(inner, q.map((v, i) => v - dot(P[i], Pi)));          // (inner)^-1 (q - P Pi)
  const post = Pi.map((v, i) => v + dot(AP[i], h));
  const w = solve(Sigma.map(r => r.map(x => delta * x)), post);        // w = Sigma^-1 post / delta
  const cols = T(mm(P, A)).map(c => solve(inner, c));                  // M = A - A P' (inner)^-1 P A
  const M = A.map((r, i) => r.map((x, j) => x - dot(AP[i], cols[j])));
  return {Pi, h, post, w, M};
}

const Sigma = [[0.04, 0.004], [0.004, 0.01]], wm = [0.6, 0.4], delta = 2.5, tau = 0.05;
const P = [[1, -1]], v = tau * (Sigma[0][0] - 2 * Sigma[0][1] + Sigma[1][1]);       // P tau Sigma P' = 0.0021
const base = blackLitterman({Sigma, wm, delta, tau, P, q: [0.03], Omega: [[v]]});
const stock = k => blackLitterman({Sigma, wm, delta, tau, P, q: [0.03], Omega: [[k * v]]}).w[0];
const twice = rho => { const r = blackLitterman({Sigma, wm, delta, tau, P: [[1, -1], [1, -1]], q: [0.03, 0.03], Omega: [[v, rho * v], [rho * v, v]]}); return r.post[0] - r.post[1]; };
const mVar = dot(wm, times(Sigma, wm)), mEx = dot(wm, base.Pi);
console.log({

  h: base.h[0], post: base.post, gap: base.post[0] - base.post[1],                    // -4.2857, [0.0563, 0.0173], 0.039
  w: base.w, dollars: base.w.map(x => x * 1e7), M: base.M,                            // [0.5143, 0.4857]
  exactView: stock(1e-12), dial: [0.1, 1, 3, 10, 100].map(stock),                     // 0.4286; 0.4442 ... 0.5983
  twiceIndependent: twice(0), twiceCorrelated: twice(0.9),                            // 0.036, 0.0388
  bull: blackLitterman({Sigma, wm, delta, tau, P, q: [0.06], Omega: [[v]]}).w,         // [0.657, 0.343]

สิ่งที่ควรตอบได้หลังอ่าน

  • ย้อนค่าเฉลี่ยจากน้ำหนักด้วย $\Pi=\delta\Sigma w_m$: 60/40 บอกเป็นนัยว่าหุ้น 6.4% พันธบัตร 1.6% ซึ่งเท่ากับ beta คูณผลตอบแทนส่วนเกินของตลาด 4.48% แบบ CAPM
  • มุมมองต้องเทียบกับ $P\Pi$: “หุ้นชนะ 3 จุด” เทียบกับ 4.8 จุดคือข่าวร้ายของหุ้น
  • ค่าเฉลี่ยหลังผสมคือค่าเฉลี่ยแบบมีเงื่อนไขของ Normal หลายตัวแปร หรือค่าเฉลี่ยถ่วงด้วยความแม่น: ส่วนต่าง 3.9 จุด แคบกว่าทั้ง prior และ view
  • น้ำหนักคือพอร์ตอ้างอิงบวก tilt ในทิศของมุมมองเท่านั้น: หุ้น 51.43% ย้าย \$857,143
  • ความมั่นใจคือปุ่มที่ไวที่สุด (หุ้น 42.86% ถึง 60%) และมุมมองซ้ำที่ใส่ว่าอิสระนับหลักฐานซ้ำ (3.60 แทน 3.88)

บทนี้จบที่น้ำหนักพอร์ตบนกระดาษ ขั้นต่อไปคือราคาและการซื้อขายจริง มูลค่าของเงินตามเวลา เริ่มจากคำถามพื้นฐานที่สุดของการเงิน: เงินหนึ่งดอลลาร์ปีหน้ามีค่าเท่าไรวันนี้
