21.2 Multivariate Optimizers for Calibration

เลือก parameter หลายตัวให้เข้าตลาดโดยวัด error, scale ก้าว และควบคุมการหยุด

desk volatility ของสหรัฐฯ ต้องทำให้โมเดลหนึ่งชุดอธิบาย SPX option หลาย strike และหลาย expiry พร้อมกัน การปรับ skew, variance และ mean reversion ด้วยมือให้แถวหนึ่งสวยมักทำให้อีกแถวพัง Multivariate optimizer จึงไม่ใช่ปุ่ม fit มหัศจรรย์ แต่เป็นเครื่องมือเดินบนภูมิประเทศที่มีร่อง สัน ขอบเขต และกับดัก—เหมือนหาทางออกในห้างที่มีร้านกาแฟทุกสิบเมตร

ศัพท์ที่ทำให้คำว่า calibrate มีความหมาย

calibration
การเลือก parameter ของโมเดลให้ราคาใกล้ quote ตลาดตามนิยาม error ที่ประกาศ ใช้สร้าง pricing engine ที่สอดคล้องกับข้อมูลวันนี้
objective function
ฟังก์ชันที่รวมความผิดพลาดเป็นตัวเลขเดียว ใช้ให้ algorithm ตัดสินว่าจุดใดดีกว่าโดยไม่ใช้สายตา
residual
ราคาโมเดลลบราคาเป้าหมายของ quote หนึ่งตัว ใช้บอกทิศและขนาดของความคลาดเคลื่อน
Jacobian
ตารางอนุพันธ์ของ residual ต่อ parameter แต่ละตัว ใช้คาดผลของก้าวเล็ก ๆ ต่อ quote ทุกตัว
Hessian
เมทริกซ์ความโค้งอันดับสองของ objective ใช้บอกว่าหุบแคบหรือแบนและช่วยกำหนดก้าว
Nelder–Mead
วิธีที่ขยับ simplex ด้วยอันดับของ objective เท่านั้น ใช้เป็น derivative-free baseline เมื่อ gradient ไม่น่าเชื่อถือ
Broyden Fletcher Goldfarb Shanno (BFGS)
วิธี quasi-Newton ที่เรียนรู้ Hessian โดยประมาณจาก gradient ที่ผ่านม ใช้เร่ง convergence โดยไม่คำนวณอนุพันธ์อันดับสองจริง
Levenberg Marquardt (LM)
วิธี least-squares ที่เพิ่ม damping ให้ Gauss–Newton ใช้กันก้าวใหญ่เกินเมื่อ parameter ยังไกลคำตอบ
Fast Fourier Transform (FFT)
อัลกอริทึมคำนวณ Discrete Fourier Transform อย่างรวดเร็ว ใช้คำนวณราคา option ทั้ง ladder หลาย strike พร้อมกันเพื่อลดเวลา reprice ในรอบ calibration
QR factorization (QR)
การแยกเมทริกซ์ออกเป็น orthogonal และ upper-triangular matrix ใช้แก้ linear least-squares และระบบสมการก้าว Gauss–Newton อย่างมีเสถียรภาพโดยไม่ต้อง invert เมทริกซ์ตรง ๆ
singular value decomposition (SVD)
การแยกองค์ประกอบเมทริกซ์ออกเป็น singular vector และ singular value ใช้ตรวจและแก้ปัญหาระบบสมการก้าวที่ ill-conditioned หรือ rank-deficient ใน multivariate optimization

implied volatility ของ option หนึ่งตัวมักมีหุบหนึ่งมิติ แต่ stochastic-volatility หรือ curve model มี parameter หลายตัว และ quote หลายสิบถึงหลายพันตัว Parameter สองชุดอาจให้ smile วันนี้ใกล้กันมาก แต่ให้ Greek และ stress P&L ต่างกันในวันพรุ่งนี้

ก่อนเลือก optimizer ให้ตอบให้ชัดว่ากำลัง fit ราคา, implied volatility หรือ error ที่เทียบกับ bid–ask ราคา $0.05 ที่ option ถูกอาจกิน spread ทั้งหมด ขณะที่ error เดียวกันบน option $20 แทบไม่มีความหมาย การไม่เขียน objective คือเลือก weight โดยไม่รู้ตัว

ตัวอย่าง USD ที่ตรวจเลขได้ — หนึ่งก้าว LM

สมมติ snapshot option หุ้นสหรัฐฯ มี mid $12.70, $6.40, $2.50 และ half-spread $0.20, $0.10, $0.10 ต่อหน่วยสัญญา โมเดลปัจจุบันให้ $12.60, $6.50, $2.48 residual ที่ normalize จึงเป็น -0.50, 1.00, -0.20 และ objective เท่ากับ 0.645

เพื่อให้ตรวจด้วยมือได้ ใช้ local Jacobian ที่ scale แล้วเป็น diagonal ค่า 10 และ สมการ LM ให้ residual เชิงเส้นใหม่คือ -0.10, 0.20, -0.04 และ objective เหลือ 0.0258 รับก้าวได้ แต่ระบบจริงต้อง reprice ด้วย engine จริงก่อน commit

ภาพ 21.2b — Nelder–Mead ขยับ simplex โดยดูอันดับ

เลือกตระกูล optimizer ตามข้อมูลที่เชื่อได้

Nelder–Mead ใช้ objective อย่างเดียว จึงเหมาะตรวจ gradient แต่ช้าเมื่อ parameter มาก BFGS ใช้ gradient ที่ผ่านการทดสอบ จึงคุ้มเมื่อมี analytic derivative หรือ automatic differentiation Gauss–Newton และ LM เหมาะเมื่อ objective เป็นผลรวมกำลังสองของ residual ราคา เพราะ Jacobian ให้โครงสร้างตรงกับโจทย์

ไม่มี algorithm ใดแก้ stale quote หรือ crossed market ได้ ถ้าข้อมูลผิด optimizer จะทำงานหนักเพื่ออธิบายความผิดของ feed นั่นไม่ใช่ convergence; นั่นคือการ calibrate noise อย่างขยัน

สรุปที่ใช้ได้จริง

  • calibration เริ่มจาก objective และ weight ที่อธิบายได้; residual ต่อ half-spread ทำให้ error มีมาตรฐานร่วมกัน
  • Nelder–Mead เป็น derivative-free check, BFGS ใช้ gradient, และ LM ใช้โครงสร้าง least-squares พร้อม damping
  • production run ต้องมี transforms, multi-start, diagnostics, accept/reject log และ out-of-sample controls
