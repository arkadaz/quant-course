21.2 Multivariate Optimizers for Calibration

calibration คือการหาตัวเลขหลายตัวของแบบจำลองที่ทำให้ราคาจากแบบจำลองใกล้ราคาตลาดที่สุด โดยรวมความพลาดเป็นตัวเลขเดียวแล้วให้อัลกอริทึมเดินลงเขา และต้องถามทุกครั้งว่าข้อมูลบอกตัวเลขนั้นได้จริงหรือไม่

เช้านี้โต๊ะเห็น variance swap ห้าอายุ ตั้งแต่ 3 เดือนถึง 3 ปี แต่ละตัวมี bid กับ ask และต้องหา $v_0$, $\theta$, $\kappa$ ของแบบจำลอง Heston ก่อนตลาดเปิด เพื่อ quote variance swap อายุ 10 ปีที่ลูกค้าขอ เด็กฝึกงานลองทุกชุดบนกริด 11 ค่าต่อตัว รวม 1,331 ชุด ได้ $(0.09,\ 0.04,\ 2)$ แล้ว quote 10 ปีที่ 20.62% เขาบอกว่าถ้าทำแบบเดียวกันกับ Heston ครบห้าตัวจะใช้ 161,051 ชุด มีวิธีที่เร็วกว่านี้ไหม และตัวเลข 20.62% เชื่อได้แค่ไหน?

ลองตอบก่อนเปิดเฉลย

Levenberg–Marquardt ใช้ 6 รอบ (แต่ละรอบคำนวณราคาห้าตัวกับความชันของมัน) ได้ความคลาดเคลื่อนรวม 0.1518 ดีกว่า 0.1685 ของกริด เพราะคำตอบจริงอยู่ระหว่างจุดของกริด: $v_0=0.0894$, $\theta=0.0394$, $\kappa=1.90$ และ 10 ปีเป็น 20.51% แต่ข้อมูลห้าจุดนี้บอก $\kappa$ ได้แค่ช่วงราว 1.41 ถึง 2.52 ทุกค่าในช่วงนั้นให้ราคาทั้งห้าอยู่ใน bid–ask ขณะที่ 10 ปีเลื่อนจาก 19.67% ถึง 21.13% ตัวเลขเดียวจึงเชื่อไม่ได้ ต้อง quote ด้วยส่วนต่างที่กว้างพอ หรือหา quote อายุยาวกว่านี้มาเพิ่ม

ภาพรวมก่อนลงสูตร

calibration คือการปรับ parameter ของแบบจำลองจนราคาจากแบบจำลองเข้ากับราคาตลาด กรณีที่ง่ายที่สุดคือ implied volatility: ราคาหนึ่งตัว parameter หนึ่งตัว หาค่าที่ตรงพอดีได้ด้วย Newton งานจริงมี quote มากกว่า parameter เสมอ (ห้า quote กับสาม parameter ในหน้านี้ หลายสิบ quote กับห้า parameter สำหรับ Heston เต็มรูป) จึงไม่มีชุดไหนตรงทุกตัว ต้องนิยามก่อนว่า “ใกล้ที่สุด” แปลว่าอะไร แล้วให้อัลกอริทึมหาชุดที่ใกล้ที่สุดตามนิยามนั้น และแม้ไม่มีแบบจำลองใดตรงทั้งผืน ชุดที่ fit พอดีก็ใช้ตั้งราคาสัญญาที่ตลาดไม่มีให้ดูได้

รูปด้านล่างคือวงจรที่ทุกอัลกอริทึมในหน้านี้วน: เลือก parameter → แบบจำลองคำนวณราคา → เทียบกับ bid–ask ของตลาด → รวมความพลาดเป็นตัวเลขเดียว → เลือก parameter ใหม่ อัลกอริทึมต่างกันแค่ขั้นสุดท้าย: grid search ไม่ใช้ข้อมูลจากรอบก่อนเลย Nelder–Mead ใช้แค่การเทียบว่าจุดไหนดีกว่า gradient descent กับ BFGS ใช้ความชัน ส่วน Gauss–Newton กับ Levenberg–Marquardt ใช้โครงสร้างผลรวมกำลังสองของความพลาดโดยตรง

ทั้งหน้าใช้โจทย์เดียว: variance เฉลี่ยตลอดอายุของ Heston ซึ่งคือราคายุติธรรมของ variance swap เราจะตั้งตัววัดความพลาดจาก bid–ask ลอง grid search สร้าง Gauss–Newton กับ Levenberg–Marquardt เทียบกับ gradient descent, BFGS และ Nelder–Mead ดูว่าหน่วยของตัวแปรกับการแปลง log มีผลมากแค่ไหน แล้วจบที่ร่องแบนซึ่งบอกว่าข้อมูลรู้อะไรไม่ได้

ศัพท์ที่ใช้ในหัวข้อนี้
Calibration
การเลือกตัวเลขของแบบจำลองให้ราคาจากแบบจำลองใกล้ราคาตลาดที่สุดตามนิยามที่ประกาศไว้ ใช้ทำทุกเช้าก่อนตั้งราคาสัญญาที่ตลาดไม่มีให้ดู ค่าที่ได้เป็นค่าที่ใช้ตั้งราคา ไม่ใช่ค่าสถิติจากข้อมูลย้อนหลัง
Residual
ราคาจากแบบจำลองลบราคากลางของตลาด หารด้วยครึ่งหนึ่งของส่วนต่าง bid–ask ใช้บอกทั้งทิศและขนาดของความพลาดของ quote หนึ่งตัวในหน่วยที่เทียบกันได้ทุกตัว ค่าไม่เกิน 1 แปลว่าราคาจากแบบจำลองอยู่ในช่วง bid–ask
Objective function
ตัวเลขเดียวที่รวมความพลาดของทุก quote ในหน้านี้คือครึ่งหนึ่งของผลรวมกำลังสองของ residual ใช้ให้อัลกอริทึมตัดสินได้เองว่าชุดไหนดีกว่า โดยไม่ต้องใช้สายตา
Jacobian
ตารางความชันของ residual ทุกตัวเทียบ parameter ทุกตัว แถวละหนึ่ง quote คอลัมน์ละหนึ่ง parameter ใช้ทายว่าขยับ parameter เล็กน้อยแล้ว residual ทุกตัวจะเปลี่ยนเท่าไร
Gauss–Newton
วิธีที่แทน residual ด้วยเส้นตรงรอบจุดปัจจุบันแล้วกระโดดไปก้นของกำลังสองของเส้นตรงนั้น ใช้เมื่อ objective เป็นผลรวมกำลังสอง ลู่เข้าเร็วใกล้คำตอบ แต่ก้าวไกลเกินได้เมื่ออยู่ไกล
Levenberg–Marquardt
Gauss–Newton ที่เติมเบรก $\lambda$ ลงในระบบสมการ เบรกมากก้าวสั้นและชี้ลงเขา เบรกน้อยก้าวเหมือน Gauss–Newton ใช้เป็นเครื่องมือหลักของ calibration แบบกำลังสองน้อยที่สุด
BFGS
วิธีแบบ quasi-Newton ที่สะสมความโค้งของ objective จากความชันที่เปลี่ยนไปในแต่ละก้าว ใช้เมื่อมี gradient แต่ไม่มีอนุพันธ์อันดับสอง มีไว้เพราะ gradient descent เดินซิกแซ็กในหุบแคบ
Nelder–Mead
วิธีที่ใช้แค่ค่าของ objective ไม่ใช้ความชัน ถือรูปสามเหลี่ยม (ในสามมิติคือสี่จุด) แล้วสะท้อน ยืด หรือหดมุมที่แย่ที่สุด ใช้เมื่อ objective ไม่เรียบหรือความชันเชื่อไม่ได้

ขั้นที่ 1 — ของที่ตลาดให้: variance swap ห้าอายุ และเส้นของ Heston

$w(T)$ คือค่าเฉลี่ยของ variance ที่ถูกดึงจาก $v_0$ เข้าหา $\theta$ แบบ exponential: อายุสั้นเห็น $v_0$ เกือบเต็ม อายุยาวเห็น $\theta$ เป็นส่วนใหญ่ และ $g(\kappa T)$ บอกสัดส่วนที่ยังเหลือของ $v_0$ quote ชุดนี้เป็นตัวเลขสมมติ สร้างจากชุดตัวอย่างของหน้า Heston ($v_0=0.09$, $\theta=0.04$, $\kappa=2$ ซึ่งให้ 28.17%, 26.76%, 24.82%, 22.86% และ 21.98%) แล้วขยับราคากลางเล็กน้อยแบบที่ตลาดจริงมีเสียงรบกวน คำตอบที่ได้จึงไม่ใช่ $(0.09,\ 0.04,\ 2)$ พอดี

ทำไมใช้หน่วย variance แทนจุดความผันผวน: สัญญาจ่ายตาม variance และในหน่วยนี้ $w$ เป็นเส้นตรงใน $v_0$ กับ $\theta$ มีแค่ $\kappa$ ที่อยู่ในฟังก์ชันโค้ง ข้อนี้จะช่วยมากตอนหาร่องแบนท้ายหน้า ส่วนต่าง bid–ask ของอายุยาวกว้างกว่า เพราะซื้อขายน้อยกว่า

ขั้นที่ 2 — ตัวเลขเดียวที่บอกว่าใกล้แค่ไหน

อัลกอริทึมเทียบ “ใกล้กว่า” ได้ก็ต่อเมื่อความพลาดห้าตัวถูกรวมเป็นตัวเลขเดียว ทางเลือกมีหลายแบบ แต่ละแบบให้เสียงดังกับ quote ต่างกลุ่ม เราหาร residual ด้วยครึ่งส่วนต่าง เพราะ quote ที่ส่วนต่างกว้างคือ quote ที่ตลาดเองก็ไม่แน่ใจ แล้วรวมกำลังสอง การเลือกนี้มีเหตุผลรองรับ: ถ้าราคากลางคือราคาจากแบบจำลองบวกเสียงรบกวนปกติที่มีความผันผวน $h_i$ การทำ $L$ ให้เล็กที่สุดคือการหาชุดที่ทำให้ข้อมูลที่เห็นมีโอกาสเกิดสูงที่สุด

\[ \begin{aligned} r_i(x)&=\frac{w(T_i)-m_i}{h_i},\\ L(x)&=\tfrac12\sum_{i=1}^{5}r_i(x)^2,\\ m_i&=w(T_i)+\varepsilon_i,\\ \varepsilon_i&\sim N(0,h_i^2),\\ -\ln p&=\tfrac12\sum_i r_i^2+\text{const},\\ x_0&=(7,\ 5,\ 1),\\ w(0.25)&=\frac{5+2(0.884797)}{100}\\ &=0.067696,\\ r_1&=\frac{0.067696-0.078967}{0.001405}\\ &=-8.022. \end{aligned} \]

บรรทัดที่สามถึงห้าคือเหตุผลของกำลังสอง: density ปกติ ของแต่ละ quote มี $e^{-r_i^2/2}$ คูณกันห้าตัวแล้วใส่ลบ log ผลคูณกลายเป็นผลบวก ค่าคงที่ไม่ขึ้นกับ $x$ จึงไม่มีผลต่อคำตอบ residual ที่ไม่เกิน 1 แปลว่าราคาจากแบบจำลองอยู่ใน bid–ask ของ quote นั้น

จุดเริ่ม $x_0$ คือเดาว่า $v_0=0.07$, $\theta=0.05$, $\kappa=1$ ห้า residual คือ −8.022, −4.737, 0.927, 3.246 และ 3.812 จึงได้ $L=56.365$ ค่าติดลบที่อายุสั้นบอกว่า variance วันนี้ต่ำไป ค่าบวกที่อายุยาวบอกว่าระดับระยะยาวสูงไป

ขั้นที่ 3 — grid search: นับงานก่อนลงมือ

โจทย์ให้อะไรมาบ้าง: ลองทุกชุดบนกริด $v_0$ ตั้งแต่ 0.04 ถึง 0.14 ทีละ 0.01, $\theta$ ตั้งแต่ 0.02 ถึง 0.07 ทีละ 0.005 และ $\kappa$ ตั้งแต่ 0.5 ถึง 5.5 ทีละ 0.5 ตัวละ 11 ค่า แล้วเก็บชุดที่ $L$ ต่ำสุด

\[ \begin{aligned} 11^3&=1{,}331,\\ x_{\rm grid}&=(9,\ 4,\ 2),\\ L_{\rm grid}&=0.1685,\\ 11^5&=161{,}051. \end{aligned} \]

คำตอบ: กริดใช้ 1,331 ชุดแล้วได้ $(0.09,\ 0.04,\ 2)$ ข้อดีของมันคือไม่หลงหุบ เพราะดูทุกจุด และไม่สนว่า objective มีรูปร่างแบบไหน แต่มีสองปัญหา คำตอบละเอียดได้เท่าช่องของกริดเท่านั้น (Levenberg–Marquardt ข้างล่างได้ $L=0.1518$ ที่ $\kappa=1.90$ ซึ่งอยู่ระหว่างจุด) และงานคูณ 11 ทุกครั้งที่เพิ่มตัวแปร Heston ครบห้าตัวต้องตั้งราคาทั้งผืน 161,051 ครั้ง ถ้าแต่ละครั้งใช้ 0.1 วินาที (สมมติ) ก็ 4.5 ชั่วโมง นี่คือ curse of dimensionality

ปัญหาที่สามเห็นได้จาก calibration ของ Heston ห้าตัวกับ call ของ Apple ที่ใช้กริดรอบจุดเริ่ม: $\kappa$ ตั้งแต่ 1.8 ถึง 2.8, $\theta$ 0.036 ถึง 0.056, vol-of-vol 0.0725 ถึง 0.0925, $\rho$ −0.63 ถึง −0.43 และ $v_0$ 0.044 ถึง 0.064 คำตอบคือ $(1.8,\ 0.046,\ 0.0925,\ -0.63,\ 0.044)$ สี่ในห้าตัวชนขอบของกริด ซึ่งบอกว่าก้นจริงอยู่นอกกล่อง กริดจึงให้ได้แค่จุดที่ดีที่สุดในกล่องที่เราเดาไว้

ตรวจเองใน 10 วินาที: $161{,}051\times0.1=16{,}105$ วินาที หารด้วย 3,600 ได้ 4.47 ชั่วโมง ส่วนชุด $(9,4,2)$ บังเอิญเป็นชุดที่ใช้สร้าง quote กริดจึงได้ค่าดี แต่ยังแพ้จุดที่อยู่ระหว่างช่อง

ขั้นที่ 4 — Gauss–Newton: แทน residual ด้วยเส้นตรง แล้วแก้ระบบ 3×3

แทนที่จะลองทุกจุด ให้ใช้ความชันบอกทาง residual แต่ละตัวเป็นฟังก์ชันโค้งของ $x$ แต่ใกล้จุดปัจจุบันมันเกือบเป็นเส้นตรง (Taylor อันดับหนึ่ง) ถ้าแทนด้วยเส้นตรง $L$ จะกลายเป็นกำลังสองของเส้นตรง ซึ่งหาก้นได้ด้วยสมการเชิงเส้น นี่คือที่มาของก้าว Gauss–Newton

\[ \begin{aligned} r(x+\delta)&\approx r+J\delta,\\ L(x+\delta)&\approx\tfrac12(r+J\delta)^{\top}(r+J\delta),\\ \frac{\partial L}{\partial\delta}&=J^{\top}(r+J\delta)=0,\\ J^{\top}J\,\delta&=-J^{\top}r,\\ \frac{\partial w}{\partial v_0}&=g,\quad \frac{\partial w}{\partial\theta}=1-g,\\ \frac{\partial w}{\partial\kappa}&=(v_0-\theta)\,T\,g'(\kappa T),\\ g'(z)&=\frac{e^{-z}(1+z)-1}{z^2}. \end{aligned} \]

บรรทัดที่สามคืออนุพันธ์ของกำลังสองตาม chain rule: $J^{\top}$ คูณเวกเตอร์ข้างใน ตั้งเป็นศูนย์แล้วได้ระบบ $3\times3$ ซึ่งคือ normal equations ของ OLS พอดี ก้าว Gauss–Newton จึงคือการ regress $-r$ บนคอลัมน์ของ $J$

$J^{\top}r$ คือ gradient ของ $L$ จริง ส่วน $J^{\top}J$ คือ Hessian ที่ทิ้งพจน์ $\sum r_i\nabla^2r_i$ ซึ่งเล็กเมื่อ residual เล็ก

สามบรรทัดล่างคือคอลัมน์ของ $J$ ก่อนหารด้วย $h_i$: สองคอลัมน์แรกได้จากสูตรเส้นตรงของ $w$ ทันที คอลัมน์ของ $\kappa$ ใช้กฎผลหารกับ $g(z)=(1-e^{-z})/z$ ได้ $\big(ze^{-z}-(1-e^{-z})\big)/z^2$ แล้วคูณ $T$ ตาม chain rule สังเกตว่าถ้า $v_0=\theta$ คอลัมน์นี้เป็นศูนย์ทั้งคอลัมน์ เพราะเส้นแบนแล้ว $\kappa$ ไม่มีผลอะไรเลย

ขั้นที่ 5 — ก้าวแรกด้วยตัวเลข และก้าวที่สองที่แย่ลง

โจทย์ให้อะไรมาบ้าง: จุดเริ่ม $x_0=(7,5,1)$ ใช้หน่วย $(100v_0,\ 100\theta,\ \kappa)$ ให้ตัวเลขทั้งสามมีขนาดใกล้กัน (เหตุผลอยู่ในขั้นเรื่องหน่วยของตัวแปร) แถวแรกของ $J$ คือ $g(0.25)/(100h_1)=0.884797/0.1405=6.2975$ และ $0.8200$ และ $-1.5088$ ห้าแถวรวมกันเป็น $J^{\top}J$ กับ $J^{\top}r$

\[ \begin{aligned} A&=J^{\top}J,\quad A_{ij}=A_{ji},\\ A_{11}&=99.77,\quad A_{12}=36.80,\\ A_{13}&=-51.55,\quad A_{22}=28.62,\\ A_{23}&=-31.93,\quad A_{33}=38.58,\\ J^{\top}r&=(-61.18,\ 10.13,\ 1.74),\\ \delta&=(1.835,\ -0.372,\ 2.099),\\ x_1&=(8.835,\ 4.628,\ 3.099),\\ L(x_1)&=10.17. \end{aligned} \]

คำตอบ: ก้าวแรกลด $L$ จาก 56.37 เหลือ 10.17 ยก $v_0$ ขึ้นและ $\theta$ ลงตามที่ residual บอก แต่ดัน $\kappa$ จาก 1 ไป 3.10 เกินไปมาก เดินต่ออีกก้าวได้ $x_2=(8.725,\ 4.056,\ 1.218)$ และ $L=20.01$ แย่ลงกว่าเดิม เพราะเส้นตรงที่วัดที่ $\kappa=3.1$ ทายผิดไกล ก้าวต่อจากนั้นให้ 1.635, 0.15184 และ 0.1518391 ครั้งนี้ลู่เข้าได้ แต่ไม่มีอะไรรับประกันว่า $L$ จะลดทุกก้าว

ตรวจเองใน 10 วินาที: แทน $\delta$ ในแถวแรก: $99.77(1.835)+36.80(-0.372)-51.55(2.099)=183.1-13.7-108.2=61.2$ เท่ากับ $-(-61.18)$ ตามต้องการ

ขั้นที่ 6 — Levenberg–Marquardt: ใส่เบรกที่ปรับเองได้

ปัญหาของก้าวที่สองคือเราเชื่อเส้นตรงไกลเกินกว่าที่มันแม่น วิธีแก้คือลงโทษก้าวยาวในแบบจำลองเส้นตรง โดยบวก $\tfrac12\lambda\delta^{\top}\delta$ เข้าไปก่อนหาก้น แล้วปรับ $\lambda$ ตามผลจริง: ก้าวที่ทำให้ $L$ ลดได้ ลดเบรกลงสิบเท่า ก้าวที่ทำให้ $L$ เพิ่ม ไม่รับ และเพิ่มเบรกสิบเท่า

\[ \begin{aligned} \ell(\delta)&=\tfrac12\|r+J\delta\|^2+\tfrac12\lambda\,\delta^{\top}\delta,\\ \frac{\partial\ell}{\partial\delta}&=J^{\top}(r+J\delta)+\lambda\delta=0,\\ (J^{\top}J+\lambda I)\,\delta&=-J^{\top}r,\\ \lambda\to0&:\ \text{Gauss–Newton},\\ \lambda\ \text{large}&:\ \delta\approx-J^{\top}r/\lambda,\\ J=10I&:\ \delta=-\frac{10\,r}{100+\lambda}. \end{aligned} \]

บรรทัดที่สามคือระบบเดิมที่บวก $\lambda$ บนเส้นทแยง เมื่อ $\lambda$ ใหญ่ ก้าวคือทิศลงเขาของ gradient descent ที่สั้นลงตาม $1/\lambda$ เมื่อ $\lambda$ เล็ก ก้าวคือ Gauss–Newton เบรกตัวเดียวจึงเลื่อนระหว่างสองวิธี และ $\lambda I$ ยังทำให้ระบบแก้ได้เสมอแม้คอลัมน์ของ $J$ จะเกือบซ้ำกัน (matrix ที่ invert ไม่ได้ กลายเป็น invert ได้)

บรรทัดสุดท้ายคือของเล่นที่อ่านรูปถัดไปได้: ถ้า parameter แต่ละตัวขยับ residual ของตัวเองสิบเท่าและไม่กระทบตัวอื่น ($J=10I$) ก้าวต่อ residual หนึ่งหน่วยคือ $10/(100+\lambda)$ ที่ $\lambda=0$ ได้ 0.1 ซึ่งลบ residual ทิ้งหมด ที่ $\lambda=25$ ได้ 0.08 และ residual เหลือ $25/125=0.2$ เท่าเดิม ที่ $\lambda=1{,}000$ ได้ 0.0091 และเหลือ 0.909 เท่า

เดินจากจุดเริ่มเดิม $(7,5,1)$ เบรกเริ่ม $\lambda=1$ หยุดเมื่อ $L$ ลดน้อยกว่า $10^{-12}$:

ขั้นที่ 7 — ทำไม gradient descent ช้า และ BFGS เรียนความโค้งได้อย่างไร

gradient descent ใช้แค่ทิศลงเขา ไม่รู้ว่าแต่ละทิศโค้งแค่ไหน ความเร็วของมันจึงขึ้นกับอัตราส่วนระหว่างความโค้งมากสุดกับน้อยสุดของหุบ ซึ่งอ่านได้จาก eigenvalue ของ $J^{\top}J$ ที่คำตอบ BFGS แก้ปัญหานี้โดยจำว่าความชันเปลี่ยนไปเท่าไรเมื่อเดินไปเท่าไร แล้วสร้างตัวประมาณของ inverse Hessian ที่ต้องทำตามเงื่อนไข secant

\[ \begin{aligned} \text{eig}(J^{\top}J)&=178.93,\ 19.09,\ 1.788,\\ c&=178.93/1.788=100.1,\\ \frac{c-1}{c+1}&=0.9802,\\ s_k&=x_{k+1}-x_k,\\ y_k&=\nabla L_{k+1}-\nabla L_k,\\ H_{k+1}\,y_k&=s_k,\\ H_{k+1}&=(I-\rho s_ky_k^{\top})\,H_k\\ &\quad\times(I-\rho y_ks_k^{\top})\\ &\quad+\rho\,s_ks_k^{\top},\\ \rho&=1/(y_k^{\top}s_k). \end{aligned} \]

gradient descent ที่ขนาดก้าวดีที่สุดคูณความคลาดเคลื่อนในทิศที่แบนที่สุดด้วย $(c-1)/(c+1)$ ทุกก้าว (ผลของ ชามรีที่ทำให้เดินซิกแซ็ก) ที่นี่ 0.9802 ต้องใช้ราว 691 ก้าวเพื่อลดความคลาดเคลื่อนในทิศนั้นลงล้านเท่า การเดินจริงจาก $x_0$ ด้วยขนาดก้าว $2/(178.93+1.788)=0.01107$ ใช้ 260 ก้าวกว่า $L$ จะห่างจากต่ำสุดไม่ถึง $10^{-6}$

ตรวจเงื่อนไข secant ของสูตร BFGS ได้ในบรรทัดเดียว: $(I-\rho y_ks_k^{\top})y_k=y_k-\rho y_k(s_k^{\top}y_k)=0$ พจน์แรกจึงหายเมื่อคูณ $y_k$ ส่วน $\rho s_ks_k^{\top}y_k=s_k$ พอดี ในการรันจริงก้าวแรกมี $s_0=(0.956,\ -0.158,\ -0.027)$ และ $y_0=(92.36,\ 31.41,\ -72.42)$ โค้ดตรวจว่า $H_1y_0$ ออกมาเท่ากับ $s_0$ ทุกหลัก สูตรนี้ยังรักษาให้ $H$ เป็น positive definite ตราบที่ $y_k^{\top}s_k\gt0$ ทิศ $-H\nabla L$ จึงลงเขาเสมอ

ผลในสามมิติ: BFGS จาก $x_0$ ใช้ 16 รอบ (คำนวณ $L$ ทั้งหมด 31 ครั้ง รวมการลดขนาดก้าวเมื่อก้าวเต็มไม่ผ่าน) จนขนาด gradient ต่ำกว่า $10^{-7}$ และได้คำตอบเดียวกับ Levenberg–Marquardt ถึงทศนิยมตำแหน่งที่เจ็ด ข้อดีของ BFGS คือลู่เข้าเร็วเมื่อ objective โค้งเป็นชาม และใช้ได้กับ objective ทุกแบบที่มี gradient ข้อเสียคือต้องการ objective ที่เรียบ อาจไปค้างที่จุดอานม้า และไม่รับประกันว่าได้ก้นที่ต่ำที่สุดของทั้งผืน รูปด้านล่างตัดชามสามมิติเป็นระนาบสองมิติให้เห็นเส้นทางจริงของแต่ละวิธี

ขั้นที่ 8 — Nelder–Mead: ใช้แค่การเทียบว่าจุดไหนดีกว่า

โจทย์ให้อะไรมาบ้าง: บางครั้งไม่มี gradient ที่เชื่อได้ เช่นราคามาจากการจำลองที่มีเสียงรบกวน Nelder–Mead ใช้แค่ค่าของ $L$: ถือรูปสามเหลี่ยม (ในสามมิติคือจุดสี่จุด) สะท้อนจุดที่แย่ที่สุดผ่านจุดกึ่งกลางของจุดที่เหลือ ถ้าดีมากให้ยืดต่อ ถ้าไม่ดีให้หดเข้า ลองบนระนาบเดียวกับรูปด้านบน สามเหลี่ยมเริ่มที่ $(7,\ 1)$, $(8,\ 1)$ และ $(7,\ 1.5)$ ซึ่งมี $L$ เป็น 61.61, 11.47 และ 94.87

\[ \begin{aligned} \text{worst}&=(7,\ 1.5),\\ c&=\tfrac12\big((7,1)+(8,1)\big)\\ &=(7.5,\ 1),\\ x_r&=2c-\text{worst}=(8,\ 0.5),\\ L(x_r)&=65.47,\\ 61.61&\lt65.47\lt94.87,\\ x_c&=c+\tfrac12(x_r-c)\\ &=(7.75,\ 0.75),\\ L(x_c)&=22.42. \end{aligned} \]

คำตอบ: จุดสะท้อนดีกว่าจุดที่แย่ที่สุด (94.87) แต่แย่กว่าจุดที่สองจากท้าย (61.61) กติกาจึงหดเข้าครึ่งทางจากจุดกึ่งกลางไปหาจุดสะท้อน ได้ $(7.75,\ 0.75)$ ที่ $L=22.42$ ซึ่งดีกว่าทั้งสองตัวเลขนั้น จึงแทนที่มุม $(7,\ 1.5)$ สามเหลี่ยมคลานต่อด้วยการหด ยืด และสะท้อน (รูปด้านล่าง) และใช้การคำนวณ $L$ 97 ครั้งจนสามมุมต่างกันไม่ถึง $10^{-10}$ บนโจทย์สามมิติเต็ม Nelder–Mead จาก $x_0$ (ก้าวเริ่ม 1, 1 และ 0.5) ใช้การคำนวณ $L$ 173 ครั้ง และได้คำตอบเดียวกับ Levenberg–Marquardt ถึงทศนิยมที่สี่ของ $\kappa$

ตรวจเองใน 10 วินาที: $2(7.5)-7=8$ และ $2(1)-1.5=0.5$ ส่วน $7.5+\tfrac12(0.5)=7.75$ และ $1+\tfrac12(-0.5)=0.75$ ข้อดีของ Nelder–Mead คือไม่ต้องมีอนุพันธ์และทนกับ objective ที่ไม่เรียบ ข้อเสียคือช้าลงมากเมื่อตัวแปรเพิ่ม บางครั้งวนหลายรอบโดย $L$ แทบไม่ลดทั้งที่ยังไม่ถึงก้น และไม่มีหลักประกันว่าจะได้ก้นที่ต่ำที่สุดของทั้งผืน

// Calibrating the Heston variance curve to five variance-swap quotes: weighted residuals, grid search,
// Gauss-Newton, Levenberg-Marquardt, gradient descent, BFGS, Nelder-Mead, scaling and a log transform,
// and the flat valley along kappa.
const { abs, exp, expm1, log, sqrt, hypot, max, min } = Math;
const T = [0.25, 0.5, 1, 2, 3];
const bid = [27.85, 26.60, 24.45, 22.55, 21.40], ask = [28.35, 27.10, 25.05, 23.35, 22.40];
function checkQuotes(bidVol, askVol) {
  if (bidVol.length !== T.length || askVol.length !== T.length) throw new RangeError('Need one bid and one ask per maturity');
  bidVol.forEach((b, i) => {
    if (!(Number.isFinite(b) && Number.isFinite(askVol[i]))) throw new TypeError('Quotes must be finite numbers');
    if (!(b > 0 && askVol[i] > b)) throw new RangeError('Each quote needs 0 < bid < ask (vol points)');
  });
}
checkQuotes(bid, ask);
// Quotes in vol points become variance; mid and half-spread in variance units.
const wBid = bid.map(v => (v / 100) ** 2), wAsk = ask.map(v => (v / 100) ** 2);
const mid = wBid.map((b, i) => (b + wAsk[i]) / 2), half = wBid.map((b, i) => (wAsk[i] - b) / 2);
// Expected average variance of Heston. Parameters x = (100 v0, 100 theta, kappa).
// expm1 and a short series keep full precision when kappa * T is tiny.
const g = z => (z === 0 ? 1 : -expm1(-z) / z);
const gPrime = z => (abs(z) < 1e-3 ? -0.5 + z / 3 - z * z / 8 : (exp(-z) * (1 + z) - 1) / (z * z));
function checkParams(x) {
  if (!Array.isArray(x) || x.length !== 3 || !x.every(Number.isFinite)) throw new TypeError('Parameters must be three finite numbers');
  if (!(x[0] > 0 && x[1] > 0 && x[2] > 0)) throw new RangeError('v0, theta and kappa must be positive');
}
const model = (x, t) => (x[1] + (x[0] - x[1]) * g(x[2] * t)) / 100;
// Residuals in half-spreads and the objective L = sum(r^2) / 2.
function residuals(x) { checkParams(x); return T.map((t, i) => (model(x, t) - mid[i]) / half[i]); }
const objective = x => 0.5 * residuals(x).reduce((s, r) => s + r * r, 0);
// The Jacobian from the formula (d/dv0 = g, d/dtheta = 1 - g, d/dkappa = (v0 - theta) T g').
const jacobian = x => T.map((t, i) => [g(x[2] * t) / 100 / half[i], (1 - g(x[2] * t)) / 100 / half[i],
  (x[0] - x[1]) / 100 * t * gPrime(x[2] * t) / half[i]]);
function normalEquations(x) {
  const J = jacobian(x), r = residuals(x), A = [[0, 0, 0], [0, 0, 0], [0, 0, 0]], grad = [0, 0, 0];
  J.forEach((row, i) => { for (let a = 0; a < 3; a++) { grad[a] += row[a] * r[i]; for (let b = 0; b < 3; b++) A[a][b] += row[a] * row[b]; } });
  return {J, r, A, grad};
}
// Gaussian elimination with row swaps for the small systems.
function solve(A, b) {
  const n = b.length, M = A.map((row, i) => [...row, b[i]]);
  for (let c = 0; c < n; c++) {
    let p = c;
    for (let r = c + 1; r < n; r++) if (abs(M[r][c]) > abs(M[p][c])) p = r;
    [M[c], M[p]] = [M[p], M[c]];
    if (abs(M[c][c]) < 1e-300) throw new RangeError('Singular system: a parameter has no effect on the quotes');
    for (let r = c + 1; r < n; r++) { const f = M[r][c] / M[c][c]; for (let k = c; k <= n; k++) M[r][k] -= f * M[c][k]; }
  }
  const x = new Array(n).fill(0);
  for (let r = n - 1; r >= 0; r--) { let s = M[r][n]; for (let k = r + 1; k < n; k++) s -= M[r][k] * x[k]; x[r] = s / M[r][r]; }
  return x;
}
const valid = x => x[0] > 0 && x[1] > 0 && x[2] > 0;
const x0 = [7, 5, 1];
// Brute-force grid, 11 values per parameter.
function gridSearch() {
  let best = {L: Infinity}, count = 0;
  for (let a = 0; a <= 10; a++) for (let b = 0; b <= 10; b++) for (let c = 0; c <= 10; c++) {
    const x = [4 + a, 2 + 0.5 * b, 0.5 + 0.5 * c], L = objective(x); count++;
    if (L < best.L) best = {x, L};
  }
  return {...best, count};
}
// Plain Gauss-Newton steps (no brake).
function gaussNewton(x, steps) {
  const path = [{x, L: objective(x)}];
  for (let k = 0; k < steps; k++) {
    const {A, grad} = normalEquations(x), d = solve(A, grad.map(v => -v)), xn = x.map((v, i) => v + d[i]);
    if (!valid(xn)) { path.push({x: xn, L: null}); break; }
    x = xn; path.push({x, L: objective(x)});
  }
  return path;
}
// Levenberg-Marquardt: lambda / 10 after a good step, x 10 after a bad one.
// With logKappa the third coordinate is ln(kappa), so kappa stays positive by construction.
function levenbergMarquardt(start, logKappa = false, maxIter = 200) {
  const toX = y => [y[0], y[1], logKappa ? exp(y[2]) : y[2]];
  let y = logKappa ? [start[0], start[1], log(start[2])] : start.slice(), lambda = 1, rejects = 0;
  const path = [];
  for (let k = 0; k < maxIter; k++) {
    const x = toX(y), {J, r} = normalEquations(x), L = objective(x);
    const Jy = J.map(row => [row[0], row[1], logKappa ? row[2] * x[2] : row[2]]);
    const A = [[0, 0, 0], [0, 0, 0], [0, 0, 0]], grad = [0, 0, 0];
    Jy.forEach((row, i) => { for (let a = 0; a < 3; a++) { grad[a] += row[a] * r[i]; for (let b = 0; b < 3; b++) A[a][b] += row[a] * row[b]; } });
    const d = solve(A.map((row, i) => row.map((v, j) => v + (i === j ? lambda : 0))), grad.map(v => -v));
    const yn = y.map((v, i) => v + d[i]), xn = toX(yn), Ln = valid(xn) ? objective(xn) : Infinity;
    path.push({x, L, lambda, accepted: Ln < L});
    if (Ln < L) { y = yn; lambda /= 10; if (L - Ln < 1e-12) break; } else { lambda *= 10; rejects++; }
  }
  const x = toX(y);
  return {x, L: objective(x), iterations: path.length, rejects, path};
}
// Eigenvalues of a symmetric 3x3 matrix by Jacobi rotations (for the curvature ratio).
function eigenvalues(S) {
  const M = S.map(row => row.slice());
  for (let sweep = 0; sweep < 60; sweep++) for (let p = 0; p < 2; p++) for (let q = p + 1; q < 3; q++) {
    if (abs(M[p][q]) < 1e-300) continue;
    const th = (M[q][q] - M[p][p]) / (2 * M[p][q]), t = (th >= 0 ? 1 : -1) / (abs(th) + sqrt(th * th + 1));
    const c = 1 / sqrt(t * t + 1), s = t * c;
    for (let k = 0; k < 3; k++) { const a = M[k][p], b = M[k][q]; M[k][p] = c * a - s * b; M[k][q] = s * a + c * b; }
    for (let k = 0; k < 3; k++) { const a = M[p][k], b = M[q][k]; M[p][k] = c * a - s * b; M[q][k] = s * a + c * b; }
  }
  return [M[0][0], M[1][1], M[2][2]].sort((a, b) => b - a);
}
// Gradient descent with the best fixed step for this curvature, counted to within 1e-6 of the minimum.
function gradientDescent(start, eta, target) {
  let x = start.slice(), k = 0;
  while (objective(x) - target > 1e-6 && k < 100000) { const {grad} = normalEquations(x); x = x.map((v, i) => v - eta * grad[i]); k++; }
  return {x, L: objective(x), iterations: k};
}
// BFGS with a backtracking line search; returns the first secant check as well.
function bfgs(start) {

  while (hypot(...grad) > 1e-7 && iterations < 200) {
    const d = H.map(row => -row.reduce((s, v, j) => s + v * grad[j], 0)), slope = d.reduce((s, v, i) => s + v * grad[i], 0), L0 = objective(x);
    let t = 1, xn = x.map((v, i) => v + d[i]); evaluations++;
    while (!(valid(xn) && objective(xn) <= L0 + 1e-4 * t * slope)) {
      t /= 2; xn = x.map((v, i) => v + t * d[i]); evaluations++;
      if (t < 1e-12) throw new RangeError('Line search failed: the direction does not go downhill');

      const rho = 1 / sy;
      const left = I.map((row, i) => row.map((v, j) => v - rho * s[i] * yv[j])), right = I.map((row, i) => row.map((v, j) => v - rho * yv[i] * s[j]));
      H = mul(mul(left, H), right).map((row, i) => row.map((v, j) => v + rho * s[i] * s[j]));
      if (!secant) secant = {s, y: yv, Hy: H.map(row => row.reduce((a, v, j) => a + v * yv[j], 0))};
    }
    x = xn; grad = gn; iterations++;
  }
  return {x, L: objective(x), iterations, evaluations, secant};
}
// Nelder-Mead (reflect 1, expand 2, contract 1/2, shrink 1/2) using only objective values.
function nelderMead(f, start, steps, tol) {
  const n = start.length;
  let S = [start.slice()];
  for (let i = 0; i < n; i++) { const p = start.slice(); p[i] += steps[i]; S.push(p); }
  let F = S.map(f), evaluations = n + 1;
  for (let it = 0; it < 10000; it++) {
    const order = S.map((_, i) => i).sort((a, b) => F[a] - F[b]); S = order.map(i => S[i]); F = order.map(i => F[i]);
    if (F[n] - F[0] < tol) break;
    const c = start.map((_, j) => S.slice(0, n).reduce((s, p) => s + p[j], 0) / n);
    const xr = c.map((v, j) => 2 * v - S[n][j]), fr = f(xr); evaluations++;
    if (fr < F[0]) {
      const xe = c.map((v, j) => 3 * v - 2 * S[n][j]), fe = f(xe); evaluations++;
      if (fe < fr) { S[n] = xe; F[n] = fe; } else { S[n] = xr; F[n] = fr; }
    } else if (fr < F[n - 1]) { S[n] = xr; F[n] = fr; }
    else {
      const xc = fr < F[n] ? c.map((v, j) => v + 0.5 * (xr[j] - v)) : c.map((v, j) => v + 0.5 * (S[n][j] - v)), fc = f(xc); evaluations++;
      if (fc < min(fr, F[n])) { S[n] = xc; F[n] = fc; }
      else for (let k = 1; k <= n; k++) { S[k] = S[k].map((v, j) => S[0][j] + 0.5 * (v - S[0][j])); F[k] = f(S[k]); evaluations++; }
    }
  }
  return {x: S[0], L: F[0], evaluations};
}

// Profile in kappa: for a fixed kappa the model is linear in (v0, theta), a 2x2 weighted least squares.
function profile(kappa) {
  let a11 = 0, a12 = 0, a22 = 0, b1 = 0, b2 = 0;
  T.forEach((t, i) => { const u = g(kappa * t) / 100 / half[i], v = (1 - g(kappa * t)) / 100 / half[i], y = mid[i] / half[i];
    a11 += u * u; a12 += u * v; a22 += v * v; b1 += u * y; b2 += v * y; });
  const det = a11 * a22 - a12 * a12, x = [(b1 * a22 - b2 * a12) / det, (a11 * b2 - a12 * b1) / det, kappa], r = residuals(x);
  return {x, L: objective(x), maxResidual: max(...r.map(abs)), vol10y: 100 * sqrt(model(x, 10))};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • residual หารด้วยครึ่งส่วนต่าง bid–ask และ $L=\tfrac12\sum r_i^2$ มาจากการสมมติเสียงรบกวนปกติ residual ไม่เกิน 1 คือราคาอยู่ใน bid–ask ส่วน RMSE เป็นเงินให้ option ราคาสูงคุมผล
  • Gauss–Newton แก้ $J^{\top}J\delta=-J^{\top}r$ ทุกก้าว ลู่เข้าเร็วแต่ก้าวเกินได้ (ก้าวที่สองทำให้ $L$ ขึ้นจาก 10.17 เป็น 20.01) Levenberg–Marquardt เติม $\lambda I$ แล้วถึง 0.151839 ใน 6 รอบโดยไม่มีก้าวที่ถูกปฏิเสธ
  • gradient descent ช้าตามอัตราส่วนความโค้ง (100.1 ใช้ 260 ก้าว) BFGS เรียนความโค้งจาก $H_{k+1}y_k=s_k$ ใช้ 16 รอบ Nelder–Mead ใช้แค่ค่า $L$ 173 ครั้ง grid search ใช้ 1,331 ครั้งและยังละเอียดได้แค่ช่องของมัน
  • หน่วยของตัวแปรกับการแปลง $\ln\kappa$ เปลี่ยนอัตราส่วนความโค้งจาก 318,091 เป็น 100.1 และเปลี่ยน 100 รอบที่ติดขอบเป็น 15 รอบที่ถึงคำตอบ
  • ข้อมูลห้าจุดบอก $\kappa$ ได้แค่ 1.41 ถึง 2.52 ทุกค่าผ่าน bid–ask แต่ variance swap 10 ปีต่างกัน 19.67% ถึง 21.13% ต้องรายงานช่วง ไม่ใช่ตัวเลขเดียว
