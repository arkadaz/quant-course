8.3 Zero Covariance ≠ Independence

covariance เป็น 0 แปลว่าไม่มีแนวโน้มแบบเส้นตรง ไม่ได้แปลว่ารู้ตัวหนึ่งแล้วไม่ช่วยบอกอะไรเกี่ยวกับอีกตัว

ธนาคารแบ่งงานซื้อขายออกเป็นหลาย book (book คือกลุ่มสถานะซื้อขายที่ทีมหนึ่งดูแล และคิดกำไรขาดทุนรวมกัน) ทุกเย็น ระบบความเสี่ยงจะวัดว่าแต่ละ book ขยับตามตลาดแค่ไหน ตัวเลขที่ใช้คือ correlation ซึ่งเป็นตัวเลขระหว่าง −1 ถึง 1 บอกว่าสองอย่างขึ้นลงตามกันเป็นเส้นตรงแค่ไหน ถ้าได้ 0 แปลว่าไม่มีแนวโน้มแบบเส้นตรงเลย

วันนี้ระบบรายงานว่า book หนึ่งมี correlation กับตลาดเป็น 0 พอดี ผู้จัดการจึงจัด book นี้ไว้ในกลุ่ม “ความเสี่ยงที่ไม่ขึ้นกับตลาด” ของที่รู้เกี่ยวกับ book นี้ (ตัวเลขสมมติ):

  • shock ของตลาดในหนึ่งวัน $X$ คือตลาดขึ้นหรือลงวันนั้นแรงแค่ไหน นับเป็นจำนวน SD (standard deviation คือขนาดการแกว่งตามปกติ) เช่น $X=2$ คือตลาดขึ้นแรง 2 SD และ $X=-2$ คือลงแรง 2 SD
  • $X$ เป็น standard Normal คือกระจายเป็นรูประฆังคว่ำ ค่าเฉลี่ย 0 และ SD 1
  • กำไรขาดทุนของ book ในวันนั้น $\Pi=1000(1-X^2)$ ดอลลาร์

ลองแทนค่าวันที่ตลาดขึ้นแรงและวันที่ตลาดลงแรง:

\[\begin{aligned}X=2:\quad\Pi&=1000(1-2^2)=-\$3{,}000,\\X=-2:\quad\Pi&=1000\big(1-(-2)^2\big)=-\$3{,}000.\end{aligned}\]

book ขาดทุนเท่ากันทั้งสองทาง แต่ระบบบอกว่าไม่ขึ้นกับตลาด รายงานผิด หรือการตีความผิด?

ลองตอบก่อนเปิดเฉลย

รายงานถูก แต่การตีความผิด correlation ของ $X$ กับ $\Pi$ เป็น 0 จริง เพราะวันที่ตลาดขึ้นกับวันที่ตลาดลงหักล้างกันพอดี หน้านี้จะแสดงว่าหักล้างกันอย่างไร แต่ book นี้ผูกกับขนาดของ shock แน่นมาก มันขาดทุนทุกวันที่ตลาดขยับเกิน 1 SD ไม่ว่าขึ้นหรือลง เพราะ $1-X^2\lt0$ เมื่อ $|X|\gt1$ ขั้นสุดท้ายของหน้าจะคำนวณให้ดูว่าวันแบบนี้เกิด 31.73% ของวัน และกำไรขาดทุนแกว่งด้วย SD ประมาณ \$1,414

รูปร่างนี้คล้าย book ที่ขาย option ทั้งฝั่งขึ้นและฝั่งลงแล้ว hedge delta ไว้ การขาย option คือรับเงินล่วงหน้า แลกกับต้องจ่ายเมื่อราคาขยับแรง ส่วน hedge delta คือซื้อขายหุ้นชดเชย จนการขยับเล็ก ๆ ไม่ว่าทิศไหนแทบไม่กระทบกำไรขาดทุน (ดู Delta Hedging P&L) ความเสี่ยงของ book แบบนี้จึงอยู่ที่ตลาดขยับแรงแค่ไหน ไม่ใช่ขยับไปทางไหน สูตร $\Pi$ เป็นตัวเลขสมมติที่ตั้งไว้ให้เห็นกลไกชัด ๆ ไม่ใช่สูตรของ option จริง

ภาพรวมก่อนลงสูตร

เริ่มจากทวนว่า covariance วัดอะไร (ดู The Mean Vector and the Covariance Matrix) ให้ $\mu_X$ และ $\mu_Y$ เป็นค่าเฉลี่ยของ $X$ และ $Y$ วิธีคิดคือเอาระยะที่สองตัวเบี่ยงจากค่าเฉลี่ยมาคูณกัน แล้วหาค่าเฉลี่ยของผลคูณ:

\[\operatorname{Cov}(X,Y)=\mathbb E\big[(X-\mu_X)(Y-\mu_Y)\big].\]

ถ้าสองตัวขึ้นลงตามกันเป็นเส้นตรง วันที่ $X$ สูงกว่าเฉลี่ย $Y$ ก็มักสูงกว่าเฉลี่ย ผลคูณส่วนใหญ่จึงเป็นบวก และ covariance จับได้ แต่ถ้าความสัมพันธ์เป็นรูปตัว U ฝั่งซ้ายของตัว U ให้ผลคูณเครื่องหมายหนึ่ง ฝั่งขวาให้อีกเครื่องหมาย ค่าเฉลี่ยจึงหักล้างกันจนเหลือ 0 ได้ correlation คือ covariance ที่ปรับสเกลให้อยู่ระหว่าง −1 ถึง 1 ถ้าตัวหนึ่งเป็น 0 อีกตัวก็เป็น 0 ด้วย

independence (การอิสระกัน) ถามคำถามที่ใหญ่กว่ามาก: รู้ค่าของตัวหนึ่งแล้ว distribution ของอีกตัวเปลี่ยนไหม (distribution คือคำบอกว่าแต่ละค่ามีโอกาสเกิดแค่ไหน) จะตอบว่า “ไม่เปลี่ยน” ได้ ต้องจริงกับทุกเหตุการณ์ ผ่านการตรวจผลคูณแค่ครั้งเดียวไม่พอ ดังนั้นทิศทางหนึ่งใช้ได้เสมอ คือถ้าอิสระกัน covariance จะเป็น 0 แต่ทิศย้อนกลับใช้ไม่ได้ทั่วไป covariance เป็น 0 ยังไม่แปลว่าอิสระกัน

หน้านี้จะเห็นเรื่องนี้สามแบบ:

  • ตัวอย่างห้าค่าที่นับด้วยมือได้
  • $X$ เป็น Normal และ $Y=X^2$
  • คู่ที่แต่ละตัวเป็น Normal เมื่อดูแยก แต่รวมกันไม่ใช่ Normal สองมิติ

จากนั้นจะดูว่าเมื่อไร covariance 0 จึงสรุปว่าอิสระได้จริง แล้วกลับไปวัดความเสี่ยงของ book ในคำถามเปิดให้ถูกวิธี

ขั้นที่ 1 — independence ให้ผลคูณแยกได้กับทุกฟังก์ชัน covariance ตรวจแค่ฟังก์ชันเดียว

ก่อนดูตัวอย่าง ต้องเห็นก่อนว่าคำว่า “อิสระกัน” เรียกร้องอะไรบ้าง และ covariance 0 ตรวจแค่ส่วนไหนของมัน นิยามของ independence คือโอกาสที่ $X\le a$ และ $Y\le b$ พร้อมกัน เท่ากับโอกาสรายตัวคูณกัน และต้องจริงกับทุกค่า $a,\ b$ ผลที่ตามมาซึ่งใช้งานบ่อยคือ ค่าเฉลี่ยของผลคูณแยกเป็นผลคูณของค่าเฉลี่ยได้ ไม่ว่าจะใส่ฟังก์ชันอะไรเข้าไป (ดู consequences of independence) ส่วน covariance ใช้สูตรลัด $\operatorname{Cov}(X,Y)=\mathbb E[XY]-\mathbb E[X]\,\mathbb E[Y]$ ซึ่งได้จากการกระจายวงเล็บในนิยาม $\mathbb E[(X-\mu_X)(Y-\mu_Y)]$

\[ \begin{aligned} P(X\le a,\ Y\le b)&=P(X\le a)\,P(Y\le b),\\ \mathbb E[f(X)\,g(Y)]&=\mathbb E[f(X)]\,\mathbb E[g(Y)],\\ f(x)=x,\ g(y)=y:\quad\mathbb E[XY]&=\mathbb E[X]\,\mathbb E[Y],\\ \operatorname{Cov}(X,Y)&=\mathbb E[XY]-\mathbb E[X]\mathbb E[Y]\\ &=0. \end{aligned} \]

อิสระกันเป็นเงื่อนไขที่ใหญ่มาก ผลคูณต้องแยกได้กับทุกค่า $a,\ b$ และกับทุกคู่ฟังก์ชัน $f,\ g$ ที่หาค่าเฉลี่ยได้ นับรวมเป็นสมการไม่รู้จบ covariance 0 คือการตรวจสมการเดียวในนั้น คือกรณีที่เลือก $f(x)=x$ และ $g(y)=y$ ผ่านข้อเดียวจึงยังสรุปไม่ได้ว่าผ่านทุกข้อ

ในทางกลับกัน ถ้าเจอฟังก์ชันคู่เดียว หรือเหตุการณ์คู่เดียว ที่ผลคูณแยกไม่ได้ ก็พิสูจน์ได้ทันทีว่าไม่อิสระ ขั้นต่อไปจะทำแบบนี้ให้ดู ส่วนแบบโอกาสกับแบบฟังก์ชันเป็นเรื่องเดียวกัน เพราะถ้าเลือก $f$ เป็นฟังก์ชันที่ให้ 1 เมื่อ $x\le a$ และให้ 0 เมื่อไม่ใช่ ค่าเฉลี่ยของ $f(X)$ ก็คือ $P(X\le a)$ พอดี

ขั้นที่ 2 — ห้าค่าที่ covariance เป็นศูนย์ แต่รู้ $X$ แล้วรู้ $Y$ ทันที

ตอนนี้ลองสร้างคู่ที่ไม่อิสระกันอย่างชัดที่สุด แล้วดูว่า covariance จับได้ไหม ให้ $X$ รับค่า $-2,\ -1,\ 0,\ 1,\ 2$ อย่างละ $1/5$ เหมือนจับฉลากห้าใบ และให้ $Y=X^2$ ดังนั้น $Y$ ถูกกำหนดโดย $X$ ทั้งหมด นี่คือ distribution ที่ตั้งไว้แน่นอน ไม่ใช่ข้อมูลห้าวันที่ต้องเอามาประมาณค่า จึงหาค่าเฉลี่ยโดยถ่วงด้วยโอกาส $1/5$ ไม่ต้องหารด้วย (จำนวนข้อมูล − 1) แบบที่ใช้กับข้อมูลตัวอย่าง

ดูด้วยโอกาสก็เห็นเหมือนกัน ตอนยังไม่รู้อะไร $Y=1$ เกิดเมื่อ $X=-1$ หรือ $X=1$ จึงมีโอกาส $P(Y=1)=2/5=40\%$ แต่ถ้ารู้แล้วว่า $X=1$ ก็ได้ $Y=1$ แน่นอน คือ $P(Y=1\mid X=1)=1$ ข้อมูลเรื่อง $X$ ทำให้โอกาสของ $Y$ เปลี่ยนจาก 40% เป็น 100%

สองบรรทัดล่างของสูตรใช้สูตรลัด $\operatorname{Var}(Z)=\mathbb E[Z^2]-(\mathbb E[Z])^2$ และ $Y^2=X^4$ ทั้งสองตัวมี variance เป็นบวก correlation (covariance หารด้วยผลคูณของ SD) จึงหาได้จริงและเท่ากับ 0 นี่ไม่ใช่กรณีพิเศษที่ correlation หาค่าไม่ได้

ขั้นที่ 3 — การคูณ marginal probability ผิดได้ทั้งสองทาง

งานความเสี่ยงมักต้องการโอกาสที่สองเรื่องร้ายเกิดพร้อมกัน วิธีลัดที่เห็นบ่อยคือเอาโอกาสรายตัวมาคูณกัน วิธีนี้ถูกเฉพาะเมื่ออิสระกัน ขั้นนี้ดูว่าวิธีลัดพลาดแค่ไหน เมื่อ covariance เป็น 0 แต่ไม่อิสระ

โจทย์ให้อะไรมาบ้าง: ใช้ห้าค่าเดิม ต้องการโอกาสที่ $X\le-1$ และ $Y\ge4$ เกิดพร้อมกัน นับจากของจริงก่อน แล้วเทียบกับคำตอบที่ได้จากการสมมติว่าอิสระ การนับทำแบบนี้:

  • $X\le-1$ เกิดเมื่อ $X=-2$ หรือ $X=-1$ คือสองค่าจากห้า
  • $Y\ge4$ เกิดเมื่อ $X=-2$ หรือ $X=2$ คือสองค่าจากห้า
  • ทั้งสองเรื่องเกิดพร้อมกันได้เมื่อ $X=-2$ เท่านั้น
\[ \begin{aligned} P(X\le-1)&=2/5=0.40,\\ P(Y\ge4)&=2/5=0.40,\\ P(X\le-1)\,P(Y\ge4)&=0.40\times0.40=0.16,\\ P(X\le-1,\ Y\ge4)&=P(X=-2)=0.20. \end{aligned} \]

คำตอบ: ของจริงคือ 20% ส่วนการคูณได้ 16% ห่างกัน $20\%-16\%=4$ จุดเปอร์เซ็นต์ ถ้าจะบอกเป็นสัดส่วน ต้องระวังว่าใช้อะไรเป็นฐาน:

\[ \begin{aligned} \frac{0.20-0.16}{0.16}&=0.25,\\ \frac{0.20-0.16}{0.20}&=0.20. \end{aligned} \]

ถ้าใช้ค่าที่คูณได้เป็นฐาน ของจริงสูงกว่า 25% ถ้าใช้ของจริงเป็นฐาน การคูณประเมินต่ำไป 20% สองประโยคนี้พูดถึงช่องว่างเดียวกัน แต่ใช้ฐานต่างกัน

ตรวจเองใน 10 วินาที: ถ้ารู้แล้วว่า $X\le-1$ จะเหลือสองค่าที่เป็นไปได้ คือ −2 กับ −1 ในสองค่านี้มีแค่ −2 ที่ให้ $Y\ge4$ ดังนั้น $P(Y\ge4\mid X\le-1)=1/2$ ซึ่งไม่เท่ากับโอกาสตอนยังไม่รู้อะไร $P(Y\ge4)=2/5$ ถ้าอิสระกัน สองค่านี้ต้องเท่ากัน

ลองทำแบบเดียวกันกับเหตุการณ์อีกสองคู่ ตารางนี้เทียบโอกาสจริงกับผลคูณของโอกาสรายตัว:

คู่เหตุการณ์โอกาสร่วมจริงผลคูณ marginal
$X\le-1,\ Y\ge4$0.200.16
$X\le-1,\ Y\le1$0.200.24
$X\le-2,\ Y\ge4$0.200.08

ตัวเลขในสองแถวล่างนับแบบเดียวกัน $Y\le1$ เกิดเมื่อ $X=-1,\ 0,\ 1$ (สามในห้า) และ $X\le-2$ เกิดเมื่อ $X=-2$ (หนึ่งในห้า) ส่วนโอกาสจริงของทั้งสองคู่คือ 0.20 เพราะแต่ละคู่เกิดพร้อมกันได้จากค่าเดียว คือ $X=-1$ และ $X=-2$ ตามลำดับ

\[ \begin{aligned} P(X\le-1)\,P(Y\le1)&=0.40\times0.60=0.24,\\ P(X\le-2)\,P(Y\ge4)&=0.20\times0.40=0.08. \end{aligned} \]

แถวที่สองกลับด้าน การคูณได้ 0.24 ซึ่งสูงกว่าของจริง 0.20 จึงไม่มีกฎว่าการสมมติว่าอิสระจะประเมินความเสี่ยงต่ำไปเสมอ แถวที่สามดูลึกลงไปในหาง (เหตุการณ์สุดโต่งที่เกิดยาก) ของจริงสูงกว่าค่าคูณถึง $0.20/0.08=2.5$ เท่า ข้อสรุปคือ ต้องคำนวณเหตุการณ์ที่สนใจจากของจริงทุกครั้ง อย่าคูณโอกาสรายตัวเอาเอง

ขั้นที่ 4 — เปลี่ยนเป็น Normal การหักล้างยังอยู่

ตัวอย่างห้าค่าอาจดูจงใจเกินไป ลองกับ distribution ที่ใช้จริงในงานการเงิน ให้ $X$ เป็น standard Normal เหมือน shock ของตลาดในคำถามเปิด และให้ $Y=X^2$ ซึ่งไม่ใช่ Normal เพราะติดลบไม่ได้ ต้องการรู้ว่า covariance ของสองตัวนี้เป็นเท่าไร

ใช้สูตรลัดจากขั้นที่ 1: $\operatorname{Cov}(X,X^2)=\mathbb E[X^3]-\mathbb E[X]\,\mathbb E[X^2]$ ค่าที่รู้แล้วคือ $\mathbb E[X]=0$ และ $\mathbb E[X^2]=\operatorname{Var}(X)+0^2=1$ จึงเหลือต้องหาแค่ $\mathbb E[X^3]$ ซึ่งคือพื้นที่ใต้กราฟ $x^3\phi(x)$

\[ \begin{aligned} \phi(x)&=\frac1{\sqrt{2\pi}}e^{-x^2/2},\qquad\phi(-x)=\phi(x),\\ \mathbb E[X^3]&=\int_{-\infty}^{\infty}x^3\phi(x)\,dx=0,\\ \operatorname{Cov}(X,X^2)&=0-0\times1=0. \end{aligned} \]

กราฟ $x^3\phi(x)$ เป็น odd function (ฟังก์ชันคี่) คือแทน $x$ ด้วย $-x$ แล้วได้ค่าเดิมแต่ติดลบ เพราะ $(-x)^3=-x^3$ ขณะที่ $\phi(-x)=\phi(x)$ (รูประฆังสมมาตร) พื้นที่ฝั่งขวากับฝั่งซ้ายจึงขนาดเท่ากัน แต่เครื่องหมายตรงข้าม รวมกันได้ 0

ข้อที่ต้องระวังคือ การหักล้างนี้ใช้ได้เพราะหางของ Normal บางพอ พื้นที่แต่ละฝั่งจึงมีค่าจำกัด หาได้ด้วย $\phi'(x)=-x\phi(x)$ (หาอนุพันธ์ของ $e^{-x^2/2}$ ตรง ๆ) แล้ว integrate by parts:

\[ \begin{aligned} \int_0^{\infty}x^3\phi(x)\,dx&=\big[-x^2\phi(x)\big]_0^{\infty}\\ &\quad+2\int_0^{\infty}x\phi(x)\,dx\\ &=0+2\phi(0)=\frac{2}{\sqrt{2\pi}}\approx0.80. \end{aligned} \]

ส่วน $\int_0^\infty x\phi(x)\,dx=\big[-\phi(x)\big]_0^\infty=\phi(0)$ ใช้เคล็ดเดียวกัน ถ้าเป็น distribution ที่หางหนามาก จนพื้นที่แต่ละฝั่งเป็นอนันต์ ผลรวมจะกลายเป็น $\infty-\infty$ ซึ่งไม่มีค่า เหตุผลเรื่องสมมาตรจึงใช้สรุปว่าได้ 0 ไม่ได้

covariance เป็น 0 แต่ $X$ กับ $Y$ ไม่อิสระกัน ดูได้จากเหตุการณ์คู่เดียว ถ้ารู้ว่า $|X|\le0.5$ ก็รู้แน่ว่า $Y=X^2\le0.25$ ซึ่งน้อยกว่า 1 ดังนั้น $P(Y\le1\mid |X|\le0.5)=1$ แต่ถ้ายังไม่รู้อะไรเลย $Y\le1$ เกิดเมื่อ $-1\le X\le1$ ใช้ $\Phi(-1)=1-\Phi(1)$ จากความสมมาตร และ $\Phi(1)\approx0.84134$ จากตาราง Normal:

\[ \begin{aligned} P(Y\le1)&=\Phi(1)-\Phi(-1)\\ &=2\Phi(1)-1\\ &\approx2\times0.84134-1=0.6827. \end{aligned} \]

ข้อมูลเรื่อง $X$ เปลี่ยนโอกาสจากประมาณ 68% เป็น 100% สองตัวนี้จึงไม่อิสระกัน

หา variance ของ $Y=X^2$ ให้ครบ

ขั้นสุดท้ายของหน้าต้องใช้ variance ของ $Y=X^2$ จึงหาไว้ตรงนี้ ต้องหา $\mathbb E[X^4]$ (เรียกว่า fourth moment) ก่อน เคล็ดคือเขียน $x^4\phi(x)=-x^3\phi'(x)$ จาก $\phi'(x)=-x\phi(x)$ แล้ว integrate by parts พจน์ขอบ $x^3\phi(x)$ เป็น 0 ที่ $\pm\infty$ เพราะ $\phi$ ลดลงเร็วกว่าพหุนามทุกตัว ส่วนที่เหลือคือ $3\,\mathbb E[X^2]=3$ จึงได้ fourth moment ของ Normal distribution เท่ากับ 3

\[ \begin{aligned} \mathbb E[X^4]&=-\int_{-\infty}^{\infty}x^3\phi'(x)\,dx\\ &=\big[-x^3\phi(x)\big]_{-\infty}^{\infty}\\ &\quad+3\int_{-\infty}^{\infty}x^2\phi(x)\,dx\\ &=0+3\times1=3,\\ \operatorname{Var}(Y)&=\mathbb E[X^4]-(\mathbb E[X^2])^2=3-1=2. \end{aligned} \]

ขั้นที่ 5 — เส้นตรงมองไม่เห็นอะไรเลย แต่เส้นโค้งเห็นทุกอย่าง

ในงานจริง covariance มักถูกใช้ผ่าน regression เส้นตรง คือใช้ $X$ ทำนาย $Y$ ด้วยเส้นตรง ขั้นนี้ดูว่าเส้นตรงที่ดีที่สุดทำนาย $Y=X^2$ ได้แค่ไหน เมื่อ $X$ เป็น standard Normal ค่าที่หาไว้แล้วในขั้นที่ 4 คือ $\mathbb E[Y]=\mathbb E[X^2]=1$ และ $\operatorname{Var}(Y)=2$

ตัวทำนายแบบเส้นตรงเขียนว่า $a+bX$ โดย $a$ คือจุดตัดแกน และ $b$ คือ slope เส้นที่ดีที่สุดคือเส้นที่ทำให้ค่าเฉลี่ยของความผิดยกกำลังสอง $\mathbb E[(Y-a-bX)^2]$ ต่ำสุด เส้นนั้นมี slope เท่ากับ covariance หารด้วย variance ของ $X$ (ที่มาอยู่ในกล่องท้ายขั้นนี้) ที่นี่ covariance เป็น 0 slope จึงเป็น 0 และเส้นที่ดีที่สุดคือเส้นราบที่ระดับค่าเฉลี่ย $\mathbb E[Y]=1$ ส่วนตัวทำนายแบบโค้ง $X^2$ ทำนายถูกทุกครั้ง

\[ \begin{aligned} b_*&=\frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(X)}=0,\qquad a_*=\mathbb E[Y]=1,\\ \mathbb E[(Y-1)^2]&=\operatorname{Var}(Y)=2,\\ \mathbb E[(Y-X^2)^2]&=0. \end{aligned} \]

เส้นตรงผิดเฉลี่ย (ยกกำลังสอง) เท่ากับ 2 คือผิดเต็มขนาดการแกว่งของ $Y$ เหมือนไม่ได้ใช้ $X$ เลย ส่วนเส้นโค้ง $X^2$ ผิดเป็น 0 สาเหตุไม่ใช่เพราะ $X$ ไม่มีข้อมูลเกี่ยวกับ $Y$ แต่เพราะเครื่องมือมองเห็นแค่ส่วนที่เป็นเส้นตรง ทั้ง covariance และ regression เส้นตรงวัดได้เฉพาะส่วนนั้น

ข้อสรุปนี้ยังอยู่แม้ใส่ noise ให้เหมือนข้อมูลจริง ให้ $Y=X^2+\varepsilon$ โดย noise $\varepsilon$ อิสระจาก $X$ มีค่าเฉลี่ย 0 และ variance $\tau^2$ เช่น noise ที่มี SD 0.08 ในรูปถัดไป ซึ่งให้ $\tau^2=0.08^2=0.0064$ เพราะ $\varepsilon$ อิสระจาก $X$ จึงมี covariance กับ $X$ และ $X^2$ เป็น 0 และ variance ของผลบวกเท่ากับผลบวกของ variance:

\[ \begin{aligned} \operatorname{Cov}(X,Y)&=\operatorname{Cov}(X,X^2)+\operatorname{Cov}(X,\varepsilon)\\ &=0+0=0,\\ \mathbb E[(Y-1)^2]&=\operatorname{Var}(Y)=2+\tau^2,\\ \mathbb E[(Y-X^2)^2]&=\mathbb E[\varepsilon^2]=\tau^2,\\ \operatorname{Corr}(X^2,Y)&=\frac{\operatorname{Cov}(X^2,Y)}{\operatorname{SD}(X^2)\,\operatorname{SD}(Y)}\\ &=\frac{2}{\sqrt2\,\sqrt{2+\tau^2}}=\sqrt{\frac{2}{2.0064}}\\ &\approx0.998. \end{aligned} \]

covariance กับ $X$ ยังเป็น 0 เส้นตรงจึงยังเป็นเส้นราบที่ 1 และผิด $2+\tau^2$ ส่วนเส้นโค้งผิดแค่ $\tau^2$ ซึ่งคือ noise ที่ไม่มีใครทำนายได้ ตัวเลขบรรทัดสุดท้ายใช้ $\operatorname{Cov}(X^2,Y)=\operatorname{Var}(X^2)=2$ เพราะ noise ไม่ผูกกับ $X^2$ ข้อมูลชุดเดียวกัน วัดด้วย $X$ ได้ correlation 0 แต่วัดด้วย $X^2$ ได้ 0.998 ทุกอย่างขึ้นกับว่าเลือกตัวแปรไหนมาวัด

ทำไม slope ที่ดีที่สุดคือ covariance หารด้วย variance
\[ \begin{aligned} L(a,b)&:=\mathbb E[(Y-a-bX)^2]\\ &=\sigma_Y^2+b^2\sigma_X^2-2b\operatorname{Cov}(X,Y)\\ &\quad+(\mu_Y-a-b\mu_X)^2,\\ a_*&=\mu_Y-b_*\mu_X,\\ b_*&=\operatorname{Cov}(X,Y)/\sigma_X^2. \end{aligned} \]

เคล็ดคือแยกความผิดออกเป็นสามก้อน $Y-a-bX=(Y-\mu_Y)-b(X-\mu_X)+(\mu_Y-a-b\mu_X)$ แล้วยกกำลังสองและหาค่าเฉลี่ย พจน์ไขว้ที่มีก้อนสุดท้ายหายไป เพราะระยะเบี่ยงจากค่าเฉลี่ยมีค่าเฉลี่ยเป็น 0 ก้อนสุดท้ายทำให้เป็น 0 ได้ด้วยการเลือก $a$ ที่เหลือเป็นพาราโบลาของ $b$ ซึ่งต่ำสุดเมื่ออนุพันธ์ $2b\sigma_X^2-2\operatorname{Cov}(X,Y)$ เป็น 0 คือที่ $b_*$ ผลเดียวกันนี้จะกลับมาอีกครั้งใน OLS regression

ขั้นที่ 6 — Normal ทีละตัว ยังไม่ใช่ jointly Normal

หลายคนจำกฎมาว่า “ถ้าทั้งสองตัวเป็น Normal และ correlation เป็น 0 ก็อิสระกัน” กฎนี้ขาดเงื่อนไขสำคัญไปหนึ่งข้อ ตัวอย่างต่อไปนี้แสดงว่าขาดอะไร

ให้ $X$ เป็น standard Normal และให้ $W$ เป็นเครื่องหมายสุ่ม $+1$ หรือ $-1$ อย่างละครึ่ง เหมือนโยนเหรียญ โดย $W$ อิสระจาก $X$ แล้วกำหนด $Y=WX$ คือเอา $X$ มาสุ่มกลับเครื่องหมาย สิ่งที่ต้องตรวจมีสามข้อ: $Y$ เป็น Normal จริงไหม covariance เป็นเท่าไร และ $Y$ ผูกกับ $X$ อย่างไร

\[ \begin{aligned} P(Y\le y)&=\tfrac12P(X\le y)+\tfrac12P(-X\le y)\\ &=\tfrac12\Phi(y)+\tfrac12\Phi(y)=\Phi(y),\\ \operatorname{Cov}(X,Y)&=\mathbb E[WX^2]\\ &=\mathbb E[W]\,\mathbb E[X^2]=0\times1=0,\\ |Y|&=|W|\,|X|=|X|. \end{aligned} \]

ข้อแรก $Y$ เป็น standard Normal จริง ไม่ใช่แค่ดูคล้าย เคล็ดคือแยกกรณีตามเหรียญ ถ้า $W=+1$ ได้ $Y=X$ ถ้า $W=-1$ ได้ $Y=-X$ และ $-X$ มี distribution เดียวกับ $X$ เพราะรูประฆังสมมาตร ทั้งสองกรณีจึงให้ $\Phi(y)$ เหมือนกัน

ข้อสอง covariance เป็น 0 เพราะ $W$ อิสระจาก $X$ ค่าเฉลี่ยของ $WX^2$ จึงแยกเป็น $\mathbb E[W]\,\mathbb E[X^2]$ ได้ และ $\mathbb E[W]=\tfrac12(+1)+\tfrac12(-1)=0$

ข้อสาม $|Y|=|X|$ เสมอ เพราะการกลับเครื่องหมายไม่เปลี่ยนขนาด ข้อนี้ทำให้ไม่อิสระกัน ลองดูเหตุการณ์ “ขนาดไม่เกิน 1” ของทั้งสองตัว ใช้ $P(|X|\le1)=0.6827$ จากขั้นที่ 4:

\[ \begin{aligned} P(|X|\le1,\ |Y|\le1)&=P(|X|\le1)=0.6827,\\ P(|X|\le1)\,P(|Y|\le1)&=0.6827^2\approx0.4661. \end{aligned} \]

ถ้าอิสระกัน สองค่านี้ต้องเท่ากัน แต่ไม่เท่า เพราะเหตุการณ์ $|Y|\le1$ คือเหตุการณ์เดียวกับ $|X|\le1$ ทุกประการ

ทำไมกฎที่จำมาจึงใช้ไม่ได้ เพราะคู่นี้ไม่ jointly Normal คือแต่ละตัวเป็น Normal เมื่อดูแยก แต่รวมกันไม่ใช่ Normal สองมิติ ตรวจได้จากสมบัติหนึ่งของ jointly Normal: ผลบวกของสองตัวต้องเป็น Normal ด้วย ซึ่งที่นี่ต้องมี variance $\operatorname{Var}(X)+\operatorname{Var}(Y)+2\operatorname{Cov}(X,Y)=1+1+0=2$ แต่

\[X+Y=X+WX=(1+W)X,\]

ทุกครั้งที่เหรียญออก $W=-1$ ผลบวกเป็น 0 พอดี จึงมีโอกาส 50% ที่ผลบวกเท่ากับ 0 เป๊ะ Normal ที่มี variance 2 ให้โอกาสกับค่าใดค่าหนึ่งเป๊ะ ๆ เป็น 0 เสมอ จึงเป็นไปไม่ได้ จุดทั้งหมดอยู่บนสองเส้น คือ $y=x$ กับ $y=-x$ เป็นรูปกากบาทตามรูปด้านล่าง

ขั้นที่ 7 — เมื่อไร covariance ศูนย์จึงแปลว่าอิสระ

ขั้นก่อน ๆ แสดงว่า covariance 0 อย่างเดียวไม่พอ ขั้นนี้ดูว่าต้องมีเงื่อนไขอะไรเพิ่ม เงื่อนไขที่ใช้บ่อยที่สุดคือ jointly Normal ถ้าทั้งคู่เป็น multivariate Normal แล้ว covariance 0 จะทำให้ density ร่วมแยกเป็นผลคูณได้

ดูกรณีสองตัวที่ SD เป็นบวก ให้ $u=(x-\mu_X)/\sigma_X$ และ $v=(y-\mu_Y)/\sigma_Y$ คือระยะจากค่าเฉลี่ยนับเป็นจำนวน SD density ของ Normal สองมิติมีหน้าตาตามบรรทัดแรกด้านล่าง (ที่มาของสูตรอยู่ในหน้า The Multivariate Normal Density) โดย $\rho$ คือ correlation ของ $X$ กับ $Y$ จากนั้นแทน $\rho=0$

\[ \begin{aligned} f_{X,Y}(x,y)&=\frac{1}{2\pi\sigma_X\sigma_Y\sqrt{1-\rho^2}}\\ &\quad\times\exp\Big(-\frac{u^2-2\rho uv+v^2}{2(1-\rho^2)}\Big),\\ \rho=0:\quad f_{X,Y}(x,y)&=\frac{e^{-(u^2+v^2)/2}}{2\pi\sigma_X\sigma_Y}\\ &=\frac{e^{-u^2/2}}{\sqrt{2\pi}\,\sigma_X}\cdot\frac{e^{-v^2/2}}{\sqrt{2\pi}\,\sigma_Y}\\ &=f_X(x)\,f_Y(y). \end{aligned} \]

ใน density ของ Normal สองมิติ ความสัมพันธ์ทั้งหมดของ $X$ กับ $Y$ อยู่ในพจน์ $-2\rho uv$ ตัวเดียว พอ $\rho=0$ พจน์นี้หายไป ใน exponent เหลือ $u^2$ กับ $v^2$ แยกกัน และ $e$ ยกกำลังผลบวกแยกเป็นผลคูณได้ เพราะ $e^{s+t}=e^s\,e^t$ density ร่วมที่แยกเป็นผลคูณของ density รายตัว คือนิยามของอิสระกัน

ข้อควรระวังคือ เหตุผลนี้เริ่มจากการสมมติว่าเป็น jointly Normal ตั้งแต่ต้น จึงไม่ได้บอกอะไรเกี่ยวกับคู่ $X$ กับ $WX$ ในขั้นก่อน กรณีหลายตัวแปรก็เหมือนกัน ถ้าเป็น multivariate Normal และ covariance matrix เป็น identity (เลข 1 บนแนวทแยง เลข 0 ที่อื่น) ทุกตัวอิสระกัน

jointly Normal ไม่ใช่กรณีเดียว ตัวแปรที่มีแค่สองค่า (Bernoulli คือเป็น 0 หรือ 1 เช่นผิดนัดชำระหนี้หรือไม่ผิดนัด) ก็มีสมบัตินี้ ให้ $p=P(X=1)$ และ $q=P(Y=1)$ ผลคูณ $XY$ เป็น 1 ได้กรณีเดียว คือเมื่อทั้งสองตัวเป็น 1 ดังนั้น

\[ \begin{aligned} \mathbb E[XY]&=P(X=1,\ Y=1),\\ \operatorname{Cov}(X,Y)&=P(X=1,\ Y=1)-pq. \end{aligned} \]

ถ้า covariance เป็น 0 ช่อง $(1,1)$ ต้องเท่ากับ $pq$ ตารางนี้มีแค่สี่ช่อง และผลรวมแถวกับผลรวมคอลัมน์ถูกกำหนดด้วย $p$ กับ $q$ แล้ว อีกสามช่องจึงถูกบังคับไปด้วย:

\[ \begin{aligned} P(X=1,\ Y=0)&=p-pq=p(1-q),\\ P(X=0,\ Y=1)&=q-pq=(1-p)q,\\ P(X=0,\ Y=0)&=1-p-q+pq\\ &=(1-p)(1-q). \end{aligned} \]

นี่คือตารางของตัวแปรอิสระพอดี ข้อที่ควรจำจึงไม่ใช่ “Normal เท่านั้น” แต่คือ ต้องมีโครงสร้างที่ทำให้สมการเดียว (covariance เป็น 0) กำหนด joint distribution ได้ทั้งหมด

ขั้นที่ 8 — แบ่งตามขนาด shock แล้วดูค่าเฉลี่ยในแต่ละกลุ่ม

ในงานจริงเราไม่มีสูตรของ $Y$ มีแต่ข้อมูล ขั้นนี้แสดงวิธีตรวจที่ใช้กับข้อมูลได้ทันที คือแบ่งวันตามขนาดของ shock แล้วหาค่าเฉลี่ยของผลลัพธ์ในแต่ละกลุ่ม ถ้าค่าเฉลี่ยเปลี่ยนไปตามกลุ่ม แปลว่ามีความสัมพันธ์ แม้ covariance จะเป็น 0

โจทย์ให้อะไรมาบ้าง:

  • $X$ เป็น standard Normal และ $Y=X^2$ (ถ้าเป็น $X^2+\varepsilon$ ที่ noise อิสระและมีค่าเฉลี่ย 0 ค่าเฉลี่ยในแต่ละกลุ่มก็เท่าเดิม)
  • แบ่งขนาด shock $|X|$ เป็นสามกลุ่ม ด้วยจุดตัด $a=0.5$ และ $b=1.5$: กลุ่มเล็ก $|X|\lt a$ กลุ่มกลาง $a\le|X|\lt b$ และกลุ่มใหญ่ $|X|\ge b$
  • เรียกค่าเฉลี่ยของ $Y$ ในสามกลุ่มนี้ว่า $m_1,\ m_2,\ m_3$

ค่าเฉลี่ยในกลุ่ม $A$ คือพื้นที่ของ $x^2\phi(x)$ ในกลุ่มนั้น หารด้วยโอกาสของกลุ่ม พื้นที่หาได้จาก antiderivative ในบรรทัดที่สอง:

\[ \begin{aligned} \mathbb E[X^2\mid A]&=\frac{\int_A x^2\phi(x)\,dx}{P(A)},\\ \int x^2\phi(x)\,dx&=\Phi(x)-x\phi(x)+C. \end{aligned} \]

สูตรที่สองตรวจได้ด้วยการหาอนุพันธ์ ใช้ $\phi'(x)=-x\phi(x)$ จะได้ $\frac{d}{dx}\big[\Phi-x\phi\big]=\phi-\phi-x\phi'=x^2\phi$ ตรงกับสิ่งที่ต้องการ

ต่อไปแทนช่วงของแต่ละกลุ่ม กลุ่มเล็กคือช่วง $-a$ ถึง $a$ มีโอกาส $2\Phi(a)-1$ กลุ่มอื่นทำแบบเดียวกันทั้งสองฝั่ง โดยใช้ $\Phi(\infty)=1$ ค่าจากสูตร $\phi$ และตาราง Normal ที่ต้องใช้คือ $\phi(0.5)=0.35207$, $\Phi(0.5)=0.69146$, $\phi(1.5)=0.12952$ และ $\Phi(1.5)=0.93319$ ดังนั้น $a\phi(a)=0.17603$ และ $b\phi(b)=0.19428$

\[ \begin{aligned} m_1&=\frac{2\Phi(a)-1-2a\phi(a)}{2\Phi(a)-1}\\ &=1-\frac{a\phi(a)}{\Phi(a)-1/2}\\ &=1-\frac{0.17603}{0.19146}\approx0.0806,\\ m_2&=1+\frac{a\phi(a)-b\phi(b)}{\Phi(b)-\Phi(a)}\\ &=1+\frac{0.17603-0.19428}{0.24173}\approx0.9245,\\ m_3&=1+\frac{b\phi(b)}{1-\Phi(b)}\\ &=1+\frac{0.19428}{0.06681}\approx3.908. \end{aligned} \]

คำตอบ: ค่าเฉลี่ยของ $Y$ เพิ่มจาก 0.08 เป็น 0.92 และ 3.91 ตามขนาด shock อย่างชัดเจน ทั้งที่ covariance รวมของ $X$ กับ $Y$ เป็น 0 การแบ่งกลุ่มตาม $|X|$ แล้วดูค่าเฉลี่ยในกลุ่ม คือวิธีตรวจที่ใช้กับข้อมูลจริงได้ทันที

ตรวจเองใน 10 วินาที: ในกลุ่ม $|X|\lt0.5$ ทุกค่ามี $X^2\lt0.25$ ค่าเฉลี่ย 0.08 จึงเป็นไปได้ ในกลุ่ม $|X|\ge1.5$ ทุกค่ามี $X^2\ge1.5^2=2.25$ ค่าเฉลี่ย 3.91 ก็ผ่าน อีกข้อที่น่าสังเกตคือ ถ้าคำนวณ covariance ของ $X$ กับ $X^2$ เฉพาะวันที่ $|X|\gt2$ ก็ยังได้ 0 เพราะสองฝั่งยังสมมาตรเหมือนเดิม การดู “correlation ในหาง” (correlation ที่คำนวณเฉพาะวันที่ตลาดขยับแรง) จึงไม่ได้ช่วยเสมอไป ต้องแบ่งตามขนาดอย่างที่ทำในขั้นนี้

ขั้นที่ 9 — ตอบคำถามเปิด: วัดความเสี่ยงของ book ให้ถูกตัวแปร

ตอนนี้มีเครื่องมือครบแล้ว กลับมาที่ book ในคำถามเปิด กำไรขาดทุนคือ $\Pi=1000(1-X^2)$ ดอลลาร์ โดย $X$ คือ shock ของตลาดแบบ standard Normal สิ่งที่อยากรู้มีสี่อย่าง: ค่าเฉลี่ย covariance กับตลาด ขนาดการแกว่ง (SD) และโอกาสขาดทุน ค่าที่หาไว้แล้วในขั้นที่ 4 คือ $\mathbb E[X^2]=1$, $\operatorname{Cov}(X,X^2)=0$ และ $\operatorname{Var}(X^2)=2$ ส่วนเลข 1000 เป็นค่าคงที่ การบวกค่าคงที่ไม่เปลี่ยน variance และไม่เปลี่ยน covariance ส่วนการคูณด้วยค่าคงที่ $c$ ทำให้ covariance คูณด้วย $c$ และ variance คูณด้วย $c^2$

\[ \begin{aligned} \mathbb E[\Pi]&=1000(1-1)=0,\\ \operatorname{Cov}(X,\Pi)&=-1000\operatorname{Cov}(X,X^2)=0,\\ \operatorname{Var}(\Pi)&=(-1000)^2\operatorname{Var}(X^2)\\ &=1000^2\times2=2{,}000{,}000,\\ \operatorname{SD}(\Pi)&=1000\sqrt2\approx1{,}414.21,\\ P(\Pi\lt0)&=P(|X|\gt1)\\ &=2[1-\Phi(1)]\\ &\approx2(1-0.84134)\approx31.73\%. \end{aligned} \]

ค่าเฉลี่ยเป็น 0 และ covariance กับตลาดเป็น 0 ตรงตามที่ระบบรายงาน แต่กำไรขาดทุนแกว่งด้วย SD ประมาณ \$1,414 และขาดทุนเกือบหนึ่งในสามของวัน $\Pi\lt0$ เกิดเมื่อ $X^2\gt1$ คือตลาดขยับเกิน 1 SD ไม่ว่าทิศไหน โอกาสจึงเป็นหางสองข้างของรูประฆังรวมกัน

วิธีวัดที่ถูกคือใช้สองตัวแปรเป็นปัจจัยเสี่ยง (ตัวแปรที่ขับกำไรขาดทุน) คือ $X$ และ $X^2$ คู่นี้มีค่าเฉลี่ย $(0,\ 1)$ และ covariance matrix $\Sigma=\begin{bmatrix}1&0\\0&2\end{bmatrix}$ ตัวเลขทุกช่องมาจากขั้นที่ 4 ส่วน $\Pi=1000-1000X^2$ เป็นค่าคงที่บวกผลรวมถ่วงน้ำหนักของปัจจัยทั้งสอง ด้วยน้ำหนัก $w=(0,\ -1000)$ สูตร $w^{\mathsf T}\Sigma w$ ของความเสี่ยงพอร์ต จึงให้ $(-1000)^2\times2=2{,}000{,}000$ ตรงกับ $\operatorname{Var}(\Pi)$ ด้านบนทันที ปัญหาในคำถามเปิดจึงไม่ใช่ว่าสูตร covariance ใช้ไม่ได้ แต่คือการทิ้งพจน์กำลังสองไป แล้ววัดแค่ correlation กับ $X$

อะไรยังใช้ได้ และอะไรใช้ไม่ได้ เมื่อ covariance เป็นศูนย์

  • สูตร variance ของผลรวมยังใช้ได้: สูตรเต็มคือ $\operatorname{Var}(aX+bY)=a^2\operatorname{Var}(X)+b^2\operatorname{Var}(Y)+2ab\operatorname{Cov}(X,Y)$ ถ้า covariance เป็น 0 พจน์สุดท้ายก็หายไป แม้ $X,\ Y$ จะไม่อิสระกัน เช่นห้าค่าข้างบน $\operatorname{Var}(X+Y)=2+2.8=4.8$ ตรวจตรงจากค่า $X+Y$ ก็ได้ 4.8 เท่ากัน (ดูเฉลยโจทย์ข้อ 1)
  • คูณโอกาสไม่ได้: ความผิดคือเห็น covariance เป็น 0 แล้วคูณโอกาสรายตัว เพื่อหาโอกาสที่สองเรื่องเกิดพร้อมกัน ในตัวอย่างห้าค่า วิธีนี้ได้ $0.40\times0.40=0.16$ แต่ของจริงคือ 0.20 และในหางที่ลึกกว่าได้ $0.20\times0.40=0.08$ ทั้งที่ของจริงคือ 0.20
  • แต่ละตัวเป็น Normal ยังไม่พอ: ความผิดคือตรวจแค่ว่าแต่ละตัวเป็น Normal แล้วใช้กฎของ jointly Normal คู่ $X$ กับ $WX$ เป็น Normal ทั้งคู่ แต่ไม่ jointly Normal กฎ “Normal และ correlation 0 แปลว่าอิสระ” จะให้ $P(|X|\le1,\ |Y|\le1)=0.6827^2\approx0.4661$ แต่ของจริงคือ 0.6827
  • correlation จากข้อมูลที่ใกล้ 0 ไม่ใช่หลักฐาน: ความผิดคือเห็น sample correlation ใกล้ 0 แล้วสรุปว่าสองอย่างไม่เกี่ยวกัน นอกจากปัญหาข้างต้นทั้งหมด ค่าจากข้อมูลยังคลาดจากค่าจริงเพราะการสุ่ม (sampling error) เช่น 30 จุดในรูปกากบาทได้ −0.03 ทั้งที่ค่าจริงคือ 0 และถ้าลองหาความสัมพันธ์หลายแบบ แล้วเลือกรายงานเฉพาะแบบที่ไม่เจอ ก็จะเจอปัญหา multiple testing คือทดสอบหลายครั้งจนบางครั้งได้ผลที่อยากได้โดยบังเอิญ
  • การคัดข้อมูลสร้างความสัมพันธ์ขึ้นมาเองได้: ตัวแปรสองตัวที่อิสระกัน ถ้าถูกเก็บเฉพาะบางกรณี เช่นเก็บเฉพาะกองทุนที่ยังอยู่รอด อาจได้ correlation ติดลบชัดเจน ในโจทย์ข้อ 3 ด้านล่าง ก่อนคัดได้ correlation 0 แต่หลังคัดได้ −0.5

ไม่ต้องบวกอะไรเพิ่ม ตรวจตรงได้ $X+Y$ มีค่า $-2+4=2$, $-1+1=0$, $0$, $1+1=2$ และ $2+4=6$ จึงได้

\[ \begin{aligned} \mathbb E[X+Y]&=(2+0+0+2+6)/5=2,\\ \operatorname{Var}(X+Y)&=\frac{0^2+(-2)^2+(-2)^2+0^2+4^2}{5}\\ &=(0+4+4+0+16)/5=4.8. \end{aligned} \]

ตรงกัน สูตร variance ของผลรวมต้องการแค่ covariance ไม่ต้องการให้อิสระกัน

2. ให้ $X$ เป็น standard Normal และ $Y=X^2+\varepsilon$ โดย noise $\varepsilon$ อิสระจาก $X$ ค่าเฉลี่ย 0 และ variance 1 (ก) covariance ของ $X$ กับ $Y$ เท่าไร (ข) เส้นตรงที่ดีที่สุด กับตัวทำนาย $X^2$ ผิดเฉลี่ย (ยกกำลังสอง) เท่าไร

เฉลย

ใช้ $\operatorname{Cov}(X,X^2)=0$ และ $\operatorname{Var}(X^2)=2$ จากขั้นที่ 4 และใช้ว่า $\varepsilon$ อิสระจาก $X$:

\[ \begin{aligned} \operatorname{Cov}(X,Y)&=\operatorname{Cov}(X,X^2)+\operatorname{Cov}(X,\varepsilon)\\ &=0+0=0,\\ \mathbb E[(Y-1)^2]&=\operatorname{Var}(Y)=2+1=3,\\ \mathbb E[(Y-X^2)^2]&=\mathbb E[\varepsilon^2]=1,\\ \frac{3-1}{3}&=\frac23. \end{aligned} \]

covariance เป็น 0 เส้นตรงที่ดีที่สุดจึงเป็นเส้นราบที่ $\mathbb E[Y]=1$ และผิดเฉลี่ย 3 ส่วนตัวทำนาย $X^2$ ผิดแค่ 1 ลดความผิดได้สองในสาม ทั้งที่ covariance เป็น 0

3. กองทุนหนึ่งมีสองกลยุทธ์ $A$ และ $B$ แต่ละปี แต่ละกลยุทธ์ทำกำไร (ค่า 1) หรือไม่ทำกำไร (ค่า 0) โอกาสอย่างละครึ่ง และสองกลยุทธ์อิสระกัน ฐานข้อมูลเก็บเฉพาะกองทุนที่มีอย่างน้อยหนึ่งกลยุทธ์ทำกำไร คือ $A+B\ge1$ เพราะกองทุนที่แพ้ทั้งสองทางปิดตัวไปแล้ว ในข้อมูลที่ผ่านการคัดนี้ $A$ กับ $B$ ยังอิสระกันหรือไม่

เฉลย

ก่อนคัดมีสี่กรณีเท่า ๆ กัน คือ $(0,0),\ (0,1),\ (1,0),\ (1,1)$ อย่างละ $1/4$ การคัดตัด $(0,0)$ ทิ้ง เหลือสามกรณี อย่างละ $1/3$ เพราะ $A$ เป็น 0 หรือ 1 จึงมี $A^2=A$ และ $AB=1$ ได้กรณีเดียวคือ $(1,1)$:

\[ \begin{aligned} \mathbb E[A]&=\mathbb E[B]=2/3,\\ \operatorname{Var}(A)&=\mathbb E[A^2]-(\mathbb E[A])^2\\ &=2/3-4/9=2/9,\\ \operatorname{Cov}(A,B)&=\mathbb E[AB]-\mathbb E[A]\,\mathbb E[B]\\ &=1/3-4/9=-1/9,\\ \operatorname{Corr}(A,B)&=\frac{-1/9}{\sqrt{2/9}\,\sqrt{2/9}}\\ &=\frac{-1/9}{2/9}=-0.5. \end{aligned} \]

ไม่อิสระกันแล้ว การคัดข้อมูลสร้าง correlation ติดลบขึ้นมาเอง ทั้งที่กลไกเดิมอิสระกัน ถ้าเห็น correlation ในข้อมูลที่ผ่านการคัด ต้องถามก่อนว่าคัดด้วยเกณฑ์อะไร

// Normal: integrate ด้วย Simpson บนช่วง [-10, 10]
const phi = x => Math.exp(-x * x / 2) / Math.sqrt(2 * Math.PI);
function simpson(f, a, b, n = 4000) {
  const h = (b - a) / n; let s = f(a) + f(b);
  for (let i = 1; i < n; i++) s += (i % 2 ? 4 : 2) * f(a + i * h);
  return s * h / 3;
}
const Phi = x => 0.5 + simpson(phi, 0, x);
const m = k => simpson(x => x ** k * phi(x), -10, 10);
console.log(m(3), m(4) - m(2) ** 2);                                  // ~0 2

สิ่งที่ควรตอบได้หลังอ่าน

  • อิสระกันทำให้ $\mathbb E[f(X)g(Y)]=\mathbb E[f(X)]\,\mathbb E[g(Y)]$ กับทุกคู่ฟังก์ชัน ส่วน covariance 0 ตรวจแค่คู่ $f(x)=x,\ g(y)=y$ คู่เดียว จึงย้อนกลับไม่ได้
  • ยกตัวอย่างคู่ที่ covariance เป็น 0 แต่ตัวหนึ่งกำหนดอีกตัวได้ทั้งหมด ทั้งแบบห้าค่าและแบบ Normal และชี้ได้ว่าการหักล้างของสองฝั่งเกิดตรงไหน
  • แต่ละตัวเป็น Normal ยังไม่พอ ต้อง jointly Normal จึงใช้ covariance 0 สรุปว่าอิสระได้ ตัวแปรที่มีแค่สองค่าก็มีสมบัตินี้เช่นกัน
  • ตรวจความสัมพันธ์ที่ไม่เป็นเส้นตรงด้วย scatter และค่าเฉลี่ยในแต่ละกลุ่ม เช่นแบ่งวันตามขนาด shock
  • วัดความเสี่ยงของกำไรขาดทุนที่ไม่เป็นเส้นตรง โดยใส่ปัจจัยอย่าง $X^2$ เข้าไปตรง ๆ แล้วใช้สูตร covariance ตามปกติ
