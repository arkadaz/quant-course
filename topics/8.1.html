8.1 The Mean Vector and the Covariance Matrix

mean vector บอกว่าผลตอบแทนหลายตัวมีศูนย์กลางอยู่ตรงไหน ส่วน covariance matrix บอกว่าแต่ละตัวแกว่งแรงแค่ไหนและแกว่งไปด้วยกันอย่างไร

ทุกเช้า ฝ่ายความเสี่ยงต้องตอบว่าพอร์ตเงิน \$10 ล้านอาจขึ้นลงได้วันละประมาณกี่ดอลลาร์ (พอร์ตคือเงินก้อนหนึ่งที่แบ่งไปถือสินทรัพย์หลายตัว) พอร์ตนี้ถือหุ้นสามกลุ่มอุตสาหกรรม คือ Technology, Energy และ Financials

เครื่องมือที่ใช้ตอบคือ covariance matrix ตาราง $3\times3$ ที่บอกว่าผลตอบแทนรายวันของแต่ละกลุ่มแกว่งแรงแค่ไหน และแกว่งไปด้วยกันแค่ไหน หน้านี้จะสร้างตารางนี้ทีละขั้น ตอนนี้ขอแค่รู้ว่ามันเป็นตารางตัวเลขที่แต่ละแถวและแต่ละคอลัมน์เป็นของหุ้นหนึ่งกลุ่ม

สองทีมส่งตารางนี้มาให้ ตัวเลขชุดเดียวกันทุกช่อง ต่างกันแค่ลำดับ:

  • ทีม A เรียงแถวและคอลัมน์เป็น Technology, Energy, Financials
  • ทีม B เรียงเป็น Energy, Technology, Financials

ทั้งสองตารางผ่านการตรวจมาตรฐาน คือสมมาตร และ eigenvalue เป็นบวกทุกตัว ผู้จัดการพอร์ตแบ่งเงินด้วยน้ำหนัก $w=(0.5,\ 0.3,\ 0.2)$ แปลว่าลง 50% ใน Technology, 30% ใน Energy และ 20% ใน Financials แล้วส่งน้ำหนักชุดเดียวกันนี้เข้าโปรแกรมคู่กับทั้งสองตาราง

ความเสี่ยงรายวันของพอร์ตที่ได้จากสองตาราง จะออกมาเท่ากันไหม (ความเสี่ยงในที่นี้คือ SD ของผลตอบแทนพอร์ตในหนึ่งวัน คือขนาดการขึ้นลงตามปกติต่อวัน)

ลองตอบก่อนเปิดเฉลย

ไม่เท่า ตัวเลขด้านล่างนี้ หน้านี้จะคำนวณให้ดูทีละขั้นในตอนท้าย

  • ตารางของทีม A ซึ่งเรียงตรงกับน้ำหนัก ให้ SD ต่อวัน 1.6571% คิดเป็นเงิน $0.016571\times\$10{,}000{,}000\approx\$165{,}711$
  • ตารางของทีม B ให้ SD ต่อวัน 1.8958% คิดเป็นเงิน $0.018958\times\$10{,}000{,}000\approx\$189{,}578$

ทีม B สูงเกินจริง $189{,}578/165{,}711\approx1.14$ เท่า หรือราว 14% ทั้งที่โปรแกรมคูณ matrix ผ่านโดยไม่มี error เลย สาเหตุคือน้ำหนักตัวแรก 0.5 ตั้งใจให้ Technology แต่แถวแรกของตารางทีม B เป็นของ Energy ซึ่งแกว่งแรงกว่า ตัวเลขในตารางไม่มีชื่อติดมาด้วย ดังนั้นลำดับแถว ลำดับคอลัมน์ และลำดับน้ำหนัก ต้องตรงกันทั้งสามที่

ภาพรวมก่อนลงสูตร

ผลตอบแทนรายวันของหุ้น คือราคาเปลี่ยนไปกี่เปอร์เซ็นต์ในหนึ่งวัน ผลตอบแทนพรุ่งนี้ของหุ้นแต่ละตัวยังไม่มีใครรู้ เราจึงมองมันเป็นตัวแปรสุ่ม ถ้ามีหุ้นหลายตัว ก็เก็บไว้ด้วยกันเป็น random vector คือ vector ที่แต่ละช่องเป็นตัวแปรสุ่ม ช่องละหนึ่งหุ้น

ลองนึกถึงหุ้นสองตัว แต่ละวันให้จุดหนึ่งจุดบนระนาบ แกนนอนคือผลตอบแทนของหุ้น A แกนตั้งคือของหุ้น B เก็บหลายวันจะได้เมฆจุดก้อนหนึ่งเหมือนในรูปด้านล่าง เราอยากรู้สามเรื่อง:

  1. เมฆอยู่ตรงไหน (ศูนย์กลาง)
  2. เมฆกว้างแค่ไหนตามแต่ละแกน (หุ้นแต่ละตัวแกว่งแรงแค่ไหน)
  3. เมฆเอียงไหม (สองหุ้นขึ้นลงไปด้วยกันหรือไม่)

mean vector ตอบเรื่องแรก มันคือค่าเฉลี่ยของแต่ละช่องแยกกัน covariance matrix ตอบอีกสองเรื่องในตารางเดียว ช่องบนแนวทแยงคือ variance ของหุ้นแต่ละตัว คือค่าเฉลี่ยของการเบี่ยงจากค่าเฉลี่ยยกกำลังสอง (ถอดรากแล้วได้ SD) ช่องนอกแนวทแยงคือ covariance ของแต่ละคู่ คือค่าเฉลี่ยของ “การเบี่ยงของตัวหนึ่ง คูณ การเบี่ยงของอีกตัว” ถ้าสองตัวมักเบี่ยงไปทางเดียวกัน ผลคูณส่วนใหญ่จะเป็นบวก covariance จึงเป็นบวก และเมฆเอียงขึ้นขวา

หน้านี้จะเดินตามลำดับนี้: สร้างทั้งสองอย่างจากนิยาม คำนวณจากข้อมูลสามวันด้วยมือ ดูว่าทำไมตัวหารเป็น $T-1$ ($T$ คือจำนวนวันของข้อมูล) ดูว่าทำไมตารางต้องสมมาตร และห้ามทำให้ variance ของพอร์ตใดติดลบ จากนั้นแปลงเป็น correlation เพื่ออ่านตารางของสินทรัพย์ 8 กลุ่ม แล้วกลับมาตอบคำถามเปิด

ขั้นที่ 1 — เรียงผลตอบแทนเป็น vector แล้วเฉลี่ยทีละช่อง

ก่อนคำนวณอะไร ต้องตกลงกันให้ชัดว่าช่องที่หนึ่ง สอง สาม คือหุ้นกลุ่มไหน ใช้หน่วยอะไร และวัดช่วงเวลาเท่าไร คำถามเปิดแสดงแล้วว่า ถ้าตกลงไม่ตรงกัน ตัวเลขจะผิดทันที ทั้งหน้านี้ใช้ข้อตกลงนี้:

  • $R_1,\ R_2,\ R_3$ คือผลตอบแทนหนึ่งวันของ Technology, Energy และ Financials ตามลำดับ
  • ผลตอบแทนเป็นแบบ simple return คือ $(P_t-P_{t-1})/P_{t-1}$ เมื่อ $P_t$ คือราคาปิดของวันที่ $t$
  • หน่วยเป็นทศนิยม เช่น $0.0005=0.05\%$ หรือเป็น bp โดย $1\text{ bp}=0.0001$
  • ค่าเฉลี่ยด้านล่างเป็นแบบจำลองสมมติ
\[ \begin{aligned} R&=(R_1,\ R_2,\ R_3)^{\mathsf T},\\ \mu:=\mathbb E[R] &=(\mathbb E[R_1],\ \mathbb E[R_2],\ \mathbb E[R_3])^{\mathsf T}\\ &=(0.0005,\ 0.0002,\ 0.00035)^{\mathsf T}\\ &=(5,\ 2,\ 3.5)^{\mathsf T}\text{ bp}. \end{aligned} \]

ค่าเฉลี่ยของ vector ไม่มีอะไรใหม่ แค่เฉลี่ยทีละช่องแยกกัน เช่น Technology เฉลี่ยวันละ 0.0005 ซึ่งเท่ากับ $0.0005/0.0001=5$ bp ที่ต้องเก็บเป็น vector ก็เพราะคูณกับน้ำหนักพอร์ตได้ในครั้งเดียว ผลตอบแทนคาดหวังของพอร์ตคือ $w^{\mathsf T}\mu=w_1\mu_1+w_2\mu_2+w_3\mu_3$ ที่ทำแบบนี้ได้ เพราะค่าเฉลี่ยของผลรวมเท่ากับผลรวมของค่าเฉลี่ย (expected value เป็น linear) แต่สามตัวเลขนี้ยังไม่บอกเลยว่าแต่ละกลุ่มแกว่งแรงแค่ไหน หรือแกว่งไปด้วยกันหรือไม่ ขั้นถัดไปจะตอบเรื่องนี้

ขั้นที่ 2 — covariance คือค่าเฉลี่ยของผลคูณการเบี่ยง

ขั้นนี้ตอบคำถามที่ค้างไว้ คือแต่ละกลุ่มแกว่งแรงแค่ไหน และแกว่งไปด้วยกันไหม วิธีคิดมีสองจังหวะ จังหวะแรก หักค่าเฉลี่ยออก ให้เหลือแต่การเบี่ยง $Z=R-\mu$ จังหวะที่สอง คูณการเบี่ยงทุกคู่ แล้วเก็บไว้ในตารางเดียว เครื่องมือที่ทำทั้งตารางได้ในครั้งเดียวคือ outer product $ZZ^{\mathsf T}$ (vector คอลัมน์คูณ vector แถว) ค่าเฉลี่ยของตารางนี้คือนิยามของ covariance matrix $\Sigma$

\[ \begin{aligned} Z&:=R-\mu,\\ \Sigma&:=\mathbb E\big[ZZ^{\mathsf T}\big],\\ \Sigma_{ij}&=\mathbb E[(R_i-\mu_i)(R_j-\mu_j)]\\ &=\mathbb E[R_iR_j]-\mu_i\mu_j,\\ \Sigma_{ii}&=\mathbb E[(R_i-\mu_i)^2]\\ &=\operatorname{Var}(R_i). \end{aligned} \]

หัวใจของนิยามคือ $ZZ^{\mathsf T}$ คอลัมน์ $3\times1$ คูณแถว $1\times3$ ได้ตาราง $3\times3$ ที่ช่อง $(i,j)$ คือ $Z_iZ_j$ ทุกคู่ครบในตารางเดียว ระวังอย่าสลับเป็น $Z^{\mathsf T}Z$ เพราะนั่นได้ตัวเลขตัวเดียว คือผลรวมกำลังสอง รูป $\mathbb E[R_iR_j]-\mu_i\mu_j$ ได้จากการกระจายวงเล็บเป็น $\mathbb E[R_iR_j]-\mu_i\mathbb E[R_j]-\mu_j\mathbb E[R_i]+\mu_i\mu_j$ ที่ดึง $\mu_i$ ออกนอก $\mathbb E$ ได้ เพราะมันเป็นค่าคงที่ และ $\mathbb E[R_j]=\mu_j$ สามพจน์หลังจึงเป็น $-\mu_i\mu_j-\mu_j\mu_i+\mu_i\mu_j=-\mu_i\mu_j$ บนแนวทแยง ($i=j$) ผลคูณกลายเป็นการเบี่ยงยกกำลังสอง ช่องนั้นจึงเป็น variance นิยามนี้ต้องการแค่ว่าค่าเฉลี่ยของผลตอบแทนยกกำลังสองมีค่าจำกัด ไม่ต้องสมมติว่าผลตอบแทนเป็น Normal

ตอนนี้ใส่ตัวเลขจริง ตารางของทีม A ในคำถามเปิด (เรียง Technology, Energy, Financials) เป็นแบบจำลองสมมติดังนี้ หน่วยคือผลตอบแทนรายวันแบบทศนิยมยกกำลังสอง ตัวคูณ $10^{-4}$ หน้าตารางแปลว่าทุกช่องคูณ $10^{-4}$ เช่นช่องแรกคือ $4\times10^{-4}=0.0004$ ถอดรากของช่องแนวทแยง จะได้ SD ต่อวันของแต่ละกลุ่ม

\[ \begin{aligned} \Sigma&=10^{-4}\begin{bmatrix}4&0.8&1.2\\0.8&9&1.8\\1.2&1.8&6\end{bmatrix},\\ \sigma_1&=\sqrt{0.0004}=2\%,\\ \sigma_2&=\sqrt{0.0009}=3\%,\\ \sigma_3&=\sqrt{0.0006}\approx2.449\%. \end{aligned} \]

อ่านแนวทแยงก่อน ช่องแรก 0.0004 เป็น variance ไม่ใช่ SD คนมักอ่านผิดเป็น 0.04% ต้องถอดรากก่อนจึงได้ SD 2% ต่อวัน Energy แกว่งแรงที่สุดที่ 3% ต่อวัน ต่อมาดูช่องนอกแนวทแยง ทุกช่องเป็นบวก แปลว่าทุกคู่มักเบี่ยงไปทางเดียวกัน สุดท้าย ช่อง $(1,2)$ เท่ากับช่อง $(2,1)$ เพราะ $Z_1Z_2=Z_2Z_1$ ตารางจึงสมมาตร

ขั้นที่ 3 — คำนวณจากข้อมูลสามวันด้วยมือ

ในงานจริงไม่มีใครบอก $\mu$ กับ $\Sigma$ มาให้ เราต้องประมาณจากข้อมูลย้อนหลัง ลองกับข้อมูลชุดเล็กที่สุดที่ยังเห็นกลไกครบ คือผลตอบแทนสามวันของ Technology และ Energy หน่วย bp (ตัวเลขสมมติ) แต่ละแถวคือหนึ่งวัน

สูตรด้านล่างทำสองอย่าง อย่างแรก เฉลี่ยแต่ละคอลัมน์ให้ได้ $\hat\mu$ อย่างที่สอง เฉลี่ยผลคูณการเบี่ยงให้ได้ $\hat\Sigma$ หมวก ^ บอกว่าเป็นค่าที่ประมาณจากข้อมูล $r_t$ คือ vector ผลตอบแทนของวันที่ $t$ และ $T=3$ คือจำนวนวัน

\[ \begin{aligned} \hat\mu&=\frac13\sum_{t=1}^{3}r_t =\begin{bmatrix}(4+6+5)/3\\(1+4+1)/3\end{bmatrix}\\ &=\begin{bmatrix}5\\2\end{bmatrix}\text{ bp},\\ \hat\Sigma&:=\frac1{T-1}\sum_{t=1}^{T}(r_t-\hat\mu)(r_t-\hat\mu)^{\mathsf T},\\ \hat\Sigma_{11}&=\frac{(-1)^2+1^2+0^2}{2}=1,\\ \hat\Sigma_{22}&=\frac{(-1)^2+2^2+(-1)^2}{2}=3,\\ \hat\Sigma_{12}&=\frac{1+2+0}{2}=1.5,\\ \hat\Sigma&=\begin{bmatrix}1&1.5\\1.5&3\end{bmatrix}\text{ bp}^2. \end{aligned} \]

ช่อง $\hat\Sigma_{12}$ ก็คือผลรวมของคอลัมน์ผลคูณในตาราง $1+2+0=3$ หารด้วย $T-1=2$ ไม่มีวันไหนเลยที่สองกลุ่มเบี่ยงสวนทางกัน covariance จึงเป็นบวก สังเกตว่าค่าเฉลี่ยหารด้วย 3 แต่ covariance หารด้วย 2 เหตุผลอยู่ในขั้นถัดไป คำเตือนหนึ่งข้อ ตาราง bp² นี้เป็นคนละชุดข้อมูลและคนละหน่วยกับแบบจำลองสามกลุ่มด้านบน แม้ชื่อสินทรัพย์จะตรงกัน ห้ามเอามาปนกัน

ขั้นที่ 4 — ทำไมตัวหารเป็น $T-1$ ไม่ใช่ $T$

คำถามที่ทุกคนถาม: การเฉลี่ยก็ต้องหารด้วยจำนวนข้อมูล ข้อมูลมี 3 วัน ทำไม covariance หารด้วย 2 คำตอบสั้น ๆ คือ เราวัดระยะรอบ $\hat\mu$ ซึ่งคำนวณจากข้อมูลชุดเดียวกัน ไม่ได้วัดรอบ $\mu$ จริงที่เราไม่รู้ และระยะรอบ $\hat\mu$ สั้นกว่าเสมอ

ดูทีละมิติก่อน คือ variance ของหุ้นตัวเดียว ให้

  • $x_1,\ldots,x_T$ คือข้อมูล $T$ วัน
  • $\bar x$ คือค่าเฉลี่ยตัวอย่าง (ค่าเฉลี่ยของข้อมูลชุดนี้)
  • $c$ คือจุดศูนย์กลางใดก็ได้ และ $SS(c)$ คือผลรวมของระยะกำลังสองจากข้อมูลทุกวันไปถึง $c$

ตัวอย่างตัวเลขใช้ข้อมูล Technology 4, 6, 5 bp ซึ่งมี $\bar x=5$ แล้วลองเทียบกับ $c=4.5$

\[ \begin{aligned} SS(c)&:=\sum_{t=1}^{T}(x_t-c)^2\\ &=SS(\bar x)+T(\bar x-c)^2,\\ SS(5)&=1+1+0=2,\\ SS(4.5)&=0.25+2.25+0.25\\ &=2.75=2+3(0.5)^2. \end{aligned} \]

สมการนี้แยก $SS(c)$ ออกเป็นสองก้อน ที่มาคือเขียน $x_t-c=(x_t-\bar x)+(\bar x-c)$ แล้วยกกำลังสองและรวมทุกวัน พจน์ไขว้ $2(\bar x-c)\sum_t(x_t-\bar x)$ หายไป เพราะผลรวมการเบี่ยงรอบค่าเฉลี่ยตัวอย่างเป็นศูนย์เสมอ (ในข้อมูลนี้ $-1+1+0=0$) ก้อนที่เหลือ $T(\bar x-c)^2$ ไม่มีวันติดลบ ดังนั้น $\bar x$ คือจุดที่ทำให้ $SS$ ต่ำที่สุด และต่ำกว่าผลรวมรอบค่าเฉลี่ยจริง $\mu$ ด้วย ถ้าหารด้วย $T$ variance ที่ได้จึงเล็กไปโดยเฉลี่ย

เล็กไปเท่าไร สมมติว่าผลตอบแทนแต่ละวันอิสระกัน และมาจาก distribution เดียวกันที่มี variance $\sigma^2$ (เรียกว่า IID: independent and identically distributed) เราใช้ความจริงสองข้อ ข้อแรก ค่าเฉลี่ยของ $(x_t-\mu)^2$ คือ $\sigma^2$ ตามนิยาม ข้อสอง ค่าเฉลี่ยตัวอย่าง $\bar x$ มีค่าเฉลี่ยเป็น $\mu$ และมี variance $\sigma^2/T$ (standard error ของค่าเฉลี่ย) แทน $c=\mu$ ในสมการข้างบน แล้วหาค่าคาดหมายของทั้งสองก้อน

\[ \begin{aligned} \mathbb E[SS(\mu)]&=T\sigma^2,\\ \mathbb E[T(\bar x-\mu)^2]&=T\cdot\frac{\sigma^2}{T}=\sigma^2,\\ \mathbb E[SS(\bar x)]&=T\sigma^2-\sigma^2\\ &=(T-1)\sigma^2. \end{aligned} \]

ก้อนที่สอง $\mathbb E[T(\bar x-\mu)^2]$ คือ $T$ คูณ variance ของ $\bar x$ (เพราะ $\bar x$ มีค่าเฉลี่ยเป็น $\mu$) จึงเท่ากับ $T\cdot\sigma^2/T=\sigma^2$ พอดี ผลรวมรอบ $\bar x$ จึงขาดไปหนึ่ง $\sigma^2$ โดยเฉลี่ย หรือพูดอีกแบบว่าเสีย degree of freedom ไปหนึ่งตัว เพราะใช้ข้อมูลชุดเดียวกันไปประมาณค่าเฉลี่ยแล้ว ดังนั้นหารด้วย $T-1$ จึงได้ $\mathbb E\big[SS(\bar x)/(T-1)\big]=\sigma^2$ เรียกว่า unbiased คือถูกโดยเฉลี่ย แบบ matrix ใช้เหตุผลเดียวกันทีละช่อง จึงได้ $\mathbb E[\hat\Sigma]=\Sigma$

สิ่งที่ $T-1$ ไม่ได้แก้

unbiased แปลว่าถูกโดยเฉลี่ยเมื่อทำซ้ำหลายครั้ง ไม่ได้แปลว่าข้อมูลสามวันให้ค่าใกล้ความจริง และผลนี้อาศัย IID ถ้าความผันผวนเปลี่ยนไปตามช่วงเวลา หรือผลตอบแทนวันนี้สัมพันธ์กับของเมื่อวาน ต้องคิดใหม่

อีกกรณีหนึ่ง ถ้าเราไม่ได้อยากประมาณค่าจริง แต่อยากได้ covariance ของข้อมูล $T$ แถวนี้เอง โดยมองว่าทุกแถวมีโอกาสเกิด $1/T$ เท่ากัน ก็หารด้วย $T$ ได้ เป็นคนละคำถาม ไม่ใช่สูตรผิด เมื่อข้อมูลยาว สองแบบต่างกันน้อยมาก เช่นข้อมูล 250 วัน (ราวหนึ่งปีของวันทำการ) สองค่าต่างกัน $250/249\approx1.004$ เท่า คือราว 0.4%

ขั้นที่ 5 — ตารางต้องสมมาตร และห้ามให้ variance ของพอร์ตใดติดลบ

ตารางที่สมมาตรไม่ได้เป็น covariance เสมอไป ยังมีเงื่อนไขอีกข้อที่ขาดไม่ได้ และมันมาจากคำถามง่าย ๆ ข้อเดียว: ถ้าถือพอร์ตด้วยน้ำหนัก $w$ คงที่ variance ของผลตอบแทนพอร์ตเป็นเท่าไร ผลตอบแทนพอร์ตคือ $w^{\mathsf T}R=w_1R_1+\cdots+w_nR_n$ และการเบี่ยงของมันจากค่าเฉลี่ยคือ $w^{\mathsf T}Z$

\[ \begin{aligned} \Sigma_{ij}&=\mathbb E[Z_iZ_j]=\mathbb E[Z_jZ_i]=\Sigma_{ji},\\ w^{\mathsf T}\Sigma w&=\mathbb E\big[w^{\mathsf T}ZZ^{\mathsf T}w\big]\\ &=\mathbb E\big[(w^{\mathsf T}Z)^2\big]\\ &=\operatorname{Var}(w^{\mathsf T}R)\ \ge\ 0. \end{aligned} \]

ความสมมาตรมาจาก $Z_iZ_j=Z_jZ_i$ ส่วนเงื่อนไขใหม่มาจากการสังเกตว่า $w^{\mathsf T}Z$ เป็นตัวเลขตัวเดียว คือการเบี่ยงของผลตอบแทนพอร์ต จึงจัดรูปได้เป็น $w^{\mathsf T}ZZ^{\mathsf T}w=(w^{\mathsf T}Z)(Z^{\mathsf T}w)=(w^{\mathsf T}Z)^2$ ค่าเฉลี่ยของสิ่งที่ยกกำลังสองแล้วติดลบไม่ได้ ดังนั้น covariance ทุกตารางต้องให้ $w^{\mathsf T}\Sigma w\ge0$ กับทุก $w$ เงื่อนไขนี้เรียกว่า positive semidefinite (PSD) ซึ่งเทียบเท่ากับ eigenvalue ทุกตัวไม่ติดลบ (eigenvalues และ positive definiteness)

ลองดูว่าตารางที่ไม่ PSD หน้าตาเป็นอย่างไร ใช้ตารางสามวันของ Technology กับ Energy สมมติพอร์ตซื้อ Technology 1 หน่วย แล้วขาย Energy $k$ หน่วยเพื่อ hedge คือใช้ Energy ที่มักขึ้นลงตาม Technology มาหักล้างการแกว่ง พอร์ตนี้มีน้ำหนัก $w=(1,\ -k)$ แทนลงใน $w^{\mathsf T}\Sigma w$ ได้สูตรด้านล่าง จากนั้นสมมติว่ามีคนแก้ช่อง covariance จาก 1.5 เป็น 2 โดยไม่แตะ variance ตารางที่แก้แล้วยังสมมาตรอยู่

\[ \begin{aligned} \operatorname{Var}(R_1-kR_2) &=\Sigma_{11}-2k\Sigma_{12}+k^2\Sigma_{22}\\ &=1-3k+3k^2,\\ k=0.5:\quad&1-1.5+0.75=0.25,\\ \Sigma_{12}=2:\quad&1-4k+3k^2,\\ k=2/3:\quad&1-8/3+4/3=-1/3,\\ \rho&=\frac{\Sigma_{12}}{\sqrt{\Sigma_{11}\Sigma_{22}}}=\frac{2}{\sqrt{1\cdot3}}\\ &\approx1.155. \end{aligned} \]

ค่า $k$ ที่เลือกมาแทน คือจุดต่ำสุดของแต่ละพาราโบลา หาได้จากอนุพันธ์เท่ากับศูนย์ ตารางจริงได้ $-3+6k=0$ คือ $k=0.5$ และ variance ต่ำสุด 0.25 ซึ่งยังเป็นบวก ตารางที่แก้แล้วได้ $-4+6k=0$ คือ $k=2/3$ และ variance $-1/3$ ซึ่งเป็นไปไม่ได้ ทั้งที่ตารางยังสมมาตร แถวสุดท้ายคือ correlation ที่แฝงอยู่ (covariance หารด้วย SD ทั้งสองตัว ซึ่งต้องอยู่ระหว่าง −1 ถึง 1) มันเกิน 1 ซึ่งเป็นสัญญาณเดียวกัน ตารางแบบนี้เกิดขึ้นจริง เมื่อประกอบตารางจากหลายช่วงข้อมูล หรือเมื่อแต่ละคู่ใช้คนละชุดวันเพราะข้อมูลขาด optimizer (โปรแกรมที่ค้นหาน้ำหนักพอร์ตที่ความเสี่ยงต่ำที่สุด) ที่เจอตารางนี้จะวิ่งไปหาพอร์ต “ความเสี่ยงติดลบ” ซึ่งไม่มีอยู่จริง

PSD ยอมให้ variance เป็นศูนย์ และข้อมูลน้อยทำให้เกิดเรื่องนี้แน่นอน

PSD ห้ามแค่ variance ติดลบ ยังยอมให้ variance เป็นศูนย์ได้ในบางทิศ ตัวอย่างง่ายที่สุดคือมีสินทรัพย์ซ้ำกันสองตัว ซื้อตัวหนึ่ง แล้วขายอีกตัวเท่ากัน ผลตอบแทนพอร์ตเป็นศูนย์ทุกวัน variance จึงเป็นศูนย์

ข้อมูลที่น้อยเกินไปก็ทำให้เกิดเรื่องนี้ได้ ดูจาก matrix เขียนข้อมูลที่หักค่าเฉลี่ยแล้วเป็น matrix $X$ ขนาด $T\times n$ (แถวคือวัน คอลัมน์คือสินทรัพย์) จะได้ $\hat\Sigma=X^{\mathsf T}X/(T-1)$ ซึ่งมี rank ไม่เกิน $T-1$ เพราะ $X$ มีแค่ $T$ แถว และหักไปอีกหนึ่ง เพราะแต่ละคอลัมน์รวมกันได้ศูนย์ (แถวสุดท้ายจึงเขียนได้จากแถวอื่น) ตามเหตุผลใน rank และ invertibility

ตัวอย่าง หุ้น $n=500$ ตัว กับข้อมูล $T=250$ วัน (ราวหนึ่งปีของวันทำการ) ได้ตาราง $500\times500$ ที่มี rank ไม่เกิน $T-1=249$ จึงมีอย่างน้อย $500-249=251$ ทิศทางที่ตารางอ้างว่า variance เป็นศูนย์ และตารางนี้หา inverse ไม่ได้ แม้โปรแกรมจะเติมตัวเลขครบทุกช่อง optimizer ที่ใช้ตารางนี้จะเจอ “พอร์ตไร้ความเสี่ยง” ปลอม ๆ เต็มไปหมด

ขั้นที่ 6 — หารด้วย SD ให้เป็น correlation แล้วอ่านตาราง 8 สินทรัพย์

covariance ปนกันอยู่สองเรื่อง คือแต่ละตัวแกว่งแรงแค่ไหน กับสองตัวขยับไปด้วยกันแน่นแค่ไหน หุ้นที่ผันผวนมากจะมี covariance ใหญ่กับทุกตัว แม้จะขยับไปด้วยกันไม่แน่นเลย ถ้าอยากวัดแค่ความแน่น ต้องหารช่อง $(i,j)$ ด้วย $\sigma_i\sigma_j$ ผลที่ได้คือ correlation

ในสูตรด้านล่าง $D$ คือ diagonal matrix ที่มี SD ของแต่ละตัวอยู่บนแนวทแยง ตัวอย่างตัวเลขใช้ตารางสามวัน ซึ่ง $\sigma_1=\sqrt1=1$ bp และ $\sigma_2=\sqrt3$ bp

\[ \begin{aligned} D&:=\operatorname{diag}(\sigma_1,\ldots,\sigma_n),\\ C_{ij}&:=\frac{\Sigma_{ij}}{\sigma_i\sigma_j},\qquad C=D^{-1}\Sigma D^{-1},\\ \hat C_{12}&=\frac{1.5}{1\cdot\sqrt3}\approx0.866. \end{aligned} \]

รูป matrix $D^{-1}\Sigma D^{-1}$ ทำสิ่งเดียวกับการหารทีละช่อง คูณ $D^{-1}$ ทางซ้ายคือหารแถว $i$ ด้วย $\sigma_i$ คูณทางขวาคือหารคอลัมน์ $j$ ด้วย $\sigma_j$ ผลจึงไม่มีหน่วย และแนวทแยงเป็น $\sigma_i^2/(\sigma_i\sigma_i)=1$ ทุกช่องอยู่ระหว่าง −1 ถึง 1 เพราะ correlation คือ cos ของมุมระหว่าง vector การเบี่ยงสองตัว (inner product มุม และ correlation) ถ้าเปลี่ยนหน่วยจาก bp เป็นทศนิยม covariance จะเปลี่ยน แต่ correlation ไม่เปลี่ยน เพราะตัวคูณหน่วยตัดกันทั้งเศษและส่วน

ตารางที่ใช้กันจริงมีสินทรัพย์มากกว่านี้ ตัวอย่างต่อไปมาจาก workbook ของคอร์สเรื่อง mean-variance (การเลือกน้ำหนักพอร์ตจากค่าเฉลี่ยและ covariance) เป็น covariance รายปีของสินทรัพย์ 8 กลุ่ม:

  • US Bond และ Intl Bond คือหุ้นกู้สหรัฐ และหุ้นกู้ต่างประเทศ (หุ้นกู้ หรือ bond คือตราสารหนี้ที่จ่ายดอกเบี้ย ราคาจึงมักแกว่งน้อยกว่าหุ้น)
  • US LG และ US LV คือหุ้นบริษัทใหญ่ในสหรัฐ แบบ growth (บริษัทที่ตลาดคาดว่าจะโตเร็ว) และแบบ value (บริษัทที่ราคาถูกเมื่อเทียบกับกำไร)
  • US SG และ US SV คือหุ้นบริษัทเล็กในสหรัฐ แบบ growth และแบบ value
  • Intl Dev คือหุ้นประเทศพัฒนาแล้วนอกสหรัฐ และ EM คือหุ้นตลาดเกิดใหม่

ลองแปลงสองคู่ด้วยมือ ตัวเลขที่ใช้อ่านมาจากตารางใน workbook คู่แรกคือ LG กับ SG: variance 0.059852 และ 0.102488 covariance 0.063497 คู่ที่สองคือ US Bond กับ LV: variance 0.001005 และ 0.029609 covariance −0.000675

\[ \begin{aligned} \sigma_{\text{LG}}&=\sqrt{0.059852}\approx24.46\%,\\ \sigma_{\text{SG}}&=\sqrt{0.102488}\approx32.01\%,\\ C_{\text{LG,SG}}&=\frac{0.063497}{0.24465\times0.32014}\\ &\approx0.81,\\ \sigma_{\text{Bond}}&=\sqrt{0.001005}\approx3.17\%,\\ \sigma_{\text{LV}}&=\sqrt{0.029609}\approx17.21\%,\\ C_{\text{Bond,LV}}&=\frac{-0.000675}{0.03170\times0.17207}\\ &\approx-0.12. \end{aligned} \]

covariance ของ LG กับ SG เท่ากับ 0.0635 ดูเป็นตัวเลขเล็ก แต่สองกลุ่มนี้แกว่งแรงทั้งคู่ คือราว 24% และ 32% ต่อปี หารด้วย SD ทั้งสองแล้วได้ correlation 0.81 แปลว่าขยับไปด้วยกันแน่นมาก ส่วนหุ้นกู้สหรัฐกับ LV มี covariance ติดลบเล็กน้อย correlation −0.12 แปลว่าแทบไม่ขยับตามกัน และเอนไปทางสวนกันนิดหน่อย นี่คือเหตุผลเชิงตัวเลขที่พอร์ตผสมหุ้นกับหุ้นกู้ ซึ่งหน้าถัดไปจะคำนวณให้เห็น

ตารางสมมาตรแปลว่าครึ่งล่างเป็นสำเนาของครึ่งบน ค่าที่ต้องประมาณจากข้อมูลจริงจึงมีแค่แนวทแยงกับครึ่งบน ให้ $N(n)$ คือจำนวนค่าที่ต้องประมาณในตารางของ $n$ สินทรัพย์ แนวทแยงมี $n$ ค่า ครึ่งบนมี $n(n-1)/2$ ค่า (จำนวนคู่ที่เลือกได้จาก $n$ ตัว)

\[ \begin{aligned} N(n)&=n+\frac{n(n-1)}{2}=\frac{n(n+1)}{2},\\ N(8)&=\frac{8\cdot9}{2}=36,\\ N(500)&=\frac{500\cdot501}{2}=125{,}250. \end{aligned} \]

ตาราง 8 สินทรัพย์จึงมีค่าอิสระ 36 ค่า ไม่ใช่ $8\times8=64$ ส่วนหุ้น 500 ตัวมีถึง 125,250 ค่า ขณะที่ข้อมูลรายวัน 5 ปีมีแค่ประมาณ $5\times252=1{,}260$ วันต่อหุ้นหนึ่งตัว (ตลาดหุ้นสหรัฐเปิดทำการปีละประมาณ 252 วัน) ปัญหาคือจำนวนค่าที่ต้องประมาณโตตาม $n^2$ แต่ข้อมูลโตตามเวลาเท่านั้น นี่คือที่มาของเทคนิค shrinkage เช่น Ledoit–Wolf ซึ่งดึงตารางที่ประมาณได้เข้าหาตารางที่ง่ายกว่า เช่น matrix ที่ variance เท่ากันทุกตัวและ covariance เป็นศูนย์ เพื่อให้ตัวเลขนิ่งขึ้น

ขั้นที่ 7 — ตอบคำถามเปิด: ลำดับชื่อต้องตรงทั้งสามที่

โจทย์ให้อะไรมาบ้าง: กลับไปที่พอร์ต \$10 ล้านในคำถามเปิด ของที่รู้มีดังนี้

  • ลำดับสินทรัพย์ของทีม A: Technology, Energy, Financials
  • ผลตอบแทนเฉลี่ยรายวัน $\mu=(0.0005,\ 0.0002,\ 0.00035)^{\mathsf T}$ (แบบจำลองสมมติจากขั้นแรก)
  • $\Sigma$ คือตารางของทีม A ที่เขียนไว้ในขั้นนิยาม covariance ด้านบน
  • น้ำหนัก $w=(0.5,\ 0.3,\ 0.2)^{\mathsf T}$
  • มูลค่าพอร์ต (NAV: net asset value) \$10 ล้าน

เริ่มจากตารางของทีม A ซึ่งเรียงตรงกับน้ำหนัก ผลตอบแทนคาดหวังใช้ $w^{\mathsf T}\mu$ ส่วน variance ใช้ $w^{\mathsf T}\Sigma w$ ซึ่งกางออกได้เป็นพจน์แนวทแยง $w_i^2\Sigma_{ii}$ สามพจน์ บวกพจน์คู่ $2w_iw_j\Sigma_{ij}$ อีกสามพจน์ (คูณ 2 เพราะช่อง $(i,j)$ กับ $(j,i)$ เท่ากัน) ตัวเลขน้ำหนักในวงเล็บคือ $w_1^2=0.25$, $w_2^2=0.09$, $w_3^2=0.04$ และ $w_1w_2=0.15$, $w_1w_3=0.10$, $w_2w_3=0.06$

\[ \begin{aligned} \mathbb E[R_p]&=w^{\mathsf T}\mu\\ &=0.5(0.0005)+0.3(0.0002)\\ &\quad+0.2(0.00035)\\ &=0.00038=3.8\text{ bp},\\ w^{\mathsf T}\Sigma w&=10^{-4}\big(0.25\cdot4+0.09\cdot9\\ &\quad+0.04\cdot6+2\cdot0.15\cdot0.8\\ &\quad+2\cdot0.10\cdot1.2+2\cdot0.06\cdot1.8\big)\\ &=10^{-4}(1+0.81+0.24\\ &\quad+0.24+0.24+0.216)\\ &=0.0002746,\\ \sigma_p&=\sqrt{0.0002746}\approx1.6571\%. \end{aligned} \]

ตอนนี้ใช้ตารางของทีม B ซึ่งเรียง Energy, Technology, Financials แต่ยังส่งน้ำหนักเดิม $(0.5,\ 0.3,\ 0.2)$ เข้าไป ตาราง $\Sigma'$ ของทีม B คือตารางเดิมที่สลับแถว 1 กับ 2 และสลับคอลัมน์ 1 กับ 2 พร้อมกัน สุดท้ายลองเรียงน้ำหนักใหม่เป็น $w'$ ให้ตรงกับลำดับของทีม B แล้วคำนวณซ้ำ

\[ \begin{aligned} \Sigma'&=10^{-4}\begin{bmatrix}9&0.8&1.8\\0.8&4&1.2\\1.8&1.2&6\end{bmatrix},\\ w^{\mathsf T}\Sigma'w&=10^{-4}(2.25+0.36+0.24\\ &\quad+0.24+0.36+0.144)\\ &=0.0003594,\\ \sqrt{0.0003594}&\approx1.8958\%,\\ w'&=(0.3,\ 0.5,\ 0.2)^{\mathsf T},\\ w'^{\mathsf T}\Sigma'w'&=0.0002746. \end{aligned} \]

คำตอบ: แปลงเป็นเงินโดยคูณด้วยมูลค่าพอร์ต ตารางของทีม A ให้

  • กำไรขาดทุนเฉลี่ยต่อวัน (mean P&L) $0.00038\times\$10{,}000{,}000=\$3{,}800$
  • SD ของกำไรขาดทุนต่อวัน $0.016571\times\$10{,}000{,}000\approx\$165{,}711$

ตารางของทีม B ที่จับน้ำหนักผิดลำดับ ให้ SD $0.018958\times\$10{,}000{,}000\approx\$189{,}578$ สูงเกินจริง $189{,}578/165{,}711\approx1.14$ เท่า หรือราว 14% แต่เมื่อเรียงน้ำหนักใหม่เป็น $w'$ ให้ตรงกับตารางของทีม B จะได้ variance 0.0002746 เท่าเดิมทุกหลัก แปลว่าสองตารางไม่ได้ผิด ที่ผิดคือการจับคู่ระหว่างตารางกับน้ำหนัก

ตรวจเองใน 10 วินาที: ช่องแรกของตารางต้องเป็น variance ของสินทรัพย์ที่น้ำหนักตัวแรกถืออยู่ น้ำหนักตัวแรก 0.5 เป็นของ Technology ซึ่งมี variance 0.0004 แต่ตารางของทีม B มีช่องแรก 0.0009 ซึ่งเป็นของ Energy แค่เทียบช่องแรกก็จับได้ ส่วนการตรวจทางพีชคณิตจับความผิดนี้ไม่ได้เลย เพราะการสลับแถวพร้อมคอลัมน์ไม่เปลี่ยนความสมมาตร และไม่เปลี่ยน eigenvalue ตัวใดเลย

ขั้นที่ 8 — ได้ SD กับ correlation มา จะสร้าง covariance กลับอย่างไร

คนมักคุยเรื่องความเสี่ยงด้วย SD กับ correlation เพราะอ่านง่ายกว่า covariance เช่นทีมวางแผนการลงทุนส่งตัวเลขแบบนี้มา แต่สูตรความเสี่ยงของพอร์ต $w^{\mathsf T}\Sigma w$ ต้องใช้ covariance จึงต้องแปลงกลับ

โจทย์ให้อะไรมาบ้าง: แบบจำลองรายปี (ตัวเลขสมมติ) ของสินทรัพย์สามตัว เรียงเป็น หุ้นสหรัฐ, หุ้นกู้สหรัฐ, ทองคำ

  • SD ต่อปี $\sigma_1=18\%$, $\sigma_2=6\%$, $\sigma_3=15\%$
  • correlation หุ้น–หุ้นกู้ $\rho_{12}=-0.20$, หุ้น–ทอง $\rho_{13}=0.05$, หุ้นกู้–ทอง $\rho_{23}=0.25$
  • น้ำหนัก $w=(0.5,\ 0.3,\ 0.2)$

สูตรแปลงกลับก็คือขั้น correlation ที่ทำย้อนกลับ คือคูณด้วย SD แทนการหาร ช่องแนวทแยงมี $\rho_{ii}=1$ จึงเหลือ $\sigma_i^2$

\[ \begin{aligned} \Sigma_{ij}&=\rho_{ij}\sigma_i\sigma_j,\qquad\Sigma=DCD,\\ \Sigma_{11}&=0.18^2=0.0324,\\ \Sigma_{22}&=0.06^2=0.0036,\\ \Sigma_{33}&=0.15^2=0.0225,\\ \Sigma_{12}&=(-0.20)(0.18)(0.06)\\ &=-0.00216,\\ \Sigma_{13}&=(0.05)(0.18)(0.15)=0.00135,\\ \Sigma_{23}&=(0.25)(0.06)(0.15)=0.00225. \end{aligned} \]

ต่อมาแทนลงใน $w^{\mathsf T}\Sigma w$ แบบเดียวกับขั้นที่แล้ว คือสามพจน์แนวทแยง $w_i^2\Sigma_{ii}$ และสามพจน์คู่ $2w_iw_j\Sigma_{ij}$

\[ \begin{aligned} w^{\mathsf T}\Sigma w&=0.25(0.0324)+0.09(0.0036)\\ &\quad+0.04(0.0225)\\ &\quad+2(0.15)(-0.00216)\\ &\quad+2(0.10)(0.00135)\\ &\quad+2(0.06)(0.00225)\\ &=0.0081+0.000324+0.0009\\ &\quad-0.000648+0.00027+0.00027\\ &=0.009216,\\ \sigma_p&=\sqrt{0.009216}=9.60\%. \end{aligned} \]

คำตอบ: SD ของพอร์ตรายปีคือ 9.60% พจน์คู่หุ้น–หุ้นกู้ติดลบ ($-0.000648$) เพราะ correlation ของคู่นี้ติดลบ มันจึงดึงความเสี่ยงรวมลง

ตรวจเองใน 10 วินาที: ช่องหุ้น–หุ้นกู้ต้องติดลบ เพราะ correlation ติดลบ และ $\Sigma_{21}$ ต้องเท่ากับ $\Sigma_{12}$ อีกวิธีตรวจคือเทียบกับการเฉลี่ย SD ตรง ๆ ซึ่งได้ $0.5(18)+0.3(6)+0.2(15)=13.8\%$ สูงกว่าคำตอบจริงมาก เพราะการเฉลี่ย SD ตรง ๆ เท่ากับสมมติว่า correlation ทุกคู่เป็น 1 คือทุกตัวขึ้นลงพร้อมกันเต็มที่ ซึ่งไม่จริง

ความผิดที่โปรแกรมไม่เตือน

  • ลำดับชื่อไม่ตรง: โค้ดคำนวณผ่าน แต่จับ covariance ของคนละคู่ ในคำถามเปิด ตัวเลขผิดคือ $\sqrt{w^{\mathsf T}\Sigma'w}=1.8958\%$ ตัวเลขถูกคือ $\sqrt{w^{\mathsf T}\Sigma w}=1.6571\%$ วิธีกันคือเก็บชื่อสินทรัพย์ไว้คู่กับตารางเสมอ
  • หน่วยปนกัน: เอาตาราง bp² ไปคำนวณ แล้วอ่านผลเป็นทศนิยม เพราะ $1\text{ bp}=10^{-4}$ จึงได้ $1\text{ bp}^2=10^{-8}$ ตัวอย่างจากตารางสามวัน พอร์ตครึ่งต่อครึ่งมี variance 1.75 bp² ตัวเลขผิดคือ อ่าน 1.75 เป็นทศนิยม ได้ SD $\sqrt{1.75}\approx1.32$ หรือ 132% ต่อวัน ตัวเลขถูกคือ $1.75\times10^{-8}$ ได้ SD $\sqrt{1.75\times10^{-8}}\approx0.000132$ หรือ 1.32 bp จำไว้ว่า mean แปลงด้วย $10^{-4}$ แต่ covariance แปลงด้วย $10^{-8}$
  • ต่างช่วงเวลา หรือข้อมูลขาด: ถ้าแต่ละคู่ใช้คนละชุดวัน ตารางอาจสมมาตรแต่ไม่ PSD เหมือนตารางสีแดงในขั้นเรื่อง PSD ตารางผิดมี $\Sigma_{12}=2$ ให้ variance ของพอร์ต hedge ต่ำสุด $-1/3$ และ correlation $2/\sqrt3\approx1.155$ ตารางถูกมี $\Sigma_{12}=1.5$ ให้ variance ต่ำสุด $0.25$ วิธีตรวจคือดูว่า correlation ทุกคู่อยู่ระหว่าง −1 ถึง 1 และ eigenvalue ที่เล็กที่สุดไม่ติดลบ
  • เชื่อค่าเฉลี่ยมากเกินไป: ค่าเฉลี่ยประมาณยากกว่า covariance มาก ตัวอย่าง LV ในตาราง 8 กลุ่มมี SD $\sigma=17.21\%$ ต่อปี ถ้าประมาณค่าเฉลี่ยรายปีจากข้อมูล $T=5$ ปี standard error ของค่าเฉลี่ยคือ $\sigma/\sqrt T=17.21\%/\sqrt5\approx7.7\%$ แต่ค่าเฉลี่ยรายปีที่ประมาณได้ของทั้ง 8 กลุ่มใน workbook อยู่ระหว่าง −6.75% ถึง 3.15% ความคลาดเคลื่อนจึงใหญ่กว่าตัวค่าเฉลี่ยเอง ค่าเฉลี่ยที่ได้อาจห่างค่าจริงมาก แม้ตาราง covariance จะค่อนข้างนิ่ง
  • ข้อมูลน้อยกว่าจำนวนสินทรัพย์: ถ้า $T\le n$ ตาราง $\hat\Sigma$ จะ singular แน่นอน เพราะ rank ไม่เกิน $T-1\lt n$ เช่นหุ้น 500 ตัวกับข้อมูล 250 วันได้ rank ไม่เกิน 249 ห้ามเอาตารางนี้ไปหา inverse ตรง ๆ

ใช้ทำอะไรในงานจริง

ระบบความเสี่ยงของบริษัทลงทุนเก็บ $\mu$ กับ $\Sigma$ ไว้ที่เดียว แล้วคำนวณความเสี่ยงของพอร์ตใดก็ได้ด้วย $\sqrt{w^{\mathsf T}\Sigma w}$ ใน spreadsheet สูตรเดียวกันเขียนด้วย MMULT ได้ คือแถวน้ำหนัก คูณตาราง covariance คูณคอลัมน์น้ำหนัก แล้วถอดราก

optimizer ของ Markowitz portfolio selection ซึ่งหาน้ำหนักพอร์ตที่ให้ผลตอบแทนคาดหวังสูงสุดที่ความเสี่ยงระดับหนึ่ง ต้องการ $\mu$ กับ $\Sigma$ เป็น input ส่วน PCA แยก $\Sigma$ ออกเป็นทิศทางความเสี่ยงหลัก เช่นทิศ “หุ้นทั้งตลาดขึ้นลงพร้อมกัน” ที่เห็นในตาราง 8 กลุ่ม

ข้อจำกัดคือ mean กับ covariance ยังไม่บอก distribution ทั้งหมด มันไม่บอกโอกาสขาดทุนหนักในหาง (วันที่ขาดทุนแรงผิดปกติ) และไม่จับความสัมพันธ์แบบไม่เป็นเส้นตรง หน้า zero covariance ไม่ได้แปลว่าอิสระ จะแสดงตัวอย่างที่ covariance เป็นศูนย์ แต่ตัวแปรหนึ่งกำหนดอีกตัวได้ทั้งหมด

โจทย์ตรวจความเข้าใจ

1. ใช้ข้อมูลสามวันของ Technology (4, 6, 5 bp) กับ Energy (1, 4, 1 bp) เดิม สมมติว่าพบภายหลังว่าระบบบันทึกผลตอบแทนของ Technology ขาดไปวันละ 100 bp ทุกวัน จึงต้องบวก 100 bp ให้ Technology ทุกวัน mean vector และ covariance matrix เปลี่ยนอย่างไร

เฉลย

ข้อมูล Technology ใหม่คือ 104, 106, 105 bp ค่าเฉลี่ยใหม่และการเบี่ยงคือ

\[ \begin{aligned} \hat\mu_1&=(104+106+105)/3=105,\\ \hat\mu&=(105,\ 2)\text{ bp},\\ r_{t,1}-\hat\mu_1&=-1,\ +1,\ 0. \end{aligned} \]

การเบี่ยงของ Technology เหมือนเดิมทุกวัน และของ Energy ก็ไม่เปลี่ยน covariance จึงเป็น $\begin{bmatrix}1&1.5\\1.5&3\end{bmatrix}$ bp² เท่าเดิม ลองดูพอร์ตครึ่งต่อครึ่ง $w=(0.5,\ 0.5)$

\[ \begin{aligned} w^{\mathsf T}\hat\mu&=0.5(105)+0.5(2)=53.5\text{ bp},\\ w^{\mathsf T}\hat\Sigma w&=0.25(1)+0.25(3)\\ &\quad+2(0.25)(1.5)=1.75\text{ bp}^2. \end{aligned} \]

ค่าเฉลี่ยขยับ แต่ variance ยัง 1.75 bp² เท่ากับก่อนบวก การเลื่อนศูนย์กลางด้วยค่าคงที่ไม่ทำให้ข้อมูลกระจายมากขึ้น

2. ข้อมูลสามวันเขียนเป็น bp แต่ระบบความเสี่ยงรับเฉพาะทศนิยม ต้องคูณ mean และ covariance ด้วยอะไร และ correlation เปลี่ยนไหม

เฉลย

เพราะ $1\text{ bp}=10^{-4}$ ผลตอบแทนทุกค่าจึงคูณ $10^{-4}$ ค่าเฉลี่ยก็คูณ $10^{-4}$ ตาม ส่วน covariance เป็นผลคูณของการเบี่ยงสองตัว แต่ละตัวคูณ $10^{-4}$ จึงคูณรวม $10^{-4}\times10^{-4}=10^{-8}$

\[ \begin{aligned} \hat\mu&=(5,\ 2)\times10^{-4}\\ &=(0.0005,\ 0.0002),\\ \hat\Sigma&=10^{-8}\begin{bmatrix}1&1.5\\1.5&3\end{bmatrix},\\ \hat C_{12}&=\frac{1.5\times10^{-8}}{\sqrt{(1\times10^{-8})(3\times10^{-8})}}\\ &=\frac{1.5}{\sqrt3}\approx0.866. \end{aligned} \]

correlation เท่าเดิม เพราะตัวคูณหน่วย $10^{-8}$ ตัดกันทั้งเศษและส่วน

3. สมมติข้อมูลชุดใหม่ที่ Energy ได้ 2 bp เท่ากันทั้งสามวัน ส่วน Technology ยังเป็น 4, 6, 5 bp ระบบต้องการ correlation ทุกคู่ ควรใส่ correlation ของสองกลุ่มเป็นศูนย์หรือไม่

ไม่ควร ค่าเฉลี่ยของ Energy คือ 2 การเบี่ยงจึงเป็น $2-2=0$ ทุกวัน ผลคือ

\[ \begin{aligned} \hat\Sigma_{12}&=\frac{(-1)(0)+(1)(0)+(0)(0)}{2}=0,\\ \hat\Sigma_{22}&=\frac{0^2+0^2+0^2}{2}=0,\\ \hat C_{12}&=\frac{0}{\sqrt{1\cdot0}}=\frac00. \end{aligned} \]

covariance คือ $\begin{bmatrix}1&0\\0&0\end{bmatrix}$ bp² แต่ correlation ต้องหารด้วย SD ของ Energy ซึ่งเป็นศูนย์ จึงนิยามไม่ได้ การใส่ศูนย์แทน แล้วสรุปว่า “ไม่สัมพันธ์” เป็นการสร้างข้อมูลขึ้นเอง ข้อมูลสามวันนี้แค่ไม่เห็นความผันผวนของ Energy ไม่ได้พิสูจน์ว่าอนาคตไม่มีความเสี่ยง

// ข้อมูลสามวัน (bp): แถว = วัน, คอลัมน์ = Technology, Energy
const rows = [[4, 1], [6, 4], [5, 1]];
const T = rows.length, n = rows[0].length;
const idx = [...Array(n).keys()];
const mean = idx.map(j => rows.reduce((s, r) => s + r[j], 0) / T);
const dev = rows.map(r => r.map((x, j) => x - mean[j]));
const cov = idx.map(i => idx.map(j =>
  dev.reduce((s, d) => s + d[i] * d[j], 0) / (T - 1)));
const corr = cov.map((r, i) => r.map((x, j) => x / Math.sqrt(cov[i][i] * cov[j][j])));
const quad = (S, w) => w.reduce((s, wi, i) =>
  s + wi * S[i].reduce((t, x, j) => t + x * w[j], 0), 0);
console.log(mean, cov, corr[0][1], quad(cov, [0.5, 0.5]));   // [5,2] ... 0.866 1.75

// ผลรวมกำลังสองรอบค่าเฉลี่ยตัวอย่าง เทียบกับรอบ 4.5
const ss = c => rows.reduce((s, r) => s + (r[0] - c) ** 2, 0);
console.log(ss(5), ss(4.5));                                  // 2 2.75

// hedge: ซื้อ Technology 1 หน่วย ขาย Energy k หน่วย
const hedge = (S, k) => quad(S, [1, -k]);
console.log(hedge(cov, 0.5), hedge([[1, 2], [2, 3]], 2 / 3)); // 0.25 -0.333

// แบบจำลองสามกลุ่ม และตารางที่เรียง Energy ก่อน
const S = [[4, 0.8, 1.2], [0.8, 9, 1.8], [1.2, 1.8, 6]].map(r => r.map(x => x * 1e-4));
const w = [0.5, 0.3, 0.2], mu = [0.0005, 0.0002, 0.00035];
const p = [1, 0, 2];
const swapped = p.map(i => p.map(j => S[i][j]));
console.log(w.reduce((s, x, i) => s + x * mu[i], 0),          // 0.00038
  Math.sqrt(quad(S, w)) * 1e7,                                  // 165711
  Math.sqrt(quad(swapped, w)) * 1e7,                            // 189578
  quad(swapped, p.map(i => w[i])));                             // 0.0002746

// SD กับ correlation กลับเป็น covariance (Sigma = D C D)
const sd = [0.18, 0.06, 0.15];
const C = [[1, -0.2, 0.05], [-0.2, 1, 0.25], [0.05, 0.25, 1]];
const annual = C.map((r, i) => r.map((x, j) => x * sd[i] * sd[j]));
console.log(Math.sqrt(quad(annual, w)), [8, 500].map(k => k * (k + 1) / 2)); // 0.096 [36,125250]

สิ่งที่ควรตอบได้หลังอ่าน

  • mean vector คือค่าเฉลี่ยทีละช่อง covariance matrix คือ $\mathbb E[(R-\mu)(R-\mu)^{\mathsf T}]$ แนวทแยงเป็น variance ส่วนนอกแนวทแยงเป็นค่าเฉลี่ยของผลคูณการเบี่ยงของแต่ละคู่
  • สร้าง $\hat\mu$ กับ $\hat\Sigma$ จากข้อมูลดิบได้ด้วยมือ และอธิบายได้ว่าทำไมหารด้วย $T-1$: ระยะที่วัดรอบค่าเฉลี่ยตัวอย่างสั้นกว่าระยะรอบค่าเฉลี่ยจริง และ $T-1$ ชดเชยส่วนนั้นโดยเฉลี่ย
  • covariance ทุกตารางต้องสมมาตรและ PSD เพราะ $w^{\mathsf T}\Sigma w$ คือ variance ของพอร์ต ตารางที่ทำให้พอร์ตใดมี variance ติดลบใช้ไม่ได้
  • แปลง covariance เป็น correlation ด้วย $D^{-1}\Sigma D^{-1}$ และแปลงกลับด้วย $DCD$ correlation ไม่มีหน่วย จึงไม่เปลี่ยนเมื่อเปลี่ยนหน่วย
  • ตาราง $n$ สินทรัพย์มีค่าอิสระ $n(n+1)/2$ ค่า ถ้าข้อมูลมีจำนวนวันน้อยกว่าจำนวนสินทรัพย์ ตารางจะ singular และลำดับชื่อในตารางต้องตรงกับลำดับน้ำหนักเสมอ

หน้าถัดไป linear transformation และความเสี่ยงของพอร์ต จะใช้ตารางนี้คำนวณความเสี่ยงของพอร์ตและกลยุทธ์หลายแบบพร้อมกันด้วย $A\Sigma A^{\mathsf T}$ และดูว่าการกระจายการลงทุนช่วยได้แค่ไหน
