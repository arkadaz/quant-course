8.1 The Mean Vector and the Covariance Matrix

ตารางความเสี่ยงต้องบอกว่าเลขของใคร ใช้หน่วยอะไร และคำนวณจากช่วงเวลาไหน

สองทีมส่ง covariance matrix ของหุ้นสามกลุ่มมาให้ ตัวเลขชุดเดียวกัน แต่ทีมหนึ่งเรียง Technology–Energy–Financials อีกทีมเรียง Energy–Technology–Financials ทั้งสองตารางสมมาตรและมี eigenvalue บวก ถ้าใส่น้ำหนัก $(0.5,0.3,0.2)$ เหมือนกัน จะได้ความเสี่ยงเท่ากันไหม?

ลองตอบก่อนเปิดเฉลย

ไม่จำเป็น เพราะน้ำหนักตัวแรกจะไปจับคนละสินทรัพย์ ในตัวอย่างท้ายบท SD รายวันเปลี่ยนจาก 1.6571% เป็น 1.8958% ทั้งที่โปรแกรมคูณ matrix ได้ตามปกติ ต้องเรียงชื่อ ค่าเฉลี่ย covariance และน้ำหนักให้ตรงกัน ไม่ใช่ตรวจเพียงขนาดตาราง

สิ่งที่เราจะสร้าง

บทที่ 7 สอนวิธีคูณตาราง บทนี้เริ่มจากสิ่งที่ตารางแทน: ผลตอบแทนที่ยังไม่รู้ล่วงหน้า เราจะสร้างค่าเฉลี่ยและ covariance จากข้อมูลสามวัน แล้วแยกให้ชัดว่าค่าที่คำนวณจากตัวอย่างต่างจากค่าของแบบจำลองอย่างไร

ข้อมูลที่ดีต้องมีทั้งตัวเลขและป้ายกำกับ ตลอดบทให้ผลตอบแทนเป็น simple return ของช่วงเวลาที่ระบุ ตัวอย่างทั้งหมดเป็นข้อมูลสมมติของสินทรัพย์สหรัฐฯ ไม่ใช่ค่าประมาณล่าสุดจากตลาด

ค่าเฉลี่ยและ SD ใช้หน่วยเดียวกับ returns ส่วน covariance ใช้ผลคูณหน่วยของสองตัวแปร สำหรับ returns หน่วยเดียวกันจึงเป็น return² หรือ bp² คำว่า “รายวัน” ระบุช่วงถือครอง ไม่ได้สั่งให้หาร covariance ด้วยจำนวนวันอีกครั้ง

ขั้นที่ 1 — กำหนดความหมายของทุกช่องก่อนคำนวณ

ให้ $R$ เป็นคอลัมน์ที่เรียง Technology, Energy, Financials ทุกช่องวัดผลตอบแทนหนึ่งวันตรงกัน ค่าเฉลี่ยของ vector คือค่าเฉลี่ยทีละช่อง โดยสมมติว่าค่าเฉลี่ยของผลตอบแทนยกกำลังสองของแต่ละตัวมีค่าจำกัด

\[ \begin{aligned} R&=(R_1,R_2,R_3)^{\mathsf T},\\ \mu:=\mathbb E[R]&=(\mathbb E[R_1],\mathbb E[R_2],\mathbb E[R_3])^{\mathsf T},\\ \text{ตัวอย่างกำหนดให้ }\mu&=(0.0005,0.0002,0.00035)^{\mathsf T}\\ &=(5,2,3.5)^{\mathsf T}\ \text{bp}. \end{aligned} \]

สามค่านี้บอกศูนย์กลางสามตำแหน่ง ไม่ได้บอกว่า returns ของแต่ละกลุ่มกระจายแค่ไหน หรือสองกลุ่มมักเบี่ยงจากค่าเฉลี่ยไปทางเดียวกันหรือไม่ ตัวอย่างในขั้นนี้เป็นค่าที่กำหนดให้ ไม่ได้ประมาณจากตารางสามวันที่เราจะใช้ต่อไป

ขั้นที่ 2 — หักค่าเฉลี่ย แล้วเก็บผลคูณของทุกคู่

เขียน $Z=R-\mu$ เพื่อวัดการเบี่ยงจากศูนย์กลาง ถ้า $Z_i$ กับ $Z_j$ เป็นบวกพร้อมกันหรือติดลบพร้อมกัน ผลคูณเป็นบวก ถ้าไปคนละทาง ผลคูณเป็นลบ covariance คือค่าเฉลี่ยของผลคูณนี้

\[ \begin{aligned} Z&:=R-\mu,\\ \Sigma&:=\mathbb E[ZZ^{\mathsf T}],\\ ZZ^{\mathsf T}&=\begin{bmatrix}Z_1^2&Z_1Z_2\\Z_2Z_1&Z_2^2\end{bmatrix}\quad\text{กรณีสองตัวแปร},\\ \Sigma_{ij}&=\mathbb E[(R_i-\mu_i)(R_j-\mu_j)]\\ &=\mathbb E[R_iR_j]-\mu_i\mu_j,\\ \Sigma_{ii}&=\mathbb E[(R_i-\mu_i)^2]=\operatorname{Var}(R_i). \end{aligned} \]

ต้องใช้ outer product $ZZ^{\mathsf T}$ ซึ่งให้ตาราง $n\times n$ ไม่ใช่ $Z^{\mathsf T}Z$ ที่รวมทุกช่องเป็น scalar covariance เป็นบวกหมายถึงผลคูณของการเบี่ยงมีค่าเฉลี่ยบวก ไม่ได้แปลว่าทั้งสองตัวต้องขึ้นลงพร้อมกันทุกวัน

ด้วย second moment ที่จำกัด นิยามนี้ใช้ได้โดยไม่ต้องสมมติ Normal แต่ mean กับ covariance ยังไม่บอก distribution ทั้งหมด เช่น ไม่กำหนดโอกาสขาดทุนรุนแรงหรือความสัมพันธ์ที่ไม่เป็นเส้นตรง

ขั้นที่ 3 — สร้างตารางจาก returns สามวันด้วยมือ

คราวนี้เปลี่ยนเป็นข้อมูลจำลองขนาดเล็กของสองกลุ่ม Technology และ Energy หน่วย bp ใช้วันเดียวกันทั้งสองคอลัมน์ และให้แต่ละวันมีน้ำหนักเท่ากัน

\[ \begin{aligned} \hat\mu&=\frac13\sum_{t=1}^{3}r_t =\begin{bmatrix}(4+6+5)/3\\(1+4+1)/3\end{bmatrix} =\begin{bmatrix}5\\2\end{bmatrix}\text{ bp},\\ \hat\Sigma&:=\frac1{T-1}\sum_{t=1}^{T}(r_t-\hat\mu)(r_t-\hat\mu)^{\mathsf T},\\ \hat\Sigma_{11}&=\frac{(-1)^2+1^2+0^2}{2}=1,\\ \hat\Sigma_{22}&=\frac{(-1)^2+2^2+(-1)^2}{2}=3,\\ \hat\Sigma_{12}&=\frac{(-1)(-1)+(1)(2)+(0)(-1)}2=1.5,\\ \hat\Sigma&=\begin{bmatrix}1&1.5\\1.5&3\end{bmatrix}\text{ bp}^2. \end{aligned} \]

ค่าเฉลี่ยใช้ตัวหาร 3 แต่ sample covariance สูตรนี้ใช้ 2 เพราะประมาณค่าเฉลี่ยจากข้อมูลชุดเดียวกันด้วย อย่าเอา variance หน่วย bp² ในตารางเล็กนี้ไปปะกับแบบจำลองสามกลุ่มหน่วยทศนิยมในขั้นที่ 7 แม้ชื่อสินทรัพย์จะตรงกัน

ขั้นที่ 4 — ตัวหาร $T-1$ แก้อะไร และไม่ได้แก้อะไร

ถ้า returns แต่ละวันเป็น IID มีค่าเฉลี่ย $\mu$ และ covariance $\Sigma$ เดียวกัน การใช้ sample mean ทำให้ความกระจายที่คำนวณรอบมันเล็กลงโดยเฉลี่ย ตัวหาร $T-1$ ชดเชยผลนี้จน $\mathbb E[\hat\Sigma]=\Sigma$ เรียกว่า unbiased estimator

พิสูจน์ว่าทำไมเหลือ $T-1$

ให้ $\bar R=T^{-1}\sum_t R_t$ ขยายวงเล็บแล้วใช้ $\sum_t(R_t-\mu)=T(\bar R-\mu)$ ภายใต้ IID เรามี $\operatorname{Cov}(\bar R)=\Sigma/T$ จึงได้

\[ \begin{aligned} &\sum_t(R_t-\bar R)(R_t-\bar R)^{\mathsf T}\\ &=\sum_t(R_t-\mu)(R_t-\mu)^{\mathsf T} -T(\bar R-\mu)(\bar R-\mu)^{\mathsf T},\\ \mathbb E[(T-1)\hat\Sigma]&=T\Sigma-T(\Sigma/T)=(T-1)\Sigma,\\ \mathbb E[\hat\Sigma]&=\Sigma\quad(T\ge2). \end{aligned} \]

IID เป็นเงื่อนไขที่เพียงพอสำหรับผลข้างต้น ไม่ใช่สิ่งที่ข้อมูลตลาดทำตามโดยอัตโนมัติ ถ้าข้อมูลสัมพันธ์ข้ามเวลา ค่าเฉลี่ยเปลี่ยน หรือเลือกแต่วันที่มีข้อมูลครบจนเกิด selection bias ต้องทบทวนวิธีประมาณอีกครั้ง

ถ้าต้องการ covariance ของ empirical distribution ที่ให้โอกาสแต่ละแถว $1/T$ ให้หารด้วย $T$ แทน นั่นเป็นคนละเป้าหมาย ไม่ใช่ตัวหารผิด ส่วน “unbiased” ก็ไม่ได้รับประกันว่าตัวอย่างเพียงสามวันใกล้ความจริง

ขั้นที่ 5 — ทำไมตารางนี้สมมาตร และให้ variance ติดลบไม่ได้

การคูณจำนวนจริงสลับที่กันได้ จึงมี $\Sigma_{ij}=\Sigma_{ji}$ ส่วนเงื่อนไข PSD มาจากการที่ variance ของผลรวมเชิงเส้นต้องไม่ติดลบ สำหรับน้ำหนัก $w$ ที่กำหนดคงที่ในช่วงที่ศึกษา

\[ \begin{aligned} \Sigma_{ij}&=\mathbb E[Z_iZ_j]=\mathbb E[Z_jZ_i]=\Sigma_{ji},\\ w^{\mathsf T}\Sigma w &=\mathbb E[w^{\mathsf T}ZZ^{\mathsf T}w]\\ &=\mathbb E[(w^{\mathsf T}Z)^2] =\operatorname{Var}(w^{\mathsf T}R)\ge0,\\ w=(1/2,1/2)^{\mathsf T}:\quad w^{\mathsf T}\hat\Sigma w &=\tfrac14(1)+2\tfrac14(1.5)+\tfrac14(3)\\ &=1.75\text{ bp}^2,\\ \hat\sigma_p&=\sqrt{1.75}\approx1.3229\text{ bp}. \end{aligned} \]

ตรวจจากอีกทางได้ทันที: returns ของพอร์ตครึ่งต่อครึ่งคือ $(2.5,5,3)$ bp มีค่าเฉลี่ย 3.5 bp และ sample variance $[(-1)^2+1.5^2+(-0.5)^2]/2=1.75$ bp² ตรงกับการคูณ matrix

PSD ไม่จำเป็นต้องเป็น PD ถ้าตัวแปรบางตัวซ้ำกันหรือมีข้อมูลน้อย ตารางอาจมีทิศทาง variance ศูนย์ สำหรับ centered data matrix $X$ ขนาด $T\times n$ สูตร $\hat\Sigma=X^{\mathsf T}X/(T-1)$ ให้ rank ไม่เกิน $\min(n,T-1)$ ตามเหตุผลใน 7.5

ดังนั้น 500 สินทรัพย์จาก 250 วันได้ rank ไม่เกิน 249 แม้โปรแกรมสร้างตาราง 500×500 ครบทุกช่องก็ตาม และ matrix ที่สมมาตรเพียงอย่างเดียวก็ยังไม่ใช่หลักฐานว่าเป็น covariance ที่ใช้ได้

ขั้นที่ 6 — หารด้วย SD เพื่อเปรียบเทียบ correlation

covariance ใหญ่ขึ้นได้เพราะสินทรัพย์เหวี่ยงแรงขึ้น แม้ correlation เท่าเดิม เราจึงหารช่อง $ij$ ด้วย $\sigma_i\sigma_j$ ถ้า SD ของทุกตัวเป็นบวก ให้ $D$ เก็บ SD บนแนวทแยง

\[ \begin{aligned} D&:=\operatorname{diag}(\sigma_1,\ldots,\sigma_n),\\ C_{ij}&:=\frac{\Sigma_{ij}}{\sigma_i\sigma_j}, \qquad C=D^{-1}\Sigma D^{-1},\\ \text{ข้อมูลสามวัน: }D&=\operatorname{diag}(1,\sqrt3)\text{ bp},\\ C_{12}&=\frac{1.5}{1\sqrt3}\approx0.8660,\\ C&\approx\begin{bmatrix}1&0.8660\\0.8660&1\end{bmatrix}. \end{aligned} \]

correlation ไม่มีหน่วยและอยู่ในช่วง $[-1,1]$ จาก Cauchy–Schwarz ใน 6.5 การเปลี่ยน returns จาก bp เป็นทศนิยมไม่เปลี่ยน correlation แต่ไม่ได้ทำให้มันกลายเป็นตัววัดความสัมพันธ์ทุกแบบ ดูตัวอย่าง zero covariance ที่ยังไม่อิสระใน 8.3

ถ้าคอลัมน์หนึ่งคงที่ SD เป็นศูนย์และ correlation ที่เกี่ยวข้องนิยามไม่ได้ อย่าใส่ศูนย์แทนแล้วสรุปว่าอิสระกัน และอย่านำ correlation matrix มาใช้แทน covariance โดยลืมคูณ SD กลับ

ขั้นที่ 7 — กลับไปตรวจแฟ้มความเสี่ยงสามกลุ่ม

โจทย์ให้อะไรมาบ้าง: แบบจำลองรายวันเรียง Technology, Energy, Financials มี $\mu=(0.0005,0.0002,0.00035)^{\mathsf T}$ และ $w=(0.5,0.3,0.2)^{\mathsf T}$ ตารางต่อไปนี้กำหนดให้ต่างหาก ไม่ได้ประมาณจากข้อมูลสามวัน

\[ \begin{aligned} \Sigma&=10^{-4}\begin{bmatrix}4&0.8&1.2\\0.8&9&1.8\\1.2&1.8&6\end{bmatrix},\\ \mathbb E[R_p]&=w^{\mathsf T}\mu\\ &=0.5(0.0005)+0.3(0.0002)+0.2(0.00035)\\ &=0.00038=3.8\text{ bp},\\ \operatorname{Var}(R_p)&=w^{\mathsf T}\Sigma w\\ &=10^{-4}(1+0.81+0.24+0.24+0.24+0.216)\\ &=0.0002746,\\ \sigma_p&=\sqrt{0.0002746}\approx0.0165711=1.6571\%. \end{aligned} \]

คำตอบ: พอร์ต NAV \$10 ล้านมี mean P&L \$3,800 ต่อวัน และ SD ประมาณ \$165,710.59 ภายใต้แบบจำลองนี้ โดยยังไม่คิดค่าธรรมเนียม ผลตอบแทนจริงไม่จำเป็นต้องใกล้ค่าเฉลี่ย และ SD ไม่ใช่เพดานขาดทุน

ตรวจเองใน 10 วินาที: ทแยงมุมช่องแรกคือ variance $0.0004$ จึงให้ SD $0.02=2\%$ ไม่ใช่ 0.04% ส่วนช่อง Technology–Financials มี covariance $0.00012$ จึงได้ correlation $0.00012/(0.02\sqrt{0.0006})\approx0.24495$

เฉลยกับดักการสลับชื่อในคำถามเปิด

ถ้าเรียงใหม่เป็น Energy, Technology, Financials ต้องสลับทั้งสองแกนของ covariance และสลับ mean กับ weights ด้วย การสลับอย่างถูกต้องไม่เปลี่ยนพอร์ต

\[ \begin{aligned} \Sigma'&=10^{-4}\begin{bmatrix}9&0.8&1.8\\0.8&4&1.2\\1.8&1.2&6\end{bmatrix},\\ \mu'&=(0.0002,0.0005,0.00035)^{\mathsf T},\\ w'&=(0.3,0.5,0.2)^{\mathsf T},\\ (w')^{\mathsf T}\mu'&=0.00038, \quad (w')^{\mathsf T}\Sigma'w'=0.0002746,\\ \text{แต่ใช้ }w\text{ เดิม: }w^{\mathsf T}\Sigma'w &=10^{-4}(2.25+0.36+0.24+0.24+0.36+0.144)\\ &=0.0003594,\\ \sqrt{0.0003594}&\approx1.8958\%. \end{aligned} \]

การสลับทั้งสองแกนคง symmetry และ eigenvalues ไว้ จึงผ่านการตรวจเชิงพีชคณิตได้ แต่เมื่อจับกับน้ำหนักผิดลำดับก็ตอบคำถามของคนละพอร์ต

ขั้นที่ 8 — ถ้าได้รับ SD กับ correlation แทน จะสร้าง covariance อย่างไร

โจทย์ให้อะไรมาบ้าง: เปลี่ยนเป็นแบบจำลองรายปีของหุ้นสหรัฐ หุ้นกู้สหรัฐ และทองคำอ้างราคา USD กำหนด SD เป็น 18%, 6%, 15% และ correlation คู่หุ้น–หุ้นกู้, หุ้น–ทอง, หุ้นกู้–ทอง เป็น $-0.20,0.05,0.25$ ตามลำดับ

\[ \begin{aligned} \Sigma_{ij}&=\rho_{ij}\sigma_i\sigma_j, \qquad\Sigma=DCD,\\ \Sigma_{11}&=0.18^2=0.0324,\\ \Sigma_{12}&=(-0.20)(0.18)(0.06)=-0.00216,\\ \Sigma_{13}&=(0.05)(0.18)(0.15)=0.00135,\\ \Sigma_{23}&=(0.25)(0.06)(0.15)=0.00225,\\ \Sigma&=\begin{bmatrix}0.0324&-0.00216&0.00135\\-0.00216&0.0036&0.00225\\0.00135&0.00225&0.0225\end{bmatrix},\\ w&=(0.5,0.3,0.2)^{\mathsf T},\\ w^{\mathsf T}\Sigma w&=0.0081+0.000324+0.0009\\ &\quad-0.000648+0.00027+0.00027\\ &=0.009216,\\ \sigma_p&=\sqrt{0.009216}=9.60\%. \end{aligned} \]

คำตอบ: ได้ SD ของพอร์ตรายปี 9.60% ซึ่งตรงกับตัวอย่างใน 7.3 ไม่ใช่ SD รายวันของสามกลุ่มอุตสาหกรรมในขั้นก่อน

ตรวจเองใน 10 วินาที: ช่องหุ้น–หุ้นกู้ต้องเป็นลบ เพราะ correlation เป็นลบ และ $\Sigma_{21}$ ต้องเท่ากับ $\Sigma_{12}$ การเอาตัวเลขต่างหน่วยหรือต่างช่วงเวลามาปะกันให้ครบตารางไม่สร้างแบบจำลองที่ถูกต้อง

พอร์ตใหญ่ขึ้น ต้องประมาณอะไรเพิ่ม

สำหรับ $n$ สินทรัพย์ mean vector มี $n$ ค่า ส่วน covariance มี variance $n$ ค่าและคู่ที่ไม่ซ้ำ $n(n-1)/2$ คู่ รวม $n(n+1)/2$ ค่า ที่ $n=3$ จึงมี covariance 6 ค่าต่างกัน ไม่ใช่ 9 ค่าที่เป็นอิสระต่อกัน

500 สินทรัพย์ต้องประมาณ covariance 125,250 ค่า และ 1,000 สินทรัพย์ต้องประมาณ 500,500 ค่า ตัวเลขเหล่านี้บอกภาระการประมาณ ไม่ใช่ข้อพิสูจน์ความแม่นยำหรือ rank การเลือกช่วงข้อมูล วิธีให้น้ำหนัก และการลด noise จึงสำคัญพอ ๆ กับสูตร

mean กับ covariance เป็น input สำคัญของ mean–variance portfolio เช่นใน 12.5 แต่ไม่เพียงพอสำหรับทุกปัญหา หากสนใจ tail loss, payoff ที่ไม่เป็นเส้นตรง หรือความเสี่ยงสภาพคล่อง ต้องใช้ข้อมูลและสมมติฐานเพิ่มเติม

ผ่านการคูณ matrix ไม่ได้แปลว่าข้อมูลตอบคำถามเดียวกัน

ตรวจเองก่อนผ่านไป 8.2

1. เพิ่ม 100 bp ให้ Technology ทุกวันในตารางสามวัน mean และ covariance เปลี่ยนอย่างไร?

เฉลย

mean เปลี่ยนจาก $(5,2)$ เป็น $(105,2)$ bp แต่ deviations เหมือนเดิมจึงได้ covariance เดิม พอร์ตครึ่งต่อครึ่งมี mean 53.5 bp แต่ variance ยัง 1.75 bp² การย้ายศูนย์กลางด้วยค่าคงที่ไม่เพิ่มความกระจาย

2. เปลี่ยนข้อมูลสามวันจาก bp เป็นทศนิยม ต้องคูณ mean และ covariance ด้วยตัวใด?

เฉลย

mean คูณ $10^{-4}$ ได้ $(0.0005,0.0002)$ ส่วน covariance คูณ $10^{-8}$ ได้ช่อง $10^{-8},1.5\times10^{-8},3\times10^{-8}$ ตามเดิม SD พอร์ตครึ่งต่อครึ่งเป็น $\sqrt{1.75}\times10^{-4}$ หรือ 1.3229 bp เท่าเดิม correlation ไม่เปลี่ยน

3. แทน Energy ทั้งสามวันด้วย 2 bp ควรใส่ correlation ของสองกลุ่มเป็นศูนย์หรือไม่?

เฉลย

ไม่ควร covariance จะเป็น $\operatorname{diag}(1,0)$ bp² แต่ correlation ต้องหารด้วย SD ของ Energy ที่เป็นศูนย์ จึงนิยามไม่ได้ ข้อมูลสามวันนี้แค่ไม่แสดงความแปรปรวนของ Energy ไม่ได้พิสูจน์ว่าอนาคตไม่มีความเสี่ยง

จากสถิติหลายตัวแปรสู่การลงทุน

งานด้าน correlation และ PCA ในยุค Pearson ช่วยให้มองความแปรปรวนของหลายตัวแปรร่วมกัน ส่วนงานของ Markowitz ในปี 1952 นำ covariance มาเชื่อมกับการเลือกพอร์ตอย่างเป็นระบบ ประเด็นสำคัญคือความเสี่ยงของพอร์ตไม่ได้ขึ้นกับ variance รายตัวเท่านั้น แต่ขึ้นกับทุกคู่ที่ถือร่วมกัน

คำนวณซ้ำด้วย JavaScript

รันด้วย Node.js ได้โดยไม่ติดตั้งไลบรารี โค้ดคำนวณจาก returns จริงในตาราง ไม่ได้พิมพ์คำตอบสำเร็จรูป การตรวจชื่อและ symmetry เป็นเพียงส่วนหนึ่งของการตรวจข้อมูล ไม่ใช่ตัวตรวจ PSD สำหรับ matrix ทั่วไปหรือหลักฐานว่าแบบจำลองทำนายอนาคตได้

function shape(A) {
  if (!Array.isArray(A) || !A.length || ![...A].every(Array.isArray)) {
    throw new TypeError('Need a rectangular matrix');
  }
  const n = A[0].length;
  if (!n || ![...A].every(r => r.length === n && [...r].every(Number.isFinite))) {
    throw new TypeError('Need a finite rectangular matrix');
  }
  return [A.length, n];
}
function vector(v, n) {
  if (!Array.isArray(v) || v.length !== n || ![...v].every(Number.isFinite)) {
    throw new TypeError('Need a matching finite vector');
  }
}
function dot(a, b) {
  if (!Array.isArray(a) || !a.length) throw new TypeError('Need a nonempty vector');
  vector(a, a.length); vector(b, a.length);
  const value = a.reduce((s, x, i) => s + x * b[i], 0);
  if (!Number.isFinite(value)) throw new RangeError('Arithmetic overflow');
  return value;
}
function sampleMoments(rows) {
  const [T, n] = shape(rows);
  if (T < 2) throw new RangeError('Need at least two observations');
  // Shift first: constant columns then center to exactly zero.
  const offsets = rows.map(r => r.map((x, j) => x - rows[0][j]));
  shape(offsets);
  const ones = rows.map(() => 1);
  const shifts = Array.from({ length: n }, (_, j) =>
    dot(offsets.map(r => r[j]), ones) / T);
  const mean = shifts.map((x, j) => rows[0][j] + x);
  vector(mean, n);
  const centered = offsets.map(r => r.map((x, j) => x - shifts[j]));
  const columns = Array.from({ length: n }, (_, j) => centered.map(r => r[j]));
  const cov = columns.map(a => columns.map(b => dot(a, b) / (T - 1)));
  return { mean, cov };
}
function square(S) {
  const [m, n] = shape(S);
  if (m !== n) throw new RangeError('Need a square matrix');
  return n;
}
function correlation(S) {
  square(S);
  if (S.some((r, i) => r.some((x, j) => x !== S[j][i]))) {
    throw new RangeError('Need a symmetric matrix');
  }
  if (S.some((r, i) => r[i] <= 0)) throw new RangeError('Positive variance required');
  const sd = S.map((r, i) => Math.sqrt(r[i]));
  return S.map((r, i) => r.map((x, j) => x / sd[i] / sd[j]));
}
function portfolio(mean, cov, weights) {
  const n = square(cov);
  vector(mean, n); vector(weights, n);
  const variance = dot(weights, cov.map(r => dot(r, weights)));
  if (variance < 0) throw new RangeError('Negative variance; inspect covariance');
  return { mean: dot(weights, mean), variance, sd: Math.sqrt(variance) };
}
function reorder(mean, cov, from, to) {
  const n = square(cov);
  vector(mean, n);
  for (const names of [from, to]) {
    if (!Array.isArray(names) || names.length !== n ||
        ![...names].every(x => typeof x === 'string' && x.length > 0) ||
        new Set(names).size !== n) throw new TypeError('Need unique asset labels');
  }
  const p = to.map(name => from.indexOf(name));
  if (p.some(i => i < 0)) throw new RangeError('Asset labels do not match');
  return { mean: p.map(i => mean[i]), cov: p.map(i => p.map(j => cov[i][j])) };
}
const rows = [[4, 1], [6, 4], [5, 1]];
const sample = sampleMoments(rows);
const half = portfolio(sample.mean, sample.cov, [0.5, 0.5]);
const halfRows = rows.map(r => [dot(r, [0.5, 0.5])]);
const mean = [0.0005, 0.0002, 0.00035];
const S = [[0.0004, 0.00008, 0.00012],
  [0.00008, 0.0009, 0.00018], [0.00012, 0.00018, 0.0006]];
const w = [0.5, 0.3, 0.2];
const labels = ['Technology', 'Energy', 'Financials'];
const order = ['Energy', 'Technology', 'Financials'];
const switched = reorder(mean, S, labels, order);
const alignedWeights = order.map(name => w[labels.indexOf(name)]);
const sector = portfolio(mean, S, w);
const annualSD = [0.18, 0.06, 0.15];
const annualCorr = [[1, -0.2, 0.05], [-0.2, 1, 0.25], [0.05, 0.25, 1]];
// Multiply the SD pair first so symmetric cells use the same rounding.
const annualCov = annualCorr.map((r, i) =>
  r.map((x, j) => x * (annualSD[i] * annualSD[j])));
const shifted = sampleMoments(rows.map(r => [r[0] + 100, r[1]]));
const decimal = sampleMoments(rows.map(r => r.map(x => x * 1e-4)));
const flat = sampleMoments(rows.map(r => [r[0], 2]));

ช่อง mean ของตัวอย่างรายปีในโค้ดตั้งศูนย์ไว้เพียงเพื่อเรียกฟังก์ชันตรวจ variance เพราะโจทย์รายปีไม่ได้กำหนด expected returns อย่านำศูนย์นี้ไปใช้เป็นสมมติฐานผลตอบแทนของสินทรัพย์จริง

floating-point อาจทำให้คำตอบต่างในหลักท้าย เช่น correlation บนแนวทแยงแสดง 1.0000000000000002 ตัวอย่างสร้าง covariance คู่สมมาตรด้วยลำดับคำนวณเดียวกันและตรวจเท่ากันตรง ๆ งานจริงต้องกำหนด tolerance ตามสเกล พร้อมแยก rounding error ออกจากความผิดของข้อมูลหรือโมเดล

สิ่งที่ควรตอบได้หลังอ่าน

  • mean vector บอกศูนย์กลาง ส่วน covariance เก็บ variance และการเคลื่อนไหวร่วมเชิงเส้น ทั้งคู่ยังไม่ระบุ distribution ทั่วไปทั้งหมด
  • รู้ว่าแต่ละตารางเรียงชื่ออย่างไร ใช้หน่วยและช่วงเวลาอะไร และเป็นค่าของแบบจำลองหรือค่าประมาณจากข้อมูล
  • สร้าง sample covariance จาก deviations ได้ อธิบายตัวหาร $T-1$ ภายใต้สมมติฐานที่ระบุ และตรวจผลด้วย variance ของพอร์ตจากข้อมูลดิบ
  • covariance ต้องสมมาตรและ PSD แต่ไม่จำเป็นต้อง invertible; correlation ต้องใช้ SD ที่เป็นบวก และไม่ใช่ความเป็นอิสระ
  • ใน 8.2 เราจะเปลี่ยนจากพอร์ตเดียวไปสู่การแปลง returns ทั้งชุด และติดตามว่า mean กับ covariance เปลี่ยนตามอย่างไร
