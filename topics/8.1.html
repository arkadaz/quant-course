8.1 Global vs Local Minima

แยกจุดต่ำสุดใกล้ตัวออกจากจุดต่ำสุดของทั้งโจทย์

เดินป่าเจอแอ่งต่ำหลังเนินแรก คุณควรหยุดเพราะลงมาถึงจุดต่ำรอบตัวแล้ว หรือเดินสำรวจต่อเพราะอาจมีหุบที่ต่ำกว่าหลังเนินถัดไป?

เฉลย: ควรสำรวจต่อ; แอ่ง A ต่ำกว่าพื้นรอบข้าง 3 เมตร แต่แอ่ง B ต่ำ 8 เมตร; A ชนะเฉพาะเพื่อนบ้าน ส่วน B ชนะเมื่อเทียบทั้งแผนที่

local minimum คือจุดต่ำเมื่อมองใกล้ ๆ ส่วน global minimum ต่ำสุดในทุกจุดที่อนุญาต ใช้แยกคำตอบที่ algorithm พบจากคำตอบที่โจทย์ต้องการจริง

หลุมแรกอาจต่ำจริงแต่ไม่ใช่ต่ำสุด; งานจริงทำ multi-start และตรวจ bound ก่อนเชื่อผล optimization

ศัพท์ที่ใช้ในหัวข้อนี้
global minimum
จุดที่ให้ค่า objective ไม่สูงกว่าจุดใดใน feasible set ใช้เป็นคำตอบต่ำสุดของปัญหาทั้งหมด
local minimum
จุดที่ไม่มีเพื่อนบ้านใกล้ ๆ ให้ objective ต่ำกว่า ใช้บอกผลที่วิธีค้นหาเฉพาะบริเวณอาจหยุด
convexity
ความโค้งแบบชามของ function ซึ่งกราฟอยู่ไม่สูงกว่าเส้นเชื่อมคู่ตำแหน่ง ใช้รับรองว่า local minimum ทุกจุดเป็น global minimum
feasible set
ชุดคำตอบที่ผ่านข้อจำกัดทั้งหมด ใช้กำหนดบริเวณที่อนุญาตให้เปรียบเทียบ objective
positive semidefinite
คุณสมบัติของ matrix ที่ quadratic form ไม่ติดลบทุกทิศ ใช้พิสูจน์ convexity หรือความโค้งแบบชามของ portfolio variance
variance
ค่าเฉลี่ยของ squared deviation จาก mean ใช้วัดขนาดความกระจายและสร้าง objective ความเสี่ยงของพอร์ต
covariance
ค่าที่วัดว่าสอง returns เคลื่อนร่วมกันอย่างไร ใช้รวมความเสี่ยงข้ามสินทรัพย์ใน portfolio variance
correlation
covariance ที่ส่วนด้วย volatilities ให้สเกลอยู่ระหว่าง -1 กับ 1 ใช้เปรียบเทียบการเคลื่อนร่วมกัน
volatility
standard deviation ของ return ตาม horizon ที่ระบุ ใช้รายงานความเสี่ยงในหน่วยเดียวกับ return
standard deviation
square root ของ variance ใช้แปลงความกระจายกลับมาอยู่ในหน่วยเดียวกับ return
alpha
ในบทนี้หมายถึงสัดส่วนผสมระหว่างคู่ตำแหน่ง ใช้เลือกทุกตำแหน่งบนเส้นตรงที่เชื่อมกัน
iShares Core U.S. Aggregate Bond exchange-traded fund (AGG)
กองทุนที่ซื้อขายบน exchange และถือพันธบัตรสหรัฐฯ แบบกว้าง ใช้เป็นขาที่มีความผันผวนต่ำกว่า SPY ในตัวอย่างพอร์ต
สัญลักษณ์ที่ใช้ในหัวข้อนี้
สัญลักษณ์ความหมายหน่วย

ที่มาที่ไป: คำว่าคำตอบที่ดีที่สุด มีสองความหมายที่ไม่เหมือนกัน

ปัญหาที่ทำให้ต้องแยกสองคำนี้ออกจากกันเกิดขึ้นจริงทุกครั้งที่มีคนปรับ parameter ของกลยุทธ์

โปรแกรมรันแล้วรายงานว่าเจอคำตอบแล้ว ผู้ใช้เชื่อ แล้วเอาไปใช้จริง โดยไม่รู้ว่ามันเจอแค่ก้นหลุมที่ใกล้ที่สุด จากจุดที่มันบังเอิญเริ่ม ไม่ใช่ก้นหลุมที่ลึกที่สุด

อาการที่สังเกตได้คือรันสองครั้งด้วยจุดเริ่มต่างกัน แล้วได้คำตอบคนละเรื่อง

หัวข้อนี้ให้เงื่อนไขที่ถ้าผ่าน จะไม่มีปัญหานี้เลย และโชคดีที่ปัญหาจัดพอร์ตมาตรฐานผ่านเงื่อนไขนั้น แต่ปัญหาปรับกลยุทธ์ส่วนใหญ่ไม่ผ่าน ซึ่งต้องรู้ไว้ก่อนจะเชื่อผลที่รันออกมา

ที่มาทางประวัติศาสตร์ — จาก Fermat สู่ Fenchel และ Rockafellar

ในทศวรรษ 1630 Pierre de Fermat ริเริ่มแนวคิดการหาค่าสูงสุดและต่ำสุดด้วยการตั้ง derivative ให้เท่ากับศูนย์ ซึ่งเป็นจุดกำเนิดของเงื่อนไข stationary point ทว่าตลอดสามร้อยปีต่อมา นักคณิตศาสตร์มักมองหาเพียงจุดที่ความชันเป็นศูนย์ โดยไม่สามารถแยกแยะได้ง่ายว่าจุดนั้นเป็นเพียงหลุมท้องถิ่น หลุมที่ลึกที่สุดของทั้งระบบ หรือเป็นเพียง saddle point

จุดเปลี่ยนเกิดขึ้นช่วงทศวรรษ 1940–1950 เมื่อ George Dantzig พัฒนา simplex method สำหรับ linear programming และ Harry Markowitz เสนอแบบจำลองจัดพอร์ตในปี 1952 ความจำเป็นในการแก้ปัญหาขนาดใหญ่ด้วยคอมพิวเตอร์ทำให้นักคณิตศาสตร์ตระหนักว่า เส้นแบ่งสำคัญของ optimization ไม่ใช่ระหว่างความเชิงเส้นกับไม่เชิงเส้น แต่คือ convexity ดังที่ R. Tyrrell Rockafellar สรุปไว้ในปี 1970 ว่าปัญหาที่มี convexity รับรองว่าทุกคำตอบที่เจอในระดับท้องถิ่นคือคำตอบที่ดีที่สุดของทั้งระบบเสมอ

Worked Example — โจทย์และสิ่งที่ให้มา

โจทย์ให้อะไรมาบ้าง: ผลขาดทุนย้อนหลังแบบ quartic กับความเสี่ยงพอร์ตแบบ quadratic ต่างเรียบและหา derivative ได้ แต่ความเรียบไม่ได้แปลว่ามีคำตอบเดียว convexity ต่างหากที่แยกชามเดียวออกจากหลายหุบ

ขั้นที่ 1 — นิยามจุดต่ำสุดสองระดับ

คำว่า 'ต่ำสุด' มีสองความหมายที่ต่างกันมาก และการสับสนสองอันนี้ คือที่มาของกลยุทธ์ที่ดูดีในคอมพิวเตอร์แต่พังจริง

\[ \begin{aligned}x^\star\text{ is global}&\iff f(x^\star)\le f(y)\quad\forall y\in\mathcal F,\\ x^\star\text{ is local}&\iff \exists r>0:\ f(x^\star)\le f(y)\quad\forall y\in\mathcal F,\ \lVert y-x^\star\rVert \lt r.\end{aligned} \]

$\mathcal F$ คือ feasible set; global minimum เปรียบเทียบกับทุก $y$ ส่วน local minimum เปรียบเทียบเฉพาะ $y$ ที่ห่างจาก $x^\star$ น้อยกว่า $r$

ขั้นที่ 2 — เงื่อนไขรูปชาม

มีเงื่อนไขหนึ่งที่ถ้าผ่าน จะไม่มีปัญหานี้เลย เพราะจุดต่ำสุดใกล้ตัวจะเป็นจุดต่ำสุดของทั้งโจทย์เสมอ

\[ f\!\left(\alpha x+(1-\alpha)y\right)\le \alpha f(x)+(1-\alpha)f(y),\qquad 0\le\alpha\le1 \]

$\alpha$ เลือกตำแหน่งบนเส้นระหว่าง $x$ กับ $y$; ถ้าค่า function ไม่สูงกว่า chord ทุกคู่ function เป็น convex

ขั้นที่ 3 — พิสูจน์ว่า convexity รับรองว่า local minimum ทุกจุดคือ global minimum

ข้อพิสูจน์แบบ contradiction นี้ยืนยันว่าโครงสร้างชามนูนไม่มีทางซ่อนหลุมที่สองเอาไว้เบื้องหลังเนินใด ๆ ได้เลย

\[ \begin{aligned} f\big(z(\alpha)\big) &= f\big((1-\alpha)x^\star + \alpha y\big) \\ &\le (1-\alpha)f(x^\star) + \alpha f(y) \\ &= f(x^\star) + \alpha \big(f(y) - f(x^\star)\big) \\ & \lt f(x^\star)\qquad (\because f(y) \lt f(x^\star)\text{ and }\alpha > 0) \\ \|z(\alpha) - x^\star\| &= \alpha \|y - x^\star\| \lt r\quad\text{for small }\alpha > 0 \end{aligned} \]

สมมติให้ $x^\star$ เป็นเพียง local minimum แต่มีจุด $y$ อื่นที่ให้ค่าต่ำกว่า การลากส่วนของเส้นตรงเชื่อมระหว่างจุดทั้งสองอาศัยนิยามของ convexity เพื่อคำนวณค่า function ตลอดเส้นทาง

เนื่องจาก $f(y) - f(x^\star)$ ติดลบ ค่าบนเส้นตรงจึงลดต่ำลงทันทีที่เริ่มก้าวออกจาก $x^\star$ เมื่อเลือก $\alpha$ ให้เล็กพอ จุดใหม่จะอยู่ใกล้ $x^\star$ น้อยกว่ารัศมี $r$ แต่กลับให้ค่า function ต่ำกว่าเดิม ซึ่งขัดแย้งกับสมมติฐานว่า $x^\star$ ต่ำสุดรอบตัว จึงพิสูจน์ได้ว่าจุดต่ำสุดเฉพาะที่ต้องเป็น global minimum เสมอ

ขั้นที่ 4 — หุบสองใบของกลยุทธ์

ยกตัวอย่างที่มีสองหุบจริง เพื่อจะได้เห็นว่าปัญหานี้เกิดขึ้นได้อย่างไร รูปที่แยกตัวประกอบแล้วสำคัญกว่ารูปกระจาย เพราะมันบอกตำแหน่งของจุดที่พื้นราบทันที โดยไม่ต้องแก้สมการกำลังสามอีกรอบ

\[ \begin{aligned}f(w)&=3w^{4}-4w^{3}-36w^{2}\\ f'(w)&=12w^{3}-12w^{2}-72w\\ &=12w\big(w^{2}-w-6\big)\\ &=12w(w-3)(w+2)\\ f'(w)=0\;&\Longrightarrow\;w=-2,\;0,\;3\end{aligned} \]

$f$ วัดผลขาดทุนของ backtest หน่วยพัน USD ส่วน $w$ คือน้ำหนักที่ให้กับสัญญาณ หา derivative ทีละพจน์ เลขชี้กำลังลงมาคูณข้างหน้าแล้วลดลงหนึ่ง จากนั้นดึงตัวร่วม $12w$ ออกมา เพราะทุกพจน์มี $w$ อยู่อย่างน้อยหนึ่งตัว

บรรทัดสี่แยกตัวประกอบวงเล็บ หาสองจำนวนที่คูณกันได้ −6 และบวกกันได้ −1 ได้ −3 กับ +2 รูปที่แยกตัวประกอบแล้วมีค่ากว่ารูปกระจาย เพราะผลคูณเป็นศูนย์เมื่อตัวใดตัวหนึ่งเป็นศูนย์ ตำแหน่งที่พื้นราบจึงอ่านออกทันทีว่ามีสามจุด ไม่ต้องแก้สมการกำลังสามอีกรอบ

ขั้นที่ 5 — แก้ $f'(w)=0$ หาจุดที่พื้นราบ

จุดต่ำสุดต้องมีความชันเป็นศูนย์ก่อน จึงเริ่มจากหา derivative แล้วแยกตัวประกอบ จะได้เห็นรากทั้งสามตัวตรง ๆ ไม่ต้องเดา

\[ \begin{aligned}f'(w)&=12w^3-12w^2-72w\\ &=12w\,(w^2-w-6)\\ &=12w\,(w+2)(w-3)=0\quad\Longrightarrow\quad w=-2,\;0,\;3\end{aligned} \]

ดึง $12w$ ออกมาก่อน เหลือ $w^2-w-6$ ซึ่งแยกได้เป็น $(w+2)(w-3)$ เพราะต้องการสองจำนวนที่คูณกันได้ $-6$ และบวกกันได้ $-1$ คือ $+2$ กับ $-3$ ผลคูณเป็นศูนย์เมื่อวงเล็บใดวงเล็บหนึ่งเป็นศูนย์ จึงได้สามจุด

ขั้นที่ 6 — วัดความลึกของแต่ละจุด

แทนสามค่ากลับเข้าสมการเดิม เพื่อดูว่าหุบไหนลึกกว่ากัน

\[ \begin{aligned}f(-2)&=3(16)-4(-8)-36(4)=48+32-144=-64\\ f(0)&=0-0-0=0\\ f(3)&=3(81)-4(27)-36(9)=243-108-324=-189\end{aligned} \]

หน่วยเป็น USD thousand ทั้งสามค่า จุดที่ $w=3$ ลึกกว่าจุดที่ $w=-2$ อยู่ 125 เพราะ $-189$ ต่ำกว่า $-64$ อยู่เท่านั้น

ขั้นที่ 7 — จัดประเภทและเทียบความลึก

มีสามจุดที่พื้นราบแล้ว ขั้นนี้ดูความโค้งเพื่อแยกว่าจุดไหนเป็นก้นหุบ จุดไหนเป็นยอดเนิน ความโค้งเป็นบวกคือหุบ ความโค้งเป็นลบคือยอด

\[ \begin{aligned}f^{\prime\prime}(w)&=36w^2-24w-72\\ f^{\prime\prime}(-2)&=120,\quad f(-2)=-64\\ f^{\prime\prime}(0)&=-72,\quad f(0)=0\\ f^{\prime\prime}(3)&=180,\quad f(3)=-189\end{aligned} \]

second derivative เป็นบวกที่ $-2$ และ $3$ จึงเป็น local minima แต่ $f(3)$ ต่ำกว่า $f(-2)$ อยู่ USD 125 thousand

ค่า $f(w)$ ในสามกรณีนี้มีหน่วยเป็นพัน USD ใช้เครื่องหมายของsecond derivative ซึ่งบอกทิศทางการโค้งของกราฟแยกจุดต่ำสุดและจุดสูงสุด แล้วเทียบค่า $f(w)$ เพื่อเลือกคำตอบ

ขั้นที่ 8 — พอร์ต SPY–AGG เป็น quadratic bowl

กลับมาที่ปัญหาพอร์ต ซึ่งโชคดีที่มีรูปชามใบเดียว จึงไม่มีปัญหาที่ว่ามาเลย

\[ \begin{aligned} \mathrm{Var}(r_p) &= \mathbb{E}\big[\big(p_1(r_1-\mu_1) + p_2(r_2-\mu_2)\big)^2\big] \\ &= p_1^2\,\mathbb{E}[(r_1-\mu_1)^2] + 2p_1p_2\,\mathbb{E}[(r_1-\mu_1)(r_2-\mu_2)] + p_2^2\,\mathbb{E}[(r_2-\mu_2)^2] \\ &= p_1^2\sigma_1^2 + 2p_1p_2\sigma_{12} + p_2^2\sigma_2^2 \\ &= \begin{bmatrix}p_1&p_2\end{bmatrix}\begin{bmatrix}\sigma_1^2&\sigma_{12}\\ \sigma_{12}&\sigma_2^2\end{bmatrix}\begin{bmatrix}p_1\\ p_2\end{bmatrix} \\ &= \begin{bmatrix}p_1&p_2\end{bmatrix}\begin{bmatrix}0.040&0.006\\ 0.006&0.010\end{bmatrix}\begin{bmatrix}p_1\\ p_2\end{bmatrix} = 0.040p_1^2 + 0.012p_1p_2 + 0.010p_2^2 \end{aligned} \]

กระจายกำลังสองของผลรวมผลตอบแทนพอร์ต ได้สามพจน์ตามนิยาม variance และ covariance

เมื่อแทนค่า annual volatilities 20% และ 10% พร้อม correlation 0.30 เข้าไป จะได้ covariance 0.006 จัดรูปเป็น quadratic form $p^{\mathsf T}Vp$ แสดงโครงสร้างชามกำลังสองชัดเจน

ขั้นที่ 9 — ตรวจ convexity ด้วย Hessian

พิสูจน์คำกล่าวอ้างนั้นด้วยเกณฑ์ที่ตรวจได้ ไม่ใช่แค่ดูรูปแล้วเชื่อ

\[ \begin{aligned} \nabla_p (p^{\mathsf T}Vp) &= \begin{bmatrix}\frac{\partial}{\partial p_1}(0.040p_1^2+0.012p_1p_2+0.010p_2^2)\\ \frac{\partial}{\partial p_2}(0.040p_1^2+0.012p_1p_2+0.010p_2^2)\end{bmatrix} = \begin{bmatrix}0.080p_1+0.012p_2\\ 0.012p_1+0.020p_2\end{bmatrix} \\ H &= \begin{bmatrix}\frac{\partial^2}{\partial p_1^2}&\frac{\partial^2}{\partial p_1\partial p_2}\\ \frac{\partial^2}{\partial p_2\partial p_1}&\frac{\partial^2}{\partial p_2^2}\end{bmatrix}(p^{\mathsf T}Vp) = \begin{bmatrix}0.080&0.012\\ 0.012&0.020\end{bmatrix} = 2V \\ D_1 &= 0.080 > 0 \\ D_2 &= 0.080(0.020) - 0.012^2 = 0.001600 - 0.000144 = 0.001456 > 0 \end{aligned} \]

หา first partial derivatives เพื่อสร้าง gradient แล้วหา second partial derivatives ซ้ำอีกครั้ง ได้ matrix $H = 2V$ คงที่ทุกจุดใน space

leading principal minors ทั้งสองลำดับ $D_1$ และ $D_2$ มีค่าเป็นบวกอย่างเคร่งครัด ตามเกณฑ์ของ Sylvester จึงรับรองว่า $H$ เป็น positive definite ทำให้พื้นผิว variance เป็น strictly convex

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

การแยกจุดต่ำสุดใกล้ตัวออกจากจุดต่ำสุดของทั้งโจทย์ ป้องกันกลยุทธ์ที่ดูดีแต่ผิด

ใช้ตรวจว่าปัญหาที่กำลังแก้นั้นปลอดภัยหรือไม่ ถ้าเป็นรูปชามใบเดียว คำตอบที่ได้คือคำตอบที่ดีที่สุดแน่นอน

ใช้อธิบายว่าทำไมการปรับ parameter ของกลยุทธ์แล้วได้ผลต่างกันทุกครั้งที่รัน เพราะจุดเริ่มต้นต่างกันนำไปสู่คนละหุบ

ใช้ตัดสินว่าต้องลองหลายจุดเริ่มต้นหรือไม่ ซึ่งเป็นข้อควรปฏิบัติมาตรฐานในการปรับแบบจำลอง

คำตอบ — มี local minima 2 จุด แต่ global อยู่ที่ w=3

คำตอบ: quartic objective มี local minima ที่ w=-2 และ w=3 แต่ค่า -189 USD thousand ที่ w=3 ต่ำกว่า -64 ที่ w=-2 จึงเป็น global minimum ของตัวอย่าง ส่วน SPY–AGG variance มี positive-definite Hessian จึงมีชามเดียว

ตรวจเองใน 10 วินาที: ใส่ w=-2 และ w=3 ใน objective ต้องได้ -64 กับ -189; สำหรับ quadratic case เช็ก leading minor 0.080 > 0 และ determinant 0.001456 > 0

ใช้ตัดสินใจ: quadratic portfolio problem ใช้ local solver แล้วเชื่อ global optimum ได้ภายใต้ covariance นี้ แต่ quartic backtest ต้องเริ่มหลายจุดและเทียบ objective ทุกคำตอบ

กับดัก: เห็นข้อความ converged แล้วแปลว่าชนะทั้งโลก

convergence บอกเพียงว่า stopping rule ผ่าน ไม่ได้พิสูจน์ global optimality บนพื้นผิว non-convex ควรเปรียบเทียบหลายจุดเริ่ม ตรวจค่ารอบคำตอบ และแยก optimisation error ออกจาก estimation error

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
การตรวจตรวจได้ว่าเป็นรูปชามใบเดียวไหมตรวจยากมากในปัญหาที่มีตัวแปรเยอะในทางปฏิบัติมักตรวจไม่ได้ ต้องใช้วิธีลองหลายจุดแทน
จำนวนหุบหุบมีไม่กี่ใบปัญหาที่ปรับหลาย parameter มีหุบนับไม่ถ้วนการหาจุดที่ดีที่สุดจริงเป็นไปไม่ได้ ต้องยอมรับคำตอบที่ดีพอ
ความหมายของคำตอบจุดต่ำสุดคือคำตอบที่ดีที่สุดจุดต่ำสุดบนข้อมูลอดีตคือการจำอดีตคำตอบที่ลึกที่สุดในการทดสอบมักแย่ที่สุดในการใช้จริง

แถวล่างสำคัญที่สุดสำหรับงานสร้างกลยุทธ์ และเป็นหัวข้อของ 15.5 ทั้งหัวข้อ

สรุปที่ใช้ได้จริง

  • global minimum ชนะทุกจุดใน feasible set ส่วน local minimum ชนะเพียงละแวกหนึ่ง
  • convex objective ทำให้ local minimum ทุกจุดเป็น global minimum
  • Hessian ของ portfolio variance เท่ากับ $2V$ และ positive definiteness รับรองชามเดียว
  • ข้อความ converged ต้องอ่านคู่กับ geometry สมมติฐานข้อมูล และหลายจุดเริ่ม
