8.1 Global vs Local Minima

แยกจุดต่ำสุดใกล้ตัวออกจากจุดต่ำสุดของทั้งโจทย์

เดินป่าเจอแอ่งต่ำหลังเนินแรก คุณควรหยุดเพราะลงมาถึงจุดต่ำรอบตัวแล้ว หรือเดินสำรวจต่อเพราะอาจมีหุบที่ต่ำกว่าหลังเนินถัดไป?

เฉลย: ควรสำรวจต่อ; แอ่ง A ต่ำกว่าพื้นรอบข้าง 3 เมตร แต่แอ่ง B ต่ำ 8 เมตร; A ชนะเฉพาะเพื่อนบ้าน ส่วน B ชนะเมื่อเทียบทั้งแผนที่

local minimum คือจุดต่ำเมื่อมองใกล้ ๆ ส่วน global minimum ต่ำสุดในทุกจุดที่อนุญาต ใช้แยกคำตอบที่ algorithm พบจากคำตอบที่โจทย์ต้องการจริง

หลุมแรกอาจต่ำจริงแต่ไม่ใช่ต่ำสุด; งานจริงทำ multi-start และตรวจ bound ก่อนเชื่อผล optimization

คำตอบและวิธีเช็ก

คำตอบ — มี local minima 2 จุด แต่ global อยู่ที่ w=3

คำตอบquartic objective มี local minima ที่ w=-2 และ w=3 แต่ค่า -189 USD thousand ที่ w=3 ต่ำกว่า -64 ที่ w=-2 จึงเป็น global minimum ของตัวอย่าง ส่วน SPY–AGG variance มี positive-definite Hessian จึงมีชามเดียว

ตรวจเองใน 10 วินาทีใส่ w=-2 และ w=3 ใน objective ต้องได้ -64 กับ -189; สำหรับ quadratic case เช็ก leading minor 0.080 > 0 และ determinant 0.001456 > 0

ใช้ตัดสินใจ: quadratic portfolio problem ใช้ local solver แล้วเชื่อ global optimum ได้ภายใต้ covariance นี้ แต่ quartic backtest ต้องเริ่มหลายจุดและเทียบ objective ทุกคำตอบ

กับดัก: เห็นข้อความ converged แล้วแปลว่าชนะทั้งโลก

convergence บอกเพียงว่า stopping rule ผ่าน ไม่ได้พิสูจน์ global optimality บนพื้นผิว non-convex ควรเปรียบเทียบหลายจุดเริ่ม ตรวจค่ารอบคำตอบ และแยก optimisation error ออกจาก estimation error

สรุปที่ใช้ได้จริง

  • global minimum ชนะทุกจุดใน feasible set ส่วน local minimum ชนะเพียงละแวกหนึ่ง
  • convex objective ทำให้ local minimum ทุกจุดเป็น global minimum
  • Hessian ของ portfolio variance เท่ากับ และ positive definiteness รับรองชามเดียว
  • ข้อความ converged ต้องอ่านคู่กับ geometry สมมติฐานข้อมูล และหลายจุดเริ่ม
