8.6 Marginals of the Multivariate Normal

เลือกสินทรัพย์ที่สนใจ โดยไม่แอบเปลี่ยน “ไม่ได้ถือ” ให้กลายเป็น “รู้ผลตอบแทนแล้ว”

แบบจำลองรายวันของ SPX และ QQQ ให้ SD เท่ากับ 2% และ 3% และ correlation 0.40 คุณถือเฉพาะ SPX จึงตั้งน้ำหนัก QQQ เป็นศูนย์ โปรแกรมอีกชุดกลับตั้ง ผลตอบแทน QQQ เป็นศูนย์แล้วคำนวณความเสี่ยงของ SPX สองวิธีนี้ควรได้ SD เท่ากันไหม?

ลองตอบก่อนเปิดเฉลย

ไม่เท่า การไม่ถือ QQQ ยังปล่อยให้ QQQ ขึ้นลงตาม distribution: SPX marginal มี SD 2% แต่การให้ข้อมูลว่า QQQ มี return ใกล้ศูนย์เป็นโจทย์ conditional ใน Gaussian model นี้จะได้ SD ประมาณ 1.833% ความต่างไม่ได้เกิดจากการกระจายเงินลงทุน แต่เกิดจากคำถามที่ป้อนเข้าโมเดล

Marginal เก็บทุกความเป็นไปได้ของตัวแปรที่ไม่ได้ถาม

ถ้าต้องการ distribution ของ SPX เพียงตัวเดียว เราต้องนับทุก outcome ของ QQQ ที่เกิดร่วมกับค่า SPX นั้น ไม่ว่าจะบวก ลบ หรือศูนย์ สำหรับ joint density จึงใช้การ integrate ไม่ใช่เลือกแถวของกราฟ density ที่ QQQ เท่ากับศูนย์

การเลือกบางชื่อจาก mean vector และ covariance matrix ทำได้ในทุก joint distribution ที่มี second moments finite ส่วนคำรับรองว่า distribution ที่เหลือยังเป็น Normal ต้องอาศัย joint Gaussianity เพิ่มเติม ไม่ใช่เห็นแต่ละ marginal ดูคล้ายระฆัง

ตัวเลขรายปีกับรายวันเป็นคนละโมเดล ห้ามนำ mean ของชุดหนึ่งไปใช้กับ covariance อีกชุดหนึ่ง Covariance ใช้หน่วย decimal-return² สำหรับช่วงเวลาที่ระบุ ไม่ใช่ variance ของอัตราผลตอบแทนต่อวัน

ขั้นที่ 1 — เขียนว่า “รวมออก” หมายถึงอะไร

แบ่ง vector เป็น $X_A$ กับ $X_B$ หากมี joint density นิยามของ marginal คือ integral ครอบคลุมทุกค่าของ $X_B$ แต่ marginal distribution ยังมีอยู่ได้แม้ full model ไม่มี density เช่น Gaussian ที่ singular

\[ \begin{aligned} f_A(x_A)&:=\int_{\mathbb R^{|B|}}f_{A,B}(x_A,x_B)\,dx_B,\\ M_{X_A}(t)&:=\mathbb E[e^{t^{\mathsf T}X_A}]\\ &=\mathbb E[e^{t^{\mathsf T}X_A+0^{\mathsf T}X_B}]\\ &=M_X(t,0). \end{aligned} \]

ศูนย์ใน MGF เป็นค่าสัมประสิทธิ์ของ argument:เราไม่กำลังถาม moment ของ $X_B$ แต่ไม่ได้บอกว่า $X_B=0$ ตัวแปรที่ไม่ถามยังสุ่มและมีความสัมพันธ์กับตัวที่ถามได้ตามเดิม

เขียนศูนย์ตรงไหนกำลังทำอะไร
น้ำหนัก $w_B=0$ไม่มี P&L จากการถือ B โดยตรง; ไม่ได้หยุดให้ return B สุ่ม
MGF argument $s_B=0$เลือกดู distribution/moments ของ A โดยไม่ถาม B
ข้อมูล $X_B\approx0$เปลี่ยนเป็น conditional question ซึ่งอาจเปลี่ยน mean และ covariance ของ A

ขั้นที่ 2 — เลือกแถวและคอลัมน์ด้วย index ชุดเดียวกัน

กำหนด annual Gaussian return vector ของหุ้นสหรัฐ พันธบัตรสหรัฐ และทองคำตามลำดับนี้ ต้องการเฉพาะหุ้นกับทองจึงเลือก components 1 และ 3 โดยยังรักษา covariance ระหว่างสองตัวไว้

\[ \begin{aligned} \mu&=\begin{bmatrix}0.09\\0.03\\0.05\end{bmatrix},\\ \Sigma&=10^{-4}\begin{bmatrix} 324&-21.6&13.5\\ -21.6&36&22.5\\ 13.5&22.5&225 \end{bmatrix},\\ P&=\begin{bmatrix}1&0&0\\0&0&1\end{bmatrix},\\ Y=PX&=\begin{bmatrix}X_1\\X_3\end{bmatrix},\\ \mu_Y&=P\mu=\begin{bmatrix}0.09\\0.05\end{bmatrix},\\ \Sigma_Y&=P\Sigma P^{\mathsf T}\\ &=\begin{bmatrix}0.0324&0.00135\\0.00135&0.0225\end{bmatrix}. \end{aligned} \]

การคูณ P ด้านซ้ายเลือกแถว และคูณ $P^{\mathsf T}$ ด้านขวาเลือกคอลัมน์ตามลำดับเดียวกัน ไม่ใช่เลือกสอง diagonal cells แล้วตั้ง covariance ระหว่างหุ้นกับทองให้ศูนย์

สูตร mean/covariance นี้มาจาก linear transformation ใน 8.2 จึงไม่ต้องใช้ Normal assumption แต่ P แบบ selection ต่างจาก matrix ที่ผสมหลาย assets ในแต่ละแถว: กรณีหลังเป็น distribution ของ linear combinations ซึ่งจะเรียนต่อใน 8.8

P ขนาด $2\times3$ เรียกได้ว่า coordinate projection แต่ไม่ใช่ square orthogonal projector ที่ต้องตรวจ $P^2=P$ หากต้องการลำดับ “ทอง, หุ้น” ให้สลับแถวของ P และเรียง weights ของพอร์ตให้ตรงกับผลที่เลือกออกมา

ขั้นที่ 3 — MGF พิสูจน์ว่า selected law ยังเป็น Gaussian

สมมติ $X$ เป็น joint Gaussian ตาม 8.4–8.5 เมื่อถาม MGF ของ $Y=PX$ ให้ส่ง argument $P^{\mathsf T}t$ กลับไปยัง full vector แล้วจัดรูป

\[ \begin{aligned} M_Y(t)&=\mathbb E[e^{t^{\mathsf T}PX}]\\ &=M_X(P^{\mathsf T}t)\\ &=\exp\{t^{\mathsf T}P\mu\\ &\qquad+\tfrac12t^{\mathsf T}P\Sigma P^{\mathsf T}t\},\\ Y&\sim N(P\mu,P\Sigma P^{\mathsf T}). \end{aligned} \]

MGF ตรงกับ Gaussian ที่มี mean/covariance ที่เลือกไว้ และ finite รอบศูนย์ จึงระบุ distribution ได้ ไม่จำเป็นต้องสร้าง joint density หรือ integrate ทีละตัวแปรใหม่ทุกครั้ง

ทำไม cross-block หายได้โดยไม่ต้องเป็นศูนย์
\[ \begin{aligned} s^{\mathsf T}\Sigma s &=s_A^{\mathsf T}\Sigma_{AA}s_A\\ &\quad+2s_A^{\mathsf T}\Sigma_{AB}s_B\\ &\quad+s_B^{\mathsf T}\Sigma_{BB}s_B,\\ s_B&=0,\\ M_{X_A}(s_A)&=\exp\{s_A^{\mathsf T}\mu_A\\ &\qquad+\tfrac12s_A^{\mathsf T}\Sigma_{AA}s_A\}. \end{aligned} \]

พจน์ cross-block หายเพราะ argument ของ B เป็นศูนย์ ไม่ใช่เพราะเราได้พิสูจน์ว่า $\Sigma_{AB}=0$ สินทรัพย์ที่ตัดออกจึงยังมีความสัมพันธ์กับสินทรัพย์ที่เหลือ และอาจให้ข้อมูลที่เปลี่ยน conditional prediction ได้

ขั้นที่ 4 — ดูการ integrate จริงในสองมิติ

สำหรับ bivariate Normal ที่ $\sigma_X,\sigma_Y\gt0$ และ $|\rho|\lt1$ กำหนด marginal scores $u=(x-\mu_X)/\sigma_X$ กับ $v=(y-\mu_Y)/\sigma_Y$ ทั้งสอง scores ยัง correlated กัน เราจัดกำลังสองเพื่อแยกพจน์ที่ขึ้นกับ y

\[ \begin{aligned} q&:=\frac{u^2-2\rho uv+v^2}{1-\rho^2},\\ q&=u^2+\frac{(v-\rho u)^2}{1-\rho^2},\\ f_{X,Y}(x,y)&=\frac{e^{-u^2/2}}{\sqrt{2\pi}\sigma_X}\\ &\quad\times\frac{e^{-(v-\rho u)^2/[2(1-\rho^2)]}}{\sqrt{2\pi}\sigma_Y\sqrt{1-\rho^2}},\\ z&=\frac{v-\rho u}{\sqrt{1-\rho^2}},\\ dy&=\sigma_Y\sqrt{1-\rho^2}\,dz,\\ J&:=\int_{-\infty}^{\infty}\frac{e^{-z^2/2}}{\sqrt{2\pi}}\,dz=1,\\ f_X(x)&=\frac{e^{-u^2/2}}{\sqrt{2\pi}\sigma_X}J\\ &=\frac{e^{-(x-\mu_X)^2/(2\sigma_X^2)}}{\sqrt{2\pi}\sigma_X}. \end{aligned} \]

เมื่อ fix x, ส่วนที่สองเป็น Normal density ใน y ซึ่งมีพื้นที่รวมหนึ่ง แม้ศูนย์กลางจะขึ้นกับ x การ integrate จึงเหลือ Normal ของ X โดยเก็บ mean $\mu_X$ และ variance $\sigma_X^2$ ไม่ได้อาศัย independence

ที่มาของ integral เท่ากับหนึ่ง

ให้ $I=\int_{-\infty}^{\infty}e^{-z^2/2}\,dz\gt0$ คูณ integral สองชุด แล้วเปลี่ยนเป็น polar coordinates ซึ่งมี area factor r

\[ \begin{aligned} I^2&=\int_{\mathbb R^2}e^{-(x^2+y^2)/2}\,dx\,dy\\ &=\int_0^{2\pi}\int_0^{\infty}e^{-r^2/2}r\,dr\,d\theta\\ &=2\pi[-e^{-r^2/2}]_0^{\infty}=2\pi,\\ I&=\sqrt{2\pi},\\ J&=I/\sqrt{2\pi}=1. \end{aligned} \]

ที่ $|\rho|=1$ สูตร density สองมิตินี้ใช้ไม่ได้ แต่การเลือก component ของ Gaussian ที่ singular ยังทำได้ด้วย affine construction หรือ MGF ไม่ต้องฝืนหารด้วยศูนย์

ขั้นที่ 5 — ตรวจพอร์ตหุ้น/ทองจากทั้ง full model และ subset

โจทย์ให้อะไรมาบ้าง: ใช้ annual model ของขั้นที่ 2 ลงเงินครึ่งหนึ่งในหุ้นและครึ่งหนึ่งในทอง ไม่ถือพันธบัตร คง holdings ตลอดช่วงและละต้นทุนในตัวอย่าง เรียก weight vector ใน subset ว่า w

\[ \begin{aligned} w&=(0.5,0.5)^{\mathsf T},\\ \mathbb E[R_p]&=0.5(0.09)+0.5(0.05)=0.07,\\ \operatorname{Var}(R_p)&=0.25(0.0324)\\ &\quad+0.25(0.0225)\\ &\quad+2(0.25)(0.00135)\\ &=0.0081+0.005625\\ &\quad+0.000675\\ &=0.0144,\\ \operatorname{SD}(R_p)&=\sqrt{0.0144}=0.12,\\ \widetilde w=P^{\mathsf T}w&=(0.5,0,0.5)^{\mathsf T},\\ w^{\mathsf T}\Sigma_Yw&=\widetilde w^{\mathsf T}\Sigma\widetilde w=0.0144. \end{aligned} \]

คำตอบ: expected annual return 7%, SD 12% จากทั้งสองเส้นทาง หาก NAV เริ่มต้น \$1 ล้าน จะเป็น mean P&L \$70,000 กับ SD \$120,000 ไม่ใช่กำไรที่รับประกัน

โค้ดท้ายหน้ารายงาน portfolioLoss ภายใต้ Gaussian ด้วย: $\Phi(-0.07/0.12)\approx27.98\%$ นี่ใช้คุณสมบัติว่า linear combination ของ joint Gaussian ยังเป็น Normal ซึ่งจะขยายความใน 8.8 ไม่ได้อาศัยเพียงรูป marginal ของสินทรัพย์แต่ละตัว

ตรวจเองใน 10 วินาที: variance ต้องมี cross-term 0.000675 หุ้นกับทองไม่เป็นอิสระเพียงเพราะนำพันธบัตรออก หากเลือกหุ้นกับพันธบัตรผิดคู่ จะได้ variance 0.00792 ซึ่งเป็นพอร์ตคนละชุด ไม่ใช่ผลที่เทียบกันได้

เมื่อถามเฉพาะทอง $R_G\sim N(0.05,0.15^2)$ ความน่าจะเป็นขาดทุนจากโมเดลจึงคำนวณได้โดยไม่ต้องตั้ง return หุ้นหรือพันธบัตรให้ค่าใด

\[ \begin{aligned} P(R_G\lt0)&=\Phi\left(\frac{0-0.05}{0.15}\right)\\ &=\Phi(-1/3)\approx36.9441\%. \end{aligned} \]

ขั้นที่ 6 — ตัด covariance ไม่ใช่ตัด inverse covariance

กลับมาที่ daily SPX/QQQ หากต้องการ SPX marginal ให้เลือก $\Sigma_{11}=0.0004$ โดยตรง แต่การ invert full covariance ก่อนแล้วหยิบ diagonal ของ inverse มา invert อีกครั้งให้คนละคำตอบ

\[ \begin{aligned} \Sigma&=\begin{bmatrix}0.0004&0.00024\\0.00024&0.0009\end{bmatrix},\\ D=\det\Sigma&=0.0004(0.0009)-0.00024^2\\ &=3.024\times10^{-7},\\ (\Sigma^{-1})_{11}&=0.0009/D\approx2976.190476,\\ \frac1{(\Sigma^{-1})_{11}}&=D/0.0009\\ &=0.0004-\frac{0.00024^2}{0.0009}\\ &=0.000336\ne0.0004. \end{aligned} \]

ค่า 0.000336 เป็น conditional variance ใน Gaussian model นี้ ไม่ใช่ marginal variance การตัด block ของ precision matrix จึงไม่ใช่ทางลัดสำหรับโจทย์ marginal

เหตุผลเดียวกันทำให้การตัด joint-density ที่ $Y=y$ ไม่ใช่ marginal ของ X:integrate slice นั้นตาม x จะได้ $f_Y(y)$ ซึ่งไม่จำเป็นต้องเป็นหนึ่ง ต้อง normalize ก่อนจึงกลายเป็น conditional density

\[ \begin{aligned} \int_{-\infty}^{\infty}f_{X,Y}(x,y)\,dx&=f_Y(y),\\ f_{X\mid Y=y}(x)&=f_{X,Y}(x,y)/f_Y(y),\\ f_Y(\mu_Y)&=\frac1{\sqrt{2\pi}(0.03)}\approx13.298076. \end{aligned} \]

สลับ u กับ v ในการจัดกำลังสองของขั้นที่ 4 แล้ว normalize slice จะอ่าน mean ของ X ได้เป็น $\mu_X+\rho\sigma_X(y-\mu_Y)/\sigma_Y$ ถ้า $y=0$ จะได้ mean $m_0$ ดังนี้ ส่วนสูตรทั่วไปจะพิสูจน์ต่อใน 8.7

\[ \begin{aligned} m_0&=0.0004+\frac{0.00024}{0.0009}(0-0.0003)\\ &=0.0004-0.00008=0.00032,\\ s_0&:=\operatorname{SD}(X\mid Y=0),\\ s_0&=\sqrt{0.000336}\approx1.8330\%. \end{aligned} \]

จึงต่างจาก marginal mean 0.04%, SD 2% โดยไม่ได้เปลี่ยน weights หรือซื้อสินทรัพย์เพิ่ม

สำหรับตัวแปรต่อเนื่อง การ condition ที่ค่าแน่นอนใช้นิยามผ่าน density หรือขีดจำกัดของช่วงแคบ ไม่ใช่หารด้วย $P(Y=0)$ ซึ่งเป็นศูนย์ และโจทย์ข้อมูลร่วมนี้ไม่ได้แปลว่าเรารู้ return ปลายงวดก่อนตัดสินใจลงทุน

ขั้นที่ 7 — Full model singular ไม่ได้ทำให้ทุก marginal ใช้ไม่ได้

ให้ Z กับ W เป็น independent standard Normal แล้วสร้าง $X=(Z,Z,W)^{\mathsf T}$ full covariance singular เพราะ component แรกกับที่สองซ้ำกัน แต่เลือกตัวแรกกับตัวที่สามจะได้ independent standard Normal สองตัวที่มี density ปกติ

\[ \begin{aligned} \Sigma_X&=\begin{bmatrix}1&1&0\\1&1&0\\0&0&1\end{bmatrix},\\ (X_1,X_3)^{\mathsf T}&\sim N\left(0,\begin{bmatrix}1&0\\0&1\end{bmatrix}\right),\\ (X_1,X_2)^{\mathsf T}&\sim N\left(0,\begin{bmatrix}1&1\\1&1\end{bmatrix}\right). \end{aligned} \]

คู่แรกมี density เต็มสองมิติ คู่หลังเป็น Gaussian ที่อยู่บนเส้นตรง ทั้งสองเป็น marginals ที่ถูกต้อง ส่วน component ที่ variance ศูนย์เป็นค่าคงที่ ต้องอ่านเป็น point mass ไม่ใช่เอา SD ศูนย์ไปหารใน Normal PDF

ถ้า full covariance เป็น PD ล่ะ
\[ \begin{aligned} a^{\mathsf T}\Sigma_Ya&=a^{\mathsf T}P\Sigma P^{\mathsf T}a\\ &=(P^{\mathsf T}a)^{\mathsf T}\Sigma(P^{\mathsf T}a)\\ &\gt0\quad(a\ne0). \end{aligned} \]

เมื่อ P เลือก distinct coordinates,$P^{\mathsf T}a\ne0$ สำหรับ $a\ne0$ จึงเก็บความเป็น PD ไว้ แต่ถ้าเลือก coordinate เดิมซ้ำจะสร้าง duplicate outputs ซึ่งอาจทำให้ covariance ใหม่ singular ได้ ไม่ใช่ความผิดของ Gaussian law

“ไม่ต้อง fit ใหม่” มีเงื่อนไข ไม่ใช่ใบอนุญาตให้ใช้โมเดลเก่าเสมอ

หากคำถามคือ unconditional distribution ของ subset ภายใต้ fixed full model เดิม ก็เลือก mean/covariance ได้ตรง ๆ ไม่ต้องประมาณ parameters อีกชุด แต่การเปลี่ยน horizon, ข้อมูล, regime หรือข้อมูลที่ condition อยู่เป็นคนละโจทย์

สิ่งที่ตรวจข้อผิดพลาดที่ป้องกัน
Names และ orderตัดแถวหนึ่งแต่คอลัมน์อีกชื่อ หรือเรียง weights ไม่ตรงกับ selected assets
Covariance ภายใน subsetเก็บแต่ diagonal แล้วสมมติ independence ทั้งที่ cross-covariance ยังอยู่
Distribution assumptionใช้ mean/covariance สร้าง Normal ทั้งที่ full law ไม่ใช่ joint Gaussian
Calibration และข้อมูลใหม่เข้าใจว่าการเลือก submatrix แก้ estimation error หรือความเสี่ยงจากโมเดลผิดได้

MGF ที่พิสูจน์ให้เลือกได้เป็นคุณสมบัติของ Gaussian family ไม่ใช่หลักฐานว่าหางตลาดจริงตรงกับ Gaussian โมเดล marginal รับข้อจำกัดของ full model มาด้วย ต้องทดสอบ tails และความเปลี่ยนแปลงตามข้อมูลนอกชุดที่ใช้ fit

ทดสอบว่ากำลังเลือกข้อมูล หรือเปลี่ยนคำถาม

1. Annual model เดิม ลงหุ้น 70%, ทอง 30% แต่ผลลัพธ์ที่เลือกจาก matrix เรียง “ทอง, หุ้น” ต้องส่ง weight vector อะไร? ถ้าไม่แก้ order จะรายงาน mean/variance ต่างอย่างไร?

เฉลย

ส่ง $(0.3,0.7)^{\mathsf T}$ ตามลำดับทอง, หุ้น จึงได้ mean 7.8%, variance 0.018468 เหมือน full vector $(0.7,0,0.3)^{\mathsf T}$ หากส่ง $(0.7,0.3)$ ตามลำดับใหม่จะเป็นพอร์ตทอง 70% ให้ mean 6.2%, variance 0.014508 การใช้ 50/50 ทดสอบอย่างเดียวจะซ่อน bug สลับลำดับนี้

2. เปลี่ยน correlation ของ daily SPX/QQQ จาก 0.40 เป็น 0.80 โดยคง means และ marginal SDs เดิม SPX marginal เปลี่ยนหรือไม่? แล้วจะใช้เส้น marginal สองเส้นกู้ค่า correlation กลับมาได้ไหม?

เฉลย

ไม่เปลี่ยน: SPX ยัง $N(0.0004,0.0004)$ ส่วน QQQ ยัง $N(0.0003,0.0009)$ เส้นสองเส้นจึงไม่บอก correlation ต้องมี joint information เพิ่ม Gaussian mean vector กับ full covariance กำหนด joint law ได้ แต่รายการ marginal means/variances อย่างเดียวไม่พอ

3. ใช้คู่ $X\sim N(0,1),Y=WX$ ของ 8.3 ซึ่ง W เป็นเครื่องหมายอิสระอย่างละครึ่ง เลือก X ตัวเดียวได้ Normal ถูกต้อง แล้วสรุปว่า full joint เป็น MVN ได้หรือไม่?

เฉลย

ไม่ได้ ทั้ง X และ Y มี Normal marginals แต่ joint อยู่บนสองเส้น $y=x,y=-x$ และ $P(X+Y=0)=1/2$ การมี Gaussian marginals ไม่ย้อนกลับไปพิสูจน์ joint Gaussianity

function finiteVector(v, n = null) {
  if (!Array.isArray(v) || !v.length || (n !== null && v.length !== n) ||
      ![...v].every(Number.isFinite)) throw new TypeError('Need a finite vector of matching size');
}
function finiteResult(x) {
  if (!Number.isFinite(x)) throw new RangeError('Arithmetic overflow');
  return x;
}
function checkLayout(mean, covariance, labels) {
  finiteVector(mean);
  const n = mean.length;
  if (!Array.isArray(labels) || labels.length !== n ||
      ![...labels].every(x => typeof x === 'string' && x.length > 0) || new Set(labels).size !== n) {
    throw new TypeError('Need unique nonempty labels matching the model');
  }
  if (!Array.isArray(covariance) || covariance.length !== n ||
      [...covariance].some(row => !Array.isArray(row) || row.length !== n || ![...row].every(Number.isFinite))) {
    throw new TypeError('Need a matching finite square covariance');
  }
  for (let i = 0; i < n; i++) for (let j = 0; j < n; j++) {
    if (covariance[i][j] !== covariance[j][i]) throw new RangeError('Covariance must be symmetric');
  }
}
function select(mean, covariance, labels, keep) {
  checkLayout(mean, covariance, labels);
  if (!Array.isArray(keep) || !keep.length || new Set(keep).size !== keep.length ||
      ![...keep].every(x => labels.includes(x))) throw new RangeError('Need a nonempty distinct subset of labels');
  const indices = keep.map(x => labels.indexOf(x));
  return {labels: [...keep], indices, mean: indices.map(i => mean[i]),
    covariance: indices.map(i => indices.map(j => covariance[i][j])),
    P: indices.map(i => labels.map((_, j) => Number(i === j)))};
}
function dot(a, b) {
  finiteVector(a); finiteVector(b, a.length);
  return finiteResult(a.reduce((s, x, i) => s + x * b[i], 0));
}
function portfolio(model, w) {
  checkLayout(model.mean, model.covariance, model.labels);
  finiteVector(w, model.mean.length);
  const variance = dot(w, model.covariance.map(row => dot(row, w)));
  if (variance < 0) throw new RangeError('Negative portfolio variance');
  return {mean: dot(w, model.mean), variance, sd: Math.sqrt(variance)};
}
function logMGF(model, s) {
  const p = portfolio(model, s);
  return finiteResult(p.mean + .5 * p.variance);
}
function integrate(f, lo, hi, n = 8000) {
  if (![lo, hi].every(Number.isFinite) || lo > hi ||
      !Number.isInteger(n) || n < 2 || n > 100000 || n % 2) throw new RangeError('Invalid integration bounds or grid');
  const h = finiteResult((hi - lo) / n);
  if (h === 0 && lo !== hi) throw new RangeError('Integration step underflow');
  let total = 0, correction = 0;
  for (let i = 0; i <= n; i++) {
    const weight = i === 0 || i === n ? 1 : i % 2 ? 4 : 2;
    const term = finiteResult(weight * f(lo + i * h)) - correction;
    const next = total + term;
    correction = (next - total) - term; total = next;
  }
  return finiteResult(total * h / 3);
}
function normalLogPDF(x, mean, variance) {
  if (![x, mean, variance].every(Number.isFinite) || variance <= 0) {
    throw new RangeError('Positive finite variance required for ordinary density');
  }
  const z = finiteResult((x - mean) / Math.sqrt(variance));
  return finiteResult(-.5 * z * z - .5 * Math.log(2 * Math.PI) - .5 * Math.log(variance));
}
const normalPDF = (x, mean, variance) => finiteResult(Math.exp(normalLogPDF(x, mean, variance)));
function Phi(x) {
  if (!Number.isFinite(x) || Math.abs(x) > 6) throw new RangeError('CDF demo limited to finite scores within 6');
  return .5 + Math.sign(x) * integrate(z => normalPDF(z, 0, 1), 0, Math.abs(x));
}
function jointPDF(x, y, mean, covariance) {
  checkLayout(mean, covariance, ['X', 'Y']);
  if (covariance[0][0] <= 0 || covariance[1][1] <= 0) throw new RangeError('Positive definite covariance required');
  const sx = Math.sqrt(covariance[0][0]), sy = Math.sqrt(covariance[1][1]);
  const rho = covariance[0][1] / sx / sy;
  if (!Number.isFinite(rho) || Math.abs(rho) >= 1) throw new RangeError('Positive definite covariance required');
  const u = finiteResult((x - mean[0]) / sx);
  const conditionalMean = finiteResult(mean[1] + rho * sy * u);
  const conditionalVariance = finiteResult(covariance[1][1] * ((1 - rho) * (1 + rho)));
  const logDensity = finiteResult(normalLogPDF(x, mean[0], covariance[0][0]) +
    normalLogPDF(y, conditionalMean, conditionalVariance));
  return finiteResult(Math.exp(logDensity));
}

สิ่งที่ควรตอบได้หลังอ่าน

  • Marginal รวมทุก outcome ของตัวที่ไม่ได้ถาม ไม่ใช่ fix return ของตัวนั้นเป็นศูนย์; MGF argument ศูนย์กับ observed return ศูนย์คนละเรื่อง
  • Mean/covariance ของ subset เป็น $P\mu,P\Sigma P^{\mathsf T}$ สำหรับทุก law ที่มี moments ส่วน Gaussianity ของ selected law ต้องมาจาก joint Gaussian model
  • เลือกแถวและคอลัมน์ด้วยชื่อชุดเดียวกันในลำดับเดียวกัน และคง off-diagonal covariance ของสมาชิกที่เลือกไว้
  • การ invert แล้วตัด precision block ไม่ใช่ marginalization; conditional distribution ใช้ข้อมูลเพิ่มและเป็นหัวข้อถัดไป
  • Singular Gaussian ยังมี marginals; บาง subset มี density เต็มมิติ บาง subset เป็นเส้นหรือ point mass

8.7 จะตอบโจทย์อีกแบบอย่างชัดเจน: เมื่อ รู้ บาง components แล้ว mean และ covariance ของส่วนที่เหลือเปลี่ยนอย่างไร และ slope นั้นเกี่ยวข้องกับ hedge ratio ภายใต้เงื่อนไขใด
