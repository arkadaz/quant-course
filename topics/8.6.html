8.6 Karush-Kuhn-Tucker (KKT) Conditions — Inequality Constraints

ดูว่าข้อจำกัดข้อใดกำลังบังคับคำตอบ

ร้านให้ตักไอศกรีมได้ไม่เกิน 3 ลูก: ที่ 2 ลูกกับ 3 ลูก กติกาเริ่มบังคับทางเลือกเมื่อใด?

เฉลย: ที่ 2 ลูกยังเหลือที่ว่าง 1 ลูก จึงไม่ต้องจ่ายราคาของข้อจำกัด; ที่ 3 ลูกพอดี ขอบเริ่มบังคับทางเลือก

Karush-Kuhn-Tucker (KKT) conditions รวม gradient, inequality constraint และ multiplier เพื่อบอกว่า constraint ใดกำลังทำงาน

constraint ที่ยังไม่แตะยังไม่บีบคำตอบ; KKT ระบุ limit ที่กำลังบีบ portfolio หรือ hedge

ที่มาที่ไป: วิทยานิพนธ์ที่ไม่มีใครอ่าน จนต้องมีคนคิดใหม่อีกสิบสองปี

William Karush เขียนเงื่อนไขชุดนี้ไว้ในวิทยานิพนธ์ปริญญาโทเมื่อปี 1939 แต่ไม่ได้ตีพิมพ์ งานของเขาจึงไม่มีใครรู้จัก

ในปี 1951 Harold Kuhn และ Albert Tucker คิดเงื่อนไขชุดเดียวกันขึ้นมาใหม่โดยไม่รู้ว่ามีคนทำไว้แล้ว และตีพิมพ์ ต่อมาเมื่อมีคนพบงานของ Karush ชื่อของเขาจึงถูกเพิ่มเข้าไปด้วย

ปัญหาที่เงื่อนไขชุดนี้แก้คือ ข้อจำกัดจริงส่วนใหญ่ไม่ใช่สมการแต่เป็นอสมการ เช่นห้ามถือติดลบ ซึ่งวิธีของ Lagrange แบบเดิมจัดการไม่ได้

ความยากอยู่ที่ข้อจำกัดแบบนี้อาจกำลังบีบคำตอบอยู่ หรืออาจยังเหลือที่ว่างและไม่มีผลอะไรเลย และเราไม่รู้ล่วงหน้าว่าข้อไหนเป็นแบบไหน

Worked Example — โจทย์และสิ่งที่ให้มา

โจทย์ให้อะไรมาบ้าง: ตัวอย่างใช้ covariance matrix ที่ positive definite และ annual horizon น้ำหนักรวมหนึ่ง ห้าม short และไม่มี transaction costs ข้อมูลถูกสร้างเพื่อสอนกลไก KKT ไม่ใช่ covariance estimate ปัจจุบันของตลาด

ขั้นที่ 1 — โจทย์และ Lagrangian

คราวนี้ข้อบังคับไม่ใช่สมการแต่เป็นอสมการ คือห้ามติดลบ ซึ่งเปลี่ยนวิธีแก้ไปพอสมควร

\[ \min_w\ w^{\mathsf T}Vw,\quad \mathbf1^{\mathsf T}w=1,\quad -w\le0,\qquad \mathcal L=w^{\mathsf T}Vw+\nu(\mathbf1^{\mathsf T}w-1)-u^{\mathsf T}w \]

objective คือ annual variance; budget เป็น equality ส่วน $-w\le0$ เขียน long-only ให้เข้ารูปมาตรฐาน และ $u$ จับคู่กับ residuals เหล่านี้

ขั้นที่ 2 — KKT checklist สี่ข้อ

เงื่อนไขที่คำตอบต้องผ่านมีสี่ข้อ ไม่ใช่ข้อเดียวเหมือนกรณีสมการ ขั้นนี้เขียนให้ครบก่อนลงมือ

\[ \begin{aligned}\text{stationarity: }&2Vw+\nu\mathbf1-u=0,\\ \text{primal feasibility: }&\mathbf1^{\mathsf T}w=1,\ w\ge0,\\ \text{dual feasibility: }&u\ge0,\\ \text{complementarity: }&u_iw_i=0\quad\forall i.\end{aligned} \]

ทุกบรรทัดต้องผ่านพร้อมกัน; complementarity บอกว่า weight บวกทำให้ multiplier เป็นศูนย์ ส่วน multiplier บวกบังคับให้ weight ชน zero

ขั้นที่ 3 — ที่มาทางเรขาคณิตของ KKT และเครื่องหมายของตัวคูณ

เจ็ดบรรทัดนี้อธิบายที่มาของเงื่อนไข complementary slackness และเครื่องหมายของตัวคูณ เมื่อข้อจำกัดไม่ทำงาน ตัวคูณต้องดับเป็นศูนย์ แต่เมื่อข้อจำกัดทำงาน ตัวคูณจะทำหน้าที่เป็นกำแพงผลักไม่ให้คำตอบล้นขอบ

\[ \begin{aligned} g_i(w)&=-w_i\le0\quad (i=1,\dots,n)\\ w_i^\star>0\;&\Longrightarrow\;g_i(w^\star) \lt 0\quad (\text{inactive})\;\Longrightarrow\;u_i=0\\ w_i^\star=0\;&\Longrightarrow\;g_i(w^\star)=0\quad (\text{active})\\ d\in\mathcal{F}\;&\Longrightarrow\;\nabla g_i(w^\star)^{\mathsf T}d\le0\quad\Longleftrightarrow\quad -d_i\le0\\ \nabla f(w^\star)^{\mathsf T}d&\ge0\quad (\forall d\in\mathcal{F})\;\Longrightarrow\;-\nabla f(w^\star)=u_i\nabla g_i(w^\star)\quad (u_i\ge0)\\ \nabla f(w^\star)&+u_i\nabla g_i(w^\star)=0\quad (u_i\ge0)\\ u_i g_i(w^\star)&=0\quad (\forall i) \end{aligned} \]

เงื่อนไข KKT ไม่ได้ถูกคิดขึ้นมาลอย ๆ แต่แยกพิจารณาตามตำแหน่งของจุดคำตอบว่าอยู่ที่ภายในหรือชนอยู่บนเส้นขอบของข้อจำกัดแต่ละข้อ

ถ้าจุดคำตอบอยู่ภายใน นั่นคือสินทรัพย์มีน้ำหนักบวก ข้อจำกัดจะไม่ส่งผลใด ๆ เลยต่อการตัดสินใจ แรงต้าน $u_i$ จึงต้องเป็นศูนย์โดยสมบูรณ์

แต่ถ้าจุดคำตอบชนขอบศูนย์ ทิศทางที่จะไม่หลุดออกนอกขอบเขตต้องไม่ทำให้น้ำหนักติดลบ เพื่อให้จุดนั้นเป็นจุดต่ำสุด vector ความชันของ objective จะต้องชี้ต้านทิศที่ออกนอกขอบเขต ทำให้ตัวคูณ $u_i$ ต้องไม่ติดลบ และผลคูณ $u_ig_i$ ต้องเป็นศูนย์เสมอ

ขั้นที่ 4 — Covariance และคำตอบที่ฝ่าฝืน mandate

แทนที่จะกลับ matrix 3×3 ทั้งก้อน ให้แก้ระบบสมการ $Vz=\mathbf1$ ก่อน แล้วค่อยส่วนด้วยผลรวมของ $z$ เพื่อบังคับให้น้ำหนักรวมเป็นหนึ่ง

\[ \begin{aligned}z&=V^{-1}\mathbf1=\begin{bmatrix}24.657534\\ 68.493151\\ -13.013699\end{bmatrix},\qquad \mathbf1^{\mathsf T}z=24.657534+68.493151-13.013699=80.136986\\[4pt] w_{\rm uncon}&=\frac{z}{80.136986}=\begin{bmatrix}0.307692\\ 0.854701\\ -0.162393\end{bmatrix}\end{aligned} \]

ตรวจ $z$ ได้เองด้วยการคูณกลับ: แถวแรกคือ $0.050(24.657534)+0.008(68.493151)+0.060(-13.013699)=1$ และอีกสองแถวก็ได้ 1 เหมือนกัน นั่นคือความหมายของ $Vz=\mathbf1$

คำตอบนี้รวมกันได้หนึ่งจริง แต่ QQQ ติดลบ 16.2393% จึงไม่ผ่านเงื่อนไข long-only ของกองทุน

ขั้นที่ 5 — หาคำตอบบน Active Set ด้วยการกระจายพจน์กำลังสองสองมิติ

แปดบรรทัดนี้สร้างสะพานเชื่อมระหว่างการตั้งสมมติฐาน active set กับคำตอบตัวเลขจริง โดยคลี่สูตรสองมิติออกมาบรรทัดต่อบรรทัด แสดงให้เห็นว่าน้ำหนัก 12.5% และ 87.5% มาจากจุดยอดของพาราโบลาอย่างแท้จริง

\[ \begin{aligned} w_3&=0\quad\Longrightarrow\quad w_2=1-w_1\\ \sigma^2(w_1)&=V_{11}w_1^2+2V_{12}w_1(1-w_1)+V_{22}(1-w_1)^2\\ \frac{d\sigma^2}{dw_1}&=2V_{11}w_1+2V_{12}(1-2w_1)-2V_{22}(1-w_1)=0\\ 0&=V_{11}w_1+V_{12}-2V_{12}w_1-V_{22}+V_{22}w_1\\ (V_{11}+V_{22}-2V_{12})w_1&=V_{22}-V_{12}\\ w_1&=\frac{V_{22}-V_{12}}{V_{11}+V_{22}-2V_{12}}\\ &=\frac{0.014-0.008}{0.050+0.014-2(0.008)}=\frac{0.006}{0.048}=0.125\\ w_2&=1-0.125=0.875 \end{aligned} \]

เมื่อ active set กำหนดให้ปลด QQQ ออกจากพอร์ตโดยตั้งน้ำหนักเป็นศูนย์ ปัญหาที่มีสามสินทรัพย์จะยุบตัวลงเหลือเพียงสองสินทรัพย์ และงบประมาณบีบให้ตัวแปรเหลือเพียง $w_1$ ตัวเดียว

เขียน variance รวมออกมาเป็น function กำลังสองของ $w_1$ โดยตรง จากนั้นหา derivative เทียบกับ $w_1$ แล้วจับเท่ากับศูนย์เพื่อหาก้นหลุมของพาราโบลา

การย้ายข้างจัดรูปธรรมดาให้สูตรปิดที่ขึ้นกับ covariance ของสองสินทรัพย์ เมื่อแทนค่าตัวเลขจริง $V_{11}=0.050$, $V_{22}=0.014$ และ $V_{12}=0.008$ จะได้น้ำหนัก SPY เท่ากับ 0.125 และ AGG เท่ากับ 0.875 ทันทีโดยไม่ต้องเดา

ขั้นที่ 6 — ตั้ง QQQ ที่ขอบแล้วแก้ใหม่

เมื่อคำตอบแบบไม่มีข้อห้ามฝ่าฝืนกติกา ให้ตรึงตัวที่ฝ่าฝืนไว้ที่ขอบ แล้วแก้ปัญหาที่เหลือใหม่

\[ w_3=0:\quad w_1=\frac{V_{22}-V_{12}}{V_{11}+V_{22}-2V_{12}}=\frac{0.014-0.008}{0.050+0.014-0.016}=0.125,\qquad w_2=0.875 \]

เมื่อ active set กำหนด QQQ ที่ zero ปัญหาเหลือสองสินทรัพย์; สูตร minimum variance ให้ SPY 12.5% และ AGG 87.5%

ขั้นที่ 7 — คำนวณ marginal variance ทุกสินทรัพย์

คูณ $V$ กับน้ำหนักใหม่ทีละแถว โดย QQQ มีน้ำหนักศูนย์ พจน์ที่สามจึงหายไปทุกแถว

\[ \begin{aligned}Vw^\star&=\begin{bmatrix}0.050(0.125)+0.008(0.875)\\ 0.008(0.125)+0.014(0.875)\\ 0.060(0.125)+0.012(0.875)\end{bmatrix}=\begin{bmatrix}0.00625+0.00700\\ 0.00100+0.01225\\ 0.00750+0.01050\end{bmatrix}=\begin{bmatrix}0.01325\\ 0.01325\\ 0.01800\end{bmatrix}\\[4pt] 2Vw^\star&=\begin{bmatrix}0.02650\\ 0.02650\\ 0.03600\end{bmatrix}\end{aligned} \]

SPY กับ AGG ที่ถือน้ำหนักบวกให้ marginal variance เท่ากันพอดีที่ 0.01325 ซึ่งเป็นสัญญาณว่าอยู่จุดต่ำสุดแล้ว ส่วน QQQ ที่ติดขอบให้ 0.01800 ซึ่งสูงกว่า การเพิ่ม QQQ จากศูนย์จึงมีแต่ทำให้ความเสี่ยงแย่ลง

ขั้นที่ 8 — กู้ multipliers แล้วตรวจทุกเงื่อนไข

ยังไม่จบแค่ได้คำตอบ ต้องย้อนกลับไปตรวจว่าครบทั้งสี่ข้อจริง โดยเฉพาะข้อที่บังคับว่าราคาเงาต้องไม่ติดลบ

\[ \nu=-0.02650,\qquad u=\begin{bmatrix}0\\ 0\\ 0.00950\end{bmatrix},\qquad u^{\mathsf T}w^\star=0 \]

stationarity ของสองสินทรัพย์ภายในให้ $\nu=-0.02650$; แถว QQQ ให้ $u_3=0.03600-0.02650=0.00950$ ซึ่งไม่ติดลบและคูณ weight zero ได้ zero

ขั้นที่ 9 — วัดต้นทุนของ long-only rule

ความเสี่ยงต่ำสุดแบบไม่มีข้อห้ามคือส่วนกลับของผลรวมที่คำนวณไว้แล้ว ส่วนของ long-only อ่านได้จาก marginal variance ในขั้นก่อนหน้า

\[ \begin{aligned}\sigma^2_{\rm uncon}&=\frac{1}{\mathbf1^{\mathsf T}V^{-1}\mathbf1}=\frac{1}{80.136986}=0.01247863\\ \sigma^2_{\rm long}&=w^{\star\mathsf T}Vw^\star=0.125(0.01325)+0.875(0.01325)+0=0.01325000\\ \Delta\sigma^2&=0.01325000-0.01247863=0.00077137\end{aligned} \]

ห้าม short ทำให้ annual variance เพิ่มขึ้น 0.00077137 ในตัวอย่างนี้ เป็นต้นทุนเชิงตัวเลขของ mandate ภายใต้ covariance ชุดนี้ ไม่ใช่ค่าธรรมเนียมที่จ่ายเป็นเงินสด

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

การจัดการข้อจำกัดที่เป็นอสมการ ทำให้แก้ปัญหาที่มีกฎห้ามได้ ซึ่งคือทุกปัญหาจริง

ใช้หาพอร์ตที่ดีที่สุดภายใต้กฎห้ามขายยืม ซึ่งเป็นกฎของกองทุนรวมเกือบทุกกอง

ใช้ระบุว่ากฎข้อไหนกำลังบีบคำตอบอยู่จริง และข้อไหนเขียนไว้เฉย ๆ แต่ไม่ได้มีผล

ใช้คำนวณต้นทุนของกฎแต่ละข้อเป็นตัวเลข เพื่อเอาไปคุยกับฝ่ายกำกับว่ากฎนั้นแพงแค่ไหน

คำตอบ — long-only บังคับ QQQ ลงที่ศูนย์

คำตอบ: long-only optimum คือ weights [0.125,0.875,0] โดย QQQ ถูกวางที่ขอบศูนย์; inequality multiplier ของ QQQ เท่ากับ 0.00950 และต้นทุนของกฎห้าม short เพิ่ม variance 0.00077137

ตรวจเองใน 10 วินาที: weights ต้องรวม 1 และไม่ติดลบ จากนั้น 0.00950×0 ต้องเท่ากับศูนย์ตาม complementarity; 0.01325000 - 0.01247863 ต้องได้ 0.00077137

ใช้ตัดสินใจ: active set นี้ผ่าน KKT จึงใช้เป็น long-only solution ได้ หาก multiplier ตัวใดติดลบต้องแก้ active set ใหม่ ห้าม clip น้ำหนักหลัง solver

กับดัก: คิดว่า multiplier ทุกตัวต้องเป็นบวก

มีเฉพาะ inequality multipliers ที่ต้องมีเครื่องหมายตามรูปมาตรฐาน Equality multiplier จะบวกหรือลบก็ได้ อีกจุดคือเปลี่ยนทิศ inequality แล้วต้องเปลี่ยนเครื่องหมาย multiplier ให้สอดคล้อง ไม่เช่นนั้นจะตีความ shadow price กลับด้าน

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
จำนวนกรณีลองทุกชุดของกฎที่ตึงได้จำนวนชุดโตแบบทวีคูณตามจำนวนกฎปัญหาที่มีกฎเยอะต้องใช้ตัวแก้ปัญหาเฉพาะทาง ไม่ใช่ไล่ลองด้วยมือ
convexityปัญหาเป็นรูปชามใบเดียวจริงสำหรับการจัดพอร์ตมาตรฐาน แต่ไม่จริงเมื่อเพิ่มต้นทุนบางแบบถ้าไม่ใช่รูปชาม เงื่อนไขที่ตรวจได้ก็ไม่รับประกันว่าเป็นคำตอบที่ดีที่สุด
ความเสถียรคำตอบนิ่งกฎที่ตึงพอดีทำให้คำตอบกระโดดเมื่อ input ขยับนิดเดียวน้ำหนักที่แนะนำอาจเปลี่ยนไปมาระหว่างวันโดยที่ตลาดแทบไม่เปลี่ยน

แถวล่างเป็นปัญหาจริงในการนำไปใช้ และมักแก้ด้วยการเพิ่มต้นทุนการซื้อขายเข้าไปในโจทย์

สรุปที่ใช้ได้จริง

  • KKT มัดเงื่อนไขสี่ข้อไว้ด้วยกัน: แรงที่จุดคำตอบต้องหักล้างกันหมด (stationarity), คำตอบต้องไม่ละเมิดข้อจำกัดใด (primal feasibility), ตัวคูณต้องไม่ติดลบ (dual feasibility) และข้อจำกัดที่ยังหลวมต้องมีตัวคูณเป็นศูนย์ (complementary slackness)
  • active constraint มี residual ศูนย์และอาจมี multiplier บวก ส่วน inactive constraint ต้องมี multiplier ศูนย์
  • long-only optimum คือ 12.5% SPY, 87.5% AGG และ 0% QQQ สำหรับ covariance สมมติชุดนี้
  • ห้าม clip แล้ว normalize; ต้องแก้ active set และตรวจ multipliers ใหม่
