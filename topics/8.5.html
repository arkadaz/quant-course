8.5 The Moment Generating Function (MGF)

เก็บ moments ใน function เดียว แล้วใช้ให้ถูกตัวแปร ถูกหน่วย และอยู่ในช่วงที่มีค่าจำกัด

หุ้นสมมติราคา \$100 มี log return หนึ่งปี $R\sim N(0.09,0.22^2)$ ราคาเฉลี่ยปลายปีควรเป็น \$109, \$109.42 หรือ \$112.10? ทำไม “เอาค่าเฉลี่ยไปใส่ใน exponential” จึงไม่ใช่คำตอบเดียวกับ “เฉลี่ยราคาที่ผ่าน exponential แล้ว”?

ลองตอบก่อนเปิดเฉลย

ได้ประมาณ \$112.10 เพราะ $\mathbb E[e^R]=e^{0.09+0.22^2/2}$ ในแบบจำลอง Normal นี้ ส่วน $100e^{\mathbb E[R]}\approx\$109.42$ เป็น median ของราคา ไม่ใช่ mean เครื่องมือที่หาค่า $\mathbb E[e^{tR}]$ ให้เราได้คือ MGF โดยต้องตรวจว่าค่านี้มีอยู่ก่อนใช้

MGF ไม่ใช่ PDF และ $t$ ไม่ใช่เวลา

MGF เปลี่ยนคำถามเกี่ยวกับ distribution ให้เป็นคำถามเกี่ยวกับ function เช่น derivative ที่ศูนย์ หรือผลคูณของ functions เราจะเริ่มจากตัวแปรที่มีสามค่า เพื่อเห็นกลไกก่อนขยับไป Normal และ vector

สัญลักษณ์ $t$ เป็น argument ที่เราเลือกป้อน ไม่ใช่ตัวแปรสุ่ม ไม่ใช่ probability และไม่ใช่เวลา หาก $X$ มีหน่วย USD ตัว $t$ ต้องมีหน่วย USD$^{-1}$ เพื่อให้ $tX$ ไม่มีหน่วย ส่วน $M_X(t)$ เองไม่มีหน่วย

ศัพท์ที่ต้องใช้
Raw moment
ค่า $\mathbb E[X^k]$ วัดกำลังรอบศูนย์ ไม่เหมือน central moment $\mathbb E[(X-\mathbb E[X])^k]$ ที่วัดรอบ mean
Moment generating function (MGF)
$M_X(t)=\mathbb E[e^{tX}]$ ในบริเวณที่ expectation มีค่าจำกัด การมี MGF รอบศูนย์เป็นเงื่อนไขที่แรงกว่าการมี mean กับ variance
Cumulant generating function (CGF)
$K_X(t)=\ln M_X(t)$ ทำให้ derivative แรกที่ศูนย์เป็น mean และ derivative ที่สองเป็น variance โดยตรง
Exponential integrability
ส่วนหางต้องเบาพอให้ expectation ของ exponential มีค่าจำกัดในช่วง argument ที่ต้องการ ไม่ใช่เพียงมีข้อมูลจำกัดจำนวนแถวให้คำนวณ
Numeraire
สิ่งที่เลือกเป็นหน่วยนับมูลค่า การกลับราคา USD ต่อหุ้นเป็นหุ้นต่อ USD เปลี่ยนหน่วยนับ ไม่ได้เท่ากับเปิด short หุ้นหนึ่งหุ้น
ตัวแปรไหน หน่วยอะไร
สัญลักษณ์ความหมาย
$X,t,M_X$ตัวแปรที่ศึกษา, argument, MGF ของตัวแปรนั้น
$M_X^{(k)}(0)$derivative ลำดับ $k$ ที่ศูนย์ ให้ raw moment เมื่อเงื่อนไขรองรับ
$\mu,\sigma^2$mean และ variance ของ Normal ที่ระบุในแต่ละตัวอย่าง อย่าสลับ parameter ระหว่างตัวอย่าง
$R,S_0,S_T$log return หนึ่งปี กับราคาเริ่ม/ปลายปีของหุ้นสมมติ
$X\in\mathbb R^n,s\in\mathbb R^n$ในส่วน multivariate ใช้ vector $X$ และ vector argument $s$ เพื่อไม่ปนกับ scalar $t$

ขั้นที่ 1 — สร้าง MGF ของบัตร 1, 2, 3 แล้ว differentiate

สุ่มบัตรหนึ่งใบจากสามใบที่มีโอกาสเท่ากัน แต่ละค่าจึงมี probability $1/3$ นี่คือ distribution ที่กำหนดไว้ ไม่ใช่ตัวอย่างข้อมูลที่กำลังประมาณ variance จึงไม่ใช้ตัวหาร $n-1$

\[ \begin{aligned} M_X(t)&:=\mathbb E[e^{tX}]\\ &=\tfrac13e^t+\tfrac13e^{2t}+\tfrac13e^{3t},\\ M_X(0)&=1,\\ M_X'(t)&=\tfrac13e^t+\tfrac23e^{2t}+e^{3t},\\ M_X'(0)&=(1+2+3)/3=2,\\ M_X''(0)&=(1^2+2^2+3^2)/3=14/3,\\ \operatorname{Var}(X)&=M_X''(0)-[M_X'(0)]^2\\ &=14/3-4=2/3. \end{aligned} \]

การ differentiate ทำให้เลขชี้กำลังดึง $X$ ลงมาทีละตัว แล้วแทน $t=0$ เพื่อให้ exponential เหลือ 1 ดังนั้นครั้งที่สองให้ raw second moment ไม่ใช่ variance และยิ่งไม่ใช่ SD

ขั้นที่ 2 — Generalize ได้เมื่อ expectation รองรับการสลับลำดับ

ให้ $M_X(t)$ finite บนช่วงเปิดรอบศูนย์ เราจึงเลือก $a\gt0$ ที่ $M_X(a),M_X(-a)$ finite ได้ เงื่อนไขนี้ช่วยควบคุมส่วนหาง ก่อนนำ Taylor series ไปไว้ใน expectation

\[ \begin{aligned} e^{tX}&=\sum_{k=0}^{\infty}\frac{t^kX^k}{k!},\\ M_X(t)&=\sum_{k=0}^{\infty}\frac{t^k\mathbb E[X^k]}{k!},\quad |t|\lt a,\\ M_X^{(k)}(0)&=\mathbb E[X^k],\\ \mathbb E[X]&=M_X'(0),\\ \operatorname{Var}(X)&=M_X''(0)-[M_X'(0)]^2. \end{aligned} \]

การเขียน Taylor series ของ exponential ได้ทุกจุด ไม่ได้อนุญาตให้สลับ expectation กับผลรวมอนันต์ในทุก distribution เราใส่เงื่อนไข finite รอบศูนย์ก่อนใช้สูตรดึง moments

ทำไมเงื่อนไขนี้ควบคุมผลรวมได้
\[ \begin{aligned} \sum_{k=0}^{\infty}\frac{|t|^k|X|^k}{k!}&=e^{|t||X|}\\ &\le e^{a|X|}\le e^{aX}+e^{-aX},\\ \mathbb E[e^{a|X|}]&\le M_X(a)+M_X(-a)\lt\infty. \end{aligned} \]

จึงมีตัวครอบที่ integrate ได้สำหรับค่าสัมบูรณ์ของ series ภายในช่วงดังกล่าว ผลรวมมีสัมประสิทธิ์ $\mathbb E[X^k]/k!$ และ differentiate ที่ศูนย์ได้ นี่เป็นเงื่อนไขที่สะดวกและเพียงพอ ไม่ได้อ้างว่าเป็นวิธีเดียวที่จะหา moment บางลำดับ

ทฤษฎีเอกลักษณ์ของ MGF ระบุว่า distributions ที่มี MGF finite และเท่ากันตลอดช่วงเปิดรอบศูนย์ต้องเป็น distribution เดียวกัน การตรงกันแค่ $t$ จุดเดียว หรือแค่ mean/variance ไม่พอ ข้อนี้ทำให้เราใช้ MGF ระบุ distribution ของผลรวมได้ภายใต้เงื่อนไขดังกล่าว

ขั้นที่ 3 — Normal MGF มาจากการจัดกำลังสองสมบูรณ์

เริ่มจาก $Z\sim N(0,1)$ แล้วค่อย scale/shift เป็น $X=\mu+\sigma Z$ การเลื่อนกึ่งกลางใน integral ไม่เปลี่ยนพื้นที่รวมของ Normal density

\[ \begin{aligned} M_Z(t)&=\frac1{\sqrt{2\pi}}\int_{-\infty}^{\infty}e^{tz-z^2/2}\,dz,\\ tz-z^2/2&=-\tfrac12(z-t)^2+\tfrac12t^2,\\ M_Z(t)&=e^{t^2/2}\underbrace{\int_{-\infty}^{\infty} \frac{e^{-(z-t)^2/2}}{\sqrt{2\pi}}\,dz}_{=1}\\ &=e^{t^2/2},\\ M_X(t)&=e^{\mu t}M_Z(\sigma t)\\ &=e^{\mu t+\sigma^2t^2/2},\quad t\in\mathbb R. \end{aligned} \]

Normal MGF finite สำหรับทุก real $t$ จึงใช้ทั้งการ differentiate ใกล้ศูนย์และการประเมินที่ $t=1$ ได้ แต่ตัวแปรชนิดอื่นอาจมี domain แคบกว่านี้

ต่อไปให้ $X$ เป็น P&L รวมตลอดหนึ่งวันใน USD โดย $X\sim N(75,300^2)$ มันเป็นจำนวนเงินของหนึ่งช่วง ไม่ใช่อัตรา USD/day เราจึงได้ mean \$75, SD \$300 และ raw second moment 95,625 USD² ดังนี้

\[ \begin{aligned} M_X'(t)&=(\mu+\sigma^2t)M_X(t),\\ M_X''(t)&=\{\sigma^2+(\mu+\sigma^2t)^2\}M_X(t),\\ M_X'(0)&=75,\\ M_X''(0)&=300^2+75^2=95{,}625,\\ \operatorname{Var}(X)&=95{,}625-75^2=90{,}000\ \mathrm{USD}^2. \end{aligned} \]

ขั้นที่ 4 — ถ้าอยากได้ variance ตรง ๆ ใช้ log-MGF

MGF เป็นบวกเมื่อ finite จึงนิยาม $K_X(t)=\ln M_X(t)$ ได้ Differentiation ของ log หักกำลังสองของ mean ให้เองที่ศูนย์

\[ \begin{aligned} K_X(t)&:=\ln M_X(t),\\ K_X'(t)&=M_X'(t)/M_X(t),\\ K_X''(t)&=\frac{M_X''(t)}{M_X(t)}-\left(\frac{M_X'(t)}{M_X(t)}\right)^2,\\ K_X'(0)&=\mathbb E[X],\\ K_X''(0)&=\operatorname{Var}(X),\\ K_X(t)&=\mu t+\tfrac12\sigma^2t^2\quad(\text{Normal}). \end{aligned} \]

สำหรับ Normal, derivatives ของ $K$ ลำดับสามขึ้นไปเป็นศูนย์ นั่นคือ higher cumulants เป็นศูนย์ ไม่ใช่ raw moments เช่น standard Normal ยังมี $\mathbb E[Z^4]=3$

กราฟ MGF ไม่จำเป็นต้องต่ำสุดที่ศูนย์: ในตัวอย่าง P&L $M'(0)=75\gt0$ จุดต่ำสุดอยู่ที่ $t=-\mu/\sigma^2=-1/1200$ และ $M(t)=e^{-1/32}\approx0.969233$ ค่า MGF ต่ำกว่า 1 ได้โดยไม่มีความผิดปกติ

ขั้นที่ 5 — ใช้ MGF ของ log return เพื่อหาราคาเฉลี่ย

โจทย์ให้อะไรมาบ้าง: หุ้นสมมติ \$100 ไม่มีเงินปันผลในตัวอย่าง มี log return หนึ่งปี $R\sim N(0.09,0.22^2)$ เรากำลังหาค่าเฉลี่ยตาม distribution ที่สมมติ ไม่ใช่สูตรตั้งราคายุติธรรมแบบ risk-neutral

\[ \begin{aligned} S_T&=100e^R,\\ \mathbb E[S_T]&=100M_R(1)\\ &=100e^{0.09+0.22^2/2}\\ &\approx112.097630\ \mathrm{USD},\\ m_S&:=\operatorname{median}(S_T),\\ m_S&=100e^{0.09}\\ &\approx109.417428\ \mathrm{USD},\\ \mathbb E[S_T/100-1]&=e^{0.1142}-1\approx12.0976\%. \end{aligned} \]

คำตอบ: ราคาเฉลี่ยประมาณ \$112.10 ส่วน \$109.42 เป็น median เพราะ Normal $R$ มี median เท่ากับ 0.09 และ exponential เพิ่มตาม $R$ ค่า 9% เป็น mean ของ log return ไม่ใช่ expected simple return

ตรวจเองใน 10 วินาที: $\sigma^2/2=0.0242$ คือส่วนเพิ่มใน exponent ไม่ใช่ส่วนต่างของราคาโดยตรง ช่องว่าง mean กับ median จริงคือประมาณ \$2.6802 บนราคาเริ่ม \$100

Jensen’s inequality บอกว่า $\mathbb E[e^R]\ge e^{\mathbb E[R]}$ แต่ไม่ได้ให้สูตรส่วนเพิ่มครึ่ง variance ในทุก distribution ผลเท่ากับ $e^{\mu+\sigma^2/2}$ มาจาก Normal MGF ที่เพิ่งพิสูจน์ ไม่ใช่รู้แค่ mean และ SD แล้วใช้ได้ทันที

ขั้นที่ 6 — การแทน $t=-1$ ไม่ใช่การคำนวณกำไรจาก short

$e^{-R}=S_0/S_T$ เป็น reciprocal price ratio ไม่ใช่กำไรหรือ gross return ของการ short หุ้นหนึ่งหุ้น ความผิดพลาดเกิดจากเห็นเครื่องหมายลบแล้วเปลี่ยนความหมายของ payoff โดยไม่ได้เขียนกระแสเงินจริง

\[ \begin{aligned} \mathbb E[e^{-R}]&=M_R(-1)\\ &=e^{-0.09+0.0242}\approx0.936318,\\ \Pi_{\text{short}}&=S_0-S_T\quad\text{ก่อนต้นทุน},\\ \mathbb E[\Pi_{\text{short}}]&=100-112.097630\\ &\approx-12.097630\ \mathrm{USD},\\ M_R(1)M_R(-1)&=e^{\sigma^2}\approx1.049590,\\ C&:=\operatorname{Cov}(e^R,e^{-R}),\\ C&=\mathbb E[1]-M_R(1)M_R(-1)\\ &=1-e^{\sigma^2}\approx-0.049590. \end{aligned} \]

ผลคูณของค่าคาดหมายไม่เท่ากับค่าคาดหมายของผลคูณ เพราะตัวแปรสองตัวนี้ไม่ได้เป็นอิสระกัน ส่วนกำไร short ต้องรวมค่าหุ้นที่ต้องซื้อคืน และในงานจริงยังมีดอกเบี้ย ค่ายืมหุ้น และเงินปันผลที่ต้องชดเชย

แม้ตั้ง mean ของ log return เป็นศูนย์จน $M_R(1)=M_R(-1)=e^{\sigma^2/2}\gt1$ ก็ไม่ได้หมายถึงมีกำไร USD ทั้ง long และ short ค่า reciprocal เปลี่ยนหน่วยนับหรือ payoff ประเด็นการกลับ quote แบบนี้เกี่ยวข้องกับ Siegel’s paradox แต่ไม่ใช่สูตรสร้าง arbitrage

ในตัวอย่างเดิม expected inverse-ratio return คือ $0.936318-1\approx-6.3682\%$ ขณะที่ expected short P&L หารด้วยราคาเริ่มเป็น $-12.0976\%$ สองตัวนี้คนละ payoff และตัวหลังยังไม่ใช่ผลตอบแทนบน margin capital จริง ซึ่งต้องกำหนดแยกต่างหาก

ขั้นที่ 7 — ผลรวมอิสระเปลี่ยน convolution เป็นผลคูณ

ให้ $X,Y$ เป็นอิสระกัน และ MGFs finite ที่ argument ที่ใช้ การ factor expectation อาศัย independence โดยตรง ไม่ใช่แค่ covariance ศูนย์

\[ \begin{aligned} M_{X+Y}(t)&=\mathbb E[e^{t(X+Y)}]\\ &=\mathbb E[e^{tX}e^{tY}]\\ &=\mathbb E[e^{tX}]\mathbb E[e^{tY}]\\ &=M_X(t)M_Y(t),\\ K_{X+Y}(t)&=K_X(t)+K_Y(t). \end{aligned} \]

แทนที่จะ convolve densities ก่อนแล้วค่อยหา moments เราสามารถคูณ MGFs หรือบวก log-MGFs ได้ ถ้าเงื่อนไข independence ไม่จริง ต้องใช้ joint distribution แทนการคูณ marginal MGFs

Figure 8.5c ใช้ P&L สอง desk ที่อิสระ: $X\sim N(50,220^2)$ และ $Y\sim N(25,180^2)$ ของช่วงหนึ่งวัน ผลรวมจึงมี mean 75 USD แต่ variance เป็น 80,800 USD² ไม่ใช่ 90,000 ของตัวอย่างก่อน

\[ \begin{aligned} M_X(t)M_Y(t)&=e^{50t+220^2t^2/2}\\ &\quad\times e^{25t+180^2t^2/2}\\ &=e^{75t+(80{,}800)t^2/2},\\ X+Y&\sim N(75,80{,}800),\\ \operatorname{SD}(X+Y)&=\sqrt{80{,}800}\\ &\approx284.2534\ \mathrm{USD}. \end{aligned} \]

บรรทัดระบุ distribution ใช้ทฤษฎีเอกลักษณ์: MGF ของผลรวมตรงกับ Normal MGF สำหรับทุก $t$ ถ้า desk มี correlation ต้องใส่ covariance และตรวจ joint model ใหม่ ไม่ใช่ใช้กราฟผลคูณนี้ต่อโดยไม่เปลี่ยนสมมติฐาน

ขั้นที่ 8 — Multivariate MGF สร้างจาก independent Gaussian coordinates

ให้ $X=\mu+LZ$ ตาม 8.4 โดย $Z$ มี independent standard Normal components และ $LL^{\mathsf T}=\Sigma$ กำหนด vector argument $s$ และ $a=L^{\mathsf T}s$ แล้วใช้ univariate MGF ที่พิสูจน์แล้วทีละ component

\[ \begin{aligned} M_X(s)&:=\mathbb E[e^{s^{\mathsf T}X}]\\ &=e^{s^{\mathsf T}\mu}\mathbb E[e^{a^{\mathsf T}Z}]\\ &=e^{s^{\mathsf T}\mu}\prod_j M_{Z_j}(a_j)\\ &=e^{s^{\mathsf T}\mu+\frac12\sum_j a_j^2},\\ \sum_j a_j^2&=s^{\mathsf T}LL^{\mathsf T}s=s^{\mathsf T}\Sigma s,\\ M_X(s)&=e^{s^{\mathsf T}\mu+\frac12s^{\mathsf T}\Sigma s}. \end{aligned} \]

ไม่มี inverse หรือ determinant ในสูตรนี้ จึงใช้กับ Gaussian ที่ covariance เป็น PSD แต่ singular ได้ด้วย ต่างจาก density เต็มมิติของ 8.4 อย่างไรก็ตามยังต้องเป็น joint Gaussian ไม่ใช่รู้เพียงว่า marginal แต่ละตัวเป็น Normal

Gradient กับ Hessian เก็บอะไร
\[ \begin{aligned} K_X(s)&=s^{\mathsf T}\mu+\tfrac12s^{\mathsf T}\Sigma s,\\ \nabla K_X(s)&=\mu+\Sigma s,\\ \nabla^2K_X(s)&=\Sigma,\\ \nabla M_X(s)&=(\mu+\Sigma s)M_X(s),\\ \nabla M_X(0)&=\mu,\\ \nabla^2M_X(0)&=\Sigma+\mu\mu^{\mathsf T}=\mathbb E[XX^{\mathsf T}]. \end{aligned} \]

Gradient รวบรวม derivatives แรก ส่วน Hessian รวบรวม derivatives ที่สอง: Hessian ของ $M$ ที่ศูนย์ให้ raw second-moment matrix แต่ Hessian ของ $K$ ให้ covariance matrix โดยตรง

ตัวอย่างใหม่ ให้ $\mu=(0.05,0.08)^{\mathsf T}$ และ $\Sigma=\begin{bmatrix}0.04&0.01\\0.01&0.09\end{bmatrix}$ เป็น parameters ของ Gaussian log returns ช่วงหนึ่งปี เมื่อ $s=(1,-0.5)^{\mathsf T}$ จะได้

\[ \begin{aligned} s^{\mathsf T}\mu&=0.05-0.5(0.08)=0.01,\\ s^{\mathsf T}\Sigma s&=0.04+0.25(0.09)-0.01=0.0525,\\ M_X(s)&=e^{0.01+0.0525/2}\approx1.036915. \end{aligned} \]

$e^{s^{\mathsf T}X}$ ในที่นี้เป็น exponential ของ linear combination ของ log returns หรือผลคูณ geometric ของ gross returns ไม่ใช่ simple return ของพอร์ตลงทุนเงินตาม weights $s$ โดยอัตโนมัติ การสร้างพอร์ตจริงต้องเริ่มจาก payoff/เงินลงทุนเช่นใน 8.2

ขั้นที่ 9 — เช็ก domain ก่อนกดปุ่มหา moment

ตัวอย่างง่ายที่ไม่ได้ finite ทุก $t$ คือ $X\sim\operatorname{Exponential}(\lambda)$ โดย $\lambda\gt0$ เลขชี้กำลังที่เหลือหลังรวมกับ density ต้องลดลงเมื่อ $x$ เพิ่ม

\[ \begin{aligned} M_X(t)&=\int_0^{\infty}e^{tx}\lambda e^{-\lambda x}\,dx\\ &=\lambda\int_0^{\infty}e^{-(\lambda-t)x}\,dx,\\ t\lt\lambda:\quad M_X(t)&=\frac{\lambda}{\lambda-t},\\ t\ge\lambda:\quad M_X(t)&=\infty. \end{aligned} \]

ที่ $t=\lambda$ integrand เป็นค่าคงที่บวกตลอดครึ่งเส้นจำนวน จึง diverge แล้ว ถ้า $\lambda=2$ จะได้ $M(1)=2$ แต่ $M(2)$ ไม่ใช่ตัวเลข finite ให้เอาไปใช้งานต่อ

Student-t ไม่มี MGF finite รอบศูนย์ แม้เลือก degrees of freedom มากพอให้ variance finite แล้วก็ตาม เพราะ exponential เอาชนะ polynomial tails ส่วนการที่ข้อมูลจำลองมีจำนวนแถวจำกัดและให้ empirical MGF finite ไม่ใช่หลักฐานว่า expectation ของ population finite

มีทุก polynomial moment ก็ยังไม่มี MGF รอบศูนย์ได้

ให้ $Z\sim N(0,1)$ และ $Y=e^Z$ ซึ่งเป็น Lognormal สำหรับทุกจำนวนเต็มไม่ติดลบ $k$ เรามี $\mathbb E[Y^k]=M_Z(k)=e^{k^2/2}\lt\infty$ แต่เมื่อ $t\gt0$

\[ \begin{aligned} M_Y(t)&=\frac1{\sqrt{2\pi}}\int_{-\infty}^{\infty} e^{t e^z-z^2/2}\,dz\\ &=\infty\qquad(t\gt0). \end{aligned} \]

เมื่อ $z$ โต พจน์ $t e^z$ โตเร็วกว่าพจน์ลบ $z^2/2$ จน integrand ไม่ลดลงให้ integrate ได้ นี่ไม่ขัดกับราคาหุ้นตัวอย่าง: ที่นั่นใช้ MGF ของ log return ที่ 1 ไม่ใช่ MGF ของตัวราคา Lognormal ที่ argument บวก

เครื่องมือ transform อีกตัวคือ characteristic function $\mathbb E[e^{iuX}]$ ซึ่งมีอยู่เสมอสำหรับ real $u$ เพราะ $|e^{iuX}|=1$ ส่วน MGF แบบ real exponent ต้องตรวจ integrability แยก แนวคิด transform เหล่านี้เชื่อมกับ Laplace transform: เปลี่ยนปัญหา expectation/convolution ให้จัดการด้วย function โดยรักษาเงื่อนไขของ transform นั้นไว้

ตรวจ derivative ด้วยตัวเลขอย่างรู้ข้อจำกัด

Central differences ประมาณ derivatives ด้วยค่าที่อยู่ใกล้ศูนย์ แต่ $h$ ใหญ่ทำให้ truncation error มาก ขณะที่ $h$ เล็กเกินไปทำให้ลบตัวเลขที่เกือบเท่ากันจนเสียความละเอียด จึงไม่ใช่ว่ายิ่งลด $h$ ยิ่งแม่นเสมอ

อย่ารวมสี่คำถามเป็นคำถามเดียว

  • ตัวแปรอะไร: P&L, log return, ราคาหุ้น และ reciprocal price เป็นคนละตัวแปร มี MGFs/payoffs คนละความหมาย
  • moment อะไร: $M''(0)$ คือ raw second moment ส่วน variance ต้องหัก mean² หรือใช้ $K''(0)$
  • domain ไหน: มี moments บางลำดับหรือคำนวณ finite sample ได้ ไม่ยืนยัน MGF finite ในช่วงที่ต้องการ
  • independence ไหน: คูณ marginal MGFs ได้เมื่อมี independence ไม่ใช่แค่แต่ละ marginal ดู Normal หรือ covariance ศูนย์

ลองสามคำถามก่อนอ่าน marginals

1. $A$ มีค่า $-1,+1$ อย่างละครึ่ง ส่วน $B\sim N(0,1)$ ทั้งคู่ mean ศูนย์และ variance หนึ่ง แล้ว $\mathbb E[e^A]$ กับ $\mathbb E[e^B]$ เท่ากันหรือไม่?

เฉลย

ไม่เท่า: $M_A(1)=(e+e^{-1})/2\approx1.543081$ ส่วน $M_B(1)=e^{1/2}\approx1.648721$ ข้อมูล mean/variance เท่ากันไม่ทำให้ MGF ทั้ง function เท่ากัน และไม่ทำให้ Gaussian half-variance formula ใช้กับ A ได้

2. เปลี่ยน P&L จาก USD เป็นพัน USD โดย $Y=X/1000$ เมื่อ $X\sim N(75,300^2)$ MGF และ raw second moment เปลี่ยนอย่างไร?

เฉลย

$M_Y(u)=M_X(u/1000)$ ดังนั้น mean เป็น 0.075, variance 0.09, raw second moment 0.095625 และ $M_Y(1)=M_X(0.001)\approx1.127497$ การเปลี่ยนหน่วยเปลี่ยน argument scale ไม่ได้เปลี่ยน payoff ทางเศรษฐกิจ

3. กลับไปคู่ $X\sim N(0,1),Y=WX$ ของ 8.3 โดย W เป็นเครื่องหมายอิสระ $\pm1$ อย่างละครึ่ง แม้ covariance ศูนย์ จะคูณ MGFs เพื่อหา $\mathbb E[e^{X+Y}]$ ได้หรือไม่?

เฉลย

ไม่ได้ เมื่อ $W=-1$ จะได้ $X+Y=0$ และเมื่อ $W=1$ จะได้ $2X$ ดังนั้น $\mathbb E[e^{X+Y}]=(1+M_X(2))/2=(1+e^2)/2\approx4.194528$ แต่การคูณ marginal MGFs ให้ $e^{1/2}e^{1/2}=e\approx2.718282$ ความต่างมาจาก dependence ที่ covariance มองไม่เห็น

คำนวณซ้ำด้วย JavaScript

รันด้วย Node.js โดยไม่ต้องติดตั้งแพ็กเกจ log-MGF ช่วยเลี่ยงการสร้าง exponential ที่ใหญ่เกินเครื่อง แต่ไม่ได้ทำให้ MGF ที่ diverge ทางคณิตศาสตร์กลับมามีค่า โค้ดแยกกรณี Exponential นอก domain ออกจาก numeric overflow

ส่วน finite law รับ outcomes ที่มีโอกาสเท่ากันเท่านั้น การใช้ log-sum-exp ป้องกัน overflow ระหว่างบวก exponentials; ไม่ได้พิสูจน์ว่า population ที่นำข้อมูลมาจากนั้นมี MGF finite

function finiteVector(v, size = null) {
  if (!Array.isArray(v) || !v.length || (size !== null && v.length !== size) ||
      ![...v].every(Number.isFinite)) throw new TypeError('Need a finite vector of the required size');
}
function finiteResult(value) {
  if (!Number.isFinite(value)) throw new RangeError('Numerical overflow or invalid arithmetic');
  return value;
}
function expChecked(logValue) {
  finiteResult(logValue);
  const value = Math.exp(logValue);
  if (!Number.isFinite(value)) throw new RangeError('MGF overflow: retain the log-MGF');
  return value;
}
function normalLogMGF(t, mean, variance) {
  if (![t, mean, variance].every(Number.isFinite) || variance < 0) {
    throw new RangeError('Normal inputs must be finite with nonnegative variance');
  }
  const u = Math.sqrt(variance) * t;
  return finiteResult(mean * t + 0.5 * u * u);
}
const normalMGF = (t, mean, variance) => expChecked(normalLogMGF(t, mean, variance));
function equalLogMGF(t, values) {
  finiteVector(values);
  if (!Number.isFinite(t)) throw new RangeError('Need a finite argument');
  const a = values.map(x => finiteResult(t * x));
  const peak = a.reduce((m, x) => Math.max(m, x), -Infinity);
  return finiteResult(peak + Math.log(a.reduce((s, x) => s + Math.exp(x - peak), 0) / a.length));
}
function exponentialLogMGF(t, rate) {
  if (![t, rate].every(Number.isFinite) || rate <= 0) throw new RangeError('Invalid exponential arguments');
  if (t >= rate) return Infinity; // Mathematical divergence, not machine overflow.
  if (t >= -rate) return -Math.log1p(-t / rate);
  return Math.log(rate) - Math.log(-t) - Math.log1p(rate / (-t));
}
function projectNormal(mean, covariance, w) {
  finiteVector(mean, 2); finiteVector(w, 2);
  if (!Array.isArray(covariance) || covariance.length !== 2 ||
      [...covariance].some(row => !Array.isArray(row) || row.length !== 2 || ![...row].every(Number.isFinite))) {
    throw new TypeError('Need a finite 2 by 2 covariance');
  }
  const a = covariance[0][0], c = covariance[0][1], d = covariance[1][1];
  if (c !== covariance[1][0]) throw new RangeError('Covariance must be symmetric');
  if (a < 0 || d < 0) throw new RangeError('Covariance must be PSD');
  let first = 0, second = 0;
  if (a === 0 || d === 0) {
    if (c !== 0) throw new RangeError('Covariance must be PSD');
    first = Math.sqrt(a) * w[0]; second = Math.sqrt(d) * w[1];
  } else {
    const s1 = Math.sqrt(a), s2 = Math.sqrt(d), rho = c / s1 / s2;
    if (!Number.isFinite(rho) || Math.abs(rho) > 1) throw new RangeError('Covariance must be PSD');
    first = s1 * w[0] + rho * s2 * w[1];
    second = s2 * Math.sqrt((1 - rho) * (1 + rho)) * w[1];
  }
  return {mean: finiteResult(w[0] * mean[0] + w[1] * mean[1]),
    variance: finiteResult(first * first + second * second)};
}
function jointLogMGF(s, mean, covariance) {
  const p = projectNormal(mean, covariance, s);
  return finiteResult(p.mean + 0.5 * p.variance);
}
function differences(mean, variance, h) {
  if (!Number.isFinite(h) || h <= 0 || !Number.isFinite(h * h) || h * h === 0) {
    throw new RangeError('Invalid difference step');
  }
  const plus = normalMGF(h, mean, variance), minus = normalMGF(-h, mean, variance);
  return {h, first: finiteResult((plus - minus) / (2 * h)),
    second: finiteResult((plus - 2 + minus) / (h * h))};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • MGF คือ expectation ของ exponential ไม่ใช่ density และ t ไม่ใช่เวลา; ต้องดูหน่วยของตัวแปรก่อนเลือก argument
  • เมื่อ finite รอบศูนย์ $M^{(k)}(0)$ ให้ raw moments; variance เท่ากับ $M''(0)-[M'(0)]^2$ หรือ $K''(0)$
  • Normal MGF มาจากการจัดกำลังสองสมบูรณ์ การอ่าน expected price จาก log return ต้องอาศัย distribution ที่ระบุ ไม่ใช่แค่ mean/SD
  • Reciprocal price ratio ไม่ใช่ ordinary short payoff และการคูณค่าคาดหมายไม่เหมือน expectation ของผลคูณเมื่อ dependent
  • MGF ของผลรวมอิสระเป็นผลคูณ; multivariate Gaussian MGF ใช้ mean/covariance รวม off-diagonals และยังใช้กับ singular Gaussian ได้
  • มี polynomial moments ไม่รับประกัน MGF รอบศูนย์; ตรวจ domain และแยก mathematical divergence จาก numerical overflow/rounding
