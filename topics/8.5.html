8.5 Markowitz Portfolio Selection

ผสมสินทรัพย์ให้ผลตอบแทนกับความแกว่งสมดุลกัน

มีตะกร้าสองใบ: ใบหนึ่งผลไม้หวานมากแต่รสแกว่ง อีกใบหวานน้อยแต่สม่ำเสมอ ถ้าคุณแบ่งเงิน 50–50 ความแกว่งรวมต้องอยู่กึ่งกลางเสมอไหม?

เฉลย: ไม่เสมอ; แม้แบ่งเงิน 50–50 ถ้าสินทรัพย์สองตัวมักดีคนละวัน การผสมอาจแกว่งน้อยกว่าทั้งคู่ ไม่ใช่แค่ค่าเฉลี่ยของความแกว่ง

Markowitz portfolio selection เลือกน้ำหนักสินทรัพย์เพื่อแลก expected return กับ variance โดยใช้ covariance วัดการขยับร่วมกัน และหา efficient allocation

diversification ซื้อวันที่ตะกร้าหนึ่งแย่แต่อีกตะกร้าช่วยพยุง; งานจริงสร้าง frontier และ risk budget จาก covariance matrix

ศัพท์ที่ใช้ในหัวข้อนี้
mean-variance
กรอบที่ให้รางวัล expected return และลงโทษ variance ใช้เลือกพอร์ตตามระดับการเกลียดความเสี่ยง
efficient frontier
ขอบของพอร์ตที่ให้ expected return สูงสุดสำหรับ risk แต่ละระดับ ใช้ตัดพอร์ตที่มีตัวเลือกอื่นดีกว่าทั้ง return และ risk
tangency portfolio
พอร์ตสินทรัพย์เสี่ยงที่ให้ Sharpe ratio สูงสุดเมื่อมีสินทรัพย์ปลอดความเสี่ยง ใช้กำหนด risky fund กลาง
Sharpe ratio
expected excess return ส่วนด้วย volatility ใช้วัดผลตอบแทนคาดหวังต่อหนึ่งหน่วยความเสี่ยง
estimation error
ความคลาดเคลื่อนระหว่าง parameter ที่ประมาณกับค่าจริงที่ไม่รู้ ใช้เตือนว่าน้ำหนัก optimal อาจเปราะต่อข้อมูลย้อนหลัง
portfolio value
มูลค่าสินทรัพย์สุทธิของกองทุน ใช้เป็นฐานแปลง portfolio weights ให้เป็น USD notionals
long position
สถานะที่มูลค่าเพิ่มเมื่อสินทรัพย์ขึ้น ใช้เป็นรูปแบบการถือกองทุนด้วยน้ำหนักบวกในพอร์ต
GMV
Global Minimum Variance (GMV) พอร์ตที่มี variance รวมต่ำที่สุดบน efficient frontier ใช้เป็นจุดอ้างอิงความเสี่ยงต่ำสุดโดยไม่ขึ้นกับผลตอบแทนเป้าหมาย
สัญลักษณ์ที่ใช้ในหัวข้อนี้

ที่มาที่ไป: วิทยานิพนธ์ที่เปลี่ยนวิธีคิดของทั้งอุตสาหกรรม

ก่อนปี 1952 การเลือกหุ้นคือการเลือกทีละตัว โดยดูว่าตัวไหนน่าจะให้ผลตอบแทนดีที่สุด แล้วซื้อตัวนั้นให้มากที่สุด

Harry Markowitz ชี้ให้เห็นในบทความปี 1952 ว่าวิธีนั้นผิดตั้งแต่ตั้งคำถาม เพราะความเสี่ยงของพอร์ตไม่ได้เท่ากับผลรวมของความเสี่ยงรายตัว มันขึ้นกับว่าของแต่ละตัวขยับสัมพันธ์กันอย่างไร

ผลที่ตามมาคือของที่ดูแย่เมื่อดูเดี่ยว ๆ อาจมีค่ามากในพอร์ต ถ้ามันขยับสวนทางกับของที่มีอยู่

ความคิดนี้ได้รางวัลโนเบลในปี 1990 และกลายเป็นภาษากลางของทั้งอุตสาหกรรม แม้ในทางปฏิบัติจะต้องปรับอีกมากก่อนใช้จริง ซึ่งเป็นเนื้อหาของหัวข้อ 17.8 และ 17.9

ที่มาของแบบจำลอง Markowitz: การปฏิวัติแนวคิดความเสี่ยงในปี 1952

Harry Markowitz นักเศรษฐศาสตร์รางวัลโนเบล เสนอแบบจำลองนี้ในวิทยานิพนธ์ปริญญาเอกและตีพิมพ์ในบทความ Portfolio Selection ในวารสาร The Journal of Finance เมื่อเดือนมีนาคม 1952 ก่อนหน้านั้น ทฤษฎีการลงทุนตามแนวคิดของ John Burr Williams ในปี 1938 เน้นสอนให้หามูลค่าปัจจุบันของเงินปันผล และเลือกลงทุนในหุ้นที่ให้ expected return สูงสุดเป็นรายตัว

แต่หลักคิดดังกล่าวมีจุดบกพร่องร้ายแรง เพราะหากนักลงทุนมองหาแต่ผลตอบแทนสูงสุดเพียงอย่างเดียว คำตอบที่ดีที่สุดตามทฤษฎีเดิมคือการทุ่มเงินทั้งหมด 100% ลงในหุ้นตัวเดียว ทั้งที่ในโลกแห่งความจริงทุกคนตระหนักดีถึงสุภาษิตว่าอย่าใส่ไข่ไว้ในตะกร้าใบเดียว แต่ไม่มีใครอธิบายทางคณิตศาสตร์ได้ว่าควรจัดสรรอย่างไร

Markowitz เป็นคนแรกที่มองเห็นว่าความเสี่ยงไม่ใช่คุณสมบัติโดดเดี่ยว แต่ส่งผลต่อกันผ่าน covariance สินทรัพย์สองตัวที่ผันผวนสูง เมื่อนำมาผสมกันอย่างถูกต้อง หากราคาเคลื่อนไหวสวนทางกัน ความเสี่ยงรวมของพอร์ตจะลดลงต่ำกว่าความเสี่ยงของสินทรัพย์เดี่ยวอย่างน่าอัศจรรย์ เขาจึงสร้าง quadratic programming เพื่อแลกเปลี่ยนระหว่าง expected return กับ variance และเปลี่ยนโฉมอุตสาหกรรมจัดการลงทุนไปตลอดกาล

Worked Example — โจทย์และสิ่งที่ให้มา

โจทย์ให้อะไรมาบ้าง: ตัวอย่างใช้ annual expected returns 12% สำหรับ SPY และ 6% สำหรับ AGG, annual volatilities 20% กับ 10%, correlation 0.30 และ rebalancing horizon หนึ่งปี ตัวเลขเป็นสมมติฐานสอน ไม่ใช่ forecast ปัจจุบัน และ model ไม่มี taxes, transaction costs หรือ weight bounds

ขั้นที่ 1 — โจทย์และ covariance

ตั้งโจทย์ให้ครบก่อน คือจะเอาผลตอบแทนสูงแต่ไม่อยากเสี่ยงมาก และน้ำหนักต้องรวมเป็นหนึ่ง

\[ \max_x\ \mu^{\mathsf{T}}x-\gamma x^{\mathsf{T}}Vx,\quad \mathbf1^{\mathsf{T}}x=1,\qquad \mu=\begin{bmatrix}0.12\\ 0.06\end{bmatrix},\quad V=\begin{bmatrix}0.040&0.006\\ 0.006&0.010\end{bmatrix} \]

objective ให้ expected annual return หัก risk penalty; covariance 0.006 มาจาก 0.30 คูณ 0.20 คูณ 0.10 และ weights ต้องรวมหนึ่ง

ขั้นที่ 2 — Lagrangian และคำตอบทั่วไป

ใช้เครื่องมือจากหัวข้อก่อนหน้าจัดการข้อบังคับ แล้วแก้ออกมาเป็นสูตรทั่วไปก่อนแทนตัวเลข ห้าบรรทัดนี้แสดงว่าสูตรน้ำหนักพอร์ตที่โด่งดัง แท้จริงคือการย้ายข้างสามครั้ง บนสมการที่ได้จากการตั้งความชันเป็นศูนย์

\[ \begin{aligned}\mathcal L&=\mu^{\mathsf{T}}x-\gamma x^{\mathsf{T}}Vx-\nu\big(\mathbf1^{\mathsf{T}}x-1\big)\\ \frac{\partial\mathcal L}{\partial x}&=\mu-2\gamma Vx-\nu\mathbf1=0\\ 2\gamma Vx&=\mu-\nu\mathbf1\\ Vx&=\frac{1}{2\gamma}\big(\mu-\nu\mathbf1\big)\\ x&=\frac{1}{2\gamma}V^{-1}\big(\mu-\nu\mathbf1\big)\end{aligned} \]

สร้าง Lagrangian ตามวิธีของหัวข้อ 8.4 คือติดราคาให้ข้อบังคับหนึ่งข้อ แล้วหา derivative เทียบน้ำหนัก ตั้งให้เป็นศูนย์ สามพจน์ที่ได้มาจากขั้นที่ 7 ของหัวข้อ 8.3 บวกพจน์ข้อบังคับที่เพิ่งเติม

ที่เหลือคือย้ายข้างสามครั้ง เก็บพจน์ที่มี $x$ ไว้ข้างเดียว ส่วนด้วย $2\gamma$ ซึ่งเป็นบวกจึงไม่มีอะไรพลิก แล้วคูณด้วย $V^{-1}$ จากด้านซ้าย ทำได้เมื่อ $V$ กลับด้านได้ ซึ่งหัวข้อ 4.5 บอกว่าต้องมีทิศครบ และหัวข้อ 4.6 บอกว่า positive definite ก็เพียงพอ ยังเหลือ $\nu$ ที่ไม่รู้ค่า ขั้นถัดไปจะหามันจากข้อบังคับ

ขั้นที่ 3 — กลับ covariance matrix

matrix 2×2 กลับด้านได้ด้วยสูตรตายตัว: สลับตัวบนซ้ายกับล่างขวา เปลี่ยนเครื่องหมายสองตัวมุมเฉียง แล้วหารทุกช่องด้วย determinant

\[ \begin{aligned}\det V&=0.040(0.010)-0.006^2=0.000400-0.000036=0.000364\\ V^{-1}&=\frac{1}{0.000364}\begin{bmatrix}0.010&-0.006\\ -0.006&0.040\end{bmatrix}=\begin{bmatrix}27.472527&-16.483516\\ -16.483516&109.890110\end{bmatrix}\end{aligned} \]

แต่ละช่องคือตัวเลขในวงเล็บส่วนด้วย 0.000364 เช่น $0.010/0.000364=27.472527$ และ $0.006/0.000364=16.483516$ determinant เป็นบวก matrix จึงกลับด้านได้

ขั้นที่ 4 — คูณ $V^{-1}$ กับสอง vector ก่อน

สี่ scalar ในขั้นถัดไปทั้งหมดสร้างจากผลคูณสองอันนี้เท่านั้น คูณให้เสร็จก่อนจะได้ไม่ต้องคูณซ้ำ

\[ \begin{aligned}V^{-1}\mathbf1&=\begin{bmatrix}27.472527-16.483516\\ -16.483516+109.890110\end{bmatrix}=\begin{bmatrix}10.989011\\ 93.406593\end{bmatrix}\\[4pt] V^{-1}\mu&=\begin{bmatrix}27.472527(0.12)-16.483516(0.06)\\ -16.483516(0.12)+109.890110(0.06)\end{bmatrix}=\begin{bmatrix}3.296703-0.989011\\ -1.978022+6.593407\end{bmatrix}=\begin{bmatrix}2.307692\\ 4.615385\end{bmatrix}\end{aligned} \]

แถวบนของ matrix คูณกับ vector ได้ตัวบน แถวล่างได้ตัวล่าง อันแรกคือบวกตามแถวเฉย ๆ เพราะ vector ที่คูณเป็นเลขหนึ่งทั้งคู่

ขั้นที่ 5 — สรุปข้อมูลเป็นสี่ scalar

เอาผลคูณจากขั้นก่อนมาบวกและคูณต่อ ไม่มีการคูณ matrix ใหม่อีกแล้ว

\[ \begin{aligned}A&=\mathbf1^{\mathsf{T}}(V^{-1}\mathbf1)=10.989011+93.406593=104.395604\\ B&=\mathbf1^{\mathsf{T}}(V^{-1}\mu)=2.307692+4.615385=6.923077\\ C&=\mu^{\mathsf{T}}(V^{-1}\mu)=0.12(2.307692)+0.06(4.615385)=0.276923+0.276923=0.553846\\ D&=A\,C-B^2=104.395604(0.553846)-6.923077^2=57.819121-47.928994=9.890127\end{aligned} \]

$A$ สรุป covariance, $B$ เชื่อม covariance กับ expected returns, $C$ เป็น quadratic score และ $D$ กำหนดความโค้งของ frontier ค่า $D$ ที่คำนวณเต็มความละเอียดคือ 9.890110 ต่างกันที่ทศนิยมตัวท้ายเพราะการปัดเลข

ขั้นที่ 6 — จุดยอดของความผันผวนต่ำสุด: Global Minimum Variance (GMV)

ชุดสมการนี้สร้างพอร์ต Global Minimum Variance (GMV) ซึ่งเผยให้เห็นความหมายทางกายภาพของค่า $A$ และ $B$ ที่คำนวณไว้ โดยจุดยอดซ้ายสุดของหัวกระสุน Markowitz ไม่ได้มาจากการเดา แต่คำนวณได้โดยตรงจากสัดส่วนของ $V^{-1}\mathbf{1}$

\[ \begin{aligned} \min_x\ x^{\mathsf T}Vx\quad&\text{subject to}\quad \mathbf{1}^{\mathsf T}x=1\\ \mathcal{L}(x,\lambda)&=x^{\mathsf T}Vx-\lambda\big(\mathbf{1}^{\mathsf T}x-1\big)\\ \nabla_x\mathcal{L}&=2Vx-\lambda\mathbf{1}=0\quad\Longrightarrow\quad x=\frac{\lambda}{2}V^{-1}\mathbf{1}\\ \mathbf{1}^{\mathsf T}x&=1\quad\Longrightarrow\quad \frac{\lambda}{2}\mathbf{1}^{\mathsf T}V^{-1}\mathbf{1}=1\quad\Longrightarrow\quad \frac{\lambda}{2}=\frac{1}{A}\\ x_{\mathrm{GMV}}&=\frac{V^{-1}\mathbf{1}}{A}=\frac{1}{104.395604}\begin{bmatrix}10.989011\\ 93.406593\end{bmatrix}=\begin{bmatrix}0.1053\\ 0.8947\end{bmatrix}\\ \sigma_{\min}^2&=x_{\mathrm{GMV}}^{\mathsf T}Vx_{\mathrm{GMV}}=\frac{\mathbf{1}^{\mathsf T}V^{-1}VV^{-1}\mathbf{1}}{A^2}=\frac{1}{A}=\frac{1}{104.395604}=0.009579\\ \sigma_{\min}&=\sqrt{0.009579}=0.097872=9.79\%\\ \mu_{\mathrm{GMV}}&=\mu^{\mathsf T}x_{\mathrm{GMV}}=\frac{\mu^{\mathsf T}V^{-1}\mathbf{1}}{A}=\frac{B}{A}=\frac{6.923077}{104.395604}=6.63\% \end{aligned} \]

ถ้าไม่สนใจผลตอบแทนเลยและต้องการลดความผันผวนให้ต่ำที่สุดในจักรวาลของสินทรัพย์ที่มี จุดยอดของเส้น frontier คือพอร์ต Global Minimum Variance (GMV) ซึ่งแก้ได้จาก Lagrangian ที่มีข้อจำกัดเรื่องงบประมาณเพียงข้อเดียว

การแก้สมการเผยให้เห็นความหมายที่แท้จริงของ scalar $A$ และ $B$ ที่คำนวณไว้ โดยค่ายกกำลังสองของความเสี่ยงต่ำสุดมีค่าเท่ากับ $\frac{1}{A}$ พอดีเป๊ะ และผลตอบแทน ณ จุดต่ำสุดนี้เท่ากับ $\frac{B}{A}$

เมื่อแทนตัวเลขจริง น้ำหนักจะเทไปที่พันธบัตร AGG สูงถึง 89.47% และถือ SPY เพียง 10.53% ให้ความผันผวนรวมลดลงเหลือ 9.79% ซึ่งต่ำกว่าความผันผวนเดี่ยวของสินทรัพย์ทั้งสองตัว

ขั้นที่ 7 — แก้พอร์ตเมื่อเลือกความเกลียดความเสี่ยง

เลือก $\gamma=2$ แล้วหาตัวคูณงบประมาณก่อน จากนั้นหักออกจาก expected return ทุกตัว แล้วจึงคูณด้วย $V^{-1}$

\[ \begin{aligned}\nu&=\frac{B-2\gamma}{A}=\frac{6.923077-4}{104.395604}=\frac{2.923077}{104.395604}=0.028000\\[4pt] \mu-\nu\mathbf1&=\begin{bmatrix}0.12-0.028\\ 0.06-0.028\end{bmatrix}=\begin{bmatrix}0.092\\ 0.032\end{bmatrix}\\[4pt] V^{-1}(\mu-\nu\mathbf1)&=\begin{bmatrix}27.472527(0.092)-16.483516(0.032)\\ -16.483516(0.092)+109.890110(0.032)\end{bmatrix}=\begin{bmatrix}2.527473-0.527473\\ -1.516484+3.516484\end{bmatrix}=\begin{bmatrix}2\\ 2\end{bmatrix}\\[4pt] x&=\frac{1}{2\gamma}\begin{bmatrix}2\\ 2\end{bmatrix}=\frac14\begin{bmatrix}2\\ 2\end{bmatrix}=\begin{bmatrix}0.50\\ 0.50\end{bmatrix}\end{aligned} \]

ที่มาของ $\nu$: บังคับให้น้ำหนักรวมเป็นหนึ่ง $\mathbf1^{\mathsf{T}}x=\frac{1}{2\gamma}\big(\mathbf1^{\mathsf{T}}V^{-1}\mu-\nu\,\mathbf1^{\mathsf{T}}V^{-1}\mathbf1\big)=\frac{B-\nu A}{2\gamma}=1$ ย้ายข้างได้ $\nu=\frac{B-2\gamma}{A}$ ตัวคูณจึงเป็นแค่ค่าที่ทำให้งบพอดี ไม่ได้เลือกเอง

ตัวคูณงบประมาณ 2.80% คือส่วนที่ต้องหักออกก่อน เหลือ 9.2% กับ 3.2% พอคูณด้วย inverse covariance ได้สองเท่ากันพอดี ส่วนด้วย $2\gamma=4$ จึงได้น้ำหนักครึ่งต่อครึ่ง และรวมกันได้หนึ่งตามเงื่อนไข

ที่มาของ $\nu$: เอา $\mathbf1^\mathsf{T}$ คูณสูตร $x$ แล้วใช้ผลรวมน้ำหนักเท่ากับ 1 จะได้ $1=(B-\nu A)/(2\gamma)$ คูณด้วย $2\gamma$ แล้วย้ายข้างเป็น $\nu A=B-2\gamma$ ส่วนด้วย $A>0$ จึงได้ตัวเลขบรรทัดแรก

ขั้นที่ 8 — ตรวจ return risk และ objective

ตรวจว่าคำตอบที่ได้ให้ผลตอบแทนและความเสี่ยงเท่าไรจริง ๆ ก่อนจะเชื่อมัน

\[ \mu_p=0.5(0.12)+0.5(0.06)=9.00\%,\quad \sigma_p^2=0.25(0.040)+0.50(0.006)+0.25(0.010)=0.0155,\quad \sigma_p=12.45\% \]

expected return เฉลี่ยตาม weights ส่วน variance รวม two variances กับ covariance cross-term; objective เท่ากับ 0.059

ขั้นที่ 9 — เขียน efficient frontier ทั้งเส้น

แทนที่จะแก้ทีละเป้าหมาย เขียนเป็นสมการเดียวที่ครอบคลุมทุกเป้าหมาย แปดบรรทัดนี้คือที่มาของเส้นโค้งที่ทุกตำราวาดไว้ และมันเป็นพาราโบลาเพราะ $m$ ปรากฏกำลังสองในบรรทัดสุดท้าย ไม่ใช่เพราะใครเลือกให้มันสวย

\[ \begin{aligned}A&=\mathbf1^{\mathsf{T}}V^{-1}\mathbf1,\quad B=\mathbf1^{\mathsf{T}}V^{-1}\mu,\quad C=\mu^{\mathsf{T}}V^{-1}\mu,\quad D=AC-B^{2}\\ x&=V^{-1}\big(\alpha\mathbf1+\beta\mu\big)\\ \mathbf1^{\mathsf{T}}x=1\;&\Longrightarrow\;A\alpha+B\beta=1\\ \mu^{\mathsf{T}}x=m\;&\Longrightarrow\;B\alpha+C\beta=m\\ \alpha=\frac{C-Bm}{D},\quad&\beta=\frac{Am-B}{D}\\[4pt] \sigma^{2}(m)=x^{\mathsf{T}}Vx&=x^{\mathsf{T}}\big(\alpha\mathbf1+\beta\mu\big)=\alpha+\beta m\\ &=\frac{C-Bm}{D}+\frac{Am-B}{D}m\\ &=\frac{Am^{2}-2Bm+C}{D}\end{aligned} \]

บรรทัดแรกตั้งชื่อสั้น ๆ ให้สี่ก้อนที่จะโผล่ซ้ำ ทั้งหมดคำนวณจาก $\mu$ กับ $V$ ได้ครั้งเดียวแล้วใช้ตลอด บรรทัดสองคือรูปของคำตอบจากเงื่อนไขความชันเป็นศูนย์ มีข้อบังคับสองข้อจึงมีตัวคูณสองตัว ต่างจากขั้นที่ 2 ที่มีตัวเดียว

แทนคำตอบนั้นลงในข้อบังคับทีละข้อ ได้สมการเชิงเส้นสองสมการ แก้ด้วยกฎกลับ 2×2 จากหัวข้อ 4.5 จากนั้นใช้ทางลัด: $Vx$ คือก้อนในวงเล็บพอดี คูณด้วย $x^{\mathsf T}$ จึงได้ $\alpha$ คูณผลรวมน้ำหนัก บวก $\beta$ คูณผลตอบแทน ซึ่งข้อบังคับกำหนดไว้แล้วทั้งคู่ แทนค่าแล้วรวมพจน์ ได้พาราโบลาในตัวแปร $m$ ห้ามหารเมื่อ $D$ เป็นศูนย์

ขั้นที่ 10 — ทฤษฎีบทการแยกสองกองทุน (Two-Fund Separation Theorem)

หกบรรทัดนี้เป็นรากฐานของอุตสาหกรรมกองทุนรวม โดยพิสูจน์ว่าเส้น efficient frontier ทั้งเส้นสามารถสังเคราะห์ขึ้นมาจากพอร์ตอ้างอิงเพียงสองพอร์ต ทำให้นักลงทุนสามารถกระจายความเสี่ยงข้ามระดับผลตอบแทนได้อย่างมีระบบ

\[ \begin{aligned} \mathbf{1}^{\mathsf T}x^{(1)}&=1,\quad \mu^{\mathsf T}x^{(1)}=r_1,\qquad \mathbf{1}^{\mathsf T}x^{(2)}=1,\quad \mu^{\mathsf T}x^{(2)}=r_2\\ \alpha&=\frac{r-r_1}{r_2-r_1},\qquad y=(1-\alpha)x^{(1)}+\alpha x^{(2)}\\ \mathbf{1}^{\mathsf T}y&=(1-\alpha)\mathbf{1}^{\mathsf T}x^{(1)}+\alpha\mathbf{1}^{\mathsf T}x^{(2)}=(1-\alpha)+\alpha=1\\ \mu^{\mathsf T}y&=(1-\alpha)\mu^{\mathsf T}x^{(1)}+\alpha\mu^{\mathsf T}x^{(2)}=(1-\alpha)r_1+\alpha r_2=r\\ v&=(1-\alpha)v_1+\alpha v_2,\qquad u=(1-\alpha)u_1+\alpha u_2\\ 2Vy-v\mu-u\mathbf{1}&=(1-\alpha)\big(2Vx^{(1)}-v_1\mu-u_1\mathbf{1}\big)+\alpha\big(2Vx^{(2)}-v_2\mu-u_2\mathbf{1}\big)=0 \end{aligned} \]

ทฤษฎีบทการแยกสองกองทุนพิสูจน์ว่า หากเรามีพอร์ตที่มีประสิทธิภาพสองพอร์ตใด ๆ บนเส้นขอบ $x^{(1)}$ และ $x^{(2)}$ ที่มีผลตอบแทนต่างกัน เราจะสามารถสร้างพอร์ตที่เหมาะสมที่สุดสำหรับทุกระดับผลตอบแทนเป้าหมาย $r$ ได้จากการผสมเชิงเส้นของสองพอร์ตนี้เสมอ

การตรวจสอบความเป็นไปได้ทำได้ง่ายมาก เพราะผลรวมน้ำหนักของ $y$ ยังคงเป็นหนึ่ง และผลตอบแทนเฉลี่ยก็วิ่งตรงไปที่เป้าหมาย $r$ ตามสัดส่วน $\alpha$ ที่เลือก

บรรทัดสุดท้ายยืนยันความสมบูรณ์แบบทางคณิตศาสตร์ เมื่อนำตัวคูณของสองระบบมารวมกัน เงื่อนไขความชันเป็นศูนย์จะสอดคล้องทันที นักลงทุนจึงไม่จำเป็นต้องถือหุ้นรายตัวนับร้อย แต่สามารถจัดพอร์ตที่ดีที่สุดได้โดยถือเพียงกองทุนดัชนีสองกองทุน

ขั้นที่ 11 — Tangency portfolio เมื่อมี cash rate

คราวนี้หัก cash rate ออกจาก expected return ก่อน แล้วคูณด้วย $V^{-1}$ จากนั้นส่วนด้วยผลรวมของตัวเอง เพื่อบังคับให้น้ำหนักรวมเป็นหนึ่ง

\[ \begin{aligned}\mu-r_f\mathbf1&=\begin{bmatrix}0.12-0.02\\ 0.06-0.02\end{bmatrix}=\begin{bmatrix}0.10\\ 0.04\end{bmatrix}\\[4pt] V^{-1}(\mu-r_f\mathbf1)&=\begin{bmatrix}2.747253-0.659341\\ -1.648352+4.395604\end{bmatrix}=\begin{bmatrix}2.087912\\ 2.747253\end{bmatrix},\qquad \text{sum}=4.835165\\[4pt] x_T&=\frac{1}{4.835165}\begin{bmatrix}2.087912\\ 2.747253\end{bmatrix}=\begin{bmatrix}0.4318\\ 0.5682\end{bmatrix}\end{aligned} \]

หัก annual risk-free rate 2% ออกก่อน เพราะ tangency สนใจผลตอบแทนส่วนเกินเท่านั้น การส่วนด้วยผลรวม 4.835165 คือขั้นที่บังคับให้ risky weights รวมกันได้หนึ่ง

ขั้นที่ 12 — Sharpe ratio ของ tangency portfolio

มีน้ำหนักแล้วจึงคิดผลตอบแทนและความเสี่ยงของพอร์ตนี้ แล้วหารกัน

คำตอบที่ได้คือ Sharpe ratio 0.7358 ซึ่งสูงกว่าสินทรัพย์เดี่ยวทั้งสองตัวที่ได้ 0.60 เท่ากัน ส่วนที่เพิ่มขึ้นมานั้นมาจากการกระจายความเสี่ยง ไม่ได้มาจากการทายทิศทางเก่งขึ้น และนี่คือเหตุผลที่พอร์ตผสมถูกใช้แทนการเลือกสินทรัพย์ตัวที่ดีที่สุด

\[ \begin{aligned}\mu_T&=0.4318(0.12)+0.5682(0.06)=0.051818+0.034091=0.085909\\ \sigma_T^2&=0.4318^2(0.040)+2(0.4318)(0.5682)(0.006)+0.5682^2(0.010)\\ &=0.007458+0.002944+0.003229=0.013631\\ \sigma_T&=\sqrt{0.013631}=0.116753\\ \operatorname{SR}_T&=\frac{0.085909-0.02}{0.116753}=\frac{0.065909}{0.116753}=0.5645\end{aligned} \]

บรรทัด variance ใช้สูตรพอร์ตสองตัวปกติ: กำลังสองของน้ำหนักคูณ variance ของแต่ละตัว บวกพจน์ไขว้ที่มีเลขสองอยู่ข้างหน้า จากนั้น Sharpe คือผลตอบแทนส่วนเกินส่วนด้วย standard deviation

แล้วเอาไปใช้ทำอะไรได้จริงบ้าง

การผสมสินทรัพย์ให้สมดุลระหว่างผลตอบแทนกับความเสี่ยง เป็นโจทย์ตั้งต้นของการจัดการลงทุนทั้งอุตสาหกรรม

ใช้หาสัดส่วนการลงทุนที่ให้ผลตอบแทนดีที่สุดสำหรับระดับความเสี่ยงที่รับได้

ใช้วาดเส้นขอบประสิทธิภาพ เพื่อให้ผู้ลงทุนเลือกจุดที่ตรงกับความอดทนของตัวเอง

ใช้หาพอร์ตที่ให้ผลตอบแทนต่อความเสี่ยงสูงสุด ซึ่งเป็นจุดตั้งต้นของทฤษฎีการตั้งราคาสินทรัพย์ในบทที่ 15

คำตอบ — portfolio ที่ได้คือ 50/50

คำตอบ: เมื่อ risk-aversion coefficient เท่ากับ 2 model ให้น้ำหนัก SPY 50% และ AGG 50% สำหรับ portfolio 100 USD million จึงเป็น notional 50 USD million ต่อกอง expected return เท่ากับ 9.00% และ volatility ประมาณ 12.45%

ตรวจเองใน 10 วินาที: น้ำหนัก 50% + 50% ต้องรวมเป็น 100% และ 0.5×12% + 0.5×6% ต้องได้ expected return 9%

ใช้ตัดสินใจ: ใช้ 50/50 เป็นจุดเริ่มเสนอ allocation แล้วตรวจ long-only bounds, liquidity, taxes, turnover และ stress risk ก่อนส่ง orders จริง

กับดัก: รายงานทศนิยมเยอะแล้วดูแม่น

matrix inverse ขยาย estimation error โดยเฉพาะเมื่อสินทรัพย์คล้ายกันมาก ควรใช้ covariance shrinkage, robust expected returns, weight bounds และ out-of-sample tests ตัวเลขแม่นต่อ input ไม่ได้แปลว่า input จริงแม่น

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
ความไวต่อ inputตัวเลขที่ใส่แม่นพอผลตอบแทนคาดหวังประมาณยากที่สุดในบรรดา input ทั้งหมดเปลี่ยน input นิดเดียว น้ำหนักที่ได้เปลี่ยนไปคนละเรื่อง และมักสุดโต่งจนใช้ไม่ได้
การขายยืมขายยืมได้ไม่จำกัดกองทุนส่วนใหญ่ห้ามขายยืมคำตอบที่ได้มักติดลบหนัก ซึ่งต้องแก้ด้วยข้อจำกัดในหัวข้อ 8.6
การวัดความเสี่ยงความเหวี่ยงเป็นตัววัดความเสี่ยงที่ดีคนกลัวขาดทุน ไม่ได้กลัวความเหวี่ยงพอร์ตที่ดีที่สุดตามสูตรอาจมีความเสี่ยงขาลงสูงกว่าที่ยอมรับได้

แถวแรกเป็นข้อวิจารณ์ที่ดังที่สุดของวิธีนี้ และเป็นเหตุผลที่มีหัวข้อ 17.8 และ 17.9

สรุปที่ใช้ได้จริง

  • mean-variance เลือกพอร์ตจาก expected return หัก risk penalty ภายใต้ budget
  • efficient frontier เก็บเฉพาะพอร์ตที่ไม่มีตัวเลือกอื่นให้ return สูงกว่าและ risk ต่ำกว่า
  • tangency portfolio ใช้ excess returns ที่ปรับด้วย inverse covariance
  • ผลลัพธ์ไวต่อ expected-return error จึงต้อง regularize, constrain และทดสอบนอกตัวอย่าง
