8.5 Markowitz Portfolio Selection

ผสมสินทรัพย์ให้ผลตอบแทนกับความผันผวนสมดุลกัน

หุ้นคาดหวัง 12% ผันผวน 20% พันธบัตรคาดหวัง 6% ผันผวน 10% correlation 0.30 ต้องลงเงินครบ 100% ความกลัวความเสี่ยง γ = 2 ควรถือหุ้นกี่เปอร์เซ็นต์ และพอร์ตไหนให้ผลตอบแทนต่อความเสี่ยงดีที่สุด?

เฉลย: หุ้นครึ่งพันธบัตรครึ่งพอดี ผลตอบแทน 9.00% ความผันผวน 12.45% ค่าเป้าหมาย 0.0590 ชนะการถือตัวเดียวที่ได้ 0.0400 ทั้งคู่ พอร์ตที่ Sharpe สูงสุดคือหุ้น 43.2% ได้ 0.5645 และพอร์ตเสี่ยงต่ำสุดคือหุ้น 10.5% เสี่ยงแค่ 9.79% สามคำถาม สามพอร์ต ออกมาจากสูตรเดียว

Markowitz portfolio selection เลือกน้ำหนักสินทรัพย์เพื่อแลก expected return กับ variance โดยใช้ covariance วัดการขยับร่วมกัน และหา efficient allocation

ศัพท์ที่ใช้ในหัวข้อนี้
mean-variance
กรอบที่ให้รางวัล expected return และลงโทษ variance ใช้เลือกพอร์ตตามระดับการเกลียดความเสี่ยง
efficient frontier
ขอบของพอร์ตที่ให้ expected return สูงสุดสำหรับความเสี่ยงแต่ละระดับ ใช้ตัดพอร์ตที่มีตัวเลือกอื่นดีกว่าทั้งผลตอบแทนและ risk
tangency portfolio
พอร์ตสินทรัพย์เสี่ยงที่ให้ Sharpe ratio สูงสุดเมื่อมีสินทรัพย์ปลอดความเสี่ยง ใช้กำหนด risky fund กลาง
Sharpe ratio
expected excess return หารด้วยความผันผวนใช้วัดผลตอบแทนคาดหวังต่อหนึ่งหน่วยความเสี่ยง
estimation error
ความคลาดเคลื่อนระหว่าง parameter ที่ประมาณกับค่าจริงที่ไม่รู้ ใช้เตือนว่าน้ำหนัก optimal อาจเปราะต่อข้อมูลย้อนหลัง
portfolio value
มูลค่าสินทรัพย์สุทธิของกองทุน ใช้เป็นฐานแปลง portfolio weights ให้เป็น USD notionals
long position
สถานะที่มูลค่าเพิ่มเมื่อสินทรัพย์ขึ้น ใช้เป็นรูปแบบการถือกองทุนด้วยน้ำหนักบวกในพอร์ต
Global Minimum Variance (GMV) portfolio
พอร์ตที่มี variance รวมต่ำที่สุดบน efficient frontier ใช้เป็นจุดอ้างอิงความเสี่ยงต่ำสุดโดยไม่ต้องรู้ผลตอบแทนคาดหวังเลย
short selling
การขายสินทรัพย์ที่ยืมมา น้ำหนักจึงติดลบได้ ใช้เมื่อสูตรบอกว่าสินทรัพย์นั้นทำให้พอร์ตแย่ลง
shadow price
ค่าที่ objective ขยับต่อการผ่อนข้อจำกัดหนึ่งหน่วย ใช้อ่านว่าข้อจำกัดงบประมาณมีต้นทุนเท่าไร
two-fund theorem
ข้อเท็จจริงที่ว่าทุกพอร์ตบน frontier สร้างได้จากการผสมพอร์ตสองพอร์ต ใช้อธิบายว่าทำไมทุกคนถือ tangency portfolio เดียวกันแล้วผสมกับเงินสด

ที่มาที่ไป: วิทยานิพนธ์ที่เปลี่ยนวิธีคิดของทั้งอุตสาหกรรม

ก่อนปี 1952 การเลือกหุ้นคือการเลือกทีละตัว โดยดูว่าตัวไหนน่าจะให้ผลตอบแทนดีที่สุด แล้วซื้อตัวนั้นให้มากที่สุด

Harry Markowitz ชี้ให้เห็นในบทความปี 1952 ว่าวิธีนั้นผิดตั้งแต่ตั้งคำถาม เพราะความเสี่ยงของพอร์ตไม่ได้เท่ากับผลรวมของความเสี่ยงรายตัว มันขึ้นกับว่าของแต่ละตัวขยับสัมพันธ์กันอย่างไร

ผลที่ตามมาคือของที่ดูแย่เมื่อดูเดี่ยว ๆ อาจมีค่ามากในพอร์ต ถ้ามันขยับสวนทางกับของที่มีอยู่

ความคิดนี้ได้รางวัลโนเบลในปี 1990 และกลายเป็นภาษากลางของทั้งอุตสาหกรรม แม้ในทางปฏิบัติจะต้องปรับอีกมากก่อนใช้จริง ซึ่งเป็นเนื้อหาของหัวข้อ 17.8 และ 17.9

ที่มาของแบบจำลอง Markowitz: การปฏิวัติแนวคิดความเสี่ยงในปี 1952

Harry Markowitz นักเศรษฐศาสตร์รางวัลโนเบล เสนอแบบจำลองนี้ในวิทยานิพนธ์ปริญญาเอกและตีพิมพ์ในบทความ Portfolio Selection ในวารสาร The Journal of Finance เมื่อเดือนมีนาคม 1952 ก่อนหน้านั้น ทฤษฎีการลงทุนตามแนวคิดของ John Burr Williams ในปี 1938 เน้นสอนให้หามูลค่าปัจจุบันของเงินปันผล และเลือกลงทุนในหุ้นที่ให้ expected return สูงสุดเป็นรายตัว

แต่หลักคิดดังกล่าวมีจุดบกพร่องร้ายแรง เพราะหากนักลงทุนมองหาแต่ผลตอบแทนสูงสุดเพียงอย่างเดียว คำตอบที่ดีที่สุดตามทฤษฎีเดิมคือการทุ่มเงินทั้งหมด 100% ลงในหุ้นตัวเดียว ทั้งที่ในโลกแห่งความจริงทุกคนตระหนักดีถึงสุภาษิตว่าอย่าใส่ไข่ไว้ในตะกร้าใบเดียว แต่ไม่มีใครอธิบายทางคณิตศาสตร์ได้ว่าควรจัดสรรอย่างไร

Markowitz เป็นคนแรกที่มองเห็นว่าความเสี่ยงไม่ใช่คุณสมบัติโดดเดี่ยว แต่ส่งผลต่อกันผ่าน covariance สินทรัพย์สองตัวที่ผันผวนสูง เมื่อนำมาผสมกันอย่างถูกต้อง หากราคาเคลื่อนไหวสวนทางกัน ความเสี่ยงรวมของพอร์ตจะลดลงต่ำกว่าความเสี่ยงของสินทรัพย์เดี่ยว เขาจึงสร้าง quadratic programming เพื่อแลกเปลี่ยนระหว่าง expected return กับ variance

โจทย์: หุ้นกับพันธบัตร ลงเงินครบ 100% ขายชอร์ตได้

โจทย์ให้อะไรมาบ้าง: หุ้นคาดหวัง 12% ผันผวน 20% พันธบัตรคาดหวัง 6% ผันผวน 10% correlation 0.30 ความกลัวความเสี่ยง γ = 2 น้ำหนักรวมต้องเป็น 1 แต่ติดลบได้ ตัวเลขเป็นสมมติฐานสอน ไม่ใช่ forecast และ model ไม่มี taxes, transaction costs หรือ weight bounds

ผลตอบแทนคาดหวังเป็น expected value ไม่ใช่ค่าที่รับประกัน γ คือผลตอบแทนที่ยอมจ่ายต่อ variance หนึ่งหน่วย ยิ่งมากยิ่งกลัวความผันผวน

ขั้นที่ 1 — ตั้งโจทย์ และสร้าง μ กับ V

ตั้งโจทย์ให้ครบก่อน คือจะเอาผลตอบแทนสูงแต่ไม่อยากเสี่ยงมาก และน้ำหนักต้องรวมเป็นหนึ่ง แล้วแปลง correlation เป็น covariance

\[ \begin{aligned} \max_x\ &\mu^{\mathsf{T}}x-\gamma\,x^{\mathsf{T}}Vx,\qquad \mathbf1^{\mathsf{T}}x=1\\[4pt] V_{12}&=\rho\sigma_1\sigma_2=0.30(0.20)(0.10)=0.006\\ \mu&=\begin{bmatrix}0.12\\ 0.06\end{bmatrix},\qquad V=\begin{bmatrix}0.040&0.006\\ 0.006&0.010\end{bmatrix}\\ \det V&=0.04(0.01)-0.006^2=0.000364>0 \end{aligned} \]

objective ให้ expected annual return หัก risk penalty ช่องทแยงคือ variance ของแต่ละตัว ช่องนอกทแยง 0.006 บอกว่าสองตัวล้มพร้อมกันแค่ไหน ถ้าตัดทิ้งโดยสมมติ ρ = 0 คำตอบทั้งข้อจะเปลี่ยน determinant บวกและทแยงบวก V จึง positive definite ปัญหามีคำตอบเดียว

0.006 ดูเล็กเพราะอยู่ในหน่วยผลตอบแทนกำลังสอง ห้ามเทียบกับ 0.30 ตรง ๆ สองตัวนี้คนละหน่วยกัน

ขั้นที่ 2 — Lagrangian และคำตอบทั่วไป

ใช้เครื่องมือจากหัวข้อก่อนหน้าจัดการข้อบังคับ แล้วแก้ออกมาเป็นสูตรทั่วไปก่อนแทนตัวเลข ห้าบรรทัดนี้แสดงว่าสูตรน้ำหนักพอร์ตที่โด่งดัง แท้จริงคือการย้ายข้างสามครั้ง บนสมการที่ได้จากการตั้งความชันเป็นศูนย์

\[ \begin{aligned}\mathcal L&=\mu^{\mathsf{T}}x-\gamma x^{\mathsf{T}}Vx-\nu\big(\mathbf1^{\mathsf{T}}x-1\big)\\ \frac{\partial\mathcal L}{\partial x}&=\mu-2\gamma Vx-\nu\mathbf1=0\\ 2\gamma Vx&=\mu-\nu\mathbf1\\ Vx&=\frac{1}{2\gamma}\big(\mu-\nu\mathbf1\big)\\ x&=\frac{1}{2\gamma}V^{-1}\big(\mu-\nu\mathbf1\big)\end{aligned} \]

สร้าง Lagrangian ตามวิธีของหัวข้อ 8.4 คือติดราคาให้ข้อบังคับหนึ่งข้อ แล้วหา derivative เทียบน้ำหนัก ตั้งให้เป็นศูนย์ สามพจน์ที่ได้มาจากขั้นที่ 9 ของหัวข้อ 8.3 บวกพจน์ข้อบังคับที่เพิ่งเติม

V ไม่ใช่ตัวเลข มันคือ matrix การหาร V ในโลก vector ทำโดยคูณ V⁻¹ เข้าทางซ้าย สูตรปิดของ Markowitz จึงมี V⁻¹ ยืนอยู่ตรงกลางเสมอ และนี่ก็เป็นจุดอ่อนที่สุดของมันด้วย ยังเหลือ ν ที่ไม่รู้ค่า ขั้นที่ 6 จะหามันจากข้อบังคับ

ขั้นที่ 3 — กลับ covariance matrix ด้วยมือ แล้วตรวจว่าได้ I จริง

matrix 2×2 กลับด้านได้ด้วยสูตรตายตัว: สลับตัวบนซ้ายกับล่างขวา เปลี่ยนเครื่องหมายสองตัวมุมเฉียง แล้วหารทุกช่องด้วย determinant

\[ \begin{aligned} V^{-1}&=\frac{1}{0.000364}\begin{bmatrix}0.010&-0.006\\ -0.006&0.040\end{bmatrix}\\ &=\begin{bmatrix}27.4725&-16.4835\\ -16.4835&109.8901\end{bmatrix}\\[4pt] (VV^{-1})_{11}&=0.04(27.4725)+0.006(-16.4835)=1.0989-0.0989=1\\ (VV^{-1})_{12}&=0.04(-16.4835)+0.006(109.8901)=-0.6593+0.6593=0\\ (VV^{-1})_{21}&=0.006(27.4725)+0.01(-16.4835)=0.1648-0.1648=0\\ (VV^{-1})_{22}&=0.006(-16.4835)+0.01(109.8901)=-0.0989+1.0989=1 \end{aligned} \]

ตัวเลขใหญ่ขนาดนี้เพราะ det V = 0.000364 เล็กมาก และทุกช่องต้องหารด้วยมัน 109.89 ไม่ได้แปลว่าเสี่ยง 109 เท่า มันอยู่ในหน่วยผกผันของ variance พันธบัตรที่เงียบกว่าได้ช่องใหญ่ที่สุด เพราะ V⁻¹ ให้น้ำหนักกับสินทรัพย์ที่เงียบมากที่สุด

ถ้า ρ ขยับจาก 0.30 เป็น 0.90 det จะเหลือ 0.0004(1 − 0.81) = 0.000076 ทุกช่องใน V⁻¹ พองขึ้น 4.8 เท่าทันที นี่คือตัวขยายข้อผิดพลาดที่พูดถึงท้ายหัวข้อ

ขั้นที่ 4 — คูณ $V^{-1}$ กับสอง vector ก่อน

ตัวเลขสรุปในขั้นถัดไปทั้งหมดสร้างจากผลคูณสองอันนี้เท่านั้น คูณให้เสร็จก่อนจะได้ไม่ต้องคูณซ้ำ

\[ \begin{aligned} V^{-1}\mathbf1&=\begin{bmatrix}27.4725-16.4835\\ -16.4835+109.8901\end{bmatrix}=\begin{bmatrix}10.9890\\ 93.4066\end{bmatrix}\\[4pt] (V^{-1}\mu)_1&=27.4725(0.12)-16.4835(0.06)\\ &=3.2967-0.9890=2.3077\\ (V^{-1}\mu)_2&=-16.4835(0.12)+109.8901(0.06)\\ &=-1.9780+6.5934=4.6154 \end{aligned} \]

แถวบนของ matrix คูณกับ vector ได้ตัวบน แถวล่างได้ตัวล่าง อันแรกคือบวกตามแถวเฉย ๆ เพราะ vector ที่คูณเป็นเลขหนึ่งทั้งคู่

ขั้นที่ 5 — สรุปข้อมูลเป็นสี่ตัวเลข A, B, C, D

เอาผลคูณจากขั้นก่อนมาบวกและคูณต่อ ไม่มีการคูณ matrix ใหม่อีกแล้ว

\[ \begin{aligned} A&=\mathbf1^{\mathsf{T}}V^{-1}\mathbf1=10.9890+93.4066=104.3956\\ B&=\mathbf1^{\mathsf{T}}V^{-1}\mu=2.3077+4.6154=6.9231\\ C&=\mu^{\mathsf{T}}V^{-1}\mu=0.12(2.3077)+0.06(4.6154)\\ &=0.276923+0.276923=0.553846\\ D&=A\,C-B^2=57.8191-47.9290=9.8901 \end{aligned} \]

สามตัวแรกบีบทุกอย่างที่ต้องรู้เกี่ยวกับสองสินทรัพย์ให้เหลือเลขสามตัว และยังเป็นสามตัวเท่าเดิมต่อให้มี 500 สินทรัพย์ A วัดว่าจักรวาลนี้เสี่ยงน้อยแค่ไหน เพราะ 1/A คือ variance ต่ำสุดที่เป็นไปได้ B เชื่อมผลตอบแทนกับความเสี่ยง C วัดว่าผลตอบแทนที่มีซื้อได้ด้วยความเสี่ยงเท่าไร

A กับ C ต้องเป็นบวกเสมอเพราะ V⁻¹ positive definite ส่วน B บวกหรือลบก็ได้ สองพจน์ของ C ออกมาเท่ากันพอดีเป็นความบังเอิญของตัวเลขชุดนี้ ไม่ใช่กฎ

ขั้นที่ 6 — หา ν จากข้อบังคับงบ แล้วได้พอร์ต 50/50

เอา 1ᵀ คูณหน้าคำตอบในขั้นที่ 2 แล้วบังคับให้เท่ากับ 1 ได้ ν ก่อน จากนั้นหักออกจาก expected return ทุกตัว แล้วจึงคูณด้วย $V^{-1}$

\[ \begin{aligned} 1&=\frac{1}{2\gamma}\big(\mathbf1^{\mathsf T}V^{-1}\mu-\nu\,\mathbf1^{\mathsf T}V^{-1}\mathbf1\big)\\ &=\frac{B-\nu A}{2\gamma}\\ \nu&=\frac{B-2\gamma}{A}=\frac{6.9231-4}{104.3956}=0.028\\[4pt] &\mu-\nu\mathbf1\\ &=\begin{bmatrix}0.12-0.028\\ 0.06-0.028\end{bmatrix}=\begin{bmatrix}0.092\\ 0.032\end{bmatrix}\\ &V^{-1}(\mu-\nu\mathbf1)\\ &=\begin{bmatrix}2.5275-0.5275\\ -1.5165+3.5165\end{bmatrix}=\begin{bmatrix}2\\ 2\end{bmatrix}\\ x&=\frac{1}{4}\begin{bmatrix}2\\ 2\end{bmatrix}=\begin{bmatrix}0.50\\ 0.50\end{bmatrix} \end{aligned} \]

ν เป็นแค่ค่าที่ทำให้งบพอดี ไม่ได้เลือกเอง 2γ = 4 มาจากพจน์ 2γVx ตรง ๆ ตัวคูณงบ 2.80% คือส่วนที่ต้องหักออกก่อน เหลือ 9.2% กับ 3.2% พอคูณ V⁻¹ เข้าไปได้ 2 เท่ากันพอดี หารด้วย 4 จึงได้ครึ่งต่อครึ่ง

ตรวจผลรวมทุกครั้ง 0.5 + 0.5 = 1 เพราะข้อบังคับนี้เป็นสิ่งเดียวที่ ν ถูกสร้างมาเพื่อบังคับ ถ้าผลรวมไม่ได้ 1 แปลว่าคำนวณ ν ผิด ไม่ใช่คำนวณ x ผิด ทั้งคู่บวกจึงไม่มีการชอร์ตเกิดขึ้นเอง และ 50/50 เป๊ะเป็นเรื่องของตัวเลขชุดนี้กับ γ = 2 พอดี

ขั้นที่ 7 — ตรวจ return risk และ objective แล้วเทียบกับถือตัวเดียว

ตรวจว่าคำตอบที่ได้ให้ผลตอบแทนและความเสี่ยงเท่าไรจริง ๆ ก่อนจะเชื่อมัน variance ต้องกางเต็มสูตร ห้ามเฉลี่ยเอา

\[ \begin{aligned} \mu_p&=0.5(0.12)+0.5(0.06)=0.09=9.00\%\\ \sigma_p^2&=0.25(0.04)+0.25(0.01)+2(0.25)(0.006)\\ &=0.0100+0.0025+0.0030=0.0155\\ \sigma_p&=\sqrt{0.0155}=12.45\%\\ J&=0.09-2(0.0155)=0.0590\\[4pt] J_{\text{stock}}&=0.12-2(0.04)=0.0400\\ J_{\text{bond}}&=0.06-2(0.01)=0.0400 \end{aligned} \]

ผสม 50/50 ได้ 0.0590 ชนะถือตัวเดียวทั้งสองแบบที่ได้ 0.0400 เท่ากันพอดี ถ้าสองตัวไม่สัมพันธ์กันเลย พจน์ไขว้เป็นศูนย์ σ² เหลือ 0.0125 หรือ 11.18% แต่ ρ = 0.30 ดันขึ้นเป็น 0.0155 ซึ่งยังต่ำกว่าค่าเฉลี่ยของ 0.04 กับ 0.01 ที่ 0.025 อยู่มาก

ผลตอบแทนเฉลี่ยแบบเส้นตรง แต่ความเสี่ยงไม่ได้เฉลี่ยแบบเส้นตรง ช่องว่างระหว่างสองอย่างนี้คือทั้งหมดที่ Markowitz ค้นพบ

ขั้นที่ 8 — ν = 2.80% คือราคาเงาของงบ และเกณฑ์ผลตอบแทน

ทดสอบตรง ๆ ว่า ν แปลว่าอะไร แก้ปัญหาใหม่ด้วยงบ 101% แล้วดูว่าค่าเป้าหมายขยับเท่าไร

\[ \begin{aligned} \nu(1.01)&=\frac{B-2\gamma(1.01)}{A}=\frac{6.9231-4.04}{104.3956}=0.027617\\ x&=(0.50105,\ 0.50895),\qquad x_1+x_2=1.01\\ J(1.01)&=0.059278\\ \frac{J(1.01)-J(1)}{0.01}&=\frac{0.000278}{0.01}=0.0278\approx\nu\\[4pt] \mu_1-\nu&=0.12-0.028=0.092\\ \mu_2-\nu&=0.06-0.028=0.032 \end{aligned} \]

เพิ่มงบ 1% ค่าเป้าหมายขยับขึ้นราว 0.000278 อัตรา 0.0278 ใกล้ ν แต่ไม่เท่าเป๊ะ เพราะ ν เองก็ขยับเมื่องบเปลี่ยน จาก 0.0280 เป็น 0.0276 เหมือนราคาเงาในหัวข้อ 8.4

อีกมุมหนึ่ง ν คือเกณฑ์ผลตอบแทน หุ้นเกินเกณฑ์ 9.2 จุด พันธบัตรเกิน 3.2 จุด สินทรัพย์ที่ผลตอบแทนคาดหวังต่ำกว่า ν จะถูกสูตรสั่งชอร์ตทันที γ คือสิ่งที่คุณเลือกเอง ส่วน ν คือสิ่งที่ตลาดกับข้อจำกัดตอบกลับมา คุณเลือก ν ไม่ได้

ขั้นที่ 9 — หมุน γ แล้วพอร์ตไต่ไปตาม frontier

γ เข้าไปแตะสูตรที่ ν ที่เดียว แทน A กับ B ได้ ν เป็นเส้นตรงของ γ แล้วเดินขั้นที่ 6 ซ้ำที่ γ = 1 และ γ = 4

\[ \begin{aligned} \nu(\gamma)&=\frac{6.9231-2\gamma}{104.3956}=0.066316-0.019158\,\gamma\\ \nu&=0\ \ \text{at}\ \ \gamma=3.4615\\[4pt] \gamma=1:&\quad \nu=0.047158,\quad x=(0.8947,\ 0.1053)\\ &\quad \mu_p=11.37\%,\quad \sigma_p=18.24\%\\ \gamma=2:&\quad \nu=0.028,\quad x=(0.50,\ 0.50)\\ &\quad \mu_p=9.00\%,\quad \sigma_p=12.45\%\\ \gamma=4:&\quad \nu=-0.010316,\quad x=(0.3026,\ 0.6974)\\ &\quad \mu_p=7.82\%,\quad \sigma_p=10.52\% \end{aligned} \]

ตรวจทิศก่อนเชื่อตัวเลข γ โตขึ้นแปลว่ากลัวมากขึ้น น้ำหนักหุ้นต้องลด 89.5% → 50.0% → 30.3% และความผันผวนต้องลด 18.24% → 12.45% → 10.52% เดินถูกทางทั้งสองแถว ถ้าเลขเดินสวนทางแปลว่าใส่เครื่องหมายของ ν ผิด ซึ่งพลาดบ่อยที่สุดตอนหัก ν ที่ติดลบ

ν ติดลบได้เพราะข้อบังคับเป็นสมการ ไม่ใช่อสมการ ราคาเงาของสมการเป็นลบได้เสมอ ต่างจากหัวข้อ 8.6 ที่บังคับให้ไม่ติดลบ ν ติดลบแปลว่าถ้าถูกบังคับให้ลงเงินเพิ่ม ค่าเป้าหมายจะแย่ลง ซึ่งสมเหตุสมผลสำหรับคนที่กลัวจัด เขาอยากถือเงินสด

ขั้นที่ 10 — γ ไปถึงอนันต์คือ Global Minimum Variance (GMV) และไม่ต้องใช้ μ เลย

หาร objective ด้วย γ แล้วปล่อยให้ γ โตไม่หยุด พจน์ผลตอบแทนหายไป เหลือแค่ลด variance ภายใต้งบ แก้ด้วย Lagrangian ข้อบังคับเดียว

\[ \begin{aligned} \tfrac{J}{\gamma}&=\tfrac1\gamma\mu^{\mathsf T}x-x^{\mathsf T}Vx\\ &\to-x^{\mathsf T}Vx\\[4pt] 0&=2Vx-\lambda\mathbf{1}\\ x&=\tfrac{\lambda}{2}V^{-1}\mathbf{1}\\ 1&=\mathbf{1}^{\mathsf T}x=\tfrac{\lambda}{2}A\\[4pt] x_{\mathrm{GMV}}&=\frac{V^{-1}\mathbf{1}}{A}=\frac{(10.9890,\ 93.4066)}{104.3956}\\ &=(0.1053,\ 0.8947)\\ \sigma_{\min}^2&=\frac{1}{A}=\frac{1}{104.3956}=0.009579\\ \sigma_{\min}&=9.79\%\\ \mu_{\mathrm{GMV}}&=\frac{B}{A}=6.63\%\\[4pt] \sigma^2(w)&=0.04w^2+0.01(1-w)^2\\ &\quad+2(0.006)w(1-w)\\ \sigma^{2\prime}(0)&=2(0.006)-2(0.01)=-0.008\lt0 \end{aligned} \]

ผลรวมน้ำหนักเป็น 1 ไม่ใช่เรื่องบังเอิญ เพราะ 1ᵀV⁻¹1/A = A/A ตัวส่วน A ถูกใส่มาเพื่อบังคับข้อนี้พอดี λ ที่นี่เป็นตัวคูณงบของโจทย์ลด variance ล้วน ไม่ใช่ γ พอร์ตนี้สำคัญกว่าที่คิดเพราะเป็นพอร์ตเดียวบนเส้นที่ไม่ต้องรู้ μ เลย และ μ คือสิ่งที่ประมาณยากที่สุดในการเงิน

ก้อนล่างอธิบายว่าทำไม 9.79% ต่ำกว่าพันธบัตรล้วนที่ 10% w คือน้ำหนักหุ้น เริ่มจากพันธบัตรล้วนที่ w = 0 แล้วใส่หุ้นเข้าไปนิดเดียว ความชันของ variance ที่จุดนั้นติดลบ ความเสี่ยงจึงลดลง เงื่อนไขคือ ρσ₁σ₂ ต่ำกว่า σ₂² หรือ ρ ต่ำกว่า σ₂/σ₁ = 0.5 ตามขั้นที่ 13 ของหัวข้อ 8.2

ของฟรีนี้มีเงื่อนไข และมักหายไปพอดีตอนวิกฤตที่ ρ พุ่งเข้าหา 1

ขั้นที่ 11 — เขียน efficient frontier ทั้งเส้น แล้วตรวจ 2 จุดที่รู้คำตอบ

แทนที่จะไล่ γ ทีละค่า เขียนเป็นสมการเดียว ถ้าอยากได้ผลตอบแทน m พอดี variance ต่ำสุดที่ทำได้คือเท่าไร มีข้อบังคับสองข้อจึงมีตัวคูณสองตัว

\[ \begin{aligned} x&=V^{-1}\big(\alpha\mathbf1+\beta\mu\big)\\ 1&=\mathbf1^{\mathsf{T}}x=A\alpha+B\beta\\ m&=\mu^{\mathsf{T}}x=B\alpha+C\beta\\ \alpha&=\frac{C-Bm}{D}\\ \beta&=\frac{Am-B}{D}\\[4pt] \sigma^{2}(m)&=x^{\mathsf{T}}\big(\alpha\mathbf1+\beta\mu\big)=\alpha+\beta m\\ &=\frac{Am^{2}-2Bm+C}{D}\\[4pt] \sigma^2(0.09)&=\frac{0.153296}{9.8901}=0.0155\\ \sigma^2(B/A)&=\frac{0.094741}{9.8901}=0.009579 \end{aligned} \]

แทนรูปของคำตอบลงในข้อบังคับทีละข้อ ได้สมการเชิงเส้นสองสมการ แก้ด้วยกฎกลับ 2×2 ของหัวข้อ 4.5 จากนั้นใช้ทางลัด Vx คือ α1 + βμ พอดี คูณ xᵀ เข้าไปจึงได้ α คูณผลรวมน้ำหนักบวก β คูณผลตอบแทน ซึ่งข้อบังคับกำหนดไว้แล้วทั้งคู่ ห้ามหารเมื่อ D เป็นศูนย์

ตรวจ 2 จุด ที่ m = 9% ตัวเศษคือ 0.845604 − 1.246154 + 0.553846 = 0.153296 ได้ 0.0155 ตรงกับขั้นที่ 7

ที่ m = B/A ตัวเศษคือ 0.459104 − 0.918209 + 0.553846 = 0.094741 ได้ 1/A ตรงกับขั้นที่ 10

โจทย์ Markowitz เขียนได้สามแบบที่ให้ frontier เส้นเดียวกัน ลด variance ที่ผลตอบแทนเป้าหมาย m แบบขั้นนี้ เพิ่มผลตอบแทนภายใต้งบความเสี่ยงที่ตั้งไว้ และเพิ่มผลตอบแทนหักค่าปรับ γσ² แบบขั้นที่ 2 ต่างกันแค่ว่าตรึงอะไรไว้ แต่ละ γ ตรงกับ m หนึ่งค่าบนเส้น

m โผล่กำลังสองในตัวเศษ เส้นจึงเป็นพาราโบลาที่ต่ำสุดที่ B/A ครึ่งบนคือ efficient frontier ครึ่งล่างไม่มีใครเลือกเพราะ σ เท่ากันแต่ผลตอบแทนต่ำกว่า ทั้งเส้นใช้แค่สี่ตัวเลข

ขั้นที่ 12 — ทฤษฎีบทการแยกสองกองทุน (Two-Fund Separation Theorem)

บรรทัดเหล่านี้เป็นรากฐานของอุตสาหกรรมกองทุนรวม โดยพิสูจน์ว่าเส้น efficient frontier ทั้งเส้นสามารถสังเคราะห์ขึ้นมาจากพอร์ตอ้างอิงเพียงสองพอร์ต ทำให้นักลงทุนสามารถกระจายความเสี่ยงข้ามระดับผลตอบแทนได้อย่างมีระบบ

\[ \begin{aligned} \mathbf{1}^{\mathsf T}x^{(k)}&=1,\qquad \mu^{\mathsf T}x^{(k)}=r_k\\ \alpha&=\frac{r-r_1}{r_2-r_1}\\ y&=(1-\alpha)x^{(1)}+\alpha x^{(2)}\\ \mathbf{1}^{\mathsf T}y&=(1-\alpha)+\alpha=1\\ \mu^{\mathsf T}y&=(1-\alpha)r_1+\alpha r_2=r\\ v&=(1-\alpha)v_1+\alpha v_2\\ u&=(1-\alpha)u_1+\alpha u_2\\ 0&=(1-\alpha)\big(2Vx^{(1)}-v_1\mu-u_1\mathbf{1}\big)\\ &\quad+\alpha\big(2Vx^{(2)}-v_2\mu-u_2\mathbf{1}\big)\\ &=2Vy-v\mu-u\mathbf{1} \end{aligned} \]

ทฤษฎีบทการแยกสองกองทุนพิสูจน์ว่า หากเรามีพอร์ตที่มีประสิทธิภาพสองพอร์ตใด ๆ บนเส้นขอบที่มีผลตอบแทนต่างกัน เราจะสามารถสร้างพอร์ตที่เหมาะสมที่สุดสำหรับทุกระดับผลตอบแทนเป้าหมาย r ได้จากการผสมเชิงเส้นของสองพอร์ตนี้เสมอ

k คือพอร์ต 1 หรือ 2 ผลรวมน้ำหนักของ y ยังเป็นหนึ่ง และผลตอบแทนวิ่งตรงไปที่เป้าหมาย r ตามสัดส่วน α บรรทัดสุดท้ายยืนยันว่าเงื่อนไขความชันเป็นศูนย์ของสองพอร์ตผสมกันแล้วยังเป็นศูนย์ ตัวคูณ v, u คือตัวคูณของสองข้อบังคับในแต่ละพอร์ต

ขั้นที่ 13 — Tangency portfolio เมื่อมี cash rate 2%

คราวนี้หัก cash rate ออกจาก expected return ก่อน แล้วคูณด้วย $V^{-1}$ จากนั้นหารด้วยผลรวมของตัวเอง เพื่อบังคับให้น้ำหนักรวมเป็นหนึ่ง

\[ \begin{aligned} \mu-r_f\mathbf1&=\begin{bmatrix}0.12-0.02\\ 0.06-0.02\end{bmatrix}=\begin{bmatrix}0.10\\ 0.04\end{bmatrix}\\ V^{-1}(\mu-r_f\mathbf1)&=\begin{bmatrix}2.7473-0.6593\\ -1.6484+4.3956\end{bmatrix}=\begin{bmatrix}2.0879\\ 2.7473\end{bmatrix}\\ \text{sum}&=4.8352\\ x_T&=\frac{1}{4.8352}\begin{bmatrix}2.0879\\ 2.7473\end{bmatrix}=\begin{bmatrix}0.4318\\ 0.5682\end{bmatrix} \end{aligned} \]

หัก annual risk-free rate 2% ออกก่อน เพราะ tangency สนใจผลตอบแทนส่วนเกินเท่านั้น การหารด้วยผลรวมคือขั้นที่บังคับให้ risky weights รวมกันได้หนึ่ง สูตรนี้ไม่มี γ เลย เพราะพอร์ตเสี่ยงที่ดีที่สุดไม่ขึ้นกับว่าคุณกลัวแค่ไหน

นี่คือใจความของ two-fund theorem เมื่อมีเงินสด ทุกคนถือพอร์ตเสี่ยงหน้าตาเดียวกัน ต่างกันแค่สัดส่วนที่ผสมกับเงินสด คนกลัวมากถือ tangency 30% กับเงินสด 70% คนกล้าถือ tangency 130% โดยกู้ 30% ส่วนผสมภายในยังเป็น 43.2/56.8 เหมือนกันหมด

ขั้นที่ 14 — Sharpe ratio: tangency ชนะทุกพอร์ต

มีน้ำหนักแล้วจึงคิดผลตอบแทนและความเสี่ยงของพอร์ตนี้ แล้วเทียบ Sharpe กับทุกพอร์ตที่หามาในหัวข้อนี้

คำตอบที่ได้คือ Sharpe ratio 0.5645 สูงกว่าหุ้นล้วนที่ได้ 0.50 และพันธบัตรล้วนที่ได้ 0.40 ส่วนที่เพิ่มขึ้นมาจากการกระจายความเสี่ยง ไม่ได้มาจากการทายทิศทางเก่งขึ้น

\[ \begin{aligned} \mu_T&=0.4318(0.12)+0.5682(0.06)=0.085909\\ \sigma_T^2&=0.4318^2(0.04)+0.5682^2(0.01)+2(0.4318)(0.5682)(0.006)\\ &=0.007459+0.003229+0.002944=0.013631\\ \sigma_T&=\sqrt{0.013631}=0.116753\\ \mathrm{SR}_T&=\frac{0.085909-0.02}{0.116753}=0.5645\\[4pt] \mathrm{SR}_{\max}^2&=C-2r_fB+r_f^2A\\ &=0.553846-0.276923+0.041758=0.318681\\ \mathrm{SR}_{\max}&=\sqrt{0.318681}=0.5645 \end{aligned} \]

บรรทัด variance ใช้สูตรพอร์ตสองตัวปกติ Sharpe คือผลตอบแทนส่วนเกินหารด้วย standard deviation สูตรปิดท้ายตรวจโดยไม่ผ่านน้ำหนักเลย ได้ 0.5645 ตรงกัน ไม่มีพอร์ตไหนจากสองสินทรัพย์นี้ทำ Sharpe เกินค่านี้ได้

การผสมสินทรัพย์ให้สมดุลระหว่างผลตอบแทนกับความเสี่ยง เป็นโจทย์ตั้งต้นของการจัดการลงทุนทั้งอุตสาหกรรม

กองทุนกล้าเสี่ยง สมดุล และระมัดระวัง ที่นักวางแผนการเงินขาย ก็คือ γ = 1, 2, 4 ที่ตั้งชื่อใหม่ และ two-fund theorem บอกว่าจริง ๆ ไม่ต้องมีสามกอง มีกองเดียวคือ tangency แล้วผสมเงินสดตามระดับความกลัวก็พอ

ใช้หาพอร์ตที่ให้ผลตอบแทนต่อความเสี่ยงสูงสุด ซึ่งเป็นจุดตั้งต้นของทฤษฎีการตั้งราคาสินทรัพย์ในบทที่ 15

คำตอบ — 50/50 ที่ γ = 2 และสามพอร์ตจากสูตรเดียว

คำถาม: ควรถือหุ้นกี่เปอร์เซ็นต์ และพอร์ตไหนให้ผลตอบแทนต่อความเสี่ยงดีที่สุด?

ของที่มี: ขั้นที่ 1 ถึง 14

1. V⁻¹ มีช่อง 27.4725, −16.4835, 109.8901 จาก det V = 0.000364 และ A = 104.3956, B = 6.9231, C = 0.553846

2 ที่ γ = 2 ได้ ν = 2.80% และหุ้น 50% พันธบัตร 50% ผลตอบแทน 9.00% ความผันผวน 12.45% ค่าเป้าหมาย 0.0590 ชนะถือตัวเดียวที่ 0.0400 สำหรับพอร์ต \$100 ล้านคือกองละ 50 ล้าน

3. GMV คือหุ้น 10.5% เสี่ยง 9.79% ต่ำกว่าพันธบัตรล้วน ส่วน tangency คือหุ้น 43.2% Sharpe 0.5645 สูงสุดที่สองสินทรัพย์นี้ให้ได้

ตรวจเองใน 10 วินาที: 0.5 × 12% + 0.5 × 6% = 9% และ (6.9231 − 4)/104.3956 = 0.028

แปลว่าอะไร: สูตรนี้คือ mandate ของกองทุนผสมในบรรทัดเดียว แต่คำตอบ 50/50 ไม่มั่นคงอย่างที่เห็น ผลตอบแทนคาดหวังของหุ้น 12% มี standard error สูงมาก ขยับเป็น 13% ซึ่งอยู่ในระดับ noise น้ำหนักหุ้นกระโดดเป็น 56.6% ทุกโต๊ะจึงใส่ขอบเขตน้ำหนักหรือหด V ก่อนเสมอ 50/50 ควรอ่านว่าจุดตั้งต้นของการถกเถียง ไม่ใช่คำสั่งซื้อขาย

โค้ดตรวจสูตรปิดของ Markowitz 
import numpy as np
V=np.array([[.04,.006],[.006,.01]]); mu=np.array([.12,.06]); one=np.ones(2)
Vi=np.linalg.inv(V); assert np.allclose(V@Vi,np.eye(2))
A,B,C=one@Vi@one,one@Vi@mu,mu@Vi@mu; D=A*C-B*B
assert np.allclose([A,B,C,D],[104.3956,6.92308,0.553846,9.89011],atol=1e-4)
def port(g,b=1.0):
    v=(B-2*g*b)/A; x=Vi@(mu-v*one)/(2*g); return v,x,mu@x-g*x@V@x
v,x,J=port(2); assert abs(v-0.028)<1e-12 and np.allclose(x,[.5,.5]) and abs(J-0.059)<1e-12
assert abs((port(2,1.01)[2]-J)/0.01-0.0278)<1e-4
assert np.allclose(port(1)[1],[0.894737,0.105263],atol=1e-6) and np.allclose(port(4)[1],[0.302632,0.697368],atol=1e-6)
assert np.allclose(Vi@one/A,[0.105263,0.894737],atol=1e-6) and abs(np.sqrt(1/A)-0.097872)<1e-6
z=Vi@(mu-.02*one); xt=z/z.sum(); assert np.allclose(xt,[0.431818,0.568182],atol=1e-6)
assert abs(np.sqrt(C-2*.02*B+.02**2*A)-0.564519)<1e-6
mu2=np.array([.13,.06]); B2=one@Vi@mu2; x2=Vi@(mu2-(B2-4)/A*one)/4
assert abs(x2[0]-0.565789)<1e-6

โค้ดนี้ตรวจ V⁻¹ ตัวเลข A, B, C, D พอร์ต 50/50 ที่ γ = 2 ราคาเงาจากงบ 101% พอร์ตที่ γ = 1 และ 4 พอร์ต GMV ที่ 9.79% tangency 43.2/56.8 Sharpe สูงสุด 0.5645 และตัวขยายข้อผิดพลาด 12% → 13% ที่ทำให้น้ำหนักหุ้นเป็น 56.6%

กับดัก: รายงานทศนิยมเยอะแล้วดูแม่น

matrix inverse ขยาย estimation error โดยเฉพาะเมื่อสินทรัพย์คล้ายกันมาก เปลี่ยน μ 0.5% น้ำหนักอาจพลิกจาก +200% เป็น −150% เมื่อมี 500 หุ้นแต่ข้อมูลรายวันแค่ราวหนึ่งปี หรือ 250 วันเทรด V กลับด้านไม่ได้เลย ควรใช้ covariance shrinkage ของหัวข้อ 17.8, robust expected returns, weight bounds และ out-of-sample tests หรือทิ้ง μ ไปใช้พอร์ต GMV หรือ risk parity ซึ่งมักชนะนอกกลุ่มตัวอย่าง

อย่าสับสน covariance 0.006 กับ correlation 0.30 ถ้าเผลอใส่ 0.30 ลงในช่องนอกทแยงของ V จะได้ det V = 0.04(0.01) − 0.09 = −0.0896 ติดลบ matrix นี้ไม่ใช่ covariance ที่ถูกต้อง และสูตรจะให้พอร์ตที่ variance ติดลบ เห็น det V ติดลบเมื่อไรให้หยุดแล้วกลับไปขั้นที่ 1

Sharpe ของ GMV (0.4732) ต่ำกว่าหุ้นล้วน (0.5000) ความเสี่ยงต่ำสุดกับความคุ้มค่าสูงสุดเป็นคนละพอร์ตเสมอ ถ้าคณะกรรมการสั่งทั้งสองอย่าง นั่นคือสองคำสั่งที่ขัดกัน ต้องถามกลับให้ชัด

ข้อจำกัด: วิธีนี้สมมติอะไร และของจริงเป็นอย่างไร

เรื่องวิธีนี้สมมติว่าของจริงเป็นอย่างไรผลที่ตามมาเวลาใช้งาน
ความไวต่อ inputตัวเลขที่ใส่แม่นพอผลตอบแทนคาดหวังประมาณยากที่สุดในบรรดา input ทั้งหมดเปลี่ยน input นิดเดียว น้ำหนักที่ได้เปลี่ยนไปคนละเรื่อง และมักสุดโต่งจนใช้ไม่ได้
การขายยืมขายยืมได้ไม่จำกัดกองทุนส่วนใหญ่ห้ามขายยืมคำตอบที่ได้มักติดลบหนัก ซึ่งต้องแก้ด้วยข้อจำกัดในหัวข้อ 8.6
การวัดความเสี่ยงความผันผวนเป็นตัววัดความเสี่ยงที่ดีคนกลัวขาดทุน ไม่ได้กลัวความผันผวนพอร์ตที่ดีที่สุดตามสูตรอาจมีความเสี่ยงขาลงสูงกว่าที่ยอมรับได้
ความคงที่μ, σ, ρ คงที่ต้องประมาณใหม่และเปลี่ยนตลอดefficient frontier ที่เห็นคือของเมื่อวาน ไม่ใช่ของพรุ่งนี้
