8.5 The Moment Generating Function (MGF)

MGF คือค่าเฉลี่ยของ $e^{tX}$ ซึ่งเก็บทุก moment ไว้ในฟังก์ชันเดียว และค่าของมันที่ $t=1$ คือราคาคาดหมายเมื่อ $X$ เป็น log return

หุ้นสมมติราคา \$100 ไม่จ่ายเงินปันผล log return หนึ่งปี $R$ เป็น Normal ค่าเฉลี่ย 0.09 และ SD 0.22 นักวิเคราะห์สามคนตอบราคาคาดหมายปลายปีไม่ตรงกัน คนแรกตอบ \$109 คนที่สองตอบ $100e^{0.09}\approx\$109.42$ คนที่สามตอบ \$112.10 ใครถูก และอีกสองคนพลาดตรงไหน

ลองตอบก่อนเปิดเฉลย

คนที่สามถูก ราคาคาดหมายคือ $100\,\mathbb E[e^R]=100\,e^{0.09+0.22^2/2}\approx\$112.10$ คนแรกเอา 9% ซึ่งเป็นค่าเฉลี่ยของ log return ไปใช้เหมือน simple return คนที่สองเอาค่าเฉลี่ยใส่ใน exponential ก่อนเฉลี่ย ได้ \$109.42 ซึ่งคือ median ของราคา ไม่ใช่ค่าเฉลี่ย เพราะ exponential โค้งขึ้น ค่าเฉลี่ยของ $e^R$ จึงสูงกว่า $e$ ยกกำลังค่าเฉลี่ย เครื่องมือที่ให้ $\mathbb E[e^{tR}]$ ออกมาเป็นสูตรคือ MGF ซึ่งหน้านี้จะสร้างให้

ภาพรวมก่อนลงสูตร

MGF ของตัวแปรสุ่ม $X$ คือ $M_X(t)=\mathbb E[e^{tX}]$ เป็นฟังก์ชันของตัวเลข $t$ ที่เราเลือกป้อน ไม่ใช่ density และ $t$ ไม่ใช่เวลา มันมีประโยชน์สองแบบ แบบแรกคือเก็บ moments ทั้งหมดไว้: ความชันที่ $t=0$ คือค่าเฉลี่ย และความโค้งที่ $t=0$ คือ moment ที่สอง แบบที่สองคือค่าที่ $t$ อื่นเป็นคำตอบทางการเงินโดยตรง ถ้า $X$ เป็น log return แล้ว $M_X(1)=\mathbb E[e^X]$ คือราคาเฉลี่ยหารด้วยราคาเริ่ม

สำหรับ Normal เราได้ MGF ในรูปปิด $e^{\mu t+\sigma^2t^2/2}$ และสำหรับ multivariate Normal ได้ $e^{s^{\mathsf T}\mu+\frac12s^{\mathsf T}\Sigma s}$ สองสูตรนี้คือที่มาของ “บวกครึ่ง variance” ทุกครั้งที่แปลง log return เป็นราคาคาดหมาย และคือเหตุผลที่ drift $\mu$ ของ geometric Brownian motion เป็นอัตราโตของราคาคาดหมาย

หน้านี้เริ่มจากบัตรสามใบที่คำนวณด้วยมือได้ ดูว่า derivative ดึง moments ออกมาอย่างไร พิสูจน์ Normal MGF ด้วยการจัดกำลังสองสมบูรณ์ ใช้มันตอบคำถามเปิดและหาราคาคาดหมายของ GBM แล้วขยายไปผลรวมของตัวแปรอิสระ หลายตัวแปร และกรณีที่ MGF ไม่มีค่า

ศัพท์ที่ใช้ในหัวข้อนี้
Raw moment
$\mathbb E[X^k]$ วัดรอบศูนย์ ต่างจาก central moment $\mathbb E[(X-\mathbb E[X])^k]$ ที่วัดรอบค่าเฉลี่ย variance คือ central moment ที่สอง
Moment generating function (MGF)
$M_X(t)=\mathbb E[e^{tX}]$ ใช้ดึง moments ด้วยการ differentiate ที่ศูนย์ ใช้ระบุ distribution ของผลรวม และใช้หาค่าเฉลี่ยของ exponential เช่นราคาจาก log return
Cumulant generating function (CGF)
$K_X(t)=\ln M_X(t)$ derivative แรกที่ศูนย์คือค่าเฉลี่ย derivative ที่สองคือ variance โดยตรง และ CGF ของผลรวมอิสระคือผลบวก
Lognormal
ตัวแปรที่ log ของมันเป็น Normal เช่นราคาปลายงวด $S_T=S_0e^R$ เมื่อ $R$ เป็น Normal (lognormal distribution)
Geometric Brownian motion (GBM)
แบบจำลองราคาที่ log return ทุกช่วงเวลาเป็น Normal และอิสระกัน มี drift $\mu$ และ volatility $\sigma$ ใช้เป็นฐานของแบบจำลอง Black–Scholes
Characteristic function
$\mathbb E[e^{iuX}]$ ใช้ exponent เป็นจำนวนจินตภาพ จึงมีค่าเสมอ ใช้แทน MGF เมื่อ MGF ไม่มีค่า

สัญลักษณ์ความหมายหน่วย

ขั้นที่ 1 — สร้าง MGF ของบัตร 1, 2, 3 แล้ว differentiate

เริ่มจากตัวอย่างที่เห็นทุกพจน์: สุ่มบัตรหนึ่งใบจากสามใบที่เขียน 1, 2, 3 ด้วยโอกาสเท่ากัน $1/3$ ค่าเฉลี่ยของ $e^{tX}$ ก็คือผลรวมของ $e^{tx}$ ของแต่ละค่า $x$ คูณโอกาสของค่านั้น

\[ \begin{aligned} M_X(t)&=\tfrac13e^{t}+\tfrac13e^{2t}+\tfrac13e^{3t},\\ M_X(0)&=1,\\ M_X'(t)&=\tfrac13e^{t}+\tfrac23e^{2t}+e^{3t},\\ M_X'(0)&=\tfrac{1+2+3}3=2,\\ M_X''(0)&=\tfrac{1^2+2^2+3^2}3=\tfrac{14}3,\\ \operatorname{Var}(X)&=\tfrac{14}3-2^2=\tfrac23. \end{aligned} \]

ทุกครั้งที่ differentiate $e^{kt}$ จะได้ตัวคูณ $k$ ลงมาหนึ่งตัว พอแทน $t=0$ exponential กลายเป็น 1 เหลือแค่ $k$ ถ่วงด้วยโอกาส ครั้งแรกจึงได้ค่าเฉลี่ย ครั้งที่สองได้ $\mathbb E[X^2]$ ซึ่งเป็น raw moment ไม่ใช่ variance ต้องหักกำลังสองของค่าเฉลี่ยออกก่อน (variance คือ $\mathbb E[X^2]-(\mathbb E[X])^2$) ตรวจตรง: ค่าเบี่ยงจากค่าเฉลี่ย 2 คือ $-1,0,1$ ยกกำลังสองเฉลี่ยได้ $2/3$ ตรงกัน

ขั้นที่ 2 — ทำไม derivative ที่ศูนย์ให้ทุก moment

เขียน $e^{tX}$ เป็น Taylor series แล้วเอาค่าเฉลี่ยทีละพจน์ ค่าเฉลี่ยของพจน์ที่ $k$ คือ $t^k\mathbb E[X^k]/k!$ MGF จึงเป็นอนุกรมกำลังของ $t$ ที่มี moments เป็นสัมประสิทธิ์

\[ \begin{aligned} e^{tX}&=\sum_{k=0}^{\infty}\frac{t^kX^k}{k!},\\ M_X(t)&=\sum_{k=0}^{\infty}\frac{t^k\,\mathbb E[X^k]}{k!},\\ M_X^{(k)}(0)&=\mathbb E[X^k],\\ \operatorname{Var}(X)&=M_X''(0)-[M_X'(0)]^2. \end{aligned} \]

บรรทัดที่สามมาจากการเทียบสัมประสิทธิ์: differentiate อนุกรมกำลัง $k$ ครั้งแล้วแทน $t=0$ เหลือแค่พจน์ที่ $k$ คูณ $k!$ ตัวที่ทำให้ขั้นนี้ถูกต้องคือการสลับค่าเฉลี่ยกับผลรวมอนันต์ ซึ่งทำได้เมื่อ $M_X(t)$ มีค่าจำกัดบนช่วงรอบศูนย์ เงื่อนไขนี้แรงกว่าการมีค่าเฉลี่ยและ variance เพราะบังคับให้หางบางพอที่ exponential จะไม่ระเบิด

ทำไมเงื่อนไข “มีค่าจำกัดรอบศูนย์” ทำให้สลับได้

ถ้า $M_X(a)$ และ $M_X(-a)$ มีค่าจำกัดสำหรับ $a\gt0$ บางค่า เมื่อ $|t|\lt a$ จะได้ตัวครอบที่มีค่าเฉลี่ยจำกัด

\[ \begin{aligned} \sum_{k}\frac{|t|^k|X|^k}{k!}&=e^{|t||X|}\le e^{a|X|},\\ e^{a|X|}&\le e^{aX}+e^{-aX},\\ \mathbb E[e^{a|X|}]&\le M_X(a)+M_X(-a)\lt\infty. \end{aligned} \]

บรรทัดที่สองจริงเพราะ $e^{a|X|}$ เท่ากับหนึ่งในสองพจน์ทางขวาเสมอ เมื่อผลรวมของค่าสัมบูรณ์มีค่าเฉลี่ยจำกัด การสลับค่าเฉลี่ยกับผลรวมอนันต์จึงถูกต้อง

ผลสำคัญอีกข้อคือทฤษฎีเอกลักษณ์: ถ้าสอง distribution มี MGF ที่มีค่าจำกัดและเท่ากันตลอดช่วงรอบศูนย์ ทั้งสองเป็น distribution เดียวกัน การเท่ากันแค่ค่าเฉลี่ยกับ variance หรือแค่ที่ $t$ จุดเดียวไม่พอ ข้อนี้ทำให้เราระบุ distribution ของผลรวมได้ด้วยการดู MGF ซึ่งใช้ในขั้นของผลรวมอิสระด้านล่าง

ขั้นที่ 3 — Normal MGF มาจากการจัดกำลังสองสมบูรณ์

เริ่มจาก standard Normal $Z$ แล้วค่อยเลื่อนและยืดเป็น $X=\mu+\sigma Z$ เอา $e^{tz}$ เข้าไปคูณ density แล้วรวม exponent ให้เป็นกำลังสองสมบูรณ์

\[ \begin{aligned} M_Z(t)&=\int_{-\infty}^{\infty}e^{tz}\frac{e^{-z^2/2}}{\sqrt{2\pi}}\,dz,\\ tz-\tfrac{z^2}2&=-\tfrac12(z-t)^2+\tfrac{t^2}2,\\ M_Z(t)&=e^{t^2/2}\int_{-\infty}^{\infty}\frac{e^{-(z-t)^2/2}}{\sqrt{2\pi}}\,dz\\ &=e^{t^2/2},\\ M_X(t)&=\mathbb E[e^{t\mu+t\sigma Z}]=e^{\mu t}M_Z(\sigma t)\\ &=e^{\mu t+\sigma^2t^2/2}. \end{aligned} \]

บรรทัดที่สองตรวจได้ด้วยการกระจาย $-\frac12(z^2-2tz+t^2)+\frac{t^2}2=tz-\frac{z^2}2$ อินทิกรัลที่เหลือคือ density ของ Normal ที่ค่าเฉลี่ย $t$ ซึ่งมีพื้นที่ 1 การคูณด้วย $e^{tz}$ จึงแค่เลื่อนระฆังไปที่ $t$ และขยายพื้นที่เป็น $e^{t^2/2}$ เท่า ตามรูปด้านล่าง ผลนี้มีค่าจำกัดกับทุก $t$ เพราะ $-z^2/2$ ชนะ $tz$ เสมอเมื่อ $z$ ใหญ่

ขั้นที่ 4 — อยากได้ variance ตรง ๆ ให้ใช้ log ของ MGF

MGF ที่มีค่าจำกัดเป็นบวกเสมอ จึงเอา log ได้ เรียกว่า CGF การ differentiate ของ log จะหักกำลังสองของค่าเฉลี่ยออกให้เองที่ศูนย์

\[ \begin{aligned} K_X(t)&:=\ln M_X(t),\\ K_X'&=M_X'/M_X,\\ K_X''&=\frac{M_X''}{M_X}-\Big(\frac{M_X'}{M_X}\Big)^2,\\ K_X'(0)&=\mathbb E[X],\quad K_X''(0)=\operatorname{Var}(X),\\ \text{Normal}:\ K_X(t)&=\mu t+\tfrac12\sigma^2t^2. \end{aligned} \]

บรรทัดที่สี่ได้จากการแทน $t=0$ และ $M_X(0)=1$ ใน CGF ของ Normal ทุก derivative ตั้งแต่ลำดับที่สามเป็นศูนย์ คือ cumulants ลำดับสูงเป็นศูนย์หมด นั่นไม่ได้แปลว่า raw moments ลำดับสูงเป็นศูนย์ เช่น standard Normal ยังมี $\mathbb E[Z^4]=3$ ตัวอย่าง: P&L หนึ่งวันของ desk เป็น Normal ค่าเฉลี่ย \$75 SD \$300

\[ \begin{aligned} M_X'(t)&=(\mu+\sigma^2t)M_X(t),\\ M_X''(t)&=\big[\sigma^2+(\mu+\sigma^2t)^2\big]M_X(t),\\ M_X'(0)&=75,\\ M_X''(0)&=300^2+75^2=95{,}625,\\ K_X''(0)&=\sigma^2=90{,}000. \end{aligned} \]

$M''(0)$ ได้ 95,625 ดอลลาร์² ซึ่งคือ $\mathbb E[X^2]$ ถ้าอ่านเป็น variance จะได้ SD \$309.2 แทน \$300 ส่วน $K''(0)$ ได้ variance 90,000 ทันที เพราะ P&L มีหน่วยดอลลาร์ $t$ ต้องมีหน่วย 1/ดอลลาร์ ค่าที่น่าสนใจจึงเป็น $t$ เล็ก ๆ อย่าง 0.001

ขั้นที่ 5 — ตอบคำถามเปิด: ราคาคาดหมายคือ MGF ของ log return ที่ $t=1$

โจทย์ให้อะไรมาบ้าง: ราคาเริ่ม \$100 ไม่มีเงินปันผล $S_T=100e^R$ โดย $R$ เป็น Normal ค่าเฉลี่ย 0.09 variance $0.22^2=0.0484$ เรากำลังหาค่าเฉลี่ยตามแบบจำลองนี้ ไม่ใช่ราคายุติธรรมแบบ risk-neutral

\[ \begin{aligned} \mathbb E[S_T]&=100\,\mathbb E[e^{1\cdot R}]=100\,M_R(1)\\ &=100\,e^{0.09+0.0484/2}\\ &=100\,e^{0.1142}\approx112.10,\\ \operatorname{median}(S_T)&=100\,e^{0.09}\approx109.42,\\ \text{mode}(S_T)&=100\,e^{0.09-0.0484}\approx104.25. \end{aligned} \]

คำตอบ: ราคาคาดหมาย \$112.10 หรือ simple return คาดหมาย 12.10% ส่วน \$109.42 คือ median เพราะ $R$ มี median 0.09 และ exponential เป็นฟังก์ชันเพิ่ม ครึ่งหนึ่งของเส้นทางราคาจะจบต่ำกว่า \$109.42 ส่วน \$109 มาจากการเอา log return 9% ไปใช้เป็น simple return ซึ่งผิดชนิดตัวแปร

ตรวจเองใน 10 วินาที: ส่วนเพิ่มใน exponent คือ $\sigma^2/2=0.0242$ ไม่ใช่ส่วนต่างของราคาโดยตรง ช่องว่าง mean–median จริงคือ $112.10-109.42=\$2.68$ ถ้า SD เป็นศูนย์ ทั้งสามค่าจะเท่ากันที่ \$109.42

Jensen’s inequality บอกแค่ว่า $\mathbb E[e^R]\ge e^{\mathbb E[R]}$ เพราะ exponential โค้งขึ้น แต่ไม่ได้บอกว่ามากกว่าเท่าไร สูตร “บวกครึ่ง variance” มาจาก Normal MGF โดยเฉพาะ ถ้า $R$ ไม่ใช่ Normal ต้องใช้ MGF ของ distribution นั้นจริง

ขั้นที่ 6 — drift ของ GBM คืออัตราโตของราคาคาดหมาย

ใน geometric Brownian motion ราคาเขียนเป็น $S_t=S_0e^{(\mu-\sigma^2/2)t+\sigma W_t}$ โดย $W$ เป็น standard Brownian motion ส่วนเพิ่ม $W_{t+s}-W_t$ เป็น Normal ค่าเฉลี่ยศูนย์ variance $s$ และอิสระจากข้อมูลจนถึงเวลา $t$ ถามว่าราคาคาดหมายอีก $s$ ปีข้างหน้าคือเท่าไร เมื่อรู้ราคาวันนี้

\[ \begin{aligned} S_{t+s}&=S_t\,e^{(\mu-\sigma^2/2)s+\sigma(W_{t+s}-W_t)},\\ \mathbb E_t[S_{t+s}]&=S_t\,e^{(\mu-\sigma^2/2)s}\,\mathbb E\big[e^{\sigma(W_{t+s}-W_t)}\big]\\ &=S_t\,e^{(\mu-\sigma^2/2)s}\,e^{\sigma^2s/2}\\ &=S_t\,e^{\mu s}. \end{aligned} \]

บรรทัดแรกได้จากการหาร $S_{t+s}$ ด้วย $S_t$ ซึ่งเหลือแค่ส่วนเพิ่ม บรรทัดที่สองดึง $S_t$ และส่วนที่ไม่สุ่มออกนอกค่าเฉลี่ย และใช้ว่าส่วนเพิ่มอิสระจากข้อมูลวันนี้ ค่าเฉลี่ยแบบมีเงื่อนไขจึงเท่ากับค่าเฉลี่ยธรรมดา บรรทัดที่สามคือ Normal MGF ที่ $t=1$ ของตัวแปรที่มี variance $\sigma^2s$ ผลคือ $-\sigma^2/2$ ที่ใส่ไว้ใน exponent ถูกหักล้างพอดี drift $\mu$ จึงเป็นอัตราโตของราคาคาดหมาย (expected future price)

เทียบกับคำถามเปิด: log return หนึ่งปีมีค่าเฉลี่ย $\mu-\sigma^2/2=0.09$ และ $\sigma=0.22$ จึงได้ $\mu=0.09+0.0242=0.1142$ และ $\mathbb E[S_1]=100e^{0.1142}=\$112.10$ ตรงกับขั้นก่อน ถ้ามองสองปี ราคาคาดหมายเป็น $100e^{0.2284}\approx\$125.66$ แต่ median เป็นแค่ $100e^{0.18}\approx\$119.72$ ช่องว่างกว้างขึ้นตามเวลา เพราะ variance ของ log return โตตามเวลา

ขั้นที่ 7 — ผลรวมของตัวแปรอิสระ: MGF คูณกัน

ถ้า $X$ กับ $Y$ อิสระกัน $e^{tX}$ กับ $e^{tY}$ ก็อิสระกัน ค่าเฉลี่ยของผลคูณจึงแยกได้ตามสมบัติของตัวแปรอิสระ การหา distribution ของผลรวมซึ่งปกติต้องทำ convolution จึงเหลือแค่การคูณ

\[ \begin{aligned} M_{X+Y}(t)&=\mathbb E[e^{tX}e^{tY}]\\ &=\mathbb E[e^{tX}]\,\mathbb E[e^{tY}]\\ &=M_X(t)\,M_Y(t),\\ K_{X+Y}(t)&=K_X(t)+K_Y(t). \end{aligned} \]

บรรทัดที่สองเป็นจุดที่ใช้ independence ซึ่งต้องการมากกว่า covariance ศูนย์ ตัวอย่าง: P&L หนึ่งวันของสอง desk ที่อิสระกัน เป็น Normal ค่าเฉลี่ย \$50 SD \$220 และค่าเฉลี่ย \$25 SD \$180

\[ \begin{aligned} M_X M_Y&=e^{50t+220^2t^2/2}\,e^{25t+180^2t^2/2}\\ &=e^{75t+80{,}800\,t^2/2},\\ \operatorname{SD}(X+Y)&=\sqrt{80{,}800}\approx284.25. \end{aligned} \]

ผลคูณมีรูปแบบเดียวกับ Normal MGF ทุก $t$ ทฤษฎีเอกลักษณ์จึงบอกว่าผลรวมเป็น Normal ค่าเฉลี่ย \$75 SD \$284.25 ไม่ใช่แค่ “ค่าเฉลี่ยกับ variance ตรงกัน” แต่ทั้ง distribution ตรงกัน ถ้าสอง desk มี correlation ต้องใช้ joint distribution แทน ซึ่งขั้นถัดไปทำให้

ขั้นที่ 8 — MGF ของ multivariate Normal

สำหรับ vector $X$ ใส่ vector $s$ แทน $t$ เขียน $X=\mu+LZ$ ตามการสร้าง MVN โดย $Z$ เป็น standard Normal อิสระ และ $LL^{\mathsf T}=\Sigma$ ให้ $a=L^{\mathsf T}s$ แล้วใช้ MGF ตัวแปรเดียวทีละ component

\[ \begin{aligned} M_X(s)&:=\mathbb E[e^{s^{\mathsf T}X}]\\ &=e^{s^{\mathsf T}\mu}\,\mathbb E[e^{a^{\mathsf T}Z}]\\ &=e^{s^{\mathsf T}\mu}\prod_jM_{Z_j}(a_j)\\ &=e^{s^{\mathsf T}\mu+\frac12\sum_ja_j^2},\\ \textstyle\sum_ja_j^2&=s^{\mathsf T}LL^{\mathsf T}s=s^{\mathsf T}\Sigma s,\\ M_X(s)&=e^{s^{\mathsf T}\mu+\frac12s^{\mathsf T}\Sigma s}. \end{aligned} \]

บรรทัดที่สองใช้ $s^{\mathsf T}LZ=(L^{\mathsf T}s)^{\mathsf T}Z=a^{\mathsf T}Z$ บรรทัดที่สามแยกผลคูณได้เพราะ $Z_j$ อิสระกัน สูตรสุดท้ายบอกว่า $s^{\mathsf T}X$ เป็น Normal ที่ค่าเฉลี่ย $s^{\mathsf T}\mu$ และ variance $s^{\mathsf T}\Sigma s$ ซึ่งคือ ความเสี่ยงของพอร์ต $w^{\mathsf T}\Sigma w$ สูตรนี้ไม่มี inverse หรือ determinant จึงใช้กับ $\Sigma$ ที่ singular ได้ด้วย และเป็นเครื่องมือที่ใช้พิสูจน์ว่า marginal และ linear combination ของ MVN เป็น Normal

gradient และ Hessian เก็บอะไรไว้
\[ \begin{aligned} K_X(s)&=s^{\mathsf T}\mu+\tfrac12s^{\mathsf T}\Sigma s,\\ \nabla K_X(s)&=\mu+\Sigma s,\\ \nabla^2K_X(s)&=\Sigma,\\ \nabla^2M_X(0)&=\Sigma+\mu\mu^{\mathsf T}=\mathbb E[XX^{\mathsf T}]. \end{aligned} \]

เหมือนกรณีตัวแปรเดียว: Hessian ของ CGF ที่ศูนย์คือ covariance matrix โดยตรง ส่วน Hessian ของ MGF ที่ศูนย์คือ raw second-moment matrix

ตัวอย่างการใช้งาน: log return หนึ่งปีของหุ้นสองตัวเป็น MVN มี $\mu=(0.05,\ 0.08)$ และ $\Sigma=\begin{bmatrix}0.04&0.01\\0.01&0.09\end{bmatrix}$ gross return คือ $G_i=e^{X_i}$ ต้องการ covariance ของ $G_1$ กับ $G_2$ ซึ่งเป็นสิ่งที่ใช้คำนวณความเสี่ยงของพอร์ตที่ถือหุ้นจริง

\[ \begin{aligned} \mathbb E[G_1]&=M_X(1,0)=e^{0.05+0.02}\approx1.0725,\\ \mathbb E[G_2]&=M_X(0,1)=e^{0.08+0.045}\approx1.1331,\\ \mathbb E[G_1G_2]&=M_X(1,1)=e^{0.13+0.075}\approx1.2275,\\ \operatorname{Cov}(G_1,G_2)&=1.2275-1.0725\times1.1331\\ &\approx0.0122. \end{aligned} \]

$s=(1,\ 1)$ ให้ $s^{\mathsf T}\Sigma s=0.04+0.09+2(0.01)=0.15$ ครึ่งหนึ่งคือ 0.075 ผลคูณของค่าเฉลี่ยเป็น $e^{0.195}$ ส่วนค่าเฉลี่ยของผลคูณเป็น $e^{0.205}$ ต่างกันด้วยตัวคูณ $e^{\Sigma_{12}}=e^{0.01}$ พอดี จึงได้สูตรทั่วไป $\operatorname{Cov}(G_1,G_2)=\mathbb E[G_1]\mathbb E[G_2](e^{\Sigma_{12}}-1)$ ซึ่งใช้แปลง covariance ของ log return เป็น covariance ของ gross return

ขั้นที่ 9 — ตรวจก่อนว่า MGF มีค่า

MGF ไม่ได้มีค่าจำกัดเสมอ ตัวอย่างง่ายที่สุดคือ Exponential ที่อัตรา $\lambda$ (เช่นเวลารอคำสั่งซื้อขายถัดไป) ซึ่งมี density $\lambda e^{-\lambda x}$ เมื่อ $x\ge0$

\[ \begin{aligned} M_X(t)&=\int_0^{\infty}e^{tx}\lambda e^{-\lambda x}\,dx\\ &=\lambda\int_0^{\infty}e^{-(\lambda-t)x}\,dx,\\ t\lt\lambda:\quad M_X(t)&=\frac{\lambda}{\lambda-t},\\ t\ge\lambda:\quad M_X(t)&=\infty. \end{aligned} \]

ถ้า $t\lt\lambda$ exponent ยังติดลบ integrand ลดลงจนพื้นที่จำกัด ถ้า $t=\lambda$ integrand เป็นค่าคงที่ $\lambda$ ตลอดครึ่งเส้นจำนวน พื้นที่จึงเป็นอนันต์ ที่ $\lambda=2$ ได้ $M(1)=2$ แต่ $M(2)$ ไม่ใช่ตัวเลขที่เอาไปใช้ต่อได้ ส่วน Normal MGF มีค่าทุก $t$ เพราะหาง $e^{-x^2/2}$ ลดเร็วกว่า exponential ใด ๆ

หางที่หนากว่านั้นทำให้ MGF ไม่มีค่าเลยในฝั่งบวก Student-t ไม่มี MGF รอบศูนย์ แม้เลือก degrees of freedom มากพอให้มี variance ก็ตาม เพราะหางแบบพหุนามแพ้ exponential เสมอ ตัวราคา lognormal $Y=e^Z$ ก็เช่นกัน: มี moment ทุกลำดับ $\mathbb E[Y^k]=M_Z(k)=e^{k^2/2}$ แต่ $\mathbb E[e^{tY}]=\infty$ ทุก $t\gt0$ เพราะ $te^z$ โตเร็วกว่า $z^2/2$ ไม่ขัดกับคำถามเปิด เพราะที่นั่นใช้ MGF ของ log return ไม่ใช่ของตัวราคา เมื่อ MGF ไม่มีค่า ใช้ characteristic function $\mathbb E[e^{iuX}]$ แทนได้เสมอ เพราะ $|e^{iuX}|=1$ ซึ่งคือเครื่องมือของ Fourier pricing

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

  • อ่าน $M''(0)$ เป็น variance: ได้ 95,625 แทน 90,000 ดอลลาร์² หรือ SD \$309 แทน \$300 ต้องหัก $[M'(0)]^2$ หรือใช้ $K''(0)$
  • ใส่ค่าเฉลี่ยใน exponential: $100e^{\mathbb E[R]}=\$109.42$ คือ median ไม่ใช่ราคาคาดหมาย \$112.10 และ “บวกครึ่ง variance” ใช้ได้เมื่อ $R$ เป็น Normal เท่านั้น
  • คิดว่า $M_R(-1)$ คือผลของการ short: $\mathbb E[e^{-R}]=e^{-0.09+0.0242}\approx0.936$ คือค่าเฉลี่ยของ $S_0/S_T$ ไม่ใช่ gross return ของการ short การ short หนึ่งหุ้นได้ $S_0-S_T$ มีค่าเฉลี่ย $100-112.10=-\$12.10$ ก่อนต้นทุนยืมหุ้น และผลคูณ $M_R(1)M_R(-1)=e^{0.0484}\approx1.0496$ ไม่ใช่ 1 เพราะ $e^R$ กับ $e^{-R}$ ไม่อิสระกัน
  • คูณ MGF ของตัวแปรที่ไม่อิสระ: covariance ศูนย์ไม่พอ ในโจทย์คู่ $X$ กับ $WX$ ด้านล่าง การคูณให้ 2.72 แทนค่าจริง 4.19
  • ลืมหน่วยของ $t$: ถ้า $X$ เป็นดอลลาร์ $M_X(1)=e^{75+45{,}000}$ ไม่มีความหมายทางการเงินและล้นเครื่องคำนวณ ต้องให้ $tX$ ไม่มีหน่วย

โจทย์ตรวจความเข้าใจ

1. $A$ มีค่า $-1$ หรือ $+1$ อย่างละครึ่ง ส่วน $B$ เป็น standard Normal ทั้งคู่ค่าเฉลี่ยศูนย์ variance หนึ่ง $\mathbb E[e^A]$ กับ $\mathbb E[e^B]$ เท่ากันไหม

เฉลย

ไม่เท่า $M_A(1)=(e+e^{-1})/2\approx1.5431$ ส่วน $M_B(1)=e^{1/2}\approx1.6487$ ค่าเฉลี่ยกับ variance เท่ากันไม่ได้ทำให้ MGF ทั้งเส้นเท่ากัน ถ้า $A$ เป็น log return สูตร “บวกครึ่ง variance” จะให้ราคาคาดหมายสูงเกินไป 6.8% เพราะ $B$ มีหางที่ยาวกว่าซึ่ง exponential ขยายให้ใหญ่

2. P&L $X$ เป็น Normal ค่าเฉลี่ย \$75 SD \$300 เปลี่ยนหน่วยเป็นพันดอลลาร์ $Y=X/1000$ MGF, raw second moment และ $M_Y(1)$ เป็นเท่าไร

เฉลย

$M_Y(u)=\mathbb E[e^{uX/1000}]=M_X(u/1000)$ $Y$ มีค่าเฉลี่ย 0.075 variance $0.3^2=0.09$ raw second moment $0.09+0.075^2=0.095625$ (คือ 95,625 หารด้วย $1000^2$) และ $M_Y(1)=e^{0.075+0.045}=e^{0.12}\approx1.1275$ การเปลี่ยนหน่วยคือการยืดแกน $t$ ไม่ได้เปลี่ยน P&L จริง

3. $X$ เป็น standard Normal และ $Y=WX$ โดย $W=\pm1$ อย่างละครึ่ง อิสระจาก $X$ (ตัวอย่างที่ marginal เป็น Normal แต่ไม่ jointly Normal) covariance เป็นศูนย์ จะคูณ MGF เพื่อหา $\mathbb E[e^{X+Y}]$ ได้ไหม

เฉลย

ไม่ได้ เมื่อ $W=-1$ จะได้ $X+Y=0$ และเมื่อ $W=1$ ได้ $2X$ ดังนั้น $\mathbb E[e^{X+Y}]=\tfrac12\cdot1+\tfrac12M_X(2)=(1+e^2)/2\approx4.1945$ แต่การคูณ marginal MGF ให้ $e^{1/2}e^{1/2}=e\approx2.7183$ ต่ำไป 35% ความต่างมาจากความสัมพันธ์ที่ covariance มองไม่เห็น

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
// MGF ของ distribution ที่ทุกค่ามีโอกาสเท่ากัน
const mgfEqual = (t, xs) => xs.reduce((s, x) => s + Math.exp(t * x), 0) / xs.length;
const cards = [1, 2, 3], h = 1e-4;
const d1 = (mgfEqual(h, cards) - mgfEqual(-h, cards)) / (2 * h);
const d2 = (mgfEqual(h, cards) - 2 + mgfEqual(-h, cards)) / (h * h);
console.log(d1, d2, d2 - d1 * d1);                       // 2 4.667 0.667

// Normal MGF และ CGF
const normalMGF = (t, m, v) => Math.exp(m * t + 0.5 * v * t * t);
console.log(300 ** 2 + 75 ** 2, 300 ** 2);               // 95625 90000

// คำถามเปิด: ราคาคาดหมาย median และ mode
const m = 0.09, v = 0.22 ** 2;
console.log(100 * normalMGF(1, m, v), 100 * Math.exp(m), 100 * Math.exp(m - v));  // 112.10 109.42 104.25

// GBM: drift mu = m + v/2, ราคาคาดหมายสองปี เทียบ median
const mu = m + v / 2;
console.log(mu, 100 * Math.exp(2 * mu), 100 * Math.exp(2 * m));                     // 0.1142 125.66 119.72

// ผลรวมอิสระของสอง desk
console.log(Math.sqrt(220 ** 2 + 180 ** 2));             // 284.25

// MGF หลายตัวแปร: covariance ของ gross return
const M2 = (s, mvec, S) => Math.exp(s[0] * mvec[0] + s[1] * mvec[1] +
  0.5 * (s[0] * s[0] * S[0][0] + 2 * s[0] * s[1] * S[0][1] + s[1] * s[1] * S[1][1]));
const mv = [0.05, 0.08], S = [[0.04, 0.01], [0.01, 0.09]];
const EG1 = M2([1, 0], mv, S), EG2 = M2([0, 1], mv, S), EGG = M2([1, 1], mv, S);
console.log(EG1, EG2, EGG, EGG - EG1 * EG2);             // 1.0725 1.1331 1.2275 0.0122

// Exponential: มีค่าเมื่อ t < lambda เท่านั้น
const expMGF = (t, lam) => t < lam ? lam / (lam - t) : Infinity;
console.log(expMGF(1, 2), expMGF(2, 2));                 // 2 Infinity

// โจทย์: สองค่าเทียบ Normal และกรณี Y = W X
console.log(mgfEqual(1, [-1, 1]), normalMGF(1, 0, 1), (1 + normalMGF(2, 0, 1)) / 2, Math.E);

สิ่งที่ควรตอบได้หลังอ่าน

  • MGF คือ $\mathbb E[e^{tX}]$ ไม่ใช่ density และ $t$ ไม่ใช่เวลา ถ้ามีค่าจำกัดรอบศูนย์ $M^{(k)}(0)=\mathbb E[X^k]$ และ variance คือ $M''(0)-[M'(0)]^2$ หรือ $K''(0)$
  • พิสูจน์ Normal MGF $e^{\mu t+\sigma^2t^2/2}$ ด้วยการจัดกำลังสองสมบูรณ์ได้ และอธิบายด้วยภาพว่า $e^{tz}\phi(z)$ คือระฆังที่เลื่อนไปและใหญ่ขึ้น
  • ราคาคาดหมายจาก Normal log return คือ $S_0e^{\mathbb E[R]+\operatorname{Var}(R)/2}$ ส่วน $S_0e^{\mathbb E[R]}$ คือ median และใน GBM ได้ $\mathbb E_t[S_{t+s}]=S_te^{\mu s}$
  • MGF ของผลรวมตัวแปรอิสระคือผลคูณ แต่ต้องการ independence จริง ไม่ใช่แค่ covariance ศูนย์
  • MGF ของ MVN คือ $e^{s^{\mathsf T}\mu+\frac12s^{\mathsf T}\Sigma s}$ ใช้หาค่าเฉลี่ยของผลคูณ gross return และ covariance $\mathbb E[G_1]\mathbb E[G_2](e^{\Sigma_{12}}-1)$ ได้
  • ตรวจว่า MGF มีค่าก่อนใช้: Exponential หยุดที่ $t=\lambda$ ส่วน Student-t และตัวราคา lognormal ไม่มี MGF ฝั่งบวก ต้องใช้ characteristic function แทน

หน้าถัดไป marginal ของ multivariate Normal จะใช้ MGF หลายตัวแปรนี้พิสูจน์ว่า ถ้าเลือกเก็บแค่บางส่วนของ vector ที่เป็น MVN ส่วนนั้นยังเป็น Normal โดยใช้ $\mu$ และ $\Sigma$ เฉพาะส่วนที่เก็บไว้
