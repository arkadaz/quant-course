8.5 The Moment Generating Function (MGF)

MGF คือค่าเฉลี่ยของ $e^{tX}$ มันเก็บทุก moment ไว้ในฟังก์ชันเดียว และถ้า $X$ เป็น log return ค่าของมันที่ $t=1$ คือราคาปลายงวดเฉลี่ยหารด้วยราคาวันนี้

ทีมวิจัยต้องเขียนในรายงานว่า “ปลายปีนี้ ราคาหุ้นตัวหนึ่งโดยเฉลี่ยจะอยู่ที่เท่าไร” ตัวเลขนี้เรียกว่าราคาคาดหมาย (expected price) คือค่าเฉลี่ยของราคาปลายปี ถ้าปีนี้เกิดซ้ำได้หลายพันครั้ง นักวิเคราะห์สามคนใช้แบบจำลองเดียวกัน แต่ได้คำตอบไม่ตรงกัน

ของที่รู้ (ตัวเลขสมมติ):

  • ราคาวันนี้ $S_0=\$100$ และหุ้นตัวนี้ไม่จ่ายเงินปันผล
  • log return หนึ่งปี $R=\ln(S_T/S_0)$ คือ log ของราคาปลายปีหารด้วยราคาวันนี้ จึงเขียนราคาปลายปีได้ว่า $S_T=S_0e^R$ (log return)
  • $R$ เป็น Normal (รูประฆัง) ค่าเฉลี่ย $0.09$ หรือ 9% ต่อปี
  • SD (standard deviation ขนาดการกระจายรอบค่าเฉลี่ย) ของ $R$ คือ $0.22$ หรือ 22% ต่อปี

คำตอบสามแบบ:

  • คนแรกคิดว่า “โตปีละ 9%” จึงตอบ $100\times1.09=\$109$
  • คนที่สองใส่ค่าเฉลี่ยของ $R$ ลงใน exponential ตอบ $100e^{0.09}\approx\$109.42$
  • คนที่สามตอบ \$112.10 หน้านี้จะคำนวณตัวเลขนี้ให้ดูทีละขั้น

ใครถูก และอีกสองคนพลาดตรงไหน

ลองตอบก่อนเปิดเฉลย

คนที่สามถูก ราคาคาดหมายคือ 100 คูณค่าเฉลี่ยของ $e^R$ และสูตรของ Normal (ซึ่งหน้านี้จะพิสูจน์) ให้

\[\begin{aligned}\mathbb E[S_T]&=100\,\mathbb E[e^R]\\&=100\,e^{0.09+0.22^2/2}\\&=100\,e^{0.1142}\approx\$112.10\end{aligned}\]

คนแรกเอา 9% ซึ่งเป็นค่าเฉลี่ยของ log return ไปใช้เหมือนผลตอบแทนธรรมดา (simple return คือกำไรหารด้วยราคาเริ่ม) ซึ่งเป็นตัวแปรคนละชนิดกัน

คนที่สองใส่ค่าเฉลี่ยลงใน exponential ก่อน แล้วค่อยคูณ 100 ได้ \$109.42 ตัวเลขนี้คือ median ของราคา คือราคาที่ครึ่งหนึ่งของผลลัพธ์อยู่ต่ำกว่า ไม่ใช่ค่าเฉลี่ย

ทำไมค่าเฉลี่ยสูงกว่า? เพราะกราฟของ exponential โค้งขึ้น ปีที่ $R$ สูงกว่าค่าเฉลี่ยดันราคาขึ้นมากกว่าที่ปีที่ $R$ ต่ำกว่าค่าเฉลี่ยดึงราคาลง ค่าเฉลี่ยของ $e^R$ จึงสูงกว่า $e^{\mathbb E[R]}$ เครื่องมือที่คำนวณ $\mathbb E[e^{tR}]$ ออกมาเป็นสูตรได้คือ MGF ซึ่งหน้านี้จะสร้างให้ดู

ภาพรวมก่อนลงสูตร

คำถามเปิดต้องการค่าเฉลี่ยของ $e^R$ ไม่ใช่ค่าเฉลี่ยของ $R$ ถ้าเราหาค่าเฉลี่ยของ $e^{tR}$ ได้สำหรับทุกตัวเลข $t$ ก็จะได้คำตอบของคำถามนี้และคำถามที่คล้ายกันทั้งหมดในครั้งเดียว ฟังก์ชันนั้นมีชื่อว่า MGF (moment generating function)

MGF ของตัวแปรสุ่ม $X$ เขียนว่า $M_X(t)=\mathbb E[e^{tX}]$ ตัว $t$ คือตัวเลขที่เราเลือกป้อนเอง ไม่ใช่เวลา และ $M_X$ ไม่ใช่ density มันเป็นแค่ค่าเฉลี่ยของ $e^{tX}$ ที่เปลี่ยนไปตาม $t$

MGF มีประโยชน์สองแบบ:

  • มันเก็บ moments ทั้งหมดไว้ (moment ลำดับ $k$ คือค่าเฉลี่ยของ $X^k$) ความชันของ $M_X$ ที่ $t=0$ คือค่าเฉลี่ย $\mathbb E[X]$ และความโค้งที่ $t=0$ คือ $\mathbb E[X^2]$
  • ค่าของมันที่ $t$ อื่นตอบคำถามการเงินได้ตรง ๆ ถ้า $X$ เป็น log return แล้ว $M_X(1)=\mathbb E[e^X]$ คือราคาปลายงวดเฉลี่ยหารด้วยราคาวันนี้

สำหรับ Normal เราจะได้ MGF เป็นสูตรปิด $e^{\mu t+\sigma^2t^2/2}$ และสำหรับ multivariate Normal (Normal หลายตัวแปรพร้อมกัน) ได้ $e^{s^{\mathsf T}\mu+\frac12s^{\mathsf T}\Sigma s}$ สองสูตรนี้คือที่มาของกฎ “บวกครึ่ง variance” ที่ใช้ทุกครั้งเมื่อแปลง log return เป็นราคาคาดหมาย มันยังอธิบายว่าทำไม drift $\mu$ ของ geometric Brownian motion (แบบจำลองราคาหุ้นมาตรฐาน) จึงเป็นอัตราโตของราคาคาดหมาย

ลำดับของหน้านี้:

  • เริ่มจากบัตรสามใบที่คำนวณด้วยมือได้ และดูว่า derivative ดึง moments ออกมาอย่างไร
  • พิสูจน์ MGF ของ Normal ด้วยการจัดกำลังสองสมบูรณ์ แล้วใช้มันตอบคำถามเปิด และหาราคาคาดหมายของ GBM
  • ขยายไปยังผลรวมของตัวแปรที่อิสระกัน กรณีหลายตัวแปร และกรณีที่ MGF ไม่มีค่า
ศัพท์ที่ใช้ในหัวข้อนี้
Raw moment
ค่าเฉลี่ยของ $X^k$ คือ $\mathbb E[X^k]$ วัดรอบศูนย์ ต่างจาก central moment $\mathbb E[(X-\mathbb E[X])^k]$ ที่วัดรอบค่าเฉลี่ย variance คือ central moment ลำดับที่สอง
Moment generating function (MGF)
ค่าเฉลี่ยของ $e^{tX}$ เขียนว่า $M_X(t)=\mathbb E[e^{tX}]$ ใช้ทำสามอย่าง: ดึง moments ออกมาด้วยการ differentiate ที่ $t=0$ บอกว่าผลรวมของตัวแปรเป็น distribution อะไร และหาค่าเฉลี่ยของ exponential เช่นราคาที่คำนวณจาก log return
Cumulant generating function (CGF)
log ของ MGF คือ $K_X(t)=\ln M_X(t)$ derivative แรกที่ $t=0$ คือค่าเฉลี่ย derivative ที่สองคือ variance โดยไม่ต้องหักอะไร และ CGF ของผลรวมของตัวแปรอิสระคือผลบวกของ CGF แต่ละตัว
Log return, gross return
log return คือ $R=\ln(S_T/S_0)$ ส่วน gross return คือ $S_T/S_0=e^R$ คือราคาปลายงวดหารด้วยราคาเริ่ม ถ้าราคาขึ้นจาก \$100 เป็น \$110 gross return คือ $110/100=1.10$
Median, mode
median คือค่าที่ครึ่งหนึ่งของผลลัพธ์อยู่ต่ำกว่า mode คือค่าที่ density สูงที่สุด ถ้า distribution เบ้ ทั้งสองค่าไม่เท่ากับค่าเฉลี่ย
Lognormal
ตัวแปรที่ log ของมันเป็น Normal เช่นราคาปลายงวด $S_T=S_0e^R$ เมื่อ $R$ เป็น Normal (lognormal distribution)
Geometric Brownian motion (GBM)
แบบจำลองราคาหุ้นที่ log return ของทุกช่วงเวลาเป็น Normal และแต่ละช่วงอิสระกัน มี drift $\mu$ (อัตราโตต่อปี) และความผันผวน $\sigma$ (SD ของ log return ต่อปี) เป็นฐานของแบบจำลอง Black–Scholes
Characteristic function
$\mathbb E[e^{iuX}]$ โดย $i=\sqrt{-1}$ เพราะ $|e^{iuX}|=1$ เสมอ ค่าเฉลี่ยนี้จึงมีค่าเสมอ ใช้แทน MGF เมื่อ MGF เป็นอนันต์
ตัวแปรไหน หน่วยอะไร
สัญลักษณ์ความหมายหน่วย

ขั้นที่ 1 — สร้าง MGF ของบัตร 1, 2, 3 แล้ว differentiate

ก่อนใช้กับหุ้น ลองกับตัวอย่างเล็กที่เขียนทุกพจน์ได้ด้วยมือ มีบัตรสามใบเขียนเลข 1, 2 และ 3 สุ่มหยิบมาหนึ่งใบ แต่ละใบมีโอกาส $1/3$ ให้ $X$ คือเลขบนบัตรที่หยิบได้

ค่าเฉลี่ยของอะไรก็ตามที่ขึ้นกับ $X$ (expected value) คือผลรวมของค่านั้นในแต่ละกรณี คูณโอกาสของกรณีนั้น ดังนั้นค่าเฉลี่ยของ $e^{tX}$ คือ $e^{t\cdot1}$, $e^{t\cdot2}$, $e^{t\cdot3}$ คูณ $1/3$ แล้วรวมกัน จากนั้นเรา differentiate เทียบกับ $t$ แล้วแทน $t=0$ เพื่อดูว่าได้อะไรออกมา

\[ \begin{aligned} M_X(t)&=\tfrac13e^{t}+\tfrac13e^{2t}+\tfrac13e^{3t},\\ M_X(0)&=\tfrac13+\tfrac13+\tfrac13=1,\\ M_X'(t)&=\tfrac13e^{t}+\tfrac23e^{2t}+e^{3t},\\ M_X'(0)&=\tfrac{1+2+3}3=2,\\ M_X''(t)&=\tfrac13e^{t}+\tfrac43e^{2t}+3e^{3t},\\ M_X''(0)&=\tfrac{1^2+2^2+3^2}3=\tfrac{14}3,\\ \operatorname{Var}(X)&=\tfrac{14}3-2^2=\tfrac23. \end{aligned} \]

ดูว่าเกิดอะไรขึ้นกับพจน์ $e^{kt}$ ทุกครั้งที่ differentiate ตัวเลข $k$ จะหลุดลงมาคูณหนึ่งตัว เพราะ $\frac{d}{dt}e^{kt}=ke^{kt}$ พอแทน $t=0$ ตัว exponential กลายเป็น $e^0=1$ เหลือแค่ $k$ ที่ถ่วงด้วยโอกาส differentiate ครั้งเดียวจึงได้ $\frac{1+2+3}3$ ซึ่งคือค่าเฉลี่ยของ $X$ differentiate สองครั้งได้ $k^2$ ถ่วงด้วยโอกาส ซึ่งคือค่าเฉลี่ยของ $X^2$

จุดที่คนมักสะดุดคือ $M_X''(0)=14/3$ ยังไม่ใช่ variance มันคือ raw moment $\mathbb E[X^2]$ ต้องหักกำลังสองของค่าเฉลี่ยออกก่อน เพราะ variance คือ $\mathbb E[X^2]-(\mathbb E[X])^2$

ตรวจด้วยวิธีตรง: ระยะห่างจากค่าเฉลี่ย 2 ของบัตรสามใบคือ $-1$, $0$, $1$ ยกกำลังสองได้ 1, 0, 1 เฉลี่ยได้ $(1+0+1)/3=2/3$ ตรงกัน

ขั้นที่ 2 — ทำไม derivative ที่ศูนย์ให้ทุก moment

บัตรสามใบเป็นแค่ตัวอย่างเดียว เราต้องรู้ว่าทำไมกลไกนี้ใช้ได้กับทุก distribution คำตอบอยู่ใน Taylor series ของ exponential: $e^u=1+u+\frac{u^2}{2!}+\frac{u^3}{3!}+\cdots$

ใส่ $u=tX$ แล้วเอาค่าเฉลี่ยทีละพจน์ ตัว $t^k$ และ $k!$ ไม่สุ่ม จึงดึงออกนอกค่าเฉลี่ยได้ ค่าเฉลี่ยของพจน์ที่ $k$ จึงเป็น $t^k\mathbb E[X^k]/k!$ ผลคือ MGF เป็นอนุกรมกำลังของ $t$ ที่มี moments เป็นสัมประสิทธิ์ เหมือนชั้นวางที่มีช่องละหนึ่งกำลังของ $t$ และ moment ลำดับ $k$ วางอยู่ในช่อง $t^k$

\[ \begin{aligned} e^{tX}&=\sum_{k=0}^{\infty}\frac{t^kX^k}{k!},\\ M_X(t)&=\sum_{k=0}^{\infty}\frac{t^k\,\mathbb E[X^k]}{k!},\\ M_X^{(k)}(0)&=\mathbb E[X^k],\\ \operatorname{Var}(X)&=M_X''(0)-[M_X'(0)]^2. \end{aligned} \]

การหยิบ moment ลำดับ $k$ ออกจากชั้นวาง ทำได้ด้วยการ differentiate $k$ ครั้งแล้วแทน $t=0$ พจน์ที่กำลังต่ำกว่า $k$ หายไป เพราะถูก differentiate จนเหลือศูนย์ พจน์ที่กำลังสูงกว่า $k$ ก็หายไป เพราะยังมี $t$ ติดอยู่ พอแทน $t=0$ ก็เป็นศูนย์ เหลือแค่พจน์ $t^k\mathbb E[X^k]/k!$ ซึ่ง differentiate $k$ ครั้งได้ $k!\,\mathbb E[X^k]/k!=\mathbb E[X^k]$ พอดี

จุดที่ต้องระวังคือการเอาค่าเฉลี่ยเข้าไปในผลรวมอนันต์ทีละพจน์ การสลับนี้ทำได้เมื่อ $M_X(t)$ มีค่าจำกัด (ไม่เป็นอนันต์) บนช่วงเล็ก ๆ รอบ $t=0$ เงื่อนไขนี้เข้มกว่าการมีค่าเฉลี่ยและ variance เพราะมันบังคับให้หางของ distribution บางพอ จนค่าเฉลี่ยของ $e^{tX}$ ไม่เป็นอนันต์

ทำไมเงื่อนไข “มีค่าจำกัดรอบศูนย์” ทำให้สลับได้

สมมติว่า $M_X(a)$ และ $M_X(-a)$ มีค่าจำกัดสำหรับ $a\gt0$ บางค่า เมื่อ $|t|\lt a$ เราหาตัวครอบได้ คือตัวแปรที่ใหญ่กว่าผลรวมของค่าสัมบูรณ์ของทุกพจน์ และมีค่าเฉลี่ยจำกัด

\[ \begin{aligned} \sum_{k}\frac{|t|^k|X|^k}{k!}&=e^{|t||X|}\le e^{a|X|},\\ e^{a|X|}&\le e^{aX}+e^{-aX},\\ \mathbb E[e^{a|X|}]&\le M_X(a)+M_X(-a)\lt\infty. \end{aligned} \]

อสมการ $e^{a|X|}\le e^{aX}+e^{-aX}$ จริง เพราะ $e^{a|X|}$ เท่ากับพจน์หนึ่งทางขวาเสมอ (ขึ้นกับว่า $X$ เป็นบวกหรือลบ) และอีกพจน์เป็นบวก เมื่อตัวครอบมีค่าเฉลี่ยจำกัด การสลับค่าเฉลี่ยกับผลรวมอนันต์จึงทำได้ (นี่คือ dominated convergence theorem)

MGF ยังทำหน้าที่เหมือนลายนิ้วมือ ข้อนี้เรียกว่าทฤษฎีเอกลักษณ์ (uniqueness theorem): ถ้าสอง distribution มี MGF ที่มีค่าจำกัด และเท่ากันทุก $t$ ในช่วงรอบศูนย์ ทั้งสองคือ distribution เดียวกัน แค่ค่าเฉลี่ยกับ variance เท่ากันยังไม่พอ และ MGF เท่ากันที่ $t$ จุดเดียวก็ไม่พอ ทฤษฎีนี้ทำให้เราบอกได้ว่าผลรวมของตัวแปรเป็น distribution อะไร โดยดูแค่ MGF ของผลรวม ซึ่งจะใช้ในขั้นผลรวมของตัวแปรอิสระด้านล่าง

ขั้นที่ 3 — Normal MGF มาจากการจัดกำลังสองสมบูรณ์

คำถามเปิดต้องการ $\mathbb E[e^R]$ เมื่อ $R$ เป็น Normal ขั้นนี้จึงหา MGF ของ Normal ให้เป็นสูตร

เริ่มจาก standard Normal $Z$ ซึ่งมีค่าเฉลี่ย 0 SD 1 และ density $\phi(z)=e^{-z^2/2}/\sqrt{2\pi}$ จากนั้นค่อยเลื่อนและยืดเป็น $X=\mu+\sigma Z$ ซึ่งมีค่าเฉลี่ย $\mu$ และ SD $\sigma$ วิธีคือเอา $e^{tz}$ คูณ density แล้วรวมเลขชี้กำลังสองก้อนให้เป็นกำลังสองสมบูรณ์ (completing the square) เป้าหมายคือทำให้สิ่งที่อยู่ในอินทิกรัลกลับมาเป็น density ของ Normal อีกตัว ซึ่งเรารู้ว่าพื้นที่เท่ากับ 1

\[ \begin{aligned} M_Z(t)&=\int_{-\infty}^{\infty}e^{tz}\frac{e^{-z^2/2}}{\sqrt{2\pi}}\,dz,\\ tz-\tfrac{z^2}2&=-\tfrac12(z-t)^2+\tfrac{t^2}2,\\ M_Z(t)&=e^{t^2/2}\int_{-\infty}^{\infty}\frac{e^{-(z-t)^2/2}}{\sqrt{2\pi}}\,dz\\ &=e^{t^2/2},\\ M_X(t)&=\mathbb E[e^{t\mu+t\sigma Z}]=e^{\mu t}M_Z(\sigma t)\\ &=e^{\mu t+\sigma^2t^2/2}. \end{aligned} \]

หัวใจของขั้นนี้คือการเขียน $tz-\frac{z^2}2$ ใหม่เป็น $-\frac12(z-t)^2+\frac{t^2}2$ ตรวจได้โดยกระจายวงเล็บ: $-\frac12(z^2-2tz+t^2)+\frac{t^2}2=tz-\frac{z^2}2$ ก้อน $e^{t^2/2}$ ไม่มี $z$ จึงดึงออกนอกอินทิกรัลได้ สิ่งที่เหลือในอินทิกรัลคือ density ของ Normal ที่ค่าเฉลี่ย $t$ ซึ่งพื้นที่เท่ากับ 1 เสมอ

ความหมายของการคำนวณนี้: การคูณ density ด้วย $e^{tz}$ แค่เลื่อนระฆังไปอยู่ที่ $z=t$ และขยายพื้นที่เป็น $e^{t^2/2}$ เท่า ตามรูปด้านล่าง

ขั้นสุดท้ายแทน $X=\mu+\sigma Z$ ตัว $e^{t\mu}$ ไม่สุ่ม จึงดึงออกนอกค่าเฉลี่ยได้ ส่วน $\mathbb E[e^{(\sigma t)Z}]$ ก็คือ $M_Z$ ที่ป้อน $\sigma t$ แทน $t$ จึงได้ $e^{\sigma^2t^2/2}$ ผลนี้มีค่าจำกัดทุก $t$ เพราะเมื่อ $z$ ใหญ่ $-z^2/2$ ลดลงเร็วกว่าที่ $tz$ เพิ่มขึ้นเสมอ

ขั้นที่ 4 — อยากได้ variance ตรง ๆ ให้ใช้ log ของ MGF

ในตัวอย่างบัตรสามใบ เราต้องหัก $(M'(0))^2$ ออกเองเพื่อให้ได้ variance ทางลัดคือใช้ log ของ MGF

MGF ที่มีค่าจำกัดเป็นบวกเสมอ เพราะมันคือค่าเฉลี่ยของ $e^{tX}$ ซึ่งเป็นบวก เราจึงเอา log ได้ ฟังก์ชัน $K_X(t)=\ln M_X(t)$ เรียกว่า CGF (cumulant generating function) เมื่อ differentiate log สองครั้ง กฎการหารจะหักกำลังสองของค่าเฉลี่ยออกให้เอง

\[ \begin{aligned} K_X(t)&:=\ln M_X(t),\\ K_X'&=M_X'/M_X,\\ K_X''&=\frac{M_X''}{M_X}-\Big(\frac{M_X'}{M_X}\Big)^2,\\ K_X'(0)&=\mathbb E[X],\quad K_X''(0)=\operatorname{Var}(X),\\ \text{Normal}:\ K_X(t)&=\mu t+\tfrac12\sigma^2t^2. \end{aligned} \]

derivative ของ $\ln M$ คือ $M'/M$ ตาม chain rule differentiate อีกครั้งด้วยกฎการหารได้ $K''$ ตอนนี้แทน $t=0$ โดยใช้ $M_X(0)=1$: $K_X'(0)=M_X'(0)=\mathbb E[X]$ และ $K_X''(0)=M_X''(0)-(M_X'(0))^2$ ซึ่งคือ $\mathbb E[X^2]-(\mathbb E[X])^2$ หรือ variance พอดี การหักที่เราต้องทำเองในบัตรสามใบ ถูกสร้างไว้ในกฎการหารแล้ว

CGF ของ Normal เป็นพหุนามกำลังสองใน $t$ derivative ตั้งแต่ลำดับที่สามจึงเป็นศูนย์ทั้งหมด derivative ของ $K$ ที่ $t=0$ เรียกว่า cumulant เราจึงพูดว่า Normal มี cumulants ลำดับสูงเป็นศูนย์ อย่าสับสนกับ raw moments ซึ่งไม่ได้เป็นศูนย์ เช่น standard Normal ยังมี $\mathbb E[Z^4]=3$

ลองกับตัวเลขที่มีหน่วยดอลลาร์ โต๊ะเทรด (desk คือทีมที่ดูแลพอร์ตของตัวเอง) วัดกำไรขาดทุนรายวัน เรียกว่า P&L (profit and loss) สมมติว่า P&L หนึ่งวัน $X$ เป็น Normal โดย

  • ค่าเฉลี่ย $\mu=\$75$ ต่อวัน
  • SD $\sigma=\$300$ ต่อวัน

เราจะหา variance จาก MGF ทั้งสองทาง: ทางตรงจาก $M''(0)$ และทางลัดจาก $K''(0)$ เพื่อดูว่าถ้าเผลออ่าน $M''(0)$ เป็น variance จะผิดไปเท่าไร

\[ \begin{aligned} M_X'(t)&=(\mu+\sigma^2t)M_X(t),\\ M_X''(t)&=\big[\sigma^2+(\mu+\sigma^2t)^2\big]M_X(t),\\ M_X'(0)&=\mu=75,\\ M_X''(0)&=\sigma^2+\mu^2=300^2+75^2\\ &=90{,}000+5{,}625=95{,}625,\\ K_X''(0)&=\sigma^2=90{,}000. \end{aligned} \]

$M''(0)=95{,}625$ ดอลลาร์² คือ $\mathbb E[X^2]$ ไม่ใช่ variance ถ้าเผลออ่านเป็น variance จะได้ SD $\sqrt{95{,}625}\approx\$309.2$ แทนที่จะเป็น \$300 ส่วน $K''(0)$ ให้ variance 90,000 ดอลลาร์² ทันที โดยไม่ต้องหักอะไร

เรื่องหน่วย: $tX$ อยู่ในเลขชี้กำลัง จึงต้องไม่มีหน่วย เมื่อ $X$ เป็นดอลลาร์ $t$ จึงมีหน่วย 1/ดอลลาร์ และค่า $t$ ที่ใช้จริงต้องเล็ก เช่น $t=0.001$ ต่อดอลลาร์

ขั้นที่ 5 — ตอบคำถามเปิด: ราคาคาดหมายคือ MGF ของ log return ที่ $t=1$

โจทย์ให้อะไรมาบ้าง:

  • ราคาวันนี้ $S_0=\$100$ ไม่มีเงินปันผล ราคาปลายปีคือ $S_T=100e^R$
  • $R$ เป็น Normal ค่าเฉลี่ย $\mu=0.09$
  • SD ของ $R$ คือ 0.22 จึงมี variance $\sigma^2=0.22^2=0.0484$

เรากำลังหาค่าเฉลี่ยของราคาตามแบบจำลองนี้ ซึ่งเป็นคนละเรื่องกับราคายุติธรรมที่ใช้ตั้งราคา option (risk-neutral pricing)

ทำไม MGF ตอบได้: ค่าเฉลี่ยของ $S_T$ คือ 100 คูณค่าเฉลี่ยของ $e^R$ และ $\mathbb E[e^{1\cdot R}]$ ก็คือ MGF ของ $R$ ที่ป้อน $t=1$ เราจึงใช้สูตร Normal MGF $e^{\mu t+\sigma^2t^2/2}$ จากขั้นการจัดกำลังสองสมบูรณ์ได้ทันที โดยแทน $t=1$, $\mu=0.09$ และ $\sigma^2=0.0484$ ในบล็อกเดียวกันนี้ เราหา median และ mode ไว้เทียบด้วย

\[ \begin{aligned} \mathbb E[S_T]&=100\,\mathbb E[e^{1\cdot R}]=100\,M_R(1)\\ &=100\,e^{0.09+0.0484/2}\\ &=100\,e^{0.1142}\approx112.10,\\ \operatorname{median}(S_T)&=100\,e^{0.09}\approx109.42,\\ \text{mode}(S_T)&=100\,e^{0.09-0.0484}\approx104.25. \end{aligned} \]

median และ mode มาจากไหน:

  • median: Normal สมมาตร median ของ $R$ จึงเท่ากับค่าเฉลี่ย 0.09 ผลลัพธ์ครึ่งหนึ่งมี $R\lt0.09$ และเพราะ $e^x$ เป็นฟังก์ชันเพิ่ม ผลลัพธ์ครึ่งนั้นก็คือครึ่งที่ราคาต่ำกว่า $100e^{0.09}$ พอดี
  • mode (ราคาที่ density สูงที่สุด): ของ lognormal อยู่ที่ $S_0e^{\mu-\sigma^2}$ ดูที่มาในกล่องด้านล่าง
ทำไม mode ของ lognormal คือ $S_0e^{\mu-\sigma^2}$

ให้ $y=\ln(s/S_0)$ density ของราคา $S_T$ ที่ราคา $s$ คือ density ของ Normal ที่ $y$ หารด้วย $s$ (ตัวหารมาจากการเปลี่ยนตัวแปร $dy=ds/s$ ดู lognormal distribution) เมื่อเอา log ของ density และเขียนเป็นฟังก์ชันของ $y$ จะได้ค่าคงที่บวกกับ

\[\begin{aligned}g(y)&=-y-\frac{(y-\mu)^2}{2\sigma^2},\\g'(y)&=-1-\frac{y-\mu}{\sigma^2}=0,\\y&=\mu-\sigma^2.\end{aligned}\]

ตัว $-y$ มาจากการหารด้วย $s=S_0e^y$ เพราะ log ของ $1/s$ คือ $-\ln S_0-y$ และเพราะ $y$ เพิ่มขึ้นตาม $s$ เสมอ จุดสูงสุดในแกน $y$ จึงเป็นจุดเดียวกับจุดสูงสุดในแกน $s$:

\[\begin{aligned}\text{mode}(S_T)&=S_0e^{\mu-\sigma^2}\\&=100e^{0.09-0.0484}\\&=100e^{0.0416}\approx\$104.25\end{aligned}\]

ตัวหาร $s$ นี้เองที่ดึงยอดของ density ให้ต่ำกว่า median: ราคาสูงถูกหารด้วยตัวเลขที่ใหญ่กว่า

คำตอบ: ราคาคาดหมายคือ \$112.10 คิดเป็นผลตอบแทนธรรมดาคาดหมาย $112.10/100-1=12.10\%$

  • คนที่สองได้ \$109.42 ซึ่งคือ median ครึ่งหนึ่งของผลลัพธ์จะจบต่ำกว่า \$109.42 แต่ค่าเฉลี่ยสูงกว่านั้น
  • คนแรกได้ \$109 เพราะเอา log return 9% ไปใช้เป็นผลตอบแทนธรรมดา ซึ่งเป็นตัวแปรคนละชนิดกัน

ตรวจเองใน 10 วินาที: ตัวที่บวกเพิ่มในเลขชี้กำลังคือ $\sigma^2/2=0.0484/2=0.0242$ มันไม่ใช่ส่วนต่างของราคาโดยตรง ส่วนต่างเป็นดอลลาร์ระหว่างค่าเฉลี่ยกับ median คือ

\[\begin{aligned}112.10-109.42&=\$2.68\\&\approx109.42\times(e^{0.0242}-1)\\&=109.42\times0.0245.\end{aligned}\]

ถ้า $\sigma=0$ ราคาไม่สุ่มเลย ค่าเฉลี่ย median และ mode จะเท่ากันที่ $100e^{0.09}=\$109.42$ เพราะเลขชี้กำลังทั้งสามเหลือ 0.09 เท่ากัน

อาจมีคนอ้าง Jensen’s inequality ซึ่งบอกว่าค่าเฉลี่ยของฟังก์ชันที่โค้งขึ้น มากกว่าหรือเท่ากับฟังก์ชันของค่าเฉลี่ย: $\mathbb E[e^R]\ge e^{\mathbb E[R]}$ แต่มันไม่ได้บอกว่ามากกว่าเท่าไร ตัวเลขที่แน่นอน (“บวกครึ่ง variance”) มาจาก Normal MGF โดยเฉพาะ ถ้า $R$ ไม่ใช่ Normal ต้องใช้ MGF ของ distribution นั้นจริง ๆ

ขั้นที่ 6 — drift ของ GBM คืออัตราโตของราคาคาดหมาย

คำถามเปิดดูราคาแค่ตอนปลายปี แต่แบบจำลองราคาหุ้นที่ใช้กันทั่วไปดูราคาต่อเนื่องตลอดเวลา แบบจำลองนั้นชื่อ geometric Brownian motion (GBM) ในขั้นนี้ $t$ คือเวลานับเป็นปี ไม่ใช่ตัวเลขที่ป้อนให้ MGF

ใน GBM ราคา ณ เวลา $t$ เขียนว่า $S_t=S_0e^{(\mu-\sigma^2/2)t+\sigma W_t}$ โดย

  • $\mu$ คือ drift หรืออัตราโตต่อปี และ $\sigma$ คือความผันผวนต่อปี
  • ระวังชื่อซ้ำ: ในขั้นก่อน $\mu$ คือค่าเฉลี่ยของ log return แต่ใน GBM ค่าเฉลี่ยของ log return ต่อปีคือ $\mu-\sigma^2/2$
  • $W_t$ คือ standard Brownian motion การเดินสุ่มแบบต่อเนื่อง ส่วนเพิ่ม $W_{t+s}-W_t$ ในช่วง $s$ ปี เป็น Normal ค่าเฉลี่ยศูนย์ variance $s$
  • ส่วนเพิ่มนั้นไม่ขึ้นกับอะไรที่เกิดก่อนเวลา $t$

หลายคนสงสัยว่า $-\sigma^2/2$ ในเลขชี้กำลังมาจากไหน ขั้นนี้จะตอบ คำถามคือ ถ้าวันนี้ (เวลา $t$) เห็นราคา $S_t$ แล้ว ราคาคาดหมายอีก $s$ ปีข้างหน้าคือเท่าไร เราเขียนค่าเฉลี่ยเมื่อรู้ข้อมูลถึงเวลา $t$ ว่า $\mathbb E_t[\,\cdot\,]$

\[ \begin{aligned} S_{t+s}&=S_t\,e^{(\mu-\sigma^2/2)s+\sigma(W_{t+s}-W_t)},\\ \mathbb E_t[S_{t+s}]&=S_t\,e^{(\mu-\sigma^2/2)s}\,\mathbb E\big[e^{\sigma(W_{t+s}-W_t)}\big]\\ &=S_t\,e^{(\mu-\sigma^2/2)s}\,e^{\sigma^2s/2}\\ &=S_t\,e^{\mu s}. \end{aligned} \]

จุดเริ่มคือหาร $S_{t+s}$ ด้วย $S_t$ ส่วนของ $W$ ที่เกิดก่อนเวลา $t$ หักล้างกันหมด เหลือในเลขชี้กำลังแค่ $(\mu-\sigma^2/2)s$ กับส่วนเพิ่ม $W_{t+s}-W_t$

จุดที่ต้องใช้เหตุผลคือการดึงของออกจากค่าเฉลี่ย เมื่อรู้ข้อมูลวันนี้ $S_t$ และ $e^{(\mu-\sigma^2/2)s}$ ไม่สุ่ม จึงออกมาข้างนอกได้ ส่วนเพิ่มของ $W$ ไม่ขึ้นกับข้อมูลวันนี้ การรู้ข้อมูลวันนี้จึงไม่เปลี่ยนค่าเฉลี่ยของมัน ค่าเฉลี่ยที่เหลือคือ Normal MGF ที่ป้อน 1 ของตัวแปร $\sigma(W_{t+s}-W_t)$ ซึ่งมีค่าเฉลี่ย 0 และ variance $\sigma^2s$ จึงได้ $e^{\sigma^2s/2}$

ผลคือ $-\sigma^2/2$ ที่ใส่ไว้ในเลขชี้กำลังถูกหักล้างพอดี drift $\mu$ จึงเป็นอัตราโตของราคาคาดหมาย ส่วนค่าเฉลี่ยของ log ราคาโตช้ากว่านั้น คือโตที่อัตรา $\mu-\sigma^2/2$ ต่อปี (expected future price)

เทียบกับคำถามเปิด: ค่าเฉลี่ยของ log return หนึ่งปีคือ $\mu-\sigma^2/2=0.09$ และ $\sigma=0.22$ เราจึงหา $\mu$ ได้ แล้วใช้ $\mathbb E[S_s]=S_0e^{\mu s}$ กับ median $S_0e^{(\mu-\sigma^2/2)s}$ ที่ $s=1$ และ $s=2$ ปี

\[\begin{aligned}\mu&=0.09+0.22^2/2=0.1142,\\\mathbb E[S_1]&=100e^{0.1142}\approx\$112.10,\\\mathbb E[S_2]&=100e^{2\times0.1142}\approx\$125.66,\\\operatorname{median}(S_2)&=100e^{2\times0.09}\approx\$119.72.\end{aligned}\]

ปีแรกได้ \$112.10 ตรงกับคำตอบของคำถามเปิด ช่องว่างระหว่างค่าเฉลี่ยกับ median กว้างขึ้นจาก \$2.68 ในปีแรก เป็น $125.66-119.72=\$5.94$ ในปีที่สอง เพราะ variance ของ log return โตตามเวลา ($\sigma^2s$) ตัวที่บวกเพิ่มในเลขชี้กำลัง $\sigma^2s/2$ จึงโตตามไปด้วย

ขั้นที่ 7 — ผลรวมของตัวแปรอิสระ: MGF คูณกัน

บริษัทหนึ่งมีโต๊ะเทรดหลายโต๊ะ ผู้จัดการอยากรู้ว่ากำไรรวมของทุกโต๊ะมี distribution แบบไหน ปกติการหา distribution ของผลรวมต้องทำ convolution คืออินทิกรัลที่ไล่ทุกคู่ค่าที่บวกกันได้ผลรวมเดียวกัน ซึ่งคำนวณยาก MGF ทำให้งานนี้เหลือแค่การคูณ

เหตุผลมีสองข้อ ข้อแรก $e^{t(X+Y)}=e^{tX}e^{tY}$ ข้อสอง ถ้า $X$ กับ $Y$ อิสระกัน (independent คือรู้ค่าหนึ่งแล้วไม่ช่วยทายอีกค่าเลย) $e^{tX}$ กับ $e^{tY}$ ก็อิสระกันด้วย ค่าเฉลี่ยของผลคูณจึงแยกเป็นผลคูณของค่าเฉลี่ยได้ ตามสมบัติของตัวแปรอิสระ

\[ \begin{aligned} M_{X+Y}(t)&=\mathbb E[e^{tX}e^{tY}]\\ &=\mathbb E[e^{tX}]\,\mathbb E[e^{tY}]\\ &=M_X(t)\,M_Y(t),\\ K_{X+Y}(t)&=K_X(t)+K_Y(t). \end{aligned} \]

จุดเดียวที่ใช้ independence คือตอนแยกค่าเฉลี่ยของผลคูณ $\mathbb E[e^{tX}e^{tY}]$ ออกเป็นสองก้อน จุดนี้ต้องการมากกว่า covariance ศูนย์ เพราะ covariance ศูนย์รับประกันแค่ $\mathbb E[XY]=\mathbb E[X]\,\mathbb E[Y]$ ไม่ได้รับประกันสำหรับ $e^{tX}$ กับ $e^{tY}$ โจทย์ข้อ 3 ท้ายหน้ามีตัวอย่างที่การคูณให้ผลผิด

ฝั่ง CGF ผลคูณกลายเป็นผลบวก เพราะ log ของผลคูณคือผลบวกของ log

ตัวอย่าง: สองโต๊ะเทรดที่อิสระกัน P&L หนึ่งวันของแต่ละโต๊ะเป็น Normal (ตัวเลขสมมติ)

  • โต๊ะแรก $X$: ค่าเฉลี่ย \$50 SD \$220
  • โต๊ะที่สอง $Y$: ค่าเฉลี่ย \$25 SD \$180

P&L รวม $X+Y$ เป็น distribution อะไร คูณ MGF ของสองโต๊ะแล้วรวมเลขชี้กำลัง:

\[ \begin{aligned} M_X M_Y&=e^{50t+220^2t^2/2}\,e^{25t+180^2t^2/2}\\ &=e^{(50+25)t+(220^2+180^2)t^2/2}\\ &=e^{75t+80{,}800\,t^2/2},\\ \operatorname{SD}(X+Y)&=\sqrt{80{,}800}\approx284.25. \end{aligned} \]

ผลคูณออกมาหน้าตาเหมือน Normal MGF ที่ค่าเฉลี่ย 75 และ variance $220^2+180^2=48{,}400+32{,}400=80{,}800$ ทุก $t$ ทฤษฎีเอกลักษณ์ (MGF เหมือนลายนิ้วมือ) จึงบอกว่า P&L รวมเป็น Normal ค่าเฉลี่ย \$75 SD \$284.25 ได้ทั้ง distribution ไม่ใช่แค่ค่าเฉลี่ยกับ variance

สังเกตว่า SD ไม่ได้บวกกันตรง ๆ ($220+180=400$) สิ่งที่บวกกันคือ variance ถ้าสองโต๊ะมี correlation (ขยับไปด้วยกัน) ต้องใช้ MGF หลายตัวแปรในขั้นถัดไปแทน

ขั้นที่ 8 — MGF ของ multivariate Normal

พอร์ตจริงถือหุ้นหลายตัวพร้อมกัน และหุ้นเหล่านั้นขยับไปด้วยกันบ้าง เราเรียง log return ของหุ้นแต่ละตัวเป็น vector $X$ และสมมติว่า $X$ เป็น multivariate Normal (MVN) ที่มี vector ค่าเฉลี่ย $\mu$ และ covariance matrix $\Sigma$

MGF ของ vector ต้องป้อน vector $s$ แทนตัวเลขเดียว $t$ มีหนึ่งค่าต่อหุ้นหนึ่งตัว และใช้ $s^{\mathsf T}X=\sum_is_iX_i$ ในเลขชี้กำลัง วิธีหาคือเขียน $X=\mu+LZ$ ตามการสร้าง MVN โดย

  • $Z$ คือ vector ของ standard Normal ที่อิสระกันทุกตัว
  • $L$ คือ matrix ที่ $LL^{\mathsf T}=\Sigma$

แล้วตั้ง $a=L^{\mathsf T}s$ เพื่อให้เลขชี้กำลังกลายเป็นผลรวมของตัวแปรอิสระ ซึ่งใช้ MGF ตัวแปรเดียวได้ทีละตัว

\[ \begin{aligned} M_X(s)&:=\mathbb E[e^{s^{\mathsf T}X}]\\ &=e^{s^{\mathsf T}\mu}\,\mathbb E[e^{a^{\mathsf T}Z}]\\ &=e^{s^{\mathsf T}\mu}\prod_jM_{Z_j}(a_j)\\ &=e^{s^{\mathsf T}\mu+\frac12\sum_ja_j^2},\\ \textstyle\sum_ja_j^2&=s^{\mathsf T}LL^{\mathsf T}s=s^{\mathsf T}\Sigma s,\\ M_X(s)&=e^{s^{\mathsf T}\mu+\frac12s^{\mathsf T}\Sigma s}. \end{aligned} \]

ทริกของขั้นนี้คือการย้าย $L$ ไปอยู่กับ $s$: $s^{\mathsf T}LZ=(L^{\mathsf T}s)^{\mathsf T}Z=a^{\mathsf T}Z=\sum_ja_jZ_j$ ตอนนี้เลขชี้กำลังเป็นผลรวมของ standard Normal ที่อิสระกัน ค่าเฉลี่ยของ $e^{\sum_ja_jZ_j}$ จึงแยกเป็นผลคูณ และแต่ละตัวคือ $M_{Z_j}(a_j)=e^{a_j^2/2}$ จากขั้น Normal MGF

สูตรสุดท้ายมีหน้าตาเหมือน Normal MGF ตัวแปรเดียวที่ป้อน 1 จึงบอกว่า $s^{\mathsf T}X$ เป็น Normal ค่าเฉลี่ย $s^{\mathsf T}\mu$ และ variance $s^{\mathsf T}\Sigma s$ ถ้า $s$ คือน้ำหนักของพอร์ต นี่ก็คือ ความเสี่ยงของพอร์ต $w^{\mathsf T}\Sigma w$

สูตรนี้ไม่มี inverse หรือ determinant ของ $\Sigma$ จึงใช้ได้แม้ $\Sigma$ เป็น singular (เช่นมีหุ้นสองตัวที่ขยับเหมือนกันทุกอย่าง) และเป็นเครื่องมือที่ใช้พิสูจน์ว่า marginal และ linear combination ของ MVN เป็น Normal

gradient และ Hessian เก็บอะไรไว้
\[ \begin{aligned} K_X(s)&=s^{\mathsf T}\mu+\tfrac12s^{\mathsf T}\Sigma s,\\ \nabla K_X(s)&=\mu+\Sigma s,\\ \nabla^2K_X(s)&=\Sigma,\\ \nabla^2M_X(0)&=\Sigma+\mu\mu^{\mathsf T}=\mathbb E[XX^{\mathsf T}]. \end{aligned} \]

เหมือนกรณีตัวแปรเดียว: Hessian (matrix ของ derivative ลำดับสอง) ของ CGF ที่ $s=0$ คือ covariance matrix โดยตรง ส่วน Hessian ของ MGF ที่ $s=0$ คือ $\mathbb E[XX^{\mathsf T}]$ ซึ่งยังไม่ได้หัก $\mu\mu^{\mathsf T}$ ออก

ตัวอย่างการใช้งาน: พอร์ตถือหุ้นสองตัว เงินในพอร์ตโตตาม gross return $G_i=e^{X_i}$ (ราคาปลายปีหารด้วยราคาวันนี้ของหุ้นตัวที่ $i$) ความเสี่ยงของพอร์ตจึงขึ้นกับ covariance ของ $G_1$ กับ $G_2$ แต่ข้อมูลที่ทีมมีเป็นของ log return $X_i$ เราจะใช้ MGF แปลงจากอย่างหนึ่งไปอีกอย่าง ของที่รู้ (ตัวเลขสมมติ):

  • ค่าเฉลี่ยของ log return หนึ่งปี $\mu=(0.05,\ 0.08)$
  • covariance matrix $\Sigma=\begin{bmatrix}0.04&0.01\\0.01&0.09\end{bmatrix}$ คือ variance 0.04 (SD 20%) สำหรับหุ้นตัวแรก variance 0.09 (SD 30%) สำหรับตัวที่สอง และ covariance $\Sigma_{12}=0.01$

เลือก $s$ ให้ $s^{\mathsf T}X$ เป็นสิ่งที่ต้องการ: $s=(1,0)$ ให้ $e^{X_1}=G_1$ จึงได้ $\mathbb E[G_1]=M_X(1,0)$ ทำนองเดียวกัน $\mathbb E[G_2]=M_X(0,1)$ และ $s=(1,1)$ ให้ $e^{X_1+X_2}=G_1G_2$ จึงได้ $\mathbb E[G_1G_2]=M_X(1,1)$ แต่ละค่าคือ $e^{s^{\mathsf T}\mu+\frac12s^{\mathsf T}\Sigma s}$ แล้วใช้ $\operatorname{Cov}(G_1,G_2)=\mathbb E[G_1G_2]-\mathbb E[G_1]\,\mathbb E[G_2]$

\[ \begin{aligned} \mathbb E[G_1]&=e^{0.05+0.04/2}=e^{0.07}\approx1.0725,\\ \mathbb E[G_2]&=e^{0.08+0.09/2}=e^{0.125}\approx1.1331,\\ \mathbb E[G_1G_2]&=e^{0.13+0.15/2}=e^{0.205}\approx1.2275,\\ \operatorname{Cov}(G_1,G_2)&=1.2275-1.0725\times1.1331\\ &\approx0.0122. \end{aligned} \]

สำหรับ $s=(1,\ 1)$ ค่า $s^{\mathsf T}\mu=0.05+0.08=0.13$ และ $s^{\mathsf T}\Sigma s=0.04+0.09+2(0.01)=0.15$ ครึ่งหนึ่งคือ 0.075 ตัว $2(0.01)$ คือที่ที่ covariance ของสองหุ้นเข้ามา

covariance มาจากไหนกันแน่? ผลคูณของค่าเฉลี่ยคือ $e^{0.07}e^{0.125}=e^{0.195}$ ส่วนค่าเฉลี่ยของผลคูณคือ $e^{0.205}$ ทั้งสองต่างกันด้วยตัวคูณ $e^{0.205-0.195}=e^{0.01}=e^{\Sigma_{12}}$ พอดี เพราะครึ่งหนึ่งของ $2\Sigma_{12}$ คือ $\Sigma_{12}$ ส่วนที่เหลือของเลขชี้กำลังอยู่ใน $\mathbb E[G_1]$ และ $\mathbb E[G_2]$ อยู่แล้ว จึงได้สูตรทั่วไป

$\operatorname{Cov}(G_1,G_2)=\mathbb E[G_1]\,\mathbb E[G_2]\,(e^{\Sigma_{12}}-1)$ ตรวจ: $e^{0.195}(e^{0.01}-1)\approx1.2153\times0.01005\approx0.0122$ ตรงกับข้างบน สูตรนี้ใช้แปลง covariance ของ log return เป็น covariance ของ gross return

ขั้นที่ 9 — ตรวจก่อนว่า MGF มีค่า

ทุกขั้นข้างบนสมมติว่า $\mathbb E[e^{tX}]$ เป็นตัวเลขจำกัด แต่ไม่จริงเสมอไป ถ้าค่าสุดขั้วของ $X$ เกิดได้บ่อยพอ (หางหนา) $e^{tX}$ จะโตเร็วจนค่าเฉลี่ยเป็นอนันต์

ตัวอย่างง่ายที่สุดคือ Exponential distribution ที่อัตรา $\lambda$ ใช้แทนเวลารอจนเหตุการณ์ถัดไปเกิด เช่นเวลารอจนคำสั่งซื้อขายถัดไปเข้ามา density ของมันคือ $\lambda e^{-\lambda x}$ เมื่อ $x\ge0$ และค่าเฉลี่ยคือ $1/\lambda$

\[ \begin{aligned} M_X(t)&=\int_0^{\infty}e^{tx}\lambda e^{-\lambda x}\,dx\\ &=\lambda\int_0^{\infty}e^{-(\lambda-t)x}\,dx,\\ t\lt\lambda:\quad M_X(t)&=\frac{\lambda}{\lambda-t},\\ t\ge\lambda:\quad M_X(t)&=\infty. \end{aligned} \]

ทุกอย่างขึ้นกับเครื่องหมายของ $\lambda-t$ ในเลขชี้กำลัง ถ้า $t\lt\lambda$ เลขชี้กำลังยังติดลบ integrand ลดลงเร็วพอจนพื้นที่จำกัด และอินทิกรัลได้ $\lambda/(\lambda-t)$ ถ้า $t=\lambda$ integrand เป็นค่าคงที่ $\lambda$ ไปตลอดครึ่งเส้นจำนวน พื้นที่จึงเป็นอนันต์ ถ้า $t\gt\lambda$ integrand ยิ่งโตขึ้นเรื่อย ๆ

ตัวอย่างตัวเลข: ที่ $\lambda=2$ ได้ $M(1)=2/(2-1)=2$ แต่ $M(2)$ เป็นอนันต์ ไม่ใช่ตัวเลขที่เอาไปใช้ต่อได้ ส่วน Normal MGF มีค่าทุก $t$ เพราะหาง $e^{-x^2/2}$ ลดลงเร็วกว่า $e^{tx}$ โตขึ้น ไม่ว่า $t$ จะใหญ่แค่ไหน

ถ้าหางหนากว่านั้นอีก MGF จะไม่มีค่าเลยในฝั่ง $t\gt0$ มีสองตัวอย่างที่ควรรู้:

  • Student-t (รูประฆังที่หางหนากว่า Normal ใช้แทนผลตอบแทนที่มีวันช็อกบ่อยกว่าที่ Normal คาด) ไม่มี MGF รอบศูนย์ แม้เลือก degrees of freedom $\nu$ (ตัวเลขที่คุมความหนาของหาง) มากพอให้มี variance ก็ตาม เพราะหางของมันลดลงแบบพหุนาม คือเหมือน $1/|x|^{\nu+1}$ ซึ่งแพ้ $e^{tx}$ เสมอ
  • ตัวราคา lognormal $Y=e^Z$ มี moment ทุกลำดับ เพราะ $\mathbb E[Y^k]=\mathbb E[e^{kZ}]=M_Z(k)=e^{k^2/2}$ แต่ $\mathbb E[e^{tY}]=\mathbb E[e^{te^Z}]=\infty$ ทุก $t\gt0$ เพราะเลขชี้กำลัง $te^z$ โตเร็วกว่า $z^2/2$ ที่ density หักออก

ข้อหลังไม่ขัดกับคำถามเปิด เพราะที่นั่นเราใช้ MGF ของ log return $R$ ซึ่งเป็น Normal ไม่ใช่ MGF ของตัวราคา $S_T$

เมื่อ MGF ไม่มีค่า ทางออกคือ characteristic function $\mathbb E[e^{iuX}]$ โดย $i=\sqrt{-1}$ มันมีค่าเสมอ เพราะ $|e^{iuX}|=1$ ไม่ว่า $X$ จะใหญ่แค่ไหน และเป็นเครื่องมือหลักของ Fourier pricing

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

  • อ่าน $M''(0)$ เป็น variance: $M''(0)$ คือ $\mathbb E[X^2]$ ไม่ใช่ variance กับ P&L ที่ค่าเฉลี่ย \$75 SD \$300 ค่าที่ผิดคือ $M''(0)=95{,}625$ ดอลลาร์² หรือ SD $\sqrt{95{,}625}\approx\$309$ ค่าที่ถูกคือ $M''(0)-[M'(0)]^2=95{,}625-75^2=90{,}000$ ดอลลาร์² หรือ SD \$300 ได้เท่ากันจาก $K''(0)$
  • ใส่ค่าเฉลี่ยลงใน exponential: $e^{\mathbb E[R]}$ ไม่ใช่ $\mathbb E[e^R]$ ค่าที่ผิดคือ $100e^{0.09}=\$109.42$ ซึ่งเป็น median ค่าที่ถูกคือ $100e^{0.09+0.0242}=\$112.10$ และกฎ “บวกครึ่ง variance” ใช้ได้เมื่อ $R$ เป็น Normal เท่านั้น
  • คิดว่า $M_R(-1)$ คือผลตอบแทนของการ short: การ short คือยืมหุ้นมาขายวันนี้แล้วซื้อคืนปลายปี กำไรต่อหุ้นคือ $S_0-S_T$ ไม่ใช่ $S_0/S_T$ ค่าที่ผิดคือ $\mathbb E[e^{-R}]=e^{-0.09+0.0242}\approx0.936$ ซึ่งเป็นค่าเฉลี่ยของ $S_0/S_T$ ค่าที่ถูกคือ $\mathbb E[S_0-S_T]=100-112.10=-\$12.10$ ก่อนหักต้นทุนยืมหุ้น
  • คิดว่า $M_R(1)M_R(-1)=1$: แม้ $e^R\cdot e^{-R}=1$ แต่ $M_R(1)M_R(-1)=e^{0.1142}e^{-0.0658}=e^{0.0484}\approx1.0496$ เพราะค่าเฉลี่ยของผลคูณไม่เท่ากับผลคูณของค่าเฉลี่ย เมื่อ $e^R$ กับ $e^{-R}$ ไม่อิสระกัน
  • คูณ MGF ของตัวแปรที่ไม่อิสระ: covariance ศูนย์ไม่พอ ในโจทย์ข้อ 3 ด้านล่าง ($X$ กับ $WX$) การคูณให้ $e^{1/2}e^{1/2}\approx2.72$ แต่ค่าจริงคือ $(1+e^2)/2\approx4.19$
  • ลืมหน่วยของ $t$: ถ้า $X$ เป็นดอลลาร์ (ค่าเฉลี่ย \$75 SD \$300) แล้วป้อน $t=1$ จะได้ $M_X(1)=e^{75+300^2/2}=e^{75+45{,}000}$ ซึ่งไม่มีความหมายทางการเงินและล้นเครื่องคำนวณ ต้องเลือก $t$ ให้ $tX$ ไม่มีหน่วย เช่นเปลี่ยนหน่วยเป็นพันดอลลาร์แบบโจทย์ข้อ 2

โจทย์ตรวจความเข้าใจ

1. นักวิเคราะห์สองคนใช้แบบจำลองต่างกันสำหรับ log return หนึ่งปีที่ถูกปรับให้ค่าเฉลี่ยเป็นศูนย์และ variance เป็นหนึ่ง (ตัวเลขสมมติ เลือกให้คำนวณง่าย)

  • คนแรกใช้ $A$ ซึ่งเป็น $-1$ หรือ $+1$ อย่างละครึ่ง เหมือนโยนเหรียญ
  • คนที่สองใช้ $B$ ซึ่งเป็น standard Normal

ทั้งคู่มีค่าเฉลี่ยศูนย์และ variance หนึ่งเท่ากัน gross return เฉลี่ย $\mathbb E[e^A]$ กับ $\mathbb E[e^B]$ เท่ากันไหม

ไม่เท่ากัน ตรวจก่อนว่า $A$ มี variance หนึ่งจริง: $\mathbb E[A^2]=\tfrac12(1)+\tfrac12(1)=1$ จากนั้นคำนวณ MGF ที่ $t=1$ ของทั้งสองตัว

\[\begin{aligned}M_A(1)&=\tfrac12e^{1}+\tfrac12e^{-1}\approx1.5431,\\M_B(1)&=e^{0+1/2}\approx1.6487,\\\frac{M_B(1)}{M_A(1)}&\approx1.068.\end{aligned}\]

ค่าเฉลี่ยกับ variance ที่เท่ากันไม่ได้ทำให้ MGF ทั้งเส้นเท่ากัน ถ้าโลกจริงเป็นแบบ $A$ แต่ใช้สูตร “บวกครึ่ง variance” ของ Normal จะได้ราคาคาดหมายสูงเกินไป $1.068-1=6.8\%$ เพราะ $B$ มีหางยาวกว่า และ exponential ขยายค่าในหางขวาให้ใหญ่ขึ้นมาก

2. ทีมความเสี่ยงอยากรายงาน P&L เป็นพันดอลลาร์แทนดอลลาร์ เพื่อให้ป้อน $t=1$ ได้โดยไม่ล้น P&L $X$ เป็น Normal ค่าเฉลี่ย \$75 SD \$300 ตัวแปรใหม่คือ $Y=X/1000$ (หน่วยพันดอลลาร์) MGF ของ $Y$ เขียนด้วย $M_X$ ได้อย่างไร raw second moment $\mathbb E[Y^2]$ และ $M_Y(1)$ เป็นเท่าไร

เฉลย

MGF ของ $Y$ คือ MGF ของ $X$ ที่ป้อนตัวเลขเล็กลงพันเท่า: $M_Y(u)=\mathbb E[e^{uX/1000}]=M_X(u/1000)$

ค่าเฉลี่ยและ SD ของ $Y$ หารด้วย 1000 ทั้งคู่ คือ $75/1000=0.075$ และ $300/1000=0.3$

\[\begin{aligned}\operatorname{Var}(Y)&=0.3^2=0.09,\\\mathbb E[Y^2]&=0.09+0.075^2\\&=0.09+0.005625=0.095625,\\M_Y(1)&=e^{0.075+0.09/2}\\&=e^{0.12}\approx1.1275.\end{aligned}\]

ตรวจ: $0.095625$ คือ $95{,}625/1000^2$ ตรงกับ $M_X''(0)$ ในขั้น CGF การเปลี่ยนหน่วยแค่ยืดแกน $t$ ไม่ได้เปลี่ยน P&L จริง

3. ตัวอย่างนี้สร้างขึ้นเพื่อดูว่า covariance ศูนย์พอสำหรับการคูณ MGF หรือไม่ (ตัวอย่างที่ marginal เป็น Normal แต่ไม่ jointly Normal)

  • $X$ เป็น standard Normal
  • $W$ เป็น $+1$ หรือ $-1$ อย่างละครึ่ง และอิสระจาก $X$
  • $Y=WX$ คือ $X$ ที่ถูกสุ่มกลับเครื่องหมาย

$Y$ เป็น standard Normal เหมือน $X$ (เพราะ Normal สมมาตร) และ covariance ของ $X$ กับ $Y$ เป็นศูนย์ จะคูณ MGF ของ $X$ กับ $Y$ เพื่อหา $\mathbb E[e^{X+Y}]$ ได้ไหม

เฉลย

ก่อนอื่นยืนยันว่า covariance เป็นศูนย์จริง: $\operatorname{Cov}(X,Y)=\mathbb E[WX^2]=\mathbb E[W]\,\mathbb E[X^2]=0\times1=0$

คำตอบคือคูณไม่ได้ เมื่อ $W=-1$ จะได้ $X+Y=0$ และเมื่อ $W=1$ จะได้ $X+Y=2X$ ค่าเฉลี่ยจึงเป็นครึ่งหนึ่งของแต่ละกรณีรวมกัน โดยใช้ $M_X(2)=e^{2^2/2}=e^2$

\[\begin{aligned}\mathbb E[e^{X+Y}]&=\tfrac12e^{0}+\tfrac12M_X(2)\\&=\tfrac{1+e^2}2\approx4.1945,\\M_X(1)\,M_Y(1)&=e^{1/2}e^{1/2}=e\approx2.7183.\end{aligned}\]

การคูณให้ค่าต่ำไป $1-2.7183/4.1945\approx35\%$ ความต่างนี้มาจากความสัมพันธ์ที่ covariance มองไม่เห็น: $|X|$ กับ $|Y|$ เท่ากันเสมอ ตัวแปรสองตัวจึงไม่อิสระกัน แม้ covariance เป็นศูนย์

const mgfEqual = (t, xs) => xs.reduce((s, x) => s + Math.exp(t * x), 0) / xs.length;
const cards = [1, 2, 3], h = 1e-4;
const d1 = (mgfEqual(h, cards) - mgfEqual(-h, cards)) / (2 * h);
const d2 = (mgfEqual(h, cards) - 2 + mgfEqual(-h, cards)) / (h * h);
console.log(d1, d2, d2 - d1 * d1);                       // 2 4.667 0.667

// Normal MGF และ CGF
const normalMGF = (t, m, v) => Math.exp(m * t + 0.5 * v * t * t);
console.log(300 ** 2 + 75 ** 2, 300 ** 2);               // 95625 90000

// คำถามเปิด: ราคาคาดหมาย median และ mode

console.log(100 * normalMGF(1, m, v), 100 * Math.exp(m), 100 * Math.exp(m - v));  // 112.10 109.42 104.25

// GBM: drift mu = m + v/2, ราคาคาดหมายสองปี เทียบ median
const mu = m + v / 2;
console.log(mu, 100 * Math.exp(2 * mu), 100 * Math.exp(2 * m));                     // 0.1142 125.66 119.72

// ผลรวมอิสระของสอง desk

// MGF หลายตัวแปร: covariance ของ gross return
const M2 = (s, mvec, S) => Math.exp(s[0] * mvec[0] + s[1] * mvec[1] +

สิ่งที่ควรตอบได้หลังอ่าน

  • MGF คือค่าเฉลี่ย $\mathbb E[e^{tX}]$ ไม่ใช่ density และ $t$ คือตัวเลขที่ป้อน ไม่ใช่เวลา ถ้ามันมีค่าจำกัดรอบ $t=0$ จะได้ $M^{(k)}(0)=\mathbb E[X^k]$ และ variance คือ $M''(0)-[M'(0)]^2$ หรือ $K''(0)$ ตรง ๆ
  • พิสูจน์ Normal MGF $e^{\mu t+\sigma^2t^2/2}$ ด้วยการจัดกำลังสองสมบูรณ์ได้ และอธิบายด้วยภาพได้ว่า $e^{tz}\phi(z)$ คือระฆังรูปเดิมที่เลื่อนไปและใหญ่ขึ้น $e^{t^2/2}$ เท่า
  • เมื่อ log return $R$ เป็น Normal ราคาคาดหมายคือ $S_0e^{\mathbb E[R]+\operatorname{Var}(R)/2}$ ส่วน $S_0e^{\mathbb E[R]}$ คือ median ในคำถามเปิดได้ \$112.10 เทียบกับ \$109.42 และใน GBM ได้ $\mathbb E_t[S_{t+s}]=S_te^{\mu s}$
  • MGF ของผลรวมของตัวแปรอิสระคือผลคูณของ MGF แต่ต้องอิสระกันจริง covariance ศูนย์อย่างเดียวไม่พอ
  • MGF ของ MVN คือ $e^{s^{\mathsf T}\mu+\frac12s^{\mathsf T}\Sigma s}$ ใช้หาค่าเฉลี่ยของผลคูณ gross return ได้ และให้สูตร covariance $\mathbb E[G_1]\,\mathbb E[G_2](e^{\Sigma_{12}}-1)$
  • ตรวจว่า MGF มีค่าก่อนใช้: ของ Exponential เป็นอนันต์ตั้งแต่ $t=\lambda$ ส่วน Student-t และตัวราคา lognormal ไม่มี MGF ฝั่ง $t\gt0$ เลย ต้องใช้ characteristic function แทน

หน้าถัดไป marginal ของ multivariate Normal จะใช้ MGF หลายตัวแปรนี้พิสูจน์ว่า ถ้าเลือกเก็บแค่บางส่วนของ vector ที่เป็น MVN ส่วนนั้นยังเป็น Normal และใช้แค่ $\mu$ กับ $\Sigma$ เฉพาะส่วนที่เก็บไว้
