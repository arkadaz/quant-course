12.3 The Hessian and Second-Order Conditions

gradient เป็นศูนย์บอกแค่ว่าพื้นราบ ความโค้งในทุกทิศซึ่งเก็บอยู่ใน Hessian เป็นตัวตัดสินว่าจุดนั้นเป็นก้นหลุม ยอดโดม หรืออานม้า

ระบบจัดพอร์ตของโต๊ะแก้สมการ “gradient ของ objective เป็นศูนย์” ให้พอร์ตหุ้น (ผลตอบแทนคาดหวัง 12% ต่อปี ความผันผวน 20%) กับพันธบัตร (6%, 10%) correlation 0.30 และมีเงินสดให้ฝากหรือกู้ที่ 2% ต่อปี นักวิเคราะห์คนแรกใส่ความกลัวความเสี่ยง $\gamma=2$ ได้หุ้น 52.2% พันธบัตร 68.7% อีกคนใช้ library ที่นิยามเครื่องหมายกลับกัน จึงเผลอใส่ $\gamma=-2$ ได้หุ้น −52.2% พันธบัตร −68.7% ทั้งสองจอขึ้นว่า gradient = 0 ทั้งสองคือพอร์ตที่ดีที่สุดของ objective ตัวเองใช่ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ใช่ พอร์ตแรกเป็นยอดสูงสุดของทั้งพื้นผิว ค่าเป้าหมาย 0.0598 เพราะความโค้งของมันคือ $-4V$ ซึ่งคว่ำลงทุกทิศ พอร์ตที่สองเป็นจุดต่ำสุดของ objective ตัวเอง ค่า −0.0198 เพราะความโค้ง $+4V$ หงายขึ้นทุกทิศ และ objective นั้นไม่มีจุดสูงสุดเลย ยิ่งกู้มาซื้อหุ้นมากค่ายิ่งสูง ความชันศูนย์แยกสองกรณีนี้ไม่ออก ความโค้งแยกได้ในบรรทัดเดียว

ภาพรวมก่อนลงสูตร

ที่จุดราบ พื้นแบนทุกทิศในระดับความชัน สิ่งที่เหลือให้ดูคือความโค้ง: ถ้าก้าวออกไปทิศไหนแล้วพื้นโค้งขึ้น ทิศนั้นปลอดภัย ถ้ามีแม้แต่ทิศเดียวที่โค้งลง จุดนั้นไม่ใช่ก้นหลุม ในตัวแปรเดียวมีแค่ $f''$ ตัวเดียว แต่ในหลายตัวแปรความโค้งเปลี่ยนตามทิศที่ก้าว เราเก็บความโค้งทุกทิศไว้ใน matrix ตัวเดียวชื่อ Hessian

รูปด้านล่างคือสามรูปทรงที่ Hessian แยกได้ ก้นหลุมโค้งขึ้นทุกทิศ เส้นระดับเป็นวงรีปิด อานม้าโค้งขึ้นทิศหนึ่งแต่ลงอีกทิศ เส้นระดับเปิดออกเป็นกากบาท และสันแบนโค้งลงด้านข้างแต่แบนสนิทตามแนวสัน ซึ่งเป็นกรณีที่คำตัดสินจากความโค้งอย่างเดียวยังไม่พอ ทั้งสามรูปใช้ Hessian จริงที่จะเจอในหน้านี้

หน้านี้นิยาม Hessian พิสูจน์ว่าทำไมความโค้งเป็นตัวตัดสิน สร้างเกณฑ์ 2×2 ที่ตรวจมือได้ ทดลองกับพื้นผิวที่มีทั้งอานม้าและก้นหลุม ดูว่าก้นหลุมเฉพาะถิ่นไม่ใช่ก้นของทั้งพื้นผิว แล้วกลับมาที่พอร์ต ซึ่ง Hessian คงที่ทั้งพื้นผิว จึงตัดสินได้ทั้งแผนที่ในครั้งเดียว ปิดด้วยสิ่งที่ eigenvalue ตัวเล็กบอกเกี่ยวกับความไวของคำตอบต่อ input ที่ผิด

ขั้นที่ 1 — นิยามของ Hessian: ความชันของความชัน

หนึ่งมิติมี $f''$ ตัวเดียว สองมิติมีสี่แบบ เพราะหา derivative ครั้งแรกเทียบตัวไหน ครั้งที่สองเทียบตัวไหนก็ได้ บรรทัดนี้เป็นนิยาม (สำหรับ $n$ ตัวแปรก็เรียงแบบเดียวกันเป็นตาราง $n\times n$)

\[ \begin{aligned} H(x)&=\begin{bmatrix}\dfrac{\partial^2 f}{\partial x_1^2}&\dfrac{\partial^2 f}{\partial x_1\partial x_2}\\[8pt]\dfrac{\partial^2 f}{\partial x_2\partial x_1}&\dfrac{\partial^2 f}{\partial x_2^2}\end{bmatrix}. \end{aligned} \]

ช่องทแยงคือความโค้งตามแต่ละแกน ช่องนอกทแยงคือความโค้งไขว้ คือความชันตาม $x_1$ เปลี่ยนเท่าไรเมื่อขยับ $x_2$ ถ้า derivative อันดับสองต่อเนื่อง ลำดับการหาไม่มีผล สองช่องนอกทแยงจึงเท่ากันและ $H$ สมมาตร ซึ่งทำให้ eigenvalues เป็นจำนวนจริงทุกตัว (eigenvalues และ positive definiteness) สำหรับ variance ของพอร์ต $x^{\mathsf T}Vx$ ซึ่ง gradient คือ $2Vx$ (gradient และเงื่อนไขอันดับหนึ่ง) หาอนุพันธ์อีกครั้งได้ $H=2V$ ทันที

ขั้นที่ 2 — ทำไมความโค้งเป็นตัวตัดสิน

ต้องการรู้ว่าเดินจาก $x$ ไป $x+z$ แล้ว $f$ เปลี่ยนเท่าไร วิธีคือยุบให้เหลือตัวแปรเดียว: มองค่าบนทางเดินเป็น function ของเวลา $t$ แล้วใช้ Taylor ของตัวแปรเดียวแบบมีเศษ

\[ \begin{aligned} g(t)&=f(x+tz),\qquad0\le t\le1,\\ g'(t)&=\nabla f(x+tz)^{\mathsf T}z,\\ g''(t)&=z^{\mathsf T}H(x+tz)\,z,\\ g(1)&=g(0)+g'(0)+\tfrac12g''(\tau),\quad0\lt\tau\lt1,\\ f(x+z)&=f(x)+\nabla f(x)^{\mathsf T}z\\ &\quad+\tfrac12\,z^{\mathsf T}H(x+\tau z)\,z. \end{aligned} \]

บรรทัดที่สองคือ chain rule: ขยับ $t$ นิดหนึ่ง ตัวแปรแต่ละตัวขยับ $z_i$ เท่า บรรทัดที่สามทำซ้ำอีกรอบ ได้ derivative อันดับสองของทุกคู่คูณ $z_iz_j$ ซึ่งคือ $z^{\mathsf T}Hz$ บรรทัดที่สี่คือ Taylor ที่เศษเขียนเป็น $g''$ ที่จุดกลางทางจุดหนึ่ง เลข ½ จึงมาจาก Taylor ไม่ได้ถูกเสกขึ้น

ที่จุดราบ $\nabla f=0$ ผลเปลี่ยนเหลือแค่ $\tfrac12z^{\mathsf T}Hz$ ถ้า $H(x)$ เป็นบวกทุกทิศ (positive definite) ความต่อเนื่องทำให้ใกล้ ๆ ก็ยังบวก ทุกก้าวเล็กจึงขึ้น: ก้นหลุม ถ้ามีทิศที่ $z^{\mathsf T}Hz\lt0$ ก้าวทิศนั้นแล้วลง: ไม่ใช่ก้นหลุม ถ้าบางทิศได้ศูนย์พอดี ทิศนั้นต้องดูอันดับที่สูงกว่า

ขั้นที่ 3 — เกณฑ์ 2×2 ที่ตรวจด้วยมือ

เหลือคำถามเดียว: $z^{\mathsf T}Hz$ เป็นบวกทุกทิศไหม เขียน $H=\begin{bmatrix}a&b\\b&c\end{bmatrix}$ แล้วจัดกำลังสองสมบูรณ์ (สมมติ $a\ne0$) เพื่อแยกเป็นสองก้อนที่ดูเครื่องหมายได้ทันที

\[ \begin{aligned} z^{\mathsf T}Hz&=az_1^2+2bz_1z_2+cz_2^2\\ &=a\Big(z_1+\tfrac{b}{a}z_2\Big)^2+\Big(c-\tfrac{b^2}{a}\Big)z_2^2\\ &=D_1\Big(z_1+\tfrac{b}{a}z_2\Big)^2+\frac{D_2}{D_1}\,z_2^2,\\ D_1&=a,\qquad D_2=ac-b^2. \end{aligned} \]

บรรทัดที่สองกางกลับได้ตรวจเอง: $a(z_1+\tfrac baz_2)^2=az_1^2+2bz_1z_2+\tfrac{b^2}{a}z_2^2$ จึงต้องหัก $\tfrac{b^2}{a}z_2^2$ คืน ตอนนี้อ่านคำตัดสินได้จากเครื่องหมายของสองตัวคูณ $D_1$ กับ $D_2/D_1$

$D_1\gt0$ และ $D_2\gt0$: บวกทั้งคู่ ก้นหลุม $D_1\lt0$ และ $D_2\gt0$: ลบทั้งคู่ ยอดโดม $D_2\lt0$: สองก้อนต่างเครื่องหมาย มีทิศขึ้นและทิศลง อานม้า $D_2=0$: มีทิศที่ความโค้งเป็นศูนย์ เกณฑ์นี้ตัดสินไม่ได้ ซึ่งคือช่องสันแบนในรูปภาพรวม

ตรวจด้วย eigenvalues อีกทาง: $\lambda^2-(a+c)\lambda+D_2=0$ ผลคูณของสองรากคือ $D_2$ ผลบวกคือ trace $a+c$ ถ้า $D_2\lt0$ สองรากต่างเครื่องหมายแน่นอน ถ้า $D_2\gt0$ เครื่องหมายเดียวกันและตามเครื่องหมายของ trace สองวิธีต้องตอบตรงกันเสมอ ถ้าขัดกันแปลว่าคิดเลขผิด

ขั้นที่ 4 — พื้นผิวทดสอบ: หาจุดราบสองจุด แล้วจับอานม้าที่ A

ใช้พื้นผิวที่คิดมือได้ $f=x_1^2+3x_1x_2+x_2^3$ พจน์กำลังสามทำให้ความโค้งเปลี่ยนตามตำแหน่ง หา partial derivative แล้วตั้งให้เป็นศูนย์พร้อมกัน

\[ \begin{aligned} \frac{\partial f}{\partial x_1}&=2x_1+3x_2=0,\\ x_1&=-1.5x_2,\\ \frac{\partial f}{\partial x_2}&=3x_1+3x_2^2=0,\\ 3(-1.5x_2)+3x_2^2&=x_2\,(3x_2-4.5)=0,\\ A&=(0,\ 0),\qquad B=(-2.25,\ 1.5),\\ H(x)&=\begin{bmatrix}2&3\\3&6x_2\end{bmatrix},\\ H(A)&=\begin{bmatrix}2&3\\3&0\end{bmatrix},\\ D_2(A)&=2(0)-3^2=-9\lt0,\\ \lambda&=1\pm\sqrt{10}\approx4.1623,\ -2.1623. \end{aligned} \]

สมการแรกเป็นเส้นตรง จึงดึง $x_1$ ออกมาแทนในสมการที่สอง ได้สองรากคือ $x_2=0$ กับ $1.5$ ที่ A $D_2$ ติดลบ จึงเป็นอานม้า eigenvalues บวกหนึ่งลบหนึ่ง ผลคูณ −9 และผลบวก 2 ตรงกับ $D_2$ และ trace

ตรวจโดยไม่ใช้ทฤษฎีเลย: เดินจาก A ไป $(0.1, 0)$ ได้ $f=0.01$ ขึ้น เดินไป $(0.1, -0.1)$ ได้ $0.01-0.03-0.001=-0.021$ ลง จุดเดียวกันขึ้นได้และลงได้ จึงไม่ใช่ทั้งต่ำสุดและสูงสุด

ขั้นที่ 5 — จุด B เป็นก้นหลุม แต่ไม่ใช่ก้นของทั้งพื้นผิว

ที่ B ช่องขวาล่างคือ $6(1.5)=9$ ตรวจด้วย minor ด้วย eigenvalue และจัดกำลังสองด้วยตัวเลขจริง ให้เห็นว่าเป็นเรื่องเดียวกัน แล้วลองจุดที่ห่างออกไป

\[ \begin{aligned} H(B)&=\begin{bmatrix}2&3\\3&9\end{bmatrix},\quad D_1=2,\quad D_2=18-9=9,\\ \lambda&=\frac{11\pm\sqrt{121-36}}{2}\approx10.1098,\ 0.8902,\\ z^{\mathsf T}H(B)z&=2(z_1+1.5z_2)^2+4.5z_2^2,\\ f(B)&=5.0625-10.125+3.375=-1.6875,\\ f(0,\ -2)&=(-2)^3=-8\lt-1.6875,\\ D_2(x)&=2(6x_2)-9=12x_2-9. \end{aligned} \]

minor บวกทั้งคู่ eigenvalue บวกทั้งคู่ และความโค้งทุกทิศเป็นผลรวมของกำลังสองที่ตัวคูณ $2=D_1$ กับ $4.5=D_2/D_1$ เป็นบวก minor test คือการจัดกำลังสองทีละตัวแปร eigenvalue test คือการหมุนแกนก่อนแล้วอ่านตัวคูณ B จึงเป็นก้นหลุมแน่นอน (positive definite ไม่ใช่แค่ semidefinite)

แต่ห่างจาก B ไม่ไกล $f(0, -2)$ ก็ต่ำกว่าแล้ว และตามแกน $x_2$ ลบ $f(0, x_2)=x_2^3$ ดิ่งไม่มีก้น พื้นผิวนี้ไม่มี global minimum เลย ความโค้ง $6x_2$ พลิกเป็นลบเมื่อ $x_2$ ติดลบ Hessian ที่จุดเดียวไม่มีทางเห็นเหวนี้ สิ่งที่พูดได้คือในครึ่งระนาบ $x_2\gt0.75$ ซึ่ง $D_2(x)\gt0$ ทุกจุด พื้นผิว convex ในเขตนั้น และเขตนั้นก็ convex ตามที่หน้า global กับ local minimum พิสูจน์ B จึงต่ำสุดในทั้งครึ่งระนาบ ตรวจที่ขอบ $x_2=0.75$: ต่ำสุดคือ −0.84375 ที่ $x_1=-1.125$ สูงกว่า −1.6875

ขั้นที่ 6 — objective ของพอร์ต: Hessian คงที่ทั้งพื้นผิว

กลับมาที่โจทย์เปิดเรื่อง เงินส่วนที่ไม่ได้อยู่ในหุ้นหรือพันธบัตร $1-x_1-x_2$ อยู่ในเงินสดที่ได้ $r_f=2\%$ (ติดลบคือกู้ที่ 2%) ผลตอบแทนคาดหวังของพอร์ตจึงเป็น $r_f+(\mu-r_f\mathbf1)^{\mathsf T}x$ คือดอกเบี้ยเงินสดบวกผลตอบแทนส่วนเกินของก้อนเสี่ยง objective แบบ mean-variance หัก $\gamma$ คูณ variance ออก ซึ่งเป็นนิยามที่เราเลือก

\[ \begin{aligned} J(x)&=r_f+(\mu-r_f\mathbf1)^{\mathsf T}x-\gamma\,x^{\mathsf T}Vx,\\ \nabla J&=(\mu-r_f\mathbf1)-2\gamma Vx,\\ H_J&=-2\gamma V,\\ \mu-r_f\mathbf1&=(0.10,\ 0.04),\quad\gamma=2:\ H_J=-4V. \end{aligned} \]

พจน์เชิงเส้นมีความชันคงที่เท่ากับตัวคูณของมัน พจน์กำลังสองให้ $2Vx$ หา derivative อีกครั้ง $x$ หายหมด เหลือค่าคงที่ ความโค้งไม่ขึ้นกับตำแหน่ง ตรวจครั้งเดียวใช้ได้ทั้งพื้นผิว ต่างจากพื้นผิวทดสอบที่ความโค้งพลิกตามที่

ผลตอบแทนคาดหวังกับดอกเบี้ยเงินสดอยู่แค่ใน gradient ไม่แตะ Hessian เลย สิ่งที่ตัดสินรูปทรงมีแค่ $\gamma$ กับ $V$ และเพราะ $V$ เป็น positive definite (eigenvalues 0.0412 กับ 0.0088) เครื่องหมายของ $\gamma$ ตัวเดียวบอกว่าเป็นโดมหรือชาม

ขั้นที่ 7 — แก้เงื่อนไขอันดับหนึ่ง ตัดสินด้วยอันดับสอง แล้วอ่านเป็นพอร์ตจริง

โจทย์ให้อะไรมาบ้าง: $4V=\begin{bmatrix}0.16&0.024\\0.024&0.04\end{bmatrix}$ และผลตอบแทนส่วนเกิน $(0.10, 0.04)$ ตั้ง $\nabla J=0$ ได้ระบบ $4Vx=(0.10, 0.04)$ แก้ด้วย Cramer's rule (ตัวส่วนคือ determinant ตัวเศษคือ determinant ที่แทนหลักหนึ่งด้วยฝั่งขวา)

\[ \begin{aligned} \det&=0.16(0.04)-0.024^2=0.005824,\\ x_1&=\frac{0.10(0.04)-0.024(0.04)}{0.005824}\approx0.521978,\\ x_2&=\frac{0.16(0.04)-0.024(0.10)}{0.005824}\approx0.686813,\\ D_1&=-0.16\lt0,\quad D_2=0.005824\gt0,\\ \mathbb E[R_p]&=0.02+0.10(0.521978)+0.04(0.686813)\\ &=0.099670,\\ x^{\mathsf T}Vx&\approx0.019918,\quad\sigma_p\approx14.113\%,\\ J^\star&=0.099670-2(0.019918)=0.059835. \end{aligned} \]

คำตอบ: หุ้น 52.20% พันธบัตร 68.68% รวม 120.88% จึงกู้เงินสด 20.88% ที่ 2% ได้ผลตอบแทนคาดหวัง 9.967% ความผันผวน 14.113% $D_1$ ลบ $D_2$ บวก จึงเป็นยอดโดม eigenvalues คือ −4 คูณ eigenvalues ของ $V$ คือ −0.1646 กับ −0.0354 ลบทั้งคู่ และเพราะ Hessian คงที่ ยอดนี้คือยอดสูงสุดของทั้งพื้นผิว ไม่ใช่แค่เฉพาะถิ่น ถ้าบังคับให้ลงเงินครบโดยไม่มีเงินสด คำตอบคือ 50/50 ที่ค่า $0.02+0.05+0.02-2(0.0155)=0.059$ กฎลงเงินครบจึงมีราคา $0.059835-0.059=0.000835$ หรือราว 8.4 bp ต่อปีในหน่วยผลตอบแทนเทียบเท่า

ตรวจเองใน 10 วินาที: แทนกลับสมการที่สอง $0.024(0.521978)+0.04(0.686813)=0.012527+0.027473=0.04$ ทางลัดของค่าเป้าหมาย: คูณเงื่อนไข $2\gamma Vx=\mu-r_f\mathbf1$ ด้วย $x$ ได้ $\gamma x^{\mathsf T}Vx=\tfrac12(\mu-r_f\mathbf1)^{\mathsf T}x$ จึง $J^\star=0.02+\tfrac12(0.079670)=0.059835$ ตรงกัน สัดส่วนหุ้นในก้อนเสี่ยงคือ $0.521978/1.208791\approx43.18\%$ ซึ่งเป็นส่วนผสมเดียวกับที่หน้า Markowitz portfolio selection จะหาด้วยอีกวิธี

ขั้นที่ 8 — ใส่ γ = −2: จุดเดิมกลับหัวเป็นจุดแย่ที่สุด

นี่คือกรณีของนักวิเคราะห์คนที่สอง gradient ยังมีจุดศูนย์ที่ตำแหน่งกลับเครื่องหมาย แต่ Hessian พลิกทั้งตาราง ลองเดินตามแนวพอร์ตคำตอบ $x=t\,x^\star$ โดยให้ $t$ เป็นขนาดของก้อนเสี่ยง

\[ \begin{aligned} H_J&=-2(-2)V=+4V,\quad\lambda\approx0.1646,\ 0.0354,\\ J(t\,x^\star)&=0.02+0.07967\,t-\gamma(0.019918)\,t^2,\\ \gamma=-2,\ t=-1:&\quad0.02-0.07967+0.039836\\ &=-0.019835,\\ \gamma=-2,\ t=2.5:&\quad0.468. \end{aligned} \]

$+4V$ หงายทุกทิศ จุดราบที่ $t=-1$ จึงเป็นก้นหลุมของ objective คือพอร์ตที่แย่ที่สุด และการหาค่าสูงสุดบนชามหงายไม่มีคำตอบ ยิ่งขยายก้อนเสี่ยงด้วยเงินกู้มาก ค่าเป้าหมายยิ่งสูงไม่มีที่หยุด เงื่อนไขอันดับหนึ่งอย่างเดียวไม่มีทางรู้ว่าเพิ่งเจออะไร

นี่คือเหตุผลจริงที่ทฤษฎีพอร์ตต้องสมมติว่านักลงทุนเกลียดความเสี่ยง ($\gamma\gt0$) ไม่ใช่เพราะฟังดูสุภาพ แต่เพราะถ้าไม่สมมติ ปัญหาไม่มีคำตอบ

ขั้นที่ 9 — eigenvalue ตัวเล็กคือทิศที่คำตอบไวต่อ input ที่ผิด

โจทย์ให้อะไรมาบ้าง: ผลตอบแทนคาดหวังประมาณจากข้อมูลได้หยาบมาก สมมติเราประเมินผลตอบแทนของพันธบัตรสูงไป 1 จุด หรือของหุ้นสูงไป 1 จุด คำตอบ $x^\star=(2\gamma V)^{-1}(\mu-r_f\mathbf1)$ ขยับเท่าไร ใช้ inverse ของ $4V$: สลับทแยง เปลี่ยนเครื่องหมายนอกทแยง หารด้วย determinant 0.005824

\[ \begin{aligned} \Delta x&=(4V)^{-1}\,\Delta\mu,\\ (4V)^{-1}&=\frac{1}{0.005824}\begin{bmatrix}0.04&-0.024\\-0.024&0.16\end{bmatrix},\\ \Delta\mu=(0.01,\ 0):&\quad\Delta x\approx(0.0687,\ -0.0412),\\ \Delta\mu=(0,\ 0.01):&\quad\Delta x\approx(-0.0412,\ 0.2747). \end{aligned} \]

คำตอบ: ผิดเรื่องหุ้น 1 จุด น้ำหนักขยับรวมราว 0.08 แต่ผิดเรื่องพันธบัตร 1 จุด น้ำหนักพันธบัตรกระโดด 27.5 จุด และเงินกู้เพิ่มจาก 20.9% เป็น 44.2% ของทุน เพราะชามของ $V$ แบนในทิศที่เกือบเป็นแกนพันธบัตร (eigenvalue 0.0354 ของ $4V$ เทียบ 0.1646 ทิศหุ้น) การหารด้วย eigenvalue ตัวเล็กขยาย error ในทิศนั้นมากกว่าอีกทิศ 4.65 เท่า

ตรวจเองใน 10 วินาที: ทิศที่แบนก็แปลว่าเดินไปแล้วเสียน้อย ใส่น้ำหนักใหม่ลงใน objective ที่ใช้ $\mu$ ตัวจริง ได้ 0.05846 ต่ำกว่ายอด 0.059835 แค่ 0.0014 ความเสียหายในค่าเป้าหมายเล็ก แต่ตำแหน่งกับเลเวอเรจเปลี่ยนมาก ซึ่งแปลว่าต้นทุนซื้อขายสูง และถ้า $V$ ก็ผิดด้วย ความเสี่ยงจริงอาจต่างจากที่คิดมาก

กับดัก: ดูความโค้งไม่ครบ ลืมบางส่วนของ gradient หรือเจอสันแบน

ที่ A ช่อง $D_1=2$ เป็นบวก หลายคนรีบสรุปว่าโค้งขึ้นจึงเป็นก้นหลุม ผิด $D_1$ ดูแค่ทิศ $x_1$ ทิศเดียว ช่องไขว้ 3 สร้างทิศผสมที่ลงได้ เช่น $(0.1, -0.1)$ ที่ให้ −0.021 ต้องผ่านเกณฑ์ครบ ไม่ใช่ผ่านเกณฑ์แรกแล้วจบ

positive semidefinite ไม่พอจะรับรองก้นหลุม มันเป็นแค่เงื่อนไขจำเป็น ตัวอย่างตัวแปรเดียว: $x^4$, $-x^4$ และ $x^3$ ล้วนมี $f''(0)=0$ ซึ่งผ่านเกณฑ์ “ไม่ติดลบ” แต่ $x^3$ ที่ $x=-0.1$ ได้ −0.001 ต่ำกว่าค่าที่ 0 จุดนั้นจึงไม่ใช่ก้นหลุม ต้อง definite (บวกจริงทุกทิศ) จึงรับรองได้

ลืมดอกเบี้ยเงินสด แล้วใส่ผลตอบแทนรวม 12% กับ 6% ลงใน objective ตรง ๆ เท่ากับสมมติว่ากู้ได้ฟรี ได้หุ้น 57.7% พันธบัตร 115.4% กู้ 73% ค่าเป้าหมาย 0.0692 และดูเหมือนกฎลงเงินครบมีราคา $0.0692-0.059=0.0102$ ซึ่งใหญ่กว่า 0.000835 ของจริงราว 12 เท่า Hessian เหมือนเดิมทุกช่อง คำตัดสินจึงยังเป็นยอดโดม ความผิดทั้งหมดอยู่ใน gradient

ถ้าประมาณ correlation ได้ 1.00 พอดี $V=\begin{bmatrix}0.04&0.02\\0.02&0.01\end{bmatrix}$ มี determinant ศูนย์ $H=-4V$ มี eigenvalue 0 กับ −0.2 คือสันแบนในรูปภาพรวม ในทิศ $(1, -2)$ variance เป็นศูนย์แต่ผลตอบแทนส่วนเกินเป็น $0.10-0.08=0.02$ ต่อหน่วย objective ตามแนวสันจึงเป็น $0.02+0.02t$ ที่ $t=100$ ได้ 2.02 และไม่มีเพดาน optimizer จะคืนน้ำหนักหลายพันเปอร์เซ็นต์ที่ long กับ short หักล้างกัน นั่นไม่ใช่บั๊กของ solver แต่เป็น $V$ ที่กลับด้านไม่ได้ (rank และ invertibility)

ใช้ทำอะไรบนโต๊ะจริง

ทุกครั้งที่ optimizer คืนคำตอบ ให้ดู eigenvalue ที่เล็กที่สุดของ covariance ก่อน ถ้าติดลบหรือใกล้ศูนย์ ซึ่งเกิดบ่อยเมื่อจำนวนสินทรัพย์มากกว่าจำนวนวันข้อมูล (covariance matrix: ต้องประมาณ $n(n+1)/2$ ค่า พอร์ต 500 ตัวคือ 125,250 ค่า) คำตอบจะมีน้ำหนักใหญ่ที่หักล้างกันเป็นคู่ ทิศที่เป็นปัญหาอ่านได้จาก eigenvector ของ eigenvalue ตัวนั้น และการดึง eigenvalue ตัวเล็กขึ้นด้วย Ledoit–Wolf shrinkage คือการทำให้ชามแบนน้อยลงโดยตรง

ถ้า objective ไม่ใช่กำลังสอง เช่น calibrate model หลาย parameter ทางที่ถูกที่สุดคือเดินออกจากคำตอบไปหลายทิศทีละนิด ถ้ามีทิศไหนดีขึ้น optimizer หยุดบนอานม้า แบบเดียวกับการเดินรอบ A ส่วนการคำนวณ Hessian ทุกช่องมีราคา $n(n+1)/2$ ช่องต่อครั้ง ซึ่งหน้า gradient descent และ Newton's method จะชั่งว่าคุ้มไหม

โจทย์ตรวจความเข้าใจ

1. หาจุดราบของ $f=x^2+xy+y^2-3x$ แล้วตัดสินด้วย Hessian จุดนั้นเป็น global ไหม?

เฉลย

$\partial f/\partial x=2x+y-3=0$ และ $\partial f/\partial y=x+2y=0$ จากสมการที่สอง $x=-2y$ แทนได้ $-3y-3=0$ จึง $y=-1$, $x=2$ Hessian $\begin{bmatrix}2&1\\1&2\end{bmatrix}$ มี $D_1=2$, $D_2=3$ eigenvalues 3 กับ 1 เป็นก้นหลุม ค่า $f(2, -1)=4-2+1-6=-3$ และเพราะ Hessian คงที่และบวกทุกที่ นี่คือ global minimum

2. ถ้าลูกค้ากลัวความเสี่ยงเป็นสองเท่า ($\gamma=4$) พอร์ตที่ได้จากการแก้เงื่อนไขอันดับหนึ่งเปลี่ยนอย่างไร?

เฉลย

คำตอบคือ $x=V^{-1}(\mu-r_f\mathbf1)/(2\gamma)$ $\gamma$ อยู่แค่ตัวส่วน น้ำหนักจึงลดครึ่งเป็น 26.10% กับ 34.34% ก้อนเสี่ยงรวม 60.44% ฝากเงินสด 39.56% ความผันผวนลดครึ่งเป็น 7.056% ค่าเป้าหมาย $0.02+\tfrac12(0.039835)=0.039918$ สัดส่วนหุ้นในก้อนเสี่ยงยัง 43.18% เท่าเดิม $\gamma$ ปรับขนาด ไม่ปรับส่วนผสม

3. ผู้ขายข้อมูลส่ง covariance $\begin{bmatrix}0.04&0.05\\0.05&0.06\end{bmatrix}$ มา ใช้เกณฑ์ 2×2 ตรวจว่าใช้ได้ไหม

เฉลย

$D_1=0.04\gt0$ แต่ $D_2=0.04(0.06)-0.05^2=0.0024-0.0025=-0.0001\lt0$ matrix นี้ไม่ใช่ PSD eigenvalues ประมาณ 0.1010 กับ −0.00099 correlation ที่ซ่อนอยู่คือ $0.05/\sqrt{0.04\times0.06}\approx1.0206$ เกิน 1 พอร์ต $(1, -0.9)$ มี “variance” $0.04-0.09+0.0486=-0.0014$ ซึ่งเป็นไปไม่ได้ optimizer ความเสี่ยงต่ำสุดจะไล่ตามทิศนี้ไม่หยุด

// Leading minors, eigenvalues and the verdict for a stationary point with symmetric 2x2 Hessian H.
function classify(H) {
  const [a, b, c] = [H[0][0], H[0][1], H[1][1]], D2 = a * c - b * b;
  const r = Math.hypot((a - c) / 2, b), eigen = [(a + c) / 2 + r, (a + c) / 2 - r];
  let verdict = 'inconclusive';
  if (D2 < 0) verdict = 'saddle';
  else if (D2 > 0) verdict = a > 0 ? 'minimum' : 'maximum';
  return {D1: a, D2, eigen, verdict};
}
// Test surface f = x1^2 + 3 x1 x2 + x2^3.
const f = ([p, q]) => p * p + 3 * p * q + q ** 3;
const hess = ([, q]) => [[2, 3], [3, 6 * q]];
// Mean-variance with cash at rf: J = rf + (mu - rf)'x - gamma x'Vx; solve 2 gamma V x = mu - rf.
function meanVariance(mu, V, gamma, rf) {
  if (gamma === 0) throw new RangeError('gamma = 0: the objective is linear, no stationary point');
  const e = mu.map(m => m - rf), A = V.map(r => r.map(v => 2 * gamma * v));
  const det = A[0][0] * A[1][1] - A[0][1] * A[1][0];
  if (Math.abs(det) < 1e-14) throw new RangeError('Singular covariance: flat ridge, no unique answer');
  const x = [(e[0] * A[1][1] - A[0][1] * e[1]) / det, (A[0][0] * e[1] - e[0] * A[1][0]) / det]; // Cramer
  const variance = V[0][0] * x[0] ** 2 + 2 * V[0][1] * x[0] * x[1] + V[1][1] * x[1] ** 2;
  const excess = e[0] * x[0] + e[1] * x[1];
  return {x, cash: 1 - x[0] - x[1], ret: rf + excess, sd: Math.sqrt(variance),
    J: rf + excess - gamma * variance, verdict: classify(V.map(r => r.map(v => -2 * gamma * v))).verdict};
}
const V = [[0.04, 0.006], [0.006, 0.01]], mu = [0.12, 0.06];
const best = meanVariance(mu, V, 2, 0.02);
// Sensitivity: dx = (2 gamma V)^-1 dmu.
const shift = dmu => { const A = V.map(r => r.map(v => 4 * v)), d = A[0][0] * A[1][1] - A[0][1] ** 2;
  return [(A[1][1] * dmu[0] - A[0][1] * dmu[1]) / d, (A[0][0] * dmu[1] - A[0][1] * dmu[0]) / d]; };

  walkUp: f([0.1, 0]), walkDown: f([0.1, -0.1]), deeper: f([0, -2]), edgeMin: f([-1.125, 0.75]),
  best, flipped: meanVariance(mu, V, -2, 0.02), freeBorrowing: meanVariance(mu, V, 2, 0),
  stockError: shift([0.01, 0]), bondError: shift([0, 0.01]),
  ridge: classify([[-0.16, -0.08], [-0.08, -0.04]]),
  exercises: {bowl: classify([[2, 1], [1, 2]]), scared: meanVariance(mu, V, 4, 0.02),
    vendor: classify([[0.04, 0.05], [0.05, 0.06]])}

สิ่งที่ควรตอบได้หลังอ่าน

  • ที่จุดราบ ผลของการขยับคือ $\tfrac12z^{\mathsf T}Hz$ ความโค้งทุกทิศจึงเป็นตัวตัดสิน: positive definite คือก้นหลุม negative definite คือยอดโดม eigenvalues ต่างเครื่องหมายคืออานม้า มี eigenvalue ศูนย์คือตัดสินไม่ได้
  • เกณฑ์ 2×2: $D_2\lt0$ อานม้า, $D_2\gt0$ ดูเครื่องหมาย $D_1$, $D_2=0$ ตัดสินไม่ได้ และต้องตรงกับเครื่องหมายของ eigenvalues
  • ก้นหลุมเฉพาะถิ่นอาจไม่ใช่ก้นของทั้งพื้นผิว: $f(B)=-1.6875$ แต่ $f(0, -2)=-8$ และพื้นผิวดิ่งไม่มีก้น
  • mean-variance มี Hessian $-2\gamma V$ คงที่ เมื่อ $\gamma=2$ ได้ยอดเดียวทั้งพื้นผิวที่หุ้น 52.20% พันธบัตร 68.68% กู้ 20.88% ค่าเป้าหมาย 0.059835 ส่วน $\gamma\lt0$ พลิกยอดเป็นก้นหลุม
  • eigenvalue ตัวเล็กคือทิศที่ชามแบน error 1 จุดในผลตอบแทนพันธบัตรขยับน้ำหนักพันธบัตร 27.5 จุด

หน้าถัดไป Lagrange multipliers จะเอาข้อจำกัดเข้าสมการตรง ๆ แทนการแทนค่า ด้วยตัวคูณที่ทั้งหาคำตอบและบอกราคาของข้อจำกัดในตัว
