12.3 The Itô Integral

left endpoints เขียนกฎห้ามมองอนาคตไว้ในนิยาม

backtest บน SPY สร้าง position จากราคาปิดของวันเดียวกันแล้วเอาไปคูณ return ของวันนั้น equity curve ขึ้นทั้งที่ input เป็น pure Brownian noise ถ้า code เห็นปลายแท่งก่อนเลือก position กำไรที่เพิ่มขึ้นไม่ได้ชื่อ edge—มันชื่อ look-ahead

ศัพท์การเงินที่เพิ่งโผล่มา

Itô integral
ลิมิตของผลรวม position ที่รู้ได้ก่อนช่วงคูณกับ Brownian increment ในช่วงนั้น ใช้แทน cumulative trading gain ของกลยุทธ์ที่ไม่มองอนาคต
adapted process
process ที่ค่า ณ เวลาใดขึ้นกับข้อมูลที่เห็นถึงเวลานั้นเท่านั้น ใช้บังคับให้ trading rule ทำได้จริงโดยไม่มี future information
look-ahead bias
ข้อผิดพลาดที่นำข้อมูลอนาคตมาใช้ตัดสินใจในอดีต ใช้ตรวจจับ backtest ที่รายงาน performance สูงเกินจริง
P&L
profit and loss หรือกำไรขาดทุนสะสมของ position ใช้วัดผลทางการเงินของ stochastic integral
martingale
process ที่ conditional expected value ในอนาคตเท่ากับค่าปัจจุบัน ใช้เป็น benchmark ว่ากลยุทธ์บน fair noise ไม่มี expected gain
Itô isometry
สมบัติที่เปลี่ยน second moment ของ stochastic integral เป็น expected integral ของ position squared ใช้คำนวณ risk โดยไม่ต้องหา distribution ทั้งก้อน

กลับไปตอบ code review

สำหรับ signal ที่เท่ากับ Brownian level ปัจจุบัน right-point implementation มี asymptotic upward bias เท่ากับ horizon ต่อ path ในหน่วยของ model ขณะที่ valid Itô gain มี mean 0 และ standard deviation ซึ่งที่ horizon 1 ปีเท่ากับ 0.7071 วิธีตรวจคือ shift position หนึ่งแถวให้ใช้เฉพาะข้อมูลก่อน return แล้ว rerun ด้วย seed เดิม

กับดัก: equate fair กับ symmetric

Itô integral มี expected value 0 ภายใต้ square-integrability แต่ distribution ไม่จำเป็นต้อง symmetric ตัวอย่างนี้ถูกจำกัดด้านล่างที่ -0.5 และมีหางกำไรยาว—fair game ไม่ได้แจกความเจ็บกับความสุขเท่ากัน เหมือน compliance ที่แฟร์แต่ไม่เคยตลก

สรุปที่ใช้ได้จริง

  • Itô integral ใช้ left endpoints เพราะ position ต้อง adapted ต่อข้อมูลที่มีจริง
  • right-point sum ของ สูงกว่า left-point sum ด้วย quadratic variation ที่ลู่เข้า
  • เมื่อ integrand square-integrable, expected Itô gain เท่ากับ 0 และ risk หาได้ด้วย Itô isometry
  • backtest ต้อง lag signal ก่อนคูณ return และทดสอบด้วย noise ที่รู้ว่าไม่มี edge
