12.3 The Hessian and Second-Order Conditions

gradient เป็นศูนย์บอกแค่ว่าพื้นตรงนั้นราบ ส่วนความโค้งในทุกทิศ ซึ่งเก็บอยู่ใน Hessian เป็นตัวตัดสินว่าจุดนั้นเป็นก้นหลุม ยอดโดม หรืออานม้า

โต๊ะจัดพอร์ต (ทีมที่ตัดสินใจว่าจะแบ่งเงินลงทุนไปไว้ที่ไหน) มีโปรแกรมช่วยเลือกสัดส่วนเงินระหว่างของสามอย่าง คือหุ้น พันธบัตร และเงินสด โปรแกรมให้คะแนนพอร์ตทุกแบบ แล้วหาพอร์ตที่คะแนนสูงสุด วิธีหาคือหาจุดที่ gradient ของคะแนนเป็นศูนย์ (gradient คือ vector ของความชันในแต่ละทิศ ดูgradient และเงื่อนไขอันดับหนึ่ง) เหตุผลคือที่ยอดเขา พื้นต้องราบทุกทิศ

ของที่รู้ (ตัวเลขสมมติของโต๊ะ):

  • หุ้น: ผลตอบแทนคาดหวัง (ผลตอบแทนเฉลี่ยที่คาดว่าจะได้) $\mu_1=12\%$ ต่อปี และความผันผวน $\sigma_1=20\%$ ต่อปี ความผันผวนคือ SD (standard deviation) ของผลตอบแทน หรือขนาดการแกว่งตามปกติรอบค่าเฉลี่ย (ดูvariance และ SD)
  • พันธบัตร: $\mu_2=6\%$ ต่อปี และ $\sigma_2=10\%$ ต่อปี
  • correlation ระหว่างหุ้นกับพันธบัตร $\rho=0.30$ แปลว่าสองตัวมักขึ้นลงไปทางเดียวกันเล็กน้อย
  • เงินสด: ฝากได้ดอกเบี้ย $r_f=2\%$ ต่อปี และกู้มาลงทุนเพิ่มได้ที่ดอกเบี้ยเดียวกัน

คะแนนของพอร์ตคือ $J=\mathbb E[R_p]-\gamma\,\sigma_p^2$ โดย $\mathbb E[R_p]$ คือผลตอบแทนคาดหวังของพอร์ต และ $\sigma_p^2$ คือ variance ของพอร์ต (ความผันผวนยกกำลังสอง) ส่วน $\gamma$ คือความกลัวความเสี่ยง (risk aversion) ตัวเลขนี้บอกว่าจะหักคะแนนเพราะความเสี่ยงหนักแค่ไหน $\gamma$ ยิ่งมาก ยิ่งหักหนัก

นักวิเคราะห์คนแรกใส่ $\gamma=2$ โปรแกรมตอบว่าให้ลงหุ้น 52.2% และพันธบัตร 68.7% ของเงินทุน สองตัวรวมกันเกิน 100% จึงต้องกู้เงินส่วนที่ขาด นักวิเคราะห์คนที่สองใช้ library (ชุดโค้ดสำเร็จรูป) ที่กำหนดเครื่องหมายกลับกัน จึงเผลอใส่ $\gamma=-2$ โปรแกรมตอบว่าหุ้น −52.2% และพันธบัตร −68.7% น้ำหนักติดลบคือ short (ยืมของมาขายก่อน แล้วซื้อคืนทีหลัง) หน้านี้จะคำนวณตัวเลขทั้งสองชุดให้ดูทีละขั้นในขั้นที่ 7 และ 8

จอของทั้งสองคนขึ้นว่า gradient เป็นศูนย์ ทั้งสองพอร์ตคือพอร์ตที่ได้คะแนนสูงสุดตามคะแนนของตัวเองใช่ไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ใช่ พอร์ตแรกคือยอดสูงสุดจริง และสูงสุดของทั้งพื้นผิวด้วย ได้คะแนน $J=0.0598$ เพราะความโค้งของคะแนนคือ $-4V$ ($V$ คือ covariance matrix ของหุ้นกับพันธบัตร) ซึ่งโค้งคว่ำลงทุกทิศ

พอร์ตที่สองกลับเป็นจุดต่ำสุดของคะแนนตัวเอง ได้ $J=-0.0198$ เพราะความโค้งกลายเป็น $+4V$ ซึ่งโค้งหงายขึ้นทุกทิศ คะแนนแบบนี้ไม่มีจุดสูงสุดเลย ยิ่งกู้มาลงทุนมาก คะแนนยิ่งสูง

gradient เป็นศูนย์ทั้งคู่ จึงแยกสองกรณีนี้ไม่ออก แต่ความโค้งแยกได้ในบรรทัดเดียว ตัวเลขทุกตัวในเฉลยนี้ หน้านี้จะคำนวณให้ดูในขั้นที่ 6 ถึง 8

ภาพรวมก่อนลงสูตร

นึกภาพพื้นผิวภูเขา ตำแหน่งบนแผนที่คือตัวแปร $x=(x_1, x_2)$ และความสูงของพื้นคือค่าของฟังก์ชัน $f(x)$ จุดที่ gradient เป็นศูนย์คือจุดที่พื้นราบ เรียกว่าจุดราบ (stationary point) ยืนตรงนั้นแล้วไม่มีทิศไหนเอียง แต่พื้นราบเกิดได้สามแบบ คือก้นหลุม ยอดโดม และอานม้า (ขึ้นทางหนึ่ง ลงอีกทางหนึ่ง เหมือนอานม้า) ความชันบอกไม่ได้ว่าเป็นแบบไหน เพราะความชันเป็นศูนย์ทั้งสามแบบ

สิ่งที่บอกได้คือความโค้ง ถ้าก้าวออกไปทิศไหนก็ตามแล้วพื้นโค้งขึ้น จุดนั้นคือก้นหลุม ถ้ามีแม้แต่ทิศเดียวที่พื้นโค้งลง จุดนั้นไม่ใช่ก้นหลุม ฟังก์ชันตัวแปรเดียวมีความโค้งค่าเดียวคือ $f''$ แต่ฟังก์ชันหลายตัวแปรโค้งไม่เท่ากันในแต่ละทิศ เราจึงเก็บความโค้งทุกทิศไว้ใน matrix ตัวเดียว เรียกว่า Hessian

รูปด้านล่างคือสามรูปทรงที่ Hessian แยกได้ แต่ละช่องวาดเส้นระดับ คือเส้นที่ลากผ่านจุดที่สูงเท่ากัน แบบเส้นชั้นความสูงในแผนที่ ก้นหลุมโค้งขึ้นทุกทิศ เส้นระดับจึงเป็นวงรีปิด อานม้าโค้งขึ้นทิศหนึ่งและโค้งลงอีกทิศ เส้นระดับจึงเปิดออกเป็นรูปกากบาท สันแบนโค้งลงด้านข้าง แต่แบนสนิทตามแนวสัน กรณีนี้ความโค้งอย่างเดียวยังตัดสินไม่ได้ ทั้งสามรูปใช้ Hessian จริงที่หน้านี้จะคำนวณ

หน้านี้เดินทีละขั้น เริ่มจากนิยาม Hessian แล้วพิสูจน์ว่าทำไมความโค้งเป็นตัวตัดสิน จากนั้นสร้างเกณฑ์ที่ตรวจด้วยมือได้สำหรับ matrix 2×2 แล้วลองกับพื้นผิวทดสอบที่มีทั้งอานม้าและก้นหลุม ตรงนี้จะเห็นว่าก้นหลุมเฉพาะที่ (local minimum) ไม่จำเป็นต้องเป็นก้นของทั้งพื้นผิว (global minimum)

ต่อจากนั้นกลับมาที่พอร์ตในโจทย์เปิดเรื่อง คะแนนของพอร์ตมี Hessian คงที่ทั้งพื้นผิว ตรวจครั้งเดียวจึงรู้รูปทรงของทั้งแผนที่ ปิดท้ายด้วยสิ่งที่ eigenvalue (ความโค้งตามแกนหลักแต่ละแกน ดูeigenvalues และ positive definiteness) ตัวที่เล็กที่สุดบอกเรา คือคำตอบไวแค่ไหนเมื่อตัวเลขที่ใส่เข้าไปผิดนิดเดียว

ศัพท์ที่ใช้ในหัวข้อนี้
Stationary point (จุดราบ)
จุดที่ gradient เป็นศูนย์ คือพื้นไม่เอียงไปทิศไหนเลย อาจเป็นก้นหลุม ยอดโดม หรืออานม้าก็ได้
Hessian
matrix ที่เก็บ derivative อันดับสองของทุกคู่ตัวแปร บอกว่าพื้นโค้งแค่ไหนในทุกทิศรอบจุดหนึ่ง ใช้ตัดสินว่าจุดราบเป็นแบบไหน
Saddle point (อานม้า)
จุดราบที่ก้าวไปบางทิศแล้วพื้นสูงขึ้น แต่ก้าวไปอีกบางทิศแล้วพื้นต่ำลง optimizer (โปรแกรมหาค่าต่ำสุดหรือสูงสุด) ที่หยุดตรงนี้ยังเดินลงต่อได้
Eigenvalue ของ Hessian
ความโค้งตามแกนหลักแต่ละแกนของพื้นผิว Hessian 2×2 มีสองค่า (ดูeigenvalues และ positive definiteness)
Positive / negative definite
matrix $H$ ที่ $z^{\mathsf T}Hz\gt0$ (หรือ $\lt0$) สำหรับทุกทิศ $z$ ที่ไม่ใช่ศูนย์ แปลว่าพื้นโค้งขึ้นทุกทิศ (หรือโค้งลงทุกทิศ) ใช้รับรองว่าเป็นก้นหลุม (หรือยอดโดม) แน่นอน ถ้าแค่ $z^{\mathsf T}Hz\ge0$ เรียกว่า positive semidefinite ซึ่งยังรับรองไม่ได้
Leading principal minors
determinant ของมุมซ้ายบนของ matrix ขนาด 1×1, 2×2, … ใช้ตรวจว่า matrix เป็น definite ไหมด้วยมือ โดยไม่ต้องหา eigenvalue
Second-order condition
เงื่อนไขเรื่องความโค้งที่จุดราบ ถ้าจุดนั้นเป็นจุดต่ำสุด Hessian ต้องเป็น positive semidefinite (เงื่อนไขจำเป็น) และถ้า Hessian เป็น positive definite ก็รับรองได้ว่าเป็นจุดต่ำสุดเฉพาะที่ (เงื่อนไขพอเพียง)
Covariance matrix $V$
ตารางที่เก็บ variance ของแต่ละสินทรัพย์ไว้บนทแยง และ covariance ของแต่ละคู่ไว้นอกทแยง variance ของพอร์ตน้ำหนัก $x$ คือ $x^{\mathsf T}Vx$ (ดูcovariance matrix และความเสี่ยงของพอร์ต)
Risk aversion $\gamma$ (ความกลัวความเสี่ยง)
ตัวคูณที่ใช้หัก variance ออกจากผลตอบแทนคาดหวังในคะแนนของพอร์ต $\gamma$ ยิ่งมาก ยิ่งยอมถือความเสี่ยงน้อย

ขั้นที่ 1 — นิยามของ Hessian: ความชันของความชัน

ก่อนจะใช้ความโค้งตัดสินอะไร ต้องเขียนความโค้งทุกทิศให้เป็นของชิ้นเดียวก่อน ฟังก์ชันตัวแปรเดียวมี derivative อันดับสองแบบเดียวคือ $f''$ ฟังก์ชันสองตัวแปรมีสี่แบบ เพราะ derivative ครั้งแรกเลือกเทียบ $x_1$ หรือ $x_2$ ได้ และครั้งที่สองก็เลือกได้อีกสองแบบ รวม $2\times2=4$ แบบ เราเรียงทั้งสี่ตัวเป็นตาราง แล้วตั้งชื่อว่า Hessian บรรทัดข้างล่างจึงเป็นนิยาม ไม่ต้องพิสูจน์ ถ้ามี $n$ ตัวแปร ก็เรียงแบบเดียวกันเป็นตาราง $n\times n$

\[ \begin{aligned} H(x)&=\begin{bmatrix}\dfrac{\partial^2 f}{\partial x_1^2}&\dfrac{\partial^2 f}{\partial x_1\partial x_2}\\[8pt]\dfrac{\partial^2 f}{\partial x_2\partial x_1}&\dfrac{\partial^2 f}{\partial x_2^2}\end{bmatrix}. \end{aligned} \]

ช่องบนทแยงคือความโค้งตามแกนแต่ละแกน ช่องนอกทแยงคือความโค้งไขว้ คือความชันตาม $x_1$ เปลี่ยนไปเท่าไรเมื่อขยับ $x_2$ ถ้า derivative อันดับสองต่อเนื่อง ลำดับการหา derivative ไม่มีผลต่อคำตอบ (ผลนี้ชื่อ Schwarz's theorem) สองช่องนอกทแยงจึงเท่ากัน และ $H$ เป็น matrix สมมาตร ข้อดีของความสมมาตรคือ eigenvalues ของ $H$ เป็นจำนวนจริงทุกตัว (ดูeigenvalues และ positive definiteness)

ตัวอย่างที่จะใช้กับพอร์ตในขั้นที่ 6: variance ของพอร์ตคือ $x^{\mathsf T}Vx$ และ gradient ของมันคือ $2Vx$ (ดูgradient และเงื่อนไขอันดับหนึ่ง) $2Vx$ เป็นฟังก์ชันเชิงเส้นของ $x$ และ derivative ของ $Ax$ เทียบ $x$ คือ matrix $A$ เอง หา derivative อีกครั้งจึงได้ $H=2V$ ทันที

ขั้นที่ 2 — ทำไมความโค้งเป็นตัวตัดสิน

ตอนนี้มี Hessian แล้ว คำถามต่อไปคือ ถ้าก้าวออกจากจุด $x$ ไปที่ $x+z$ ค่า $f$ เปลี่ยนไปเท่าไร และ Hessian เข้ามาเกี่ยวตรงไหน ($z$ คือก้าว บอกทั้งทิศและระยะ) เรารู้สูตร Taylor ของฟังก์ชันตัวแปรเดียวอยู่แล้ว จึงยุบปัญหาให้เหลือตัวแปรเดียว วิธีคือเดินเป็นเส้นตรงจาก $x$ ไป $x+z$ แล้วมองค่า $f$ บนทางเดินเป็นฟังก์ชัน $g(t)$ ของตัวแปร $t$ ที่วิ่งจาก 0 ถึง 1

\[ \begin{aligned} g(t)&=f(x+tz),\qquad0\le t\le1,\\ g'(t)&=\nabla f(x+tz)^{\mathsf T}z,\\ g''(t)&=z^{\mathsf T}H(x+tz)\,z,\\ g(1)&=g(0)+g'(0)+\tfrac12g''(\tau),\quad0\lt\tau\lt1,\\ f(x+z)&=f(x)+\nabla f(x)^{\mathsf T}z\\ &\quad+\tfrac12\,z^{\mathsf T}H(x+\tau z)\,z. \end{aligned} \]

หัวใจของขั้นนี้คือ $g$ เป็นฟังก์ชันตัวแปรเดียว จึงใช้ Taylor แบบมีเศษที่รู้จักแล้วได้ทันที ส่วนที่ต้องคิดคือ derivative ของ $g$ ซึ่งได้จาก chain rule: ขยับ $t$ นิดหนึ่ง ตัวแปรตัวที่ $i$ ขยับ $z_i$ เท่า จึงได้ $g'=\sum_i\frac{\partial f}{\partial x_i}z_i=\nabla f^{\mathsf T}z$ ทำ chain rule ซ้ำอีกรอบ ทุกคู่ $(i, j)$ ให้ $\frac{\partial^2f}{\partial x_i\partial x_j}z_iz_j$ และผลรวมของทุกคู่คือ $z^{\mathsf T}Hz$ พอดี เศษของ Taylor คือ $\tfrac12g''$ ที่จุด $\tau$ จุดหนึ่งระหว่างทาง เลข ½ จึงมาจาก Taylor ไม่ได้ถูกเสกขึ้น

ผลที่เอาไปใช้คือ ที่จุดราบ $\nabla f(x)=0$ พจน์กลางหายไป ค่าที่เปลี่ยนจึงเหลือแค่ $\tfrac12z^{\mathsf T}H(x+\tau z)\,z$ ถ้า $H(x)$ เป็น positive definite ($z^{\mathsf T}Hz\gt0$ ทุกทิศ) และ Hessian ต่อเนื่อง จุดที่อยู่ใกล้ ๆ ก็ยังให้ค่าบวก ดังนั้นทุกก้าวเล็ก ๆ ทำให้ $f$ สูงขึ้น จุดนั้นจึงเป็นก้นหลุม ถ้ามีทิศที่ $z^{\mathsf T}Hz\lt0$ ก้าวสั้น ๆ ไปทิศนั้นทำให้ $f$ ต่ำลง จุดนั้นจึงไม่ใช่ก้นหลุม ถ้าบางทิศได้ศูนย์พอดี พจน์นี้บอกอะไรไม่ได้ในทิศนั้น ต้องไปดู derivative อันดับที่สูงกว่า

ขั้นที่ 3 — เกณฑ์ 2×2 ที่ตรวจด้วยมือ

ขั้นที่ 2 ทำให้เหลือคำถามเดียว คือ $z^{\mathsf T}Hz$ เป็นบวกทุกทิศ $z$ หรือไม่ แต่ทิศมีไม่จำกัด ลองทีละทิศไม่ได้ ทางออกคือเขียน $z^{\mathsf T}Hz$ ใหม่ให้เป็นผลรวมของสองก้อนที่ยกกำลังสอง แล้วดูแค่เครื่องหมายของตัวคูณหน้าแต่ละก้อน เขียน Hessian สมมาตรขนาด 2×2 เป็น $H=\begin{bmatrix}a&b\\b&c\end{bmatrix}$ แล้วจัดกำลังสองสมบูรณ์ (สมมติ $a\ne0$)

\[ \begin{aligned} z^{\mathsf T}Hz&=az_1^2+2bz_1z_2+cz_2^2\\ &=a\Big(z_1+\tfrac{b}{a}z_2\Big)^2+\Big(c-\tfrac{b^2}{a}\Big)z_2^2\\ &=D_1\Big(z_1+\tfrac{b}{a}z_2\Big)^2+\frac{D_2}{D_1}\,z_2^2,\\ D_1&=a,\qquad D_2=ac-b^2. \end{aligned} \]

ขั้นที่ต้องระวังคือการจัดกำลังสอง ตรวจเองได้โดยกางกลับ: $a(z_1+\tfrac baz_2)^2=az_1^2+2bz_1z_2+\tfrac{b^2}{a}z_2^2$ ก้อนนี้ให้ $\tfrac{b^2}{a}z_2^2$ เกินมา จึงต้องหักคืนจาก $cz_2^2$ เหลือ $(c-\tfrac{b^2}{a})z_2^2$ และ $c-\tfrac{b^2}{a}=\tfrac{ac-b^2}{a}=\tfrac{D_2}{D_1}$ ตัวเลข $D_1$ คือ determinant ของมุมซ้ายบน 1×1 และ $D_2$ คือ determinant ของทั้ง matrix สองตัวนี้เรียกรวมกันว่า leading principal minors

ก้อนในวงเล็บยกกำลังสองไม่มีวันติดลบ คำตัดสินจึงขึ้นกับเครื่องหมายของตัวคูณสองตัว คือ $D_1$ กับ $D_2/D_1$ เท่านั้น:

  • $D_1\gt0$ และ $D_2\gt0$: ตัวคูณบวกทั้งคู่ พื้นโค้งขึ้นทุกทิศ จึงเป็นก้นหลุม
  • $D_1\lt0$ และ $D_2\gt0$: ตัวคูณลบทั้งคู่ พื้นโค้งลงทุกทิศ จึงเป็นยอดโดม
  • $D_2\lt0$: $D_1$ กับ $D_2/D_1$ ต่างเครื่องหมายเสมอ จึงมีทั้งทิศขึ้นและทิศลง เป็นอานม้า
  • $D_2=0$: มีทิศที่ความโค้งเป็นศูนย์ เกณฑ์นี้ตัดสินไม่ได้ นี่คือช่องสันแบนในรูปแรก

อีกทางหนึ่งคือตรวจด้วย eigenvalues ซึ่งคือรากของสมการนี้:

\[ \begin{aligned} \det(H-\lambda I)&=(a-\lambda)(c-\lambda)-b^2\\ &=\lambda^2-(a+c)\lambda+D_2=0. \end{aligned} \]

จากสมการกำลังสอง ผลคูณของสองรากคือ $D_2$ และผลบวกคือ $a+c$ (เรียกว่า trace) ดังนั้นถ้า $D_2\lt0$ สองรากต้องต่างเครื่องหมาย ถ้า $D_2\gt0$ สองรากมีเครื่องหมายเดียวกัน และเป็นเครื่องหมายเดียวกับ trace

สองวิธีจึงต้องตอบตรงกันเสมอ เพราะเมื่อ $D_2\gt0$ จะได้ $ac\gt b^2\ge0$ แปลว่า $a$ กับ $c$ เครื่องหมายเดียวกัน trace จึงมีเครื่องหมายเดียวกับ $D_1=a$ ถ้าสองวิธีตอบขัดกัน แปลว่าคิดเลขผิดที่ใดที่หนึ่ง

ขั้นที่ 4 — พื้นผิวทดสอบ: หาจุดราบสองจุด แล้วจับอานม้าที่ A

ก่อนกลับไปที่พอร์ต ลองใช้เครื่องมือกับพื้นผิวที่คิดด้วยมือได้ $f(x_1, x_2)=x_1^2+3x_1x_2+x_2^3$ พื้นผิวนี้ตั้งขึ้นเพื่อทดลอง ไม่ใช่เรื่องการเงิน ที่เลือกตัวนี้เพราะพจน์ $x_2^3$ ทำให้ความโค้งเปลี่ยนไปตามตำแหน่ง จุดราบแต่ละจุดจึงได้คำตัดสินต่างกัน ขั้นแรกหาจุดราบ: หา partial derivative ทั้งสองตัว แล้วตั้งให้เป็นศูนย์พร้อมกัน

\[ \begin{aligned} \frac{\partial f}{\partial x_1}&=2x_1+3x_2=0,\\ x_1&=-1.5x_2,\\ \frac{\partial f}{\partial x_2}&=3x_1+3x_2^2=0,\\ 3(-1.5x_2)+3x_2^2&=x_2\,(3x_2-4.5)=0,\\ A&=(0,\ 0),\qquad B=(-2.25,\ 1.5),\\ H(x)&=\begin{bmatrix}2&3\\3&6x_2\end{bmatrix},\\ H(A)&=\begin{bmatrix}2&3\\3&0\end{bmatrix},\\ D_2(A)&=2(0)-3^2=-9\lt0,\\ \lambda&=1\pm\sqrt{10}\approx4.1623,\ -2.1623. \end{aligned} \]

สมการแรกเป็นเส้นตรง จึงแก้หา $x_1=-1.5x_2$ แล้วแทนลงในสมการที่สอง ได้ $x_2(3x_2-4.5)=0$ รากคือ $x_2=0$ หรือ $x_2=4.5/3=1.5$ แทนกลับได้ $x_1=0$ และ $x_1=-1.5\times1.5=-2.25$ ตามลำดับ จึงมีจุดราบสองจุด ตั้งชื่อว่า A กับ B Hessian ได้จาก derivative อันดับสองทีละช่อง: $\partial^2f/\partial x_1^2=2$, $\partial^2f/\partial x_1\partial x_2=3$ และ $\partial^2f/\partial x_2^2=6x_2$ มีแค่ช่องขวาล่างที่ขึ้นกับตำแหน่ง

ที่ A ได้ $D_2=-9\lt0$ ตามเกณฑ์ในขั้นที่ 3 จึงเป็นอานม้า ตรวจอีกทางด้วย eigenvalues: trace คือ $2+0=2$ สมการจึงเป็น $\lambda^2-2\lambda-9=0$ และรากคือ $\lambda=1\pm\sqrt{10}$ ได้บวกหนึ่งลบหนึ่ง ผลคูณ $(1+\sqrt{10})(1-\sqrt{10})=1-10=-9$ ตรงกับ $D_2$ และผลบวก 2 ตรงกับ trace

ตรวจอีกครั้งโดยไม่ใช้ทฤษฎีเลย ที่ A ค่า $f(0, 0)=0$ ก้าวจาก A ไปสองทิศ:

\[ \begin{aligned} f(0.1,\ 0)&=0.1^2=0.01\gt0,\\ f(0.1,\ -0.1)&=0.1^2+3(0.1)(-0.1)+(-0.1)^3\\ &=0.01-0.03-0.001=-0.021\lt0. \end{aligned} \]

ก้าวทิศแรกแล้วสูงขึ้น ก้าวทิศที่สองแล้วต่ำลง จุดเดียวกันขึ้นได้และลงได้ A จึงไม่ใช่ทั้งจุดต่ำสุดและจุดสูงสุด

ขั้นที่ 5 — จุด B เป็นก้นหลุม แต่ไม่ใช่ก้นของทั้งพื้นผิว

ที่ B มี $x_2=1.5$ ช่องขวาล่างของ Hessian จึงเป็น $6x_2=6\times1.5=9$ ขั้นนี้ตรวจ B ด้วยสามวิธี คือ minor, eigenvalue และการจัดกำลังสองด้วยตัวเลขจริง เพื่อให้เห็นว่าทั้งสามวิธีพูดเรื่องเดียวกัน จากนั้นเดินออกไปไกลจาก B เพื่อดูว่าก้นหลุมนี้ลึกที่สุดจริงไหม

\[ \begin{aligned} H(B)&=\begin{bmatrix}2&3\\3&9\end{bmatrix},\quad D_1=2,\\ D_2&=2(9)-3^2=18-9=9,\\ \lambda&=\frac{11\pm\sqrt{11^2-4(9)}}{2}\approx10.1098,\ 0.8902,\\ z^{\mathsf T}H(B)z&=2(z_1+1.5z_2)^2+4.5z_2^2,\\ f(B)&=(-2.25)^2+3(-2.25)(1.5)+1.5^3\\ &=5.0625-10.125+3.375=-1.6875,\\ f(0,\ -2)&=(-2)^3=-8\lt-1.6875,\\ D_2(x)&=2(6x_2)-3^2=12x_2-9. \end{aligned} \]

สามวิธีตอบตรงกัน minor บวกทั้งคู่ eigenvalues บวกทั้งคู่ (trace คือ $2+9=11$ และผลคูณคือ $D_2=9$ จึงได้สมการ $\lambda^2-11\lambda+9=0$ แล้วใช้สูตรรากสมการกำลังสอง) และความโค้งทุกทิศเป็นผลรวมของกำลังสองที่มีตัวคูณบวก คือ $D_1=2$ กับ $D_2/D_1=9/2=4.5$ (ส่วน $1.5$ ในวงเล็บคือ $b/a=3/2$)

ที่ตรงกันไม่ใช่เรื่องบังเอิญ เพราะเป็นเรื่องเดียวกันมองสองแบบ minor test คือการจัดกำลังสองทีละตัวแปร ส่วน eigenvalue test คือการหมุนแกนให้ตรงกับแกนหลักก่อน แล้วอ่านตัวคูณ ดังนั้น B เป็นก้นหลุมแน่นอน (positive definite ไม่ใช่แค่ semidefinite)

แต่ก้นหลุมนี้ไม่ใช่จุดต่ำสุดของทั้งพื้นผิว เดินจาก B ไปไม่ไกล ที่ $(0, -2)$ ก็ได้ $f=-8$ ต่ำกว่า $f(B)=-1.6875$ แล้ว และตามแกน $x_2$ ด้านลบ $f(0, x_2)=x_2^3$ ดิ่งลงไม่มีก้น พื้นผิวนี้จึงไม่มี global minimum (จุดต่ำสุดของทั้งพื้นผิว) เลย สาเหตุคือความโค้ง $6x_2$ กลายเป็นลบเมื่อ $x_2$ ติดลบ Hessian ที่จุด B จุดเดียวมองไม่เห็นเหวนี้

สิ่งที่พูดได้อย่างปลอดภัยมีแค่ในเขตที่จำกัด ในครึ่งระนาบ $x_2\gt0.75$ จะได้ $D_2(x)=12x_2-9\gt0$ และ $D_1=2\gt0$ ทุกจุด Hessian จึงเป็น positive definite ทั้งเขต พื้นผิวจึง convex (โค้งหงายทุกที่) ในเขตนั้น ตัวครึ่งระนาบเองก็เป็นเขต convex เพราะเส้นตรงที่ลากระหว่างสองจุดในเขตอยู่ในเขตทั้งเส้น หน้าglobal กับ local minimum พิสูจน์ไว้ว่า ฟังก์ชัน convex บนเขต convex มีก้นหลุมเฉพาะที่เป็นก้นของทั้งเขตเสมอ B จึงต่ำสุดในทั้งครึ่งระนาบนี้ ตรวจที่ขอบ $x_2=0.75$ ได้:

\[ \begin{aligned} f(x_1,\ 0.75)&=x_1^2+3(0.75)x_1+0.75^3\\ &=x_1^2+2.25x_1+0.421875,\\ x_1&=-2.25/2=-1.125,\\ f(-1.125,\ 0.75)&=1.265625-2.53125+0.421875\\ &=-0.84375\gt-1.6875. \end{aligned} \]

บนขอบ จุดต่ำสุดอยู่ที่ $x_1=-1.125$ (จุดยอดของพาราโบลา $x_1^2+2.25x_1$) และยังสูงกว่า $f(B)$ ตรงกับที่ทฤษฎีบอก

ขั้นที่ 6 — objective ของพอร์ต: Hessian คงที่ทั้งพื้นผิว

กลับมาที่โจทย์เปิดเรื่อง ตอนนี้ต้องเขียนคะแนนของพอร์ตเป็นสูตรของน้ำหนัก แล้วหา Hessian ของมัน ให้ $x=(x_1, x_2)$ คือสัดส่วนของเงินทุนที่ลงหุ้นและพันธบัตร เงินที่เหลือ $1-x_1-x_2$ อยู่ในเงินสดที่ได้ดอกเบี้ย $r_f=2\%$ ถ้าส่วนนี้ติดลบ แปลว่ากู้มาที่ดอกเบี้ย 2%

ผลตอบแทนคาดหวังของพอร์ตคือผลรวมของสามก้อนตามน้ำหนัก จัดใหม่ได้เป็นดอกเบี้ยเงินสด บวกผลตอบแทนส่วนเกิน (ส่วนที่ได้เกินดอกเบี้ยเงินสด) ของก้อนเสี่ยง variance ของพอร์ตคือ $x^{\mathsf T}Vx$ (ดูความเสี่ยงของพอร์ต) เงินสดไม่แกว่ง จึงไม่อยู่ใน $V$ ทแยงของ $V$ คือ $\sigma_1^2=0.2^2=0.04$ กับ $\sigma_2^2=0.1^2=0.01$ และนอกทแยงคือ covariance $\rho\sigma_1\sigma_2=0.3\times0.2\times0.1=0.006$ คะแนน $J$ คือผลตอบแทนคาดหวังลบด้วย $\gamma$ คูณ variance ตามที่ตั้งไว้ในโจทย์เปิดเรื่อง นี่คือนิยามที่เราเลือกเอง เรียกว่า objective แบบ mean-variance

\[ \begin{aligned} \mathbb E[R_p]&=r_f(1-x_1-x_2)+\mu_1x_1+\mu_2x_2\\ &=r_f+(\mu-r_f\mathbf1)^{\mathsf T}x,\\ V&=\begin{bmatrix}\sigma_1^2&\rho\sigma_1\sigma_2\\\rho\sigma_1\sigma_2&\sigma_2^2\end{bmatrix}\\ &=\begin{bmatrix}0.04&0.006\\0.006&0.01\end{bmatrix},\\ J(x)&=r_f+(\mu-r_f\mathbf1)^{\mathsf T}x-\gamma\,x^{\mathsf T}Vx,\\ \nabla J&=(\mu-r_f\mathbf1)-2\gamma Vx,\\ H_J&=-2\gamma V,\\ \mu-r_f\mathbf1&=(0.12-0.02,\ 0.06-0.02)\\ &=(0.10,\ 0.04),\\ \gamma=2:\quad H_J&=-4V. \end{aligned} \]

ทำไม Hessian ออกมาเป็นค่าคงที่ พจน์ $r_f$ เป็นค่าคงที่ derivative จึงเป็นศูนย์ พจน์เชิงเส้น $(\mu-r_f\mathbf1)^{\mathsf T}x$ มีความชันคงที่เท่ากับตัวคูณของมัน พจน์กำลังสอง $x^{\mathsf T}Vx$ ให้ gradient $2Vx$ ตามขั้นที่ 1 หา derivative อีกครั้ง $x$ หายหมด เหลือ $-2\gamma V$ ซึ่งไม่ขึ้นกับตำแหน่ง ความโค้งจึงเท่ากันทุกจุด ตรวจครั้งเดียวใช้ได้ทั้งพื้นผิว ต่างจากพื้นผิวทดสอบที่ความโค้งเปลี่ยนไปตามที่

สังเกตว่าผลตอบแทนคาดหวังกับดอกเบี้ยเงินสดอยู่แค่ใน gradient ไม่แตะ Hessian เลย สิ่งที่กำหนดรูปทรงของพื้นผิวมีแค่ $\gamma$ กับ $V$ และ $V$ เป็น positive definite เพราะ eigenvalues ของมันบวกทั้งคู่ หาได้จากสมการในขั้นที่ 3 โดย trace ของ $V$ คือ $0.04+0.01=0.05$:

\[ \begin{aligned} \det V&=0.04(0.01)-0.006^2=0.000364,\\ \lambda^2-0.05\lambda+0.000364&=0,\\ \lambda&=\tfrac12\Big(0.05\pm\sqrt{0.05^2-4(0.000364)}\Big)\\ &\approx0.04116,\ 0.00884. \end{aligned} \]

ดังนั้นเครื่องหมายของ $\gamma$ ตัวเดียวบอกว่าพื้นผิวเป็นโดมหรือชาม ถ้า $\gamma\gt0$ ได้ $H_J=-2\gamma V$ ที่ eigenvalues ลบทั้งคู่ คือโดมคว่ำ ถ้า $\gamma\lt0$ ได้ eigenvalues บวกทั้งคู่ คือชามหงาย

ขั้นที่ 7 — แก้เงื่อนไขอันดับหนึ่ง ตัดสินด้วยอันดับสอง แล้วอ่านเป็นพอร์ตจริง

ขั้นนี้คือการคำนวณของนักวิเคราะห์คนแรก ($\gamma=2$) ทำสามอย่างตามลำดับ คือหาจุดราบ ใช้ Hessian ตัดสินว่าเป็นยอดหรือก้น แล้วแปลน้ำหนักที่ได้เป็นพอร์ตจริง

โจทย์ให้อะไรมาบ้าง: จากขั้นที่ 6 เมื่อ $\gamma=2$ จะได้ $2\gamma V=4V=\begin{bmatrix}0.16&0.024\\0.024&0.04\end{bmatrix}$ (คูณทุกช่องของ $V$ ด้วย 4) และผลตอบแทนส่วนเกิน $\mu-r_f\mathbf1=(0.10, 0.04)$ ตั้ง $\nabla J=0$ ได้ระบบสมการเชิงเส้นสองสมการ $4Vx=(0.10, 0.04)$ ระบบขนาด 2×2 แก้ได้เร็วด้วย Cramer's rule: $x_i$ เท่ากับ determinant ของ $4V$ ที่เอาฝั่งขวาไปแทนหลักที่ $i$ หารด้วย determinant ของ $4V$ เอง

\[ \begin{aligned} \det(4V)&=0.16(0.04)-0.024^2=0.005824,\\ x_1&=\frac{0.10(0.04)-0.024(0.04)}{0.005824}\approx0.521978,\\ x_2&=\frac{0.16(0.04)-0.024(0.10)}{0.005824}\approx0.686813,\\ D_1&=-0.16\lt0,\quad D_2=0.005824\gt0,\\ \mathbb E[R_p]&=0.02+0.10(0.521978)+0.04(0.686813)\\ &\approx0.0996703,\\ x^{\mathsf T}Vx&=0.04x_1^2+2(0.006)x_1x_2+0.01x_2^2\\ &\approx0.01089844+0.00430202+0.00471712\\ &\approx0.0199176,\\ \sigma_p&=\sqrt{0.0199176}\approx14.113\%,\\ J^\star&=0.0996703-2(0.0199176)\\ &\approx0.059835. \end{aligned} \]

คำตอบ: ลงหุ้น 52.20% และพันธบัตร 68.68% ของเงินทุน รวม $0.521978+0.686813=1.208791$ หรือ 120.88% เงินสดจึงเป็น $1-1.208791=-0.208791$ คือกู้ 20.88% ของทุนที่ดอกเบี้ย 2% พอร์ตนี้มีผลตอบแทนคาดหวัง 9.967% ต่อปี และความผันผวน 14.113% ต่อปี

Hessian ของคะแนนคือ $H_J=-4V$ ช่องซ้ายบนคือ $D_1=-0.16$ ติดลบ ส่วน $D_2=\det(-4V)=\det(4V)=0.005824$ เป็นบวก (สำหรับ matrix 2×2 การกลับเครื่องหมายทุกช่องไม่เปลี่ยน determinant) ตามเกณฑ์ในขั้นที่ 3 จุดนี้จึงเป็นยอดโดม ตรวจด้วย eigenvalues ได้ $-4\times0.04116\approx-0.1646$ และ $-4\times0.00884\approx-0.0354$ ลบทั้งคู่ และเพราะ Hessian คงที่ ยอดนี้คือยอดสูงสุดของทั้งพื้นผิว ไม่ใช่แค่ยอดเฉพาะที่

คะแนน $J$ มีหน่วยเป็นผลตอบแทนต่อปี จึงใช้วัดราคาของกฎต่าง ๆ ได้ ลองเทียบกับกฎ “ลงเงินครบ 100% ในหุ้นกับพันธบัตร ไม่มีเงินสด ไม่กู้” ภายใต้กฎนี้ $x_2=1-x_1$ และเงินสดเป็นศูนย์ แทนลงใน $J$:

\[ \begin{aligned} \mathbb E[R_p]&=0.12x_1+0.06(1-x_1)=0.06+0.06x_1,\\ \sigma_p^2&=0.04x_1^2+0.012x_1(1-x_1)\\ &\quad+0.01(1-x_1)^2\\ &=0.038x_1^2-0.008x_1+0.01,\\ J&=0.06+0.06x_1-2\sigma_p^2\\ &=0.04+0.076x_1-0.076x_1^2,\\ x_1&=0.076/(2\times0.076)=0.5,\\ J&=0.04+0.038-0.019=0.059,\\ J^\star-J&=0.059835-0.059=0.000835. \end{aligned} \]

$J$ เป็นพาราโบลาคว่ำในตัวแปร $x_1$ ยอดของมันอยู่ที่ $x_1=0.5$ คำตอบภายใต้กฎนี้จึงเป็นหุ้นครึ่งหนึ่ง พันธบัตรครึ่งหนึ่ง กฎลงเงินครบจึงทำให้เสียคะแนน 0.000835 ต่อปี หรือราว 8.4 bp (basis point คือ 0.01%) ในหน่วยผลตอบแทนที่ปรับความเสี่ยงแล้ว

ตรวจเองใน 10 วินาที: แทนน้ำหนักกลับลงในสมการที่สองของ $4Vx=(0.10, 0.04)$ ต้องได้ 0.04 พอดี จากนั้นใช้ทางลัดหาคะแนน: ที่จุดราบ $2\gamma Vx=\mu-r_f\mathbf1$ คูณทั้งสองข้างด้วย $x^{\mathsf T}$ แล้วหารด้วย 2 ได้ $\gamma x^{\mathsf T}Vx=\tfrac12(\mu-r_f\mathbf1)^{\mathsf T}x$ คือส่วนที่หักออกเท่ากับครึ่งหนึ่งของผลตอบแทนส่วนเกินพอดี คะแนนที่จุดราบจึงเหลือ $J^\star=r_f+\tfrac12(\mu-r_f\mathbf1)^{\mathsf T}x$

\[ \begin{aligned} 0.024x_1&=0.024(0.521978)\approx0.012527,\\ 0.04x_2&=0.04(0.686813)\approx0.027473,\\ 0.024x_1+0.04x_2&=0.012527+0.027473=0.04,\\ (\mu-r_f\mathbf1)^{\mathsf T}x&=0.0996703-0.02=0.0796703,\\ J^\star&=0.02+\tfrac12(0.0796703)\approx0.059835. \end{aligned} \]

ตรงกับที่คิดแบบเต็ม สุดท้าย สัดส่วนหุ้นในก้อนเสี่ยงคือ $0.521978/1.208791\approx43.18\%$ ส่วนผสมนี้คือส่วนผสมเดียวกับที่หน้าMarkowitz portfolio selection จะหาด้วยอีกวิธี

ขั้นที่ 8 — ใส่ γ = −2: จุดเดิมกลับหัวเป็นจุดแย่ที่สุด

นี่คือกรณีของนักวิเคราะห์คนที่สอง เมื่อ $\gamma=-2$ สมการ $\nabla J=0$ กลายเป็น $-4Vx=(0.10, 0.04)$ คำตอบจึงเป็น $-x^\star$ คือพอร์ตของคนแรกกลับเครื่องหมายทุกตัว ($x^\star=(0.521978, 0.686813)$ คือคำตอบของ $\gamma=2$ จากขั้นที่ 7) gradient ยังเป็นศูนย์ได้ แต่ Hessian พลิกเครื่องหมายทั้งตาราง

เพื่อดูภาพทั้งหมด ลองเดินตามเส้นตรงที่ผ่านคำตอบ คือพอร์ต $x=t\,x^\star$ โดย $t$ คือขนาดของก้อนเสี่ยง $t=1$ คือพอร์ตของคนแรก $t=-1$ คือพอร์ตของคนที่สอง และ $t=0$ คือเงินสดล้วน ค่าสองตัวที่ใช้มาจากขั้นที่ 7 คือ $(\mu-r_f\mathbf1)^{\mathsf T}x^\star=0.0796703$ และ $x^{\star\mathsf T}Vx^\star=0.0199176$

\[ \begin{aligned} H_J&=-2(-2)V=+4V,\quad\lambda\approx0.1646,\ 0.0354,\\ J(t\,x^\star)&=r_f+t\,(\mu-r_f\mathbf1)^{\mathsf T}x^\star\\ &\quad-\gamma t^2\,x^{\star\mathsf T}Vx^\star\\ &=0.02+0.0796703\,t-0.0199176\,\gamma t^2,\\ \gamma=-2,\ t=-1:&\quad0.02-0.0796703+0.0398352\\ &\approx-0.019835,\\ \gamma=-2,\ t=2.5:&\quad0.02+0.1991758+0.2489700\\ &\approx0.468. \end{aligned} \]

$+4V$ มี eigenvalues $4\times0.04116\approx0.1646$ และ $4\times0.00884\approx0.0354$ บวกทั้งคู่ พื้นผิวจึงหงายขึ้นทุกทิศ จุดราบที่ $t=-1$ จึงเป็นก้นหลุมของคะแนน คือพอร์ตที่คะแนนแย่ที่สุด ส่วนการหาคะแนนสูงสุดบนชามหงายไม่มีคำตอบ ยิ่งขยายก้อนเสี่ยงด้วยเงินกู้ คะแนนยิ่งสูงไม่มีที่หยุด แค่ $t=2.5$ ก็ได้ 0.468 แล้ว เงื่อนไขอันดับหนึ่ง (gradient เป็นศูนย์) อย่างเดียวบอกไม่ได้เลยว่าเพิ่งเจอยอดหรือเจอก้น

นี่คือเหตุผลจริงที่ทฤษฎีพอร์ตต้องสมมติว่านักลงทุนไม่ชอบความเสี่ยง ($\gamma\gt0$) เหตุผลไม่ใช่เพราะฟังดูสมจริง แต่เพราะถ้าไม่สมมติ ปัญหาก็ไม่มีคำตอบ

ขั้นที่ 9 — eigenvalue ตัวเล็กคือทิศที่คำตอบไวต่อ input ที่ผิด

ตัวเลขผลตอบแทนคาดหวัง $\mu$ ที่ใส่เข้าไปในโปรแกรมประมาณมาจากข้อมูลในอดีต และประมาณได้หยาบมาก ผิดไป 1 จุดเปอร์เซ็นต์ (0.01) เป็นเรื่องปกติ ขั้นนี้ถามว่า error ขนาดนี้ทำให้คำตอบขยับไปแค่ไหน และ Hessian ตอบคำถามนี้ได้ทันที

โจทย์ให้อะไรมาบ้าง: สมมติเราใส่ผลตอบแทนหุ้นสูงเกินจริง 1 จุด คือ $\Delta\mu=(0.01, 0)$ หรือใส่ผลตอบแทนพันธบัตรสูงเกินจริง 1 จุด คือ $\Delta\mu=(0, 0.01)$ คำตอบจากขั้นที่ 7 คือ $x^\star=(2\gamma V)^{-1}(\mu-r_f\mathbf1)$ ซึ่งเป็นเชิงเส้นใน $\mu$ ถ้า $\mu$ ผิดไป $\Delta\mu$ คำตอบก็ขยับไป $\Delta x=(4V)^{-1}\Delta\mu$ ตรง ๆ inverse ของ matrix 2×2 หาได้ง่าย: สลับสองช่องบนทแยง เปลี่ยนเครื่องหมายสองช่องนอกทแยง แล้วหารด้วย determinant 0.005824 จากขั้นที่ 7

\[ \begin{aligned} \Delta x&=(4V)^{-1}\,\Delta\mu,\\ (4V)^{-1}&=\frac{1}{0.005824}\begin{bmatrix}0.04&-0.024\\-0.024&0.16\end{bmatrix},\\ \Delta\mu=(0.01,\ 0):&\quad\Delta x=\tfrac{1}{0.005824}(0.0004,\ -0.00024)\\ &\quad\approx(0.0687,\ -0.0412),\\ \Delta\mu=(0,\ 0.01):&\quad\Delta x=\tfrac{1}{0.005824}(-0.00024,\ 0.0016)\\ &\quad\approx(-0.0412,\ 0.2747). \end{aligned} \]

คำตอบ: ผิดเรื่องหุ้น 1 จุด น้ำหนักขยับไปเป็นระยะ $\sqrt{0.0687^2+0.0412^2}\approx0.080$ แต่ผิดเรื่องพันธบัตร 1 จุด น้ำหนักพันธบัตรกระโดดขึ้น 27.5 จุดเปอร์เซ็นต์ และเงินกู้เพิ่มจาก 20.9% เป็น 44.2% ของทุน:

\[ \begin{aligned} x_1&=0.521978-0.041209=0.480769,\\ x_2&=0.686813+0.274725=0.961538,\\ 1-x_1-x_2&=1-1.442307=-0.442307. \end{aligned} \]

ทำไมพันธบัตรไวกว่ามาก เพราะชามของคะแนนแบนในทิศที่เกือบเป็นแกนพันธบัตร ในทิศนั้น eigenvalue ของ $4V$ คือ 0.0354 เทียบกับ 0.1646 ในทิศที่เกือบเป็นแกนหุ้น การคูณด้วย $(4V)^{-1}$ คือการหารด้วย eigenvalue ทีละทิศ ทิศที่ eigenvalue เล็กจึงถูกขยายมากกว่า $0.1646/0.0354\approx4.65$ เท่า

ตรวจเองใน 10 วินาที: ทิศที่แบนก็แปลว่าเดินไปแล้วเสียคะแนนน้อยด้วย ตามขั้นที่ 2 คะแนนที่หายไปเมื่อเดินจากยอดไป $\Delta x$ คือ $-\tfrac12\Delta x^{\mathsf T}H_J\Delta x$ สูตรนี้ตรงเป๊ะ ไม่ใช่ค่าประมาณ เพราะคะแนนเป็นพหุนามกำลังสอง Hessian จึงคงที่ และเพราะ $4V\Delta x=\Delta\mu$ จึงย่อได้อีก ใส่น้ำหนักใหม่ลงในคะแนนที่ใช้ $\mu$ ตัวจริง:

\[ \begin{aligned} -\tfrac12\Delta x^{\mathsf T}H_J\Delta x&=\tfrac12\Delta x^{\mathsf T}(4V\Delta x)\\ &=\tfrac12\Delta x^{\mathsf T}\Delta\mu\\ &=\tfrac12(0.274725)(0.01)\approx0.0013736,\\ J&=0.059835-0.0013736\approx0.05846. \end{aligned} \]

คะแนนหายไปแค่ 0.0014 แต่น้ำหนักกับเลเวอเรจ (สัดส่วนเงินกู้) เปลี่ยนไปมาก ในทางปฏิบัติแปลว่าต้องซื้อขายมาก และเสียค่าซื้อขายสูง และถ้า $V$ ก็ประมาณผิดด้วย ความเสี่ยงจริงอาจต่างจากที่คิดไว้มาก

กับดัก: ดูความโค้งไม่ครบ ลืมบางส่วนของ gradient หรือเจอสันแบน

กับดักที่ 1: เห็นช่องแรกของ Hessian เป็นบวก แล้วสรุปว่าเป็นก้นหลุม ที่ A ช่อง $D_1=2$ เป็นบวก หลายคนรีบสรุปว่าพื้นโค้งขึ้น จึงเป็นก้นหลุม ผิด เพราะ $D_1$ บอกความโค้งแค่ทิศ $x_1$ ทิศเดียว ช่องไขว้ที่เป็น 3 ทำให้ทิศผสมโค้งลงได้ ต้องดู $D_2=2(0)-3^2=-9\lt0$ ด้วย ซึ่งบอกว่า A เป็นอานม้า ก้าวจาก A ไปที่ $(0.1, -0.1)$ ก็ได้ $f=-0.021$ ต่ำกว่า $f(A)=0$ จริง ต้องผ่านเกณฑ์ครบทุกข้อ ไม่ใช่ผ่านข้อแรกแล้วจบ

กับดักที่ 2: เห็น Hessian ไม่ติดลบ (positive semidefinite) แล้วรับรองว่าเป็นก้นหลุม semidefinite เป็นแค่เงื่อนไขจำเป็น ไม่พอจะรับรอง ตัวอย่างตัวแปรเดียว: $x^4$, $-x^4$ และ $x^3$ ล้วนมี $f'(0)=0$ และ $f''(0)=0$ จึงผ่านเกณฑ์ “ไม่ติดลบ” ทั้งสามตัว แต่ $x^4$ เป็นก้นหลุม $-x^4$ เป็นยอด และ $x^3$ ที่ $x=-0.1$ ได้ $(-0.1)^3=-0.001$ ต่ำกว่าค่า 0 ที่ $x=0$ จุดนั้นจึงไม่ใช่ก้นหลุม ต้องเป็น definite (บวกจริงทุกทิศ) จึงรับรองได้

กับดักที่ 3: ลืมดอกเบี้ยเงินสด คนที่ใส่ผลตอบแทนรวม 12% กับ 6% ลงในคะแนนตรง ๆ แทนผลตอบแทนส่วนเกิน 10% กับ 4% กำลังสมมติโดยไม่รู้ตัวว่ากู้เงินได้ฟรี ($r_f=0$) แก้ $4Vx=(0.12, 0.06)$ แบบเดียวกับขั้นที่ 7 แล้วใช้ทางลัด $J=r_f+\tfrac12(\mu-r_f\mathbf1)^{\mathsf T}x$ ได้:

\[ \begin{aligned} x_1&=\frac{0.12(0.04)-0.024(0.06)}{0.005824}\approx0.5769,\\ x_2&=\frac{0.16(0.06)-0.024(0.12)}{0.005824}\approx1.1538,\\ J&=0+\tfrac12\big(0.12(0.5769)+0.06(1.1538)\big)\\ &\approx0.0692. \end{aligned} \]

ผลผิดคือหุ้น 57.7% พันธบัตร 115.4% และกู้ $1.731-1=0.731$ หรือ 73% ของทุน กฎลงเงินครบจึงดูเหมือนมีราคา $0.0692-0.059=0.0102$ ขณะที่ราคาจริงจากขั้นที่ 7 คือ 0.000835 ผิดไปราว $0.0102/0.000835\approx12$ เท่า ที่น่ากลัวคือ Hessian ยังเป็น $-4V$ เหมือนเดิมทุกช่อง คำตัดสินยังเป็นยอดโดม ความผิดทั้งหมดอยู่ใน gradient ซึ่งเกณฑ์ความโค้งไม่มีทางจับได้

กับดักที่ 4: correlation ที่ประมาณได้เป็น 1.00 พอดี เมื่อ $\rho=1$ covariance นอกทแยงคือ $1\times0.2\times0.1=0.02$ จึงได้ $V=\begin{bmatrix}0.04&0.02\\0.02&0.01\end{bmatrix}$ ซึ่งมี $\det V=0.04(0.01)-0.02^2=0$ Hessian $-4V$ มี trace $-0.16-0.04=-0.2$ และ determinant 0 eigenvalues จึงเป็น 0 กับ −0.2 นี่คือสันแบนในรูปแรก

สันอยู่ตรงไหน เมื่อ $\rho=1$ หุ้นขยับเป็นสองเท่าของพันธบัตรเสมอ เพราะ $\sigma_1/\sigma_2=0.2/0.1=2$ ซื้อหุ้น 1 ส่วนแล้ว short พันธบัตร 2 ส่วน การแกว่งจึงหักล้างกันหมด ในทิศ $z=(1, -2)$ จึงได้ $Vz=(0.04-0.04,\ 0.02-0.02)=(0, 0)$ variance เป็นศูนย์ แต่ผลตอบแทนส่วนเกินยังเป็น $0.10(1)+0.04(-2)=0.02$ ต่อหน่วย เดินจากเงินสดล้วนไปตามสันเป็นระยะ $t$ คะแนนจึงเป็น $J=0.02+0.02t$ ที่ $t=100$ ได้ $0.02+0.02(100)=2.02$ และไม่มีเพดาน

ผลคือ optimizer จะคืนน้ำหนักหลายพันเปอร์เซ็นต์ ที่ long (ซื้อถือ) ตัวหนึ่งและ short อีกตัวหักล้างกัน คำตอบที่ถูกคือปัญหานี้ไม่มีคำตอบเดียว นั่นไม่ใช่บั๊กของ solver แต่เป็นเพราะ $V$ กลับด้านไม่ได้ (ดูrank และ invertibility)

ใช้ทำอะไรบนโต๊ะจริง

ทุกครั้งที่ optimizer ของพอร์ตคืนคำตอบ ให้ดู eigenvalue ที่เล็กที่สุดของ covariance matrix ก่อน ถ้าค่านั้นติดลบหรือใกล้ศูนย์ คำตอบจะมีน้ำหนักก้อนใหญ่ที่ long ตัวหนึ่งและ short อีกตัวหักล้างกันเป็นคู่ แบบเดียวกับสันแบนในกับดักที่ 4 ทิศที่เป็นปัญหาอ่านได้จาก eigenvector ของ eigenvalue ตัวนั้น

ปัญหานี้เกิดบ่อยเมื่อจำนวนสินทรัพย์มากกว่าจำนวนวันของข้อมูล เพราะ covariance matrix ของสินทรัพย์ $n$ ตัว มีค่าที่ต้องประมาณ $n(n+1)/2$ ค่า (variance $n$ ค่าบนทแยง บวก covariance $n(n-1)/2$ คู่ ดูcovariance matrix) พอร์ต 500 ตัวจึงมี $500\times501/2=125{,}250$ ค่าที่ต้องประมาณ วิธีแก้อย่าง Ledoit–Wolf shrinkage ดึง covariance ที่ประมาณได้เข้าหาเป้าที่เรียบกว่า ผลคือ eigenvalue ตัวเล็กถูกยกขึ้น ชามจึงแบนน้อยลงโดยตรง

ถ้าคะแนนไม่ใช่พหุนามกำลังสอง เช่นตอน calibrate model (ปรับ parameter หลายตัวให้ model ตรงกับราคาในตลาด) Hessian จะเปลี่ยนไปตามตำแหน่งแบบพื้นผิวทดสอบ วิธีตรวจที่ถูกที่สุดคือเดินออกจากคำตอบไปหลายทิศทีละนิด แล้วดูว่ามีทิศไหนดีขึ้นไหม ถ้ามี แปลว่า optimizer หยุดอยู่บนอานม้า แบบเดียวกับที่เราเดินรอบ A ส่วนการคำนวณ Hessian ครบทุกช่องมีต้นทุน คือต้องหา $n(n+1)/2$ ค่าต่อครั้ง (ไม่ใช่ $n^2$ เพราะ $H$ สมมาตร) หน้าgradient descent และ Newton's method จะชั่งว่าคุ้มไหม

โจทย์ตรวจความเข้าใจ

1. ฝึกมือกับพื้นผิวง่าย ๆ ก่อน ให้ $f(x, y)=x^2+xy+y^2-3x$ หาจุดราบของ $f$ แล้วใช้ Hessian ตัดสินว่าเป็นก้นหลุม ยอดโดม หรืออานม้า จุดนั้นเป็นจุดต่ำสุดของทั้งพื้นผิว (global minimum) ไหม?

เฉลย

ตั้ง partial derivative ทั้งสองตัวให้เป็นศูนย์ แล้วแก้ระบบสมการ:

\[ \begin{aligned} \partial f/\partial x&=2x+y-3=0,\\ \partial f/\partial y&=x+2y=0,\quad x=-2y,\\ 2(-2y)+y-3&=-3y-3=0,\quad y=-1,\ x=2,\\ H&=\begin{bmatrix}2&1\\1&2\end{bmatrix},\quad D_1=2,\\ D_2&=2(2)-1^2=3,\\ f(2,\ -1)&=4+(-2)+1-6=-3. \end{aligned} \]

$D_1\gt0$ และ $D_2\gt0$ จึงเป็นก้นหลุม ตรวจด้วย eigenvalues: trace 4 และผลคูณ 3 จึงได้ 3 กับ 1 บวกทั้งคู่ ตรงกัน Hessian เป็นค่าคงที่และ positive definite ทุกที่ พื้นผิวจึงหงายทุกที่ จุด $(2, -1)$ ที่ $f=-3$ จึงเป็น global minimum

2. ลูกค้าอีกรายกลัวความเสี่ยงเป็นสองเท่าของรายแรก จึงใช้ $\gamma=4$ ส่วนตัวเลขอื่นเหมือนโจทย์เปิดเรื่องทุกตัว พอร์ตที่ได้จากการแก้ $\nabla J=0$ เปลี่ยนไปอย่างไร?

เฉลย

จาก $\nabla J=0$ ได้ $x=V^{-1}(\mu-r_f\mathbf1)/(2\gamma)$ ตัว $\gamma$ อยู่แค่ในตัวส่วน เพิ่ม $\gamma$ จาก 2 เป็น 4 น้ำหนักทุกตัวจึงลดลงครึ่งหนึ่ง Hessian $-2\gamma V=-8V$ ยังลบทุกทิศ จุดนี้จึงยังเป็นยอดสูงสุด

\[ \begin{aligned} x_1&=0.521978/2\approx0.2610,\\ x_2&=0.686813/2\approx0.3434,\\ 1-x_1-x_2&=1-0.6044=0.3956,\\ \sigma_p&=14.113\%/2\approx7.056\%,\\ J&=0.02+\tfrac12(0.0796703/2)\approx0.039918. \end{aligned} \]

ได้หุ้น 26.10% พันธบัตร 34.34% ก้อนเสี่ยงรวม 60.44% และฝากเงินสด 39.56% แทนที่จะกู้ ความผันผวนลดลงครึ่งหนึ่งเพราะน้ำหนักทุกตัวลดลงครึ่งหนึ่ง ส่วนคะแนนใช้ทางลัดจากขั้นที่ 7 สัดส่วนหุ้นในก้อนเสี่ยงคือ $0.2610/0.6044\approx43.18\%$ เท่าเดิม $\gamma$ จึงปรับแค่ขนาดของก้อนเสี่ยง ไม่ปรับส่วนผสมข้างใน

3. ผู้ขายข้อมูล (บริษัทที่ขายตัวเลขประมาณการให้โต๊ะ) ส่ง covariance matrix ของสินทรัพย์สองตัวมาเป็น $\begin{bmatrix}0.04&0.05\\0.05&0.06\end{bmatrix}$ covariance matrix ที่ถูกต้องต้องเป็น positive semidefinite เพราะ variance ของพอร์ตใด ๆ ติดลบไม่ได้ ก่อนป้อนเข้า optimizer ให้ใช้เกณฑ์ 2×2 ตรวจว่า matrix นี้ใช้ได้ไหม

เฉลย

ใช้ไม่ได้ ตรวจด้วย minor แล้วหาว่าผิดตรงไหน:

\[ \begin{aligned} D_1&=0.04\gt0,\\ D_2&=0.04(0.06)-0.05^2\\ &=0.0024-0.0025=-0.0001\lt0,\\ \rho&=\frac{0.05}{\sqrt{0.04\times0.06}}\approx1.0206\gt1,\\ \sigma_p^2&=0.04(1)^2+2(0.05)(1)(-0.9)\\ &\quad+0.06(-0.9)^2\\ &=0.04-0.09+0.0486=-0.0014. \end{aligned} \]

$D_2$ ติดลบ matrix นี้จึงไม่ใช่ positive semidefinite ตรวจด้วย eigenvalues: trace คือ $0.04+0.06=0.10$ สมการจึงเป็น $\lambda^2-0.10\lambda-0.0001=0$ ได้รากประมาณ 0.1010 กับ −0.00099 ต่างเครื่องหมาย ตรงกับเกณฑ์

ต้นเหตุอยู่ที่ covariance 0.05 ใหญ่เกินไป correlation ที่ซ่อนอยู่ คือ covariance หารด้วยผลคูณของ SD สองตัว ได้เกิน 1 ซึ่งเป็นไปไม่ได้ ผลคือพอร์ต $(1, -0.9)$ (ซื้อตัวแรก 1 ส่วน short ตัวที่สอง 0.9 ส่วน) มี “variance” ติดลบ optimizer ที่หาความเสี่ยงต่ำสุดจะไล่ตามทิศนี้ไปไม่หยุด ต้องส่งกลับให้ผู้ขายแก้

// Leading minors, eigenvalues and the verdict for a stationary point with symmetric 2x2 Hessian H.
function classify(H) {
  const [a, b, c] = [H[0][0], H[0][1], H[1][1]], D2 = a * c - b * b;
  const r = Math.hypot((a - c) / 2, b), eigen = [(a + c) / 2 + r, (a + c) / 2 - r];
  let verdict = 'inconclusive';
  if (D2 < 0) verdict = 'saddle';
  else if (D2 > 0) verdict = a > 0 ? 'minimum' : 'maximum';
  return {D1: a, D2, eigen, verdict};
}
// Test surface f = x1^2 + 3 x1 x2 + x2^3.
const f = ([p, q]) => p * p + 3 * p * q + q ** 3;
const hess = ([, q]) => [[2, 3], [3, 6 * q]];
// Mean-variance with cash at rf: J = rf + (mu - rf)'x - gamma x'Vx; solve 2 gamma V x = mu - rf.
function meanVariance(mu, V, gamma, rf) {
  if (gamma === 0) throw new RangeError('gamma = 0: the objective is linear, no stationary point');
  const e = mu.map(m => m - rf), A = V.map(r => r.map(v => 2 * gamma * v));
  const det = A[0][0] * A[1][1] - A[0][1] * A[1][0];
  if (Math.abs(det) < 1e-14) throw new RangeError('Singular covariance: flat ridge, no unique answer');
  const x = [(e[0] * A[1][1] - A[0][1] * e[1]) / det, (A[0][0] * e[1] - e[0] * A[1][0]) / det]; // Cramer
  const variance = V[0][0] * x[0] ** 2 + 2 * V[0][1] * x[0] * x[1] + V[1][1] * x[1] ** 2;
  const excess = e[0] * x[0] + e[1] * x[1];
  return {x, cash: 1 - x[0] - x[1], ret: rf + excess, sd: Math.sqrt(variance),
    J: rf + excess - gamma * variance, verdict: classify(V.map(r => r.map(v => -2 * gamma * v))).verdict};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ที่จุดราบ ค่าที่เปลี่ยนเมื่อก้าวไป $z$ คือ $\tfrac12z^{\mathsf T}Hz$ ความโค้งทุกทิศจึงเป็นตัวตัดสิน positive definite คือก้นหลุม negative definite คือยอดโดม eigenvalues ต่างเครื่องหมายคืออานม้า และถ้ามี eigenvalue เป็นศูนย์ ความโค้งตัดสินไม่ได้
  • เกณฑ์ 2×2: ถ้า $D_2\lt0$ คืออานม้า ถ้า $D_2\gt0$ ให้ดูเครื่องหมายของ $D_1$ (บวกคือก้นหลุม ลบคือยอดโดม) ถ้า $D_2=0$ ตัดสินไม่ได้ คำตอบต้องตรงกับเครื่องหมายของ eigenvalues เสมอ
  • ก้นหลุมเฉพาะที่อาจไม่ใช่ก้นของทั้งพื้นผิว บนพื้นผิวทดสอบ $f(B)=-1.6875$ แต่ $f(0, -2)=-8$ และพื้นผิวดิ่งลงไม่มีก้น
  • คะแนนแบบ mean-variance มี Hessian $-2\gamma V$ คงที่ทั้งพื้นผิว เมื่อ $\gamma=2$ จึงได้ยอดเดียวของทั้งพื้นผิว คือหุ้น 52.20% พันธบัตร 68.68% กู้ 20.88% และคะแนน 0.059835 ส่วน $\gamma\lt0$ พลิกยอดให้กลายเป็นก้นหลุม
