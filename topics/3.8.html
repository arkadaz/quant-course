3.8 Linear Transformations and Portfolio Risk

จาก return vector ผ่าน weights ไป variance และ diversification ที่วัดได้

portfolio มี sector holdings ห้าตัวและ risk committee ถามว่าเพิ่ม holdings แล้ว volatility ลดจริงแค่ไหน Linear transformation ทำให้ map returns เป็น portfolio return และ covariance เป็น risk number เดียว

ศัพท์การเงินที่เพิ่งโผล่มา

linear transformation
การ map vector ด้วย matrix ที่รักษาการบวกและ scalar multiplication ใช้เปลี่ยน asset returns เป็น portfolio or factor returns
portfolio return
ผลตอบแทนรวมที่เกิดจาก weighted sum ของ asset returns ใช้วัด P&L percentage ของ portfolio
portfolio variance
variance ของ portfolio return หลังรวมทั้ง weights และ covariance ใช้กำหนด risk budget
diversification
การกระจาย position ไปหลาย exposures ที่ไม่เคลื่อนเหมือนกันเพื่อลด aggregate risk ใช้เลือกจำนวน holdings และ weights
weight vector
vector ของสัดส่วนหรือ notional weights ใน portfolio ใช้กำหนด exposure ต่อแต่ละ asset
SPY
กองทุนที่ติดตาม S&P 500 ในตลาดสหรัฐฯ ใช้เป็น broad-market holding
AAPL
หุ้น Apple ในตลาดสหรัฐฯ ใช้เป็น single-name holding ในตัวอย่าง

ตอบคำถาม committee

เพิ่ม holdings ช่วยลด risk เฉพาะส่วนที่ไม่เคลื่อนร่วมกัน ถ้า sector assets มี common market component สูง volatility จะไม่ลงถึงศูนย์ การรายงาน diversification curve ทำให้คำว่า spread risk มีเลขรองรับ

กับดัก: นับจำนวนชื่อแทนดู covariance

สิบ holdings ที่เคลื่อนเหมือนกันอาจมี risk ใกล้หนึ่ง holding การนับ ticker โดยไม่ดู เป็นการวัด diversification ด้วยจำนวนเสื้อทีม ไม่ใช่ด้วย covariance
