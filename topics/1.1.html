1.1 Random Variables and the Cumulative Distribution Function (CDF)

CDF ตอบคำถามเดียว: “โอกาสที่ค่าที่สุ่มได้จะไม่เกินเกณฑ์ที่เราตั้ง มีเท่าไร” คำถามเรื่องช่วง เรื่องหาง และเรื่องระดับขาดทุน สร้างต่อจากคำตอบนี้ทั้งหมด

ฝ่ายความเสี่ยงของกองทุนแห่งหนึ่งดูแลพอร์ตหุ้นมูลค่า \$50 ล้าน (พอร์ตคือหุ้นทั้งหมดที่กองทุนถืออยู่รวมกัน) ทุกเช้าหัวหน้าฝ่ายต้องรู้ว่า วันหนึ่ง ๆ พอร์ตมีโอกาสขาดทุนหนักแค่ไหน เพราะถ้าโอกาสสูงเกินไป ต้องขายหุ้นบางส่วนออกเพื่อลดความเสี่ยง

ข้อมูลที่มีคือผลตอบแทนรายวันสิบวันล่าสุด ผลตอบแทนรายวันคือมูลค่าพอร์ตที่เปลี่ยนไปในหนึ่งวัน คิดเป็นเปอร์เซ็นต์ เช่น −2% แปลว่าพอร์ตเสียไป $0.02\times\$50$ ล้าน $=\$1$ ล้าน สิบวันนี้เป็นตัวเลขสมมติที่เลือกให้นับง่าย เรียงจากน้อยไปมากได้ดังนี้

−3%, −2%, −1%, −1%, 0%, 0%, +1%, +2%, +2%, +4%

หัวหน้าหยิบมาหนึ่งวันแบบสุ่ม ทุกวันมีโอกาสถูกหยิบเท่ากัน การหยิบนี้แทนคำถามจริงว่า “พรุ่งนี้จะเป็นวันแบบไหน” ถ้าเชื่อว่าพรุ่งนี้หน้าตาเหมือนสิบวันนี้ แล้วหัวหน้าถามสองข้อ

  1. โอกาสที่วันนั้นขาดทุนตั้งแต่ 2% ขึ้นไป (เสียตั้งแต่ \$1 ล้าน) มีเท่าไร
  2. โอกาสที่วันนั้นกำไรเกิน 2% มีเท่าไร
ลองตอบก่อนเปิดเฉลย

ข้อแรก “ขาดทุนตั้งแต่ 2%” คือผลตอบแทนไม่เกิน −2% วันที่เข้าเงื่อนไขมีสองวัน คือ −3% กับ −2% จึงได้ $2/10=20\%$ ถ้านับแค่วัน −3% จะได้ $1/10=10\%$ ซึ่งผิด เพราะคำว่า “ตั้งแต่” รวมวันที่เสียพอดี 2% ด้วย

ข้อสอง วันที่กำไรเกิน 2% มีวันเดียวคือ +4% จึงได้ $1/10=10\%$ วัน +2% สองวันไม่นับ เพราะ “เกิน” ไม่รวมค่าที่เท่ากับเกณฑ์ ทั้งสองคำตอบอ่านได้จากฟังก์ชันเดียวที่หน้านี้จะสร้าง ชื่อว่า CDF

ภาพรวมก่อนลงสูตร

ก่อนหยิบ เรายังไม่รู้ว่าจะได้วันไหน แต่รู้ว่าแต่ละวันมีผลตอบแทนเท่าไร จึงเขียนกฎได้ว่า “หยิบได้วันไหน ให้อ่านผลตอบแทนของวันนั้น” กฎที่เปลี่ยนผลสุ่มให้เป็นตัวเลขหนึ่งตัวแบบนี้เรียกว่า random variable

เราเขียน random variable ด้วยตัวใหญ่ $X$ ค่าของ $X$ ยังไม่รู้จนกว่าจะหยิบ ส่วนตัวเล็ก $x$ คือเกณฑ์ที่เราตั้งเองเพื่อถาม เช่น $x=-2\%$ สองตัวนี้ต่างกัน ตัวใหญ่คือของที่สุ่ม ตัวเล็กคือเส้นที่เราขีดไว้

ทั้งสองคำถามของหัวหน้าเขียนด้วยประโยคแบบเดียวได้: “โอกาสที่ $X$ ไม่เกิน $x$ มีเท่าไร” ข้อแรกถามตรง ๆ ที่ $x=-2\%$ ข้อสองถามที่ $x=2\%$ แต่กลับด้าน เพราะวันที่กำไรเกิน 2% คือทุกวันที่เหลือ หลังตัดวันที่ไม่เกิน 2% ออกไป

ถ้าตอบคำถามนี้ไว้ล่วงหน้าทุกเกณฑ์ $x$ แล้วจดเป็นตาราง เราจะได้ฟังก์ชันหนึ่งตัว: ใส่เกณฑ์ $x$ เข้าไป ได้โอกาสออกมา ฟังก์ชันนี้ชื่อ cumulative distribution function หรือ CDF คำว่า cumulative แปลว่าสะสม เพราะมันนับรวมทุกค่าตั้งแต่ต่ำสุดขึ้นมาจนถึง $x$

CDF ใช้ได้กับ random variable ทุกชนิด ทั้งแบบที่ค่าเป็นจุด ๆ นับไล่ได้ เช่น สิบวันนี้ และแบบต่อเนื่องที่ค่าเป็นเลขใดก็ได้บนเส้นจำนวน วิชาความน่าจะเป็นจึงเริ่มจาก CDF ก่อนเครื่องมืออื่น

แผนของหน้านี้มีห้าช่วง

  • สร้าง CDF ของสิบวันนี้ด้วยการนับ
  • ใช้ CDF ตอบคำถามสามแบบ: โอกาสของช่วง เช่น ระหว่าง −2% ถึง +2% โอกาสของค่าเดียว เช่น 0% พอดี และโอกาสของหางขวา คือฝั่งกำไรมากที่เกินเกณฑ์
  • อ่าน CDF กลับทาง: ให้โอกาสมา แล้วหาเกณฑ์ เกณฑ์ที่ได้เรียกว่า quantile
  • ทำซ้ำกับข้อมูลจริง คือผลตอบแทนรายวันของ SPY ตลอดปี 2024 จำนวน 252 วัน SPY คือกองทุนที่ซื้อขายในตลาดหุ้นเหมือนหุ้นตัวหนึ่ง และขึ้นลงตามดัชนี S&P 500 ของหุ้นใหญ่ 500 ตัวในสหรัฐ ส่วนที่มาของเลข 252 อยู่ในตัวอย่าง SPY ด้านล่าง
  • หา VaR จากข้อมูล SPY ชุดเดียวกัน VaR คือตัวเลขที่ธนาคารใช้ตอบว่า “วันแย่ระดับ 1 ใน 100 วัน พอร์ตจะเสียประมาณเท่าไร”
ศัพท์ที่ใช้ในหน้านี้
random variable
กฎที่เปลี่ยนผลสุ่มแต่ละแบบให้เป็นตัวเลขหนึ่งตัว เช่น หยิบได้วันไหน → ผลตอบแทนของวันนั้น มีไว้เพื่อให้ถามเรื่องโอกาสเป็นตัวเลขได้ แทนการบรรยายเป็นคำ
CDF (cumulative distribution function)
ฟังก์ชัน $F(x)=P(X\le x)$ ใส่เกณฑ์ $x$ แล้วได้โอกาสที่ $X$ ไม่เกิน $x$ คือโอกาสสะสมจากค่าต่ำสุดขึ้นมาถึง $x$ ใช้ตอบคำถามเรื่องช่วง ค่าเดียว และหาง
ECDF (empirical CDF)
CDF ที่ได้จากการนับข้อมูลจริง คือสัดส่วนของวันที่ไม่เกินเกณฑ์ ใช้แทน CDF จริงที่เราไม่รู้ โดยเชื่อว่าข้อมูลย้อนหลังเป็นตัวแทนของสิ่งที่จะเกิด
quantile
การอ่าน CDF กลับทาง: ให้ระดับโอกาสมา แล้วหาเกณฑ์ที่น้อยที่สุดซึ่งยอดสะสมขึ้นถึงระดับนั้น ใช้แปลงระดับโอกาสให้เป็นระดับขาดทุน
median
quantile ที่ระดับ 0.5 คือเส้นแบ่งที่ครึ่งหนึ่งของข้อมูลอยู่ต่ำกว่าหรือเท่ากับมัน
tail (หาง)
ปลายสองข้างของการกระจายของค่า หางซ้ายคือวันที่ขาดทุนหนัก หางขวาคือวันที่กำไรมาก ผู้ดูแลความเสี่ยงสนใจหางซ้ายที่สุด
VaR (Value at Risk)
ระดับขาดทุนในช่วงเวลาที่กำหนด เช่น หนึ่งวัน ที่โอกาสจะเสียเกินระดับนี้ไม่เกินที่ตั้งไว้ เช่น 1% ซึ่งเรียกว่า VaR 99% ถ้า VaR 99% รายวันเท่ากับ \$1 ล้าน แปลว่าประมาณ 99 วันจาก 100 วัน พอร์ตจะเสียไม่เกิน \$1 ล้าน ธนาคารใช้ตัวเลขนี้เป็นเพดานคุมความเสี่ยง

ขั้นที่ 1 — CDF คือยอดนับสะสม

ขั้นแรกคือสร้าง CDF ให้เห็นกับตา เพราะทุกคำถามต่อจากนี้ประกอบจากมัน เราหยิบหนึ่งวันจากสิบวันแบบสุ่ม แต่ละวันจึงมีโอกาสถูกหยิบ $1/10$ เท่ากัน ดังนั้นโอกาสที่ $X$ ไม่เกินเกณฑ์ ก็คือจำนวนวันที่ไม่เกินเกณฑ์ หารด้วย 10

ในสูตร $P(\ldots)$ อ่านว่า “โอกาสที่เหตุการณ์ในวงเล็บจะเกิด” และ $\equiv$ แปลว่า “นิยามว่า”

\[\begin{aligned} F(x)&\equiv P(X\le x)\\ F(-2\%)&=\frac{2}{10}=0.20\\ F(0\%)&=\frac{6}{10}=0.60\\ F(2\%)&=\frac{9}{10}=0.90\\ F(3\%)&=\frac{9}{10}=0.90 \end{aligned}\]

CDF นับ “ทุกวันจนถึงเกณฑ์” ไม่ใช่ “เฉพาะวันที่เท่ากับเกณฑ์” ดูที่ 0% เป็นตัวอย่าง วันขาดทุนมีสี่วัน (−3%, −2%, −1%, −1%) วัน 0% มีอีกสองวัน รวมเป็น $4+2=6$ วัน จึงได้ $6/10$

จุดที่คนมักสะดุดคือ $F(3\%)$ ไม่มีวันไหนได้ 3% พอดี แต่คำถาม “ไม่เกิน 3%” ยังตอบได้ คือเก้าวันเดิม ทุกวันยกเว้นวัน +4% แปลว่าเกณฑ์ $x$ เป็นเลขอะไรก็ได้บนเส้นจำนวน ไม่ต้องเป็นค่าที่มีในข้อมูล

ตารางข้างล่างนับแบบเดียวกันที่ทุกเกณฑ์ซึ่งมีข้อมูลตกอยู่ ระหว่างสองแถวที่ติดกัน ความสูงของ $F$ คงที่ เพราะไม่มีวันใหม่ให้นับเพิ่ม

ขั้นที่ 2 — โอกาสของช่วงคือผลต่างของความสูงสองตำแหน่ง

คำถามถัดไปที่ฝ่ายความเสี่ยงมักถามคือเรื่องช่วง เช่น “วันปกติ” ที่พอร์ตขยับไม่แรง มีกี่เปอร์เซ็นต์ของวันทั้งหมด ให้ช่วงที่ถามคือผลตอบแทนมากกว่า −2% แต่ไม่เกิน +2% เราไม่ต้องนับใหม่ เพราะค่า CDF สองตำแหน่งที่มีอยู่แล้วให้คำตอบได้ทันที

ให้ $a$ เป็นขอบล่างของช่วง และ $b$ เป็นขอบบน โดย $a\lt b$ ในตัวอย่างนี้ $a=-2\%$ และ $b=2\%$

\[\begin{aligned} P(X\le b)&=P(X\le a)+P(a\lt X\le b)\\ P(a\lt X\le b)&=F(b)-F(a)\\[4pt] P(-2\%\lt X\le 2\%)&=0.90-0.20\\ &=0.70 \end{aligned}\]

ความคิดคือแบ่งวันเป็นกอง วันทั้งหมดที่ไม่เกิน $b$ แยกได้เป็นสองกอง กองแรกคือวันที่ไม่เกิน $a$ กองที่สองคือวันที่มากกว่า $a$ แต่ไม่เกิน $b$ ไม่มีวันไหนอยู่ทั้งสองกอง โอกาสของสองกองจึงบวกกันได้ตรง ๆ พอย้าย $P(X\le a)=F(a)$ ไปอีกข้าง ก็ได้สูตรผลต่าง ตัวเลข $0.90$ คือ $F(2\%)$ และ $0.20$ คือ $F(-2\%)$ จากตารางในขั้นก่อน

ระวังขอบซ้าย วัน −2% อยู่ในกองแรก (ไม่เกิน $a$) จึงถูกลบออกไปด้วย ช่วงที่ได้จึงเป็น “มากกว่า −2%” ไม่ใช่ “ตั้งแต่ −2%” ถ้าโจทย์อยากรวมวัน −2% ด้วย ต้องบวกโอกาสของวันนั้นคืน คือ $1/10=0.10$ คำตอบจึงเป็น $0.70+0.10=0.80$ หรือ 80%

ขั้นที่ 3 — จุดเดียวคือขนาดการกระโดด หางขวาคือหนึ่งลบยอดสะสม

สามคำถามนี้ฟังคล้ายกันแต่ให้คำตอบต่างกัน: “ได้ 0% พอดี” “ได้ไม่เกิน 0%” และ “ได้มากกว่า 2%” CDF ตอบข้อกลางได้ตรง ๆ ส่วนอีกสองข้อต้องประกอบเอาจาก CDF

สำหรับคำถาม “พอดี” เราต้องมีชื่อเรียกความสูงของบันได ก่อน กระโดด จึงเขียน $F(a^-)$ แทนโอกาสสะสมของทุกค่าที่น้อยกว่า $a$ โดยยังไม่รวม $a$ เอง เช่น $F(0\%^-)$ นับวันที่ต่ำกว่า 0% ซึ่งมีสี่วัน จึงได้ $4/10=0.40$ และ $F(2\%^-)$ นับวันที่ต่ำกว่า 2% ซึ่งมีเจ็ดวัน จึงได้ $7/10=0.70$

\[\begin{aligned} P(X=a)&=F(a)-F(a^-)\\ P(X=0\%)&=0.60-0.40=0.20\\[4pt] P(X\gt b)&=1-F(b)\\ P(X\gt 2\%)&=1-0.90=0.10\\ P(X\ge 2\%)&=1-F(2\%^-)\\ &=1-0.70=0.30 \end{aligned}\]

เริ่มจากค่าเดียวพอดี วัน 0% มีสองวัน บันไดจึงกระโดดจาก 0.40 ขึ้นเป็น 0.60 ตรงเกณฑ์ 0% ขนาดของการกระโดด $0.60-0.40=0.20$ คือโอกาสของ 0% พอดี เพราะสิ่งเดียวที่ถูกนับเพิ่มตรงนั้นคือสองวันนี้

หางขวาคือฝั่งกำไรมาก ใช้หลักแบ่งกองเดิม ทุกวันอยู่ในกอง “ไม่เกิน $b$” หรือกอง “เกิน $b$” อย่างใดอย่างหนึ่ง และโอกาสของทุกวันรวมกันเท่ากับ 1 จึงได้ $P(X\gt b)=1-F(b)$

จุดที่พลาดง่ายคือคำว่า “ตั้งแต่ 2%” ซึ่งต้องนับวัน +2% ด้วย เราจึงลบยอดที่นับถึง ก่อน 2% คือ $F(2\%^-)=0.70$ ไม่ใช่ $F(2\%)=0.90$ คำตอบเปลี่ยนจาก 10% เป็น 30% เพราะมีสองวันยืนอยู่บนเกณฑ์พอดี

ขั้นที่ 4 — สามสมบัติที่ CDF ทุกตัวต้องมี

ในงานจริง CDF มักมาจากโปรแกรมหรือระบบของคนอื่น เราจึงควรรู้ว่า CDF ที่ถูกต้องต้องมีหน้าตาแบบไหน ถ้าตารางไหนผิดสมบัติข้อใดข้อหนึ่งในสามข้อนี้ แปลว่ามีการนับหรือการบันทึกผิดที่ใดที่หนึ่ง ทั้งสามข้อมาจากเหตุผลแบ่งกองเดิม จึงไม่ต้องจำแยก

สัญลักษณ์ที่ใช้: $x_1$ กับ $x_2$ คือเกณฑ์สองค่าที่ $x_1$ อยู่ทางซ้าย $\lim$ คือ limit ค่าที่ $F$ เข้าใกล้เมื่อเกณฑ์วิ่งไปไกลมาก ส่วน $h\to0^+$ แปลว่า $h$ เป็นบวกและหดเข้าหาศูนย์ คือเข้าหา $a$ จากทางขวา

\[\begin{aligned} F(x_2)-F(x_1)&=P(x_1\lt X\le x_2)\\ &\ge 0,\qquad x_1\lt x_2\\[4pt] \lim_{x\to-\infty}F(x)&=0\\ \lim_{x\to+\infty}F(x)&=1\\[4pt] \lim_{h\to 0^+}F(a+h)&=F(a) \end{aligned}\]

ข้อแรก CDF ไม่เคยลดลง เพราะเมื่อเลื่อนเกณฑ์ไปทางขวา วันที่นับไว้แล้วยังอยู่ครบ มีแต่วันใหม่ที่อาจถูกนับเพิ่ม ผลต่าง $F(x_2)-F(x_1)$ จึงเป็นโอกาสของช่วงหนึ่ง ซึ่งติดลบไม่ได้ อย่าสับสนกับกราฟราคา แกนนอนของ CDF คือเกณฑ์ ไม่ใช่เวลา

ข้อสอง CDF เริ่มที่ 0 และจบที่ 1 เพราะเกณฑ์ที่ต่ำมากไม่นับวันไหนเลย และเกณฑ์ที่สูงมากนับครบทุกวัน กับข้อมูลสิบวัน CDF แตะ 0 และ 1 จริง ๆ (ต่ำกว่า −3% กับตั้งแต่ +4%) แต่แบบจำลองที่ยอมให้ค่าไปไกลได้ไม่จำกัด เช่น normal distribution (รูประฆังคว่ำ) จะเข้าใกล้ 0 และ 1 เรื่อย ๆ โดยไม่แตะ จึงต้องเขียนเป็น limit

ข้อสามอธิบายว่าทำไมจุดทึบในรูปบันไดอยู่บนขั้นบน เครื่องหมาย $\le$ ใน $P(X\le a)$ นับค่าที่เท่ากับ $a$ ด้วย ยอดจึงกระโดดทันทีที่เกณฑ์มาถึง $a$ ไม่ต้องรอให้เลย $a$ เข้าหา $a$ จากทางขวาจึงได้ $F(a)$ พอดี ส่วนเข้าหาจากทางซ้ายได้ $F(a^-)$ ผลต่างของสองค่านี้คือโอกาสของจุด $a$ เช่น ที่ 0% ทางขวาได้ 0.60 ทางซ้ายได้ 0.40

ขั้นที่ 5 — อ่านกลับทาง: จากระดับโอกาสไปหาเกณฑ์

ถึงตอนนี้เราถามทางเดียว คือให้เกณฑ์แล้วหาโอกาส แต่ฝ่ายความเสี่ยงมักถามกลับทาง คือให้โอกาสแล้วหาเกณฑ์ เช่น “ถ้าเรียงวันจากแย่ไปดี เส้นที่แบ่งวันแย่ที่สุด 25% ออกมา อยู่ที่ผลตอบแทนเท่าไร” เกณฑ์ที่ตอบคำถามแบบนี้เรียกว่า quantile เขียนว่า $q_\alpha$ โดย $\alpha$ คือระดับโอกาสที่ให้มา เช่น $\alpha=0.25$

บันไดมีทั้งช่วงแบนและช่วงกระโดด บางระดับ $\alpha$ จึงตรงกับเกณฑ์ได้หลายค่า หรือไม่ตรงกับเกณฑ์ไหนพอดีเลย เราจึงต้องตั้งกติกาให้ชัด กติกาที่หน้านี้ใช้คือ $q_\alpha$ เป็นเกณฑ์ที่น้อยที่สุดซึ่ง $F$ ขึ้นถึงระดับ $\alpha$ แล้ว พูดง่าย ๆ คือไล่เกณฑ์จากซ้ายไปขวา แล้วหยุดที่ค่าแรกที่ $F(x)\ge\alpha$

\[\begin{aligned} F(-2\%)&=0.20\lt 0.25\\ F(-1\%)&=0.40\ge 0.25\\ q_{0.25}&=-1\%\\[4pt] F(-1\%)&=0.40\lt 0.50\\ F(0\%)&=0.60\ge 0.50\\ q_{0.50}&=0\% \end{aligned}\]

ภาพที่ช่วยคือลากเส้นแนวนอนที่ความสูง $\alpha$ จากแกนตั้งไปทางขวาจนชนบันได แล้วอ่านเกณฑ์ตรงจุดชน ที่ $\alpha=0.25$ ยอดสะสมที่ −2% ได้แค่ 0.20 ยังไม่ถึง แต่ที่ −1% บันไดกระโดดจาก 0.20 ขึ้นเป็น 0.40 ข้ามระดับ 0.25 ไป เส้นจึงชนตรงการกระโดดนี้ และได้ $q_{0.25}=-1\%$

ที่ $\alpha=0.50$ เส้นชนการกระโดดที่ 0% (จาก 0.40 เป็น 0.60) จึงได้ $q_{0.50}=0\%$ ค่า $q_{0.50}$ มีชื่อเฉพาะว่า median คือเส้นแบ่งที่ครึ่งหนึ่งของวันอยู่ต่ำกว่าหรือเท่ากับมัน

กรณีที่ต้องคิดคือเส้นทับช่วงแบนพอดี เช่น $\alpha=0.10$ บันไดสูง 0.10 ตลอดตั้งแต่ −3% ไปจนเกือบถึง −2% ทุกเกณฑ์ในช่วงนี้มี $F(x)=0.10$ จึงผ่านเงื่อนไข $F(x)\ge0.10$ ทั้งหมด กติกา “เกณฑ์ที่น้อยที่สุด” จึงเลือกจุดเริ่มของช่วงแบน คือ $q_{0.10}=-3\%$ ถ้าไม่ตั้งกติกาไว้ คำตอบจะเป็นค่าใดในช่วงนี้ก็ได้

ขั้นที่ 6 — ใช้วิธีเดียวกันกับข้อมูลจริง: ECDF ของ SPY

สิบวันในตัวอย่างแรกเป็นตัวเลขสมมติ ตอนนี้ลองกับข้อมูลจริง สมมติว่าพอร์ต \$50 ล้านของเราลงทุนใน SPY ทั้งหมด พอร์ตจึงขึ้นลงเป็นเปอร์เซ็นต์เท่ากับ SPY ทุกวัน SPY เป็น ETF คือกองทุนที่ซื้อขายในตลาดหุ้นเหมือนหุ้นตัวหนึ่ง และขึ้นลงตามดัชนี S&P 500 คำถามเป็นแบบเดียวกับขั้นก่อน ๆ คือวันที่ผลตอบแทนมากกว่า −2% แต่ไม่เกิน +2% มีสัดส่วนเท่าไร และวันที่กำไรเกิน 2% มีสัดส่วนเท่าไร

โจทย์ให้อะไรมาบ้าง:

  • ผลตอบแทนรายวันของ SPY ตลอดปี 2024 จำนวน $n=252$ ค่า แต่ละค่าคิดจากราคาปิดสองวันติดกัน $r_t=(S_t-S_{t-1})/S_{t-1}$ โดย $S_t$ คือราคาปิดของวันทำการที่ $t$
  • เลข 252 คือจำนวนวันที่ตลาดหุ้นนิวยอร์กเปิดในปี 2024 ปีนั้นมี 366 วัน เป็น 52 สัปดาห์เต็มกับอีกสองวัน (วันจันทร์และวันอังคารสุดท้ายของปี) จึงมีเสาร์อาทิตย์ $52\times2=104$ วัน และมีวันหยุดตลาดที่ตกวันธรรมดาอีก 10 วัน คือ New Year's Day, Martin Luther King Jr. Day, Presidents' Day, Good Friday, Memorial Day, Juneteenth, Independence Day, Labor Day, Thanksgiving และ Christmas ตลาดจึงเปิด $366-104-10=252$ วัน
  • ผลตอบแทนหนึ่งค่าใช้ราคาปิดสองวัน ผลตอบแทน 252 ค่าจึงใช้ราคาปิด $252+1=253$ ค่า ค่าที่เพิ่มมาคือราคาปิดวันทำการสุดท้ายของปี 2023 ซึ่งใช้คิดผลตอบแทนของวันแรกในปี 2024

เราไม่รู้ CDF จริงของวันพรุ่งนี้ จึงใช้สิ่งที่ใกล้ที่สุดแทน คือสัดส่วนที่นับได้จากข้อมูลย้อนหลัง เรียกว่า ECDF (empirical CDF แปลว่า CDF ที่นับจากข้อมูลจริง) ให้ $N_x$ เป็นจำนวนวันที่ผลตอบแทนไม่เกิน $x$ วิธีนับเหมือนสิบวันทุกอย่าง เปลี่ยนแค่ตัวหารจาก 10 เป็น $n=252$

ตารางนี้นับจากผลตอบแทนจริงทั้ง 252 ค่าแล้ว และเลือกมาเฉพาะแถวที่ต้องใช้ สามแถวแรกคือวันที่แย่อันดับสอง สาม และสี่ของปี

−2.2663% (แย่อันดับสาม)3$3/252\approx0.01190$

นำตัวเลขในตารางเข้าสูตรผลต่างของช่วง และสูตรหนึ่งลบของหางขวา ซึ่งสร้างไว้กับข้อมูลสิบวัน

\[\begin{aligned} \widehat F(x)&\equiv\frac{N_x}{n},\qquad n=252\\[4pt] \widehat P(-2\%\lt X\le 2\%)&=\frac{249-4}{252}\\ &=\frac{245}{252}\approx 97.22\%\\ \widehat P(X\gt 2\%)&=\frac{252-249}{252}\\ &=\frac{3}{252}\approx 1.19\% \end{aligned}\]

คำตอบ: ปี 2024 มีวันที่ผลตอบแทนมากกว่า −2% แต่ไม่เกิน +2% อยู่ 245 วัน คิดเป็น 97.22% และมีวันที่กำไรเกิน 2% สามวัน คิดเป็น 1.19%

หมวกบนใน $\widehat F$ และ $\widehat P$ เตือนว่าตัวเลขนี้คือสัดส่วนที่นับจากข้อมูลย้อนหลัง ถ้าจะใช้เป็นโอกาสของวันพรุ่งนี้ ต้องเชื่อเพิ่มอีกข้อว่าตลาดยังทำตัวแบบเดิม

ตรวจเองใน 10 วินาที: สามกองต้องรวมกันได้ครบทุกวัน กองที่ไม่เกิน −2% มีสี่วัน ช่วงกลาง 245 วัน และกองที่เกิน +2% สามวัน $4+245+3=252$ พอดี ไม่มีวันไหนหายหรือถูกนับซ้ำ

ขั้นที่ 7 — quantile 1% ของ SPY กลายเป็น VaR ได้อย่างไร

ฝ่ายความเสี่ยงต้องรายงานผู้บริหารทุกวันด้วยตัวเลขตัวเดียว: “ในวันแย่ระดับ 1 ใน 100 วัน พอร์ตจะเสียประมาณเท่าไร” ตัวเลขนี้เรียกว่า VaR 99% รายวัน VaR ย่อจาก Value at Risk ส่วน 99% มาจากว่า 99 วันจาก 100 วัน พอร์ตควรเสียไม่เกินเส้นนี้

วิธีหามีสองจังหวะ จังหวะแรกอ่าน ECDF กลับทางที่ระดับ $\alpha=0.01$ ด้วยกติกา quantile เดิม ได้เกณฑ์ผลตอบแทน $q_{0.01}$ ซึ่งติดลบ จังหวะที่สองแปลงเปอร์เซ็นต์เป็นเงิน โดยคูณกับมูลค่าพอร์ต $V=\$50{,}000{,}000$ แล้วกลับเครื่องหมาย เพราะเราอยากเขียนขาดทุนเป็นเลขบวก

\[\begin{aligned} \frac{N_x}{252}&\ge 0.01\\ N_x&\ge 0.01\times 252=2.52\\ \frac{2}{252}&\lt 0.01\le\frac{3}{252}\\ q_{0.01}&=-2.2663\%\\[4pt] \mathrm{VaR}_{99\%}&=-q_{0.01}\times V\\ &=0.022663\times\$50{,}000{,}000\\ &=\boxed{\$1{,}133{,}150} \end{aligned}\]

ทำไมต้องคูณ $0.01\times252$ ก่อน เพราะกติกา quantile ต้องการ $\widehat F(x)=N_x/252\ge0.01$ ซึ่งก็คือ $N_x\ge2.52$ จำนวนวันเป็นเศษไม่ได้ จึงต้องนับให้ถึงสามวัน ยอดสะสมถึงวันแย่อันดับสองได้ $2/252\approx0.79\%$ ยังไม่ถึง 1% พอนับถึงวันแย่อันดับสามได้ $3/252\approx1.19\%$ ผ่านระดับแล้ว เกณฑ์จึงเป็นผลตอบแทนของวันแย่อันดับสาม คือ −2.2663%

กลับเครื่องหมายแล้วคูณมูลค่าพอร์ต ได้ประมาณ \$1.13 ล้าน ตัวเลขนี้เรียกว่า historical VaR 99% รายวัน คำว่า historical บอกว่าหามาจากข้อมูลย้อนหลังตรง ๆ ไม่ผ่านแบบจำลองใด

อย่าอ่าน VaR เป็นขาดทุนสูงสุด ปี 2024 มีสองวันที่เสียมากกว่านี้ แค่วันแย่อันดับสอง (−2.9124%) ก็เสีย $0.029124\times\$50{,}000{,}000=\$1{,}456{,}200$ แล้ว VaR บอกแค่ว่าเส้นอยู่ตรงไหน ไม่บอกว่าวันที่ข้ามเส้นจะเสียหนักเท่าไร คำถามหลังนี้เป็นงานของ expected shortfall ซึ่งคือค่าเฉลี่ยของขาดทุนในวันที่แย่กว่าเส้น VaR

จุดที่พลาดแล้วได้คำตอบผิดโดยไม่รู้ตัว

สับสน “ตั้งแต่” กับ “เกิน”: “ขาดทุนตั้งแต่ 2%” รวมวันที่เสีย 2% พอดี จึงต้องเขียนเป็น $X\le-2\%$ ซึ่งได้ $P(X\le-2\%)=2/10=20\%$ ถ้าเผลอเขียนเป็น $X\lt-2\%$ จะได้ $P(X\lt-2\%)=1/10=10\%$ ซึ่งผิด คำตอบต่างกันเท่าตัว เพราะมีวันหนึ่งยืนอยู่บนเกณฑ์พอดี ข้อมูลรายวันที่ปัดเหลือทศนิยมสองตำแหน่งมีค่าตกบนเกณฑ์กลม ๆ อย่าง −2.00% บ่อยกว่าที่คิด

อ่านความสูงของบันไดเป็นโอกาสของจุด: คำตอบผิดคือ $P(X=0\%)=F(0\%)=0.6$ คำตอบที่ถูกคือ $P(X=0\%)=F(0\%)-F(0\%^-)=0.6-0.4=0.2$ ความสูงของบันไดคือยอดสะสม ส่วนโอกาสของจุดหนึ่งคือขนาดของการกระโดดตรงจุดนั้น

โปรแกรมต่างกัน quantile ต่างกัน: หน้านี้ใช้กติกา “เกณฑ์ที่น้อยที่สุดที่ถึงระดับ” ได้ VaR \$1,133,150 แต่หลายโปรแกรมใช้อีกวิธี เช่น PERCENTILE.INC ใน Excel และค่าตั้งต้นของ numpy.percentile วิธีนี้เรียงข้อมูลแล้วให้วันแย่ที่สุดอยู่ตำแหน่ง 1 วันดีที่สุดอยู่ตำแหน่ง $n$ แล้ววางระดับ $\alpha$ ไว้ที่ตำแหน่ง $k=1+(n-1)\alpha$ ถ้า $k$ ไม่ใช่จำนวนเต็ม ก็แทรกค่าตามสัดส่วนระหว่างสองอันดับที่ล้อมอยู่

\[\begin{aligned} k&=1+(252-1)\times0.01=3.51\\ q&=-2.2663+0.51\times0.2084\\ &=-2.160016\%\\ \mathrm{VaR}&=0.02160016\times\$50{,}000{,}000\\ &=\$1{,}080{,}008 \end{aligned}\]

ตำแหน่ง 3.51 แปลว่าเลยวันแย่อันดับสาม (−2.2663%) ไปอีก 0.51 ของระยะถึงวันแย่อันดับสี่ (−2.0579%) ระยะนั้นคือ $-2.0579-(-2.2663)=0.2084$ จุด VaR ที่ได้ต่างจากเดิม $1{,}133{,}150-1{,}080{,}008=\$53{,}142$ ทั้งที่ใช้ข้อมูลชุดเดียวกัน รายงาน VaR จึงต้องบอกด้วยว่าหา quantile วิธีไหน

ถือว่าอดีตคืออนาคต: ถ้าปีที่ใช้คำนวณเป็นปีที่ตลาดสงบ วันขาดทุนหนักในข้อมูลมีน้อย VaR ที่ได้จึงต่ำ ถ้า VaR 99% ถูกต้อง หนึ่งปีควรมีวันที่ขาดทุนเกินเส้นราว $0.01\times252=2.52$ วัน แต่ถ้าปีถัดไปตลาดผันผวนขึ้น วันที่เกินเส้นจะมีมากกว่านี้มาก การตรวจว่าเส้น VaR ถูกข้ามบ่อยเกินไปหรือไม่ เรียกว่า VaR backtesting

ใช้ทำอะไรบนโต๊ะจริง

ธนาคารและกองทุนรายงาน historical VaR ทุกวัน และขั้นตอนที่ใช้ก็คือทุกอย่างในหน้านี้ เริ่มจากเอาหุ้นที่พอร์ตถืออยู่วันนี้ ไปคิดว่าในแต่ละวันย้อนหลัง พอร์ตนี้จะได้หรือเสียเงินเท่าไร ตัวเลขกำไรขาดทุนรายวันนี้เรียกว่า P&L (profit and loss) จากนั้นเรียง นับ แล้วอ่าน quantile แบบเดียวกับ SPY

ข้อดีคือไม่ต้องสมมติว่าผลตอบแทนมีรูปร่างแบบ normal (รูประฆังคว่ำ) ข้อมูลเป็นอย่างไรก็ใช้อย่างนั้น ข้อเสียคือหางซ้าย 1% ของข้อมูลหนึ่งปีมีแค่ $0.01\times252\approx2.5$ วัน ตัวเลขจึงขยับแรงเมื่อวันแย่วันเดียวหลุดออกจากหน้าต่างข้อมูล หน้าต่างข้อมูลคือช่วงวันย้อนหลังที่ใช้คำนวณ ซึ่งเลื่อนไปข้างหน้าวันละหนึ่งวัน

กติกา Basel ซึ่งเป็นมาตรฐานที่ผู้กำกับธนาคารทั่วโลกใช้ กำหนดให้ใช้ข้อมูลย้อนหลังอย่างน้อยหนึ่งปี ในทางปฏิบัติธนาคารมักนับเป็น 250 วันทำการ (ปัดจากราว 252 วันต่อปีให้เป็นเลขกลม) หรือใช้หน้าต่างที่ยาวกว่านั้น และรายงาน VaR คู่กับ expected shortfall

โจทย์ตรวจความเข้าใจ

1. วันถัดมาตลาดร่วงแรง พอร์ตเสีย 4% ฝ่ายความเสี่ยงเพิ่มผลตอบแทน −4% นี้เข้าไปในข้อมูลสิบวันเดิม รวมเป็น 11 วัน ECDF ที่ −2% เป็นเท่าไร และสัดส่วนของวันที่ผลตอบแทนมากกว่า −2% แต่ไม่เกิน +2% เป็นเท่าไร

เฉลย

วันที่ไม่เกิน −2% เพิ่มจากสองเป็นสามวัน (−4%, −3%, −2%) และตัวหารเพิ่มจาก 10 เป็น 11 วันที่ไม่เกิน +2% มีสิบวัน คือทุกวันยกเว้น +4%

\[\begin{aligned} \widehat F(-2\%)&=\frac{3}{11}\approx0.273\\ \widehat F(2\%)&=\frac{10}{11}\\ \widehat P(-2\%\lt X\le2\%)&=\frac{10}{11}-\frac{3}{11}\\ &=\frac{7}{11}\approx0.636 \end{aligned}\]

จำนวนวันในช่วงกลางยังเป็นเจ็ดวันเท่าเดิม แต่สัดส่วนลดจาก 0.7 เหลือ 0.636 เพราะตัวหารโตขึ้น ทุกครั้งที่เพิ่มข้อมูล ต้องตรวจทั้งตัวเศษและตัวหาร

2. หัวหน้าฝ่ายความเสี่ยงถามว่า ถ้าเรียงสิบวันเดิมจากแย่ไปดี เส้นที่แบ่งวันแย่ที่สุด 10% และ 30% ออกมาอยู่ที่ผลตอบแทนเท่าไร ให้หา $q_{0.10}$ และ $q_{0.30}$ ด้วยกติกา “เกณฑ์ที่น้อยที่สุดซึ่ง $F$ ถึงระดับแล้ว”

เฉลย

ระดับ 0.10 ถึงตั้งแต่เกณฑ์แรกของข้อมูล เพราะ $F(-3\%)=1/10=0.10\ge0.10$ จึงได้ $q_{0.10}=-3\%$

ระดับ 0.30 ที่ −2% ยังไม่ถึง เพราะ $F(-2\%)=0.20\lt0.30$ แต่ที่ −1% ถึงแล้ว เพราะ $F(-1\%)=0.40\ge0.30$ จึงได้ $q_{0.30}=-1\%$ สังเกตว่า $q_{0.25}$ กับ $q_{0.30}$ เท่ากัน เพราะทั้งสองระดับชนการกระโดดเดียวกันที่ −1% ซึ่งพาบันไดจาก 0.20 ขึ้นเป็น 0.40

3. การเดิมพันอย่างหนึ่งให้กำไรเป็นดอลลาร์ได้แค่สามค่า คือ −1, 1 หรือ 2 (ตัวเลขสมมติ) ให้ random variable $Y$ เป็นกำไรนี้ มีคนส่งตาราง CDF ของ $Y$ มาให้ ตารางบอกว่า $F(-1)=0.3$, $F(0)=0.3$, $F(1)=0.8$ และ $F(2)=1$ ให้หา $P(Y=0)$, $P(Y=1)$ และ $P(0\lt Y\le 2)$

เฉลย

โอกาสของค่าเดียวคือขนาดการกระโดด $F(a)-F(a^-)$ ระหว่าง −1 กับ 0 ไม่มีค่าใดของ $Y$ เลย ยอดสะสมก่อนถึง 0 จึงเท่ากับ $F(-1)=0.3$ ทำนองเดียวกัน ยอดสะสมก่อนถึง 1 เท่ากับ $F(0)=0.3$ และก่อนถึง 2 เท่ากับ $F(1)=0.8$

\[\begin{aligned} P(Y=0)&=F(0)-F(0^-)\\ &=0.3-0.3=0\\ P(Y=1)&=F(1)-F(1^-)\\ &=0.8-0.3=0.5\\ P(0\lt Y\le2)&=F(2)-F(0)\\ &=1-0.3=0.7 \end{aligned}\]

บันไดไม่กระโดดที่ 0 เพราะ 0 ไม่ใช่ค่าที่ $Y$ ออกได้ ถ้าอ่าน $F(0)=0.3$ เป็นโอกาสของศูนย์ก็ผิดทันที ส่วนช่วง $0\lt Y\le2$ รวมโอกาสของ 1 กับของ 2 ไว้ด้วยกัน คือ $0.5+0.2=0.7$ โดยโอกาสของ 2 คือ $F(2)-F(1)=1-0.8=0.2$

คำนวณซ้ำด้วย JavaScript

เปิดดูโค้ด 
const r = [-3, -2, -1, -1, 0, 0, 1, 2, 2, 4]; // ผลตอบแทน (%)
const F = x => r.filter(v => v <= x).length / r.length;
const Fminus = x => r.filter(v => v < x).length / r.length;
console.log(F(-2));             // 0.2
console.log(F(2) - F(-2));      // 0.7  (ช่วง)
console.log(F(0) - Fminus(0));  // 0.2  (จุด 0%)
console.log(1 - F(2));          // 0.1  (หางขวา)
console.log(1 - Fminus(2));     // 0.3  (ตั้งแต่ +2%)

// quantile: เกณฑ์ที่น้อยที่สุดซึ่ง F ถึงระดับ a
const quantile = (data, a) => {
  const s = [...data].sort((u, v) => u - v);
  return s[Math.ceil(a * s.length) - 1];
};
console.log(quantile(r, 0.25), quantile(r, 0.5)); // -1 0

// SPY 2024 จากตารางสรุป
console.log((249 - 4) / 252, 3 / 252); // 0.9722  0.0119
console.log(Math.ceil(0.01 * 252));    // 3 → วันแย่อันดับสาม
console.log(0.022663 * 50e6);          // ≈ 1133150

สิ่งที่ควรตอบได้หลังอ่าน

  • random variable คือกฎที่เปลี่ยนผลสุ่มให้เป็นตัวเลข และ CDF คือ $F(x)=P(X\le x)$ ซึ่งนับค่าที่เท่ากับเกณฑ์ด้วย
  • โอกาสของช่วงใช้ $F(b)-F(a)$ โอกาสของค่าเดียวใช้ขนาดการกระโดด $F(a)-F(a^-)$ และหางขวาใช้ $1-F(x)$ ทั้งสามสูตรมาจากการแบ่งวันเป็นกองที่ไม่ซ้อนกัน
  • CDF ไม่เคยลดลง เริ่มที่ 0 จบที่ 1 และจุดทึบอยู่บนขั้นบนเสมอ
  • quantile คือการอ่าน CDF กลับทางด้วยกติกา “เกณฑ์ที่น้อยที่สุดที่ถึงระดับ” historical VaR 99% รายวันของพอร์ต \$50 ล้านที่ถือ SPY ปี 2024 มาจากวันแย่อันดับสาม คือ $0.022663\times\$50{,}000{,}000=\$1{,}133{,}150$
  • VaR ไม่ใช่ขาดทุนสูงสุด และตัวเลขเปลี่ยนได้ตามวิธีหา quantile และตามหน้าต่างข้อมูลที่เลือก

หน้าถัดไป discrete random variables และ PMF จะเปลี่ยนจากการนับยอดสะสม มาเป็นการบอกโอกาสของแต่ละค่าตรง ๆ ตารางโอกาสรายค่านี้เรียกว่า PMF (probability mass function) แล้วจะเห็นว่าขนาดการกระโดดของบันไดในหน้านี้ก็คือ PMF นั่นเอง
