1.1 Random Variables and the Cumulative Distribution Function (CDF)

จากการนับวันขาดทุน สู่การอ่านโอกาสและระดับความเสี่ยง

พอร์ตหนึ่งมีผลตอบแทนสิบวันดังนี้: −3%, −2%, −1%, −1%, 0%, 0%, +1%, +2%, +2%, +4% ถ้าสุ่มเลือกหนึ่งวันจากสิบวันนี้ โอกาสที่จะขาดทุนตั้งแต่ 2% ขึ้นไปเป็นเท่าไร?

ก่อนคำนวณ ลองขีดเส้นใต้วันที่เข้าเงื่อนไข คำถามนี้ไม่ได้ถามเฉพาะวันที่ได้ −2% แต่รวมวันที่แย่กว่านั้นด้วย วิธีนับให้ครบคือจุดเริ่มต้นของ CDF

สิ่งที่เราจะทำในบทเรียนนี้

เราจะใช้ข้อมูลเล็ก ๆ ชุดเดียวสร้าง CDF ด้วยมือ แล้วใช้มันตอบคำถามสามแบบ: โอกาสที่ผลตอบแทนไม่เกินเกณฑ์ โอกาสที่อยู่ในช่วง และเกณฑ์ขาดทุนที่สอดคล้องกับโอกาสที่กำหนด จากนั้นจึงนำวิธีเดียวกันไปอ่านตัวอย่าง SPY จำนวน 252 วัน

ยังไม่ต้องรู้แคลคูลัส ใช้เพียงการนับ การหาร และการลบ สิ่งสำคัญคือแยกให้ได้ว่าเรากำลังบอกสิ่งที่เกิดในข้อมูล หรือกำลังตั้งสมมติฐานเกี่ยวกับอนาคต

เริ่มจากโจทย์ — สุ่มหนึ่งวันจากข้อมูลสิบวัน

ของที่มี: ผลตอบแทนสิบค่าที่ให้ไว้ข้างต้น และกติกาว่าทุกวันมีโอกาสถูกเลือกเท่ากัน วันละ 1/10

คำถาม: โอกาสขาดทุนตั้งแต่ 2% ขึ้นไปเป็นเท่าไร?

คำตอบ: วันที่ได้ −3% และ −2% เข้าเงื่อนไข รวมสองวันจากสิบวัน จึงมีโอกาส $2/10=20\%$

ตรวจเองใน 10 วินาที: “ขาดทุนตั้งแต่ 2%” แปลว่าผลตอบแทนไม่เกิน −2% ไม่ใช่ผลตอบแทนมากกว่า −2% และไม่ใช่เฉพาะค่า −2% พอดี

ตั้งชื่อให้สิ่งที่ยังไม่รู้ และแยกออกจากเกณฑ์ที่เราถาม

ให้ $X$ แทนผลตอบแทนของวันที่สุ่มเลือก ก่อนเลือก เรายังไม่รู้ว่าจะได้ค่าใด ตัวเลขที่ขึ้นอยู่กับผลสุ่มเช่นนี้เรียกว่า Random Variable (RV) ส่วน $x$ ตัวเล็กเป็นเกณฑ์ที่เรากำหนดเอง เช่น −2% หรือ +2%

สัญลักษณ์ $P(X\le x)$ อ่านว่า “โอกาสที่ผลตอบแทนจะไม่เกิน $x$” เครื่องหมาย $\le$ รวมกรณีที่เท่ากับเกณฑ์ด้วย ในตัวอย่างนี้ $P(X\le-2\%)$ จึงนับทั้ง −3% และ −2%

Random variable กับ distribution ไม่ใช่สิ่งเดียวกัน: ตัวแรกบอกว่าเราวัดอะไร ส่วน distribution บอกว่าแต่ละค่าหรือช่วงมีโอกาสเท่าไร สำหรับโจทย์นี้ โอกาสมาจากกติกาสุ่มวันเท่า ๆ กัน ไม่ใช่การทำนายตลาดพรุ่งนี้

ขั้นที่ 1 — สร้าง CDF จากยอดนับสะสม

Cumulative Distribution Function (CDF) คือฟังก์ชันที่รับเกณฑ์ $x$ แล้วให้โอกาสของผลลัพธ์ทั้งหมดที่ไม่เกินเกณฑ์นั้น เราเขียนชื่อย่อของฟังก์ชันว่า $F$

\[ \begin{aligned} F(x)&\equiv P(X\le x)\\ F(-2\%)&=\frac{2}{10}=0.20\\ F(0\%)&=\frac{6}{10}=0.60\\ F(2\%)&=\frac{9}{10}=0.90 \end{aligned} \]

ที่เกณฑ์ 0% เรานับวันที่ขาดทุนสี่วันรวมกับวันที่ผลตอบแทนเป็นศูนย์สองวัน จึงได้หกวัน CDF เก็บยอดรวมถึงเกณฑ์ ไม่ได้เก็บเฉพาะจำนวนวันที่มีค่าเท่ากับเกณฑ์

ตารางที่ใช้ตอบคำถามได้โดยไม่ต้องนับใหม่

ระหว่าง +2% กับ +4% ไม่มีข้อมูลเพิ่ม ดังนั้น $F(3\%)$ ก็ยังเท่ากับ 0.90 เกณฑ์ไม่จำเป็นต้องเป็นค่าที่ปรากฏในข้อมูล

ขั้นที่ 2 — หาโอกาสของช่วงด้วยการลบยอดสะสม

สมมติว่าอยากนับวันที่ผลตอบแทนมากกว่า −2% แต่ไม่เกิน +2% ยอดถึง +2% มีเก้าวัน แต่รวมสองวันที่ไม่เกิน −2% มาด้วย จึงต้องลบสองวันนั้นออก

\[ \begin{aligned} P(-2\%\lt X\le2\%) &=F(2\%)-F(-2\%)\\ &=\frac{9-2}{10}=0.70\\[3pt] P(X\le b)&=P(X\le a)+P(a\lt X\le b)\\ P(a\lt X\le b)&=F(b)-F(a),\qquad a\lt b \end{aligned} \]

สูตรทั่วไปมาจากการแบ่งผลลัพธ์ที่ไม่เกิน $b$ ออกเป็นสองกลุ่มที่ไม่ซ้ำกัน: กลุ่มที่ไม่เกิน $a$ และกลุ่มที่มากกว่า $a$ แต่ไม่เกิน $b$ เมื่อลบกลุ่มแรกออก จึงเหลือช่วงที่ต้องการ

สังเกตขอบซ้าย: สูตรนี้ไม่รวมค่าที่เท่ากับ $a$ เพราะค่านั้นถูกนับอยู่ใน $F(a)$ และถูกลบออกไปแล้ว ถ้าต้องการรวม −2% ด้วย ให้บวกโอกาสของค่า −2% กลับเข้าไปอีก $1/10$ คำตอบจึงเปลี่ยนจาก 70% เป็น 80%

ขั้นที่ 3 — แยกโอกาสของจุดเดียวออกจากโอกาสของหาง

คำว่า “เท่ากับ 0%” “ไม่เกิน 0%” และ “มากกว่า 2%” ถามคนละเรื่อง ให้ $F(a^-)$ หมายถึงยอดสะสมก่อนถึงค่า $a$ ซึ่งยังไม่รวมค่านั้น

\[ \begin{aligned} P(X=0\%)&=F(0\%)-F(0\%{}^-)\\ &=\frac{6}{10}-\frac{4}{10}=0.20\\[3pt] P(X\gt2\%)&=1-P(X\le2\%)\\ &=1-\frac{9}{10}=0.10\\[3pt] P(X=a)&=F(a)-F(a^-) \end{aligned} \]

สองวันที่ได้ 0% ทำให้ CDF กระโดดจาก 0.40 เป็น 0.60 ความสูงของขั้นจึงเท่ากับโอกาสของค่า 0% พอดี ส่วนหางขวานับวันที่เหลือหลังจากตัดทุกวันที่ไม่เกินเกณฑ์ออก จึงใช้หนึ่งลบ CDF

เหตุใด CDF จึงขึ้นได้ แต่ลงไม่ได้

เมื่อเพิ่มเกณฑ์จาก −2% เป็น 0% วันที่เคยนับแล้วยังอยู่ครบ มีแต่วันใหม่ที่อาจถูกนับเพิ่ม ดังนั้น CDF จึงเพิ่มหรือเท่าเดิมเสมอ แกนนอนของกราฟนี้คือเกณฑ์ผลตอบแทน ไม่ใช่เวลา จึงไม่ขึ้นลงเหมือนกราฟราคาหุ้น

สำหรับข้อมูลสิบวัน เกณฑ์ที่ต่ำกว่า −3% นับไม่ได้สักวันจึงให้ค่า 0 ส่วนเกณฑ์ตั้งแต่ +4% ขึ้นไปนับได้ครบจึงให้ค่า 1 แต่แบบจำลองบางชนิดมีค่าที่เป็นไปได้ไกลออกไปไม่สิ้นสุด จึงเพียงเข้าใกล้ 0 และ 1 โดยไม่ถึงที่เกณฑ์จำกัด

ขั้นที่ 4 — ตรวจสมบัติของ CDF จากเหตุผลเดียวกับการนับ

เมื่อ $x_1\lt x_2$ โอกาสที่เพิ่มมาระหว่างสองเกณฑ์ไม่มีทางติดลบ ส่วนขอบเขตซ้ายและขวาบอกพฤติกรรมเมื่อเลื่อนเกณฑ์ไปไกลขึ้นเรื่อย ๆ

\[ \begin{aligned} F(x_2)-F(x_1)&=P(x_1\lt X\le x_2)\ge0\\ 0&\le F(x)\le1\\ \lim_{x\to-\infty}F(x)&=0\\ \lim_{x\to+\infty}F(x)&=1 \end{aligned} \]

คำว่า limit ในสองบรรทัดท้ายหมายถึงค่าที่เข้าใกล้เมื่อเลื่อนเกณฑ์ไปไกลมาก ไม่ได้บังคับให้ทุก CDF ต้องแตะ 0 หรือ 1 ณ เกณฑ์ใดเกณฑ์หนึ่ง ถ้าตาราง CDF ลดลงเมื่อเกณฑ์เพิ่มขึ้น แสดงว่ามีข้อผิดพลาดในการนับหรือบันทึก

จากการสุ่มวันในอดีต ไปสู่การประมาณโอกาสในอนาคต

ถ้าสุ่มหนึ่งวันจากข้อมูลเก่าด้วยโอกาสเท่ากัน ยอดนับหารจำนวนวันให้ความน่าจะเป็นของการสุ่มนั้นโดยตรง แต่ถ้าถามถึงวันพรุ่งนี้ เราไม่รู้ distribution จริง จึงอาจใช้สัดส่วนในอดีตเป็นค่าประมาณ เรียกฟังก์ชันที่นับจากข้อมูลว่า Empirical Cumulative Distribution Function (ECDF)

ให้ $n$ เป็นจำนวนข้อมูล และใช้หมวกบน $\widehat F$ เพื่อเตือนว่าเป็นค่าที่คำนวณจากข้อมูล ไม่ใช่ distribution อนาคตที่เรารู้แน่นอน

ขั้นที่ 5 — เขียน ECDF โดยระบุให้ชัดว่านับอะไร

นิยาม ECDF คือจำนวนข้อมูลที่ไม่เกินเกณฑ์หารด้วยจำนวนข้อมูลทั้งหมด สำหรับผลตอบแทนสิบวันของเรา ตัวเศษที่เกณฑ์ −2% เท่ากับสอง

\[ \begin{aligned} \widehat F(x)&\equiv\frac{\#\{\text{observations}\le x\}}{n}\\ \widehat F(-2\%)&=\frac{2}{10}=0.20 \end{aligned} \]

เครื่องหมาย $\#$ หมายถึง “จำนวนสมาชิก” ECDF อธิบายข้อมูลได้โดยไม่ต้องสมมติ Normal หรือ distribution รูปอื่น แต่การนำไปทำนายต้องมีเหตุผลว่าข้อมูลเก่ายังเป็นตัวแทนของสิ่งที่จะเกิดหรือไม่ การนับจากอดีตกับการเชื่อว่าอนาคตเหมือนอดีตเป็นคนละขั้นตอน

Worked Example — อ่านความเสี่ยงของพอร์ต SPY

ของที่มี: พอร์ตมูลค่า \$50 ล้านที่เคลื่อนไหวตาม SPY ซึ่งเป็น ETF ติดตามดัชนี S&P 500 โจทย์ให้ตารางสรุปผลตอบแทนรายวันปี 2024 จำนวน 252 ค่า และให้ใช้ historical ECDF โดยให้น้ำหนักทุกวันเท่ากัน

คำถาม: มีวันอยู่ในช่วง $-2\%\lt X\le2\%$ กี่วัน มีวันกำไรเกิน 2% กี่วัน และถ้าใช้เกณฑ์หางซ้าย 1% จะได้ระดับขาดทุนเป็นเงินเท่าไร?

หน้านี้ให้ยอดนับเป็นข้อมูลโจทย์ ไม่ได้แสดงผลตอบแทนครบทั้ง 252 ค่า การตรวจคำตอบต่อจากนี้เริ่มจากยอดนับในตาราง คำนวณด้วยเศษส่วนก่อน แล้วค่อยปัดทศนิยมตอนรายงานผล

ขั้นที่ 6 — ตอบคำถามเรื่องช่วงและหางขวา

\[ \begin{aligned} \widehat P(-2\%\lt X\le2\%) &=\frac{249}{252}-\frac{4}{252}\\ &=\frac{245}{252}\approx97.22\%\\ \widehat P(X\gt2\%) &=1-\frac{249}{252}\\ &=\frac{3}{252}\approx1.19\% \end{aligned} \]

คำตอบของข้อมูลปีนี้คือ 245 วันและ 3 วันตามลำดับ หมวกบน $\widehat P$ เตือนว่าเป็นสัดส่วนจากข้อมูล หากคูณเศษส่วนด้วย 252 ก็ได้ยอดนับเดิมกลับมา นี่ไม่ใช่ข้อสรุปว่าปีหน้าจะเกิดจำนวนวันเท่าเดิม

ถ้าโจทย์ให้โอกาส แล้วถามกลับหาเกณฑ์

ก่อนหน้านี้เราเลือกเกณฑ์แล้วอ่านโอกาส คราวนี้กลับทาง: อยากรู้ว่าต้องเลื่อนเกณฑ์ไปถึงค่าใด ยอดสะสมจึงถึงอย่างน้อย 1% ค่าที่แบ่ง distribution ตามสัดส่วนเช่นนี้เรียกว่า quantile

หน้านี้ใช้กติกา “เลือกข้อมูลอันดับแรกที่ ECDF ถึงสัดส่วนที่ต้องการ” เรียง 252 วันจากผลตอบแทนน้อยไปมากแล้วนับ วันแย่อันดับ 2 ยังให้เพียง 0.794% แต่วันแย่อันดับ 3 ให้ 1.190% จึงเลือกอันดับ 3 โดยไม่เฉลี่ยระหว่างสองวัน

ขั้นที่ 7 — หา quantile 1% และแปลงเป็น VaR

ให้ $q_{0.01}$ เป็น quantile 1% ตามกติกาข้างต้น และให้ VaR เป็นจำนวนเงินขาดทุนบวก สำหรับพอร์ตที่มีผลตอบแทนเดียวกับ SPY ใช้มูลค่าพอร์ตคูณขนาดผลตอบแทนติดลบที่เกณฑ์นั้น

\[ \begin{aligned} 0.01\times252&=2.52\\ \frac{2}{252}&\lt0.01\le\frac{3}{252}\\ q_{0.01}&=-2.2663\%\\ \mathrm{VaR}_{99\%} &=-q_{0.01}\times\$50{,}000{,}000\\ &=0.022663\times\$50{,}000{,}000\\ &=\boxed{\$1{,}133{,}150} \end{aligned} \]

Historical Value at Risk (VaR) รายวัน 99% ของตัวอย่างนี้จึงประมาณ \$1.13 ล้าน เป็นเกณฑ์ขาดทุนที่อ่านจากข้อมูล ไม่ใช่ขาดทุนสูงสุด ไม่ใช่ค่าเฉลี่ยของวันแย่ และไม่ใช่คำรับประกันว่าจะมีวันขาดทุนเกินเกณฑ์เพียง 1% ในอนาคต

เมื่อผลตอบแทนเท่ากับ −2.2663% พอร์ตขาดทุนเท่ากับ VaR พอดี ไม่ได้ขาดทุนเกิน ส่วนวันที่ผลตอบแทนน้อยกว่านี้มีสองวัน สัดส่วนที่ขาดทุนเกินจึงเป็น $2/252\approx0.794\%$ การแยก “เท่ากับ” ออกจาก “เกิน” ทำให้เข้าใจได้ว่าทำไม ECDF ที่จุดตัดเป็น 1.190% แต่สัดส่วนที่แย่กว่าเกณฑ์ยังไม่เกิน 1%

ทำไมโปรแกรมสองตัวอาจให้ quantile ไม่เท่ากัน

บางวิธีเลือกค่าที่มีอยู่ในข้อมูล บางวิธีแทรกค่าระหว่างอันดับ ถ้าใช้ตำแหน่ง $1+(252-1)(0.01)=3.51$ จะอ่านระหว่างวันแย่อันดับ 3 ที่ −2.2663% กับอันดับ 4 ที่ −2.0579% ได้ $-2.2663+0.51(-2.0579+2.2663)=-2.160016\%$ หรือ VaR ประมาณ \$1.08 ล้าน

นี่เป็นกติกาคนละแบบ ไม่ใช่ความคลาดเคลื่อนจากการปัดเศษอย่างเดียว รายงานจึงต้องบอกช่วงเวลา ระดับความเชื่อมั่น แหล่งข้อมูล และวิธีหา quantile หากต้องการควบคุมสัดส่วนข้อมูลที่ขาดทุนเกินเกณฑ์ ต้องตรวจสัดส่วนนั้นโดยตรงด้วย

เมื่อไรจึงคูณโอกาสด้วยจำนวนวันได้

ถ้าใช้ข้อมูลเก่า การคูณ ECDF ด้วยจำนวนแถวเป็นเพียงการย้อนกลับไปหายอดนับ แต่ถ้ากำลังวางแผนอนาคต และสมมติว่าแต่ละวันมีโอกาสเกิดเหตุการณ์เท่ากับ $p$ จำนวนวันที่คาดว่าจะเกิดใน $n$ วันคือ $np$ คำว่า “คาดว่า” หมายถึงค่าเฉลี่ยตามแบบจำลอง ไม่ใช่จำนวนวันที่ต้องเกิดจริง

ขั้นที่ 8 — ตรวจจำนวนครั้งเฉลี่ยด้วยตัวอย่างสองวัน

สมมติว่าโอกาสเกิดเหตุการณ์วันละ 0.30 และสองวันเป็นอิสระกัน ให้ $N$ เป็นจำนวนวันที่เกิดเหตุการณ์ในสองวันนี้

\[ \begin{aligned} P(N=0)&=0.70^2=0.49\\ P(N=1)&=0.30(0.70)+0.70(0.30)=0.42\\ P(N=2)&=0.30^2=0.09\\ \text{average count} &=0(0.49)+1(0.42)+2(0.09)\\ &=0.60=2(0.30) \end{aligned} \]

ความเป็นอิสระทำให้คูณโอกาสเพื่อแจกแจงสามกรณีนี้ได้ แต่สูตรจำนวนครั้งเฉลี่ย $np$ ไม่จำเป็นต้องใช้ independence ถ้าทุกวันมีโอกาสเท่ากับ $p$ เพราะค่าเฉลี่ยของจำนวนครั้งรวมเท่ากับผลบวกของค่าเฉลี่ยแต่ละวัน เราจะสร้างเหตุผลนี้อย่างเป็นระบบในหัวข้อ 1.3

หมายเหตุเรื่อง 252 วันและข้อมูลราคาปิด

ในตัวอย่าง SPY ใช้ 252 วันตามชุดข้อมูลที่โจทย์กำหนด จำนวนวันซื้อขายจริงขึ้นกับปฏิทินของแต่ละปี ส่วนการใช้ 252 เป็นหนึ่งปีในการแปลงหน่วยเป็นข้อตกลงที่ต้องระบุ ไม่ใช่จำนวนวันตายตัวของทุกปี

ผลตอบแทน close-to-close หนึ่งค่าต้องใช้ราคาปิดสองวัน หากมีราคาปิด 252 ค่า จะคำนวณผลตอบแทนติดกันได้ 251 ค่า ถ้าต้องการผลตอบแทนครบทุกวันของปี ต้องมีราคาปิดวันซื้อขายสุดท้ายของปีก่อนด้วย อย่าสับสนระหว่างจำนวนราคากับจำนวนผลตอบแทน

ลองทำเอง — มีวันขาดทุนเพิ่มหนึ่งวัน

ของที่มี: กลับไปที่ข้อมูลสิบวันแรก แล้วเพิ่มผลตอบแทน −4% อีกหนึ่งวัน รวมเป็นสิบเอ็ดวัน ให้ทุกวันมีน้ำหนักเท่ากัน

คำถาม: ECDF ที่ −2% เปลี่ยนเป็นเท่าไร และสัดส่วนของช่วง $-2\%\lt X\le2\%$ เปลี่ยนเป็นเท่าไร? ลองนับเองก่อนเปิดคำตอบ

เปิดคำตอบและวิธีตรวจ

วันที่ไม่เกิน −2% เพิ่มจากสองเป็นสามวัน จึงได้ $\widehat F(-2\%)=3/11$ ส่วนจำนวนวันที่อยู่ในช่วง $(-2\%,2\%]$ ยังเป็นเจ็ดวัน จึงได้ $7/11$

ตรวจจากผลต่าง CDF: ยอดถึง +2% เป็น $10/11$ แล้วลบ $3/11$ เหลือ $7/11$ ตรงกัน จำนวนวันในช่วงไม่เปลี่ยน แต่สัดส่วนลดลงเพราะจำนวนข้อมูลทั้งหมดเพิ่มขึ้น

ตรวจเองใน 10 วินาที: ทุกครั้งที่เพิ่มข้อมูล ต้องตรวจทั้งตัวเศษและตัวหาร อย่าเพิ่มตัวหารโดยลืมว่าข้อมูลใหม่อาจเข้าเงื่อนไขด้วย

PDF

quantile คือเกณฑ์ที่แบ่ง distribution ตามสัดส่วนที่กำหนด ส่วน tail คือบริเวณปลายของ distribution เช่น หางซ้ายของผลตอบแทนที่ขาดทุนหนัก

VaR เป็นเกณฑ์ขาดทุนตามช่วงเวลาและระดับความเชื่อมั่น P&L คือกำไรขาดทุน และ NAV คือมูลค่าทรัพย์สินสุทธิที่อาจใช้เป็นฐานแปลงผลตอบแทนเป็นเงิน

const returns = [-3, -2, -1, -1, 0, 0, 1, 2, 2, 4]; // หน่วย %
const ecdf = (data, x) =>
  data.filter(value => value <= x).length / data.length;
console.log(ecdf(returns, -2));             // 0.2
console.log(ecdf(returns, 2) - ecdf(returns, -2)); // ประมาณ 0.7
console.log(1 - ecdf(returns, 2));          // ประมาณ 0.1
console.log(ecdf([...returns, -4], -2));    // 3/11

สรุป — เลือกวิธีนับให้ตรงกับคำถาม

  • ไม่เกินเกณฑ์: ใช้ $F(x)=P(X\le x)$ และรวมค่าที่เท่ากับเกณฑ์ด้วย
  • อยู่ในช่วง $(a,b]$: ใช้ $F(b)-F(a)$ หากต้องรวมขอบซ้าย ต้องบวกโอกาสที่จุดนั้นกลับเข้าไป
  • เท่ากับค่าเดียว: ใช้ความสูงของขั้น $F(a)-F(a^-)$ ไม่ใช่ยอดสะสมทั้งหมด
  • เกินเกณฑ์: ใช้ $1-F(x)$ ส่วนการให้โอกาสแล้วหาเกณฑ์กลับเป็นปัญหา quantile
  • ECDF บอกสัดส่วนในข้อมูล การใช้ทำนายอนาคตต้องมีสมมติฐานเพิ่มเติม และ VaR ไม่ใช่เพดานขาดทุน
