15.3 Multi-Factor Models

ให้แรงร่วมไม่กี่ตัวอธิบายว่าหุ้นขยับไปด้วยกันอย่างไร แล้วใช้มันทั้งแยกฝีมือออกจาก exposure และสร้าง covariance ของหุ้นหลายร้อยตัวจากตัวเลขไม่กี่พันตัว

ทีมจะใช้ Markowitz จัดพอร์ตหุ้น 500 ตัวจากข้อมูลรายวัน 250 วัน (ขนาดหน้าต่างหนึ่งปีที่กฎ Basel ใช้กับ VaR ส่วนปีซื้อขายจริงของตลาดหุ้นสหรัฐฯ มีราว 252 วัน) ข้อมูลมี $500\times250=125{,}000$ ตัวเลข ส่วน covariance matrix ต้องประมาณ 125,250 ตัวเลข นักวิเคราะห์บอกว่า “ข้อมูลเกือบหนึ่งตัวต่อหนึ่งตัวเลข ถือว่าพอ” ใช้ได้ไหม?

ลองตอบก่อนเปิดเฉลย

ใช้ไม่ได้ และปัญหาหนักกว่าแค่ข้อมูลน้อย matrix ที่ได้มี rank ไม่เกิน 249 จึงมีทิศทางพอร์ต 251 ทิศที่ข้อมูลบอกว่าไม่มีความเสี่ยงเลย optimizer จะทุ่มเงินลงทิศพวกนั้นทันที model ห้าปัจจัยใช้ตัวเลขแค่ 3,015 ตัว ได้ข้อมูลราว 41.5 จุดต่อตัว ลดภาระลง 97.6% และ matrix ที่ได้มี inverse เสมอ ราคาที่จ่ายคือต้องเชื่อว่าหุ้นขยับร่วมกันผ่านแรงร่วมเท่านั้น

ภาพรวมก่อนลงสูตร

CAPM ใช้ตลาดเป็นแรงผลักตัวเดียว แต่หุ้นเล็กมักขึ้นลงพร้อมหุ้นเล็กด้วยกัน หุ้นราคาถูกเทียบมูลค่าทางบัญชีมักขยับพร้อมกัน และหุ้นที่เพิ่งชนะก็มักไปด้วยกัน model หลายปัจจัยเปิดให้มีแรงร่วมหลายตัว แต่ละแรงคือผลตอบแทนของพอร์ตที่สร้างตามกติกา แล้วให้หุ้นแต่ละตัวรับแรงพวกนั้นมากน้อยต่างกันตาม loading ส่วนที่แรงร่วมอธิบายไม่ได้เป็นเสียงเฉพาะตัวของหุ้นนั้น ซึ่งไม่เกี่ยวกับหุ้นอื่น

รูปด้านล่างคือโครงของ model: วงกลมสี่วงคือแรงร่วม สี่เหลี่ยมแปดอันคือหุ้น เส้นคือ loading และลูกศรเทาจากด้านล่างคือเสียงเฉพาะตัว หุ้นสองตัวจะขยับด้วยกันได้ทางเดียว คือผ่านวงกลมที่ทั้งคู่ต่อสายอยู่ โครงนี้ใช้สองงาน งานแรกคือแยกผลตอบแทนของกองทุนว่ามาจากแรงไหนเท่าไร ซึ่งเปลี่ยนตัวเลข alpha ได้มาก งานที่สองซึ่งใหญ่กว่าคือสร้าง covariance ของหุ้นจำนวนมากจากตัวเลขไม่กี่ตัว

หน้านี้จะนิยาม model แยกผลตอบแทนของกองทุนหนึ่งด้วยมือ ดูว่าทำไม loading แยกกันไม่ออกเมื่อแรงคล้ายกัน พิสูจน์ว่าทำไมผลตอบแทนคาดหวังต้องเป็นเส้นตรงของ loading (APT) สร้าง covariance จาก model นับตัวเลขที่ต้องประมาณ ดูว่า sample covariance พังอย่างไรเมื่อหุ้นมากกว่าวัน แล้วแก้ด้วยโครงสร้างและ shrinkage

ขั้นที่ 1 — นิยาม model หลายปัจจัย และผลตอบแทนคาดหวังของมัน

เขียนสมการของ CAPM ใหม่ โดยให้มี factor $K$ ตัวแทนตลาดตัวเดียว loading ประมาณด้วย regression หลายตัวแปร ซึ่งคือสมการ $X^{\mathsf T}X\hat\beta=X^{\mathsf T}\mathbf y$ ของ OLS ที่ $X$ มี $K+1$ คอลัมน์ บรรทัดแรกเป็นนิยาม ส่วนบรรทัดสุดท้ายได้จากการหาค่าคาดหวังทั้งสองข้าง

\[ \begin{aligned} r_{i,t}&=a_i+\sum_{k=1}^{K}b_{ik}f_{k,t}+u_{i,t},\\ \mathbb E[u_{i,t}]&=0,\\ \mathbb E[r_i]&=a_i+\sum_{k=1}^{K}b_{ik}\,\mathbb E[f_k]. \end{aligned} \]

ค่าคาดหวังของผลบวกคือผลบวกของค่าคาดหวัง (expected value เป็นเส้นตรง) และ $b_{ik}$ เป็นตัวเลขคงที่ จึงดึงออกมานอก $\mathbb E$ ได้ ส่วนที่เหลือมีค่าเฉลี่ยศูนย์ด้วยเหตุผลเดียวกับ CAPM คือ intercept ดูดค่าเฉลี่ยไปหมดแล้ว ผลตอบแทนคาดหวังจึงแยกเป็นสองแหล่งที่ต่างกันมาก: ส่วนที่ได้จากการถือ factor ซึ่งมาพร้อมความเสี่ยงของ factor และส่วน $a_i$ ที่เหลือ

สิ่งที่สูตรไม่ได้บอกคือ รายชื่อ factor เป็นการตัดสินใจของเรา ไม่ใช่ข้อเท็จจริง ใส่ factor เพิ่มแล้ว SSE ไม่มีทางเพิ่ม alpha ที่เหลือจึงหดได้เสมอด้วยการเพิ่มคอลัมน์เฉย ๆ ต้องตรึงรายชื่อ factor ก่อนดูผล

ขั้นที่ 2 — กองทุน A: alpha ของ CAPM 0.36% เหลือเท่าไรเมื่อหักสี่ปัจจัย

โจทย์ให้อะไรมาบ้าง: กองทุน A มี loading ต่อ market, size, value และ momentum เท่ากับ 1.0, 0.3, 0.4 และ 0.2 สมมติผลตอบแทนคาดหวังรายเดือนของสี่ factor เป็น 0.6%, 0.2%, 0.3% และ 0.4% และ $a=0.10\%$ กองทุนมีเงิน \$10 ล้าน สมมติต่อว่า size, value และ momentum ไม่มี covariance กับ market

\[ \begin{aligned} 1.0(0.6)&=0.60,\quad0.3(0.2)=0.06,\\ 0.4(0.3)&=0.12,\quad0.2(0.4)=0.08,\\ \mathbb E[r_A]&=0.10+0.60+0.06+0.12+0.08\\ &=0.96\%,\\ \beta_{\rm CAPM}&=\frac{\operatorname{Cov}(r_A,f_M)}{\operatorname{Var}(f_M)}=b_M=1.0,\\ \alpha_{\rm CAPM}&=0.96-1.0(0.60)=0.36\%. \end{aligned} \]

คำตอบ: กองทุนคาดได้ 0.96% ต่อเดือน หรือ \$96,000 บนเงิน \$10 ล้าน ถ้าวัดด้วย CAPM ตัวเดียว alpha คือ 0.36% หรือ \$36,000 ต่อเดือน แต่ 0.26 จุดในนั้นมาจาก exposure ต่อ size, value และ momentum ที่ซื้อได้ถูกด้วยกองทุน factor เมื่อหักสี่ปัจจัยแล้วเหลือ alpha จริงแค่ 0.10% หรือ \$10,000 ค่าธรรมเนียมที่คิดจาก “alpha” จึงควรคิดจากตัวหลัง

ตรวจเองใน 10 วินาที: $0.60+0.06+0.12+0.08=0.86$ บวก 0.10 ได้ 0.96 ส่วน $\beta_{\rm CAPM}=b_M$ ได้เพราะสมมติว่าอีกสาม factor ไม่มี covariance กับตลาด ถ้ามี slope ของ CAPM จะดูด exposure ส่วนนั้นเข้ามาด้วย

ขั้นที่ 3 — factor ที่คล้ายกันทำให้ loading แยกกันไม่ออก

ถ้า value กับ factor ใหม่ตัวหนึ่งขยับด้วยกันแทบตลอด regression จะรู้ได้อย่างไรว่าผลตอบแทนมาจากตัวไหน? ดูจาก variance ของค่าประมาณ สมมติสอง factor ถูกปรับให้มีค่าเฉลี่ยศูนย์ variance หนึ่ง และ correlation $\rho$ มีข้อมูล $n$ ช่วง ส่วนที่เหลือมี variance $\sigma^2$ อิสระกัน

\[ \begin{aligned} \hat\beta&=(X^{\mathsf T}X)^{-1}X^{\mathsf T}\mathbf y,\\ \operatorname{Cov}(\hat\beta)&=\sigma^2(X^{\mathsf T}X)^{-1},\\ X^{\mathsf T}X&=n\begin{bmatrix}1&\rho\\\rho&1\end{bmatrix},\\ (X^{\mathsf T}X)^{-1}&=\frac{1}{n(1-\rho^2)}\begin{bmatrix}1&-\rho\\-\rho&1\end{bmatrix},\\ \operatorname{Var}(\hat b_k)&=\frac{\sigma^2}{n}\cdot\frac{1}{1-\rho^2},\\ \rho=0.9:&\quad\frac{1}{1-0.81}\approx5.26,\\ \rho=0.99:&\quad\frac{1}{1-0.9801}\approx50.25. \end{aligned} \]

บรรทัดที่สองมาจากการแทน $\mathbf y=X\beta+\varepsilon$ ลงในบรรทัดแรก ส่วนที่สุ่มคือ $(X^{\mathsf T}X)^{-1}X^{\mathsf T}\varepsilon$ covariance ของมันคือ $(X^{\mathsf T}X)^{-1}X^{\mathsf T}(\sigma^2I)X(X^{\mathsf T}X)^{-1}$ ซึ่งยุบเหลือ $\sigma^2(X^{\mathsf T}X)^{-1}$ ตัวคูณ $1/(1-\rho^2)$ เรียกว่า variance inflation factor

ที่ $\rho=0.9$ variance พองขึ้น 5.26 เท่า SE พองขึ้น $\sqrt{5.26}\approx2.29$ เท่า ที่ 0.99 SE พอง 7.09 เท่า แต่ผลรวม $\hat b_1+\hat b_2$ มี variance $\tfrac{\sigma^2}{n}\cdot\tfrac{2}{1+\rho}$ ซึ่งที่ 0.9 แค่ 1.05 เท่า model รวมยังทำนายได้ดี แค่แบ่งเครดิตให้แต่ละ factor ไม่ได้ ภาพในใจคือการยืนบนเก้าอี้สองตัวที่ชิดกันมาก: รู้ว่าน้ำหนักรวมเท่าไร แต่ไม่รู้ว่าเก้าอี้แต่ละตัวรับไปเท่าไร

ขั้นที่ 4 — ทำไมผลตอบแทนคาดหวังต้องเป็นเส้นตรงของ loading (APT)

เริ่มจากตัวอย่าง สมมติพอร์ตกระจายตัวดีสามพอร์ตที่ความเสี่ยงเฉพาะตัวเกือบหมดไปแล้ว มีปัจจัยเดียว P1 มี loading 0.5 คาดได้ 0.55% ต่อเดือน P2 มี loading 1.5 คาดได้ 1.25% ผสม P1 กับ P2 อย่างละครึ่งได้ loading 1.0 และคาดได้ 0.90% ถ้า P3 มี loading 1.0 แต่คาดได้ 1.00% ก็ซื้อ P3 หนึ่งดอลลาร์ ขายส่วนผสมหนึ่งดอลลาร์ ไม่ใช้เงินและไม่มีความเสี่ยงปัจจัย แต่ได้ 0.10% ต่อเดือนฟรี ทุกคนจะทำจนราคา P3 ขึ้นและผลตอบแทนคาดหวังลงเหลือ 0.90% จุดทั้งสามจึงต้องอยู่บนเส้นเดียว $0.20+0.70b$

\[ \begin{aligned} r_i&=\mu_i+\sum_k b_{ik}\tilde f_k+u_i,\\ \sum_i w_i&=0,\quad\sum_i w_ib_{ik}=0,\\ r_p&=\sum_i w_i\mu_i+\sum_i w_iu_i,\\ \operatorname{Var}(r_p)&=\sum_i w_i^2\sigma_{u_i}^2\approx0,\\ \sum_i w_i\mu_i&=0,\\ \mu_i&=\lambda_0+\sum_k b_{ik}\lambda_k. \end{aligned} \]

บรรทัดที่สองคือพอร์ตที่ไม่ใช้เงินและไม่มี exposure ต่อ factor ใดเลย พจน์ factor จึงหายในบรรทัดที่สาม เมื่อกระจายน้ำหนักไปหลายร้อยตัว ส่วนเฉพาะตัวที่อิสระกันเหลือ variance ราว $\sigma_u^2/N$ ใกล้ศูนย์ พอร์ตที่ไม่ใช้เงินและไม่มีความเสี่ยงต้องได้ผลตอบแทนศูนย์ ไม่อย่างนั้นเป็นกำไรฟรี

จังหวะที่ยากคือบรรทัดสุดท้าย: ทุก $w$ ที่ตั้งฉากกับ vector ของ 1 และกับทุกคอลัมน์ของ $B$ ต้องตั้งฉากกับ $\mu$ ด้วย แปลว่า $\mu$ เขียนได้เป็นผลรวมเชิงเส้นของ vector เหล่านั้น (range กับ null space ของ matrix) สินทรัพย์ที่ loading ศูนย์ทุกตัวต้องได้ $\lambda_0=R_f$ และ $\lambda_k$ คือราคาของ factor $k$ ต่อ loading หนึ่งหน่วย CAPM คือกรณีพิเศษที่มี factor เดียวคือตลาด และ $\lambda_1=\mu_m-R_f$

ขั้นที่ 5 — covariance ของหุ้นทุกตัวจาก model: $B\Sigma_fB^{\mathsf T}+D$

ประโยชน์ที่ใหญ่กว่า attribution คือการสร้าง covariance เขียนสมการ model สำหรับหุ้นทุกตัวพร้อมกันเป็น vector ลบค่าเฉลี่ยออก แล้วใส่นิยามของ covariance matrix ข้อสมมติสองข้อทำงานในบรรทัดที่ห้า

\[ \begin{aligned} r_t-\mathbb E[r_t]&=B\tilde f_t+u_t,\\ \Sigma&=\mathbb E\big[(B\tilde f+u)(B\tilde f+u)^{\mathsf T}\big]\\ &=B\,\mathbb E[\tilde f\tilde f^{\mathsf T}]B^{\mathsf T}+\mathbb E[uu^{\mathsf T}]\\ &\quad+B\,\mathbb E[\tilde fu^{\mathsf T}]+\mathbb E[u\tilde f^{\mathsf T}]B^{\mathsf T},\\ \mathbb E[\tilde fu^{\mathsf T}]&=0,\quad\mathbb E[uu^{\mathsf T}]=D,\\ \Sigma&=B\Sigma_fB^{\mathsf T}+D. \end{aligned} \]

กระจายผลคูณได้สี่ก้อน ก้อนแรกคือแรงร่วม ก้อนที่สองคือส่วนเฉพาะตัว สองก้อนสุดท้ายเป็นพจน์ไขว้ ข้อสมมติแรกคือส่วนเฉพาะตัวไม่เกี่ยวกับ factor พจน์ไขว้จึงหาย ข้อสมมติที่สองคือส่วนเฉพาะตัวของหุ้นสองตัวไม่เกี่ยวกัน $\mathbb E[uu^{\mathsf T}]$ จึงเหลือแต่แนวทแยง ช่อง $(i,j)$ ของก้อนแรกคือ $\sum_{k,l}b_{ik}[\Sigma_f]_{kl}b_{jl}$ ซึ่งคือสูตร covariance ของการแปลงเชิงเส้นเดิม

ผลคือการขยับร่วมกันทั้งหมดของหุ้นสองตัวต้องผ่าน factor ตรงกับรูปโครงที่หุ้นต่อกันได้ผ่านวงกลมเท่านั้น ถ้าหุ้นธนาคารสองตัวมีข่าวร้ายร่วมกันที่ factor ไม่รู้จัก model จะมองไม่เห็น ข้อนี้กลับมาในความผิดท้ายหน้า

ขั้นที่ 6 — หุ้นสองตัว หนึ่ง factor: คำนวณทุกช่อง แล้วแยกความเสี่ยงของพอร์ต

โจทย์ให้อะไรมาบ้าง: loading $B=(1.2, 0.8)^{\mathsf T}$ variance ของ factor 1.00 %² ต่อวัน และ idiosyncratic variance 2.25 กับ 4.00 %² ต่อวัน (ตัวเลขสมมติ) แล้วถามว่าพอร์ตครึ่งต่อครึ่ง $w=(0.5, 0.5)$ เสี่ยงเท่าไร และมาจากไหน

\[ \begin{aligned} B\Sigma_fB^{\mathsf T}&=\begin{bmatrix}1.44&0.96\\0.96&0.64\end{bmatrix},\\ \Sigma&=\begin{bmatrix}3.69&0.96\\0.96&4.64\end{bmatrix},\\ \rho_{12}&=\frac{0.96}{\sqrt{3.69(4.64)}}\approx0.232,\\ \det\Sigma&=17.1216-0.9216=16.20,\\ \mathbf b&=B^{\mathsf T}w=0.6+0.4=1.0,\\ w^{\mathsf T}\Sigma w&=\mathbf b^{\mathsf T}\Sigma_f\mathbf b+w^{\mathsf T}Dw\\ &=1.00+1.5625\\ &=2.5625. \end{aligned} \]

คำตอบ: covariance ของสองหุ้นคือ 0.96 %² ต่อวัน มาจาก $1.2\times0.8\times1.00$ เท่านั้น correlation 0.232 ไม่มีใครวัดตรง ๆ มันถูกสร้างจาก loading สองตัว determinant 16.20 และ trace 8.33 เป็นบวกทั้งคู่ eigenvalue ทั้งสอง (ราว 3.09 และ 5.24) จึงเป็นบวก matrix นี้เป็น positive definite และมี inverse

พอร์ตครึ่งต่อครึ่งมี exposure $\mathbf b=1.0$ ซึ่งคือ loading ของแต่ละหุ้นถ่วงด้วยน้ำหนัก variance แยกได้เป็นก้อน factor 1.00 กับก้อนเฉพาะตัว $0.25(2.25)+0.25(4.00)=1.5625$ ส่วนเฉพาะตัวจึงเป็น 61% ของความเสี่ยง ตัวเลข “% idiosyncratic” นี้คือสถิติที่โต๊ะความเสี่ยงรายงานทุกวัน และ P&L ของพอร์ตก็แยกแบบเดียวกันได้เป็น P&L จาก factor ($\mathbf b^{\mathsf T}f_t$) บวก P&L เฉพาะตัว

ตรวจเองใน 10 วินาที: คำนวณตรงจาก $\Sigma$: $0.25(3.69+4.64+2\times0.96)=0.25(10.25)=2.5625$ ตรงกับผลรวมสองก้อน

ขั้นที่ 7 — นับตัวเลขที่ต้องประมาณ: 500 หุ้น

โจทย์ให้อะไรมาบ้าง: หุ้น $N=500$ ตัว ข้อมูล $T=250$ วัน model ห้าปัจจัย ($K=5$) covariance แบบตรงต้องการ variance $N$ ตัวบนแนวทแยงกับคู่ที่ไม่ซ้ำ $N(N-1)/2$ คู่ เพราะ matrix สมมาตร ส่วน model ต้องการ loading $NK$ ตัว covariance ของ factor $K(K+1)/2$ ตัว และ idiosyncratic variance $N$ ตัว

\[ \begin{aligned} \frac{N(N+1)}{2}&=\frac{500(501)}{2}=125{,}250,\\ NK+\frac{K(K+1)}{2}+N&=2{,}500+15+500\\ &=3{,}015,\\ \frac{125{,}000}{125{,}250}&\approx0.998,\quad\frac{125{,}000}{3{,}015}\approx41.5,\\ 1-\frac{3{,}015}{125{,}250}&\approx97.6\%. \end{aligned} \]

คำตอบ: แบบตรงมีข้อมูลไม่ถึงหนึ่งจุดต่อตัวเลข model ห้าปัจจัยมี 41.5 จุดต่อตัวเลข และลดภาระลง 97.6% ถ้าใช้กฎหัวแม่มือที่อยากได้ราว 30 จุดต่อตัวเลข แบบตรงต้องใช้ $125{,}250\times30/500=7{,}515$ วัน หรือราว 29.8 ปีที่ 252 วันซื้อขายต่อปี ซึ่งหุ้นครึ่งหนึ่งในดัชนียังไม่เข้าตลาดด้วยซ้ำ ส่วน model ใช้ราว 181 วัน

ตรวจเองใน 10 วินาที: $500\times499/2=124{,}750$ คู่นอกแนวทแยง บวก 500 บนแนวทแยงได้ 125,250 และ $5\times6/2=15$ คือจำนวนตัวเลขใน covariance ของห้า factor

ขั้นที่ 8 — หุ้นมากกว่าวัน: sample covariance บอกว่ามีพอร์ตที่ไม่มีความเสี่ยง

นับอย่างเดียวยังไม่พอ ปัญหาที่หนักกว่าเห็นได้จากตัวอย่างเล็กที่สุด หุ้นสามตัว ข้อมูลสองวัน: วันแรกได้ $(1, 2, 0)\%$ วันที่สองได้ $(3, 0, 2)\%$ ค่าเฉลี่ยคือ $(2, 1, 1)$

\[ \begin{aligned} d_t&:=r_t-\bar r,\quad\sum_{t=1}^{T}d_t=0,\\ S&=\frac{1}{T-1}\sum_{t=1}^{T}d_td_t^{\mathsf T},\\ d_1&=(-1, 1, -1),\quad d_2=-d_1,\\ S&=2d_1d_1^{\mathsf T}=\begin{bmatrix}2&-2&2\\-2&2&-2\\2&-2&2\end{bmatrix},\\ w&=(1, 1, 0):\quad d_1^{\mathsf T}w=0,\\ w^{\mathsf T}Sw&=2(d_1^{\mathsf T}w)^2=0. \end{aligned} \]

ข้อมูลสองวันบอกว่าพอร์ตที่ซื้อหุ้นแรกกับหุ้นที่สองอย่างละเท่ากันไม่มีความเสี่ยงเลย เพราะในสองวันนั้นสองตัวขยับสวนกันพอดี พอร์ต $(1, 0, -1)$ ก็ได้ศูนย์เช่นกัน ใครที่เอา $S$ นี้ไปให้ optimizer จะได้พอร์ตที่ lever ทิศนี้ไม่จำกัด เพราะทิศที่ “ไม่มีความเสี่ยง” แต่มีผลตอบแทนคาดหวังสักนิดให้ Sharpe เป็นอนันต์

ในกรณีทั่วไป $S$ เป็นผลรวมของ $T$ ก้อนที่แต่ละก้อนมี rank หนึ่ง และเพราะ $d_t$ รวมกันได้ศูนย์ ก้อนสุดท้ายเขียนได้จากก้อนอื่น rank จึงไม่เกิน $T-1$ หุ้น 500 ตัวกับ 250 วันได้ rank ไม่เกิน 249 เหลือ eigenvalue ศูนย์อย่างน้อย 251 ตัว คือ 251 ทิศทางที่ข้อมูลบอกว่าไม่มีความเสี่ยง ทั้งที่โลกจริงไม่ใช่ (eigenvalue ศูนย์คือ matrix ที่ไม่ positive definite)

ขั้นที่ 9 — covariance ของ model มี inverse เสมอ และ shrinkage ซ่อม $S$ ได้

ทำไม model ไม่พังแบบเดียวกัน? คำนวณความเสี่ยงของพอร์ต $w$ ใด ๆ จาก $\Sigma=B\Sigma_fB^{\mathsf T}+D$ แล้วดูว่ามันเป็นศูนย์ได้หรือไม่ จากนั้นดูวิธีที่งานจริงใช้ซ่อม $S$ โดยผสมมันกับ matrix ที่มีโครงสร้าง $F$

\[ \begin{aligned} w^{\mathsf T}\Sigma w&=(B^{\mathsf T}w)^{\mathsf T}\Sigma_f(B^{\mathsf T}w)\\ &\quad+\sum_i w_i^2\sigma_{u_i}^2\gt0,\\ w=(1, -1.5):\quad B^{\mathsf T}w&=1.2-1.2=0,\\ w^{\mathsf T}\Sigma w&=2.25+1.5^2(4.00)=11.25,\\ \Sigma_{\rm sh}&:=\delta F+(1-\delta)S,\\ F=\operatorname{diag}(S),\ \delta&=0.5,\\ \Sigma_{\rm sh}&=\begin{bmatrix}2&-1&1\\-1&2&-1\\1&-1&2\end{bmatrix},\\ w=(1, 1, 0):\quad w^{\mathsf T}\Sigma_{\rm sh}w&=2+2-2=2. \end{aligned} \]

ก้อนแรกไม่ติดลบเพราะ $\Sigma_f$ เป็น covariance ก้อนที่สองเป็นบวกทุกครั้งที่ $w$ ไม่เป็นศูนย์ เพราะหุ้นทุกตัวมีความเสี่ยงเฉพาะตัว พอร์ต $(1, -1.5)$ ที่ตัด factor ได้หมดยังเหลือ 11.25 %² ต่อวัน $D$ เติมค่าบวกลงแนวทแยง จึงไม่มีทิศไหนที่ความเสี่ยงเป็นศูนย์

shrinkage ใช้แนวคิดเดียวกันกับ $S$ ที่พัง ผสมครึ่งหนึ่งกับแนวทแยงของมันเอง พอร์ต $(1, 1, 0)$ ได้ variance 2 แทน 0 และ eigenvalue เปลี่ยนจาก 6, 0, 0 เป็น 4, 1, 1 เพราะ $\Sigma_{\rm sh}=I+0.5S$ เป้าหมาย $F$ ที่ใช้กันบ่อยอีกแบบคือ variance เฉลี่ยของทุกหุ้นคูณ identity matrix ซึ่งในตัวอย่างนี้เท่ากับ $2I$ ตัวเดียวกันพอดี Ledoit–Wolf เลือก $\delta$ จากข้อมูล ส่วน 0.5 ที่นี่ตั้งเพื่อสาธิต

ความผิดที่ทำให้ความเสี่ยงดูต่ำกว่าจริง

ส่วนเฉพาะตัวที่ไม่เฉพาะตัวจริง: ถ้าสองหุ้นในตัวอย่างหนึ่ง factor เป็นธนาคารที่ส่วนเฉพาะตัวมี correlation 0.5 จริง covariance ที่แท้คือ $0.96+0.5(1.5)(2.0)=2.46$ ไม่ใช่ 0.96 พอร์ตครึ่งต่อครึ่งมี SD จริง 1.820% ต่อวัน แต่ model รายงาน 1.601% ต่ำไป 12% โดยไม่มีสัญญาณเตือน งานจริงจึงเพิ่ม factor ของอุตสาหกรรมเข้าไป และตรวจ correlation ของส่วนที่เหลือเป็นกลุ่ม

อ่าน loading ทีละตัวตอนที่ factor คล้ายกัน: ที่ correlation 0.9 SE ของแต่ละ loading พองขึ้น 2.29 เท่า loading ที่ดูเหมือนบวกชัดอาจสลับเครื่องหมายเมื่อเพิ่มข้อมูลอีกไม่กี่เดือน ให้รายงานผลรวมของกลุ่ม factor ที่คล้ายกัน หรือรวมมันเป็นตัวเดียวก่อน

ใช้ sample covariance ตรง ๆ เมื่อหุ้นมากกว่าวัน: optimizer ไม่รู้ว่า 251 ทิศที่ความเสี่ยงเป็นศูนย์เป็นภาพลวง มันจะถือทิศเหล่านั้นหนักที่สุด ผลคือพอร์ตที่ความเสี่ยงจริงสูงกว่าที่รายงานหลายเท่า

เชื่อ factor ที่ค้นเจอจากข้อมูลชุดเดิม: งานวิจัยตีพิมพ์ factor ไว้หลายร้อยตัว (มักเรียกว่า factor zoo) จำนวนมากมาจากการลองหลายแบบบนข้อมูลชุดเดียวกันแล้วเลือกตัวที่ผ่าน หลายตัวหายไปหลังตีพิมพ์ และหลายตัวอธิบายกันเองจนเกือบซ้ำ เพิ่ม factor แล้ว $R^2$ ในข้อมูลเก่าขึ้นเสมอ แม้ loading จะเป็นตัวเลขสุ่ม ต้องทดสอบนอกตัวอย่างและนับจำนวนครั้งที่ลอง (multiple testing, overfitting)

ใช้ทำอะไรบนโต๊ะจริง

risk model เชิงพาณิชย์ที่โต๊ะหุ้นใช้ทุกวันเป็น factor model ที่มี factor ของตลาด ประเทศ อุตสาหกรรม และลักษณะของบริษัท (style) หลายสิบตัว ใช้พยากรณ์ความเสี่ยงของพอร์ตหลายพันตัว แยกเป็นก้อน factor กับก้อนเฉพาะตัว ฝ่ายวัดผลใช้ regression หลายตัวแปรตัดสินว่าผู้จัดการได้ alpha จริงหรือแค่ถือ exposure ที่ซื้อได้ถูก และผู้จัดการใช้ exposure $B^{\mathsf T}w$ ของพอร์ตสร้างพอร์ตที่เป็นกลางต่อ factor ที่ไม่ต้องการ

ในทางปฏิบัติมีสามวิธีหาตัวเลขของ model วิธีแรกใช้ลักษณะของบริษัทที่รู้อยู่แล้ว เช่นขนาดหรือ book-to-price เป็น loading แล้วหาผลตอบแทนของ factor ทุกวันด้วย cross-sectional regression วิธีที่สองให้ข้อมูลหาทั้ง loading และ factor เองด้วย PCA วิธีที่สามใช้ผลตอบแทนของ factor ที่สังเกตได้ เช่นดัชนีหรือพอร์ตของงานวิจัย แล้วหา loading ด้วย regression อนุกรมเวลาแบบ beta ของ CAPM โครงสร้างทั้งหมดของ model และการแยกความเสี่ยงถูกขยายต่อใน สมการ factor model

function checkMatrix(A, name) {
  if (!Array.isArray(A) || A.length === 0 || !A.every(r => Array.isArray(r) && r.length === A[0].length && r.every(Number.isFinite))) {
    throw new TypeError(name + ' must be a non-empty rectangular matrix of finite numbers');
  }
  return [A.length, A[0].length];
}
const transpose = A => A[0].map((_, j) => A.map(r => r[j]));
function multiply(A, B) {
  const [, k] = checkMatrix(A, 'Left matrix'), [k2] = checkMatrix(B, 'Right matrix');
  if (k !== k2) throw new RangeError('Inner dimensions do not match');
  return A.map(r => B[0].map((_, j) => r.reduce((s, v, t) => s + v * B[t][j], 0)));
}
const quadratic = (S, w) => w.reduce((s, wi, i) => s + wi * S[i].reduce((t, v, j) => t + v * w[j], 0), 0);
// Expected excess return split into alpha plus loading times premium for each factor.
function attribution(alpha, loadings, premiums) {
  if (!Number.isFinite(alpha) || !Array.isArray(loadings) || !Array.isArray(premiums) || loadings.length !== premiums.length) {
    throw new TypeError('Need a finite alpha and loadings and premiums of the same length');
  }
  if (![...loadings, ...premiums].every(Number.isFinite)) throw new TypeError('Loadings and premiums must be finite');
  const contributions = loadings.map((b, k) => b * premiums[k]);
  const expected = alpha + contributions.reduce((s, v) => s + v, 0);
  // If the other factors are uncorrelated with the market (factor 0), a market-only regression keeps
  // slope loadings[0] and its intercept absorbs every other contribution.
  return {contributions, expected, capmAlpha: expected - contributions[0]};
}
// Factor-model covariance B F B^T + diag(d); every residual variance must be positive.
function factorCovariance(B, F, d) {
  const [n, k] = checkMatrix(B, 'Loadings'), [k1, k2] = checkMatrix(F, 'Factor covariance');
  if (k1 !== k || k2 !== k) throw new RangeError('Factor covariance must be K by K');
  if (!Array.isArray(d) || d.length !== n || !d.every(v => Number.isFinite(v) && v > 0)) {
    throw new RangeError('Need one positive residual variance per asset');
  }
  return multiply(multiply(B, F), transpose(B)).map((r, i) => r.map((v, j) => v + (i === j ? d[i] : 0)));
}
// Portfolio variance split into factor part b' F b (b = B' w) and specific part sum w_i^2 d_i.
function riskSplit(B, F, d, w) {
  const b = transpose(B).map(col => col.reduce((s, v, i) => s + v * w[i], 0));
  const factor = quadratic(F, b), specific = w.reduce((s, wi, i) => s + wi * wi * d[i], 0);
  return {exposure: b, factor, specific, total: factor + specific, specificShare: specific / (factor + specific)};
}
function eigen2(S) {
  const tr = S[0][0] + S[1][1], det = S[0][0] * S[1][1] - S[0][1] * S[1][0], gap = Math.sqrt(tr * tr - 4 * det);
  return {det, values: [(tr - gap) / 2, (tr + gap) / 2]};
}
const countParameters = (N, K) => ({direct: N * (N + 1) / 2, factor: N * K + K * (K + 1) / 2 + N});
function sampleCovariance(rows) {
  const [T, N] = checkMatrix(rows, 'Returns');
  if (T < 2) throw new RangeError('Need at least two dates');
  const mean = rows[0].map((_, j) => rows.reduce((s, r) => s + r[j], 0) / T);
  const d = rows.map(r => r.map((v, j) => v - mean[j]));
  return Array.from({length: N}, (_, i) => Array.from({length: N}, (_, j) => d.reduce((s, r) => s + r[i] * r[j], 0) / (T - 1)));
}
// Rank by Gaussian elimination with partial pivoting; pivots below tol times the largest entry count as zero.
function rank(S, tol = 1e-10) {
  const A = S.map(r => r.slice()), n = A.length, m = A[0].length;
  const scale = Math.max(...A.map(r => Math.max(...r.map(Math.abs))));
  let r = 0;
  for (let c = 0; c < m && r < n; c++) {
    let p = r;
    for (let i = r + 1; i < n; i++) if (Math.abs(A[i][c]) > Math.abs(A[p][c])) p = i;
    if (Math.abs(A[p][c]) <= tol * scale) continue;
    [A[r], A[p]] = [A[p], A[r]];
    for (let i = r + 1; i < n; i++) {
      const f = A[i][c] / A[r][c];
      for (let j = c; j < m; j++) A[i][j] -= f * A[r][j];
    }
    r++;
  }
  return r;
}
// Seeded standard normals (mulberry32 + Box-Muller) so the rank demonstration is reproducible.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), q = 2 * Math.PI * u();
    spare = r * Math.sin(q);
    return r * Math.cos(q);
  };
}
function sampleRank(T, N, seed) {
  if (!Number.isInteger(T) || !Number.isInteger(N) || T < 2 || N < 1) throw new RangeError('Need whole numbers T >= 2 and N >= 1');
  const z = normals(seed), rows = Array.from({length: T}, () => Array.from({length: N}, z));
  return rank(sampleCovariance(rows));
}
function shrink(S, delta) {
  checkMatrix(S, 'Sample covariance');
  if (!(delta >= 0 && delta <= 1)) throw new RangeError('Shrinkage weight must lie between 0 and 1');
  return S.map((r, i) => r.map((v, j) => (1 - delta) * v + (i === j ? delta * v : 0)));
}
const vif = rho => {
  if (!(Math.abs(rho) < 1)) throw new RangeError('Correlation must lie strictly between -1 and 1');
  return 1 / (1 - rho * rho);
};

สิ่งที่ควรตอบได้หลังอ่าน

  • ผลตอบแทนคาดหวังแยกเป็น $a+\sum_kb_k\mathbb E[f_k]$ กองทุน A ได้ 0.96% แต่ alpha จริงแค่ 0.10% ไม่ใช่ 0.36% ของ CAPM
  • factor ที่ correlation 0.9 ทำให้ variance ของแต่ละ loading พอง 5.26 เท่า ผลรวมยังแม่น แต่แบ่งเครดิตไม่ได้
  • ถ้าไม่มีกำไรฟรี ผลตอบแทนคาดหวังต้องเป็นเส้นตรงของ loading (APT) และ CAPM คือกรณี factor เดียว
  • model สร้าง $\Sigma=B\Sigma_fB^{\mathsf T}+D$ จากตัวเลข 3,015 ตัวแทน 125,250 ตัว มี inverse เสมอเพราะ $D$ เป็นบวก และแยกความเสี่ยงของพอร์ตเป็นก้อน factor กับก้อนเฉพาะตัวได้
  • หุ้น 500 ตัวกับ 250 วันให้ sample covariance ที่มี rank ไม่เกิน 249 คือ 251 ทิศที่ข้อมูลบอกผิดว่าไม่มีความเสี่ยง shrinkage ยกทิศเหล่านั้นขึ้นจากศูนย์
