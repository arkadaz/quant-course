25.1 Excess Returns, Log Returns, and the Numeraire

ผลตอบแทนที่แบบจำลองความเสี่ยงใช้คือผลตอบแทนที่นับปันผล หักดอกเบี้ยของเงินสดในงวดเดียวกัน วัดเป็นดอลลาร์ และรวมหลายงวดด้วยการทบต้น ซึ่ง log return ทำให้กลายเป็นการบวก

กองทุน market-neutral ทุน \$200 ล้าน ถือหุ้นฝั่ง long \$300 ล้านซึ่งปีนี้ขึ้น 11.0% และ short ตะกร้าหุ้น \$300 ล้านซึ่งขึ้น 6.0% SOFR เฉลี่ยทั้งปี 4.8% รายงานประจำปีเขียนว่ากองทุนทำได้ 12.3% ผู้ลงทุนคนหนึ่งบอกว่า “ชนะเงินฝากสองเท่าครึ่ง” ฝีมือเลือกหุ้นของกองทุนจริง ๆ คือกี่ % และถ้าปีหน้า SOFR เป็น 6.0% โดยหุ้นขยับเท่าเดิม รายงานจะเขียนว่าเท่าไร?

ลองตอบก่อนเปิดเฉลย

ฝีมือคือ 7.5% อีก 4.8 จุดคือดอกเบี้ยของเงินสด \$200 ล้านที่กองทุนถือไว้ ซึ่งผู้ลงทุนได้เองถ้าฝากเงิน ปีหน้ารายงานจะเขียน 13.5% ทั้งที่ฝีมือยังเป็น 7.5% เท่าเดิม ตัวเลขที่วัดฝีมือคือ excess return และสำหรับพอร์ตนี้มันไม่ขยับตาม SOFR เลย เพราะเงินที่ลงฝั่ง long เท่ากับฝั่ง short ถ้าพอร์ตเอียงเป็น long \$350 ล้าน short \$250 ล้าน excess return จะลดครึ่งจุดทุกครั้งที่ SOFR ขึ้นหนึ่งจุด

ภาพรวมก่อนลงสูตร

ผลตอบแทนฟังดูเป็นตัวเลขที่ไม่ต้องตกลงอะไรกัน แต่ 12.3% ในโจทย์มีของสองอย่างปนกัน: ดอกเบี้ยที่เงินสดของกองทุนได้อยู่แล้ว กับกำไรจากการเลือกหุ้น แบบจำลองความเสี่ยงและ factor model ที่กินผลตอบแทนของหุ้นหลายพันตัวต้องการแค่ส่วนหลัง จึงต้องตกลงสี่เรื่องก่อนป้อนตัวเลขเข้าระบบ: นับอะไร (ราคาและปันผล) หักอะไร (ดอกเบี้ยของเงินสดในงวดเดียวกัน ได้ excess return) วัดเป็นเงินสกุลไหน (numeraire ซึ่งเล่มนี้ใช้ดอลลาร์) และรวมหลายงวดอย่างไร (ทบต้น ไม่ใช่บวก)

เรื่องสุดท้ายมีเครื่องมือช่วย: log return $\ln(1+r)$ เปลี่ยนการคูณเป็นการบวก ผลรวมของ log return จึงตรงกับเงินจริงพอดี ส่วนผลรวมของผลตอบแทนธรรมดาสูงเกินจริงเสมอ โดยเฉลี่ยราว $\sigma^2/2$ ต่องวด

หน้านี้เดินตามลำดับนั้น: ผลตอบแทนที่นับปันผล PnL ของพอร์ตพร้อมบัญชีเงินสด excess return และ NMV ที่คุมว่าดอกเบี้ยรั่วเข้ามาเท่าไร การนับคืนของดอกเบี้ยรายวัน การทบต้นด้วย log return ช่องว่าง $\sigma^2/2$ แล้วปิดที่หุ้นต่างสกุลเงิน รูปด้านล่างคือคำตอบของโจทย์เปิดหน้าในภาพเดียว

ศัพท์ที่ใช้ในหัวข้อนี้
Dividend-adjusted return
ผลตอบแทนที่นับทั้งราคาที่เปลี่ยนและปันผลที่ได้ในงวดนั้น ใช้เป็นผลตอบแทนตั้งต้นของทุกการคำนวณ เพราะผู้ถือหุ้นได้เงินทั้งสองก้อน
Excess return
ผลตอบแทนลบดอกเบี้ยของเงินสดในงวดเดียวกัน บอกว่าการลงทุนนี้ให้มากกว่าการถือเงินสดเฉย ๆ เท่าไร factor model และแบบจำลองความเสี่ยงใช้ตัวนี้ทั้งหมด
Net Market Value (NMV)
มูลค่าฝั่ง long ลบมูลค่าฝั่ง short บอกว่าพอร์ตใช้เงินสดสุทธิไปเท่าไร และเป็นตัวคูณที่คุมว่าระดับดอกเบี้ยรั่วเข้า excess return ของพอร์ตแค่ไหน
SOFR และ Actual/360
Secured Overnight Financing Rate คืออัตราดอกเบี้ยข้ามคืนของเงินดอลลาร์ที่มีพันธบัตรรัฐบาลสหรัฐฯ ค้ำ ใช้แทนดอกเบี้ยของเงินสด ตลาดเงินดอลลาร์คิดดอกเบี้ยตามจำนวนคืนจริงหารด้วย 360
Log return
$\ln(1+r)$ บวกกันข้ามงวดได้ตรง ๆ เพราะ log ของผลคูณคือผลบวกของ log ใช้ทุกครั้งที่ต้องรวมหลายงวด
Volatility drag
ช่องว่างราว $\sigma^2/2$ ต่องวดระหว่างค่าเฉลี่ยของผลตอบแทนธรรมดากับค่าเฉลี่ยของ log return ทำให้เงินที่ขึ้นลงแรงโตช้ากว่าค่าเฉลี่ยที่รายงาน
Numeraire
หน่วยเงินที่ใช้วัดทุกอย่าง เล่มนี้ใช้ดอลลาร์ หุ้นในสกุลอื่นต้องแปลงผลตอบแทนเป็นดอลลาร์ก่อนเข้าแบบจำลอง
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$P_i(t),\ D_i(t)$ราคาปิดของหุ้น $i$ วัน $t$ และปันผลต่อหุ้นที่จ่ายในงวดนั้นดอลลาร์ต่อหุ้น
$r_i,\ r_f$ผลตอบแทนของหุ้น $i$ และดอกเบี้ยของเงินสดในงวดเดียวกันทศนิยมต่องวด
$w_i$เงินที่ลงในหุ้น $i$ ติดลบเมื่อ shortดอลลาร์
$A,\ \mathrm{NMV}$ทุนของกองทุน และ $\sum_i w_i$ดอลลาร์
$\tilde r$log return $\ln(1+r)$ต่องวด
$\mu,\ \sigma$ค่าเฉลี่ยและความผันผวนของผลตอบแทนต่องวดทศนิยมต่องวด
$r_\ell,\ g$ผลตอบแทนของหุ้นในสกุลท้องถิ่น และผลตอบแทนของเงินท้องถิ่นเทียบดอลลาร์ทศนิยม

ขั้นที่ 1 — ผลตอบแทนหนึ่งวันที่นับปันผล

ผลตอบแทนคือเงินที่ได้เพิ่มต่อเงินหนึ่งดอลลาร์ที่ลงไป นี่คือนิยาม ถ้าถือหุ้นข้ามวัน ex-dividend ราคาจะลดลงราวเท่าปันผล เพราะเงินก้อนนั้นย้ายจากบริษัทมาเข้าบัญชีเรา สูตรจึงต้องนับทั้งราคาและปันผล ตัวอย่างสมมติ: วันอังคาร ราคาปิดจาก \$50.00 เป็น \$50.60 และได้ปันผล \$0.25 ต่อหุ้น

\[ \begin{aligned} r_i(t)&=\frac{P_i(t)+D_i(t)}{P_i(t-1)}-1\\ &=\frac{50.60+0.25}{50.00}-1\\ &=1.700\%,\\ D=0:&\quad\frac{50.60}{50.00}-1\\ &\quad=1.200\%. \end{aligned} \]

บรรทัดแรกเขียนนิยามในรูป “มูลค่าตอนจบหารด้วยเงินที่ลงไป ลบหนึ่ง” ซึ่งเท่ากับ $(P_i(t)+D_i(t)-P_i(t-1))/P_i(t-1)$ ลืมปันผลวันเดียวหายไปครึ่งจุด และถ้าหุ้นจ่าย \$0.25 ทุกไตรมาส ทั้งปีหายไป $4(0.25)/50=2\%$

หุ้นปันผลสูงจะดูแย่กว่าหุ้นที่ไม่จ่ายปันผลทั้งที่ผู้ถือได้เงินเท่ากัน ฐานข้อมูลราคาส่วนใหญ่มีทั้งราคาดิบและราคาที่ปรับปันผลแล้ว ต้องรู้ว่ากำลังใช้แบบไหน

ขั้นที่ 2 — PnL ของพอร์ต และเงินสดที่เหลือ

ต่อจากหุ้นหนึ่งตัวเป็นทั้งพอร์ต พอร์ตลง $w_i$ ดอลลาร์ในหุ้น $i$ จึงได้หุ้น $w_i/P_i(0)$ หุ้น ติดลบเมื่อ short เงินสดที่เหลือจากทุนคือ $A-\sum_i w_i$ ได้ดอกเบี้ย $r_f$ ถ้าติดลบคือยืมมาและจ่าย $r_f$ หน้านี้สมมติว่ายืมและฝากที่อัตราเดียวกัน แล้วหักสิ่งที่ทุนจะได้ถ้าฝากเงินเฉย ๆ คือ $Ar_f$

\[ \begin{aligned} n_i&=w_i/P_i(0),\\ \text{PnL}_i&=n_i\big(P_i(1)+D_i(1)\big)\\ &\quad-n_iP_i(0)\\ &=w_i\,r_i,\\ \text{PnL}&=\sum_iw_ir_i\\ &\quad+\Big(A-\sum_iw_i\Big)r_f,\\ \text{PnL}-Ar_f&=\sum_iw_i\,(r_i-r_f). \end{aligned} \]

สามบรรทัดแรกคือจำนวนหุ้น $n_i$ คูณมูลค่าตอนจบ ลบเงินที่ลงไป $n_iP_i(0)=w_i$ ดึง $n_iP_i(0)$ ออกเป็นตัวร่วมแล้วใช้นิยามผลตอบแทนที่นับปันผลด้านบน ได้ $w_ir_i$ ทันที ใช้ได้กับ short ด้วยเพราะ $w_i$ ติดลบ คนที่ short ต้องจ่ายทั้งราคาที่ขึ้นและปันผลคืนให้ผู้ให้ยืมหุ้น

บรรทัดสุดท้ายคือหัวใจ: เมื่อหัก $Ar_f$ ออก ก้อน $Ar_f$ ในวงเล็บหายไป ผลตอบแทนของทุกหุ้นกลายเป็นผลตอบแทนลบ $r_f$ เอง ตัวคูณของ $r_f$ ที่ซ่อนอยู่คือ $\sum_iw_i$ ซึ่งคือ NMV

ขั้นที่ 3 — โจทย์เปิดหน้า: 12.3% ในรายงาน ฝีมือ 7.5%

โจทย์ให้อะไรมาบ้าง: ทุน $A=\$200$ ล้าน ฝั่ง long $w=+300$ ได้ 11.0% ฝั่ง short $w=-300$ ได้ 6.0% SOFR 4.8% หน่วยเป็นล้านดอลลาร์ ใช้สูตร PnL ที่เพิ่งได้

\[ \begin{aligned} \sum_iw_ir_i&=300(0.11)-300(0.06)\\ &=33.0-18.0=15.0,\\ \mathrm{NMV}&=300-300=0,\\ \text{PnL}&=15.0+200(0.048)\\ &=24.6,\\ 24.6/200&=12.3\%,\\ 15.0/200&=7.5\%. \end{aligned} \]

คำตอบ: รายงานเขียน 12.3% ซึ่งคือผลตอบแทนรวมบนทุน ในนั้นมี 4.8 จุดที่มาจากดอกเบี้ยของเงินสด \$200 ล้าน excess return คือ 7.5% ถ้าปีหน้า SOFR เป็น 6.0% ผลตอบแทนรวมเป็น $(15.0+200(0.06))/200=13.5\%$ แต่ excess return ยัง $15.0/200=7.5\%$ เพราะ NMV เป็นศูนย์ ตัวคูณของ $r_f$ จึงเป็นศูนย์

ตรวจเองใน 10 วินาที: ฝั่ง long ชนะฝั่ง short 5 จุดบนขนาด \$300 ล้าน ได้ \$15 ล้าน หารทุน \$200 ล้านได้ 7.5% และ $12.3\%-4.8\%=7.5\%$

ขั้นที่ 4 — พอร์ตที่เอียง: ดอกเบี้ยรั่วเข้าครึ่งจุดต่อจุด

ถ้าพอร์ตไม่ neutral ระดับดอกเบี้ยจะรั่วเข้า excess return ขนาดของการรั่วอ่านได้จากสูตร PnL ด้านบนเลย หารทั้งสองข้างด้วยทุนแล้วดูว่า excess return เปลี่ยนเท่าไรเมื่อ $r_f$ ขึ้นหนึ่งหน่วย ตัวอย่าง: long \$350 ล้าน short \$250 ล้าน ขนาดรวมยัง \$600 ล้านเท่าเดิม ผลตอบแทนของสองฝั่งเท่าเดิม

\[ \begin{aligned} \frac{\text{PnL}-Ar_f}{A}&=\frac{\sum_iw_ir_i}{A}-\frac{\mathrm{NMV}}{A}\,r_f,\\ \sum_iw_ir_i&=38.5-15.0=23.5,\\ \frac{23.5}{200}&=11.75\%,\\ \frac{\mathrm{NMV}}{A}&=\frac{100}{200}=0.5,\\ r_f=4.8\%:&\quad11.75\%-2.40\%\\ &\quad=9.35\%. \end{aligned} \]

excess return ของพอร์ตนี้เป็นเส้นตรงใน $r_f$ ที่ความชัน $-\mathrm{NMV}/A=-0.5$ ทุกหนึ่งจุดของ SOFR กิน excess return ครึ่งจุด เพราะพอร์ตใช้เงินสดสุทธิ \$100 ล้านที่ควรได้ดอกเบี้ย ถ้า SOFR เป็นศูนย์ excess return คือ 11.75% ที่ 4.8% เหลือ 9.35% และที่ 10% เหลือ 6.75%

ผลตอบแทนรวมบนทุนของพอร์ตนี้คือ $(23.5+100(0.048))/200=14.15\%$ ซึ่งเท่ากับ $9.35\%+4.8\%$ พอดี ความเอียงของพอร์ตจึงไม่ได้เป็นแค่ความเสี่ยงตลาด แต่เป็นการเดิมพันกับระดับดอกเบี้ยด้วย

ขั้นที่ 5 — ดอกเบี้ยรายวัน: นับคืน ไม่ใช่นับวันทำการ

แบบจำลองรายวันต้องหัก $r_f$ ของวันเดียวกัน SOFR คิดดอกเบี้ยตามจำนวนคืนที่เงินค้างหารด้วย 360 ผลตอบแทนวันอังคาร (ปิดจันทร์ถึงปิดอังคาร) ครอบคลุมหนึ่งคืน แต่ผลตอบแทนวันจันทร์ (ปิดศุกร์ถึงปิดจันทร์) ครอบคลุมสามคืน

\[ \begin{aligned} \text{Tue}:&\quad0.048\times\tfrac{1}{360}\\ &\quad=0.01333\%,\\ \text{Mon}:&\quad0.048\times\tfrac{3}{360}\\ &\quad=0.04000\%,\\ \text{year}:&\quad0.048\times\tfrac{365}{360}\\ &\quad=4.867\%,\\ \text{wrong}:&\quad252\times0.01333\%\\ &\quad=3.360\%. \end{aligned} \]

ทั้งปีต้องได้ 365 คืนเสมอไม่ว่าจะมีวันหยุดกี่วัน เพราะวันหยุดแค่ย้ายคืนไปรวมกับวันทำการถัดไป คนที่ใช้ $0.048/360$ กับทุกวันทำการ (ปีหนึ่งมีราว 252 วัน คือ 365 วันลบเสาร์อาทิตย์ 104 วันและวันหยุดตลาดราว 9 วัน) จะหักดอกเบี้ยทั้งปีแค่ 3.360% ขาดไป 1.507 จุด หรือ 31% ของดอกเบี้ยจริง

excess return ของวันอังคารในตัวอย่างปันผลด้านบนคือ $1.700\%-0.01333\%=1.68667\%$ ตัวเลขรายวันดูเล็กจนน่าทิ้ง แต่รวมทั้งปีคือ 4.867 จุด มากกว่า excess return ทั้งปีของกลยุทธ์จำนวนมาก

ขั้นที่ 6 — ทบต้นหลายงวด และ log return ที่บวกกันได้

ผลตอบแทนหลายงวดไม่ใช่ผลบวกของผลตอบแทนรายงวด เงิน \$1 ที่ผ่าน $T$ งวดกลายเป็นผลคูณของ $1+r(t)$ นี่คือนิยามของผลตอบแทนทบต้น ส่วน log ของผลคูณคือผลบวกของ log นี่คือสมบัติของ logarithm ใช้เส้นทางสมมติหกวัน: +10%, −8%, +12%, −15%, +9%, +6%

\[ \begin{aligned} r(1{:}T)&=\prod_{t=1}^{T}\big(1+r(t)\big)-1\\ &=(1.10)(0.92)(1.12)\\ &\quad\times(0.85)(1.09)(1.06)-1\\ &=11.314\%,\\ \sum_tr(t)&=14.000\%,\\ \sum_t\tilde r(t)&=0.095310-0.083382\\ &\quad+0.113329-0.162519\\ &\quad+0.086178+0.058269\\ &=0.107185,\\ e^{0.107185}-1&=11.314\%. \end{aligned} \]

ผลรวมของ log คือ log ของผลคูณพอดี จึงไม่มีการประมาณเลย แต่ต้องถอด exponential ก่อนอ่านเป็นเงิน: 0.107185 ไม่ได้แปลว่ากำไร 10.72% แต่แปลว่ากำไร 11.314%

ผลรวมของผลตอบแทนธรรมดาได้ 14% สูงกว่าเงินจริง 2.69 จุด และผิดไปทางมองโลกสวยเสมอ เพราะ $\ln(1+r)\le r$ ทุกค่า $r$ ดูวันที่ −15%: log return คือ −0.1625 ต่ำกว่า −0.15 อยู่ 1.25 จุด วันที่ +12%: log return คือ 0.1133 ต่ำกว่า 0.12 อยู่ 0.67 จุด ทุกวันมีส่วนต่างที่เป็นบวก และส่วนต่างสะสมโดยไม่มีอะไรหักล้าง

ถ้าผลตอบแทนเล็ก เช่นรายวันของหุ้นที่ขยับราว 1% จะใช้ $\tilde r\approx r$ และ $e^{x}-1\approx x$ แทนกันได้ แต่กับรายปีหรือหุ้นที่ขยับแรง การประมาณนี้หลุด และหลุดไปทางสูงเกินเสมอ

ขั้นที่ 7 — ช่องว่างมีขนาดราว σ²/2 ต่องวด

ช่องว่าง $r-\ln(1+r)$ ของแต่ละวันในเส้นทางด้านบนดูเหมือนเท่ากับ $r^2/2$ คร่าว ๆ (วัน −15% ได้ 1.25 จุด เทียบ $0.15^2/2=1.125$) อยากรู้ขนาดโดยเฉลี่ย จึงกระจาย log รอบศูนย์ด้วย Taylor series แล้วหาค่าเฉลี่ย โดยใช้ $\mathbb E[r^2]=\sigma^2+\mu^2$ ซึ่งมาจากนิยามของ variance

\[ \begin{aligned} \ln(1+r)&=r-\tfrac12r^2+\tfrac13r^3-\cdots,\\ \mathbb E[\tilde r]&\approx\mu-\tfrac12(\sigma^2+\mu^2),\\ \mu-\mathbb E[\tilde r]&\approx\tfrac12\sigma^2,\\ \sigma=1\%:&\quad252\times\tfrac12(0.01)^2\\ &\quad=1.26\%,\\ \sigma_{\rm yr}&=0.01\sqrt{252}=15.87\%,\\ \tfrac12\sigma_{\rm yr}^2&=\tfrac12(0.15875)^2=1.26\%. \end{aligned} \]

บรรทัดที่สามทิ้ง $\mu^2/2$ เพราะค่าเฉลี่ยรายวันราว 0.03% เล็กกว่าความผันผวนรายวัน 1% มาก และทิ้งพจน์กำลังสามขึ้นไปซึ่งเล็กกว่านั้นอีก ช่องว่างรายวัน $0.5(0.0001)=0.005\%$ ดูไม่มีอะไร แต่รวม 252 วันได้ 1.26 จุดต่อปี เท่ากับ $\tfrac12\sigma_{\rm yr}^2$ เพราะ variance บวกกันตามจำนวนวัน

ที่ความผันผวน 30% ต่อปี ช่องว่างเป็น $0.5(0.09)=4.5$ จุด และที่ 60% เป็น 18 จุด ช่องว่างโตตามกำลังสองของความผันผวน นี่คือเรื่องเดียวกับ drift ของ GBM: ราคาคาดหวังโตที่ $\mu$ แต่ log ของราคา (และราคากลาง) โตที่ $\mu-\sigma^2/2$

ขั้นที่ 8 — ค่าเฉลี่ยเรขาคณิตไม่เคยเกินค่าเฉลี่ยเลขคณิต

รายงานผลงานมักโชว์ค่าเฉลี่ยของผลตอบแทนรายงวด $\bar r$ แต่เงินของผู้ลงทุนโตตามค่าเฉลี่ยเรขาคณิต $G=\big[\prod_t(1+r_t)\big]^{1/T}-1$ สองตัวนี้เรียงกันเสมอ พิสูจน์ด้วยความจริงที่เพิ่งเห็นในรูปเส้นโค้ง: $\ln x$ งอลง จึงอยู่ใต้เส้นสัมผัสของมันทุกจุด ตั้ง $x_t=1+r_t$ และให้ $m$ เป็นค่าเฉลี่ยของ $x_t$ ซึ่งคือ $1+\bar r$ แล้วใช้เส้นสัมผัสที่จุด $m$

\[ \begin{aligned} \ln x_t&\le\ln m+\frac{x_t-m}{m},\\ \frac1T\sum_t\ln x_t&\le\ln m+0,\\ 1+G&\le m=1+\bar r,\\ \text{6 days}:&\quad\bar r=14\%/6=2.333\%,\\ &\quad G=1.113140^{1/6}-1\\ &\quad=1.802\%. \end{aligned} \]

บรรทัดที่สองได้จากการหาค่าเฉลี่ยทั้งสองข้าง ก้อน $(x_t-m)/m$ เฉลี่ยแล้วเป็นศูนย์พอดีเพราะ $m$ คือค่าเฉลี่ยของ $x_t$ เอง แล้วยกทั้งสองข้างขึ้นเป็นกำลังของ $e$ ได้บรรทัดที่สาม สองตัวเท่ากันเฉพาะเมื่อทุกงวดได้ผลตอบแทนเท่ากัน

เส้นทางหกวันมีค่าเฉลี่ยเลขคณิต 2.333% ต่อวัน แต่เงินโตจริงแค่ 1.802% ต่อวัน ตรวจ: $1.01802^6=1.1131$ กรณีสุดขั้วคือขึ้น 50% แล้วลง 50%: ค่าเฉลี่ยเลขคณิต 0% แต่ค่าเฉลี่ยเรขาคณิต $\sqrt{0.75}-1=-13.40\%$ ต่องวด เงิน \$1 เหลือ \$0.75 ช่องว่างระหว่างสองค่าเฉลี่ยคือ volatility drag ในอีกรูปหนึ่ง

ขั้นที่ 9 — หุ้นต่างสกุลเงิน: numeraire คือดอลลาร์

นักลงทุนดอลลาร์ซื้อหุ้นยุโรปด้วยการแลกดอลลาร์เป็นยูโร สิ่งที่เขาได้ต้องวัดเป็นดอลลาร์ เพราะดอลลาร์คือ numeraire เงินหนึ่งดอลลาร์โตตามหุ้นในสกุลยูโร แล้วโตอีกชั้นตามค่าเงินยูโร จึงเป็นผลคูณของสองตัว ตัวอย่างสมมติ ทุกตัวเป็นของช่วงเดียวกัน: หุ้นขึ้น $r_\ell=3.0\%$ ในสกุลยูโร EURUSD จาก 1.0900 เป็น 1.1008 ดอกเบี้ยยูโร 2.4% ดอกเบี้ยดอลลาร์ 4.8%

\[ \begin{aligned} g&=\frac{1.1008}{1.0900}-1=0.9908\%,\\ r_\$&=(1+r_\ell)(1+g)-1\\ &=(1.03)(1.009908)-1\\ &=4.0206\%,\\ r_\$-r_f^{\$}&=4.0206\%-4.8\%\\ &=-0.7794\%. \end{aligned} \]

ผลลัพธ์นี้แยกเป็นก้อนที่ตั้งชื่อได้ กางวงเล็บของ $r_\$$ ได้ $r_\ell+g+r_\ell g$ แล้วบวกลบ $r_f^{\rm EUR}$ เข้าไปหนึ่งครั้ง จะได้สามก้อนที่รวมกันเท่า $r_\$-r_f^{\$}$ พอดี

\[ \begin{aligned} r_\ell-r_f^{\rm EUR}&=0.6000\%,\\ g+r_f^{\rm EUR}-r_f^{\$}&=-1.4092\%,\\ r_\ell\,g&=+0.0297\%,\\ \text{sum}&=-0.7794\%. \end{aligned} \]

ก้อนแรกคือ excess return ของหุ้นในบ้านของมันเอง ก้อนที่สองคือ excess return ของการถือเงินยูโรแทนดอลลาร์ ซึ่งได้ทั้งค่าเงินที่แข็งขึ้นและดอกเบี้ยยูโร แต่เสียดอกเบี้ยดอลลาร์ ก้อนที่สามคือกำไรของหุ้นที่ได้ค่าเงินด้วย หุ้นขึ้น 3% และยูโรแข็ง 1% แต่นักลงทุนดอลลาร์แพ้เงินฝากดอลลาร์ 0.78 จุด เพราะดอกเบี้ยดอลลาร์สูงกว่ายูโร 2.4 จุด

log return ไม่มีก้อนไขว้: $\ln1.03+\ln1.009908=0.029559+0.009859=0.039418$ ซึ่งคือ $\ln1.040206$ พอดี นี่เป็นอีกเหตุผลที่งานข้ามสกุลเงินชอบ log return

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

รายงานผลตอบแทนรวมเป็นฝีมือ: กองทุนในโจทย์ได้ 12.3% ในปีที่ SOFR 4.8% และ 13.5% ในปีที่ 6.0% ทั้งที่ฝีมือเท่ากันที่ 7.5% การเทียบผลงานข้ามปีด้วยผลตอบแทนรวมคือการเทียบระดับดอกเบี้ยของแต่ละปี

ใช้ $r_f/360$ กับทุกวันทำการ: ดอกเบี้ยทั้งปีเหลือ 3.360% แทน 4.867% excess return ของทุกหุ้นสูงไป 1.5 จุดต่อปีทั้งที่ไม่มีใครทำอะไร

ป้อนผลตอบแทนดิบเข้า factor model: ผลตอบแทนดิบของทุกหุ้นมีดอกเบี้ยของวันนั้นปนอยู่ เฉลี่ยวันละ $4.867\%/252=0.0193\%$ factor ที่มี loading เท่ากับ 1 ทุกหุ้น เช่น market factor จะดูดก้อนนี้ไปทั้งหมด และรายงานว่าตลาดให้ผลตอบแทนเกินจริงราว 4.87 จุดต่อปี พอร์ตที่เอียง long จะดูเหมือนมีฝีมือจับจังหวะตลาด ทั้งที่เป็นแค่ดอกเบี้ย

บวกผลตอบแทนธรรมดาข้ามหลายงวด: เส้นทางหกวันให้ผลรวม 14% แต่เงินจริง 11.31% รายวันที่ขยับ 1% ช่องว่างแค่ $0.01-\ln1.01=0.005$ จุด แต่ปีที่ขึ้น 40% มี log return $\ln1.4=33.65\%$ ต่างกัน 6.35 จุด การประมาณ $\tilde r\approx r$ ใช้ได้กับงวดสั้นเท่านั้น

ทิ้งก้อนไขว้ของค่าเงินในเดือนที่ขยับแรง: ในตัวอย่างหุ้นยุโรป ก้อนไขว้แค่ 0.03 จุด แต่ถ้าหุ้นขึ้น 30% และเงินท้องถิ่นแข็ง 20% ก้อนไขว้คือ $0.30\times0.20=6$ จุด การแยกแบบเส้นตรงจะหายไปทั้ง 6 จุด

ใช้ทำอะไรบนโต๊ะจริง

ข้อมูลที่ป้อน factor model คือ excess return รายวันที่นับปันผลและวัดเป็นดอลลาร์ ทีมข้อมูลเก็บสามตัวเลขแยกกันเสมอ: ผลตอบแทนราคาพร้อมปันผล ดอกเบี้ยของวันตามจำนวนคืน และค่ายืมหุ้นของฝั่ง short ในโลกจริงการยืมเงินเสีย SOFR บวกส่วนต่าง และเงินที่ได้จากการ short ได้ดอกเบี้ย SOFR ลบค่ายืมหุ้น (securities lending) สองก้อนหลังนี้รวมกันเรียกว่า carry และรายงานแยกจากฝีมือเลือกหุ้น

งานข้ามหุ้นใช้ผลตอบแทนธรรมดา งานข้ามเวลาใช้ log return เหตุผลอยู่ที่ว่าอะไรบวกกันได้: ผลตอบแทนของพอร์ตคือ $\sum_iw_ir_i/A$ ซึ่งเป็นเส้นตรงในผลตอบแทนธรรมดา ถ้าผลตอบแทนของทุกหุ้นเป็น Normal ร่วมกัน PnL ของพอร์ตก็เป็น Normal และคิด variance ได้จาก weight กับ covariance matrix ตัวเดียว (ความเสี่ยงของพอร์ตจาก covariance matrix) แต่ผลคูณของผลตอบแทนหลายงวดไม่เป็น Normal อีกต่อไป ขณะที่ผลรวมของ log return ที่อิสระกันยังเป็น Normal และ variance บวกกันตามจำนวนงวด

ทำไมหักดอกเบี้ยข้ามคืน ไม่หักผลตอบแทนพันธบัตร 10 ปี? เพราะ $r_f$ ต้องเป็นดอกเบี้ยของงวดเดียวกับผลตอบแทน เงินสดหนึ่งวันได้ดอกเบี้ยหนึ่งวัน พันธบัตร 10 ปีมีราคาขึ้นลงของตัวเอง จึงไม่ใช่เงินสดที่แทบไม่มีความเสี่ยง ส่วนทีมความเสี่ยงดู NMV ทุกวันเพราะมันคือความไวของ excess return ต่อระดับดอกเบี้ย และพอร์ตหลายสกุลเงินต้องตัดสินใจว่าจะ hedge ก้อนค่าเงินหรือถือไว้เป็นการเดิมพัน

โจทย์ตรวจความเข้าใจ

1. หุ้นปิดเมื่อวาน \$80.00 วันนี้เป็นวัน ex-dividend ปิดที่ \$79.20 และจ่ายปันผล \$1.20 ต่อหุ้น ผลตอบแทนของวันนี้คือเท่าไร และถ้าลืมปันผลจะได้เท่าไร?

เฉลย

$(79.20+1.20)/80.00-1=80.40/80.00-1=0.50\%$ ถ้าลืมปันผลได้ $79.20/80.00-1=-1.00\%$ วันที่ผู้ถือได้กำไรครึ่งจุดจะถูกบันทึกเป็นวันขาดทุนหนึ่งจุด

2. ทุน \$200 ล้าน long \$400 ล้านที่ขึ้น 8% และ short \$200 ล้านของตะกร้าที่ขึ้น 5% SOFR 5% ผลตอบแทนรวมบนทุน excess return และความไวของ excess return ต่อ SOFR คือเท่าไร?

เฉลย

$\sum_iw_ir_i=400(0.08)-200(0.05)=32-10=22$ NMV $=200$ เงินสดเหลือ $200-200=0$ จึงไม่มีดอกเบี้ยรับ ผลตอบแทนรวม $22/200=11\%$ excess return $=(22-200(0.05))/200=12/200=6\%$ ตรวจด้วย $\sum_iw_i(r_i-r_f)=400(0.03)-200(0)=12$ ตรงกัน ความไวคือ $-\mathrm{NMV}/A=-1$: SOFR ขึ้นหนึ่งจุด excess return ลดหนึ่งจุดเต็ม เพราะพอร์ตใช้เงินสดเท่าทุนทั้งก้อน

3. กองทุนได้ +20%, −10% และ +5% ในสามปี ผลตอบแทนทบต้นสามปี ค่าเฉลี่ยเลขคณิต และค่าเฉลี่ยเรขาคณิตคือเท่าไร?

เฉลย

ผลคูณ $1.2\times0.9\times1.05=1.134$ ทบต้นสามปีได้ 13.4% ค่าเฉลี่ยเลขคณิต $(20-10+5)/3=5.00\%$ ค่าเฉลี่ยเรขาคณิต $1.134^{1/3}-1=4.2808\%$ ต่ำกว่าตามการพิสูจน์ด้วยเส้นสัมผัส ตรวจด้วย log: $\ln1.2+\ln0.9+\ln1.05=0.125751$ และ $e^{0.125751}=1.134$

รันใน Node.js ได้โดยไม่ติดตั้งแพ็กเกจ โค้ดคิดผลตอบแทนที่นับปันผล PnL ของพอร์ตพร้อมบัญชีเงินสด excess return ที่ระดับดอกเบี้ยต่าง ๆ ดอกเบี้ยตามจำนวนคืน การทบต้นกับผลรวมของ log ของเส้นทางหกวัน ช่องว่าง $\sigma^2/2$ และก้อนทั้งสามของหุ้นยุโรป

เปิดดูโค้ด 
const {log, exp, sqrt} = Math;

// dividend-adjusted return: (end price + dividend) / start price - 1
const simpleReturn = (p0, p1, dividend = 0) => (p1 + dividend) / p0 - 1;

// dollar positions {value, ret}, a short has value < 0; cash = capital - NMV earns rf
function bookReturns(capital, positions, rf) {
  let nmv = 0, raw = 0;
  for (const {value, ret} of positions) { nmv += value; raw += value * ret; }
  const total = raw + (capital - nmv) * rf;
  return {nmv, total: total / capital, excess: (total - capital * rf) / capital};
}

// Actual/360 money-market interest for a number of calendar nights
const accrual = (rate, nights) => rate * nights / 360;

// compounding, sum of logs, arithmetic and geometric means of a return path
const compound = rs => rs.reduce((w, r) => w * (1 + r), 1) - 1;
const logSum = rs => rs.reduce((s, r) => s + log(1 + r), 0);
const mean = rs => rs.reduce((s, r) => s + r, 0) / rs.length;
const geometric = rs => exp(logSum(rs) / rs.length) - 1;

// dollar return of a euro stock: local excess + currency excess + cross term
function usdReturn(local, fx0, fx1, rateEur, rateUsd) {
  const g = fx1 / fx0 - 1, usd = (1 + local) * (1 + g) - 1;
  return {g, usd, excess: usd - rateUsd, localExcess: local - rateEur,
    currencyExcess: g + rateEur - rateUsd, cross: local * g};
}

const pct = x => (100 * x).toFixed(4) + '%';
const neutral = [{value: 300, ret: 0.11}, {value: -300, ret: 0.06}];
const tilted = [{value: 350, ret: 0.11}, {value: -250, ret: 0.06}];
const path = [0.10, -0.08, 0.12, -0.15, 0.09, 0.06];

console.log('dividend day', pct(simpleReturn(50, 50.6, 0.25)), 'without dividend', pct(simpleReturn(50, 50.6)));
for (const rf of [0.048, 0.06]) {
  const b = bookReturns(200, neutral, rf);
  console.log('neutral book, SOFR', rf, 'total', pct(b.total), 'excess', pct(b.excess));

สิ่งที่ควรตอบได้หลังอ่าน

  • ผลตอบแทนหนึ่งงวดคือ $(P_i(t)+D_i(t))/P_i(t-1)-1$ ลืมปันผล \$0.25 บนหุ้น \$50 หายไปครึ่งจุด และ 2% ต่อปีถ้าจ่ายทุกไตรมาส
  • หักดอกเบี้ยที่ทุนได้อยู่แล้วออกจาก PnL จะได้ $\sum_iw_i(r_i-r_f)$ กองทุนในโจทย์รายงาน 12.3% แต่ excess return คือ 7.5%
  • excess return ของพอร์ตไวต่อดอกเบี้ยด้วยความชัน $-\mathrm{NMV}/A$: ศูนย์เมื่อ NMV เป็นศูนย์ และ −0.5 เมื่อ long \$350 ล้าน short \$250 ล้านบนทุน \$200 ล้าน
  • ดอกเบี้ยรายวันคิดตามจำนวนคืน วันจันทร์มีสามคืน ทั้งปีได้ $4.8\%\times365/360=4.867\%$ ไม่ใช่ 3.360%
  • ผลรวมของ log คือ log ของผลคูณพอดี เส้นทางหกวันให้ 11.314% ทั้งจากการทบต้นและจาก $e^{0.107185}-1$ ขณะที่ผลรวมของผลตอบแทนธรรมดาได้ 14% ช่องว่างเฉลี่ยราว $\sigma^2/2$ ต่องวด และค่าเฉลี่ยเรขาคณิตไม่เคยเกินค่าเฉลี่ยเลขคณิต
  • หุ้นต่างสกุลให้ excess return ดอลลาร์เท่ากับ excess return ท้องถิ่น บวก excess return ของค่าเงิน บวกก้อนไขว้ หุ้น +3% กับยูโร +1% ยังแพ้เงินฝากดอลลาร์ 0.78 จุด

ตอนนี้มีผลตอบแทนที่สะอาดแล้ว หน้าถัดไปเอา excess return รายวันแบบนี้มาดูว่ามีนิสัยอะไรที่ทุกตลาดมีเหมือนกัน: หางหนากว่า Normal ทิศไม่มีความจำแต่ขนาดมี และหางบางลงเมื่อรวมหลายวัน อ่านต่อที่ นิสัยของผลตอบแทนหุ้น (stylized facts)
