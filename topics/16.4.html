16.4 Autoregressive Conditional Heteroskedasticity (ARCH) and Generalized ARCH (GARCH) Volatility Forecasting

GARCH คือสูตรอัปเดตความผันผวนทุกเช้า: variance ของพรุ่งนี้มาจากข่าวกำลังสองของวันนี้กับ variance เดิม ความผันผวนจึงพุ่งหลังวันที่ตลาดขยับแรง แล้วค่อย ๆ กลับสู่ระดับปกติ ตัวเลขนี้ใช้กำหนดขนาดพอร์ตได้ทุกวัน

คุณดูแลพอร์ตหุ้นมูลค่า \$100 ล้าน (พอร์ตคือหุ้นทั้งหมดที่ถืออยู่) ฝ่ายบริหารความเสี่ยงตั้งกฎไว้ข้อหนึ่ง: ในวันแย่ 1 วันจาก 100 วัน พอร์ตต้องขาดทุนไม่เกิน \$3 ล้าน ตัวเลขขาดทุนนี้เรียกว่า 1-day 99% VaR (Value at Risk) ทุกเช้าต้องตรวจว่ากฎยังผ่านไหม ถ้าไม่ผ่าน ต้องขายหุ้นออกบางส่วนจนผ่าน

VaR ขึ้นกับว่าวันนี้ตลาดน่าจะแกว่งแรงแค่ไหน ขนาดการแกว่งนี้เรียกว่าความผันผวนรายวัน $\sigma$ คือ SD ของผลตอบแทนหนึ่งวัน (ผลตอบแทนคือราคาเปลี่ยนไปกี่ % ในวันนั้น) เช่น $\sigma=1\%$ แปลว่าวันปกติราคาขยับขึ้นหรือลงราว 1%

ของที่รู้:

  • มูลค่าพอร์ต $A=\$100$ ล้าน และเพดาน VaR $L=\$3$ ล้าน
  • เมื่อวาน แบบจำลองคาดความผันผวนไว้ $\sigma_{t-1}=1\%$ ต่อวัน
  • แต่เมื่อวานตลาดร่วงจริง ผลตอบแทน $r_{t-1}=-4\%$ แรงเป็น 4 เท่าของที่คาด
  • ทีมใช้สูตรอัปเดตความผันผวนทุกเช้าชื่อ GARCH(1,1) สูตรนี้มีตัวเลขสามตัวที่ฟิตจากข้อมูลย้อนหลังไว้แล้ว (ค่าสมมติ): $\omega=1.8\times10^{-6}$, $\alpha=0.09$, $\beta=0.89$ หน้านี้จะอธิบายว่าแต่ละตัวทำหน้าที่อะไร

ในห้องประชุม คนหนึ่งบอกว่า “ใช้ 1% ต่อไป วันเดียวไม่เปลี่ยนโลก” อีกคนบอกว่า “ใช้ 4% เพราะนั่นคือสิ่งที่เพิ่งเกิด” ความผันผวนของวันนี้ควรเป็นเท่าไร และต้องขายหุ้นออกเท่าไรให้ VaR ไม่เกิน \$3 ล้าน?

ลองตอบก่อนเปิดเฉลย

ไม่ใช่ทั้งสองค่า GARCH ให้คำตอบอยู่ระหว่างกลาง แต่ใกล้ 1% มากกว่า สูตรของมันคือ $\sigma_t^2=\omega+\alpha r_{t-1}^2+\beta\sigma_{t-1}^2$ (ขั้นที่ 2 อธิบายที่มา) ส่วน VaR คือ $2.326348\,\sigma_tA$ โดย 2.326348 คือระยะ (นับเป็นจำนวน SD) ที่ Normal มีโอกาสตกต่ำกว่าแค่ 1% (ขั้นที่ 7 อธิบายที่มา) ตัวเลขเงินในสามบรรทัดล่างนับเป็นล้านดอลลาร์

\[\begin{aligned}\sigma_t^2&=1.8\times10^{-6}+0.09(0.04)^2\\&\quad+0.89(0.01)^2=0.0002348,\\\sigma_t&=\sqrt{0.0002348}=1.532\%,\\\mathrm{VaR}_{\rm before}&=2.326348(0.01)(100)=2.33,\\\mathrm{VaR}_{\rm after}&=2.326348(0.01532)(100)=3.56,\\A_{\max}&=\frac{3}{2.326348(0.015323)}=84.16.\end{aligned}\]

VaR ขึ้นจาก \$2.33 ล้านเป็น \$3.56 ล้าน เกินเพดาน \$3 ล้าน จึงต้องลดพอร์ตเหลือ \$84.16 ล้าน คือขายออก $100-84.16=\$15.84$ ล้าน เส้นพยากรณ์ของ GARCH บอกว่า ถ้าไม่มีเหตุร้ายใหม่ พอร์ตกลับไปเต็ม \$100 ล้านได้ในวันทำการที่ 32 แต่ต้องคำนวณใหม่ทุกเช้าด้วยข้อมูลจริง ไม่ใช่นัดวันซื้อคืนไว้ล่วงหน้า

ภาพรวมก่อนลงสูตร

ทำไมความผันผวนถึงเปลี่ยนได้ทุกวัน หน้า ACF วัดผลตอบแทนรายวันของหุ้นจริงแล้วพบสองอย่าง อย่างแรก ผลตอบแทนแทบไม่จำทิศ วันที่ราคาขึ้นไม่ได้บอกว่าพรุ่งนี้จะขึ้น อย่างที่สอง ผลตอบแทนจำขนาดได้นาน วันที่ขยับแรงมักตามด้วยวันที่ขยับแรง ไม่ว่าจะขึ้นหรือลง

ถ้าขนาดของเมื่อวานช่วยบอกขนาดของวันนี้ได้ ความผันผวนก็ไม่ใช่ค่าคงที่ตัวเดียวแบบใน geometric Brownian motion แต่เป็นตัวแปรที่ขยับทุกวันตามข่าว ในหน้านี้ “ข่าว” คือส่วนของผลตอบแทนที่คาดไม่ถึง แบบจำลองตระกูล ARCH/GARCH เขียนกฎการขยับนั้นเป็นสมการเดียว: variance ของพรุ่งนี้ เท่ากับพื้นคงที่ บวกส่วนหนึ่งของข่าวกำลังสองของวันนี้ บวกส่วนหนึ่งของ variance วันนี้

รูปด้านล่างเทียบสามวิธีประมาณความผันผวนในเหตุการณ์เดียวกัน ก่อนวันร่วง ตลาดขยับวันละ 1% พอดี วันร่วงตลาดลง 4% หลังจากนั้นกลับมาขยับวันละ 1% พอดีทุกวัน สามวิธีคือ

  • GARCH ของหน้านี้ (เส้นน้ำเงิน) กระโดดขึ้นมากที่สุด แล้วลดลงเรียบ ๆ เข้าหาระดับปกติ
  • EWMA (เส้นม่วง) คือค่าเฉลี่ยของข่าวกำลังสองที่ให้น้ำหนักข่าวใหม่มาก และข่าวเก่าน้อยลงเรื่อย ๆ เป็นวิธีที่ระบบความเสี่ยงสำเร็จรูปชื่อ RiskMetrics ใช้ มันกระโดดน้อยกว่าและลดช้ากว่า
  • ค่าเฉลี่ยของข่าวกำลังสอง 20 วันล่าสุดแบบน้ำหนักเท่ากัน (เส้นส้ม) ค้างที่ระดับเดิม 20 วัน แล้วตกหน้าผาทันทีในวันที่วันร่วงหลุดออกจากหน้าต่าง 20 วัน หน้าผานี้มาจากปฏิทินล้วน ๆ ไม่ได้มาจากตลาด

หน้านี้เดินตามลำดับนี้

  • เริ่มจาก ARCH ซึ่งง่ายที่สุด แล้วดูว่ามันลืมเร็วเกินไป
  • เติมความจำเข้าไปจนได้ GARCH แล้วกางสมการให้เห็นว่ามันคือค่าเฉลี่ยถ่วงของข่าวกำลังสองย้อนหลังบวกพื้น
  • หาระดับปกติที่ความผันผวนกลับไปหา
  • คำนวณความผันผวนวันนี้และเส้นพยากรณ์วันข้างหน้า แล้วแปลงเป็น VaR และขนาดพอร์ต
  • ดูว่า GARCH คือ ARMA ของข่าวกำลังสอง และทำไมมันสร้างหางหนาได้เอง
  • แยกข่าวดีกับข่าวร้าย แล้วปิดด้วยวิธีประมาณ $\omega$, $\alpha$, $\beta$ จากข้อมูลจริง
ศัพท์ที่ใช้ในหัวข้อนี้
ความผันผวน (volatility)
SD ของผลตอบแทนหนึ่งวัน บอกว่าวันปกติราคาขยับขึ้นหรือลงราวกี่ % ยกกำลังสองแล้วได้ variance หน้านี้เขียนเป็นทศนิยม เช่น 1% คือ 0.01
ข่าว (shock)
ส่วนของผลตอบแทนที่คาดไม่ถึง คือผลตอบแทนลบค่าเฉลี่ย หน้านี้ถือค่าเฉลี่ยเป็นศูนย์ ข่าวจึงเท่ากับผลตอบแทน วันร่วง 4% คือข่าว −0.04
Conditional variance
variance ของผลตอบแทนพรุ่งนี้ เมื่อรู้ข้อมูลถึงวันนี้แล้ว ต่างจาก variance เฉลี่ยของทุกวันในอดีต ตัวนี้แหละที่บอกว่าวันนี้ควรถือความเสี่ยงได้แค่ไหน
ARCH
autoregressive conditional heteroskedasticity: แบบจำลองที่ variance ของวันนี้ขึ้นกับข่าวกำลังสองของไม่กี่วันก่อน ใช้จับว่าวันแรงมักตามด้วยวันแรง
GARCH
generalized ARCH: ARCH ที่เพิ่ม variance ของเมื่อวานเข้าไปในสมการ ความจำจึงยาว ทั้งที่ใช้ parameter แค่สามตัว เป็นแบบจำลองความผันผวนรายวันที่ใช้กันมากที่สุด
EWMA
exponentially weighted moving average: ค่าเฉลี่ยของข่าวกำลังสองที่น้ำหนักหดลงเท่า ๆ กันทุกวันที่ย้อนไป $\sigma_t^2=(1-\lambda)\epsilon_{t-1}^2+\lambda\sigma_{t-1}^2$ มันคือ GARCH ที่ไม่มีพื้นและไม่มีระดับปกติ ระบบความเสี่ยงสำเร็จรูปนิยมใช้ เพราะมี parameter ตัวเดียว
Persistence
ค่า $\alpha+\beta$ บนเส้นพยากรณ์ ส่วนที่ variance เกินระดับปกติจะเหลือ $\alpha+\beta$ เท่าในวันถัดไป ใช้หา half-life ของช่วงปั่นป่วน
Half-life
จำนวนวันที่ของบางอย่างหดเหลือครึ่ง ถ้ามันเหลือ $p$ เท่าทุกวัน half-life คือ $k$ ที่ทำให้ $p^k=0.5$ คือ $k=\ln0.5/\ln p$
Value at Risk (VaR)
ขาดทุนใน 1 วันที่แบบจำลองคาดว่าจะเกินได้แค่ 1 วันใน 100 วัน ใช้เป็นเพดานความเสี่ยงของโต๊ะ ไม่ใช่เพดานขาดทุน เพราะวันที่แย่กว่านั้นยังเกิดได้ นิยามเต็มอยู่ในหน้า VaR และ expected shortfall
Leverage effect
การที่วันลบดันความผันผวนของหุ้นมากกว่าวันบวกขนาดเท่ากัน GARCH แบบปกติมองไม่เห็น เพราะใช้ข่าวกำลังสองซึ่งตัดทิศทิ้ง รุ่นอย่าง GJR-GARCH แยกสองฝั่งออกจากกัน
Kurtosis
ค่าเฉลี่ยของ (ระยะห่างจากค่าเฉลี่ย)4 หารด้วย variance ยกกำลังสอง กำลังสี่ขยายค่าที่อยู่ไกลมาก ๆ จึงใช้วัดความหนาของหาง Normal มีค่า 3 ค่าที่สูงกว่าบอกว่าหางหนากว่า
วันทำการ
วันที่ตลาดเปิดซื้อขาย ปีหนึ่งมีราว 252 วัน ขั้นที่ 4 แสดงที่มาของตัวเลขนี้
สัญลักษณ์และหน่วย
สัญลักษณ์ความหมายหน่วย
$r_t,\ \epsilon_t$ผลตอบแทนของวัน $t$ และข่าว คือผลตอบแทนลบค่าเฉลี่ย (โจทย์ถือค่าเฉลี่ยเป็นศูนย์ สองตัวนี้จึงเท่ากัน)ทศนิยมต่อวัน (0.01 คือ 1%)
$z_t$ก้อนสุ่ม Normal มาตรฐาน (ค่าเฉลี่ย 0, SD 1) ของวัน $t$ อิสระกันทุกวันไม่มีหน่วย
$\sigma_t^2,\ \sigma_t$variance และความผันผวนของวัน $t$ เมื่อรู้ข้อมูลถึงวันก่อนทศนิยม² และทศนิยมต่อวัน
$\omega,\ \alpha,\ \beta$พื้นของ variance, น้ำหนักของข่าวกำลังสอง, น้ำหนักของ variance เมื่อวานทศนิยม², ไม่มีหน่วย, ไม่มีหน่วย
$V$variance ระยะยาวที่แบบจำลองกลับไปหาทศนิยม²
$f_h$variance ที่พยากรณ์ไว้สำหรับ $h$ วันหลังวันนี้ทศนิยม²
$A,\ L,\ z_{0.99}$มูลค่าพอร์ต, เพดาน VaR และ quantile 99% ของ Normalดอลลาร์, ดอลลาร์, ไม่มีหน่วย

ขั้นที่ 1 — จาก “วันแรงตามด้วยวันแรง” สู่สมการของ variance: ARCH(1)

ถ้าขนาดของเมื่อวานช่วยบอกขนาดของวันนี้ได้ ทางที่ตรงที่สุดคือให้ variance ของวันนี้ขึ้นกับข่าวกำลังสองของเมื่อวาน ทำไมต้องยกกำลังสอง เพราะเราสนใจขนาด ไม่สนทิศ วันลง 4% กับวันขึ้น 4% ให้ $(\pm0.04)^2=0.0016$ เท่ากัน

ก่อนอื่นต้องเขียนผลตอบแทนเป็นภาษาของแบบจำลอง (บรรทัดแรกข้างล่าง) ผลตอบแทน $r_t$ คือค่าเฉลี่ย $\mu$ บวกข่าว $\epsilon_t$ ข่าวคือความผันผวนของวันนั้น $\sigma_t$ คูณก้อนสุ่ม $z_t$ ที่เป็น Normal มาตรฐานและอิสระกันทุกวัน แบบนี้ $\sigma_t$ คุมขนาด ส่วน $z_t$ คุมทิศ บรรทัดที่สองคือนิยามของ ARCH(1): variance วันนี้เท่ากับพื้น $\omega$ บวก $\alpha$ คูณข่าวกำลังสองของเมื่อวาน เลข 1 ในวงเล็บแปลว่ามองข่าวย้อนหลังแค่ 1 วัน

ลองใส่ตัวเลข ใช้ $\alpha=0.09$ เท่ากับแบบจำลองหลักของหน้านี้ ส่วน $\omega$ เลือกให้ระดับปกติของ ARCH(1) เท่ากับของแบบจำลองหลัก คือ $V=9.0\times10^{-5}$ (ขั้นที่ 4 หาค่านี้) ระดับปกติของ ARCH(1) คือ $V=\omega/(1-\alpha)$ ด้วยเหตุผลเดียวกับขั้นที่ 4 จึงได้ $\omega=V(1-\alpha)=9.0\times10^{-5}\times0.91=8.19\times10^{-5}$ แล้วดูสองวัน วันนี้ หลังวันร่วง −4% และพรุ่งนี้ ถ้าวันนี้ตลาดนิ่งสนิท ($\epsilon_t=0$)

\[ \begin{aligned} r_t&=\mu+\epsilon_t,\qquad\epsilon_t=\sigma_tz_t,\\ \sigma_t^2&=\omega+\alpha\,\epsilon_{t-1}^2,\\ \epsilon_{t-1}&=-0.04:\\ \sigma_t^2&=8.19\times10^{-5}+0.09(0.0016)\\ &=2.259\times10^{-4},\\ \sigma_t&\approx1.503\%,\\ \epsilon_t&=0:\\ \sigma_{t+1}^2&=8.19\times10^{-5},\\ \sigma_{t+1}&\approx0.905\%. \end{aligned} \]

ARCH(1) ตอบสนองต่อวันร่วงทันที ความผันผวนขึ้นจาก 1% เป็น 1.503% ปัญหาอยู่ที่วันถัดไป ถ้าวันนี้นิ่งสนิท variance ของพรุ่งนี้เหลือแค่พื้น $\omega$ คือความผันผวน 0.905% ซึ่งต่ำกว่าระดับปกติ 0.9487% ด้วยซ้ำ วันร่วงเมื่อวานซืนถูกลืมหมดในวันเดียว เพราะสมการมองย้อนหลังได้แค่วันเดียว

นี่เป็นกรณีสุดขั้วที่วันถัดมาไม่มีข่าวเลย ถ้าวันถัดมายังขยับแรง ข่าวกำลังสองก็ส่งต่อกันเป็นทอด ๆ ได้ แต่ที่ $\alpha=0.09$ การส่งต่อนี้จางเร็วมาก ทางแก้แรกคือใส่ข่าวกำลังสองย้อนหลังหลายวัน แต่ต้องประมาณน้ำหนักแยกทีละวัน ทางที่ประหยัดกว่าคือเก็บความจำไว้ในตัวแปรเดียว คือ variance ของเมื่อวานเอง เพราะมันสรุปข่าวของทุกวันก่อนหน้าไว้แล้ว

ขั้นที่ 2 — GARCH(1,1) และเงื่อนไขที่ทำให้มันใช้ได้

ขั้นนี้เติมก้อน $\beta\sigma_{t-1}^2$ เข้าไปในสมการ ARCH(1) ทำไมก้อนนี้ถึงช่วย เพราะ variance ของเมื่อวานคำนวณมาจากข่าวของวันก่อน ๆ อยู่แล้ว ใส่มันเข้าไปจึงเท่ากับพกความจำของอดีตทั้งหมดมาด้วยตัวแปรตัวเดียว ผลคือความผันผวนไม่ใช่ค่าคงที่อีกต่อไป มันกลายเป็นตัวแปรที่เดินไปตามเวลา

บรรทัดแรกข้างล่างคือนิยามของ GARCH(1,1) ซึ่งเป็นแบบจำลองที่เราเลือกใช้ เลข (1,1) แปลว่าใช้ข่าวกำลังสองย้อนหลัง 1 วัน และ variance ย้อนหลัง 1 วัน ตามด้วยค่าของหน้านี้ และเงื่อนไขสองข้อ ข้อแรกทำให้ variance เป็นบวกเสมอ ข้อสองทำให้มี variance ระยะยาวที่มีค่าจำกัด

\[ \begin{aligned} \sigma_t^2&=\omega+\alpha\,\epsilon_{t-1}^2+\beta\,\sigma_{t-1}^2,\\ \omega&=1.8\times10^{-6},\\ \alpha&=0.09,\quad\beta=0.89,\\ \omega&\gt0,\quad\alpha\ge0,\quad\beta\ge0,\\ \alpha+\beta&=0.09+0.89=0.98\lt1. \end{aligned} \]

ดูเงื่อนไขข้อแรกก่อน $\omega$ คือพื้นที่บวกทุกวัน อีกสองก้อนคือข่าวกำลังสองกับ variance เดิม ซึ่งไม่ติดลบอยู่แล้ว เมื่อ $\alpha$ และ $\beta$ ไม่ติดลบ variance ใหม่จึงไม่มีทางต่ำกว่า $\omega$

กลไกทำงานแบบนี้ ข่าวกำลังสองที่ใหญ่ดัน variance ขึ้น วันถัดไปจึงมีโอกาสขยับแรงอีก วันแรงจึงเกาะกลุ่มกัน แต่ variance ไม่พุ่งขึ้นไปไม่หยุด เพราะเงื่อนไขข้อสอง $\alpha+\beta\lt1$ บนเส้นพยากรณ์ ส่วนที่ variance เกินระดับปกติจะเหลือ $\alpha+\beta=0.98$ เท่าทุกวัน คือหายไป $1-0.98=2\%$ ต่อวัน (ขั้นที่ 6 แสดงที่มา) นี่ไม่ได้แปลว่าความผันผวนจริงต้องลดทุกวัน ข่าวใหม่ยังดันขึ้นได้เสมอ ถ้า $\alpha+\beta\ge1$ ส่วนเกินไม่หด จึงไม่มี variance ระยะยาวที่มีค่าจำกัด เหตุผลเดียวกับที่ AR(1) ต้องมี $|\phi|\lt1$

ขั้นที่ 3 — กางสมการ: GARCH คือ EWMA ของข่าวกำลังสองที่มีพื้น

สมการของ GARCH ใช้กดเครื่องคิดเลขได้ แต่ยังไม่บอกว่ามันให้น้ำหนักข่าวในอดีตแต่ละวันเท่าไร วิธีดูคือแทนสมการของเมื่อวานลงไปแทน $\sigma_{t-1}^2$ แล้วทำซ้ำไปเรื่อย ๆ แบบเดียวกับที่กางสมการ AR(1) สองบรรทัดท้ายคำนวณน้ำหนักของข่าวสี่วันล่าสุด และจำนวนวันที่น้ำหนักหดเหลือครึ่ง

\[ \begin{aligned} \sigma_t^2&=\omega+\alpha\epsilon_{t-1}^2\\ &\quad+\beta(\omega+\alpha\epsilon_{t-2}^2)\\ &\quad+\beta^2\sigma_{t-2}^2\\ &=\omega(1+\beta)\\ &\quad+\alpha(\epsilon_{t-1}^2+\beta\epsilon_{t-2}^2)\\ &\quad+\beta^2\sigma_{t-2}^2\\ &=\frac{\omega}{1-\beta}\\ &\quad+\alpha\sum_{k=0}^{\infty}\beta^k\epsilon_{t-1-k}^2,\\ \alpha\beta^0,\ \alpha\beta^1&=0.0900,\ 0.0801,\\ \alpha\beta^2,\ \alpha\beta^3&=0.0713,\ 0.0634,\\ 0.89^{k}=0.5\ \Rightarrow\ k&=\frac{\ln0.5}{\ln0.89}\\ &\approx5.95\ \text{days}. \end{aligned} \]

แทนรอบเดียวก็เห็นรูปแบบ: variance ของเมื่อวานหายไป มีข่าวกำลังสองของเมื่อวานซืนคูณ $\alpha\beta$ กับพื้น $\beta\omega$ เข้ามาแทน ทำซ้ำไปเรื่อย ๆ ข่าวทุกวันในอดีตจะโผล่มาครบ ข่าวที่ย้อนไป $k+1$ วันได้น้ำหนัก $\alpha\beta^k$ ส่วนพื้น $\omega$ สะสมเป็น $\omega(1+\beta+\beta^2+\cdots)=\omega/(1-\beta)$ ตามสูตรอนุกรมเรขาคณิต แบบเดียวกับ $c/(1-\phi)$ ของ AR(1)

ตัวเลขบอกเรื่องเดียวกัน ข่าวเมื่อวานได้น้ำหนัก 0.09 ข่าวเมื่อสี่วันก่อนเหลือ $0.09\times0.89^3=0.0634$ น้ำหนักเหลือ 0.89 เท่าทุกวันที่ย้อนไป จึงหดเหลือครึ่งทุก 5.95 วัน ไม่มีวันไหนหลุดออกไปทันที ต่างจากหน้าต่าง 20 วันที่ตัดข่าวเก่าทิ้งแบบหน้าผา

สมการที่กางแล้วหน้าตาคล้ายวิธีที่ระบบความเสี่ยงสำเร็จรูปใช้กันมาก คือ EWMA ซึ่งมีตัวเลขตัวเดียว $\lambda$ คือสัดส่วนที่น้ำหนักเหลือในแต่ละวันที่ย้อนไป ระบบ RiskMetrics ใช้ $\lambda=0.94$ กับข้อมูลรายวัน เขียนเทียบกันได้ดังนี้

\[ \begin{aligned} \sigma_t^2&=(1-\lambda)\epsilon_{t-1}^2+\lambda\sigma_{t-1}^2\\ &=(1-\lambda)\sum_{k=0}^{\infty}\lambda^k\epsilon_{t-1-k}^2,\\ \omega=0,&\quad\alpha=1-\lambda,\quad\beta=\lambda,\\ \lambda=0.94:&\quad\frac{\ln0.5}{\ln0.94}\approx11.2\ \text{days}. \end{aligned} \]

วางสองสมการเทียบกัน จะเห็นว่าเหมือนกันทุกอย่าง ยกเว้นพื้น $\omega/(1-\beta)$ ที่ GARCH มีแต่ EWMA ไม่มี EWMA จึงคือ GARCH ที่ $\omega=0$ และ $\alpha+\beta=(1-\lambda)+\lambda=1$ พอดี น้ำหนักหดครึ่งทุก 11.2 วัน ช้ากว่า GARCH ของหน้านี้

ข้อดีของ EWMA คือมีตัวเลขตัวเดียว ใช้ค่าเดียวกันได้กับทุกสินทรัพย์ อธิบายลูกค้าง่าย และไม่ต้องประมาณสามตัวต่อหุ้นหนึ่งตัว ข้อเสียคือไม่มีระดับปกติ ถ้าถามว่าอีก 10 วันความผันผวนจะเป็นเท่าไร EWMA ตอบค่าเดิมของวันนี้ เพราะ $(1-\lambda)+\lambda=1$ ทำให้ค่าพยากรณ์ไม่หดเลย เส้นพยากรณ์จึงเป็นเส้นแนวนอน ไม่ค่อย ๆ กลับสู่ระดับปกติแบบ GARCH

อย่าสับสนสองอัตราของ GARCH $\beta=0.89$ คืออัตราที่ข่าวเก่าจางไปในค่าของวันนี้ (half-life 5.95 วัน) ส่วน $\alpha+\beta=0.98$ คืออัตราที่เส้นพยากรณ์กลับสู่ระดับปกติ (ขั้นที่ 6) ซึ่งช้ากว่า ทำไมช้ากว่า เพราะตอนพยากรณ์ เราคาดว่าวันข้างหน้าจะมีข่าวใหม่ที่ใหญ่เท่ากับ variance ที่ยังสูงอยู่ ข่าวที่คาดไว้นี้ดัน variance กลับขึ้นส่วนหนึ่ง แต่ในรูปแรกของหน้า เราสมมติให้วันต่อ ๆ ไปขยับแค่ 1% ซึ่งเล็กกว่าที่คาด เส้น GARCH ในรูปนั้นจึงลดเร็ว ใกล้อัตรา $\beta$

ขั้นที่ 4 — ระดับปกติที่ variance กลับไปหา

ถ้าไม่มีวันร่วงและปล่อยตลาดไปนาน ๆ variance จะแกว่งอยู่รอบค่าหนึ่ง ค่านี้คือระดับปกติ $V$ เราต้องรู้มัน เพราะเส้นพยากรณ์ทุกเส้นวิ่งเข้าหามัน วิธีหาเหมือนค่าเฉลี่ยระยะยาวของ AR(1): หาค่าเฉลี่ยของสมการ GARCH ทั้งสองข้าง แล้วตั้งให้ค่าเฉลี่ยของวันนี้เท่ากับของเมื่อวาน ก้อนเดียวที่ต้องคิดก่อนคือค่าเฉลี่ยของข่าวกำลังสอง (บรรทัดแรก)

\[ \begin{aligned} \mathbb E[\epsilon_t^2]&=\mathbb E[\sigma_t^2]\,\mathbb E[z_t^2]=\mathbb E[\sigma_t^2],\\ V&=\omega+\alpha V+\beta V,\\ V&=\frac{\omega}{1-\alpha-\beta}\\ &=\frac{1.8\times10^{-6}}{0.02}\\ &=9.0\times10^{-5},\\ \sqrt V&\approx0.9487\%\ \text{per day},\\ \sqrt{252V}&\approx0.9487\%(15.87)\\ &\approx15.06\%\ \text{per year}. \end{aligned} \]

ข่าวกำลังสองคือ $\epsilon_t^2=\sigma_t^2z_t^2$ บรรทัดแรกแยกค่าเฉลี่ยของผลคูณนี้เป็นผลคูณของค่าเฉลี่ยได้ เพราะ $\sigma_t$ ถูกกำหนดจากข้อมูลถึงเมื่อวานแล้ว ส่วน $z_t$ เป็นก้อนสุ่มใหม่ที่อิสระจากมัน และ $\mathbb E[z_t^2]=1$ เพราะ $z_t$ มี variance 1 ค่าเฉลี่ยของข่าวกำลังสองจึงเท่ากับค่าเฉลี่ยของ variance คือ $V$ แทนลงในสมการ GARCH ได้บรรทัดที่สอง แล้วแก้หา $V$

สังเกตว่า $V$ ไม่ใช่ $\omega$ ตัวส่วน 0.02 ขยาย $\omega$ ขึ้น $1/0.02=50$ เท่า เหมือนที่ $c$ ไม่ใช่ค่าเฉลี่ยของ AR(1)

แปลงเป็นรายปีด้วยการคูณ $\sqrt{252}=15.87$ ไม่ใช่ 252 เพราะข่าวแต่ละวันไม่สัมพันธ์กัน variance จึงบวกกันตามจำนวนวัน แต่ SD คือรากของ variance จึงโตตามรากของจำนวนวัน ปีหนึ่งมี 252 วันทำการ มาจาก 365 วัน ลบเสาร์อาทิตย์ 104 วัน ลบวันหยุดตลาดราว 9 วัน: $365-104-9=252$ คนที่คูณ 252 ตรง ๆ จะได้ $0.9487\%\times252=239\%$ ต่อปี สูงเกินไป $239/15.06=15.9$ เท่า

ขั้นที่ 5 — ความผันผวนของวันนี้หลังวันร่วง 4%

ตอนนี้มีเครื่องมือครบแล้ว กลับไปตอบคำถามแรกของโจทย์เปิด: ความผันผวนของวันนี้เป็นเท่าไร

โจทย์ให้อะไรมาบ้าง:

  • ข่าวเมื่อวาน $\epsilon_{t-1}=-0.04$ (ตลาดร่วง 4%) ยกกำลังสองได้ $\epsilon_{t-1}^2=0.0016$ โจทย์ถือค่าเฉลี่ยผลตอบแทนเป็นศูนย์ −4% ทั้งก้อนจึงเป็นข่าว
  • variance ที่แบบจำลองคาดไว้สำหรับเมื่อวาน $\sigma_{t-1}^2=(0.01)^2=0.0001$ (ความผันผวน 1%)
  • ตัวเลขของแบบจำลอง $\omega=0.0000018$, $\alpha=0.09$, $\beta=0.89$

ทุกตัวเขียนเป็นทศนิยม ไม่ใช่ % คำนวณสมการ GARCH ทีละก้อน แล้วรวมกัน

\[ \begin{aligned} \omega&=0.0000018,\\ \alpha\epsilon_{t-1}^2&=0.09(0.0016)=0.000144,\\ \beta\sigma_{t-1}^2&=0.89(0.0001)=0.000089,\\ \sigma_t^2&=0.0000018+0.000144\\ &\quad+0.000089=0.0002348,\\ \sigma_t&=\sqrt{0.0002348}=1.5323\%,\\ \sqrt{252}\,\sigma_t&=15.87(1.5323\%)\\ &=24.32\%\ \text{per year}. \end{aligned} \]

คำตอบ: 1.532% ต่อวัน ผลรวมสามก้อนยังเป็น variance ต้องถอดรากก่อนจึงได้ความผันผวน แต่ละก้อนมีส่วนแค่ไหน หารแต่ละก้อนด้วยผลรวม

\[ \begin{aligned} \alpha\epsilon_{t-1}^2/\sigma_t^2&=0.000144/0.0002348=61.3\%,\\ \beta\sigma_{t-1}^2/\sigma_t^2&=0.000089/0.0002348=37.9\%,\\ \omega/\sigma_t^2&=0.0000018/0.0002348=0.8\%. \end{aligned} \]

ข่าวเมื่อวานครองคำพยากรณ์ แต่ความผันผวนขึ้นแค่ $1.532/1-1=53\%$ ทั้งที่ข่าวใหญ่กว่าที่คาด $4\%/1\%=4$ เท่า เพราะแบบจำลองให้น้ำหนักข่าววันเดียวแค่ $\alpha=0.09$ แบบจำลองจึงตอบสนอง แต่ไม่ตื่นตระหนก

เทียบกับวิธีที่สาม คือค่าเฉลี่ยหน้าต่าง 20 วันที่ให้น้ำหนักเท่ากัน สมมติว่า 19 วันก่อนวันร่วงแกว่งวันละ 1% พอดี (ข่าวกำลังสองวันละ 0.0001) แล้วเฉลี่ยรวมกับวันร่วง

\[ \begin{aligned} \frac{19\times0.0001+0.0016}{20}&=\frac{0.0035}{20}=0.000175,\\ \sqrt{0.000175}&=1.323\%. \end{aligned} \]

ถ้าวันต่อ ๆ ไปแกว่ง 1% ทุกวันใหม่ที่เข้ามาแทนวัน 1% ที่หลุดออกไป ตัวเลขจึงค้างที่ 1.323% จนวันร่วงหลุดหน้าต่าง แล้วตกเป็น 1.000% ทันที ตามเส้นส้มในรูปแรก แต่ความเสี่ยงไม่ได้หายไปเพียงเพราะปฏิทินเดินผ่าน 20 วัน

ตรวจเองใน 10 วินาที: $0.0000018+0.000144+0.000089=0.0002348$ และ $1.5323^2\approx2.348$

ขั้นที่ 6 — พยากรณ์หลายวัน และ half-life ของช่วงปั่นป่วน

ฝ่ายความเสี่ยงไม่ได้อยากรู้แค่วันนี้ เขาอยากรู้ด้วยว่าอีกกี่วันความผันผวนจะกลับมาปกติ และความเสี่ยงรวม 10 วันข้างหน้าเป็นเท่าไร ปัญหาคือ variance ของพรุ่งนี้ต้องใช้ข่าวของวันนี้ ซึ่งยังไม่เกิด เราไม่รู้ว่าข่าวจะขึ้นหรือลง แต่รู้ค่าเฉลี่ยของข่าวกำลังสอง มันเท่ากับ variance ที่พยากรณ์ไว้ (เหตุผลเดียวกับบรรทัดแรกของขั้นที่ 4) แทนค่าเฉลี่ยนี้ลงไปแทนข่าวที่ยังไม่รู้ แล้ว $\alpha$ กับ $\beta$ จะยุบรวมเป็นตัวเดียว

ให้ $f_h$ คือ variance ที่คาดไว้ของวันที่อยู่ถัดจากวันนี้ไป $h$ วัน โดยใช้ข้อมูลถึงเมื่อวาน ($\mathbb E_{t-1}$ คือค่าคาดเมื่อรู้ข้อมูลถึงวัน $t-1$) และ $f_0$ คือ variance ของวันนี้ ตัวเลขข้างล่างเขียนในหน่วย $10^{-6}$ ให้อ่านง่าย 0.0002348 จึงเขียนเป็น 234.8 ส่วน $\omega$ เป็น 1.8 และ $V$ เป็น 90

\[ \begin{aligned} f_h&:=\mathbb E_{t-1}[\sigma_{t+h}^2],\qquad f_0=\sigma_t^2,\\ f_{h+1}&=\omega+\alpha f_h+\beta f_h\\ &=\omega+0.98f_h,\\ f_1&=1.8+0.98(234.8)\\ &=231.904,\\ f_2&=1.8+0.98(231.904)\\ &\approx229.066,\\ f_h-V&=0.98^h(f_0-V)\\ &=0.98^h(234.8-90)\\ &=0.98^h(144.8),\\ h_{1/2}&=\frac{\ln0.5}{\ln0.98}\\ &\approx\frac{-0.693147}{-0.020203}\\ &\approx34.3\ \text{days}. \end{aligned} \]

ทำไม $\alpha f_h$ ใช้แทนก้อนข่าวได้ เพราะค่าคาดของข่าวกำลังสองในอนาคตคือ $\mathbb E_{t-1}[\epsilon_{t+h}^2]=f_h$ ด้วยเหตุผลเดียวกับระดับปกติ ($\mathbb E[z^2]=1$) บวกกับ tower property (ค่าคาดของค่าคาดที่รู้ข้อมูลมากกว่า คือค่าคาดเดิม)

ต่อมา ลบสมการระดับปกติ $V=\omega+0.98V$ ออกจากสมการของ $f_{h+1}$ ตัว $\omega$ จะหายไป เหลือ $f_{h+1}-V=0.98(f_h-V)$ ส่วนเกินจึงเหลือ 0.98 เท่าทุกวัน ซึ่งคือรูปแบบของ AR(1) ทุกประการ ส่วนเกินวันนี้ $144.8\times10^{-6}$ จึงหดเหลือครึ่งใน 34.3 วันทำการ

ระวังว่า half-life 34.3 วันเป็นของ variance ไม่ใช่ของ $\sigma$ ถ้าถามว่า $\sigma$ จะลงถึงครึ่งทางระหว่าง 1.532% กับ 0.9487% เมื่อไร ให้ยกครึ่งทางนั้นกำลังสองเป็น variance แล้วหาวันที่เส้นพยากรณ์ลงมาถึง (บรรทัดที่สามใช้หน่วย $10^{-6}$ เหมือนเดิม)

ต่อไปคือความเสี่ยงหลายวัน ถ้าถือพอร์ตไว้ 10 วัน ผลตอบแทนรวมคือผลบวกของผลตอบแทนรายวัน 10 วัน ข่าวแต่ละวันไม่สัมพันธ์กัน variance ของผลบวกจึงเท่ากับผลบวกของ variance ที่พยากรณ์ไว้ของแต่ละวัน ($h=0$ ถึง 9) หลายคนใช้ทางลัด คูณ $\sqrt{10}$ กับความผันผวนของวันนี้ หรือกับระดับปกติ ข้างล่างเทียบทั้งสามแบบ (หน่วย $10^{-6}$ จนถึงบรรทัดที่ถอดราก)

\[ \begin{aligned} \sum_{h=0}^{9}f_h&=10V+(f_0-V)\sum_{h=0}^{9}0.98^h\\ &=10(90)+144.8\times\frac{1-0.98^{10}}{1-0.98}\\ &=900+144.8(9.146)\\ &=2224.4,\\ \sqrt{2224.4\times10^{-6}}&=4.716\%,\\ \sqrt{10}\times1.5323\%&=4.846\%,\\ \sqrt{10}\times0.9487\%&=3.000\%. \end{aligned} \]

บรรทัดแรกแยกผลรวมเป็นสองส่วน คือระดับปกติ 10 วัน กับส่วนเกินที่หดแบบเรขาคณิต ส่วนหลังรวมด้วยสูตรอนุกรมเรขาคณิต $1+q+\cdots+q^9=(1-q^{10})/(1-q)$ ที่ $q=0.98$ ทางลัดแรกได้ 4.846% สูงไป เพราะลืมว่าความผันผวนกำลังลดลงทุกวัน ทางลัดที่สองได้ 3.000% ต่ำไปมาก เพราะลืมว่าวันนี้ตลาดยังปั่นป่วน

ขั้นที่ 7 — แปลงความผันผวนเป็น VaR และขนาดพอร์ต

ตอนนี้มีความผันผวนของวันนี้แล้ว ขั้นนี้แปลงมันเป็นตัวเลขเงิน เพื่อตอบคำถามที่สองของโจทย์เปิด: ต้องขายหุ้นออกเท่าไร

โจทย์ให้อะไรมาบ้าง:

  • มูลค่าพอร์ต $A=\$100$ ล้าน และเพดาน VaR $L=\$3$ ล้าน
  • ความผันผวนของวันนี้ $\sigma_t=\sqrt{0.0002348}=1.5323\%$ จากขั้นที่ 5
  • quantile 99% ของ Normal มาตรฐาน $z_{0.99}=2.326348$ คือจุดที่ Normal มาตรฐานมีโอกาสสูงกว่าแค่ 1% เพราะ Normal สมมาตร จุด $-2.326348$ จึงมีโอกาสต่ำกว่าแค่ 1%

ทำไม VaR เท่ากับ $z_{0.99}\sigma_tA$ สมมติว่าผลตอบแทนวันนี้เป็น Normal ที่ค่าเฉลี่ยศูนย์และ SD $\sigma_t$ กำไรขาดทุนของพอร์ต (P&L) คือ $A$ คูณผลตอบแทน วันแย่ 1 วันใน 100 วันคือวันที่ผลตอบแทนต่ำกว่า $-z_{0.99}\sigma_t$ ขาดทุนที่จุดนั้นจึงเป็น $z_{0.99}\sigma_tA$ ถ้าจะให้ VaR ไม่เกิน $L$ พอร์ตต้องไม่ใหญ่กว่า $A_{\max}=L/(z_{0.99}\sigma_t)$

\[ \begin{aligned} \mathrm{VaR}&=z_{0.99}\,\sigma_t\,A,\\ \mathrm{VaR}_{\rm before}&=2.326348(0.01)(10^8)\\ &=2{,}326{,}348,\\ \mathrm{VaR}_{\rm after}&=2.326348\sqrt{0.0002348}\\ &\quad\times10^8\\ &\approx3{,}564{,}706,\\ A_{\max}&=\frac{3{,}000{,}000}{2.326348\sqrt{0.0002348}}\\ &\approx84.16\times10^6,\\ 1-A_{\max}/A&\approx1-0.8416=15.84\%. \end{aligned} \]

คำถามต่อมาคือ พอร์ตจะกลับไปเต็ม \$100 ล้านได้เมื่อไร คำตอบคือเมื่อความผันผวนลดลงจนพอร์ตเต็มผ่านเพดาน ความผันผวนสูงสุดที่พอร์ตเต็มรับได้คือ $\sigma_{\max}=L/(z_{0.99}A)$ ยกกำลังสองเป็น variance แล้วหาว่าเส้นพยากรณ์ของขั้นที่ 6 ลงมาถึงค่านี้ในวันที่เท่าไร (ตั้งแต่บรรทัดที่สามใช้หน่วย $10^{-6}$ เหมือนขั้นที่ 6)

\[ \begin{aligned} \sigma_{\max}&=\frac{3{,}000{,}000}{2.326348\times10^8}\approx1.2896\%,\\ \sigma_{\max}^2&=(0.0128957)^2\approx166.30\times10^{-6},\\ 90+0.98^h(144.8)&\le166.30,\\ 0.98^h&\le\frac{166.30-90}{144.8}\approx0.5269,\\ h&\ge\frac{\ln0.5269}{\ln0.98}=31.7. \end{aligned} \]

บรรทัดสุดท้ายหารด้วย $\ln0.98$ ซึ่งติดลบ เครื่องหมาย $\le$ จึงกลับเป็น $\ge$

คำตอบ: VaR ขึ้นจาก \$2.33 ล้านเป็น \$3.56 ล้าน เกินเพดาน $3.5647/3=1.19$ เท่า คือเกิน 19% จึงต้องลดพอร์ตเหลือ \$84.16 ล้าน คือขายออก $100-84.16=\$15.84$ ล้านเช้านี้ พอร์ตเต็ม \$100 ล้านรับความผันผวนได้สูงสุด 1.2896% ต่อวัน เส้นพยากรณ์ลงมาถึงค่านี้ที่ $h=31.7$ จึงกลับเต็มขนาดได้ในวันที่ 32 แต่นี่เป็นแผนบนกระดาษ ทุกเช้าต้องตรวจใหม่ด้วยข่าวจริง ไม่ใช่วันซื้อคืนที่แน่นอน

ตรวจเองใน 10 วินาที: VaR เป็นเส้นตรงใน $\sigma$ อัตราส่วน $3.5647/2.3263=1.532$ เท่ากับอัตราส่วนของความผันผวนพอดี และ $100/1.532\times(3/2.326)\approx84.2$ ล้าน

ขั้นที่ 8 — GARCH คือ ARMA(1,1) ของข่าวกำลังสอง

เส้นพยากรณ์ในขั้นที่ 6 มีหน้าตาเหมือน AR(1) ทุกประการ ขั้นนี้แสดงว่าไม่ใช่เรื่องบังเอิญ และได้ของแถมคือ ACF ของข่าวกำลังสอง ซึ่งเอาไปเทียบกับข้อมูลจริงได้ (ACF ที่ lag $k$ วัดว่าค่าวันนี้สัมพันธ์กับค่าเมื่อ $k$ วันก่อนแค่ไหน)

ตั้งตัวแปรใหม่ $v_t$ คือส่วนที่ข่าวกำลังสองจริงต่างจาก variance ที่คาดไว้ เป็น “ความประหลาดใจ” ในเรื่องขนาด ค่าเฉลี่ยของมันเมื่อรู้อดีตเป็นศูนย์ เพราะ $\mathbb E[z_t^2]=1$ จากนั้นแทน $\sigma^2=\epsilon^2-v$ ลงในสมการ GARCH เพื่อให้เหลือแต่ $\epsilon^2$ แล้วอ่านค่า $\phi$, $\theta$ ออกมาใช้สูตร ACF

\[ \begin{aligned} v_t&:=\epsilon_t^2-\sigma_t^2=\sigma_t^2(z_t^2-1),\\ \epsilon_t^2-v_t&=\omega+\alpha\epsilon_{t-1}^2\\ &\quad+\beta(\epsilon_{t-1}^2-v_{t-1}),\\ \epsilon_t^2&=\omega+(\alpha+\beta)\epsilon_{t-1}^2\\ &\quad+v_t-\beta v_{t-1},\\ \phi&=0.98,\quad\theta=-0.89,\\ 1+\phi\theta&=1-0.8722=0.1278,\\ 1+2\phi\theta+\theta^2&=1-1.7444+0.7921\\ &=0.0477,\\ \rho_1&=\frac{(1+\phi\theta)(\phi+\theta)}{1+2\phi\theta+\theta^2}\\ &=\frac{0.1278(0.09)}{0.0477}\\ &\approx0.2411,\\ \rho_k&=0.98\,\rho_{k-1},\\ \rho_{10}&=0.2411(0.98)^9\approx0.2010,\\ \rho_{20}&=0.2411(0.98)^{19}\approx0.1643. \end{aligned} \]

บรรทัดที่สามคือ ARMA(1,1) ที่มีข่าวกำลังสองเป็นอนุกรม ส่วน AR คือ $\phi=\alpha+\beta$ ส่วน MA คือ $\theta=-\beta$ และ $v_t$ ทำหน้าที่เป็น noise ค่าเฉลี่ยระยะยาวคือ $\omega/(1-0.98)=V$ แบบเดียวกับ $c/(1-\phi)$ เราใช้สูตร ACF ของ ARMA(1,1) ได้ตรง ๆ เพราะ $v_t$ ไม่สัมพันธ์ข้ามวัน แม้ขนาดของมันจะขึ้นกับ $\sigma_t$ ก็ตาม ถ้าเขียนด้วย $\alpha$, $\beta$ จะได้ $\rho_1=\alpha(1-\alpha\beta-\beta^2)/(1-2\alpha\beta-\beta^2)$

ตัวเลขบอกอะไร lag 1 อยู่ที่ 0.24 เท่านั้น เพราะก้อน MA ที่ติดลบดึงลง แต่หลังจากนั้นจางช้ามาก ที่อัตรา 0.98 ต่อ lag ยังเหลือ 0.16 ที่ lag 20 นี่คือ volatility clustering (วันแรงเกาะกลุ่มกัน) ในรูปที่วัดได้ด้วย ACF AR(1) ธรรมดาทำรูปแบบนี้ไม่ได้ เพราะ ACF ของ AR(1) คือ $\phi^k$ ถ้าจะให้จางช้าที่ 0.98 ค่าที่ lag 1 ก็ต้องสูงถึง 0.98 ด้วย สูตรนี้ใช้ได้เมื่อกำลังสี่ของข่าวมีค่าเฉลี่ยจำกัด ขั้นถัดไปจะตรวจเงื่อนไขนี้

ข้อควรรู้จากข้อมูลจริง: เมื่อฟิต GARCH(1,1) กับดัชนีหุ้น แล้วบังคับให้ kurtosis ของแบบจำลองตรงกับข้อมูล ACF ของข่าวกำลังสองที่แบบจำลองทำนายมักสูงกว่าที่วัดได้ และความจำยาวเกินไปเล็กน้อย GARCH จับลักษณะประจำตัวของผลตอบแทนจริง (stylized facts) ได้หลายข้อ แต่ไม่ครบ

ขั้นที่ 9 — หางอ้วนที่ GARCH สร้างขึ้นเอง

ขั้นนี้ตอบคำถามที่ดูขัดกัน $z_t$ เป็น Normal ทุกวัน แต่ถ้าเก็บผลตอบแทนทั้งปีมาวาด histogram หางกลับหนากว่า Normal ทำไม เพราะผลตอบแทนทั้งปีคือส่วนผสมของ Normal หลายตัวที่กว้างไม่เท่ากัน วันสงบให้ Normal แคบ วันปั่นป่วนให้ Normal กว้าง ความหนาของหางวัดด้วย kurtosis $K=\mathbb E[r^4]/(\operatorname{Var}r)^2$ (เมื่อค่าเฉลี่ยเป็นศูนย์) Normal มี $K=3$

ลองตัวอย่างเล็กก่อน ครึ่งหนึ่งของวันมี $\sigma=1$ อีกครึ่งมี $\sigma=2$ ทั้งสองกลุ่มมีค่าเฉลี่ยศูนย์ variance รวมจึงเป็นค่าเฉลี่ยของ variance แต่ละกลุ่ม ตาม law of total variance ส่วนกำลังสี่ใช้ $\mathbb E[r^4]=3\sigma^4$ ของ Normal ที่ SD $\sigma$ ซึ่งมาจาก $\mathbb E[z^4]=3$ ของ Normal มาตรฐาน (หาได้จาก moment generating function) กลุ่ม $\sigma=2$ จึงมี $\sigma^2=4$ และ $\sigma^4=16$

\[ \begin{aligned} \operatorname{Var}&=\tfrac12(1)+\tfrac12(4)=2.5,\\ \mathbb E[r^4]&=\tfrac12(3)+\tfrac12(3\times16)=25.5,\\ K_{\rm mix}&=25.5/2.5^2=4.08. \end{aligned} \]

ได้ 4.08 มากกว่า 3 ทั้งที่แต่ละกลุ่มเป็น Normal แท้ GARCH ทำแบบเดียวกัน แต่ $\sigma_t$ เปลี่ยนไปเรื่อย ๆ ทุกวัน ไม่ได้มีแค่สองค่า เราต้องการ $\mathbb E[\sigma^4]$ เพราะ $\mathbb E[\epsilon^4]=3\mathbb E[\sigma^4]$

วิธีหาคือเขียนสมการ GARCH ใหม่ด้วย $\epsilon_{t-1}^2=z_{t-1}^2\sigma_{t-1}^2$ เป็น $\sigma_t^2=\omega+(\alpha z_{t-1}^2+\beta)\sigma_{t-1}^2$ ยกกำลังสองทั้งสองข้าง แล้วหาค่าเฉลี่ย ใช้ stationarity (การแจกแจงไม่เปลี่ยนตามเวลา) บังคับให้ $\mathbb E[\sigma^4]$ ของวันนี้กับเมื่อวานเท่ากัน สุดท้ายแทน $\omega=V(1-p)$ โดย $p=\alpha+\beta$ ซึ่งมาจากสูตรระดับปกติในขั้นที่ 4

\[ \begin{aligned} c_4&:=\mathbb E[(\alpha z^2+\beta)^2]\\ &=3\alpha^2+2\alpha\beta+\beta^2\\ &=0.0243+0.1602+0.7921\\ &=0.9766,\\ \mathbb E[\sigma^4]&=\omega^2+2\omega pV+c_4\,\mathbb E[\sigma^4],\\ \mathbb E[\sigma^4](1-c_4)&=V^2(1-p)^2\\ &\quad+2pV^2(1-p)\\ &=V^2(1-p^2),\\ K&=\frac{3\,\mathbb E[\sigma^4]}{V^2}=\frac{3(1-p^2)}{1-c_4}\\ &=\frac{3(1-0.98^2)}{1-0.9766}\\ &=\frac{3(0.0396)}{0.0234}=\frac{0.1188}{0.0234}\\ &\approx5.08. \end{aligned} \]

ที่มาของแต่ละบรรทัด $c_4$ ได้จากการกาง $(\alpha z^2+\beta)^2=\alpha^2z^4+2\alpha\beta z^2+\beta^2$ แล้วใช้ $\mathbb E[z^4]=3$ กับ $\mathbb E[z^2]=1$ บรรทัด $\mathbb E[\sigma^4]$ ได้จากการกางกำลังสองของ $\omega+(\alpha z^2+\beta)\sigma^2$ ก้อนกลาง $2\omega(\alpha z^2+\beta)\sigma^2$ มีค่าเฉลี่ย $2\omega pV$ เพราะ $z_{t-1}$ อิสระจาก $\sigma_{t-1}$ บรรทัดถัดมาแทน $\omega=V(1-p)$ แล้วดึง $V^2(1-p)$ ออกมา เหลือ $(1-p)+2p=1+p$ บรรทัด $K$ ใช้ $\mathbb E[\epsilon^4]=\mathbb E[\sigma^4]\,\mathbb E[z^4]=3\mathbb E[\sigma^4]$ และ variance ของข่าวคือ $V$

เงื่อนไขที่ต้องระวังคือ $c_4\lt1$ ถ้าไม่ผ่าน $\mathbb E[\sigma^4]$ ไม่มีค่าจำกัด และ kurtosis เป็นอนันต์ แบบจำลองนี้ได้ $c_4=0.9766$ จึงใช้สูตรได้ ผลคือ kurtosis 5.08 ทั้งที่ $z_t$ เป็น Normal แท้ และทุกค่าที่ $\alpha\gt0$ ให้ kurtosis มากกว่า 3 เสมอ เพราะ $c_4-p^2=2\alpha^2\gt0$ ตัวส่วน $1-c_4$ จึงเล็กกว่าตัวเศษ $1-p^2$

ข้อมูลจริงหางหนากว่านี้อีก ผลตอบแทนรายวันของ SPY (กองทุนที่ซื้อขายเหมือนหุ้นและวิ่งตามดัชนี S&P 500) ปี 2001–2017 มี kurtosis ที่วัดได้ราว 11.4 ถ้าหารผลตอบแทนแต่ละวันด้วย $\sigma_t$ ที่ GARCH(1,1) พยากรณ์ไว้ ผลที่ได้ใกล้ Normal ขึ้นมาก ระยะห่างจาก Normal ที่วัดด้วยสถิติ Kolmogorov–Smirnov (ระยะห่างมากที่สุดระหว่าง CDF ของข้อมูลกับ CDF ของ Normal) ลดจาก 0.098 เหลือ 0.040 GARCH จึงอธิบายหางหนาได้ส่วนใหญ่ แต่ไม่หมด

ใช้ไม้บรรทัดนี้กับวันร่วงจริง ถ้า $\sigma$ คงที่ 1% วัน −4% คือ $-0.04/0.01=-4$ SD Normal ให้โอกาส $\Phi(-4)=3.17\times10^{-5}$ ต่อวัน ($\Phi$ คือ CDF ของ Normal มาตรฐาน) ถ้าแต่ละวันอิสระกัน ต้องรอเฉลี่ย $1/(3.17\times10^{-5}\times252)\approx125$ ปีกว่าจะเจอสักครั้ง

แต่ถ้าวันถัดไปร่วง −4% อีกครั้ง หลังจาก GARCH พยากรณ์ $\sigma_t=1.532\%$ ไว้แล้ว วันนั้นเป็นแค่ $-0.04/0.01532=-2.61$ SD ไม้บรรทัดที่ถูกคือ $\sigma_t$ ที่พยากรณ์ก่อนวันนั้น ไม่ใช่ค่าที่อัปเดตหลังเห็นข่าวแล้ว Black Monday 19 ตุลาคม 1987 ที่ GBM มองว่าเป็น −18.2 SD (ข้อจำกัดของ GBM กับราคาหุ้น) ก็ต้องเทียบกับ $\sigma_t$ ที่พยากรณ์ไว้ก่อนวันนั้น จึงจะประเมิน GARCH ได้ยุติธรรม

ขั้นที่ 10 — ข่าวร้ายกับข่าวดีไม่เท่ากัน: GJR-GARCH

สมการ GARCH ใช้ $\epsilon^2$ ทิศของข่าวจึงหายไป วันร่วง 4% กับวันขึ้น 4% ดัน variance เท่ากัน แต่ในหุ้น วันลบมักดันความผันผวนแรงกว่าวันบวกขนาดเท่ากัน ปรากฏการณ์นี้เรียกว่า leverage effect แบบจำลอง GJR-GARCH (ตั้งชื่อตามผู้เสนอสามคน Glosten, Jagannathan และ Runkle) แก้ด้วยการให้ข่าวสองฝั่งมีน้ำหนักต่างกัน $\alpha^+$ สำหรับข่าวบวก และ $\alpha^-$ สำหรับข่าวลบ

ตัวเลขข้างล่างเป็นค่าสมมติ $\alpha^+=0.03$, $\alpha^-=0.15$ และ $\beta=0.89$ เท่าเดิม เลือกให้ความจำเฉลี่ยเท่าเดิม เพราะข่าวบวกและข่าวลบเกิดอย่างละครึ่ง: $0.03/2+0.15/2+0.89=0.98$ แล้วเทียบสองกรณี คือหลังวันร่วง −4% กับหลังวันขึ้น +4% variance เมื่อวานยังเป็น 0.0001 ก้อนความจำ $0.89(0.0001)=0.000089$ จึงเท่ากันทั้งสองกรณี

\[ \begin{aligned} \epsilon_{t-1}\ge0:&\quad\sigma_t^2=\omega+\alpha^+\epsilon_{t-1}^2+\beta\sigma_{t-1}^2,\\ \epsilon_{t-1}\lt0:&\quad\sigma_t^2=\omega+\alpha^-\epsilon_{t-1}^2+\beta\sigma_{t-1}^2,\\ -4\%:&\quad\sigma_t^2=1.8\times10^{-6}\\ &\quad+0.15(0.0016)+0.000089\\ &\quad=0.0003308,\\ &\quad\sigma_t\approx1.819\%,\\ +4\%:&\quad\sigma_t^2=1.8\times10^{-6}\\ &\quad+0.03(0.0016)+0.000089\\ &\quad=0.0001388,\\ &\quad\sigma_t\approx1.178\%. \end{aligned} \]

GARCH ปกติให้ 1.532% ทั้งสองกรณี GJR ให้ 1.819% หลังวันร่วง แต่แค่ 1.178% หลังวันขึ้น ถ้าตลาดจริงเป็นแบบ GJR แต่โต๊ะใช้ GARCH ปกติ ความผันผวนหลังวันร่วงจะต่ำไป $1.819-1.532=0.29$ จุดเปอร์เซ็นต์ และวันหลังวันร่วงคือวันที่ต้องการตัวเลขที่ถูกที่สุด อย่างไรก็ตาม หลักฐานจากข้อมูลช่วงหลังบอกว่าความไม่สมมาตรนี้อ่อนลง จึงควรทดสอบกับข้อมูลที่จะใช้จริงก่อนเลือกแบบจำลอง

ขั้นที่ 11 — α กับ β มาจากไหน: maximum likelihood

ตลอดหน้านี้เราใช้ $\omega$, $\alpha$, $\beta$ ที่มีคนให้มา ขั้นนี้ดูว่าได้มาอย่างไร หลักที่ใช้คือ maximum likelihood: เลือก parameter ที่ทำให้ข้อมูลที่เห็นจริงมีโอกาสเกิดสูงที่สุดภายใต้แบบจำลอง

ทำได้เพราะเหตุนี้ ถ้าเลือก $\omega$, $\alpha$, $\beta$ มาชุดหนึ่ง สมการ GARCH สร้าง $\sigma_t^2$ ของทุกวันจากข้อมูลผลตอบแทนย้อนหลังได้ทันที ถ้า $z_t$ เป็น Normal ผลตอบแทนแต่ละวันก็มี density Normal ที่ variance $\sigma_t^2$ เอา log ของ density ทุกวันมาบวกกัน ได้ log-likelihood $\ln L$ (บรรทัดแรก) แล้วให้ optimizer เชิงตัวเลข คือโปรแกรมที่ลองปรับ parameter ไปเรื่อย ๆ หาชุดที่ทำให้ $\ln L$ มากที่สุด บรรทัดท้ายลองชุดอื่นที่มีความจำ 0.98 เท่าเดิม เพื่อดูว่าความผันผวนหลังวันร่วงต่างกันแค่ไหน

\[ \begin{aligned} \ln L&=\sum_{t=1}^{T}\Big[-\tfrac12\ln(2\pi)-\tfrac12\ln\sigma_t^2\\ &\qquad-\frac{\epsilon_t^2}{2\sigma_t^2}\Big],\\ Q&:=\sum_{t=1}^{T}\Big[\ln\sigma_t^2+\frac{\epsilon_t^2}{\sigma_t^2}\Big]\\ &=-2\ln L-T\ln(2\pi),\\ \alpha=0.20,\ \beta=0.78:&\quad\sigma_t^2=1.8\times10^{-6}\\ &\quad+0.20(0.0016)+0.78(0.0001)\\ &\quad=3.998\times10^{-4},\\ &\quad\sigma_t=2.00\%. \end{aligned} \]

บรรทัด $Q$ คือ $\ln L$ ที่คูณ −2 แล้วตัดค่าคงที่ทิ้ง การหาค่าสูงสุดของ $\ln L$ จึงเท่ากับการหาค่าต่ำสุดของ $Q$ ใน $Q$ มีสองแรงดึงกัน ก้อน $\ln\sigma_t^2$ ลงโทษการตั้ง variance สูงเกินไป ก้อน $\epsilon_t^2/\sigma_t^2$ ลงโทษการตั้ง variance ต่ำเกินไปในวันที่ข่าวใหญ่ ชุด parameter ที่ดีที่สุดคือชุดที่สมดุลสองแรงนี้ได้ดีที่สุดตลอดช่วงข้อมูล

บรรทัดท้ายเตือนเรื่องหนึ่ง ชุด $\alpha=0.20$, $\beta=0.78$ มีความจำ $0.20+0.78=0.98$ เท่าเดิม จึงให้ระดับปกติและ half-life ของเส้นพยากรณ์เท่าเดิม แต่หลังวันร่วงให้ความผันผวน 2.00% แทน 1.53% ข้อมูลบอกผลรวม $\alpha+\beta$ ได้ชัดกว่าบอกว่าแบ่งเป็น $\alpha$ กับ $\beta$ อย่างไร คำพยากรณ์ระยะยาวจึงเชื่อถือได้มากกว่าคำพยากรณ์วันแรก

เงื่อนไข $\alpha+\beta\lt1$ ทำให้ variance เฉลี่ยมีค่าจำกัด ยังมีเงื่อนไขที่หลวมกว่า ซึ่งรับประกันแค่ว่าเส้นทางของ $\sigma_t^2$ มีการแจกแจงที่นิ่งในระยะยาว คือ $\mathbb E[\ln(\beta+\alpha z^2)]\lt0$ ที่มาคือ ถ้าไม่นับ $\omega$ variance แต่ละวันถูกคูณด้วยตัวคูณสุ่ม $\beta+\alpha z^2$ ถ้าค่าเฉลี่ยของ log ตัวคูณติดลบ ผลคูณยาว ๆ จะหดลงในระยะยาว ค่านี้หาด้วยการอินทิเกรตเชิงตัวเลข (โค้ดท้ายหน้า) แบบจำลองนี้ได้ −0.027 จึงผ่าน

EWMA ที่ $\lambda=0.94$ ได้ −0.003 และไม่มี $\omega$ คอยยกพื้น ถ้าใช้ EWMA เป็นกลไกที่สร้างข้อมูล เส้นทาง variance จึงหดเข้าศูนย์ในระยะยาวเกือบแน่นอน EWMA จึงเหมาะเป็นตัวกรองที่ใช้ประมาณความผันผวนจากข้อมูล ไม่ใช่แบบจำลองของตลาด

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

ดีใจที่ประมาณ $\alpha+\beta$ ได้เกือบ 1: ค่าแบบนี้มักเป็นสัญญาณเตือน ไม่ใช่ข่าวดี ที่ $\alpha+\beta=0.98$ half-life ของช่วงปั่นป่วนคือ 34.3 วัน แต่ถ้าได้ 0.999 half-life กลายเป็น $\ln0.5/\ln0.999=693$ วันทำการ หรือ $693/252=2.75$ ปี สาเหตุที่พบบ่อยคือข้อมูลคร่อมการเปลี่ยนระบอบ (regime) เช่นมีทั้งช่วงสงบและช่วงวิกฤตที่ระดับความผันผวนต่างกันมาก แบบจำลองอธิบายการกระโดดของระดับไม่ได้ จึงอธิบายด้วยความจำที่ยาวผิดปกติแทน ทางแก้คือประมาณแยกช่วง หรือใช้แบบจำลองที่สลับระบอบได้

ลืมถอดราก หรือใส่หน่วยผิด: ผลรวมสามก้อน 0.0002348 คือ variance ถ้าอ่านเป็นความผันผวนตรง ๆ จะได้ 0.02348% ต่อวัน ต่ำไป $1.532/0.02348\approx65$ เท่า ค่าที่ถูกคือ $\sqrt{0.0002348}=0.01532=1.532\%$ ถ้าใส่ −4 แทน −0.04 ข่าวกำลังสองจะเป็น $(-4)^2=16$ แทน $(-0.04)^2=0.0016$ เพี้ยน 10,000 เท่า ถ้าแปลงเป็นรายปีด้วย 252 แทน $\sqrt{252}$ จะได้ $0.9487\%\times252=239\%$ แทน $0.9487\%\times15.87=15.06\%$ และ $\omega$ มีหน่วยทศนิยม² ต่อวัน จึงเอาไปใช้กับข้อมูลรายสัปดาห์ไม่ได้

คูณรากของเวลากับความผันผวนค่าเดียว: SD ของผลตอบแทน 10 วันที่ถูกคือผลรวม variance ที่พยากรณ์ไว้ แล้วถอดราก ได้ 4.716% ทางลัด $\sqrt{10}\times1.5323\%=4.846\%$ สูงไป ทางลัด $\sqrt{10}\times0.9487\%=3.000\%$ ต่ำไป $1-3.000/4.716=36\%$ ความผิดแบบหลังอันตรายกว่า เพราะประเมินความเสี่ยงต่ำในวันที่ตลาดยังปั่นป่วน

ลืมว่า VaR ข้างบนสมมติ Normal: ภายในแบบจำลองนี้ quantile $2.326\sigma_t$ ถูกต้อง เพราะ $z_t$ เป็น Normal หางหนาที่เห็นเมื่อรวมทุกวัน (ขั้นที่ 9) ไม่ได้ทำให้มันผิด ความเสี่ยงอยู่ที่ข้อมูลจริง ข่าวที่หารด้วยความผันผวนแล้ว $\epsilon_t/\sigma_t$ อาจยังมีหางหนากว่า Normal จึงต้องตรวจกับข้อมูลจริง และอาจเปลี่ยนไปใช้การแจกแจง Student-t ซึ่งหางหนากว่า อีกปัญหาหนึ่ง ถ้าทุกโต๊ะในตลาดใช้กฎเดียวกัน หลังวันร่วงทุกคนจะขายพร้อมกัน ตลาดก็ร่วงต่อ ความผันผวนขึ้นอีก ทุกคนต้องขายอีก วงจรนี้ไม่อยู่ในแบบจำลองเลย

ใช้ทำอะไรบนโต๊ะจริง

ระบบความเสี่ยงรายวันต้องการ $\sigma_t$ เป็นวัตถุดิบ GARCH และ EWMA คือแหล่งของ $\sigma_t$ ทั้งใน VaR และ expected shortfall (ขาดทุนเฉลี่ยในวันที่แย่กว่า VaR ดู VaR และ expected shortfall) และในกฎ volatility targeting ซึ่งถือเงินลงทุนเป็นสัดส่วนกลับกับ $\sigma_t$ คือความผันผวนขึ้นเป็นสองเท่า ก็ถือน้อยลงครึ่งหนึ่ง การลดพอร์ตหลังวันร่วงในหน้านี้คือกฎนั้นในรูปที่ง่ายที่สุด

ระบบความเสี่ยงขนาดใหญ่มักใช้ EWMA กับ factor จำนวนมาก (factor คือตัวขับเคลื่อนร่วมของหุ้นหลายตัว เช่นทั้งตลาด หรือกลุ่มอุตสาหกรรม) และมักเลือก half-life ยาว ตั้งแต่สามเดือนถึงสองปี ค่ายาวแบบนี้ให้ตัวเลขนิ่ง แต่ตอบสนองช้าเกินไปตอนวิกฤตเริ่ม จึงเติมตัวปรับระยะสั้นที่มี half-life 10 ถึง 20 วันทำการ (short-term volatility updating) เพื่อจับการพุ่งของความผันผวนให้ทัน

variance ที่พยากรณ์หลายวันใช้เป็นจุดอ้างอิงเทียบกับ implied volatility ตาม term structure (ความผันผวนที่ราคา option ในตลาดบอกเป็นนัย แยกตามอายุสัญญา) แต่ไม่ควรคาดว่าจะเท่ากัน เพราะราคา option รวมค่าตอบแทนที่คนขาย option เรียกเพื่อรับความเสี่ยงไว้ด้วย ถ้ามีข้อมูลระหว่างวัน realized volatility ที่คำนวณจากราคาทุก 5 นาที มักพยากรณ์ได้ดีกว่าการใช้ราคาปิดวันละจุด แต่ต้องระวังราคาที่เด้งไปมาระหว่างราคาเสนอซื้อกับราคาเสนอขาย (แบบจำลองของ Roll) ซึ่งทำให้ความผันผวนดูสูงเกินจริง

หลังฟิตแบบจำลองแล้ว งานจริงต้องตรวจสองอย่างด้วยการทดสอบ Ljung–Box (ทดสอบว่า ACF หลาย lag รวมกันต่างจากศูนย์ไหม) อย่างแรก ข่าวที่หารด้วยความผันผวนแล้ว $\epsilon_t/\sigma_t$ ต้องเป็น white noise คือไม่สัมพันธ์ข้ามวัน อย่างที่สอง กำลังสองของมันต้องไม่มีความจำเหลือ ถ้ายังเหลือ แปลว่าแบบจำลองยังจับวันแรงเกาะกลุ่มได้ไม่หมด

ใช้สูตรระดับปกติจากขั้นที่ 4 แปลงเป็นรายปีด้วย $\sqrt{252}=15.87$ และใช้ half-life ของความจำ $\alpha+\beta=0.95$ จากขั้นที่ 6

\[\begin{aligned}V&=\frac{\omega}{1-\alpha-\beta}=\frac{2\times10^{-6}}{0.05}=4\times10^{-5},\\\sqrt V&=0.6325\%\ \text{per day},\\15.87\times0.6325\%&=10.04\%\ \text{per year},\\h_{1/2}&=\frac{\ln0.5}{\ln0.95}=13.51\ \text{days}.\end{aligned}\]

สินทรัพย์นี้ลืมช่วงปั่นป่วนเร็วกว่าแบบจำลองในหน้านี้ $34.3/13.51=2.5$ เท่า

2. ต่อจากโจทย์เปิด เช้านี้มีตัวเลขสองชุด

  • GARCH ให้ variance วันนี้ 0.0002348 (ความผันผวน 1.532%) และเส้นพยากรณ์ในขั้นที่ 6 บอกว่าพรุ่งนี้คาดไว้ 1.523%
  • EWMA ที่ $\lambda=0.94$ ให้ variance วันนี้ 0.00019 (ความผันผวน 1.378% จากรูปแรกของหน้า)

สมมติว่าวันนี้ตลาดนิ่งสนิท ข่าว $\epsilon_t=0$ ความผันผวนของพรุ่งนี้ตาม GARCH และตาม EWMA เป็นเท่าไร และทำไม GARCH ถึงต่างจากค่าที่คาดไว้ 1.523%?

เฉลย

ใส่ข่าวศูนย์ลงในสมการของแต่ละวิธี

\[\begin{aligned}\sigma_{t+1}^2&=0.0000018+0.09(0)^2\\&\quad+0.89(0.0002348)\\&=0.000210772,\\\sigma_{t+1}&=\sqrt{0.000210772}=1.452\%,\\\sigma_{t+1,\rm EWMA}^2&=0.06(0)^2+0.94(0.00019)\\&=0.0001786,\\\sigma_{t+1,\rm EWMA}&=\sqrt{0.0001786}=1.336\%.\end{aligned}\]

GARCH ได้ 1.452% ต่ำกว่าค่าพยากรณ์ 1.523% เพราะตอนพยากรณ์ เราใส่ข่าวกำลังสองเฉลี่ยไว้ 0.0002348 แต่วันจริงไม่มีข่าวเลย ก้อนความจำ $\beta\sigma_t^2$ ยังค้างอยู่ ความผันผวนจึงไม่ร่วงลงไปที่ 0.905% แบบ ARCH(1) ในขั้นที่ 1 ส่วน EWMA ลดลงแค่ $1-1.336/1.378=3\%$ เพราะ EWMA ให้น้ำหนักข่าวใหม่แค่ $1-\lambda=6\%$

3. ตลาดหนึ่งมีวันสองแบบ 80% ของวันเป็นวันสงบที่ $\sigma=1$ อีก 20% เป็นวันปั่นป่วนที่ $\sigma=3$ ในแต่ละวันผลตอบแทนเป็น Normal ที่ค่าเฉลี่ยศูนย์ ถ้าเก็บผลตอบแทนทุกวันมารวมกัน kurtosis เป็นเท่าไร?

เฉลย

ทำแบบเดียวกับตัวอย่างครึ่งต่อครึ่งในขั้นที่ 9 variance รวมคือค่าเฉลี่ยของ $\sigma^2$ และกำลังสี่เฉลี่ยคือค่าเฉลี่ยของ $3\sigma^4$

function checkGarch({omega, alpha, beta}) {
  if (![omega, alpha, beta].every(Number.isFinite)) throw new TypeError('omega, alpha and beta must be finite');
  if (!(omega > 0) || alpha < 0 || beta < 0) throw new RangeError('Need omega > 0, alpha >= 0 and beta >= 0');
  if (!(alpha + beta < 1)) throw new RangeError('Need alpha + beta < 1 for a long-run variance');
}
// Long-run variance from "the same on average every day": V = omega + (alpha + beta) V.
function longRun(model) {
  checkGarch(model);
  const variance = model.omega / (1 - model.alpha - model.beta);
  return {variance, daily: Math.sqrt(variance), annual: Math.sqrt(252 * variance)};
}
function nextVariance(model, shock, variance) {
  checkGarch(model);
  if (!Number.isFinite(shock) || !(variance > 0)) throw new RangeError('Need a finite shock and a positive variance');
  return model.omega + model.alpha * shock * shock + model.beta * variance;
}
// Unknown future shocks are replaced by their mean square, which is the forecast variance itself.
function forecastPath(model, today, horizon) {
  checkGarch(model);
  if (!(today > 0) || !Number.isInteger(horizon) || horizon < 0) throw new RangeError('Need a positive variance and a whole horizon');
  const f = [today];
  for (let h = 1; h <= horizon; h++) f.push(model.omega + (model.alpha + model.beta) * f[h - 1]);
  return f;
}
function halfLife(persistence) {
  if (!(persistence > 0 && persistence < 1)) throw new RangeError('Need 0 < persistence < 1');
  return Math.log(0.5) / Math.log(persistence);
}
// After the crash every day moves exactly 1%: GARCH, EWMA (lambda 0.94) and a 20-day window.
function calmAfterCrash(model, days) {
  let g = nextVariance(model, -0.04, 1e-4), e = 0.06 * 0.0016 + 0.94 * 1e-4;
  const out = [];
  for (let d = 0; d <= days; d++) {
    out.push({d, garch: Math.sqrt(g), ewma: Math.sqrt(e), window: d < 20 ? Math.sqrt((19e-4 + 0.0016) / 20) : 0.01});
    g = model.omega + model.alpha * 1e-4 + model.beta * g;
    e = 0.06 * 1e-4 + 0.94 * e;
  }
  return out;
}
// Standard Normal CDF: 0.5 plus the density integrated from 0 to z by Simpson's rule.
function normalCdf(z) {
  if (!Number.isFinite(z)) throw new TypeError('z must be finite');
  const steps = 2000, w = z / steps, f = t => Math.exp(-t * t / 2) / Math.sqrt(2 * Math.PI);
  let s = f(0) + f(z);
  for (let i = 1; i < steps; i++) s += (i % 2 ? 4 : 2) * f(i * w);
  return 0.5 + s * w / 3;
}
function valueAtRisk(z, sigma, notional) {
  if (![z, sigma, notional].every(v => Number.isFinite(v) && v > 0)) throw new RangeError('Need positive z, sigma and notional');
  return z * sigma * notional;
}
// Kurtosis of GARCH(1,1) with Normal z: needs E[(alpha z^2 + beta)^2] = 3a^2 + 2ab + b^2 < 1.
function kurtosis({alpha, beta, omega}) {
  checkGarch({alpha, beta, omega});
  const p = alpha + beta, c4 = 3 * alpha * alpha + 2 * alpha * beta + beta * beta;
  if (!(c4 < 1)) throw new RangeError('Fourth moment is infinite: kurtosis undefined');
  return {c4, kurtosis: 3 * (1 - p * p) / (1 - c4)};
}
// Squared shocks follow ARMA(1,1) with phi = alpha + beta and theta = -beta.
function squaredAcf({alpha, beta, omega}, lags) {
  kurtosis({alpha, beta, omega});
  const phi = alpha + beta, theta = -beta;
  const rho = [(1 + phi * theta) * (phi + theta) / (1 + 2 * phi * theta + theta * theta)];
  for (let k = 2; k <= lags; k++) rho.push(phi * rho[k - 2]);
  return rho;
}
// E[log(beta + alpha z^2)] by Simpson's rule over z in (-10, 10): negative means a stationary variance path.
function logGrowth(alpha, beta) {
  const steps = 20000, a = -10, w = 20 / steps;
  let s = 0;
  for (let i = 0; i <= steps; i++) {
    const z = a + i * w, weight = i === 0 || i === steps ? 1 : (i % 2 ? 4 : 2);
    s += weight * Math.log(beta + alpha * z * z) * Math.exp(-z * z / 2) / Math.sqrt(2 * Math.PI);
  }
  return s * w / 3;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ARCH(1) ให้ variance ขึ้นกับข่าวกำลังสองของเมื่อวานเท่านั้น จึงลืมเร็ว GARCH(1,1) เติม variance เดิมเข้าไป กางออกแล้วคือค่าเฉลี่ยถ่วงของข่าวกำลังสองย้อนหลังด้วยน้ำหนัก $\alpha\beta^k$ บวกพื้น EWMA คือกรณี $\omega=0$ และ $\alpha+\beta=1$
  • ระดับปกติคือ $V=\omega/(1-\alpha-\beta)$ ถอดรากได้ความผันผวน 0.9487% ต่อวัน แปลงเป็นรายปีด้วยการคูณ $\sqrt{252}$ ได้ 15.06% ไม่ใช่คูณ 252
  • หลังวันร่วง 4% ความผันผวนวันนี้คือ 1.532% ส่วนที่ variance เกินระดับปกติจะเหลือ $(\alpha+\beta)^h$ เท่าใน $h$ วัน จึงมี half-life 34.3 วัน ความเสี่ยงหลายวันได้จากผลรวม variance ที่พยากรณ์ไว้ (10 วันได้ 4.716%) ไม่ใช่ $\sqrt{10}$ คูณความผันผวนค่าเดียว
  • VaR \$3.56 ล้านเกินเพดาน \$3 ล้าน จึงลดพอร์ต 15.84% เหลือ \$84.16 ล้าน เส้นพยากรณ์บอกว่ากลับเต็มขนาดได้ในวันที่ 32 แต่วันกลับจริงต้องตัดสินจากข้อมูลที่อัปเดตทุกเช้า
  • GARCH คือ ARMA(1,1) ของข่าวกำลังสอง จึงสร้าง ACF ของ $\epsilon^2$ ที่จางช้า และสร้าง kurtosis 5.08 ได้จาก $z_t$ ที่เป็น Normal แต่ยังจับความไม่สมมาตรของข่าวดีข่าวร้าย การเปลี่ยนระบอบ และหางที่หนากว่านั้นไม่ได้

บทถัดไปเริ่มที่ VaR และ expected shortfall ซึ่งใช้ $\sigma_t$ จากหน้านี้เป็นวัตถุดิบ แล้วถามต่อว่า VaR วัดอะไรได้และวัดอะไรไม่ได้ expected shortfall แก้อะไร และตรวจย้อนหลังอย่างไรว่าแบบจำลองความเสี่ยงยังใช้ได้ ภาพรวมของทั้งบทอยู่ที่หน้าแนะนำบท time series
