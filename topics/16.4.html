16.4 Autoregressive Conditional Heteroskedasticity (ARCH) and Generalized ARCH (GARCH) Volatility Forecasting

ให้ความเสี่ยงวันนี้เรียนรู้จากแรงกระแทกเมื่อวาน

เมื่อวานเกิดการแกว่งใหญ่ แต่ model พยากรณ์การแกว่งวันนี้ต่ำ; forecast วันนี้ควรยกขึ้นทันทีและค่อยลดลงช้าหรือไม่?

เฉลย: ควรให้ shock ล่าสุดดัน forecast ขึ้น แล้วปล่อยให้มัน decay ตามข้อมูล. ARCH และ GARCH เปลี่ยน shock เก่าเป็นกติกาขนาดความเสี่ยงที่ audit ได้; volatility clustering เหมือนพื้นยังสั่นหลังรถบรรทุกผ่านไป.

ที่มาที่ไป: ความผันผวนที่ไม่ยอมอยู่นิ่ง

ทุกแบบจำลองก่อนหน้านี้สมมติว่าความผันผวนคงที่ ซึ่งใครที่เคยดูตลาดจริงจะรู้ทันทีว่าไม่จริง วันที่เหวี่ยงแรงมักตามด้วยวันที่เหวี่ยงแรง และช่วงสงบก็ยาวเป็นเดือน

ข้อจำกัดที่ต้องใส่ใน model governance

GARCH symmetric ให้ข่าวบวกและลบขนาดเท่ากันดัน volatility เท่ากัน ซึ่งไม่จริงกับ equity leverage effect; ใช้ Glosten–Jagannathan–Runkle (GJR) GARCH หรือ exponential GARCH (EGARCH) เมื่อต้องการ asymmetry. ถ้า alpha+beta ≥ 1 ให้สงสัย regime change จาก 2008 หรือ coronavirus disease (COVID) ก่อนเรียกว่า long memory. ห้ามใส่ −4 แทน −0.04 เพราะ squared shock จะผิด 10,000 เท่า และอย่าให้ทุก desk ลดพอร์ตพร้อมกันโดยไม่มี liquidity/stress overlay

›ตรวจทุกตัวเลขหลักของ GARCHเปิดโค้ด
import numpy as np
omega,alpha,beta=1.8e-6,.09,.89
eps,sigprev=-.04,.01
V=omega/(1-alpha-beta)
v=omega+alpha*eps**2+beta*sigprev**2
hl=np.log(.5)/np.log(alpha+beta)
assert abs(V-9e-5)<1e-12
assert abs(v-.0002348)<1e-10
assert abs(np.sqrt(v)-.015323)<1e-5
assert abs(hl-34.31)<.02
var=2.326*np.sqrt(v)*100_000_000
assert abs(var-3_563_000)<5_000
โค้ดทำงานบน proportion และ USD notional; production ต้อง backtest VaR, ใช้ rolling/walk-forward fit, ตรวจ residual autocorrelation function (ACF) และเลือก innovation distribution ให้ตรง tail

ก่อนไปต่อ — บทความเสี่ยง

GARCH ให้ conditional volatility และเส้นทาง forecast แต่ VaR ยังเป็นเพียง quantile ภายใต้สมมติฐาน distribution, horizon และ liquidity ที่ระบุ; ก่อน deploy ให้ตรวจ autocorrelation function (ACF) ของ standardized residuals ด้วย หัวข้อถัดไปเรื่อง risk measurement จะเติม Expected Shortfall, backtest และการตัดสินใจขนาดสถานะที่ไม่พึ่งเลขเดียว

สรุปที่ใช้ได้จริง

  • GARCH(1,1) แยก floor, shock response และ memory; stationary เมื่อ omega>0, alpha,beta≥0 และ alpha+beta<1
  • คำนวณ variance ในหน่วย proportion² ก่อนถอดรากและ annualise ด้วย sqrt(252); persistence 0.98 ให้ half-life 34.3 วัน
  • conditional volatility เปลี่ยนเป็น VaR และ notional rule ได้ แต่ต้องประกาศ confidence, horizon, distribution, units และ limit
  • symmetric GARCH พลาด leverage effect, regime change และ liquidity feedback; ใช้ asymmetric model และ stress overlay เมื่อจำเป็น
