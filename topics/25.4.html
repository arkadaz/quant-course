25.4 Realized Volatility from High-Frequency Data

ราคาระหว่างวันช่วยให้วัดความผันผวนได้แม่นขึ้น แต่ไม่ช่วยให้รู้ผลตอบแทนคาดหวังเลย และถ้าเก็บราคาถี่เกินไป ความคลาดเคลื่อนของราคาที่บันทึกจะดันความผันผวนที่วัดได้ให้สูงเกินจริง

ทีมลงทุนทีมหนึ่งอยากรู้สองเรื่องของหุ้นตัวหนึ่ง เรื่องแรกคือหุ้นนี้คาดว่าจะขึ้นปีละเท่าไร (ผลตอบแทนคาดหวัง) เรื่องที่สองคือราคาแกว่งแรงแค่ไหน (ความผันผวน) ตอนนี้ทีมมีราคาปิดของทุกวันย้อนหลังหนึ่งปี และกำลังคิดจะซื้อข้อมูลราคาทุก 5 นาทีของปีเดียวกันมาใช้แทน

ของที่รู้ (ตัวเลขสมมติ):

  • ผลตอบแทนคาดหวังจริง $\mu=8\%$ ต่อปี หน้านี้เรียกตัวเลขนี้ว่า drift คือระยะที่ log ของราคาขยับขึ้นโดยเฉลี่ยในหนึ่งปี
  • ความผันผวนจริง $\sigma=16\%$ ต่อปี คือ SD (standard deviation) ของผลตอบแทนในหนึ่งปี
  • ข้อมูลยาวหนึ่งปี ตลาดหุ้นสหรัฐเปิดปีละ 252 วันทำการ ราคาปิดรายวันจึงให้ผลตอบแทน 252 ตัว
  • ตลาดเปิดวันละ 390 นาที (9:30 ถึง 16:00 น.) ราคาทุก 5 นาทีจึงให้ $390/5=78$ ช่วงต่อวัน คือข้อมูลมากขึ้น 78 เท่า

ทีมไม่เห็น $\mu$ กับ $\sigma$ ตัวจริง ต้องประมาณจากข้อมูล หน้านี้สมมติค่าจริงไว้ก่อน เพื่อจะคำนวณได้ว่าวิธีวัดแต่ละแบบพลาดจากค่าจริงได้แค่ไหน

คนหนึ่งในทีมให้เหตุผลว่า ความแม่นโตตามรากที่สองของจำนวนข้อมูล ข้อมูลมากขึ้น 78 เท่า จึงแม่นขึ้น $\sqrt{78}=8.83$ เท่า เขาสรุปว่า “เราจะรู้ทั้งผลตอบแทนคาดหวังและความผันผวนแม่นขึ้นเกือบ 9 เท่า” เขาพูดถูกไหม และถ้าซื้อข้อมูลทุก 1 นาทีแทน จะดีกว่าอีกไหม

ลองตอบก่อนเปิดเฉลย

ถูกครึ่งเดียว หน้านี้จะคำนวณทุกตัวเลขด้านล่างให้ดูทีละขั้น

  • ความผันผวน: แม่นขึ้นจริง 8.83 เท่า ถ้าใช้ราคาปิดรายวัน ค่าที่วัดได้จะพลาดราว ±0.713 จุดเปอร์เซ็นต์ คือได้ราว 16% ± 0.713% ถ้าใช้ราคาทุก 5 นาที จะพลาดเหลือ ±0.081 จุด ซึ่งก็คือ $0.713/8.83=0.081$
  • ผลตอบแทนคาดหวัง: ไม่แม่นขึ้นเลย SE (standard error คือ SD ของค่าที่ประมาณได้) ยังเป็น $\sigma=16$ จุดเปอร์เซ็นต์ ไม่ว่าจะใช้ข้อมูลรายวันหรือทุก 5 นาที ค่า t คือค่าประมาณหารด้วย SE จึงได้ $t=8/16=0.5$ ค่า t ที่ 2 เป็นระดับที่คนทั่วไปเริ่มเชื่อว่าไม่ใช่โชค แต่ค่า t โตได้ทางเดียวคือมีข้อมูลหลายปี และโตตามรากที่สองของจำนวนปี $T$ คือ $t=0.5\sqrt T$ ตั้งให้เท่ากับ 2 ได้ $T=(2/0.5)^2=16$ ปี
  • ข้อมูลทุก 1 นาที: แย่กว่า เพราะราคาที่บันทึกเด้งไปมาระหว่างราคาที่มีคนรอซื้อ (bid) กับราคาที่มีคนรอขาย (ask) ในหุ้น \$50 ตัวอย่างจากหน้า แบบจำลองของ Roll สองราคานี้ห่างกัน 2.4 เซนต์ การเด้งนี้ทำให้ความผันผวนที่วัดทุก 1 นาทีสูงเกินจริง 20% ความถี่ที่ความผิดรวมต่ำที่สุดอยู่ราว 4 ถึง 5 นาที

ภาพรวมก่อนลงสูตร

ความผันผวนของหุ้นไม่คงที่ บางสัปดาห์ราคาแกว่งแรง บางสัปดาห์นิ่ง ทีมที่คุมความเสี่ยงจึงอยากรู้ความผันผวนของ “วันนี้” ไม่ใช่ค่าเฉลี่ยของทั้งปี ทางหนึ่งคือใช้แบบจำลองอย่าง GARCH ซึ่งเดาความผันผวนที่มองไม่เห็นจากผลตอบแทนรายวันย้อนหลัง อีกทางคือวัดตรง ๆ จากราคาระหว่างวัน

วิธีวัดตรง ๆ ทำแบบนี้ ซอยหนึ่งวันเป็น $N$ ช่วงสั้น ๆ เช่นช่วงละ 5 นาที ให้ $r_j$ คือการขยับของราคาในช่วงที่ $j$ แล้วยกกำลังสองทุกช่วงมาบวกกัน

\[\mathrm{RV}=r_1^2+r_2^2+\cdots+r_N^2.\]

ผลรวมนี้เรียกว่า realized variance รากที่สองของมันเรียกว่า realized volatility ทั้งสองย่อว่า RV วิธีนี้ทำได้เพราะทุกวันนี้ราคาของทุก tick (การซื้อขายแต่ละครั้งที่ถูกบันทึก) หาซื้อได้ทั่วไป และไม่ต้องมีแบบจำลองเลย

ทำไมผลรวมกำลังสองจึงเป็น variance ของทั้งวัน: การขยับของทั้งวันคือ $r_1+r_2+\cdots+r_N$ การขยับย่อยอิสระกัน variance ของผลรวมจึงเท่ากับผลรวมของ variance ย่อย คือ $\operatorname{Var}(r_1)+\cdots+\operatorname{Var}(r_N)$ ในช่วงสั้น ๆ ค่าเฉลี่ยของ $r_j$ แทบเป็นศูนย์ $r_j^2$ หนึ่งตัวจึงเป็นตัวอย่างหนึ่งตัวของ $\operatorname{Var}(r_j)$

คำถามของหน้านี้คือ ข้อมูลที่ถี่ขึ้นช่วยอะไรได้บ้าง คำตอบมีสามข้อ

  • ผลตอบแทนคาดหวังไม่แม่นขึ้นเลย ไม่ว่าจะซอยละเอียดแค่ไหน เพราะเมื่อบวกการขยับย่อยทุกช่วงเข้าด้วยกัน จุดตรงกลางหักกันหมด เหลือแค่ราคาปลายปีลบราคาต้นปี
  • variance แม่นขึ้น ตามรากที่สองของจำนวนช่วง เพราะทุกช่วงให้ตัวอย่างใหม่ของการแกว่งหนึ่งตัว
  • แต่ถี่เกินไปก็ผิด เพราะราคาที่บันทึกไม่ใช่ราคาจริงพอดี มันคลาดเคลื่อนเล็กน้อยทุกครั้ง แบบที่หน้า แบบจำลองของ Roll อธิบาย ความคลาดเคลื่อนนี้ถูกนับซ้ำทุกช่วง ยิ่งซอยถี่ RV ยิ่งสูงเกินจริง ความถี่ที่ดีที่สุดจึงอยู่ตรงกลาง

รูปด้านล่างแสดงข้อสามในภาพเดียว โดยใช้หุ้น \$50 ตัวอย่างจากหน้าแบบจำลองของ Roll แกนนอนคือความยาวของแต่ละช่วงเป็นนาที แกนตั้งคือ RV ของหนึ่งวัน คิดเป็นเปอร์เซ็นต์ของ variance จริงของวันนั้น ถ้า RV วัดได้ตรงเป๊ะ ค่าจะอยู่ที่ 100% เส้นสีส้มคือค่าเฉลี่ยของ RV ถ้าวัดซ้ำหลายวัน แถบฟ้าคือขนาดที่ RV แกว่งจากวันหนึ่งไปอีกวัน

ขั้นที่ 1 — แบบจำลองและตัวประมาณสองตัว

ก่อนจะเทียบราคาปิดรายวันกับราคาทุก 5 นาที ต้องตกลงกันก่อนสองเรื่อง คือราคาเดินอย่างไร และค่าประมาณสองตัวคิดจากข้อมูลอย่างไร ขั้นนี้เป็นนิยามล้วน ๆ ยังไม่มีอะไรต้องพิสูจน์

  • ราคาเดินอย่างไร: ให้ $p$ คือ log ของราคา ในเวลาสั้น ๆ $dt$ ค่า $p$ ขยับไป $dp$ ซึ่งมีสองส่วน ส่วนแรกคือ drift คงที่ $\mu\,dt$ ส่วนที่สองคือการขยับแบบสุ่ม $\sigma\,dW$ โดย $W$ คือ Brownian motion แบบเดียวกับใน geometric Brownian motion
  • ข้อมูลหน้าตาอย่างไร: ซอยหนึ่งปีเป็น $n$ ช่วงเท่ากัน ช่วงละ $1/n$ ปี ผลตอบแทนของช่วงที่ $j$ คือ $r_j$ เท่ากับ log ของราคาปลายช่วงลบ log ของราคาต้นช่วง
  • $r_j$ แต่ละตัวเป็นอย่างไร: ทุกช่วงเป็น Normal ที่อิสระกัน ค่าเฉลี่ยคือ $\mu/n$ และ variance คือ $\sigma^2/n$ เพราะทั้ง drift และ variance สะสมตามเวลา ช่วงที่ยาว $1/n$ ปีจึงได้ $1/n$ ส่วนของทั้งปี
  • ค่าประมาณสองตัว: ประมาณ drift ด้วยผลรวมของ $r_j$ ทั้งปี และประมาณ variance ด้วยผลรวมของ $r_j^2$ ทั้งปี หมวก ^ บนสัญลักษณ์แปลว่าค่าที่คิดจากข้อมูล
\[ \begin{aligned} dp&=\mu\,dt+\sigma\,dW,\\ r_j&=p\big(\tfrac jn\big)-p\big(\tfrac{j-1}n\big),\\ r_j&\sim N\big(\mu/n,\ \sigma^2/n\big),\\ \hat\mu&=\sum_{j=1}^{n}r_j,\\ \hat\sigma^2&=\sum_{j=1}^{n}r_j^2. \end{aligned} \]

จุดที่ดูแปลกคือค่าประมาณ variance ไม่ได้หักค่าเฉลี่ยออกก่อนยกกำลังสอง ซึ่งดูผิดหลักสถิติ ที่ทำได้เพราะในช่วงสั้น drift ต่อช่วงเล็กมากเมื่อเทียบกับการแกว่งต่อช่วง ลองเทียบสองค่านี้ด้วยข้อมูลรายวันของโจทย์ ($n=252$)

\[ \begin{aligned} \mu/n&=0.08/252=0.00032,\\ \sigma/\sqrt n&=0.16/\sqrt{252}=0.0101. \end{aligned} \]

การแกว่งต่อวันใหญ่กว่า drift ต่อวันราว $0.0101/0.00032\approx32$ เท่า ค่าเฉลี่ยที่ไม่ได้หักจึงแทบไม่ทำให้ $r^2$ เปลี่ยน และค่าเฉลี่ยของ $r^2$ เกือบเท่ากับ variance ขั้น variance ด้านล่างจะวัดว่าความเอียงที่เกิด (bias) เล็กแค่ไหน

สังเกตอีกอย่างว่าค่าประมาณทั้งสองตัวใช้ข้อมูลชุดเดียวกันทุกจุด ถ้ามันแม่นไม่เท่ากัน ความต่างต้องมาจากสูตร ไม่ใช่จากข้อมูล

ขั้นที่ 2 — drift: ซอยละเอียดแค่ไหนก็ไม่ช่วย

ขั้นนี้ตอบครึ่งแรกของคำถาม: ข้อมูลที่ถี่ขึ้นช่วยให้รู้ drift แม่นขึ้นไหม เริ่มจากเขียนค่าประมาณ $\hat\mu$ ให้เห็นทุกพจน์ แต่ละ $r_j$ คือ log ของราคาปลายช่วงลบ log ของราคาต้นช่วง เมื่อบวกกัน จุดตรงกลางทุกจุดโผล่สองครั้ง ครั้งหนึ่งเป็นบวก (เป็นปลายของช่วงหนึ่ง) อีกครั้งเป็นลบ (เป็นต้นของช่วงถัดไป) จึงหักกันหมด

\[ \begin{aligned} \hat\mu&=\big[p(\tfrac1n)-p(0)\big]\\ &\quad+\big[p(\tfrac2n)-p(\tfrac1n)\big]+\cdots\\ &\quad+\big[p(1)-p(\tfrac{n-1}n)\big]\\ &=p(1)-p(0)\sim N(\mu,\sigma^2),\\ \operatorname{SE}(\hat\mu)&=\sigma=0.16,\\ t&=\frac{\mu}{\operatorname{SE}}=\frac{0.08}{0.16}=0.5. \end{aligned} \]

ค่า t แค่ 0.5 ยังเชื่อไม่ได้ คำถามต่อไปคือต้องมีข้อมูลกี่ปี ถ้ามีข้อมูล $T$ ปี ค่าประมาณคือการขยับทั้งหมดหารด้วย $T$ การขยับทั้งหมดมีค่าเฉลี่ย $\mu T$ และมี variance $\sigma^2T$ เพราะ variance สะสมตามเวลา SD ของมันจึงเป็น $\sigma\sqrt T$ ค่า t คือค่าเฉลี่ยหารด้วย SD ส่วนการหารด้วย $T$ นั้นหักกันเองทั้งบนและล่าง จากนั้นตั้ง t ให้เท่ากับ 2 แล้วแก้หา $T$

\[ \begin{aligned} t_T&=\frac{\mu T}{\sigma\sqrt T}=\frac{\mu}{\sigma}\sqrt T\\ &=0.5\sqrt T,\\ T&=\Big(\frac{2\sigma}{\mu}\Big)^2\\ &=\Big(\frac{2\times0.16}{0.08}\Big)^2=4^2=16. \end{aligned} \]

ในสูตรไม่มี $n$ เลย เพราะค่าประมาณใช้แค่ราคาต้นปีกับปลายปี ราคาตรงกลางหักกันหมด จะเก็บราคาทุกวันหรือทุกมิลลิวินาที SE ก็ยังเป็น 16 จุดเปอร์เซ็นต์ ทางเดียวที่ทำให้ t โตคือเวลา และ t โตช้า ตามรากที่สองของ $T$ จึงต้องใช้ 16 ปีกว่า t จะถึง 2

$\mu/\sigma$ (ผลตอบแทนคาดหวังหารด้วยความผันผวน) คือ Sharpe Ratio ของ log return กลยุทธ์ที่ Sharpe Ratio 0.5 จึงต้องรัน 16 ปีกว่าจะพิสูจน์ตัวเองได้ที่ t เท่ากับ 2 (เรื่องเดียวกับ การทดสอบ Sharpe Ratio) ข้อมูลที่ละเอียดขึ้นซื้อเวลานั้นไม่ได้

ขั้นที่ 3 — variance: ซอยละเอียดช่วยได้จริง

ขั้นนี้ตอบครึ่งหลังของคำถาม: ข้อมูลที่ถี่ขึ้นช่วยให้วัด variance แม่นขึ้นไหม ค่าประมาณ $\hat\sigma^2$ พลาดได้สองแบบ จึงต้องหาสองค่า

  • bias คือค่าเฉลี่ยของ $\hat\sigma^2$ ลบค่าจริง $\sigma^2$ บอกว่ามันเอียงไปทางเดียวเท่าไร
  • variance ของ $\hat\sigma^2$ บอกว่ามันแกว่งรอบค่าเฉลี่ยของตัวเองแค่ไหน จากข้อมูลชุดหนึ่งไปอีกชุด

$\hat\sigma^2$ คือผลรวมของ $r_j^2$ ดังนั้นค่าแรกต้องใช้ค่าเฉลี่ยของ $r_j^2$ และค่าที่สองต้องใช้ค่าเฉลี่ยของ $r_j^4$ ด้วย วิธีหามีสามจังหวะ

  • เขียน $r_j=a+\sqrt b\,z$ โดย $a$ คือค่าเฉลี่ยของ $r_j$ และ $b$ คือ variance ของมัน ส่วน $z$ เป็น Normal มาตรฐาน (ค่าเฉลี่ย 0, variance 1)
  • กาง $(a+\sqrt b\,z)^2$ และ $(a+\sqrt b\,z)^4$ ออก แล้วแทนค่าเฉลี่ยของกำลังของ $z$ คือ $\mathbb E[z]=\mathbb E[z^3]=0$, $\mathbb E[z^2]=1$ และ $\mathbb E[z^4]=3$ ซึ่งได้จาก moment generating function ของ Normal พจน์ที่มี $z$ กำลังคี่จึงหายหมด
  • ผลตอบแทนย่อยอิสระกัน ค่าเฉลี่ยและ variance ของผลรวม $n$ ตัวจึงเป็น $n$ เท่าของแต่ละตัว
\[ \begin{aligned} a&=\mu/n,\quad b=\sigma^2/n,\\ \mathbb E[r_j^2]&=a^2+b,\\ \mathbb E[r_j^4]&=a^4+6a^2b+3b^2,\\ \operatorname{Var}(r_j^2)&=\mathbb E[r_j^4]-(a^2+b)^2\\ &=2b^2+4a^2b,\\ \mathbb E[\hat\sigma^2]&=n(a^2+b)=\sigma^2+\mu^2/n,\\ \operatorname{Var}(\hat\sigma^2)&=n(2b^2+4a^2b)\\ &=\frac{2\sigma^4}{n}+\frac{4\mu^2\sigma^2}{n^2}. \end{aligned} \]

จังหวะที่ต้องระวังคือ variance ของ $r_j^2$ ซึ่งเท่ากับค่าเฉลี่ยของ $r_j^4$ ลบกำลังสองของค่าเฉลี่ยของ $r_j^2$ กาง $(a^2+b)^2=a^4+2a^2b+b^2$ แล้วลบออกจาก $\mathbb E[r_j^4]$ พจน์ $a^4$ หักกันเอง เหลือ $6a^2b-2a^2b=4a^2b$ และ $3b^2-b^2=2b^2$ จากนั้นคูณด้วย $n$ และแทน $a,b$ กลับ

ผลมีสองเรื่อง เรื่องแรก bias คือ $\mu^2/n$ ซึ่งหดลงเมื่อจำนวนจุดเพิ่ม เรื่องที่สอง พจน์ $4\mu^2\sigma^2/n^2$ เล็กกว่าพจน์แรกมากจนทิ้งได้ เหลือ SD ของ $\hat\sigma^2$ ราว $\sqrt{2\sigma^4/n}$ เทียบเป็นสัดส่วนของ $\sigma^2$ ได้ $\sqrt{2\sigma^4/n}/\sigma^2=\sqrt{2/n}$ ตัวเลขนี้เรียกว่า SE สัมพัทธ์ มันก็หดลงเมื่อจำนวนจุดเพิ่มเช่นกัน ค่าประมาณจึงลู่เข้าค่าจริง (consistent) ทั้งที่ไม่ได้หักค่าเฉลี่ย

ทำไม drift กับ variance ได้ผลต่างกัน: ซอยหนึ่งปีเป็น $n$ ส่วน แต่ละส่วนมี drift $\mu/n$ ปนอยู่กับการแกว่งขนาด $\sigma/\sqrt n$ บวกกลับครบ $n$ ส่วนก็ได้ drift $\mu$ ปนกับการแกว่ง $\sigma$ เท่าเดิม การซอยจึงไม่ได้ข้อมูลใหม่ของ drift เลย ส่วน variance โผล่ในทุกช่วงย่อย และแต่ละช่วงเป็นตัวอย่างอิสระ ยิ่งซอยยิ่งได้ตัวอย่างมาเฉลี่ยมาก

ผลนี้มีประโยชน์ทันที ถ้าความผันผวนเปลี่ยนช้า ค่าที่วัดได้แม่นของวันนี้ก็ใช้ทำนายพรุ่งนี้ได้เลย โดยไม่ต้องมีแบบจำลองอย่าง GARCH

ขั้นที่ 4 — ใส่ตัวเลขของโจทย์

ตอนนี้มีสูตรครบแล้ว ขั้นนี้ใส่ตัวเลขของโจทย์ต้นหน้า เพื่อตอบคำอ้าง “แม่นขึ้นเกือบ 9 เท่า”

โจทย์ให้อะไรมาบ้าง:

  • drift $\mu=8\%$ และความผันผวน $\sigma=16\%$ ต่อปี
  • ราคาปิดรายวันหนึ่งปีให้ $n=252$
  • ราคาทุก 5 นาทีให้ $390/5=78$ ช่วงต่อวัน ทั้งปีจึงได้ $n=78\times252=19{,}656$

ทีมอยากรู้ความแม่นของความผันผวน $\sigma$ ไม่ใช่ของ variance $\sigma^2$ ต้องแปลงก่อน สมมติว่า variance ที่วัดได้พลาดไปสัดส่วน $x$ คือวัดได้ $\sigma^2(1+x)$ ถอดรากได้ $\sigma\sqrt{1+x}\approx\sigma(1+x/2)$ เมื่อ $x$ เล็ก ความผันผวนจึงพลาดแค่ครึ่งหนึ่งของ variance SE สัมพัทธ์ของความผันผวนจึงเป็น $\tfrac12\sqrt{2/n}$ คูณด้วย $\sigma=16\%$ ก็ได้ SE เป็นจุดเปอร์เซ็นต์

\[ \begin{aligned} \text{daily}:&\quad\tfrac12\sqrt{2/252}=4.454\%,\\ &\quad16\%\times0.04454=0.713\%,\\ \text{5 min}:&\quad\tfrac12\sqrt{2/19{,}656}\\ &\quad=0.504\%,\\ &\quad16\%\times0.00504=0.081\%,\\ \text{ratio}:&\quad\sqrt{19{,}656/252}=\sqrt{78}\\ &\quad=8.83,\\ \text{bias}:&\quad\frac{\mu^2}{n\sigma^2}=\frac{0.08^2}{19{,}656\times0.16^2}\\ &\quad=1.27\times10^{-5}. \end{aligned} \]

คำตอบ: ความผันผวนที่วัดจากราคาปิดรายวันพลาดราว ±0.713 จุดเปอร์เซ็นต์ จากราคาทุก 5 นาทีเหลือ ±0.081 จุด แม่นขึ้น 8.83 เท่าจริงตามที่เพื่อนในทีมบอก แต่ผลตอบแทนคาดหวังไม่แม่นขึ้นเลย SE ยังเป็น 16 จุดเท่าเดิมตามขั้น drift ด้านบน ส่วน bias ที่เกิดจากการไม่หักค่าเฉลี่ยคือ $1.27\times10^{-5}$ ของ variance คือราว 1 ส่วนใน $1/(1.27\times10^{-5})\approx78{,}700$ ส่วน เล็กจนทิ้งได้

ตรวจเองใน 10 วินาที: จุดมากขึ้น 78 เท่า ความแม่นดีขึ้นตาม $\sqrt{78}\approx8.8$ และ $0.713/8.83=0.081$

ขั้นที่ 5 — ความคลาดเคลื่อนของราคาดันกลับ

ทุกอย่างข้างบนสมมติว่าเราเห็นราคาจริง แต่ราคาที่บันทึกในระบบคือราคาจริงบวกความคลาดเคลื่อนเล็ก ๆ เช่นการซื้อขายที่เกิดที่ราคา bid บ้าง ราคา ask บ้าง ราคาจึงเด้งไปมาทั้งที่มูลค่าของหุ้นไม่ได้เปลี่ยน ขั้นนี้ดูว่าการเด้งนี้ทำอะไรกับ RV

จากขั้นนี้ไป วัดการขยับเป็นดอลลาร์ต่อหุ้นแทนผลตอบแทน และใช้หุ้น \$50 จากหน้า แบบจำลองของ Roll เพราะมีตัวเลขครบ (ตัวเลขสมมติ)

  • ราคาจริงขยับด้วย SD $\sigma_\epsilon=\$0.0256$ ต่อนาที (ขั้นช่วงข้ามคืนด้านล่างจะแปลงเป็นความผันผวนต่อปีได้ 16.05% ใกล้หุ้นในโจทย์)
  • ราคาที่บันทึกคลาดเคลื่อนจากราคาจริงด้วย SD $\sigma_\eta=\$0.012$ ตัวเลขนี้คือครึ่งหนึ่งของ spread 2.4 เซนต์ เพราะราคาที่บันทึกอยู่ที่ bid หรือ ask ซึ่งห่างจากราคากลางข้างละ $2.4/2=1.2$ เซนต์
  • ตลาดเปิด $M=390$ นาทีต่อวัน เก็บราคาทุก $q$ นาที จึงได้ $N=M/q$ ช่วงต่อวัน

ให้ $e_j$ คือการขยับจริงของราคาในช่วงที่ $j$ และ $\eta_j$ คือความคลาดเคลื่อนของราคาที่บันทึกตอนปลายช่วงที่ $j$ การขยับที่เห็นคือราคาที่บันทึกตอนปลายช่วงลบตอนต้นช่วง จึงมีสองส่วน

\[ \begin{aligned} r_j&=e_j+(\eta_j-\eta_{j-1}),\\ \operatorname{Var}(r_j)&=q\sigma_\epsilon^2+2\sigma_\eta^2. \end{aligned} \]

ส่วนแรก $e_j$ มี variance $q\sigma_\epsilon^2$ เพราะเป็นผลรวมของการขยับนาทีละครั้ง $q$ ครั้งที่อิสระกัน ส่วนที่สองคือความคลาดเคลื่อนสองตัวที่อิสระกัน variance จึงบวกกันได้ $\sigma_\eta^2+\sigma_\eta^2=2\sigma_\eta^2$ ค่าเฉลี่ยของ $r_j$ เป็นศูนย์ (ไม่นับ drift ซึ่งเล็กมากในช่วงไม่กี่นาที ตามที่ขั้นแรกแสดงไว้) ค่าเฉลี่ยของ $r_j^2$ จึงเท่ากับ variance นี้ RV คือผลรวมของ $r_j^2$ ทั้ง $N$ ช่วง ค่าเฉลี่ยของ RV จึงเป็น $N$ เท่าของมัน

\[ \begin{aligned} \mathbb E[\mathrm{RV}_q]&=N(q\sigma_\epsilon^2+2\sigma_\eta^2)\\ &=M\sigma_\epsilon^2+2\tfrac{M}{q}\sigma_\eta^2,\\ \frac{\text{bias}}{\text{true}}&=\frac{2(M/q)\sigma_\eta^2}{M\sigma_\epsilon^2}=\frac{2\sigma_\eta^2}{q\sigma_\epsilon^2}\\ &=\frac{2(0.012)^2}{q\,(0.0256)^2}\\ &=\frac{0.4395}{q},\\ \text{vol}:&\quad\sqrt{1+0.4395/q}-1,\\ q=1:&\quad43.95\%,\ \ \text{vol}+19.98\%,\\ q=5:&\quad8.79\%,\ \ \text{vol}+4.30\%,\\ q=30:&\quad1.46\%,\ \ \text{vol}+0.73\%. \end{aligned} \]

ค่าเฉลี่ยของ RV มีสองก้อน ก้อนแรกคือ variance จริงของวัน $M\sigma_\epsilon^2=390\times0.0256^2=0.25559$ ดอลลาร์² ก้อนนี้ไม่ขึ้นกับ $q$ ก้อนที่สองคือความคลาดเคลื่อนที่ถูกนับซ้ำ $M/q$ ครั้ง ครั้งละ $2\sigma_\eta^2$ ยิ่งเก็บถี่ ยิ่งนับมาก ก้อนที่สองนี้คือ bias หารด้วยก้อนแรกได้ $0.4395/q$

ความผันผวนคือรากที่สองของ variance จึงพองตาม $\sqrt{1+0.4395/q}$ เช่นที่ 1 นาที $\sqrt{1.4395}=1.1998$ คือพอง 19.98% นี่คือเส้นส้มในรูปภาพรวมด้านบน

bias นี้ต่างจากความคลาดเคลื่อนแบบสุ่มตรงที่มันเอียงขึ้นทางเดียวทุกวัน เก็บข้อมูลกี่ปีก็ไม่หาย ขั้น variance ด้านบนบอกให้ซอยให้ละเอียด ขั้นนี้บอกให้หยุดก่อน

ขั้นที่ 6 — ความถี่ที่ความผิดรวมต่ำที่สุด

ตอนนี้มีสองแรงดึงกันคนละทาง ซอยถี่ ความสุ่มลดแต่ bias เพิ่ม ซอยห่าง bias ลดแต่ความสุ่มเพิ่ม จะเลือกได้ต้องมีคะแนนความผิดรวมตัวเดียว คะแนนที่ใช้คือ MSE (mean squared error) ของ RV หนึ่งวัน คือ bias กำลังสองบวก variance ของ RV แล้วหา $q$ ที่ทำให้ MSE ต่ำที่สุด MSE มีสองชิ้น

  • bias กำลังสอง: bias ของ RV หนึ่งวันคือ $2(M/q)\sigma_\eta^2$ จากขั้นก่อน ยกกำลังสองได้ $4M^2\sigma_\eta^4/q^2$
  • variance: เพื่อให้ได้สูตรง่าย ชิ้นนี้คิดแบบไม่มีความคลาดเคลื่อนและไม่มี drift แต่ละช่วงเป็น Normal ที่มี variance $q\sigma_\epsilon^2$ กำลังสองของมันจึงมี variance $2(q\sigma_\epsilon^2)^2$ (คือสูตร $2b^2$ ของขั้น variance เมื่อ $a=0$) มี $N=M/q$ ช่วง รวมได้ $(M/q)\cdot2q^2\sigma_\epsilon^4=2Mq\sigma_\epsilon^4$

จากนั้นหาอนุพันธ์ของ MSE เทียบกับ $q$ ตั้งให้เท่ากับศูนย์ แล้วแก้หา $q$ ที่ดีที่สุด เรียกว่า $q^{*}$ ค่า $\kappa=\sigma_\eta/\sigma_\epsilon$ คือขนาดความคลาดเคลื่อนเทียบกับการขยับจริงหนึ่งนาที

\[ \begin{aligned} \text{MSE}(q)&=\frac{4M^2\sigma_\eta^4}{q^2}+2Mq\sigma_\epsilon^4,\\ \text{MSE}'(q)&=-\frac{8M^2\sigma_\eta^4}{q^3}+2M\sigma_\epsilon^4=0,\\ (q^{*})^3&=\frac{4M\sigma_\eta^4}{\sigma_\epsilon^4}=4M\kappa^4. \end{aligned} \]

ใส่ตัวเลขของหุ้น \$50 ได้ $\kappa=0.012/0.0256=0.46875$ จึงได้ $\kappa^4=0.048279$ และ $4M=4\times390=1{,}560$ เพื่อให้อ่านความผิดรวมเป็นเปอร์เซ็นต์ของ variance จริงของวัน $M\sigma_\epsilon^2$ ได้ ให้หาร MSE ด้วย $M^2\sigma_\epsilon^4$ แล้วถอดราก

\[ \begin{aligned} q^{*}&=(1{,}560\times0.048279)^{1/3}\\ &=75.32^{1/3}=4.22\ \text{min},\\ \frac{\sqrt{\text{MSE}}}{M\sigma_\epsilon^2}&=\sqrt{\frac{4\kappa^4}{q^2}+\frac{2q}{M}},\\ q=4.22:&\quad\sqrt{0.01083+0.02166}=18.02\%,\\ q=5:&\quad\sqrt{0.00772+0.02564}=18.27\%. \end{aligned} \]

สูตร $q^{*}$ บอกว่าความถี่ที่ดีที่สุดขึ้นกับ $\kappa$ เท่านั้น ยิ่งราคาที่บันทึกคลาดเคลื่อนมากเมื่อเทียบกับการขยับจริง ยิ่งต้องเก็บห่าง ที่จุดต่ำสุด ก้อน variance (0.02166) ใหญ่เป็นสองเท่าของก้อน bias กำลังสอง (0.01083) พอดี เหตุผลคือสมการ $\text{MSE}'=0$ ถ้าคูณทั้งสมการด้วย $q$ จะได้ $2Mq\sigma_\epsilon^4=2\times\dfrac{4M^2\sigma_\eta^4}{q^2}$ คือก้อน variance เท่ากับสองเท่าของก้อน bias กำลังสอง

ความผิดรวมที่จุดต่ำสุดคือ 18.02% ของ variance จริงของวัน ก้นของเส้นค่อนข้างแบน ทุก $q$ ตั้งแต่ 2.8 ถึง 6.9 นาทีให้ความผิดรวมเกินจุดต่ำสุดไม่ถึง 10% (โค้ดท้ายหน้าไล่หาช่วงนี้) ออกนอกช่วงแล้วแย่ลงเร็ว ใช้สูตรเดียวกันกับ 8 และ 10 นาที

\[ \begin{aligned} q=8:&\quad\sqrt{0.00302+0.04103}=20.99\%,\\ &\quad20.99/18.02=1.16,\\ q=10:&\quad\sqrt{0.00193+0.05128}=23.07\%,\\ &\quad23.07/18.02=1.28. \end{aligned} \]

ทำไมคนนิยม 5 นาที: วันซื้อขาย 390 นาทีแบ่งเป็นช่วงเท่า ๆ กันแถวจุดต่ำสุดได้ลงตัวที่ 3, 5 หรือ 6 นาที แต่ $390/4=97.5$ ไม่ลงตัว ช่วง 5 นาที (78 ช่วง) ให้ 18.27% แทบเท่าจุดต่ำสุด

สูตรด้านบนคิด variance แบบง่าย ถ้าคิดให้ครบ คือนับความสุ่มของความคลาดเคลื่อนเองด้วยตามสูตรในขั้นหนึ่งวันของ RV ด้านล่าง จุดต่ำสุดขยับไปเป็น 4.25 นาที ที่ความผิดรวม 19.32% (โค้ดท้ายหน้าค้นหาให้) แทบไม่ต่างจากเดิม ตัวเลข 5 นาทีที่คนทำงานใช้กันมานานจึงมีเหตุผลรองรับ งานของ Liu, Patton และ Sheppard (2015) ที่เปรียบเทียบตัวประมาณหลายสิบแบบบนข้อมูลจริงหลายตลาดก็พบว่า RV ธรรมดาที่ 5 นาทีเอาชนะได้ยาก

ขั้นที่ 7 — หนึ่งวันของ RV ที่สามความถี่

ขั้นความผิดรวมใช้ variance แบบง่ายเพื่อให้ได้สูตรปิด ขั้นนี้คิดให้ครบ ว่า RV ของวันเดียวแกว่งแค่ไหนเมื่อเก็บราคาทุก 1, 5 และ 30 นาที ตัวเลขชุดนี้คือจุดส้มในรูปภาพรวมต้นหน้า

โจทย์ให้อะไรมาบ้าง:

  • หุ้น \$50 ตัวเดิม variance จริงของวัน $M\sigma_\epsilon^2=0.25559$ ดอลลาร์² และ $\sigma_\eta^2=0.012^2=0.000144$
  • สมมติความคลาดเคลื่อนเป็น Normal การขยับที่เห็นทั้งวันจึงเป็นเวกเตอร์ Normal (Normal หลายตัวที่อาจสัมพันธ์กัน)
  • แต่ละช่วงมี variance $v=q\sigma_\epsilon^2+2\sigma_\eta^2$ จากขั้นความคลาดเคลื่อนด้านบน
  • สองช่วงติดกันใช้ความคลาดเคลื่อนตัวเดียวกันที่รอยต่อ $r_j$ มี $+\eta_j$ (ปลายช่วง) ส่วน $r_{j+1}$ มี $-\eta_j$ (ต้นช่วง) จึงได้ $\operatorname{Cov}(r_j,r_{j+1})=-\sigma_\eta^2$ นี่คือลายนิ้วมือของ Roll ช่วงที่ไม่ติดกันไม่มีอะไรร่วมกัน covariance จึงเป็นศูนย์

ค่าเฉลี่ยของ RV ได้มาแล้วจากขั้นความคลาดเคลื่อน คือ $M\sigma_\epsilon^2+2N\sigma_\eta^2$ ที่ยังขาดคือ variance ของ RV ซึ่งต้องใช้สามชิ้น

  • สำหรับ Normal สองตัว $x, y$ ที่ค่าเฉลี่ยศูนย์ $\operatorname{Cov}(x^2,y^2)=2\operatorname{Cov}(x,y)^2$ ได้จากโมเมนต์ที่สี่ของ Normal แบบเดียวกับขั้น variance ด้านบน (เมื่อ $x=y$ จะได้ $\operatorname{Var}(x^2)=2\operatorname{Var}(x)^2$)
  • variance ของผลรวม $\sum r_j^2$ คือผลรวมของ variance ของแต่ละตัว ตัวละ $2v^2$ มี $N$ ตัว
  • บวก covariance ของทุกคู่ ซึ่งเหลือแค่คู่ติดกัน $N-1$ คู่ คู่ละ $2(-\sigma_\eta^2)^2=2\sigma_\eta^4$ และนับสองครั้ง เพราะคู่ $(j-1,j)$ กับ $(j,j-1)$ ต่างก็อยู่ในผลรวม

ลองคิดแถว $q=1$ ให้ดู

\[ \begin{aligned} \operatorname{Var}(\mathrm{RV}_q)&=N\cdot2v^2+2(N-1)\cdot2\sigma_\eta^4\\ &=2\big[Nv^2+2(N-1)\sigma_\eta^4\big],\\ q=1:&\quad v=0.00065536+0.000288\\ &\quad=0.00094336,\\ &\quad\operatorname{Var}=2[0.00034707+0.00001613]\\ &\quad=0.00072640,\\ &\quad\text{SD}=\sqrt{0.00072640}=0.0270,\\ &\quad\text{mean}=0.25559+2(390)(0.000144)\\ &\quad=0.3679. \end{aligned} \]

ทำแบบเดียวกันกับ $q=5$ ($N=78$) และ $q=30$ ($N=13$)

\[ \begin{aligned} q=5:&\quad v=0.0032768+0.000288\\ &\quad=0.0035648,\\ &\quad\operatorname{Var}=2[0.00099121+0.00000319]\\ &\quad=0.0019888,\\ &\quad\text{SD}=\sqrt{0.0019888}=0.0446,\\ &\quad\text{mean}=0.25559+2(78)(0.000144)\\ &\quad=0.2781,\\ q=30:&\quad v=0.0196608+0.000288\\ &\quad=0.0199488,\\ &\quad\operatorname{Var}=2[0.0051734+0.0000005]\\ &\quad=0.0103478,\\ &\quad\text{SD}=\sqrt{0.0103478}=0.1017,\\ &\quad\text{mean}=0.25559+2(13)(0.000144)\\ &\quad=0.2593. \end{aligned} \]

คำตอบ: ช่วง 1 นาทีแกว่งน้อยที่สุด แต่ค่าเฉลี่ยสูงเกินจริงไปทางเดียว $0.3679/0.25559-1=44\%$ ช่วง 30 นาทีแทบไม่มี bias แต่แกว่ง $0.1017/0.25559=40\%$ ของค่าจริง ช่วง 5 นาทีถ่วงสองอย่างได้ดีที่สุด

จะเทียบให้เป็นตัวเลขเดียว ใช้ความผิดรวม $\sqrt{\text{bias}^2+\text{SD}^2}$ หารด้วยค่าจริง 0.25559 โดย bias คือค่าเฉลี่ยลบค่าจริง ได้ $0.3679-0.25559=0.1123$, $0.2781-0.25559=0.0225$ และ $0.2593-0.25559=0.0037$

\[ \begin{aligned} q=1:&\quad\sqrt{0.1123^2+0.0270^2}\\ &\quad=0.1155=45\%\ \text{of}\ 0.25559,\\ q=5:&\quad\sqrt{0.0225^2+0.0446^2}\\ &\quad=0.0500=19.5\%\ \text{of}\ 0.25559,\\ q=30:&\quad\sqrt{0.0037^2+0.1017^2}\\ &\quad=0.1018=40\%\ \text{of}\ 0.25559. \end{aligned} \]

โค้ดท้ายหน้าจำลอง 2,000 วัน (ตัวสร้างเลขสุ่ม mulberry32 seed 25) แล้ววัดค่าเฉลี่ย ± SD ของ RV จริง ได้ 0.3683 ± 0.0277, 0.2779 ± 0.0445 และ 0.2602 ± 0.1016 ใกล้สูตรทุกแถว

ตรวจเองใน 10 วินาที: ที่ 30 นาทีมีแค่ $390/30=13$ ช่วง SE สัมพัทธ์จึงราว $\sqrt{2/13}=39\%$ ใกล้ 40% ในตาราง

ขั้นที่ 8 — หักความคลาดเคลื่อนออกด้วย autocovariance

ถ้ารู้แน่ว่าความคลาดเคลื่อนทำให้ RV สูงเกิน ก็น่าจะหักมันออกได้ หน้า แบบจำลองของ Roll แสดงวิธีไว้แล้ว ให้ $\gamma_0$ คือ variance ของการขยับที่เห็น และ $\gamma_1$ คือ covariance ของการขยับกับการขยับช่วงก่อนหน้า (เรียกว่า autocovariance ที่ lag 1) $\gamma_1$ ติดลบเพราะการเด้ง และ variance จริงของการขยับคือ $\sigma_\epsilon^2=\gamma_0+2\gamma_1$

ขั้นนี้ใช้ความคิดเดียวกันกับ RV คือนอกจากบวก $r_j^2$ แล้ว ให้บวกผลคูณของการขยับสองช่วงติดกันเข้าไปสองเท่าด้วย แล้วดูว่าค่าเฉลี่ยเหลือเท่าไร ค่าเฉลี่ยของ $r_j^2$ คือ $v$ และค่าเฉลี่ยของ $r_jr_{j-1}$ คือ covariance ของคู่ติดกัน $-\sigma_\eta^2$ จากขั้นก่อน แทน $Nv=M\sigma_\epsilon^2+2N\sigma_\eta^2$ แล้วพจน์ที่มี $N$ จะหักกันเอง

\[ \begin{aligned} \mathrm{RV}^{\rm AC}&=\sum_{j=1}^{N}r_j^2+2\sum_{j=2}^{N}r_jr_{j-1},\\ \mathbb E[\mathrm{RV}^{\rm AC}]&=Nv-2(N-1)\sigma_\eta^2\\ &=M\sigma_\epsilon^2+2N\sigma_\eta^2-2N\sigma_\eta^2+2\sigma_\eta^2\\ &=M\sigma_\epsilon^2+2\sigma_\eta^2,\\ q=1:&\quad0.25559+0.000288=0.25588. \end{aligned} \]

bias ที่เหลือมีแค่ความคลาดเคลื่อนคู่เดียวที่ต้นวันกับปลายวัน $2\sigma_\eta^2=0.000288$ คิดเป็น $0.000288/0.25559=0.11\%$ ของค่าจริง ไม่ว่าจะใช้ $q$ เท่าไร เพราะความคลาดเคลื่อนตรงกลางวันหักกันหมด

แล้วมันแกว่งแค่ไหน SD ของ $\mathrm{RV}^{\rm AC}$ ที่ 1 นาทีคิดจาก covariance ของเวกเตอร์ Normal แบบเดียวกับขั้นก่อน แต่มีคู่ที่ต้องนับมากกว่า โค้ดท้ายหน้าคิดได้ 0.0369 ความผิดรวมจึงเป็น $\sqrt{0.0369^2+0.000288^2}/0.25559=14.4\%$ ต่ำกว่า 19.3% ของ RV ธรรมดาที่ความถี่ดีที่สุด ราคาที่ต้องจ่ายคือ SD สูงกว่า RV ธรรมดาที่ 1 นาที (0.0369 เทียบกับ 0.0270) เพราะผลคูณของการขยับติดกันก็สุ่มเหมือนกัน

ผลนี้ต้องอาศัยว่าความคลาดเคลื่อนของแต่ละนาทีอิสระกัน ข้อมูลจริงไม่ได้เป็นแบบนั้นเสมอ ตัวอย่างคือคำสั่งซื้อใหญ่ที่ถูกซอยเป็นคำสั่งย่อยทิศเดียวกันหลายนาทีติดกัน ราคาที่บันทึกจึงเอียงไปทางเดียวต่อเนื่อง บนข้อมูลจริง RV ธรรมดาที่ 5 นาทียังเป็นตัวตั้งที่แข็งแรง ตัวที่ชนะได้บ้างมีสองแบบ

  • subsampling: คิด RV 5 นาทีห้าชุดที่เริ่มนาทีที่ 0, 1, 2, 3 และ 4 แล้วเฉลี่ย ได้ใช้ข้อมูลทุกนาที แต่ bias ยังอยู่ระดับของ 5 นาที
  • ตัวประมาณแบบ kernel: ใช้ข้อมูลระดับวินาที แล้วบวกผลคูณของการขยับที่ห่างกันหลายช่วงเข้าไปด้วยน้ำหนักที่ลดลง เพื่อหักความคลาดเคลื่อนที่ลากยาวหลายช่วง

ขั้นที่ 9 — ช่วงข้ามคืนที่ข้อมูลระหว่างวันมองไม่เห็น

RV รวมเฉพาะ 390 นาทีที่ตลาดเปิด แต่พอร์ตแบกความเสี่ยงตั้งแต่ราคาปิดวันนี้ถึงราคาปิดพรุ่งนี้ ช่วงนั้นรวมช่วงข้ามคืนด้วย คือ 16:00 น. ถึง 9:30 น. ของวันถัดไป ซึ่งเป็นช่วงที่ข่าวสำคัญมักออก ถ้าไม่เติมช่วงนี้กลับ ความผันผวนจะต่ำเกินจริง

ให้ $f$ คือสัดส่วนของ variance ปิดถึงปิดที่เกิดช่วงข้ามคืน ตัวอย่างนี้สมมติ $f=25\%$ กับหุ้น \$50 ตัวเดิม การแปลง RV เป็นความผันผวนปิดถึงปิดต่อปีมีสามจังหวะ

  • ถอดรากของ RV ได้ SD ของการขยับต่อวันเป็นดอลลาร์ แล้วหารด้วยราคา \$50 ให้เป็นสัดส่วนของราคา
  • คูณ $\sqrt{252}$ เพื่อแปลงเป็นต่อปี เพราะ variance สะสมตามจำนวนวัน และปีหนึ่งมี 252 วันทำการ
  • variance ระหว่างวันเป็นแค่ $1-f$ ส่วนของ variance ปิดถึงปิด จึงหาร variance ด้วย $1-f$ ซึ่งในรูปของความผันผวนคือหารด้วย $\sqrt{1-f}$
\[ \begin{aligned} \sigma_{\rm day}&=\sqrt{0.25559}/50\\ &=0.50556/50=1.0111\%,\\ \sqrt{252}\,\sigma_{\rm day}&=15.875\times1.0111\%\\ &=16.05\%,\\ f=25\%:&\quad\frac{16.05\%}{\sqrt{1-0.25}}=18.53\%. \end{aligned} \]

การปรับคือคูณความผันผวนด้วย $1/\sqrt{0.75}=1.1547$ ถ้าไม่ปรับ ความผันผวนจะต่ำไป $18.53-16.05=2.48$ จุด ค่า $f$ ต้องประมาณจากข้อมูลของหุ้นนั้นเอง ตัวเลข 25% ในที่นี้เป็นค่าสมมติ

อีกเรื่องที่ต้องระวังคือนาทีแรก ๆ หลังตลาดเปิด ช่วงนั้นความผันผวนและ spread สูงผิดปกติ หลายทีมจึงตัดช่วงนี้ออก หรือคิดแยก

ความผิดที่ให้คำตอบผิดโดยไม่มีอะไรเตือน

ใช้ข้อมูลถี่เพื่อ “ปรับปรุง” ผลตอบแทนคาดหวัง: ข้อมูลถี่ไม่ช่วย drift เลย คนที่เชื่อว่าแม่นขึ้น $\sqrt{78}=8.83$ เท่า จะคิด SE ได้ $16/8.83=1.81$ จุด ซึ่งผิด ค่าที่ถูกกับข้อมูลหนึ่งปียังเป็น $\sigma/\sqrt T=16/\sqrt1=16$ จุด เพราะผลรวมของผลตอบแทนย่อยยุบเหลือราคาปลายลบราคาต้น ถ้าเห็นค่า t ของผลตอบแทนคาดหวังโตขึ้นหลังเปลี่ยนเป็นข้อมูลถี่ แปลว่ามีอะไรผิด สาเหตุที่พบบ่อยคือคิดผลตอบแทนจากราคาที่ผ่านการเฉลี่ยมาแล้ว หรือจากช่วงเวลาที่ซ้อนกัน จึงนับข้อมูลชุดเดียวกันหลายครั้ง

เก็บทุกนาทีหรือทุก tick: ความคลาดเคลื่อนของราคาถูกนับซ้ำทุกช่วง RV จึงพองขึ้น ในหุ้น \$50 ที่ spread 2.4 เซนต์ ความผันผวนจริงคือ 16.05% แต่ RV ทุก 1 นาทีให้ $16.05\%\times\sqrt{1+0.4395}=19.26\%$ คือพอง 20% หุ้นที่ spread กว้างกว่านี้พองมากกว่านี้

ลืมช่วงข้ามคืน: RV มองไม่เห็นช่วงตลาดปิด ความผันผวนจึงต่ำเกินจริง ที่ $f=25\%$ RV ให้ 16.05% แต่ความผันผวนปิดถึงปิดที่พอร์ตแบกจริงคือ $16.05\%/\sqrt{0.75}=18.53\%$ VaR (ขาดทุนที่วันแย่ ๆ ไม่ควรเกิน) โตตามความผันผวน จึงต่ำไปในสัดส่วนเดียวกัน คือต่ำไป $1-16.05/18.53=13.4\%$

ใช้ความถี่เดียวกันกับทุกหุ้น: ความถี่ที่ดีที่สุดขึ้นกับหุ้นแต่ละตัว ด้วยสองเหตุผล

  • หุ้นที่ซื้อขายห่าง เช่นมีการซื้อขายราวทุก 10 นาที ช่วง 5 นาทีราวครึ่งหนึ่ง ($5/10=0.5$) จะไม่มีการซื้อขายเลย ราคาค้าง การขยับในช่วงนั้นเป็นศูนย์ RV จึงต่ำเกินจริง
  • จากสูตร $q^*=(4M\kappa^4)^{1/3}$ ความถี่ที่ดีที่สุดโตตาม $\kappa^{4/3}$ หุ้น \$50 ในหน้านี้มี $\kappa=0.469$ จึงได้ 4.22 นาที แต่หุ้นที่ $\kappa=1$ ได้ $(4\times390\times1)^{1/3}=11.6$ นาที ถ้ายังใช้ 5 นาทีกับหุ้นตัวนั้น variance จะพอง $2\kappa^2/q=2/5=40\%$ เทียบกับแค่ $2(0.469)^2/5=8.8\%$ ของหุ้น \$50

เชื่อ RV ของวันเดียวที่ความถี่ต่ำ: ช่วงยาวทำให้มีตัวอย่างน้อย ที่ 30 นาทีมีแค่ $390/30=13$ ช่วง SD ของ RV หนึ่งวันคือ $0.1017/0.25559=40\%$ ของค่าจริง วันที่วัดได้สูงกว่าจริง 40% จึงเป็นเรื่องปกติ ไม่ใช่สัญญาณว่าตลาดเปลี่ยน

ใช้ทำอะไรบนโต๊ะจริง

ระบบความเสี่ยงที่มีข้อมูลระหว่างวันทำแบบนี้ทุกเย็น

  • คิด RV ของวันจากช่วง 5 นาที
  • หารด้วย $1-f$ เพื่อเติมช่วงข้ามคืน โดยใช้ $f$ ของหุ้นแต่ละตัว
  • ส่งค่าที่ได้เข้าแบบจำลองพยากรณ์ความผันผวนของพรุ่งนี้

ที่ต้องพยากรณ์เพราะความผันผวนเปลี่ยนไปวันต่อวัน และขนาดของการขยับมีความจำ คือวันที่แกว่งแรงมักตามด้วยวันที่แกว่งแรง (หนึ่งใน stylized facts คือลักษณะที่พบซ้ำในข้อมูลราคาแทบทุกตลาด) งานจริงจึงพยากรณ์ RV ของพรุ่งนี้ด้วยแบบจำลองอนุกรมเวลาอย่าง AR(1) บน RV เอง (ทายค่าพรุ่งนี้จากค่าวันนี้คูณสัมประสิทธิ์หนึ่งตัวบวกค่าคงที่) หรือเฉลี่ยแบบ EWMA (ค่าเฉลี่ยที่ให้น้ำหนักวันล่าสุดมากที่สุด และน้ำหนักลดลงเรื่อย ๆ เมื่อย้อนไปในอดีต) แล้วใช้ความผันผวนที่ได้คุมขนาดพอร์ต และตั้ง VaR

ทีมกลยุทธ์ใช้ผลเรื่อง drift ตอบคำถามอีกแบบหนึ่ง คือ backtest (การทดสอบกลยุทธ์กับข้อมูลในอดีต) ต้องยาวแค่ไหนจึงเชื่อได้ คำตอบคือ $T=(2/\mathrm{SR})^2$ ปี โดย SR คือ Sharpe Ratio คำตอบนี้ขึ้นกับ Sharpe Ratio เท่านั้น ไม่ขึ้นกับความถี่ของข้อมูล

โจทย์ตรวจความเข้าใจ

1. ทีมกลยุทธ์มีกลยุทธ์ที่คาดว่าจะให้ Sharpe Ratio ต่อปี 0.7 (ผลตอบแทนที่ได้เกินเงินฝาก หารด้วยความผันผวน) ทีมอยากรู้ว่าต้องรันกี่ปีจึงได้ค่า t เท่ากับ 2 มีคนเสนอให้ใช้ข้อมูลรายนาทีแทนรายวันเพื่อย่นเวลา ต้องรันกี่ปี และข้อเสนอนี้ช่วยไหม

เฉลย

ใช้สูตรจากขั้น drift แทน $\mu/\sigma$ ด้วย Sharpe Ratio

\[T=\Big(\frac{2}{0.7}\Big)^2=2.857^2=8.16\ \text{years}.\]

ข้อมูลรายนาทีไม่ช่วย เพราะ SE ของ drift ต่อปีคือ $\sigma/\sqrt T$ ซึ่งไม่มีจำนวนจุดต่อปีอยู่ในสูตร

2. หุ้นอีกตัวมีความผันผวนจริง 30% ต่อปี ทีมมีข้อมูลหนึ่งปี และสมมติว่าราคาที่บันทึกไม่มีความคลาดเคลื่อน ถ้าวัดความผันผวนจากราคาปิดรายวัน และจากราคาทุก 5 นาที ค่าที่วัดได้จะคลาดเคลื่อน (SE) กี่จุดเปอร์เซ็นต์

เฉลย

SE สัมพัทธ์ของความผันผวนคือ $\tfrac12\sqrt{2/n}$ คูณด้วย 30 จุด โดย $n=252$ สำหรับรายวัน และ $n=19{,}656$ สำหรับทุก 5 นาที

\[ \begin{aligned} \text{daily}:&\quad30\times\tfrac12\sqrt{2/252}=1.336,\\ \text{5 min}:&\quad30\times\tfrac12\sqrt{2/19{,}656}=0.151. \end{aligned} \]

แม่นขึ้น $\sqrt{19{,}656/252}=\sqrt{78}=8.83$ เท่า เท่ากับหุ้นในโจทย์ต้นหน้า เพราะอัตราส่วนนี้ไม่ขึ้นกับ $\sigma$

3. หุ้นเล็กตัวหนึ่งมีราคาจริงขยับด้วย SD $\sigma_\epsilon=\$0.02$ ต่อนาที แต่ spread กว้างจนความคลาดเคลื่อนของราคาที่บันทึกมี SD $\sigma_\eta=\$0.02$ เท่ากัน (ตัวเลขสมมติ) ถ้าคิด RV จากราคาทุก 1 นาที ความผันผวนจะพองกี่เท่า และควรเก็บราคาทุกกี่นาที

เฉลย

ขนาดความคลาดเคลื่อนเทียบกับการขยับจริงคือ $\kappa=0.02/0.02=1$ ใช้สูตร bias จากขั้นความคลาดเคลื่อน และสูตร $q^*$ จากขั้นความผิดรวม

\[ \begin{aligned} \frac{\text{bias}}{\text{true}}&=\frac{2\kappa^2}{q}=\frac{2\times1}{1}=2,\\ q^*&=(4M\kappa^4)^{1/3}=(4\times390\times1^4)^{1/3}\\ &=1{,}560^{1/3}\\ &=11.6\ \text{min}. \end{aligned} \]

variance ที่วัดได้เป็น $1+2=3$ เท่าของจริง คือของจริง 1 ส่วน บวก bias อีก 2 ส่วน ความผันผวนเป็นรากที่สองของ variance จึงพอง $\sqrt3=1.732$ เท่า ความถี่ที่ดีที่สุดคือ 11.6 นาที ห่างกว่าหุ้น \$50 ในหน้านี้ (4.22 นาที) เพราะความคลาดเคลื่อนเทียบกับการขยับจริงใหญ่กว่า ($\kappa=1$ เทียบกับ 0.469)

const {sqrt, log, cos, sin, PI} = Math;

// estimators of drift and variance from n equal sub-period returns
function estimators(mu, sigma, n, years = 1) {
  const a = mu / n, b = sigma * sigma / n;
  return {driftSE: sigma / sqrt(years), t: mu * years / (sigma * sqrt(years)), bias: n * a * a,
    varSE: sqrt(n * (2 * b * b + 4 * a * a * b)), relVar: sqrt(2 / n), relVol: 0.5 * sqrt(2 / n)};
}
const yearsForT = (sharpe, t = 2) => (t / sharpe) ** 2;
// one day of M minutes sampled every q minutes, true move se and price noise sn per minute
function day(q, se, sn, M = 390) {
  const N = M / q, v = q * se * se + 2 * sn * sn, c = sn * sn;
  const truth = M * se * se, bias = 2 * N * c;
  return {N, truth, mean: truth + bias, bias, sdGaussian: sqrt(2 * (N * v * v + 2 * (N - 1) * c * c)),
    mseSimple: bias * bias + 2 * M * q * se ** 4, mseFull: bias * bias + 2 * (N * v * v + 2 * (N - 1) * c * c)};
}
const qStar = (se, sn, M = 390) => (4 * M * sn ** 4 / se ** 4) ** (1 / 3);
function argmin(f, lo, hi) {
  const g = (sqrt(5) - 1) / 2;
  let a = lo, b = hi;
  for (let i = 0; i < 200; i++) { const c = b - g * (b - a), d = a + g * (b - a); if (f(c) < f(d)) b = d; else a = c; }
  return (a + b) / 2;
}
// RV plus twice the lag-1 cross products; variance from the Gaussian covariance of the returns
function acCorrected(q, se, sn, M = 390) {
  const N = M / q, v = q * se * se + 2 * sn * sn, c = -sn * sn;
  const S = (i, j) => (i === j ? v : Math.abs(i - j) === 1 ? c : 0);
  // Var(r'Ar) = 2 trace(A S A S) with A = 1 on the diagonal and the two first off-diagonals
  const AS = (i, j) => S(i - 1, j) * (i > 0) + S(i, j) + S(i + 1, j) * (i < N - 1);
  let tr = 0;
  for (let i = 0; i < N; i++) for (let j = Math.max(0, i - 2); j <= Math.min(N - 1, i + 2); j++) tr += AS(i, j) * AS(j, i);
  return {mean: N * v + 2 * (N - 1) * c, sd: sqrt(2 * tr)};
}
function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}
function normals(rnd) {
  let spare = null;
  return () => {
    if (spare !== null) { const s = spare; spare = null; return s; }
    let u = 0;
    while (u === 0) u = rnd();
    const v = rnd(), R = sqrt(-2 * log(u));
    spare = R * sin(2 * PI * v);
    return R * cos(2 * PI * v);
  };
}
// simulate days of 390 one-minute prices (true random walk plus noise); return each day's estimates
function simulateDays(days, seed, se, sn, M = 390) {
  const z = normals(mulberry32(seed)), p = new Float64Array(M + 1), out = {rv1: [], rv5: [], rv30: [], ac1: []};
  const rv = q => { let s = 0; for (let t = q; t <= M; t += q) s += (p[t] - p[t - q]) ** 2; return s; };
  for (let d = 0; d < days; d++) {
    let m = 0;
    p[0] = m + sn * z();
    for (let t = 1; t <= M; t++) { m += se * z(); p[t] = m + sn * z(); }
    let ac = 0;
    for (let t = 1; t <= M; t++) { const r = p[t] - p[t - 1]; ac += r * r + (t > 1 ? 2 * r * (p[t - 1] - p[t - 2]) : 0); }
    out.rv1.push(rv(1)); out.rv5.push(rv(5)); out.rv30.push(rv(30)); out.ac1.push(ac);
  }
  return out;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ข้อมูลถี่ไม่ช่วยรู้ drift เพราะผลรวมของผลตอบแทนย่อยยุบเหลือราคาปลายลบราคาต้น SE ของ drift จึงเป็น $\sigma$ และไม่มี $n$ ในสูตร ที่ Sharpe Ratio 0.5 ต้องรอ $(2/0.5)^2=16$ ปีจึงได้ t เท่ากับ 2
  • ข้อมูลถี่ช่วยวัด variance เพราะทุกช่วงให้ตัวอย่างใหม่ RV มี bias $\mu^2/n$ และ SE สัมพัทธ์ราว $\sqrt{2/n}$ ความผันผวนจึงพลาดได้ ±0.713 จุดจากราคาปิดรายวัน และ ±0.081 จุดจากราคาทุก 5 นาที
  • ความคลาดเคลื่อนของราคาที่บันทึกเพิ่ม bias $2(M/q)\sigma_\eta^2$ ซึ่งไม่หายไปตามเวลา ในหุ้น \$50 ตัวอย่าง ความผันผวนพอง 20% ที่ 1 นาที และ 4.3% ที่ 5 นาที
  • ความผิดรวม (MSE) ต่ำสุดที่ $q^*=(4M\sigma_\eta^4/\sigma_\epsilon^4)^{1/3}=4.22$ นาที ทุกความถี่ตั้งแต่ 2.8 ถึง 6.9 นาทีเกินจุดต่ำสุดไม่ถึง 10% และช่วง 5 นาทีให้ 18.27% แทบเท่าจุดต่ำสุดที่ 18.02%
  • บวก $2\sum r_jr_{j-1}$ เข้าไปหัก bias ของความคลาดเคลื่อนออกได้เกือบหมด และต้องเติมช่วงข้ามคืนกลับเสมอ ที่ $f=25\%$ ความผันผวนเปลี่ยนจาก 16.05% เป็น 18.53%

ตอนนี้วัดความผันผวนของวันนี้ได้แล้ว หน้าถัดไปถามต่อว่าจะพยากรณ์มันไปข้างหน้าอย่างไร หน้านั้นจะแสดงว่า EWMA (ค่าเฉลี่ยที่ให้น้ำหนักข้อมูลล่าสุดมากที่สุด) ที่ใช้กันทั้งอุตสาหกรรม มาจากแบบจำลองสองบรรทัดแบบเดียวกับราคาที่บันทึกคลาดเคลื่อน และ GARCH คือ EWMA ที่มีค่าคงที่เพิ่มหนึ่งตัว อ่านต่อที่ EWMA, Kalman filter และ GARCH
