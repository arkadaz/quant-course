5.4 Independence

เมื่อใดจึงคูณโอกาสรายตัวได้ และต้องตรวจอะไรให้ครบก่อนเชื่อ?

หุ้นอยู่คนละอุตสาหกรรม แปลว่าอิสระหรือไม่?

การถือหุ้นเทคโนโลยีกับหุ้นพลังงานอาจลดการกระจุกตัวบางด้าน แต่ไม่ได้พิสูจน์ว่าผลตอบแทนเป็นอิสระ ทั้งคู่อาจตอบสนองต่อดอกเบี้ย สภาพคล่อง หรือภาวะเศรษฐกิจเดียวกัน คำว่า independent ในความน่าจะเป็นมีข้อกำหนดแรงกว่า “ดูไม่ค่อยไปด้วยกัน” มาก

เราจะใช้ตารางสองชุดที่มี marginal เหมือนกัน เพื่อเห็นว่าสิ่งที่ต้องตรวจอยู่ในช่องร่วม แล้วแยกนิยามจริงออกจากเครื่องมือสังเกตอย่าง correlation และ scatter plot

1. ขอบตารางเท่ากัน แต่ข้างในไม่เหมือนกัน

ทั้งสองตารางมี marginal ของ $X$ เท่ากับ $(0.20,0.50,0.30)$ แต่ช่อง $X=-2,Y=\mathrm{down}$ ต่างกัน:

ช่องเดียวที่ไม่ตรงพอหักล้าง independence ในตาราง A แต่จะรับรองตาราง B ต้องตรวจทุกช่อง ซึ่งล้วนเป็นผลคูณของขอบ เช่น $0.30(0.60)=0.18$ ในแถวสุดท้าย ความน่าจะเป็นตามเงื่อนไขของ A เปลี่ยนจาก 0.20 เป็น $0.15/0.40=0.375$ หรือเพิ่มเป็น 1.875 เท่าของเดิม ขณะที่ B ยังเป็น $0.08/0.40=0.20$

2. นิยามที่ใช้ได้กับการแจกแจงทุกชนิด

เหตุการณ์ $A,B$ อิสระเมื่อ $P(A\cap B)=P(A)P(B)$ สำหรับตัวแปรสุ่ม $X,Y$ เราต้องให้ข้อความนี้จริงกับ ทุก เหตุการณ์ที่สร้างจากแต่ละตัวแปร กล่าวคือสำหรับเซตที่วัดได้ $A,B$:

\[ P(X\in A,Y\in B)=P(X\in A)P(Y\in B). \]

วิธีที่เทียบเท่ากันและตรวจผ่านการแจกแจงได้คือ

\[ X\perp Y \quad\Longleftrightarrow\quad F_{X,Y}(x,y)=F_X(x)F_Y(y) \quad\text{ทุก }x,y. \]

สัญลักษณ์ $\perp$ อ่านว่าอิสระ ไม่ใช่ตั้งฉากทางเรขาคณิตในที่นี้ เหตุผลที่ตรวจเพียงเหตุการณ์ “ไม่เกินเกณฑ์” ทุกเกณฑ์ได้ คือ CDF ระบุการแจกแจงทั้งหมด และกรอบสี่เหลี่ยมสร้างได้จากการบวกลบเกณฑ์เหล่านี้

3. ตรวจผ่านหนึ่งเกณฑ์ ไม่ได้แปลว่าผ่านทั้งการแจกแจง

ให้ $X,Y$ มีค่า $0,1,2$ และ joint PMF เป็นตารางไร้หน่วย

\[ p_{X,Y}(i,j)=\frac19 \begin{bmatrix}1&2&0\\2&0&1\\0&1&2\end{bmatrix}, \qquad i,j=0,1,2. \]

ทุกแถวและคอลัมน์รวมได้ $1/3$ ที่เกณฑ์ $(0,0)$ ได้ $F(0,0)=1/9=F_X(0)F_Y(0)$ แต่ที่ $(0,1)$:

\[ F(0,1)=\frac39=\frac13 \ne\frac13\frac23=\frac29. \]

จึงไม่อิสระ การผ่านจุดทดสอบหนึ่งจุดเป็นหลักฐานเฉพาะจุดนั้นเท่านั้น การใช้ข้อมูลจริงที่มีจำกัดยิ่งไม่สามารถพิสูจน์ความเท่ากันทุกเกณฑ์ได้เด็ดขาด เราทำได้เพียงทดสอบความสอดคล้องของสมมติฐานกับข้อมูล

4. ถ้ามี density ให้ตรวจการแยกผลคูณ

สำหรับการแจกแจงที่มี joint PDF ความเป็นอิสระเทียบเท่ากับ

\[ f_{X,Y}(x,y)=f_X(x)f_Y(y) \quad\text{เกือบทุกจุด}. \]

ถ้า CDF เรียบ การหาอนุพันธ์ผสมทำให้เห็นทางเดินได้ชัด:

\[ \begin{aligned} \partial_y\partial_x[F_X(x)F_Y(y)] &=\partial_y[f_X(x)F_Y(y)]\\ &=f_X(x)f_Y(y). \end{aligned} \]

กลับกัน หาก density แยกเป็นผลคูณ เมื่ออินทิเกรตบน $(-\infty,x]\times(-\infty,y]$ ก็ได้ CDF เป็นผลคูณเช่นกัน คำว่า “เกือบทุกจุด” สำคัญ: เปลี่ยนค่า density เพียงจุดเดียวไม่เปลี่ยนความน่าจะเป็น จึงไม่ควรหักล้าง independence จากจุดโดดเดี่ยวที่ไม่มีผลต่ออินทิกรัล แต่ถ้าฟังก์ชันต่อเนื่องในบริเวณและต่างกันที่จุดภายใน ความต่างจะคงอยู่ในย่านที่มีพื้นที่บวก

\[ f_{X\mid Y}(x\mid y) =\frac{f_X(x)f_Y(y)}{f_Y(y)}=f_X(x) \qquad(f_Y(y)\gt0). \]

ดังนั้นข้อมูล $Y$ ไม่เปลี่ยน ทั้งการแจกแจง ของ $X$ สำหรับเกือบทุกค่าเงื่อนไข ไม่ใช่แค่ไม่เปลี่ยน mean หรือ variance

5. ตรวจ density พร้อมตรวจ support

แบบที่หนึ่ง: $f(x,y)=2$ บน $0\le y\le x\le1$ marginal คือ $2x$ และ $2(1-y)$ ดังนั้นที่จุดภายใน $(0.5,0.25)$ ค่า joint เป็น 2 แต่ผลคูณเป็น $4(0.5)(0.75)=1.5$ ทั้งสองฟังก์ชันต่อเนื่องใกล้จุดนี้ จึงต่างกันบนบริเวณ ไม่ใช่เพียงจุดเดียว และไม่อิสระ

มองอีกทาง เหตุการณ์ $X\lt1/4$ กับ $Y\gt3/4$ ต่างมีโอกาส $1/16$ แต่เกิดร่วมกันไม่ได้เพราะ $Y\le X$ จึงมี joint probability 0 ไม่ใช่ผลคูณ $1/256$ วิธีใช้เหตุการณ์นี้ไม่ต้องกังวลเรื่องค่า density ที่จุดเดียว

แบบที่สอง: $g(x,y)=4xy$ บน $0\le x,y\le1$ และเป็นศูนย์นอกสี่เหลี่ยม

\[ \begin{aligned} g_X(x)&=\int_0^14xy\,dy=2x,\\ g_Y(y)&=\int_0^14xy\,dx=2y,\\ g_X(x)g_Y(y)&=4xy=g(x,y),\\ \int_0^12x\,dx&=\int_0^12y\,dy=1. \end{aligned} \]

แบบที่สองจึงอิสระ ตัวอย่างสองแบบนี้มี marginal ของ $X$ เหมือนกัน แต่ marginal ของ $Y$ ไม่เหมือนกัน อย่าสรุปว่าแค่เห็น $2x$ ปรากฏเหมือนกันแล้วการแจกแจงร่วมต้องเหมือนกัน

สำหรับ density อิสระ บริเวณที่เป็นบวกจะเป็น ผลคูณคาร์ทีเซียน ของบริเวณที่ marginal แต่ละตัวเป็นบวก โดยไม่นับความต่างบนเซตพื้นที่ศูนย์ หากบริเวณรายตัวเป็นช่วง จึงได้รูปสี่เหลี่ยม แต่รายตัวอาจมี support หลายช่วงแยกกันได้ ดังนั้นคำว่า “ต้องเป็นสี่เหลี่ยมเดียวเสมอ” แรงเกินไป และแม้ support เป็นสี่เหลี่ยมก็ยังไม่พอพิสูจน์ independence เช่น $f=x+y$ จาก 5.1

6. ภาพช่วยตั้งข้อสงสัย แต่ไม่แทนการพิสูจน์

รูป 5.4a เป็น normal อิสระที่จำลอง 700 คู่ แกนใช้ผลตอบแทนมาตรฐาน ไม่มีหน่วย แม้ป้ายใช้ชื่อ AAPL และ XOM แต่ไม่ใช่ข้อมูลหุ้นจริง การไม่เห็นทิศทางชัดเจนสอดคล้องกับโมเดลที่ใช้สร้างรูป ไม่ได้เป็นเกณฑ์พิสูจน์ independence ของข้อมูลทั่วไป

รูป 5.4b สร้าง $Y=0.75X+\sqrt{1-0.75^2}\,\varepsilon$ โดย $X,\varepsilon$ เป็น standard normal อิสระ รูปร่างเอียงจึงมีสาเหตุจากกลไกที่ระบุ ไม่ใช่แค่ภาพลวงตาจากการสุ่ม

รูป 5.4c กำหนดโอกาสหางรายตัวเท่ากันเป็น $q$ เส้นอิสระคือ $q^2$ ส่วน Gaussian copula ที่ $\rho=0.6$ ให้โอกาสหางร่วมสูงกว่าในช่วงที่วาด จึงไม่ควรแทน joint ด้วยผลคูณโดยไม่มีเงื่อนไข เส้นที่สูงกว่านี้ยังไม่ใช่ข้อสรุปเรื่อง tail dependence ในลิมิต ซึ่งจะดูใน 5.6

รูป 5.4d เทียบ mean คงที่ศูนย์กับ mean $0.65y$ การเห็น mean เปลี่ยนช่วยหักล้าง independence เมื่อค่าคาดหมายมีอยู่ แต่การเห็น mean คงที่ยังรับรองไม่ได้ เพราะข้อมูลอาจเปลี่ยนความกว้างหรือรูปทรงแทน

7. Correlation ศูนย์ยังไม่พอ

ให้ $X\sim\mathrm{Uniform}(-1,1)$ และ $Y=X^2$ จะได้ $E[X]=E[X^3]=0$ จึงมี $\operatorname{Cov}(X,Y)=0$ ทั้งที่รู้ $X$ แล้วรู้ $Y$ แน่นอน และเมื่อรู้ $Y$ ก็รู้ขนาด $|X|$ ตัวแปรจึงพึ่งพากันอย่างชัดเจน

ในตัวอย่างนี้ $E[X\mid Y]=0$ ด้วยสมมาตร แต่ conditional variance เท่ากับ $Y$ จึงเป็นตัวอย่างว่าการไม่เปลี่ยน mean ไม่ได้แปลว่าไม่เปลี่ยน distribution ข้อยกเว้นที่ใช้บ่อยคือ jointly Gaussian: covariance ศูนย์ทำให้อิสระได้ การที่ marginal ทั้งสองเป็น normal อย่างเดียวไม่เพียงพอ

8. หลายตัวแปร: อิสระทุกคู่กับอิสระร่วมไม่เหมือนกัน

\[ \begin{aligned} F_{X_1,\ldots,X_n}(x_1,\ldots,x_n) &=\prod_{i=1}^n F_{X_i}(x_i),\\ f_{X_1,\ldots,X_n}(\mathbf x) &=\prod_{i=1}^n f_{X_i}(x_i) \quad\text{เมื่อมี density}. \end{aligned} \]

นี่คือนิยามและรูป density ของความเป็นอิสระร่วม (mutual independence) ไม่ใช่แค่ตรวจทีละคู่ เช่น สุ่มบิตอิสระ $A,B$ ที่เป็น 0 หรือ 1 เท่ากัน แล้วให้ $C=A\mathbin{\mathrm{XOR}}B$ ตัวแปรทุกคู่เป็นอิสระ แต่เมื่อรู้ $A,B$ จะรู้ $C$ ทันที ทั้งสามไม่อิสระร่วม: โอกาสที่ทั้งสามเป็นศูนย์คือ $1/4$ ไม่ใช่ $1/8$

หากแบ่งเป็นเวกเตอร์สองกลุ่ม $\mathbf U,\mathbf V$ ความเป็นอิสระระหว่างกลุ่มหมายถึง $f_{\mathbf U,\mathbf V}=f_{\mathbf U}f_{\mathbf V}$ ไม่ได้บังคับให้ตัวแปรภายในกลุ่มเดียวกันอิสระกัน และทำให้ $f_{\mathbf V\mid\mathbf U}=f_{\mathbf V}$ เมื่อส่วนหารเป็นบวก

JavaScript: ตรวจทุกช่อง ไม่ใช่เฉพาะช่องที่ลงตัว

function inspect(p) {
  const rows=p.map(row => row.reduce((a,b) => a+b,0));
  const cols=p[0].map((_,j) => p.reduce((s,row) => s+row[j],0));
  let maxError=0;
  p.forEach((row,i) => row.forEach((v,j) => {
    maxError=Math.max(maxError,Math.abs(v-rows[i]*cols[j]));
  }));
  return {rows,cols,maxError};
}
const dependent=inspect([[.05,.15],[.30,.20],[.25,.05]]);
const independent=inspect([[.12,.08],[.30,.20],[.18,.12]]);
const p=[[1,2,0],[2,0,1],[0,1,2]].map(row => row.map(v => v/9));
const trap=inspect(p);
let ex=0,ey=0,exy=0;
const n=10000;
for(let i=0;i<n;i++) {
  const x=-1+(i+.5)*2/n, y=x*x;
  ex+=x/n; ey+=y/n; exy+=x*y/n;
}
const states=[];
for(const a of [0,1]) for(const b of [0,1]) states.push([a,b,a^b]);
const allZero=states.filter(s => s.every(v => v===0)).length/4;
console.log({dependent,independent,trap,
  onePoint:p[0][0],nextPoint:p[0][0]+p[0][1],
  covariance:exy-ex*ey,allZero,
  triangularJoint:0,triangularProduct:(1/16)**2,
  squareJoint:4*.5*.25,squareProduct:(2*.5)*(2*.25)});

ผลคาดหวัง: ความคลาดเคลื่อนสูงสุดของ A คือ 0.07 ส่วน B ใกล้ศูนย์ covariance ของ $(X,X^2)$ ใกล้ศูนย์ และ allZero=0.25 ค่าเหล่านี้ตรวจตัวอย่างที่มีนิยามแน่นอน ไม่ใช่เครื่องตัดสิน independence ของข้อมูลจริงแบบไร้ความคลาดเคลื่อน

    marginal คือ $x+1/2$ และ $y+1/2$ ที่ $(0.2,0.2)$ ผลคูณ 0.49 แต่ joint 0.4 และต่างกันในย่านรอบจุด จึงไม่อิสระ

  3. การปฏิเสธสมมติฐาน independence ไม่ได้จากข้อมูลชุดหนึ่ง พิสูจน์ว่าอิสระหรือไม่?

ใช้สมมติฐานให้ตรงขอบเขต

แบบจำลองจากการทดลองซ้ำอย่างอิสระ เช่น การโยนเหรียญ เป็นพื้นฐานให้การคูณความน่าจะเป็นและการแจกแจงทวินาม แต่ความสะดวกของสูตรไม่ใช่เหตุผลว่าตลาดต้องอิสระ การเปลี่ยนสภาวะตลาด ความสัมพันธ์ไม่เชิงเส้น และการเกิดพร้อมกันในหาง ล้วนถูกซ่อนจาก correlation ค่าเดียวได้
