17.5 Monte Carlo and the Bootstrap

Monte Carlo สุ่มเส้นทางจากแบบจำลองแล้วเฉลี่ย ส่วน bootstrap สุ่มซ้ำจากข้อมูลที่มีอยู่ ทั้งสองให้คำตอบที่ต้องรายงานคู่กับความคลาดจากการสุ่มเสมอ

desk ต้องเสนอราคา Asian call อายุหนึ่งปี หุ้น \$100 strike \$100 ดอกเบี้ย 2% ความผันผวน 30% จ่ายตามราคาเฉลี่ยเลขคณิตของ 12 สิ้นเดือน ไม่มีสูตรปิดแบบ Black–Scholes ให้ใช้ตรง ๆ จึงสุ่ม 10,000 เส้นทางได้ \$7.84 ส่วนต่างที่ desk จะได้คือ \$0.05 ต่อสัญญา เอา \$7.84 ไปเสนอได้เลยไหม

ลองตอบก่อนเปิดเฉลย

ยังไม่ควร ผลจ่ายของแต่ละเส้นทางแกว่งราว \$12.59 จึงได้ standard error $12.59/\sqrt{10{,}000}=\$0.126$ ช่วงเชื่อมั่นประมาณ 95% ภายใต้แบบจำลองคือ \$7.59 ถึง \$8.09 กว้างกว่าส่วนต่างสิบเท่า ถ้าใช้ Asian แบบค่าเฉลี่ยเรขาคณิตเป็นตัวควบคุมกับ 100,000 เส้นทาง ช่วงหดเหลือ \$7.778 ± 0.003 แม่นพอเสนอราคา (ภายใต้แบบจำลองนี้ ไม่ใช่การรับรองราคาตลาด)

ภาพรวมก่อนลงสูตร

ราคาของสัญญาคือค่าคาดหวังของผลจ่ายคิดลด เมื่อหาค่าคาดหวังด้วยสูตรไม่ได้ ก็ประมาณมันด้วยการสุ่มเส้นทางราคาจำนวนมากจากแบบจำลอง คิดผลจ่ายของแต่ละเส้น แล้วเฉลี่ย law of large numbers รับรองว่าค่าเฉลี่ยเข้าใกล้ค่าคาดหวัง และ central limit theorem บอกว่าคลาดได้แค่ไหน นั่นคือ Monte Carlo

Monte Carlo มีจุดอ่อนข้อเดียวแต่หนัก ความคลาดลดตามรากที่สองของจำนวนเส้นทาง แม่นขึ้นสิบเท่าต้องสุ่มร้อยเท่า quant จึงลงแรงกับการลดความแกว่งของสิ่งที่เฉลี่ย ด้วยคู่แฝด antithetic และตัวควบคุม (control variate) มากกว่าการซื้อเครื่องเพิ่ม

ครึ่งหลังของหน้ากลับคำถาม ถ้าไม่มีแบบจำลอง มีแต่ข้อมูลผลตอบแทนในอดีต จะรู้ได้อย่างไรว่าค่าเฉลี่ยหรือ Sharpe ratio ที่คำนวณได้เชื่อได้แค่ไหน bootstrap ตอบด้วยการสุ่มหยิบข้อมูลเดิมซ้ำแบบใส่คืน ทำเหมือนข้อมูลที่มีคือตลาดทั้งตลาด

ขั้นที่ 1 — ค่าคงที่ของก้าวรายเดือน

Geometric Brownian motion เดินทีละเดือนด้วย $S_k=S_{k-1}\exp(\text{drift}+\text{shock}\,Z_k)$ เพื่อตั้งราคา drift ต้องใช้ดอกเบี้ย $r$ ไม่ใช่ผลตอบแทนที่คาดจริง เพราะราคาคือต้นทุนของการสร้างผลจ่ายด้วยหุ้นกับเงินกู้ (ดู risk-neutral measure) คิดสองค่าคงที่นี้ก่อน เพราะทุกเส้นทางใช้ร่วมกัน

\[ \begin{aligned} \Delta t&=\tfrac1{12},\\ r-\tfrac12\sigma^2&=0.02-0.045=-0.025,\\ \text{drift}&=-0.025\,\Delta t=-0.0020833,\\ \text{shock}&=\sigma\sqrt{\Delta t}=\frac{0.30}{\sqrt{12}}=0.0866025,\\ S_k&=S_{k-1}\,e^{-0.0020833+0.0866025\,Z_k}. \end{aligned} \]

drift ของ log ราคาติดลบทั้งที่ดอกเบี้ยเป็นบวก เพราะหัก $\tfrac12\sigma^2$ ที่มาจากความโค้งของ log (Itô's lemma) ค่าเฉลี่ยของราคายังโตตาม $r$ แต่มัธยฐานลดลง ส่วน shock ต่อเดือนใหญ่กว่า drift 41 เท่า ในระดับเดือนความผันผวนจึงคุมเกือบทุกอย่าง

ถ้าคำถามไม่ใช่ราคาแต่เป็น VaR ของพอร์ตจริง ต้องใช้ drift ภายใต้โอกาสจริงแทน การใช้ drift ของการตั้งราคาไปตอบคำถามความเสี่ยงโดยอัตโนมัติเป็นความผิดที่พบบ่อย

ขั้นที่ 2 — เดินหนึ่งเส้นทางด้วยมือ

ก่อนให้เครื่องสุ่มเป็นแสน เดินหนึ่งเส้นทางด้วยมือ ใช้เลขสุ่ม 12 ตัวข้างล่าง แล้วดูว่าเส้นทางนี้จ่ายเท่าไร

\[ \begin{aligned} Z&=(0.42,\ -1.31,\ 0.77,\ -0.55,\\ &\qquad1.08,\ 0.16,\ -0.92,\ 1.44,\\ &\qquad-0.28,\ 0.61,\ -1.05,\ 0.33),\\ S_1&=100\,e^{-0.0020833+0.0866025(0.42)}\\ &=100\,e^{0.034290}=103.488,\\ S_2&=103.488\,e^{-0.115533}=92.197,\\ S_{3..6}&\approx(98.350,\ 93.580,\ 102.541,\ 103.755),\\ S_{7..10}&\approx(95.610,\ 108.083,\ 105.274,\ 110.754),\\ S_{11..12}&\approx(100.917,\ 103.626),\\ A&=\frac{1{,}218.175}{12}=101.5146,\\ X&=e^{-0.02}(101.5146-100)\\ &=0.980199(1.5146)=1.4846. \end{aligned} \]

ราคาเฉลี่ยทั้งปี 101.5146 สูงกว่า strike ผลจ่ายสิ้นปีคือ \$1.5146 คิดลดกลับมาวันนี้ด้วย $e^{-0.02}=0.980199$ ได้ \$1.4846 ราคาสิ้นปี 103.626 สูงกว่าค่าเฉลี่ย ถ้าเป็น European call เส้นทางนี้จะจ่ายมากกว่า \$3.63 เพราะ Asian เฉลี่ยทั้ง 12 จุด

ขั้นที่ 3 — คู่แฝด antithetic: เลขเดิม เครื่องหมายกลับ

ถ้า $Z$ เป็น Normal มาตรฐาน $-Z$ ก็เป็นเหมือนกัน เส้นทางที่ใช้ $-Z_k$ จึงเป็นเส้นทางที่ถูกต้องอีกเส้นโดยไม่ต้องสุ่มเลขใหม่ แล้วตรวจจุดสุดท้ายของเส้นทางแรกด้วยสูตรรวดเดียว

\[ \begin{aligned} S^{B}_{1..4}&\approx(96.227,\ 107.563,\ 100.415,\ 105.095),\\ S^{B}_{5..8}&\approx(95.511,\ 94.001,\ 101.585,\ 89.488),\\ S^{B}_{9..12}&\approx(91.494,\ 86.605,\ 94.652,\ 91.794),\\ A_B&\approx\frac{1{,}154.432}{12}\approx96.2027,\quad X_B=0,\\ \bar X_{\text{pair}}&=\frac{1.4846+0}{2}=0.7423,\\ S_{12}&=100\,e^{12(-0.0020833)+0.0866025\sum Z}\\ &=100\,e^{-0.025+0.0866025(0.70)}\approx103.626. \end{aligned} \]

คู่แฝดลงเมื่อเส้นแรกขึ้น ค่าเฉลี่ย 96.2027 ต่ำกว่า strike จึงจ่ายศูนย์ ค่าเฉลี่ยของคู่คือ \$0.7423 คู่นี้บอกเรื่องสำคัญล่วงหน้า เส้นแรกได้ +1.51 แต่คู่แฝดไม่ได้ −1.51 ได้ 0 เพราะผลจ่ายตัดด้านลบทิ้ง การหักล้างของคู่จึงไม่สมบูรณ์

บรรทัดสุดท้ายใช้ว่า log ราคาเป็นผลบวกของก้าว จุดสุดท้ายจึงขึ้นกับผลรวม $\sum Z=0.70$ อย่างเดียว ได้ 103.626 ตรงกับการเดินทีละเดือน

ขั้นที่ 4 — ราคาประมาณต้องมาคู่กับ standard error

โจทย์ให้อะไรมาบ้าง: ผลจ่ายคิดลดของ 10,000 และ 100,000 เส้นทางอิสระจากโค้ดท้ายหน้า (seed 175) ราคาประมาณคือค่าเฉลี่ย ค่าเฉลี่ยของ $N$ ตัวที่อิสระมี variance $1/N$ ของตัวเดียว (ดู standard error ของตัวประมาณ) ส่วน 1.96 คือจุดตัดของช่วงเชื่อมั่น 95% แบบสองด้าน

\[ \begin{aligned} \widehat C&=\frac1N\sum_{i=1}^{N}X_i,\\ s_X^2&=\frac{1}{N-1}\sum_{i=1}^{N}(X_i-\widehat C)^2,\\ \mathrm{SE}&=\frac{s_X}{\sqrt N},\\ N=10^4&:\ \widehat C\approx7.8388,\ s_X\approx12.586,\\ \mathrm{SE}&\approx0.1259,\quad 1.96\,\mathrm{SE}\approx0.2468,\\ \mathrm{CI}_{95\%}&\approx[7.59,\ 8.09],\\ N=10^5&:\ \widehat C\approx7.8157,\ s_X\approx12.532,\\ \mathrm{SE}&\approx0.0396. \end{aligned} \]

คำตอบ: ผลจ่ายของเส้นทางเดียวแกว่งราว \$12.59 เพราะเกินครึ่งของเส้นทางจ่ายศูนย์ แต่บางเส้นจ่ายหลายสิบดอลลาร์ (รูปข้างล่าง) จาก 10,000 เส้นทางได้ช่วงเชื่อมั่นประมาณ 95% ตั้งแต่ \$7.59 ถึง \$8.09 กว้างกว่าส่วนต่าง \$0.05 สิบเท่า ที่ 100,000 เส้นทางได้ \$7.8157 ± 0.078 ค่าที่แม่นมาก (\$7.7779 จากตัวควบคุมข้างล่าง) อยู่ห่าง 0.96 SE ซึ่งเป็นระยะปกติของการสุ่ม ไม่ใช่ความผิดของโค้ด

ตรวจเองใน 10 วินาที: $12.586/100=0.126$ และ $1.96\times0.126=0.25$ ช่วงจึงกว้างราว ±0.25 รอบ 7.84

ขั้นที่ 5 — กฎรากที่สอง: แม่นขึ้นสองเท่าต้องสุ่มสี่เท่า

SE หารด้วย $\sqrt N$ ไม่ใช่ $N$ ถามกลับว่าอยากให้ SE เล็กลงครึ่งหนึ่ง ต้องเพิ่มเส้นทางเท่าไร และ SE หนึ่งเซนต์ต้องใช้กี่เส้น

\[ \begin{aligned} \frac{s_X}{\sqrt{N_{\text{new}}}}&=\frac12\cdot\frac{s_X}{\sqrt{N_{\text{old}}}},\\ N_{\text{new}}&=4N_{\text{old}},\\ \frac{12.532}{\sqrt{400{,}000}}&=0.0198=\frac{0.0396}{2},\\ \frac{12.53}{\sqrt{N}}&=0.01,\\ N&=\Big(\frac{12.53}{0.01}\Big)^2=1{,}570{,}009. \end{aligned} \]

แม่นขึ้น 10 เท่าต้องสุ่ม 100 เท่า เครื่องที่เร็วขึ้น 10 เท่าจึงให้ความแม่นเพิ่มแค่ $\sqrt{10}=3.16$ เท่า SE หนึ่งเซนต์ต้องใช้ราว 1.57 ล้านเส้นทาง นี่คือเหตุที่ quant ลงแรงกับการลด $s_X$ (ตัวเศษ) แทนการเพิ่ม $N$ (ตัวส่วน)

แล้วทำไมไม่ใช้ตาราง integration แบบที่เรียนในวิชาเลขเชิงตัวเลข Asian นี้มีเลขสุ่ม 12 ตัว จึงต้องเฉลี่ยฟังก์ชันใน 12 มิติ ตารางสม่ำเสมอ $N$ จุดใน $d$ มิติมีระยะห่างระดับ $N^{-1/d}$ แม้ใช้กฎ trapezoid ที่คลาดอันดับสองก็ได้อัตรา $N^{-2/d}$ ซึ่งที่ $d=12$ คือ $N^{-1/6}$ ช้ากว่า $N^{-1/2}$ ของ Monte Carlo มาก และอัตราของ Monte Carlo ไม่ขึ้นกับจำนวนมิติเลย

ขั้นที่ 6 — European และ Asian แบบเรขาคณิตมีสูตรปิด

ก่อนลด variance ต้องมีของที่รู้คำตอบจริงไว้เทียบ European call มี สูตร Black–Scholes ส่วน Asian แบบค่าเฉลี่ยเรขาคณิต $G=(S_1\cdots S_{12})^{1/12}$ มีสูตรเพราะ $\ln G$ คือค่าเฉลี่ยของ log ราคา 12 จุด ซึ่งเป็น Normal ร่วมกันภายใต้ GBM ค่าเฉลี่ยของมันจึงเป็น Normal ด้วย ให้ $\mu_G$ และ $v$ เป็นค่าเฉลี่ยและ variance ของ $\ln G$

\[ \begin{aligned} d_1&=\frac{0.02+0.045}{0.30}\approx0.21667,\quad d_2\approx-0.08333,\\ C_{\text{Eur}}&\approx100(0.585766)-100e^{-0.02}(0.466793)\\ &\approx12.8216,\\ \textstyle\sum_{i,j=1}^{12}\min(i,j)&=650,\\ v&=0.09\cdot\frac{650}{12\cdot144}\approx0.0338542,\\ \mu_G&=\ln100-0.025\big(\tfrac{13}{24}\big)\approx\ln100-0.0135417,\\ d&=\frac{\mu_G-\ln100+v}{\sqrt v}\approx0.110397,\\ C_{\text{geo}}&\approx e^{-0.02}\big[100.33912(0.543953)\\ &\qquad-100(0.470665)\big]\approx7.3645. \end{aligned} \]

variance ของ $\ln G$ คือ $\sigma^2/144$ คูณผลบวกของ covariance ของ Brownian motion ทุกคู่วันสังเกต และ covariance ที่เวลา $t_i$ กับ $t_j$ คือ $\min(t_i,t_j)$ (ดู การคำนวณ $\mathbb E_0[W_{t+s}W_s]$) ผลบวก $\min(i,j)$ ทุกคู่ของ 1 ถึง 12 คือ 650 หารด้วย 12 เพื่อแปลงเป็นปี ส่วนค่าเฉลี่ยของวันสังเกตคือ $\tfrac{1}{12}\sum_k k/12=13/24$ ปี และ $100.33912=100e^{\mu_G-\ln100+v/2}$ คือค่าคาดหวังของ $G$

ค่าเฉลี่ยเรขาคณิตไม่เกินค่าเฉลี่ยเลขคณิตเสมอ ราคา \$7.3645 จึงต่ำกว่า Asian ที่ต้องการ แต่สองตัวขยับตามกันแทบเป๊ะบนทุกเส้นทาง ซึ่งเป็นคุณสมบัติที่ตัวควบคุมต้องการพอดี Asian แบบเลขคณิต (\$7.78) ถูกกว่า European ราว 39% เพราะค่าเฉลี่ยแกว่งน้อยกว่าราคาจุดเดียว

ขั้นที่ 7 — คู่ antithetic ลด variance ได้เท่าไร

ใช้เลขสุ่ม 50,000 ชุดกับคู่แฝด รวม 100,000 เส้นทางเท่าวิธีตรง ถามว่าค่าเฉลี่ยของคู่แกว่งน้อยกว่าเส้นทางอิสระสองเส้นแค่ไหน ใช้สูตร variance ของผลบวกสองตัวที่มี correlation $\rho_-$

\[ \begin{aligned} \bar X_{\text{pair}}&=\tfrac12\big(g(Z)+g(-Z)\big),\\ \operatorname{Var}(\bar X_{\text{pair}})&=\tfrac14\big(2\sigma_X^2+2\rho_-\sigma_X^2\big)\\ &=\tfrac12\sigma_X^2(1+\rho_-),\\ \rho_-&\approx-0.3875,\\ \frac{1}{1+\rho_-}&\approx\frac{1}{0.6125}\approx1.63,\\ \mathrm{SE}_{\text{anti}}&=0.0309,\quad \mathrm{SE}_{\text{plain}}=0.0396. \end{aligned} \]

ถ้าสองเส้นอิสระ ($\rho_-=0$) variance ของค่าเฉลี่ยคือ $\tfrac12\sigma_X^2$ คู่แฝดที่ correlation ติดลบจึงแม่นกว่าด้วยจำนวนเส้นทางเท่ากัน ได้ประโยชน์เท่ากับสุ่มเพิ่ม 1.63 เท่า ตามที่คู่แฝดด้วยมือเตือนไว้ ช่วยได้ไม่มากเพราะผลจ่ายตัดด้านลบทิ้ง correlation ของคู่จึงไปไม่ถึง −1 สำหรับผลจ่ายที่เป็นเส้นตรงตามราคา antithetic ทำได้ดีกว่านี้มาก

ขั้นที่ 8 — control variate: หักความโชคดีของการสุ่มออก

ถ้ามีตัวแปร $Y$ ที่รู้ค่าเฉลี่ยจริง $\nu$ และขยับตามผลจ่าย เมื่อ $\bar Y$ ของการสุ่มชุดนี้สูงกว่า $\nu$ แปลว่าชุดนี้โชคดี และผลจ่ายน่าจะสูงเกินด้วย จึงหักออกตามสัดส่วน $c$ เมื่อ $c$ คงที่ ค่าคาดหวังไม่เปลี่ยน จากนั้นหาค่า $c$ ที่ทำให้ variance ต่ำสุด

\[ \begin{aligned} X^{(c)}&=X-c\,(Y-\nu),\quad \mathbb E[X^{(c)}]=\mathbb E[X],\\ \operatorname{Var}(X^{(c)})&=\operatorname{Var}X-2c\operatorname{Cov}(X,Y)\\ &\quad+c^2\operatorname{Var}Y,\\ c^*&=\frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}Y},\\ \operatorname{Var}(X^{(c^*)})&=(1-\rho^2)\operatorname{Var}X,\\ Y=e^{-rT}S_T,\ \nu=100&:\ c^*\approx\frac{315.46}{954.60}\approx0.3305,\\ \rho&\approx0.8147,\ 1-\rho^2\approx0.3362,\\ \mathrm{SE}&\approx0.0230,\\ Y=e^{-rT}(G-K)^+,\ \nu\approx7.3645&:\ \rho\approx0.99915,\\ \frac{1}{1-\rho^2}&\approx592,\ \mathrm{SE}\approx0.00163,\\ \widehat C&\approx7.7779. \end{aligned} \]

variance เป็นพาราโบลาใน $c$ ตั้ง derivative เป็นศูนย์ได้ $c^*$ ซึ่งเป็นรูปเดียวกับความชันของ OLS regression และ hedge ratio แทนกลับได้ variance ที่เหลือ $1-\rho^2$ ของเดิม ตัวควบคุมจึงดีเท่าที่มันขยับตามผลจ่าย

ตัวแรกคือราคาหุ้นสิ้นปีคิดลด ซึ่งมีค่าคาดหวัง \$100 เท่าราคาเริ่มต้นภายใต้การตั้งราคา correlation ราว 0.81 variance เหลือราว 34% SE 0.0230 ตัวที่สองคือผลจ่ายคิดลดของ Asian แบบเรขาคณิตบนเส้นทางเดียวกัน correlation 0.99915 ลด variance ราว 592 เท่า ได้ \$7.7779 ± 0.0032 เทียบได้กับวิธีตรงราว 59 ล้านเส้นทาง (ไม่ได้แปลว่าเวลาลดลง 592 เท่า เพราะตัวควบคุมก็มีต้นทุนคำนวณ)

โค้ดประมาณ $c$ จากเส้นทางชุดเดียวกับที่หาราคา ซึ่งทำให้เกิดความเอนเล็กน้อยที่หายไปเมื่อ $N$ ใหญ่ ถ้าต้องการรักษาค่าคาดหวังให้ตรงพอดี ให้หา $c$ จากชุดนำร่องแยกแล้วตรึงไว้

ขั้นที่ 9 — bootstrap: สุ่มซ้ำจากข้อมูลที่มี

เปลี่ยนคำถาม กลยุทธ์หนึ่งมีผลตอบแทนห้าวัน −2%, −1%, 0%, 1% และ 3% ค่าเฉลี่ยของมันเชื่อได้แค่ไหน ไม่มีแบบจำลองให้สุ่ม bootstrap จึงทำเหมือนห้าค่านี้คือตลาดทั้งตลาด แล้วสุ่มห้าวันใหม่แบบใส่คืน ชุดที่เป็นไปได้มี $5^5=3{,}125$ แบบเท่า ๆ กัน จึงนับได้ครบโดยไม่ต้องสุ่มจริง

\[ \begin{aligned} \bar R&=\frac{0.01}{5}=0.002,\\ D&=0.022^2+0.012^2+0.002^2\\ &\quad+0.008^2+0.028^2=0.00148,\\ \operatorname{Var}_*(R^*)&=\frac{D}{5}=0.000296,\\ \operatorname{Var}_*(\bar R^*)&=\frac{0.000296}{5}=0.0000592,\\ \mathrm{SE}_*&=\sqrt{0.0000592}\approx0.7694\%,\\ P_*(\bar R^*\le0)&=\frac{1{,}443}{3{,}125}\approx46.18\%. \end{aligned} \]

ตัวอย่าง bootstrap หนึ่งวันคือหยิบหนึ่งในห้าค่าด้วยโอกาสเท่ากัน variance ของมันจึงหารด้วย 5 ไม่ใช่ 4 ค่าเฉลี่ยของห้าวันที่หยิบอิสระมี variance เล็กลงอีก 5 เท่า ได้ SE 0.77% ใหญ่กว่าค่าเฉลี่ย 0.2% เกือบสี่เท่า SE แบบตำรา (หารด้วย $n-1$) คือ 0.860% bootstrap ให้ต่ำกว่านิดหน่อยเพราะใช้ตัวหาร $n$

นับครบ 3,125 ชุด มี 1,443 ชุดที่ค่าเฉลี่ยไม่เป็นบวก ห้าวันจึงบอกแทบไม่ได้ว่ากลยุทธ์ได้กำไร ข้อดีของ bootstrap ไม่ได้อยู่ที่ค่าเฉลี่ย ซึ่งมีสูตร SE อยู่แล้ว แต่อยู่ที่ค่าสถิติที่ไม่มีสูตรง่าย เช่น median, Sharpe ratio, skewness, kurtosis หรือ VaR จากข้อมูล ทำแบบเดียวกันทุกตัว หยิบซ้ำ คำนวณ ดูการกระจาย

ขั้นที่ 10 — bootstrap ทีละวันทำลายวันที่เกาะกลุ่ม

การหยิบทีละวันอิสระถูกต้องเมื่อวันต่าง ๆ อิสระกันจริง แต่ GARCH แสดงว่าวันแรงมักตามด้วยวันแรง ข้อมูลสิบวันข้างล่าง (ตัวเลขสมมติ หน่วย %) มีช่วงปั่นป่วนสามวันติด −3.2, +2.8, −2.5 ถามว่าตัวอย่าง bootstrap ยาวแปดวันมีโอกาสเห็นสามวันนั้นติดกันตามลำดับเท่าไร ถ้าหยิบทีละวัน เทียบกับหยิบเป็นท่อนละสี่วัน

\[ \begin{aligned} R&=(0.2,\ -0.1,\ 0.4,\ -3.2,\ 2.8,\\ &\qquad-2.5,\ 0.3,\ 0.1,\ -0.2,\ 0.4),\\ P_{\text{iid}}&=0.5994\%\approx6\Big(\frac{1}{10}\Big)^3,\\ \ell=4&:\ 10-4+1=7\ \text{blocks},\quad 7^2=49,\\ P_{\text{block}}&=\frac{26}{49}=53.06\%. \end{aligned} \]

เมื่อหยิบทีละวัน ลำดับสามค่านี้เริ่มได้ในหกตำแหน่ง แต่ละตำแหน่งมีโอกาส $1/1{,}000$ รวมคร่าว ๆ 0.6% นับตรงได้ 0.5994% การหยิบอิสระจึงแทบไม่เคยสร้างช่วงปั่นป่วนแบบเดิม เมื่อหยิบเป็นท่อนละสี่วัน มี 7 ท่อนให้เลือก ตัวอย่างแปดวันประกอบจากสองท่อน มี 49 แบบเท่า ๆ กัน ในนั้น 26 แบบมีลำดับสามค่านี้ติดกัน รวม 53.06%

ท่อนยาวเก็บความสัมพันธ์ได้นานกว่า แต่มีท่อนต่างกันให้เลือกน้อยลง กฎที่ใช้ได้จริงคือดู autocorrelation ของข้อมูล (หรือของกำลังสองของมัน) ว่าลากไปถึงกี่วัน แล้วตั้งความยาวท่อนอย่างน้อยเท่านั้น การสุ่มซ้ำไม่สร้างผลตอบแทนรายวันที่แรงกว่าค่าที่มีอยู่ แต่การต่อท่อนใหม่อาจสร้างขาดทุนสะสมหลายวันที่ลึกกว่าเส้นทางเดิมได้

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

รายงานราคาโดยไม่มี SE: \$7.84 จาก 10,000 เส้นทางกับ \$7.78 จากตัวควบคุมดูต่างกันนิดเดียว แต่เลขแรกคลาดได้ ±0.25 ถ้าไม่บอก SE ผู้ฟังแยกไม่ออกว่าตัวเลขไหนเชื่อได้

ใช้ผลตอบแทนที่คาดแทน $r$ ตอนตั้งราคา: Asian แบบเรขาคณิตมีสูตรปิด ใช้ drift 8% แทน 2% ได้ \$9.2451 แทน \$7.3645 แพงไป 25.5% ทั้งที่โค้ดรันผ่านทุกบรรทัด

SE เล็กแล้วคิดว่าราคาถูก: SE วัดแค่ความคลาดจากการสุ่มภายใต้แบบจำลองที่เลือก ถ้า GBM ที่ความผันผวน 30% คงที่ผิด สุ่มพันล้านเส้นทางก็ได้คำตอบที่ผิดอย่างแม่นยำ ต้องทดสอบความไวต่อพารามิเตอร์แยกต่างหาก

ใช้ seed เดียวกันแล้วนับเป็นหลักฐานอิสระ: สุ่มสองครั้งด้วย seed เดียวกันได้ตัวเลขเดิม ความคลาดไม่ได้หายไป แค่ถูกซ่อน

bootstrap กลยุทธ์ที่ดีที่สุดจากหลายร้อยตัว: ถ้าลอง 20 กลยุทธ์ที่ไม่มีฝีมือเลย แต่ละตัวมีโอกาสชนะตลาด 9 ปีจาก 10 แค่ 1.07% แต่โอกาสที่อย่างน้อยหนึ่งตัวทำได้คือ $1-(1-0.0107)^{20}=19.4\%$ bootstrap ของตัวที่ชนะจะบอกว่ามันเก่ง เพราะมันมองไม่เห็นอีก 19 ตัวที่ทิ้งไป ต้องปรับตามการทดสอบหลายครั้ง และระวัง survivorship bias ที่ข้อมูลเหลือแต่ตัวที่รอดมา

ใช้ทำอะไรบนโต๊ะจริง

Monte Carlo ใช้ตั้งราคาสัญญาที่ขึ้นกับเส้นทางหรือหลายสินทรัพย์ โดยรายงาน SE และเลือกตัวควบคุมที่มีสูตรปิดใกล้เคียงที่สุด ฝ่ายความเสี่ยงใช้ Monte Carlo คิด VaR และ ES ของพอร์ตที่มี option โดยสุ่มหลายสินทรัพย์พร้อมกันด้วย Cholesky และตีราคาสัญญาใหม่ในทุกสถานการณ์ ถ้ามีหลายร้อยปัจจัย ก็สุ่มเฉพาะไม่กี่ทิศแรกของ PCA เพื่อลดมิติ

bootstrap ใช้วัดความไม่แน่นอนของค่าสถิติจากข้อมูลย้อนหลังก่อนเชื่อมัน เช่นช่วงเชื่อมั่นของ Sharpe ratio ของกลยุทธ์ หรือของ skewness และ kurtosis ของผลตอบแทนรายวัน ซึ่งไม่มีสูตร SE ที่เชื่อถือได้เมื่อหางหนา

โจทย์ตรวจความเข้าใจ

1. ผลจ่ายคิดลดแกว่ง \$12.53 ถ้าสุ่ม 40,000 เส้นทาง SE เท่าไร และต้องกี่เส้นทางจึงได้ SE หนึ่งเซนต์

เฉลย

$12.53/\sqrt{40{,}000}=12.53/200=\$0.06265$ SE 0.01 ต้องการ $(12.53/0.01)^2=1{,}570{,}009$ เส้นทาง หรือราว 1.57 ล้าน ถ้ามีตัวควบคุมที่ correlation 0.9 variance เหลือ $1-0.81=0.19$ ใช้แค่ราว $0.19\times1{,}570{,}009\approx298{,}300$ เส้นทาง

2. ผลตอบแทนสี่วัน −1%, 0%, 1% และ 2% หา SE ของค่าเฉลี่ยแบบ bootstrap

เฉลย

ค่าเฉลี่ย 0.5% ระยะห่างกำลังสองรวม $0.015^2+0.005^2+0.005^2+0.015^2=0.0005$ variance ของหนึ่งวันที่หยิบคือ $0.0005/4=0.000125$ ของค่าเฉลี่ยสี่วันคือ $0.000125/4=0.00003125$ SE $=0.559\%$ ยังใหญ่กว่าค่าเฉลี่ย

3. ผู้จัดการกองทุน 20 คนไม่มีฝีมือ แต่ละปีชนะตลาดด้วยโอกาส 50% อิสระกัน โอกาสที่คนเก่งที่สุดชนะอย่างน้อย 9 ปีจาก 10 คือเท่าไร ถ้าประมาณด้วย Monte Carlo 10,000 รอบ SE ของคำตอบเท่าไร

เฉลย

คนเดียว $P(X\ge9)=(\binom{10}{9}+\binom{10}{10})/2^{10}=11/1{,}024=0.0107$ อย่างน้อยหนึ่งใน 20 คนคือ $1-(1-0.0107)^{20}=0.1943$ ผลจ่ายของ Monte Carlo แต่ละรอบคือ 1 หรือ 0 variance จึงเป็น $p(1-p)=0.1943(0.8057)=0.1565$ SE $=\sqrt{0.1565/10{,}000}=0.0040$ คำตอบจากการสุ่มจึงควรอยู่ราว $0.194\pm0.008$

// Seeded uniforms (mulberry32) and standard Normals by Box-Muller, so every number can be reproduced
function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}
function normals(seed) {
  const u = mulberry32(seed);
  let spare = null;
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    let a; do { a = u(); } while (a === 0);
    const b = u(), rad = Math.sqrt(-2 * Math.log(a));
    spare = rad * Math.sin(2 * Math.PI * b);
    return rad * Math.cos(2 * Math.PI * b);
  };
}
// Standard Normal CDF (erf series / continued fraction)
function Phi(x) {
  const t = Math.abs(x) / Math.SQRT2;
  let e;
  if (t < 2.5) { let s = 0, term = t; for (let k = 0; k < 200; k++) { const add = term / (2 * k + 1); s += add; if (Math.abs(add) < 1e-17 * s) break; term *= -t * t / (k + 1); } e = 2 / Math.sqrt(Math.PI) * s; }
  else { let f = t; for (let k = 120; k >= 1; k--) f = t + (k / 2) / f; e = 1 - Math.exp(-t * t) / Math.sqrt(Math.PI) / f; }
  return 0.5 * (1 + Math.sign(x) * e);
}
const mean = a => a.reduce((s, x) => s + x, 0) / a.length;
const cov = (a, b) => { const ma = mean(a), mb = mean(b); return a.reduce((s, x, i) => s + (x - ma) * (b[i] - mb), 0) / (a.length - 1); };

// One monthly path: arithmetic average, geometric average, last price
function path(z, {S0, r, sigma, m}) {
  const dt = 1 / m, drift = (r - 0.5 * sigma * sigma) * dt, shock = sigma * Math.sqrt(dt);
  let logS = Math.log(S0), sum = 0, sumLog = 0;
  for (let k = 0; k < m; k++) { logS += drift + shock * z[k]; sum += Math.exp(logS); sumLog += logS; }
  return {avg: sum / m, geo: Math.exp(sumLog / m), last: Math.exp(logS)};
}
function european({S0, K, r, sigma, T}) {
  const d1 = (Math.log(S0 / K) + (r + 0.5 * sigma * sigma) * T) / (sigma * Math.sqrt(T));
  return S0 * Phi(d1) - K * Math.exp(-r * T) * Phi(d1 - sigma * Math.sqrt(T));
}
function geometricAsian({S0, K, r, sigma, m, drift = r}) {
  let meanT = 0, minSum = 0;                       // log G is Normal
  for (let i = 1; i <= m; i++) { meanT += i / m / m; for (let j = 1; j <= m; j++) minSum += Math.min(i, j) / m; }
  const mu = Math.log(S0) + (drift - 0.5 * sigma * sigma) * meanT, v = sigma * sigma * minSum / (m * m);
  const d = (mu - Math.log(K) + v) / Math.sqrt(v);
  return Math.exp(-r) * (Math.exp(mu + v / 2) * Phi(d) - K * Phi(d - Math.sqrt(v)));
}

function control(x, y, known) {
  const c = cov(x, y) / cov(y, y), rho = cov(x, y) / Math.sqrt(cov(x, x) * cov(y, y));
  const adj = x.map((v, i) => v - c * (y[i] - known));
  return {c, rho, price: mean(adj), se: Math.sqrt(cov(adj, adj) / adj.length)};
}
