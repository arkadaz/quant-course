17.5 Monte Carlo and the Bootstrap

คำนวณราคาพร้อมความคลาดเคลื่อน และแยกความไม่แน่นอนของแบบจำลองจากข้อมูล

ต้องประเมินค่า payoff ที่ขึ้นกับราคาเฉลี่ยหลายวัน แต่ไม่มีสูตรสั้นให้กด; ตัวเลขจากการสุ่มหนึ่งครั้งพอหรือไม่?

เฉลย: ไม่พอ—ต้องดูค่าเฉลี่ยและความคลาดของการสุ่ม. Monte Carlo ให้ค่าเฉลี่ยและ standard error ส่วน bootstrap ถามว่าข้อสรุปไวต่อ sample แค่ไหน; ชิมซุปหลายช้อนก็ยังไม่พอถ้าหม้อที่จำลองผิด.

Monte Carlo
การคำนวณโดยสุ่มผลลัพธ์ตามแบบจำลอง ใช้ประมาณราคาหรือความเสี่ยงเมื่อหาค่าเฉลี่ยตรง ๆ ยาก
bootstrap
การสุ่มข้อมูลเดิมกลับมาใช้ซ้ำพร้อมคืนตัวอย่าง ใช้ประเมินความไม่แน่นอนของสถิติจากข้อมูลที่มี
Asian call option
สิทธิที่จ่ายส่วนบวกของราคาเฉลี่ยเหนือราคากำหนด ใช้ผูกผลจ่ายกับหลายวันแทนวันสุดท้ายเพียงวันเดียว
payoff
จำนวนเงินที่สัญญาจ่ายตามผลลัพธ์ของสินทรัพย์ ใช้แปลงเส้นทางราคาเป็นกระแสเงินสด
risk-neutral
มาตรวัดความน่าจะเป็นสำหรับตั้งราคาที่ทำให้ราคาคิดลดมีคุณสมบัติสมดุล ใช้คำนวณมูลค่าสัญญา ไม่ใช่โอกาสจริงที่หุ้นจะขึ้น
Geometric Brownian Motion (GBM)
แบบจำลองราคาบวกที่ log ของราคาเปลี่ยนด้วยส่วนเฉลี่ยและส่วนสุ่มต่อเนื่อง ใช้สร้างเส้นทางราคาภายใต้ parameter คงที่
standard error (SE)
standard deviation ของค่าประมาณเมื่อสุ่มซ้ำ ใช้บอกความแม่นของตัวเลขเฉลี่ย ไม่ใช่ความแกว่งของราคาหุ้น
antithetic variates
การจับคู่ตัวสุ่มกับค่ากลับเครื่องหมาย ใช้ลด variance ของค่าเฉลี่ยเมื่อผลลัพธ์คู่นั้นเคลื่อนไหวสวนกัน
control variates
การหักความคลาดเคลื่อนของตัวแปรที่รู้ค่าเฉลี่ยจริงออกจากผลลัพธ์ ใช้ลด variance ของค่าประมาณ
covariance
คืออะไร: ตัวเลขที่บอกว่าสองสิ่งขยับไปทางเดียวกันแค่ไหน โดยยังมีหน่วยติดมาด้วย ใช้ทำอะไร: เป็นสิ่งที่ต้องรักษาไว้ตอนสุ่มสร้างข้อมูลจำลองหลายตัวพร้อมกัน ทำไมค่ามันอ่านยาก: เพราะหน่วยของมันคือผลคูณของหน่วยทั้งสองตัว ค่า 0.0004 จึงไม่ได้บอกอะไรจนกว่าจะรู้ว่าตัวแปรทั้งสองมีขนาดเท่าไร
correlation
คืออะไร: ตัวเดียวกันที่หารด้วยขนาดของทั้งสองตัวแล้ว จึงอยู่ระหว่าง ถึง เสมอ ใช้ทำอะไร: ใช้พูดคุยและเปรียบเทียบข้ามคู่สินทรัพย์ ทำไมต้องมีทั้งสองตัว: เพราะตัวนี้อ่านง่ายแต่ใช้คำนวณต่อไม่ได้ตรง ๆ การสร้างข้อมูลจำลองต้องกลับไปใช้ตัวที่มีหน่วยเสมอ
block bootstrap
การสุ่มข้อมูลที่ติดกันเป็นช่วง ใช้รักษาความสัมพันธ์ระยะสั้นบางส่วนของอนุกรมเวลาระหว่างการสุ่มซ้ำ

ที่มาที่ไป: ชื่อที่มาจากบ่อนคาสิโน

วิธีนี้ถูกพัฒนาขึ้นที่ Los Alamos ในทศวรรษ 1940 โดย Stanisław Ulam และ John von Neumann ระหว่างงานที่เกี่ยวกับการเคลื่อนที่ของนิวตรอน

Ulam เล่าว่าความคิดมาจากตอนป่วยแล้วเล่นไพ่คนเดียว เขาสงสัยว่าโอกาสชนะเป็นเท่าไร แล้วพบว่าการเล่นซ้ำหลายรอบแล้วนับ ง่ายกว่าการคำนวณตรง ๆ มาก

ชื่อของวิธีมาจากบ่อนคาสิโนในโมนาโก ซึ่งเป็นที่ที่ลุงของ Ulam ชอบไปเล่นพนัน

ส่วนอีกครึ่งของหัวข้อนี้คือเทคนิคที่ Bradley Efron เสนอในปี 1979 ซึ่งใช้ข้อมูลจริงที่มีอยู่มาสุ่มซ้ำ แทนที่จะสุ่มจากแบบจำลอง จึงไม่ต้องสมมติรูปทรงของ distribution เลย

เริ่มจากโจทย์

ของที่โจทย์ให้ — Worked Example — ตั้งราคา Asian call จาก 20,000 เส้นทาง

โจทย์ให้ราคาเริ่มต้น 100 USD, strike 100 USD, อายุหนึ่งปี, rate 3% และ volatility 20% เราเฉลี่ยราคาเฉพาะปลายเดือน 12 จุด แล้วสุ่ม 20,000 เส้นทางด้วย seed ที่ระบุ

ใช้ GBM ภายใต้ risk-neutral โดยสมมติว่าไม่มี dividend ไม่มีต้นทุน และ rate คงที่ สูตรก้าวที่จุดสังเกตเป็นแบบ exact จึงไม่ต้องเพิ่ม error จาก Euler แต่ถ้า GBM เล่าโลกผิด การสุ่มเพิ่มก็ไม่ช่วยแก้ model risk

Monte Carlo และ bootstrap แยก sampling error ออกจาก model risk แต่รายงานของผู้ลงทุนยังต้องเห็นว่าทุนเคยตกจากยอดเท่าไร หัวข้อถัดไปเปลี่ยนผลตอบแทนตามเวลาให้เป็นความเสียหายจากยอดสะสมและกฎลดความเสี่ยงที่ต้องทดสอบนอกชุดข้อมูล

รักษาความต่อเนื่องเมื่อข้อมูลจำวันก่อน

การสุ่มวันเดี่ยวทำลายการเกาะกลุ่มของความผันผวนและความสัมพันธ์ตามเวลา ใช้ block bootstrap โดยเลือกช่วงต่อเนื่องจากข้อมูลฝึกแล้วนำมาต่อกัน ระบุวิธีจัดการปลายข้อมูลและทดสอบหลายความยาวช่วง ไม่มีจำนวนวันสากลที่รับรองว่าถูกทุกตลาด การสุ่มซ้ำไม่สร้างวิกฤตที่ไม่เคยปรากฏในข้อมูล

จาก 20,000 paths และ seed 175 วิธีตรงให้ราคา 5.68185 USD ต่อหุ้น, standard error 0.05905 USD และช่วงประมาณ 95% จาก 5.56611 ถึง 5.79760 USD

เมื่อใช้ control variate coefficient 0.5 ราคาเป็น 5.69791 USD และ standard error ลดเหลือ 0.04264 USD ตรวจเร็ว: error ลดลงประมาณ 28% และช่วง 5.61433 ถึง 5.78148 USD ยังทับกับช่วงเดิม จึงไม่ได้เกิดคำตอบคนละโลก

ถ้าสัญญาจ่ายหลายหุ้น ให้คูณทั้งราคาและ standard error ด้วยจำนวนหุ้นเดียวกัน

แบบจำลองที่ใช้สุ่มแบบจำลองถูกต้องการสุ่มไม่ได้แก้ปัญหาว่าแบบจำลองผิดการสุ่มล้านรอบจากแบบจำลองที่ผิด ก็ยังได้คำตอบที่ผิดอยู่ดี แค่แม่นขึ้น
การใช้ข้อมูลจริงสุ่มซ้ำข้อมูลในอดีตครอบคลุมสิ่งที่จะเกิดวิกฤติที่ยังไม่เคยเกิดไม่อยู่ในข้อมูลวิธีนี้มองไม่เห็นความเสี่ยงที่ไม่เคยปรากฏมาก่อนเลย
แถวกลางเป็นความเข้าใจผิดที่พบบ่อย การสุ่มลดความคลาดเคลื่อนจากการสุ่ม ไม่ได้ลดความผิดของแบบจำลอง
›คำนวณซ้ำได้เปิดโค้ด
import numpy as np
rng=np.random.default_rng(175)
z=rng.normal(size=(20000,12));dt=1/12
s=100*np.exp(np.cumsum((.03-.5*.2**2)*dt+.2*np.sqrt(dt)*z,axis=1))
x=np.exp(-.03)*np.maximum(s.mean(axis=1)-100,0)
y=np.exp(-.03)*s[:,-1]
for name,a in [('plain',x),('control',x-.5*(y-100))]:
 se=a.std(ddof=1)/np.sqrt(len(a));print(name,a.mean(),se,(a.mean()-1.96*se,a.mean()+1.96*se))
assert abs(100*np.exp(.01/12)-100.083368)<1e-6
r=np.array([-.02,-.01,0,.01,.03]);assert abs(r.var()/5-.0000592)<1e-12

  • สร้างผลจ่ายคิดลดแล้วรายงานราคาและ SE จากหน่วยสุ่มที่เป็นอิสระ
  • ตัวควบคุมลดความคลาดเคลื่อนได้เมื่อรู้ค่าเฉลี่ยและมีความสัมพันธ์ที่เหมาะสม
  • bootstrap ประเมินความไม่แน่นอนของข้อมูลที่มี; ข้อมูลตามเวลาต้องรักษาความต่อเนื่อง
