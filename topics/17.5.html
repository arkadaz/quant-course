17.5 Monte Carlo and the Bootstrap

Monte Carlo คือการสุ่มเส้นทางราคาจากแบบจำลองหลาย ๆ เส้นแล้วเฉลี่ย ส่วน bootstrap คือการหยิบซ้ำจากข้อมูลจริงที่มีอยู่ ทั้งสองวิธีได้คำตอบจากการสุ่ม คำตอบจึงคลาดได้ และต้องบอกขนาดความคลาดนั้นทุกครั้ง

ลูกค้าคนหนึ่งขอซื้อสัญญาจากโต๊ะเทรด (desk คือทีมในธนาคารที่ซื้อขายและเสนอราคาสัญญาให้ลูกค้า) สัญญานี้คือ Asian call: อีกหนึ่งปีข้างหน้า ธนาคารจะดูราคาหุ้นตอนสิ้นเดือนทั้ง 12 เดือน แล้วเฉลี่ยเป็นราคาเฉลี่ย $A$ ถ้า $A$ สูงกว่าราคาที่ตกลงกันไว้ $K$ (เรียกว่า strike) ลูกค้าได้ส่วนต่าง $A-K$ ถ้าไม่สูงกว่า ลูกค้าได้ศูนย์ เขียนเป็นสูตรได้ว่าผลจ่ายสิ้นปีคือ $\max(A-K,\,0)$ ลูกค้าต้องจ่ายค่าสัญญาให้โต๊ะตั้งแต่วันนี้ โต๊ะจึงต้องตั้งราคาสัญญาให้ได้ก่อน

ของที่รู้ (ตัวเลขสมมติเพื่อการสอน):

  • ราคาหุ้นวันนี้ $S_0=\$100$
  • strike $K=\$100$
  • อายุสัญญา $T=1$ ปี
  • ดอกเบี้ยเงินฝากต่อปี $r=2\%$
  • ความผันผวนต่อปี $\sigma=30\%$ คือ SD (standard deviation) ของผลตอบแทนหุ้นในหนึ่งปี
  • ส่วนต่างกำไรที่โต๊ะบวกเพิ่มจากราคาทุน \$0.05 ต่อสัญญา

ถ้าสัญญาดูราคาวันสุดท้ายวันเดียว (เรียกว่า European call) จะมีสูตร Black–Scholes ให้คิดราคาได้ทันที แต่ราคาเฉลี่ยของ 12 จุดไม่มีสูตรแบบนั้น โต๊ะจึงให้คอมพิวเตอร์สุ่มเส้นทางราคาหุ้นที่เป็นไปได้ 10,000 เส้น คิดผลจ่ายของแต่ละเส้น แล้วเฉลี่ย ได้ราคา \$7.84 (หน้านี้จะคำนวณตัวเลขนี้ให้ดูในขั้นที่ 4)

โต๊ะเอา \$7.84 บวกส่วนต่าง \$0.05 ไปเสนอลูกค้าได้เลยไหม

ลองตอบก่อนเปิดเฉลย

ยังไม่ควร เพราะ \$7.84 เป็นค่าเฉลี่ยของตัวเลขสุ่ม ถ้าสุ่มใหม่อีกรอบจะได้ตัวเลขอื่น ต้องรู้ก่อนว่ามันคลาดได้แค่ไหน ขนาดความคลาดนี้เรียกว่า standard error (SE) ผลจ่ายของแต่ละเส้นทางแกว่งด้วย SD $s_X=\$12.59$ (หน้านี้คำนวณในขั้นที่ 4) และ SE ของค่าเฉลี่ย $N=10{,}000$ ตัวคือ

\[\begin{aligned} \mathrm{SE}&=\frac{s_X}{\sqrt N}=\frac{12.59}{100}=\$0.126,\\ 1.96\,\mathrm{SE}&=1.96\times0.126=\$0.25. \end{aligned}\]

เลข 1.96 คือระยะที่ครอบ 95% ของรูประฆัง Normal ช่วงที่น่าจะครอบราคาจริงของแบบจำลองด้วยความมั่นใจราว 95% จึงเป็น $7.84\pm0.25$ คือ \$7.59 ถึง \$8.09 ช่วงนี้กว้าง $8.09-7.59=\$0.50$ เท่ากับ $0.50/0.05=10$ เท่าของส่วนต่างกำไร ถ้าเสนอราคาตอนนี้ โต๊ะอาจขาดทุนทั้งที่คิดว่ากำไร

หน้านี้จะลดความคลาดลงด้วยเทคนิคที่เรียกว่า control variate ผลคือ 100,000 เส้นทางให้ \$7.778 ± 0.003 ซึ่งแคบกว่าส่วนต่าง \$0.05 มาก จึงแม่นพอเสนอราคา แต่ระวัง ความแม่นนี้คือความแม่นภายใต้แบบจำลองที่เลือก ไม่ได้รับรองว่าแบบจำลองถูกต้อง

ภาพรวมก่อนลงสูตร

ราคาที่ยุติธรรมของสัญญาแบบนี้คือ “ผลจ่ายเฉลี่ย” คิดลดกลับมาเป็นเงินวันนี้ โดยเฉลี่ยในโลกของการตั้งราคาที่ขั้นที่ 1 จะอธิบาย คำว่าคิดลด (discount) คือการคูณเงินที่จะได้ในอนาคตด้วย $e^{-rT}$ เพราะเงินวันนี้เอาไปฝากได้ดอกเบี้ย เงินหนึ่งดอลลาร์ปีหน้าจึงมีค่าน้อยกว่าหนึ่งดอลลาร์วันนี้ ส่วน “เฉลี่ย” ในที่นี้คือค่าคาดหวัง (expected value) ซึ่งเป็นอินทิกรัลของผลจ่ายคูณ density ของทุกเส้นทางราคาที่เป็นไปได้

ถ้าอินทิกรัลนั้นไม่มีสูตร เราก็ประมาณมันด้วยการทดลองจริง ให้คอมพิวเตอร์สุ่มเส้นทางราคาจากแบบจำลองเป็นหมื่นเป็นแสนเส้น คิดผลจ่ายของแต่ละเส้น แล้วหาค่าเฉลี่ย วิธีนี้เรียกว่า Monte Carlo (ตั้งชื่อตามบ่อนคาสิโนที่โมนาโก เพราะใช้การสุ่มเหมือนทอยลูกเต๋า) มีทฤษฎีสองข้อรองรับ ข้อแรกคือ law of large numbers ซึ่งบอกว่าค่าเฉลี่ยจะเข้าใกล้ค่าคาดหวังเมื่อสุ่มมากพอ ข้อสองคือ central limit theorem ซึ่งบอกว่าค่าเฉลี่ยยังคลาดอยู่เท่าไร

Monte Carlo มีจุดอ่อนใหญ่ข้อเดียว ความคลาดลดลงตามรากที่สองของจำนวนเส้นทาง ถ้าอยากแม่นขึ้น 10 เท่า ต้องสุ่มเพิ่ม $10^2=100$ เท่า quant (คนที่ใช้คณิตศาสตร์ตั้งราคาและวัดความเสี่ยง) จึงไม่ค่อยแก้ปัญหาด้วยการซื้อเครื่องเพิ่ม แต่ลดการแกว่งของตัวที่เอามาเฉลี่ยแทน หน้านี้สอนสองวิธี คือคู่แฝดกลับด้าน (antithetic) และตัวควบคุม (control variate)

ครึ่งหลังของหน้ากลับคำถาม สมมติว่าไม่มีแบบจำลองเลย มีแต่ผลตอบแทนจริงในอดีตไม่กี่วัน เราคำนวณค่าเฉลี่ย หรือ Sharpe ratio (ผลตอบแทนเฉลี่ยหารด้วยความผันผวน) จากข้อมูลนั้นได้ แต่ตัวเลขนั้นเชื่อได้แค่ไหน วิธีที่ตอบคำถามนี้เรียกว่า bootstrap มันทำเหมือนข้อมูลที่มีอยู่คือตลาดทั้งตลาด แล้วหยิบข้อมูลเดิมขึ้นมาใหม่ซ้ำหลาย ๆ รอบแบบใส่คืน

ลำดับของหน้า: ขั้นที่ 1 ถึง 3 เดินเส้นทางราคาด้วยมือ ขั้นที่ 4 และ 5 วัดความคลาดและดูว่ามันลดช้าแค่ไหน ขั้นที่ 6 ถึง 8 ลดความคลาด ขั้นที่ 9 และ 10 คือ bootstrap

ขั้นที่ 1 — ค่าคงที่ของก้าวรายเดือน

ก่อนจะสุ่มเส้นทางได้ เราต้องมีกฎว่าราคาเดือนหนึ่งเดินไปเดือนถัดไปอย่างไร หน้านี้ใช้แบบจำลอง Geometric Brownian motion (GBM) ซึ่งบอกว่าทุกเดือนราคาถูกคูณด้วยตัวคูณสุ่มหนึ่งตัว:

\[S_k=S_{k-1}\exp\big(\text{drift}+\text{shock}\times Z_k\big).\]

ในตัวคูณนี้ $Z_k$ คือเลขสุ่มจาก Normal มาตรฐาน (ค่าเฉลี่ย 0 และ SD 1) หนึ่งตัวต่อหนึ่งเดือน drift คือส่วนที่ log ราคาขยับเท่ากันทุกเดือน ส่วน shock คือขนาดของส่วนสุ่ม สูตรของสองค่านี้มาจากหน้า GBM คือ drift $=(r-\tfrac12\sigma^2)\Delta t$ และ shock $=\sigma\sqrt{\Delta t}$ เมื่อ $\Delta t$ คือความยาวหนึ่งก้าวเป็นปี

ทำไมใช้ดอกเบี้ย $r$ ไม่ใช้ผลตอบแทนที่คาดว่าหุ้นจะให้จริง เพราะเรากำลังตั้งราคา และราคาที่ยุติธรรมคือต้นทุนของการสร้างผลจ่ายแบบเดียวกันขึ้นเองด้วยหุ้นกับเงินกู้ ต้นทุนนี้ไม่ขึ้นกับว่าใครคาดว่าหุ้นจะขึ้นเท่าไร ผลคือเราคิดราคาได้ในโลกสมมติที่หุ้นโตเฉลี่ยเท่าดอกเบี้ย (โลกนี้เรียกว่า risk-neutral measure) ค่าคงที่สองตัวนี้ทุกเส้นทางใช้ร่วมกัน จึงคิดไว้ก่อนครั้งเดียว:

\[ \begin{aligned} \Delta t&=\tfrac1{12},\\ \tfrac12\sigma^2&=\tfrac12(0.30)^2=0.045,\\ r-\tfrac12\sigma^2&=0.02-0.045=-0.025,\\ \text{drift}&=-0.025\times\tfrac1{12}=-0.0020833,\\ \text{shock}&=\sigma\sqrt{\Delta t}=\frac{0.30}{\sqrt{12}}=0.0866025,\\ S_k&=S_{k-1}\,e^{-0.0020833+0.0866025\,Z_k}. \end{aligned} \]

drift ของ log ราคาติดลบ ทั้งที่ดอกเบี้ยเป็นบวก เหตุผลคือการหัก $\tfrac12\sigma^2$ ซึ่งมาจากความโค้งของฟังก์ชัน log (ที่มาอยู่ใน Itô's lemma) ผลที่ได้คือราคาเฉลี่ยยังโตตามดอกเบี้ย $r$ แต่ราคากลาง (median) ลดลงเล็กน้อย เพราะเส้นที่พุ่งขึ้นแรงไม่กี่เส้นดึงค่าเฉลี่ยขึ้นไป

เทียบขนาดกัน $0.0866025/0.0020833\approx41.6$ ส่วนสุ่มในหนึ่งเดือนจึงใหญ่กว่าส่วนที่เดินคงที่ราว 42 เท่า ในระยะหนึ่งเดือน ความผันผวนเป็นตัวกำหนดเกือบทุกอย่าง

ข้อควรระวัง ถ้าคำถามไม่ใช่ “สัญญานี้ราคาเท่าไร” แต่เป็น “พอร์ตจริงอาจขาดทุนเท่าไร” เช่นการคิด VaR (ขาดทุนที่ไม่น่าจะเกิน เช่น 99 วันจาก 100) ต้องใช้ drift ที่เชื่อว่าหุ้นจะโตจริงแทน การหยิบ drift ของการตั้งราคาไปตอบคำถามความเสี่ยงเป็นความผิดที่พบบ่อย

ก่อนให้เครื่องสุ่มเป็นแสนเส้น ลองเดินหนึ่งเส้นทางด้วยมือก่อน จะได้เห็นทุกชิ้นของการคำนวณ เราใช้เลขสุ่ม 12 ตัวที่ตั้งไว้ข้างล่าง (เลือกมาเพื่อการสอน โค้ดท้ายหน้าใช้ชุดเดียวกัน) เดือนละหนึ่งตัว แล้วดูว่าเส้นทางนี้จ่ายเท่าไร

แต่ละเดือนทำสามอย่าง: เอา $Z_k$ คูณ shock บวก drift แล้วยก $e$ ขึ้นกำลังนั้น สุดท้ายคูณกับราคาเดือนก่อน เดือนแรกและเดือนที่สองเขียนให้ดูเต็ม ๆ เดือนที่เหลือทำแบบเดียวกัน:

\[ \begin{aligned} Z&=(0.42,\ -1.31,\ 0.77,\ -0.55,\\ &\qquad1.08,\ 0.16,\ -0.92,\ 1.44,\\ &\qquad-0.28,\ 0.61,\ -1.05,\ 0.33),\\ S_1&=100\,e^{-0.0020833+0.0866025(0.42)}\\ &=100\,e^{0.034290}=103.488,\\ S_2&=103.488\,e^{-0.0020833+0.0866025(-1.31)}\\ &=103.488\,e^{-0.115533}=92.197,\\ S_{3..6}&\approx(98.350,\ 93.580,\ 102.541,\ 103.755),\\ S_{7..10}&\approx(95.610,\ 108.083,\ 105.274,\ 110.754),\\ S_{11..12}&\approx(100.917,\ 103.626). \end{aligned} \]

ได้ราคาครบ 12 เดือนแล้ว ต่อไปคือหาราคาเฉลี่ย $A$ ผลจ่ายสิ้นปี $\max(A-K,0)$ และคิดลดกลับมาวันนี้ด้วย $e^{-rT}=e^{-0.02}=0.980199$ ผลจ่ายคิดลดของเส้นนี้เรียกว่า $X$:

\[ \begin{aligned} A&=\frac{S_1+\cdots+S_{12}}{12}=\frac{1{,}218.175}{12}\\ &=101.5146,\\ X&=e^{-0.02}\max(101.5146-100,\ 0)\\ &=0.980199\times1.5146=\$1.4846. \end{aligned} \]

ราคาเฉลี่ยทั้งปีสูงกว่า strike อยู่ \$1.5146 ลูกค้าจึงได้เงินก้อนนี้ตอนสิ้นปี เงินที่จะได้ในอีกหนึ่งปีมีค่าวันนี้น้อยกว่าเล็กน้อย เพราะถ้ามีเงินวันนี้ก็ฝากได้ดอกเบี้ย 2% จึงต้องคูณด้วย 0.980199 ได้ \$1.4846

เทียบกับ European call ซึ่งดูแค่ราคาวันสุดท้าย เส้นทางนี้จบปีที่ \$103.626 European call จึงจะจ่าย $103.626-100=\$3.626$ (ก่อนคิดลด) เป็น $3.626/1.5146\approx2.4$ เท่าของ Asian เพราะ Asian เอาราคาทั้ง 12 จุดมาเฉลี่ย เดือนที่ราคาต่ำอย่างเดือนที่สอง (\$92.197) จึงดึงค่าเฉลี่ยลง

ขั้นที่ 3 — คู่แฝด antithetic: เลขเดิม เครื่องหมายกลับ

เลขสุ่มแต่ละตัวมีต้นทุน ถ้าใช้เลขชุดเดียวได้สองเส้นทางก็คุ้มกว่า ทำได้เพราะรูประฆัง Normal สมมาตรรอบศูนย์ ถ้า $Z$ เป็น Normal มาตรฐาน $-Z$ ก็เป็น Normal มาตรฐานเหมือนกัน ดังนั้นถ้ากลับเครื่องหมายเลขสุ่มทั้ง 12 ตัวของเส้นที่แล้ว เป็น $-Z_k$ จะได้อีกเส้นทางหนึ่งที่ถูกต้องตามแบบจำลองทุกอย่าง โดยไม่ต้องสุ่มเลขใหม่ เส้นใหม่นี้เรียกว่าคู่แฝด antithetic ขอเรียกเส้นจากขั้นที่ 2 ว่าเส้นเดิม และเรียกคู่แฝดว่าเส้น B (ตัวยก B ในสูตร)

เดินเส้น B แบบเดียวกับขั้นที่ 2 แต่ใช้ $-Z_k$ แล้วหาค่าเฉลี่ยของผลจ่ายของคู่:

\[ \begin{aligned} S^{B}_{1..4}&\approx(96.227,\ 107.563,\ 100.415,\ 105.095),\\ S^{B}_{5..8}&\approx(95.511,\ 94.001,\ 101.585,\ 89.488),\\ S^{B}_{9..12}&\approx(91.494,\ 86.605,\ 94.652,\ 91.794),\\ A_B&\approx\frac{1{,}154.432}{12}\approx96.2027,\\ X_B&=e^{-0.02}\max(96.2027-100,\ 0)=0,\\ \bar X_{\text{pair}}&=\frac{1.4846+0}{2}=\$0.7423. \end{aligned} \]

เดือนไหนเส้นเดิมขึ้น เส้น B ก็ลง เพราะเลขสุ่มกลับเครื่องหมายกัน ราคาเฉลี่ยของเส้น B คือ 96.2027 ต่ำกว่า strike จึงจ่ายศูนย์ ค่าเฉลี่ยของคู่คือ \$0.7423

คู่นี้เตือนเรื่องสำคัญไว้ล่วงหน้า ราคาเฉลี่ยของเส้นเดิมสูงกว่า strike อยู่ $101.5146-100=1.51$ ดอลลาร์ และของเส้น B ต่ำกว่า strike อยู่ $100-96.2027=3.80$ ดอลลาร์ แต่ผลจ่ายของเส้น B ไม่ได้ติดลบตาม มันเป็นศูนย์ เพราะผลจ่าย $\max(A-K,0)$ ตัดส่วนที่ติดลบทิ้ง การหักล้างกันของคู่จึงไม่สมบูรณ์ ขั้นที่ 7 จะวัดว่าเรื่องนี้ทำให้ antithetic ช่วยได้น้อยลงแค่ไหน

ระหว่างนี้ตรวจเลขของขั้นที่ 2 ได้ด้วย ราคาเดือนที่ 12 คือ 100 คูณตัวคูณ 12 ตัว และการคูณ $e$ กำลังต่าง ๆ คือการบวกเลขชี้กำลัง ราคาสุดท้ายจึงขึ้นกับผลรวมของเลขสุ่มอย่างเดียว ผลรวมนั้นคือ $\sum Z_k=0.70$:

\[ \begin{aligned} S_{12}&=100\,e^{12(-0.0020833)+0.0866025\sum Z_k}\\ &=100\,e^{-0.025+0.0866025(0.70)}\\ &=100\,e^{0.0356218}\approx103.626. \end{aligned} \]

ได้ 103.626 ตรงกับที่เดินทีละเดือน เป็นการตรวจที่ใช้บ่อยในโค้ดจริง คิดจุดสุดท้ายแบบรวดเดียวเทียบกับแบบทีละก้าว ถ้าไม่ตรงกันแปลว่ามีที่ผิด

ขั้นที่ 4 — ราคาประมาณต้องมาคู่กับ standard error

ตอนนี้ให้คอมพิวเตอร์ทำแบบขั้นที่ 2 ซ้ำเป็นหมื่นเป็นแสนเส้น แต่ละเส้นใช้เลขสุ่มชุดใหม่ที่ไม่เกี่ยวกับเส้นอื่น (เส้นทางอิสระ) ทุกเส้นให้ผลจ่ายคิดลดหนึ่งตัว เรียกเส้นที่ $i$ ว่า $X_i$ คำถามคือ ราคาที่ได้คือเท่าไร และคลาดได้แค่ไหน

โจทย์ให้อะไรมาบ้าง: ผลจ่ายคิดลด $X_1,\dots,X_N$ จากโค้ดท้ายหน้า (seed 175) ชุดหนึ่ง $N=10{,}000$ เส้น และอีกชุด $N=100{,}000$ เส้น

เครื่องมือ: ราคาประมาณ $\widehat C$ คือค่าเฉลี่ยของ $X_i$ ส่วน $s_X$ คือ SD ของ $X_i$ ซึ่งบอกว่าผลจ่ายของเส้นทางเดียวแกว่งแค่ไหน ค่าเฉลี่ยของ $N$ ตัวที่อิสระกันมี variance เป็น $1/N$ ของตัวเดียว SD ของค่าเฉลี่ยจึงเป็น $1/\sqrt N$ ของตัวเดียว (พิสูจน์ใน standard error ของตัวประมาณ) ตัวเลขนี้คือ SE:

\[ \begin{aligned} \widehat C&=\frac1N\sum_{i=1}^{N}X_i,\\ s_X^2&=\frac{1}{N-1}\sum_{i=1}^{N}(X_i-\widehat C)^2,\\ \mathrm{SE}&=\frac{s_X}{\sqrt N}. \end{aligned} \]

ค่าเฉลี่ยของตัวเลขสุ่มจำนวนมากมีการแจกแจงใกล้รูประฆัง Normal และ 95% ของรูประฆังอยู่ภายในระยะ 1.96 SD จากจุดกลาง ช่วง $\widehat C\pm1.96\,\mathrm{SE}$ จึงเป็นช่วงเชื่อมั่น 95% ของราคา คือถ้าทำการสุ่มทั้งชุดซ้ำ 100 ครั้ง ช่วงแบบนี้จะครอบราคาจริงของแบบจำลองราว 95 ครั้ง

โค้ดวัดได้ $\widehat C\approx7.8388$ และ $s_X\approx12.586$ จาก 10,000 เส้น แทนค่าลงไป:

\[ \begin{aligned} \mathrm{SE}&=\frac{12.586}{\sqrt{10{,}000}}=\frac{12.586}{100}\approx0.1259,\\ 1.96\,\mathrm{SE}&=1.96\times0.1259\approx0.2468,\\ \mathrm{CI}_{95\%}&=7.8388\pm0.2468\\ &\approx[7.59,\ 8.09]. \end{aligned} \]

จาก 100,000 เส้น โค้ดวัดได้ $\widehat C\approx7.8157$ และ $s_X\approx12.532$:

\[ \begin{aligned} \mathrm{SE}&=\frac{12.532}{\sqrt{100{,}000}}=\frac{12.532}{316.23}\approx0.0396,\\ 1.96\,\mathrm{SE}&=1.96\times0.0396\approx0.078. \end{aligned} \]

คำตอบ: ผลจ่ายของเส้นทางเดียวแกว่งมาก SD ราว \$12.59 เทียบกับค่าเฉลี่ยแค่ \$7.84 เหตุผลคือเกินครึ่งของเส้นทางจ่ายศูนย์พอดี แต่บางเส้นจ่ายหลายสิบดอลลาร์ (ดูรูปถัดไป) จาก 10,000 เส้นทาง ช่วงเชื่อมั่น 95% คือ \$7.59 ถึง \$8.09 กว้าง $8.09-7.59=\$0.50$ เท่ากับ $0.50/0.05=10$ เท่าของส่วนต่าง \$0.05 จึงยังเสนอราคาไม่ได้ ที่ 100,000 เส้นทางได้ \$7.8157 ± 0.078

ราคาที่แม่นมาก \$7.7779 (หาได้ในขั้นที่ 8) ต่างจาก \$7.8157 อยู่ $7.8157-7.7779=0.0378$ คิดเป็น $0.0378/0.0396\approx0.96$ SE ระยะไม่ถึง 2 SE แบบนี้เป็นเรื่องปกติของการสุ่ม ไม่ได้แปลว่าโค้ดผิด

ตรวจเองใน 10 วินาที: $12.586/100=0.126$ และ $1.96\times0.126=0.25$ ช่วงจึงกว้างราว ±0.25 รอบ 7.84

ขั้นที่ 5 — กฎรากที่สอง: แม่นขึ้นสองเท่าต้องสุ่มสี่เท่า

สูตร $\mathrm{SE}=s_X/\sqrt N$ หารด้วย $\sqrt N$ ไม่ได้หารด้วย $N$ ข้อนี้มีผลกับงบประมาณเครื่องมาก ลองถามสองคำถาม ข้อแรก ถ้าอยากให้ SE เล็กลงครึ่งหนึ่ง ต้องเพิ่มเส้นทางกี่เท่า ข้อสอง ถ้าอยากได้ SE แค่หนึ่งเซนต์ (\$0.01) ต้องใช้กี่เส้น ให้ $N_{\text{old}}$ คือจำนวนเส้นทางเดิม และ $N_{\text{new}}$ คือจำนวนที่ต้องการ:

\[ \begin{aligned} \frac{s_X}{\sqrt{N_{\text{new}}}}&=\frac12\cdot\frac{s_X}{\sqrt{N_{\text{old}}}},\\ \sqrt{N_{\text{new}}}&=2\sqrt{N_{\text{old}}},\\ N_{\text{new}}&=4N_{\text{old}}. \end{aligned} \]

ตรวจกับตัวเลขจริง สี่เท่าของ 100,000 คือ 400,000 เส้น ใช้ $s_X=12.532$ จากขั้นที่ 4 แล้วแก้หา $N$ ที่ให้ SE หนึ่งเซนต์:

\[ \begin{aligned} \frac{12.532}{\sqrt{400{,}000}}&=\frac{12.532}{632.46}\approx0.0198,\\ \frac{0.0396}{2}&=0.0198,\\ \frac{12.53}{\sqrt{N}}&=0.01,\\ N&=\Big(\frac{12.53}{0.01}\Big)^2=1{,}253^2\\ &=1{,}570{,}009. \end{aligned} \]

กฎทั่วไปคือ ถ้าอยากแม่นขึ้น $k$ เท่า ต้องสุ่มเพิ่ม $k^2$ เท่า แม่นขึ้น 10 เท่าจึงต้องสุ่ม 100 เท่า กลับกัน เครื่องที่เร็วขึ้น 10 เท่าให้ความแม่นเพิ่มแค่ $\sqrt{10}\approx3.16$ เท่า และ SE หนึ่งเซนต์ต้องใช้ราว 1.57 ล้านเส้นทาง นี่คือเหตุที่ quant ลงแรงกับการลด $s_X$ ซึ่งอยู่บนเศษ แทนการเพิ่ม $N$ ซึ่งอยู่ใต้ราก

วิศวกรอาจถามว่า ทำไมไม่ใช้วิธีอินทิกรัลเชิงตัวเลขแบบตาราง เช่นกฎ trapezoid ที่เรียนมา เหตุผลคือจำนวนมิติ ผลจ่ายของ Asian นี้ขึ้นกับเลขสุ่ม 12 ตัว ค่าคาดหวังจึงเป็นอินทิกรัลใน 12 มิติ ($d=12$) ถ้าวางตาราง $N$ จุดเท่า ๆ กันใน $d$ มิติ แต่ละแกนได้จุดแค่ $N^{1/d}$ จุด เช่น หนึ่งล้านจุดได้แกนละ $(10^6)^{1/12}=10^{0.5}\approx3.2$ จุด ซึ่งหยาบมาก

เขียนเป็นอัตราได้ว่า ระยะห่างระหว่างจุดคือ $h\approx N^{-1/d}$ กฎ trapezoid คลาดราว $h^2=N^{-2/d}$ ที่ $d=12$ คือ $N^{-1/6}$ ส่วน Monte Carlo คลาดราว $N^{-1/2}$ ซึ่งลดเร็วกว่ามาก และอัตรา $N^{-1/2}$ นี้ไม่ขึ้นกับจำนวนมิติเลย

ขั้นที่ 6 — European และ Asian แบบเรขาคณิตมีสูตรให้คิดตรง ๆ

วิธีลดความคลาดในขั้นที่ 8 ต้องใช้ “ของที่รู้คำตอบแน่นอน” ไว้เทียบ ขั้นนี้จึงหาราคาที่คิดได้ด้วยสูตรของสัญญาสองแบบที่หน้าตาคล้าย Asian ของเรา แบบแรกคือ European call ซึ่งดูราคาวันสุดท้าย มีสูตร Black–Scholes ให้ใช้ตรง ๆ ในสูตรนี้ $\Phi(x)$ คือโอกาสที่เลข Normal มาตรฐานมีค่าไม่เกิน $x$ ส่วน $\ln(S_0/K)=\ln1=0$ เพราะ $S_0=K$ และ strike คิดลดคือ $Ke^{-rT}=100\times0.980199=98.0199$:

\[ \begin{aligned} d_1&=\frac{\ln(S_0/K)+(r+\tfrac12\sigma^2)T}{\sigma\sqrt T}\\ &=\frac{0+0.02+0.045}{0.30}\approx0.21667,\\ d_2&=d_1-\sigma\sqrt T=0.21667-0.30=-0.08333,\\ C_{\text{Eur}}&=S_0\,\Phi(d_1)-Ke^{-rT}\,\Phi(d_2)\\ &=100(0.585766)-98.0199(0.466793)\\ &\approx12.8216. \end{aligned} \]

แบบที่สองคือ Asian ที่ใช้ค่าเฉลี่ยเรขาคณิต $G=(S_1\cdots S_{12})^{1/12}$ แทนค่าเฉลี่ยเลขคณิต แบบนี้มีสูตรเพราะ log ของมันเป็นค่าเฉลี่ยธรรมดา:

\[\ln G=\tfrac1{12}\big(\ln S_1+\cdots+\ln S_{12}\big).\]

ภายใต้ GBM log ราคาทั้ง 12 จุดเป็น Normal ร่วมกัน และผลบวกของ Normal ร่วมกันก็เป็น Normal ดังนั้น $\ln G$ เป็น Normal เหมือน log ราคาวันสุดท้ายใน Black–Scholes เราจึงใช้สูตรหน้าตาเดียวกันได้ เพียงแต่ต้องรู้ค่าเฉลี่ย $\mu_G$ และ variance $v$ ของ $\ln G$ (สูตร $\mathbb E[(e^Y-K)^+]$ เมื่อ $Y$ เป็น Normal คือแกนเดียวกับที่ใช้พิสูจน์ Black–Scholes) ค่า $\bar t=13/24$ ปีคือค่าเฉลี่ยของวันสังเกตทั้ง 12 วัน และผลบวก 650 มีที่มาในคำอธิบายข้างล่าง:

\[ \begin{aligned} \mu_G&=\ln S_0+(r-\tfrac12\sigma^2)\,\bar t\\ &=\ln100-0.025\times\tfrac{13}{24}\\ &=\ln100-0.0135417,\\ v&=\frac{\sigma^2}{144}\cdot\frac{650}{12}=\frac{0.09\times650}{1{,}728}\\ &\approx0.0338542,\quad \sqrt v\approx0.183995,\\ \mathbb E[G]&=e^{\mu_G+v/2}=100\,e^{0.0033854}\\ &\approx100.33912,\\ d&=\frac{\mu_G-\ln K+v}{\sqrt v}=\frac{0.0203125}{0.183995}\\ &\approx0.110397,\\ C_{\text{geo}}&=e^{-rT}\big[\mathbb E[G]\,\Phi(d)-K\,\Phi(d-\sqrt v)\big]\\ &=0.980199\big[100.33912(0.543953)\\ &\qquad-100(0.470665)\big]\approx7.3645. \end{aligned} \]

ส่วนที่ยากคือ $v$ ซึ่งเป็น variance ของค่าเฉลี่ยของ 12 ตัวที่ไม่อิสระกัน ราคาเดือนที่ 5 กับเดือนที่ 8 ใช้เลขสุ่มของห้าเดือนแรกร่วมกัน จึงขยับตามกัน variance ของค่าเฉลี่ยจึงต้องรวม covariance ทุกคู่ คือ $\tfrac{1}{144}\sum_{i,j}\operatorname{Cov}(\ln S_i,\ln S_j)$ ส่วนสุ่มของ log ราคาที่เวลา $t$ คือ $\sigma W_t$ เมื่อ $W_t$ คือ Brownian motion และ $\operatorname{Cov}(W_s,W_t)=\min(s,t)$ (ที่มาอยู่ใน การคำนวณ $\mathbb E_0[W_{t+s}W_s]$) เพราะสองเวลานี้ใช้ก้าวสุ่มร่วมกันเท่ากับช่วงที่สั้นกว่า ดังนั้น $\operatorname{Cov}(\ln S_i,\ln S_j)=\sigma^2\min(t_i,t_j)$

วันสังเกตคือ $t_i=i/12$ ปี ดังนั้น $\min(t_i,t_j)=\min(i,j)/12$ ผลบวก $\sum_{i,j=1}^{12}\min(i,j)$ นับง่ายถ้ามองว่า $\min(i,j)$ คือจำนวนเลข $k$ ที่ไม่เกินทั้ง $i$ และ $j$ สำหรับ $k$ แต่ละตัวมีคู่ $(i,j)$ ที่ทั้งสองตัวไม่ต่ำกว่า $k$ อยู่ $(13-k)^2$ คู่ ผลบวกจึงเป็น $12^2+11^2+\cdots+1^2=650$ ส่วนค่าเฉลี่ยของวันสังเกตคือ $\bar t=\tfrac1{12}\sum_{k=1}^{12}\tfrac{k}{12}=\tfrac{78}{144}=\tfrac{13}{24}$ ปี

ค่าเฉลี่ยเรขาคณิตไม่เคยเกินค่าเฉลี่ยเลขคณิต ราคา \$7.3645 จึงต่ำกว่า Asian ที่เราต้องการ แต่บนทุกเส้นทาง สองค่าเฉลี่ยนี้ขยับตามกันแทบเป๊ะ และนี่คือคุณสมบัติที่ตัวควบคุมในขั้นที่ 8 ต้องการพอดี

เทียบราคาด้วย Asian แบบเลขคณิต (\$7.78 จากขั้นที่ 8) ถูกกว่า European ราว $1-7.78/12.82\approx39\%$ เพราะค่าเฉลี่ยของ 12 จุดแกว่งน้อยกว่าราคาจุดเดียว และ option ที่ตัวแปรแกว่งน้อยมีค่าน้อยกว่า

ขั้นที่ 7 — คู่ antithetic ลด variance ได้เท่าไร

ขั้นที่ 3 ทำคู่แฝดหนึ่งคู่ด้วยมือ ตอนนี้ให้เครื่องทำ 50,000 คู่ เลขสุ่ม 50,000 ชุดกับคู่แฝดของมันรวมเป็น 100,000 เส้นทาง เท่ากับวิธีตรงในขั้นที่ 4 จึงเทียบกันได้อย่างยุติธรรม คำถามคือ ค่าเฉลี่ยของคู่แฝดแกว่งน้อยกว่าค่าเฉลี่ยของสองเส้นที่สุ่มแยกกันแค่ไหน

ให้ $g(Z)$ คือผลจ่ายคิดลดของเส้นทางที่สร้างจากเลขสุ่มชุด $Z$ ให้ $\sigma_X$ คือ SD ของผลจ่ายหนึ่งเส้น (ราว 12.53 จากขั้นที่ 4) และให้ $\rho_-$ คือ correlation ระหว่าง $g(Z)$ กับ $g(-Z)$ เราใช้สูตร variance ของผลบวกสองตัว $\operatorname{Var}(U+V)=\operatorname{Var}U+\operatorname{Var}V+2\operatorname{Cov}(U,V)$ โดย $\operatorname{Cov}=\rho_-\sigma_X^2$:

\[ \begin{aligned} \bar X_{\text{pair}}&=\tfrac12\big(g(Z)+g(-Z)\big),\\ \operatorname{Var}(\bar X_{\text{pair}})&=\tfrac14\big(\sigma_X^2+\sigma_X^2+2\rho_-\sigma_X^2\big)\\ &=\tfrac12\sigma_X^2(1+\rho_-). \end{aligned} \]

โค้ดวัด correlation ของคู่ได้ $\rho_-\approx-0.3875$ และวัด SD ของค่าเฉลี่ยคู่ได้ 6.918 จาก 50,000 คู่ แทนค่า:

\[ \begin{aligned} 1+\rho_-&=1-0.3875=0.6125,\\ \frac{1}{1+\rho_-}&=\frac{1}{0.6125}\approx1.63,\\ \mathrm{SE}_{\text{anti}}&=\frac{6.918}{\sqrt{50{,}000}}=\frac{6.918}{223.61}\approx0.0309,\\ \mathrm{SE}_{\text{plain}}&=0.0396. \end{aligned} \]

ถ้าสองเส้นสุ่มแยกกัน ($\rho_-=0$) variance ของค่าเฉลี่ยคือ $\tfrac12\sigma_X^2$ คู่แฝดมี $\rho_-$ ติดลบ วงเล็บ $(1+\rho_-)$ จึงเล็กกว่า 1 และค่าเฉลี่ยคู่แกว่งน้อยกว่า ทั้งที่ใช้จำนวนเส้นทางเท่ากัน variance ลดลงเหลือ 0.6125 เท่า ได้ประโยชน์เท่ากับสุ่มเพิ่ม 1.63 เท่า ราคาที่โค้ดได้คือ \$7.7821

ตรวจสูตรกับตัวเลขที่วัดได้ สูตรทำนายว่า SD ของค่าเฉลี่ยคู่คือ $\sigma_X\sqrt{(1+\rho_-)/2}=12.53\sqrt{0.30625}\approx6.93$ ใกล้กับ 6.918 ที่วัดได้

ช่วยได้ไม่มาก ตามที่คู่แฝดด้วยมือในขั้นที่ 3 เตือนไว้ ผลจ่าย $\max(A-K,0)$ ตัดด้านลบทิ้ง เมื่อเส้นหนึ่งได้มาก คู่ของมันไม่ได้เสียเท่ากัน แค่ได้ศูนย์ correlation ของคู่จึงไปไม่ถึง −1 ถ้าผลจ่ายเป็นเส้นตรงตามราคา เช่นถือหุ้นเฉย ๆ correlation ของคู่จะใกล้ −1 มาก และ antithetic ช่วยได้มากกว่านี้หลายเท่า

ขั้นที่ 8 — control variate: หักความโชคดีของการสุ่มออก

นี่คือวิธีที่ช่วยได้มากที่สุดในหน้านี้ ความคิดเป็นแบบนี้ สมมติว่าบนเส้นทางเดียวกัน เราคำนวณอีกค่าหนึ่ง $Y$ ได้ด้วย และรู้ค่าเฉลี่ยจริงของ $Y$ จากสูตร เรียกค่านั้นว่า $\nu$ ถ้า $Y$ ขยับขึ้นลงตามผลจ่าย $X$ แล้วการสุ่มรอบนี้ได้ค่าเฉลี่ยของ $Y$ สูงกว่า $\nu$ แปลว่ารอบนี้สุ่มได้เส้นทางที่ราคาสูงเกินจริงมาเยอะ ผลจ่ายเฉลี่ยของ $X$ ก็น่าจะสูงเกินด้วย เราจึงหักส่วนเกินนั้นออกเป็นสัดส่วน $c$

การหักนี้ไม่ทำให้ราคาเพี้ยน เพราะค่าเฉลี่ยของ $Y-\nu$ เป็นศูนย์พอดี เมื่อ $c$ เป็นค่าคงที่ ค่าคาดหวังจึงไม่เปลี่ยน งานที่เหลือคือเลือก $c$ ให้ variance ต่ำที่สุด เขียน variance ของตัวใหม่ด้วยสูตร variance ของผลต่าง:

\[ \begin{aligned} X^{(c)}&=X-c\,(Y-\nu),\\ \mathbb E[X^{(c)}]&=\mathbb E[X]-c\cdot0=\mathbb E[X],\\ \operatorname{Var}(X^{(c)})&=\operatorname{Var}X-2c\operatorname{Cov}(X,Y)\\ &\quad+c^2\operatorname{Var}Y. \end{aligned} \]

variance นี้เป็นพาราโบลาหงายใน $c$ จุดต่ำสุดคือจุดที่ derivative เป็นศูนย์ แล้วแทนกลับเพื่อดูว่าเหลือ variance เท่าไร โดยใช้ $\rho=\operatorname{Cov}(X,Y)/\sqrt{\operatorname{Var}X\operatorname{Var}Y}$:

\[ \begin{aligned} -2\operatorname{Cov}(X,Y)+2c\operatorname{Var}Y&=0,\\ c^*&=\frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}Y},\\ \operatorname{Var}(X^{(c^*)})&=\operatorname{Var}X-\frac{\operatorname{Cov}(X,Y)^2}{\operatorname{Var}Y}\\ &=(1-\rho^2)\operatorname{Var}X. \end{aligned} \]

$c^*$ มีรูปเดียวกับความชันของ OLS regression และ hedge ratio ซึ่งไม่ใช่เรื่องบังเอิญ ทั้งสามเรื่องคือการหาว่าต้องหักตัวแปรหนึ่งออกเท่าไรจึงเหลือส่วนที่แกว่งน้อยที่สุด ผลลัพธ์บอกว่า variance เหลือ $1-\rho^2$ ของเดิม ตัวควบคุมจึงดีเท่าที่มันขยับตามผลจ่าย ถ้า $\rho=0.9$ เหลือ $1-0.81=19\%$ ถ้า $\rho=0.999$ เหลือแค่ราว $0.2\%$

ตัวควบคุมตัวแรก: ราคาหุ้นสิ้นปีคิดลด $Y=e^{-rT}S_T$ ในโลกของการตั้งราคา หุ้นโตเฉลี่ยเท่าดอกเบี้ย พอคิดลดด้วยดอกเบี้ยเดียวกันจึงได้ค่าเฉลี่ยกลับมาเท่าราคาวันนี้พอดี $\nu=S_0=\$100$ โค้ดวัดจาก 100,000 เส้นทางได้ $\operatorname{Cov}(X,Y)\approx315.46$ และ $\operatorname{Var}Y\approx954.60$:

\[ \begin{aligned} c^*&=\frac{315.46}{954.60}\approx0.3305,\\ \rho&\approx0.8147,\quad 1-\rho^2\approx0.3362,\\ \mathrm{SE}&=0.0396\sqrt{0.3362}\approx0.0230. \end{aligned} \]

ตัวควบคุมตัวที่สอง: ผลจ่ายคิดลดของ Asian แบบเรขาคณิตบนเส้นทางเดียวกัน $Y=e^{-rT}\max(G-K,0)$ ค่าเฉลี่ยจริงของมันคือราคาจากสูตรในขั้นที่ 6 $\nu\approx7.3645$ โค้ดวัด correlation ได้ $\rho\approx0.999155$:

\[ \begin{aligned} 1-\rho^2&\approx0.001690,\\ \frac{1}{1-\rho^2}&\approx592,\\ \mathrm{SE}&=\frac{0.0396}{\sqrt{592}}=\frac{0.0396}{24.33}\approx0.00163,\\ \widehat C&\approx7.7779. \end{aligned} \]

ตัวแรกมี correlation ราว 0.81 เพราะราคาสิ้นปีบอกได้แค่บางส่วนว่าค่าเฉลี่ยทั้งปีเป็นอย่างไร variance จึงเหลือราว 34% และ SE ลดจาก 0.0396 เหลือ 0.0230 ราคาที่ได้คือ \$7.7924

ตัวที่สองมี correlation 0.999155 เพราะค่าเฉลี่ยเรขาคณิตกับเลขคณิตของเส้นเดียวกันแทบเป็นตัวเดียวกัน variance ลดลงราว 592 เท่า ได้ราคา $7.7779\pm1.96\times0.00163=7.7779\pm0.0032$ ถ้าจะได้ความแม่นเท่านี้ด้วยวิธีตรง ต้องใช้ $100{,}000\times592\approx59$ ล้านเส้นทาง แต่ไม่ได้แปลว่าเวลาคำนวณลดลง 592 เท่า เพราะการคำนวณตัวควบคุมบนทุกเส้นก็ใช้เวลาเหมือนกัน

ข้อระวังเล็กน้อย โค้ดหา $c$ จากเส้นทางชุดเดียวกับที่ใช้หาราคา ทำให้ราคาเอนไปเล็กน้อย ความเอนนี้หายไปเมื่อ $N$ ใหญ่ ถ้าต้องการให้ค่าคาดหวังตรงพอดี ให้รันชุดนำร่องสั้น ๆ แยกต่างหากเพื่อหา $c$ แล้วตรึงค่านั้นไว้ตอนรันจริง

ขั้นที่ 9 — bootstrap: สุ่มซ้ำจากข้อมูลที่มี

ตอนนี้เปลี่ยนคำถาม ไม่มีสัญญาให้ตั้งราคาแล้ว และไม่มีแบบจำลองให้สุ่ม มีแต่ข้อมูลจริง สมมติว่าทีมหนึ่งทดลองกลยุทธ์ใหม่ (กฎการซื้อขายชุดหนึ่ง) มาห้าวัน ได้ผลตอบแทนรายวัน (ตัวเลขสมมติ):

\[R=(-2\%,\ -1\%,\ 0\%,\ 1\%,\ 3\%).\]

ค่าเฉลี่ยคือ $\bar R=(-2-1+0+1+3)\%/5=1\%/5=0.2\%$ ต่อวัน คำถามคือ ตัวเลข 0.2% นี้เชื่อได้แค่ไหน ถ้าได้ข้อมูลห้าวันชุดใหม่ ค่าเฉลี่ยจะแกว่งไปได้ไกลเท่าไร

bootstrap ตอบแบบนี้ ทำเหมือนว่าห้าค่านี้คือทุกอย่างที่ตลาดให้ได้ แล้วสร้าง “ข้อมูลห้าวันชุดใหม่” ด้วยการหยิบหนึ่งในห้าค่าขึ้นมา จดไว้ ใส่คืน แล้วหยิบใหม่ จนครบห้าครั้ง เพราะใส่คืนทุกครั้ง ค่าเดียวกันจึงถูกหยิบซ้ำได้ และบางค่าอาจไม่ถูกหยิบเลย หยิบแต่ละครั้งมีทางเลือก 5 ทาง ชุดใหม่ที่เป็นไปได้จึงมี $5^5=3{,}125$ แบบ ทุกแบบมีโอกาสเท่ากัน จำนวนนี้น้อยพอที่จะนับครบทุกแบบได้โดยไม่ต้องสุ่มจริง

เครื่องหมาย $*$ แปลว่า “คิดในโลกของ bootstrap” เช่น $R^*$ คือค่าที่หยิบได้หนึ่งครั้ง และ $\bar R^*$ คือค่าเฉลี่ยของชุดใหม่หนึ่งชุด ให้ $D$ คือผลบวกของระยะห่างกำลังสองจากค่าเฉลี่ย (ระยะห่างคือ −0.022, −0.012, −0.002, 0.008 และ 0.028):

\[ \begin{aligned} D&=0.022^2+0.012^2+0.002^2\\ &\quad+0.008^2+0.028^2=0.00148,\\ \operatorname{Var}_*(R^*)&=\frac{D}{5}=0.000296,\\ \operatorname{Var}_*(\bar R^*)&=\frac{0.000296}{5}=0.0000592,\\ \mathrm{SE}_*&=\sqrt{0.0000592}\approx0.7694\%,\\ P_*(\bar R^*\le0)&=\frac{1{,}443}{3{,}125}\approx46.18\%. \end{aligned} \]

การหยิบหนึ่งครั้งคือการเลือกหนึ่งในห้าค่าด้วยโอกาส $1/5$ เท่ากัน นี่คือการแจกแจงที่รู้ครบทุกค่า ไม่ใช่การประมาณจากตัวอย่าง variance ของมันจึงหาร $D$ ด้วย 5 ไม่ใช่ 4 ต่อมา ค่าเฉลี่ยของห้าครั้งที่หยิบอิสระกันมี variance เล็กลงอีก 5 เท่า ด้วยเหตุผลเดียวกับ SE ในขั้นที่ 4

ผลคือ SE 0.77% ใหญ่กว่าค่าเฉลี่ย 0.2% ถึง $0.77/0.2\approx3.8$ เท่า ถ้าใช้สูตร SE แบบตำราที่หารด้วย $n-1=4$ จะได้ $\sqrt{0.00148/4/5}=\sqrt{0.000074}\approx0.860\%$ bootstrap ได้ต่ำกว่านิดหน่อยเพราะหารด้วย $n=5$

โอกาส 46.18% มาจากการนับครบทั้ง 3,125 ชุด (โค้ดท้ายหน้านับให้) มี 1,443 ชุดที่ค่าเฉลี่ยไม่เป็นบวก คิดเป็นเกือบครึ่ง ห้าวันจึงบอกแทบไม่ได้เลยว่ากลยุทธ์นี้ทำกำไรจริง

สำหรับค่าเฉลี่ย เรามีสูตร SE อยู่แล้ว ข้อดีจริงของ bootstrap อยู่ที่ค่าสถิติที่ไม่มีสูตรง่าย เช่น median, Sharpe ratio, skewness (ความเบ้ของการแจกแจง), kurtosis (ความหนาของหาง) หรือ VaR ที่คิดจากข้อมูล ทุกตัวใช้ขั้นตอนเดียวกัน หยิบซ้ำแบบใส่คืน คำนวณค่าสถิติของแต่ละชุด แล้วดูว่ามันกระจายกว้างแค่ไหน

ขั้นที่ 10 — bootstrap ทีละวันทำลายวันที่เกาะกลุ่ม

ขั้นที่ 9 หยิบทีละวันอย่างอิสระ วิธีนี้ถูกต้องเฉพาะเมื่อแต่ละวันไม่เกี่ยวกันจริง แต่ตลาดจริงไม่เป็นแบบนั้น แบบจำลอง GARCH (แบบจำลองที่ความผันผวนวันนี้ขึ้นกับความแรงของวันก่อน ๆ) แสดงว่าวันที่ราคาขยับแรงมักตามมาด้วยวันแรงอีก วันแรงจึงมักมาเป็นกลุ่ม ถ้า bootstrap หยิบทีละวัน กลุ่มนี้จะถูกกระจายออกจากกัน และเราจะประเมินความเสี่ยงของช่วงตลาดปั่นป่วนต่ำเกินจริง

ลองวัดเรื่องนี้เป็นตัวเลข ข้อมูลสิบวันข้างล่างเป็นตัวเลขสมมติ หน่วย % วันที่ 4, 5 และ 6 เป็นช่วงปั่นป่วนติดกัน คือ −3.2, +2.8 และ −2.5:

\[ \begin{aligned} R&=(0.2,\ -0.1,\ 0.4,\ -3.2,\ 2.8,\\ &\qquad-2.5,\ 0.3,\ 0.1,\ -0.2,\ 0.4). \end{aligned} \]

สร้างข้อมูลชุดใหม่ยาวแปดวัน ถามว่ามีโอกาสเท่าไรที่สามวันปั่นป่วนนี้จะโผล่มาติดกันตามลำดับเดิม เทียบสองวิธี วิธีแรกหยิบทีละวัน วิธีที่สองหยิบเป็นท่อนของวันติดกัน ท่อนละ $\ell=4$ วัน

หยิบทีละวัน: แต่ละครั้งได้วันที่ต้องการด้วยโอกาส $1/10$ สามวันที่ถูกต้องเรียงกันในตำแหน่งที่กำหนดจึงมีโอกาส $(1/10)^3$ ลำดับยาวสามวันเริ่มได้ที่ตำแหน่ง 1 ถึง 6 ของแปดวัน รวม $8-3+1=6$ ตำแหน่ง บวกกันได้ค่าประมาณ แล้วหักกรณีที่ลำดับโผล่สองครั้งซึ่งถูกนับซ้ำ สองครั้งนั้นต้องไม่ทับกัน (สามค่านี้ต่างกันหมด) คู่ตำแหน่งเริ่มที่เป็นไปได้คือ (1,4), (1,5), (1,6), (2,5), (2,6) และ (3,6) รวม 6 คู่ คู่ละโอกาส $(1/10)^6=10^{-6}$:

\[ \begin{aligned} P_{\text{iid}}&\approx6\Big(\frac{1}{10}\Big)^3=0.6\%,\\ P_{\text{iid}}&=0.006-6\times10^{-6}=0.5994\%. \end{aligned} \]

หยิบเป็นท่อน: ท่อนยาว 4 วันเริ่มได้ที่วันที่ 1 ถึง 7 จึงมี $n_{\text{block}}$ ท่อนให้เลือก ข้อมูลแปดวันคือสองท่อนต่อกัน แต่ละท่อนเลือกอิสระ จึงมี $n_{\text{pair}}$ แบบที่โอกาสเท่ากัน แล้วนับแบบที่มีสามวันปั่นป่วนติดกัน $n_{\text{hit}}$ (วิธีนับอยู่ใต้สูตร):

\[ \begin{aligned} n_{\text{block}}&=10-4+1=7,\\ n_{\text{pair}}&=7\times7=49,\\ n_{\text{hit}}&=14+14-4+2=26,\\ P_{\text{block}}&=\frac{26}{49}\approx53.06\%. \end{aligned} \]

วิธีนับ $n_{\text{hit}}$: ท่อนที่ครอบวันที่ 4 ถึง 6 ไว้ทั้งหมดมีสองท่อน คือท่อนที่เริ่มวันที่ 3 (วันที่ 3–6) และท่อนที่เริ่มวันที่ 4 (วันที่ 4–7) ถ้าท่อนแรกเป็นหนึ่งในสองท่อนนี้ ท่อนที่สองเป็นอะไรก็ได้ ได้ $2\times7=14$ แบบ ถ้าท่อนที่สองเป็นหนึ่งในสองท่อนนี้ก็ได้อีก 14 แบบ แต่กรณีที่ทั้งสองท่อนเป็นท่อนพวกนี้ ($2\times2=4$ แบบ) ถูกนับสองครั้ง จึงหักออก 4 นอกจากนี้ลำดับยังข้ามรอยต่อได้อีก 2 แบบ คือท่อน 2–5 ต่อด้วยท่อน 6–9 และท่อน 1–4 ต่อด้วยท่อน 5–8

ผลต่างใหญ่มาก หยิบทีละวันเห็นช่วงปั่นป่วนแบบเดิมแค่ราว 6 ครั้งในพันครั้ง หยิบเป็นท่อนเห็นเกินครึ่ง การหยิบทีละวันจึงแทบไม่เคยสร้างช่วงตลาดปั่นป่วนแบบที่เกิดจริงขึ้นมาใหม่

จะตั้งท่อนยาวเท่าไร ท่อนยาวเก็บความต่อเนื่องได้นานกว่า แต่มีท่อนที่ต่างกันให้เลือกน้อยลง ผลจึงแกว่งมากขึ้น กฎที่ใช้ได้จริงคือดู autocorrelation (correlation ของข้อมูลกับตัวเองเมื่อเลื่อนไปกี่วัน) ของผลตอบแทน หรือของผลตอบแทนยกกำลังสอง ว่ายังไม่หายไปจนถึงกี่วัน แล้วตั้งความยาวท่อนอย่างน้อยเท่านั้น

ข้อสังเกตสุดท้าย การหยิบซ้ำไม่มีทางสร้างผลตอบแทนรายวันที่แรงกว่าค่าที่มีในข้อมูล แต่การต่อท่อนแบบใหม่อาจสร้างขาดทุนสะสมหลายวันที่ลึกกว่าที่เคยเกิดในข้อมูลจริงได้

ความผิดที่ให้คำตอบผิดแบบเงียบ ๆ

รายงานราคาโดยไม่บอก SE: ตัวเลขเดี่ยว ๆ ไม่บอกว่าเชื่อได้แค่ไหน \$7.84 จาก 10,000 เส้นทาง กับ \$7.78 จากตัวควบคุม ดูต่างกันนิดเดียว แต่ SE ต่างกันถึง $0.126/0.00163\approx77$ เท่า:

\[\begin{aligned} \widehat C_{\text{plain}}&=7.84\pm1.96(0.126)\\ &=7.84\pm0.25,\\ \widehat C_{\text{control}}&=7.778\pm1.96(0.00163)\\ &=7.778\pm0.003. \end{aligned}\]

ถ้าไม่บอก SE ผู้ฟังแยกไม่ออกว่าตัวเลขไหนใช้เสนอราคาได้

ใช้ผลตอบแทนที่คาดว่าหุ้นจะให้ แทนดอกเบี้ย $r$ ตอนตั้งราคา: โค้ดรันผ่านทุกบรรทัด แต่ราคาผิด ลองกับ Asian แบบเรขาคณิตซึ่งมีสูตร ถ้าให้หุ้นโต 8% ต่อปีแทน 2% (แต่ยังคิดลดด้วย 2%) ราคาจากสูตรของขั้นที่ 6 เปลี่ยนจาก \$7.3645 เป็น \$9.2451 (โค้ดท้ายหน้าคิดให้) แพงเกินไป $9.2451/7.3645-1\approx25.5\%$

เห็น SE เล็กแล้วคิดว่าราคาถูก: SE วัดแค่ความคลาดจากการสุ่ม ภายในแบบจำลองที่เลือกไว้ ถ้าตัวแบบจำลองผิด เช่นความผันผวนจริงไม่ได้คงที่ 30% ต่อให้สุ่มพันล้านเส้นทาง ก็ได้คำตอบที่ผิดอย่างแม่นยำ ต้องทดสอบแยกต่างหากว่าราคาไวต่อค่าที่สมมติแค่ไหน เช่นเปลี่ยน $\sigma$ เป็น 25% และ 35% แล้วดูว่าราคาขยับเท่าไร

รันสองครั้งด้วย seed เดียวกัน แล้วนับว่าเป็นหลักฐานสองชิ้น: seed เดียวกันให้เลขสุ่มชุดเดิมทุกตัว จึงได้คำตอบเดิมเป๊ะ ดูเหมือนผลนิ่ง แต่ความคลาดไม่ได้หายไป แค่ถูกซ่อน ถ้าจะดูว่าคำตอบแกว่งแค่ไหน ต้องเปลี่ยน seed หรือดู SE

bootstrap กลยุทธ์ที่ชนะจากการลองหลายตัว: ตัวที่ชนะอาจแค่โชคดี สมมติลอง 20 กลยุทธ์ที่ไม่มีฝีมือเลย แต่ละปีชนะตลาดด้วยโอกาสครึ่งต่อครึ่ง โอกาสที่ตัวหนึ่งชนะอย่างน้อย 9 ปีจาก 10 และโอกาสที่อย่างน้อยหนึ่งใน 20 ตัวทำได้ (ที่มาอยู่ในโจทย์ข้อ 3) คือ

\[\begin{aligned} p&=\frac{11}{1{,}024}\approx1.07\%,\\ 1-(1-p)^{20}&=1-(0.9893)^{20}\approx19.4\%. \end{aligned}\]

bootstrap ของตัวที่ชนะจะบอกว่ามันเก่ง เพราะ bootstrap เห็นแค่ข้อมูลของตัวนั้น มันมองไม่เห็นอีก 19 ตัวที่ถูกทิ้งไป ต้องปรับตามจำนวนตัวที่ลองด้วยการทดสอบหลายครั้ง และระวัง survivorship bias คือข้อมูลที่เหลือให้ดูมีแต่ตัวที่รอดมา ตัวที่เจ๊งถูกลบไปแล้ว

ใช้ทำอะไรบนโต๊ะจริง

ฝ่ายตั้งราคาใช้ Monte Carlo กับสัญญาที่ไม่มีสูตร เช่นสัญญาที่ผลจ่ายขึ้นกับทั้งเส้นทางราคาแบบ Asian หรือสัญญาที่ผูกกับหุ้นหลายตัวพร้อมกัน ทุกราคาที่รายงานต้องมี SE กำกับ และนิยมเลือกตัวควบคุมจากสัญญาหน้าตาใกล้กันที่มีสูตร แบบที่ขั้นที่ 8 ใช้ Asian แบบเรขาคณิต

ฝ่ายความเสี่ยงใช้ Monte Carlo คิด VaR และ ES (ขาดทุนที่ไม่น่าจะเกิน และขาดทุนเฉลี่ยในวันที่แย่กว่านั้น) ของพอร์ตที่มี option วิธีคือสุ่มราคาของหลายสินทรัพย์พร้อมกันให้ขยับตาม correlation ที่วัดได้ ซึ่งทำด้วย Cholesky แล้วตีราคาทุกสัญญาในพอร์ตใหม่ในทุกสถานการณ์ที่สุ่มได้ ถ้าพอร์ตขึ้นกับปัจจัยหลายร้อยตัว ก็สุ่มเฉพาะไม่กี่ทิศหลักที่ได้จาก PCA เพื่อลดจำนวนมิติ

bootstrap ใช้ตรวจว่าค่าสถิติที่คำนวณจากข้อมูลย้อนหลังเชื่อได้แค่ไหน ก่อนเอาไปตัดสินใจ เช่นช่วงเชื่อมั่นของ Sharpe ratio ของกลยุทธ์ หรือของ skewness และ kurtosis ของผลตอบแทนรายวัน ค่าเหล่านี้ไม่มีสูตร SE ที่เชื่อได้เมื่อข้อมูลมีหางหนา (วันที่ขยับแรงมากเกิดบ่อยกว่ารูประฆัง Normal)

โจทย์ตรวจความเข้าใจ

1. กลับไปที่ Asian call ของโจทย์เปิดเรื่อง ขั้นที่ 4 วัด SD ของผลจ่ายคิดลดหนึ่งเส้นได้ $s_X=\$12.53$ (ก) ถ้าสุ่ม $N=40{,}000$ เส้นทาง SE เท่าไร (ข) ต้องใช้กี่เส้นทางจึงได้ SE หนึ่งเซนต์ (ค) ถ้ามีตัวควบคุมที่มี correlation กับผลจ่าย $\rho=0.9$ ข้อ (ข) จะเหลือกี่เส้นทาง

เฉลย

(ก) และ (ข) ใช้ $\mathrm{SE}=s_X/\sqrt N$ ตรง ๆ แล้วแก้หา $N$ ส่วน (ค) ใช้ข้อที่ว่าตัวควบคุมทำให้ variance เหลือ $1-\rho^2$ เท่า จำนวนเส้นทางที่ต้องใช้จึงลดลงด้วยสัดส่วนเดียวกัน:

\[\begin{aligned} \mathrm{SE}&=\frac{12.53}{\sqrt{40{,}000}}=\frac{12.53}{200}=\$0.06265,\\ N_{0.01}&=\Big(\frac{12.53}{0.01}\Big)^2=1{,}570{,}009,\\ 1-\rho^2&=1-0.81=0.19,\\ N_{\text{ctrl}}&=0.19\times1{,}570{,}009\approx298{,}300. \end{aligned}\]

วิธีตรงต้องใช้ราว 1.57 ล้านเส้น ส่วนตัวควบคุมที่ correlation 0.9 ใช้แค่ราว 3 แสนเส้น

2. อีกกลยุทธ์หนึ่งมีผลตอบแทนจริงสี่วัน −1%, 0%, 1% และ 2% (ตัวเลขสมมติ) ใช้ bootstrap แบบขั้นที่ 9 หา SE ของค่าเฉลี่ย แล้วเทียบกับค่าเฉลี่ยเอง

เฉลย

ทำตามขั้นที่ 9 ทุกอย่าง เพียงเปลี่ยน 5 เป็น 4 ค่าเฉลี่ยคือ $(-1+0+1+2)\%/4=0.5\%$ ระยะห่างจากค่าเฉลี่ยคือ −1.5%, −0.5%, 0.5% และ 1.5%:

\[\begin{aligned} D&=0.015^2+0.005^2+0.005^2+0.015^2\\ &=0.0005,\\ \operatorname{Var}_*(R^*)&=\frac{0.0005}{4}=0.000125,\\ \operatorname{Var}_*(\bar R^*)&=\frac{0.000125}{4}=0.00003125,\\ \mathrm{SE}_*&=\sqrt{0.00003125}\approx0.559\%. \end{aligned}\]

SE 0.559% ยังใหญ่กว่าค่าเฉลี่ย 0.5% สี่วันจึงบอกไม่ได้ว่ากลยุทธ์นี้ทำกำไรจริง

3. มีผู้จัดการกองทุน 20 คนที่ไม่มีฝีมือเลย แต่ละปีแต่ละคนชนะตลาดด้วยโอกาส 50% เหมือนโยนเหรียญ และทุกปีทุกคนไม่เกี่ยวกัน หลังผ่านไป 10 ปี คนที่ผลงานดีที่สุดจะดูเก่งมาก (ก) โอกาสที่อย่างน้อยหนึ่งคนชนะตลาดอย่างน้อย 9 ปีจาก 10 คือเท่าไร (ข) ถ้าไม่คิดด้วยสูตร แต่ใช้ Monte Carlo จำลองสถานการณ์นี้ 10,000 รอบแล้วนับสัดส่วน คำตอบจะคลาดได้แค่ไหน

เฉลย

(ก) ให้ $W$ คือจำนวนปีที่คนหนึ่งชนะ จาก 10 ปี การชนะ 9 ปีเลือกปีที่แพ้ได้ $\binom{10}{9}=10$ แบบ การชนะครบ 10 ปีมี 1 แบบ ทุกแบบมีโอกาส $(1/2)^{10}$ แล้วคิดโอกาสที่ไม่มีใครใน 20 คนทำได้เลย ลบออกจาก 1:

\[\begin{aligned} P(W\ge9)&=\frac{\binom{10}{9}+\binom{10}{10}}{2^{10}}=\frac{11}{1{,}024}\\ &\approx0.0107,\\ p&=1-(1-0.0107)^{20}\approx0.1943. \end{aligned}\]

(ข) แต่ละรอบของ Monte Carlo ให้ผลเป็น 1 (มีคนทำได้) หรือ 0 (ไม่มี) ตัวแปรแบบนี้มี variance $p(1-p)$ SE ของสัดส่วนที่นับได้จึงเป็น $\sqrt{p(1-p)/N}$ ด้วยเหตุผลเดียวกับขั้นที่ 4:

\[\begin{aligned} p(1-p)&=0.1943\times0.8057\approx0.1565,\\ \mathrm{SE}&=\sqrt{\frac{0.1565}{10{,}000}}\approx0.0040,\\ 1.96\,\mathrm{SE}&\approx0.008. \end{aligned}\]

คำตอบจากการสุ่มจึงควรอยู่ราว $0.194\pm0.008$ หรือ 18.6% ถึง 20.2%

function mulberry32(seed) {
  return () => {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);

}

const cov = (a, b) => { const ma = mean(a), mb = mean(b); return a.reduce((s, x, i) => s + (x - ma) * (b[i] - mb), 0) / (a.length - 1); };

// One monthly path: arithmetic average, geometric average, last price
function path(z, {S0, r, sigma, m}) {
  const dt = 1 / m, drift = (r - 0.5 * sigma * sigma) * dt, shock = sigma * Math.sqrt(dt);
  let logS = Math.log(S0), sum = 0, sumLog = 0;
  for (let k = 0; k < m; k++) { logS += drift + shock * z[k]; sum += Math.exp(logS); sumLog += logS; }
  return {avg: sum / m, geo: Math.exp(sumLog / m), last: Math.exp(logS)};
}
function european({S0, K, r, sigma, T}) {
  const d1 = (Math.log(S0 / K) + (r + 0.5 * sigma * sigma) * T) / (sigma * Math.sqrt(T));
  return S0 * Phi(d1) - K * Math.exp(-r * T) * Phi(d1 - sigma * Math.sqrt(T));
}
function geometricAsian({S0, K, r, sigma, m, drift = r}) {
  let meanT = 0, minSum = 0;                       // log G is Normal
  for (let i = 1; i <= m; i++) { meanT += i / m / m; for (let j = 1; j <= m; j++) minSum += Math.min(i, j) / m; }
  const mu = Math.log(S0) + (drift - 0.5 * sigma * sigma) * meanT, v = sigma * sigma * minSum / (m * m);
  const d = (mu - Math.log(K) + v) / Math.sqrt(v);
  return Math.exp(-r) * (Math.exp(mu + v / 2) * Phi(d) - K * Phi(d - Math.sqrt(v)));
}

function control(x, y, known) {
  const c = cov(x, y) / cov(y, y), rho = cov(x, y) / Math.sqrt(cov(x, x) * cov(y, y));
  const adj = x.map((v, i) => v - c * (y[i] - known));
  return {c, rho, price: mean(adj), se: Math.sqrt(cov(adj, adj) / adj.length)};
}

สิ่งที่ควรตอบได้หลังอ่าน

  • ราคาจาก Monte Carlo คือค่าเฉลี่ยของผลจ่ายคิดลด และต้องรายงานคู่กับ $\mathrm{SE}=s_X/\sqrt N$ เสมอ ในโจทย์เปิดเรื่อง 10,000 เส้นทางให้ $7.84\pm1.96(0.126)=7.84\pm0.25$ ช่วงนี้กว้างกว่าส่วนต่างกำไร \$0.05 มาก จึงยังใช้เสนอราคาไม่ได้
  • SE ลดตาม $\sqrt N$ แม่นขึ้นสองเท่าต้องสุ่มสี่เท่า SE หนึ่งเซนต์ต้องใช้ $(12.53/0.01)^2\approx1.57$ ล้านเส้นทาง ข้อดีคืออัตรานี้ไม่ขึ้นกับจำนวนมิติ ส่วนวิธีตารางจะแย่ลงมากเมื่อมิติเพิ่ม
  • antithetic ใช้เลขสุ่มกลับเครื่องหมายเป็นคู่แฝด ช่วยได้แค่ 1.63 เท่า เพราะผลจ่ายตัดด้านลบทิ้ง control variate ทำให้ variance เหลือ $1-\rho^2$ เท่า ราคาหุ้นสิ้นปี ($\rho\approx0.81$) ช่วยราว 3 เท่า Asian แบบเรขาคณิต ($\rho\approx0.999$) ช่วยราว 592 เท่า ได้ราคา \$7.7779 ± 0.0032
  • bootstrap หยิบข้อมูลเดิมซ้ำแบบใส่คืนเพื่อดูว่าค่าสถิติแกว่งแค่ไหน ข้อมูลห้าวันให้ SE 0.77% ใหญ่กว่าค่าเฉลี่ย 0.2% เกือบสี่เท่า ถ้าวันแรง ๆ เกาะกลุ่มกัน ต้องหยิบเป็นท่อนของวันติดกัน ไม่ใช่ทีละวัน
