13.5 Multidimensional Itô and the Product Rule

เมื่อสองราคาขยับแบบสุ่มพร้อมกัน ผลคูณของการขยับสองตัว $dX\,dY$ ไม่หายไป แต่มีขนาดเท่ากับ correlation คูณเวลา พจน์นี้เพิ่ม drift ให้ผลคูณของสองราคา และทำให้ความผันผวนรวมกันแบบ variance ไม่ใช่บวกกันตรง ๆ

ธนาคารบางแห่งขายสัญญาที่เรียกว่า structured note คือสัญญาที่จ่ายเงินให้ลูกค้าตามสูตรที่ผูกกับราคาในตลาด ทีมที่ออกแบบและตั้งราคาสัญญาแบบนี้เรียกว่าโต๊ะ structured note ก่อนขาย โต๊ะต้องรู้ว่าสัญญาจะจ่ายเงินเฉลี่ยเท่าไร และจ่ายแกว่งมากแค่ไหน

note ในหน้านี้เป็นตัวอย่างสมมติ มันผูกกับกองทุนสองกองที่ซื้อขายเหมือนหุ้น กองแรกคือ SPY ซึ่งวิ่งตามดัชนี S&P 500 ของหุ้นใหญ่ 500 ตัวในสหรัฐ กองที่สองคือ QQQ ซึ่งวิ่งตามดัชนี Nasdaq-100 ของหุ้นใหญ่ 100 ตัวในตลาด Nasdaq ส่วนมากเป็นหุ้นเทคโนโลยี สองกองนี้มักขึ้นลงไปด้วยกัน แต่ไม่ทุกวัน

สูตรจ่ายเงินใช้ “ตัวคูณผลตอบแทนสะสม” (total-return factor) ของแต่ละกอง คือมูลค่าของเงิน \$1 ที่ลงในกองนั้นวันนี้ รวมเงินปันผลที่ได้ระหว่างทาง ตัวคูณจึงเริ่มที่ 1 เสมอ เรียกตัวคูณของ SPY ว่า $X$ และของ QQQ ว่า $Y$ เมื่อครบหนึ่งปี note จ่าย $N\,X_1Y_1$ โดย $X_1$ และ $Y_1$ คือค่าของตัวคูณตอนครบปี และ $N=\$1$ ล้าน คือยอดเงินตั้งต้นที่สูตรเอาไปคูณ (notional) เช่น ถ้าปีนั้น SPY ขึ้น 10% และ QQQ ขึ้น 20% note จะจ่าย $10^6\times1.10\times1.20=\$1{,}320{,}000$

ของที่รู้ (ตัวเลขสมมติของโต๊ะ แบบจำลองของโต๊ะให้แต่ละกองโตแบบสุ่ม โดยมีตัวเลขสองตัวคุม คือ drift กับความผันผวน):

  • drift คืออัตราโตเฉลี่ยต่อปี ของ SPY คือ $\mu_X=8\%$ ของ QQQ คือ $\mu_Y=10\%$
  • ความผันผวนคือขนาดการแกว่งของผลตอบแทนในหนึ่งปี วัดเป็น SD (ดูvariance และ SD) ของ SPY คือ $\sigma_X=20\%$ ของ QQQ คือ $\sigma_Y=25\%$
  • correlation $\rho=0.60$ วัดว่าสองกองขยับไปด้วยกันแค่ไหน $\rho=1$ คือไปทางเดียวกันเสมอ $\rho=0$ คือไม่เกี่ยวกันเลย $\rho=-1$ คือสวนกันเสมอ

นักวิเคราะห์ในโต๊ะคิดว่าผลคูณของสองกองก็น่าจะโตด้วยผลบวกของ drift และแกว่งด้วยผลบวกของความผันผวน เขาใช้กฎของราคาคาดหวังในอนาคต ที่ว่าของที่โตด้วย drift $\mu$ มีค่าเฉลี่ยหลังหนึ่งปีเป็น $e^{\mu}$ เท่าของวันนี้ แล้วคิดแบบนี้

\[\begin{aligned}\mu&=0.08+0.10=0.18,\\\mathbb E[NX_1Y_1]&=10^6e^{0.18}\\&=\$1{,}197{,}217,\\\sigma&=0.20+0.25=0.45.\end{aligned}\]

note จ่ายเฉลี่ย \$1,197,217 และผันผวน 45% ต่อปี สองตัวเลขนี้ใช้ได้ไหม?

ลองตอบก่อนเปิดเฉลย

ใช้ไม่ได้ทั้งสองตัว ผลคูณ $XY$ ได้ drift เพิ่มอีกก้อนหนึ่ง คือ $\rho\sigma_X\sigma_Y$ ที่นักวิเคราะห์ไม่ได้ใส่ (ขั้นที่ 5 จะพิสูจน์ว่าก้อนนี้มาจากไหน)

\[\begin{aligned}\rho\sigma_X\sigma_Y&=0.60\times0.20\times0.25=0.03,\\\mu_V&=0.18+0.03=0.21,\\\mathbb E[NX_1Y_1]&=10^6e^{0.21}=\$1{,}233{,}678,\\\text{gap}&=1{,}233{,}678-1{,}197{,}217\\&=\$36{,}461.\end{aligned}\]

note จึงจ่ายเฉลี่ยมากกว่าที่เขาคิด \$36,461 ส่วนความผันผวนของผลคูณต้องรวมกันแบบ variance (ความผันผวนยกกำลังสอง) ไม่ใช่บวกกันตรง ๆ

\[\begin{aligned}\sigma_V^2&=0.20^2+0.25^2+2(0.03)\\&=0.04+0.0625+0.06=0.1625,\\\sigma_V&=\sqrt{0.1625}=0.4031.\end{aligned}\]

ความผันผวนจริงคือ 40.31% ไม่ใช่ 45% ความผิดทั้งสองมาจากพจน์เดียวกัน คือผลคูณของการขยับสองตัวในช่วงเวลาสั้น ๆ $dX\,dY$ calculus ปกติทิ้งพจน์นี้ไป แต่เมื่อราคาขยับแบบสุ่ม มันมีขนาด $\rho\sigma_X\sigma_YXY\,dt$ และทิ้งไม่ได้

ภาพรวมก่อนลงสูตร

หน้านี้ต่อจากสองหน้าก่อน Brownian motion $W$ คือแบบจำลองของเส้นทางสุ่ม ที่การขยับในช่วงเวลายาว $\Delta t$ เป็น Normal ค่าเฉลี่ย 0 และ variance $\Delta t$ ตอนดูว่าทำไม calculus ปกติใช้กับ Brownian motion ไม่ได้ เราแบ่งเวลาเป็นท่อนสั้น ๆ แล้วบวกกำลังสองของการขยับในทุกท่อน ผลรวมนี้ไม่หายไปเมื่อซอยท่อนละเอียดขึ้น แต่เท่ากับเวลาที่ผ่านไป เขียนย่อว่า $(dW)^2=dt$ โดย $dW$ คือการขยับของ $W$ ในช่วงเวลาสั้นมาก $dt$

กฎสั้น ๆ ว่าของเล็กแต่ละคู่คูณกันได้อะไร เรียกว่า “ตารางคูณ” ของ Itô ตอนนี้มีสามข้อ คือ $(dW)^2=dt$, $dt\,dW=0$ และ $(dt)^2=0$ แล้วItô's lemma ก็คือ chain rule ที่ใช้ตารางนี้ จึงเก็บพจน์ $(dW)^2$ ไว้ ไม่ทิ้งเหมือน calculus ปกติ

แต่ทั้งสองหน้ามีความสุ่มแค่แหล่งเดียว งานจริงแทบไม่เคยเป็นแบบนั้น note ในโจทย์ผูกกับสองกองทุน หุ้นต่างประเทศต้องคิดทั้งราคาหุ้นและอัตราแลกเปลี่ยน และการเทียบผลงานของสองหุ้นก็ต้องใช้สองราคา ทุกกรณีเป็นฟังก์ชันของสองราคาที่สุ่มพร้อมกัน

คำถามใหม่จึงมีข้อเดียว ให้ $W^X$ และ $W^Y$ เป็น Brownian motion สองตัวที่ขยับไปด้วยกันบ้าง ในแต่ละท่อนเวลา เอาการขยับของตัวแรก $\Delta W^X$ คูณการขยับของตัวที่สอง $\Delta W^Y$ เรียกว่าผลคูณไขว้ แล้วบวกผลคูณไขว้ของทุกท่อนทั้งปี ผลรวมนี้จะหายไปเมื่อซอยท่อนละเอียด เหมือนของเส้นเรียบที่หาอนุพันธ์ได้ หรือจะเหลือค้างเหมือนผลรวมกำลังสอง?

คำตอบคือเหลือค้าง ได้ $\rho$ คูณเวลา รูปด้านล่างแสดงเรื่องนี้เรื่องเดียว ครึ่งล่างของรูปคือผลรวมของผลคูณไขว้ เส้นของคู่ที่ correlate กันไต่ขึ้นตามเส้นประ $\rho t$ ส่วนเส้นของคู่ที่อิสระกันวนอยู่แถวศูนย์

หน้านี้เดินตามลำดับนี้

  1. นับผลคูณของการขยับในหนึ่งก้าวด้วยมือ (ขั้นที่ 1)
  2. สร้าง Brownian motion สองตัวที่ correlate กัน แล้วได้ช่องใหม่ของตารางคูณ $dW^X\,dW^Y=\rho\,dt$ (ขั้นที่ 2)
  3. ขยาย Itô's lemma ไปสองตัวแปร จนได้กฎผลคูณ (ขั้นที่ 3 และ 4)
  4. ใช้กฎนี้ตอบโจทย์ note และหาอัตราส่วนของสองราคา (ขั้นที่ 5 ถึง 7)
  5. ตรวจด้วยการจำลองทีละวัน (ขั้นที่ 8) แล้วจบที่คำถามของโต๊ะ ถ้าประมาณ correlation คลาด ค่าเฉลี่ยของ note จะคลาดกี่ดอลลาร์ (ขั้นที่ 9)

ขั้นที่ 1 — หนึ่งก้าวด้วยมือ: ผลคูณของสองตัวที่ไม่มี drift

โจทย์ให้อะไรมาบ้าง: ก่อนดูทั้งปี ลองดูแค่ก้าวเดียว ซึ่งนับได้ด้วยมือ สองราคาเริ่มที่ 1 ในก้าวนี้แต่ละราคาขึ้น 10% หรือลง 10% โอกาสอย่างละครึ่ง การขยับ $\Delta X$ และ $\Delta Y$ จึงเป็น $+0.1$ หรือ $-0.1$ ค่าเฉลี่ยของแต่ละราคาหลังหนึ่งก้าวคือ $\tfrac12(1.1)+\tfrac12(0.9)=1$ แปลว่าเฉลี่ยแล้วไม่ขยับ

คำถามคือ ผลคูณของสองราคาหลังหนึ่งก้าว $(1+\Delta X)(1+\Delta Y)$ เฉลี่ยเท่าไร ลองสามกรณี

  • ขยับไปด้วยกันเสมอ ($\rho=1$): ขึ้นทั้งคู่หรือลงทั้งคู่ โอกาสอย่างละครึ่ง
  • สวนกันเสมอ ($\rho=-1$): ตัวหนึ่งขึ้น อีกตัวลง โอกาสอย่างละครึ่ง
  • ไม่เกี่ยวกัน ($\rho=0$): เกิดได้สี่แบบ โอกาสแบบละ $\tfrac14$
\[ \begin{aligned} \rho=1&:\ \tfrac12(1.1)(1.1)+\tfrac12(0.9)(0.9)\\ &\quad=\tfrac12(1.21+0.81)=1.01,\\ \rho=-1&:\ \tfrac12(1.1)(0.9)+\tfrac12(0.9)(1.1)\\ &\quad=0.99,\\ \rho=0&:\ \tfrac14(1.21+0.99+0.99+0.81)\\ &\quad=1.00,\\ \mathbb E[\Delta X\,\Delta Y]&=\rho(0.1)(0.1)\\ &=+0.01,\ -0.01,\ 0. \end{aligned} \]

คำตอบ: แต่ละราคาเฉลี่ยไม่ขยับ แต่ผลคูณขยับได้ ในกรณีแรก ขึ้นพร้อมกันได้ $1.1\times1.1=1.21$ ลงพร้อมกันได้ $0.9\times0.9=0.81$ ฝั่งขึ้นได้มากกว่าที่ฝั่งลงเสีย ค่าเฉลี่ยจึงเป็น 1.01 เกิน 1 อยู่ 0.01

ส่วนเกิน 0.01 นี้คือค่าเฉลี่ยของผลคูณการขยับ $\Delta X\,\Delta Y$ พอดี และเท่ากับ correlation คูณขนาดการขยับของสองตัว $\rho\times0.1\times0.1$ ในกรณีสวนกัน ส่วนเกินกลายเป็นส่วนขาด $-0.01$ และในกรณีไม่เกี่ยวกัน ส่วนเกินเป็นศูนย์

ตรวจเองใน 10 วินาที: กระจายวงเล็บ $(1+\Delta X)(1+\Delta Y)=1+\Delta X+\Delta Y+\Delta X\,\Delta Y$ สองพจน์กลางเฉลี่ยศูนย์ เพราะแต่ละราคาเฉลี่ยไม่ขยับ จึงเหลือพจน์สุดท้าย กรณีแรกเครื่องหมายเหมือนกันเสมอ จึงได้ $(\pm0.1)(\pm0.1)=+0.01$ ทุกครั้ง กรณีที่สองเครื่องหมายต่างกันเสมอ จึงได้ $-0.01$ ทุกครั้ง

ขั้นที่ 2 — สร้าง Brownian motion สองตัวที่ correlate กัน แล้วบวกผลคูณไขว้ทั้งปี

ขั้นที่แล้วมีแค่หนึ่งก้าว ตอนนี้ต้องการสองเส้นทางทั้งปี ที่การขยับในทุกท่อนมี correlation $\rho$ เท่ากัน แบ่งเวลา $T$ ปีเป็น $n$ ท่อน ท่อนละ $\Delta t=T/n$ ปี ใน Brownian motion มาตรฐาน การขยับในหนึ่งท่อนเป็น Normal ค่าเฉลี่ย 0 และ variance $\Delta t$

วิธีสร้างเหมือนการจำลอง multivariate normal ด้วย Cholesky เริ่มจาก Brownian motion สองตัวที่อิสระกัน คือ $W^X$ และ $W^\perp$ แล้วสร้างการขยับของ $W^Y$ จากสองส่วน ส่วนแรกคือการขยับของ $W^X$ คูณ $\rho$ เป็นส่วนที่ร่วมกับ $X$ ส่วนที่สองคือการขยับของ $W^\perp$ คูณ $\sqrt{1-\rho^2}$ เป็นส่วนที่เป็นของ $Y$ เอง

จากนั้นถามแบบเดียวกับที่เคยถามกับกำลังสอง บวกผลคูณไขว้ทุกท่อนแล้วเหลือเท่าไร ส่วนที่ร่วมกันให้กำลังสอง $(\Delta W^X)^2$ ซึ่งรู้แล้วว่ารวมได้เวลา จึงเหลือแค่ต้องดูส่วนที่อิสระกัน $\Delta W^X\Delta W^\perp$

\[ \begin{aligned} \Delta W^Y_i&=\rho\,\Delta W^X_i+\sqrt{1-\rho^2}\,\Delta W^\perp_i,\\ \operatorname{Var}(\Delta W^Y_i)&=\rho^2\Delta t+(1-\rho^2)\Delta t\\ &=\Delta t,\\ \mathbb E[\Delta W^X_i\Delta W^\perp_i]&=0\times0=0,\\ \operatorname{Var}(\Delta W^X_i\Delta W^\perp_i)&=\Delta t\times\Delta t,\\ \operatorname{Var}\Big(\textstyle\sum_i\Delta W^X_i\Delta W^\perp_i\Big)&=n\,\Delta t^2=T^2/n,\\ n=252,\ T=1&:\ \operatorname{SD}=\sqrt{1/252}=0.063,\\ dW^X\,dW^Y&=\rho\,(dW^X)^2\\ &\quad+\sqrt{1-\rho^2}\,dW^X\,dW^\perp\\ &=\rho\,dt+0. \end{aligned} \]

สูตรสร้างนี้ใช้ได้เพราะ $W^Y$ ยังเป็น Brownian motion มาตรฐาน สองส่วนที่ประกอบเป็น $\Delta W^Y_i$ อิสระกัน variance ของมันจึงบวกกันได้ และรวมเป็น $\Delta t$ พอดี

ส่วนที่อิสระกันหายไปเพราะผลคูณ $\Delta W^X_i\Delta W^\perp_i$ ของแต่ละท่อนเป็นบวกบ้างลบบ้าง เฉลี่ยศูนย์ บวกกันหลายท่อนจึงหักล้างกันเอง ขนาดการแกว่งของแต่ละท่อนคือ variance $\Delta t\times\Delta t$ เพราะสองตัวที่อิสระกันและเฉลี่ยศูนย์ มี variance ของผลคูณเท่ากับผลคูณของ variance บวก $n$ ท่อนที่อิสระกันได้ variance $n\,\Delta t^2=T^2/n$ ซึ่งหดเข้าหาศูนย์เมื่อซอยท่อนละเอียดขึ้น ต่างจาก $(\Delta W)^2$ ที่เป็นบวกทุกท่อน จึงไม่หักล้างกัน และรวมได้ $T$

เมื่อแทนสองผลนี้ลงไป ส่วนที่ร่วมกันให้ $\rho\,(dW^X)^2=\rho\,dt$ และส่วนที่อิสระให้ศูนย์ ตารางคูณจึงมีช่องใหม่ $dW^X\,dW^Y=\rho\,dt$ ลองเช็กสองปลาย ที่ $\rho=1$ สองตัวเป็นตัวเดียวกัน ช่องใหม่กลับเป็น $(dW)^2=dt$ ที่ $\rho=0$ สองตัวอิสระกัน ช่องใหม่เป็นศูนย์ ส่วนกฎเดิมที่ว่า $dt$ คูณอะไรก็เป็นศูนย์ยังใช้ได้เหมือนเดิม

เทียบกับรูปแรกของหน้า เส้นม่วงคือผลรวมที่หาย มันจบที่ −0.011 ซึ่งเล็กกว่า SD 0.063 มาก ($0.011/0.063=0.17$ ไม่ถึงหนึ่งในห้า) ส่วนเส้นเขียวคือผลรวมที่เหลือค้าง ได้ $\rho t$

ขั้นที่ 3 — Itô สองตัวแปร: Taylor ที่เก็บพจน์ไขว้

ตอนนี้ตารางคูณครบแล้ว จึงขยาย Itô's lemma ไปสองตัวแปรได้ เราต้องการสิ่งนี้เพราะมูลค่าของ note เป็นฟังก์ชันของสองราคา และต้องรู้ว่ามันขยับอย่างไรเมื่อสองราคาขยับพร้อมกัน

ให้ $X$ และ $Y$ ขยับตาม SDE (สมการที่บอกว่าการขยับในช่วงสั้น ๆ คือส่วนที่ไหลแน่นอน บวกส่วนสุ่ม) $dX=a_X\,dt+b_X\,dW^X$ และ $dY=a_Y\,dt+b_Y\,dW^Y$ โดย $a_X$ คืออัตราไหลแน่นอน (drift) ของ $X$ และ $b_X$ คือขนาดของส่วนสุ่ม ของ $Y$ ก็เช่นกัน

เมื่อยกกำลังสองหรือคูณกัน แล้วใช้ตารางคูณ ($(dt)^2=0$, $dt\,dW=0$, $(dW)^2=dt$ และ $dW^X\,dW^Y=\rho\,dt$) จะเหลือแค่ส่วนสุ่มคูณส่วนสุ่ม จึงได้ $(dX)^2=b_X^2\,dt$, $(dY)^2=b_Y^2\,dt$ และ $dX\,dY=\rho\,b_Xb_Y\,dt$

จากนั้นเขียน Taylor ของ $f(t,x,y)$ ถึงอันดับสอง แบบเดียวกับตอนพิสูจน์ Itô's lemma แล้วแทนสามผลนี้ลงไป ($f_x$ คืออนุพันธ์ย่อยตาม $x$ และ $f_{xy}$ คืออนุพันธ์ย่อยตาม $x$ แล้วตาม $y$) สุดท้ายแยกผลเป็นส่วนที่คูณ $dt$ (drift) กับส่วนที่คูณ $dW$ (noise)

\[ \begin{aligned} df&=f_t\,dt+f_x\,dX+f_y\,dY\\ &\quad+\tfrac12f_{xx}(dX)^2+\tfrac12f_{yy}(dY)^2\\ &\quad+f_{xy}\,dX\,dY,\\ \text{drift}&=f_t+a_Xf_x+a_Yf_y\\ &\quad+\tfrac12b_X^2f_{xx}+\tfrac12b_Y^2f_{yy}\\ &\quad+\rho\,b_Xb_Yf_{xy},\\ \text{noise}&=f_xb_X\,dW^X+f_yb_Y\,dW^Y. \end{aligned} \]

ผลนี้บอกว่า drift ของ $f$ มีพจน์เพิ่มจาก calculus ปกติสามพจน์ สองพจน์แรกคือพจน์กำลังสองของแต่ละตัว ซึ่งรู้จักแล้วจากกรณีตัวแปรเดียว พจน์ที่สาม $\rho\,b_Xb_Yf_{xy}$ คือของใหม่ มันอยู่รอดเพราะ $dX\,dY$ มีขนาด $dt$ เท่ากับพจน์กำลังสอง

จุดที่คนมักงงคือพจน์ไขว้ไม่มี $\tfrac12$ เหตุผลคือส่วนอันดับสองของ Taylor สองตัวแปรคือ $\tfrac12\big(f_{xx}(dX)^2+2f_{xy}\,dX\,dY+f_{yy}(dY)^2\big)$ อนุพันธ์ไขว้ปรากฏสองครั้ง ($f_{xy}$ และ $f_{yx}$ ซึ่งเท่ากัน) เลข 2 จึงตัดกับ $\tfrac12$ พอดี

พจน์อันดับสามทุกตัวหายไปด้วยเหตุผลเดียวกับกรณีตัวแปรเดียว เช่น $(dX)^2\,dX$ มีขนาด $dt\times dW$ ซึ่งเป็นศูนย์ ส่วน noise ของ $df$ ไม่ต่างจาก calculus ปกติเลย คือความชันตามแต่ละตัวคูณส่วนสุ่มของตัวนั้น

ขั้นที่ 4 — กฎผลคูณ: พจน์ที่สามทิ้งไม่ได้

ผลคูณของสองราคาสุ่มโผล่บ่อยที่สุด เช่น note ในโจทย์ หรือราคาหุ้นต่างประเทศคูณอัตราแลกเปลี่ยน จึงควรมีกฎสำเร็จรูปไว้ใช้ ใส่ $f=xy$ ลงในสูตรของขั้นที่แล้ว ฟังก์ชันนี้มี $f_t=0$, $f_x=y$, $f_y=x$, $f_{xx}=f_{yy}=0$ และ $f_{xy}=1$ เหลือแค่สามพจน์

เพื่อให้เห็นว่ากฎนี้ไม่ได้ประมาณอะไรเลย ให้เทียบกับการกระจายวงเล็บของหนึ่งท่อนตรง ๆ ซึ่งเป็นพีชคณิตล้วน

\[ \begin{aligned} (X+\Delta X)(Y+\Delta Y)-XY&=X\,\Delta Y+Y\,\Delta X\\ &\quad+\Delta X\,\Delta Y,\\ d(XY)&=X\,dY+Y\,dX+dX\,dY. \end{aligned} \]

ใน calculus ปกติ พจน์ที่สาม $\Delta X\,\Delta Y$ ทิ้งได้ เพราะของเล็กคูณของเล็กได้ของที่เล็กกว่ามาก ถ้า $\Delta X$ และ $\Delta Y$ มีขนาดราว $\Delta t$ ผลคูณจะมีขนาด $\Delta t^2$ ทั้งปีมี $1/\Delta t$ ท่อน รวมได้ราว $\Delta t$ ซึ่งหายไปเมื่อซอยละเอียด

แต่การขยับสุ่มแต่ละตัวมีขนาดราว $\sqrt{\Delta t}$ ไม่ใช่ $\Delta t$ ผลคูณจึงมีขนาด $\sqrt{\Delta t}\times\sqrt{\Delta t}=\Delta t$ เท่ากับพจน์ drift รวมทั้งปีจึงได้ $\rho\,b_Xb_Y$ คูณเวลา ไม่หายไป ตัวอย่างสี่มุมในขั้นที่ 1 คือพจน์นี้ในหนึ่งก้าว

เช็กกับของที่รู้แล้ว ถ้าให้ $Y=X$ กฎนี้กลายเป็น $d(X^2)=2X\,dX+(dX)^2$ ซึ่งคือ Itô's lemma ของ $x^2$

ขั้นที่ 5 — ผลคูณของสอง GBM ก็เป็น GBM: drift มีพจน์ไขว้ และความผันผวนรวมแบบ variance

ตอนนี้กลับไปที่ note แบบจำลองของโต๊ะให้ SPY และ QQQ เป็น GBM คนละตัว (ดูนิยามของ GBM) แปลว่าผลตอบแทนในช่วงสั้น ๆ ของแต่ละตัว คือ drift คูณเวลา บวกความผันผวนคูณการขยับสุ่ม $dX/X=\mu_X\,dt+\sigma_X\,dW^X$ และ $dY/Y=\mu_Y\,dt+\sigma_Y\,dW^Y$

เราอยากรู้ว่าผลคูณ $V=XY$ ซึ่งคือเงินที่ note จ่ายหารด้วย $N$ โตอย่างไร ทำเป็นสามขั้น หาพจน์ไขว้ $dX\,dY$ ก่อน แทนลงในกฎผลคูณแล้วหารด้วย $V$ ทั้งสมการ สุดท้ายหาขนาดของส่วนสุ่มสองก้อนที่บวกกัน ด้วยตารางคูณเดิม

\[ \begin{aligned} dX\,dY&=XY\,\sigma_X\sigma_Y\,dW^XdW^Y\\ &=\rho\,\sigma_X\sigma_Y\,XY\,dt,\\ \frac{dV}{V}&=\frac{dX}{X}+\frac{dY}{Y}+\frac{dX\,dY}{XY}\\ &=(\mu_X+\mu_Y+\rho\sigma_X\sigma_Y)\,dt\\ &\quad+\sigma_X\,dW^X+\sigma_Y\,dW^Y,\\ (\sigma_XdW^X+\sigma_YdW^Y)^2&=(\sigma_X^2+\sigma_Y^2\\ &\quad+2\rho\sigma_X\sigma_Y)\,dt,\\ \sigma_V^2&=\sigma_X^2+\sigma_Y^2+2\rho\sigma_X\sigma_Y. \end{aligned} \]

พจน์ไขว้หาได้ง่าย เพราะส่วน drift ของ $dX$ และ $dY$ คูณกับอะไรก็ได้ $dt\,dW$ หรือ $(dt)^2$ ซึ่งเป็นศูนย์ เหลือแค่ส่วนสุ่มคูณส่วนสุ่ม ผลที่ได้คือ drift ของผลคูณไม่ใช่แค่ $\mu_X+\mu_Y$ ยังมี $\rho\sigma_X\sigma_Y$ งอกออกมา ทั้งที่ไม่มีใครใส่เข้าไป ก้อนนี้คือ covariance ของผลตอบแทนสองตัว (correlation คูณ SD ของสองตัว) และมาจากมุมแดงของรูปสี่เหลี่ยม

ส่วนสุ่มสองก้อนรวมกันเป็นการขยับ Normal ก้อนเดียวที่มี variance $\sigma_V^2\,dt$ เราจึงเขียนมันเป็น $\sigma_V\,dW^V$ ด้วย Brownian motion ตัวใหม่ $W^V$ ได้ $V$ จึงเป็น GBM เหมือนกัน สูตรของ $\sigma_V^2$ เป็นสูตรเดียวกับความเสี่ยงของพอร์ตสองสินทรัพย์

การบวกความผันผวนตรง ๆ คือการแอบสมมติว่า $\rho=1$ เพราะ $(\sigma_X+\sigma_Y)^2=\sigma_X^2+\sigma_Y^2+2\sigma_X\sigma_Y$ ตรงกับสูตรข้างบนเมื่อ $\rho=1$ เท่านั้น ถ้า $\rho\lt1$ ส่วนสุ่มสองก้อนหักกันได้บ้าง ความผันผวนรวมจึงเล็กกว่าผลบวก

ขั้นที่ 6 — คำตอบของโจทย์เปิดเรื่อง

โจทย์ให้อะไรมาบ้าง: ตัวเลขสมมติของโต๊ะจากโจทย์เปิดเรื่อง

  • SPY: drift $\mu_X=0.08$ ความผันผวน $\sigma_X=0.20$
  • QQQ: drift $\mu_Y=0.10$ ความผันผวน $\sigma_Y=0.25$
  • correlation $\rho=0.60$ และ notional $N=\$1$ ล้าน

ขั้นที่ 5 บอกว่า $V=XY$ เป็น GBM ที่มี drift $\mu_V$ และ GBM ที่เริ่มที่ $S_0$ มีค่าเฉลี่ยหลัง $T$ ปีเป็น $\mathbb E[S_T]=S_0e^{\mu T}$ (ราคาคาดหวังในอนาคต) ที่ $S_0=1$ และ $T=1$ จึงได้ $\mathbb E[V_1]=e^{\mu_V}$ ทีนี้แทนตัวเลข

\[ \begin{aligned} \rho\sigma_X\sigma_Y&=0.60(0.20)(0.25)=0.030,\\ \mu_V&=0.08+0.10+0.030=0.21,\\ \sigma_V^2&=0.04+0.0625+2(0.030)\\ &=0.1625,\quad\sigma_V=0.4031,\\ \mathbb E[NV_1]&=10^6e^{0.21}=1{,}233{,}678,\\ 10^6e^{0.18}&=1{,}197{,}217,\\ \text{gap}&=1{,}233{,}678-1{,}197{,}217\\ &=36{,}461. \end{aligned} \]

คำตอบ: note จ่ายเฉลี่ย \$1,233,678 มากกว่าคำตอบที่ลืมพจน์ไขว้ \$36,461 และผลคูณผันผวน 40.31% ไม่ใช่ 45%

ข้อควรระวัง ตัวเลขนี้คือค่าเฉลี่ยของเงินที่จะจ่ายจริงในอีกหนึ่งปี ภายใต้ drift ที่โต๊ะคาดไว้สำหรับโลกจริง มันยังไม่ใช่ราคาขายวันนี้ ราคาขายต้องคิดลด เพราะเงินในอีกหนึ่งปีมีค่าน้อยกว่าเงินวันนี้ และต้องเป็นราคาที่ไม่เปิดช่องให้ใครได้เงินฟรี ซึ่งต้องเปลี่ยนไปใช้ risk-neutral measure เป็นเรื่องของหน้าถัดไป

ตรวจเองใน 10 วินาที: ใช้ $e^x\approx1+x+\tfrac{x^2}{2}+\tfrac{x^3}{6}$ ได้ $e^{0.21}\approx1+0.21+0.0221+0.0015=1.2336$ ส่วนต่างหาได้จาก $e^{0.21}-e^{0.18}=e^{0.18}(e^{0.03}-1)$ โดย $e^{0.03}-1\approx0.0305$ จึงได้ $1.1972\times0.0305=0.0365$ คูณ $10^6$ ได้ราว \$36,500 ใกล้ \$36,461

ขั้นที่ 7 — อัตราส่วนสองราคา: ความโค้งของ 1/Y เพิ่ม drift

บางครั้งโต๊ะสนใจผลงานเทียบกัน เช่น SPY ชนะ QQQ ได้แค่ไหน หรือสนใจอัตราแลกเปลี่ยน ซึ่งเป็นราคาของเงินสกุลหนึ่งหารด้วยอีกสกุล ทั้งสองเรื่องคืออัตราส่วนของสองราคา $Z=X/Y$ ถ้า $Z$ โตขึ้น แปลว่า SPY ทำผลงานดีกว่า QQQ

ใช้ Itô สองตัวแปรจากขั้นที่ 3 กับ $f=x/y$ อนุพันธ์ที่ต้องใช้คือ $f_x=1/y$, $f_y=-x/y^2$, $f_{xx}=0$, $f_{yy}=2x/y^3$ และ $f_{xy}=-1/y^2$ ($f_t=0$) แทนลงไปได้ $dZ$ แล้วหารด้วย $Z=X/Y$ ทั้งสมการ สุดท้ายแทน $(dY)^2/Y^2=\sigma_Y^2\,dt$ และ $dX\,dY/(XY)=\rho\sigma_X\sigma_Y\,dt$ จากขั้นที่ 5

\[ \begin{aligned} dZ&=\frac{dX}{Y}-\frac{X\,dY}{Y^2}\\ &\quad+\frac{X(dY)^2}{Y^3}-\frac{dX\,dY}{Y^2},\\ \frac{dZ}{Z}&=\frac{dX}{X}-\frac{dY}{Y}+\frac{(dY)^2}{Y^2}\\ &\quad-\frac{dX\,dY}{XY},\\ \mu_Z&=\mu_X-\mu_Y+\sigma_Y^2-\rho\sigma_X\sigma_Y\\ &=0.08-0.10+0.0625-0.030\\ &=0.0125,\\ \sigma_Z^2&=\sigma_X^2+\sigma_Y^2-2\rho\sigma_X\sigma_Y\\ &=0.04+0.0625-0.060=0.0425,\\ \sigma_Z&=\sqrt{0.0425}=0.2062. \end{aligned} \]

ทำไม drift ของอัตราส่วนไม่ใช่แค่ $\mu_X-\mu_Y$? เพราะ $1/y$ เป็นเส้นโค้งหงาย ($f_{yy}=2x/y^3\gt0$) เมื่อ $Y$ แกว่งขึ้นลงเท่า ๆ กัน $1/Y$ ได้ตอนขาลงของ $Y$ มากกว่าที่เสียตอนขาขึ้น ความโค้งนี้เพิ่ม $\sigma_Y^2=0.25^2=0.0625$ เข้าไปใน drift ส่วนพจน์ไขว้มาพร้อมเครื่องหมายลบ เพราะ $f_{xy}\lt0$

calculus ปกติให้อัตราส่วนโต $0.08-0.10=-2\%$ ต่อปี คำตอบจริงคือ $-0.02+0.0625-0.030=+1.25\%$ ความโค้งเพิ่ม 6.25 จุด และพจน์ไขว้หักไป 3 จุด

ในความผันผวน correlation ก็มาพร้อมเครื่องหมายลบ เพราะส่วนสุ่มของ $dZ/Z$ คือ $\sigma_X\,dW^X-\sigma_Y\,dW^Y$ สองตัวที่ขยับไปด้วยกันจึงหักล้างกันเมื่อหาร ถ้าสองตัวไม่เกี่ยวกัน ($\rho=0$) อัตราส่วนจะผันผวน $\sqrt{0.1025}=32.02\%$ แต่ correlation 0.6 ทำให้เหลือแค่ 20.62% นี่คือเหตุผลที่ pairs trading (กลยุทธ์ที่ซื้อตัวหนึ่งพร้อมขายอีกตัวที่ขยับคล้ายกัน แล้วหากำไรจากอัตราส่วนของสองตัว) เลือกคู่ที่ correlation สูง

ขั้นที่ 8 — ตรวจด้วยการเดิน SDE สองตัวทีละวัน

โจทย์ให้อะไรมาบ้าง: สูตรทั้งหมดข้างบนได้มาจากการพิสูจน์ ขั้นนี้ตรวจมันด้วยวิธีที่ไม่ใช้สูตรเหล่านั้นเลย คือจำลองเส้นทางสุ่มจำนวนมากแล้วหาค่าเฉลี่ย โค้ดท้ายหน้าทำแบบนี้

  • เดิน $X$ และ $Y$ จาก 1 วันละก้าว 252 ก้าว (หนึ่งปีทำการ) ทำทั้งหมด 20,000 เส้นทาง ด้วย seed 135
  • แต่ละก้าวสร้าง $\Delta W^Y$ ด้วย Cholesky แบบเดียวกับขั้นที่ 2
  • คูณ $X$ ด้วย $1+\mu_X\Delta t+\sigma_X\Delta W^X$ และคูณ $Y$ ด้วย $1+\mu_Y\Delta t+\sigma_Y\Delta W^Y$ ซึ่งคือ GBM หนึ่งก้าวตรง ๆ

ค่าเฉลี่ยจากการสุ่มคลาดเคลื่อนได้เสมอ จึงวัดระยะห่างจากทฤษฎีเป็นจำนวน SE (standard error คือขนาดความคลาดของค่าเฉลี่ยจากการสุ่ม เท่ากับ SD ของหนึ่งเส้นทาง หารด้วยรากของจำนวนเส้นทาง ดูstandard error) ห่างไม่เกินราว 2 SE ถือว่าตรงกัน

ขั้นที่ 9 — correlation ที่ประมาณคลาด ทำให้ราคาคลาดเท่าไร

ตัวเลข $\rho=0.60$ ไม่ได้มาจากฟ้า โต๊ะประมาณมันจากข้อมูลในอดีต สมมติว่าใช้ผลตอบแทนรายวันหนึ่งปี คือ $n=252$ วัน ค่าที่ประมาณได้ $\hat\rho$ จึงคลาดจากค่าจริงได้ ขนาดความคลาดโดยประมาณคือ SE ราว $(1-\rho^2)/\sqrt n$ (สูตรประมาณมาตรฐานของstandard error ของ correlation เมื่อข้อมูลมาก หน้านี้ยกมาใช้โดยไม่พิสูจน์)

คำถามของโต๊ะคือ ถ้า $\rho$ คลาดไปเท่านี้ ค่าเฉลี่ยที่ note จ่ายจะคลาดกี่ดอลลาร์ จากรูป drift ของผลคูณ ค่าเฉลี่ยคือ $10^6e^{0.18+0.05\rho}$ จึงหาอนุพันธ์ตาม $\rho$ ที่ $\rho=0.6$ ได้ความชันเป็นดอลลาร์ต่อ correlation หนึ่งหน่วย แล้วคูณกับ SE

\[ \begin{aligned} \operatorname{SE}(\hat\rho)&\approx\frac{1-0.6^2}{\sqrt{252}}=\frac{0.64}{15.87}\\ &=0.0403,\\ \frac{d}{d\rho}\,10^6e^{0.18+0.05\rho}&=10^6(0.05)\,e^{0.18+0.05\rho}\\ &=50{,}000\,e^{0.21}=61{,}684,\\ 61{,}684\times0.0403&=2{,}487. \end{aligned} \]

ความชัน \$61,684 ต่อ correlation หนึ่งหน่วยแปลว่า ทุก 0.01 ของ correlation ย้ายค่าเฉลี่ยของ note ราว $61{,}684\times0.01=\$617$ ข้อมูลหนึ่งปีบอก $\rho$ ได้แม่นแค่ราว ±0.04 ความไม่แน่นอนจาก $\rho$ ตัวเดียวจึงเป็นราว ±\$2,500 ต่อ notional \$1 ล้าน

โต๊ะจึงต้องรายงานความไวต่อ correlation แยกจากความไวต่อราคาและความผันผวน และในตลาดจริง correlation ไม่คงที่ วันที่ตลาดตกหนัก หุ้นแทบทุกตัวตกพร้อมกัน correlation จึงพุ่งขึ้น ตัวเลข $\rho$ ที่ใช้ตั้งราคาจึงเป็นการตัดสินใจของโต๊ะ ไม่ใช่ค่าที่อ่านจากข้อมูลได้ตรง ๆ

ความผิดที่ให้ตัวเลขผิดโดยไม่มีใครเตือน

บวก drift ของสองตัวแล้วจบ: ลืมพจน์ไขว้ใน drift ของผลคูณ ค่าเฉลี่ยของ note จึงต่ำไป ผิดคือ $10^6e^{0.08+0.10}=\$1{,}197{,}217$ ถูกคือ $10^6e^{0.08+0.10+0.03}=\$1{,}233{,}678$ ต่ำไป \$36,461 ต่อ \$1 ล้าน ความผิดนี้ใหญ่ขึ้นเมื่อ $\rho$ หรือความผันผวนสูงขึ้น ที่ $\rho=1$ พจน์ไขว้เป็น $1\times0.20\times0.25=0.05$ เต็มก้อน

บวกความผันผวนตรง ๆ: การบวกตรง ๆ คือการแอบใช้ $\rho=1$ ผิดคือ $0.20+0.25=0.45$ ถูกคือ $\sqrt{0.1625}=0.4031$ สูงไป $0.45-0.4031=0.047$ หรือ 4.7 จุด ราคาของ option สูงขึ้นเมื่อความผันผวนสูงขึ้น option บนผลคูณที่ตั้งราคาด้วย 45% จึงแพงเกินไป และ hedge ratio (จำนวนหน่วยของสินทรัพย์ที่ต้องถือเพื่อหักล้างความเสี่ยงของสัญญา) ก็ผิดทั้งชุด

กลับด้านตัวแปรแล้วลืมกลับเครื่องหมายของ correlation: correlation ผูกกับว่าเราวัดตัวแปรด้านไหน ถ้าตัวหนึ่งกลับด้าน เครื่องหมายของ $\rho$ ต้องกลับด้วย เช่น อัตราแลกเปลี่ยนแบบบาทต่อดอลลาร์ขึ้นในวันที่ดอลลาร์แข็ง แต่แบบดอลลาร์ต่อบาทลงในวันเดียวกัน

ตัวอย่างในหน้านี้ อัตราส่วน $X/Y$ คือ $X$ คูณ $1/Y$ และ $1/Y$ ขยับสวนกับ $Y$ correlation ของ $X$ กับ $1/Y$ จึงเป็น $-\rho$ ส่วน drift ของ $1/Y$ คือ $-\mu_Y+\sigma_Y^2=-0.10+0.0625=-0.0375$ (ความโค้งของ $1/y$ ในขั้นที่ 7) ถ้าใช้สูตรผลคูณแต่ลืมกลับเครื่องหมาย จะผิดแบบนี้

\[ \begin{aligned} \text{wrong}&=0.08-0.0375+(0.60)(0.20)(0.25)\\ &=0.0725,\\ \text{right}&=0.08-0.0375+(-0.60)(0.20)(0.25)\\ &=0.0125. \end{aligned} \]

ได้ 7.25% แทน 1.25% ผิดไป $0.0725-0.0125=0.06$ หรือ 6 จุด

ใส่พจน์ไขว้ใน drift ของผลบวก: พอร์ตที่บวกมูลค่าสองตัว $X+Y$ ไม่มีพจน์ไขว้ใน drift เพราะ $f=x+y$ มี $f_{xy}=0$ จึงได้ $d(X+Y)=dX+dY$ ตรง ๆ แต่ความผันผวนของพอร์ตแบบบวกยังรวมกันแบบ variance อยู่ ถ้าเริ่มที่ $X=Y=1$ drift ที่ถูกคือ $\mu_XX+\mu_YY=0.08+0.10=0.18$ ต่อปี ถ้าเผลอเติม $\rho\sigma_X\sigma_YXY=0.03$ เข้าไปจะได้ 0.21 ซึ่งสูงเกินจริง

ใช้ทำอะไรบนโต๊ะจริง

ทุกสัญญาที่อ้างอิงหลายสินทรัพย์ใช้เรื่องในหน้านี้ เช่น basket (จ่ายตามค่าเฉลี่ยของหลายสินทรัพย์) spread (จ่ายตามส่วนต่างของสองราคา) best-of (จ่ายตามตัวที่ดีที่สุดในกลุ่ม) และ quanto ที่คูณราคาหุ้นต่างประเทศกับอัตราแลกเปลี่ยน

ตัวอย่างใกล้ตัว นักลงทุนไทยที่ถือ SPY สนใจมูลค่าเป็นบาท ซึ่งเท่ากับราคาดอลลาร์คูณอัตราบาทต่อดอลลาร์ นี่คือกฎผลคูณตรง ๆ (โจทย์ข้อ 3)

บทเรียนที่ลึกกว่าคือ ราคาของ option บน SPY ตัวเดียว และบน QQQ ตัวเดียว บอกแค่การกระจายของแต่ละราคาแยกกัน ไม่บอก $\rho$ เลย ลองนึกถึงสองโลกที่ SPY และ QQQ หน้าตาเหมือนกันทุกอย่างเมื่อดูทีละตัว แต่โลกหนึ่งมี $\rho=0.6$ อีกโลกมี $\rho=-0.4$ ราคา option ทีละตัวในสองโลกเท่ากันทุกตัว แต่ note ผลคูณจ่ายเฉลี่ยต่างกัน \$60,167 (โจทย์ข้อ 1 จะคำนวณให้ดู) ตัวเลข $\rho$ จึงต้องมาจากข้อมูลในอดีต หรือจากสัญญาที่อ้างอิงหลายตัวพร้อมกัน ไม่มีทางอ่านออกจากตลาด option ทีละตัว

กฎผลคูณยังเป็นเครื่องมือหลักตอนตั้งพอร์ตเลียนแบบของ Black–Scholes ที่ถือทั้งหุ้นและเงินสด และหน้าถัดไปใช้มันพิสูจน์ว่า ราคาที่คิดลดด้วยดอกเบี้ยแล้วกลายเป็น martingale (ของที่ค่าเฉลี่ยในอนาคตเท่ากับค่าวันนี้) หลังเปลี่ยนน้ำหนักของเส้นทาง

function checkPair(p) {
  const {muX, muY, sX, sY, rho} = p;
  if (![muX, muY, sX, sY, rho].every(Number.isFinite)) throw new TypeError('Drifts, volatilities and correlation must be finite numbers');
  if (sX <= 0 || sY <= 0 || Math.abs(rho) > 1) throw new RangeError('Need volatilities > 0 and -1 <= rho <= 1');
}
// Two GBMs dX/X = muX dt + sX dWx, dY/Y = muY dt + sY dWy with dWx dWy = rho dt.
// Product V = XY: d(XY) = X dY + Y dX + dX dY, and dX dY = rho sX sY XY dt.
// Ratio Z = X/Y: 1/Y has drift -muY + sY^2, and the cross term enters with a minus sign.
function pairDynamics(p) {
  checkPair(p);
  const {muX, muY, sX, sY, rho} = p, cross = rho * sX * sY;
  return {cross, product: {drift: muX + muY + cross, vol: Math.sqrt(sX * sX + sY * sY + 2 * cross)},
    ratio: {drift: muX - muY + sY * sY - cross, vol: Math.sqrt(sX * sX + sY * sY - 2 * cross)}};
}
// mulberry32 + Box-Muller: seeded standard Normals, the same generator on every page of this chapter.
function normals(seed) {
  let a = seed >>> 0, spare = null;
  const u = () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), a | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return (((t ^ (t >>> 14)) >>> 0) + 0.5) / 4294967296;
  };
  return () => {
    if (spare !== null) { const z = spare; spare = null; return z; }
    const r = Math.sqrt(-2 * Math.log(u())), angle = 2 * Math.PI * u();
    spare = r * Math.sin(angle);
    return r * Math.cos(angle);
  };
}
// Step both SDEs daily from 1; dWy = rho dWx + sqrt(1 - rho^2) dW_perp (Cholesky). No Ito result is used.
function simulatePair(p, paths, steps, seed) {
  checkPair(p);
  if (!Number.isInteger(paths) || paths < 2 || !Number.isInteger(steps) || steps < 1) throw new RangeError('Need whole numbers paths >= 2 and steps >= 1');
  const {muX, muY, sX, sY, rho} = p, z = normals(seed), dt = 1 / steps, sq = Math.sqrt(dt), c = Math.sqrt(1 - rho * rho);
  let sV = 0, sZ = 0, sL = 0, sL2 = 0, cxy = 0, perp = 0;
  for (let k = 0; k < paths; k++) {
    let X = 1, Y = 1, crossSum = 0, perpSum = 0;
    for (let i = 0; i < steps; i++) {
      const a = sq * z(), b = sq * z(), dWy = rho * a + c * b;
      X *= 1 + muX * dt + sX * a; Y *= 1 + muY * dt + sY * dWy;
      crossSum += a * dWy; perpSum += a * b;
    }
    const L = Math.log(X * Y);
    sV += X * Y; sZ += X / Y; sL += L; sL2 += L * L; cxy += crossSum; perp += perpSum;
  }
  const mL = sL / paths;
  return {meanV: sV / paths, meanZ: sZ / paths, sdLogV: Math.sqrt((sL2 - paths * mL * mL) / (paths - 1)),
    meanCross: cxy / paths, meanPerp: perp / paths};
}
const desk = {muX: 0.08, muY: 0.10, sX: 0.20, sY: 0.25, rho: 0.60};
const d = pairDynamics(desk), N = 20000, sim = simulatePair(desk, N, 252, 135);
const sdV = Math.exp(d.product.drift) * Math.sqrt(Math.exp(d.product.vol ** 2) - 1);
const sdZ = Math.exp(d.ratio.drift) * Math.sqrt(Math.exp(d.ratio.vol ** 2) - 1);
const neg = pairDynamics({...desk, rho: -0.40}), zeroRho = pairDynamics({...desk, rho: 0});
const thb = pairDynamics({muX: 0.08, muY: 0, sX: 0.20, sY: 0.08, rho: -0.30});
const rhoSE = (1 - desk.rho ** 2) / Math.sqrt(252), slope = 1e6 * desk.sX * desk.sY * Math.exp(d.product.drift);

สิ่งที่ควรตอบได้หลังอ่าน

  • เมื่อสอง Brownian motion มี correlation $\rho$ ตารางคูณมีช่องใหม่ $dW^X\,dW^Y=\rho\,dt$ ส่วนที่ร่วมกันให้ $\rho\,dt$ ส่วนที่อิสระกันรวมทั้งปีแล้วหาย เพราะ SD ของผลรวมคือ $\sqrt{1/n}$ ซึ่งหดเมื่อซอยละเอียด
  • Itô สองตัวแปรเพิ่มสามพจน์ใน drift คือ $\tfrac12b_X^2f_{xx}+\tfrac12b_Y^2f_{yy}+\rho b_Xb_Yf_{xy}$ และกฎผลคูณคือ $d(XY)=X\,dY+Y\,dX+dX\,dY$
  • ผลคูณของสอง GBM ก็เป็น GBM มี drift $\mu_X+\mu_Y+\rho\sigma_X\sigma_Y$ และความผันผวนรวมแบบ variance $\sigma_V^2=\sigma_X^2+\sigma_Y^2+2\rho\sigma_X\sigma_Y$
  • note ที่จ่าย \$1 ล้าน คูณตัวคูณของ SPY คูณของ QQQ จ่ายเฉลี่ย \$1,233,678 ไม่ใช่ \$1,197,217 ผันผวน 40.31% ไม่ใช่ 45% และค่าเฉลี่ยขยับ \$617 ต่อ correlation ที่เปลี่ยน 0.01
  • อัตราส่วน $X/Y$ ได้ $+\sigma_Y^2$ จากความโค้งของ $1/y$ และ $-\rho\sigma_X\sigma_Y$ จากพจน์ไขว้ จึงโต 1.25% ต่อปี ไม่ใช่ −2%

หน้าถัดไป Girsanov และ risk-neutral measure ใช้กฎผลคูณกับราคาหุ้นคูณน้ำหนักของเส้นทาง แล้วตอบว่าทำไมราคาของ option ไม่ขึ้นกับ drift ของหุ้นเลย
