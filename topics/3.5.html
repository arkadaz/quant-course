3.5 Hypothesis Testing and Sharpe-Ratio Inference

การทดสอบถามว่า “ถ้าไม่มี edge เลย ข้อมูลแบบนี้หายากแค่ไหน” และ Sharpe ratio ของข้อมูลอิสระก็คือสถิติ t ที่หารด้วยรากของจำนวนปี

ทีมวิจัยส่ง backtest สามปีของกลยุทธ์สมมติตัวหนึ่ง Sharpe รายปี 1.20 หลังหักต้นทุนแล้ว มาขออนุมัติเงินจริง Sharpe เกินหนึ่ง ดูดีพอ คุณควรถามอะไรก่อนเซ็น และหลักฐานนี้แข็งแค่ไหน

ลองตอบก่อนเปิดเฉลย

ถามก่อนว่าคำนวณจากข้อมูลความถี่ไหน ถ้าเป็นผลตอบแทนรายวัน 756 วัน สถิติคือ $1.20\sqrt3\approx2.08$ ได้ p ราว 3.8% ผ่านเกณฑ์ 5% แบบเฉียด ๆ ถ้ามีแค่ผลตอบแทนรายปีสามตัว p จะเป็นราว 17.3% ไม่ผ่าน ต่อให้ Sharpe จริงคือ 1.20 การทดสอบสามปีก็จับได้เพียงราว 55% ของครั้ง และ SE ของ Sharpe คือราว 0.58 ช่วง 95% จึงกว้างตั้งแต่ราว 0.07 ถึง 2.33 หลักฐานยังบางมาก

ภาพรวมก่อนลงสูตร

การทดสอบสมมติฐานกลับด้านคำถามจาก confidence interval แทนที่จะถามว่าค่าใดเข้ากับข้อมูล มันตั้งโลกสมมติขึ้นมาหนึ่งโลก เช่น “กลยุทธ์ไม่มี edge” แล้วถามว่าในโลกนั้นข้อมูลที่สุดโต่งอย่างน้อยเท่าที่เห็นเกิดบ่อยแค่ไหน ตัวเลขนี้คือ p-value ถ้ามันเล็กมาก โลกสมมติก็อธิบายข้อมูลได้ยาก

สำหรับกลยุทธ์ เครื่องมือหลักคือ Sharpe ratio เมื่อผลตอบแทนแต่ละงวดอิสระกัน Sharpe ที่คำนวณได้คือสถิติ $t$ ของค่าเฉลี่ยหารด้วยรากของจำนวนปี หลักฐานจึงโตตาม $\sqrt T$ เหมือนทุกอย่างในบทนี้ หน้านี้จะตอบสามคำถามแยกกัน: ข้อมูลนี้น่าประหลาดใจแค่ไหน (p-value) ถ้ามี edge จริงเราจะจับได้บ่อยแค่ไหน (power) และเรารู้ Sharpe แม่นแค่ไหน (SE)

เริ่มจากการทดสอบที่นับได้ด้วยมือ คือผู้จัดการกองทุนที่ชนะตลาดเก้าในสิบปี แล้วต่อไปยัง Sharpe การเลือกความถี่ข้อมูล power ช่วงของ Sharpe ขอบเขตของโอกาสขาดทุนที่ไม่ต้องสมมติ normal และผลของผลตอบแทนที่สัมพันธ์กันตามเวลา

ขั้นที่ 1 — ผู้จัดการที่ชนะตลาดเก้าในสิบปี

โจทย์ให้อะไรมาบ้าง: ผู้จัดการคนหนึ่งชนะตลาด (หลังปรับความเสี่ยงแล้ว) เก้าในสิบปี เขาบอกว่าตัวเองมีฝีมือและควรเก็บค่าธรรมเนียมสูง ตั้งโลกสมมติว่าเขาไม่มีฝีมือ: แต่ละปีชนะด้วยโอกาส $p=1/2$ และแต่ละปีอิสระกัน ให้ $X$ เป็นจำนวนปีที่ชนะ

\[\begin{aligned} X&\sim\operatorname{Binomial}(10,\ \tfrac12),\\ P(X\ge9)&=\binom{10}{9}\Big(\tfrac12\Big)^{10}+\binom{10}{10}\Big(\tfrac12\Big)^{10}\\ &=\frac{10+1}{1{,}024}\approx1.07\%. \end{aligned}\]

คำตอบ: ถ้าเขาไม่มีฝีมือ ประวัติดีอย่างน้อยเท่านี้เกิดเพียง 1.07% ของครั้ง ต่ำกว่าเกณฑ์ 5% ที่นิยมใช้ จึงปฏิเสธโลกไร้ฝีมือ เรานับ “อย่างน้อยเก้า” ไม่ใช่ “เก้าพอดี” เพราะคำถามคือผลที่ดีเท่านี้หรือดีกว่าหายากแค่ไหน และเป็นการทดสอบด้านเดียวเพราะสนใจแค่ฝีมือดี (สูตร binomial ให้จำนวนวิธีเลือกปีที่แพ้) แต่ถ้าเขาเป็นคนที่เก่งที่สุดจากผู้จัดการ 20 คน คำถามเปลี่ยนไปทันที ปัญหาการทดสอบหลายครั้ง จะคำนวณว่าตัวเลขนี้กลายเป็นราว 19%

ตรวจเองใน 10 วินาที: $2^{10}=1{,}024$ และการแพ้หนึ่งปีจากสิบปีเลือกได้ 10 แบบ บวกกรณีชนะหมดอีกหนึ่ง ได้ 11

ขั้นที่ 2 — ล็อกคำถามก่อนคำนวณ

ผู้จัดการคนนั้นใช้โครงเดียวกับทุกการทดสอบ ต้องตั้งสี่อย่างไว้ก่อนเห็นข้อมูล: โลกอ้างอิง $H_0$ ทางเลือก $H_1$ ด้านที่ทดสอบ และเกณฑ์ $\alpha$ จากนั้นคำนวณสถิติ $t_{\rm obs}$ จากข้อมูล แล้วหา p-value

\[\begin{aligned} H_0&:\ \mu=0,\qquad H_1:\ \mu\ne0,\\ p&=P_{H_0}\big(|t|\ge|t_{\rm obs}|\big),\\ P_{H_0}(p\le\alpha)&=\alpha,\\ P_{H_1}(p\le\alpha)&=1-\beta. \end{aligned}\]

p-value วัดความประหลาดใจของข้อมูลในโลก $H_0$ ไม่ได้วัดความน่าจะเป็นของ $H_0$ บรรทัดที่สองเป็นแบบสองด้าน เพราะ $H_1$ สนใจทั้งกำไรและขาดทุนผิดปกติ กฎการตัดสินคือปฏิเสธ $H_0$ เมื่อ $p\le\alpha$ บรรทัดที่สามบอกว่าในโลก $H_0$ กฎนี้ปฏิเสธผิด $\alpha$ ของครั้ง บรรทัดสุดท้ายนิยาม $\beta$ เป็นโอกาสไม่ปฏิเสธทั้งที่ $H_1$ จริง และ $1-\beta$ คือ power ถ้าตั้งใจทดสอบแค่ด้านบวกไว้ก่อน p จะเหลือราวครึ่งหนึ่งสำหรับสถิติบวก แต่สลับเป็นด้านเดียวหลังเห็นผลไม่ได้ เพราะเท่ากับให้ตัวเองโอกาสผ่านสองเท่า มีความผิดสองแบบ: ปฏิเสธ $H_0$ ทั้งที่มันจริง (false positive) เกิดด้วยโอกาส $\alpha$ และไม่ปฏิเสธทั้งที่มี edge จริง (false negative) เกิดด้วยโอกาส $\beta$ การไม่ปฏิเสธไม่ได้ยืนยันว่า $H_0$ จริง และการปฏิเสธไม่ได้บอกว่า edge ใหญ่พอคุ้มทุน p = 0.03 ไม่ได้แปลว่ามีโอกาส 97% ที่กลยุทธ์ดีจริง การแปลงเป็นโอกาสแบบนั้นต้องใช้ Bayes’ theorem กับสัดส่วนไอเดียที่ดีจริงตั้งแต่ต้น ซึ่ง ปัญหาการทดสอบหลายครั้ง คำนวณให้ดู

ขั้นที่ 3 — Sharpe ที่คำนวณได้คือสถิติ t หารด้วย √T

กลับมาที่ backtest ให้ $r_i$ เป็นผลตอบแทนส่วนเกินหลังต้นทุนของงวดที่ $i$ มี $n$ งวด หนึ่งปีมี $q$ งวด จึงมี $T=n/q$ ปี สถิติ $t$ ของการทดสอบค่าเฉลี่ยศูนย์คือค่าเฉลี่ยหารด้วย SE ของมัน เขียนใหม่ด้วย Sharpe ได้ทันที

\[\begin{aligned} t_{\rm obs}&=\frac{\bar r}{s/\sqrt n}=\hat s\sqrt n,\\ \widehat{\mathrm{SR}}&=\sqrt q\,\hat s,\\ t_{\rm obs}&=\widehat{\mathrm{SR}}\sqrt{n/q}=\widehat{\mathrm{SR}}\sqrt T,\\ 1.20\sqrt3&\approx2.0785. \end{aligned}\]

ถ้าผลตอบแทนแต่ละงวดอิสระและมาจากการแจกแจงเดียวกัน Sharpe ที่คำนวณได้กับสถิติ $t$ ของค่าเฉลี่ยคือตัวเดียวกัน ต่างกันแค่ตัวคูณ $\sqrt T$ ตัวเลข 2.0785 ออกมาเท่ากันไม่ว่าข้อมูลจะเป็นรายวัน รายเดือน หรือรายปี แต่การแจกแจงอ้างอิงไม่เท่ากัน ถ้าผลตอบแทนเป็น normal ภายใต้ $H_0$ สถิตินี้เป็น Student $t$ ที่ df เท่ากับ $n-1$ ไม่ใช่ $T-1$

ความถี่จำนวนข้อมูล / dfp สองด้านที่เกณฑ์ 5%
รายวัน $q=252$756 / 755ราว 3.80%ปฏิเสธแบบเฉียด
รายเดือน $q=12$36 / 35ราว 4.51%ปฏิเสธแบบเฉียด
รายปี $q=1$3 / 2ราว 17.32%ไม่ปฏิเสธ

สามแถวเป็นชุดข้อมูลสมมติที่ Sharpe รายปีเท่ากัน ไม่ใช่คำแนะนำให้เลือกความถี่ที่ได้ p ถูกใจ ข้อมูลรายปีสามตัวทำให้ SD เองไม่แน่นอนมาก Student $t$ ที่ df 2 จึงหางหนามาก ตัวเลข 252 คือจำนวนวันทำการโดยประมาณต่อปีของตลาดหุ้นสหรัฐฯ (ปี 2024 เปิด 251 วัน)

ขั้นที่ 4 — ประมาณด้วย normal และเส้นผ่านของ Sharpe

เมื่อมีข้อมูลรายวันหลายร้อยตัว Student $t$ แทบเป็น normal จึงคำนวณง่าย ๆ ได้ และกลับด้านเป็นคำถามที่ทีมชอบถาม: Sharpe ต้องสูงเท่าไรจึงจะผ่านเกณฑ์

\[\begin{aligned} p&\approx2\big[1-\Phi(2.0785)\big]\approx3.77\%,\\ \widehat{\mathrm{SR}}\sqrt T&\ge1.96,\\ \mathrm{SR}_{\rm crit}&=\frac{1.96}{\sqrt3}\approx1.132. \end{aligned}\]

เส้นผ่านของ Sharpe ลดลงตาม $1/\sqrt T$ สามปีต้องเกิน 1.13 สิบปีต้องเกิน $1.96/\sqrt{10}\approx0.62$ Sharpe 1.20 จึงสูงกว่าเส้นสามปีเพียง 0.07 ซึ่งบางมาก การประมาณ normal ให้ 3.77% ใกล้ค่าจาก $t_{755}$ ที่ 3.80% แต่ห่างไกลจาก 17.32% ของ $t_2$ ถ้ามีแค่สามจุดรายปี ห้ามใช้ normal เด็ดขาด p ด้านเดียว (ถ้ากำหนดไว้ก่อน) คือราว 1.88%

ขั้นที่ 5 — Power: ถ้า edge มีจริง เราจะเห็นมันบ่อยแค่ไหน

p-value ถามโลกที่ไม่มี edge power ถามโลกที่มี สมมติ Sharpe จริงคือ $S$ ต่อปี ในแบบจำลอง normal ที่ประมาณ SD ได้แม่น สถิติ $t$ จะแกว่งรอบ $\delta=S\sqrt T$ ด้วย SD หนึ่ง การทดสอบปฏิเสธเมื่อ $t$ ออกนอก ±1.96

\[\begin{aligned} \delta&=S\sqrt T,\\ 1-\beta&=P(t\gt1.96)+P(t\lt-1.96)\\ &=\Phi(\delta-1.96)+\Phi(-\delta-1.96),\\ S=1.2,\ T=3:\quad1-\beta&\approx54.7\%,\\ \delta=1.96+0.8416&\ \Rightarrow\ T=\Big(\frac{2.8016}{S}\Big)^2. \end{aligned}\]

ถ้ากลยุทธ์ดีจริงระดับ Sharpe 1.2 การทดสอบสามปีจะจับได้แค่ครึ่งหนึ่งเศษ เพราะสถิติแกว่งรอบ 2.08 ซึ่งอยู่ติดเกณฑ์ 1.96 พอดี ครึ่งหนึ่งของครั้งมันตกต่ำกว่าเกณฑ์ บรรทัดที่สองนับทั้งสองหาง แต่หางลบเล็กมากเมื่อ $\delta$ เป็นบวก บรรทัดสุดท้ายวางแผนให้ power 80%: ต้องให้ $\delta$ เกินเกณฑ์ 1.96 อีก 0.8416 ซึ่งคือ quantile 80% ของ normal ที่ $S=1.2$ ต้องใช้ราว 5.45 ปี ผู้จัดการ IR 0.5 ต้องใช้ราว 31.4 ปี และที่ 16 ปีซึ่งสถิติเฉลี่ยถึง 2 พอดี power มีแค่ราว 51.6% สำหรับข้อมูลน้อยที่ต้องประมาณ SD ด้วย power ที่แม่นต้องใช้ noncentral $t$ สูตรนี้เป็นการประมาณเมื่อข้อมูลมาก

ขั้นที่ 6 — Sharpe แม่นแค่ไหน: SE และช่วงของ Sharpe

นอกจากถามว่า Sharpe ต่างจากศูนย์ไหม ทีมยังอยากรู้ว่า 1.20 คลาดได้แค่ไหน Sharpe เป็นอัตราส่วนของสองค่าที่ต่างก็ประมาณมา ให้ $s=\mu/\sigma$ เป็น Sharpe จริงต่องวด ใช้ delta method (ขยับเล็ก ๆ รอบค่าจริง) กับทั้งตัวตั้งและตัวหาร

\[\begin{aligned} \hat s-s&\approx\frac{\bar r-\mu}{\sigma}-\frac{\mu}{\sigma^2}(\hat\sigma-\sigma),\\ \operatorname{Var}(\hat s)&\approx\frac1n+\frac{\mu^2}{\sigma^4}\cdot\frac{\sigma^2}{2n}=\frac{1+s^2/2}{n},\\ \operatorname{SE}(\widehat{\mathrm{SR}})&\approx\sqrt{\frac{1+\mathrm{SR}^2/(2q)}{T}},\\ q=252:\quad\operatorname{SE}&\approx\sqrt{\frac{1+1.44/504}{3}}\approx0.578. \end{aligned}\]

ความไม่แน่นอนของ Sharpe มาจากสองแหล่ง ค่าเฉลี่ยที่คลาด (พจน์ 1) และ SD ที่คลาด (พจน์ $s^2/2$) บรรทัดแรกคือความชันของ $\mu/\sigma$ ต่อ $\mu$ และต่อ $\sigma$ บรรทัดสองใช้ $\operatorname{Var}(\bar r)=\sigma^2/n$ และ $\operatorname{Var}(\hat\sigma)\approx\sigma^2/(2n)$ จาก estimator และ standard error ส่วนพจน์ไขว้หายเพราะค่าเฉลี่ยกับ SD ของข้อมูล normal อิสระกัน บรรทัดสามแปลงเป็นรายปี: คูณ variance ด้วย $q$ และแทน $s^2=\mathrm{SR}^2/q$ ข้อมูลรายวันสามปีให้ SE ราว 0.578 ช่วง 95% แบบประมาณคือ $1.20\pm1.96(0.578)$ หรือ 0.07 ถึง 2.33 ถ้ารู้ SD ล่วงหน้า SE จะเป็น $1/\sqrt3\approx0.577$ พจน์ SD แทบไม่มีผลเมื่อข้อมูลถี่ แต่ถ้ามีแค่ข้อมูลรายปีสามตัว สูตรให้ 0.757 ซึ่งยังไม่น่าเชื่อถือเพราะการประมาณนี้ต้องการข้อมูลมาก สังเกตหน่วยด้วย: ผลตอบแทนโตตามเวลา SD โตตามรากของเวลา Sharpe จึงมีหน่วย “ต่อรากที่สองของเวลา” Sharpe รายวันคูณ $\sqrt{21}$ เป็นรายเดือน (ราว 21 วันทำการต่อเดือน) และคูณ $\sqrt{252}$ เป็นรายปี

ขั้นที่ 7 — Sharpe บอกขอบเขตโอกาสขาดทุนได้ โดยไม่ต้องสมมติ normal

ผู้บริหารถามเสมอว่า “ปีนี้มีโอกาสขาดทุนหนักแค่ไหน” คำตอบแบบ normal ไวต่อหางมาก อสมการ Cantelli (Chebyshev ฉบับด้านเดียว) ให้ขอบเขตที่ใช้ได้กับทุกการแจกแจงที่มีค่าเฉลี่ย $\mu$ และ SD $\sigma$ เขียนการขาดทุนเป็นจำนวนเท่าของ SD คือ $L\sigma$ แล้วใช้ $\mu=\mathrm{SR}\cdot\sigma$

\[\begin{aligned} P(\xi\lt\mu-\lambda)&\le\frac{\sigma^2}{\sigma^2+\lambda^2},\\ \lambda=(L+\mathrm{SR})\sigma:\quad P(\xi\lt-L\sigma)&\le\frac{1}{1+(L+\mathrm{SR})^2},\\ \mathrm{SR}=3,\ L=2:\quad&\le\frac{1}{26}\approx3.85\%,\\ P(Z\lt-2-3)=\Phi(-5)&\approx2.9\times10^{-7}. \end{aligned}\]

Sharpe สูงทำให้ขาดทุนหนักเกิดยาก ไม่ว่าการแจกแจงจะหน้าตาแบบไหน แต่ขอบเขตนี้หลวมกว่าที่ normal บอกมาก บรรทัดสองแทน $\lambda=(L+\mathrm{SR})\sigma$ เพราะ “ต่ำกว่า $-L\sigma$” คือ “ต่ำกว่าค่าเฉลี่ยเกิน $L\sigma+\mu$” บรรทัดสุดท้ายคือคำตอบแบบ normal ซึ่งผลตอบแทนอยู่ห่างค่าเฉลี่ย $L+\mathrm{SR}=5$ SD ตัวอย่าง: กลยุทธ์ Sharpe รายปี 3 ความผันผวนรายปี \$50 ล้าน โอกาสขาดทุนอย่างน้อย \$100 ล้าน (สอง SD) ในหนึ่งปีไม่เกิน 3.85% ทุกกรณี ถ้าเชื่อ normal จะได้ราวสามในสิบล้าน ช่องว่างหลายหมื่นเท่านี้คือขนาดของความเสี่ยงที่ซ่อนอยู่ในข้อสมมติเรื่องหาง สำหรับ backtest ในโจทย์ ($\mathrm{SR}=1.2$, $L=0$) โอกาสขาดทุนทั้งปีไม่เกิน $1/(1+1.44)\approx41\%$ ขณะที่ normal บอก $\Phi(-1.2)\approx11.5\%$

ขั้นที่ 8 — ผลตอบแทนที่สัมพันธ์กันตามเวลา: Sharpe ที่ annualize แล้วสูงเกินจริง

ทุกสูตรข้างบนพิงความอิสระของแต่ละงวด กองทุนที่ถือสินทรัพย์สภาพคล่องต่ำมักมีผลตอบแทนรายเดือนที่สัมพันธ์กันเชิงบวก เพราะราคาประเมินค่อย ๆ ปรับตามตลาด ถ้า autocorrelation ระหว่างงวดคือ $\rho_k=\rho^k$ variance ของผลรวมหลายงวดจะโตเร็วกว่าจำนวนงวด

\[\begin{aligned} \operatorname{Var}\Big(\sum_{i=1}^{q}r_i\Big)&\approx q\sigma^2\,\frac{1+\rho}{1-\rho},\\ \mathrm{SR}_{\rm adj}&\approx\sqrt q\,\hat s\,\sqrt{\frac{1-\rho}{1+\rho}}\approx\widehat{\mathrm{SR}}(1-\rho),\\ \rho=0.3:\quad1.20\sqrt{0.7/1.3}&\approx0.88. \end{aligned}\]

งวดที่ดีตามด้วยงวดที่ดี ทำให้ทั้งปีแกว่งมากกว่าที่ $\sigma\sqrt q$ บอก การคูณ Sharpe ต่องวดด้วย $\sqrt q$ ตรง ๆ จึงสูงเกินจริง บรรทัดแรกคือตัวคูณระยะยาวของ AR(1) แบบเดียวกับใน central limit theorem (ใช้ได้ดีเมื่อ $q$ ใหญ่) บรรทัดสองหาร SD ทั้งปีด้วยรากของตัวคูณนั้น และเมื่อ $\rho$ เล็ก รากนี้ประมาณ $1-\rho$ ได้ กองทุนที่รายงาน Sharpe 1.20 จากผลตอบแทนรายเดือนที่ $\rho=0.3$ จึงมี Sharpe จริงราว 0.88 สถิติทดสอบก็ต้องหารด้วยตัวคูณเดียวกัน ถ้า $\rho=0.5$ สถิติ 2.08 จะเหลือ $2.08/\sqrt3\approx1.20$ หายจากระดับ “ผ่านเกณฑ์” ไปไกล ในงานจริงใช้ SE แบบ HAC (Newey–West) หรือ block bootstrap และตรวจ autocorrelation function ก่อนเสมอ

ความผิดที่ทำให้ตัวเลขดูน่าเชื่อแต่ผิด

อ่าน p เป็นโอกาสที่กลยุทธ์ไม่มีฝีมือ: p = 1.07% ของผู้จัดการเก้าในสิบปีคือโอกาสของข้อมูลในโลกไร้ฝีมือ ถ้าในตลาดมีผู้จัดการฝีมือดีเพียงน้อยนิด โอกาสที่คนนี้ไร้ฝีมืออาจยังสูงกว่ามาก

เปลี่ยนเป็นด้านเดียวหลังเห็นผล: p สองด้าน 3.77% กลายเป็น 1.88% ทันที การเลือกด้านหลังเห็นข้อมูลทำให้อัตราปฏิเสธผิดจริงเป็น 10% ไม่ใช่ 5%

ใช้ normal กับข้อมูลรายปีไม่กี่ตัว: สามจุดรายปีให้ p 17.32% ภายใต้ $t_2$ ไม่ใช่ 3.77%

เทียบ Sharpe ของกลยุทธ์ที่ขาดทุน: กลยุทธ์ค่าเฉลี่ย −5% ความผันผวน 5% มี Sharpe −1 ส่วนกลยุทธ์ค่าเฉลี่ย −5% เท่ากันแต่ความผันผวน 10% มี Sharpe −0.5 ซึ่ง “ดีกว่า” ทั้งที่ขาดทุนเท่ากันและเสี่ยงกว่า Sharpe ใช้จัดอันดับได้ดีเมื่อค่าเฉลี่ยเป็นบวกเท่านั้น

ลืมต้นทุนและการลองหลายแบบ: Sharpe ก่อนหักค่าธรรมเนียม slippage และค่ายืมหุ้นไม่ใช่หลักฐานของเงินจริง และถ้ากลยุทธ์นี้คือตัวที่ดีที่สุดจาก 200 แบบ p ของตัวเดียวไม่มีความหมายอีกต่อไป

ใช้ทำอะไรบนโต๊ะจริง

ก่อนอนุมัติกลยุทธ์ ขอให้ทีมบันทึกไว้ล่วงหน้า: $H_0$ ด้านที่ทดสอบ เกณฑ์ ความถี่ $q$ จำนวนข้อมูล $n$ จำนวนปี $T$ นิยามผลตอบแทนและต้นทุน วิธีจัดการ autocorrelation และ Sharpe ที่อยากจับได้พร้อม power ของมัน แล้วรายงาน estimate, SE, ช่วง, p และ power คู่กัน การผ่านเกณฑ์สถิติแยกจากเรื่อง capacity สภาพคล่อง leverage และความเสี่ยงหาง ซึ่งต้องตัดสินแยก การวัดผลแบบอื่นที่ใช้หลักเดียวกันได้แก่ alpha ของ CAPM และ การ backtest VaR

function integrate(f, a, b, steps = 4000) {
  const h = (b - a) / steps;
  let s = f(a) + f(b);
  for (let i = 1; i < steps; i++) s += (i % 2 ? 4 : 2) * f(a + i * h);
  return s * h / 3;
}
function Phi(x) {
  const ax = Math.abs(x), d = Math.exp(-ax * ax / 2) / Math.sqrt(2 * Math.PI);
  if (ax < 3) {
    let term = ax, sum = ax;
    for (let k = 1; term > 1e-17 * sum; k++) { term *= ax * ax / (2 * k + 1); sum += term; }
    return x < 0 ? 0.5 - d * sum : 0.5 + d * sum;
  }
  let f = 0;
  for (let k = 300; k >= 1; k--) f = k / (ax + f);
  return x < 0 ? d / (ax + f) : 1 - d / (ax + f);
}
// Two-sided Student-t p-value via x = sqrt(df) tan(theta).
function twoSidedT(t, df) {
  const f = th => Math.cos(th) ** (df - 1);
  const th = Math.atan(Math.abs(t) / Math.sqrt(df));
  return integrate(f, th, Math.PI / 2) / integrate(f, 0, Math.PI / 2);
}
const choose = (n, k) => { let c = 1; for (let i = 1; i <= k; i++) c = c * (n - k + i) / i; return c; };
const binomTail = (n, k) => { let s = 0; for (let j = k; j <= n; j++) s += choose(n, j); return s / 2 ** n; };
const SR = 1.2, years = 3, stat = SR * Math.sqrt(years);
const power = d => Phi(d - 1.96) + Phi(-d - 1.96);
const seSR = q => Math.sqrt((1 + SR * SR / (2 * q)) / years);
const result = {
  nineOfTen: binomTail(10, 9), eightOfTen: binomTail(10, 8),
  stat, normalP: 2 * (1 - Phi(stat)), oneSided: 1 - Phi(stat),
  dailyP: twoSidedT(stat, 755), monthlyP: twoSidedT(stat, 35), annualP: twoSidedT(stat, 2),
  criticalSharpe: 1.96 / Math.sqrt(years),
  power: power(stat), powerIR16: power(2),
  years80: [1.2, 0.8, 0.5].map(s => ((1.96 + 0.841621) / s) ** 2),
  power08: power(0.8 * Math.sqrt(3)),
  seDaily: seSR(252), seAnnualData: seSR(1), seKnownSD: 1 / Math.sqrt(years),
  ci: [SR - 1.96 * seSR(252), SR + 1.96 * seSR(252)],
  cantelli: 1 / (1 + (2 + 3) ** 2), normalTail: Phi(-5),
  lossBoundHook: 1 / (1 + SR * SR), lossNormalHook: Phi(-SR),
  srAdjusted: SR * Math.sqrt(0.7 / 1.3), statRho05: stat / Math.sqrt(3)
};
console.log(JSON.stringify(result, null, 1));

สิ่งที่ควรตอบได้หลังอ่าน

  • p-value คือโอกาสของข้อมูลที่สุดโต่งอย่างน้อยเท่าที่เห็นในโลก $H_0$ ผู้จัดการเก้าในสิบปีได้ 11/1,024 = 1.07%
  • Sharpe ของข้อมูลอิสระคือสถิติ $t$ หารด้วย $\sqrt T$: Sharpe 1.20 สามปีให้สถิติ 2.08 แต่ p ขึ้นกับ df คือ 3.80% (รายวัน) ถึง 17.32% (รายปี)
  • power ของการทดสอบสามปีเมื่อ Sharpe จริงคือ 1.2 มีแค่ราว 55% และ power 80% ต้องใช้ $(2.80/S)^2$ ปี
  • SE ของ Sharpe รายปีคือราว $\sqrt{(1+\mathrm{SR}^2/(2q))/T}$ สามปีรายวันได้ 0.578
  • Cantelli ให้ขอบเขตโอกาสขาดทุนสำหรับทุกการแจกแจง ซึ่งหลวมกว่า normal หลายหมื่นเท่าในหาง และ autocorrelation บวกทำให้ Sharpe ที่ annualize สูงเกินจริง
