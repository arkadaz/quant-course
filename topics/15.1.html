15.1 Ordinary Least Squares (OLS) Regression

ลากเส้นตรงผ่านจุดข้อมูล โดยให้ความพลาดยกกำลังสองรวมกันน้อยที่สุด ความชัน (slope) ของเส้นนี้คือ covariance หารด้วย variance และเป็นขนาด hedge ที่เหลือความเสี่ยงน้อยที่สุด

สมมติว่าคุณดูแลพอร์ตที่ถือหุ้น Apple (ชื่อย่อในตลาดคือ AAPL) มูลค่า \$1,000,000 ราคาหุ้นตัวนี้ขึ้นลงด้วยสองเหตุ เหตุแรกคือทั้งตลาดขึ้นลงพร้อมกัน เหตุที่สองคือข่าวเฉพาะของ Apple เอง คุณอยากตัดเหตุแรกทิ้ง ให้เหลือแค่ส่วนที่เป็นเรื่องของ Apple

เครื่องมือที่ใช้คือ SPY ซึ่งเป็นกองทุนที่ซื้อขายเหมือนหุ้น และวิ่งตามดัชนี S&P 500 (ดัชนีที่รวมราคาหุ้นใหญ่ 500 ตัวของสหรัฐ) SPY จึงใช้แทน “ทั้งตลาด” ได้ วิธีคือ short SPY ซึ่งแปลว่ายืม SPY มาขายก่อน แล้วซื้อคืนทีหลัง ฝั่ง short จึงได้กำไรเมื่อราคาลง ถ้าตลาดลง AAPL ขาดทุน แต่ฝั่ง short ได้กำไรมาชดเชย การถือของสองฝั่งให้หักล้างกันแบบนี้เรียกว่า hedge

ข้อมูลที่มีคือผลตอบแทนรายเดือนของทั้งสองตัว ห้าเดือนล่าสุด ผลตอบแทนรายเดือนคือราคาเปลี่ยนไปกี่ % ในหนึ่งเดือน (ตัวเลขสมมติ ตั้งให้คิดตามด้วยมือได้)

เดือน12345
SPY $x_t$ (%)2.0−1.50.53.0−1.0
AAPL $y_t$ (%)3.4−2.80.25.1−1.4

เพื่อนร่วมโต๊ะเสนอวิธีง่าย ๆ เขาหาค่าเฉลี่ยของแต่ละตัว ($\bar x$ ของ SPY และ $\bar y$ ของ AAPL) แล้วดูว่า AAPL ขึ้นมากกว่า SPY กี่เท่า

\[\begin{aligned}\bar x&=\frac{2.0-1.5+0.5+3.0-1.0}{5}=0.60,\\\bar y&=\frac{3.4-2.8+0.2+5.1-1.4}{5}=0.90,\\\bar y/\bar x&=0.90/0.60=1.5,\\1.5\times\$1{,}000{,}000&=\$1{,}500{,}000.\end{aligned}\]

เขาสรุปว่า AAPL ไวกว่าตลาด 1.5 เท่า คือตลาดขยับ 1% AAPL ขยับ 1.5% จึงให้ short SPY \$1.5 ล้าน ควรเชื่อเขาไหม?

ลองตอบก่อนเปิดเฉลย

ไม่ควร ค่าเฉลี่ยบอกแค่ว่าแต่ละตัวขึ้นเฉลี่ยเดือนละเท่าไร มันไม่ได้บอกว่าเดือนที่ SPY ขึ้นแรง AAPL ขึ้นตามแรงแค่ไหน แต่ hedge ต้องการรู้เรื่องหลัง เพราะเราอยากให้ฝั่ง short หักล้างการขยับของ AAPL ทีละเดือน

หน้านี้จะคำนวณขนาดที่ถูกให้ดูทีละขั้น ด้วยเส้นตรงที่เรียกว่าเส้น OLS ผลคือ AAPL ขยับราว 1.7075 เท่าของ SPY จึงควร short $1.707483\times\$1{,}000{,}000\approx\$1{,}707{,}483$ ในห้าเดือนนี้ พอร์ตที่ short แค่ 1.5 เท่ายังเหลือความผันผวน 0.53% ต่อเดือน แต่พอร์ตที่ short 1.7075 เท่าเหลือแค่ 0.35% ต่อเดือน ตัวเลขสองตัวนี้จะคำนวณในขั้นมุม hedge ด้านล่าง

ภาพรวมก่อนลงสูตร

โจทย์เปิดเรื่องถามว่า “เดือนที่ SPY ขยับ 1% AAPL มักขยับกี่ %” ถ้าวาดห้าเดือนเป็นห้าจุดบนกราฟ (แกนนอน SPY แกนตั้ง AAPL) คำตอบคือความชันของเส้นตรงที่ลากผ่านกลุ่มจุดได้ดีที่สุด ความชันนี้เรียกว่า slope และใช้เป็นขนาด hedge ได้เลย

เราเคยได้คำตอบแบบนี้มาแล้วตอนหา hedge ratio จาก conditional distribution ของ MVN (MVN คือ Normal หลายตัวแปร) ตอนนั้นได้ $\beta=\operatorname{Cov}/\operatorname{Var}$ โดย covariance วัดว่าสองตัวขยับไปด้วยกันแค่ไหน และ variance วัดว่า SPY แกว่งแค่ไหน แต่ตอนนั้นเราสมมติว่ารู้ covariance ของ model อยู่แล้ว บนโต๊ะจริงไม่มีใครบอก covariance ให้ มีแค่ข้อมูลย้อนหลังไม่กี่จุด

OLS (Ordinary Least Squares) คือวิธีเปลี่ยนจุดพวกนั้นเป็นเส้นตรงหนึ่งเส้น กติกาคือ วัดระยะแนวตั้งจากแต่ละจุดถึงเส้น ยกกำลังสอง แล้วรวมกัน เส้นที่ได้ผลรวมน้อยที่สุดคือเส้นที่ OLS เลือก

ดูรูปด้านล่าง จุดดำห้าจุดคือห้าเดือน เส้นน้ำเงินคือเส้นที่ OLS เลือก ขีดแดงแนวตั้งคือระยะที่เส้นพลาดในแต่ละเดือน เรียกว่า residual เส้นส้มประคือเส้น slope 1.5 ของเพื่อนร่วมโต๊ะ ทั้งสองเส้นผ่านจุดเขียว ซึ่งคือจุดค่าเฉลี่ย $(\bar x, \bar y)=(0.60, 0.90)$ แต่เส้นส้มถูกกำหนดด้วยจุดเขียวจุดเดียว (ลากจากจุด $(0, 0)$ ผ่านจุดเขียว) ส่วนเส้นน้ำเงินฟังทั้งห้าจุด

หน้านี้เดินตามลำดับนี้

  • ตั้งกติกาให้คะแนนเส้น แล้วใช้อนุพันธ์หาเส้นที่ได้คะแนนดีที่สุด
  • ลองกับห้าเดือนในโจทย์ จนได้ขนาด short เป็นดอลลาร์
  • มองจากมุม hedge ตรง ๆ แล้วพบว่าได้ slope ตัวเดียวกัน
  • แบ่ง variance ของ AAPL เป็นส่วนที่เส้นอธิบายได้กับส่วนที่เหลือ
  • วัดว่า slope ที่ได้จากห้าเดือนคลาดจากค่าจริงได้แค่ไหน
  • เขียนทุกอย่างเป็น matrix เพื่อใช้กับหลายตัวแปร
  • ปิดด้วยจุดข้อมูลจุดเดียวที่หมุนทั้งเส้นได้

การทาย $y$ จาก $x$ ด้วยสูตรที่มีตัวปรับ (parameter) ซึ่งหาค่าจากข้อมูล ใช้ตอบคำถามว่า “ถ้า $x$ ขยับเท่านี้ $y$ มักขยับเท่าไร”
Intercept และ slope
เส้นตรง $a+bx$ มี intercept $a$ คือค่าของเส้นตอน $x=0$ และ slope $b$ คือเส้นขึ้นกี่หน่วยเมื่อ $x$ เพิ่มหนึ่งหน่วย
Ordinary Least Squares (OLS)
วิธีเลือก intercept และ slope ให้ผลรวมของ residual ยกกำลังสองน้อยที่สุด ใช้กันมากที่สุด เพราะมีสูตรตรงที่คำนวณด้วยมือได้
Residual
ค่าจริงลบค่าที่เส้นทาย ในเดือนเดียวกัน บอกว่าเส้นพลาดตรงไหน และพลาดแบบมีรูปแบบที่เส้นมองไม่เห็นหรือไม่
SSE (sum of squared errors)
ผลรวมของ residual ยกกำลังสองทุกเดือน เป็นคะแนนของเส้น ยิ่งน้อยยิ่งดี
$R^2$ (coefficient of determination)
ส่วนของ variance ของ $y$ ในข้อมูลชุดนี้ที่เส้นอธิบายได้ เป็นตัวเลขระหว่าง 0 ถึง 1 บอกว่าเส้นเข้ากับข้อมูลย้อนหลังแค่ไหน แต่ไม่ได้รับรองว่าจะทายอนาคตได้
Standard error (SE)
ความผันผวนของค่าที่ประมาณได้ ถ้าเก็บข้อมูลชุดใหม่จากกลไกเดิมแล้วคำนวณซ้ำหลาย ๆ รอบ บอกว่า slope ที่ได้คลาดจากค่าจริงได้แค่ไหน
Degrees of freedom
จำนวนข้อมูลที่ยังเปลี่ยนได้อิสระ หลังหักตัวเลขที่ใช้ไปกับการประมาณ เช่น ห้าเดือนที่ใช้ไปกับ $a$ และ $b$ แล้วเหลือ 3
Leverage
น้ำหนักที่จุดข้อมูลหนึ่งมีต่อเส้น ขึ้นกับว่า $x$ ของจุดนั้นอยู่ห่างค่าเฉลี่ยแค่ไหน ใช้หาจุดที่ตัวเดียวก็หมุนเส้นได้
Design matrix
matrix $X$ ที่มีหนึ่งแถวต่อหนึ่งเดือน คอลัมน์แรกเป็น 1 ทุกแถว (ไว้คูณกับ intercept) คอลัมน์ถัดไปเป็นตัวแปรที่ใช้ทาย ทำให้เขียน OLS เป็นสมการเดียวที่ขยายไปหลายตัวแปรได้

ขั้นที่ 1 — นิยามเส้น นิยามความพลาด และกติกาให้คะแนน

ก่อนจะบอกว่าเส้นไหน “ดีที่สุด” ต้องตกลงสามเรื่องก่อน หนึ่ง เส้นหน้าตาอย่างไร สอง ความพลาดของแต่ละเดือนวัดอย่างไร สาม ให้คะแนนทั้งเส้นอย่างไร สามเรื่องนี้เป็นนิยาม ยังไม่มีอะไรต้องพิสูจน์

ในสูตร $a$ คือ intercept (ค่าของเส้นตอน $x=0$) และ $b$ คือ slope (เส้นขึ้นกี่หน่วยเมื่อ $x$ เพิ่มหนึ่งหน่วย) $\hat y_t$ คือค่าที่เส้นทายสำหรับเดือน $t$ ส่วน $n=5$ คือจำนวนเดือน

\[ \begin{aligned} \hat y_t&:=a+bx_t,\\ e_t&:=y_t-\hat y_t,\\ \operatorname{SSE}(a,b)&:=\sum_{t=1}^{n}e_t^2\\ &=\sum_{t=1}^{n}(y_t-a-bx_t)^2. \end{aligned} \]

เส้นคือ intercept บวก slope คูณ SPY ความพลาด $e_t$ คือ AAPL จริงลบค่าที่เส้นทาย และคะแนนของเส้นคือ SSE ผลรวมของความพลาดยกกำลังสอง ยิ่งน้อยยิ่งดี ทำไมวัดความพลาดในแนวตั้ง? เพราะคำถามบนโต๊ะคือ “SPY ขยับเท่านี้ AAPL ควรขยับเท่าไร” เรารู้ $x$ (SPY) แล้วอยากทาย $y$ (AAPL) ระยะแนวตั้ง $e_t$ จึงบอกว่าทาย AAPL พลาดไปกี่ % ซึ่งเป็นหน่วยของสิ่งที่เราสนใจพอดี

ทำไมต้องยกกำลังสอง ไม่รวม $e_t$ ตรง ๆ? เพราะบวกกับลบจะหักกันเอง เส้นแย่ ๆ ก็รวมได้ศูนย์ ตัวอย่างคือเส้นแนวนอน $\hat y_t=0.90$ ซึ่งไม่สนใจ SPY เลย ผลรวมความพลาดของมันคือ $\sum_t(y_t-0.90)=4.5-5\times0.90=0$ พอดี แต่ SSE ของมันคือ 43.36 (ผลรวมคอลัมน์สุดท้ายของตารางห้าเดือนด้านล่าง) การยกกำลังสองช่วยสามเรื่อง คือ ไม่ให้บวกกับลบหักกัน ลงโทษความพลาดก้อนใหญ่หนักกว่าก้อนเล็ก และได้ฟังก์ชันเรียบที่หาอนุพันธ์ได้

กติกากำลังสองยังมีความหมายลึกกว่านั้น ลองตัด SPY ออกไปก่อน สมมติว่าต้องทาย AAPL ทุกเดือนด้วยตัวเลขตัวเดียว $c$ ถ้าให้คะแนนด้วยกำลังสอง $c$ ที่ดีที่สุดคือค่าเฉลี่ย ถ้าให้คะแนนด้วยระยะห่างแบบค่าสัมบูรณ์ $c$ ที่ดีที่สุดคือ median (ตัวกลางเมื่อเรียงจากน้อยไปมาก AAPL เรียงได้ −2.8, −1.4, 0.2, 3.4, 5.1 ตัวกลางคือ 0.20)

\[ \begin{aligned} \frac{d}{dc}\sum_t(y_t-c)^2&=-2\sum_t(y_t-c)=0,\\ c&=\bar y=0.90,\\ \sum_t|y_t-0.20|&=3.2+3.0+0+4.9+1.6\\ &=12.70,\\ \sum_t|y_t-0.90|&=2.5+3.7+0.7+4.2+2.3\\ &=13.40,\\ \log f(e_t)&=-\tfrac12\log(2\pi\sigma^2)-\frac{e_t^2}{2\sigma^2},\\ \sum_t\log f(e_t)&=-\tfrac n2\log(2\pi\sigma^2)-\frac{\operatorname{SSE}}{2\sigma^2}. \end{aligned} \]

กำลังสองพาไปหาค่าเฉลี่ย เพราะอนุพันธ์ของผลรวมกำลังสองเป็นศูนย์ตรงที่ $\sum_t(y_t-c)=0$ พอดี ส่วนค่าสัมบูรณ์ให้ 12.70 ที่ median ซึ่งน้อยกว่า 13.40 ที่ค่าเฉลี่ย จึงเลือก median แทน เมื่อเติม SPY กลับเข้ามา OLS จึงเป็นการหา “ค่าเฉลี่ยของ AAPL เมื่อรู้ SPY”

สองแถวล่างตอบอีกคำถาม ถ้าความพลาดเป็น Normal ที่มี variance $\sigma^2$ ตัว $f$ คือ density ของมัน (ฟังก์ชันที่บอกว่าค่าแต่ละค่าเกิดง่ายแค่ไหน) ผลรวม log ของ density คือค่าคงที่ลบ $\operatorname{SSE}/(2\sigma^2)$ เส้นที่ทำให้ข้อมูลห้าเดือน “น่าเกิดขึ้นที่สุด” จึงเป็นเส้นที่ SSE น้อยที่สุด ซึ่งก็คือเส้น OLS เส้นเดียวกัน

ขั้นที่ 2 — ตั้งความชันทิศ a เป็นศูนย์: เส้นต้องผ่านจุดค่าเฉลี่ย

ตอนนี้ SSE เป็นฟังก์ชันของตัวไม่รู้สองตัว คือ $a$ กับ $b$ ลองนึกภาพพื้นผิวที่ความสูงคือ SSE อยู่เหนือระนาบ $(a, b)$ เพราะ SSE เป็นผลรวมของพจน์ยกกำลังสอง พื้นผิวนี้จึงเป็นชามหงาย จุดต่ำสุดของชามอยู่ตรงที่ความชันเป็นศูนย์ทั้งสองทิศ (เงื่อนไขอันดับหนึ่ง: gradient เป็นศูนย์ที่จุดต่ำสุด) เริ่มจากทิศ $a$ ก่อน เพราะได้ผลที่อ่านง่ายที่สุด

\[ \begin{aligned} \frac{\partial\operatorname{SSE}}{\partial a}&=-2\sum_t(y_t-a-bx_t)=0,\\ \sum_t y_t-na-b\sum_t x_t&=0,\\ a&=\bar y-b\bar x. \end{aligned} \]

อนุพันธ์ของ $(y_t-a-bx_t)^2$ เทียบ $a$ คือ $-2(y_t-a-bx_t)$ ตาม chain rule เพราะ $a$ อยู่ในวงเล็บโดยมีเครื่องหมายลบ จุดที่ต้องระวังคือก้อนกลาง $a$ ไม่เปลี่ยนตามเดือน การรวม $a$ ห้าเดือนจึงได้ $na$ ไม่ใช่ $a$ ตัวเดียว เมื่อหารทั้งสมการด้วย $n$ ก้อน $\sum_t y_t/n$ กลายเป็น $\bar y$ และ $\sum_t x_t/n$ กลายเป็น $\bar x$

ความหมายคือ ไม่ว่า slope จะเป็นเท่าไร เส้นที่ดีที่สุดต้องผ่านจุดค่าเฉลี่ย $(\bar x, \bar y)$ เสมอ ย้ายข้างแล้วเห็นชัด: $\bar y=a+b\bar x$ นี่คือจุดเขียวที่ทั้งสองเส้นในรูปแรกผ่าน

แถวแรกยังให้ของแถม เพราะ $y_t-a-bx_t$ ก็คือ $e_t$ สมการจึงบอกว่า $\sum_t e_t=0$ แปลว่า residual ของเส้น OLS ที่มี intercept รวมกันได้ศูนย์พอดี เราจะใช้ข้อนี้ตรวจเลขตอนไล่ residual ทีละเดือน

ขั้นที่ 3 — ตั้งความชันทิศ b เป็นศูนย์: ได้ covariance หารด้วย variance

ตอนนี้รู้แล้วว่า $a=\bar y-b\bar x$ เหลือตัวไม่รู้ตัวเดียวคือ $b$ จึงตั้งความชันทิศ $b$ ให้เป็นศูนย์ แล้วแทน $a$ ลงไป ก่อนเริ่ม ขอตั้งชื่อผลรวมสองตัวที่จะโผล่มา

  • $S_{xx}:=\sum_t(x_t-\bar x)^2$ คือผลรวมของระยะห่าง SPY จากค่าเฉลี่ย ยกกำลังสอง บอกว่า SPY กระจายกว้างแค่ไหน
  • $S_{xy}:=\sum_t(x_t-\bar x)(y_t-\bar y)$ คือผลรวมของระยะห่างของสองตัวคูณกัน เดือนที่ทั้งคู่อยู่ฝั่งเดียวกันของค่าเฉลี่ยให้ผลคูณเป็นบวก ผลรวมนี้จึงบอกว่าสองตัวขยับไปทางเดียวกันแค่ไหน
\[ \begin{aligned} \frac{\partial\operatorname{SSE}}{\partial b}&=-2\sum_t x_te_t=0,\\ e_t&=(y_t-\bar y)-b(x_t-\bar x),\\ \sum_t x_t(y_t-\bar y)&=b\sum_t x_t(x_t-\bar x),\\ \sum_t x_t(y_t-\bar y)&=S_{xy},\\ \sum_t x_t(x_t-\bar x)&=S_{xx},\\ \hat b&=\frac{S_{xy}}{S_{xx}}. \end{aligned} \]

อนุพันธ์ของ $e_t^2=(y_t-a-bx_t)^2$ เทียบ $b$ คือ $-2x_te_t$ เพราะ $b$ มี $x_t$ คูณอยู่ จากนั้นแทน $a=\bar y-b\bar x$ ลงใน $e_t$ แล้วจัดกลุ่ม ได้ $e_t=(y_t-\bar y)-b(x_t-\bar x)$ ย้ายก้อนที่มี $b$ ไปอีกข้างของสมการ

จังหวะที่คนมักสะดุดคือการเปลี่ยน $x_t$ ที่อยู่ข้างหน้าให้เป็น $x_t-\bar x$ ทำได้อย่างไร? ส่วนต่างของสองแบบคือ $\bar x\sum_t(y_t-\bar y)$ และก้อนนี้เป็นศูนย์ เพราะระยะห่างจากค่าเฉลี่ยรวมกันได้ศูนย์เสมอ: $\sum_t(y_t-\bar y)=\sum_t y_t-n\bar y=0$ การเปลี่ยนจึงเท่ากับบวกศูนย์ แต่ทำให้สูตรสมมาตรและอ่านออก ฝั่ง $x$ ก็ใช้เหตุผลเดียวกัน

ทำไมเรียกว่า covariance หารด้วย variance? ถ้าหาร $S_{xy}$ ด้วย $n-1$ จะได้ sample covariance ของ SPY กับ AAPL และถ้าหาร $S_{xx}$ ด้วย $n-1$ จะได้ sample variance ของ SPY (sample แปลว่าคำนวณจากข้อมูล) ตัวหาร $n-1$ ตัดกันเองในเศษส่วน $\hat b$ จึงเป็นสูตรเดียวกับ hedge ratio ของ MVN ต่างกันแค่ที่นั่นใช้ค่าของ model ส่วนตรงนี้ใช้ค่าจากข้อมูล

จุดนี้เป็นก้นชามจริง ไม่ใช่ยอดเขา เพราะอนุพันธ์อันดับสองทิศ $b$ คือ $2\sum_t x_t^2$ ซึ่งเป็นบวกเสมอ

ขั้นที่ 4 — ห้าเดือนในโจทย์: จากตารางถึงขนาด hedge

โจทย์ให้อะไรมาบ้าง: ข้อมูลห้าเดือนจากตารางในโจทย์เปิดเรื่อง คือ SPY $x=(2.0, -1.5, 0.5, 3.0, -1.0)$ และ AAPL $y=(3.4, -2.8, 0.2, 5.1, -1.4)$ หน่วย % ต่อเดือน จับคู่เดือนต่อเดือน และพอร์ต AAPL มูลค่า \$1,000,000 ตัวเลขทุกตัวหลังจากนี้มาจากของเหล่านี้เท่านั้น

\[ \begin{aligned} \bar x&=\frac{2.0-1.5+0.5+3.0-1.0}{5}\\ &=\frac{3.0}{5}=0.60,\\ \bar y&=\frac{3.4-2.8+0.2+5.1-1.4}{5}\\ &=\frac{4.5}{5}=0.90. \end{aligned} \]

ขั้นที่ 5 — มองจากมุม hedge: slope ตัวเดียวกันทิ้งความเสี่ยงน้อยที่สุด

โจทย์เปิดเรื่องไม่ได้ถามหาเส้น แต่ถามว่าควร short เท่าไร ลองตอบจากมุม hedge ตรง ๆ โดยไม่พูดถึงเส้นเลย

ทุก ๆ AAPL \$1 ที่ถือ ให้ short SPY มูลค่า $h$ ดอลลาร์ ตัว $h$ นี้เรียกว่า hedge ratio เดือนที่ AAPL ได้ $y_t$% และ SPY ได้ $x_t$% พอร์ตรวมได้ $y_t-hx_t$% (ฝั่ง short ได้กำไรเมื่อ SPY ลง จึงเป็นเครื่องหมายลบ) เราอยากให้พอร์ตรวมนี้แกว่งน้อยที่สุด จึงวัดด้วย $V(h)$ คือผลรวมกำลังสองของระยะห่างจากค่าเฉลี่ยของพอร์ตรวม (หาร $V$ ด้วย $n-1$ ก็คือ variance ของพอร์ตรวม) แล้วหา $h$ ที่ทำให้ $V$ ต่ำที่สุด

\[ \begin{aligned} V(h)&:=\sum_t\big[(y_t-\bar y)-h(x_t-\bar x)\big]^2\\ &=S_{yy}-2hS_{xy}+h^2S_{xx},\\ V'(h)&=-2S_{xy}+2hS_{xx}=0,\\ h^*&=S_{xy}/S_{xx}=\hat b,\\ V(\hat b)&=S_{yy}-S_{xy}^2/S_{xx}. \end{aligned} \]

ค่าเฉลี่ยของพอร์ตรวมคือ $\bar y-h\bar x$ ระยะห่างของเดือน $t$ จึงเป็น $(y_t-\bar y)-h(x_t-\bar x)$ เมื่อกระจายกำลังสองของ $(u-hv)$ เป็น $u^2-2huv+h^2v^2$ แล้วรวมทุกเดือน แต่ละก้อนกลายเป็น $S_{yy}$, $S_{xy}$ และ $S_{xx}$ ที่คำนวณไว้แล้ว ได้พหุนามดีกรีสองของ $h$ ที่เปิดขึ้น เพราะ $S_{xx}\gt0$ ก้นของมันอยู่ที่ $h^*=S_{xy}/S_{xx}$ ซึ่งคือ $\hat b$ ตัวเดิม แทน $h^*$ กลับเข้าไปได้ $S_{yy}-2S_{xy}^2/S_{xx}+S_{xy}^2/S_{xx}$ ซึ่งยุบเหลือแถวสุดท้าย

ไม่ใช่เรื่องบังเอิญ $V(h)$ ก็คือ SSE ของเส้นที่มี slope $h$ และผ่านจุดค่าเฉลี่ย การหา hedge ที่ดีที่สุดกับการหาเส้นที่ดีที่สุดจึงเป็นโจทย์เดียวกัน

ทีนี้แทนตัวเลขจากตารางห้าเดือน ($S_{yy}=43.36$, $S_{xy}=25.10$, $S_{xx}=14.70$) เพื่อเทียบ hedge ของเพื่อน $h=1.5$ กับ $h^*=\hat b$ ค่า $V$ มีหน่วย %² ซึ่งอ่านยาก จึงแปลงเป็นความผันผวนต่อเดือนด้วย โดยหารด้วย $n-1=4$ ได้ variance แล้วถอดรากได้ SD ส่วน $h=0$ คือไม่ hedge เลย ได้ $V(0)=S_{yy}$

\[ \begin{aligned} V(1.5)&=S_{yy}-2(1.5)S_{xy}+1.5^2S_{xx}\\ &=43.36-75.30+33.075\\ &=1.135,\\ V(\hat b)&=43.36-25.10^2/14.70\\ &=43.36-42.857823\\ &\approx0.502177,\\ \sqrt{V(0)/4}&=\sqrt{43.36/4}\approx3.292\%,\\ \sqrt{V(1.5)/4}&=\sqrt{1.135/4}\approx0.53\%,\\ \sqrt{V(\hat b)/4}&=\sqrt{0.502177/4}\approx0.35\%,\\ V(1.5)/V(\hat b)&=1.135/0.502177\approx2.26. \end{aligned} \]

พอร์ตที่ไม่ hedge มีความผันผวน 3.29% ต่อเดือน hedge แบบเพื่อนเหลือ 0.53% hedge ด้วย $\hat b$ เหลือ 0.35% นี่คือตัวเลขในเฉลยของโจทย์เปิดเรื่อง hedge 1.5 เท่าดูไม่ห่างจาก 1.7075 มาก แต่ทิ้ง variance ไว้มากกว่าถึง 2.26 เท่า

$S_{yy}=43.36$ คือผลรวมกำลังสองของระยะห่าง AAPL จากค่าเฉลี่ย หารด้วย $n-1$ ก็คือ variance ของ AAPL พูดง่าย ๆ คือ AAPL ขึ้นลงมากแค่ไหนก่อนมีเส้น คำถามคือ เส้นอธิบายก้อน 43.36 นี้ได้กี่ส่วน

วิธีคือแยกระยะห่างของแต่ละเดือน $y_t-\bar y$ เป็นสองท่อน ท่อนแรก $\hat y_t-\bar y$ คือส่วนที่เส้นทายได้ ท่อนที่สอง $e_t$ คือส่วนที่เส้นพลาด แล้วยกกำลังสองรวมกันทุกเดือน

\[ \begin{aligned} y_t-\bar y&=(\hat y_t-\bar y)+e_t,\\ \hat y_t-\bar y&=\hat b(x_t-\bar x),\\ \sum_t(\hat y_t-\bar y)e_t&=\hat b\sum_t x_te_t-\hat b\bar x\sum_t e_t\\ &=0-0=0,\\ S_{yy}&=\hat b^2S_{xx}+\operatorname{SSE},\\ \hat b^2S_{xx}&=1.707483^2(14.70)\approx42.857823,\\ 43.36&\approx42.857823+0.502177,\\ R^2&:=1-\frac{\operatorname{SSE}}{S_{yy}}=\frac{S_{xy}^2}{S_{xx}S_{yy}}\\ &=1-\frac{0.502177}{43.36}\approx0.988418,\\ \bar R^2&:=1-\frac{\operatorname{SSE}/(n-2)}{S_{yy}/(n-1)}\\ &=1-\frac{0.502177/3}{43.36/4}\\ &=1-\frac{0.167392}{10.84}\approx0.984558. \end{aligned} \]

ท่อนแรกเขียนเป็น $\hat b(x_t-\bar x)$ ได้ เพราะเส้นผ่านจุดค่าเฉลี่ย เมื่อยกกำลังสองผลบวกของสองท่อน จะมีพจน์ไขว้ $2\sum_t(\hat y_t-\bar y)e_t$ งอกออกมา จุดสำคัญคือพจน์นี้เป็นศูนย์ เพราะมันแตกเป็นสองก้อน คือ $\sum_t x_te_t$ กับ $\sum_t e_t$ และทั้งสองก้อนเป็นศูนย์จากสมการอนุพันธ์ทิศ $b$ และทิศ $a$ ที่เราได้มาแล้ว จึงเหลือแค่ $S_{yy}$ เท่ากับส่วนที่เส้นอธิบายบวก SSE

ในมุมเรขาคณิต ให้มองห้าเดือนเป็น vector ห้ามิติ พจน์ไขว้ที่เป็นศูนย์แปลว่า vector ของ residual ตั้งฉากกับ vector ของส่วนที่อธิบายได้ ความยาวกำลังสองจึงบวกกันแบบพีทาโกรัส ดังรูปสามเหลี่ยมด้านล่าง

$R^2$ คือส่วนที่เส้นอธิบายได้หารด้วยทั้งหมด ในกรณีตัวแปรเดียว $R^2$ เท่ากับ correlation ยกกำลังสอง: correlation ของห้าเดือนนี้คือ $\sqrt{0.988418}\approx0.994192$ ซึ่งก็คือ cosine ของมุมระหว่างสอง vector ตาม correlation คือ cosine ของมุม

$\bar R^2$ (adjusted $R^2$) ปรับ $R^2$ โดยหักจำนวนตัวเลขที่ใช้ไปกับการประมาณ ตัวบนคือ SSE หารด้วย $n-2=3$ เพราะเส้นใช้ตัวเลขไปสองตัว ($a$ กับ $b$) ตัวล่างคือ $S_{yy}$ หารด้วย $n-1=4$ เพราะใช้ไปหนึ่งตัว ($\bar y$) ผลคือ $\bar R^2$ จะลดลงเมื่อใส่ตัวแปรที่ไม่ช่วยทายเพิ่มเข้าไป

$R^2$ ยังบอกเรื่อง hedge ได้ตรง ๆ variance ที่เหลือหลัง hedge คือ $1-R^2$ ของเดิม ถอดรากได้สัดส่วนของ SD ที่เหลือ แล้วคูณกับ SD ก่อน hedge ซึ่งคือ 3.292% ต่อเดือน (คำนวณในขั้นมุม hedge)

\[ \begin{aligned} 1-R^2&=1-0.988418=0.011582,\\ \sqrt{0.011582}&\approx0.1076,\\ 3.292\%\times0.1076&\approx0.354\%. \end{aligned} \]

ได้ 0.354% ต่อเดือน ตรงกับที่มุม hedge คำนวณไว้ แปลว่าหลัง hedge เหลือ variance แค่ 1.16% ของเดิม แต่ระวัง $R^2=98.84\%$ นี้มาจากห้าจุด กับเส้นที่มีตัวปรับสองตัว ขั้นถัดไปจะวัดว่า slope ที่ได้แม่นแค่ไหน

ขั้นที่ 8 — slope คลาดได้แค่ไหน: SE, t และช่วง 95%

ห้าเดือนนี้เป็นแค่ข้อมูลหนึ่งชุด ถ้าเก็บห้าเดือนชุดใหม่ slope ที่ได้จะไม่เท่าเดิม คำถามคือ slope แกว่งได้แค่ไหน จะตอบได้ต้องมี model ก่อนว่าข้อมูลเกิดขึ้นอย่างไร ขั้นนี้สมมติสามข้อ

  • AAPL เกิดจากเส้นจริงบวกเสียงรบกวน $y_t=a+bx_t+\varepsilon_t$ โดย $a$ กับ $b$ คือค่าจริงที่เราไม่รู้
  • เสียงรบกวน $\varepsilon_t$ ของแต่ละเดือนอิสระกัน และมี variance $\sigma^2$ เท่ากันทุกเดือน
  • ค่า SPY $x_t$ ถือเป็นของที่กำหนดแล้ว สิ่งที่สุ่มมีแค่ $\varepsilon_t$

SE (standard error) ของ slope คือ SD ของ $\hat b$ ถ้าทำซ้ำกับข้อมูลชุดใหม่หลาย ๆ ชุด ขั้นนี้หาสูตรของมัน แทนตัวเลข แล้วสร้างช่วงที่น่าจะครอบ slope จริงไว้

\[ \begin{aligned} \hat b&=\frac{1}{S_{xx}}\sum_t(x_t-\bar x)y_t,\\ \operatorname{Var}(\hat b)&=\frac{\sum_t(x_t-\bar x)^2\sigma^2}{S_{xx}^2}\\ &=\frac{\sigma^2}{S_{xx}},\\ s_e&=\sqrt{\operatorname{SSE}/(n-2)}\\ &=\sqrt{0.502177/3}\approx0.409136,\\ \operatorname{SE}(\hat b)&=\frac{s_e}{\sqrt{S_{xx}}}=\frac{0.409136}{\sqrt{14.70}}\\ &\approx0.106711,\\ t&=\frac{\hat b}{\operatorname{SE}(\hat b)}=\frac{1.707483}{0.106711}\approx16.00,\\ \hat b&\pm3.182\times\operatorname{SE}(\hat b)\\ &=1.707483\pm3.182(0.106711)\\ &=1.707483\pm0.3396\\ &\approx[1.3679,\ 2.0471]. \end{aligned} \]

ทำไม variance ของ $\hat b$ เป็น $\sigma^2/S_{xx}$? แถวแรกคือสูตร $S_{xy}/S_{xx}$ เดิมที่ตัด $\bar y$ ออก ตัดได้เพราะ $\sum_t(x_t-\bar x)\bar y=\bar y\times0=0$ เมื่อเขียนแบบนี้ $\hat b$ คือผลรวมถ่วงน้ำหนักของ $y_t$ ที่อิสระกัน น้ำหนักของเดือน $t$ คือ $(x_t-\bar x)/S_{xx}$ variance ของผลรวมแบบนี้คือผลรวมของน้ำหนักยกกำลังสองคูณ $\sigma^2$ (variance ของผลรวมตัวแปรอิสระคือผลรวมของ variance) ผลรวมของน้ำหนักยกกำลังสองคือ $S_{xx}/S_{xx}^2=1/S_{xx}$ ข้อสรุปคือ ยิ่ง SPY กระจายกว้าง ($S_{xx}$ ใหญ่) slope ยิ่งนิ่ง

เราไม่รู้ $\sigma^2$ จึงประมาณจาก residual เป็น $s_e^2$ ทำไมหารด้วย $n-2=3$ ไม่ใช่ 5? เพราะ residual ต้องทำตามสองสมการ คือ $\sum_t e_t=0$ และ $\sum_t x_te_t=0$ รู้สามตัวก็คำนวณอีกสองตัวได้ เหลือตัวที่อิสระจริงแค่สามตัว จำนวนนี้เรียกว่า degrees of freedom เป็นเหตุผลเดียวกับตัวหาร $T-1$ ของ sample covariance

ค่า $t$ คือ slope หารด้วย SE บอกว่า slope อยู่ห่างศูนย์กี่ SE ส่วน 3.182 คือค่าจากการแจกแจง Student t ที่ degrees of freedom 3 ซึ่งครอบพื้นที่ 95% ตรงกลาง (โค้ดท้ายหน้าคำนวณได้ 3.1824) ใช้สร้าง confidence interval 95% คือช่วงที่ถ้าทำซ้ำกับข้อมูลหลายชุด จะครอบค่าจริงได้ 95 ครั้งใน 100 ค่านี้ใหญ่กว่า 1.96 ของ Normal มาก เพราะข้อมูลมีน้อย จึงต้องเผื่อมากขึ้น

แปลงช่วงของ slope เป็นขนาด short โดยคูณด้วยมูลค่าพอร์ต \$1,000,000 (ใช้ทศนิยมเต็ม 1.367881 และ 2.047085)

\[ \begin{aligned} 1.367881\times\$1{,}000{,}000&\approx\$1{,}367{,}881,\\ 2.047085\times\$1{,}000{,}000&\approx\$2{,}047{,}085,\\ \$2{,}047{,}085-\$1{,}367{,}881&=\$679{,}204. \end{aligned} \]

ช่วงของขนาด short กว้างเกือบ \$680,000 ทั้งที่ $R^2$ สูงถึง 98.84% ส่วน $t=16$ บอกแค่ว่า slope ไม่ใช่ศูนย์แน่ ๆ ไม่ได้บอกว่าเรารู้ค่ามันแม่น สิ่งที่ทำให้ช่วงแคบลงได้คือข้อมูลที่มากขึ้น

ขั้นที่ 9 — เขียนเป็น matrix: สมการเดียวสำหรับกี่ตัวแปรก็ได้

ใน model หลายปัจจัย เราจะทาย AAPL จากตัวแปรสี่ตัวพร้อมกัน ถ้าหาอนุพันธ์ทีละทิศแบบขั้นก่อน ๆ จะได้สมการห้าสมการที่ยาวมาก ทางที่สั้นกว่าคือวางข้อมูลเป็น matrix แล้วทำขั้นตอนเดิมครั้งเดียว ลองกับห้าเดือนเดิมก่อน โดยตั้งชื่อของสามอย่าง

  • design matrix $X$ มีหนึ่งแถวต่อหนึ่งเดือน คอลัมน์แรกเป็น 1 ทุกแถว (ไว้คูณกับ $a$) คอลัมน์ที่สองคือ SPY $x_t$ (ไว้คูณกับ $b$)
  • $\mathbf y$ คือ vector ของ AAPL ห้าเดือน
  • $\beta=(a, b)$ คือ vector ของตัวไม่รู้ ทำให้ $X\beta$ คือค่าที่เส้นทายทั้งห้าเดือนในทีเดียว

SSE จึงเป็นความยาวกำลังสองของ vector $\mathbf y-X\beta$ การหาอนุพันธ์ใช้สูตรของ quadratic form จาก gradient และเงื่อนไขอันดับหนึ่ง ส่วนตัวเลขใน $X^{\mathsf T}X$ และ $X^{\mathsf T}\mathbf y$ เป็นผลรวมธรรมดาของข้อมูล

\[ \begin{aligned} X&=\begin{bmatrix}1&2.0\\1&-1.5\\1&0.5\\1&3.0\\1&-1.0\end{bmatrix},\quad\beta=\begin{bmatrix}a\\b\end{bmatrix},\\ \operatorname{SSE}(\beta)&=(\mathbf y-X\beta)^{\mathsf T}(\mathbf y-X\beta),\\ \nabla\operatorname{SSE}&=-2X^{\mathsf T}(\mathbf y-X\beta)=0,\\ X^{\mathsf T}X\hat\beta&=X^{\mathsf T}\mathbf y,\\ X^{\mathsf T}X&=\begin{bmatrix}n&\sum_t x_t\\\sum_t x_t&\sum_t x_t^2\end{bmatrix}=\begin{bmatrix}5&3\\3&16.5\end{bmatrix},\\ X^{\mathsf T}\mathbf y&=\begin{bmatrix}\sum_t y_t\\\sum_t x_ty_t\end{bmatrix}=\begin{bmatrix}4.5\\27.8\end{bmatrix},\\ \textstyle\sum_t x_t^2&=4+2.25+0.25+9+1=16.5,\\ \textstyle\sum_t x_ty_t&=6.8+4.2+0.1+15.3+1.4\\ &=27.8,\\ \det(X^{\mathsf T}X)&=5(16.5)-3^2=73.5,\\ \hat\beta&=\frac{1}{73.5}\begin{bmatrix}16.5&-3\\-3&5\end{bmatrix}\begin{bmatrix}4.5\\27.8\end{bmatrix}\\ &=\frac{1}{73.5}\begin{bmatrix}16.5(4.5)-3(27.8)\\-3(4.5)+5(27.8)\end{bmatrix}\\ &=\frac{1}{73.5}\begin{bmatrix}-9.15\\125.5\end{bmatrix}\\ &\approx\begin{bmatrix}-0.124490\\1.707483\end{bmatrix},\\ \operatorname{Cov}(\hat\beta)&=\sigma^2(X^{\mathsf T}X)^{-1}. \end{aligned} \]

สมการ $X^{\mathsf T}X\hat\beta=X^{\mathsf T}\mathbf y$ ไม่มีอะไรใหม่ ถ้าอ่านออกมาทีละแถวจะได้ $5a+3b=4.5$ ซึ่งคือสมการ $\sum_t y_t=na+b\sum_t x_t$ ของทิศ $a$ และ $3a+16.5b=27.8$ ซึ่งคือ $\sum_t x_ty_t=a\sum_t x_t+b\sum_t x_t^2$ ของทิศ $b$ matrix แค่จัดสองสมการเดิมให้เป็นระเบียบ ส่วนตัวเลขใน $\sum_t x_ty_t$ คือ SPY คูณ AAPL ทีละเดือน เช่น $2.0\times3.4=6.8$

การแก้หา $\hat\beta$ ใช้สูตร inverse ของ matrix 2×2: สลับสองตัวบนแนวทแยง เปลี่ยนเครื่องหมายสองตัวนอกแนวทแยง แล้วหารด้วย determinant ผลที่ได้คือ $\hat a$ และ $\hat b$ ตัวเดียวกับขั้นห้าเดือน

สมการ $X^{\mathsf T}(\mathbf y-X\hat\beta)=0$ ยังอ่านเป็นเรขาคณิตได้ มันบอกว่า vector ของ residual ตั้งฉากกับทุกคอลัมน์ของ $X$ ค่าที่เส้นทาย $\hat{\mathbf y}=X\hat\beta$ จึงเป็นเงาที่ตกตั้งฉาก (projection) ของ $\mathbf y$ ลงบนพื้นที่ที่คอลัมน์ของ $X$ กางออก ถ้าเปลี่ยนหน่วย หรือผสมคอลัมน์ใหม่แต่ยังกางพื้นที่เดิม เงานี้ก็ไม่เปลี่ยน

แถวสุดท้ายมาจากการแทน $\mathbf y=X\beta+\varepsilon$ ลงในสูตร ได้ $\hat\beta=\beta+(X^{\mathsf T}X)^{-1}X^{\mathsf T}\varepsilon$ ส่วนที่สุ่มมีแค่ $\varepsilon$ ช่องล่างขวาของ inverse คือ $5/73.5=1/14.70$ ตรงกับ $\sigma^2/S_{xx}$ ของ slope ในขั้น SE ช่องบนซ้ายคือ $16.5/73.5\approx0.2245$ ซึ่งเท่ากับ $1/n+\bar x^2/S_{xx}=0.2+0.36/14.70$ ตัวนี้ หน้า CAPM จะใช้วัดว่า alpha คลาดได้แค่ไหน

matrix นี้หา inverse ได้ก็ต่อเมื่อ determinant ไม่เป็นศูนย์ และ $\det=n\sum_t x_t^2-(\sum_t x_t)^2=nS_{xx}=5\times14.70=73.5$ พอดี ถ้า SPY เท่ากันทุกเดือน $S_{xx}=0$ ข้อมูลก็บอก slope ไม่ได้ นี่คือเรื่อง rank และ invertibility เมื่อคอลัมน์เกือบซ้ำกัน inverse จะพอง และ SE พองตาม เมื่อมี $K$ ตัวแปร สมการหน้าตาเดิม แค่ $X$ มี $K+1$ คอลัมน์

ขั้นที่ 10 — จุดเดียวหมุนเส้นได้: leverage

สมมติว่ามีเดือนหนึ่งที่บันทึกผิด หรือเป็นเดือนวิกฤตที่ไม่เหมือนเดือนอื่น slope จะเปลี่ยนไปเท่าไร? สูตร $\hat b=\sum_t(x_t-\bar x)y_t/S_{xx}$ จากขั้น SE ตอบได้ทันที เพราะ $\hat b$ เป็นผลรวมเชิงเส้นของ $y_t$ ถ้า AAPL ของเดือน $k$ เดือนเดียวขยับไป $\Delta y_k$ slope จะขยับ $\Delta\hat b$ ตามแถวแรกข้างล่าง

ลองให้ AAPL ขยับขึ้น $\Delta y_k=1.9$ จุด (ตัวเลขสมมติ) แล้วเทียบสองเดือน เดือนที่ 4 มี SPY ห่างค่าเฉลี่ย $3.0-0.60=2.4$ ส่วนเดือนที่ 3 ห่าง $0.5-0.60=-0.1$ จากนั้นคำนวณ leverage $h_k$ ของแต่ละเดือน ซึ่งวัดน้ำหนักของเดือนนั้นต่อเส้น (ตัว $h_k$ นี้เป็นคนละตัวกับ hedge ratio $h$ ชื่อมาจาก hat matrix)

\[ \begin{aligned} \Delta\hat b&=\frac{(x_k-\bar x)\,\Delta y_k}{S_{xx}},\\ k=4:&\quad\frac{2.4(1.9)}{14.70}\approx0.3102,\\ k=3:&\quad\frac{-0.1(1.9)}{14.70}\approx-0.0129,\\ h_k&:=\frac1n+\frac{(x_k-\bar x)^2}{S_{xx}},\\ h_4&=1/5+2.4^2/14.70\\ &=0.2+5.76/14.70\approx0.5918,\\ h_3&=1/5+(-0.1)^2/14.70\\ &=0.2+0.01/14.70\approx0.2007. \end{aligned} \]

AAPL ขยับขึ้น 1.9 จุดเท่ากัน แต่ผลต่อ slope ต่างกันราว $0.3102/0.0129\approx24$ เท่า เดือนที่ 4 มี SPY อยู่ห่างค่าเฉลี่ยถึง 2.4 จึงดึง slope จาก 1.7075 เป็น $1.7075+0.3102=2.0177$ ขนาด short เพิ่มราว $0.310204\times\$1{,}000{,}000\approx\$310{,}204$ ส่วนเดือนที่ 3 มี SPY 0.5 ซึ่งแทบตรงค่าเฉลี่ย ขยับ AAPL เท่าไรก็แทบไม่หมุนเส้น เหมือนคานกระดก จุดหมุนอยู่ที่ค่าเฉลี่ย ยิ่งไกลจุดหมุน แรงเท่ากันยิ่งหมุนได้มาก

$h_k$ ตอบคำถามว่า ถ้า $y_k$ ขยับ 1 ค่าที่เส้นทายตรงเดือน $k$ จะขยับตามเท่าไร ที่มาคือ $\hat y_k=\bar y+\hat b(x_k-\bar x)$ เมื่อ $y_k$ ขยับ 1 ค่า $\bar y$ ขยับ $1/n$ และ $\hat b$ ขยับ $(x_k-\bar x)/S_{xx}$ ตามแถวแรก รวมกันได้สูตร $h_k$ (ในภาษา matrix มันคือแนวทแยงของ projection $X(X^{\mathsf T}X)^{-1}X^{\mathsf T}$)

รวม $h_k$ ทุกเดือนได้ 2 เสมอ เพราะ $1/n$ ห้าครั้งรวมได้ 1 และ $(x_k-\bar x)^2/S_{xx}$ ห้าครั้งรวมได้ $S_{xx}/S_{xx}=1$ เลข 2 นี้เท่ากับจำนวนตัวปรับ ($a$ กับ $b$) ค่าเฉลี่ยของ leverage จึงเป็น $2/5=0.4$ เดือนที่ 4 ได้ 0.59 เกือบ 1.5 เท่าของค่าเฉลี่ย ส่วนเดือนที่ 3 ได้แค่ 0.20 ซึ่งใกล้ค่าต่ำสุดที่เป็นไปได้คือ $1/n=0.2$ เดือนที่ leverage สูงแบบเดือนที่ 4 ต้องตรวจให้ดีก่อนนำ hedge ratio ไปใช้

ความผิดที่ให้คำตอบผิดโดยไม่มี error ขึ้น

จับคู่ผิดเดือน: ถ้าไฟล์หนึ่งเลื่อนไปหนึ่งแถว AAPL เดือน $t$ จะถูกจับคู่กับ SPY เดือน $t-1$ เหลือสี่คู่ (SPY, AAPL) คือ (2.0, −2.8), (−1.5, 0.2), (0.5, 5.1), (3.0, −1.4) โปรแกรมรันผ่านทุกบรรทัด แต่ผลกลับทิศ ใช้เครื่องหมาย $'$ แทนค่าจากข้อมูลที่จับคู่ผิด

\[ \begin{aligned} \bar x'&=(2.0-1.5+0.5+3.0)/4=1.0,\\ \bar y'&=(-2.8+0.2+5.1-1.4)/4=0.275,\\ S_{xx}'&=1.0^2+2.5^2+0.5^2+2.0^2=11.5,\\ S_{xy}'&=1.0(-3.075)+(-2.5)(-0.075)\\ &\quad+(-0.5)(4.825)+2.0(-1.675)\\ &=-8.65,\\ \hat b'&=-8.65/11.5\approx-0.752174. \end{aligned} \]

slope ที่ถูกคือ $25.10/14.70\approx1.71$ แต่ข้อมูลที่จับคู่ผิดให้ −0.75 และ $R^2$ เหลือแค่ 0.18 (โค้ดท้ายหน้าคำนวณให้) slope ติดลบแปลว่าต้อง “ซื้อ” SPY $0.752174\times\$1{,}000{,}000\approx\$752{,}174$ แทนที่จะ short \$1,707,483 hedge จึงเพิ่มความเสี่ยงแทนที่จะลด ตรวจวันที่ของทั้งสองคอลัมน์ให้ตรงกันก่อนคำนวณเสมอ

ทำ regression กลับด้าน: ถ้าใช้ AAPL ทาย SPY (สลับ $x$ กับ $y$) แล้วกลับเศษเป็นส่วน จะได้ขนาด hedge ผิด เพราะเส้นนั้นวัดความพลาดในแนวนอน ซึ่งตอบคำถามว่า “เห็น AAPL แล้วทาย SPY” ให้ $\hat c$ คือ slope ของเส้นกลับด้านนี้

\[ \begin{aligned} \hat c&=S_{xy}/S_{yy}=25.10/43.36\approx0.5789,\\ 1/\hat c&=43.36/25.10\approx1.7275,\\ \hat b&=25.10/14.70\approx1.7075,\\ (1.7275-1.7075)\times\$1{,}000{,}000&\approx\$20{,}000. \end{aligned} \]

ขนาด hedge ต่างไปราว \$20,000 สองเส้นนี้ทับกันก็ต่อเมื่อ $R^2=1$ (โจทย์ข้อ 1 ด้านล่างแสดงว่าผลคูณของสอง slope คือ $R^2$) ให้ตัวที่จะถูก hedge (AAPL) อยู่ทางซ้ายของสมการเสมอ

อ่านหน่วยของ intercept ผิด: ถ้าข้อมูลเก็บเป็นทศนิยมแทน % (0.020 แทน 2.0%) slope ยังเป็น 1.7075 และ $t$ ยังเป็น 16.00 แต่ intercept กลายเป็น −0.001245 ซึ่งหมายถึง $-0.001245\times100=-0.1245\%$ ต่อเดือน ถ้าอ่าน −0.001245 เป็น % ตรง ๆ ตัวเลขจะเล็กไป 100 เท่า ตัวเลขนี้คือสิ่งที่ CAPM จะเรียกว่า alpha จึงผิดไม่ได้

ใช้ระดับราคาแทนผลตอบแทน: ราคาสองตัวที่ไต่ขึ้นเรื่อย ๆ ทั้งคู่ (มี trend) ให้ $R^2$ สูงได้ แม้ไม่เกี่ยวกันเลย และ SE ของ slope จะเล็กเกินจริงมาก เพราะความพลาดของเดือนที่ติดกันไม่อิสระกัน ซึ่งผิดข้อสมมติที่ขั้น SE ใช้ ส่วนหน้า spurious regression จะวัดขนาดของความผิดนี้ให้เห็นเป็นตัวเลข

ความผันผวนของความพลาดไม่คงที่: ถ้าเดือนวิกฤตมีความพลาดใหญ่กว่าเดือนปกติหลายเท่า สูตร SE ข้างบนจะผิด และเดือนที่แกว่งแรงจะคุมทิศของเส้น วิธีแก้มาตรฐานคือ weighted least squares คือให้น้ำหนักแต่ละเดือนเท่ากับหนึ่งหารด้วย variance ของความพลาดเดือนนั้น ซึ่งทำได้ง่าย ๆ โดยหาร $y_t$ และแถวของ $X$ ด้วย SD ของความพลาดเดือนนั้นก่อน แล้วทำ OLS ตามปกติ

ใช้ทำอะไรบนโต๊ะจริง

เส้นตรงแบบในหน้านี้โผล่อยู่ในงานจริงหลายแบบ

  • slope ของผลตอบแทนหุ้นเทียบกับผลตอบแทนตลาดเรียกว่า beta ใช้ตั้งขนาด hedge และรายงานว่าพอร์ตเปิดรับความเสี่ยงตลาดมากแค่ไหน (CAPM: beta และ alpha)
  • regression หลายตัวแปรแยกผลตอบแทนของกองทุนออกเป็นส่วนที่มาจากปัจจัยต่าง ๆ (factor) เช่น ตลาด ขนาดบริษัท หรือหุ้นราคาถูก (model หลายปัจจัย)
  • slope ของ log ราคาของหุ้นสองตัวที่ขยับคู่กัน คือ hedge ratio ของ pairs trading
  • regression ของผลตอบแทนเดือนหน้าบนสัญญาณของเดือนนี้ คือขั้นแรกของการทดสอบกลยุทธ์ และ spurious regression และ overfitting เตือนว่ามันหลอกเราได้ง่ายแค่ไหน
  • risk model ขนาดใหญ่ใช้ OLS แบบถ่วงน้ำหนัก ทำกับหุ้นหลายพันตัวพร้อมกันทุกวัน (cross-sectional regression)

function checkPairs(x, y) {
  if (!Array.isArray(x) || !Array.isArray(y) || x.length !== y.length) {
    throw new TypeError('x and y must be arrays of the same length');
  }
  if (![...x, ...y].every(Number.isFinite)) throw new TypeError('x and y must hold finite numbers');
  if (x.length < 3) throw new RangeError('Need at least three pairs: two numbers are fitted, one is left for error');
  if (x.every(v => v === x[0])) throw new RangeError('x never changes, so the slope is undefined');
}
function sums(x, y) {
  const n = x.length, xbar = x.reduce((s, v) => s + v, 0) / n, ybar = y.reduce((s, v) => s + v, 0) / n;
  let Sxy = 0, Sxx = 0, Syy = 0;
  for (let t = 0; t < n; t++) {
    const dx = x[t] - xbar, dy = y[t] - ybar;
    Sxy += dx * dy; Sxx += dx * dx; Syy += dy * dy;
  }
  return {n, xbar, ybar, Sxy, Sxx, Syy};
}
// Two-sided 95% critical value of Student t, from the finite series for P(|T| <= t) with integer dof.
function tCritical(dof) {
  if (!Number.isInteger(dof) || dof < 1) throw new RangeError('Degrees of freedom must be a positive integer');
  const inside = t => {
    const th = Math.atan(t / Math.sqrt(dof)), c = Math.cos(th), s = Math.sin(th);
    let term = dof % 2 ? c : 1, sum = dof === 1 ? 0 : term;
    for (let k = dof % 2 ? 3 : 2; k <= dof - 2; k += 2) { term *= (k - 1) / k * c * c; sum += term; }
    return dof % 2 ? 2 / Math.PI * (th + s * sum) : s * sum;
  };
  let lo = 0, hi = 1000;
  for (let i = 0; i < 100; i++) { const mid = (lo + hi) / 2; if (inside(mid) < 0.95) lo = mid; else hi = mid; }
  return (lo + hi) / 2;
}
function fitLine(x, y) {
  checkPairs(x, y);
  const S = sums(x, y), n = S.n, b = S.Sxy / S.Sxx, a = S.ybar - b * S.xbar;
  const fitted = x.map(v => a + b * v), residuals = y.map((v, t) => v - fitted[t]);
  const sse = residuals.reduce((s, e) => s + e * e, 0);
  const s = Math.sqrt(sse / (n - 2)); // two fitted numbers use up two degrees of freedom
  const seB = s / Math.sqrt(S.Sxx), seA = s * Math.sqrt(1 / n + S.xbar ** 2 / S.Sxx), tCrit = tCritical(n - 2);
  return {...S, a, b, fitted, residuals, sse, ssr: b * S.Sxy, r2: 1 - sse / S.Syy,
    adjR2: 1 - (sse / (n - 2)) / (S.Syy / (n - 1)), s, seB, tB: b / seB, seA, tA: a / seA,
    tCrit, ci: [b - tCrit * seB, b + tCrit * seB],
    leverage: x.map(v => 1 / n + (v - S.xbar) ** 2 / S.Sxx),
    checks: {sumE: residuals.reduce((u, e) => u + e, 0), sumXE: residuals.reduce((u, e, t) => u + e * x[t], 0)}};
}
// Route 2: solve (X^T X) beta = X^T y with X = [1, x], using the 2 by 2 inverse.
function normalEquations(x, y) {
  checkPairs(x, y);
  const n = x.length, sx = x.reduce((s, v) => s + v, 0), sxx = x.reduce((s, v) => s + v * v, 0);
  const sy = y.reduce((s, v) => s + v, 0), sxy = x.reduce((s, v, t) => s + v * y[t], 0);
  const det = n * sxx - sx * sx;
  return {XtX: [[n, sx], [sx, sxx]], Xty: [sy, sxy], det, beta: [(sxx * sy - sx * sxy) / det, (n * sxy - sx * sy) / det],
    inverseDiagonal: [sxx / det, n / det]};
}

  if (!Number.isFinite(h)) throw new TypeError('Hedge ratio must be a finite number');
  const S = sums(x, y);
  return S.Syy - 2 * h * S.Sxy + h * h * S.Sxx;
}

สิ่งที่ควรตอบได้หลังอ่าน

  • OLS เลือก $a$ กับ $b$ ให้ SSE (ผลรวมความพลาดยกกำลังสอง) น้อยที่สุด ได้ $\hat b=S_{xy}/S_{xx}$ ซึ่งคือ covariance หารด้วย variance และ $\hat a=\bar y-\hat b\bar x$ เส้นจึงผ่านจุดค่าเฉลี่ยเสมอ
  • slope ของ OLS คือ hedge ratio ที่ทิ้ง variance ไว้น้อยที่สุด ในห้าเดือนนี้คือ 1.7075 ไม่ใช่ 1.5 จากอัตราส่วนของค่าเฉลี่ย เพราะค่าเฉลี่ยไม่ได้บอกว่าสองตัวขยับไปด้วยกันแค่ไหน
  • residual รวมกันได้ศูนย์ และคูณ $x$ แล้วรวมกันก็ได้ศูนย์ ในภาษา matrix คือ residual ตั้งฉากกับทุกคอลัมน์ของ $X$ variance ของ $y$ จึงแยกแบบพีทาโกรัสเป็นส่วนที่เส้นอธิบายบวกส่วนที่เหลือ
  • $R^2=98.84\%$ ไม่ได้แปลว่ารู้ slope แม่น ช่วง 95% ของห้าเดือนนี้คือ 1.37 ถึง 2.05 หรือ short ได้ตั้งแต่ \$1.37 ล้าน ถึง \$2.05 ล้าน
  • เดือนที่ $x$ อยู่ไกลค่าเฉลี่ยมี leverage สูง ขยับจุดเดียวก็หมุนเส้นได้ จึงต้องตรวจเดือนแบบนี้ก่อนเชื่อ hedge ratio
